# Aplicativos/serviços comerciais

Omarchy é focado principalmente em fornecer software gratuito e de código aberto, mas não é religioso quanto a isso. Às vezes, a melhor solução é uma oferta comercial, e está tudo bem. Aqui estão algumas das opções para as quais oferecemos uma instalação fácil.

## 1Password

Manter suas senhas em um gerenciador de senhas é uma prática recomendada. Ainda mais se você trabalha com uma equipe. E o [1password](https://1password.com/) é uma ótima solução, que também vem com uma ferramenta de linha de comando para integrar consultas de chaves em scripts.

Você inicia o 1Password com `Super + Shift + /`. Se ele ainda não estiver instalado, essa tecla de atalho inicia a instalação primeiro (você também pode usar _Instalar > Serviço > 1Password_ no menu do Omarchy). O instalador também traz a ferramenta de linha de comando do 1Password e configura a extensão do 1Password para Chrome e Chromium; reinicie seu navegador para carregá-la.

## Bitwarden

[Bitwarden](https://bitwarden.com/) é a alternativa de código aberto no espaço de gerenciadores de senhas, com um plano gratuito que cobre a maior parte do uso pessoal. Instale-o com _Instalar > Serviço > Bitwarden_ no menu do Omarchy, o que também traz a ferramenta de linha de comando do Bitwarden.

## Spotify

[Spotify](https://spotify.com/) é o serviço de streaming de música mais popular do mundo. O Omarchy o oferece como um aplicativo web, que oferece o player completo, as teclas de mídia e o Spotify Connect, mas não downloads offline. Inicie-o com `Super + Shift + M`.

## Slack

[Slack](https://slack.com/) é onde muitas equipes conversam, tanto dentro da empresa quanto com colaboradores externos. Instale-o com _Instalar > Serviço > Slack_ no menu do Omarchy, e ele abrirá assim que estiver pronto.

## Notion

[Notion](https://www.notion.com/) é um espaço de trabalho para notas, documentos e projetos. Instale seu aplicativo para desktop com _Instalar > Serviço > Notion_ no menu do Omarchy.

## Dropbox

[Dropbox](https://www.dropbox.com/) é uma ótima maneira de sincronizar arquivos entre máquinas mantendo um backup na nuvem. Para configurá-lo, selecione _Instalar > Serviço > Dropbox_ no menu do Omarchy. Ele adiciona um ícone do Dropbox à barra: clique nele para fazer login, depois use o mesmo painel para verificar seu armazenamento e abrir arquivos sincronizados recentemente.

## Tailscale

[Tailscale](https://tailscale.com/) é uma VPN mesh que torna super simples obter acesso a todos os seus computadores e servidores pela internet com segurança. Para configurá-lo, selecione _Instalar > Serviço > Tailscale_ no menu do Omarchy.

Ele ganha um painel na barra, um aplicativo web para o console de administração e o Taildrop para enviar arquivos entre suas máquinas — veja [rede](35-networking.md).

## ONCE

[ONCE](https://once.com/) é a linha de software da 37signals que você compra uma vez e executa no seu próprio servidor, como o sistema de chat Campfire. Selecione _Instalar > Serviço > ONCE_ no menu do Omarchy para instalá-lo, o que ativa seu serviço em segundo plano e o leva à interface de terminal do ONCE para continuar a partir daí.

## NordVPN

[NordVPN](https://nordvpn.com/) é um serviço de VPN padrão que permite que seu tráfego saia pela maioria das regiões ao redor do mundo. Para configurá-lo, selecione _Instalar > Serviço > NordVPN_ no menu do Omarchy. Após a reinicialização que ele solicita, execute `nordvpn login` para se autenticar.
