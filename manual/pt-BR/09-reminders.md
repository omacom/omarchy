# Lembretes

O Omarchy tem uma maneira integrada de definir lembretes simples com base em um temporizador de contagem regressiva e com uma mensagem. Você pode fazer isso via `Super + Ctrl + R`, ver todos os definidos via `Super + Ctrl + Alt + R` e limpar todos via `Super + Ctrl + Shift + R`. Tudo também acessível via _Acionar > Lembrete_. Você também pode usar a CLI com `omarchy reminder 7 'Tea ready'`.
