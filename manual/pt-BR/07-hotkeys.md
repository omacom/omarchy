# Atalhos de teclado

Você pode ver todas as principais combinações de teclas com `Super + K` (combinações do Tmux com `Super + Alt + K` e combinações do Herdr com `Super + Ctrl + K`).

| `Super + Alt + /` | Voltar pelas opções de escala do monitor |

| `Alt + Shift + Tab` | Percorrer para trás as janelas no workspace ativo |

| `Ctrl + Alt + Shift + Tab`| Percorrer o foco para trás entre os monitores |

Os atalhos de redimensionamento usam as teclas físicas `code:20` e `code:21` (XKB `<AE11>` e `<AE12>`), independentemente dos caracteres impressos no teclado. Nos teclados dos EUA, essas teclas são `-` e `=`; nos teclados japoneses (JIS), elas são `-` e `^`; nos teclados espanhóis, elas são `'` e `¡`. No JIS, `Super + ^` é `Super + Equal`, enquanto `Super + Shift + -` (que digita `=`) é `Super + Shift + Minus`.

## Área de transferência universal

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + A`           | Selecionar tudo em aplicativos que suportam `Ctrl + A`    |
| `Super + C`           | Copiar    |
| `Super + X`           | Recortar (não no terminal)    |
| `Super + V`           | Colar    |
| `Super + Ctrl + V`           | Gerenciador da área de transferência    |

Normalmente no Linux, você precisa de `Ctrl + Shift + C/V` para copiar e colar no terminal e de `Ctrl + C/V` para fazer isso em todos os outros lugares. Esses atalhos unificados de área de transferência do Omarchy funcionam em todo lugar.
