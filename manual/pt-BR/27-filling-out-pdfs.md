# Preenchendo PDFs

O Omarchy vem com um visualizador de PDFs agradável e básico chamado Visualizador de Documentos. É esse o programa que abrirá qualquer PDF em que você simplesmente clicar duas vezes.

Mas você só pode usar o Visualizador de Documentos para preencher PDFs que tiverem sido configurados como formulários. Se você precisar preencher PDFs que não tiverem, ou se precisar assinar um PDF, use o [Signed](https://github.com/omacom/signed). Inicie-o pelo inicializador de aplicativos (`Super + Space`), ou clique com o botão direito no arquivo, selecione _Abrir com..._ e escolha o Signed.

Pressione `T` para digitar texto e `D` para colocar a data de hoje. Os dois vão parar onde o ponteiro do mouse estiver. Arraste qualquer coisa para movê-la, arraste seu canto para deixá-la maior ou menor e clique duas vezes no texto para alterá-lo.

Para assinar, você precisará de uma imagem da sua assinatura: uma digitalização, ou uma foto bem iluminada dela em papel branco. Abra o menu _Assinatura_ (`Shift + S`), escolha _Adicionar assinatura..._, escolha a imagem e dê um nome a ela. O Signed remove o papel e mantém a tinta. A partir de então, `S` coloca sua assinatura sob o ponteiro do mouse.

Quando tiver terminado, use _Salvar cópia assinada..._ (`Ctrl + S`) para salvar o PDF preenchido ao lado do original, que nunca é alterado. Pressione `?` dentro do Signed para ver todos os atalhos.
