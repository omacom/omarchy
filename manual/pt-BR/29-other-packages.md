# Outros pacotes

O Arch tem uma incrível riqueza de pacotes disponíveis para quase qualquer tipo de software entre o repositório oficial e o Arch User Repository (AUR).

Não poderia ser mais fácil de usar também. Você instala um novo pacote do Arch indo a _Instalar > Pacote_ no menu do Omarchy (`Super + Space`) e digitando o pacote que quer. Ele filtrará automaticamente por busca difusa a lista de todos os pacotes. (Você também pode fazer isso manualmente usando `omarchy pkg add [package]` no terminal).

Você pode fazer o mesmo com o AUR, basta usar _Instalar > AUR_. Só lembre que o AUR não é verificado pela equipe do Arch. É como o RubyGems ou o npm. Qualquer um pode publicar.

Se você quiser remover um pacote, pode usar _Remover > Pacote_ no menu do Omarchy. Ele removerá o pacote, os arquivos de configuração e as dependências. (Você também pode fazer isso manualmente usando `omarchy pkg drop [package]`).
