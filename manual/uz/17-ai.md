### Agentlarni o'rnatish va yangilash

Hermes va OpenClaw'dan tashqari, bu agentlar mise'ning lazy o'rnatishidan foydalanadi: birinchi ishga tushirish CLI'ni o'rnatadi, keyingi ishga tushirishlar undan qayta foydalanadi. mise shuningdek o'rnatilgan agent uchun yangi nashrni ko'pi bilan har to'rt soatda bir marta, u boshlanishidan oldin yoki shell so'rovida fonda tekshiradi. Agar o'sha yangilash muvaffaqiyatsiz bo'lsa yoki siz oflayn bo'lsangiz, o'rnatilgan versiya ishlaydi. `omarchy update` o'rnatilgan agentlarni Omarchy'ning qolgan qismi bilan birga yangilaydi, va `mup` faqat mise tomonidan boshqariladigan vositalarni yangilaydi.

Agentning o'z yangilovchisi, masalan `claude update`, `codex update`, yoki ilovadagi yangilash tugmasi, mise tomonidan boshqariladigan o'rnatmani yangilamaydi. `codex update` muvaffaqiyatsiz bo'ladi, va `claude update` muvaffaqiyatli deb xabar berishi mumkin, shu bilan birga mise kuzatmaydigan alohida nusxani o'rnatadi. Agar siz agentning native o'rnatuvchisi va yangilovchisidan foydalanishni afzal ko'rsangiz, uni `disable_tools` ga qo'shing; qarang [Oldindan o'rnatilgan CLI vositalari](18-development-tools.md#preinstalled-cli-tools).

Barcha sozlangan lazy vositalarni kerak bo'lishidan oldin o'rnatish uchun `mise install --include-lazy` ni ishga tushiring. Bu Omarchy'ning boshqa standart CLI vositalarini ham, agentlarni ham o'z ichiga oladi. Bitta vositani o'rnatish yoki o'zingizning o'rnatmangizdan foydalanish uchun qarang [Oldindan o'rnatilgan CLI vositalari](18-development-tools.md#preinstalled-cli-tools).

`grok` mise'ning birinchi tomon `grok` paketi orqali, `claude` va `codex` kabi o'rnatiladi. `grok` ni ishga tushiring, yoki agentlar panelida uni yulduzcha bilan belgilang. x.ai dagi `curl | bash` o'rnatuvchisini o'tkazib yuboring. O'sha yo'l ikkinchi nusxani `~/.grok/bin` ga qo'yadi, uni `PATH` ga oldindan qo'shadi va Omarchy'ning wrapper'ini ustiga yozadi.

`dsh` o'z brauzer UI'ini `127.0.0.1:3080` da ochadi, ishga tushirish katalogi uning standart ish maydoni sifatida. Uning brauzer UI'i boshlang'ich prompt qabul qilmaydi, shuning uchun `omarchy agent prompt` uni clipboard'ingizdagi prompt bilan yopishtirish uchun ochadi. Omarchy uni DeepSeek'ning tasdiqsiz ruxsat preseti bilan boshlaydi. DeepSeek Harness rasmiy model API'sidan foydalanganingizda sessiya loglarini DeepSeek'ga yuklaydi; buni uning brauzer UI'ida _Settings > General > Upload Session Log_ ostida o'chiring. Unga yuborgan fikr-mulohazangiz ham sessiya bilan birga yuklanadi, agar uni `DSH_TELEMETRY_MODE=DISABLED` bilan boshlamasangiz.

### Standart agent

Standart agentingizni agentlar panelida agent yonidagi yulduzcha bilan tanlang, u standartda to'ldirilgan bo'ladi, yoki `omarchy default agent <name>` bilan, u shuningdek u yerda qatori bo'lmagan har qanday harness'ni ham qabul qiladi. Agar agent hali o'rnatilmagan bo'lsa, uni tanlash avval uni o'rnatadi, va u shuningdek ilova ishga tushirgichida, Agent yonida, o'z ishga tushirgichiga ega bo'ladi. Yangi Omarchy sizni bir martalik xabarnoma bilan uni sozlashga taklif qiladi, u agentlar panelini ochadi.

Claude'ni tanlash shuningdek Chromium, Chrome, Brave, Brave Origin va Edge uchun uning brauzer kengaytmasini sozlashga harakat qiladi. Kengaytma sozlamasi barcha foydalanuvchilarga tegishli va tizim parolingizni so'rashi mumkin; bekor qilish yoki kengaytma o'rnatilishi muvaffaqiyatsiz bo'lishi baribir Claude'ni tanlaydi va ishga tushiradi. Brauzeringizni qayta ishga tushiring, so'ralsa kengaytmani yoqing va uni ulashni yakunlash uchun Claude'ga kiring. Ulanishni tekshirish uchun Claude'da `/chrome` ni ishga tushiring. Firefox va Zen bu kengaymani qo'llab-quvvatlamaydi. Agar bu sozlama qo'shilishidan oldin Claude allaqachon standartingiz bo'lgan bo'lsa, kengaytmani o'rnatish uchun uni yana tanlang.

Tanlaganingizdan so'ng, `Super + Shift + Ctrl + A` standart agentni alohida terminal oynasida ishga tushiradi (yoki hali tanlamagan bo'lsangiz tanlovchini ochadi). Siz shuningdek uni `omarchy agent prompt "Review this project"` bilan to'g'ridan-to'g'ri vazifaga boshlashingiz mumkin. Freebuff va DeepSeek Harness boshlang'ich prompt qabul qilmaydi, shuning uchun ular o'rniga clipboard'ingizdagi prompt bilan yopishtirish uchun ochiladi. Shu tarzda ishga tushirilgan agentlar ularning tegishli so'rash uchun to'xtamaydigan rejimlarida qarovsiz ishlaydi, shuning uchun ular haqiqatan ham ish qilishiga tayyor bo'ling! MiniMax Code o'z interaktiv sessiyalari uchun bunday rejimga ega emas, shuning uchun u odatdagidek ruxsatlar so'raydi. Va agentlar uy katalogingiz uchun ishonchni eslab qolishdan bosh tortgani sababli, `$HOME` dan ishga tushirishlar o'rniga `~/Work` da boshlanadi.

Terminal yorliqlari ham bor: `a` standart agentni joriy terminalda inline ishga tushiradi, `c`, `cx` va `cy` esa OpenCode, Claude Code va Codex'ni to'g'ridan-to'g'ri boshlaydi (yana ularning avtomatik tasdiqlaydigan rejimlarida). Tema o'zgarishlari agentlarga ham sinxronlashadi: Claude Code, Pi, OpenCode va Hermes (Omarchy uni o'rnatgandan so'ng) Omarchy temasini almashtirganingizda hammasi ergashadi.

### Agent ko'rsatmalaringiz

Har bir agent uchun shaxsiy qoidalar `~/.agents/AGENTS.md` ga, `~/.agents/skills` dagi shared ko'nikmalar yoniga boradi. Uni agentlar panelidagi + yonidagi hujjat belgisi bilan oching, yoki `omarchy agent instructions --edit` bilan, u shuningdek uni o'z global faylini saqlaydigan har bir harness'ga bog'laydi: `~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.pi/agent/AGENTS.md`, `~/.config/opencode/AGENTS.md`, Copilot'ning `~/.copilot/copilot-instructions.md` va hokazo. Crush va Amp `~/.config/AGENTS.md` bog'lanishini o'qiydi, omp, Kimi va DeepSeek Harness esa `~/.agents/AGENTS.md` ni to'g'ridan-to'g'ri o'qiydi. Standart agentni tanlash ham uni bog'laydi. Sizda allaqachon bo'lgan ko'rsatmalar fayli, agar hali yo'q bo'lsa shared'ga aylanadi; aks holda u bog'lanish yonida `.bak` sifatida saqlanadi. Boshqa agent o'rnatgandan so'ng qayta bog'lash uchun `omarchy agent instructions` ni ishga tushiring.

### Agentlar paneli

Yuqori panelda agentlar belgisi bor. Agent sozlamaganingizdan oldin, uning paneli boshlashning uchta usulini taklif qiladi: Claude, Codex, Grok, Gemini, Muse, Cursor yoki Copilot obunasiga kirish, yoki More ostida OpenCode Go, MiniMax, Synthetic yoki Z.ai kodlash rejasi; Fireworks, OpenCode Zen and Go, OpenRouter bilan ishlatganingizcha to'lash, yoki More ostida DeepSeek yoki OpenCode kiradigan har qanday boshqa provider, hammasi OpenCode'da ishlaydi; yoki kompyuteringiz uchun eng yaxshi modelni ishga tushirish, agar unga mos kelsa. Birinchi tugatganingiz standart agentingizga aylanadi, va paneldagi +, yoki Omarchy Menu'da _Agent > Add_ keyinchalik xuddi shu uchtasini taklif qiladi. Shundan so'ng, panel har bir obunani bitta sahifaga qo'yadi: har bir agent va hisob uning rejasi bilan, uning 5 soatlik sessiya va haftalik limitlaridan har biri uchun o'lchagich resetgacha bo'lgan vaqt bilan (aniq foiz uchun ustiga olib boring), yoki qolgan oldindan to'langan balans, barchasi bo'ylab ishlatganingiz orqali aylanadigan qator ostida, masalan shu haftadagi tokenlar va eng ko'p ishlatilgan modelingiz. _Make something cool_ ostida u yangi tema, plugin, ilova yoki o'yin uchun starter promptlarni taklif qiladi, ular vazifani standart agentingizga topshiradi. Ilovalar Omarchy'ning o'z Hype, Monologue va Omacut'lari kabi, C++ va Qt Quick'da, omarchy-make-app agent skill'iga ergashib quriladi, va ularga kerak bo'lgan kompilator va Qt qismlari o'rnatilgan holda keladi. O'yinlar `~/Games/vibes` dagi bitta three.js sahifasidir, omarchy-make-game agent skill'iga ergashadi, va hammasi joriy temadagi bitta Game Vibes ishga tushirgichidan ochiladi; ular three.js'ni web'dan yuklaydi, shuning uchun boshlash uchun ulanish kerak. Claude Code, Codex, Grok, Kimi, Cursor va uning Grok Bot allowance'i, GitHub Copilot, Muse, Gemini (Antigravity orqali) va Devin ularning limitlari bilan qutidan tashqarida qamrab olingan, Kimchi uning rejasi, oldindan to'langan kreditlari va sarflash budjetlari bilan, va Hermes, Mistral Vibe va Qwen Code sessiyalari va tokenlarini siz ularni ishlatganingizdan keyin ko'rsatadi. pi, omp yoki opencode orqali ishlatadigan provider rejalari va kalitlari ham paydo bo'ladi: OpenCode Zen and Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan va Synthetic ularning limitlari bilan; OpenRouter va DeepSeek ularning oldindan to'langan balanslari bilan; Fireworks uning oxirgi 30 kundagi sarfi bilan. O'z uskunangizda ishga tushiradigan modellaringizdan tokenlar ham jami hisobga kiradi; modellarning o'zi o'z paneliga ega, [Mahalliy modellar](#local-models) ostida tasvirlangan. Har bir agent bitta marta hisoblanadi, kim unga to'lov qilsa o'sha ostida, uni qancha harness orqali boshqarsangiz ham.

Panel uchun panel belgisini chap tugma bilan bosing yoki `Super + Ctrl + X` bosing, standart agentingizni ishga tushirish uchun o'ng tugma bilan bosing, va yangilash uchun o'rta tugma bilan bosing. Uning ortidagi foydalanish yozuvlari har 15 daqiqada `omarchy agent usage update` tomonidan qayta yaratiladi, va panel hatto sinxronlangan papka orqali boshqa mashinalaringizdan foydalanishni birlashtira oladi. To'liq sozlamalar uchun `$OMARCHY_PATH/shell/plugins/agents/` ostidagi README'ga qarang.

### Bir nechta obunalar

Agar siz bir nechta Claude, Codex yoki Grok rejasi uchun to'lasangiz — masalan shaxsiy Max va ish rejasi — Omarchy ularning hammasini tizimga kirgan holda saqlay oladi va ular orasida harakatlanadi. Obunani agentlar panelidagi + bilan qo'shing, u sizni o'sha yerda bosqichma-bosqich olib boradi, yoki `omarchy agent account add claude Work` bilan (yoki `codex`, yoki `grok`). Xuddi shu + va buyruq Gemini (`gemini`) va OpenCode (`opencode`) ga kiradi, va Fireworks (`fireworks`) yoki OpenRouter (`openrouter`) API kalitini OpenCode'da saqlaydi; buyruq shuningdek Copilot (`copilot`), Cursor (`cursor`) va Muse (`muse`) ga kiradi. Ular har biri bitta tizimga kirishni saqlaydi. Agar yo'q bo'lsa, u CLI'ni o'rnatadi. Provider uchun birinchi hisob normal brauzeringiz orqali kiradi, aynan CLI doimo qidiradigan joyda. Undan keyingi har biri private oyna orqali kiradi, shuning uchun brauzeringiz allaqachon kirgan hisob xatolik bilan olinmaydi; u yerda qo'shayotgan hisobingiz sifatida kiring, va oldin ochgan har qanday private oynani avval yoping. Buning uchun hech qachon CLI'dan chiqmang: chiqish saqlangan kirishni bekor qiladi, va o'sha hisobni yana qo'shish kerak bo'ladi.

Obuna kirishlaringizni SSH orqali boshqa Omarchy mashinasiga nusxalash uchun `omarchy agent account copy user@laptop` ni ishga tushiring. Yuboruvchi manzilda o'rnatilmagan bo'lsa vaqtinchalik qabul qiluvchini ta'minlaydi, shuning uchun eski Omarchy mashinalari yangilanishsiz hisoblarni qabul qila oladi. O'rnatilgan qabul qiluvchilar ustunlikka ega. Bu barcha Claude, Codex va Grok obunalarini nusxalaydi; ularni tanlash uchun provider nomlarini qo'shing, masalan `omarchy agent account copy laptop claude`. Hisob nomlari va buyruq ID'lari manba bilan mos keladi, manzilda allaqachon mavjud hisoblarni ham o'z ichiga oladi. Nomi to'qnashsa, aloqasiz manzil hisoblari raqamli suffix oladi, va sozlamalar, ko'nikmalar, pluginlar va suhbat tarixi har bir mashinada mahalliy qoladi.

Mavjud manzil credential'lari saqlanadi. U yerda allaqachon kirgan manba hisobi credential'larini almashtirmasdan nomi sinxronlanadi; boshqa hisoblar uning yoniga qo'shiladi. Mos hisoblar uchun saqlangan credential'larni almashtirish uchun, manzilda o'sha hisob sessiyalarini tugatgandan so'ng `omarchy agent account copy --replace laptop claude` dan foydalaning. Yangi manzil shuningdek manbaning faol hisobi va almashtirish afzalliklarini oladi; o'rnashgan manzil o'zinikini saqlaydi.

Credential'lar SSH orqali sayohat qiladi va manzilda private fayllarda saqlanadi, shuning uchun faqat ishonadigan mashinalaringizga nusxalang. Bu bir martalik nusxa, doimiy sinxronlash emas. Codex refresh tokenlari boshqa mashina tomonidan aylantirilishi mumkin, nusxalangan kirishni yangilash kerak bo'lgan holatda qoldiradi; alohida kirishlar bir nechta mashinada bir vaqtning o'zida foydalanish uchun eng ishonchli tanlov bo'lib qoladi. Qarang [Codex'ning hisob autentifikatsiyasi bo'yicha qo'llanmasi](https://developers.openai.com/codex/auth/ci-cd-auth).

Provider boshiga bitta hisob faol, va har bir yangi sessiya shunday boshlanadi: `cx`, `cy`, oddiy `claude`, `codex` yoki `grok`, `omarchy agent` orqali ishga tushirilgan har qanday narsa, va CLI'ni `PATH` da topadigan scriptlar yoki editorlar. `omarchy agent account use work` bilan almashtiring (va `omarchy agent account use main` bilan orqaga), yoki panelda hisob raqamini bosib keyin `Enter` bosib (yoki uning yulduzini bosib). Ishlayotgan Claude sessiyalari ham ularning keyingi xabaridan almashtiradi: har bir Claude sessiyasi `~/.claude` da ishlaydi, u doimo faol hisob kirishini saqlaydi. Eski Omarchy tomonidan hisobning o'z papkasida boshlangan Claude sessiyasi chiqmaguncha o'sha kirishni saqlaydi, shuning uchun almashtirish o'sha sessiyalarni nomlaydi va ular ketgandan so'ng o'z-o'zidan tugaydi. Ishlayotgan Codex va Grok sessiyalari boshlagan hisobda qoladi. Suhbat tarixi, sozlamalar, ko'nikmalar va pluginlar hisoblar bo'ylab ulashilgan, shuning uchun bir xil papkada `claude --continue` yangi hisobda qoldirgan joyingizdan davom etadi.

Bir nechta hisob bilan, panel har bir hisob limitlarini yonma-yon ko'rsatadi, ishlatilayotganida to'ldirilgan yulduz bilan. Omarchy faol hisob limitning 95%idan o'tganda sizga xabar beradi, va xabarnomani bosish eng ko'p bo'sh joyi bo'lgan hisobga o'tadi. U hech qachon o'z-o'zidan o'tmaydi. Thresholdni `omarchy agent account threshold 90` bilan o'zgartiring. Agar har bir hisob threshold'dan yuqori bo'lsa, bu haqda bir marta eshitasiz, qaysi hisob birinchi bo'shashi bilan birga. Faol hisob uning threshold'idan 15 ball ichida bo'lsa (standartda 80%), uning limitlari har 15 da o'rniga har uch daqiqada tekshiriladi.

`omarchy agent account list` har bir hisob va uning eng oxirgi limitlarini ko'rsatadi, `omarchy agent account remove work` bittasini unutadi, va `omarchy agent account rename primary Hey` bittasini qayta nomlaydi (yoki panelda hisob nomini bosing). Bu buyruqlar standart agentingiz hisoblarida ishlaydi; boshqa providerga yetish uchun uni avval nomlang, masalan `omarchy agent account use codex side`. `~/.claude` yoki `~/.codex` da allaqachon bo'lgan kirishingiz _Main_ hisobdir. Codex'niki qayerda bo'lsa o'sha yerda qoladi; Claude'niki boshqa hisob faol bo'lganda o'z papkasida kutadi. Taxminan sakkiz soatdan ortiq ishlatilmagan hisob _Sign-in required_ ko'rsatishi mumkin; uni panelda to'g'ridan-to'g'ri yana kirish uchun bosing, yoki unga o'ting va sessiya boshlang, u kirishni o'z-o'zidan yangilaydi. `claude mcp add` bilan qo'shadigan MCP serverlar har bir Claude hisobiga yetadi, chunki ularning hammasi `~/.claude` da ishlaydi; Codex va Grok uchun, hisob qo'shilganda sizda bo'lgan serverlar unga keladi, lekin keyingilari faqat siz ularni qo'shgan hisobga yetadi. Claude Desktop o'z kirishini saqlaydi, va CLI binary'siga absolute path bilan sozlangan Codex yoki Grok vositalari o'tishga ergashmaydi. Aniq `CLAUDE_CONFIG_DIR`, `CODEX_HOME` yoki `GROK_HOME` tanlangan hisobdan ustun turadi.

### Crash diagnostikasi

Omarchy systemd-coredump'ni jarayon crash'lari uchun kuzatadi. Standart agent tanlaganingizdan so'ng, core dump qiladigan har qanday dasturingiz "Process crashed" xabarnomasini keltiradi — uni bosing, va crash sizning standart agentingizga Omarchy'ning omarchy-diagnose-crash skill'i bilan birga topshiriladi, u agentni core dump'dan faktlarni aniqlash va crash yuqoriga xabar berishga arziydimi yoki yo'qligini hal qilish orqali olib boradi. Siz shuningdek uni `coredumpctl list` dan har qanday PID'ga qarshi qo'lda `omarchy agent crash <pid>` bilan ishga tushirishingiz mumkin.

Kuzatuv standart bo'yicha yoqilgan. Uni _Trigger > Toggle > Crash Capture Off_ ostida o'chiring (yoki `omarchy toggle crash-capture` bilan) va xabarnomalar to'xtaydi; `omarchy agent crash <pid>` hali ham qo'lda ishlaydi.

Crash'lar shuningdek bir vaqtning o'zida bitta dasturda o'chirilishi mumkin, bu diagnostika oxirida sizga taklif qiladigan narsadir. `omarchy crash mute hyprland` faqat o'sha dastur uchun xabarnomalarni to'xtatadi, `omarchy crash mute hyprland off` ularni qaytaradi, va `omarchy crash mute` o'z-o'zidan siz o'chirganlaringizni ro'yxatlaydi. U binary path'ini uning nomi kabi mamnuniyat bilan qabul qiladi, shuning uchun `omarchy crash mute /usr/bin/hyprland` xuddi shu ishni qiladi. Unda bo'sh joy bo'lgan nomni quote qiling, masalan `omarchy crash mute 'Some App'`. Qolgan hamma narsa hali ham xabar beradi, va o'chirilgan dastur hali ham crash bo'ladi — bu eslatmani yashiradi, hech narsani tuzatmaydi.

### Desktop ilovalari

_Install > AI_ menyusi shuningdek bir nechta grafik AI ilovalarini olib yuradi: Amp Desktop, Antigravity Desktop, ChatGPT desktop ilovasi, Claude desktop ilovasi (Anthropic'ning Linux beta'si, Chat, Cowork va Claude Code tab'lari bilan), xAI modellar bilan chat qilish uchun Grok Bot, Herdr Desktop, Hermes Desktop, OpenClaw, Perplexity desktop ilovasi va T3 Code. Grok Bot desktop chat ilovasidir. Kodlash agenti `grok` buyrug'idir.

Hermes Desktop bilish kerak bo'lgani, chunki mashinada bitta Hermes bor, va u ilovaniki: Hermes faqat ilova orqali o'rnatiladi, va standart agent ishga tushiradigan `hermes` buyrug'i ilovaniki. Hermesni standart agent sifatida tanlash _Install > AI_ kirishi qiladigan xuddi shu narsani o'rnatadi: paket, va Hermes'ning o'z o'rnatuvchisi tomonidan sozlangan `~/.hermes` ostidagi Hermes runtime, birinchi marta bir necha daqiqa oladi. O'sha runtime terminal `hermes` buyrug'i, standart agent va ilova hammasi ishlatadigan yagona Hermesdir, va u Omarchy nashrini kutmasdan `hermes update` bilan o'zini yangilaydi. Uni o'rnatish shuningdek Hermesga Omarchy temasini `omarchy` nomli skin sifatida topshiradi, har bir Hermes yuzasi siz tema almashtirganingizda unga ergashadi; agar xohlamasangiz Hermes'ning Appearance sozlamalari ostida yoki `/skin` bilan boshqasini tanlang, va Omarchy o'sha tanlovni yolg'iz qoldiradi. Ilovani _Remove > AI_ ostida olib tashlash avval Hermesni yopadi, gateway bilan birga, o'sha runtime'ni u bilan olib ketadi, va siz boshqacha aytmasangiz chatlaringiz, xotiralaringiz va Hermes o'zi uchun yozgan skill'larni saqlaydi: u o'sha ma'lumot va ulanish sozlamalaringiz ham ketishi kerakmi deb so'raydi, standart yo'q.

OpenClaw'ning desktop tajribasi uning Control UI'idir, u o'zining mahalliy gateway'i tomonidan qo'llab-quvvatlanadigan web ilova sifatida ochiladi. OpenClaw `~/.openclaw` da yashaydi va o'zini yangilaydi: Control UI'ning "Update Gateway" tugmasidan foydalaning yoki `openclaw update` ni ishga tushiring, va gateway yangi versiyada qayta boshlanadi. Omarchy faqat yangi o'rnatma boshlanadigan nashrni tanlaydi. OpenClaw shuningdek standart agentingiz bo'lishi mumkin: uni _Agent > Harness_ ostida tanlash `~/.openclaw` da xuddi shu nusxani sozlaydi, va agent OpenClaw'ning terminal UI'ini uning gateway'iga ulangan holda ochadi. OpenClaw'ni _Remove > AI_ ostida olib tashlash gateway xizmati va ilovani u bilan olib ketadi va keyin `~/.openclaw` ham ketishi kerakmi deb so'raydi, chunki u OpenClaw'ning o'zi va u yuklab oladigan plugin runtime'lari bilan birga chatlaringiz va credential'laringizni saqlaydi; standart uni saqlaydi, va OpenClaw'ni yana o'rnatish uni qayta oladi.

Herdr Desktop [Herdr](https://herdr.dev) desktop ilovasidir: oynani yopganingizda uning core'ida ishlashda davom etadigan terminal va kodlash agentlarining spaces, tab va pane'lari. U paket o'rniga Herdr'ning o'z o'rnatuvchisidan keladi, shuning uchun u `~/.local/share/herdr-app` da yashaydi, sizda hali yo'q bo'lganda uning core'ini `~/.local/bin/herdr-core` da olib keladi, va ikkalasini ham o'zi yangilaydi. U Omarchy `Super + Ctrl + Return` da yetkazib beradigan `herdr` buyrug'i yonida o'tiradi, uni almashtirmaydi, va o'sha buyruqning to'g'ridan-to'g'ri tugmalarini oladi: `Alt + Return` va `Alt + Shift + Return` pane'ni pastga yoki o'ngga bo'ladi, `Alt + Escape` uni yopadi, `Ctrl + Alt + Arrow` pane'lar orasida harakatlanadi, `Alt + 1..9` va `Alt + Left/Right` tab tanlaydi, va `Alt + Up/Down` spaces orasida harakatlanadi. `Ctrl + 1..9` space tanlaydi va `Alt + Shift + Up/Down` agentlar bo'ylab qadamlaydi. `Ctrl + Space` prefix tugmalari faqat terminalda qoladi, chunki ilova ketma-ketlik uchun oddiy Ctrl tugmasini ushlab turolmaydi. Omarchy bularni `~/.config/herdr-app/keys.json` ga yozadi, va `omarchy-refresh-herdr-app` ularni qayta qo'yadi. Uni o'rnatish Herdr'ning Omarchy temasini tanlaydi, u shundan keyin Omarchy temangizga ergashadi. Herdr light rejim uchun bitta tema va dark uchun bitta tema saqlaydi, shuning uchun dark va light Omarchy temasi orasida almashgandan so'ng, boshqa rejim uchun Herdr'ning tema tanlovchisida Omarchy'ni yana bir marta tanlang.

T3 Code paket o'rniga `~/.local/share/t3code` dagi rasmiy AppImage nashridan ishlaydi, shuning uchun u o'zini yangilaydi. Uni o'rnatish Stable yoki Nightly kanalida boshlashni so'raydi; keyinchalik T3 Code sozlamalarida almashtiring. Threadlaringiz va sozlamalaringiz `~/.t3` da yashaydi, va T3 Code'ni _Remove > AI_ ostida olib tashlash ularni u bilan olib ketadi.

### Mahalliy modellar

Kodlash agentlaringiz uchun o'z mashinangizda ochiq modelni ishga tushiring. Promtlaringiz va kodingiz mashinada qoladi; modelga yuborilgan hech narsa undan chiqmaydi. Boshlang:

```bash
omarchy models use best text
```

Bu bu mashina uchun eng yaxshi text modelini sozlaydi, agentlaringiz ishlatadigan tur. Image, video va music modellarining o'z eng yaxshisi bor: `omarchy models use best image`, `video` yoki `music`. Har bir turning bu mashina uchun tanlovini ko'rish uchun `omarchy models use best` ni ishga tushiring.

Yoki mahalliy modellar panelini yuqori paneldagi sparkles belgisidan, agentlar belgisi yonida, yoki Super + Ctrl + Alt + X bilan oching, va + tanlang. Belgi model bu mashinaga mos kelganda paydo bo'ladi. Modellarni ishga tushiradigan Podman Omarchy bilan keladi, NVIDIA mashinasida NVIDIA container toolkit ham, bu ularga GPU beradi; agar biri yo'q bo'lsa, birinchi sozlash uni o'rnatadi. Omarchy keyin bu mashina uchun tavsiya etilgan modelni tanlaydi, uni yuklab oladi va boshlaydi. O'nlab GB yuklab olishni va model ishlayotganda mashina xotirasining ko'p qismini ishlatilishini kuting: Flash Next to'liq 256K konteksti bilan taxminan 100 GiB ishlatadi. Agar boshqa modellar unga kerak bo'lgan xotirani egallasa, u to'xtatilgan holda sozlanadi, birini to'xtatganingizda boshlashga tayyor. Model logout'da to'xtaydi; xotira boshqa narsa uchun kerak bo'lganda uni o'zingiz to'xtating.

`omarchy models list` variantlarni ko'rsatadi va ba'zilari nega mos kelmasligini tushuntiradi. Boshqasini sozlash uchun `omarchy models use <recipe>` ni ishga tushiring. Bugun, `qwen3.8-flash-next-gufo` va `qwen3.8-27b-gufo` 128 GB Strix Halo mashinalari uchun mavjud; 27B taxminan 40 GiB oladi, shuning uchun boshqa ish uchun joy qoldiradi. Intel'ning Arc B390'i bilan 64 GB laptopda, `qwen3.6-35b-a3b-llamacpp` taxminan 30 GiBda ishlaydi. Yangi recipe'lar va tavsiyalar `omarchy update` bilan, paket orqali keladi.

Siz sozlagan har bir model mahalliy modellar panelida o'z qatoriga ega bo'ladi: boshlash uchun play, to'xtatish va xotirasini bo'shatish uchun pause, va agentingizni unda ochish uchun terminal tugmasi. Yuqorida, bar mashina xotirasi Omarchy'ning o'zi (tizim va ilovalaringiz), har bir ishlaydigan model va bo'sh joy orasida qanday bo'linishini ko'rsatadi. To'xtagan modelga ishora qiling va bar u mos keladimi yoki qancha yetishmasligini ko'rsatadi. Bir nechtasi xotirada birga mos kelsa bir vaqtning o'zida ishlay oladi; agar biri mos kelmasa, Omarchy qaysi ishlaydigan modelni to'xtatishni aytadi. Ularni qayta tartiblash uchun qatorlarni ularning logosi bo'ylab sudrab olib boring, va model va uning yuklab olishini olib tashlash uchun tanlangan qatorda Delete bosing.

Siz sozlagan har bir kodlash modeli shuningdek ilova ishga tushirgichida, model nomi ostida va uning ishlab chiqaruvchisi logosi bilan, Claude, Codex yoki Grok'ga kirish bittasini qo'shishi kabi, o'z kirishiga ega bo'ladi. U agentingizni o'sha modelda ochadi, va agar ishlamayotgan bo'lsa avval modelni boshlaydi: terminal uning yuklanishini ko'rsatadi va u tayyor bo'lganda agentga topshiradi. Modelni olib tashlash uning kirishini olib tashlaydi.

Har bir model kodlash uchun emas. Image, video va music modellari o'rniga Fantasi'da ochiladi, Omarchy'ning ushbu mashinada ishlaydigan model bilan rasmlar, video va musiqa yaratish ilovasi, u yerda yoki mahalliy modellar panelidagi ularning qatoridan tanlanadi.

Model aynan sozlangani kabi ishlashda davom etadi, shuning uchun Omarchy yangilanishi hech qachon agentlaringiz ostida birini qayta boshlamaydi. Omarchy'da siz sozlagan model uchun yangi runtime yoki yangi weight'lar bo'lganda, uning qatori yangilash tugmasini ko'rsatadi: uni bosing va model fonda yana sozlanadi, faqat o'zgargan narsani yuklab oladi, va yangi versiyada qayta boshlanadi. To'xtagan model to'xtagan holda qoladi. `omarchy models update` terminaldan har bir model uchun xuddi shuni qiladi.

Buyruq qatoridan, `omarchy models start <recipe>` va `omarchy models stop <recipe>` xuddi shuni qiladi, `omarchy models status` har bir modelni ko'rsatadi, va `omarchy agent --local` standart agentingiz nima bo'lishidan qat'iy nazar, pi'da siz oxirgi boshlagan modelni ochadi. O'sha modelni agent hotkey'i, Quake console'i va _Make something_ ochadigan narsa qilish uchun `omarchy default agent local` ni ishga tushiring yoki _Agent > Harness_ ostida _Local model_ tanlang. pi shuningdek siz sozlagan har bir modelni, va siz juftlangan mashinalardagilarni, o'z model tanlovchisida ro'yxatlaydi, shuning uchun oddiy `pi` ham ularga yetadi. Har qanday OpenAI-compatible client ham ulana oladi: `status` har bir model manzilini ko'rsatadi (birinchisi `http://127.0.0.1:11435/v1`), recipe nomi modeldir, va kalit `~/.config/omarchy/agent-local/key` da.

`omarchy models remove <recipe>` modelni va boshqa hech bir model ishlatmaydigan yuklab olishlarni o'chiradi.

Uchinchi tomon runtime'lari ularning publisher'i bilan etiketlangan. Omarchy har bir modelni tarmoqqa kirishsiz ishga tushiradi.

### Mahalliy LLM'lar

Omarchy mahalliy LLM modellarini ishga tushirishning ikki usulini tavsiya qiladi: LM Studio va Ollama. LM Studio ochiq vaznli modellarni topish, ularni o'rnatish va ishga tushirish uchun GUI interfeysini taqdim etadi. Bu oson boshlash uchun ajoyib usul. Ollama xuddi shunday qilish uchun CLI taklif qiladi. Lekin agar siz mahalliy modellarga yangi bo'lsangiz, men LM Studio bilan boshlardim. Siz ikkalasini ham Omarchy Menu'da _Install > AI_ ostida o'rnatishingiz mumkin.

### Omarchy skill'lari

Agent skill'lari AI'ga muayyan vositalardan muayyan tarzda foydalanishga yordam beradi, va Omarchy ularning yettitasini yetkazib beradi. omarchy skill'i tizimni moslashni qamrab oladi, masalan Hyprland konfiguratsiyangizni sozlash yoki bar'ni moslash. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app va omarchy-make-game yangi narsa yaratishni qamrab oladi, omarchy-contribute bug haqida xabar berish yoki fix'ni upstream'ga yuborishni qamrab oladi, va omarchy-diagnose-crash crash'ning core dump'i orqali ishlaydi. Ular Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` va har bir `~/.hermes/profiles/*/skills`), va generic `~/.agents/skills` joylashuvi uchun skill kataloglariga symlink qilingan, shuning uchun ko'p harness'lar ularni avtomatik oladi. Xuddi shu nomdagi o'zingizning skill papkangiz ustunlikka ega.

Lekin siz bu skill'larga experimantal sifatida qarashingiz kerak. Turli modellar uni turli samara bilan ishlatadi. Avval plan rejimida ishlash eng yaxshisi, shuning uchun agent nimani o'zgartirmoqchi ekanligi haqida tasavvurga ega bo'lasiz. Va keyin o'zgarishlarni orqaga qaytarishga yoki hatto `omarchy reinstall configs` ni chaqirishga tayyor bo'ling, agar agent hammasini buzib tashlasa.
