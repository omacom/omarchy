### Agentlarni o'rnatish va yangilash

Hermes va OpenClaw dan tashqari, bu agentlar mise ning kechiktirilgan o'rnatishidan foydalanadi: birinchi ishga tushirish CLI ni o'rnatadi, keyingi ishga tushirishlar esa undan qayta foydalanadi. mise shuningdek o'rnatilgan agent uchun yangi nashr bor-yo'qligini ko'pi bilan har to'rt soatda bir marta, u boshlanishidan sal oldin yoki shell so'rovida fonda tekshiradi. Agar o'sha yangilanish muvaffaqiyatsiz tugasa yoki siz oflayn bo'lsangiz, o'rnatilgan versiya ishlaydi. `omarchy update` o'rnatilgan agentlarni Omarchy ning qolgan qismi bilan birga yangilaydi, `mup` esa faqat mise boshqaradigan vositalarni yangilaydi.

Agentning o'z yangilovchisi, masalan `claude update`, `codex update` yoki ilovadagi yangilash tugmasi, mise boshqaradigan o'rnatmani yangilamaydi. `codex update` muvaffaqiyatsiz tugaydi, `claude update` esa muvaffaqiyat haqida xabar berib, mise kuzatmaydigan alohida nusxani o'rnatishi mumkin. Agar agentning o'z o'rnatuvchisi va yangilovchisidan foydalanishni afzal ko'rsangiz, uni `disable_tools` ga qo'shing; qarang [Oldindan o'rnatilgan CLI vositalari](18-development-tools.md#preinstalled-cli-tools).

Barcha sozlangan kechiktirilgan vositalarni kerak bo'lishidan oldin o'rnatish uchun `mise install --include-lazy` ni ishga tushiring. Bu agentlar bilan birga Omarchy ning boshqa standart CLI vositalarini ham o'z ichiga oladi. Bitta vositani o'rnatish yoki o'z o'rnatmangizdan foydalanish uchun qarang [Oldindan o'rnatilgan CLI vositalari](18-development-tools.md#preinstalled-cli-tools).

`grok` mise ning birinchi tomon `grok` paketi orqali, `claude` va `codex` bilan bir xil tarzda o'rnatiladi. `grok` ni ishga tushiring yoki uni _Agent > Harness_ ostida tanlang. x.ai dagi `curl | bash` o'rnatuvchisini o'tkazib yuboring. O'sha yo'l ikkinchi nusxani `~/.grok/bin` ga joylashtiradi, uni `PATH` boshiga qo'shadi va Omarchy ning wrapper ini ustiga yozadi.

`dsh` o'zining brauzer UI sini `127.0.0.1:3080` da ochadi, ishga tushirish katalogi uning standart workspace i hisoblanadi. Uning brauzer UI si boshlang'ich prompt qabul qilmaydi, shuning uchun `omarchy agent prompt` uni prompt sizning clipboard ingizda yopishtirish uchun ochiq holda ochadi. Omarchy uni DeepSeek ning tasdiq talab qilmaydigan ruxsatlar preset i bilan boshlaydi. DeepSeek Harness rasmiy model API sidan foydalanganda session loglarini DeepSeek ga yuklaydi; buni uning brauzer UI sida _Settings > General > Upload Session Log_ ostida o'chiring. Unga yuborgan feedback ingiz ham, agar uni `DSH_TELEMETRY_MODE=DISABLED` bilan boshlamasangiz, session bilan birga yuklanadi.

### Standart agent

Standart agentingizni `omarchy default agent <name>` bilan yoki Omarchy Menu (`Super + Space`) dagi _Agent > Harness_ ostida tanlang. Agar agent hali o'rnatilmagan bo'lsa, uni tanlash avval o'rnatadi, shuningdek u ilova ishga tushirgichida, Agent yonida, o'zining ishga tushirgichiga ega bo'ladi. Yangi Omarchy sizni bir martalik bildirishnoma bilan bu tanlovni qilishga taklif qiladi.

Claude ni tanlash Chromium, Chrome, Brave, Brave Origin va Edge uchun uning brauzer kengaytmasini o'rnatishga ham urinadi. Kengaytma o'rnatmasi barcha foydalanuvchilarga tegishli va tizim parolingizni so'rashi mumkin; bekor qilish yoki kengaytmani o'rnatish muvaffaqiyatsiz tugashi ham Claude ni tanlab, ishga tushiradi. Brauzeringizni qayta ishga tushiring, so'ralsa kengaytmani yoqing va uni ulashni yakunlash uchun Claude ga kiring. Ulanishni tekshirish uchun Claude da `/chrome` ni ishga tushiring. Firefox va Zen bu kengaytmani qo'llab-quvvatlamaydi. Agar bu o'rnatma qo'shilishidan oldin Claude allaqachon standart agentingiz bo'lgan bo'lsa, kengaytmani o'rnatish uchun uni yana tanlang.

Tanlaganingizdan keyin, `Super + Shift + Ctrl + A` standart agentni alohida terminal oynasida ishga tushiradi (yoki hali tanlamagan bo'lsangiz, tanlovchini ochadi). Uni `omarchy agent prompt "Review this project"` bilan to'g'ridan-to'g'ri vazifaga ham ishga tushirishingiz mumkin. Freebuff va DeepSeek Harness boshlang'ich prompt qabul qilmaydi, shuning uchun ular o'rniga prompt sizning clipboard ingizda yopishtirish uchun ochiq holda ochiladi. Bu tarzda ishga tushirilgan agentlar o'zlarining tegishli to'xtab-so'ramaslik rejimlarida qarovsiz ishlaydi, shuning uchun ular haqiqatan ham ish bajarishiga tayyor bo'ling! MiniMax Code ning interaktiv sessionlari uchun bunday rejim yo'q, shuning uchun u odatdagidek ruxsatlar so'raydi. Va agentlar uy katalogingiz uchun trust ni eslab qolishdan bosh tortgani sababli, `$HOME` dan ishga tushirishlar o'rniga `~/Work` da boshlanadi.

Terminal yorliqlari ham bor: `a` standart agentni joriy terminalda ichki ishga tushiradi, `c`, `cx` va `cy` esa OpenCode, Claude Code va Codex ni to'g'ridan-to'g'ri boshlaydi (yana ularning avtomatik tasdiqlaydigan rejimlarida). Tema o'zgarishlari agentlarga ham sinxronlanadi: Claude Code, Pi, OpenCode va Hermes (Omarchy uni o'rnatgandan keyin) Omarchy temasini almashtirganingizda hammasi birga moslashadi.

### Agent ko'rsatmalaringiz

Har bir agent uchun shaxsiy qoidalar `~/.agents/skills` dagi umumiy skilllar yonida, `~/.agents/AGENTS.md` ga joylashadi. Uni _Agent > Instructions_ ostida oching, u shuningdek uni o'zining global faylini saqlaydigan har bir harness ga bog'laydi: `~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.pi/agent/AGENTS.md`, `~/.config/opencode/AGENTS.md`, Copilot ning `~/.copilot/copilot-instructions.md` va hokazo. Crush va Amp `~/.config/AGENTS.md` bog'lanishini o'qiydi, omp, Kimi va DeepSeek Harness esa `~/.agents/AGENTS.md` ni to'g'ridan-to'g'ri o'qiydi. Standart agentni tanlash uni ham bog'laydi. Sizda allaqachon bo'lgan ko'rsatmalar fayli, agar hali umumiysi bo'lmasa, umumiyga aylanadi; aks holda u bog'lanish yonida `.bak` sifatida saqlanadi. Boshqa agentni o'rnatgandan keyin qayta bog'lash uchun `omarchy agent instructions` ni ishga tushiring.

### Agentlar paneli

Yuqori panelda agentlar belgisi bor. Agentni o'rnatmaguningizcha, uning paneli sizni Claude, Codex yoki Grok ga kirish orqali bosqichma-bosqich olib boradi va birinchisi standart agentingizga aylanadi. Shundan keyin panel har bir obunani bitta sahifaga joylashtiradi: har bir agent va hisob o'z rejasi bilan, uning har bir 5 soatlik session va haftalik limitlari uchun qayta o'rnatilishiga qolgan vaqt bilan birga o'lchagich (aniq foiz uchun ustiga olib boring) yoki qolgan oldindan to'langan balans, ularning barchasi bo'ylab foydalanganlaringizni navbat bilan ko'rsatadigan qator ostida, masalan bu haftadagi tokenlar va eng ko'p ishlatgan modelingiz. _Make something cool_ ostida u vazifani standart agentingizga topshiradigan yangi tema, plugin, ilova yoki o'yin uchun boshlang'ich promptlarni taklif qiladi. Ilovalar Omarchy ning o'z Hype, Monologue va Omacut ilovalari kabi, C++ va Qt Quick da, omarchy-make-app agent skill iga amal qilib quriladi va ularga kerak bo'lgan compiler va Qt qismlari o'rnatilgan holda keladi. O'yinlar `~/Games/vibes` dagi bitta three.js sahifasi bo'lib, omarchy-make-game agent skill iga amal qiladi va barchasi joriy temadagi bitta Game Vibes ishga tushirgichidan ochiladi; ular three.js ni webdan yuklaydi, shuning uchun boshlash uchun ulanish kerak. Claude Code, Codex, Grok, Kimi, Cursor va uning Grok Bot imtiyozi, GitHub Copilot, Muse, Antigravity va Devin limitlari bilan qutidan chiqiboq qamrab olingan, Kimchi o'z rejasi, oldindan to'langan kreditlari va xarajat budgetlari bilan, Hermes, Mistral Vibe va Qwen Code esa ulardan foydalanganingizdan keyin sessionlari va tokenlarini ko'rsatadi. pi, omp yoki opencode orqali foydalanadigan provider rejalari va kalitlari ham ko'rinadi: OpenCode Zen va Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan va Synthetic limitlari bilan; OpenRouter va DeepSeek oldindan to'langan balanslari bilan; Fireworks oxirgi 30 kundagi xarajati bilan. O'z hardware ingizda ishga tushiradigan modellardan tokenlar ham jami hisobga qo'shiladi; modellarning o'z paneli bor, u [Lokal modellar](#local-models) ostida tasvirlangan. Har bir agent, uni nechta harness orqali boshqarmang, kim hisob-kitob qilsa o'shaning ostida bir marta hisoblanadi.

Panel uchun panel belgisini chap tugma bilan bosing yoki `Super + Ctrl + X` ni bosing, standart agentingizni ishga tushirish uchun o'ng tugma bilan bosing va yangilash uchun o'rta tugma bilan bosing. Uning ortidagi foydalanish yozuvlari har 15 daqiqada `omarchy agent usage update` tomonidan qayta yaratiladi va panel sinxronlangan papka orqali boshqa mashinalaringizdan foydalanishni ham birlashtira oladi. To'liq sozlamalar uchun `$OMARCHY_PATH/shell/plugins/agents/` ostidagi README ga qarang.

### Bir nechta obuna

Agar bir nechta Claude, Codex yoki Grok rejasiga to'lasangiz — masalan shaxsiy Max va ish rejasi — Omarchy ularning barchasini kirgan holda saqlab, ular orasida harakatlana oladi. Obunani agentlar panelidagi + bilan qo'shing, u sizni o'sha yerning o'zida bosqichma-bosqich olib boradi, yoki `omarchy agent account add claude Work` (yoki `codex`, yoki `grok`) bilan. Agar CLI yo'q bo'lsa, uni o'rnatadi. Provider uchun birinchi hisob normal brauzeringiz orqali, CLI doim qaraydigan joyda kiradi. Undan keyingi har biri private oyna orqali kiradi, shuning uchun brauzeringiz allaqachon kirgan hisob xatolik bilan tanlanib qolmaydi; u yerda qo'shayotgan hisobingiz sifatida kiring va avval ochib qo'ygan har qanday private oynani yoping. Buning uchun hech qachon CLI dan chiqmang: chiqish saqlangan kirishni bekor qiladi va o'sha hisobni yana qo'shishga to'g'ri keladi.

Obuna kirishlaringizni SSH orqali boshqa Omarchy mashinasiga nusxalash uchun `omarchy agent account copy user@laptop` ni ishga tushiring. Agar manzil mashinasida o'rnatilgani bo'lmasa, yuboruvchi vaqtinchalik qabul qiluvchini taqdim etadi, shuning uchun eski Omarchy mashinalari yangilanishsiz hisoblarni qabul qila oladi. O'rnatilgan qabul qiluvchilar ustunlikka ega. Bu barcha Claude, Codex va Grok obunalarini nusxalaydi; ularni tanlash uchun provider nomlarini qo'shing, masalan `omarchy agent account copy laptop claude`. Hisob nomlari va buyruq ID lari manbaga mos keladi, shu jumladan manzil mashinasida allaqachon mavjud hisoblar ham. Agar nomlari to'qnashsa, aloqasiz manzil hisoblari raqamli suffix oladi va sozlamalar, skilllar, pluginlar va suhbat tarixi har bir mashinada lokal bo'lib qoladi.

Mavjud manzil credentiallari saqlanadi. U yerda allaqachon kirgan manba hisobining credentiallarini almashtirmasdan nomi sinxronlanadi; boshqa hisoblar uning yoniga qo'shiladi. Mos hisoblar uchun saqlangan credentiallarni almashtirish uchun manzil mashinasida o'sha hisob sessionlarini yopgandan keyin `omarchy agent account copy --replace laptop claude` dan foydalaning. Yangi manzil mashinasi manbaning faol hisobini va almashtirish afzalliklarini ham oladi; o'rnashgan manzil mashinasi o'zinikini saqlaydi.

Credentiallar SSH orqali sayohat qiladi va manzil mashinasida private fayllarda saqlanadi, shuning uchun faqat ishonadigan mashinalaringizga nusxalang. Bu bir martalik nusxa, doimiy sinxronizatsiya emas. Codex refresh tokenlari boshqa mashina tomonidan aylantirilishi mumkin, bu nusxalangan kirishni yangilashga muhtoj qoldiradi; bir nechta mashinada bir vaqtda foydalanish uchun alohida kirishlar eng ishonchli tanlov bo'lib qoladi. Qarang [Codex ning hisob autentifikatsiyasi bo'yicha qo'llanmasi](https://developers.openai.com/codex/auth/ci-cd-auth).

Har bir provider uchun bitta hisob faol va har bir yangi session o'sha sifatida boshlanadi: `cx`, `cy`, oddiy `claude`, `codex` yoki `grok`, `omarchy agent` orqali ishga tushirilgan har qanday narsa va CLI ni `PATH` da topadigan scriptlar yoki editorlar. `omarchy agent account use work` bilan almashtiring (va `omarchy agent account use main` bilan orqaga), yoki panelda hisob raqamini bosib, keyin `Enter` ni bosish (yoki uning Use tugmasini bosish) orqali. Ishlayotgan Claude sessionlari ham keyingi xabaringizdan almashadi: har bir Claude sessioni `~/.claude` da ishlaydi, u doim faol hisobning kirishini saqlaydi. Eski Omarchy tomonidan hisobning o'z papkasida boshlangan Claude sessioni u chiqmaguncha o'sha kirishni saqlaydi, shuning uchun almashtirish o'sha sessionlarni nomlaydi va ular ketgandan keyin o'z-o'zidan tugaydi. Ishlayotgan Codex va Grok sessionlari boshlangan hisobda qoladi. Suhbat tarixi, sozlamalar, skilllar va pluginlar hisoblar orasida ulashiladi, shuning uchun xuddi shu papkada `claude --continue` yangi hisobda qoldirgan joyingizdan davom etadi.

Bir nechta hisob bo'lsa, panel har bir hisob limitlarini yonma-yon ko'rsatadi, faoli belgilangan holda. Standart bo'yicha Omarchy faol hisob limitning 95% idan o'tganda sizni xabardor qiladi va bildirishnomani bosish eng ko'p bo'sh joyi bor hisobga o'tadi. Panelda hisob qatoriga olib boring va Use yonida paydo bo'ladigan Autoswitch ni bosing (yoki `m` ni bosing), yoki uning o'z-o'zidan almashishi uchun `omarchy agent account mode auto` ni ishga tushiring; u yoqilgan paytda Autoswitch Use ning o'rnini oladi va uni yana bosish xabardor qilishga qaytadi. Chegarani o'zgartirish uchun raqam qo'shing, masalan `omarchy agent account mode auto 90`. Agar har bir hisob chegaradan oshgan bo'lsa, bu haqida bir marta eshitasiz, qaysi hisob birinchi bo'shashi bilan birga. Faol hisob chegarasidan 15 punkt ichida bo'lsa (standartda 80%), uning limitlari har 15 daqiqa o'rniga har uch daqiqada tekshiriladi.

`omarchy agent account list` har bir hisobni va uning eng so'nggi limitlarini ko'rsatadi, `omarchy agent account remove work` bittasini unutadi va `omarchy agent account rename primary Hey` bittasining nomini o'zgartiradi (yoki panelda hisob nomini bosing). Bu buyruqlar standart agentingiz hisoblarida ishlaydi; boshqa providerga yetish uchun avval uni nomlang, masalan `omarchy agent account use codex side`. `~/.claude` yoki `~/.codex` da allaqachon bo'lgan kirishingiz _Main_ hisobdir. Codex niki turgan joyida qoladi; Claude niki boshqa hisob faol bo'lsa, o'z papkasida kutadi. Taxminan sakkiz soatdan ortiq foydalanilmagan hisob _Sign-in required_ ko'rsatishi mumkin; o'sha hisobni panelning o'zida yana kiritish uchun uni bosing yoki unga o'tib session boshlang, bu kirishni o'z-o'zidan yangilaydi. `claude mcp add` bilan qo'shadigan MCP serverlar har bir Claude hisobiga yetadi, chunki ularning barchasi `~/.claude` da ishlaydi; Codex va Grok uchun hisob qo'shilganda sizda bo'lgan serverlar unga birga keladi, lekin keyingilari faqat ularni qo'shgan hisobingizga yetadi. Claude Desktop o'z kirishini saqlaydi va CLI binary siga mutlaq yo'l bilan sozlangan Codex yoki Grok vositalari almashtirishga ergashmaydi. Aniq `CLAUDE_CONFIG_DIR`, `CODEX_HOME` yoki `GROK_HOME` tanlangan hisobdan ustun turadi.

### Qulash diagnostikasi

Omarchy jarayon qulashlari uchun systemd-coredump ni kuzatadi. Standart agentni tanlaganingizdan keyin, core dump qiladigan har qanday dasturingiz "Process crashed" bildirishnomasini olib keladi — uni bosing va qulash standart agentingizga Omarchy ning omarchy-diagnose-crash skill i bilan birga topshiriladi, u agentni core dump dan faktlarni aniqlash va qulashni upstream ga xabar qilishga arziydimi yoki yo'qligini hal qilish orqali bosqichma-bosqich olib boradi. Uni `coredumpctl list` dagi har qanday PID ga qarshi qo'lda ham `omarchy agent crash <pid>` bilan ishga tushirishingiz mumkin.

Kuzatuv standart bo'yicha yoqilgan. Uni _Trigger > Toggle > Crash Capture Off_ ostida (yoki `omarchy toggle crash-capture` bilan) o'chiring va bildirishnomalar to'xtaydi; `omarchy agent crash <pid>` hamon qo'lda ishlaydi.

Qulashlarni bitta dasturdan bir martadan ham ovozsizlantirish mumkin, diagnostika oxirida sizga shuni taklif qiladi. `omarchy crash mute hyprland` bildirishnomalarni faqat o'sha dastur uchun to'xtatadi, `omarchy crash mute hyprland off` ularni qaytaradi va `omarchy crash mute` o'z-o'zidan ovozsizlantirilganlar ro'yxatini ko'rsatadi. U binary ning yo'lini ham nomi kabi mamnuniyat bilan qabul qiladi, shuning uchun `omarchy crash mute /usr/bin/hyprland` xuddi shu ishni qiladi. Nomida bo'sh joy bor nomni qo'shtirnoqqa oling, masalan `omarchy crash mute 'Some App'`. Qolgan hamma narsa hamon xabar beradi va ovozsizlantirilgan dastur hamon qulayd i — bu eslatmani yashiradi, hech narsani tuzatmaydi.

### Ish stoli ilovalari

_Install > AI_ menyusi bir nechta grafik AI ilovalarini ham olib keladi: Amp Desktop, Antigravity Desktop, ChatGPT ish stoli ilovasi, Claude ish stoli ilovasi (Anthropic ning Linux beta versiyasi, Chat, Cowork va Claude Code tab lari bilan), xAI modellari bilan suhbatlashish uchun Grok Bot, Herdr Desktop, Hermes Desktop, OpenClaw, Perplexity ish stoli ilovasi va T3 Code. Grok Bot ish stoli suhbat ilovasidir. Kodlash agenti `grok` buyrug'idir.

Hermes Desktop bilish kerak bo'lgani, chunki mashinada bitta Hermes bor va u ilovaniki: Hermes faqat ilova orqali o'rnatiladi va standart agent ishga tushiradigan `hermes` buyrug'i ilovaniki. Hermes ni standart agent sifatida tanlash _Install > AI_ yozuvi qiladigan xuddi shu narsani o'rnatadi: paket va Hermes ning o'z o'rnatuvchisi tomonidan o'rnatilgan, birinchi marta bir necha daqiqa oladigan, `~/.hermes` ostidagi Hermes runtime i. O'sha runtime terminal `hermes` buyrug'i, standart agent va ilova hammasi foydalanadigan bitta Hermes dir va u Omarchy nashrini kutmasdan `hermes update` bilan o'zini yangilaydi. Uni o'rnatish Hermes ga Omarchy temasini `omarchy` nomli skin sifatida ham beradi, har bir Hermes yuzasi temalarni almashtirganingizda unga ergashadi; agar xohlamasangiz, Hermes ning Appearance sozlamalarida yoki `/skin` bilan boshqasini tanlang va Omarchy o'sha tanlovni o'z holicha qoldiradi. Ilovani _Remove > AI_ ostida olib tashlash avval Hermes ni yopadi, gateway bilan birga, o'sha runtime ni u bilan birga oladi va agar boshqacha aytmasangiz, suhbatlaringiz, xotiralaringiz va Hermes o'zi uchun yozgan skilllarni saqlaydi: u ma'lumotlar va ulanish sozlamalaringiz ham ketishi kerakmi yoki yo'qligini so'raydi, standart javob yo'q.

OpenClaw ning ish stoli tajribasi uning Control UI si bo'lib, u o'zining lokal gateway i tomonidan ta'minlangan web ilova sifatida ochiladi. OpenClaw `~/.openclaw` da yashaydi va o'zini yangilaydi: Control UI ning "Update Gateway" tugmasidan foydalaning yoki `openclaw update` ni ishga tushiring va gateway yangi versiyada qayta boshlanadi. Omarchy faqat yangi o'rnatma boshlanadigan nashrni tanlaydi. OpenClaw standart agentingiz ham bo'lishi mumkin: uni _Agent > Harness_ ostida tanlash `~/.openclaw` dagi xuddi shu nusxani o'rnatadi va agent OpenClaw ning gateway iga ulangan terminal UI sini ochadi. OpenClaw ni _Remove > AI_ ostida olib tashlash gateway xizmati va ilovani u bilan birga oladi va keyin `~/.openclaw` ham ketishi kerakmi yoki yo'qligini so'raydi, chunki u suhbatlaringiz va credentiallaringizni OpenClaw ning o'zi va u yuklab oladigan plugin runtime lari bilan birga saqlaydi; standart uni saqlaydi va OpenClaw ni yana o'rnatish uni qayta oladi.

Herdr Desktop bu [Herdr](https://herdr.dev) ish stoli ilovasi: oynasini yopganingizda uning yadrosida ishlashda davom etadigan terminallar va kodlash agentlarining spaces, tab va pane lari. U paketdan emas, Herdr ning o'z o'rnatuvchisidan keladi, shuning uchun u `~/.local/share/herdr-app` da yashaydi, agar sizda hali bo'lmasa, yadrosini `~/.local/bin/herdr-core` da birga olib keladi va ikkalasini ham o'zi yangilaydi. U Omarchy `Super + Ctrl + Return` da taqdim etadigan `herdr` buyrug'ining yonida turadi, uning o'rnini bosmaydi va o'sha buyruqning to'g'ridan-to'g'ri tugmalarini oladi: `Alt + Return` va `Alt + Shift + Return` pane ni pastga yoki o'ngga bo'ladi, `Alt + Escape` uni yopadi, `Ctrl + Alt + Arrow` pane lar orasida harakatlanadi, `Alt + 1..9` va `Alt + Left/Right` tab ni tanlaydi va `Alt + Up/Down` space lar orasida harakatlanadi. `Ctrl + 1..9` space ni tanlaydi va `Alt + Shift + Up/Down` agentlar bo'ylab qadamlaydi. `Ctrl + Space` prefix tugmalari faqat terminal uchun qoladi, chunki ilova ketma-ketlik uchun oddiy Ctrl tugmasini ushlab turolmaydi. Omarchy bularni `~/.config/herdr-app/keys.json` ga yozadi va `omarchy-refresh-herdr-app` ularni qaytaradi. Uni o'rnatish Herdr ning Omarchy temasini tanlaydi, u shundan keyin Omarchy temangizga ergashadi. Herdr light mode uchun bitta tema va dark mode uchun bitta tema saqlaydi, shuning uchun dark va light Omarchy temalari orasida almashgandan keyin, boshqa rejim uchun Herdr ning tema tanlovchisida Omarchy ni yana bir marta tanlang.

T3 Code paketdan emas, `~/.local/share/t3code` dagi rasmiy AppImage nashridan ishlaydi, shuning uchun o'zini yangilaydi. Uni o'rnatish Stable yoki Nightly kanalida boshlashni so'raydi; keyinroq T3 Code sozlamalarida almashtiring. Threadlaringiz va sozlamalaringiz `~/.t3` da yashaydi va T3 Code ni _Remove > AI_ ostida olib tashlash ularni u bilan birga oladi.

### Lokal modellar

Kodlash agentlaringiz uchun ochiq modelni o'z mashinangizda ishga tushiring. Promptlaringiz va kodingiz mashinada qoladi; modelga yuborilgan hech narsa undan chiqmaydi. Quyidagidan boshlang:

```bash
omarchy models use best text
```

Bu ushbu mashina uchun eng yaxshi text modelini o'rnatadi, agentlaringiz foydalanadigan tur. Image, video va music modellarining ham o'z eng yaxshisi bor: `omarchy models use best image`, `video` yoki `music`. Har bir turning bu mashina uchun tanlovini ko'rish uchun `omarchy models use best` ni ishga tushiring.

Yoki lokal modellar panelini yuqori paneldagi agentlar belgisi yonidagi uchqunlar belgisidan yoki Super + Ctrl + Alt + X bilan oching va + ni tanlang. Belgi model ushbu mashinaga mos kelganda paydo bo'ladi. Modellarni ishga tushiradigan Podman Omarchy bilan keladi, NVIDIA mashinasida ularga GPU ni beradigan NVIDIA ning container toolkit i ham; agar ikkalasidan biri yo'q bo'lsa, birinchi o'rnatma uni o'rnatadi. Keyin Omarchy ushbu mashina uchun tavsiya etilgan modelni tanlaydi, uni yuklab oladi va boshlaydi. O'nlab GB yuklab olishni va model ishlayotganda mashina xotirasining ko'p qismi ishlatilishini kuting: Flash Next to'liq 256K context i bilan taxminan 100 GiB ishlatadi. Agar boshqa modellar unga kerak xotirani egallagan bo'lsa, u to'xtatilgan holda o'rnatiladi, bittasini to'xtatganingizdan keyin boshlashga tayyor. Model logout da to'xtaydi; xotira boshqa narsa uchun kerak bo'lganda uni o'zingiz to'xtating.

`omarchy models list` variantlarni ko'rsatadi va ba'zilari nima uchun mos kelmasligini tushuntiradi. Boshqasini o'rnatish uchun `omarchy models use <recipe>` ni ishga tushiring. Bugun 128 GB Strix Halo mashinalari uchun `qwen3.8-flash-next-gufo` va `qwen3.8-27b-gufo` mavjud; 27B taxminan 40 GiB oladi, shuning uchun boshqa ish uchun joy qoldiradi. Intel ning Arc B390 siga ega 64 GB laptopda `qwen3.6-35b-a3b-llamacpp` taxminan 30 GiB da ishlaydi. Yangi recipe lar va tavsiyalar paket orqali `omarchy update` bilan keladi.

O'rnatgan har bir modelingiz lokal modellar panelida o'z qatoriga ega bo'ladi: boshlash uchun play, to'xtatish va xotirasini bo'shatish uchun pause va unda agentingizni ochish uchun terminal tugmasi. Yuqorida bar mashina xotirasi Omarchy ning o'zi (tizim va ilovalaringiz), har bir ishlaydigan model va bo'sh joy orasida qanday bo'linganini ko'rsatadi. To'xtatilgan modelga ishora qiling va bar u mos keladimi yoki qancha yetishmayotganini ko'rsatadi. Bir nechtasi xotiraga birga sig'sa, bir vaqtda ishlashi mumkin; agar bittasi sig'masa, Omarchy qaysi ishlaydigan modelni to'xtatishni aytadi. Qatorlarni tartibini o'zgartirish uchun logotipi bo'yicha torting va model va uning yuklab olinishini olib tashlash uchun tanlangan qatorda Delete ni bosing.

O'rnatgan har bir modelingiz ilova ishga tushirgichida ham, model nomi ostida va uning ishlab chiqaruvchisi logotipi bilan, Claude, Codex yoki Grok ga kirish bittasini qo'shgani kabi, o'z yozuviga ega bo'ladi. U modelingizda agentingizni ochadi va agar model ishlamayotgan bo'lsa, avval uni boshlaydi: terminal uning yuklanishini ko'rsatadi va u tayyor bo'lgandan keyin agentga topshiradi. Modelni olib tashlash uning yozuvini olib tashlaydi.

Har bir model ham kodlash uchun emas. Image, video va music modellari o'rniga Fantasi da ochiladi, Omarchy ning ushbu mashinada ishlaydigan model bilan rasmlar, video va music yaratish ilovasi, ularning ishga tushirgich yozuvidan va lokal modellar panelidagi qatoridan.

Model aniq o'rnatilganidek ishlashda davom etadi, shuning uchun Omarchy yangilanishi hech qachon agentlaringiz ostidagi bittasini qayta boshlamaydi. Omarchy da siz o'rnatgan model uchun yangi runtime yoki yangi weightlar bo'lsa, uning qatori yangilash tugmasini ko'rsatadi: uni bosing va model fonda yana o'rnatiladi, faqat o'zgargan narsani yuklab oladi va yangi versiyada qayta boshlanadi. To'xtatilgan model to'xtatilgan holda qoladi. `omarchy models update` terminaldan har bir model uchun xuddi shuni qiladi.

Buyruq qatoridan `omarchy models start <recipe>` va `omarchy models stop <recipe>` xuddi shuni qiladi, `omarchy models status` har bir modelni ko'rsatadi va `omarchy agent --local` standart agentingizni oxirgi boshlagan modelingizda ochadi. pi, OpenCode va Qwen Code bittasidan foydalanishi mumkin; boshqa har qanday standart bilan u pi da ochiladi, yoki pi bo'lmasa OpenCode da. pi siz o'rnatgan har bir modelni va juftlagan mashinalaringizdagilarni ham o'z model tanlovchisida ro'yxatlaydi, shuning uchun oddiy `pi` ham ularga yetadi. Har qanday OpenAI-compatible client ham ulanishi mumkin: `status` har bir model manzilini ko'rsatadi (birinchisi `http://127.0.0.1:11435/v1`), recipe nomi modeldir va kalit `~/.config/omarchy/agent-local/key` da.

`omarchy models remove <recipe>` modelni va boshqa hech bir model foydalanmaydigan yuklab olishlarni o'chiradi.

Uchinchi tomon runtime lari nashriyotchisi bilan belgilanadi. Omarchy har bir modelni network ga kirishsiz ishga tushiradi.

### Lokal LLM lar

Omarchy lokal LLM modellarini ishga tushirishning ikki usulini tavsiya qiladi: LM Studio va Ollama. LM Studio ochiq vaznli modellarni topish, ularni o'rnatish va ishga tushirish uchun GUI interface ini taqdim etadi. Bu oson boshlashning ajoyib usuli. Ollama ham xuddi shunday qilish uchun CLI taklif qiladi. Lekin agar lokal modellarga yangi bo'lsangiz, LM Studio dan boshlagan bo'lardim. Ikkalasidan birini Omarchy Menu dagi _Install > AI_ ostida o'rnatishingiz mumkin.

### Omarchy skill lari

Agent skill lari AI ga muayyan vositalardan muayyan tarzda foydalanishga yordam beradi va Omarchy ularning yettitasini taqdim etadi. omarchy skill i tizimni moslashni qamrab oladi, masalan Hyprland config ingizni sozlash yoki panelni moslash. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app va omarchy-make-game yangi narsa yaratishni qamrab oladi, omarchy-contribute upstream ga bug haqida xabar berish yoki fix yuborishni qamrab oladi va omarchy-diagnose-crash qulashning core dump i orqali ishlaydi. Ular Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` va har bir `~/.hermes/profiles/*/skills`) va umumiy `~/.agents/skills` joylashuvi uchun skill kataloglariga symlink qilingan, shuning uchun ko'pchilik harnesslar ularni avtomatik oladi. Xuddi shu nomdagi o'z skill papkangiz ustunlikka ega.

Lekin bu skilllarni experimental deb hisoblashingiz kerak. Turli modellar uni turlicha samar bilan ishlatadi. Avval plan mode da ishga tushirish eng yaxshisi, shunda agent nimani o'zgartirmoqchi ekanligi haqida tasavvurga ega bo'lasiz. Keyin esa o'zgarishlarni orqaga qaytarishga yoki agar agent hamma narsani tartibsiz qilib tashlasa, hatto `omarchy reinstall configs` ni chaqirishga tayyor bo'ling.
