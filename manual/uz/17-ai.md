# AI

Omarchy AI kodlash agentlariga birinchi darajali fuqarolardek munosabatda bo‘ladi, lekin siz uchun sevimlisini tanlab bermaydi. Buning o‘rniga, har bir asosiy kodlash agenti CLI si oldindan ulangan, kerak bo‘lgandagina yuklanadigan ishga tushirgich sifatida keladi. Ishga tushirgichlar `~/.local/bin/` ichidagi [mise](https://mise.jdx.dev/) tomonidan boshqariladigan kichkina stublar, shuning uchun siz ulardan birini ilk marta haqiqatan ishga tushirmaguningizcha hech narsa yuklab olinmaydi. Hermes bundan mustasno: u uchun hech qanday stub yaratilmaydi va uni tanlash Hermes Desktop ni o‘rnatadi, bu quyidagi _Ish stoli ilovalari_ bo‘limida tushuntiriladi. Bularning istalganini chaqiring va so‘ralganda autentifikatsiyadan o‘ting:

| Buyruq    | Agent                                                            |
|------------|------------------------------------------------------------------|
| `claude`   | [Claude Code](https://code.claude.com/docs/en/overview)          |
| `codex`    | [OpenAI Codex](https://github.com/openai/codex)                  |
| `opencode` | [OpenCode](https://opencode.ai/)                                 |
| `agy`      | [Google Antigravity CLI](https://github.com/google-antigravity/antigravity-cli) |
| `copilot`  | [GitHub Copilot CLI](https://github.com/github/copilot-cli)      |
| `crush`    | [Crush](https://github.com/charmbracelet/crush)                  |
| `grok`     | xAI dan [Grok Build](https://x.ai/build)                        |
| `kimi`     | [Kimi Code](https://www.kimi.com/code/docs/en/)                  |
| `pi`       | [Mario Zechner'ning Pi si](https://github.com/badlogic/pi-mono)        |
| `omp`      | [Oh My Pi](https://github.com/can1357/oh-my-pi)                  |
| `ori`      | [Ori](https://openrouter.ai/docs/guides/ori/harness), OpenRouter harnessi |
| `hermes`   | [Hermes](https://hermes-agent.nousresearch.com/), Nous Research agenti  |
| `muse`     | [Muse Code](https://dev.meta.ai), Meta'ning kodlash agenti           |
| `cursor-agent` | [Cursor CLI](https://cursor.com/cli)                         |

`ori` boshqalardan ajralib turadi: u boshqa harnesslarni OpenRouter'ning butun modellar katalogiga qarshi ishga tushiradi, shuning uchun `ori claude`, `ori codex` yoki `ori opencode` o‘sha agentlarni siz ko‘rsatgan istalgan modelda boshlaydi va `ori code` Ori'ning o‘z agenti hisoblanadi.

Qo‘shimcha CLI ni xuddi shu tarzda o‘rash uchun `omarchy-mise-install <package> [command-name]` buyrug‘ini ishga tushiring. Siz `omarchy update` (yoki `mup` taxallusini) ishga tushirganingizda stublar mise boshqaradigan hamma narsalar qatori dolzarb holda saqlanadi.

`grok` mise'ning birinchi tomon `grok` paketi orqali, xuddi `claude` va `codex` kabi o‘rnatiladi. `grok` ni ishga tushiring yoki uni _Sozlash > Standartlar > Agent_ ostida tanlang. x.ai dagi `curl | bash` o‘rnatuvchisidan foydalanmang. O‘sha yo‘l ikkinchi nusxani `~/.grok/bin` ga qo‘yadi, uni `PATH` ga oldindan qo‘shadi va Omarchy o‘ramini ustiga yozib yuboradi.

### Standart agent

Standart agentingizni `omarchy default agent <name>` bilan yoki Omarchy Menu sidagi (`Super + Space`) _Sozlash > Standartlar > Agent_ ostida tanlang. Agar agent hali o‘rnatilmagan bo‘lsa, uni tanlash avval uni o‘rnatadi. Yangi Omarchy sizni bir martalik bildirishnoma bilan ushbu tanlovni qilishga taklif qiladi.

Claude ni tanlash uning Chromium, Chrome, Brave, Brave Origin va Edge uchun brauzer kengaytmasini ham sozlashga urinadi. Kengaytmani sozlash barcha foydalanuvchilarga taalluqli va tizim parolingizni so‘rashi mumkin; bekor qilish yoki kengaytmani o‘rnatish muvaffaqiyatsiz bo‘lishi ham baribir Claude ni tanlaydi va ishga tushiradi. Brauzeringizni qayta ishga tushiring, so‘ralsa kengaytmani yoqing va uni ulashni tugatish uchun Claude ga kiring. Ulanishni tekshirish uchun Claude da `/chrome` buyrug‘ini ishga tushiring. Firefox va Zen bu kengaytmani qo‘llab-quvvatlamaydi. Agar Claude ushbu sozlash qo‘shilishidan oldin allaqachon standart agentingiz bo‘lgan bo‘lsa, kengaytmani o‘rnatish uchun uni yana tanlang.

[Muse Code](https://dev.meta.ai) — Meta'ning `muse` i — boshqa agentlar kabi oldindan o‘rnatilgan mise stubidan foydalanadi. Uni standart agent sifatida tanlash Meta'ning rasmiy ishga tushirgichini mise'ning HTTP backendi orqali o‘rnatadi. Ishga tushirgich mashinangiz uchun native binary ni tekshiradi va yangilaydi.

Tanlaganingizdan so‘ng, `Super + Shift + Ctrl + A` standart agentni maxsus terminal oynasida ishga tushiradi (yoki agar siz hali tanlamagan bo‘lsangiz, tanlovchisini chiqaradi). Siz uni `omarchy agent prompt "Review this project"` bilan to‘g‘ridan to‘g‘ri vazifaga ham ishga tushirishingiz mumkin. Shu tarzda ishga tushirilgan agentlar o‘zlarining to‘xtab so‘ramaydigan tegishli rejimlarida qarovsiz ishlaydi, shuning uchun ular haqiqatan ham ishlarni bajarishiga tayyor bo‘ling! Agentlar uy katalogingizga ishonchni eslab qolishdan bosh tortgani sababli, `$HOME` dan ishga tushirishlar o‘rniga `~/Work` da boshlanadi.

Terminal yorliqlari ham bor: `a` standart agentni joriy terminalda ichkarida ishga tushiradi, `c`, `cx` va `cy` esa OpenCode, Claude Code va Codex ni to‘g‘ridan to‘g‘ri boshlaydi (yana ularning avtomatik tasdiqlovchi rejimlarida). Mavzu o‘zgarishlari agentlarga ham sinxronlashadi: siz Omarchy mavzusini almashtirganingizda Claude Code, Pi, OpenCode va Hermes (Omarchy uni o‘rnatganidan so‘ng) hammasi ergashadi.

### Agentlar paneli

Yuqori barda agentlar belgisi bor. Agentni sozlashingizdan oldin, uning paneli sizni Claude, Codex yoki Grok ga kirish jarayonidan o‘tkazadi va birinchisi standart agentingizga aylanadi. Shundan so‘ng panel har bir obunani bitta sahifaga joylaydi: har bir agent va akkaunt uning rejasi bilan, uning har bir 5 soatlik sessiya va haftalik limitlari uchun qayta tiklanishigacha qolgan vaqt bilan birga o‘lchagich (aniq foiz uchun ustiga olib boring) yoki qolgan oldindan to‘langan balans, ularning barchasi bo‘ylab foydalanganlaringiz bo‘ylab aylanib turadigan satr ostida, masalan, bu haftadagi tokenlar va eng ko‘p ishlatgan modelingiz. _Biror narsa yaratish_ ostida u vazifani standart agentingizga topshiradigan yangi mavzu, plagin yoki ilova uchun boshlang‘ich promptlarni taklif qiladi. Ilovalar Omarchy'ning o‘z Hype, Monologue va Omacut i kabi, C++ va Qt Quick da, omarchy-app agent skill iga amal qilib yaratiladi va ularga kerak bo‘lgan kompilyator hamda Qt qismlari o‘rnatilgan holda keladi. Claude Code, Codex, Grok, Fireworks va Kimi qutidan chiqqan holda qo‘llab-quvvatlanadi. Kimi hozirda mahalliy token yoki prompt statistikasiz akkaunt kvota limitlarini xabar qiladi.

Panel uchun bar belgisini chap tugma bilan bosing, standart agentingizni ishga tushirish uchun o‘ng tugma bilan bosing. Uning ortidagi foydalanish yozuvlari har 15 daqiqada `omarchy agent usage-update` tomonidan qayta yaratiladi va panel hatto sinxronlangan jild orqali boshqa mashinalaringizdagi foydalanishni ham birlashtirishi mumkin. To‘liq sozlamalar uchun `$OMARCHY_PATH/shell/plugins/agents/` ostidagi README ga qarang.

### Bir nechta obuna

Agar siz bittadan ortiq Claude, Codex yoki Grok rejasiga to‘lasangiz — aytaylik, shaxsiy Max va ish uchun bittasi — Omarchy ularning hammasini kirgan holda saqlashi va ular o‘rtasida harakatlanishi mumkin. Obunani agentlar panelidagi + bilan qo‘shing, u sizni shu yerning o‘zida jarayondan o‘tkazadi, yoki `omarchy agent account add claude Work` bilan (yoki `codex`, yoki `grok`). Agar CLI yetishmayotgan bo‘lsa, u uni o‘rnatadi. Provayder uchun birinchi akkaunt oddiy brauzeringiz orqali, CLI har doim qaraydigan joyda kiradi. Shundan keyingi har biri xususiy oyna orqali kiradi, shuning uchun brauzeringiz allaqachon kirgan akkaunt xatolik bilan tanlanib qolmaydi; u yerda siz qo‘shayotgan akkaunt sifatida kiring va avval allaqachon ochiq bo‘lgan har qanday xususiy oynani yoping. Buning uchun hech qachon CLI dan chiqmang: chiqish saqlangan kirishni bekor qiladi va o‘sha akkauntni yana qo‘shishga to‘g‘ri kelardi.

Obuna kirishlaringizni SSH orqali boshqa Omarchy mashinasiga nusxalash uchun `omarchy agent account copy user@laptop` buyrug‘ini ishga tushiring. Belgilangan joyda o‘rnatilgan qabul qiluvchi bo‘lmaganda yuboruvchi vaqtinchalik qabul qiluvchini taqdim etadi, shuning uchun eski Omarchy mashinalari yangilanishsiz akkauntlarni qabul qilishi mumkin. O‘rnatilgan qabul qiluvchilar ustunlikka ega. Bu barcha Claude, Codex va Grok obunalarini nusxalaydi; ularni tanlash uchun provayder nomlarini qo‘shing, masalan `omarchy agent account copy laptop claude` dagi kabi. Akkaunt nomlari va buyruq ID lari manbaga mos keladi, shu jumladan belgilangan joyda allaqachon mavjud bo‘lgan akkauntlar ham. Bog‘liq bo‘lmagan belgilangan joy akkauntlari nomlari zid kelganda raqamli qo‘shimcha oladi va sozlamalar, skillar, plaginlar va suhbat tarixi har bir mashinada mahalliy qoladi.

Mavjud belgilangan joy ma’lumotlari saqlanib qoladi. U yerda allaqachon kirgan manba akkaunti ma’lumotlarini almashtirmasdan nomi sinxronlashtiriladi; boshqa akkauntlar uning yoniga qo‘shiladi. Mos keladigan akkauntlar uchun saqlangan ma’lumotlarni almashtirish uchun, belgilangan joyda o‘sha akkaunt sessiyalaridan chiqqaningizdan so‘ng `omarchy agent account copy --replace laptop claude` dan foydalaning. Yangi belgilangan joy manbaning faol akkauntini va almashtirish afzalliklarini ham oladi; o‘rnashgan belgilangan joy o‘zinikini saqlaydi.

Ma’lumotlar SSH orqali o‘tadi va belgilangan joydagi xususiy fayllarda saqlanadi, shuning uchun faqat siz ishonadigan mashinalarga nusxalang. Bu bir martalik nusxa, doimiy sinxronizatsiya emas. Codex yangilash tokenlari boshqa mashina tomonidan almashtirilishi mumkin, bu esa nusxalangan kirishni yangilashga muhtoj holda qoldiradi; alohida kirishlar bir nechta mashinada bir vaqtning o‘zida foydalanish uchun eng ishonchli tanlov bo‘lib qoladi. [Codex'ning akkaunt autentifikatsiyasi bo‘yicha ko‘rsatmasiga](https://developers.openai.com/codex/auth/ci-cd-auth) qarang.

Har bir provayder uchun bitta akkaunt faol bo‘ladi va har bir yangi sessiya shunday boshlanadi: `cx`, `cy`, oddiy `claude`, `codex` yoki `grok`, `omarchy agent` orqali ishga tushirilgan har qanday narsa va CLI ni `PATH` da topadigan skriptlar yoki muharrirlar. `omarchy agent account use work` bilan almashtiring (va `omarchy agent account use main` bilan orqaga) yoki panelda akkaunt raqamini va keyin `Enter` ni bosish orqali (yoki uning Use tugmasini bosish orqali). Alla qachon ishlayotgan sessiyalar ular boshlangan akkauntda qoladi. Suhbat tarixi, sozlamalar, skillar va plaginlar akkauntlar o‘rtasida baham ko‘riladi, shuning uchun ayni jilddagi `claude --continue` yangi akkauntda qoldirgan joyingizdan davom ettiradi.

Bittadan ortiq akkaunt bilan panel har bir akkaunt limitlarini faol biri belgilangan holda yonma-yon ko‘rsatadi. Standart bo‘yicha Omarchy faol akkaunt limitning 95% idan oshganda sizga xabar beradi va bildirishnomani bosish eng ko‘p zaxiraga ega akkauntga o‘tadi. Panelda akkaunt satri ustiga olib boring va Use yonida paydo bo‘ladigan Autoswitch ni bosing (yoki `m` ni bosing), yoki u o‘zi almashtirishi uchun `omarchy agent account mode auto` buyrug‘ini ishga tushiring; u yoqilganida Autoswitch Use o‘rnini egallaydi va uni yana bosish bildirishga qaytadi. Ostona qiymatini o‘zgartirish uchun raqam qo‘shing, masalan `omarchy agent account mode auto 90` dagi kabi. Agar har bir akkaunt ostonadan oshgan bo‘lsa, bu haqida bir marta, qaysi akkaunt birinchi bo‘shashi bilan birga eshitasiz. Faol akkaunt o‘z ostonasidan 15 punkt ichida bo‘lganida (standart bo‘yicha 80%), uning limitlari har 15 daqiqada emas, har uch daqiqada tekshiriladi.

`omarchy agent account list` har bir akkauntni va uning eng so‘nggi limitlarini ko‘rsatadi, `omarchy agent account remove work` birini unutadi va `omarchy agent account rename primary Hey` birini qayta nomlaydi (yoki panelda akkaunt nomini bosing). Ushbu buyruqlar standart agentingiz akkauntlarida ishlaydi; boshqa provayderga yetish uchun avval uni nomlang, masalan `omarchy agent account use codex side` dagi kabi. Sizda `~/.claude` yoki `~/.codex` da allaqachon bo‘lgan kirish _Main_ akkaunti bo‘lib, turgan joyida qoladi. Taxminan sakkiz soatdan ko‘proq foydalanilmay qolgan akkaunt _Sign-in required_ ni ko‘rsatishi mumkin; o‘sha akkauntga panelning o‘zida yana kirish uchun uni bosing yoki unda sessiya boshlang, bu kirishni o‘zi yangilaydi. Akkaunt qo‘shilganida sizda bo‘lgan MCP serverlari unga ham o‘tadi, lekin keyinchalik `claude mcp add` bilan qo‘shganlaringiz faqat siz ularni qo‘shgan akkauntga yetadi. Claude Desktop va CLI binary siga mutlaq yo‘l bilan sozlangan vositalar almashtirishga ergashmaydi. Aniq `CLAUDE_CONFIG_DIR`, `CODEX_HOME` yoki `GROK_HOME` tanlangan akkauntdan ustun keladi.

### Buzilish diagnostikasi

Omarchy jarayon buzilishlari uchun systemd-coredump ni kuzatadi. Biror narsa segfault bo‘lganda, siz "Process crashed" bildirishnomasini olasiz — uni bosing va buzilish Omarchy'ning diagnose-crash skill i bilan birga standart agentingizga topshiriladi, u agentni core dump dan faktlarni aniqlash va buzilish yuqori oqimga xabar berishga arzishini hal qilish jarayonidan o‘tkazadi. Siz uni `coredumpctl list` dan istalgan PID ga qarshi `omarchy agent crash <pid>` bilan qo‘lda ham ishga tushirishingiz mumkin.

Kuzatish standart bo‘yicha yoqilgan. Uni _Trigger > Toggle > Crash Capture_ ostida (yoki `omarchy toggle crash-capture` bilan) o‘chiring va bildirishnomalar to‘xtaydi; `omarchy agent crash <pid>` qo‘lda hamon ishlaydi.

Buzilishlar bir vaqtda bitta dastur bo‘yicha ham ovozini o‘chirish mumkin, diagnostika oxirida sizga aynan shuni taklif qiladi. `omarchy crash mute hyprland` faqat o‘sha dastur uchun bildirishnomalarni to‘xtatadi, `omarchy crash mute hyprland off` ularni qaytaradi va `omarchy crash mute` o‘zicha siz ovozni o‘chirganlaringizni ro‘yxat qiladi. U binary yo‘lini uning nomi kabi mamnuniyat bilan qabul qiladi, shuning uchun `omarchy crash mute /usr/bin/hyprland` ayni ishni qiladi. Ichida bo‘sh joy bor nomni tirnoqqa oling, masalan `omarchy crash mute 'Some App'` dagi kabi. Qolgan hamma narsa hamon xabar beradi va ovozi o‘chirilgan dastur hamon buziladi — bu eslatmani yashiradi, hech narsani tuzatmaydi.

### Ish stoli ilovalari

_O‘rnatish > AI_ menyusi bir nechta grafik AI ilovalarini ham o‘z ichiga oladi: ChatGPT ish stoli ilovasi, Claude ish stoli ilovasi (Anthropic'ning Chat, Cowork va Claude Code yorliqlari bilan Linux beta si), xAI modellari bilan suhbatlashish uchun Grok Bot, Hermes Desktop, OpenClaw va Perplexity ish stoli ilovasi. Grok Bot ish stoli suhbat ilovasidir. Kodlash agenti `grok` buyrug‘idir.

Hermes Desktop bilish kerak bo‘lgani, chunki mashinada bitta Hermes bo‘ladi va u ilovaniki: Hermes faqat har doim ilova orqali o‘rnatiladi va standart agent ishga tushiradigan `hermes` buyrug‘i ilovanikidir. Hermes ni standart agent sifatida tanlash _O‘rnatish > AI_ yozuvi qiladigan ayni narsani o‘rnatadi: paket va Hermes'ning o‘z o‘rnatuvchisi tomonidan sozlangan `~/.hermes` ostidagi Hermes runtime, bu birinchi marta bir necha daqiqa oladi. O‘sha runtime terminal `hermes` buyrug‘i, standart agent va ilova hammasi foydalanadigan yagona Hermes dir va u Omarchy relizini kutish o‘rniga `hermes update` bilan o‘zini yangilaydi. Uni o‘rnatish Hermes ga Omarchy mavzusini `omarchy` deb nomlangan skin sifatida ham beradi, siz mavzularni almashtirganingizda har bir Hermes yuzasi unga ergashadi; agar ergashmasligini xohlasangiz Hermes'ning Appearance sozlamalari ostida yoki `/skin` bilan boshqasini tanlang va Omarchy o‘sha tanlovni o‘z holiga qoldiradi. Ilovani _Olib tashlash > AI_ ostida olib tashlash avval Hermes ni, gateway ni ham qo‘shib yopadi, o‘sha runtime ni o‘zi bilan olib ketadi va agar siz boshqacha aytmasangiz suhbatlaringiz, xotiralaringiz va Hermes o‘zi uchun yozgan skillarni saqlaydi: u o‘sha ma’lumotlar va ulanish sozlamalaringiz ham ketishi kerakmi, deb standart javobi yo‘q qilib so‘raydi.

OpenClaw'ning ish stoli tajribasi uning Control UI si bo‘lib, u o‘zining mahalliy gateway i tomonidan qo‘llab-quvvatlanadigan veb-ilova sifatida ochiladi. OpenClaw `~/.openclaw` da yashaydi va o‘zini yangilaydi: Control UI'ning "Update Gateway" tugmasidan foydalaning yoki `openclaw update` buyrug‘ini ishga tushiring va gateway yangi versiyada qayta ishga tushadi. Omarchy faqat yangi o‘rnatish boshlanadigan relizni tanlaydi. OpenClaw ni _Olib tashlash > AI_ ostida olib tashlash gateway xizmati va ilovani o‘zi bilan olib ketadi va keyin `~/.openclaw` ham ketishi kerakmi, deb so‘raydi, chunki u OpenClaw'ning o‘zi va u yuklab oladigan plagin runtime lari bilan birga suhbatlaringiz va ma’lumotlaringizni saqlaydi; standart holat uni saqlaydi va OpenClaw ni yana o‘rnatish uni qayta topadi.

### Mahalliy LLMlar

Omarchy mahalliy LLM modellarini ishga tushirishning ikkita usulini tavsiya qiladi: LM Studio va Ollama. LM Studio open-weight modellarni topish, ularni o‘rnatish va ishga tushirish uchun GUI interfeysini taqdim etadi. Bu oson boshlashning ajoyib usuli. Ollama shunga o‘xshash ishni qilish uchun CLI taklif qiladi. Lekin agar siz mahalliy modellarga yangi bo‘lsangiz, men LM Studio dan boshlagan bo‘lardim. Siz ikkalasidan birini Omarchy Menu sidagi _O‘rnatish > AI_ ostida o‘rnatishingiz mumkin.

### Omarchy Skill i

Agent skillari AI ga muayyan vositalardan muayyan tarzda foydalanishga yordam beradi va Omarchy tizimni moslashtirish uchun standart skill bilan keladi. Hyprland konfiguratsiyangizni sozlash, barni moslashtirish yoki hatto noldan yangi mavzu yaratish kabi. U Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` va har bir `~/.hermes/profiles/*/skills`) va umumiy `~/.agents/skills` joylashuvi uchun skill kataloglariga symlink qilingan, shuning uchun ko‘pchilik harnesslar uni avtomatik topadi.

Lekin siz ushbu skillga eksperimental sifatida munosabatda bo‘lishingiz kerak. Turli modellar undan turli samarada foydalanadi. Avval plan rejimida ishga tushirgan ma’qul, shunda agent nimani o‘zgartirmoqchi ekani haqida tasavvurga ega bo‘lasiz. Keyin esa, agar agent hamma narsani chalkashtirib yuborsa, o‘zgarishlarni orqaga qaytarishga yoki hatto `omarchy reinstall configs` ni chaqirishga tayyor bo‘ling.
