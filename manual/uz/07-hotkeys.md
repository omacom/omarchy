# Tezkor tugmalar

Barcha asosiy klaviatura bog‘lamlarini `Super + K` bilan ko‘rishingiz mumkin (Tmux bog‘lamlari `Super + Alt + K` bilan va Herdr bog‘lamlari `Super + Ctrl + K` bilan).

## Universal almashuv buferi

| Tezkor tugma | Funksiya |
| ----------------------- | --------------------- |
| `Super + C` | Nusxa olish |
| `Super + X` | Kesish (terminalda emas) |
| `Super + V` | Joylashtirish |
| `Super + Ctrl + V` | Almashuv buferi menejeri |

Odatda Linuxda terminalda nusxa olish/joylashtirish uchun `Ctrl + Shift + C/V`, boshqa hamma joyda esa `Ctrl + C/V` kerak bo‘ladi. Ushbu Omarchy birlashtirilgan almashuv buferi tezkor tugmalari hamma joyda ishlaydi.

## Tasvirga olish

| Tezkor tugma | Funksiya |
| ------------------- | ------------------------------ |
| `Print Screen` | Skrinshot |
| `Super + Ctrl + Alt + C` | Skrinshot (xuddi shu tasvir, Print Screen tugmasi yo‘q klaviaturalar uchun) |
| `Super + Ctrl + C` | Tasvirga olish menyusi |
| `Alt + Print Screen` | Ekran yozuvi |
| `Super + Print Screen` | Rang tanlagich |
| `Super + Ctrl + Print Screen` | Matnni ajratib almashuv buferiga olish |
| `Super + Alt + [` | Yozish paytida veb-kamera qoplamasini kichikroq qilish |
| `Super + Alt + ]` | Yozish paytida veb-kamera qoplamasini kattaroq qilish |
| `Alt + Shift + L` | Veb-ilova yoki Chromiumdan joriy URLni nusxalash |
| `Alt + Shift + D` | Joriy sahifadagi videoni `~/Videos` ga yuklab olish |
| `Super + Ctrl + X` | Diktovkani boshlash/to‘xtatish (_Sozlash > Standartlar > Diktovka_ talab qilinadi) |
| `Right Alt` / `F9` | Bosib gapirish diktovkasi (Voxtype yoki Superwhisper talab qilinadi) |

Ekran yozuvlarida tezkor tugma avval qaysi audioni xohlashingizni so‘raydi, keyin yozishni boshlaydi. To‘xtatish uchun yana bosing. Tafsilotlar uchun [skrinshotlar va yozib olish](12-screenshots-recording.md) ga qarang.

Tasvirga olishning barcha variantlari Omarchy menyusida (`Super + Space`) _Ishga tushirish > Tasvirga olish_ ostida ham mavjud.

## Tmux

Prefiks tugmasi `Ctrl + Space` (`Ctrl + B` ham ishlaydi). Ushbu bog‘lamlarni `~/.config/tmux/tmux.conf` da o‘zgartirishingiz mumkin.

### Panellar

| Tezkor tugma | Funksiya |
| ----------------------- | --------------------- |
| `Prefix + v` | Panelni yoniga bo‘lish (vertikal) |
| `Prefix + h` | Panelni pastga bo‘lish (gorizontal) |
| `Prefix + x` | Panelni yopish |
| `Prefix + z` | Panelni kattalashtirishni almashtirish (to‘liq ekran) |
| `Alt + Enter` | Panelni pastga bo‘lish (prefikssiz) |
| `Alt + Shift + Enter` | Panelni yoniga bo‘lish (prefikssiz) |
| `Alt + Escape` | Panelni yopish (prefikssiz) |
| `Ctrl + Alt + Arrows` | Panellar o‘rtasida harakatlanish |
| `Ctrl + Alt + Shift + Arrows` | Panellar o‘lchamini o‘zgartirish |

### Oynalar

| Tezkor tugma | Funksiya |
| ----------------------- | --------------------- |
| `Prefix + c` | Yangi oyna |
| `Prefix + k` | Oynani yopish |
| `Prefix + r` | Oynani qayta nomlash |
| `Alt + 1-9` | Muayyan oynaga o‘tish |
| `Alt + Arrow Left/Right` | Oynalar o‘rtasida harakatlanish |
| `Alt + Shift + Arrow Left/Right` | Oynani chapga/o‘ngga ko‘chirish |

### Sessiyalar

| Tezkor tugma | Funksiya |
| ----------------------- | --------------------- |
| `Prefix + C` | Yangi sessiya |
| `Prefix + K` | Sessiyani yopish |
| `Prefix + R` | Sessiyani qayta nomlash |
| `Prefix + N` | Keyingi sessiya |
| `Prefix + P` | Oldingi sessiya |
| `Alt + Arrow Up/Down` | Sessiyalar o‘rtasida harakatlanish |
| `Prefix + s` | Sessiyalar ro‘yxati |
| `Prefix + d` | Sessiyadan uzilish |

### Nusxa olish rejimi (vi uslubi)

| Tezkor tugma | Funksiya |
| ----------------------- | --------------------- |
| `Prefix + [` | Nusxa olish rejimiga kirish |
| `v` | Tanlashni boshlash (nusxa olish rejimida) |
| `y` | Tanlovni nusxalash (nusxa olish rejimida) |

### Umumiy

| Tezkor tugma | Funksiya |
| ----------------------- | --------------------- |
| `Prefix + q` | Konfiguratsiyani qayta yuklash |
| `Prefix + ?` | Tmux tugma bog‘lamlarini ko‘rsatish |
| `Prefix + :` | Buyruq satri |

### Tmux tartib funksiyalari

Ushbu funksiyalar Tmux sessiyasi ichida ishga tushirilishi kerak.

| Buyruq | Funksiya |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Muharrir, AI va terminal bilan ishlab chiqish tartibini yaratish |
| `tdlm <ai> [<second_ai>]` | Har bir ichki papka uchun ishlab chiqish tartibini yaratish |
| `tsl <count> <command>` | Ko‘p panelli swarm tartibini yaratish |
