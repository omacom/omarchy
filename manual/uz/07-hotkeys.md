# Tezkor tugmalar

Asosiy tugmalar birikmalarining hammasini `Super + K` bilan ko‘rishingiz mumkin (Tmux birikmalari `Super + Alt + K` bilan va Herdr birikmalari `Super + Ctrl + K` bilan).

## Universal almashish buferi

| Tugmalar birikmasi | Vazifasi |
| ----------------------- | --------------------- |
| `Super + C` | Nusxalash |
| `Super + X` | Qirqish (terminalda emas) |
| `Super + V` | Joylashtirish |
| `Super + Ctrl + V` | Almashish buferi menejeri |

Odatda Linux da terminalda nusxalash va joylashtirish uchun `Ctrl + Shift + C/V`, boshqa hamma joyda buni qilish uchun esa `Ctrl + C/V` kerak bo‘ladi. Omarchy ning ushbu yagona almashish buferi tezkor tugmalari hamma joyda ishlaydi.

## Tasvirga olish

| Tugmalar birikmasi | Vazifasi |
| ------------------- | ------------------------------ |
| `Print Screen` | Skrinshot |
| `Super + Ctrl + Alt + C` | Skrinshot (xuddi o‘sha tasvir, Print Screen tugmasi yo‘q klaviaturalar uchun) |
| `Super + Ctrl + C` | Tasvirga olish menyusi |
| `Alt + Print Screen` | Ekranni yozib olish |
| `Super + Print Screen` | Rang tanlagich |
| `Super + Ctrl + Print Screen` | Matnni almashish buferiga ajratib olish |
| `Super + Alt + [` | Yozib olish paytida veb-kamera qoplamasini kichraytirish |

Tasvirga olishning barcha variantlariga Omarchy menyusida (`Super + Space`) _Trigger > Capture_ ostida ham kirish mumkin.
