# Tezkor tugmalar

Barcha asosiy tugmalar birikmalarini `Super + K` bilan ko'rishingiz mumkin (Tmux birikmalari `Super + Alt + K` bilan va Herdr birikmalari `Super + Ctrl + K` bilan).

| Tezkor tugma | Funksiya |
| ----------------------- | --------------------- |
| `Super + Space` | Omarchy menyusi (ilovalar va boshqa hamma narsa) |
| `Super + Alt + Space` | Ilovalar panjarasi |
| `Super + Escape` | Tizim menyusi (kutish rejimi, qayta ishga tushirish va boshqalar) |
| `Super + Ctrl + L` | Kompyuterni qulflash |

| `Super + Home` | Saqlangan oyna kengligini tiklash |
| `Super + Left Mouse` | Oynani sudrab yurish |
| `Super + Right Mouse` | Oyna o'lchamini o'zgartirish |
| `Super + Scroll Wheel` | Fokusdagi monitordagi ish maydonlari bo'ylab aylantirish |
| `Super + G` | Oynalarni guruhlashni yoqish/o'chirish |
| `Super + Alt + G` | Oynani guruhdan chiqarish |

| `Super + Alt + Shift + Tab` | Guruh ichidagi oynalar bo'ylab orqaga aylanish |

| `Super + Alt + 1/2/3/4/5` | Guruhdagi muayyan oynaga o'tish |

| `Super + Ctrl + Alt + Z` | Ekrandan to'liq uzoqlashish |

| `Alt + Shift + Tab` | Faol ish maydonidagi oynalar bo'ylab orqaga aylanish |
| `Ctrl + Alt + Tab` | Fokusni monitorlar bo'ylab oldinga aylanish |
| `Ctrl + Alt + Shift + Tab` | Fokusni monitorlar bo'ylab orqaga aylanish |

O'lcham o'zgartirish yorliqlari klaviaturada bosilgan belgilardan qat'i nazar, fizik `code:20` va `code:21` tugmalaridan (XKB `<AE11>` va `<AE12>`) foydalanadi. US klaviaturalarida bu tugmalar `-` va `=`; yapon (JIS) klaviaturalarida ular `-` va `^`; ispan klaviaturalarida ular `'` va `¡`. JIS da `Super + ^` bu `Super + Equal`, `Super + Shift + -` (`=` ni yozadi) esa `Super + Shift + Minus` dir.

## Universal bufer

| Tezkor tugma | Funksiya |
| ----------------------- | --------------------- |
| `Super + A` | `Ctrl + A` ni qo'llab-quvvatlaydigan ilovalarda hammasini tanlash |
| `Super + C` | Nusxalash |
| `Super + X` | Kesish (terminalda emas) |

Odatda Linux da terminalda nusxalash va qo'yish uchun `Ctrl + Shift + C/V` va boshqa hamma joyda buni qilish uchun `Ctrl + C/V` kerak bo'ladi. Ushbu Omarchy birlashtirilgan bufer tezkor tugmalari hamma joyda ishlaydi.

Barcha tasvirga olish variantlariga Omarchy menyusidagi (`Super + Space`) _Trigger > Capture_ ostida ham kirish mumkin.

## Tmux

### Panellar

| Tezkor tugma | Funksiya |
| ----------------------- | --------------------- |

| `Prefix + x` | Panelni o'ldirish |
