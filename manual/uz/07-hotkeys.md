# Tezkor tugmalar

Barcha asosiy klaviatura bog‘lanishlarini `Super + K` bilan ko‘rishingiz mumkin (Tmux bog‘lanishlari `Super + Alt + K` bilan va Herdr bog‘lanishlari `Super + Ctrl + K` bilan).

O‘lcham o‘zgartirish tezkor tugmalari fizik `code:20` va `code:21` tugmalaridan (XKB `<AE11>` va `<AE12>`) foydalanadi, klaviaturada bosilgan belgilardan qat’i nazar. AQSh klaviaturalarida bu tugmalar `-` va `=`; yapon (JIS) klaviaturalarida ular `-` va `^`; ispan klaviaturalarida ular `'` va `¡`. JIS da, `Super + ^` bu `Super + Equal`, `Super + Shift + -` (u `=` ni yozadi) esa `Super + Shift + Minus` dir.

## Universal almashuv buferi

| Tezkor tugma                  | Funksiya              |
| ----------------------- | --------------------- |
| `Super + A`           | `Ctrl + A` ni qo‘llab-quvvatlaydigan ilovalarda hammasini tanlash    |
| `Super + C`           | Nusxalash    |
| `Super + X`           | Qirqish (terminalda emas)    |
| `Super + V`           | Qo‘yish    |
| `Super + Ctrl + V`           | Almashuv buferi boshqaruvchisi    |

Odatda Linux da, terminalda nusxalash va qo‘yish uchun `Ctrl + Shift + C/V` kerak bo‘ladi, boshqa hamma joyda esa `Ctrl + C/V` kerak bo‘ladi. Bu Omarchy universal almashuv buferi tezkor tugmalari hamma joyda ishlaydi.
