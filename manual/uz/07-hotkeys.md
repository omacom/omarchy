# Tezkor tugmalar

Barcha asosiy klaviatura bog‘lamlarini `Super + K` bilan ko‘rishingiz mumkin (Tmux bog‘lamlari `Super + Alt + K` bilan va Herdr bog‘lamlari `Super + Ctrl + K` bilan).

## Universal almashish buferi

| Tugma                  | Funksiya              |
| ----------------------- | --------------------- |
| `Super + C`           | Nusxalash    |
| `Super + X`           | Kesish (terminalda emas)    |
| `Super + V`           | Qo‘yish    |

Odatda Linux da terminalda copy'n'paste qilish uchun `Ctrl + Shift + C/V` va boshqa hamma joyda qilish uchun `Ctrl + C/V` kerak bo‘ladi. Ushbu Omarchy birlashtirilgan almashish buferi tezkor tugmalari hamma joyda ishlaydi.

## Tasvirga olish

| Tugma              | Funksiya                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Screenshot                      |
| `Super + Ctrl + Alt + C`            | Screenshot (xuddi shu tasvir, Print Screen tugmasi yo‘q klaviaturalar uchun) |
| `Super + Ctrl + C` | Tasvirga olish menyusi |
| `Alt + Print Screen`            | Screenrecord                     |
| `Super + Print Screen` | Rang tanlagich |
| `Super + Ctrl + Print Screen` | Matnni ajratib almashish buferiga olish |
| `Super + Alt + [` | Yozib olish paytida webcam qoplamasini kichraytirish |
| `Super + Alt + ]` | Yozib olish paytida webcam qoplamasini kattalashtirish |

| `Alt + Shift + D` | Joriy sahifadagi videoni `~/Videos` ga yuklab olish |

| `Right Alt` / `F9` | Push-to-talk diktovka (Voxtype yoki Superwhisper talab qilinadi) |

Screenrecording larda tezkor tugma avval qaysi audioni xohlashingizni so‘raydi, keyin yozishni boshlaydi. To‘xtatish uchun uni yana bosing. Tafsilotlar uchun [skrinshotlar va yozib olish](12-screenshots-recording.md) ga qarang.

Barcha tasvirga olish variantlariga Omarchy menyusida (`Super + Space`) _Trigger > Capture_ ostida ham kirish mumkin.

## Tmux

Prefix tugmasi `Ctrl + Space` (`Ctrl + B` ham ishlaydi). Ushbu bog‘lamlarni `~/.config/tmux/tmux.conf` da o‘zgartirishingiz mumkin.

### Panellar

| Tugma                  | Funksiya              |
| ----------------------- | --------------------- |
| `Prefix + v` | Panelni yoniga bo‘lish (vertikal) |
| `Prefix + h` | Panelni pastiga bo‘lish (gorizontal) |
| `Prefix + x` | Panelni o‘ldirish |
| `Prefix + z` | Panelni yaqinlashtirishni almashtirish (fullscreen) |
| `Alt + Enter` | Panelni pastiga bo‘lish (prefix siz) |
| `Alt + Shift + Enter` | Panelni yoniga bo‘lish (prefix siz) |
| `Alt + Escape` | Panelni o‘ldirish (prefix siz) |
| `Ctrl + Alt + Arrows` | Panellar orasida harakatlanish |
| `Ctrl + Alt + Shift + Arrows` | Panellar o‘lchamini o‘zgartirish |

### Oynalar

### Tmux joylashuv funksiyalari

| Buyruq | Funksiya |
| ------- | -------- |
