# Yagona bufer va tarix

Odatda Linux'da terminalda nusxa ko'chirib joylashtirish uchun `Ctrl + Shift + C/V`, boshqa hamma joyda esa buni qilish uchun `Ctrl + C/V` kerak bo'ladi. Linux'da tug'ilib o'smagan har bir kishi uchun bunga o'rganish qiyin! Mac'dan kelayotgan bo'lsangiz, Super'dan Ctrl'ga o'tish ham xuddi shunday.

Omarchy bu ikkala muammoni ham (deyarli) hamma joyda ishlaydigan yagona bufer tezkor tugmalari bilan hal qiladi. Ular quyidagilar:

| Tezkor tugma | Buyruq |
| ------- | ----------- |
| Super + A | Barchasini tanlash |
| Super + C | Nusxa ko'chirish |
| Super + X | Kesib olish |
| Super + V | Joylashtirish |
| Super + Ctrl + V | Bufer tarixi |

_E'tibor bering, aksariyat agent ish muhitlari rasmlarni joylashtirish uchun `Ctrl + V` dan, matnni joylashtirish uchun esa `Super + V` dan foydalanadi._

Fokusdagi matn maydonidagi yoki `Ctrl + A` ni qo'llab-quvvatlaydigan boshqa ilovadagi hamma narsadan nusxa ko'chirish uchun `Super + A`, keyin `Super + C` ni ishlating. Terminalda `Ctrl + A` buyruqlar qatori matnini tanlash o'rniga uning boshiga o'tadi.

### Bufer tarixi

Bufer tarixini Omarchy qobig'i taqdim etadi va u ham matn, ham rasmlar uchun ishlaydi. Uni `Super + Ctrl + V` bilan chaqirasiz va yozuvni Return bilan tanlaysiz, shunda u to'g'ridan-to'g'ri siz bo'lgan ilovaga joylashtiriladi. Uni faqat buferga nusxa ko'chirish uchun `Shift + Return` ni, uni ochish uchun `Alt + Return` ni, uni tarixdan o'chirish uchun `Delete` ni, butun tarixni tozalash uchun esa `Shift + Delete` ni ishlating.
