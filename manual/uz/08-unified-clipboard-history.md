# Yagona bufer va tarix

Odatda Linuxda terminalda nusxalash va qoʻyish uchun `Ctrl + Shift + C/V`, boshqa hamma joyda esa `Ctrl + C/V` kerak. Linuxda tugʻilib oʻsmagan har kishi uchun bunga oʻrganish qiyin! Xuddi Macdan kelayotgan boʻlsangiz superdan ctrlga oʻtish kabi.

Omarchy ikkala muammoni ham (deyarli) hamma joyda ishlaydigan yagona bufer hotkeylari bilan hal qiladi. Ular:

| Hotkey | Buyruq |
| ------- | ----------- |
| Super + C | Nusxalash |
| Super + X | Kesish |
| Super + V | Qoʻyish |
| Super + Ctrl + V | Bufer tarixi |

_Esda tuting, koʻplab agent harnesslari rasmlarni qoʻyish uchun `Ctrl + V`, matnni qoʻyish uchun esa `Super + V` ishlatadi._

### Bufer tarixi

Bufer tarixi Omarchy shelli tomonidan taqdim etiladi va matn ham, rasmlar uchun ham ishlaydi. Siz uni `Super + Ctrl + V` bilan chaqirasiz, yozuvingizni return bilan tanlaysiz va keyin u `Super + V` da qoʻyishga tayyor holda buferga joylashtiriladi.
