# Atgādinājumi

Omarchy ir iebūvēts veids, kā iestatīt vienkāršus atgādinājumus, pamatojoties uz atpakaļskaitīšanas taimeri un ar ziņojumu. Tu to vari izdarīt, izmantojot `Super + Ctrl + R`, redzēt visus iestatītos, izmantojot `Super + Ctrl + Alt + R`, un notīrīt visus, izmantojot `Super + Ctrl + Shift + R`. Visam var piekļūt arī, izmantojot _Palaist > Atgādinājums_. Tu vari izmantot arī cli ar `omarchy reminder 7 'Tea ready'`.
