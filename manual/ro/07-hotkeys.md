# Scurtături

Poți vedea toate mapările principale de tastatură cu `Super + K` (mapările Tmux cu `Super + Alt + K` și mapările Herdr cu `Super + Ctrl + K`).

## Navigarea

| Scurtătură                  | Funcție              |
| ----------------------- | --------------------- |
| `Super + Space`           | Meniul Omarchy (aplicații și tot restul)    |
| `Super + Alt + Space` | Grila de aplicații |
| `Super + Escape` | Meniul de sistem (suspendă, repornește etc.)  |
| `Super + Ctrl + L` | Blochează calculatorul |
| `Super + W` sau `Super + Q` | Închide fereastra             |
| `Ctrl + Alt + Del` | Închide toate ferestrele |
| `Super + T`               | Comută fereastra între mozaic/plutitoare             |
| `Super + J` | Comută poziția ferestrei (orizontal/vertical) |
| `Super + O`               | Comută desprinderea ferestrei în lipicioasă și plutitoare |
| `Super + L`               | Parcurge aranjările mozaic, defilantă și plutitoare |
| `Super + Alt + L`         | Parcurge aranjările în sens invers |
| `Super + P`               | Comută stilul pseudo al ferestrei (natural vs întins) |
| `Super + F`                 | Treci la ecran complet              |
| `Super + Alt + F`                 | Treci la lățime completă              |
| `Super + Ctrl + F`                 | Treci la ecran complet în interiorul ferestrei              |
| `Super + 1/2/3/4`         | Sari la un anumit spațiu de lucru     |
| `Super + Tab` | Sari la spațiul de lucru următor |
| `Super + Shift + Tab` | Sari la spațiul de lucru anterior |
| `Super + Ctrl + Tab` | Sari la spațiul de lucru de dinainte |
| `Super + Shift + 1/2/3/4` | Mută fereastra pe un spațiu de lucru |
| `Super + Shift + Alt + 1/2/3/4` | Mută fereastra pe un spațiu de lucru fără s-o urmezi |
| `Super + S` / `Super + Grave` | Comută scratchpadul |
| `Super + Alt + S` / `Super + Shift + Grave` | Mută fereastra pe scratchpad |
| `Super + Shift + Alt + Arrows` | Mută spațiile de lucru pe monitorul din direcție |
| `Super + Arrow`  | Mută focalizarea pe fereastra din direcția săgeții              |
| `Super + Shift + Arrow`  | Schimbă fereastra cu alta din direcția săgeții     |
| `Super + Minus` | Extinde fereastra spre stânga |
| `Super + Equal` | Micșorează fereastra spre stânga |
| `Super + Shift + Minus` | Micșorează fereastra în sus |
| `Super + Shift + Equal` | Extinde fereastra în jos |
| `Super + Alt + Minus/Equal` | Aceeași redimensionare în pași mai mici |
| `Super + Ctrl + Minus/Equal` | Aceeași redimensionare în pași mai mari |
| `Super + Alt + Home` | Salvează lățimea ferestrei |
| `Super + Home` | Restabilește lățimea salvată a ferestrei |
| `Super + Left Mouse` | Trage fereastra |
| `Super + Right Mouse` | Redimensionează fereastra |
| `Super + Scroll Wheel` | Derulează printre spațiile de lucru |
| `Super + G`               | Comută gruparea ferestrelor      |
| `Super + Alt + G`               | Scoate fereastra din grupare      |
| `Super + Alt + Tab`               | Parcurge ferestrele din grupare      |
| `Super + Alt + Shift + Tab`               | Parcurge înapoi ferestrele din grupare      |
| `Super + Alt + 1/2/3/4/5`               | Sari la o anumită fereastră din grupare      |
| `Super + Alt + Arrow`  | Mută fereastra în grupare în direcția săgeții  |
| `Super + Ctrl + Left/Right`  | Te muți între ferestrele dintr-un grup mozaic |
| `Super + Ctrl + Z` | Mărește pe ecran (repetă pentru mai mult zoom) |
| `Super + Ctrl + Alt + Z` | Micșorează complet de pe ecran |
| `Super + /` | Pășește înainte prin opțiunile de scalare a monitorului |
| `Super + Alt + /` | Pășește înapoi prin opțiunile de scalare a monitorului |
| `Alt + Tab` | Parcurge înainte ferestrele de pe spațiul de lucru activ |
| `Alt + Shift + Tab` | Parcurge înapoi ferestrele de pe spațiul de lucru activ |
| `Ctrl + Alt + Tab`| Parcurge focalizarea înainte printre monitoare |
| `Ctrl + Alt + Shift + Tab`| Parcurge focalizarea înapoi printre monitoare |

## Clipboard universal

| Scurtătură                  | Funcție              |
| ----------------------- | --------------------- |
| `Super + C`           | Copiază    |
| `Super + X`           | Taie (nu în terminal)    |
| `Super + V`           | Lipește    |
| `Super + Ctrl + V`           | Manager de clipboard    |

De obicei, pe Linux, ai nevoie de `Ctrl + Shift + C/V` ca să copiezi și să lipești în terminal și de `Ctrl + C/V` ca să o faci peste tot în rest. Aceste scurtături de clipboard unificate ale Omarchy funcționează peste tot.

## Captură

| Scurtătură              | Funcție                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Meniu Captură (pentru tastaturi fără buton PrintScr) |
| `Print Screen`            | Captură de ecran                      |
| `Alt + Print Screen`            | Înregistrare ecran                     |
| `Super + Print Screen` | Selector de culoare |
| `Super + Ctrl + Print Screen` | Extragerea textului pe clipboard |
| `Super + Alt + [` | Face suprapunerea webcam mai mică în timpul înregistrării |
| `Super + Alt + ]` | Face suprapunerea webcam mai mare în timpul înregistrării |
| `Alt + Shift + L` | Copiază URL-ul curent din webapp sau Chromium |
| `Alt + Shift + D` | Descarcă videoclipul de pe pagina curentă în `~/Videos` |
| `Super + Ctrl + X` | Pornește/oprește dictarea (necesită _Configurare > Implicite > Dictation_) |
| `Right Alt` / `F9` | Dictare cu apăsare ca să vorbești (necesită Voxtype sau Superwhisper) |

La înregistrările de ecran, scurtătura întreabă mai întâi ce sunet vrei, apoi pornește înregistrarea. Apas-o din nou ca să oprești. Vezi [capturile de ecran și înregistrarea](12-screenshots-recording.md) pentru detalii.

Toate opțiunile de captură sunt accesibile și sub _Declanșator > Captură_ în meniul Omarchy (`Super + Space`).

## Tmux

Tasta prefix este `Ctrl + Space` (funcționează și `Ctrl + B`). Poți schimba aceste mapări în `~/.config/tmux/tmux.conf`.

### Panouri

| Scurtătură                  | Funcție              |
| ----------------------- | --------------------- |
| `Prefix + v` | Divizează panoul alături (vertical) |
| `Prefix + h` | Divizează panoul dedesubt (orizontal) |
| `Prefix + x` | Omoară panoul |
| `Prefix + z` | Comută zoomul panoului (ecran complet) |
| `Alt + Enter` | Divizează panoul dedesubt (fără prefix) |
| `Alt + Shift + Enter` | Divizează panoul alături (fără prefix) |
| `Alt + Escape` | Omoară panoul (fără prefix) |
| `Ctrl + Alt + Arrows` | Te muți între panouri |
| `Ctrl + Alt + Shift + Arrows` | Redimensionează panourile |

### Ferestre

| Scurtătură                  | Funcție              |
| ----------------------- | --------------------- |
| `Prefix + c` | Fereastră nouă |
| `Prefix + k` | Omoară fereastra |
| `Prefix + r` | Redenumește fereastra |
| `Alt + 1-9` | Mergi la o anumită fereastră |
| `Alt + Arrow Left/Right` | Te muți între ferestre |
| `Alt + Shift + Arrow Left/Right` | Mută fereastra la stânga/la dreapta |

### Sesiuni

| Scurtătură                  | Funcție              |
| ----------------------- | --------------------- |
| `Prefix + C` | Sesiune nouă |
| `Prefix + K` | Omoară sesiunea |
| `Prefix + R` | Redenumește sesiunea |
| `Prefix + N` | Sesiunea următoare |
| `Prefix + P` | Sesiunea anterioară |
| `Alt + Arrow Up/Down` | Te muți între sesiuni |
| `Prefix + s` | Enumeră sesiunile |
| `Prefix + d` | Desprinde-te de sesiune |

### Mod copiere (în stil vi)

| Scurtătură                  | Funcție              |
| ----------------------- | --------------------- |
| `Prefix + [` | Intră în modul copiere |
| `v` | Începe selecția (în modul copiere) |
| `y` | Copiază selecția (în modul copiere) |

### Generale

| Scurtătură                  | Funcție              |
| ----------------------- | --------------------- |
| `Prefix + q` | Reîncarcă configurația |
| `Prefix + ?` | Arată mapările Tmux |
| `Prefix + :` | Indicator de comandă |

### Funcții de aranjare Tmux

Aceste funcții trebuie rulate în interiorul unei sesiuni Tmux.

| Comandă | Funcție |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Creează o aranjare de dezvoltare cu editor, AI și terminal |
| `tdlm <ai> [<second_ai>]` | Creează o aranjare de dezvoltare per subdirector |
| `tsl <count> <command>` | Creează o aranjare-roi cu mai multe panouri |
