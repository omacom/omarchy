# 頂部列

螢幕頂部那條就是 Omarchy 列。它不是外加的狀態列，而是 Omarchy shell 的一部分，也就是那個長期執行的 Quickshell 程序，同一個程序也負責繪製選單、通知、OSD 彈出視窗和鎖定畫面。這就是為什麼它跟其他所有東西的主題都能完美契合，也為什麼面板能立即開啟，而不是另行啟動一個應用程式。

它也是桌面上唯一永遠留在畫面上的部分，所以值得弄清楚那些小圖示到底都在做什麼。

## 預設有哪些東西

這條列有三個區段。左邊是 Omarchy logo（選單啟動器）和工作區指示器。中間是狀態指示器、時鐘、Elsewhen（世界時鐘）、天氣，以及 Omarchy 更新徽章。右邊則是：系統匣、鍵盤配置（設定不只一個配置時才會顯示）、agents、bluetooth、network、audio、display 和 power。

其中有幾個只有在有話要說時才會出現。鍵盤配置只有在你設定了不只一個配置時才會出現。更新徽章只有在有 Omarchy 更新等待處理時才會出現。而 agents 圖示則會在 Omarchy 第一次在這台機器上發現 AI coding 使用量時出現（請參閱 [AI](17-ai.md)）。

## 面板

點擊列上的圖示會開啟一個面板，這是一個正經的彈出視窗，裡面有滑桿、清單和鍵盤導覽，而不是一個工具提示。每個面板也都有熱鍵，所以你永遠不必去瞄準一個 16 像素的圖示：

| 熱鍵 | 面板 |
| --- | --- |
| `Super + Ctrl + A` | Audio |
| `Super + Ctrl + N` | Network |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | Display |
| `Super + Ctrl + P` | Power |
| `Super + Ctrl + Alt + D` | Calendar |
| `Super + Ctrl + Alt + E` | World clock |
| `Super + Ctrl + 1-9` | 切換右側區段中的第 n 個面板 |

這些面板不是只能看的讀數。它們就是讓你實際動手做事的地方：

- **Audio** 有主音量滑桿、輸出裝置選擇器，以及針對每個應用程式的混音器，所以你可以在不影響其他所有東西的情況下，調低某一個瀏覽器分頁的音量。
- **Network** 會掃描 Wi-Fi、顯示訊號強度、進行連線，並讓你選擇 DNS 提供者。
- **Bluetooth** 會列出你的裝置，包含連線/中斷連線和電池電量。
- **Power** 會顯示電池統計資料、切換電源設定檔（它會分別記住使用電池和 AC 時的選擇），並印出一些系統資訊。
- **Display** 帶有亮度滑桿、文字大小、螢幕縮放預設，而且——當你有不只一台螢幕時——還有多螢幕專屬控制。更深入的故事請參閱[螢幕](33-monitors.md)。
- **Clock** 會開啟一張帶有 ISO 週數和月份步進的月份格線。
- **World clock** 為每個城市保留一列，包含它的天氣，以及它那一天的進展如何。搜尋可以找到城鎮和時區，所以 Fort Lauderdale 就是 Fort Lauderdale，而不是 New York。如果最上方那一行寫錯了城市，點它並告訴它你在哪裡；挑一個位於另一個時區的地方，系統時鐘也會跟著移到那裡，旅行時很方便。將滑鼠懸停在一個城市上，點擊人物按鈕，說明誰住在那裡——可以用一般名字，或用 `@` GitHub 帳號把他們的頭像也帶進來。

每個面板都支援鍵盤和滑鼠：方向鍵可以移動，Return 可以啟動，Tab 可以跳到相鄰的面板，Escape 可以關閉。

`Super + Ctrl + 1-9` 會從左到右計算右側區段中的面板，並跳過系統匣，因為它本身沒有面板。所以這個數字會和你會指向的那個圖示吻合。

### Tailscale 和 Dropbox

還有另外兩個小工具，只有在你從**安裝 → 服務**安裝了對應的服務之後才會出現在列上，而且兩個都值得了解一下，因為它們不只是回報狀態而已。

**Tailscale** 面板可以連線和中斷 tailnet、切換帳號，並選擇一個 exit node（你自己的機器和 Mullvad 地區都會出現在那份清單裡）。它還可以瀏覽你的機器——而且選好一台之後，`s` 會透過 Taildrop 把檔案送到它那裡，這是把檔案移到你的手機或另一台筆記型電腦最快的方法。`c` 會複製該機器的 IP，`n` 會複製它的名稱，`d` 則會複製它完整的 DNS 名稱。每個機器列上也有一個傳送按鈕，如果你比較想用點的。同樣的事情從終端機執行就是 `omarchy tailscale send <machine> [file...]`。

**Dropbox** 面板負責登入、顯示你已經用了多少儲存空間，並列出最近同步的檔案。

移除任何一個服務，都會把對應的小工具從列上拿掉。

## 指示器

中間那一小簇就是指示器小工具。這些是代表你已開啟的模式的狀態圖示：不要打擾、夜間模式、一個排隊中的[提醒](09-reminders.md)、進行中的螢幕錄影、保持喚醒，以及[聽寫](11-text-extraction-dictation.md)。模式啟用時它們會亮起，不然就會乖乖待在一旁——將滑鼠懸停在列上的任意位置，就能窺見那些未啟用的指示器。點擊一個指示器就會切換該模式。還有一個只能顯示狀態：當有人透過 gliff 連線到這台機器時，遠端工作階段會亮起紅燈。

如果你寧願讓它們永遠可見，可以把小工具上的 `alwaysShow` 設為 `true`。如果你只在意其中某幾個，就在 `items` 裡列出你想要的：`["Dnd", "Reminder", "NightLight"]`。你可以擁有不只一個指示器小工具，所以不同區段可以顯示不同的子集。

## 重新排列這條列

這條列會自行設定。你不必開啟設定檔就能移動東西。

抓取列上靠近中間的一塊空白區域，把它往另一個螢幕邊緣拖，這條列就會移到那裡——左、右、上、下都能用，而且每個小工具都會跟著適應（直向列會改用精簡的僅圖示形式）。按住不放也能啟動同樣的拖曳。在同一個空白處連點兩下左鍵，就能讓列的背景依序從透明切換到玻璃質感再到不透明。而拖曳任何小工具，就能重新排序它，或把它扔進另一個區段；其他小工具會滑開，為它即將落下的位置騰出空間。

這條列的中間是一個盒子：放在裡面的東西會以一個群組的形式保持置中，它兩邊的小工具則掛在它的邊緣上。當你拖曳一個小工具時，這個盒子會以輪廓的形式顯示出來，空的時候則會是一條橫貫列上的線，而且你可以把它放到盒子裡面或旁邊。當一次放置會落在盒子裡時，盒子會長大，把該小工具收進去。

你想留在身邊、但不想永遠看見的小工具，可以放進系統匣的抽屜裡：把它拖到系統匣上，抽屜就會打開把它收進去。它會待在應用程式圖示後面，每次抽屜出現時跟著出現，而且在它的面板開啟期間保持抽屜開啟。要把它放回去，就把它拖回列上。

如果你寧願從選單裡挑，**外觀 → 選單列**裡有位置設定，而**列背景**可以挑選這條列的繪製方式：**不透明列**、**玻璃質感列**（透明，並把後面的東西模糊化），或**透明列**。

同樣的事情也有命令可用，這正是你在設定 [dotfiles](31-dotfiles.md) 時會想要的方式：

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

若要完全新增或移除一個小工具，請使用 plugin 命令。`omarchy plugin list` 會印出 shell 知道的每個小工具及其 id，然後：

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## 隱藏這條列

`Super + Shift + Space` 可以在不殺掉 shell 的情況下關閉和重新開啟這條列——面板和熱鍵會繼續運作，你只是把像素拿回來。它也在選單裡的**外觀 → 選單列 → 隱藏列**底下。

## 設定檔

所有這些都儲存在 `~/.config/omarchy/shell.json` 裡的 `bar` 鍵底下。這是精簡過的版本：

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

每個小工具都是五個 layout 陣列其中一個裡面的一筆項目，它的設定就直接寫在那筆項目上——沒有另外的設定檔，也沒有 `config` 子物件。時鐘的 `format`、`formatAlt`（右鍵點擊會切換到的格式）和 `verticalFormat` 全都直接住在 `{ "id": "omarchy.clock" }` 上。

`center` 就是列中間的那個盒子：裡面的每一樣東西都會以一個群組的形式在螢幕上置中。`centerBegin` 和 `centerEnd` 則掛在盒子的兩側，天氣和更新徽章來來去去時，時鐘還能維持正中央，就是靠這個。把不只一個小工具放進 `center`，它們就會一起置中；讓它保持空的，`centerBegin` 和 `centerEnd` 就會在列的中間相會。

有一條規則值得記牢：**一旦你有了自己的 `shell.json`，它就是權威**。在你自訂任何東西之前，shell 會讀取 Omarchy 的預設檔案。而你一拖曳小工具、執行 `omarchy bar`，或自己編輯檔案的那一刻起，它就是你的了——沒有深度合併，所以未來 Omarchy 版本裡的新預設小工具不會自動出現在你的列上。每當你想要一個乾淨的起點，`omarchy bar defaults` 都能把出貨時的版面配置放回去。

同一個檔案在最上層也放著你的閒置計時，位於 `bar` 鍵之外：`idle.screensaver` 和 `idle.lock`，兩者都是從你開始閒置起算的秒數。所以預設的螢幕保護程式會在 150 秒後啟用，而鎖定會在 300 秒後啟用。
