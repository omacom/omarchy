# 頂部列

螢幕頂端的那條長條就是 Omarchy 列。它不是外加的狀態列，而是 Omarchy shell 的一部分，也就是那個長時間執行的單一 Quickshell 程序，它同時也負責繪製選單、通知、OSD 彈出視窗和鎖定畫面。這就是為什麼它的主題能和其他所有東西完美契合，也是為什麼面板能立即開啟，而不用再啟動一個新的應用程式。

它也是桌面上唯一永遠顯示在螢幕上的部分，所以很值得搞清楚那些小圖示到底能做什麼。

## 預設有哪些東西

這條列有三個區段。左邊是 Omarchy 標誌（選單啟動器）和工作區指示器。中間是狀態指示器、時鐘、Elsewhen（世界時鐘）、天氣，以及 Omarchy 更新徽章。右邊則是：系統匣、鍵盤配置（當你設定了不只一種配置或輸入法時）、agents、bluetooth、網路、音訊、顯示和電源。

其中有幾個只會在有事要說的時候才出現。鍵盤配置只有在你設定了不只一種配置或輸入法時才會出現。更新徽章只有在有 Omarchy 更新正在等待時才會出現。

## 這些面板

點擊列上的圖示會開啟一個面板，這是一個像樣的彈出視窗，帶有滑桿、清單和鍵盤導覽，而不是一個提示框。每一個面板也都有快速鍵，所以你永遠不用去瞄準一個 16 像素的小圖示：

| 快速鍵 | 面板 |
| --- | --- |
| `Super + Ctrl + A` | 音訊 |
| `Super + Ctrl + N` | 網路 |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | 顯示 |
| `Super + Ctrl + P` | 電源 |
| `Super + Ctrl + Alt + D` | 行事曆 |
| `Super + Ctrl + Alt + E` | 世界時鐘 |
| `Super + Ctrl + X` | Agents |
| `Super + Ctrl + 1-9` | 切換右側區段中的第 n 個面板 |

這些面板不是只能看的讀數。它們就是你實際動手做事的地方：

- **音訊**有主音量滑桿、輸出裝置選擇器，以及按應用程式區分的混音器，所以你可以把那一個瀏覽器分頁的音量調小，而不去動到其他所有東西。
- **網路**會掃描 Wi-Fi、顯示訊號強度、進行連線，並讓你選擇 DNS 供應商。
- **Bluetooth**會列出你的裝置，帶有連線／中斷連線和電池電量。
- **電源**會顯示電池統計資料、切換電源設定檔（它會分別記住電池和 AC 時的選擇），並印出一些系統資訊。
- **顯示**帶有亮度滑桿、文字大小、顯示器縮放預設，以及——當你有不只一台螢幕時——各顯示器專屬的控制項。更深入的故事請參閱[顯示器](33-monitors.md)。
- **時鐘**會開啟一個帶有 ISO 週數和月份切換的月份網格。
- **世界時鐘**為每個城市保留一列，帶有它的天氣，以及它那一天過得如何。搜尋能找城鎮也能找時區，所以 Fort Lauderdale 就是 Fort Lauderdale，而不是 New York。如果頂端那一行寫錯了城市，點它並告訴它你在哪裡；選一個在另一個時區的地方，系統時鐘也會跟著移到那裡，旅行時很方便。把滑鼠停在一個城市上，點擊人物按鈕，說誰住在那裡——可以用普通姓名，或用 `@` GitHub 帳號把他們的臉孔也一併帶進來。

每個面板都能用鍵盤，也能用滑鼠：方向鍵移動，Return 啟動，Tab 移到相鄰的面板，Escape 關閉。

`Super + Ctrl + 1-9` 會從左到右計算右側區段中的面板，跳過系統匣，因為它本身沒有面板。所以這個數字會和你會指著的那個圖示對得上。

### Tailscale 和 Dropbox

還有兩個元件只有在你從 **Install → Service** 安裝了對應的服務之後才會出現在列上，而且兩個都值得了解一下，因為它們不只是回報狀態。

**Tailscale** 面板可以連接和中斷 tailnet 的連線、在帳號之間切換，並選擇一個 exit node（你自己的機器和 Mullvad 區域都會出現在那份清單裡）。它也能瀏覽你的機器——而且選定一台之後，按 `s` 就能透過 Taildrop 把檔案傳給它，這是把檔案移到你的手機或另一台筆電最快的方法。`c` 複製那台機器的 IP，`n` 複製它的名稱，`d` 複製它的完整 DNS 名稱。每個機器列上也有一個傳送按鈕，如果你比較想用點的。同樣的事情從終端機做就是 `omarchy tailscale send <machine> [file...]`。

**Dropbox** 面板處理登入、顯示你已用了多少儲存空間，並列出最近同步的檔案。

移除任一服務，它的元件就會從列上消失。

## 指示器

中間那一小簇就是指示器元件。這些是給你已開啟的模式用的狀態圖示：勿擾模式、夜間光線、一個排入佇列的[提醒](09-reminders.md)、進行中的螢幕錄影，和保持清醒，外加在免密碼 sudo 開啟時，或有人連線到遠端工作階段時的警告。它們會在模式啟用時亮起，不然就閃到一邊——把滑鼠停在它們旁邊、也就是那些未啟用的指示器會待著的地方，就能偷看一下它們。點擊一個指示器就會切換那個模式。還有一個只能表示狀態：當有人透過 gliff 連線到這台機器時，遠端工作階段會亮起紅色。

如果你比較希望它們永遠可見，把該元件上的 `alwaysShow` 設為 `true`。而如果你只在乎其中某幾個，把你想要的幾個列在 `items` 裡：`["Dnd", "Reminder", "NightLight"]`。你可以有不只一個指示器元件，所以不同的區段可以顯示不同的子集。

## 重新排列這條列

這條列會自己設定自己。你不用為了移動東西而去開啟設定檔。

抓住列上中間附近的一塊空地，把它拖向另一個螢幕邊緣，這條列就會移到那裡——左、右、上、下都能用，而且每個元件都會適應（直式列會退回成精簡的僅圖示形式）。按住不放也能開始同樣的拖曳。在同樣的空地上按兩下左鍵，就能循環切換列的背景，從透明到玻璃質感到不透明。而拖曳任何元件就能重新排列它，或把它扔進另一個區段；其他元件會滑開，在它將要落下的地方騰出空間。

列的中間是一個盒子：不管裡面有什麼，都會以一組的形式保持置中，而它兩邊的元件則掛在它的邊緣上。當你拖曳一個元件時，這個盒子會顯示為一個輪廓，或在它是空的時候顯示為一條橫過這條列的線，而你可以把它放進去，或放在它旁邊。當一次放置會落進這個盒子裡時，這個盒子會變大，把那個元件收進去。

一個你想留著但不想一直看著的元件可以放進系統匣的抽屜裡：把它拖到系統匣上，抽屜就會打開把它收進去。它會待在那裡，在應用程式圖示之後，只要抽屜出現它就會出現，而且當它的面板開啟時它會讓抽屜保持開啟。把它拖回列上就能放回去。

如果你比較喜歡從選單裡挑，**Appearance → Menu Bar** 裡有位置，而 **Bar Background** 挑選這條列要如何繪製：**Opaque Bar**、**Glassy Bar**（透明的，帶有背後內容的模糊），或 **Clear Bar**。

同樣的事情也有指令，這正是你為 [dotfiles 設定](31-dotfiles.md) 安裝環境時想要的：

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

若要完全新增或移除一個元件，使用 plugin 指令。`omarchy plugin list` 會印出 shell 所知道的每個元件，連同它的 id，然後：

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## 隱藏這條列

`Super + Shift + Space` 會把這條列關掉再開啟，不會殺掉 shell——面板和快速鍵都繼續運作，你只是把那些像素拿回來。它也在選單裡的 **Appearance → Menu Bar → Hide Bar** 底下。

## 設定檔

這一切都儲存在 `~/.config/omarchy/shell.json` 裡，放在 `bar` 鍵底下。這是一個修剪過的版本：

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

每個元件都是五個 layout 陣列之一中的一個條目，而它的設定就直接寫在那個條目上——沒有另外的設定檔，也沒有 `config` 子物件。時鐘的 `format`、`formatAlt`（右鍵會循環切換到的東西）和 `verticalFormat` 全都直接住在 `{ "id": "omarchy.clock" }` 上。

`center` 是這條列正中間的盒子：裡面的一切都以一組的形式置中在螢幕上。`centerBegin` 和 `centerEnd` 掛在這個盒子的兩側，這就是為什麼即使天氣和更新徽章來來去去，時鐘都還能保持正中央。把不只一個元件放進 `center`，它們會一起置中；把它留空，`centerBegin` 和 `centerEnd` 就會在列的中間相遇。

有一條值得內化的規則：**一旦你有了自己的 `shell.json`，它就是權威來源**。在你自訂任何東西之前，shell 會讀取 Omarchy 的預設檔案。你一拖曳一個元件、執行 `omarchy bar`，或自己編輯這個檔案，你就擁有它了——沒有深層合併，所以未來 Omarchy 版本中的新預設元件不會自動出現在你的列上。`omarchy bar defaults` 能在你想要一張乾淨的白紙時，隨時把出廠的配置放回去。

同一個檔案也會在頂層保存你的閒置計時，在 `bar` 鍵之外：`idle.screensaver` 和 `idle.lock`，兩者都是從你閒置開始算的秒數。所以預設的螢幕保護程式會在 150 秒時啟動，而鎖定會在 300 秒時啟動。
