# 頂部列

螢幕頂部那條就是 Omarchy 列。它不是外加的狀態列，而是 Omarchy shell 的一部分，也就是那個長時間執行的單一 Quickshell 程序，它同時也負責繪製選單、通知、OSD 彈出視窗和鎖定畫面。這就是為什麼它能和其它一切完美配合主題，也是為什麼面板能立即開啟，而不用再啟動一個新的應用程式。

它也是桌面上唯一永遠顯示在螢幕上的部分，所以值得弄清楚那些小圖示到底能做什麼。

## 預設有哪些東西

頂部列分為三個區段。左側是 Omarchy 標誌（選單啟動器）和工作區指示器。中央有狀態指示器、時鐘、Elsewhen（世界時鐘）、天氣，以及 Omarchy 更新徽章。右側則有：系統匣、鍵盤配置（設定了多於一種配置時才會顯示）、agents、bluetooth、network、audio、display 和 power。

其中有幾項只在有話要說時才會出現。鍵盤配置只在你設定了多於一種配置時才會出現。更新徽章只在有 Omarchy 更新等待安裝時才會出現。而 agents 圖示則會在 Omarchy 第一次在這台機器上發現 AI 程式開發使用量時出現（參見 [AI](17-ai.md)）。

幾乎每個小工具在左鍵、右鍵和中鍵點按時都有作用，有幾個還會回應捲動。這是大家最容易錯過的部分，很多好東西都藏在右鍵和中鍵裡。

## 面板

點按頂部列圖示會開啟面板，那是一個正規的彈出視窗，有滑桿、清單和鍵盤導覽，而不是一個小提示框。每個面板也都有快捷鍵，所以你永遠不用去瞄準一個 16 像素的小圖示：

| 快捷鍵 | 面板 |
| --- | --- |
| `Super + Ctrl + A` | 音訊 |
| `Super + Ctrl + N` | 網路 |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | 顯示 |
| `Super + Ctrl + P` | 電源 |
| `Super + Ctrl + Alt + D` | 行事曆 |
| `Super + Ctrl + Alt + E` | 世界時鐘 |
| `Super + Ctrl + 1-9` | 切換右側區段中的第 n 個面板 |

面板不是只能看的資訊顯示。它們是真的讓你動手做事的地方：

- **音訊**有主音量滑桿、輸出裝置選擇器，以及各應用程式獨立的混音器，所以你可以只把那一個瀏覽器分頁的音量調低，而不影響其它任何東西。
- **網路**會掃描 Wi-Fi、顯示訊號強度、進行連線，並讓你選擇 DNS 服務提供者。
- **Bluetooth**會列出你的裝置，並提供連線／中斷連線和電池電量。
- **電源**會顯示電池統計資料、切換電源設定檔（它會分別記住電池和 AC 時的選擇），並列出一些系統資訊。
- **顯示**有亮度滑桿、文字大小、顯示器縮放預設值，而且當你有多於一個螢幕時，還有各顯示器獨立的控制項。更深入的說明請參見[顯示器](33-monitors.md)。
- **時鐘**會開啟一個帶有 ISO 週數、可切換月份的月曆格。
- **世界時鐘**每個城市佔一列，附有當地天氣以及當地一天進行到哪裡。搜尋可以找到城鎮，也可以找到時區，所以 Fort Lauderdale 就是 Fort Lauderdale，而不是 New York。如果頂部那行顯示的城市不對，點它並告訴它你在哪裡；選一個在另一個時區的地方，系統時鐘也會一起移過去，旅行時非常方便。將滑鼠停在一個城市上，點按人物按鈕來說明誰住在那裡，可以用一般名字，或用 `@` GitHub 帳號把他們的大頭貼一起帶進來。

每個面板除了滑鼠之外也都支援鍵盤：方向鍵可以移動，Return 可以啟用，Tab 可以跳到相鄰的面板，Escape 可以關閉。

`Super + Ctrl + 1-9` 會從左到右計算右側區段中的面板，並略過系統匣，因為它沒有自己的面板。所以數字會和你會指著的那個圖示相符。

### Tailscale 和 Dropbox

還有兩個小工具，只在你從 **Install → Service** 安裝了對應的服務後才會出現在頂部列上，而且兩者都值得認識，因為它們不只是回報狀態。

**Tailscale** 面板可以連線和中斷 tailnet、在帳號之間切換，並選擇 exit node（你自己的機器和 Mullvad 區域都會出現在那個清單中）。它也能瀏覽你的機器，選取其中一台後，按 `s` 就能透過 Taildrop 將檔案傳送給它，這是把檔案移到你的手機或另一台筆記型電腦最快的方法。`c` 會複製該機器的 IP，`n` 會複製其名稱，`d` 會複製其完整 DNS 名稱。每個機器列上也有一個傳送按鈕，如果你比較想用點按的話。從終端機做同樣的事是 `omarchy tailscale send <machine> [file...]`。

**Dropbox** 面板可以處理登入、顯示你已用了多少儲存空間，並列出最近同步的檔案。

移除任一服務都會把其小工具從頂部列上撤下。

## 指示器

中央那一小群就是指示器小工具。這些是代表你已開啟的模式的狀態圖示：勿擾、夜間模式、排隊中的[提醒](09-reminders.md)、正在進行的螢幕錄影、保持清醒，以及[聽寫](11-text-extraction-dictation.md)。它們在模式啟用時會亮起，其餘時間不會妨礙你，將滑鼠停在它們旁邊、也就是未啟用的指示器所在的位置，就可以偷看那些指示器。點按指示器可以切換該模式。還有一個只是狀態顯示：當有人透過 gliff 連線到這台機器時，遠端工作階段會亮起紅色。

如果你希望它們永遠可見，可以把該小工具上的 `alwaysShow` 設定為 `true`。如果你只在意其中幾個，可以在 `items` 中列出你想要的：`["Dnd", "Reminder", "NightLight"]`。你可以有多於一個指示器小工具，所以不同的區段可以顯示不同的子集。

## 重新排列頂部列

頂部列會自己設定自己。你不用為了移動東西而去打開設定檔。

抓住中央附近頂部列上的一塊空白處，把它拖向另一個螢幕邊緣，頂部列就會移到那裡，左、右、上、下都可以，而且每個小工具都會隨之調整（垂直列會改用緊湊的純圖示形式）。點按並按住也能開始同樣的拖曳。在同一塊空白處按兩下左鍵，可以將頂部列背景從透明切換為玻璃質感再切換為不透明。而拖曳任何小工具就能重新排序，或把它丟到另一個區段；其它小工具會滑開，為它即將落下的位置騰出空間。

頂部列的中央是一個方框：裡面的東西會作為一個群組保持置中，它兩側的小工具則掛在它的邊緣上。當你拖曳小工具時，這個方框會以輪廓顯示，空白時則會顯示為橫跨頂部列的一條線，你可以把它放進方框裡或放在它旁邊。當放下的位置會落在方框中時，方框會擴大以容納該小工具。

你想保留但不想讓它一直露在外面的小工具，可以放進系統匣的抽屜裡：把它拖到系統匣上，抽屜就會打開並接住它。它會待在那裡，排在應用程式圖示之後，每當抽屜出現時它也會出現，而且在其面板開啟期間，它會讓抽屜保持開啟。把它拖回頂部列上就能把它放回去。

如果你比較想從選單中選擇，**Appearance → Menu Bar** 裡有位置設定，而 **Bar Background** 則可以選擇頂部列的繪製方式：**Opaque Bar**、**Glassy Bar**（半透明，背後的內容會被模糊），或 **Clear Bar**。

同樣的事情也有指令可用，這正是你在設定 [dotfiles](31-dotfiles.md) 時會想要的方式：

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

要完整新增或移除一個小工具，請使用 plugin 指令。`omarchy plugin list` 會列出 shell 所知道的每個小工具及其 id，然後：

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## 隱藏頂部列

`Super + Shift + Space` 可以在不結束 shell 的情況下關閉和重新開啟頂部列，面板和快捷鍵仍可使用，你只是把像素拿回來了。它也在選單的 **Appearance → Menu Bar → Hide Bar** 裡。

## 設定檔

這一切都儲存在 `~/.config/omarchy/shell.json` 裡，位於 `bar` 鍵之下。這是精簡後的版本：

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

每個小工具都是五個 layout 陣列其中之一的一個項目，其設定就直接寫在該項目上，沒有獨立的設定檔，也沒有 `config` 子物件。時鐘的 `format`、`formatAlt`（右鍵會切換到的格式）和 `verticalFormat` 全都直接寫在 `{ "id": "omarchy.clock" }` 上。

`center` 是頂部列中央的那個方框：裡面的每一樣東西都會作為一個群組在螢幕上置中。`centerBegin` 和 `centerEnd` 則掛在方框的兩側，這就是為什麼即使天氣和更新徽章來來去去，時鐘依然能保持在正中央。在 `center` 中放多於一個小工具，它們會一起置中；讓它保持空白，`centerBegin` 和 `centerEnd` 就會在頂部列中央相遇。

有一條規則值得記牢：**一旦你有了自己的 `shell.json`，就以它為準**。在你自訂任何東西之前，shell 會讀取 Omarchy 的預設檔案。一旦你拖曳了小工具、執行了 `omarchy bar`，或自己編輯了檔案，它就是你的了，不會有深層合併，所以未來 Omarchy 版本中的新預設小工具不會自動出現在你的頂部列上。只要你想要一張乾淨的白紙，`omarchy bar defaults` 隨時都能把出廠版面恢復回來。

同一個檔案的最上層、`bar` 鍵之外，也保存了你的閒置計時：`idle.screensaver` 和 `idle.lock`，兩者都是從你開始閒置起算的秒數。所以預設情況下，螢幕保護程式會在 150 秒時啟動，鎖定則在 300 秒時啟動。
