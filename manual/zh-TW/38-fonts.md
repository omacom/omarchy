# 字體

Omarchy 預設使用 JetBrainsMono Nerd Font 作為終端機與系統字體。

 ![fonts-jetbrainsmono](images/fonts-jetbrainsmono.webp)

你可以透過 Omarchy 選單（`Super + Space`）中的 _外觀 > 字體_ 選單變更這項設定。這會在各處設定等寬字體：終端機、狀態列，以及任何其他需要等寬字體的地方。

你可以透過 Omarchy 選單中的 _安裝 > 風格 > 字體_ 安裝其他熱門的程式設計字體：Cascadia Mono、Meslo LG Mono、Fira Code、Victor Code、Bitstream Vera Mono 與 Iosevka 都只需點一下即可安裝，且皆為 Nerd Font 版本，因此狀態列與終端機中的圖示符號能繼續正常運作。安裝其中一款後，請在 _外觀 > 字體_ 下選取它。

## 中文、日文與韓文

中文、日文與韓文共用許多漢字，但其中一些字的寫法不同，因此同一個字在某位讀者眼中看起來恰當，在另一位讀者眼中卻很陌生。在 _設定 > 地區 > 語言_ 下選取其中一種語言，或選取其輸入法，即會設定相符的字形。若要自行選擇，請在終端機中執行 `omarchy font cjk jp`、`kr`、`sc`、`tc`（臺灣）或 `hk`（香港）；`omarchy font cjk default` 則會回到系統的選擇，也就是日文字形。網頁或文件以自身語言標示的文字，以及整個桌面處於這些語言之一時，都會保留該語言的字形。
