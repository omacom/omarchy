# 快捷鍵

你可以用 `Super + K` 查看所有主要鍵盤綁定（Tmux 綁定用 `Super + Alt + K`，Herdr 綁定用 `Super + Ctrl + K`）。

## 導覽

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy 選單（應用程式與其他所有功能）    |
| `Super + Alt + Space` | 應用程式網格 |
| `Super + Escape` | 系統選單（暫停、重新啟動等）  |
| `Super + Ctrl + L` | 鎖定電腦 |

| `Alt + Shift + Tab` | 在目前工作區的視窗間向後循環切換 |

| `Ctrl + Alt + Shift + Tab`| 在顯示器間向後循環切換焦點 |

## 通用剪貼簿

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + C`           | 複製    |
| `Super + X`           | 剪下（終端機中不適用）    |
| `Super + V`           | 貼上    |
| `Super + Ctrl + V`           | 剪貼簿管理器    |

通常在 Linux 上，你在終端機中需要用 `Ctrl + Shift + C/V` 來複製貼上，在其他地方則用 `Ctrl + C/V`。這些 Omarchy 統一剪貼簿快捷鍵到處都能用。

## 擷取

| Hotkey              | Function                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | 截圖                      |
| `Super + Ctrl + Alt + C`            | 截圖（相同功能，適用於沒有 Print Screen 鍵的鍵盤） |
| `Super + Ctrl + C` | 擷取選單 |
| `Alt + Print Screen`            | 螢幕錄影                     |
| `Super + Print Screen` | 色彩選取器 |
| `Super + Ctrl + Print Screen` | 將文字擷取至剪貼簿 |
| `Super + Alt + [` | 錄影時縮小網路攝影機覆蓋畫面 |
| `Super + Alt + ]` | 錄影時放大網路攝影機覆蓋畫面 |
| `Alt + Shift + L` | 從 webapp 或 Chromium 複製目前 URL |
| `Alt + Shift + D` | 將目前頁面上的影片下載至 `~/Videos` |
| `Super + Ctrl + X` | 開始/停止聽寫（需要 _Setup > Defaults > Dictation_） |
| `Right Alt` / `F9` | 按住說話聽寫（需要 Voxtype 或 Superwhisper） |

進行螢幕錄影時，第一次按下快捷鍵會先詢問你要使用哪種音訊，然後開始錄影。再按一次即可停止。詳情請參閱[截圖與錄影](12-screenshots-recording.md)。

所有擷取選項也可以在 Omarchy 選單（`Super + Space`）的 _Trigger > Capture_ 下存取。

## Tmux

前綴鍵是 `Ctrl + Space`（`Ctrl + B` 也可使用）。你可以在 `~/.config/tmux/tmux.conf` 中變更這些綁定。

### 窗格

| ----------------------- | --------------------- |
| `Prefix + v` | 在旁邊分割窗格（垂直） |

| `Prefix + x` | 終止窗格 |
| `Prefix + z` | 切換窗格縮放（全螢幕） |
| `Alt + Enter` | 在下方分割窗格（無需前綴） |
| `Alt + Shift + Enter` | 在旁邊分割窗格（無需前綴） |
| `Alt + Escape` | 終止窗格（無需前綴） |

### Tmux 版面配置函式

這些函式必須在 Tmux 工作階段內執行。

| Command | Function |
| ------- | -------- |
