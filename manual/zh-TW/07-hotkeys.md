# 快速鍵

你可以使用 `Super + K` 查看所有主要鍵盤綁定（Tmux 綁定使用 `Super + Alt + K`，Herdr 綁定使用 `Super + Ctrl + K`）。

## 通用剪貼簿

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + C`           | 複製    |
| `Super + X`           | 剪下（在終端機中不適用）    |
| `Super + V`           | 貼上    |
| `Super + Ctrl + V`           | 剪貼簿管理員    |

在 Linux 上，通常你需要在終端機中使用 `Ctrl + Shift + C/V` 來複製貼上，在其他所有地方則使用 `Ctrl + C/V`。這些 Omarchy 統一剪貼簿快速鍵在所有地方都能使用。

| Hotkey              | Function                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | 螢幕截圖                      |
| `Super + Ctrl + Alt + C`            | 螢幕截圖（相同的截圖，適用於沒有 Print Screen 鍵的鍵盤） |

所有擷取選項也可以在 Omarchy 選單（`Super + Space`）的 _Trigger > Capture_ 下存取。

## Tmux

前置鍵是 `Ctrl + Space`（`Ctrl + B` 也可以）。你可以在 `~/.config/tmux/tmux.conf` 中變更這些綁定。

### 窗格

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + v` | 在旁邊分割窗格（垂直） |
| `Prefix + h` | 在下方分割窗格（水平） |
| `Prefix + x` | 關閉窗格 |
| `Prefix + z` | 切換窗格縮放（全螢幕） |
| `Alt + Enter` | 在下方分割窗格（無需前置鍵） |
| `Alt + Shift + Enter` | 在旁邊分割窗格（無需前置鍵） |
| `Alt + Escape` | 關閉窗格（無需前置鍵） |
| `Ctrl + Alt + Arrows` | 在窗格之間移動 |
| `Ctrl + Alt + Shift + Arrows` | 調整窗格大小 |
