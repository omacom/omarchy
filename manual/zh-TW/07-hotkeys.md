# 快捷鍵

你可以用 `Super + K` 查看所有主要鍵盤綁定（Tmux 綁定用 `Super + Alt + K`，Herdr 綁定用 `Super + Ctrl + K`）。

## 導覽

| 快捷鍵                  | 功能              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy 選單（應用程式與其他所有功能）    |
| `Super + Alt + Space` | 應用程式格狀清單 |
| `Super + Escape` | 系統選單（暫停、重新啟動等）  |
| `Super + Ctrl + L` | 鎖定電腦 |
| `Super + W` or `Super + Q` | 關閉視窗             |
| `Ctrl + Alt + Del` | 關閉所有視窗 |
| `Super + T`               | 在平鋪/浮動之間切換視窗             |
| `Super + J` | 切換視窗位置（水平/垂直） |
| `Super + O`               | 切換將視窗彈出為粘置浮動 |
| `Super + L`               | 在 dwindle、scrolling 與浮動版面之間循環切換 |
| `Super + Alt + L`         | 以反方向在版面之間循環切換 |
| `Super + P`               | 切換偽視窗樣式（自然 v 拉伸） |
| `Super + F`                 | 進入全螢幕              |
| `Super + Alt + F`                 | 進入全寬              |
| `Super + Ctrl + F`                 | 在視窗內進入全螢幕              |
| `Super + 1/2/3/4`         | 跳至目前焦點螢幕上的指定工作區 |
| `Super + Tab` | 跳至目前焦點螢幕上的下一個工作區 |
| `Super + Shift + Tab` | 跳至目前焦點螢幕上的上一個工作區 |
| `Super + Ctrl + Tab` | 跳至目前焦點螢幕上的前一個工作區 |
| `Super + Shift + 1/2/3/4` | 將視窗移到目前焦點螢幕上的工作區 |
| `Super + Shift + Alt + 1/2/3/4` | 將視窗移到目前焦點螢幕上的工作區，但不跟隨過去 |
| `Super + S` | 切換完整 scratchpad |
| `Super + Alt + S` | 將視窗移到完整 scratchpad |
| `Super + Grave` | 切換 Quake 主控台 |
| `Super + Shift + Grave` | 將視窗移到 Quake 主控台 |
| `Super + Shift + Ctrl + Arrows` | 將視窗移到該方向的螢幕 |
| `Super + Shift + Alt + Arrows` | 將工作區移到該方向的螢幕 |
| `Super + Arrow`  | 將焦點移到箭頭方向的視窗，到了螢幕邊緣時會跨到該側的螢幕 |
| `Super + Shift + Arrow`  | 將視窗與箭頭方向的另一個視窗交換，包括該側螢幕上的視窗 |
| `Super + Minus` | 向左擴大視窗 |
| `Super + Equal` | 向左縮小視窗 |
| `Super + Shift + Minus` | 向上縮小視窗 |
| `Super + Shift + Equal` | 向下擴大視窗 |
| `Super + Alt + Minus/Equal` | 以較小幅度進行相同的調整大小 |
| `Super + Ctrl + Minus/Equal` | 以較大幅度進行相同的調整大小 |
| `Super + Alt + Home` | 儲存視窗寬度 |
| `Super + Home` | 還原已儲存的視窗寬度 |
| `Super + Left Mouse` | 拖曳視窗 |
| `Super + Right Mouse` | 調整視窗大小 |
| `Super + Scroll Wheel` | 在目前焦點螢幕上的工作區之間捲動切換 |
| `Super + G`               | 切換視窗群組      |
| `Super + Alt + G`               | 將視窗移出群組      |
| `Super + Alt + Tab`               | 在群組內的視窗之間循環切換      |
| `Super + Alt + Shift + Tab`               | 在群組內的視窗之間反向循環切換      |
| `Super + Alt + Scroll Wheel` | 在群組內的視窗之間循環切換 |
| `Super + Alt + 1/2/3/4/5`               | 跳至群組內的指定視窗      |
| `Super + Alt + Arrow`  | 將視窗依箭頭方向移入群組，包括該側螢幕上的視窗 |
| `Super + Ctrl + Left/Right`  | 在平鋪群組內的視窗之間移動 |
| `Super + Ctrl + Z` | 放大畫面（重複按下可繼續放大） |
| `Super + Ctrl + Alt + Z` | 從畫面完全縮小 |
| `Super + /` | 向前逐一切換螢幕縮放選項 |
| `Super + Alt + /` | 向後逐一切換螢幕縮放選項 |
| `Alt + Tab` | 在目前工作區的視窗之間向前循環切換 |
| `Alt + Shift + Tab` | 在目前工作區的視窗之間向後循環切換 |
| `Ctrl + Alt + Tab`| 在螢幕之間向前循環切換焦點 |
| `Ctrl + Alt + Shift + Tab`| 在螢幕之間向後循環切換焦點 |

## 通用剪貼簿

| 快捷鍵                  | 功能              |
| ----------------------- | --------------------- |
| `Super + C`           | 複製    |
| `Super + X`           | 剪下（在終端機中除外）    |
| `Super + V`           | 貼上    |
| `Super + Ctrl + V`           | 剪貼簿管理員    |

通常在 Linux 上，你在終端機中需要用 `Ctrl + Shift + C/V` 來複製貼上，在其他地方則用 `Ctrl + C/V`。這些 Omarchy 統一剪貼簿快捷鍵到處都能用。

## 擷取

| 快捷鍵              | 功能                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | 截圖                      |
| `Super + Ctrl + Alt + C`            | 截圖（同樣的截圖，用於沒有 Print Screen 鍵的鍵盤） |
| `Super + Ctrl + C` | 擷取選單 |
| `Alt + Print Screen`            | 螢幕錄影                     |
| `Super + Print Screen` | 取色器 |
| `Super + Ctrl + Print Screen` | 將文字擷取至剪貼簿 |
| `Super + Alt + [` | 錄影時縮小 webcam 疊加畫面 |
| `Super + Alt + ]` | 錄影時放大 webcam 疊加畫面 |
| `Alt + Shift + L` | 從 webapp 或 Chromium 複製目前 URL |
| `Alt + Shift + D` | 將目前頁面上的影片下載到 `~/Videos` |
| `Super + Ctrl + X` | 開始/停止聽寫（需要 _Setup > Defaults > Dictation_） |
| `Right Alt` / `F9` | 按住說話聽寫（需要 Voxtype 或 Superwhisper） |

進行螢幕錄影時，快捷鍵會先詢問你要哪種音訊，然後才開始錄影。再按一次即可停止。詳情請見[截圖與錄影](12-screenshots-recording.md)。

所有擷取選項也可以從 Omarchy 選單（`Super + Space`）的 _Trigger > Capture_ 存取。

## Tmux

前綴鍵是 `Ctrl + Space`（`Ctrl + B` 也可以）。你可以在 `~/.config/tmux/tmux.conf` 中變更這些綁定。

### 窗格

| 快捷鍵                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + v` | 在旁邊分割窗格（垂直） |
| `Prefix + h` | 在下方分割窗格（水平） |
| `Prefix + x` | 終止窗格 |
| `Prefix + z` | 切換窗格縮放（全螢幕） |
| `Alt + Enter` | 在下方分割窗格（無需前綴） |
| `Alt + Shift + Enter` | 在旁邊分割窗格（無需前綴） |
| `Alt + Escape` | 終止窗格（無需前綴） |
| `Ctrl + Alt + Arrows` | 在窗格之間移動 |
| `Ctrl + Alt + Shift + Arrows` | 調整窗格大小 |

### 視窗

| 快捷鍵                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + c` | 新視窗 |
| `Prefix + k` | 終止視窗 |
| `Prefix + r` | 重新命名視窗 |
| `Alt + 1-9` | 前往指定視窗 |
| `Alt + Arrow Left/Right` | 在視窗之間移動 |
| `Alt + Shift + Arrow Left/Right` | 將視窗向左/向右移動 |

### 工作階段

| 快捷鍵                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + C` | 新工作階段 |
| `Prefix + K` | 終止工作階段 |
| `Prefix + R` | 重新命名工作階段 |
| `Prefix + N` | 下一個工作階段 |
| `Prefix + P` | 上一個工作階段 |
| `Alt + Arrow Up/Down` | 在工作階段之間移動 |
| `Prefix + s` | 列出工作階段 |
| `Prefix + d` | 從工作階段分離 |

### 複製模式（vi 風格）

| 快捷鍵                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + [` | 進入複製模式 |
| `v` | 開始選取（在複製模式中） |
| `y` | 複製選取內容（在複製模式中） |

### 一般

| 快捷鍵                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + q` | 重新載入設定 |
| `Prefix + ?` | 顯示 Tmux 鍵盤綁定 |
| `Prefix + :` | 指令提示 |

### Tmux 版面函式

這些函式必須在 Tmux 工作階段內執行。

| 指令 | 功能 |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | 建立包含編輯器、AI 與終端機的開發版面 |
| `tdlm <ai> [<second_ai>]` | 依每個子目錄建立開發版面 |
| `tsl <count> <command>` | 建立多窗格 swarm 版面 |
