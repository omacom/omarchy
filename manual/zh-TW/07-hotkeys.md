# 快捷鍵

你可以使用 `Super + K` 查看所有主要鍵盤綁定（Tmux 綁定使用 `Super + Alt + K`，Herdr 綁定使用 `Super + Ctrl + K`）。

## 導覽

| Hotkey                  | 功能              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy 選單（應用程式與其他所有功能）    |
| `Super + Alt + Space` | 應用程式格狀檢視 |
| `Super + Escape` | 系統選單（暫停、重新啟動等）  |
| `Super + Ctrl + L` | 鎖定電腦 |
| `Super + W` or `Super + Q` | 關閉視窗             |
| `Ctrl + Alt + Del` | 關閉所有視窗 |
| `Super + T`               | 在平鋪／浮動之間切換視窗             |
| `Super + J` | 切換視窗位置（水平／垂直） |
| `Super + O`               | 切換將視窗彈出為 sticky'n'floating |
| `Super + L`               | 在 dwindle、scrolling 與 floating 版面配置之間循環切換 |
| `Super + Alt + L`         | 以反向順序在版面配置之間循環切換 |
| `Super + P`               | 切換偽視窗樣式（natural 對 stretch） |

| `Super + Ctrl + F`                 | 在視窗內進入全螢幕              |

| `Super + Tab` | 跳至目前焦點顯示器上的下一個工作區 |

| `Super + Arrow`  | 將焦點移到箭頭方向的視窗，在螢幕邊緣時跨到該側的顯示器 |

| `Super + Shift + Equal` | 向下擴展視窗 |
| `Super + Alt + Minus/Equal` | 以較小幅度進行相同縮放 |
| `Super + Ctrl + Minus/Equal` | 以較大幅度進行相同縮放 |
| `Super + Alt + Home` | 儲存視窗寬度 |
| `Super + Home` | 還原已儲存的視窗寬度 |
| `Super + Left Mouse` | 拖曳視窗 |
| `Super + Right Mouse` | 調整視窗大小 |
| `Super + Scroll Wheel` | 捲動切換目前焦點顯示器上的工作區 |
| `Super + G`               | 切換視窗分組      |
| `Super + Alt + G`               | 將視窗移出分組      |
| `Super + Alt + Tab`               | 在分組內的視窗之間循環切換      |
| `Super + Alt + Shift + Tab`               | 在分組內的視窗之間反向循環切換      |
| `Super + Alt + Scroll Wheel` | 在分組內的視窗之間循環切換 |

| `Super + Ctrl + Z` | 放大螢幕（重複操作可進一步放大） |
| `Super + Ctrl + Alt + Z` | 完全縮小螢幕 |
| `Super + /` | 向前逐步切換顯示器縮放選項 |
| `Super + Alt + /` | 向後逐步切換顯示器縮放選項 |
| `Alt + Tab` | 在目前工作區的視窗之間向前循環切換 |
| `Alt + Shift + Tab` | 在目前工作區的視窗之間向後循環切換 |
| `Ctrl + Alt + Tab`| 在顯示器之間向前循環切換焦點 |
| `Ctrl + Alt + Shift + Tab`| 在顯示器之間向後循環切換焦點 |

## 通用剪貼簿

| Hotkey                  | 功能              |
| ----------------------- | --------------------- |
| `Super + C`           | 複製    |
| `Super + X`           | 剪下（終端機中不適用）    |
| `Super + V`           | 貼上    |
| `Super + Ctrl + V`           | 剪貼簿管理員    |

在 Linux 上，通常你需要在終端機中使用 `Ctrl + Shift + C/V` 才能複製貼上，在其他地方則使用 `Ctrl + C/V`。這些 Omarchy 統一剪貼簿快捷鍵在任何地方都能使用。

## 擷取

| Hotkey              | 功能                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | 截圖                      |
| `Super + Ctrl + Alt + C`            | 截圖（相同的截圖，適用於沒有 Print Screen 鍵的鍵盤） |
| `Super + Ctrl + C` | 擷取選單 |
| `Alt + Print Screen`            | 螢幕錄影                     |
| `Super + Print Screen` | 顏色選取器 |
| `Super + Ctrl + Print Screen` | 將文字擷取至剪貼簿 |
| `Super + Alt + [` | 錄影時縮小 webcam 浮動畫面 |

| `Alt + Shift + L` | 從 webapp 或 Chromium 複製目前 URL |
| `Alt + Shift + D` | 將目前頁面上的影片下載到 `~/Videos` |
| `Super + Ctrl + X` | 開始／停止聽寫（需要 _Setup > Defaults > Dictation_） |

進行螢幕錄影時，快捷鍵會先詢問你想要哪種音訊，然後開始錄影。再按一次即可停止。詳情請參閱[截圖與錄影](12-screenshots-recording.md)。

所有擷取選項也可以在 Omarchy 選單（`Super + Space`）的 _Trigger > Capture_ 下存取。

## Tmux

前綴鍵是 `Ctrl + Space`（`Ctrl + B` 也可以使用）。你可以在 `~/.config/tmux/tmux.conf` 中變更這些綁定。

### 窗格

| Hotkey                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + v` | 在旁邊分割窗格（垂直） |
| `Prefix + h` | 在下方分割窗格（水平） |
| `Prefix + x` | 關閉窗格 |
| `Prefix + z` | 切換窗格縮放（全螢幕） |
| `Alt + Enter` | 在下方分割窗格（無需前綴） |
| `Alt + Shift + Enter` | 在旁邊分割窗格（無需前綴） |
| `Alt + Escape` | 關閉窗格（無需前綴） |
| `Ctrl + Alt + Arrows` | 在窗格之間移動 |
| `Ctrl + Alt + Shift + Arrows` | 調整窗格大小 |

### 視窗

| Hotkey                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + c` | 新增視窗 |
| `Prefix + k` | 關閉視窗 |
| `Prefix + r` | 重新命名視窗 |
| `Alt + 1-9` | 前往指定視窗 |
| `Alt + Arrow Left/Right` | 在視窗之間移動 |
| `Alt + Shift + Arrow Left/Right` | 將視窗向左／向右移動 |

### 工作階段

| Hotkey                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + C` | 新增工作階段 |
| `Prefix + K` | 關閉工作階段 |
| `Prefix + R` | 重新命名工作階段 |

| `Alt + Arrow Up/Down` | 在工作階段之間移動 |
| `Prefix + s` | 列出工作階段 |

### 複製模式（vi 風格）

| Hotkey                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + [` | 進入複製模式 |
| `v` | 開始選取（在複製模式中） |

### 一般

| Hotkey                  | 功能              |
| ----------------------- | --------------------- |

| `Prefix + ?` | 顯示 Tmux 鍵盤綁定 |

### Tmux 版面配置函式

這些函式必須在 Tmux 工作階段內執行。

| Command | 功能 |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | 以編輯器、AI 與終端機建立開發版面配置 |
| `tdlm <ai> [<second_ai>]` | 為每個子目錄建立開發版面配置 |
| `tsl <count> <command>` | 建立多窗格 swarm 版面配置 |
