# 快捷鍵

你可以用 `Super + K` 查看所有主要鍵盤綁定（Tmux 綁定用 `Super + Alt + K`，Herdr 綁定用 `Super + Ctrl + K`）。

| `Alt + Shift + Tab` | 在目前工作區的視窗之間向後循環切換 |

| `Ctrl + Alt + Shift + Tab`| 在螢幕之間向後循環切換焦點 |

調整大小的快捷鍵使用實體按鍵 `code:20` 與 `code:21`（XKB `<AE11>` 與 `<AE12>`），不論鍵盤上印的是什麼字元。在美式鍵盤上，這些鍵是 `-` 與 `=`；在日式（JIS）鍵盤上是 `-` 與 `^`；在西班牙文鍵盤上是 `'` 與 `¡`。在 JIS 上，`Super + ^` 即 `Super + Equal`，而 `Super + Shift + -`（會打出 `=`）即 `Super + Shift + Minus`。
