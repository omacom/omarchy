# 快捷鍵

你可以用 `Super + K` 查看所有主要的鍵盤綁定（用 `Super + Alt + K` 查看 Tmux 綁定，用 `Super + Ctrl + K` 查看 Herdr 綁定）。

## 導覽

| 快捷鍵                  | 功能              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy 選單（應用程式及其他一切）    |
| `Super + Alt + Space` | 應用程式格子 |
| `Super + Escape` | 系統選單（睡眠、重新啟動等）  |
| `Super + Ctrl + L` | 鎖定電腦 |
| `Super + W` or `Super + Q` | 關閉視窗             |
| `Ctrl + Alt + Del` | 關閉所有視窗 |
| `Super + T`               | 在平鋪/浮動之間切換視窗             |
| `Super + J` | 切換視窗位置（水平/垂直） |
| `Super + O`               | 將視窗切換為置頂浮動 |
| `Super + L`               | 在 dwindle、捲動和浮動配置之間循環 |
| `Super + Alt + L`         | 以相反方向循環配置 |
| `Super + P`               | 切換偽視窗樣式（自然與拉伸） |
| `Super + F`                 | 進入全螢幕              |
| `Super + Alt + F`                 | 進入全寬              |
| `Super + Ctrl + F`                 | 在視窗內全螢幕              |
| `Super + 1/2/3/4`         | 跳至指定的工作區     |
| `Super + Tab` | 跳至下一個工作區 |
| `Super + Shift + Tab` | 跳至上一個工作區 |
| `Super + Ctrl + Tab` | 跳至先前的工作區 |
| `Super + Shift + 1/2/3/4` | 將視窗移至工作區 |
| `Super + Shift + Alt + 1/2/3/4` | 將視窗移至工作區但不跟隨 |
| `Super + S` / `Super + Grave` | 切換暫存區 |
| `Super + Alt + S` / `Super + Shift + Grave` | 將視窗移至暫存區 |
| `Super + Shift + Alt + Arrows` | 將工作區移至指定方向的顯示器 |
| `Super + Arrow`  | 將焦點移至箭頭方向的視窗              |
| `Super + Shift + Arrow`  | 與箭頭方向的另一視窗交換位置     |
| `Super + Minus` | 向左擴展視窗 |
| `Super + Equal` | 向左縮小視窗 |
| `Super + Shift + Minus` | 向上縮小視窗 |
| `Super + Shift + Equal` | 向下擴展視窗 |
| `Super + Alt + Minus/Equal` | 以較小步階進行相同大小調整 |
| `Super + Ctrl + Minus/Equal` | 以較大步階進行相同大小調整 |
| `Super + Alt + Home` | 儲存視窗寬度 |
| `Super + Home` | 還原已儲存的視窗寬度 |
| `Super + Left Mouse` | 四處拖曳視窗 |
| `Super + Right Mouse` | 調整視窗大小 |
| `Super + Scroll Wheel` | 捲動瀏覽工作區 |
| `Super + G`               | 切換視窗分組      |
| `Super + Alt + G`               | 將視窗移出分組      |
| `Super + Alt + Tab`               | 在分組中的視窗之間循環      |
| `Super + Alt + Shift + Tab`               | 在分組中的視窗之間向後循環      |
| `Super + Alt + 1/2/3/4/5`               | 跳至分組中的指定視窗      |
| `Super + Alt + Arrow`  | 將視窗沿箭頭方向移入分組  |
| `Super + Ctrl + Left/Right`  | 在平鋪群組內的視窗之間移動 |
| `Super + Ctrl + Z` | 放大螢幕（重複按鍵可進一步放大） |
| `Super + Ctrl + Alt + Z` | 從螢幕完全縮小 |
| `Super + /` | 向前步進顯示器縮放選項 |
| `Super + Alt + /` | 向後步進顯示器縮放選項 |
| `Alt + Tab` | 在目前工作區的視窗之間向前循環 |
| `Alt + Shift + Tab` | 在目前工作區的視窗之間向後循環 |
| `Ctrl + Alt + Tab`| 在顯示器之間向前循環切換焦點 |
| `Ctrl + Alt + Shift + Tab`| 在顯示器之間向後循環切換焦點 |

## 通用剪貼簿

| 快捷鍵                  | 功能              |
| ----------------------- | --------------------- |
| `Super + C`           | 複製    |
| `Super + X`           | 剪下（不在終端機中）    |
| `Super + V`           | 貼上    |
| `Super + Ctrl + V`           | 剪貼簿管理器    |

一般在 Linux 上，你需要在終端機裡用 `Ctrl + Shift + C/V` 來複製貼上，在其他地方則用 `Ctrl + C/V`。這些 Omarchy 統一剪貼簿快捷鍵到處都能用。

## 擷取

| 快捷鍵              | 功能                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | 擷取選單（用於沒有 PrintScr 按鈕的鍵盤） |
| `Print Screen`            | 螢幕截圖                      |
| `Alt + Print Screen`            | 螢幕錄影                     |
| `Super + Print Screen` | 色彩選擇器 |
| `Super + Ctrl + Print Screen` | 將文字擷取至剪貼簿 |
| `Super + Alt + [` | 錄影時讓網路攝影機覆蓋層變小 |
| `Super + Alt + ]` | 錄影時讓網路攝影機覆蓋層變大 |
| `Alt + Shift + L` | 從網頁應用程式或 Chromium 複製目前 URL |
| `Alt + Shift + D` | 將目前頁面的影片下載至 `~/Videos` |
| `Super + Ctrl + X` | 啟動/停止聽寫（需要 _Setup > Defaults > Dictation_） |
| `Right Alt` / `F9` | 按住說話聽寫（需要 Voxtype 或 Superwhisper） |

使用螢幕錄影時，快捷鍵會先詢問你想要哪一種音訊，然後才開始錄影。再按一次即可停止。詳情見[螢幕截圖與錄影](12-screenshots-recording.md)。

所有擷取選項也可以在 Omarchy 選單（`Super + Space`）的 _Trigger > Capture_ 底下取得。

## Tmux

前綴鍵是 `Ctrl + Space`（`Ctrl + B` 也行）。你可以在 `~/.config/tmux/tmux.conf` 中變更這些綁定。

### 窗格

| 快捷鍵                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + v` | 在旁邊分割窗格（垂直） |
| `Prefix + h` | 在下方分割窗格（水平） |
| `Prefix + x` | 關閉窗格 |
| `Prefix + z` | 切換窗格縮放（全螢幕） |
| `Alt + Enter` | 在下方分割窗格（無需前綴鍵） |
| `Alt + Shift + Enter` | 在旁邊分割窗格（無需前綴鍵） |
| `Alt + Escape` | 關閉窗格（無需前綴鍵） |
| `Ctrl + Alt + Arrows` | 在窗格之間移動 |
| `Ctrl + Alt + Shift + Arrows` | 調整窗格大小 |

### 視窗

| 快捷鍵                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + c` | 新視窗 |
| `Prefix + k` | 關閉視窗 |
| `Prefix + r` | 重新命名視窗 |
| `Alt + 1-9` | 前往指定視窗 |
| `Alt + Arrow Left/Right` | 在視窗之間移動 |
| `Alt + Shift + Arrow Left/Right` | 將視窗左/右移動 |

### 工作階段

| 快捷鍵                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + C` | 新工作階段 |
| `Prefix + K` | 關閉工作階段 |
| `Prefix + R` | 重新命名工作階段 |
| `Prefix + N` | 下一個工作階段 |
| `Prefix + P` | 上一個工作階段 |
| `Alt + Arrow Up/Down` | 在工作階段之間移動 |
| `Prefix + s` | 列出工作階段 |
| `Prefix + d` | 從工作階段脫離 |

### 複製模式（vi 風格）

| 快捷鍵                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + [` | 進入複製模式 |
| `v` | 開始選取（在複製模式中） |
| `y` | 複製選取內容（在複製模式中） |

### 一般

| 快捷鍵                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + q` | 重新載入設定 |
| `Prefix + ?` | 顯示 Tmux 快捷鍵 |
| `Prefix + :` | 命令提示 |

### Tmux 配置函式

這些函式必須在 Tmux 工作階段內執行。

| 指令 | 功能 |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | 建立包含編輯器、AI 和終端機的開發配置 |
| `tdlm <ai> [<second_ai>]` | 為每個子目錄建立開發配置 |
| `tsl <count> <command>` | 建立多窗格群集配置 |
