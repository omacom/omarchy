# 快捷鍵

你可以使用 `Super + K` 查看所有主要鍵盤綁定（Tmux 綁定使用 `Super + Alt + K`，Herdr 綁定使用 `Super + Ctrl + K`）。

| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy 選單（應用程式與所有其他功能）    |
| `Super + Alt + Space` | 應用程式格狀檢視 |
| `Super + Escape` | 系統選單（暫停、重新啟動等）  |
| `Super + Ctrl + L` | 鎖定電腦 |
| `Super + W` or `Super + Q` | 關閉視窗             |
| `Ctrl + Alt + Del` | 關閉所有視窗 |
| `Super + T`               | 在平鋪／浮動之間切換視窗             |
| `Super + J` | 切換視窗位置（水平／垂直） |
| `Super + O`               | 切換將視窗彈出為置頂浮動 |
| `Super + L`               | 依序切換 dwindle、scrolling 與 floating 版面配置 |

| `Super + Tab` | 跳至目前焦點螢幕上的下一個工作區 |
| `Super + Shift + Tab` | 跳至目前焦點螢幕上的上一個工作區 |
| `Super + Ctrl + Tab` | 跳至目前焦點螢幕上的前一個工作區 |
| `Super + Shift + 1/2/3/4` | 將視窗移至目前焦點螢幕上的工作區 |

| `Super + Home` | 還原已儲存的視窗寬度 |
| `Super + Left Mouse` | 拖曳視窗 |
| `Super + Right Mouse` | 調整視窗大小 |
| `Super + Scroll Wheel` | 捲動切換目前焦點螢幕上的工作區 |
| `Super + G`               | 切換視窗群組      |
| `Super + Alt + G`               | 將視窗移出群組      |
| `Super + Alt + Tab`               | 在群組中的視窗之間依序切換      |
| `Super + Alt + Shift + Tab`               | 在群組中的視窗之間反向依序切換      |

| `Alt + Shift + Tab` | 在目前工作區的視窗之間向後依序切換 |
| `Ctrl + Alt + Tab`| 在螢幕之間向前依序切換焦點 |
| `Ctrl + Alt + Shift + Tab`| 在螢幕之間向後依序切換焦點 |

調整大小的快捷鍵使用實體按鍵 `code:20` 與 `code:21`（XKB `<AE11>` 與 `<AE12>`），與鍵盤上印製的字元無關。在美式鍵盤上，這些按鍵是 `-` 與 `=`；在日式（JIS）鍵盤上，它們是 `-` 與 `^`；在西班牙式鍵盤上，它們是 `'` 與 `¡`。在 JIS 上，`Super + ^` 就是 `Super + Equal`，而 `Super + Shift + -`（輸入 `=`）則是 `Super + Shift + Minus`。

## 通用剪貼簿

| 快捷鍵                  | 功能              |
| ----------------------- | --------------------- |
