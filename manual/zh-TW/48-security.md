# 安全性

Omarchy 非常嚴肅地看待安全性。這是一個讓你能在_真實世界_中做_真正的工作_的作業系統。在這裡，弄丟一台筆記型電腦不該演變成一場安全緊急事件。以下是我們的做法：

1. *全磁碟加密是強制性的*：這是保護你資料實體安全最重要的一步。如果你的電腦遺失或遭竊，資料會使用標準的 LUKS (Linux Unified Key Setup) 完全加密。
2. *防火牆預設啟用*：所有傳入流量預設都會被封鎖，僅開放 port 53317 供 [LocalSend](https://localsend.org/) 使用。就連 ssh 也會保持關閉，直到你透過_設定 > 安全性 > SSHD_ 將它開啟為止；啟用過程會一併開啟 port 22（並針對暴力破解進行速率限制）。我們甚至使用 [ufw-docker](https://github.com/chaifeng/ufw-docker) 設定來鎖定 Docker 存取，避免你的容器意外暴露在外。
3. *Arch 永遠擁有最新更新*：Arch 是 Omarchy 所基於的底層發行版，它是一個滾動式發行版。這表示任何套件中被發現並修補的安全漏洞，都能很快透過 `omarchy-update` 安裝。這樣一來，你永遠都在執行所有軟體的最新、最安全版本。
4. *Omarchy 維護自己的套件與鏡像站*：Omarchy 預設只依賴 Arch 自己的 core/extra/multilib 套件庫，以及它自己的 Omarchy Package Repository 提供的套件。你可以直接從 AUR 安裝軟體，但基礎安裝不會這麼做——只有少數選擇性安裝，例如第三方瀏覽器，才會從 AUR 拉取。
5. *Cloudflare 保護我們免受 DDoS 攻擊*：Omarchy 的發行基礎設施——ISO、Omarchy 套件、Arch 鏡像站——都受到 Cloudflare 強大的 DDoS 防護盾保護，並託管在他們的 CDN 上。這提供了卓越的可用性。

## 變更你的密碼

在加密安裝中，你有兩個密碼：一個是在開機時解鎖磁碟的密碼，另一個是你登入和執行 `sudo` 時使用的密碼。初始設定會將它們設為相同。兩者都可以在 Omarchy 選單的_更新 > 密碼_下變更——第一個選_磁碟加密_，第二個選_使用者_。變更磁碟密碼時會先要求你輸入目前的密碼，所以請先準備好。如果變更過程被中斷，請再次執行_磁碟加密_：它會詢問目前能解鎖磁碟的密碼，並完成變更。

## 轉交一台你已經使用過的機器

如果你要把機器交給別人，你不必重新安裝它。在 Omarchy 選單中執行_設定 > 重設電腦_，輸入 `reset` 確認，然後重新開機。這會清除每一個使用者帳號以及 `/home` 中的所有內容，丟棄你自安裝以來所做的所有套件與系統變更，並清除機器的身分識別資訊——網路連線、主機金鑰，全都一併清除。重新啟動後出現的會是初次開機時的設定精靈，準備好讓新擁有者輸入他們自己的名稱、密碼和加密密碼。

它的運作方式是還原安裝程式所拍攝的基準快照，所以只有從 Omarchy ISO 安裝的機器才能使用。而在沒有加密的磁碟上，重設只是刪除而非安全抹除，所以如果資料很敏感，請改做一次全新安裝。

## 免密碼 sudo

有時候你會希望 `sudo` 不要再一直詢問密碼，最常見的情況是 AI agent 正在為你長時間執行系統工作時。_設定 > 安全性 > 免密碼 Sudo_ 會詢問要允許存取多久：**15 分鐘**、**1 小時**、**1 天**，或**永久**。當存取啟用時，選單列的其他指示器旁邊會出現一個紅色警告圖示。點按它或再次執行該命令即可關閉存取。你也可以用 `omarchy-sudo-passwordless 30` 傳入你自己的分鐘數（從 1 到 1440），或使用 `omarchy-sudo-passwordless permanent`。

有時限的存取會自動到期，包括在跨越期限的暫停狀態恢復後立即到期。重新啟動電腦會提早結束它。永久存取在重新開機後依然有效，並會保持啟用，直到你將它停用為止。

更新或移除 Omarchy 的設定套件，會在任何暫時授權的到期支援變更之前結束該授權。如果該命令回報授權或清除錯誤，請在嘗試啟用另一個授權之前先解決它；出現錯誤並不表示免密碼存取未啟用。

對這一點要有清醒的認識：當它開啟時，任何以你的使用者身分執行的程式，都可以在不被詢問的情況下以 root 身分做任何事。這正是它的全部目的，也正是它的全部風險。

## 簽章金鑰

所有 ISO 簽章與 Omarchy 套件庫套件的公開金鑰是 `40DFB630FF42BCFFB047046CF0134EE680CAC571`（[在 openpgp.org 上驗證](https://keys.openpgp.org/search?q=pkgs%40omarchy.org)）。`omarchy/omarchy-keyring` 套件也包含這把金鑰，並將用於無縫推出任何潛在的更新。

你可以在任何 ISO 發行版的 URL 後面加上 `.sig` 來找到它的簽章，例如 `https://iso.omarchy.org/omarchy-x.x.x.iso.sig`。
