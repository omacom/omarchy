# 安全性

Omarchy 對安全性極為認真。這是一套要讓你能在_真實世界_做_真正的工作_的作業系統。在那個世界裡，弄丟一台筆電不能演變成一場安全緊急事件。以下是我們的做法：

1. *預設啟用全磁碟加密*：這是保護你的資料實體安全最重要的一步。如果你的電腦遺失或被偷，資料會使用標準的 LUKS (Linux Unified Key Setup) 完整加密。安裝程式允許你在拋棄式機器上選擇不啟用（參見[開始使用](02-getting-started.md)）；未加密的安裝完全沒有這層保護，任何拿到硬碟的人都能讀取其中的資料。
2. *預設啟用防火牆*：所有連入流量預設都會被阻擋，只有少數例外：供 [LocalSend](https://localsend.org/) 使用的連接埠 53317；傳送到電腦自身解析器、位於 Docker bridge 位址 (172.17.0.1) 的 DNS 查詢，且接受來自 Docker 分配給其容器的私人位址範圍；以及多播 DNS（連接埠 5353），讓印表機和你網路上的其他裝置能互相找到彼此，也會在此公布你電腦的名稱。除此之外，防火牆還保留了 UFW 的標準允許項目：ping、從你的路由器取得位址 (DHCP)，以及 UPnP 探索。就連 ssh 也會保持關閉，直到你透過 _Setup > Security > SSHD_ 將它開啟為止；該操作會授權你的 SSH 金鑰、關閉密碼登入，然後才開啟連接埠 22（並以速率限制防範暴力破解）。我們甚至使用 [ufw-docker](https://github.com/chaifeng/ufw-docker) 設定來鎖定 Docker 的存取，避免你的容器意外暴露在全世界面前。
3. *Arch 永遠擁有最新更新*：Arch 是 Omarchy 所建基的底層發行版，是一個滾動式發行版。這意味著，任何套件中被發現並修補的安全漏洞，都能很快透過 `omarchy-update` 取得並安裝。這樣你永遠都在執行所有軟體的最新、最安全版本。
4. *Omarchy 維護自己的套件和鏡像站*：Omarchy 預設只依賴 Arch 自己的 core/extra/multilib 套件庫（在 ARM 機器上是 Arch Linux ARM 的套件庫，在 Apple Silicon 上還加上 Asahi ALARM）以及它自己的 Omarchy Package Repository 提供的套件。你可以直接從 AUR 安裝軟體，但基礎安裝不會這麼做——只有少數選擇性安裝，例如第三方瀏覽器，才會從 AUR 拉取套件。
5. *Cloudflare 保護我們免受 DDoS 攻擊*：Omarchy 的散布基礎設施——ISO、Omarchy 套件、Arch 鏡像站——都受到 Cloudflare 強大的 DDoS 防護盾保護，並託管在他們的 CDN 上。這提供了卓越的可用性。

## 變更你的密碼

在已加密的安裝中，你有兩組密碼：一組是在開機時解鎖硬碟的密碼，另一組是你登入和執行 `sudo` 時使用的密碼。初始設定會將兩者設為相同。兩組密碼都可以在 Omarchy 選單的 _Update > Password_ 下變更——第一組選 _Drive Encryption_，第二組選 _User_。變更硬碟密碼時，會先要求輸入目前的密碼，所以請先準備好。如果變更過程被中斷，請再次執行 _Drive Encryption_：它會要求輸入目前能解鎖硬碟的密碼，並完成變更。

## 轉交一台你已經用過的機器

如果你要把機器交給別人，不必重新安裝。執行 Omarchy 選單中的 _Remove > Factory Reset_，輸入 `reset` 確認，如有要求就輸入你的硬碟加密密碼，然後重新開機。這會清除每一個使用者帳號和 `/home` 中的所有內容，捨棄你自安裝以來新增的所有套件和系統變更，並清除機器的身分識別——網路連線、主機金鑰，全都清除。重新開機後出現的是第一次開機時的設定精靈，讓新擁有者輸入他們自己的名稱、密碼和加密密碼。

它的運作方式是還原安裝程式建立的基準快照，所以只適用於從 Omarchy ISO 安裝的機器。而在沒有加密的硬碟上，重設只是刪除而非安全抹除，所以如果資料具敏感性，請改做全新安裝。

## 免密碼 sudo

有時候你會希望 `sudo` 不再反覆詢問，最常見的情況是 AI agent 正在為你長時間執行系統工作。_Setup > Security > Passwordless Sudo_ 會詢問要允許存取多久：**15 分鐘**、**1 小時**、**1 天**，或**永久**。存取啟用期間，選單列其他指示圖示旁會出現一個紅色警告圖示。點選它或再次執行該指令即可關閉存取。你也可以用 `omarchy-sudo-passwordless 30` 傳入你自訂的分鐘數（從 1 到 1440），或使用 `omarchy-sudo-passwordless permanent`。

有時限的存取會自動到期，包括從跨越期限的暫停狀態恢復後立即到期。重新啟動電腦會提早結束它。永久存取在重新開機後依然保留，並會保持啟用，直到你將它停用為止。

更新或移除 Omarchy 的設定套件，會在其到期支援變更之前結束任何暫時授權。如果該指令回報授權或清理錯誤，請先解決該錯誤，再嘗試啟用另一項授權；出現錯誤並不表示免密碼存取未啟用。

對這一點要看清楚：它開啟時，任何以你的使用者身分執行的程式，都能在不被詢問的情況下以 root 身分做任何事。這正是它的用意所在，也正是它的全部風險所在。

## 簽署金鑰

所有 ISO 簽章和 Omarchy 套件庫套件的公開金鑰是 `40DFB630FF42BCFFB047046CF0134EE680CAC571`（[在 openpgp.org 上驗證](https://keys.openpgp.org/search?q=pkgs%40omarchy.org)）。`omarchy/omarchy-keyring` 套件也包含這把金鑰，並將用於無縫推出任何潛在的更新。

你可以為任何 ISO 發行版找到其簽章，只要在其 URL 後加上 `.sig`，例如 `https://iso.omarchy.org/omarchy-x.x.x.iso.sig`。
