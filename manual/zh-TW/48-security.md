# 安全性

Omarchy 對安全性極為重視。這套作業系統就是要讓你能在 _真實世界_ 做 _真正的工作_。遺失一台筆記型電腦，不該演變成一場安全緊急事故。以下是我們的做法：

1. *全磁碟加密預設開啟*：這是保護資料實體安全最重要的一步。如果你的電腦遺失或遭竊，資料會以標準 LUKS（Linux Unified Key Setup）完整加密。安裝程式允許你為用完即丟的機器選擇退出（參見[開始使用](02-getting-started.md)）；未加密的安裝完全沒有這層保護，任何拿到磁碟的人都能讀取其中內容。
2. *防火牆預設啟用*：所有傳入流量預設都會被阻擋，僅有少數例外：供 [LocalSend](https://localsend.org/) 使用的連接埠 53317；傳送至電腦自身解析器、位於 Docker bridge 位址（172.17.0.1）的 DNS 查詢，這些查詢僅接受來自 Docker 分配給其容器的私有位址範圍；以及多播 DNS（連接埠 5353），它讓印表機與你網路上的其他裝置能彼此發現，也會在該處宣告你電腦的名稱。除此之外，防火牆保留 UFW 對 ping、向路由器取得位址（DHCP）以及 UPnP 探索的標準允許規則。就連 ssh 也處於關閉狀態，直到你透過 _Setup > Security > SSHD_ 將它開啟；該操作會授權你的 SSH 金鑰、關閉密碼登入，然後才開啟連接埠 22（且有速率限制以防禦暴力破解）。我們甚至使用 [ufw-docker](https://github.com/chaifeng/ufw-docker) 設定來鎖定 Docker 存取，防止你的容器意外暴露於外界。
3. *Arch 永遠擁有最新更新*：Arch 是 Omarchy 所基於的底層發行版，屬於滾動式發行版。這表示任何套件中被發現並修補的安全漏洞，都能很快透過 `omarchy-update` 取得並安裝。如此一來，你永遠都在執行一切軟體的最新、最安全版本。
4. *Omarchy 維護自己的套件與鏡像站*：Omarchy 預設僅仰賴來自 Arch 自家 core/extra/multilib 儲存庫（在 ARM 機器上則為 Arch Linux ARM 的儲存庫，另在 Apple Silicon 上加上 Asahi ALARM）以及其自家 Omarchy Package Repository 的套件。你可以直接從 AUR 安裝軟體，但基本安裝不會這麼做——只有少數選擇性安裝項目，例如第三方瀏覽器，才會從 AUR 拉取。
5. *Cloudflare 保護我們免於 DDoS*：Omarchy 的散布基礎設施——ISO、Omarchy 套件、Arch 鏡像站——都受到 Cloudflare 強大的 DDoS 防護盾保護，並託管於其 CDN 上。這提供了卓越的可用性。

## 變更你的密碼

在加密安裝中，你有兩組密碼：一組在開機時解鎖磁碟，另一組用於登入與 `sudo`。設定程序會將兩者設為相同。Omarchy 選單中的 _Update > Password_ 會一次變更兩者，讓它們保持一致：它會先詢問目前的磁碟密碼，再詢問新密碼，先變更磁碟的密碼，然後將你的登入密碼設為與之相符。若沒有磁碟加密，它只會變更你的登入密碼。如果變更過程被中斷，請再次執行 _Update > Password_：它會詢問目前能解鎖磁碟的密碼，完成變更，並將你的登入密碼設為該密碼。若要變更另一個加密磁碟的密碼，請在終端機中執行 `omarchy-drive-password`。

## 將你已使用過的機器轉交他人

如果你要把機器交給別人，不必重新安裝。執行 Omarchy 選單中的 _Remove > Factory Reset_，輸入 `reset` 確認，若被要求則輸入你的磁碟加密密碼，然後重新開機。這會清除每一個使用者帳號與 `/home` 中的一切，丟棄你自安裝以來新增的所有套件與系統變更，並清除機器的身分識別資訊——網路連線、主機金鑰，全部抹除。重新啟動後，出現的是首次開機時的設定精靈，讓新擁有者能輸入他們自己的名稱、密碼與加密密碼。

它的運作方式是還原安裝程式所拍攝的基準快照，因此僅適用於從 Omarchy ISO 安裝的機器。而在未加密的磁碟上，重置只是刪除而非安全抹除，因此若資料具有敏感性，請改為執行全新安裝。

## 免密碼 sudo

有時你會希望 `sudo` 別再一直詢問，最常見的情況是 AI agent 正在為你長時間處理系統工作。_Setup > Security > Passwordless Sudo_ 會詢問你允許存取的時長：**15 分鐘**、**1 小時**、**1 天**或**永久**。存取啟用期間，選單列其他指標旁會出現一個紅色警告圖示。點選它或再次執行該指令即可關閉存取。你也可以用 `omarchy-sudo-passwordless 30` 傳入你自訂的分鐘數（從 1 到 1440），或使用 `omarchy-sudo-passwordless permanent`。

有時限的存取會自動到期，包括在暫停期間跨過期限、恢復後立即到期的情況。重新啟動電腦會提早結束它。永久存取會在重新開機後保留，並持續啟用直到你將它停用。

更新或移除 Omarchy 的設定套件，會在其到期支援變更之前結束任何暫時授權。如果該指令回報授權或清理錯誤，請在嘗試啟用另一項授權前先解決該錯誤；出現錯誤並不表示免密碼存取未處於啟用狀態。

對這一點要看得很清楚：它開啟時，任何以你的使用者身分執行的程式，都能在不被詢問的情況下以 root 身分執行任何事。這正是它的目的所在，也正是它的風險所在。

## 簽署金鑰

所有 ISO 簽章與 Omarchy 儲存庫套件的公鑰為 `40DFB630FF42BCFFB047046CF0134EE680CAC571`（[在 openpgp.org 上驗證](https://keys.openpgp.org/search?q=pkgs%40omarchy.org)）。`omarchy/omarchy-keyring` 套件同樣包含這把金鑰，並將用於無縫推出任何潛在的更新。

你在任何 ISO 發行版的 URL 後面加上 `.sig`，就能找到它的簽章，例如 `https://iso.omarchy.org/omarchy-x.x.x.iso.sig`。
