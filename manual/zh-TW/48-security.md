# 安全性

Omarchy 對安全性極為重視。這是一套讓你能在 _真實世界_ 中做 _正經工作_ 的作業系統。在這裡，遺失一台筆記型電腦不該演變成一場安全緊急事件。以下是我們的做法：

1. *全磁碟加密預設開啟*：這是保護資料實體安全最重要的一步。如果你的電腦遺失或被竊，資料會使用標準 LUKS (Linux Unified Key Setup) 完整加密。安裝程式允許你為用完即丟的機器選擇退出（請參閱 [開始使用](02-getting-started.md)）；未加密的安裝完全沒有這層保護，任何拿到磁碟機的人都能讀取其中內容。
2. *預設啟用防火牆*：所有傳入流量預設都會被封鎖，只有少數例外：供 [LocalSend](https://localsend.org/) 使用的連接埠 53317；傳送至電腦自身解析器、位於 Docker 橋接位址 (172.17.0.1) 的 DNS 查詢，且僅接受來自 Docker 分配給其容器的私人位址範圍；以及多點傳送 DNS（連接埠 5353），它讓印表機和你網路上的其他裝置能彼此發現，也會在該網路上宣告你的電腦名稱。除此之外，防火牆保留 UFW 的標準允許項目，包括 ping、向你的路由器取得位址 (DHCP)，以及 UPnP 探索。就連 ssh 也會保持關閉，直到你透過 _設定 > 安全性 > SSHD_ 將它開啟為止，開啟時會一併開放連接埠 22（並設有速率限制以防範暴力破解）。我們甚至使用 [ufw-docker](https://github.com/chaifeng/ufw-docker) 設定鎖定 Docker 存取，防止你的容器意外暴露在外。
3. *Arch 永遠提供最新更新*：Omarchy 所建基的底層發行版 Arch 是滾動式發行版。這表示任何套件中被發現並修補的安全漏洞，都能很快透過 `omarchy-update` 安裝。這樣一來，你永遠都在執行所有軟體的最新、最安全版本。
4. *Omarchy 維護自己的套件與鏡像站*：Omarchy 預設只依賴 Arch 自己的 core/extra/multilib 套件庫，以及它自己的 Omarchy Package Repository 中的套件。你可以直接從 AUR 安裝軟體，但基本安裝不會這麼做——只有少數選擇性安裝項目，例如第三方瀏覽器，才會從 AUR 取得套件。
5. *Cloudflare 保護我們免於 DDoS*：Omarchy 的散佈基礎設施——ISO、Omarchy 套件、Arch 鏡像站——都受到 Cloudflare 強大的 DDoS 防護盾保護，並託管在其 CDN 上。這提供了卓越的可用性。

## 變更你的密碼

在加密安裝中，你有兩個密碼：一個在開機時解鎖磁碟機，另一個用來登入並執行 `sudo`。設定程式會將兩者設為相同。兩者都可以在 Omarchy 選單的 _更新 > 密碼_ 下變更——第一個選 _磁碟機加密_，第二個選 _使用者_。變更磁碟機密碼時會先要求輸入目前的密碼，所以請先準備好。如果變更中途被中斷，請再次執行 _磁碟機加密_：它會要求輸入目前能解鎖磁碟機的密碼，並完成變更。

## 將你已經用過的機器轉交他人

如果你要將機器交給其他人，你不必重新安裝。在 Omarchy 選單中執行 _移除 > 恢復原廠設定_，輸入 `reset` 確認，然後重新開機。這會清除每個使用者帳戶以及 `/home` 中的所有內容，捨棄你自安裝以來所做的所有套件與系統變更，並清除機器的身分識別——網路連線、主機金鑰，全部清掉。重新啟動後出現的會是首次開機時的設定精靈，準備讓新擁有者輸入他們自己的名稱、密碼和加密密碼。

它的運作方式是還原安裝程式所建立的基準快照，因此僅適用於從 Omarchy ISO 安裝的機器。而且在未加密的磁碟機上，重設只是刪除而非安全抹除，所以如果資料敏感，請改為全新安裝。

## 免密碼 sudo

有時你會希望 `sudo` 不再詢問密碼，最常見的情況是 AI agent 正在為你長時間執行系統工作時。_設定 > 安全性 > 免密碼 Sudo_ 會詢問允許存取的時間長度：**15 分鐘**、**1 小時**、**1 天**或**永久**。存取啟用期間，選單列其他指示器旁會出現一個紅色警告圖示。點選它或再次執行該命令即可關閉存取。你也可以使用 `omarchy-sudo-passwordless 30` 傳入自訂的分鐘數（從 1 到 1440），或使用 `omarchy-sudo-passwordless permanent`。

限時存取會自動到期，包括在跨越期限的暫停狀態恢復後立即到期。重新啟動電腦會提早結束它。永久存取在重新開機後仍會保留，並持續啟用，直到你將它停用為止。

更新或移除 Omarchy 的設定套件，會在到期支援變更之前結束任何暫時授權。如果該命令回報授權或清理錯誤，請先解決它，再嘗試啟用另一項授權；出現錯誤並不表示免密碼存取未啟用。

對這一點要有清醒的認識：只要它開啟，任何以你的使用者身分執行的程式，都能在不被詢問的情況下以 root 身分做任何事。這正是它的全部目的，也是它的全部風險。

## 簽署金鑰

所有 ISO 簽章與 Omarchy 套件庫套件的公開金鑰為 `40DFB630FF42BCFFB047046CF0134EE680CAC571`（[在 openpgp.org 驗證](https://keys.openpgp.org/search?q=pkgs%40omarchy.org)）。`omarchy/omarchy-keyring` 套件也包含此金鑰，並將用於無縫推出任何潛在更新。

你可以透過在其 URL 後加上 `.sig` 來找到任何 ISO 發行版的簽章，例如 `https://iso.omarchy.org/omarchy-x.x.x.iso.sig`。
