# 安全性

Omarchy 極度重視安全性。這是一個讓你能在 _真實世界_ 中做 _真正工作_ 的作業系統。在這裡，遺失一台筆電不至於演變成一場安全緊急事件。那麼我們做了什麼：

1. *全磁碟加密是強制的*：這是保障你資料實體安全最重要的一步。如果你的電腦遺失或被偷，資料會使用標準的 LUKS（Linux Unified Key Setup）完整加密。
2. *防火牆預設啟用*：所有傳入流量預設都被阻擋，除了供 [LocalSend](https://localsend.org/) 使用的連接埠 53317 之外。就連 ssh 也預設關閉，直到你透過 _設定 > 安全性 > SSHD_ 將它開啟，這會在設定過程中開啟連接埠 22（並以速率限制防止暴力破解）。我們甚至使用 [ufw-docker](https://github.com/chaifeng/ufw-docker) 的配置來鎖緊 Docker 存取，以防止你的容器意外暴露給全世界。
3. *Arch 永遠有最新更新*：Arch 是 Omarchy 所建立的底層發行版，它是一個滾動式發行版。這表示任何已發現並修補的安全漏洞，都可以很快用 `omarchy-update` 安裝。這樣一來，你永遠都在運行最新、最安全的版本。
4. *Omarchy 維護自己的套件和鏡像站*：Omarchy 預設只依賴 Arch 自己的 core/extra/multilib 套件庫和它自己的 Omarchy 套件庫中的套件。你可以直接從 AUR 安裝軟體，但基本安裝不會——只有少數選用安裝，例如第三方瀏覽器，會從 AUR 拉取。
5. *Cloudflare 保護我們免受 DDoS 攻擊*：所有 Omarchy 的散布基礎設施——ISO、Omarchy 套件、Arch 鏡像站——都受到 Cloudflare 強大的 DDoS 防護保護，並託管在他們的 CDN 上。這提供了出色的可用性。

## 變更你的密碼

在加密安裝上你有兩個密碼：一個是在開機時解鎖磁碟的，另一個是你登入和執行 `sudo` 時使用的。安裝設定會把兩者設成一樣。兩者都可以在 Omarchy 選單的 _更新 > 密碼_ 之下變更——第一個用 _磁碟加密_，第二個用 _使用者_。變更磁碟密碼會先要求你輸入目前的密碼，所以請把它準備好。如果變更中途被打斷，再次執行 _磁碟加密_：它會詢問目前能解鎖磁碟的密碼，並完成變更。

## 把一台你已經用過的機器轉交出去

如果你要把機器交給別人，你不需要重新安裝它。在 Omarchy 選單中執行 _設定 > 重設電腦_，輸入 `reset` 確認，然後重新開機。這會抹除每一個使用者帳號和 `/home` 中的一切，丟棄你自安裝以來所做的所有套件和系統變更，並清除機器的身分——網路連線、主機金鑰，全都包括。重新開機出現的，會是第一次開機時的那個設定精靈，準備讓新主人輸入他們自己的姓名、密碼和加密密碼。

它的運作方式是還原安裝程式所建立的基線快照，所以它只適用於從 Omarchy ISO 安裝的機器。而且在沒有加密的磁碟上，重設是刪除而不是安全抹除，所以如果資料很敏感，請改做一次全新安裝。

## 免密碼 sudo

有時候你希望 `sudo` 不要再一直詢問，最常見的情況是當 AI 代理程式正在為你執行一長段系統工作時。_設定 > 安全性 > 免密碼 sudo_ 會詢問允許存取多久：**15 minutes**、**1 Hour**、**1 Day** 或 **Permanently**。當存取啟用時，其他選單列指示圖示旁邊會出現一個紅色警告圖示。點選它或再次執行該指令即可關閉存取。你也可以用 `omarchy-sudo-passwordless 30` 傳入你自己的分鐘數（從 1 到 1440），或使用 `omarchy-sudo-passwordless permanent`。

有時限的存取會自動到期，包括在從跨越期限的暫停中喚醒後立刻到期。重新啟動電腦會提前結束它。永久存取在重新開機後仍然有效，並會一直啟用直到你停用它。

更新或移除 Omarchy 的設定套件，會在其到期支援變更之前結束任何臨時授權。如果該指令回報授權或清理錯誤，請在嘗試啟用另一項授權之前先解決它；出現錯誤並不代表免密碼存取處於未啟用狀態。

對這一項要保持清醒：當它開啟時，任何以你的使用者身分執行的程式都能不被詢問地以 root 身分做任何事。那正是它的全部目的，也是它的全部風險。

## 簽章金鑰

所有 ISO 簽章和 Omarchy repo 套件的公開金鑰是 `40DFB630FF42BCFFB047046CF0134EE680CAC571`（[在 openpgp.org 驗證](https://keys.openpgp.org/search?q=pkgs%40omarchy.org)）。`omarchy/omarchy-keyring` 套件也包含這把金鑰，並將用於無縫推出任何潛在更新。

你可以透過在 URL 後加上 .sig 來找到任何 ISO 版本的簽章。例如 https://iso.omarchy.org/omarchy-x.x.x.iso.sig.
