# 安全性

Omarchy 對安全性極為認真。這應該是一個你可以在_現實世界_中用來做_真正的工作_的作業系統。在這裡，弄丟一台筆記型電腦不應該導致安全緊急事件。所以我們這樣做：

1. *預設啟用全磁碟加密*：這是保護你資料實體安全最重要的一步。如果你的電腦遺失或遭竊，資料會使用標準的 LUKS (Linux Unified Key Setup) 完整加密。安裝程式允許你在拋棄式機器上選擇不啟用（參見 [開始使用](02-getting-started.md)）；未加密的安裝完全沒有這層保護，任何拿到該磁碟機的人都能讀取其中的資料。
2. *預設啟用防火牆*：依預設會阻擋所有傳入流量，但有少數例外：供 [LocalSend](https://localsend.org/) 使用的連接埠 53317；傳送到電腦自身解析器、位於 Docker bridge 位址 (172.17.0.1) 的 DNS 查詢，且僅接受來自 Docker 分配給其容器的私人位址範圍；以及多點傳送 DNS（連接埠 5353），它能讓你網路上的印表機與其他裝置互相找到彼此，也會在該網路上宣告你的電腦名稱。在此之外，防火牆保留了 UFW 對 ping、向你的路由器取得位址 (DHCP) 以及 UPnP 探索的標準放行。甚至 ssh 也處於關閉狀態，直到你透過 _設定 > 安全性 > SSHD_ 將它開啟為止；該設定會在設定過程中開啟連接埠 22（並以速率限制防範暴力破解）。我們甚至使用 [ufw-docker](https://github.com/chaifeng/ufw-docker) 設定來鎖定 Docker 的存取，避免你的容器意外暴露在外。
3. *Arch 永遠提供最新更新*：Arch 是 Omarchy 所基於的底層發行版，屬於滾動式發行版。這代表任何套件中被發現並修補的安全漏洞，都能很快透過 `omarchy-update` 安裝。這樣你永遠都在執行所有軟體的最新、最安全版本。
4. *Omarchy 維護自己的套件與鏡像站*：依預設，Omarchy 只依賴 Arch 官方的 core/extra/multilib 套件庫，以及其自身的 Omarchy Package Repository。你可以直接從 AUR 安裝軟體，但基本安裝不會這樣做 — 只有少數選擇性安裝，例如第三方瀏覽器，才會從 AUR 取得。
5. *Cloudflare 保護我們免受 DDoS 攻擊*：Omarchy 的散布基礎設施 — ISO、Omarchy 套件、Arch 鏡像站 — 都受到 Cloudflare 強大的 DDoS 防護盾保護，並託管在其 CDN 上。這提供了卓越的可用性。

## 變更你的密碼

在加密安裝中，你有兩個密碼：一個在開機時解除磁碟機鎖定，另一個用來登入並執行 `sudo`。設定會將兩者設為相同。兩者都可以在 Omarchy 選單的 _更新 > 密碼_ 下變更 — 第一個選 _磁碟機加密_，第二個選 _使用者_。變更磁碟機密碼時，會先要求你輸入目前的密碼，所以請先準備好。如果變更被中斷，請再次執行 _磁碟機加密_：它會要求你輸入目前能解除磁碟機鎖定的密碼，並完成變更。

## 將你已經用過的機器交給別人

如果你要把機器交給別人，不必重新安裝。在 Omarchy 選單中執行 _設定 > 重置電腦_，輸入 `reset` 確認，然後重新開機。這會清除每個使用者帳號以及 `/home` 中的所有內容，捨棄你自安裝以來所做的所有套件與系統變更，並清除機器的身分資訊 — 網路連線、主機金鑰，全部清掉。重新開機後出現的，是首次開機時的設定精靈，已準備好讓新擁有者輸入他們自己的名稱、密碼和加密密碼。

它透過還原安裝程式所建立的基準快照來運作，因此僅適用於從 Omarchy ISO 安裝的機器。而且在未加密的磁碟機上，重置只是刪除，而不是安全抹除，所以如果資料很敏感，請改為全新安裝。

## 免密碼 sudo

有時你會希望 `sudo` 不再詢問密碼，最常見的情況是 AI agent 正在為你長時間處理系統工作。_設定 > 安全性 > 免密碼 Sudo_ 會詢問你要允許存取多久：**15 分鐘**、**1 小時**、**1 天**，或 **永久**。存取啟用期間，選單列中的其他指示器旁會出現一個紅色警告圖示。點按它，或再次執行該命令，即可關閉存取。你也可以使用 `omarchy-sudo-passwordless 30` 傳入你自己指定的分鐘數（1 到 1440），或使用 `omarchy-sudo-passwordless permanent`。

限時存取會自動到期，包括在暫停期間已跨過截止時間、恢復後立即到期。重新啟動電腦會提早結束它。永久存取在重新開機後仍會保留，並持續啟用，直到你將它停用為止。

更新或移除 Omarchy 的設定套件，會在其到期支援變更之前結束任何暫時授權。如果該命令回報授權或清理錯誤，請先解決該錯誤，再嘗試啟用另一項授權；出現錯誤並不表示免密碼存取處於未啟用狀態。

對於這一點要看清楚：當它啟用時，任何以你的使用者身分執行的程式，都能在不被詢問的情況下以 root 身分執行任何操作。這正是它的全部目的，也是它的全部風險。

## 簽署金鑰

所有 ISO 簽章與 Omarchy 套件庫套件所用的公開金鑰是 `40DFB630FF42BCFFB047046CF0134EE680CAC571`（[在 openpgp.org 上驗證](https://keys.openpgp.org/search?q=pkgs%40omarchy.org)）。`omarchy/omarchy-keyring` 套件也包含這把金鑰，並將用於無縫推出任何可能的更新。

你可以透過在任何 ISO 版本的 URL 後面加上 `.sig`，來找到它的簽章，例如 `https://iso.omarchy.org/omarchy-x.x.x.iso.sig`。
