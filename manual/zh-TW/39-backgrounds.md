# 背景

每個主題都附帶自己的一組背景，你也可以在 `~/.config/omarchy/backgrounds/[theme]` 加入你自己的額外背景。如果你想為 nord 主題新增一張額外背景圖片，只要把檔案放進 `~/.config/omarchy/backgrounds/nord` 即可。

最簡單的做法是前往 Omarchy 選單中的 _安裝 > 風格 > 背景_。這會打開存放該主題背景的資料夾。按 `Super + Shift + F` 再開啟另一個檔案管理器，找到你的背景，把它複製過去。現在它就會出現在你用 `Super + Ctrl + Space` 挑選背景時的選項中。

背景除了靜態圖片之外也可以是影片。把 `mp4`、`m4v`、`mov`、`webm`、`mkv` 或 `avi` 檔案放進同一個資料夾，它就會和圖片並列出現。影片由 OWE 桌布引擎播放。它會為所有顯示器只解碼一次影片，並透過預設音訊輸出播放聲音，而且只要沒有任何地方看得到它時就會停止播放。鎖定畫面也會透過 OWE 繪製同一個解碼畫面，但靜音。影片桌布的耗電量還是比靜態桌布高得多。

主題可以為靜態背景附上一段短短的開場影片。對於 `backgrounds/road.webp`，對應的影片位於 `backgrounds/intros/road.mp4`。它會在開機時以及切換到選中該背景的主題時自動播放，然後回到靜態畫面。開場影片不會出現在背景選擇器中，也永遠不會循環播放。

關閉 _觸發 > 外觀 > 動畫_ 也會同時關閉背景開場影片。Omarchy 在虛擬機器中預設就會這樣做。`omarchy theme bg intro toggle` 指令可以單獨切換開場影片。重新整理主題，或在同一主題內選另一張背景，都不會播放開場影片。

你可以在以下網址找到一大堆很酷的精選背景收藏：https://github.com/dharmx/walls.

影片背景在播放暫停或無法使用時，會在鎖定畫面上保留一張快取的靜態畫面。動畫 GIF 會在桌面上播放，並在鎖定畫面上顯示一個靜態影格。
