# 螢幕截圖與錄影

你能從螢幕上抓下來的一切，都掛在 Print Screen 鍵上。單獨按這一個鍵會拍一張圖片，而加上修飾鍵則會錄影、取色，或擷取一個區域內的文字。如果你的鍵盤根本沒有 Print Screen 鍵，`Super + Ctrl + C` 會以選單形式開啟同一組功能。

| 快捷鍵 | 功能 |
| ------ | -------- |
| `Print Screen` | 螢幕截圖 |
| `Alt + Print Screen` | 螢幕錄影（或停止正在運行的那個） |
| `Super + Print Screen` | 色彩選擇器 |
| `Super + Ctrl + Print Screen` | 從一個區域擷取文字 |
| `Super + Ctrl + C` | 擷取選單 |
| `Super + Ctrl + .` | 轉碼一張圖片或一段影片 |

## 螢幕截圖

按下 `Print Screen`，Omasnap 會在它的覆蓋層出現之前就擷取目前焦點所在的顯示器，所以當你瞄準時，沒有任何東西會在你底下移動。拖曳一個自由形式的區域、點選一個視窗來擷取它，或點選空白區域來擷取整個顯示器。在繪製之前按下 `S`，可以擷取一個捲動區域。改變主意了？再按一次 `Print Screen` 就能關閉 Omasnap。

在你選取一個區域後，Omasnap 會儲存擷取的內容、把它複製到剪貼簿，並顯示 10 秒的預覽。使用預覽的釘選按鈕或 `Ctrl + P` 把它留在螢幕上，或選擇編輯來標註它。

標註編輯器可以繪製箭頭、線條、形狀、醒目標示、編號標記、文字和安全遮罩；裁切或切除圖片的一部分；對它的文字進行 OCR；並加上背景。在編輯器中，按下 `Enter` 來複製並儲存完成的 PNG，按 `Ctrl + C` 只複製不儲存，或按 `Ctrl + S` 只儲存不複製。

儲存的螢幕截圖預設會落在 `~/Pictures/Screenshots` 中，名稱類似 `screenshot-2026-08-13_14-22-05-firefox.png`。設定 `OMASNAP_SCREENSHOT_DIR` 來使用另一個目錄——在哪裡放置工作階段環境變數，見[常見問題](46-faq.md)。Omasnap 會在儲存第一張截圖時建立該目錄。在 `~/.config/omasnap/omasnap.conf` 中設定 `[output] autosave = false` 來停用自動儲存。

從終端機，`omarchy screenshot` 會開啟同一個覆蓋層，而你可以選擇它的起始模式：`omarchy capture screenshot region`、`windows`、`fullscreen` 或 `scroll`。第二個引數 `copy` 或 `save` 會跳過預覽，並把截圖直接送到那個目的地。若要在輸出前編輯，對於全螢幕編輯器使用 `omarchy screenshot --editor=overlay`，對於獨立視窗使用 `omarchy screenshot --editor=window`。

### 用鍵盤驅動選擇器

當選取畫面開啟時，你完全不需要使用滑鼠：

| 按鍵 | 功能 |
| --- | -------- |
| `S` | 切換捲動區域模式 |
| `Super + Arrow keys` | 在視窗模式中於視窗之間移動 |
| `Return` | 擷取醒目標示的視窗 |
| `Ctrl + A` | 擷取整個目前焦點所在的顯示器 |
| `R` | 還原本工作階段中上次繪製的區域 |
| `Esc` | 關閉 Omasnap |

這些綁定只在 Omasnap 開啟時存在，所以它們不會與你自己的設定中的任何東西衝突。

## 螢幕錄影

`Alt + Print Screen` 會開啟 _觸發 > 擷取 > 螢幕錄影_，它會問你想要什麼配音：無音訊、桌面音訊、桌面加麥克風，或桌面加麥克風加網路攝影機。最後一個只有在你真的插了一台攝影機時才會出現。選一個，Omarchy 的錄影選擇器會讓你拖曳一個區域，或點選一個視窗或顯示器。

錄影運行在 gpu-screen-recorder 上，它以 60fps 在 GPU 上編碼，必要時則退回到 CPU。成果是一個 MP4，位於 `~/Videos` 中，名稱為 `screenrecording-2026-08-13_14-22-05.mp4`。設定 `OMARCHY_SCREENRECORD_DIR` 來變更它——但請注意，與螢幕截圖目錄不同，這個目錄必須已經存在，否則錄影會拒絕啟動。

當你在錄影時，選單列上會出現一個小小的指示。點選它即可停止。你也可以再次按下 `Alt + Print Screen` 來停止，或使用 _觸發 > 擷取 > 螢幕錄影_ 底下的_停止螢幕錄影_項目，它只在確實有東西在錄影時才會出現。

停止時，它會先做一點整理再把檔案交給你：第一幀會被裁掉，如果有音訊，它會被正規化到 -14 LUFS，且最開頭 PipeWire 擷取時的那個爆音會被靜音。接著會出現一則帶有錄影縮圖的通知。點選它即可在 mpv 中播放該檔案。

### 網路攝影機覆蓋層

當你用網路攝影機錄影時，攝影機畫面會以一個釘選、裁切過的人像視窗形式，出現在你所錄製畫面的右下角。如果它正擋在你需要的東西上面，你可以即時調整它的大小：

| 快捷鍵 | 功能 |
| ------ | -------- |
| `Super + Alt + [` | 讓網路攝影機覆蓋層變小 |
| `Super + Alt + ]` | 讓網路攝影機覆蓋層變大 |

有三種大小——小、中、大——而快捷鍵會在它們之間步進。中是預設值。它們與錄影畫面成比例，所以無論你錄的是一台 1080p 顯示器還是一台 6K 顯示器，攝影機在畫面中佔的份量都相同。而如果你錄的是一個區域而非整個顯示器，覆蓋層會錨定在那個區域的角落而非顯示器的角落，所以它會留在畫面內。

你也可以用 `omarchy-capture-webcam-resize small` 直接呼叫它，或用 `reset` 回到中。

## 文字、QR 碼和色彩

`Super + Ctrl + Print Screen` 會選取一個區域並透過 OCR 把它送到剪貼簿。這個功能在[文字擷取與聽寫](11-text-extraction-dictation.md)中有完整介紹。

_觸發 > 擷取 > QR 碼_對 QR 碼做同樣的把戲。選取含有該碼的區域，解碼後的值就會進到剪貼簿。它只尋找 QR 碼——否則密集的螢幕內容往往會被誤判為條碼。值得知道的是：解碼後的值只進到剪貼簿，不去任何其他地方。它不會被列印出來，不會出現在通知中，而且會被標記為敏感，所以不會留在[剪貼簿紀錄](08-unified-clipboard-history.md)裡。QR 碼經常攜帶機密——舉例來說，2FA 設定碼背後的 `otpauth://` URI——而你不會希望那種東西出現在日誌中。貼上仍然可以正常運作。

`Super + Print Screen`（或 _觸發 > 擷取 > 色彩_）會把游標變成一個滴管。點選螢幕上的任何東西，那個色彩就會落在剪貼簿上。再按一次快捷鍵，就能在不取色的情況下退出。

## 分享前先轉碼

一段 4K 螢幕錄影，或一張來自你手機的原始 HEIC，往往太大，無法直接傳送。`Super + Ctrl + .`（或 _觸發 > 轉碼_）能解決這個問題。它會在 `~/Pictures` 和 `~/Videos` 之上為你提供一個模糊檔案選擇器，然後詢問格式和大小。

圖片可轉成 jpg 或 png，分高、中、低三檔，寬度上限分別為 3160、2160 和 1080 像素。影片可轉成 mp4 或動畫 gif，分 4k、1080p 和 720p。轉換後的檔案會寫在原始檔案旁邊，名稱中帶有解析度——`demo-1080p.mp4`——而路徑會以檔案 URI 的形式複製到剪貼簿，所以你可以直接把它貼進一個接受檔案拖放的應用程式裡。

如果你已經知道自己想要什麼，它也能從終端機運作：`omarchy transcode ~/Videos/demo.mov mp4 1080p`。還有 `omarchy transcode ascii`，它會把一張圖片變成 ASCII 藝術——那個主要是用在[品牌](41-branding.md)上的。

## 把它傳到某個地方

一旦你拿到了檔案，`Super + Ctrl + S` 會開啟分享選單，並透過 LocalSend 把它傳給你網路上的另一台裝置。相關說明見 [GUI 應用程式](22-guis.md)。
