# 其他套件

Arch 在官方儲存庫和 Arch User Repository（AUR）之間擁有驚人的套件財富，幾乎適用於任何類型的軟體。

使用起來再簡單不過了。你前往 Omarchy 選單（`Super + Space`）中的 _安裝 > Package_ 並輸入你想要的套件，即可安裝新的 Arch 套件。它會自動對所有套件的清單進行模糊篩選。（你也可以在終端機中使用 `omarchy pkg add [package]` 手動完成）。

你可以用 AUR 做同樣的事，只要使用 _安裝 > AUR_ 即可。只是請記住，AUR 沒有經過 Arch 團隊的審查。它就像 RubyGems 或 npm。任何人都可以上傳。

如果你想移除一個套件，你可以使用 Omarchy 選單中的 _移除 > Package_。它會移除套件、設定檔和相依套件。（你也可以使用 `omarchy pkg drop [package]` 手動完成）。
