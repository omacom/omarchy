# 填寫 PDF

Omarchy 附帶一個不錯的基本 PDF 檢視器，叫做 Document Viewer。這是當你雙擊任何 PDF 時會開啟的程式。

但你只能用 Document Viewer 來填寫那些已被設定為表單的 PDF。如果你需要填寫還沒被這樣設定的 PDF，或者你需要簽署 PDF，請使用 [Signed](https://github.com/omacom/signed)。透過應用程式啟動器（`Super + Space`）啟動它，或右鍵按一下檔案、選取 _Open With..._，然後選取 Signed。

按 `T` 輸入文字，按 `D` 放下今天的日期。兩者都會落在你的滑鼠指標所在的位置。拖曳任何東西可移動它，拖曳其角可將其放大或縮小，雙擊文字可更改它。

要簽名，你需要一張你簽名的圖片：掃描圖，或在白紙上拍的一張光線良好的照片。開啟 _Signature_ 選單（`Shift + S`），選擇 _Add signature..._，挑選圖片，並給它一個名稱。Signed 會移除紙張並保留墨跡。從那時起，`S` 會把你的簽名放在滑鼠指標下方。

完成後，使用 _Save signed copy..._（`Ctrl + S`）將填好的 PDF 儲存在原始檔案旁邊，原始檔案永遠不會被更改。在 Signed 裡面按 `?` 可查看每個快捷鍵。
