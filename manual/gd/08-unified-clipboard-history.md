# Stòr-bhòrd aonaichte & eachdraidh

Mar as trice air Linux, feumaidh tu `Ctrl + Shift + C/V` gus lethbhreac a dhèanamh 's a chur ann san tèirmineal agus `Ctrl + C/V` gus a dhèanamh anns a h-uile àite eile. Tha sin doirbh fàs cleachdte ris do dhuine sam bith nach do rugadh 's nach deach àrach air Linux! Agus tha an aon rud fìor mu ghluasad o super gu ctrl, ma tha thu a' tighinn on Mac.

Fuasglaidh Omarchy an dà dhuilgheadas le iuchraichean-grada aonaichte an stòr-bhùird a dh'obraicheas (cha mhòr) anns a h-uile àite. Seo iad:

| Iuchair-ghrad | Àithne |
| ------- | ----------- |
| Super + C | Dèan lethbhreac |
| Super + X | Gearr às |
| Super + V | Cuir ann |
| Super + Ctrl + V | Eachdraidh an stòr-bhùird |

_Thoir an aire gun cleachd a' mhòr-chuid de dh'acfhainnean àidseant `Ctrl + V` airson dealbhan a chur ann, ach `Super + V` airson teacsa a chur ann._

### Eachdraidh an stòr-bhùird

Is e slige Omarchy a bheir dhut eachdraidh an stòr-bhùird agus obraichidh i le teacsa is dealbhan le chèile. Cuiridh tu gu dol i le `Super + Ctrl + V`, taghaidh tu an innteart agad le Return, agus an uairsin thèid a chur air an stòr-bhòrd, deiseil airson a chur ann le `Super + V`.
