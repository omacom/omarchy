# Iuchraichean-grada

Chì thu a h-uile prìomh cheangal iuchrach le `Super + K` (ceanglaichean iuchrach Tmux le `Super + Alt + K` agus ceanglaichean iuchrach Herdr le `Super + Ctrl + K`).

## Seòladh

| Iuchair-ghrad           | Gnìomh                |
| ----------------------- | --------------------- |
| `Super + Space`           | Clàr-taice Omarchy (aplacaidean agus a h-uile càil eile)    |
| `Super + Alt + Space` | Griod nan aplacaidean |
| `Super + Escape` | Clàr-taice an t-siostaim (cuir na dhàil, ath-thòisich is msaa)  |
| `Super + Ctrl + L` | Glais an coimpiutair |

## Stòr-bhòrd uile-choitcheann

| Iuchair-ghrad           | Gnìomh                |
| ----------------------- | --------------------- |
| `Super + C`           | Dèan lethbhreac    |
| `Super + X`           | Gearr às (ach chan ann san tèirmineal)    |
| `Super + V`           | Cuir ann    |
| `Super + Ctrl + V`           | Manaidsear an stòr-bhùird    |

Mar as trice air Linux, feumaidh tu `Ctrl + Shift + C/V` gus lethbhreac a dhèanamh 's a chur ann san tèirmineal agus `Ctrl + C/V` gus a dhèanamh anns a h-uile àite eile. Obraichidh iuchraichean-grada aonaichte an stòr-bhùird aig Omarchy anns a h-uile àite.

| ------------------- | ------------------------------ |
| `Print Screen`            | Glacadh-sgrìn                      |

| `Super + Alt + [` | Lùghdaich tar-chòmhdachadh a' chamara-lìn fhad 's a tha thu a' clàradh |
| `Super + Alt + ]` | Meudaich tar-chòmhdachadh a' chamara-lìn fhad 's a tha thu a' clàradh |

Le clàradh na sgrìn, faighnichidh an iuchair-ghrad dhiot an toiseach dè an fhuaim a tha thu ag iarraidh, agus an uairsin tòisichidh e air clàradh. Brùth oirre a-rithist gus stad. Faic [glacaidhean-sgrìn agus clàradh](12-screenshots-recording.md) airson a' mhion-fhiosrachaidh.

Gheibh thu cuideachd a h-uile roghainn glacaidh fo _Cuir gu dol > Glac_ ann an clàr-taice Omarchy (`Super + Space`).

## Tmux

Is e `Ctrl + Space` an iuchair ro-leasachain (obraichidh `Ctrl + B` cuideachd). Is urrainn dhut na ceanglaichean seo atharrachadh ann an `~/.config/tmux/tmux.conf`.

### Panailean

| Iuchair-ghrad           | Gnìomh                |
| ----------------------- | --------------------- |
| `Prefix + v` | Sgoilt am panail ri thaobh (inghearach) |
| `Prefix + h` | Sgoilt am panail foidhe (còmhnard) |
| `Prefix + x` | Marbh am panail |
| `Prefix + z` | Toglaich sùm a' phanail (làn-sgrìn) |
