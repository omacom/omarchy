# Cuimhneachain

Tha dòigh aig Omarchy na bhroinn fhèin gus cuimhneachain shìmplidh a shuidheachadh stèidhichte air tìmear cunntaidh sìos agus le teachdaireachd. Is urrainn dhut seo a dhèanamh le `Super + Ctrl + R`, a h-uile gin a chaidh a shuidheachadh fhaicinn le `Super + Ctrl + Alt + R`, agus am falamhachadh uile le `Super + Ctrl + Shift + R`. Gheibh thu a h-uile càil cuideachd le _Cuir gu dol > Cuimhneachan_. 'S urrainn dhut an CLI a chleachdadh cuideachd le `omarchy reminder 7 'Tea ready'`.
