# Meabhrúcháin

Tá slí ionsuite ag Omarchy chun meabhrúcháin shimplí a shocrú bunaithe ar lasc ama comhairimh síos agus le teachtaireacht. Is féidir leat é seo a dhéanamh trí `Super + Ctrl + R`, iad uile atá socraithe a fheiceáil trí `Super + Ctrl + Alt + R`, agus iad uile a ghlanadh trí `Super + Ctrl + Shift + R`. Tá gach rud ar fáil freisin trí _Spreag > Meabhrúchán_. Is féidir leat an cli a úsáid freisin le `omarchy reminder 7 'Tea ready'`.
