# Eochracha Aicearra

Is féidir leat na príomhcheangail eochrach go léir a fheiceáil le `Super + K` (ceangail Tmux le `Super + Alt + K` agus ceangail Herdr le `Super + Ctrl + K`).

## Nascleanúint

| Eochair Aicearra                  | Feidhm              |
| ----------------------- | --------------------- |
| `Super + Space`           | Roghchlár Omarchy (aipeanna agus gach rud eile)    |
| `Super + Alt + Space` | Greille aipeanna |
| `Super + Escape` | Roghchlár an chórais (cur ar fionraí, atosú, srl)  |
| `Super + Ctrl + L` | Glasáil an ríomhaire |
| `Super + W` or `Super + Q` | Dún an fhuinneog             |

| `Ctrl + Alt + Tab`| Téigh le fócas ar aghaidh trí na monatóirí |
| `Ctrl + Alt + Shift + Tab`| Téigh le fócas ar gcúl trí na monatóirí |

## Gearrthaisce uilíoch

| Eochair Aicearra                  | Feidhm              |
| ----------------------- | --------------------- |
| `Super + C`           | Cóipeáil    |
| `Super + X`           | Gearr (ní sa teirminéal)    |
| `Super + V`           | Greamaigh    |
| `Super + Ctrl + V`           | Bainisteoir na gearrthaisce    |

De ghnáth ar Linux, bíonn `Ctrl + Shift + C/V` ag teastáil uait chun cóipeáil is greamú a dhéanamh sa teirminéal agus `Ctrl + C/V` chun é a dhéanamh i ngach áit eile. Oibríonn na heochracha aicearra gearrthaisce aontaithe Omarchy seo i ngach áit.

## Gabháil

| Eochair Aicearra              | Feidhm                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Gabháil scáileáin                      |
| `Super + Ctrl + Alt + C`            | Gabháil scáileáin (an seat céanna, do mhéarchláir nach bhfuil eochair Print Screen acu) |
| `Super + Ctrl + C` | Roghchlár gabhála |
| `Alt + Print Screen`            | Taifeadadh scáileáin                     |
| `Super + Print Screen` | Roghnóir datha |
| `Super + Ctrl + Print Screen` | Eastóscadh téacs chuig an ngearrthaisce |
| `Super + Alt + [` | Déan an forleagan ceamara gréasáin níos lú agus tú ag taifeadadh |
| `Super + Alt + ]` | Déan an forleagan ceamara gréasáin níos mó agus tú ag taifeadadh |
| `Alt + Shift + L` | Cóipeáil an URL reatha ó webapp nó ó Chromium |
| `Alt + Shift + D` | Íoslódáil an físeán ar an leathanach reatha chuig `~/Videos` |
| `Super + Ctrl + X` | Tosaigh/stop deachtú (teastaíonn _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | Deachtú brú-chun-labhairt (teastaíonn Voxtype nó Superwhisper) |

Le taifeadtaí scáileáin, fiafraíonn an eochair aicearra ar dtús cén fhuaim atá uait, ansin tosaíonn an taifeadadh. Buail arís í chun stopadh. Féach [gabhálacha scáileáin agus taifeadadh](12-screenshots-recording.md) le haghaidh na sonraí.

Tá na roghanna gabhála go léir inrochtana freisin faoi _Trigger > Capture_ i roghchlár Omarchy (`Super + Space`).

## Tmux

Is í an eochair réimíre ná `Ctrl + Space` (oibríonn `Ctrl + B` freisin). Is féidir leat na ceangail seo a athrú in `~/.config/tmux/tmux.conf`.

### Pánaí

| Eochair Aicearra                  | Feidhm              |
| ----------------------- | --------------------- |
| `Prefix + v` | Scoilt an pána in aice leis (ingearach) |
| `Prefix + h` | Scoilt an pána thíos (cothrománach) |
| `Prefix + x` | Maraigh an pána |
| `Prefix + z` | Scoránaigh zúmáil an phána (scáileán iomlán) |
| `Alt + Enter` | Scoilt an pána thíos (gan réimír) |
| `Alt + Shift + Enter` | Scoilt an pána in aice leis (gan réimír) |
| `Alt + Escape` | Maraigh an pána (gan réimír) |
| `Ctrl + Alt + Arrows` | Bog idir pánaí |
| `Ctrl + Alt + Shift + Arrows` | Athraigh méid na bpánaí |

### Fuinneoga

| Eochair Aicearra                  | Feidhm              |
| ----------------------- | --------------------- |
| `Prefix + c` | Fuinneog nua |
| `Prefix + k` | Maraigh an fhuinneog |

| `Alt + 1-9` | Téigh chuig fuinneog ar leith |
