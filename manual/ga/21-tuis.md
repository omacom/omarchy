# TUIs

## Lazygit

Is rogha aoibhinn é [Lazygit](https://github.com/jesseduffield/lazygit) in ionad rud éigin cosúil leis an bhfeidhmchlár GitHub Desktop, agus ritheann sé taobh istigh den teirminéal.

Is féidir leat é a rith go díreach, trí dhul go dtí aon eolaire arna bhainistiú ag git agus `lazygit` a rith. Nó is féidir leat é a rith taobh istigh de Neovim áit ar féidir é a thosú le `Space G G`.

Léimeann tú idir na pánaí éagsúla ag úsáid `Tab`. Sa phána Files, roghnaíonn tú comhaid le haghaidh stáitsithe ag úsáid `Space`, agus ansin is féidir leat commit nua a chruthú ag úsáid `c`. Is féidir leat na horduithe go léir atá ar fáil a fheiceáil ag úsáid `?`.

## Btop

Is bainisteoir acmhainní álainn é [Btop](https://github.com/aristocratos/btop) a thaispeánann úsáid chuimhne, CPU, diosca, agus líonra. Liostaíonn sé na próisis ghníomhacha go léir freisin, agus ligeann sé duit iad a bhainistiú.

Glaonn Omarchy Activity Monitor air, agus tosaíonn tú é ón lainseálaí feidhmchlár nó trí `Super + Shift + T` a bhrú. Osclaíonn sé mar fhuinneog ar foluain, ar féidir leat a thíliú le `Super + T`.

## Herdr

Is bainisteoir spás oibre teirminéil é [Herdr](https://github.com/omacom-io/herdr) a thugann spásanna oibre, cluaisíní, agus pánaí duit, agus a choinníonn iad go léir ag rith i seisiún leanúnach ar féidir leat dícheangal uaidh agus teacht ar ais chuige níos déanaí.

Tosaíonn tú é (nó athcheanglaíonn tú le do sheisiún reatha) ón lainseálaí feidhmchlár nó le `Super + Ctrl + Return`. Soláthraíonn Omarchy cumraíocht Herdr a léiríonn a chumraíocht Tmux, mar sin is é `Ctrl + Space` an eochair réimíre anseo freisin. Is féidir leat na ceangail eochrach go léir a bhrabhsáil le `Super + Ctrl + K`.

## Fastfetch

Taispeánann [Fastfetch](https://github.com/fastfetch-cli/fastfetch) faisnéis faoin gcóras, cosúil le leagan an eithne, aga fónaimh, téama, CPU, cuimhne, agus tuilleadh. Is comharba é ar an uirlis mhóréilimh neofetch.

Tá sé seo pacáistithe ag Omarchy mar _System > About_ sa roghchlár Omarchy (`Super + Space`).

## Cliamp

Is seinnteoir ceoil teirminéil retro é [Cliamp](https://www.cliamp.stream/) arna spreagadh ag Winamp 2.x, le stáisiúin raidió ionsuite le haghaidh buillí lo-fi. Lainseáil é le `Super + Shift + Alt + M`, nó ón roghchlár Omarchy faoi _Apps_. Brúigh `?` le haghaidh liosta iomlán na gceangal eochrach.

## Cad faoi Wi-Fi agus Bluetooth?

Ní bhfaighidh tú TUIanna le haghaidh Wi-Fi agus Bluetooth — baineann na poist sin le blaosc Omarchy. Cliceáil an deilbhín Wi-Fi sa bharra uachtarach (nó brúigh `Super + Ctrl + N`) chun líonraí a fheiceáil agus ceangal a dhéanamh, agus cliceáil an deilbhín Bluetooth (nó brúigh `Super + Ctrl + B`) chun gléasanna a phéireáil agus a cheangal. Féach [líonrú](35-networking.md) le haghaidh an scéil iomláin.

## Do chuid féin a chur leis

Is féidir le haon chlár teirminéil an chóireáil iomlán feidhmchláir a fháil. Téigh go _Install > TUI_ sa roghchlár Omarchy (`Super + Space`), tabhair ainm dó, ordú lainseála, stíl fuinneoige, agus deilbhín, agus taispeánfar é sa lainseálaí feidhmchlár cosúil le haon fheidhmchlár eile. Is féidir leat é a bhaint arís faoi _Remove > TUI_.
