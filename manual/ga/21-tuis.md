# TUIs

## Lazygit

Is rogha dhraíochtúil é [Lazygit](https://github.com/jesseduffield/lazygit) ar rud éigin cosúil leis an bhfeidhmchlár GitHub Desktop, agus ritheann sé taobh istigh den teirminéal.

Is féidir leat é a rith go díreach, trí dhul go dtí aon eolaire atá á bhainistiú ag git agus `lazygit` a rith. Nó is féidir leat é a rith taobh istigh de Neovim áit ar féidir é a thosú le `Space G G`.

Léimeann tú idir na pannaí éagsúla le `Tab`. Sa phána Files, roghnaíonn tú comhaid le cur ar stáitse le `Space`, agus ansin is féidir leat commit nua a chruthú le `c`. Is féidir leat na horduithe uile atá ar fáil a fheiceáil le `?`.

## Btop

Is bainisteoir acmhainní álainn é [Btop](https://github.com/aristocratos/btop) a thaispeánann úsáid chuimhne, CPU, diosca agus líonra. Liostaíonn sé na próisis ghníomhacha uile freisin, agus ligeann sé duit iad a bhainistiú.

Tugann Omarchy Activity air, agus tosaíonn tú é trí `Super + Shift + T` a bhrú. Osclaíonn sé mar fhuinneog ar snámh, ar féidir leat tíl a dhéanamh di le `Super + T`.

## Herdr

Is bainisteoir spás oibre teirminéil é [Herdr](https://github.com/omacom-io/herdr) a thugann spásanna oibre, cluaisíní agus pannaí duit, agus a choinníonn iad uile ag rith i seisiún seasmhach ar féidir leat scaradh uaidh agus filleadh air níos déanaí.

Tosaíonn tú é (nó athcheanglaíonn tú le do sheisiún reatha) le `Super + Ctrl + Return`. Soláthraíonn Omarchy cumraíocht Herdr a dhéanann scáthánú ar a chumraíocht Tmux, mar sin is í `Ctrl + Space` an eochair réimíre anseo freisin. Is féidir leat na ceangail eochrach uile a bhrabhsáil le `Super + Ctrl + K`.

## Fastfetch

Taispeánann [Fastfetch](https://github.com/fastfetch-cli/fastfetch) faisnéis chórais, cosúil le leagan na heithne, aga fónaimh, téama, CPU, cuimhne, agus tuilleadh. Is comharba é ar an uirlis cháiliúil neofetch.

Tá sé seo pacáistithe ag Omarchy mar _About_ i roghchlár Omarchy (`Super + Space`).

## Cliamp

Is seinnteoir ceoil teirminéil retro é [Cliamp](https://www.cliamp.stream/) atá spreagtha ag Winamp 2.x, ina bhfuil stáisiúin raidió ionsuite le haghaidh buillí lo-fi. Seol é le `Super + Shift + Alt + M`, nó ó roghchlár Omarchy faoi _Apps_. Brúigh `?` le haghaidh liosta iomlán na gceangal eochrach.

## Cad faoi Wi-Fi agus Bluetooth?

Ní bhfaighidh tú TUIanna le haghaidh Wi-Fi agus Bluetooth — is leis an mblaosc Omarchy na poist sin. Cliceáil ar an deilbhín Wi-Fi sa bharra uachtarach (nó brúigh `Super + Ctrl + N`) chun líonraí a fheiceáil agus ceangal leo, agus cliceáil ar an deilbhín Bluetooth (nó brúigh `Super + Ctrl + B`) chun gléasanna a phéireáil agus a cheangal. Féach [líonrú](35-networking.md) le haghaidh an scéil iomláin.

## Do chuid féin a chur leis

Is féidir le haon chlár teirminéil an chóireáil iomlán feidhmchláir a fháil. Téigh go _Install > TUI_ i roghchlár Omarchy (`Super + Space`), tabhair ainm dó, ordú seolta, stíl fuinneoige, agus deilbhín, agus beidh sé le feiceáil sa tosaitheoir feidhmchlár díreach cosúil le haon fheidhmchlár eile. Is féidir leat é a bhaint arís faoi _Remove > TUI_.
