# TUIs

## Lazygit

Is rogha aoibhinn é [Lazygit](https://github.com/jesseduffield/lazygit) seachas rud éigin cosúil le feidhmchlár GitHub Desktop, agus ritheann sé taobh istigh den teirminéal.

Is féidir leat é a rith go díreach, trí dhul go dtí aon eolaire atá á bhainistiú ag git agus `lazygit` a rith. Nó is féidir leat é a rith taobh istigh de Neovim, áit ar féidir é a thosú le `Space G G`.

Bogann tú idir na pánaí éagsúla le `Tab`. Sa phána Files, roghnaíonn tú comhaid le haghaidh stáitsithe le `Space`, agus ansin is féidir leat commit nua a chruthú le `c`. Is féidir leat na horduithe go léir atá ar fáil a fheiceáil le `?`.

## Btop

Is bainisteoir acmhainní álainn é [Btop](https://github.com/aristocratos/btop) a thaispeánann úsáid chuimhne, CPU, diosca agus líonra. Liostaíonn sé na próisis ghníomhacha go léir freisin, agus ligeann sé duit iad a bhainistiú.

Tugann Omarchy Activity Monitor air, agus tosaíonn tú é ón tosaitheoir aipeanna nó trí `Super + Shift + T` a bhrú. Osclaíonn sé mar fhuinneog ar snámh, ar féidir leat a thíliú le `Super + T`.

## Herdr

Is bainisteoir spásanna oibre teirminéil é [Herdr](https://github.com/omacom-io/herdr) a thugann spásanna oibre, cluaisíní agus pánaí duit, agus a choinníonn iad go léir ag rith i seisiún seasmhach ar féidir leat scaradh uaidh agus filleadh air níos déanaí.

Tosaíonn tú é (nó athcheanglaíonn tú le do sheisiún reatha) le `Super + Ctrl + Return`. Cuireann Omarchy cumraíocht Herdr ar fáil a fhrithchaitheann a chumraíocht Tmux, mar sin is í `Ctrl + Space` an eochair réimíre anseo freisin. Is féidir leat na ceangail eochrach go léir a bhrabhsáil le `Super + Ctrl + K`.

## Fastfetch

Taispeánann [Fastfetch](https://github.com/fastfetch-cli/fastfetch) faisnéis faoin gcóras, cosúil le leagan an eithne, aga oibriúcháin, téama, CPU, cuimhne, agus tuilleadh. Is comharba é ar an uirlis neofetch a bhfuil tóir uirthi.

Tá sé seo pacáistithe ag Omarchy mar _About_ sa roghchlár Omarchy (`Super + Space`).

## Cliamp

Is seinnteoir ceoil teirminéil retro é [Cliamp](https://www.cliamp.stream/), spreagtha ag Winamp 2.x, ina bhfuil stáisiúin raidió ionsuite le haghaidh buillí lo-fi. Seol é le `Super + Shift + Alt + M`, nó ón roghchlár Omarchy faoi _Apps_. Brúigh `?` chun liosta iomlán na gceangal eochrach a fheiceáil.

## Cad faoi Wi-Fi agus Bluetooth?

Ní bhfaighidh tú TUIs le haghaidh Wi-Fi agus Bluetooth — baineann na poist sin le blaosc Omarchy. Cliceáil ar an deilbhín Wi-Fi sa bharra uachtarach (nó brúigh `Super + Ctrl + N`) chun líonraí a fheiceáil agus ceangal a dhéanamh, agus cliceáil ar an deilbhín Bluetooth (nó brúigh `Super + Ctrl + B`) chun gléasanna a phéireáil agus a cheangal. Féach [líonrú](35-networking.md) chun an scéal iomlán a fháil.

## Do cheann féin a chur leis

Is féidir le haon chlár teirminéil an chóireáil iomlán mar aip a fháil. Téigh go _Install > TUI_ sa roghchlár Omarchy (`Super + Space`), tabhair ainm dó, ordú seolta, stíl fuinneoige, agus deilbhín, agus beidh sé le feiceáil sa tosaitheoir aipeanna díreach cosúil le haon fheidhmchlár eile. Is féidir leat é a bhaint arís faoi _Remove > TUI_.
