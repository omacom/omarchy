# Dreceres de teclat

Pots veure totes les dreceres de teclat principals amb `Super + K` (les dreceres de Tmux amb `Super + Alt + K` i les de Herdr amb `Super + Ctrl + K`).

## Navegació

| Drecera                  | Funció              |
| ----------------------- | --------------------- |
| `Super + Space`           | Menú d'Omarchy (aplicacions i tota la resta)    |
| `Super + Alt + Space` | Graella d'aplicacions |
| `Super + Escape` | Menú del sistema (suspèn, reinicia, etc.)  |
| `Super + Ctrl + L` | Bloqueja l'ordinador |
| `Super + W` or `Super + Q` | Tanca la finestra             |
| `Ctrl + Alt + Del` | Tanca totes les finestres |
| `Super + T`               | Commuta la finestra entre mosaic/flotant             |
| `Super + J` | Commuta la posició de la finestra (horitzontal/vertical) |
| `Super + O`               | Commuta la finestra emergent a fixa i flotant |
| `Super + L`               | Passa pels dissenys dwindle, scrolling i flotant en cicle |
| `Super + Alt + L`         | Passa pels dissenys en ordre invers en cicle |
| `Super + P`               | Commuta l'estil pseudo de la finestra (natural vs. estirat) |
| `Super + F`                 | Passa a pantalla completa              |
| `Super + Alt + F`                 | Passa a amplada completa              |
| `Super + Ctrl + F`                 | Passa a pantalla completa dins de la finestra              |
| `Super + 1/2/3/4`         | Salta a un espai de treball concret al monitor amb el focus |
| `Super + Tab` | Salta a l'espai de treball següent al monitor amb el focus |
| `Super + Shift + Tab` | Salta a l'espai de treball anterior al monitor amb el focus |
| `Super + Ctrl + Tab` | Salta a l'espai de treball previ al monitor amb el focus |
| `Super + Shift + 1/2/3/4` | Mou la finestra a l'espai de treball al monitor amb el focus |
| `Super + Shift + Alt + 1/2/3/4` | Mou la finestra a l'espai de treball al monitor amb el focus sense seguir-la |
| `Super + S` | Commuta l'scratchpad complet |
| `Super + Alt + S` | Mou la finestra a l'scratchpad complet |
| `Super + Grave` | Commuta la consola Quake |
| `Super + Shift + Grave` | Mou la finestra a la consola Quake |
| `Super + Shift + Ctrl + Arrows` | Mou la finestra cap al monitor en aquella direcció |
| `Super + Shift + Alt + Arrows` | Mou l'espai de treball cap al monitor en aquella direcció |
| `Super + Arrow`  | Mou el focus a la finestra en la direcció de la fletxa, i creua al monitor d'aquell costat a la vora de la pantalla |
| `Super + Shift + Arrow`  | Intercanvia la finestra amb una altra en la direcció de la fletxa, inclosa una al monitor d'aquell costat |
| `Super + Minus` | Eixampla la finestra cap a l'esquerra |
| `Super + Equal` | Encongeix la finestra cap a l'esquerra |
| `Super + Shift + Minus` | Encongeix la finestra cap amunt |
| `Super + Shift + Equal` | Eixampla la finestra cap avall |
| `Super + Alt + Minus/Equal` | El mateix redimensionament en passos més petits |
| `Super + Ctrl + Minus/Equal` | El mateix redimensionament en passos més grans |
| `Super + Alt + Home` | Desa l'amplada de la finestra |
| `Super + Home` | Restaura l'amplada desada de la finestra |
| `Super + Left Mouse` | Arrossega la finestra |
| `Super + Right Mouse` | Redimensiona la finestra |
| `Super + Scroll Wheel` | Desplaça't pels espais de treball al monitor amb el focus |
| `Super + G`               | Commuta l'agrupament de finestres      |
| `Super + Alt + G`               | Treu la finestra de l'agrupament      |
| `Super + Alt + Tab`               | Passa per les finestres de l'agrupament en cicle      |
| `Super + Alt + Shift + Tab`               | Passa enrere per les finestres de l'agrupament en cicle      |
| `Super + Alt + Scroll Wheel` | Passa per les finestres de l'agrupament en cicle |
| `Super + Alt + 1/2/3/4/5`               | Salta a una finestra concreta de l'agrupament      |
| `Super + Alt + Arrow`  | Mou la finestra a l'agrupament en la direcció de la fletxa, inclosa una al monitor d'aquell costat |
| `Super + Ctrl + Left/Right`  | Mou-te entre finestres dins d'un grup en mosaic |
| `Super + Ctrl + Z` | Amplia la pantalla (repeteix per ampliar més) |
| `Super + Ctrl + Alt + Z` | Allunya completament la pantalla |
| `Super + /` | Avança per les opcions d'escalat del monitor |
| `Super + Alt + /` | Retrocedeix per les opcions d'escalat del monitor |
| `Alt + Tab` | Passa endavant per les finestres de l'espai de treball actiu en cicle |
| `Alt + Shift + Tab` | Passa enrere per les finestres de l'espai de treball actiu en cicle |
| `Ctrl + Alt + Tab`| Passa el focus endavant pels monitors en cicle |
| `Ctrl + Alt + Shift + Tab`| Passa el focus enrere pels monitors en cicle |

## Porta-retalls universal

| Drecera                  | Funció              |
| ----------------------- | --------------------- |
| `Super + C`           | Copia    |
| `Super + X`           | Retalla (no al terminal)    |
| `Super + V`           | Enganxa    |
| `Super + Ctrl + V`           | Gestor del porta-retalls    |

Normalment a Linux, necessites `Ctrl + Shift + C/V` per copiar i enganxar al terminal i `Ctrl + C/V` per fer-ho a tot arreu. Aquestes dreceres unificades del porta-retalls d'Omarchy funcionen a tot arreu.

## Captura

| Drecera              | Funció                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Captura de pantalla                      |
| `Super + Ctrl + Alt + C`            | Captura de pantalla (la mateixa captura, per a teclats sense tecla Print Screen) |
| `Super + Ctrl + C` | Menú de captura |
| `Alt + Print Screen`            | Gravació de pantalla                     |
| `Super + Print Screen` | Selector de color |
| `Super + Ctrl + Print Screen` | Extracció de text al porta-retalls |
| `Super + Alt + [` | Fes més petita la superposició de la càmera web mentre graves |
| `Super + Alt + ]` | Fes més gran la superposició de la càmera web mentre graves |
| `Alt + Shift + L` | Copia l'URL actual des d'una webapp o de Chromium |
| `Alt + Shift + D` | Baixa el vídeo de la pàgina actual a `~/Videos` |
| `Super + Ctrl + X` | Inicia/atura el dictat (requereix _Configuració > Valors per defecte > Dictat_) |
| `Right Alt` / `F9` | Dictat amb polsador per parlar (requereix Voxtype o Superwhisper) |

Amb les gravacions de pantalla, la drecera primer et pregunta quin àudio vols, després comença a gravar. Prem-la de nou per aturar-la. Consulta [captures de pantalla i gravació](12-screenshots-recording.md) per als detalls.

Totes les opcions de captura també són accessibles a _Activador > Captura_ al menú d'Omarchy (`Super + Space`).

## Tmux

La tecla de prefix és `Ctrl + Space` (`Ctrl + B` també funciona). Pots canviar aquestes dreceres a `~/.config/tmux/tmux.conf`.

### Panells

| Drecera                  | Funció              |
| ----------------------- | --------------------- |
| `Prefix + v` | Divideix el panell al costat (vertical) |
| `Prefix + h` | Divideix el panell a sota (horitzontal) |
| `Prefix + x` | Mata el panell |
| `Prefix + z` | Commuta el zoom del panell (pantalla completa) |
| `Alt + Enter` | Divideix el panell a sota (sense prefix) |
| `Alt + Shift + Enter` | Divideix el panell al costat (sense prefix) |
| `Alt + Escape` | Mata el panell (sense prefix) |
| `Ctrl + Alt + Arrows` | Mou-te entre panells |
| `Ctrl + Alt + Shift + Arrows` | Redimensiona els panells |

### Finestres

| Drecera                  | Funció              |
| ----------------------- | --------------------- |
| `Prefix + c` | Nova finestra |
| `Prefix + k` | Mata la finestra |
| `Prefix + r` | Reanomena la finestra |
| `Alt + 1-9` | Vés a una finestra concreta |
| `Alt + Arrow Left/Right` | Mou-te entre finestres |
| `Alt + Shift + Arrow Left/Right` | Mou la finestra a l'esquerra/dreta |

### Sessions

| Drecera                  | Funció              |
| ----------------------- | --------------------- |
| `Prefix + C` | Nova sessió |
| `Prefix + K` | Mata la sessió |
| `Prefix + R` | Reanomena la sessió |
| `Prefix + N` | Sessió següent |
| `Prefix + P` | Sessió anterior |
| `Alt + Arrow Up/Down` | Mou-te entre sessions |
| `Prefix + s` | Llista les sessions |
| `Prefix + d` | Desconnecta't de la sessió |

### Mode de còpia (estil vi)

| Drecera                  | Funció              |
| ----------------------- | --------------------- |
| `Prefix + [` | Entra al mode de còpia |
| `v` | Comença la selecció (al mode de còpia) |
| `y` | Copia la selecció (al mode de còpia) |

### General

| Drecera                  | Funció              |
| ----------------------- | --------------------- |
| `Prefix + q` | Recarrega la configuració |
| `Prefix + ?` | Mostra les dreceres de Tmux |
| `Prefix + :` | Indicador d'ordres |

### Funcions de disseny de Tmux

Aquestes funcions s'han d'executar dins d'una sessió de Tmux.

| Ordre | Funció |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Crea un disseny de desenvolupament amb editor, AI i terminal |
| `tdlm <ai> [<second_ai>]` | Crea un disseny de desenvolupament per subdirectori |
| `tsl <count> <command>` | Crea un disseny d'eixam amb diversos panells |
