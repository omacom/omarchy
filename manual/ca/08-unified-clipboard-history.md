# Porta-retalls i historial unificats

Normalment a Linux, necessites `Ctrl + Shift + C/V` per copiar i enganjar al terminal i `Ctrl + C/V` per fer-ho a tot arreu. Això costa d'aprendre a qualsevol que no hagi nascut i crescut amb Linux! I també costa passar de super a ctrl, si vens del Mac.

Omarchy resol tots dos problemes amb dreceres de porta-retalls unificades que funcionen (gairebé) a tot arreu. Són:

| Hotkey | Command |
| ------- | ----------- |
| Super + A | Selecciona-ho tot |
| Super + C | Copia |
| Super + X | Retalla |
| Super + V | Enganxa |
| Super + Ctrl + V | Historial del porta-retalls |

_Tingues en compte que la majoria d'arnesos d'agents faran servir `Ctrl + V` per enganjar imatges, però `Super + V` per enganjar text._

Fes servir `Super + A` i després `Super + C` per copiar-ho tot en un camp de text amb el focus o en una altra aplicació que admeti `Ctrl + A`. En un terminal, `Ctrl + A` porta al principi de la línia d'ordres en lloc de seleccionar-ne el text.

### Historial del porta-retalls

L'historial del porta-retalls el proporciona el shell d'Omarchy i funciona tant amb text com amb imatges. L'actives amb `Super + Ctrl + V`, selecciones l'entrada amb Retorn i, a continuació, es col·locarà al porta-retalls, a punt per enganxar-la amb `Super + V`.
