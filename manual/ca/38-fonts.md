# Tipus de lletra

Omarchy utilitza JetBrainsMono Nerd Font com a tipus de lletra tant del terminal com del sistema per defecte.

 ![fonts-jetbrainsmono](images/fonts-jetbrainsmono.webp)

Pots canviar-ho mitjançant el menú _Aparença > Tipus de lletra_ del menú d'Omarchy (`Super + Space`). Això estableix el tipus de lletra monoespaiat a tot arreu: el terminal, la barra i qualsevol altra cosa que el demani.

Pots instal·lar altres tipus de lletra de programació populars mitjançant _Instal·la > Estil > Tipus de lletra_ al menú d'Omarchy: Cascadia Mono, Meslo LG Mono, Fira Code, Victor Code, Bitstream Vera Mono i Iosevka són a un sol clic de distància, en les seves versions Nerd Font perquè els glifs de la barra i del terminal continuïn funcionant. Després d'instal·lar-ne un, tria'l a _Aparença > Tipus de lletra_.

## Xinès, japonès i coreà

El xinès, el japonès i el coreà comparteixen molts caràcters, però en dibuixen alguns de manera diferent, de manera que el mateix caràcter sembla correcte a un lector i estrany a un altre. Triar una d'aquestes llengües a _Configuració > Idioma_, o el seu mètode d'entrada, estableix les formes corresponents. Per triar-les tu mateix, executa `omarchy font cjk jp`, `kr`, `sc`, `tc` (Taiwan) o `hk` (Hong Kong) en un terminal; `omarchy font cjk default` torna a l'elecció del sistema, que són les formes japoneses. El text que una pàgina web o un document marca amb el seu propi idioma, i tot l'escriptori mentre està en una d'aquestes llengües, manté les formes d'aquella llengua.
