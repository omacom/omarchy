# Altres paquets

Arch té una riquesa increïble de paquets disponibles per a gairebé qualsevol mena de programari entre el repositori oficial i l'Arch User Repository (AUR).

No podria ser més fàcil de fer servir, tampoc. Instal·les un nou paquet d'Arch anant a _Instal·la > Paquet_ al menú d'Omarchy (`Super + Space`) i escrivint el paquet que vols. Filtrarà automàticament de manera difusa la llista de tots els paquets. (També ho pots fer manualment amb `omarchy pkg add [package]` al terminal).

Pots fer el mateix amb l'AUR, només fes servir _Instal·la > AUR_. Només recorda que l'AUR no l'ha revisat l'equip d'Arch. És com RubyGems o npm. Qualsevol hi pot pujar coses.

Si vols eliminar un paquet, pots fer servir _Elimina > Paquet_ des del menú d'Omarchy. Eliminarà el paquet, els fitxers de configuració i les dependències. (També ho pots fer manualment amb `omarchy pkg drop [package]`).
