# Recordatoris

Omarchy té una manera integrada de crear recordatoris senzills basats en un temporitzador de compte enrere i amb un missatge. Podeu fer-ho amb `Super + Ctrl + R`, veure tots els que heu creat amb `Super + Ctrl + Alt + R` i esborrar-los tots amb `Super + Ctrl + Shift + R`. Tot també és accessible a _Activa > Recordatori_. També podeu fer servir la cli amb `omarchy reminder 7 'Tea ready'`.
