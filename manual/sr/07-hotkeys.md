# Тастерске пречице

Све главне тастерске везе можете видети са `Super + K` (Tmux везе са `Super + Alt + K`, а Herdr везе са `Super + Ctrl + K`).

## Како су распоређене пречице

Свака пречица се налази на једној равни, коју одређују њени модификатори, и свака раван има један посао. То спречава да се пречице стапају једна у другу и значи да обично можете погодити где се нешто налази.

| Раван | Шта се тамо налази | Примери |
| --- | --- | --- |
| `Super + key` | Систем: прозори, радни простори, распореди и основни менији | `Super + Space` Omarchy мени, `Super + W` затвори прозор, `Super + F` цео екран |
| `Super + Shift + key` | Апликације | `Super + Shift + B` прегледач, `Super + Shift + E` е-пошта, `Super + Shift + N` уређивач |
| `Super + Ctrl + key` | Панели и системски менији | `Super + Ctrl + A` аудио, `Super + Ctrl + N` мрежа, `Super + Ctrl + C` мени за снимање |
| `Super + Ctrl + Alt + key` | Брзе радње и обавештења | `Super + Ctrl + Alt + T` прикажи време, `Super + Ctrl + Alt + B` батерија, `Super + Ctrl + Alt + C` снимак екрана |

Додавање `Alt` пречици даје вам варијанту исте ствари, никада нешто неповезно:

- `Super + Shift + B` отвара прегледач; `Super + Shift + Alt + B` отвара приватни прозор
- `Super + Shift + E` отвара е-пошту; `Super + Shift + Alt + E` започиње нову
- `Super + F` прелази на цео екран; `Super + Alt + F` прелази на пуну ширину
- `Super + Ctrl + C` отвара мени за снимање; `Super + Ctrl + Alt + C` прескаче мени и прави снимак екрана

Када додајете пречицу:

1. Изаберите раван према томе шта ради, затим изаберите тастер.
2. Немојте померати постојећу пречицу да бисте направили места. Пронађите слободан тастер на правој равни.
3. `Alt` користите само за варијанту пречице без њега.

Неколико пречица крши ова правила јер су згодне. `Shift` са стрелицом или `Tab` помера или иде уназад, уместо да отвара апликацију, а `Print`, медијски тастери, `Alt + Tab` и `Ctrl + Alt + Del` раде онако како раде свуда другде. Они су изузеци, а не обрасци за копирање.

Ако вам нека подразумевана не одговара (рецимо да желите `Super + Shift + S` за снимке екрана као на Windows-у), промените је у `~/.config/hypr/bindings.lua`.

| Пречица | Функција |
| ----------------------- | --------------------- |
| `Super + Space` | Omarchy мени (апликације и све остало) |
| `Super + Alt + Space` | Мрежа апликација |
| `Super + Escape` | Системски мени (обустава, поновно покретање, итд.) |

| `Super + O` | Укључи/искључи пребацивање прозора у лепљиви и лебдећи режим |

| `Super + Alt + L` | Кружно мењај распореде уназад |

| `Super + Tab` | Скочи на следећи радни простор на фокусираном монитору |
| `Super + Shift + Tab` | Скочи на претходни радни простор на фокусираном монитору |
| `Super + Ctrl + Tab` | Скочи на ранији радни простор на фокусираном монитору |
| `Super + Shift + 1/2/3/4` | Помери прозор на радни простор на фокусираном монитору |
| `Super + Shift + Alt + 1/2/3/4` | Помери прозор на радни простор на фокусираном монитору без праћења |
| `Super + S` | Укључи/искључи цео scratchpad |
| `Super + Alt + S` | Помери прозор на цео scratchpad |
| `Super + Grave` | Укључи/искључи Quake конзолу |
| `Super + Shift + Grave` | Помери прозор у Quake конзолу |
| `Super + Shift + Ctrl + Arrows` | Помери прозор на монитор у том правцу |
| `Super + Shift + Alt + Arrows` | Помери радни простор на монитор у том правцу |
| `Super + Arrow` | Помери фокус на прозор у правцу стрелице, прелазећи на монитор са те стране на ивици екрана |
| `Super + Shift + Arrow` | Замени прозор са другим у правцу стрелице, укључујући онај на монитору са те стране |
| `Super + Minus` | Прошири прозор улево |
| `Super + Equal` | Смањи прозор улево |
| `Super + Shift + Minus` | Смањи прозор нагоре |
| `Super + Shift + Equal` | Прошири прозор надоле |
| `Super + Alt + Minus/Equal` | Исто мењање величине у мањим корацима |
| `Super + Ctrl + Minus/Equal` | Исто мењање величине у већим корацима |
| `Super + Alt + Home` | Сачувај ширину прозора |
| `Super + Home` | Врати сачувану ширину прозора |
| `Super + Left Mouse` | Превуци прозор |
| `Super + Right Mouse` | Промени величину прозора |
| `Super + Scroll Wheel` | Скролуј кроз радне просторе на фокусираном монитору |
| `Super + G` | Укључи/искључи груписање прозора |
| `Super + Alt + G` | Извади прозор из групе |
| `Super + Alt + Tab` | Кружно прелази између прозора у групи |
| `Super + Alt + Shift + Tab` | Кружно прелази уназад између прозора у групи |
| `Super + Alt + Scroll Wheel` | Кружно прелази између прозора у групи |
| `Super + Alt + 1/2/3/4/5` | Скочи на одређени прозор у групи |
| `Super + Alt + Arrow` | Помери прозор у групу у правцу стрелице, укључујући онај на монитору са те стране |
| `Super + Ctrl + Left/Right` | Крећи се између прозора унутар поплочане групе |
| `Super + Ctrl + Z` | Зумирај екран (понови за више зумирања) |
| `Super + Ctrl + Alt + Z` | Потпуно одзумирај екран |
| `Super + /` | Корак напред кроз опције скалирања монитора |
| `Super + Alt + /` | Корак уназад кроз опције скалирања монитора |
| `Alt + Tab` | Кружно прелази унапред кроз прозоре на активном радном простору |
| `Alt + Shift + Tab` | Кружно прелази уназад кроз прозоре на активном радном простору |
| `Ctrl + Alt + Tab` | Кружно померај фокус унапред кроз мониторе |
| `Ctrl + Alt + Shift + Tab` | Кружно померај фокус уназад кроз мониторе |

Пречице за мењање величине користе физичке тастере `code:20` и `code:21` (XKB `<AE11>` и `<AE12>`), без обзира на знакове одштампане на тастатури. На америчким тастатурама ти тастери су `-` и `=`; на јапанским (JIS) тастатурама су `-` и `^`; на шпанским тастатурама су `'` и `¡`. На JIS тастатури, `Super + ^` је `Super + Equal`, док је `Super + Shift + -` (којим се куца `=`) `Super + Shift + Minus`.
