# Пречице на тастатури

Све главне пречице на тастатури можете видети помоћу `Super + K` (Tmux пречице помоћу `Super + Alt + K`, а Herdr пречице помоћу `Super + Ctrl + K`).

## Навигација

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy мени (апликације и све остало)    |
| `Super + Alt + Space` | Мрежа апликација |
| `Super + Escape` | Системски мени (обустава, поновно покретање итд.)  |
| `Super + Ctrl + L` | Закључај рачунар |
| `Super + W` or `Super + Q` | Затвори прозор             |
| `Ctrl + Alt + Del` | Затвори све прозоре |
| `Super + T`               | Пребаци прозор између слагања и плутања             |
| `Super + J` | Пребаци положај прозора (хоризонтално/вертикално) |
| `Super + O`               | Пребаци прозор у искачући лепљиви и плутајући режим |
| `Super + L`               | Кружно прелази кроз распореде dwindle, scrolling и floating |
| `Super + Alt + L`         | Кружно прелази кроз распореде у обрнутом смеру |
| `Super + P`               | Пребаци стил псеудо-прозора (природно наспрам растегнуто) |
| `Super + F`                 | Пређи у цео екран              |
| `Super + Alt + F`                 | Пређи у пуну ширину              |
| `Super + Ctrl + F`                 | Пређи у цео екран унутар прозора              |
| `Super + 1/2/3/4`         | Иди на одређени радни простор на фокусираном монитору |
| `Super + Tab` | Иди на следећи радни простор на фокусираном монитору |
| `Super + Shift + Tab` | Иди на претходни радни простор на фокусираном монитору |
| `Super + Ctrl + Tab` | Иди на ранији радни простор на фокусираном монитору |
| `Super + Shift + 1/2/3/4` | Премести прозор на радни простор на фокусираном монитору |
| `Super + Shift + Alt + 1/2/3/4` | Премести прозор на радни простор на фокусираном монитору без праћења |
| `Super + S` | Укључи/искључи цео scratchpad |
| `Super + Alt + S` | Премести прозор у цео scratchpad |
| `Super + Grave` | Укључи/искључи Quake конзолу |
| `Super + Shift + Grave` | Премести прозор у Quake конзолу |
| `Super + Shift + Ctrl + Arrows` | Премести прозор на монитор у том смеру |
| `Super + Shift + Alt + Arrows` | Премести радни простор на монитор у том смеру |
| `Super + Arrow`  | Премести фокус на прозор у смеру стрелице, прелазећи на монитор са те стране на ивици екрана |
| `Super + Shift + Arrow`  | Замени прозор са другим у смеру стрелице, укључујући онај на монитору са те стране |
| `Super + Minus` | Прошири прозор улево |
| `Super + Equal` | Смањи прозор улево |
| `Super + Shift + Minus` | Смањи прозор нагоре |
| `Super + Shift + Equal` | Прошири прозор надоле |
| `Super + Alt + Minus/Equal` | Исто мењање величине у мањим корацима |
| `Super + Ctrl + Minus/Equal` | Исто мењање величине у већим корацима |
| `Super + Alt + Home` | Сачувај ширину прозора |
| `Super + Home` | Врати сачувану ширину прозора |
| `Super + Left Mouse` | Превуци прозор |
| `Super + Right Mouse` | Промени величину прозора |
| `Super + Scroll Wheel` | Померај се кроз радне просторе на фокусираном монитору |
| `Super + G`               | Укључи/искључи груписање прозора      |
| `Super + Alt + G`               | Избаци прозор из групе      |
| `Super + Alt + Tab`               | Кружно прелази између прозора у групи      |
| `Super + Alt + Shift + Tab`               | Кружно прелази уназад између прозора у групи      |
| `Super + Alt + Scroll Wheel` | Кружно прелази између прозора у групи |
| `Super + Alt + 1/2/3/4/5`               | Иди на одређени прозор у групи      |
| `Super + Alt + Arrow`  | Премести прозор у групу у смеру стрелице, укључујући онај на монитору са те стране |
| `Super + Ctrl + Left/Right`  | Крећи се између прозора унутар групе за слагање |
| `Super + Ctrl + Z` | Увећај приказ на екрану (понови за још веће увећање) |
| `Super + Ctrl + Alt + Z` | Потпуно умањи приказ са екрана |
| `Super + /` | Крећи се унапред кроз опције скалирања монитора |
| `Super + Alt + /` | Крећи се уназад кроз опције скалирања монитора |
| `Alt + Tab` | Кружно прелази унапред кроз прозоре на активном радном простору |
| `Alt + Shift + Tab` | Кружно прелази уназад кроз прозоре на активном радном простору |
| `Ctrl + Alt + Tab`| Кружно премештај фокус унапред кроз мониторе |
| `Ctrl + Alt + Shift + Tab`| Кружно премештај фокус уназад кроз мониторе |

## Универзални међуспремник

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + C`           | Копирај    |
| `Super + X`           | Исеци (није у терминалу)    |
| `Super + V`           | Налепи    |
| `Super + Ctrl + V`           | Менаџер међуспремника    |

Обично на Linux-у треба `Ctrl + Shift + C/V` за копирање и лепљење у терминалу и `Ctrl + C/V` да то радите свуда другде. Ове Omarchy обједињене пречице за међуспремник раде свуда.

## Tmux

Кључ префикса је `Ctrl + Space` (`Ctrl + B` такође ради). Ове пречице можете променити у `~/.config/tmux/tmux.conf`.

### Панели

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + v` | Подели панел бочно (вертикално) |
| `Prefix + h` | Подели панел испод (хоризонтално) |
| `Prefix + x` | Убиј панел |
| `Prefix + z` | Укључи/искључи зумирање панела (цео екран) |
| `Alt + Enter` | Подели панел испод (без префикса) |
| `Alt + Shift + Enter` | Подели панел бочно (без префикса) |
| `Alt + Escape` | Убиј панел (без префикса) |
| `Ctrl + Alt + Arrows` | Крећи се између панела |
| `Ctrl + Alt + Shift + Arrows` | Промени величину панела |

### Прозори

### Tmux функције за распоред

Ове функције морају се покренути унутар Tmux сесије.

| Command | Function |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Направи развојни распоред са уређивачем, AI-јем и терминалом |
