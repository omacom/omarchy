# Пречице

Можете видети све главне пречице на тастатури помоћу `Super + K` (пречице за Tmux помоћу `Super + Alt + K`, а пречице за Herdr помоћу `Super + Ctrl + K`).

## Навигација

| Пречица                  | Функција              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy мени (апликације и све остало)    |
| `Super + Alt + Space` | Мрежа апликација |
| `Super + Escape` | Системски мени (суспендовање, поновно покретање итд.)  |
| `Super + Ctrl + L` | Закључај рачунар |
| `Super + W` or `Super + Q` | Затвори прозор             |
| `Ctrl + Alt + Del` | Затвори све прозоре |
| `Super + T`               | Пребаци прозор између поплочавања и плутања             |
| `Super + J` | Пребаци положај прозора (хоризонтално/вертикално) |
| `Super + O`               | Пребаци искакање прозора у лепљиви и плутајући режим |
| `Super + L`               | Кружно мењај распореде dwindle, scrolling и floating |
| `Super + Alt + L`         | Кружно мењај распореде обрнутим редоследом |
| `Super + P`               | Пребаци pseudo стил прозора (природни наспрам развученог) |
| `Super + F`                 | Пређи на цео екран              |
| `Super + Alt + F`                 | Пређи на пуну ширину              |
| `Super + Ctrl + F`                 | Пређи на цео екран унутар прозора              |
| `Super + 1/2/3/4`         | Скочи на одређени радни простор на монитору у фокусу |
| `Super + Tab` | Скочи на следећи радни простор на монитору у фокусу |
| `Super + Shift + Tab` | Скочи на претходни радни простор на монитору у фокусу |
| `Super + Ctrl + Tab` | Скочи на ранији радни простор на монитору у фокусу |
| `Super + Shift + 1/2/3/4` | Помери прозор на радни простор на монитору у фокусу |
| `Super + Shift + Alt + 1/2/3/4` | Помери прозор на радни простор на монитору у фокусу без праћења |
| `Super + S` | Пребаци пуни scratchpad |
| `Super + Alt + S` | Помери прозор у пуни scratchpad |
| `Super + Grave` | Пребаци Quake конзолу |
| `Super + Shift + Grave` | Помери прозор у Quake конзолу |
| `Super + Shift + Ctrl + Arrows` | Помери прозор на монитор у том смеру |
| `Super + Shift + Alt + Arrows` | Помери радни простор на монитор у том смеру |
| `Super + Arrow`  | Помери фокус на прозор у смеру стрелице, прелазећи на монитор на тој страни на ивици екрана |
| `Super + Shift + Arrow`  | Замени прозор другим у смеру стрелице, укључујући онај на монитору на тој страни |
| `Super + Minus` | Прошири прозор улево |
| `Super + Equal` | Смањи прозор улево |
| `Super + Shift + Minus` | Смањи прозор нагоре |
| `Super + Shift + Equal` | Прошири прозор надоле |
| `Super + Alt + Minus/Equal` | Исто мењање величине у мањим корацима |
| `Super + Ctrl + Minus/Equal` | Исто мењање величине у већим корацима |
| `Super + Alt + Home` | Сачувај ширину прозора |
| `Super + Home` | Врати сачувану ширину прозора |
| `Super + Left Mouse` | Вуци прозор около |
| `Super + Right Mouse` | Мењај величину прозора |
| `Super + Scroll Wheel` | Кролуј кроз радне просторе на монитору у фокусу |
| `Super + G`               | Пребаци груписање прозора      |
| `Super + Alt + G`               | Извади прозор из групе      |
| `Super + Alt + Tab`               | Кружно мењај прозоре у групи      |
| `Super + Alt + Shift + Tab`               | Кружно мењај прозоре у групи уназад      |
| `Super + Alt + Scroll Wheel` | Кружно мењај прозоре у групи |
| `Super + Alt + 1/2/3/4/5`               | Скочи на одређени прозор у групи      |
| `Super + Alt + Arrow`  | Помери прозор у групу у смеру стрелице, укључујући онај на монитору на тој страни |
| `Super + Ctrl + Left/Right`  | Крећи се између прозора унутар групе за поплочавање |
| `Super + Ctrl + Z` | Увећај приказ на екрану (понови за већи зум) |
| `Super + Ctrl + Alt + Z` | Потпуно смањи приказ са екрана |
| `Super + /` | Коракни напред кроз опције скалирања монитора |
| `Super + Alt + /` | Коракни назад кроз опције скалирања монитора |
| `Alt + Tab` | Кружно иди напред кроз прозоре на активном радном простору |
| `Alt + Shift + Tab` | Кружно иди назад кроз прозоре на активном радном простору |
| `Ctrl + Alt + Tab`| Кружно померај фокус напред кроз мониторе |
| `Ctrl + Alt + Shift + Tab`| Кружно померај фокус назад кроз мониторе |

## Универзални клипборд

| Пречица                  | Функција              |
| ----------------------- | --------------------- |
| `Super + C`           | Копирај    |
| `Super + X`           | Исеци (не у терминалу)    |
| `Super + V`           | Налепи    |
| `Super + Ctrl + V`           | Менаџер клипборда    |

Обично на Linux-у морате да користите `Ctrl + Shift + C/V` за копирање и лепљење у терминалу, а `Ctrl + C/V` да то радите свуда другде. Ове Omarchy обједињене пречице за клипборд раде свуда.

## Снимање

| Пречица              | Функција                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Снимак екрана                      |
| `Super + Ctrl + Alt + C`            | Снимак екрана (исти снимак, за тастатуре без тастера Print Screen) |
| `Super + Ctrl + C` | Мени за снимање |
| `Alt + Print Screen`            | Снимање екрана                     |
| `Super + Print Screen` | Бирач боја |
| `Super + Ctrl + Print Screen` | Издвајање текста у клипборд |
| `Super + Alt + [` | Смањи преклоп веб-камере током снимања |
| `Super + Alt + ]` | Повећај преклоп веб-камере током снимања |
| `Alt + Shift + L` | Копирај тренутни URL из веб-апликације или Chromium-а |
| `Alt + Shift + D` | Преузми видео на тренутној страници у `~/Videos` |
| `Super + Ctrl + X` | Покрени/заустави диктирање (захтева _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | Диктирање притиском за разговор (захтева Voxtype или Superwhisper) |

Код снимања екрана, пречица прво пита који звук желите, а затим почиње снимање. Притисните је поново да зауставите. Погледајте [снимци екрана и снимање](12-screenshots-recording.md) за детаље.

Свим опцијама снимања може се приступити и под _Trigger > Capture_ у Omarchy менију (`Super + Space`).

## Tmux

Префиксни тастер је `Ctrl + Space` (`Ctrl + B` такође ради). Ова повезивања можете променити у `~/.config/tmux/tmux.conf`.

### Панели

| Пречица                  | Функција              |
| ----------------------- | --------------------- |
| `Prefix + v` | Подели панел поред (вертикално) |
| `Prefix + h` | Подели панел испод (хоризонтално) |
| `Prefix + x` | Убиј панел |
| `Prefix + z` | Пребаци зум панела (цео екран) |
| `Alt + Enter` | Подели панел испод (без префикса) |
| `Alt + Shift + Enter` | Подели панел поред (без префикса) |
| `Alt + Escape` | Убиј панел (без префикса) |
| `Ctrl + Alt + Arrows` | Крећи се између панела |
| `Ctrl + Alt + Shift + Arrows` | Мењај величину панела |

### Прозори

| Пречица                  | Функција              |
| ----------------------- | --------------------- |
| `Prefix + c` | Нови прозор |
| `Prefix + k` | Убиј прозор |
| `Prefix + r` | Преименуј прозор |
| `Alt + 1-9` | Иди на одређени прозор |
| `Alt + Arrow Left/Right` | Крећи се између прозора |
| `Alt + Shift + Arrow Left/Right` | Помери прозор улево/удесно |

### Сесије

| Пречица                  | Функција              |
| ----------------------- | --------------------- |
| `Prefix + C` | Нова сесија |
| `Prefix + K` | Убиј сесију |

| `Prefix + N` | Следећа сесија |
| `Prefix + P` | Претходна сесија |
| `Alt + Arrow Up/Down` | Крећи се између сесија |
| `Prefix + s` | Наведи сесије |
| `Prefix + d` | Откачи се од сесије |

### Режим копирања (у vi стилу)

| Пречица                  | Функција              |

| `v` | Почни избор (у режиму копирања) |

### Опште

| Пречица                  | Функција              |
| ----------------------- | --------------------- |
| `Prefix + q` | Поново учитај конфигурацију |
| `Prefix + ?` | Прикажи Tmux пречице на тастатури |
| `Prefix + :` | Командни промпт |

### Функције распореда за Tmux

Ове функције морају да се покрену унутар Tmux сесије.

| Команда | Функција |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Направи развојни распоред са уређивачем, AI и терминалом |
| `tdlm <ai> [<second_ai>]` | Направи развојни распоред по поддиректоријуму |
| `tsl <count> <command>` | Направи распоред роја са више панела |
