# Пречице на тастатури

Можете видети све главне пречице на тастатури са `Super + K` (пречице за Tmux са `Super + Alt + K` и пречице за Herdr са `Super + Ctrl + K`).

## Навигација

| Пречица                  | Функција              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy мени (апликације и све остало)    |
| `Super + Alt + Space` | Мрежа апликација |
| `Super + Escape` | Системски мени (обустава, поновно покретање, итд.)  |
| `Super + Ctrl + L` | Закључавање рачунара |
| `Super + W` or `Super + Q` | Затварање прозора             |
| `Ctrl + Alt + Del` | Затварање свих прозора |
| `Super + T`               | Пребацивање прозора између плочастог/лебдећег режима             |
| `Super + J` | Промена положаја прозора (хоризонтално/вертикално) |
| `Super + O`               | Укључивање/искључивање искачућег прозора у лепљиви и лебдећи режим |
| `Super + L`               | Кружење кроз распореде dwindle, scrolling и floating |
| `Super + Alt + L`         | Кружење кроз распореде у обрнутом смеру |
| `Super + P`               | Укључивање/искључивање псеудо стила прозора (природно наспрам растегнутог) |
| `Super + F`                 | Прелазак на цео екран              |
| `Super + Alt + F`                 | Прелазак на пуну ширину              |
| `Super + Ctrl + F`                 | Прелазак на цео екран унутар прозора              |
| `Super + 1/2/3/4`         | Скок на одређени радни простор на фокусираном монитору |
| `Super + Tab` | Скок на следећи радни простор на фокусираном монитору |
| `Super + Shift + Tab` | Скок на претходни радни простор на фокусираном монитору |
| `Super + Ctrl + Tab` | Скок на ранији радни простор на фокусираном монитору |
| `Super + Shift + 1/2/3/4` | Померање прозора на радни простор на фокусираном монитору |
| `Super + Shift + Alt + 1/2/3/4` | Померање прозора на радни простор на фокусираном монитору без праћења |
| `Super + S` | Укључивање/искључивање целог scratchpad-а |
| `Super + Alt + S` | Померање прозора на цео scratchpad |
| `Super + Grave` | Укључивање/искључивање Quake конзоле |
| `Super + Shift + Grave` | Померање прозора на Quake конзолу |
| `Super + Shift + Ctrl + Arrows` | Померање прозора на монитор у том смеру |
| `Super + Shift + Alt + Arrows` | Померање радног простора на монитор у том смеру |
| `Super + Arrow`  | Померање фокуса на прозор у смеру стрелице, уз прелазак на монитор на тој страни на ивици екрана |
| `Super + Shift + Arrow`  | Замена прозора са другим у смеру стрелице, укључујући онај на монитору на тој страни |
| `Super + Minus` | Ширење прозора улево |
| `Super + Equal` | Скупљање прозора улево |
| `Super + Shift + Minus` | Скупљање прозора нагоре |
| `Super + Shift + Equal` | Ширење прозора надоле |
| `Super + Alt + Minus/Equal` | Иста промена величине у мањим корацима |
| `Super + Ctrl + Minus/Equal` | Иста промена величине у већим корацима |
| `Super + Alt + Home` | Чување ширине прозора |
| `Super + Home` | Враћање сачуване ширине прозора |
| `Super + Left Mouse` | Вучење прозора около |
| `Super + Right Mouse` | Промена величине прозора |
| `Super + Scroll Wheel` | Померање кроз радне просторе на фокусираном монитору |
| `Super + G`               | Укључивање/искључивање груписања прозора      |
| `Super + Alt + G`               | Извађивање прозора из групе      |
| `Super + Alt + Tab`               | Кружење између прозора у групи      |
| `Super + Alt + Shift + Tab`               | Кружење уназад између прозора у групи      |
| `Super + Alt + Scroll Wheel` | Кружење између прозора у групи |
| `Super + Alt + 1/2/3/4/5`               | Скок на одређени прозор у групи      |
| `Super + Alt + Arrow`  | Померање прозора у групу у смеру стрелице, укључујући онај на монитору на тој страни |
| `Super + Ctrl + Left/Right`  | Кретање између прозора унутар плочасте групе |
| `Super + Ctrl + Z` | Зумирање екрана (поновите за веће зумирање) |
| `Super + Ctrl + Alt + Z` | Потпуно одзумирање екрана |
| `Super + /` | Корак унапред кроз опције скалирања монитора |
| `Super + Alt + /` | Корак уназад кроз опције скалирања монитора |
| `Alt + Tab` | Кружење унапред кроз прозоре на активном радном простору |
| `Alt + Shift + Tab` | Кружење уназад кроз прозоре на активном радном простору |
| `Ctrl + Alt + Tab`| Кружење фокуса унапред кроз мониторе |
| `Ctrl + Alt + Shift + Tab`| Кружење фокуса уназад кроз мониторе |

Пречице за промену величине користе физичке тастере `code:20` и `code:21` (XKB `<AE11>` и `<AE12>`), без обзира на знакове одштампане на тастатури. На америчким тастатурама ти тастери су `-` и `=`; на јапанским (JIS) тастатурама су `-` и `^`; на шпанским тастатурама су `'` и `¡`. На JIS тастатури, `Super + ^` је `Super + Equal`, док је `Super + Shift + -` (којим се куца `=`) `Super + Shift + Minus`.

## Универзални међуспремник

| Пречица                  | Функција              |
| ----------------------- | --------------------- |
| `Super + A`           | Избор свега у апликацијама које подржавају `Ctrl + A`    |
| `Super + C`           | Копирање    |
| `Super + X`           | Исецање (не у терминалу)    |
| `Super + V`           | Налепљивање    |
| `Super + Ctrl + V`           | Управитељ међуспремника    |

Обично на Linux-у треба `Ctrl + Shift + C/V` за копирање и лепљење у терминалу и `Ctrl + C/V` да то радите свуда другде. Ове унификоване пречице за међуспремник у Omarchy-ју раде свуда.

## Tmux

| ----------------------- | --------------------- |
| `Prefix + v` | Подела окна поред (вертикално) |
