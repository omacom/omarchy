# Пречице на тастатури

Све главне пречице на тастатури можете видети помоћу `Super + K` (пречице за Tmux помоћу `Super + Alt + K` и пречице за Herdr помоћу `Super + Ctrl + K`).

## Кретање

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy мени (апликације и све остало)    |
| `Super + Alt + Space` | Мрежа апликација |
| `Super + Escape` | Системски мени (обустава, поновно покретање, итд.)  |
| `Super + Ctrl + L` | Закључај рачунар |
| `Super + W` or `Super + Q` | Затвори прозор             |
| `Ctrl + Alt + Del` | Затвори све прозоре |
| `Super + T`               | Пребацуј прозор између плочастог и плутајућег режима             |
| `Super + J` | Пребаци положај прозора (хоризонтално/вертикално) |
| `Super + O`               | Пребаци искачући прозор у лепљиви и плутајући режим |
| `Super + L`               | Кружно мењај распореде dwindle, scrolling и floating |
| `Super + Alt + L`         | Кружно мењај распореде уназад |
| `Super + P`               | Пребаци стил псеудопрозора (природно наспрам растегнуто) |

| `Super + Alt + F`                 | Прикажи преко целе ширине              |
| `Super + Ctrl + F`                 | Прикажи преко целог екрана унутар прозора              |
| `Super + 1/2/3/4`         | Скочи на одређени радни простор на фокусираном монитору |
| `Super + Tab` | Скочи на следећи радни простор на фокусираном монитору |

| `Super + Shift + Alt + 1/2/3/4` | Помери прозор на радни простор на фокусираном монитору без праћења |

| `Super + Shift + Grave` | Помери прозор на Quake конзолу |

| `Super + Shift + Arrow`  | Замени прозор другим у смеру стрелице, укључујући онај на монитору с те стране |
| `Super + Minus` | Прошири прозор улево |
| `Super + Equal` | Скупи прозор улево |
| `Super + Shift + Minus` | Скупи прозор нагоре |
| `Super + Shift + Equal` | Прошири прозор надоле |
| `Super + Alt + Minus/Equal` | Исто мењање величине у мањим корацима |
| `Super + Ctrl + Minus/Equal` | Исто мењање величине у већим корацима |
| `Super + Alt + Home` | Сачувај ширину прозора |
| `Super + Home` | Врати сачувану ширину прозора |
| `Super + Left Mouse` | Вуци прозор около |

| `Super + Alt + Arrow`  | Помери прозор у групу у смеру стрелице, укључујући онај на монитору с те стране |
| `Super + Ctrl + Left/Right`  | Крећи се између прозора унутар плочасте групе |
| `Super + Ctrl + Z` | Увећај приказ екрана (понови за још веће увећање) |

| `Super + /` | Корак унапред кроз опције скалирања монитора |
| `Super + Alt + /` | Корак уназад кроз опције скалирања монитора |
| `Alt + Tab` | Кружно иди унапред кроз прозоре на активном радном простору |
| `Alt + Shift + Tab` | Кружно иди уназад кроз прозоре на активном радном простору |
| `Ctrl + Alt + Tab`| Кружно померај фокус унапред кроз мониторе |
| `Ctrl + Alt + Shift + Tab`| Кружно померај фокус уназад кроз мониторе |

## Tmux

Префиксни тастер је `Ctrl + Space` (`Ctrl + B` такође ради). Ове пречице можете променити у `~/.config/tmux/tmux.conf`.

### Окна

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + v` | Подели окно бочно (вертикално) |
| `Prefix + h` | Подели окно испод (хоризонтално) |
| `Prefix + x` | Убиј окно |
| `Prefix + z` | Укључи/искључи зумирање окна (цео екран) |
| `Alt + Enter` | Подели окно испод (без префикса) |
| `Alt + Shift + Enter` | Подели окно бочно (без префикса) |
| `Alt + Escape` | Убиј окно (без префикса) |
| `Ctrl + Alt + Arrows` | Крећи се између окана |
| `Ctrl + Alt + Shift + Arrows` | Мењај величину окана |

### Прозори

### Tmux функције распореда

Ове функције морају се покренути унутар Tmux сесије.

| Command | Function |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Креирај развојни распоред са уређивачем, AI-јем и терминалом |
