# Пречице

Све главне везе тастатуре можете видети са `Super + K` (Tmux везе са `Super + Alt + K` и Herdr везе са `Super + Ctrl + K`).

## Навигација

| Пречица                  | Функција              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy мени (апликације и све остало)    |
| `Super + Alt + Space` | Мрежа апликација |
| `Super + Escape` | Системски мени (суспендовање, рестарт итд.)  |
| `Super + Ctrl + L` | Закључај рачунар |
| `Super + W` или `Super + Q` | Затвори прозор             |
| `Ctrl + Alt + Del` | Затвори све прозоре |
| `Super + T`               | Пребаци прозор између плочица/плутајућег             |
| `Super + J` | Пребаци положај прозора (хоризонтално/вертикално) |
| `Super + O`               | Пребаци извлачење прозора у лепљиво плутање |
| `Super + L`               | Кружење кроз распореде dwindle, померање и плутајући |
| `Super + Alt + L`         | Кружење кроз распореде у обрнутом смеру |
| `Super + P`               | Пребаци стил псеудо прозора (природно наспрам растегнуто) |
| `Super + F`                 | Преко целог екрана              |
| `Super + Alt + F`                 | На пуну ширину              |
| `Super + Ctrl + F`                 | Преко целог екрана унутар прозора              |
| `Super + 1/2/3/4`         | Скочи на одређени радни простор     |
| `Super + Tab` | Скочи на следећи радни простор |
| `Super + Shift + Tab` | Скочи на претходни радни простор |
| `Super + Ctrl + Tab` | Скочи на бивши радни простор |
| `Super + Shift + 1/2/3/4` | Помери прозор на радни простор |
| `Super + Shift + Alt + 1/2/3/4` | Помери прозор на радни простор без праћења |
| `Super + S` / `Super + Grave` | Пребаци нацрт |
| `Super + Alt + S` / `Super + Shift + Grave` | Помери прозор на нацрт |
| `Super + Shift + Alt + Arrows` | Помери радне просторе на монитор у смеру |
| `Super + Arrow`  | Помери фокус на прозор у смеру стрелице              |
| `Super + Shift + Arrow`  | Замени прозор с другим у смеру стрелице     |
| `Super + Minus` | Прошири прозор улево |
| `Super + Equal` | Смањи прозор улево |
| `Super + Shift + Minus` | Смањи прозор нагоре |
| `Super + Shift + Equal` | Прошири прозор надоле |
| `Super + Alt + Minus/Equal` | Исто мењање величине у мањим корацима |
| `Super + Ctrl + Minus/Equal` | Исто мењање величине у већим корацима |
| `Super + Alt + Home` | Сачувај ширину прозора |
| `Super + Home` | Врати сачувану ширину прозора |
| `Super + Left Mouse` | Превлачи прозор около |
| `Super + Right Mouse` | Мењај величину прозора |
| `Super + Scroll Wheel` | Померај кроз радне просторе |
| `Super + G`               | Пребаци груписање прозора      |
| `Super + Alt + G`               | Помери прозор из групе      |
| `Super + Alt + Tab`               | Кружење између прозора у групи      |
| `Super + Alt + Shift + Tab`               | Кружење уназад између прозора у групи      |
| `Super + Alt + 1/2/3/4/5`               | Скочи на одређени прозор у групи      |
| `Super + Alt + Arrow`  | Помери прозор у групу у смеру стрелице  |
| `Super + Ctrl + Left/Right`  | Крећи се између прозора унутар групе плочица |
| `Super + Ctrl + Z` | Увећај екран (понови за веће увећање) |
| `Super + Ctrl + Alt + Z` | Потпуно умањи екран |
| `Super + /` | Корак напред кроз опције скалирања монитора |
| `Super + Alt + /` | Корак назад кроз опције скалирања монитора |
| `Alt + Tab` | Кружење напред кроз прозоре на активном радном простору |
| `Alt + Shift + Tab` | Кружење назад кроз прозоре на активном радном простору |
| `Ctrl + Alt + Tab`| Кружење фокуса напред кроз мониторе |
| `Ctrl + Alt + Shift + Tab`| Кружење фокуса назад кроз мониторе |

## Универзални клипборд

| Пречица                  | Функција              |
| ----------------------- | --------------------- |
| `Super + C`           | Копирај    |
| `Super + X`           | Исеци (не у терминалу)    |
| `Super + V`           | Налепи    |
| `Super + Ctrl + V`           | Менаџер клипборда    |

Обично на Linux-у требате `Ctrl + Shift + C/V` за копирање и лепљење у терминалу и `Ctrl + C/V` да то радите свуда другде. Ове Omarchy обједињене пречице клипборда раде свуда.

## Снимање

| Пречица              | Функција                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Мени снимања (за тастатуре без дугмета PrintScr) |
| `Print Screen`            | Снимак екрана                      |
| `Alt + Print Screen`            | Снимање екрана                     |
| `Super + Print Screen` | Бирач боја |
| `Super + Ctrl + Print Screen` | Извлачење текста на клипборд |
| `Super + Alt + [` | Учини преклоп веб-камере мањим током снимања |
| `Super + Alt + ]` | Учини преклоп веб-камере већим током снимања |
| `Alt + Shift + L` | Копирај тренутни URL из веб-апликације или Chromium-а |
| `Alt + Shift + D` | Преузми видео на тренутној страници у `~/Videos` |
| `Super + Ctrl + X` | Покрени/заустави диктирање (захтева _Подешавање > Подразумевано > Диктирање_) |
| `Right Alt` / `F9` | Диктирање притисни-за-говор (захтева Voxtype или Superwhisper) |

Код снимања екрана, пречица прво пита који звук желите, затим почиње снимање. Притисните је поново да зауставите. Видети [снимке екрана и снимање](12-screenshots-recording.md) за детаље.

Све опције снимања доступне су и под _Покрени > Сними_ у Omarchy менију (`Super + Space`).

## Tmux

Префиксни тастер је `Ctrl + Space` (`Ctrl + B` такође ради). Ове везе можете променити у `~/.config/tmux/tmux.conf`.

### Табле

| Пречица                  | Функција              |
| ----------------------- | --------------------- |
| `Prefix + v` | Подели таблу поред (вертикално) |
| `Prefix + h` | Подели таблу испод (хоризонтално) |
| `Prefix + x` | Убиј таблу |
| `Prefix + z` | Пребаци увећање табле (преко целог екрана) |
| `Alt + Enter` | Подели таблу испод (без префикса) |
| `Alt + Shift + Enter` | Подели таблу поред (без префикса) |
| `Alt + Escape` | Убиј таблу (без префикса) |
| `Ctrl + Alt + Arrows` | Крећи се између табли |
| `Ctrl + Alt + Shift + Arrows` | Мењај величину табли |

### Прозори

| Пречица                  | Функција              |
| ----------------------- | --------------------- |
| `Prefix + c` | Нови прозор |
| `Prefix + k` | Убиј прозор |
| `Prefix + r` | Преименуј прозор |
| `Alt + 1-9` | Иди на одређени прозор |
| `Alt + Arrow Left/Right` | Крећи се између прозора |
| `Alt + Shift + Arrow Left/Right` | Помери прозор улево/удесно |

### Сесије

| Пречица                  | Функција              |
| ----------------------- | --------------------- |
| `Prefix + C` | Нова сесија |
| `Prefix + K` | Убиј сесију |
| `Prefix + R` | Преименуј сесију |
| `Prefix + N` | Следећа сесија |
| `Prefix + P` | Претходна сесија |
| `Alt + Arrow Up/Down` | Крећи се између сесија |
| `Prefix + s` | Наведи сесије |
| `Prefix + d` | Одвоји се од сесије |

### Режим копирања (vi стил)

| Пречица                  | Функција              |
| ----------------------- | --------------------- |
| `Prefix + [` | Уђи у режим копирања |
| `v` | Почни избор (у режиму копирања) |
| `y` | Копирај избор (у режиму копирања) |

### Опште

| Пречица                  | Функција              |
| ----------------------- | --------------------- |
| `Prefix + q` | Поново учитај конфигурацију |
| `Prefix + ?` | Прикажи Tmux пречице |
| `Prefix + :` | Командни упит |

### Функције распореда Tmux-а

Ове функције се морају покретати унутар Tmux сесије.

| Команда | Функција |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Креирај развојни распоред с едитором, AI-јем и терминалом |
| `tdlm <ai> [<second_ai>]` | Креирај развојни распоред по поддиректоријуму |
| `tsl <count> <command>` | Креирај рој распоред с више табли |
