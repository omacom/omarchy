# Пречице на тастатури

Све главне пречице на тастатури можете видети са `Super + K` (Tmux пречице са `Super + Alt + K`, а Herdr пречице са `Super + Ctrl + K`).

## Како су пречице распоређене

Свака пречица се налази на једној равни, коју одређују њени модификатори, и свака раван има један задатак. То спречава да се пречице међусобно помешају и значи да обично можете погодити где се нешто налази.

| Раван | Шта се ту налази | Примери |
| --- | --- | --- |
| `Super + key` | Систем: прозори, радни простори, распореди и главни менији | `Super + Space` Omarchy мени, `Super + W` затварање прозора, `Super + F` цео екран |
| `Super + Shift + key` | Апликације | `Super + Shift + B` прегледач, `Super + Shift + E` е-пошта, `Super + Shift + N` уређивач |
| `Super + Ctrl + key` | Панели и системски менији | `Super + Ctrl + A` звук, `Super + Ctrl + N` мрежа, `Super + Ctrl + C` мени за хватање |
| `Super + Ctrl + Alt + key` | Брзе радње и обавештења | `Super + Ctrl + Alt + T` приказ времена, `Super + Ctrl + Alt + B` батерија, `Super + Ctrl + Alt + C` слика екрана |

Додавање тастера `Alt` пречици даје вам варијанту исте ствари, никада нешто неповезно:

- `Super + Shift + B` отвара прегледач; `Super + Shift + Alt + B` отвара приватни прозор
- `Super + Shift + E` отвара е-пошту; `Super + Shift + Alt + E` започиње нову
- `Super + F` прелази на цео екран; `Super + Alt + F` прелази на целу ширину
- `Super + Ctrl + C` отвара мени за хватање; `Super + Ctrl + Alt + C` прескаче мени и прави слику екрана

Када додајете пречицу:

1. Изаберите раван према томе шта пречица ради, па изаберите тастер.
2. Не померајте постојећу пречицу да бисте направили места. Пронађите слободан тастер на правој равни.
3. Користите `Alt` само за варијанту пречице без њега.

Неколико пречица крши ова правила зато што су згодне. `Shift` са стрелицом или тастером `Tab` помера или обрће уместо да отвара апликацију, а `Print`, медијски тастери, `Alt + Tab` и `Ctrl + Alt + Del` раде онако како раде свуда другде. То су изузеци, а не обрасци за копирање.

Ако вам подразумевана пречица не одговара (рецимо да желите `Super + Shift + S` за слике екрана као на Windows систему), поново је повежите у `~/.config/hypr/bindings.lua`.

| `Ctrl + Alt + Shift + Tab`| Кружење фокуса уназад кроз мониторе |

Пречице за мењање величине користе физичке тастере `code:20` и `code:21` (XKB `<AE11>` и `<AE12>`), без обзира на знакове одштампане на тастатури. На америчким тастатурама ти тастери су `-` и `=`; на јапанским (JIS) тастатурама то су `-` и `^`; на шпанским тастатурама то су `'` и `¡`. На JIS распореду, `Super + ^` је `Super + Equal`, док је `Super + Shift + -` (који куца `=`) заправо `Super + Shift + Minus`.

### Функције Tmux распореда

Ове функције морају се покретати унутар Tmux сесије.

| Команда | Функција |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Прављење развојног распореда са уређивачем, AI и терминалом |
| `tdlm <ai> [<second_ai>]` | Прављење развојног распореда по поддиректоријуму |
| `tsl <count> <command>` | Прављење распореда роја са више окана |

## Брза довршавања

| ------------ |  ---------- |
