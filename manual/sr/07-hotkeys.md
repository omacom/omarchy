# Пречице на тастатури

Све главне тастерске пречице можете видети помоћу `Super + K` (Tmux пречице помоћу `Super + Alt + K`, а Herdr пречице помоћу `Super + Ctrl + K`).

## Навигација

| Пречица | Функција |
| ----------------------- | --------------------- |
| `Super + Space` | Omarchy мени (апликације и све остало) |
| `Super + Alt + Space` | Мрежа апликација |
| `Super + Escape` | Системски мени (обустава, поновно покретање итд.) |
| `Super + Ctrl + L` | Закључај рачунар |
| `Super + W` or `Super + Q` | Затвори прозор |
| `Ctrl + Alt + Del` | Затвори све прозоре |
| `Super + T` | Пребаци прозор између режима ређања и плутања |
| `Super + J` | Пребаци положај прозора (хоризонтално/вертикално) |
| `Super + O` | Пребаци прозор у искачући лепљиво-плутајући режим |
| `Super + L` | Кружно мењај распореде dwindle, scrolling и floating |
| `Super + Alt + L` | Кружно мењај распореде уназад |
| `Super + P` | Укључи/искључи стил псеудо-прозора (природно наспрам растегнутог) |
| `Super + F` | Пређи на цео екран |
| `Super + Alt + F` | Пређи на пуну ширину |
| `Super + Ctrl + F` | Пређи на цео екран унутар прозора |
| `Super + 1/2/3/4` | Скочи на одређени радни простор на фокусираном монитору |
| `Super + Tab` | Скочи на следећи радни простор на фокусираном монитору |
| `Super + Shift + Tab` | Скочи на претходни радни простор на фокусираном монитору |
| `Super + Ctrl + Tab` | Скочи на ранији радни простор на фокусираном монитору |
| `Super + Shift + 1/2/3/4` | Премести прозор на радни простор на фокусираном монитору |
| `Super + Shift + Alt + 1/2/3/4` | Премести прозор на радни простор на фокусираном монитору без праћења |
| `Super + S` | Укључи/искључи пуни scratchpad |
| `Super + Alt + S` | Премести прозор у пуни scratchpad |
| `Super + Grave` | Укључи/искључи Quake конзолу |
| `Super + Shift + Grave` | Премести прозор у Quake конзолу |
| `Super + Shift + Ctrl + Arrows` | Премести прозор на монитор у том смеру |
| `Super + Shift + Alt + Arrows` | Премести радни простор на монитор у том смеру |
| `Super + Arrow` | Премести фокус на прозор у смеру стрелице, прелазећи на монитор с те стране на ивици екрана |
| `Super + Shift + Arrow` | Замени прозор с другим у смеру стрелице, укључујући онај на монитору с те стране |
| `Super + Minus` | Прошири прозор улево |
| `Super + Equal` | Смањи прозор улево |
| `Super + Shift + Minus` | Смањи прозор нагоре |
| `Super + Shift + Equal` | Прошири прозор надоле |
| `Super + Alt + Minus/Equal` | Исто мењање величине у мањим корацима |
| `Super + Ctrl + Minus/Equal` | Исто мењање величине у већим корацима |
| `Super + Alt + Home` | Сачувај ширину прозора |
| `Super + Home` | Врати сачувану ширину прозора |
| `Super + Left Mouse` | Превуци прозор |
| `Super + Right Mouse` | Промени величину прозора |
| `Super + Scroll Wheel` | Скролуј кроз радне просторе на фокусираном монитору |
| `Super + G` | Укључи/искључи груписање прозора |
| `Super + Alt + G` | Измести прозор из групе |
| `Super + Alt + Tab` | Кружно мењај прозоре у групи |
| `Super + Alt + Shift + Tab` | Кружно мењај прозоре у групи уназад |
| `Super + Alt + Scroll Wheel` | Кружно мењај прозоре у групи |
| `Super + Alt + 1/2/3/4/5` | Скочи на одређени прозор у групи |
| `Super + Alt + Arrow` | Премести прозор у групу у смеру стрелице, укључујући онај на монитору с те стране |
| `Super + Ctrl + Left/Right` | Крећи се између прозора унутар групе за ређање |
| `Super + Ctrl + Z` | Увећај приказ на екрану (понови за још веће увећање) |
| `Super + Ctrl + Alt + Z` | Потпуно умањи приказ екрана |
| `Super + /` | Корак унапред кроз опције скалирања монитора |
| `Super + Alt + /` | Корак уназад кроз опције скалирања монитора |
| `Alt + Tab` | Кружно иди унапред кроз прозоре на активном радном простору |
| `Alt + Shift + Tab` | Кружно иди уназад кроз прозоре на активном радном простору |
| `Ctrl + Alt + Tab` | Кружно померај фокус унапред кроз мониторе |
| `Ctrl + Alt + Shift + Tab` | Кружно померај фокус уназад кроз мониторе |

Пречице за мењање величине користе физичке тастере `code:20` и `code:21` (XKB `<AE11>` и `<AE12>`), без обзира на знакове одштампане на тастатури. На америчким тастатурама ти тастери су `-` и `=`; на јапанским (JIS) тастатурама су `-` и `^`; на шпанским тастатурама су `'` и `¡`. На JIS тастатури, `Super + ^` је `Super + Equal`, док је `Super + Shift + -` (које куца `=`) заправо `Super + Shift + Minus`.

## Универзални међуспремник

| Пречица | Функција |
| ----------------------- | --------------------- |
| `Super + A` | Изабери све у апликацијама које подржавају `Ctrl + A` |
| `Super + C` | Копирај |
| `Super + X` | Исеци (не у терминалу) |
| `Super + V` | Налепи |
| `Super + Ctrl + V` | Менаџер међуспремника |

Обично на Linux-у морате да користите `Ctrl + Shift + C/V` да бисте копирали и налепили у терминалу, а `Ctrl + C/V` да бисте то радили свуда другде. Ове Omarchy обједињене пречице за међуспремник раде свуда.

## Tmux

Префиксни тастер је `Ctrl + Space` (`Ctrl + B` такође ради). Ове пречице можете променити у `~/.config/tmux/tmux.conf`.

### Окна

| Пречица | Функција |
| ----------------------- | --------------------- |
| `Prefix + v` | Подели окно бочно (вертикално) |
| `Prefix + h` | Подели окно испод (хоризонтално) |
| `Prefix + x` | Убиј окно |
| `Prefix + z` | Укључи/искључи зумирање окна (цео екран) |
| `Alt + Enter` | Подели окно испод (без префикса) |
| `Alt + Shift + Enter` | Подели окно бочно (без префикса) |
| `Alt + Escape` | Убиј окно (без префикса) |
| `Ctrl + Alt + Arrows` | Крећи се између окна |
| `Ctrl + Alt + Shift + Arrows` | Мењај величину окна |

### Прозори

| Пречица | Функција |
| ----------------------- | --------------------- |

### Tmux функције распореда

Ове функције морају се покренути унутар Tmux сесије.

| Команда | Функција |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Направи развојни распоред са уређивачем, AI-јем и терминалом |
| `tdlm <ai> [<second_ai>]` | Направи развојни распоред за сваки поддиректоријум |
| `tsl <count> <command>` | Направи распоред роја са више окна |
