# Пречице на тастатури

Све главне везе тастатуре можете да видите помоћу `Super + K` (Tmux везе помоћу `Super + Alt + K`, а Herdr везе помоћу `Super + Ctrl + K`).

## Како су пречице организоване

Свака пречица се налази на једној равни, коју одређују њени модификатори, а свака раван има један посао. То спречава да се пречице међусобно замагљују и значи да обично можете да погодите где се нешто налази.

| Раван | Шта се ту налази | Примери |
| --- | --- | --- |
| `Super + key` | Систем: прозори, радни простори, распореди и главни менији | `Super + Space` Omarchy мени, `Super + W` затварање прозора, `Super + F` цео екран |
| `Super + Shift + key` | Апликације | `Super + Shift + B` прегледач, `Super + Shift + E` е-пошта, `Super + Shift + N` уређивач |
| `Super + Ctrl + key` | Панели и системски менији | `Super + Ctrl + A` звук, `Super + Ctrl + N` мрежа, `Super + Ctrl + C` мени за снимање |
| `Super + Ctrl + Alt + key` | Брзе радње и обавештења | `Super + Ctrl + Alt + T` прикажи време, `Super + Ctrl + Alt + B` батерија, `Super + Ctrl + Alt + C` снимак екрана |

Додавање `Alt` пречици даје вам варијанту исте ствари, никада нешто неповеззано:

- `Super + Shift + B` отвара прегледач; `Super + Shift + Alt + B` отвара приватни прозор
- `Super + Shift + E` отвара е-пошту; `Super + Shift + Alt + E` започиње нову
- `Super + F` прелази на цео екран; `Super + Alt + F` прелази на целу ширину
- `Super + Ctrl + C` отвара мени за снимање; `Super + Ctrl + Alt + C` прескаче мени и прави снимак екрана

Када додајете пречицу:

1. Изаберите раван према томе шта ради, затим изаберите тастер.
2. Не померајте постојећу пречицу да бисте направили места. Пронађите слободан тастер на правој равни.
3. Користите `Alt` само за варијанту пречице без њега.

Неколико пречица крши ова правила јер су згодне. `Shift` са стрелицом или `Tab` помера или иде уназад уместо да отвара апликацију, а `Print`, медијски тастери, `Alt + Tab` и `Ctrl + Alt + Del` раде онако како раде свуда другде. То су изузеци, не обрасци за копирање.

Ако вам подразумевана не одговара (рецимо да желите `Super + Shift + S` за снимке екрана као на Windows-у), поново је вежите у `~/.config/hypr/bindings.lua`.

На тачпеду превлачења са три и четири прста мењају радне просторе, померају прозоре и отварају мени и Quake конзолу; погледајте [тастатура, миш и тракпад](34-keyboard-mouse-trackpad.md) за гестове.

Пречице за мењање величине користе физичке тастере `code:20` и `code:21` (XKB `<AE11>` и `<AE12>`), без обзира на знакове одштампане на тастатури. На америчким тастатурама ти тастери су `-` и `=`; на јапанским (JIS) тастатурама су `-` и `^`; на шпанским тастатурама су `'` и `¡`. На JIS тастатури `Super + ^` је `Super + Equal`, док је `Super + Shift + -` (чиме се куца `=`) заправо `Super + Shift + Minus`.
