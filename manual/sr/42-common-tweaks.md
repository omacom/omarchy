# Уобичајена подешавања

Ово је збирка уобичајених прилагођавања Omarchy подешавања. Знај да ће повремено можда бити неопходно да ажурирања система врате одређене конфигурације у првобитно стање. Ако се то догоди, твоје промене неће бити изгубљене, већ стављене у `.bak` датотеку у истом директоријуму.

Ако нешто забрљаш, појединачне конфигурације можеш да вратиш у првобитно подешавање преко _Ажурирај > Конфигурација_ у Omarchy менију. Ако _заиста_ све забрљаш, све конфигурације можеш да ресетујеш преко `omarchy-reinstall`.

### Откриј све иконе у системској траци стално

По подразумеваној вредности, иконе у системској траци, као што су Dropbox, 1Password или Steam, сакривене су иза стрелице за проширивање траке, која их открива када пређеш преко ње. Ако желиш да буду откривене стално, кликни десним тастером на стрелицу за проширивање да отвориш управљач икона у траци, а затим прикачи иконе које желиш да остану видљиве (можеш и да сакријеш оне које никада не желиш да видиш).

### Заобљени углови прозора

Подразумевани дизајн Omarchy-ја је дизајн оштрих углова, али ако волиш то мало да ублажиш, можеш да промениш `~/.config/hypr/looknfeel.lua` тако да заобљење више није коментарисано:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### Уклони размаке прозора

На екранима лаптопова неки људи више воле да не троше ниједан пиксел на размаке прозора (или чак на горњу траку, коју можеш да искључиш пречицом `Super + Shift + Space`). Све размаке и ивице можеш да искључиш пречицом `Super + Shift + Backspace`, или да их трајно уклониш уклањањем коментара у овом одељку датотеке `~/.config/hypr/looknfeel.lua`:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
