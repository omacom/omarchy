# Тастатура, миш, трекпед

Hyprland вам омогућава да детаљно подесите све своје улазне уређаје. Можете да убрзате понављање тастатуре до надзвучне брзине или да подесите трекпед да користи природно померање. Све то мењате у `~/.config/hypr/input.lua`, до чега можете доћи и преко _Setup > Input_ у Omarchy менију (`Super + Space`). Све што тамо подесите замењује Omarchy подразумеване вредности.

Ево примера:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Све опције за унос можете [видети на Hyprland викију за уносе](https://wiki.hypr.land/Configuring/Basics/Variables/#input).

CapsLock ради као обичан Caps Lock, а `Shift + CapsLock` је compose тастер за [брзе емоџије](07-hotkeys.md#quick-emojis) и [друга довршавања](07-hotkeys.md#quick-completions). Ако бисте радије да compose тастер буде негде другде, замените `omarchy:shift_caps_compose` у `kb_options`. На пример, ово помера compose тастер на Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Функцијски тастери

Горњи ред тастатуре лаптопа подразумевано шаље медијске тастере (јачину звука, осветљеност и тако даље), а држање `Fn` даје F1-F12; `Fn + Esc` закључава то у супротном смеру док га поново не притиснете. Већина тастатура сама памти то закључавање. ASUS лаптопови и тастатуре у Apple стилу то препуштају Linux-у, који их при сваком покретању стартује на медијским тастерима. Да би уместо тога стартовали на F1-F12, покрените `omarchy keyboard toprow fnkeys` (а `omarchy keyboard toprow mediakeys` да се вратите назад); на неким лаптоповима то ступа на снагу након поновног покретања. Apple Silicon Mac рачунари задржавају своје подешавање.

### Гестови трекпеда

Превуците по трекпеду да се крећете по радној површини:

| Гест | Радња |
| --- | --- |
| Три прста лево / десно | Претходни / следећи радни простор, укључујући празне |
| Три прста нагоре | Укључи/искључи AI конзолу |
| Три прста надоле | Отвори Omarchy мени |
| Четири прста лево / десно | Премести активни прозор на претходни / следећи радни простор |
| Четири прста надоле | Укључи/искључи цео екран |

Да бисте променили неки гест, поништите га у `~/.config/hypr/input.lua` пре него што додате свој [гест додирне табле](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), јер Hyprland неће прихватити два геста на истим прстима и у истом смеру:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Да бисте искључили све Omarchy гестове, подесите `omarchy_default_gestures = false` близу врха `~/.config/hypr/hyprland.lua`, пре него што се Omarchy подразумеване вредности учитају.

На Dell XPS лаптоповима са хаптичким тачпедом снагу клика можете подесити и на ниску, средњу или високу под _Trigger > Hardware > Touchpad Haptics_.

### Куцање на кинеском, јапанском и другим језицима

Изаберите јапански, корејски, кинески (поједностављени, Pinyin), тајвански (Zhuyin) или хонгконшки (Cangjie) када вас инсталер пита за тастатуру. Omarchy аутоматски подешава тастатуру и одговарајући механизам за унос, укључујући и током офлајн подешавања при првом покретању. Јапански користи Mozc, корејски користи стандардни Hangul са два скупа, поједностављени кинески користи Pinyin, Тајван користи Chewing-ов стандардни Zhuyin распоред, а Хонг Конг користи Cangjie са хонгконшким облицима знакова. Јапански (америчка тастатура) пружа Mozc са америчким распоредом тастатуре. Тастери за Hangul, Zhuyin и Cangjie остају на својим стандардним положајима чак и када латинична слова куцате са Dvorak, Colemak или AZERTY распоредом. Ако сте пре овога додали Hangul или Chewing, поништите им избор и поново их изаберите под _Setup > Keyboard > Input Methods_ да бисте им тастере преместили тамо; Omarchy механизам којим већ куцате оставља на миру.

Куцање почиње у латиничном режиму. Притисните `Super + I` да кружите кроз подешене методе уноса, а `Super + Shift + I` да кружите уназад. Додирните само `Shift` да изађете из методе уноса као што је Pinyin на латинична слова, а додирните га поново да се вратите назад, онако како раде Sogou, Microsoft Pinyin и macOS; `Shift` плус слово и даље куца велико слово. На јапанским тастатурама, 全角/半角 пребацује унос, 変換 га укључује, а 無変換 га искључује. Код корејског, 한/영 пребацује Hangul, а 한자 претвара у Hanja, без обзира на то да ли ваша тастатура има наменске тастере или за њих шаље Right Alt и Right Ctrl, као што многи лаптопови раде, тако да Right Alt и Right Ctrl тамо нису обични модификатори; диктирање се уместо тога пребацује са Alt + Space. `Ctrl + Space` остаје доступан за Tmux и Herdr; `Shift + CapsLock` остаје compose тастер.

Индикатор тастатуре појављује се десно на траци када имате више распореда тастатуре или метода уноса. Кликните на њега да пребаците језике уноса; јапански приказује あ за хирагану. За избор јапанских знакова, пребаците се на јапански, откуцајте реч као што је `nihongo`, па двапут притисните Space. Притисните Enter да прихватите свој избор. Ако имате и више распореда тастатуре, кликните десним тастером на индикатор да кружите кроз њих.

Користите _Setup > Keyboard > Keyboard Inputs_ да изаберете распореде као што су енглески и француски, из истих избора који се нуде током инсталације. Користите _Setup > Keyboard > Input Methods_ да изаберете који су механизми за састављање активни. Оба бирача отварају се унутар Omarchy менија, са вашим тренутним изборима означеним. Кликните или притисните Enter да пребаците избор; свака промена се одмах примењује. Поништавање избора методе уноса уклања је из циклуса без деинсталације; тастатура остаје доступна.

Покрените `omarchy setup keyboard` или `omarchy setup input` да отворите исте бираче. Да додате један језик из командне линије, користите `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` или `cangjie5`. Quick, Boshiamy и Array долазе у истом пакету као Cangjie и појављују се у бирачу Input Methods. Ваши прилагођени тастери за пребацивање се чувају. За алтернативне распореде или тастере механизма, инсталирајте `fcitx5-configtool` помоћу `omarchy pkg add fcitx5-configtool` и покрените га из терминала. Избор језика уноса не мења језик радне површине. Избор јапанског, корејског или кинеског под _Setup > Language_ додаје његову методу уноса када још немате ниједну.

Користите `Super + I` да кружите кроз методе уноса или распореде тастатуре, а `Super + Shift + I` да идете назад у супротном смеру, па се са три подешене можете кретати између два суседа. Индикатор уноса појављује се десно на траци само када је подешено више од једне методе уноса или распореда. Ова веза на радној површини ради упоредо са вашим постојећим Fcitx тастерима за пребацивање; можете је заменити у `~/.config/hypr/bindings.lua`. Механизми за унос и compose секвенце користе [Fcitx5](https://fcitx-im.org/) сервис који већ ради у свакој сесији.

### Користите ALT као SUPER

На неким тастатурама није згодно користити примарни мета тастер (Windows/cmd тастер) као SUPER. Уместо тога можете то променити на ALT помоћу ове промене:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
