# Дотфајлови

Omarchy се првенствено конфигурише преко такозваних дотфајлова који се налазе у `~/.config`. Они се сматрају вашим датотекама за ваше измене. Датотеке које се налазе у `/usr/share/omarchy` припадају самом Omarchy-ју и не би требало да дирате по њима. Ако треба да промените било шта у `/usr/share/omarchy`, уместо тога би требало да препишете вредност у `~/.config`.

Кључне конфигурације могу се уређивати директно из менија Omarchy-ја (`Super + Space`), као што су _Setup > Keybindings_, _Setup > Input_ и _Setup > Config > [file]_. Када то радите на овај начин, сваки процес који треба поново покренути након измена конфигурације аутоматски ће бити поново покренут након што изађете из уређивача (Neovim подразумевано — `:wq`, запамтите! — али то можете променити преко _Setup > Defaults > Editor_).

Ево листе кључних датотека у `~/.config` и онога што оне контролишу:

| File                  | Purpose              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | Главна Hyprland конфигурација. Учитава подразумеване Omarchy поставке плус ваше датотеке за преписивање наведене у наставку. [Сазнајте више о Hyprland конфигурацијама](https://wiki.hypr.land/Configuring/).  |
| `~/.config/hypr/bindings.lua` | Ваше сопствене пречице на тастатури и преписивања подразумеваних. |
| `~/.config/hypr/monitors.lua` | Поставке монитора које панел за мониторе не покрива, као што су ротација, додатни режими или држање монитора искљученим. |
| `~/.config/hypr/input.lua` | Контролише распоред тастатуре, миша и поставке додирне табле. |
| `~/.config/hypr/looknfeel.lua` | Контролише размаке, ивице, анимације и остатак изгледа. |
| `~/.config/hypr/autostart.lua` | Контролише додатне процесе који се покрећу са сесијом. |
| `~/.config/omarchy/shell.json` | Контролише Omarchy љуску: положај траке, распоред и виџете, плус чувар екрана, закључавање и времена мировања. |
| `~/.config/foot/foot.ini` | Контролише ваш терминал (foot је подразумевани). |
| `~/.XCompose` | Дефинише ваше емотиконе за брзи приступ и аутоматско довршавање имена/имејла. Обавезно покрените `omarchy-restart-xcompose` након уношења измена. |

Ако на крају направите много измена да бисте подесили сопствену поставку, добра је идеја да направите резервну копију свих ових дотфајлова. [Stow је одличан начин да то урадите](https://www.youtube.com/watch?v=NoFiYOqnC4o).

### Покретање сопствених апликација са сесијом

Ако желите да се нешто покреће сваки пут када се пријавите — демон за синхронизацију, апликација за ћаскање, ваша сопствена скрипта — ставите то у `~/.config/hypr/autostart.lua`:

```lua
o.launch_on_start("my-service")
```

То покреће команду као део сесије, па се правилно чисти када се поново одјавите.

### Покретање скрипти на системске догађаје

Omarchy покреће кукице у неколико тренутака, а на њих можете да окачите сопствене скрипте. Оне се налазе у `~/.config/omarchy/hooks/<event>.d/`, по један директоријум за сваки догађај, и свака извршна датотека тамо се покреће када се догађај деси:

| Event | When it runs |
| ----- | ------------ |
| `post-boot` | Одмах након што се радна површина покрене |
| `post-update` | При крају `omarchy update`, након пакета, миграција и поновног покретања сервиса, пре него што се ажурирају mise алати |
| `pre-refresh-pacman` | Након што `omarchy refresh pacman` поново синхронизује конфигурацију пакета, пре него што ажурира пакете; промена канала га покреће током истог корака освежавања |
| `theme-set` | Након промене теме (име теме у `$1`) |
| `font-set` | Након промене фонта (име фонта у `$1`) |
| `battery-low` | Када батерија постане слаба (проценат у `$1`) |

Кукица `pre-refresh-pacman` је место где припадају прилагођена спремишта или редови `IgnorePkg`, јер се покреће пре трансакције пакета. Обе кукице повезане са ажурирањем покрећу се као ваш корисник након што Omarchy обрише своје кеширано sudo овлашћење, па кукици која користи `sudo` треба сопствено овлашћење и може да затражи вашу лозинку.

Сваки од тих директоријума већ садржи датотеку `.sample` која показује облик кукице — уклоните `.sample` из имена да бисте је ставили у рад. Да бисте инсталирали скрипту коју сте написали негде другде, користите `omarchy hook install post-boot ~/my-hook`, што је копира унутра и чини је извршном.

### Додавање сопствених ставки менија

Мени Omarchy-ја (`Super + Space`) може се проширити сопственим редовима уређивањем `~/.config/omarchy/extensions/omarchy-menu.jsonc`. Ставке су означене тачкастим id-јем, а id је оно што их смешта у стабло, па се `personal` појављује на кореном менију, а `personal.notes` се појављује унутар њега:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

Поново употребите постојећи id и преписаћете тај ред уместо да додате нови. Датотека се испоручује са свим доступним пољима документованим као коментари.

### Додавање сопствених извоза љуске, функција и алијаса

Omarchy се испоручује са гомилом ергономских алијаса и корисних функција, али је веома уобичајено да желите да додате сопствене. И алијасе, функције и извозе треба да додате у `~/.bashrc`. Ова датотека неће бити преписана при ажурирањима. Ако желите да промените било коју од подразумеваних Omarchy поставки, можете их безбедно додати и овде.

### Постављање променљивих окружења за радну површину

Извози сесије радне површине припадају у `~/.config/uwsm/env.d/`. Ове датотеке се покрећу пре него што се ваша радна површина покрене, па вас грешка љуске може вратити на екран за пријаву. Држите исправан терминал отворен док их уређујете. Да бисте онемогућили преписивање, изместите га из `env.d`. Погледајте [опоравак пријаве](45-troubleshooting.md#my-password-is-accepted-but-i-return-to-the-login-screen) ако измена спречава пријаву.

### Мењање интерних Omarchy датотека

Видите, ово је ваш рачунар. Можете са њим да радите шта год желите, али саветовао бих да не мењате датотеке у `/usr/share/omarchy` директно. Оне припадају Omarchy pacman пакету, па ће ваше измене једноставно бити преписане при следећем ажурирању. Боље вам је да уместо тога само препишете све подразумеване вредности које вам се не свиђају у фасцикли `~/.config/*`.

На тај начин можете да промените скоро све, као што су подразумеване пречице на тастатури. Само уредите `~/.config/hypr/bindings.lua` да, рецимо, замените [Obsidian](https://obsidian.md/) са [Joplin](https://joplinapp.org/) (инсталирајте са `omarchy-pkg-add joplin-bin`):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` уклања постојећу пречицу пре додавања њене замене. Прима исте аргументе као `o.bind`, укључујући помоћнике за покретање и опције пречице. Користите `o.bind` да додате пречицу, или `hl.unbind` да је уклоните без замене.

Ако инсистирате на чепркању по интерним Omarchy датотекама, пређите на dev канал преко _Update > Channel > Dev_. То повезује Omarchy са git изводом изворног кода у `~/omarchy`, који слободно можете да мењате до миле воље. Овде нема никога да вам говори шта да радите!

### Враћање свих измена

Ако на крају направите збрку од конфигурација, увек их можете вратити на подразумеване преко _Update > Config_ у менију Omarchy-ја. Или покретањем `omarchy reinstall configs` да ресетујете све.
