# Алатке за развој

## Алтернативни уређивачи

Omarchy на новим инсталацијама подразумевано долази са уређивачем Plain и унапред инсталираним [Neovim](https://neovim.io/), али ако желите нешто мало уобичајеније и познатије, можете покренути мени Omarchy (`Super + Space`) и погледати опције под _Инсталирај > Уређивач_. Тамо су наведени VSCode, Cursor, Zed, Sublime Text, Helix, Vim и Emacs. Ако не пронађете оно што тражите, погледајте _Инсталирај > Пакет_ и проверите да ли се налази у неком Arch пакету (а ако се не налази, покушајте _Инсталирај > AUR_ да проверите AUR).

Оригинални уређивач `vi` такође је доступан одмах по инсталацији. Покрените `vi filename` да бисте уредили датотеку у терминалу.

Усклађивање теме нуди се за `VSCode`, `Cursor`, `VSCodium` и `Helix`.

Подразумевани уређивач за цео систем можете подесити под `Setup > Defaults > Editor`.

## Окружење

Omarchy подржава подешавање читавог низа развојних окружења кроз одељак _Инсталирај > Развој_ у менију Omarchy (`Super + Space`). Наравно, тамо ћете пронаћи _Ruby on Rails_, али и сва три главна извршна окружења за JavaScript (Node.js, Bun, Deno), као и популарне PHP оквире као што су Laravel и Symfony. Ох, а ту су и Go, Rust, Python, Java, Elixir (са Phoenix), .NET, OCaml, Zig, Clojure и Scala. Избор је заиста широк!

Већином ових окружења управља [Mise](https://mise.jdx.dev/). То је алатка која вам омогућава да инсталирате и покрећете више верзија једног програмског језика на истој машини. Слична је алаткама rbenv или rvm за Ruby или virtualenv за Python, али ради са гомилом различитих окружења.

Да бисте инсталирали, рецимо, Ruby, покренули бисте `mise use -g ruby`, чиме се Ruby и инсталира и поставља као глобално подразумевани. Или, ако ваш пројекат има датотеку .ruby-version, можете једноставно покренути `mise i` у корену тог пројекта.

## Унапред инсталиране CLI алатке

`uv`, Node.js и `playwright-cli` (да би агенти управљали прегледачем помоћу инсталираног Chrome) долазе инсталирани као пакети, а `omarchy update` их одржава ажурним заједно са остатком система. `ghui`, [Hunk](https://github.com/modem-dev/hunk) и CLI алатке за Basecamp, Cloudflare и HEY удаљене су само један избор под _Инсталирај > CLI_, а [агенти за програмирање](17-ai.md) под _Инсталирај > AI > CLI_.

mise само управља извршним окружењима које подесите из _Инсталирај > Развој_; Omarchy сам преко њега ништа не инсталира. Покрените `omarchy update` да бисте их ажурирали заједно са остатком система Omarchy; псеудоним `mup` ажурира само алатке којима управља mise. Да бисте додали још једну алатку у сопствену конфигурацију, користите `mise use -g <tool>`.

## Docker

[Docker](https://www.docker.com/) једва да треба представљати. Омогућава вам да покрећете изоловане контејнере, а Omarchy инсталира све што је потребно да би добро радио, укључујући сам Docker и [Docker Compose](https://docs.docker.com/compose/).

Подразумевано ваш корисник *није* у групи `docker`. Та група је заправо root без лозинке — све што се у њој налази може да покрене `docker run -v /:/host` и преузме машину — па би иначе један једини злонамерни скрипт или зависност која се покреће под вашим налогом била само једну команду удаљена од root приступа. Зато Docker на командној линији покрећете са `sudo` (`sudo docker ps`, `sudo docker compose up`), а графичке алатке које комуницирају са демоном — Windows VM — траже ауторизацију када им је потребна. Ако желите да вратите погодност подешавања без групе и разумете компромис, омогућите је из **Подешавање > Безбедност > Sudoless Docker** (или покрените `omarchy-setup-security-sudoless-docker`), чиме вас након упозорења додаје у групу `docker`; тада обични `docker` и псеудоним `d` поново раде без `sudo`.

Уобичајене базе података за локални развој у Docker можете подесити помоћу _Инсталирај > Развој > Docker DB_ у менију Omarchy.

## GitHub CLI

[GitHub CLI](https://cli.github.com/) је `gh`, за рад са репозиторијумима, проблемима и захтевима за повлачење из терминала. _Подешавање > Git_ га инсталира када тамо одлучите да се пријавите на GitHub, а затим `gh repo clone org/repo` клонира репозиторијум. Покрените `gh --help` да бисте истражили његове команде.

_Инсталирај > CLI > GitHub_ инсталира GitHub CLI, `gh`, заједно са `ghui`, терминалским интерфејсом за захтеве за повлачење. [Lazygit](https://github.com/jesseduffield/lazygit) је унапред инсталиран за рад са самим Git.
