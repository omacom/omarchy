# Алати за развој

## Алтернативни уређивачи

Omarchy се на новим инсталацијама испоручује са Plain као подразумеваним уређивачем и унапред инсталираним [Neovim](https://neovim.io/), али ако желите нешто мало више мејнстрим и познатије, можете да покренете Omarchy мени (`Super + Space`) и погледате опције под _Install > Editor_. Тамо смо навели VSCode, Cursor, Zed, Sublime Text, Helix, Vim и Emacs. Ако не пронађете оно што тражите, погледајте _Install > Package_ и проверите да ли није у неком Arch пакету (а ако није, пробајте _Install > AUR_ да проверите AUR).

Оригинални уређивач `vi` такође је доступан одмах по инсталацији. Покрените `vi filename` да бисте уредили датотеку у терминалу.

Упаривање теме нуди се за `VSCode`, `Cursor`, `VSCodium` и `Helix`.

Подразумевани уређивач за цео систем можете да подесите под `Setup > Defaults > Editor`.

## Окружења

Omarchy подржава подешавање целог низа развојних окружења кроз одељак _Install > Development_ у Omarchy менију (`Super + Space`). Тамо ћете, наравно, пронаћи _Ruby on Rails_, али и сва три главна окружења за извршавање JavaScript-а (Node.js, Bun, Deno), као и популарне PHP оквире као што су Laravel и Symfony. А ту су, наравно, и Go, Rust, Python, Java, Elixir (са Phoenix), .NET, OCaml, Zig, Clojure и Scala. Избор је заиста широк!

Већином ових окружења управља [Mise](https://mise.jdx.dev/). То је алат који вам омогућава да инсталирате и покрећете више верзија истог програмског језика на истој машини. Сличан је алатима rbenv или rvm за Ruby или virtualenv за Python, али ради за гомилу различитих окружења.

Да бисте инсталирали, рецимо, Ruby, покренули бисте `mise use -g ruby`, чиме се Ruby и инсталира и поставља као глобално подразумевани. Или, ако ваш пројекат има датотеку .ruby-version, можете просто да покренете `mise i` у корену тог пројекта.

## Унапред инсталирани CLI алати

`uv`, Node.js и `playwright-cli` (да агенти могу да управљају прегледачем, користећи инсталирани Chrome) долазе инсталирани као пакети, а `omarchy update` их одржава актуелним заједно са остатком система. [Hunk](https://github.com/modem-dev/hunk) и CLI алати за GitHub, Basecamp, Cloudflare и HEY удаљени су један избор под _Install > CLI_, а [агенти за програмирање](17-ai.md) под _Install > AI > CLI_.

mise управља само окружењима за извршавање која подесите из _Install > Development_; Omarchy преко њега сам ништа не инсталира. Покрените `omarchy update` да бисте их ажурирали заједно са остатком Omarchy-ја; алиас `mup` ажурира само алате којима управља mise. Да бисте додали још један алат у сопствену конфигурацију, користите `mise use -g <tool>`.

## Docker

[Docker](https://www.docker.com/) готово да не треба представљати. Омогућава вам да покрећете изоловане контејнере, а Omarchy инсталира све што је потребно да добро ради, укључујући сам Docker и [Docker Compose](https://docs.docker.com/compose/).

Подразумевано ваш корисник *није* у групи `docker`. Та група је практично root без лозинке — све што је у њој може да покрене `docker run -v /:/host` и преузме машину — па би једна злонамерна скрипта или зависност која се извршава као ви иначе била само једну команду удаљена од root-а. Зато на командној линији Docker покрећете са `sudo` (`sudo docker ps`, `sudo docker compose up`), а графички алати који разговарају са демоном — Windows VM — траже ауторизацију када им је потребна. Ако желите назад погодност подешавања без групе и разумете компромис, омогућите је из **Setup > Security > Sudoless Docker** (или покрените `omarchy-setup-security-sudoless-docker`), чиме се, након упозорења, додајете у групу `docker`; тада обичан `docker` и алиас `d` поново раде без `sudo`.

Уобичајене базе података за локални развој у Docker-у можете да подесите користећи _Install > Development > Docker DB_ у Omarchy менију.

## GitHub CLI

[GitHub CLI](https://cli.github.com/) је `gh`, за рад са репозиторијумима, проблемима и захтевима за повлачење из терминала. _Setup > Git_ га инсталира када тамо одаберете да се пријавите на GitHub, или га инсталирајте засебно из _Install > CLI > GitHub_. Затим `gh repo clone org/repo` клонира репозиторијум; покрените `gh --help` да бисте истражили његове команде.

[Lazygit](https://github.com/jesseduffield/lazygit) је унапред инсталиран за рад са самим Git-ом.
