# Алати за развој

## Алтернативни уређивачи

Omarchy подразумевано долази са [Neovim](https://neovim.io/), али ако желите нешто мало више мејнстрим и познатије, можете покренути Omarchy мени (`Super + Space`) и погледати опције под _Инсталирај > Editor_. Тамо су наведени VSCode, Cursor, Zed, Sublime Text, Helix, Vim и Emacs. Ако не нађете оно што тражите, погледајте _Инсталирај > Package_ и проверите да ли није у неком Arch пакету (а ако није, пробајте _Инсталирај > AUR_ да проверите AUR).

Оригинални уређивач `vi` је такође доступан одмах по инсталацији. Покрените `vi filename` да уредите датотеку у терминалу.

Усклађивање теме нуди се за `VSCode`, `Cursor`, `VSCodium` и `Helix`.

Подразумевани уређивач за цео систем можете подесити под `Подешавање > Defaults > Editor`.

## Окружење

Omarchy подржава подешавање целог низа развојних окружења кроз одељак _Инсталирај > Development_ у Omarchy менију (`Super + Space`). Наћи ћете, наравно, _Ruby on Rails_, али и сва три главна окружења за JavaScript (Node.js, Bun, Deno), као и популарне PHP фрејмворке попут Laravel и Symfony. А, да, ту су и Go, Rust, Python, Java, Elixir (са Phoenix), .NET, OCaml, Zig, Clojure и Scala. Избор је веома широк!

Већином ових окружења управља [Mise](https://mise.jdx.dev/). То је алат који вам омогућава да инсталирате и покрећете више верзија програмског језика на истој машини. То је као rbenv или rvm за Ruby или virtualenv за Python, али ради за гомилу различитих окружења.

Да инсталирате, рецимо, Ruby, покренули бисте `mise use -g ruby`, што ће и инсталирати Ruby и поставити га као глобални подразумевани. Или, ако ваш пројекат има .ruby-version датотеку, можете једноставно покренути `mise i` у корену тог пројекта.

## Docker

[Docker](https://www.docker.com/) тешко да треба представљање. Омогућава вам покретање изолованих контејнера, а Omarchy инсталира све што је потребно да добро ради, укључујући сам Docker и [Docker Compose](https://docs.docker.com/compose/).

Подразумевано ваш корисник *није* у групи `docker`. Та група је практично root без лозинке — све што је у њој може `docker run -v /:/host` и преузети машину — па би један одбијег скрипт или зависност који се извршава као ви иначе био једну команду удаљен од root-а. Зато на командној линији Docker покрећете са `sudo` (`sudo docker ps`, `sudo docker compose up`), а графички алати који разговарају са демоном — Windows VM — траже ауторизацију када им је потребна. Ако желите погодност поставке без групе назад и разумете компромис, омогућите је из **Подешавање > Security > Sudoless Docker** (или покрените `omarchy-setup-security-sudoless-docker`), што вас додаје у групу `docker` након упозорења; тада обичан `docker` и алијас `d` поново раде без `sudo`.

Можете подесити уобичајене базе података за локални развој у Docker-у помоћу _Инсталирај > Development > Docker DB_ у Omarchy менију.

## GitHub CLI

[GitHub CLI](https://cli.github.com/) вам омогућава да се аутентификујете са својим GitHub налогом и клонирате приватне репозиторијуме помоћу њега. Повезан је као један од mise стубова који се учитавају по потреби, па се први пут када покренете `gh`, сам инсталира. За аутентификацију покрените `gh auth login`. Потом можете преузимати приватне репозиторијуме помоћу `gh repo clone org/repo`.

Можете извршити и гомилу других GitHub операција помоћу ове команде. Једноставно покрените `gh` да видите све што је могуће.

Ту је и стуб који се инсталира по потреби за `ghui` за управљање вашим pull request-има у TUI-ју такође. А [lazygit](https://github.com/jesseduffield/lazygit) је унапред инсталиран, ако желите да управљате и самим git-ом из TUI-ја.
