# Подсетници

Omarchy има уграђен начин за подешавање једноставних подсетника заснованих на тајмеру за одбројавање и с поруком. То можете учинити преко `Super + Ctrl + R`, видети све подешене преко `Super + Ctrl + Alt + R`, а обрисати све преко `Super + Ctrl + Shift + R`. Све је доступно и преко _Покрени > Подсетник_. Такође можете користити CLI са `omarchy reminder 7 'Tea ready'`.
