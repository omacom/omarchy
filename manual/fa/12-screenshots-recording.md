# اسکرین‌شات‌ها و ضبط صفحه

هر چیزی که می‌توانید از صفحه بردارید به کلید Print Screen وابسته است. این کلید به‌تنهایی عکس می‌گیرد، و کلیدهای کمکی ضبط، یک رنگ، یا متن داخل یک ناحیه را برمی‌دارند. اگر صفحه‌کلیدتان اصلاً کلید Print Screen ندارد، `Super + Ctrl + Alt + C` همان اسکرین‌شات را می‌گیرد، و `Super + Ctrl + C` کل مجموعه را به‌صورت یک منو باز می‌کند.

| Hotkey | Function |
| ------ | -------- |
| `Print Screen` | اسکرین‌شات |
| `Super + Ctrl + Alt + C` | اسکرین‌شات |
| `Alt + Print Screen` | ضبط صفحه (یا توقف ضبطی که در حال اجراست) |
| `Super + Print Screen` | انتخاب‌گر رنگ |
| `Super + Ctrl + Print Screen` | استخراج متن از یک ناحیه |
| `Super + Ctrl + C` | منوی Capture |
| `Super + Ctrl + .` | تبدیل فرمت یک عکس یا ویدیو |

## اسکرین‌شات‌ها

`Print Screen` (یا `Super + Ctrl + Alt + C`) را بزنید و Omasnap مانیتور در فوکوس را پیش از ظاهر شدن پوشش خودش ثبت می‌کند، پس وقتی هدف می‌گیرید هیچ چیزی زیر دست‌تان جابه‌جا نمی‌شود. یک ناحیهٔ آزاد بکشید، روی یک پنجره کلیک کنید تا آن را ثبت کنید، یا روی فضای خالی کلیک کنید تا کل مانیتور را ثبت کنید. پیش از کشیدن، `S` را بزنید تا یک ناحیهٔ اسکرول‌شونده را ثبت کنید. نظرتان عوض شد؟ همان کلید را دوباره بزنید تا Omasnap بسته شود.

پس از انتخاب یک ناحیه، Omasnap ثبت را ذخیره می‌کند، آن را در کلیپ‌بورد کپی می‌کند، و ۱۰ ثانیه یک پیش‌نمایش نشان می‌دهد. از دکمهٔ پین پیش‌نمایش یا `Ctrl + P` استفاده کنید تا آن را روی صفحه نگه دارید، یا Edit را انتخاب کنید تا روی آن یادداشت‌گذاری کنید.

ویرایشگر یادداشت‌گذاری می‌تواند پیکان، خط، شکل، هایلایت، نشانگرهای شماره‌دار، متن، و پوشاندن‌های امن بکشد؛ بخشی از تصویر را برش بزند یا جدا کند؛ متن آن را OCR کند؛ و یک پس‌زمینه اضافه کند. در ویرایشگر، `Enter` را بزنید تا PNG نهایی کپی و ذخیره شود، `Ctrl + C` را بزنید تا بدون ذخیره کپی شود، یا `Ctrl + S` را بزنید تا بدون کپی ذخیره شود.

اسکرین‌شات‌های ذخیره‌شده به‌طور پیش‌فرض در `~/Pictures/Screenshots` قرار می‌گیرند، با نامی مانند `screenshot-2026-08-13_14-22-05-firefox.png`. برای استفاده از یک فهرست دیگر، `OMASNAP_SCREENSHOT_DIR` را تنظیم کنید — برای محل قرار دادن متغیرهای محیطی نشست، [پرسش‌های متداول](46-faq.md) را ببینید. Omasnap هنگام ذخیرهٔ اولین شات، آن فهرست را می‌سازد. برای غیرفعال کردن ذخیرهٔ خودکار، `[output] autosave = false` را در `~/.config/omasnap/omasnap.conf` تنظیم کنید.

از ترمینال، `omarchy screenshot` همان پوشش را باز می‌کند، و می‌توانید حالت شروع آن را انتخاب کنید: `omarchy capture screenshot region`، `windows`، `fullscreen` یا `scroll`. آرگومان دومِ `copy` یا `save` پیش‌نمایش را رد می‌کند و شات را مستقیم به آن مقصد می‌فرستد. برای ویرایش پیش از خروجی، از `omarchy screenshot --editor=overlay` برای یک ویرایشگر تمام‌صفحه یا از `omarchy screenshot --editor=window` برای یک پنجرهٔ جدا استفاده کنید.

### هدایت انتخاب‌گر از صفحه‌کلید

وقتی انتخاب بالا آمده است، اصلاً لازم نیست از ماوس استفاده کنید:

| Key | Function |
| --- | -------- |
| `S` | تغییر حالت ناحیهٔ اسکرول‌شونده |
| `Super + Arrow keys` | جابه‌جایی میان پنجره‌ها در حالت Window |
| `Return` | ثبت پنجرهٔ برجسته‌شده |
| `Ctrl + A` | ثبت کل مانیتور در فوکوس |
| `R` | بازیابی آخرین ناحیهٔ کشیده‌شده در این نشست |
| `Esc` | بستن Omasnap |

این میانبرها فقط وقتی وجود دارند که Omasnap باز باشد، پس نمی‌توانند با چیزی در پیکربندی خودتان تداخل پیدا کنند.

## ضبط صفحه

`Alt + Print Screen` مسیر _Trigger > Capture > Screenrecord_ را باز می‌کند، که می‌پرسد در صدای ضبط چه می‌خواهید: بدون صدا، صدای دسکتاپ، دسکتاپ به‌همراه میکروفون، یا دسکتاپ به‌همراه میکروفون به‌همراه وب‌کم. آن گزینهٔ آخری فقط وقتی ظاهر می‌شود که واقعاً یک دوربین وصل کرده باشید. یکی را انتخاب کنید و انتخاب‌گر ضبط Omarchy به شما اجازه می‌دهد یک ناحیه بکشید یا روی یک پنجره یا مانیتور کلیک کنید.

ضبط روی gpu-screen-recorder اجرا می‌شود، که روی GPU با سرعت 60fps رمزگذاری می‌کند و اگر مجبور شود به CPU برمی‌گردد. نتیجه یک MP4 در `~/Videos` است، با نامی مانند `screenrecording-2026-08-13_14-22-05.mp4`. برای تغییر آن، `OMARCHY_SCREENRECORD_DIR` را تنظیم کنید — اما توجه کنید که برخلاف فهرست اسکرین‌شات، این یکی باید از قبل وجود داشته باشد، وگرنه ضبط از شروع شدن سر باز می‌زند.

وقتی در حال ضبط هستید، یک نشانگر کوچک در نوار ظاهر می‌شود. برای توقف، روی آن کلیک کنید. همچنین می‌توانید دوباره با `Alt + Print Screen` متوقف کنید، یا با ورودی _Stop Screenrecording_ در مسیر _Trigger > Capture > Screenrecord_، که فقط وقتی ظاهر می‌شود که واقعاً چیزی در حال ضبط باشد.

توقف، پیش از تحویل فایل به شما کمی مرتب‌کاری انجام می‌دهد: فریم اول بریده می‌شود، و اگر صدایی باشد تا ‎-14 LUFS نرمال‌سازی می‌شود و صدای تقِ ضبط PipeWire در همان ابتدای کار بی‌صدا می‌شود. سپس یک اعلان با یک بندانگشتی از ضبط ظاهر می‌شود. روی آن کلیک کنید تا فایل در mpv پخش شود.

### پوشش وب‌کم

وقتی با وب‌کم ضبط می‌کنید، دوربین به‌صورت یک پنجرهٔ پرترهٔ پین‌شده و برش‌خورده در گوشهٔ پایین-راست هر چیزی که ضبط می‌کنید ظاهر می‌شود. اگر روی چیزی که لازم دارید نشسته است، آن را در لحظه تغییر اندازه دهید:

| Hotkey | Function |
| ------ | -------- |
| `Super + Alt + [` | کوچک‌تر کردن پوشش وب‌کم |
| `Super + Alt + ]` | بزرگ‌تر کردن پوشش وب‌کم |

سه اندازه وجود دارد — کوچک، متوسط و بزرگ — و کلیدهای میانبر میان آن‌ها گام برمی‌دارند. متوسط پیش‌فرض است. آن‌ها متناسب با ضبط هستند، پس دوربین چه در حال ضبط یک مانیتور 1080p باشید چه یک مانیتور 6K، همان سهم از فریم را می‌گیرد. و اگر به‌جای کل یک نمایشگر یک ناحیه را ضبط کرده باشید، پوشش به گوشهٔ آن ناحیه لنگر می‌شود نه گوشهٔ مانیتور، پس داخل شات باقی می‌ماند.

همچنین می‌توانید آن را مستقیم با `omarchy-capture-webcam-resize small` صدا بزنید، یا با `reset` تا به متوسط برگردد.

## متن، کدهای QR و رنگ‌ها

`Super + Ctrl + Print Screen` یک ناحیه را انتخاب می‌کند و آن را با OCR به کلیپ‌بورد می‌فرستد. این درست و حسابی در [استخراج متن و دیکته](11-text-extraction-dictation.md) پوشش داده شده است.

مسیر _Trigger > Capture > QR Code_ همین حقه را برای کدهای QR انجام می‌دهد. ناحیه‌ای را که کد در آن است انتخاب کنید، و مقدار رمزگشایی‌شده به کلیپ‌بورد می‌رود. این فقط دنبال کدهای QR می‌گردد — وگرنه محتوای متراکم صفحه عادت دارد خودش را به‌دروغ جای بارکد جا بزند. دانستنش ارزش دارد: مقدار رمزگشایی‌شده به کلیپ‌بورد می‌رود و هیچ جای دیگر. چاپ نمی‌شود، در اعلان نیست، و حساس علامت‌گذاری شده است تا در [تاریخچهٔ کلیپ‌بورد](08-unified-clipboard-history.md) باقی نماند. کدهای QR معمولاً راز حمل می‌کنند — برای نمونه URI ‏`otpauth://` پشت یک کد راه‌اندازی 2FA — و نمی‌خواهید آن در یک لاگ باشد. چسباندن همچنان خوب کار می‌کند.

`Super + Print Screen` (یا _Trigger > Capture > Color_) نشانگر را به یک قطره‌چکان تبدیل می‌کند. روی هر چیزی روی صفحه کلیک کنید و رنگ در کلیپ‌بورد قرار می‌گیرد. کلید میانبر را دوباره بزنید تا بدون انتخاب کردن بیرون بیایید.

## تبدیل فرمت پیش از اشتراک‌گذاری

یک ضبط صفحهٔ 4K یا یک HEIC خام از گوشی‌تان اغلب برای فرستادنِ همین‌طوری خیلی بزرگ است. `Super + Ctrl + .` (یا _Trigger > Transcode_) این را درست می‌کند. یک انتخاب‌گر فایل فازی روی `~/Pictures` و `~/Videos` به شما پیشنهاد می‌دهد، و سپس یک فرمت و یک اندازه می‌خواهد.

عکس‌ها به jpg یا png در سطح بالا، متوسط یا پایین می‌روند، که عرض را به‌ترتیب به 3160، 2160 و 1080 پیکسل محدود می‌کنند. ویدیوها به mp4 یا یک gif متحرک در 4k، 1080p یا 720p می‌روند. فایل تبدیل‌شده کنار اصل نوشته می‌شود و وضوح در نام آن می‌آید — `demo-1080p.mp4` — و مسیر به‌صورت یک file URI در کلیپ‌بورد کپی می‌شود، پس می‌توانید آن را مستقیم در برنامه‌ای بچسبانید که رها کردن فایل را می‌پذیرد.

از ترمینال هم کار می‌کند، اگر از قبل بدانید چه می‌خواهید: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. همچنین `omarchy transcode ascii` وجود دارد، که یک تصویر را به هنر ASCII تبدیل می‌کند — آن یکی بیشتر برای [برندینگ](41-branding.md) است.

## ارسال آن به جایی

وقتی فایل را به دست آوردید، `Super + Ctrl + S` منوی Share را باز می‌کند و آن را از طریق LocalSend به دستگاه دیگری در شبکه‌تان می‌فرستد. برای آن، [رابط‌های گرافیکی](22-guis.md) را ببینید.
