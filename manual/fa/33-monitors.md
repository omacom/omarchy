# مانیتورها

Omarchy به‌صورت پیش‌فرض فرض می‌کند روی یک نمایشگر در ردهٔ retina با قابلیت 2x کار می‌کنید. این همان چیزی است که برای داشتن آن فونت‌های برنامه‌نویسی زیبا و شفاف لازم دارید. تقریباً همهٔ لپ‌تاپ‌های ممتاز جدید با صفحه‌نمایش‌های وضوح بالا برای همین بهینه شده‌اند. این همان چیزی است که روی یک مانیتور 27" 5K مثل [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) یا 32" 6K مثل [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) می‌خواهید اجرا کنید.

اما اگر نمایشگری با PPI برابر 218 یا بالاتر ندارید، باید تنظیمات مانیتور را تغییر دهید. برای مثال، اگر یک مانیتور 27" یا 32" 4K دارید، می‌توانید با باز کردن `~/.config/hypr/monitors.lua` (از طریق _Setup > Monitors_ در منوی Omarchy) و تغییر به مقدار توصیه‌شده برای آن ترکیب، از مقیاس‌بندی کسری استفاده کنید:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

اگر از یک نمایشگر 1080p یا 1440p استفاده می‌کنید، احتمالاً فقط مقیاس‌بندی 1x را می‌خواهید، پس می‌توانید از این استفاده کنید:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

تغییرات `GDK_SCALE` روی برنامه‌هایی اعمال می‌شود که بعد از تغییر اجرا شوند (و GTK فقط اعداد صحیح را رعایت می‌کند، پس آن را روی نزدیک‌ترین عدد صحیح به مقیاس مانیتورتان نگه دارید). پس حتماً پنجره‌هایی را که بعد از تغییر بیش از حد بزرگ شده‌اند ببندید (یا همهٔ پنجره‌ها را با `Ctrl + Alt + Del` ببندید!).

همچنین می‌توانید با استفاده از `Super + /` برای بالاتر رفتن و `Super + Alt + /` برای پایین‌تر آمدن، یا با انتخاب یکی از پنل مانیتور در نوار بالا، به‌سرعت بین نسبت‌های اصلی مقیاس‌بندی مانیتور (1x, 1.25x, 1.6x, 2x, 3x, 4x) جابه‌جا شوید. این‌ها فقط مانیتوری را تغییر می‌دهند که فوکوس روی آن است، پس صفحهٔ لپ‌تاپ و یک نمایشگر خارجی هر کدام می‌توانند مقیاس خودشان را داشته باشند. این انتخاب به‌صورت یک قانون `hl.monitor` برای آن مانیتور در `~/.config/hypr/monitors.lua` ذخیره می‌شود، پس بعد از راه‌اندازی مجدد باقی می‌ماند و بر `omarchy_monitor_scale` اولویت دارد، که همچنان مقیاس هر مانیتوری بدون قانون مخصوص خودش باقی می‌ماند.

### بزرگ‌تر یا کوچک‌تر کردن متن

مقیاس‌بندی مانیتور اندازهٔ همه‌چیز را تغییر می‌دهد. اگر تنها چیزی که می‌خواهید _متن_ بزرگ‌تر یا کوچک‌تر است، برای آن یک تنظیم واحد وجود دارد:

```
omarchy display text size 14
```

این یک اندازهٔ پیکسلی بین 9 و 20 می‌گیرد، و پوستهٔ Omarchy، برنامه‌های GTK و ترمینال شما را با هم جابه‌جا می‌کند، پس کل دسکتاپ متناسب باقی می‌ماند. آن را بدون آرگومان اجرا کنید تا ببینید کجا هستید، و `omarchy display text size reset` را اجرا کنید تا به مقدار پیش‌فرض برگردید. Foot تنها عقب‌مانده است: راهی برای بارگذاری مجدد پیکربندی‌اش ندارد، پس ترمینال‌های در حال اجرا اندازهٔ قدیمی‌شان را نگه می‌دارند تا وقتی یک ترمینال جدید باز کنید.

### گسترش دادن و آینه‌ای کردن نمایشگرهای لپ‌تاپ

وقتی یک صفحهٔ خارجی را به لپ‌تاپ‌تان وصل می‌کنید، نمایشگر به‌صورت خودکار گسترش داده می‌شود. اما می‌توانید با استفاده از _Trigger > Hardware_ در منوی Omarchy یا `Super + Ctrl + Alt + Delete` آن را به آینه‌ای کردن تغییر دهید. این به‌خصوص وقتی مفید است که آن صفحهٔ خارجی یک پروژکتور باشد، و بخواهید حین کار چیزی را نشان دهید.

وقتی در حال گسترش دادن هستید، بستن در لپ‌تاپ به‌صورت خودکار صفحهٔ داخلی را خاموش می‌کند. باز کردن در آن را دوباره روشن می‌کند. همچنین می‌توانید این را به‌صورت دستی با استفاده از _Trigger > Hardware_ در منوی Omarchy یا `Super + Ctrl + Delete` کنترل کنید.

### چیدن چند صفحه‌نمایش

Hyprland با چند صفحه‌نمایش عالی کار می‌کند. دربارهٔ نحوهٔ چیدن آن‌ها در [مستندات مانیتور Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/) بیشتر بخوانید. در Omarchy، این‌ها به‌صورت ورودی‌های `hl.monitor` در `~/.config/hypr/monitors.lua` قرار می‌گیرند — این فایل با مثال‌های کامنت‌شده‌ای برای ثابت کردن یک مانیتور مشخص روی یک وضوح، موقعیت و چرخش عرضه می‌شود.

هر مانیتور فضاهای کاری 1 تا 10 مخصوص خودش را دارد، پس `Super + 1` همیشه یعنی اولین فضای کاری مانیتوری که روی آن هستید. پشت صحنه، Hyprland همچنان فضاهای کاری را در میان همهٔ مانیتورها شماره‌گذاری می‌کند: صفحهٔ لپ‌تاپ‌تان (یا اولین مانیتور) 1–10 را می‌گیرد، مانیتور بعدی 11–20 را، و به همین ترتیب، و هر مانیتور هر بار که آن را وصل می‌کنید بلوک خودش را نگه می‌دارد. اگر برای یک مانیتور مشخص [قوانین فضای کاری](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) یا قوانین پنجره می‌نویسید از این اعداد استفاده کنید، پس فضای کاری 12 دومین فضای کاری دومین مانیتور شماست. `~/.local/state/omarchy/monitor-workspaces` فهرست می‌کند که هر مانیتور کدام بلوک را دارد.

کلیدهای جهت‌دار در میان مانیتورهایی که در چیدمان شما یک لبهٔ مشترک دارند کار می‌کنند. صفحه‌هایی که فقط در یک گوشه به هم می‌رسند، یا بین‌شان فاصله‌ای وجود دارد، همسایه نیستند، پس برای جابه‌جایی بین آن‌ها از `Ctrl + Alt + Tab` استفاده کنید.

| کلید میانبر | در میان مانیتورها |
| --- | --- |
| `Super + Arrow` | وقتی دیگر پنجره‌ای در آن جهت باقی نمانده است، فوکوس را به مانیتور آن سمت می‌برد |
| `Super + Shift + Arrow` | با یک پنجره روی مانیتور آن سمت جابه‌جا می‌شود |
| `Super + Alt + Arrow` | پنجره را به یک گروه روی مانیتور آن سمت می‌برد |
| `Super + Shift + Ctrl + Arrow` | پنجره را به مانیتور آن سمت، روی فضای کاری‌ای که نشان می‌دهد، می‌برد |
| `Super + Shift + Alt + Arrow` | فضای کاری را به مانیتور آن سمت می‌برد و اگر آزاد باشد شماره‌اش را نگه می‌دارد |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | فوکوس را بدون توجه به چیدمان به مانیتور بعدی یا قبلی می‌برد |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | روی مانیتوری که روی آن هستید باقی می‌مانند |

همچنین می‌توانید نگاهی به [Hyprmon](https://github.com/erans/hyprmon/) بیندازید، اگر یک TUI می‌خواهید که در موقعیت‌دهی چند صفحه‌نمایش به شما کمک کند.

### کنترل روشنایی

روشنایی مانیتور با کلیدهای عملکردی اختصاصی برای افزایش/کاهش روشنایی کنترل می‌شود. اگر هنگام فشردن این کلیدها Shift را نگه دارید، به حداکثر یا حداقل روشنایی می‌روید. این کلیدها نمایشگری را کنترل می‌کنند که فوکوس روی آن است، پس مانیتورهای خارجی که DDC/CI صحبت می‌کنند به همان روش صفحهٔ لپ‌تاپ تنظیم می‌شوند.

### نمایشگرهای Apple

اگر از یک نمایشگر Apple استفاده می‌کنید، کلیدهای معمولی روشنایی صفحه‌کلید نیز به‌صورت خودکار کار می‌کنند، اگر فوکوس روی نمایشگر Apple باشد. این کار از طریق دستور `asdcontrol` انجام می‌شود.

توجه کنید که اگر از یک نمایشگر Apple 6K XDR استفاده می‌کنید، ممکن است یک صفحهٔ شبح در فهرست `hyprctl monitors` خود ببینید. می‌توانید این را با چیزی مثل `hl.monitor({ output = "DP-2", disabled = true })` از طریق _Setup > Monitors_ خاموش کنید.

روی دستگاه‌های Intel، باید با استفاده از یک کابل Thunderbolt معمولی به نمایشگرهای Apple وصل شوید. روی دستگاه‌های دیگر بدون Thunderbolt، معمولاً باید از یک [کابل DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) استفاده کنید تا کار کند.
