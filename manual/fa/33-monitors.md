# مانیتورها

Omarchy فرض می‌کند به‌طور پیش‌فرض روی یک نمایشگر کلاس رتینا با قابلیت 2x اجرا می‌شوید. این همان چیزی است که برای گرفتن آن فونت‌های برنامه‌نویس زیبا و ترد نیاز دارید. این همان چیزی است که تقریباً همه لپ‌تاپ‌های ممتاز جدید با صفحه‌های با وضوح بالا برای آن بهینه شده‌اند. این همان چیزی است که می‌خواهید روی یک [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) ۲۷ اینچی 5K یا یک [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) ۳۲ اینچی 6K اجرا کنید.

اما اگر نمایشگری با PPI ۲۱۸ یا بالاتر اجرا نمی‌کنید، می‌خواهید تنظیمات مانیتور را تغییر دهید. مثلاً، اگر یک ۲۷ یا ۳۲ اینچی 4K دارید، می‌توانید از مقیاس‌بندی کسری با باز کردن `~/.config/hypr/monitors.lua` (از طریق _تنظیمات > Monitors_ در منوی Omarchy) و تغییر به توصیه برای آن ترکیب استفاده کنید:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

اگر از یک نمایشگر 1080p یا 1440p استفاده می‌کنید، احتمالاً فقط می‌خواهید از مقیاس‌بندی 1x استفاده کنید، پس می‌توانید از این استفاده کنید:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

تغییرات در `GDK_SCALE` روی برنامه‌هایی که پس از تغییر شروع شده‌اند اعمال می‌شود (و GTK فقط اعداد کامل را ارج می‌نهد، پس آن را روی نزدیک‌ترین عدد صحیح مقیاس مانیتور خود نگه دارید). پس مطمئن شوید پنجره‌هایی را که پس از تغییر بیش از اندازه هستند ببندید (یا همه پنجره‌ها را با `Ctrl + Alt + Del` ببندید!).

همچنین می‌توانید به‌سرعت از میان نسبت‌های اصلی مقیاس‌بندی مانیتور (1x، 1.25x، 1.6x، 2x، 3x، 4x) با استفاده از `Super + /` برای بالاتر رفتن و `Super + Alt + /` برای پایین‌تر رفتن قدم بزنید. اگر پیکربندی پیش‌فرض را دارید، این تغییرات پس از راه‌اندازی مجدد هم باقی می‌مانند.

### بزرگ‌تر یا کوچک‌تر کردن متن

مقیاس‌بندی مانیتور اندازه هر چیزی را تغییر می‌دهد. اگر همه آنچه می‌خواهید _متن_ بزرگ‌تر یا کوچک‌تر است، یک دکمه واحد برای آن وجود دارد:

```
omarchy display text size 14
```

این یک اندازه پیکسل بین ۹ و ۲۰ می‌گیرد، و شل Omarchy، برنامه‌های GTK و ترمینال شما را با هم حرکت می‌دهد، پس کل دسکتاپ در تناسب می‌ماند. آن را بدون آرگومان اجرا کنید تا ببینید کجا هستید، و `omarchy display text size reset` برای بازگشت به پیش‌فرض. Foot تنها بازمانده است: راهی برای بارگذاری دوباره پیکربندی خود ندارد، پس ترمینال‌های در حال اجرا اندازه قدیمی خود را نگه می‌دارند تا یک ترمینال جدید باز کنید.

### گسترش و آینه کردن نمایشگرهای لپ‌تاپ

وقتی یک صفحه خارجی را به لپ‌تاپ خود وصل می‌کنید، نمایشگر به‌طور خودکار گسترش می‌یابد. اما می‌توانید آن را به آینه کردن تغییر دهید با استفاده از _اجرا > Hardware_ در منوی Omarchy یا `Super + Ctrl + Alt + Delete`. این به‌ویژه اگر آن صفحه خارجی یک پروژکتور باشد، و بخواهید در حین کار چیزی نشان دهید، مفید است.

وقتی در حال گسترش هستید، بستن در لپ‌تاپ به‌طور خودکار صفحه داخلی را خاموش می‌کند. باز کردن در آن را دوباره روشن می‌کند. همچنین می‌توانید این را دستی با استفاده از _اجرا > Hardware_ در منوی Omarchy یا `Super + Ctrl + Delete` کنترل کنید.

### چیدمان چند صفحه

Hyprland با چند صفحه عالی کار می‌کند. درباره نحوه چیدمان آن‌ها در [مستندات مانیتور Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/) بیشتر بخوانید. همچنین می‌توانید [فضاهای کاری خاص را به مانیتورهای خاص مقید کنید](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/). در Omarchy، این قوانین در `~/.config/hypr/monitors.lua` به‌صورت ورودی‌های `hl.monitor` قرار می‌گیرند — فایل با مثال‌های نظرگذاری‌شده برای سنجاق کردن یک مانیتور خاص به یک وضوح، موقعیت و چرخش ارائه می‌شود.

همچنین می‌توانید [Hyprmon](https://github.com/erans/hyprmon/) را ببینید، اگر یک TUI می‌خواهید تا در موقعیت‌یابی چند صفحه به شما کمک کند.

### کنترل روشنایی

روشنایی مانیتور توسط کلیدهای عملکرد اختصاصی برای روشنایی بالا/پایین کنترل می‌شود. اگر هنگام زدن این‌ها shift را نگه دارید، به حداکثر یا حداقل روشنایی می‌روید. کلیدها نمایشگری را که روی آن متمرکز هستید کنترل می‌کنند، پس مانیتورهای خارجی که DDC/CI صحبت می‌کنند به همان روش صفحه لپ‌تاپ تنظیم می‌شوند.

### نمایشگرهای Apple

اگر از یک نمایشگر Apple استفاده می‌کنید، کلیدهای روشنایی صفحه‌کلید معمولی هم به‌طور خودکار کار می‌کنند، اگر روی نمایشگر Apple متمرکز باشید. این از طریق دستور `asdcontrol` انجام می‌شود.

توجه داشته باشید که اگر از یک نمایشگر Apple 6K XDR استفاده می‌کنید، ممکن است یک صفحه شبح در فهرست `hyprctl monitors` خود ببینید. می‌توانید این را با چیزی مانند `hl.monitor({ output = "DP-2", disabled = true })` از طریق _تنظیمات > Monitors_ خاموش کنید.

روی دستگاه‌های Intel، باید با استفاده از یک کابل Thunderbolt معمولی به نمایشگرهای Apple وصل شوید. روی دستگاه‌های دیگر بدون Thunderbolt، معمولاً باید از یک [کابل DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) استفاده کنید تا کار کند.
