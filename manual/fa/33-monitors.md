# مانیتورها

Omarchy به‌طور پیش‌فرض فرض می‌کند که از یک نمایشگر در کلاس رتینا با قابلیت 2x استفاده می‌کنید. این همان چیزی است که برای داشتن آن فونت‌های برنامه‌نویسی زیبا و واضح به آن نیاز دارید. تقریباً همهٔ لپ‌تاپ‌های پریمیوم جدید با صفحه‌نمایش‌های وضوح‌بالا برای همین بهینه شده‌اند. این همان چیزی است که می‌خواهید روی یک [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) 27 اینچی 5K یا یک [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) 32 اینچی 6K اجرا کنید.

اما اگر از نمایشگری با PPI برابر 218 یا بالاتر استفاده نمی‌کنید، باید تنظیمات مانیتور را تغییر دهید. برای مثال، اگر یک نمایشگر 27 اینچی یا 32 اینچی 4K دارید، می‌توانید با باز کردن `~/.config/hypr/monitors.lua` (از طریق _تنظیمات > مانیتورها_ در منوی Omarchy) و تغییر به مقدار توصیه‌شده برای آن ترکیب، از مقیاس‌بندی کسری استفاده کنید:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

اگر از یک نمایشگر 1080p یا 1440p استفاده می‌کنید، احتمالاً فقط مقیاس‌بندی 1x را می‌خواهید، پس می‌توانید از این استفاده کنید:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

تغییرات `GDK_SCALE` روی برنامه‌هایی اعمال می‌شود که بعد از تغییر اجرا شوند (و GTK فقط اعداد صحیح را می‌پذیرد، پس آن را روی نزدیک‌ترین عدد صحیح به مقیاس مانیتورتان نگه دارید). پس حتماً پنجره‌هایی را که بعد از تغییر بیش از حد بزرگ شده‌اند ببندید (یا همهٔ پنجره‌ها را با `Ctrl + Alt + Del` ببندید!).

همچنین می‌توانید با استفاده از `Super + /` برای بالاتر رفتن و `Super + Alt + /` برای پایین‌تر آمدن، یا با انتخاب یکی از پنل مانیتور در نوار بالایی، به‌سرعت بین نسبت‌های اصلی مقیاس‌بندی مانیتور (1x، 1.25x، 1.6x، 2x، 3x، 4x) جابه‌جا شوید. این‌ها فقط مانیتوری را تغییر می‌دهند که فوکوس روی آن است، پس صفحهٔ لپ‌تاپ و یک نمایشگر خارجی هرکدام می‌توانند مقیاس خودشان را داشته باشند. این انتخاب به‌صورت یک قانون `hl.monitor` برای آن مانیتور در `~/.config/hypr/monitors.lua` ذخیره می‌شود، پس بعد از راه‌اندازی مجدد باقی می‌ماند و بر `omarchy_monitor_scale` اولویت دارد، که همچنان مقیاس هر مانیتوری بدون قانون مخصوص خودش باقی می‌ماند. از آنجا که `GDK_SCALE` یک مقدار واحد برای همهٔ صفحه‌هاست، این تغییرات آن را بر اساس مانیتوری با کمترین مقیاس تنظیم می‌کنند، پس برنامه‌های X11 روی صفحهٔ متراکم‌تر کمی کوچک درمی‌آیند، به‌جای اینکه روی صفحهٔ دیگر بیش از حد بزرگ شوند.

### بزرگ‌تر یا کوچک‌تر کردن متن

مقیاس‌بندی مانیتور اندازهٔ همه‌چیز را تغییر می‌دهد. اگر تنها چیزی که می‌خواهید _متن_ بزرگ‌تر یا کوچک‌تر است، فقط یک تنظیم برای آن وجود دارد:

```
omarchy display text size 14
```

این یک اندازهٔ پیکسلی بین 9 تا 20 می‌گیرد و پوستهٔ Omarchy، برنامه‌های GTK و ترمینال شما را با هم جابه‌جا می‌کند، پس کل دسکتاپ متناسب باقی می‌ماند. آن را بدون آرگومان اجرا کنید تا ببینید الان کجا هستید، و `omarchy display text size reset` را برای برگشتن به مقدار پیش‌فرض اجرا کنید. Foot تنها عقب‌مانده است: راهی برای بارگذاری مجدد پیکربندی‌اش ندارد، پس ترمینال‌های در حال اجرا اندازهٔ قدیمی‌شان را نگه می‌دارند تا وقتی یک ترمینال جدید باز کنید.

### گسترش دادن و آینه‌ای کردن نمایشگرهای لپ‌تاپ

وقتی یک صفحهٔ خارجی را به لپ‌تاپ‌تان وصل می‌کنید، نمایشگر به‌طور خودکار گسترش داده می‌شود. اما می‌توانید با استفاده از _راه‌انداز > سخت‌افزار_ در منوی Omarchy یا `Super + Ctrl + Alt + Delete` آن را به آینه‌ای کردن تغییر دهید. این به‌ویژه اگر آن صفحهٔ خارجی یک پروژکتور باشد و بخواهید هنگام کار چیزی را نشان دهید، مفید است.

وقتی در حال گسترش دادن هستید، بستن درِ لپ‌تاپ صفحهٔ داخلی را به‌طور خودکار خاموش می‌کند. باز کردن درِ لپ‌تاپ آن را دوباره روشن می‌کند. همچنین می‌توانید این را به‌صورت دستی با استفاده از _راه‌انداز > سخت‌افزار_ در منوی Omarchy یا `Super + Ctrl + Delete` کنترل کنید.

### چیدمان چند صفحه

Hyprland با چند صفحه عالی کار می‌کند. دربارهٔ نحوهٔ چیدمان آن‌ها در [مستندات مانیتور Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/) بیشتر بخوانید. در Omarchy، این‌ها به‌صورت ورودی‌های `hl.monitor` در `~/.config/hypr/monitors.lua` قرار می‌گیرند — فایل با مثال‌های کامنت‌شده برای ثابت کردن یک مانیتور خاص روی یک وضوح، موقعیت و چرخش عرضه می‌شود.

هر مانیتور فضاهای کاری 1 تا 10 مخصوص خودش را دارد، پس `Super + 1` همیشه یعنی اولین فضای کاری مانیتوری که روی آن هستید. در پشت صحنه، Hyprland همچنان فضاهای کاری را در همهٔ مانیتورها شماره‌گذاری می‌کند: صفحهٔ لپ‌تاپ شما (یا اولین مانیتور) 1–10 را می‌گیرد، مانیتور بعدی 11–20 را، و به همین ترتیب، و هر مانیتور هر بار که آن را وصل می‌کنید بلوک خودش را نگه می‌دارد. اگر برای یک مانیتور خاص [قوانین فضای کاری](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) یا قوانین پنجره می‌نویسید از آن شماره‌ها استفاده کنید، پس فضای کاری 12 دومین فضای کاری دومین مانیتور شماست. `~/.local/state/omarchy/monitor-workspaces` فهرست می‌کند که هر مانیتور کدام بلوک را دارد.

کلیدهای جهت‌نما روی مانیتورهایی که در چیدمان شما یک لبهٔ مشترک دارند کار می‌کنند. صفحه‌هایی که فقط در یک گوشه به هم می‌رسند، یا بین‌شان فاصله است، همسایه نیستند، پس برای جابه‌جایی بین آن‌ها از `Ctrl + Alt + Tab` استفاده کنید.

| کلید میانبر | بین مانیتورها |
| --- | --- |
| `Super + Arrow` | وقتی دیگر پنجره‌ای در آن جهت نمانده باشد، فوکوس را به مانیتور آن سمت می‌برد |
| `Super + Shift + Arrow` | با یک پنجره روی مانیتور آن سمت جابه‌جا می‌شود |
| `Super + Alt + Arrow` | پنجره را به یک گروه روی مانیتور آن سمت منتقل می‌کند |
| `Super + Shift + Ctrl + Arrow` | پنجره را به مانیتور آن سمت، روی فضای کاری‌ای که نشان می‌دهد، منتقل می‌کند |
| `Super + Shift + Alt + Arrow` | فضای کاری را به مانیتور آن سمت منتقل می‌کند و اگر آزاد باشد شماره‌اش را نگه می‌دارد |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | فوکوس را به مانیتور بعدی یا قبلی می‌برد، هر چیدمانی که باشد |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | روی مانیتوری که روی آن هستید می‌مانند |

همچنین می‌توانید [Hyprmon](https://github.com/erans/hyprmon/) را بررسی کنید، اگر یک TUI می‌خواهید که در موقعیت‌دهی چند صفحه به شما کمک کند.

### کنترل روشنایی

روشنایی مانیتور با کلیدهای تابعی اختصاصی افزایش/کاهش روشنایی کنترل می‌شود. اگر هنگام فشار دادن این کلیدها Shift را نگه دارید، به حداکثر یا حداقل روشنایی می‌روید. کلیدها نمایشگری را کنترل می‌کنند که فوکوس روی آن است، پس مانیتورهای خارجی که DDC/CI صحبت می‌کنند به همان روش صفحهٔ لپ‌تاپ تنظیم می‌شوند.

### نمایشگرهای Apple

اگر از یک نمایشگر Apple استفاده می‌کنید، کلیدهای معمولی روشنایی صفحه‌کلید نیز به‌طور خودکار کار خواهند کرد، اگر فوکوس روی نمایشگر Apple باشد. این کار از طریق دستور `asdcontrol` انجام می‌شود.

توجه کنید که اگر از یک نمایشگر Apple 6K XDR استفاده می‌کنید، ممکن است یک صفحهٔ خیالی در فهرست `hyprctl monitors` خود ببینید. می‌توانید این را با چیزی مثل `hl.monitor({ output = "DP-2", disabled = true })` از طریق _تنظیمات > مانیتورها_ خاموش کنید.

روی دستگاه‌های Intel، باید با استفاده از یک کابل Thunderbolt معمولی به نمایشگرهای Apple وصل شوید. روی دستگاه‌های دیگر بدون Thunderbolt، معمولاً برای اینکه کار کند باید از یک [کابل DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) استفاده کنید.
