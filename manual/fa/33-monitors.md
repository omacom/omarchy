# نمایشگرها

Omarchy به‌طور پیش‌فرض فرض می‌کند روی یک نمایشگر در ردهٔ retina با قابلیت 2x کار می‌کنید. این همان چیزی است که برای داشتن آن فونت‌های برنامه‌نویسی زیبا و واضح لازم دارید. این همان چیزی است که تقریباً همهٔ لپ‌تاپ‌های ممتاز جدید با صفحه‌نمایش‌های وضوح‌بالا برای آن بهینه شده‌اند. این همان چیزی است که می‌خواهید روی یک نمایشگر ۲۷ اینچی 5K مانند [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) یا ۳۲ اینچی 6K مانند [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) اجرا کنید.

اما اگر از نمایشگری با PPI برابر ۲۱۸ یا بالاتر استفاده نمی‌کنید، باید تنظیمات نمایشگر را تغییر دهید. برای مثال، اگر یک نمایشگر ۲۷ یا ۳۲ اینچی 4K دارید، می‌توانید با باز کردن `~/.config/hypr/monitors.lua` (از طریق _Setup > Monitors_ در منوی Omarchy) و تغییر به مقدار توصیه‌شده برای آن ترکیب، از مقیاس‌بندی کسری استفاده کنید:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

اگر از یک نمایشگر 1080p یا 1440p استفاده می‌کنید، احتمالاً فقط مقیاس‌بندی 1x را می‌خواهید، پس می‌توانید از این استفاده کنید:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

تغییرات در `GDK_SCALE` روی برنامه‌هایی اعمال می‌شود که پس از تغییر اجرا شوند (و GTK فقط اعداد صحیح را می‌پذیرد، پس آن را روی نزدیک‌ترین عدد صحیح به مقیاس نمایشگرتان نگه دارید). پس مطمئن شوید پنجره‌هایی را که پس از تغییر بیش‌ازحد بزرگ شده‌اند ببندید (یا همهٔ پنجره‌ها را با `Ctrl + Alt + Del` ببندید!).

همچنین می‌توانید با استفاده از `Super + /` برای بالاتر رفتن و `Super + Alt + /` برای پایین‌تر رفتن، به‌سرعت بین نسبت‌های اصلی مقیاس‌بندی نمایشگر (1x، 1.25x، 1.6x، 2x، 3x، 4x) جابه‌جا شوید. اگر پیکربندی پیش‌فرض را دارید، این تغییرات پس از راه‌اندازی مجدد هم باقی خواهند ماند.

### بزرگ‌تر یا کوچک‌تر کردن متن

مقیاس‌بندی نمایشگر اندازهٔ همه‌چیز را تغییر می‌دهد. اگر تنها چیزی که می‌خواهید متن بزرگ‌تر یا کوچک‌تر است، برای آن فقط یک تنظیم وجود دارد:

```
omarchy display text size 14
```

این دستور یک اندازهٔ پیکسلی بین ۹ تا ۲۰ می‌گیرد و پوستهٔ Omarchy، برنامه‌های GTK و ترمینال شما را با هم جابه‌جا می‌کند، تا کل دسک‌تاپ متناسب بماند. آن را بدون آرگومان اجرا کنید تا ببینید اکنون کجا هستید، و `omarchy display text size reset` را برای بازگشت به مقدار پیش‌فرض اجرا کنید. Foot تنها عقب‌مانده است: هیچ راهی برای بارگذاری مجدد پیکربندی‌اش ندارد، پس ترمینال‌های در حال اجرا اندازهٔ قدیمی خود را حفظ می‌کنند تا وقتی یک ترمینال جدید باز کنید.

### گسترش دادن و آینه‌ای کردن نمایشگرهای لپ‌تاپ

وقتی یک صفحه‌نمایش خارجی را به لپ‌تاپ خود وصل می‌کنید، نمایشگر به‌طور خودکار گسترش می‌یابد. اما می‌توانید با استفاده از _Trigger > Hardware_ در منوی Omarchy یا `Super + Ctrl + Alt + Delete` آن را به‌جای آن به حالت آینه‌ای تغییر دهید. این به‌ویژه اگر آن صفحه‌نمایش خارجی یک پروژکتور باشد و بخواهید هنگام کار چیزی را نشان دهید، مفید است.

وقتی در حال گسترش دادن هستید، بستن درِ لپ‌تاپ به‌طور خودکار صفحه‌نمایش داخلی را خاموش می‌کند. باز کردن در، آن را دوباره روشن می‌کند. همچنین می‌توانید این را به‌صورت دستی با استفاده از _Trigger > Hardware_ در منوی Omarchy یا `Super + Ctrl + Delete` کنترل کنید.

### چیدمان چند صفحه‌نمایش

Hyprland با چند صفحه‌نمایش عالی کار می‌کند. دربارهٔ نحوهٔ چیدمان آن‌ها در [مستندات نمایشگر Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/) بیشتر بخوانید. در Omarchy، این‌ها به‌صورت ورودی‌های `hl.monitor` در `~/.config/hypr/monitors.lua` قرار می‌گیرند — این فایل با مثال‌های کامنت‌گذاری‌شده برای ثابت کردن یک نمایشگر مشخص به یک وضوح، موقعیت و چرخش عرضه می‌شود.

هر نمایشگر فضاهای کاری ۱ تا ۱۰ مخصوص به خود را دارد، پس `Super + 1` همیشه یعنی اولین فضای کاری نمایشگری که روی آن هستید. پشت صحنه، Hyprland همچنان فضاهای کاری را در همهٔ نمایشگرها شماره‌گذاری می‌کند: صفحه‌نمایش لپ‌تاپ شما (یا اولین نمایشگر) ۱–۱۰ را می‌گیرد، نمایشگر بعدی ۱۱–۲۰ را می‌گیرد و به همین ترتیب، و هر نمایشگر هر بار که آن را وصل می‌کنید بلوک خود را حفظ می‌کند. اگر برای یک نمایشگر مشخص [قوانین فضای کاری](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) یا قوانین پنجره می‌نویسید، از این اعداد استفاده کنید؛ پس فضای کاری ۱۲ دومین فضای کاری دومین نمایشگر شماست. `~/.local/state/omarchy/monitor-workspaces` فهرست می‌کند که هر نمایشگر کدام بلوک را دارد.

کلیدهای جهت‌دار در میان نمایشگرهایی که در چیدمان شما یک لبهٔ مشترک دارند کار می‌کنند. صفحه‌نمایش‌هایی که فقط در یک گوشه به هم می‌رسند، یا بین آن‌ها فاصله‌ای وجود دارد، همسایه نیستند، پس برای رفتن بین آن‌ها از `Ctrl + Alt + Tab` استفاده کنید.

| کلید میانبر | در میان نمایشگرها |
| --- | --- |
| `Super + Arrow` | وقتی دیگر پنجره‌ای در آن جهت باقی نمانده باشد، تمرکز را به نمایشگر آن سمت منتقل می‌کند |
| `Super + Shift + Arrow` | با یک پنجره روی نمایشگر آن سمت جابه‌جا می‌شود |
| `Super + Alt + Arrow` | پنجره را به یک گروه روی نمایشگر آن سمت منتقل می‌کند |
| `Super + Shift + Ctrl + Arrow` | پنجره را به نمایشگر آن سمت، روی فضای کاری‌ای که نشان می‌دهد، منتقل می‌کند |
| `Super + Shift + Alt + Arrow` | فضای کاری را به نمایشگر آن سمت منتقل می‌کند و اگر آزاد باشد شماره‌اش را حفظ می‌کند |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | تمرکز را به نمایشگر بعدی یا قبلی منتقل می‌کند، چیدمان هر چه باشد |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | روی نمایشگری که روی آن هستید باقی می‌مانند |

همچنین می‌توانید نگاهی به [Hyprmon](https://github.com/erans/hyprmon/) بیندازید، اگر یک TUI می‌خواهید که در موقعیت‌دهی چند صفحه‌نمایش به شما کمک کند.

### کنترل روشنایی

روشنایی نمایشگر با کلیدهای عملکردی اختصاصی برای افزایش/کاهش روشنایی کنترل می‌شود. اگر هنگام فشار دادن این کلیدها shift را نگه دارید، به حداکثر یا حداقل روشنایی خواهید رفت. این کلیدها نمایشگری را که روی آن تمرکز دارید کنترل می‌کنند، پس نمایشگرهای خارجی‌ای که به زبان DDC/CI صحبت می‌کنند به همان شیوهٔ صفحه‌نمایش لپ‌تاپ تنظیم می‌شوند.

### نمایشگرهای Apple

اگر از یک نمایشگر Apple استفاده می‌کنید، کلیدهای معمولی روشنایی صفحه‌کلید نیز به‌طور خودکار کار خواهند کرد، اگر روی نمایشگر Apple تمرکز داشته باشید. این کار از طریق دستور `asdcontrol` انجام می‌شود.

توجه کنید که اگر از یک نمایشگر Apple 6K XDR استفاده می‌کنید، ممکن است یک صفحه‌نمایش خیالی در فهرست `hyprctl monitors` خود ببینید. می‌توانید این را با چیزی مانند `hl.monitor({ output = "DP-2", disabled = true })` از طریق _Setup > Monitors_ خاموش کنید.

روی دستگاه‌های Intel، باید با استفاده از یک کابل معمولی Thunderbolt به نمایشگرهای Apple متصل شوید. روی دستگاه‌های دیگر بدون Thunderbolt، معمولاً باید از یک [کابل DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) استفاده کنید تا کار کند.
