# مانیتورها

Omarchy به‌صورت پیش‌فرض فرض می‌کند که روی یک نمایشگر در رده‌ی retina با قابلیت 2x کار می‌کنید. این همان چیزی است که برای داشتن آن فونت‌های برنامه‌نویسی خوش‌تراش و واضح لازم دارید. همان چیزی است که تقریباً همه‌ی لپ‌تاپ‌های پریمیوم جدید با صفحه‌نمایش‌های وضوح‌بالا برایش بهینه شده‌اند. همان چیزی است که می‌خواهید روی یک نمایشگر 27" 5K مانند [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) یا یک نمایشگر 32" 6K مانند [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) اجرا کنید.

اما اگر نمایشگری با PPI برابر 218 یا بالاتر ندارید، باید تنظیمات مانیتور را تغییر دهید. برای مثال، اگر یک نمایشگر 27" یا 32" 4K دارید، می‌توانید از پنل مانیتور در نوار بالایی یک مقیاس کسری برای آن انتخاب کنید، یا با باز کردن `~/.config/hypr/monitors.lua` و تغییر به توصیه‌ی مربوط به آن ترکیب، مقدار پیش‌فرض را برای هر مانیتور تنظیم کنید:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

اگر از نمایشگر 1080p یا 1440p استفاده می‌کنید، احتمالاً فقط مقیاس 1x می‌خواهید، و همین‌طور برای برنامه‌های GTK و X11، پس می‌توانید از این استفاده کنید:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

تغییرات `GDK_SCALE` روی برنامه‌هایی اعمال می‌شود که بعد از تغییر اجرا شده‌اند (و GTK فقط اعداد صحیح را می‌پذیرد، پس آن را روی نزدیک‌ترین عدد صحیح به مقیاس مانیتورتان نگه دارید). پس مطمئن شوید پنجره‌هایی را که بعد از تغییر بیش‌ازحد بزرگ شده‌اند می‌بندید (یا همه‌ی پنجره‌ها را با `Ctrl + Alt + Del` ببندید!).

همچنین می‌توانید با استفاده از `Super + /` برای رفتن به بالاتر و `Super + Alt + /` برای رفتن به پایین‌تر، یا با انتخاب از پنل مانیتور در نوار بالایی، به‌سرعت بین نسبت‌های اصلی مقیاس مانیتور (1x, 1.25x, 1.6x, 2x, 3x, 4x) جابه‌جا شوید. این‌ها فقط مانیتوری را تغییر می‌دهند که روی آن فوکوس دارید، پس صفحه‌ی لپ‌تاپ و یک نمایشگر خارجی هر کدام می‌توانند مقیاس خودشان را داشته باشند. این پنل وضوح هر مانیتور را هم تنظیم می‌کند. انتخاب‌های شما برای آن مانیتور فیزیکی در `~/.local/state/omarchy/monitors/settings` ذخیره می‌شود، پس بعد از راه‌اندازی مجدد باقی می‌مانند و همراه مانیتور به هر پورت یا داکی که دفعه‌ی بعد به آن وصل شود می‌روند. این انتخاب‌ها بر هر قاعده‌ای برای همان مانیتور در `~/.config/hypr/monitors.lua` اولویت دارند، فایلی که Omarchy هرگز ویرایشش نمی‌کند. از آنجا که `GDK_SCALE` یک مقدار واحد برای همه‌ی صفحه‌هاست، یک مقیاس انتخاب‌شده آن را از روی مانیتوری با کمترین مقیاس تنظیم می‌کند، پس برنامه‌های X11 روی صفحه‌ی متراکم‌تر کمی کوچک درمی‌آیند، نه اینکه روی صفحه‌ی دیگر بیش‌ازحد بزرگ شوند.

### بزرگ‌تر یا کوچک‌تر کردن متن

مقیاس مانیتور اندازه‌ی همه‌چیز را تغییر می‌دهد. اگر تنها چیزی که می‌خواهید متن بزرگ‌تر یا کوچک‌تر است، برای آن فقط یک دستگیره وجود دارد:

```
omarchy display text size 14
```

این دستور یک اندازه‌ی پیکسلی بین 9 تا 20 می‌گیرد و پوسته‌ی Omarchy، برنامه‌های GTK و ترمینال شما را با هم جابه‌جا می‌کند، پس کل دسک‌تاپ متناسب باقی می‌ماند. آن را بدون آرگومان اجرا کنید تا ببینید الان کجا هستید، و `omarchy display text size reset` را اجرا کنید تا به مقدار پیش‌فرض برگردید. Foot تنها عقب‌مانده است: راهی برای بارگذاری مجدد پیکربندی‌اش ندارد، پس ترمینال‌های در حال اجرا اندازه‌ی قدیمی‌شان را حفظ می‌کنند تا وقتی که یک ترمینال جدید باز کنید.

### گسترش و آینه‌ای کردن نمایشگرهای لپ‌تاپ

وقتی یک صفحه‌ی خارجی را به لپ‌تاپ‌تان وصل می‌کنید، نمایشگر به‌صورت خودکار گسترش پیدا می‌کند. اما می‌توانید با استفاده از _Trigger > Hardware_ در منوی Omarchy یا `Super + Ctrl + Alt + Delete` آن را به‌جای آن به حالت آینه‌ای تغییر دهید. این به‌ویژه وقتی مفید است که آن صفحه‌ی خارجی یک پروژکتور باشد و بخواهید حین کار چیزی را نمایش دهید.

وقتی در حالت گسترش هستید، بستن درِ لپ‌تاپ به‌صورت خودکار صفحه‌ی داخلی را خاموش می‌کند. باز کردن در، آن را دوباره روشن می‌کند. همچنین می‌توانید این را به‌صورت دستی با استفاده از _Trigger > Hardware_ در منوی Omarchy یا `Super + Ctrl + Delete` کنترل کنید.

### چیدن چند صفحه

Hyprland با چند صفحه عالی کار می‌کند. پنل مانیتور در نوار بالایی آن‌ها را همان‌جایی که قرار گرفته‌اند می‌کشد: یکی را به لبه‌ی دیگری بکشید تا به آنجا منتقل شود و این چیدمان همراه با سایر تنظیمات هر مانیتور ذخیره می‌شود. برای هر چیزی که پنل پوشش نمی‌دهد، درباره‌ی نحوه‌ی چیدن آن‌ها در [مستندات مانیتور Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/) بیشتر بخوانید. در Omarchy، این‌ها در `~/.config/hypr/monitors.lua` به‌صورت ورودی‌های `hl.monitor` قرار می‌گیرند — این فایل با مثال‌های کامنت‌شده برای ثابت کردن یک مانیتور مشخص روی یک وضوح، موقعیت و چرخش عرضه می‌شود.

هر مانیتور فضای کاری 1 تا 10 مخصوص خودش را دارد، پس `Super + 1` همیشه یعنی اولین فضای کاری مانیتوری که روی آن هستید. در پشت صحنه، Hyprland همچنان فضاهای کاری را در میان همه‌ی مانیتورها شماره‌گذاری می‌کند: صفحه‌ی لپ‌تاپ شما (یا اولین مانیتور) 1–10 را می‌گیرد، مانیتور بعدی 11–20 را و به همین ترتیب، و هر مانیتور هر بار که آن را وصل می‌کنید بلوک خودش را حفظ می‌کند. اگر [قوانین فضای کاری](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) یا قوانین پنجره را برای یک مانیتور مشخص می‌نویسید از آن شماره‌ها استفاده کنید، پس فضای کاری 12 دومین فضای کاری دومین مانیتور شماست. `~/.local/state/omarchy/monitors/workspaces` فهرست می‌کند که هر مانیتور کدام بلوک را دارد.

کلیدهای جهت‌دار روی مانیتورهایی که در چیدمان شما یک لبه‌ی مشترک دارند کار می‌کنند. صفحه‌هایی که فقط در یک گوشه به هم می‌رسند، یا بین‌شان فاصله است، همسایه نیستند، پس برای جابه‌جایی بین آن‌ها از `Ctrl + Alt + Tab` استفاده کنید.

| کلید میانبر | بین مانیتورها |
| --- | --- |
| `Super + Arrow` | وقتی دیگر پنجره‌ای در آن جهت باقی نمانده باشد، فوکوس را به مانیتور آن سمت منتقل می‌کند |
| `Super + Shift + Arrow` | با پنجره‌ای روی مانیتور آن سمت جابه‌جا می‌شود |
| `Super + Alt + Arrow` | پنجره را به یک گروه روی مانیتور آن سمت منتقل می‌کند |
| `Super + Shift + Ctrl + Arrow` | پنجره را به مانیتور آن سمت، روی فضای کاری‌ای که نشان می‌دهد، منتقل می‌کند |
| `Super + Shift + Alt + Arrow` | فضای کاری را به مانیتور آن سمت منتقل می‌کند و اگر آزاد باشد شماره‌اش را حفظ می‌کند |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | بدون توجه به چیدمان، فوکوس را به مانیتور بعدی یا قبلی منتقل می‌کند |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | روی مانیتوری که روی آن هستید باقی می‌مانند |

همچنین می‌توانید [Hyprmon](https://github.com/erans/hyprmon/) را بررسی کنید، اگر یک TUI می‌خواهید که در موقعیت‌دهی چند صفحه به شما کمک کند.

### کنترل روشنایی

روشنایی مانیتور با کلیدهای عملکردی اختصاصی افزایش/کاهش روشنایی کنترل می‌شود. اگر هنگام فشار دادن این کلیدها shift را نگه دارید، به حداکثر یا حداقل روشنایی می‌روید. این کلیدها نمایشگری را کنترل می‌کنند که روی آن فوکوس دارید، پس مانیتورهای خارجی که DDC/CI صحبت می‌کنند به همان شیوه‌ی صفحه‌ی لپ‌تاپ تنظیم می‌شوند.

### نمایشگرهای Apple

اگر از یک نمایشگر Apple استفاده می‌کنید، کلیدهای معمولی روشنایی صفحه‌کلید هم به‌صورت خودکار کار خواهند کرد، اگر روی نمایشگر Apple فوکوس داشته باشید. این کار از طریق دستور `asdcontrol` انجام می‌شود.

توجه کنید که اگر از یک نمایشگر Apple 6K XDR استفاده می‌کنید، ممکن است در فهرست `hyprctl monitors` خود یک صفحه‌ی خیالی ببینید. می‌توانید این را با چیزی مانند `hl.monitor({ output = "DP-2", disabled = true })` در `~/.config/hypr/monitors.lua` خاموش کنید.

روی دستگاه‌های Intel، باید نمایشگرهای Apple را با یک کابل Thunderbolt معمولی وصل کنید. روی دستگاه‌های دیگر بدون Thunderbolt، معمولاً برای اینکه کار کند باید از یک [کابل DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) استفاده کنید.
