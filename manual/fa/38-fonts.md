# قلم‌ها

Omarchy به طور پیش‌فرض از JetBrainsMono Nerd Font هم به عنوان قلم ترمینال و هم قلم سیستم استفاده می‌کند.

 ![fonts-jetbrainsmono](images/fonts-jetbrainsmono.webp)

می‌توانید این را از طریق منوی _ظاهر > قلم_ در منوی Omarchy (`Super + Space`) تغییر دهید. این قلم تک‌فاصله را در همه جا تنظیم می‌کند: ترمینال، نوار و هر چیز دیگری که آن را درخواست کند.

می‌توانید قلم‌های برنامه‌نویسی محبوب دیگر را از طریق _نصب > ظاهر > قلم_ در منوی Omarchy نصب کنید: Cascadia Mono و Meslo LG Mono و Fira Code و Victor Code و Bitstream Vera Mono و Iosevka همگی فقط یک کلیک فاصله دارند، در نسخه‌های Nerd Font خودشان تا گلیف‌ها در نوار و ترمینال همچنان کار کنند. بعد از نصب یکی، آن را در _ظاهر > قلم_ انتخاب کنید.
