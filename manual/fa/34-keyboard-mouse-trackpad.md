# صفحه‌کلید، ماوس، ترک‌پد

Hyprland به شما اجازه می‌دهد همه ورودی‌هایتان را با جزئیات فراوان پیکربندی کنید. می‌توانید تکرار صفحه‌کلید را به‌طرز فوق‌العاده‌ای سریع کنید یا کاری کنید ترک‌پد از پیمایش طبیعی استفاده کند. همه این‌ها را در `~/.config/hypr/input.lua` تغییر می‌دهید، که از طریق _Setup > Input_ در منوی Omarchy (`Super + Space`) نیز می‌توانید به آن برسید. هر چیزی که آنجا تنظیم کنید جایگزین پیش‌فرض‌های Omarchy می‌شود.

در اینجا یک نمونه آمده است:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

می‌توانید [همه گزینه‌های ورودی را ببینید](https://wiki.hypr.land/Configuring/Basics/Variables/#input) در ویکی Hyprland برای ورودی‌ها.

CapsLock به‌عنوان یک Caps Lock معمولی کار می‌کند، و `Shift + CapsLock` کلید compose برای [ایموجی‌های سریع](07-hotkeys.md#quick-emojis) و [تکمیل‌های دیگر](07-hotkeys.md#quick-completions) است. اگر ترجیح می‌دهید کلید compose جای دیگری باشد، `omarchy:shift_caps_compose` را در `kb_options` جایگزین کنید. برای مثال، این کار کلید compose را به Right Alt منتقل می‌کند:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### حرکات ترک‌پد

همچنین می‌توانید [حرکات تاچ‌پد](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/) را فعال کنید، مانند کشیدن سه انگشت برای تغییر فضاهای کاری:

```lua
hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })
```

در لپ‌تاپ‌های Dell XPS با تاچ‌پد هپتیک، همچنین می‌توانید قدرت کلیک را در _Trigger > Hardware > Touchpad Haptics_ روی کم، متوسط یا زیاد تنظیم کنید.

### تایپ به چینی، ژاپنی و زبان‌های دیگر

هنگامی که نصب‌کننده صفحه‌کلیدتان را می‌پرسد، ژاپنی، کره‌ای، چینی (ساده‌شده، Pinyin)، تایوان (Zhuyin) یا هنگ‌کنگ (Cangjie) را انتخاب کنید. Omarchy صفحه‌کلید و موتور ورودی منطبق را به‌طور خودکار پیکربندی می‌کند، از جمله در طول راه‌اندازی آفلاین هنگام اولین بوت. ژاپنی از Mozc استفاده می‌کند، کره‌ای از Hangul استاندارد دومجموعه‌ای استفاده می‌کند، چینی ساده‌شده از Pinyin استفاده می‌کند، تایوان از آرایش استاندارد Zhuyin مربوط به Chewing استفاده می‌کند، و هنگ‌کنگ از Cangjie با فرم‌های نویسه هنگ‌کنگی استفاده می‌کند. ژاپنی (صفحه‌کلید US) Mozc را با چیدمان صفحه‌کلید US ارائه می‌دهد. کلیدهای Hangul، Zhuyin و Cangjie حتی وقتی حروف لاتین را با Dvorak، Colemak یا AZERTY تایپ می‌کنید، در موقعیت‌های استاندارد خود باقی می‌مانند. اگر پیش از این Hangul یا Chewing را اضافه کرده‌اید، آن را در _Setup > Typing > Input Methods_ از حالت انتخاب خارج و دوباره انتخاب کنید تا کلیدهایش به آنجا منتقل شوند؛ Omarchy موتوری را که از قبل با آن تایپ می‌کنید به حال خود می‌گذارد.

تایپ در حالت لاتین شروع می‌شود. `Super + I` را فشار دهید تا در میان روش‌های ورودی پیکربندی‌شده بچرخید، و `Super + Shift + I` را فشار دهید تا در جهت عکس بچرخید. `Shift` را به‌تنهایی بزنید تا از روش ورودی مانند Pinyin به حروف لاتین خارج شوید، و دوباره آن را بزنید تا برگردید، همان‌طور که Sogou، Microsoft Pinyin و macOS کار می‌کنند؛ `Shift` به‌همراه یک حرف همچنان یک حرف بزرگ تایپ می‌کند. در صفحه‌کلیدهای ژاپنی، 全角/半角 ورودی را روشن/خاموش می‌کند، 変換 آن را روشن می‌کند، و 無変換 آن را خاموش می‌کند. با کره‌ای، 한/영 Hangul را تغییر می‌دهد و 한자 به Hanja تبدیل می‌کند، چه صفحه‌کلیدتان کلیدهای اختصاصی داشته باشد و چه مانند بسیاری از لپ‌تاپ‌ها برای آن‌ها Right Alt و Right Ctrl بفرستد، بنابراین Right Alt و Right Ctrl در آنجا تغییردهنده‌های ساده نیستند؛ قابلیت فشردن و نگه‌داشتن برای دیکته روی F9 باقی می‌ماند. `Ctrl + Space` برای Tmux و Herdr در دسترس باقی می‌ماند؛ `Shift + CapsLock` کلید compose باقی می‌ماند.

نشانگر صفحه‌کلید وقتی چند چیدمان صفحه‌کلید یا روش ورودی داشته باشید، در سمت راست نوار ظاهر می‌شود. برای تغییر زبان‌های ورودی روی آن کلیک کنید؛ ژاپنی あ را برای hiragana نمایش می‌دهد. برای انتخاب نویسه‌های ژاپنی، به ژاپنی تغییر دهید، کلمه‌ای مانند `nihongo` تایپ کنید، سپس Space را دو بار فشار دهید. Enter را فشار دهید تا انتخابتان پذیرفته شود. اگر چند چیدمان صفحه‌کلید هم دارید، روی نشانگر راست‌کلیک کنید تا در میان آن‌ها بچرخید.

از _Setup > Typing > Keyboard Layouts_ استفاده کنید تا چیدمان‌هایی مانند English و French را از همان گزینه‌هایی که هنگام نصب ارائه می‌شوند انتخاب کنید. از _Setup > Typing > Input Methods_ استفاده کنید تا انتخاب کنید کدام موتورهای ترکیب فعال باشند. هر دو انتخاب‌گر درون منوی Omarchy باز می‌شوند و انتخاب‌های فعلی شما تیک خورده‌اند. برای فعال یا غیرفعال کردن یک گزینه کلیک کنید یا Enter را فشار دهید؛ هر تغییر بلافاصله اعمال می‌شود. خارج کردن یک روش ورودی از حالت انتخاب، آن را بدون حذف نصب، از چرخه خارج می‌کند؛ صفحه‌کلید در دسترس باقی می‌ماند.

`omarchy setup keyboard` یا `omarchy setup input` را اجرا کنید تا همان انتخاب‌گرها باز شوند. برای افزودن یک زبان از خط فرمان، از `omarchy setup input mozc`، `hangul`، `pinyin`، `chewing` یا `cangjie5` استفاده کنید. Quick، Boshiamy و Array در همان بسته Cangjie قرار دارند و در انتخاب‌گر Input Methods ظاهر می‌شوند. کلیدهای تغییر سفارشی شما حفظ می‌شوند. برای چیدمان‌ها یا کلیدهای جایگزین موتور، `fcitx5-configtool` را با `omarchy pkg add fcitx5-configtool` نصب کنید و آن را از یک ترمینال اجرا کنید. انتخاب یک زبان ورودی، زبان دسکتاپ را تغییر نمی‌دهد. انتخاب ژاپنی، کره‌ای یا چینی در _Setup > Language_، وقتی هنوز هیچ روش ورودی ندارید، روش ورودی آن را اضافه می‌کند.

از `Super + I` استفاده کنید تا در میان روش‌های ورودی یا چیدمان‌های صفحه‌کلید بچرخید، و از `Super + Shift + I` استفاده کنید تا در جهت عکس برگردید، بنابراین با سه مورد پیکربندی‌شده می‌توانید بین دو همسایه جابه‌جا شوید. نشانگر ورودی فقط وقتی بیش از یک روش ورودی یا چیدمان پیکربندی شده باشد، در سمت راست نوار ظاهر می‌شود. این میانبر دسکتاپ در کنار کلیدهای تغییر Fcitx موجود شما کار می‌کند؛ می‌توانید آن را در `~/.config/hypr/bindings.lua` بازنویسی کنید. موتورهای ورودی و توالی‌های compose از سرویس [Fcitx5](https://fcitx-im.org/) که از قبل در هر نشست در حال اجراست استفاده می‌کنند.

### استفاده از ALT به‌عنوان SUPER

در برخی صفحه‌کلیدها، استفاده از کلید متای اصلی (کلید Windows/cmd) به‌عنوان SUPER راحت نیست. می‌توانید با این تغییر، آن را به ALT تغییر دهید:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
