# صفحه‌کلید، ماوس، ترک‌پد

Hyprland به شما امکان می‌دهد همه ورودی‌هایتان را با جزئیات فراوان پیکربندی کنید. می‌توانید تکرار صفحه‌کلید را به‌طرز فوق‌العاده‌ای سریع کنید یا ترک‌پد را وادار کنید از پیمایش طبیعی استفاده کند. همه این‌ها را در `~/.config/hypr/input.lua` تغییر می‌دهید، که از طریق _Setup > Input_ در منوی Omarchy (`Super + Space`) نیز می‌توانید به آن برسید. هر چیزی که آنجا تنظیم کنید، جایگزین پیش‌فرض‌های Omarchy می‌شود.

این یک مثال است:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

می‌توانید [همه گزینه‌های ورودی را ببینید](https://wiki.hypr.land/Configuring/Basics/Variables/#input) در ویکی Hyprland برای ورودی‌ها.

CapsLock به‌عنوان یک Caps Lock عادی کار می‌کند، و `Shift + CapsLock` کلید compose برای [ایموجی‌های سریع](07-hotkeys.md#quick-emojis) و [تکمیل‌های دیگر](07-hotkeys.md#quick-completions) است. اگر ترجیح می‌دهید کلید compose جای دیگری باشد، `omarchy:shift_caps_compose` را در `kb_options` جایگزین کنید. برای مثال، این کار کلید compose را به Right Alt منتقل می‌کند:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### حرکات ترک‌پد

روی ترک‌پد بکشید تا در دسکتاپ حرکت کنید:

| حرکت | عمل |
| --- | --- |
| سه انگشت به چپ / راست | فضای کاری قبلی / بعدی، از جمله فضای‌های خالی |
| سه انگشت به بالا | تغییر وضعیت کنسول AI |
| سه انگشت به پایین | باز کردن منوی Omarchy |
| چهار انگشت به چپ / راست | انتقال پنجره فعال به فضای کاری قبلی / بعدی |
| چهار انگشت به پایین | تغییر وضعیت تمام‌صفحه |

برای تغییر یکی از آن‌ها، پیش از افزودن [حرکت ترک‌پد](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/) خودتان، آن را در `~/.config/hypr/input.lua` غیرفعال کنید، چون Hyprland دو حرکت با انگشت‌ها و جهت یکسان را نمی‌پذیرد:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

برای خاموش کردن همه حرکات Omarchy، `omarchy_default_gestures = false` را نزدیک بالای `~/.config/hypr/hyprland.lua`، پیش از بارگیری پیش‌فرض‌های Omarchy، تنظیم کنید.

در لپ‌تاپ‌های Dell XPS دارای ترک‌پد haptic، همچنین می‌توانید قدرت کلیک را در _Trigger > Hardware > Touchpad Haptics_ روی low، mid یا high تنظیم کنید.

### تایپ به چینی، ژاپنی و زبان‌های دیگر

وقتی نصب‌کننده صفحه‌کلیدتان را می‌پرسد، ژاپنی، کره‌ای، چینی (ساده‌شده، Pinyin)، تایوان (Zhuyin) یا هنگ‌کنگ (Cangjie) را انتخاب کنید. Omarchy صفحه‌کلید و موتور ورودی منطبق را به‌طور خودکار پیکربندی می‌کند، از جمله در حین راه‌اندازی آفلاین نخستین بوت. ژاپنی از Mozc استفاده می‌کند، کره‌ای از Hangul استاندارد دو-مجموعه‌ای استفاده می‌کند، چینی ساده‌شده از Pinyin استفاده می‌کند، تایوان از آرایش استاندارد Zhuyin در Chewing استفاده می‌کند، و هنگ‌کنگ از Cangjie با فرم‌های نویسه هنگ‌کنگی استفاده می‌کند. Japanese (US keyboard) Mozc را با چیدمان صفحه‌کلید US فراهم می‌کند. کلیدهای Hangul، Zhuyin و Cangjie حتی وقتی حروف لاتین را با Dvorak، Colemak یا AZERTY تایپ می‌کنید، در موقعیت‌های استاندارد خود باقی می‌مانند. اگر پیش از این Hangul یا Chewing را اضافه کرده‌اید، آن را در _Setup > Typing > Input Methods_ از حالت انتخاب خارج و دوباره انتخاب کنید تا کلیدهایش به آنجا منتقل شوند؛ Omarchy موتوری را که هم‌اکنون با آن تایپ می‌کنید، دست‌نخورده باقی می‌گذارد.

تایپ در حالت لاتین شروع می‌شود. `Super + I` را فشار دهید تا میان روش‌های ورودی پیکربندی‌شده بچرخید، و `Super + Shift + I` را برای چرخش به عقب فشار دهید. `Shift` را به‌تنهایی بزنید تا از یک روش ورودی مانند Pinyin خارج شوید و به حروف لاتین بروید، و دوباره آن را بزنید تا برگردید، همان‌طور که Sogou، Microsoft Pinyin و macOS کار می‌کنند؛ `Shift` به‌همراه یک حرف همچنان یک حرف بزرگ تایپ می‌کند. در صفحه‌کلیدهای ژاپنی، 全角/半角 ورودی را تغییر وضعیت می‌دهد، 変換 آن را روشن می‌کند، و 無変換 آن را خاموش می‌کند. با کره‌ای، 한/영 Hangul را عوض می‌کند و 한자 به Hanja تبدیل می‌کند، چه صفحه‌کلیدتان کلیدهای اختصاصی داشته باشد چه Right Alt و Right Ctrl را برای آن‌ها بفرستد، همان‌طور که بسیاری از لپ‌تاپ‌ها انجام می‌دهند، بنابراین Right Alt و Right Ctrl در آنجا اصلاح‌گرهای ساده نیستند؛ قابلیت دیکته push-to-talk روی F9 باقی می‌ماند. `Ctrl + Space` برای Tmux و Herdr در دسترس باقی می‌ماند؛ `Shift + CapsLock` کلید compose باقی می‌ماند.

نشانگر صفحه‌کلید وقتی چند چیدمان صفحه‌کلید یا روش ورودی دارید، در سمت راست نوار ظاهر می‌شود. روی آن کلیک کنید تا زبان‌های ورودی را عوض کنید؛ ژاپنی あ را برای hiragana نمایش می‌دهد. برای انتخاب نویسه‌های ژاپنی، به ژاپنی بروید، کلمه‌ای مانند `nihongo` تایپ کنید، سپس Space را دو بار فشار دهید. Enter را فشار دهید تا انتخابتان پذیرفته شود. اگر چند چیدمان صفحه‌کلید هم دارید، روی نشانگر راست‌کلیک کنید تا میان آن‌ها بچرخید.

از _Setup > Typing > Keyboard Layouts_ استفاده کنید تا چیدمان‌هایی مانند انگلیسی و فرانسوی را از همان گزینه‌هایی انتخاب کنید که در حین نصب ارائه می‌شوند. از _Setup > Typing > Input Methods_ استفاده کنید تا انتخاب کنید کدام موتورهای ترکیب فعال باشند. هر دو انتخاب‌گر داخل منوی Omarchy باز می‌شوند و انتخاب‌های فعلی شما در آن‌ها علامت خورده‌اند. برای تغییر وضعیت یک گزینه، کلیک کنید یا Enter را فشار دهید؛ هر تغییر بلافاصله اعمال می‌شود. خارج کردن یک روش ورودی از حالت انتخاب، آن را از چرخه حذف می‌کند بدون اینکه آن را حذف نصب کند؛ صفحه‌کلید همچنان در دسترس باقی می‌ماند.

`omarchy setup keyboard` یا `omarchy setup input` را اجرا کنید تا همان انتخاب‌گرها باز شوند. برای افزودن یک زبان از خط فرمان، از `omarchy setup input mozc`، `hangul`، `pinyin`، `chewing` یا `cangjie5` استفاده کنید. Quick، Boshiamy و Array در همان بسته Cangjie عرضه می‌شوند و در انتخاب‌گر Input Methods ظاهر می‌شوند. کلیدهای جابه‌جایی سفارشی شما حفظ می‌شوند. برای چیدمان‌ها یا کلیدهای جایگزین موتور، `fcitx5-configtool` را با `omarchy pkg add fcitx5-configtool` نصب کنید و آن را از یک ترمینال اجرا کنید. انتخاب یک زبان ورودی، زبان دسکتاپ را تغییر نمی‌دهد. انتخاب ژاپنی، کره‌ای یا چینی در _Setup > Language_ وقتی هنوز هیچ روش ورودی ندارید، روش ورودی آن را اضافه می‌کند.

از `Super + I` استفاده کنید تا میان روش‌های ورودی یا چیدمان‌های صفحه‌کلید بچرخید، و از `Super + Shift + I` برای رفتن به عقب در جهت دیگر، بنابراین با سه مورد پیکربندی‌شده می‌توانید میان دو همسایه حرکت کنید. نشانگر ورودی فقط وقتی بیش از یک روش ورودی یا چیدمان پیکربندی شده باشد، در سمت راست نوار ظاهر می‌شود. این اتصال دسکتاپ در کنار کلیدهای جابه‌جایی موجود Fcitx شما کار می‌کند؛ می‌توانید آن را در `~/.config/hypr/bindings.lua` بازنویسی کنید. موتورهای ورودی و توالی‌های compose از سرویس [Fcitx5](https://fcitx-im.org/) استفاده می‌کنند که هم‌اکنون در هر نشست در حال اجراست.

### استفاده از ALT به‌عنوان SUPER

در برخی صفحه‌کلیدها، استفاده از کلید متای اصلی (کلید Windows/cmd) به‌عنوان SUPER راحت نیست. می‌توانید با این تغییر، به‌جای آن از ALT استفاده کنید:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
