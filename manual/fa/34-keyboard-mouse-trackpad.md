# صفحه‌کلید، ماوس، ترک‌پد

Hyprland به شما اجازه می‌دهد همه ورودی‌هایتان را با جزئیات زیاد پیکربندی کنید. می‌توانید تکرار صفحه‌کلید را فوق‌العاده سریع کنید یا کاری کنید ترک‌پد از پیمایش طبیعی استفاده کند. همه این‌ها را در `~/.config/hypr/input.lua` تغییر می‌دهید، که از طریق _تنظیمات > ورودی_ در منوی Omarchy (`Super + Space`) هم می‌توانید به آن برسید. هر چیزی که آنجا تنظیم کنید جایگزین پیش‌فرض‌های Omarchy می‌شود.

این یک مثال است:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

می‌توانید [همه گزینه‌های ورودی را ببینید](https://wiki.hypr.land/Configuring/Basics/Variables/#input) در ویکی Hyprland برای ورودی‌ها.

CapsLock مثل یک Caps Lock معمولی کار می‌کند، و `Shift + CapsLock` کلید compose برای [ایموجی‌های سریع](07-hotkeys.md#quick-emojis) و [تکمیل‌های دیگر](07-hotkeys.md#quick-completions) است. اگر ترجیح می‌دهید کلید compose جای دیگری باشد، `omarchy:shift_caps_compose` را در `kb_options` جایگزین کنید. برای مثال، این کار کلید compose را به Right Alt منتقل می‌کند:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### حرکات ترک‌پد

روی ترک‌پد بکشید تا در دسکتاپ حرکت کنید:

| حرکت | عمل |
| --- | --- |
| سه انگشت به چپ / راست | فضای کاری قبلی / بعدی، از جمله فضای‌های خالی |
| سه انگشت به بالا | تغییر وضعیت کنسول هوش مصنوعی |
| سه انگشت به پایین | باز کردن منوی Omarchy |
| چهار انگشت به چپ / راست | انتقال پنجره فعال به فضای کاری قبلی / بعدی |
| چهار انگشت به پایین | تغییر وضعیت تمام‌صفحه |

برای تغییر یکی از آن‌ها، قبل از افزودن [حرکت ترک‌پد](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/) خودتان، آن را در `~/.config/hypr/input.lua` غیرفعال کنید، چون Hyprland دو حرکت روی همان انگشت‌ها و در همان جهت را نمی‌پذیرد:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

برای خاموش کردن همه حرکات Omarchy، `omarchy_default_gestures = false` را نزدیک بالای `~/.config/hypr/hyprland.lua`، قبل از بارگذاری پیش‌فرض‌های Omarchy، تنظیم کنید.

در لپ‌تاپ‌های Dell XPS با ترک‌پد هپتیک، همچنین می‌توانید قدرت کلیک را در بخش _محرک > سخت‌افزار > هپتیک ترک‌پد_ روی کم، متوسط یا زیاد تنظیم کنید.

### تایپ به چینی، ژاپنی و زبان‌های دیگر

وقتی نصب‌کننده صفحه‌کلیدتان را می‌پرسد، ژاپنی، کره‌ای، چینی (ساده‌شده، Pinyin)، تایوان (Zhuyin) یا هنگ‌کنگ (Cangjie) را انتخاب کنید. Omarchy صفحه‌کلید و موتور ورودی متناظر را به‌طور خودکار پیکربندی می‌کند، از جمله هنگام راه‌اندازی آفلاین در اولین بوت. ژاپنی از Mozc استفاده می‌کند، کره‌ای از Hangul استاندارد دومجموعه‌ای استفاده می‌کند، چینی ساده‌شده از Pinyin استفاده می‌کند، تایوان از آرایش استاندارد Zhuyin در Chewing استفاده می‌کند، و هنگ‌کنگ از Cangjie با فرم‌های نویسه هنگ‌کنگی استفاده می‌کند. ژاپنی (صفحه‌کلید US) Mozc را با چیدمان صفحه‌کلید US ارائه می‌کند. کلیدهای Hangul، Zhuyin و Cangjie در موقعیت‌های استانداردشان باقی می‌مانند، حتی وقتی حروف لاتین را با Dvorak، Colemak یا AZERTY تایپ می‌کنید. اگر قبل از این Hangul یا Chewing را اضافه کرده بودید، آن را در _تنظیمات > تایپ > روش‌های ورودی_ از انتخاب خارج کنید و دوباره انتخاب کنید تا کلیدهایش به آنجا منتقل شوند؛ Omarchy موتوری را که همین حالا با آن تایپ می‌کنید دست‌نخورده باقی می‌گذارد.

تایپ در حالت لاتین شروع می‌شود. `Super + I` را فشار دهید تا بین روش‌های ورودی پیکربندی‌شده بچرخید، و `Super + Shift + I` را فشار دهید تا در جهت عکس بچرخید. `Shift` را به‌تنهایی بزنید تا از روش ورودی‌ای مثل Pinyin بیرون بیایید و به حروف لاتین بروید، و دوباره آن را بزنید تا برگردید، همان‌طور که Sogou، Microsoft Pinyin و macOS کار می‌کنند؛ `Shift` به‌همراه یک حرف همچنان یک حرف بزرگ تایپ می‌کند. در صفحه‌کلیدهای ژاپنی، 全角/半角 ورودی را تغییر وضعیت می‌دهد، 変換 آن را روشن می‌کند، و 無変換 آن را خاموش می‌کند. در کره‌ای، 한/영 بین Hangul جابه‌جا می‌شود و 한자 به Hanja تبدیل می‌کند، چه صفحه‌کلیدتان کلیدهای اختصاصی داشته باشد و چه برای آن‌ها Right Alt و Right Ctrl بفرستد، همان‌طور که بسیاری از لپ‌تاپ‌ها این کار را می‌کنند، بنابراین Right Alt و Right Ctrl در آنجا تغییر‌دهنده‌های ساده نیستند؛ در عوض دیکته با Alt + Space تغییر وضعیت می‌دهد. `Ctrl + Space` برای Tmux و Herdr در دسترس باقی می‌ماند؛ `Shift + CapsLock` همچنان کلید compose باقی می‌ماند.

وقتی چند چیدمان صفحه‌کلید یا روش ورودی دارید، نشانگر صفحه‌کلید در سمت راست نوار ظاهر می‌شود. روی آن کلیک کنید تا زبان‌های ورودی را عوض کنید؛ ژاپنی برای هیراگانا あ را نمایش می‌دهد. برای انتخاب نویسه‌های ژاپنی، به ژاپنی بروید، کلمه‌ای مثل `nihongo` تایپ کنید، سپس Space را دو بار فشار دهید. Enter را فشار دهید تا انتخابتان پذیرفته شود. اگر چند چیدمان صفحه‌کلید هم دارید، روی نشانگر راست‌کلیک کنید تا بین آن‌ها بچرخید.

از _تنظیمات > تایپ > چیدمان‌های صفحه‌کلید_ استفاده کنید تا چیدمان‌هایی مثل انگلیسی و فرانسوی را انتخاب کنید، از همان انتخاب‌هایی که هنگام نصب ارائه می‌شوند. از _تنظیمات > تایپ > روش‌های ورودی_ استفاده کنید تا انتخاب کنید کدام موتورهای ترکیب فعال باشند. هر دو انتخاب‌گر داخل منوی Omarchy باز می‌شوند و انتخاب‌های فعلی‌تان علامت خورده‌اند. برای تغییر وضعیت یک انتخاب، کلیک کنید یا Enter را فشار دهید؛ هر تغییر بلافاصله اعمال می‌شود. خارج کردن یک روش ورودی از انتخاب، آن را از چرخه حذف می‌کند بدون اینکه حذف نصب شود؛ صفحه‌کلید همچنان در دسترس باقی می‌ماند.

`omarchy setup keyboard` یا `omarchy setup input` را اجرا کنید تا همان انتخاب‌گرها باز شوند. برای افزودن یک زبان از خط فرمان، از `omarchy setup input mozc`، `hangul`، `pinyin`، `chewing` یا `cangjie5` استفاده کنید. Quick، Boshiamy و Array در همان بسته Cangjie عرضه می‌شوند و در انتخاب‌گر روش‌های ورودی ظاهر می‌شوند. کلیدهای جابه‌جایی سفارشی شما حفظ می‌شوند. برای چیدمان‌ها یا کلیدهای جایگزین موتور، `fcitx5-configtool` را با `omarchy pkg add fcitx5-configtool` نصب کنید و آن را از یک ترمینال اجرا کنید. انتخاب یک زبان ورودی، زبان دسکتاپ را تغییر نمی‌دهد. انتخاب ژاپنی، کره‌ای یا چینی در _تنظیمات > زبان_ وقتی هنوز هیچ‌کدام را ندارید، روش ورودی آن را اضافه می‌کند.

از `Super + I` استفاده کنید تا بین روش‌های ورودی یا چیدمان‌های صفحه‌کلید بچرخید، و از `Super + Shift + I` استفاده کنید تا در جهت عکس برگردید، بنابراین با سه مورد پیکربندی‌شده می‌توانید بین دو همسایه حرکت کنید. نشانگر ورودی فقط وقتی در سمت راست نوار ظاهر می‌شود که بیش از یک روش ورودی یا چیدمان پیکربندی شده باشد. این میانبر دسکتاپ در کنار کلیدهای جابه‌جایی Fcitx موجود شما کار می‌کند؛ می‌توانید آن را در `~/.config/hypr/bindings.lua` بازنویسی کنید. موتورهای ورودی و توالی‌های compose از سرویس [Fcitx5](https://fcitx-im.org/) استفاده می‌کنند که از قبل در هر نشست در حال اجراست.

### استفاده از ALT به‌عنوان SUPER

در بعضی صفحه‌کلیدها، استفاده از کلید متای اصلی (کلید Windows/cmd) به‌عنوان SUPER راحت نیست. می‌توانید با این تغییر، آن را به ALT تغییر دهید:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
