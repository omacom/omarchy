# صفحه‌کلید، ماوس، ترک‌پد

Hyprland به شما امکان می‌دهد همه ورودی‌هایتان را با جزئیات زیاد پیکربندی کنید. می‌توانید تکرار صفحه‌کلید را به‌طرز مافوق صوت سریع کنید یا کاری کنید ترک‌پد از اسکرول طبیعی استفاده کند. همه این‌ها را در `~/.config/hypr/input.lua` تغییر می‌دهید، که از طریق _Setup > Input_ در منوی Omarchy (`Super + Space`) هم می‌توانید به آن برسید. هر چیزی که آنجا تنظیم کنید جایگزین پیش‌فرض‌های Omarchy می‌شود.

در اینجا یک مثال آمده است:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

می‌توانید [همه گزینه‌های ورودی را ببینید](https://wiki.hypr.land/Configuring/Basics/Variables/#input) در ویکی Hyprland برای ورودی‌ها.

CapsLock به‌عنوان یک Caps Lock معمولی کار می‌کند، و `Shift + CapsLock` کلید compose برای [ایموجی‌های سریع](07-hotkeys.md#quick-emojis) و [تکمیل‌های دیگر](07-hotkeys.md#quick-completions) است. اگر ترجیح می‌دهید کلید compose جای دیگری باشد، `omarchy:shift_caps_compose` را در `kb_options` جایگزین کنید. به‌عنوان مثال، این کار کلید compose را به Right Alt منتقل می‌کند:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### کلیدهای تابعی

ردیف بالای صفحه‌کلید لپ‌تاپ به‌صورت پیش‌فرض کلیدهای رسانه‌ای (بلندی صدا، روشنایی و غیره) را ارسال می‌کند، و نگه داشتن `Fn` کلیدهای F1-F12 را می‌دهد؛ `Fn + Esc` آن را به‌صورت برعکس قفل می‌کند تا زمانی که دوباره آن را فشار دهید. بیشتر صفحه‌کلیدها خودشان آن قفل را به خاطر می‌سپارند. لپ‌تاپ‌های ASUS و صفحه‌کلیدهای به سبک Apple این کار را به Linux واگذار می‌کنند، که در هر بوت آن‌ها را با کلیدهای رسانه‌ای شروع می‌کند. برای اینکه در عوض با F1-F12 شروع شوند، `omarchy keyboard toprow fnkeys` را اجرا کنید (و `omarchy keyboard toprow mediakeys` برای برگشتن)؛ در بعضی لپ‌تاپ‌ها بعد از یک راه‌اندازی مجدد اثر می‌کند. مک‌های Apple Silicon تنظیم خودشان را نگه می‌دارند.

### حرکات ترک‌پد

روی ترک‌پد بکشید تا در دسکتاپ جابه‌جا شوید:

| حرکت | عمل |
| --- | --- |
| سه انگشت به چپ / راست | فضای کاری قبلی / بعدی، از جمله فضای‌های خالی |
| سه انگشت به بالا | باز و بسته کردن کنسول AI |
| سه انگشت به پایین | باز کردن منوی Omarchy |
| چهار انگشت به چپ / راست | انتقال پنجره فعال به فضای کاری قبلی / بعدی |
| چهار انگشت به پایین | باز و بسته کردن تمام‌صفحه |

برای تغییر یکی از آن‌ها، قبل از افزودن [حرکت ترک‌پد](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/) خودتان، آن را در `~/.config/hypr/input.lua` غیرفعال کنید، چون Hyprland دو حرکت با انگشتان و جهت یکسان را قبول نمی‌کند:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

برای خاموش کردن همه حرکات Omarchy، `omarchy_default_gestures = false` را نزدیک ابتدای `~/.config/hypr/hyprland.lua`، قبل از بارگذاری پیش‌فرض‌های Omarchy، تنظیم کنید.

در لپ‌تاپ‌های Dell XPS دارای تاچ‌پد لمسی، همچنین می‌توانید قدرت کلیک را در _Trigger > Hardware > Touchpad Haptics_ روی کم، متوسط یا زیاد تنظیم کنید.

### تایپ به چینی، ژاپنی و زبان‌های دیگر

وقتی نصب‌کننده صفحه‌کلیدتان را می‌پرسد، ژاپنی، کره‌ای، چینی (ساده‌شده، Pinyin)، تایوان (Zhuyin) یا هنگ‌کنگ (Cangjie) را انتخاب کنید. Omarchy صفحه‌کلید و موتور ورودی منطبق را به‌صورت خودکار پیکربندی می‌کند، از جمله هنگام راه‌اندازی آفلاین اولین بوت. ژاپنی از Mozc استفاده می‌کند، کره‌ای از Hangul استاندارد دو مجموعه‌ای استفاده می‌کند، چینی ساده‌شده از Pinyin استفاده می‌کند، تایوان از چیدمان استاندارد Zhuyin مربوط به Chewing استفاده می‌کند، و هنگ‌کنگ از Cangjie با شکل‌های نویسه هنگ‌کنگی استفاده می‌کند. ژاپنی (صفحه‌کلید US) Mozc را با چیدمان صفحه‌کلید US فراهم می‌کند. کلیدهای Hangul، Zhuyin و Cangjie حتی وقتی حروف لاتین را با Dvorak، Colemak یا AZERTY تایپ می‌کنید، در موقعیت‌های استانداردشان باقی می‌مانند. اگر قبلاً Hangul یا Chewing را اضافه کرده‌اید، آن را در _Setup > Keyboard > Input Methods_ از انتخاب خارج کنید و دوباره انتخاب کنید تا کلیدهایش به آنجا منتقل شوند؛ Omarchy موتوری را که همین حالا با آن تایپ می‌کنید به حال خودش می‌گذارد.

تایپ در حالت لاتین شروع می‌شود. `Super + I` را فشار دهید تا بین روش‌های ورودی پیکربندی‌شده بچرخید، و `Super + Shift + I` را فشار دهید تا به عقب بچرخید. `Shift` را به‌تنهایی بزنید تا از روش ورودی مانند Pinyin بیرون بیایید و وارد حروف لاتین شوید، و دوباره آن را بزنید تا برگردید، همان‌طور که Sogou، Microsoft Pinyin و macOS کار می‌کنند؛ `Shift` به‌همراه یک حرف همچنان یک حرف بزرگ تایپ می‌کند. در صفحه‌کلیدهای ژاپنی، 全角/半角 ورودی را باز و بسته می‌کند، 変換 آن را روشن می‌کند، و 無変換 آن را خاموش می‌کند. در کره‌ای، 한/영 Hangul را تغییر می‌دهد و 한자 به Hanja تبدیل می‌کند، چه صفحه‌کلیدتان کلیدهای اختصاصی داشته باشد و چه برای آن‌ها Right Alt و Right Ctrl ارسال کند، همان‌طور که بسیاری از لپ‌تاپ‌ها انجام می‌دهند، پس Right Alt و Right Ctrl در آنجا تغییردهنده‌های ساده نیستند؛ دیکته در عوض با Alt + Space باز و بسته می‌شود. `Ctrl + Space` برای Tmux و Herdr در دسترس باقی می‌ماند؛ `Shift + CapsLock` کلید compose باقی می‌ماند.

نشانگر صفحه‌کلید وقتی چند چیدمان صفحه‌کلید یا روش ورودی دارید، در سمت راست نوار ظاهر می‌شود. روی آن کلیک کنید تا زبان‌های ورودی را تغییر دهید؛ ژاپنی برای هیراگانا あ را نمایش می‌دهد. برای انتخاب‌های نویسه ژاپنی، به ژاپنی تغییر دهید، واژه‌ای مانند `nihongo` تایپ کنید، سپس Space را دو بار فشار دهید. Enter را فشار دهید تا انتخابتان را بپذیرید. اگر چند چیدمان صفحه‌کلید هم دارید، روی نشانگر راست‌کلیک کنید تا بین آن‌ها بچرخید.

از _Setup > Keyboard > Keyboard Inputs_ برای انتخاب چیدمان‌هایی مانند انگلیسی و فرانسوی، از همان انتخاب‌هایی که هنگام نصب ارائه می‌شوند، استفاده کنید. از _Setup > Keyboard > Input Methods_ برای انتخاب موتورهای ترکیب فعال استفاده کنید. هر دو انتخاب‌گر داخل منوی Omarchy باز می‌شوند و انتخاب‌های فعلی شما علامت خورده‌اند. کلیک کنید یا Enter را فشار دهید تا یک انتخاب را باز و بسته کنید؛ هر تغییر بلافاصله اعمال می‌شود. خارج کردن یک روش ورودی از انتخاب آن را بدون حذف نصب، از چرخه حذف می‌کند؛ صفحه‌کلید همچنان در دسترس باقی می‌ماند.

`omarchy setup keyboard` یا `omarchy setup input` را اجرا کنید تا همان انتخاب‌گرها باز شوند. برای افزودن یک زبان از خط فرمان، از `omarchy setup input mozc`، `hangul`، `pinyin`، `chewing` یا `cangjie5` استفاده کنید. Quick، Boshiamy و Array در همان بسته Cangjie می‌آیند و در انتخاب‌گر Input Methods ظاهر می‌شوند. کلیدهای تغییر سفارشی شما حفظ می‌شوند. برای چیدمان‌ها یا کلیدهای جایگزین موتور، `fcitx5-configtool` را با `omarchy pkg add fcitx5-configtool` نصب کنید و آن را از یک ترمینال اجرا کنید. انتخاب یک زبان ورودی زبان دسکتاپ را تغییر نمی‌دهد. انتخاب ژاپنی، کره‌ای یا چینی در _Setup > Language_ وقتی هنوز هیچ‌کدام را ندارید، روش ورودی آن را اضافه می‌کند.

از `Super + I` برای چرخیدن بین روش‌های ورودی یا چیدمان‌های صفحه‌کلید استفاده کنید، و از `Super + Shift + I` برای برگشتن به جهت دیگر، پس با سه مورد پیکربندی‌شده می‌توانید بین دو همسایه جابه‌جا شوید. نشانگر ورودی فقط وقتی بیش از یک روش ورودی یا چیدمان پیکربندی شده باشد، در سمت راست نوار ظاهر می‌شود. این اتصال دسکتاپ در کنار کلیدهای تغییر Fcitx موجود شما کار می‌کند؛ می‌توانید آن را در `~/.config/hypr/bindings.lua` بازنویسی کنید. موتورهای ورودی و توالی‌های compose از سرویس [Fcitx5](https://fcitx-im.org/) استفاده می‌کنند که همین حالا در هر نشست در حال اجراست.

### استفاده از ALT به‌عنوان SUPER

در بعضی صفحه‌کلیدها، استفاده از کلید متای اصلی (کلید Windows/cmd) به‌عنوان SUPER راحت نیست. می‌توانید با این تغییر، در عوض ALT را به آن تبدیل کنید:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
