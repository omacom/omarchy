# آمدن از Mac یا Windows

اگر سال‌ها با macOS یا Windows کار کرده‌اید، انگشت‌هایتان صد چیز را بلدند که مغزتان فراموش کرده است اصلا یادشان گرفته است. این فصل لایهٔ ترجمه است: اینکه آن غریزه‌ها در Omarchy کجا می‌روند. خود قابلیت‌ها جای دیگری با جزئیات پوشش داده شده‌اند — این فقط نقشه است.

### Super مرکز همه‌چیز است

تمام حافظهٔ عضلانی‌ای که دور Cmd یا کلید Windows ساخته‌اید، به یک کلید منتقل می‌شود: Super. همان کلید Windows روی کیبورد PC است، و تکیه‌گاه تقریبا همهٔ میانبرها در Omarchy است.

رفلکس Spotlight یا Raycast یا منوی Start شما می‌شود `Super + Space`. این منوی Omarchy را باز می‌کند، که اپ‌ها را اجرا می‌کند، تنظیمات را تغییر می‌دهد، نرم‌افزار نصب می‌کند، از صفحه عکس می‌گیرد — تقریبا همه‌چیز. شروع به تایپ کنید تا فیلتر شود. `Super + Alt + Space` همهٔ اپ‌ها را روی یک شبکه نشان می‌دهد، همان‌طور که Launchpad نشان می‌دهد. ببینید [ناوبری](04-navigation.md).

### هیچ آیکون دسکتاپی نیست، و داک فقط وقتی شناور می‌شوید ظاهر می‌شود

هیچ آیکونی برای چیدن روی دسکتاپ نیست، و روی یک فضای کاری کاشی‌کاری‌شده هیچ داکی نیست — داک فقط روی یک فضای کاری شناور ظاهر می‌شود (ببینید [ناوبری](04-navigation.md)). اپ‌ها از یک میانبر شروع می‌شوند (`Super + Return` برای ترمینال، `Super + Shift + Return` برای مرورگر، و `Super + K` برای فهرستی از هر چیزی که نگاشت شده است) یا از منو. تنها بخش ماندگار رابط کاربری [نوار بالایی](05-the-top-bar.md) است، که همان کاری را پوشش می‌دهد که نوار منو، سینی سیستم، و Notification Center قبلا برایتان می‌کردند — و تقریبا هر ویجت روی آن با کلیک چپ، راست، و وسط کاری انجام می‌دهد.

### پنجره‌ها خودشان جا می‌گیرند

بزرگ‌ترین تغییر ذهنیت: پنجره‌ها را دور صفحه نمی‌کشید و به نیمه‌های صفحه نمی‌چسبانید. یک پنجره باز کنید و تمام صفحه را می‌گیرد. دومی را باز کنید و صفحه را تقسیم می‌کنند. هیچ‌وقت پنجره‌ای را از زیر پنجرهٔ دیگری بیرون نمی‌کشید، چون پنجره‌ها روی هم نمی‌افتند.

وقتی واقعا به یک پنجرهٔ شناور نیاز دارید، `Super + T` پنجرهٔ فعال را از کاشی‌کاری بیرون می‌آورد (و برمی‌گرداند). اما اول به کاشی‌کاری یک فرصت واقعی بدهید — قلب کل ماجرا همین است. [ناوبری](04-navigation.md) شما را از میانش عبور می‌دهد.

فضاهای کاری آشنا به نظر می‌رسند: همان macOS Spaces یا دسکتاپ‌های مجازی Windows هستند، با این تفاوت که واقعا از آن‌ها استفاده خواهید کرد، چون `Super + 1/2/3/4` مستقیم به یکی می‌پرد و `Super + Shift + 1/2/3/4` پنجرهٔ فعال را به آنجا می‌فرستد. هیچ تأخیر انیمیشنی نیست، فقط پرش‌های فوری. یعنی شاید حتی دیگر به چند مانیتور نیاز نداشته باشید، اگر قبلا به آن عادت داشتید.

### کپی و چسباندن همان‌طور که باید کار می‌کنند

روی Mac همه‌جا Cmd + C را داشتید. روی Windows همه‌جا Ctrl + C را داشتید — به‌جز ترمینال، که آنجا برنامه‌تان را می‌کشد. Omarchy به شما `Super + C` و `Super + X` و `Super + V` می‌دهد، و همه‌جا کار می‌کنند، از جمله در ترمینال. هیچ رفلکس جداگانه‌ای برای شل لازم نیست یاد بگیرید.

اهالی Windows: تاریخچهٔ کلیپ‌بورد Win + V شما روی `Super + Ctrl + V` زندگی می‌کند، و علاوه بر متن، تصاویر را هم نگه می‌دارد. ببینید [کلیپ‌بورد و تاریخچهٔ یکپارچه](08-unified-clipboard-history.md).

| سراغ چه می‌روید | در Omarchy |
| ------------- | ---------- |
| Spotlight / Raycast / Start menu | `Super + Space` — منوی Omarchy |
| AirDrop | LocalSend، از طریق `Super + Ctrl + S` — ببینید [رابط‌های گرافیکی](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` یا `Print Screen` — ببینید [اسکرین‌شات‌ها و ضبط](12-screenshots-recording.md) |
| Notification Center | تاریخچهٔ اعلان‌ها روی `Super + Shift + Alt + ,` |
| Time Machine (برای سیستم) | [اسنپ‌شات‌های سیستم](47-system-snapshots.md) خودکار در هر به‌روزرسانی |
| App Store / دانلود یک نصب‌کننده | _Install_ در منو، یا `omarchy pkg add` — ببینید [پکیج‌های دیگر](29-other-packages.md) |
| System Settings / Control Panel | _Setup_ در منو، که فایل‌های کانفیگ ساده را ویرایش می‌کند — ببینید [دات‌فایل‌ها](31-dotfiles.md) |
| Finder / File Explorer | Files، روی `Super + Shift + F` — ببینید [رابط‌های گرافیکی](22-guis.md) |
| Safari / Edge | Google Chrome روی `Super + Shift + Return`؛ یکی دیگر را زیر _Setup > Defaults > Browser_ انتخاب کنید — ببینید [مرورگرها](23-browsers.md) |
| Preview / Photos | Omaview برای عکس‌ها، ویدیو و موسیقی، Document Viewer برای PDFها — ببینید [رابط‌های گرافیکی](22-guis.md) |
| TextEdit / Notepad | Plain، روی `Super + Shift + N`؛ یکی دیگر را زیر _Setup > Defaults > Editor_ انتخاب کنید |

### بعضی چیزها واقعا متفاوت‌اند

بسیاری از تنظیمات در فایل‌های متنی‌ای زندگی می‌کنند که ویرایششان می‌کنید، نه در پنل‌هایی که در آن‌ها کلیک می‌کنید. این ابتدایی به نظر می‌رسد تا وقتی متوجه می‌شوید یعنی هر تغییری را می‌توان دید، به ماشین بعدی‌تان کپی کرد، و در کنترل نسخه گذاشت. منوی _Setup_ شما را مستقیم داخل فایل درست می‌اندازد و وقتی تمام کردید، هر چیزی را که نیاز به راه‌اندازی مجدد دارد راه‌اندازی مجدد می‌کند.

به‌روزرسانی‌ها از طریق یک فرمان می‌آیند — _Update > Omarchy_ — که خود Omarchy و هر پکیج روی سیستم را به‌روز می‌کند، و اول یک اسنپ‌شات می‌گیرد. هیچ به‌روزکنندهٔ جداگانه‌ای برای هر اپ نیست که در زمان‌های تصادفی نق بزند. ببینید [به‌روزرسانی‌ها](30-updates.md).

نرم‌افزار از یک مدیر پکیج می‌آید، نه از نصب‌کننده‌های دانلودشده.

و وقتی یک پنجره را می‌بندید، اپ واقعا خارج می‌شود. هیچ برزخ macOSای وجود ندارد که برنامه بدون هیچ پنجره‌ای به کارش ادامه بدهد. `Super + W` — یا `Super + Q`، اگر حافظهٔ انگشتی‌ای که با آن آمده‌اید آن است — یعنی رفته است.

### روی سخت‌افزار Mac

Omarchy روی Macهای Intel به‌خوبی اجرا می‌شود، و روی Macهای M1 و M2 و M3 با Omarchy for Apple Silicon. ببینید [پشتیبانی از Mac](44-mac-support.md). و کیبورد با شما مهربان است: Omarchy هیچ چیزی را دوباره نگاشت نمی‌کند، و Linux کلید Command را Super در نظر می‌گیرد، پس Super درست همان‌جایی می‌نشیند که Cmd همیشه بود. شست‌تان متوجه جابه‌جایی نخواهد شد.

### دو هفته به آن فرصت بدهید

غریزه‌ها سریع‌تر از آنچه فکر می‌کنید منتقل می‌شوند. فصل [کلیدهای میانبر](07-hotkeys.md) را یک بار مرور کنید، و هر وقت روی یک نگاشت خالی شدید، `Super + K` را بزنید — همهٔ آن‌ها را به شما نشان می‌دهد. این تنها میانبری است که واقعا باید حفظ کنید.
