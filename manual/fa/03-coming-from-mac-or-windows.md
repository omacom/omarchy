# آمدن از Mac یا Windows

اگر سال‌ها با macOS یا Windows کار کرده‌اید، انگشتانتان صدها چیز می‌دانند که مغزتان فراموش کرده است اصلاً یادشان گرفته است. این فصل لایه ترجمه است: آن غریزه‌ها در Omarchy به کجا می‌روند. خود ویژگی‌ها در جای دیگری با جزئیات پوشش داده شده‌اند — این فقط نقشه است.

### Super مرکز همه‌چیز است

همه حافظه عضلانی‌ای که دور Cmd یا کلید Windows ساخته‌اید به یک کلید منتقل می‌شود: Super. همان کلید Windows روی صفحه‌کلید PC است، و تکیه‌گاه تقریباً همه کلیدهای میانبر در Omarchy است.

رفلکس Spotlight یا Raycast یا منوی Start شما می‌شود `Super + Space`. این منوی Omarchy را باز می‌کند، که برنامه‌ها را اجرا می‌کند، تنظیمات را تغییر می‌دهد، نرم‌افزار نصب می‌کند، از صفحه عکس می‌گیرد — تقریباً همه‌چیز. شروع به تایپ کنید تا فیلتر شود. `Super + Alt + Space` همه برنامه‌ها را روی یک شبکه نشان می‌دهد، همان‌طور که Launchpad می‌کند. ببینید [پیمایش](04-navigation.md).

### بدون آیکون دسکتاپ، و داک فقط وقتی شناور می‌شوید ظاهر می‌شود

هیچ آیکونی برای چیدن روی دسکتاپ نیست، و هیچ داکی روی فضای کاری کاشی‌کاری‌شده نیست — داک فقط روی فضای کاری شناور ظاهر می‌شود (ببینید [پیمایش](04-navigation.md)). برنامه‌ها از یک کلید میانبر شروع می‌شوند (`Super + Return` برای ترمینال، `Super + Shift + Return` برای مرورگر، و `Super + K` برای فهرستی از هر چیزی که نگاشت شده است) یا از منو. تنها بخش ثابت رابط کاربری [نوار بالایی](05-the-top-bar.md) است، که همان کاری را پوشش می‌دهد که پیش‌تر نوار منو، سینی سیستم و Notification Center برایتان می‌کردند — و تقریباً هر ویجت روی آن با کلیک چپ، راست و وسط کاری انجام می‌دهد.

### پنجره‌ها خودشان جای خود را پیدا می‌کنند

بزرگ‌ترین تغییر ذهنیت: پنجره‌ها را دور صفحه نمی‌کشید یا به نیمه‌های صفحه نمی‌چسبانید. یک پنجره باز کنید و تمام صفحه را می‌گیرد. دومی را باز کنید و صفحه را تقسیم می‌کنند. هرگز پنجره‌ای را از زیر دیگری بیرون نمی‌کشید، چون پنجره‌ها روی هم نمی‌افتند.

وقتی واقعاً به یک پنجره شناور نیاز دارید، `Super + T` پنجره فعال را از کاشی‌کاری بیرون می‌آورد (و برمی‌گرداند). اما اول به کاشی‌کاری واقعاً فرصت بدهید — قلب کل ماجراست. [پیمایش](04-navigation.md) شما را قدم‌به‌قدم در آن راهنمایی می‌کند.

فضای‌های کاری آشنا به نظر می‌رسند: همان macOS Spaces یا دسکتاپ‌های مجازی Windows هستند، با این تفاوت که واقعاً از آن‌ها استفاده خواهید کرد، چون `Super + 1/2/3/4` مستقیم به یکی می‌پرد و `Super + Shift + 1/2/3/4` پنجره فعال را به آنجا می‌فرستد. بدون تأخیر انیمیشن، فقط پرش‌های آنی. این یعنی شاید حتی دیگر به چند مانیتور نیاز نداشته باشید، اگر قبلاً به آن عادت داشتید.

### کپی و چسباندن بی‌دردسر کار می‌کنند

در Mac همه‌جا Cmd + C داشتید. در Windows همه‌جا Ctrl + C داشتید — به‌جز ترمینال، که آنجا برنامه‌تان را می‌کشد. Omarchy به شما `Super + C`، `Super + X` و `Super + V` می‌دهد، و همه‌جا کار می‌کنند، از جمله در ترمینال. لازم نیست برای shell رفلکس جداگانه‌ای یاد بگیرید.

اهالی Windows: تاریخچه کلیپ‌بورد Win + V شما روی `Super + Ctrl + V` زندگی می‌کند، و علاوه بر متن، تصاویر را هم نگه می‌دارد. ببینید [کلیپ‌بورد یکپارچه و تاریخچه](08-unified-clipboard-history.md).

### جدول ترجمه

| دنبال چه می‌روید | در Omarchy |
| ------------- | ---------- |
| Spotlight / Raycast / Start menu | `Super + Space` — منوی Omarchy |
| AirDrop | LocalSend، از طریق `Super + Ctrl + S` — ببینید [رابط‌های گرافیکی](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` یا `Print Screen` — ببینید [اسکرین‌شات‌ها و ضبط](12-screenshots-recording.md) |
| Notification Center | تاریخچه اعلان‌ها روی `Super + Shift + Alt + ,` |
| Time Machine (برای سیستم) | [اسنپ‌شات‌های سیستمی](47-system-snapshots.md) خودکار در هر به‌روزرسانی |
| App Store / دانلود کردن یک اینستالر | _Install_ در منو، یا `omarchy pkg add` — ببینید [پکیج‌های دیگر](29-other-packages.md) |
| System Settings / Control Panel | _Setup_ در منو، که فایل‌های کانفیگ ساده را ویرایش می‌کند — ببینید [دات‌فایل‌ها](31-dotfiles.md) |
| Finder / File Explorer | Files، روی `Super + Shift + F` — ببینید [رابط‌های گرافیکی](22-guis.md) |
| Safari / Edge | Google Chrome روی `Super + Shift + Return`؛ دیگری را زیر _Setup > Defaults > Browser_ انتخاب کنید — ببینید [مرورگرها](23-browsers.md) |
| Preview / Photos | Omaview برای تصاویر، ویدیو و موسیقی، Document Viewer برای PDFها — ببینید [رابط‌های گرافیکی](22-guis.md) |
| TextEdit / Notepad | Plain، روی `Super + Shift + N`؛ دیگری را زیر _Setup > Defaults > Editor_ انتخاب کنید |

### بعضی چیزها واقعاً فرق دارند

خیلی از تنظیمات در فایل‌های متنی‌ای زندگی می‌کنند که ویرایش می‌کنید، نه پنل‌هایی که در آن‌ها کلیک می‌کنید. این بدوی به نظر می‌رسد تا وقتی بفهمید یعنی هر تغییری را می‌توان دید، به ماشین بعدی‌تان کپی کرد، و در کنترل نسخه گذاشت. منوی _Setup_ شما را مستقیم در فایل درست می‌اندازد و وقتی تمام کردید هر چیزی را که نیاز به ری‌استارت دارد ری‌استارت می‌کند.

به‌روزرسانی‌ها از یک دستور می‌آیند — _Update > Omarchy_ — که خود Omarchy و هر پکیج روی سیستم را به‌روز می‌کند، و اول یک اسنپ‌شات می‌گیرد. هیچ آپدیتر جداگانه‌ای برای هر برنامه سر وقت نامشخص نق نمی‌زند. ببینید [به‌روزرسانی‌ها](30-updates.md).

نرم‌افزار از یک مدیر پکیج می‌آید، نه از اینستالرهای دانلودشده.

و وقتی پنجره‌ای را می‌بندید، برنامه واقعاً خارج می‌شود. هیچ برزخ macOSی وجود ندارد که برنامه بدون پنجره به کار ادامه دهد. `Super + W` — یا `Super + Q`، اگر آن حافظه انگشتی است که با آن وارد شده‌اید — یعنی تمام، رفت.

### روی سخت‌افزار Mac

Omarchy روی Intel Macها خوب اجرا می‌شود — ببینید [پشتیبانی از Mac](44-mac-support.md). و صفحه‌کلید با شما مهربان است: Omarchy هیچ چیزی را دوباره نگاشت نمی‌کند، و Linux کلید Command را به‌عنوان Super در نظر می‌گیرد، پس Super درست همان‌جایی می‌نشیند که Cmd همیشه بود. شستتان متوجه جابه‌جایی نخواهد شد.

### دو هفته به آن فرصت بدهید

این غریزه‌ها سریع‌تر از چیزی که فکر می‌کنید منتقل می‌شوند. فصل [کلیدهای میانبر](07-hotkeys.md) را یک بار سریع بخوانید، و هر وقت در یک بایندینگ گیر کردید، `Super + K` را بزنید — همه آن‌ها را نشان‌تان می‌دهد. این تنها کلید میانبری است که واقعاً باید حفظ کنید.
