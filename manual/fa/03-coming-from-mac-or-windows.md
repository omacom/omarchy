# آمدن از Mac یا Windows

اگر سال‌ها روی macOS یا Windows بوده‌ای، انگشتانت صد چیز را می‌دانند که مغزت فراموش کرده اصلاً یاد گرفته است. این فصل لایهٔ ترجمه است: آن غریزه‌ها در Omarchy کجا می‌روند. خود قابلیت‌ها جای دیگر به‌تفصیل پوشش داده شده‌اند — این فقط نقشه است.

### Super مرکز همه‌چیز است

تمام حافظهٔ عضلانی‌ای که دور Cmd یا کلید Windows ساخته‌ای به یک کلید منتقل می‌شود: Super. همان کلید Windows روی کیبورد PC است، و لنگر تقریباً همهٔ کلیدهای میانبر در Omarchy است.

واکنش غریزی تو به Spotlight یا Raycast یا منوی Start تبدیل می‌شود به `Super + Space`. این منوی Omarchy را باز می‌کند، که برنامه‌ها را اجرا می‌کند، تنظیمات را تغییر می‌دهد، نرم‌افزار نصب می‌کند، از صفحه عکس می‌گیرد — تقریباً همه‌چیز. شروع به تایپ کن تا فیلتر شود. `Super + Alt + Space` همهٔ برنامه‌ها را روی یک شبکه نشان می‌دهد، همان‌طور که Launchpad نشان می‌دهد. ببین [ناوبری](04-navigation.md).

### هیچ آیکون دسکتاپی نیست، و داک سر راه نمی‌آید

هیچ آیکونی برای چیدن روی دسکتاپ نیست، و داک وقتی یک فضای کاری پنجره‌ای داشت پنهان می‌شود، تا وقتی نشانگر را به لبهٔ صفحه‌اش هل بدهی، لبهٔ راست مگر اینکه جابه‌جایش کنی (ببین [ناوبری](04-navigation.md)). برنامه‌ها از یک کلید میانبر شروع می‌شوند (`Super + Return` برای ترمینال، `Super + Shift + Return` برای مرورگر، و `Super + K` برای فهرست همهٔ چیزهایی که نگاشت شده‌اند) یا از منو. تنها بخش ماندگار رابط کاربری [نوار بالا](05-the-top-bar.md) است، که همان کاری را پوشش می‌دهد که نوار منو، سینی سیستم، و Notification Center قبلاً برایت می‌کردند — و تقریباً هر ویجت روی آن با کلیک چپ، راست، و وسط کاری انجام می‌دهد.

### پنجره‌ها خودشان جا می‌گیرند

بزرگ‌ترین تغییر ذهنیت: پنجره‌ها را دور صفحه نمی‌کشی و به نیمه‌های صفحه نمی‌چسبانی. یک پنجره باز کن و تمام صفحه را می‌گیرد. دومی را باز کن و صفحه را تقسیم می‌کنند. هیچ‌وقت پنجره‌ای را از زیر دیگری بیرون نمی‌کشی، چون پنجره‌ها روی هم نمی‌افتند.

وقتی واقعاً به یک پنجرهٔ شناور نیاز داری، `Super + T` پنجرهٔ فعال را از چیدمان کاشی‌وار بیرون می‌آورد (و برمی‌گرداند). اما اول به چیدمان کاشی‌وار یک فرصت واقعی بده — قلب کل ماجراست. [ناوبری](04-navigation.md) قدم‌به‌قدم تو را از آن عبور می‌دهد.

فضاهای کاری آشنا به نظر می‌رسند: همان macOS Spaces یا دسکتاپ‌های مجازی Windows هستند، با این تفاوت که واقعاً از آن‌ها استفاده خواهی کرد، چون `Super + 1/2/3/4` مستقیم به یکی می‌پرد و `Super + Shift + 1/2/3/4` پنجرهٔ فعال را آنجا می‌فرستد. هیچ تأخیر انیمیشنی نیست، فقط پرش‌های فوری. این یعنی شاید حتی به چند مانیتور هم نیاز نداشته باشی، اگر قبلاً به آن عادت داشتی.

### کپی و پیست فقط کار می‌کنند

روی Mac همه‌جا Cmd + C داشتی. روی Windows همه‌جا Ctrl + C داشتی — به‌جز ترمینال، که آنجا برنامه‌ات را می‌کشد. Omarchy به تو `Super + C` و `Super + X` و `Super + V` می‌دهد، و همه‌جا کار می‌کنند، از جمله ترمینال. هیچ واکنش غریزی جداگانه‌ای برای یاد گرفتن برای شل نیست.

اهالی Windows: تاریخچهٔ کلیپ‌بورد Win + V شما روی `Super + Ctrl + V` زندگی می‌کند، و علاوه بر متن، تصاویر را هم نگه می‌دارد. ببین [کلیپ‌بورد یکپارچه و تاریخچه](08-unified-clipboard-history.md).

### جدول ترجمه

| چیزی که سراغش می‌روی | در Omarchy |
| ------------- | ---------- |
| Spotlight / Raycast / Start menu | `Super + Space` — منوی Omarchy |
| AirDrop | LocalSend، از طریق `Super + Ctrl + S` — ببین [رابط‌های گرافیکی](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` یا `Print Screen` — ببین [اسکرین‌شات‌ها و ضبط](12-screenshots-recording.md) |
| Notification Center | تاریخچهٔ اعلان‌ها روی `Super + Shift + Alt + ,` |
| Time Machine (برای سیستم) | [اسنپ‌شات‌های سیستم](47-system-snapshots.md) خودکار روی هر به‌روزرسانی |
| App Store / دانلود یک نصب‌کننده | _Install_ در منو، یا `omarchy pkg add` — ببین [بسته‌های دیگر](29-other-packages.md) |
| System Settings / Control Panel | _Setup_ در منو، که فایل‌های پیکربندی ساده را ویرایش می‌کند — ببین [dotfiles](31-dotfiles.md) |
| Finder / File Explorer | Files، روی `Super + Shift + F` — ببین [رابط‌های گرافیکی](22-guis.md) |
| Safari / Edge | Google Chrome روی `Super + Shift + Return`؛ یکی دیگر را زیر _Setup > Defaults > Browser_ انتخاب کن — ببین [مرورگرها](23-browsers.md) |
| Preview / Photos | Omaview برای عکس‌ها، ویدیو و موسیقی، Document Viewer برای PDFها — ببین [رابط‌های گرافیکی](22-guis.md) |
| TextEdit / Notepad | Plain، روی `Super + Shift + N`؛ یکی دیگر را زیر _Setup > Defaults > Editor_ انتخاب کن |

### بعضی چیزها واقعاً فرق دارند

خیلی از تنظیمات در فایل‌های متنی‌ای زندگی می‌کنند که ویرایششان می‌کنی، نه پنل‌هایی که در آن‌ها کلیک می‌کنی. این بدوی به نظر می‌رسد تا وقتی بفهمی یعنی هر تغییری را می‌توان دید، روی ماشین بعدی‌ات کپی کرد، و در کنترل نسخه گذاشت. منوی _Setup_ تو را مستقیم در فایل درست می‌اندازد و وقتی کارت تمام شد هر چیزی که نیاز به راه‌اندازی مجدد دارد را دوباره راه می‌اندازد.

به‌روزرسانی‌ها از طریق یک دستور می‌آیند — _Update > Omarchy_ — که خود Omarchy و هر بسته روی سیستم را به‌روز می‌کند، و اول یک اسنپ‌شات می‌گیرد. هیچ به‌روزرسان جداگانه‌ای برای هر برنامه نیست که تصادفی نق بزند. ببین [به‌روزرسانی‌ها](30-updates.md).

نرم‌افزار از یک مدیر بسته می‌آید، نه از نصب‌کننده‌های دانلودشده.

و وقتی پنجره‌ای را می‌بندی، برنامه واقعاً خارج می‌شود. هیچ برزخ macOSای نیست که برنامه بدون هیچ پنجره‌ای به اجرا ادامه دهد. `Super + W` — یا `Super + Q`، اگر آن حافظهٔ انگشتی‌ای است که با آن رسیده‌ای — یعنی رفته.

### روی سخت‌افزار Mac

Omarchy روی Macهای Intel خوب اجرا می‌شود، و روی Macهای M1 و M2 و M3 با Omarchy for Apple Silicon. ببین [پشتیبانی Mac](44-mac-support.md). و کیبورد با تو مهربان است: Omarchy هیچ چیزی را دوباره نگاشت نمی‌کند، و Linux کلید Command را به‌عنوان Super در نظر می‌گیرد، پس Super دقیقاً همان‌جایی می‌نشیند که Cmd همیشه بود. شستت متوجه این جابه‌جایی نخواهد شد.

### دو هفته به آن فرصت بده

غریزه‌ها سریع‌تر از آنچه فکر می‌کنی منتقل می‌شوند. فصل [کلیدهای میانبر](07-hotkeys.md) را یک بار سریع بخوان، و هر وقت روی یک نگاشت ذهنت خالی شد، `Super + K` را بزن — همهٔ آن‌ها را به تو نشان می‌دهد. این تنها کلید میانبری است که واقعاً باید حفظ کنی.
