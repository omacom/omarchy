# آمدن از Mac یا Windows

اگر سال‌ها با macOS یا Windows کار کرده‌اید، انگشت‌هایتان صد چیز را می‌دانند که مغزتان فراموش کرده اصلاً زمانی یادشان گرفته است. این فصل لایهٔ ترجمه است: آن غریزه‌ها در Omarchy کجا می‌نشینند. خودِ قابلیت‌ها جای دیگری با جزئیات پوشش داده شده‌اند — این فقط نقشه است.

### Super مرکز همه‌چیز است

تمام حافظهٔ عضلانی‌ای که دور Cmd یا کلید Windows ساخته‌اید به یک کلید منتقل می‌شود: Super. همان کلید Windows روی کیبورد PC است، و تکیه‌گاه تقریباً هر میانبر در Omarchy است.

واکنش غریزی‌تان به Spotlight یا Raycast یا منوی Start می‌شود `Super + Space`. این منوی Omarchy را باز می‌کند، که برنامه‌ها را اجرا می‌کند، تنظیمات را تغییر می‌دهد، نرم‌افزار نصب می‌کند، از صفحه عکس می‌گیرد — تقریباً همه‌چیز. شروع به تایپ کنید تا فیلتر شود. `Super + Alt + Space` همهٔ برنامه‌ها را روی یک شبکه نشان می‌دهد، همان‌طور که Launchpad این کار را می‌کند. ببینید: [ناوبری](04-navigation.md).

### نه داکی هست و نه آیکون‌های دسکتاپ

هیچ‌چیزی برای کلیک‌کردن و اجرا کردن نیست، هیچ آیکونی برای چیدن روی دسکتاپ نیست. برنامه‌ها از یک میانبر شروع می‌شوند (`Super + Return` برای ترمینال، `Super + Shift + Return` برای مرورگر، و `Super + K` برای فهرست هر چیزی که نگاشت شده است) یا از منو. تنها بخش همیشگی رابط کاربری [نوار بالا](05-the-top-bar.md) است، که همان کاری را پوشش می‌دهد که قبلاً نوار منو، سینی سیستم و Notification Center برایتان انجام می‌دادند — و تقریباً هر ویجت روی آن با کلیک چپ، راست و وسط کاری انجام می‌دهد.

### پنجره‌ها خودشان سر جایشان می‌نشینند

بزرگ‌ترین تغییر ذهنی: پنجره‌ها را این‌طرف و آن‌طرف نمی‌کشید یا به نیمه‌های صفحه نمی‌چسبانید. یک پنجره باز کنید و تمام صفحه را می‌گیرد. دومی را باز کنید و صفحه را تقسیم می‌کنند. هرگز پنجره‌ای را از زیر پنجرهٔ دیگری بیرون نمی‌کشید، چون پنجره‌ها روی هم نمی‌افتند.

وقتی واقعاً به یک پنجرهٔ شناور نیاز دارید، `Super + T` پنجرهٔ فعال را از حالت کاشی‌کاری بیرون می‌آورد (و برمی‌گرداند). اما اول به کاشی‌کاری یک فرصت واقعی بدهید — قلب کل ماجرا همین است. [ناوبری](04-navigation.md) شما را در آن راه می‌برد.

فضاهای کاری آشنا به نظر می‌رسند: همان macOS Spaces یا دسکتاپ‌های مجازی Windows هستند، با این تفاوت که واقعاً از آن‌ها استفاده خواهید کرد، چون `Super + 1/2/3/4` مستقیم به یکی از آن‌ها می‌پرد و `Super + Shift + 1/2/3/4` پنجرهٔ فعال را به آنجا می‌فرستد. هیچ تأخیر انیمیشنی نیست، فقط پرش‌های آنی. یعنی شاید حتی به چند مانیتور هم نیاز نداشته باشید، اگر قبلاً به آن عادت داشتید.

### کپی و چسباندن همان‌طور که باید کار می‌کنند

روی Mac همه‌جا Cmd + C داشتید. روی Windows همه‌جا Ctrl + C داشتید — به‌جز ترمینال، که آنجا برنامه‌تان را می‌کشد. Omarchy به شما `Super + C`، `Super + X` و `Super + V` می‌دهد، و این‌ها همه‌جا کار می‌کنند، از جمله در ترمینال. هیچ واکنش غریزی جداگانه‌ای برای شل لازم نیست یاد بگیرید.

اهالی Windows: تاریخچهٔ کلیپ‌بورد Win + V شما روی `Super + Ctrl + V` است، و علاوه بر متن، تصاویر را هم نگه می‌دارد. ببینید: [کلیپ‌بورد یکپارچه و تاریخچه](08-unified-clipboard-history.md).

### جدول ترجمه

| دست‌تان سراغ این می‌رود | در Omarchy |
| ------------- | ---------- |
| Spotlight / Raycast / Start menu | `Super + Space` — منوی Omarchy |
| AirDrop | LocalSend، از طریق `Super + Ctrl + S` — ببینید: [رابط‌های گرافیکی](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` یا `Print Screen` — ببینید: [اسکرین‌شات‌ها و ضبط](12-screenshots-recording.md) |
| Notification Center | تاریخچهٔ اعلان‌ها روی `Super + Shift + Alt + ,` |
| Time Machine (برای سیستم) | [اسنپ‌شات‌های سیستمی](47-system-snapshots.md) خودکار در هر به‌روزرسانی |
| App Store / دانلود یک نصب‌کننده | _Install_ در منو، یا `omarchy pkg add` — ببینید: [بسته‌های دیگر](29-other-packages.md) |
| System Settings / Control Panel | _Setup_ در منو، که فایل‌های پیکربندی ساده را ویرایش می‌کند — ببینید: [دات‌فایل‌ها](31-dotfiles.md) |

### بعضی چیزها واقعاً متفاوت‌اند

بسیاری از تنظیمات در فایل‌های متنی‌ای زندگی می‌کنند که ویرایش‌شان می‌کنید، نه پنل‌هایی که در آن‌ها کلیک کنید. این بدوی به نظر می‌رسد تا وقتی بفهمید یعنی هر تغییر کوچکی را می‌توان دید، روی دستگاه بعدی‌تان کپی کرد، و در کنترل نسخه گذاشت. منوی _Setup_ شما را مستقیم داخل فایل درست می‌اندازد و وقتی کارتان تمام شد، هرچه لازم باشد دوباره راه‌اندازی شود را دوباره راه‌اندازی می‌کند.

به‌روزرسانی‌ها از یک فرمان می‌آیند — _Update > Omarchy_ — که خودِ Omarchy و هر بسته روی سیستم را به‌روز می‌کند، و اول یک اسنپ‌شات می‌گیرد. خبری از به‌روزرسان‌های جداگانهٔ هر برنامه نیست که بی‌موقع نق بزنند. ببینید: [به‌روزرسانی‌ها](30-updates.md).

نرم‌افزار از یک مدیر بسته می‌آید، نه از نصب‌کننده‌های دانلودشده.

و وقتی پنجره‌ای را می‌بندید، برنامه واقعاً خارج می‌شود. خبری از برزخ macOS نیست که برنامه بدون هیچ پنجره‌ای به اجرا ادامه دهد. `Super + W` — یا `Super + Q`، اگر حافظهٔ انگشت‌هایتان با همان آمده است — یعنی تمام، رفت.

### روی سخت‌افزار Mac

Omarchy روی Macهای Intel خوب اجرا می‌شود — ببینید: [پشتیبانی از Mac](44-mac-support.md). و کیبورد با شما مهربان است: Omarchy هیچ‌چیز را دوباره نگاشت نمی‌کند، و Linux با کلید Command مثل Super رفتار می‌کند، پس Super دقیقاً همان‌جا می‌نشیند که Cmd همیشه بود. شست‌تان متوجه این جابه‌جایی نخواهد شد.

### دو هفته به آن فرصت دهید

این غریزه‌ها سریع‌تر از چیزی که فکر می‌کنید منتقل می‌شوند. فصل [میانبرها](07-hotkeys.md) را یک بار سریع بخوانید، و هر وقت یک نگاشت یادتان رفت، `Super + K` را بزنید — همه‌شان را نشانتان می‌دهد. این تنها میانبری است که واقعاً باید حفظ کنید.
