# کلیدهای میانبر

می‌توانید همه‌ی پیوندهای اصلی صفحه‌کلید را با `Super + K` ببینید (پیوندهای Tmux با `Super + Alt + K` و پیوندهای Herdr با `Super + Ctrl + K`).

## نحوه‌ی چیدمان کلیدهای میانبر

هر کلید میانبر روی یک صفحه قرار دارد که اصلاح‌کننده‌هایش آن را تعیین می‌کنند، و هر صفحه یک وظیفه دارد. همین باعث می‌شود کلیدهای میانبر با هم قاطی نشوند، و یعنی معمولاً می‌توانید حدس بزنید هر چیزی کجا قرار دارد.

| صفحه | چه چیزی آنجا قرار دارد | مثال‌ها |
| --- | --- | --- |
| `Super + key` | سیستم: پنجره‌ها، فضاهای کاری، چیدمان‌ها و منوهای اصلی | `Super + Space` منوی Omarchy، `Super + W` بستن پنجره، `Super + F` تمام‌صفحه |
| `Super + Shift + key` | برنامه‌ها | `Super + Shift + B` مرورگر، `Super + Shift + E` ایمیل، `Super + Shift + N` ویرایشگر |
| `Super + Ctrl + key` | پنل‌ها و منوهای سیستم | `Super + Ctrl + A` صدا، `Super + Ctrl + N` شبکه، `Super + Ctrl + C` منوی ثبت |
| `Super + Ctrl + Alt + key` | اقدام‌های سریع و اطلاعیه‌ها | `Super + Ctrl + Alt + T` نمایش زمان، `Super + Ctrl + Alt + B` باتری، `Super + Ctrl + Alt + C` اسکرین‌شات |

افزودن `Alt` به یک کلید میانبر گونه‌ای از همان چیز را به شما می‌دهد، هرگز چیزی نامرتبط را نمی‌دهد:

- `Super + Shift + B` مرورگر را باز می‌کند؛ `Super + Shift + Alt + B` یک پنجره‌ی خصوصی باز می‌کند
- `Super + Shift + E` ایمیل را باز می‌کند؛ `Super + Shift + Alt + E` یک ایمیل جدید شروع می‌کند
- `Super + F` به تمام‌صفحه می‌رود؛ `Super + Alt + F` به تمام‌عرض می‌رود
- `Super + Ctrl + C` منوی ثبت را باز می‌کند؛ `Super + Ctrl + Alt + C` از منو رد می‌شود و یک اسکرین‌شات می‌گیرد

هنگام افزودن یک کلید میانبر:

1. صفحه را از کاری که انجام می‌دهد انتخاب کنید، سپس کلید را انتخاب کنید.
2. یک کلید میانبر موجود را برای جا باز کردن جابه‌جا نکنید. یک کلید آزاد روی صفحه‌ی درست پیدا کنید.
3. فقط برای گونه‌ای از کلید میانبر بدون آن، از `Alt` استفاده کنید.

چند کلید میانبر این قوانین را می‌شکنند چون راحت‌ترند. `Shift` با یک پیکان یا `Tab` به‌جای باز کردن یک برنامه، جابه‌جا می‌کند یا جهت را برعکس می‌کند، و `Print`، کلیدهای رسانه، `Alt + Tab` و `Ctrl + Alt + Del` همان‌طور کار می‌کنند که همه‌جای دیگر کار می‌کنند. آن‌ها استثنا هستند، نه الگوهایی برای کپی کردن.

اگر یک پیش‌فرض به کارتان نمی‌آید (مثلاً می‌خواهید `Super + Shift + S` برای اسکرین‌شات‌ها باشد مثل Windows)، آن را در `~/.config/hypr/bindings.lua` دوباره پیوند دهید.

| `Super + Alt + Shift + Tab` | چرخش معکوس بین پنجره‌ها در گروه‌بندی |
| `Super + Alt + Scroll Wheel` | چرخش بین پنجره‌ها در گروه‌بندی |
| `Super + Alt + 1/2/3/4/5` | پرش به پنجره‌ای مشخص در گروه‌بندی |
| `Super + Alt + Arrow` | انتقال پنجره به داخل گروه‌بندی در جهت پیکان، از جمله پنجره‌ای روی نمایشگر آن سمت |
| `Super + Ctrl + Left/Right` | جابه‌جایی بین پنجره‌ها داخل یک گروه کاشی‌کاری |
| `Super + Ctrl + Z` | بزرگ‌نمایی روی صفحه (برای بزرگ‌نمایی بیشتر تکرار کنید) |
| `Super + Ctrl + Alt + Z` | خروج کامل از بزرگ‌نمایی صفحه |
| `Super + /` | حرکت به جلو بین گزینه‌های مقیاس‌بندی نمایشگر |
| `Super + Alt + /` | حرکت به عقب بین گزینه‌های مقیاس‌بندی نمایشگر |
| `Alt + Tab` | چرخش به جلو بین پنجره‌ها در فضای کاری فعال |
| `Alt + Shift + Tab` | چرخش به عقب بین پنجره‌ها در فضای کاری فعال |
| `Ctrl + Alt + Tab` | چرخش فوکوس به جلو بین نمایشگرها |
| `Ctrl + Alt + Shift + Tab` | چرخش فوکوس به عقب بین نمایشگرها |
| `Super + I` | تعویض زبان ورودی (با بیش از یک چیدمان یا روش ورودی) |
| `Super + Shift + I` | تعویض زبان ورودی به قبلی |

روی تاچ‌پد، کشیدن سه و چهار انگشتی فضاهای کاری را عوض می‌کند، پنجره‌ها را جابه‌جا می‌کند و منو و کنسول Quake را باز می‌کند؛ برای حرکت‌ها [صفحه‌کلید، ماوس و ترک‌پد](34-keyboard-mouse-trackpad.md) را ببینید.

میانبرهای تغییر اندازه از کلیدهای فیزیکی `code:20` و `code:21` (در XKB یعنی `<AE11>` و `<AE12>`) استفاده می‌کنند، صرف‌نظر از نویسه‌های چاپ‌شده روی صفحه‌کلید. روی صفحه‌کلیدهای US این کلیدها `-` و `=` هستند؛ روی صفحه‌کلیدهای ژاپنی (JIS) آن‌ها `-` و `^` هستند؛ روی صفحه‌کلیدهای اسپانیایی آن‌ها `'` و `¡` هستند. در JIS، `Super + ^` همان `Super + Equal` است، در حالی که `Super + Shift + -` (که `=` را تایپ می‌کند) همان `Super + Shift + Minus` است.

## کلیپ‌بورد جهانی

| کلید میانبر | عملکرد |
| ----------------------- | --------------------- |
| `Super + A` | انتخاب همه در برنامه‌هایی که از `Ctrl + A` پشتیبانی می‌کنند |
| `Super + C` | کپی |
| `Super + X` | برش (در ترمینال نه) |
| `Super + V` | چسباندن |
| `Super + Ctrl + V` | مدیر کلیپ‌بورد |

معمولاً در Linux، برای کپی و چسباندن در ترمینال به `Ctrl + Shift + C/V` نیاز دارید و برای انجام آن در همه‌جای دیگر به `Ctrl + C/V`. این کلیدهای میانبر یکپارچه‌ی کلیپ‌بورد Omarchy همه‌جا کار می‌کنند.

| کلید میانبر | عملکرد |
| ------------------- | ------------------------------ |
| `Print Screen` | اسکرین‌شات |

| `Super + Print Screen` | انتخابگر رنگ |
| `Super + Ctrl + Print Screen` | استخراج متن به کلیپ‌بورد |
| `Super + Alt + [` | کوچک‌تر کردن پوشش وب‌کم هنگام ضبط |
| `Super + Alt + ]` | بزرگ‌تر کردن پوشش وب‌کم هنگام ضبط |

در ضبط‌های صفحه، کلید میانبر ابتدا می‌پرسد چه صدایی می‌خواهید، سپس ضبط را شروع می‌کند. برای توقف دوباره آن را بزنید. برای جزئیات [اسکرین‌شات‌ها و ضبط](12-screenshots-recording.md) را ببینید.

همه‌ی گزینه‌های ثبت همچنین در _ماشه > ثبت_ در منوی Omarchy (`Super + Space`) در دسترس هستند.

## سبک

| کلید میانبر | عملکرد |
| ----------------------- | --------------------- |
| `Super + Ctrl + T` | انتخاب یک تم جدید (همچنین `Super + Ctrl + Shift + Space`) |
| `Super + Ctrl + W` | انتخاب پس‌زمینه‌ی تم (همچنین `Super + Ctrl + Space`) |

همه‌ی گزینه‌های سبک همچنین در _ظاهر_ در منوی Omarchy (`Super + Space`) در دسترس هستند.

## Tmux

کلید پیشوند `Ctrl + Space` است (`Ctrl + B` هم کار می‌کند). می‌توانید این پیوندها را در `~/.config/tmux/tmux.conf` تغییر دهید.

### پنل‌ها

| کلید میانبر | عملکرد |
| ----------------------- | --------------------- |
| `Prefix + v` | تقسیم پنل در کنار (عمودی) |
| `Prefix + h` | تقسیم پنل در پایین (افقی) |
| `Prefix + x` | کشتن پنل |
| `Prefix + z` | تغییر وضعیت بزرگ‌نمایی پنل (تمام‌صفحه) |
| `Alt + Enter` | تقسیم پنل در پایین (بدون پیشوند) |
| `Alt + Shift + Enter` | تقسیم پنل در کنار (بدون پیشوند) |
| `Alt + Escape` | کشتن پنل (بدون پیشوند) |
| `Ctrl + Alt + Arrows` | جابه‌جایی بین پنل‌ها |
| `Ctrl + Alt + Shift + Arrows` | تغییر اندازه‌ی پنل‌ها |

### پنجره‌ها

| کلید میانبر | عملکرد |
| ----------------------- | --------------------- |
| `Prefix + c` | پنجره‌ی جدید |
| `Prefix + k` | کشتن پنجره |
| `Prefix + r` | تغییر نام پنجره |
| `Alt + 1-9` | رفتن به پنجره‌ای مشخص |
| `Alt + Arrow Left/Right` | جابه‌جایی بین پنجره‌ها |
| `Alt + Shift + Arrow Left/Right` | انتقال پنجره به چپ/راست |

### نشست‌ها

### توابع چیدمان Tmux

این توابع باید داخل یک نشست Tmux اجرا شوند.

| فرمان | عملکرد |

| `tdlm <ai> [<second_ai>]` | ایجاد چیدمان توسعه به ازای هر زیرپوشه |
