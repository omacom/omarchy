# کلیدهای میانبر

با `Super + K` می‌توانید همه پیوندهای اصلی صفحه‌کلید را ببینید (پیوندهای Tmux با `Super + Alt + K` و پیوندهای Herdr با `Super + Ctrl + K`).

## نحوه چیدمان کلیدهای میانبر

هر کلید میانبر روی یک صفحه قرار دارد که اصلاح‌گرهایش آن را تعیین می‌کنند، و هر صفحه یک کار دارد. همین باعث می‌شود کلیدهای میانبر با هم قاطی نشوند، و یعنی معمولاً می‌توانید حدس بزنید هر چیزی کجا قرار دارد.

| صفحه | چه چیزی آنجا قرار دارد | مثال‌ها |
| --- | --- | --- |
| `Super + key` | سیستم: پنجره‌ها، فضای کاری‌ها، چیدمان‌ها و منوهای اصلی | `Super + Space` منوی Omarchy، `Super + W` بستن پنجره، `Super + F` تمام‌صفحه |
| `Super + Shift + key` | برنامه‌ها | `Super + Shift + B` مرورگر، `Super + Shift + E` ایمیل، `Super + Shift + N` ویرایشگر |
| `Super + Ctrl + key` | پنل‌ها و منوهای سیستم | `Super + Ctrl + A` صدا، `Super + Ctrl + N` شبکه، `Super + Ctrl + C` منوی ثبت |
| `Super + Ctrl + Alt + key` | اقدام‌های سریع و اطلاعیه‌ها | `Super + Ctrl + Alt + T` نشان دادن زمان، `Super + Ctrl + Alt + B` باتری، `Super + Ctrl + Alt + C` عکس صفحه |

افزودن `Alt` به یک کلید میانبر، گونه‌ای از همان چیز را به شما می‌دهد، هرگز چیزی نامربوط را نه:

- `Super + Shift + B` مرورگر را باز می‌کند؛ `Super + Shift + Alt + B` یک پنجره خصوصی باز می‌کند
- `Super + Shift + E` ایمیل را باز می‌کند؛ `Super + Shift + Alt + E` یک ایمیل جدید شروع می‌کند
- `Super + F` به تمام‌صفحه می‌رود؛ `Super + Alt + F` به تمام‌عرض می‌رود
- `Super + Ctrl + C` منوی ثبت را باز می‌کند؛ `Super + Ctrl + Alt + C` منو را رد می‌کند و یک عکس صفحه می‌گیرد

هنگام افزودن یک کلید میانبر:

1. صفحه را از روی کاری که انجام می‌دهد انتخاب کنید، سپس کلید را انتخاب کنید.
2. یک کلید میانبر موجود را برای باز کردن جا جابه‌جا نکنید. یک کلید آزاد روی صفحه درست پیدا کنید.
3. فقط برای گونه‌ای از کلید میانبر بدون آن، از `Alt` استفاده کنید.

چند کلید میانبر این قوانین را می‌شکنند چون راحت هستند. `Shift` همراه با یک پیکان یا `Tab` به‌جای باز کردن یک برنامه، جابه‌جا می‌کند یا برعکس می‌کند، و `Print`، کلیدهای رسانه، `Alt + Tab` و `Ctrl + Alt + Del` همان‌طور کار می‌کنند که همه‌جای دیگر کار می‌کنند. آن‌ها استثنا هستند، نه الگوهایی برای کپی کردن.

اگر یک پیش‌فرض به کارتان نمی‌آید (مثلاً می‌خواهید `Super + Shift + S` برای عکس‌های صفحه مثل Windows باشد)، آن را در `~/.config/hypr/bindings.lua` دوباره پیوند دهید.

| `Super + Ctrl + Left/Right`  | جابه‌جایی بین پنجره‌ها در داخل یک گروه کاشی‌کاری |

| `Super + Alt + /` | گام به عقب در میان گزینه‌های مقیاس‌بندی نمایشگر |

| `Alt + Shift + Tab` | چرخه رو به عقب در میان پنجره‌های روی فضای کاری فعال |
| `Ctrl + Alt + Tab`| چرخه تمرکز رو به جلو در میان نمایشگرها |
| `Ctrl + Alt + Shift + Tab`| چرخه تمرکز رو به عقب در میان نمایشگرها |

میانبرهای تغییر اندازه از کلیدهای فیزیکی `code:20` و `code:21` (در XKB یعنی `<AE11>` و `<AE12>`) استفاده می‌کنند، صرف‌نظر از نویسه‌های چاپ‌شده روی صفحه‌کلید. روی صفحه‌کلیدهای US این کلیدها `-` و `=` هستند؛ روی صفحه‌کلیدهای ژاپنی (JIS) آن‌ها `-` و `^` هستند؛ روی صفحه‌کلیدهای اسپانیایی آن‌ها `'` و `¡` هستند. روی JIS، `Super + ^` همان `Super + Equal` است، در حالی که `Super + Shift + -` (که `=` را تایپ می‌کند) همان `Super + Shift + Minus` است.

## کلیپ‌بورد همگانی

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Super + A`           | انتخاب همه در برنامه‌هایی که از `Ctrl + A` پشتیبانی می‌کنند    |
| `Super + C`           | کپی    |
| `Super + X`           | برش (نه در ترمینال)    |
| `Super + V`           | چسباندن    |
| `Super + Ctrl + V`           | مدیر کلیپ‌بورد    |

معمولاً در Linux، برای کپی‌کردن‌و‌چسباندن در ترمینال به `Ctrl + Shift + C/V` و برای انجام آن در همه‌جای دیگر به `Ctrl + C/V` نیاز دارید. این کلیدهای میانبر یکپارچه کلیپ‌بورد Omarchy در همه‌جا کار می‌کنند.

همه گزینه‌های ثبت همچنین در منوی Omarchy (`Super + Space`) زیر _محرک > ثبت_ در دسترس هستند.

## Tmux

کلید پیشوند `Ctrl + Space` است (`Ctrl + B` هم کار می‌کند). می‌توانید این پیوندها را در `~/.config/tmux/tmux.conf` تغییر دهید.

### پن‌ها

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Prefix + v` | تقسیم پن در کنار (عمودی) |
| `Prefix + h` | تقسیم پن در پایین (افقی) |
| `Prefix + x` | از بین بردن پن |
| `Prefix + z` | فعال/غیرفعال کردن بزرگ‌نمایی پن (تمام‌صفحه) |
| `Alt + Enter` | تقسیم پن در پایین (بدون پیشوند) |
| `Alt + Shift + Enter` | تقسیم پن در کنار (بدون پیشوند) |
| `Alt + Escape` | از بین بردن پن (بدون پیشوند) |
| `Ctrl + Alt + Arrows` | جابه‌جایی بین پن‌ها |
| `Ctrl + Alt + Shift + Arrows` | تغییر اندازه پن‌ها |

### پنجره‌ها

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Prefix + c` | پنجره جدید |
| `Prefix + k` | از بین بردن پنجره |
| `Prefix + r` | تغییر نام پنجره |
| `Alt + 1-9` | رفتن به پنجره مشخص |
| `Alt + Arrow Left/Right` | جابه‌جایی بین پنجره‌ها |
| `Alt + Shift + Arrow Left/Right` | انتقال پنجره به چپ/راست |

### نشست‌ها

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Prefix + C` | نشست جدید |
| `Prefix + K` | از بین بردن نشست |
| `Prefix + R` | تغییر نام نشست |
| `Prefix + N` | نشست بعدی |
| `Prefix + P` | نشست قبلی |
| `Alt + Arrow Up/Down` | جابه‌جایی بین نشست‌ها |
| `Prefix + s` | فهرست کردن نشست‌ها |
| `Prefix + d` | جدا شدن از نشست |

### حالت کپی (به سبک vi)

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Prefix + [` | ورود به حالت کپی |
| `v` | شروع انتخاب (در حالت کپی) |
| `y` | کپی کردن انتخاب (در حالت کپی) |

### عمومی

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Prefix + q` | بارگذاری مجدد پیکربندی |
| `Prefix + ?` | نشان دادن پیوندهای کلید Tmux |
| `Prefix + :` | خط فرمان |

### توابع چیدمان Tmux

این توابع باید داخل یک نشست Tmux اجرا شوند.

| فرمان | عملکرد |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | ایجاد چیدمان توسعه با ویرایشگر، AI و ترمینال |
| `tdlm <ai> [<second_ai>]` | ایجاد چیدمان توسعه به ازای هر زیرپوشه |
| `tsl <count> <command>` | ایجاد چیدمان گروهی چندپنی |

| `Shift + CapsLock Space Space` | — (خط تیره بلند)   |
