# کلیدهای میانبر

می‌توانید همه اتصال‌های اصلی صفحه‌کلید را با `Super + K` ببینید (اتصال‌های Tmux با `Super + Alt + K` و اتصال‌های Herdr با `Super + Ctrl + K`).

## نحوه چیدمان کلیدهای میانبر

هر کلید میانبر روی یک صفحه قرار دارد که توسط کلیدهای اصلاح‌گر آن تعیین می‌شود و هر صفحه یک وظیفه دارد. همین باعث می‌شود کلیدهای میانبر با هم قاطی نشوند و یعنی معمولا می‌توانید حدس بزنید هر چیزی کجا قرار دارد.

| صفحه | چه چیزی آنجا قرار دارد | مثال‌ها |
| --- | --- | --- |
| `Super + key` | سیستم: پنجره‌ها، فضاهای کاری، چیدمان‌ها و منوهای اصلی | `Super + Space` منوی Omarchy، `Super + W` بستن پنجره، `Super + F` تمام‌صفحه |
| `Super + Shift + key` | برنامه‌ها | `Super + Shift + B` مرورگر، `Super + Shift + E` ایمیل، `Super + Shift + N` ویرایشگر |
| `Super + Ctrl + key` | پنل‌ها و منوهای سیستم | `Super + Ctrl + A` صدا، `Super + Ctrl + N` شبکه، `Super + Ctrl + C` منوی ضبط |
| `Super + Ctrl + Alt + key` | اقدام‌های سریع و اطلاعیه‌ها | `Super + Ctrl + Alt + T` نمایش زمان، `Super + Ctrl + Alt + B` باتری، `Super + Ctrl + Alt + C` اسکرین‌شات |

افزودن `Alt` به یک کلید میانبر، گونه‌ای از همان چیز را به شما می‌دهد، هرگز چیزی نامرتبط را نمی‌دهد:

- `Super + Shift + B` مرورگر را باز می‌کند؛ `Super + Shift + Alt + B` یک پنجره خصوصی باز می‌کند
- `Super + Shift + E` ایمیل را باز می‌کند؛ `Super + Shift + Alt + E` یک ایمیل جدید شروع می‌کند
- `Super + F` به تمام‌صفحه می‌رود؛ `Super + Alt + F` به تمام‌عرض می‌رود
- `Super + Ctrl + C` منوی ضبط را باز می‌کند؛ `Super + Ctrl + Alt + C` منو را رد می‌کند و یک اسکرین‌شات می‌گیرد

هنگام افزودن یک کلید میانبر:

1. صفحه را از روی کاری که انجام می‌دهد انتخاب کنید، سپس کلید را انتخاب کنید.
2. یک کلید میانبر موجود را برای باز کردن جا جابه‌جا نکنید. یک کلید آزاد روی صفحه درست پیدا کنید.
3. از `Alt` فقط برای گونه‌ای از کلید میانبر بدون آن استفاده کنید.

چند کلید میانبر این قواعد را می‌شکنند چون راحت هستند. `Shift` همراه با یک کلید جهت‌دار یا `Tab` به جای باز کردن یک برنامه، جابه‌جا می‌کند یا جهت را برعکس می‌کند و `Print`، کلیدهای رسانه، `Alt + Tab` و `Ctrl + Alt + Del` همان‌طور کار می‌کنند که در همه جاهای دیگر کار می‌کنند. آن‌ها استثنا هستند، نه الگوهایی برای کپی کردن.

اگر یک پیش‌فرض به مذاق شما خوش نمی‌آید (مثلا می‌خواهید `Super + Shift + S` برای اسکرین‌شات‌ها مانند Windows باشد)، آن را در `~/.config/hypr/bindings.lua` دوباره تنظیم کنید.

| `Super + Alt + Shift + Tab`               | چرخش رو به عقب بین پنجره‌ها در گروه‌بندی      |
| `Super + Alt + Scroll Wheel` | چرخش بین پنجره‌ها در گروه‌بندی |
| `Super + Alt + 1/2/3/4/5`               | پرش به پنجره مشخص در گروه‌بندی      |
| `Super + Alt + Arrow`  | انتقال پنجره به داخل گروه‌بندی در جهت پیکان، از جمله پنجره‌ای روی نمایشگر آن سمت |
| `Super + Ctrl + Left/Right`  | جابه‌جایی بین پنجره‌ها در داخل یک گروه کاشی‌کاری |
| `Super + Ctrl + Z` | بزرگ‌نمایی روی صفحه (برای بزرگ‌نمایی بیشتر تکرار کنید) |
| `Super + Ctrl + Alt + Z` | کوچک‌نمایی کامل از صفحه |
| `Super + /` | حرکت به جلو در میان گزینه‌های مقیاس‌بندی نمایشگر |
| `Super + Alt + /` | حرکت به عقب در میان گزینه‌های مقیاس‌بندی نمایشگر |
| `Alt + Tab` | چرخش رو به جلو در میان پنجره‌های فضای کاری فعال |
| `Alt + Shift + Tab` | چرخش رو به عقب در میان پنجره‌های فضای کاری فعال |
| `Ctrl + Alt + Tab`| چرخش فوکوس رو به جلو در میان نمایشگرها |
| `Ctrl + Alt + Shift + Tab`| چرخش فوکوس رو به عقب در میان نمایشگرها |
| `Super + I` | تغییر زبان ورودی (با بیش از یک چیدمان یا روش ورودی) |
| `Super + Shift + I` | برگرداندن زبان ورودی |

روی تاچ‌پد، کشیدن سه و چهار انگشت فضاهای کاری را تغییر می‌دهد، پنجره‌ها را جابه‌جا می‌کند و منو و کنسول Quake را باز می‌کند؛ برای حرکت‌ها به [صفحه‌کلید، ماوس و ترک‌پد](34-keyboard-mouse-trackpad.md) مراجعه کنید.

میانبرهای تغییر اندازه از کلیدهای فیزیکی `code:20` و `code:21` (در XKB یعنی `<AE11>` و `<AE12>`) استفاده می‌کنند، صرف‌نظر از نویسه‌های چاپ‌شده روی صفحه‌کلید. روی صفحه‌کلیدهای US این کلیدها `-` و `=` هستند؛ روی صفحه‌کلیدهای ژاپنی (JIS) آن‌ها `-` و `^` هستند؛ روی صفحه‌کلیدهای اسپانیایی آن‌ها `'` و `¡` هستند. روی JIS، `Super + ^` همان `Super + Equal` است، در حالی که `Super + Shift + -` (که `=` را تایپ می‌کند) همان `Super + Shift + Minus` است.

## کلیپ‌بورد جهانی

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Super + A`           | انتخاب همه در برنامه‌هایی که از `Ctrl + A` پشتیبانی می‌کنند    |
| `Super + C`           | کپی    |
| `Super + X`           | برش (نه در ترمینال)    |
| `Super + V`           | چسباندن    |
| `Super + Ctrl + V`           | مدیر کلیپ‌بورد    |

معمولا در Linux، برای کپی‌ون‌چسباندن در ترمینال به `Ctrl + Shift + C/V` و برای انجام آن در همه جاهای دیگر به `Ctrl + C/V` نیاز دارید. این کلیدهای میانبر یکپارچه کلیپ‌بورد Omarchy در همه جا کار می‌کنند.

## ضبط

| کلید میانبر              | عملکرد                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | اسکرین‌شات                      |
| `Super + Ctrl + Alt + C`            | اسکرین‌شات (همان عکس، برای صفحه‌کلیدهایی بدون کلید Print Screen) |
| `Super + Ctrl + C` | منوی ضبط |
| `Alt + Print Screen`            | ضبط صفحه                     |
| `Super + Shift + Ctrl + Alt + C` | ضبط صفحه بدون صدا، با رد کردن منو (برای توقف دوباره بزنید) |
| `Super + Print Screen` | انتخابگر رنگ |
| `Super + Ctrl + Print Screen` | استخراج متن به کلیپ‌بورد |
| `Super + Alt + [` | کوچک‌تر کردن پوشش وب‌کم هنگام ضبط |
| `Super + Alt + ]` | بزرگ‌تر کردن پوشش وب‌کم هنگام ضبط |
| `Alt + Shift + L` | کپی کردن URL فعلی از وب‌اپ یا مرورگر |
| `Alt + Shift + D` | دانلود ویدیوی صفحه فعلی به `~/Videos` |
| `Alt + Space` | شروع/توقف دیکته (نیازمند _Setup > Defaults > Dictation_) |
| `Right Alt` | نگه داشتن برای دیکته (نیازمند _Setup > Defaults > Dictation_) |

در ضبط‌های صفحه، کلید میانبر ابتدا می‌پرسد چه صدایی می‌خواهید، سپس ضبط را شروع می‌کند. برای توقف دوباره آن را بزنید. برای جزئیات به [اسکرین‌شات‌ها و ضبط](12-screenshots-recording.md) مراجعه کنید.

همه گزینه‌های ضبط همچنین زیر _Trigger > Capture_ در منوی Omarchy (`Super + Space`) در دسترس هستند.

## سبک

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |

## Tmux

کلید پیشوند `Ctrl + Space` است (`Ctrl + B` هم کار می‌کند). می‌توانید این اتصال‌ها را در `~/.config/tmux/tmux.conf` تغییر دهید.

### قاب‌ها

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Prefix + v` | تقسیم قاب در کنار (عمودی) |
| `Prefix + h` | تقسیم قاب در پایین (افقی) |
| `Prefix + x` | کشتن قاب |
| `Prefix + z` | تغییر وضعیت بزرگ‌نمایی قاب (تمام‌صفحه) |
| `Alt + Enter` | تقسیم قاب در پایین (بدون پیشوند) |
| `Alt + Shift + Enter` | تقسیم قاب در کنار (بدون پیشوند) |
| `Alt + Escape` | کشتن قاب (بدون پیشوند) |
| `Ctrl + Alt + Arrows` | جابه‌جایی بین قاب‌ها |
| `Ctrl + Alt + Shift + Arrows` | تغییر اندازه قاب‌ها |

### پنجره‌ها
