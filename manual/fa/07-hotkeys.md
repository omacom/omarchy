# کلیدهای میانبر

می‌توانید همه‌ی اتصال‌های اصلی صفحه‌کلید را با `Super + K` ببینید (اتصال‌های Tmux با `Super + Alt + K` و اتصال‌های Herdr با `Super + Ctrl + K`).

## نحوه‌ی چیدمان کلیدهای میانبر

هر کلید میانبر روی یک صفحه قرار دارد که اصلاح‌گرهایش آن را تعیین می‌کنند و هر صفحه یک کار دارد. همین باعث می‌شود کلیدهای میانبر با هم قاطی نشوند و یعنی معمولاً می‌توانید حدس بزنید هر چیزی کجاست.

| صفحه | چه چیزی آنجا قرار دارد | مثال‌ها |
| --- | --- | --- |
| `Super + key` | سیستم: پنجره‌ها، فضاهای کاری، چیدمان‌ها و منوهای اصلی | `Super + Space` منوی Omarchy، `Super + W` بستن پنجره، `Super + F` تمام‌صفحه |
| `Super + Shift + key` | برنامه‌ها | `Super + Shift + B` مرورگر، `Super + Shift + E` ایمیل، `Super + Shift + N` ویرایشگر |
| `Super + Ctrl + key` | پنل‌ها و منوهای سیستم | `Super + Ctrl + A` صدا، `Super + Ctrl + N` شبکه، `Super + Ctrl + C` منوی ضبط |
| `Super + Ctrl + Alt + key` | اقدامات سریع و اطلاعیه‌ها | `Super + Ctrl + Alt + T` نمایش زمان، `Super + Ctrl + Alt + B` باتری، `Super + Ctrl + Alt + C` اسکرین‌شات |

افزودن `Alt` به یک کلید میانبر، گونه‌ای از همان چیز را به شما می‌دهد، هرگز چیزی نامرتبط را نه:

- `Super + Shift + B` مرورگر را باز می‌کند؛ `Super + Shift + Alt + B` یک پنجره‌ی خصوصی باز می‌کند
- `Super + Shift + E` ایمیل را باز می‌کند؛ `Super + Shift + Alt + E` یک ایمیل جدید شروع می‌کند
- `Super + F` تمام‌صفحه می‌شود؛ `Super + Alt + F` تمام‌عرض می‌شود
- `Super + Ctrl + C` منوی ضبط را باز می‌کند؛ `Super + Ctrl + Alt + C` منو را رد می‌کند و یک اسکرین‌شات می‌گیرد

هنگام افزودن یک کلید میانبر:

1. صفحه را از روی کاری که انجام می‌دهد انتخاب کنید، بعد کلید را انتخاب کنید.
2. یک کلید میانبر موجود را برای جا باز کردن جابه‌جا نکنید. یک کلید آزاد روی صفحه‌ی درست پیدا کنید.
3. فقط برای گونه‌ای از کلید میانبر بدون آن، از `Alt` استفاده کنید.

چند کلید میانبر این قوانین را می‌شکنند چون راحت‌اند. `Shift` با یک پیکان یا `Tab` به‌جای باز کردن یک برنامه، جابه‌جا می‌کند یا جهت را برعکس می‌کند و `Print`، کلیدهای رسانه، `Alt + Tab` و `Ctrl + Alt + Del` همان‌طور کار می‌کنند که همه‌جای دیگر کار می‌کنند. آن‌ها استثنا هستند، نه الگوهایی برای کپی کردن.

اگر یک پیش‌فرض به کارتان نمی‌آید (مثلاً می‌خواهید `Super + Shift + S` برای اسکرین‌شات‌ها مثل Windows باشد)، آن را در `~/.config/hypr/bindings.lua` دوباره تنظیم کنید.

| `Alt + Shift + Tab` | چرخش به عقب بین پنجره‌ها در فضای کاری فعال |

| `Ctrl + Alt + Shift + Tab` | چرخش فوکوس به عقب بین نمایشگرها |
| `Super + I` | تعویض زبان ورودی (با بیش از یک چیدمان یا روش ورودی) |
| `Super + Shift + I` | برگرداندن تعویض زبان ورودی |

روی تاچ‌پد، کشیدن سه و چهار انگشتی فضاهای کاری را عوض می‌کند، پنجره‌ها را جابه‌جا می‌کند و منو و کنسول Quake را باز می‌کند؛ برای ژست‌ها [صفحه‌کلید، ماوس و ترک‌پد](34-keyboard-mouse-trackpad.md) را ببینید.

میانبرهای تغییر اندازه از کلیدهای فیزیکی `code:20` و `code:21` (در XKB یعنی `<AE11>` و `<AE12>`) استفاده می‌کنند، صرف‌نظر از نویسه‌های چاپ‌شده روی صفحه‌کلید. در صفحه‌کلیدهای US این کلیدها `-` و `=` هستند؛ در صفحه‌کلیدهای ژاپنی (JIS) `-` و `^` هستند؛ در صفحه‌کلیدهای اسپانیایی `'` و `¡` هستند. در JIS، `Super + ^` همان `Super + Equal` است، در حالی که `Super + Shift + -` (که `=` را تایپ می‌کند) همان `Super + Shift + Minus` است.

## کلیپ‌بورد همگانی

| کلید میانبر | عملکرد |
| ----------------------- | --------------------- |
| `Super + A` | انتخاب همه در برنامه‌هایی که از `Ctrl + A` پشتیبانی می‌کنند |
| `Super + C` | کپی |
| `Super + X` | برش (نه در ترمینال) |
| `Super + V` | چسباندن |
| `Super + Ctrl + V` | مدیر کلیپ‌بورد |

معمولاً در Linux، برای کپی و چسباندن در ترمینال به `Ctrl + Shift + C/V` و برای انجام آن در همه‌جای دیگر به `Ctrl + C/V` نیاز دارید. این کلیدهای میانبر یکپارچه‌ی کلیپ‌بورد Omarchy همه‌جا کار می‌کنند.

## ضبط

| کلید میانبر | عملکرد |
| ------------------- | ------------------------------ |
| `Print Screen` | اسکرین‌شات |
| `Super + Ctrl + Alt + C` | اسکرین‌شات (همان نما، برای صفحه‌کلیدهای بدون کلید Print Screen) |
| `Super + Ctrl + C` | منوی ضبط |
| `Alt + Print Screen` | ضبط صفحه |
| `Super + Shift + Ctrl + Alt + C` | ضبط صفحه بدون صدا، بدون عبور از منو (برای توقف دوباره بزنید) |
| `Super + Print Screen` | انتخابگر رنگ |
| `Super + Ctrl + Print Screen` | استخراج متن به کلیپ‌بورد |
| `Super + Alt + [` | کوچک‌تر کردن پوشش وب‌کم هنگام ضبط |
| `Super + Alt + ]` | بزرگ‌تر کردن پوشش وب‌کم هنگام ضبط |
| `Alt + Shift + L` | کپی URL فعلی از وب‌برنامه یا مرورگر |
| `Alt + Shift + D` | دانلود ویدیوی صفحه‌ی فعلی به `~/Videos` |
| `Alt + Space` | شروع/توقف دیکته (نیازمند _Setup > Defaults > Dictation_) |
| `Right Alt` | نگه داشتن برای دیکته (نیازمند _Setup > Defaults > Dictation_) |

در ضبط‌های صفحه، کلید میانبر اول می‌پرسد چه صدایی می‌خواهید، بعد ضبط را شروع می‌کند. برای توقف دوباره آن را بزنید. برای جزئیات [اسکرین‌شات‌ها و ضبط](12-screenshots-recording.md) را ببینید.

همه‌ی گزینه‌های ضبط همچنین تحت _Trigger > Capture_ در منوی Omarchy (`Super + Space`) در دسترس‌اند.

## Tmux

کلید پیشوند `Ctrl + Space` است (`Ctrl + B` هم کار می‌کند). می‌توانید این اتصال‌ها را در `~/.config/tmux/tmux.conf` تغییر دهید.

### پنل‌ها

| کلید میانبر | عملکرد |
| ----------------------- | --------------------- |
| `Prefix + v` | تقسیم پنل در کنار (عمودی) |
| `Prefix + h` | تقسیم پنل در زیر (افقی) |
| `Prefix + x` | بستن پنل |
| `Prefix + z` | تغییر وضعیت بزرگ‌نمایی پنل (تمام‌صفحه) |
| `Alt + Enter` | تقسیم پنل در زیر (بدون پیشوند) |
| `Alt + Shift + Enter` | تقسیم پنل در کنار (بدون پیشوند) |
| `Alt + Escape` | بستن پنل (بدون پیشوند) |
| `Ctrl + Alt + Arrows` | حرکت بین پنل‌ها |
| `Ctrl + Alt + Shift + Arrows` | تغییر اندازه‌ی پنل‌ها |
