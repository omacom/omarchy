# کلیدهای میانبر

می‌توانید همهٔ پیوندهای اصلی صفحه‌کلید را با `Super + K` ببینید (پیوندهای Tmux با `Super + Alt + K` و پیوندهای Herdr با `Super + Ctrl + K`).

## کلیدهای میانبر چطور چیده شده‌اند

هر کلید میانبر روی یک لایه قرار دارد که اصلاح‌گرهایش آن را تعیین می‌کنند، و هر لایه یک کار دارد. همین باعث می‌شود کلیدهای میانبر با هم قاطی نشوند، و یعنی معمولاً می‌توانید حدس بزنید هر چیزی کجاست.

| لایه | چه چیزی آنجا قرار دارد | مثال‌ها |
| --- | --- | --- |
| `Super + key` | سیستم: پنجره‌ها، فضای‌های کاری، چیدمان‌ها و منوهای اصلی | `Super + Space` منوی Omarchy، `Super + W` بستن پنجره، `Super + F` تمام‌صفحه |
| `Super + Shift + key` | برنامه‌ها | `Super + Shift + B` مرورگر، `Super + Shift + E` ایمیل، `Super + Shift + N` ویرایشگر |
| `Super + Ctrl + key` | پنل‌ها و منوهای سیستم | `Super + Ctrl + A` صدا، `Super + Ctrl + N` شبکه، `Super + Ctrl + C` منوی ضبط |
| `Super + Ctrl + Alt + key` | اقدام‌های سریع و اطلاعیه‌ها | `Super + Ctrl + Alt + T` نمایش زمان، `Super + Ctrl + Alt + B` باتری، `Super + Ctrl + Alt + C` اسکرین‌شات |

افزودن `Alt` به یک کلید میانبر، گونه‌ای از همان چیز را به شما می‌دهد، هرگز چیزی نامربوط را نه:

- `Super + Shift + B` مرورگر را باز می‌کند؛ `Super + Shift + Alt + B` یک پنجرهٔ خصوصی باز می‌کند
- `Super + Shift + E` ایمیل را باز می‌کند؛ `Super + Shift + Alt + E` یک ایمیل جدید شروع می‌کند
- `Super + F` تمام‌صفحه می‌شود؛ `Super + Alt + F` تمام‌عرض می‌شود
- `Super + Ctrl + C` منوی ضبط را باز می‌کند؛ `Super + Ctrl + Alt + C` از منو رد می‌شود و یک اسکرین‌شات می‌گیرد

هنگام افزودن یک کلید میانبر:

1. لایه را از کاری که انجام می‌دهد انتخاب کنید، بعد کلید را انتخاب کنید.
2. یک کلید میانبر موجود را برای باز کردن جا جابه‌جا نکنید. یک کلید آزاد روی لایهٔ درست پیدا کنید.
3. فقط برای گونه‌ای از کلید میانبرِ بدون آن از `Alt` استفاده کنید.

چند کلید میانبر این قواعد را می‌شکنند چون راحت‌اند. `Shift` با یک پیکان یا `Tab` به‌جای باز کردن یک برنامه، جابه‌جا می‌کند یا برعکس می‌کند، و `Print`، کلیدهای رسانه، `Alt + Tab` و `Ctrl + Alt + Del` همان‌طور کار می‌کنند که همه‌جای دیگر کار می‌کنند. آن‌ها استثنا هستند، نه الگوهایی برای کپی کردن.

اگر یک پیش‌فرض به کارتان نمی‌آید (مثلاً می‌خواهید `Super + Shift + S` برای اسکرین‌شات‌ها مثل Windows باشد)، آن را در `~/.config/hypr/bindings.lua` دوباره پیوند دهید.

کلیدهای میانبر تغییر اندازه از کلیدهای فیزیکی `code:20` و `code:21` (در XKB‏ `<AE11>` و `<AE12>`) استفاده می‌کنند، صرف‌نظر از نویسه‌های چاپ‌شده روی صفحه‌کلید. روی صفحه‌کلیدهای US این کلیدها `-` و `=` هستند؛ روی صفحه‌کلیدهای ژاپنی (JIS) آن‌ها `-` و `^` هستند؛ روی صفحه‌کلیدهای اسپانیایی آن‌ها `'` و `¡` هستند. روی JIS‏، `Super + ^` همان `Super + Equal` است، در حالی که `Super + Shift + -` (که `=` را تایپ می‌کند) همان `Super + Shift + Minus` است.

## کلیپ‌بورد همگانی

| کلید میانبر | کارکرد |
| ----------------------- | --------------------- |
| `Super + A` | انتخاب همه در برنامه‌هایی که از `Ctrl + A` پشتیبانی می‌کنند |
| `Super + C` | کپی |
| `Super + X` | برش (نه در پایانه) |
| `Super + V` | چسباندن |
| `Super + Ctrl + V` | مدیر کلیپ‌بورد |

معمولاً در Linux، برای کپی‌و‌چسباندن در پایانه به `Ctrl + Shift + C/V` و برای انجام آن در همه‌جای دیگر به `Ctrl + C/V` نیاز دارید. این کلیدهای میانبر یکپارچهٔ کلیپ‌بورد Omarchy همه‌جا کار می‌کنند.

| کلید میانبر | کارکرد |
| ------------------- | ------------------------------ |
| `Print Screen` | اسکرین‌شات |

| `Super + Ctrl + Print Screen` | استخراج متن به کلیپ‌بورد |
| `Super + Alt + [` | کوچک‌تر کردن پوشش وب‌کم هنگام ضبط |
| `Super + Alt + ]` | بزرگ‌تر کردن پوشش وب‌کم هنگام ضبط |

| `Alt + Space` | شروع/توقف دیکته (نیازمند _راه‌اندازی > پیش‌فرض‌ها > دیکته_) |

در ضبط‌های صفحه، کلید میانبر اول می‌پرسد کدام صدا را می‌خواهید، بعد ضبط را شروع می‌کند. دوباره آن را بزنید تا متوقف شود. برای جزئیات [اسکرین‌شات‌ها و ضبط](12-screenshots-recording.md) را ببینید.

همهٔ گزینه‌های ضبط همچنین زیر _محرک > ضبط_ در منوی Omarchy (`Super + Space`) در دسترس‌اند.

## Tmux

کلید پیشوند `Ctrl + Space` است (`Ctrl + B` هم کار می‌کند). می‌توانید این پیوندها را در `~/.config/tmux/tmux.conf` تغییر دهید.

### پنل‌ها

| کلید میانبر | کارکرد |
| ----------------------- | --------------------- |
| `Prefix + v` | تقسیم پنل در کنار (عمودی) |
| `Prefix + h` | تقسیم پنل در پایین (افقی) |
| `Prefix + x` | از بین بردن پنل |
