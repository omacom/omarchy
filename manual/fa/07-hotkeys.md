# کلیدهای میان‌بر

می‌توانید همه نگاشت‌های اصلی صفحه‌کلید را با `Super + K` ببینید (نگاشت‌های Tmux با `Super + Alt + K` و نگاشت‌های Herdr با `Super + Ctrl + K`).

## کلیدهای میان‌بر چطور چیده شده‌اند

هر کلید میان‌بر روی یک صفحه قرار دارد که اصلاح‌کننده‌هایش آن را تعیین می‌کنند، و هر صفحه یک کار دارد. همین است که نمی‌گذارد کلیدهای میان‌بر با هم قاطی شوند، و یعنی معمولاً می‌توانید حدس بزنید هر چیز کجا زندگی می‌کند.

| صفحه | چه چیزی آنجا زندگی می‌کند | مثال‌ها |
| --- | --- | --- |
| `Super + key` | سیستم: پنجره‌ها، فضاهای کاری، چیدمان‌ها و منوهای اصلی | `Super + Space` منوی Omarchy، `Super + W` بستن پنجره، `Super + F` تمام‌صفحه |
| `Super + Shift + key` | برنامه‌ها | `Super + Shift + B` مرورگر، `Super + Shift + E` ایمیل، `Super + Shift + N` ویرایشگر |
| `Super + Ctrl + key` | پنل‌ها و منوهای سیستم | `Super + Ctrl + A` صدا، `Super + Ctrl + N` شبکه، `Super + Ctrl + C` منوی ثبت |
| `Super + Ctrl + Alt + key` | اقدامات سریع و اطلاعیه‌ها | `Super + Ctrl + Alt + T` نمایش زمان، `Super + Ctrl + Alt + B` باتری، `Super + Ctrl + Alt + C` اسکرین‌شات |

افزودن `Alt` به یک کلید میان‌بر یک گونه از همان چیز را به شما می‌دهد، هرگز چیزی نامربوط را نمی‌دهد:

- `Super + Shift + B` مرورگر را باز می‌کند؛ `Super + Shift + Alt + B` یک پنجره خصوصی باز می‌کند
- `Super + Shift + E` ایمیل را باز می‌کند؛ `Super + Shift + Alt + E` یک ایمیل جدید شروع می‌کند
- `Super + F` تمام‌صفحه می‌شود؛ `Super + Alt + F` تمام‌عرض می‌شود
- `Super + Ctrl + C` منوی ثبت را باز می‌کند؛ `Super + Ctrl + Alt + C` از منو رد می‌شود و یک اسکرین‌شات می‌گیرد

هنگام افزودن یک کلید میان‌بر:

1. صفحه را از روی کاری که انجام می‌دهد انتخاب کنید، بعد کلید را انتخاب کنید.
2. یک کلید میان‌بر موجود را برای جا باز کردن جابه‌جا نکنید. روی صفحه درست یک کلید آزاد پیدا کنید.
3. از `Alt` فقط برای یک گونه از کلید میان‌بر بدون آن استفاده کنید.

چند کلید میان‌بر این قواعد را می‌شکنند چون راحت‌ترند. `Shift` با یک کلید جهت‌دار یا `Tab` به‌جای باز کردن یک برنامه، جابه‌جا می‌کند یا جهت را برعکس می‌کند، و `Print`، کلیدهای رسانه‌ای، `Alt + Tab` و `Ctrl + Alt + Del` همان‌طور کار می‌کنند که همه‌جای دیگر کار می‌کنند. آن‌ها استثنا هستند، نه الگوهایی برای کپی کردن.

اگر یک مقدار پیش‌فرض به کارتان نمی‌آید (مثلاً می‌خواهید `Super + Shift + S` مثل Windows برای اسکرین‌شات‌ها باشد)، آن را در `~/.config/hypr/bindings.lua` دوباره نگاشت کنید.

| `Ctrl + Alt + Shift + Tab` | چرخاندن فوکوس به عقب بین مانیتورها |

میان‌برهای تغییر اندازه از کلیدهای فیزیکی `code:20` و `code:21` (در XKB‏ `<AE11>` و `<AE12>`) استفاده می‌کنند، صرف‌نظر از نویسه‌هایی که روی صفحه‌کلید چاپ شده‌اند. روی صفحه‌کلیدهای US این کلیدها `-` و `=` هستند؛ روی صفحه‌کلیدهای ژاپنی (JIS)‏ `-` و `^` هستند؛ روی صفحه‌کلیدهای اسپانیایی `'` و `¡` هستند. روی JIS، ‏`Super + ^` همان `Super + Equal` است، در حالی که `Super + Shift + -` (که `=` را تایپ می‌کند) همان `Super + Shift + Minus` است.

## کلیپ‌بورد همگانی

| کلید میان‌بر | کارکرد |
| ----------------------- | --------------------- |
| `Super + A` | انتخاب همه در برنامه‌هایی که از `Ctrl + A` پشتیبانی می‌کنند |
| `Super + C` | کپی |

همه گزینه‌های ثبت همچنین زیر _Trigger > Capture_ در منوی Omarchy (`Super + Space`) در دسترس‌اند.
