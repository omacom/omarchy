# کلیدهای میانبر

می‌توانید همه اتصال‌های اصلی صفحه‌کلید را با `Super + K` ببینید (اتصال‌های Tmux با `Super + Alt + K` و اتصال‌های Herdr با `Super + Ctrl + K`).

## پیمایش

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + Space`           | منوی Omarchy (برنامه‌ها و همه چیزهای دیگر)    |
| `Super + Alt + Space` | شبکه برنامه‌ها |
| `Super + Escape` | منوی سیستم (تعلیق، راه‌اندازی مجدد و غیره)  |

| `Super + W` or `Super + Q` | بستن پنجره             |
| `Ctrl + Alt + Del` | بستن همه پنجره‌ها |

| `Super + J` | تغییر موقعیت پنجره (افقی/عمودی) |

## کلیپ‌بورد جهانی

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + C`           | کپی    |
| `Super + X`           | برش (نه در ترمینال)    |
| `Super + V`           | چسباندن    |
| `Super + Ctrl + V`           | مدیر کلیپ‌بورد    |

معمولاً در Linux، برای کپی'n'چسباندن در ترمینال به `Ctrl + Shift + C/V` و برای انجام آن در همه جاهای دیگر به `Ctrl + C/V` نیاز دارید. این کلیدهای میانبر یکپارچه کلیپ‌بورد Omarchy در همه جا کار می‌کنند.

## ثبت

| Hotkey              | Function                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | اسکرین‌شات                      |
| `Super + Ctrl + Alt + C`            | اسکرین‌شات (همان عکس، برای صفحه‌کلیدهایی که کلید Print Screen ندارند) |
| `Super + Ctrl + C` | منوی ثبت |
| `Alt + Print Screen`            | ضبط صفحه                     |

| `Super + Ctrl + Print Screen` | استخراج متن به کلیپ‌بورد |
| `Super + Alt + [` | کوچک‌تر کردن پوشش وب‌کم هنگام ضبط |
| `Super + Alt + ]` | بزرگ‌تر کردن پوشش وب‌کم هنگام ضبط |
| `Alt + Shift + L` | کپی کردن URL فعلی از وب‌اپ یا Chromium |
| `Alt + Shift + D` | دانلود ویدیوی صفحه فعلی به `~/Videos` |
| `Super + Ctrl + X` | شروع/توقف دیکته (نیازمند _تنظیمات > پیش‌فرض‌ها > دیکته_) |
| `Right Alt` / `F9` | دیکته فشاری برای صحبت (نیازمند Voxtype یا Superwhisper) |

در ضبط‌های صفحه، کلید میانبر ابتدا می‌پرسد کدام صدا را می‌خواهید، سپس ضبط را شروع می‌کند. دوباره آن را بزنید تا متوقف شود. برای جزئیات به [اسکرین‌شات‌ها و ضبط](12-screenshots-recording.md) مراجعه کنید.

همه گزینه‌های ثبت همچنین در منوی Omarchy (`Super + Space`) زیر _محرک > ثبت_ در دسترس هستند.

همه گزینه‌های سبک همچنین در منوی Omarchy (`Super + Space`) زیر _سبک_ در دسترس هستند.

## Tmux
