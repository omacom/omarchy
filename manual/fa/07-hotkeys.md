# کلیدهای میانبر

می‌توانید همه‌ی اتصال‌های اصلی صفحه‌کلید را با `Super + K` ببینید (اتصال‌های Tmux با `Super + Alt + K` و اتصال‌های Herdr با `Super + Ctrl + K`).

## ناوبری

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Super + Space`           | منوی Omarchy (برنامه‌ها و همه‌چیز دیگر)    |
| `Super + Alt + Space` | شبکه‌ی برنامه‌ها |
| `Super + Escape` | منوی سیستم (تعلیق، راه‌اندازی مجدد، و غیره)  |
| `Super + Ctrl + L` | قفل کردن رایانه |
| `Super + W` or `Super + Q` | بستن پنجره             |
| `Ctrl + Alt + Del` | بستن همه‌ی پنجره‌ها |
| `Super + T`               | جابه‌جایی پنجره بین حالت کاشی‌کاری/شناور             |
| `Super + J` | جابه‌جایی موقعیت پنجره (افقی/عمودی) |
| `Super + O`               | فعال/غیرفعال کردن بیرون کشیدن پنجره به حالت چسبان و شناور |
| `Super + L`               | چرخش بین چیدمان‌های dwindle، scrolling و floating |
| `Super + Alt + L`         | چرخش معکوس بین چیدمان‌ها |
| `Super + P`               | جابه‌جایی سبک پنجره‌ی شبه (natural در برابر stretch) |
| `Super + F`                 | رفتن به حالت تمام‌صفحه              |
| `Super + Alt + F`                 | رفتن به حالت تمام‌عرض              |
| `Super + Ctrl + F`                 | رفتن به حالت تمام‌صفحه در داخل پنجره              |
| `Super + 1/2/3/4`         | پرش به فضای کاری مشخص روی نمایشگر متمرکز |
| `Super + Tab` | پرش به فضای کاری بعدی روی نمایشگر متمرکز |
| `Super + Shift + Tab` | پرش به فضای کاری قبلی روی نمایشگر متمرکز |
| `Super + Ctrl + Tab` | پرش به فضای کاری پیشین روی نمایشگر متمرکز |
| `Super + Shift + 1/2/3/4` | انتقال پنجره به فضای کاری روی نمایشگر متمرکز |
| `Super + Shift + Alt + 1/2/3/4` | انتقال پنجره به فضای کاری روی نمایشگر متمرکز بدون دنبال کردن آن |
| `Super + S` | فعال/غیرفعال کردن اسکرچ‌پد کامل |
| `Super + Alt + S` | انتقال پنجره به اسکرچ‌پد کامل |
| `Super + Grave` | فعال/غیرفعال کردن کنسول Quake |
| `Super + Shift + Grave` | انتقال پنجره به کنسول Quake |
| `Super + Shift + Ctrl + Arrows` | انتقال پنجره به نمایشگر در آن جهت |
| `Super + Shift + Alt + Arrows` | انتقال فضای کاری به نمایشگر در آن جهت |
| `Super + Arrow`  | انتقال فوکوس به پنجره در جهت پیکان، با عبور به نمایشگر آن سمت در لبه‌ی صفحه |
| `Super + Shift + Arrow`  | تعویض پنجره با پنجره‌ی دیگری در جهت پیکان، از جمله پنجره‌ای روی نمایشگر آن سمت |
| `Super + Minus` | گسترش پنجره به سمت چپ |
| `Super + Equal` | کوچک کردن پنجره از سمت چپ |
| `Super + Shift + Minus` | کوچک کردن پنجره از بالا |
| `Super + Shift + Equal` | گسترش پنجره به سمت پایین |
| `Super + Alt + Minus/Equal` | همان تغییر اندازه با گام‌های کوچک‌تر |
| `Super + Ctrl + Minus/Equal` | همان تغییر اندازه با گام‌های بزرگ‌تر |
| `Super + Alt + Home` | ذخیره‌ی عرض پنجره |
| `Super + Home` | بازیابی عرض ذخیره‌شده‌ی پنجره |
| `Super + Left Mouse` | کشیدن پنجره به اطراف |
| `Super + Right Mouse` | تغییر اندازه‌ی پنجره |
| `Super + Scroll Wheel` | پیمایش بین فضاهای کاری روی نمایشگر متمرکز |
| `Super + G`               | فعال/غیرفعال کردن گروه‌بندی پنجره      |
| `Super + Alt + G`               | خارج کردن پنجره از گروه‌بندی      |
| `Super + Alt + Tab`               | چرخش بین پنجره‌ها در گروه‌بندی      |
| `Super + Alt + Shift + Tab`               | چرخش معکوس بین پنجره‌ها در گروه‌بندی      |
| `Super + Alt + Scroll Wheel` | چرخش بین پنجره‌ها در گروه‌بندی |
| `Super + Alt + 1/2/3/4/5`               | پرش به پنجره‌ی مشخص در گروه‌بندی      |
| `Super + Alt + Arrow`  | انتقال پنجره به داخل گروه‌بندی در جهت پیکان، از جمله پنجره‌ای روی نمایشگر آن سمت |
| `Super + Ctrl + Left/Right`  | جابه‌جایی بین پنجره‌ها در داخل یک گروه کاشی‌کاری |
| `Super + Ctrl + Z` | بزرگ‌نمایی صفحه (برای بزرگ‌نمایی بیشتر تکرار کنید) |
| `Super + Ctrl + Alt + Z` | کوچک‌نمایی کامل صفحه |
| `Super + /` | حرکت به جلو بین گزینه‌های مقیاس‌بندی نمایشگر |
| `Super + Alt + /` | حرکت به عقب بین گزینه‌های مقیاس‌بندی نمایشگر |
| `Alt + Tab` | چرخش به جلو بین پنجره‌های فضای کاری فعال |
| `Alt + Shift + Tab` | چرخش به عقب بین پنجره‌های فضای کاری فعال |
| `Ctrl + Alt + Tab`| چرخش فوکوس به جلو بین نمایشگرها |
| `Ctrl + Alt + Shift + Tab`| چرخش فوکوس به عقب بین نمایشگرها |

میانبرهای تغییر اندازه از کلیدهای فیزیکی `code:20` و `code:21` (در XKB برابر `<AE11>` و `<AE12>`) استفاده می‌کنند، صرف‌نظر از نویسه‌های چاپ‌شده روی صفحه‌کلید. روی صفحه‌کلیدهای US این کلیدها `-` و `=` هستند؛ روی صفحه‌کلیدهای ژاپنی (JIS) آن‌ها `-` و `^` هستند؛ روی صفحه‌کلیدهای اسپانیایی `'` و `¡` هستند. روی JIS، `Super + ^` همان `Super + Equal` است، در حالی که `Super + Shift + -` (که `=` را تایپ می‌کند) همان `Super + Shift + Minus` است.

## کلیپ‌بورد همگانی

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Super + A`           | انتخاب همه در برنامه‌هایی که از `Ctrl + A` پشتیبانی می‌کنند    |
| `Super + C`           | کپی    |
| `Super + X`           | برش (در ترمینال نه)    |
| `Super + V`           | چسباندن    |
| `Super + Ctrl + V`           | مدیر کلیپ‌بورد    |

معمولاً در Linux، برای کپی و چسباندن در ترمینال به `Ctrl + Shift + C/V` و برای انجام آن در همه‌جای دیگر به `Ctrl + C/V` نیاز دارید. این کلیدهای میانبر یکپارچه‌ی کلیپ‌بورد Omarchy همه‌جا کار می‌کنند.

## ضبط

| کلید میانبر              | عملکرد                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | اسکرین‌شات                      |
| `Super + Ctrl + Alt + C`            | اسکرین‌شات (همان عکس، برای صفحه‌کلیدهایی که کلید Print Screen ندارند) |

| `Super + Print Screen` | انتخاب‌گر رنگ |
| `Super + Ctrl + Print Screen` | استخراج متن به کلیپ‌بورد |
| `Super + Alt + [` | کوچک‌تر کردن لایه‌ی رویی وب‌کم هنگام ضبط |
| `Super + Alt + ]` | بزرگ‌تر کردن لایه‌ی رویی وب‌کم هنگام ضبط |
| `Alt + Shift + L` | کپی URL فعلی از وب‌اپ یا Chromium |
| `Alt + Shift + D` | دانلود ویدیوی صفحه‌ی فعلی در `~/Videos` |
| `Alt + Space` | شروع/توقف دیکته (نیازمند _Setup > Defaults > Dictation_) |
| `Right Alt` | نگه داشتن برای دیکته (نیازمند _Setup > Defaults > Dictation_) |

در ضبط‌های صفحه، کلید میانبر ابتدا می‌پرسد کدام صدا را می‌خواهید، سپس ضبط را شروع می‌کند. برای توقف دوباره آن را بزنید. برای جزئیات به [اسکرین‌شات‌ها و ضبط](12-screenshots-recording.md) مراجعه کنید.

همه‌ی گزینه‌های ضبط همچنین در منوی Omarchy (`Super + Space`) زیر _Trigger > Capture_ در دسترس هستند.

## سبک

| کلید میانبر                  | عملکرد              |

## Tmux

کلید پیشوند `Ctrl + Space` است (`Ctrl + B` هم کار می‌کند). می‌توانید این اتصال‌ها را در `~/.config/tmux/tmux.conf` تغییر دهید.

### قاب‌ها

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Prefix + v` | تقسیم قاب در کنار (عمودی) |
| `Prefix + h` | تقسیم قاب در پایین (افقی) |
| `Prefix + x` | بستن قاب |
| `Prefix + z` | فعال/غیرفعال کردن بزرگ‌نمایی قاب (تمام‌صفحه) |
| `Alt + Enter` | تقسیم قاب در پایین (بدون پیشوند) |
| `Alt + Shift + Enter` | تقسیم قاب در کنار (بدون پیشوند) |
| `Alt + Escape` | بستن قاب (بدون پیشوند) |
| `Ctrl + Alt + Arrows` | جابه‌جایی بین قاب‌ها |
| `Ctrl + Alt + Shift + Arrows` | تغییر اندازه‌ی قاب‌ها |

### پنجره‌ها

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Prefix + c` | پنجره‌ی جدید |
| `Prefix + k` | بستن پنجره |
| `Prefix + r` | تغییر نام پنجره |
| `Alt + 1-9` | رفتن به پنجره‌ی مشخص |
| `Alt + Arrow Left/Right` | جابه‌جایی بین پنجره‌ها |
| `Alt + Shift + Arrow Left/Right` | انتقال پنجره به چپ/راست |

### نشست‌ها

### عمومی

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Prefix + q` | بارگذاری مجدد پیکربندی |

### توابع چیدمان Tmux

این توابع باید داخل یک نشست Tmux اجرا شوند.

| دستور | عملکرد |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | ایجاد چیدمان توسعه با ویرایشگر، AI و ترمینال |
| `tdlm <ai> [<second_ai>]` | ایجاد چیدمان توسعه برای هر زیرپوشه |
| `tsl <count> <command>` | ایجاد چیدمان ازدحامی چندقابی |
