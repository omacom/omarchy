# کلیدهای میانبر

می‌توانید همهٔ پیوندهای اصلی صفحه‌کلید را با `Super + K` ببینید (پیوندهای Tmux با `Super + Alt + K` و پیوندهای Herdr با `Super + Ctrl + K`).

## پیمایش

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Super + Space`           | منوی Omarchy (برنامه‌ها و همه‌چیز دیگر)    |
| `Super + Alt + Space` | شبکهٔ برنامه‌ها |
| `Super + Escape` | منوی سیستم (تعلیق، راه‌اندازی مجدد، و غیره)  |
| `Super + Ctrl + L` | قفل کردن رایانه |
| `Super + W` or `Super + Q` | بستن پنجره             |
| `Ctrl + Alt + Del` | بستن همهٔ پنجره‌ها |
| `Super + T`               | تغییر وضعیت پنجره بین کاشی‌کاری/شناور             |
| `Super + J` | تغییر موقعیت پنجره (افقی/عمودی) |
| `Super + O`               | تغییر وضعیت پنجرهٔ بازشونده به چسبان و شناور |
| `Super + L`               | چرخش میان چیدمان‌های dwindle، scrolling و floating |
| `Super + Alt + L`         | چرخش میان چیدمان‌ها در جهت معکوس |
| `Super + P`               | تغییر سبک پنجرهٔ شبه‌حالت (natural در برابر stretch) |
| `Super + F`                 | رفتن به تمام‌صفحه              |
| `Super + Alt + F`                 | رفتن به تمام‌عرض              |
| `Super + Ctrl + F`                 | رفتن به تمام‌صفحه در داخل پنجره              |
| `Super + 1/2/3/4`         | پرش به فضای کاری خاص روی مانیتور متمرکز |
| `Super + Tab` | پرش به فضای کاری بعدی روی مانیتور متمرکز |
| `Super + Shift + Tab` | پرش به فضای کاری قبلی روی مانیتور متمرکز |
| `Super + Ctrl + Tab` | پرش به فضای کاری پیشین روی مانیتور متمرکز |
| `Super + Shift + 1/2/3/4` | انتقال پنجره به فضای کاری روی مانیتور متمرکز |
| `Super + Shift + Alt + 1/2/3/4` | انتقال پنجره به فضای کاری روی مانیتور متمرکز بدون دنبال کردن آن |
| `Super + S` | تغییر وضعیت اسکرچ‌پد کامل |
| `Super + Alt + S` | انتقال پنجره به اسکرچ‌پد کامل |
| `Super + Grave` | تغییر وضعیت کنسول Quake |
| `Super + Shift + Grave` | انتقال پنجره به کنسول Quake |
| `Super + Shift + Ctrl + Arrows` | انتقال پنجره به مانیتور در آن جهت |
| `Super + Shift + Alt + Arrows` | انتقال فضای کاری به مانیتور در آن جهت |
| `Super + Arrow`  | انتقال تمرکز به پنجره در جهت پیکان، با عبور به مانیتور آن سمت در لبهٔ صفحه |
| `Super + Shift + Arrow`  | جابه‌جایی پنجره با پنجره‌ای دیگر در جهت پیکان، از جمله پنجره‌ای روی مانیتور آن سمت |
| `Super + Minus` | گسترش پنجره به سمت چپ |
| `Super + Equal` | کوچک کردن پنجره به سمت چپ |
| `Super + Shift + Minus` | کوچک کردن پنجره به سمت بالا |
| `Super + Shift + Equal` | گسترش پنجره به سمت پایین |
| `Super + Alt + Minus/Equal` | همان تغییر اندازه در گام‌های کوچک‌تر |
| `Super + Ctrl + Minus/Equal` | همان تغییر اندازه در گام‌های بزرگ‌تر |
| `Super + Alt + Home` | ذخیرهٔ عرض پنجره |
| `Super + Home` | بازیابی عرض ذخیره‌شدهٔ پنجره |
| `Super + Left Mouse` | کشیدن پنجره به اطراف |
| `Super + Right Mouse` | تغییر اندازهٔ پنجره |
| `Super + Scroll Wheel` | پیمایش میان فضاهای کاری روی مانیتور متمرکز |
| `Super + G`               | تغییر وضعیت گروه‌بندی پنجره      |
| `Super + Alt + G`               | خارج کردن پنجره از گروه‌بندی      |
| `Super + Alt + Tab`               | چرخش میان پنجره‌ها در گروه‌بندی      |
| `Super + Alt + Shift + Tab`               | چرخش معکوس میان پنجره‌ها در گروه‌بندی      |
| `Super + Alt + Scroll Wheel` | چرخش میان پنجره‌ها در گروه‌بندی |
| `Super + Alt + 1/2/3/4/5`               | پرش به پنجرهٔ خاص در گروه‌بندی      |
| `Super + Alt + Arrow`  | انتقال پنجره به داخل گروه‌بندی در جهت پیکان، از جمله پنجره‌ای روی مانیتور آن سمت |
| `Super + Ctrl + Left/Right`  | جابه‌جایی میان پنجره‌ها در داخل یک گروه کاشی‌کاری |
| `Super + Ctrl + Z` | بزرگ‌نمایی روی صفحه (تکرار برای بزرگ‌نمایی بیشتر) |
| `Super + Ctrl + Alt + Z` | خروج کامل از بزرگ‌نمایی صفحه |
| `Super + /` | گام برداشتن به جلو میان گزینه‌های مقیاس‌بندی مانیتور |
| `Super + Alt + /` | گام برداشتن به عقب میان گزینه‌های مقیاس‌بندی مانیتور |
| `Alt + Tab` | چرخش به جلو میان پنجره‌ها در فضای کاری فعال |
| `Alt + Shift + Tab` | چرخش به عقب میان پنجره‌ها در فضای کاری فعال |
| `Ctrl + Alt + Tab`| چرخش تمرکز به جلو میان مانیتورها |
| `Ctrl + Alt + Shift + Tab`| چرخش تمرکز به عقب میان مانیتورها |

## کلیپ‌بورد جهانی

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Super + C`           | کپی    |
| `Super + X`           | برش (نه در پایانه)    |
| `Super + V`           | چسباندن    |
| `Super + Ctrl + V`           | مدیر کلیپ‌بورد    |

معمولاً در Linux، برای کپی و چسباندن در پایانه به `Ctrl + Shift + C/V` و برای انجام آن در همه‌جای دیگر به `Ctrl + C/V` نیاز دارید. این کلیدهای میانبر یکپارچهٔ کلیپ‌بورد Omarchy در همه‌جا کار می‌کنند.

## ثبت

| کلید میانبر              | عملکرد                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | عکس از صفحه                      |
| `Super + Ctrl + Alt + C`            | عکس از صفحه (همان عکس، برای صفحه‌کلیدهایی که کلید Print Screen ندارند) |
| `Super + Ctrl + C` | منوی ثبت |
| `Alt + Print Screen`            | ضبط صفحه                     |
| `Super + Print Screen` | انتخاب‌گر رنگ |
| `Super + Ctrl + Print Screen` | استخراج متن به کلیپ‌بورد |
| `Super + Alt + [` | کوچک‌تر کردن پوشش وب‌کم هنگام ضبط |
| `Super + Alt + ]` | بزرگ‌تر کردن پوشش وب‌کم هنگام ضبط |
| `Alt + Shift + L` | کپی کردن URL فعلی از وب‌برنامه یا Chromium |
| `Alt + Shift + D` | دانلود ویدیوی صفحهٔ فعلی در `~/Videos` |
| `Super + Ctrl + X` | شروع/توقف دیکته (نیازمند _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | دیکتهٔ فشاری برای صحبت (نیازمند Voxtype یا Superwhisper) |

در ضبط‌های صفحه، کلید میانبر ابتدا می‌پرسد کدام صدا را می‌خواهید، سپس ضبط را شروع می‌کند. برای توقف، دوباره آن را بزنید. برای جزئیات به [عکس‌های صفحه و ضبط](12-screenshots-recording.md) مراجعه کنید.

همهٔ گزینه‌های ثبت همچنین در منوی Omarchy (`Super + Space`) زیر _Trigger > Capture_ در دسترس هستند.

## سبک

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Super + Ctrl + T` | انتخاب یک تم جدید (همچنین `Super + Ctrl + Shift + Space`) |
| `Super + Ctrl + W` | انتخاب پس‌زمینهٔ تم (همچنین `Super + Ctrl + Space`) |
| `Super + Backspace` | تغییر وضعیت شفافیت روی یک پنجره |
| `Super + Ctrl + Backspace` | تغییر وضعیت نسبت ابعاد مربعی تک‌پنجره |

تصاویر پس‌زمینهٔ اضافی در `~/.config/omarchy/backgrounds/<theme name>` قرار دارند. همچنین از طریق _Install > Style > Background_ در منوی Omarchy در دسترس است.

همهٔ گزینه‌های سبک همچنین در منوی Omarchy (`Super + Space`) زیر _Style_ در دسترس هستند.

## Tmux

کلید پیشوند `Ctrl + Space` است (`Ctrl + B` نیز کار می‌کند). می‌توانید این پیوندها را در `~/.config/tmux/tmux.conf` تغییر دهید.

### پنل‌ها

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Prefix + v` | تقسیم پنل در کنار (عمودی) |
| `Prefix + h` | تقسیم پنل در پایین (افقی) |
| `Prefix + x` | بستن پنل |
| `Prefix + z` | تغییر وضعیت بزرگ‌نمایی پنل (تمام‌صفحه) |
| `Alt + Enter` | تقسیم پنل در پایین (بدون پیشوند) |
| `Alt + Shift + Enter` | تقسیم پنل در کنار (بدون پیشوند) |
| `Alt + Escape` | بستن پنل (بدون پیشوند) |
| `Ctrl + Alt + Arrows` | جابه‌جایی میان پنل‌ها |
| `Ctrl + Alt + Shift + Arrows` | تغییر اندازهٔ پنل‌ها |

### پنجره‌ها

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Prefix + c` | پنجرهٔ جدید |
| `Prefix + k` | بستن پنجره |

| `Alt + 1-9` | رفتن به پنجرهٔ خاص |
| `Alt + Arrow Left/Right` | جابه‌جایی میان پنجره‌ها |

### توابع چیدمان Tmux

این توابع باید در داخل یک نشست Tmux اجرا شوند.

| دستور | عملکرد |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | ایجاد چیدمان توسعه با ویرایشگر، AI و پایانه |
| `tdlm <ai> [<second_ai>]` | ایجاد چیدمان توسعه به ازای هر زیرپوشه |
| `tsl <count> <command>` | ایجاد چیدمان ازدحامی چندپنلی |
