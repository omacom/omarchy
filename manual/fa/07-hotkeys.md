# کلیدهای میانبر

می‌توانید همه پیوندهای اصلی صفحه‌کلید را با `Super + K` ببینید (پیوندهای Tmux با `Super + Alt + K` و پیوندهای Herdr با `Super + Ctrl + K`).

## کلیدهای میانبر چطور چیده شده‌اند

هر کلید میانبر روی یک صفحه قرار دارد که اصلاح‌کننده‌هایش آن را تعیین می‌کنند، و هر صفحه یک کار دارد. همین باعث می‌شود کلیدهای میانبر با هم قاطی نشوند، و یعنی معمولاً می‌توانید حدس بزنید هر چیزی کجا قرار دارد.

| صفحه | چه چیزهایی آنجا قرار دارند | مثال‌ها |
| --- | --- | --- |
| `Super + key` | سیستم: پنجره‌ها، فضاهای کاری، چیدمان‌ها و منوهای اصلی | `Super + Space` منوی Omarchy، `Super + W` بستن پنجره، `Super + F` تمام‌صفحه |
| `Super + Shift + key` | برنامه‌ها | `Super + Shift + B` مرورگر، `Super + Shift + E` ایمیل، `Super + Shift + N` ویرایشگر |
| `Super + Ctrl + key` | پنل‌ها و منوهای سیستم | `Super + Ctrl + A` صدا، `Super + Ctrl + N` شبکه، `Super + Ctrl + C` منوی ضبط |
| `Super + Ctrl + Alt + key` | اقدامات سریع و اطلاعیه‌ها | `Super + Ctrl + Alt + T` نمایش زمان، `Super + Ctrl + Alt + B` باتری، `Super + Ctrl + Alt + C` اسکرین‌شات |

افزودن `Alt` به یک کلید میانبر، گونه‌ای از همان چیز را به شما می‌دهد، هرگز چیزی نامرتبط را نمی‌دهد:

- `Super + Shift + B` مرورگر را باز می‌کند؛ `Super + Shift + Alt + B` یک پنجره خصوصی باز می‌کند
- `Super + Shift + E` ایمیل را باز می‌کند؛ `Super + Shift + Alt + E` یک ایمیل جدید شروع می‌کند
- `Super + F` تمام‌صفحه می‌شود؛ `Super + Alt + F` تمام‌عرض می‌شود
- `Super + Ctrl + C` منوی ضبط را باز می‌کند؛ `Super + Ctrl + Alt + C` از منو رد می‌شود و یک اسکرین‌شات می‌گیرد

هنگام افزودن یک کلید میانبر:

1. صفحه را از روی کاری که انجام می‌دهد انتخاب کنید، سپس کلید را انتخاب کنید.
2. یک کلید میانبر موجود را برای باز کردن جا جابه‌جا نکنید. یک کلید آزاد روی صفحه درست پیدا کنید.
3. از `Alt` فقط برای گونه‌ای از کلید میانبر بدون آن استفاده کنید.

تعدادی از کلیدهای میانبر این قوانین را می‌شکنند چون راحت هستند. `Shift` همراه با یک پیکان یا `Tab` به جای باز کردن یک برنامه، جابه‌جا می‌کند یا معکوس می‌کند، و `Print`، کلیدهای رسانه، `Alt + Tab` و `Ctrl + Alt + Del` همان‌طور کار می‌کنند که در همه جای دیگر کار می‌کنند. آن‌ها استثنا هستند، نه الگوهایی برای کپی کردن.

اگر یک پیش‌فرض به کارتان نمی‌آید (مثلاً می‌خواهید `Super + Shift + S` برای اسکرین‌شات‌ها باشد، مثل Windows)، آن را در `~/.config/hypr/bindings.lua` دوباره پیوند دهید.

روی تاچ‌پد، کشیدن سه و چهار انگشت فضاهای کاری را تغییر می‌دهد، پنجره‌ها را جابه‌جا می‌کند و منو و کنسول Quake را باز می‌کند؛ برای حرکت‌ها به [صفحه‌کلید، ماوس و ترک‌پد](34-keyboard-mouse-trackpad.md) مراجعه کنید.

میانبرهای تغییر اندازه از کلیدهای فیزیکی `code:20` و `code:21` (در XKB یعنی `<AE11>` و `<AE12>`) استفاده می‌کنند، صرف‌نظر از نویسه‌های چاپ‌شده روی صفحه‌کلید. روی صفحه‌کلیدهای US این کلیدها `-` و `=` هستند؛ روی صفحه‌کلیدهای ژاپنی (JIS) آن‌ها `-` و `^` هستند؛ روی صفحه‌کلیدهای اسپانیایی آن‌ها `'` و `¡` هستند. در JIS، `Super + ^` همان `Super + Equal` است، در حالی که `Super + Shift + -` (که `=` را تایپ می‌کند) همان `Super + Shift + Minus` است.

## کلیپ‌بورد جهانی

| کلید میانبر | کارکرد |
| ----------------------- | --------------------- |
| `Super + A` | انتخاب همه در برنامه‌هایی که از `Ctrl + A` پشتیبانی می‌کنند |
| `Super + C` | کپی |

معمولاً در Linux، برای کپی و چسباندن در ترمینال به `Ctrl + Shift + C/V` و برای انجام آن در همه جای دیگر به `Ctrl + C/V` نیاز دارید. این کلیدهای میانبر یکپارچه کلیپ‌بورد Omarchy در همه جا کار می‌کنند.

## ضبط

| کلید میانبر | کارکرد |
| ------------------- | ------------------------------ |
| `Print Screen` | اسکرین‌شات |
| `Super + Ctrl + Alt + C` | اسکرین‌شات (همان عکس، برای صفحه‌کلیدهایی بدون کلید Print Screen) |
| `Super + Ctrl + C` | منوی ضبط |
| `Alt + Print Screen` | ضبط صفحه |
| `Super + Shift + Ctrl + Alt + C` | ضبط صفحه بدون صدا، بدون نمایش منو (برای توقف دوباره بزنید) |
| `Super + Print Screen` | انتخابگر رنگ |
| `Super + Ctrl + Print Screen` | استخراج متن به کلیپ‌بورد |
| `Super + Alt + [` | کوچک‌تر کردن پوشش وب‌کم هنگام ضبط |
| `Super + Alt + ]` | بزرگ‌تر کردن پوشش وب‌کم هنگام ضبط |
| `Alt + Shift + L` | کپی URL فعلی از وب‌اپ یا مرورگر |
| `Alt + Shift + D` | دانلود ویدیوی صفحه فعلی در `~/Videos` |
| `Alt + Space` | شروع/توقف دیکته (نیازمند _تنظیمات > پیش‌فرض‌ها > دیکته_) |
| `Right Alt` | برای دیکته نگه دارید (نیازمند _تنظیمات > پیش‌فرض‌ها > دیکته_) |

در ضبط‌های صفحه، کلید میانبر ابتدا می‌پرسد کدام صدا را می‌خواهید، سپس ضبط را شروع می‌کند. برای توقف دوباره آن را بزنید. برای جزئیات به [اسکرین‌شات‌ها و ضبط](12-screenshots-recording.md) مراجعه کنید.

همه گزینه‌های ضبط همچنین زیر _ماشه > ضبط_ در منوی Omarchy (`Super + Space`) در دسترس هستند.

| کلید میانبر | کارکرد |

## Tmux

کلید پیشوند `Ctrl + Space` است (`Ctrl + B` هم کار می‌کند). می‌توانید این پیوندها را در `~/.config/tmux/tmux.conf` تغییر دهید.

### پنل‌ها

| کلید میانبر | کارکرد |
| ----------------------- | --------------------- |
| `Prefix + v` | تقسیم پنل در کنار (عمودی) |
| `Prefix + h` | تقسیم پنل در پایین (افقی) |
| `Prefix + x` | بستن پنل |
| `Prefix + z` | تغییر وضعیت بزرگ‌نمایی پنل (تمام‌صفحه) |

| `Ctrl + Alt + Arrows` | جابه‌جایی بین پنل‌ها |
