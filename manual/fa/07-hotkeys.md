# کلیدهای میانبر

می‌توانید همه پیوندهای اصلی صفحه‌کلید را با `Super + K` ببینید (پیوندهای Tmux با `Super + Alt + K` و پیوندهای Herdr با `Super + Ctrl + K`).

## پیمایش

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Super + Space`           | منوی Omarchy (برنامه‌ها و همه چیزهای دیگر)    |
| `Super + Alt + Space` | شبکه برنامه‌ها |
| `Super + Escape` | منوی سیستم (تعلیق، راه‌اندازی مجدد و غیره)  |
| `Super + Ctrl + L` | قفل کردن رایانه |
| `Super + W` or `Super + Q` | بستن پنجره             |
| `Ctrl + Alt + Del` | بستن همه پنجره‌ها |
| `Super + T`               | جابه‌جایی پنجره بین حالت کاشی‌کاری/شناور             |
| `Super + J` | جابه‌جایی موقعیت پنجره (افقی/عمودی) |
| `Super + O`               | جابه‌جایی پنجره بازشو به حالت چسبان و شناور |
| `Super + L`               | چرخش بین چیدمان‌های dwindle، scrolling و floating |
| `Super + Alt + L`         | چرخش معکوس بین چیدمان‌ها |
| `Super + P`               | جابه‌جایی سبک پنجره شبه (طبیعی در برابر کشیده) |
| `Super + F`                 | رفتن به تمام‌صفحه              |
| `Super + Alt + F`                 | رفتن به تمام‌عرض              |
| `Super + Ctrl + F`                 | رفتن به تمام‌صفحه در داخل پنجره              |
| `Super + 1/2/3/4`         | پرش به فضای کاری مشخص روی مانیتور متمرکز |
| `Super + Tab` | پرش به فضای کاری بعدی روی مانیتور متمرکز |
| `Super + Shift + Tab` | پرش به فضای کاری قبلی روی مانیتور متمرکز |
| `Super + Ctrl + Tab` | پرش به فضای کاری پیشین روی مانیتور متمرکز |
| `Super + Shift + 1/2/3/4` | انتقال پنجره به فضای کاری روی مانیتور متمرکز |
| `Super + Shift + Alt + 1/2/3/4` | انتقال پنجره به فضای کاری روی مانیتور متمرکز بدون دنبال کردن آن |
| `Super + S` | جابه‌جایی اسکرچ‌پد کامل |
| `Super + Alt + S` | انتقال پنجره به اسکرچ‌پد کامل |
| `Super + Grave` | جابه‌جایی کنسول Quake |
| `Super + Shift + Grave` | انتقال پنجره به کنسول Quake |
| `Super + Shift + Ctrl + Arrows` | انتقال پنجره به مانیتور در آن جهت |
| `Super + Shift + Alt + Arrows` | انتقال فضای کاری به مانیتور در آن جهت |
| `Super + Arrow`  | انتقال تمرکز به پنجره در جهت پیکان، با عبور به مانیتور آن سمت در لبه صفحه |
| `Super + Shift + Arrow`  | تعویض پنجره با پنجره دیگری در جهت پیکان، از جمله پنجره‌ای روی مانیتور آن سمت |
| `Super + Minus` | گسترش پنجره به چپ |
| `Super + Equal` | کوچک کردن پنجره به چپ |
| `Super + Shift + Minus` | کوچک کردن پنجره به بالا |
| `Super + Shift + Equal` | گسترش پنجره به پایین |
| `Super + Alt + Minus/Equal` | همان تغییر اندازه با گام‌های کوچک‌تر |
| `Super + Ctrl + Minus/Equal` | همان تغییر اندازه با گام‌های بزرگ‌تر |
| `Super + Alt + Home` | ذخیره عرض پنجره |
| `Super + Home` | بازیابی عرض ذخیره‌شده پنجره |
| `Super + Left Mouse` | کشیدن پنجره به اطراف |
| `Super + Right Mouse` | تغییر اندازه پنجره |
| `Super + Scroll Wheel` | پیمایش بین فضاهای کاری روی مانیتور متمرکز |
| `Super + G`               | جابه‌جایی گروه‌بندی پنجره      |
| `Super + Alt + G`               | خارج کردن پنجره از گروه‌بندی      |
| `Super + Alt + Tab`               | چرخش بین پنجره‌ها در گروه‌بندی      |
| `Super + Alt + Shift + Tab`               | چرخش معکوس بین پنجره‌ها در گروه‌بندی      |
| `Super + Alt + Scroll Wheel` | چرخش بین پنجره‌ها در گروه‌بندی |
| `Super + Alt + 1/2/3/4/5`               | پرش به پنجره مشخص در گروه‌بندی      |
| `Super + Alt + Arrow`  | انتقال پنجره به داخل گروه‌بندی در جهت پیکان، از جمله پنجره‌ای روی مانیتور آن سمت |
| `Super + Ctrl + Left/Right`  | جابه‌جایی بین پنجره‌ها در داخل یک گروه کاشی‌کاری |
| `Super + Ctrl + Z` | بزرگ‌نمایی صفحه (برای بزرگ‌نمایی بیشتر تکرار کنید) |
| `Super + Ctrl + Alt + Z` | کوچک‌نمایی کامل صفحه |
| `Super + /` | حرکت رو به جلو بین گزینه‌های مقیاس‌بندی مانیتور |
| `Super + Alt + /` | حرکت رو به عقب بین گزینه‌های مقیاس‌بندی مانیتور |
| `Alt + Tab` | چرخش رو به جلو بین پنجره‌ها روی فضای کاری فعال |
| `Alt + Shift + Tab` | چرخش رو به عقب بین پنجره‌ها روی فضای کاری فعال |
| `Ctrl + Alt + Tab`| چرخش تمرکز رو به جلو بین مانیتورها |
| `Ctrl + Alt + Shift + Tab`| چرخش تمرکز رو به عقب بین مانیتورها |

## کلیپ‌بورد همگانی

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Super + C`           | کپی    |
| `Super + X`           | برش (نه در ترمینال)    |
| `Super + V`           | چسباندن    |
| `Super + Ctrl + V`           | مدیر کلیپ‌بورد    |

معمولاً در Linux، برای کپی و چسباندن در ترمینال به `Ctrl + Shift + C/V` و در همه‌جای دیگر به `Ctrl + C/V` نیاز دارید. این کلیدهای میانبر یکپارچه کلیپ‌بورد Omarchy در همه‌جا کار می‌کنند.

## ضبط

| کلید میانبر              | عملکرد                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | اسکرین‌شات                      |
| `Super + Ctrl + Alt + C`            | اسکرین‌شات (همان عکس، برای صفحه‌کلیدهای بدون کلید Print Screen) |
| `Super + Ctrl + C` | منوی ضبط |
| `Alt + Print Screen`            | ضبط صفحه                     |
| `Super + Print Screen` | انتخابگر رنگ |
| `Super + Ctrl + Print Screen` | استخراج متن به کلیپ‌بورد |
| `Super + Alt + [` | کوچک‌تر کردن پوشش وب‌کم هنگام ضبط |
| `Super + Alt + ]` | بزرگ‌تر کردن پوشش وب‌کم هنگام ضبط |
| `Alt + Shift + L` | کپی URL فعلی از وب‌اپ یا Chromium |
| `Alt + Shift + D` | دانلود ویدیوی صفحه فعلی در `~/Videos` |
| `Super + Ctrl + X` | شروع/توقف دیکته (نیازمند _راه‌اندازی > پیش‌فرض‌ها > دیکته_) |
| `Right Alt` / `F9` | دیکته فشاری برای صحبت (نیازمند Voxtype یا Superwhisper) |

در ضبط‌های صفحه، کلید میانبر ابتدا می‌پرسد کدام صدا را می‌خواهید، سپس ضبط را شروع می‌کند. برای توقف، دوباره آن را بزنید. برای جزئیات، [اسکرین‌شات‌ها و ضبط](12-screenshots-recording.md) را ببینید.

همه گزینه‌های ضبط همچنین در منوی Omarchy (`Super + Space`) زیر _ماشه > ضبط_ در دسترس هستند.

همه گزینه‌های سبک همچنین در منوی Omarchy (`Super + Space`) زیر _سبک_ در دسترس هستند.

## Tmux

کلید پیشوند `Ctrl + Space` است (`Ctrl + B` هم کار می‌کند). می‌توانید این پیوندها را در `~/.config/tmux/tmux.conf` تغییر دهید.

### قاب‌ها

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Prefix + v` | تقسیم قاب در کنار (عمودی) |
| `Prefix + h` | تقسیم قاب در پایین (افقی) |
| `Prefix + x` | کشتن قاب |
| `Prefix + z` | جابه‌جایی بزرگ‌نمایی قاب (تمام‌صفحه) |
| `Alt + Enter` | تقسیم قاب در پایین (بدون پیشوند) |
| `Alt + Shift + Enter` | تقسیم قاب در کنار (بدون پیشوند) |
| `Alt + Escape` | کشتن قاب (بدون پیشوند) |
| `Ctrl + Alt + Arrows` | جابه‌جایی بین قاب‌ها |
| `Ctrl + Alt + Shift + Arrows` | تغییر اندازه قاب‌ها |

### پنجره‌ها

| کلید میانبر                  | عملکرد              |
| ----------------------- | --------------------- |
| `Prefix + c` | پنجره جدید |
| `Prefix + k` | کشتن پنجره |

| `Alt + Arrow Left/Right` | جابه‌جایی بین پنجره‌ها |
| `Alt + Shift + Arrow Left/Right` | انتقال پنجره به چپ/راست |

### توابع چیدمان Tmux

این توابع باید داخل یک نشست Tmux اجرا شوند.

| دستور | عملکرد |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | ایجاد چیدمان توسعه با ویرایشگر، هوش مصنوعی و ترمینال |
| `tdlm <ai> [<second_ai>]` | ایجاد چیدمان توسعه برای هر زیرپوشه |
| `tsl <count> <command>` | ایجاد چیدمان ازدحامی چندقابی |

| `A`                        | افزودن فایل جدید در پوشه والد      |

| `?`                        | نمایش راهنما برای همه فرمان‌ها      |

[همه کلیدهای میانبر Neovim پیکربندی‌شده توسط LazyVim را ببینید](https://www.lazyvim.org/keymaps).

## تکمیل‌های سریع

| کلید میانبر       | تکمیل       |
| ------------ |  ---------- |
| `Shift + CapsLock Space Space` | — (خط تیره ام)   |
| `Shift + CapsLock Space N` | نام شما (همان‌طور که هنگام راه‌اندازی وارد کردید)  |
| `Shift + CapsLock Space E` | ایمیل شما (همان‌طور که هنگام راه‌اندازی وارد کردید)  |

می‌توانید با ویرایش `~/.XCompose` موارد بیشتری از خودتان اضافه کنید، سپس `omarchy-restart-xcompose` را در ترمینال اجرا کنید تا تغییرات دریافت شوند.
