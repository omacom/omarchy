# کلیدهای میانبر

می‌توانید همه‌ی اتصال‌های اصلی صفحه‌کلید را با `Super + K` ببینید (اتصال‌های Tmux با `Super + Alt + K` و اتصال‌های Herdr با `Super + Ctrl + K`).

## کلیدهای میانبر چطور چیده شده‌اند

هر کلید میانبر روی یک صفحه قرار دارد که اصلاح‌گرهایش آن را تعیین می‌کنند، و هر صفحه یک کار دارد. همین است که کلیدهای میانبر را از درهم‌ریختن حفظ می‌کند، و یعنی معمولاً می‌توانید حدس بزنید هر چیزی کجا قرار دارد.

| صفحه | چه چیزهایی آنجا قرار دارند | مثال‌ها |
| --- | --- | --- |
| `Super + key` | سیستم: پنجره‌ها، فضای‌های کاری، چیدمان‌ها و منوهای اصلی | `Super + Space` منوی Omarchy، `Super + W` بستن پنجره، `Super + F` تمام‌صفحه |
| `Super + Shift + key` | برنامه‌ها | `Super + Shift + B` مرورگر، `Super + Shift + E` ایمیل، `Super + Shift + N` ویرایشگر |
| `Super + Ctrl + key` | پنل‌ها و منوهای سیستم | `Super + Ctrl + A` صدا، `Super + Ctrl + N` شبکه، `Super + Ctrl + C` منوی ضبط |
| `Super + Ctrl + Alt + key` | اقدام‌های سریع و اطلاعیه‌ها | `Super + Ctrl + Alt + T` نمایش زمان، `Super + Ctrl + Alt + B` باتری، `Super + Ctrl + Alt + C` اسکرین‌شات |

افزودن `Alt` به یک کلید میانبر گونه‌ای از همان چیز را به شما می‌دهد، هرگز چیزی نامرتبط را نه:

- `Super + Shift + B` مرورگر را باز می‌کند؛ `Super + Shift + Alt + B` یک پنجره‌ی خصوصی باز می‌کند
- `Super + Shift + E` ایمیل را باز می‌کند؛ `Super + Shift + Alt + E` یک ایمیل جدید شروع می‌کند
- `Super + F` به تمام‌صفحه می‌رود؛ `Super + Alt + F` به تمام‌عرض می‌رود
- `Super + Ctrl + C` منوی ضبط را باز می‌کند؛ `Super + Ctrl + Alt + C` منو را رد می‌کند و اسکرین‌شات می‌گیرد

هنگام افزودن یک کلید میانبر:

1. صفحه را از کاری که انجام می‌دهد انتخاب کنید، بعد کلید را انتخاب کنید.
2. یک کلید میانبر موجود را برای جا باز کردن جابه‌جا نکنید. یک کلید آزاد روی صفحه‌ی درست پیدا کنید.
3. `Alt` را فقط برای گونه‌ای از کلید میانبر بدون آن به کار ببرید.

چند کلید میانبر این قواعد را می‌شکنند چون راحت هستند. `Shift` همراه با یک پیکان یا `Tab` به‌جای باز کردن یک برنامه جابه‌جا می‌کند یا برعکس می‌کند، و `Print`، کلیدهای رسانه، `Alt + Tab` و `Ctrl + Alt + Del` همان‌طور کار می‌کنند که همه‌جای دیگر کار می‌کنند. آن‌ها استثنا هستند، نه الگوهایی برای کپی کردن.

اگر یک پیش‌فرض به مذاق شما نیست (مثلاً می‌خواهید `Super + Shift + S` برای اسکرین‌شات‌ها باشد مثل Windows)، آن را در `~/.config/hypr/bindings.lua` دوباره متصل کنید.

روی تاچ‌پد، کشیدن سه و چهار انگشتی فضای‌های کاری را عوض می‌کند، پنجره‌ها را جابه‌جا می‌کند و منو و کنسول Quake را باز می‌کند؛ برای حرکات، [صفحه‌کلید، ماوس و ترک‌پد](34-keyboard-mouse-trackpad.md) را ببینید.

تغییر اندازه از دو کلید سمت راست 0 استفاده می‌کند، هرچه صفحه‌کلید شما روی آن‌ها چاپ کرده باشد: `-` و `=` روی صفحه‌کلیدهای US، `+` و `´` روی دانمارکی و سوئدی، `+` و `\` روی نروژی، `ß` و `´` روی آلمانی، `'` و `¡` روی اسپانیایی، و `-` و `^` روی ژاپنی (JIS). `Super + K` آن‌ها را همان‌طور فهرست می‌کند که صفحه‌کلید شما چاپ می‌کند. روی JIS، `Super + ^` همان `Super + Equal` است، در حالی که `Super + Shift + -` (که `=` تایپ می‌کند) همان `Super + Shift + Minus` است. مقیاس‌بندی نمایشگر و مدیر گذرواژه از `/` استفاده می‌کنند؛ روی چیدمان‌هایی که `/` را فقط با Shift تایپ می‌کنند، همان‌طور که بیشتر چیدمان‌های اروپایی چنین می‌کنند، به‌جای آن از کلید سمت چپ Shift راست استفاده می‌کنند (`-` روی دانمارکی و آلمانی).

همه‌ی گزینه‌های ضبط همچنین زیر _Trigger > Capture_ در منوی Omarchy (`Super + Space`) در دسترس هستند.

## Tmux

کلید پیشوند `Ctrl + Space` است (`Ctrl + B` هم کار می‌کند). می‌توانید این اتصال‌ها را در `~/.config/tmux/tmux.conf` تغییر دهید.

### پین‌ها

| کلید میانبر | کارکرد |
| ----------------------- | --------------------- |
| `Prefix + v` | تقسیم پین در کنار (عمودی) |

| `Prefix + x` | بستن پین |
| `Prefix + z` | جابه‌جایی بزرگ‌نمایی پین (تمام‌صفحه) |
