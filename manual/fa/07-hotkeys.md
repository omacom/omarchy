# کلیدهای میانبر

می‌توانید همهٔ نگاشت‌های اصلی صفحه‌کلید را با `Super + K` ببینید (نگاشت‌های Tmux با `Super + Alt + K` و نگاشت‌های Herdr با `Super + Ctrl + K`).

## ناوبری

| کلید میانبر | عملکرد |
| ----------------------- | --------------------- |
| `Super + Space`           | منوی Omarchy (برنامه‌ها و هر چیز دیگر)    |
| `Super + Alt + Space` | شبکهٔ برنامه‌ها |
| `Super + Escape` | منوی سیستم (تعلیق، راه‌اندازی مجدد و غیره)  |
| `Super + Ctrl + L` | قفل کردن کامپیوتر |
| `Super + W` or `Super + Q` | بستن پنجره             |
| `Ctrl + Alt + Del` | بستن همهٔ پنجره‌ها |
| `Super + T`               | تغییر وضعیت پنجره بین کاشی‌کاری/شناور             |
| `Super + J` | تغییر وضعیت موقعیت پنجره (افقی/عمودی) |
| `Super + O`               | تغییر وضعیت بیرون آوردن پنجره به حالت چسبان و شناور |
| `Super + L`               | چرخش بین چیدمان‌های dwindle، پیمایش و شناور |
| `Super + Alt + L`         | چرخش بین چیدمان‌ها در جهت معکوس |
| `Super + P`               | تغییر وضعیت سبک شبه‌پنجره (طبیعی در برابر کشیده) |
| `Super + F`                 | رفتن به تمام‌صفحه              |
| `Super + Alt + F`                 | رفتن به تمام‌عرض              |
| `Super + Ctrl + F`                 | رفتن به تمام‌صفحه inside window              |
| `Super + 1/2/3/4`         | پرش به فضای کاری مشخص     |
| `Super + Tab` | پرش به فضای کاری بعدی |
| `Super + Shift + Tab` | پرش به فضای کاری قبلی |
| `Super + Ctrl + Tab` | پرش به فضای کاری پیشین |
| `Super + Shift + 1/2/3/4` | انتقال پنجره به فضای کاری |
| `Super + Shift + Alt + 1/2/3/4` | انتقال پنجره به فضای کاری بدون دنبال کردن |
| `Super + S` / `Super + Grave` | روشن/خاموش کردن چرک‌نویس |
| `Super + Alt + S` / `Super + Shift + Grave` | انتقال پنجره به چرک‌نویس |
| `Super + Shift + Alt + Arrows` | انتقال فضاهای کاری به مانیتور جهت‌دار |
| `Super + Arrow`  | انتقال تمرکز به پنجره در جهت پیکان              |
| `Super + Shift + Arrow`  | جابه‌جایی پنجره با پنجره‌ای دیگر در جهت پیکان     |
| `Super + Minus` | گسترش پنجره به سمت چپ |
| `Super + Equal` | کوچک کردن پنجره به سمت چپ |
| `Super + Shift + Minus` | کوچک کردن پنجره به سمت بالا |
| `Super + Shift + Equal` | گسترش پنجره به سمت پایین |
| `Super + Alt + Minus/Equal` | همان تغییر اندازه با قدم‌های کوچک‌تر |
| `Super + Ctrl + Minus/Equal` | همان تغییر اندازه با قدم‌های بزرگ‌تر |
| `Super + Alt + Home` | ذخیرهٔ عرض پنجره |
| `Super + Home` | بازگرداندن عرض ذخیره‌شدهٔ پنجره |
| `Super + Left Mouse` | کشیدن پنجره به اطراف |
| `Super + Right Mouse` | تغییر اندازه پنجره |
| `Super + Scroll Wheel` | پیمایش در فضاهای کاری |
| `Super + G`               | روشن/خاموش کردن گروه‌بندی پنجره      |
| `Super + Alt + G`               | انتقال پنجره به خارج از گروه‌بندی      |
| `Super + Alt + Tab`               | چرخش بین پنجره‌های گروه      |
| `Super + Alt + Shift + Tab`               | چرخش معکوس بین پنجره‌های گروه      |
| `Super + Alt + 1/2/3/4/5`               | پرش به پنجرهٔ مشخص در گروه      |
| `Super + Alt + Arrow`  | انتقال پنجره به داخل گروه در جهت پیکان  |
| `Super + Ctrl + Left/Right`  | جابه‌جایی بین پنجره‌های داخل یک گروه کاشی‌کاری |
| `Super + Ctrl + Z` | بزرگ‌نمایی صفحه (برای بزرگ‌نمایی بیشتر تکرار کنید) |
| `Super + Ctrl + Alt + Z` | کوچک‌نمایی کامل صفحه |
| `Super + /` | قدم به جلو در گزینه‌های مقیاس‌بندی مانیتور |
| `Super + Alt + /` | قدم به عقب در گزینه‌های مقیاس‌بندی مانیتور |
| `Alt + Tab` | چرخش رو به جلو در پنجره‌های فضای کاری فعال |
| `Alt + Shift + Tab` | چرخش رو به عقب در پنجره‌های فضای کاری فعال |
| `Ctrl + Alt + Tab`| چرخش تمرکز رو به جلو در مانیتورها |
| `Ctrl + Alt + Shift + Tab`| چرخش تمرکز رو به عقب در مانیتورها |

## کلیپ‌بورد جهانی

| کلید میانبر | عملکرد |
| ----------------------- | --------------------- |
| `Super + C`           | کپی    |
| `Super + X`           | برش (نه در ترمینال)    |
| `Super + V`           | چسباندن    |
| `Super + Ctrl + V`           | مدیر کلیپ‌بورد    |

معمولاً در لینوکس، برای کپی و چسباندن در ترمینال به `Ctrl + Shift + C/V` و در بقیهٔ جاها به `Ctrl + C/V` نیاز دارید. این کلیدهای میانبر یکپارچهٔ کلیپ‌بورد Omarchy در همه جا کار می‌کنند.

## ضبط

| کلید میانبر | عملکرد |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | منوی ضبط (برای صفحه‌کلیدهای بدون دکمهٔ PrintScr) |
| `Print Screen`            | عکس صفحه                      |
| `Alt + Print Screen`            | ضبط صفحه                     |
| `Super + Print Screen` | انتخاب‌گر رنگ |
| `Super + Ctrl + Print Screen` | استخراج متن به کلیپ‌بورد |
| `Super + Alt + [` | پوشش وب‌کم را هنگام ضبط کوچک‌تر کن |
| `Super + Alt + ]` | پوشش وب‌کم را هنگام ضبط بزرگ‌تر کن |
| `Alt + Shift + L` | کپی کردن URL فعلی از وب‌برنامه یا Chromium |
| `Alt + Shift + D` | دانلود ویدیوی صفحهٔ فعلی به `~/Videos` |
| `Super + Ctrl + X` | شروع/توقف دیکته (نیازمند _تنظیمات > پیش‌فرض‌ها > دیکته_) |
| `Right Alt` / `F9` | دیکتهٔ فشار برای صحبت (نیازمند Voxtype یا Superwhisper) |

در ضبط‌های صفحه، کلید میانبر ابتدا می‌پرسد کدام صدا را می‌خواهید، سپس ضبط را شروع می‌کند. دوباره آن را بزنید تا متوقف شود. برای جزئیات به [عکس‌های صفحه و ضبط](12-screenshots-recording.md) مراجعه کنید.

همهٔ گزینه‌های ضبط همچنین زیر _اجرا > ضبط_ در منوی Omarchy (`Super + Space`) در دسترس‌اند.

| ----------------------- | --------------------- |

همهٔ گزینه‌های ظاهر همچنین زیر _ظاهر_ در منوی Omarchy (`Super + Space`) در دسترس‌اند.

## Tmux

کلید پیشوند `Ctrl + Space` است (`Ctrl + B` نیز کار می‌کند). می‌توانید این نگاشت‌ها را در `~/.config/tmux/tmux.conf` تغییر دهید.

### صفحه‌ها

| کلید میانبر | عملکرد |
| ----------------------- | --------------------- |
| `Prefix + v` | تقسیم صفحه در کنار (عمودی) |
| `Prefix + h` | تقسیم صفحه در زیر (افقی) |
| `Prefix + x` | کشتن صفحه |
| `Prefix + z` | روشن/خاموش کردن بزرگ‌نمایی صفحه (تمام‌صفحه) |
| `Alt + Enter` | تقسیم صفحه در زیر (بدون پیشوند) |
| `Alt + Shift + Enter` | تقسیم صفحه در کنار (بدون پیشوند) |
| `Alt + Escape` | کشتن صفحه (no prefix) |
| `Ctrl + Alt + Arrows` | جابه‌جایی بین صفحه‌ها |
| `Ctrl + Alt + Shift + Arrows` | تغییر اندازه صفحه‌ها |

### پنجره‌ها

| کلید میانبر | عملکرد |
| ----------------------- | --------------------- |
| `Prefix + c` | پنجرهٔ جدید |
| `Prefix + k` | کشتن پنجره |
| `Prefix + r` | تغییر نام پنجره |
| `Alt + 1-9` | رفتن به پنجرهٔ مشخص |
| `Alt + Arrow Left/Right` | جابه‌جایی بین پنجره‌ها |
| `Alt + Shift + Arrow Left/Right` | انتقال پنجره به چپ/راست |

### نشست‌ها

| کلید میانبر | عملکرد |
| ----------------------- | --------------------- |
| `Prefix + C` | نشست جدید |
| `Prefix + K` | کشتن نشست |
| `Prefix + R` | تغییر نام نشست |
| `Prefix + N` | نشست بعدی |
| `Prefix + P` | نشست قبلی |
| `Alt + Arrow Up/Down` | جابه‌جایی بین نشست‌ها |
| `Prefix + s` | فهرست نشست‌ها |
| `Prefix + d` | جدا شدن از نشست |

### کپی mode (vi-style)

| کلید میانبر | عملکرد |
| ----------------------- | --------------------- |
| `Prefix + [` | ورود به حالت کپی |
| `v` | شروع انتخاب (در حالت کپی) |
| `y` | کپی selection (in copy mode) |

### عمومی

| کلید میانبر | عملکرد |
| ----------------------- | --------------------- |
| `Prefix + q` | بارگذاری مجدد پیکربندی |
| `Prefix + ?` | نمایش نگاشت‌های کلید Tmux |
| `Prefix + :` | خط فرمان |

### توابع چیدمان Tmux

این توابع باید در داخل یک نشست Tmux اجرا شوند.

| فرمان | عملکرد |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | ایجاد چیدمان توسعه با ویرایشگر، هوش مصنوعی و ترمینال |
| `tdlm <ai> [<second_ai>]` | ایجاد چیدمان توسعه به ازای هر زیرپوشه |
| `tsl <count> <command>` | ایجاد چیدمان انبوه چندصفحه‌ای |

| `?`                        | نمایش راهنما برای همهٔ فرمان‌ها      |

[همهٔ کلیدهای میانبر Neovim پیکربندی‌شده توسط LazyVim را ببینید](https://www.lazyvim.org/keymaps).
