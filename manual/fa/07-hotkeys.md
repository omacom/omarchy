# کلیدهای میانبر

همهٔ اتصال‌های اصلی صفحه‌کلید را می‌توانید با `Super + K` ببینید (اتصال‌های Tmux با `Super + Alt + K` و اتصال‌های Herdr با `Super + Ctrl + K`).

## کلیدهای میانبر چطور چیده شده‌اند

هر کلید میانبر روی یک صفحه قرار می‌گیرد که اصلاح‌گرهایش آن را تعیین می‌کنند، و هر صفحه یک کار دارد. همین است که نمی‌گذارد کلیدهای میانبر با هم قاطی شوند، و یعنی معمولاً می‌توانید حدس بزنید هر چیز کجا زندگی می‌کند.

| صفحه | چه چیزی آنجا زندگی می‌کند | مثال‌ها |
| --- | --- | --- |
| `Super + key` | سیستم: پنجره‌ها، فضاهای کاری، چیدمان‌ها و منوهای اصلی | `Super + Space` منوی Omarchy، `Super + W` بستن پنجره، `Super + F` تمام‌صفحه |
| `Super + Shift + key` | برنامه‌ها | `Super + Shift + B` مرورگر، `Super + Shift + E` ایمیل، `Super + Shift + N` ویرایشگر |
| `Super + Ctrl + key` | پنل‌ها و منوهای سیستم | `Super + Ctrl + A` صدا، `Super + Ctrl + N` شبکه، `Super + Ctrl + C` منوی ضبط |
| `Super + Ctrl + Alt + key` | اقدام‌های سریع و اعلان‌ها | `Super + Ctrl + Alt + T` نمایش زمان، `Super + Ctrl + Alt + B` باتری، `Super + Ctrl + Alt + C` اسکرین‌شات |

افزودن `Alt` به یک کلید میانبر یک گونهٔ دیگر از همان چیز را به شما می‌دهد، هرگز چیزی نامربوط را نه:

- `Super + Shift + B` مرورگر را باز می‌کند؛ `Super + Shift + Alt + B` یک پنجرهٔ خصوصی باز می‌کند
- `Super + Shift + E` ایمیل را باز می‌کند؛ `Super + Shift + Alt + E` یک ایمیل جدید شروع می‌کند
- `Super + F` تمام‌صفحه می‌شود؛ `Super + Alt + F` تمام‌عرض می‌شود
- `Super + Ctrl + C` منوی ضبط را باز می‌کند؛ `Super + Ctrl + Alt + C` منو را رد می‌کند و اسکرین‌شات می‌گیرد

هنگام افزودن یک کلید میانبر:

1. صفحه را از کاری که انجام می‌دهد انتخاب کنید، بعد کلید را انتخاب کنید.
2. یک کلید میانبر موجود را برای باز کردن جا جابه‌جا نکنید. یک کلید آزاد روی صفحهٔ درست پیدا کنید.
3. فقط برای یک گونهٔ دیگر از کلید میانبر بدون آن، از `Alt` استفاده کنید.

چند کلید میانبر این قواعد را می‌شکنند چون راحت‌اند. `Shift` همراه با یک پیکان یا `Tab` به‌جای باز کردن یک برنامه، جابه‌جا می‌کند یا برعکس می‌کند، و `Print`، کلیدهای رسانه، `Alt + Tab` و `Ctrl + Alt + Del` همان‌طور کار می‌کنند که همه‌جای دیگر کار می‌کنند. آن‌ها استثنا هستند، نه الگوهایی برای کپی کردن.

اگر یک پیش‌فرض به کارتان نمی‌آید (مثلاً می‌خواهید `Super + Shift + S` برای اسکرین‌شات‌ها باشد، مثل Windows)، آن را در `~/.config/hypr/bindings.lua` دوباره مقید کنید.

| `Super + /` | رفتن به جلو در گزینه‌های مقیاس‌بندی مانیتور |

| `Super + I` | تغییر زبان ورودی (با بیش از یک چیدمان یا روش ورودی) |
| `Super + Shift + I` | برگرداندن زبان ورودی |

روی تاچ‌پد، کشیدن سه و چهار انگشتی فضاهای کاری را عوض می‌کند، پنجره‌ها را جابه‌جا می‌کند و منو و کنسول Quake را باز می‌کند؛ برای ژست‌ها [صفحه‌کلید، ماوس و ترک‌پد](34-keyboard-mouse-trackpad.md) را ببینید.

تغییر اندازه از دو کلید سمت راست 0 استفاده می‌کند، هرچه صفحه‌کلیدتان روی آن‌ها چاپ کرده باشد: `-` و `=` روی صفحه‌کلیدهای US، `+` و `´` روی دانمارکی و سوئدی، `+` و `\` روی نروژی، `ß` و `´` روی آلمانی، `'` و `¡` روی اسپانیایی، و `-` و `^` روی ژاپنی (JIS). `Super + K` آن‌ها را همان‌طور فهرست می‌کند که صفحه‌کلیدتان چاپ می‌کند. روی JIS، `Super + ^` همان `Super + Equal` است، درحالی‌که `Super + Shift + -` (که `=` را تایپ می‌کند) همان `Super + Shift + Minus` است. مقیاس‌بندی مانیتور و مدیر گذرواژه از `/` استفاده می‌کنند؛ روی چیدمان‌هایی که `/` را فقط با Shift تایپ می‌کنند، مثل بیشتر چیدمان‌های اروپایی، آن‌ها به‌جای آن از کلید سمت چپ Shift راست استفاده می‌کنند (`-` روی دانمارکی و آلمانی).

## ضبط

| کلید میانبر              | کارکرد                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | اسکرین‌شات                      |
| `Super + Ctrl + Alt + C`            | اسکرین‌شات (همان نما، برای صفحه‌کلیدهایی بدون کلید Print Screen) |
| `Super + Ctrl + C` | منوی ضبط |
| `Alt + Print Screen`            | ضبط صفحه                     |
| `Super + Shift + Ctrl + Alt + C` | ضبط صفحه بدون صدا، با رد کردن منو (برای توقف دوباره بزنید) |
| `Super + Print Screen` | انتخابگر رنگ |
| `Super + Ctrl + Print Screen` | استخراج متن به کلیپ‌بورد |
| `Super + Alt + [` | کوچک‌تر کردن لایهٔ وب‌کم هنگام ضبط |
| `Super + Alt + ]` | بزرگ‌تر کردن لایهٔ وب‌کم هنگام ضبط |
| `Alt + Shift + L` | کپی URL فعلی از وب‌اپ یا مرورگر |
| `Alt + Shift + D` | دانلود ویدیوی صفحهٔ فعلی در `~/Videos` |
| `Alt + Space` | شروع/توقف دیکته (نیازمند _Setup > Defaults > Dictation_) |
| `Right Alt` | نگه دارید تا دیکته کنید (نیازمند _Setup > Defaults > Dictation_) |

در ضبط‌های صفحه، کلید میانبر اول می‌پرسد چه صدایی می‌خواهید، بعد ضبط را شروع می‌کند. برای توقف دوباره آن را بزنید. برای جزئیات [اسکرین‌شات‌ها و ضبط](12-screenshots-recording.md) را ببینید.

همهٔ گزینه‌های ضبط همچنین زیر _Trigger > Capture_ در منوی Omarchy (`Super + Space`) در دسترس‌اند.

تصاویر پس‌زمینهٔ اضافی در `~/.config/omarchy/backgrounds/<theme name>` زندگی می‌کنند. همچنین از طریق _Install > Style > Background_ در منوی Omarchy در دسترس‌اند.

همهٔ گزینه‌های سبک همچنین زیر _Appearance_ در منوی Omarchy (`Super + Space`) در دسترس‌اند.

## Tmux

کلید پیشوند `Ctrl + Space` است (`Ctrl + B` هم کار می‌کند). می‌توانید این اتصال‌ها را در `~/.config/tmux/tmux.conf` تغییر دهید.

### پن‌ها

| کلید میانبر                  | کارکرد              |
| ----------------------- | --------------------- |

| `Prefix + h` | تقسیم پن در پایین (افقی) |
| `Prefix + x` | کشتن پن |
