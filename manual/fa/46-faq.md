# پرسش‌های متداول

### چگونه بین چیدمان‌های صفحه‌کلید جابه‌جا شوم؟

فایل `~/.config/hypr/input.lua` خود را ویرایش کنید و این را اضافه کنید تا با `Left Alt + Right Alt` بین چیدمان‌ها جابه‌جا شوید:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

وقتی چند چیدمان پیکربندی کرده باشید، نوار به‌طور خودکار چیدمان فعلی صفحه‌کلید شما را نشان می‌دهد (و می‌توانید برای جابه‌جایی روی آن هم کلیک کنید).

### چگونه قالب ساعت را به ۱۲ ساعته تغییر دهم؟

روی ساعت در نوار راست‌کلیک کنید تا بین قالب‌های رایج، از جمله قالب‌های ۱۲ ساعته، بچرخید. همچنین می‌توانید قالب را مستقیماً تنظیم کنید:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

این یکشنبه 10:55 AM را نمایش می‌دهد.

### چگونه منطقه زمانی خود را تغییر دهم؟

در منوی Omarchy گزینه _Update > Timezone_ را اجرا کنید و از فهرست انتخاب کنید. اگر منطقه زمانی درست است اما خود ساعت عقب یا جلو افتاده است، _Update > Time_ همگام‌سازی زمان را برایتان از نو راه‌اندازی می‌کند.

### چگونه DNS خود را تغییر دهم، Wi-Fi خود را به اشتراک بگذارم، یا سرعت اتصالم را بررسی کنم؟

همه این‌ها در [شبکه](35-networking.md) قرار دارند.

### چگونه بفهمم دیسکم چقدر سریع است؟

_Trigger > Speed Test > Disk Speed Test_ سرعت خواندن و نوشتن زنده روی درایو شما را اندازه می‌گیرد، یا از ترمینال `omarchy disk speedtest` را اجرا کنید.

### چگونه یک چاپگر اضافه کنم؟

چاپ از همان ابتدا تنظیم شده و در حال اجراست، و هر چاپگر را خودتان از _Print Settings_ در اجراکننده برنامه (`Super + Space`) اضافه می‌کنید.

_Add_ را انتخاب کنید و لحظه‌ای فرصت دهید تا جستجو کند: چاپگری که از طریق USB وصل شده باشد، و بیشتر چاپگرهای شبکه، برایتان پیدا می‌شوند. اگر چاپگر شما در فهرست نیست، _Network Printer > Internet Printing Protocol (ipp)_ را انتخاب کنید و نشانی آن را وارد کنید — نمایشگر خود چاپگر یا صفحه وب آن به شما می‌گوید که آن نشانی چیست، معمولاً چیزی مثل `192.168.1.50` با یک صف `ipp/print`. سپس _Forward_ یک درایور پیشنهاد می‌دهد، که در آن یک چاپگر مدرن بهترین عملکرد را با پروفایل بدون درایور _IPP Everywhere_ دارد و یک چاپگر قدیمی‌تر درایور اختصاصی همان مدل را می‌خواهد.

روی یک چاپگر راست‌کلیک کنید و _Set as Default_ را انتخاب کنید تا مشخص کنید برنامه‌هایتان اول سراغ کدام یک بروند، و _Properties_ را برای تنظیم اندازه کاغذ، چاپ دورو و کیفیت انتخاب کنید.

کشف خودکار، که در آن چاپگرهای روی شبکه بدون اضافه شدن ظاهر می‌شوند، در حالی که بازطراحی می‌شود موقتاً خاموش است، و به همین دلیل مرحله اول بالا بر عهده شماست، نه خودکار. چاپ در یک فایل PDF بدون هیچ چاپگری هم کار می‌کند.

### چگونه محل ذخیره اسکرین‌شات‌ها یا ضبط‌های صفحه را تغییر دهم؟

اسکرین‌شات‌های ذخیره‌شده به‌طور پیش‌فرض به `~/Pictures/Screenshots` می‌روند. برای استفاده از یک پوشه دیگر، این را به فایلی در `~/.config/uwsm/env.d/` (مثل `~/.config/uwsm/env.d/capture`) اضافه کنید:

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

همین کار را می‌توانید برای ضبط‌های صفحه با استفاده از `OMARCHY_SCREENRECORD_DIR` انجام دهید.

Omasnap پوشه اسکرین‌شات خود را به‌طور خودکار ایجاد می‌کند. پوشه ضبط صفحه را خودتان ایجاد کنید، سپس Omarchy را دوباره راه‌اندازی کنید تا هر یک از تغییرات محیطی اعمال شود.

### چگونه بلندگوها + وب‌کم روی Apple Studio Display خود را به کار بیندازم؟

فکر می‌کنید همه‌چیز باید فقط با وصل کردن USB C کار کند، اما متأسفانه این‌طور نیست. راه‌حلی که پیدا کرده‌ام تا به‌طور قابل اعتماد کار کند استفاده از [کابل WJESOG DisplayPort + USB-A => USB-C](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) است. آن وقت بلندگوها و وب‌کم بدون هیچ دردسری کار می‌کنند.

یادتان باشد که در Omarchy برای Apple Displayها (هم Studio و هم XDR) با استفاده از دکمه‌های معمول روشنایی صفحه‌کلید، کنترل داخلی روشنایی دارید.

### چگونه از شر همه نرم‌افزارهای اضافی خلاص شوم؟

اگر برنامه‌هایی مانند Obsidian یا LibreOffice یا هر یک از چیزهای ازپیش‌نصب‌شده دیگر را نمی‌خواهید، خیلی راحت می‌توانید آن‌ها را حذف کنید.

_Remove > Package_ را اجرا کنید تا هر بسته‌ای را که نصب شده است ببینید. سپس می‌توانید هر بسته‌ای را که می‌خواهید حذف کنید با tab انتخاب کنید، و حذف همه چیزهایی را که انتخاب کرده‌اید با return شروع کنید.

و می‌توانید از _Remove > Web App_ در منوی Omarchy برای حذف هر یک از وب‌اپ‌های ازپیش‌نصب‌شده‌ای که نمی‌خواهید استفاده کنید.

یا _Remove > Preinstalls_ را اجرا کنید تا همه موارد اضافی ازپیش‌نصب‌شده — وب‌اپ‌ها، TUIها و برنامه‌های اختیاری — را یک‌جا پاک کنید. کلیدهای میانبری که آن‌ها را اجرا می‌کردند هم همراهشان از بین می‌روند، پس یک فهرست پاک از کلیدهای میانبر برایتان باقی می‌ماند تا آن را با کلیدهای میانبر خودتان در `~/.config/hypr/bindings.lua` پر کنید.
