# پرسش‌های متداول

### چطور بین چیدمان‌های صفحه‌کلید جابه‌جا شوم؟

فایل `~/.config/hypr/input.lua` خود را ویرایش کنید و این را اضافه کنید تا با `Left Alt + Right Alt` بین چیدمان‌ها جابه‌جا شوید:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

وقتی چند چیدمان پیکربندی کرده باشید، نوار به‌طور خودکار چیدمان فعلی صفحه‌کلید شما را نشان می‌دهد (و می‌توانید برای جابه‌جا شدن روی آن هم کلیک کنید).

### چطور قالب ساعت را به ۱۲ ساعته تغییر دهم؟

روی ساعت در نوار راست‌کلیک کنید تا بین قالب‌های رایج، از جمله قالب‌های ۱۲ ساعته، بچرخید. می‌توانید قالب را مستقیم هم تنظیم کنید:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

این، یکشنبه 10:55 AM را نمایش می‌دهد.

### چطور منطقه زمانی‌ام را تغییر دهم؟

در منوی Omarchy مسیر _Setup > Region > Timezone_ را اجرا کنید و از فهرست انتخاب کنید. اگر منطقه زمانی درست است اما خود ساعت عقب یا جلو افتاده است، _Update > Time_ همگام‌سازی زمان را برایتان از نو راه می‌اندازد.

### چطور DNS خودم را تغییر دهم، Wi-Fi خودم را به اشتراک بگذارم، یا سرعت اتصالم را بررسی کنم؟

همه این‌ها در [شبکه](35-networking.md) هستند.

### چطور بفهمم دیسکم چقدر سریع است؟

_Trigger > Speed Test > Disk Speed Test_ سرعت زنده خواندن و نوشتن روی درایو شما را اندازه می‌گیرد، یا از ترمینال `omarchy disk speedtest` را اجرا کنید.

### چطور یک چاپگر اضافه کنم؟

چاپ از همان اول راه‌اندازی شده و در حال اجراست، و هر چاپگر را خودتان از _Print Settings_ در اجراکننده برنامه (`Super + Alt + Space`) اضافه می‌کنید.

_Add_ را انتخاب کنید و کمی به آن فرصت بدهید تا بگردد: چاپگری که با USB وصل شده باشد، و بیشتر چاپگرهای شبکه، برایتان پیدا می‌شوند. اگر چاپگر شما در فهرست نیست، _Network Printer > Internet Printing Protocol (ipp)_ را انتخاب کنید و نشانی‌اش را وارد کنید — نمایشگر خود چاپگر یا صفحه وب آن به شما می‌گوید آن نشانی چیست، معمولاً چیزی مثل `192.168.1.50` با یک صف `ipp/print`. بعد _Forward_ یک درایور پیشنهاد می‌دهد، که در آن یک چاپگر مدرن با پروفایل بدون درایور _IPP Everywhere_ بهترین کارکرد را دارد و یک چاپگر قدیمی‌تر درایور اختصاصی مدل خودش را می‌خواهد.

روی یک چاپگر راست‌کلیک کنید و _Set as Default_ را انتخاب کنید تا مشخص کنید برنامه‌هایتان اول سراغ کدام‌یک بروند، و _Properties_ را برای تنظیم اندازه کاغذ، چاپ دورو و کیفیت انتخاب کنید.

کشف خودکار، که در آن چاپگرهای روی شبکه بدون اضافه شدن ظاهر می‌شوند، در حالی که دارد بازطراحی می‌شود موقتاً خاموش است، و به همین دلیل است که قدم اول بالا با شماست، نه خودکار. چاپ کردن در یک فایل PDF بدون هیچ چاپگری هم کار می‌کند.

### چطور جای ذخیره شدن اسکرین‌شات‌ها یا ضبط‌های صفحه را تغییر دهم؟

اسکرین‌شات‌های ذخیره‌شده به‌طور پیش‌فرض به `~/Pictures/Screenshots` می‌روند. برای استفاده از یک پوشه دیگر، این را به فایلی زیر `~/.config/uwsm/env.d/` (مثل `~/.config/uwsm/env.d/capture`) اضافه کنید:

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

همین کار را برای ضبط‌های صفحه هم می‌توانید با استفاده از `OMARCHY_SCREENRECORD_DIR` انجام دهید.

Omasnap پوشه اسکرین‌شات خودش را به‌طور خودکار می‌سازد. پوشه ضبط صفحه را خودتان بسازید، و بعد برای اعمال هر کدام از این تغییرات محیطی، Omarchy را از نو راه بیندازید.

### چطور بلندگوها + وب‌کم را روی Apple Studio Display خودم به کار بیندازم؟

آدم فکر می‌کند فقط با وصل کردن USB C همه‌چیز باید کار کند، اما متأسفانه این‌طور نیست. راه‌حلی که من پیدا کرده‌ام تا به‌طور قابل‌اعتماد کار کند، استفاده از [کابل WJESOG DisplayPort + USB-A => USB-C](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) است. آن‌وقت بلندگوها و وب‌کم مثل ساعت کار می‌کنند.

یادتان باشد که در Omarchy برای نمایشگرهای Apple (هم Studio و هم XDR) کنترل روشنایی داخلی دارید و با همان دکمه‌های معمول روشنایی صفحه‌کلید کار می‌کند.

### چطور از شر همه نرم‌افزارهای اضافی خلاص شوم؟

اگر برنامه‌هایی مثل Obsidian یا LibreOffice یا هر کدام از چیزهای از پیش نصب‌شده دیگر را نمی‌خواهید، خیلی راحت می‌توانید حذفشان کنید.

_Remove > Package_ را اجرا کنید تا هر بسته‌ای را که نصب شده است ببینید. بعد می‌توانید هر بسته‌ای را که می‌خواهید حذف کنید با tab انتخاب کنید، و با return حذف کردن همه چیزهایی را که انتخاب کرده‌اید شروع کنید.

و می‌توانید از _Remove > Web App_ در منوی Omarchy برای حذف هر کدام از وب‌اپ‌های از پیش نصب‌شده‌ای که نمی‌خواهید استفاده کنید.

یا _Remove > Preinstalls_ را اجرا کنید تا همه extras از پیش نصب‌شده — وب‌اپ‌ها، TUIها، و برنامه‌های اختیاری — را یک‌جا جارو کنید. کلیدهای میان‌بری که آن‌ها را اجرا می‌کردند هم همراهشان می‌روند، پس یک لوح پاک از اتصال‌های کلیدی برایتان می‌ماند که با اتصال‌های خودتان در `~/.config/hypr/bindings.lua` پرش کنید.
