# کلیپ‌بورد یکپارچه و تاریخچه

معمولاً در Linux، برای کپی‌وپیست در ترمینال به `Ctrl + Shift + C/V` و برای انجام این کار در هر جای دیگر به `Ctrl + C/V` نیاز دارید. عادت کردن به این برای هر کسی که روی Linux زاده و بزرگ نشده، سخت است! اگر از Mac می‌آیید، تغییر از super به ctrl هم همین‌طور است.

Omarchy هر دو مشکل را با کلیدهای میانبر یکپارچه کلیپ‌بورد که (تقریباً) همه‌جا کار می‌کنند حل می‌کند. این‌ها هستند:

| کلید میانبر | فرمان |
| ------- | ----------- |
| Super + A | انتخاب همه |
| Super + C | کپی |
| Super + X | برش |
| Super + V | چسباندن |
| Super + Ctrl + V | تاریخچه کلیپ‌بورد |

_توجه داشته باشید که بیشتر harnessهای agent از `Ctrl + V` برای چسباندن تصاویر، اما از `Super + V` برای چسباندن متن استفاده می‌کنند._

از `Super + A` و سپس `Super + C` استفاده کنید تا همه‌چیز را در یک فیلد متنی در تمرکز یا برنامه دیگری که از `Ctrl + A` پشتیبانی می‌کند کپی کنید. در ترمینال، `Ctrl + A` به جای انتخاب متن دستور، به ابتدای خط فرمان می‌رود.

### تاریخچه کلیپ‌بورد

تاریخچه کلیپ‌بورد توسط پوسته Omarchy ارائه می‌شود و هم برای متن و هم برای تصاویر کار می‌کند. آن را با `Super + Ctrl + V` فعال می‌کنید و ورودی‌تان را با return انتخاب می‌کنید، که آن را مستقیماً در برنامه‌ای که در آن بودید می‌چسباند. از `Shift + Return` استفاده کنید تا فقط آن را در کلیپ‌بورد کپی کنید، از `Alt + Return` برای باز کردن آن، از `Delete` برای حذف آن از تاریخچه و از `Shift + Delete` برای پاک کردن کل تاریخچه استفاده کنید.
