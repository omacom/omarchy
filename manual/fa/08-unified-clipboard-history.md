# کلیپ‌بورد یکپارچه و سابقه

معمولاً در لینوکس، برای کپی و چسباندن در ترمینال به `Ctrl + Shift + C/V` و در بقیهٔ جاها به `Ctrl + C/V` نیاز دارید. عادت کردن به آن برای هر کسی که در لینوکس زاده و پرورش نیافته باشد دشوار است! تغییر از super به ctrl هم همین‌طور، اگر از Mac آمده باشید.

Omarchy هر دو مشکل را با کلیدهای میانبر یکپارچهٔ کلیپ‌بورد که (تقریباً) در همه جا کار می‌کنند حل می‌کند. آن‌ها عبارت‌اند از:

| کلید میانبر | فرمان |
| ------- | ----------- |
| Super + C | کپی |
| Super + X | برش |
| Super + V | چسباندن |
| Super + Ctrl + V | تاریخچه کلیپ‌بورد |

_توجه داشته باشید که اکثر ابزارهای عامل برای چسباندن تصاویر از `Ctrl + V` و برای چسباندن متن از `Super + V` استفاده خواهند کرد._

### تاریخچه کلیپ‌بورد

تاریخچه کلیپ‌بورد توسط پوستهٔ Omarchy ارائه می‌شود و هم برای متن و هم برای تصاویر کار می‌کند. آن را با `Super + Ctrl + V` فعال می‌کنید، ورودی‌تان را با return انتخاب می‌کنید و سپس آن روی کلیپ‌بورد قرار می‌گیرد و آمادهٔ چسباندن با `Super + V` خواهد بود.
