# بسته‌های دیگر

Arch ثروت شگفت‌انگیزی از بسته‌ها برای تقریباً هر نوع نرم‌افزاری بین مخزن رسمی و Arch User Repository (AUR) در دسترس دارد.

استفاده از آن هم نمی‌تواند آسان‌تر باشد. یک بسته Arch جدید را با رفتن به _نصب > Package_ در منوی Omarchy (`Super + Space`) و تایپ بسته‌ای که می‌خواهید نصب می‌کنید. به‌طور خودکار فهرست همه بسته‌ها را به‌صورت فازی فیلتر می‌کند. (همچنین می‌توانید آن را دستی با استفاده از `omarchy pkg add [package]` در ترمینال انجام دهید).

می‌توانید همین کار را با AUR انجام دهید، فقط از _نصب > AUR_ استفاده کنید. فقط به خاطر داشته باشید که AUR توسط تیم Arch بررسی نمی‌شود. مانند RubyGems یا npm است. هر کسی می‌تواند آپلود کند.

اگر می‌خواهید یک بسته را حذف کنید، می‌توانید از _حذف > Package_ از منوی Omarchy استفاده کنید. بسته، فایل‌های پیکربندی و وابستگی‌ها را حذف می‌کند. (همچنین می‌توانید آن را دستی با استفاده از `omarchy pkg drop [package]` انجام دهید).
