# تغییرات رایج

این مجموعه‌ای از دست‌کاری‌های رایج برای شخصی‌سازی تنظیمات Omarchy است. بدان که شاید گاهی لازم شود به‌روزرسانی‌های سیستم بعضی پیکربندی‌ها را به حالت اولیه‌شان برگردانند. اگر این اتفاق بیفتد، تغییراتت از دست نمی‌روند، بلکه در یک فایل `.bak.<timestamp>` در کنار فایل اصلی قرار می‌گیرند.

اگر خراب‌کاری کردی، می‌توانی از طریق _Update > Config_ در منوی Omarchy، پیکربندی‌های تکی را به تنظیمات اولیه‌شان برگردانی. اگر _واقعاً_ همه‌چیز را به هم ریختی، می‌توانی با `omarchy reinstall configs` همه پیکربندی‌ها را بازنشانی کنی، یا با `omarchy reinstall` همه بسته‌ها و پیکربندی‌های پیش‌فرض را دوباره نصب کنی.

### نمایش همیشگی همه آیکن‌های سینی سیستم

به‌طور پیش‌فرض، آیکن‌های سینی سیستم، مثل Dropbox، 1password یا Steam، پشت پیکان گسترش‌دهنده سینی پنهان هستند و وقتی نشانگر را روی آن می‌بری، آشکار می‌شوند. اگر دوست داری همیشه در معرض دید باشند، روی پیکان گسترش‌دهنده راست‌کلیک کن تا مدیر آیکن‌های سینی باز شود، سپس آیکن‌هایی را که می‌خواهی همیشه قابل مشاهده نگه داری پین کن (می‌توانی آن‌هایی را هم که هرگز نمی‌خواهی ببینی پنهان کنی).

### گوشه‌های گرد پنجره

طراحی پیش‌فرض Omarchy گوشه‌های مربعی دارد، اما اگر دوست داری کمی آن را نرم‌تر کنی، در منوی Omarchy گزینه _Appearance > Windows > Window Corners > Rounded Corners_ را انتخاب کن، یا `omarchy hyprland corners rounded` را اجرا کن. _Theme Corners_ به هر چیزی که تم استفاده می‌کند برمی‌گردد. برای انتخاب شعاع دلخواه خودت، روی _Theme Corners_ بمان (`omarchy hyprland corners theme`)، چون Rounded و Sharp بعد از پیکربندی تو بارگذاری می‌شوند و آن را بازنویسی می‌کنند، و در `~/.config/hypr/looknfeel.lua` بخش rounding را از حالت کامنت خارج کن:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### حذف فاصله‌های پنجره

روی نمایشگرهای لپ‌تاپ، بعضی‌ها ترجیح می‌دهند هیچ پیکسلی را برای فاصله‌های پنجره هدر ندهند (یا حتی برای نوار بالایی، که می‌توانی با `Super + Shift + Space` خاموش و روشنش کنی). می‌توانی با `Super + Shift + Backspace` همه فاصله‌ها و حاشیه‌ها را خاموش و روشن کنی، یا با خارج کردن این بخش از `~/.config/hypr/looknfeel.lua` از حالت کامنت، آن‌ها را به‌طور دائمی حذف کنی:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
