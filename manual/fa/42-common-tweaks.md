# تغییرات رایج

این مجموعه‌ای از سفارشی‌سازی‌های رایج برای تنظیم Omarchy است. بدانید که گاهی ممکن است لازم باشد به‌روزرسانی‌های سیستم پیکربندی‌های خاصی را به وضعیت اصلی‌شان برگردانند. اگر این اتفاق بیفتد، تغییرات شما از بین نمی‌روند، بلکه در یک فایل `.bak` در همان دایرکتوری قرار می‌گیرند.

اگر چیزی را خراب کردید، می‌توانید پیکربندی‌های منفرد را از طریق _به‌روزرسانی > پیکربندی_ در منوی Omarchy به تنظیم اصلی‌شان برگردانید. اگر _واقعاً_ همه چیز را خراب کردید، می‌توانید همه پیکربندی‌ها را از طریق `omarchy-reinstall` بازنشانی کنید.

### آشکار کردن همه آیکون‌های سینی در همه اوقات

به طور پیش‌فرض، آیکون‌های سینی، مثل Dropbox و 1password یا Steam، پشت فلش بازکننده سینی پنهان هستند که وقتی رویش نگه دارید آن‌ها را آشکار می‌کند. اگر دوست دارید همیشه در معرض دید باشند، روی فلش بازکننده راست‌کلیک کنید تا مدیر آیکون سینی باز شود، بعد آیکون‌هایی را که می‌خواهید همیشه قابل مشاهده نگه دارید پین کنید (همچنین می‌توانید آن‌هایی را که هرگز نمی‌خواهید ببینید پنهان کنید).

### گوشه‌های گرد پنجره

طراحی پیش‌فرض Omarchy گوشه‌های مربعی است، اما اگر دوست دارید آن را کمی نرم کنید، می‌توانید `~/.config/hypr/looknfeel.lua` را تغییر دهید تا گرد کردن دیگر کامنت‌شده نباشد:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### حذف فاصله‌های پنجره

روی نمایشگرهای لپ‌تاپ، بعضی افراد ترجیح می‌دهند هیچ پیکسلی را روی فاصله‌های پنجره هدر ندهند (یا حتی یک نوار بالا، که می‌توانید با `Super + Shift + Space` خاموشش کنید). می‌توانید همه فاصله‌ها و حاشیه‌ها را با `Super + Shift + Backspace` تغییر وضعیت دهید، یا با حذف کامنت‌ها در این بخش از `~/.config/hypr/looknfeel.lua` آن‌ها را به طور دائمی حذف کنید:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
