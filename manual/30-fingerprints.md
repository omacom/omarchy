# Fingerprints

Open **Setup → Security → Fingerprints** to add, verify, or remove a fingerprint. Choose the reader, hand, and finger. Touch ID shows its three-fingerprint limit; other supported readers use the same interface.

Use **Setup → Security → Enable Fingerprint Authentication** to install the appropriate driver and enable sign-in after successful verification. Keep password access.

**Remove → Security → Disable Fingerprint Authentication** disables fingerprint sign-in without deleting enrolled fingers or removing drivers. Delete individual fingerprints in the manager.
