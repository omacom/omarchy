# Mga Hotkey

Makikita mo ang lahat ng pangunahing binding ng keyboard gamit ang `Super + K` (mga binding ng Tmux gamit ang `Super + Alt + K` at mga binding ng Herdr gamit ang `Super + Ctrl + K`).

## Pag-navigate

| Hotkey                  | Tungkulin              |
| ----------------------- | --------------------- |
| `Super + Space`           | Menu ng Omarchy (mga app at lahat ng iba pa)    |
| `Super + Alt + Space` | Grid ng mga app |
| `Super + Escape` | Menu ng sistema (suspend, restart, atbp.)  |
| `Super + Ctrl + L` | I-lock ang computer |
| `Super + W` o `Super + Q` | Isara ang bintana             |

| `Super + T`               | I-toggle ang bintana sa pagitan ng tiling/lumulutang             |
| `Super + J` | I-toggle ang posisyon ng bintana (pahalang/patayo) |
| `Super + O`               | I-toggle ang pag-pop ng bintana papunta sa sticky'n'floating |
| `Super + L`               | Umikot sa mga layout na dwindle, scrolling, at lumulutang |
| `Super + Alt + L`         | Umikot sa mga layout nang pabaligtad |
| `Super + P`               | I-toggle ang istilo ng pseudo window (natural laban sa stretch) |

| `Super + Alt + F`                 | Mag-full width              |
| `Super + Ctrl + F`                 | Mag-full screen sa loob ng bintana              |

| `Super + Tab` | Tumalon papunta sa susunod na workspace |

| `Super + S` / `Super + Grave` | I-toggle ang scratchpad |

| `Super + Scroll Wheel` | Mag-scroll sa mga workspace |

| `Super + Alt + G`               | Ilipat ang bintana palabas ng pagpapangkat      |

| `Super + Alt + Arrow`  | Ilipat ang bintana papasok sa pagpapangkat sa direksyon ng arrow  |
| `Super + Ctrl + Left/Right`  | Lumipat sa pagitan ng mga bintana sa loob ng isang tiling group |
| `Super + Ctrl + Z` | Mag-zoom in sa screen (ulitin para sa mas maraming zoom) |
| `Super + Ctrl + Alt + Z` | Mag-zoom out nang buo mula sa screen |
| `Super + /` | Humakbang pasulong sa mga opsyon ng scaling ng monitor |
| `Super + Alt + /` | Humakbang pabalik sa mga opsyon ng scaling ng monitor |
| `Alt + Tab` | Umikot pasulong sa mga bintana sa aktibong workspace |
| `Alt + Shift + Tab` | Umikot pabalik sa mga bintana sa aktibong workspace |

## Pangkalahatang clipboard

| Hotkey                  | Tungkulin              |
| ----------------------- | --------------------- |
| `Super + C`           | Kopyahin    |
| `Super + X`           | I-cut (hindi sa terminal)    |
| `Super + V`           | I-paste    |
| `Super + Ctrl + V`           | Tagapamahala ng clipboard    |

Karaniwan sa Linux, kailangan mo ng `Ctrl + Shift + C/V` para mag-copy'n'paste sa terminal at `Ctrl + C/V` para gawin ito sa lahat ng iba pang lugar. Gumagana kahit saan ang mga pinag-isang clipboard hotkey ng Omarchy na ito.

## Kuha

| Hotkey              | Tungkulin                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Menu ng kuha (para sa mga keyboard na walang PrintScr button) |
| `Print Screen`            | Screenshot                      |
| `Alt + Print Screen`            | Pag-record ng screen                     |
| `Super + Print Screen` | Tagapili ng kulay |
| `Super + Ctrl + Print Screen` | Pagkuha ng teksto papunta sa clipboard |
| `Super + Alt + [` | Paliitin ang overlay ng webcam habang nagre-record |
| `Super + Alt + ]` | Palakihin ang overlay ng webcam habang nagre-record |
| `Alt + Shift + L` | Kopyahin ang kasalukuyang URL mula sa webapp o Chromium |
| `Alt + Shift + D` | I-download ang video sa kasalukuyang pahina papunta sa `~/Videos` |
| `Super + Ctrl + X` | Simulan/itigil ang diktasyon (nangangailangan ng _Pag-setup > Mga Default > Diktasyon_) |
| `Right Alt` / `F9` | Push-to-talk na diktasyon (nangangailangan ng Voxtype o Superwhisper) |

Sa mga pag-record ng screen, itatanong muna ng hotkey kung anong audio ang gusto mo, pagkatapos ay sisimulan ang pag-record. Pindutin ito ulit para itigil. Tingnan ang [mga screenshot at pag-record](12-screenshots-recording.md) para sa mga detalye.

Lahat ng opsyon sa kuha ay maa-access din sa ilalim ng _Mag-trigger > Kuha_ sa menu ng Omarchy (`Super + Space`).

## Tmux

Ang prefix key ay `Ctrl + Space` (gumagana rin ang `Ctrl + B`). Maaari mong baguhin ang mga binding na ito sa `~/.config/tmux/tmux.conf`.

### Mga Pane

| Hotkey                  | Tungkulin              |
| ----------------------- | --------------------- |
| `Prefix + v` | Hatiin ang pane sa tabi (patayo) |
| `Prefix + h` | Hatiin ang pane sa ibaba (pahalang) |
| `Prefix + x` | Patayin ang pane |
| `Prefix + z` | I-toggle ang zoom ng pane (fullscreen) |
| `Alt + Enter` | Hatiin ang pane sa ibaba (walang prefix) |
| `Alt + Shift + Enter` | Hatiin ang pane sa tabi (walang prefix) |
| `Alt + Escape` | Patayin ang pane (walang prefix) |
| `Ctrl + Alt + Arrows` | Lumipat sa pagitan ng mga pane |
| `Ctrl + Alt + Shift + Arrows` | I-resize ang mga pane |

### Mga Bintana

| Hotkey                  | Tungkulin              |
| ----------------------- | --------------------- |
| `Prefix + c` | Bagong bintana |
| `Prefix + k` | Patayin ang bintana |
| `Prefix + r` | Palitan ang pangalan ng bintana |
| `Alt + 1-9` | Pumunta sa partikular na bintana |
| `Alt + Arrow Left/Right` | Lumipat sa pagitan ng mga bintana |
| `Alt + Shift + Arrow Left/Right` | Ilipat ang bintana pa-kaliwa/pa-kanan |

### Mga Session

| Hotkey                  | Tungkulin              |
| ----------------------- | --------------------- |
| `Prefix + C` | Bagong session |
| `Prefix + K` | Patayin ang session |
| `Prefix + R` | Palitan ang pangalan ng session |
| `Prefix + N` | Susunod na session |
| `Prefix + P` | Nakaraang session |
| `Alt + Arrow Up/Down` | Lumipat sa pagitan ng mga session |
| `Prefix + s` | Ilista ang mga session |
| `Prefix + d` | Kumalas mula sa session |

### Copy mode (istilong vi)

| Hotkey                  | Tungkulin              |
| ----------------------- | --------------------- |
| `Prefix + [` | Pumasok sa copy mode |
| `v` | Simulan ang pagpili (sa copy mode) |
| `y` | Kopyahin ang pinili (sa copy mode) |

### Pangkalahatan

| Hotkey                  | Tungkulin              |
| ----------------------- | --------------------- |
| `Prefix + q` | I-reload ang config |
| `Prefix + ?` | Ipakita ang mga keybinding ng Tmux |
| `Prefix + :` | Command prompt |

### Mga function ng layout ng Tmux

Ang mga function na ito ay kailangang patakbuhin sa loob ng isang session ng Tmux.

| Command | Tungkulin |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Gumawa ng dev layout na may editor, AI, at terminal |
| `tdlm <ai> [<second_ai>]` | Gumawa ng dev layout bawat subdirectory |
| `tsl <count> <command>` | Gumawa ng multi-pane swarm layout |
