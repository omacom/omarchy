# Pagpuno ng mga PDF

May kasamang mahusay at basic na PDF viewer ang Omarchy na tinatawag na Document Viewer. Ito ang program na magbubukas ng anumang PDF na i-double-click mo lang.

Pero maaari mo lang gamitin ang Document Viewer para punan ang mga PDF na na-setup bilang mga form. Kung kailangan mong punan ang mga PDF na hindi pa, o kailangan mong pirmahan ang isang PDF, gamitin ang [Signed](https://github.com/omacom/signed). Simulan ito sa pamamagitan ng application launcher (`Super + Space`), o i-right-click ang file, piliin ang _Open With..._, at piliin ang Signed.

Pindutin ang `T` para mag-type ng teksto at ang `D` para ilagay ang petsa ngayon. Parehong dumadating kung saan naroon ang mouse pointer mo. I-drag ang anumang bagay para ilipat ito, i-drag ang sulok nito para palakihin o paliitin ito, at i-double-click ang teksto para baguhin ito.

Para pumirma, kakailanganin mo ng larawan ng iyong lagda: isang scan, o isang mahusay na naiilawan na larawan nito sa puting papel. Buksan ang _Signature_ menu (`Shift + S`), piliin ang _Add signature..._, piliin ang larawan, at bigyan ito ng pangalan. Tinatanggal ng Signed ang papel at pinapanatili ang tinta. Mula noon, inilalagay ng `S` ang iyong lagda sa ilalim ng mouse pointer.

Kapag tapos ka na, gamitin ang _Save signed copy..._ (`Ctrl + S`) para i-save ang napunang PDF sa tabi ng orihinal, na hindi kailanman nababago. Pindutin ang `?` sa loob ng Signed para makita ang bawat shortcut.
