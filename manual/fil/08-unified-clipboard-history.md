# Pinag-isang Clipboard at Kasaysayan

Karaniwan sa Linux, kailangan mo ng `Ctrl + Shift + C/V` para mag-copy'n'paste sa terminal at `Ctrl + C/V` para gawin ito sa lahat ng iba pang lugar. Mahirap masanay dito para sa sinumang hindi ipinanganak at lumaki sa Linux! Ganoon din ang paglipat mula super papuntang ctrl, kung galing ka sa Mac.

Tinutugunan ng Omarchy ang dalawang problemang ito gamit ang pinag-isang mga clipboard hotkey na gumagana (halos) kahit saan. Ito ay ang mga sumusunod:

| Hotkey | Utos |
| ------- | ----------- |
| Super + A | Piliin ang lahat |
| Super + C | Kopyahin |
| Super + X | Gupitin |
| Super + V | I-paste |
| Super + Ctrl + V | Kasaysayan ng clipboard |

_Tandaan na karamihan sa mga agent harness ay gagamit ng `Ctrl + V` para sa pag-paste ng mga larawan, ngunit `Super + V` para sa pag-paste ng teksto._

Gamitin ang `Super + A`, pagkatapos ay `Super + C` para kopyahin ang lahat sa isang nakatuong text field o iba pang app na sumusuporta sa `Ctrl + A`. Sa terminal, lumilipat ang `Ctrl + A` sa simula ng command line sa halip na piliin ang teksto nito.

### Kasaysayan ng clipboard

Ibinibigay ng Omarchy shell ang kasaysayan ng clipboard at gumagana ito para sa teksto at mga larawan. Bubuksan mo ito gamit ang `Super + Ctrl + V` at pipiliin mo ang entry mo gamit ang return, na direktang magpe-paste nito sa app na ginagamit mo noon. Gamitin ang `Shift + Return` para kopyahin lang ito sa clipboard, `Alt + Return` para buksan ito, `Delete` para alisin ito sa kasaysayan, at `Shift + Delete` para i-clear ang buong kasaysayan.
