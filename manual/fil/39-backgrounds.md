# Mga Background

May sariling set ng mga background ang bawat tema, at maaari kang magdagdag ng sarili mo sa `~/.config/omarchy/backgrounds/[theme]`. Kung gusto mong magdagdag ng karagdagang background image sa, halimbawa, nord theme, ilagay mo lang ang file sa `~/.config/omarchy/backgrounds/nord`.

Pinakamadali itong gawin sa pagpunta sa _Install > Style > Background_ sa Omarchy Menu. Bubuksan nito ang folder kung saan nakaimbak ang mga background para sa temang iyon. Pindutin ang `Super + Shift + F` para magbukas ng isa pang file manager, hanapin ang background mo, at kopyahin ito roon.  Kasama na ito ngayon sa mga pagpipiliang background na mapipili mo gamit ang `Super + Ctrl + W`.

Maaari ring maging video ang mga background, hindi lang mga still. Maglagay ng `mp4`, `m4v`, `mov`, `webm`, `mkv`, o `avi` file sa parehong folder at lalabas ito kasama ng mga larawan. Pinapatugtog ang mga video ng OWE wallpaper engine. Dinidecode nito ang video nang isang beses para sa lahat ng monitor at pinapatugtog ang tunog nito sa default na audio output, at humihinto ito sa pag-play tuwing walang nakakakita rito. Mas malaki pa rin ang kain sa kuryente ng video wallpaper kaysa sa still.

Maaaring magsama ang mga tema ng maikling intro para sa isang still na background. Para sa `backgrounds/road.webp`, ang katugmang video ay nasa `backgrounds/intros/road.mp4`. Awtomatiko itong tumutugtog sa boot, kapag lumilipat sa isang tema na napili ang background na iyon, at kapag pinipili ang background na iyon, pagkatapos ay babalik sa still. Hindi lumalabas ang mga intro video sa background picker at hindi kailanman naglu-loop.

Ang pag-off sa _Appearance > Animations_ ay nag-o-off din sa mga background intro. Ginagawa ito ng Omarchy bilang default sa isang virtual machine. Maaaring i-toggle nang hiwalay ng `omarchy theme bg intro toggle` command ang mga intro. Hindi nagpapatugtog ng intro ang pag-refresh ng isang tema.

Ang isang still ay maaari ring magkaroon ng loop, isang tahimik na bersyon ng parehong larawan na patuloy na gumagalaw, sa `backgrounds/loops/road.mp4`. Tumutugtog ito kapalit ng still, pagkatapos ng intro nito kung mayroon, at humihinto kapag naka-off ang mga animation. Sa baterya, ang still ang lumalabas sa halip, at bumabalik ang loop kapag nakasaksak ka na. Hindi lumalabas ang mga loop sa background picker.

May makikita kang napakalaking koleksyon ng cool na curated na mga background sa [dharmx/walls](https://github.com/dharmx/walls).

Ipinapakita ng lock screen ang isang still frame ng isang video background, sa parehong paraan kung paano nito ipinapakita ang isang still frame ng isang animated na GIF.
