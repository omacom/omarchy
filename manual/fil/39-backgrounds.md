# Mga Background

Bawat tema ay may kasama nang sariling set ng mga background, at makakapagdagdag ka ng sarili mong mga extra sa `~/.config/omarchy/backgrounds/[theme]`. Kung gusto mong magdagdag ng extra na larawang background sa, halimbawa, nord na tema, ilagay mo lang ang file sa `~/.config/omarchy/backgrounds/nord`.

Pinakamadali itong gawin sa pamamagitan ng pagpunta sa _I-install > Estilo > Background_ sa Omarchy Menu. Bubuksan nito ang folder kung saan nakaimbak ang mga background para sa temang iyon. Pindutin ang `Super + Shift + F` para magbukas ng isa pang file manager, hanapin ang background mo, at kopyahin ito papunta roon. Ngayon, kasama na ito sa mga pagpipiliang background na mapipili mo gamit ang `Super + Ctrl + W`.

Maaari ding maging mga video ang mga background bukod sa mga still. Maglagay ng `mp4`, `m4v`, `mov`, `webm`, `mkv`, o `avi` na file sa parehong folder at lalabas ito kasama ng mga larawan. Pinapatugtog ang mga video ng OWE wallpaper engine. Dine-decode nito ang video nang isang beses para sa lahat ng monitor at pinapatugtog ang tunog nito sa pamamagitan ng default na audio output, at humihinto ito sa pag-play tuwing walang nakakakita rito. Mas malaki pa rin nang malaki ang konsumo sa kuryente ng isang video wallpaper kaysa sa isang still.

Maaaring magsama ang mga tema ng maikling intro para sa isang still na background. Para sa `backgrounds/road.webp`, ang katugmang video ay nasa `backgrounds/intros/road.mp4`. Awtomatiko itong nagpe-play sa pag-boot, kapag lumilipat sa isang temang nakapili ang background na iyon, at kapag pinipili ang background na iyon, pagkatapos ay babalik ito sa still. Hindi lumalabas ang mga intro video sa tagapili ng background at hindi kailanman naglu-loop ang mga ito.

Ang pagpili sa _Hitsura > I-off ang Mga Animation_ ay nag-o-off din sa mga intro ng background. Ginagawa ito ng Omarchy bilang default sa isang virtual machine. Maaaring i-toggle nang hiwalay ng utos na `omarchy theme bg intro toggle` ang mga intro. Hindi nagpe-play ng intro ang pag-refresh ng isang tema.

Maaari ding magkaroon ng loop ang isang still, isang tahimik na bersyon ng parehong larawan na patuloy na gumagalaw, sa `backgrounds/loops/road.mp4`. Nagpe-play ito bilang kapalit ng still, pagkatapos ng intro nito kung mayroon man ito, at humihinto kapag naka-off ang mga animation. Kapag nasa baterya, ang still ang ipinapakita sa halip, at babalik ang loop sa sandaling isaksak mo ito. Hindi lumalabas ang mga loop sa tagapili ng background.

Makakahanap ka ng napakalaking koleksyon ng mga astig at piniling background sa [dharmx/walls](https://github.com/dharmx/walls).

Nagpapakita ang lock screen ng isang still frame ng isang video background, sa parehong paraan kung paano ito nagpapakita ng isang still frame ng isang animated na GIF.
