# Mga Background

Bawat tema ay may sariling hanay ng mga background, at maaari kang magdagdag ng sarili mong mga extra sa `~/.config/omarchy/backgrounds/[theme]`. Kung gusto mong magdagdag ng extra na background image sa, sabihin na nating, nord na tema, ilalagay mo lang ang file sa `~/.config/omarchy/backgrounds/nord`.

Pinakamadali mong magagawa ito sa pamamagitan ng pagpunta sa _Install > Style > Background_ sa Omarchy Menu. Bubuksan nito ang folder kung saan nakaimbak ang mga background para sa temang iyon. Pindutin ang `Super + Shift + F` para magbukas ng isa pang file manager, hanapin ang background mo, at kopyahin ito papunta roon. Ngayon, kasama na ito sa mga pagpipiliang background na maaari mong pagpilian gamit ang `Super + Ctrl + W`.

Ang temang walang sariling mga background ay makakakuha ng isa na ginuhit mula sa mga kulay nito: ang logo ng Omarchy sa accent color ng tema sa background color nito. Magdagdag ng sarili mo para palitan ito.

Maaari ring maging video ang mga background bukod sa mga still image. Maglagay ng `mp4`, `m4v`, `mov`, `webm`, `mkv`, o `avi` na file sa parehong folder at lalabas ito kasama ng mga image. Pini-play ng OWE wallpaper engine ang mga video. Dine-decode nito ang video nang isang beses para sa lahat ng monitor at pini-play ang tunog nito sa default na audio output, at itinitigil nito ang playback tuwing walang nakakakita rito. Mas malaki pa rin nang malaki ang konsumo sa kuryente ng isang video wallpaper kaysa sa isang still na wallpaper.

Maaaring magsama ang mga tema ng maikling intro para sa isang still na background. Para sa `backgrounds/road.webp`, ang katugmang video ay nasa `backgrounds/intros/road.mp4`. Awtomatiko itong nagpe-play sa boot, kapag lumilipat sa isang temang nakapili ang background na iyon, at kapag pinipili ang background na iyon, pagkatapos ay babalik ito sa still. Hindi lumalabas ang mga intro video sa background picker at hindi kailanman naglu-loop.

Ang pagpili sa _Appearance > Animations Off_ ay nag-o-off din sa mga background intro. Ginagawa ito ng Omarchy bilang default sa isang virtual machine. Maaaring i-toggle nang hiwalay ng `omarchy theme bg intro toggle` na command ang mga intro. Ang pag-refresh ng isang tema ay hindi nagpe-play ng intro.

Ang isang still ay maaari ring magkaroon ng loop, isang tahimik na bersyon ng parehong larawan na patuloy na gumagalaw, sa `backgrounds/loops/road.mp4`. Nagpe-play ito kapalit ng still, pagkatapos ng intro nito kung mayroon man, at humihinto kapag naka-off ang mga animation. Sa baterya, ang still ang ipinapakita sa halip, at bumabalik ang loop kapag nakasaksak ka na. Hindi lumalabas ang mga loop sa background picker.

Makakahanap ka ng malaking koleksyon ng mga cool at curated na background sa [dharmx/walls](https://github.com/dharmx/walls).

Ipinapakita ng lock screen ang isang still frame ng isang video background, sa parehong paraan kung paano ito nagpapakita ng still frame ng isang animated na GIF.
