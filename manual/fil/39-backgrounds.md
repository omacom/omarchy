# Mga Background

Ang bawat tema ay may kasamang sarili nitong hanay ng mga background, at maaari kang magdagdag ng sarili mong mga ekstra sa `~/.config/omarchy/backgrounds/[theme]`. Kung gusto mong magdagdag ng karagdagang larawan ng background sa, halimbawa, temang nord, ilagay mo lang ang file sa `~/.config/omarchy/backgrounds/nord`.

Pinakamadali itong gawin sa pamamagitan ng pagpunta sa _Install > Style > Background_ sa Omarchy Menu. Bubuksan nito ang folder kung saan nakaimbak ang mga background para sa temang iyon. Pindutin ang `Super + Shift + F` upang magbukas ng isa pang file manager, hanapin ang iyong background, at kopyahin ito roon. Ngayon ay isasama na ito sa mga pagpipiliang background na mapipili mo gamit ang `Super + Ctrl + W`.

Maaaring video rin ang mga background bukod sa mga still. Maglagay ng `mp4`, `m4v`, `mov`, `webm`, `mkv`, o `avi` na file sa parehong folder at lalabas ito kasama ng mga larawan. Pinapatugtog ang mga video ng OWE wallpaper engine. Minsan lang nito dini-decode ang video para sa lahat ng monitor at pinapatugtog ang tunog nito sa default na audio output, at itinitigil nito ang playback tuwing walang nakakakita rito. Mas malaki pa rin nang malayo ang konsumo sa kuryente ng isang video wallpaper kumpara sa isang still.

Maaaring magsama ang mga tema ng maikling intro para sa isang still na background. Para sa `backgrounds/road.webp`, ang katugmang video ay nasa `backgrounds/intros/road.mp4`. Awtomatiko itong tumutugtog sa boot at kapag lumilipat sa isang temang nakapili ang background na iyon, pagkatapos ay babalik sa still. Hindi lumalabas ang mga intro video sa background picker at hindi kailanman umuulit ang mga ito.

Ang pagpatay sa _Appearance > Animations_ ay pumapatay rin sa mga background intro. Ginagawa ito ng Omarchy bilang default sa isang virtual machine. Maaaring i-toggle nang hiwalay ang mga intro gamit ang utos na `omarchy theme bg intro toggle`. Ang pag-refresh ng isang tema o pagpili ng ibang background sa loob ng parehong tema ay hindi nagpapatugtog ng intro.

Makakahanap ka ng napakalaking koleksyon ng magagandang na-curate na background sa https://github.com/dharmx/walls.

Nagpapakita ang lock screen ng isang still frame ng isang video background, sa parehong paraan kung paano ito nagpapakita ng isang still frame ng isang animated na GIF.
