# Mga Background

Bawat tema ay may kasamang sarili nitong set ng mga background, at maaari kang magdagdag ng sarili mong mga karagdagan sa `~/.config/omarchy/backgrounds/[theme]`. Kung gusto mong magdagdag ng karagdagang background image sa, halimbawa, temang nord, ilagay mo lang ang file sa `~/.config/omarchy/backgrounds/nord`.

Pinakamadali mo itong magagawa sa pamamagitan ng pagpunta sa _I-install > Istilo > Background_ sa Omarchy Menu. Ilalabas nito ang folder kung saan nakaimbak ang mga background para sa temang iyon. Pindutin ang `Super + Shift + F` para magsimula ng isa pang file manager, hanapin ang background mo, at kopyahin ito papunta roon. Mula ngayon, kasama na ito sa mga pagpipiliang background na maaari mong piliin gamit ang `Super + Ctrl + W`.

Maaari ring maging video ang mga background bukod sa mga still image. Maglagay ng `mp4`, `m4v`, `mov`, `webm`, `mkv`, o `avi` na file sa parehong folder at lalabas ito kasama ng mga image. Pinapatugtog ang mga video ng OWE wallpaper engine. Dine-decode nito ang video nang isang beses para sa lahat ng monitor at pinapatugtog ang tunog nito sa pamamagitan ng default na audio output, at itinitigil nito ang playback tuwing walang nakakakita rito. Mas malaki pa rin nang malayo ang konsumo ng kuryente ng video wallpaper kaysa sa still na wallpaper.

Maaaring magsama ang mga tema ng maikling intro para sa isang still na background. Para sa `backgrounds/road.webp`, ang katugmang video ay nasa `backgrounds/intros/road.mp4`. Awtomatiko itong tumutugtog sa boot, kapag lumilipat sa isang tema na napili ang background na iyon, at kapag pinipili ang background na iyon, pagkatapos ay babalik ito sa still. Hindi lumalabas ang mga intro video sa background picker at hindi kailanman naglo-loop.

Ang pag-off sa _Hitsura > Mga Animasyon_ ay nag-o-off din sa mga background intro. Ginagawa ito ng Omarchy bilang default sa isang virtual machine. Maaaring i-toggle nang hiwalay ng `omarchy theme bg intro toggle` na command ang mga intro. Hindi nagpapatugtog ng intro ang pag-refresh ng isang tema.

Makakahanap ka ng malaking koleksiyon ng mga cool at curated na background sa [dharmx/walls](https://github.com/dharmx/walls).

Nagpapakita ang lock screen ng still frame ng isang video background, sa parehong paraan kung paano ito nagpapakita ng still frame ng isang animated na GIF.
