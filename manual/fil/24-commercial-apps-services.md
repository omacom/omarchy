# Mga komersyal na app/serbisyo

Pangunahing nakatuon ang Omarchy sa pagbibigay ng libre at open source na software, pero hindi ito dogmatiko tungkol doon. Minsan, ang pinakamahusay na solusyon ay isang komersyal na produkto, at ayos lang iyon. Narito ang ilan sa mga opsyong binibigyan ka namin ng madaling paraan para i-install.

## 1Password

Ang pag-iingat ng iyong mga password sa isang password manager ay isang best practice. Doble pa iyon kung nagtatrabaho ka kasama ang isang team. At ang [1password](https://1password.com/) ay isang mahusay na solusyon, na may kasama ring command line tool para sa pagsasama ng mga paghahanap ng key sa mga script.

Sinisimulan mo ang 1Password gamit ang `Super + Shift + /`. Kung hindi pa ito naka-install, sisimulan muna ng hotkey na iyon ang pag-install (maaari mo ring gamitin ang _Install > Service > 1Password_ mula sa menu ng Omarchy). Itinatakda rin ng installer ang extension ng 1Password para sa Chromium.

## Bitwarden

Ang [Bitwarden](https://bitwarden.com/) ay ang open source na alternatibo sa larangan ng mga password manager, na may libreng tier na sumasaklaw sa karamihan ng personal na paggamit. I-install ito gamit ang _Install > Service > Bitwarden_ mula sa menu ng Omarchy, na kasama ring nagdadala ng command line tool ng Bitwarden.

## Spotify

Ang [Spotify](https://spotify.com/) ay ang pinakasikat na streaming music service sa mundo. Ibinibigay ito ng Omarchy bilang isang web app, na nagbibigay sa iyo ng buong player, mga media key, at Spotify Connect, pero hindi ng mga offline download. Simulan ito gamit ang `Super + Shift + M`.

## Slack

Ang [Slack](https://slack.com/) ay kung saan maraming team ang nagcha-chat, kapwa sa loob ng kumpanya at kasama ang mga collaborator sa labas. I-install ito gamit ang _Install > Service > Slack_ mula sa menu ng Omarchy, at magbubukas ito kaagad kapag handa na.

## Dropbox

Ang [Dropbox](https://www.dropbox.com/) ay isang mahusay na paraan upang mag-sync ng mga file sa pagitan ng mga makina habang nag-iingat ng backup sa cloud. Upang i-set up ito, piliin ang _Install > Service > Dropbox_ mula sa menu ng Omarchy. Kapag tumatakbo na ito, i-hover ang tray sa kanang itaas ng bar at i-right-click ang icon ng Dropbox upang tapusin ang pag-setup.

## Tailscale

Ang [Tailscale](https://tailscale.com/) ay isang mesh VPN na ginagawang napakasimple ang secure na pag-access sa lahat ng iyong computer at server sa internet. Upang i-set up ito, piliin ang _Install > Service > Tailscale_ mula sa menu ng Omarchy.

Makakakuha ito ng panel sa bar, isang web app para sa admin console, at Taildrop para sa pagpapadala ng mga file sa pagitan ng iyong mga makina — tingnan ang [networking](35-networking.md).

## ONCE

Ang [ONCE](https://once.com/) ay ang linya ng software ng 37signals na binibili mo nang isang beses at pinapatakbo sa sarili mong server, tulad ng Campfire chat system. Piliin ang _Install > Service > ONCE_ mula sa menu ng Omarchy upang i-install ito, na mag-e-enable sa background service nito at magdadala sa iyo sa terminal interface ng ONCE upang magpatuloy mula roon.

## NordVPN

Ang [NordVPN](https://nordvpn.com/) ay isang karaniwang VPN service na hinahayaan kang ilabas ang iyong traffic mula sa karamihan ng mga rehiyon sa buong mundo. Upang i-set up ito, piliin ang _Install > Service > NordVPN_ mula sa menu ng Omarchy. Pagkatapos ng reboot na hinihingi nito, patakbuhin ang `nordvpn login` upang mag-authenticate.
