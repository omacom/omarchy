# Mga komersyal na app/serbisyo

Karamihan ay nakatuon ang Omarchy sa pagbibigay ng libre at open source na software, pero hindi ito relihiyoso tungkol dito. Minsan ang pinakamahusay na solusyon ay isang komersyal na alok, at ayos lang iyon. Narito ang ilan sa mga pagpipiliang binibigyan namin ng madaling pag-install.

## 1Password

Best practice ang pag-iingat ng iyong mga password sa isang password manager. Doble pa kung nagtatrabaho ka kasama ang isang team. At ang [1password](https://1password.com/) ay isang mahusay na solusyon, na may kasama ring command line tool para sa pagsasama ng mga key lookup sa mga script.

Sinisimulan mo ang 1Password gamit ang `Super + Shift + /`. Kung hindi pa ito naka-install, sinisimulan muna ng hotkey na iyon ang pag-install (maaari mo ring gamitin ang _Install > Service > 1Password_ mula sa Omarchy menu). Sinese-setup din ng installer ang 1Password extension para sa Chromium.

## Bitwarden

Ang [Bitwarden](https://bitwarden.com/) ay ang open source na alternatibo sa larangan ng password manager, na may libreng tier na sumasaklaw sa karamihan ng personal na paggamit. I-install ito gamit ang _Install > Service > Bitwarden_ mula sa Omarchy menu, na nagdadala rin ng Bitwarden command line tool.

## Spotify

Ang [Spotify](https://spotify.com/) ay ang pinakasikat na streaming music service sa mundo. At ibinibigay ng Linux application ang lahat ng inaasahan mo, kasama ang offline na pagtugtog.

Sinisimulan mo ang Spotify gamit ang `Super + Shift + M`. Tulad ng 1Password, sinisimulan muna ng hotkey ang pag-install kung hindi pa naka-install ang Spotify (o gamitin ang _Install > Service > Spotify_ mula sa Omarchy menu).

## Slack

Ang [Slack](https://slack.com/) ay kung saan maraming team ang nagcha-chat, pareho sa loob ng kumpanya at kasama ang mga collaborator sa labas. I-install ito gamit ang _Install > Service > Slack_ mula sa Omarchy menu, at bubuksan ito kaagad kapag handa na.

## Dropbox

Ang [Dropbox](https://www.dropbox.com/) ay isang mahusay na paraan para mag-sync ng mga file sa pagitan ng mga makina habang nag-iingat ng backup sa cloud. Para i-setup ito, piliin ang _Install > Service > Dropbox_ mula sa Omarchy menu. Kapag tumatakbo na ito, i-hover ang tray sa kanang itaas ng bar at i-right-click ang Dropbox icon para tapusin ang setup.

## Tailscale

Ang [Tailscale](https://tailscale.com/) ay isang mesh VPN na ginagawang napakasimple ang pagkuha ng access sa lahat ng iyong mga computer at server sa internet nang ligtas. Para i-setup ito, piliin ang _Install > Service > Tailscale_ mula sa Omarchy menu.

Nakakakuha ito ng panel sa bar, isang web app para sa admin console, at Taildrop para sa pagpapadala ng mga file sa pagitan ng iyong mga makina — tingnan ang [networking](35-networking.md).

## ONCE

Ang [ONCE](https://once.com/) ay linya ng software ng 37signals na binibili mo nang isang beses at pinapatakbo sa sarili mong server, tulad ng Campfire chat system. Piliin ang _Install > Service > ONCE_ mula sa Omarchy menu para i-install ito, na nagpapagana sa background service nito at nagdadala sa iyo sa ONCE terminal interface para ituloy mula roon.

## NordVPN

Ang [NordVPN](https://nordvpn.com/) ay isang standard na VPN service na nagbibigay-daan sa iyong ilabas ang iyong trapiko mula sa karamihan ng mga rehiyon sa buong mundo. Para i-setup ito, piliin ang _Install > Service > NordVPN_ mula sa Omarchy menu. Pagkatapos ng reboot na hinihingi nito, patakbuhin ang `nordvpn login` para mag-authenticate.
