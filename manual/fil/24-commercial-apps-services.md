# Mga komersyal na app/serbisyo

Pangunahing nakatuon ang Omarchy sa pagbibigay ng libre at open source na software, pero hindi ito relihiyoso tungkol doon. Minsan ang pinakamahusay na solusyon ay isang komersyal na alok, at ayos lang iyon. Narito ang ilan sa mga opsyong binibigyan namin ng madaling pag-install.

## 1Password

Isang best practice ang pag-iingat ng iyong mga password sa isang password manager. Doble pa kung nagtatrabaho ka kasama ang isang team. At ang [1password](https://1password.com/) ay isang mahusay na solusyon, na may kasama ring command line tool para sa pagsasama ng mga paghahanap ng key sa mga script.

Sinisimulan mo ang 1Password gamit ang `Super + Shift + /`. Kung hindi pa ito naka-install, sisimulan muna ng hotkey na iyon ang pag-install (maaari mo ring gamitin ang _Install > Service > 1Password_ mula sa menu ng Omarchy). Dinadala rin ng installer ang 1Password command line tool at inaayos ang 1Password extension para sa Chrome at Chromium; i-restart ang iyong browser para i-load ito.

## Bitwarden

Ang [Bitwarden](https://bitwarden.com/) ay ang open source na alternatibo sa larangan ng mga password manager, na may libreng tier na sumasaklaw sa karamihan ng personal na paggamit. I-install ito gamit ang _Install > Service > Bitwarden_ mula sa menu ng Omarchy, na kasama ring nagdadala ng Bitwarden command line tool.

## Spotify

Ang [Spotify](https://spotify.com/) ang pinakasikat na serbisyo ng streaming music sa mundo. Inihahatid ito ng Omarchy bilang isang web app, na nagbibigay sa iyo ng buong player, media keys, at Spotify Connect, pero hindi ng mga offline download. Simulan ito gamit ang `Super + Shift + M`.

## Slack

Ang [Slack](https://slack.com/) ay kung saan maraming team ang nagcha-chat, kapwa sa loob ng kumpanya at kasama ang mga collaborator sa labas. I-install ito gamit ang _Install > Service > Slack_ mula sa menu ng Omarchy, at magbubukas ito sa sandaling handa na ito.

## Notion

Ang [Notion](https://www.notion.com/) ay isang workspace para sa mga note, doc, at proyekto. I-install ang desktop app nito gamit ang _Install > Service > Notion_ mula sa menu ng Omarchy.

## WeChat

Ang [WeChat](https://www.wechat.com/) ay ang messaging app na ginagamit ng karamihan sa China, para sa pagcha-chat, mga tawag, at pakikipag-ugnayan sa sinumang nakatira roon. I-install ang opisyal na Linux client ng Tencent gamit ang _Install > Service > WeChat_ mula sa menu ng Omarchy, at magbubukas ito sa sandaling handa na ito. Available lang ito sa mga x86 na computer.

## Dropbox

Ang [Dropbox](https://www.dropbox.com/) ay isang mahusay na paraan para mag-sync ng mga file sa pagitan ng mga machine habang nag-iingat ng backup sa cloud. Para i-set up ito, piliin ang _Install > Service > Dropbox_ mula sa menu ng Omarchy. Nagdaragdag ito ng Dropbox icon sa bar: i-click ito para mag-log in, pagkatapos ay gamitin ang parehong panel para tingnan ang iyong storage at buksan ang mga kamakailang na-sync na file.

## Tailscale

Ang [Tailscale](https://tailscale.com/) ay isang mesh VPN na ginagawang napakadali ng ligtas na pag-access sa lahat ng iyong computer at server sa internet. Para i-set up ito, piliin ang _Install > Service > Tailscale_ mula sa menu ng Omarchy.

Nagkakaroon ito ng panel sa bar, isang web app para sa admin console, at Taildrop para sa pagpapadala ng mga file sa pagitan ng iyong mga machine — tingnan ang [networking](35-networking.md).

## ONCE

Ang [ONCE](https://once.com/) ay ang linya ng software ng 37signals na binibili mo nang isang beses at pinapatakbo sa sarili mong server, tulad ng Campfire chat system. Piliin ang _Install > Service > ONCE_ mula sa menu ng Omarchy para i-install ito, na mag-e-enable sa background service nito at magdadala sa iyo sa ONCE terminal interface para ikaw na ang magpatuloy mula roon.

## NordVPN

Ang [NordVPN](https://nordvpn.com/) ay isang karaniwang serbisyo ng VPN na nagbibigay-daan sa iyong ilabas ang iyong traffic mula sa karamihan ng mga rehiyon sa buong mundo. Para i-set up ito, piliin ang _Install > Service > NordVPN_ mula sa menu ng Omarchy. Pagkatapos ng reboot na hinihingi nito, patakbuhin ang `nordvpn login` para mag-authenticate.
