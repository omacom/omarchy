# Mga Paalala

Ang Omarchy ay may built-in na paraan para magtakda ng mga simpleng paalala batay sa isang countdown timer at may mensahe. Magagawa mo ito sa pamamagitan ng `Super + Ctrl + R`, makikita ang lahat ng nakatakda sa pamamagitan ng `Super + Ctrl + Alt + R`, at mabubura ang lahat sa pamamagitan ng `Super + Ctrl + Shift + R`. Lahat ay maa-access din sa pamamagitan ng _Mag-trigger > Paalala_. Maaari mo ring gamitin ang CLI gamit ang `omarchy reminder 7 'Tea ready'`.
