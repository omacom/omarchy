# Mga Notice

Mabilis mong maa-access ang petsa at oras, katayuan ng baterya, at kasalukuyang panahon gamit ang mga hotkey notice.

### Petsa at Oras

`Super + Ctrl + Alt + T`

 ![notice-datetime](images/notice-datetime.webp)

### Panahon

`Super + Ctrl + Alt + W`

 ![notice-weather](images/notice-weather.webp)

Ang lokasyon ay natutukoy mula sa iyong IP address, na karaniwan ay sapat nang malapit, ngunit hindi palagi. Maaari mo itong ayusin gamit ang `omarchy weather location --set Malibu`, o maging tiyak tungkol dito sa pamamagitan ng pagdaragdag ng mga coordinate: `omarchy weather location --set Malibu 34.0259,-118.7798`. Patakbuhin ang `omarchy weather location` nang mag-isa para makita kung saan ka nito iniisip na naroroon, at ang `--clear` para bumalik sa auto-detection.
