# Iba Pang Mga Package

May kamangha-manghang kayamanan ng mga package ang Arch para sa halos anumang uri ng software sa pagitan ng opisyal na repository at ng Arch User Repository (AUR).

Hindi na ito maaaring maging mas madali pang gamitin. Nag-i-install ka ng bagong Arch package sa pamamagitan ng pagpunta sa _Install > Package_ sa Omarchy menu (`Super + Space`) at pag-type ng package na gusto mo. Awtomatikong i-fi-fuzzy filter nito ang listahan ng lahat ng package. (Maaari mo rin itong gawin nang mano-mano gamit ang `omarchy pkg add [package]` sa terminal).

Maaari mo ring gawin ang pareho sa AUR, gamitin lang ang _Install > AUR_. Tandaan lang na hindi sinusuri ng Arch team ang AUR. Parang RubyGems o npm ito. Kahit sino ay maaaring mag-upload.

Kung gusto mong alisin ang isang package, maaari mong gamitin ang _Remove > Package_ mula sa Omarchy menu. Aalisin nito ang package, mga config file, at mga dependency. (Maaari mo rin itong gawin nang mano-mano gamit ang `omarchy pkg drop [package]`).
