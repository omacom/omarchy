# Mga Font

Gumagamit ang Omarchy ng JetBrainsMono Nerd Font bilang default na font ng terminal at ng sistema.

 ![fonts-jetbrainsmono](images/fonts-jetbrainsmono.webp)

Maaari mong baguhin ito sa pamamagitan ng menu na _Hitsura > Font_ sa menu ng Omarchy (`Super + Space`). Itinatakda niyon ang monospace na font sa lahat ng lugar: sa terminal, sa bar, at sa anumang iba pang humihingi nito.

Maaari kang mag-install ng iba pang sikat na programming font sa pamamagitan ng _Mag-install > Estilo > Font_ sa menu ng Omarchy: isang click lang ang layo ng Cascadia Mono, Meslo LG Mono, Fira Code, Victor Code, Bitstream Vera Mono, at Iosevka, lahat sa kanilang mga bersyong Nerd Font para patuloy na gumana ang mga glyph sa bar at terminal. Kapag nag-install ka ng isa, lilipat din ang buong sistema rito, at maaari kang bumalik anumang oras sa ilalim ng _Hitsura > Font_.

## Tsino, Hapones, at Koreano

Nagkakapareho ang Tsino, Hapones, at Koreano sa maraming karakter ngunit magkakaiba ang pagguhit sa ilan sa mga ito, kaya ang parehong karakter ay mukhang tama sa isang mambabasa at banyaga sa isa pa. Kapag pumili ka ng isa sa mga wikang ito sa ilalim ng _Pag-setup > Rehiyon > Wika_, o ng input method nito, itinatakda niyon ang magkakatugmang anyo. Para ikaw mismo ang pumili sa mga ito, patakbuhin ang `omarchy font cjk jp`, `kr`, `sc`, `tc` (Taiwan), o `hk` (Hong Kong) sa isang terminal; ibabalik ng `omarchy font cjk default` ang pinili ng sistema, na siyang mga anyong Hapones. Pinapanatili ng tekstong minarkahan ng isang web page o dokumento ng sarili nitong wika, at ng buong desktop habang nasa isa ito sa mga wikang ito, ang mga anyo ng wikang iyon.
