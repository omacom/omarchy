# Otros paquetes

Entre el repositorio oficial y el Arch User Repository (AUR), Arch tiene una variedad asombrosa de paquetes para casi cualquier tipo de software.

Y usar cualquiera de los dos no puede ser más sencillo. Para instalar un paquete nuevo de Arch, ve a _Instalar > Paquete_ en el menú de Omarchy (`Super + Space`) y escribe el paquete que quieres. Filtrará automáticamente la lista de todos los paquetes según escribes. (También puedes hacerlo manualmente usando `omarchy pkg add [package]` en la terminal).

Puedes hacer lo mismo con el AUR, solo tienes que usar _Instalar > AUR_. Solo recuerda que el AUR no está revisado por el equipo de Arch. Es como RubyGems o npm. Cualquiera puede subir.

Si quieres quitar un paquete, puedes usar _Quitar > Paquete_ desde el menú de Omarchy. Quitará el paquete, los archivos de configuración y las dependencias. (También puedes hacerlo manualmente usando `omarchy pkg drop [package]`).
