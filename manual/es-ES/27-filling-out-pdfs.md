# Rellenar PDF

Omarchy viene con un visor de PDF sencillo y agradable llamado Document Viewer. Es el programa que abre cualquier PDF con solo hacer doble clic.

Pero Document Viewer solo sirve para rellenar PDF configurados como formularios. Si necesitas rellenar PDF que no sean formularios, o firmar uno, usa [Signed](https://github.com/omacom/signed). Inícialo desde el lanzador de aplicaciones (`Super + Space`), o haz clic derecho en el archivo, selecciona _Open With..._ y elige Signed.

Pulsa `T` para escribir texto y `D` para poner la fecha de hoy. Ambos aparecen donde esté el puntero de tu ratón. Arrastra cualquier cosa para moverla, arrastra su esquina para hacerla más grande o más pequeña, y haz doble clic en el texto para cambiarlo.

Para firmar, necesitarás una imagen de tu firma: un escaneo, o una foto bien iluminada de tu firma en papel blanco. Abre el menú _Signature_ (`Shift + S`), elige _Add signature..._, escoge la imagen y dale un nombre. Signed quita el papel y conserva la tinta. A partir de ahí, `S` pone tu firma bajo el puntero del ratón.

Cuando termines, usa _Save signed copy..._ (`Ctrl + S`) para guardar el PDF rellenado junto al original, que nunca se modifica. Pulsa `?` dentro de Signed para ver todos los atajos.
