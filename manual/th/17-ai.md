### การติดตั้งและอัปเดตเอเจนต์

ยกเว้น Hermes เอเจนต์เหล่านี้ใช้การติดตั้งแบบ lazy ของ mise: การเปิดใช้ครั้งแรกจะติดตั้ง CLI และการเปิดใช้ครั้งต่อ ๆ ไปจะใช้ตัวที่ติดตั้งไว้ mise ยังตรวจสอบเอเจนต์ที่ติดตั้งไว้ว่ามีรุ่นใหม่ออกมาหรือไม่ อย่างมากที่สุดทุกสี่ชั่วโมง ทันทีก่อนที่มันจะเริ่ม หรือในพื้นหลังที่พรอมต์เชลล์ หากการอัปเดตนั้นล้มเหลวหรือคุณออฟไลน์ ตัวที่ติดตั้งไว้จะทำงาน `omarchy update` จะอัปเดตเอเจนต์ที่ติดตั้งไว้พร้อมกับส่วนอื่น ๆ ของ Omarchy และ `mup` จะอัปเดตเฉพาะเครื่องมือที่จัดการโดย mise เท่านั้น

ตัวอัปเดตของเอเจนต์เอง เช่น `claude update`, `codex update` หรือปุ่มอัปเดตในแอป ไม่ได้อัปเดตตัวที่ติดตั้งโดย mise `codex update` จะล้มเหลว และ `claude update` อาจรายงานว่าสำเร็จในขณะที่ติดตั้งสำเนาแยกต่างหากที่ mise ไม่ได้ติดตาม หากคุณอยากใช้ตัวติดตั้งและตัวอัปเดตดั้งเดิมของเอเจนต์มากกว่า ให้เพิ่มมันลงใน `disable_tools`; ดู [Preinstalled CLI tools](18-development-tools.md#preinstalled-cli-tools)

ในการติดตั้งเครื่องมือ lazy ที่กำหนดค่าไว้ทั้งหมดก่อนที่คุณจะต้องการใช้ ให้รัน `mise install --include-lazy` ซึ่งรวมถึงเครื่องมือ CLI ค่าเริ่มต้นอื่น ๆ ของ Omarchy รวมถึงเอเจนต์ด้วย ดู [Preinstalled CLI tools](18-development-tools.md#preinstalled-cli-tools) สำหรับการติดตั้งเครื่องมือตัวเดียวหรือใช้การติดตั้งของคุณเอง

`grok` ถูกติดตั้งผ่านแพ็กเกจ `grok` แบบ first-party ของ mise ในแบบเดียวกับ `claude` และ `codex` ให้รัน `grok` หรือเลือกมันใต้ _Setup > Defaults > Agent_ ข้ามตัวติดตั้งแบบ `curl | bash` บน x.ai ไป เส้นทางนั้นจะใส่สำเนาที่สองไว้ใน `~/.grok/bin`, ใส่ไว้หน้าสุดบน `PATH` และเขียนทับ wrapper ของ Omarchy

`dsh` เปิด UI บนเบราว์เซอร์ของมันที่ `127.0.0.1:3080` โดยไดเรกทอรีที่เปิดใช้เป็น workspace เริ่มต้น UI บนเบราว์เซอร์ของมันไม่รับพรอมต์เริ่มต้น ดังนั้น `omarchy agent prompt` จะเปิดมันโดยมีพรอมต์อยู่บนคลิปบอร์ดของคุณให้วาง Omarchy เริ่มมันด้วยชุดสิทธิ์แบบ no-approval ของ DeepSeek DeepSeek Harness จะอัปโหลดบันทึกเซสชันไปยัง DeepSeek เมื่อคุณใช้ API โมเดลอย่างเป็นทางการของมัน; ปิดได้ใต้ _Settings > General > Upload Session Log_ ใน UI บนเบราว์เซอร์ของมัน ข้อเสนอแนะที่คุณส่งให้มันจะถูกอัปโหลดไปพร้อมกับเซสชันด้วย เว้นแต่คุณเริ่มมันด้วย `DSH_TELEMETRY_MODE=DISABLED`

### เอเจนต์เริ่มต้น

เลือกเอเจนต์เริ่มต้นของคุณด้วย `omarchy default agent <name>` หรือใต้ _Setup > Defaults > Agent_ ใน Omarchy Menu (`Super + Space`) หากยังไม่ได้ติดตั้งเอเจนต์นั้น การเลือกมันจะติดตั้งมันก่อน Omarchy ที่ติดตั้งใหม่จะเชิญให้คุณตัดสินใจเรื่องนี้ด้วยการแจ้งเตือนเพียงครั้งเดียว

การเลือก Claude ยังพยายามตั้งค่าส่วนขยายเบราว์เซอร์ของมันสำหรับ Chromium, Chrome, Brave, Brave Origin และ Edge การติดตั้งส่วนขยายใช้กับผู้ใช้ทุกคนและอาจขอรหัสผ่านระบบของคุณ; การยกเลิกหรือการติดตั้งส่วนขยายที่ล้มเหลวยังคงเลือกและเปิดใช้ Claude รีสตาร์ตเบราว์เซอร์ของคุณ, เปิดใช้งานส่วนขยายหากระบบถาม และลงชื่อเข้าใช้ Claude เพื่อเชื่อมต่อมันให้เสร็จ รัน `/chrome` ใน Claude เพื่อตรวจการเชื่อมต่อ Firefox และ Zen ไม่รองรับส่วนขยายนี้ หาก Claude เป็นเอเจนต์เริ่มต้นของคุณอยู่แล้วก่อนที่จะเพิ่มการติดตั้งนี้เข้ามา ให้เลือกมันอีกครั้งเพื่อติดตั้งส่วนขยาย

เมื่อคุณเลือกแล้ว `Super + Shift + Ctrl + A` จะเปิดเอเจนต์เริ่มต้นในหน้าต่างเทอร์มินัลเฉพาะ (หรือเปิดตัวเลือกขึ้นมาหากคุณยังไม่ได้เลือก) คุณสามารถเปิดมันเข้าไปทำงานตรง ๆ ได้ด้วย `omarchy agent prompt "Review this project"` Freebuff และ DeepSeek Harness ไม่รับพรอมต์เริ่มต้น ดังนั้นพวกมันจะเปิดโดยมีพรอมต์อยู่บนคลิปบอร์ดของคุณให้วางแทน เอเจนต์ที่เปิดใช้ด้วยวิธีนี้จะทำงานโดยไม่มีใครดูแลในโหมด don't-stop-to-ask ของแต่ละตัว ดังนั้นเตรียมพร้อมไว้เลยว่าพวกมันจะลงมือทำสิ่งต่าง ๆ จริง ๆ! MiniMax Code ไม่มีโหมดแบบนั้นสำหรับเซสชันแบบอินเทอร์แอกทีฟของมัน ดังนั้นมันจะขอสิทธิ์ตามปกติ และเนื่องจากเอเจนต์ปฏิเสธที่จะจดจำความเชื่อถือสำหรับไดเรกทอรีหลักของคุณ การเปิดใช้จาก `$HOME` จะเริ่มใน `~/Work` แทน

ยังมีทางลัดบนเทอร์มินัลด้วย: `a` รันเอเจนต์เริ่มต้นแบบ inline ในเทอร์มินัลปัจจุบัน ส่วน `c`, `cx` และ `cy` เริ่ม OpenCode, Claude Code และ Codex โดยตรง (ในโหมดอนุมัติอัตโนมัติของพวกมันอีกเช่นกัน) การเปลี่ยนธีมยังซิงก์ไปยังเอเจนต์ด้วย: Claude Code, Pi, OpenCode และ Hermes (เมื่อ Omarchy ได้ติดตั้งมันแล้ว) ล้วนตามไปด้วยเมื่อคุณสลับธีมของ Omarchy

### แผงเอเจนต์

แถบบนสุดมีไอคอนเอเจนต์ ก่อนที่คุณจะตั้งค่าเอเจนต์ แผงของมันจะพาคุณลงชื่อเข้าใช้ Claude, Codex หรือ Grok และตัวแรกจะกลายเป็นเอเจนต์เริ่มต้นของคุณ หลังจากนั้น แผงจะรวมการสมัครใช้งานทุกอย่างไว้ในหน้าเดียว: เอเจนต์และบัญชีแต่ละตัวพร้อมแพ็กเกจของมัน, มิเตอร์สำหรับขีดจำกัดเซสชัน 5 ชั่วโมงและรายสัปดาห์ของแต่ละตัวพร้อมเวลาจนกว่าจะรีเซ็ต (ชี้เมาส์ค้างไว้เพื่อดูเปอร์เซ็นต์ที่แน่นอน) หรือยอดเงินเติมเงินคงเหลือ ใต้บรรทัดที่หมุนเวียนผ่านสิ่งที่คุณใช้ไปในทุกตัว เช่น จำนวนโทเค็นในสัปดาห์นี้และโมเดลที่คุณใช้มากที่สุด ใต้ _Make something_ มันเสนอพรอมต์เริ่มต้นสำหรับธีม, ปลั๊กอิน หรือแอปใหม่ ที่ส่งงานนั้นให้เอเจนต์เริ่มต้นของคุณ แอปต่าง ๆ ถูกสร้างในแบบเดียวกับ Hype, Monologue และ Omacut ของ Omarchy เอง ใน C++ และ Qt Quick โดยทำตามสกิลเอเจนต์ omarchy-app และคอมไพเลอร์และชิ้นส่วน Qt ที่พวกมันต้องการก็ติดตั้งมาด้วย Claude Code, Codex, Grok, Kimi, Cursor และโควตา Grok Bot ของมัน, GitHub Copilot, Muse, Antigravity, Kimchi และ Devin ได้รับการรองรับตั้งแต่ต้นพร้อมขีดจำกัดของพวกมัน และ Hermes, Mistral Vibe และ Qwen Code จะแสดงเซสชันและโทเค็นของพวกมันเมื่อคุณได้ใช้พวกมันแล้ว แพ็กเกจและคีย์ของผู้ให้บริการที่คุณใช้ผ่าน pi, omp หรือ opencode ก็ปรากฏเช่นกัน: OpenCode Zen และ Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan และ Synthetic พร้อมขีดจำกัดของพวกมัน; Fireworks, OpenRouter และ DeepSeek พร้อมยอดเงินเติมเงินของพวกมัน; และโมเดลที่คุณรันบนฮาร์ดแวร์ของคุณเองใต้ Local models เอเจนต์ทุกตัวถูกนับเพียงครั้งเดียว ใต้ผู้ที่เรียกเก็บเงินจากมัน ไม่ว่าคุณจะขับมันผ่าน harness กี่ตัวก็ตาม

คลิกซ้ายที่ไอคอนแถบเพื่อแผง คลิกขวาเพื่อเปิดเอเจนต์เริ่มต้นของคุณ บันทึกการใช้งานที่อยู่เบื้องหลังมันจะถูกสร้างใหม่ทุก 15 นาทีโดย `omarchy agent usage-update` และแผงยังสามารถผสานการใช้งานจากเครื่องอื่น ๆ ของคุณผ่านโฟลเดอร์ที่ซิงก์ได้ ดู README ใต้ `$OMARCHY_PATH/shell/plugins/agents/` สำหรับการตั้งค่าทั้งหมด

### การสมัครใช้งานหลายรายการ

หากคุณจ่ายเงินให้แพ็กเกจ Claude, Codex หรือ Grok มากกว่าหนึ่ง — Max ส่วนตัวกับของงาน เป็นต้น — Omarchy สามารถเก็บพวกมันทั้งหมดให้ลงชื่อเข้าใช้ไว้และสลับไปมาระหว่างพวกมันได้ เพิ่มการสมัครใช้งานด้วย + ในแผงเอเจนต์ ซึ่งจะพาคุณทำเรื่องนี้ตรงนั้นเลย หรือด้วย `omarchy agent account add claude Work` (หรือ `codex` หรือ `grok`) มันจะติดตั้ง CLI หากยังไม่มี บัญชีแรกสำหรับผู้ให้บริการจะลงชื่อเข้าใช้ผ่านเบราว์เซอร์ปกติของคุณ ตรงที่ที่ CLI มองหาเสมอ ทุกบัญชีหลังจากนั้นจะลงชื่อเข้าใช้ผ่านหน้าต่างส่วนตัว ดังนั้นบัญชีที่เบราว์เซอร์ของคุณลงชื่อเข้าใช้อยู่แล้วจะไม่ถูกหยิบมาโดยไม่ตั้งใจ; ลงชื่อเข้าใช้ที่นั่นในฐานะบัญชีที่คุณกำลังเพิ่ม และปิดหน้าต่างส่วนตัวใด ๆ ที่คุณเปิดค้างไว้ก่อน อย่าออกจากระบบของ CLI เพื่อทำเรื่องนี้เด็ดขาด: การออกจากระบบจะเพิกถอนการลงชื่อเข้าใช้ที่บันทึกไว้ และบัญชีนั้นจะต้องถูกเพิ่มใหม่อีกครั้ง

ในการคัดล็อกการลงชื่อเข้าใช้การสมัครใช้งานของคุณไปยังเครื่อง Omarchy อื่นผ่าน SSH ให้รัน `omarchy agent account copy user@laptop` ผู้ส่งจะเตรียมตัวรับชั่วคราวให้เมื่อปลายทางยังไม่มีติดตั้งไว้ ดังนั้นเครื่อง Omarchy รุ่นเก่ากว่าสามารถรับบัญชีได้โดยไม่ต้องอัปเดต ตัวรับที่ติดตั้งไว้จะมีความสำคัญก่อนสุด สำเนานี้คัดล็อกการสมัครใช้งาน Claude, Codex และ Grok ทั้งหมด; เพิ่มชื่อผู้ให้บริการเพื่อเลือกพวกมัน เช่น ใน `omarchy agent account copy laptop claude` ชื่อบัญชีและรหัสคำสั่งตรงกับต้นทาง รวมถึงบัญชีที่มีอยู่แล้วบนปลายทาง บัญชีของปลายทางที่ไม่เกี่ยวข้องจะได้รับคำต่อท้ายที่เป็นตัวเลขหากชื่อซ้ำกัน และการตั้งค่า, สกิล, ปลั๊กอิน และประวัติการสนทนาจะอยู่กับแต่ละเครื่อง

ข้อมูลประจำตัวของปลายทางที่มีอยู่จะถูกเก็บไว้ บัญชีต้นทางที่ลงชื่อเข้าใช้ที่นั่นอยู่แล้วจะถูกซิงก์ชื่อโดยไม่แทนที่ข้อมูลประจำตัวของมัน; บัญชีอื่น ๆ จะถูกเพิ่มควบคู่ไปด้วย ในการแทนที่ข้อมูลประจำตัวที่บันทึกไว้สำหรับบัญชีที่ตรงกัน ให้ใช้ `omarchy agent account copy --replace laptop claude` หลังจากออกจากเซสชันของบัญชีนั้นบนปลายทางแล้ว ปลายทางใหม่ยังได้รับบัญชีที่ใช้งานอยู่และค่ากำหนดการสลับของต้นทางด้วย; ปลายทางที่มีอยู่แล้วจะเก็บของตัวเองไว้

ข้อมูลประจำตัวเดินทางผ่าน SSH และถูกเก็บไว้ในไฟล์ส่วนตัวบนปลายทาง ดังนั้นจงคัดล็อกไปยังเครื่องที่คุณเชื่อถือเท่านั้น นี่เป็นการคัดล็อกครั้งเดียว ไม่ใช่การซิงก์อย่างต่อเนื่อง โทเค็นรีเฟรชของ Codex สามารถถูกหมุนได้โดยเครื่องอื่น ทำให้การลงชื่อเข้าใช้ที่คัดล็อกมาต้องการการต่ออายุ; การลงชื่อเข้าใช้แยกกันยังคงเป็นตัวเลือกที่เชื่อถือได้มากที่สุดสำหรับการใช้พร้อมกันบนหลายเครื่อง ดู [Codex's account authentication guidance](https://developers.openai.com/codex/auth/ci-cd-auth)

มีบัญชีที่ใช้งานอยู่ได้เพียงหนึ่งบัญชีต่อผู้ให้บริการ และทุกเซสชันใหม่จะเริ่มเป็นบัญชีนั้น: `cx`, `cy`, `claude`, `codex` หรือ `grok` ธรรมดา, อะไรก็ตามที่เปิดผ่าน `omarchy agent` และสคริปต์หรือตัวแก้ไขที่พบ CLI บน `PATH` สลับด้วย `omarchy agent account use work` (และกลับด้วย `omarchy agent account use main`) หรือในแผงโดยกดหมายเลขของบัญชีแล้วตามด้วย `Enter` (หรือคลิกปุ่ม Use ของมัน) เซสชันที่กำลังทำงานอยู่แล้วจะอยู่บนบัญชีที่พวกมันเริ่มด้วย ประวัติการสนทนา, การตั้งค่า, สกิล และปลั๊กอินถูกแชร์ข้ามบัญชี ดังนั้น `claude --continue` ในโฟลเดอร์เดิมจะสานต่อจากจุดที่คุณค้างไว้บนบัญชีใหม่

เมื่อมีมากกว่าหนึ่งบัญชี แผงจะแสดงขีดจำกัดของแต่ละบัญชีเคียงข้างกัน โดยบัญชีที่ใช้งานอยู่มีการทำเครื่องหมายไว้ โดยค่าเริ่มต้น Omarchy จะแจ้งให้คุณทราบเมื่อบัญชีที่ใช้งานอยู่ผ่าน 95% ของขีดจำกัด และการคลิกการแจ้งเตือนจะสลับไปยังบัญชีที่มีพื้นที่เหลือมากที่สุด ชี้เมาส์ค้างไว้เหนือบรรทัดของบัญชีในแผงและคลิก Autoswitch ที่ปรากฏข้าง Use (หรือกด `m`) หรือรัน `omarchy agent account mode auto` เพื่อให้มันสลับด้วยตัวเองแทน; ในขณะที่มันเปิดอยู่ Autoswitch จะเข้ามาแทนที่ Use และการคลิกมันอีกครั้งจะกลับไปเป็นการแจ้งเตือน เพิ่มตัวเลขเพื่อเปลี่ยนเกณฑ์ เช่น ใน `omarchy agent account mode auto 90` หากทุกบัญชีเกินเกณฑ์ คุณจะได้รับแจ้งเพียงครั้งเดียว พร้อมกับว่าบัญชีใดจะว่างก่อน ขณะที่บัญชีที่ใช้งานอยู่ห่างจากเกณฑ์ของมันไม่เกิน 15 จุด (80% ที่ค่าเริ่มต้น) ขีดจำกัดของมันจะถูกตรวจทุกสามนาทีแทนที่จะเป็นทุก 15 นาที

`omarchy agent account list` แสดงทุกบัญชีและขีดจำกัดล่าสุดของพวกมัน, `omarchy agent account remove work` จะลืมบัญชีหนึ่ง และ `omarchy agent account rename primary Hey` จะเปลี่ยนชื่อบัญชีหนึ่ง (หรือคลิกชื่อของบัญชีในแผง) คำสั่งเหล่านี้ทำงานกับบัญชีของเอเจนต์เริ่มต้นของคุณ; ในการเข้าถึงผู้ให้บริการอื่น ให้ระบุชื่อมันก่อน เช่น ใน `omarchy agent account use codex side` การลงชื่อเข้าใช้ที่คุณมีอยู่แล้วใน `~/.claude` หรือ `~/.codex` คือบัญชี _Main_ และจะอยู่ที่เดิม บัญชีที่ไม่ได้ใช้มากว่าประมาณแปดชั่วโมงอาจแสดง _Sign-in required_; คลิกมันเพื่อลงชื่อเข้าใช้บัญชีนั้นอีกครั้งตรงในแผง หรือเริ่มเซสชันในมัน ซึ่งจะรีเฟรชการลงชื่อเข้าใช้ด้วยตัวมันเอง เซิร์ฟเวอร์ MCP ที่คุณมีอยู่เมื่อบัญชีถูกเพิ่มจะติดไปกับมัน แต่เซิร์ฟเวอร์ที่คุณเพิ่มภายหลังด้วย `claude mcp add` จะไปถึงเฉพาะบัญชีที่คุณเพิ่มพวกมันในตอนนั้น Claude Desktop และเครื่องมือที่กำหนดค่าด้วยเส้นทางสัมบูรณ์ไปยังไบนารี CLI จะไม่ตามการสลับไป ตัวแปร `CLAUDE_CONFIG_DIR`, `CODEX_HOME` หรือ `GROK_HOME` ที่ระบุอย่างชัดเจนจะมีความสำคัญเหนือบัญชีที่เลือก

### การวินิจฉัยอาการแครช

Omarchy เฝ้าดู systemd-coredump เพื่อหาอาการแครชของโปรเซส เมื่อบางสิ่งเกิด segfault คุณจะได้รับการแจ้งเตือน "Process crashed" — คลิกมัน และอาการแครชจะถูกส่งให้เอเจนต์เริ่มต้นของคุณพร้อมสกิล diagnose-crash ของ Omarchy ซึ่งจะพาเอเจนต์วางข้อเท็จจริงจาก core dump และตัดสินใจว่าอาการแครชนั้นคุ้มค่าจะรายงานไปยังต้นน้ำหรือไม่ คุณยังรันมันด้วยมือกับ PID ใด ๆ จาก `coredumpctl list` ได้ด้วย `omarchy agent crash <pid>`

การเฝ้าดูเปิดอยู่โดยค่าเริ่มต้น ปิดมันใต้ _Trigger > Toggle > Crash Capture_ (หรือด้วย `omarchy toggle crash-capture`) และการแจ้งเตือนจะหยุด; `omarchy agent crash <pid>` ยังคงทำงานด้วยมือได้

อาการแครชยังสามารถเงียบได้ทีละโปรแกรม ซึ่งเป็นสิ่งที่การวินิจฉัยเสนอให้คุณในตอนท้าย `omarchy crash mute hyprland` หยุดการแจ้งเตือนสำหรับโปรแกรมนั้นเท่านั้น, `omarchy crash mute hyprland off` นำพวกมันกลับมา และ `omarchy crash mute` เพียงลำพังจะแสดงรายการสิ่งที่คุณปิดเสียงไว้ มันรับเส้นทางของไบนารีได้อย่างยินดีพอ ๆ กับชื่อของมัน ดังนั้น `omarchy crash mute /usr/bin/hyprland` จะทำสิ่งเดียวกัน ใส่ชื่อที่มีเว้นวรรคไว้ในเครื่องหมายอัญประกาศ เช่น ใน `omarchy crash mute 'Some App'` ทุกอย่างอื่นยังคงแจ้งเตือน และโปรแกรมที่ปิดเสียงไว้ยังคงแครชอยู่ — สิ่งนี้ซ่อนตัวเตือน มันไม่ได้ซ่อมอะไรเลย

### แอปเดสก์ท็อป

เมนู _Install > AI_ ยังมีแอป AI แบบกราฟิกอยู่สองสามตัว: แอปเดสก์ท็อป ChatGPT, แอปเดสก์ท็อป Claude (เบต้าบน Linux ของ Anthropic ที่มีแท็บ Chat, Cowork และ Claude Code), Grok Bot สำหรับแชตกับโมเดลของ xAI, Hermes Desktop, OpenClaw, แอปเดสก์ท็อป Perplexity และ T3 Code Grok Bot คือแอปแชตบนเดสก์ท็อป เอเจนต์เขียนโค้ดคือคำสั่ง `grok`

Hermes Desktop คือตัวที่ต้องรู้ไว้ เพราะเครื่องหนึ่งมี Hermes เพียงหนึ่งเดียว และมันเป็นของแอป: Hermes จะถูกติดตั้งผ่านแอปเท่านั้น และคำสั่ง `hermes` ที่เอเจนต์เริ่มต้นรันคือของแอป การเลือก Hermes เป็นเอเจนต์เริ่มต้นจะติดตั้งสิ่งเดียวกับที่รายการ _Install > AI_ ทำ: แพ็กเกจ และ runtime ของ Hermes ใต้ `~/.hermes` ที่ตั้งค่าโดยตัวติดตั้งของ Hermes เอง ซึ่งใช้เวลาสองสามนาทีในครั้งแรก runtime นั้นคือ Hermes หนึ่งเดียวที่คำสั่ง `hermes` บนเทอร์มินัล, เอเจนต์เริ่มต้น และแอปล้วนใช้ และมันอัปเดตตัวเองด้วย `hermes update` แทนที่จะรอการเปิดตัวของ Omarchy การติดตั้งมันยังมอบธีมของ Omarchy ให้ Hermes เป็นสกินชื่อ `omarchy` ซึ่งทุกพื้นผิวของ Hermes จะตามไปด้วยเมื่อคุณสลับธีม; เลือกอย่างอื่นใต้การตั้งค่า Appearance ของ Hermes หรือด้วย `/skin` หากคุณไม่อยากให้มันเป็นเช่นนั้น และ Omarchy จะไม่แตะต้องตัวเลือกนั้น การลบแอปใต้ _Remove > AI_ จะปิด Hermes ก่อน รวมถึง gateway, เอา runtime นั้นไปกับมัน และเก็บแชต, ความทรงจำ และสกิลที่ Hermes เขียนให้ตัวเอง เว้นแต่คุณบอกเป็นอย่างอื่น: มันจะถาม โดยค่าเริ่มต้นคือไม่ ว่าข้อมูลนั้นและการตั้งค่าการเชื่อมต่อของคุณควรหายไปด้วยหรือไม่

ประสบการณ์บนเดสก์ท็อปของ OpenClaw คือ Control UI ของมัน ซึ่งเปิดเป็นเว็บแอปที่หนุนหลังด้วย gateway ภายในของมันเอง OpenClaw อยู่ใน `~/.openclaw` และอัปเดตตัวเอง: ใช้ปุ่ม "Update Gateway" ของ Control UI หรือรัน `openclaw update` และ gateway จะรีสตาร์ตบนเวอร์ชันใหม่ Omarchy เพียงเลือกว่ารุ่นใดที่การติดตั้งใหม่จะเริ่มจาก การลบ OpenClaw ใต้ _Remove > AI_ จะเอา gateway service และแอปไปกับมัน แล้วถามว่า `~/.openclaw` ควรหายไปด้วยหรือไม่ เนื่องจากที่นั่นเก็บแชตและข้อมูลประจำตัวของคุณไว้ควบคู่กับ OpenClaw  itself และ runtime ของปลั๊กอินที่มันดาวน์โหลด; ค่าเริ่มต้นจะเก็บมันไว้ และการติดตั้ง OpenClaw อีกครั้งจะหยิบมันกลับมา

T3 Code รันจากรุ่น AppImage อย่างเป็นทางการใน `~/.local/share/t3code` แทนที่จะมาจากแพ็กเกจ ดังนั้นมันจึงอัปเดตตัวเอง การติดตั้งมันจะถามว่าจะเริ่มบนช่อง Stable หรือ Nightly; สลับภายหลังได้ในการตั้งค่าของ T3 Code เธรดและการตั้งค่าของคุณอยู่ใน `~/.t3` และการลบ T3 Code ใต้ _Remove > AI_ จะเอาพวกมันไปกับมัน

### LLM แบบโลคัล

Omarchy แนะนำสองวิธีในการรันโมเดล LLM แบบโลคัล: LM Studio และ Ollama LM Studio มีอินเทอร์เฟซ GUI สำหรับค้นหาโมเดลแบบ open-weight, ติดตั้งพวกมัน และรันพวกมัน เป็นวิธีที่ยอดเยี่ยมในการเริ่มต้นได้อย่างง่ายดาย Ollama มี CLI ให้ทำแบบเดียวกัน แต่หากคุณเป็นมือใหม่กับโมเดลแบบโลคัล ผมจะเริ่มด้วย LM Studio คุณสามารถติดตั้งตัวใดตัวหนึ่งได้ใต้ _Install > AI_ ใน Omarchy Menu

### สกิล Omarchy

สกิลของเอเจนต์ช่วยให้ AI ใช้เครื่องมือเฉพาะในวิธีเฉพาะ และ Omarchy มาพร้อมกับสกิลค่าเริ่มต้นสำหรับการปรับแต่งระบบ เหมือนการปรับแต่งการกำหนดค่า Hyprland ของคุณ, ปรับแถบ หรือแม้แต่การสร้างธีมใหม่ตั้งแต่ต้น มันถูก symlink เข้าไปในไดเรกทอรีสกิลสำหรับ Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` และแต่ละ `~/.hermes/profiles/*/skills`) และตำแหน่งทั่วไป `~/.agents/skills` ดังนั้น harness ส่วนใหญ่หยิบมันขึ้นมาโดยอัตโนมัติ

แต่คุณควรถือว่าสกิลนี้เป็นของทดลอง โมเดลต่างกันจะใช้มันให้ผลต่างกัน ทางที่ดีที่สุดคือรันในโหมดวางแผนก่อน เพื่อให้คุณมีภาพว่าเอเจนต์อยากเปลี่ยนอะไร แล้วจงพร้อมที่จะย้อนกลับการเปลี่ยนแปลง หรือแม้กระทั่งเรียกใช้ `omarchy reinstall configs` หากเอเจนต์ทำทุกอย่างเละเทะไปหมด
