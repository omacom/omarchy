# AI

Omarchy ปฏิบัติต่อ AI coding agent ราวกับพลเมืองชั้นหนึ่ง แต่จะไม่เลือกตัวโปรดแทนคุณ เพราะทุก CLI ของ coding agent รายใหญ่ถูกเตรียมไว้ล่วงหน้าแล้วในรูปแบบตัวเรียกใช้งานแบบ lazy-loaded ตัวเรียกใช้งานเหล่านี้เป็น stub ขนาดเล็กที่จัดการโดย [mise](https://mise.jdx.dev/) ใน `~/.local/bin/` จึงไม่มีอะไรถูกดาวน์โหลดเลยจนกว่าคุณจะรันมันจริงครั้งแรก Hermes เป็นข้อยกเว้น: ไม่มี stub ใดสำหรับมัน และการเลือกมันจะติดตั้ง Hermes Desktop ดังที่หัวข้อ _แอปเดสก์ท็อป_ ด้านล่างอธิบายไว้ เรียกใช้ตัวใดตัวหนึ่งเหล่านี้และยืนยันตัวตนเมื่อถูกขอ:

| คำสั่ง    | เอเจนต์                                                            |
|------------|------------------------------------------------------------------|
| `claude`   | [Claude Code](https://code.claude.com/docs/en/overview)          |
| `codex`    | [OpenAI Codex](https://github.com/openai/codex)                  |
| `opencode` | [OpenCode](https://opencode.ai/)                                 |
| `agy`      | [Google Antigravity CLI](https://github.com/google-antigravity/antigravity-cli) |
| `copilot`  | [GitHub Copilot CLI](https://github.com/github/copilot-cli)      |
| `crush`    | [Crush](https://github.com/charmbracelet/crush)                  |
| `grok`     | [Grok Build](https://x.ai/build) จาก xAI                        |
| `kimi`     | [Kimi Code](https://www.kimi.com/code/docs/en/)                  |
| `pi`       | [Pi ของ Mario Zechner](https://github.com/badlogic/pi-mono)        |
| `omp`      | [Oh My Pi](https://github.com/can1357/oh-my-pi)                  |
| `ori`      | [Ori](https://openrouter.ai/docs/guides/ori/harness), harness ของ OpenRouter |
| `hermes`   | [Hermes](https://hermes-agent.nousresearch.com/), เอเจนต์ของ Nous Research  |
| `muse`     | [Muse Code](https://dev.meta.ai), เอเจนต์เขียนโค้ดของ Meta           |
| `cursor-agent` | [Cursor CLI](https://cursor.com/cli)                         |

`ori` คือตัวที่แตกต่างจากตัวอื่น: มันรัน harness ตัวอื่นกับโมเดลทั้งแค็ตตาล็อกของ OpenRouter ดังนั้น `ori claude`, `ori codex` หรือ `ori opencode` จะเริ่มเอเจนต์เหล่านั้นบนโมเดลใดก็ตามที่คุณชี้ให้ และ `ori code` คือเอเจนต์ของ Ori เอง

หากต้องการห่อ CLI เพิ่มเติมด้วยวิธีเดียวกัน ให้รัน `omarchy-mise-install <package> [command-name]` stub เหล่านี้จะถูกทำให้นั้นทันสมัยไปพร้อมกับทุกอย่างอื่นที่ mise จัดการ เมื่อคุณรัน `omarchy update` (หรือ alias `mup`)

`grok` ถูกติดตั้งผ่านแพ็กเกจ `grok` แบบ first-party ของ mise ด้วยวิธีเดียวกับ `claude` และ `codex` ให้รัน `grok` หรือเลือกมันใน _Setup > Defaults > Agent_ ข้ามตัวติดตั้งแบบ `curl | bash` บน x.ai ไปเลย เส้นทางนั้นจะวางสำเนาที่สองไว้ใน `~/.grok/bin` นำมันไปไว้ข้างหน้าสุดใน `PATH` และเขียนทับ wrapper ของ Omarchy

### เอเจนต์เริ่มต้น

เลือกเอเจนต์เริ่มต้นของคุณด้วย `omarchy default agent <name>` หรือใน _Setup > Defaults > Agent_ ใน Omarchy Menu (`Super + Space`) หากยังไม่ได้ติดตั้งเอเจนต์นั้น การเลือกมันจะติดตั้งมันให้ก่อน Omarchy ที่ติดตั้งใหม่จะชวนให้คุณตัดสินใจเรื่องนี้ด้วยการแจ้งเตือนเพียงครั้งเดียว

การเลือก Claude ยังพยายามตั้งค่าส่วนขยายเบราว์เซอร์ของมันสำหรับ Chromium, Chrome, Brave, Brave Origin และ Edge ด้วย การตั้งค่าส่วนขยายนี้มีผลต่อผู้ใช้ทุกคน และอาจขอรหัสผ่านระบบของคุณ การยกเลิกหรือการติดตั้งส่วนขยายที่ล้มเหลวยังคงเลือกและเรียกใช้งาน Claude อยู่ดี รีสตาร์ทเบราว์เซอร์ของคุณ เปิดใช้งานส่วนขยายหากถูกขอ และลงชื่อเข้าใช้ Claude เพื่อเชื่อมต่อมันให้เสร็จสมบูรณ์ รัน `/chrome` ใน Claude เพื่อตรวจสอบการเชื่อมต่อ Firefox และ Zen ไม่รองรับส่วนขยายนี้ หาก Claude เป็นเอเจนต์เริ่มต้นของคุณอยู่แล้วก่อนที่จะมีการเพิ่มการตั้งค่านี้ ให้เลือกมันอีกครั้งเพื่อติดตั้งส่วนขยาย

[Muse Code](https://dev.meta.ai) — `muse` ของ Meta — ใช้ stub ของ mise ที่ติดตั้งไว้ล่วงหน้าเหมือนเอเจนต์ตัวอื่น การเลือกมันเป็นเอเจนต์เริ่มต้นจะติดตั้งตัวเรียกใช้งานอย่างเป็นทางการของ Meta ผ่าน HTTP backend ของ mise ตัวเรียกใช้งานนั้นจะตรวจสอบและอัปเดตไบนารีแบบ native สำหรับเครื่องของคุณ

เมื่อคุณเลือกแล้ว `Super + Shift + Ctrl + A` จะเรียกใช้งานเอเจนต์เริ่มต้นในหน้าต่างเทอร์มินัลเฉพาะ (หรือแสดงตัวเลือกขึ้นมาหากคุณยังไม่ได้เลือก) คุณยังเรียกใช้งานมันเข้าสู่งานโดยตรงได้ด้วย `omarchy agent prompt "Review this project"` เอเจนต์ที่เรียกใช้งานด้วยวิธีนี้จะทำงานโดยไม่มีคนคอยเฝ้าในโหมดไม่หยุดถามของใครของมัน ดังนั้นจงพร้อมให้มันลงมือทำสิ่งต่าง ๆ จริง ๆ! และเนื่องจากเอเจนต์ปฏิเสธที่จะจดจำความเชื่อถือสำหรับโฮมไดเรกทอรีของคุณ การเรียกใช้งานจาก `$HOME` จะเริ่มใน `~/Work` แทน

ยังมีทางลัดในเทอร์มินัลอีกด้วย: `a` รันเอเจนต์เริ่มต้นแบบ inline ในเทอร์มินัลปัจจุบัน ขณะที่ `c`, `cx` และ `cy` เริ่ม OpenCode, Claude Code และ Codex โดยตรง (อีกครั้ง ในโหมดอนุมัติอัตโนมัติของมัน) การเปลี่ยนธีมยังซิงค์ไปยังเอเจนต์ด้วย: Claude Code, Pi, OpenCode และ Hermes (เมื่อ Omarchy ติดตั้งมันแล้ว) ล้วนปรับตามไปด้วยเมื่อคุณสลับธีมของ Omarchy

### แผงเอเจนต์

แถบด้านบนมีไอคอนเอเจนต์ ก่อนที่คุณจะตั้งค่าเอเจนต์ แผงของมันจะพาคุณผ่านขั้นตอนการลงชื่อเข้าใช้ Claude, Codex หรือ Grok และตัวแรกจะกลายเป็นเอเจนต์เริ่มต้นของคุณ หลังจากนั้น แผงนี้จะวางการสมัครใช้บริการทุกอันไว้ในหน้าเดียว: เอเจนต์และบัญชีแต่ละอันพร้อมแพ็กเกจของมัน มิเตอร์สำหรับขีดจำกัดเซสชัน 5 ชั่วโมงและขีดจำกัดรายสัปดาห์แต่ละอันพร้อมเวลาจนกว่าจะรีเซ็ต (วางเมาส์เหนือมันเพื่อดูเปอร์เซ็นต์ที่แน่นอน) หรือยอดคงเหลือแบบเติมเงินที่เหลืออยู่ ใต้บรรทัดหนึ่งที่หมุนเวียนแสดงสิ่งที่คุณใช้ไปในทั้งหมดนั้น เช่น โทเคนในสัปดาห์นี้และโมเดลที่คุณใช้มากที่สุด ใต้ _Make something_ มันมีพรอมต์เริ่มต้นสำหรับธีม ปลั๊กอิน หรือแอปใหม่ ซึ่งส่งงานให้เอเจนต์เริ่มต้นของคุณ แอปถูกสร้างขึ้นด้วยวิธีเดียวกับ Hype, Monologue และ Omacut ของ Omarchy เอง ใน C++ และ Qt Quick ตามสกิลเอเจนต์ omarchy-app และคอมไพเลอร์กับชิ้นส่วน Qt ที่จำเป็นก็ติดตั้งมาให้แล้ว Claude Code, Codex, Grok, Fireworks และ Kimi ได้รับการรองรับตั้งแต่ต้น ปัจจุบัน Kimi รายงานขีดจำกัดโควตาของบัญชีโดยไม่มีสถิติโทเคนหรือพรอมต์ในเครื่อง

คลิกซ้ายที่ไอคอนบนแถบเพื่อเปิดแผง คลิกขวาเพื่อเรียกใช้งานเอเจนต์เริ่มต้นของคุณ บันทึกการใช้งานเบื้องหลังมันถูกสร้างใหม่ทุก 15 นาทีโดย `omarchy agent usage-update` และแผงนี้ยังรวมการใช้งานจากเครื่องอื่นของคุณผ่านโฟลเดอร์ที่ซิงค์กันได้ด้วย ดู README ใต้ `$OMARCHY_PATH/shell/plugins/agents/` สำหรับการตั้งค่าทั้งหมด

### หลายการสมัครใช้บริการ

หากคุณจ่ายเงินสำหรับแพ็กเกจ Claude, Codex หรือ Grok มากกว่าหนึ่งแพ็กเกจ — เช่น Max ส่วนตัวหนึ่งอันและอันสำหรับงานอีกหนึ่งอัน — Omarchy สามารถคงให้ทั้งหมดลงชื่อเข้าใช้อยู่และสลับไปมาระหว่างพวกมันได้ เพิ่มการสมัครใช้บริการด้วยเครื่องหมาย + ในแผงเอเจนต์ ซึ่งจะพาคุณผ่านขั้นตอนตรงนั้นเลย หรือด้วย `omarchy agent account add claude Work` (หรือ `codex` หรือ `grok`) มันจะติดตั้ง CLI หากยังไม่มีอยู่ บัญชีแรกสำหรับผู้ให้บริการหนึ่งรายจะลงชื่อเข้าใช้ผ่านเบราว์เซอร์ปกติของคุณ ตรงที่ที่ CLI มองหาอยู่เสมอ ทุกบัญชีหลังจากนั้นจะลงชื่อเข้าใช้ผ่านหน้าต่างส่วนตัว เพื่อไม่ให้บัญชีที่เบราว์เซอร์ของคุณลงชื่อเข้าใช้อยู่แล้วถูกหยิบขึ้นมาโดยผิดพลาด ลงชื่อเข้าใช้ตรงนั้นในฐานะบัญชีที่คุณกำลังเพิ่ม และปิดหน้าต่างส่วนตัวใด ๆ ที่คุณเปิดอยู่แล้วก่อน อย่าออกจากระบบ CLI เพื่อทำสิ่งนี้เด็ดขาด: การออกจากระบบจะเพิกถอนการลงชื่อเข้าใช้ที่บันทึกไว้ และบัญชีนั้นจะต้องถูกเพิ่มใหม่อีกครั้ง

หากต้องการคัดลอกการเข้าสู่ระบบการสมัครใช้บริการของคุณไปยังเครื่อง Omarchy อีกเครื่องหนึ่งผ่าน SSH ให้รัน `omarchy agent account copy user@laptop` ผู้ส่งจะจัดหาตัวรับชั่วคราวให้เมื่อปลายทางยังไม่ได้ติดตั้งตัวรับไว้ ดังนั้นเครื่อง Omarchy รุ่นเก่ากว่าจึงรับบัญชีได้โดยไม่ต้องอัปเดต ตัวรับที่ติดตั้งไว้จะมีความสำคัญก่อน การคัดลอกนี้คัดลอกการสมัครใช้บริการ Claude, Codex และ Grok ทั้งหมด เพิ่มชื่อผู้ให้บริการเพื่อเลือกเฉพาะบางอัน เช่นใน `omarchy agent account copy laptop claude` ชื่อบัญชีและ ID คำสั่งจะตรงกับต้นทาง รวมถึงบัญชีที่มีอยู่แล้วบนปลายทาง บัญชีปลายทางที่ไม่เกี่ยวข้องจะได้รับคำต่อท้ายเป็นตัวเลขหากชื่อของมันขัดแย้งกัน และการตั้งค่า สกิล ปลั๊กอิน และประวัติการสนทนายังคงอยู่เฉพาะในแต่ละเครื่อง

ข้อมูลรับรองปลายทางที่มีอยู่เดิมจะถูกเก็บไว้ บัญชีต้นทางที่ลงชื่อเข้าใช้อยู่ที่นั่นแล้วจะมีชื่อของมันซิงค์ให้ตรงกันโดยไม่แทนที่ข้อมูลรับรองของมัน ส่วนบัญชีอื่นจะถูกเพิ่มเคียงข้างมัน หากต้องการแทนที่ข้อมูลรับรองที่บันทึกไว้สำหรับบัญชีที่ตรงกัน ให้ใช้ `omarchy agent account copy --replace laptop claude` หลังจากปิดเซสชันของบัญชีนั้นบนปลายทางแล้ว ปลายทางใหม่ยังได้รับบัญชีที่ใช้งานอยู่และการตั้งค่าการสลับบัญชีของต้นทางด้วย ส่วนปลายทางที่ตั้งค่าไว้แล้วจะคงของมันเองไว้

ข้อมูลรับรองเดินทางผ่าน SSH และถูกเก็บไว้ในไฟล์ส่วนตัวบนปลายทาง ดังนั้นจงคัดลอกไปยังเครื่องที่คุณไว้ใจเท่านั้น นี่คือการคัดลอกเพียงครั้งเดียว ไม่ใช่การซิงโครไนซ์อย่างต่อเนื่อง โทเคนรีเฟรชของ Codex อาจถูกหมุนเวียนโดยเครื่องอื่น ทำให้การเข้าสู่ระบบที่คัดลอกมาจำเป็นต้องต่ออายุ การลงชื่อเข้าใช้แยกกันยังคงเป็นทางเลือกที่เชื่อถือได้ที่สุดสำหรับการใช้งานพร้อมกันบนหลายเครื่อง ดู [คำแนะนำการยืนยันตัวตนบัญชีของ Codex](https://developers.openai.com/codex/auth/ci-cd-auth)

หนึ่งบัญชีต่อผู้ให้บริการหนึ่งรายเป็นที่ใช้งานอยู่ และทุกเซสชันใหม่จะเริ่มในฐานะบัญชีนั้น: `cx`, `cy`, `claude`, `codex` หรือ `grok` แบบธรรมดา สิ่งใดก็ตามที่เรียกใช้งานผ่าน `omarchy agent` และสคริปต์หรือตัวแก้ไขที่พบ CLI บน `PATH` สลับด้วย `omarchy agent account use work` (และสลับกลับด้วย `omarchy agent account use main`) หรือในแผงโดยกดหมายเลขของบัญชีแล้วกด `Enter` (หรือคลิกปุ่ม Use ของมัน) เซสชันที่กำลังทำงานอยู่แล้วจะยังอยู่บนบัญชีที่มันเริ่มด้วย ประวัติการสนทนา การตั้งค่า สกิล และปลั๊กอินถูกแชร์ข้ามบัญชี ดังนั้น `claude --continue` ในโฟลเดอร์เดียวกันจะสานต่อจากจุดที่คุณค้างไว้บนบัญชีใหม่

เมื่อมีมากกว่าหนึ่งบัญชี แผงจะแสดงขีดจำกัดของแต่ละบัญชีเคียงข้างกัน โดยบัญชีที่ใช้งานอยู่จะมีเครื่องหมายกำกับ ตามค่าเริ่มต้น Omarchy จะแจ้งเตือนคุณเมื่อบัญชีที่ใช้งานอยู่ผ่าน 95% ของขีดจำกัดหนึ่ง และการคลิกการแจ้งเตือนนั้นจะสลับไปยังบัญชีที่มีพื้นที่เหลือมากที่สุด วางเมาส์เหนือบรรทัดของบัญชีหนึ่งในแผงแล้วคลิก Autoswitch ที่ปรากฏข้าง Use (หรือกด `m`) หรือรัน `omarchy agent account mode auto` เพื่อให้มันสลับด้วยตัวมันเองแทน ขณะที่เปิดอยู่ Autoswitch จะเข้ามาแทนที่ Use และการคลิกมันอีกครั้งจะกลับไปเป็นการแจ้งเตือน เพิ่มตัวเลขเพื่อเปลี่ยนเกณฑ์ เช่นใน `omarchy agent account mode auto 90` หากทุกบัญชีเกินเกณฑ์ คุณจะได้รับการบอกเรื่องนั้นเพียงครั้งเดียว พร้อมกับว่าบัญชีใดจะว่างก่อน ขณะที่บัญชีที่ใช้งานอยู่ห่างจากเกณฑ์ของมันภายใน 15 จุด (80% ที่ค่าเริ่มต้น) ขีดจำกัดของมันจะถูกตรวจสอบทุกสามนาทีแทนที่จะเป็นทุก 15 นาที

`omarchy agent account list` แสดงทุกบัญชีและขีดจำกัดล่าสุดของมัน `omarchy agent account remove work` ลืมบัญชีหนึ่ง และ `omarchy agent account rename primary Hey` เปลี่ยนชื่อบัญชีหนึ่ง (หรือคลิกชื่อของบัญชีหนึ่งในแผง) คำสั่งเหล่านี้ทำงานกับบัญชีของเอเจนต์เริ่มต้นของคุณ หากต้องการไปถึงผู้ให้บริการอีกรายหนึ่ง ให้ระบุชื่อมันก่อน เช่นใน `omarchy agent account use codex side` การเข้าสู่ระบบที่คุณมีอยู่แล้วใน `~/.claude` หรือ `~/.codex` คือบัญชี _Main_ และยังคงอยู่ตรงที่ของมัน บัญชีที่ไม่ได้ใช้งานนานกว่าประมาณแปดชั่วโมงอาจแสดง _Sign-in required_ คลิกมันเพื่อลงชื่อเข้าใช้บัญชีนั้นอีกครั้งในแผงได้ทันที หรือเริ่มเซสชันในบัญชีนั้น ซึ่งจะรีเฟรชการลงชื่อเข้าใช้ด้วยตัวมันเอง เซิร์ฟเวอร์ MCP ที่คุณมีอยู่เมื่อบัญชีหนึ่งถูกเพิ่มจะติดไปกับบัญชีนั้นด้วย แต่เซิร์ฟเวอร์ที่คุณเพิ่มภายหลังด้วย `claude mcp add` จะไปถึงเฉพาะบัญชีที่คุณเพิ่มมันในบัญชีนั้นเท่านั้น Claude Desktop และเครื่องมือที่กำหนดค่าด้วยเส้นทางแบบสัมบูรณ์ไปยังไบนารี CLI จะไม่สลับตามไปด้วย `CLAUDE_CONFIG_DIR`, `CODEX_HOME` หรือ `GROK_HOME` ที่ระบุไว้ชัดเจนจะมีความสำคัญเหนือบัญชีที่เลือกไว้

### การวินิจฉัยการล่ม

Omarchy เฝ้าดู systemd-coredump สำหรับการล่มของโพรเซส เมื่อบางสิ่ง segfault คุณจะได้รับการแจ้งเตือน “Process crashed” — คลิกมัน และการล่มนั้นจะถูกส่งให้เอเจนต์เริ่มต้นของคุณพร้อมสกิล diagnose-crash ของ Omarchy ซึ่งพาเอเจนต์ผ่านขั้นตอนการสืบหาข้อเท็จจริงจาก core dump และตัดสินใจว่าการล่มนั้นคุ้มค่าที่จะรายงานไปยังต้นน้ำหรือไม่ คุณยังรันมันด้วยตัวเองกับ PID ใด ๆ จาก `coredumpctl list` ได้ด้วย `omarchy agent crash <pid>`

การเฝ้าดูนี้เปิดอยู่ตามค่าเริ่มต้น ปิดมันใน _Trigger > Toggle > Crash Capture_ (หรือด้วย `omarchy toggle crash-capture`) และการแจ้งเตือนจะหยุดลง `omarchy agent crash <pid>` ยังคงทำงานด้วยตัวเองอยู่

การล่มยังปิดเสียงได้ทีละโปรแกรมด้วย ซึ่งเป็นสิ่งที่การวินิจฉัยเสนอให้คุณในตอนท้าย `omarchy crash mute hyprland` หยุดการแจ้งเตือนสำหรับโปรแกรมนั้นเท่านั้น `omarchy crash mute hyprland off` นำพวกมันกลับมา และ `omarchy crash mute` โดยตัวมันเองจะแสดงรายการสิ่งที่คุณปิดเสียงไว้ มันรับเส้นทางของไบนารีได้ยินดีพอ ๆ กับชื่อของมัน ดังนั้น `omarchy crash mute /usr/bin/hyprland` จึงทำสิ่งเดียวกัน ใส่เครื่องหมายอัญประกาศครอบชื่อที่มีช่องว่างอยู่ เช่นใน `omarchy crash mute 'Some App'` ทุกอย่างอื่นยังคงแจ้งเตือนอยู่ และโปรแกรมที่ถูกปิดเสียงยังคงล่มอยู่ — สิ่งนี้ซ่อนตัวเตือน มันไม่ได้แก้ไขอะไรเลย

### แอปเดสก์ท็อป

เมนู _Install > AI_ ยังมีแอป AI แบบกราฟิกอยู่สองสามแอปด้วย: แอปเดสก์ท็อป ChatGPT แอปเดสก์ท็อป Claude (Linux beta ของ Anthropic ที่มีแท็บ Chat, Cowork และ Claude Code) Grok Bot สำหรับแชตกับโมเดลของ xAI, Hermes Desktop, OpenClaw และแอปเดสก์ท็อป Perplexity Grok Bot คือแอปแชตเดสก์ท็อป ส่วน coding agent คือคำสั่ง `grok`

Hermes Desktop คือตัวที่ต้องรู้เอาไว้ เพราะเครื่องหนึ่งเครื่องจะมี Hermes เพียงหนึ่งเดียว และมันเป็นของแอป: Hermes จะถูกติดตั้งผ่านแอปเท่านั้นเสมอ และคำสั่ง `hermes` ที่เอเจนต์เริ่มต้นรันก็เป็นของแอป การเลือก Hermes เป็นเอเจนต์เริ่มต้นจะติดตั้งสิ่งเดียวกับที่รายการ _Install > AI_ ติดตั้ง: แพ็กเกจ และรันไทม์ Hermes ใต้ `~/.hermes` ที่ตั้งค่าโดยตัวติดตั้งของ Hermes เอง ซึ่งใช้เวลาสองสามนาทีในครั้งแรก รันไทม์นั้นคือ Hermes เพียงหนึ่งเดียวที่คำสั่ง `hermes` ในเทอร์มินัล เอเจนต์เริ่มต้น และแอปต่างก็ใช้ และมันอัปเดตตัวมันเองด้วย `hermes update` แทนที่จะรอการเผยแพร่ Omarchy การติดตั้งมันยังมอบธีม Omarchy ให้ Hermes ในรูปแบบสกินชื่อ `omarchy` ซึ่งพื้นผิว Hermes ทุกอันจะปรับตามไปด้วยเมื่อคุณสลับธีม เลือกอีกอันหนึ่งในการตั้งค่า Appearance ของ Hermes หรือด้วย `/skin` หากคุณอยากให้มันไม่ทำเช่นนั้นมากกว่า และ Omarchy จะปล่อยทางเลือกนั้นไว้ตามเดิม การลบแอปใน _Remove > AI_ จะปิด Hermes ก่อน รวมถึง gateway ด้วย นำรันไทม์นั้นออกไปด้วย และเก็บแชต ความทรงจำ และสกิลที่ Hermes เขียนให้ตัวมันเองของคุณไว้ เว้นแต่คุณจะบอกให้มันทำอย่างอื่น: มันจะถาม โดยค่าเริ่มต้นคือไม่ ว่าข้อมูลนั้นและการตั้งค่าการเชื่อมต่อของคุณควรไปด้วยหรือไม่

ประสบการณ์เดสก์ท็อปของ OpenClaw คือ Control UI ของมัน ซึ่งเปิดขึ้นเป็นเว็บแอปที่หนุนโดย gateway ในเครื่องของมันเอง OpenClaw อาศัยอยู่ใน `~/.openclaw` และอัปเดตตัวมันเอง: ใช้ปุ่ม “Update Gateway” ของ Control UI หรือรัน `openclaw update` และ gateway จะรีสตาร์ทบนเวอร์ชันใหม่ Omarchy เลือกเพียงรุ่นที่การติดตั้งใหม่จะเริ่มจากรุ่นนั้นเท่านั้น การลบ OpenClaw ใน _Remove > AI_ จะนำบริการ gateway และแอปออกไปด้วย แล้วถามว่า `~/.openclaw` ควรไปด้วยหรือไม่ เนื่องจากที่นั้นเก็บแชตและข้อมูลรับรองของคุณไว้เคียงข้างตัว OpenClaw เองและรันไทม์ปลั๊กอินที่มันดาวน์โหลด ค่าเริ่มต้นจะเก็บมันไว้ และการติดตั้ง OpenClaw อีกครั้งจะหยิบมันกลับขึ้นมา

### LLM ในเครื่อง

Omarchy แนะนำสองวิธีในการรันโมเดล LLM ในเครื่อง: LM Studio และ Ollama LM Studio มีอินเทอร์เฟซแบบ GUI สำหรับการค้นหาโมเดลแบบ open-weight ติดตั้งมัน และรันมัน นี่คือวิธีที่ยอดเยี่ยมในการเริ่มต้นได้ง่าย ๆ Ollama มี CLI สำหรับทำสิ่งคล้ายกันนั้น แต่หากคุณเพิ่งเริ่มใช้โมเดลในเครื่อง ผมจะเริ่มด้วย LM Studio คุณสามารถติดตั้งตัวใดตัวหนึ่งได้ใน _Install > AI_ ใน Omarchy Menu

### สกิล Omarchy

สกิลของเอเจนต์ช่วยให้ AI ใช้เครื่องมือเฉพาะด้วยวิธีเฉพาะ และ Omarchy มาพร้อมสกิลเริ่มต้นสำหรับปรับแต่งระบบ เช่นการปรับการกำหนดค่า Hyprland ของคุณ ปรับแถบ หรือแม้แต่สร้างธีมใหม่ตั้งแต่ศูนย์ มันถูกทำ symlink เข้าไปในไดเรกทอรีสกิลสำหรับ Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` และแต่ละ `~/.hermes/profiles/*/skills`) และตำแหน่งทั่วไป `~/.agents/skills` ดังนั้น harness ส่วนใหญ่จึงหยิบมันขึ้นมาโดยอัตโนมัติ

แต่คุณควรปฏิบัติต่อสกิลนี้เหมือนของทดลอง โมเดลต่างกันจะใช้มันได้ผลต่างกัน วิธีที่ดีที่สุดคือรันในโหมดวางแผนก่อน เพื่อให้คุณเห็นภาพว่าเอเจนต์อยากเปลี่ยนอะไร แล้วเตรียมพร้อมที่จะย้อนกลับการเปลี่ยนแปลง หรือแม้แต่เรียกใช้ `omarchy reinstall configs` หากเอเจนต์ทำทุกอย่างเละเทะ
