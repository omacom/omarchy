### การติดตั้งและอัปเดตเอเจนต์

ยกเว้น Hermes และ OpenClaw เอเจนต์เหล่านี้ใช้การติดตั้งแบบ lazy ของ mise: การเปิดใช้ครั้งแรกจะติดตั้ง CLI และการเปิดใช้ครั้งต่อๆ ไปจะใช้ซ้ำ mise ยังตรวจสอบเอเจนต์ที่ติดตั้งแล้วว่ามีรุ่นใหม่หรือไม่ อย่างมากที่สุดหนึ่งครั้งทุกสี่ชั่วโมง ก่อนที่มันจะเริ่มทำงาน หรือในพื้นหลังที่พรอมต์ของเชลล์ หากการอัปเดตนั้นล้มเหลวหรือคุณออฟไลน์อยู่ เวอร์ชันที่ติดตั้งไว้จะทำงาน `omarchy update` อัปเดตเอเจนต์ที่ติดตั้งไว้พร้อมกับส่วนที่เหลือของ Omarchy และ `mup` อัปเดตเฉพาะเครื่องมือที่ mise จัดการเท่านั้น

ตัวอัปเดตของเอเจนต์เอง เช่น `claude update`, `codex update` หรือปุ่มอัปเดตในแอป ไม่ได้อัปเดตการติดตั้งที่ mise จัดการ `codex update` จะล้มเหลว และ `claude update` อาจรายงานว่าสำเร็จขณะที่ติดตั้งสำเนาแยกต่างหากที่ mise ไม่ได้ติดตาม หากคุณต้องการใช้ตัวติดตั้งและตัวอัปเดตดั้งเดิมของเอเจนต์มากกว่า ให้เพิ่มมันลงใน `disable_tools`; ดู [เครื่องมือ CLI ที่ติดตั้งไว้ล่วงหน้า](18-development-tools.md#preinstalled-cli-tools)

เพื่อติดตั้งเครื่องมือ lazy ที่กำหนดค่าไว้ทั้งหมดก่อนที่คุณจะต้องการใช้ ให้รัน `mise install --include-lazy` ซึ่งรวมถึงเครื่องมือ CLI เริ่มต้นอื่นๆ ของ Omarchy ด้วย รวมถึงเอเจนต์ต่างๆ ดู [เครื่องมือ CLI ที่ติดตั้งไว้ล่วงหน้า](18-development-tools.md#preinstalled-cli-tools) สำหรับการติดตั้งเครื่องมือเดียวหรือใช้การติดตั้งของคุณเอง

`grok` ติดตั้งผ่านแพ็กเกจ `grok` อย่างเป็นทางการของ mise ในแบบเดียวกับ `claude` และ `codex` รัน `grok` หรือติดดาวให้มันในแผงเอเจนต์ ข้ามตัวติดตั้ง `curl | bash` บน x.ai ไปเลย เส้นทางนั้นจะวางสำเนาที่สองไว้ใน `~/.grok/bin` เพิ่มมันไว้หน้าสุดบน `PATH` และเขียนทับตัวห่อหุ้มของ Omarchy

`dsh` เปิดอินเทอร์เฟซผู้ใช้ในเบราว์เซอร์ของมันที่ `127.0.0.1:3080` โดยใช้ไดเรกทอรีที่เปิดใช้เป็นพื้นที่ทำงานเริ่มต้น อินเทอร์เฟซผู้ใช้ในเบราว์เซอร์ของมันไม่รับพรอมต์เริ่มต้น ดังนั้น `omarchy agent prompt` จะเปิดมันพร้อมพรอมต์อยู่บนคลิปบอร์ดของคุณให้วาง Omarchy เริ่มมันด้วยพรีเซ็ตสิทธิ์แบบไม่ต้องอนุมัติของ DeepSeek DeepSeek Harness อัปโหลดบันทึกเซสชันไปยัง DeepSeek เมื่อคุณใช้ API โมเดลอย่างเป็นทางการของมัน; ปิดการทำงานนั้นได้ภายใต้ _Settings > General > Upload Session Log_ ในอินเทอร์เฟซผู้ใช้ในเบราว์เซอร์ของมัน ความคิดเห็นที่คุณส่งให้มันจะถูกอัปโหลดไปพร้อมกับเซสชันด้วย เว้นแต่คุณจะเริ่มมันด้วย `DSH_TELEMETRY_MODE=DISABLED`

### เอเจนต์เริ่มต้น

เลือกเอเจนต์เริ่มต้นของคุณด้วยดาวข้างเอเจนต์ในแผงเอเจนต์ ซึ่งจะทึบอยู่บนตัวที่เป็นค่าเริ่มต้น หรือด้วย `omarchy default agent <name>` ซึ่งรับฮาร์เนสใดๆ ที่ไม่มีบรรทัดอยู่ที่นั่นได้ด้วย หากเอเจนต์ยังไม่ได้ติดตั้ง การเลือกมันจะติดตั้งมันก่อน และมันยังได้รับตัวเรียกใช้ของตัวเองในตัวเรียกใช้แอป ข้าง Agent ด้วย Omarchy ที่ติดตั้งใหม่จะเชิญคุณให้ตั้งค่าหนึ่งตัวด้วยการแจ้งเตือนครั้งเดียว ซึ่งจะเปิดแผงเอเจนต์

การเลือก Claude ยังพยายามตั้งค่าส่วนขยายเบราว์เซอร์ของมันสำหรับ Chromium, Chrome, Brave, Brave Origin และ Edge ด้วย การตั้งค่าส่วนขยายใช้กับผู้ใช้ทุกคนและอาจขอรหัสผ่านระบบของคุณ; การยกเลิกหรือการติดตั้งส่วนขยายที่ล้มเหลวยังคงเลือกและเปิดใช้ Claude รีสตาร์ทเบราว์เซอร์ของคุณ เปิดใช้งานส่วนขยายหากได้รับแจ้ง และลงชื่อเข้าใช้ Claude เพื่อเชื่อมต่อให้เสร็จ รัน `/chrome` ใน Claude เพื่อตรวจสอบการเชื่อมต่อ Firefox และ Zen ไม่รองรับส่วนขยายนี้ หาก Claude เป็นค่าเริ่มต้นของคุณอยู่แล้วก่อนที่การตั้งค่านี้จะถูกเพิ่มเข้ามา ให้เลือกมันอีกครั้งเพื่อติดตั้งส่วนขยาย

เมื่อคุณเลือกแล้ว `Super + Shift + Ctrl + A` จะเปิดเอเจนต์เริ่มต้นในหน้าต่างเทอร์มินัลเฉพาะ (หรือเปิดตัวเลือกหากคุณยังไม่ได้เลือก) คุณยังเปิดมันให้ทำงานทันทีได้ด้วย `omarchy agent prompt "Review this project"` Freebuff และ DeepSeek Harness ไม่รับพรอมต์เริ่มต้น ดังนั้นพวกมันจะเปิดพร้อมพรอมต์อยู่บนคลิปบอร์ดของคุณให้วางแทน เอเจนต์ที่เปิดใช้ด้วยวิธีนี้จะทำงานโดยไม่มีผู้ดูแลในโหมดไม่หยุดเพื่อถามของแต่ละตัว ดังนั้นจงพร้อมให้พวกมันลงมือทำสิ่งต่างๆ จริงๆ! MiniMax Code ไม่มีโหมดดังกล่าวสำหรับเซสชันแบบโต้ตอบของมัน ดังนั้นมันจะขอสิทธิ์ตามปกติ และเนื่องจากเอเจนต์ปฏิเสธที่จะจดจำความเชื่อถือสำหรับไดเรกทอรีบ้านของคุณ การเปิดใช้จาก `$HOME` จะเริ่มใน `~/Work` แทน

ยังมีทางลัดในเทอร์มินัลด้วย: `a` รันเอเจนต์เริ่มต้นแบบอินไลน์ในเทอร์มินัลปัจจุบัน ขณะที่ `c`, `cx` และ `cy` เริ่ม OpenCode, Claude Code และ Codex โดยตรง (อีกครั้งในโหมดอนุมัติอัตโนมัติของพวกมัน) การเปลี่ยนธีมยังซิงค์ไปยังเอเจนต์ด้วย: Claude Code, Pi, OpenCode และ Hermes (เมื่อ Omarchy ติดตั้งมันแล้ว) ทั้งหมดจะเปลี่ยนตามเมื่อคุณสลับธีม Omarchy

### คำสั่งสำหรับเอเจนต์ของคุณ

กฎส่วนตัวสำหรับทุกเอเจนต์อยู่ใน `~/.agents/AGENTS.md` ข้างทักษะที่ใช้ร่วมกันใน `~/.agents/skills` เปิดมันด้วยไอคอนเอกสารข้าง + ในแผงเอเจนต์ หรือ `omarchy agent instructions --edit` ซึ่งยังเชื่อมโยงมันเข้าไปในแต่ละฮาร์เนสที่เก็บไฟล์ส่วนกลางของตัวเองไว้: `~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.pi/agent/AGENTS.md`, `~/.config/opencode/AGENTS.md`, `~/.copilot/copilot-instructions.md` ของ Copilot และอื่นๆ Crush และ Amp อ่านลิงก์ `~/.config/AGENTS.md` ขณะที่ omp, Kimi และ DeepSeek Harness อ่าน `~/.agents/AGENTS.md` โดยตรง การเลือกเอเจนต์เริ่มต้นจะเชื่อมโยงมันด้วยเช่นกัน ไฟล์คำสั่งที่คุณมีอยู่แล้วจะกลายเป็นไฟล์ที่ใช้ร่วมกันหากยังไม่มีไฟล์ดังกล่าวมาก่อน; มิฉะนั้นมันจะถูกเก็บไว้ข้างลิงก์ในชื่อ `.bak` รัน `omarchy agent instructions` เพื่อเชื่อมโยงใหม่หลังจากติดตั้งเอเจนต์อื่น

### แผงเอเจนต์

แถบด้านบนมีไอคอนเอเจนต์ ก่อนที่คุณจะตั้งค่าเอเจนต์ แผงของมันเสนอสามวิธีในการเริ่มต้น: ลงชื่อเข้าใช้การสมัครสมาชิก Claude, Codex, Grok, Gemini, Muse, Cursor หรือ Copilot หรือภายใต้ More แผนเขียนโค้ด OpenCode Go, MiniMax, Synthetic หรือ Z.ai; จ่ายตามการใช้งานจริงกับ Fireworks, OpenCode Zen and Go, OpenRouter หรือภายใต้ More DeepSeek หรือผู้ให้บริการรายอื่นที่ OpenCode ลงชื่อเข้าใช้ได้ ทั้งหมดรันใน OpenCode; หรือรันโมเดลที่ดีที่สุดสำหรับคอมพิวเตอร์ของคุณ เมื่อมีตัวที่เหมาะกับมัน ตัวแรกที่คุณทำเสร็จจะกลายเป็นเอเจนต์เริ่มต้นของคุณ และ + ในแผง หรือ _Agent > Add_ ใน Omarchy Menu เสนอสามวิธีเดียวกันในภายหลัง หลังจากนั้น แผงจะวางทุกการสมัครสมาชิกไว้ในหน้าเดียว: แต่ละเอเจนต์และบัญชีพร้อมแผนของมัน มิเตอร์สำหรับขีดจำกัดเซสชัน 5 ชั่วโมงและรายสัปดาห์ของแต่ละตัวพร้อมเวลาจนกว่าจะรีเซ็ต (วางเมาส์เหนือเพื่อดูเปอร์เซ็นต์ที่แน่นอน) หรือยอดเงินเติมเงินคงเหลือ ภายใต้บรรทัดที่หมุนเวียนสิ่งที่คุณใช้ไปในทั้งหมด เช่น โทเค็นในสัปดาห์นี้และโมเดลที่คุณใช้มากที่สุด ภายใต้ _Make something cool_ มันเสนอพรอมต์เริ่มต้นสำหรับธีม ปลั๊กอิน แอป หรือเกมใหม่ที่มอบงานให้เอเจนต์เริ่มต้นของคุณ แอปถูกสร้างในแบบเดียวกับ Hype, Monologue และ Omacut ของ Omarchy เอง ใน C++ และ Qt Quick ตามทักษะเอเจนต์ omarchy-make-app และคอมไพเลอร์กับชิ้นส่วน Qt ที่พวกมันต้องการได้รับการติดตั้งมาให้ เกมเป็นหน้า three.js หน้าเดียวใน `~/Games/vibes` ตามทักษะเอเจนต์ omarchy-make-game และทั้งหมดเปิดจากตัวเรียกใช้ Game Vibes ตัวเดียวในธีมปัจจุบัน; พวกมันโหลด three.js จากเว็บ ดังนั้นจึงต้องมีการเชื่อมต่อเพื่อเริ่มต้น Claude Code, Codex, Grok, Kimi, Cursor และโควตา Grok Bot ของมัน, GitHub Copilot, Muse, Gemini (ผ่าน Antigravity) และ Devin ได้รับการครอบคลุมตั้งแต่แรกพร้อมขีดจำกัดของพวกมัน Kimchi พร้อมแผน เครดิตเติมเงิน และงบใช้จ่ายของมัน และ Hermes, Mistral Vibe และ Qwen Code แสดงเซสชันและโทเค็นของพวกมันเมื่อคุณได้ใช้พวกมันแล้ว แผนและคีย์ของผู้ให้บริการที่คุณใช้ผ่าน pi, omp หรือ opencode ก็ปรากฏด้วยเช่นกัน: OpenCode Zen and Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan และ Synthetic พร้อมขีดจำกัดของพวกมัน; OpenRouter และ DeepSeek พร้อมยอดเงินเติมเงินของพวกมัน; Fireworks พร้อมยอดใช้จ่ายในช่วง 30 วันที่ผ่านมา โทเค็นจากโมเดลที่คุณรันบนฮาร์ดแวร์ของคุณเองก็นับรวมในยอดรวมด้วย; ตัวโมเดลเองมีแผงของตัวเอง อธิบายไว้ภายใต้ [โมเดลในเครื่อง](#local-models) ทุกเอเจนต์ถูกนับครั้งเดียว ภายใต้ผู้ที่เรียกเก็บเงินสำหรับมัน ไม่ว่าคุณจะขับมันผ่านกี่ฮาร์เนสก็ตาม

คลิกซ้ายที่ไอคอนแถบหรือกด `Super + Ctrl + X` สำหรับแผง คลิกขวาเพื่อเปิดเอเจนต์เริ่มต้นของคุณ และคลิกกลางเพื่อรีเฟรช บันทึกการใช้งานที่อยู่เบื้องหลังมันถูกสร้างใหม่ทุก 15 นาทีโดย `omarchy agent usage update` และแผงยังสามารถรวมการใช้งานจากเครื่องอื่นๆ ของคุณผ่านโฟลเดอร์ที่ซิงค์ได้ ดู README ภายใต้ `$OMARCHY_PATH/shell/plugins/agents/` สำหรับการตั้งค่าแบบเต็ม

### การสมัครสมาชิกหลายรายการ

หากคุณจ่ายสำหรับแผน Claude, Codex หรือ Grok มากกว่าหนึ่งแผน — เช่น Max ส่วนตัวและอีกอันสำหรับงาน — Omarchy สามารถให้พวกมันทั้งหมดลงชื่อเข้าใช้อยู่และย้ายไปมาระหว่างพวกมันได้ เพิ่มการสมัครสมาชิกด้วย + ในแผงเอเจนต์ ซึ่งจะพาคุณผ่านขั้นตอนตรงนั้นเลย หรือด้วย `omarchy agent account add claude Work` (หรือ `codex` หรือ `grok`) + และคำสั่งเดียวกันลงชื่อเข้าใช้ Gemini (`gemini`) และ OpenCode (`opencode`) และบันทึกคีย์ API ของ Fireworks (`fireworks`) หรือ OpenRouter (`openrouter`) ใน OpenCode; คำสั่งยังลงชื่อเข้าใช้ Copilot (`copilot`), Cursor (`cursor`) และ Muse (`muse`) ด้วย พวกนั้นเก็บการลงชื่อเข้าใช้เพียงหนึ่งรายการแต่ละตัว มันจะติดตั้ง CLI หากขาดไป บัญชีแรกสำหรับผู้ให้บริการจะลงชื่อเข้าใช้ผ่านเบราว์เซอร์ปกติของคุณ ตรงที่ที่ CLI มองหาเสมอ ทุกบัญชีหลังจากนั้นจะลงชื่อเข้าใช้ผ่านหน้าต่างส่วนตัว ดังนั้นบัญชีที่เบราว์เซอร์ของคุณลงชื่อเข้าใช้อยู่แล้วจะไม่ถูกหยิบขึ้นมาโดยผิดพลาด; ลงชื่อเข้าใช้ที่นั่นในฐานะบัญชีที่คุณกำลังเพิ่ม และปิดหน้าต่างส่วนตัวใดๆ ที่คุณเปิดไว้อยู่แล้วก่อน อย่าออกจากระบบ CLI เพื่อทำสิ่งนี้เด็ดขาด: การออกจากระบบจะเพิกถอนการลงชื่อเข้าใช้ที่บันทึกไว้ และบัญชีนั้นจะต้องถูกเพิ่มอีกครั้ง

เพื่อคัดลอกการเข้าสู่ระบบการสมัครสมาชิกของคุณไปยังเครื่อง Omarchy อื่นผ่าน SSH ให้รัน `omarchy agent account copy user@laptop` ผู้ส่งจะจัดหาตัวรับชั่วคราวเมื่อปลายทางยังไม่ได้ติดตั้งไว้ ดังนั้นเครื่อง Omarchy รุ่นเก่ากว่าสามารถรับบัญชีได้โดยไม่ต้องอัปเดต ตัวรับที่ติดตั้งไว้จะมีลำดับความสำคัญกว่า สิ่งนี้คัดลอกการสมัครสมาชิก Claude, Codex และ Grok ทั้งหมด; เพิ่มชื่อผู้ให้บริการเพื่อเลือกพวกมัน เช่นใน `omarchy agent account copy laptop claude` ชื่อบัญชีและ ID คำสั่งตรงกับต้นทาง รวมถึงบัญชีที่มีอยู่แล้วบนปลายทาง บัญชีปลายทางที่ไม่เกี่ยวข้องจะได้รับคำต่อท้ายเป็นตัวเลขหากชื่อของพวกมันขัดกัน และการตั้งค่า ทักษะ ปลั๊กอิน และประวัติการสนทนาจะยังคงอยู่ในเครื่องแต่ละเครื่อง

ข้อมูลประจำตัวปลายทางที่มีอยู่จะถูกเก็บไว้ บัญชีต้นทางที่ลงชื่อเข้าใช้อยู่ที่นั่นแล้วจะมีชื่อของมันซิงค์โดยไม่แทนที่ข้อมูลประจำตัวของมัน; บัญชีอื่นๆ จะถูกเพิ่มควบคู่ไปกับมัน เพื่อแทนที่ข้อมูลประจำตัวที่บันทึกไว้สำหรับบัญชีที่ตรงกัน ให้ใช้ `omarchy agent account copy --replace laptop claude` หลังจากออกจากเซสชันของบัญชีนั้นบนปลายทางแล้ว ปลายทางใหม่ยังได้รับบัญชีที่ใช้งานอยู่และการตั้งค่าการสลับของต้นทางด้วย; ปลายทางที่ตั้งค่าไว้แล้วจะเก็บของตัวเองไว้

ข้อมูลประจำตัวเดินทางผ่าน SSH และถูกเก็บไว้ในไฟล์ส่วนตัวบนปลายทาง ดังนั้นให้คัดลอกไปยังเครื่องที่คุณเชื่อถือเท่านั้น นี่เป็นการคัดลอกครั้งเดียว ไม่ใช่การซิงโครไนซ์อย่างต่อเนื่อง โทเค็นรีเฟรชของ Codex สามารถถูกหมุนเวียนโดยเครื่องอื่น ทำให้การเข้าสู่ระบบที่คัดลอกมาต้องต่ออายุ; การลงชื่อเข้าใช้แยกกันยังคงเป็นตัวเลือกที่น่าเชื่อถือที่สุดสำหรับการใช้งานพร้อมกันบนหลายเครื่อง ดู [คำแนะนำการยืนยันตัวตนบัญชีของ Codex](https://developers.openai.com/codex/auth/ci-cd-auth)

หนึ่งบัญชีต่อผู้ให้บริการจะใช้งานอยู่ และทุกเซสชันใหม่จะเริ่มในฐานะบัญชีนั้น: `cx`, `cy`, `claude`, `codex` หรือ `grok` ธรรมดา อะไรก็ตามที่เปิดผ่าน `omarchy agent` และสคริปต์หรือโปรแกรมแก้ไขที่พบ CLI บน `PATH` สลับด้วย `omarchy agent account use work` (และกลับด้วย `omarchy agent account use main`) หรือในแผงโดยกดหมายเลขของบัญชีแล้วกด `Enter` (หรือคลิกดาวของมัน) เซสชัน Claude ที่กำลังรันอยู่จะสลับด้วย ตั้งแต่ข้อความถัดไปของพวกมัน: ทุกเซสชัน Claude รันใน `~/.claude` ซึ่งเก็บการลงชื่อเข้าใช้ของบัญชีที่ใช้งานอยู่เสมอ เซสชัน Claude ที่เริ่มในโฟลเดอร์ของบัญชีเองโดย Omarchy รุ่นเก่ากว่าจะเก็บการลงชื่อเข้าใช้นั้นไว้จนกว่าจะออก ดังนั้นการสลับจะระบุชื่อเซสชันเหล่านั้นและเสร็จสิ้นเองเมื่อพวกมันหายไป เซสชัน Codex และ Grok ที่กำลังรันอยู่จะยังคงอยู่บนบัญชีที่พวกมันเริ่มด้วย ประวัติการสนทนา การตั้งค่า ทักษะ และปลั๊กอินถูกใช้ร่วมกันระหว่างบัญชี ดังนั้น `claude --continue` ในโฟลเดอร์เดียวกันจะดำเนินการต่อจากจุดที่คุณค้างไว้บนบัญชีใหม่

เมื่อมีมากกว่าหนึ่งบัญชี แผงจะแสดงขีดจำกัดของแต่ละบัญชีเคียงข้างกัน โดยมีดาวทึบอยู่บนบัญชีที่ใช้งานอยู่ Omarchy จะแจ้งเตือนคุณเมื่อบัญชีที่ใช้งานอยู่ผ่าน 95% ของขีดจำกัด และการคลิกการแจ้งเตือนจะสลับไปยังบัญชีที่มีพื้นที่เหลือมากที่สุด มันจะไม่สลับเองเด็ดขาด เปลี่ยนเกณฑ์ด้วย `omarchy agent account threshold 90` หากทุกบัญชีเกินเกณฑ์ คุณจะได้รับแจ้งครั้งเดียว พร้อมกับว่าบัญชีใดจะว่างก่อน ขณะที่บัญชีที่ใช้งานอยู่ภายใน 15 จุดจากเกณฑ์ของมัน (80% ที่ค่าเริ่มต้น) ขีดจำกัดของมันจะถูกตรวจสอบทุกสามนาทีแทนที่จะเป็นทุก 15 นาที

`omarchy agent account list` แสดงทุกบัญชีและขีดจำกัดล่าสุดของพวกมัน `omarchy agent account remove work` ลืมหนึ่งบัญชี และ `omarchy agent account rename primary Hey` เปลี่ยนชื่อหนึ่งบัญชี (หรือคลิกชื่อบัญชีในแผง) คำสั่งเหล่านี้ทำงานบนบัญชีของเอเจนต์เริ่มต้นของคุณ; เพื่อเข้าถึงผู้ให้บริการอื่น ให้ระบุชื่อมันก่อน เช่นใน `omarchy agent account use codex side` การเข้าสู่ระบบที่คุณมีอยู่แล้วใน `~/.claude` หรือ `~/.codex` คือบัญชี _Main_ ของ Codex จะอยู่ที่เดิม; ของ Claude จะรออยู่ในโฟลเดอร์ของตัวเองขณะที่บัญชีอื่นใช้งานอยู่ บัญชีที่ไม่ได้ใช้เป็นเวลามากกว่าประมาณแปดชั่วโมงสามารถแสดง _Sign-in required_; คลิกมันเพื่อลงชื่อบัญชีนั้นเข้าใช้อีกครั้งในแผงเลย หรือสลับไปยังมันและเริ่มเซสชัน ซึ่งจะรีเฟรชการลงชื่อเข้าใช้เอง เซิร์ฟเวอร์ MCP ที่คุณเพิ่มด้วย `claude mcp add` จะเข้าถึงทุกบัญชี Claude เนื่องจากพวกมันทั้งหมดรันใน `~/.claude`; สำหรับ Codex และ Grok เซิร์ฟเวอร์ที่คุณมีเมื่อบัญชีถูกเพิ่มจะตามไปยังบัญชีนั้น แต่เซิร์ฟเวอร์ในภายหลังจะเข้าถึงเฉพาะบัญชีที่คุณเพิ่มพวกมันในนั้น Claude Desktop เก็บการลงชื่อเข้าใช้ของตัวเอง และเครื่องมือ Codex หรือ Grok ที่กำหนดค่าด้วยเส้นทางสัมบูรณ์ไปยังไบนารี CLI จะไม่ตามการสลับ ตัวแปร `CLAUDE_CONFIG_DIR`, `CODEX_HOME` หรือ `GROK_HOME` ที่ชัดเจนจะมีลำดับความสำคัญเหนือบัญชีที่เลือก

### การวินิจฉัยการขัดข้อง

Omarchy เฝ้าดู systemd-coredump สำหรับการขัดข้องของกระบวนการ เมื่อคุณเลือกเอเจนต์เริ่มต้นแล้ว โปรแกรมใดๆ ของคุณที่ dumps core จะนำการแจ้งเตือน "Process crashed" มา — คลิกมัน และการขัดข้องจะถูกส่งให้เอเจนต์เริ่มต้นของคุณพร้อมกับทักษะ omarchy-diagnose-crash ของ Omarchy ซึ่งจะพาเอเจนต์ผ่านการสร้างข้อเท็จจริงจาก core dump และตัดสินใจว่าการขัดข้องนั้นคุ้มค่าที่จะรายงานไปยังต้นน้ำหรือไม่ คุณยังรันมันด้วยตนเองกับ PID ใดๆ จาก `coredumpctl list` ด้วย `omarchy agent crash <pid>` ได้ด้วย

การเฝ้าดูเปิดอยู่ตามค่าเริ่มต้น ปิดมันภายใต้ _Trigger > Toggle > Crash Capture Off_ (หรือด้วย `omarchy toggle crash-capture`) และการแจ้งเตือนจะหยุด; `omarchy agent crash <pid>` ยังคงทำงานด้วยตนเอง

การขัดข้องยังสามารถปิดเสียงได้ทีละโปรแกรม ซึ่งเป็นสิ่งที่การวินิจฉัยเสนอให้คุณในตอนท้าย `omarchy crash mute hyprland` หยุดการแจ้งเตือนสำหรับโปรแกรมนั้นเท่านั้น `omarchy crash mute hyprland off` นำพวกมันกลับมา และ `omarchy crash mute` เพียงอย่างเดียวจะแสดงรายการสิ่งที่คุณปิดเสียงไว้ มันรับเส้นทางของไบนารีได้พอๆ กับชื่อของมัน ดังนั้น `omarchy crash mute /usr/bin/hyprland` ทำสิ่งเดียวกัน ใส่เครื่องหมายคำพูดรอบชื่อที่มีช่องว่าง เช่นใน `omarchy crash mute 'Some App'` ทุกอย่างอื่นยังคงแจ้งเตือน และโปรแกรมที่ปิดเสียงยังคงขัดข้อง — สิ่งนี้ซ่อนการเตือน มันไม่ได้แก้ไขอะไรเลย

### แอปบนเดสก์ท็อป

เมนู _Install > AI_ ยังมีแอป AI แบบกราฟิกอยู่สองสามตัว: Amp Desktop, Antigravity Desktop, แอปเดสก์ท็อป ChatGPT, แอปเดสก์ท็อป Claude (เบต้า Linux ของ Anthropic พร้อมแท็บ Chat, Cowork และ Claude Code), Grok Bot สำหรับแชทกับโมเดลของ xAI, Herdr Desktop, Hermes Desktop, OpenClaw, แอปเดสก์ท็อป Perplexity และ T3 Code Grok Bot คือแอปแชทบนเดสก์ท็อป เอเจนต์เขียนโค้ดคือคำสั่ง `grok`

Hermes Desktop เป็นตัวที่ต้องรู้ เพราะเครื่องหนึ่งมี Hermes เดียว และมันเป็นของแอป: Hermes ถูกติดตั้งผ่านแอปเท่านั้นเสมอ และคำสั่ง `hermes` ที่เอเจนต์เริ่มต้นรันคือของแอป การเลือก Hermes เป็นเอเจนต์เริ่มต้นจะติดตั้งสิ่งเดียวกับที่รายการ _Install > AI_ ติดตั้ง: แพ็กเกจ และรันไทม์ Hermes ภายใต้ `~/.hermes` ที่ตั้งค่าโดยตัวติดตั้งของ Hermes เอง ซึ่งใช้เวลาสองสามนาทีในครั้งแรก รันไทม์นั้นคือ Hermes ตัวเดียวที่คำสั่ง `hermes` ในเทอร์มินัล เอเจนต์เริ่มต้น และแอปทั้งหมดใช้ และมันอัปเดตตัวเองด้วย `hermes update` แทนที่จะรอการเปิดตัว Omarchy การติดตั้งมันยังมอบธีม Omarchy ให้ Hermes เป็นสกินชื่อ `omarchy` ซึ่งทุกพื้นผิวของ Hermes จะตามเมื่อคุณสลับธีม; เลือกอย่างอื่นภายใต้การตั้งค่า Appearance ของ Hermes หรือด้วย `/skin` หากคุณไม่ต้องการให้มันทำเช่นนั้น และ Omarchy จะปล่อยตัวเลือกนั้นไว้ตามเดิม การลบแอปภายใต้ _Remove > AI_ จะปิด Hermes ก่อน รวมถึงเกตเวย์ นำรันไทม์นั้นไปด้วย และเก็บแชท ความทรงจำ และทักษะที่ Hermes เขียนให้ตัวเองของคุณไว้ เว้นแต่คุณจะบอกเป็นอย่างอื่น: มันจะถาม โดยค่าเริ่มต้นคือไม่ ว่าข้อมูลนั้นและการตั้งค่าการเชื่อมต่อของคุณควรหายไปด้วยหรือไม่

ประสบการณ์บนเดสก์ท็อปของ OpenClaw คือ Control UI ของมัน ซึ่งเปิดเป็นเว็บแอปที่ได้รับการสนับสนุนโดยเกตเวย์ในเครื่องของตัวเอง OpenClaw อยู่ใน `~/.openclaw` และอัปเดตตัวเอง: ใช้ปุ่ม "Update Gateway" ของ Control UI หรือรัน `openclaw update` และเกตเวย์จะรีสตาร์ทบนเวอร์ชันใหม่ Omarchy เลือกเฉพาะรุ่นที่การติดตั้งใหม่เริ่มต้นจากเท่านั้น OpenClaw ยังสามารถเป็นเอเจนต์เริ่มต้นของคุณได้: การเลือกมันภายใต้ _Agent > Harness_ จะตั้งค่าสำเนาเดียวกันนั้นใน `~/.openclaw` และเอเจนต์จะเปิดอินเทอร์เฟซผู้ใช้ในเทอร์มินัลของ OpenClaw ที่เชื่อมต่อกับเกตเวย์ของมัน การลบ OpenClaw ภายใต้ _Remove > AI_ จะนำบริการเกตเวย์และแอปไปด้วย จากนั้นถามว่า `~/.openclaw` ควรหายไปด้วยหรือไม่ เนื่องจากที่นั่นเก็บแชทและข้อมูลประจำตัวของคุณควบคู่ไปกับ OpenClaw เองและรันไทม์ปลั๊กอินที่มันดาวน์โหลด; ค่าเริ่มต้นจะเก็บมันไว้ และการติดตั้ง OpenClaw อีกครั้งจะหยิบมันกลับมา

Herdr Desktop คือแอปเดสก์ท็อป [Herdr](https://herdr.dev): พื้นที่ แท็บ และบานหน้าต่างของเทอร์มินัลและเอเจนต์เขียนโค้ดที่ยังคงทำงานในแกนหลักของมันเมื่อคุณปิดหน้าต่าง มันมาจากตัวติดตั้งของ Herdr เองแทนที่จะเป็นแพ็กเกจ ดังนั้นมันอยู่ใน `~/.local/share/herdr-app` นำแกนหลักของมันมาใน `~/.local/bin/herdr-core` เมื่อคุณยังไม่มี และอัปเดตทั้งสองอย่างเอง มันอยู่ข้างคำสั่ง `herdr` ที่ Omarchy จัดส่งบน `Super + Ctrl + Return` แทนที่จะแทนที่มัน และได้รับคีย์โดยตรงของคำสั่งนั้น: `Alt + Return` และ `Alt + Shift + Return` แยกบานหน้าต่างลงหรือไปขวา `Alt + Escape` ปิดมัน `Ctrl + Alt + Arrow` ย้ายระหว่างบานหน้าต่าง `Alt + 1..9` และ `Alt + Left/Right` เลือกแท็บ และ `Alt + Up/Down` ย้ายระหว่างพื้นที่ `Ctrl + 1..9` เลือกพื้นที่และ `Alt + Shift + Up/Down` ก้าวผ่านเอเจนต์ คีย์นำหน้า `Ctrl + Space` ยังคงเป็นเฉพาะเทอร์มินัล เนื่องจากแอปไม่สามารถถือคีย์ Ctrl ธรรมดาไว้สำหรับลำดับได้ Omarchy เขียนสิ่งเหล่านี้ไปยัง `~/.config/herdr-app/keys.json` และ `omarchy-refresh-herdr-app` จะนำพวกมันกลับมา การติดตั้งมันจะเลือกธีม Omarchy ของ Herdr ซึ่งจะตามธีม Omarchy ของคุณต่อจากนั้น Herdr เก็บธีมหนึ่งสำหรับโหมดสว่างและอีกหนึ่งสำหรับโหมดมืด ดังนั้นหลังจากสลับระหว่างธีม Omarchy แบบมืดและแบบสว่าง ให้เลือก Omarchy ในตัวเลือกธีมของ Herdr อีกครั้งสำหรับอีกโหมดหนึ่ง

T3 Code รันจากรุ่น AppImage อย่างเป็นทางการใน `~/.local/share/t3code` แทนที่จะเป็นจากแพ็กเกจ ดังนั้นมันจึงอัปเดตตัวเอง การติดตั้งมันจะถามว่าจะเริ่มบนช่อง Stable หรือ Nightly; สลับในภายหลังในการตั้งค่าของ T3 Code เธรดและการตั้งค่าของคุณอยู่ใน `~/.t3` และการลบ T3 Code ภายใต้ _Remove > AI_ จะนำพวกมันไปด้วย

### โมเดลในเครื่อง

รันโมเดลแบบเปิดบนเครื่องของคุณเองสำหรับเอเจนต์เขียนโค้ดของคุณ พรอมต์และโค้ดของคุณอยู่บนเครื่อง; ไม่มีอะไรที่ส่งให้โมเดลออกจากเครื่อง เริ่มต้นด้วย:

```bash
omarchy models use best text
```

นั่นตั้งค่าโมเดลข้อความที่ดีที่สุดสำหรับเครื่องนี้ ชนิดที่เอเจนต์ของคุณใช้ โมเดลภาพ วิดีโอ และเพลงมีตัวที่ดีที่สุดของตัวเอง: `omarchy models use best image`, `video` หรือ `music` รัน `omarchy models use best` เพื่อดูตัวเลือกของแต่ละชนิดสำหรับเครื่องนี้

หรือเปิดแผงโมเดลในเครื่องจากไอคอนประกายของมันในแถบด้านบน ข้างไอคอนเอเจนต์ หรือด้วย Super + Ctrl + Alt + X และเลือก + ไอคอนจะปรากฏเมื่อมีโมเดลที่เหมาะกับเครื่องนี้ Podman ซึ่งรันโมเดล มาพร้อม Omarchy เช่นเดียวกับชุดเครื่องมือคอนเทนเนอร์ของ NVIDIA บนเครื่อง NVIDIA ซึ่งให้ GPU แก่พวกมัน; หากอย่างใดอย่างหนึ่งขาดไป การตั้งค่าครั้งแรกจะติดตั้งมัน จากนั้น Omarchy จะเลือกโมเดลที่แนะนำสำหรับเครื่องนี้ ดาวน์โหลดมัน และเริ่มมัน คาดว่าจะมีการดาวน์โหลดหลายสิบ GB และหน่วยความจำของเครื่องส่วนใหญ่จะถูกใช้ขณะโมเดลทำงาน: Flash Next ใช้ประมาณ 100 GiB กับบริบทเต็ม 256K ของมัน หากโมเดลอื่นถือหน่วยความจำที่มันต้องการ มันจะถูกตั้งค่าในสถานะหยุด พร้อมเริ่มเมื่อคุณหยุดตัวหนึ่ง โมเดลจะหยุดเมื่อออกจากระบบ; หยุดมันด้วยตัวเองเมื่อคุณต้องการหน่วยความจำสำหรับอย่างอื่น

`omarchy models list` แสดงตัวเลือกและอธิบายว่าทำไมบางตัวไม่เหมาะ เพื่อตั้งค่าอีกตัว ให้รัน `omarchy models use <recipe>` วันนี้ `qwen3.8-flash-next-gufo` และ `qwen3.8-27b-gufo` พร้อมใช้งานสำหรับเครื่อง Strix Halo 128 GB; ตัว 27B ใช้ประมาณ 40 GiB ดังนั้นจึงเหลือพื้นที่สำหรับงานอื่น บนแล็ปท็อป 64 GB ที่มี Arc B390 ของ Intel `qwen3.6-35b-a3b-llamacpp` รันในประมาณ 30 GiB สูตรและคำแนะนำใหม่มาพร้อม `omarchy update` ผ่านแพ็กเกจ

ทุกโมเดลที่คุณตั้งค่าจะได้รับบรรทัดของตัวเองในแผงโมเดลในเครื่อง: เล่นเพื่อเริ่มมัน หยุดชั่วคราวเพื่อหยุดมันและปลดปล่อยหน่วยความจำของมัน และปุ่มเทอร์มินัลเพื่อเปิดเอเจนต์ของคุณบนมัน ทั่วด้านบน แถบแสดงว่าหน่วยความจำของเครื่องแบ่งอย่างไรระหว่าง Omarchy เอง (ระบบและแอปของคุณ) แต่ละโมเดลที่กำลังทำงาน และสิ่งที่ว่าง ชี้ไปที่โมเดลที่หยุดอยู่และแถบจะแสดงว่ามันเหมาะหรือไม่ หรือขาดไปเท่าไหร่ หลายตัวสามารถรันพร้อมกันได้เมื่อพวกมันพอดีในหน่วยความจำด้วยกัน; หากตัวหนึ่งไม่เหมาะ Omarchy จะบอกว่าต้องหยุดโมเดลที่กำลังทำงานตัวใด ลากบรรทัดโดยโลโก้ของพวกมันเพื่อจัดลำดับใหม่ และกด Delete บนบรรทัดที่เลือกเพื่อลบโมเดลและการดาวน์โหลดของมัน

ทุกโมเดลเขียนโค้ดที่คุณตั้งค่ายังได้รับรายการของตัวเองในตัวเรียกใช้แอป ภายใต้ชื่อของโมเดลและพร้อมโลโก้ของผู้สร้างมัน ในแบบเดียวกับการลงชื่อเข้าใช้ Claude, Codex หรือ Grok เพิ่มรายการหนึ่ง มันเปิดเอเจนต์ของคุณบนโมเดลนั้น และเริ่มโมเดลก่อนหากมันยังไม่ได้ทำงาน: เทอร์มินัลแสดงมันกำลังโหลดและส่งมอบให้เอเจนต์เมื่อมันพร้อม การลบโมเดลจะลบรายการของมัน

ไม่ใช่ทุกโมเดลสำหรับเขียนโค้ด โมเดลภาพ วิดีโอ และเพลงเปิดใน Fantasi แทน แอปของ Omarchy สำหรับสร้างภาพ วิดีโอ และเพลงด้วยโมเดลที่ทำงานบนเครื่องนี้ เลือกที่นั่นหรือจากบรรทัดของพวกมันในแผงโมเดลในเครื่อง

โมเดลจะทำงานต่อไปอย่างที่มันถูกตั้งค่าไว้ ดังนั้นการอัปเดต Omarchy จะไม่รีสตาร์ทตัวหนึ่งภายใต้เอเจนต์ของคุณ เมื่อ Omarchy มีรันไทม์ใหม่กว่าหรือเวทใหม่กว่าสำหรับโมเดลที่คุณตั้งค่าไว้ บรรทัดของมันจะแสดงปุ่มอัปเดต: กดมันและโมเดลจะถูกตั้งค่าใหม่ในพื้นหลัง ดาวน์โหลดเฉพาะสิ่งที่เปลี่ยนแปลง และรีสตาร์ทบนเวอร์ชันใหม่ โมเดลที่หยุดอยู่จะยังคงหยุดอยู่ `omarchy models update` ทำสิ่งเดียวกันสำหรับทุกโมเดลจากเทอร์มินัล

จากบรรทัดคำสั่ง `omarchy models start <recipe>` และ `omarchy models stop <recipe>` ทำสิ่งเดียวกัน `omarchy models status` แสดงทุกโมเดล และ `omarchy agent --local-model <recipe>` เปิดโมเดลนั้นใน pi ไม่ว่าเอเจนต์เริ่มต้นของคุณจะเป็นอะไร เพื่อทำให้โมเดลในเครื่องของคุณเป็นสิ่งที่ปุ่มลัดเอเจนต์ คอนโซล Quake และ _Make something_ เปิด ให้รัน `omarchy default agent local` หรือเลือก _Local model_ ภายใต้ _Agent > Harness_ pi ยังแสดงรายการทุกโมเดลที่คุณตั้งค่าไว้ และโมเดลบนเครื่องที่คุณจับคู่ด้วย ในตัวเลือกโมเดลของตัวเอง ดังนั้น `pi` ธรรมดาก็เข้าถึงพวกมันได้เช่นกัน ไคลเอนต์ที่เข้ากันได้กับ OpenAI ใดๆ ก็เชื่อมต่อได้เช่นกัน: `status` แสดงที่อยู่ของแต่ละโมเดล (ตัวแรกคือ `http://127.0.0.1:11435/v1`) ชื่อสูตรคือโมเดล และคีย์อยู่ใน `~/.config/omarchy/agent-local/key`

`omarchy models remove <recipe>` ลบโมเดลและการดาวน์โหลดที่ไม่มีโมเดลอื่นใช้

รันไทม์ของบุคคลที่สามจะระบุชื่อผู้เผยแพร่ของพวกมัน Omarchy รันทุกโมเดลโดยไม่มีการเข้าถึงเครือข่าย

### LLM ในเครื่อง

Omarchy แนะนำสองวิธีในการรันโมเดล LLM ในเครื่อง: LM Studio และ Ollama LM Studio จัดหาอินเทอร์เฟซ GUI สำหรับค้นหาโมเดลแบบเปิด ติดตั้งพวกมัน และรันพวกมัน เป็นวิธีที่ดีในการเริ่มต้นได้ง่ายๆ Ollama เสนอ CLI สำหรับทำเช่นเดียวกัน แต่หากคุณเพิ่งเริ่มใช้โมเดลในเครื่อง ผมจะเริ่มด้วย LM Studio คุณสามารถติดตั้งอย่างใดอย่างหนึ่งได้ภายใต้ _Install > AI_ ใน Omarchy Menu

### ทักษะ Omarchy

ทักษะเอเจนต์ช่วยให้ AI ใช้เครื่องมือเฉพาะในวิธีเฉพาะ และ Omarchy จัดส่งเจ็ดทักษะ ทักษะ omarchy ครอบคลุมการปรับแต่งระบบ เช่น การปรับ config Hyprland ของคุณหรือปรับแถบ omarchy-make-theme, omarchy-make-plugin, omarchy-make-app และ omarchy-make-game ครอบคลุมการสร้างสิ่งใหม่ omarchy-contribute ครอบคลุมการรายงานบั๊กหรือส่งการแก้ไขไปยังต้นน้ำ และ omarchy-diagnose-crash ทำงานผ่าน core dump ของการขัดข้อง พวกมันถูกเชื่อมโยงแบบ symlink เข้าไปในไดเรกทอรีทักษะสำหรับ Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` และแต่ละ `~/.hermes/profiles/*/skills`) และตำแหน่งทั่วไป `~/.agents/skills` ดังนั้นฮาร์เนสส่วนใหญ่จึงหยิบพวกมันขึ้นมาโดยอัตโนมัติ โฟลเดอร์ทักษะของคุณเองที่มีชื่อเดียวกันจะมีลำดับความสำคัญกว่า

แต่คุณควรปฏิบัติต่อทักษะเหล่านี้เสมือนเป็นการทดลอง โมเดลต่างๆ จะใช้มันให้เกิดผลต่างกัน เป็นการดีที่สุดที่จะรันในโหมดวางแผนก่อน เพื่อให้คุณมีแนวคิดว่าเอเจนต์ต้องการเปลี่ยนอะไร จากนั้นจงพร้อมที่จะย้อนกลับการเปลี่ยนแปลง หรือแม้กระทั่งเรียกใช้ `omarchy reinstall configs` หากเอเจนต์ทำทุกอย่างเละเทะ
