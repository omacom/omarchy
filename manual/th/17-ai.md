### การติดตั้งและอัปเดตเอเจนต์

ยกเว้น Hermes เอเจนต์เหล่านี้ใช้การติดตั้งแบบขี้เกียจของ mise: การเรียกใช้ครั้งแรกจะติดตั้ง CLI และการเรียกใช้ครั้งต่อๆ ไปจะใช้ตัวที่ติดตั้งแล้วซ้ำ mise ยังตรวจสอบเอเจนต์ที่ติดตั้งแล้วว่ามีรุ่นใหม่หรือไม่ อย่างมากที่สุดหนึ่งครั้งทุกสี่ชั่วโมง ก่อนที่มันจะเริ่มทำงาน หรือในเบื้องหลังที่พรอมต์ของเชลล์ หากการอัปเดตนั้นล้มเหลวหรือคุณออฟไลน์อยู่ รุ่นที่ติดตั้งไว้จะทำงาน `omarchy update` อัปเดตเอเจนต์ที่ติดตั้งแล้วไปพร้อมกับส่วนที่เหลือของ Omarchy และ `mup` อัปเดตเฉพาะเครื่องมือที่ mise จัดการเท่านั้น

ตัวอัปเดตของเอเจนต์เอง เช่น `claude update`, `codex update` หรือปุ่มอัปเดตในแอป ไม่ได้อัปเดตตัวที่ติดตั้งโดย mise จัดการ `codex update` จะล้มเหลว และ `claude update` อาจรายงานว่าสำเร็จในขณะที่ติดตั้งสำเนาแยกต่างหากที่ mise ไม่ได้ติดตาม หากคุณอยากใช้ตัวติดตั้งและตัวอัปเดตแบบดั้งเดิมของเอเจนต์มากกว่า ให้เพิ่มมันเข้าไปใน `disable_tools`; ดู [เครื่องมือ CLI ที่ติดตั้งมาพร้อม](18-development-tools.md#preinstalled-cli-tools)

ในการติดตั้งเครื่องมือแบบขี้เกียจที่ตั้งค่าไว้ทั้งหมดก่อนที่คุณจะต้องการใช้ ให้รัน `mise install --include-lazy` ซึ่งรวมถึงเครื่องมือ CLI เริ่มต้นตัวอื่นๆ ของ Omarchy นอกเหนือจากเอเจนต์ด้วย ดู [เครื่องมือ CLI ที่ติดตั้งมาพร้อม](18-development-tools.md#preinstalled-cli-tools) สำหรับการติดตั้งเครื่องมือตัวเดียวหรือใช้การติดตั้งของคุณเอง

`grok` ติดตั้งผ่านแพ็กเกจ `grok` โดยตรงของ mise ในแบบเดียวกับ `claude` และ `codex` รัน `grok` หรือเลือกมันใต้ _Setup > Defaults > Agent_ ข้ามตัวติดตั้ง `curl | bash` บน x.ai ไปเลย เส้นทางนั้นจะวางสำเนาที่สองไว้ใน `~/.grok/bin`, แทรกมันไว้หน้าสุดบน `PATH` และเขียนทับ wrapper ของ Omarchy

`dsh` เปิด UI บนเบราว์เซอร์ของมันที่ `127.0.0.1:3080` โดยใช้ไดเรกทอรีที่เรียกใช้เป็น workspace เริ่มต้น UI บนเบราว์เซอร์ของมันไม่รับพรอมต์เริ่มต้น ดังนั้น `omarchy agent prompt` จะเปิดมันโดยวางพรอมต์ไว้บนคลิปบอร์ดของคุณให้แปะเอง Omarchy เริ่มมันด้วยชุดสิทธิ์แบบไม่ต้องขออนุมัติของ DeepSeek DeepSeek Harness อัปโหลดบันทึกเซสชันไปยัง DeepSeek เมื่อคุณใช้ API โมเดลอย่างเป็นทางการของมัน; ปิดสิ่งนั้นได้ใต้ _Settings > General > Upload Session Log_ ใน UI บนเบราว์เซอร์ของมัน ความคิดเห็นที่คุณส่งไปก็จะถูกอัปโหลดไปพร้อมกับเซสชันด้วย เว้นแต่คุณจะเริ่มมันด้วย `DSH_TELEMETRY_MODE=DISABLED`

### เอเจนต์เริ่มต้น

เลือกเอเจนต์เริ่มต้นของคุณด้วย `omarchy default agent <name>` หรือใต้ _Setup > Defaults > Agent_ ใน Omarchy Menu (`Super + Space`) หากเอเจนต์ยังไม่ได้ติดตั้ง การเลือกมันจะติดตั้งมันก่อน Omarchy ที่ติดตั้งใหม่จะชวนให้คุณเลือกสิ่งนี้ด้วยการแจ้งเตือนเพียงครั้งเดียว

การเลือก Claude ยังพยายามตั้งค่าส่วนขยายเบราว์เซอร์ของมันสำหรับ Chromium, Chrome, Brave, Brave Origin และ Edge ด้วย การตั้งค่าส่วนขยายใช้กับผู้ใช้ทุกคนและอาจขอรหัสผ่านระบบของคุณ; การยกเลิกหรือการติดตั้งส่วนขยายที่ล้มเหลวยังคงเลือกและเรียกใช้ Claude ต่อไป รีสตาร์ทเบราว์เซอร์ของคุณ เปิดใช้งานส่วนขยายหากได้รับแจ้ง และลงชื่อเข้าใช้ Claude เพื่อเชื่อมต่อให้เสร็จ รัน `/chrome` ใน Claude เพื่อตรวจสอบการเชื่อมต่อ Firefox และ Zen ไม่รองรับส่วนขยายนี้ หาก Claude เป็นเอเจนต์เริ่มต้นของคุณอยู่แล้วก่อนที่จะมีการเพิ่มการตั้งค่านี้ ให้เลือกมันอีกครั้งเพื่อติดตั้งส่วนขยาย

เมื่อคุณเลือกแล้ว `Super + Shift + Ctrl + A` จะเรียกใช้เอเจนต์เริ่มต้นในหน้าต่างเทอร์มินัลเฉพาะ (หรือเปิดตัวเลือกขึ้นมาหากคุณยังไม่ได้เลือก) คุณยังเรียกใช้มันตรงเข้าสู่งานได้ด้วย `omarchy agent prompt "Review this project"` Freebuff และ DeepSeek Harness ไม่รับพรอมต์เริ่มต้น ดังนั้นพวกมันจะเปิดโดยวางพรอมต์ไว้บนคลิปบอร์ดของคุณให้แปะแทน เอเจนต์ที่เรียกใช้ด้วยวิธีนี้จะทำงานโดยไม่มีผู้ดูแลในโหมดไม่หยุดเพื่อถามของแต่ละตัว ดังนั้นเตรียมพร้อมไว้เลยว่ามันจะลงมือทำสิ่งต่างๆ จริงๆ! MiniMax Code ไม่มีโหมดแบบนั้นสำหรับเซสชันแบบโต้ตอบของมัน ดังนั้นมันจะขอสิทธิ์ตามปกติ และเนื่องจากเอเจนต์ปฏิเสธที่จะจดจำความเชื่อถือสำหรับไดเรกทอรีโฮมของคุณ การเรียกใช้จาก `$HOME` จะเริ่มใน `~/Work` แทน

มีทางลัดบนเทอร์มินัลด้วยเช่นกัน: `a` รันเอเจนต์เริ่มต้นแบบอินไลน์ในเทอร์มินัลปัจจุบัน ขณะที่ `c`, `cx` และ `cy` เริ่ม OpenCode, Claude Code และ Codex โดยตรง (อีกครั้ง ในโหมดอนุมัติอัตโนมัติของพวกมัน) การเปลี่ยนธีมยังซิงค์ไปยังเอเจนต์ด้วย: Claude Code, Pi, OpenCode และ Hermes (เมื่อ Omarchy ติดตั้งมันแล้ว) ล้วนเปลี่ยนตามเมื่อคุณสลับธีม Omarchy

### แผงเอเจนต์

แถบบนสุดมีไอคอนเอเจนต์ ก่อนที่คุณจะตั้งค่าเอเจนต์ แผงของมันจะพาคุณผ่านขั้นตอนการลงชื่อเข้าใช้ Claude, Codex หรือ Grok และตัวแรกจะกลายเป็นเอเจนต์เริ่มต้นของคุณ หลังจากนั้น แผงจะรวมทุกการสมัครสมาชิกไว้ในหน้าเดียว: เอเจนต์และบัญชีแต่ละตัวพร้อมแผนของมัน มิเตอร์สำหรับขีดจำกัดเซสชัน 5 ชั่วโมงและขีดจำกัดรายสัปดาห์ของแต่ละตัวพร้อมเวลาจนกว่าจะรีเซ็ต (วางเมาส์เหนือเพื่อดูเปอร์เซ็นต์ที่แน่นอน) หรือยอดคงเหลือแบบเติมเงินที่เหลืออยู่ ใต้บรรทัดที่หมุนเวียนสิ่งที่คุณใช้ไปในทุกตัว เช่น โทเค็นสัปดาห์นี้และโมเดลที่คุณใช้บ่อยที่สุด ใต้ _Make something_ มันเสนอพรอมต์เริ่มต้นสำหรับธีม ปลั๊กอิน หรือแอปใหม่ ที่ส่งงานต่อให้เอเจนต์เริ่มต้นของคุณ แอปถูกสร้างในแบบเดียวกับ Hype, Monologue และ Omacut ของ Omarchy เอง คือใน C++ และ Qt Quick ตามสกิลเอเจนต์ omarchy-app และคอมไพเลอร์กับชิ้นส่วน Qt ที่พวกมันต้องการก็ติดตั้งมาพร้อม Claude Code, Codex, Grok, Kimi, Cursor และโควตา Grok Bot ของมัน, GitHub Copilot, Muse, Antigravity, Kimchi และ Devin ครอบคลุมมาให้พร้อมใช้พร้อมขีดจำกัดของพวกมัน และ Hermes, Mistral Vibe และ Qwen Code จะแสดงเซสชันและโทเค็นของพวกมันเมื่อคุณได้ใช้พวกมันแล้ว แผนและคีย์ของผู้ให้บริการที่คุณใช้ผ่าน pi, omp หรือ opencode ก็แสดงขึ้นมาด้วย: OpenCode Zen และ Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan และ Synthetic พร้อมขีดจำกัดของพวกมัน; Fireworks, OpenRouter และ DeepSeek พร้อมยอดคงเหลือแบบเติมเงินของพวกมัน; และโมเดลที่คุณรันบนฮาร์ดแวร์ของคุณเองใต้ Local models เอเจนต์ทุกตัวถูกนับเพียงครั้งเดียว ใต้ผู้ที่เรียกเก็บเงินจากมัน ไม่ว่าคุณจะขับมันผ่านฮาร์เนสกี่ตัวก็ตาม

คลิกซ้ายที่ไอคอนบนแถบเพื่อเปิดแผง คลิกขวาเพื่อเรียกใช้เอเจนต์เริ่มต้นของคุณ บันทึกการใช้งานที่อยู่เบื้องหลังมันถูกสร้างใหม่ทุก 15 นาทีโดย `omarchy agent usage-update` และแผงยังสามารถรวมการใช้งานจากเครื่องอื่นๆ ของคุณผ่านโฟลเดอร์ที่ซิงค์ไว้ได้ ดู README ใต้ `$OMARCHY_PATH/shell/plugins/agents/` สำหรับการตั้งค่าทั้งหมด

### การสมัครสมาชิกหลายรายการ

หากคุณจ่ายเงินให้แผน Claude, Codex หรือ Grok มากกว่าหนึ่งแผน — เช่น Max ส่วนตัวหนึ่งและสำหรับงานอีกหนึ่ง — Omarchy สามารถให้ทุกแผนลงชื่อเข้าใช้ค้างไว้และย้ายไปมาระหว่างพวกมันได้ เพิ่มการสมัครสมาชิกด้วย + ในแผงเอเจนต์ ซึ่งจะพาคุณผ่านขั้นตอนนั้นตรงนั้นเลย หรือด้วย `omarchy agent account add claude Work` (หรือ `codex` หรือ `grok`) มันจะติดตั้ง CLI หากยังไม่มี บัญชีแรกสำหรับผู้ให้บริการหนึ่งจะลงชื่อเข้าใช้ผ่านเบราว์เซอร์ปกติของคุณ ตรงจุดที่ CLI มองหาเสมอ ทุกบัญชีหลังจากนั้นจะลงชื่อเข้าใช้ผ่านหน้าต่างส่วนตัว ดังนั้นบัญชีที่เบราว์เซอร์ของคุณลงชื่อเข้าใช้อยู่แล้วจะไม่ถูกหยิบขึ้นมาโดยไม่ตั้งใจ; ลงชื่อเข้าใช้ที่นั่นเป็นบัญชีที่คุณกำลังเพิ่ม และปิดหน้าต่างส่วนตัวใดๆ ที่คุณเปิดค้างไว้ก่อน อย่าออกจากระบบของ CLI เพื่อทำสิ่งนี้: การออกจากระบบจะเพิกถอนการลงชื่อเข้าใช้ที่บันทึกไว้ และบัญชีนั้นจะต้องถูกเพิ่มอีกครั้ง

ในการคัดลอกการเข้าสู่ระบบการสมัครสมาชิกของคุณไปยังเครื่อง Omarchy อีกเครื่องผ่าน SSH ให้รัน `omarchy agent account copy user@laptop` ผู้ส่งจะจัดหาตัวรับชั่วคราวให้เมื่อปลายทางยังไม่ได้ติดตั้งไว้ ดังนั้นเครื่อง Omarchy รุ่นเก่ากว่าสามารถรับบัญชีได้โดยไม่ต้องอัปเดต ตัวรับที่ติดตั้งไว้จะมีความสำคัญก่อน การดำเนินการนี้คัดลอกการสมัครสมาชิก Claude, Codex และ Grok ทั้งหมด; เพิ่มชื่อผู้ให้บริการเพื่อเลือกพวกมัน เช่นใน `omarchy agent account copy laptop claude` ชื่อบัญชีและ ID คำสั่งตรงกับต้นทาง รวมถึงบัญชีที่มีอยู่แล้วบนปลายทาง บัญชีปลายทางที่ไม่เกี่ยวข้องจะได้รับคำต่อท้ายเป็นตัวเลขหากชื่อของพวกมันขัดกัน และการตั้งค่า สกิล ปลั๊กอิน และประวัติการสนทนาจะยังคงอยู่ในเครื่องแต่ละเครื่อง

ข้อมูลประจำตัวปลายทางที่มีอยู่จะถูกเก็บไว้ บัญชีต้นทางที่ลงชื่อเข้าใช้อยู่ที่นั่นแล้วจะถูกซิงค์ชื่อโดยไม่แทนที่ข้อมูลประจำตัวของมัน; บัญชีอื่นๆ จะถูกเพิ่มเข้าไปควบคู่กับมัน ในการแทนที่ข้อมูลประจำตัวที่บันทึกไว้สำหรับบัญชีที่ตรงกัน ให้ใช้ `omarchy agent account copy --replace laptop claude` หลังจากปิดเซสชันของบัญชีนั้นบนปลายทาง ปลายทางใหม่ยังได้รับบัญชีที่ใช้งานอยู่และการตั้งค่าการสลับของต้นทางด้วย; ปลายทางที่ใช้งานมานานแล้วจะเก็บของตัวเองไว้

ข้อมูลประจำตัวเดินทางผ่าน SSH และถูกเก็บไว้ในไฟล์ส่วนตัวบนปลายทาง ดังนั้นจงคัดลอกไปยังเครื่องที่คุณไว้ใจเท่านั้น นี่คือการคัดลอกครั้งเดียว ไม่ใช่การซิงโครไนซ์ต่อเนื่อง โทเค็นรีเฟรชของ Codex สามารถถูกหมุนโดยเครื่องอื่นได้ ทำให้การเข้าสู่ระบบที่คัดลอกมาต้องต่ออายุ; การลงชื่อเข้าใช้แยกกันยังคงเป็นตัวเลือกที่เชื่อถือได้มากที่สุดสำหรับการใช้พร้อมกันบนหลายเครื่อง ดู [คำแนะนำการยืนยันตัวตนบัญชีของ Codex](https://developers.openai.com/codex/auth/ci-cd-auth)

หนึ่งบัญชีต่อผู้ให้บริการจะใช้งานอยู่ และทุกเซสชันใหม่จะเริ่มเป็นบัญชีนั้น: `cx`, `cy`, `claude`, `codex` หรือ `grok` ธรรมดาๆ, สิ่งใดก็ตามที่เรียกใช้ผ่าน `omarchy agent` และสคริปต์หรือโปรแกรมแก้ไขที่พบ CLI บน `PATH` สลับด้วย `omarchy agent account use work` (และกลับด้วย `omarchy agent account use main`) หรือในแผงโดยกดหมายเลขของบัญชีแล้วกด `Enter` (หรือคลิกปุ่ม Use ของมัน) เซสชันที่กำลังทำงานอยู่แล้วจะยังคงอยู่บนบัญชีที่มันเริ่มด้วย ประวัติการสนทนา การตั้งค่า สกิล และปลั๊กอินถูกแชร์ข้ามบัญชี ดังนั้น `claude --continue` ในโฟลเดอร์เดียวกันจะทำต่อจากจุดที่คุณค้างไว้บนบัญชีใหม่

เมื่อมีมากกว่าหนึ่งบัญชี แผงจะแสดงขีดจำกัดของแต่ละบัญชีเคียงข้างกัน โดยทำเครื่องหมายบัญชีที่ใช้งานอยู่ โดยค่าเริ่มต้น Omarchy จะแจ้งเตือนคุณเมื่อบัญชีที่ใช้งานอยู่ผ่าน 95% ของขีดจำกัด และการคลิกการแจ้งเตือนจะสลับไปยังบัญชีที่มีพื้นที่เหลือมากที่สุด วางเมาส์เหนือบรรทัดของบัญชีในแผงและคลิก Autoswitch ที่ปรากฏข้าง Use (หรือกด `m`) หรือรัน `omarchy agent account mode auto` เพื่อให้มันสลับด้วยตัวเองแทน; ขณะที่มันเปิดอยู่ Autoswitch จะเข้ามาแทนที่ Use และการคลิกมันอีกครั้งจะกลับไปเป็นการแจ้งเตือน เพิ่มตัวเลขเพื่อเปลี่ยนเกณฑ์ เช่นใน `omarchy agent account mode auto 90` หากทุกบัญชีเกินเกณฑ์ คุณจะได้รับแจ้งเพียงครั้งเดียว พร้อมกับว่าบัญชีใดจะว่างก่อน ขณะที่บัญชีที่ใช้งานอยู่ห่างจากเกณฑ์ของมันภายใน 15 จุด (80% ที่ค่าเริ่มต้น) ขีดจำกัดของมันจะถูกตรวจสอบทุกสามนาทีแทนที่จะเป็นทุก 15 นาที

`omarchy agent account list` แสดงทุกบัญชีและขีดจำกัดล่าสุดของพวกมัน, `omarchy agent account remove work` ลืมบัญชีหนึ่ง และ `omarchy agent account rename primary Hey` เปลี่ยนชื่อบัญชีหนึ่ง (หรือคลิกชื่อของบัญชีในแผง) คำสั่งเหล่านี้ทำงานกับบัญชีของเอเจนต์เริ่มต้นของคุณ; ในการเข้าถึงผู้ให้บริการอื่น ให้ระบุชื่อมันก่อน เช่นใน `omarchy agent account use codex side` การเข้าสู่ระบบที่คุณมีอยู่แล้วใน `~/.claude` หรือ `~/.codex` คือบัญชี _Main_ และยังคงอยู่ที่เดิม บัญชีที่ถูกทิ้งไว้โดยไม่ได้ใช้มากกว่าประมาณแปดชั่วโมงอาจแสดง _Sign-in required_; คลิกมันเพื่อลงชื่อเข้าใช้บัญชีนั้นอีกครั้งตรงในแผง หรือเริ่มเซสชันในมัน ซึ่งจะรีเฟรชการลงชื่อเข้าใช้ด้วยตัวเอง เซิร์ฟเวอร์ MCP ที่คุณมีเมื่อบัญชีถูกเพิ่มจะตามไปยังบัญชีนั้นด้วย แต่เซิร์ฟเวอร์ที่คุณเพิ่มภายหลังด้วย `claude mcp add` จะไปถึงเฉพาะบัญชีที่คุณเพิ่มพวกมันเข้าไป Claude Desktop และเครื่องมือที่ตั้งค่าด้วยพาธสัมบูรณ์ไปยังไบนารี CLI จะไม่ตามการสลับนี้ `CLAUDE_CONFIG_DIR`, `CODEX_HOME` หรือ `GROK_HOME` ที่ระบุอย่างชัดเจนจะมีความสำคัญกว่าบัญชีที่เลือก

### การวินิจฉัยการแครช

Omarchy เฝ้าดู systemd-coredump สำหรับการแครชของกระบวนการ เมื่อบางอย่างเกิด segfault คุณจะได้รับการแจ้งเตือน "Process crashed" — คลิกมัน และการแครชจะถูกส่งต่อให้เอเจนต์เริ่มต้นของคุณพร้อมกับสกิล diagnose-crash ของ Omarchy ซึ่งจะพาเอเจนต์ผ่านการสร้างข้อเท็จจริงจาก core dump และการตัดสินใจว่าการแครชนั้นคุ้มค่าที่จะรายงานไปยังต้นน้ำหรือไม่ คุณยังรันมันด้วยมือกับ PID ใดๆ จาก `coredumpctl list` ได้ด้วย `omarchy agent crash <pid>`

การเฝ้าดูเปิดอยู่โดยค่าเริ่มต้น ปิดมันใต้ _Trigger > Toggle > Crash Capture_ (หรือด้วย `omarchy toggle crash-capture`) และการแจ้งเตือนจะหยุด; `omarchy agent crash <pid>` ยังคงทำงานด้วยมือได้

การแครชยังสามารถถูกปิดเสียงทีละโปรแกรมได้ ซึ่งเป็นสิ่งที่การวินิจฉัยเสนอให้คุณในตอนท้าย `omarchy crash mute hyprland` หยุดการแจ้งเตือนสำหรับโปรแกรมนั้นเท่านั้น, `omarchy crash mute hyprland off` นำพวกมันกลับมา และ `omarchy crash mute` เพียงอย่างเดียวจะแสดงรายการสิ่งที่คุณปิดเสียงไว้ มันรับพาธของไบนารีได้เป็นอย่างดีพอๆ กับชื่อของมัน ดังนั้น `omarchy crash mute /usr/bin/hyprland` ทำสิ่งเดียวกัน ใส่เครื่องหมายคำพูดครอบชื่อที่มีช่องว่าง เช่นใน `omarchy crash mute 'Some App'` ทุกอย่างอื่นยังคงแจ้งเตือน และโปรแกรมที่ปิดเสียงไว้ยังคงแครช — สิ่งนี้ซ่อนการเตือน มันไม่ได้แก้ไขอะไรเลย

### แอปเดสก์ท็อป

เมนู _Install > AI_ ยังมีแอป AI แบบกราฟิกอยู่สองสามตัว: แอปเดสก์ท็อป ChatGPT, แอปเดสก์ท็อป Claude (รุ่นเบต้าสำหรับ Linux ของ Anthropic พร้อมแท็บ Chat, Cowork และ Claude Code), Grok Bot สำหรับแชทกับโมเดลของ xAI, Hermes Desktop, OpenClaw, แอปเดสก์ท็อป Perplexity และ T3 Code Grok Bot คือแอปแชทบนเดสก์ท็อป เอเจนต์เขียนโค้ดคือคำสั่ง `grok`

Hermes Desktop คือตัวที่ต้องรู้ไว้ เพราะเครื่องหนึ่งมี Hermes เดียว และมันเป็นของแอป: Hermes จะถูกติดตั้งผ่านแอปเท่านั้น และคำสั่ง `hermes` ที่เอเจนต์เริ่มต้นรันคือของแอป การเลือก Hermes เป็นเอเจนต์เริ่มต้นจะติดตั้งสิ่งเดียวกับที่รายการ _Install > AI_ ทำ: แพ็กเกจ และรันไทม์ Hermes ใต้ `~/.hermes` ที่ตัวติดตั้งของ Hermes เองตั้งค่าให้ ซึ่งใช้เวลาสองสามนาทีในครั้งแรก รันไทม์นั้นคือ Hermes ตัวเดียวที่คำสั่ง `hermes` บนเทอร์มินัล เอเจนต์เริ่มต้น และแอปใช้ทั้งหมด และมันอัปเดตตัวเองด้วย `hermes update` แทนที่จะรอการออก Omarchy รุ่นใหม่ การติดตั้งมันยังมอบธีม Omarchy ให้ Hermes เป็นสกินชื่อ `omarchy` ซึ่งทุกพื้นผิวของ Hermes จะตามเมื่อคุณสลับธีม; เลือกตัวอื่นใต้การตั้งค่า Appearance ของ Hermes หรือด้วย `/skin` หากคุณไม่อยากให้มันทำแบบนั้น และ Omarchy จะปล่อยตัวเลือกนั้นไว้ตามเดิม การลบแอปใต้ _Remove > AI_ จะปิด Hermes ก่อน รวมเกตเวย์ด้วย พารันไทม์นั้นไปด้วย และเก็บแชท ความทรงจำ และสกิลที่ Hermes เขียนให้ตัวเองไว้ เว้นแต่คุณจะบอกเป็นอื่น: มันจะถาม โดยค่าเริ่มต้นคือไม่ ว่าข้อมูลนั้นและการตั้งค่าการเชื่อมต่อของคุณควรหายไปด้วยหรือไม่

ประสบการณ์บนเดสก์ท็อปของ OpenClaw คือ Control UI ของมัน ซึ่งเปิดเป็นเว็บแอปที่หนุนหลังด้วยเกตเวย์ในเครื่องของมันเอง OpenClaw อาศัยอยู่ใน `~/.openclaw` และอัปเดตตัวเอง: ใช้ปุ่ม "Update Gateway" ของ Control UI หรือรัน `openclaw update` และเกตเวย์จะรีสตาร์ทบนรุ่นใหม่ Omarchy เลือกเฉพาะรุ่นที่การติดตั้งใหม่จะเริ่มจาก การลบ OpenClaw ใต้ _Remove > AI_ จะพาบริการเกตเวย์และแอปไปด้วย แล้วจึงถามว่า `~/.openclaw` ควรหายไปด้วยหรือไม่ เนื่องจากที่นั่นเก็บแชทและข้อมูลประจำตัวของคุณไว้ควบคู่กับ OpenClaw เองและรันไทม์ปลั๊กอินที่มันดาวน์โหลดมา; ค่าเริ่มต้นเก็บมันไว้ และการติดตั้ง OpenClaw อีกครั้งจะหยิบมันกลับขึ้นมา

T3 Code รันจากรุ่น AppImage อย่างเป็นทางการใน `~/.local/share/t3code` แทนที่จะมาจากแพ็กเกจ ดังนั้นมันจึงอัปเดตตัวเอง การติดตั้งมันจะถามว่าจะเริ่มบนช่อง Stable หรือ Nightly; สลับภายหลังได้ในการตั้งค่าของ T3 Code เธรดและการตั้งค่าของคุณอาศัยอยู่ใน `~/.t3` และการลบ T3 Code ใต้ _Remove > AI_ จะพาพวกมันไปด้วย

### โมเดลในเครื่อง

รันโมเดลแบบเปิดบนเครื่องของคุณเองสำหรับเอเจนต์เขียนโค้ดของคุณ พรอมต์และโค้ดของคุณอยู่บนเครื่อง; ไม่มีอะไรที่ส่งไปยังโมเดลออกจากเครื่องไป เริ่มด้วย:

```bash
omarchy agent local use best
```

หรือ ในแผงเอเจนต์ในแถบบนสุด ให้เลือก + แล้วจึงเลือก Local AI ซึ่งจะปรากฏขึ้นเมื่อโมเดลพอดีกับเครื่องนี้ ครั้งแรก การดำเนินการนี้จะติดตั้ง Podman ซึ่งรันโมเดล และบนเครื่อง NVIDIA จะติดตั้งชุดเครื่องมือคอนเทนเนอร์ของ NVIDIA ซึ่งให้ GPU แก่พวกมัน จากนั้น Omarchy จะเลือกโมเดลที่แนะนำสำหรับเครื่องนี้ ดาวน์โหลดมัน และเริ่มมัน คาดไว้เลยว่าจะมีการดาวน์โหลดหลายสิบ GB และหน่วยความจำส่วนใหญ่ของเครื่องจะถูกใช้ขณะโมเดลทำงาน: Flash Next ใช้ประมาณ 100 GiB กับบริบทเต็ม 256K ของมัน หากโมเดลอื่นถือหน่วยความจำที่มันต้องการอยู่ มันจะถูกตั้งค่าไว้ในสถานะหยุด พร้อมเริ่มเมื่อคุณหยุดโมเดลหนึ่ง โมเดลจะหยุดเมื่อออกจากระบบ; หยุดมันด้วยตัวเองเมื่อคุณต้องการหน่วยความจำสำหรับอย่างอื่น

`omarchy agent local list` แสดงตัวเลือกและอธิบายว่าทำไมบางตัวจึงไม่พอดี ในการตั้งค่าอีกตัว ให้รัน `omarchy agent local use <recipe>` ปัจจุบัน `qwen3.8-flash-next-halogen` และ `qwen3.8-27b-gufo` พร้อมใช้งานสำหรับเครื่อง Strix Halo ขนาด 128 GB สูตรและคำแนะนำใหม่มาพร้อมกับ `omarchy update` ผ่านแพ็กเกจ

ทุกโมเดลที่คุณตั้งค่าจะได้รับบรรทัดของมันเองในแผงเอเจนต์ ข้างการสมัครสมาชิกของคุณ: เล่นเพื่อเริ่มมัน หยุดชั่วคราวเพื่อหยุดมันและคืนหน่วยความจำของมัน และปุ่มเทอร์มินัลเพื่อเปิดเอเจนต์ของคุณบนมัน หลายตัวสามารถทำงานพร้อมกันได้เมื่อพวกมันพอดีในหน่วยความจำด้วยกัน; หากตัวหนึ่งไม่พอดี Omarchy จะบอกว่าให้หยุดโมเดลที่กำลังทำงานตัวใด ลากบรรทัดเพื่อจัดลำดับพวกมันใหม่ และกด Delete บนบรรทัดที่เลือกเพื่อลบโมเดลและการดาวน์โหลดของมัน

จากบรรทัดคำสั่ง `omarchy agent local start <recipe>` และ `omarchy agent local stop <recipe>` ทำสิ่งเดียวกัน, `omarchy agent local status` แสดงทุกโมเดล และ `omarchy agent --local` เปิดเอเจนต์เริ่มต้นของคุณบนโมเดลล่าสุดที่คุณเริ่ม (pi หากเอเจนต์เริ่มต้นของคุณใช้โมเดลในเครื่องไม่ได้) ไคลเอนต์ที่เข้ากันได้กับ OpenAI ใดๆ ก็สามารถเชื่อมต่อได้เช่นกัน: `status` แสดงที่อยู่ของแต่ละโมเดล (ตัวแรกคือ `http://127.0.0.1:11435/v1`), ชื่อสูตรคือโมเดล และคีย์อยู่ใน `~/.config/omarchy/agent-local/key`

`omarchy agent local remove <recipe>` ลบโมเดลและการดาวน์โหลดที่ไม่มีโมเดลอื่นใช้

รันไทม์ของบุคคลที่สามจะถูกระบุชื่อผู้เผยแพร่ของพวกมัน Omarchy รันทุกโมเดลโดยไม่มีการเข้าถึงเครือข่าย

### LLM ในเครื่อง

Omarchy แนะนำสองวิธีในการรันโมเดล LLM ในเครื่อง: LM Studio และ Ollama LM Studio ให้อินเทอร์เฟซ GUI สำหรับค้นหาโมเดลแบบเปิดน้ำหนัก ติดตั้งพวกมัน และรันพวกมัน เป็นวิธีที่ยอดเยี่ยมในการเริ่มต้นอย่างง่ายดาย Ollama เสนอ CLI ในการทำเช่นเดียวกัน แต่ถ้าคุณเพิ่งเริ่มกับโมเดลในเครื่อง ผมแนะนำให้เริ่มด้วย LM Studio คุณสามารถติดตั้งตัวใดตัวหนึ่งได้ใต้ _Install > AI_ ใน Omarchy Menu

### สกิล Omarchy

สกิลเอเจนต์ช่วยให้ AI ใช้เครื่องมือเฉพาะในวิธีเฉพาะ และ Omarchy มาพร้อมกับสกิลเริ่มต้นสำหรับการปรับแต่งระบบ เช่น การปรับแต่งการตั้งค่า Hyprland ของคุณ การปรับแถบ หรือแม้แต่การสร้างธีมใหม่ตั้งแต่ต้น มันถูกเชื่อมโยงแบบ symlink เข้าไปในไดเรกทอรีสกิลสำหรับ Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` และแต่ละ `~/.hermes/profiles/*/skills`) และตำแหน่งทั่วไป `~/.agents/skills` ดังนั้นฮาร์เนสส่วนใหญ่จึงหยิบมันขึ้นมาโดยอัตโนมัติ

แต่คุณควรปฏิบัติต่อสกิลนี้เสมือนเป็นการทดลอง โมเดลต่างๆ จะใช้มันให้ผลต่างกัน ดีที่สุดคือรันในโหมดวางแผนก่อน เพื่อให้คุณพอเห็นภาพว่าเอเจนต์อยากเปลี่ยนอะไร แล้วจึงเตรียมพร้อมที่จะย้อนกลับการเปลี่ยนแปลง หรือแม้แต่เรียกใช้ `omarchy reinstall configs` หากเอเจนต์ทำทุกอย่างเละเทะไปหมด
