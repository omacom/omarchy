### การติดตั้งและอัปเดตเอเจนต์

ยกเว้น Hermes เอเจนต์เหล่านี้ใช้การติดตั้งแบบ lazy ของ mise: การเปิดใช้ครั้งแรกจะติดตั้ง CLI และการเปิดใช้ครั้งต่อ ๆ ไปจะใช้ตัวที่ติดตั้งไว้ซ้ำ นอกจากนี้ mise ยังตรวจสอบว่าเอเจนต์ที่ติดตั้งไว้มีรุ่นใหม่หรือไม่ อย่างมากที่สุดหนึ่งครั้งทุกสี่ชั่วโมง ทันทีก่อนที่มันจะเริ่มทำงาน หรือในเบื้องหลังที่พรอมต์ของเชลล์ หากการอัปเดตนั้นล้มเหลวหรือคุณออฟไลน์อยู่ เวอร์ชันที่ติดตั้งไว้จะทำงาน `omarchy update` จะอัปเดตเอเจนต์ที่ติดตั้งไว้พร้อมกับส่วนอื่น ๆ ของ Omarchy และ `mup` จะอัปเดตเฉพาะเครื่องมือที่จัดการโดย mise เท่านั้น

ตัวอัปเดตของเอเจนต์เอง เช่น `claude update`, `codex update` หรือปุ่มอัปเดตในแอป จะไม่อัปเดตตัวติดตั้งที่จัดการโดย mise `codex update` จะล้มเหลว และ `claude update` อาจรายงานว่าสำเร็จในขณะที่ติดตั้งสำเนาแยกต่างหากที่ mise ไม่ได้ติดตาม หากคุณต้องการใช้ตัวติดตั้งและตัวอัปเดตแบบเนทีฟของเอเจนต์มากกว่า ให้เพิ่มมันลงใน `disable_tools`; ดู [เครื่องมือ CLI ที่ติดตั้งมาล่วงหน้า](18-development-tools.md#preinstalled-cli-tools)

หากต้องการติดตั้งเครื่องมือแบบ lazy ที่กำหนดค่าไว้ทั้งหมดก่อนที่คุณจะต้องการใช้ ให้รัน `mise install --include-lazy` ซึ่งรวมถึงเครื่องมือ CLI เริ่มต้นอื่น ๆ ของ Omarchy ตลอดจนเอเจนต์ต่าง ๆ ด้วย ดู [เครื่องมือ CLI ที่ติดตั้งมาล่วงหน้า](18-development-tools.md#preinstalled-cli-tools) สำหรับการติดตั้งเครื่องมือตัวเดียวหรือการใช้ตัวติดตั้งของคุณเอง

`grok` ติดตั้งผ่านแพ็กเกจ `grok` ของ mise โดยตรง ในลักษณะเดียวกับ `claude` และ `codex` ให้รัน `grok` หรือเลือกมันใต้ _Setup > Defaults > Agent_ ข้ามตัวติดตั้งแบบ `curl | bash` บน x.ai ไปได้เลย เส้นทางนั้นจะวางสำเนาที่สองไว้ใน `~/.grok/bin`, แทรกไว้ข้างหน้าใน `PATH` และเขียนทับ wrapper ของ Omarchy

`dsh` จะเปิด UI บนเบราว์เซอร์ของมันที่ `127.0.0.1:3080` โดยใช้ไดเรกทอรีที่เปิดใช้เป็นพื้นที่ทำงานเริ่มต้น UI บนเบราว์เซอร์ของมันไม่รับพรอมต์เริ่มต้น ดังนั้น `omarchy agent prompt` จะเปิดมันโดยมีพรอมต์อยู่บนคลิปบอร์ดของคุณให้วาง Omarchy เริ่มมันด้วยพรีเซ็ตสิทธิ์แบบไม่ต้องอนุมัติของ DeepSeek DeepSeek Harness จะอัปโหลดบันทึกเซสชันไปยัง DeepSeek เมื่อคุณใช้ API โมเดลอย่างเป็นทางการของมัน; ปิดสิ่งนั้นได้ใต้ _Settings > General > Upload Session Log_ ใน UI บนเบราว์เซอร์ของมัน ความคิดเห็นที่คุณส่งไปก็จะถูกอัปโหลดพร้อมกับเซสชันด้วยเช่นกัน เว้นแต่คุณจะเริ่มมันด้วย `DSH_TELEMETRY_MODE=DISABLED`

### เอเจนต์เริ่มต้น

เลือกเอเจนต์เริ่มต้นของคุณด้วย `omarchy default agent <name>` หรือใต้ _Setup > Defaults > Agent_ ใน Omarchy Menu (`Super + Space`) หากเอเจนต์นั้นยังไม่ได้ติดตั้ง การเลือกมันจะติดตั้งก่อน Omarchy ที่ติดตั้งใหม่จะเชิญชวนให้คุณตัดสินใจเลือกสิ่งนี้ด้วยการแจ้งเตือนเพียงครั้งเดียว

การเลือก Claude ยังพยายามตั้งค่าส่วนขยายเบราว์เซอร์ของมันสำหรับ Chromium, Chrome, Brave, Brave Origin และ Edge ด้วย การตั้งค่าส่วนขยายจะใช้กับผู้ใช้ทุกคนและอาจขอรหัสผ่านระบบของคุณ; การยกเลิกหรือการติดตั้งส่วนขยายที่ล้มเหลวก็ยังเลือกและเปิดใช้ Claude อยู่ดี รีสตาร์ทเบราว์เซอร์ของคุณ เปิดใช้ส่วนขยายหากระบบแจ้ง และลงชื่อเข้าใช้ Claude เพื่อเชื่อมต่อให้เสร็จสมบูรณ์ รัน `/chrome` ใน Claude เพื่อตรวจสอบการเชื่อมต่อ Firefox และ Zen ไม่รองรับส่วนขยายนี้ หาก Claude เป็นค่าเริ่มต้นของคุณอยู่แล้วก่อนที่จะมีการเพิ่มการตั้งค่านี้เข้าไป ให้เลือกมันอีกครั้งเพื่อติดตั้งส่วนขยาย

เมื่อคุณเลือกแล้ว `Super + Shift + Ctrl + A` จะเปิดใช้เอเจนต์เริ่มต้นในหน้าต่างเทอร์มินัลเฉพาะ (หรือเปิดตัวเลือกขึ้นมาหากคุณยังไม่ได้เลือก) คุณยังสามารถเปิดใช้มันตรงเข้าสู่งานได้ด้วย `omarchy agent prompt "Review this project"` Freebuff และ DeepSeek Harness ไม่รับพรอมต์เริ่มต้น ดังนั้นพวกมันจะเปิดโดยมีพรอมต์อยู่บนคลิปบอร์ดของคุณให้วางแทน เอเจนต์ที่เปิดใช้ด้วยวิธีนี้จะทำงานโดยไม่มีผู้ดูแลในโหมดไม่ต้องหยุดเพื่อถามของแต่ละตัว ดังนั้นจงเตรียมพร้อมให้พวกมันลงมือทำสิ่งต่าง ๆ จริง ๆ! MiniMax Code ไม่มีโหมดดังกล่าวสำหรับเซสชันแบบอินเทอร์แอกทีฟของมัน ดังนั้นมันจะขอสิทธิ์ตามปกติ และเนื่องจากเอเจนต์ปฏิเสธที่จะจดจำความไว้วางใจสำหรับไดเรกทอรีโฮมของคุณ การเปิดใช้จาก `$HOME` จะเริ่มใน `~/Work` แทน

ยังมีทางลัดบนเทอร์มินัลด้วย: `a` จะรันเอเจนต์เริ่มต้นแบบอินไลน์ในเทอร์มินัลปัจจุบัน ขณะที่ `c`, `cx` และ `cy` จะเริ่ม OpenCode, Claude Code และ Codex โดยตรง (อีกครั้งในโหมดอนุมัติอัตโนมัติของพวกมัน) การเปลี่ยนธีมยังซิงค์ไปยังเอเจนต์ด้วย: Claude Code, Pi, OpenCode และ Hermes (เมื่อ Omarchy ติดตั้งมันแล้ว) ต่างก็ตามไปด้วยเมื่อคุณเปลี่ยนธีม Omarchy

### แผงเอเจนต์

แถบด้านบนมีไอคอนเอเจนต์ ก่อนที่คุณจะตั้งค่าเอเจนต์ แผงของมันจะแนะนำคุณตลอดการลงชื่อเข้าใช้ Claude, Codex หรือ Grok และตัวแรกจะกลายเป็นเอเจนต์เริ่มต้นของคุณ หลังจากนั้น แผงจะรวมการสมัครสมาชิกทุกอย่างไว้ในหน้าเดียว: เอเจนต์และบัญชีแต่ละตัวพร้อมแพ็กเกจของมัน มิเตอร์สำหรับขีดจำกัดเซสชัน 5 ชั่วโมงและขีดจำกัดรายสัปดาห์แต่ละอย่างพร้อมเวลาจนกว่าจะรีเซ็ต (วางเมาส์เหนือเพื่อดูเปอร์เซ็นต์ที่แน่นอน) หรือยอดเงินแบบเติมเงินคงเหลือ ใต้บรรทัดที่หมุนเวียนผ่านสิ่งที่คุณใช้ไปในทุกตัว เช่น โทเคนในสัปดาห์นี้และโมเดลที่คุณใช้มากที่สุด ใต้ _Make something_ มันนำเสนอพรอมต์เริ่มต้นสำหรับธีม ปลั๊กอิน หรือแอปใหม่ที่ส่งมอบงานให้เอเจนต์เริ่มต้นของคุณ แอปถูกสร้างขึ้นในแบบเดียวกับ Hype, Monologue และ Omacut ของ Omarchy เอง ใน C++ และ Qt Quick โดยทำตามสกิลเอเจนต์ omarchy-app และคอมไพเลอร์และชิ้นส่วน Qt ที่พวกมันต้องการก็ติดตั้งมาพร้อมแล้ว Claude Code, Codex, Grok, Kimi, Cursor และโควตา Grok Bot ของมัน, GitHub Copilot, Muse, Antigravity, Kimchi และ Devin ได้รับการครอบคลุมมาตั้งแต่แรกพร้อมขีดจำกัดของพวกมัน และ Hermes, Mistral Vibe และ Qwen Code จะแสดงเซสชันและโทเคนของพวกมันเมื่อคุณได้ใช้พวกมันแล้ว แพ็กเกจผู้ให้บริการและคีย์ที่คุณใช้ผ่าน pi, omp หรือ opencode ก็แสดงขึ้นด้วยเช่นกัน: OpenCode Zen และ Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan และ Synthetic พร้อมขีดจำกัดของพวกมัน; Fireworks, OpenRouter และ DeepSeek พร้อมยอดเงินแบบเติมเงินของพวกมัน; และโมเดลที่คุณรันบนฮาร์ดแวร์ของคุณเองใต้ Local models เอเจนต์ทุกตัวถูกนับเพียงครั้งเดียว ภายใต้ผู้ที่เรียกเก็บเงินจากมัน ไม่ว่าคุณจะขับเคลื่อนมันผ่าน harness กี่ตัวก็ตาม

คลิกซ้ายที่ไอคอนแถบเพื่อเปิดแผง คลิกขวาเพื่อเปิดใช้เอเจนต์เริ่มต้นของคุณ บันทึกการใช้งานที่อยู่เบื้องหลังมันถูกสร้างใหม่ทุก 15 นาทีโดย `omarchy agent usage-update` และแผงยังสามารถรวมการใช้งานจากเครื่องอื่น ๆ ของคุณผ่านโฟลเดอร์ที่ซิงค์ไว้ได้ ดู README ใต้ `$OMARCHY_PATH/shell/plugins/agents/` สำหรับการตั้งค่าแบบเต็ม

### การสมัครสมาชิกหลายรายการ

หากคุณจ่ายเงินสำหรับแพ็กเกจ Claude, Codex หรือ Grok มากกว่าหนึ่งแพ็กเกจ — เช่น Max ส่วนตัวและอีกอันสำหรับงาน — Omarchy สามารถให้พวกมันทั้งหมดลงชื่อเข้าใช้อยู่และสลับไปมาระหว่างพวกมันได้ เพิ่มการสมัครสมาชิกด้วย + ในแผงเอเจนต์ ซึ่งจะแนะนำคุณตลอดขั้นตอนตรงนั้นเลย หรือด้วย `omarchy agent account add claude Work` (หรือ `codex` หรือ `grok`) มันจะติดตั้ง CLI หากขาดไป บัญชีแรกสำหรับผู้ให้บริการจะลงชื่อเข้าใช้ผ่านเบราว์เซอร์ปกติของคุณ ตรงที่ที่ CLI มองหาเสมอ ทุกบัญชีหลังจากนั้นจะลงชื่อเข้าใช้ผ่านหน้าต่างส่วนตัว ดังนั้นบัญชีที่เบราว์เซอร์ของคุณลงชื่อเข้าใช้อยู่แล้วจะไม่ถูกหยิบขึ้นมาโดยไม่ตั้งใจ; ให้ลงชื่อเข้าใช้ที่นั่นในฐานะบัญชีที่คุณกำลังเพิ่ม และปิดหน้าต่างส่วนตัวใด ๆ ที่คุณเปิดไว้อยู่แล้วก่อน อย่าออกจากระบบของ CLI เพื่อทำสิ่งนี้เด็ดขาด: การออกจากระบบจะเพิกถอนการลงชื่อเข้าใช้ที่บันทึกไว้ และบัญชีนั้นจะต้องถูกเพิ่มใหม่อีกครั้ง

หากต้องการคัดลอกการเข้าสู่ระบบการสมัครสมาชิกของคุณไปยังเครื่อง Omarchy อื่นผ่าน SSH ให้รัน `omarchy agent account copy user@laptop` ผู้ส่งจะจัดเตรียมตัวรับชั่วคราวเมื่อปลายทางยังไม่ได้ติดตั้งไว้ ดังนั้นเครื่อง Omarchy รุ่นเก่ากว่าสามารถรับบัญชีได้โดยไม่ต้องอัปเดต ตัวรับที่ติดตั้งไว้จะมีความสำคัญเหนือกว่า การดำเนินการนี้จะคัดลอกการสมัครสมาชิก Claude, Codex และ Grok ทั้งหมด; เพิ่มชื่อผู้ให้บริการเพื่อเลือกพวกมัน เช่นใน `omarchy agent account copy laptop claude` ชื่อบัญชีและ ID คำสั่งจะตรงกับต้นทาง รวมถึงบัญชีที่มีอยู่แล้วบนปลายทาง บัญชีปลายทางที่ไม่เกี่ยวข้องกันจะได้รับคำต่อท้ายที่เป็นตัวเลขหากชื่อของพวกมันขัดกัน และการตั้งค่า สกิล ปลั๊กอิน และประวัติการสนทนาจะยังคงอยู่เฉพาะบนแต่ละเครื่อง

ข้อมูลประจำตัวปลายทางที่มีอยู่จะถูกเก็บไว้ บัญชีต้นทางที่ลงชื่อเข้าใช้อยู่ที่นั่นแล้วจะมีชื่อที่ซิงโครไนซ์โดยไม่แทนที่ข้อมูลประจำตัวของมัน; บัญชีอื่น ๆ จะถูกเพิ่มควบคู่ไปด้วย หากต้องการแทนที่ข้อมูลประจำตัวที่บันทึกไว้สำหรับบัญชีที่ตรงกัน ให้ใช้ `omarchy agent account copy --replace laptop claude` หลังจากออกจากเซสชันของบัญชีนั้นบนปลายทางแล้ว ปลายทางใหม่ยังจะได้รับบัญชีที่ใช้งานอยู่ของต้นทางและความต้องการในการสลับด้วย; ปลายทางที่มีการใช้งานมานานแล้วจะเก็บของตัวเองไว้

ข้อมูลประจำตัวเดินทางผ่าน SSH และถูกเก็บไว้ในไฟล์ส่วนตัวบนปลายทาง ดังนั้นให้คัดลอกไปยังเครื่องที่คุณไว้วางใจเท่านั้น นี่คือการคัดลอกเพียงครั้งเดียว ไม่ใช่การซิงโครไนซ์อย่างต่อเนื่อง โทเคนรีเฟรชของ Codex สามารถถูกหมุนเวียนโดยเครื่องอื่นได้ ทำให้การเข้าสู่ระบบที่คัดลอกมาต้องต่ออายุ; การลงชื่อเข้าใช้แยกกันยังคงเป็นตัวเลือกที่น่าเชื่อถือที่สุดสำหรับการใช้งานพร้อมกันบนหลายเครื่อง ดู [คำแนะนำการยืนยันตัวตนบัญชีของ Codex](https://developers.openai.com/codex/auth/ci-cd-auth)

บัญชีหนึ่งบัญชีต่อผู้ให้บริการจะใช้งานอยู่ และทุกเซสชันใหม่จะเริ่มในฐานะบัญชีนั้น: `cx`, `cy`, `claude`, `codex` หรือ `grok` ธรรมดา อะไรก็ตามที่เปิดใช้ผ่าน `omarchy agent` และสคริปต์หรือโปรแกรมแก้ไขที่พบ CLI บน `PATH` สลับด้วย `omarchy agent account use work` (และกลับด้วย `omarchy agent account use main`) หรือในแผงโดยกดหมายเลขของบัญชีแล้วกด `Enter` (หรือคลิกปุ่ม Use ของมัน) เซสชันที่กำลังทำงานอยู่แล้วจะยังคงอยู่บนบัญชีที่พวกมันเริ่มด้วย ประวัติการสนทนา การตั้งค่า สกิล และปลั๊กอินถูกแชร์ข้ามบัญชี ดังนั้น `claude --continue` ในโฟลเดอร์เดียวกันจะดำเนินการต่อจากจุดที่คุณค้างไว้บนบัญชีใหม่

เมื่อมีมากกว่าหนึ่งบัญชี แผงจะแสดงขีดจำกัดของแต่ละบัญชีเคียงข้างกัน โดยบัญชีที่ใช้งานอยู่จะถูกทำเครื่องหมายไว้ โดยค่าเริ่มต้น Omarchy จะแจ้งเตือนคุณเมื่อบัญชีที่ใช้งานอยู่ผ่าน 95% ของขีดจำกัด และการคลิกการแจ้งเตือนจะสลับไปยังบัญชีที่มีพื้นที่เหลือมากที่สุด วางเมาส์เหนือบรรทัดของบัญชีในแผงและคลิก Autoswitch ที่ปรากฏข้าง Use (หรือกด `m`) หรือรัน `omarchy agent account mode auto` เพื่อให้มันสลับด้วยตัวเองแทน; ขณะที่เปิดอยู่ Autoswitch จะแทนที่ Use และการคลิกมันอีกครั้งจะกลับไปเป็นการแจ้งเตือน เพิ่มตัวเลขเพื่อเปลี่ยนเกณฑ์ เช่นใน `omarchy agent account mode auto 90` หากทุกบัญชีเกินเกณฑ์ คุณจะได้รับแจ้งเกี่ยวกับมันหนึ่งครั้ง พร้อมกับว่าบัญชีใดจะว่างก่อน ขณะที่บัญชีที่ใช้งานอยู่ภายใน 15 จุดจากเกณฑ์ของมัน (80% ที่ค่าเริ่มต้น) ขีดจำกัดของมันจะถูกตรวจสอบทุกสามนาทีแทนที่จะเป็นทุก 15 นาที

`omarchy agent account list` แสดงทุกบัญชีและขีดจำกัดล่าสุดของพวกมัน `omarchy agent account remove work` ลืมบัญชีหนึ่งบัญชี และ `omarchy agent account rename primary Hey` เปลี่ยนชื่อบัญชีหนึ่งบัญชี (หรือคลิกชื่อของบัญชีในแผง) คำสั่งเหล่านี้ทำงานบนบัญชีของเอเจนต์เริ่มต้นของคุณ; หากต้องการเข้าถึงผู้ให้บริการรายอื่น ให้ระบุชื่อมันก่อน เช่นใน `omarchy agent account use codex side` การเข้าสู่ระบบที่คุณมีอยู่แล้วใน `~/.claude` หรือ `~/.codex` คือบัญชี _Main_ และจะยังคงอยู่ที่เดิม บัญชีที่ไม่ได้ใช้งานนานกว่าประมาณแปดชั่วโมงสามารถแสดง _Sign-in required_; คลิกมันเพื่อลงชื่อเข้าใช้บัญชีนั้นอีกครั้งในแผง หรือเริ่มเซสชันในมัน ซึ่งจะรีเฟรชการลงชื่อเข้าใช้ด้วยตัวมันเอง เซิร์ฟเวอร์ MCP ที่คุณมีเมื่อบัญชีถูกเพิ่มจะตามไปยังบัญชีนั้นด้วย แต่เซิร์ฟเวอร์ที่คุณเพิ่มในภายหลังด้วย `claude mcp add` จะไปถึงเฉพาะบัญชีที่คุณเพิ่มพวกมันเข้าไปเท่านั้น Claude Desktop และเครื่องมือที่กำหนดค่าด้วยเส้นทางสัมบูรณ์ไปยังไบนารี CLI จะไม่ตามการสลับไป การกำหนด `CLAUDE_CONFIG_DIR`, `CODEX_HOME` หรือ `GROK_HOME` อย่างชัดเจนจะมีความสำคัญเหนือบัญชีที่เลือกไว้

### การวินิจฉัยการขัดข้อง

Omarchy เฝ้าดู systemd-coredump สำหรับการขัดข้องของกระบวนการ เมื่อบางอย่างเกิด segfault คุณจะได้รับการแจ้งเตือน "Process crashed" — คลิกมัน และการขัดข้องจะถูกส่งมอบให้เอเจนต์เริ่มต้นของคุณพร้อมกับสกิล diagnose-crash ของ Omarchy ซึ่งจะแนะนำเอเจนต์ตลอดการสร้างข้อเท็จจริงจาก core dump และการตัดสินใจว่าการขัดข้องนั้นคุ้มค่าที่จะรายงานไปยัง upstream หรือไม่ คุณยังสามารถรันมันด้วยตนเองกับ PID ใด ๆ จาก `coredumpctl list` ด้วย `omarchy agent crash <pid>` ได้ด้วย

การเฝ้าดูเปิดอยู่โดยค่าเริ่มต้น ปิดมันใต้ _Trigger > Toggle > Crash Capture_ (หรือด้วย `omarchy toggle crash-capture`) และการแจ้งเตือนจะหยุด; `omarchy agent crash <pid>` ยังคงทำงานด้วยตนเองได้

การขัดข้องยังสามารถถูกปิดเสียงทีละโปรแกรมได้ ซึ่งเป็นสิ่งที่การวินิจฉัยเสนอให้คุณในตอนท้าย `omarchy crash mute hyprland` จะหยุดการแจ้งเตือนสำหรับโปรแกรมนั้นเท่านั้น `omarchy crash mute hyprland off` จะนำพวกมันกลับมา และ `omarchy crash mute` ด้วยตัวมันเองจะแสดงรายการสิ่งที่คุณปิดเสียงไว้ มันรับเส้นทางของไบนารีได้อย่างยินดีพอ ๆ กับชื่อของมัน ดังนั้น `omarchy crash mute /usr/bin/hyprland` จะทำสิ่งเดียวกัน ใส่เครื่องหมายคำพูดชื่อที่มีช่องว่าง เช่นใน `omarchy crash mute 'Some App'` ทุกอย่างอื่นยังคงแจ้งเตือนอยู่ และโปรแกรมที่ปิดเสียงก็ยังคงขัดข้องอยู่ — นี่เป็นการซ่อนการเตือนความจำ มันไม่ได้แก้ไขอะไรเลย

### แอปบนเดสก์ท็อป

เมนู _Install > AI_ ยังมีแอป AI แบบกราฟิกอยู่สองสามแอปด้วย: แอปเดสก์ท็อป ChatGPT, แอปเดสก์ท็อป Claude (รุ่นเบต้าสำหรับ Linux ของ Anthropic พร้อมแท็บ Chat, Cowork และ Claude Code), Grok Bot สำหรับแชทกับโมเดลของ xAI, Hermes Desktop, OpenClaw, แอปเดสก์ท็อป Perplexity และ T3 Code Grok Bot คือแอปแชทบนเดสก์ท็อป เอเจนต์เขียนโค้ดคือคำสั่ง `grok`

Hermes Desktop เป็นตัวที่ต้องรู้ไว้ เพราะเครื่องหนึ่งเครื่องมี Hermes เพียงหนึ่งเดียว และมันเป็นของแอป: Hermes จะติดตั้งผ่านแอปเท่านั้น และคำสั่ง `hermes` ที่เอเจนต์เริ่มต้นรันคือของแอป การเลือก Hermes เป็นเอเจนต์เริ่มต้นจะติดตั้งสิ่งเดียวกับที่รายการ _Install > AI_ ติดตั้ง: แพ็กเกจ และรันไทม์ Hermes ใต้ `~/.hermes` ที่ตั้งค่าโดยตัวติดตั้งของ Hermes เอง ซึ่งใช้เวลาสองสามนาทีในครั้งแรก รันไทม์นั้นคือ Hermes ตัวเดียวที่คำสั่ง `hermes` บนเทอร์มินัล เอเจนต์เริ่มต้น และแอปทั้งหมดใช้ และมันอัปเดตตัวเองด้วย `hermes update` แทนที่จะรอการออกเวอร์ชัน Omarchy การติดตั้งมันยังมอบธีม Omarchy ให้ Hermes เป็นสกินชื่อ `omarchy` ซึ่งทุกพื้นผิวของ Hermes จะทำตามขณะที่คุณเปลี่ยนธีม; เลือกอีกอันใต้การตั้งค่า Appearance ของ Hermes หรือด้วย `/skin` หากคุณต้องการให้มันไม่ทำเช่นนั้น และ Omarchy จะปล่อยตัวเลือกนั้นไว้ตามเดิม การลบแอปใต้ _Remove > AI_ จะปิด Hermes ก่อน รวมเกตเวย์ด้วย นำรันไทม์นั้นไปกับมัน และเก็บแชท ความทรงจำ และสกิลที่ Hermes เขียนให้ตัวเองไว้ เว้นแต่คุณจะบอกเป็นอย่างอื่น: มันจะถาม โดยค่าเริ่มต้นคือไม่ ว่าข้อมูลนั้นและการตั้งค่าการเชื่อมต่อของคุณควรไปด้วยหรือไม่

ประสบการณ์บนเดสก์ท็อปของ OpenClaw คือ Control UI ของมัน ซึ่งเปิดเป็นเว็บแอปที่ได้รับการสนับสนุนโดยเกตเวย์แบบโลคัลของมันเอง OpenClaw อยู่ใน `~/.openclaw` และอัปเดตตัวเอง: ใช้ปุ่ม "Update Gateway" ของ Control UI หรือรัน `openclaw update` และเกตเวย์จะรีสตาร์ทบนเวอร์ชันใหม่ Omarchy เลือกเฉพาะเวอร์ชันที่การติดตั้งใหม่จะเริ่มจาก การลบ OpenClaw ใต้ _Remove > AI_ จะนำบริการเกตเวย์และแอปไปกับมัน จากนั้นจะถามว่า `~/.openclaw` ควรไปด้วยหรือไม่ เนื่องจากที่นั่นเก็บแชทและข้อมูลประจำตัวของคุณควบคู่ไปกับ OpenClaw เองและรันไทม์ปลั๊กอินที่มันดาวน์โหลด; ค่าเริ่มต้นจะเก็บมันไว้ และการติดตั้ง OpenClaw อีกครั้งจะหยิบมันกลับขึ้นมา

T3 Code รันจากรุ่น AppImage อย่างเป็นทางการของมันใน `~/.local/share/t3code` แทนที่จะมาจากแพ็กเกจ ดังนั้นมันจึงอัปเดตตัวเอง การติดตั้งมันจะถามว่าจะเริ่มบนช่อง Stable หรือ Nightly; สลับในภายหลังได้ในการตั้งค่าของ T3 Code เธรดและการตั้งค่าของคุณอยู่ใน `~/.t3` และการลบ T3 Code ใต้ _Remove > AI_ จะนำพวกมันไปด้วย

### โมเดลแบบโลคัล

รันโมเดลแบบเปิดบนเครื่องของคุณเองสำหรับเอเจนต์เขียนโค้ดของคุณ พรอมต์และโค้ดของคุณยังคงอยู่บนเครื่อง; ไม่มีอะไรที่ส่งไปยังโมเดลออกจากเครื่องไป เริ่มต้นด้วย:

```bash
omarchy agent local use best
```

หรือ ในแผงเอเจนต์ในแถบด้านบน เลือก + แล้วเลือก Local AI ซึ่งจะแสดงขึ้นเมื่อโมเดลพอดีกับเครื่องนี้ ในครั้งแรก การดำเนินการนี้จะติดตั้ง Podman ซึ่งรันโมเดล และบนเครื่อง NVIDIA จะติดตั้งชุดเครื่องมือคอนเทนเนอร์ของ NVIDIA ซึ่งให้ GPU แก่พวกมัน จากนั้น Omarchy จะเลือกโมเดลที่แนะนำสำหรับเครื่องนี้ ดาวน์โหลดมัน และเริ่มมัน คาดว่าจะมีการดาวน์โหลดหลายสิบ GB และหน่วยความจำส่วนใหญ่ของเครื่องจะถูกใช้ขณะที่โมเดลทำงาน: Flash Next ใช้ประมาณ 100 GiB กับบริบทเต็ม 256K ของมัน หากโมเดลอื่นถือหน่วยความจำที่มันต้องการไว้ มันจะถูกตั้งค่าให้หยุดอยู่ พร้อมที่จะเริ่มเมื่อคุณหยุดตัวหนึ่งตัวใด โมเดลจะหยุดเมื่อออกจากระบบ; หยุดมันด้วยตัวเองเมื่อคุณต้องการหน่วยความจำสำหรับอย่างอื่น

`omarchy agent local list` แสดงตัวเลือกและอธิบายว่าทำไมบางตัวจึงไม่พอดี หากต้องการตั้งค่าอีกตัว ให้รัน `omarchy agent local use <recipe>` ปัจจุบัน `qwen3.8-flash-next-gufo` และ `qwen3.8-27b-gufo` พร้อมใช้งานสำหรับเครื่อง Strix Halo ขนาด 128 GB; ตัว 27B ใช้ประมาณ 40 GiB ดังนั้นจึงเหลือพื้นที่สำหรับงานอื่น สูตรและคำแนะนำใหม่มาพร้อมกับ `omarchy update` ผ่านแพ็กเกจ

โมเดลทุกตัวที่คุณตั้งค่าจะมีบรรทัดของตัวเองในแผงเอเจนต์ ถัดจากการสมัครสมาชิกของคุณ: เล่นเพื่อเริ่มมัน หยุดชั่วคราวเพื่อหยุดมันและเพิ่มหน่วยความจำให้ว่าง และปุ่มเทอร์มินัลเพื่อเปิดเอเจนต์ของคุณบนมัน หลายตัวสามารถทำงานพร้อมกันได้เมื่อพวกมันพอดีในหน่วยความจำด้วยกัน; หากตัวหนึ่งไม่พอดี Omarchy จะบอกว่าโมเดลที่กำลังทำงานตัวใดให้หยุด ลากบรรทัดเพื่อจัดเรียงใหม่ และกด Delete บนบรรทัดที่เลือกเพื่อลบโมเดลและการดาวน์โหลดของมัน

จากบรรทัดคำสั่ง `omarchy agent local start <recipe>` และ `omarchy agent local stop <recipe>` ทำสิ่งเดียวกัน `omarchy agent local status` แสดงทุกโมเดล และ `omarchy agent --local` เปิดเอเจนต์เริ่มต้นของคุณบนโมเดลล่าสุดที่คุณเริ่ม (pi หากเอเจนต์เริ่มต้นของคุณไม่สามารถใช้โมเดลแบบโลคัลได้) ไคลเอนต์ที่เข้ากันได้กับ OpenAI ตัวใดก็สามารถเชื่อมต่อได้เช่นกัน: `status` แสดงที่อยู่ของแต่ละโมเดล (ตัวแรกคือ `http://127.0.0.1:11435/v1`) ชื่อสูตรคือโมเดล และคีย์อยู่ใน `~/.config/omarchy/agent-local/key`

`omarchy agent local remove <recipe>` ลบโมเดลและการดาวน์โหลดที่ไม่มีโมเดลอื่นใช้

รันไทม์ของบุคคลที่สามจะถูกติดป้ายด้วยผู้เผยแพร่ของพวกมัน Omarchy รันทุกโมเดลโดยไม่มีการเข้าถึงเครือข่าย

### LLM แบบโลคัล

Omarchy แนะนำสองวิธีในการรันโมเดล LLM แบบโลคัล: LM Studio และ Ollama LM Studio มีอินเทอร์เฟซ GUI สำหรับการค้นหาโมเดลแบบ open-weight การติดตั้งพวกมัน และการรันพวกมัน มันเป็นวิธีที่ดีในการเริ่มต้นได้ง่าย ๆ Ollama นำเสนอ CLI สำหรับการทำเช่นเดียวกัน แต่ถ้าคุณเป็นมือใหม่กับโมเดลแบบโลคัล ผมจะเริ่มต้นด้วย LM Studio คุณสามารถติดตั้งตัวใดตัวหนึ่งได้ใต้ _Install > AI_ ใน Omarchy Menu

### สกิล Omarchy

สกิลเอเจนต์ช่วยให้ AI ใช้เครื่องมือเฉพาะในวิธีเฉพาะ และ Omarchy มาพร้อมกับสกิลเริ่มต้นสำหรับการปรับแต่งระบบ เช่น การปรับแต่งไฟล์กำหนดค่า Hyprland ของคุณ การปรับแถบ หรือแม้แต่การสร้างธีมใหม่ตั้งแต่ต้น มันถูกเชื่อมโยงแบบ symlink เข้าไปในไดเรกทอรีสกิลสำหรับ Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` และแต่ละ `~/.hermes/profiles/*/skills`) และตำแหน่งทั่วไป `~/.agents/skills` ดังนั้น harness ส่วนใหญ่จะหยิบมันขึ้นมาโดยอัตโนมัติ

แต่คุณควรถือว่าสกิลนี้เป็นการทดลอง โมเดลที่แตกต่างกันจะใช้มันเพื่อให้เกิดผลแตกต่างกัน ทางที่ดีที่สุดคือรันในโหมดวางแผนก่อน เพื่อให้คุณมีความคิดว่าเอเจนต์ต้องการเปลี่ยนแปลงอะไร จากนั้นเตรียมพร้อมที่จะย้อนกลับการเปลี่ยนแปลง หรือแม้แต่เรียกใช้ `omarchy reinstall configs` หากเอเจนต์ทำทุกอย่างเละเทะไปหมด
