# เบราว์เซอร์

Omarchy มาพร้อม [Chromium](https://www.chromium.org/) เป็นเบราว์เซอร์เริ่มต้น มันคือรุ่นโอเพนซอร์สธรรมดา จัดธีมให้เข้ากับส่วนที่เหลือของระบบคุณ และมันคือสิ่งที่ `Super + Shift + Return` เปิด และสิ่งที่ [เว็บแอป](25-web-apps.md) ทุกตัวรันอยู่ข้างใน

ถ้า Chromium ไม่ใช่รสนิยมของคุณ คุณก็ไม่ได้ติดอยู่กับมัน ใต้ _ติดตั้ง > Browser_ ในเมนู Omarchy คุณจะพบ Chrome, Edge, Brave, Brave Origin, Firefox และ [Zen](https://zen-browser.app/) เลือกสักตัวแล้ว Omarchy จะติดตั้งมัน ตั้งค่าไดเรกทอรีนโยบาย และนำธีมปัจจุบันของคุณไปใช้กับมัน

## ตั้งตัวใดตัวหนึ่งเป็นค่าเริ่มต้น

การติดตั้งเบราว์เซอร์ไม่ได้เลื่อนมันเป็นค่าเริ่มต้น เมื่อมันอยู่บนเครื่องแล้ว ให้ไปที่ _ตั้งค่า > Defaults > Browser_ แล้วเลือกมัน — เมนูจะแสดงเฉพาะเบราว์เซอร์ที่คุณติดตั้งไว้จริงเท่านั้น และทำเครื่องหมายตัวเริ่มต้นปัจจุบันด้วยเครื่องหมายถูก

จากเทอร์มินัลใช้คำสั่งนี้:

```bash
omarchy default browser firefox
```

รันโดยไม่มีอาร์กิวเมนต์แล้วมันจะบอกค่าเริ่มต้นปัจจุบันให้คุณ สิ่งนี้ตั้งค่า XDG handler ดังนั้นมันไม่ใช่แค่ปุ่มลัดของ Omarchy ที่ทำตาม — อะไรก็ตามที่เปิดลิงก์ ตั้งแต่แอปแชทไปจนถึงคำสั่งเทอร์มินัล ก็จะไปที่เบราว์เซอร์ที่คุณเลือก

## คัดลอก URL และดาวน์โหลดวิดีโอ

เบราว์เซอร์ตระกูล Chromium (ตัว Chromium เอง, Chrome, Edge และ Brave) มาพร้อมส่วนขยาย Omarchy สองตัวที่เอื้อมออกจากเบราว์เซอร์เข้าไปในส่วนที่เหลือของระบบคุณ

**Copy URL** วางที่อยู่ของแท็บปัจจุบันลงคลิปบอร์ดของคุณด้วย `Alt + Shift + L` นั่นเร็วกว่าการคลิกเข้าไปในแถบที่อยู่แล้วคัดลอก และเพราะมันผ่านคลิปบอร์ดของระบบแทนที่จะเป็นของเบราว์เซอร์ คุณจึงได้รับการแจ้งเตือนจาก Omarchy เพื่อยืนยัน และ URL ก็พร้อมใช้งานทันทีใน [ประวัติคลิปบอร์ด](08-unified-clipboard-history.md) และทุกแอปอื่น ๆ มีปุ่มบนแถบเครื่องมือด้วย ถ้าคุณชอบคลิกมากกว่า

**Download Video** ดึงวิดีโอที่เล่นอยู่ในหน้าคุณกำลังดูด้วย `Alt + Shift + D` มันส่ง URL ให้ [yt-dlp](https://github.com/yt-dlp/yt-dlp) ดังนั้นมันจึงใช้ได้กับมากกว่า YouTube มาก และการดาวน์โหลดจะไปลงใน `~/Videos` ความคืบหน้าจะแสดงในหน้าจอแสดงผลเดียวกับที่ใช้กับระดับเสียงและความสว่าง อัปเดตอยู่กับที่แทนที่จะซ้อนการแจ้งเตือน ตั้งค่า `OMARCHY_YTDLP_DIR` ถ้าคุณอยากให้ไฟล์ไปอยู่ที่อื่นแทน — ดู [คำถามที่พบบ่อย](46-faq.md) สำหรับที่ที่จะวางตัวแปรสภาพแวดล้อม

ส่วนขยายทั้งสองคุยกับ Omarchy ผ่านโฮสต์การส่งข้อความเนทีฟตัวเล็ก ๆ ซึ่งติดตั้งให้คุณพร้อมกับเบราว์เซอร์ นั่นคือชิ้นส่วนที่ทำให้วิดีโอของเว็บเพจมาลงในไดเรกทอรีหลักของคุณ และ URL มาลงในตัวจัดการคลิปบอร์ดของคุณได้ ซึ่งส่วนขยายปกติทำเองไม่ได้

สิ่งเหล่านี้มีเฉพาะตระกูล Chromium เท่านั้น Firefox และ Zen ไม่ได้พวกมัน

## Firefox และ Zen

Firefox และ Zen เป็นตระกูลอื่น ดังนั้นพวกมันจึงได้รับการดูแลต่างกัน Omarchy ติดตั้งไฟล์นโยบายสำหรับค่าเริ่มต้นที่สมเหตุสมผล และสลับพวกมันเข้าสู่โหมด Wayland เนทีฟ ซึ่งคุณต้องการสำหรับการปรับขนาดแบบเศษส่วนและการเลื่อนแทร็กแพดอย่างราบรื่น

พวกมันไม่ได้ส่วนขยาย Chromium ด้านบน และพวกมันไม่ได้ถูกจัดธีมโดย Omarchy ดังนั้นส่วนเหล่านั้นของประสบการณ์จึงเป็นของคุณที่จะตั้งค่าเอง

## การนำตัวใดตัวหนึ่งออกอีกครั้ง

อะไรก็ตามที่คุณติดตั้งที่นี่สามารถนำออกได้ที่ _นำออก > Browser_ Chromium ไม่ได้อยู่ในรายการนั้น — มันเป็นส่วนหนึ่งของระบบพื้นฐาน
