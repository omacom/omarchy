# เบราว์เซอร์

Omarchy มาพร้อมกับ [Google Chrome](https://www.google.com/chrome/) เป็นเบราว์เซอร์เริ่มต้น มันถูกตกแต่งธีมให้เข้ากับส่วนอื่น ๆ ของระบบของคุณ และเป็นตัวที่ `Super + Shift + Return` เปิดขึ้นมา และเป็นตัวที่ทุก [เว็บแอป](25-web-apps.md) ทำงานอยู่ภายใน มันเปิดตรงไปยังหน้าต่างเบราว์เซอร์เลย: ไม่มีหน้าจอต้อนรับหรือข้อความแจ้งให้ลงชื่อเข้าใช้ สถิติการใช้งานและรายงานการขัดข้องจะไม่ถูกส่งไปยัง Google และข้อความแจ้งเรื่องความเป็นส่วนตัวของโฆษณาถูกปิดไว้แล้ว คุณยังสามารถลงชื่อเข้าใช้บัญชี Google ของคุณจากปุ่มโปรไฟล์ได้ทุกเมื่อหากต้องการซิงก์

ถ้า Chrome ไม่ใช่แนวของคุณ คุณไม่ได้ติดอยู่กับมัน ภายใต้ _ติดตั้ง > เบราว์เซอร์_ ในเมนู Omarchy คุณจะพบ [Chromium](https://www.chromium.org/) (รุ่นโอเพนซอร์สแบบเปลือย ๆ ที่ Chrome สร้างขึ้นจากมัน), Edge, Brave, Brave Origin, Firefox และ [Zen](https://zen-browser.app/) เลือกมาสักตัว แล้ว Omarchy จะติดตั้งให้ ตั้งค่าไดเรกทอรีนโยบายของมัน และนำธีมปัจจุบันของคุณไปใช้กับมัน

## ตั้งอันหนึ่งให้เป็นค่าเริ่มต้น

การติดตั้งเบราว์เซอร์ไม่ได้เลื่อนขั้นให้มัน เมื่อมันอยู่ในเครื่องแล้ว ให้ไปที่ _ตั้งค่า > ค่าเริ่มต้น > เบราว์เซอร์_ แล้วเลือกมัน — เมนูจะแสดงเฉพาะเบราว์เซอร์ที่คุณติดตั้งไว้จริง ๆ เท่านั้น และจะทำเครื่องหมายถูกไว้ที่ค่าเริ่มต้นปัจจุบัน

จากเทอร์มินัลใช้คำสั่งนี้:

```bash
omarchy default browser firefox
```

รันโดยไม่ใส่ argument แล้วมันจะบอกคุณว่าค่าเริ่มต้นปัจจุบันคืออะไร วิธีนี้ตั้งค่า XDG handler ดังนั้นจึงไม่ใช่แค่ปุ่มลัดของ Omarchy ที่ตามไปด้วย — ทุกอย่างที่เปิดลิงก์ ตั้งแต่แอปแชตไปจนถึงคำสั่งในเทอร์มินัล จะไปยังเบราว์เซอร์ที่คุณเลือก

## Copy URL และ Download Video

เบราว์เซอร์ตระกูล Chromium (ตัว Chromium เอง, Chrome, Edge และ Brave) มาพร้อมส่วนขยายของ Omarchy สองตัวที่เอื้อมออกไปนอกเบราว์เซอร์และเข้าไปในส่วนอื่น ๆ ของระบบของคุณ

**Copy URL** วางที่อยู่ของแท็บปัจจุบันลงในคลิปบอร์ดของคุณด้วย `Alt + Shift + L` นั่นเร็วกว่าการคลิกเข้าไปในแถบที่อยู่แล้วคัดลอก และเพราะมันผ่านคลิปบอร์ดของระบบแทนที่จะเป็นของเบราว์เซอร์ คุณจะได้รับการแจ้งเตือนจาก Omarchy เพื่อยืนยัน และ URL จะพร้อมใช้งานทันทีใน [ประวัติคลิปบอร์ด](08-unified-clipboard-history.md) และทุกแอปอื่น ๆ มีปุ่มบนแถบเครื่องมือด้วย หากคุณชอบคลิกมากกว่า

**Download Video** ดึงวิดีโอที่กำลังเล่นอยู่บนหน้าที่คุณกำลังดูด้วย `Alt + Shift + D` มันส่ง URL ไปให้ [yt-dlp](https://github.com/yt-dlp/yt-dlp) ดังนั้นจึงใช้ได้กับมากกว่า YouTube มากมาย และไฟล์ที่ดาวน์โหลดจะไปอยู่ใน `~/Videos` ความคืบหน้าจะแสดงบนการแสดงผลบนหน้าจอเดียวกับที่ใช้แสดงระดับเสียงและความสว่าง โดยอัปเดตในที่เดิมแทนที่จะกองการแจ้งเตือนซ้อนกันขึ้นเรื่อย ๆ ตั้งค่า `OMARCHY_YTDLP_DIR` หากคุณอยากให้ไฟล์ไปอยู่ที่อื่นแทน — ดู [FAQ](46-faq.md) ว่าควรใส่ตัวแปรสภาพแวดล้อมไว้ที่ไหน

ส่วนขยายทั้งสองตัวคุยกับ Omarchy ผ่าน native messaging host ขนาดเล็ก ซึ่งจะถูกติดตั้งให้คุณพร้อมกับเบราว์เซอร์ นี่คือชิ้นส่วนที่ทำให้วิดีโอของเว็บเพจไปอยู่ในไดเรกทอรีโฮมของคุณได้ และทำให้ URL ไปอยู่ในตัวจัดการคลิปบอร์ดของคุณได้ ซึ่งส่วนขยายธรรมดาทำเองไม่ได้

เหล่านี้มีเฉพาะตระกูล Chromium เท่านั้น Firefox และ Zen จะไม่ได้พวกมันไป

## Firefox และ Zen

Firefox และ Zen เป็นคนละตระกูลกัน ดังนั้นพวกมันจึงได้รับการดูแลต่างออกไป: Omarchy ติดตั้งไฟล์นโยบายสำหรับค่าเริ่มต้นที่สมเหตุสมผล และสลับพวกมันเข้าสู่โหมด Wayland แบบเนทีฟ ซึ่งคุณต้องการสำหรับการปรับสเกลแบบเศษส่วนและการเลื่อนด้วยแทร็กแพดที่ลื่นไหล

พวกมันไม่ได้รับส่วนขยาย Chromium ข้างต้น และพวกมันไม่ถูกตกแต่งธีมโดย Omarchy ดังนั้นส่วนเหล่านั้นของประสบการณ์จึงเป็นของคุณที่จะต้องตั้งค่าเอง

## ลบออกอีกครั้ง

เบราว์เซอร์ใด ๆ เหล่านี้ รวมถึง Chrome ด้วย สามารถถอดออกได้อีกครั้งภายใต้ _ลบออก > เบราว์เซอร์_ จากนั้นลิงก์จะไปยัง Chrome หรือ Chromium หากอีกตัวยังติดตั้งอยู่
