# เบราว์เซอร์

Omarchy มาพร้อมกับ [Google Chrome](https://www.google.com/chrome/) เป็นเบราว์เซอร์เริ่มต้น มันถูกปรับธีมให้เข้ากับส่วนอื่น ๆ ของระบบของคุณ และเป็นสิ่งที่ `Super + Shift + Return` (หรือ `Super + Shift + B`) เปิดขึ้นมา พร้อมกับ `Super + Shift + Alt + B` สำหรับหน้าต่างส่วนตัว และเป็นสิ่งที่ [เว็บแอป](25-web-apps.md) ทุกตัวทำงานอยู่ภายใน มันเปิดตรงไปยังหน้าต่างเบราว์เซอร์เลย: ไม่มีหน้าจอต้อนรับหรือข้อความแจ้งให้ลงชื่อเข้าใช้ ไม่มีการส่งสถิติการใช้งานและรายงานการขัดข้องไปยัง Google และข้อความแจ้งเรื่องความเป็นส่วนตัวด้านโฆษณาถูกปิดไว้แล้ว คุณยังสามารถลงชื่อเข้าใช้บัญชี Google ของคุณได้จากปุ่มโปรไฟล์เมื่อใดก็ตามที่คุณต้องการซิงค์

ถ้า Chrome ไม่ใช่สไตล์ของคุณ คุณก็ไม่ได้ติดอยู่กับมัน ภายใต้ _Install > Browser_ ในเมนู Omarchy คุณจะพบ [Chromium](https://www.chromium.org/) (เวอร์ชันโอเพนซอร์สล้วน ๆ ที่ใช้สร้าง Chrome), Edge, Brave, Brave Origin, Firefox และ [Zen](https://zen-browser.app/) (Edge เฉพาะเครื่อง x86 เท่านั้น) เลือกตัวหนึ่งแล้ว Omarchy จะติดตั้งให้ ตั้งค่าไดเรกทอรีนโยบายของมัน และนำธีมปัจจุบันของคุณไปใช้กับมัน

## ทำให้ตัวหนึ่งเป็นค่าเริ่มต้น

การติดตั้งเบราว์เซอร์ไม่ได้ทำให้มันกลายเป็นค่าเริ่มต้น หากต้องการเปลี่ยน ให้ไปที่ _Setup > Defaults > Browser_ แล้วเลือกตัวหนึ่ง ค่าเริ่มต้นปัจจุบันจะมีเครื่องหมายถูกกำกับไว้ และการเลือกเบราว์เซอร์ที่คุณยังไม่มีจะติดตั้งมันให้ก่อน

จากเทอร์มินัล ให้ใช้คำสั่งนี้:

```bash
omarchy default browser firefox
```

รันโดยไม่ใส่ argument แล้วมันจะบอกคุณว่าค่าเริ่มต้นปัจจุบันคืออะไร การทำเช่นนี้จะตั้งค่า XDG handler ดังนั้นจึงไม่ใช่แค่ปุ่มลัดของ Omarchy ที่ตามไปด้วย — อะไรก็ตามที่เปิดลิงก์ ตั้งแต่แอปแชตไปจนถึงคำสั่งในเทอร์มินัล จะไปยังเบราว์เซอร์ที่คุณเลือก

## Copy URL และ Download Video

เบราว์เซอร์ตระกูล Chromium (ตัว Chromium เอง, Chrome, Edge, Brave และ Brave Origin) มาพร้อมกับส่วนขยายของ Omarchy สามตัว: สองตัวที่เอื้อมออกไปนอกเบราว์เซอร์และเข้าไปในส่วนอื่น ๆ ของระบบของคุณ และอีกตัวหนึ่งที่จัดระเบียบ WhatsApp

**Copy URL** จะนำที่อยู่ของแท็บปัจจุบันไปไว้บนคลิปบอร์ดของคุณด้วย `Alt + Shift + L` ซึ่งเร็วกว่าการคลิกเข้าไปในแถบที่อยู่แล้วคัดลอก และเพราะมันผ่านคลิปบอร์ดของระบบแทนที่จะเป็นของเบราว์เซอร์ คุณจะได้รับการแจ้งเตือนจาก Omarchy เพื่อยืนยัน และ URL นั้นก็จะพร้อมใช้งานทันทีใน [ประวัติคลิปบอร์ด](08-unified-clipboard-history.md) และทุกแอปอื่น ๆ นอกจากนี้ยังมีปุ่มบนแถบเครื่องมือด้วย หากคุณชอบคลิกมากกว่า

**Download Video** จะดึงวิดีโอที่กำลังเล่นบนหน้าที่คุณกำลังดูอยู่ด้วย `Alt + Shift + D` มันส่ง URL ไปให้ [yt-dlp](https://github.com/yt-dlp/yt-dlp) ดังนั้นจึงใช้งานได้กับอะไรมากกว่า YouTube มากมาย และไฟล์ที่ดาวน์โหลดจะไปอยู่ใน `~/Videos` ความคืบหน้าจะแสดงใน on-screen display เดียวกันกับที่ใช้สำหรับระดับเสียงและความสว่าง โดยอัปเดตอยู่กับที่แทนที่จะกองการแจ้งเตือนซ้อนขึ้นไปเรื่อย ๆ ตั้งค่า `OMARCHY_YTDLP_DIR` หากคุณอยากให้ไฟล์ไปอยู่ที่อื่นแทน — ดู [FAQ](46-faq.md) สำหรับตำแหน่งที่จะวางตัวแปร environment

ส่วนขยายทั้งสองตัวคุยกับ Omarchy ผ่าน native messaging host ตัวเล็ก ๆ ซึ่งจะถูกติดตั้งให้คุณพร้อมกับเบราว์เซอร์ นั่นคือชิ้นส่วนที่ทำให้วิดีโอของหน้าเว็บหนึ่ง ๆ ไปอยู่ในไดเรกทอรี home ของคุณ และ URL ไปอยู่ในตัวจัดการคลิปบอร์ดของคุณได้ ซึ่งส่วนขยายทั่วไปทำเองไม่ได้

**WhatsApp Slim** ทำให้ WhatsApp Web ใช้ธีมตามระบบของคุณ และยุบรายการแชตของมันเมื่อหน้าต่างแคบ

สิ่งเหล่านี้ใช้ได้กับตระกูล Chromium เท่านั้น Firefox และ Zen จะไม่ได้พวกมัน

## Firefox และ Zen

Firefox และ Zen เป็นคนละตระกูลกัน ดังนั้นจึงได้รับการดูแลต่างออกไป: Omarchy จะติดตั้งไฟล์ policies สำหรับค่าเริ่มต้นที่สมเหตุสมผล และสลับพวกมันเข้าสู่โหมด native Wayland ซึ่งคุณต้องการสำหรับ fractional scaling และการเลื่อนด้วยแทร็กแพดอย่างลื่นไหล

พวกมันไม่ได้ส่วนขยาย Chromium ข้างต้น และไม่ได้รับการปรับธีมโดย Omarchy ดังนั้นส่วนเหล่านั้นของประสบการณ์จึงเป็นเรื่องของคุณที่จะตั้งค่าเอง

## ลบตัวหนึ่งออกอีกครั้ง

เบราว์เซอร์ใด ๆ เหล่านี้ รวมถึง Chrome ด้วย สามารถเอาออกได้ภายใต้ _Remove > Browser_ จากนั้นลิงก์จะไปยัง Chrome หรือ Chromium หากอีกตัวยังคงติดตั้งอยู่
