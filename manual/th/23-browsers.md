# เบราว์เซอร์

Omarchy มาพร้อมกับ [Google Chrome](https://www.google.com/chrome/) เป็นเบราว์เซอร์เริ่มต้น มันถูกตกแต่งด้วยธีมให้เข้ากับส่วนอื่น ๆ ของระบบของคุณ และเป็นตัวที่ `Super + Shift + Return` (หรือ `Super + Shift + B`) จะเปิดขึ้นมา โดยใช้ `Super + Shift + Alt + B` สำหรับหน้าต่างส่วนตัว และเป็นตัวที่ [เว็บแอป](25-web-apps.md) ทุกตัวทำงานอยู่ข้างใน มันเปิดตรงไปยังหน้าต่างเบราว์เซอร์เลย: ไม่มีหน้าจอต้อนรับหรือข้อความแจ้งให้ลงชื่อเข้าใช้ สถิติการใช้งานและรายงานข้อขัดข้องจะไม่ถูกส่งไปให้ Google และข้อความแจ้งเรื่องความเป็นส่วนตัวของโฆษณาถูกปิดไว้แล้ว คุณยังลงชื่อเข้าใช้บัญชี Google ของคุณจากปุ่มโปรไฟล์ได้ทุกเมื่อที่ต้องการซิงค์

ถ้า Chrome ไม่ใช่สไตล์ของคุณ คุณก็ไม่ได้ติดอยู่กับมัน ในเมนู Omarchy ใต้ _Install > Browser_ คุณจะพบ [Chromium](https://www.chromium.org/) (รุ่นโอเพนซอร์สล้วน ๆ ที่ใช้สร้าง Chrome), Edge, Brave, Brave Origin, Firefox, [Zen](https://zen-browser.app/) และ [Ladybird](https://ladybird.org/) (Edge มีเฉพาะบนเครื่อง x86 เท่านั้น) เลือกตัวใดตัวหนึ่ง แล้ว Omarchy จะติดตั้งให้ ตั้งค่าไดเรกทอรีนโยบายของมัน และนำธีมปัจจุบันของคุณไปใช้กับมัน

## การตั้งตัวใดตัวหนึ่งเป็นค่าเริ่มต้น

การติดตั้งเบราว์เซอร์ไม่ได้ทำให้มันกลายเป็นเบราว์เซอร์เริ่มต้น หากต้องการสลับ ให้ไปที่ _Setup > Defaults > Browser_ แล้วเลือกตัวหนึ่ง ตัวที่เป็นค่าเริ่มต้นปัจจุบันจะมีเครื่องหมายถูกกำกับไว้ และการเลือกเบราว์เซอร์ที่คุณยังไม่มีจะติดตั้งมันก่อนเป็นอันดับแรก

จากเทอร์มินัลใช้คำสั่งนี้:

```bash
omarchy default browser firefox
```

รันโดยไม่ใส่ argument มันจะบอกค่าเริ่มต้นปัจจุบันให้คุณทราบ คำสั่งนี้จะตั้งค่า XDG handler ดังนั้นจึงไม่ใช่แค่ปุ่มลัดของ Omarchy เท่านั้นที่เปลี่ยนตาม — ทุกอย่างที่เปิดลิงก์ ตั้งแต่แอปแชตไปจนถึงคำสั่งในเทอร์มินัล จะไปยังเบราว์เซอร์ที่คุณเลือก

## Copy URL และ Download Video

เบราว์เซอร์ในตระกูล Chromium (ตัว Chromium เอง, Chrome, Edge, Brave และ Brave Origin) มาพร้อมกับส่วนขยายของ Omarchy สามตัว: สองตัวที่เอื้อมออกไปนอกเบราว์เซอร์และเข้าไปในส่วนอื่น ๆ ของระบบของคุณ และอีกตัวหนึ่งที่ช่วยจัดระเบียบ WhatsApp

**Copy URL** จะนำที่อยู่ของแท็บปัจจุบันไปไว้บนคลิปบอร์ดของคุณด้วย `Alt + Shift + L` ซึ่งเร็วกว่าการคลิกเข้าไปในแถบที่อยู่แล้วคัดลอก และเพราะมันส่งผ่านคลิปบอร์ดของระบบแทนที่จะเป็นของเบราว์เซอร์ คุณจะได้รับการแจ้งเตือนจาก Omarchy เพื่อยืนยัน และ URL จะพร้อมใช้งานทันทีใน [ประวัติคลิปบอร์ด](08-unified-clipboard-history.md) และทุกแอปอื่น ๆ นอกจากนี้ยังมีปุ่มบนแถบเครื่องมือด้วย หากคุณชอบคลิกมากกว่า

**Download Video** จะดึงวิดีโอที่กำลังเล่นอยู่ในหน้าที่คุณกำลังดูอยู่ด้วย `Alt + Shift + D` มันจะส่ง URL ไปให้ [yt-dlp](https://github.com/yt-dlp/yt-dlp) ดังนั้นจึงใช้งานได้กับอะไรที่มากกว่า YouTube มาก และไฟล์ที่ดาวน์โหลดจะไปอยู่ใน `~/Videos` ความคืบหน้าจะแสดงบนการแสดงผลบนหน้าจอเดียวกับที่ใช้แสดงระดับเสียงและความสว่าง โดยอัปเดตตรงที่เดิมแทนที่จะกองการแจ้งเตือนซ้อนกันขึ้นเรื่อย ๆ ตั้งค่า `OMARCHY_YTDLP_DIR` หากคุณอยากให้ไฟล์ไปอยู่ที่อื่นแทน — ดู [FAQ](46-faq.md) สำหรับตำแหน่งที่ควรวางตัวแปรสภาพแวดล้อม

ส่วนขยายทั้งสองตัวสื่อสารกับ Omarchy ผ่าน native messaging host ขนาดเล็ก ซึ่งจะถูกติดตั้งให้คุณพร้อมกับเบราว์เซอร์ ชิ้นส่วนนี้เองที่ทำให้วิดีโอของหน้าเว็บหนึ่งไปอยู่ในโฮมไดเรกทอรีของคุณได้ และทำให้ URL ไปอยู่ในตัวจัดการคลิปบอร์ดของคุณได้ ซึ่งเป็นสิ่งที่ส่วนขยายทั่วไปทำเองไม่ได้

**WhatsApp Slim** ทำให้ WhatsApp Web ใช้ตามธีมระบบของคุณ และยุบรายการแชตของมันเมื่อหน้าต่างแคบ

ส่วนขยายเหล่านี้มีเฉพาะสำหรับตระกูล Chromium เท่านั้น Firefox และ Zen จะไม่ได้ใช้

## Firefox และ Zen

Firefox และ Zen เป็นอีกตระกูลหนึ่ง จึงได้รับการดูแลที่ต่างออกไป: Omarchy จะติดตั้งไฟล์นโยบายสำหรับค่าเริ่มต้นที่เหมาะสม และสลับพวกมันให้อยู่ในโหมด Wayland แบบเนทีฟ ซึ่งเป็นโหมดที่คุณต้องการสำหรับการปรับสเกลแบบเศษส่วนและการเลื่อนด้วยแทร็กแพดที่ลื่นไหล

พวกมันจะไม่ได้รับส่วนขยาย Chromium ข้างต้น และจะไม่ถูกตกแต่งธีมโดย Omarchy ดังนั้นประสบการณ์ในส่วนเหล่านั้นจึงเป็นเรื่องที่คุณต้องตั้งค่าเอง

## Ladybird

Ladybird เป็นเบราว์เซอร์ที่เขียนขึ้นใหม่ตั้งแต่ต้น โดยมีเอนจินของตัวเองแทนที่จะเป็นของ Chromium หรือ Firefox มันยังอยู่ในช่วงอัลฟา ดังนั้นจงคาดหวังไว้ได้เลยว่าจะมีเว็บไซต์ที่ยังใช้งานไม่ได้ และ Omarchy จะติดตั้งมันมาในสภาพเดิม ๆ: ไม่มีส่วนขยาย ไม่มีธีม ไม่มีนโยบาย มันไม่มีหน้าต่างส่วนตัวเช่นกัน ดังนั้น `Super + Shift + Alt + B` จะเปิดมันด้วยโปรไฟล์ชั่วคราวที่จะถูกลบเมื่อคุณปิดมัน [เว็บแอป](25-web-apps.md) จะยังคงทำงานใน Chrome หรือ Chromium ต่อไป

## การลบตัวใดตัวหนึ่งออกอีกครั้ง

เบราว์เซอร์เหล่านี้ตัวใดก็ได้ รวมถึง Chrome สามารถถอดออกได้อีกครั้งที่ _Remove > Browser_ หลังจากนั้นลิงก์จะไปยัง Chrome หรือ Chromium หากอีกตัวยังคงติดตั้งอยู่
