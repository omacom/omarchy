# GUIs

## ไฟล์

Files (Nautilus) คือตัวจัดการไฟล์แบบกราฟิก `Super + Shift + F` เปิดมัน และ `Super + Shift + Alt + F` เปิดมันในไดเรกทอรีที่เทอร์มินัลของคุณนั่งอยู่ ซึ่งช่วยลดการคลิกได้เยอะ `Ctrl + L` ให้คุณพิมพ์พาธ และกด `Space` บนไฟล์ใด ๆ ก็ให้ตัวอย่างด่วนโดยไม่ต้องเปิดอะไรเลย

เสียบแท่ง USB หรือการ์ด SD แล้วมันจะเมานต์โดยอัตโนมัติ ดังนั้นมันก็โผล่ขึ้นมาในแถบข้างเลย สำหรับอะไรที่ซับซ้อนกว่านั้น — ฟอร์แมตไดรฟ์ ตรวจสุขภาพ SMART สร้างพาร์ติชัน — ให้เปิด _Disks_ จากตัวเปิดแอป (`Super + Space`)

การดับเบิลคลิกใช้ค่าเริ่มต้นที่สมเหตุสมผล รูปภาพเปิดใน imv วิดีโอเปิดใน mpv PDF เปิดใน Document Viewer และข้อความธรรมดาเปิดใน Neovim

## Disktree

เมื่อไดรฟ์เต็มและคุณไม่รู้เลยว่าอะไรกินมันอยู่ ให้เปิด [Disktree](https://github.com/tobi/disktree) จากตัวเปิดแอป (`Super + Space`) มันแสดง treemap แบบกราฟิกของไดเรกทอรีหลักของคุณ บล็อกใหญ่กินพื้นที่มากกว่า เดินเข้าไปในไดเรกทอรีด้วยคีย์บอร์ดหรือเมาส์ ทำเครื่องหมายสิ่งที่ควรไป และตรวจสิ่งที่คุณเลือกก่อนลบอะไรออก รัน `disktree --disk` เพื่อสแกนทั้งดิสก์

## Obsidian

[Obsidian](https://obsidian.md/) คือแอปพลิเคชันจดบันทึกฟรีและขยายได้สูง ที่ใช้ไฟล์ Markdown ธรรมดาสำหรับจัดเก็บ

Obsidian ฟรีสำหรับทุกวัตถุประสงค์ รวมถึงการใช้ส่วนตัว เชิงพาณิชย์ และไม่แสวงผลกำไร

Obsidian ยังเสนอ [ส่วนเสริมเชิงพาณิชย์สำหรับการซิงค์](https://obsidian.md/sync) กับแอปมือถือบน iOS และ Android ด้วย (https://obsidian.md/pricing)

คุณเริ่ม Obsidian ด้วย `Super + Shift + O` หากต้องการใช้การซิงค์ธีม คุณต้องเลือกธีม `Omarchy` ใต้การตั้งค่า

## Omawrite

[Omawrite](https://github.com/omacom-io/omawrite) คือแอปเขียน Markdown ที่เรียบง่ายตายตัวของ Omarchy เอง ไม่มี vault ไม่มีปลั๊กอิน มีแค่คุณกับคำพูด

คุณเริ่ม Omawrite ด้วย `Super + Shift + W`

## Pinta

[Pinta](https://www.pinta-project.com/) เป็นเครื่องมือแก้ไขรูปภาพพื้นฐานที่ยอดเยี่ยมสำหรับการครอบ ปรับขนาด และการปรับแต่งพื้นฐานอื่น ๆ แค่ไม่ต้องคาดหวังว่ามันจะเป็นทางเลือกแทน Photoshop แต่มันก็ยังมี Magic Wand และเลเยอร์อยู่!

คุณเริ่ม Pinta ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Aether

[Aether](https://github.com/bjarneo/aether) เป็นแอปพลิเคชันจัดธีมที่สามารถสกัดสีจากรูปภาพพื้นหลังแล้วเปลี่ยนให้เป็นธีมที่สมบูรณ์และสอดคล้องกัน มันคือวิธีที่ง่ายที่สุดในการ [สร้างธีมของคุณเอง](43-making-your-own-theme.md)

คุณเริ่ม Aether ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## LocalSend

[LocalSend](https://localsend.org/) ให้คุณส่งไฟล์ไปยังอุปกรณ์อื่นในเครือข่ายเดียวกันที่รันแอปนี้ เหมือน AirDrop ของ Apple แต่มันข้ามแพลตฟอร์ม ดังนั้นคุณจึงส่งไฟล์ไปและกลับจาก Windows, macOS, Android, iOS และแน่นอน Linux ได้

คุณสามารถเปิดเมนูแชร์ด้วย `Super + Ctrl + S` หรือใต้ _สั่งการ > แชร์_ ในเมนู Omarchy มันให้คุณสี่ตัวเลือก:

- **Clipboard** ส่งอะไรก็ตามที่คุณคัดลอกไว้เป็นไฟล์ข้อความ เหมาะมากสำหรับการเอาลิงก์หรือสไนปเป็ตไปไว้บนโทรศัพท์โดยไม่ต้องอีเมลหาตัวเอง
- **File** เปิดตัวเลือกไฟล์ที่คุณเลือกได้หลายไฟล์พร้อมกัน
- **Folder** ส่งทั้งไดเรกทอรี
- **Receive** เปิด LocalSend ตัวจริงเพื่อให้อุปกรณ์อื่นส่งอะไรมาหาคุณได้

สิ่งเดียวกันนี้ก็ทำงานจากเทอร์มินัลด้วย `omarchy share clipboard`, `omarchy share file [path]` และ `omarchy share folder [path]` เว้นพาธไว้แล้วคุณจะได้ตัวเลือกไฟล์

คุณยังส่งตรงจากตัวจัดการไฟล์ได้ด้วย คลิกขวาที่สิ่งที่เลือกใน Nautilus แล้วเลือก _Send via LocalSend_

ไฟร์วอลล์ของ Omarchy ปิดอยู่เป็นค่าเริ่มต้น ยกเว้นพอร์ตของ LocalSend ดังนั้นสิ่งนี้จึงทำงานได้ทันทีบนการติดตั้งใหม่ ดู [ความปลอดภัย](48-security.md)

## LibreOffice

[LibreOffice](https://www.libreoffice.org/) เป็นแพ็กเกจสำนักงานที่สมบูรณ์ พร้อมตัวประมวลผลคำ สเปรดชีต งานนำเสนอ แอปพลิเคชันวาดภาพ และอื่น ๆ มันเข้ากันได้กับไฟล์จาก Microsoft Office ดังนั้นนี่จึงเป็นวิธีที่ดีในการเปิดเอกสาร Word เหล่านั้นได้

คุณเริ่ม LibreOffice ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Hype

[Hype](https://github.com/omacom/hype) คือแอปนำเสนอที่เรียบง่ายตายตัวของ Omarchy เอง ชุดสไลด์ของคุณคือไฟล์ Markdown เดียวพร้อมรูปภาพและวิดีโออยู่ข้าง ๆ เขียนแต่ละสไลด์ใต้ตัวอย่างสด ลากสไลด์ให้เรียงลำดับ แล้วนำเสนอแบบเต็มจอหรือส่งออกเป็น PDF และ PowerPoint มันยังรับธีม Omarchy ของคุณมาด้วย

คุณเริ่ม Hype ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) กด `?` ข้างในเพื่อดูทางลัดทุกตัว

## Signed

[Signed](https://github.com/omacom/signed) คือวิธีเรียบง่ายตายตัวของ Omarchy เองในการเซ็นและกรอก PDF วางลายเซ็นที่บันทึกไว้ ข้อความ และวันที่ของวันนี้ไว้ที่ใดก็ได้บนหน้า แล้วบันทึกสำเนาที่เซ็นแล้วไว้ข้างต้นฉบับ ดูวิธีทำได้ที่ [การกรอก PDF](27-filling-out-pdfs.md)

คุณเริ่ม Signed ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) หรือเปิด PDF ด้วยมันจากตัวจัดการไฟล์

## Omacalc

[Omacalc](https://github.com/omacom-io/omacalc) คือเครื่องคิดเลขเรียบง่ายตายตัวของ Omarchy เอง ซึ่งเปิดในหน้าต่างลอย

คุณเริ่ม Omacalc ด้วย `Super + Ctrl + Q` (หรือปุ่มเครื่องคิดเลข ถ้าคีย์บอร์ดของคุณมี)

## Signal

[Signal](https://signal.org/) คือผู้บุกเบิกการส่งข้อความเข้ารหัสแบบ E2E และเป็นตัวเลือกการสื่อสารที่ยอดเยี่ยมสำหรับทุกคนที่ไม่อยากผ่านกลุ่มบริษัทเทคโนโลยียักษ์ใหญ่รายใดรายหนึ่ง

คุณเริ่ม Signal ด้วย `Super + Shift + G` มันไม่ได้เป็นส่วนหนึ่งของการติดตั้งพื้นฐาน ดังนั้นครั้งแรกที่คุณกด Omarchy จะเสนอติดตั้งให้คุณ (มันอยู่ใต้ _ติดตั้ง > Service_ ในเมนู Omarchy ด้วยเช่นกัน)

## mpv

[mpv](https://mpv.io/) เป็นเครื่องเล่นสื่อที่เรียบง่ายและรวดเร็ว ที่จะเล่นอะไรก็ได้จากแหล่งใดก็ได้ เหมาะมากสำหรับการดูวิดีโอ

คุณเริ่ม mpv ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) หรือแค่ดับเบิลคลิกที่วิดีโอในตัวจัดการไฟล์

## Omacut

[Omacut](https://github.com/omacom-io/omacut) คือตัวตัดแต่งวิดีโอที่เรียบง่ายตายตัวของ Omarchy เอง เมื่อสิ่งที่คุณต้องการมีแค่ตัดหัวและท้ายของคลิปออก มันก็ดีกว่าการเปิดโปรแกรมตัดต่อวิดีโอเต็มรูปแบบ

คุณเริ่ม Omacut ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Monologue

[Monologue](https://github.com/omacom/monologue) คือตัวบันทึกเว็บแคมที่เรียบง่ายตายตัวของ Omarchy เอง เลือกกล้องและไมโครโฟนของคุณสักครั้ง แล้วกด `Space` เพื่อบันทึก และอีกครั้งเพื่อหยุดชั่วคราวและทำเทคเดิมต่อ มันบันทึกที่ความละเอียดสูงสุดของกล้องคุณเสมอ พร้อมมิเตอร์ไมโครโฟนสดเพื่อให้คุณตรวจระดับเสียงได้ก่อนเริ่ม

หยุดเทคแล้วมันจะเปิดขึ้นมาทันทีในตัวแก้ไขในตัว ดับเบิลคลิกที่คลิปเพื่อแยกมัน ลากที่จับเพื่อตัดแต่งแต่ละชิ้น และลบส่วนที่คุณไม่ต้องการออก จากนั้นบันทึกเป็น MP4 การบันทึกต้นฉบับของคุณจะถูกเก็บไว้จนกว่าคุณจะทิ้งมัน ดังนั้นคุณจึงกลับมาตัดมันต่างออกไปได้เสมอ

คุณเริ่ม Monologue ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)
