# GUIs

## ไฟล์

Files (Nautilus) คือโปรแกรมจัดการไฟล์แบบกราฟิก `Super + Shift + F` เปิดมันขึ้นมา และ `Super + Shift + Alt + F` เปิดมันในไดเรกทอรีที่เทอร์มินัลของคุณอยู่ ซึ่งช่วยประหยัดการคลิกไปได้เยอะ `Ctrl + L` ให้คุณพิมพ์พาธได้ และการกด `Space` บนไฟล์ใด ๆ จะแสดงตัวอย่างอย่างรวดเร็วโดยไม่ต้องเปิดอะไรเลย

เสียบแฟลชไดรฟ์ USB หรือการ์ด SD เข้าไป มันจะถูกเมานต์โดยอัตโนมัติ จึงปรากฏขึ้นในแถบด้านข้างทันที สำหรับอะไรที่ซับซ้อนกว่านั้น — การฟอร์แมตไดรฟ์ การตรวจสอบสุขภาพ SMART การสร้างพาร์ติชัน — ให้เปิด _Disks_ จากตัวเปิดแอป (`Super + Space`)

การดับเบิลคลิกเป็นไปตามค่าเริ่มต้นที่สมเหตุสมผล: รูปภาพ วิดีโอ และเพลงเปิดใน Omaview, PDF เปิดใน Document Viewer, Markdown เปิดใน Omawrite และข้อความธรรมดาเปิดในโปรแกรมแก้ไขที่เลือกไว้ภายใต้ _Setup > Default > Editor_

## Disktree

เมื่อไดรฟ์เต็มและคุณไม่รู้เลยว่าอะไรกำลังกินพื้นที่อยู่ ให้เปิด [Disktree](https://github.com/tobi/disktree) จากตัวเปิดแอป (`Super + Space`) มันแสดงแผนภาพ treemap แบบกราฟิกของไดเรกทอรีบ้านของคุณ บล็อกที่ใหญ่กว่าใช้พื้นที่มากกว่า เดินเข้าไปในไดเรกทอรีต่าง ๆ ด้วยแป้นพิมพ์หรือเมาส์ ทำเครื่องหมายสิ่งที่ต้องลบ และตรวจสอบรายการที่เลือกก่อนลบอะไรก็ตาม รัน `disktree --disk` เพื่อสแกนทั้งดิสก์

## Obsidian

[Obsidian](https://obsidian.md/) เป็นแอปจดบันทึกฟรีที่ขยายความสามารถได้สูงมาก ซึ่งใช้ไฟล์ Markdown ธรรมดาสำหรับจัดเก็บ

Obsidian ใช้ฟรีสำหรับทุกวัตถุประสงค์ รวมถึงการใช้งานส่วนตัว เชิงพาณิชย์ และไม่แสวงหาผลกำไร

Obsidian ยังมี [ส่วนเสริมเชิงพาณิชย์สำหรับการซิงค์](https://obsidian.md/sync) กับแอปมือถือบน iOS และ Android อีกด้วย (https://obsidian.md/pricing)

คุณเปิด Obsidian ด้วย `Super + Shift + O` หากต้องการใช้การซิงค์ธีม คุณต้องเลือกธีม `Omarchy` ภายใต้การตั้งค่า

## Omawrite

[Omawrite](https://github.com/omacom-io/omawrite) เป็นแอปเขียน Markdown ที่เรียบง่ายสุด ๆ ของ Omarchy เอง ไม่มี vault ไม่มีปลั๊กอิน มีแค่คุณกับถ้อยคำ

คุณเปิด Omawrite ด้วย `Super + Shift + W`

## Pinta

[Pinta](https://www.pinta-project.com/) เป็นเครื่องมือแก้ไขรูปภาพพื้นฐานที่เหมาะมากสำหรับการครอบตัด ปรับขนาด และการปรับแต่งพื้นฐานอื่น ๆ แค่อย่าคาดหวังว่ามันจะเป็นทางเลือกแทน Photoshop แต่มันก็ยังมี Magic Wand และเลเยอร์!

คุณเปิด Pinta ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Aether

[Aether](https://github.com/bjarneo/aether) เป็นแอปพลิเคชันสร้างธีมที่สามารถดึงสีจากภาพพื้นหลังและเปลี่ยนให้เป็นธีมที่สมบูรณ์และกลมกลืนกัน เป็นวิธีที่ง่ายที่สุดในการ [สร้างธีมของคุณเอง](43-making-your-own-theme.md)

คุณเปิด Aether ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## LocalSend

[LocalSend](https://localsend.org/) ให้คุณส่งไฟล์ไปยังอุปกรณ์อื่นบนเครือข่ายเดียวกันที่รันแอปนี้อยู่ เหมือน AirDrop ของ Apple เพียงแต่มันข้ามแพลตฟอร์มได้ ดังนั้นคุณจึงส่งไฟล์ไปและกลับจาก Windows, macOS, Android, iOS และแน่นอน Linux ได้

คุณเปิดเมนู Share ได้ด้วย `Super + Ctrl + S` หรือภายใต้ _Trigger > Share_ ในเมนู Omarchy มันให้คุณสี่ตัวเลือก:

- **Clipboard** ส่งสิ่งที่คุณคัดลอกไว้เป็นไฟล์ข้อความ เหมาะมากสำหรับการส่งลิงก์หรือโค้ดสั้น ๆ ไปยังโทรศัพท์ของคุณโดยไม่ต้องส่งอีเมลหาตัวเอง
- **File** เปิดตัวเลือกไฟล์ซึ่งคุณสามารถเลือกหลายไฟล์พร้อมกันได้
- **Folder** ส่งไดเรกทอรีทั้งไดเรกทอรี
- **Receive** เปิด LocalSend ตัวจริงเพื่อให้อุปกรณ์อื่นส่งบางอย่างมาหาคุณได้

สิ่งเดียวกันนี้ทำงานจากเทอร์มินัลด้วย `omarchy share clipboard`, `omarchy share file [path]` และ `omarchy share folder [path]` หากไม่ใส่พาธ คุณจะได้ตัวเลือกไฟล์

คุณยังส่งตรงจากโปรแกรมจัดการไฟล์ได้อีกด้วย: คลิกขวาที่รายการที่เลือกใน Nautilus แล้วเลือก _Send via LocalSend_

ไฟร์วอลล์ของ Omarchy ปิดอยู่เป็นค่าเริ่มต้น ยกเว้นพอร์ตของ LocalSend ดังนั้นสิ่งนี้จึงใช้งานได้ทันทีตั้งแต่ติดตั้งใหม่ ดู [ความปลอดภัย](48-security.md)

## LibreOffice

[LibreOffice](https://www.libreoffice.org/) เป็นชุดโปรแกรมสำนักงานที่ครบถ้วน พร้อมโปรแกรมประมวลผลคำ สเปรดชีต งานนำเสนอ แอปพลิเคชันวาดรูป และอื่น ๆ มันเข้ากันได้กับไฟล์จาก Microsoft Office ดังนั้นนี่จึงเป็นวิธีที่ดีเยี่ยมในการเปิดเอกสาร Word เหล่านั้นได้

คุณเปิด LibreOffice ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Hype

[Hype](https://github.com/omacom/hype) เป็นแอปนำเสนอที่เรียบง่ายสุด ๆ ของ Omarchy เอง ชุดสไลด์ของคุณเป็นไฟล์ Markdown ไฟล์เดียว โดยมีรูปภาพและวิดีโออยู่ข้าง ๆ: เขียนแต่ละสไลด์ใต้ตัวอย่างแบบสด ลากสไลด์เพื่อจัดลำดับ จากนั้นนำเสนอแบบเต็มจอหรือส่งออกเป็น PDF และ PowerPoint มันยังรับธีม Omarchy ของคุณมาด้วย

คุณเปิด Hype ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) กด `?` ข้างในเพื่อดูทุกทางลัด

## Signed

[Signed](https://github.com/omacom/signed) เป็นวิธีเซ็น PDF และกรอกแบบฟอร์มใน PDF ที่เรียบง่ายสุด ๆ ของ Omarchy เอง วางลายเซ็นที่บันทึกไว้ ข้อความ และวันที่ของวันนี้ไว้ที่ใดก็ได้บนหน้า จากนั้นบันทึกสำเนาที่เซ็นแล้วไว้ข้างไฟล์ต้นฉบับ ดู [การกรอก PDF](27-filling-out-pdfs.md) สำหรับวิธีทำ

คุณเปิด Signed ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) หรือเปิด PDF ด้วยมันจากโปรแกรมจัดการไฟล์

## Checkmate

[Checkmate](https://github.com/omacom/checkmate) เป็นเกมหมากรุก 3D ของ Omarchy เอง เล่นกับเพื่อนบนคอมพิวเตอร์เครื่องเดียวกันหรือกับคู่ต่อสู้ในตัวที่สามระดับ บนชุดหมากรุกแกะสลักสี่ชุดที่แต่ละชุดเคลื่อนไหวในแบบของตัวเอง: ยานโคจร ไม้และงาช้างแกะสลัก สัตว์ในป่า และลูกกวาด เกมไม่มีนาฬิกาและบันทึกหลังการเดินทุกครั้ง

คุณเปิด Checkmate ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) โดยมันจะแสดงชื่อเป็น Chess กด `?` ข้างในเพื่อดูทุกทางลัด

## Omacalc

[Omacalc](https://github.com/omacom-io/omacalc) เป็นเครื่องคิดเลขที่เรียบง่ายสุด ๆ ของ Omarchy เอง ซึ่งเปิดในหน้าต่างลอย

คุณเปิด Omacalc ด้วย `Super + Shift + Q` (หรือปุ่มเครื่องคิดเลข หากแป้นพิมพ์ของคุณมี)

## Signal

[Signal](https://signal.org/) เป็นผู้บุกเบิกการส่งข้อความเข้ารหัสแบบ E2E และเป็นตัวเลือกการสื่อสารที่ยอดเยี่ยมสำหรับใครก็ตามที่ไม่อยากผ่านบริษัทเทคโนโลยียักษ์ใหญ่รายใดรายหนึ่ง

คุณเปิด Signal ด้วย `Super + Shift + G` มันไม่ได้เป็นส่วนหนึ่งของการติดตั้งพื้นฐาน ดังนั้นครั้งแรกที่คุณกดปุ่มนั้น Omarchy จะเสนอติดตั้งให้คุณ (มันอยู่ภายใต้ _Install > Service_ ในเมนู Omarchy ด้วย)

## Omaview

[Omaview](https://github.com/omacom/omaview) เป็นโปรแกรมดูรูปภาพและเครื่องเล่นสื่อที่เรียบง่ายสุด ๆ ของ Omarchy เอง: หน้าต่างเดียวสำหรับรูปภาพ วิดีโอ และเพลงของคุณ เปิดรูปภาพแล้วปุ่มลูกศรจะไล่ดูไฟล์ที่เหลือในโฟลเดอร์ของมัน `N` และ `P` ทำแบบเดียวกันสำหรับทุกอย่าง และ `Ctrl + M` แสดงทั้งโฟลเดอร์เป็นตาราง มันแสดงรูปภาพ HEIC, AVIF และ JPEG XL ได้ด้วย และเล่นต่อจากจุดที่คุณค้างไว้ในอะไรก็ตามที่ยาว ๆ

กด `F` สำหรับเต็มจอ `E` เพื่อแก้ไขรูปภาพใน Omasnap หรือตัดวิดีโอใน Omacut `Ctrl + P` เพื่อพิมพ์รูปภาพ และ `Delete` เพื่อย้ายไฟล์ไปยัง Trash (`Ctrl + Z` นำมันกลับมา) กด `?` ข้างในเพื่อดูทุกทางลัด

คุณเปิด Omaview ในชื่อ _Media Viewer_ ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) หรือเพียงดับเบิลคลิกรูปภาพ วิดีโอ หรือเพลงในโปรแกรมจัดการไฟล์

## Omacut

[Omacut](https://github.com/omacom-io/omacut) เป็นโปรแกรมตัดวิดีโอที่เรียบง่ายสุด ๆ ของ Omarchy เอง เมื่อสิ่งที่คุณต้องการมีเพียงตัดส่วนต้นและส่วนท้ายของคลิปออก มันดีกว่าการเปิดโปรแกรมตัดต่อวิดีโอเต็มรูปแบบขึ้นมา

คุณเปิด Omacut ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Monologue

[Monologue](https://github.com/omacom/monologue) เป็นโปรแกรมบันทึกเว็บแคมที่เรียบง่ายสุด ๆ ของ Omarchy เอง เลือกกล้องและไมโครโฟนของคุณครั้งเดียว จากนั้นกด `Space` เพื่อบันทึก และกดอีกครั้งเพื่อหยุดชั่วคราวและบันทึกเทคเดิมต่อ มันบันทึกที่ความละเอียดสูงสุดของกล้องของคุณเสมอ พร้อมมิเตอร์ไมโครโฟนแบบสดเพื่อให้คุณตรวจสอบระดับเสียงก่อนเริ่มได้

หยุดเทคแล้วมันจะเปิดทันทีในโปรแกรมแก้ไขในตัว ดับเบิลคลิกคลิปเพื่อแยกมัน ลากที่จับเพื่อตัดแต่ละชิ้น และลบส่วนที่คุณไม่ต้องการออก จากนั้นบันทึกเป็น MP4 บันทึกต้นฉบับของคุณจะถูกเก็บไว้จนกว่าคุณจะทิ้งมัน ดังนั้นคุณจึงกลับมาตัดมันแบบอื่นได้เสมอ

คุณเปิด Monologue ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)
