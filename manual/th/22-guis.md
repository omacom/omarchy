# GUIs

## Files

Files (Nautilus) คือตัวจัดการไฟล์แบบกราฟิก เปิดด้วย `Super + Shift + F` และ `Super + Shift + Alt + F` จะเปิดในไดเรกทอรีที่เทอร์มินัลของคุณอยู่ตอนนี้ ซึ่งช่วยประหยัดการคลิกไปได้เยอะมาก `Ctrl + L` ให้คุณพิมพ์พาธได้ และการกด `Space` บนไฟล์ใด ๆ จะแสดงตัวอย่างแบบด่วนให้โดยไม่ต้องเปิดอะไรเลย

เสียบแท่ง USB หรือการ์ด SD เข้าไป มันจะถูกเมานต์โดยอัตโนมัติ จึงปรากฏขึ้นในแถบด้านข้างทันที สำหรับงานที่ซับซ้อนกว่านั้น — ฟอร์แมตไดรฟ์ ตรวจสอบสุขภาพ SMART สร้างพาร์ติชัน — ให้เปิด _Disks_ จากตัวเปิดแอป (`Super + Space`)

การดับเบิลคลิกเป็นไปตามค่าเริ่มต้นที่สมเหตุสมผล: รูปภาพ วิดีโอ และเพลงจะเปิดใน Omaview, PDF เปิดใน Document Viewer, Markdown เปิดใน Omawrite และข้อความธรรมดาเปิดในตัวแก้ไขที่เลือกไว้ใต้ _Setup > Default > Editor_

## Disktree

เมื่อไดรฟ์เต็มและคุณไม่รู้เลยว่าอะไรกำลังกินพื้นที่อยู่ ให้เปิด [Disktree](https://github.com/tobi/disktree) จากตัวเปิดแอป (`Super + Space`) มันจะแสดงแผนภาพทรีแมปแบบกราฟิกของไดเรกทอรีโฮมของคุณ บล็อกที่ใหญ่กว่าจะใช้พื้นที่มากกว่า เดินเข้าไปในไดเรกทอรีต่าง ๆ ด้วยคีย์บอร์ดหรือเมาส์ ทำเครื่องหมายสิ่งที่ควรลบออก และตรวจสอบรายการที่เลือกก่อนจะลบอะไรทิ้ง รัน `disktree --disk` เพื่อสแกนทั้งดิสก์

## Obsidian

[Obsidian](https://obsidian.md/) คือแอปจดบันทึกฟรีที่ขยายความสามารถได้อย่างมาก ซึ่งใช้ไฟล์ Markdown ธรรมดาสำหรับจัดเก็บข้อมูล

Obsidian ใช้ฟรีได้ทุกวัตถุประสงค์ รวมถึงการใช้งานส่วนตัว เชิงพาณิชย์ และไม่แสวงหาผลกำไร

Obsidian ยังมี [ส่วนเสริมเชิงพาณิชย์สำหรับการซิงค์](https://obsidian.md/sync) กับแอปบนมือถือใน iOS และ Android อีกด้วย (https://obsidian.md/pricing)

คุณเปิด Obsidian ด้วย `Super + Shift + O` หากต้องการใช้การซิงค์ธีม คุณต้องเลือกธีม `Omarchy` ใต้การตั้งค่า

## Omawrite

[Omawrite](https://github.com/omacom-io/omawrite) คือแอปเขียน Markdown ที่เรียบง่ายสุด ๆ ของ Omarchy เอง ไม่มี vault ไม่มีปลั๊กอิน มีแค่คุณกับถ้อยคำ

คุณเปิด Omawrite ด้วย `Super + Shift + W`

## Pinta

[Pinta](https://www.pinta-project.com/) คือเครื่องมือแก้ไขรูปภาพพื้นฐานที่เหมาะมากสำหรับการครอบตัด ปรับขนาด และการปรับแต่งพื้นฐานอื่น ๆ แค่อย่าคาดหวังว่ามันจะเป็นตัวแทนของ Photoshop แต่มันก็ยังมี Magic Wand และเลเยอร์นะ!

คุณเปิด Pinta ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Aether

[Aether](https://github.com/bjarneo/aether) คือแอปพลิเคชันสร้างธีมที่สามารถดึงสีจากภาพพื้นหลังและเปลี่ยนให้เป็นธีมที่สมบูรณ์และกลมกลืนกันได้ เป็นวิธีที่ง่ายที่สุดในการ [สร้างธีมของคุณเอง](43-making-your-own-theme.md)

คุณเปิด Aether ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## LocalSend

[LocalSend](https://localsend.org/) ให้คุณส่งไฟล์ไปยังอุปกรณ์อื่น ๆ บนเครือข่ายเดียวกันที่รันแอปนี้อยู่ได้ เหมือน AirDrop ของ Apple แต่มันข้ามแพลตฟอร์มได้ ดังนั้นคุณจึงส่งไฟล์ไปและกลับจาก Windows, macOS, Android, iOS และแน่นอน Linux ได้

คุณเปิดเมนู Share ได้ด้วย `Super + Ctrl + S` หรือใต้ _Trigger > Share_ ในเมนู Omarchy มันให้คุณสี่ตัวเลือก:

- **Clipboard** ส่งสิ่งที่คุณคัดลอกไว้เป็นไฟล์ข้อความ เหมาะมากสำหรับส่งลิงก์หรือโค้ดสั้น ๆ ไปยังโทรศัพท์ของคุณโดยไม่ต้องส่งอีเมลหาตัวเอง
- **File** เปิดตัวเลือกไฟล์ซึ่งคุณสามารถเลือกได้หลายไฟล์พร้อมกัน
- **Folder** ส่งไดเรกทอรีทั้งหมด
- **Receive** เปิด LocalSend ตัวจริงเพื่อให้อุปกรณ์อื่นส่งบางอย่างมาหาคุณได้

สิ่งเดียวกันนี้ทำงานจากเทอร์มินัลได้ด้วย `omarchy share clipboard`, `omarchy share file [path]` และ `omarchy share folder [path]` ไม่ต้องใส่พาธก็ได้ แล้วคุณจะได้ตัวเลือกไฟล์

คุณยังส่งตรงจากตัวจัดการไฟล์ได้อีกด้วย: คลิกขวาที่รายการที่เลือกใน Nautilus แล้วเลือก _Send via LocalSend_

ไฟร์วอลล์ของ Omarchy ปิดอยู่เป็นค่าเริ่มต้น ยกเว้นพอร์ตของ LocalSend ดังนั้นสิ่งนี้จึงใช้งานได้ทันทีตั้งแต่ติดตั้งใหม่ ๆ ดู [ความปลอดภัย](48-security.md)

## LibreOffice

[LibreOffice](https://www.libreoffice.org/) คือชุดโปรแกรมสำนักงานที่ครบถ้วน พร้อมโปรแกรมประมวลผลคำ สเปรดชีต งานนำเสนอ แอปพลิเคชันวาดภาพ และอื่น ๆ อีกมากมาย มันเข้ากันได้กับไฟล์จาก Microsoft Office ดังนั้นนี่จึงเป็นวิธีที่ดีเยี่ยมในการเปิดเอกสาร Word เหล่านั้นได้

คุณเปิด LibreOffice ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Hype

[Hype](https://github.com/omacom/hype) คือแอปนำเสนอที่เรียบง่ายสุด ๆ ของ Omarchy เอง สไลด์ของคุณคือไฟล์ Markdown ไฟล์เดียวที่มีรูปภาพและวิดีโออยู่ข้าง ๆ: เขียนแต่ละสไลด์ใต้ตัวอย่างแบบสด ลากสไลด์เพื่อจัดลำดับ จากนั้นนำเสนอแบบเต็มหน้าจอหรือส่งออกเป็น PDF และ PowerPoint มันยังรับธีม Omarchy ของคุณมาด้วย

คุณเปิด Hype ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) กด `?` ข้างในเพื่อดูทางลัดทั้งหมด

## Signed

[Signed](https://github.com/omacom/signed) คือวิธีเซ็น PDF และกรอกแบบฟอร์มใน PDF ที่เรียบง่ายสุด ๆ ของ Omarchy เอง วางลายเซ็นที่บันทึกไว้ ข้อความ และวันที่ของวันนี้ไว้ที่ใดก็ได้บนหน้า จากนั้นบันทึกสำเนาที่เซ็นแล้วไว้ข้างต้นฉบับ ดูวิธีทำได้ที่ [การกรอก PDF](27-filling-out-pdfs.md)

คุณเปิด Signed ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) หรือเปิด PDF ด้วยมันจากตัวจัดการไฟล์

## Game Vibes

Game Vibes ในตัวเปิดแอปพลิเคชัน (`Super + Space`) คือที่ที่เกมเล็ก ๆ ของ Omarchy อาศัยอยู่: Checkmate เกมหมากรุก 3D ที่เล่นกับเพื่อนหรือคู่ต่อสู้ในตัว, Cards เกมไพ่ Klondike solitaire และ Neon Swarm เกมยิงอาร์เคด แต่ละเกมเป็นเว็บเพจเดียวที่ทำตามธีมของคุณ เลือกเกมด้วยปุ่มลูกศรและ `Enter` และกลับมาที่รายการด้วย `Esc` จากหน้าจอชื่อเรื่องของเกม หรือ `Q` ขณะที่เกมหยุดชั่วคราว มันเปิดแบบเต็มหน้าจอ: `Super + F` ทำให้มันเป็นหน้าต่าง และ `Super + W` ปิดมัน

เกมที่คุณสร้างด้วยเอเจนต์ก็ปรากฏที่นี่เช่นกัน: เลือก _Make something cool → Game_ ในแผงเอเจนต์และอธิบายเกม หรือระบุชื่อเกมที่มีอยู่แล้วใน Game Vibes เพื่อทำงานกับมันต่อ เอเจนต์จะคัดลอกมันไปยัง `~/Games/vibes` ซึ่งมันจะเป็นของคุณให้เปลี่ยนได้ตามใจ และจะเปิดมันเมื่อเสร็จแล้ว คุณสร้างสำเนานั้นเองได้ด้วย `omarchy games vibes copy <game>` เกมที่คนอื่นแชร์จะติดตั้งเหมือนธีม: เลือก _Install > Gaming > Game Vibes_ และวางที่อยู่ git ของมัน หรือรัน `omarchy games vibes install <git-repo-url>` ส่วน _Remove > Gaming_ จะเอามันออกอีกครั้ง และ _Update > Game Vibes Games_ จะดึงเวอร์ชันใหม่มา เกมต่าง ๆ โหลด three.js จากเว็บ ดังนั้นพวกมันจึงต้องการการเชื่อมต่อเพื่อเริ่มต้น

## Omacalc

[Omacalc](https://github.com/omacom-io/omacalc) คือเครื่องคิดเลขที่เรียบง่ายสุด ๆ ของ Omarchy เอง ซึ่งเปิดในหน้าต่างลอย

คุณเปิด Omacalc ด้วย `Super + Shift + Q` (หรือปุ่มเครื่องคิดเลข หากคีย์บอร์ดของคุณมี)

## Signal

[Signal](https://signal.org/) คือผู้บุกเบิกการส่งข้อความแบบเข้ารหัส E2E และเป็นตัวเลือกการสื่อสารที่ยอดเยี่ยมสำหรับใครก็ตามที่อยากเลี่ยงบริษัทเทคโนโลยียักษ์ใหญ่

คุณเปิด Signal ด้วย `Super + Shift + G` มันไม่ได้เป็นส่วนหนึ่งของการติดตั้งพื้นฐาน ดังนั้นครั้งแรกที่คุณกดปุ่มนั้น Omarchy จะเสนอให้ติดตั้งให้คุณ (มันอยู่ใต้ _Install > Service_ ในเมนู Omarchy ด้วย)

## Omaview

[Omaview](https://github.com/omacom/omaview) คือโปรแกรมดูรูปภาพและเครื่องเล่นสื่อที่เรียบง่ายสุด ๆ ของ Omarchy เอง: หน้าต่างเดียวสำหรับรูปภาพ วิดีโอ และเพลงของคุณ เปิดรูปภาพแล้วปุ่มลูกศรจะไล่ดูไฟล์ที่เหลือในโฟลเดอร์ของมัน `N` และ `P` ทำแบบเดียวกันสำหรับทุกอย่าง และ `Ctrl + M` จะแสดงทั้งโฟลเดอร์เป็นตาราง มันแสดงรูปภาพ HEIC, AVIF และ JPEG XL ได้ด้วย และเล่นต่อจากจุดที่คุณค้างไว้ในอะไรก็ตามที่ยาว ๆ ได้

กด `F` เพื่อเต็มหน้าจอ `E` เพื่อแก้ไขรูปภาพใน Omasnap หรือตัดวิดีโอใน Omacut `Ctrl + P` เพื่อพิมพ์รูปภาพ และ `Delete` เพื่อย้ายไฟล์ไปยังถังขยะ (`Ctrl + Z` นำมันกลับมา) กด `?` ข้างในเพื่อดูทางลัดทั้งหมด

คุณเปิด Omaview ในชื่อ _Media Viewer_ ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) หรือแค่ดับเบิลคลิกที่รูปภาพ วิดีโอ หรือเพลงในตัวจัดการไฟล์

## Omacut

[Omacut](https://github.com/omacom-io/omacut) คือโปรแกรมตัดวิดีโอที่เรียบง่ายสุด ๆ ของ Omarchy เอง เมื่อสิ่งที่คุณต้องการมีแค่ตัดส่วนต้นและส่วนท้ายของคลิปออก มันดีกว่าการเปิดโปรแกรมตัดต่อวิดีโอเต็มรูปแบบขึ้นมาเยอะ

คุณเปิด Omacut ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Monologue

[Monologue](https://github.com/omacom/monologue) คือโปรแกรมบันทึกเว็บแคมที่เรียบง่ายสุด ๆ ของ Omarchy เอง เลือกกล้องและไมโครโฟนของคุณครั้งเดียว จากนั้นกด `Space` เพื่อบันทึก และกดอีกครั้งเพื่อหยุดชั่วคราวและบันทึกเทคเดียวกันต่อ มันจะบันทึกที่ความละเอียดสูงสุดของกล้องของคุณเสมอ พร้อมมาตรวัดระดับไมโครโฟนแบบสดเพื่อให้คุณตรวจสอบระดับเสียงได้ก่อนเริ่มต้น

หยุดเทคแล้วมันจะเปิดขึ้นมาทันทีในตัวแก้ไขในตัว ดับเบิลคลิกที่คลิปเพื่อแยกมัน ลากที่จับเพื่อตัดแต่ละส่วน และลบส่วนที่คุณไม่ต้องการออก จากนั้นบันทึกเป็น MP4 บันทึกต้นฉบับของคุณจะถูกเก็บไว้จนกว่าคุณจะทิ้งมัน ดังนั้นคุณจึงกลับมาตัดมันแบบอื่นได้เสมอ

คุณเปิด Monologue ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)
