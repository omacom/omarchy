# แอปกราฟิก

## Files

Files (Folio) คือโปรแกรมจัดการไฟล์แบบกราฟิก `Super + Shift + F` เปิดโปรแกรมนี้ขึ้นมา และ `Super + Shift + Alt + F` เปิดโปรแกรมนี้ในไดเรกทอรีที่เทอร์มินัลของคุณกำลังอยู่ ซึ่งช่วยประหยัดการคลิกไปได้เยอะ `Ctrl + L` ให้คุณพิมพ์เส้นทางได้ และการกด `Space` บนไฟล์ใด ๆ จะแสดงตัวอย่างไฟล์นั้นแบบเต็มขนาดโดยไม่ต้องเปิดมัน

เสียบแท่ง USB หรือการ์ด SD เข้าไป มันจะถูกเมานต์โดยอัตโนมัติ จึงปรากฏขึ้นในแถบด้านข้างทันที สำหรับอะไรที่ซับซ้อนกว่านั้น — การฟอร์แมตไดรฟ์ การตรวจสอบสุขภาพ SMART การสร้างพาร์ติชัน — ให้เปิด _Disks_ จากตัวเปิดแอป (`Super + Space`)

การดับเบิลคลิกเป็นไปตามค่าเริ่มต้นที่สมเหตุสมผล: รูปภาพ วิดีโอ และเพลงเปิดใน Omaview, PDF เปิดใน Document Viewer, Markdown เปิดใน Omawrite และข้อความธรรมดาเปิดในโปรแกรมแก้ไขของคุณ คือ Plain เว้นแต่คุณจะเลือกโปรแกรมอื่นไว้ใน _Setup > Defaults > Editor_

## Disktree

เมื่อไดรฟ์เต็มและคุณไม่รู้เลยว่าอะไรกำลังกินพื้นที่อยู่ ให้เปิด [Disktree](https://github.com/tobi/disktree) จากตัวเปิดแอป (`Super + Space`) มันแสดงแผนภาพ treemap แบบกราฟิกของไดเรกทอรี home ของคุณ บล็อกที่ใหญ่กว่าใช้พื้นที่มากกว่า เดินเข้าไปในไดเรกทอรีต่าง ๆ ด้วยคีย์บอร์ดหรือเมาส์ ทำเครื่องหมายสิ่งที่ควรลบออก และตรวจทานสิ่งที่คุณเลือกไว้ก่อนจะลบอะไรทิ้ง รัน `disktree --disk` เพื่อสแกนทั้งดิสก์

## Obsidian

[Obsidian](https://obsidian.md/) คือแอปจดบันทึกที่ใช้งานได้ฟรีและขยายความสามารถได้มากมาย ซึ่งใช้ไฟล์ Markdown ธรรมดาในการจัดเก็บข้อมูล

Obsidian ใช้งานได้ฟรีสำหรับทุกวัตถุประสงค์ รวมถึงการใช้งานส่วนตัว เชิงพาณิชย์ และไม่แสวงหาผลกำไร

Obsidian ยังมี [ส่วนเสริมเชิงพาณิชย์สำหรับการซิงค์](https://obsidian.md/sync) กับแอปบนมือถือใน iOS และ Android ให้ใช้ด้วย (https://obsidian.md/pricing)

คุณเปิด Obsidian ด้วย `Super + Shift + O` หากต้องการใช้การซิงค์ธีม คุณต้องเลือกธีม `Omarchy` ในส่วนการตั้งค่า

## Omawrite

[Omawrite](https://github.com/omacom-io/omawrite) คือแอปเขียน Markdown ที่เรียบง่ายสุด ๆ ของ Omarchy เอง ไม่มี vault ไม่มีปลั๊กอิน มีแค่คุณกับถ้อยคำของคุณ

คุณเปิด Omawrite ด้วย `Super + Shift + W`

## Pinta

[Pinta](https://www.pinta-project.com/) คือเครื่องมือแก้ไขภาพพื้นฐานที่เหมาะมากสำหรับการครอบตัด การปรับขนาด และการปรับแต่งพื้นฐานอื่น ๆ แค่อย่าไปคาดหวังว่ามันจะเป็นตัวแทนของ Photoshop แต่มันก็ยังมี Magic Wand และเลเยอร์ให้ใช้อยู่นะ!

คุณเปิด Pinta ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Aether

[Aether](https://github.com/bjarneo/aether) คือแอปสร้างธีมที่สามารถดึงสีจากภาพพื้นหลังและเปลี่ยนให้กลายเป็นธีมที่สมบูรณ์และกลมกลืนกันได้ นี่คือวิธีที่ง่ายที่สุดในการ [สร้างธีมของคุณเอง](43-making-your-own-theme.md)

คุณเปิด Aether ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## LocalSend

[LocalSend](https://localsend.org/) ให้คุณส่งไฟล์ไปยังอุปกรณ์เครื่องอื่นบนเครือข่ายเดียวกันที่รันแอปนี้อยู่ได้ เหมือนกับ AirDrop ของ Apple แต่เป็นแบบข้ามแพลตฟอร์ม ดังนั้นคุณจึงส่งไฟล์ไปและกลับจาก Windows, macOS, Android, iOS และแน่นอนว่า Linux ได้

คุณสามารถเปิดเมนู Share ได้ด้วย `Super + Ctrl + S` หรือใน _Trigger > Share_ ในเมนู Omarchy มันให้ตัวเลือกคุณสี่อย่าง:

- **Clipboard** ส่งสิ่งที่คุณคัดลอกไว้เป็นไฟล์ข้อความ เหมาะมากสำหรับการส่งลิงก์หรือโค้ดสั้น ๆ ไปยังโทรศัพท์ของคุณโดยไม่ต้องส่งอีเมลหาตัวเอง
- **File** เปิดตัวเลือกไฟล์ซึ่งคุณสามารถเลือกได้หลายไฟล์พร้อมกัน
- **Folder** ส่งไดเรกทอรีทั้งไดเรกทอรี
- **Receive** เปิด LocalSend ขึ้นมาโดยตรงเพื่อให้อุปกรณ์เครื่องอื่นส่งบางอย่างมาหาคุณได้

สิ่งเดียวกันนี้ใช้งานได้จากเทอร์มินัลด้วย `omarchy share clipboard`, `omarchy share file [path]` และ `omarchy share folder [path]` ถ้าไม่ใส่ path คุณก็จะได้ตัวเลือกไฟล์ขึ้นมา

คุณยังส่งตรงจากโปรแกรมจัดการไฟล์ได้อีกด้วย: คลิกขวาที่สิ่งที่เลือกไว้ใน Files แล้วแชร์มันด้วย LocalSend

ไฟร์วอลล์ของ Omarchy ปิดอยู่เป็นค่าเริ่มต้น ยกเว้นพอร์ตของ LocalSend ดังนั้นสิ่งนี้จึงใช้งานได้ทันทีหลังติดตั้งใหม่ ดู [ความปลอดภัย](48-security.md)

## LibreOffice

[LibreOffice](https://www.libreoffice.org/) คือชุดโปรแกรมสำนักงานที่ครบเครื่อง พร้อมโปรแกรมประมวลผลคำ สเปรดชีต โปรแกรมนำเสนอ แอปวาดภาพ และอื่น ๆ อีกมากมาย มันเข้ากันได้กับไฟล์จาก Microsoft Office ดังนั้นนี่จึงเป็นวิธีที่ยอดเยี่ยมในการเปิดเอกสาร Word เหล่านั้น

คุณเปิด LibreOffice ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Hype

[Hype](https://github.com/omacom/hype) คือแอปนำเสนอที่เรียบง่ายสุด ๆ ของ Omarchy เอง สไลด์ของคุณคือไฟล์ Markdown ไฟล์เดียวที่มีภาพและวิดีโออยู่ข้าง ๆ กัน: เขียนแต่ละสไลด์ใต้ตัวอย่างที่แสดงแบบสด ลากสไลด์เพื่อจัดลำดับ จากนั้นนำเสนอแบบเต็มจอหรือส่งออกเป็น PDF และ PowerPoint ได้เลย มันยังดึงธีม Omarchy ของคุณมาใช้ด้วย

คุณเปิด Hype ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) กด `?` ข้างในแอปเพื่อดูทางลัดทุกอย่าง

## Signed

[Signed](https://github.com/omacom/signed) คือวิธีเซ็น PDF และกรอกแบบฟอร์มใน PDF ที่เรียบง่ายสุด ๆ ของ Omarchy เอง วางลายเซ็นที่บันทึกไว้ ข้อความ และวันที่ของวันนี้ลงตรงไหนก็ได้บนหน้า จากนั้นบันทึกสำเนาที่เซ็นแล้วไว้ข้างต้นฉบับ ดู [การกรอก PDF](27-filling-out-pdfs.md) เพื่อดูวิธีการ

คุณเปิด Signed ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) หรือเปิด PDF ด้วยมันจากโปรแกรมจัดการไฟล์

## Game Vibes

Game Vibes ในตัวเปิดแอปพลิเคชัน (`Super + Space`) คือที่ที่เกมเล็ก ๆ ของ Omarchy อาศัยอยู่: Checkmate เกมหมากรุก 3D ที่เล่นกับเพื่อนหรือคู่ต่อสู้ในตัว, Cards เกมไพ่โซลิแทร์แบบ Klondike, Death Wish เกมแพลตฟอร์มที่ต้องแม่นยำระดับพิกเซล มีห้องสิบห้องที่เต็มไปด้วยหนามและใบเลื่อย และ Neon Swarm เกมยิงสไตล์อาร์เคด แต่ละเกมคือเว็บเพจเดียวที่ตามธีมของคุณ เลือกเกมหนึ่งด้วยปุ่มลูกศรและ `Enter` แล้วกลับมาที่รายการด้วย `Esc` จากหน้าจอชื่อเรื่องของเกม หรือ `Q` ขณะที่หยุดเกมชั่วคราว มันเปิดขึ้นมาแบบเต็มจอ: `Super + F` ทำให้มันกลายเป็นหน้าต่าง และ `Super + W` ปิดมันลง

เกมที่คุณสร้างกับ agent ก็ปรากฏที่นี่เช่นกัน: เลือก _Make something cool → Game_ ในแผง agents และอธิบายเกมที่คุณต้องการ หรือระบุชื่อเกมที่มีอยู่แล้วใน Game Vibes เพื่อทำงานกับมันต่อ agent จะคัดลอกมันไปยัง `~/Games/vibes` ซึ่งมันจะเป็นของคุณให้แก้ไขได้ตามใจ และเปิดมันให้เมื่อทำเสร็จ คุณทำสำเนานั้นเองได้ด้วย `omarchy games vibes copy <game>` เกมที่คนอื่นแชร์มาติดตั้งได้เหมือนธีม: เลือก _Install > Gaming > Game Vibes_ แล้ววางที่อยู่ git ของมัน หรือรัน `omarchy games vibes install <git-repo-url>` ส่วน _Remove > Gaming_ เอาเกมออกอีกครั้ง และ _Update > Game Vibes Games_ ดึงเวอร์ชันใหม่มาให้ เกมต่าง ๆ โหลด three.js จากเว็บ ดังนั้นพวกมันจึงต้องการการเชื่อมต่ออินเทอร์เน็ตในการเริ่มเล่น

## Omacalc

[Omacalc](https://github.com/omacom-io/omacalc) คือเครื่องคิดเลขที่เรียบง่ายสุด ๆ ของ Omarchy เอง ซึ่งเปิดขึ้นมาในหน้าต่างแบบลอย

คุณเปิด Omacalc ด้วย `Super + Shift + Q` (หรือปุ่มเครื่องคิดเลข ถ้าคีย์บอร์ดของคุณมีปุ่มนั้น)

## Signal

[Signal](https://signal.org/) คือผู้บุกเบิกการส่งข้อความแบบเข้ารหัส E2E และเป็นตัวเลือกการสื่อสารที่ยอดเยี่ยมสำหรับใครก็ตามที่ไม่อยากผ่านบรรดาบริษัทเทคโนโลยียักษ์ใหญ่

คุณเปิด Signal ด้วย `Super + Shift + G` มันไม่ได้เป็นส่วนหนึ่งของการติดตั้งพื้นฐาน ดังนั้นครั้งแรกที่คุณกดปุ่มนั้น Omarchy จะเสนอให้ติดตั้งมันให้คุณ (มันยังอยู่ใน _Install > Service_ ในเมนู Omarchy ด้วย)

## Omaview

[Omaview](https://github.com/omacom/omaview) คือโปรแกรมดูรูปภาพและเครื่องเล่นสื่อที่เรียบง่ายสุด ๆ ของ Omarchy เอง: หน้าต่างเดียวสำหรับรูปภาพ วิดีโอ และเพลงของคุณ เปิดรูปภาพขึ้นมาแล้วปุ่มลูกศรจะไล่ไปตามไฟล์ที่เหลือในโฟลเดอร์ของมัน `N` และ `P` ทำแบบเดียวกันสำหรับทุกอย่าง และ `Ctrl + M` แสดงทั้งโฟลเดอร์เป็นตาราง มันแสดงภาพ HEIC, AVIF และ JPEG XL ได้ด้วย และเล่นต่อจากจุดที่คุณค้างไว้ในอะไรก็ตามที่ยาว ๆ

กด `F` เพื่อดูแบบเต็มจอ `E` เพื่อแก้ไขรูปภาพใน Omasnap หรือตัดวิดีโอใน Omacut `Ctrl + P` เพื่อพิมพ์รูปภาพ และ `Delete` เพื่อย้ายไฟล์ไปยังถังขยะ (`Ctrl + Z` เอามันกลับมา) กด `?` ข้างในแอปเพื่อดูทางลัดทุกอย่าง

คุณเปิด Omaview ในชื่อ _Media Viewer_ ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) หรือแค่ดับเบิลคลิกที่รูปภาพ วิดีโอ หรือเพลงในโปรแกรมจัดการไฟล์ก็ได้

## Omacut

[Omacut](https://github.com/omacom-io/omacut) คือโปรแกรมตัดวิดีโอที่เรียบง่ายสุด ๆ ของ Omarchy เอง เมื่อสิ่งที่คุณต้องการมีแค่การตัดหัวและท้ายของคลิปออก มันดีกว่าการเปิดโปรแกรมตัดต่อวิดีโอเต็มรูปแบบขึ้นมาเยอะ

คุณเปิด Omacut ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Monologue

[Monologue](https://github.com/omacom/monologue) คือโปรแกรมบันทึกภาพจากเว็บแคมที่เรียบง่ายสุด ๆ ของ Omarchy เอง เลือกกล้องและไมโครโฟนของคุณครั้งเดียว จากนั้นกด `Space` เพื่อบันทึก และกดอีกครั้งเพื่อหยุดชั่วคราวและบันทึกเทคเดิมต่อ มันบันทึกที่ความละเอียดสูงสุดของกล้องของคุณเสมอ พร้อมมาตรวัดระดับเสียงไมโครโฟนแบบสดเพื่อให้คุณตรวจสอบระดับเสียงก่อนเริ่มได้

หยุดเทคแล้วมันจะเปิดขึ้นมาทันทีในโปรแกรมแก้ไขในตัว ดับเบิลคลิกที่คลิปเพื่อแยกมันออก ลากที่จับเพื่อตัดแต่ละชิ้น และลบส่วนที่คุณไม่ต้องการออก จากนั้นบันทึกเป็น MP4 การบันทึกต้นฉบับของคุณจะถูกเก็บไว้จนกว่าคุณจะทิ้งมัน ดังนั้นคุณจึงกลับมาตัดมันแบบอื่นได้เสมอ

คุณเปิด Monologue ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)
