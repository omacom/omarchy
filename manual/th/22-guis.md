# แอป GUI

## Files

Files (Folio) คือโปรแกรมจัดการไฟล์แบบกราฟิก `Super + Shift + F` เปิดโปรแกรมนี้ และ `Super + Shift + Alt + F` เปิดโปรแกรมนี้ในไดเรกทอรีที่เทอร์มินัลของคุณอยู่ในตอนนี้ ซึ่งช่วยประหยัดการคลิกได้มาก `Ctrl + L` ให้คุณพิมพ์เส้นทาง และกด `Space` บนไฟล์ใดก็ได้เพื่อดูตัวอย่างไฟล์นั้นแบบเต็มขนาดโดยไม่ต้องเปิดมัน

เสียบ USB stick หรือ SD card ปุ๊บ มันก็จะถูกเมานต์โดยอัตโนมัติ เลยโผล่ขึ้นมาในแถบด้านข้างทันที สำหรับงานที่ซับซ้อนกว่านั้น — การฟอร์แมตไดรฟ์ การตรวจสุขภาพ SMART การสร้างพาร์ติชัน — ให้เปิด _Disks_ จากตัวเปิดแอป (`Super + Space`)

ไดรฟ์ที่เข้ารหัสไว้จะขอรหัสผ่านเมื่อเสียบเข้าไป หากต้องการให้ไดรฟ์ตัวหนึ่งปลดล็อกด้วยตัวเอง ให้เพิ่ม keyfile เข้าไปในไดรฟ์ด้วย `sudo cryptsetup luksAddKey /dev/sdX1 <keyfile>` และวาง keyfile นั้นไว้ที่ `~/.config/omarchy/drive-keys/<UUID>` โดยตั้งชื่อตาม UUID ที่ `lsblk -dno UUID /dev/sdX1` พิมพ์ออกมาสำหรับพาร์ติชันที่เข้ารหัสนั้น และให้อ่านได้เฉพาะคุณเท่านั้น (`chmod 600`) หาก keyfile นั้นหายไปหรือถูกปฏิเสธ ระบบจะขอรหัสผ่านจากคุณตามปกติ

การดับเบิลคลิกเป็นไปตามค่าเริ่มต้นที่สมเหตุสมผล: รูปภาพ วิดีโอ และเพลงจะเปิดใน Omaview, PDF จะเปิดใน Document Viewer, Markdown จะเปิดใน Omawrite และข้อความธรรมดาจะเปิดในโปรแกรมแก้ไขของคุณ คือ Plain เว้นแต่คุณจะเลือกโปรแกรมอื่นไว้ใน _Setup > Defaults > Editor_

## Disktree

เมื่อไดรฟ์เต็มและคุณไม่รู้เลยว่าอะไรกำลังกินพื้นที่อยู่ ให้เปิด [Disktree](https://github.com/tobi/disktree) จากตัวเปิดแอป (`Super + Space`) มันแสดงแผนภาพ treemap แบบกราฟิกของโฮมไดเรกทอรีของคุณ บล็อกที่ใหญ่กว่าจะใช้พื้นที่มากกว่า เดินเข้าไปในไดเรกทอรีต่าง ๆ ด้วยแป้นพิมพ์หรือเมาส์ ทำเครื่องหมายสิ่งที่ควรลบ และตรวจสอบรายการที่คุณเลือกก่อนจะลบอะไรออกไป รัน `disktree --disk` เพื่อสแกนทั้งดิสก์

## Obsidian

[Obsidian](https://obsidian.md/) เป็นแอปจดบันทึกที่ใช้งานฟรีและต่อขยายได้อย่างมาก ซึ่งใช้ไฟล์ Markdown ธรรมดาในการจัดเก็บ

Obsidian ใช้งานฟรีสำหรับทุกวัตถุประสงค์ รวมถึงการใช้งานส่วนตัว เชิงพาณิชย์ และไม่แสวงหาผลกำไร

Obsidian ยังมี [ส่วนเสริมเชิงพาณิชย์สำหรับการซิงค์](https://obsidian.md/sync) กับแอปมือถือบน iOS และ Android อีกด้วย (https://obsidian.md/pricing)

คุณเปิด Obsidian ด้วย `Super + Shift + O` หากต้องการใช้การซิงค์ธีม คุณต้องเลือกธีม `Omarchy` ในส่วนการตั้งค่า

## Omawrite

[Omawrite](https://github.com/omacom-io/omawrite) เป็นแอปเขียน Markdown ที่เรียบง่ายสุด ๆ ของ Omarchy เอง ไม่มี vault ไม่มีปลั๊กอิน มีแค่คุณกับถ้อยคำ

คุณเปิด Omawrite ด้วย `Super + Shift + W`

คุณเปิด Pinta ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Aether

[Aether](https://github.com/bjarneo/aether) เป็นแอปสร้างธีมที่สามารถดึงสีจากภาพพื้นหลังและเปลี่ยนให้เป็นธีมที่ครบถ้วนและกลมกลืนกัน เป็นวิธีที่ง่ายที่สุดในการ [สร้างธีมของคุณเอง](43-making-your-own-theme.md)

คุณเปิด Aether ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## LocalSend

[LocalSend](https://localsend.org/) ให้คุณส่งไฟล์ไปยังอุปกรณ์อื่นบนเครือข่ายเดียวกันที่รันแอปนี้อยู่ เหมือน AirDrop ของ Apple เพียงแต่มันเป็นแบบข้ามแพลตฟอร์ม คุณจึงส่งไฟล์ไปและกลับระหว่าง Windows, macOS, Android, iOS และแน่นอน Linux ได้

คุณเปิดเมนู Share ได้ด้วย `Super + Ctrl + S` หรือใน _Trigger > Share_ ในเมนู Omarchy มันให้คุณสี่ตัวเลือก:

- **Clipboard** ส่งสิ่งที่คุณคัดลอกไว้เป็นไฟล์ข้อความ เหมาะมากสำหรับการส่งลิงก์หรือโค้ดสั้น ๆ ไปยังโทรศัพท์ของคุณโดยไม่ต้องส่งอีเมลหาตัวเอง
- **File** เปิดตัวเลือกไฟล์ที่คุณสามารถเลือกได้หลายไฟล์พร้อมกัน
- **Folder** ส่งทั้งไดเรกทอรี
- **Receive** เปิด LocalSend ตัวจริงเพื่อให้อุปกรณ์อื่นส่งบางอย่างมาหาคุณ

แบบเดียวกันนี้ทำงานจากเทอร์มินัลได้ด้วย `omarchy share clipboard`, `omarchy share file [path]` และ `omarchy share folder [path]` ถ้าไม่ใส่เส้นทาง คุณจะได้ตัวเลือกไฟล์

คุณยังส่งตรงจากโปรแกรมจัดการไฟล์ได้ด้วย: คลิกขวาที่รายการที่เลือกใน Files แล้วแชร์ด้วย LocalSend

ไฟร์วอลล์ของ Omarchy ปิดอยู่เป็นค่าเริ่มต้น ยกเว้นพอร์ตของ LocalSend ดังนั้นฟีเจอร์นี้จึงใช้งานได้ทันทีตั้งแต่ติดตั้งใหม่ ดู [ความปลอดภัย](48-security.md)

## LibreOffice

[LibreOffice](https://www.libreoffice.org/) เป็นชุดโปรแกรมสำนักงานครบชุดที่มีโปรแกรมประมวลผลคำ สเปรดชีต งานนำเสนอ แอปวาดภาพ และอื่น ๆ มันเข้ากันได้กับไฟล์จาก Microsoft Office ดังนั้นนี่จึงเป็นวิธีที่ดีมากในการเปิดเอกสาร Word เหล่านั้น

คุณเปิด LibreOffice ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Hype

[Hype](https://github.com/omacom/hype) เป็นแอปงานนำเสนอที่เรียบง่ายสุด ๆ ของ Omarchy เอง สไลด์ของคุณคือไฟล์ Markdown ไฟล์เดียวที่มีรูปภาพและวิดีโออยู่ข้าง ๆ: เขียนแต่ละสไลด์ใต้ตัวอย่างแบบสด ลากสไลด์เพื่อจัดลำดับ จากนั้นนำเสนอแบบเต็มจอหรือส่งออกเป็น PDF และ PowerPoint มันยังรับธีม Omarchy ของคุณมาด้วย

คุณเปิด Hype ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) กด `?` ข้างในเพื่อดูทางลัดทั้งหมด

## Signed

[Signed](https://github.com/omacom/signed) เป็นวิธีเซ็น PDF และกรอกแบบฟอร์มใน PDF ที่เรียบง่ายสุด ๆ ของ Omarchy เอง วางลายเซ็นที่บันทึกไว้ ข้อความ และวันที่ของวันนี้ลงตรงไหนก็ได้บนหน้า จากนั้นบันทึกสำเนาที่เซ็นแล้วไว้ข้างไฟล์ต้นฉบับ ดู [การกรอก PDF](27-filling-out-pdfs.md) สำหรับวิธีทำ

คุณเปิด Signed ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) หรือเปิด PDF ด้วยมันจากโปรแกรมจัดการไฟล์

## Game Vibes

Game Vibes ในตัวเปิดแอปพลิเคชัน (`Super + Space`) เป็นที่ที่เกมเล็ก ๆ ของ Omarchy อยู่: Checkmate เกมหมากรุก 3D ที่เล่นกับเพื่อนหรือคู่ต่อสู้ในตัว; Cards เกมไพ่โซลิแทร์ Klondike; Death Wish เกมแพลตฟอร์มที่ต้องแม่นระดับพิกเซล มีสิบห้องที่เต็มไปด้วยหนามและเลื่อย; และ Neon Swarm เกมยิงสไตล์อาร์เคด แต่ละเกมเป็นหน้าเว็บหน้าเดียวที่ปรับตามธีมของคุณ เลือกเกมหนึ่งด้วยปุ่มลูกศรและ `Enter` และกลับมาที่รายการด้วย `Esc` จากหน้าชื่อเกม หรือ `Q` ขณะที่เกมหยุดชั่วคราว มันเปิดแบบเต็มจอ: `Super + F` ทำให้มันเป็นหน้าต่าง และ `Super + W` ปิดมัน

เกมที่คุณสร้างด้วย agent ก็จะมาปรากฏที่นี่เช่นกัน: เลือก _Make something cool → Game_ ในแผง agents แล้วอธิบายเกมหนึ่งเกม หรือระบุชื่อเกมที่มีอยู่แล้วใน Game Vibes เพื่อทำงานกับมันต่อ agent จะคัดลอกมันไปยัง `~/Games/vibes` ซึ่งมันจะเป็นของคุณให้แก้ไขได้ และจะเปิดมันเมื่อเสร็จ คุณสามารถสร้างสำเนานั้นเองได้ด้วย `omarchy games vibes copy <game>` เกมที่คนอื่นแชร์จะติดตั้งเหมือนธีม: เลือก _Install > Gaming > Game Vibes_ แล้ววางที่อยู่ git ของมัน หรือรัน `omarchy games vibes install <git-repo-url>` _Remove > Gaming_ จะเอามันออกอีกครั้ง และ _Update > Game Vibes Games_ จะดึงเวอร์ชันใหม่ เกมโหลด three.js จากเว็บ ดังนั้นพวกมันต้องการการเชื่อมต่อเพื่อเริ่มเล่น

## Omacalc

[Omacalc](https://github.com/omacom-io/omacalc) เป็นเครื่องคิดเลขที่เรียบง่ายสุด ๆ ของ Omarchy เอง ซึ่งเปิดในหน้าต่างลอย

คุณเปิด Omacalc ด้วย `Super + Shift + Q` (หรือปุ่มเครื่องคิดเลข ถ้าแป้นพิมพ์ของคุณมี)

## Signal

[Signal](https://signal.org/) เป็นผู้บุกเบิกการส่งข้อความแบบเข้ารหัส E2E และเป็นตัวเลือกการสื่อสารที่ดีมากสำหรับใครก็ตามที่อยากจะไม่ผ่านบริษัทเทคโนโลยียักษ์ใหญ่รายใดรายหนึ่ง

คุณเปิด Signal ด้วย `Super + Shift + G` มันไม่ได้เป็นส่วนหนึ่งของการติดตั้งพื้นฐาน ดังนั้นครั้งแรกที่คุณกดปุ่มนั้น Omarchy จะเสนอติดตั้งให้คุณ (มันยังอยู่ใน _Install > Service_ ในเมนู Omarchy ด้วย)

## Omaview

[Omaview](https://github.com/omacom/omaview) เป็นโปรแกรมดูรูปภาพและเครื่องเล่นสื่อที่เรียบง่ายสุด ๆ ของ Omarchy เอง: หน้าต่างเดียวสำหรับรูปภาพ วิดีโอ และเพลงของคุณ เปิดรูปภาพหนึ่งรูปแล้วปุ่มลูกศรจะเลื่อนผ่านรูปที่เหลือในโฟลเดอร์ของมัน `N` และ `P` ทำแบบเดียวกันสำหรับทุกอย่าง และ `Ctrl + M` แสดงทั้งโฟลเดอร์เป็นตาราง มันแสดงภาพถ่าย HEIC, AVIF และ JPEG XL ได้ด้วย และเล่นต่อจากจุดที่คุณค้างไว้ในอะไรก็ตามที่ยาว

กด `F` เพื่อเต็มจอ `E` เพื่อแก้ไขรูปภาพใน Omasnap หรือตัดวิดีโอใน Omacut `Ctrl + P` เพื่อพิมพ์รูปภาพ และ `Delete` เพื่อย้ายไฟล์ไปยัง Trash (`Ctrl + Z` นำมันกลับมา) กด `?` ข้างในเพื่อดูทางลัดทั้งหมด

คุณเปิด Omaview เป็น _Media Viewer_ ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) หรือแค่ดับเบิลคลิกรูปภาพ วิดีโอ หรือเพลงในโปรแกรมจัดการไฟล์

## Monologue

[Monologue](https://github.com/omacom/monologue) เป็นโปรแกรมบันทึกเว็บแคมที่เรียบง่ายสุด ๆ ของ Omarchy เอง เลือกกล้องและไมโครโฟนของคุณครั้งเดียว จากนั้นกด `Space` เพื่อบันทึก และกดอีกครั้งเพื่อหยุดชั่วคราวและบันทึกเทคเดียวกันต่อ มันบันทึกที่ความละเอียดสูงสุดของกล้องของคุณเสมอ พร้อมมาตรวัดไมโครโฟนแบบสดเพื่อให้คุณตรวจสอบระดับเสียงก่อนเริ่มได้

หยุดเทคแล้วมันจะเปิดทันทีในโปรแกรมแก้ไขในตัว ดับเบิลคลิกคลิปเพื่อแยกมัน ลากที่จับเพื่อตัดแต่ละชิ้น และลบส่วนที่คุณไม่ต้องการออก จากนั้นบันทึกเป็น MP4 การบันทึกต้นฉบับของคุณจะถูกเก็บไว้จนกว่าคุณจะทิ้งมัน ดังนั้นคุณจึงกลับมาตัดมันแบบอื่นได้เสมอ

คุณเปิด Monologue ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)
