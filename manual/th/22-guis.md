# GUIs

## Files

Files (Nautilus) คือโปรแกรมจัดการไฟล์แบบกราฟิก `Super + Shift + F` เปิดมันขึ้นมา และ `Super + Shift + Alt + F` เปิดมันในไดเรกทอรีที่เทอร์มินัลของคุณอยู่ ซึ่งช่วยประหยัดการคลิกได้มาก `Ctrl + L` ให้คุณพิมพ์พาธได้ และการกด `Space` บนไฟล์ใดก็ได้จะแสดงตัวอย่างอย่างรวดเร็วโดยไม่ต้องเปิดอะไรเลย

เสียบ USB stick หรือ SD card เข้าไปแล้วมันจะถูก mount โดยอัตโนมัติ จึงปรากฏในแถบข้างทันที สำหรับอะไรที่ซับซ้อนกว่านั้น — ฟอร์แมตไดรฟ์ ตรวจสอบสุขภาพ SMART สร้างพาร์ติชัน — ให้เปิด _Disks_ จากตัวเปิดแอป (`Super + Space`)

การดับเบิลคลิกเป็นไปตามค่าเริ่มต้นที่สมเหตุสมผล: รูปภาพ วิดีโอ และเพลงเปิดใน Omaview, PDF เปิดใน Document Viewer, Markdown เปิดใน Omawrite และข้อความธรรมดาเปิดในโปรแกรมแก้ไขที่เลือกไว้ภายใต้ _Setup > Default > Editor_

## Disktree

เมื่อไดรฟ์เต็มและคุณไม่รู้เลยว่าอะไรกำลังกินพื้นที่อยู่ ให้เปิด [Disktree](https://github.com/tobi/disktree) จากตัวเปิดแอป (`Super + Space`) มันแสดง treemap แบบกราฟิกของไดเรกทอรีบ้านของคุณ บล็อกที่ใหญ่กว่าใช้พื้นที่มากกว่า เดินเข้าไปในไดเรกทอรีด้วยคีย์บอร์ดหรือเมาส์ ทำเครื่องหมายสิ่งที่ควรลบออก และตรวจสอบรายการที่เลือกไว้ก่อนลบอะไรก็ตาม รัน `disktree --disk` เพื่อสแกนทั้งดิสก์

## Obsidian

[Obsidian](https://obsidian.md/) คือแอปพลิเคชันจดบันทึกฟรีและขยายความสามารถได้สูงมาก ซึ่งใช้ไฟล์ Markdown ธรรมดาสำหรับการจัดเก็บ

Obsidian ฟรีสำหรับทุกวัตถุประสงค์ รวมถึงการใช้งานส่วนตัว เชิงพาณิชย์ และไม่แสวงหาผลกำไร

Obsidian ยังมี [ส่วนเสริมเชิงพาณิชย์สำหรับการซิงค์](https://obsidian.md/sync) กับแอปมือถือบน iOS และ Android ด้วย (https://obsidian.md/pricing)

คุณเริ่ม Obsidian ด้วย `Super + Shift + O` ในการใช้การซิงค์ธีม คุณต้องเลือกธีม `Omarchy` ภายใต้การตั้งค่า

## Omawrite

[Omawrite](https://github.com/omacom-io/omawrite) คือแอปเขียน Markdown ที่เรียบง่ายสุดๆ ของ Omarchy เอง ไม่มี vault ไม่มีปลั๊กอิน มีแค่คุณกับคำต่างๆ

คุณเริ่ม Omawrite ด้วย `Super + Shift + W`

## Pinta

[Pinta](https://www.pinta-project.com/) คือเครื่องมือแก้ไขรูปภาพพื้นฐานที่ยอดเยี่ยมสำหรับการครอบตัด ปรับขนาด และการจัดการพื้นฐานอื่นๆ แค่อย่าคาดหวังว่ามันจะเป็นทางเลือกแทน Photoshop แต่มันก็ยังมี Magic Wand และเลเยอร์อยู่นะ!

คุณเริ่ม Pinta ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Aether

[Aether](https://github.com/bjarneo/aether) คือแอปพลิเคชันทำธีมที่สามารถดึงสีจากภาพพื้นหลังและเปลี่ยนให้เป็นธีมที่สมบูรณ์และสอดคล้องกัน มันเป็นวิธีที่ง่ายที่สุดในการ [สร้างธีมของคุณเอง](43-making-your-own-theme.md)

คุณเริ่ม Aether ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## LocalSend

[LocalSend](https://localsend.org/) ให้คุณส่งไฟล์ไปยังอุปกรณ์อื่นๆ บนเครือข่ายเดียวกันที่กำลังรันแอปนี้ เหมือน AirDrop ของ Apple แต่มันข้ามแพลตฟอร์ม ดังนั้นคุณจึงส่งไฟล์ไปและกลับจาก Windows, macOS, Android, iOS และแน่นอน Linux ได้

คุณเปิดเมนู Share ได้ด้วย `Super + Ctrl + S` หรือภายใต้ _Trigger > Share_ ในเมนู Omarchy มันให้คุณสี่ตัวเลือก:

- **Clipboard** ส่งสิ่งที่คุณคัดลอกไว้เป็นไฟล์ข้อความ เหมาะมากสำหรับการเอาลิงก์หรือข้อความสั้นๆ ไปยังโทรศัพท์ของคุณโดยไม่ต้องส่งอีเมลหาตัวเอง
- **File** เปิดตัวเลือกไฟล์ที่ซึ่งคุณสามารถเลือกหลายไฟล์พร้อมกันได้
- **Folder** ส่งทั้งไดเรกทอรี
- **Receive** เปิด LocalSend ตัวจริงเพื่อให้อุปกรณ์อื่นส่งบางอย่างมาหาคุณได้

สิ่งเดียวกันนี้ทำงานจากเทอร์มินัลได้ด้วย `omarchy share clipboard`, `omarchy share file [path]` และ `omarchy share folder [path]` ไม่ใส่พาธก็จะได้ตัวเลือกไฟล์

คุณยังส่งโดยตรงจากโปรแกรมจัดการไฟล์ได้ด้วย: คลิกขวาที่รายการใดก็ตามที่เลือกไว้ใน Nautilus แล้วเลือก _Send via LocalSend_

ไฟร์วอลล์ของ Omarchy ปิดตามค่าเริ่มต้น ยกเว้นพอร์ตของ LocalSend ดังนั้นสิ่งนี้จึงใช้งานได้ทันทีตั้งแต่ติดตั้งใหม่ ดู [ความปลอดภัย](48-security.md)

## LibreOffice

[LibreOffice](https://www.libreoffice.org/) คือชุดโปรแกรมสำนักงานที่สมบูรณ์ พร้อมโปรแกรมประมวลผลคำ สเปรดชีต งานนำเสนอ แอปพลิเคชันวาดภาพ และอื่นๆ อีกมากมาย มันเข้ากันได้กับไฟล์จาก Microsoft Office ดังนั้นนี่จึงเป็นวิธีที่ยอดเยี่ยมในการเปิดเอกสาร Word เหล่านั้นได้

คุณเริ่ม LibreOffice ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Hype

[Hype](https://github.com/omacom/hype) คือแอปนำเสนอที่เรียบง่ายสุดๆ ของ Omarchy เอง ชุดสไลด์ของคุณคือไฟล์ Markdown เดียวที่มีรูปภาพและวิดีโออยู่ข้างๆ: เขียนแต่ละสไลด์ใต้ตัวอย่างสด ลากสไลด์เพื่อจัดลำดับ จากนั้นนำเสนอแบบเต็มจอหรือส่งออกเป็น PDF และ PowerPoint มันยังรับธีม Omarchy ของคุณมาใช้ด้วย

คุณเริ่ม Hype ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) กด `?` ข้างในมันเพื่อดูทุกทางลัด

## Signed

[Signed](https://github.com/omacom/signed) คือวิธีเซ็น PDF และกรอก PDF ที่เรียบง่ายสุดๆ ของ Omarchy เอง วางลายเซ็นที่บันทึกไว้ ข้อความ และวันที่ของวันนี้ไว้ที่ใดก็ได้บนหน้า จากนั้นบันทึกสำเนาที่เซ็นแล้วไว้ข้างต้นฉบับ ดู [การกรอก PDF](27-filling-out-pdfs.md) สำหรับวิธีทำ

คุณเริ่ม Signed ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) หรือเปิด PDF ด้วยมันจากโปรแกรมจัดการไฟล์

## Omacalc

[Omacalc](https://github.com/omacom-io/omacalc) คือเครื่องคิดเลขที่เรียบง่ายสุดๆ ของ Omarchy เอง ซึ่งเปิดในหน้าต่างลอย

คุณเริ่ม Omacalc ด้วย `Super + Shift + Q` (หรือปุ่มเครื่องคิดเลข หากคีย์บอร์ดของคุณมี)

## Signal

[Signal](https://signal.org/) คือผู้บุกเบิกการส่งข้อความเข้ารหัสแบบ E2E และเป็นตัวเลือกการสื่อสารที่ยอดเยี่ยมสำหรับใครก็ตามที่ไม่อยากผ่านกลุ่มบริษัทเทคโนโลยีขนาดใหญ่รายใดรายหนึ่ง

คุณเริ่ม Signal ด้วย `Super + Shift + G` มันไม่ได้เป็นส่วนหนึ่งของการติดตั้งพื้นฐาน ดังนั้นครั้งแรกที่คุณกดปุ่มนั้น Omarchy จะเสนอติดตั้งให้คุณ (มันยังอยู่ภายใต้ _Install > Service_ ในเมนู Omarchy ด้วย)

## Omaview

[Omaview](https://github.com/omacom/omaview) คือโปรแกรมดูรูปภาพและเครื่องเล่นสื่อที่เรียบง่ายสุดๆ ของ Omarchy เอง: หน้าต่างเดียวสำหรับรูปภาพ วิดีโอ และเพลงของคุณ เปิดรูปภาพหนึ่งรูปแล้วปุ่มลูกศรจะไล่ดูไฟล์ที่เหลือในโฟลเดอร์ของมัน `N` และ `P` ทำแบบเดียวกันสำหรับทุกอย่าง และ `Ctrl + M` แสดงทั้งโฟลเดอร์เป็นตาราง มันแสดงรูปภาพ HEIC, AVIF และ JPEG XL ได้ด้วย และเล่นต่อจากจุดที่คุณหยุดไว้ในอะไรก็ตามที่ยาว

กด `F` สำหรับเต็มจอ `E` เพื่อแก้ไขรูปภาพใน Omasnap หรือตัดวิดีโอใน Omacut `Ctrl + P` เพื่อพิมพ์รูปภาพ และ `Delete` เพื่อย้ายไฟล์ไปยัง Trash (`Ctrl + Z` นำมันกลับมา) กด `?` ข้างในมันเพื่อดูทุกทางลัด

คุณเริ่ม Omaview ในชื่อ _Media Viewer_ ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) หรือแค่ดับเบิลคลิกรูปภาพ วิดีโอ หรือเพลงในโปรแกรมจัดการไฟล์

## Omacut

[Omacut](https://github.com/omacom-io/omacut) คือโปรแกรมตัดวิดีโอที่เรียบง่ายสุดๆ ของ Omarchy เอง เมื่อสิ่งที่คุณต้องการมีแค่ตัดส่วนต้นและส่วนท้ายออกจากคลิป มันดีกว่าการเปิดโปรแกรมตัดต่อวิดีโอเต็มรูปแบบขึ้นมา

คุณเริ่ม Omacut ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Monologue

[Monologue](https://github.com/omacom/monologue) คือโปรแกรมบันทึกเว็บแคมที่เรียบง่ายสุดๆ ของ Omarchy เอง เลือกกล้องและไมโครโฟนของคุณครั้งเดียว จากนั้นกด `Space` เพื่อบันทึก และกดอีกครั้งเพื่อหยุดชั่วคราวและบันทึกเทคเดียวกันต่อ มันบันทึกที่ความละเอียดสูงสุดของกล้องของคุณเสมอ พร้อมมิเตอร์ไมโครโฟนแบบสดเพื่อให้คุณตรวจสอบระดับเสียงได้ก่อนเริ่ม

หยุดเทคแล้วมันจะเปิดขึ้นทันทีในโปรแกรมแก้ไขในตัว ดับเบิลคลิกคลิปเพื่อแยกมัน ลากที่จับเพื่อตัดแต่ละชิ้น และลบส่วนที่คุณไม่ต้องการออก จากนั้นบันทึกเป็น MP4 ไฟล์บันทึกต้นฉบับของคุณจะถูกเก็บไว้จนกว่าคุณจะทิ้งมัน ดังนั้นคุณจึงกลับมาตัดมันในแบบอื่นได้เสมอ

คุณเริ่ม Monologue ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)
