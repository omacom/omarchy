# แอป GUI

## Files

Files (Folio) เป็นตัวจัดการไฟล์แบบกราฟิก กด `Super + Shift + F` เพื่อเปิดมัน และ `Super + Shift + Alt + F` จะเปิดมันในไดเรกทอรีที่เทอร์มินัลของคุณอยู่ตอนนี้ ซึ่งช่วยประหยัดการคลิกได้มาก `Ctrl + L` ให้คุณพิมพ์พาธได้ และการกด `Space` บนไฟล์ใด ๆ จะแสดงตัวอย่างแบบเต็มขนาดโดยไม่ต้องเปิดไฟล์

เสียบแท่ง USB หรือการ์ด SD แล้วมันจะถูกเมานต์โดยอัตโนมัติ จึงปรากฏขึ้นในแถบด้านข้างเลย สำหรับอะไรที่ซับซ้อนกว่านั้น — ฟอร์แมตไดรฟ์ ตรวจสอบสุขภาพ SMART สร้างพาร์ติชัน — ให้เปิด _Disks_ จากตัวเปิดแอป (`Super + Space`)

การดับเบิลคลิกเป็นไปตามค่าเริ่มต้นที่สมเหตุสมผล: รูปภาพ วิดีโอ และเพลงจะเปิดใน Omaview, PDF จะเปิดใน Document Viewer, Markdown จะเปิดใน Omawrite และข้อความธรรมดาจะเปิดในตัวแก้ไขที่เลือกไว้ใต้ _Setup > Default > Editor_

## Disktree

เมื่อไดรฟ์เต็มและคุณไม่รู้เลยว่าอะไรกำลังกินพื้นที่อยู่ ให้เปิด [Disktree](https://github.com/tobi/disktree) จากตัวเปิดแอป (`Super + Space`) มันแสดง treemap แบบกราฟิกของไดเรกทอรี home ของคุณ บล็อกที่ใหญ่กว่าจะใช้พื้นที่มากกว่า เดินเข้าไปในไดเรกทอรีต่าง ๆ ด้วยคีย์บอร์ดหรือเมาส์ ทำเครื่องหมายสิ่งที่ควรลบออก และตรวจสอบสิ่งที่คุณเลือกไว้ก่อนลบอะไรก็ตาม เรียกใช้ `disktree --disk` เพื่อสแกนทั้งดิสก์

## Obsidian

[Obsidian](https://obsidian.md/) เป็นแอปจดบันทึกที่ฟรีและขยายความสามารถได้มาก ซึ่งใช้ไฟล์ Markdown ธรรมดาในการจัดเก็บข้อมูล

Obsidian ฟรีสำหรับทุกวัตถุประสงค์ รวมถึงการใช้งานส่วนตัว เชิงพาณิชย์ และไม่แสวงหาผลกำไร

Obsidian ยังมี [ส่วนเสริมเชิงพาณิชย์สำหรับการซิงค์](https://obsidian.md/sync) กับแอปมือถือบน iOS และ Android ให้ใช้ด้วย (https://obsidian.md/pricing)

คุณเปิด Obsidian ด้วย `Super + Shift + O` หากต้องการใช้การซิงค์ธีม คุณต้องเลือกธีม `Omarchy` ใต้การตั้งค่า

## Omawrite

[Omawrite](https://github.com/omacom-io/omawrite) เป็นแอปเขียน Markdown ที่เรียบง่ายสุด ๆ ของ Omarchy เอง ไม่มี vault ไม่มีปลั๊กอิน มีแค่คุณกับถ้อยคำ

คุณเปิด Omawrite ด้วย `Super + Shift + W`

## Pinta

[Pinta](https://www.pinta-project.com/) เป็นเครื่องมือแก้ไขรูปภาพพื้นฐานที่เหมาะมากสำหรับการครอบตัด ปรับขนาด และการปรับแต่งพื้นฐานอื่น ๆ แค่อย่าไปคาดหวังว่ามันจะเป็นทางเลือกแทน Photoshop แต่มันก็ยังมี Magic Wand และ layers อยู่!

คุณเปิด Pinta ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Aether

[Aether](https://github.com/bjarneo/aether) เป็นแอปธีมที่สามารถดึงสีจากภาพพื้นหลังและเปลี่ยนให้กลายเป็นธีมที่สมบูรณ์และกลมกลืนกันได้ เป็นวิธีที่ง่ายที่สุดในการ [สร้างธีมของคุณเอง](43-making-your-own-theme.md)

คุณเปิด Aether ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## LocalSend

[LocalSend](https://localsend.org/) ให้คุณส่งไฟล์ไปยังอุปกรณ์อื่นบนเครือข่ายเดียวกันที่รันแอปนี้อยู่ คล้ายกับ AirDrop ของ Apple แต่มันทำงานข้ามแพลตฟอร์มได้ ดังนั้นคุณจึงส่งไฟล์ไปและกลับจาก Windows, macOS, Android, iOS และแน่นอน Linux ได้

คุณสามารถเปิดเมนู Share ได้ด้วย `Super + Ctrl + S` หรือใต้ _Trigger > Share_ ในเมนู Omarchy มันมีสี่ตัวเลือกให้คุณ:

- **Clipboard** ส่งสิ่งที่คุณคัดลอกไว้เป็นไฟล์ข้อความ เหมาะมากสำหรับส่งลิงก์หรือข้อความสั้น ๆ ไปยังโทรศัพท์ของคุณโดยไม่ต้องอีเมลหาตัวเอง
- **File** เปิดตัวเลือกไฟล์ที่คุณสามารถเลือกหลายไฟล์พร้อมกันได้
- **Folder** ส่งทั้งไดเรกทอรี
- **Receive** เปิด LocalSend ตัวจริงเพื่อให้อุปกรณ์อื่นส่งบางอย่างมาให้คุณได้

สิ่งเดียวกันนี้ทำงานจากเทอร์มินัลได้ด้วย `omarchy share clipboard`, `omarchy share file [path]` และ `omarchy share folder [path]` หากไม่ใส่พาธ คุณจะได้ตัวเลือกไฟล์

คุณยังส่งโดยตรงจากตัวจัดการไฟล์ได้ด้วย: คลิกขวาที่สิ่งที่เลือกไว้ใน Files แล้วแชร์มันด้วย LocalSend

ไฟร์วอลล์ของ Omarchy ปิดอยู่เป็นค่าเริ่มต้น ยกเว้นพอร์ตของ LocalSend ดังนั้นสิ่งนี้จึงใช้งานได้ทันทีในการติดตั้งใหม่ ดู [ความปลอดภัย](48-security.md)

## LibreOffice

[LibreOffice](https://www.libreoffice.org/) เป็นชุดโปรแกรมสำนักงานที่ครบถ้วน มีโปรแกรมประมวลผลคำ สเปรดชีต งานนำเสนอ โปรแกรมวาดภาพ และอื่น ๆ อีกมากมาย มันเข้ากันได้กับไฟล์จาก Microsoft Office ดังนั้นนี่จึงเป็นวิธีที่ดีมากในการเปิดเอกสาร Word เหล่านั้น

คุณเปิด LibreOffice ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Hype

[Hype](https://github.com/omacom/hype) เป็นแอปนำเสนอที่เรียบง่ายสุด ๆ ของ Omarchy เอง สไลด์ของคุณคือไฟล์ Markdown เดียวที่มีรูปภาพและวิดีโออยู่ข้าง ๆ เขียนแต่ละสไลด์ใต้ตัวอย่างแบบสด ลากสไลด์เพื่อจัดลำดับ จากนั้นนำเสนอแบบเต็มจอหรือส่งออกเป็น PDF และ PowerPoint มันยังรับธีม Omarchy ของคุณมาใช้ด้วย

คุณเปิด Hype ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) กด `?` ข้างในเพื่อดูทางลัดทั้งหมด

## Signed

[Signed](https://github.com/omacom/signed) เป็นวิธีเซ็น PDF และกรอก PDF ที่เรียบง่ายสุด ๆ ของ Omarchy เอง วางลายเซ็นที่บันทึกไว้ ข้อความ และวันที่ของวันนี้ไว้ที่ใดก็ได้บนหน้า จากนั้นบันทึกสำเนาที่เซ็นแล้วไว้ข้างต้นฉบับ ดูวิธีทำได้ที่ [การกรอก PDF](27-filling-out-pdfs.md)

คุณเปิด Signed ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) หรือเปิด PDF ด้วยมันจากตัวจัดการไฟล์

## Game Vibes

Game Vibes ในตัวเปิดแอปพลิเคชัน (`Super + Space`) คือที่อยู่ของเกมเล็ก ๆ ของ Omarchy: Checkmate เกมหมากรุก 3D สำหรับเล่นกับเพื่อนหรือคู่ต่อสู้ในตัว; Cards เกม Klondike solitaire; และ Neon Swarm เกมยิงแนวอาร์เคด แต่ละเกมเป็นเว็บเพจเดียวที่ตามธีมของคุณ เลือกเกมด้วยปุ่มลูกศรและ `Enter` และกลับมาที่รายการด้วย `Esc` จากหน้าชื่อเกม หรือ `Q` ขณะที่เกมหยุดชั่วคราว มันเปิดแบบเต็มจอ: `Super + F` ทำให้มันกลายเป็นหน้าต่าง และ `Super + W` ปิดมัน

เกมที่คุณสร้างด้วย agent ก็จะปรากฏที่นี่เช่นกัน: เลือก _Make something cool → Game_ ในแผง agents แล้วอธิบายเกมที่ต้องการ หรือระบุชื่อเกมที่มีอยู่แล้วใน Game Vibes เพื่อทำงานกับมันต่อ agent จะคัดลอกมันไปยัง `~/Games/vibes` ซึ่งเป็นของคุณที่จะเปลี่ยนแปลงได้ และจะเปิดมันเมื่อเสร็จ คุณสามารถสร้างสำเนานั้นเองด้วย `omarchy games vibes copy <game>` เกมที่คนอื่นแชร์จะติดตั้งเหมือนธีม: เลือก _Install > Gaming > Game Vibes_ แล้ววางที่อยู่ git ของมัน หรือเรียกใช้ `omarchy games vibes install <git-repo-url>` _Remove > Gaming_ จะนำเกมออกอีกครั้ง และ _Update > Game Vibes Games_ จะดึงเวอร์ชันใหม่มา เกมจะโหลด three.js จากเว็บ ดังนั้นจึงต้องมีการเชื่อมต่อเพื่อเริ่มเล่น

## Omacalc

[Omacalc](https://github.com/omacom-io/omacalc) เป็นเครื่องคิดเลขที่เรียบง่ายสุด ๆ ของ Omarchy เอง ซึ่งเปิดในหน้าต่างลอย

คุณเปิด Omacalc ด้วย `Super + Shift + Q` (หรือปุ่มเครื่องคิดเลข หากคีย์บอร์ดของคุณมี)

## Signal

[Signal](https://signal.org/) เป็นผู้บุกเบิกการส่งข้อความแบบเข้ารหัส E2E และเป็นตัวเลือกการสื่อสารที่ดีมากสำหรับใครก็ตามที่ไม่อยากผ่านบริษัทเทคโนโลยียักษ์ใหญ่รายใดรายหนึ่ง

คุณเปิด Signal ด้วย `Super + Shift + G` มันไม่ได้เป็นส่วนหนึ่งของการติดตั้งพื้นฐาน ดังนั้นครั้งแรกที่คุณกดปุ่มนั้น Omarchy จะเสนอให้ติดตั้งให้คุณ (มันยังอยู่ใต้ _Install > Service_ ในเมนู Omarchy ด้วย)

## Omaview

[Omaview](https://github.com/omacom/omaview) เป็นโปรแกรมดูรูปภาพและเล่นสื่อที่เรียบง่ายสุด ๆ ของ Omarchy เอง: หน้าต่างเดียวสำหรับรูปภาพ วิดีโอ และเพลงของคุณ เปิดรูปภาพแล้วปุ่มลูกศรจะไล่ผ่านส่วนที่เหลือของโฟลเดอร์นั้น `N` และ `P` ทำแบบเดียวกันสำหรับทุกอย่าง และ `Ctrl + M` แสดงทั้งโฟลเดอร์เป็นตาราง มันแสดงรูปภาพ HEIC, AVIF และ JPEG XL ได้ด้วย และจะเล่นต่อจากจุดที่คุณค้างไว้ในสื่อที่มีความยาวทุกอย่าง

กด `F` เพื่อเต็มจอ `E` เพื่อแก้ไขรูปภาพใน Omasnap หรือตัดวิดีโอใน Omacut `Ctrl + P` เพื่อพิมพ์รูปภาพ และ `Delete` เพื่อย้ายไฟล์ไปยัง Trash (`Ctrl + Z` จะนำมันกลับมา) กด `?` ข้างในเพื่อดูทางลัดทั้งหมด

คุณเปิด Omaview ในชื่อ _Media Viewer_ ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`) หรือแค่ดับเบิลคลิกรูปภาพ วิดีโอ หรือเพลงในตัวจัดการไฟล์

## Omacut

[Omacut](https://github.com/omacom-io/omacut) เป็นโปรแกรมตัดวิดีโอที่เรียบง่ายสุด ๆ ของ Omarchy เอง เมื่อสิ่งที่คุณต้องการมีแค่ตัดส่วนต้นและส่วนท้ายออกจากคลิป มันดีกว่าการเปิดโปรแกรมตัดต่อวิดีโอแบบเต็มรูปแบบขึ้นมา

คุณเปิด Omacut ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Monologue

[Monologue](https://github.com/omacom/monologue) เป็นโปรแกรมบันทึกเว็บแคมที่เรียบง่ายสุด ๆ ของ Omarchy เอง เลือกกล้องและไมโครโฟนของคุณครั้งเดียว จากนั้นกด `Space` เพื่อบันทึก และกดอีกครั้งเพื่อหยุดชั่วคราวและบันทึกเทคเดิมต่อ มันบันทึกที่ความละเอียดสูงสุดของกล้องของคุณเสมอ พร้อมมาตรวัดไมโครโฟนแบบสดเพื่อให้คุณตรวจสอบระดับเสียงได้ก่อนเริ่ม

หยุดเทคแล้วมันจะเปิดขึ้นทันทีในตัวแก้ไขในตัว ดับเบิลคลิกคลิปเพื่อแยกมัน ลากที่จับเพื่อตัดแต่งแต่ละส่วน และลบส่วนที่คุณไม่ต้องการออก จากนั้นบันทึกเป็น MP4 การบันทึกต้นฉบับของคุณจะถูกเก็บไว้จนกว่าคุณจะทิ้งมัน ดังนั้นคุณจึงกลับมาตัดมันในแบบที่แตกต่างได้เสมอ

คุณเปิด Monologue ผ่านตัวเปิดแอปพลิเคชัน (`Super + Space`)
