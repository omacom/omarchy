# สแน็ปช็อตของระบบ

เราสร้างสแน็ปช็อตโดยอัตโนมัติในการอัปเดต Omarchy ทุกครั้ง แต่ถ้าคุณอยากสร้างของคุณเอง คุณสามารถใช้ `omarchy-snapshot create` ได้

วิธีการบูตและกู้คืนสแน็ปช็อตจะขึ้นอยู่กับ boot loader ที่เครื่องของคุณเริ่มต้นด้วย การติดตั้งแบบ UEFI ใหม่จะใช้ systemd-boot ส่วนการติดตั้งแบบเก่าและเครื่อง BIOS จะใช้ Limine โดย `omarchy-boot-backend` จะบอกคุณว่าคุณใช้แบบไหน

## ด้วย systemd-boot

เลือก _System > Snapshots_ ในเมนู Omarchy และเลือกสแน็ปช็อตที่คุณอยากบูตเข้าไป เครื่องจะรีสตาร์ตเข้าไปในสแน็ปช็อตนั้นหนึ่งครั้ง หรือให้กด Space ค้างไว้ขณะที่เครื่องเริ่มทำงานเพื่อดูเมนูบูต ซึ่งสแน็ปช็อตทุกอันจะแสดงอยู่ที่นั่นเรียงจากใหม่สุดไปเก่าสุด พร้อมเวอร์ชัน Omarchy และวันที่

สแน็ปช็อตจะบูตด้วยเลเยอร์ชั่วคราวอยู่ด้านบน คุณจึงใช้งานได้ตามปกติ แต่ทุกอย่างที่คุณเปลี่ยนจะหายไปในการรีบูตครั้งถัดไป ถ้าอยากเก็บไว้ ให้ทำให้มันเป็นระบบของคุณ: คลิกการแจ้งเตือนที่ปรากฏเมื่อคุณเข้าสู่ระบบ เลือก _System > Snapshots > Restore This Snapshot_ หรือรัน `omarchy-snapshot restore` การกู้คืนจะเกิดขึ้นขณะที่เครื่องรีสตาร์ต ระบบในสภาพเดิมก่อนหน้านั้นจะยังคงอยู่ในเมนูบูตในชื่อ _Before restore_ และ `omarchy-snapshot restore backup` จะทำให้มันกลับมา

จากเทอร์มินัล:

- `omarchy-snapshot list` แสดงรายการสแน็ปช็อตที่คุณบูตได้;
- `omarchy-snapshot boot 12` รีสตาร์ตเข้าไปในสแน็ปช็อต 12 หนึ่งครั้ง;
- `omarchy-snapshot restore 12` ทำให้สแน็ปช็อต 12 กลายเป็นระบบในการรีสตาร์ตครั้งถัดไป และ `omarchy-snapshot restore --cancel` เปลี่ยนใจคุณก่อนการรีสตาร์ตนั้น

## ด้วย Limine

ในการบูตและกู้คืนสแน็ปช็อต คุณต้องเลือกมันจาก boot loader ของ Limine เมนูบูตจะถูกซ่อนไว้เป็นค่าเริ่มต้น ดังนั้นให้กดปุ่มใดก็ได้ทันทีที่ Limine เริ่มทำงานเพื่อเปิดมันขึ้นมา

จากหน้าจอนั้น เลือกสแน็ปช็อตที่คุณอยากบูตเข้าไปโดยดูจากวันที่และเวอร์ชัน เวอร์ชันของ Omarchy ณ เวลาที่สร้างสแน็ปช็อตสามารถดูได้ที่มุมซ้ายล่าง

 ![snapshots-bootloader](images/snapshots-bootloader.webp)

เมื่อคุณเข้าไปถึง การแจ้งเตือนจะปรากฏขึ้นเพื่อแจ้งให้คุณทราบว่าคุณอยู่ในสแน็ปช็อตที่บูตได้ และถ้าคุณคลิกมัน กระบวนการกู้คืนจะเริ่มทำงาน หรืออีกวิธีหนึ่ง คุณสามารถใช้ `omarchy-snapshot restore` ได้

## การกู้คืนครอบคลุมอะไรบ้าง

การกู้คืนจะนำ root filesystem ของคุณกลับมา แต่ไม่นำ `/home` ของคุณกลับมา ดังนั้นมันจึงใช้ได้สำหรับการย้อนกลับการอัปเดตระบบที่พัง แต่ใช้ไม่ได้สำหรับการกู้ไฟล์ส่วนตัวที่สูญหาย

นี่ยังหมายความว่าไดเรกทอรี `~/.config` ของคุณจะยังคงเดิมไม่เปลี่ยนแปลง ดังนั้นถ้าคุณกำลังย้อนกลับไปใช้เวอร์ชันก่อนหน้าของไลบรารีหรือแอปพลิเคชันที่เก็บไฟล์การตั้งค่าในรูปแบบใหม่ คุณจะต้องจัดการเรื่องนั้นเองด้วยมือ

บันทึกของ Omarchy เองว่าย้ายข้อมูลใดไปแล้วบ้างก็เช่นเดียวกัน: มันอยู่ใน home directory ของคุณ ดังนั้นมันจึงรอดจากการกู้คืน การย้ายข้อมูลที่รันหลังจากสร้างสแน็ปช็อตจะยังคงถูกทำเครื่องหมายว่าทำเสร็จแล้ว แม้ว่าการเปลี่ยนแปลงที่พวกมันทำกับ root filesystem จะถูกย้อนกลับแล้วก็ตาม และการ `omarchy update` ครั้งถัดไปจะไม่รันพวกมันอีกครั้ง ดังนั้นถ้าคุณอัปเดตอีกครั้งหลังการกู้คืนและบางอย่างที่การอัปเดตก่อนหน้านี้ตั้งค่าไว้ยังคงขาดหายไป นั่นน่าจะเป็นสาเหตุ
