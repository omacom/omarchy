# สแน็ปช็อตของระบบ

เราสร้างสแน็ปช็อตโดยอัตโนมัติทุกครั้งที่มีการอัปเดต Omarchy แต่หากคุณต้องการสร้างสแน็ปช็อตของคุณเอง คุณสามารถใช้ `omarchy-snapshot create` ได้

ในการบูตและกู้คืนสแน็ปช็อต คุณเลือกสแน็ปช็อตนั้นจากตัวโหลดการบูต Limine เมนูบูตจะถูกซ่อนไว้เป็นค่าเริ่มต้น ดังนั้นให้กดปุ่มใดก็ได้ทันทีที่ Limine เริ่มทำงานเพื่อเปิดเมนูขึ้นมา

จากหน้าจอนั้น เลือกสแน็ปช็อตที่คุณต้องการบูตเข้าใช้งานตามวันที่และเวอร์ชัน เวอร์ชันของ Omarchy ณ เวลาที่สร้างสแน็ปช็อตสามารถดูได้ที่มุมล่างซ้าย

 ![snapshots-bootloader](images/snapshots-bootloader.webp)

เมื่อคุณเข้ามาข้างในแล้ว การแจ้งเตือนจะปรากฏขึ้นเพื่อแจ้งให้คุณทราบว่าคุณอยู่ในสแน็ปช็อตที่สามารถบูตได้ และหากคุณคลิกที่การแจ้งเตือนนั้น กระบวนการกู้คืนจะเริ่มขึ้น หรืออีกทางหนึ่ง คุณสามารถใช้ `omarchy-snapshot restore` ได้

 ![snapshots-restore](images/snapshots-restore.webp)

การดำเนินการนี้จะกู้คืนระบบไฟล์ root ของคุณ แต่จะไม่กู้คืน `/home` ของคุณ ดังนั้นจึงใช้ได้สำหรับการย้อนกลับการอัปเดตระบบที่เสียหาย แต่ใช้ไม่ได้สำหรับการกู้คืนไฟล์ส่วนตัวที่สูญหาย

ซึ่งหมายความว่าไดเรกทอรี `~/.config` ของคุณจะยังคงอยู่ตามเดิม ดังนั้นหากคุณกำลังย้อนกลับไปยังเวอร์ชันก่อนหน้าของไลบรารีหรือแอปพลิเคชันที่จัดเก็บไฟล์การกำหนดค่าในรูปแบบใหม่ คุณจะต้องจัดการเรื่องนั้นด้วยตัวเอง

เช่นเดียวกันกับบันทึกของ Omarchy เองว่า migration ใดบ้างที่ทำงานไปแล้ว: บันทึกนั้นอยู่ในไดเรกทอรี home ของคุณ จึงรอดพ้นจากการกู้คืน migration ที่ทำงานหลังจากที่สร้างสแน็ปช็อตจะยังคงถูกทำเครื่องหมายว่าเสร็จสิ้นแล้ว แม้ว่าการเปลี่ยนแปลงที่ migration เหล่านั้นทำกับระบบไฟล์ root จะถูกย้อนกลับไปแล้วก็ตาม และการทำ `omarchy update` ครั้งต่อไปก็จะไม่รัน migration เหล่านั้นอีก ดังนั้นหากคุณอัปเดตอีกครั้งหลังการกู้คืนแล้วพบว่าบางสิ่งที่การอัปเดตก่อนหน้านี้เคยตั้งค่าไว้ยังคงหายไป นั่นน่าจะเป็นสาเหตุ

_หมายเหตุ: ฟีเจอร์นี้ใช้ได้เฉพาะกับการติดตั้งที่ใช้ตัวโหลดการบูต Limine ซึ่งใช้เป็นค่าเริ่มต้นตั้งแต่ Omarchy 2.0 เท่านั้น ไม่สามารถใช้ได้หากคุณใช้ GRUB หรือ systemd-boot_
