# เตือนความจำ

Omarchy มีวิธีตั้งรายการเตือนความจำง่าย ๆ ตามการนับถอยหลังพร้อมข้อความในตัว คุณสามารถทำได้ผ่าน `Super + Ctrl + R` ดูรายการทั้งหมดที่ตั้งไว้ผ่าน `Super + Ctrl + Alt + R` และล้างทั้งหมดผ่าน `Super + Ctrl + Shift + R` ทุกอย่างยังเข้าถึงได้ผ่าน _สั่งการ > เตือนความจำ_ คุณยังใช้ CLI ด้วย `omarchy reminder 7 'Tea ready'` ได้ด้วย
