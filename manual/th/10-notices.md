# ประกาศแจ้ง

คุณเข้าถึงวันที่และเวลา สถานะแบตเตอรี่ และสภาพอากาศปัจจุบันได้อย่างรวดเร็วโดยใช้ปุ่มลัดประกาศแจ้ง

### วันที่และเวลา

`Super + Ctrl + Alt + T`

 ![notice-datetime](images/notice-datetime.webp)

### สภาพอากาศ

`Super + Ctrl + Alt + W`

 ![notice-weather](images/notice-weather.webp)

ตำแหน่งตรวจพบจากที่อยู่ IP ของคุณ ซึ่งมักจะใกล้เคียงพอ แต่ก็ไม่เสมอไป คุณสามารถปักหมุดมันด้วย `omarchy weather location --set Malibu` หรือระบุให้แม่นยำโดยการเพิ่มพิกัด: `omarchy weather location --set Malibu 34.0259,-118.7798` รัน `omarchy weather location` เพียงอย่างเดียวเพื่อดูว่ามันคิดว่าคุณอยู่ที่ไหน และ `--clear` เพื่อกลับไปใช้การตรวจพบอัตโนมัติ
