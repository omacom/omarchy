# การแจ้งเตือน

การแจ้งเตือนจะปรากฏที่มุมขวาบนของจอแสดงผลที่กำลังโฟกัสอยู่ คุณยังเข้าถึงวันที่และเวลา สถานะแบตเตอรี่ และสภาพอากาศปัจจุบันได้อย่างรวดเร็วโดยใช้การแจ้งเตือนด้วยปุ่มลัด

## การแจ้งเตือน

การแจ้งเตือนจากแอปหรือเว็บไซต์เดียวกันจะซ้อนกันเป็นชุด ดังนั้นช่อง Slack ที่คุยไม่หยุดจะไม่ดันการแจ้งเตือนว่า build ล้มเหลวของคุณหลุดจากหน้าจอ เลื่อนตัวชี้ไปวางเหนือชุดนั้นเพื่อคลี่มันออก จะไม่มีอะไรใหม่เลื่อนเข้ามาใต้ตัวชี้ของคุณในขณะที่คุณกำลังอ่าน คลิกการ์ดเพื่อกระโดดไปยังต้นทาง คลิกขวา คลิกกลาง หรือกด ✕ เพื่อปิดมัน

การ์ดจะเสนอสิ่งที่มันพกมา: _คัดลอกรหัส_ สำหรับรหัสยืนยัน (เก็บไว้ไม่ให้อยู่ใน [ประวัติคลิปบอร์ด](08-unified-clipboard-history.md) และล้างออกหลังจากหนึ่งนาที) พร้อมกับปุ่มใด ๆ ที่แอปให้มา ลิงก์ในข้อความของการแจ้งเตือนจะเปิดเมื่อคลิก

`Super + ,` ปิดการแจ้งเตือนใหม่ล่าสุด หรือเปิดสิ่งที่มันชี้ไปเมื่อมันเสนอตัวเลือกนั้น `Super + Alt + ,` ปิดเฉพาะอันสุดท้าย `Super + Shift + ,` ปิดทั้งหมด และ `Super + Shift + Alt + ,` เปิดประวัติ หากต้องการใช้โดยไม่ต้องใช้เมาส์ กด `Super + Ctrl + ,` การแจ้งเตือนใหม่ล่าสุดจะถูกเลือกและปุ่มของมันจะมีหมายเลขกำกับ: กดหมายเลขเพื่อใช้ปุ่มนั้น กด `Enter` เพื่อคลิกการแจ้งเตือน กด `↑` และ `↓` เพื่อย้ายระหว่างการแจ้งเตือน กด `Delete` เพื่อปิดอันหนึ่ง และกด `Esc` เพื่อคืนคีย์บอร์ดกลับไป มันยังปล่อยเองโดยอัตโนมัติหลังจากไม่มีการใช้งานไม่กี่วินาที

การปิดเสียงการแจ้งเตือนจะกักพวกมันไว้ ยกเว้นการยืนยันของ Omarchy เอง การแจ้งเตือนฉุกเฉิน และรหัสยืนยัน ซึ่งคุณเพิ่งขอไปเมื่อครู่ นำสองสามอันล่าสุดกลับมาแสดงบนหน้าจอ ไม่ว่าจะถูกกักไว้หรือไม่ ด้วย `Super + Shift + Alt + ,` ประวัติจะถูกเก็บไว้หนึ่งวัน

## การแจ้งเตือนด้วยปุ่มลัด

### วันที่และเวลา

`Super + Ctrl + Alt + T`

 ![notice-datetime](images/notice-datetime.webp)

### สภาพอากาศ

`Super + Ctrl + Alt + W`

 ![notice-weather](images/notice-weather.webp)

ตำแหน่งจะถูกตรวจจับจากที่อยู่ IP ของคุณ ซึ่งโดยปกติก็ใกล้เคียงพอ แต่ไม่เสมอไป คุณสามารถตรึงมันไว้ด้วย `omarchy weather location --set Malibu` หรือระบุให้แม่นยำด้วยการเพิ่มพิกัด: `omarchy weather location --set Malibu 34.0259,-118.7798` รัน `omarchy weather location` เพียงอย่างเดียวเพื่อดูว่ามันคิดว่าคุณอยู่ที่ไหน และ `--clear` เพื่อกลับไปใช้การตรวจจับอัตโนมัติ
