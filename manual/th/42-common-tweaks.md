# การปรับแต่งทั่วไป

นี่คือคอลเลกชันการปรับแต่งทั่วไปสำหรับการตั้งค่า Omarchy พึงรู้ว่าบางครั้งการอัปเดตระบบอาจจำเป็นต้องคืนค่าการกำหนดค่าบางอย่างกลับสู่สภาพเดิม ถ้าสิ่งนี้เกิดขึ้น การเปลี่ยนแปลงของคุณจะไม่สูญหาย แต่จะถูกใส่ไว้ในไฟล์ `.bak` ในไดเรกทอรีเดียวกัน

ถ้าคุณทำอะไรพัง คุณสามารถคืนค่าการกำหนดค่าแต่ละรายการกลับสู่การตั้งค่าเดิมได้ผ่าน _อัปเดต > การกำหนดค่า_ ในเมนู Omarchy ถ้าคุณทำทุกอย่างพัง _จริง ๆ_ คุณสามารถรีเซ็ตการกำหนดค่าทั้งหมดได้ผ่าน `omarchy-reinstall`

### แสดงไอคอนถาดทั้งหมดตลอดเวลา

เป็นค่าเริ่มต้น ไอคอนถาด เช่น Dropbox, 1password หรือ Steam จะซ่อนอยู่หลังลูกศรขยายถาด ซึ่งจะแสดงพวกมันเมื่อคุณวางเมาส์เหนือมัน ถ้าคุณอยากให้พวกมันเปิดเผยตลอดเวลา คลิกขวาที่ลูกศรขยายเพื่อเปิดตัวจัดการไอคอนถาด แล้วตรึงไอคอนที่คุณอยากให้มองเห็นอยู่เสมอ (คุณยังซ่อนไอคอนที่คุณไม่อยากเห็นเลยได้ด้วย)

### มุมหน้าต่างโค้งมน

การออกแบบเริ่มต้นของ Omarchy คือมุมเหลี่ยม แต่ถ้าคุณชอบทำให้มันนุ่มนวลขึ้นเล็กน้อย คุณสามารถเปลี่ยน `~/.config/hypr/looknfeel.lua` เพื่อให้ rounding ไม่ถูกคอมเมนต์ออกอีกต่อไป:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### นำช่องว่างหน้าต่างออก

บนจอแสดงผลแล็ปท็อป บางคนชอบไม่เสียพิกเซลใด ๆ ให้กับช่องว่างหน้าต่าง (หรือแม้แต่แถบบน ซึ่งคุณปิดได้ด้วย `Super + Shift + Space`) คุณสามารถสลับช่องว่างและเส้นขอบทั้งหมดออกด้วย `Super + Shift + Backspace` หรือนำพวกมันออกอย่างถาวรโดยลบคอมเมนต์ในส่วนนี้ของ `~/.config/hypr/looknfeel.lua`:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
