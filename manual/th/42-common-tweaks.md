# การปรับแต่งที่พบบ่อย

นี่คือชุดรวมการปรับแต่งยอดนิยมสำหรับชุดติดตั้ง Omarchy โปรดทราบว่าบางครั้งการอัปเดตระบบอาจจำเป็นต้องคืนค่าคอนฟิกบางอย่างกลับสู่สภาพเดิม หากเกิดกรณีนี้ขึ้น การเปลี่ยนแปลงของคุณจะไม่สูญหาย แต่จะถูกเก็บไว้ในไฟล์ `.bak.<timestamp>` ข้างไฟล์ต้นฉบับ

ถ้าคุณทำอะไรพัง คุณสามารถคืนค่าคอนฟิกแต่ละรายการกลับสู่การตั้งค่าดั้งเดิมได้ผ่าน _อัปเดต > คอนฟิก_ ในเมนู Omarchy ถ้าคุณทำทุกอย่างพัง _จริง ๆ_ คุณสามารถรีเซ็ตคอนฟิกทั้งหมดได้ด้วย `omarchy reinstall configs` หรือติดตั้งแพ็กเกจและคอนฟิกเริ่มต้นทั้งหมดใหม่ด้วย `omarchy reinstall`

### แสดงไอคอนในถาดระบบทั้งหมดตลอดเวลา

โดยค่าเริ่มต้น ไอคอนในถาดระบบ เช่น Dropbox, 1password หรือ Steam จะถูกซ่อนไว้หลังลูกศรขยายถาดระบบ ซึ่งจะแสดงไอคอนเหล่านั้นเมื่อคุณวางตัวชี้เมาส์เหนือลูกศร หากคุณต้องการให้ไอคอนเหล่านั้นแสดงอยู่ตลอดเวลา ให้คลิกขวาที่ลูกศรขยายเพื่อเปิดตัวจัดการไอคอนในถาดระบบ จากนั้นปักหมุดไอคอนที่คุณต้องการให้มองเห็นอยู่เสมอ (คุณยังสามารถซ่อนไอคอนที่คุณไม่อยากเห็นเลยได้ด้วย)

### มุมหน้าต่างแบบโค้งมน

ดีไซน์เริ่มต้นของ Omarchy ใช้มุมแบบเหลี่ยม แต่ถ้าคุณอยากทำให้มันดูนุ่มนวลลงสักหน่อย ให้เลือก _ลักษณะที่ปรากฏ > หน้าต่าง > มุมหน้าต่าง > มุมโค้งมน_ ในเมนู Omarchy หรือรัน `omarchy hyprland corners rounded` ส่วน _มุมตามธีม_ จะกลับไปใช้สิ่งที่ธีมกำหนดไว้ หากต้องการเลือกรัศมีความโค้งเอง ให้คงไว้ที่ _มุมตามธีม_ (`omarchy hyprland corners theme`) เนื่องจากโหมด Rounded และ Sharp จะโหลดหลังคอนฟิกของคุณและเขียนทับคอนฟิกนั้น แล้ว取消การคอมเมนต์ส่วน rounding ใน `~/.config/hypr/looknfeel.lua`:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### ลบช่องว่างระหว่างหน้าต่าง

บนหน้าจอแล็ปท็อป บางคนชอบที่จะไม่เสียพิกเซลไปกับช่องว่างระหว่างหน้าต่างเลย (หรือแม้แต่แถบด้านบน ซึ่งคุณสามารถสลับเปิด/ปิดได้ด้วย `Super + Shift + Space`) คุณสามารถสลับปิดช่องว่างและขอบทั้งหมดได้ด้วย `Super + Shift + Backspace` หรือลบออกอย่างถาวรโดยการนำคอมเมนต์ในส่วนนี้ของ `~/.config/hypr/looknfeel.lua` ออก:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
