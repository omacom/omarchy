# มาจาก Mac หรือ Windows

ถ้าคุณใช้ macOS หรือ Windows มาหลายปี นิ้วของคุณจะจำอะไรได้เป็นร้อยอย่างที่สมองลืมไปแล้วว่าเคยเรียนรู้ บทนี้คือชั้นแปลภาษา: สัญชาตญาณเหล่านั้นจะไปอยู่ตรงไหนใน Omarchy ส่วนตัวฟีเจอร์เองมีอธิบายเชิงลึกไว้ที่อื่นแล้ว — ตรงนี้เป็นแค่แผนที่

### Super คือศูนย์กลางของทุกสิ่ง

ความจำของกล้ามเนื้อทั้งหมดที่คุณสร้างไว้รอบปุ่ม Cmd หรือปุ่ม Windows จะย้ายมาอยู่ที่ปุ่มเดียว: Super นั่นคือปุ่ม Windows บนคีย์บอร์ด PC และมันคือหลักยึดของแทบทุกคีย์ลัดใน Omarchy

รีเฟล็กซ์การเรียก Spotlight หรือ Raycast หรือเมนู Start ของคุณจะกลายเป็น `Super + Space` ซึ่งจะเปิดเมนู Omarchy ที่ใช้เปิดแอป เปลี่ยนการตั้งค่า ติดตั้งซอฟต์แวร์ จับภาพหน้าจอ — แทบทุกอย่าง เริ่มพิมพ์เพื่อกรองได้เลย `Super + Alt + Space` จะแสดงทุกแอปบนตารางเดียว แบบเดียวกับที่ Launchpad ทำ ดู [การนำทาง](04-navigation.md)

### ไม่มีไอคอนบนเดสก์ท็อป และ dock จะหลบให้พ้นทาง

ไม่มีไอคอนให้จัดเรียงบนเดสก์ท็อป และ dock จะซ่อนตัวเมื่อ workspace มีหน้าต่าง จนกว่าคุณจะดันตัวชี้ไปที่ขอบจอด้านที่มันอยู่ ซึ่งคือด้านล่าง เว้นแต่คุณจะย้ายมันไป (ดู [การนำทาง](04-navigation.md)) แอปต่าง ๆ เปิดได้จากคีย์ลัด (`Super + Return` สำหรับ terminal, `Super + Shift + Return` สำหรับเบราว์เซอร์ และ `Super + K` สำหรับรายการทุกอย่างที่แมปไว้) หรือจากเมนู ชิ้นส่วน UI ชิ้นเดียวที่อยู่ตลอดคือ [แถบด้านบน](05-the-top-bar.md) ซึ่งครอบคลุมหน้าที่ที่แถบเมนู ถาดระบบ และ Notification Center เคยทำให้คุณมาก่อน — และวิดเจ็ตเกือบทุกตัวบนนั้นทำอะไรบางอย่างเมื่อคลิกซ้าย ขวา และกลาง

### หน้าต่างจัดวางตัวเอง

การเปลี่ยนวิธีคิดครั้งใหญ่ที่สุด: คุณไม่ต้องลากหน้าต่างไปมา หรือ snap มันเข้ากับครึ่งหน้าจอ เปิดหน้าต่างหนึ่งมันก็กินพื้นที่ทั้งหน้าจอ เปิดหน้าต่างที่สองพวกมันก็แบ่งหน้าจอกัน คุณไม่ต้องควานหาหน้าต่างจากใต้หน้าต่างอื่นเลย เพราะหน้าต่างไม่ซ้อนทับกัน

เมื่อคุณจำเป็นต้องใช้หน้าต่างลอยจริง ๆ `Super + T` จะสลับหน้าต่างที่ใช้งานอยู่ให้ออกจาก tiling (และกลับเข้าไปได้) แต่ลองให้โอกาส tiling จริง ๆ ก่อน — มันคือหัวใจของทั้งหมดนี้ [การนำทาง](04-navigation.md) จะพาคุณไปรู้จักมัน

Workspaces จะให้ความรู้สึกคุ้นเคย: มันคือ Spaces ของ macOS หรือเดสก์ท็อปเสมือนของ Windows เพียงแต่คุณจะได้ใช้มันจริง ๆ เพราะ `Super + 1/2/3/4` กระโดดตรงไปยังอันนั้นเลย และ `Super + Shift + 1/2/3/4` ส่งหน้าต่างที่ใช้งานอยู่ไปที่นั่น ไม่มีดีเลย์จากแอนิเมชัน มีแต่การกระโดดแบบทันที นั่นหมายความว่าคุณอาจไม่จำเป็นต้องใช้หลายจออีกต่อไปเลย ถ้าคุณเคยชินกับแบบนั้นมาก่อน

### คัดลอกและวางใช้ได้เลย

บน Mac คุณมี Cmd + C ทุกที่ บน Windows คุณมี Ctrl + C ทุกที่ — ยกเว้นใน terminal ที่มันจะฆ่าโปรแกรมของคุณ Omarchy ให้ `Super + C`, `Super + X` และ `Super + V` แก่คุณ และมันใช้ได้ทุกที่ รวมถึงใน terminal ด้วย ไม่ต้องเรียนรู้รีเฟล็กซ์แยกต่างหากสำหรับ shell

ชาว Windows: ประวัติคลิปบอร์ด Win + V ของคุณจะมาอยู่ที่ `Super + Ctrl + V` และมันเก็บรูปภาพไว้ได้เช่นเดียวกับข้อความ ดู [คลิปบอร์ดและประวัติแบบรวมศูนย์](08-unified-clipboard-history.md)

| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` หรือ `Print Screen` — ดู [ภาพหน้าจอและการบันทึก](12-screenshots-recording.md) |

| Finder / File Explorer | Files, ที่ `Super + Shift + F` — ดู [GUIs](22-guis.md) |

| Preview / Photos | Omaview สำหรับรูปภาพ วิดีโอ และเพลง, Document Viewer สำหรับ PDFs — ดู [GUIs](22-guis.md) |
| TextEdit / Notepad | Plain, ที่ `Super + Shift + N`; เลือกตัวอื่นได้ที่ _Setup > Defaults > Editor_ |

### บางอย่างต่างออกไปจริง ๆ

การตั้งค่าจำนวนมากอยู่ในไฟล์ข้อความที่คุณแก้ไขเอง ไม่ใช่แผงต่าง ๆ ให้คลิกผ่าน ฟังดูดั้งเดิมจนกว่าคุณจะตระหนักว่ามันหมายความว่าทุกการปรับแต่งสามารถมองเห็นได้ คัดลอกไปยังเครื่องถัดไปของคุณได้ และใส่ไว้ในการควบคุมเวอร์ชันได้ เมนู _Setup_ จะพาคุณตรงไปยังไฟล์ที่ถูกต้อง และรีสตาร์ตอะไรก็ตามที่ต้องรีสตาร์ตเมื่อคุณทำเสร็จ

การอัปเดตมาผ่านคำสั่งเดียว — _Update > Omarchy_ — ซึ่งอัปเดตตัว Omarchy เองและทุกแพ็กเกจบนระบบ โดยถ่าย snapshot ก่อน ไม่มีการอัปเดตแยกตามแอปมาคอยกวนใจคุณแบบสุ่ม ๆ ดู [การอัปเดต](30-updates.md)

ซอฟต์แวร์มาจากตัวจัดการแพ็กเกจ ไม่ใช่จากตัวติดตั้งที่ดาวน์โหลดมา

และเมื่อคุณปิดหน้าต่าง แอปก็จะออกจริง ๆ ไม่มีภาวะค้างเติ่งแบบ macOS ที่โปรแกรมยังทำงานต่อไปโดยไม่มีหน้าต่าง `Super + W` — หรือ `Super + Q` ถ้านั่นคือความจำของนิ้วที่คุณติดตัวมา — หมายความว่าหายไปเลย

### บนฮาร์ดแวร์ Mac

Omarchy ทำงานได้ดีบน Mac ที่ใช้ Intel และบน Mac ที่ใช้ M1, M2 และ M3 ด้วย Omarchy for Apple Silicon ดู [การรองรับ Mac](44-mac-support.md) และคีย์บอร์ดก็เป็นมิตรกับคุณ: Omarchy ไม่ remap อะไรเลย และ Linux ถือว่าปุ่ม Command คือ Super ดังนั้น Super จึงอยู่ตรงตำแหน่งที่ Cmd เคยอยู่พอดี นิ้วหัวแม่มือของคุณจะไม่รู้สึกถึงการย้ายที่เลย

### ให้เวลามันสองสัปดาห์

สัญชาตญาณจะย้ายมาเร็วกว่าที่คุณคิด อ่านบท [คีย์ลัด](07-hotkeys.md) ผ่าน ๆ สักครั้ง และเมื่อไหร่ที่คุณนึกไม่ออกว่า binding คืออะไร ให้กด `Super + K` — มันจะแสดงทั้งหมดให้คุณดู นั่นคือคีย์ลัดตัวเดียวที่คุณต้องจำจริง ๆ
