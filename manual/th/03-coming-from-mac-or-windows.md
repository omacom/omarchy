# มาจาก Mac หรือ Windows

ถ้าคุณใช้ macOS หรือ Windows มานานหลายปี นิ้วของคุณจะจำสิ่งต่าง ๆ ได้เป็นร้อยอย่างที่สมองของคุณลืมไปแล้วว่าเคยเรียนรู้มา บทนี้คือชั้นแปลภาษา: สัญชาตญาณเหล่านั้นไปอยู่ที่ไหนใน Omarchy ฟีเจอร์ต่าง ๆ เองมีอธิบายเชิงลึกไว้ที่อื่นแล้ว — นี่เป็นเพียงแผนที่เท่านั้น

### Super คือศูนย์กลางของทุกอย่าง

ความจำของกล้ามเนื้อทั้งหมดที่คุณสร้างมารอบ Cmd หรือปุ่ม Windows จะย้ายมาอยู่ที่ปุ่มเดียว: Super นั่นคือปุ่ม Windows บนคีย์บอร์ด PC และมันคือจุดยึดของปุ่มลัดแทบทุกปุ่มใน Omarchy

ปฏิกิริยาที่จะเปิด Spotlight หรือ Raycast หรือเมนู Start ของคุณจะกลายเป็น `Super + Space` นั่นจะเปิดเมนู Omarchy ซึ่งใช้เปิดแอป เปลี่ยนการตั้งค่า ติดตั้งซอฟต์แวร์ จับภาพหน้าจอ — แทบทุกอย่าง เริ่มพิมพ์เพื่อกรองผลลัพธ์ `Super + Alt + Space` จะแสดงทุกแอปบนตารางเดียว แบบเดียวกับที่ Launchpad ทำ ดู [การนำทาง](04-navigation.md)

### ไม่มี dock และไม่มีไอคอนบนเดสก์ท็อป

ไม่มีอะไรให้คลิกเพื่อเปิดสิ่งต่าง ๆ ไม่มีไอคอนให้จัดเรียงบนเดสก์ท็อป แอปต่าง ๆ เปิดจากปุ่มลัด (`Super + Return` สำหรับเทอร์มินัล `Super + Shift + Return` สำหรับเบราว์เซอร์ และ `Super + K` สำหรับรายการของทุกอย่างที่มีการกำหนดไว้) หรือจากเมนู UI ชิ้นเดียวที่อยู่ตลอดคือ [แถบด้านบน](05-the-top-bar.md) ซึ่งครอบคลุมสิ่งที่แถบเมนู ถาดระบบ และ Notification Center เคยทำให้คุณมาก่อน — และวิดเจ็ตแทบทุกชิ้นบนแถบนั้นจะทำบางอย่างเมื่อคลิกซ้าย คลิกขวา และคลิกกลาง

### หน้าต่างจัดวางตัวเอง

การเปลี่ยนกรอบความคิดครั้งใหญ่ที่สุด: คุณไม่ต้องลากหน้าต่างไปรอบ ๆ หรือจัดให้ชิดครึ่งจอ เปิดหน้าต่างหนึ่งขึ้นมาแล้วมันจะใช้พื้นที่ทั้งจอ เปิดหน้าต่างที่สองแล้วทั้งสองจะแบ่งจอกัน คุณไม่ต้องควานหาหน้าต่างจากใต้อีกหน้าต่างหนึ่งเลย เพราะหน้าต่างไม่ซ้อนทับกัน

เมื่อคุณจำเป็นต้องใช้หน้าต่างแบบลอยจริง ๆ `Super + T` จะสลับหน้าต่างที่ใช้งานอยู่ออกจากการจัดเรียงแบบเรียงต่อกัน (และกลับเข้าไป) แต่ขอให้ลองใช้การจัดเรียงแบบเรียงต่อกันอย่างจริงจังก่อน — มันคือหัวใจของทั้งหมดนี้ [การนำทาง](04-navigation.md) จะพาคุณไปรู้จักมัน

Workspaces จะให้ความรู้สึกคุ้นเคย: มันคือ Spaces ของ macOS หรือเดสก์ท็อปเสมือนของ Windows เพียงแต่คุณจะได้ใช้มันจริง ๆ เพราะ `Super + 1/2/3/4` จะกระโดดตรงไปยังพื้นที่ทำงานนั้น และ `Super + Shift + 1/2/3/4` จะส่งหน้าต่างที่ใช้งานอยู่ไปที่นั่น ไม่มีดีเลย์จากแอนิเมชัน มีแค่การกระโดดทันที ซึ่งหมายความว่าคุณอาจไม่จำเป็นต้องใช้หลายจอเลยด้วยซ้ำ ถ้าคุณเคยชินกับแบบนั้นมาก่อน

### คัดลอกและวางใช้ได้เลย

บน Mac คุณมี Cmd + C ใช้ได้ทุกที่ บน Windows คุณมี Ctrl + C ใช้ได้ทุกที่ — ยกเว้นในเทอร์มินัล ที่มันจะฆ่าโปรแกรมของคุณ Omarchy ให้คุณใช้ `Super + C`, `Super + X` และ `Super + V` และมันใช้ได้ทุกที่ รวมถึงในเทอร์มินัลด้วย ไม่ต้องเรียนรู้ปฏิกิริยาแยกต่างหากสำหรับเชลล์

ชาว Windows: ประวัติคลิปบอร์ด Win + V ของคุณอยู่บน `Super + Ctrl + V` และมันเก็บรูปภาพได้เช่นเดียวกับข้อความ ดู [คลิปบอร์ดและประวัติแบบรวมศูนย์](08-unified-clipboard-history.md)

### ตารางแปลภาษา

| สิ่งที่คุณเคยใช้ | ใน Omarchy |
| ------------- | ---------- |
| Spotlight / Raycast / เมนู Start | `Super + Space` — เมนู Omarchy |
| AirDrop | LocalSend ผ่าน `Super + Ctrl + S` — ดู [GUIs](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` หรือ `Print Screen` — ดู [ภาพหน้าจอและการบันทึก](12-screenshots-recording.md) |
| Notification Center | ประวัติการแจ้งเตือนบน `Super + Shift + Alt + ,` |
| Time Machine (สำหรับระบบ) | [สแนปช็อตของระบบ](47-system-snapshots.md) แบบอัตโนมัติในทุกการอัปเดต |
| App Store / การดาวน์โหลดตัวติดตั้ง | _Install_ ในเมนู หรือ `omarchy pkg add` — ดู [แพ็กเกจอื่น ๆ](29-other-packages.md) |
| System Settings / Control Panel | _Setup_ ในเมนู ซึ่งแก้ไขไฟล์คอนฟิกแบบข้อความธรรมดา — ดู [dotfiles](31-dotfiles.md) |

### บางอย่างแตกต่างออกไปจริง ๆ

การตั้งค่าจำนวนมากอยู่ในไฟล์ข้อความที่คุณแก้ไข ไม่ใช่แผงต่าง ๆ ที่คุณคลิกผ่านไปเรื่อย ๆ ฟังดูดั้งเดิมจนกระทั่งคุณตระหนักว่ามันหมายความว่าทุกการปรับแต่งสามารถมองเห็นได้ คัดลอกไปยังเครื่องถัดไปของคุณได้ และเก็บไว้ในการควบคุมเวอร์ชันได้ เมนู _Setup_ จะพาคุณตรงไปยังไฟล์ที่ถูกต้อง และรีสตาร์ตสิ่งที่ต้องรีสตาร์ตเมื่อคุณทำเสร็จ

การอัปเดตมาผ่านคำสั่งเดียว — _Update > Omarchy_ — ซึ่งอัปเดต Omarchy เองและทุกแพ็กเกจบนระบบ โดยสร้างสแนปช็อตก่อน ไม่มีตัวอัปเดตแยกตามแอปมาคอยกวนใจคุณแบบสุ่ม ๆ ดู [การอัปเดต](30-updates.md)

ซอฟต์แวร์มาจากตัวจัดการแพ็กเกจ ไม่ใช่จากตัวติดตั้งที่ดาวน์โหลดมา

และเมื่อคุณปิดหน้าต่าง แอปจะปิดตัวลงจริง ๆ ไม่มีภาวะค้างคาแบบ macOS ที่โปรแกรมยังทำงานต่อไปโดยไม่มีหน้าต่าง `Super + W` — หรือ `Super + Q` ถ้านั่นคือความจำของนิ้วที่คุณติดตัวมา — หมายถึงหายไปเลย

### บนฮาร์ดแวร์ Mac

Omarchy ทำงานได้ดีบน Intel Macs — ดู [การรองรับ Mac](44-mac-support.md) และคีย์บอร์ดก็ใจดีกับคุณ: Omarchy ไม่ได้ remap อะไรเลย และ Linux ถือว่าปุ่ม Command คือ Super ดังนั้น Super จึงอยู่ตรงตำแหน่งที่ Cmd เคยอยู่เสมอ นิ้วโป้งของคุณจะไม่รู้สึกถึงการย้ายเลย

### ให้เวลาสองสัปดาห์

สัญชาตญาณจะย้ายมาเร็วกว่าที่คุณคิด อ่านบท [ปุ่มลัด](07-hotkeys.md) ผ่าน ๆ สักครั้ง และเมื่อใดก็ตามที่คุณนึกการกำหนดปุ่มไม่ออก ให้กด `Super + K` — มันจะแสดงทั้งหมดให้คุณดู นั่นคือปุ่มลัดเดียวที่คุณต้องจำจริง ๆ
