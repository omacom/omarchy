# ย้ายมาจาก Mac หรือ Windows

ถ้าคุณใช้ macOS หรือ Windows มานานหลายปี นิ้วของคุณรู้เป็นร้อยสิ่งที่สมองของคุณลืมไปแล้วว่าเคยเรียนรู้ บทนี้คือชั้นการแปล: สัญชาตญาณเหล่านั้นย้ายไปที่ไหนใน Omarchy ฟีเจอร์ต่าง ๆ เองมีอธิบายอย่างลึกไว้ที่อื่นแล้ว — ตรงนี้เป็นเพียงแผนที่เท่านั้น

### Super คือศูนย์กลางของทุกสิ่ง

ความจำของกล้ามเนื้อทั้งหมดที่คุณสร้างไว้รอบ ๆ Cmd หรือปุ่ม Windows จะถ่ายโอนไปสู่ปุ่มเดียว: Super นั่นคือปุ่ม Windows บนคีย์บอร์ด PC และเป็นจุดยึดของปุ่มลัดเกือบทุกปุ่มใน Omarchy

ปฏิกิริยาต่อ Spotlight หรือ Raycast หรือเมนู Start ของคุณจะกลายเป็น `Super + Space` นั่นเปิดเมนู Omarchy ซึ่งเปิดแอป เปลี่ยนการตั้งค่า ติดตั้งซอฟต์แวร์ จับภาพหน้าจอ — แทบทุกอย่าง เริ่มพิมพ์เพื่อกรอง `Super + Alt + Space` แสดงทุกแอปในตารางเดียว แบบเดียวกับ Launchpad ดู [การนำทาง](04-navigation.md)

### ไม่มี dock และไม่มีไอคอนบนเดสก์ท็อป

ไม่มีอะไรให้คลิกเพื่อเปิดอะไรเลย ไม่มีไอคอนให้จัดวางบนเดสก์ท็อป แอปเปิดจากปุ่มลัด (`Super + Return` สำหรับเทอร์มินัล `Super + Shift + Return` สำหรับเบราว์เซอร์ และ `Super + K` สำหรับรายการทุกสิ่งที่ผูกไว้) หรือจากเมนู อินเทอร์เฟซเดียวที่อยู่ตลอดคือ [แถบบน](05-the-top-bar.md) ซึ่งทำหน้าที่แทนแถบเมนู ถาดระบบ และ Notification Center ที่เคยทำให้คุณก่อนหน้านี้ — และวิดเจ็ตเกือบทุกตัวบนแถบนั้นทำอะไรบางอย่างเมื่อคลิกซ้าย คลิกขวา และคลิกกลาง

### หน้าต่างวางตัวเอง

การปรับทัศนคติครั้งใหญ่ที่สุด: คุณไม่ลากหน้าต่างไปมา หรือจับมันติดด้านครึ่งหน้าจอ เปิดหน้าต่างหนึ่ง มันกินทั้งหน้าจอ เปิดหน้าต่างที่สอง พวกมันแบ่งหน้าจอกัน คุณไม่ต้องงัดหน้าต่างจากใต้หน้าต่างอีกบานหนึ่งอีกเลย เพราะหน้าต่างไม่ซ้อนกัน

เมื่อคุณต้องการหน้าต่างลอยจริง ๆ `Super + T` จะสลับหน้าต่างที่ใช้งานอยู่ออกจากการเรียง (และกลับเข้า) แต่ขอให้โอกาสรูปแบบการเรียงนี้อย่างแท้จริงก่อน — มันคือหัวใจของทุกสิ่งทั้งหมด [การนำทาง](04-navigation.md) จะพาคุณผ่านมัน

พื้นที่งานจะรู้สึกคุ้นเคย: พวกมันคือ Spaces ของ macOS หรือเดสก์ท็อปเสมือนของ Windows เพียงแต่คุณจะใช้มันจริง ๆ เพราะ `Super + 1/2/3/4` กระโดดตรงไปพื้นที่งานหนึ่ง และ `Super + Shift + 1/2/3/4` ส่งหน้าต่างที่ใช้งานอยู่ไปที่นั่น ไม่มีความหน่วงจากแอนิเมชัน มีแต่การกระโดดทันที นี่หมายความว่าคุณอาจไม่ต้องการจอภาพหลายจอเลย หากคุณเคยชินกับมันมาก่อน

### คัดลอกและวางใช้ได้เลย

บน Mac คุณมี Cmd + C ทุกที่ บน Windows คุณมี Ctrl + C ทุกที่ — ยกเว้นเทอร์มินัล ที่ซึ่งมันฆ่าโปรแกรมของคุณ Omarchy ให้คุณ `Super + C` `Super + X` และ `Super + V` และพวกมันใช้ได้ทุกที่ รวมทั้งเทอร์มินัล ไม่ต้องเรียนรู้ปฏิกิริยาแยกสำหรับเชลล์

ชาว Windows: ประวัติคลิปบอร์ด Win + V ของคุณอยู่ที่ `Super + Ctrl + V` และมันเก็บภาพเช่นเดียวกับข้อความ ดู [คลิปบอร์ดและประวัติแบบรวมศูนย์](08-unified-clipboard-history.md)

### ตารางแปล

| คุณหยิบอะไร | ใน Omarchy |
| ------------- | ---------- |
| Spotlight / Raycast / เมนู Start | `Super + Space` — เมนู Omarchy |
| AirDrop | LocalSend ผ่าน `Super + Ctrl + S` — ดู [GUI](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Print Screen` — ดู [ภาพหน้าจอและการอัด](12-screenshots-recording.md) |
| Notification Center | ประวัติการแจ้งเตือนบน `Super + Shift + Alt + ,` |
| Time Machine (สำหรับระบบ) | [ภาพรวมระบบ](47-system-snapshots.md) อัตโนมัติทุกครั้งที่มีการอัปเดต |
| App Store / ดาวน์โหลดตัวติดตั้ง | _ติดตั้ง_ ในเมนู หรือ `omarchy pkg add` — ดู [แพ็กเกจอื่น ๆ](29-other-packages.md) |
| System Settings / Control Panel | _ตั้งค่า_ ในเมนู ซึ่งแก้ไขไฟล์คอนฟิกธรรมดา — ดู [dotfiles](31-dotfiles.md) |

### บางสิ่งแตกต่างกันจริง ๆ

การตั้งค่าจำนวนมากอยู่ในไฟล์ข้อความที่คุณแก้ไข ไม่ใช่แผงที่คุณคลิกผ่าน มันฟังดูดึกดำบรรพ์จนกระทั่งคุณตระหนักว่ามันหมายความว่าการปรับแต่งทุกครั้งมองเห็นได้ คัดลอกไปยังเครื่องถัดไปของคุณได้ และนำไปอยู่ภายใต้การควบคุมเวอร์ชันได้ เมนู _ตั้งค่า_ พาคุณตรงไปยังไฟล์ที่ถูกต้อง และรีสตาร์ตอะไรก็ตามที่จำเป็นต้องรีสตาร์ตเมื่อคุณเสร็จ

การอัปเดตมาผ่านคำสั่งเดียว — _อัปเดต > Omarchy_ — ซึ่งอัปเดต Omarchy เองและทุกแพ็กเกจบนระบบ โดยการสร้างภาพรวมก่อน ไม่มีตัวอัปเดตต่อแอปมารบกวนคุณแบบสุ่ม ดู [การอัปเดต](30-updates.md)

ซอฟต์แวร์มาจากตัวจัดการแพ็กเกจ ไม่ใช่จากตัวติดตั้งที่ดาวน์โหลดมา

และเมื่อคุณปิดหน้าต่าง แอปก็ปิดจริง ๆ ไม่มีสภาพก้ำกึ่งของ macOS ที่โปรแกรมยังคงทำงานโดยไม่มีหน้าต่าง `Super + W` — หรือ `Super + Q` ถ้านั่นคือความจำของนิ้วที่คุณเอามาด้วย — หมายความว่าหายไป

### บนฮาร์ดแวร์ Mac

Omarchy ทำงานได้ดีบน Mac Intel — ดู [การรองรับ Mac](44-mac-support.md) และคีย์บอร์ดก็ใจดีกับคุณ: Omarchy ไม่ผูกอะไรใหม่เลย และ Linux ถือว่าปุ่ม Command เป็น Super ดังนั้น Super จึงอยู่ตรงตำแหน่งที่ Cmd เคยอยู่พอดี นิ้วโป้งของคุณจะไม่รู้สึกถึงการย้ายเลย

### ให้เวลาสองสัปดาห์

สัญชาตญาณถ่ายโอนเร็วกว่าที่คุณคิด ลองอ่านบท [ปุ่มลัด](07-hotkeys.md) แบบคร่าว ๆ สักครั้ง และเมื่อใดก็ตามที่คุณนึกปุ่มลัดไม่ออก กด `Super + K` — มันแสดงปุ่มลัดทั้งหมดให้คุณดู นั่นคือปุ่มลัดเดียวที่คุณจำเป็นต้องจำจริง ๆ
