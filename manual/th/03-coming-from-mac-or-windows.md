# มาจาก Mac หรือ Windows

ถ้าคุณใช้ macOS หรือ Windows มาหลายปี นิ้วของคุณจะรู้จักสิ่งต่าง ๆ นับร้อยอย่างที่สมองของคุณลืมไปแล้วว่าเคยเรียนรู้มา บทนี้คือชั้นสำหรับการแปลความ: สัญชาตญาณเหล่านั้นจะไปอยู่ตรงไหนใน Omarchy ตัวฟีเจอร์ต่าง ๆ มีอธิบายไว้อย่างละเอียดที่อื่นแล้ว — นี่เป็นเพียงแผนที่เท่านั้น

### Super คือศูนย์กลางของทุกสิ่ง

ความจำของกล้ามเนื้อทั้งหมดที่คุณสร้างไว้รอบ ๆ Cmd หรือปุ่ม Windows จะย้ายมาอยู่ที่ปุ่มเดียว: Super นั่นคือปุ่ม Windows บนคีย์บอร์ด PC และมันคือหลักยึดสำหรับแทบทุกคีย์ลัดใน Omarchy

รีเฟล็กซ์ Spotlight หรือ Raycast หรือเมนู Start ของคุณจะกลายเป็น `Super + Space` นั่นจะเปิดเมนู Omarchy ซึ่งใช้เปิดแอป เปลี่ยนการตั้งค่า ติดตั้งซอฟต์แวร์ จับภาพหน้าจอ — แทบทุกอย่าง เริ่มพิมพ์เพื่อกรอง `Super + Alt + Space` จะแสดงทุกแอปบนตารางเดียว แบบที่ Launchpad ทำ ดู [การนำทาง](04-navigation.md)

### ไม่มีไอคอนบนเดสก์ท็อป และ dock จะหลบอยู่ให้พ้นทาง

ไม่มีไอคอนให้จัดเรียงบนเดสก์ท็อป และ dock จะซ่อนตัวเมื่อ workspace มีหน้าต่างอยู่ จนกว่าคุณจะดันตัวชี้ไปที่ขอบหน้าจอนั้น ขอบด้านขวา เว้นแต่คุณจะย้ายมันไปไว้ที่อื่น (ดู [การนำทาง](04-navigation.md)) แอปจะเริ่มทำงานจากคีย์ลัด (`Super + Return` สำหรับเทอร์มินัล, `Super + Shift + Return` สำหรับเบราว์เซอร์ และ `Super + K` สำหรับรายการของทุกอย่างที่ถูกแมปไว้) หรือจากเมนู UI ชิ้นเดียวที่อยู่ถาวรคือ [แถบด้านบน](05-the-top-bar.md) ซึ่งครอบคลุมสิ่งที่ menu bar, system tray และ Notification Center เคยทำให้คุณมาก่อน — และแทบทุก widget บนนั้นจะทำบางอย่างเมื่อคลิกซ้าย คลิกขวา และคลิกกลาง

### หน้าต่างจัดวางตัวเอง

การเปลี่ยนวิธีคิดครั้งใหญ่ที่สุด: คุณไม่ต้องลากหน้าต่างไปรอบ ๆ หรือ snap มันไปยังครึ่งหน้าจอ เปิดหน้าต่างหนึ่งขึ้นมา มันจะกินพื้นที่ทั้งหน้าจอ เปิดหน้าต่างที่สอง พวกมันจะแบ่งหน้าจอกัน คุณไม่ต้องควานหาหน้าต่างจากใต้หน้าต่างอีกอันเลย เพราะหน้าต่างจะไม่ซ้อนทับกัน

เมื่อคุณจำเป็นต้องใช้หน้าต่างแบบลอยจริง ๆ `Super + T` จะสลับหน้าต่างที่ใช้งานอยู่ออกจากการจัดเรียงแบบ tiling (และกลับเข้าไป) แต่ให้โอกาส tiling อย่างจริงจังก่อน — มันคือหัวใจของทั้งหมดนี้ [การนำทาง](04-navigation.md) จะพาคุณผ่านเรื่องนี้ไปทีละขั้น

Workspaces จะให้ความรู้สึกคุ้นเคย: มันคือ Spaces ของ macOS หรือ virtual desktops ของ Windows เพียงแต่คุณจะได้ใช้มันจริง ๆ เพราะ `Super + 1/2/3/4` จะกระโดดตรงไปยัง workspace นั้น และ `Super + Shift + 1/2/3/4` จะส่งหน้าต่างที่ใช้งานอยู่ไปที่นั่น ไม่มี animation ให้หน่วงเวลา มีแต่การกระโดดแบบทันที ซึ่งหมายความว่าคุณอาจไม่จำเป็นต้องใช้หลายจอเลยด้วยซ้ำ ถ้าคุณเคยชินกับแบบนั้นมาก่อน

### คัดลอกและวางใช้ได้เลย

บน Mac คุณมี Cmd + C ใช้ได้ทุกที่ บน Windows คุณมี Ctrl + C ใช้ได้ทุกที่ — ยกเว้นในเทอร์มินัล ที่มันจะฆ่าโปรแกรมของคุณ Omarchy ให้ `Super + C`, `Super + X` และ `Super + V` แก่คุณ และมันใช้ได้ทุกที่ รวมถึงในเทอร์มินัลด้วย ไม่ต้องเรียนรู้รีเฟล็กซ์แยกต่างหากสำหรับ shell

ชาว Windows ทั้งหลาย: ประวัติ clipboard Win + V ของคุณจะอยู่บน `Super + Ctrl + V` และมันเก็บรูปภาพได้เช่นเดียวกับข้อความ ดู [คลิปบอร์ดและประวัติแบบรวมศูนย์](08-unified-clipboard-history.md)

### บางสิ่งต่างออกไปจริง ๆ

การตั้งค่าจำนวนมากอยู่ในไฟล์ข้อความที่คุณแก้ไขเอง ไม่ใช่ในแผงต่าง ๆ ที่คุณคลิกผ่านไปเรื่อย ๆ ฟังดูดั้งเดิม จนกว่าคุณจะตระหนักว่ามันหมายความว่าทุกการปรับแต่งสามารถมองเห็นได้ คัดลอกไปยังเครื่องถัดไปของคุณได้ และใส่ไว้ใน version control ได้ เมนู _Setup_ จะพาคุณตรงไปยังไฟล์ที่ถูกต้อง และรีสตาร์ทสิ่งที่ต้องรีสตาร์ทให้เมื่อคุณเสร็จแล้ว

การอัปเดตมาผ่านคำสั่งเดียว — _Update > Omarchy_ — ซึ่งอัปเดต Omarchy เองและทุกแพ็กเกจบนระบบ โดยถ่าย snapshot ก่อน ไม่มีตัวอัปเดตแยกตามแอปมาคอยกวนใจคุณแบบสุ่ม ๆ ดู [การอัปเดต](30-updates.md)

ซอฟต์แวร์มาจาก package manager ไม่ใช่จากตัวติดตั้งที่ดาวน์โหลดมา

และเมื่อคุณปิดหน้าต่าง แอปจะออกจริง ๆ ไม่มีภาวะค้างคาแบบ macOS ที่โปรแกรมยังทำงานต่อไปโดยไม่มีหน้าต่าง `Super + W` — หรือ `Super + Q` ถ้านั่นคือความจำของนิ้วที่คุณติดตัวมา — หมายความว่าหายไปเลย

### บนฮาร์ดแวร์ Mac

Omarchy ทำงานได้ดีบน Intel Macs และบน Macs ที่ใช้ M1, M2 และ M3 ด้วย Omarchy for Apple Silicon ดู [การรองรับ Mac](44-mac-support.md) และคีย์บอร์ดก็ใจดีกับคุณ: Omarchy ไม่ได้ remap อะไรเลย และ Linux ถือว่าปุ่ม Command คือ Super ดังนั้น Super จึงอยู่ตรงตำแหน่งที่ Cmd เคยอยู่มาตลอด นิ้วโป้งของคุณจะไม่รู้สึกถึงการย้ายที่เลย

### ให้เวลามันสองสัปดาห์

สัญชาตญาณจะถ่ายโอนเร็วกว่าที่คุณคิด อ่านบท [คีย์ลัด](07-hotkeys.md) แบบผ่าน ๆ สักครั้ง และเมื่อใดก็ตามที่คุณนึก binding ไม่ออก ให้กด `Super + K` — มันจะแสดงทั้งหมดให้คุณเห็น นั่นคือคีย์ลัดเดียวที่คุณต้องจำจริง ๆ
