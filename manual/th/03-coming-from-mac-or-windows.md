# มาจาก Mac หรือ Windows

หากคุณใช้ macOS หรือ Windows มาหลายปี นิ้วของคุณจะจดจำสิ่งต่าง ๆ นับร้อยอย่างที่สมองของคุณลืมไปแล้วว่าเคยเรียนรู้มา บทนี้คือชั้นแปลความ: สัญชาตญาณเหล่านั้นจะไปที่ไหนใน Omarchy คุณสมบัติต่าง ๆ เองมีอธิบายเชิงลึกไว้ที่อื่นแล้ว — ที่นี่เป็นเพียงแผนที่เท่านั้น

### Super คือศูนย์กลางของทุกสิ่ง

ความจำของกล้ามเนื้อทั้งหมดที่คุณสร้างไว้รอบ ๆ Cmd หรือปุ่ม Windows จะย้ายมาอยู่ที่ปุ่มเดียว: Super นั่นคือปุ่ม Windows บนคีย์บอร์ด PC และมันคือจุดยึดของปุ่มลัดเกือบทุกปุ่มใน Omarchy

ปฏิกิริยาตอบสนองแบบ Spotlight หรือ Raycast หรือเมนู Start ของคุณจะกลายเป็น `Super + Space` นั่นจะเปิดเมนู Omarchy ซึ่งใช้เปิดแอป เปลี่ยนการตั้งค่า ติดตั้งซอฟต์แวร์ จับภาพหน้าจอ — แทบทุกอย่าง เริ่มพิมพ์เพื่อกรองรายการ `Super + Alt + Space` จะแสดงทุกแอปบนตารางเดียว แบบเดียวกับที่ Launchpad ทำ ดู [การนำทาง](04-navigation.md)

### ไม่มีไอคอนบนเดสก์ท็อป และ dock จะแสดงเฉพาะเมื่อคุณ float เท่านั้น

ไม่มีไอคอนให้จัดเรียงบนเดสก์ท็อป และไม่มี dock บน workspace แบบ tiling — dock จะปรากฏเฉพาะบน workspace แบบ floating เท่านั้น (ดู [การนำทาง](04-navigation.md)) แอปต่าง ๆ เริ่มทำงานจากปุ่มลัด (`Super + Return` สำหรับ terminal, `Super + Shift + Return` สำหรับเบราว์เซอร์ และ `Super + K` สำหรับรายการของทุกอย่างที่ถูกแมปไว้) หรือจากเมนู ชิ้นส่วน UI เดียวที่อยู่ถาวรคือ [แถบด้านบน](05-the-top-bar.md) ซึ่งครอบคลุมสิ่งที่แถบเมนู ถาดระบบ และ Notification Center เคยทำให้คุณมาก่อน — และวิดเจ็ตเกือบทุกตัวบนนั้นจะทำบางอย่างเมื่อคลิกซ้าย คลิกขวา และคลิกกลาง

### หน้าต่างจัดวางตัวเอง

การเปลี่ยนกรอบความคิดที่ใหญ่ที่สุด: คุณไม่ต้องลากหน้าต่างไปรอบ ๆ หรือ snap มันไปยังครึ่งหน้าจอ เปิดหน้าต่างหนึ่งขึ้นมา มันจะใช้พื้นที่ทั้งหน้าจอ เปิดหน้าต่างที่สอง พวกมันจะแบ่งหน้าจอกัน คุณไม่ต้องควานหาหน้าต่างจากใต้หน้าต่างอื่นเลย เพราะหน้าต่างไม่ซ้อนทับกัน

เมื่อคุณต้องการหน้าต่างแบบ floating จริง ๆ `Super + T` จะสลับหน้าต่างที่ใช้งานอยู่ออกจาก tiling (และกลับเข้าไป) แต่ขอให้ลองใช้ tiling อย่างจริงจังก่อน — มันคือหัวใจของทุกสิ่ง [การนำทาง](04-navigation.md) จะพาคุณไปทำความรู้จักกับมัน

Workspaces จะรู้สึกคุ้นเคย: มันคือ Spaces ของ macOS หรือเดสก์ท็อปเสมือนของ Windows เพียงแต่คุณจะได้ใช้มันจริง ๆ เพราะ `Super + 1/2/3/4` จะกระโดดตรงไปยัง workspace นั้น และ `Super + Shift + 1/2/3/4` จะส่งหน้าต่างที่ใช้งานอยู่ไปที่นั่น ไม่มีความหน่วงจากแอนิเมชัน มีแค่การกระโดดทันที ซึ่งหมายความว่าคุณอาจไม่จำเป็นต้องใช้หลายจอภาพเลยด้วยซ้ำ หากคุณเคยชินกับแบบนั้นมาก่อน

### คัดลอกและวางใช้งานได้เลย

บน Mac คุณมี Cmd + C อยู่ทุกที่ บน Windows คุณมี Ctrl + C อยู่ทุกที่ — ยกเว้น terminal ที่มันจะฆ่าโปรแกรมของคุณ Omarchy ให้ `Super + C`, `Super + X` และ `Super + V` แก่คุณ และพวกมันใช้งานได้ทุกที่ รวมถึงใน terminal ด้วย ไม่ต้องเรียนรู้ปฏิกิริยาตอบสนองแยกต่างหากสำหรับ shell

ชาว Windows: ประวัติคลิปบอร์ด Win + V ของคุณอยู่บน `Super + Ctrl + V` และมันเก็บรูปภาพไว้เช่นเดียวกับข้อความ ดู [คลิปบอร์ดและประวัติแบบรวมศูนย์](08-unified-clipboard-history.md)

### บางสิ่งแตกต่างออกไปจริง ๆ

การตั้งค่าจำนวนมากอาศัยอยู่ในไฟล์ข้อความที่คุณแก้ไข ไม่ใช่แผงต่าง ๆ ที่คุณคลิกผ่าน นั่นฟังดูดั้งเดิม จนกว่าคุณจะตระหนักว่ามันหมายความว่าทุกการปรับแต่งสามารถมองเห็นได้ คัดลอกไปยังเครื่องถัดไปของคุณได้ และนำไปไว้ใน version control ได้ เมนู _Setup_ จะพาคุณตรงไปยังไฟล์ที่ถูกต้อง และรีสตาร์ทอะไรก็ตามที่จำเป็นต้องรีสตาร์ทเมื่อคุณเสร็จ

การอัปเดตมาผ่านคำสั่งเดียว — _Update > Omarchy_ — ซึ่งอัปเดต Omarchy เองและทุกแพ็กเกจบนระบบ โดยสร้าง snapshot ก่อน ไม่มีตัวอัปเดตแยกตามแอปมาคอยกวนใจคุณในเวลาสุ่ม ๆ ดู [การอัปเดต](30-updates.md)

ซอฟต์แวร์มาจาก package manager ไม่ใช่จากตัวติดตั้งที่ดาวน์โหลดมา

และเมื่อคุณปิดหน้าต่าง แอปจะปิดตัวลงจริง ๆ ไม่มีภาวะค้างคาแบบ macOS ที่โปรแกรมยังทำงานต่อไปโดยไม่มีหน้าต่าง `Super + W` — หรือ `Super + Q` หากนั่นคือความจำของนิ้วที่คุณติดตัวมา — หมายความว่าหายไปเลย

### บนฮาร์ดแวร์ Mac

Omarchy ทำงานได้ดีบน Intel Macs และบน Macs รุ่น M1, M2 และ M3 ด้วย Omarchy for Apple Silicon ดู [การรองรับ Mac](44-mac-support.md) และคีย์บอร์ดก็เป็นมิตรกับคุณ: Omarchy ไม่ได้ remap อะไรเลย และ Linux ถือว่าปุ่ม Command คือ Super ดังนั้น Super จึงอยู่ตรงตำแหน่งที่ Cmd เคยอยู่มาตลอด นิ้วหัวแม่มือของคุณจะไม่ทันสังเกตการย้ายครั้งนี้เลย

### ให้เวลามันสองสัปดาห์

สัญชาตญาณจะถ่ายโอนมาเร็วกว่าที่คุณคิด อ่านบท [ปุ่มลัด](07-hotkeys.md) ผ่าน ๆ สักครั้ง และเมื่อใดก็ตามที่คุณนึกปุ่มลัดไม่ออก ให้กด `Super + K` — มันจะแสดงปุ่มลัดทั้งหมดให้คุณดู นั่นคือปุ่มลัดเดียวที่คุณต้องจำจริง ๆ
