# มาจาก Mac หรือ Windows

หากคุณใช้ macOS หรือ Windows มาหลายปี นิ้วของคุณรู้เป็นร้อยอย่างที่สมองของคุณลืมไปแล้วว่าเคยเรียนรู้ บทนี้คือชั้นแปลภาษา: สัญชาตญาณเหล่านั้นไปอยู่ที่ไหนใน Omarchy ตัวฟีเจอร์เองมีอธิบายเชิงลึกไว้ที่อื่นแล้ว — นี่เป็นแค่แผนที่

### Super คือศูนย์กลางของทุกสิ่ง

ความจำของกล้ามเนื้อทั้งหมดที่คุณสร้างมารอบ ๆ Cmd หรือปุ่ม Windows จะถ่ายโอนไปยังปุ่มเดียว: Super นั่นคือปุ่ม Windows บนคีย์บอร์ด PC และมันคือจุดยึดของแทบทุกคีย์ลัดใน Omarchy

ปฏิกิริยาตอบสนองแบบ Spotlight หรือ Raycast หรือเมนู Start ของคุณจะกลายเป็น `Super + Space` นั่นจะเปิดเมนู Omarchy ซึ่งใช้เปิดแอป เปลี่ยนการตั้งค่า ติดตั้งซอฟต์แวร์ จับภาพหน้าจอ — แทบทุกอย่าง เริ่มพิมพ์เพื่อกรอง `Super + Alt + Space` จะแสดงทุกแอปบนตารางเดียว แบบเดียวกับที่ Launchpad ทำ ดู [การนำทาง](04-navigation.md)

### ไม่มีไอคอนบนเดสก์ท็อป และ dock จะโผล่มาเฉพาะตอนที่คุณลอยหน้าต่าง

ไม่มีไอคอนให้จัดเรียงบนเดสก์ท็อป และไม่มี dock บนพื้นที่ทำงานแบบเรียงหน้าต่าง — dock จะปรากฏเฉพาะบนพื้นที่ทำงานแบบลอยเท่านั้น (ดู [การนำทาง](04-navigation.md)) แอปเริ่มทำงานจากคีย์ลัด (`Super + Return` สำหรับ terminal, `Super + Shift + Return` สำหรับเบราว์เซอร์ และ `Super + K` สำหรับรายการของทุกอย่างที่ผูกไว้) หรือจากเมนู ชิ้นส่วน UI ชิ้นเดียวที่คงอยู่ตลอดคือ [แถบด้านบน](05-the-top-bar.md) ซึ่งครอบคลุมสิ่งที่แถบเมนู ถาดระบบ และ Notification Center เคยทำให้คุณมาก่อน — และแทบทุกวิดเจ็ตบนนั้นทำอะไรบางอย่างเมื่อคลิกซ้าย คลิกขวา และคลิกกลาง

### หน้าต่างจัดวางตัวเอง

การเปลี่ยนวิธีคิดที่ใหญ่ที่สุด: คุณไม่ต้องลากหน้าต่างไปรอบ ๆ หรือจับมันชิดครึ่งหน้าจอ เปิดหน้าต่างหนึ่งแล้วมันจะกินทั้งหน้าจอ เปิดหน้าต่างที่สองแล้วพวกมันจะแบ่งหน้าจอกัน คุณไม่ต้องควานหาหน้าต่างจากใต้หน้าต่างอื่นเลย เพราะหน้าต่างไม่ทับซ้อนกัน

เมื่อคุณต้องการหน้าต่างแบบลอยจริง ๆ `Super + T` จะสลับหน้าต่างที่ใช้งานอยู่ออกจากการเรียงหน้าต่าง (และกลับเข้าไป) แต่ให้โอกาสการเรียงหน้าต่างอย่างจริงจังก่อน — มันคือหัวใจของทุกอย่าง [การนำทาง](04-navigation.md) จะพาคุณผ่านมันไป

พื้นที่ทำงานจะให้ความรู้สึกคุ้นเคย: พวกมันคือ Spaces ของ macOS หรือเดสก์ท็อปเสมือนของ Windows เพียงแต่คุณจะได้ใช้มันจริง ๆ เพราะ `Super + 1/2/3/4` จะกระโดดตรงไปยังพื้นที่ทำงานนั้น และ `Super + Shift + 1/2/3/4` จะส่งหน้าต่างที่ใช้งานอยู่ไปที่นั่น ไม่มีความหน่วงของแอนิเมชัน มีแค่การกระโดดทันที นี่หมายความว่าคุณอาจไม่ต้องการจอภาพหลายจอด้วยซ้ำ หากคุณเคยชินกับแบบนั้นมาก่อน

### คัดลอกและวางใช้ได้เลย

บน Mac คุณมี Cmd + C อยู่ทุกที่ บน Windows คุณมี Ctrl + C อยู่ทุกที่ — ยกเว้น terminal ที่มันจะฆ่าโปรแกรมของคุณ Omarchy ให้ `Super + C`, `Super + X` และ `Super + V` แก่คุณ และพวกมันใช้ได้ทุกที่ รวมถึงใน terminal ด้วย ไม่ต้องเรียนรู้ปฏิกิริยาตอบสนองแยกต่างหากสำหรับ shell

ชาว Windows: ประวัติคลิปบอร์ด Win + V ของคุณอยู่บน `Super + Ctrl + V` และมันเก็บรูปภาพไว้ด้วยเช่นเดียวกับข้อความ ดู [คลิปบอร์ดและประวัติแบบรวมศูนย์](08-unified-clipboard-history.md)

### บางสิ่งต่างออกไปจริง ๆ

การตั้งค่าจำนวนมากอยู่ในไฟล์ข้อความที่คุณแก้ไข ไม่ใช่แผงที่คุณคลิกผ่าน นั่นฟังดูดั้งเดิมจนกว่าคุณจะตระหนักว่ามันหมายความว่าทุกการปรับแต่งสามารถมองเห็นได้ คัดลอกไปยังเครื่องถัดไปของคุณได้ และใส่ไว้ในการควบคุมเวอร์ชันได้ เมนู _Setup_ จะพาคุณตรงไปยังไฟล์ที่ถูกต้องและรีสตาร์ทอะไรก็ตามที่ต้องรีสตาร์ทเมื่อคุณทำเสร็จ

การอัปเดตมาผ่านคำสั่งเดียว — _Update > Omarchy_ — ซึ่งอัปเดต Omarchy เองและทุกแพ็กเกจบนระบบ โดยถ่ายสแนปชอตก่อน ไม่มีตัวอัปเดตแยกตามแอปมาคอยกวนใจคุณแบบสุ่ม ๆ ดู [การอัปเดต](30-updates.md)

ซอฟต์แวร์มาจากตัวจัดการแพ็กเกจ ไม่ใช่จากตัวติดตั้งที่ดาวน์โหลดมา

และเมื่อคุณปิดหน้าต่าง แอปจะออกจริง ๆ ไม่มีภาวะค้างคาแบบ macOS ที่โปรแกรมยังทำงานต่อไปโดยไม่มีหน้าต่าง `Super + W` — หรือ `Super + Q` หากนั่นคือความจำของนิ้วที่คุณติดตัวมา — หมายความว่าหายไปเลย

### บนฮาร์ดแวร์ Mac

Omarchy ทำงานได้ดีบน Intel Macs — ดู [การรองรับ Mac](44-mac-support.md) และคีย์บอร์ดก็ใจดีกับคุณ: Omarchy ไม่ได้แมปอะไรใหม่ และ Linux ถือว่าปุ่ม Command คือ Super ดังนั้น Super จึงอยู่ตรงตำแหน่งที่ Cmd เคยอยู่เสมอ นิ้วหัวแม่มือของคุณจะไม่ทันสังเกตการย้ายนี้เลย

### ให้เวลามันสองสัปดาห์

สัญชาตญาณถ่ายโอนเร็วกว่าที่คุณคิด อ่านบท [คีย์ลัด](07-hotkeys.md) ผ่าน ๆ สักครั้ง และเมื่อใดก็ตามที่คุณนึกการผูกปุ่มไม่ออก ให้กด `Super + K` — มันจะแสดงทั้งหมดให้คุณเห็น นั่นคือคีย์ลัดเดียวที่คุณต้องจำจริง ๆ
