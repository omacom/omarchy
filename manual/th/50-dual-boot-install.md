# การติดตั้งแบบ Dual Boot

คุณสามารถติดตั้ง Omarchy ลงในพาร์ติชันเดียวควบคู่ไปกับ Windows หรือการติดตั้งอื่น ๆ ได้

วิธีการติดตั้งนี้ยังคงมาพร้อมกับการเข้ารหัส LUKS สำหรับพาร์ติชันเป็นค่าเริ่มต้น ดังนั้นโดยพื้นฐานแล้วจึงไม่ต่างจากการติดตั้งแบบเต็มไดรฟ์ และเพียงต้องการพื้นที่ว่างบนดิสก์เท่านั้น

## การสร้างพื้นที่ว่างบน Windows

หากต้องการติดตั้งควบคู่ไปกับ Windows ให้พิมพ์ `disk management` ในเมนู Start แล้วเลือกตัวเลือก **Create and format hard disk partitions**

 ![dual-boot-1](images/dual-boot-1.webp)

ค้นหาพาร์ติชันที่เหมาะสม คลิกขวา แล้วเลือก **Shrink Volume**

![dual-boot-2](images/dual-boot-2.webp)

 ป้อนจำนวนพื้นที่ที่คุณต้องการลดขนาดโวลุ่มลง โปรดทราบว่านี่จะเป็นขนาดของการติดตั้ง Omarchy ในอนาคตของคุณ รวมพาร์ติชันสำหรับบูตด้วย

 ![dual-boot-3](images/dual-boot-3.webp)

เมื่อเสร็จแล้ว คุณจะเห็นบางอย่างลักษณะนี้ โดยส่วนขนาด 50GB คือตำแหน่งที่เราจะติดตั้ง Omarchy ในตัวอย่างนี้

 ![dual-boot-4](images/dual-boot-4.webp)

## การติดตั้ง Omarchy

ขั้นตอนการติดตั้ง Omarchy โดยพื้นฐานแล้วเหมือนกับการติดตั้งปกติ หลังจากที่คุณเลือกดิสก์แล้ว คุณจะได้รับตัวเลือก **Free space install** ให้เลือกตัวเลือกนั้นเพื่อป้องกันการล้างข้อมูลทั้งดิสก์

 ![dual-boot-5](images/dual-boot-5.webp)

ยืนยันว่าทุกอย่างเรียบร้อยดี แล้วรอให้การติดตั้งเสร็จสิ้นตามปกติ นี่เป็นขั้นตอนที่คุณสามารถเลือกติดตั้งแบบไม่เข้ารหัสได้เช่นกัน (ไม่แนะนำ) เหมือนกับการติดตั้งแบบเต็มไดรฟ์
 ![dual-boot-6](images/dual-boot-6.webp)

## การเพิ่มการติดตั้งอื่น ๆ ลงใน Bootloader

เมื่อคุณติดตั้ง Omarchy เสร็จ คุณจะสังเกตเห็นว่าตอนนี้ bootloader ของ Limine เป็นค่าเริ่มต้นแล้ว ด้วยสิ่งนี้ คุณยังสามารถเพิ่มตัวเลือกใน Limine สำหรับการติดตั้งอื่น ๆ ของคุณ เช่น Windows ได้อีกด้วย

หากต้องการเพิ่มระบบปฏิบัติการอื่น ๆ ให้รัน `limine-scan` แล้วทำตามคำแนะนำเพื่อเพิ่มรายการที่คุณต้องการลงในการกำหนดค่าของ Limine เมนูบูตจะถูกซ่อนไว้เป็นค่าเริ่มต้น และจะเริ่ม Omarchy หลังจากหนึ่งวินาที หากต้องการเลือก Windows หรือรายการอื่น ให้กดปุ่มใด ๆ ทันทีที่ Limine เริ่มทำงาน เมื่อเมนูปรากฏขึ้น ให้ใช้ปุ่มลูกศรเพื่อเลือกรายการแล้วกด Enter หาก Omarchy เริ่มทำงานก่อนที่คุณจะกดปุ่ม ให้รีสตาร์ทแล้วลองอีกครั้ง

## Bitlocker

สิ่งสำคัญที่ต้องทราบคือวิธีการติดตั้งนี้ไม่สามารถใช้งานร่วมกับ Bitlocker ได้ เนื่องจากมันเข้ารหัสทั้งไดรฟ์ ไม่ใช่แค่พาร์ติชัน หากคุณพบข้อผิดพลาดที่ระบุว่า Bitlocker เปิดใช้งานอยู่ ให้บูตเข้าสู่ Windows ไปที่ **Settings -> Privacy & Security -> Device encryption** แล้วปิด Bitlocker อาจใช้เวลาสักพักในการถอดรหัสไดรฟ์

 ![dual-boot-7](images/dual-boot-7.webp)

## การติดตั้ง Windows ใหม่

หากคอมพิวเตอร์เครื่องนี้มาพร้อมกับ Windows คีย์ผลิตภัณฑ์ของ Windows จะถูกจัดเก็บไว้ใน firmware ให้รัน `omarchy windows key` เพื่อพิมพ์คีย์นั้นออกมา เพื่อที่คุณจะสามารถเปิดใช้งาน Windows ได้อีกครั้งหากคุณติดตั้ง Windows ใหม่บนเครื่องนี้
