# การติดตั้งแบบ Dual Boot

คุณสามารถติดตั้ง Omarchy ลงในพาร์ติชันเดียวควบคู่ไปกับ Windows หรือระบบอื่นที่ติดตั้งไว้ได้

วิธีการติดตั้งแบบนี้ยังคงมาพร้อมกับการเข้ารหัส LUKS สำหรับพาร์ติชันเป็นค่าเริ่มต้น ดังนั้นโดยพื้นฐานแล้วจึงไม่ต่างจากการติดตั้งแบบเต็มไดรฟ์ และเพียงต้องการพื้นที่ว่างบนดิสก์เท่านั้น

## การเตรียมพื้นที่บน Windows

หากต้องการติดตั้งควบคู่กับ Windows ให้พิมพ์ `disk management` ในเมนู Start แล้วเลือกตัวเลือก **Create and format hard disk partitions**

 ![dual-boot-1](images/dual-boot-1.webp)

ค้นหาพาร์ติชันที่เหมาะสม คลิกขวา แล้วเลือก **Shrink Volume**

![dual-boot-2](images/dual-boot-2.webp)

 ป้อนจำนวนพื้นที่ที่คุณต้องการลดขนาดโวลุ่มลง โปรดทราบว่านี่จะเป็นขนาดของการติดตั้ง Omarchy ในอนาคตของคุณ รวมพาร์ติชันสำหรับบูตด้วย

 ![dual-boot-3](images/dual-boot-3.webp)

เมื่อเสร็จแล้ว คุณควรเห็นลักษณะประมาณนี้ โดยส่วนขนาด 50GB คือตำแหน่งที่เราจะติดตั้ง Omarchy ในตัวอย่างนี้

 ![dual-boot-4](images/dual-boot-4.webp)

## การติดตั้ง Omarchy

ขั้นตอนการติดตั้ง Omarchy โดยพื้นฐานแล้วเหมือนกับการติดตั้งปกติ หลังจากคุณเลือกดิสก์แล้ว คุณจะเห็นตัวเลือก **Free space install** ให้เลือกตัวเลือกนั้นเพื่อป้องกันการล้างดิสก์ทั้งหมด

 ![dual-boot-5](images/dual-boot-5.webp)

ตรวจสอบว่าทุกอย่างถูกต้องแล้วรอให้การติดตั้งเสร็จสิ้นตามปกติ ตรงนี้คุณยังสามารถเลือกติดตั้งแบบไม่เข้ารหัสได้เช่นกัน (ไม่แนะนำ) เช่นเดียวกับการติดตั้งแบบเต็มไดรฟ์
 ![dual-boot-6](images/dual-boot-6.webp)

## การเพิ่มระบบอื่นที่ติดตั้งไว้ไปยัง Bootloader

เมื่อติดตั้ง Omarchy เสร็จแล้ว คุณจะสังเกตเห็นว่า Limine bootloader เป็นค่าเริ่มต้นแล้ว ด้วยสิ่งนี้ คุณยังสามารถเพิ่มตัวเลือกให้กับ Limine สำหรับระบบอื่นที่คุณติดตั้งไว้ เช่น Windows ได้อีกด้วย

หากต้องการเพิ่มระบบปฏิบัติการอื่น ให้รัน `limine-scan` แล้วทำตามข้อความแจ้งเพื่อเพิ่มรายการที่คุณต้องการลงในไฟล์กำหนดค่าของ Limine เมนูบูตจะถูกซ่อนไว้เป็นค่าเริ่มต้น และจะเริ่ม Omarchy หลังจากหนึ่งวินาที หากต้องการเลือก Windows หรือรายการอื่น ให้กดปุ่มใดก็ได้ทันทีที่ Limine เริ่มทำงาน เมื่อเมนูปรากฏขึ้น ให้ใช้ปุ่มลูกศรเพื่อเลือกรายการแล้วกด Enter หาก Omarchy เริ่มทำงานก่อนที่คุณจะกดปุ่ม ให้รีสตาร์ทแล้วลองอีกครั้ง

## Bitlocker

สิ่งสำคัญที่ต้องทราบคือวิธีการติดตั้งแบบนี้ไม่สามารถใช้งานร่วมกับ Bitlocker ได้ เนื่องจาก Bitlocker เข้ารหัสทั้งไดรฟ์ ไม่ใช่แค่พาร์ติชัน หากคุณพบข้อผิดพลาดที่ระบุว่า Bitlocker เปิดใช้งานอยู่ ให้บูตเข้าสู่ Windows ไปที่ **Settings -> Privacy & Security -> Device encryption** แล้วปิด Bitlocker การถอดรหัสไดรฟ์อาจใช้เวลาสักครู่
