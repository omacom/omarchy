# การรองรับ Mac

## Omarchy for Apple Silicon

Omarchy for Apple Silicon เป็นโซลูชันอย่างเป็นทางการของ Omacom เปิดตัวครั้งแรกพร้อมกับ Omarchy 4.5 โดยจะติดตั้งควบคู่ไปกับ macOS และคุณสามารถเลือกระหว่างทั้งสองระบบได้เมื่อ Mac ของคุณเริ่มทำงาน

ได้รับแจ้งเกี่ยวกับ Omarchy Mac ใช่ไหม ไปที่ [มาจาก Omarchy Mac](#coming-from-omarchy-mac)

ใช้งานได้บน Mac เหล่านี้:

| Mac | ชิป |
| --- | --- |
| MacBook Air | M1, M2, M3 |
| MacBook Pro | M1, M1 Pro, M1 Max, M2, M2 Pro, M2 Max, M3, M3 Pro, M3 Max |
| MacBook Neo | A18 Pro |
| Mac mini | M1, M2, M2 Pro |
| Mac Studio | M1 Max, M1 Ultra, M2 Max, M2 Ultra |
| iMac | M1, M3 |
| Mac Pro | M2 Ultra |

Mac รุ่น M4 และใหม่กว่ายังไม่ได้รับการรองรับในขณะนี้ การรองรับ M4 กำลังอยู่ระหว่างการทดสอบบน edge channel และจะตามมาเป็นลำดับถัดไป โปรแกรมติดตั้งจะตรวจสอบ Mac ของคุณก่อนที่จะเปลี่ยนแปลงสิ่งใด

บน Mac ที่ใช้ Apple Silicon ทุกรุ่น รวมถึง M4 และใหม่กว่า คุณสามารถเรียกใช้ Omarchy ในเครื่องเสมือนด้วย [Try Omarchy](https://github.com/omacom/try-omarchy) ได้

### สิ่งที่คุณต้องมี

- macOS 15 Sequoia หรือใหม่กว่า และบัญชีผู้ดูแลระบบ
- พื้นที่ว่างบนดิสก์สำหรับ Omarchy โปรแกรมติดตั้งจะแนะนำขนาดและให้คุณเปลี่ยนแปลงได้
- ข้อมูลสำรองของ Mac ของคุณ แหล่งจ่ายไฟ และการเชื่อมต่ออินเทอร์เน็ต การติดตั้งจะดาวน์โหลดข้อมูลหลายกิกะไบต์

### การติดตั้ง

คุณติดตั้งจาก macOS ติดตั้ง Omarchy Installer ด้วย [Homebrew](https://brew.sh):

```sh
brew install omacom/mac/omarchy
```

หรือดาวน์โหลด Omarchy Installer รุ่นล่าสุดจาก [หน้า releases](https://github.com/omacom/omarchy-mac-installer/releases) แล้วเปิดขึ้นมา

โปรแกรมติดตั้งจะตรวจสอบ Mac ของคุณ แสดงแผนให้คุณดู และสร้างพื้นที่สำหรับ Omarchy โดยการย่อพาร์ติชันของ macOS โดย macOS จะยังคงอยู่บนดิสก์ และไม่จำเป็นต้องใช้ไดรฟ์ USB เมื่อขั้นตอนแรกเสร็จสิ้น โปรแกรมจะแนะนำให้คุณทำการตั้งค่าให้เสร็จสมบูรณ์ใน macOS Recovery: ปิดเครื่อง กดปุ่มเปิด/ปิดค้างไว้จนกว่าข้อความ "Loading startup options" จะปรากฏขึ้น เลือก Omarchy แล้วทำตามขั้นตอน

ในการบูตครั้งแรก Omarchy จะขอรหัสผ่านที่ใช้เข้ารหัสดิสก์ของมัน โดยไม่มีคีย์กู้คืน: หากคุณลืมรหัสผ่าน ไฟล์ Omarchy ของคุณจะไม่สามารถกู้คืนได้

หากต้องการสลับระหว่าง Omarchy และ macOS ในภายหลัง ให้ปิดเครื่อง จากนั้นกดปุ่มเปิด/ปิดค้างไว้จนกว่าตัวเลือกการเริ่มต้นจะปรากฏขึ้น แล้วเลือกตัวเลือกที่ต้องการ

### มาจาก Omarchy Mac

ขณะนี้ Omarchy Mac เป็นส่วนหนึ่งของ Omarchy for Apple Silicon และ Mac ทุกเครื่องที่เคยใช้งานจะได้รับการรองรับ การติดตั้งปัจจุบันของคุณจะยังคงทำงานต่อไป และแพ็กเกจระบบของมันจะยังคงอัปเดต แต่จะไม่ได้รับการอัปเดต Omarchy อีกต่อไป โดยไม่มีกำหนดเส้นตายและไม่มีการอัปเกรดแบบ in-place: คุณต้องสำรองข้อมูล ลบการติดตั้งเก่า ติดตั้งใหม่ และกู้คืนข้อมูล ขั้นตอนที่ 2 ถึง 5 เกิดขึ้นใน macOS ดังนั้นให้เปิดหน้านี้บนโทรศัพท์ของคุณก่อนที่จะรีสตาร์ท

1. **สำรองข้อมูลจาก Omarchy ออกนอก Mac** การลบการติดตั้งเก่าจะลบข้อมูลทั้งหมด และ macOS ไม่สามารถอ่านดิสก์ของ Omarchy ได้ คัดลอกโฟลเดอร์ home ของคุณไปยังไดรฟ์ภายนอกหรือคอมพิวเตอร์เครื่องอื่น รวมถึงคีย์ SSH และ GPG โปรไฟล์เบราว์เซอร์ และงานที่ยังไม่ได้ push บันทึกรายการแพ็กเกจของคุณด้วย `pacman -Qqe > ~/packages.txt` สำรองข้อมูล macOS ด้วยเช่นกัน เนื่องจากทั้งการลบและการติดตั้งต่างก็ปรับขนาดดิสก์ของมัน
2. **เริ่ม Mac ของคุณใน macOS** ปิดเครื่อง กดปุ่มเปิด/ปิดค้างไว้จนกว่าตัวเลือกการเริ่มต้นจะปรากฏขึ้น แล้วเลือก macOS
3. **ติดตั้ง Omarchy Installer** ตามที่แสดงใน [การติดตั้ง](#installing)
4. **ลบการติดตั้งเก่า** เปิด Omarchy Installer แล้วเลือก Installation > Remove Omarchy มันจะแสดงสิ่งที่จะลบและคืนพื้นที่ให้กับ macOS หากมันไม่รู้จักการติดตั้งของคุณ มันจะหยุดโดยไม่เปลี่ยนแปลงดิสก์ ขอความช่วยเหลือใน [Discord](https://discord.gg/tXFUdasqhY) แทนที่จะลบพาร์ติชันด้วยตนเอง ซึ่งอาจลบ macOS ได้
5. **ติดตั้ง Omarchy for Apple Silicon** ด้วยโปรแกรมติดตั้ง
6. **กู้คืนไฟล์ของคุณ** นำการตั้งค่าของคุณกลับมาทีละส่วน แทนที่จะคัดลอก `~/.config` ทั้งหมดทับค่าเริ่มต้นใหม่ เนื่องจากการตั้งค่าเก่าอาจเขียนทับค่าเหล่านั้นได้

### ข้อควรรู้

- บน MacBook รุ่น M1 และ M2 ให้ปลุกจากโหมดพักเครื่องโดยการเปิดฝาหรือกดปุ่มเปิด/ปิด
- มีคำถามหรือปัญหา: สอบถามได้ใน [Discord](https://discord.gg/tXFUdasqhY) ของเรา

[README ของโปรแกรมติดตั้ง](https://github.com/omacom/omarchy-mac-installer#readme) ครอบคลุมเรื่อง release channels การอัปเดตโปรแกรมติดตั้ง และการลบ Omarchy

## Mac ที่ใช้ Intel

ในการทดสอบอย่างง่าย เราสามารถเพิ่มประสิทธิภาพได้ถึง 36% บน MacBook Pro รุ่นปี 2019 เพียงแค่ติดตั้ง Omarchy

 ![macbook-omarchy](images/macbook-omarchy.webp)

### การติดตั้ง Omarchy บน Mac

Omarchy รองรับเฉพาะการเป็นระบบปฏิบัติการ **เพียงระบบเดียว** ที่ติดตั้งอยู่ในขณะนี้เท่านั้น ในระหว่างการติดตั้ง ไดรฟ์จะถูกล้างข้อมูลและ MacOS จะไม่สามารถบูตได้อีกต่อไป

คุณยังคงสามารถกู้คืนได้ในภายหลังผ่าน Internet Recovery หากต้องการ

สำหรับส่วนนี้ เราจะถือว่าคุณได้อ่าน [เริ่มต้นใช้งาน](02-getting-started.md) แล้วและมีไดรฟ์ USB พร้อมใช้งาน หากยังไม่ได้ทำ ให้ไปทำตอนนี้เลย

#### ปิด Secure Boot

จำเป็นต้องปิด Secure Boot ของ Apple เพื่อบูตจาก USB ที่บูตได้ รวมถึงระบบปฏิบัติการ หากต้องการปิด ให้ทำตามขั้นตอนต่อไปนี้:

1. ปิด Mac ของคุณ
2. เปิดเครื่องและกด Command-R ค้างไว้ _ทันที_ จนกว่าคุณจะเห็นหน้าจอการโหลดปรากฏขึ้น
3. เลือกผู้ใช้ของคุณและป้อนรหัสผ่านหากระบบแจ้ง
4. เมื่ออยู่ในหน้าจอการกู้คืน ให้เลือก **Utilities > Startup Security Utility** จากแถบเมนู
5. ป้อนรหัสผ่านของคุณเมื่อระบบแจ้งให้ยืนยันตัวตน
6. เลือก "No Security" จากตัวเลือก Secure Boot
7. เลือก "Allow booting from external or removable media" จากตัวเลือก External Boot

#### เริ่มการติดตั้ง

1. เสียบไดรฟ์ USB
2. รีสตาร์ท Mac ของคุณและกด Option ค้างไว้ _ทันที_ จนกว่าคุณจะเห็นหน้าจออุปกรณ์บูต
3. เลือกอุปกรณ์ EFI Boot สีส้ม
4. ดำเนินการ [ติดตั้งตามปกติ](02-getting-started.md) ต่อไป

โปรแกรมติดตั้งจะตรวจจับฮาร์ดแวร์ของ Mac และใช้การแก้ไขที่จำเป็นโดยอัตโนมัติ: ไดรเวอร์และเฟิร์มแวร์ Broadcom Wi-Fi ไดรเวอร์คีย์บอร์ด SPI บน MacBook รุ่นที่ต้องการ และการแก้ไขปัญหา NVMe suspend สำหรับรุ่นเดียวกันเหล่านั้น

### ข้อจำกัดที่ทราบ

สมาชิกในชุมชนกำลังทำงานอย่างต่อเนื่องเพื่อหาวิธีแก้ไขปัญหาเหล่านี้ ดังนั้นหากปัญหาเหล่านี้เป็นปัญหาสำหรับคุณ ให้เข้าร่วม #omarchy-on-other ใน [Discord](https://discord.gg/tXFUdasqhY) ของเรา และดูว่ามีวิธีการล่าสุดในการแก้ไขปัญหาเหล่านี้หรือไม่

#### อุปกรณ์ที่มีชิป T1

ชิป Apple T1 เปิดตัวในช่วงปลายปี 2016 และใช้เฉพาะใน MacBook Pro รุ่นแรกที่มี Touch Bar เท่านั้น
- MacBook Pro 13 นิ้ว (2016, พอร์ต Thunderbolt 3 สองพอร์ต) – รุ่น: A1706
- MacBook Pro 13 นิ้ว (2016, พอร์ต Thunderbolt 3 สี่พอร์ต) – รุ่น: A1708
- MacBook Pro 15 นิ้ว (2016) – รุ่น: A1707

#### ปัญหาที่ทราบ

- Touch Bar ไม่ทำงาน
- เสียงไม่ทำงาน

#### อุปกรณ์ที่มีชิป T2

ชิปความปลอดภัย Apple T2 เปิดตัวในปี 2017 ชิป T2 ถูกยกเลิกไปพร้อมกับการเปลี่ยนผ่านไปสู่ Apple silicon (ชิปซีรีส์ M) ซึ่งเริ่มต้นในปี 2020

- iMac Pro (2017) – รุ่น: A1862
- MacBook Pro 13 นิ้ว (2018, พอร์ต Thunderbolt 3 สี่พอร์ต) – รุ่น: A1989
- MacBook Pro 15 นิ้ว (2018) – รุ่น: A1990
- MacBook Air (Retina, 13 นิ้ว, 2018) – รุ่น: A1932
- Mac mini (2018) – รุ่น: A1998
- MacBook Pro 13 นิ้ว (2019, พอร์ต Thunderbolt 3 สองพอร์ต) – รุ่น: A2159
- MacBook Pro 13 นิ้ว (2019, พอร์ต Thunderbolt 3 สี่พอร์ต) – รุ่น: A2178
- MacBook Pro 15 นิ้ว (2019) – รุ่น: A1990
- iMac (Retina 5K, 27 นิ้ว, 2020) – รุ่น: A2115 (iMac20,1 และ iMac20,2)
- MacBook Pro 13 นิ้ว (2020, พอร์ต Thunderbolt 3 สองพอร์ต) – รุ่น: A2265
- MacBook Pro 15 นิ้ว (2020) – รุ่น: A1990

บนรุ่นเหล่านี้ โปรแกรมติดตั้งจะตั้งค่าเคอร์เนล `linux-t2` ที่แพตช์แล้ว การกำหนดค่าเสียง T2 เฟิร์มแวร์ Broadcom Wi-Fi/Bluetooth ของ Apple และการควบคุมพัดลมผ่าน `t2fanrd` โดยอัตโนมัติ Touch Bar ทำงานบนการรองรับสไตล์ Boot Camp ที่มีมาในเคอร์เนล

iMac ขนาด 27 นิ้ว รุ่นปี 2017 ไม่มีชิป T2 ดังนั้นโปรแกรมติดตั้งจะตั้งค่าเหมือนกับ Mac ที่ใช้ Intel รุ่นอื่นๆ
