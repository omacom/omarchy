# การรองรับ Mac

## Omarchy สำหรับ Apple Silicon

Omarchy สำหรับ Apple Silicon เป็นโซลูชันอย่างเป็นทางการของ Omacom เปิดตัวครั้งแรกพร้อมกับ Omarchy 4.5 มันติดตั้งอยู่ข้าง macOS และคุณเลือกว่าจะใช้ระบบใดเมื่อ Mac ของคุณเริ่มทำงาน

ได้รับข้อความแจ้งเกี่ยวกับ Omarchy Mac ใช่ไหม? ไปที่ [มาจาก Omarchy Mac](#coming-from-omarchy-mac)

มันทำงานบน Mac เหล่านี้:

| Mac | ชิป |
| --- | --- |
| MacBook Air | M1, M2, M3 |
| MacBook Pro | M1, M1 Pro, M1 Max, M2, M2 Pro, M2 Max, M3, M3 Pro, M3 Max |
| MacBook Neo | A18 Pro |
| Mac mini | M1, M2, M2 Pro |
| Mac Studio | M1 Max, M1 Ultra, M2 Max, M2 Ultra |
| iMac | M1, M3 |
| Mac Pro | M2 Ultra |

Mac รุ่น M4 และใหม่กว่ายังไม่ได้รับการรองรับ การรองรับ M4 กำลังทดสอบอยู่ในช่อง edge และจะตามมาเป็นลำดับถัดไป โปรแกรมติดตั้งจะตรวจสอบ Mac ของคุณก่อนที่จะเปลี่ยนแปลงอะไร

บน Mac ที่ใช้ Apple Silicon ทุกรุ่น รวมถึง M4 และใหม่กว่า คุณสามารถเรียกใช้ Omarchy ใน virtual machine ได้ด้วย [Try Omarchy](https://github.com/omacom/try-omarchy)

### สิ่งที่คุณต้องมี

- macOS 15 Sequoia หรือใหม่กว่า และบัญชีผู้ดูแลระบบ
- พื้นที่ว่างบนดิสก์สำหรับ Omarchy โปรแกรมติดตั้งจะแนะนำขนาดและให้คุณเปลี่ยนได้
- ข้อมูลสำรองของ Mac ของคุณ ไฟ และการเชื่อมต่ออินเทอร์เน็ต การติดตั้งจะดาวน์โหลดข้อมูลหลายกิกะไบต์

### การติดตั้ง

คุณติดตั้งจาก macOS ติดตั้ง Omarchy Installer ด้วย [Homebrew](https://brew.sh):

```sh
brew install omacom/mac/omarchy
```

หรือดาวน์โหลด Omarchy Installer รุ่นล่าสุดจาก [หน้า releases](https://github.com/omacom/omarchy-mac-installer/releases) ของมันแล้วเปิดขึ้นมา

โปรแกรมติดตั้งจะตรวจสอบ Mac ของคุณ แสดงแผนให้คุณดู และสร้างพื้นที่สำหรับ Omarchy โดยการย่อพาร์ติชันของ macOS macOS ยังคงอยู่บนดิสก์ และไม่จำเป็นต้องใช้ไดรฟ์ USB เมื่อขั้นตอนแรกเสร็จสิ้น มันจะแนะนำให้คุณทำการตั้งค่าให้เสร็จใน macOS Recovery: ปิดเครื่อง กดปุ่มเปิด/ปิดค้างไว้จนกระทั่ง "Loading startup options" ปรากฏขึ้น เลือก Omarchy แล้วทำตามขั้นตอน

เมื่อบูตครั้งแรก Omarchy จะขอรหัสผ่านที่ใช้เข้ารหัสดิสก์ของมัน ไม่มีคีย์กู้คืน: หากคุณลืมรหัสผ่าน ไฟล์ Omarchy ของคุณจะไม่สามารถกู้คืนได้

หากต้องการสลับระหว่าง Omarchy และ macOS ในภายหลัง ให้ปิดเครื่อง จากนั้นกดปุ่มเปิด/ปิดค้างไว้จนกระทั่งตัวเลือกการเริ่มต้นปรากฏขึ้น แล้วเลือกตัวเลือกที่ต้องการ

### มาจาก Omarchy Mac

ขณะนี้ Omarchy Mac เป็นส่วนหนึ่งของ Omarchy สำหรับ Apple Silicon และ Mac ทุกเครื่องที่เคยใช้มันได้รับการรองรับ การติดตั้งปัจจุบันของคุณจะยังคงทำงานต่อไป และแพ็กเกจระบบของมันยังคงอัปเดตได้ แต่จะไม่ได้รับการอัปเดต Omarchy อีกต่อไป ไม่มีกำหนดเวลาและไม่มีการอัปเกรดแบบ in-place: คุณต้องสำรองข้อมูล ลบการติดตั้งเก่าออก ติดตั้งใหม่ตั้งแต่ต้น แล้วกู้คืน ขั้นตอนที่ 2 ถึง 5 จะทำใน macOS ดังนั้นให้เปิดหน้านี้บนโทรศัพท์ของคุณก่อนรีสตาร์ท

1. **สำรองข้อมูลจาก Omarchy ออกนอก Mac** การลบการติดตั้งเก่าจะลบมันทิ้ง และ macOS ไม่สามารถอ่านดิสก์ของ Omarchy ได้ คัดลอกโฟลเดอร์ home ของคุณไปยังไดรฟ์ภายนอกหรือคอมพิวเตอร์เครื่องอื่น รวมถึงคีย์ SSH และ GPG โปรไฟล์เบราว์เซอร์ และงานที่ยังไม่ได้ push บันทึกรายการแพ็กเกจของคุณด้วย `pacman -Qqe > ~/packages.txt` สำรองข้อมูล macOS ด้วยเช่นกัน เนื่องจากทั้งการลบและการติดตั้งจะปรับขนาดดิสก์ของมัน
2. **เริ่ม Mac ของคุณใน macOS** ปิดเครื่อง กดปุ่มเปิด/ปิดค้างไว้จนกระทั่งตัวเลือกการเริ่มต้นปรากฏขึ้น แล้วเลือก macOS
3. **ติดตั้ง Omarchy Installer** ตามที่แสดงใน [การติดตั้ง](#installing)
4. **ลบการติดตั้งเก่าออก** เปิด Omarchy Installer แล้วเลือก Installation > Remove Omarchy มันจะแสดงสิ่งที่จะลบและคืนพื้นที่ให้กับ macOS หากมันจำการติดตั้งของคุณไม่ได้ มันจะหยุดโดยไม่เปลี่ยนดิสก์ ขอความช่วยเหลือใน [Discord](https://discord.gg/tXFUdasqhY) แทนที่จะลบพาร์ติชันด้วยมือ ซึ่งอาจลบ macOS ทิ้งได้
5. **ติดตั้ง Omarchy สำหรับ Apple Silicon** ด้วยโปรแกรมติดตั้ง
6. **กู้คืนไฟล์ของคุณ** นำการตั้งค่าของคุณกลับมาทีละส่วน แทนที่จะคัดลอก `~/.config` ทั้งหมดทับค่าเริ่มต้นใหม่ เนื่องจากการตั้งค่าเก่าอาจเขียนทับค่าเหล่านั้นได้

### สิ่งที่ควรรู้

- มีคำถามหรือปัญหา: ถามใน [Discord](https://discord.gg/tXFUdasqhY) ของเรา

## Mac ที่ใช้ Intel

ในการทดสอบง่าย ๆ เราสามารถเพิ่มประสิทธิภาพได้ 36% บน MacBook Pro ปี 2019 เพียงแค่ติดตั้ง Omarchy

 ![macbook-omarchy](images/macbook-omarchy.webp)

### การติดตั้ง Omarchy บน Mac

ขณะนี้ Omarchy รองรับการเป็นระบบปฏิบัติการ **เดียว** ที่ติดตั้งเท่านั้น ระหว่างการติดตั้ง ไดรฟ์จะถูกล้างและ MacOS จะไม่สามารถบูตได้อีกต่อไป

คุณยังสามารถกู้คืนมันในภายหลังผ่าน Internet Recovery ได้หากต้องการ

สำหรับส่วนนี้ เราจะถือว่าคุณได้อ่าน [เริ่มต้นใช้งาน](02-getting-started.md) แล้ว และมีไดรฟ์ USB พร้อมแล้ว หากยังไม่ได้ทำ ให้ไปทำตอนนี้เลย

#### ปิดใช้งาน Secure Boot

จำเป็นต้องปิดใช้งาน Secure Boot ของ Apple เพื่อบูต USB ที่บูตได้ รวมถึงระบบปฏิบัติการด้วย หากต้องการปิดใช้งาน ให้ทำดังต่อไปนี้:

1. ปิด Mac ของคุณ
2. เปิดเครื่องแล้วกด Command-R ค้างไว้ _ทันที_ จนกระทั่งเห็นหน้าจอโหลดปรากฏขึ้น
3. เลือกผู้ใช้ของคุณและป้อนรหัสผ่านหากระบบขอ
4. เมื่ออยู่ในหน้าจอกู้คืน ให้เลือก **Utilities > Startup Security Utility** จากแถบเมนู
5. ป้อนรหัสผ่านของคุณเมื่อระบบขอให้ยืนยันตัวตน
6. เลือก "No Security" จากตัวเลือก Secure Boot
7. เลือก "Allow booting from external or removable media" จากตัวเลือก External Boot

#### เริ่มการติดตั้ง

1. เสียบไดรฟ์ USB
2. รีสตาร์ท Mac ของคุณแล้วกด Option ค้างไว้ _ทันที_ จนกระทั่งเห็นหน้าจออุปกรณ์บูต
3. เลือกอุปกรณ์ EFI Boot สีส้ม
4. ดำเนินการ [ติดตั้งตามปกติ](02-getting-started.md)

โปรแกรมติดตั้งจะตรวจจับฮาร์ดแวร์ของ Mac และใช้การแก้ไขที่จำเป็นโดยอัตโนมัติ: ไดรเวอร์และเฟิร์มแวร์ Broadcom Wi-Fi ไดรเวอร์กล้อง FaceTime HD บนเครื่องที่มี Broadcom 1570 (เฟิร์มแวร์ของมันจะดาวน์โหลดจาก Apple เมื่อ Mac ออนไลน์ เนื่องจากโปรแกรมติดตั้งทำงานแบบออฟไลน์) ไดรเวอร์คีย์บอร์ด SPI บนรุ่น MacBook ที่ต้องการ และตัวแก้ไข NVMe suspend สำหรับรุ่นเดียวกันเหล่านั้น

### ข้อจำกัดที่ทราบ

สมาชิกในชุมชนกำลังทำงานอย่างต่อเนื่องเพื่อหาทางแก้ไขความท้าทายเหล่านี้ ดังนั้นหากสิ่งเหล่านี้เป็นปัญหาสำหรับคุณ เข้าร่วม #omarchy-on-other ใน [Discord](https://discord.gg/tXFUdasqhY) ของเราและดูว่ามีวิธีการล่าสุดในการแก้ไขหรือไม่

#### กล้อง FaceTime HD

ไดรเวอร์กล้องจะทำให้เครื่องค้างหากมันถูกโหลดอยู่เมื่อ Mac เข้าสู่โหมดไฮเบอร์เนต ดังนั้นมันจะถูกยกเลิกการโหลดก่อน มันไม่สามารถยกเลิกการโหลดได้ในขณะที่แอปเปิดกล้องอยู่ ดังนั้นการไฮเบอร์เนตจะถูกยกเลิกพร้อมการแจ้งเตือนที่ระบุชื่อแอป: ปิดแอปนั้นแล้วไฮเบอร์เนตอีกครั้ง ซึ่งรวมถึงการไฮเบอร์เนตโดยอัตโนมัติเมื่อแบตเตอรี่อยู่ในระดับวิกฤต และ suspend-then-hibernate ซึ่งจะถูกปฏิเสธก่อนที่จะระงับการทำงาน การระงับการทำงานแบบธรรมดาจะถูกปฏิเสธโดยตัวไดรเวอร์เองในขณะที่กล้องเปิดอยู่ โดยไม่มีการแจ้งเตือน

เฟิร์มแวร์ของกล้องจะดาวน์โหลดจาก Apple ดังนั้นกล้องจะทำงานก็ต่อเมื่อ Mac ได้ออนไลน์แล้วเท่านั้น การดาวน์โหลดจะเริ่มเมื่อบูตและจะลองใหม่ทุก 15 นาทีในขณะที่เครือข่ายเป็นปัญหา; หากไฟล์ของ Apple เปลี่ยนไป มันจะหยุดและรอการอัปเดต Omarchy หากกล้องไม่ปรากฏ `journalctl -u facetimehd-firmware-fetcher` จะบอกสาเหตุ `sudo systemctl restart facetimehd-firmware-fetcher` จะลองอีกครั้ง และการรีบูตจะโหลดไดรเวอร์หากการดาวน์โหลดเสร็จสิ้นแล้วแต่กล้องยังคงไม่ปรากฏ
