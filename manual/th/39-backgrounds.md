# พื้นหลัง

ทุกธีมมาพร้อมชุดพื้นหลังของตัวเอง และคุณสามารถเพิ่มพื้นหลังอื่นๆ ของคุณเองได้ใน `~/.config/omarchy/backgrounds/[theme]` หากคุณต้องการเพิ่มรูปพื้นหลังเสริมให้กับธีมอย่างเช่น nord ก็แค่วางไฟล์ไว้ใน `~/.config/omarchy/backgrounds/nord`

คุณสามารถทำเช่นนี้ได้ง่ายที่สุดโดยไปที่ _Install > Style > Background_ ใน Omarchy Menu นั่นจะเปิดโฟลเดอร์ที่เก็บพื้นหลังสำหรับธีมนั้นขึ้นมา กด `Super + Shift + F` เพื่อเปิดตัวจัดการไฟล์อีกตัว ค้นหาพื้นหลังของคุณ แล้วคัดลอกมันไปไว้ที่นั่น ตอนนี้มันก็จะรวมอยู่ในตัวเลือกพื้นหลังที่คุณสามารถเลือกสลับไปมาได้โดยใช้ `Super + Ctrl + W`

พื้นหลังสามารถเป็นวิดีโอได้เช่นกัน ไม่ใช่แค่ภาพนิ่ง วางไฟล์ `mp4`, `m4v`, `mov`, `webm`, `mkv` หรือ `avi` ลงในโฟลเดอร์เดียวกัน แล้วมันจะปรากฏอยู่เคียงข้างรูปภาพต่างๆ วิดีโอจะถูกเล่นโดยเอนจินวอลเปเปอร์ OWE มันถอดรหัสวิดีโอเพียงครั้งเดียวสำหรับจอภาพทั้งหมด และเล่นเสียงผ่านอุปกรณ์ส่งออกเสียงเริ่มต้น และมันจะหยุดเล่นทุกครั้งที่ไม่มีอะไรสามารถมองเห็นมันได้ วอลเปเปอร์แบบวิดีโอยังคงใช้พลังงานมากกว่าวอลเปเปอร์แบบภาพนิ่งอยู่มาก

ธีมต่างๆ สามารถใส่บทนำสั้นๆ สำหรับพื้นหลังแบบภาพนิ่งได้ สำหรับ `backgrounds/road.webp` วิดีโอที่จับคู่กันจะอยู่ที่ `backgrounds/intros/road.mp4` มันจะเล่นโดยอัตโนมัติตอนบูต เมื่อสลับไปยังธีมที่เลือกพื้นหลังนั้นไว้ และเมื่อเลือกพื้นหลังนั้น จากนั้นจึงกลับไปยังภาพนิ่ง วิดีโอบทนำจะไม่ปรากฏในตัวเลือกพื้นหลัง และจะไม่เล่นวนซ้ำเลย

การปิด _Appearance > Animations_ จะปิดบทนำของพื้นหลังด้วย Omarchy ทำเช่นนี้ตามค่าเริ่มต้นใน virtual machine คำสั่ง `omarchy theme bg intro toggle` สามารถเปิด/ปิดบทนำแยกต่างหากได้ การรีเฟรชธีมจะไม่เล่นบทนำ

คุณสามารถค้นหาคอลเลกชันพื้นหลังสุดเท่ที่คัดสรรมาแล้วจำนวนมากได้ใน [dharmx/walls](https://github.com/dharmx/walls)

หน้าจอล็อกจะแสดงเฟรมภาพนิ่งของพื้นหลังแบบวิดีโอ ในแบบเดียวกับที่มันแสดงเฟรมภาพนิ่งของ GIF แบบเคลื่อนไหว
