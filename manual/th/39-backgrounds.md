# พื้นหลัง

ทุกธีมมาพร้อมกับชุดพื้นหลังของตัวเอง และคุณสามารถเพิ่มพื้นหลังของคุณเองได้ใน `~/.config/omarchy/backgrounds/[theme]` หากคุณต้องการเพิ่มภาพพื้นหลังพิเศษให้กับธีม nord เป็นต้น คุณก็แค่วางไฟล์ไว้ใน `~/.config/omarchy/backgrounds/nord`

วิธีที่ง่ายที่สุดคือไปที่ _Install > Style > Background_ ใน Omarchy Menu ซึ่งจะเปิดโฟลเดอร์ที่เก็บพื้นหลังสำหรับธีมนั้นขึ้นมา กด `Super + Shift + F` เพื่อเปิด file manager อีกหน้าต่าง ค้นหาพื้นหลังของคุณ แล้วคัดลอกมันไปไว้ที่นั่น ตอนนี้มันจะอยู่ในตัวเลือกพื้นหลังที่คุณสลับเลือกได้โดยใช้ `Super + Ctrl + W`

พื้นหลังเป็นวิดีโอได้เช่นกัน ไม่ใช่แค่ภาพนิ่ง วางไฟล์ `mp4`, `m4v`, `mov`, `webm`, `mkv` หรือ `avi` ลงในโฟลเดอร์เดียวกัน แล้วมันจะปรากฏควบคู่ไปกับภาพต่าง ๆ วิดีโอจะถูกเล่นโดย OWE wallpaper engine มันถอดรหัสวิดีโอเพียงครั้งเดียวสำหรับทุกจอภาพ และเล่นเสียงผ่านอุปกรณ์ส่งออกเสียงเริ่มต้น และมันจะหยุดเล่นทุกครั้งที่ไม่มีอะไรสามารถมองเห็นมันได้ วิดีโอพื้นหลังยังคงใช้พลังงานมากกว่าภาพนิ่งมาก

ธีมต่าง ๆ สามารถมี intro สั้น ๆ สำหรับพื้นหลังภาพนิ่งได้ สำหรับ `backgrounds/road.webp` วิดีโอที่จับคู่กันจะอยู่ที่ `backgrounds/intros/road.mp4` มันจะเล่นโดยอัตโนมัติเมื่อ boot และเมื่อสลับไปยังธีมที่มีพื้นหลังนั้นถูกเลือกไว้ จากนั้นจะกลับไปยังภาพนิ่ง วิดีโอ intro จะไม่อยู่ในตัวเลือกพื้นหลัง และจะไม่วนซ้ำเลย

การปิด _Appearance > Animations_ จะปิด intro ของพื้นหลังด้วย Omarchy ทำเช่นนี้ตามค่าเริ่มต้นใน virtual machine คำสั่ง `omarchy theme bg intro toggle` สามารถสลับเปิดปิด intro แยกต่างหากได้ การรีเฟรชธีมหรือการเลือกพื้นหลังอื่นภายในธีมเดียวกันจะไม่เล่น intro

คุณสามารถค้นหาคอลเลกชันขนาดใหญ่ของพื้นหลังเท่ ๆ ที่คัดสรรมาแล้วได้ใน [dharmx/walls](https://github.com/dharmx/walls)

หน้าจอ lock screen จะแสดงภาพนิ่งหนึ่งเฟรมของพื้นหลังที่เป็นวิดีโอ ในลักษณะเดียวกับที่มันแสดงภาพนิ่งหนึ่งเฟรมของ GIF แบบเคลื่อนไหว
