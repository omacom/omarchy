# แบรนดิ้ง

Omarchy ให้คุณตั้งโลโก้บริษัทหรือรูปส่วนตัวของคุณได้ทั้งสำหรับหน้าปลดล็อกตอนบูต โปรแกรมพักหน้าจอ และหน้าจอเกี่ยวกับ

### หน้าปลดล็อกตอนบูต

คุณสามารถใช้ `omarchy plymouth preview` เพื่อดูว่าโลโก้และสีแบบกำหนดเองของคุณจะออกมาหน้าตาเป็นอย่างไรได้ คำสั่งนี้รับสีพื้นหลัง สีข้อความ ไฟล์ png ของโลโก้ และพาธสำหรับรูปตัวอย่าง:

```
omarchy plymouth preview '#1d2021' '#ebdbb2' logo.png preview.png
```

จากนั้นนำการตั้งค่านี้ไปใช้ด้วย `omarchy plymouth set '#1d2021' '#ebdbb2' logo.png` ซึ่งจะทำให้หน้าจอเข้าสู่ระบบของ SDDM ใช้สีและโลโก้เดียวกันด้วย หากคุณต้องการย้อนกลับ คุณสามารถใช้ `omarchy plymouth reset` ได้

 ![branding-plymouth-shopify](images/branding-plymouth-shopify.webp)

### โปรแกรมพักหน้าจอ

คุณสามารถเปลี่ยนโลโก้ที่ใช้สำหรับโปรแกรมพักหน้าจอได้ที่ _Appearance > Branding > Screensaver_ มันเป็นโลโก้แบบ ASCII คุณจึงแก้ไขข้อความได้โดยตรง แต่คุณจะส่งรูปภาพ png หรือ svg ให้มันก็ได้ และเราจะแปลงรูปนั้นเป็น ASCII ให้ มันออกมาดูเท่ไม่เบาเลย

 ![branding-screensaver](images/branding-screensaver.webp)

ในเมนูนั้นมีรายการอยู่สามรายการ:

- **แก้ไขข้อความ** เปิด `~/.config/omarchy/branding/screensaver.txt` ในโปรแกรมแก้ไขของคุณ พิมพ์หรือวางอะไรก็ได้ตามใจ — งานศิลปะ ASCII ชื่อของคุณ คำหยาบ ๆ สักคำ บันทึกแล้วออกมา โปรแกรมพักหน้าจอจะเริ่มทำงานทันทีเพื่อให้คุณได้เห็นมัน
- **ตั้งค่าจากรูปภาพ** เปิดตัวเลือกไฟล์สำหรับ png หรือ svg แปลงมันเป็น ASCII และแสดงผลลัพธ์ให้คุณดู โลโก้ที่มีเส้นขอบเงาชัดเจนจะออกมาดีกว่าภาพถ่ายมาก
- **คืนค่าเริ่มต้น** นำโลโก้ Omarchy กลับมา

### หน้าจอเกี่ยวกับ

ตัวเลือกสามตัวแบบเดียวกันนี้อยู่ที่ _Appearance > Branding > About_ สำหรับหน้าจอ _About_ ที่คุณเปิดได้จากเมนู Omarchy และทำงานเหมือนกันทุกอย่าง — ไฟล์คือ `~/.config/omarchy/branding/about.txt` และหน้าต่าง About จะโผล่ขึ้นมาหลังการเปลี่ยนแปลงแต่ละครั้ง งานศิลปะของ About จะถูกแปลงให้มีขนาดเล็กกว่าของโปรแกรมพักหน้าจอ เพราะมันต้องพอดีอยู่ในหน้าต่าง ไม่ใช่เต็มจอแสดงผลของคุณ

ขณะที่หน้าต่างเปิดอยู่ แสงสีเขียววาบหนึ่งจะเอนพาดผ่านงานศิลปะของคุณทุก ๆ สองสามวินาที แล้วก็ปล่อยให้มันนิ่งเหมือนเดิมอีกครั้ง งานศิลปะของคุณเองก็ได้รับแสงวาบนี้เช่นกัน ตราบใดที่ทุกตัวอักษรในนั้นกว้างหนึ่งคอลัมน์ — ซึ่งงานทุกชิ้นที่ _ตั้งค่าจากรูปภาพ_ สร้างขึ้นก็เป็นเช่นนั้น งานศิลปะที่สร้างจาก emoji หรือตัวอักษรแบบกว้างสองเท่าจะอยู่นิ่งแทน และหน้าจอก็จะนิ่งเช่นกันหากคุณใช้ fastfetch config ของตัวเอง: โลโก้ที่นิ่งในกรณีเหล่านั้นคือแอนิเมชันกำลังหลีกทางให้ ไม่ใช่กำลังล้มเหลว เพราะการเลื่อนแสงวาบพาดผ่านพวกมันจะทำให้ส่วนที่เหลือของบรรทัดไปอยู่ในตำแหน่งที่ผิด

 ![branding-about](images/branding-about.webp)

### แปลงรูปภาพด้วยตัวเอง

ตัวเลือก _ตั้งค่าจากรูปภาพ_ ทั้งสองตัวเป็นเพียงการเรียก `omarchy transcode ascii` ซึ่งคุณสามารถเรียกใช้โดยตรงได้หากต้องการควบคุมการแปลง:

```
omarchy transcode ascii ~/logo.svg ~/.config/omarchy/branding/screensaver.txt --width 100
```

มันรับ `--width` และ `--height` ในหน่วยคอลัมน์และแถวของเทอร์มินัล `--mode` ที่เป็นได้ทั้ง `braille` (ค่าเริ่มต้น และละเอียดกว่ามาก) หรือ `block` `--threshold` เป็นเปอร์เซ็นต์สำหรับตัดสินว่าพิกเซลใดนับเป็นส่วนหนึ่งของโลโก้ และ `--invert` สำหรับกรณีที่โลโก้ของคุณเป็นสีอ่อนบนพื้นหลังสีเข้ม หากแปลงออกมาแล้วได้เป็นก้อนตัน สิ่งที่มักต้องปรับก็คือ threshold นี่แหละ

### ใช้คำแทนโลโก้

`omarchy ascii` วาดข้อความเป็น Delta Corps Priest 1 ซึ่งเป็นฟอนต์ FIGlet ที่ใช้วาด wordmark ของ Omarchy เอง ดังนั้นโปรแกรมพักหน้าจอจึงพูดอะไรสักอย่างแทนที่จะแสดงรูปภาพได้:

```
omarchy ascii "Back in five" > ~/.config/omarchy/branding/screensaver.txt
```

มันรับข้อความเป็นอาร์กิวเมนต์ หรืออ่านจาก pipe เมื่อไม่มีข้อความให้มา ฟอนต์นี้มีเฉพาะตัวอักษรและช่องว่างเท่านั้น — มันถูกวาดขึ้นมาโดยไม่มีตัวเลขหรือเครื่องหมายวรรคตอน — ดังนั้นสิ่งอื่นใดนอกเหนือจากนั้นจะถูกตัดทิ้งและแจ้งชื่อไว้ที่ stderr แทนที่จะถูกกลืนหายไปเงียบ ๆ
