# แบรนด์ดิ้ง

Omarchy อนุญาตให้คุณตั้งโลโก้บริษัทหรือภาพส่วนตัวของคุณสำหรับทั้งการปลดล็อกตอนบูต พักหน้าจอ และหน้าจอเกี่ยวกับ

### การปลดล็อกตอนบูต

คุณสามารถใช้ `omarchy plymouth preview` เพื่อดูว่าโลโก้และสีที่กำหนดเองของคุณจะมีหน้าตาอย่างไร มันรับสีพื้นหลัง สีข้อความ โลโก้ png และพาธสำหรับภาพตัวอย่าง:

```
omarchy plymouth preview '#1d2021' '#ebdbb2' logo.png preview.png
```

จากนั้นใช้การตั้งค่านั้นด้วย `omarchy plymouth set '#1d2021' '#ebdbb2' logo.png` ซึ่งจะทำให้หน้าจอเข้าสู่ระบบ SDDM มีสีและโลโก้เดียวกันด้วย ถ้าคุณอยากย้อนกลับ คุณสามารถใช้ `omarchy plymouth reset`

 ![branding-plymouth-shopify](images/branding-plymouth-shopify.webp)

### พักหน้าจอ

คุณสามารถเปลี่ยนโลโก้ที่ใช้สำหรับพักหน้าจอได้ภายใต้ _สไตล์ > พักหน้าจอ_ มันเป็นโลโก้ ASCII คุณจึงแก้ไขข้อความได้โดยตรง แต่คุณยังส่งภาพ png หรือ svg ให้มันได้ และเราจะแปลงสิ่งนั้นเป็น ASCII มันดูเท่ทีเดียว

 ![branding-screensaver](images/branding-screensaver.webp)

ในเมนูนั้นมีสามรายการ:

- **แก้ข้อความ** เปิด `~/.config/omarchy/branding/screensaver.txt` ในตัวแก้ไขของคุณ พิมพ์หรือวางอะไรก็ได้ที่คุณชอบ — ASCII art ชื่อของคุณ คำหยาบ บันทึกและออก แล้วพักหน้าจอจะเริ่มทำงานทันทีเพื่อให้คุณเห็นมัน
- **ตั้งจากภาพ** เปิดตัวเลือกไฟล์สำหรับ png หรือ svg แปลงมันเป็น ASCII และแสดงผลลัพธ์ให้คุณเห็น โลโก้ที่มีเงาร่างชัดเจนใช้ได้ดีกว่าภาพถ่ายมาก
- **คืนค่าเริ่มต้น** ใส่โลโก้ Omarchy กลับไป

### หน้าจอเกี่ยวกับ

สามตัวเลือกเดียวกันอยู่ภายใต้ _สไตล์ > เกี่ยวกับ_ สำหรับหน้าจอ _เกี่ยวกับ_ ที่คุณได้จากเมนู Omarchy และพวกมันทำงานเหมือนกันทุกประการ — ไฟล์คือ `~/.config/omarchy/branding/about.txt` และหน้าต่างเกี่ยวกับจะโผล่ขึ้นมาหลังการเปลี่ยนแปลงแต่ละครั้ง งานศิลป์เกี่ยวกับจะถูกแปลงเป็นขนาดที่เล็กกว่างานของพักหน้าจอ เพราะมันต้องใส่ลงในหน้าต่างแทนที่จะเต็มจอแสดงผลของคุณ

ขณะที่หน้าต่างเปิดอยู่ แสงสีเขียวแวบหนึ่งจะพาดผ่านงานศิลป์ทุกสองสามวินาทีแล้วปล่อยให้มันนิ่งอีกครั้ง งานศิลป์ของคุณเองก็ได้มันเช่นกัน ตราบใดที่ทุกตัวอักษรในนั้นกว้างหนึ่งคอลัมน์ — ซึ่งอะไรก็ตามที่ _ตั้งจากภาพ_ สร้างขึ้นก็เป็นเช่นนั้น งานศิลป์ที่สร้างจากอิโมจิหรือตัวอักษรความกว้างสองเท่าจะอยู่นิ่งแทน และหน้าจอก็เช่นกันถ้าคุณเก็บการกำหนดค่า fastfetch ของตัวเองไว้: โลโก้ที่นิ่งในกรณีเหล่านั้นคือแอนิเมชันที่หลีกทางให้แทนที่จะล้มเหลว เพราะการเลื่อนแสงแวบผ่านพวกมันจะทำให้ส่วนที่เหลือของบรรทัดลงจอดผิดที่

 ![branding-about](images/branding-about.webp)

### การแปลงภาพด้วยตัวเอง

ตัวเลือก _ตั้งจากภาพ_ ทั้งสองตัวแค่เรียก `omarchy transcode ascii` ซึ่งคุณสามารถรันได้โดยตรงถ้าคุณอยากควบคุมการแปลง:

```
omarchy transcode ascii ~/logo.svg ~/.config/omarchy/branding/screensaver.txt --width 100
```

มันรับ `--width` และ `--height` ในคอลัมน์และแถวของเทอร์มินัล `--mode` เป็น `braille` (ค่าเริ่มต้น และละเอียดกว่ามาก) หรือ `block` เปอร์เซ็นต์ `--threshold` สำหรับตัดสินว่าพิกเซลใดนับเป็นส่วนหนึ่งของโลโก้ และ `--invert` สำหรับตอนที่โลโก้ของคุณเป็นสีอ่อนบนพื้นหลังสีเข้ม ถ้าการแปลงออกมาเป็นก้อนเละ ๆ threshold มักเป็นปุ่มที่ต้องหมุน

### คำแทนโลโก้

`omarchy ascii` วาดข้อความใน Delta Corps Priest 1 ซึ่งเป็นฟอนต์ FIGlet ที่ตัว wordmark ของ Omarchy เองถูกวาดด้วย พักหน้าจอจึงพูดอะไรบางอย่างแทนที่จะแสดงภาพได้:

```
omarchy ascii "Back in five" > ~/.config/omarchy/branding/screensaver.txt
```

มันรับข้อความเป็นอาร์กิวเมนต์ หรืออ่านจากไปป์เมื่อไม่ได้รับอะไรเลย ฟอนต์นี้มีแค่ตัวอักษรและช่องว่าง — มันถูกวาดโดยไม่มีตัวเลขหรือเครื่องหมายวรรคตอน — อะไรอื่นจึงถูกทิ้งและระบุชื่อบน stderr แทนที่จะถูกกลืนไปเงียบ ๆ
