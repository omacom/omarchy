# การสร้างแบรนด์

Omarchy ให้คุณตั้งโลโก้บริษัทหรือรูปภาพส่วนตัวของคุณได้ ทั้งสำหรับการปลดล็อกตอนบูต โปรแกรมพักหน้าจอ และหน้าจอเกี่ยวกับ

### การปลดล็อกตอนบูต

คุณสามารถใช้ `omarchy plymouth preview` เพื่อดูว่าโลโก้และสีที่คุณกำหนดเองจะมีหน้าตาเป็นอย่างไรได้ คำสั่งนี้รับสีพื้นหลัง สีข้อความ ไฟล์ png ของโลโก้ และพาธสำหรับรูปภาพตัวอย่าง:

```
omarchy plymouth preview '#1d2021' '#ebdbb2' logo.png preview.png
```

จากนั้นใช้การตั้งค่านั้นด้วย `omarchy plymouth set '#1d2021' '#ebdbb2' logo.png` ซึ่งจะทำให้หน้าจอเข้าสู่ระบบ SDDM ใช้สีและโลโก้เดียวกันด้วย หากต้องการย้อนกลับ คุณสามารถใช้ `omarchy plymouth reset` ได้

 ![branding-plymouth-shopify](images/branding-plymouth-shopify.webp)

### โปรแกรมพักหน้าจอ

คุณสามารถเปลี่ยนโลโก้ที่ใช้สำหรับโปรแกรมพักหน้าจอได้ที่ _ลักษณะที่ปรากฏ > การสร้างแบรนด์ > โปรแกรมพักหน้าจอ_ มันคือโลโก้ ASCII ดังนั้นคุณจึงแก้ไขข้อความได้โดยตรง แต่คุณก็ส่งรูปภาพ png หรือ svg ให้มันได้เช่นกัน และเราจะแปลงรูปนั้นเป็น ASCII ให้ มันออกมาดูเท่ไม่เบาเลย

 ![branding-screensaver](images/branding-screensaver.webp)

ในเมนูนั้นมีสามรายการ:

- **แก้ไขข้อความ** เปิด `~/.config/omarchy/branding/screensaver.txt` ในโปรแกรมแก้ไขของคุณ พิมพ์หรือวางอะไรก็ได้ตามใจ — งานศิลปะ ASCII ชื่อของคุณ คำหยาบสักคำ บันทึกแล้วออก และโปรแกรมพักหน้าจอจะเริ่มทำงานทันทีเพื่อให้คุณเห็นมัน
- **ตั้งค่าจากรูปภาพ** เปิดตัวเลือกไฟล์สำหรับ png หรือ svg แปลงมันเป็น ASCII และแสดงผลลัพธ์ให้คุณดู โลโก้ที่มีเงารูปร่างชัดเจนจะออกมาดีกว่าภาพถ่ายมาก
- **คืนค่าเริ่มต้น** นำโลโก้ Omarchy กลับมา

### หน้าจอเกี่ยวกับ

ตัวเลือกสามอย่างเดียวกันนี้อยู่ใต้ _ลักษณะที่ปรากฏ > การสร้างแบรนด์ > เกี่ยวกับ_ สำหรับหน้าจอ _เกี่ยวกับ_ ที่คุณได้จากเมนู Omarchy และพวกมันทำงานเหมือนกันทุกอย่าง — ไฟล์คือ `~/.config/omarchy/branding/about.txt` และหน้าต่างเกี่ยวกับจะเด้งขึ้นมาหลังจากการเปลี่ยนแปลงแต่ละครั้ง งานศิลปะสำหรับหน้าจอเกี่ยวกับจะถูกแปลงให้มีขนาดเล็กกว่าของโปรแกรมพักหน้าจอ เนื่องจากมันต้องพอดีอยู่ในหน้าต่างแทนที่จะเติมเต็มจอแสดงผลของคุณ

ขณะที่หน้าต่างเปิดอยู่ แถบแสงสีขาวสว่างจะพาดเอียงผ่านงานศิลปะทุก ๆ สองสามวินาที แล้วก็ปล่อยให้มันนิ่งอีกครั้ง งานศิลปะของคุณเองก็ได้แบบนั้นเช่นกัน ตราบใดที่ทุกอักขระในนั้นกว้างหนึ่งคอลัมน์ — สิ่งใดก็ตามที่ _ตั้งค่าจากรูปภาพ_ สร้างขึ้นจะเป็นแบบนั้น งานศิลปะที่สร้างจาก emoji หรืออักขระความกว้างสองเท่าจะนิ่งอยู่กับที่แทน และหน้าจอก็จะเป็นเช่นนั้นเช่นกันหากคุณเก็บคอนฟิกของ fastfetch ของคุณเองไว้: โลโก้ที่นิ่งในกรณีเหล่านั้นคือแอนิเมชันกำลังหลีกทางให้ แทนที่จะล้มเหลว เนื่องจากการเลื่อนแสงวาบผ่านพวกมันจะทำให้ส่วนที่เหลือของบรรทัดไปลงเอยในตำแหน่งที่ผิด

 ![branding-about](images/branding-about.webp)

### แปลงรูปภาพด้วยตัวเอง

ตัวเลือก _ตั้งค่าจากรูปภาพ_ ทั้งสองก็แค่เรียก `omarchy transcode ascii` ซึ่งคุณสามารถรันโดยตรงได้หากต้องการควบคุมการแปลง:

```
omarchy transcode ascii ~/logo.svg ~/.config/omarchy/branding/screensaver.txt --width 100
```

มันรับ `--width` และ `--height` ในหน่วยคอลัมน์และแถวของเทอร์มินัล `--mode` เป็น `braille` (ค่าเริ่มต้น และละเอียดกว่ามาก) หรือ `block` เปอร์เซ็นต์ `--threshold` สำหรับตัดสินว่าพิกเซลใดนับเป็นส่วนหนึ่งของโลโก้ และ `--invert` สำหรับเมื่อโลโก้ของคุณเป็นสีอ่อนบนพื้นหลังสีเข้ม หากการแปลงออกมาเป็นก้อนตัน ๆ โดยปกติ threshold คือตัวที่ต้องปรับ

### ใช้คำพูดแทนโลโก้

`omarchy ascii` วาดข้อความด้วย Delta Corps Priest 1 ฟอนต์ FIGlet ที่ wordmark ของ Omarchy เองก็ถูกวาดด้วย ดังนั้นโปรแกรมพักหน้าจอจึงพูดอะไรบางอย่างได้แทนที่จะแสดงรูปภาพ:

```
omarchy ascii "Back in five" > ~/.config/omarchy/branding/screensaver.txt
```

มันรับข้อความเป็นอาร์กิวเมนต์ หรืออ่านจาก pipe เมื่อไม่ได้รับข้อความใด ๆ ฟอนต์นี้มีเฉพาะตัวอักษรและช่องว่างเท่านั้น — มันถูกวาดมาโดยไม่มีตัวเลขหรือเครื่องหมายวรรคตอน — ดังนั้นสิ่งอื่นใดนอกเหนือจากนั้นจะถูกตัดทิ้งและระบุชื่อไว้บน stderr แทนที่จะถูกกลืนหายไปอย่างเงียบ ๆ
