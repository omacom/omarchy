# แบรนดิ้ง

Omarchy ให้คุณตั้งค่าโลโก้บริษัทหรือรูปภาพส่วนตัวของคุณได้ทั้งสำหรับโปรแกรมรักษาหน้าจอและหน้าจอเกี่ยวกับ

### โปรแกรมรักษาหน้าจอ

คุณเปลี่ยนโลโก้ที่ใช้สำหรับโปรแกรมรักษาหน้าจอได้ที่ _Appearance > Branding > Screensaver_ มันเป็นโลโก้ ASCII คุณจึงแก้ไขข้อความได้โดยตรง แต่คุณก็ส่งรูปภาพ png หรือ svg ให้มันได้เช่นกัน แล้วเราจะแปลงรูปนั้นให้เป็น ASCII ให้ มันดูเท่มากทีเดียว

 ![branding-screensaver](images/branding-screensaver.webp)

ในเมนูนั้นมีสามรายการ:

- **แก้ไขข้อความ** จะเปิด `~/.config/omarchy/branding/screensaver.txt` ในโปรแกรมแก้ไขข้อความของคุณ พิมพ์หรือวางอะไรก็ได้ตามใจชอบ — ภาพ ASCII ชื่อของคุณ คำหยาบ บันทึกแล้วออกจากโปรแกรม โปรแกรมรักษาหน้าจอจะเริ่มทำงานทันทีเพื่อให้คุณเห็นผลงาน
- **ตั้งค่าจากรูปภาพ** จะเปิดตัวเลือกรูปภาพสำหรับไฟล์ png หรือ svg แปลงให้เป็น ASCII และแสดงผลลัพธ์ให้คุณเห็น โลโก้ที่มีเงารูปร่างชัดเจนจะใช้ได้ดีกว่าภาพถ่ายมาก
- **คืนค่าเริ่มต้น** จะนำโลโก้ Omarchy กลับมา

### หน้าจอเกี่ยวกับ

ตัวเลือกสามแบบเดียวกันนี้อยู่ที่ _Appearance > Branding > About_ สำหรับหน้าจอ _About_ ที่คุณเข้าถึงได้จากเมนู Omarchy และทำงานเหมือนกันทุกประการ — ไฟล์คือ `~/.config/omarchy/branding/about.txt` และหน้าต่าง About จะโผล่ขึ้นมาหลังการเปลี่ยนแปลงแต่ละครั้ง ภาพ About จะถูกแปลงให้มีขนาดเล็กกว่าของโปรแกรมรักษาหน้าจอ เนื่องจากมันต้องพอดีในหน้าต่างแทนที่จะเต็มจอแสดงผลของคุณ

ขณะที่หน้าต่างเปิดอยู่ แถบแสงสีขาวสว่างจะพาดเอียงผ่านภาพทุก ๆ สองสามวินาที แล้วปล่อยให้ภาพกลับมานิ่งอีกครั้ง ภาพของคุณเองก็ได้เอฟเฟกต์นี้เช่นกัน ตราบใดที่อักขระทุกตัวในภาพมีความกว้างหนึ่งคอลัมน์ — ซึ่งทุกสิ่งที่ _ตั้งค่าจากรูปภาพ_ สร้างขึ้นจะเป็นแบบนั้น ภาพที่สร้างจาก emoji หรืออักขระความกว้างสองเท่าจะอยู่นิ่งแทน และหน้าจอก็จะเป็นเช่นนั้นด้วยหากคุณเก็บ fastfetch config ของตัวเองไว้: โลโก้ที่อยู่นิ่งในกรณีเหล่านั้นคือภาพเคลื่อนไหวกำลังหลีกทางให้ มากกว่าจะล้มเหลว เนื่องจากการเลื่อนแสงวาวข้ามภาพเหล่านั้นจะทำให้ส่วนที่เหลือของบรรทัดไปอยู่ในตำแหน่งที่ผิด

 ![branding-about](images/branding-about.webp)

### แปลงรูปภาพด้วยตัวเอง

ตัวเลือก _ตั้งค่าจากรูปภาพ_ ทั้งสองแบบก็แค่เรียกใช้ `omarchy transcode ascii` ซึ่งคุณสามารถเรียกใช้โดยตรงได้หากต้องการควบคุมการแปลง:

```
omarchy transcode ascii ~/logo.svg ~/.config/omarchy/branding/screensaver.txt --width 100
```

มันรับ `--width` และ `--height` ในหน่วยคอลัมน์และแถวของเทอร์มินัล `--mode` ที่เป็นได้ทั้ง `braille` (ค่าเริ่มต้น และละเอียดกว่ามาก) หรือ `block` `--threshold` เป็นเปอร์เซ็นต์สำหรับตัดสินว่าพิกเซลใดนับเป็นส่วนหนึ่งของโลโก้ และ `--invert` สำหรับเวลาที่โลโก้ของคุณมีสีอ่อนบนพื้นหลังสีเข้ม หากแปลงออกมาแล้วได้เป็นก้อนเบลอ ปกติแล้ว threshold คือปุ่มที่ควรหมุนปรับ

### คำแทนโลโก้

`omarchy ascii` วาดข้อความด้วย Delta Corps Priest 1 ซึ่งเป็นฟอนต์ FIGlet ที่ใช้วาดตัวอักษรชื่อ Omarchy เอง โปรแกรมรักษาหน้าจอจึงพูดอะไรบางอย่างได้แทนที่จะแสดงรูปภาพ:

```
omarchy ascii "Back in five" > ~/.config/omarchy/branding/screensaver.txt
```

มันรับข้อความในรูปแบบอาร์กิวเมนต์ หรืออ่านจาก pipe เมื่อไม่ได้ให้ข้อความใด ๆ ฟอนต์นี้มีเฉพาะตัวอักษรและช่องว่างเท่านั้น — มันถูกวาดขึ้นโดยไม่มีตัวเลขหรือเครื่องหมายวรรคตอน — ดังนั้นสิ่งอื่นใดนอกเหนือจากนั้นจะถูกตัดทิ้งและระบุชื่อไว้บน stderr แทนที่จะถูกกลืนหายไปอย่างเงียบ ๆ
