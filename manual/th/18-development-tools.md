# เครื่องมือพัฒนา

## โปรแกรมแก้ไขข้อความทางเลือก

Omarchy มาพร้อมกับ Plain เป็นโปรแกรมแก้ไขข้อความเริ่มต้นบนระบบที่ติดตั้งใหม่ และมี [Neovim](https://neovim.io/) ติดตั้งมาให้ล่วงหน้า แต่ถ้าคุณอยากได้อะไรที่ได้รับความนิยมมากกว่าและคุ้นเคยกว่า คุณสามารถเปิด Omarchy Menu (`Super + Space`) และดูตัวเลือกต่าง ๆ ได้ภายใต้ _Install > Editor_ เรามี VSCode, Cursor, Zed, Sublime Text, Helix, Vim และ Emacs อยู่ในรายการนั้น ถ้าคุณไม่พบสิ่งที่คุณกำลังมองหา ให้ลองดูที่ _Install > Package_ และดูว่ามันอยู่ในแพ็กเกจของ Arch หรือเปล่า (และถ้าไม่มี ให้ลอง _Install > AUR_ เพื่อตรวจสอบที่ AUR)

โปรแกรมแก้ไขข้อความ `vi` ดั้งเดิมก็มีให้ใช้งานตั้งแต่แรกเช่นกัน รัน `vi filename` เพื่อแก้ไขไฟล์ในเทอร์มินัล

มีการรองรับการจับคู่ธีมให้สำหรับ `VSCode`, `Cursor`, `VSCodium` และ `Helix`

คุณสามารถตั้งค่าโปรแกรมแก้ไขข้อความเริ่มต้นสำหรับทั้งระบบได้ที่ `Setup > Defaults > Editor`

## สภาพแวดล้อม

Omarchy รองรับการตั้งค่าสภาพแวดล้อมสำหรับการพัฒนามากมายผ่านส่วน _Install > Development_ ของ Omarchy Menu (`Super + Space`) แน่นอนว่าคุณจะพบ _Ruby on Rails_ แต่ก็ยังมีรันไทม์หลักทั้งสามแบบสำหรับ JavaScript (Node.js, Bun, Deno) รวมถึงเฟรมเวิร์ก PHP ยอดนิยมอย่าง Laravel และ Symfony อ้อ และยังมี Go, Rust, Python, Java, Elixir (พร้อม Phoenix), .NET, OCaml, Zig, Clojure และ Scala ด้วย เป็นตัวเลือกที่กว้างมากจริง ๆ!

สภาพแวดล้อมส่วนใหญ่เหล่านี้จัดการโดย [Mise](https://mise.jdx.dev/) ซึ่งเป็นเครื่องมือที่ช่วยให้คุณติดตั้งและรันภาษาโปรแกรมหลายเวอร์ชันบนเครื่องเดียวกันได้ มันเหมือน rbenv หรือ rvm สำหรับ Ruby หรือ virtualenv สำหรับ Python แต่ทำงานได้กับสภาพแวดล้อมที่หลากหลายมากมาย

ตัวอย่างเช่น ถ้าจะติดตั้ง Ruby คุณรัน `mise use -g ruby` ซึ่งจะทั้งติดตั้ง Ruby และตั้งให้มันเป็นค่าเริ่มต้นทั่วทั้งระบบ หรือถ้าโปรเจกต์ของคุณมีไฟล์ .ruby-version คุณก็แค่รัน `mise i` ที่โฟลเดอร์หลักของโปรเจกต์นั้นได้เลย

## เครื่องมือ CLI ที่ติดตั้งมาให้ล่วงหน้า

`uv`, Node.js และ `playwright-cli` (สำหรับให้ agent ขับเคลื่อนเบราว์เซอร์ โดยใช้ Chrome ที่ติดตั้งไว้) ติดตั้งมาเป็นแพ็กเกจ และ `omarchy update` จะคอยอัปเดตสิ่งเหล่านี้ให้ทันสมัยพร้อมกับส่วนอื่น ๆ ของระบบ `ghui`, [Hunk](https://github.com/modem-dev/hunk) และ CLI ของ Basecamp, Cloudflare และ HEY เลือกติดได้ที่ _Install > CLI_ ส่วน [agent สำหรับเขียนโค้ด](17-ai.md) อยู่ที่ _Install > AI > CLI_

mise จะจัดการเฉพาะรันไทม์ที่คุณตั้งค่าจาก _Install > Development_ เท่านั้น Omarchy จะไม่ติดตั้งอะไรผ่าน mise ด้วยตัวเองเลย รัน `omarchy update` เพื่ออัปเดตสิ่งเหล่านี้พร้อมกับส่วนอื่น ๆ ของ Omarchy ส่วน alias `mup` จะอัปเดตเฉพาะเครื่องมือที่ mise จัดการเท่านั้น ถ้าจะเพิ่มเครื่องมืออื่นเข้ากับการกำหนดค่าของคุณเอง ให้ใช้ `mise use -g <tool>`

## Docker

[Docker](https://www.docker.com/) แทบไม่ต้องแนะนำกันแล้ว มันช่วยให้คุณรันคอนเทนเนอร์แบบแยกขาดจากกันได้ และ Omarchy ก็ติดตั้งทุกอย่างที่จำเป็นเพื่อให้มันทำงานได้ดี รวมถึงตัว Docker เองและ [Docker Compose](https://docs.docker.com/compose/)

โดยค่าเริ่มต้น ผู้ใช้ของคุณจะ *ไม่ได้* อยู่ในกลุ่ม `docker` กลุ่มนั้นมีค่าเท่ากับ root ที่ไม่ต้องใช้รหัสผ่าน — อะไรก็ตามที่อยู่ในกลุ่มนั้นสามารถทำ `docker run -v /:/host` และยึดครองเครื่องได้เลย — ดังนั้น สคริปต์หรือ dependency ตัวร้ายเพียงตัวเดียวที่รันภายใต้ผู้ใช้ของคุณ ก็จะห่างจากการได้สิทธิ์ root เพียงคำสั่งเดียวเท่านั้น ดังนั้น ที่บรรทัดคำสั่ง คุณจะรัน Docker ด้วย `sudo` (`sudo docker ps`, `sudo docker compose up`) และเครื่องมือแบบกราฟิกที่สื่อสารกับ daemon — อย่าง Windows VM — จะขอการยืนยันสิทธิ์เมื่อจำเป็น ถ้าคุณอยากได้ความสะดวกของการตั้งค่าแบบไม่ต้องอยู่ในกลุ่มกลับคืนมา และเข้าใจข้อแลกเปลี่ยนนี้แล้ว ให้เปิดใช้มันจาก **Setup > Security > Sudoless Docker** (หรือรัน `omarchy-setup-security-sudoless-docker`) ซึ่งจะเพิ่มคุณเข้าไปในกลุ่ม `docker` หลังจากแสดงคำเตือนแล้ว จากนั้นการใช้ `docker` แบบธรรมดาและ alias `d` จะทำงานได้โดยไม่ต้องใช้ `sudo` อีกครั้ง

คุณสามารถตั้งค่าฐานข้อมูลยอดนิยมสำหรับการพัฒนาบนเครื่องของคุณใน Docker ได้โดยใช้ _Install > Development > Docker DB_ ในเมนู Omarchy

## GitHub CLI

[GitHub CLI](https://cli.github.com/) คือ `gh` สำหรับการทำงานกับ repository, issue และ pull request จากเทอร์มินัล _Setup > Git_ จะติดตั้งมันเมื่อคุณเลือกที่จะเข้าสู่ระบบ GitHub ที่นั่น จากนั้น `gh repo clone org/repo` จะ clone repository มา รัน `gh --help` เพื่อสำรวจคำสั่งของมัน

_Install > CLI > GitHub_ จะติดตั้ง GitHub CLI, `gh` พร้อมกับ `ghui` ซึ่งเป็นอินเทอร์เฟซในเทอร์มินัลสำหรับ pull request ส่วน [Lazygit](https://github.com/jesseduffield/lazygit) นั้นติดตั้งมาให้ล่วงหน้าแล้วสำหรับการทำงานกับ Git โดยตรง
