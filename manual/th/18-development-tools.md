# เครื่องมือพัฒนา

## โปรแกรมแก้ไขทางเลือก

Omarchy มาพร้อมกับ Plain เป็นโปรแกรมแก้ไขเริ่มต้นในการติดตั้งใหม่ และมี [Neovim](https://neovim.io/) ติดตั้งมาให้ล่วงหน้า แต่ถ้าคุณอยากได้อะไรที่ธรรมดาและคุ้นเคยกว่านี้หน่อย คุณสามารถเปิด Omarchy Menu (`Super + Space`) และดูตัวเลือกภายใต้ _Install > Editor_ เรามี VSCode, Cursor, Zed, Sublime Text, Helix, Vim และ Emacs อยู่ในรายการที่นั่น หากคุณไม่พบสิ่งที่คุณกำลังมองหา ลองดูที่ _Install > Package_ และดูว่ามันอยู่ในแพ็กเกจของ Arch หรือไม่ (และถ้าไม่มี ลองใช้ _Install > AUR_ เพื่อตรวจสอบ AUR)

โปรแกรมแก้ไข `vi` ดั้งเดิมก็มีให้ใช้งานตั้งแต่แกะกล่องเช่นกัน รัน `vi filename` เพื่อแก้ไขไฟล์ในเทอร์มินัล

การจับคู่ธีมมีให้สำหรับ `VSCode`, `Cursor`, `VSCodium` และ `Helix`

คุณสามารถตั้งค่าโปรแกรมแก้ไขเริ่มต้นทั้งระบบได้ภายใต้ `Setup > Defaults > Editor`

## สภาพแวดล้อม

Omarchy รองรับการตั้งค่าสภาพแวดล้อมการพัฒนามากมายผ่านส่วน _Install > Development_ ของ Omarchy Menu (`Super + Space`) แน่นอนว่าคุณจะพบ _Ruby on Rails_ แต่ก็ยังมีรันไทม์หลักทั้งสามสำหรับ JavaScript (Node.js, Bun, Deno) อีกด้วย รวมถึงเฟรมเวิร์ก PHP ยอดนิยมอย่าง Laravel และ Symfony อ้อ และยังมี Go, Rust, Python, Java, Elixir (พร้อม Phoenix), .NET, OCaml, Zig, Clojure และ Scala อีกด้วย ตัวเลือกเยอะมากจริง ๆ!

สภาพแวดล้อมเหล่านี้ส่วนใหญ่จัดการโดย [Mise](https://mise.jdx.dev/) มันเป็นเครื่องมือที่ช่วยให้คุณติดตั้งและรันภาษาโปรแกรมหลายเวอร์ชันบนเครื่องเดียวกันได้ มันเหมือน rbenv หรือ rvm สำหรับ Ruby หรือ virtualenv สำหรับ Python แต่ใช้งานได้กับสภาพแวดล้อมต่าง ๆ มากมาย

ตัวอย่างเช่น หากต้องการติดตั้ง Ruby คุณจะรัน `mise use -g ruby` ซึ่งจะทั้งติดตั้ง Ruby และตั้งให้มันเป็นค่าเริ่มต้นทั่วโลก หรือหากโปรเจกต์ของคุณมีไฟล์ .ruby-version คุณก็แค่รัน `mise i` ในโฟลเดอร์รากของโปรเจกต์นั้นได้เลย

## เครื่องมือ CLI ที่ติดตั้งมาให้ล่วงหน้า

`uv`, Node.js และ `playwright-cli` (สำหรับให้เอเจนต์ขับเคลื่อนเบราว์เซอร์โดยใช้ Chrome ที่ติดตั้งไว้) มาในรูปแบบแพ็กเกจที่ติดตั้งมาให้ และ `omarchy update` จะทำให้พวกมันทันสมัยพร้อมกับส่วนอื่น ๆ ของระบบ [Hunk](https://github.com/modem-dev/hunk) และ CLI ของ GitHub, Basecamp, Cloudflare และ HEY อยู่ห่างแค่การเลือกครั้งเดียวภายใต้ _Install > CLI_ และ[เอเจนต์เขียนโค้ด](17-ai.md) อยู่ภายใต้ _Install > AI > CLI_

mise จะจัดการเฉพาะรันไทม์ที่คุณตั้งค่าจาก _Install > Development_ เท่านั้น Omarchy จะไม่ติดตั้งอะไรผ่านมันเอง รัน `omarchy update` เพื่ออัปเดตพวกมันพร้อมกับส่วนอื่น ๆ ของ Omarchy นามสมมติ `mup` จะอัปเดตเฉพาะเครื่องมือที่ mise จัดการเท่านั้น หากต้องการเพิ่มเครื่องมืออื่นลงในการกำหนดค่าของคุณเอง ให้ใช้ `mise use -g <tool>`

## Docker

[Docker](https://www.docker.com/) แทบไม่ต้องแนะนำอะไร มันช่วยให้คุณรันคอนเทนเนอร์แบบแยกขาดจากกันได้ และ Omarchy ติดตั้งทุกอย่างที่จำเป็นเพื่อให้มันทำงานได้ดี รวมถึง Docker เองและ [Docker Compose](https://docs.docker.com/compose/)

โดยค่าเริ่มต้น ผู้ใช้ของคุณจะ*ไม่*อยู่ในกลุ่ม `docker` กลุ่มนั้นเทียบเท่ากับ root แบบไม่ต้องใช้รหัสผ่าน — อะไรก็ตามที่อยู่ในกลุ่มนั้นสามารถสั่ง `docker run -v /:/host` และยึดเครื่องไปได้เลย — ดังนั้นสคริปต์หรือดีเพนเดนซีตัวร้ายตัวเดียวที่รันในนามของคุณก็จะห่างจาก root แค่คำสั่งเดียว ไม่อย่างนั้น ดังนั้นบนบรรทัดคำสั่ง คุณจะรัน Docker ด้วย `sudo` (`sudo docker ps`, `sudo docker compose up`) และเครื่องมือแบบกราฟิกที่คุยกับดีมอน — Windows VM — จะขอการยืนยันตัวตนเมื่อจำเป็น หากคุณอยากได้ความสะดวกของวิธีที่ไม่ต้องอยู่ในกลุ่มกลับคืนมาและเข้าใจข้อแลกเปลี่ยน เปิดใช้งานได้จาก **Setup > Security > Sudoless Docker** (หรือรัน `omarchy-setup-security-sudoless-docker`) ซึ่งจะเพิ่มคุณเข้าไปในกลุ่ม `docker` หลังจากแสดงคำเตือน จากนั้น `docker` ธรรมดาและนามสมมติ `d` จะทำงานได้โดยไม่ต้องใช้ `sudo` อีกครั้ง

คุณสามารถตั้งค่าฐานข้อมูลที่ใช้กันทั่วไปสำหรับการพัฒนาภายในเครื่องใน Docker ได้โดยใช้ _Install > Development > Docker DB_ ในเมนู Omarchy

## GitHub CLI

[GitHub CLI](https://cli.github.com/) คือ `gh` สำหรับทำงานกับที่เก็บโค้ด ประเด็นปัญหา และ pull request จากเทอร์มินัล _Setup > Git_ จะติดตั้งมันเมื่อคุณเลือกที่จะลงชื่อเข้าใช้ GitHub ที่นั่น หรือติดตั้งแยกต่างหากได้จาก _Install > CLI > GitHub_ จากนั้น `gh repo clone org/repo` จะโคลนที่เก็บโค้ด รัน `gh --help` เพื่อสำรวจคำสั่งของมัน

[Lazygit](https://github.com/jesseduffield/lazygit) ติดตั้งมาให้ล่วงหน้าสำหรับทำงานกับ Git เอง
