# เครื่องมือสำหรับนักพัฒนา

## โปรแกรมแก้ไขทางเลือก

Omarchy มาพร้อมกับ [Neovim](https://neovim.io/) เป็นค่าเริ่มต้น แต่ถ้าคุณอยากได้อะไรที่คุ้นเคยและเป็นกระแสหลักมากกว่านี้หน่อย คุณสามารถเรียกใช้ Omarchy Menu (`Super + Space`) แล้วดูตัวเลือกต่าง ๆ ภายใต้ _Install > Editor_ ได้เลย เรามี VSCode, Cursor, Zed, Sublime Text, Helix, Vim และ Emacs อยู่ในรายการนั้น ถ้าคุณไม่พบสิ่งที่กำลังมองหา ให้ลองดูที่ _Install > Package_ และดูว่ามันไม่อยู่ในแพ็กเกจของ Arch หรือเปล่า (และถ้าไม่อยู่ ให้ลองไปดูที่ _Install > AUR_ เพื่อตรวจสอบใน AUR)

โปรแกรมแก้ไข `vi` ดั้งเดิมก็พร้อมใช้งานทันทีเช่นกัน เรียกใช้ `vi filename` เพื่อแก้ไขไฟล์ในเทอร์มินัล

มีการจับคู่ธีมให้สำหรับ `VSCode`, `Cursor`, `VSCodium` และ `Helix`

คุณสามารถตั้งค่าโปรแกรมแก้ไขเริ่มต้นสำหรับทั้งระบบได้ภายใต้ `Setup > Defaults > Editor`

## สภาพแวดล้อม

Omarchy รองรับการตั้งค่าสภาพแวดล้อมสำหรับการพัฒนาได้มากมายหลายอย่างผ่านส่วน _Install > Development_ ของ Omarchy Menu (`Super + Space`) แน่นอนว่าคุณจะพบ _Ruby on Rails_ และยังพบรันไทม์หลักทั้งสามตัวสำหรับ JavaScript (Node.js, Bun, Deno) รวมถึงเฟรมเวิร์ก PHP ยอดนิยมอย่าง Laravel และ Symfony ด้วย อ้อ และยังมี Go, Rust, Python, Java, Elixir (พร้อม Phoenix), .NET, OCaml, Zig, Clojure และ Scala ด้วยเช่นกัน มีให้เลือกหลากหลายมากจริง ๆ!

สภาพแวดล้อมเหล่านี้ส่วนใหญ่ได้รับการจัดการโดย [Mise](https://mise.jdx.dev/) มันเป็นเครื่องมือที่ช่วยให้คุณติดตั้งและเรียกใช้ภาษาโปรแกรมหลายเวอร์ชันบนเครื่องเดียวกันได้ มันคล้ายกับ rbenv หรือ rvm สำหรับ Ruby หรือ virtualenv สำหรับ Python แต่มันใช้งานได้กับสภาพแวดล้อมที่แตกต่างกันมากมาย

ตัวอย่างเช่น หากต้องการติดตั้ง Ruby คุณจะต้องเรียกใช้ `mise use -g ruby` ซึ่งจะทั้งติดตั้ง Ruby และตั้งให้มันเป็นค่าเริ่มต้นระดับโกลบอล หรือถ้าโปรเจกต์ของคุณมีไฟล์ .ruby-version คุณก็แค่เรียกใช้ `mise i` ในโฟลเดอร์รากของโปรเจกต์นั้นได้เลย

## เครื่องมือ CLI ที่ติดตั้งมาล่วงหน้า

Omarchy ทำให้เครื่องมือต่าง ๆ เช่น `gh`, `uv` และ [เอเจนต์เขียนโค้ด](17-ai.md) ส่วนใหญ่พร้อมใช้งานผ่าน [การติดตั้งแบบ lazy ของ mise](https://mise.jdx.dev/dev-tools/shims.html#lazy-tools) ครั้งแรกที่คุณเรียกใช้เครื่องมือตัวใดตัวหนึ่ง mise จะติดตั้งมันให้ ส่วนการเรียกใช้ในครั้งต่อ ๆ ไปจะใช้เวอร์ชันที่ติดตั้งไว้แล้ว โดยจะไม่ตรวจสอบหาการอัปเดตทุกครั้งที่เปิดใช้งาน

คุณยังสามารถตรวจสอบค่าเริ่มต้นหรือติดตั้งเครื่องมือเหล่านั้นล่วงหน้าได้ด้วย:

```bash
mise ls --current              # List the tools configured for this directory
mise install gh               # Install one tool now
mise install --include-lazy    # Install all configured tools, including lazy tools
```

เรียกใช้ `omarchy update` เพื่ออัปเดตเครื่องมือที่ติดตั้งไว้พร้อมกับส่วนอื่น ๆ ของ Omarchy ส่วนนามแฝง `mup` จะอัปเดตเฉพาะเครื่องมือที่ mise จัดการเท่านั้น หากต้องการเพิ่มเครื่องมืออีกตัวลงในการกำหนดค่าของคุณเอง ให้ใช้ `mise use -g <tool>`

การตั้งค่า Python ยังติดตั้ง `uv` ผ่าน mise ด้วย การลบสภาพแวดล้อมสำหรับการพัฒนา Python ออกจะยังคงให้ `uv` ใช้งานได้ในฐานะเครื่องมืออิสระ

### การใช้การติดตั้งของคุณเอง

คำสั่งของ mise มาก่อน `~/.local/bin` บน `PATH` ดังนั้นเครื่องมือที่คุณติดตั้งด้วยตัวเอง เช่น ด้วยตัวติดตั้งของ Claude Code หรือของ Cursor เอง ก็ยังจะไปเรียกใช้สำเนาของ mise อยู่ดี แอปที่เปิดจากเดสก์ท็อปก็ค้นพบคำสั่งของ mise ก่อนแพ็กเกจของระบบเช่นกัน ดังนั้นแอปที่เรียกใช้ `gh` จะได้สำเนาของ mise แม้ว่าคุณจะติดตั้ง `github-cli` ด้วย pacman ไว้แล้ว และ mise จะติดตั้งสำเนานั้นตั้งแต่ครั้งแรกที่เรียกใช้ หากต้องการใช้สำเนาของคุณเองแทน ให้ปิดใช้งานสำเนาของ mise ใน `~/.config/mise/config.toml` ตัวอย่างเช่น ถ้าคุณติดตั้ง Cursor CLI ด้วยตัวเอง:

```toml
[settings]
disable_tools = ["cursor-agent"]
```

ถ้าคุณมีตาราง `[settings]` อยู่แล้ว ให้เพิ่มรายการเข้าไปตรงนั้น ขยายรายการ `disable_tools` ที่มีอยู่แทนที่จะแทนที่มัน ตรวจสอบให้แน่ใจว่าการติดตั้งของคุณอยู่บน `PATH` ใช้ชื่อเครื่องมือของ mise ซึ่งอาจแตกต่างจากคำสั่งของมันได้ เช่น `oh-my-pi` มีคำสั่งเป็น `omp` นอกจากนี้ตัวเรียกใช้เอเจนต์เริ่มต้นยังให้ความสำคัญกับ Cursor หรือ Muse ที่ผู้ใช้ติดตั้งไว้ใน `~/.local/bin` ก่อนด้วย

### การลบและคืนค่าเริ่มต้น

_Remove Preinstalls_ จะทำให้ mise ข้ามการประกาศเครื่องมือของ Omarchy สำหรับผู้ใช้ของคุณ โดยเพิ่มเครื่องมือเหล่านั้นลงใน `ignored_config_paths` ใน `~/.config/mise/miserc.toml` ส่วน _Restore Preinstalls_ จะลบบรรทัดนั้นออกอีกครั้ง เครื่องมือที่คุณประกาศด้วยตัวเอง ไม่ว่าจะอยู่ในการกำหนดค่าของคุณเองหรือใน `mise.toml` ของโปรเจกต์ ก็ยังคงทำงานต่อไปได้ทั้งสองกรณี ถ้าคุณเลือกเอเจนต์เริ่มต้นหรือตั้งค่า Python หลังจากลบสิ่งที่ติดตั้งมาล่วงหน้าออกแล้ว เครื่องมือตัวนั้นจะถูกเพิ่มลงในการกำหนดค่าของคุณเอง ทั้งสองอย่างนี้มีผลเฉพาะกับผู้ใช้ของคุณเท่านั้น ผู้ใช้คนอื่น ๆ บนเครื่องจะยังคงรักษาตัวเลือกของตัวเองไว้

## Docker

[Docker](https://www.docker.com/) แทบไม่จำเป็นต้องแนะนำอะไรกันอีกแล้ว มันช่วยให้คุณเรียกใช้คอนเทนเนอร์แบบแยกขาดจากกันได้ และ Omarchy ก็ติดตั้งทุกอย่างที่จำเป็นต่อการใช้งานมันได้อย่างดี รวมถึงตัว Docker เองและ [Docker Compose](https://docs.docker.com/compose/) ด้วย

ตามค่าเริ่มต้น ผู้ใช้ของคุณจะ *ไม่ได้* อยู่ในกลุ่ม `docker` กลุ่มนั้นมีผลเท่ากับ root ที่ไม่ต้องใช้รหัสผ่าน อะไรก็ตามที่อยู่ในกลุ่มนั้นสามารถใช้ `docker run -v /:/host` และเข้ายึดเครื่องได้ ดังนั้นสคริปต์หรือดีเพนเดนซีตัวร้ายเพียงตัวเดียวที่ทำงานในฐานะคุณอาจอยู่ห่างจาก root เพียงคำสั่งเดียวเท่านั้น ดังนั้นบนบรรทัดคำสั่ง คุณจึงต้องเรียกใช้ Docker ด้วย `sudo` (`sudo docker ps`, `sudo docker compose up`) ส่วนเครื่องมือแบบกราฟิกที่คุยกับดีมอน อย่างเช่น Windows VM จะขอการอนุญาตเมื่อจำเป็นต้องใช้ ถ้าคุณอยากได้ความสะดวกสบายของการตั้งค่าแบบไม่ต้องมีกลุ่มกลับคืนมาและเข้าใจถึงข้อแลกเปลี่ยนนี้แล้ว ให้เปิดใช้งานจาก **Setup > Security > Sudoless Docker** (หรือเรียกใช้ `omarchy-setup-security-sudoless-docker`) ซึ่งจะเพิ่มคุณเข้าไปในกลุ่ม `docker` หลังจากแสดงคำเตือนแล้ว จากนั้น `docker` แบบธรรมดาและนามแฝง `d` จะกลับมาทำงานได้โดยไม่ต้องใช้ `sudo` อีกครั้ง

คุณสามารถตั้งค่าฐานข้อมูลทั่วไปสำหรับการพัฒนาในเครื่องด้วย Docker ได้โดยใช้ _Install > Development > Docker DB_ ในเมนู Omarchy

## GitHub CLI

[GitHub CLI](https://cli.github.com/) พร้อมใช้งานในชื่อ `gh` สำหรับการทำงานกับที่เก็บโค้ด, issue และ pull request จากเทอร์มินัล เรียกใช้ `gh auth login` เพื่อติดตั้งมันในการใช้งานครั้งแรกและยืนยันตัวตน จากนั้นเรียกใช้ `gh repo clone org/repo` เพื่อโคลนที่เก็บโค้ด เรียกใช้ `gh --help` เพื่อสำรวจคำสั่งต่าง ๆ ของมัน

สำหรับอินเทอร์เฟซในเทอร์มินัลสำหรับ pull request ให้เรียกใช้ `ghui` โดย mise จะติดตั้งมันให้ในการใช้งานครั้งแรกเช่นกัน [Lazygit](https://github.com/jesseduffield/lazygit) ได้รับการติดตั้งมาล่วงหน้าสำหรับการทำงานกับ Git โดยเฉพาะ
