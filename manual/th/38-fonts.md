# ฟอนต์

Omarchy ใช้ JetBrainsMono Nerd Font เป็นทั้งฟอนต์ของเทอร์มินัลและฟอนต์ของระบบโดยค่าเริ่มต้น

 ![fonts-jetbrainsmono](images/fonts-jetbrainsmono.webp)

คุณเปลี่ยนสิ่งนี้ได้ผ่านเมนู _ลักษณะที่ปรากฏ > ฟอนต์_ ในเมนู Omarchy (`Super + Space`) การตั้งค่านี้จะตั้งค่าฟอนต์ monospace ในทุกที่: เทอร์มินัล แถบ และทุกอย่างอื่นที่ขอใช้ฟอนต์นี้

คุณติดตั้งฟอนต์สำหรับเขียนโปรแกรมยอดนิยมอื่น ๆ ได้ผ่าน _ติดตั้ง > สไตล์ > ฟอนต์_ ในเมนู Omarchy: Cascadia Mono, Meslo LG Mono, Fira Code, Victor Code, Bitstream Vera Mono และ Iosevka ล้วนอยู่ห่างเพียงคลิกเดียว ในเวอร์ชัน Nerd Font ของฟอนต์เหล่านั้น เพื่อให้สัญลักษณ์ต่าง ๆ ในแถบและเทอร์มินัลยังคงทำงานได้ หลังจากติดตั้งฟอนต์ใดฟอนต์หนึ่งแล้ว ให้เลือกฟอนต์นั้นภายใต้ _ลักษณะที่ปรากฏ > ฟอนต์_

## ภาษาจีน ภาษาญี่ปุ่น และภาษาเกาหลี

ภาษาจีน ภาษาญี่ปุ่น และภาษาเกาหลีใช้ตัวอักษรหลายตัวร่วมกัน แต่เขียนตัวอักษรบางตัวแตกต่างกัน ดังนั้นตัวอักษรเดียวกันจึงดูถูกต้องสำหรับผู้อ่านคนหนึ่ง แต่ดูแปลกสำหรับผู้อ่านอีกคนหนึ่ง การเลือกภาษาใดภาษาหนึ่งในเหล่านี้ภายใต้ _การตั้งค่า > ภูมิภาค > ภาษา_ หรือวิธีการป้อนข้อมูลของภาษานั้น จะตั้งค่ารูปแบบที่ตรงกัน หากต้องการเลือกด้วยตัวเอง ให้รัน `omarchy font cjk jp`, `kr`, `sc`, `tc` (ไต้หวัน) หรือ `hk` (ฮ่องกง) ในเทอร์มินัล; `omarchy font cjk default` จะกลับไปใช้ตัวเลือกของระบบ ซึ่งเป็นรูปแบบภาษาญี่ปุ่น ข้อความที่เว็บเพจหรือเอกสารระบุภาษาของตัวเองไว้ และเดสก์ท็อปทั้งหมดในขณะที่อยู่ในภาษาใดภาษาหนึ่งเหล่านี้ จะยังคงใช้รูปแบบของภาษานั้น
