# ฟอนต์

Omarchy ใช้ JetBrainsMono Nerd Font เป็นทั้งฟอนต์เทอร์มินัลและฟอนต์ระบบตามค่าเริ่มต้น

 ![fonts-jetbrainsmono](images/fonts-jetbrainsmono.webp)

คุณสามารถเปลี่ยนสิ่งนี้ได้ผ่านเมนู _รูปลักษณ์ > ฟอนต์_ ในเมนู Omarchy (`Super + Space`) การตั้งค่านั้นจะกำหนดฟอนต์ monospace ในทุกที่: เทอร์มินัล แถบ และสิ่งอื่นใดที่ร้องขอฟอนต์นั้น

คุณสามารถติดตั้งฟอนต์สำหรับเขียนโปรแกรมยอดนิยมอื่นๆ ได้ผ่าน _ติดตั้ง > สไตล์ > ฟอนต์_ ในเมนู Omarchy: Cascadia Mono, Meslo LG Mono, Fira Code, Victor Code, Bitstream Vera Mono และ Iosevka ล้วนอยู่ห่างเพียงคลิกเดียว ในเวอร์ชัน Nerd Font ของพวกมัน เพื่อให้สัญลักษณ์ในแถบและเทอร์มินัลยังคงทำงานต่อไป การติดตั้งฟอนต์ใดฟอนต์หนึ่งจะเปลี่ยนทั้งระบบไปใช้ฟอนต์นั้นด้วย และคุณสามารถเปลี่ยนกลับได้ทุกเมื่อภายใต้ _รูปลักษณ์ > ฟอนต์_

## ภาษาจีน ภาษาญี่ปุ่น และภาษาเกาหลี

ภาษาจีน ภาษาญี่ปุ่น และภาษาเกาหลีใช้ตัวอักษรร่วมกันหลายตัว แต่เขียนบางตัวแตกต่างกัน ดังนั้นตัวอักษรเดียวกันจึงดูถูกต้องสำหรับผู้อ่านคนหนึ่ง แต่ดูแปลกสำหรับผู้อ่านอีกคนหนึ่ง การเลือกภาษาใดภาษาหนึ่งเหล่านี้ภายใต้ _ตั้งค่า > ภูมิภาค > ภาษา_ หรือวิธีป้อนข้อมูลของภาษานั้น จะกำหนดรูปแบบที่ตรงกัน หากต้องการเลือกเอง ให้รัน `omarchy font cjk jp`, `kr`, `sc`, `tc` (ไต้หวัน) หรือ `hk` (ฮ่องกง) ในเทอร์มินัล; `omarchy font cjk default` จะกลับไปใช้ตัวเลือกของระบบ ซึ่งเป็นรูปแบบภาษาญี่ปุ่น ข้อความที่หน้าเว็บหรือเอกสารระบุภาษาของตนเองไว้ และเดสก์ท็อปทั้งหมดในขณะที่ใช้ภาษาใดภาษาหนึ่งเหล่านี้ จะยังคงใช้รูปแบบของภาษานั้น
