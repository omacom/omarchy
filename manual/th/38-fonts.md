# แบบอักษร

Omarchy ใช้ JetBrainsMono Nerd Font เป็นทั้งแบบอักษรของเทอร์มินัลและแบบอักษรของระบบตามค่าเริ่มต้น

 ![fonts-jetbrainsmono](images/fonts-jetbrainsmono.webp)

คุณเปลี่ยนสิ่งนี้ได้ผ่านเมนู _ลักษณะที่ปรากฏ > แบบอักษร_ ในเมนู Omarchy (`Super + Space`) ซึ่งจะตั้งค่าแบบอักษรแบบ monospace ในทุกที่: เทอร์มินัล แถบ และสิ่งอื่นใดที่ร้องขอแบบอักษรนั้น

คุณสามารถติดตั้งแบบอักษรสำหรับเขียนโปรแกรมยอดนิยมอื่น ๆ ได้ผ่าน _ติดตั้ง > สไตล์ > แบบอักษร_ ในเมนู Omarchy: Cascadia Mono, Meslo LG Mono, Fira Code, Victor Code, Bitstream Vera Mono และ Iosevka อยู่ห่างเพียงคลิกเดียว ในเวอร์ชัน Nerd Font ของพวกมัน เพื่อให้สัญลักษณ์ภาพในแถบและเทอร์มินัลยังคงใช้งานได้ หลังจากติดตั้งหนึ่งในนั้นแล้ว ให้เลือกมันภายใต้ _ลักษณะที่ปรากฏ > แบบอักษร_

## ภาษาจีน ญี่ปุ่น และเกาหลี

ภาษาจีน ญี่ปุ่น และเกาหลีใช้ตัวอักษรร่วมกันหลายตัว แต่เขียนบางตัวแตกต่างกัน ดังนั้นตัวอักษรเดียวกันจึงดูถูกต้องสำหรับผู้อ่านคนหนึ่ง แต่ดูแปลกสำหรับอีกคนหนึ่ง การเลือกหนึ่งในภาษาเหล่านี้ภายใต้ _การตั้งค่า > ภาษา_ หรือวิธีการป้อนข้อมูลของภาษานั้น จะตั้งค่ารูปแบบที่ตรงกัน หากต้องการเลือกด้วยตัวเอง ให้รัน `omarchy font cjk jp`, `kr`, `sc`, `tc` (ไต้หวัน) หรือ `hk` (ฮ่องกง) ในเทอร์มินัล; `omarchy font cjk default` จะกลับไปใช้ตัวเลือกของระบบ ซึ่งเป็นรูปแบบภาษาญี่ปุ่น ข้อความที่เว็บเพจหรือเอกสารระบุภาษาของตัวเองไว้ และเดสก์ท็อปทั้งหมดในขณะที่อยู่ในหนึ่งในภาษาเหล่านี้ จะคงรูปแบบของภาษานั้นไว้
