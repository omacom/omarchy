# แถบบน

แถบที่อยู่ตามแนวด้านบนของหน้าจอของคุณคือแถบ Omarchy มันไม่ใช่แถบสถานะที่ต่อพ่วงเข้ามา แต่เป็นส่วนหนึ่งของ Omarchy shell ซึ่งคือกระบวนการ Quickshell ระยะยาวเพียงตัวเดียวที่ยังวาดเมนู การแจ้งเตือน ป๊อปอัป OSD และหน้าจอล็อกด้วย นั่นคือเหตุผลที่มันเข้าธีมกับทุกสิ่งอื่นได้อย่างสมบูรณ์ และเหตุผลที่แผงเปิดขึ้นมาทันทีแทนที่จะสร้างแอปใหม่

มันยังเป็นส่วนเดียวของเดสก์ท็อปที่อยู่บนหน้าจอตลอดเวลา ดังนั้นจึงคุ้มค่าที่จะรู้ว่าสัญลักษณ์เล็ก ๆ เหล่านั้นทำอะไร

## มีอะไรบ้างตามค่าเริ่มต้น

แถบมีสามส่วน ทางซ้ายคือโลโก้ Omarchy (ตัวเรียกเมนู) และตัวบ่งชี้พื้นที่งาน ตรงกลางคุณจะได้ตัวบ่งชี้สถานะ นาฬิกา Elsewhen (นาฬิกาโลก) สภาพอากาศ และตราสัญลักษณ์การอัปเดต Omarchy ทางขวา: เค้าโครงแป้นพิมพ์ (เมื่อกำหนดไว้มากกว่าหนึ่งเค้าโครง) ถาดระบบ เอเจนต์ bluetooth เครือข่าย เสียง จอแสดงผล และพลังงาน

บางส่วนในนั้นจะแสดงเฉพาะเมื่อมันมีอะไรจะพูด เค้าโครงแป้นพิมพ์จะปรากฏเฉพาะถ้าคุณกำหนดเค้าโครงไว้มากกว่าหนึ่งเค้าโครง ตราสัญลักษณ์การอัปเดตจะปรากฏเฉพาะเมื่อมีการอัปเดต Omarchy รออยู่ และไอคอนเอเจนต์จะปรากฏครั้งแรกที่ Omarchy พบการใช้งานการเขียนโค้ดด้วย AI บนเครื่อง (ดู [AI](17-ai.md))

## การคลิกไปรอบ ๆ

วิดเจ็ตเกือบทุกตัวทำอะไรบางอย่างเมื่อคลิกซ้าย คลิกขวา และคลิกกลาง และหลายตัวตอบสนองต่อการเลื่อน นี่คือส่วนที่คนพลาด — ปุ่มขวาและปุ่มกลางคือที่ที่ของดีจำนวนมากซ่อนอยู่

| วิดเจ็ต | ซ้าย | ขวา | กลาง / เลื่อน |

| พื้นที่งาน | โฟกัสพื้นที่งานนั้น | — | เลื่อน: พื้นที่งานถัดไป/ก่อนหน้า |
| นาฬิกา | ป๊อปอัปปฏิทิน | หมุนรูปแบบป้ายกำกับ | กลาง: ตัวเลือกเขตเวลา |
| สภาพอากาศ | ป๊อปอัปพยากรณ์ | สภาพอากาศเต็มรูปแบบเป็นการแจ้งเตือน | กลาง: รีเฟรช |
| เสียง | แผงเสียง | ปิดเสียง | กลาง: แผง · เลื่อน: ระดับเสียง |
| ไมโครโฟน | ปิดเสียงไมโครโฟน | — | กลาง: แผงเสียง · เลื่อน: ระดับอินพุต |

ไม่ใช่ทุกอย่างในตารางนั้นที่อยู่บนแถบของคุณตั้งแต่แกะกล่อง วิดเจ็ตสื่อ (กำลังเล่น MPRIS พร้อมแทร็กและศิลปินที่เลื่อนได้) และวิดเจ็ตไมโครโฟนต่างก็มีมาให้ในตัวแต่ปิดอยู่ตามค่าเริ่มต้น — เพิ่มพวกมันเข้ามาหากคุณต้องการ ดังที่อธิบายไว้ด้านล่าง

## แผงต่าง ๆ

การคลิกไอคอนบนแถบจะเปิดแผง ซึ่งเป็นป๊อปอัปจริง ๆ พร้อมแถบเลื่อน รายการ และการนำทางด้วยคีย์บอร์ด แทนที่จะเป็นคำแนะนำแบบ tooltip แต่ละแผงยังมีปุ่มลัดด้วย ดังนั้นคุณไม่มีวันต้องเล็งไปที่สัญลักษณ์ขนาด 16 พิกเซล:

| ปุ่มลัด | แผง |
| --- | --- |
| `Super + Ctrl + A` | เสียง |
| `Super + Ctrl + W` | เครือข่าย |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | จอแสดงผล |
| `Super + Ctrl + P` | พลังงาน |
| `Super + Ctrl + Alt + D` | ปฏิทิน |
| `Super + Ctrl + Alt + E` | นาฬิกาโลก |
| `Super + Ctrl + 1-9` | สลับแผงลำดับที่ n ในส่วนด้านขวา |

แผงต่าง ๆ ไม่ใช่แค่จออ่านค่า พวกมันคือที่ที่คุณทำสิ่งนั้นจริง ๆ:

- **เสียง** มีแถบเลื่อนระดับเสียงหลัก ตัวเลือกอุปกรณ์เอาต์พุต และมิกเซอร์ต่อแอป ดังนั้นคุณลดเสียงแท็บเบราว์เซอร์นั้นลงได้โดยไม่แตะทุกสิ่งอื่น
- **เครือข่าย** สแกนหา Wi-Fi แสดงความแรงสัญญาณ เชื่อมต่อ และให้คุณเลือกผู้ให้บริการ DNS
- **Bluetooth** แสดงรายการอุปกรณ์ของคุณพร้อมการเชื่อมต่อ/ตัดการเชื่อมต่อและระดับแบตเตอรี่
- **พลังงาน** แสดงสถิติแบตเตอรี่ สลับโปรไฟล์พลังงาน (มันจำตัวเลือกแยกสำหรับแบตเตอรี่และ AC) และพิมพ์ข้อมูลระบบบางอย่าง
- **จอแสดงผล** มีแถบเลื่อนความสว่าง ขนาดตัวอักษร ค่าตั้งล่วงหน้าของมาตราส่วนจอภาพ และ — เมื่อคุณมีมากกว่าหนึ่งหน้าจอ — การควบคุมต่อจอภาพ ดู [จอภาพ](33-monitors.md) สำหรับเรื่องที่ลึกกว่านั้น
- **นาฬิกา** เปิดตารางรายเดือนพร้อมเลขสัปดาห์ ISO และการเปลี่ยนเดือน

ทุกแผงรองรับคีย์บอร์ดเช่นเดียวกับเมาส์: ลูกศรเลื่อน Return เปิดใช้งาน Tab ก้าวไปยังแผงข้าง ๆ และ Escape ปิด

`Super + Ctrl + 1-9` นับแผงจากซ้ายไปขวาในส่วนด้านขวา โดยข้ามถาดเนื่องจากมันไม่มีแผงของตัวเอง ดังนั้นตัวเลขจึงตรงกับไอคอนที่คุณชี้ไป

### Tailscale และ Dropbox

วิดเจ็ตอีกสองตัวจะปรากฏบนแถบเฉพาะเมื่อคุณติดตั้งบริการที่ตรงกันจาก **ติดตั้ง → บริการ** และทั้งสองตัวคุ้มค่าที่จะรู้เพราะพวกมันทำอะไรมากกว่าแค่รายงานสถานะ

แผง **Tailscale** เชื่อมต่อและตัดการเชื่อมต่อ tailnet สลับระหว่างบัญชี และเลือกโหนดออก (ทั้งเครื่องของคุณเองและภูมิภาคของ Mullvad ปรากฏในรายการนั้น) มันยังเรียกดูเครื่องของคุณด้วย — และเมื่อเลือกเครื่องหนึ่งแล้ว `s` จะส่งไฟล์ไปยังมันผ่าน Taildrop ซึ่งเป็นวิธีที่เร็วที่สุดในการย้ายไฟล์ไปยังโทรศัพท์หรือแล็ปท็อปอีกเครื่องของคุณ `c` คัดลอก IP ของเครื่อง `n` คัดลอกชื่อของมัน และ `d` คัดลอกชื่อ DNS แบบเต็มของมัน ยังมีปุ่มส่งบนแต่ละแถวเครื่องด้วย หากคุณอยากคลิกมากกว่า สิ่งเดียวกันจากเทอร์มินัลคือ `omarchy tailscale send <machine> [file...]`

แผง **Dropbox** จัดการการเข้าสู่ระบบ แสดงพื้นที่เก็บข้อมูลที่คุณใช้ไป และแสดงรายการไฟล์ที่ซิงค์เมื่อเร็ว ๆ นี้

การถอนการติดตั้งบริการตัวใดตัวหนึ่งในสองนั้นจะนำวิดเจ็ตของมันออกจากแถบ

## ตัวบ่งชี้

กลุ่มเล็ก ๆ ตรงกลางคือวิดเจ็ตตัวบ่งชี้ เหล่านี้คือสัญลักษณ์สถานะสำหรับโหมดที่คุณเปิดไว้: ห้ามรบกวน แสงกลางคืน [เครื่องเตือนความจำ](09-reminders.md) ที่เข้าแถวไว้ การอัดหน้าจอที่กำลังใช้งานอยู่ โหมดตื่นอยู่ และ [การพูดพิมพ์](11-text-extraction-dictation.md) พวกมันจะสว่างขึ้นเมื่อโหมดนั้นใช้งานอยู่ และไม่เกะกะในเวลาอื่น — ชี้ไปทางซ้ายของนาฬิกา (เหนือมันบนแถบแนวตั้ง) เพื่อแอบดูโหมดที่ไม่ได้ใช้งาน การคลิกตัวบ่งชี้จะสลับโหมดนั้น อีกตัวหนึ่งเป็นเพียงสถานะเท่านั้น: เซสชันระยะไกลจะสว่างเป็นสีแดงขณะที่ใครบางคนเชื่อมต่อกับเครื่องนี้ผ่าน gliff

ถ้าคุณอยากให้พวกมันมองเห็นตลอดเวลา ตั้ง `alwaysShow` เป็น `true` บนตัววิดเจ็ต และถ้าคุณสนใจเพียงบางตัว จาระแนกตัวที่คุณต้องการใน `items`: `["Dnd", "Reminder", "NightLight"]` คุณมีวิดเจ็ตตัวบ่งชี้ได้มากกว่าหนึ่งตัว ดังนั้นส่วนต่าง ๆ จึงแสดงชุดย่อยที่แตกต่างกันได้

## การจัดแถบใหม่

แถบกำหนดตัวมันเอง คุณไม่จำเป็นต้องเปิดไฟล์คอนฟิกเพื่อย้ายสิ่งต่าง ๆ

จับผืนที่ว่างของแถบบริเวณตรงกลางแล้วลากมันไปยังขอบหน้าจออื่น และแถบจะย้ายไปที่นั่น — ซ้าย ขวา บน หรือล่างใช้ได้ทั้งหมด และทุกวิดเจ็ตจะปรับตัวตาม (แถบแนวตั้งจะถอยไปเป็นรูปแบบเฉพาะไอคอนแบบกะทัดรัด) การคลิกค้างไว้ก็เริ่มการลากเดียวกัน ดับเบิลคลิกซ้ายบนพื้นที่ว่างเดียวกันเพื่อหมุนพื้นหลังของแถบจากใสไปเป็นกระจกไปเป็นทึบ และลากวิดเจ็ตใด ๆ เพื่อจัดลำดับของมันใหม่ หรือโยนมันไปยังส่วนอื่น

วิดเจ็ตที่คุณอยากเก็บไว้ใกล้มือแต่ไม่ได้อยากเห็นอยู่ตลอดเวลา ไปไว้ในลิ้นชักของถาดได้: ลากมันไปลงบนถาด และลิ้นชักจะเปิดออกมารับมัน มันจะอยู่ตรงนั้นตามหลังไอคอนแอปต่าง ๆ ปรากฏขึ้นเมื่อใดก็ตามที่ลิ้นชักปรากฏ และยังคงเปิดลิ้นชักค้างไว้ขณะที่แผงของมันเปิดอยู่ ลากมันกลับออกมายังแถบเพื่อนำมันกลับไป

ถ้าคุณอยากเลือกจากเมนูมากกว่า **สั่งการ → ลักษณะ → แถบเมนู** มีตำแหน่งนั้น และ **พื้นหลังแถบ** เลือกว่าจะวาดแถบอย่างไร: **แถบทึบ** **แถบกระจก** (มองทะลุได้ โดยมีสิ่งที่อยู่หลังมันพร่ามัว) หรือ **แถบใส**

สิ่งเดียวกันมีคำสั่ง ซึ่งเป็นสิ่งที่คุณต้องการสำหรับการตั้งค่าแบบ [dotfiles](31-dotfiles.md):

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.clock --section center --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

หากต้องการเพิ่มหรือลบวิดเจ็ตจำนวนมากทั้งหมด ให้ใช้คำสั่งปลั๊กอิน `omarchy plugin list` พิมพ์ทุกวิดเจ็ตที่ shell รู้จักพร้อม id ของมัน จากนั้น:

```bash
omarchy plugin enable omarchy.media --section center
omarchy plugin disable omarchy.weather
```

## การซ่อนแถบ

`Super + Shift + Space` สลับแถบปิดและเปิดอีกครั้งโดยไม่ฆ่า shell — แผงและปุ่มลัดยังคงทำงาน คุณแค่ได้พิกเซลคืน มันยังอยู่ในเมนูภายใต้ **สั่งการ → ลักษณะ → แถบเมนู → ซ่อนแถบ** ด้วย

## ไฟล์คอนฟิก

ทั้งหมดจัดเก็บอยู่ใน `~/.config/omarchy/shell.json` ภายใต้คีย์ `bar` นี่คือเวอร์ชันที่ตัดออกบางส่วน:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "centerAnchor": "omarchy.clock",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

ทุกวิดเจ็ตคือหนึ่งรายการในหนึ่งในสามอาร์เรย์เค้าโครง และการตั้งค่าของมันอยู่ที่รายการนั้นในตัว — ไม่มีไฟล์การตั้งค่าแยกและไม่มีออบเจ็กต์ย่อย `config` รูปแบบ `format` ของนาฬิกา `formatAlt` (สิ่งที่คลิกขวาหมุนไป) และ `verticalFormat` ทั้งหมดอยู่ตรงนั้นบน `{ "id": "omarchy.clock" }`

`centerAnchor` ตั้งชื่อวิดเจ็ตตรงกลางตัวหนึ่งที่ได้รับการปักหมุดให้อยู่ตรงกึ่งกลางหน้าจออย่างแม่นยำ โดยมีตัวอื่น ๆ อยู่ข้าง ๆ มัน นั่นคือวิธีที่นาฬิกายังคงอยู่ตรงกลางสนิทแม้ขณะที่สภาพอากาศและตราสัญลักษณ์การอัปเดตไป ๆ มา ๆ ตั้งให้เป็นสตริงว่างและรายการตรงกลางก็จะเป็นแค่กลุ่มที่อยู่กลางแทน

กฎข้อหนึ่งที่คุ้มค่าที่จะจดจำ: **เมื่อคุณมี `shell.json` ของตัวเองแล้ว มันคือหลักการชี้ขาด** จนกว่าคุณจะปรับแต่งอะไรก็ตาม shell จะอ่านไฟล์เริ่มต้นของ Omarchy ทันทีที่คุณลากวิดเจ็ต รัน `omarchy bar` หรือแก้ไขไฟล์นั้นด้วยตัวคุณเอง คุณเป็นเจ้าของมัน — ไม่มีการผสานแบบลึก ดังนั้นวิดเจ็ตเริ่มต้นใหม่ในรุ่น Omarchy ในอนาคตจะไม่ปรากฏบนแถบของคุณโดยอัตโนมัติ `omarchy bar defaults` นำเค้าโครงที่จัดส่งกลับมาเมื่อใดก็ตามที่คุณอยากเริ่มใหม่หมดจด

ไฟล์เดียวกันนั้นยังเก็บจังหวะเวลาว่างของคุณในระดับบนสุด นอกเหนือจากคีย์ `bar`: `idle.screensaver` และ `idle.lock` ทั้งสองอยู่ในหน่วยวินาทีนับตั้งแต่คุณว่าง ดังนั้นพักหน้าจอเริ่มต้นจะเริ่มที่ 150 วินาที และการล็อกที่ 300 วินาที
