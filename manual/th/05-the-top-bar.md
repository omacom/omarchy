# แถบด้านบน

แถบที่ทอดยาวไปตามด้านบนของหน้าจอคือแถบของ Omarchy มันไม่ใช่แถบสถานะที่ถูกจับมาติดเพิ่มภายหลัง แต่เป็นส่วนหนึ่งของเชลล์ Omarchy ซึ่งเป็นกระบวนการ Quickshell ที่ทำงานต่อเนื่องเพียงกระบวนการเดียว และยังเป็นตัววาดเมนู การแจ้งเตือน ป๊อปอัป OSD และหน้าจอล็อกอีกด้วย นั่นคือเหตุผลที่มันใช้ธีมเข้ากันได้อย่างสมบูรณ์แบบกับทุกอย่าง และเหตุผลที่แผงต่าง ๆ เปิดขึ้นมาทันทีแทนที่จะต้องเปิดแอปใหม่

มันยังเป็นส่วนเดียวของเดสก์ท็อปที่อยู่บนหน้าจอตลอดเวลา ดังนั้นจึงคุ้มค่าที่จะรู้ว่าสัญลักษณ์เล็ก ๆ เหล่านั้นทำอะไรบ้าง

## สิ่งที่อยู่บนแถบตามค่าเริ่มต้น

แถบมีสามส่วน ทางซ้ายคือโลโก้ Omarchy (ตัวเปิดเมนู) และตัวบ่งชี้พื้นที่ทำงาน ตรงกลางคุณจะได้ตัวบ่งชี้สถานะ นาฬิกา Elsewhen (นาฬิกาโลก) สภาพอากาศ และป้ายอัปเดต Omarchy ทางขวาคือถาดระบบ รูปแบบแป้นพิมพ์ (เมื่อตั้งค่าไว้มากกว่าหนึ่งรูปแบบ) เอเจนต์ บลูทูธ เครือข่าย เสียง จอแสดงผล และพลังงาน

บางอย่างในจำนวนนั้นจะปรากฏเฉพาะเมื่อมีเรื่องจะบอกเท่านั้น รูปแบบแป้นพิมพ์จะปรากฏเฉพาะเมื่อคุณตั้งค่าไว้มากกว่าหนึ่งรูปแบบ ป้ายอัปเดตจะปรากฏเฉพาะเมื่อมีอัปเดต Omarchy รออยู่ และไอคอนเอเจนต์จะปรากฏในครั้งแรกที่ Omarchy พบการใช้งาน AI coding บนเครื่อง (ดู [AI](17-ai.md))

## แผงต่าง ๆ

การคลิกไอคอนบนแถบจะเปิดแผง ซึ่งเป็นป๊อปอัปที่เหมาะสม มีแถบเลื่อน รายการ และการนำทางด้วยแป้นพิมพ์ แทนที่จะเป็นเพียงคำแนะนำเครื่องมือ แต่ละแผงยังมีปุ่มลัดอีกด้วย ดังนั้นคุณจึงไม่ต้องเล็งไปที่สัญลักษณ์ขนาด 16 พิกเซลเลย:

| ปุ่มลัด | แผง |
| --- | --- |
| `Super + Ctrl + A` | เสียง |
| `Super + Ctrl + N` | เครือข่าย |
| `Super + Ctrl + B` | บลูทูธ |
| `Super + Ctrl + D` | จอแสดงผล |
| `Super + Ctrl + P` | พลังงาน |
| `Super + Ctrl + Alt + D` | ปฏิทิน |
| `Super + Ctrl + Alt + E` | นาฬิกาโลก |
| `Super + Ctrl + 1-9` | เปิด/ปิดแผงที่ n ในส่วนด้านขวา |

แผงต่าง ๆ ไม่ใช่แค่ตัวแสดงข้อมูล พวกมันคือที่ที่คุณทำสิ่งนั้นจริง ๆ:

- **เสียง** มีแถบเลื่อนระดับเสียงหลัก ตัวเลือกอุปกรณ์ส่งออก และมิกเซอร์แยกตามแอป ดังนั้นคุณจึงหรี่เสียงแท็บเบราว์เซอร์แท็บเดียวนั้นได้โดยไม่กระทบอย่างอื่น
- **เครือข่าย** สแกนหา Wi-Fi แสดงความแรงของสัญญาณ เชื่อมต่อ และให้คุณเลือกผู้ให้บริการ DNS
- **บลูทูธ** แสดงรายการอุปกรณ์ของคุณพร้อมการเชื่อมต่อ/ตัดการเชื่อมต่อและระดับแบตเตอรี่
- **พลังงาน** แสดงสถิติแบตเตอรี่ สลับโปรไฟล์พลังงาน (มันจำตัวเลือกแยกต่างหากสำหรับแบตเตอรี่และ AC) และแสดงข้อมูลระบบบางอย่าง
- **จอแสดงผล** มีแถบเลื่อนความสว่าง ขนาดข้อความ ค่าที่ตั้งไว้ล่วงหน้าสำหรับการปรับขนาดจอภาพ และเมื่อคุณมีมากกว่าหนึ่งหน้าจอ ก็จะมีตัวควบคุมแยกตามจอภาพอีกด้วย ดูเรื่องราวที่ลึกกว่านี้ได้ที่ [จอภาพ](33-monitors.md)
- **นาฬิกา** เปิดตารางรายเดือนพร้อมหมายเลขสัปดาห์แบบ ISO และการเลื่อนเปลี่ยนเดือน
- **นาฬิกาโลก** เก็บหนึ่งแถวต่อหนึ่งเมือง พร้อมสภาพอากาศของเมืองนั้นและสภาพของวันในเมืองนั้น การค้นหาจะค้นหาเมืองต่าง ๆ รวมถึงเขตเวลาด้วย ดังนั้น Fort Lauderdale ก็คือ Fort Lauderdale ไม่ใช่ New York หากบรรทัดที่ด้านบนระบุเมืองผิด ให้คลิกที่บรรทัดนั้นแล้วบอกว่าคุณอยู่ที่ไหน เลือกที่ใดที่หนึ่งบนเขตเวลาอื่นแล้วนาฬิการะบบก็จะย้ายไปที่นั่นด้วย ซึ่งมีประโยชน์เมื่อคุณเดินทาง วางเมาส์เหนือเมืองแล้วคลิกปุ่มรูปคนเพื่อบอกว่าใครอาศัยอยู่ที่นั่น จะใช้ชื่อธรรมดา หรือใช้ชื่อผู้ใช้ GitHub ที่ขึ้นต้นด้วย `@` เพื่อดึงใบหน้าของพวกเขามาด้วยก็ได้

ทุกแผงรับคำสั่งจากแป้นพิมพ์เช่นเดียวกับเมาส์ ลูกศรใช้เลื่อน Return ใช้เปิดใช้งาน Tab ใช้ก้าวไปยังแผงข้างเคียง และ Escape ใช้ปิด

`Super + Ctrl + 1-9` จะนับแผงจากซ้ายไปขวาในส่วนด้านขวา โดยข้ามถาดไปเพราะถาดไม่มีแผงของตัวเอง ดังนั้นตัวเลขจึงตรงกับไอคอนที่คุณจะชี้ไป

### Tailscale และ Dropbox

วิดเจ็ตอีกสองตัวจะปรากฏบนแถบก็ต่อเมื่อคุณติดตั้งบริการที่ตรงกันจาก **Install → Service** และทั้งสองตัวก็คุ้มค่าที่จะรู้จักเพราะพวกมันทำได้มากกว่าแค่รายงานสถานะ

แผง **Tailscale** เชื่อมต่อและตัดการเชื่อมต่อ tailnet สลับระหว่างบัญชี และเลือก exit node (ทั้งเครื่องของคุณเองและภูมิภาค Mullvad จะปรากฏในรายการนั้น) มันยังเรียกดูเครื่องของคุณได้อีกด้วย และเมื่อเลือกเครื่องหนึ่งไว้แล้ว `s` จะส่งไฟล์ไปยังเครื่องนั้นผ่าน Taildrop ซึ่งเป็นวิธีที่เร็วที่สุดในการย้ายไฟล์ไปยังโทรศัพท์หรือแล็ปท็อปอีกเครื่องของคุณ `c` คัดลอก IP ของเครื่อง `n` คัดลอกชื่อของมัน และ `d` คัดลอกชื่อ DNS แบบเต็มของมัน นอกจากนี้ยังมีปุ่มส่งบนแต่ละแถวของเครื่องอีกด้วย หากคุณอยากคลิกมากกว่า การทำสิ่งเดียวกันจากเทอร์มินัลคือ `omarchy tailscale send <machine> [file...]`

แผง **Dropbox** จัดการการเข้าสู่ระบบ แสดงพื้นที่เก็บข้อมูลที่คุณใช้ไปแล้ว และแสดงรายการไฟล์ที่ซิงค์ล่าสุด

การลบบริการใดบริการหนึ่งออกจะนำวิดเจ็ตของมันออกจากแถบไปด้วย

## ตัวบ่งชี้

กลุ่มเล็ก ๆ ตรงกลางคือวิดเจ็ตตัวบ่งชี้ เหล่านี้คือสัญลักษณ์สถานะสำหรับโหมดที่คุณเปิดไว้ ได้แก่ ห้ามรบกวน แสงกลางคืน [ตัวเตือน](09-reminders.md) ที่อยู่ในคิว การบันทึกหน้าจอที่กำลังทำงานอยู่ การป้องกันไม่ให้เครื่องหลับ และ[การพูดเพื่อพิมพ์](11-text-extraction-dictation.md) พวกมันจะสว่างขึ้นเมื่อโหมดกำลังทำงานอยู่ และไม่เช่นนั้นก็จะหลบไปให้พ้นทาง วางเมาส์เหนือที่ใดก็ได้บนแถบเพื่อแอบดูตัวที่ไม่ได้ทำงานอยู่ การคลิกตัวบ่งชี้จะเปิด/ปิดโหมดนั้น อีกตัวหนึ่งมีไว้แสดงสถานะเท่านั้น เซสชันระยะไกลจะสว่างเป็นสีแดงขณะที่ใครบางคนเชื่อมต่อมายังเครื่องนี้ผ่าน gliff

หากคุณต้องการให้พวกมันมองเห็นได้ตลอดเวลา ให้ตั้งค่า `alwaysShow` เป็น `true` บนวิดเจ็ต และหากคุณสนใจแค่บางตัวเท่านั้น ให้ระบุตัวที่คุณต้องการใน `items`: `["Dnd", "Reminder", "NightLight"]` คุณสามารถมีวิดเจ็ตตัวบ่งชี้ได้มากกว่าหนึ่งตัว ดังนั้นส่วนต่าง ๆ จึงแสดงชุดย่อยที่ต่างกันได้

## การจัดเรียงแถบใหม่

แถบกำหนดค่าตัวเอง คุณไม่จำเป็นต้องเปิดไฟล์กำหนดค่าเพื่อย้ายสิ่งต่าง ๆ

จับพื้นที่ว่างบนแถบบริเวณตรงกลางแล้วลากไปยังขอบหน้าจออีกด้าน แล้วแถบจะย้ายไปที่นั่น ซ้าย ขวา บน หรือล่าง ใช้ได้ทั้งหมด และวิดเจ็ตทุกตัวก็ปรับตัวตาม (แถบแนวตั้งจะถอยกลับไปเป็นรูปแบบกะทัดรัดที่มีเฉพาะไอคอน) การคลิกค้างไว้ก็เริ่มการลากแบบเดียวกัน ดับเบิลคลิกซ้ายที่พื้นที่ว่างเดียวกันนั้นเพื่อสลับพื้นหลังของแถบจากใสไปเป็นแบบกระจกไปเป็นแบบทึบ และลากวิดเจ็ตใดก็ได้เพื่อจัดเรียงใหม่หรือโยนมันเข้าไปในส่วนอื่น วิดเจ็ตอื่น ๆ จะเลื่อนแยกออกจากกันเพื่อเปิดพื้นที่ตรงจุดที่มันจะลง

ตรงกลางของแถบเป็นกล่อง สิ่งใดก็ตามที่อยู่ในนั้นจะอยู่กึ่งกลางเป็นกลุ่มเดียวกัน และวิดเจ็ตที่อยู่ด้านใดด้านหนึ่งของมันจะห้อยอยู่ตามขอบของมัน ขณะที่คุณลากวิดเจ็ต กล่องจะแสดงเป็นเส้นขอบ หรือเป็นเส้นพาดผ่านแถบเมื่อมันว่างเปล่า และคุณสามารถวางลงในนั้นหรือข้าง ๆ มันได้ เมื่อการวางจะลงในกล่อง กล่องจะขยายเพื่อรับวิดเจ็ตนั้นเข้าไป

วิดเจ็ตที่คุณต้องการให้อยู่ใกล้ตัวแต่ไม่ต้องการให้มองเห็นตลอดเวลาสามารถเข้าไปอยู่ในลิ้นชักของถาดได้ ลากมันไปบนถาด แล้วลิ้นชักจะเปิดเพื่อรับมันเข้าไป มันจะอยู่ที่นั่นต่อจากไอคอนแอป ปรากฏขึ้นเมื่อใดก็ตามที่ลิ้นชักปรากฏ และจะคงเปิดลิ้นชักไว้ขณะที่แผงของมันเปิดอยู่ ลากมันกลับออกมาบนแถบเพื่อนำมันกลับมา

หากคุณอยากเลือกจากเมนูมากกว่า **Appearance → Menu Bar** มีตำแหน่งให้เลือก และ **Bar Background** จะเลือกวิธีวาดแถบ ได้แก่ **Opaque Bar**, **Glassy Bar** (โปร่งใส โดยมีสิ่งที่อยู่ด้านหลังถูกเบลอ) หรือ **Clear Bar**

สิ่งเดียวกันเหล่านี้มีคำสั่งให้ใช้ ซึ่งเป็นสิ่งที่คุณต้องการสำหรับการตั้งค่า [dotfiles](31-dotfiles.md):

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

หากต้องการเพิ่มหรือลบวิดเจ็ตออกทั้งหมด ให้ใช้คำสั่งปลั๊กอิน `omarchy plugin list` จะพิมพ์วิดเจ็ตทุกตัวที่เชลล์รู้จักพร้อม id ของมัน จากนั้น:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## การซ่อนแถบ

`Super + Shift + Space` จะปิดแถบและเปิดกลับมาโดยไม่ฆ่าเชลล์ แผงและปุ่มลัดยังคงทำงานต่อไป คุณเพียงแค่ได้พิกเซลกลับคืนมาเท่านั้น มันยังอยู่ในเมนูภายใต้ **Appearance → Menu Bar → Hide Bar** อีกด้วย

## ไฟล์กำหนดค่า

ทั้งหมดนี้ถูกเก็บไว้ใน `~/.config/omarchy/shell.json` ภายใต้คีย์ `bar` นี่คือเวอร์ชันที่ตัดทอนแล้ว:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

วิดเจ็ตทุกตัวเป็นหนึ่งรายการในหนึ่งในอาร์เรย์เลย์เอาต์ทั้งห้า และการตั้งค่าของมันอยู่แบบอินไลน์บนรายการนั้น ไม่มีไฟล์การตั้งค่าแยกต่างหากและไม่มีออบเจ็กต์ย่อย `config` ค่า `format`, `formatAlt` (สิ่งที่การคลิกขวาจะสลับไป) และ `verticalFormat` ของนาฬิกาล้วนอยู่ตรงนั้นบน `{ "id": "omarchy.clock" }`

`center` คือกล่องตรงกลางของแถบ ทุกอย่างในนั้นจะอยู่กึ่งกลางหน้าจอเป็นกลุ่มเดียวกัน `centerBegin` และ `centerEnd` จะห้อยอยู่ด้านใดด้านหนึ่งของกล่อง ซึ่งเป็นวิธีที่นาฬิกายังคงอยู่ตรงกลางอย่างแม่นยำแม้ว่าสภาพอากาศและป้ายอัปเดตจะมาและไป ใส่วิดเจ็ตมากกว่าหนึ่งตัวใน `center` แล้วพวกมันจะอยู่กึ่งกลางไปด้วยกัน ปล่อยให้มันว่างไว้แล้ว `centerBegin` และ `centerEnd` จะมาบรรจบกันตรงกลางแถบ

กฎข้อหนึ่งที่ควรซึมซับไว้: **เมื่อคุณมี `shell.json` ของตัวเองแล้ว มันคือฉบับที่เป็นทางการ** จนกว่าคุณจะปรับแต่งอะไรก็ตาม เชลล์จะอ่านไฟล์เริ่มต้นของ Omarchy ทันทีที่คุณลากวิดเจ็ต เรียกใช้ `omarchy bar` หรือแก้ไขไฟล์ด้วยตัวเอง คุณคือเจ้าของมัน ไม่มีการรวมแบบลึก ดังนั้นวิดเจ็ตเริ่มต้นใหม่ในรุ่น Omarchy ในอนาคตจะไม่ปรากฏบนแถบของคุณโดยอัตโนมัติ `omarchy bar defaults` จะนำเลย์เอาต์ที่มาพร้อมเครื่องกลับมาเมื่อใดก็ตามที่คุณต้องการเริ่มใหม่จากศูนย์

ไฟล์เดียวกันนี้ยังเก็บเวลาว่างของคุณไว้ที่ระดับบนสุด ภายนอกคีย์ `bar` ได้แก่ `idle.screensaver` และ `idle.lock` ทั้งคู่เป็นวินาทีนับตั้งแต่คุณไม่ได้ใช้งาน ดังนั้นโปรแกรมพักหน้าจอเริ่มต้นจะเริ่มทำงานที่ 150 วินาที และการล็อกจะเริ่มที่ 300 วินาที
