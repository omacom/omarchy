# แถบด้านบน

แถบยาวตามขอบบนของหน้าจอคือแถบ Omarchy มันไม่ใช่แถบสถานะที่จับมาติดเพิ่มทีหลัง แต่เป็นส่วนหนึ่งของเชลล์ Omarchy ซึ่งเป็นกระบวนการ Quickshell ตัวเดียวที่ทำงานต่อเนื่องยาวนาน และยังเป็นตัววาดเมนู การแจ้งเตือน ป๊อปอัป OSD และหน้าจอล็อกอีกด้วย นั่นคือเหตุผลที่ธีมของมันเข้ากันอย่างสมบูรณ์แบบกับทุกอย่างที่เหลือ และเหตุผลที่แผงควบคุมเปิดขึ้นมาทันทีแทนที่จะต้องเปิดแอปใหม่ขึ้นมา

มันยังเป็นชิ้นส่วนเดียวของเดสก์ท็อปที่อยู่บนหน้าจอตลอดเวลา จึงคุ้มค่าที่จะรู้ว่าสัญลักษณ์เล็กๆ ทั้งหมดนั้นทำอะไรบ้าง

## ค่าเริ่มต้นมีอะไรอยู่บนนั้นบ้าง

แถบมีสามส่วน ทางซ้ายคือโลโก้ Omarchy (ตัวเปิดเมนู) และตัวบ่งชี้พื้นที่ทำงาน ตรงกลางคุณจะได้ตัวบ่งชี้สถานะ นาฬิกา Elsewhen (นาฬิกาโลก) สภาพอากาศ และป้ายอัปเดต Omarchy ทางขวา: ถาดระบบ รูปแบบแป้นพิมพ์ (เมื่อกำหนดค่าไว้มากกว่าหนึ่งรูปแบบ) เอเจนต์ บลูทูธ เครือข่าย เสียง จอภาพ และพลังงาน

บางส่วนในนั้นจะปรากฏก็ต่อเมื่อมีเรื่องจะบอกเท่านั้น รูปแบบแป้นพิมพ์จะปรากฏก็ต่อเมื่อคุณกำหนดค่าไว้มากกว่าหนึ่งรูปแบบ ป้ายอัปเดตจะปรากฏก็ต่อเมื่อมีอัปเดต Omarchy รออยู่ และไอคอนเอเจนต์จะปรากฏครั้งแรกเมื่อ Omarchy พบการใช้งาน AI coding บนเครื่อง (ดู [AI](17-ai.md))

## แผงควบคุมต่างๆ

การคลิกไอคอนบนแถบจะเปิดแผงควบคุม ซึ่งเป็นป๊อปอัปเต็มรูปแบบที่มีแถบเลื่อน รายการ และการนำทางด้วยแป้นพิมพ์ แทนที่จะเป็นแค่คำแนะนำเครื่องมือ แต่ละแผงยังมีปุ่มลัดด้วย คุณจึงไม่ต้องเล็งไปที่สัญลักษณ์ขนาด 16 พิกเซลเลย:

| ปุ่มลัด | แผง |
| --- | --- |
| `Super + Ctrl + A` | เสียง |
| `Super + Ctrl + N` | เครือข่าย |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | จอภาพ |
| `Super + Ctrl + P` | พลังงาน |
| `Super + Ctrl + Alt + D` | ปฏิทิน |
| `Super + Ctrl + Alt + E` | นาฬิกาโลก |
| `Super + Ctrl + 1-9` | สลับแผงที่ n ในส่วนด้านขวา |

แผงเหล่านี้ไม่ใช่แค่ตัวแสดงค่าอ่าน มันคือที่ที่คุณลงมือทำสิ่งนั้นจริงๆ:

- **Audio** มีแถบเลื่อนระดับเสียงหลัก ตัวเลือกอุปกรณ์เอาต์พุต และมิกเซอร์แยกตามแอป คุณจึงหรี่เสียงแท็บเบราว์เซอร์แท็บเดียวนั้นได้โดยไม่ต้องแตะต้องอย่างอื่นเลย
- **Network** สแกนหา Wi-Fi แสดงความแรงของสัญญาณ เชื่อมต่อ และให้คุณเลือกผู้ให้บริการ DNS
- **Bluetooth** แสดงรายการอุปกรณ์ของคุณพร้อมการเชื่อมต่อ/ตัดการเชื่อมต่อและระดับแบตเตอรี่
- **Power** แสดงสถิติแบตเตอรี่ สลับโปรไฟล์พลังงาน (มันจำตัวเลือกแยกต่างหากสำหรับแบตเตอรี่และ AC) และแสดงข้อมูลระบบบางอย่าง
- **Display** มีแถบเลื่อนความสว่าง ขนาดข้อความ พรีเซ็ตการปรับสเกลจอภาพ และ — เมื่อคุณมีมากกว่าหนึ่งหน้าจอ — การควบคุมแยกตามจอ ดูเรื่องที่ลึกกว่านี้ได้ที่ [จอภาพ](33-monitors.md)
- **Clock** เปิดตารางรายเดือนที่มีหมายเลขสัปดาห์ ISO และการเลื่อนเปลี่ยนเดือน
- **World clock** เก็บบรรทัดสำหรับแต่ละเมือง พร้อมสภาพอากาศของเมืองนั้นและสภาพของวันนั้น การค้นหาค้นหาได้ทั้งเมืองและเขตเวลา Fort Lauderdale จึงเป็น Fort Lauderdale ไม่ใช่ New York ถ้าบรรทัดด้านบนระบุชื่อเมืองผิด ให้คลิกมันแล้วบอกว่าคุณอยู่ที่ไหน เลือกที่ไหนสักแห่งในเขตเวลาอื่น นาฬิการะบบก็จะย้ายไปที่นั่นด้วย ซึ่งสะดวกมากเวลาเดินทาง วางเมาส์เหนือเมืองแล้วคลิกปุ่มรูปคนเพื่อบอกว่าใครอาศัยอยู่ที่นั่น — ใช้ชื่อธรรมดา หรือแฮนเดิล GitHub ที่ขึ้นต้นด้วย `@` เพื่อดึงใบหน้าของพวกเขามาด้วย

ทุกแผงรับคำสั่งจากแป้นพิมพ์เช่นเดียวกับเมาส์: ลูกศรใช้เลื่อน Return ใช้เปิดใช้งาน Tab ใช้ก้าวไปยังแผงข้างเคียง และ Escape ใช้ปิด

`Super + Ctrl + 1-9` นับแผงจากซ้ายไปขวาในส่วนด้านขวา โดยข้ามถาดระบบไปเพราะมันไม่มีแผงของตัวเอง ตัวเลขจึงตรงกับไอคอนที่คุณจะชี้ไปนั่นเอง

### Tailscale และ Dropbox

วิดเจ็ตอีกสองตัวจะปรากฏบนแถบก็ต่อเมื่อคุณติดตั้งบริการที่ตรงกันจาก **Install → Service** เท่านั้น และทั้งสองตัวคุ้มค่าที่จะรู้จักเพราะมันทำได้มากกว่าแค่รายงานสถานะ

แผง **Tailscale** เชื่อมต่อและตัดการเชื่อมต่อ tailnet สลับระหว่างบัญชี และเลือก exit node (ทั้งเครื่องของคุณเองและภูมิภาค Mullvad ต่างก็ปรากฏในรายการนั้น) มันยังเรียกดูเครื่องต่างๆ ของคุณได้ด้วย — และเมื่อเลือกเครื่องหนึ่งไว้ `s` จะส่งไฟล์ไปให้เครื่องนั้นผ่าน Taildrop ซึ่งเป็นวิธีที่เร็วที่สุดในการย้ายไฟล์ไปยังโทรศัพท์หรือแล็ปท็อปอีกเครื่อง `c` คัดลอก IP ของเครื่อง `n` คัดลอกชื่อ และ `d` คัดลอกชื่อ DNS เต็มของมัน ในแต่ละแถวของเครื่องยังมีปุ่มส่งให้ด้วย ถ้าคุณอยากคลิกมากกว่า การทำสิ่งเดียวกันจากเทอร์มินัลคือ `omarchy tailscale send <machine> [file...]`

แผง **Dropbox** จัดการการเข้าสู่ระบบ แสดงว่าคุณใช้พื้นที่เก็บข้อมูลไปเท่าไร และแสดงรายการไฟล์ที่ซิงก์ล่าสุด

การนำบริการตัวใดตัวหนึ่งออกจะนำวิดเจ็ตของมันออกจากแถบไปด้วย

## ตัวบ่งชี้

กลุ่มเล็กๆ ตรงกลางคือวิดเจ็ตตัวบ่งชี้ เหล่านี้คือสัญลักษณ์สถานะสำหรับโหมดที่คุณเปิดไว้: ห้ามรบกวน ไฟกลางคืน [การเตือน](09-reminders.md) ที่อยู่ในคิว การบันทึกหน้าจอที่กำลังทำงานอยู่ การคงให้เครื่องตื่นอยู่ตลอด และ[การป้อนตามคำบอก](11-text-extraction-dictation.md) พวกมันจะสว่างขึ้นเมื่อโหมดทำงานอยู่ และในเวลาอื่นก็จะหลบไปให้พ้นทาง — วางเมาส์ไว้ข้างๆ พวกมันตรงจุดที่ตัวที่ไม่ได้ทำงานอยู่จะอยู่ เพื่อแอบดูพวกนั้น การคลิกตัวบ่งชี้จะสลับเปิด/ปิดโหมดนั้น อีกตัวหนึ่งเป็นสถานะอย่างเดียว: เซสชันระยะไกลจะสว่างเป็นสีแดงขณะที่ใครบางคนเชื่อมต่อเข้ามายังเครื่องนี้ผ่าน gliff

ถ้าคุณอยากให้พวกมันมองเห็นได้ตลอด ให้ตั้ง `alwaysShow` เป็น `true` บนวิดเจ็ต และถ้าคุณสนใจแค่บางตัว ให้ระบุตัวที่ต้องการใน `items`: `["Dnd", "Reminder", "NightLight"]` คุณมีวิดเจ็ตตัวบ่งชี้ได้มากกว่าหนึ่งตัว ส่วนต่างๆ จึงแสดงชุดย่อยที่แตกต่างกันได้

## การจัดเรียงแถบใหม่

แถบกำหนดค่าตัวเองได้ คุณไม่ต้องเปิดไฟล์การกำหนดค่าเพื่อย้ายสิ่งต่างๆ

จับพื้นที่ว่างของแถบบริเวณตรงกลางแล้วลากไปยังขอบหน้าจอด้านอื่น แถบก็จะย้ายไปที่นั่น — ซ้าย ขวา บน หรือล่าง ใช้ได้ทั้งหมด และทุกวิดเจ็ตปรับตัวตาม (แถบแนวตั้งจะถอยกลับไปเป็นรูปแบบกะทัดรัดที่มีเฉพาะไอคอน) การคลิกค้างไว้ก็เริ่มการลากแบบเดียวกัน ดับเบิลคลิกซ้ายที่พื้นที่ว่างเดียวกันนั้นเพื่อวนเปลี่ยนพื้นหลังของแถบจากใสเป็นแบบแก้วเป็นทึบแสง และลากวิดเจ็ตใดๆ เพื่อจัดลำดับใหม่หรือโยนมันเข้าไปในส่วนอื่น วิดเจ็ตอื่นๆ จะเลื่อนแยกออกจากกันเพื่อเปิดที่ว่างตรงจุดที่มันจะลงจอด

ตรงกลางของแถบเป็นกล่อง: อะไรก็ตามที่อยู่ในนั้นจะอยู่กึ่งกลางรวมกันเป็นกลุ่มเดียว และวิดเจ็ตที่อยู่สองข้างของมันจะห้อยอยู่ตามขอบของมัน ขณะที่คุณลากวิดเจ็ต กล่องจะแสดงเป็นเส้นขอบ หรือเป็นเส้นพาดผ่านแถบเมื่อมันว่างเปล่า และคุณวางลงในกล่องหรือข้างๆ กล่องก็ได้ เมื่อการวางจะลงในกล่อง กล่องจะขยายตัวเพื่อรับวิดเจ็ตเข้าไป

วิดเจ็ตที่คุณอยากให้อยู่ใกล้ตัวแต่ไม่อยากให้มองเห็นตลอดเวลา สามารถเข้าไปอยู่ในลิ้นชักของถาดระบบได้: ลากมันไปวางบนถาดระบบ ลิ้นชักจะเปิดออกเพื่อรับมันเข้าไป มันจะอยู่ที่นั่นต่อจากไอคอนแอป ปรากฏขึ้นเมื่อใดก็ตามที่ลิ้นชักปรากฏ และทำให้ลิ้นชักของมันเปิดค้างไว้ขณะที่แผงของมันเปิดอยู่ ลากมันกลับออกมาบนแถบเพื่อนำมันกลับไปไว้ที่เดิม

ถ้าคุณอยากเลือกจากเมนูมากกว่า **Appearance → Menu Bar** มีตำแหน่งให้เลือก และ **Bar Background** เลือกว่าจะวาดแถบอย่างไร: **Opaque Bar**, **Glassy Bar** (โปร่งใส โดยมีสิ่งที่อยู่ข้างหลังเบลอ) หรือ **Clear Bar**

สิ่งเดียวกันเหล่านี้มีคำสั่งด้วย ซึ่งเป็นสิ่งที่คุณต้องการสำหรับการตั้งค่า [dotfiles](31-dotfiles.md):

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

หากต้องการเพิ่มหรือนำวิดเจ็ตออกทั้งหมด ให้ใช้คำสั่งปลั๊กอิน `omarchy plugin list` จะพิมพ์วิดเจ็ตทุกตัวที่เชลล์รู้จักพร้อม id ของมัน จากนั้น:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## การซ่อนแถบ

`Super + Shift + Space` สลับแถบให้ปิดและเปิดกลับมาโดยไม่ต้องฆ่าเชลล์ — แผงและปุ่มลัดยังทำงานต่อไป คุณแค่ได้พิกเซลกลับคืนมา มันยังอยู่ในเมนูภายใต้ **Appearance → Menu Bar → Hide Bar** ด้วย

## ไฟล์การกำหนดค่า

ทั้งหมดนี้เก็บไว้ใน `~/.config/omarchy/shell.json` ภายใต้คีย์ `bar` นี่คือเวอร์ชันที่ตัดทอนมาแล้ว:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

ทุกวิดเจ็ตคือหนึ่งรายการในหนึ่งในอาร์เรย์เลย์เอาต์ทั้งห้า และการตั้งค่าของมันอยู่แบบอินไลน์บนรายการนั้น — ไม่มีไฟล์การตั้งค่าแยกต่างหากและไม่มีออบเจ็กต์ย่อย `config` `format`, `formatAlt` (สิ่งที่การคลิกขวาวนเปลี่ยนไป) และ `verticalFormat` ของนาฬิกาต่างก็อยู่ตรงนั้นบน `{ "id": "omarchy.clock" }`

`center` คือกล่องตรงกลางแถบ: ทุกอย่างในนั้นอยู่กึ่งกลางหน้าจอรวมกันเป็นกลุ่มเดียว `centerBegin` และ `centerEnd` ห้อยอยู่สองข้างของกล่อง ซึ่งเป็นวิธีที่นาฬิกาอยู่กึ่งกลางเป๊ะๆ แม้สภาพอากาศและป้ายอัปเดตจะมาๆ ไปๆ ก็ตาม ใส่วิดเจ็ตมากกว่าหนึ่งตัวใน `center` พวกมันก็จะอยู่กึ่งกลางรวมกัน เว้นว่างไว้ `centerBegin` และ `centerEnd` ก็จะมาบรรจบกันตรงกลางแถบ

กฎข้อหนึ่งที่คุ้มค่าที่จะซึมซับไว้: **เมื่อคุณมี `shell.json` ของตัวเองแล้ว มันคือตัวกำหนดหลัก** จนกว่าคุณจะปรับแต่งอะไรก็ตาม เชลล์จะอ่านไฟล์ค่าเริ่มต้นของ Omarchy ทันทีที่คุณลากวิดเจ็ต รัน `omarchy bar` หรือแก้ไขไฟล์ด้วยตัวเอง คุณคือเจ้าของมัน — ไม่มีการผสานแบบลึก วิดเจ็ตค่าเริ่มต้นใหม่ใน Omarchy รุ่นถัดไปจึงจะไม่ปรากฏบนแถบของคุณโดยอัตโนมัติ `omarchy bar defaults` จะนำเลย์เอาต์ที่มาพร้อมเครื่องกลับมาเมื่อใดก็ตามที่คุณต้องการเริ่มจากศูนย์

ไฟล์เดียวกันนี้ยังเก็บเวลาว่างงานของคุณไว้ที่ระดับบนสุด นอกคีย์ `bar` ด้วย: `idle.screensaver` และ `idle.lock` ทั้งคู่มีหน่วยเป็นวินาทีนับตั้งแต่คุณเริ่มว่างงาน โปรแกรมรักษาหน้าจอเริ่มต้นจึงเริ่มทำงานที่ 150 วินาที และการล็อกที่ 300 วินาที
