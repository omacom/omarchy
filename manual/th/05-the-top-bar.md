# แถบด้านบน

แถบที่อยู่ตามขอบด้านบนของหน้าจอคือแถบของ Omarchy มันไม่ใช่แถบสถานะที่เอามาติดเพิ่มทีหลัง แต่เป็นส่วนหนึ่งของเชลล์ Omarchy ซึ่งเป็นกระบวนการ Quickshell ที่ทำงานต่อเนื่องเพียงกระบวนการเดียว และยังวาดเมนู การแจ้งเตือน ป๊อปอัป OSD และหน้าจอล็อกด้วย นั่นคือเหตุผลที่มันเข้าธีมกับทุกอย่างได้อย่างสมบูรณ์แบบ และเหตุผลที่แผงเปิดขึ้นมาทันทีแทนที่จะต้องเรียกแอปใหม่ขึ้นมา

มันยังเป็นชิ้นส่วนเดียวของเดสก์ท็อปที่อยู่บนหน้าจอตลอดเวลา จึงคุ้มค่าที่จะรู้ว่าสัญลักษณ์เล็ก ๆ เหล่านั้นแต่ละตัวทำอะไร

## มีอะไรอยู่บนนั้นตามค่าเริ่มต้น

แถบมีสามส่วน ทางซ้ายคือโลโก้ Omarchy (ตัวเปิดเมนู) และตัวบ่งชี้พื้นที่ทำงาน ตรงกลางคุณจะได้ตัวบ่งชี้สถานะ นาฬิกา Elsewhen (นาฬิกาโลก) สภาพอากาศ และป้ายอัปเดต Omarchy ทางขวา: ถาดระบบ รูปแบบแป้นพิมพ์ (เมื่อมีการกำหนดค่ามากกว่าหนึ่งรูปแบบหรือวิธีป้อนข้อมูล) agents, bluetooth, เครือข่าย เสียง จอแสดงผล และพลังงาน

บางรายการในนั้นจะปรากฏเฉพาะเมื่อมีอะไรจะบอกเท่านั้น รูปแบบแป้นพิมพ์จะปรากฏเฉพาะเมื่อคุณกำหนดค่ามากกว่าหนึ่งรูปแบบหรือวิธีป้อนข้อมูล ป้ายอัปเดตจะปรากฏเฉพาะเมื่อมีอัปเดต Omarchy รออยู่

## แผงต่าง ๆ

การคลิกไอคอนบนแถบจะเปิดแผง ซึ่งเป็นป๊อปอัปแบบจริงจังที่มีแถบเลื่อน รายการ และการนำทางด้วยแป้นพิมพ์ แทนที่จะเป็นคำแนะนำเครื่องมือ แต่ละแผงยังมีปุ่มลัดด้วย คุณจึงไม่จำเป็นต้องเล็งไปที่สัญลักษณ์ขนาด 16 พิกเซลเลย:

| ปุ่มลัด | แผง |
| --- | --- |
| `Super + Ctrl + A` | เสียง |
| `Super + Ctrl + N` | เครือข่าย |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | จอแสดงผล |
| `Super + Ctrl + P` | พลังงาน |
| `Super + Ctrl + Alt + D` | ปฏิทิน |
| `Super + Ctrl + Alt + E` | นาฬิกาโลก |
| `Super + Ctrl + X` | Agents |
| `Super + Ctrl + 1-9` | สลับแผงที่ n ในส่วนด้านขวา |

แผงต่าง ๆ ไม่ใช่แค่ตัวแสดงข้อมูล พวกมันคือที่ที่คุณลงมือทำสิ่งนั้นจริง ๆ:

- **Audio** มีแถบเลื่อนระดับเสียงหลัก ตัวเลือกอุปกรณ์เอาต์พุต และมิกเซอร์แยกตามแอป คุณจึงลดเสียงแท็บเบราว์เซอร์แท็บนั้นแท็บเดียวได้โดยไม่กระทบทุกอย่างอื่น
- **Network** สแกนหา Wi-Fi แสดงความแรงของสัญญาณ เชื่อมต่อ และให้คุณเลือกผู้ให้บริการ DNS
- **Bluetooth** แสดงรายการอุปกรณ์ของคุณพร้อมการเชื่อมต่อ/ตัดการเชื่อมต่อและระดับแบตเตอรี่
- **Power** แสดงสถิติแบตเตอรี่ สลับโปรไฟล์พลังงาน (มันจำตัวเลือกแยกต่างหากสำหรับแบตเตอรี่และ AC) และพิมพ์ข้อมูลระบบบางอย่าง
- **Display** มีแถบเลื่อนความสว่าง ขนาดตัวอักษร พรีเซ็ตการปรับสเกลจอภาพ และ — เมื่อคุณมีมากกว่าหนึ่งหน้าจอ — การควบคุมแยกตามจอภาพ ดู [จอภาพ](33-monitors.md) สำหรับเรื่องราวที่ลึกกว่า
- **Clock** เปิดตารางเดือนพร้อมเลขสัปดาห์ ISO และการเลื่อนเปลี่ยนเดือน
- **World clock** เก็บหนึ่งแถวต่อหนึ่งเมือง พร้อมสภาพอากาศของเมืองนั้นและสภาพความเป็นไปของวันที่นั่น การค้นหาค้นหาเมืองต่าง ๆ ได้เช่นเดียวกับเขตเวลา ดังนั้น Fort Lauderdale ก็คือ Fort Lauderdale ไม่ใช่ New York ถ้าบรรทัดด้านบนระบุเมืองผิด ให้คลิกที่มันแล้วบอกว่าคุณอยู่ที่ไหน เลือกที่ไหนสักแห่งในเขตเวลาอื่น นาฬิการะบบก็จะย้ายไปที่นั่นด้วย ซึ่งสะดวกมากเมื่อคุณเดินทาง วางเมาส์ค้างเหนือเมืองแล้วคลิกปุ่มรูปคนเพื่อบอกว่าใครอาศัยอยู่ที่นั่น — ชื่อธรรมดา ๆ หรือแฮนเดิล GitHub ที่ขึ้นต้นด้วย `@` เพื่อพาใบหน้าของพวกเขามาด้วย

ทุกแผงรับแป้นพิมพ์ได้เช่นเดียวกับเมาส์: ลูกศรใช้เลื่อน Return ใช้เปิดใช้งาน Tab ใช้ก้าวไปยังแผงข้างเคียง และ Escape ใช้ปิด

`Super + Ctrl + 1-9` นับแผงจากซ้ายไปขวาในส่วนด้านขวา โดยข้ามถาดเพราะมันไม่มีแผงของตัวเอง ตัวเลขจึงตรงกับไอคอนที่คุณจะชี้ไปนั่นเอง

### Tailscale และ Dropbox

วิดเจ็ตอีกสองตัวจะปรากฏบนแถบเฉพาะเมื่อคุณติดตั้งบริการที่ตรงกันจาก **Install → Service** และทั้งสองตัวควรรู้จักไว้เพราะมันทำได้มากกว่าแค่รายงานสถานะ

แผง **Tailscale** เชื่อมต่อและตัดการเชื่อมต่อ tailnet สลับระหว่างบัญชี และเลือก exit node (ทั้งเครื่องของคุณเองและภูมิภาค Mullvad จะปรากฏในรายการนั้น) มันยังเรียกดูเครื่องต่าง ๆ ของคุณได้ด้วย — และเมื่อเลือกเครื่องหนึ่งไว้ `s` จะส่งไฟล์ไปยังเครื่องนั้นผ่าน Taildrop ซึ่งเป็นวิธีที่เร็วที่สุดในการย้ายไฟล์ไปยังโทรศัพท์หรือแล็ปท็อปอีกเครื่องของคุณ `c` คัดลอก IP ของเครื่อง `n` คัดลอกชื่อของมัน และ `d` คัดลอกชื่อ DNS เต็มของมัน ในแต่ละแถวของเครื่องยังมีปุ่มส่งด้วย ถ้าคุณอยากคลิกมากกว่า สิ่งเดียวกันจากเทอร์มินัลคือ `omarchy tailscale send <machine> [file...]`

แผง **Dropbox** จัดการการเข้าสู่ระบบ แสดงว่าคุณใช้พื้นที่เก็บข้อมูลไปเท่าไร และแสดงรายการไฟล์ที่ซิงค์ล่าสุด

การลบบริการใดบริการหนึ่งออกจะเอาวิดเจ็ตของมันออกจากแถบไปด้วย

## ตัวบ่งชี้

กลุ่มเล็ก ๆ ตรงกลางคือวิดเจ็ตตัวบ่งชี้ เหล่านี้คือสัญลักษณ์สถานะสำหรับโหมดที่คุณเปิดไว้: ห้ามรบกวน ไฟกลางคืน [การเตือนความจำ](09-reminders.md) ที่อยู่ในคิว การบันทึกหน้าจอที่กำลังทำงานอยู่ และไม่หลับ รวมถึงคำเตือนขณะที่ sudo แบบไม่ต้องใช้รหัสผ่านเปิดอยู่ หรือมีคนเชื่อมต่อมายังเซสชันระยะไกล พวกมันจะสว่างขึ้นเมื่อโหมดทำงานอยู่ และอย่างอื่นก็จะหลบทางให้ — วางเมาส์ค้างไว้ข้าง ๆ พวกมันตรงจุดที่ตัวที่ไม่ได้ทำงานจะอยู่ เพื่อแอบดูตัวเหล่านั้น การคลิกตัวบ่งชี้จะสลับโหมดนั้น อีกตัวหนึ่งเป็นสถานะอย่างเดียวเท่านั้น: เซสชันระยะไกลจะสว่างเป็นสีแดงขณะที่ใครบางคนเชื่อมต่อมายังเครื่องนี้ผ่าน gliff

ถ้าคุณอยากให้พวกมันมองเห็นอยู่เสมอ ให้ตั้ง `alwaysShow` เป็น `true` บนวิดเจ็ต และถ้าคุณสนใจแค่บางตัว ให้ระบุตัวที่คุณต้องการใน `items`: `["Dnd", "Reminder", "NightLight"]` คุณสามารถมีวิดเจ็ตตัวบ่งชี้ได้มากกว่าหนึ่งตัว ดังนั้นส่วนต่าง ๆ จึงแสดงชุดย่อยที่แตกต่างกันได้

## การจัดเรียงแถบใหม่

แถบกำหนดค่าตัวเอง คุณไม่ต้องเปิดไฟล์กำหนดค่าเพื่อย้ายสิ่งต่าง ๆ

จับพื้นที่ว่างของแถบบริเวณตรงกลางแล้วลากไปยังขอบหน้าจอด้านอื่น แถบก็จะย้ายไปที่นั่น — ซ้าย ขวา บน หรือล่าง ใช้ได้ทั้งหมด และวิดเจ็ตทุกตัวจะปรับตัวตาม (แถบแนวตั้งจะถอยไปเป็นรูปแบบกะทัดรัดที่มีเฉพาะไอคอน) การคลิกค้างไว้จะเริ่มการลากแบบเดียวกัน ดับเบิลคลิกซ้ายบนพื้นที่ว่างเดียวกันนั้นเพื่อวนเปลี่ยนพื้นหลังของแถบจากใสเป็นคล้ายกระจกเป็นทึบ และลากวิดเจ็ตใดก็ได้เพื่อจัดลำดับใหม่หรือโยนมันเข้าไปในส่วนอื่น วิดเจ็ตอื่น ๆ จะเลื่อนแยกออกจากกันเพื่อเปิดที่ว่างตรงจุดที่มันจะลง

ตรงกลางของแถบเป็นกล่อง: อะไรก็ตามที่อยู่ในนั้นจะอยู่ตรงกลางเป็นกลุ่มเดียว และวิดเจ็ตที่อยู่ด้านใดด้านหนึ่งของมันจะแขวนอยู่ตามขอบของมัน ขณะที่คุณลากวิดเจ็ต กล่องจะแสดงเป็นเส้นขอบ หรือเป็นเส้นพาดแถบเมื่อมันว่างเปล่า และคุณสามารถวางลงในนั้นหรือข้าง ๆ มันได้ เมื่อการวางจะลงในกล่อง กล่องจะขยายเพื่อรับวิดเจ็ตเข้าไป

วิดเจ็ตที่คุณอยากให้อยู่ใกล้ตัวแต่ไม่อยากให้มองเห็นตลอดสามารถเข้าไปอยู่ในลิ้นชักของถาดได้: ลากมันไปที่ถาด แล้วลิ้นชักจะเปิดออกเพื่อรับมันเข้าไป มันจะอยู่ที่นั่นต่อจากไอคอนแอป ปรากฏขึ้นเมื่อใดก็ตามที่ลิ้นชักปรากฏ และทำให้ลิ้นชักของมันเปิดค้างไว้ขณะที่แผงของมันเปิดอยู่ ลากมันกลับออกมาบนแถบเพื่อเอามันกลับคืน

ถ้าคุณอยากเลือกจากเมนูมากกว่า **Appearance → Menu Bar** มีตำแหน่ง และ **Bar Background** ใช้เลือกวิธีวาดแถบ: **Opaque Bar**, **Glassy Bar** (โปร่งใส โดยมีสิ่งที่อยู่ข้างหลังเบลอ) หรือ **Clear Bar**

สิ่งเดียวกันเหล่านี้มีคำสั่งด้วย ซึ่งเป็นสิ่งที่คุณต้องการสำหรับการตั้งค่า [dotfiles](31-dotfiles.md):

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

หากต้องการเพิ่มหรือเอาวิดเจ็ตออกทั้งหมด ให้ใช้คำสั่งปลั๊กอิน `omarchy plugin list` จะพิมพ์วิดเจ็ตทุกตัวที่เชลล์รู้จักพร้อม id ของมัน แล้วจากนั้น:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## การซ่อนแถบ

`Super + Shift + Space` สลับแถบให้ปิดและกลับมาเปิดโดยไม่ฆ่าเชลล์ — แผงและปุ่มลัดยังทำงานต่อไป คุณแค่ได้พิกเซลกลับคืนมา มันยังอยู่ในเมนูใต้ **Appearance → Menu Bar → Hide Bar** ด้วย

## ไฟล์กำหนดค่า

ทั้งหมดนี้ถูกเก็บไว้ใน `~/.config/omarchy/shell.json` ใต้คีย์ `bar` นี่คือเวอร์ชันที่ตัดทอนมาแล้ว:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

วิดเจ็ตทุกตัวเป็นหนึ่งรายการในหนึ่งในอาร์เรย์เค้าโครงทั้งห้า และการตั้งค่าของมันอยู่แบบอินไลน์บนรายการนั้นเลย — ไม่มีไฟล์การตั้งค่าแยกต่างหากและไม่มีออบเจ็กต์ย่อย `config` `format`, `formatAlt` (สิ่งที่การคลิกขวาวนเปลี่ยนไป) และ `verticalFormat` ของนาฬิกา ล้วนอยู่ตรงนั้นบน `{ "id": "omarchy.clock" }`

`center` คือกล่องตรงกลางแถบ: ทุกอย่างในนั้นจะอยู่ตรงกลางหน้าจอเป็นกลุ่มเดียว `centerBegin` และ `centerEnd` แขวนอยู่ด้านใดด้านหนึ่งของกล่อง ซึ่งเป็นวิธีที่นาฬิกายังคงอยู่ตรงกลางเป๊ะแม้สภาพอากาศและป้ายอัปเดตจะไป ๆ มา ๆ ใส่วิดเจ็ตมากกว่าหนึ่งตัวใน `center` พวกมันจะอยู่ตรงกลางด้วยกัน ปล่อยให้มันว่างเปล่า `centerBegin` และ `centerEnd` ก็จะมาบรรจบกันตรงกลางแถบ

กฎหนึ่งข้อที่ควรซึมซับไว้: **เมื่อคุณมี `shell.json` ของตัวเองแล้ว มันคือตัวกำหนดหลัก** จนกว่าคุณจะปรับแต่งอะไร เชลล์จะอ่านไฟล์ค่าเริ่มต้นของ Omarchy ทันทีที่คุณลากวิดเจ็ต เรียกใช้ `omarchy bar` หรือแก้ไขไฟล์ด้วยตัวเอง คุณคือเจ้าของมัน — ไม่มีการผสานแบบลึก ดังนั้นวิดเจ็ตค่าเริ่มต้นใหม่ ๆ ในรุ่น Omarchy ในอนาคตจะไม่ปรากฏบนแถบของคุณโดยอัตโนมัติ `omarchy bar defaults` จะเอารูปแบบที่จัดส่งมาให้กลับคืนมาเมื่อใดก็ตามที่คุณต้องการเริ่มจากศูนย์

ไฟล์เดียวกันนี้ยังเก็บเวลาการอยู่นิ่งของคุณไว้ที่ระดับบนสุด นอกคีย์ `bar`: `idle.screensaver` และ `idle.lock` ทั้งคู่เป็นวินาทีนับตั้งแต่คุณอยู่นิ่ง ดังนั้นโปรแกรมรักษาหน้าจอตามค่าเริ่มต้นจะเริ่มทำงานที่ 150 วินาที และการล็อกที่ 300 วินาที
