# แป้นพิมพ์ เมาส์ แทร็กแพด

Hyprland ให้คุณกำหนดค่าอุปกรณ์ป้อนข้อมูลทั้งหมดได้อย่างละเอียดมาก คุณสามารถเปลี่ยนการทำซ้ำของแป้นพิมพ์ให้เร็วเหนือเสียง หรือทำให้แทร็กแพดใช้การเลื่อนแบบธรรมชาติ คุณเปลี่ยนทั้งหมดได้ใน `~/.config/hypr/input.lua` ซึ่งเข้าถึงได้ผ่าน _Setup > Input_ ในเมนู Omarchy (`Super + Space`) เช่นกัน สิ่งใดก็ตามที่คุณตั้งไว้ที่นั่นจะแทนที่ค่าเริ่มต้นของ Omarchy

นี่คือตัวอย่าง:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

คุณสามารถ [ดูตัวเลือกการป้อนข้อมูลทั้งหมด](https://wiki.hypr.land/Configuring/Basics/Variables/#input) สำหรับอุปกรณ์ป้อนข้อมูลได้บนวิกิ Hyprland

CapsLock ทำงานเป็น Caps Lock ปกติ และ `Shift + CapsLock` เป็นปุ่ม compose สำหรับ [อิโมจิด่วน](07-hotkeys.md#quick-emojis) และ [การเติมข้อความด่วนอื่น ๆ](07-hotkeys.md#quick-completions) หากคุณต้องการให้ปุ่ม compose อยู่ตำแหน่งอื่น ให้แทนที่ `omarchy:shift_caps_compose` ใน `kb_options` ตัวอย่างเช่น โค้ดนี้ย้ายปุ่ม compose ไปที่ Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### ปุ่มฟังก์ชัน

แถวบนสุดของแป้นพิมพ์แล็ปท็อปจะส่งปุ่มสื่อ (ระดับเสียง ความสว่าง และอื่น ๆ) เป็นค่าเริ่มต้น และการกด `Fn` ค้างไว้จะให้ F1-F12; `Fn + Esc` จะล็อกสลับไปอีกแบบจนกว่าคุณจะกดอีกครั้ง แป้นพิมพ์ส่วนใหญ่จำการล็อกนั้นไว้เอง แล็ปท็อป ASUS และแป้นพิมพ์สไตล์ Apple ปล่อยให้ Linux จัดการ ซึ่งจะเริ่มต้นที่ปุ่มสื่อทุกครั้งที่บูต หากต้องการให้เริ่มต้นที่ F1-F12 แทน ให้รัน `omarchy device keyboard toprow fnkeys` (และ `omarchy device keyboard toprow mediakeys` เพื่อกลับไปแบบเดิม); ในแล็ปท็อปบางรุ่นจะมีผลหลังจากรีบูต Apple Silicon Macs ยังคงใช้การตั้งค่าของตัวเอง

### ท่าทางบนแทร็กแพด

ปัดบนแทร็กแพดเพื่อเคลื่อนที่ไปรอบ ๆ เดสก์ท็อป:

| ท่าทาง | การกระทำ |
| --- | --- |
| สามนิ้วไปทางซ้าย / ขวา | Workspace ก่อนหน้า / ถัดไป รวมถึง workspace ที่ว่างเปล่า |
| สามนิ้วขึ้น | สลับ AI console |
| สามนิ้วลง | เปิดเมนู Omarchy |
| สี่นิ้วไปทางซ้าย / ขวา | ย้ายหน้าต่างที่ใช้งานอยู่ไปยัง workspace ก่อนหน้า / ถัดไป |
| สี่นิ้วลง | สลับโหมดเต็มหน้าจอ |

หากต้องการเปลี่ยนท่าทางใดท่าทางหนึ่ง ให้ยกเลิกการตั้งค่าของท่าทางนั้นใน `~/.config/hypr/input.lua` ก่อนเพิ่ม [ท่าทางบนทัชแพด](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/) ของคุณเอง เนื่องจาก Hyprland จะไม่ยอมรับสองท่าทางที่ใช้จำนวนนิ้วและทิศทางเดียวกัน:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

หากต้องการปิดท่าทางทั้งหมดของ Omarchy ให้ตั้ง `omarchy_default_gestures = false` ไว้ใกล้ด้านบนของ `~/.config/hypr/hyprland.lua` ก่อนที่ค่าเริ่มต้นของ Omarchy จะโหลด

บนแล็ปท็อป Dell XPS ที่มีทัชแพดแบบสั่นตอบสนอง คุณสามารถตั้งความแรงของการคลิกเป็น low, mid, หรือ high ได้ภายใต้ _Trigger > Hardware > Touchpad Haptics_ เช่นกัน

### การพิมพ์ภาษาจีน ญี่ปุ่น และภาษาอื่น ๆ

เลือกภาษาญี่ปุ่น เกาหลี จีน (ตัวย่อ, Pinyin), ไต้หวัน (Zhuyin), หรือฮ่องกง (Cangjie) เมื่อโปรแกรมติดตั้งถามแป้นพิมพ์ของคุณ Omarchy จะกำหนดค่าแป้นพิมพ์และเครื่องมือป้อนข้อมูลที่ตรงกันโดยอัตโนมัติ รวมถึงระหว่างการตั้งค่าครั้งแรกแบบออฟไลน์เมื่อบูตครั้งแรก ภาษาญี่ปุ่นใช้ Mozc ภาษาเกาหลีใช้ Hangul แบบสองชุดมาตรฐาน ภาษาจีนตัวย่อใช้ Pinyin ไต้หวันใช้การจัดวาง Zhuyin มาตรฐานของ Chewing และฮ่องกงใช้ Cangjie พร้อมรูปแบบตัวอักษรฮ่องกง Japanese (US keyboard) ให้ Mozc พร้อมรูปแบบแป้นพิมพ์ US ปุ่ม Hangul, Zhuyin, และ Cangjie ยังคงอยู่ในตำแหน่งมาตรฐานแม้เมื่อคุณพิมพ์ตัวอักษรละตินด้วย Dvorak, Colemak, หรือ AZERTY หากคุณเพิ่ม Hangul หรือ Chewing ก่อนหน้านี้ ให้ยกเลิกการเลือกแล้วเลือกใหม่ภายใต้ _Setup > Keyboard > Input Methods_ เพื่อย้ายปุ่มของมันไปที่นั่น; Omarchy จะปล่อยเครื่องมือที่คุณใช้พิมพ์อยู่แล้วไว้ตามเดิม

การพิมพ์เริ่มต้นในโหมดละติน กด `Super + I` เพื่อวนผ่านวิธีการป้อนข้อมูลที่กำหนดค่าไว้ และ `Super + Shift + I` เพื่อวนย้อนกลับ แตะ `Shift` เพียงอย่างเดียวเพื่อก้าวออกจากวิธีการป้อนข้อมูลอย่าง Pinyin ไปสู่ตัวอักษรละติน และแตะอีกครั้งเพื่อกลับไป แบบเดียวกับที่ Sogou, Microsoft Pinyin, และ macOS ทำงาน; `Shift` พร้อมตัวอักษรยังคงพิมพ์ตัวพิมพ์ใหญ่ บนแป้นพิมพ์ญี่ปุ่น 全角/半角 สลับการป้อนข้อมูล 変換 เปิดใช้งาน และ 無変換 ปิดใช้งาน สำหรับภาษาเกาหลี 한/영 สลับ Hangul และ 한자 แปลงเป็น Hanja ไม่ว่าแป้นพิมพ์ของคุณจะมีปุ่มเฉพาะหรือส่ง Right Alt และ Right Ctrl สำหรับปุ่มเหล่านั้น อย่างที่แล็ปท็อปหลายรุ่นทำ ดังนั้น Right Alt และ Right Ctrl จึงไม่ใช่ปุ่ม modifier ธรรมดาที่นั่น; การเขียนตามคำบอกสลับด้วย Alt + Space แทน `Ctrl + Space` ยังคงพร้อมใช้สำหรับ Tmux และ Herdr; `Shift + CapsLock` ยังคงเป็นปุ่ม compose

ตัวบ่งชี้แป้นพิมพ์จะปรากฏทางด้านขวาของแถบเมื่อคุณมีรูปแบบแป้นพิมพ์หรือวิธีการป้อนข้อมูลหลายแบบ คลิกเพื่อสลับภาษาป้อนข้อมูล; ภาษาญี่ปุ่นแสดง あ สำหรับ hiragana สำหรับตัวเลือกตัวอักษรญี่ปุ่น ให้สลับไปภาษาญี่ปุ่น พิมพ์คำเช่น `nihongo` จากนั้นกด Space สองครั้ง กด Enter เพื่อยอมรับตัวเลือกของคุณ หากคุณมีรูปแบบแป้นพิมพ์หลายแบบด้วย ให้คลิกขวาที่ตัวบ่งชี้เพื่อวนผ่านรูปแบบเหล่านั้น

ใช้ _Setup > Keyboard > Keyboard Inputs_ เพื่อเลือกรูปแบบ เช่น ภาษาอังกฤษและภาษาฝรั่งเศส จากตัวเลือกเดียวกับที่เสนอระหว่างการติดตั้ง ใช้ _Setup > Keyboard > Input Methods_ เพื่อเลือกว่าเครื่องมือประกอบข้อความใดทำงานอยู่ ตัวเลือกทั้งสองเปิดภายในเมนู Omarchy โดยตัวเลือกปัจจุบันของคุณถูกทำเครื่องหมายไว้ คลิกหรือกด Enter เพื่อสลับตัวเลือก; การเปลี่ยนแปลงแต่ละครั้งมีผลทันที การยกเลิกการเลือกวิธีการป้อนข้อมูลจะลบมันออกจากวงจรโดยไม่ถอนการติดตั้ง; แป้นพิมพ์ยังคงพร้อมใช้

รัน `omarchy setup keyboard` หรือ `omarchy setup input` เพื่อเปิดตัวเลือกเดียวกัน หากต้องการเพิ่มภาษาเดียวจากบรรทัดคำสั่ง ให้ใช้ `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing`, หรือ `cangjie5` Quick, Boshiamy, และ Array มาอยู่ในแพ็กเกจเดียวกับ Cangjie และปรากฏในตัวเลือก Input Methods ปุ่มสลับที่คุณกำหนดเองจะถูกเก็บไว้ สำหรับรูปแบบหรือปุ่มของเครื่องมือทางเลือก ให้ติดตั้ง `fcitx5-configtool` ด้วย `omarchy pkg add fcitx5-configtool` และเปิดใช้จากเทอร์มินัล การเลือกภาษาป้อนข้อมูลจะไม่เปลี่ยนภาษาของเดสก์ท็อป การเลือกภาษาญี่ปุ่น เกาหลี หรือจีนภายใต้ _Setup > Language_ จะเพิ่มวิธีการป้อนข้อมูลของมันเมื่อคุณยังไม่มี

ใช้ `Super + I` เพื่อวนผ่านวิธีการป้อนข้อมูลหรือรูปแบบแป้นพิมพ์ และ `Super + Shift + I` เพื่อกลับไปอีกทาง ดังนั้นเมื่อกำหนดค่าไว้สามแบบ คุณสามารถเคลื่อนระหว่างสองแบบที่อยู่ติดกันได้ ตัวบ่งชี้การป้อนข้อมูลจะปรากฏทางด้านขวาของแถบเฉพาะเมื่อมีการกำหนดค่าวิธีการป้อนข้อมูลหรือรูปแบบมากกว่าหนึ่งแบบ การผูกคีย์บนเดสก์ท็อปนี้ทำงานควบคู่กับปุ่มสลับ Fcitx ที่มีอยู่ของคุณ; คุณสามารถแทนที่ได้ใน `~/.config/hypr/bindings.lua` เครื่องมือป้อนข้อมูลและลำดับ compose ใช้บริการ [Fcitx5](https://fcitx-im.org/) ที่ทำงานอยู่แล้วในทุกเซสชัน

### ใช้ ALT เป็น SUPER

บนแป้นพิมพ์บางรุ่น การใช้ปุ่ม meta หลัก (ปุ่ม Windows/cmd) เป็น SUPER ไม่สะดวก คุณสามารถเปลี่ยนให้เป็น ALT แทนได้ด้วยการเปลี่ยนแปลงนี้:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
