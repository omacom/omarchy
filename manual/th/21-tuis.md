# TUIs

## Lazygit

[Lazygit](https://github.com/jesseduffield/lazygit) เป็นทางเลือกที่น่าใช้แทนอะไรอย่างเช่นแอปพลิเคชัน GitHub Desktop และมันทำงานอยู่ภายในเทอร์มินัล

คุณสามารถรันมันโดยตรงได้ โดยไปยังไดเรกทอรีใดก็ตามที่จัดการด้วย git แล้วรัน `lazygit` หรือคุณสามารถรันมันภายใน Neovim ได้ ซึ่งสามารถเริ่มได้ด้วย `Space G G`

คุณสลับไปยังบานหน้าต่างต่าง ๆ ได้โดยใช้ `Tab` ในบานหน้าต่าง Files คุณเลือกไฟล์สำหรับ staging ได้โดยใช้ `Space` จากนั้นคุณสามารถสร้าง commit ใหม่ได้โดยใช้ `c` คุณสามารถดูคำสั่งที่มีทั้งหมดได้โดยใช้ `?`

## Btop

[Btop](https://github.com/aristocratos/btop) เป็นตัวจัดการทรัพยากรที่สวยงาม ซึ่งแสดงการใช้งานหน่วยความจำ CPU ดิสก์ และเครือข่าย มันยังแสดงรายการกระบวนการที่กำลังทำงานทั้งหมด และให้คุณจัดการกระบวนการเหล่านั้นได้ด้วย

Omarchy เรียกมันว่า Activity และคุณเริ่มมันได้โดยการกด `Super + Shift + T` มันจะเปิดเป็นหน้าต่างแบบลอย ซึ่งคุณสามารถจัดวางแบบไทล์ได้ด้วย `Super + T`

## Herdr

[Herdr](https://github.com/omacom-io/herdr) เป็นตัวจัดการพื้นที่ทำงานของเทอร์มินัลที่ให้ workspaces แท็บ และบานหน้าต่างแก่คุณ และทำให้ทั้งหมดนั้นทำงานต่อไปในเซสชันแบบถาวรที่คุณสามารถถอดออกและกลับเข้ามาใหม่ในภายหลังได้

คุณเริ่มมัน (หรือเชื่อมต่อกลับไปยังเซสชันที่มีอยู่ของคุณ) ได้ด้วย `Super + Ctrl + Return` Omarchy มาพร้อมกับการตั้งค่าของ Herdr ที่สะท้อนการตั้งค่าของ Tmux ดังนั้นคีย์ prefix ที่นี่จึงเป็น `Ctrl + Space` เช่นกัน คุณสามารถดูรายการการผูกคีย์ทั้งหมดได้ด้วย `Super + Ctrl + K`

## Fastfetch

[Fastfetch](https://github.com/fastfetch-cli/fastfetch) แสดงข้อมูลระบบ เช่น เวอร์ชัน kernel เวลาที่ระบบทำงาน ธีม CPU หน่วยความจำ และอื่น ๆ อีกมากมาย มันเป็นตัวต่อยอดจากเครื่องมือ neofetch ที่ได้รับความนิยม

Omarchy ได้จัดแพ็กเกจอันนี้ไว้เป็น _About_ ในเมนูของ Omarchy (`Super + Space`)

## Cliamp

[Cliamp](https://www.cliamp.stream/) เป็นเครื่องเล่นเพลงในเทอร์มินัลสไตล์เรโทรที่ได้แรงบันดาลใจจาก Winamp 2.x พร้อมด้วยสถานีวิทยุในตัวสำหรับ lo-fi beats เปิดใช้งานมันได้ด้วย `Super + Shift + Alt + M` หรือจากเมนูของ Omarchy ภายใต้ _Apps_ กด `?` เพื่อดูรายการการผูกคีย์แบบเต็ม

## แล้ว Wi-Fi และ Bluetooth ล่ะ?

คุณจะไม่พบ TUI สำหรับ Wi-Fi และ Bluetooth — งานเหล่านั้นเป็นของเชลล์ของ Omarchy คลิกไอคอน Wi-Fi ในแถบด้านบน (หรือกด `Super + Ctrl + N`) เพื่อดูเครือข่ายและเชื่อมต่อ และคลิกไอคอน Bluetooth (หรือกด `Super + Ctrl + B`) เพื่อจับคู่และเชื่อมต่ออุปกรณ์ ดู [ระบบเครือข่าย](35-networking.md) สำหรับเรื่องราวฉบับเต็ม

## การเพิ่มของคุณเอง

โปรแกรมเทอร์มินัลใด ๆ ก็สามารถได้รับการดูแลแบบแอปเต็มรูปแบบได้ ไปที่ _Install > TUI_ ในเมนูของ Omarchy (`Super + Space`) ตั้งชื่อ คำสั่งสำหรับเปิดใช้งาน สไตล์หน้าต่าง และไอคอนให้มัน แล้วมันจะปรากฏในตัวเปิดแอปเหมือนกับแอปพลิเคชันอื่น ๆ คุณลบมันออกอีกครั้งได้ภายใต้ _Remove > TUI_
