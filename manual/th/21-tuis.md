# TUIs

## Lazygit

[Lazygit](https://github.com/jesseduffield/lazygit) เป็นทางเลือกที่น่าเพลิดเพลินแทนที่อะไรอย่างแอปพลิเคชัน GitHub Desktop และมันทำงานอยู่ภายในเทอร์มินัล

คุณสามารถเรียกใช้มันได้โดยตรง โดยเข้าไปยังไดเรกทอรีใด ๆ ที่จัดการโดย git แล้วเรียกใช้ `lazygit` หรือคุณสามารถเรียกใช้มันภายใน Neovim ก็ได้ ซึ่งสามารถเริ่มได้ด้วย `Space G G`

คุณสลับไปมาระหว่างบานหน้าต่างต่าง ๆ โดยใช้ `Tab` ในบานหน้าต่าง Files คุณเลือกไฟล์สำหรับ staging โดยใช้ `Space` จากนั้นคุณสามารถสร้าง commit ใหม่ได้โดยใช้ `c` คุณสามารถดูคำสั่งทั้งหมดที่มีได้โดยใช้ `?`

## Btop

[Btop](https://github.com/aristocratos/btop) เป็นตัวจัดการทรัพยากรที่สวยงามซึ่งแสดงการใช้งานหน่วยความจำ CPU ดิสก์ และเครือข่าย นอกจากนี้ยังแสดงรายการโปรเซสที่กำลังทำงานอยู่ทั้งหมด และช่วยให้คุณจัดการโปรเซสเหล่านั้นได้

Omarchy เรียกมันว่า Activity Monitor และคุณสามารถเริ่มมันได้จากตัวเปิดแอปหรือโดยการกด `Super + Shift + T` มันจะเปิดขึ้นเป็นหน้าต่างแบบลอย ซึ่งคุณสามารถจัดวางแบบไทล์ได้ด้วย `Super + T`

## Herdr

[Herdr](https://github.com/omacom-io/herdr) เป็นตัวจัดการพื้นที่ทำงานในเทอร์มินัลที่มอบ workspaces, tabs และ panes ให้คุณ และทำให้ทั้งหมดยังคงทำงานอยู่ในเซสชันแบบถาวรที่คุณสามารถถอดตัวออกมาแล้วกลับมาในภายหลังได้

คุณสามารถเริ่มมัน (หรือเชื่อมกลับไปยังเซสชันที่มีอยู่ของคุณ) ได้ด้วย `Super + Ctrl + Return` Omarchy มาพร้อมกับการกำหนดค่า Herdr ที่สะท้อนการกำหนดค่า Tmux ของมัน ดังนั้นคีย์ prefix จึงเป็น `Ctrl + Space` ที่นี่ด้วยเช่นกัน คุณสามารถเรียกดูการผูกคีย์ทั้งหมดได้ด้วย `Super + Ctrl + K`

## Fastfetch

[Fastfetch](https://github.com/fastfetch-cli/fastfetch) แสดงข้อมูลระบบ เช่น เวอร์ชัน kernel, uptime, theme, CPU, หน่วยความจำ และอื่น ๆ อีกมากมาย มันเป็นตัวตายตัวแทนของเครื่องมือ neofetch ที่ได้รับความนิยม

Omarchy ได้บรรจุสิ่งนี้ไว้เป็น _About_ ในเมนู Omarchy (`Super + Space`)

## Cliamp

[Cliamp](https://www.cliamp.stream/) เป็นเครื่องเล่นเพลงในเทอร์มินัลสไตล์เรโทรที่ได้รับแรงบันดาลใจจาก Winamp 2.x พร้อมด้วยสถานีวิทยุในตัวสำหรับบีต lo-fi เปิดใช้มันด้วย `Super + Shift + Alt + M` หรือจากเมนู Omarchy ภายใต้ _Apps_ กด `?` เพื่อดูรายการการผูกคีย์ทั้งหมด

## แล้ว Wi-Fi และ Bluetooth ล่ะ?

คุณจะไม่พบ TUI สำหรับ Wi-Fi และ Bluetooth — งานเหล่านั้นเป็นของเชลล์ Omarchy คลิกไอคอน Wi-Fi ในแถบด้านบน (หรือกด `Super + Ctrl + N`) เพื่อดูเครือข่ายและเชื่อมต่อ และคลิกไอคอน Bluetooth (หรือกด `Super + Ctrl + B`) เพื่อจับคู่และเชื่อมต่ออุปกรณ์ ดู [เครือข่าย](35-networking.md) สำหรับเรื่องราวทั้งหมด

## เพิ่มของคุณเอง

โปรแกรมเทอร์มินัลใด ๆ ก็สามารถได้รับการดูแลแบบแอปเต็มรูปแบบได้ ไปที่ _Install > TUI_ ในเมนู Omarchy (`Super + Space`) ตั้งชื่อให้มัน ใส่คำสั่งเปิดใช้งาน สไตล์หน้าต่าง และไอคอน แล้วมันจะปรากฏในตัวเปิดแอปเหมือนกับแอปพลิเคชันอื่น ๆ คุณยังสามารถลบมันออกอีกครั้งได้ภายใต้ _Remove > TUI_
