# TUIs

## Lazygit

[Lazygit](https://github.com/jesseduffield/lazygit) เป็นทางเลือกที่น่าใช้แทนอะไรอย่างแอปพลิเคชัน GitHub Desktop และมันทำงานอยู่ภายในเทอร์มินัล

คุณสามารถเรียกใช้มันได้โดยตรง โดยเข้าไปที่ไดเรกทอรีใดก็ได้ที่จัดการด้วย git แล้วรัน `lazygit` หรือคุณจะรันมันภายใน Neovim ก็ได้ ซึ่งที่นั่นสามารถเปิดมันได้ด้วย `Space G G`

คุณสลับไปมาระหว่างบานหน้าต่างต่าง ๆ ได้โดยใช้ `Tab` ในบานหน้าต่าง Files คุณเลือกไฟล์สำหรับ staging ได้โดยใช้ `Space` จากนั้นคุณสามารถสร้าง commit ใหม่ได้โดยใช้ `c` คุณสามารถดูคำสั่งทั้งหมดที่มีได้โดยใช้ `?`

## Btop

[Btop](https://github.com/aristocratos/btop) เป็นตัวจัดการทรัพยากรที่สวยงาม ซึ่งแสดงการใช้งานหน่วยความจำ, CPU, ดิสก์ และเครือข่าย มันยังแสดงรายการกระบวนการที่กำลังทำงานอยู่ทั้งหมด และให้คุณจัดการกระบวนการเหล่านั้นได้

Omarchy เรียกมันว่า Activity Monitor และคุณเปิดมันได้จากตัวเปิดแอป หรือโดยการกด `Super + Shift + T` มันจะเปิดขึ้นมาเป็นหน้าต่างลอย ซึ่งคุณสามารถจัดวางแบบเรียงต่อกันได้ด้วย `Super + T`

## Herdr

[Herdr](https://herdr.dev) เป็นตัวจัดการพื้นที่ทำงานในเทอร์มินัลที่ให้เวิร์กสเปซ แท็บ และบานหน้าต่างแก่คุณ และเก็บทุกอย่างให้ทำงานต่อไปในเซสชันแบบถาวรที่คุณสามารถแยกตัวออกมาและกลับมาภายหลังได้

คุณเปิดมัน (หรือเชื่อมกลับเข้าสู่เซสชันที่มีอยู่ของคุณ) ได้จากตัวเปิดแอป หรือด้วย `Super + Ctrl + Return` Omarchy มาพร้อมกับการกำหนดค่า Herdr ที่สอดคล้องกับการกำหนดค่า Tmux ของมัน ดังนั้นคีย์ prefix ที่นี่ก็คือ `Ctrl + Space` เช่นกัน คุณสามารถเรียกดูการผูกคีย์ทั้งหมดได้ด้วย `Super + Ctrl + K`

## Fastfetch

[Fastfetch](https://github.com/fastfetch-cli/fastfetch) แสดงข้อมูลระบบ เช่น เวอร์ชันเคอร์เนล เวลาที่ระบบทำงานมานาน ธีม CPU หน่วยความจำ และอื่น ๆ มันเป็นตัวต่อยอดจากเครื่องมือ neofetch ยอดนิยม

Omarchy ได้จัดแพ็กเกจสิ่งนี้ไว้เป็น _ระบบ > เกี่ยวกับ_ ในเมนู Omarchy (`Super + Space`)

## Cliamp

[Cliamp](https://www.cliamp.stream/) เป็นเครื่องเล่นเพลงในเทอร์มินัลสไตล์เรโทรที่ได้รับแรงบันดาลใจจาก Winamp 2.x มาพร้อมกับสถานีวิทยุในตัวสำหรับบีท lo-fi เปิดมันด้วย `Super + Shift + Alt + M` หรือจากเมนู Omarchy ภายใต้ _แอป_ กด `?` เพื่อดูรายการการผูกคีย์ทั้งหมด

## แล้ว Wi-Fi กับ Bluetooth ล่ะ?

คุณจะไม่พบ TUI สำหรับ Wi-Fi และ Bluetooth — งานเหล่านั้นเป็นของเชลล์ Omarchy คลิกไอคอน Wi-Fi ในแถบบน (หรือกด `Super + Ctrl + N`) เพื่อดูเครือข่ายและเชื่อมต่อ และคลิกไอคอน Bluetooth (หรือกด `Super + Ctrl + B`) เพื่อจับคู่และเชื่อมต่ออุปกรณ์ ดู [ระบบเครือข่าย](35-networking.md) สำหรับเรื่องราวทั้งหมด

## เพิ่มของคุณเอง

โปรแกรมเทอร์มินัลใด ๆ ก็ได้รับการดูแลแบบแอปเต็มรูปแบบได้ ไปที่ _ติดตั้ง > TUI_ ในเมนู Omarchy (`Super + Space`) ตั้งชื่อให้มัน ใส่คำสั่งเปิดใช้งาน สไตล์หน้าต่าง และไอคอน แล้วมันจะปรากฏในตัวเปิดแอปเหมือนกับแอปพลิเคชันอื่น ๆ คุณสามารถลบมันอีกครั้งได้ภายใต้ _ลบออก > TUI_
