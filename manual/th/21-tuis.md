# TUIs

## Lazygit

[Lazygit](https://github.com/jesseduffield/lazygit) เป็นทางเลือกที่น่าพอใจแทนอะไรอย่างแอปพลิเคชัน GitHub Desktop และมันรันอยู่ภายในเทอร์มินัล

คุณสามารถรันมันโดยตรง โดยไปที่ไดเรกทอรีใดก็ได้ที่จัดการโดย git แล้วรัน `lazygit` หรือคุณจะรันมันภายใน Neovim ก็ได้ โดยเริ่มด้วย `Space G G`

คุณกระโดดไปมาระหว่างบานต่าง ๆ ด้วย `Tab` ในบาน Files คุณเลือกไฟล์สำหรับ staging ด้วย `Space` จากนั้นคุณก็สร้าง commit ใหม่ได้ด้วย `c` คุณดูคำสั่งทั้งหมดที่มีได้ด้วย `?`

## Btop

[Btop](https://github.com/aristocratos/btop) เป็นตัวจัดการทรัพยากรที่สวยงาม แสดงการใช้หน่วยความจำ CPU ดิสก์ และเครือข่าย มันยังแสดงกระบวนการที่ सक्रियอยู่ทั้งหมด และให้คุณจัดการพวกมันได้

Omarchy เรียกมันว่า Activity และคุณเริ่มมันโดยกด `Super + Ctrl + T` มันเปิดเป็นหน้าต่างลอย ซึ่งคุณปูกระเบื้องได้ด้วย `Super + T`

## Herdr

[Herdr](https://github.com/omacom-io/herdr) เป็นตัวจัดการพื้นที่งานเทอร์มินัลที่ให้คุณมีพื้นที่งาน แท็บ และบาน และเก็บทั้งหมดให้รันต่อไปในเซสชันคงอยู่ที่คุณถอดออกและกลับมาทีหลังได้

คุณเริ่มมัน (หรือแนบกลับไปที่เซสชันที่มีอยู่ของคุณ) ด้วย `Super + Ctrl + Return` Omarchy มาพร้อมการกำหนดค่า Herdr ที่สะท้อนคอนฟิก Tmux ของมัน ดังนั้นปุ่มนำหน้าก็คือ `Ctrl + Space` ที่นี่เช่นกัน คุณสามารถเรียกดูปุ่มลัดทั้งหมดได้ด้วย `Super + Ctrl + K`

## Fastfetch

[Fastfetch](https://github.com/fastfetch-cli/fastfetch) แสดงข้อมูลระบบ เช่น เวอร์ชันเคอร์เนล เวลาทำงาน ธีม CPU หน่วยความจำ และอื่น ๆ มันคือผู้สืบทอดของเครื่องมือ neofetch ยอดนิยม

Omarchy จัดทำสิ่งนี้เป็น _เกี่ยวกับ_ ในเมนู Omarchy (`Super + Space`)

## Cliamp

[Cliamp](https://www.cliamp.stream/) เป็นเครื่องเล่นเพลงเทอร์มินัลย้อนยุคที่ได้แรงบันดาลใจจาก Winamp 2.x พร้อมสถานีวิทยุในตัวสำหรับจังหวะ lo-fi เปิดมันด้วย `Super + Shift + Alt + M` หรือจากเมนู Omarchy ใต้ _แอป_ กด `?` สำหรับรายการปุ่มลัดฉบับเต็ม

## แล้ว Wi-Fi กับ Bluetooth ล่ะ?

คุณจะไม่พบ TUI สำหรับ Wi-Fi และ Bluetooth — งานเหล่านั้นเป็นของ shell ของ Omarchy คลิกไอคอน Wi-Fi ในแถบเมนู (หรือกด `Super + Ctrl + W`) เพื่อดูเครือข่ายและเชื่อมต่อ และคลิกไอคอน Bluetooth (หรือกด `Super + Ctrl + B`) เพื่อจับคู่และเชื่อมต่ออุปกรณ์ ดูเรื่องราวฉบับเต็มได้ที่ [เครือข่าย](35-networking.md)

## เพิ่มของคุณเอง

โปรแกรมเทอร์มินัลใด ๆ ก็ได้รับการดูแลแบบแอปเต็มรูปแบบได้ ไปที่ _ติดตั้ง > TUI_ ในเมนู Omarchy (`Super + Space`) ตั้งชื่อให้มัน ใส่คำสั่งเปิด รูปแบบหน้าต่าง และไอคอน แล้วมันจะโผล่ขึ้นมาในตัวเปิดแอปเหมือนแอปพลิเคชันอื่น ๆ คุณสามารถนำมันออกอีกครั้งได้ที่ _นำออก > TUI_
