# การแก้ไขปัญหา

### ฉันทำระบบพังตอนอัปเดต!

ก่อนอื่นให้ลอง [ย้อนกลับระบบของคุณ](47-system-snapshots.md) ไปเป็นเวอร์ชันก่อนการอัปเดตล่าสุดของคุณ หากไม่ได้ผล ให้ใช้ `omarchy-debug` เพื่อแชร์ปัญหาของคุณใน #omarchy-help ใน Discord และหากทั้งหมดนั้นไม่ได้ผล คุณสามารถติดตั้งค่ากำหนดเริ่มต้นและแพ็กเกจใหม่ได้โดยใช้ `omarchy-reinstall`

### ทำไมบางแอปถึงใหญ่เหลือเกินบนจอของฉัน?

Omarchy สันนิษฐานว่าคุณใช้จอความละเอียดสูงแบบ 2x ดังนั้นจึงตั้งค่า `GDK_SCALE` เป็น 2 จนกว่าคุณจะเลือกสเกลในแผงจอภาพ หากคุณใช้จอแบบ 1x และแอป GTK หรือ X11 ออกมาใหญ่เกินขนาด ให้เลือก 1x ให้กับจอนั้นในแผงจอภาพ หรือเพิ่ม `hl.env("GDK_SCALE", "1")` ลงใน `~/.config/hypr/monitors.lua` (จากนั้นรีสตาร์ทแอปใดก็ตามที่มีขนาดใหญ่เกินไป) ดู [คู่มือเรื่องจอภาพ](33-monitors.md)

สำหรับ Spotify คุณสามารถใช้ `Ctrl + Minus` เพื่อย่อ UI ให้เล็กลงได้ (และ `Ctrl + Plus` เพื่อทำให้ใหญ่ขึ้น)

### ทำไมคีย์ลัด Super ของฉันถึงหยุดทำงานทั้งหมด?

บนแล็ปท็อป ASUS ROG และ TUF บางรุ่น `Fn + Super` เป็นคีย์ลัดที่พลาดกันได้ง่าย ซึ่งจะสลับการล็อกปุ่ม Windows ในเฟิร์มแวร์ (มีไว้สำหรับการเล่นเกมเพื่อที่คุณจะได้ไม่ออกจากเกมโดยไม่ตั้งใจ) ไม่มีอะไรบนหน้าจอบอกคุณว่าเกิดเรื่องนี้ขึ้น ขณะที่การล็อกเปิดอยู่ Super จะไม่ส่งอะไรออกมาเลย — ดังนั้นคีย์ลัด Omarchy ทุกตัวที่ใช้ Super จะหยุดทำงานไปเฉย ๆ และดูเหมือนว่า Hyprland พัง

กด `Fn + Super` หนึ่งครั้งก่อนที่คุณจะไปขุดคุ้ยใน `~/.config/hypr/` และหากนั่นไม่ทำให้ Super กลับมา ให้กดอีกครั้งเพื่อที่คุณจะได้ไม่ปล่อยให้การล็อกเปิดค้างไว้ นี่ไม่ใช่ Fn-lock ซึ่งเปลี่ยนเฉพาะการทำงานของแถวปุ่ม F เท่านั้น

### Wi-Fi, Bluetooth, เสียง หรือแทร็กแพดของฉันหยุดทำงานไปเฉย ๆ

ก่อนรีบูต ให้ลองรีสตาร์ทระบบย่อยที่มีปัญหานั้นแยกต่างหาก _Update > Hardware_ ในเมนู Omarchy มี Wi-Fi, Bluetooth, Audio และ Trackpad และการโหลดหนึ่งในนั้นใหม่จะแก้สถานการณ์ส่วนใหญ่แบบ "เมื่อห้านาทีก่อนยังใช้ได้อยู่เลย" ได้ — หูฟัง Bluetooth ที่ไม่ยอมเชื่อมต่อใหม่ แทร็กแพดที่ตายไปหลัง suspend เสียงที่หายไปตอนคุณถอดจอออก

### ทำไมลำโพงภายนอกของฉันถึงไม่มีเสียง?

น่าจะเป็นเพราะยังไม่ได้ตั้งค่าให้เป็นเอาต์พุตหลัก คลิกที่ไอคอนลำโพงทางด้านขวาของแถบ แล้วมันจะเปิดป๊อปอัประดับเสียงขึ้นมา ซึ่งคุณสามารถเลือกอุปกรณ์เอาต์พุตได้ (และมิกซ์ระดับเสียงแยกตามแอปได้ด้วย)

### ลำโพงแล็ปท็อปของฉันเสียงฟังดูแปลก ๆ

บนแล็ปท็อปบางรุ่น Omarchy จะใช้การปรับแต่งลำโพงโดยอัตโนมัติเพื่อแก้ไขการตอบสนองความถี่ของลำโพงในตัว `omarchy audio tuning status` จะบอกคุณว่ามีการใช้งานอยู่บนเครื่องของคุณหรือไม่ และ `omarchy audio tuning off` จะปิดมันหากคุณอยากฟังเสียงลำโพงแบบดิบ ๆ มากกว่า

### ทำไมฉันเข้าสู่ระบบหรือใช้ sudo ด้วยรหัสผ่านของฉันไม่ได้?

คุณอาจพิมพ์ผิดหลายครั้งเกินไปจนถูกล็อก หากเรื่องนี้เกิดขึ้นบนหน้าจอล็อก คุณสามารถกด `CTRL + ALT + F2` เพื่อเริ่ม TTY ใหม่ ซึ่งคุณสามารถเข้าสู่ระบบเป็น root ได้ จากนั้นรัน `faillock --reset --user [your-username]` นั่นจะรีเซ็ตการล็อก และคุณก็พร้อมใช้งานต่อ

### ทำไมพรอมต์การอนุญาตของ 1Password สำหรับ 1Password SSH Agent / CLI ของฉันถึงไม่ปรากฏ?

เรื่องนี้อาจเกิดขึ้นได้จาก 2 สาเหตุ:

เพื่อให้พรอมต์การอนุมัติแบบ rich ปรากฏขึ้น ต้องเปิด Settings > Advanced > Use Hardware Acceleration _หมายเหตุ: ต้องรีบูตเพื่อให้เริ่มทำงาน_

 ![troubleshooting-1password](images/troubleshooting-1password.webp)

หรือหากคุณยังไม่ได้เปิด 1Password ตั้งแต่บูตเครื่อง พรอมต์ก็จะไม่ปรากฏ
