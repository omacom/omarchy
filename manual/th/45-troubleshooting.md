# การแก้ไขปัญหา

### ฉันทำระบบพังเพราะการอัปเดต!

ลอง [ย้อนกลับระบบของคุณ](47-system-snapshots.md) ไปยังเวอร์ชันก่อนการอัปเดตล่าสุดของคุณก่อน หากไม่ได้ผล ให้ใช้ `omarchy-debug` เพื่อแชร์ปัญหาของคุณใน #omarchy-help ใน Discord และหากทั้งหมดนั้นยังไม่ได้ผล คุณสามารถติดตั้งค่าคอนฟิกและแพ็กเกจเริ่มต้นใหม่ได้โดยใช้ `omarchy-reinstall`

### ทำไมบางแอปถึงใหญ่เหลือเกินบนจอแสดงผลของฉัน?

Omarchy สันนิษฐานว่าคุณใช้จอแสดงผลความละเอียดสูงแบบ 2x จึงตั้งค่า `GDK_SCALE` เป็น 2 จนกว่าคุณจะเลือกอัตราส่วนในแผงจอมอนิเตอร์ หากคุณใช้จอแสดงผลแบบ 1x และแอป GTK หรือ X11 มีขนาดใหญ่เกินไป ให้เลือก 1x สำหรับจอนั้นในแผงจอมอนิเตอร์ หรือเพิ่ม `hl.env("GDK_SCALE", "1")` ลงใน `~/.config/hypr/monitors.lua` (จากนั้นรีสตาร์ทแอปใด ๆ ที่มีขนาดใหญ่เกินไป) ดู [คู่มือเรื่องจอมอนิเตอร์](33-monitors.md)

สำหรับ Spotify คุณสามารถใช้ `Ctrl + Minus` เพื่อย่อ UI ให้เล็กลงได้ (และใช้ `Ctrl + Plus` เพื่อขยายให้ใหญ่ขึ้น)

### ทำไมคีย์ลัด Super ของฉันถึงหยุดทำงานทั้งหมด?

บนแล็ปท็อป ASUS ROG และ TUF บางรุ่น `Fn + Super` เป็นคีย์ผสมที่พลาดกันได้ง่าย ซึ่งจะสลับการล็อกปุ่ม Windows ในระดับเฟิร์มแวร์ (มีไว้สำหรับเล่นเกม เพื่อไม่ให้คุณออกจากเกมโดยไม่ตั้งใจ) ไม่มีอะไรบนหน้าจอบอกคุณเลยว่าเกิดเรื่องนี้ขึ้น ขณะที่การล็อกเปิดอยู่ Super จะไม่ส่งอะไรออกมาเลย — คีย์ลัด Omarchy ทุกตัวที่ใช้ Super จึงหยุดทำงานเฉย ๆ และดูเหมือน Hyprland พังไปแล้ว

กด `Fn + Super` หนึ่งครั้งก่อนที่คุณจะไปขุดคุ้ยใน `~/.config/hypr/` และหากกดแล้ว Super ยังไม่กลับมา ให้กดอีกครั้งเพื่อที่คุณจะได้ไม่เปิดการล็อกทิ้งไว้ นี่ไม่ใช่ Fn-lock ซึ่งเปลี่ยนเฉพาะการทำงานของแถวปุ่ม F เท่านั้น

### Wi-Fi, Bluetooth, เสียง หรือแทร็กแพดของฉันหยุดทำงานไปเฉย ๆ

ก่อนรีบูต ให้ลองรีสตาร์ทระบบย่อยที่มีปัญหาแยกต่างหากก่อน _Update > Hardware_ ในเมนู Omarchy มี Wi-Fi, Bluetooth, Audio และ Trackpad และการโหลดหนึ่งในนั้นใหม่จะแก้สถานการณ์แบบ "เมื่อห้านาทีก่อนยังใช้ได้อยู่" ส่วนใหญ่ได้ — หูฟัง Bluetooth ที่ไม่ยอมเชื่อมต่อใหม่ แทร็กแพดที่ตายไปหลังปลุกจาก suspend เสียงที่หายไปเมื่อคุณถอดจอมอนิเตอร์ออก

### ทำไมลำโพงภายนอกของฉันถึงไม่มีเสียง?

เป็นไปได้มากว่าเพราะยังไม่ได้ตั้งให้เป็นอุปกรณ์ส่งออกหลัก คลิกที่ไอคอนลำโพงทางด้านขวาของแถบ แล้วมันจะเปิดป๊อปอัประดับเสียงขึ้นมา ซึ่งคุณสามารถเลือกอุปกรณ์ส่งออกได้ (และปรับระดับเสียงแยกตามแอปได้ด้วย)

### ลำโพงแล็ปท็อปของฉันเสียงแปลก ๆ

บนแล็ปท็อปบางรุ่น Omarchy จะปรับจูนลำโพงโดยอัตโนมัติเพื่อแก้ไขการตอบสนองความถี่ของลำโพงในตัว `omarchy audio tuning status` จะบอกคุณว่ามีการปรับจูนที่เปิดใช้งานอยู่บนเครื่องของคุณหรือไม่ และ `omarchy audio tuning off` จะปิดมันหากคุณอยากฟังเสียงลำโพงแบบดิบ ๆ มากกว่า

### ทำไมฉันถึงล็อกอินหรือใช้ sudo ด้วยรหัสผ่านไม่ได้?

คุณอาจพิมพ์ผิดหลายครั้งเกินไปจนถูกล็อกออก หากเรื่องนี้เกิดขึ้นที่หน้าจอล็อก คุณสามารถกด `CTRL + ALT + F2` เพื่อเริ่ม TTY ใหม่ ซึ่งคุณสามารถล็อกอินเป็น root ได้ จากนั้นรัน `faillock --reset --user [your-username]` คำสั่งนั้นจะรีเซ็ตการล็อกออก แล้วคุณก็ใช้งานต่อได้เลย

### รหัสผ่านของฉันผ่าน แต่ฉันกลับมาที่หน้าจอล็อกอิน

ไฟล์สภาพแวดล้อมของเซสชันที่เสียหายสามารถขัดขวางไม่ให้เดสก์ท็อปเริ่มทำงานได้ แม้รหัสผ่านของคุณจะถูกต้องก็ตาม เรื่องนี้ควรตรวจสอบเป็นพิเศษหลังจากแก้ไข `~/.config/uwsm/env.d/`

กด `Ctrl + Alt + F2` ล็อกอินด้วยชื่อผู้ใช้และรหัสผ่านปกติของคุณ แล้วตรวจสอบ journal ของผู้ใช้ในการบูตปัจจุบัน:

```bash
journalctl --user -b -t uwsm_env-preloader --no-pager
```

มองหาข้อผิดพลาดที่ระบุชื่อไฟล์สภาพแวดล้อมไฟล์หนึ่งของคุณ เช่น `bad substitution` ซึ่งอยู่ก่อนข้อความที่บอกว่าไม่พบเครื่องหมายเอาต์พุตของ env ย้ายไฟล์นั้นออกจาก `env.d` ก่อนลองล็อกอินอีกครั้ง ตัวอย่างเช่น หากข้อผิดพลาดระบุชื่อ `99-custom`:

```bash
mkdir -p ~/.config/uwsm/disabled
mv -i ~/.config/uwsm/env.d/99-custom ~/.config/uwsm/disabled/
```

UWSM จะข้ามไฟล์ที่มีข้อผิดพลาดทางไวยากรณ์ แต่ข้อผิดพลาดร้ายแรงที่ปรากฏเฉพาะตอนไฟล์ทำงาน เช่น `bad substitution` ก็ยังสามารถขัดขวางไม่ให้เดสก์ท็อปเริ่มทำงานได้ การย้อนกลับ snapshot ของระบบจะไม่ซ่อมแซมไฟล์เหล่านี้ เพราะ `/home` ไม่ได้ถูกย้อนกลับไปด้วย

เมื่อคุณล็อกอินได้แล้ว ให้แก้ไขสำเนาที่บันทึกไว้ก่อนย้ายมันกลับ `sh -n` ตรวจจับข้อผิดพลาดทางไวยากรณ์ได้โดยไม่ต้องรันไฟล์ แต่ไม่สามารถตรวจจับข้อผิดพลาดทุกอย่างที่เกิดขึ้นเมื่อไฟล์ถูก source ได้ เปิดเทอร์มินัลที่ใช้งานได้ทิ้งไว้ขณะทดสอบการเปลี่ยนแปลง

### ทำไมพรอมต์ขออนุญาตของ 1Password สำหรับ 1Password SSH Agent / CLI ถึงไม่ปรากฏ?

เรื่องนี้เกิดขึ้นได้จาก 2 สาเหตุ:

เพื่อให้พรอมต์ขออนุมัติแบบละเอียดปรากฏ Settings > Advanced > Use Hardware Acceleration ต้องเปิดอยู่ _หมายเหตุ: การตั้งค่านี้ต้องรีบูตก่อนจึงจะเริ่มทำงาน_

 ![troubleshooting-1password](images/troubleshooting-1password.webp)

หรือหากคุณยังไม่ได้เปิด 1Password ตั้งแต่บูตเครื่อง พรอมต์ก็จะไม่ปรากฏ
