# การแก้ไขปัญหา

### ฉันทำระบบพังเพราะการอัปเดต!

ก่อนอื่นให้ลอง[ย้อนกลับระบบของคุณ](47-system-snapshots.md)ไปเป็นเวอร์ชันก่อนการอัปเดตล่าสุดของคุณ ถ้าวิธีนั้นไม่ได้ผล ให้ใช้ `omarchy-debug` เพื่อแชร์ปัญหาของคุณใน #omarchy-help ใน Discord และถ้าทุกอย่างไม่ได้ผลจริง ๆ คุณสามารถติดตั้งคอนฟิกและแพ็กเกจเริ่มต้นใหม่ได้โดยใช้ `omarchy-reinstall`

### ทำไมบางแอปถึงใหญ่เหลือเกินบนจอของฉัน?

Omarchy สันนิษฐานว่าคุณใช้จอแสดงผลความละเอียดสูงแบบ 2x ซึ่งต้องตั้งค่า `GDK_SCALE` เป็น 2 ใน `~/.config/hypr/monitors.lua` แต่ถ้าคุณใช้จอแบบ 1x คุณสามารถเปลี่ยน `local omarchy_gdk_scale = 2` เป็น 1 ได้ (แล้วรีสตาร์ทแอปที่ใหญ่เกินไป) ดู[คู่มือเกี่ยวกับจอภาพ](33-monitors.md)

สำหรับ Spotify คุณสามารถใช้ `Ctrl + Minus` เพื่อย่อ UI ได้ (และใช้ `Ctrl + Plus` เพื่อขยายให้ใหญ่ขึ้น)

### ทำไมคีย์ลัด Super ของฉันถึงหยุดทำงานทั้งหมด?

บนแล็ปท็อป ASUS ROG และ TUF บางรุ่น `Fn + Super` เป็นคีย์ผสมที่พลาดง่าย ซึ่งจะสลับการล็อกปุ่ม Windows ในระดับ firmware (มีไว้สำหรับการเล่นเกมเพื่อที่คุณจะได้ไม่ออกจากเกมโดยไม่ได้ตั้งใจ) จะไม่มีอะไรบนหน้าจอบอกคุณเลยว่าเกิดเรื่องนี้ขึ้น ขณะที่การล็อกเปิดอยู่ Super จะไม่ส่งสัญญาณอะไรออกมาเลย — ดังนั้นคีย์ลัดของ Omarchy ทุกตัวที่ใช้ Super จะหยุดทำงานไปเฉย ๆ และดูเหมือน Hyprland พัง

กด `Fn + Super` หนึ่งครั้งก่อนที่คุณจะไปขุดคุ้ยใน `~/.config/hypr/` และถ้านั่นไม่ทำให้ Super กลับมา ให้กดอีกครั้งเพื่อที่คุณจะได้ไม่เปิดการล็อกทิ้งไว้ นี่ไม่ใช่ Fn-lock ซึ่งมีผลแค่กับพฤติกรรมของแถวปุ่ม F เท่านั้น

### Wi-Fi, Bluetooth, เสียง หรือ trackpad ของฉันจู่ ๆ ก็หยุดทำงาน

ก่อนที่คุณจะ reboot ให้ลองรีสตาร์ทระบบย่อยที่มีปัญหาเพียงอย่างเดียวก่อน _Update > Hardware_ ในเมนู Omarchy มี Wi-Fi, Bluetooth, Audio และ Trackpad และการโหลดหนึ่งในนั้นใหม่จะแก้ไขสถานการณ์แบบ "เมื่อห้านาทีที่แล้วยังใช้ได้อยู่เลย" ส่วนใหญ่ได้ — หูฟัง Bluetooth ที่ไม่ยอมเชื่อมต่อใหม่, trackpad ที่ตายสนิทหลัง suspend, เสียงที่หายไปตอนคุณถอดจอออก

### ทำไมลำโพงภายนอกของฉันถึงไม่มีเสียง?

อาจเป็นเพราะยังไม่ได้ตั้งค่าให้พวกมันเป็นอุปกรณ์ส่งออกหลัก คลิกที่ไอคอนลำโพงทางด้านขวาของแถบ แล้วมันจะเปิดหน้าต่างป๊อปอัปปรับระดับเสียงขึ้นมา ซึ่งคุณสามารถเลือกอุปกรณ์ส่งออกได้ (และปรับระดับเสียงแยกตามแอปได้ด้วย)

### ลำโพงแล็ปท็อปของฉันเสียงแปลกไป

บนแล็ปท็อปบางเครื่อง Omarchy จะใช้การจูนลำโพงโดยอัตโนมัติเพื่อแก้ไขการตอบสนองความถี่ของลำโพงในตัว `omarchy audio tuning status` จะบอกคุณว่ามีการจูนแบบนี้เปิดใช้งานอยู่บนเครื่องของคุณหรือไม่ และ `omarchy audio tuning off` จะปิดมันถ้าคุณอยากฟังเสียงลำโพงแบบดิบ ๆ มากกว่า

### ทำไมฉันถึง login หรือ sudo ด้วยรหัสผ่านของฉันไม่ได้?

คุณอาจพิมพ์รหัสผ่านผิดหลายครั้งเกินไปจนถูกล็อกออก ถ้าเรื่องนี้เกิดขึ้นบนหน้าจอล็อก คุณสามารถกด `CTRL + ALT + F2` เพื่อเริ่ม TTY ใหม่ ซึ่งคุณสามารถ login เป็น root ได้ จากนั้นรัน `faillock --reset --user [your-username]` นั่นจะรีเซ็ตการล็อกออก และคุณก็พร้อมใช้งานได้เลย

### ทำไมข้อความแจ้งขออนุญาตของ 1Password สำหรับ 1Password SSH Agent / CLI ของฉันถึงไม่ปรากฏ?

เรื่องนี้อาจเกิดขึ้นได้จาก 2 สาเหตุ:

เพื่อให้ข้อความแจ้งขออนุมัติแบบละเอียดปรากฏขึ้น ต้องเปิด Settings > Advanced > Use Hardware Acceleration ไว้ _หมายเหตุ: ต้อง reboot ก่อนจึงจะเริ่มใช้งานได้_

 ![troubleshooting-1password](images/troubleshooting-1password.webp)

หรือถ้าคุณยังไม่ได้เปิด 1Password ตั้งแต่บูตเครื่องขึ้นมา ข้อความแจ้งก็จะไม่ปรากฏ
