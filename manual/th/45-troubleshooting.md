# การแก้ไขปัญหา

### ผมทำระบบพังด้วยการอัปเดต!

ก่อนอื่นลอง [ย้อนระบบของคุณ](47-system-snapshots.md) กลับไปเป็นเวอร์ชันก่อนการอัปเดตล่าสุดของคุณ ถ้านั่นไม่ได้ผล ใช้ `omarchy-debug` เพื่อแชร์ปัญหาของคุณใน #omarchy-help ใน Discord และถ้าทั้งหมดนั้นล้มเหลว คุณสามารถติดตั้งการกำหนดค่าและแพ็กเกจเริ่มต้นใหม่ได้โดยใช้ `omarchy-reinstall`

### ทำไมบางแอปจึงใหญ่จังบนจอของผม?

Omarchy สมมติว่าเป็นจอแสดงผลความละเอียดสูง 2x ซึ่งต้องตั้ง `GDK_SCALE` เป็น 2 ใน `~/.config/hypr/monitors.lua` แต่ถ้าคุณใช้จอ 1x คุณสามารถเปลี่ยน `local omarchy_gdk_scale = 2` เป็น 1 (แล้วรีสตาร์ตแอปใด ๆ ที่ใหญ่เกินไป) ดู [คู่มือเรื่องจอภาพ](33-monitors.md)

สำหรับ Spotify คุณสามารถใช้ `Ctrl + Minus` เพื่อย่อ UI (และ `Ctrl + Plus` เพื่อทำให้มันใหญ่ขึ้น)

### Wi-Fi, Bluetooth, เสียง หรือแทร็กแพดของผมเพิ่งหยุดทำงาน

ก่อนรีบูต ลองรีสตาร์ตระบบย่อยที่เป็นปัญหาเพียงระบบเดียว _อัปเดต > ฮาร์ดแวร์_ ในเมนู Omarchy มี Wi-Fi, Bluetooth, เสียง และแทร็กแพด และการโหลดหนึ่งในนั้นใหม่ช่วยแก้สถานการณ์ "ห้านาทีก่อนยังใช้ได้อยู่เลย" ส่วนใหญ่ได้ — ชุดหูฟัง Bluetooth ที่ไม่ยอมเชื่อมต่อใหม่ แทร็กแพดที่ตายหลังการพักเครื่อง เสียงที่หายไปเมื่อคุณถอดจอภาพ

### ทำไมลำโพงภายนอกของผมจึงไม่เล่นเสียง?

อาจเป็นเพราะพวกมันไม่ได้ถูกตั้งเป็นเอาต์พุตหลัก คลิกที่ไอคอนลำโพงทางด้านขวาของแถบ แล้วมันจะเปิดหน้าต่างป๊อปอัประดับเสียงที่คุณสามารถเลือกอุปกรณ์เอาต์พุตได้ (และมิกซ์ระดับเสียงแต่ละแอปได้ด้วย)

### ลำโพงแล็ปท็อปของผมเสียงแปลก ๆ

บนแล็ปท็อปบางเครื่อง Omarchy ใช้การปรับจูนลำโพงโดยอัตโนมัติซึ่งแก้ไขการตอบสนองความถี่ของลำโพงในตัว `omarchy audio tuning status` บอกคุณว่ามีการปรับจูนนั้นทำงานบนเครื่องของคุณหรือไม่ และ `omarchy audio tuning off` ปิดมันถ้าคุณอยากได้ยินลำโพงแบบดิบ ๆ มากกว่า

### ทำไมผมเข้าสู่ระบบหรือ sudo ด้วยรหัสผ่านไม่ได้?

คุณอาจพิมพ์มันผิดหลายครั้งเกินไปและถูกล็อกออก ถ้าสิ่งนี้เกิดขึ้นบนหน้าจอล็อก คุณสามารถกด `CTRL + ALT + F2` เพื่อเริ่ม TTY ใหม่ที่คุณสามารถเข้าสู่ระบบเป็น root ได้ แล้วรัน `faillock --reset --user [your-username]` นั่นจะรีเซ็ตการล็อกออก และคุณก็พร้อมใช้งาน

### ทำไมข้อความแจ้งการอนุญาต 1Password สำหรับ 1Password SSH Agent / CLI ของผมไม่ปรากฏ?

สิ่งนี้เกิดขึ้นได้ด้วย 2 สาเหตุ:

เพื่อให้ข้อความแจ้งการอนุมัติแบบสมบูรณ์ปรากฏ ต้องเปิด Settings > Advanced > Use Hardware Acceleration _หมายเหตุ: สิ่งนี้ต้องรีบูตเพื่อเริ่มทำงาน_

 ![troubleshooting-1password](images/troubleshooting-1password.webp)

หรือถ้าคุณยังไม่ได้เปิด 1Password ตั้งแตบูตเครื่อง ข้อความแจ้งจะไม่ปรากฏ
