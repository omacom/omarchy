# การแก้ปัญหา

### ฉันทำระบบพังด้วยอัปเดต!

ก่อนอื่น ให้ลอง [ย้อนระบบของคุณกลับ](47-system-snapshots.md) ไปยังเวอร์ชันก่อนอัปเดตล่าสุดของคุณ หากไม่ได้ผล ให้ใช้ `omarchy-debug` เพื่อแชร์ปัญหาของคุณใน #omarchy-help ใน Discord และหากทั้งหมดนั้นไม่ได้ผล คุณสามารถติดตั้ง configs และ packages ค่าเริ่มต้นใหม่ได้โดยใช้ `omarchy-reinstall`

### ทำไมบางแอปจึงใหญ่เหลือเกินบนจอแสดงผลของฉัน?

Omarchy สันนิษฐานว่าคุณใช้จอแสดงผลความละเอียดสูงแบบ 2x จึงตั้งค่า `GDK_SCALE` เป็น 2 จนกว่าคุณจะเลือก scale ในแผง monitor หากคุณใช้จอแสดงผลแบบ 1x และแอป GTK หรือ X11 แสดงผลขนาดใหญ่เกินไป ให้เลือก 1x สำหรับจอนั้นในแผง monitor หรือเพิ่ม `hl.env("GDK_SCALE", "1")` ลงใน `~/.config/hypr/monitors.lua` (จากนั้น restart แอปใดก็ตามที่มีขนาดใหญ่เกินไป) ดู [คู่มือว่าด้วย monitors](33-monitors.md)

สำหรับ Spotify คุณสามารถใช้ `Ctrl + Minus` เพื่อย่อ UI ให้เล็กลง (และใช้ `Ctrl + Plus` เพื่อทำให้ใหญ่ขึ้น)

### ทำไมคีย์ลัด Super ทั้งหมดของฉันจึงหยุดทำงาน?

บนแล็ปท็อป ASUS ROG และ TUF บางรุ่น `Fn + Super` เป็นคีย์ผสมที่พลาดได้ง่าย ซึ่งจะสลับการล็อกปุ่ม Windows ในระดับ firmware (มีไว้สำหรับการเล่นเกมเพื่อไม่ให้คุณออกจากเกมโดยไม่ตั้งใจ) ไม่มีอะไรบนหน้าจอบอกคุณว่าเกิดสิ่งนี้ขึ้น ขณะที่การล็อกเปิดอยู่ Super จะไม่ส่งอะไรออกมาเลย — ดังนั้นคีย์ลัด Omarchy ทุกตัวที่ใช้ Super จึงหยุดทำงานเฉย ๆ และดูเหมือน Hyprland พัง

กด `Fn + Super` หนึ่งครั้งก่อนที่คุณจะลงไปขุดคุ้ยใน `~/.config/hypr/` และหากไม่ได้ทำให้ Super กลับมา ให้กดอีกครั้งเพื่อไม่ให้คุณทิ้งการล็อกไว้ในสถานะเปิด นี่ไม่ใช่ Fn-lock ซึ่งเปลี่ยนเฉพาะการทำงานของแถวปุ่ม F เท่านั้น

### Wi-Fi, Bluetooth, เสียง หรือ trackpad ของฉันหยุดทำงานไปเฉย ๆ

ก่อนที่คุณจะ reboot ให้ลอง restart ระบบย่อยที่มีปัญหาเพียงตัวเดียวด้วยตัวเอง _Update > Hardware_ ในเมนู Omarchy มี Wi-Fi, Bluetooth, Audio และ Trackpad และการโหลดหนึ่งในนั้นใหม่จะแก้ไขสถานการณ์ส่วนใหญ่แบบ "เมื่อห้านาทีที่แล้วยังใช้ได้อยู่เลย" ได้ — หูฟัง Bluetooth ที่ไม่ยอมเชื่อมต่อใหม่, trackpad ที่ดับไปหลังจาก suspend, เสียงที่หายไปเมื่อคุณถอดปลั๊กจอภาพ

### ทำไมลำโพงภายนอกของฉันจึงไม่มีเสียง?

อาจเป็นเพราะยังไม่ได้ตั้งค่าให้เป็น output หลัก คลิกที่ไอคอนลำโพงทางด้านขวาของ bar แล้ว popup ระดับเสียงจะเปิดขึ้น ซึ่งคุณสามารถเลือกอุปกรณ์ output ได้ (และผสมระดับเสียงแยกตามแอปได้ด้วย)

### ลำโพงแล็ปท็อปของฉันเสียงฟังดูผิดปกติ

บนแล็ปท็อปบางรุ่น Omarchy จะปรับใช้การจูนลำโพงโดยอัตโนมัติซึ่งแก้ไขการตอบสนองความถี่ของลำโพงในตัว `omarchy audio tuning status` จะบอกคุณว่ามีการจูนที่ใช้งานอยู่บนเครื่องของคุณหรือไม่ และ `omarchy audio tuning off` จะปิดการจูนนั้นหากคุณอยากได้ยินเสียงลำโพงแบบดิบ ๆ มากกว่า

### ทำไมฉันจึง login หรือ sudo ด้วยรหัสผ่านของฉันไม่ได้?

คุณอาจพิมพ์ผิดสิบครั้งและถูกบล็อก การบล็อกจะหายไปเองหลังจากสองนาที หากคุณรอไม่ได้ และเหตุการณ์นี้เกิดขึ้นบนหน้าจอล็อก คุณสามารถกด `CTRL + ALT + F2` เพื่อเริ่ม TTY ใหม่ที่คุณสามารถ login เป็น root ได้ จากนั้นรัน `faillock --reset --user [your-username]` คำสั่งนั้นจะรีเซ็ตการบล็อก และคุณก็พร้อมใช้งานต่อได้

### รหัสผ่านของฉันถูกต้อง แต่ฉันกลับไปที่หน้าจอ login

ไฟล์สภาพแวดล้อมของ session ที่เสียหายอาจทำให้ desktop ไม่สามารถเริ่มทำงานได้แม้รหัสผ่านของคุณจะถูกต้อง ประเด็นนี้น่าตรวจสอบเป็นพิเศษหลังจากแก้ไข `~/.config/uwsm/env.d/`

กด `Ctrl + Alt + F2`, login ด้วยชื่อผู้ใช้และรหัสผ่านปกติของคุณ และตรวจสอบ journal ของผู้ใช้ของ boot ปัจจุบัน:

```bash
journalctl --user -b -t uwsm_env-preloader --no-pager
```

มองหาข้อผิดพลาดที่ระบุชื่อไฟล์สภาพแวดล้อมไฟล์ใดไฟล์หนึ่งของคุณ เช่น `bad substitution` ซึ่งอยู่ก่อนข้อความที่ระบุว่าไม่พบเครื่องหมาย output ของ env นำไฟล์นั้นออกจาก `env.d` ก่อนลอง login อีกครั้ง ตัวอย่างเช่น หากข้อผิดพลาดระบุชื่อ `99-custom`:

```bash
mkdir -p ~/.config/uwsm/disabled
mv -i ~/.config/uwsm/env.d/99-custom ~/.config/uwsm/disabled/
```

UWSM จะข้ามไฟล์ที่มีข้อผิดพลาดทาง syntax แต่ข้อผิดพลาดร้ายแรงที่แสดงขึ้นเฉพาะขณะที่ไฟล์กำลังทำงาน เช่น `bad substitution` ยังคงสามารถทำให้ desktop ไม่สามารถเริ่มทำงานได้ การย้อนกลับ system snapshot ไม่ได้ซ่อมแซมไฟล์เหล่านี้ เพราะ `/home` ไม่ถูกย้อนกลับ

เมื่อคุณ login ได้แล้ว ให้แก้สำเนาที่บันทึกไว้ก่อนย้ายกลับ `sh -n` จะตรวจจับข้อผิดพลาดทาง syntax โดยไม่รันไฟล์ แต่ไม่สามารถตรวจจับข้อผิดพลาดทุกอย่างที่เกิดขึ้นเมื่อไฟล์ถูก source ได้ ให้เปิด terminal ที่ใช้งานได้ค้างไว้ขณะทดสอบการเปลี่ยนแปลง

### ทำไมข้อความแจ้งขออนุญาตของ 1Password สำหรับ 1Password SSH Agent / CLI ของฉันจึงไม่ปรากฏ?

สิ่งนี้อาจเกิดขึ้นได้จาก 2 สาเหตุ:

เพื่อให้ข้อความแจ้งขออนุญาตแบบละเอียดปรากฏขึ้น ต้องเปิด Settings > Advanced > Use Hardware Acceleration ไว้ _หมายเหตุ: การตั้งค่านี้ต้อง reboot จึงจะเริ่มทำงาน_

 ![troubleshooting-1password](images/troubleshooting-1password.webp)

หรือหากคุณยังไม่ได้เปิด 1Password นับตั้งแต่ boot เครื่อง ข้อความแจ้งนั้นจะไม่ปรากฏ
