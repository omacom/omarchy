# Dotfiles

Omarchy กำหนดค่าส่วนใหญ่ผ่านสิ่งที่เรียกว่า dotfiles ซึ่งอยู่ใน `~/.config` ไฟล์เหล่านั้นถือเป็นไฟล์ของคุณ สำหรับการเปลี่ยนแปลงของคุณ ส่วนไฟล์ที่อยู่ใน `/usr/share/omarchy` เป็นของ Omarchy เอง และคุณไม่ควรไปยุ่งกับไฟล์เหล่านั้น หากคุณจำเป็นต้องเปลี่ยนแปลงอะไรใน `/usr/share/omarchy` คุณควรเขียนทับค่าดังกล่าวใน `~/.config` แทน

ไฟล์กำหนดค่าหลักสามารถแก้ไขได้โดยตรงจากเมนู Omarchy (`Super + Space`) เช่น _Setup > Keyboard > Keybindings_, _Setup > Input_ และ _Setup > Config > [file]_ เมื่อคุณแก้ไขด้วยวิธีนี้ โปรเซสใดก็ตามที่ต้องรีสตาร์ทหลังจากแก้ไขไฟล์กำหนดค่าจะถูกรีสตาร์ทโดยอัตโนมัติหลังจากคุณออกจากโปรแกรมแก้ไข (Neovim เป็นค่าเริ่มต้น — `:wq` อย่าลืม! — แต่คุณสามารถเปลี่ยนได้ผ่าน _Setup > Defaults > Editor_)

นี่คือรายการไฟล์สำคัญใน `~/.config` และสิ่งที่ไฟล์เหล่านั้นควบคุม:

| File                  | Purpose              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | ไฟล์กำหนดค่าหลักของ Hyprland โหลดค่าเริ่มต้นของ Omarchy รวมถึงไฟล์ override ของคุณที่อยู่ด้านล่าง [เรียนรู้เพิ่มเติมเกี่ยวกับไฟล์กำหนดค่าของ Hyprland](https://wiki.hypr.land/Configuring/)  |
| `~/.config/hypr/bindings.lua` | คีย์ลัดของคุณเองและการเขียนทับค่าเริ่มต้น |
| `~/.config/hypr/monitors.lua` | การตั้งค่าจอภาพที่แผงควบคุมจอภาพไม่ครอบคลุม เช่น การหมุนจอ โหมดเพิ่มเติม หรือการปิดจอภาพไว้ |
| `~/.config/hypr/input.lua` | ควบคุมรูปแบบแป้นพิมพ์ เมาส์ และการตั้งค่า trackpad ของคุณ |
| `~/.config/hypr/looknfeel.lua` | ควบคุมช่องว่าง เส้นขอบ แอนิเมชัน และส่วนที่เหลือของรูปลักษณ์ |
| `~/.config/hypr/autostart.lua` | ควบคุมโปรเซสเพิ่มเติมที่เริ่มทำงานพร้อมกับเซสชัน |
| `~/.config/omarchy/shell.json` | ควบคุม Omarchy shell: ตำแหน่งของแถบ เลย์เอาต์ และวิดเจ็ต รวมถึง screensaver การล็อก และการตั้งเวลา idle |
| `~/.config/foot/foot.ini` | ควบคุมเทอร์มินัลของคุณ (foot เป็นค่าเริ่มต้น) |
| `~/.XCompose` | กำหนด emoji สำหรับการเข้าถึงด่วนและการเติมชื่อ/อีเมลอัตโนมัติของคุณ อย่าลืมเรียกใช้ `omarchy-restart-xcompose` หลังจากทำการเปลี่ยนแปลง |

หากสุดท้ายคุณทำการเปลี่ยนแปลงมากมายเพื่อปรับแต่งการตั้งค่าของคุณเอง ก็ควรสำรองข้อมูล dotfiles เหล่านี้ทั้งหมดไว้ [Stow เป็นวิธีที่ยอดเยี่ยมในการทำเช่นนั้น](https://www.youtube.com/watch?v=NoFiYOqnC4o)

### การเริ่มแอปของคุณเองพร้อมกับเซสชัน

หากคุณต้องการให้บางอย่างทำงานทุกครั้งที่คุณเข้าสู่ระบบ — sync daemon แอปแชท หรือสคริปต์ของคุณเอง — ให้ใส่ไว้ใน `~/.config/hypr/autostart.lua`:

```lua
o.launch_on_start("my-service")
```

วิธีนี้จะเริ่มคำสั่งดังกล่าวเป็นส่วนหนึ่งของเซสชัน ดังนั้นมันจะถูกทำความสะอาดอย่างเหมาะสมเมื่อคุณออกจากระบบอีกครั้ง

### การเรียกใช้สคริปต์ตามเหตุการณ์ของระบบ

Omarchy จะเรียกใช้ hooks ในช่วงเวลาจำนวนหนึ่ง และคุณสามารถแขวนสคริปต์ของคุณเองไว้กับ hooks เหล่านั้นได้ hooks เหล่านั้นอยู่ใน `~/.config/omarchy/hooks/<event>.d/` โดยมีหนึ่งไดเรกทอรีต่อหนึ่งเหตุการณ์ และไฟล์ที่สามารถเรียกใช้งานได้ทุกไฟล์ในนั้นจะทำงานเมื่อเหตุการณ์นั้นเกิดขึ้น:

| Event | When it runs |
| ----- | ------------ |
| `post-boot` | ทันทีหลังจากเดสก์ท็อปเริ่มทำงานแล้ว |
| `post-update` | ใกล้ตอนท้ายของ `omarchy update` หลังจากแพ็กเกจ การย้ายข้อมูล และการรีสตาร์ทบริการ ก่อนที่เครื่องมือของ mise จะได้รับการอัปเดต |
| `pre-refresh-pacman` | หลังจาก `omarchy refresh pacman` ซิงค์ไฟล์กำหนดค่าแพ็กเกจใหม่ ก่อนที่จะอัปเดตแพ็กเกจ การสลับ channel จะเรียกใช้ hooks นี้ในขั้นตอน refresh เดียวกันนั้น |
| `theme-set` | หลังจากเปลี่ยนธีม (ชื่อธีมอยู่ใน `$1`) |
| `font-set` | หลังจากเปลี่ยนฟอนต์ (ชื่อฟอนต์อยู่ใน `$1`) |
| `battery-low` | เมื่อแบตเตอรี่เหลือน้อย (เปอร์เซ็นต์อยู่ใน `$1`) |

`pre-refresh-pacman` hook เป็นที่ที่ repository แบบกำหนดเองหรือบรรทัด `IgnorePkg` ควรอยู่ เนื่องจากมันทำงานก่อนธุรกรรมแพ็กเกจ hooks ที่เกี่ยวข้องกับการอัปเดตทั้งสองจะทำงานในฐานะผู้ใช้ของคุณหลังจาก Omarchy ล้างการอนุญาต sudo ที่แคชไว้ ดังนั้น hook ที่ใช้ `sudo` จะต้องการการอนุญาตของตัวเองและอาจขอรหัสผ่านของคุณ

แต่ละไดเรกทอรีเหล่านั้นมีไฟล์ `.sample` อยู่แล้วซึ่งแสดงรูปแบบของ hook — ให้ตัด `.sample` ออกจากชื่อเพื่อนำมันมาใช้งาน หากต้องการติดตั้งสคริปต์ที่คุณเขียนไว้ที่อื่น ให้ใช้ `omarchy hook install post-boot ~/my-hook` ซึ่งจะคัดลอกสคริปต์นั้นเข้าไปและทำให้สามารถเรียกใช้งานได้

### การเพิ่มรายการเมนูของคุณเอง

เมนู Omarchy (`Super + Space`) สามารถขยายได้ด้วยแถวของคุณเองโดยการแก้ไข `~/.config/omarchy/extensions/omarchy-menu.jsonc` รายการต่าง ๆ จะถูกกำหนดคีย์ด้วย id แบบจุด และ id นั้นเองที่เป็นตัวกำหนดตำแหน่งของรายการในโครงสร้าง ดังนั้น `personal` จะแสดงขึ้นบนเมนูหลัก และ `personal.notes` จะแสดงขึ้นภายในนั้น:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

หากคุณใช้ id ที่มีอยู่ซ้ำ คุณจะเขียนทับแถวนั้นแทนที่จะเพิ่มแถวใหม่ ไฟล์นี้มาพร้อมกับคำอธิบายฟิลด์ทั้งหมดที่มีให้ใช้งานในรูปแบบคอมเมนต์

### การเพิ่ม shell exports, functions และ aliases ของคุณเอง

Omarchy มาพร้อมกับ aliases ที่สะดวกต่อการใช้งานจำนวนมากและฟังก์ชันที่มีประโยชน์ แต่ก็เป็นเรื่องปกติมากที่คุณจะอยากเพิ่มของของคุณเอง คุณควรเพิ่มทั้ง aliases, functions และ exports ใน `~/.bashrc` ไฟล์นี้จะไม่ถูกเขียนทับเมื่อมีการอัปเดต หากคุณต้องการเปลี่ยนแปลงค่าเริ่มต้นใด ๆ ของ Omarchy คุณก็สามารถเพิ่มไว้ที่นี่ได้อย่างปลอดภัยเช่นกัน

### การตั้งค่าตัวแปรสภาพแวดล้อมสำหรับเดสก์ท็อป

การ export สำหรับเซสชันเดสก์ท็อปควรอยู่ใน `~/.config/uwsm/env.d/` ไฟล์เหล่านี้จะทำงานก่อนที่เดสก์ท็อปของคุณจะเริ่มทำงาน ดังนั้นข้อผิดพลาดของ shell อาจส่งคุณกลับไปที่หน้าจอเข้าสู่ระบบได้ ให้เปิดเทอร์มินัลที่ยังใช้งานได้ค้างไว้ขณะแก้ไขไฟล์เหล่านี้ หากต้องการปิดใช้งาน override ให้ย้ายมันออกจาก `env.d` ดู [การกู้คืนการเข้าสู่ระบบ](45-troubleshooting.md#my-password-is-accepted-but-i-return-to-the-login-screen) หากการเปลี่ยนแปลงทำให้เข้าสู่ระบบไม่ได้

### การเปลี่ยนแปลงไฟล์ภายในของ Omarchy

ฟังนะ นี่คือคอมพิวเตอร์ของคุณ คุณจะทำอะไรกับมันก็ได้ตามที่คุณต้องการ แต่ผมขอแนะนำว่าอย่าเปลี่ยนแปลงไฟล์ใน `/usr/share/omarchy` โดยตรง ไฟล์เหล่านั้นเป็นของแพ็กเกจ pacman ของ Omarchy ดังนั้นการเปลี่ยนแปลงของคุณจะถูกเขียนทับไปเฉย ๆ ในการอัปเดตครั้งถัดไป คุณควรเขียนทับค่าเริ่มต้นใด ๆ ที่คุณไม่ชอบในโฟลเดอร์ `~/.config/*` แทนจะดีกว่า

คุณสามารถเปลี่ยนแปลงแทบทุกอย่างได้ด้วยวิธีนั้น เช่น คีย์ลัดเริ่มต้น เพียงแก้ไข `~/.config/hypr/bindings.lua` เพื่อเปลี่ยนจาก [Obsidian](https://obsidian.md/) เป็น [Joplin](https://joplinapp.org/) เป็นต้น (ติดตั้งด้วย `omarchy-pkg-add joplin-bin`):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` จะลบคีย์ลัดที่มีอยู่เดิมออกก่อนที่จะเพิ่มคีย์ลัดทดแทน มันรับอาร์กิวเมนต์เดียวกันกับ `o.bind` รวมถึงตัวช่วยในการเปิดแอปและตัวเลือกของคีย์ลัด ใช้ `o.bind` เพื่อเพิ่มคีย์ลัด หรือใช้ `hl.unbind` เพื่อลบคีย์ลัดออกโดยไม่ต้องแทนที่

หากคุณยืนกรานที่จะแฮ็กไฟล์ภายในของ Omarchy ให้สลับไปใช้ช่อง dev ผ่าน _Update > Channel > Dev_ วิธีนั้นจะเชื่อมโยง Omarchy เข้ากับ git checkout ของซอร์สโค้ดใน `~/omarchy` ซึ่งคุณสามารถเปลี่ยนแปลงได้อย่างอิสระตามใจชอบ ไม่มีใครที่นี่จะมาบอกว่าคุณต้องทำอะไร!

### การรีเซ็ตการเปลี่ยนแปลงใด ๆ

หากสุดท้ายคุณทำให้ไฟล์กำหนดค่าวุ่นวายไปหมด คุณก็สามารถคืนค่าเหล่านั้นกลับไปเป็นค่าเริ่มต้นได้เสมอผ่าน _Update > Config_ ในเมนู Omarchy หรือโดยการเรียกใช้ `omarchy reinstall configs` เพื่อรีเซ็ตทุกอย่าง
