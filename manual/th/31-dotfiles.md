# Dotfiles

Omarchy ถูกตั้งค่าเป็นหลักผ่านสิ่งที่เรียกว่า dotfiles ซึ่งอยู่ใน `~/.config` ไฟล์เหล่านั้นถือเป็นไฟล์ของคุณสำหรับการเปลี่ยนแปลงของคุณ ไฟล์ที่อยู่ใน `/usr/share/omarchy` เป็นของ Omarchy เอง และคุณไม่ควรไปยุ่งกับไฟล์เหล่านั้น หากคุณจำเป็นต้องเปลี่ยนอะไรใน `/usr/share/omarchy` คุณควรเขียนทับค่าใน `~/.config` แทน

การตั้งค่าหลักสามารถแก้ไขได้โดยตรงจากเมนู Omarchy (`Super + Space`) เช่น _Setup > Keyboard > Keybindings_, _Setup > Input_ และ _Setup > Config > [file]_ เมื่อคุณทำด้วยวิธีนี้ โพรเซสใดก็ตามที่ต้องรีสตาร์ทหลังจากแก้ไขการตั้งค่าจะรีสตาร์ทโดยอัตโนมัติหลังจากคุณออกจากโปรแกรมแก้ไข (Neovim เป็นค่าเริ่มต้น — `:wq` จำไว้นะ! — แต่คุณสามารถเปลี่ยนได้ผ่าน _Setup > Defaults > Editor_)

นี่คือรายการไฟล์สำคัญใน `~/.config` และสิ่งที่ไฟล์เหล่านั้นควบคุม:

| File                  | Purpose              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | ไฟล์ตั้งค่าหลักของ Hyprland โหลดค่าเริ่มต้นของ Omarchy บวกกับไฟล์เขียนทับของคุณด้านล่าง [เรียนรู้เพิ่มเติมเกี่ยวกับการตั้งค่า Hyprland](https://wiki.hypr.land/Configuring/)  |
| `~/.config/hypr/bindings.lua` | คีย์ลัดของคุณเองและการเขียนทับค่าเริ่มต้น |
| `~/.config/hypr/monitors.lua` | การตั้งค่าจอภาพที่แผงควบคุมจอภาพไม่ครอบคลุม เช่น การหมุน โหมดเพิ่มเติม หรือการปิดจอภาพไว้ |
| `~/.config/hypr/input.lua` | ควบคุมรูปแบบแป้นพิมพ์ เมาส์ และการตั้งค่า trackpad ของคุณ |
| `~/.config/hypr/looknfeel.lua` | ควบคุมช่องว่าง เส้นขอบ แอนิเมชัน และส่วนที่เหลือของรูปลักษณ์ |
| `~/.config/hypr/autostart.lua` | ควบคุมโพรเซสเพิ่มเติมที่เริ่มพร้อมกับเซสชัน |
| `~/.config/omarchy/shell.json` | ควบคุม Omarchy shell: ตำแหน่งของแถบ เลย์เอาต์ และวิดเจ็ต บวกกับเวลาของ screensaver การล็อก และการ idle |
| `~/.config/foot/foot.ini` | ควบคุมเทอร์มินัลของคุณ (foot เป็นค่าเริ่มต้น) |
| `~/.XCompose` | กำหนดอีโมจิแบบเข้าถึงด่วนและการเติมชื่อ/อีเมลอัตโนมัติของคุณ อย่าลืมรัน `omarchy-restart-xcompose` หลังจากทำการเปลี่ยนแปลง |

หากสุดท้ายคุณทำการเปลี่ยนแปลงมากมายเพื่อปรับแต่งการตั้งค่าของคุณเอง ก็เป็นความคิดที่ดีที่จะสำรอง dotfiles ทั้งหมดเหล่านี้ [Stow เป็นวิธีที่ยอดเยี่ยมในการทำเช่นนั้น](https://www.youtube.com/watch?v=NoFiYOqnC4o)

### เริ่มแอปของคุณเองพร้อมกับเซสชัน

หากคุณต้องการให้บางอย่างรันทุกครั้งที่คุณเข้าสู่ระบบ — sync daemon แอปแชต สคริปต์ของคุณเอง — ให้ใส่ไว้ใน `~/.config/hypr/autostart.lua`:

```lua
o.launch_on_start("my-service")
```

นั่นจะเริ่มคำสั่งนั้นเป็นส่วนหนึ่งของเซสชัน ดังนั้นมันจะถูกเก็บกวาดอย่างเหมาะสมเมื่อคุณออกจากระบบอีกครั้ง

### การรันสคริปต์ตามอีเวนต์ของระบบ

Omarchy จะยิง hooks ในช่วงเวลาสองสามช่วง และคุณสามารถแขวนสคริปต์ของคุณเองไว้กับ hooks เหล่านั้นได้ พวกมันอยู่ใน `~/.config/omarchy/hooks/<event>.d/` หนึ่งไดเรกทอรีต่อหนึ่งอีเวนต์ และทุกไฟล์ในนั้นที่ไม่ลงท้ายด้วย `.sample` จะรันด้วย bash เมื่ออีเวนต์นั้นเกิดขึ้น:

| Event | When it runs |
| ----- | ------------ |
| `post-boot` | ทันทีหลังจากเดสก์ท็อปเริ่มทำงานแล้ว |
| `post-update` | ใกล้ตอนจบของ `omarchy update` หลังจากแพ็กเกจ การย้ายข้อมูล และการรีสตาร์ทเซอร์วิส ก่อนที่เครื่องมือ mise จะถูกอัปเดต |
| `pre-refresh-pacman` | หลังจาก `omarchy refresh pacman` ซิงค์การตั้งค่าแพ็กเกจใหม่ ก่อนที่มันจะอัปเดตแพ็กเกจ การสลับแชนเนลจะรันมันในขั้นตอนรีเฟรชเดียวกันนั้น |
| `theme-set` | หลังจากเปลี่ยนธีม (ชื่อธีมใน `$1`) |
| `font-set` | หลังจากเปลี่ยนฟอนต์ (ชื่อฟอนต์ใน `$1`) |
| `battery-low` | เมื่อแบตเตอรี่ใกล้หมด (เปอร์เซ็นต์ใน `$1`) |

hook `pre-refresh-pacman` คือที่ที่ repository แบบกำหนดเองหรือบรรทัด `IgnorePkg` ควรอยู่ เนื่องจากมันรันก่อนธุรกรรมแพ็กเกจ ทั้งสองรันในฐานะผู้ใช้ของคุณ `post-update` รันขณะที่การอนุญาต sudo ของ `omarchy update` ยังคงสดใหม่ ดังนั้น hook ที่ใช้ `sudo` จะไม่ขอรหัสผ่านของคุณอีก `pre-refresh-pacman` รันทันทีหลังจาก `omarchy refresh pacman` ได้ใช้ sudo ด้วยตัวเอง

แต่ละไดเรกทอรีเหล่านั้นมีไฟล์ `.sample` อยู่แล้วซึ่งแสดงรูปแบบของ hook — เอา `.sample` ออกจากชื่อเพื่อให้มันทำงาน ในการติดตั้งสคริปต์ที่คุณเขียนไว้ที่อื่น ให้ใช้ `omarchy hook install post-boot ~/my-hook` ซึ่งจะคัดลอกมันเข้ามาและทำให้มันสามารถเรียกใช้งานได้

### การเพิ่มรายการเมนูของคุณเอง

เมนู Omarchy (`Super + Space`) สามารถขยายได้ด้วยแถวของคุณเองโดยการแก้ไข `~/.config/omarchy/extensions/omarchy-menu.jsonc` รายการต่าง ๆ ถูกกำหนดด้วย id แบบมีจุด และ id นั้นคือสิ่งที่จัดวางพวกมันไว้ในโครงสร้าง ดังนั้น `personal` จะปรากฏบนเมนูหลัก และ `personal.notes` จะปรากฏอยู่ภายในนั้น:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

การใช้ id ที่มีอยู่ซ้ำจะเขียนทับแถวนั้นแทนที่จะเพิ่มแถวใหม่ ไฟล์นี้มาพร้อมกับฟิลด์ทั้งหมดที่มีให้ใช้ซึ่งบันทึกไว้เป็นคอมเมนต์

### การเพิ่ม shell exports, functions และ aliases ของคุณเอง

Omarchy มาพร้อมกับ aliases ที่ใช้งานสะดวกมากมายและ functions ที่เป็นประโยชน์ แต่เป็นเรื่องปกติมากที่คุณจะอยากเพิ่มของของคุณเอง คุณควรเพิ่มทั้ง aliases, functions และ exports ใน `~/.bashrc` ไฟล์นี้จะไม่ถูกเขียนทับเมื่อมีการอัปเดต หากคุณต้องการเปลี่ยนค่าเริ่มต้นใด ๆ ของ Omarchy คุณก็สามารถเพิ่มพวกมันที่นี่ได้อย่างปลอดภัยเช่นกัน

### การตั้งค่าตัวแปรสภาพแวดล้อมสำหรับเดสก์ท็อป

exports ของเซสชันเดสก์ท็อปอยู่ใน `~/.config/uwsm/env.d/` ไฟล์เหล่านี้รันก่อนที่เดสก์ท็อปของคุณจะเริ่ม ดังนั้นข้อผิดพลาดของ shell อาจส่งคุณกลับไปที่หน้าจอเข้าสู่ระบบได้ เปิดเทอร์มินัลที่ยังทำงานได้ค้างไว้ขณะที่แก้ไขพวกมัน ในการปิดการเขียนทับ ให้ย้ายมันออกจาก `env.d` ดู [การกู้คืนการเข้าสู่ระบบ](45-troubleshooting.md#my-password-is-accepted-but-i-return-to-the-login-screen) หากการเปลี่ยนแปลงทำให้เข้าสู่ระบบไม่ได้

### การเปลี่ยนไฟล์ภายในของ Omarchy

ฟังนะ นี่คือคอมพิวเตอร์ของคุณ คุณจะทำอะไรกับมันก็ได้ตามที่คุณต้องการ แต่ผมขอแนะนำว่าไม่ควรทำการเปลี่ยนแปลงไฟล์ใน `/usr/share/omarchy` โดยตรง พวกมันเป็นของแพ็กเกจ pacman ของ Omarchy ดังนั้นการเปลี่ยนแปลงของคุณจะถูกเขียนทับในการอัปเดตครั้งต่อไปเฉย ๆ คุณควรเขียนทับค่าเริ่มต้นใด ๆ ที่คุณไม่ชอบในโฟลเดอร์ `~/.config/*` แทนจะดีกว่า

คุณสามารถเปลี่ยนแทบทุกอย่างได้ด้วยวิธีนั้น เช่น คีย์ลัดเริ่มต้น เพียงแก้ไข `~/.config/hypr/bindings.lua` เพื่อ สมมติว่า แทนที่ [Obsidian](https://obsidian.md/) ด้วย [Joplin](https://joplinapp.org/) (ติดตั้งด้วย `omarchy-pkg-add joplin-bin`):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` จะลบการผูกที่มีอยู่ก่อนที่จะเพิ่มสิ่งทดแทนเข้าไป มันรับอาร์กิวเมนต์เดียวกันกับ `o.bind` รวมถึง launch helpers และตัวเลือกการผูก ใช้ `o.bind` เพื่อเพิ่มการผูก หรือใช้ `hl.unbind` เพื่อลบการผูกโดยไม่แทนที่มัน

หากคุณยืนกรานจะแฮ็กไฟล์ภายในของ Omarchy ให้สลับไปยังแชนเนล dev ผ่าน _Update > Channel > Dev_ นั่นจะเชื่อม Omarchy ไปยัง git checkout ของซอร์สโค้ดใน `~/omarchy` ซึ่งคุณมีอิสระที่จะเปลี่ยนแปลงได้ตามใจชอบ ไม่มีใครที่นี่จะมาบอกว่าคุณต้องทำอะไร!

### การรีเซ็ตการเปลี่ยนแปลงใด ๆ

หากสุดท้ายคุณทำไฟล์ตั้งค่าวุ่นวายไปหมด คุณก็สามารถคืนค่าพวกมันกลับไปเป็นค่าเริ่มต้นได้เสมอผ่าน _Update > Config_ ในเมนู Omarchy หรือโดยการรัน `omarchy reinstall configs` เพื่อรีเซ็ตทุกอย่าง
