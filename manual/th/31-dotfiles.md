# Dotfiles

Omarchy ถูกกำหนดค่าส่วนใหญ่ผ่านสิ่งที่เรียกว่า dotfiles ซึ่งอยู่ใน `~/.config` ไฟล์เหล่านั้นถือเป็นไฟล์ของคุณสำหรับการเปลี่ยนแปลงของคุณ ไฟล์ที่อยู่ใน `/usr/share/omarchy` เป็นของ Omarchy เอง และคุณไม่ควรไปยุ่งกับไฟล์เหล่านั้น หากคุณจำเป็นต้องเปลี่ยนอะไรใน `/usr/share/omarchy` คุณควรเขียนทับค่าใน `~/.config` แทน

การตั้งค่าหลักสามารถแก้ไขได้โดยตรงจากเมนู Omarchy (`Super + Space`) เช่น _Setup > Keybindings_, _Setup > Input_ และ _Setup > Config > [file]_ เมื่อคุณทำด้วยวิธีนี้ โปรเซสใด ๆ ที่ต้องรีสตาร์ทหลังจากแก้ไขการตั้งค่าจะถูกรีสตาร์ทโดยอัตโนมัติหลังจากคุณออกจากโปรแกรมแก้ไข (Neovim เป็นค่าเริ่มต้น — `:wq` จำไว้! — แต่คุณสามารถเปลี่ยนได้ผ่าน _Setup > Defaults > Editor_)

นี่คือรายการไฟล์สำคัญใน `~/.config` และสิ่งที่พวกมันควบคุม:

| File                  | Purpose              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | การตั้งค่าหลักของ Hyprland โหลดค่าเริ่มต้นของ Omarchy พร้อมกับไฟล์ override ของคุณด้านล่าง [เรียนรู้เพิ่มเติมเกี่ยวกับการตั้งค่าของ Hyprland](https://wiki.hypr.land/Configuring/)  |
| `~/.config/hypr/bindings.lua` | คีย์ลัดของคุณเองและการเขียนทับค่าเริ่มต้น |
| `~/.config/hypr/monitors.lua` | การตั้งค่าจอภาพที่แผงจอภาพไม่ครอบคลุม เช่น การหมุน โหมดเพิ่มเติม หรือการปิดจอภาพไว้ |
| `~/.config/hypr/input.lua` | ควบคุมเลย์เอาต์แป้นพิมพ์ เมาส์ และการตั้งค่า trackpad ของคุณ |
| `~/.config/hypr/looknfeel.lua` | ควบคุมช่องว่าง ขอบ แอนิเมชัน และส่วนที่เหลือของรูปลักษณ์ |
| `~/.config/hypr/autostart.lua` | ควบคุมโปรเซสเพิ่มเติมที่เริ่มต้นพร้อมกับเซสชัน |
| `~/.config/omarchy/shell.json` | ควบคุมเชลล์ของ Omarchy: ตำแหน่งของแถบ เลย์เอาต์ และ widgets รวมถึงเวลาของ screensaver, lock และ idle |
| `~/.config/foot/foot.ini` | ควบคุมเทอร์มินัลของคุณ (foot เป็นค่าเริ่มต้น) |
| `~/.XCompose` | กำหนดอิโมจิแบบเข้าถึงด่วนและการเติมชื่อ/อีเมลอัตโนมัติของคุณ อย่าลืมรัน `omarchy-restart-xcompose` หลังจากทำการเปลี่ยนแปลง |

หากคุณเปลี่ยนแปลงหลายอย่างเพื่อปรับแต่งการตั้งค่าของคุณเอง เป็นความคิดที่ดีที่จะสำรอง dotfiles เหล่านี้ทั้งหมด [Stow เป็นวิธีที่ยอดเยี่ยมในการทำเช่นนั้น](https://www.youtube.com/watch?v=NoFiYOqnC4o)

### เริ่มต้นแอปของคุณเองพร้อมกับเซสชัน

หากคุณต้องการให้บางสิ่งรันทุกครั้งที่คุณเข้าสู่ระบบ — sync daemon, แอปแชท, สคริปต์ของคุณเอง — ให้ใส่ไว้ใน `~/.config/hypr/autostart.lua`:

```lua
o.launch_on_start("my-service")
```

นั่นจะเริ่มต้นคำสั่งดังกล่าวเป็นส่วนหนึ่งของเซสชัน ดังนั้นมันจึงถูกทำความสะอาดอย่างเหมาะสมเมื่อคุณออกจากระบบอีกครั้ง

### รันสคริปต์ตามเหตุการณ์ของระบบ

Omarchy จะเรียก hooks ในช่วงเวลาจำนวนหนึ่ง และคุณสามารถแขวนสคริปต์ของคุณเองไว้กับ hooks เหล่านั้นได้ พวกมันอยู่ใน `~/.config/omarchy/hooks/<event>.d/` หนึ่งไดเรกทอรีต่อหนึ่งเหตุการณ์ และไฟล์ที่สามารถเรียกใช้งานได้ทุกไฟล์ในนั้นจะรันเมื่อเหตุการณ์นั้นเกิดขึ้น:

| Event | When it runs |
| ----- | ------------ |
| `post-boot` | ทันทีหลังจากเดสก์ท็อปเริ่มต้นแล้ว |
| `post-update` | ใกล้สิ้นสุดของ `omarchy update` หลังจากแพ็กเกจ การย้ายข้อมูล และการรีสตาร์ทบริการ ก่อนที่เครื่องมือของ mise จะถูกอัปเดต |
| `pre-refresh-pacman` | หลังจาก `omarchy refresh pacman` ซิงค์การตั้งค่าแพ็กเกจใหม่ ก่อนที่มันจะอัปเดตแพ็กเกจ การเปลี่ยน channel จะรันมันในช่วงขั้นตอน refresh เดียวกันนั้น |
| `theme-set` | หลังจากเปลี่ยนธีม (ชื่อธีมอยู่ใน `$1`) |
| `font-set` | หลังจากเปลี่ยนฟอนต์ (ชื่อฟอนต์อยู่ใน `$1`) |
| `battery-low` | เมื่อแบตเตอรี่เหลือน้อย (เปอร์เซ็นต์อยู่ใน `$1`) |

hook `pre-refresh-pacman` เป็นที่ที่ repository แบบกำหนดเองหรือบรรทัด `IgnorePkg` ควรอยู่ เนื่องจากมันรันก่อนธุรกรรมของแพ็กเกจ hooks ที่เกี่ยวข้องกับการอัปเดตทั้งสองตัวจะรันในฐานะผู้ใช้ของคุณหลังจาก Omarchy ล้างการอนุญาต sudo ที่แคชไว้ ดังนั้น hook ที่ใช้ `sudo` จึงต้องการการอนุญาตของตัวเองและอาจถามรหัสผ่านของคุณ

แต่ละไดเรกทอรีเหล่านั้นมีไฟล์ `.sample` อยู่แล้วซึ่งแสดงรูปแบบของ hook — ให้ลบ `.sample` ออกจากชื่อเพื่อให้มันทำงาน ในการติดตั้งสคริปต์ที่คุณเขียนไว้ที่อื่น ให้ใช้ `omarchy hook install post-boot ~/my-hook` ซึ่งจะคัดลอกมันเข้ามาและทำให้มันสามารถเรียกใช้งานได้

### เพิ่มรายการเมนูของคุณเอง

เมนู Omarchy (`Super + Space`) สามารถขยายได้ด้วยแถวของคุณเองโดยแก้ไข `~/.config/omarchy/extensions/omarchy-menu.jsonc` รายการจะถูกกำหนดด้วย id แบบจุด และ id นั้นคือสิ่งที่วางพวกมันไว้ในโครงสร้างต้นไม้ ดังนั้น `personal` จะปรากฏบนเมนูหลัก และ `personal.notes` จะปรากฏภายในนั้น:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

การใช้ id ที่มีอยู่ซ้ำจะทำให้คุณเขียนทับแถวนั้นแทนที่จะเพิ่มแถวใหม่ ไฟล์นี้มาพร้อมกับฟิลด์ทั้งหมดที่มีอยู่ซึ่งบันทึกไว้เป็นความคิดเห็น

### เพิ่ม shell exports, functions และ aliases ของคุณเอง

Omarchy มาพร้อมกับ aliases ที่ใช้งานสะดวกและฟังก์ชันที่มีประโยชน์มากมาย แต่เป็นเรื่องธรรมดามากที่จะต้องการเพิ่มของคุณเอง คุณควรเพิ่มทั้ง aliases, functions และ exports ใน `~/.bashrc` ไฟล์นี้จะไม่ถูกเขียนทับเมื่อมีการอัปเดต หากคุณต้องการเปลี่ยนค่าเริ่มต้นใด ๆ ของ Omarchy คุณก็สามารถเพิ่มพวกมันที่นี่ได้อย่างปลอดภัยเช่นกัน

### เปลี่ยนไฟล์ภายในของ Omarchy

ฟังนะ นี่คือคอมพิวเตอร์ของคุณ คุณสามารถทำอะไรก็ได้ตามที่ต้องการกับมัน แต่ผมแนะนำว่าอย่าทำการเปลี่ยนแปลงไฟล์ใน `/usr/share/omarchy` โดยตรง พวกมันเป็นของแพ็กเกจ pacman ของ Omarchy ดังนั้นการเปลี่ยนแปลงของคุณจะถูกเขียนทับไปเฉย ๆ ในการอัปเดตครั้งถัดไป คุณควรเขียนทับค่าเริ่มต้นใด ๆ ที่คุณไม่ชอบในโฟลเดอร์ `~/.config/*` แทนจะดีกว่า

คุณสามารถเปลี่ยนเกือบทุกอย่างได้ด้วยวิธีนั้น เช่น คีย์ลัดเริ่มต้น เพียงแก้ไข `~/.config/hypr/bindings.lua` เพื่อ เช่น แทนที่ [Obsidian](https://obsidian.md/) ด้วย [Joplin](https://joplinapp.org/) (ติดตั้งด้วย `omarchy-pkg-add joplin-bin`):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` จะลบการผูกที่มีอยู่ก่อนที่จะเพิ่มสิ่งทดแทน มันรับอาร์กิวเมนต์เดียวกันกับ `o.bind` รวมถึงตัวช่วยในการเปิดใช้และตัวเลือกของการผูก ใช้ `o.bind` เพื่อเพิ่มการผูก หรือ `hl.unbind` เพื่อลบการผูกโดยไม่แทนที่มัน

หากคุณยืนยันที่จะแฮ็กไฟล์ภายในของ Omarchy ให้เปลี่ยนไปใช้ channel dev ผ่าน _Update > Channel > Dev_ นั่นจะเชื่อม Omarchy ไปยัง git checkout ของซอร์สโค้ดใน `~/omarchy` ซึ่งคุณมีอิสระที่จะเปลี่ยนแปลงได้ตามใจชอบ ไม่มีใครที่นี่จะมาบอกว่าคุณต้องทำอะไร!

### รีเซ็ตการเปลี่ยนแปลงใด ๆ

หากคุณทำให้การตั้งค่ายุ่งเหยิงในที่สุด คุณสามารถเปลี่ยนกลับไปเป็นค่าเริ่มต้นได้เสมอผ่าน _Update > Config_ ในเมนู Omarchy หรือโดยรัน `omarchy reinstall configs` เพื่อรีเซ็ตทุกอย่าง
