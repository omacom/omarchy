# Dotfiles

Omarchy ส่วนใหญ่กำหนดค่าผ่านสิ่งที่เรียกว่า dotfiles ที่อยู่ใน `~/.config` สิ่งเหล่านั้นถือเป็นไฟล์ของคุณสำหรับการเปลี่ยนแปลงของคุณ ไฟล์ที่อยู่ใน `/usr/share/omarchy` เป็นของตัว Omarchy เอง และคุณไม่ควรไปยุ่งกับพวกมัน ถ้าคุณต้องการเปลี่ยนอะไรใน `/usr/share/omarchy` คุณควรเขียนทับค่าใน `~/.config` แทน

คอนฟิกสำคัญแก้ไขตรงจากเมนู Omarchy ได้ (`Super + Space`) เช่น _ตั้งค่า > จอภาพ_, _ตั้งค่า > ปุ่มลัด_, _ตั้งค่า > อินพุต_ และ _ตั้งค่า > Config > [file]_ เมื่อคุณทำแบบนี้ กระบวนการใด ๆ ที่ต้องการรีสตาร์ตหลังแก้ไขคอนฟิกโดยอัตโนมัติจะรีสตาร์ตหลังคุณออกจากโปรแกรมแก้ไข (Neovim เป็นค่าเริ่มต้น — `:wq` จำไว้! — แต่คุณเปลี่ยนได้ผ่าน _ตั้งค่า > Defaults > Editor_)

นี่คือรายการไฟล์สำคัญใน `~/.config` และสิ่งที่พวกมันควบคุม:

| File                  | Purpose              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | คอนฟิกหลักของ Hyprland โหลดค่าเริ่มต้นของ Omarchy บวกไฟล์แทนที่ของคุณด้านล่าง [เรียนรู้เพิ่มเติมเกี่ยวกับคอนฟิก Hyprland](https://wiki.hypr.land/Configuring/)  |
| `~/.config/hypr/bindings.lua` | ปุ่มลัดของคุณเองและการแทนที่ค่าเริ่มต้น |
| `~/.config/hypr/monitors.lua` | ควบคุมจอภาพ ความละเอียด และตำแหน่งของคุณ |
| `~/.config/hypr/input.lua` | ควบคุมเค้าโครงแป้นพิมพ์ เมาส์ และการตั้งค่าแทร็กแพดของคุณ |
| `~/.config/hypr/looknfeel.lua` | ควบคุมช่องว่าง ขอบ แอนิเมชัน และรูปลักษณ์ส่วนที่เหลือ |
| `~/.config/hypr/autostart.lua` | ควบคุมกระบวนการพิเศษที่เริ่มพร้อมเซสชัน |
| `~/.config/omarchy/shell.json` | ควบคุม shell ของ Omarchy: ตำแหน่งแถบ เค้าโครง และวิดเจ็ต บวกเวลาของโปรแกรมพักหน้าจอ การล็อก และสถานะว่าง |
| `~/.config/foot/foot.ini` | ควบคุมเทอร์มินัลของคุณ (foot คือค่าเริ่มต้น) |
| `~/.XCompose` | กำหนดอีโมจิเข้าถึงด่วนและการเติมชื่อ/อีเมลอัตโนมัติของคุณ อย่าลืมรัน `omarchy-restart-xcompose` หลังทำการเปลี่ยนแปลง |

ถ้าคุณลงเอยด้วยการเปลี่ยนแปลงมากมายเพื่อปรับแต่งการตั้งค่าของคุณเอง เป็นความคิดที่ดีที่จะสำรอง dotfiles เหล่านี้ทั้งหมด [Stow เป็นวิธีที่ดีในการทำอย่างนั้น](https://www.youtube.com/watch?v=NoFiYOqnC4o)

### การเริ่มแอปของคุณเองพร้อมเซสชัน

ถ้าคุณต้องการให้อะไรบางอย่างรันทุกครั้งที่คุณเข้าสู่ระบบ — daemon ซิงค์ แอปแชท สคริปต์ของคุณเอง — ใส่มันไว้ใน `~/.config/hypr/autostart.lua`:

```lua
o.launch_on_start("my-service")
```

นั่นเริ่มคำสั่งนั้นเป็นส่วนหนึ่งของเซสชัน ดังนั้นมันจึงถูกทำความสะอาดอย่างเหมาะสมเมื่อคุณออกจากระบบอีกครั้ง

### การรันสคริปต์บนเหตุการณ์ของระบบ

Omarchy ยิง hook ในช่วงเวลาสองสามช่วง และคุณแขวนสคริปต์ของคุณเองไว้กับพวกมันได้ พวกมันอยู่ใน `~/.config/omarchy/hooks/<event>.d/` หนึ่งไดเรกทอรีต่อหนึ่งเหตุการณ์ และไฟล์ที่รันได้ทุกไฟล์ในนั้นจะรันเมื่อเหตุการณ์เกิดขึ้น:

| Event | When it runs |
| ----- | ------------ |
| `post-boot` | ทันทีหลังเดสก์ท็อปเริ่มแล้ว |
| `post-update` | ใกล้ตอนท้ายของ `omarchy update` หลังจากแพ็กเกจ การย้าย และการรีสตาร์ตบริการ ก่อนเครื่องมือ mise จะถูกอัปเดต |
| `pre-refresh-pacman` | หลัง `omarchy refresh pacman` ซิงค์คอนฟิกแพ็กเกจซ้ำ ก่อนมันอัปเดตแพ็กเกจ การสลับช่องทางจะรันมันระหว่างขั้นตอนรีเฟรชเดียวกันนั้น |
| `theme-set` | หลังเปลี่ยนธีม (ชื่อธีมอยู่ใน `$1`) |
| `font-set` | หลังเปลี่ยนฟอนต์ (ชื่อฟอนต์อยู่ใน `$1`) |
| `battery-low` | เมื่อแบตเตอรี่เหลือน้อย (เปอร์เซ็นต์อยู่ใน `$1`) |

hook `pre-refresh-pacman` คือที่ที่ที่เก็บแบบกำหนดเองหรือบรรทัด `IgnorePkg` ควรอยู่ เนื่องจากมันรันก่อนธุรกรรมแพ็กเกจ hook ที่เกี่ยวกับการอัปเดตทั้งสองรันในฐานะผู้ใช้ของคุณหลังจาก Omarchy ล้างการให้สิทธิ์ sudo ที่แคชไว้แล้ว ดังนั้น hook ที่ใช้ `sudo` ต้องการการให้สิทธิ์ของตัวเองและอาจขอรหัสผ่านของคุณ

แต่ละไดเรกทอรีเหล่านั้นมีไฟล์ `.sample` อยู่แล้วซึ่งแสดงรูปร่างของ hook — ตัด `.sample` ออกจากชื่อเพื่อนำมันไปทำงาน หากต้องการติดตั้งสคริปต์ที่คุณเขียนไว้ที่อื่น ให้ใช้ `omarchy hook install post-boot ~/my-hook` ซึ่งจะคัดลอกมันเข้ามาและทำให้มันรันได้

### การเพิ่มรายการเมนูของคุณเอง

เมนู Omarchy (`Super + Space`) ขยายด้วยแถวของคุณเองได้โดยแก้ไข `~/.config/omarchy/extensions/omarchy-menu.jsonc` รายการต่าง ๆ คีย์โดย id แบบมีจุด และ id คือสิ่งที่วางพวกมันในทรี ดังนั้น `personal` จึงโผล่บนเมนูราก และ `personal.notes` โผล่อยู่ข้างในมัน:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

ใช้ id ที่มีอยู่ซ้ำแล้วคุณจะแทนที่แถวนั้นแทนที่จะเพิ่มแถวใหม่ ไฟล์นี้มาพร้อมฟิลด์ทั้งหมดที่มีให้ซึ่งบันทึกไว้เป็นความคิดเห็น

### การเพิ่ม export ฟังก์ชัน และนามแฝง shell ของคุณเอง

Omarchy มาพร้อมนามแฝงที่เหมาะกับสรีระและฟังก์ชันที่มีประโยชน์มากมาย แต่เป็นเรื่องธรรมดามากที่จะอยากเพิ่มของคุณเอง คุณควรเพิ่มทั้งนามแฝง ฟังก์ชัน และ export ใน `~/.bashrc` ไฟล์นี้จะไม่ถูกเขียนทับเมื่ออัปเดต ถ้าคุณต้องการเปลี่ยนค่าเริ่มต้นใด ๆ ของ Omarchy คุณยังเพิ่มพวกมันไว้ที่นี่ได้อย่างปลอดภัยเช่นกัน

### การเปลี่ยนไฟล์ภายในของ Omarchy

ฟังนะ นี่คือคอมพิวเตอร์ของคุณ คุณทำอะไรกับมันก็ได้ตามต้องการ แต่ฉันขอแนะนำว่าอย่าทำการเปลี่ยนแปลงไฟล์ใน `/usr/share/omarchy` โดยตรง พวกมันเป็นของแพ็กเกจ pacman ของ Omarchy ดังนั้นการเปลี่ยนแปลงของคุณก็จะถูกเขียนทับเฉย ๆ เมื่ออัปเดตครั้งต่อไป คุณควรแคเขียนทับค่าเริ่มต้นใด ๆ ที่คุณไม่ชอบในโฟลเดอร์ `~/.config/*` แทนจะดีกว่า

คุณเปลี่ยนแทบทุกอย่างได้ด้วยวิธีนั้น เช่น ปุ่มลัดเริ่มต้น แค่แก้ไข `~/.config/hypr/bindings.lua` เพื่อ สมมติว่า แทนที่ [Obsidian](https://obsidian.md/) ด้วย [Joplin](https://joplinapp.org/) (ติดตั้งด้วย `omarchy-pkg-add joplin-bin`):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` ลบการผูกที่มีอยู่ก่อนเพิ่มตัวแทนที่ของมัน มันรับอาร์กิวเมนต์เดียวกันกับ `o.bind` รวมถึงตัวช่วยเปิดและตัวเลือกการผูก ใช้ `o.bind` เพื่อเพิ่มการผูก หรือ `hl.unbind` เพื่อลบอันหนึ่งออกโดยไม่แทนที่มัน

ถ้าคุณยืนกรานจะแฮกไฟล์ภายในของ Omarchy ให้สลับไปช่อง dev ผ่าน _อัปเดต > Channel > Dev_ นั่นเชื่อม Omarchy ไปยัง git checkout ของซอร์สโค้ดใน `~/omarchy` ซึ่งคุณเปลี่ยนได้ตามใจชอบ ไม่มีใครที่นี่จะมาบอกว่าคุณต้องทำอะไร!

### การรีเซ็ตการเปลี่ยนแปลงใด ๆ

ถ้าคุณลงเอยด้วยการทำการกำหนดค่าพะรุงพะรัง คุณสามารถย้อนพวกมันกลับไปค่าเริ่มต้นได้เสมอผ่าน _อัปเดต > Config_ ในเมนู Omarchy หรือโดยรัน `omarchy reinstall configs` เพื่อรีเซ็ตทุกอย่าง
