# Dotfiles

Omarchy กำหนดค่าส่วนใหญ่ผ่านไฟล์ที่เรียกว่า dotfiles ซึ่งอยู่ใน `~/.config` ไฟล์เหล่านั้นถือเป็นไฟล์ของคุณสำหรับการเปลี่ยนแปลงของคุณ ไฟล์ที่อยู่ใน `/usr/share/omarchy` เป็นของ Omarchy เอง และคุณไม่ควรไปยุ่งกับไฟล์เหล่านั้น หากคุณจำเป็นต้องเปลี่ยนอะไรใน `/usr/share/omarchy` คุณควรเขียนทับค่าใน `~/.config` แทน

การตั้งค่าหลักสามารถแก้ไขได้โดยตรงจากเมนู Omarchy (`Super + Space`) เช่น _Setup > Keybindings_, _Setup > Input_ และ _Setup > Config > [file]_ เมื่อคุณทำด้วยวิธีนี้ โปรเซสใดก็ตามที่ต้องรีสตาร์ทหลังจากแก้ไขการตั้งค่าจะถูกรีสตาร์ทโดยอัตโนมัติหลังจากคุณออกจากโปรแกรมแก้ไข (Neovim เป็นค่าเริ่มต้น — `:wq` อย่าลืม! — แต่คุณสามารถเปลี่ยนได้ผ่าน _Setup > Defaults > Editor_)

นี่คือรายการไฟล์หลักใน `~/.config` และสิ่งที่พวกมันควบคุม:

| File                  | Purpose              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | การตั้งค่าหลักของ Hyprland โหลดค่าเริ่มต้นของ Omarchy รวมถึงไฟล์ override ของคุณด้านล่าง [เรียนรู้เพิ่มเติมเกี่ยวกับการตั้งค่า Hyprland](https://wiki.hypr.land/Configuring/)  |
| `~/.config/hypr/bindings.lua` | การผูกปุ่มของคุณเองและการ override ค่าเริ่มต้น |
| `~/.config/hypr/monitors.lua` | การตั้งค่าจอภาพที่แผงควบคุมจอภาพไม่ครอบคลุม เช่น การหมุน โหมดเพิ่มเติม หรือการปิดจอภาพไว้ |
| `~/.config/hypr/input.lua` | ควบคุมเลย์เอาต์แป้นพิมพ์ เมาส์ และการตั้งค่า trackpad ของคุณ |
| `~/.config/hypr/looknfeel.lua` | ควบคุมช่องว่าง เส้นขอบ แอนิเมชัน และส่วนที่เหลือของรูปลักษณ์ |
| `~/.config/hypr/autostart.lua` | ควบคุมโปรเซสเพิ่มเติมที่เริ่มพร้อมกับเซสชัน |
| `~/.config/omarchy/shell.json` | ควบคุมเชลล์ของ Omarchy: ตำแหน่งแถบ เลย์เอาต์ และวิดเจ็ต รวมถึงโปรแกรมรักษาหน้าจอ การล็อก และระยะเวลา idle |
| `~/.config/foot/foot.ini` | ควบคุมเทอร์มินัลของคุณ (foot เป็นค่าเริ่มต้น) |
| `~/.XCompose` | กำหนดอีโมจิแบบเข้าถึงด่วนและการเติมชื่อ/อีเมลอัตโนมัติของคุณ อย่าลืมรัน `omarchy-restart-xcompose` หลังจากทำการเปลี่ยนแปลง |

หากสุดท้ายคุณทำการเปลี่ยนแปลงมากมายเพื่อปรับแต่งการตั้งค่าของคุณเอง ก็ควรสำรองข้อมูล dotfiles เหล่านี้ทั้งหมดไว้ [Stow เป็นวิธีที่ยอดเยี่ยมในการทำเช่นนั้น](https://www.youtube.com/watch?v=NoFiYOqnC4o)

### การเริ่มแอปของคุณเองพร้อมกับเซสชัน

หากคุณต้องการให้บางอย่างทำงานทุกครั้งที่คุณเข้าสู่ระบบ — ไม่ว่าจะเป็น daemon สำหรับซิงค์ แอปแชท หรือสคริปต์ของคุณเอง — ให้ใส่ไว้ใน `~/.config/hypr/autostart.lua`:

```lua
o.launch_on_start("my-service")
```

นั่นจะเริ่มคำสั่งดังกล่าวเป็นส่วนหนึ่งของเซสชัน ดังนั้นมันจะถูกทำความสะอาดอย่างเหมาะสมเมื่อคุณออกจากระบบอีกครั้ง

### การรันสคริปต์ตามเหตุการณ์ของระบบ

Omarchy จะเรียกใช้ hooks ในช่วงเวลาสองสามช่วง และคุณสามารถแขวนสคริปต์ของคุณเองไว้กับ hooks เหล่านั้นได้ พวกมันอยู่ใน `~/.config/omarchy/hooks/<event>.d/` หนึ่งไดเรกทอรีต่อหนึ่งเหตุการณ์ และทุกไฟล์ที่สามารถเรียกใช้งานได้ในนั้นจะทำงานเมื่อเหตุการณ์นั้นเกิดขึ้น:

| Event | When it runs |
| ----- | ------------ |
| `post-boot` | ทันทีหลังจากเดสก์ท็อปเริ่มทำงานแล้ว |
| `post-update` | ช่วงใกล้จบของ `omarchy update` หลังจากแพ็กเกจ การย้ายข้อมูล และการรีสตาร์ทบริการ ก่อนที่เครื่องมือของ mise จะถูกอัปเดต |
| `pre-refresh-pacman` | หลังจาก `omarchy refresh pacman` ซิงค์การตั้งค่าแพ็กเกจใหม่ ก่อนที่มันจะอัปเดตแพ็กเกจ การสลับช่องจะเรียกใช้มันในขั้นตอนการรีเฟรชเดียวกันนั้น |
| `theme-set` | หลังจากเปลี่ยนธีม (ชื่อธีมอยู่ใน `$1`) |
| `font-set` | หลังจากเปลี่ยนฟอนต์ (ชื่อฟอนต์อยู่ใน `$1`) |
| `battery-low` | เมื่อแบตเตอรี่เหลือน้อย (เปอร์เซ็นต์อยู่ใน `$1`) |

hook `pre-refresh-pacman` คือที่ที่ repository แบบกำหนดเองหรือบรรทัด `IgnorePkg` ควรอยู่ เนื่องจากมันทำงานก่อนธุรกรรมแพ็กเกจ hooks ที่เกี่ยวข้องกับการอัปเดตทั้งสองตัวจะทำงานในฐานะผู้ใช้ของคุณ หลังจาก Omarchy ล้างการอนุญาต sudo ที่แคชไว้ ดังนั้น hook ที่ใช้ `sudo` จะต้องการการอนุญาตของตัวเอง และอาจขอรหัสผ่านของคุณ

แต่ละไดเรกทอรีเหล่านั้นมีไฟล์ `.sample` ที่แสดงรูปแบบของ hook อยู่แล้ว — ให้เอา `.sample` ออกจากชื่อเพื่อให้มันเริ่มทำงาน หากต้องการติดตั้งสคริปต์ที่คุณเขียนไว้ที่อื่น ให้ใช้ `omarchy hook install post-boot ~/my-hook` ซึ่งจะคัดลอกมันเข้าไปและทำให้มันสามารถเรียกใช้งานได้

### การเพิ่มรายการเมนูของคุณเอง

เมนู Omarchy (`Super + Space`) สามารถขยายได้ด้วยแถวของคุณเองโดยการแก้ไข `~/.config/omarchy/extensions/omarchy-menu.jsonc` รายการต่าง ๆ จะถูกกำหนดคีย์ด้วย id แบบมีจุด และ id นั่นแหละคือสิ่งที่จัดวางพวกมันในโครงสร้างต้นไม้ ดังนั้น `personal` จะปรากฏบนเมนูหลัก และ `personal.notes` จะปรากฏอยู่ภายในนั้น:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

การใช้ id ที่มีอยู่ซ้ำจะทำให้คุณเขียนทับแถวนั้นแทนที่จะเพิ่มแถวใหม่ ไฟล์นี้มาพร้อมกับฟิลด์ทั้งหมดที่ใช้ได้ซึ่งอธิบายไว้เป็นความคิดเห็น

### การเพิ่ม shell exports, functions และ aliases ของคุณเอง

Omarchy มาพร้อมกับ aliases ที่ใช้งานสะดวกและ functions ที่มีประโยชน์มากมาย แต่เป็นเรื่องปกติมากที่คุณจะอยากเพิ่มของตัวเอง คุณควรเพิ่มทั้ง aliases, functions และ exports ใน `~/.bashrc` ไฟล์นี้จะไม่ถูกเขียนทับเมื่ออัปเดต หากคุณต้องการเปลี่ยนค่าเริ่มต้นใด ๆ ของ Omarchy คุณก็สามารถเพิ่มไว้ที่นี่ได้อย่างปลอดภัยเช่นกัน

### การตั้งค่าตัวแปรสภาพแวดล้อมสำหรับเดสก์ท็อป

exports ของเซสชันเดสก์ท็อปควรอยู่ใน `~/.config/uwsm/env.d/` ไฟล์เหล่านี้จะทำงานก่อนที่เดสก์ท็อปของคุณจะเริ่ม ดังนั้นข้อผิดพลาดของเชลล์อาจส่งคุณกลับไปที่หน้าจอเข้าสู่ระบบได้ ให้เปิดเทอร์มินัลที่ใช้งานได้ทิ้งไว้ขณะแก้ไขไฟล์เหล่านี้ หากต้องการปิดการใช้งาน override ให้ย้ายมันออกจาก `env.d` ดู [การกู้คืนการเข้าสู่ระบบ](45-troubleshooting.md#my-password-is-accepted-but-i-return-to-the-login-screen) หากการเปลี่ยนแปลงทำให้เข้าสู่ระบบไม่ได้

### การเปลี่ยนไฟล์ภายในของ Omarchy

ฟังนะ นี่คือคอมพิวเตอร์ของคุณ คุณจะทำอะไรกับมันก็ได้ตามที่ต้องการ แต่ฉันแนะนำว่าไม่ควรทำการเปลี่ยนแปลงไฟล์ใน `/usr/share/omarchy` โดยตรง พวกมันเป็นของแพ็กเกจ pacman ของ Omarchy ดังนั้นการเปลี่ยนแปลงของคุณจะถูกเขียนทับในการอัปเดตครั้งถัดไป คุณควรเขียนทับค่าเริ่มต้นใด ๆ ที่คุณไม่ชอบในโฟลเดอร์ `~/.config/*` แทนจะดีกว่า

คุณสามารถเปลี่ยนได้แทบทุกอย่างด้วยวิธีนั้น เช่น การผูกปุ่มเริ่มต้น เพียงแก้ไข `~/.config/hypr/bindings.lua` เพื่อ เช่น แทนที่ [Obsidian](https://obsidian.md/) ด้วย [Joplin](https://joplinapp.org/) (ติดตั้งด้วย `omarchy-pkg-add joplin-bin`):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` จะลบการผูกที่มีอยู่ก่อนที่จะเพิ่มตัวแทนที่เข้ามาแทน มันรับอาร์กิวเมนต์เดียวกันกับ `o.bind` รวมถึงตัวช่วยเปิดโปรแกรมและตัวเลือกการผูก ใช้ `o.bind` เพื่อเพิ่มการผูก หรือ `hl.unbind` เพื่อลบการผูกโดยไม่ต้องแทนที่

หากคุณยืนยันจะแฮ็กไฟล์ภายในของ Omarchy ให้เปลี่ยนไปใช้ช่อง dev ผ่าน _Update > Channel > Dev_ ซึ่งจะลิงก์ Omarchy ไปยัง git checkout ของซอร์สโค้ดใน `~/omarchy` ซึ่งคุณสามารถเปลี่ยนได้ตามใจชอบเลย ไม่มีใครที่นี่จะมาบอกว่าคุณต้องทำอะไรหรอก!

### การรีเซ็ตการเปลี่ยนแปลงใด ๆ

หากสุดท้ายคุณทำการตั้งค่าพังเละเทะ คุณก็สามารถย้อนกลับไปเป็นค่าเริ่มต้นได้เสมอผ่าน _Update > Config_ ในเมนู Omarchy หรือด้วยการรัน `omarchy reinstall configs` เพื่อรีเซ็ตทุกอย่าง
