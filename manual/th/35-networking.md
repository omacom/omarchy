# เครือข่าย

ระบบเครือข่ายใน Omarchy จัดการโดย NetworkManager และคุณควบคุมมันได้จากไอคอนเครือข่ายใน [แถบด้านบน](05-the-top-bar.md) หรือด้วย `Super + Ctrl + N`

แผงนั้นจะสแกนหาเครือข่าย Wi-Fi แสดงความแรงของสัญญาณ และเชื่อมต่อให้ ส่วน Ethernet ไม่ต้องทำอะไรเลย — เสียบสายแล้วใช้งานได้ทันที หากคุณอยากอยู่ในเทอร์มินัลมากกว่า `nmtui` ก็ให้การควบคุมแบบเดียวกันกับคุณ และยังมีกลุ่มคำสั่ง `omarchy network` ด้วย

## การแชร์ Wi-Fi ของคุณ

แทนที่จะต้องอ่านรหัสผ่านยาว ๆ ออกเสียง ให้เปิด _Setup > Network > QR Code_ ขณะที่คุณเชื่อมต่อ Wi-Fi อยู่ หน้าจอจะแสดง QR Code ที่กล้องโทรศัพท์เครื่องใดก็สแกนเพื่อเข้าร่วมเครือข่ายได้ เป็นหนึ่งในสิ่งที่คุณจะได้ใช้บ่อยกว่าที่คาดเมื่อรู้ว่ามันอยู่ตรงนั้น

หากคุณต้องการรหัสผ่านจริง ๆ `omarchy network password <interface>` จะพิมพ์มันออกมา

## DNS

Omarchy ใช้ DNS ใดก็ตามที่เครือข่ายของคุณแจกให้ผ่าน DHCP คุณสามารถแทนที่ค่านั้นสำหรับเครื่องทั้งเครื่องได้ที่ _Setup > Network > DNS_ ซึ่ง Cloudflare และ Google อยู่ห่างแค่คลิกเดียว เลือก _Custom_ เพื่อพิมพ์เซิร์ฟเวอร์ของคุณเอง

จากเทอร์มินัล `omarchy dns` จะพิมพ์ผู้ให้บริการปัจจุบัน และ `omarchy dns Cloudflare` จะตั้งค่าหนึ่งรายการ

## การตรึงย่านความถี่ Wi-Fi

หากเราเตอร์ของคุณใช้ชื่อเครือข่ายเดียวกันสำหรับ 2.4GHz, 5GHz และ 6GHz แล็ปท็อปของคุณบางครั้งจะเกาะย่านที่ช้าอยู่ต่อไป `omarchy network band` จะแสดงว่าคุณอยู่บนย่านใด และ `omarchy network band 5` จะตรึงไว้ ใช้ `auto` เพื่อให้มันเลือกอีกครั้ง

วิธีนี้ตรึงย่านความถี่ ไม่ใช่จุดเชื่อมต่อเฉพาะจุด ดังนั้นคุณจึงยังโรมมิ่งระหว่าง AP ได้ตามปกติ

## มันเร็วแค่ไหน?

_Trigger > Speed Test > Network Speed Test_ จะวัดความเร็วอัปโหลดและดาวน์โหลดจริงของคุณด้วยมาตรวัดคู่หนึ่ง จากเทอร์มินัลใช้ `omarchy network speedtest down` หรือ `up` มันวัดกับบริการของ Omarchy เอง และนับเฉพาะการถ่ายโอนเพื่อทดสอบของมันเท่านั้น การดาวน์โหลดอื่น ๆ อาจแย่งแบนด์วิดท์ได้ แต่จะไม่ถูกบวกเข้าไปในผลการทดสอบความเร็ว (มีการทดสอบความเร็วดิสก์อยู่ข้าง ๆ กันในเมนูนั้นด้วย หากคุณกำลังวัดประสิทธิภาพของคอขวดอีกตัวหนึ่งอยู่)

## ไฟร์วอลล์

ไฟร์วอลล์เปิดอยู่เป็นค่าเริ่มต้นและบล็อกการรับส่งข้อมูลขาเข้าทั้งหมด โดยมีข้อยกเว้นเพียงอย่างเดียวคือพอร์ต 53317 เพื่อให้ [LocalSend](22-guis.md) ใช้งานได้ทันที

SSH จะปิดอยู่จนกว่าคุณจะเปิดด้วย _Setup > Security > SSHD_ ซึ่งจะเริ่ม daemon เปิดพอร์ต 22 แบบจำกัดอัตราเพื่อป้องกันการเดารหัสแบบ brute force และอนุญาตคีย์ Docker ก็ถูกล็อกไว้เช่นกัน เพื่อไม่ให้คอนเทนเนอร์เปิดตัวเองออกสู่โลกภายนอกโดยไม่ตั้งใจ ดูเรื่องราวทั้งหมดได้ที่ [ความปลอดภัย](48-security.md)

## Tailscale

[Tailscale](https://tailscale.com/) เป็น mesh VPN ที่ทำให้การเข้าถึงคอมพิวเตอร์และเซิร์ฟเวอร์ทั้งหมดของคุณผ่านอินเทอร์เน็ตเป็นเรื่องง่ายและปลอดภัย ติดตั้งได้ด้วย _Install > Service > Tailscale_

นั่นจะให้แผง Tailscale ในแถบ ซึ่งใช้เชื่อมต่อและตัดการเชื่อมต่อ tailnet สลับบัญชี และเลือก exit node — ทั้งเครื่องของคุณเองและภูมิภาคของ Mullvad จะปรากฏในรายการ นอกจากนี้ยังเรียกดูเครื่องของคุณได้ และนั่นคือที่ที่ Taildrop อยู่: เลือกเครื่องหนึ่งแล้วกด `s` เพื่อส่งไฟล์ไปให้มัน หรือกด `c`, `n` และ `d` เพื่อคัดลอก IP ชื่อ หรือชื่อ DNS แบบเต็มของมัน คำสั่งเทียบเท่าในเทอร์มินัลคือ `omarchy tailscale send <machine> [file...]` และไฟล์ที่ส่งมาหาคุณจะมาอยู่ใน `~/Downloads` โดยอัตโนมัติ การแจ้งเตือนที่ประกาศว่ามีไฟล์มาถึงจะรอจนกว่าคุณจะคลิกเปิดหรือปิดมัน ดังนั้นไฟล์ที่มาถึงขณะที่คุณไม่อยู่ที่เครื่องจะยังคงอยู่ให้คุณตอบสนองเมื่อคุณกลับมา

การติดตั้งยังเพิ่มเว็บแอปสำหรับคอนโซลผู้ดูแลระบบของ Tailscale ด้วย

## เมื่อมันหยุดทำงาน

ก่อนรีบูต ให้ลองรีสตาร์ทเฉพาะส่วนที่มีปัญหาด้วยตัวเองก่อน _Update > Hardware_ มี Wi-Fi, Bluetooth, Audio และ Trackpad และการโหลดหนึ่งในนั้นใหม่มักแก้สถานการณ์ "มันยังใช้ได้เมื่อห้านาทีที่แล้ว" ส่วนใหญ่ได้ ดู [การแก้ปัญหา](45-troubleshooting.md)
