# เครือข่าย

การจัดการเครือข่ายใน Omarchy จัดการโดย NetworkManager และคุณควบคุมได้จากไอคอนเครือข่ายใน [แถบด้านบน](05-the-top-bar.md) หรือด้วย `Super + Ctrl + N`

แผงนั้นจะสแกนหาเครือข่าย Wi-Fi แสดงความแรงของสัญญาณ และเชื่อมต่อ Ethernet ไม่ต้องทำอะไรเลย — เสียบสายแล้วก็ใช้งานได้ทันที หากคุณอยากอยู่ใน terminal มากกว่า `nmtui` ก็ให้การควบคุมแบบเดียวกัน และยังมีกลุ่มคำสั่ง `omarchy network` อีกด้วย

## การแชร์ Wi-Fi ของคุณ

แทนที่จะอ่านรหัสผ่านยาว ๆ ออกมาดัง ๆ ให้รัน _Setup > Network > QR Code_ ขณะที่คุณเชื่อมต่อ Wi-Fi อยู่ นั่นจะแสดง QR code บนหน้าจอที่กล้องโทรศัพท์เครื่องใดก็สแกนเพื่อเข้าร่วมได้ เป็นหนึ่งในสิ่งที่คุณจะใช้บ่อยกว่าที่คิดเมื่อรู้ว่ามันอยู่ตรงนั้น

หากคุณจำเป็นต้องใช้ตัวรหัสผ่านเองจริง ๆ `omarchy network password <interface>` จะพิมพ์มันออกมา

## DNS

Omarchy ใช้ DNS ใดก็ตามที่เครือข่ายของคุณแจกผ่าน DHCP คุณสามารถแทนที่ค่านั้นสำหรับทั้งเครื่องได้ภายใต้ _Setup > Network > DNS_ ซึ่ง Cloudflare และ Google อยู่ห่างไปเพียงคลิกเดียว เลือก _Custom_ เพื่อพิมพ์เซิร์ฟเวอร์ของคุณเอง

จาก terminal `omarchy dns` จะพิมพ์ผู้ให้บริการปัจจุบัน และ `omarchy dns Cloudflare` จะตั้งค่าผู้ให้บริการนั้น

## การตรึงย่านความถี่ Wi-Fi

หากเราเตอร์ของคุณรวม 2.4GHz, 5GHz และ 6GHz ไว้ในชื่อเครือข่ายเดียวกัน แล็ปท็อปของคุณจะเกาะติดกับย่านที่ช้าอยู่บางครั้ง `omarchy network band` จะแสดงว่าคุณอยู่บนย่านใด และ `omarchy network band 5` จะตรึงไว้ ใช้ `auto` เพื่อให้มันเลือกเองอีกครั้ง

วิธีนี้ตรึงย่านความถี่แทนที่จะเป็น access point ตัวใดตัวหนึ่ง ดังนั้นคุณยังคงโรมมิ่งระหว่าง APs ได้ตามปกติ

## มันเร็วแค่ไหน?

_Trigger > Speed Test > Network Speed Test_ จะวัดความเร็วอัปโหลดและดาวน์โหลดจริงของคุณด้วยหน้าปัดคู่หนึ่ง จาก terminal คือ `omarchy network speedtest down` หรือ `up` (มี disk speed test อยู่ข้าง ๆ ในเมนูนั้นด้วย เผื่อคุณกำลัง benchmarking คอขวดอีกตัวอยู่)

## ไฟร์วอลล์

ไฟร์วอลล์เปิดอยู่เป็นค่าเริ่มต้นและบล็อกการรับส่งข้อมูลขาเข้าทั้งหมด โดยมีข้อยกเว้นเพียงหนึ่งเดียวคือ port 53317 เพื่อให้ [LocalSend](22-guis.md) ใช้งานได้ทันที

SSH ปิดอยู่จนกว่าคุณจะเปิดด้วย _Setup > Security > SSHD_ ซึ่งจะเริ่ม daemon เปิด port 22 แบบจำกัดอัตราเพื่อป้องกัน brute force และอนุญาตคีย์ Docker ก็ถูกล็อกไว้เช่นกัน ดังนั้น containers จึงไม่สามารถเผลอเปิดตัวเองออกสู่โลกภายนอกได้โดยไม่ตั้งใจ ดู [ความปลอดภัย](48-security.md) สำหรับเรื่องราวทั้งหมด

## Tailscale

[Tailscale](https://tailscale.com/) คือ mesh VPN ที่ทำให้การเข้าถึงคอมพิวเตอร์และเซิร์ฟเวอร์ทั้งหมดของคุณผ่านอินเทอร์เน็ตเป็นเรื่องง่ายและปลอดภัย ติดตั้งด้วย _Install > Service > Tailscale_

นั่นจะให้แผง Tailscale ในแถบ ซึ่งเชื่อมต่อและตัดการเชื่อมต่อ tailnet สลับบัญชี และเลือก exit node — ทั้งเครื่องของคุณเองและภูมิภาคของ Mullvad จะปรากฏในรายการ นอกจากนี้ยังเรียกดูเครื่องของคุณได้ และนั่นคือที่ที่ Taildrop อยู่: เลือกเครื่องหนึ่งแล้วกด `s` เพื่อส่งไฟล์ไปให้ หรือ `c`, `n` และ `d` เพื่อคัดลอก IP, ชื่อ หรือชื่อ DNS เต็มของมัน สิ่งที่เทียบเท่าใน terminal คือ `omarchy tailscale send <machine> [file...]` และไฟล์ที่ส่งมาหาคุณจะลงจอดใน `~/Downloads` โดยอัตโนมัติ การแจ้งเตือนที่ประกาศการมาถึงจะรอจนกว่าคุณจะคลิกเปิดหรือปิดทิ้ง ดังนั้นไฟล์ที่ปรากฏขึ้นขณะคุณไม่อยู่ที่เครื่องจะยังอยู่รอให้คุณตอบกลับเมื่อคุณกลับมา

การติดตั้งมันยังเพิ่ม web app สำหรับ Tailscale admin console อีกด้วย

## เมื่อมันหยุดทำงาน

ก่อนรีบูต ลองรีสตาร์ทเฉพาะชิ้นที่ก่อปัญหาแยกต่างหาก _Update > Hardware_ มี Wi-Fi, Bluetooth, Audio และ Trackpad และการโหลดหนึ่งในนั้นใหม่จะแก้สถานการณ์ "มันเพิ่งใช้ได้เมื่อห้านาทีก่อน" ส่วนใหญ่ได้ ดู [การแก้ไขปัญหา](45-troubleshooting.md)
