# เครือข่าย

เครือข่ายใน Omarchy จัดการโดย NetworkManager และคุณควบคุมมันจากไอคอนเครือข่ายใน [แถบบน](05-the-top-bar.md) หรือด้วย `Super + Ctrl + W`

แผงนั้นสแกนหาเครือข่าย Wi-Fi แสดงความแรงของสัญญาณ และเชื่อมต่อให้ ส่วน Ethernet ไม่ต้องทำอะไรเลย — เสียบสายเข้าไปก็ใช้งานได้ ถ้าคุณอยากอยู่ในเทอร์มินัลมากกว่า `nmtui` ให้การควบคุมแบบเดียวกัน และยังมีกลุ่มคำสั่ง `omarchy network` ด้วย

## การแชร์ Wi-Fi ของคุณ

แทนที่จะอ่านรหัสผ่านยาว ๆ ออกเสียง ให้รัน _ตั้งค่า > เครือข่าย > QR Code_ ขณะที่คุณเชื่อมต่อ Wi-Fi อยู่ ระบบจะแสดง QR code บนหน้าจอที่กล้องโทรศัพท์เครื่องไหนก็สแกนเพื่อเข้าร่วมได้ เป็นหนึ่งในสิ่งที่คุณจะใช้บ่อยกว่าที่คิดเมื่อรู้ว่ามันอยู่ตรงนั้น

ถ้าคุณต้องการตัวรหัสผ่านเองจริง ๆ `omarchy network password <interface>` จะพิมพ์มันออกมา

## DNS

Omarchy ใช้ DNS อะไรก็ตามที่เครือข่ายของคุณแจกผ่าน DHCP คุณสามารถแทนที่ค่านั้นสำหรับทั้งเครื่องได้ภายใต้ _ตั้งค่า > เครือข่าย > DNS_ ซึ่ง Cloudflare และ Google อยู่ห่างเพียงคลิกเดียว เลือก _กำหนดเอง_ เพื่อพิมพ์เซิร์ฟเวอร์ของคุณเอง

จากเทอร์มินัล `omarchy dns` จะพิมพ์ผู้ให้บริการปัจจุบัน และ `omarchy dns Cloudflare` จะตั้งค่าให้

## การตรึงย่านความถี่ Wi-Fi

ถ้าเราเตอร์ของคุณรวม 2.4GHz, 5GHz และ 6GHz ไว้ในชื่อเครือข่ายเดียวกัน แล็ปท็อปของคุณบางครั้งจะยึดติดกับย่านที่ช้า `omarchy network band` แสดงว่าคุณอยู่ย่านไหน และ `omarchy network band 5` จะตรึงมันไว้ ใช้ `auto` เพื่อให้มันเลือกอีกครั้ง

วิธีนี้ตรึงย่านความถี่แทนที่จะเป็นจุดเข้าใช้งานเฉพาะจุด คุณจึงยังโรมมิ่งระหว่าง AP ได้ตามปกติ

## เร็วแค่ไหน?

_สั่งการ > ทดสอบความเร็ว > ทดสอบความเร็วเครือข่าย_ วัดความเร็วอัปโหลดและดาวน์โหลดจริงของคุณด้วยหน้าปัดคู่หนึ่ง จากเทอร์มินัลคือ `omarchy network speedtest down` หรือ `up` (มีการทดสอบความเร็วดิสก์อยู่ข้าง ๆ ในเมนูนั้นด้วย ถ้าคุณกำลังวัดประสิทธิภาพคอขวดอีกจุดหนึ่ง)

## ไฟร์วอลล์

ไฟร์วอลล์เปิดอยู่เป็นค่าเริ่มต้นและบล็อกทราฟฟิกขาเข้าทั้งหมด โดยมีข้อยกเว้นเพียงข้อเดียวคือ พอร์ต 53317 เพื่อให้ [LocalSend](22-guis.md) ใช้งานได้ทันที

SSH จะปิดอยู่จนกว่าคุณจะเปิดมันด้วย _ตั้งค่า > ความปลอดภัย > SSHD_ ซึ่งจะเริ่ม daemon เปิดพอร์ต 22 แบบจำกัดอัตราต่อการเดารหัสแบบ brute force และอนุญาตคีย์ Docker ก็ถูกล็อกดาวน์เช่นกัน คอนเทนเนอร์จึงไม่สามารถเปิดตัวเองสู่โลกภายนอกโดยไม่ได้ตั้งใจ ดูเรื่องราวทั้งหมดได้ที่ [ความปลอดภัย](48-security.md)

## Tailscale

[Tailscale](https://tailscale.com/) เป็น mesh VPN ที่ทำให้การเข้าถึงคอมพิวเตอร์และเซิร์ฟเวอร์ทั้งหมดของคุณผ่านอินเทอร์เน็ตเป็นเรื่องง่ายและปลอดภัย ติดตั้งมันด้วย _ติดตั้ง > บริการ > Tailscale_

นั่นจะทำให้คุณมีแผง Tailscale ในแถบ ซึ่งเชื่อมต่อและตัดการเชื่อมต่อ tailnet สลับบัญชี และเลือก exit node — เครื่องของคุณเองและภูมิภาค Mullvad ทั้งคู่จะปรากฏในรายการ มันยังเรียกดูเครื่องของคุณได้ และนั่นคือที่อยู่ของ Taildrop: เลือกเครื่องหนึ่งแล้วกด `s` เพื่อส่งไฟล์ไปให้ หรือ `c`, `n` และ `d` เพื่อคัดลอก IP ชื่อ หรือชื่อ DNS เต็มของมัน คำสั่งเทียบเท่าในเทอร์มินัลคือ `omarchy tailscale send <machine> [file...]` และไฟล์ที่ส่งมาหาคุณจะลงจอดใน `~/Downloads` โดยอัตโนมัติ การแจ้งเตือนที่ประกาศการมาถึงจะรอจนกว่าคุณจะคลิกเปิดหรือปิดมัน ไฟล์ที่โผล่มาตอนคุณไม่อยู่ที่เครื่องจึงยังอยู่ให้ตอบเมื่อคุณกลับมา

การติดตั้งมันยังเพิ่มเว็บแอปสำหรับคอนโซลผู้ดูแล Tailscale ด้วย

## เมื่อมันหยุดทำงาน

ก่อนรีบูต ลองรีสตาร์ตชิ้นส่วนที่เป็นปัญหาเพียงชิ้นเดียวก่อน _อัปเดต > ฮาร์ดแวร์_ มี Wi-Fi, Bluetooth, เสียง และแทร็กแพด และการโหลดหนึ่งในนั้นใหม่ช่วยแก้สถานการณ์ "ห้านาทีก่อนยังใช้ได้อยู่เลย" ส่วนใหญ่ได้ ดู [การแก้ไขปัญหา](45-troubleshooting.md)
