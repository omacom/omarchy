# คลิปบอร์ดและประวัติแบบรวมศูนย์

โดยปกติบน Linux คุณต้องใช้ `Ctrl + Shift + C/V` เพื่อคัดลอกและวางในเทอร์มินัล และใช้ `Ctrl + C/V` เพื่อทำทุกที่อื่น นั่นเป็นสิ่งที่ปรับตัวได้ยากสำหรับใครก็ตามที่ไม่ได้เติบโตมากับ Linux! และการสลับจาก super ไป ctrl ก็เช่นเดียวกัน หากคุณมาจาก Mac

Omarchy แก้ปัญหาทั้งสองอย่างด้วยปุ่มลัดคลิปบอร์ดแบบรวมศูนย์ที่ใช้งานได้ (เกือบ) ทุกที่ ปุ่มเหล่านั้นคือ:

| ปุ่มลัด | คำสั่ง |
| ------- | ----------- |
| Super + C | คัดลอก |
| Super + X | ตัด |
| Super + V | วาง |
| Super + Ctrl + V | ประวัติคลิปบอร์ด |

_โปรดทราบว่าตัวรันเอเจนต์ส่วนใหญ่จะใช้ `Ctrl + V` สำหรับการวางภาพ แต่ใช้ `Super + V` สำหรับการวางข้อความ_

### ประวัติคลิปบอร์ด

ประวัติคลิปบอร์ดให้บริการโดย Omarchy shell และใช้งานได้ทั้งข้อความและภาพ คุณเรียกมันด้วย `Super + Ctrl + V` เลือกรายการของคุณด้วย return แล้วรายการนั้นจะถูกวางไว้บนคลิปบอร์ดพร้อมวางด้วย `Super + V`
