# คลิปบอร์ดแบบรวมเป็นหนึ่งและประวัติ

ปกติบน Linux คุณต้องใช้ `Ctrl + Shift + C/V` เพื่อคัดลอกและวางในเทอร์มินัล และใช้ `Ctrl + C/V` เพื่อทำแบบเดียวกันในที่อื่น ๆ นั่นเป็นเรื่องที่ต้องใช้เวลาทำความคุ้นเคยสำหรับใครก็ตามที่ไม่ได้เกิดและเติบโตมากับ Linux! การเปลี่ยนจาก super ไปเป็น ctrl ก็เช่นเดียวกัน หากคุณย้ายมาจาก Mac

Omarchy จัดการทั้งสองปัญหานี้ด้วยแป้นลัดคลิปบอร์ดแบบรวมเป็นหนึ่งที่ใช้งานได้ (เกือบ) ทุกที่ ได้แก่:

| แป้นลัด | คำสั่ง |
| ------- | ----------- |
| Super + A | เลือกทั้งหมด |
| Super + C | คัดลอก |
| Super + X | ตัด |
| Super + V | วาง |
| Super + Ctrl + V | ประวัติคลิปบอร์ด |

_โปรดทราบว่า agent harness ส่วนใหญ่จะใช้ `Ctrl + V` สำหรับวางรูปภาพ แต่ใช้ `Super + V` สำหรับวางข้อความ_

ใช้ `Super + A` แล้วตามด้วย `Super + C` เพื่อคัดลอกทุกอย่างในช่องข้อความที่โฟกัสอยู่หรือแอปอื่นที่รองรับ `Ctrl + A` ในเทอร์มินัล `Ctrl + A` จะย้ายไปยังจุดเริ่มต้นของบรรทัดคำสั่งแทนที่จะเลือกข้อความของมัน

### ประวัติคลิปบอร์ด

ประวัติคลิปบอร์ดให้บริการโดย Omarchy shell และใช้งานได้ทั้งกับข้อความและรูปภาพ คุณเรียกใช้งานได้ด้วย `Super + Ctrl + V` และเลือกรายการของคุณด้วย return ซึ่งจะวางมันลงในแอปที่คุณอยู่ก่อนหน้านี้โดยตรง ใช้ `Shift + Return` เพื่อเพียงคัดลอกมันไปยังคลิปบอร์ด ใช้ `Alt + Return` เพื่อเปิดมัน ใช้ `Delete` เพื่อลบมันออกจากประวัติ และใช้ `Shift + Delete` เพื่อล้างประวัติทั้งหมด
