# แพ็กเกจอื่น ๆ

Arch มีแพ็กเกจมหาศาลอย่างน่าอัศจรรย์ให้สำหรับซอฟต์แวร์แทบทุกประเภท ระหว่างที่เก็บอย่างเป็นทางการกับ Arch User Repository (AUR)

มันใช้ง่ายสุด ๆ ด้วยเช่นกัน คุณติดตั้งแพ็กเกจ Arch ใหม่โดยไปที่ _ติดตั้ง > Package_ ในเมนู Omarchy (`Super + Space`) แล้วพิมพ์แพ็กเกจที่คุณต้องการ มันจะคัดกรองรายการแพ็กเกจทั้งหมดแบบ fuzzy โดยอัตโนมัติ (คุณยังทำด้วยมือโดยใช้ `omarchy pkg add [package]` ในเทอร์มินัลได้ด้วย)

คุณทำสิ่งเดียวกันกับ AUR ได้ แค่ใช้ _ติดตั้ง > AUR_ แค่จำไว้ว่า AUR ไม่ได้รับการตรวจสอบโดยทีม Arch มันเหมือน RubyGems หรือ npm ใครก็อัปโหลดได้

ถ้าคุณต้องการลบแพ็กเกจ คุณสามารถใช้ _นำออก > Package_ จากเมนู Omarchy มันจะลบแพ็กเกจ ไฟล์คอนฟิก และสิ่งที่ต้องพึ่งพา (คุณยังทำด้วยมือโดยใช้ `omarchy pkg drop [package]` ได้ด้วย)
