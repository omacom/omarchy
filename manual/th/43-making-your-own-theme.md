# การสร้างธีมของคุณเอง

คุณสามารถเพิ่มธีมของคุณเองลงใน `~/.config/omarchy/themes` ได้ เพียงคัดลอกธีมที่มีอยู่แล้วธีมหนึ่งมาเป็นพื้นฐาน (ดูได้ใน `/usr/share/omarchy/themes`) แล้วปรับแต่งตามใจชอบ ตราบใดที่ธีมของคุณอยู่ในโฟลเดอร์นั้น มันก็จะถูกรวมอยู่ในเมนูเลือกธีม

ไฟล์หลักที่คุณต้องปรับแต่งคือ `colors.toml` ไฟล์นี้กำหนดชุดสีที่จะนำไปใช้สร้างการตั้งค่าให้กับเทอร์มินัล (Foot/Alacritty/Ghostty/Kitty), btop, Chromium, Hyprland, Neovim, Helix, VSCode, Obsidian และเชลล์ทั้งหมดของ Omarchy (แถบด้านบน, เมนู, การแจ้งเตือน, OSD และหน้าจอล็อก)

คุณยังสามารถใช้แอปพลิเคชัน Aether ที่มาพร้อมกันเพื่อสร้างธีมใหม่โดยใช้ส่วนติดต่อผู้ใช้แบบ GUI ที่สวยงามเพื่อทดลองเล่นกับสีและค้นหาพื้นหลังได้ เพียงเปิดจากตารางแอปด้วย `Super + Alt + Space`

### สิ่งที่ธีมที่ติดตั้งแล้วสามารถบรรจุได้

ธีมที่คุณเขียนเองใน `~/.config/omarchy/themes` สามารถบรรจุอะไรก็ได้ตามที่คุณต้องการ — นี่คือเครื่องของคุณและไฟล์ของคุณ และ Omarchy จะนำทั้งหมดไปใช้

ธีมที่คุณติดตั้งจาก repo ของผู้อื่นด้วย `omarchy theme install` จะเก็บทุกอย่างที่เป็นสีไว้ และจะตัดไฟล์จำนวนหนึ่งที่อาจรันโค้ดบนเครื่องของคุณออกไป ได้แก่ ไฟล์ `.lua` ทุกไฟล์, ไฟล์ตั้งค่าของเทอร์มินัล (`alacritty.toml`, `foot.ini`, `ghostty.conf`, `kitty.conf`) และ `vscode.json` ไฟล์ `hyprland.lua` ของธีมคือ Lua ที่ compositor ของคุณรันตอนเข้าสู่ระบบ, ไฟล์ตั้งค่าเทอร์มินัลระบุชื่อโปรแกรมที่เทอร์มินัลของคุณจะเริ่มทำงาน และ `vscode.json` ระบุชื่อส่วนขยาย VSCode ที่จะติดตั้ง การติดตั้งธีมของผู้อื่นควรเปลี่ยนรูปลักษณ์ของเดสก์ท็อปของคุณ ไม่ควรเปลี่ยนสิ่งที่มันรันเลย

ทุกอย่างอื่นยังคงทำงานตรงตามที่ผู้เขียนธีมเขียนไว้ — `btop.theme`, `chromium.theme`, `helix.toml`, `icons.theme`, `shell.toml`, ภาพพื้นหลังและภาพตัวอย่างทั้งหมดจะถูกเก็บไว้ มีเพียงสิ่งที่ถูกตัดออกไปเท่านั้นที่จะถูกสร้างขึ้นใหม่จาก `colors.toml` บนเครื่องของคุณ

Omarchy แยกแยะทั้งสองแบบออกจากกันโดยดูว่าธีมนั้นมี git repo ของตัวเองอยู่ข้างในหรือไม่ ซึ่งเป็นสิ่งที่ `omarchy theme install` ทิ้งไว้เมื่อมันทำการโคลน ดังนั้นธีมที่คุณเขียนจึงยังคงเป็นของคุณต่อไป และธีมที่คุณดึงมาจากอินเทอร์เน็ตก็จะคงเป็นเพียงเรื่องสีเท่านั้น

### โหมดสว่าง

หากคุณกำลังทำธีมโหมดสว่าง ให้ตั้งค่า `mode = "light"` ไว้ที่ด้านบนของไฟล์ `colors.toml` ของคุณ จากนั้นมันจะจับคู่กับโหมดสว่างสำหรับทุกแอปโดยอัตโนมัติ (วิธีแบบเก่าที่วางไฟล์เปล่าชื่อ `light.mode` ไว้ที่รูทของธีมก็ยังใช้งานได้เช่นกัน)

### สีของไอคอน

หากคุณต้องการให้ไอคอนของตัวจัดการไฟล์มีสีที่เข้ากับธีมของคุณ ให้เพิ่มไฟล์ชื่อ `icons.theme` พร้อมชื่อของชุดไอคอนที่คุณต้องการใช้ โดยค่าเริ่มต้น ตัวเลือกที่มีคือ: `Yaru Yaru-blue Yaru-dark Yaru-magenta Yaru-olive Yaru-prussiangreen Yaru-purple Yaru-red Yaru-sage Yaru-wartybrown Yaru-yellow`

### ภาพสำหรับปลดล็อก

ธีมที่มีภาพ `unlock.png` และ `preview-unlock.png` มาให้จะแสดงอยู่ในรายการใต้ _Appearance > Unlock_ โดย `unlock.png` ของคุณควรเป็น png แบบโปร่งใสจะดีที่สุด และคุณสามารถสร้างภาพตัวอย่างได้โดยใช้ `omarchy plymouth preview`

### การทำธีมให้แอปที่ Omarchy ไม่ได้ครอบคลุม

หากคุณใช้แอปที่ไม่ได้อยู่ในรายการนั้น คุณสามารถสอน Omarchy ให้ทำธีมให้แอปนั้นได้ด้วยตัวเองโดยใช้เทมเพลต วางไฟล์ไว้ใน `~/.config/omarchy/themed/` โดยตั้งชื่อตามไฟล์ตั้งค่าที่มันสร้างขึ้น บวกกับนามสกุล `.tpl` และเขียนไฟล์ตั้งค่าโดยใช้ `{{ background }}`, `{{ foreground }}`, `{{ accent }}`, `{{ red }}`, `{{ color0 }}` ไปจนถึง `{{ color15 }}` และส่วนที่เหลือของชุดสีในฐานะตัวยึดตำแหน่ง ทุกครั้งที่คุณสลับธีม ไฟล์นั้นจะถูกสร้างขึ้นใหม่ด้วยสีของธีมนั้น

ในโฟลเดอร์นั้นมีไฟล์ `alacritty.toml.tpl.sample` ที่มีคำอธิบายกำกับไว้อย่างครบถ้วนให้คุณคัดลอกจาก — มันแสดงรายการตัวแปรทุกตัวที่คุณสามารถใช้ได้ พร้อมกับตัวดัดแปลง `_strip` และ `_rgb` สำหรับแอปที่ต้องการสีโดยไม่มี `#` หรือต้องการสีเป็นค่า RGB แบบทศนิยม เทมเพลตของคุณจะมีลำดับความสำคัญเหนือกว่าเทมเพลตของ Omarchy เอง ดังนั้นคุณจึงสามารถใช้วิธีนี้เพื่อแทนที่วิธีการทำธีมให้กับแอปที่มีมาในตัวได้เช่นกัน

### การเผยแพร่ธีมของคุณ

หากคุณต้องการเผยแพร่ธีมของคุณเพื่อให้ผู้อื่นสามารถใช้งานได้ คุณต้องนำมันไปไว้บน git server สาธารณะ เช่น GitHub จากนั้นผู้คนก็จะสามารถติดตั้งได้โดยใช้ _Install > Style > Theme_ ในเมนู Omarchy โดยใช้ URL นั้น ขอแนะนำให้คุณปฏิบัติตามธรรมเนียมการตั้งชื่อแบบ `omarchy-[themename]-theme` เพราะธีมจะแสดงอย่างถูกต้องเป็นเพียง `[themename]` ในเมนูเลือกธีมหลังการติดตั้ง

ส่วน `[themename]` ที่เหลืออยู่นั้นจะกลายเป็นชื่อไดเรกทอรีของธีม ดังนั้นมันต้องเป็นชื่อที่ Omarchy สามารถส่งต่อได้อย่างปลอดภัย: มันต้องขึ้นต้นด้วยตัวอักษร, ตัวเลข หรือเครื่องหมายขีดล่าง และส่วนที่เหลือสามารถประกอบด้วยตัวอักษร, ตัวเลข, `.`, `_`, `+` และ `-` ตัวพิมพ์ใหญ่จะถูกแปลงเป็นตัวพิมพ์เล็กให้คุณ แต่อย่างอื่น — ช่องว่าง, เครื่องหมายคำพูด, อักขระที่ไม่ใช่ภาษาอังกฤษ — จะถูกปฏิเสธในเวลาติดตั้ง แทนที่จะถูกแปลงเป็นชื่อไดเรกทอรี ดังนั้น `omarchy-tokyo-night-theme`, `omarchy-flexoki_light-theme` และ `omarchy-c++-theme` จึงติดตั้งได้ไม่มีปัญหาทั้งหมด

โปรดจำไว้ว่าเมื่อมันถูกติดตั้งจาก repo แล้ว ไฟล์ `.lua`, ไฟล์ตั้งค่าเทอร์มินัล หรือ `vscode.json` ใด ๆ ที่มันมาพร้อมด้วยจะถูกตัดออกไป ดังนั้นอย่าสร้างธีมโดยยึดสิ่งเหล่านั้นเป็นหลัก

คุณสามารถให้ธีมของคุณถูกเพิ่มเข้าไปใน [หน้า extra themes](https://omarchy.org/themes/) ได้โดยการส่ง pull request ไปยัง [repo omarchy-site](https://github.com/omacom-io/omarchy-site)
