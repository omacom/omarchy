# การสร้างธีมของคุณเอง

คุณสามารถเพิ่มธีมของคุณเองลงใน `~/.config/omarchy/themes` ได้ เพียงคัดลอกธีมที่มีอยู่ธีมใดธีมหนึ่งมาเป็นพื้นฐาน (ดูได้ใน `/usr/share/omarchy/themes`) แล้วปรับแต่งได้ตามใจชอบ ตราบใดที่ธีมของคุณอยู่ในโฟลเดอร์นั้น มันก็จะปรากฏในเมนูเลือกธีม

ไฟล์หลักที่คุณต้องปรับแต่งคือ `colors.toml` ไฟล์นี้กำหนดชุดสีที่จะนำไปใช้สร้างการกำหนดค่าสำหรับเทอร์มินัล (Foot/Alacritty/Ghostty/Kitty), btop, Chromium, Hyprland, Neovim, Helix, VSCode, Obsidian, แอป Qt, ไฟแบ็กไลต์ของแป้นพิมพ์, วิธีการป้อนข้อมูล, ตัวเลือกการแชร์หน้าจอ, ไอคอนแอป, เครื่องมือ AI หลายตัว (Claude, Pi, Hermes, T3 Code, Herdr) และเชลล์ทั้งหมดของ Omarchy (แถบด้านบน, เมนู, การแจ้งเตือน, OSD และหน้าจอล็อก)

คุณยังสามารถใช้แอปพลิเคชัน Aether ที่ให้มาด้วยเพื่อสร้างธีมใหม่โดยใช้ส่วนติดต่อ GUI ที่สวยงามสำหรับทดลองสีและค้นหาพื้นหลังได้ เพียงเปิดแอปจากตารางแอปด้วย `Super + Alt + Space`

### ธีมที่ติดตั้งแล้วสามารถมีอะไรได้บ้าง

ธีมที่คุณเขียนเองใน `~/.config/omarchy/themes` สามารถมีอะไรก็ได้ตามที่คุณต้องการ — นี่คือเครื่องของคุณและไฟล์ของคุณ และ Omarchy จะนำทั้งหมดไปใช้

ธีมที่คุณติดตั้งจากที่เก็บของผู้อื่นด้วย `omarchy theme install` จะเก็บทุกอย่างที่เป็นสีไว้ และจะตัดไฟล์จำนวนหนึ่งที่จะเรียกใช้โค้ดบนเครื่องของคุณออก ได้แก่ ไฟล์ `.lua` ทุกไฟล์, การกำหนดค่าของเทอร์มินัล (`alacritty.toml`, `foot.ini`, `ghostty.conf`, `kitty.conf`) และ `vscode.json` ไฟล์ `hyprland.lua` ของธีมคือ Lua ที่คอมโพสิเตอร์ของคุณเรียกใช้ตอนเข้าสู่ระบบ, การกำหนดค่าของเทอร์มินัลจะระบุโปรแกรมที่เทอร์มินัลของคุณจะเริ่มทำงาน และ `vscode.json` จะระบุส่วนขยาย VSCode ที่จะติดตั้ง การติดตั้งธีมของใครสักคนควรเปลี่ยนรูปลักษณ์ของเดสก์ท็อปของคุณเท่านั้น ไม่ควรเปลี่ยนสิ่งที่มันเรียกใช้เลย

ทุกอย่างที่เหลือยังคงทำงานได้ตรงตามที่ผู้เขียนธีมเขียนไว้ทุกประการ — `btop.theme`, `chromium.theme`, `helix.toml`, `shell.toml`, พื้นหลังและภาพตัวอย่างทั้งหมดจะถูกเก็บไว้ มีเพียงสิ่งที่ถูกตัดออกเท่านั้นที่จะถูกสร้างขึ้นใหม่จาก `colors.toml` บนเครื่องของคุณ

Omarchy แยกแยะทั้งสองแบบออกจากกันโดยดูว่าธีมนั้นมีที่เก็บ git ของตัวเองอยู่ภายในหรือไม่ ซึ่งเป็นสิ่งที่ `omarchy theme install` ทิ้งไว้เมื่อมันโคลนธีมมา ดังนั้นธีมที่คุณเขียนจึงยังคงเป็นของคุณ และธีมที่คุณดึงมาจากอินเทอร์เน็ตก็จะคงอยู่เพียงในฐานะสีเท่านั้น

### โหมดสว่าง

หากคุณกำลังสร้างธีมโหมดสว่าง ให้ตั้งค่า `mode = "light"` ไว้ที่ด้านบนของไฟล์ `colors.toml` ของคุณ จากนั้นมันจะถูกจับคู่กับโหมดสว่างสำหรับทุกแอปโดยอัตโนมัติ (วิธีเก่าที่วางไฟล์เปล่าชื่อ `light.mode` ไว้ที่รากของธีมของคุณก็ยังคงใช้ได้เช่นกัน)

### ภาพสำหรับปลดล็อก

ธีมที่มาพร้อมภาพ `unlock.png` และ `preview-unlock.png` จะแสดงอยู่ในรายการใต้ _รูปลักษณ์ > ปลดล็อก_ ภาพ `unlock.png` ของคุณควรเป็น png แบบโปร่งใสจะดีที่สุด และคุณสามารถสร้างภาพตัวอย่างได้โดยใช้ `omarchy plymouth preview`

### การกำหนดธีมให้แอปที่ Omarchy ไม่ครอบคลุม

หากคุณใช้แอปที่ไม่ได้อยู่ในรายการนั้น คุณสามารถสอนให้ Omarchy กำหนดธีมให้แอปนั้นได้ด้วยตัวเองโดยใช้เทมเพลต วางไฟล์ไว้ใน `~/.config/omarchy/themed/` โดยตั้งชื่อตามการกำหนดค่าที่มันจะสร้างขึ้นบวกกับนามสกุล `.tpl` และเขียนการกำหนดค่าโดยใช้ `{{ background }}`, `{{ foreground }}`, `{{ accent }}`, `{{ red }}`, `{{ color0 }}` ไปจนถึง `{{ color15 }}` และจานสีที่เหลือในรูปแบบตัวแทน ทุกครั้งที่คุณสลับธีม ไฟล์จะถูกสร้างขึ้นใหม่ด้วยสีของธีมนั้น

มีไฟล์ `alacritty.toml.tpl.sample` ที่ใส่คำอธิบายไว้อย่างครบถ้วนอยู่ในโฟลเดอร์นั้นให้คุณคัดลอก — มันแสดงรายการตัวแปรทุกตัวที่คุณสามารถใช้ได้ รวมถึงตัวปรับแต่ง `_strip` และ `_rgb` สำหรับแอปที่ต้องการสีโดยไม่มี `#` หรือเป็นค่า RGB แบบทศนิยม เทมเพลตของคุณจะมีความสำคัญเหนือกว่าเทมเพลตของ Omarchy เอง ดังนั้นคุณจึงสามารถใช้วิธีนี้เพื่อแทนที่วิธีที่แอปในตัวถูกกำหนดธีมได้ด้วย

### การเผยแพร่ธีมของคุณ

หากคุณต้องการเผยแพร่ธีมของคุณเพื่อให้ผู้อื่นสามารถใช้งานได้ คุณจำเป็นต้องวางมันไว้บนเซิร์ฟเวอร์ git สาธารณะ เช่น GitHub จากนั้นผู้คนจะสามารถติดตั้งมันได้โดยใช้ _ติดตั้ง > สไตล์ > ธีม_ ในเมนู Omarchy โดยใช้ URL นั้น ขอแนะนำให้คุณทำตามรูปแบบการตั้งชื่อ `omarchy-[themename]-theme` เนื่องจากธีมจะแสดงอย่างถูกต้องเป็นเพียง `[themename]` ในเมนูเลือกธีมหลังการติดตั้ง

`[themename]` ที่เหลืออยู่นั้นจะกลายเป็นชื่อไดเรกทอรีของธีม ดังนั้นมันจึงต้องเป็นชื่อที่ Omarchy สามารถส่งต่อได้อย่างปลอดภัย: มันต้องขึ้นต้นด้วยตัวอักษร ตัวเลข หรือขีดล่าง และส่วนที่เหลืออาจประกอบด้วยตัวอักษร ตัวเลข `.`, `_`, `+` และ `-` ตัวพิมพ์ใหญ่จะถูกแปลงเป็นตัวพิมพ์เล็กให้คุณ แต่อย่างอื่น — ช่องว่าง เครื่องหมายอัญประกาศ อักขระที่ไม่ใช่ภาษาอังกฤษ — จะถูกปฏิเสธในเวลาติดตั้งแทนที่จะถูกแปลงเป็นชื่อไดเรกทอรี ดังนั้น `omarchy-tokyo-night-theme`, `omarchy-flexoki_light-theme` และ `omarchy-c++-theme` จึงติดตั้งได้ทั้งหมดโดยไม่มีปัญหา

โปรดจำไว้ว่าเมื่อมันถูกติดตั้งจากที่เก็บแล้ว ไฟล์ `.lua`, การกำหนดค่าของเทอร์มินัล หรือ `vscode.json` ใด ๆ ที่มันมาพร้อมด้วยจะถูกตัดออก ดังนั้นอย่าสร้างธีมโดยยึดสิ่งเหล่านั้นเป็นหลัก

คุณสามารถให้ธีมของคุณถูกเพิ่มลงใน [หน้าเว็บธีมเพิ่มเติม](https://omarchy.org/themes/) ได้โดยส่ง pull request ไปยัง [ที่เก็บ omarchy-site](https://github.com/omacom-io/omarchy-site)
