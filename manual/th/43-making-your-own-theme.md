# การสร้างธีมของคุณเอง

คุณสามารถเพิ่มธีมของคุณเองไปยัง `~/.config/omarchy/themes` ได้ แค่คัดลอกธีมที่มีอยู่ธีมใดธีมหนึ่งมาเป็นฐาน (ดูใน `/usr/share/omarchy/themes`) แล้วปรับแต่งตามใจชอบของคุณเลย ตราบใดที่ธีมของคุณอยู่ในโฟลเดอร์นั้น มันก็จะรวมอยู่ในเมนูเลือกธีมด้วย

ไฟล์หลักที่คุณต้องปรับคือ `colors.toml` ไฟล์นั้นกำหนดชุดสีที่จะถูกนำไปใช้สร้างการกำหนดค่าสำหรับเทอร์มินัล (Foot/Alacritty/Ghostty/Kitty), btop, Chromium, Hyprland, Neovim, Helix, VSCode, Obsidian และเชลล์ทั้งหมดของ Omarchy (แถบด้านบน เมนู การแจ้งเตือน OSD และหน้าจอล็อก)

คุณยังสามารถใช้แอปพลิเคชัน Aether ที่รวมมาด้วยเพื่อสร้างธีมใหม่โดยใช้ส่วนติดต่อ GUI ที่สวยงามสำหรับเล่นกับสีและค้นหาภาพพื้นหลังได้ แค่เปิดมันจากตารางแอปด้วย `Super + Alt + Space`

### ธีมที่ติดตั้งมาสามารถมีอะไรได้บ้าง

ธีมที่คุณเขียนเองใน `~/.config/omarchy/themes` สามารถมีอะไรก็ได้ตามที่คุณชอบ — นี่คือเครื่องของคุณและไฟล์ของคุณ และ Omarchy จะนำทั้งหมดนั้นไปใช้

ธีมที่คุณติดตั้งจาก repo ของคนอื่นด้วย `omarchy theme install` จะเก็บทุกอย่างที่เป็นเรื่องสีไว้ และจะทิ้งไฟล์จำนวนหยิบมือที่จะเรียกใช้โค้ดบนเครื่องของคุณ นั่นคือไฟล์ `.lua` ใด ๆ ไฟล์กำหนดค่าของเทอร์มินัล (`alacritty.toml`, `foot.ini`, `ghostty.conf`, `kitty.conf`) และ `vscode.json` ไฟล์ `hyprland.lua` ของธีมคือ Lua ที่ compositor ของคุณเรียกใช้ตอนเข้าสู่ระบบ ไฟล์กำหนดค่าของเทอร์มินัลระบุชื่อโปรแกรมที่เทอร์มินัลของคุณจะเริ่มทำงาน และ `vscode.json` ระบุชื่อส่วนขยายของ VSCode ที่จะติดตั้ง การติดตั้งธีมของใครสักคนควรเปลี่ยนหน้าตาของเดสก์ท็อปของคุณ ไม่ควรเปลี่ยนสิ่งที่มันเรียกใช้เลย

ทุกอย่างที่เหลือยังคงทำงานได้ตรงตามที่ผู้สร้างธีมเขียนไว้ — `btop.theme`, `chromium.theme`, `helix.toml`, `shell.toml` ภาพพื้นหลังและภาพตัวอย่างทั้งหมดจะถูกเก็บไว้ มีเพียงสิ่งที่ถูกทิ้งเท่านั้นที่จะถูกสร้างขึ้นใหม่จาก `colors.toml` บนเครื่องของคุณ

Omarchy แยกสองกรณีนี้ออกจากกันโดยดูว่าธีมนั้นมี git repo ของตัวเองอยู่ข้างในหรือไม่ ซึ่งนั่นคือสิ่งที่ `omarchy theme install` ทิ้งไว้เบื้องหลังตอนที่มัน clone มา ดังนั้นธีมที่คุณเขียนก็ยังคงเป็นของคุณ และธีมที่คุณดึงมาจากอินเทอร์เน็ตก็ยังคงเป็นเพียงเรื่องสี

### โหมดสว่าง

หากคุณกำลังสร้างธีมโหมดสว่าง ให้ตั้ง `mode = "light"` ไว้ที่ด้านบนของ `colors.toml` ของคุณ จากนั้นมันจะถูกจับคู่กับโหมดสว่างสำหรับทุกแอปโดยอัตโนมัติ (วิธีเก่าที่ทิ้งไฟล์เปล่าชื่อ `light.mode` ไว้ที่รากของธีมของคุณก็ยังใช้ได้เช่นกัน)

### ภาพปลดล็อก

ธีมที่มีภาพ `unlock.png` และ `preview-unlock.png` มาให้จะแสดงรายการอยู่ภายใต้ _รูปลักษณ์ > ปลดล็อก_ ไฟล์ `unlock.png` ของคุณควรเป็น png แบบโปร่งใสจะดีที่สุด และคุณสามารถสร้างภาพตัวอย่างได้โดยใช้ `omarchy plymouth preview`

### การทำธีมให้แอปที่ Omarchy ไม่ครอบคลุม

หากคุณใช้แอปที่ไม่ได้อยู่ในรายการนั้น คุณสามารถสอนให้ Omarchy ทำธีมให้มันได้เองด้วยเทมเพลต ทิ้งไฟล์ไว้ใน `~/.config/omarchy/themed/` โดยตั้งชื่อตามไฟล์กำหนดค่าที่มันสร้างขึ้นบวกกับนามสกุล `.tpl` และเขียนไฟล์กำหนดค่าโดยใช้ `{{ background }}`, `{{ foreground }}`, `{{ accent }}`, `{{ red }}`, `{{ color0 }}` ไปจนถึง `{{ color15 }}` และส่วนที่เหลือของชุดสีเป็นตัวแทน ทุกครั้งที่คุณเปลี่ยนธีม ไฟล์นั้นจะถูกสร้างขึ้นใหม่ด้วยสีของธีมนั้น

มีไฟล์ `alacritty.toml.tpl.sample` ที่มีคำอธิบายครบถ้วนอยู่ในโฟลเดอร์นั้นให้คุณคัดลอก — มันแสดงรายการตัวแปรทุกตัวที่คุณสามารถใช้ได้ พร้อมด้วยตัวปรับแต่ง `_strip` และ `_rgb` สำหรับแอปที่ต้องการสีโดยไม่มี `#` หรือเป็นค่า RGB แบบทศนิยม เทมเพลตของคุณมีความสำคัญเหนือกว่าเทมเพลตของ Omarchy เอง ดังนั้นคุณยังสามารถใช้สิ่งนี้เพื่อแทนที่วิธีที่แอปในตัวถูกทำธีมได้ด้วย

### การเผยแพร่ธีมของคุณ

หากคุณต้องการเผยแพร่ธีมของคุณเพื่อให้ผู้อื่นสามารถใช้มันได้ คุณต้องวางมันไว้บนเซิร์ฟเวอร์ git สาธารณะ เช่น GitHub จากนั้นผู้คนจะสามารถติดตั้งมันได้โดยใช้ _ติดตั้ง > สไตล์ > ธีม_ ในเมนู Omarchy โดยใช้ URL นั้น ขอแนะนำให้คุณทำตามรูปแบบการตั้งชื่อ `omarchy-[themename]-theme` เพราะธีมจะแสดงอย่างถูกต้องเป็นเพียง `[themename]` ในเมนูเลือกธีมหลังการติดตั้ง

ส่วน `[themename]` ที่เหลืออยู่นั้นจะกลายเป็นชื่อไดเรกทอรีของธีม ดังนั้นมันต้องเป็นชื่อที่ Omarchy สามารถส่งต่อได้อย่างปลอดภัย มันต้องขึ้นต้นด้วยตัวอักษร ตัวเลข หรือเครื่องหมายขีดล่าง และส่วนที่เหลือสามารถมีตัวอักษร ตัวเลข `.`, `_`, `+` และ `-` ได้ ตัวพิมพ์ใหญ่จะถูกแปลงเป็นตัวพิมพ์เล็กให้คุณ แต่อย่างอื่น — ช่องว่าง เครื่องหมายอัญประกาศ อักขระที่ไม่ใช่ภาษาอังกฤษ — จะถูกปฏิเสธตอนติดตั้งแทนที่จะถูกเปลี่ยนเป็นชื่อไดเรกทอรี ดังนั้น `omarchy-tokyo-night-theme`, `omarchy-flexoki_light-theme` และ `omarchy-c++-theme` ล้วนติดตั้งได้โดยไม่มีปัญหา

จำไว้ว่าเมื่อมันถูกติดตั้งจาก repo แล้ว ไฟล์ `.lua` ไฟล์กำหนดค่าของเทอร์มินัล หรือ `vscode.json` ใด ๆ ที่มันมีมาด้วยจะถูกทิ้ง ดังนั้นอย่าสร้างธีมโดยยึดสิ่งเหล่านั้นเป็นหลัก

คุณสามารถให้ธีมของคุณถูกเพิ่มเข้าไปใน [หน้าเพจธีมเสริม](https://omarchy.org/themes/) ได้โดยการส่ง pull request ไปยัง [repo omarchy-site](https://github.com/omacom-io/omarchy-site)
