# การสร้างธีมของคุณเอง

คุณสามารถเพิ่มธีมของคุณเองลงใน `~/.config/omarchy/themes` ได้ เพียงคัดลอกธีมที่มีอยู่แล้วธีมหนึ่งมาเป็นพื้นฐาน (ดูได้ใน `/usr/share/omarchy/themes`) แล้วปรับแต่งตามใจชอบ ตราบใดที่ธีมของคุณอยู่ในโฟลเดอร์นั้น มันก็จะปรากฏในเมนูเลือกธีม

ไฟล์หลักที่คุณต้องปรับแต่งคือ `colors.toml` ซึ่งกำหนดชุดสีที่นำไปใช้สร้างไฟล์ตั้งค่าสำหรับ terminal (Foot/Alacritty/Ghostty/Kitty), btop, Chromium, Hyprland, Neovim, Helix, VSCode, Obsidian, แอป Qt, ไฟแบ็กไลต์คีย์บอร์ด, วิธีป้อนข้อความ, ตัวเลือกการแชร์หน้าจอ, ไอคอนแอป, เครื่องมือ AI หลายตัว (Claude, Pi, Hermes, T3 Code, Herdr) และ Omarchy shell ทั้งหมด (แถบด้านบน, เมนู, การแจ้งเตือน, OSD และหน้าจอล็อก)

คุณยังสามารถใช้แอปพลิเคชัน Aether ที่ให้มาด้วยเพื่อสร้างธีมใหม่ผ่านอินเทอร์เฟซ GUI ที่สวยงามสำหรับทดลองสีและค้นหาพื้นหลังได้ เพียงเปิดแอปจากตารางแอปด้วย `Super + Alt + Space`

### ธีมที่ติดตั้งมาสามารถมีอะไรได้บ้าง

ธีมที่คุณเขียนเองใน `~/.config/omarchy/themes` สามารถมีอะไรก็ได้ตามที่คุณต้องการ — นี่คือเครื่องของคุณและไฟล์ของคุณ และ Omarchy จะนำทุกอย่างไปใช้

ธีมที่คุณติดตั้งจาก repo ของคนอื่นด้วย `omarchy theme install` จะเก็บทุกอย่างที่เป็นสีไว้ และตัดไฟล์จำนวนหนึ่งที่จะรันโค้ดบนเครื่องของคุณออกไป ได้แก่ ไฟล์ `.lua` ใด ๆ, ไฟล์ตั้งค่า terminal (`alacritty.toml`, `foot.ini`, `ghostty.conf`, `kitty.conf`) และ `vscode.json` โดย `hyprland.lua` ของธีมคือ Lua ที่ compositor ของคุณรันตอนเข้าสู่ระบบ ไฟล์ตั้งค่า terminal จะระบุโปรแกรมที่ terminal ของคุณเริ่มทำงาน และ `vscode.json` จะระบุส่วนขยาย VSCode ที่ต้องติดตั้ง การติดตั้งธีมของใครสักคนควรเปลี่ยนหน้าตาของเดสก์ท็อปของคุณเท่านั้น ไม่ใช่สิ่งที่มันรัน

ทุกอย่างที่เหลือยังคงทำงานตรงตามที่ผู้สร้างธีมเขียนไว้ — `btop.theme`, `chromium.theme`, `helix.toml`, `shell.toml`, พื้นหลังและตัวอย่างแสดงผลทั้งหมดจะถูกเก็บไว้ เฉพาะสิ่งที่ถูกตัดออกเท่านั้นที่จะถูกสร้างขึ้นใหม่จาก `colors.toml` บนเครื่องของคุณ

Omarchy แยกแยะทั้งสองแบบจากว่าธีมนั้นมี git repo ของตัวเองอยู่ข้างในหรือไม่ ซึ่งเป็นสิ่งที่ `omarchy theme install` ทิ้งไว้เมื่อมัน clone มา ดังนั้นธีมที่คุณเขียนจึงยังคงเป็นของคุณ และธีมที่คุณดึงมาจากอินเทอร์เน็ตจะยังคงเป็นเพียงสีเท่านั้น

### โหมดสว่าง

หากคุณกำลังสร้างธีมโหมดสว่าง ให้ตั้ง `mode = "light"` ไว้ที่ด้านบนของ `colors.toml` ของคุณ จากนั้นมันจะถูกจับคู่กับโหมดสว่างสำหรับทุกแอปโดยอัตโนมัติ (วิธีเก่าที่วางไฟล์เปล่าชื่อ `light.mode` ไว้ที่รากของธีมของคุณก็ยังคงใช้ได้เช่นกัน)

### หน้าจอบูตและหน้าจอเข้าสู่ระบบ

หน้าจอที่ถามรหัสผ่านไดรฟ์ตอนบูต และหน้าจอเข้าสู่ระบบ จะวาดโลโก้ Omarchy ด้วยสี `accent` ของธีมของคุณบน `background` ของมัน โดยมีช่องรหัสผ่านเป็นสี `foreground` และใช้สี `red` เมื่อรหัสผ่านผิด ไม่มีอะไรต้องใส่เพิ่มสำหรับหน้าจอเหล่านี้: Omarchy ไม่ใช้ `unlock.png` หรือ `preview-unlock.png` ของธีมอีกต่อไป บน Mac ที่ใช้ Apple Silicon หน้าจอรหัสผ่านไดรฟ์จะยังคงใช้หน้าตาเริ่มต้นของ Omarchy ไม่ว่าธีมจะเป็นอะไรก็ตาม

### การทำธีมให้แอปที่ Omarchy ไม่ครอบคลุม

หากคุณใช้แอปที่ไม่อยู่ในรายการนั้น คุณสามารถสอนให้ Omarchy ทำธีมให้แอปนั้นได้เองด้วยเทมเพลต วางไฟล์ไว้ใน `~/.config/omarchy/themed/` โดยตั้งชื่อตามไฟล์ตั้งค่าที่มันสร้างบวกนามสกุล `.tpl` และเขียนไฟล์ตั้งค่าด้วย `{{ background }}`, `{{ foreground }}`, `{{ accent }}`, `{{ red }}`, `{{ color0 }}` ถึง `{{ color15 }}` และสีที่เหลือในจานสีเป็น placeholder ทุกครั้งที่คุณเปลี่ยนธีม ไฟล์จะถูกสร้างขึ้นใหม่ด้วยสีของธีมนั้น

มีไฟล์ `alacritty.toml.tpl.sample` ที่ใส่คอมเมนต์ไว้ครบถ้วนอยู่ในโฟลเดอร์นั้นให้คัดลอก — มันแสดงตัวแปรทุกตัวที่คุณใช้ได้ รวมถึงตัวปรับแต่ง `_strip` และ `_rgb` สำหรับแอปที่ต้องการสีโดยไม่มี `#` หรือเป็น RGB แบบทศนิยม เทมเพลตของคุณจะมีความสำคัญเหนือกว่าของ Omarchy เอง ดังนั้นคุณยังสามารถใช้วิธีนี้เพื่อแทนที่วิธีทำธีมให้แอปในตัวได้อีกด้วย

### การเผยแพร่ธีมของคุณ

หากคุณต้องการเผยแพร่ธีมของคุณเพื่อให้คนอื่นใช้ได้ คุณต้องนำมันไปไว้บน git server สาธารณะ เช่น GitHub จากนั้นผู้คนจะสามารถติดตั้งมันได้โดยใช้ _Install > Style > Theme_ ในเมนู Omarchy ด้วย URL นั้น ขอแนะนำให้คุณทำตามรูปแบบการตั้งชื่อ `omarchy-[themename]-theme` เพราะธีมจะแสดงอย่างถูกต้องเป็นเพียง `[themename]` ในเมนูเลือกธีมหลังการติดตั้ง

`[themename]` ที่เหลืออยู่นั้นจะกลายเป็นชื่อไดเรกทอรีของธีม ดังนั้นมันต้องเป็นชื่อที่ Omarchy สามารถส่งต่อได้อย่างปลอดภัย: มันต้องขึ้นต้นด้วยตัวอักษร ตัวเลข หรือเครื่องหมายขีดล่าง และส่วนที่เหลืออาจประกอบด้วยตัวอักษร ตัวเลข `.`, `_`, `+` และ `-` ตัวพิมพ์ใหญ่จะถูกแปลงเป็นตัวพิมพ์เล็กให้คุณ แต่อย่างอื่น — ช่องว่าง เครื่องหมายคำพูด อักขระที่ไม่ใช่ภาษาอังกฤษ — จะถูกปฏิเสธตอนติดตั้ง แทนที่จะถูกแปลงเป็นชื่อไดเรกทอรี ดังนั้น `omarchy-tokyo-night-theme`, `omarchy-flexoki_light-theme` และ `omarchy-c++-theme` จึงติดตั้งได้ทั้งหมดโดยไม่มีปัญหา

โปรดจำไว้ว่าเมื่อมันถูกติดตั้งจาก repo แล้ว ไฟล์ `.lua` ไฟล์ตั้งค่า terminal หรือ `vscode.json` ใด ๆ ที่มันใส่มา จะถูกตัดออก ดังนั้นอย่าสร้างธีมโดยยึดสิ่งเหล่านั้นเป็นหลัก

คุณสามารถให้ธีมของคุณถูกเพิ่มลงใน [หน้าธีมเสริม](https://omarchy.org/themes/) ได้โดยส่ง pull request ไปที่ [repo omarchy-site](https://github.com/omacom-io/omarchy-site)
