# เว็บแอป

คุณสามารถเพิ่มเว็บแอปของคุณเองได้โดยใช้ _Install > Web App_ ในเมนู Omarchy (`Super + Space`) มันจะขอชื่อแอป, URL ของแอป และ URL ของไอคอนจากคุณ หากมันไม่สามารถดึงไอคอนผ่าน favicon ได้ คุณสามารถหาไอคอน PNG สวย ๆ สำหรับเว็บแอปยอดนิยมหลายตัวได้ที่ [Dashboard Icons](https://dashboardicons.com)

จากนั้นคุณจะเข้าถึงแอปเหล่านั้นได้ผ่านตัวเปิดแอป (`Super + Space`) และแอปเหล่านั้นจะใช้หน้าต่างเว็บแอปไร้กรอบที่สวยงาม

หากคุณต้องการลบเว็บแอป เพียงไปที่ _Remove > Web App_ ในเมนู Omarchy

ควรลงชื่อเข้าใช้บัญชีทั้งหมดของคุณโดยใช้เบราว์เซอร์ปกติก่อนใช้ทางลัดเว็บแอป กรอบครอบแบบบางนั้นทำงานร่วมกับ 1password ได้ไม่ดีนัก ดังนั้นการลงชื่อเข้าใช้โดยตรงไว้ก่อนจึงง่ายกว่า

ปุ่มลัดแป้นพิมพ์ทั้งหมดสำหรับเว็บแอปเหล่านี้สามารถเปลี่ยนได้ใน `~/.config/hypr/bindings.lua`

เมื่อคุณอยู่ในเว็บแอป คุณสามารถคัดลอก URL ปัจจุบันไปยังคลิปบอร์ดได้โดยใช้ `Shift + Alt + L`

ตามค่าเริ่มต้น Omarchy มาพร้อมกับแอปเริ่มต้นหลากหลายอยู่แล้ว:

## HEY

[HEY](https://www.hey.com/) เป็นบริการอีเมลและปฏิทินที่ทำหน้าที่เป็นทางเลือกที่ยอดเยี่ยมสำหรับคนที่เบื่อ Gmail, Outlook หรือ Apple Mail มันสร้างโดย [37signals](https://37signals.com/) ซึ่งเป็นต้นกำเนิดของ Omarchy

คุณสามารถเปิด HEY Email ได้โดยใช้ `Super + Shift + E` กระโดดตรงไปเขียนอีเมลใหม่ได้โดยใช้ `Super + Shift + Alt + E` และเปิด HEY Calendar ได้โดยใช้ `Super + Shift + C`

## Basecamp

[Basecamp](https://basecamp.com/) เป็นบริการจัดการโครงการที่ช่วยให้ทีมเล็ก ๆ ทำงานได้เร็วขึ้นและก้าวหน้าได้มากขึ้น แทนที่จะปะติดปะต่อ Trello, Slack, Asana, Notion หรืออะไรก็แล้วแต่เข้าด้วยกันอย่างสะเปะสะปะ คุณสามารถมีทุกอย่างในที่เดียวได้ด้วย Basecamp มันสร้างโดย [37signals](https://37signals.com/) ซึ่งเป็นต้นกำเนิดของ Omarchy

คุณสามารถเปิด Basecamp ได้โดยใช้ตัวเปิดแอปพลิเคชัน (`Super + Space`)

## ChatGPT

[ChatGPT](https://chatgpt.com) เป็นแชตบอต AI ที่ได้รับความนิยมมากที่สุดในโลก

คุณสามารถเปิด ChatGPT ได้โดยใช้ `Super + Shift + A`

## Grok

[Grok](https://grok.com) เป็นแชตบอตของ xAI

คุณสามารถเปิด Grok ได้โดยใช้ `Super + Shift + Alt + A`

## WhatsApp

[WhatsApp](https://www.whatsapp.com/) เป็นหนึ่งในบริการส่งข้อความที่ได้รับความนิยมมากที่สุดในโลก และเวอร์ชันเว็บก็เป็นตัวเลือกที่ยอดเยี่ยมสำหรับ Linux

คุณสามารถเปิด WhatsApp ได้โดยใช้ `Super + Shift + Alt + G` มันจะเปิดมาพร้อมส่วนขยาย WhatsApp Slim ของ Omarchy ซึ่งทำให้มันใช้ธีมตามของคุณและยุบรายการแชตเมื่อหน้าต่างแคบ

## แอป Google

Google Messages, Google Photos, Google Maps และ Google Contacts ล้วนรวมมาเป็นเว็บแอปเช่นกัน

คุณสามารถเปิด Google Messages ได้โดยใช้ `Super + Shift + Ctrl + G` เปิด Google Photos ได้โดยใช้ `Super + Shift + P` และเปิด Google Maps ได้โดยใช้ `Super + Shift + S` ส่วน Google Contacts เข้าถึงได้ผ่านตัวเปิดแอป (`Super + Space`)

## X

X คือที่ที่ข่าวด่วนแตกออกมา

คุณสามารถเปิด X ได้โดยใช้ `Super + Shift + X` และตรงไปเขียนโพสต์ใหม่ได้ด้วย `Super + Shift + Alt + X`

## YouTube

[YouTube](https://youtube.com/) เป็นแพลตฟอร์มวิดีโอที่ได้รับความนิยมมากที่สุดในโลก

คุณสามารถเปิด YouTube ได้โดยใช้ `Super + Shift + Y`

## Netflix

[Netflix](https://www.netflix.com/) รวมมาเป็นเว็บแอปในการติดตั้งใหม่

คุณเปิด Netflix ได้โดยใช้ตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Zoom

[Zoom](https://zoom.us/) เป็นระบบวิดีโอแชตที่ได้รับความนิยมมากที่สุดที่ใช้กันใน US การเชื่อมต่อที่ยอดเยี่ยมทั่วโลก และการประชุมนาน 40 นาทีสามารถจัดได้โดยไม่ต้องมีบัญชีแบบชำระเงิน Omarchy ครอบไคลเอนต์เว็บของ Zoom ไว้ และลิงก์การประชุม zoom จะเปิดตรงเข้าไปในนั้น

คุณเปิด Zoom ได้โดยใช้ตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Discord

[Discord](https://discord.com/) เป็นที่ที่ชุมชนเกมและโอเพนซอร์สส่วนใหญ่รวมตัวกัน รวมถึง[ชุมชนของ Omarchy เอง](https://discord.gg/tXFUdasqhY)

คุณเปิด Discord ได้โดยใช้ตัวเปิดแอปพลิเคชัน (`Super + Space`)

## แอป Microsoft

เลือก _Install > Service > Microsoft_ เพื่อเพิ่ม Outlook, Word, Excel, PowerPoint, Teams และ OneDrive เป็นเว็บแอป แอปแต่ละตัวมีตัวเปิดของตัวเองและเปิดขึ้นมาโดยตรง โดยใช้ URL เชิงพาณิชย์ของ Microsoft 365 และโปรไฟล์เบราว์เซอร์ที่มีอยู่ของคุณ แอปเหล่านี้เปิดในหน้าต่างแอปเบราว์เซอร์เดียวกันกับเว็บแอปอื่น ๆ ของ Omarchy; มันไม่ได้ติดตั้งไคลเอนต์ Teams for Linux แยกต่างหาก

ลบชุดรวมนี้ด้วย _Remove > Services > Microsoft_ หรือลบแอปแต่ละตัวด้วย _Remove > Web App_ คุณยังสามารถติดตั้งเฉพาะแอปที่คุณต้องการผ่าน _Install > Web App_ ได้เช่นกัน

สำหรับคลาวด์ภาครัฐหรือคลาวด์อธิปไตย ให้แก้ไข URL บนบรรทัด `Exec=` ในตัวเปิดที่เกี่ยวข้องภายใต้ `~/.local/share/applications/` เช่น `Microsoft Teams.desktop` โดยใช้ URL ที่องค์กรของคุณให้มา ให้เขียน `%` ตามตัวอักษรใด ๆ ในบรรทัดนั้นเป็น `%%` การเปลี่ยนแปลงจะมีผลในการเปิดครั้งถัดไป การเรียกใช้ตัวติดตั้งชุดรวมอีกครั้งจะแทนที่ตัวเปิดของมันด้วย URL เริ่มต้น

หากต้องการแยกการลงชื่อเข้าใช้งานที่ทำงานให้เป็นเอกเทศ ให้ต่อท้ายไดเรกทอรีข้อมูลเบราว์เซอร์เข้ากับบรรทัด `Exec=` ของตัวเปิดแต่ละตัว:

```ini
Exec=omarchy-launch-webapp "https://teams.cloud.microsoft/" --user-data-dir=/absolute/path/to/work-browser-profile
```

แทนที่ไดเรกทอรีตัวอย่างด้วยพาธสัมบูรณ์ที่คุณเลือก และใช้พาธเดียวกันสำหรับตัวเปิดทั้งหกตัวเพื่อแชร์การลงชื่อเข้าใช้งานที่ทำงานระหว่างกัน เว็บแอปเหล่านี้ใช้เบราว์เซอร์ที่รองรับซึ่ง Omarchy เลือกไว้ โดยจะถอยกลับไปใช้ Chrome เมื่อเบราว์เซอร์เริ่มต้นไม่ได้รับการรองรับ
