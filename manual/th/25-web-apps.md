# เว็บแอป

คุณสามารถเพิ่มเว็บแอปของคุณเองได้โดยใช้ _ติดตั้ง > Web App_ ในเมนู Omarchy (`Super + Space`) มันจะถามชื่อแอป URL ของแอป และ URL ของไอคอน ถ้ามันดึงผ่าน favicon ไม่ได้ คุณหาไอคอน PNG สวย ๆ สำหรับเว็บแอปยอดนิยมหลายตัวได้ที่ [Dashboard Icons](https://dashboardicons.com)

จากนั้นพวกมันจะเข้าถึงได้ผ่านตัวเปิดแอป (`Super + Space`) และใช้หน้าต่างเว็บแอปไร้กรอบที่สวยงาม

ถ้าคุณต้องการลบเว็บแอป แค่ไปที่ _นำออก > Web App_ ในเมนู Omarchy

ดีที่สุดคือคุณเข้าสู่ระบบทุกบัญชีโดยใช้เบราว์เซอร์ปกติก่อนใช้ทางลัดเว็บแอป กรอบห่อแบบบางทำงานกับ 1password ได้ไม่ดีนัก ดังนั้นแค่เข้าสู่ระบบโดยตรงก่อนจะง่ายกว่า

ปุ่มลัดคีย์บอร์ดทั้งหมดสำหรับเว็บแอปเหล่านี้เปลี่ยนได้ใน `~/.config/hypr/bindings.lua`

เมื่อคุณอยู่ในเว็บแอป คุณสามารถคัดลอก URL ปัจจุบันไปยังคลิปบอร์ดได้ด้วย `Shift + Alt + L`

โดยค่าเริ่มต้น Omarchy มาพร้อมแอปเริ่มต้นหลากหลายอยู่แล้ว:

## HEY

[HEY](https://www.hey.com/) เป็นบริการอีเมลและปฏิทินที่ทำหน้าที่เป็นทางเลือกที่ดีสำหรับคนที่เบื่อ Gmail, Outlook หรือ Apple Mail มันทำโดย [37signals](https://37signals.com/) ที่ซึ่ง Omarchy มีต้นกำเนิด

คุณสามารถเริ่ม HEY Email ได้ด้วย `Super + Shift + E` กระโดดตรงไปเขียนอีเมลใหม่ด้วย `Super + Shift + Alt + E` และเริ่ม HEY Calendar ด้วย `Super + Shift + C`

## Basecamp

[Basecamp](https://basecamp.com/) เป็นบริการจัดการโปรเจกต์ที่ช่วยให้ทีมเล็ก ๆ เคลื่อนไหวเร็วขึ้นและก้าวหน้ามากขึ้น แทนที่จะปะติดปะต่อ Trello, Slack, Asana, Notion หรืออะไรก็ตามเข้าด้วยกัน คุณมีทั้งหมดไว้ในที่เดียวด้วย Basecamp มันทำโดย [37signals](https://37signals.com/) ที่ซึ่ง Omarchy มีต้นกำเนิด

คุณสามารถเริ่ม Basecamp ได้โดยใช้ตัวเปิดแอปพลิเคชัน (`Super + Space`)

## ChatGPT

[ChatGPT](https://chatgpt.com) คือแชทบอท AI ที่ได้รับความนิยมมากที่สุดในโลก

คุณสามารถเริ่ม ChatGPT ได้ด้วย `Super + Shift + A`

## Grok

[Grok](https://grok.com) คือแชทบอทของ xAI

คุณสามารถเริ่ม Grok ได้ด้วย `Super + Shift + Alt + A`

## WhatsApp

[WhatsApp](https://www.whatsapp.com/) เป็นหนึ่งในบริการส่งข้อความที่ได้รับความนิยมมากที่สุดในโลก และเวอร์ชันเว็บก็เป็นตัวเลือกที่ดีสำหรับ Linux

คุณสามารถเริ่ม WhatsApp ได้ด้วย `Super + Shift + Alt + G`

## แอป Google

Google Messages, Google Photos, Google Maps และ Google Contacts ทั้งหมดรวมอยู่ในฐานะเว็บแอปด้วยเช่นกัน

คุณสามารถเริ่ม Google Messages ได้ด้วย `Super + Shift + Ctrl + G` Google Photos ด้วย `Super + Shift + P` และ Google Maps ด้วย `Super + Shift + S` ส่วน Google Contacts มีให้ผ่านตัวเปิดแอป (`Super + Space`)

## X

X คือที่ที่ข่าวแตกออกมา

คุณสามารถเริ่ม X ได้ด้วย `Super + Shift + X` และตรงไปเขียนโพสต์ใหม่ด้วย `Super + Shift + Alt + X`

## YouTube

[YouTube](https://youtube.com/) คือแพลตฟอร์มวิดีโอที่ได้รับความนิยมมากที่สุดในโลก

คุณสามารถเริ่ม YouTube ได้ด้วย `Super + Shift + Y`

## Zoom

[Zoom](https://zoom.us/) คือระบบแชตวิดีโอที่ได้รับความนิยมมากที่สุดในสหรัฐ การเชื่อมต่อยอดเยี่ยมทั่วโลก และการประชุม 40 นาทิจัดได้โดยไม่ต้องมีบัญชีแบบเสียเงิน Omarchy ห่อไคลเอนต์เว็บของ Zoom ไว้ และลิงก์ประชุม Zoom จะเปิดตรงเข้าไปในนั้นเลย

คุณเริ่ม Zoom โดยใช้ตัวเปิดแอปพลิเคชัน (`Super + Space`)

## Discord

[Discord](https://discord.com/) คือที่ที่ชุมชนเกมและโอเพนซอร์สส่วนใหญ่สังสรรค์กัน รวมถึง [ของ Omarchy เอง](https://discord.gg/tXFUdasqhY) ด้วย

คุณเริ่ม Discord โดยใช้ตัวเปิดแอปพลิเคชัน (`Super + Space`)

## แอป Microsoft

เลือก _ติดตั้ง > Service > Microsoft_ เพื่อเพิ่ม Outlook, Word, Excel, PowerPoint, Teams และ OneDrive เป็นเว็บแอป แต่ละแอปมีตัวเปิดของตัวเองและเปิดโดยตรง โดยใช้ URL เชิงพาณิชย์ของ Microsoft 365 และโปรไฟล์เบราว์เซอร์ที่มีอยู่ของคุณ พวกมันเปิดในหน้าต่างแอปเบราว์เซอร์เดียวกับเว็บแอปอื่น ๆ ของ Omarchy พวกมันไม่ได้ติดตั้งไคลเอนต์ Teams for Linux แยกต่างหาก

ลบชุดนี้ด้วย _นำออก > Service > Microsoft_ หรือลบแต่ละแอปด้วย _นำออก > Web App_ คุณยังติดตั้งแค่แอปที่คุณต้องการผ่าน _ติดตั้ง > Web App_ ได้ด้วย

สำหรับคลาวด์ของรัฐบาลหรืออธิปไตย ให้แก้ไข URL บนบรรทัด `Exec=` ในตัวเปิดที่เกี่ยวข้องใต้ `~/.local/share/applications/` เช่น `Microsoft Teams.desktop` โดยใช้ URL ที่องค์กรของคุณจัดให้ เขียน `%` แบบตรงตัวใด ๆ ในบรรทัดนั้นเป็น `%%` การเปลี่ยนแปลงจะมีผลเมื่อเปิดครั้งต่อไป การรันตัวติดตั้งชุดอีกครั้งจะแทนที่ตัวเปิดของมันด้วย URL เริ่มต้น

หากต้องการแยกการลงชื่อเข้าใช้งานที่ทำงานออกจากกัน ให้ต่อท้ายไดเรกทอรีข้อมูลเบราว์เซอร์ลงในบรรทัด `Exec=` ของแต่ละตัวเปิด:

```ini
Exec=omarchy-launch-webapp "https://teams.cloud.microsoft/" --user-data-dir=/absolute/path/to/work-browser-profile
```

แทนที่ไดเรกทอรีตัวอย่างด้วยพาธสัมบูรณ์ที่คุณเลือกเอง และใช้พาธเดียวกันสำหรับตัวเปิดทั้งหกตัวเพื่อแชร์การลงชื่อเข้าใช้งานที่ทำงานระหว่างพวกมัน เว็บแอปเหล่านี้ใช้เบราว์เซอร์ที่รองรับซึ่ง Omarchy เลือกไว้ โดยถอยกลับไปใช้ Chromium เมื่อเบราว์เซอร์เริ่มต้นไม่ได้รับการรองรับ
