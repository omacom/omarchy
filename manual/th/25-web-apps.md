# แอปเว็บ

คุณสามารถเพิ่มแอปเว็บของคุณเองได้โดยใช้ _Install > Web App_ ในเมนู Omarchy (`Super + Space`) ระบบจะขอให้คุณระบุชื่อแอป, URL ของแอป และ URL ของไอคอน หากไม่สามารถดึงไอคอนผ่าน favicon ได้ คุณสามารถหาไอคอน PNG ที่ยอดเยี่ยมสำหรับแอปเว็บยอดนิยมมากมายได้ที่ [Dashboard Icons](https://dashboardicons.com)

จากนั้นคุณจะสามารถเข้าถึงแอปเหล่านั้นได้ผ่านตัวเปิดแอป (`Super + Space`) และแอปจะใช้หน้าต่างแอปเว็บแบบไร้กรอบที่สวยงาม

หากต้องการลบแอปเว็บ เพียงไปที่ _Remove > Web App_ ในเมนู Omarchy

ทางที่ดีที่สุดคือเข้าสู่ระบบบัญชีทั้งหมดของคุณโดยใช้เบราว์เซอร์ปกติก่อนใช้ทางลัดแอปเว็บ กรอบครอบแบบบางทำงานร่วมกับ 1password ได้ไม่ดีนัก ดังนั้นการเข้าสู่ระบบโดยตรงไว้ก่อนจึงง่ายกว่า

ปุ่มลัดบนแป้นพิมพ์ทั้งหมดสำหรับแอปเว็บเหล่านี้สามารถเปลี่ยนได้ใน `~/.config/hypr/bindings.lua`

เมื่อคุณอยู่ในแอปเว็บ คุณสามารถคัดลอก URL ปัจจุบันไปยังคลิปบอร์ดได้โดยใช้ `Shift + Alt + L`

โดยค่าเริ่มต้น Omarchy มีชุดแอปเริ่มต้นรวมมาให้แล้วดังนี้:

## HEY

[HEY](https://www.hey.com/) เป็นบริการอีเมลและปฏิทินที่ทำหน้าที่เป็นทางเลือกที่ยอดเยี่ยมสำหรับคนที่เบื่อ Gmail, Outlook หรือ Apple Mail บริการนี้สร้างโดย [37signals](https://37signals.com/) ซึ่งเป็นต้นกำเนิดของ Omarchy

คุณสามารถเริ่ม HEY Email ได้โดยใช้ `Super + Shift + E`, ข้ามไปยังการเขียนอีเมลใหม่ได้โดยตรงโดยใช้ `Super + Shift + Alt + E` และเริ่ม HEY Calendar ได้โดยใช้ `Super + Shift + C`

## Basecamp

[Basecamp](https://basecamp.com/) เป็นบริการจัดการโครงการที่ช่วยให้ทีมขนาดเล็กทำงานได้เร็วขึ้นและก้าวหน้าได้มากขึ้น แทนที่จะเอาส่วนผสมมั่ว ๆ ของ Trello, Slack, Asana, Notion หรืออะไรก็ตามมาปะติดปะต่อกัน คุณสามารถมีทุกอย่างไว้ในที่เดียวด้วย Basecamp บริการนี้สร้างโดย [37signals](https://37signals.com/) ซึ่งเป็นต้นกำเนิดของ Omarchy

คุณสามารถเริ่ม Basecamp ได้โดยใช้ตัวเปิดแอป (`Super + Space`)

## ChatGPT

[ChatGPT](https://chatgpt.com) เป็นแชตบอท AI ที่ได้รับความนิยมมากที่สุดในโลก

คุณสามารถเริ่ม ChatGPT ได้โดยใช้ `Super + Shift + A`

## Grok

[Grok](https://grok.com) เป็นแชตบอทของ xAI

คุณสามารถเริ่ม Grok ได้โดยใช้ `Super + Shift + Alt + A`

## WhatsApp

[WhatsApp](https://www.whatsapp.com/) เป็นหนึ่งในบริการส่งข้อความที่ได้รับความนิยมมากที่สุดในโลก และเวอร์ชันเว็บก็เป็นตัวเลือกที่ยอดเยี่ยมสำหรับ Linux

คุณสามารถเริ่ม WhatsApp ได้โดยใช้ `Super + Shift + Alt + G`

## แอป Google

Google Messages, Google Photos, Google Maps และ Google Contacts ต่างก็รวมมาให้ในรูปแบบแอปเว็บเช่นกัน

คุณสามารถเริ่ม Google Messages ได้โดยใช้ `Super + Shift + Ctrl + G`, Google Photos ได้โดยใช้ `Super + Shift + P` และ Google Maps ได้โดยใช้ `Super + Shift + S` ส่วน Google Contacts สามารถเข้าถึงได้ผ่านตัวเปิดแอป (`Super + Space`)

## X

X คือที่ที่ข่าวแตกออกมา

คุณสามารถเริ่ม X ได้โดยใช้ `Super + Shift + X` และข้ามไปยังการเขียนโพสต์ใหม่ได้โดยตรงด้วย `Super + Shift + Alt + X`

## YouTube

[YouTube](https://youtube.com/) เป็นแพลตฟอร์มวิดีโอที่ได้รับความนิยมมากที่สุดในโลก

คุณสามารถเริ่ม YouTube ได้โดยใช้ `Super + Shift + Y`

## Zoom

[Zoom](https://zoom.us/) เป็นระบบวิดีโอแชตที่ได้รับความนิยมมากที่สุดในสหรัฐอเมริกา เชื่อมต่อได้ยอดเยี่ยมทั่วโลก และสามารถจัดการประชุมนาน 40 นาทีได้โดยไม่ต้องมีบัญชีแบบชำระเงิน Omarchy ครอบเว็บไคลเอนต์ของ Zoom ไว้ และลิงก์การประชุม Zoom จะเปิดเข้าสู่แอปนี้โดยตรง

คุณเริ่ม Zoom ได้โดยใช้ตัวเปิดแอป (`Super + Space`)

## Discord

[Discord](https://discord.com/) เป็นที่ที่ชุมชนเกมและโอเพนซอร์สส่วนใหญ่มารวมตัวกัน รวมถึง[ชุมชนของ Omarchy เอง](https://discord.gg/tXFUdasqhY)

คุณเริ่ม Discord ได้โดยใช้ตัวเปิดแอป (`Super + Space`)

## แอป Microsoft

เลือก _Install > Service > Microsoft_ เพื่อเพิ่ม Outlook, Word, Excel, PowerPoint, Teams และ OneDrive เป็นแอปเว็บ แต่ละแอปมีตัวเปิดของตัวเองและเปิดขึ้นมาโดยตรง โดยใช้ URL ของ Microsoft 365 เชิงพาณิชย์และโปรไฟล์เบราว์เซอร์ที่มีอยู่ของคุณ แอปเหล่านี้เปิดในหน้าต่างแอปเบราว์เซอร์เดียวกันกับแอปเว็บอื่น ๆ ของ Omarchy แอปเหล่านี้จะไม่ติดตั้งไคลเอนต์ Teams for Linux แยกต่างหาก

ลบชุดแอปนี้ออกด้วย _Remove > Service > Microsoft_ หรือลบแอปทีละรายการด้วย _Remove > Web App_ คุณยังสามารถติดตั้งเฉพาะแอปที่ต้องการผ่าน _Install > Web App_ ได้อีกด้วย

สำหรับคลาวด์ของรัฐบาลหรือคลาวด์อธิปไตย ให้แก้ไข URL ในบรรทัด `Exec=` ในตัวเปิดแอปที่เกี่ยวข้องภายใต้ `~/.local/share/applications/` เช่น `Microsoft Teams.desktop` โดยใช้ URL ที่องค์กรของคุณจัดเตรียมไว้ให้ เขียน `%` ตามตัวอักษรใด ๆ ในบรรทัดนั้นเป็น `%%` การเปลี่ยนแปลงจะมีผลในการเปิดครั้งถัดไป การเรียกใช้ตัวติดตั้งชุดแอปอีกครั้งจะแทนที่ตัวเปิดแอปเหล่านั้นด้วย URL เริ่มต้น

หากต้องการแยกการเข้าสู่ระบบสำหรับงานออกจากกัน ให้เพิ่มไดเรกทอรีข้อมูลของเบราว์เซอร์ต่อท้ายบรรทัด `Exec=` ของตัวเปิดแอปแต่ละตัว:

```ini
Exec=omarchy-launch-webapp "https://teams.cloud.microsoft/" --user-data-dir=/absolute/path/to/work-browser-profile
```

แทนที่ไดเรกทอรีตัวอย่างด้วยพาธแบบสัมบูรณ์ที่คุณเลือก และใช้พาธเดียวกันสำหรับตัวเปิดแอปทั้งหกตัวเพื่อแชร์การเข้าสู่ระบบสำหรับงานระหว่างแอปเหล่านั้น แอปเว็บจะใช้เบราว์เซอร์ที่รองรับซึ่ง Omarchy เลือกไว้ และจะกลับไปใช้ Chrome เมื่อเบราว์เซอร์เริ่มต้นไม่ได้รับการรองรับ
