# ยินดีต้อนรับสู่ Omarchy!

Omarchy คือดิสทริบิวชัน Linux แบบ [omakase](https://manuals.omamix.org/3/omacom/76/omakase-computing) ที่สร้างขึ้นบน [Arch](https://archlinux.org/) ตัวจัดการหน้าต่างแบบ tiling อย่าง [Hyprland](https://hypr.land/) และชุดเครื่องมือสร้างเดสก์ท็อป [Quickshell](https://quickshell.org/) มันมาพร้อมทุกสิ่งที่ผู้ใช้คอมพิวเตอร์ยุคใหม่ที่รู้ทันเทคโนโลยีต้องการเพื่อเริ่มทำงานได้อย่างมีประสิทธิภาพทันที ตั้งแต่ [Neovim](https://neovim.io/) (btw) ไปจนถึง Google Chrome จาก [Obsidian](https://obsidian.md/) ไปจนถึง LibreOffice และจาก [Hype](https://github.com/omacom/hype) ไปจนถึง [Monologue](https://github.com/omacom/monologue) ให้ตายสิ แม้แต่เครื่องเล่นเพลงสไตล์ Winamp ย้อนยุคก็ยังมี!

แต่นี่ไม่ใช่แค่ถุงรวมแพ็กเกจที่ติดตั้งไว้ล่วงหน้าแบบสุ่ม ๆ หรอกนะ มันคือระบบที่สมบูรณ์ซึ่งออกแบบมาโดยคำนึงถึงทั้งความสวยงามและประสิทธิภาพในการทำงาน เพราะระบบที่ _สวยงาม_ คือระบบที่ _สร้างแรงจูงใจ_ และประสิทธิภาพในการทำงานก็ [เป็นผลพวงมาจากแรงจูงใจ](https://world.hey.com/dhh/beautiful-motivations-6fef7c73) มาโดยตลอด ที่นี่ไม่มีอะไรรกเกินจำเป็นเลยแม้แต่น้อย มีแค่ทุกอย่างที่ผมใช้เท่านั้น

จริงอยู่ว่าการจะซึมซับความงามของระบบอย่าง Omarchy ที่เน้น TUI อย่างหนัก ชื่นชอบธีมอย่างเต็มที่ และใช้ตัวจัดการหน้าต่างแบบ tiling อาจต้องอาศัยการค่อย ๆ ฝึกสายตากันบ้าง แต่นั่นคือเหตุผลที่คุณมาอยู่ที่นี่ไม่ใช่เหรอ? เพื่อสัมผัสอะไรที่อยู่นอกเขตสบายของคุณสักหน่อย? เพื่อออกผจญภัยเล็ก ๆ ไปสู่วิธีการทำงานกับคอมพิวเตอร์แบบใหม่? ผมหวังว่าจะเป็นอย่างนั้นนะ

Omarchy ไม่เหมือน Windows และก็ไม่เหมือน macOS เช่นกัน มันไม่ได้พยายามจะทำให้คุ้นเคยมากที่สุดเท่าที่จะเป็นไปได้ มันพยายามจะสวยงามและ _ดีกว่า_ จงโอบรับความเป็น Linux ของมันทั้งหมด การแก้ไขไฟล์ config บางไฟล์ด้วยมือ ใช่เลย เน้นการใช้ terminal อย่างหนัก แน่นอนที่สุด
