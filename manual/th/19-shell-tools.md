# เครื่องมือ Shell

นอกเหนือจากเครื่องมือ Linux มาตรฐาน Omarchy ยังมาพร้อมเครื่องมือ shell ที่พัฒนาขึ้นอีกมากมาย นี่คือตัวสำคัญ ๆ

## fzf

[fzf](https://junegunn.github.io/fzf/) ให้คุณค้นหาไฟล์แบบ fuzzy ผ่านนามแฝง `ff` ไปที่ไดเรกทอรีใดก็ได้ พิมพ์ `ff` แล้วคุณจะค้นหาแบบ fuzzy ไปยังไฟล์ใดก็ได้ในทรีนั้น พร้อมเห็นตัวอย่างไฟล์ที่คุณกำลังกรองแคบลงทางด้านขวา

คุณสามารถใช้ `Ctrl + R` เพื่อใช้ fzf ค้นหาแบบ fuzzy ผ่านประวัติคำสั่งของคุณ

เครื่องมือนี้ยังถูกใช้โดย Neovim เมื่อคุณพิมพ์ `Space Space` ด้วย

คู่มือฉบับเต็มดูได้ผ่าน `man fzf`

## Zoxide

[Zoxide](https://github.com/ajeetdsouza/zoxide) เป็นตัวแทนของ cd มันจำไดเรกทอรีที่คุณเคยไป เพื่อให้คุณกระโดดไปที่นั่นได้ง่ายขึ้นในครั้งต่อไป สมมติคุณทำ `cd ~/.config/omarchy` สักครั้ง ครั้งต่อไปคุณก็แค่ทำ `cd omarchy` (หรือแม้แต่ `cd oma`) แล้ว Zoxide จะพาคุณตรงไปที่นั่นเลย

คู่มือฉบับเต็มดูได้ผ่าน `man zoxide`

## ripgrep

[ripgrep](https://github.com/BurntSushi/ripgrep) ค้นหาเนื้อหาในไฟล์โดยใช้ `rg <pattern> <path>` เช่น `rg Controller app/` เพื่อหาคำว่า `Controller` ทุกจุดที่กล่าวถึงในไดเรกทอรี app

เครื่องมือนี้ยังถูกใช้โดย Neovim เมื่อคุณพิมพ์ `Space S G` ด้วย

คู่มือฉบับเต็มดูได้ผ่าน `man rg`

## eza

[eza](https://eza.rocks/) เป็นตัวแทนของ ls มันให้รายการไดเรกทอรีพร้อมข้อมูลมากขึ้น สี และไอคอน โดยค่าเริ่มต้น eza ถูกตั้งนามแฝงเป็น ls แล้ว คุณยังใช้ `lt` เพื่อดูรายการแบบซ้อนสองระดับได้ `lsa` ให้รายการที่รวมไฟล์ที่ซ่อนอยู่ และ `lta` ให้รายการแบบซ้อนพร้อมไฟล์ที่ซ่อนอยู่

คู่มือฉบับเต็มดูได้ผ่าน `man eza`

## fd

[fd](https://github.com/sharkdp/fd) เป็นตัวแทนของ `find` ที่ใช้ง่ายกว่า ใช้ `fd person.rb` เพื่อหาไฟล์ชื่อ `person.rb` ภายในทรีปัจจุบัน `fd person.rb /` จะค้นหาทั้งระบบไฟล์ `fd person.rb / -H` ค้นหาทั้งระบบไฟล์ รวมถึงไดเรกทอรีที่ซ่อนอยู่ด้วย

คู่มือฉบับเต็มดูได้ผ่าน `man fd`

## bat

[bat](https://github.com/sharkdp/bat) คือ `cat` ที่มีการเน้นไวยากรณ์ หมายเลขบรรทัด และการแบ่งหน้า รัน `bat somefile.rb` แล้วคุณจะเข้าใจว่าทำไมมันยากที่จะกลับไปใช้แบบเดิม มันยังแอบทำงานให้คุณที่อื่นด้วย นั่นคือสิ่งที่ระบายสี man page ของคุณ และสิ่งที่แสดงตัวอย่างใน `ff`

คู่มือฉบับเต็มดูได้ผ่าน `man bat`

## tldr

[tldr](https://tldr.sh/) คือยาต้าน man page ที่เปิดมาพร้อมประวัติสามหน้าจอก่อนจะแสดงตัวอย่างสักอัน `tldr tar` ให้รูปแบบการเรียกใช้ไม่กี่แบบที่คุณต้องการจริง ๆ

## yt-dlp

[yt-dlp](https://github.com/yt-dlp/yt-dlp) ดาวน์โหลดวิดีโอจาก YouTube และอีกหลายร้อยเว็บไซต์ `yt-dlp <url>` ดึงคุณภาพที่ดีที่สุดที่มีมาไว้ในไดเรกทอรีปัจจุบัน

คู่มือฉบับเต็มดูได้ผ่าน `man yt-dlp`

## try

[try](https://github.com/tobi/try) ทำให้จัดการการทดลองเขียนโปรแกรมด้วยไดเรกทอรีประทับวันที่ได้ง่าย การทดลองทั้งหมดอยู่ใน `~/Work/tries` และคุณเข้าถึงได้ผ่าน `try`

Omarchy ไม่ได้เพิ่มไดเรกทอรี `bin/` ของโปรเจกต์ลงใน `PATH` โดยอัตโนมัติ ให้รันเครื่องมือเฉพาะโปรเจกต์ที่เชื่อถือได้ด้วยพาธสัมพัทธ์ที่ชัดเจน เช่น `bin/rails` หรือ `./bin/dev`
