# การอัปเดต

Omarchy และแพ็กเกจของคุณจะได้รับการดูแลให้ทันสมัยอยู่เสมอผ่าน _Update > Omarchy_ ในเมนู Omarchy (`Super + Space`)

ตัว Omarchy เองติดตั้งเป็นแพ็กเกจ pacman ปกติจาก [ที่เก็บแพ็กเกจ Omarchy](https://github.com/omacom-io/omarchy-pkgs) ดังนั้นการอัปเดตจะติดตั้ง [รุ่นล่าสุดของ Omarchy](https://github.com/omacom/omarchy/releases) เรียกใช้ migration ที่ค้างอยู่ทั้งหมดเพื่อให้ระบบของคุณซิงค์กับรุ่นล่าสุด และอัปเดตแพ็กเกจระบบทั้งหมดจาก [Omarchy Arch Mirror](https://github.com/omacom-io/omarchy-mirror) และ [AUR](https://aur.archlinux.org/) (หากคุณติดตั้งแพ็กเกจ AUR ใด ๆ ไว้)

เมื่อมีรุ่นใหม่ออกมา ไอคอนลูกศรวงกลมจะปรากฏขึ้นทางขวาของนาฬิกาของคุณ คลิกที่ไอคอนนั้นแล้วกระบวนการอัปเดตจะเริ่มขึ้น

![update-available](images/update-available.webp)

### สี่แชนแนล

Omarchy อัปเดตผ่านสี่แชนแนล ได้แก่ stable, RC, edge และ dev การติดตั้งใหม่จะเริ่มต้นที่แชนแนล stable ซึ่งติดตาม [รุ่นทางการ](https://github.com/omacom/omarchy/releases/) รวมถึง [stable Omarchy Arch mirror](https://github.com/omacom-io/omarchy-mirror) ที่ตามหลังรุ่นล่าสุดอยู่หนึ่งเดือน เพื่อให้เราสามารถจับปัญหาความเข้ากันไม่ได้ใหม่ ๆ ที่ต้องเปลี่ยนการตั้งค่าได้ก่อนที่มันจะสร้างปัญหาให้กับผู้คน

แต่ถ้าคุณอยากช่วยตรวจหาปัญหาที่อาจเกิดขึ้นเหล่านั้น คุณสามารถใช้แชนแนล edge ได้ แชนแนลนี้จะทำให้แพ็กเกจ Omarchy ของคุณติดตามบิลด์พัฒนาล่าสุดอยู่เสมอ และให้คุณอัปเดตเป็นแพ็กเกจ Arch ล่าสุดได้ทันทีที่มีให้ใช้ คุณควรทำแบบนี้ก็ต่อเมื่อคุณมีประสบการณ์กับ Linux และรู้วิธีคืนสภาพระบบที่มีปัญหา

ก่อนรุ่นใหญ่ใหม่แต่ละรุ่น เราจะทำการตรวจสอบขั้นสุดท้ายโดยใช้แชนแนล RC หากคุณสนใจช่วยขัดเกลาในขั้นตอนสุดท้าย มาร่วมพูดคุยกันได้ใน #omarchy-release-candidates บน Discord

สุดท้ายคือแชนแนล dev ซึ่งเชื่อม Omarchy โดยตรงไปยัง git checkout ของซอร์สโค้ดใน `~/omarchy` ร่วมกับแพ็กเกจ edge คุณควรใช้แชนแนลนี้ก็ต่อเมื่อคุณเป็นผู้ใช้ Linux ที่มีประสบการณ์ ทำงานโดยตรงบน Omarchy และยอมทนรับความเสียหายได้

คุณสามารถสลับระหว่างแชนแนลได้โดยใช้ _Update > Channel_ จากเมนู Omarchy (หรือ `omarchy-channel-set` ในเทอร์มินัล)

### การสลับเคอร์เนล

Omarchy บูตด้วยเคอร์เนล `linux-omarchy` ของตัวเอง แต่คุณสามารถติดตั้งเคอร์เนลอื่นไว้ข้าง ๆ ได้ เช่น เคอร์เนล `linux` มาตรฐานของ Arch หรือบิลด์ทดลองที่คุณกำลังทดสอบอยู่ เมื่อมีมากกว่าหนึ่งตัว _Update > Kernel_ ในเมนู Omarchy จะแสดงรายการเคอร์เนลเหล่านั้นพร้อมเครื่องหมายถูกข้างตัวที่บูตเป็นค่าเริ่มต้น เลือกอีกตัวหนึ่ง ป้อนรหัสผ่านของคุณหนึ่งครั้ง แล้วมันจะบูตหลังจากรีสตาร์ตครั้งถัดไป เคอร์เนลอื่น ๆ จะยังคงอยู่ในเมนูบูต ดังนั้นคุณยังสามารถเลือกด้วยตัวเองได้หากค่าเริ่มต้นใหม่สร้างปัญหาให้คุณ ในเทอร์มินัล ใช้ `omarchy-kernel` เพื่อดูค่าเริ่มต้นปัจจุบัน ใช้ `omarchy-kernel list` เพื่อดูสิ่งที่ติดตั้งอยู่ และใช้ `omarchy-kernel set <kernel>` เพื่อสลับ

### การอัปเดตเฟิร์มแวร์

ไม่ใช่แค่แพ็กเกจของคุณเท่านั้นที่ล้าสมัยได้ แล็ปท็อปและอุปกรณ์ต่อพ่วงจำนวนมากส่งเฟิร์มแวร์ BIOS, SSD และ dock ผ่าน Linux Vendor Firmware Service และ _Update > Firmware_ ในเมนู Omarchy จะดึงและติดตั้งสิ่งใดก็ตามที่ฮาร์ดแวร์ของคุณกำลังรออยู่ มันจะติดตั้ง `fwupd` ในครั้งแรกที่คุณเรียกใช้ เฟิร์มแวร์จำนวนมากเขียนได้เฉพาะระหว่างการรีบูตเท่านั้น ดังนั้นอย่าแปลกใจหากระบบขอให้คุณรีบูต

เมื่อคุณต้องการเปลี่ยนการตั้งค่าใน BIOS เอง ให้กด `Alt` ค้างไว้ในเมนูระบบ (`Super + Escape`) แล้ว _Reboot_ จะกลายเป็น _Reboot to BIOS_ ซึ่งจะรีสตาร์ตตรงเข้าสู่หน้าตั้งค่าเฟิร์มแวร์โดยไม่ต้องกดปุ่มให้ถูกจังหวะตอนบูต จากเทอร์มินัล ใช้ `omarchy system firmware`

### คำเตือนเกี่ยวกับการอัปเดตโดยตรงด้วย pacman/yay

หากคุณคุ้นเคยกับ Arch อยู่แล้ว คุณอาจอยากเรียกใช้ `pacman -Syu` หรือ `yay -Syu` ด้วยตัวเอง แต่ถ้าคุณทำแบบนั้น คุณจะพลาด snapshot, migration และการอัปเดตการตั้งค่าที่ Omarchy เรียกใช้พร้อมกับแพ็กเกจใหม่ นั่นคือเหตุผลที่ Omarchy จะหยุดการอัปเกรดระบบโดยตรงจริง ๆ และชี้ให้คุณไปใช้ `omarchy update` แทน (หากคุณรู้จริง ๆ ว่ากำลังทำอะไรอยู่ ตัวป้องกันจะบอกวิธีข้ามมันสำหรับการทำรายการเพียงครั้งเดียว)

### การย้อนกลับจากการอัปเดตที่มีปัญหา

หากคุณเคยเจอปัญหาหลังจากทำการอัปเดต คุณสามารถย้อนระบบของคุณกลับไปยัง snapshot ที่ถ่ายไว้ก่อนการอัปเดตได้ เพียงรีสตาร์ตแล้วเลือก snapshot นั้นในเมนูโหลดตอนบูตจากช่วงก่อนที่คุณจะเริ่มการอัปเดต

![bootloader](images/bootloader.webp)

หากไฟล์ตั้งค่าของคุณเสียหายไม่ว่าด้วยวิธีใด คุณยังสามารถติดตั้ง Omarchy ใหม่ได้โดยใช้ `omarchy reinstall` ในเทอร์มินัล การทำเช่นนี้จะติดตั้งแพ็กเกจเริ่มต้นของ Omarchy ทั้งหมดใหม่ วางคุณไว้บน stable และดาวน์เกรดแพ็กเกจใด ๆ ที่ใหม่เกินไป และรีเซ็ตไฟล์ตั้งค่าทั้งหมด โปรดทราบว่าการเปลี่ยนแปลงการตั้งค่าของผู้ใช้ที่คุณทำกับค่าเริ่มต้นของ Omarchy ทั้งหมดจะถูกเขียนทับเมื่อทำเช่นนี้!
