# การอัปเดต

Omarchy และแพ็กเกจของคุณจะได้รับการดูแลให้ทันสมัยอยู่เสมอผ่าน _อัปเดต > Omarchy_ ในเมนู Omarchy (`Super + Space`)

ตัว Omarchy เองติดตั้งเป็นแพ็กเกจ pacman ตามปกติจาก [ที่เก็บแพ็กเกจ Omarchy](https://github.com/omacom-io/omarchy-pkgs) ดังนั้นการอัปเดตจะติดตั้ง [รุ่นล่าสุดของ Omarchy](https://github.com/omacom/omarchy/releases) เรียกใช้การย้ายข้อมูลที่ค้างอยู่ทั้งหมดเพื่อให้ระบบของคุณซิงค์กับรุ่นล่าสุด และอัปเดตแพ็กเกจระบบทั้งหมดจาก [Omarchy Arch Mirror](https://github.com/omacom-io/omarchy-mirror) และ [AUR](https://aur.archlinux.org/) (หากคุณติดตั้งแพ็กเกจจาก AUR ไว้)

เมื่อมีรุ่นใหม่ออกมา ไอคอนลูกศรวงกลมจะปรากฏทางด้านขวาของนาฬิกาของคุณ คลิกที่ไอคอนนั้นแล้วกระบวนการอัปเดตจะเริ่มขึ้น

![update-available](images/update-available.webp)

### สี่ช่องทาง

Omarchy อัปเดตผ่านสี่ช่องทาง ได้แก่ stable, RC, edge และ dev การติดตั้งใหม่จะเริ่มต้นที่ช่องทาง stable ซึ่งติดตาม [รุ่นที่เผยแพร่อย่างเป็นทางการ](https://github.com/omacom/omarchy/releases/) รวมถึง [Omarchy Arch mirror แบบ stable](https://github.com/omacom-io/omarchy-mirror) ที่ตามหลังรุ่นล่าสุดอยู่หนึ่งเดือน เพื่อให้เราจับปัญหาความเข้ากันไม่ได้ใหม่ ๆ ที่ต้องปรับการกำหนดค่าได้ก่อนที่จะสร้างปัญหาให้กับผู้ใช้

แต่ถ้าคุณอยากช่วยตรวจหาปัญหาที่อาจเกิดขึ้นเหล่านั้น คุณสามารถใช้ช่องทาง edge ได้ ช่องทางนี้จะทำให้แพ็กเกจ Omarchy ของคุณติดตามรุ่นพัฒนาล่าสุด และให้คุณอัปเดตไปใช้แพ็กเกจ Arch ล่าสุดทันทีที่มีให้ใช้ คุณควรทำเช่นนี้ก็ต่อเมื่อคุณมีประสบการณ์กับ Linux และรู้วิธีแก้ไขระบบที่มีปัญหา

ก่อนการเปิดตัวรุ่นหลักใหม่ทุกครั้ง เราจะทำการตรวจสอบขั้นสุดท้ายโดยใช้ช่องทาง RC หากคุณสนใจที่จะช่วยขัดเกลาในขั้นตอนสุดท้าย มาเจอกันได้ใน #omarchy-release-candidates บน Discord

สุดท้าย มีช่องทาง dev ซึ่งเชื่อมโยง Omarchy โดยตรงไปยังที่เก็บโค้ดต้นฉบับที่เช็คเอาต์ด้วย git ใน `~/omarchy` ร่วมกับแพ็กเกจ edge คุณควรใช้ช่องทางนี้ก็ต่อเมื่อคุณเป็นผู้ใช้ Linux ที่มีประสบการณ์ กำลังพัฒนา Omarchy โดยตรง และเต็มใจที่จะทนกับระบบที่อาจพังได้

คุณสามารถสลับระหว่างช่องทางได้โดยใช้ _อัปเดต > ช่องทาง_ จากเมนู Omarchy (หรือ `omarchy channel set <stable|rc|edge|dev>` ในเทอร์มินัล พร้อมกับ `omarchy channel current` เพื่อดูว่าคุณอยู่ช่องทางไหน)

### การสลับเคอร์เนล

Omarchy บูตด้วยเคอร์เนล `linux-omarchy` ของตัวเอง แต่คุณสามารถติดตั้งเคอร์เนลอื่นไว้ข้าง ๆ ได้ เช่น เคอร์เนล `linux` มาตรฐานของ Arch หรือรุ่นทดลองที่คุณกำลังทดสอบ เมื่อมีมากกว่าหนึ่งเคอร์เนล _อัปเดต > เคอร์เนล_ ในเมนู Omarchy จะแสดงรายการเคอร์เนลเหล่านั้น โดยมีเครื่องหมายถูกอยู่ข้างเคอร์เนลที่ใช้บูตเป็นค่าเริ่มต้น เลือกเคอร์เนลอื่น ป้อนรหัสผ่านของคุณหนึ่งครั้ง แล้วระบบจะบูตด้วยเคอร์เนลนั้นหลังจากรีสตาร์ทครั้งถัดไป เคอร์เนลอื่น ๆ จะยังคงอยู่ในเมนูบูต ดังนั้นคุณยังสามารถเลือกเคอร์เนลด้วยตนเองได้หากค่าเริ่มต้นใหม่สร้างปัญหาให้คุณ ในเทอร์มินัล ใช้ `omarchy kernel` เพื่อดูค่าเริ่มต้นปัจจุบัน ใช้ `omarchy kernel list` เพื่อดูสิ่งที่ติดตั้งอยู่ และใช้ `omarchy kernel set <kernel>` เพื่อสลับ

### การอัปเดตเฟิร์มแวร์

ไม่ใช่แค่แพ็กเกจของคุณเท่านั้นที่จะล้าสมัย แล็ปท็อปและอุปกรณ์ต่อพ่วงจำนวนมากส่งเฟิร์มแวร์ BIOS, SSD และแท่นเชื่อมต่อผ่าน Linux Vendor Firmware Service และ _อัปเดต > เฟิร์มแวร์_ ในเมนู Omarchy จะดึงและติดตั้งสิ่งที่ฮาร์ดแวร์ของคุณรออยู่ทั้งหมด มันจะติดตั้ง `fwupd` ให้ในครั้งแรกที่คุณเรียกใช้ เฟิร์มแวร์จำนวนมากสามารถเขียนได้เฉพาะระหว่างการรีบูตเท่านั้น ดังนั้นอย่าแปลกใจหากระบบขอให้คุณรีบูต

เมื่อคุณต้องการเปลี่ยนการตั้งค่าใน BIOS เอง ให้กด `Alt` ค้างไว้ในเมนูระบบ (`Super + Escape`) แล้ว _รีบูต_ จะเปลี่ยนเป็น _รีบูตไปยัง BIOS_ ซึ่งจะรีสตาร์ทตรงไปยังหน้าตั้งค่าเฟิร์มแวร์โดยไม่ต้องกดปุ่มที่ถูกต้องให้ทันตอนบูต ในเทอร์มินัล ใช้ `omarchy system firmware`

### คำเตือนเกี่ยวกับการอัปเดตด้วย pacman/yay โดยตรง

หากคุณคุ้นเคยกับ Arch อยู่แล้ว คุณอาจอยากเรียกใช้ `pacman -Syu` หรือ `yay -Syu` ด้วยตัวเอง แต่ถ้าคุณทำเช่นนั้น คุณจะพลาดสแน็ปช็อต การย้ายข้อมูล และการอัปเดตการกำหนดค่าที่ Omarchy เรียกใช้พร้อมกับแพ็กเกจใหม่ นั่นคือเหตุผลที่ Omarchy จะหยุดการอัปเกรดระบบโดยตรงและชี้ให้คุณไปใช้ `omarchy update` แทน (หากคุณรู้จริง ๆ ว่ากำลังทำอะไร ระบบป้องกันจะบอกวิธีข้ามมันสำหรับการดำเนินการครั้งเดียว)

### การย้อนกลับการอัปเดตที่มีปัญหา

หากคุณพบปัญหาหลังจากทำการอัปเดต คุณสามารถย้อนระบบของคุณกลับไปยังสแน็ปช็อตที่ถ่ายไว้ก่อนการอัปเดตได้ เพียงรีสตาร์ทและเลือกสแน็ปช็อตในเมนูโหลดการบูตที่ถ่ายไว้ก่อนที่คุณจะเริ่มการอัปเดต

![bootloader](images/bootloader.webp)

หากไฟล์กำหนดค่าของคุณเสียหายด้วยเหตุผลบางอย่าง คุณยังสามารถติดตั้ง Omarchy ใหม่ได้โดยใช้ `omarchy reinstall` ในเทอร์มินัล ซึ่งจะติดตั้งแพ็กเกจเริ่มต้นของ Omarchy ทั้งหมดใหม่ ตั้งให้คุณอยู่บน stable (edge บน Apple Silicon) และดาวน์เกรดแพ็กเกจใด ๆ ที่ใหม่เกินไป และรีเซ็ตไฟล์กำหนดค่าทั้งหมด โปรดทราบว่าการเปลี่ยนแปลงการกำหนดค่าของผู้ใช้ทั้งหมดที่คุณทำกับค่าเริ่มต้นของ Omarchy จะถูกเขียนทับเมื่อทำเช่นนี้!
