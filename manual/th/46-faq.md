# คำถามที่พบบ่อย

### ผมสลับระหว่างเค้าโครงแป้นพิมพ์อย่างไร?

แก้ไขไฟล์ `~/.config/hypr/input.lua` ของคุณและเพิ่มสิ่งนี้เพื่อสลับระหว่างเค้าโครงบน `Left Alt + Right Alt`:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

แถบจะแสดงเค้าโครงแป้นพิมพ์ปัจจุบันของคุณโดยอัตโนมัติเมื่อคุณกำหนดค่าหลายเค้าโครง (และคุณยังคลิกมันเพื่อสลับได้ด้วย)

### ผมเปลี่ยนรูปแบบนาฬิกาเป็น 12 ชั่วโมงอย่างไร?

คลิกขวาที่นาฬิกาในแถบเพื่อวนผ่านรูปแบบทั่วไป รวมถึงแบบ 12 ชั่วโมง คุณยังตั้งรูปแบบได้โดยตรง:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

สิ่งนี้จะแสดง Sunday 10:55 AM

### ผมเปลี่ยนเขตเวลาอย่างไร?

รัน _อัปเดต > เขตเวลา_ ในเมนู Omarchy และเลือกจากรายการ ถ้าเขตเวลาถูกแต่ตัวนาฬิกาเองเพี้ยนไป _อัปเดต > เวลา_ จะรีสตาร์ตการซิงโครไนซ์เวลาให้คุณ

### ผมเปลี่ยน DNS แชร์ Wi-Fi หรือตรวจความเร็วการเชื่อมต่ออย่างไร?

สิ่งเหล่านั้นทั้งหมดอยู่ใน [เครือข่าย](35-networking.md)

### ผมตรวจว่าดิสก์ของผมเร็วแค่ไหนอย่างไร?

_สั่งการ > ทดสอบความเร็ว > ทดสอบความเร็วดิสก์_ วัดความเร็วอ่านและเขียนแบบสดบนไดรฟ์ของคุณ หรือ `omarchy disk speedtest` จากเทอร์มินัล

### ทำไมผมเข้าสู่บัญชี Google ใน Chromium ไม่ได้?

Chromium แบบโอเพนซอร์สธรรมดาไม่ได้มาพร้อมข้อมูลประจำตัว OAuth ที่ Google ต้องการสำหรับการเข้าสู่บัญชี รัน _ติดตั้ง > บริการ > บัญชี Chromium_ ในเมนู Omarchy เพื่อเพิ่มพวกมัน รีสตาร์ตเบราว์เซอร์ และการเข้าสู่ระบบจะผ่านไปได้

### ผมเพิ่มเครื่องพิมพ์อย่างไร?

การพิมพ์ถูกตั้งค่าและทำงานทันที และคุณเพิ่มเครื่องพิมพ์แต่ละเครื่องด้วยตัวเองจาก _Print Settings_ ในตัวเปิดแอป (`Super + Space`)

เลือก _Add_ และให้เวลามันสักครู่เพื่อค้นหา: เครื่องพิมพ์ที่เสียบผ่าน USB และเครื่องพิมพ์เครือข่ายส่วนใหญ่ จะถูกค้นพบให้คุณ ถ้าของคุณไม่อยู่ในรายการ เลือก _Network Printer > Internet Printing Protocol (ipp)_ และป้อนที่อยู่ของมัน — จอแสดงผลของเครื่องพิมพ์เองหรือหน้าเว็บของมันจะบอกคุณว่านั่นคืออะไร มักเป็นอะไรอย่างเช่น `192.168.1.50` พร้อมคิว `ipp/print` จากนั้น _Forward_ จะเสนอไดรเวอร์ ซึ่งเครื่องพิมพ์สมัยใหม่ทำงานได้ดีที่สุดบนโปรไฟล์ _IPP Everywhere_ แบบไม่ต้องใช้ไดรเวอร์ และเครื่องรุ่นเก่ากว่าอยากได้ไดรเวอร์ของรุ่นนั้นเอง

คลิกขวาที่เครื่องพิมพ์และเลือก _Set as Default_ เพื่อเลือกว่าแอปของคุณจะหยิบอันไหนก่อน และ _Properties_ เพื่อตั้งขนาดกระดาษ การพิมพ์สองหน้า และคุณภาพ

การค้นพบอัตโนมัติ ซึ่งเครื่องพิมพ์บนเครือข่ายปรากฏโดยไม่ต้องเพิ่ม ถูกปิดชั่วคราวขณะที่มันกำลังถูกทำใหม่ นั่นคือเหตุผลว่าทำไมขั้นตอนแรกข้างต้นจึงเป็นของคุณแทนที่จะเป็นอัตโนมัติ การพิมพ์เป็นไฟล์ PDF ทำงานได้โดยไม่ต้องมีเครื่องพิมพ์เลย

### ผมเปลี่ยนที่บันทึกภาพหน้าจอหรือการอัดหน้าจออย่างไร?

ภาพหน้าจอที่บันทึกไว้ไปอยู่ที่ `~/Pictures/Screenshots` เป็นค่าเริ่มต้น หากต้องการใช้ไดเรกทอรีอื่น เพิ่มสิ่งนี้ไปยังไฟล์ภายใต้ `~/.config/uwsm/env.d/` (เช่น `~/.config/uwsm/env.d/capture`):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

คุณทำแบบเดียวกันสำหรับการอัดหน้าจอได้โดยใช้ `OMARCHY_SCREENRECORD_DIR`

Omasnap สร้างไดเรกทอรีภาพหน้าจอของมันโดยอัตโนมัติ สร้างไดเรกทอรีการอัดหน้าจอด้วยตัวเอง แล้วรีสตาร์ต Omarchy เพื่อให้การเปลี่ยนตัวแปรสภาพแวดล้อมอย่างใดอย่างหนึ่งมีผล

### ผมทำให้ลำโพง + เว็บแคมทำงานบน Apple Studio Display ของผมอย่างไร?

คุณอาจคิดว่ามันควรทำงานทั้งหมดแค่เสียบ USB C แต่โชคไม่ดีนั่นไม่ใช่กรณี ทางแก้ที่ผมพบว่าทำให้มันทำงานได้อย่างเชื่อถือได้คือการใช้ [สาย WJESOG DisplayPort + USB-A => USB-C](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) จากนั้นลำโพงและเว็บแคมก็ทำงานได้อย่างยอดเยี่ยม

จำไว้ว่าคุณมีการควบคุมความสว่างในตัวใน Omarchy สำหรับ Apple Displays (ทั้ง Studio และ XDR) โดยใช้ปุ่มความสว่างคีย์บอร์ดปกติ

### ผมกำจัดซอฟต์แวร์พิเศษทั้งหมดอย่างไร?

ถ้าคุณไม่ต้องการโปรแกรมอย่าง Obsidian หรือ LibreOffice หรือของที่ติดตั้งมาล่วงหน้าอื่น ๆ คุณสามารถนำมันออกได้ง่ายมาก

รัน _นำออก > แพ็กเกจ_ เพื่อดูทุกแพ็กเกจที่ติดตั้งอยู่ จากนั้นคุณสามารถเลือกแพ็กเกจใด ๆ ที่คุณอยากนำออกด้วย tab และเริ่มนำทุกอย่างที่คุณเลือกออกด้วย return

และคุณสามารถใช้ _นำออก > เว็บแอป_ จากเมนู Omarchy เพื่อนำเว็บแอปที่ติดตั้งมาล่วงหน้าอันใดที่คุณไม่ต้องการออก

หรือรัน _นำออก > ของที่ติดตั้งมาล่วงหน้า_ เพื่อกวาดของพิเศษที่ติดตั้งมาล่วงหน้าทั้งหมดออก — เว็บแอป TUI และแอปพลิเคชันเสริม — ในครั้งเดียว ปุ่มลัดที่เปิดพวกมันจะหายไปพร้อมกับพวกมัน คุณจึงเหลือพื้นที่ว่างสะอาดของการผูกปุ่มให้เติมด้วยของคุณเองใน `~/.config/hypr/bindings.lua`
