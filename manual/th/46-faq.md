# FAQ

### ฉันจะสลับระหว่างรูปแบบแป้นพิมพ์ได้อย่างไร

แก้ไขไฟล์ `~/.config/hypr/input.lua` ของคุณและเพิ่มสิ่งนี้เพื่อสลับระหว่างรูปแบบด้วย `Left Alt + Right Alt`:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

แถบจะแสดงรูปแบบแป้นพิมพ์ปัจจุบันของคุณโดยอัตโนมัติเมื่อคุณตั้งค่าหลายรูปแบบไว้ (และคุณสามารถคลิกเพื่อสลับได้เช่นกัน)

### ฉันจะเปลี่ยนรูปแบบนาฬิกาเป็น 12 ชั่วโมงได้อย่างไร

คลิกขวาที่นาฬิกาในแถบเพื่อวนผ่านรูปแบบทั่วไป รวมถึงรูปแบบ 12 ชั่วโมง คุณยังสามารถตั้งค่ารูปแบบโดยตรงได้เช่นกัน:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

สิ่งนี้จะแสดง วันอาทิตย์ 10:55 AM

### ฉันจะเปลี่ยนเขตเวลาของฉันได้อย่างไร

เรียกใช้ _Setup > Region > Timezone_ ในเมนู Omarchy และเลือกจากรายการ หากเขตเวลาถูกต้องแต่นาฬิกาเองคลาดเคลื่อน _Update > Time_ จะรีสตาร์ทการซิงโครไนซ์เวลาให้คุณ

### ฉันจะเปลี่ยน DNS แชร์ Wi-Fi หรือตรวจสอบความเร็วการเชื่อมต่อของฉันได้อย่างไร

สิ่งเหล่านั้นทั้งหมดอยู่ใน [ระบบเครือข่าย](35-networking.md)

### ฉันจะตรวจสอบว่าดิสก์ของฉันเร็วแค่ไหนได้อย่างไร

_Trigger > Speed Test > Disk Speed Test_ วัดความเร็วในการอ่านและเขียนแบบสดบนไดรฟ์ของคุณ หรือใช้ `omarchy disk speedtest` จากเทอร์มินัล

### ฉันจะเพิ่มเครื่องพิมพ์ได้อย่างไร

การพิมพ์ได้รับการตั้งค่าและพร้อมใช้งานตั้งแต่แกะกล่อง และคุณเพิ่มเครื่องพิมพ์แต่ละเครื่องด้วยตัวเองจาก _Print Settings_ ในตัวเปิดแอป (`Super + Alt + Space`)

เลือก _Add_ และรอสักครู่เพื่อให้มันค้นหา: เครื่องพิมพ์ที่เสียบผ่าน USB และเครื่องพิมพ์เครือข่ายส่วนใหญ่ จะถูกค้นพบให้คุณ หากเครื่องพิมพ์ของคุณไม่อยู่ในรายการ ให้เลือก _Network Printer > Internet Printing Protocol (ipp)_ และป้อนที่อยู่ของมัน — หน้าจอของเครื่องพิมพ์เองหรือหน้าเว็บของมันจะบอกคุณว่าที่อยู่นั้นคืออะไร โดยปกติจะเป็นอะไรอย่างเช่น `192.168.1.50` พร้อมคิว `ipp/print` จากนั้น _Forward_ จะเสนอไดรเวอร์ ซึ่งเครื่องพิมพ์สมัยใหม่จะทำงานได้ดีที่สุดกับโปรไฟล์ _IPP Everywhere_ แบบไม่ต้องใช้ไดรเวอร์ และเครื่องรุ่นเก่าจะต้องการไดรเวอร์ของรุ่นนั้นเอง

คลิกขวาที่เครื่องพิมพ์และเลือก _Set as Default_ เพื่อเลือกเครื่องที่แอปของคุณจะเข้าถึงเป็นอันดับแรก และ _Properties_ เพื่อตั้งค่าขนาดกระดาษ การพิมพ์สองหน้า และคุณภาพ

การค้นหาอัตโนมัติ ซึ่งเครื่องพิมพ์บนเครือข่ายจะปรากฏขึ้นโดยไม่ต้องเพิ่ม กำลังถูกปิดชั่วคราวในขณะที่กำลังปรับปรุงใหม่ ซึ่งเป็นเหตุผลว่าทำไมขั้นตอนแรกข้างต้นจึงเป็นหน้าที่ของคุณแทนที่จะเป็นแบบอัตโนมัติ การพิมพ์เป็นไฟล์ PDF ใช้งานได้โดยไม่ต้องมีเครื่องพิมพ์เลย

### ฉันจะเปลี่ยนตำแหน่งที่บันทึกภาพหน้าจอหรือการบันทึกหน้าจอได้อย่างไร

ภาพหน้าจอที่บันทึกไว้ โดยค่าเริ่มต้นจะไปที่ `~/Pictures/Screenshots` หากต้องการใช้ไดเรกทอรีอื่น ให้เพิ่มสิ่งนี้ลงในไฟล์ภายใต้ `~/.config/uwsm/env.d/` (เช่น `~/.config/uwsm/env.d/capture`):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

คุณสามารถทำเช่นเดียวกันสำหรับการบันทึกหน้าจอโดยใช้ `OMARCHY_SCREENRECORD_DIR`

Omasnap สร้างไดเรกทอรีภาพหน้าจอโดยอัตโนมัติ ให้สร้างไดเรกทอรีการบันทึกหน้าจอด้วยตัวเอง จากนั้นรีสตาร์ท Omarchy เพื่อให้การเปลี่ยนแปลงสภาพแวดล้อมอย่างใดอย่างหนึ่งมีผล

### ฉันจะทำให้ลำโพง + เว็บแคมทำงานบน Apple Studio Display ของฉันได้อย่างไร

คุณคงคิดว่าแค่เสียบ USB C ทุกอย่างก็น่าจะทำงานได้ แต่โชคไม่ดีที่ไม่เป็นเช่นนั้น วิธีแก้ปัญหาที่ฉันพบว่าทำให้มันทำงานได้อย่างน่าเชื่อถือคือการใช้ [สาย WJESOG DisplayPort + USB-A => USB-C](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) จากนั้นลำโพงและเว็บแคมก็ทำงานได้อย่างยอดเยี่ยม

จำไว้ว่าคุณมีระบบควบคุมความสว่างในตัวใน Omarchy สำหรับ Apple Displays (ทั้ง Studio และ XDR) โดยใช้ปุ่มความสว่างบนแป้นพิมพ์ปกติ

### ฉันจะกำจัดซอฟต์แวร์ส่วนเกินทั้งหมดได้อย่างไร

หากคุณไม่ต้องการโปรแกรมอย่าง Obsidian หรือ LibreOffice หรือสิ่งอื่น ๆ ที่ติดตั้งมาล่วงหน้า คุณสามารถลบออกได้อย่างง่ายดายมาก

เรียกใช้ _Remove > Package_ เพื่อดูทุกแพ็กเกจที่ติดตั้ง จากนั้นคุณสามารถเลือกแพ็กเกจที่คุณต้องการลบด้วย tab และเริ่มลบทุกอย่างที่คุณเลือกด้วย return

และคุณสามารถใช้ _Remove > Web App_ จากเมนู Omarchy เพื่อลบเว็บแอปที่ติดตั้งมาล่วงหน้าใด ๆ ที่คุณไม่ต้องการ

หรือเรียกใช้ _Remove > Preinstalls_ เพื่อกวาดสิ่งพิเศษที่ติดตั้งมาล่วงหน้าทั้งหมด — เว็บแอป, TUI และแอปพลิเคชันเสริม — ออกไปในคราวเดียว ปุ่มลัดที่เปิดใช้พวกมันจะหายไปพร้อมกับพวกมัน ดังนั้นคุณจะเหลือชุดการผูกปุ่มที่ว่างเปล่าสะอาดตาให้เติมด้วยของคุณเองใน `~/.config/hypr/bindings.lua`
