# คำถามที่พบบ่อย

### ฉันจะสลับระหว่างรูปแบบแป้นพิมพ์ได้อย่างไร?

แก้ไขไฟล์ `~/.config/hypr/input.lua` ของคุณและเพิ่มสิ่งนี้เพื่อสลับระหว่างรูปแบบต่าง ๆ ด้วย `Left Alt + Right Alt`:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

แถบจะแสดงรูปแบบแป้นพิมพ์ปัจจุบันของคุณโดยอัตโนมัติเมื่อคุณตั้งค่าหลายรูปแบบไว้ (และคุณคลิกที่มันเพื่อสลับได้เช่นกัน)

### ฉันจะเปลี่ยนรูปแบบนาฬิกาเป็นแบบ 12 ชั่วโมงได้อย่างไร?

คลิกขวาที่นาฬิกาในแถบเพื่อวนเปลี่ยนรูปแบบที่ใช้กันทั่วไป รวมถึงรูปแบบ 12 ชั่วโมงด้วย คุณตั้งค่ารูปแบบโดยตรงได้เช่นกัน:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

สิ่งนี้จะแสดง วันอาทิตย์ 10:55 AM

### ฉันจะเปลี่ยนเขตเวลาของฉันได้อย่างไร?

รัน _Update > Timezone_ ในเมนู Omarchy และเลือกจากรายการ หากเขตเวลาถูกต้องแต่นาฬิกาเองเดินคลาดเคลื่อน _Update > Time_ จะรีสตาร์ทการซิงค์เวลาให้คุณ

### ฉันจะเปลี่ยน DNS แชร์ Wi-Fi หรือตรวจสอบความเร็วการเชื่อมต่อของฉันได้อย่างไร?

สิ่งเหล่านั้นทั้งหมดอยู่ใน [ระบบเครือข่าย](35-networking.md)

### ฉันจะตรวจสอบว่าดิสก์ของฉันเร็วแค่ไหนได้อย่างไร?

_Trigger > Speed Test > Disk Speed Test_ วัดความเร็วการอ่านและเขียนแบบเรียลไทม์บนไดรฟ์ของคุณ หรือใช้ `omarchy disk speedtest` จากเทอร์มินัล

### ฉันจะเพิ่มเครื่องพิมพ์ได้อย่างไร?

การพิมพ์ได้รับการตั้งค่าและพร้อมใช้งานตั้งแต่แรก และคุณเพิ่มเครื่องพิมพ์แต่ละเครื่องเองได้จาก _Print Settings_ ในตัวเปิดแอป (`Super + Space`)

เลือก _Add_ และให้เวลามันค้นหาสักครู่: เครื่องพิมพ์ที่เสียบผ่าน USB และเครื่องพิมพ์เครือข่ายส่วนใหญ่จะถูกค้นพบให้คุณ หากเครื่องของคุณไม่อยู่ในรายการ ให้เลือก _Network Printer > Internet Printing Protocol (ipp)_ และป้อนที่อยู่ของมัน — จอแสดงผลของเครื่องพิมพ์เองหรือเว็บเพจของมันจะบอกคุณว่าที่อยู่นั้นคืออะไร โดยปกติจะเป็นอะไรอย่างเช่น `192.168.1.50` พร้อมคิว `ipp/print` จากนั้น _Forward_ จะเสนอไดรเวอร์ ซึ่งเครื่องพิมพ์สมัยใหม่จะทำงานได้ดีที่สุดบนโปรไฟล์ _IPP Everywhere_ แบบไม่ต้องใช้ไดรเวอร์ และเครื่องรุ่นเก่ากว่าต้องการไดรเวอร์เฉพาะของรุ่นนั้น

คลิกขวาที่เครื่องพิมพ์และเลือก _Set as Default_ เพื่อเลือกเครื่องที่แอปของคุณจะใช้เป็นเครื่องแรก และ _Properties_ เพื่อตั้งค่าขนาดกระดาษ การพิมพ์สองหน้า และคุณภาพ

การค้นพบอัตโนมัติ ซึ่งเครื่องพิมพ์บนเครือข่ายจะปรากฏขึ้นโดยไม่ต้องเพิ่ม ถูกปิดไว้ชั่วคราวในขณะที่กำลังปรับปรุงใหม่ นั่นคือเหตุผลที่ขั้นตอนแรกข้างต้นเป็นหน้าที่ของคุณแทนที่จะเป็นแบบอัตโนมัติ การพิมพ์เป็นไฟล์ PDF ทำงานได้โดยไม่ต้องมีเครื่องพิมพ์เลย

### ฉันจะเปลี่ยนตำแหน่งที่บันทึกภาพหน้าจอหรือการบันทึกหน้าจอได้อย่างไร?

ภาพหน้าจอที่บันทึกจะไปที่ `~/Pictures/Screenshots` โดยค่าเริ่มต้น หากต้องการใช้ไดเรกทอรีอื่น ให้เพิ่มสิ่งนี้ลงในไฟล์ภายใต้ `~/.config/uwsm/env.d/` (เช่น `~/.config/uwsm/env.d/capture`):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

คุณทำแบบเดียวกันกับการบันทึกหน้าจอได้โดยใช้ `OMARCHY_SCREENRECORD_DIR`

Omasnap สร้างไดเรกทอรีภาพหน้าจอของมันโดยอัตโนมัติ ส่วนไดเรกทอรีการบันทึกหน้าจอให้คุณสร้างเอง จากนั้นรีสตาร์ท Omarchy เพื่อให้การเปลี่ยนแปลงสภาพแวดล้อมอย่างใดอย่างหนึ่งมีผล

### ฉันจะทำให้ลำโพง + เว็บแคมบน Apple Studio Display ของฉันทำงานได้อย่างไร?

คุณคงคิดว่าแค่เสียบ USB C ทุกอย่างก็น่าจะทำงานได้เลย แต่น่าเสียดายที่ไม่ใช่แบบนั้น วิธีแก้ปัญหาที่ฉันพบว่าทำให้มันทำงานได้อย่างเสถียรคือการใช้ [สาย WJESOG DisplayPort + USB-A => USB-C](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) จากนั้นลำโพงและเว็บแคมก็ทำงานได้อย่างไม่มีปัญหา

จำไว้ว่าคุณมีการควบคุมความสว่างในตัวใน Omarchy สำหรับ Apple Displays (ทั้ง Studio และ XDR) โดยใช้ปุ่มปรับความสว่างบนแป้นพิมพ์ตามปกติ

### ฉันจะกำจัดซอฟต์แวร์ส่วนเกินทั้งหมดได้อย่างไร?

หากคุณไม่ต้องการโปรแกรมอย่าง Obsidian หรือ LibreOffice หรือโปรแกรมอื่น ๆ ที่ติดตั้งมาล่วงหน้า คุณสามารถลบมันออกได้ง่ายมาก

รัน _Remove > Package_ เพื่อดูทุกแพ็กเกจที่ติดตั้งไว้ จากนั้นคุณสามารถเลือกแพ็กเกจใด ๆ ที่ต้องการลบด้วย tab และเริ่มลบทุกอย่างที่คุณเลือกไว้ด้วย return

และคุณสามารถใช้ _Remove > Web App_ จากเมนู Omarchy เพื่อลบเว็บแอปที่ติดตั้งมาล่วงหน้าใด ๆ ที่คุณไม่ต้องการออกได้

หรือรัน _Remove > Preinstalls_ เพื่อกวาดส่วนเสริมที่ติดตั้งมาล่วงหน้าทั้งหมด — เว็บแอป TUIs และแอปพลิเคชันเสริม — ออกไปในคราวเดียว ปุ่มลัดที่เคยเปิดพวกมันจะหายไปด้วย ดังนั้นคุณจะเหลือการผูกปุ่มที่ว่างเปล่าสะอาด ๆ ให้เติมด้วยของคุณเองใน `~/.config/hypr/bindings.lua`
