# FAQ

### ฉันจะสลับระหว่างรูปแบบแป้นพิมพ์ได้อย่างไร?

แก้ไขไฟล์ `~/.config/hypr/input.lua` ของคุณและเพิ่มข้อความนี้เพื่อสลับระหว่างรูปแบบต่าง ๆ ด้วย `Left Alt + Right Alt`:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

แถบจะแสดงรูปแบบแป้นพิมพ์ปัจจุบันของคุณโดยอัตโนมัติเมื่อคุณตั้งค่าหลายรูปแบบไว้ (และคุณคลิกที่แถบนั้นเพื่อสลับได้เช่นกัน)

### ฉันจะเปลี่ยนรูปแบบนาฬิกาเป็นแบบ 12 ชั่วโมงได้อย่างไร?

คลิกขวาที่นาฬิกาในแถบเพื่อสลับวนระหว่างรูปแบบทั่วไป รวมถึงรูปแบบ 12 ชั่วโมง คุณตั้งค่ารูปแบบโดยตรงได้เช่นกัน:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

วิธีนี้จะแสดงวันอาทิตย์ 10:55 AM

### ฉันจะเปลี่ยนเขตเวลาของฉันได้อย่างไร?

เรียกใช้ _Setup > Region > Timezone_ ในเมนู Omarchy แล้วเลือกจากรายการ หากเขตเวลาถูกต้องแต่ตัวนาฬิกาเองคลาดเคลื่อน _Update > Time_ จะเริ่มการซิงโครไนซ์เวลาใหม่ให้คุณ

### ฉันจะเปลี่ยน DNS ของฉัน แชร์ Wi-Fi ของฉัน หรือตรวจสอบความเร็วการเชื่อมต่อของฉันได้อย่างไร?

ทั้งหมดนั้นอยู่ใน [ระบบเครือข่าย](35-networking.md)

### ฉันจะตรวจสอบได้อย่างไรว่าดิสก์ของฉันเร็วแค่ไหน?

_Trigger > Speed Test > Disk Speed Test_ จะวัดความเร็วในการอ่านและเขียนแบบเรียลไทม์บนไดรฟ์ของคุณ หรือใช้ `omarchy disk speedtest` จากเทอร์มินัล

### ฉันจะเพิ่มเครื่องพิมพ์ได้อย่างไร?

การพิมพ์ได้รับการตั้งค่าและพร้อมใช้งานตั้งแต่แรก และคุณเพิ่มเครื่องพิมพ์แต่ละเครื่องด้วยตัวเองจาก _Print Settings_ ในตัวเรียกใช้แอปพลิเคชัน (`Super + Space`)

เลือก _Add_ แล้วรอสักครู่เพื่อให้ระบบค้นหา: เครื่องพิมพ์ที่เสียบผ่าน USB และเครื่องพิมพ์เครือข่ายส่วนใหญ่จะถูกค้นพบให้คุณ หากเครื่องพิมพ์ของคุณไม่อยู่ในรายการ ให้เลือก _Network Printer > Internet Printing Protocol (ipp)_ แล้วป้อนที่อยู่ของมัน — หน้าจอของเครื่องพิมพ์เองหรือหน้าเว็บของมันจะบอกคุณว่าที่อยู่นั้นคืออะไร โดยปกติจะเป็นอะไรอย่างเช่น `192.168.1.50` พร้อมคิว `ipp/print` จากนั้น _Forward_ จะเสนอไดรเวอร์ให้ โดยเครื่องพิมพ์สมัยใหม่จะทำงานได้ดีที่สุดกับโปรไฟล์ _IPP Everywhere_ แบบไม่ต้องใช้ไดรเวอร์ ส่วนเครื่องพิมพ์รุ่นเก่าจะต้องการไดรเวอร์เฉพาะของรุ่นนั้น

คลิกขวาที่เครื่องพิมพ์แล้วเลือก _Set as Default_ เพื่อเลือกว่าแอปต่าง ๆ ของคุณจะใช้เครื่องไหนเป็นอันดับแรก และเลือก _Properties_ เพื่อตั้งค่าขนาดกระดาษ การพิมพ์สองหน้า และคุณภาพ

การค้นหาอัตโนมัติ ซึ่งเครื่องพิมพ์บนเครือข่ายจะปรากฏขึ้นโดยไม่ต้องเพิ่มเอง ถูกปิดไว้ชั่วคราวในขณะที่กำลังปรับปรุงใหม่ นั่นคือเหตุผลที่ขั้นตอนแรกข้างต้นเป็นหน้าที่ของคุณแทนที่จะเป็นแบบอัตโนมัติ การพิมพ์ลงไฟล์ PDF ใช้งานได้โดยไม่ต้องมีเครื่องพิมพ์เลย

### ฉันจะเปลี่ยนตำแหน่งที่บันทึกภาพหน้าจอหรือการบันทึกหน้าจอได้อย่างไร?

ภาพหน้าจอที่บันทึกไว้จะไปยัง `~/Pictures/Screenshots` ตามค่าเริ่มต้น หากต้องการใช้ไดเรกทอรีอื่น ให้เพิ่มข้อความนี้ลงในไฟล์ภายใต้ `~/.config/uwsm/env.d/` (เช่น `~/.config/uwsm/env.d/capture`):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

คุณทำแบบเดียวกันกับการบันทึกหน้าจอได้โดยใช้ `OMARCHY_SCREENRECORD_DIR`

Omasnap จะสร้างไดเรกทอรีภาพหน้าจอให้โดยอัตโนมัติ คุณต้องสร้างไดเรกทอรีการบันทึกหน้าจอด้วยตัวเอง จากนั้นรีสตาร์ต Omarchy เพื่อให้การเปลี่ยนแปลงสภาพแวดล้อมอย่างใดอย่างหนึ่งมีผล

### ฉันจะทำให้ลำโพง + เว็บแคมบน Apple Studio Display ของฉันทำงานได้อย่างไร?

คุณคงคิดว่าแค่เสียบ USB C ก็ควรจะทำงานได้ทั้งหมด แต่โชคไม่ดีที่ไม่ใช่แบบนั้น วิธีแก้ที่ฉันพบว่าทำให้มันทำงานได้อย่างเชื่อถือได้คือการใช้ [the WJESOG DisplayPort + USB-A => USB-C cable](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) จากนั้นลำโพงและเว็บแคมก็ทำงานได้อย่างไม่มีปัญหา

โปรดจำไว้ว่าคุณมีการควบคุมความสว่างในตัวใน Omarchy สำหรับ Apple Displays (ทั้ง Studio และ XDR) โดยใช้ปุ่มความสว่างบนแป้นพิมพ์ปกติ

### ฉันจะกำจัดซอฟต์แวร์เสริมทั้งหมดได้อย่างไร?

หากคุณไม่ต้องการโปรแกรมอย่าง Obsidian หรือ LibreOffice หรือสิ่งอื่น ๆ ที่ติดตั้งมาล่วงหน้า คุณสามารถลบออกได้อย่างง่ายมาก

เรียกใช้ _Remove > Package_ เพื่อดูทุกแพ็กเกจที่ติดตั้งอยู่ จากนั้นคุณสามารถเลือกแพ็กเกจใด ๆ ที่คุณต้องการลบด้วย tab และเริ่มลบทุกอย่างที่คุณเลือกด้วย return

และคุณสามารถใช้ _Remove > Web App_ จากเมนู Omarchy เพื่อลบเว็บแอปที่ติดตั้งมาล่วงหน้าอันใดก็ตามที่คุณไม่ต้องการ

หรือเรียกใช้ _Remove > Preinstalls_ เพื่อกวาดส่วนเสริมที่ติดตั้งมาล่วงหน้าทั้งหมด — เว็บแอป, TUI และแอปพลิเคชันเสริม — ออกไปในคราวเดียว ปุ่มลัดที่เคยเรียกใช้พวกมันจะหายไปพร้อมกับพวกมันด้วย ดังนั้นคุณจะเหลือการกำหนดปุ่มที่ว่างเปล่าสะอาดตาไว้เติมด้วยปุ่มของคุณเองใน `~/.config/hypr/bindings.lua`
