# โหมดสลีปของระบบ

Omarchy เปิดใช้งาน suspend เป็นค่าเริ่มต้น และเปิดใช้งาน hibernation เมื่อตั้งค่าเรียบร้อยแล้ว แต่ถ้าคุณเจอปัญหากับอย่างใดอย่างหนึ่งบนเครื่องของคุณ คุณสามารถปิดใช้งานได้

บนเครื่อง NVIDIA GB10 เช่น DGX Spark และ ASUS Ascent GX10 ทั้ง suspend และ hibernation จะถูกปิดไว้ เช่นเดียวกับใน DGX OS ของ NVIDIA เพราะยังไม่ปรากฏว่าโหมดสลีปทำงานได้บนฮาร์ดแวร์นั้น เช่นเดียวกับ ASUS Zenbook A16 (UX3607OA) ที่ suspend ยังทำให้ชิปเข้าสู่โหมดสลีปได้ไม่เต็มที่และอาจค้างข้ามคืนได้ ปุ่มสลับ suspend และการตั้งค่า hibernation จะใช้ไม่ได้กับเครื่องเหล่านั้น หากต้องการเปิดโหมดสลีปกลับมาอีกครั้ง ให้ลบ `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf` ด้วย `sudo rm` จากนั้น Suspend จะกลับมาอยู่ในเมนู และสามารถตั้งค่า hibernation ได้เหมือนบนเครื่องอื่น ๆ การรัน `sudo omarchy apply hardware --install-user "$USER"` จะนำไฟล์นั้นกลับมา

### โปรไฟล์พลังงาน

บนแล็ปท็อป Omarchy จะจดจำโปรไฟล์พลังงานของคุณแยกกันสำหรับตอนเสียบปลั๊กและตอนใช้แบตเตอรี่ และจะสลับระหว่างสองโปรไฟล์นี้เมื่อคุณเสียบปลั๊กและถอดปลั๊ก โดยค่าเริ่มต้นจากโรงงาน นั่นหมายถึง performance เมื่อใช้ไฟ AC และ balanced เมื่อใช้แบตเตอรี่

คุณสามารถดูได้ว่าเครื่องของคุณมีโปรไฟล์อะไรให้ใช้บ้างด้วย `omarchy powerprofiles list` และตั้งค่าโปรไฟล์ที่ต้องการสำหรับสถานะปัจจุบันของคุณด้วย `omarchy powerprofiles set autodetect power-saver` หากต้องการตั้งค่าให้กับอีกสถานะหนึ่งโดยไม่ต้องถอดปลั๊กอะไรเลย ให้ระบุชื่อสถานะนั้นโดยตรง: `omarchy powerprofiles set battery power-saver` ไม่ว่าคุณจะเลือกอะไรไว้ คุณจะได้โปรไฟล์นั้นกลับมาในครั้งต่อไปที่คุณอยู่ในสถานะนั้น

### เปิด/ปิด suspend

คุณสามารถสลับ suspend ได้โดยรัน `omarchy toggle suspend` จากเทอร์มินัล คำสั่งนี้เพียงแค่แสดง/ซ่อนตัวเลือกภายใต้ _System_ (หรือ `Super + Esc`) จากนั้นคุณก็ลองดูได้ว่ามันทำงานได้อย่างสม่ำเสมอบนระบบของคุณหรือไม่ ถ้าไม่ คุณสามารถซ่อนมันอีกครั้งด้วยคำสั่งเดิม

### เปิด/ปิด hibernation

คุณสามารถตั้งค่า hibernation ได้โดยรัน `omarchy hibernation setup` จากเทอร์มินัล (ไม่สามารถใช้ได้บน Apple Silicon Macs) Hibernation จะสร้าง subvolume /swap บนไดรฟ์สำหรับบูตของคุณ โดยมีขนาดเท่ากับหน่วยความจำ RAM จริงที่ติดตั้งไว้ ดังนั้นต้องแน่ใจว่าคุณมีพื้นที่ว่างเหลือเฟือ บนเครื่องขนาด 32GB คุณจะต้องมีพื้นที่ว่าง 32GB+ เสมอสำหรับโวลุ่มนี้ Hibernation ยังต้องใช้ Limine bootloader ที่เป็นค่าเริ่มต้นด้วย

เมื่อตั้งค่าเรียบร้อยแล้ว คุณจะเห็นตัวเลือก hibernate ภายใต้ _System_ (หรือ `Super + Esc`) จากนั้นคุณก็ลองดูได้ว่ามันทำงานได้อย่างสม่ำเสมอบนระบบของคุณหรือไม่ ถ้าไม่ คุณสามารถลบมันออกอีกครั้งได้โดยรัน `omarchy hibernation remove`
