# การพักการทำงานของระบบ

Omarchy เปิดใช้งาน suspend และ hibernation ไว้เป็นค่าเริ่มต้น แต่ถ้าเครื่องของคุณมีปัญหากับอย่างใดอย่างหนึ่ง คุณสามารถปิดการใช้งานได้

บนเครื่อง NVIDIA GB10 เช่น DGX Spark และ ASUS Ascent GX10, suspend และ hibernation จะถูกปิดไว้ เช่นเดียวกับใน DGX OS ของ NVIDIA เพราะยังไม่มีการพิสูจน์ว่า sleep ใช้งานได้บนฮาร์ดแวร์นั้น ASUS Zenbook A16 (UX3607OA) ก็เช่นเดียวกัน โดย suspend ยังไม่สามารถทำให้ชิปเข้าสู่โหมดนอนได้อย่างสมบูรณ์ และอาจค้างข้ามคืนได้ ตัวสลับเปิด/ปิด suspend และการตั้งค่า hibernation จะไม่สามารถใช้ได้ที่นั่น หากต้องการเปิด sleep กลับมาอีกครั้ง ให้ลบ `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf` ด้วย `sudo rm`; จากนั้น Suspend จะกลับมาที่เมนู และสามารถตั้งค่า hibernation ได้เหมือนกับเครื่องอื่น การรัน `sudo omarchy apply hardware --install-user "$USER"` จะนำไฟล์นั้นกลับมา

### โปรไฟล์พลังงาน

บนแล็ปท็อป Omarchy จะจดจำโปรไฟล์พลังงานของคุณแยกกันระหว่างตอนเสียบปลั๊กกับตอนใช้แบตเตอรี่ และจะสลับไปมาระหว่างสองสถานะนี้เมื่อคุณเสียบและถอดปลั๊ก โดยค่าเริ่มต้น นั่นหมายถึง performance เมื่อใช้ไฟ AC และ balanced เมื่อใช้แบตเตอรี่

คุณสามารถดูได้ว่าเครื่องของคุณมีอะไรให้ใช้บ้างด้วย `omarchy powerprofiles list` และตั้งค่าอันที่ต้องการสำหรับสถานะที่คุณอยู่ในขณะนี้ด้วย `omarchy powerprofiles set autodetect power-saver` หากต้องการตั้งค่าอีกสถานะหนึ่งโดยไม่ต้องถอดปลั๊กอะไรเลย ให้ระบุชื่อสถานะนั้นโดยตรง: `omarchy powerprofiles set battery power-saver` ไม่ว่าคุณจะเลือกอะไร คุณจะได้ค่านั้นกลับมาในครั้งต่อไปที่อยู่ในสถานะนั้น

### สลับเปิด/ปิด suspend

คุณสลับเปิด/ปิด suspend ได้โดยรัน `omarchy toggle suspend` จากเทอร์มินัล คำสั่งนั้นแค่แสดง/ซ่อนตัวเลือกดังกล่าวภายใต้ _System_ (หรือ `Super + Esc`) จากนั้นคุณก็ลองดูได้ว่ามันทำงานได้อย่างสม่ำเสมอบนระบบของคุณหรือไม่ ถ้าไม่ คุณสามารถซ่อนมันอีกครั้งด้วยคำสั่งเดิม

### สลับเปิด/ปิด hibernation

คุณตั้งค่า hibernation ได้โดยรัน `omarchy hibernation setup` จากเทอร์มินัล Hibernation จะสร้าง subvolume ชื่อ /swap บนไดรฟ์บูตของคุณ โดยมีขนาดเท่ากับ RAM จริงที่คุณมี ดังนั้นตรวจสอบให้แน่ใจว่าคุณมีพื้นที่ว่างเหลือมากพอ บนเครื่องที่มี RAM 32GB คุณจะต้องมีพื้นที่ว่าง 32GB ขึ้นไปเสมอสำหรับโวลุ่มนี้ Hibernation ยังต้องการบูตโหลดเดอร์ Limine ที่เป็นค่าเริ่มต้นอีกด้วย

เมื่อตั้งค่าเสร็จแล้ว คุณจะเห็นตัวเลือก hibernate ภายใต้ _System_ (หรือ `Super + Esc`) จากนั้นคุณก็ลองดูได้ว่ามันทำงานได้อย่างสม่ำเสมอบนระบบของคุณหรือไม่ ถ้าไม่ คุณสามารถลบมันออกอีกครั้งโดยรัน `omarchy hibernation remove`
