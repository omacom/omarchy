# การพักระบบ

Omarchy เปิดใช้งาน suspend และ hibernation เป็นค่าเริ่มต้น แต่หากคุณมีปัญหากับอย่างใดอย่างหนึ่งบนเครื่องของคุณ คุณสามารถปิดใช้งานได้

บนเครื่อง NVIDIA GB10 เช่น DGX Spark และ ASUS Ascent GX10 นั้น suspend และ hibernation ถูกปิดใช้งานไว้ เช่นเดียวกับใน DGX OS ของ NVIDIA เพราะยังไม่มีการแสดงให้เห็นว่า sleep ทำงานได้บนฮาร์ดแวร์นั้น ปุ่มสลับ suspend และการตั้งค่า hibernation จึงใช้ไม่ได้ที่นั่น หากต้องการเปิด sleep กลับมาอีกครั้ง ให้ลบ `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf` ด้วย `sudo rm` จากนั้น Suspend จะกลับมาอยู่ในเมนู และสามารถตั้งค่า hibernation ได้เหมือนบนเครื่องอื่น ๆ การรัน `sudo omarchy apply hardware --install-user "$USER"` จะนำไฟล์นั้นกลับมา

### โปรไฟล์พลังงาน

บนแล็ปท็อป Omarchy จะจดจำโปรไฟล์พลังงานของคุณแยกกันสำหรับตอนเสียบปลั๊กและตอนใช้แบตเตอรี่ และจะสลับไปมาระหว่างทั้งสองเมื่อคุณเสียบและถอดปลั๊ก ค่าเริ่มต้นคือ performance เมื่อใช้ไฟ AC และ balanced เมื่อใช้แบตเตอรี่

คุณสามารถดูได้ว่าเครื่องของคุณมีอะไรให้เลือกบ้างด้วย `omarchy powerprofiles list` และตั้งค่าที่คุณต้องการสำหรับสถานะที่คุณอยู่ในขณะนี้ด้วย `omarchy powerprofiles set autodetect power-saver` หากต้องการตั้งค่าอีกสถานะหนึ่งโดยไม่ต้องถอดปลั๊กอะไรเลย ให้ระบุชื่อสถานะนั้นโดยตรง: `omarchy powerprofiles set battery power-saver` ไม่ว่าคุณจะเลือกอะไรไว้ นั่นคือสิ่งที่คุณจะได้กลับมาในครั้งต่อไปที่คุณอยู่ในสถานะนั้น

### สลับ suspend

คุณสลับ suspend ได้โดยรัน `omarchy toggle suspend` จากเทอร์มินัล คำสั่งนี้เพียงแค่แสดง/ซ่อนตัวเลือกภายใต้ _System_ (หรือ `Super + Esc`) จากนั้นคุณก็สามารถดูได้ว่ามันทำงานได้อย่างสม่ำเสมอบนระบบของคุณหรือไม่ หากไม่ คุณสามารถซ่อนมันอีกครั้งด้วยคำสั่งเดียวกัน

### สลับ hibernation

คุณตั้งค่า hibernation ได้โดยรัน `omarchy hibernation setup` จากเทอร์มินัล Hibernation จะสร้าง subvolume /swap บนไดรฟ์สำหรับบูตของคุณ โดยมีขนาดเท่ากับ RAM จริงที่ติดตั้งไว้ ดังนั้นโปรดแน่ใจว่าคุณมีพื้นที่เหลือเฟือ บนเครื่องขนาด 32GB คุณจะต้องมีพื้นที่ว่าง 32GB+ สำหรับโวลุ่มนี้เสมอ Hibernation ยังต้องการ bootloader Limine ที่เป็นค่าเริ่มต้นอีกด้วย

เมื่อตั้งค่าเสร็จแล้ว คุณจะเห็นตัวเลือก hibernate ภายใต้ _System_ (หรือ `Super + Esc`) จากนั้นคุณก็สามารถดูได้ว่ามันทำงานได้อย่างสม่ำเสมอบนระบบของคุณหรือไม่ หากไม่ คุณสามารถลบมันออกอีกครั้งได้โดยรัน `omarchy hibernation remove`
