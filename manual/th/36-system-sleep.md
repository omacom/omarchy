# การพักระบบ

Omarchy เปิดใช้งาน suspend เป็นค่าเริ่มต้น และเปิดใช้งาน hibernation เมื่อตั้งค่าเรียบร้อยแล้ว แต่หากเครื่องของคุณมีปัญหากับอย่างใดอย่างหนึ่ง คุณสามารถปิดการใช้งานพวกมันได้

บนเครื่อง NVIDIA GB10 เช่น DGX Spark และ ASUS Ascent GX10 นั้น suspend และ hibernation จะถูกปิดไว้ เช่นเดียวกับใน NVIDIA's DGX OS เพราะยังไม่มีการแสดงให้เห็นว่า sleep ทำงานได้บนฮาร์ดแวร์ดังกล่าว การสลับเปิด/ปิด suspend และการตั้งค่า hibernation จึงใช้ไม่ได้ที่นั่น หากต้องการเปิด sleep กลับมาอีกครั้ง ให้ลบ `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf` ด้วย `sudo rm` จากนั้น Suspend จะกลับมาอยู่ในเมนู และสามารถตั้งค่า hibernation ได้เหมือนกับเครื่องอื่น ๆ การเรียกใช้ `sudo omarchy apply hardware --install-user "$USER"` จะนำไฟล์นั้นกลับมา

### โปรไฟล์พลังงาน

บนแล็ปท็อป Omarchy จะจดจำโปรไฟล์พลังงานของคุณแยกกันสำหรับตอนเสียบปลั๊กอยู่และตอนที่ทำงานด้วยแบตเตอรี่ และจะสลับไปมาระหว่างสองโปรไฟล์นี้เมื่อคุณเสียบปลั๊กและถอดปลั๊ก โดยค่าเริ่มต้นที่ให้มานั้นหมายถึง performance เมื่อใช้ไฟ AC และ balanced เมื่อใช้แบตเตอรี่

คุณสามารถดูได้ว่าเครื่องของคุณมีตัวเลือกอะไรบ้างด้วย `omarchy powerprofiles list` และตั้งค่าโปรไฟล์ที่คุณต้องการสำหรับสถานะที่คุณอยู่ในขณะนี้ด้วย `omarchy powerprofiles set autodetect power-saver` หากต้องการตั้งค่าให้กับอีกสถานะหนึ่งโดยไม่ต้องถอดปลั๊กใด ๆ ให้ระบุชื่อสถานะนั้นโดยตรง: `omarchy powerprofiles set battery power-saver` ไม่ว่าคุณจะเลือกอะไรไว้ นั่นคือสิ่งที่จะกลับมาในครั้งต่อไปที่คุณอยู่ในสถานะนั้น

### เปิด/ปิด suspend

คุณเปิด/ปิด suspend ได้โดยการเรียกใช้ `omarchy toggle suspend` จากเทอร์มินัล ซึ่งเป็นการแสดง/ซ่อนตัวเลือกภายใต้ _System_ (หรือ `Super + Esc`) เท่านั้น จากนั้นคุณก็จะดูได้ว่ามันทำงานได้อย่างสม่ำเสมอบนระบบของคุณหรือไม่ หากไม่ คุณสามารถซ่อนมันอีกครั้งได้ด้วยคำสั่งเดียวกัน

### เปิด/ปิด hibernation

คุณตั้งค่า hibernation ได้โดยการเรียกใช้ `omarchy hibernation setup` จากเทอร์มินัล (ไม่สามารถใช้ได้บน Apple Silicon Macs) Hibernation จะสร้าง subvolume /swap บนไดรฟ์บูตของคุณที่มีขนาดเท่ากับหน่วยความจำ RAM จริงของคุณ ดังนั้นโปรดตรวจสอบให้แน่ใจว่าคุณมีพื้นที่เหลืออยู่มากพอ บนเครื่อง 32GB คุณจะต้องมีพื้นที่ว่าง 32GB+ สำหรับโวลุ่มนี้เสมอ Hibernation ยังต้องการ bootloader เริ่มต้น Limine อีกด้วย

เมื่อตั้งค่าเรียบร้อยแล้ว คุณจะเห็นตัวเลือก hibernate ภายใต้ _System_ (หรือ `Super + Esc`) จากนั้นคุณก็จะดูได้ว่ามันทำงานได้อย่างสม่ำเสมอบนระบบของคุณหรือไม่ หากไม่ คุณสามารถลบมันออกอีกครั้งได้โดยการเรียกใช้ `omarchy hibernation remove`
