# การพักเครื่อง

Omarchy เปิดใช้งานการพักเครื่อง (suspend) และการจำศีล (hibernation) เป็นค่าเริ่มต้น แต่ถ้าคุณมีปัญหากับอย่างใดอย่างหนึ่งบนเครื่องของคุณ คุณสามารถปิดพวกมันได้

### โปรไฟล์พลังงาน

บนแล็ปท็อป Omarchy จำโปรไฟล์พลังงานของคุณแยกกันสำหรับตอนเสียบปลั๊กและตอนใช้แบตเตอรี่ และสลับระหว่างสองอย่างนั้นเมื่อคุณเสียบและถอดปลั๊ก ออกมาจากกล่องนั่นหมายถึงประสิทธิภาพ (performance) บนไฟ AC และสมดุล (balanced) บนแบตเตอรี่

คุณดูได้ว่าเครื่องของคุณมีอะไรให้บ้างด้วย `omarchy powerprofiles list` และตั้งค่าอันที่คุณต้องการสำหรับสถานะที่คุณอยู่ตอนนี้ด้วย `omarchy powerprofiles set autodetect power-saver` หากต้องการตั้งค่าอีกสถานะหนึ่งโดยไม่ต้องถอดปลั๊กอะไรเลย ให้ระบุชื่อมันโดยตรง: `omarchy powerprofiles set battery power-saver` อะไรก็ตามที่คุณเลือกคือสิ่งที่คุณจะได้กลับมาในครั้งต่อไปที่คุณอยู่ในสถานะนั้น

### สลับการพักเครื่อง

คุณสลับการพักเครื่องโดยรัน `omarchy toggle suspend` จากเทอร์มินัล นั่นแค่แสดง/ซ่อนตัวเลือกภายใต้ _ระบบ_ (หรือ `Super + Esc`) แล้วคุณก็จะเห็นได้ว่ามันทำงานสม่ำเสมอบนระบบของคุณหรือไม่ ถ้าไม่ คุณซ่อนมันอีกครั้งได้ด้วยคำสั่งเดียวกัน

### สลับการจำศีล

คุณตั้งค่าการจำศีลโดยรัน `omarchy hibernation setup` จากเทอร์มินัล การจำศีลสร้าง subvolume /swap บนไดรฟ์บูตของคุณขนาดเท่าการจัดสรร RAM จริงของคุณ ดังนั้นตรวจสอบให้แน่ใจว่าคุณมีพื้นที่เหลือมากมาย บนเครื่อง 32GB คุณจะต้องมีพื้นที่ว่าง 32GB+ สำหรับโวลุ่มนี้เสมอ การจำศีลยังต้องการ bootloader Limine ที่เป็นค่าเริ่มต้นด้วย

เมื่อตั้งค่าแล้ว คุณจะเห็นตัวเลือกจำศีลภายใต้ _ระบบ_ (หรือ `Super + Esc`) แล้วคุณก็จะเห็นได้ว่ามันทำงานสม่ำเสมอบนระบบของคุณหรือไม่ ถ้าไม่ คุณสามารถนำมันออกอีกครั้งโดยรัน `omarchy hibernation remove`
