# เริ่มต้นใช้งาน

Omarchy ติดตั้งโดยใช้ ISO คุณสามารถเลือกระหว่างการติดตั้งแบบเต็มดิสก์ ซึ่งจะยึดทั้งไดรฟ์ หรือการติดตั้งในพื้นที่ว่าง ซึ่งจะวาง Omarchy ไว้ในพื้นที่ที่ยังไม่ได้จัดสรรบนไดรฟ์ — นั่นคือวิธีที่คุณจะ dual boot คู่กับ Windows หรือ OS อื่น (ดู [การติดตั้งแบบ dual-boot](50-dual-boot-install.md) — โปรดทราบว่าคุณจะต้องปิด BitLocker ใน Windows ก่อน) ไม่ว่าจะเลือกแบบใด การติดตั้งจะใช้การเข้ารหัสแบบเต็มรูปแบบเป็นค่าเริ่มต้น และตัวเลือกแบบเต็มดิสก์จะล้างไดรฟ์ที่เลือก ดังนั้นอย่าลืมสำรองข้อมูลก่อนใช้ไดรฟ์ที่มีอยู่!

[ดาวน์โหลด Omarchy ISO](https://omarchy.org/) ก่อน นำไปใส่ใน USB stick (ใช้ [Rufus](https://rufus.ie/) บน Windows, [balenaEtcher](https://etcher.balena.io/) บน Mac หรือ [caligula](https://github.com/ifd3f/caligula) บน Linux) แล้ว boot จาก stick นั้น

_คุณต้องปิด Secure Boot และ/หรือ TPM ใน BIOS คุณต้องปิดสิ่งเหล่านี้เพื่อที่จะสามารถติดตั้ง Omarchy ได้ สิ่งเหล่านี้คือแผนด้านความปลอดภัยของ Microsoft ที่มีไว้สำหรับ Windows และ Linux distribution ที่เกี่ยวข้องกับ Microsoft_

จากนั้นตอบคำถามการตั้งค่า และยืนยันดังนี้:

 ![install-config](images/install-config.webp)

จากนั้นเลือกไดรฟ์สำหรับการติดตั้งของคุณ แล้วนั่งพักและชมการแสดงการติดตั้งไปได้เลย การติดตั้งสามารถเสร็จได้ในเวลาไม่ถึงหนึ่งนาทีบนเครื่องสมัยใหม่ที่เร็วที่สุด แต่ไม่ควรใช้เวลานานเกิน 5 นาทีแม้แต่บนคอมพิวเตอร์รุ่นเก่า

 ![install-done](images/install-done.webp)

ตอนนี้คุณพร้อมที่จะ Omarchy แล้ว!

### ใช้คีย์บอร์ดแบบมีสายหรือ 2.4ghz!

การเข้ารหัสแบบเต็มดิสก์จะไม่ยอมให้คุณป้อนรหัสผ่านจากคีย์บอร์ด Bluetooth ตอนเริ่มต้น เช่นเดียวกับที่คุณไม่สามารถใช้คีย์บอร์ด Bluetooth เพื่อเข้าสู่ BIOS บน PC ได้ คุณจะต้องใช้คีย์บอร์ดที่ใช้ dongle แบบ 2.4ghz หรือสาย (ซึ่งดีกว่ามากในเรื่อง latency อยู่แล้ว!) ส่วนตัวผมชอบ [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard) มาก!

### การติดตั้งสำหรับเจ้าของคนอื่น

หากคุณกำลังตั้งค่าเครื่องให้คนอื่น — สมาชิกในครอบครัว พนักงานใหม่ หรือผู้ซื้อ — คุณไม่ควรตอบคำถามส่วนตัวแทนพวกเขา กด `Ctrl + C` บนหน้าจอแรกสุดของตัวติดตั้ง (การเลือกคีย์บอร์ด) แล้ว Omarchy จะเสนอให้เตรียมเครื่องสำหรับเจ้าของคนอื่นแทน ระบบจะติดตั้งทันที แต่การตั้งค่าส่วนตัวทั้งหมด — รูปแบบคีย์บอร์ด ชื่อผู้ใช้ รหัสผ่าน — จะถูกเลื่อนออกไปจนกว่าเครื่องจะ boot เป็นครั้งแรก ไดรฟ์ยังคงเข้ารหัสตามค่าเริ่มต้น และรหัสผ่านที่เจ้าของคนใหม่เลือกตอน boot ครั้งแรกนั้นจะกลายเป็นรหัสผ่านสำหรับการเข้ารหัสด้วย (เครื่องที่คุณใช้งานอยู่แล้วก็สามารถส่งมอบได้โดยไม่ต้องติดตั้งใหม่เช่นกัน — ดู [การรีเซ็ตคอมพิวเตอร์](48-security.md))

### การติดตั้งแบบ unattended

ISO ยังสามารถติดตั้งได้เองทั้งหมด — ไม่ต้องใช้คีย์บอร์ด ไม่ต้องใช้ wizard — เมื่อได้รับข้อมูลการตั้งค่าจากไดรฟ์ที่สอง นั่นคือวิธีที่จะถือว่า Omarchy เป็น base image สำหรับ VM และเครื่องใน fleet ดู [การติดตั้งแบบ unattended](51-unattended-installs.md)

### การติดตั้งแบบไม่มีการเข้ารหัส

Omarchy ได้รับการติดตั้งพร้อมการเข้ารหัสเป็นค่าเริ่มต้น นี่คือตัวเลือกที่ปลอดภัยและมีความรับผิดชอบสำหรับคอมพิวเตอร์ทุกเครื่องที่อาจสูญหายหรือถูกขโมยได้ คุณไม่ต้องการให้ใครก็ตามที่เข้าถึงฮาร์ดแวร์ของคุณสามารถเข้าถึงข้อมูลของคุณได้!

แต่ในสถานการณ์พิเศษ เช่น การติดตั้ง Omarchy แบบระยะไกลบนคอมพิวเตอร์ที่ได้รับการป้องกัน หรือสำหรับการติดตั้งแบบใช้แล้วทิ้งที่ไม่มีข้อมูลละเอียดอ่อน คุณอาจต้องการติดตั้งโดยไม่มีการเข้ารหัส คุณสามารถกด `Ctrl + C` บนหน้าจอยืนยันการ format ดิสก์เพื่อเปลี่ยนไปเป็นการติดตั้งแบบไม่มีการเข้ารหัสได้

### ภาษา

Omarchy พูดได้ 50 ภาษา — ชุดเดียวกันกับ omarchy.org — และ English เป็นค่าเริ่มต้น หากต้องการเปลี่ยน ให้เปิดเมนู Omarchy แล้วไปที่ _Setup > Region > Language_ หรือรัน `omarchy language <code>` ใน terminal (`omarchy language list` จะแสดงรหัส) เมนู เดสก์ท็อป และการแจ้งเตือนของ Omarchy เองจะเปลี่ยนภาษาทันที และทุกแอปพลิเคชันที่คุณเปิดหลังจากนั้นก็จะเปลี่ยนตามด้วย แอปที่เปิดอยู่แล้วจะเปลี่ยนเมื่อคุณ restart แอปเหล่านั้น

หากต้องการคงภาษาไว้ แต่เขียนวันที่ เวลา ตัวเลข เงิน หน่วย และขนาดกระดาษในแบบที่อีกภูมิภาคหนึ่งทำ (เช่น English ที่ใช้วันที่แบบยุโรปและนาฬิกาแบบ 24 ชั่วโมง) ให้เลือกภูมิภาคภายใต้ _Setup > Region > Formats_ ซึ่งแต่ละตัวเลือกจะแสดงตัวอย่าง หรือรัน `omarchy region <code>` (`omarchy region list` จะแสดงรหัส) _Same as language_ จะกลับไปใช้รูปแบบของภาษานั้นเอง เช่นเดียวกับการเปลี่ยนภาษา การเปลี่ยนแปลงนี้จะมีผลกับแอปที่คุณเปิดหลังจากนั้น
