# เริ่มต้นใช้งาน

Omarchy ติดตั้งโดยใช้ ISO คุณสามารถเลือกระหว่างการติดตั้งแบบทั้งดิสก์ ซึ่งจะยึดครองไดรฟ์ทั้งไดรฟ์ หรือการติดตั้งในพื้นที่ว่าง ซึ่งจะใส่ Omarchy ลงในพื้นที่ที่ยังไม่ได้จัดสรรบนไดรฟ์ — นั่นคือวิธีทำ dual boot ควบคู่ไปกับ Windows หรือระบบปฏิบัติการอื่น (ดู [การติดตั้งแบบ dual-boot](50-dual-boot-install.md) — โปรดทราบว่าคุณต้องปิด BitLocker ใน Windows ก่อน) ไม่ว่าจะเลือกแบบไหน การติดตั้งจะตั้งค่าเริ่มต้นเป็นการเข้ารหัสแบบเต็มรูปแบบ และตัวเลือกแบบทั้งดิสก์จะล้างไดรฟ์ที่เลือกทั้งหมด ดังนั้นอย่าลืมสำรองข้อมูลไว้ก่อนใช้ไดรฟ์ที่มีอยู่เดิม!

ก่อนอื่นให้ [ดาวน์โหลด ISO ของ Omarchy](https://omarchy.org/) ใส่ลงใน USB stick (ใช้ [balenaEtcher](https://etcher.balena.io/) บน Mac/Windows หรือ [caligula](https://github.com/ifd3f/caligula) บน Linux) แล้วบูตจาก stick นั้น

_คุณต้องปิด Secure Boot และ/หรือ TPM ใน BIOS คุณต้องปิดสิ่งเหล่านี้จึงจะสามารถติดตั้ง Omarchy ได้ ทั้งสองอย่างคือระบบรักษาความปลอดภัยของ Microsoft ที่ทำมาเพื่อ Windows และระบบ Linux ที่ผูกอยู่กับ Microsoft_

จากนั้นตอบคำถามการกำหนดค่า และยืนยันแบบนี้:

 ![install-config](images/install-config.webp)

จากนั้นเลือกไดรฟ์สำหรับการติดตั้งของคุณ แล้วนั่งพักดูรายการติดตั้งได้เลย มันอาจเสร็จภายในไม่ถึงหนึ่งนาทีบนเครื่องรุ่นใหม่ที่เร็วที่สุด แต่ก็ไม่ควรใช้เกิน 5 นาทีแม้แต่บนคอมพิวเตอร์ที่เก่ากว่า

### ใช้คีย์บอร์ดแบบมีสายหรือ 2.4ghz!

การเข้ารหัสดิสก์แบบเต็มรูปแบบจะไม่ยอมให้คุณใส่รหัสผ่านจากคีย์บอร์ด Bluetooth ตอนเริ่มเครื่อง เหมือนกับที่คุณไม่สามารถใช้คีย์บอร์ด Bluetooth เพื่อเข้าสู่ BIOS บน PC ได้นั่นแหละ คุณต้องใช้คีย์บอร์ดที่ใช้ dongle 2.4ghz หรือสายเคเบิลแทน (ซึ่งดีกว่ามากอยู่แล้วในเรื่อง latency!) ส่วนตัวผมรัก [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard) มาก!

### การติดตั้งให้เจ้าของคนอื่น

หากคุณกำลังตั้งค่าเครื่องให้คนอื่น — สมาชิกในครอบครัว พนักงานใหม่ หรือผู้ซื้อ — คุณไม่ควรตอบคำถามส่วนตัวแทนพวกเขา ให้กด `Ctrl + C` ตั้งแต่หน้าจอแรกสุดของตัวติดตั้ง (หน้าจอเลือกคีย์บอร์ด) แล้ว Omarchy จะเสนอให้เตรียมเครื่องสำหรับเจ้าของคนอื่นแทน ระบบจะติดตั้งทันที แต่การตั้งค่าส่วนตัวทั้งหมด — รูปแบบคีย์บอร์ด ชื่อผู้ใช้ รหัสผ่าน — จะถูกเลื่อนไปจนกว่าเครื่องจะบูตครั้งแรก ไดรฟ์ยังถูกเข้ารหัสโดยค่าเริ่มต้น และรหัสผ่านที่เจ้าของใหม่เลือกในการบูตครั้งแรกนั้นก็จะกลายเป็นรหัสผ่านการเข้ารหัสด้วย (เครื่องที่คุณใช้งานไปแล้วก็สามารถส่งต่อได้โดยไม่ต้องติดตั้งใหม่เช่นกัน — ดู [การรีเซ็ตคอมพิวเตอร์](48-security.md))

### การติดตั้งแบบไม่ต้องดูแล

ISO ยังสามารถติดตั้งได้เองโดยสมบูรณ์ — ไม่ต้องใช้คีย์บอร์ด ไม่ต้องใช้ wizard — เมื่อมีการส่งมอบค่ากำหนดให้มันบนไดรฟ์อีกตัว นั่นคือวิธีถือว่า Omarchy เป็น base image สำหรับ VM และเครื่องในกลุ่มทั้งหมด ดู [การติดตั้งแบบไม่ต้องดูแล](51-unattended-installs.md)

### การติดตั้งโดยไม่มีการเข้ารหัส

Omarchy จะถูกติดตั้งพร้อมการเข้ารหัสโดยค่าเริ่มต้น นั่นคือตัวเลือกที่ปลอดภัยและรับผิดชอบสำหรับคอมพิวเตอร์ใดๆ ที่อาจสูญหายหรือถูกขโมยได้ คุณไม่อยากให้ใครก็ตามที่เข้าถึงฮาร์ดแวร์ของคุณสามารถเอาข้อมูลของคุณไปได้หรอก!

แต่ในกรณีพิเศษ เช่น การติดตั้ง Omarchy แบบระยะไกลบนคอมพิวเตอร์ที่ได้รับการปกป้อง หรือการติดตั้งแบบทิ้งๆ ขว้างๆ ที่ไม่มีข้อมูลอ่อนไหว คุณอาจอยากติดตั้งโดยไม่มีการเข้ารหัส คุณสามารถกด `Ctrl + C` ที่หน้าจอยืนยันการฟอร์แมตดิสก์ เพื่อสลับไปเป็นการติดตั้งแบบไม่มีการเข้ารหัสได้

### ภาษา

Omarchy พูดได้ 50 ภาษา — เป็นชุดภาษาเดียวกับ omarchy.org — และภาษาอังกฤษคือค่าเริ่มต้น หากต้องการสลับ ให้เปิดเมนู Omarchy แล้วไปที่ _Setup > Language_ หรือรัน `omarchy language <code>` ใน terminal (`omarchy language list` จะแสดงรหัสต่างๆ) เมนู เดสก์ท็อป และการแจ้งเตือนของ Omarchy เองจะเปลี่ยนภาษาทันที และทุกแอปพลิเคชันที่คุณเปิดหลังจากนั้นก็จะตามไปด้วย แอปที่เปิดอยู่แล้วจะสลับเมื่อคุณรีสตาร์ทมัน
