# เริ่มต้นใช้งาน

Omarchy ติดตั้งโดยใช้ ISO คุณสามารถเลือกระหว่างการติดตั้งแบบเต็มดิสก์ ซึ่งจะยึดทั้งไดรฟ์ หรือการติดตั้งแบบใช้พื้นที่ว่าง ซึ่งจะวาง Omarchy ไว้ในพื้นที่ที่ยังไม่ได้จัดสรรบนไดรฟ์ — นั่นคือวิธี dual boot ควบคู่ไปกับ Windows หรือ OS อื่น (ดู [การติดตั้งแบบ dual-boot](50-dual-boot-install.md) — โปรดทราบว่าคุณจะต้องปิด BitLocker ใน Windows ก่อน) ไม่ว่าจะเลือกแบบไหน การติดตั้งจะใช้การเข้ารหัสเต็มรูปแบบเป็นค่าเริ่มต้น และตัวเลือกแบบเต็มดิสก์จะล้างไดรฟ์ที่เลือก ดังนั้นอย่าลืมสำรองข้อมูลก่อนใช้ไดรฟ์ที่มีอยู่!

[ดาวน์โหลด Omarchy ISO](https://omarchy.org/) ก่อน ใส่ลงใน USB stick (ใช้ [Rufus](https://rufus.ie/) บน Windows, [balenaEtcher](https://etcher.balena.io/) บน Mac หรือ [caligula](https://github.com/ifd3f/caligula) บน Linux) แล้ว boot จาก stick นั้น

_คุณต้องปิด Secure Boot และ/หรือ TPM ใน BIOS คุณต้องปิดสิ่งเหล่านี้เพื่อที่จะติดตั้ง Omarchy ได้ สิ่งเหล่านี้เป็นแผนการรักษาความปลอดภัยของ Microsoft ที่สร้างมาสำหรับ Windows และ Linux distribution ที่เกี่ยวข้องกับ Microsoft_

จากนั้นตอบคำถามการกำหนดค่า และยืนยันตามนี้:

 ![install-config](images/install-config.webp)

จากนั้นเลือกไดรฟ์สำหรับการติดตั้งของคุณ แล้วนั่งพักชมโชว์การติดตั้งไปได้เลย บนเครื่องรุ่นใหม่ที่เร็วที่สุดอาจเสร็จได้ในเวลาไม่ถึงหนึ่งนาที แต่แม้บนคอมพิวเตอร์รุ่นเก่าก็ไม่ควรใช้เวลานานเกิน 5 นาที

 ![install-done](images/install-done.webp)

ตอนนี้คุณพร้อมใช้ Omarchy แล้ว!

### ใช้คีย์บอร์ดแบบมีสายหรือ 2.4ghz!

การเข้ารหัสเต็มดิสก์จะไม่ยอมให้คุณป้อนรหัสผ่านจากคีย์บอร์ด Bluetooth ตอนเริ่มต้นระบบ เหมือนกับที่คุณใช้คีย์บอร์ด Bluetooth เพื่อเข้า BIOS บน PC ไม่ได้นั่นแหละ คุณจะต้องใช้คีย์บอร์ดที่ใช้ dongle 2.4ghz หรือสาย (ซึ่งดีกว่ามากในเรื่อง latency อยู่แล้ว!) ส่วนตัวผมชอบ [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard) มาก!

### การติดตั้งสำหรับเจ้าของคนอื่น

หากคุณกำลังตั้งค่าเครื่องให้คนอื่น — สมาชิกในครอบครัว พนักงานใหม่ ผู้ซื้อ — คุณไม่ควรตอบคำถามส่วนตัวแทนพวกเขา กด `Ctrl + C` ที่หน้าจอแรกสุดของตัวติดตั้ง (การเลือกคีย์บอร์ด) แล้ว Omarchy จะเสนอให้เตรียมเครื่องสำหรับเจ้าของคนอื่นแทน ระบบจะติดตั้งทันที แต่การตั้งค่าส่วนตัวทั้งหมด — รูปแบบคีย์บอร์ด ชื่อผู้ใช้ รหัสผ่าน — จะถูกเลื่อนไปจนกว่าเครื่องจะ boot เป็นครั้งแรก ไดรฟ์ยังคงเข้ารหัสตามค่าเริ่มต้น และรหัสผ่านที่เจ้าของใหม่เลือกตอน boot ครั้งแรกนั้นจะกลายเป็นรหัสผ่านการเข้ารหัสด้วย (เครื่องที่คุณใช้งานอยู่แล้วก็สามารถส่งมอบได้โดยไม่ต้องติดตั้งใหม่เช่นกัน — ดู [การรีเซ็ตคอมพิวเตอร์](48-security.md))

### การติดตั้งแบบไม่ต้องดูแล

ISO ยังสามารถติดตั้งได้เองทั้งหมด — ไม่ต้องใช้คีย์บอร์ด ไม่ต้องใช้ตัวช่วยติดตั้ง — เมื่อได้รับข้อมูลการกำหนดค่าบนไดรฟ์ที่สอง นั่นคือวิธีที่จะปฏิบัติต่อ Omarchy เสมือนเป็น base image สำหรับ VM และเครื่องจำนวนมากใน fleet ดู [การติดตั้งแบบไม่ต้องดูแล](51-unattended-installs.md)

### การติดตั้งแบบไม่มีการเข้ารหัส

Omarchy ติดตั้งมาพร้อมการเข้ารหัสเป็นค่าเริ่มต้น นี่คือตัวเลือกที่ปลอดภัยและมีความรับผิดชอบสำหรับคอมพิวเตอร์เครื่องใดก็ตามที่อาจสูญหายหรือถูกขโมย คุณคงไม่อยากให้ใครก็ตามที่เข้าถึงฮาร์ดแวร์ของคุณได้สามารถเข้าถึงข้อมูลของคุณได้!

แต่ในสถานการณ์พิเศษ เช่น การติดตั้ง Omarchy ระยะไกลบนคอมพิวเตอร์ที่ได้รับการป้องกัน หรือการติดตั้งแบบใช้แล้วทิ้งที่ไม่มีข้อมูลสำคัญ คุณอาจต้องการติดตั้งโดยไม่มีการเข้ารหัส คุณสามารถกด `Ctrl + C` ที่หน้าจอยืนยันการฟอร์แมตดิสก์เพื่อเปลี่ยนเป็นการติดตั้งแบบไม่มีการเข้ารหัสได้

### ภาษา

Omarchy พูดได้ 50 ภาษา — ชุดเดียวกันกับ omarchy.org — และ English เป็นค่าเริ่มต้น หากต้องการเปลี่ยน ให้เปิดเมนู Omarchy แล้วไปที่ _Setup > Region > Language_ หรือรัน `omarchy language <code>` ใน terminal (`omarchy language list` จะแสดงรหัสต่าง ๆ) เมนู เดสก์ท็อป และการแจ้งเตือนของ Omarchy เองจะเปลี่ยนภาษาทันที และทุกแอปพลิเคชันที่คุณเปิดหลังจากนั้นก็จะเปลี่ยนตามด้วย แอปที่เปิดอยู่แล้วจะเปลี่ยนเมื่อคุณรีสตาร์ทแอปเหล่านั้น

หากต้องการคงภาษาไว้ แต่เขียนวันที่ เวลา ตัวเลข เงิน หน่วย และขนาดกระดาษตามแบบของภูมิภาคอื่น (เช่น English ที่ใช้วันที่แบบยุโรปและนาฬิกา 24 ชั่วโมง) ให้เลือกภูมิภาคภายใต้ _Setup > Region > Formats_ โดยแต่ละตัวเลือกจะแสดงตัวอย่าง หรือรัน `omarchy region formats <code>` (`omarchy region formats list` จะแสดงรหัสต่าง ๆ) _Same as language_ จะกลับไปใช้รูปแบบของภาษานั้นเอง เช่นเดียวกับการเปลี่ยนภาษา มันจะมีผลกับแอปที่คุณเปิดหลังจากนั้น
