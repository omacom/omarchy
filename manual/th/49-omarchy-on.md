# Omarchy บน...

### ชิป Apple M1/M2

[Asahi Alarm](https://asahi-alarm.org/) เป็น Arch เวอร์ชันสำหรับคอมพิวเตอร์ Apple M1/M2 ที่สร้างบน [Asahi Linux](https://asahilinux.org/) คุณสามารถทำให้ Omarchy รันบนนั้นได้ด้วยความพยายามบางส่วน ดู [คู่มือที่ผู้ใช้จัดทำ](https://github.com/omarchy-mac/omarchy-mac)

### เครื่องเสมือน Apple

คุณยังติดตั้ง Omarchy ภายใน VM Parallels ได้ เป็นกระบวนการที่ค่อนข้างยุ่งยาก แต่มี [คู่มือที่ผู้ใช้จัดทำ](https://github.com/omacom/omarchy/discussions/452) สำหรับเรื่องนั้นเช่นกัน

### VirtualBox

VirtualBox เป็นตัวรัน VM ยอดนิยม [คุณสามารถรัน Omarchy ข้างในนั้นได้เช่นกัน](https://github.com/omacom/omarchy/discussions/176) แต่ประสิทธิภาพอาจไม่ดีนัก

### VMware Workstation บน Windows 11

ตัวรัน VM ยอดนิยมอีกตัวสำหรับ Windows [Omarchy ถูกตั้งค่าภายในนั้นเช่นกัน](https://github.com/omacom/omarchy/discussions/572)

### Steam Deck

Steam Deck รันบน Arch ซึ่งหมายความว่าคุณสามารถรัน Omarchy บน Steam Deck ของคุณได้ Altynbek Orumbayev มี [สคริปต์ตั้งค่าเต็มรูปแบบและคำอธิบายวิธีทำ](https://github.com/aorumbayev/deckarchy) เท่แค่ไหนล่ะ!

### NixOS

Omarchy จริง ๆ คือ Arch + Hyprland แต่ Henry Sipp ได้ [ย้ายแก่นของการตั้งค่าไปยัง NixOS](https://github.com/henrysipp/omarchy-nix) ดังนั้นถ้าคุณถูก nix-pill แล้ว นี่คือจุดเริ่มต้นที่ดี มันอาจหรืออาจไม่อัปเดตตามการเปลี่ยนแปลงล่าสุดของ Omarchy แต่ก็ค่อนข้างเท่อยู่ดี!

### อย่างอื่น!

ถ้าคุณกำลังพยายามทำให้ Omarchy รันบนการกำหนดค่าที่ไม่ใช่ค่าเริ่มต้น คุณควรเข้าร่วมช่อง #omarchy-on-other บน [Discord ชุมชนของเรา](https://discord.gg/tXFUdasqhY)
