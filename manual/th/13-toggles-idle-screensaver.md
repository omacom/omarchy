# สวิตช์ ช่วงว่าง และพักหน้าจอ

จำนวนมากของสิ่งที่คุณเปลี่ยนเป็นประจำทุกวันไม่ใช่การตั้งค่าจริง ๆ มันคือโหมดที่คุณเปิดไว้หนึ่งชั่วโมงแล้วปิดอีกครั้ง: แสงกลางคืนขณะที่คุณทำงานดึก ห้ามรบกวนขณะที่คุณกำลังนำเสนอ นอนไม่หลับขณะที่คุณกำลังดูอะไรบางอย่าง Omarchy เรียกพวกมันว่าสวิตช์ และพวกมันทั้งหมดทำงานในแบบเดียวกัน — ปุ่มลัด รายการเมนู และคำสั่ง ทั้งหมดแตะสวิตช์เดียวกัน

### เมนูสวิตช์

`Super + Ctrl + O` เปิด _สั่งการ > สลับ_ โดยตรง หรือคุณเดินไปที่นั่นจากเมนู Omarchy (`Super + Space`) ทุกสิ่งในรายการนั้นคือสวิตช์ที่คุณพลิกได้โดยไม่ต้องคิดว่าสถานะอยู่ที่ไหน สวิตช์สำหรับรูปลักษณ์ของเดสก์ท็อปอยู่ถัดจากมัน ภายใต้ _สั่งการ > ลักษณะ_

จากเทอร์มินัล สวิตช์เดียวกันคือ `omarchy toggle <thing>` รัน `omarchy toggle` เพียงอย่างเดียวเพื่อดูทั้งกลุ่ม

| สวิตช์ | ปุ่มลัด | คำสั่ง |
| ------ | ------ | ------- |
| แสงกลางคืน | `Super + Ctrl + N` | `omarchy toggle nightlight` |
| ปิดเสียงการแจ้งเตือน | `Super + Ctrl + ,` | `omarchy toggle notification silencing` |
| ตื่นอยู่ (ไม่ล็อกเมื่อว่าง) | `Super + Ctrl + I` | `omarchy toggle idle` |
| การเก็บข้อมูลการขัดข้อง | — | `omarchy toggle crash-capture` |
| พักหน้าจอ | — | `omarchy toggle screensaver` |
| การซิงค์ธีม [Herdr](https://herdr.dev) | — | `omarchy toggle theme sync` |
| แถบเมนู | `Super + Shift + Space` | `omarchy toggle bar` |
| ทัชแพด | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| จอสัมผัส | — | `omarchy toggle touchscreen` |
| พักเครื่อง | — | `omarchy toggle suspend` |
| Hybrid GPU | — | `omarchy toggle hybrid gpu` |

สวิตช์ทัชแพด จอสัมผัส และ Hybrid GPU อยู่ภายใต้ _สั่งการ > ฮาร์ดแวร์_ (`Super + Ctrl + H`) แทนที่จะอยู่ภายใต้สลับ เนื่องจากพวกมันปรากฏเฉพาะเมื่อคุณมีฮาร์ดแวร์นั้นจริง ๆ สวิตช์ทัชแพดและจอสัมผัสอยู่รอดผ่านการโหลด Hyprland ใหม่ — ชื่อของอุปกรณ์ที่ปิดใช้งานจะถูกบันทึกลงในไฟล์สถานะขนาดเล็กที่ Hyprland อ่านตอนเริ่มเพื่อปิดใช้งานมันอีกครั้ง

_สั่งการ > ลักษณะ_ มีแถบเมนูและแอนิเมชัน พร้อมบางสิ่งที่ไม่ใช่คำสั่ง `omarchy toggle` แต่พฤติกรรมเหมือนกัน: เปอร์เซ็นต์แบตเตอรี่ในแถบ เค้าโครงพื้นที่งานเริ่มต้น ช่องว่างหน้าต่าง (`Super + Shift + Backspace`) และอัตราส่วนสี่เหลี่ยมแบบ 1 หน้าต่าง (`Super + Ctrl + Backspace`)

ส่วนใหญ่เป็นแค่ไฟล์แฟล็กภายใต้ `~/.local/state/omarchy/toggles/` หากคุณต้องการแตกกิ่งตามหนึ่งในนั้นในสคริปต์ `omarchy-toggle-enabled` ให้รหัสออกแทนที่จะทำให้คุณต้องไปค้นหา:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

แฟล็กต่าง ๆ ตั้งชื่อตามสถานะปิด — `screensaver-off` `suspend-off` `bar-off` — ดังนั้นการปรากฏอยู่ของพวกมันหมายความว่าฟีเจอร์นั้นปิดใช้งานอยู่

### ตัวบ่งชี้ในแถบ

เมื่อโหมดเปิดอยู่ คุณจะได้สัญลักษณ์เล็ก ๆ อยู่กลางแถบบนถัดจากนาฬิกา นั่นคือวิดเจ็ตตัวบ่งชี้ และมันมีทั้งการพูดพิมพ์ การอัดหน้าจอ รายการเตือนความจำที่รออยู่ แสงกลางคืน ห้ามรบกวน และการตื่นอยู่

ตัวบ่งชี้ที่ไม่ได้ใช้งานจะถูกซ่อน ชี้ไปที่บริเวณรอบ ๆ พวกมัน แล้วพวกมันจะจางเข้ามาแบบหม่น ๆ ดังนั้นคุณจึงคลิกหนึ่งในนั้นเพื่อเปิดมันโดยไม่ต้องรู้ปุ่มลัดของมัน การคลิกตัวที่กำลังใช้งานจะปิดมันกลับ ถ้าคุณอยากเห็นพวกมันทั้งหมดตลอดเวลา ตั้งค่า `alwaysShow` เป็น `true` บนรายการ `omarchy.indicators` ใน `~/.config/omarchy/shell.json` — ดู [แถบบน](05-the-top-bar.md) สำหรับวิธีที่วิดเจ็ตแถบถูกกำหนดค่า

### แสงกลางคืน

`Super + Ctrl + N` ทำให้หน้าจออุ่นเป็น 4000K และการกดอีกครั้งจะคืนมันกลับเป็น 6500K มันขับโดย hyprsunset ซึ่งสวิตช์นี้เริ่มให้คุณหากมันยังไม่ได้ทำงานอยู่

ตามค่าเริ่มต้น hyprsunset ไม่ทำอะไรกับหน้าจอของคุณเลย `~/.config/hypr/hyprsunset.conf` จัดส่งพร้อมโปรไฟล์เอกลักษณ์โดยเฉพาะ เพื่อให้จอแสดงผลไม่ถูกแตะต้องจนกว่าคุณจะขอความอบอุ่น หากคุณอยากให้มันสลับตามนาฬิกา แทนที่สิ่งนั้นด้วยโปรไฟล์เวลา:

```
profile {
    time = 20:00
    temperature = 4000
}
```

จากนั้นเริ่ม hyprsunset ตอนเข้าสู่ระบบโดยการเพิ่ม `o.launch_on_start("hyprsunset")` ไปยัง `~/.config/hypr/autostart.lua` คู่ 4000K/6500K ที่สวิตช์ใช้เป็นการตายตัว ดังนั้นไฟล์คอนฟิกคือที่ที่คุณไปหากคุณต้องการอุณหภูมิต่างออกไป

### ห้ามรบกวน

`Super + Ctrl + ,` ปิดเสียงการแจ้งเตือน ไม่มีขนมปังปิ้งปรากฏขึ้นขณะที่มันเปิดอยู่ และตัวบ่งชี้ระฆังที่มีเครื่องหมายกากบาทอยู่ในแถบเพื่อเตือนคุณว่าทำไมเดสก์ท็อปจึงเงียบลง

อย่างไรก็ตามไม่มีอะไรสูญหายเลย การแจ้งเตือนที่ปิดเสียงจะถูกเขียนตรงลงในประวัติการแจ้งเตือนของคุณ ซึ่งคือบันทึกที่คุณต้องการเมื่อคุณกลับมาและสงสัยว่าคุณพลาดอะไรไป เปิดมันด้วย `Super + Shift + Alt + ,` ดู [ประกาศแจ้ง](10-notices.md) สำหรับส่วนที่เหลือของเรื่องการแจ้งเตือน

ข้อความสองชนิดยังคงผ่านมาได้: ขนมปังปิ้งยืนยันของ Omarchy เองสำหรับสิ่งที่คุณเพิ่งทำ ("เปลี่ยนธีมแล้ว" "บันทึกภาพหน้าจอแล้ว") และการแจ้งเตือนวิกฤตที่ส่งจากบรรทัดคำสั่ง แอปแชตที่ทำเครื่องหมายทุกอย่างว่าวิกฤตเพื่อบังคับทางมาอยู่ตรงหน้าคุณไม่เข้าข่าย

### ช่วงว่าง

Omarchy shell เป็นเจ้าของพฤติกรรมช่วงว่าง และจังหวะเวลาเป็นบล็อก `idle` ในระดับบนสุดใน `~/.config/omarchy/shell.json`:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

ทั้งสองตัวเลขคือวินาทีนับจากช่วงเวลาที่คุณว่าง — ไม่ใช่นับจากกันและกัน ดังนั้นด้วยค่าเริ่มต้น พักหน้าจอจะปรากฏหลังสองนาทีครึ่ง และหน้าจอล็อกจะเข้ายึดที่ห้านาที ไม่ว่าพักหน้าจอจะทำงานหรือไม่ก็ตาม บันทึกไฟล์และ shell จะหยิบเอาจังหวะเวลาใหม่ขึ้นมาทันที

ถ้าคุณปิดพักหน้าจอก่อนเส้นตายการล็อก นั่นนับเป็นกิจกรรมและการล็อกที่รออยู่จะถูกยกเลิก คุณไม่ถูกล็อกออกแค่เพราะชำเลืองมองเครื่องของคุณ

หากต้องการหยุดการล็อกเมื่อว่างโดยสิ้นเชิง `Super + Ctrl + I` — หรือ `omarchy toggle idle` — จะเปิดโหมดตื่นอยู่ และตัวบ่งชี้ถ้วยกาแฟจะปรากฏในแถบ นั่นคือปุ่มที่กดก่อนการนำเสนอยาว ๆ หรือการสร้างที่คุณอยากดู กดอีกครั้งเพื่อกลับสู่ปกติ `omarchy toggle idle status` พิมพ์สถานะปัจจุบันเป็น JSON หากคุณต้องการมันจากสคริปต์

เรื่องนี้เกี่ยวกับการล็อกและพักหน้าจอ ไม่ใช่เรื่องพลังงาน การพักเครื่องและการจำศีลมีการตั้งค่าของตัวเองใน [การพักระบบ](36-system-sleep.md)

### พักหน้าจอ

พักหน้าจอของ Omarchy คือศิลปะ ASCII ที่วิ่งผ่านเอฟเฟกต์ข้อความแบบสุ่ม หนึ่งชุดต่อจอภาพ ปุ่มหรือการขยับเมาส์ใด ๆ จะออกจากมัน

คุณเริ่มมันตามต้องการจาก _ระบบ > พักหน้าจอ_ (`Super + Esc`) ซึ่งบังคับให้มันปรากฏแม้ว่าคุณจะปิดพักหน้าจอช่วงว่างไว้ก็ตาม ไม่มีปุ่มลัดผูกไว้เป็นค่าเริ่มต้น

`omarchy toggle screensaver` คือสิ่งที่ปิดพักหน้าจอช่วงว่างนั้น หากคุณอยากตรงจากทำงานไปสู่ถูกล็อก มันต้องใช้เทอร์มินัลที่มันรู้วิธีตั้งค่า — Alacritty Foot Ghostty หรือ Kitty — และจะบอกคุณหากเทอร์มินัลเริ่มต้นของคุณเป็นอย่างอื่น

โลโก้ที่มันวาดเป็นของคุณที่จะเปลี่ยน ภายใต้ _สไตล์ > พักหน้าจอ_ อัปโหลดไฟล์ png หรือ svg แล้ว Omarchy จะแปลงมันเป็น ASCII ดู [การสร้างแบรนด์](41-branding.md)

### หน้าจอล็อก

`Super + Ctrl + L` ล็อกเครื่อง นั่นรันหน้าจอล็อกจาก Omarchy shell ทำให้จอแสดงผลว่างเปล่า รีเซ็ตเค้าโครงแป้นพิมพ์ของคุณกลับไปเป็นเค้าโครงแรก เพื่อให้คุณไม่พิมพ์รหัสผ่านของคุณในตัวอักษรที่ผิด และ — หากคุณมีมันทำงานอยู่ — ล็อก 1Password ระหว่างทางออก

หน้าจอล็อกใช้รหัสผ่าน และมันยังใช้ลายนิ้วมือได้ด้วยเมื่อคุณตั้งค่ามันแล้ว เรื่องนั้น และวิธีอื่น ๆ ในการยืนยันตัวตนอธิบายไว้ใน [การยืนยันตัวตนด้วยฮาร์ดแวร์](37-hardware-authentication.md)
