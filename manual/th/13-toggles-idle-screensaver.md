# สวิตช์สลับโหมด, การไม่มีกิจกรรม และโปรแกรมรักษาหน้าจอ

สิ่งที่คุณเปลี่ยนอยู่ทุกวันจำนวนมากไม่ใช่การตั้งค่าจริง ๆ มันคือโหมดที่คุณเปิดไว้สักชั่วโมงแล้วปิดทิ้ง: แสงกลางคืนขณะที่คุณทำงานดึก, ห้ามรบกวนขณะที่คุณกำลังนำเสนอ, คงสถานะตื่นขณะที่คุณกำลังดูอะไรอยู่ Omarchy เรียกสิ่งเหล่านั้นว่าสวิตช์สลับโหมด และทั้งหมดทำงานแบบเดียวกัน — ปุ่มลัด, รายการในเมนู และคำสั่ง ล้วนกดไปที่สวิตช์ตัวเดียวกัน

### เมนูสวิตช์สลับโหมด

`Super + Ctrl + O` เปิด _Trigger > Toggle_ โดยตรง หรือคุณจะเดินไปจากเมนู Omarchy (`Super + Space`) ก็ได้ ทุกอย่างในรายการนั้นคือสวิตช์ที่คุณพลิกได้โดยไม่ต้องคิดว่าสถานะของมันเก็บอยู่ที่ไหน สวิตช์สำหรับลักษณะของเดสก์ท็อปอยู่ข้าง ๆ กันนั้น ภายใต้ _Appearance_

จากเทอร์มินัล สวิตช์เดียวกันเหล่านั้นคือ `omarchy toggle <thing>` เรียก `omarchy toggle` เพียงอย่างเดียวเพื่อดูทั้งกลุ่ม

| สวิตช์สลับโหมด | ปุ่มลัด | คำสั่ง |
| ------ | ------ | ------- |
| แสงกลางคืน | — | `omarchy toggle nightlight` |
| ปิดเสียงการแจ้งเตือน | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| คงสถานะตื่น (ไม่ล็อกเมื่อไม่มีกิจกรรม) | `Super + Ctrl + I` | `omarchy toggle idle` |
| การบันทึกเมื่อเกิดการขัดข้อง | — | `omarchy toggle crash-capture` |
| โปรแกรมรักษาหน้าจอ | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) การซิงค์ธีม | — | `omarchy toggle theme sync` |
| แถบเมนู | `Super + Shift + Space` | `omarchy toggle bar` |
| ทัชแพด | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| หน้าจอสัมผัส | — | `omarchy toggle touchscreen` |
| ระงับการทำงานชั่วคราว | — | `omarchy toggle suspend` |
| Hybrid GPU | — | `omarchy toggle hybrid gpu` |

สวิตช์ทัชแพด, หน้าจอสัมผัส และ Hybrid GPU อยู่ภายใต้ _Trigger > Hardware_ (`Super + Ctrl + H`) ไม่ใช่ภายใต้ Toggle เพราะพวกมันจะแสดงขึ้นมาก็ต่อเมื่อคุณมีฮาร์ดแวร์นั้นอยู่จริง ๆ สวิตช์ทัชแพดและหน้าจอสัมผัสจะยังคงอยู่หลังการโหลด Hyprland ใหม่ — ชื่อของอุปกรณ์ที่ถูกปิดใช้งานจะถูกบันทึกไว้ในไฟล์สถานะขนาดเล็กที่ Hyprland อ่านตอนเริ่มต้นเพื่อปิดใช้งานมันอีกครั้ง

_Appearance_ เก็บแถบเมนูและภาพเคลื่อนไหวไว้ รวมทั้งบางอย่างที่ไม่ใช่คำสั่ง `omarchy toggle` แต่ทำงานแบบเดียวกัน: เปอร์เซ็นต์แบตเตอรี่ในแถบ, เค้าโครงพื้นที่ทำงานเริ่มต้น และภายใต้ _Windows_, ระยะห่างของหน้าต่าง (`Super + Shift + Backspace`) และอัตราส่วนสี่เหลี่ยมจัตุรัสแบบ 1 หน้าต่าง (`Super + Ctrl + Backspace`)

ส่วนใหญ่แล้ว สิ่งเหล่านี้เป็นแค่ไฟล์ธงภายใต้ `~/.local/state/omarchy/toggles/` หากคุณต้องการแยกเงื่อนไขตามหนึ่งในนั้นในสคริปต์ `omarchy-toggle-enabled` จะให้รหัสการออกแก่คุณ แทนที่จะทำให้คุณต้องไปค้นหาเอง:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

ธงเหล่านี้ตั้งชื่อตามสถานะปิด — `screensaver-off`, `suspend-off`, `bar-off` — ดังนั้นการมีอยู่ของมันหมายความว่าคุณสมบัตินั้นถูกปิดใช้งาน

### ตัวบ่งชี้ในแถบ

เมื่อโหมดใดเปิดอยู่ คุณจะได้สัญลักษณ์เล็ก ๆ ตรงกลางแถบด้านบนข้างนาฬิกา นั่นคือวิดเจ็ตตัวบ่งชี้ และมันบรรจุการป้อนตามคำบอก, การบันทึกหน้าจอ, การเตือนความจำที่รอดำเนินการ, แสงกลางคืน, ห้ามรบกวน และคงสถานะตื่นไว้

ตัวบ่งชี้ที่ไม่ได้ใช้งานจะถูกซ่อนไว้ เลื่อนตัวชี้ไปไว้เหนือแถบตรงไหนก็ได้ แล้วพวกมันจะค่อย ๆ ปรากฏขึ้นแบบจาง ๆ เพื่อให้คุณคลิกตัวหนึ่งเพื่อเปิดมันได้โดยไม่ต้องรู้ปุ่มลัดของมัน การคลิกตัวที่ใช้งานอยู่จะปิดมันกลับไป หากคุณอยากเห็นทั้งหมดตลอดเวลา ให้ตั้ง `alwaysShow` เป็น `true` บนรายการ `omarchy.indicators` ใน `~/.config/omarchy/shell.json` — ดู [แถบด้านบน](05-the-top-bar.md) สำหรับวิธีการกำหนดค่าวิดเจ็ตของแถบ

### แสงกลางคืน

แสงกลางคืนทำให้หน้าจออุ่นขึ้นเป็น 4000K และการสลับมันอีกครั้งจะนำมันกลับไปเป็น 6500K พลิกมันจากเมนูสวิตช์สลับโหมด (`Super + Ctrl + O`) หรือด้วย `omarchy toggle nightlight` มันขับเคลื่อนโดย hyprsunset ซึ่งสวิตช์จะเริ่มให้คุณหากมันยังไม่ได้ทำงานอยู่

โดยค่าเริ่มต้น hyprsunset จะไม่ทำอะไรกับหน้าจอของคุณเลย `~/.config/hypr/hyprsunset.conf` มาพร้อมโปรไฟล์เอกลักษณ์อย่างแม่นยำเพื่อให้จอแสดงผลยังคงไม่ถูกแตะต้องจนกว่าคุณจะขอความอบอุ่น หากคุณอยากให้มันสลับตามนาฬิกามากกว่า ให้แทนที่สิ่งนั้นด้วยโปรไฟล์ตามเวลา:

```
profile {
    time = 20:00
    temperature = 4000
}
```

จากนั้นเริ่ม hyprsunset ตอนเข้าสู่ระบบโดยเพิ่ม `o.launch_on_start("hyprsunset")` ไปที่ `~/.config/hypr/autostart.lua` คู่ 4000K/6500K ที่สวิตช์ใช้ถูกกำหนดตายตัว ดังนั้นไฟล์การกำหนดค่าคือที่ที่คุณไปหากคุณต้องการอุณหภูมิอื่น

### ห้ามรบกวน

`Super + Ctrl + Alt + ,` ปิดเสียงการแจ้งเตือน จะไม่มีข้อความแจ้งเตือนแบบป๊อปอัปปรากฏขึ้นขณะที่มันเปิดอยู่ และตัวบ่งชี้กระดิ่งที่มีเส้นขีดฆ่าจะอยู่ในแถบเพื่อเตือนคุณว่าทำไมเดสก์ท็อปจึงเงียบลง

อย่างไรก็ตาม ไม่มีอะไรสูญหายไป การแจ้งเตือนที่ถูกปิดเสียงจะถูกพักไว้: นำสองสามรายการล่าสุดกลับมาบนหน้าจอด้วย `Super + Shift + Alt + ,` ดู [การแจ้งเตือน](10-notices.md) สำหรับส่วนที่เหลือ

ข้อความสองชนิดยังผ่านเข้ามาได้: ข้อความแจ้งเตือนยืนยันของ Omarchy เองสำหรับสิ่งที่คุณเพิ่งทำ ("เปลี่ยนธีมแล้ว", "บันทึกภาพหน้าจอแล้ว") และการแจ้งเตือนวิกฤตที่ส่งจากบรรทัดคำสั่ง แอปแชทที่ทำเครื่องหมายทุกอย่างว่าวิกฤตเพื่อบังคับให้ตัวเองมาอยู่ตรงหน้าคุณไม่มีคุณสมบัตินั้น

### การไม่มีกิจกรรม

เชลล์ของ Omarchy เป็นเจ้าของพฤติกรรมเมื่อไม่มีกิจกรรม และการกำหนดเวลาอยู่ในบล็อก `idle` ระดับบนสุดใน `~/.config/omarchy/shell.json`:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

ตัวเลขทั้งสองเป็นวินาทีที่นับจากช่วงเวลาที่คุณเริ่มไม่มีกิจกรรม — ไม่ได้นับต่อจากกัน ดังนั้นด้วยค่าเริ่มต้น โปรแกรมรักษาหน้าจอจะขึ้นมาหลังจากสองนาทีครึ่ง และหน้าจอล็อกจะเข้ามาแทนที่ที่ห้านาที ไม่ว่าโปรแกรมรักษาหน้าจอจะทำงานหรือไม่ก็ตาม บันทึกไฟล์ แล้วเชลล์จะรับการกำหนดเวลาใหม่ไปใช้ทันที

หากคุณปิดโปรแกรมรักษาหน้าจอก่อนเส้นตายการล็อก นั่นนับเป็นกิจกรรม และการล็อกที่รอดำเนินการจะถูกยกเลิก คุณจะไม่ถูกล็อกออกเพียงเพราะเหลือบมองเครื่องของคุณ

เพื่อหยุดการล็อกเมื่อไม่มีกิจกรรมไปเลย `Super + Ctrl + I` — หรือ `omarchy toggle idle` — จะพลิกเปิดคงสถานะตื่น และตัวบ่งชี้ถ้วยกาแฟจะปรากฏในแถบ นั่นคือปุ่มที่ต้องกดก่อนการนำเสนอยาว ๆ หรือการสร้างที่คุณอยากเฝ้าดู กดมันอีกครั้งเพื่อกลับสู่ภาวะปกติ `omarchy toggle idle status` จะพิมพ์สถานะปัจจุบันเป็น JSON หากคุณต้องการมันจากสคริปต์

เรื่องนี้เกี่ยวกับการล็อกและโปรแกรมรักษาหน้าจอ ไม่ใช่พลังงาน การระงับการทำงานชั่วคราวและการจำศีลมีการตั้งค่าของตัวเองใน [การนอนหลับของระบบ](36-system-sleep.md)

### โปรแกรมรักษาหน้าจอ

โปรแกรมรักษาหน้าจอของ Omarchy คือศิลปะ ASCII ที่วิ่งผ่านเอฟเฟกต์ข้อความแบบสุ่ม หนึ่งอินสแตนซ์ต่อหนึ่งจอภาพ ปุ่มใด ๆ หรือการเคลื่อนไหวของเมาส์จะออกจากมัน

คุณเริ่มมันตามต้องการได้จาก _System > Screensaver_ (`Super + Esc`) ซึ่งบังคับให้มันขึ้นมาแม้ว่าคุณจะปิดโปรแกรมรักษาหน้าจอเมื่อไม่มีกิจกรรมไปแล้วก็ตาม ไม่มีปุ่มลัดผูกไว้กับมันโดยค่าเริ่มต้น

`omarchy toggle screensaver` คือสิ่งที่ปิดตัวที่ทำงานเมื่อไม่มีกิจกรรม หากคุณอยากไปตรงจากทำงานไปสู่ถูกล็อกมากกว่า ปุ่มใด ๆ, การคลิก, การเลื่อน หรือการเคลื่อนไหวของเมาส์จะปิดมัน

โลโก้ที่มันวาดเป็นของคุณที่จะเปลี่ยน ภายใต้ _Appearance > Branding > Screensaver_ อัปโหลด png หรือ svg แล้ว Omarchy จะแปลงมันเป็น ASCII ดู [การสร้างแบรนด์](41-branding.md)

### หน้าจอล็อก

`Super + Ctrl + L` ล็อกเครื่อง นั่นจะเรียกใช้หน้าจอล็อกจากเชลล์ของ Omarchy, ทำให้จอแสดงผลมืดลง, รีเซ็ตเค้าโครงแป้นพิมพ์ของคุณเป็นเค้าโครงแรกเพื่อให้คุณไม่พิมพ์รหัสผ่านในตัวอักษรที่ผิด และ — หากคุณเปิดมันทำงานอยู่ — ล็อก 1Password ระหว่างทางออก

หน้าจอล็อกใช้รหัสผ่าน และมันจะใช้ลายนิ้วมือด้วยเมื่อคุณตั้งค่าอันหนึ่งขึ้นมาแล้ว เรื่องนั้น และวิธีอื่น ๆ ในการยืนยันตัวตน ครอบคลุมอยู่ใน [การยืนยันตัวตนด้วยฮาร์ดแวร์](37-hardware-authentication.md)
