# การสลับเปิด/ปิด, การไม่มีกิจกรรม และโปรแกรมพักหน้าจอ

สิ่งหลายอย่างที่คุณเปลี่ยนในแต่ละวันไม่ใช่การตั้งค่าจริง ๆ มันเป็นโหมดที่คุณเปิดไว้สักชั่วโมงแล้วปิดอีกครั้ง: แสงกลางคืนขณะที่คุณทำงานดึก, โหมดห้ามรบกวนขณะที่คุณกำลังนำเสนอ, การคอยปลุกระบบไว้ขณะที่คุณกำลังดูอะไรบางอย่าง Omarchy เรียกสิ่งเหล่านี้ว่าท็อกเกิล และทั้งหมดทำงานแบบเดียวกัน — ปุ่มลัด, รายการในเมนู และคำสั่ง ทั้งหมดกดไปที่สวิตช์เดียวกัน

### เมนูท็อกเกิล

`Super + Ctrl + O` เปิด _Trigger > Toggle_ โดยตรง หรือคุณเดินไปจากเมนู Omarchy (`Super + Space`) ก็ได้ ทุกอย่างในรายการนั้นเป็นสวิตช์ที่คุณพลิกได้โดยไม่ต้องคิดว่าสถานะเก็บไว้ที่ไหน สวิตช์สำหรับลักษณะของเดสก์ท็อปอยู่ถัดจากนั้น ภายใต้ _Appearance_

จากเทอร์มินัล สวิตช์เดียวกันคือ `omarchy toggle <thing>` รัน `omarchy toggle` เพียงอย่างเดียวเพื่อดูทั้งกลุ่ม

| ท็อกเกิล | ปุ่มลัด | คำสั่ง |
| ------ | ------ | ------- |
| แสงกลางคืน | — | `omarchy toggle nightlight` |
| ปิดเสียงการแจ้งเตือน | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| คอยปลุกไว้ (ไม่มีการล็อกเมื่อไม่มีกิจกรรม) | `Super + Ctrl + I` | `omarchy toggle idle` |
| การบันทึกข้อมูลการขัดข้อง | — | `omarchy toggle crash-capture` |
| โปรแกรมพักหน้าจอ | — | `omarchy toggle screensaver` |
| การซิงค์ธีม [Herdr](https://herdr.dev) | — | `omarchy toggle theme sync` |
| แถบเมนู | `Super + Shift + Space` | `omarchy toggle bar` |
| ทัชแพด | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| หน้าจอสัมผัส | — | `omarchy toggle touchscreen` |
| Suspend | — | `omarchy toggle suspend` |
| Hybrid GPU | — | `omarchy toggle hybrid gpu` |

สวิตช์ทัชแพด, หน้าจอสัมผัส และ Hybrid GPU อยู่ภายใต้ _Trigger > Hardware_ (`Super + Ctrl + H`) แทนที่จะอยู่ภายใต้ Toggle เนื่องจากมันจะปรากฏเฉพาะเมื่อคุณมีฮาร์ดแวร์นั้นจริง ๆ เท่านั้น สวิตช์ทัชแพดและหน้าจอสัมผัสจะยังคงอยู่หลังการโหลด Hyprland ใหม่ — ชื่อของอุปกรณ์ที่ปิดใช้งานจะถูกบันทึกไว้ในไฟล์สถานะขนาดเล็กที่ Hyprland อ่านตอนเริ่มต้นระบบเพื่อปิดใช้งานมันอีกครั้ง

_Appearance_ เป็นที่เก็บแถบเมนูและอนิเมชัน พร้อมกับบางอย่างที่ไม่ใช่คำสั่ง `omarchy toggle` แต่ทำงานแบบเดียวกัน: เปอร์เซ็นต์แบตเตอรี่ในแถบ, เลย์เอาต์พื้นที่ทำงานเริ่มต้น และภายใต้ _Windows_, ช่องว่างระหว่างหน้าต่าง (`Super + Shift + Backspace`) และอัตราส่วนสี่เหลี่ยมจัตุรัสสำหรับ 1 หน้าต่าง (`Super + Ctrl + Backspace`)

เมื่อ Hyprland ไม่มี GPU ให้วาดภาพและเรนเดอร์ด้วย CPU แทน (llvmpipe) เช่น บน Mac ที่ GPU ยังไม่ได้รับการรองรับ, ในเครื่องเสมือนส่วนใหญ่ หรือเมื่อไดรเวอร์กราฟิกโหลดไม่สำเร็จ Omarchy จะปิดอนิเมชัน, การเบลอ และเงาสำหรับเซสชันนั้น และแจ้งให้คุณทราบหนึ่งครั้งด้วยการแจ้งเตือน _Appearance > Animations On_ จะนำสิ่งเหล่านั้นกลับมา และ Omarchy จะจดจำไว้สำหรับเซสชันต่อ ๆ ไปด้วย

ส่วนใหญ่เหล่านี้เป็นเพียงไฟล์แฟล็กภายใต้ `~/.local/state/omarchy/toggles/` หากคุณต้องการแยกเงื่อนไขตามหนึ่งในนั้นในสคริปต์ `omarchy-toggle-enabled` จะให้รหัสจบการทำงานแก่คุณแทนที่จะทำให้คุณต้องไปค้นหาเอง:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

แฟล็กเหล่านี้ตั้งชื่อตามสถานะปิด — `screensaver-off`, `suspend-off`, `bar-off` — ดังนั้นการมีอยู่ของมันหมายความว่าคุณลักษณะนั้นถูกปิดใช้งาน

### ตัวบ่งชี้ในแถบ

เมื่อโหมดเปิดอยู่ คุณจะเห็นสัญลักษณ์เล็ก ๆ ตรงกลางของแถบด้านบนถัดจากนาฬิกา นั่นคือวิดเจ็ตตัวบ่งชี้ และมันบรรจุการพิมพ์ตามคำบอก, การบันทึกหน้าจอ, การเตือนความจำที่รอดำเนินการ, แสงกลางคืน, โหมดห้ามรบกวน และการคอยปลุกไว้

ตัวบ่งชี้ที่ไม่ได้ใช้งานจะถูกซ่อนไว้ วางตัวชี้เมาส์ไว้ที่ใดก็ได้บนแถบ แล้วมันจะค่อย ๆ ปรากฏขึ้นแบบจาง ๆ เพื่อให้คุณคลิกตัวหนึ่งเพื่อเปิดมันได้โดยไม่ต้องรู้ปุ่มลัดของมัน การคลิกตัวที่ใช้งานอยู่จะปิดมันกลับ หากคุณอยากเห็นทั้งหมดตลอดเวลา ให้ตั้ง `alwaysShow` เป็น `true` บนรายการ `omarchy.indicators` ใน `~/.config/omarchy/shell.json` — ดู [แถบด้านบน](05-the-top-bar.md) สำหรับวิธีตั้งค่าวิดเจ็ตของแถบ

### แสงกลางคืน

แสงกลางคืนทำให้หน้าจออุ่นขึ้นเป็น 4000K และการสลับมันอีกครั้งจะทำให้กลับเป็น 6500K พลิกมันจากเมนูท็อกเกิล (`Super + Ctrl + O`) หรือด้วย `omarchy toggle nightlight` มันขับเคลื่อนโดย hyprsunset ซึ่งท็อกเกิลจะเริ่มให้คุณหากมันยังไม่ได้ทำงานอยู่

ตามค่าเริ่มต้น hyprsunset จะไม่ทำอะไรกับหน้าจอของคุณเลย `~/.config/hypr/hyprsunset.conf` มาพร้อมกับโปรไฟล์ identity อย่างแม่นยำเพื่อให้จอแสดงผลยังคงไม่ถูกแตะต้องจนกว่าคุณจะขอความอุ่น หากคุณอยากให้มันสลับตามนาฬิกา ให้แทนที่สิ่งนั้นด้วยโปรไฟล์ตามเวลา:

```
profile {
    time = 20:00
    temperature = 4000
}
```

จากนั้นเริ่ม hyprsunset ตอนเข้าสู่ระบบโดยการเพิ่ม `o.launch_on_start("hyprsunset")` ไปที่ `~/.config/hypr/autostart.lua` คู่ 4000K/6500K ที่ท็อกเกิลใช้เป็นค่าคงที่ ดังนั้นไฟล์กำหนดค่าคือที่ที่คุณต้องไปหากคุณต้องการอุณหภูมิอื่น

### โหมดห้ามรบกวน

`Super + Ctrl + Alt + ,` ปิดเสียงการแจ้งเตือน จะไม่มีป๊อปอัปแจ้งเตือนปรากฏขณะที่มันเปิดอยู่ และตัวบ่งชี้กระดิ่งที่ถูกขีดฆ่าจะอยู่ในแถบเพื่อเตือนคุณว่าทำไมเดสก์ท็อปจึงเงียบลง

อย่างไรก็ตาม ไม่มีอะไรสูญหายไป การแจ้งเตือนที่ถูกปิดเสียงจะถูกพักไว้: นำสองสามรายการล่าสุดกลับมาบนหน้าจอด้วย `Super + Shift + Alt + ,` ดู [ประกาศ](10-notices.md) สำหรับส่วนที่เหลือ

ข้อความสองชนิดยังคงทะลุเข้ามาได้: โทสต์ยืนยันของ Omarchy เองสำหรับสิ่งที่คุณเพิ่งทำ ("Theme changed", "Screenshot saved") และการแจ้งเตือนระดับวิกฤตที่ส่งจากบรรทัดคำสั่ง แอปแชทที่ทำเครื่องหมายทุกอย่างว่าวิกฤตเพื่อบังคับให้ตัวเองมาอยู่ตรงหน้าคุณนั้นไม่เข้าข่าย

### การไม่มีกิจกรรม

เชลล์ของ Omarchy เป็นเจ้าของพฤติกรรมเมื่อไม่มีกิจกรรม และช่วงเวลาต่าง ๆ เป็นบล็อก `idle` ระดับบนสุดใน `~/.config/omarchy/shell.json`:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

ตัวเลขทั้งสองเป็นวินาทีที่นับจากช่วงเวลาที่คุณเริ่มไม่มีกิจกรรม — ไม่ใช่นับต่อจากกัน ดังนั้นด้วยค่าเริ่มต้น โปรแกรมพักหน้าจอจะปรากฏหลังจากสองนาทีครึ่ง และหน้าจอล็อกจะเข้ามาแทนที่ที่ห้านาที ไม่ว่าโปรแกรมพักหน้าจอจะทำงานหรือไม่ก็ตาม บันทึกไฟล์แล้วเชลล์จะรับช่วงเวลาใหม่ไปใช้ทันที

หากคุณปิดโปรแกรมพักหน้าจอก่อนถึงกำหนดการล็อก นั่นนับเป็นกิจกรรม และการล็อกที่รอดำเนินการจะถูกยกเลิก คุณจะไม่ถูกล็อกออกเพราะแค่เหลือบมองเครื่องของคุณ

หากต้องการหยุดการล็อกเมื่อไม่มีกิจกรรมโดยสิ้นเชิง `Super + Ctrl + I` — หรือ `omarchy toggle idle` — จะเปิดการคอยปลุกไว้ และตัวบ่งชี้ถ้วยกาแฟจะปรากฏในแถบ นั่นคือปุ่มที่ต้องกดก่อนการนำเสนอที่ยาวนานหรือการบิลด์ที่คุณอยากเฝ้าดู กดมันอีกครั้งเพื่อกลับเป็นปกติ `omarchy toggle idle status` จะพิมพ์สถานะปัจจุบันเป็น JSON หากคุณต้องการมันจากสคริปต์

นี่เป็นเรื่องของการล็อกและโปรแกรมพักหน้าจอ ไม่ใช่เรื่องพลังงาน Suspend และการจำศีลมีการตั้งค่าของตัวเองใน [การหลับของระบบ](36-system-sleep.md)

### โปรแกรมพักหน้าจอ

โปรแกรมพักหน้าจอของ Omarchy เป็นงานศิลปะ ASCII ที่วิ่งผ่านเอฟเฟกต์ข้อความแบบสุ่ม หนึ่งอินสแตนซ์ต่อหนึ่งจอภาพ ปุ่มใด ๆ หรือการเคลื่อนไหวของเมาส์จะออกจากมัน

คุณสามารถเริ่มมันได้ตามต้องการจาก _System > Screensaver_ (`Super + Esc`) ซึ่งจะบังคับให้มันปรากฏแม้ว่าคุณจะปิดโปรแกรมพักหน้าจอเมื่อไม่มีกิจกรรมไว้ ไม่มีปุ่มลัดผูกไว้กับมันตามค่าเริ่มต้น

`omarchy toggle screensaver` คือสิ่งที่ปิดตัวเมื่อไม่มีกิจกรรม หากคุณอยากไปตรงจากทำงานไปสู่การล็อก ปุ่มใด ๆ, การคลิก, การเลื่อน หรือการเคลื่อนไหวของเมาส์จะปิดมัน

โลโก้ที่มันวาดเป็นของคุณที่จะเปลี่ยนได้ ภายใต้ _Appearance > Branding > Screensaver_ อัปโหลด png หรือ svg แล้ว Omarchy จะแปลงมันเป็น ASCII ดู [การสร้างแบรนด์](41-branding.md)

### หน้าจอล็อก

`Super + Ctrl + L` ล็อกเครื่อง นั่นจะรันหน้าจอล็อกจากเชลล์ของ Omarchy, ทำให้จอแสดงผลว่างเปล่า, รีเซ็ตเลย์เอาต์แป้นพิมพ์ของคุณเป็นอันแรกเพื่อที่คุณจะไม่พิมพ์รหัสผ่านในตัวอักษรที่ผิด และ — หากคุณเปิดมันทำงานอยู่ — จะล็อก 1Password ระหว่างทางออกไปด้วย

หน้าจอล็อกรับรหัสผ่าน และมันจะรับลายนิ้วมือด้วยเมื่อคุณตั้งค่าไว้แล้ว สิ่งนั้นและวิธีอื่น ๆ ในการยืนยันตัวตนครอบคลุมอยู่ใน [การยืนยันตัวตนด้วยฮาร์ดแวร์](37-hardware-authentication.md)
