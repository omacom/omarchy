# ตัวสลับ การไม่มีการใช้งาน และโปรแกรมพักหน้าจอ

สิ่งที่คุณเปลี่ยนอยู่ทุกวันจำนวนมากไม่ได้เป็นค่าตั้งค่าจริง ๆ แต่เป็นโหมดที่คุณเปิดไว้สักชั่วโมงแล้วปิดกลับคืน: แสงกลางคืนขณะที่คุณทำงานดึก ห้ามรบกวนขณะที่คุณกำลังนำเสนอ หรือการอยู่ตื่นตลอดเวลาขณะที่คุณกำลังดูอะไรบางอย่าง Omarchy เรียกสิ่งเหล่านั้นว่าตัวสลับ และพวกมันทั้งหมดทำงานในลักษณะเดียวกัน นั่นคือปุ่มลัด รายการในเมนู และคำสั่ง ล้วนกดสวิตช์ตัวเดียวกัน

### เมนูตัวสลับ

`Super + Ctrl + O` เปิด _Trigger > Toggle_ โดยตรง หรือคุณจะเดินไปที่นั่นจากเมนู Omarchy (`Super + Space`) ก็ได้ ทุกอย่างในรายการนั้นคือสวิตช์ที่คุณสลับได้โดยไม่ต้องคิดว่าสถานะของมันเก็บอยู่ที่ไหน สวิตช์สำหรับรูปลักษณ์ของเดสก์ท็อปจะอยู่ถัดจากนั้น ภายใต้ _Appearance_

จากเทอร์มินัล สวิตช์เดียวกันเหล่านั้นคือ `omarchy toggle <thing>` เรียกใช้ `omarchy toggle` โดยไม่มีอาร์กิวเมนต์เพื่อดูทั้งกลุ่ม

| ตัวสลับ | ปุ่มลัด | คำสั่ง |
| ------ | ------ | ------- |
| แสงกลางคืน | — | `omarchy toggle nightlight` |
| ปิดเสียงการแจ้งเตือน | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| อยู่ตื่นตลอดเวลา (ไม่ล็อคเมื่อไม่มีการใช้งาน) | `Super + Ctrl + I` | `omarchy toggle idle` |
| การบันทึกเมื่อเกิดข้อขัดข้อง | — | `omarchy toggle crash-capture` |
| โปรแกรมพักหน้าจอ | — | `omarchy toggle screensaver` |
| การซิงค์ธีม [Herdr](https://herdr.dev) | — | `omarchy toggle theme sync` |
| แถบเมนู | `Super + Shift + Space` | `omarchy toggle bar` |
| เดสก์ท็อปเต็มจอ (ไม่มีแถบ ไม่มีช่องว่าง) | `Super + Ctrl + Alt + F` | `omarchy toggle fullscreen desktop` |
| แอนิเมชัน การเบลอ และเงา | — | `omarchy toggle animations` |
| ทัชแพด | `XF86TouchpadToggle` | `omarchy device touchpad` |
| หน้าจอสัมผัส | — | `omarchy device touchscreen` |
| การระงับการทำงาน | — | `omarchy toggle suspend` |
| GPU แบบไฮบริด | — | `omarchy device gpu hybrid` |

สวิตช์ทัชแพด หน้าจอสัมผัส และ GPU แบบไฮบริดจะอยู่ภายใต้ _Trigger > Hardware_ (`Super + Ctrl + H`) แทนที่จะอยู่ภายใต้ Toggle เนื่องจากพวกมันจะปรากฏเฉพาะเมื่อคุณมีฮาร์ดแวร์นั้นจริง ๆ เท่านั้น สวิตช์ทัชแพดและหน้าจอสัมผัสจะยังคงอยู่หลังการโหลด Hyprland ใหม่ ชื่อของอุปกรณ์ที่ถูกปิดใช้งานจะถูกบันทึกไว้ในไฟล์สถานะขนาดเล็กที่ Hyprland อ่านตอนเริ่มต้นเพื่อปิดใช้งานมันอีกครั้ง

_Appearance_ มีแถบเมนูและแอนิเมชัน พร้อมกับอีกสองสามอย่างที่ไม่ใช่คำสั่ง `omarchy toggle` แต่ทำงานในลักษณะเดียวกัน ได้แก่ เปอร์เซ็นต์แบตเตอรี่ในแถบ เลย์เอาต์พื้นที่ทำงานเริ่มต้น และภายใต้ _Windows_ ช่องว่างของหน้าต่าง (`Super + Shift + Backspace`) และอัตราส่วนสี่เหลี่ยมจัตุรัสแบบ 1 หน้าต่าง (`Super + Ctrl + Backspace`)

เมื่อ Hyprland ไม่มี GPU ให้ใช้วาดและเรนเดอร์ด้วย CPU แทน (llvmpipe) เช่น บนเครื่อง Mac ที่ GPU ยังไม่ได้รับการรองรับ ในเครื่องเสมือนส่วนใหญ่ หรือเมื่อไดรเวอร์กราฟิกโหลดไม่สำเร็จ Omarchy จะปิดแอนิเมชัน การเบลอ และเงาสำหรับเซสชันนั้น และบอกคุณเพียงครั้งเดียวด้วยการแจ้งเตือน _Appearance > Animations On_ จะนำพวกมันกลับมา และ Omarchy จะจำการตั้งค่านั้นไว้สำหรับเซสชันในภายหลังด้วย

ส่วนใหญ่ของสิ่งเหล่านี้เป็นเพียงไฟล์แฟล็กภายใต้ `~/.local/state/omarchy/toggles/` หากคุณต้องการแยกเงื่อนไขตามหนึ่งในนั้นในสคริปต์ `omarchy-toggle-enabled` จะให้รหัสการออกแก่คุณแทนที่จะทำให้คุณต้องไปค้นหาเอง:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

แฟล็กเหล่านั้นตั้งชื่อตามสถานะปิด นั่นคือ `screensaver-off`, `suspend-off`, `bar-off` ดังนั้นการมีอยู่ของมันจึงหมายความว่าคุณสมบัตินั้นถูกปิดใช้งาน

### ตัวบ่งชี้ในแถบ

เมื่อโหมดใดโหมดหนึ่งเปิดอยู่ คุณจะเห็นสัญลักษณ์เล็ก ๆ ตรงกลางของแถบด้านบนถัดจากนาฬิกา นั่นคือวิดเจ็ตตัวบ่งชี้ และมันบรรจุการบันทึกหน้าจอ การเตือนความจำที่รอดำเนินการ แสงกลางคืน ห้ามรบกวน และการอยู่ตื่นตลอดเวลา พร้อมกับคำเตือนในขณะที่ sudo แบบไม่ใช้รหัสผ่านเปิดอยู่ หรือมีคนเชื่อมต่อเข้ามาในเซสชันระยะไกล

ตัวบ่งชี้ที่ไม่ได้ใช้งานจะถูกซ่อนไว้ เลื่อนเมาส์ไปที่ใดก็ได้บนแถบแล้วพวกมันจะค่อย ๆ ปรากฏขึ้นแบบจาง ๆ เพื่อให้คุณคลิกตัวหนึ่งเพื่อเปิดมันได้โดยไม่ต้องรู้ปุ่มลัดของมัน การคลิกตัวที่ใช้งานอยู่จะปิดมันกลับคืน หากคุณอยากเห็นพวกมันทั้งหมดตลอดเวลา ให้ตั้ง `alwaysShow` เป็น `true` บนรายการ `omarchy.indicators` ใน `~/.config/omarchy/shell.json` ดู [แถบด้านบน](05-the-top-bar.md) สำหรับวิธีการกำหนดค่าวิดเจ็ตของแถบ

### แสงกลางคืน

แสงกลางคืนทำให้หน้าจออุ่นขึ้นเป็น 4000K และการสลับมันอีกครั้งจะทำให้มันกลับไปเป็น 6500K สลับมันจากเมนูตัวสลับ (`Super + Ctrl + O`) หรือด้วย `omarchy toggle nightlight` มันถูกขับเคลื่อนโดย hyprsunset ซึ่งตัวสลับจะเริ่มต้นให้คุณหากมันยังไม่ได้ทำงานอยู่

โดยค่าเริ่มต้น hyprsunset จะไม่ทำอะไรกับหน้าจอของคุณเลย `~/.config/hypr/hyprsunset.conf` มาพร้อมกับโปรไฟล์ระบุตัวตนอย่างแม่นยำเพื่อให้จอแสดงผลยังคงไม่ถูกแตะต้องจนกว่าคุณจะขอความอบอุ่น หากคุณอยากให้มันสลับตามนาฬิกามากกว่า ให้แทนที่สิ่งนั้นด้วยโปรไฟล์เวลา:

```
profile {
    time = 20:00
    temperature = 4000
}
```

จากนั้นเริ่มต้น hyprsunset ตอนเข้าสู่ระบบโดยการเพิ่ม `o.launch_on_start("hyprsunset")` ไปยัง `~/.config/hypr/autostart.lua` คู่ 4000K/6500K ที่ตัวสลับใช้ถูกกำหนดตายตัว ดังนั้นไฟล์การกำหนดค่าคือที่ที่คุณไปหากคุณต้องการอุณหภูมิที่แตกต่างออกไป

### ห้ามรบกวน

`Super + Ctrl + Alt + ,` ปิดเสียงการแจ้งเตือน จะไม่มีข้อความแจ้งเตือนแบบป๊อปอัปปรากฏขึ้นขณะที่มันเปิดอยู่ และตัวบ่งชี้กระดิ่งที่ถูกขีดฆ่าจะอยู่ในแถบเพื่อเตือนคุณว่าทำไมเดสก์ท็อปจึงเงียบลง

อย่างไรก็ตาม ไม่มีอะไรสูญหาย การแจ้งเตือนที่ถูกปิดเสียงจะถูกระงับไว้: นำสองสามรายการล่าสุดกลับมาบนหน้าจอด้วย `Super + Shift + Alt + ,` ดู [การแจ้งเตือน](10-notices.md) สำหรับส่วนที่เหลือ

ข้อความสามประเภทยังคงผ่านเข้ามาได้: ข้อความยืนยันของ Omarchy เองสำหรับสิ่งที่คุณเพิ่งทำ ("เปลี่ยนธีมแล้ว", "บันทึกภาพหน้าจอแล้ว") การแจ้งเตือนสำคัญที่ส่งจากบรรทัดคำสั่ง และรหัสยืนยัน แอปแชทที่ทำเครื่องหมายทุกอย่างว่าสำคัญเพื่อบังคับให้ตัวเองมาอยู่ตรงหน้าคุณนั้นไม่เข้าข่าย

### การไม่มีการใช้งาน

เชลล์ของ Omarchy เป็นเจ้าของพฤติกรรมเมื่อไม่มีการใช้งาน และระยะเวลาต่าง ๆ คือบล็อก `idle` ระดับบนสุดใน `~/.config/omarchy/shell.json`:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

ตัวเลขทั้งสองคือวินาทีที่นับจากช่วงเวลาที่คุณหยุดใช้งาน ไม่ได้นับต่อจากกัน ดังนั้นด้วยค่าเริ่มต้น โปรแกรมพักหน้าจอจะปรากฏขึ้นหลังจากสองนาทีครึ่ง และหน้าจอล็อคจะเข้าควบคุมที่ห้านาที ไม่ว่าโปรแกรมพักหน้าจอจะทำงานหรือไม่ก็ตาม บันทึกไฟล์แล้วเชลล์จะรับระยะเวลาใหม่ไปใช้ทันที

หากคุณปิดโปรแกรมพักหน้าจอก่อนถึงกำหนดเวลาล็อค นั่นจะนับเป็นกิจกรรมและการล็อคที่รอดำเนินการจะถูกยกเลิก คุณจะไม่ถูกล็อคออกเพียงเพราะเหลือบมองเครื่องของคุณ

หากต้องการหยุดการล็อคเมื่อไม่มีการใช้งานโดยสิ้นเชิง `Super + Ctrl + I` หรือ `omarchy toggle idle` จะสลับการอยู่ตื่นตลอดเวลาให้เปิดอยู่ และตัวบ่งชี้ถ้วยกาแฟจะปรากฏขึ้นในแถบ นั่นคือตัวที่ต้องกดก่อนการนำเสนอที่ยาวนานหรือการสร้างที่คุณต้องการเฝ้าดู กดมันอีกครั้งเพื่อกลับสู่ภาวะปกติ `omarchy toggle idle status` จะพิมพ์สถานะปัจจุบันเป็น JSON หากคุณต้องการมันจากสคริปต์

เรื่องนี้เกี่ยวกับการล็อคและโปรแกรมพักหน้าจอ ไม่ใช่พลังงาน การระงับการทำงานและการจำศีลมีการตั้งค่าของตัวเองใน [โหมดสลีปของระบบ](36-system-sleep.md)

### โปรแกรมพักหน้าจอ

โปรแกรมพักหน้าจอของ Omarchy คือศิลปะ ASCII ที่ทำงานผ่านเอฟเฟกต์ข้อความแบบสุ่ม หนึ่งอินสแตนซ์ต่อหนึ่งจอภาพ การกดปุ่มใด ๆ หรือการเคลื่อนไหวของเมาส์จะออกจากมัน

คุณสามารถเริ่มมันได้ตามต้องการจาก _System > Screensaver_ (`Super + Esc`) ซึ่งบังคับให้มันปรากฏขึ้นแม้ว่าคุณจะปิดโปรแกรมพักหน้าจอเมื่อไม่มีการใช้งานไว้แล้วก็ตาม โดยค่าเริ่มต้นจะไม่มีปุ่มลัดผูกไว้กับมัน

`omarchy toggle screensaver` คือสิ่งที่ปิดตัวเมื่อไม่มีการใช้งาน หากคุณอยากไปตรงจากทำงานสู่ถูกล็อคมากกว่า การกดปุ่ม การคลิก การเลื่อน หรือการเคลื่อนไหวของเมาส์ใด ๆ จะปิดมัน

โลโก้ที่มันวาดเป็นของคุณที่จะเปลี่ยน ภายใต้ _Appearance > Branding > Screensaver_ อัปโหลด png หรือ svg แล้ว Omarchy จะแปลงมันเป็น ASCII ดู [แบรนด์](41-branding.md)

### หน้าจอล็อค

`Super + Ctrl + L` ล็อคเครื่อง นั่นจะเรียกใช้หน้าจอล็อคจากเชลล์ของ Omarchy ทำให้จอแสดงผลว่างเปล่า รีเซ็ตเลย์เอาต์แป้นพิมพ์ของคุณเป็นเลย์เอาต์แรก เพื่อให้คุณไม่พิมพ์รหัสผ่านของคุณในตัวอักษรที่ผิด และหากคุณมีมันทำงานอยู่ จะล็อค 1Password ระหว่างทางออก

หน้าจอล็อครับรหัสผ่าน และมันจะรับลายนิ้วมือด้วยเมื่อคุณได้ตั้งค่าอันหนึ่งไว้แล้ว เรื่องนั้น และวิธีอื่น ๆ ในการยืนยันตัวตน ได้รับการกล่าวถึงใน [การยืนยันตัวตนด้วยฮาร์ดแวร์](37-hardware-authentication.md)
