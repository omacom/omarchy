# สวิตช์, การไม่ได้ใช้งาน และภาพพักหน้าจอ

สิ่งที่คุณเปลี่ยนในแต่ละวันจำนวนมากไม่ได้เป็นค่าตั้งจริง ๆ มันเป็นโหมดที่คุณเปิดไว้สักชั่วโมงแล้วปิดกลับ: แสงอุ่นกลางคืนขณะทำงานดึก, ห้ามรบกวนขณะนำเสนอ, ไม่พักเครื่องขณะกำลังดูอะไรอยู่ Omarchy เรียกสิ่งเหล่านี้ว่าสวิตช์ และทั้งหมดทำงานแบบเดียวกัน — ปุ่มลัด, รายการในเมนู และคำสั่ง ล้วนกดสวิตช์ตัวเดียวกัน

### เมนูสวิตช์

`Super + Ctrl + O` เปิด _Trigger > Toggle_ โดยตรง หรือจะเดินไปจากเมนู Omarchy (`Super + Space`) ก็ได้ ทุกอย่างในรายการนั้นเป็นสวิตช์ที่คุณพลิกได้โดยไม่ต้องคิดว่าสถานะเก็บอยู่ที่ไหน สวิตช์สำหรับรูปลักษณ์ของเดสก์ท็อปอยู่ข้าง ๆ กัน ใต้ _Appearance_

จากเทอร์มินัล สวิตช์เดียวกันคือ `omarchy toggle <thing>` รัน `omarchy toggle` อย่างเดียวเพื่อดูทั้งกลุ่ม

| สวิตช์ | ปุ่มลัด | คำสั่ง |
| ------ | ------ | ------- |
| แสงอุ่นกลางคืน | — | `omarchy toggle nightlight` |
| ปิดเสียงการแจ้งเตือน | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| ไม่พักเครื่อง (ไม่ล็อกเมื่อไม่ได้ใช้งาน) | `Super + Ctrl + I` | `omarchy toggle idle` |
| การบันทึกข้อมูลเมื่อโปรแกรมล่ม | — | `omarchy toggle crash-capture` |
| ภาพพักหน้าจอ | — | `omarchy toggle screensaver` |
| การซิงก์ธีม [Herdr](https://herdr.dev) | — | `omarchy toggle theme sync` |
| แถบเมนู | `Super + Shift + Space` | `omarchy toggle bar` |
| ทัชแพด | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| หน้าจอสัมผัส | — | `omarchy toggle touchscreen` |
| พักเครื่อง | — | `omarchy toggle suspend` |
| Hybrid GPU | — | `omarchy toggle hybrid gpu` |

สวิตช์ทัชแพด, หน้าจอสัมผัส และ Hybrid GPU อยู่ใต้ _Trigger > Hardware_ (`Super + Ctrl + H`) แทนที่จะอยู่ใต้ Toggle เพราะจะแสดงเฉพาะเมื่อคุณมีฮาร์ดแวร์นั้นจริง ๆ สวิตช์ทัชแพดและหน้าจอสัมผัสจะคงอยู่หลัง Hyprland โหลดใหม่ — ชื่อของอุปกรณ์ที่ปิดไว้จะถูกบันทึกไว้ในไฟล์สถานะขนาดเล็กที่ Hyprland อ่านตอนเริ่มต้นเพื่อปิดมันอีกครั้ง

_Appearance_ มีแถบเมนูและภาพเคลื่อนไหว รวมทั้งอีกสองสามอย่างที่ไม่ใช่คำสั่ง `omarchy toggle` แต่ทำงานแบบเดียวกัน: เปอร์เซ็นต์แบตเตอรี่ในแถบ, เลย์เอาต์พื้นที่ทำงานเริ่มต้น และใต้ _Windows_ คือช่องว่างระหว่างหน้าต่าง (`Super + Shift + Backspace`) และสัดส่วนสี่เหลี่ยมจัตุรัสสำหรับ 1 หน้าต่าง (`Super + Ctrl + Backspace`)

ส่วนใหญ่เป็นแค่ไฟล์ธงใต้ `~/.local/state/omarchy/toggles/` ถ้าต้องการแยกเงื่อนไขตามสวิตช์ตัวใดตัวหนึ่งในสคริปต์ `omarchy-toggle-enabled` จะให้รหัสออกแทนที่จะให้คุณไปค้นหาเอง:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

ธงต่าง ๆ ตั้งชื่อตามสถานะปิด — `screensaver-off`, `suspend-off`, `bar-off` — ดังนั้นการมีอยู่ของมันหมายความว่าฟีเจอร์นั้นถูกปิดอยู่

### ตัวบ่งชี้ในแถบ

เมื่อโหมดใดเปิดอยู่ คุณจะเห็นสัญลักษณ์เล็ก ๆ ตรงกลางแถบบนถัดจากนาฬิกา นั่นคือวิดเจ็ตตัวบ่งชี้ และมันมีทั้งการพิมพ์ด้วยเสียง, การบันทึกหน้าจอ, การเตือนที่รอดำเนินการ, แสงอุ่นกลางคืน, ห้ามรบกวน และไม่พักเครื่อง

ตัวบ่งชี้ที่ไม่ได้ใช้งานจะถูกซ่อนไว้ เลื่อนเมาส์ไปวางที่ใดก็ได้บนแถบแล้วพวกมันจะค่อย ๆ ปรากฏแบบจาง ๆ เพื่อให้คุณคลิกตัวใดตัวหนึ่งเพื่อเปิดได้โดยไม่ต้องรู้ปุ่มลัด การคลิกตัวที่ใช้งานอยู่จะปิดมันกลับ หากอยากเห็นทั้งหมดตลอดเวลา ให้ตั้ง `alwaysShow` เป็น `true` ในรายการ `omarchy.indicators` ใน `~/.config/omarchy/shell.json` — ดู [แถบบน](05-the-top-bar.md) สำหรับวิธีตั้งค่าวิดเจ็ตของแถบ

### แสงอุ่นกลางคืน

แสงอุ่นกลางคืนทำให้หน้าจออุ่นขึ้นเป็น 4000K และสลับอีกครั้งจะกลับไปเป็น 6500K พลิกได้จากเมนูสวิตช์ (`Super + Ctrl + O`) หรือด้วย `omarchy toggle nightlight` มันขับเคลื่อนโดย hyprsunset ซึ่งสวิตช์จะเริ่มให้หากยังไม่ได้ทำงานอยู่

โดยค่าเริ่มต้น hyprsunset จะไม่ทำอะไรกับหน้าจอของคุณเลย `~/.config/hypr/hyprsunset.conf` มาพร้อมโปรไฟล์ identity อย่างแม่นยำเพื่อให้จอแสดงผลไม่ถูกแตะต้องจนกว่าคุณจะขอความอุ่น หากอยากให้มันสลับตามนาฬิกา ให้แทนที่ด้วยโปรไฟล์เวลา:

```
profile {
    time = 20:00
    temperature = 4000
}
```

จากนั้นเริ่ม hyprsunset ตอนเข้าสู่ระบบโดยเพิ่ม `o.launch_on_start("hyprsunset")` ไปที่ `~/.config/hypr/autostart.lua` คู่ 4000K/6500K ที่สวิตช์ใช้เป็นค่าตายตัว ดังนั้นไฟล์ตั้งค่าคือที่ที่คุณไปหากต้องการอุณหภูมิอื่น

### ห้ามรบกวน

`Super + Ctrl + Alt + ,` ปิดเสียงการแจ้งเตือน จะไม่มีป๊อปอัปโผล่ขึ้นมาขณะเปิดอยู่ และตัวบ่งชี้ระฆังที่ขีดฆ่าจะอยู่ในแถบเพื่อเตือนคุณว่าทำไมเดสก์ท็อปถึงเงียบลง

แต่ไม่มีอะไรสูญหาย การแจ้งเตือนที่ปิดเสียงไว้จะถูกพักไว้: นำสองสามรายการล่าสุดกลับมาบนหน้าจอด้วย `Super + Shift + Alt + ,` ดู [การแจ้งเตือน](10-notices.md) สำหรับส่วนที่เหลือ

ข้อความสองชนิดยังทะลุผ่านได้: ข้อความยืนยันของ Omarchy เองสำหรับสิ่งที่คุณเพิ่งทำ ("Theme changed", "Screenshot saved") และการแจ้งเตือนวิกฤตที่ส่งจากบรรทัดคำสั่ง แอปแชทที่ทำเครื่องหมายทุกอย่างเป็นวิกฤตเพื่อบังคับให้ตัวเองมาอยู่ตรงหน้าคุณนั้นไม่เข้าข่าย

### การไม่ได้ใช้งาน

เชลล์ของ Omarchy เป็นเจ้าของพฤติกรรมเมื่อไม่ได้ใช้งาน และเวลาต่าง ๆ เป็นบล็อก `idle` ระดับบนสุดใน `~/.config/omarchy/shell.json`:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

ตัวเลขทั้งสองเป็นวินาทีนับจากช่วงเวลาที่คุณเริ่มไม่ได้ใช้งาน — ไม่ได้นับต่อจากกัน ดังนั้นด้วยค่าเริ่มต้น ภาพพักหน้าจอจะขึ้นมาหลังสองนาทีครึ่ง และหน้าจอล็อกจะเข้าควบคุมที่ห้านาที ไม่ว่าภาพพักหน้าจอจะทำงานหรือไม่ก็ตาม บันทึกไฟล์แล้วเชลล์จะรับเวลาใหม่ไปใช้ทันที

หากคุณปิดภาพพักหน้าจอก่อนถึงกำหนดล็อก นั่นนับเป็นกิจกรรมและการล็อกที่รออยู่จะถูกยกเลิก คุณจะไม่ถูกล็อกออกเพียงเพราะเหลือบมองเครื่องของคุณ

หากต้องการหยุดการล็อกเมื่อไม่ได้ใช้งานทั้งหมด `Super + Ctrl + I` — หรือ `omarchy toggle idle` — จะเปิดโหมดไม่พักเครื่อง และตัวบ่งชี้ถ้วยกาแฟจะปรากฏในแถบ นั่นคือตัวที่ต้องกดก่อนการนำเสนอยาว ๆ หรือก่อนงานสร้างที่คุณอยากเฝ้าดู กดอีกครั้งเพื่อกลับสู่ปกติ `omarchy toggle idle status` จะพิมพ์สถานะปัจจุบันเป็น JSON หากคุณต้องการใช้จากสคริปต์

นี่เป็นเรื่องการล็อกและภาพพักหน้าจอ ไม่ใช่เรื่องพลังงาน การพักเครื่องและการจำศีลมีการตั้งค่าของตัวเองใน [การหลับของระบบ](36-system-sleep.md)

### ภาพพักหน้าจอ

ภาพพักหน้าจอของ Omarchy เป็นศิลปะ ASCII ที่วิ่งผ่านเอฟเฟกต์ข้อความแบบสุ่ม หนึ่งอินสแตนซ์ต่อหนึ่งจอภาพ การกดแป้นใด ๆ หรือการเคลื่อนเมาส์จะออกจากมัน

คุณเริ่มมันตามต้องการได้จาก _System > Screensaver_ (`Super + Esc`) ซึ่งจะบังคับให้มันขึ้นมาแม้คุณจะปิดภาพพักหน้าจอเมื่อไม่ได้ใช้งานไว้ ไม่มีปุ่มลัดผูกไว้ให้โดยค่าเริ่มต้น

`omarchy toggle screensaver` คือสิ่งที่ปิดตัวเมื่อไม่ได้ใช้งาน หากคุณอยากไปจากทำงานตรงไปล็อกเลย มันต้องการเทอร์มินัลที่มันรู้วิธีตั้งค่า — Alacritty, Foot, Ghostty หรือ Kitty — และจะบอกคุณเช่นนั้นหากเทอร์มินัลเริ่มต้นของคุณเป็นอย่างอื่น

โลโก้ที่มันวาดเป็นของคุณที่จะเปลี่ยนได้ ใต้ _Appearance > Branding > Screensaver_ อัปโหลด png หรือ svg แล้ว Omarchy จะแปลงเป็น ASCII ดู [การสร้างแบรนด์](41-branding.md)

### หน้าจอล็อก

`Super + Ctrl + L` ล็อกเครื่อง นั่นจะเรียกใช้หน้าจอล็อกจากเชลล์ของ Omarchy, ทำให้จอแสดงผลว่าง, รีเซ็ตเลย์เอาต์แป้นพิมพ์ของคุณกลับไปเป็นอันแรกเพื่อที่คุณจะไม่พิมพ์รหัสผ่านด้วยตัวอักษรผิดชุด และ — หากคุณเปิดมันไว้ — จะล็อก 1Password ระหว่างทางออก

หน้าจอล็อกใช้รหัสผ่าน และจะใช้ลายนิ้วมือด้วยเมื่อคุณตั้งค่าไว้แล้ว เรื่องนั้น และวิธีอื่น ๆ ในการยืนยันตัวตน มีอธิบายไว้ใน [การยืนยันตัวตนด้วยฮาร์ดแวร์](37-hardware-authentication.md)
