# ตัวสลับ การพักเครื่อง และสกรีนเซฟเวอร์

สิ่งที่คุณเปลี่ยนอยู่เป็นประจำจำนวนมากไม่ใช่การตั้งค่าจริง ๆ มันคือโหมดที่คุณเปิดไว้สักชั่วโมงแล้วปิดทีหลัง: แสงโทนอุ่นกลางคืนเวลาทำงานดึก ห้ามรบกวนเวลากำลังนำเสนอ หรือค้างจอไว้เวลากำลังดูอะไรอยู่ Omarchy เรียกสิ่งเหล่านี้ว่าตัวสลับ และทุกตัวทำงานแบบเดียวกันหมด — ปุ่มลัด รายการในเมนู และคำสั่ง ล้วนกดสวิตช์ตัวเดียวกัน

### เมนูตัวสลับ

`Super + Ctrl + O` เปิด _เรียกใช้ > ตัวสลับ_ โดยตรง หรือจะเดินไปจากเมนู Omarchy (`Super + Space`) ก็ได้ ทุกอย่างในรายการนั้นคือสวิตช์ที่คุณพลิกได้โดยไม่ต้องคิดว่าสถานะเก็บอยู่ที่ไหน สวิตช์สำหรับรูปลักษณ์ของเดสก์ท็อปอยู่ถัดจากนั้น ใต้ _ลักษณะที่ปรากฏ_

จากเทอร์มินัล สวิตช์เดียวกันเหล่านั้นคือ `omarchy toggle <thing>` เรียก `omarchy toggle` อย่างเดียวเพื่อดูทั้งกลุ่ม

| ตัวสลับ | ปุ่มลัด | คำสั่ง |
| ------ | ------ | ------- |
| แสงกลางคืน | — | `omarchy toggle nightlight` |
| เงียบการแจ้งเตือน | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| ค้างจอไว้ (ไม่ล็อกเมื่อพักเครื่อง) | `Super + Ctrl + I` | `omarchy toggle idle` |
| การเก็บข้อมูลเมื่อเกิดการขัดข้อง | — | `omarchy toggle crash-capture` |
| สกรีนเซฟเวอร์ | — | `omarchy toggle screensaver` |
| การซิงค์ธีม [Herdr](https://herdr.dev) | — | `omarchy toggle theme sync` |
| แถบเมนู | `Super + Shift + Space` | `omarchy toggle bar` |
| ทัชแพด | `XF86TouchpadToggle` | `omarchy device touchpad` |
| หน้าจอสัมผัส | — | `omarchy device touchscreen` |
| พักการทำงาน | — | `omarchy toggle suspend` |
| GPU แบบไฮบริด | — | `omarchy toggle hybrid gpu` |

สวิตช์ทัชแพด หน้าจอสัมผัส และ GPU แบบไฮบริดอยู่ใต้ _เรียกใช้ > ฮาร์ดแวร์_ (`Super + Ctrl + H`) ไม่ได้อยู่ใต้ตัวสลับ เพราะมันจะแสดงขึ้นมาก็ต่อเมื่อคุณมีฮาร์ดแวร์นั้นจริง ๆ เท่านั้น สวิตช์ทัชแพดและหน้าจอสัมผัสจะยังคงอยู่หลัง Hyprland โหลดใหม่ — ชื่อของอุปกรณ์ที่ถูกปิดไว้จะถูกบันทึกไว้ในไฟล์สถานะขนาดเล็กที่ Hyprland อ่านตอนเริ่มต้นเพื่อปิดมันอีกครั้ง

_ลักษณะที่ปรากฏ_ เก็บแถบเมนูและภาพเคลื่อนไหวไว้ พร้อมกับอีกสองสามอย่างที่ไม่ใช่คำสั่ง `omarchy toggle` แต่ทำงานเหมือนกัน: เปอร์เซ็นต์แบตเตอรี่ในแถบ การจัดวางพื้นที่ทำงานเริ่มต้น และใต้ _หน้าต่าง_ คือช่องว่างระหว่างหน้าต่าง (`Super + Shift + Backspace`) และอัตราส่วนจัตุรัสแบบ 1 หน้าต่าง (`Super + Ctrl + Backspace`)

เมื่อ Hyprland ไม่มี GPU ให้วาดด้วยและเรนเดอร์ด้วย CPU แทน (llvmpipe) อย่างบน Mac ที่ GPU ยังไม่ได้รับการรองรับ ในเครื่องเสมือนส่วนใหญ่ หรือเมื่อไดรเวอร์กราฟิกโหลดไม่สำเร็จ Omarchy จะปิดภาพเคลื่อนไหว การเบลอ และเงาในเซสชันนั้น และบอกคุณครั้งเดียวด้วยการแจ้งเตือน _ลักษณะที่ปรากฏ > เปิดภาพเคลื่อนไหว_ จะนำทุกอย่างกลับมา และ Omarchy จะจำการตั้งค่านั้นไว้สำหรับเซสชันถัด ๆ ไปด้วย

ส่วนใหญ่แล้ว สิ่งเหล่านี้เป็นแค่ไฟล์ธงใต้ `~/.local/state/omarchy/toggles/` หากคุณต้องการแยกเงื่อนไขตามหนึ่งในนั้นในสคริปต์ `omarchy-toggle-enabled` จะให้รหัสออกกับคุณแทนที่จะทำให้คุณต้องไปค้นหาเอง:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

ธงเหล่านั้นตั้งชื่อตามสถานะปิด — `screensaver-off`, `suspend-off`, `bar-off` — เพราะฉะนั้นการมีอยู่ของมันหมายความว่าคุณสมบัตินั้นถูกปิดอยู่

### ตัวบ่งชี้ในแถบ

เมื่อโหมดหนึ่งเปิดอยู่ คุณจะเห็นสัญลักษณ์เล็ก ๆ ตรงกลางแถบด้านบนถัดจากนาฬิกา นั่นคือวิดเจ็ตตัวบ่งชี้ และมันแสดงการพิมพ์ด้วยเสียง การบันทึกหน้าจอ การเตือนความจำที่รอดำเนินการ แสงกลางคืน ห้ามรบกวน และค้างจอไว้

ตัวบ่งชี้ที่ไม่ได้ใช้งานจะถูกซ่อนไว้ เลื่อนเมาส์ไปวางที่ใดก็ได้บนแถบแล้วมันจะค่อย ๆ ปรากฏแบบจาง ๆ เพื่อให้คุณคลิกหนึ่งตัวเพื่อเปิดมันได้โดยไม่ต้องรู้ปุ่มลัด การคลิกตัวที่ใช้งานอยู่จะปิดมันกลับ หากคุณอยากเห็นทั้งหมดตลอดเวลา ให้ตั้ง `alwaysShow` เป็น `true` บนรายการ `omarchy.indicators` ใน `~/.config/omarchy/shell.json` — ดู [แถบด้านบน](05-the-top-bar.md) สำหรับวิธีตั้งค่าวิดเจ็ตแถบ

### แสงกลางคืน

แสงกลางคืนทำให้หน้าจออุ่นขึ้นเป็น 4000K และสลับอีกครั้งจะทำให้กลับไปเป็น 6500K พลิกมันจากเมนูตัวสลับ (`Super + Ctrl + O`) หรือด้วย `omarchy toggle nightlight` มันขับเคลื่อนโดย hyprsunset ซึ่งตัวสลับจะเริ่มให้คุณหากมันยังไม่ได้ทำงานอยู่

โดยค่าเริ่มต้น hyprsunset ไม่ทำอะไรกับหน้าจอของคุณเลย `~/.config/hypr/hyprsunset.conf` มาพร้อมโปรไฟล์แบบคงสภาพเดิมโดยเฉพาะ เพื่อให้จอแสดงผลยังคงไม่ถูกแตะต้องจนกว่าคุณจะขอความอุ่น หากคุณอยากให้มันสลับตามนาฬิกาแทน ให้แทนที่ด้วยโปรไฟล์ตามเวลา:

```
profile {
    time = 20:00
    temperature = 4000
}
```

จากนั้นเริ่ม hyprsunset ตอนเข้าสู่ระบบโดยเพิ่ม `o.launch_on_start("hyprsunset")` ไปที่ `~/.config/hypr/autostart.lua` คู่ 4000K/6500K ที่ตัวสลับใช้ถูกกำหนดตายตัวไว้ เพราะฉะนั้นไฟล์กำหนดค่าคือที่ที่คุณต้องไปหากต้องการอุณหภูมิอื่น

### ห้ามรบกวน

`Super + Ctrl + Alt + ,` ทำให้การแจ้งเตือนเงียบลง จะไม่มีหน้าต่างแจ้งเตือนเด้งขึ้นมาขณะที่มันเปิดอยู่ และตัวบ่งชี้ระฆังที่ขีดฆ่าจะอยู่ในแถบเพื่อเตือนคุณว่าทำไมเดสก์ท็อปถึงเงียบไป

แต่ไม่มีอะไรสูญหาย การแจ้งเตือนที่ถูกเงียบไว้จะถูกพักไว้: นำสองสามรายการล่าสุดกลับมาบนหน้าจอด้วย `Super + Shift + Alt + ,` ดู [ข้อความแจ้งเตือน](10-notices.md) สำหรับส่วนที่เหลือ

ข้อความสองชนิดยังคงผ่านเข้ามาได้: ข้อความแจ้งเตือนยืนยันของ Omarchy เองสำหรับสิ่งที่คุณเพิ่งทำ ("Theme changed", "Screenshot saved") และการแจ้งเตือนวิกฤตที่ส่งจากบรรทัดคำสั่ง แอปแชตที่ตั้งทุกอย่างเป็นวิกฤตเพื่อบังคับให้โผล่มาตรงหน้าคุณไม่เข้าข่ายนี้

### การพักเครื่อง

เชลล์ของ Omarchy เป็นเจ้าของพฤติกรรมการพักเครื่อง และเวลาต่าง ๆ คือบล็อก `idle` ระดับบนสุดใน `~/.config/omarchy/shell.json`:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

ตัวเลขทั้งสองคือวินาทีนับจากช่วงเวลาที่คุณเริ่มพักเครื่อง — ไม่ได้ต่อจากกัน เพราะฉะนั้นด้วยค่าเริ่มต้น สกรีนเซฟเวอร์จะขึ้นมาหลังจากสองนาทีครึ่ง และหน้าจอล็อกจะเข้ามาแทนที่ที่ห้านาที ไม่ว่าสกรีนเซฟเวอร์จะทำงานหรือไม่ก็ตาม บันทึกไฟล์แล้วเชลล์จะรับเวลาใหม่ไปใช้ทันที

หากคุณปิดสกรีนเซฟเวอร์ก่อนถึงกำหนดล็อก นั่นนับเป็นกิจกรรมและการล็อกที่รออยู่จะถูกยกเลิก คุณจะไม่ถูกล็อกจากการแค่เหลือบมองเครื่องของคุณ

หากต้องการหยุดการล็อกเมื่อพักเครื่องไปเลย `Super + Ctrl + I` — หรือ `omarchy toggle idle` — จะเปิดค้างจอไว้ และตัวบ่งชี้ถ้วยกาแฟจะปรากฏในแถบ นั่นคือปุ่มที่ต้องกดก่อนการนำเสนอยาว ๆ หรือการสร้างที่คุณอยากเฝ้าดู กดอีกครั้งเพื่อกลับสู่ภาวะปกติ `omarchy toggle idle status` จะพิมพ์สถานะปัจจุบันเป็น JSON หากคุณต้องการมันจากสคริปต์

เรื่องนี้เกี่ยวกับการล็อกและสกรีนเซฟเวอร์ ไม่ใช่พลังงาน การพักการทำงานและการจำศีลมีการตั้งค่าของตัวเองใน [การพักระบบ](36-system-sleep.md)

### สกรีนเซฟเวอร์

สกรีนเซฟเวอร์ของ Omarchy คือศิลปะ ASCII ที่ทำงานผ่านเอฟเฟกต์ข้อความแบบสุ่ม หนึ่งอินสแตนซ์ต่อหนึ่งจอภาพ ปุ่มใด ๆ หรือการเคลื่อนไหวของเมาส์จะออกจากมัน

คุณเริ่มมันตามต้องการได้จาก _ระบบ > สกรีนเซฟเวอร์_ (`Super + Esc`) ซึ่งบังคับให้มันขึ้นมาแม้ว่าคุณจะปิดสกรีนเซฟเวอร์เมื่อพักเครื่องไว้ โดยค่าเริ่มต้นไม่มีปุ่มลัดผูกไว้กับมัน

`omarchy toggle screensaver` คือสิ่งที่ปิดตัวเมื่อพักเครื่อง หากคุณอยากไปตรงจากทำงานสู่ถูกล็อกเลย ปุ่มใด ๆ การคลิก การเลื่อน หรือการเคลื่อนไหวของเมาส์จะปิดมัน

โลโก้ที่มันวาดเป็นของคุณที่จะเปลี่ยน ใต้ _ลักษณะที่ปรากฏ > แบรนด์ดิ้ง > สกรีนเซฟเวอร์_ อัปโหลด png หรือ svg แล้ว Omarchy จะแปลงมันเป็น ASCII ดู [แบรนด์ดิ้ง](41-branding.md)

### หน้าจอล็อก

`Super + Ctrl + L` ล็อกเครื่อง นั่นจะเรียกหน้าจอล็อกจากเชลล์ของ Omarchy ทำให้จอแสดงผลว่างเปล่า รีเซ็ตการจัดวางแป้นพิมพ์ของคุณเป็นแบบแรกเพื่อให้คุณไม่พิมพ์รหัสผ่านด้วยตัวอักษรผิดชุด และ — หากคุณเปิดมันไว้ — ล็อก 1Password ระหว่างทางออก

หน้าจอล็อกรับรหัสผ่าน และมันจะรับลายนิ้วมือด้วยเมื่อคุณตั้งค่าหนึ่งไว้แล้ว เรื่องนั้น และวิธีอื่น ๆ ในการยืนยันตัวตน ครอบคลุมอยู่ใน [การยืนยันตัวตนด้วยฮาร์ดแวร์](37-hardware-authentication.md)
