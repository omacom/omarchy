# การยืนยันตัวตนด้วยฮาร์ดแวร์

### การยืนยันตัวตนด้วยลายนิ้วมือ

แล็ปท็อปจำนวนมากมาพร้อมกับเซ็นเซอร์ลายนิ้วมือสำหรับการยืนยันตัวตน คุณสามารถใช้เซ็นเซอร์นี้กับ Omarchy ได้โดยเรียกใช้ _Setup > Security > Fingerprint_ ในเมนู Omarchy (`Super + Space`)

การทำเช่นนั้นจะเปิดภาพลายนิ้วมือแบบเต็มหน้าจอซึ่งจะค่อย ๆ เติมเต็มขณะที่คุณแตะเซ็นเซอร์ เบื้องหลัง Omarchy จะติดตั้งแพ็กเกจลายนิ้วมือ บันทึกลายนิ้วมือของคุณ ตรวจสอบลายนิ้วมือ และคุณก็พร้อมที่จะใช้ลายนิ้วมือของคุณเพื่อปลดล็อกจากหน้าจอล็อก (ซึ่งคุณสามารถเรียกใช้ได้ด้วย `Super + Ctrl + L`) เข้าสู่โหมด sudo และอนุญาตข้อความแจ้งของระบบ

เมื่อหน้าจอล็อกปิดจอแสดงผลแล้ว เซ็นเซอร์จะหยุดพักเพื่อประหยัดพลังงาน ดังนั้นให้ปลุกหน้าจอด้วยปุ่มใด ๆ หรือทัชแพดก่อนแตะเซ็นเซอร์

เมื่อปิดฝาแล็ปท็อป ข้อความแจ้งให้ใช้ลายนิ้วมือจะถูกข้ามโดยอัตโนมัติ ดังนั้นคุณจะไปยังข้อความแจ้งให้ใส่รหัสผ่านโดยตรง แทนที่จะต้องรอเซ็นเซอร์ที่คุณเอื้อมไม่ถึง หากในกรณีอื่นคุณจำเป็นต้องทำงานบนแป้นพิมพ์ภายนอกที่ไม่มีเซ็นเซอร์ เพียงกด `CTRL + C` เมื่อระบบแจ้งให้คุณใช้ลายนิ้วมือระหว่างใช้ `sudo`

คุณสามารถลบการยืนยันตัวตนด้วยลายนิ้วมือได้ภายใต้ _Remove > Security > Fingerprint_ ในเมนู Omarchy

### การยืนยันตัวตนด้วย Fido2

หากคุณกำลังใช้อุปกรณ์ Fido2 คุณสามารถตั้งค่าให้อุปกรณ์ดังกล่าวใช้สำหรับการยืนยันตัวตนด้วย `sudo` ได้โดยใช้ _Setup > Security > Fido2_ ในเมนู Omarchy (`Super + Space`) อย่างไรก็ตาม การตั้งค่านี้ครอบคลุม `sudo` และข้อความแจ้งการอนุญาตของระบบ แต่ไม่ครอบคลุมการปลดล็อกคอมพิวเตอร์ของคุณ

คุณสามารถลบการยืนยันตัวตนด้วย fido2 ได้ภายใต้ _Remove > Security > Fido2_ ในเมนู Omarchy
