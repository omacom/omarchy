# การยืนยันตัวตนด้วยฮาร์ดแวร์

### การยืนยันตัวตนด้วยลายนิ้วมือ

แล็ปท็อปหลายรุ่นมาพร้อมเซนเซอร์ลายนิ้วมือสำหรับยืนยันตัวตน คุณสามารถใช้มันกับ Omarchy ได้โดยเรียกใช้ _Setup > Security > Fingerprint_ ในเมนู Omarchy (`Super + Space`)

ตัวติดตั้งนั้นจะติดตั้งแพ็กเกจลายนิ้วมือ บันทึกลายนิ้วมือของคุณ ตรวจสอบมัน และคุณก็จะพร้อมใช้ลายนิ้วมือเพื่อปลดล็อกจอจากจอล็อก (ซึ่งคุณเรียกขึ้นมาได้ด้วย `Super + Ctrl + L`) เข้าโหมด sudo และยืนยันคำขอจากระบบ

เมื่อจอล็อกปิดจอแสดงผลลงแล้ว เซนเซอร์จะพักเพื่อประหยัดพลังงาน ดังนั้นปลุกจอด้วยปุ่มใดก็ได้หรือด้วยทัชแพดก่อนแตะเซนเซอร์

เมื่อปิดฝาแล็ปท็อปของคุณ คำขอให้สแกนลายนิ้วมือจะถูกข้ามโดยอัตโนมัติ คุณจะไปเจอกับคำขอให้ใส่รหัสผ่านทันที แทนที่จะต้องรอเซนเซอร์ที่คุณแตะไม่ถึง หากคุณจำเป็นต้องทำงานบนคีย์บอร์ดภายนอกที่ไม่มีเซนเซอร์ในกรณีอื่น ก็แค่กด `CTRL + C` เมื่อคุณถูกขอให้สแกนลายนิ้วมือระหว่างใช้ `sudo`

คุณสามารถลบการยืนยันตัวตนด้วยลายนิ้วมือได้ที่ _Remove > Security > Fingerprint_ ในเมนู Omarchy

### การยืนยันตัวตนด้วย Fido2

หากคุณใช้อุปกรณ์ Fido2 คุณสามารถตั้งค่าให้มันใช้ยืนยันตัวตนสำหรับ `sudo` ได้โดยใช้ _Setup > Security > Fido2_ ในเมนู Omarchy (`Super + Space`) อย่างไรก็ตาม มันครอบคลุมเฉพาะ `sudo` และคำขออนุญาตของระบบเท่านั้น ไม่รวมถึงการปลดล็อกคอมพิวเตอร์ของคุณ

คุณสามารถลบการยืนยันตัวตนด้วย fido2 ได้ที่ _Remove > Security > Fido2_ ในเมนู Omarchy
