# ภาพหน้าจอและการอัด

ทุกสิ่งที่คุณหยิบออกจากหน้าจอได้ห้อยอยู่กับปุ่ม Print Screen ปุ่มเดียวโดด ๆ ถ่ายภาพ และตัวปรับแต่งจะอัด จับสี หรือหยิบข้อความภายในภูมิภาค หากคีย์บอร์ดของคุณไม่มีปุ่ม Print Screen เลย `Super + Ctrl + C` เปิดชุดเดียวกันเป็นเมนู

| ปุ่มลัด | ฟังก์ชัน |
| ------ | -------- |
| `Print Screen` | ภาพหน้าจอ |
| `Alt + Print Screen` | อัดหน้าจอ (หรือหยุดการอัดที่กำลังทำงานอยู่) |
| `Super + Print Screen` | ตัวเลือกสี |
| `Super + Ctrl + Print Screen` | แยกข้อความจากภูมิภาค |
| `Super + Ctrl + C` | เมนูจับภาพ |
| `Super + Ctrl + .` | แปลงภาพหรือวิดีโอ |

## ภาพหน้าจอ

กด `Print Screen` แล้ว Omasnap จะจับภาพจอภาพที่โฟกัสก่อนที่ชั้นซ้อนทับของมันจะปรากฏ ดังนั้นจึงไม่มีอะไรขยับใต้ตัวคุณขณะที่คุณเล็ง ลากภูมิภาคอิสระ คลิกหน้าต่างเพื่อจับภาพมัน หรือคลิกพื้นที่เปิดเพื่อจับภาพจอภาพทั้งหมด กด `S` ก่อนวาดเพื่อจับภาพภูมิภาคแบบเลื่อน เปลี่ยนใจหรือ กด `Print Screen` อีกครั้งเพื่อปิด Omasnap

หลังจากที่คุณเลือกพื้นที่ Omasnap จะบันทึกภาพที่จับไว้ คัดลอกมันไปยังคลิปบอร์ด และแสดงตัวอย่างเป็นเวลา 10 วินาที ใช้ปุ่มปักหมุดของตัวอย่างหรือ `Ctrl + P` เพื่อรักษามันไว้บนหน้าจอ หรือเลือกแก้ไขเพื่อใส่คำอธิบายประกอบให้มัน

ตัวแก้ไขคำอธิบายประกอบวาดลูกศร เส้น รูปทรง ไฮไลต์ เครื่องหมายที่มีเลขกำกับ ข้อความ และการปกปิดที่ปลอดภัยได้ ครอบหรือตัดส่วนของภาพออก ทำ OCR ข้อความของมัน และเพิ่มพื้นหลังได้ ในตัวแก้ไข กด `Enter` เพื่อคัดลอกและบันทึกไฟล์ PNG ที่เสร็จแล้ว `Ctrl + C` เพื่อคัดลอกมันโดยไม่บันทึก หรือ `Ctrl + S` เพื่อบันทึกมันโดยไม่คัดลอก

ภาพหน้าจอที่บันทึกไว้จะลงใน `~/Pictures/Screenshots` เป็นค่าเริ่มต้น โดยมีชื่ออย่าง `screenshot-2026-08-13_14-22-05-firefox.png` ตั้งค่า `OMASNAP_SCREENSHOT_DIR` เพื่อใช้ไดเรกทอรีอื่น — ดู [คำถามที่พบบ่อย](46-faq.md) ว่าจะวางตัวแปรสภาพแวดล้อมเซสชันไว้ที่ไหน Omasnap สร้างไดเรกทอรีเมื่อมันบันทึกภาพแรก ตั้งค่า `[output] autosave = false` ใน `~/.config/omasnap/omasnap.conf` เพื่อปิดการบันทึกอัตโนมัติ

จากเทอร์มินัล `omarchy screenshot` เปิดชั้นซ้อนทับเดียวกัน และคุณเลือกโหมดเริ่มต้นของมันได้: `omarchy capture screenshot region` `windows` `fullscreen` หรือ `scroll` อาร์กิวเมนต์ที่สองเป็น `copy` หรือ `save` จะข้ามตัวอย่างและส่งภาพตรงไปยังปลายทางนั้น หากต้องการแก้ไขก่อนส่งออก ใช้ `omarchy screenshot --editor=overlay` สำหรับตัวแก้ไขแบบเต็มหน้าจอ หรือ `omarchy screenshot --editor=window` สำหรับหน้าต่างแยก

### การขับตัวเลือกจากคีย์บอร์ด

ขณะที่ส่วนเลือกปรากฏอยู่ คุณไม่จำเป็นต้องใช้เมาส์เลย:

| ปุ่ม | ฟังก์ชัน |
| --- | -------- |
| `S` | สลับโหมดภูมิภาคแบบเลื่อน |
| `Super + Arrow keys` | ย้ายระหว่างหน้าต่างในโหมดหน้าต่าง |
| `Return` | จับภาพหน้าต่างที่ไฮไลต์ไว้ |
| `Ctrl + A` | จับภาพจอภาพที่โฟกัสเต็มจอ |
| `R` | คืนค่าภูมิภาคล่าสุดที่วาดในเซสชันนี้ |
| `Esc` | ปิด Omasnap |

การผูกเหล่านี้จะมีอยู่เฉพาะขณะที่ Omasnap เปิดอยู่เท่านั้น ดังนั้นพวกมันจึงชนอะไรในคอนฟิกของคุณเองไม่ได้

## การอัดหน้าจอ

`Alt + Print Screen` เปิด _สั่งการ > จับภาพ > อัดหน้าจอ_ ซึ่งถามว่าคุณต้องการอะไรบนเพลงประกอบ: ไม่มีเสียง เสียงเดสก์ท็อป เสียงเดสก์ท็อปพร้อมไมโครโฟน หรือเสียงเดสก์ท็อปพร้อมไมโครโฟนพร้อมเว็บแคม แบบสุดท้ายนั้นจะปรากฏเฉพาะหากคุณเสียบกล้องอยู่จริง เลือกหนึ่งแบบ แล้วตัวเลือกการอัดของ Omarchy จะให้คุณลากภูมิภาค หรือคลิกหน้าต่างหรือจอภาพ

การอัดทำงานบน gpu-screen-recorder ซึ่งเข้ารหัสบน GPU ที่ 60fps และถอยไปใช้ CPU หากจำเป็น ผลลัพธ์คือไฟล์ MP4 ใน `~/Videos` ชื่อ `screenrecording-2026-08-13_14-22-05.mp4` ตั้งค่า `OMARCHY_SCREENRECORD_DIR` เพื่อเปลี่ยนสิ่งนั้น — แต่โปรดทราบว่าไม่เหมือนไดเรกทอรีภาพหน้าจอ อันนี้ต้องมีอยู่แล้ว มิฉะนั้นการอัดจะปฏิเสธที่จะเริ่ม

ขณะที่คุณกำลังอัด ตัวบ่งชี้เล็ก ๆ จะปรากฏในแถบ คลิกมันเพื่อหยุด คุณยังหยุดด้วย `Alt + Print Screen` อีกครั้ง หรือด้วยรายการ _หยุดอัดหน้าจอ_ ภายใต้ _สั่งการ > จับภาพ > อัดหน้าจอ_ ซึ่งจะปรากฏเฉพาะขณะที่กำลังอัดอะไรอยู่จริง ๆ

การหยุดจะเก็บกวาดเล็กน้อยก่อนจะส่งไฟล์ให้คุณ: เฟรมแรกจะถูกตัดออก และถ้ามีเสียง มันจะถูกปรับมาตรฐานเป็น -14 LUFS โดยเสียงป๊อปจากการจับภาพของ PipeWire ที่ต้นสุดจะถูกปิดเสียง จากนั้นการแจ้งเตือนจะปรากฏพร้อมภาพย่อจากการอัด คลิกมันเพื่อเล่นไฟล์ใน mpv

### ชั้นซ้อนทับเว็บแคม

เมื่อคุณอัดด้วยเว็บแคม กล้องจะปรากฏเป็นหน้าต่างภาพบุคคลที่ปักหมุดและถูกครอบไว้ที่มุมล่างขวาของสิ่งที่คุณกำลังอัดอยู่ หากมันอยู่บนสิ่งที่คุณต้องการ ปรับขนาดมันได้ทันที:

| ปุ่มลัด | ฟังก์ชัน |
| ------ | -------- |
| `Super + Alt + [` | ทำให้ชั้นซ้อนทับเว็บแคมเล็กลง |
| `Super + Alt + ]` | ทำให้ชั้นซ้อนทับเว็บแคมใหญ่ขึ้น |

มีสามขนาด — เล็ก กลาง และใหญ่ — และปุ่มลัดก้าวผ่านพวกมัน กลางเป็นค่าเริ่มต้น พวกมันเป็นสัดส่วนกับการอัด ดังนั้นกล้องจึงกินสัดส่วนเดียวกันของเฟรมไม่ว่าคุณกำลังอัดจอภาพ 1080p หรือจอภาพ 6K ก็ตาม และถ้าคุณอัดภูมิภาคแทนที่จะเป็นทั้งจอแสดงผล ชั้นซ้อนทับจะยึดมุมของภูมิภาคนั้นแทนมุมของจอภาพ ดังนั้นมันจึงอยู่ภายในภาพ

คุณยังเรียกมันโดยตรงด้วย `omarchy-capture-webcam-resize small` หรือ `reset` เพื่อกลับเป็นกลางได้ด้วย

## ข้อความ รหัส QR และสี

`Super + Ctrl + Print Screen` เลือกภูมิภาคและทำ OCR มันไปยังคลิปบอร์ด นั่นอธิบายอย่างถูกต้องไว้ใน [การแยกข้อความและการพูดพิมพ์](11-text-extraction-dictation.md)

_สั่งการ > จับภาพ > QR Code_ ทำเคล็ดลับเดียวกันสำหรับรหัส QR เลือกภูมิภาคที่มีรหัสอยู่ ค่าที่ถอดรหัสแล้วจะไปสู่คลิปบอร์ด มันมองหาเฉพาะรหัส QR — เนื้อหาหน้าจอที่หนาแน่นมีนิสัยชอบกลายเป็นผลบวกปลอมเป็นบาร์โค้ดเป็นอย่างอื่น แหล่งข้อมูลที่ควรรู้: ค่าที่ถอดรหัสแล้วไปสู่คลิปบอร์ดและไม่ไปไหนอื่นเลย มันไม่ได้ถูกพิมพ์ มันไม่อยู่ในการแจ้งเตือน และมันถูกทำเครื่องหมายว่าละเอียดอ่อน ดังนั้นมันจึงไม่ค้างอยู่ใน [ประวัติคลิปบอร์ด](08-unified-clipboard-history.md) รหัส QR มักแบกรับความลับ — URI `otpauth://` ที่อยู่เบื้องหลังรหัสตั้งค่า 2FA เป็นต้น — และคุณไม่ต้องการสิ่งนั้นในบันทึก การวางยังคงทำงานได้ดี

`Super + Print Screen` (หรือ _สั่งการ > จับภาพ > สี_) เปลี่ยนเคอร์เซอร์ให้เป็นหลอดดูดตา คลิกอะไรก็ได้บนหน้าจอ และสีจะลงบนคลิปบอร์ด กดปุ่มลัดอีกครั้งเพื่อถอยออกโดยไม่เลือก

## การแปลงก่อนที่คุณจะแชร์

การอัดหน้าจอ 4K หรือไฟล์ HEIC ดิบจากโทรศัพท์ของคุณมักใหญ่เกินกว่าจะส่งเฉย ๆ `Super + Ctrl + .` (หรือ _สั่งการ > แปลงวิดีโอ_) แก้ไขสิ่งนั้น มันแสดงตัวเลือกไฟล์แบบค้นหาไม่ตรงเป๊ะเหนือ `~/Pictures` และ `~/Videos` จากนั้นถามรูปแบบและขนาด

ภาพจะไปเป็น jpg หรือ png ที่ระดับสูง กลาง หรือต่ำ ซึ่งจำกัดความกว้างที่ 3160 2160 และ 1080 พิกเซล วิดีโอไปเป็น mp4 หรือ gif เคลื่อนไหวที่ 4k 1080p หรือ 720p ไฟล์ที่แปลงแล้วจะถูกเขียนถัดจากต้นฉบับโดยมีความละเอียดอยู่ในชื่อ — `demo-1080p.mp4` — และพาธจะถูกคัดลอกไปยังคลิปบอร์ดเป็น URI ไฟล์ ดังนั้นคุณจึงวางมันตรงเข้าไปในแอปที่รับไฟล์ที่วางลงได้

มันทำงานจากเทอร์มินัลด้วย หากคุณรู้แล้วว่าคุณต้องการอะไร: `omarchy transcode ~/Videos/demo.mov mp4 1080p` ยังมี `omarchy transcode ascii` ซึ่งเปลี่ยนภาพให้เป็นศิลปะ ASCII — อันนั้นส่วนใหญ่ไว้สำหรับ [การสร้างแบรนด์](41-branding.md)

## การส่งไปที่ไหนสักแห่ง

เมื่อคุณได้ไฟล์แล้ว `Super + Ctrl + S` เปิดเมนูแชร์และส่งมันไปยังอุปกรณ์อื่นบนเครือข่ายของคุณผ่าน LocalSend ดู [GUI](22-guis.md) สำหรับเรื่องนั้น
