# การจับภาพหน้าจอและการบันทึก

ทุกอย่างที่คุณดึงออกมาจากหน้าจอได้ผูกอยู่กับปุ่ม Print Screen ปุ่มเดียวโดด ๆ จะถ่ายภาพ และปุ่มตัวปรับแต่งจะทำการบันทึก หยิบสี หรือเอาข้อความที่อยู่ภายในพื้นที่ หากแป้นพิมพ์ของคุณไม่มีปุ่ม Print Screen เลย `Super + Ctrl + Alt + C` จะถ่ายภาพหน้าจอเดียวกัน และ `Super + Ctrl + C` จะเปิดชุดทั้งหมดขึ้นมาเป็นเมนู

| Hotkey | Function |
| ------ | -------- |
| `Print Screen` | ภาพหน้าจอ |
| `Super + Ctrl + Alt + C` | ภาพหน้าจอ |
| `Alt + Print Screen` | บันทึกหน้าจอ (หรือหยุดการบันทึกที่กำลังทำงานอยู่) |
| `Super + Print Screen` | ตัวเลือกสี |
| `Super + Ctrl + Print Screen` | ดึงข้อความจากพื้นที่ |
| `Super + Ctrl + C` | เมนูการจับภาพ |
| `Super + Ctrl + .` | แปลงไฟล์ภาพหรือวิดีโอ |

## ภาพหน้าจอ

กด `Print Screen` (หรือ `Super + Ctrl + Alt + C`) แล้ว Omasnap จะจับภาพจอมอนิเตอร์ที่โฟกัสอยู่ก่อนที่โอเวอร์เลย์ของมันจะปรากฏขึ้น ดังนั้นไม่มีอะไรขยับใต้ตัวคุณขณะที่คุณเล็ง ลากพื้นที่แบบอิสระ คลิกหน้าต่างเพื่อจับภาพหน้าต่างนั้น หรือคลิกพื้นที่ว่างเพื่อจับภาพทั้งจอมอนิเตอร์ กด `S` ก่อนวาดเพื่อจับภาพพื้นที่แบบเลื่อนได้ เปลี่ยนใจแล้วหรือ? กดปุ่มเดิมอีกครั้งเพื่อปิด Omasnap

หลังจากคุณเลือกพื้นที่แล้ว Omasnap จะบันทึกภาพที่จับไว้ คัดลอกไปยังคลิปบอร์ด และแสดงการแจ้งเตือนพร้อมภาพขนาดย่อของมัน เหมือนที่การบันทึกหน้าจอที่บันทึกไว้ทำ เลือก Open เพื่อดูภาพที่บันทึกไว้ในโปรแกรมดูรูปภาพของคุณ หรือ Edit เพื่อใส่คำอธิบายประกอบลงไป

โปรแกรมแก้ไขคำอธิบายประกอบสามารถวาดลูกศร เส้น รูปทรง ไฮไลต์ เครื่องหมายตัวเลข ข้อความ และการปกปิดข้อมูลอย่างปลอดภัย ครอบตัดหรือตัดส่วนหนึ่งของภาพออก ทำ OCR ข้อความของมัน และเพิ่มฉากหลังได้ ในโปรแกรมแก้ไข กด `Enter` เพื่อคัดลอกและบันทึก PNG ที่เสร็จแล้ว กด `Ctrl + C` เพื่อคัดลอกโดยไม่บันทึก หรือกด `Ctrl + S` เพื่อบันทึกโดยไม่คัดลอก

ภาพหน้าจอที่บันทึกไว้จะอยู่ใน `~/Pictures/Screenshots` ตามค่าเริ่มต้น โดยมีชื่อเช่น `screenshot-2026-08-13_14-22-05-firefox.png` ตั้งค่า `OMASNAP_SCREENSHOT_DIR` เพื่อใช้ไดเรกทอรีอื่น — ดู [คำถามที่พบบ่อย](46-faq.md) สำหรับที่ที่จะใส่ตัวแปรสภาพแวดล้อมของเซสชัน Omasnap จะสร้างไดเรกทอรีเมื่อมันบันทึกภาพแรก ตั้งค่า `[output] autosave = false` ใน `~/.config/omasnap/omasnap.conf` เพื่อปิดการบันทึกอัตโนมัติ จากนั้นภาพที่จับไว้จะถูกคัดลอกเท่านั้น และแสดงในตัวอย่างเป็นเวลา 10 วินาที ซึ่งคุณสามารถตรึงไว้บนหน้าจอได้ด้วยปุ่มตรึงของมันหรือ `Ctrl + P`

จากเทอร์มินัล `omarchy screenshot` จะเปิดโอเวอร์เลย์เดียวกัน และคุณสามารถเลือกโหมดเริ่มต้นของมันได้: `omarchy capture screenshot region`, `windows`, `fullscreen` หรือ `scroll` อาร์กิวเมนต์ที่สองเป็น `copy` หรือ `save` จะส่งภาพไปยังปลายทางนั้นโดยตรง หากต้องการแก้ไขก่อนส่งออก ให้ใช้ `omarchy screenshot --editor=overlay` สำหรับโปรแกรมแก้ไขแบบเต็มหน้าจอ หรือ `omarchy screenshot --editor=window` สำหรับหน้าต่างแยกต่างหาก

### การควบคุมตัวเลือกด้วยแป้นพิมพ์

ขณะที่หน้าจอการเลือกเปิดอยู่ คุณไม่จำเป็นต้องใช้เมาส์เลย:

| Key | Function |
| --- | -------- |
| `S` | สลับโหมดพื้นที่แบบเลื่อนได้ |
| `Super + Arrow keys` | เลื่อนไปมาระหว่างหน้าต่างในโหมด Window |
| `Return` | จับภาพหน้าต่างที่ไฮไลต์อยู่ |
| `Ctrl + A` | จับภาพจอมอนิเตอร์ที่โฟกัสอยู่ทั้งจอ |
| `R` | คืนค่าพื้นที่สุดท้ายที่วาดในเซสชันนี้ |
| `Esc` | ปิด Omasnap |

การผูกปุ่มเหล่านี้มีอยู่เฉพาะขณะที่ Omasnap เปิดอยู่เท่านั้น ดังนั้นมันจึงไม่สามารถชนกับอะไรในการตั้งค่าของคุณเองได้

## การบันทึกหน้าจอ

`Alt + Print Screen` เปิด _Trigger > Capture > Screenrecord_ ซึ่งจะถามว่าคุณต้องการอะไรในซาวด์แทร็ก: ไม่มีเสียง เสียงจากเดสก์ท็อป เสียงจากเดสก์ท็อปบวกไมโครโฟน หรือเสียงจากเดสก์ท็อปบวกไมโครโฟนบวกเว็บแคม ตัวเลือกสุดท้ายนั้นจะแสดงขึ้นมาก็ต่อเมื่อคุณเสียบกล้องไว้จริง ๆ เท่านั้น เลือกหนึ่งตัวเลือก แล้วตัวเลือกการบันทึกของ Omarchy จะให้คุณลากพื้นที่หรือคลิกหน้าต่างหรือจอมอนิเตอร์

การบันทึกทำงานบน gpu-screen-recorder ซึ่งเข้ารหัสบน GPU ที่ 60fps และถอยกลับไปใช้ CPU หากจำเป็น ผลลัพธ์คือไฟล์ MP4 ใน `~/Videos` ชื่อ `screenrecording-2026-08-13_14-22-05.mp4` ตั้งค่า `OMARCHY_SCREENRECORD_DIR` เพื่อเปลี่ยนที่นั้น — แต่โปรดทราบว่าไม่เหมือนกับไดเรกทอรีภาพหน้าจอ ไดเรกทอรีนี้ต้องมีอยู่แล้ว มิฉะนั้นการบันทึกจะไม่ยอมเริ่ม

ขณะที่คุณกำลังบันทึก ตัวบ่งชี้เล็ก ๆ จะปรากฏขึ้นในแถบ คลิกมันเพื่อหยุด คุณยังสามารถหยุดด้วย `Alt + Print Screen` อีกครั้ง หรือด้วยรายการ _Stop Screenrecording_ ใต้ _Trigger > Capture > Screenrecord_ ซึ่งจะปรากฏเฉพาะขณะที่กำลังบันทึกบางอย่างอยู่จริงเท่านั้น

การหยุดจะจัดการเก็บกวาดเล็กน้อยก่อนส่งไฟล์ให้คุณ: เฟรมแรกจะถูกตัดออก และหากมีเสียง มันจะถูกปรับให้เป็นมาตรฐานที่ -14 LUFS โดยเสียงป๊อปจากการจับภาพของ PipeWire ในช่วงเริ่มต้นสุดจะถูกปิดเสียงออก จากนั้นการแจ้งเตือนจะปรากฏขึ้นพร้อมภาพขนาดย่อจากการบันทึก คลิกมันเพื่อเล่นไฟล์ใน Omaview

### โอเวอร์เลย์เว็บแคม

เมื่อคุณบันทึกด้วยเว็บแคม กล้องจะปรากฏเป็นหน้าต่างภาพบุคคลที่ถูกตรึงและครอบตัดไว้ที่มุมล่างขวาของสิ่งที่คุณกำลังบันทึก หากมันนั่งทับสิ่งที่คุณต้องการอยู่ ปรับขนาดมันได้ทันที:

| Hotkey | Function |
| ------ | -------- |
| `Super + Alt + [` | ทำให้โอเวอร์เลย์เว็บแคมเล็กลง |
| `Super + Alt + ]` | ทำให้โอเวอร์เลย์เว็บแคมใหญ่ขึ้น |

มีสามขนาด — เล็ก กลาง และใหญ่ — และแป้นลัดจะเลื่อนไปมาระหว่างขนาดเหล่านั้น ขนาดกลางเป็นค่าเริ่มต้น ขนาดเหล่านี้เป็นสัดส่วนกับการบันทึก ดังนั้นกล้องจึงกินพื้นที่ในเฟรมเท่ากันไม่ว่าคุณจะบันทึกจอมอนิเตอร์ 1080p หรือ 6K และหากคุณบันทึกพื้นที่แทนที่จะเป็นทั้งจอแสดงผล โอเวอร์เลย์จะยึดกับมุมของพื้นที่นั้นแทนที่จะเป็นของจอมอนิเตอร์ ดังนั้นมันจึงอยู่ภายในภาพ

คุณยังสามารถเรียกมันโดยตรงด้วย `omarchy-capture-webcam-resize small` หรือ `reset` เพื่อกลับไปขนาดกลาง

## ข้อความ รหัส QR และสี

`Super + Ctrl + Print Screen` เลือกพื้นที่และทำ OCR มันไปยังคลิปบอร์ด เรื่องนั้นครอบคลุมอย่างเหมาะสมใน [การดึงข้อความและการพิมพ์ด้วยเสียง](11-text-extraction-dictation.md)

_Trigger > Capture > QR Code_ ทำเทคนิคเดียวกันสำหรับรหัส QR เลือกพื้นที่ที่มีรหัสอยู่ในนั้น แล้วค่าที่ถอดรหัสได้จะไปยังคลิปบอร์ด มันมองหาเฉพาะรหัส QR เท่านั้น — เนื้อหาบนหน้าจอที่หนาแน่นมักจะให้ผลบวกปลอมเป็นบาร์โค้ดในกรณีอื่น ควรทราบไว้: ค่าที่ถอดรหัสได้จะไปยังคลิปบอร์ดและไม่ไปที่อื่นเลย มันจะไม่ถูกพิมพ์ออกมา มันไม่อยู่ในการแจ้งเตือน และมันถูกทำเครื่องหมายว่าเป็นข้อมูลละเอียดอ่อน ดังนั้นมันจึงไม่ค้างอยู่ใน [ประวัติคลิปบอร์ด](08-unified-clipboard-history.md) รหัส QR มักพกพาความลับเป็นประจำ — URI `otpauth://` ที่อยู่เบื้องหลังรหัสตั้งค่า 2FA เป็นตัวอย่างหนึ่ง — และคุณไม่ต้องการให้สิ่งนั้นอยู่ในบันทึก การวางยังคงทำงานได้ตามปกติ

`Super + Print Screen` (หรือ _Trigger > Capture > Color_) เปลี่ยนเคอร์เซอร์เป็นหลอดหยดสี คลิกอะไรก็ได้บนหน้าจอแล้วสีจะลงไปในคลิปบอร์ด กดแป้นลัดอีกครั้งเพื่อถอยออกโดยไม่เลือก

## การแปลงไฟล์ก่อนที่คุณจะแชร์

การบันทึกหน้าจอ 4K หรือไฟล์ HEIC ดิบจากโทรศัพท์ของคุณมักใหญ่เกินกว่าจะส่งไปได้เลย `Super + Ctrl + .` (หรือ _Trigger > Transcode_) แก้ปัญหานั้น มันเสนอตัวเลือกไฟล์แบบค้นหาไม่ต้องเป๊ะเหนือ `~/Pictures` และ `~/Videos` จากนั้นถามรูปแบบและขนาด

รูปภาพจะไปยัง jpg หรือ png ที่คุณภาพสูง กลาง หรือต่ำ ซึ่งจำกัดความกว้างไว้ที่ 3160, 2160 และ 1080 พิกเซล วิดีโอจะไปยัง mp4 หรือ gif แบบเคลื่อนไหวที่ 4k, 1080p หรือ 720p ไฟล์ที่แปลงแล้วจะถูกเขียนไว้ข้างไฟล์ต้นฉบับโดยมีความละเอียดอยู่ในชื่อ — `demo-1080p.mp4` — และเส้นทางจะถูกคัดลอกไปยังคลิปบอร์ดเป็น file URI ดังนั้นคุณจึงวางมันลงในแอปที่รับการวางไฟล์ได้โดยตรง

มันทำงานจากเทอร์มินัลได้เช่นกัน หากคุณรู้แล้วว่าต้องการอะไร: `omarchy transcode ~/Videos/demo.mov mp4 1080p` นอกจากนี้ยังมี `omarchy transcode ascii` ซึ่งเปลี่ยนรูปภาพเป็นศิลปะ ASCII — อันนั้นส่วนใหญ่ไว้สำหรับ [การสร้างแบรนด์](41-branding.md)

## การส่งมันไปที่ใดที่หนึ่ง

เมื่อคุณได้ไฟล์แล้ว `Super + Ctrl + S` จะเปิดเมนู Share และส่งมันไปยังอุปกรณ์อื่นบนเครือข่ายของคุณผ่าน LocalSend ดู [GUIs](22-guis.md) สำหรับเรื่องนั้น
