# ภาพหน้าจอและการบันทึกหน้าจอ

ทุกอย่างที่คุณจับภาพจากหน้าจอได้ล้วนผูกอยู่กับคีย์ Print Screen ทั้งสิ้น คีย์เดียวโดด ๆ จะถ่ายภาพ และคีย์ตัวปรับแต่งจะบันทึกหน้าจอ เลือกสี หรืออ่านข้อความภายในพื้นที่ที่เลือก หากคีย์บอร์ดของคุณไม่มีคีย์ Print Screen เลย `Super + Ctrl + Alt + C` จะถ่ายภาพหน้าจอแบบเดียวกัน และ `Super + Ctrl + C` จะเปิดชุดเครื่องมือทั้งหมดเป็นเมนู

| ปุ่มลัด | ฟังก์ชัน |
| ------ | -------- |
| `Print Screen` | ภาพหน้าจอ |
| `Super + Ctrl + Alt + C` | ภาพหน้าจอ |
| `Alt + Print Screen` | บันทึกหน้าจอ (หรือหยุดการบันทึกที่กำลังทำอยู่) |
| `Super + Print Screen` | ตัวเลือกสี |
| `Super + Ctrl + Print Screen` | แยกข้อความจากพื้นที่ที่เลือก |
| `Super + Ctrl + C` | เมนูการจับภาพ |
| `Super + Ctrl + .` | แปลงไฟล์ภาพหรือวิดีโอ |

## ภาพหน้าจอ

กด `Print Screen` (หรือ `Super + Ctrl + Alt + C`) แล้ว Omasnap จะจับภาพจอภาพที่โฟกัสอยู่ก่อนที่โอเวอร์เลย์ของมันจะปรากฏขึ้น ดังนั้นจะไม่มีอะไรขยับไปมาขณะที่คุณกำลังเล็ง ลากเพื่อเลือกพื้นที่แบบอิสระ คลิกที่หน้าต่างเพื่อจับภาพหน้าต่างนั้น หรือคลิกบนพื้นที่ว่างเพื่อจับภาพจอภาพทั้งจอ กด `S` ก่อนเริ่มลากเพื่อจับภาพพื้นที่แบบเลื่อนได้ เปลี่ยนใจแล้วหรือ? กดคีย์เดิมอีกครั้งเพื่อปิด Omasnap

หลังจากคุณเลือกพื้นที่แล้ว Omasnap จะบันทึกภาพที่จับไว้ คัดลอกไปยังคลิปบอร์ด และแสดงตัวอย่างเป็นเวลา 10 วินาที ใช้ปุ่มปักหมุดของตัวอย่างหรือ `Ctrl + P` เพื่อให้มันค้างอยู่บนหน้าจอ หรือเลือก Edit เพื่อใส่คำอธิบายประกอบลงในภาพ

ตัวแก้ไขคำอธิบายประกอบสามารถวาดลูกศร เส้น รูปร่าง ไฮไลต์ เครื่องหมายตัวเลข ข้อความ และการปกปิดข้อมูลอย่างปลอดภัย ครอบตัดหรือตัดส่วนหนึ่งของภาพออก OCR ข้อความในภาพ และเพิ่มฉากหลังได้ ในตัวแก้ไข กด `Enter` เพื่อคัดลอกและบันทึก PNG ที่เสร็จแล้ว กด `Ctrl + C` เพื่อคัดลอกโดยไม่บันทึก หรือกด `Ctrl + S` เพื่อบันทึกโดยไม่คัดลอก

ภาพหน้าจอที่บันทึกไว้จะไปอยู่ที่ `~/Pictures/Screenshots` โดยค่าเริ่มต้น โดยมีชื่อเช่น `screenshot-2026-08-13_14-22-05-firefox.png` ตั้งค่า `OMASNAP_SCREENSHOT_DIR` เพื่อใช้ไดเรกทอรีอื่น — ดู [FAQ](46-faq.md) สำหรับตำแหน่งที่ควรวางตัวแปรสภาพแวดล้อมของเซสชัน Omasnap จะสร้างไดเรกทอรีเมื่อบันทึกภาพแรก ตั้งค่า `[output] autosave = false` ใน `~/.config/omasnap/omasnap.conf` เพื่อปิดการบันทึกอัตโนมัติ

จากเทอร์มินัล `omarchy screenshot` จะเปิดโอเวอร์เลย์เดียวกัน และคุณสามารถเลือกโหมดเริ่มต้นได้: `omarchy capture screenshot region`, `windows`, `fullscreen` หรือ `scroll` อาร์กิวเมนต์ที่สองเป็น `copy` หรือ `save` จะข้ามตัวอย่างและส่งภาพไปยังปลายทางนั้นโดยตรง หากต้องการแก้ไขก่อนส่งออก ให้ใช้ `omarchy screenshot --editor=overlay` สำหรับตัวแก้ไขแบบเต็มจอ หรือ `omarchy screenshot --editor=window` สำหรับหน้าต่างแยกต่างหาก

### การควบคุมตัวเลือกด้วยคีย์บอร์ด

ขณะที่หน้าจอเลือกพื้นที่แสดงอยู่ คุณไม่จำเป็นต้องใช้เมาส์เลย:

| คีย์ | ฟังก์ชัน |
| --- | -------- |
| `S` | สลับโหมดพื้นที่แบบเลื่อนได้ |
| `Super + Arrow keys` | เลื่อนไปมาระหว่างหน้าต่างต่าง ๆ ในโหมด Window |
| `Return` | จับภาพหน้าต่างที่ไฮไลต์อยู่ |
| `Ctrl + A` | จับภาพจอภาพที่โฟกัสอยู่ทั้งจอ |
| `R` | เรียกคืนพื้นที่ล่าสุดที่วาดไว้ในเซสชันนี้ |
| `Esc` | ปิด Omasnap |

ปุ่มลัดเหล่านี้มีอยู่เฉพาะขณะที่ Omasnap เปิดอยู่เท่านั้น ดังนั้นมันจะไม่ชนกับอะไรในการตั้งค่าของคุณเอง

## การบันทึกหน้าจอ

`Alt + Print Screen` จะเปิด _Trigger > Capture > Screenrecord_ ซึ่งจะถามว่าคุณต้องการอะไรในแทร็กเสียง: ไม่มีเสียง เสียงของเดสก์ท็อป เสียงเดสก์ท็อปร่วมกับไมโครโฟน หรือเสียงเดสก์ท็อปร่วมกับไมโครโฟนและเว็บแคม ตัวเลือกสุดท้ายนั้นจะแสดงขึ้นมาก็ต่อเมื่อคุณเสียบกล้องไว้จริง ๆ เท่านั้น เลือกหนึ่งตัวเลือก แล้วตัวเลือกการบันทึกของ Omarchy จะให้คุณลากเลือกพื้นที่หรือคลิกที่หน้าต่างหรือจอภาพ

การบันทึกทำงานบน gpu-screen-recorder ซึ่งเข้ารหัสบน GPU ที่ 60fps และจะถอยกลับไปใช้ CPU หากจำเป็น ผลลัพธ์ที่ได้คือ MP4 ใน `~/Videos` ชื่อ `screenrecording-2026-08-13_14-22-05.mp4` ตั้งค่า `OMARCHY_SCREENRECORD_DIR` เพื่อเปลี่ยนตำแหน่งนั้น — แต่โปรดทราบว่าไดเรกทอรีนี้ไม่เหมือนกับไดเรกทอรีภาพหน้าจอตรงที่มันต้องมีอยู่แล้ว ไม่เช่นนั้นการบันทึกจะปฏิเสธที่จะเริ่ม

ขณะที่คุณกำลังบันทึก ตัวบ่งชี้เล็ก ๆ จะปรากฏขึ้นในแถบ คลิกที่มันเพื่อหยุด คุณยังสามารถหยุดด้วย `Alt + Print Screen` อีกครั้ง หรือด้วยรายการ _Stop Screenrecording_ ภายใต้ _Trigger > Capture > Screenrecord_ ซึ่งจะปรากฏเฉพาะขณะที่กำลังบันทึกบางอย่างอยู่จริงเท่านั้น

การหยุดจะเก็บงานเล็กน้อยก่อนส่งไฟล์ให้คุณ: เฟรมแรกจะถูกตัดออก และหากมีเสียง เสียงจะถูกปรับให้เป็นมาตรฐานที่ -14 LUFS พร้อมกับเสียงป๊อปจากการจับเสียงของ PipeWire ในตอนต้นสุดถูกปิดเสียงไป จากนั้นการแจ้งเตือนจะปรากฏขึ้นพร้อมภาพขนาดย่อจากการบันทึก คลิกที่มันเพื่อเล่นไฟล์ใน mpv

### โอเวอร์เลย์เว็บแคม

เมื่อคุณบันทึกด้วยเว็บแคม กล้องจะปรากฏเป็นหน้าต่างแนวตั้งที่ถูกปักหมุดและครอบตัดไว้ที่มุมล่างขวาของสิ่งที่คุณกำลังบันทึก หากมันบังสิ่งที่คุณต้องการอยู่ ให้ปรับขนาดมันได้ทันที:

| ปุ่มลัด | ฟังก์ชัน |
| ------ | -------- |
| `Super + Alt + [` | ทำให้โอเวอร์เลย์เว็บแคมเล็กลง |
| `Super + Alt + ]` | ทำให้โอเวอร์เลย์เว็บแคมใหญ่ขึ้น |

มีสามขนาด — เล็ก กลาง และใหญ่ — และปุ่มลัดจะเลื่อนไปมาระหว่างขนาดเหล่านี้ ขนาดกลางเป็นค่าเริ่มต้น ขนาดเหล่านี้เป็นสัดส่วนกับการบันทึก ดังนั้นกล้องจะกินพื้นที่ในเฟรมในสัดส่วนเดียวกันไม่ว่าคุณจะบันทึกจอภาพ 1080p หรือจอภาพ 6K และหากคุณบันทึกพื้นที่หนึ่งแทนที่จะเป็นทั้งจอ โอเวอร์เลย์จะยึดกับมุมของพื้นที่นั้นแทนที่จะเป็นมุมของจอภาพ ดังนั้นมันจะอยู่ภายในภาพเสมอ

คุณยังสามารถเรียกใช้โดยตรงด้วย `omarchy-capture-webcam-resize small` หรือ `reset` เพื่อกลับไปยังขนาดกลางได้

## ข้อความ, QR codes และสี

`Super + Ctrl + Print Screen` จะเลือกพื้นที่และ OCR มันไปยังคลิปบอร์ด เรื่องนี้ครอบคลุมอย่างเหมาะสมใน [การแยกข้อความและการพูดเพื่อพิมพ์](11-text-extraction-dictation.md)

_Trigger > Capture > QR Code_ ทำเทคนิคเดียวกันสำหรับ QR codes เลือกพื้นที่ที่มีรหัสอยู่ แล้วค่าที่ถอดรหัสได้จะไปยังคลิปบอร์ด มันมองหาเฉพาะ QR codes เท่านั้น — มิฉะนั้นเนื้อหาบนหน้าจอที่หนาแน่นมักจะถูกตรวจจับผิดเป็นบาร์โค้ด รู้ไว้ด้วยว่า: ค่าที่ถอดรหัสได้จะไปยังคลิปบอร์ดและไม่ไปที่อื่นเลย มันจะไม่ถูกพิมพ์ออกมา จะไม่อยู่ในการแจ้งเตือน และถูกทำเครื่องหมายว่าเป็นข้อมูลอ่อนไหวเพื่อไม่ให้มันค้างอยู่ใน [ประวัติคลิปบอร์ด](08-unified-clipboard-history.md) QR codes มักบรรจุความลับอยู่เป็นประจำ — URI `otpauth://` ที่อยู่เบื้องหลังรหัสตั้งค่า 2FA เป็นตัวอย่างหนึ่ง — และคุณไม่ต้องการให้สิ่งนั้นอยู่ในบันทึก การวางยังคงทำงานได้ตามปกติ

`Super + Print Screen` (หรือ _Trigger > Capture > Color_) จะเปลี่ยนเคอร์เซอร์ให้เป็นหลอดหยดสี คลิกอะไรก็ได้บนหน้าจอแล้วสีนั้นจะลงไปอยู่ในคลิปบอร์ด กดปุ่มลัดอีกครั้งเพื่อถอยออกโดยไม่เลือกสี

## การแปลงไฟล์ก่อนแชร์

การบันทึกหน้าจอระดับ 4K หรือ HEIC ดิบจากโทรศัพท์ของคุณมักมีขนาดใหญ่เกินกว่าจะส่งไปเฉย ๆ `Super + Ctrl + .` (หรือ _Trigger > Transcode_) จะแก้ปัญหานั้น มันจะเสนอตัวเลือกไฟล์แบบค้นหาคลุมเครือทั่วทั้ง `~/Pictures` และ `~/Videos` ให้คุณ จากนั้นจะถามถึงรูปแบบและขนาด

ภาพจะแปลงไปเป็น jpg หรือ png ที่ระดับสูง กลาง หรือต่ำ ซึ่งจำกัดความกว้างไว้ที่ 3160, 2160 และ 1080 พิกเซล วิดีโอจะแปลงไปเป็น mp4 หรือ gif แบบเคลื่อนไหวที่ 4k, 1080p หรือ 720p ไฟล์ที่แปลงแล้วจะถูกเขียนไว้ข้างไฟล์ต้นฉบับโดยมีความละเอียดอยู่ในชื่อ — `demo-1080p.mp4` — และพาธจะถูกคัดลอกไปยังคลิปบอร์ดเป็น URI ของไฟล์ ดังนั้นคุณจึงวางมันลงในแอปที่รับการวางไฟล์ได้โดยตรง

มันทำงานจากเทอร์มินัลด้วยเช่นกัน หากคุณรู้อยู่แล้วว่าต้องการอะไร: `omarchy transcode ~/Videos/demo.mov mp4 1080p` นอกจากนี้ยังมี `omarchy transcode ascii` ซึ่งเปลี่ยนภาพให้เป็นศิลปะ ASCII — อันนั้นส่วนใหญ่ไว้สำหรับ [การสร้างแบรนด์](41-branding.md)
