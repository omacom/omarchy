# ภาพหน้าจอและการบันทึกหน้าจอ

ทุกอย่างที่คุณจับภาพจากหน้าจอได้ผูกอยู่กับปุ่ม Print Screen ทั้งหมด กดปุ่มเดียวเปล่า ๆ จะถ่ายภาพ ส่วนปุ่มเสริมจะใช้บันทึก เลือกสี หรือดึงข้อความในพื้นที่ที่เลือก ถ้าคีย์บอร์ดของคุณไม่มีปุ่ม Print Screen เลย `Super + Ctrl + Alt + C` จะถ่ายภาพหน้าจอแบบเดียวกัน และ `Super + Ctrl + C` จะเปิดชุดเครื่องมือทั้งหมดเป็นเมนู

| ปุ่มลัด | ฟังก์ชัน |
| ------ | -------- |
| `Print Screen` | ภาพหน้าจอ |
| `Super + Ctrl + Alt + C` | ภาพหน้าจอ |
| `Alt + Print Screen` | บันทึกหน้าจอ (หรือหยุดการบันทึกที่กำลังทำอยู่) |
| `Super + Print Screen` | ตัวเลือกสี |
| `Super + Ctrl + Print Screen` | ดึงข้อความจากพื้นที่ที่เลือก |
| `Super + Ctrl + C` | เมนูจับภาพ |
| `Super + Ctrl + .` | แปลงไฟล์ภาพหรือวิดีโอ |

## ภาพหน้าจอ

กด `Print Screen` (หรือ `Super + Ctrl + Alt + C`) แล้ว Omasnap จะจับภาพจอที่โฟกัสอยู่ก่อนที่โอเวอร์เลย์ของมันจะปรากฏ ดังนั้นจะไม่มีอะไรเลื่อนไปใต้ตัวคุณระหว่างที่คุณเล็ง ลากเลือกพื้นที่แบบอิสระ คลิกหน้าต่างเพื่อจับภาพหน้าต่างนั้น หรือคลิกพื้นที่ว่างเพื่อจับภาพทั้งจอ กด `S` ก่อนลากเพื่อจับภาพพื้นที่แบบเลื่อนได้ เปลี่ยนใจแล้วเหรอ? กดปุ่มเดิมอีกครั้งเพื่อปิด Omasnap

หลังจากคุณเลือกพื้นที่แล้ว Omasnap จะบันทึกภาพที่จับไว้ คัดลอกไปยังคลิปบอร์ด และแสดงการแจ้งเตือนพร้อมภาพขนาดย่อ เหมือนที่การบันทึกหน้าจอที่บันทึกไว้ทำ เลือก Open เพื่อดูภาพที่บันทึกไว้ในโปรแกรมดูภาพของคุณ หรือ Edit เพื่อใส่คำอธิบายประกอบ

โปรแกรมแก้ไขคำอธิบายประกอบสามารถวาดลูกศร เส้น รูปร่าง ไฮไลต์ เครื่องหมายตัวเลข ข้อความ และการปกปิดข้อมูลอย่างปลอดภัย ครอบตัดหรือตัดส่วนของภาพออก OCR ข้อความในภาพ และเพิ่มฉากหลังได้ ในโปรแกรมแก้ไข กด `Enter` เพื่อคัดลอกและบันทึก PNG ที่เสร็จแล้ว กด `Ctrl + C` เพื่อคัดลอกโดยไม่บันทึก หรือกด `Ctrl + S` เพื่อบันทึกโดยไม่คัดลอก

ภาพหน้าจอที่บันทึกไว้จะอยู่ใน `~/Pictures/Screenshots` โดยค่าเริ่มต้น โดยมีชื่อเช่น `screenshot-2026-08-13_14-22-05-firefox.png` ตั้งค่า `OMASNAP_SCREENSHOT_DIR` เพื่อใช้ไดเรกทอรีอื่น — ดู [คำถามที่พบบ่อย](46-faq.md) สำหรับที่ที่ควรใส่ตัวแปรสภาพแวดล้อมของเซสชัน Omasnap จะสร้างไดเรกทอรีเมื่อบันทึกภาพแรก ตั้งค่า `[output] autosave = false` ใน `~/.config/omasnap/omasnap.conf` เพื่อปิดการบันทึกอัตโนมัติ จากนั้นภาพที่จับจะถูกคัดลอกเท่านั้น และแสดงในตัวอย่างเป็นเวลา 7 วินาที ซึ่งคุณสามารถตรึงไว้บนหน้าจอด้วยปุ่มปักหมุดหรือ `Ctrl + P` ได้

จากเทอร์มินัล `omarchy screenshot` จะเปิดโอเวอร์เลย์เดียวกัน และคุณสามารถเลือกโหมดเริ่มต้นได้: `omarchy capture screenshot region`, `windows`, `fullscreen`, หรือ `scroll` อาร์กิวเมนต์ที่สองเป็น `copy` หรือ `save` จะส่งภาพไปยังปลายทางนั้นโดยตรง หากต้องการแก้ไขก่อนส่งออก ให้ใช้ `omarchy screenshot --editor=overlay` สำหรับโปรแกรมแก้ไขแบบเต็มจอ หรือ `omarchy screenshot --editor=window` สำหรับหน้าต่างแยกต่างหาก

### การควบคุมตัวเลือกด้วยคีย์บอร์ด

ขณะที่ตัวเลือกแสดงอยู่ คุณไม่จำเป็นต้องใช้เมาส์เลย:

| ปุ่ม | ฟังก์ชัน |
| --- | -------- |
| `S` | สลับโหมดพื้นที่แบบเลื่อนได้ |
| `Super + Arrow keys` | เลื่อนไปมาระหว่างหน้าต่างในโหมด Window |
| `Return` | จับภาพหน้าต่างที่ไฮไลต์ไว้ |
| `Ctrl + A` | จับภาพจอที่โฟกัสอยู่ทั้งจอ |
| `R` | คืนค่าพื้นที่สุดท้ายที่วาดในเซสชันนี้ |
| `Esc` | ปิด Omasnap |

การผูกปุ่มเหล่านี้จะมีอยู่เฉพาะขณะที่ Omasnap เปิดอยู่เท่านั้น จึงไม่ชนกับอะไรใน config ของคุณเอง

## การบันทึกหน้าจอ

`Alt + Print Screen` จะเปิด _Trigger > Capture > Screenrecord_ ซึ่งจะถามว่าคุณต้องการอะไรในซาวด์แทร็ก: ไม่มีเสียง เสียงเดสก์ท็อป เสียงเดสก์ท็อปบวกไมโครโฟน หรือเสียงเดสก์ท็อปบวกไมโครโฟนบวกเว็บแคม ตัวเลือกสุดท้ายนั้นจะแสดงขึ้นมาก็ต่อเมื่อคุณเสียบกล้องไว้จริง ๆ เท่านั้น เลือกหนึ่งตัวเลือกแล้วตัวเลือกการบันทึกของ Omarchy จะให้คุณลากเลือกพื้นที่หรือคลิกหน้าต่างหรือจอภาพ

การบันทึกทำงานบน gpu-screen-recorder ซึ่งเข้ารหัสบน GPU ที่ 60fps และจะถอยกลับไปใช้ CPU หากจำเป็น บน GPU ที่มันไม่รองรับ เช่นของ Apple Silicon Omarchy จะบันทึกด้วย wf-recorder แทน ผลลัพธ์จะเป็น MP4 ใน `~/Videos` ชื่อ `screenrecording-2026-08-13_14-22-05.mp4` ตั้งค่า `OMARCHY_SCREENRECORD_DIR` เพื่อเปลี่ยนที่นั้น — แต่โปรดทราบว่าไดเรกทอรีนี้ต่างจากไดเรกทอรีภาพหน้าจอตรงที่มันต้องมีอยู่แล้ว มิฉะนั้นการบันทึกจะปฏิเสธที่จะเริ่ม

ขณะที่คุณกำลังบันทึก ตัวบ่งชี้เล็ก ๆ จะปรากฏในแถบ คลิกมันเพื่อหยุด คุณยังสามารถหยุดด้วย `Alt + Print Screen` อีกครั้ง หรือด้วยรายการ _Stop Screenrecording_ ภายใต้ _Trigger > Capture > Screenrecord_ ซึ่งจะปรากฏเฉพาะขณะที่กำลังมีการบันทึกอยู่จริงเท่านั้น

การหยุดจะเก็บกวาดเล็กน้อยก่อนส่งไฟล์ให้คุณ: เฟรมแรกจะถูกตัดออก และหากมีเสียง เสียงจะถูกปรับให้เป็นมาตรฐานที่ -14 LUFS โดยเสียงป๊อปจากการจับภาพ PipeWire ตอนเริ่มต้นสุดจะถูกปิดเสียงออก จากนั้นการแจ้งเตือนจะปรากฏพร้อมภาพขนาดย่อจากการบันทึก เลือก _Open_ เพื่อเล่นไฟล์ใน Omaview หรือ _Cut_ เพื่อตัดมันใน Omacut

### โอเวอร์เลย์เว็บแคม

เมื่อคุณบันทึกด้วยเว็บแคม กล้องจะปรากฏเป็นหน้าต่างแนวตั้งที่ถูกตรึงและครอบตัดไว้ที่มุมล่างขวาของสิ่งที่คุณกำลังบันทึก หากมันบังสิ่งที่คุณต้องการอยู่ ให้ปรับขนาดมันได้ทันที:

| ปุ่มลัด | ฟังก์ชัน |
| ------ | -------- |
| `Super + Alt + [` | ทำให้โอเวอร์เลย์เว็บแคมเล็กลง |
| `Super + Alt + ]` | ทำให้โอเวอร์เลย์เว็บแคมใหญ่ขึ้น |

มีสามขนาด — เล็ก กลาง และใหญ่ — และปุ่มลัดจะสลับไปมาระหว่างขนาดเหล่านั้น ขนาดกลางเป็นค่าเริ่มต้น ขนาดเหล่านี้เป็นสัดส่วนกับการบันทึก ดังนั้นกล้องจะกินพื้นที่ในเฟรมในสัดส่วนเดียวกันไม่ว่าคุณจะบันทึกจอ 1080p หรือจอ 6K และหากคุณบันทึกพื้นที่แทนที่จะเป็นทั้งจอภาพ โอเวอร์เลย์จะยึดกับมุมของพื้นที่นั้นแทนที่จะเป็นมุมของจอภาพ ดังนั้นมันจะอยู่ภายในภาพเสมอ

คุณยังสามารถเรียกมันโดยตรงด้วย `omarchy-capture-webcam-resize small` หรือ `reset` เพื่อกลับไปยังขนาดกลาง

## ข้อความ, QR code และสี

`Super + Ctrl + Print Screen` จะเลือกพื้นที่และ OCR มันไปยังคลิปบอร์ด เรื่องนั้นครอบคลุมอย่างเหมาะสมใน [การดึงข้อความและการพูดเพื่อพิมพ์](11-text-extraction-dictation.md)

_Trigger > Capture > QR Code_ ทำเคล็ดลับเดียวกันสำหรับ QR code เลือกพื้นที่ที่มี code อยู่ในนั้น แล้วค่าที่ถอดรหัสแล้วจะไปยังคลิปบอร์ด มันจะมองหาเฉพาะ QR code เท่านั้น — ไม่อย่างนั้นเนื้อหาหน้าจอที่หนาแน่นมีนิสัยชอบตรวจจับผิดเป็นบาร์โค้ด ควรทราบไว้ว่า: ค่าที่ถอดรหัสแล้วจะไปยังคลิปบอร์ดและไม่ไปที่อื่นเลย มันจะไม่ถูกพิมพ์ออกมา ไม่อยู่ในการแจ้งเตือน และถูกทำเครื่องหมายว่าละเอียดอ่อนเพื่อไม่ให้มันติดอยู่ใน [ประวัติคลิปบอร์ด](08-unified-clipboard-history.md) QR code มักบรรจุความลับเป็นประจำ — URI `otpauth://` ที่อยู่เบื้องหลัง code ตั้งค่า 2FA เป็นต้น — และคุณไม่ต้องการให้สิ่งนั้นอยู่ในบันทึก การวางยังคงทำงานได้ดี

`Super + Print Screen` (หรือ _Trigger > Capture > Color_) จะเปลี่ยนเคอร์เซอร์เป็นหลอดหยดสี คลิกอะไรก็ได้บนหน้าจอแล้วสีจะลงบนคลิปบอร์ด กดปุ่มลัดอีกครั้งเพื่อถอนตัวออกโดยไม่เลือก

## การแปลงไฟล์ก่อนที่คุณจะแชร์

การบันทึกหน้าจอ 4K หรือ HEIC ดิบจากโทรศัพท์ของคุณมักใหญ่เกินกว่าจะส่งไปได้เลย `Super + Ctrl + .` (หรือ _Trigger > Transcode_) แก้ปัญหานั้น มันเสนอตัวเลือกไฟล์แบบ fuzzy บน `~/Pictures` และ `~/Videos` จากนั้นจะถามรูปแบบและขนาด

ภาพจะแปลงเป็น jpg หรือ png ที่ระดับสูง กลาง หรือต่ำ ซึ่งจำกัดความกว้างไว้ที่ 3160, 2160 และ 1080 พิกเซล วิดีโอจะแปลงเป็น mp4 หรือ gif แบบเคลื่อนไหวที่ 4k, 1080p หรือ 720p ไฟล์ที่แปลงแล้วจะถูกเขียนไว้ข้างไฟล์ต้นฉบับโดยมีความละเอียดอยู่ในชื่อ — `demo-1080p.mp4` — และพาธจะถูกคัดลอกไปยังคลิปบอร์ดเป็น file URI ดังนั้นคุณจึงวางมันลงในแอปที่รับการวางไฟล์ได้โดยตรง

มันทำงานจากเทอร์มินัลได้เช่นกัน หากคุณรู้อยู่แล้วว่าต้องการอะไร: `omarchy transcode ~/Videos/demo.mov mp4 1080p` นอกจากนี้ยังมี `omarchy transcode ascii` ซึ่งเปลี่ยนภาพให้เป็น ASCII art — อันนั้นส่วนใหญ่ใช้สำหรับ [การสร้างแบรนด์](41-branding.md)

## การส่งมันไปที่ใดที่หนึ่ง

เมื่อคุณได้ไฟล์แล้ว `Super + Ctrl + S` จะเปิดเมนู Share และส่งมันไปยังอุปกรณ์อื่นบนเครือข่ายของคุณผ่าน LocalSend ดู [GUIs](22-guis.md) สำหรับเรื่องนั้น
