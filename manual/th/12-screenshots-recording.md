# ภาพหน้าจอและการบันทึกหน้าจอ

ทุกอย่างที่คุณจับภาพจากหน้าจอได้ผูกอยู่กับปุ่ม Print Screen ทั้งหมด ปุ่มเดียวล้วน ๆ ถ่ายภาพ และปุ่มเสริมต่าง ๆ จะทำการบันทึก จับสี หรือดึงข้อความภายในพื้นที่ที่เลือก ถ้าแป้นพิมพ์ของคุณไม่มีปุ่ม Print Screen เลย `Super + Ctrl + Alt + C` จะถ่ายภาพหน้าจอแบบเดียวกัน และ `Super + Ctrl + C` จะเปิดชุดเครื่องมือทั้งหมดขึ้นมาเป็นเมนู

| Hotkey | Function |
| ------ | -------- |
| `Print Screen` | ภาพหน้าจอ |
| `Super + Ctrl + Alt + C` | ภาพหน้าจอ |
| `Alt + Print Screen` | บันทึกหน้าจอ (หรือหยุดการบันทึกที่กำลังทำอยู่) |
| `Super + Print Screen` | ตัวหยิบสี |
| `Super + Ctrl + Print Screen` | ดึงข้อความจากพื้นที่ที่เลือก |
| `Super + Ctrl + C` | เมนูจับภาพ |
| `Super + Ctrl + .` | แปลงไฟล์รูปภาพหรือวิดีโอ |

## ภาพหน้าจอ

กด `Print Screen` (หรือ `Super + Ctrl + Alt + C`) แล้ว Omasnap จะจับภาพจอที่โฟกัสอยู่ก่อนที่โอเวอร์เลย์ของมันจะปรากฏขึ้น ดังนั้นจะไม่มีอะไรขยับใต้ตัวคุณขณะที่คุณเล็ง ลากพื้นที่แบบอิสระ คลิกที่หน้าต่างเพื่อจับภาพหน้าต่างนั้น หรือคลิกพื้นที่ว่างเพื่อจับภาพทั้งจอ กด `S` ก่อนลากเพื่อจับภาพพื้นที่แบบเลื่อนได้ เปลี่ยนใจแล้วหรือ? กดปุ่มเดิมอีกครั้งเพื่อปิด Omasnap

หลังจากที่คุณเลือกพื้นที่แล้ว Omasnap จะบันทึกภาพที่จับไว้ คัดลอกไปยังคลิปบอร์ด และแสดงการแจ้งเตือนพร้อมภาพขนาดย่อของมัน เหมือนที่การบันทึกหน้าจอที่บันทึกไว้ทำ เลือก Open เพื่อดูภาพที่บันทึกไว้ในโปรแกรมดูรูปภาพของคุณ หรือ Edit เพื่อใส่คำอธิบายประกอบลงไป

โปรแกรมแก้ไขคำอธิบายประกอบสามารถวาดลูกศร เส้น รูปทรง ไฮไลต์ เครื่องหมายตัวเลข ข้อความ และการปกปิดข้อมูลอย่างปลอดภัย ครอบตัดหรือตัดบางส่วนของภาพออก OCR ข้อความในภาพ และเพิ่มฉากหลังได้ ในโปรแกรมแก้ไข กด `Enter` เพื่อคัดลอกและบันทึก PNG ที่เสร็จแล้ว กด `Ctrl + C` เพื่อคัดลอกโดยไม่บันทึก หรือกด `Ctrl + S` เพื่อบันทึกโดยไม่คัดลอก

ภาพหน้าจอที่บันทึกไว้จะอยู่ใน `~/Pictures/Screenshots` ตามค่าเริ่มต้น โดยมีชื่ออย่างเช่น `screenshot-2026-08-13_14-22-05-firefox.png` ตั้งค่า `OMASNAP_SCREENSHOT_DIR` เพื่อใช้ไดเรกทอรีอื่น — ดู [คำถามที่พบบ่อย](46-faq.md) สำหรับที่ที่จะใส่ตัวแปรสภาพแวดล้อมของเซสชัน Omasnap จะสร้างไดเรกทอรีเมื่อมันบันทึกภาพแรก ตั้งค่า `[output] autosave = false` ใน `~/.config/omasnap/omasnap.conf` เพื่อปิดการบันทึกอัตโนมัติ จากนั้นภาพที่จับไว้จะถูกคัดลอกเท่านั้น และแสดงในตัวอย่างเป็นเวลา 10 วินาที ซึ่งคุณสามารถตรึงไว้บนหน้าจอด้วยปุ่มปักหมุดของมันหรือ `Ctrl + P`

จากเทอร์มินัล `omarchy screenshot` จะเปิดโอเวอร์เลย์เดียวกัน และคุณสามารถเลือกโหมดเริ่มต้นของมันได้: `omarchy capture screenshot region`, `windows`, `fullscreen` หรือ `scroll` อาร์กิวเมนต์ที่สองเป็น `copy` หรือ `save` จะส่งภาพไปยังปลายทางนั้นโดยตรง หากต้องการแก้ไขก่อนส่งออก ให้ใช้ `omarchy screenshot --editor=overlay` สำหรับโปรแกรมแก้ไขแบบเต็มจอ หรือ `omarchy screenshot --editor=window` สำหรับหน้าต่างแยกต่างหาก

### ควบคุมตัวเลือกด้วยแป้นพิมพ์

ขณะที่ส่วนการเลือกแสดงอยู่ คุณไม่จำเป็นต้องใช้เมาส์เลย:

| Key | Function |
| --- | -------- |
| `S` | สลับโหมดพื้นที่แบบเลื่อนได้ |
| `Super + Arrow keys` | ย้ายระหว่างหน้าต่างในโหมด Window |
| `Return` | จับภาพหน้าต่างที่ไฮไลต์ไว้ |
| `Ctrl + A` | จับภาพจอที่โฟกัสอยู่ทั้งจอ |
| `R` | คืนค่าพื้นที่ล่าสุดที่ลากในเซสชันนี้ |
| `Esc` | ปิด Omasnap |

การผูกปุ่มเหล่านี้มีอยู่เฉพาะขณะที่ Omasnap เปิดอยู่เท่านั้น ดังนั้นมันจึงไม่มีทางไปชนกับอะไรใน config ของคุณเอง

## การบันทึกหน้าจอ

`Alt + Print Screen` จะเปิด _Trigger > Capture > Screenrecord_ ซึ่งจะถามว่าคุณต้องการอะไรในซาวด์แทร็ก: ไม่มีเสียง เสียงของเดสก์ท็อป เสียงของเดสก์ท็อปพร้อมไมโครโฟน หรือเสียงของเดสก์ท็อปพร้อมไมโครโฟนพร้อมเว็บแคม ตัวเลือกสุดท้ายนั้นจะปรากฏขึ้นก็ต่อเมื่อคุณเสียบกล้องไว้จริง ๆ เท่านั้น เลือกหนึ่งตัวเลือก แล้วตัวเลือกการบันทึกของ Omarchy จะให้คุณลากพื้นที่ หรือคลิกที่หน้าต่างหรือจอภาพ

การบันทึกทำงานบน gpu-screen-recorder ซึ่งเข้ารหัสบน GPU ที่ 60fps และจะถอยกลับไปใช้ CPU ถ้าจำเป็น ผลลัพธ์ที่ได้คือ MP4 ใน `~/Videos` ชื่อว่า `screenrecording-2026-08-13_14-22-05.mp4` ตั้งค่า `OMARCHY_SCREENRECORD_DIR` เพื่อเปลี่ยนที่นั้น — แต่โปรดทราบว่าไดเรกทอรีนี้ต่างจากไดเรกทอรีภาพหน้าจอตรงที่มันต้องมีอยู่แล้ว ไม่อย่างนั้นการบันทึกจะปฏิเสธที่จะเริ่ม

ขณะที่คุณกำลังบันทึก ตัวบ่งชี้เล็ก ๆ จะปรากฏขึ้นในแถบ คลิกที่มันเพื่อหยุด คุณยังสามารถหยุดด้วย `Alt + Print Screen` อีกครั้ง หรือด้วยรายการ _Stop Screenrecording_ ใต้ _Trigger > Capture > Screenrecord_ ซึ่งจะปรากฏขึ้นเฉพาะขณะที่กำลังมีการบันทึกอะไรอยู่จริง ๆ เท่านั้น

การหยุดจะจัดการเก็บกวาดเล็กน้อยก่อนส่งไฟล์ให้คุณ: เฟรมแรกจะถูกตัดออก และถ้ามีเสียง เสียงจะถูกปรับให้เป็นปกติที่ -14 LUFS พร้อมเสียงป๊อปจากการจับภาพของ PipeWire ที่อยู่ตอนเริ่มต้นสุดถูกปิดเสียงออกไป จากนั้นการแจ้งเตือนจะปรากฏขึ้นพร้อมภาพขนาดย่อจากการบันทึก คลิกที่มันเพื่อเล่นไฟล์ใน mpv

### โอเวอร์เลย์เว็บแคม

เมื่อคุณบันทึกด้วยเว็บแคม กล้องจะปรากฏเป็นหน้าต่างแนวตั้งที่ถูกตรึงและครอบตัดไว้ที่มุมล่างขวาของสิ่งที่คุณกำลังบันทึก ถ้ามันบังอะไรที่คุณต้องการอยู่ ให้ปรับขนาดมันได้ทันที:

| Hotkey | Function |
| ------ | -------- |
| `Super + Alt + [` | ทำให้โอเวอร์เลย์เว็บแคมเล็กลง |
| `Super + Alt + ]` | ทำให้โอเวอร์เลย์เว็บแคมใหญ่ขึ้น |

มีสามขนาด — เล็ก กลาง และใหญ่ — และปุ่มลัดจะเลื่อนขั้นระหว่างขนาดเหล่านั้น กลางเป็นค่าเริ่มต้น ขนาดเหล่านี้เป็นสัดส่วนกับการบันทึก ดังนั้นกล้องจะกินพื้นที่ในเฟรมในสัดส่วนเดียวกันไม่ว่าคุณจะกำลังบันทึกจอ 1080p หรือจอ 6K และถ้าคุณบันทึกเป็นพื้นที่แทนที่จะเป็นทั้งจอแสดงผล โอเวอร์เลย์จะยึดกับมุมของพื้นที่นั้นแทนที่จะเป็นมุมของจอ ดังนั้นมันจะอยู่ภายในภาพเสมอ

คุณยังสามารถเรียกมันโดยตรงด้วย `omarchy-capture-webcam-resize small` หรือ `reset` เพื่อกลับไปเป็นขนาดกลาง

## ข้อความ, QR codes และสี

`Super + Ctrl + Print Screen` จะเลือกพื้นที่และ OCR มันไปยังคลิปบอร์ด เรื่องนั้นครอบคลุมไว้อย่างเหมาะสมใน [การดึงข้อความและการพิมพ์ด้วยเสียง](11-text-extraction-dictation.md)

_Trigger > Capture > QR Code_ ทำเคล็ดลับเดียวกันสำหรับ QR codes เลือกพื้นที่ที่มีโค้ดอยู่ในนั้น แล้วค่าที่ถอดรหัสได้จะไปยังคลิปบอร์ด มันมองหาเฉพาะ QR codes เท่านั้น — ไม่อย่างนั้นเนื้อหาบนหน้าจอที่หนาแน่นมักจะถูกตรวจจับผิดเป็นบาร์โค้ด ควรทราบไว้ว่า: ค่าที่ถอดรหัสได้จะไปยังคลิปบอร์ดและไม่ไปที่อื่นเลย มันจะไม่ถูกพิมพ์ออกมา มันจะไม่อยู่ในการแจ้งเตือน และมันถูกทำเครื่องหมายว่าเป็นข้อมูลละเอียดอ่อนเพื่อไม่ให้มันค้างอยู่ใน [ประวัติคลิปบอร์ด](08-unified-clipboard-history.md) QR codes มักพกพาความลับเป็นประจำ — `otpauth://` URI ที่อยู่เบื้องหลังโค้ดตั้งค่า 2FA เป็นตัวอย่างหนึ่ง — และคุณไม่ต้องการให้สิ่งนั้นอยู่ในบันทึก การวางยังคงทำงานได้ตามปกติ

`Super + Print Screen` (หรือ _Trigger > Capture > Color_) จะเปลี่ยนเคอร์เซอร์ให้เป็นหลอดหยดสี คลิกอะไรก็ได้บนหน้าจอ แล้วสีจะไปยังคลิปบอร์ด กดปุ่มลัดอีกครั้งเพื่อถอยออกโดยไม่ต้องหยิบสี

## การแปลงไฟล์ก่อนแชร์

การบันทึกหน้าจอ 4K หรือ HEIC ดิบจากโทรศัพท์ของคุณมักใหญ่เกินกว่าจะส่งไปได้เลย `Super + Ctrl + .` (หรือ _Trigger > Transcode_) แก้ปัญหานั้น มันจะเสนอตัวเลือกไฟล์แบบค้นหาคลุมเครือเหนือ `~/Pictures` และ `~/Videos` ให้คุณ จากนั้นจะถามถึงรูปแบบและขนาด

รูปภาพจะกลายเป็น jpg หรือ png ที่ระดับสูง กลาง หรือต่ำ ซึ่งจำกัดความกว้างไว้ที่ 3160, 2160 และ 1080 pixels วิดีโอจะกลายเป็น mp4 หรือ gif แบบเคลื่อนไหวที่ 4k, 1080p หรือ 720p ไฟล์ที่แปลงแล้วจะถูกเขียนไว้ข้างไฟล์ต้นฉบับโดยมีชื่อความละเอียดอยู่ในชื่อ — `demo-1080p.mp4` — และพาธจะถูกคัดลอกไปยังคลิปบอร์ดเป็น file URI ดังนั้นคุณจึงวางมันลงในแอปที่รับการลากไฟล์วางได้โดยตรง

มันทำงานจากเทอร์มินัลได้ด้วย ถ้าคุณรู้อยู่แล้วว่าต้องการอะไร: `omarchy transcode ~/Videos/demo.mov mp4 1080p` นอกจากนี้ยังมี `omarchy transcode ascii` ซึ่งเปลี่ยนรูปภาพให้เป็น ASCII art — อันนั้นส่วนใหญ่ใช้สำหรับ [การสร้างแบรนด์](41-branding.md)
