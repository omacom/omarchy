# จอภาพ

Omarchy ถือว่าคุณใช้จอระดับ retina ที่ทำ 2x ได้เป็นค่าเริ่มต้น นี่คือสิ่งที่คุณต้องมีเพื่อให้ได้ฟอนต์สำหรับโปรแกรมเมอร์ที่สวยและคมชัด เป็นจอแบบที่แล็ปท็อประดับพรีเมียมรุ่นใหม่เกือบทั้งหมดที่มีหน้าจอความละเอียดสูงได้รับการปรับแต่งมาให้ใช้ เป็นจอแบบที่คุณอยากใช้กับจอ 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) หรือ 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/)

แต่ถ้าคุณไม่ได้ใช้จอที่มี PPI ตั้งแต่ 218 ขึ้นไป คุณจะต้องเปลี่ยนการตั้งค่าจอภาพ ตัวอย่างเช่น หากคุณมีจอ 27" หรือ 32" 4K คุณสามารถใช้การปรับสเกลแบบเศษส่วนได้โดยเปิด `~/.config/hypr/monitors.lua` (ผ่าน _Setup > Monitors_ ในเมนู Omarchy) แล้วสลับไปใช้ค่าที่แนะนำสำหรับชุดนั้น:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

หากคุณใช้จอ 1080p หรือ 1440p คุณอาจอยากใช้การปรับสเกลแบบ 1x มากกว่า ดังนั้นคุณสามารถใช้:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

การเปลี่ยนแปลง `GDK_SCALE` จะมีผลกับแอปพลิเคชันที่เริ่มทำงานหลังจากการเปลี่ยนแปลง (และ GTK ยอมรับเฉพาะจำนวนเต็มเท่านั้น ดังนั้นให้ตั้งไว้ที่จำนวนเต็มที่ใกล้เคียงที่สุดกับสเกลของจอของคุณ) ดังนั้นอย่าลืมปิดหน้าต่างที่มีขนาดใหญ่เกินไปหลังการเปลี่ยนแปลง (หรือปิดหน้าต่างทั้งหมดด้วย `Ctrl + Alt + Del`!)

คุณยังสามารถเลื่อนผ่านอัตราส่วนการปรับสเกลจอหลัก ๆ ได้อย่างรวดเร็ว (1x, 1.25x, 1.6x, 2x, 3x, 4x) โดยใช้ `Super + /` เพื่อเพิ่ม และ `Super + Alt + /` เพื่อลด หรือเลือกจากแผงจอภาพในแถบด้านบน สิ่งเหล่านี้เปลี่ยนเฉพาะจอที่คุณกำลังโฟกัสอยู่เท่านั้น ดังนั้นหน้าจอแล็ปท็อปและจอภายนอกจึงมีสเกลของตัวเองได้ ตัวเลือกจะถูกบันทึกไปที่ `~/.config/hypr/monitors.lua` ในรูปแบบกฎ `hl.monitor` สำหรับจอนั้น ดังนั้นจึงคงอยู่หลังรีบูต และมีผลเหนือกว่า `omarchy_monitor_scale` ซึ่งยังคงเป็นสเกลสำหรับทุกจอที่ไม่มีกฎของตัวเอง เนื่องจาก `GDK_SCALE` เป็นค่าเดียวสำหรับทุกหน้าจอ การเปลี่ยนแปลงเหล่านี้จึงตั้งค่าจากจอที่มีสเกลต่ำที่สุด ดังนั้นแอป X11 จึงออกมาเล็กไปหน่อยบนจอที่หนาแน่นกว่า แทนที่จะใหญ่เกินไปบนอีกจอหนึ่ง

### การทำให้ข้อความใหญ่ขึ้นหรือเล็กลง

การปรับสเกลจอจะเปลี่ยนขนาดของทุกอย่าง หากคุณต้องการแค่ข้อความที่ใหญ่ขึ้นหรือเล็กลง มีปุ่มปรับเพียงปุ่มเดียวสำหรับเรื่องนั้น:

```
omarchy display text size 14
```

คำสั่งนั้นรับขนาดพิกเซลระหว่าง 9 ถึง 20 และปรับเชลล์ของ Omarchy, แอปพลิเคชัน GTK และเทอร์มินัลของคุณไปพร้อมกัน ดังนั้นเดสก์ท็อปทั้งหมดจึงคงสัดส่วนไว้ได้ รันโดยไม่ใส่ argument เพื่อดูว่าคุณอยู่ที่เท่าใด และใช้ `omarchy display text size reset` เพื่อกลับไปเป็นค่าเริ่มต้น Foot คือตัวเดียวที่ตามไม่ทัน: มันไม่มีวิธีโหลดการตั้งค่าใหม่ ดังนั้นเทอร์มินัลที่กำลังทำงานอยู่จะยังคงขนาดเดิมไว้จนกว่าคุณจะเปิดอันใหม่

### การขยายและมิเรอร์จอแล็ปท็อป

เมื่อคุณเชื่อมต่อจอภายนอกกับแล็ปท็อป จอจะถูกขยายโดยอัตโนมัติ แต่คุณสามารถเปลี่ยนเป็นการมิเรอร์แทนได้โดยใช้ _Trigger > Hardware_ ในเมนู Omarchy หรือ `Super + Ctrl + Alt + Delete` สิ่งนี้มีประโยชน์เป็นพิเศษหากจอภายนอกนั้นเป็นโปรเจกเตอร์ และคุณต้องการแสดงบางสิ่งในขณะที่ทำงาน

เมื่อคุณกำลังขยาย การปิดฝาแล็ปท็อปจะปิดหน้าจอภายในโดยอัตโนมัติ การเปิดฝาจะเปิดกลับมาอีกครั้ง คุณยังสามารถควบคุมสิ่งนี้ด้วยตนเองได้โดยใช้ _Trigger > Hardware_ ในเมนู Omarchy หรือ `Super + Ctrl + Delete`

### การจัดวางหลายหน้าจอ

Hyprland ทำงานได้เยี่ยมกับหลายหน้าจอ อ่านเพิ่มเติมเกี่ยวกับวิธีจัดวางจอได้ใน [เอกสารเรื่องจอภาพของ Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/) ใน Omarchy สิ่งเหล่านี้อยู่ใน `~/.config/hypr/monitors.lua` ในรูปแบบรายการ `hl.monitor` — ไฟล์นี้มาพร้อมตัวอย่างที่คอมเมนต์ไว้สำหรับการกำหนดจอใดจอหนึ่งโดยเฉพาะให้ใช้ความละเอียด ตำแหน่ง และการหมุน

ทุกจอมี workspace 1 ถึง 10 เป็นของตัวเอง ดังนั้น `Super + 1` จึงหมายถึง workspace แรกของจอที่คุณอยู่เสมอ เบื้องหลัง Hyprland ยังคงกำหนดหมายเลข workspace ข้ามจอทั้งหมด: หน้าจอแล็ปท็อปของคุณ (หรือจอแรก) ได้ 1–10 จอถัดไปได้ 11–20 และต่อไปเรื่อย ๆ และแต่ละจอจะเก็บบล็อกของมันไว้ทุกครั้งที่คุณเสียบเข้าไป ใช้หมายเลขเหล่านั้นหากคุณเขียน [กฎ workspace](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) หรือกฎหน้าต่างสำหรับจอใดจอหนึ่งโดยเฉพาะ ดังนั้น workspace 12 คือ workspace ที่สองของจอที่สองของคุณ `~/.local/state/omarchy/monitor-workspaces` แสดงรายการว่าจอแต่ละจอมีบล็อกใด

ปุ่มลูกศรทำงานข้ามจอที่มีขอบร่วมกันในเลย์เอาต์ของคุณ จอที่สัมผัสกันแค่ที่มุม หรือมีช่องว่างระหว่างกัน ไม่ถือเป็นจอข้างเคียง ดังนั้นให้ใช้ `Ctrl + Alt + Tab` เพื่อย้ายไปมาระหว่างจอเหล่านั้น

| ปุ่มลัด | ข้ามจอภาพ |
| --- | --- |
| `Super + Arrow` | ย้ายโฟกัสไปยังจอบนด้านนั้นเมื่อไม่มีหน้าต่างเหลือในทิศทางนั้นอีกต่อไป |
| `Super + Shift + Arrow` | สลับกับหน้าต่างบนจอบนด้านนั้น |
| `Super + Alt + Arrow` | ย้ายหน้าต่างไปอยู่ในกลุ่มบนจอบนด้านนั้น |
| `Super + Shift + Ctrl + Arrow` | ย้ายหน้าต่างไปยังจอบนด้านนั้น ไปยัง workspace ที่จอนั้นกำลังแสดงอยู่ |
| `Super + Shift + Alt + Arrow` | ย้าย workspace ไปยังจอบนด้านนั้น โดยคงหมายเลขเดิมไว้หากว่างอยู่ |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | ย้ายโฟกัสไปยังจอถัดไปหรือจอก่อนหน้า ไม่ว่าเลย์เอาต์จะเป็นอย่างไร |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | อยู่บนจอที่คุณอยู่ |

คุณยังสามารถดู [Hyprmon](https://github.com/erans/hyprmon/) ได้ หากคุณต้องการ TUI เพื่อช่วยคุณจัดตำแหน่งหลายหน้าจอ

### การควบคุมความสว่าง

ความสว่างของจอควบคุมด้วยปุ่มฟังก์ชันเฉพาะสำหรับเพิ่ม/ลดความสว่าง หากคุณกด Shift ค้างไว้ขณะกดปุ่มเหล่านี้ คุณจะไปที่ความสว่างสูงสุดหรือต่ำสุด ปุ่มเหล่านี้ควบคุมจอที่คุณกำลังโฟกัสอยู่ ดังนั้นจอภายนอกที่ใช้ DDC/CI จะถูกปรับในลักษณะเดียวกับหน้าจอแล็ปท็อป

### จอ Apple

หากคุณใช้จอ Apple ปุ่มความสว่างบนแป้นพิมพ์ปกติจะทำงานโดยอัตโนมัติเช่นกัน หากคุณกำลังโฟกัสที่จอ Apple สิ่งนี้ทำผ่านคำสั่ง `asdcontrol`

โปรดทราบว่าหากคุณใช้จอ Apple 6K XDR คุณอาจเห็นจอลวงในรายการ `hyprctl monitors` ของคุณ คุณสามารถปิดสิ่งนี้ได้ด้วยอะไรทำนอง `hl.monitor({ output = "DP-2", disabled = true })` ผ่าน _Setup > Monitors_

บนเครื่อง Intel คุณควรเชื่อมต่อกับจอ Apple โดยใช้สาย Thunderbolt ธรรมดา บนเครื่องอื่นที่ไม่มี Thunderbolt โดยทั่วไปคุณจะต้องใช้ [สาย DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) เพื่อให้มันทำงานได้
