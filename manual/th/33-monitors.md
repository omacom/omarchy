# จอภาพ

Omarchy สมมติว่าคุณกำลังรันบนจอแสดงผลระดับเรตินาที่ทำ 2x ได้เป็นค่าเริ่มต้น นี่คือสิ่งที่คุณต้องการเพื่อให้ได้ฟอนต์โปรแกรมเมอร์ที่คมชัดสวยงามเหล่านั้น มันคือสิ่งที่แล็ปท็อปพรีเมียมรุ่นใหม่แทบทั้งหมดที่มีหน้าจอความละเอียดสูงปรับให้เหมาะ มันคือสิ่งที่คุณอยากจะรันบน 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) หรือ 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/)

แต่ถ้าคุณไม่ได้รันจอแสดงผลที่มี PPI 218 ขึ้นไป คุณควรเปลี่ยนการตั้งค่าจอภาพ ตัวอย่างเช่น ถ้าคุณมี 27" หรือ 32" 4K คุณสามารถใช้การปรับขนาดแบบเศษส่วนโดยเปิด `~/.config/hypr/monitors.lua` (ผ่าน _ตั้งค่า > จอภาพ_ ในเมนู Omarchy) แล้วสลับไปคำแนะนำสำหรับคอมโบนั้น:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

ถ้าคุณใช้จอแสดงผล 1080p หรือ 1440p คุณน่าจะแค่อยากใช้การปรับขนาด 1x ดังนั้นคุณจึงใช้:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

การเปลี่ยนแปลง `GDK_SCALE` มีผลกับแอปพลิเคชันที่เริ่มหลังการเปลี่ยนแปลง (และ GTK เคารพเฉพาะจำนวนเต็มเท่านั้น ดังนั้นให้เก็บมันที่จำนวนเต็มที่ใกล้เคียงที่สุดของสเกลจอภาพคุณ) ดังนั้นให้แน่ใจว่าคุณออกจากหน้าต่างที่คุณมีซึ่งใหญ่เกินไปหลังการเปลี่ยนแปลง (หรือปิดทุกหน้าต่างด้วย `Ctrl + Alt + Del`!)

คุณยังก้าวผ่านอัตราส่วนการปรับขนาดจอภาพหลัก ๆ (1x, 1.25x, 1.6x, 2x, 3x, 4x) ได้อย่างรวดเร็วโดยใช้ `Super + /` เพื่อสูงขึ้นและ `Super + Alt + /` เพื่อต่ำลง ถ้าคุณมีการกำหนดค่าเริ่มต้น การเปลี่ยนแปลงเหล่านี้จะคงอยู่เลยจากการรีบูตด้วยเช่นกัน

### ทำให้ข้อความใหญ่ขึ้นหรือเล็กลง

การปรับขนาดจอภาพเปลี่ยนขนาดของทุกอย่าง ถ้าสิ่งที่คุณต้องการมีแค่ _ข้อความ_ ที่ใหญ่ขึ้นหรือเล็กลง ก็มีปุ่มเดียวสำหรับเรื่องนั้น:

```
omarchy display text size 14
```

นั่นรับขนาดพิกเซลระหว่าง 9 ถึง 20 และย้าย shell ของ Omarchy แอปพลิเคชัน GTK และเทอร์มินัลของคุณไปด้วยกัน ดังนั้นทั้งเดสก์ท็อปจึงยังได้สัดส่วน รันมันโดยไม่มีอาร์กิวเมนต์เพื่อดูว่าคุณอยู่ที่ไหน และ `omarchy display text size reset` เพื่อกลับไปค่าเริ่มต้น Foot คือตัวล้าหลังตัวเดียว มันไม่มีวิธีโหลดคอนฟิกซ้ำ ดังนั้นเทอร์มินัลที่รันอยู่จึงเก็บขนาดเก่าไว้จนกว่าคุณจะเปิดอันใหม่

### ขยายและสะท้อนจอแสดงผลแล็ปท็อป

เมื่อคุณเชื่อมต่อหน้าจอภายนอกเข้ากับแล็ปท็อปของคุณ จอแสดงผลจะถูกขยายโดยอัตโนมัติ แต่คุณสามารถเปลี่ยนไปเป็นการสะท้อนแทนได้โดยใช้ _สั่งการ > ฮาร์ดแวร์_ ในเมนู Omarchy หรือ `Super + Ctrl + Alt + Delete` สิ่งนี้มีประโยชน์เป็นพิเศษถ้าหน้าจอภายนอกนั้นคือโปรเจ็กเตอร์ และคุณอยากแสดงอะไรบางอย่างขณะทำงาน

เมื่อคุณกำลังขยาย การปิดฝาบนแล็ปท็อปจะปิดหน้าจอภายในโดยอัตโนมัติ การเปิดฝาจะเปิดมันกลับมาอีกครั้ง คุณยังควบคุมสิ่งนี้ด้วยมือโดยใช้ _สั่งการ > ฮาร์ดแวร์_ ในเมนู Omarchy หรือ `Super + Ctrl + Delete` ได้ด้วย

### จัดเรียงหลายหน้าจอ

Hyprland ทำงานได้ดีกับหลายหน้าจอ อ่านเพิ่มเติมเกี่ยวกับวิธีจัดวางพวกมันได้ใน [เอกสารจอภาพ Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/) คุณสามารถ [ผูกพื้นที่งานเฉพาะเข้ากับจอภาพเฉพาะ](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) ได้เช่นกัน ใน Omarchy กฎเหล่านี้อยู่ใน `~/.config/hypr/monitors.lua` ในฐานะรายการ `hl.monitor` — ไฟล์นี้มาพร้อมตัวอย่างที่คอมเมนต์ไว้สำหรับการปักจอภาพเฉพาะให้กับความละเอียด ตำแหน่ง และการหมุน

คุณยังลองดู [Hyprmon](https://github.com/erans/hyprmon/) ได้ด้วย ถ้าคุณอยากได้ TUI ช่วยวางตำแหน่งหลายหน้าจอ

### ควบคุมความสว่าง

ความสว่างจอภาพควบคุมโดยปุ่มฟังก์ชันเฉพาะสำหรับเพิ่ม/ลดความสว่าง ถ้าคุณกด shift ค้างไว้ขณะกด คุณจะไปความสว่างสูงสุดหรือต่ำสุด ปุ่มต่าง ๆ ควบคุมจอแสดงผลที่คุณโฟกัสอยู่ ดังนั้นจอภายนอกที่พูด DDC/CI ก็ปรับในวิธีเดียวกันกับหน้าจอแล็ปท็อป

### จอแสดงผล Apple

ถ้าคุณใช้จอแสดงผล Apple ปุ่มความสว่างคีย์บอร์ดปกติก็จะทำงานโดยอัตโนมัติด้วยเช่นกัน ถ้าคุณโฟกัสบนจอแสดงผล Apple สิ่งนี้ทำผ่านคำสั่ง `asdcontrol`

โปรดทราบว่าถ้าคุณใช้จอแสดงผล Apple 6K XDR คุณอาจเห็นหน้าจอหลอนในรายการ `hyprctl monitors` ของคุณ คุณสามารถปิดสิ่งนี้ได้ด้วยอะไรอย่าง `hl.monitor({ output = "DP-2", disabled = true })` ผ่าน _ตั้งค่า > จอภาพ_

บนเครื่อง Intel คุณควรเชื่อมต่อเข้ากับจอแสดงผล Apple โดยใช้สาย Thunderbolt ปกติ บนเครื่องอื่นที่ไม่มี Thunderbolt คุณมักจะต้องใช้ [สาย DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) เพื่อให้มันทำงาน
