# จอภาพ

โดยค่าเริ่มต้น Omarchy จะถือว่าคุณกำลังใช้จอระดับ retina ที่รองรับการสเกลแบบ 2x นี่คือสิ่งที่คุณต้องการเพื่อให้ได้ฟอนต์สำหรับโปรแกรมเมอร์ที่สวยและคมชัด นี่คือสิ่งที่แล็ปท็อประดับพรีเมียมรุ่นใหม่เกือบทั้งหมดที่มีหน้าจอความละเอียดสูงได้รับการปรับแต่งมาให้เหมาะสม นี่คือสิ่งที่คุณอยากใช้บนจอ 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) หรือจอ 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/)

แต่ถ้าคุณไม่ได้ใช้จอที่มี PPI ตั้งแต่ 218 ขึ้นไป คุณจะต้องเปลี่ยนการตั้งค่าจอภาพ ตัวอย่างเช่น หากคุณมีจอ 4K ขนาด 27" หรือ 32" คุณสามารถเลือกการสเกลแบบเศษส่วนให้กับจอนั้นได้จากแผงจอภาพในแถบด้านบน หรือตั้งค่าเริ่มต้นสำหรับทุกจอโดยเปิด `~/.config/hypr/monitors.lua` แล้วเปลี่ยนไปใช้ค่าที่แนะนำสำหรับชุดจอนั้น:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

หากคุณใช้จอ 1080p หรือ 1440p คุณอาจอยากใช้การสเกลแบบ 1x ไปเลย รวมถึงใช้แบบเดียวกันกับแอป GTK และ X11 ด้วย ดังนั้นคุณสามารถใช้ได้ดังนี้:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

การเปลี่ยนแปลง `GDK_SCALE` จะมีผลกับแอปพลิเคชันที่เริ่มทำงานหลังจากการเปลี่ยนแปลงเท่านั้น (และ GTK รองรับเฉพาะจำนวนเต็ม ดังนั้นให้ตั้งไว้ที่จำนวนเต็มที่ใกล้เคียงที่สุดกับสเกลของจอภาพคุณ) ดังนั้นอย่าลืมปิดหน้าต่างที่มีขนาดใหญ่เกินไปหลังจากเปลี่ยนแปลง (หรือปิดทุกหน้าต่างด้วย `Ctrl + Alt + Del`!)

คุณยังสามารถเลื่อนผ่านอัตราส่วนการสเกลหลักของจอภาพ (1x, 1.25x, 1.6x, 2x, 3x, 4x) ได้อย่างรวดเร็วโดยใช้ `Super + /` เพื่อเพิ่ม และ `Super + Alt + /` เพื่อลด หรือเลือกจากแผงจอภาพในแถบด้านบน การเปลี่ยนแปลงเหล่านี้จะมีผลเฉพาะกับจอที่คุณกำลังโฟกัสอยู่ ดังนั้นหน้าจอแล็ปท็อปและจอภายนอกจึงมีสเกลของตัวเองได้ แผงนี้ยังตั้งค่าความละเอียด อัตราการรีเฟรช และการหมุนของแต่ละจออีกด้วย ตัวเลือกของคุณจะถูกบันทึกไว้สำหรับจอภาพเครื่องนั้นใน `~/.local/state/omarchy/monitors/settings` ดังนั้นจึงคงอยู่หลังจากรีบูต และตามจอภาพไปยังพอร์ตหรือด็อกใดก็ตามที่เสียบในครั้งต่อไป ตัวเลือกเหล่านี้จะมีผลเหนือกฎใดๆ สำหรับจอเดียวกันใน `~/.config/hypr/monitors.lua` ซึ่ง Omarchy จะไม่เข้าไปแก้ไข หากคุณต้องการตั้งค่าจอภาพทั้งหมดในไฟล์นั้น ให้เพิ่ม `omarchy_monitor_panel_settings = false` ลงไป และการเปลี่ยนแปลงจากแผงจะมีผลจนกว่า Hyprland จะโหลดใหม่เท่านั้น เนื่องจาก `GDK_SCALE` เป็นค่าเดียวสำหรับทุกหน้าจอ สเกลที่เลือกจะถูกตั้งจากจอที่มีสเกลต่ำที่สุด ดังนั้นแอป X11 จะออกมาเล็กไปเล็กน้อยบนจอที่หนาแน่นกว่า แทนที่จะใหญ่เกินไปบนอีกจอหนึ่ง

### ปรับขนาดตัวอักษรให้ใหญ่ขึ้นหรือเล็กลง

การสเกลจอภาพจะเปลี่ยนขนาดของทุกอย่าง หากสิ่งที่คุณต้องการมีเพียงตัวอักษรที่ใหญ่ขึ้นหรือเล็กลง ก็มีปุ่มปรับเพียงอย่างเดียวสำหรับสิ่งนั้น:

```
omarchy display text size 14
```

คำสั่งนี้รับขนาดเป็นพิกเซลระหว่าง 9 ถึง 20 และจะปรับ Omarchy shell, แอปพลิเคชัน GTK และเทอร์มินัลของคุณไปพร้อมกัน เพื่อให้เดสก์ท็อปทั้งหมดยังคงได้สัดส่วนที่เหมาะสม เรียกใช้โดยไม่ระบุอาร์กิวเมนต์เพื่อดูว่าคุณกำลังใช้ขนาดใดอยู่ และใช้ `omarchy display text size reset` เพื่อกลับไปใช้ค่าเริ่มต้น Foot เป็นตัวเดียวที่ตามไม่ทัน: มันไม่มีวิธีโหลดการตั้งค่าใหม่ ดังนั้นเทอร์มินัลที่กำลังทำงานอยู่จะยังคงใช้ขนาดเดิมจนกว่าคุณจะเปิดอันใหม่

### การขยายและการมิเรอร์จอแล็ปท็อป

เมื่อคุณเชื่อมต่อหน้าจอภายนอกเข้ากับแล็ปท็อปของคุณ จอภาพจะถูกขยายโดยอัตโนมัติ แต่คุณสามารถเปลี่ยนเป็นการมิเรอร์แทนได้โดยใช้ _Trigger > Hardware_ ในเมนู Omarchy หรือ `Super + Ctrl + Alt + Delete` วิธีนี้มีประโยชน์เป็นพิเศษหากหน้าจอภายนอกนั้นเป็นโปรเจกเตอร์ และคุณต้องการแสดงบางอย่างในขณะที่กำลังทำงาน

เมื่อคุณกำลังขยายจอ การปิดฝาแล็ปท็อปจะปิดหน้าจอภายในโดยอัตโนมัติ การเปิดฝาจะเปิดกลับขึ้นมาอีกครั้ง คุณยังสามารถควบคุมสิ่งนี้ได้ด้วยตนเองโดยใช้ _Trigger > Hardware_ ในเมนู Omarchy หรือ `Super + Ctrl + Delete`

### การจัดเรียงหลายหน้าจอ

Hyprland ทำงานได้ยอดเยี่ยมกับหลายหน้าจอ แผงจอภาพในแถบด้านบนจะวาดจอเหล่านั้นตามตำแหน่งที่ตั้งอยู่จริง: ลากจอหนึ่งไปแนบกับด้านข้างของอีกจอหนึ่งเพื่อย้ายไปไว้ตรงนั้น และการจัดเรียงจะถูกบันทึกไว้พร้อมกับการตั้งค่าอื่นๆ ของแต่ละจอ สำหรับสิ่งใดก็ตามที่แผงไม่ครอบคลุม อ่านเพิ่มเติมเกี่ยวกับวิธีจัดวางได้ใน [เอกสารจอภาพของ Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/) ใน Omarchy สิ่งเหล่านี้จะอยู่ใน `~/.config/hypr/monitors.lua` ในรูปแบบรายการ `hl.monitor` — ไฟล์นี้มาพร้อมตัวอย่างที่คอมเมนต์ไว้สำหรับปิดจอ, โหมดที่แผงไม่มีให้เลือก, สี 10-bit และอัตราการรีเฟรชแบบแปรผัน

จอภาพทุกจอมีเวิร์กสเปซ 1 ถึง 10 เป็นของตัวเอง ดังนั้น `Super + 1` จึงหมายถึงเวิร์กสเปซแรกของจอที่คุณกำลังใช้งานอยู่เสมอ เบื้องหลัง Hyprland ยังคงกำหนดหมายเลขเวิร์กสเปซข้ามทุกจอ: หน้าจอแล็ปท็อปของคุณ (หรือจอแรก) จะได้ 1–10, จอถัดไปได้ 11–20 และต่อไปเรื่อยๆ และแต่ละจอจะคงบล็อกของตัวเองไว้ทุกครั้งที่คุณเสียบกลับเข้ามา ใช้หมายเลขเหล่านั้นหากคุณเขียน [กฎเวิร์กสเปซ](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) หรือกฎหน้าต่างสำหรับจอใดจอหนึ่งเป็นการเฉพาะ ดังนั้นเวิร์กสเปซ 12 จึงเป็นเวิร์กสเปซที่สองของจอที่สองของคุณ `~/.local/state/omarchy/monitors/workspaces` จะแสดงรายการว่าจอแต่ละจอมีบล็อกใด

ปุ่มลูกศรจะทำงานข้ามจอภาพที่แชร์ขอบร่วมกันในเลย์เอาต์ของคุณ หน้าจอที่เพียงสัมผัสกันที่มุม หรือมีช่องว่างระหว่างกัน จะไม่ถือว่าเป็นจอที่อยู่ติดกัน ดังนั้นให้ใช้ `Ctrl + Alt + Tab` เพื่อสลับไปมาระหว่างจอเหล่านั้น

| ปุ่มลัด | ข้ามจอภาพ |
| --- | --- |
| `Super + Arrow` | ย้ายโฟกัสไปยังจอภาพด้านนั้นเมื่อไม่มีหน้าต่างเหลืออยู่ในทิศทางนั้นอีกต่อไป |
| `Super + Shift + Arrow` | สลับกับหน้าต่างบนจอภาพด้านนั้น |
| `Super + Alt + Arrow` | ย้ายหน้าต่างเข้าไปในกลุ่มบนจอภาพด้านนั้น |
| `Super + Shift + Ctrl + Arrow` | ย้ายหน้าต่างไปยังจอภาพด้านนั้น ไปยังเวิร์กสเปซที่จอนั้นกำลังแสดงอยู่ |
| `Super + Shift + Alt + Arrow` | ย้ายเวิร์กสเปซไปยังจอภาพด้านนั้น โดยคงหมายเลขเดิมไว้หากว่างอยู่ |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | ย้ายโฟกัสไปยังจอภาพถัดไปหรือก่อนหน้า ไม่ว่าเลย์เอาต์จะเป็นอย่างไร |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | คงอยู่บนจอภาพที่คุณกำลังใช้งานอยู่ |

คุณยังสามารถลองดู [Hyprmon](https://github.com/erans/hyprmon/) ได้ หากคุณต้องการ TUI มาช่วยในการจัดตำแหน่งหลายหน้าจอ

### การควบคุมความสว่าง

ความสว่างของจอภาพควบคุมด้วยปุ่มฟังก์ชันเฉพาะสำหรับเพิ่ม/ลดความสว่าง หากคุณกด Shift ค้างไว้ขณะกดปุ่มเหล่านี้ คุณจะไปที่ความสว่างสูงสุดหรือต่ำสุด ปุ่มเหล่านี้จะควบคุมจอที่คุณกำลังโฟกัสอยู่ ดังนั้นจอภายนอกที่สื่อสารผ่าน DDC/CI จึงถูกปรับในลักษณะเดียวกับหน้าจอแล็ปท็อป

### จอภาพ Apple

หากคุณใช้จอภาพ Apple ปุ่มความสว่างบนคีย์บอร์ดทั่วไปจะทำงานโดยอัตโนมัติเช่นกัน หากคุณกำลังโฟกัสอยู่ที่จอภาพ Apple การทำงานนี้ทำผ่านคำสั่ง `asdcontrol`

โปรดทราบว่าหากคุณใช้จอภาพ Apple 6K XDR คุณอาจเห็นหน้าจอหลอกในรายการ `hyprctl monitors` ของคุณ คุณสามารถปิดได้ด้วยคำสั่งอย่างเช่น `hl.monitor({ output = "DP-2", disabled = true })` ใน `~/.config/hypr/monitors.lua`

บนเครื่อง Intel คุณควรเชื่อมต่อกับจอภาพ Apple โดยใช้สาย Thunderbolt ทั่วไป บนเครื่องอื่นๆ ที่ไม่มี Thunderbolt โดยทั่วไปคุณจะต้องใช้ [สาย DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) เพื่อให้ใช้งานได้
