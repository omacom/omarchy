# จอภาพ

Omarchy ถือว่าคุณกำลังใช้จอแสดงผลระดับ retina ที่รองรับ 2x เป็นค่าเริ่มต้น นี่คือสิ่งที่คุณต้องมีเพื่อให้ได้ฟอนต์สำหรับโปรแกรมเมอร์ที่สวยและคมชัดเหล่านั้น มันคือสิ่งที่แล็ปท็อประดับพรีเมียมรุ่นใหม่เกือบทั้งหมดที่มีหน้าจอความละเอียดสูงได้รับการปรับแต่งมาให้ใช้ มันคือสิ่งที่คุณอยากใช้บนจอ 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) หรือ 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/)

แต่ถ้าคุณไม่ได้ใช้จอแสดงผลที่มี PPI ตั้งแต่ 218 ขึ้นไป คุณจะต้องเปลี่ยนการตั้งค่าจอภาพ ตัวอย่างเช่น ถ้าคุณมีจอ 4K ขนาด 27" หรือ 32" คุณสามารถเลือกสเกลแบบเศษส่วนให้จอนั้นได้จากแผงจอภาพในแถบด้านบน หรือตั้งค่าเริ่มต้นสำหรับทุกจอภาพโดยเปิด `~/.config/hypr/monitors.lua` แล้วเปลี่ยนไปใช้ค่าที่แนะนำสำหรับชุดจอนั้น:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

ถ้าคุณใช้จอแสดงผล 1080p หรือ 1440p คุณอาจอยากใช้สเกล 1x และใช้แบบเดียวกันสำหรับแอป GTK และ X11 คุณจึงใช้ได้ดังนี้:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

การเปลี่ยนแปลง `GDK_SCALE` จะมีผลกับแอปพลิเคชันที่เริ่มทำงานหลังจากการเปลี่ยนแปลง (และ GTK รองรับเฉพาะจำนวนเต็มเท่านั้น ดังนั้นให้ใช้จำนวนเต็มที่ใกล้เคียงที่สุดกับสเกลของจอภาพของคุณ) ดังนั้นอย่าลืมปิดหน้าต่างที่คุณเปิดไว้ซึ่งมีขนาดใหญ่เกินไปหลังจากการเปลี่ยนแปลง (หรือปิดหน้าต่างทั้งหมดด้วย `Ctrl + Alt + Del`!)

คุณยังสามารถไล่เปลี่ยนอัตราส่วนสเกลของจอภาพหลัก ๆ (1x, 1.25x, 1.6x, 2x, 3x, 4x) ได้อย่างรวดเร็วโดยใช้ `Super + /` เพื่อเพิ่ม และ `Super + Alt + /` เพื่อลด หรือเลือกจากแผงจอภาพในแถบด้านบน การเปลี่ยนแปลงเหล่านี้จะมีผลเฉพาะจอภาพที่คุณกำลังโฟกัสอยู่ ดังนั้นหน้าจอแล็ปท็อปและจอแสดงผลภายนอกจึงมีสเกลของตัวเองได้ แผงนี้ยังตั้งค่าความละเอียดของจอภาพแต่ละจอด้วย ตัวเลือกของคุณจะถูกบันทึกไว้สำหรับจอภาพทางกายภาพนั้นใน `~/.local/state/omarchy/monitors/settings` ดังนั้นจึงคงอยู่หลังการรีบูตและติดตามจอภาพไปยังพอร์ตหรือด็อกใดก็ตามที่คุณเสียบในครั้งต่อไป ตัวเลือกเหล่านี้มีความสำคัญเหนือกฎใด ๆ สำหรับจอภาพเดียวกันใน `~/.config/hypr/monitors.lua` ซึ่ง Omarchy ไม่เคยแก้ไข เนื่องจาก `GDK_SCALE` เป็นค่าเดียวสำหรับทุกหน้าจอ สเกลที่เลือกจะกำหนดค่าจากจอภาพที่มีสเกลต่ำที่สุด ดังนั้นแอป X11 จึงจะออกมาเล็กไปเล็กน้อยบนหน้าจอที่หนาแน่นกว่า แทนที่จะใหญ่เกินไปบนอีกจอหนึ่ง

### ทำให้ข้อความใหญ่ขึ้นหรือเล็กลง

สเกลของจอภาพเปลี่ยนขนาดของทุกอย่าง ถ้าสิ่งที่คุณต้องการมีแค่ข้อความที่ใหญ่ขึ้นหรือเล็กลง มีปุ่มปรับเพียงอย่างเดียวสำหรับสิ่งนั้น:

```
omarchy display text size 14
```

คำสั่งนี้รับขนาดเป็นพิกเซลระหว่าง 9 ถึง 20 และจะปรับเชลล์ของ Omarchy, แอปพลิเคชัน GTK และเทอร์มินัลของคุณไปด้วยกัน ดังนั้นเดสก์ท็อปทั้งหมดจึงคงสัดส่วนไว้ รันโดยไม่มีอาร์กิวเมนต์เพื่อดูว่าคุณอยู่ที่เท่าใด และใช้ `omarchy display text size reset` เพื่อกลับไปเป็นค่าเริ่มต้น Foot เป็นตัวเดียวที่ตามไม่ทัน: มันไม่มีวิธีโหลดการตั้งค่าใหม่ ดังนั้นเทอร์มินัลที่กำลังทำงานอยู่จะคงขนาดเดิมไว้จนกว่าคุณจะเปิดอันใหม่

### ขยายและทำมิเรอร์จอแสดงผลแล็ปท็อป

เมื่อคุณเชื่อมต่อหน้าจอภายนอกเข้ากับแล็ปท็อปของคุณ จอแสดงผลจะถูกขยายโดยอัตโนมัติ แต่คุณสามารถเปลี่ยนเป็นการทำมิเรอร์แทนได้โดยใช้ _Trigger > Hardware_ ในเมนู Omarchy หรือ `Super + Ctrl + Alt + Delete` สิ่งนี้มีประโยชน์เป็นพิเศษถ้าหน้าจอภายนอกนั้นเป็นโปรเจกเตอร์ และคุณต้องการแสดงบางอย่างในขณะที่ทำงาน

เมื่อคุณกำลังขยายจอแสดงผล การปิดฝาแล็ปท็อปจะปิดหน้าจอภายในโดยอัตโนมัติ การเปิดฝาจะเปิดมันกลับขึ้นมาอีกครั้ง คุณยังสามารถควบคุมสิ่งนี้ด้วยตนเองได้โดยใช้ _Trigger > Hardware_ ในเมนู Omarchy หรือ `Super + Ctrl + Delete`

### จัดเรียงหลายหน้าจอ

Hyprland ทำงานได้ดีเยี่ยมกับหลายหน้าจอ แผงจอภาพในแถบด้านบนจะวาดจอเหล่านั้นตามตำแหน่งที่ตั้งอยู่: ลากจอหนึ่งไปแนบกับด้านข้างของอีกจอเพื่อย้ายมันไปตรงนั้น และการจัดเรียงจะถูกบันทึกไว้พร้อมกับการตั้งค่าอื่น ๆ ของแต่ละจอภาพ สำหรับสิ่งใดก็ตามที่แผงไม่ครอบคลุม อ่านเพิ่มเติมเกี่ยวกับวิธีจัดวางได้ใน [เอกสารจอภาพของ Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/) ใน Omarchy สิ่งเหล่านี้จะอยู่ใน `~/.config/hypr/monitors.lua` เป็นรายการ `hl.monitor` — ไฟล์นี้มาพร้อมตัวอย่างที่คอมเมนต์ไว้สำหรับตรึงจอภาพเฉพาะเจาะจงไว้กับความละเอียด ตำแหน่ง และการหมุน

จอภาพทุกจอมีเวิร์กสเปซ 1 ถึง 10 เป็นของตัวเอง ดังนั้น `Super + 1` จึงหมายถึงเวิร์กสเปซแรกของจอภาพที่คุณอยู่เสมอ เบื้องหลัง Hyprland ยังคงกำหนดหมายเลขเวิร์กสเปซต่อเนื่องกันข้ามจอภาพทั้งหมด: หน้าจอแล็ปท็อปของคุณ (หรือจอภาพแรก) ได้ 1–10 จอภาพถัดไปได้ 11–20 และต่อไปแบบนี้ และแต่ละจอภาพจะเก็บบล็อกของตัวเองไว้ทุกครั้งที่คุณเสียบมันเข้าไป ใช้หมายเลขเหล่านี้ถ้าคุณเขียน [กฎเวิร์กสเปซ](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) หรือกฎหน้าต่างสำหรับจอภาพเฉพาะเจาะจง ดังนั้นเวิร์กสเปซ 12 คือเวิร์กสเปซที่สองของจอภาพที่สองของคุณ `~/.local/state/omarchy/monitors/workspaces` จะแสดงรายการว่าจอภาพแต่ละจอมีบล็อกใด

ปุ่มลูกศรทำงานข้ามจอภาพที่แชร์ขอบร่วมกันในเลย์เอาต์ของคุณ หน้าจอที่สัมผัสกันแค่ตรงมุม หรือมีช่องว่างระหว่างกัน จะไม่ถือว่าเป็นจอข้างเคียงกัน ดังนั้นให้ใช้ `Ctrl + Alt + Tab` เพื่อย้ายระหว่างจอเหล่านั้น

| ปุ่มลัด | ข้ามจอภาพ |
| --- | --- |
| `Super + Arrow` | ย้ายโฟกัสไปยังจอภาพในทิศทางนั้นเมื่อไม่มีหน้าต่างเหลืออยู่ในทิศทางนั้นอีกต่อไป |
| `Super + Shift + Arrow` | สลับกับหน้าต่างบนจอภาพในทิศทางนั้น |
| `Super + Alt + Arrow` | ย้ายหน้าต่างเข้าไปในกลุ่มบนจอภาพในทิศทางนั้น |
| `Super + Shift + Ctrl + Arrow` | ย้ายหน้าต่างไปยังจอภาพในทิศทางนั้น ไปยังเวิร์กสเปซที่แสดงอยู่ |
| `Super + Shift + Alt + Arrow` | ย้ายเวิร์กสเปซไปยังจอภาพในทิศทางนั้น โดยคงหมายเลขไว้ถ้าว่างอยู่ |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | ย้ายโฟกัสไปยังจอภาพถัดไปหรือก่อนหน้า ไม่ว่าเลย์เอาต์จะเป็นอย่างไร |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | อยู่บนจอภาพที่คุณอยู่ |

คุณยังสามารถลองดู [Hyprmon](https://github.com/erans/hyprmon/) ได้ หากคุณต้องการ TUI เพื่อช่วยในการจัดตำแหน่งหลายหน้าจอ

### ควบคุมความสว่าง

ความสว่างของจอภาพถูกควบคุมโดยปุ่มฟังก์ชันเฉพาะสำหรับเพิ่ม/ลดความสว่าง หากคุณกด Shift ค้างไว้ขณะที่กดปุ่มเหล่านี้ คุณจะไปยังความสว่างสูงสุดหรือต่ำสุด ปุ่มเหล่านี้ควบคุมจอแสดงผลที่คุณกำลังโฟกัสอยู่ ดังนั้นจอภาพภายนอกที่รองรับ DDC/CI จึงถูกปรับในแบบเดียวกับหน้าจอแล็ปท็อป

### จอแสดงผล Apple

หากคุณใช้จอแสดงผล Apple ปุ่มความสว่างบนแป้นพิมพ์ปกติจะทำงานโดยอัตโนมัติด้วยเช่นกัน หากคุณกำลังโฟกัสที่จอแสดงผล Apple สิ่งนี้ทำผ่านคำสั่ง `asdcontrol`

โปรดทราบว่าถ้าคุณใช้จอแสดงผล Apple 6K XDR คุณอาจเห็นหน้าจอหลอกในรายการ `hyprctl monitors` ของคุณ คุณสามารถปิดสิ่งนี้ได้ด้วยอะไรอย่างเช่น `hl.monitor({ output = "DP-2", disabled = true })` ใน `~/.config/hypr/monitors.lua`

บนเครื่อง Intel คุณควรเชื่อมต่อกับจอแสดงผล Apple โดยใช้สาย Thunderbolt ทั่วไป บนเครื่องอื่นที่ไม่มี Thunderbolt โดยทั่วไปคุณจะต้องใช้ [สาย DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) เพื่อให้ใช้งานได้
