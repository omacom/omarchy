# จอภาพ

โดยค่าเริ่มต้น Omarchy สันนิษฐานว่าคุณใช้จอภาพระดับ retina ที่รองรับ 2x นี่คือสิ่งที่คุณต้องมีเพื่อให้ได้ฟอนต์สำหรับโปรแกรมเมอร์ที่สวยและคมชัด นี่คือสิ่งที่แล็ปท็อประดับพรีเมียมรุ่นใหม่เกือบทั้งหมดพร้อมจอความละเอียดสูงถูกปรับให้เหมาะที่สุด นี่คือสิ่งที่คุณอยากใช้บน [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) ขนาด 27" ความละเอียด 5K หรือ [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) ขนาด 32" ความละเอียด 6K

แต่ถ้าคุณไม่ได้ใช้จอภาพที่มี PPI ตั้งแต่ 218 ขึ้นไป คุณจะต้องเปลี่ยนการตั้งค่าจอภาพ ตัวอย่างเช่น ถ้าคุณมีจอ 4K ขนาด 27" หรือ 32" คุณสามารถใช้การปรับสเกลแบบเศษส่วนได้โดยเปิด `~/.config/hypr/monitors.lua` (ผ่าน _Setup > Monitors_ ในเมนู Omarchy) แล้วเปลี่ยนไปใช้ค่าที่แนะนำสำหรับชุดนั้น:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

ถ้าคุณใช้จอภาพ 1080p หรือ 1440p คุณอาจอยากใช้การปรับสเกลแบบ 1x มากกว่า ดังนั้นคุณสามารถใช้:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

การเปลี่ยนแปลง `GDK_SCALE` จะมีผลกับแอปพลิเคชันที่เริ่มทำงานหลังจากการเปลี่ยนแปลง (และ GTK ยอมรับเฉพาะจำนวนเต็มเท่านั้น ดังนั้นให้ตั้งไว้ที่จำนวนเต็มที่ใกล้เคียงที่สุดกับสเกลของจอภาพคุณ) ดังนั้นอย่าลืมปิดหน้าต่างที่มีขนาดใหญ่เกินไปหลังจากการเปลี่ยนแปลง (หรือปิดทุกหน้าต่างด้วย `Ctrl + Alt + Del`!)

คุณยังสามารถไล่เปลี่ยนอัตราส่วนการปรับสเกลหลักของจอภาพ (1x, 1.25x, 1.6x, 2x, 3x, 4x) ได้อย่างรวดเร็วโดยใช้ `Super + /` เพื่อเพิ่ม และ `Super + Alt + /` เพื่อลด หรือเลือกค่าหนึ่งจากแผงจอภาพในแถบด้านบน การเปลี่ยนเหล่านี้จะมีผลเฉพาะจอภาพที่คุณกำลังโฟกัสอยู่เท่านั้น ดังนั้นจอแล็ปท็อปและจอภาพภายนอกจึงมีสเกลของตัวเองแยกกันได้ ตัวเลือกจะถูกบันทึกไปยัง `~/.config/hypr/monitors.lua` ในรูปแบบกฎ `hl.monitor` สำหรับจอภาพนั้น ดังนั้นจึงยังคงอยู่หลังรีบูต และมีความสำคัญเหนือกว่า `omarchy_monitor_scale` ซึ่งยังคงเป็นสเกลสำหรับทุกจอภาพที่ไม่มีกฎของตัวเอง

### การทำให้ตัวอักษรใหญ่ขึ้นหรือเล็กลง

การปรับสเกลจอภาพจะเปลี่ยนขนาดของทุกอย่าง ถ้าสิ่งที่คุณต้องการมีแค่ตัวอักษรที่ใหญ่ขึ้นหรือเล็กลง ก็มีปุ่มปรับเพียงอย่างเดียวสำหรับเรื่องนั้น:

```
omarchy display text size 14
```

คำสั่งนี้รับขนาดเป็นพิกเซลระหว่าง 9 ถึง 20 และจะปรับเชลล์ของ Omarchy, แอปพลิเคชัน GTK และเทอร์มินัลของคุณไปพร้อมกัน ดังนั้นเดสก์ท็อปทั้งหมดจึงคงสัดส่วนไว้ได้ รันคำสั่งโดยไม่ใส่ argument เพื่อดูว่าคุณอยู่ที่ค่าใด และใช้ `omarchy display text size reset` เพื่อกลับไปใช้ค่าเริ่มต้น Foot เป็นตัวเดียวที่ตามไม่ทัน: มันไม่มีวิธีโหลดการตั้งค่าใหม่ ดังนั้นเทอร์มินัลที่กำลังทำงานอยู่จะยังคงใช้ขนาดเดิมจนกว่าคุณจะเปิดอันใหม่

### การขยายและสะท้อนจอภาพแล็ปท็อป

เมื่อคุณเชื่อมต่อจอภายนอกเข้ากับแล็ปท็อป จอภาพจะถูกขยายโดยอัตโนมัติ แต่คุณสามารถเปลี่ยนเป็นการสะท้อนแทนได้โดยใช้ _Trigger > Hardware_ ในเมนู Omarchy หรือ `Super + Ctrl + Alt + Delete` วิธีนี้มีประโยชน์อย่างยิ่งถ้าจอภายนอกนั้นคือโปรเจกเตอร์ และคุณต้องการแสดงบางอย่างขณะทำงาน

เมื่อคุณกำลังขยายจอ การปิดฝาแล็ปท็อปจะปิดจอภายในโดยอัตโนมัติ การเปิดฝาจะเปิดมันกลับมาอีกครั้ง คุณยังสามารถควบคุมสิ่งนี้ด้วยตนเองได้โดยใช้ _Trigger > Hardware_ ในเมนู Omarchy หรือ `Super + Ctrl + Delete`

### การจัดวางหลายจอ

Hyprland ทำงานได้ยอดเยี่ยมกับหลายจอ อ่านเพิ่มเติมเกี่ยวกับวิธีจัดวางจอเหล่านี้ได้ใน [เอกสารจอภาพของ Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/) ใน Omarchy สิ่งเหล่านี้จะอยู่ใน `~/.config/hypr/monitors.lua` ในรูปแบบรายการ `hl.monitor` — ไฟล์นี้มาพร้อมตัวอย่างที่คอมเมนต์ไว้สำหรับการตรึงจอภาพเฉพาะเจาะจงไว้กับความละเอียด ตำแหน่ง และการหมุนหนึ่ง

ทุกจอภาพมี workspace 1 ถึง 10 ของตัวเอง ดังนั้น `Super + 1` จึงหมายถึง workspace แรกของจอภาพที่คุณอยู่เสมอ เบื้องหลัง Hyprland ยังคงกำหนดเลข workspace ข้ามจอภาพทั้งหมด: จอแล็ปท็อปของคุณ (หรือจอภาพแรก) จะได้ 1–10 จอภาพถัดไปจะได้ 11–20 และต่อไปแบบนี้ และทุกจอภาพจะรักษาช่วงของตัวเองไว้ทุกครั้งที่คุณเสียบมันเข้าไป ใช้ตัวเลขเหล่านี้ถ้าคุณเขียน [กฎ workspace](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) หรือกฎหน้าต่างสำหรับจอภาพเฉพาะเจาะจง ดังนั้น workspace 12 จึงเป็น workspace ที่สองของจอภาพที่สองของคุณ `~/.local/state/omarchy/monitor-workspaces` จะแสดงว่าจอภาพแต่ละจอมีช่วงใด

ปุ่มลูกศรทำงานข้ามจอภาพที่มีขอบร่วมกันในเลย์เอาต์ของคุณ จอที่สัมผัสกันเพียงตรงมุม หรือมีช่องว่างระหว่างกัน จะไม่ถือเป็นจอข้างเคียง ดังนั้นให้ใช้ `Ctrl + Alt + Tab` เพื่อสลับระหว่างจอเหล่านั้น

| ปุ่มลัด | ข้ามจอภาพ |
| --- | --- |
| `Super + Arrow` | ย้ายโฟกัสไปยังจอภาพด้านนั้น เมื่อไม่มีหน้าต่างเหลือในทิศทางนั้นแล้ว |
| `Super + Shift + Arrow` | สลับกับหน้าต่างบนจอภาพด้านนั้น |
| `Super + Alt + Arrow` | ย้ายหน้าต่างเข้าไปในกลุ่มบนจอภาพด้านนั้น |
| `Super + Shift + Ctrl + Arrow` | ย้ายหน้าต่างไปยังจอภาพด้านนั้น บน workspace ที่จอนั้นกำลังแสดงอยู่ |
| `Super + Shift + Alt + Arrow` | ย้าย workspace ไปยังจอภาพด้านนั้น โดยคงเลขเดิมไว้ถ้าว่างอยู่ |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | ย้ายโฟกัสไปยังจอภาพถัดไปหรือก่อนหน้า ไม่ว่าเลย์เอาต์จะเป็นอย่างไร |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | อยู่บนจอภาพที่คุณอยู่ |

คุณยังสามารถลองดู [Hyprmon](https://github.com/erans/hyprmon/) ได้เช่นกัน ถ้าคุณอยากได้ TUI มาช่วยจัดตำแหน่งหลายจอ

### การควบคุมความสว่าง

ความสว่างของจอภาพควบคุมด้วยปุ่มฟังก์ชันเฉพาะสำหรับเพิ่ม/ลดความสว่าง ถ้าคุณกด Shift ค้างไว้ขณะกดปุ่มเหล่านี้ คุณจะไปถึงความสว่างสูงสุดหรือต่ำสุด ปุ่มเหล่านี้ควบคุมจอภาพที่คุณกำลังโฟกัสอยู่ ดังนั้นจอภาพภายนอกที่สื่อสารด้วย DDC/CI จะถูกปรับในแบบเดียวกับจอแล็ปท็อป

### จอภาพ Apple

ถ้าคุณใช้จอภาพ Apple ปุ่มความสว่างบนคีย์บอร์ดทั่วไปก็จะทำงานโดยอัตโนมัติเช่นกัน ถ้าคุณกำลังโฟกัสอยู่ที่จอภาพ Apple อยู่ การทำงานนี้ทำผ่านคำสั่ง `asdcontrol`

โปรดทราบว่าถ้าคุณใช้จอภาพ Apple 6K XDR คุณอาจเห็นจอหลอกในรายการ `hyprctl monitors` ของคุณ คุณสามารถปิดสิ่งนี้ได้ด้วยอะไรอย่างเช่น `hl.monitor({ output = "DP-2", disabled = true })` ผ่าน _Setup > Monitors_

บนเครื่อง Intel คุณควรเชื่อมต่อกับจอภาพ Apple โดยใช้สาย Thunderbolt ทั่วไป บนเครื่องอื่นที่ไม่มี Thunderbolt โดยทั่วไปคุณจะต้องใช้ [สาย DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) เพื่อให้มันทำงานได้
