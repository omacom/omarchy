# จอภาพ

Omarchy สันนิษฐานไว้ก่อนว่าคุณใช้จอแสดงผลระดับ retina ที่รองรับ 2x เป็นค่าเริ่มต้น นี่คือสิ่งที่คุณต้องมีเพื่อให้ได้ฟอนต์สำหรับนักโปรแกรมที่สวยและคมชัด นี่คือสิ่งที่แล็ปท็อปรุ่นใหม่ระดับพรีเมียมเกือบทั้งหมดที่มีหน้าจอความละเอียดสูงได้รับการปรับแต่งมาให้ใช้ และนี่คือสิ่งที่คุณอยากใช้บนจอ 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) หรือ 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/)

แต่ถ้าคุณไม่ได้ใช้จอแสดงผลที่มี PPI ตั้งแต่ 218 ขึ้นไป คุณจะต้องเปลี่ยนการตั้งค่าจอภาพ ตัวอย่างเช่น ถ้าคุณมีจอ 4K ขนาด 27" หรือ 32" คุณสามารถใช้การปรับสเกลแบบเศษส่วนได้โดยเปิด `~/.config/hypr/monitors.lua` (ผ่าน _Setup > Monitors_ ในเมนู Omarchy) แล้วเปลี่ยนไปใช้ค่าที่แนะนำสำหรับชุดนั้น:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

ถ้าคุณใช้จอแสดงผล 1080p หรือ 1440p คุณน่าจะอยากใช้การปรับสเกลแบบ 1x มากกว่า ดังนั้นคุณสามารถใช้:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

การเปลี่ยนแปลง `GDK_SCALE` จะมีผลกับแอปพลิเคชันที่เปิดหลังจากการเปลี่ยนแปลงเท่านั้น (และ GTK รองรับเฉพาะจำนวนเต็ม ดังนั้นให้ตั้งไว้ที่จำนวนเต็มที่ใกล้เคียงที่สุดกับสเกลของจอภาพของคุณ) ดังนั้นอย่าลืมปิดหน้าต่างที่มีขนาดใหญ่เกินไปหลังจากการเปลี่ยนแปลง (หรือปิดหน้าต่างทั้งหมดด้วย `Ctrl + Alt + Del`!)

คุณยังสามารถไล่เปลี่ยนอัตราส่วนการปรับสเกลหลักของจอภาพ (1x, 1.25x, 1.6x, 2x, 3x, 4x) ได้อย่างรวดเร็วโดยใช้ `Super + /` เพื่อเพิ่ม และ `Super + Alt + /` เพื่อลด ถ้าคุณใช้การกำหนดค่าเริ่มต้น การเปลี่ยนแปลงเหล่านี้จะคงอยู่แม้รีบูตเครื่องแล้วก็ตาม

### ทำให้ตัวอักษรใหญ่ขึ้นหรือเล็กลง

การปรับสเกลจอภาพจะเปลี่ยนขนาดของทุกอย่าง ถ้าสิ่งที่คุณต้องการมีแค่ _ตัวอักษร_ ที่ใหญ่ขึ้นหรือเล็กลง ก็มีปุ่มปรับเพียงปุ่มเดียวสำหรับเรื่องนั้น:

```
omarchy display text size 14
```

คำสั่งนี้รับขนาดเป็นพิกเซลระหว่าง 9 ถึง 20 และจะปรับเชลล์ของ Omarchy, แอปพลิเคชัน GTK และเทอร์มินัลของคุณไปพร้อมกัน เพื่อให้เดสก์ท็อปทั้งหมดยังคงได้สัดส่วนที่เหมาะสม เรียกใช้โดยไม่ใส่ argument เพื่อดูว่าคุณกำลังใช้ค่าใดอยู่ และใช้ `omarchy display text size reset` เพื่อกลับไปใช้ค่าเริ่มต้น Foot เป็นตัวเดียวที่ตามไม่ทัน: มันไม่มีวิธีโหลดการกำหนดค่าใหม่ ดังนั้นเทอร์มินัลที่เปิดอยู่จะยังคงใช้ขนาดเดิมจนกว่าคุณจะเปิดเทอร์มินัลใหม่

### ขยายและมิเรอร์จอของแล็ปท็อป

เมื่อคุณเชื่อมต่อหน้าจอภายนอกเข้ากับแล็ปท็อป จอแสดงผลจะถูกขยายโดยอัตโนมัติ แต่คุณสามารถเปลี่ยนเป็นการมิเรอร์แทนได้โดยใช้ _Trigger > Hardware_ ในเมนู Omarchy หรือ `Super + Ctrl + Alt + Delete` ซึ่งมีประโยชน์เป็นพิเศษถ้าหน้าจอภายนอกนั้นเป็นโปรเจกเตอร์ และคุณต้องการแสดงบางอย่างในขณะที่ทำงานไปด้วย

เมื่อคุณกำลังขยายจอ การปิดฝาแล็ปท็อปจะปิดหน้าจอภายในโดยอัตโนมัติ การเปิดฝาจะเปิดหน้าจอกลับขึ้นมาอีกครั้ง คุณยังสามารถควบคุมเรื่องนี้ด้วยตัวเองได้โดยใช้ _Trigger > Hardware_ ในเมนู Omarchy หรือ `Super + Ctrl + Delete`

### จัดวางหลายจอ

Hyprland ทำงานได้ดีเยี่ยมกับหลายหน้าจอ อ่านเพิ่มเติมเกี่ยวกับวิธีจัดวางจอเหล่านี้ได้ใน [เอกสารเรื่องจอภาพของ Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/) ใน Omarchy สิ่งเหล่านี้จะอยู่ใน `~/.config/hypr/monitors.lua` ในรูปแบบรายการ `hl.monitor` — ไฟล์นี้มาพร้อมตัวอย่างที่ถูกคอมเมนต์ไว้สำหรับกำหนดจอภาพเฉพาะเจาะจงให้ใช้ความละเอียด ตำแหน่ง และการหมุนที่ระบุ

จอภาพแต่ละจอมี workspace 1 ถึง 10 เป็นของตัวเอง ดังนั้น `Super + 1` จึงหมายถึง workspace แรกของจอที่คุณกำลังอยู่เสมอ เบื้องหลัง Hyprland ยังคงกำหนดหมายเลข workspace ต่อเนื่องข้ามจอทั้งหมด: หน้าจอแล็ปท็อปของคุณ (หรือจอแรก) จะได้ 1–10 จอถัดไปจะได้ 11–20 และไล่ต่อไปเรื่อย ๆ และแต่ละจอจะเก็บกลุ่มหมายเลขของตัวเองไว้ทุกครั้งที่คุณเสียบจอนั้นเข้ามา ใช้หมายเลขเหล่านี้ถ้าคุณเขียน [กฎ workspace](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) หรือกฎหน้าต่างสำหรับจอใดจอหนึ่งโดยเฉพาะ เพื่อให้ workspace 12 เป็น workspace ที่สองของจอที่สองของคุณ `~/.local/state/omarchy/monitor-workspaces` จะแสดงรายการว่าจอแต่ละจอมีกลุ่มหมายเลขใด

ปุ่มลูกศรทำงานข้ามจอที่มีขอบร่วมกันในเลย์เอาต์ของคุณ จอที่เพียงสัมผัสกันที่มุม หรือมีช่องว่างระหว่างกัน ไม่ถือว่าเป็นจอข้างเคียง ดังนั้นให้ใช้ `Ctrl + Alt + Tab` เพื่อไปยังจอเหล่านั้น

| ปุ่มลัด | ข้ามจอ |
| --- | --- |
| `Super + Arrow` | ย้ายโฟกัสไปยังจอในทิศทางนั้น เมื่อไม่มีหน้าต่างเหลือในทิศทางนั้นอีกแล้ว |
| `Super + Shift + Arrow` | สลับกับหน้าต่างบนจอในทิศทางนั้น |
| `Super + Alt + Arrow` | ย้ายหน้าต่างเข้าไปในกลุ่มบนจอในทิศทางนั้น |
| `Super + Shift + Ctrl + Arrow` | ย้ายหน้าต่างไปยังจอในทิศทางนั้น บน workspace ที่จอนั้นกำลังแสดงอยู่ |
| `Super + Shift + Alt + Arrow` | ย้าย workspace ไปยังจอในทิศทางนั้น โดยคงหมายเลขเดิมไว้ถ้าหมายเลขนั้นว่างอยู่ |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | ย้ายโฟกัสไปยังจอถัดไปหรือจอก่อนหน้า ไม่ว่าเลย์เอาต์จะเป็นอย่างไร |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | อยู่บนจอที่คุณกำลังอยู่ |

คุณยังสามารถลองดู [Hyprmon](https://github.com/erans/hyprmon/) ได้เช่นกัน ถ้าคุณต้องการ TUI ที่ช่วยคุณจัดตำแหน่งหลายหน้าจอ

### ควบคุมความสว่าง

ความสว่างของจอภาพควบคุมด้วยปุ่มฟังก์ชันเฉพาะสำหรับเพิ่ม/ลดความสว่าง ถ้าคุณกด shift ค้างไว้ขณะกดปุ่มเหล่านี้ คุณจะปรับไปถึงความสว่างสูงสุดหรือต่ำสุด ปุ่มเหล่านี้จะควบคุมจอแสดงผลที่คุณกำลังโฟกัสอยู่ ดังนั้นจอภายนอกที่สื่อสารด้วย DDC/CI จะถูกปรับในลักษณะเดียวกับหน้าจอแล็ปท็อป

### จอ Apple

ถ้าคุณใช้จอ Apple ปุ่มความสว่างบนคีย์บอร์ดทั่วไปก็จะทำงานโดยอัตโนมัติเช่นกัน ถ้าคุณกำลังโฟกัสอยู่ที่จอ Apple การทำงานนี้ทำผ่านคำสั่ง `asdcontrol`

โปรดทราบว่าถ้าคุณใช้จอ Apple 6K XDR คุณอาจเห็นจอหลอกในรายการ `hyprctl monitors` ของคุณ คุณสามารถปิดจอนี้ได้ด้วยบางอย่างเช่น `hl.monitor({ output = "DP-2", disabled = true })` ผ่าน _Setup > Monitors_

บนเครื่อง Intel คุณควรเชื่อมต่อกับจอ Apple โดยใช้สาย Thunderbolt ทั่วไป บนเครื่องอื่นที่ไม่มี Thunderbolt โดยทั่วไปคุณจะต้องใช้ [สาย DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) เพื่อให้ใช้งานได้
