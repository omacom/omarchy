# จอภาพ

โดยค่าเริ่มต้น Omarchy จะถือว่าคุณกำลังใช้จอแสดงผลระดับ retina ที่รองรับการสเกลแบบ 2x นี่คือสิ่งที่คุณต้องการเพื่อให้ได้ฟอนต์สำหรับโปรแกรมเมอร์ที่สวยและคมชัด นี่คือสิ่งที่แล็ปท็อประดับพรีเมียมรุ่นใหม่เกือบทั้งหมดที่มีหน้าจอความละเอียดสูงได้รับการปรับให้เหมาะสม นี่คือสิ่งที่คุณอยากใช้บนจอขนาด 27" 5K อย่าง [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) หรือจอขนาด 32" 6K อย่าง [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/)

แต่ถ้าคุณไม่ได้ใช้จอแสดงผลที่มี PPI ตั้งแต่ 218 ขึ้นไป คุณจะต้องเปลี่ยนการตั้งค่าจอภาพ ตัวอย่างเช่น ถ้าคุณมีจอ 4K ขนาด 27" หรือ 32" คุณสามารถเลือกสเกลแบบเศษส่วนให้กับจอนั้นได้จากแผงจอภาพในแถบด้านบน หรือตั้งค่าเริ่มต้นสำหรับจอภาพทุกจอโดยเปิด `~/.config/hypr/monitors.lua` แล้วเปลี่ยนไปใช้ค่าที่แนะนำสำหรับชุดอุปกรณ์นั้น:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

ถ้าคุณใช้จอแสดงผล 1080p หรือ 1440p คุณอาจอยากใช้การสเกลแบบ 1x และใช้แบบเดียวกันกับแอป GTK และ X11 คุณจึงสามารถใช้:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

การเปลี่ยนแปลง `GDK_SCALE` จะมีผลกับแอปพลิเคชันที่เริ่มทำงานหลังจากการเปลี่ยนแปลงนั้น (และ GTK จะยอมรับเฉพาะจำนวนเต็มเท่านั้น ดังนั้นให้คงค่าไว้ที่จำนวนเต็มที่ใกล้ที่สุดกับสเกลของจอภาพของคุณ) ดังนั้นอย่าลืมปิดหน้าต่างที่คุณเปิดอยู่และมีขนาดใหญ่เกินไปหลังจากการเปลี่ยนแปลง (หรือปิดหน้าต่างทั้งหมดด้วย `Ctrl + Alt + Del`!)

คุณยังสามารถสลับไปยังอัตราส่วนการสเกลจอภาพหลัก ๆ ได้อย่างรวดเร็ว (1x, 1.25x, 1.6x, 2x, 3x, 4x) โดยใช้ `Super + /` เพื่อเพิ่ม และใช้ `Super + Alt + /` เพื่อลด หรือเลือกอัตราส่วนจากแผงจอภาพในแถบด้านบน การเปลี่ยนแปลงเหล่านี้จะมีผลเฉพาะกับจอภาพที่คุณกำลังโฟกัสอยู่ ดังนั้นหน้าจอแล็ปท็อปและจอแสดงผลภายนอกจึงมีสเกลของตัวเองได้ แผงนี้ยังตั้งค่าความละเอียด อัตราการรีเฟรช และการหมุนของจอภาพแต่ละจออีกด้วย ตัวเลือกของคุณจะถูกบันทึกไว้สำหรับจอภาพเครื่องนั้นใน `~/.local/state/omarchy/monitors/settings` ดังนั้นตัวเลือกเหล่านั้นจะยังคงอยู่หลังรีบูต และจะตามจอภาพไปไม่ว่ามันจะเสียบเข้ากับพอร์ตหรือแท่นเชื่อมต่อใดในครั้งต่อไป ตัวเลือกเหล่านี้จะมีลำดับความสำคัญเหนือกฎใด ๆ สำหรับจอภาพเดียวกันใน `~/.config/hypr/monitors.lua` ซึ่ง Omarchy จะไม่แก้ไขเลย ถ้าคุณอยากตั้งค่าจอภาพทั้งหมดของคุณในไฟล์นั้น ให้เพิ่ม `omarchy_monitor_panel_settings = false` ลงในไฟล์นั้น และการเปลี่ยนแปลงจากแผงจะคงอยู่จนกว่า Hyprland จะโหลดใหม่เท่านั้น เนื่องจาก `GDK_SCALE` เป็นค่าเดียวสำหรับทุกหน้าจอ สเกลที่เลือกจึงจะตั้งค่าจากจอภาพที่มีสเกลต่ำที่สุด ดังนั้นแอป X11 จะออกมาเล็กกว่าเล็กน้อยบนหน้าจอที่หนาแน่นกว่า แทนที่จะมีขนาดใหญ่เกินไปบนอีกหน้าจอหนึ่ง

### การทำให้ข้อความใหญ่ขึ้นหรือเล็กลง

การสเกลจอภาพจะเปลี่ยนขนาดของทุกอย่าง ถ้าสิ่งที่คุณต้องการมีเพียงข้อความที่ใหญ่ขึ้นหรือเล็กลง ก็มีปุ่มปรับเพียงอย่างเดียวสำหรับเรื่องนั้น:

```
omarchy display text size 14
```

คำสั่งนี้รับขนาดเป็นพิกเซลระหว่าง 9 ถึง 20 และจะปรับเชลล์ของ Omarchy แอปพลิเคชัน GTK และเทอร์มินัลของคุณไปด้วยกัน ดังนั้นเดสก์ท็อปทั้งหมดจะยังคงได้สัดส่วนกัน รันคำสั่งนี้โดยไม่ใส่ข้อกำหนดเพื่อดูว่าคุณกำลังอยู่ที่ค่าใด และใช้ `omarchy display text size reset` เพื่อกลับไปใช้ค่าเริ่มต้น Foot คือตัวเดียวที่ตามไม่ทัน: มันไม่มีวิธีโหลดการตั้งค่าของมันใหม่ ดังนั้นเทอร์มินัลที่กำลังทำงานอยู่จะยังคงใช้ขนาดเดิมจนกว่าคุณจะเปิดเทอร์มินัลใหม่

### การขยายและการสะท้อนจอแล็ปท็อป

เมื่อคุณเชื่อมต่อหน้าจอภายนอกเข้ากับแล็ปท็อปของคุณ จอแสดงผลจะถูกขยายโดยอัตโนมัติ แต่คุณสามารถเปลี่ยนเป็นการสะท้อนแทนได้ด้วย _ขยาย_ | _สะท้อน_ ในแผงจอภาพในแถบด้านบน _Trigger > Hardware_ ในเมนู Omarchy หรือ `Super + Ctrl + Alt + Delete` วิธีนี้มีประโยชน์เป็นพิเศษถ้าหน้าจอภายนอกนั้นเป็นโปรเจกเตอร์ และคุณต้องการแสดงบางอย่างขณะทำงาน

เมื่อคุณกำลังขยายจอ การปิดฝาแล็ปท็อปจะปิดหน้าจอภายในโดยอัตโนมัติ การเปิดฝาจะเปิดหน้าจอนั้นกลับมาอีกครั้ง คุณยังสามารถควบคุมเรื่องนี้ด้วยตนเองได้โดยใช้ _Trigger > Hardware_ ในเมนู Omarchy หรือ `Super + Ctrl + Delete`

### การจัดเรียงหลายหน้าจอ

Hyprland ทำงานได้ดีกับหลายหน้าจอ แผงจอภาพในแถบด้านบนจะวาดหน้าจอเหล่านั้นตามตำแหน่งที่ตั้งอยู่: ลากจอหนึ่งไปแนบกับด้านข้างของอีกจอหนึ่งเพื่อย้ายมันไปที่นั่น และการจัดเรียงจะถูกบันทึกไว้พร้อมกับการตั้งค่าอื่น ๆ ของแต่ละจอ สำหรับสิ่งที่แผงไม่ครอบคลุม อ่านเพิ่มเติมเกี่ยวกับวิธีจัดวางหน้าจอได้ใน [เอกสารจอภาพของ Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/) ใน Omarchy สิ่งเหล่านี้จะอยู่ใน `~/.config/hypr/monitors.lua` ในรูปแบบรายการ `hl.monitor` — ไฟล์นี้มาพร้อมกับตัวอย่างที่ถูกคอมเมนต์ไว้สำหรับการปิดจอภาพ โหมดที่แผงไม่มีให้ สี 10-bit และอัตราการรีเฟรชแบบผันแปร

จอภาพแต่ละจอมีพื้นที่ทำงาน 1 ถึง 10 ของตัวเอง ดังนั้น `Super + 1` จะหมายถึงพื้นที่ทำงานแรกของจอภาพที่คุณกำลังอยู่เสมอ เบื้องหลัง Hyprland ยังคงกำหนดหมายเลขพื้นที่ทำงานข้ามจอภาพทั้งหมด: หน้าจอแล็ปท็อปของคุณ (หรือจอภาพแรก) จะได้รับหมายเลข 1–10 จอภาพถัดไปจะได้รับ 11–20 และต่อไปแบบนี้ และจอภาพแต่ละจอจะคงบล็อกหมายเลขของมันไว้ทุกครั้งที่คุณเสียบมันเข้าไป ใช้หมายเลขเหล่านี้ถ้าคุณเขียน [กฎพื้นที่ทำงาน](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) หรือกฎหน้าต่างสำหรับจอภาพใดจอภาพหนึ่งโดยเฉพาะ ดังนั้นพื้นที่ทำงาน 12 จึงเป็นพื้นที่ทำงานที่สองของจอภาพที่สองของคุณ `~/.local/state/omarchy/monitors/workspaces` จะแสดงรายการว่าจอภาพแต่ละจอมีบล็อกหมายเลขใด

ปุ่มลูกศรจะทำงานข้ามจอภาพที่มีขอบร่วมกันในเลย์เอาต์ของคุณ หน้าจอที่สัมผัสกันเพียงตรงมุม หรือมีช่องว่างระหว่างกัน จะไม่ถือว่าเป็นจอข้างเคียงกัน ดังนั้นให้ใช้ `Ctrl + Alt + Tab` เพื่อย้ายระหว่างหน้าจอเหล่านั้น

| ปุ่มลัด | ข้ามจอภาพ |
| --- | --- |
| `Super + Arrow` | ย้ายโฟกัสไปยังจอภาพด้านนั้น เมื่อไม่มีหน้าต่างเหลืออยู่ในทิศทางนั้นอีกแล้ว |
| `Super + Shift + Arrow` | สลับกับหน้าต่างบนจอภาพด้านนั้น |
| `Super + Alt + Arrow` | ย้ายหน้าต่างเข้าไปในกลุ่มบนจอภาพด้านนั้น |
| `Super + Shift + Ctrl + Arrow` | ย้ายหน้าต่างไปยังจอภาพด้านนั้น ไปยังพื้นที่ทำงานที่จอนั้นกำลังแสดงอยู่ |
| `Super + Shift + Alt + Arrow` | ย้ายพื้นที่ทำงานไปยังจอภาพด้านนั้น โดยคงหมายเลขเดิมไว้ถ้าหมายเลขนั้นว่างอยู่ |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | ย้ายโฟกัสไปยังจอภาพถัดไปหรือก่อนหน้า ไม่ว่าเลย์เอาต์จะเป็นอย่างไร |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | อยู่บนจอภาพที่คุณกำลังใช้อยู่ |

คุณยังสามารถลองดู [Hyprmon](https://github.com/erans/hyprmon/) ได้เช่นกัน ถ้าคุณอยากได้ TUI มาช่วยในการจัดตำแหน่งหลายหน้าจอของคุณ

### การควบคุมความสว่าง

ความสว่างของจอภาพควบคุมด้วยปุ่มฟังก์ชันเฉพาะสำหรับเพิ่ม/ลดความสว่าง ถ้าคุณกด Shift ค้างไว้ขณะกดปุ่มเหล่านี้ คุณจะไปยังความสว่างสูงสุดหรือต่ำสุด ปุ่มเหล่านี้จะควบคุมจอแสดงผลที่คุณกำลังโฟกัสอยู่ ดังนั้นจอภาพภายนอกที่สื่อสารด้วย DDC/CI จะถูกปรับในลักษณะเดียวกันกับหน้าจอแล็ปท็อป

### จอภาพ Apple

ถ้าคุณกำลังใช้จอภาพ Apple ปุ่มปรับความสว่างบนแป้นพิมพ์ปกติก็จะทำงานโดยอัตโนมัติเช่นกัน ถ้าคุณกำลังโฟกัสอยู่ที่จอภาพ Apple การทำงานนี้ทำผ่านคำสั่ง `asdcontrol`

โปรดทราบว่าถ้าคุณกำลังใช้จอภาพ Apple 6K XDR คุณอาจเห็นหน้าจอหลอกในรายการ `hyprctl monitors` ของคุณ คุณสามารถปิดสิ่งนี้ได้ด้วยคำสั่งอย่างเช่น `hl.monitor({ output = "DP-2", disabled = true })` ใน `~/.config/hypr/monitors.lua`

บนเครื่อง Intel คุณควรเชื่อมต่อกับจอภาพ Apple โดยใช้สาย Thunderbolt ปกติ บนเครื่องอื่นที่ไม่มี Thunderbolt โดยทั่วไปคุณจะต้องใช้ [สาย DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) เพื่อให้มันทำงานได้
