# จอภาพ

Omarchy ถือว่าคุณกำลังใช้งานจอแสดงผลระดับ retina ที่รองรับ 2x เป็นค่าเริ่มต้น นี่คือสิ่งที่คุณต้องการเพื่อให้ได้ฟอนต์สำหรับโปรแกรมเมอร์ที่สวยและคมชัด นี่คือสิ่งที่แล็ปท็อประดับพรีเมียมรุ่นใหม่เกือบทุกรุ่นที่มีหน้าจอความละเอียดสูงได้รับการปรับให้เหมาะสม นี่คือสิ่งที่คุณต้องการใช้งานบนจอ 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) หรือ 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/)

แต่ถ้าคุณไม่ได้ใช้งานจอแสดงผลที่มี PPI ตั้งแต่ 218 ขึ้นไป คุณจะต้องเปลี่ยนการตั้งค่าจอภาพ ตัวอย่างเช่น ถ้าคุณมีจอ 4K ขนาด 27" หรือ 32" คุณสามารถเลือกสเกลแบบเศษส่วนสำหรับจอนั้นได้จากแผงจอภาพในแถบด้านบน หรือตั้งค่าเริ่มต้นสำหรับจอภาพทุกจอโดยเปิด `~/.config/hypr/monitors.lua` แล้วเปลี่ยนไปใช้คำแนะนำสำหรับชุดค่าผสมนั้น:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

ถ้าคุณใช้จอแสดงผล 1080p หรือ 1440p คุณอาจต้องการใช้การสเกลแบบ 1x เท่านั้น และใช้แบบเดียวกันสำหรับแอป GTK และ X11 ดังนั้นคุณสามารถใช้:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

การเปลี่ยนแปลง `GDK_SCALE` จะมีผลกับแอปพลิเคชันที่เริ่มทำงานหลังจากการเปลี่ยนแปลง (และ GTK รองรับเฉพาะจำนวนเต็มเท่านั้น ดังนั้นให้คงไว้ที่จำนวนเต็มที่ใกล้เคียงที่สุดกับสเกลของจอภาพของคุณ) ดังนั้นอย่าลืมปิดหน้าต่างที่มีขนาดใหญ่เกินไปหลังจากการเปลี่ยนแปลง (หรือปิดหน้าต่างทั้งหมดด้วย `Ctrl + Alt + Del`!)

คุณยังสามารถไล่เปลี่ยนอัตราส่วนการสเกลหลักของจอภาพได้อย่างรวดเร็ว (1x, 1.25x, 1.6x, 2x, 3x, 4x) โดยใช้ `Super + /` เพื่อเพิ่มขึ้น และ `Super + Alt + /` เพื่อลดลง หรือเลือกค่าหนึ่งจากแผงจอภาพในแถบด้านบน การเปลี่ยนแปลงเหล่านี้จะมีผลเฉพาะกับจอภาพที่คุณกำลังโฟกัสอยู่ ดังนั้นหน้าจอแล็ปท็อปและจอแสดงผลภายนอกจึงมีสเกลของตัวเองได้ แผงนี้ยังตั้งค่าความละเอียด อัตราการรีเฟรช และการหมุนของจอภาพแต่ละจออีกด้วย ตัวเลือกของคุณจะถูกบันทึกไว้สำหรับจอภาพเครื่องนั้นใน `~/.local/state/omarchy/monitors/settings` ดังนั้นจึงคงอยู่หลังจากรีบูต และตามจอภาพไปไม่ว่าจะเสียบเข้ากับพอร์ตหรือด็อกใดในครั้งต่อไป ตัวเลือกเหล่านี้มีความสำคัญเหนือกว่ากฎใด ๆ สำหรับจอภาพเดียวกันใน `~/.config/hypr/monitors.lua` ซึ่ง Omarchy ไม่เคยแก้ไข หากคุณต้องการตั้งค่าจอภาพทั้งหมดในไฟล์นั้นแทน ให้เพิ่ม `omarchy_monitor_panel_settings = false` ลงไป และการเปลี่ยนแปลงจากแผงจะมีผลจนกว่า Hyprland จะโหลดใหม่เท่านั้น เนื่องจาก `GDK_SCALE` เป็นค่าเดียวสำหรับทุกหน้าจอ สเกลที่เลือกจะกำหนดค่านี้จากจอภาพที่มีสเกลต่ำที่สุด ดังนั้นแอป X11 จะออกมาเล็กเล็กน้อยบนหน้าจอที่หนาแน่นกว่า แทนที่จะใหญ่เกินไปบนอีกหน้าจอหนึ่ง

### การทำให้ข้อความใหญ่ขึ้นหรือเล็กลง

การสเกลจอภาพจะเปลี่ยนขนาดของทุกสิ่ง หากสิ่งที่คุณต้องการคือ _ข้อความ_ ที่ใหญ่ขึ้นหรือเล็กลงเท่านั้น มีปุ่มปรับเพียงปุ่มเดียวสำหรับสิ่งนั้น:

```
omarchy display text size 14
```

คำสั่งนี้รับขนาดเป็นพิกเซลระหว่าง 9 ถึง 20 และจะปรับเชลล์ของ Omarchy, แอปพลิเคชัน GTK และเทอร์มินัลของคุณไปด้วยกัน ดังนั้นเดสก์ท็อปทั้งหมดจึงคงสัดส่วนไว้ รันคำสั่งนี้โดยไม่มีอาร์กิวเมนต์เพื่อดูว่าคุณอยู่ที่ค่าใด และใช้ `omarchy display text size reset` เพื่อกลับไปเป็นค่าเริ่มต้น Foot เป็นตัวเดียวที่ตามไม่ทัน: มันไม่มีวิธีโหลดการกำหนดค่าใหม่ ดังนั้นเทอร์มินัลที่กำลังทำงานอยู่จะคงขนาดเดิมไว้จนกว่าคุณจะเปิดเทอร์มินัลใหม่

### การขยายและมิเรอร์จอแสดงผลของแล็ปท็อป

เมื่อคุณเชื่อมต่อหน้าจอภายนอกเข้ากับแล็ปท็อป จอแสดงผลจะถูกขยายโดยอัตโนมัติ แต่คุณสามารถเปลี่ยนเป็นการมิเรอร์แทนได้ด้วย _Extend_ | _Mirror_ ในแผงจอภาพในแถบด้านบน, _Trigger > Hardware_ ในเมนู Omarchy หรือ `Super + Ctrl + Alt + Delete` สิ่งนี้มีประโยชน์เป็นพิเศษหากหน้าจอภายนอกนั้นเป็นโปรเจกเตอร์ และคุณต้องการแสดงบางสิ่งในขณะที่ทำงาน

เมื่อคุณกำลังขยายจอแสดงผล การปิดฝาแล็ปท็อปจะปิดหน้าจอภายในโดยอัตโนมัติ การเปิดฝาจะเปิดกลับมาอีกครั้ง คุณยังสามารถควบคุมสิ่งนี้ด้วยตนเองได้โดยใช้ _Trigger > Hardware_ ในเมนู Omarchy หรือ `Super + Ctrl + Delete`

ขณะที่แล็ปท็อปเสียบปลั๊กอยู่ การปิดฝาจะไม่ทำให้เครื่องเข้าสู่โหมดสลีป ดังนั้นแล็ปท็อปที่เชื่อมต่อกับด็อกจะยังคงตื่นอยู่แม้ว่าหน้าจอภายนอกจะตัดการเชื่อมต่อชั่วครู่ เมื่อไม่มีหน้าจอภายนอกเชื่อมต่ออยู่ การปิดฝาขณะเสียบไฟจะเพียงแค่ล็อกเครื่องเท่านั้น เมื่อใช้แบตเตอรี่ การปิดฝาจะระงับการทำงานตามปกติ

### การจัดวางหลายหน้าจอ

Hyprland ทำงานได้ยอดเยี่ยมกับหลายหน้าจอ แผงจอภาพในแถบด้านบนจะวาดจอเหล่านั้นในตำแหน่งที่พวกมันอยู่: ลากจอหนึ่งไปแนบกับด้านข้างของอีกจอหนึ่งเพื่อย้ายไปที่นั่น และการจัดวางจะถูกบันทึกพร้อมกับการตั้งค่าอื่น ๆ ของจอภาพแต่ละจอ สำหรับสิ่งที่แผงไม่ครอบคลุม อ่านเพิ่มเติมเกี่ยวกับวิธีจัดวางจอเหล่านั้นได้ใน [เอกสารจอภาพของ Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/) ใน Omarchy สิ่งเหล่านี้จะอยู่ใน `~/.config/hypr/monitors.lua` ในรูปแบบรายการ `hl.monitor` — ไฟล์นี้มาพร้อมตัวอย่างที่คอมเมนต์ไว้สำหรับการปิดจอภาพไว้, โหมดที่แผงไม่มีให้, สี 10-bit และอัตราการรีเฟรชแบบแปรผัน

จอภาพทุกจอมีเวิร์กสเปซ 1 ถึง 10 เป็นของตัวเอง ดังนั้น `Super + 1` จึงหมายถึงเวิร์กสเปซแรกของจอภาพที่คุณอยู่เสมอ เบื้องหลัง Hyprland ยังคงกำหนดหมายเลขเวิร์กสเปซต่อเนื่องไปในจอภาพทั้งหมด: หน้าจอแล็ปท็อปของคุณ (หรือจอภาพแรก) จะได้ 1–10, จอภาพถัดไปจะได้ 11–20 และไล่ต่อไปเช่นนี้ และจอภาพแต่ละจอจะรักษาแถบหมายเลขของมันไว้ทุกครั้งที่คุณเสียบเข้ามา ใช้หมายเลขเหล่านี้หากคุณเขียน [กฎเวิร์กสเปซ](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) หรือกฎหน้าต่างสำหรับจอภาพเฉพาะเจาะจง ดังนั้นเวิร์กสเปซ 12 จึงเป็นเวิร์กสเปซที่สองของจอภาพที่สองของคุณ `~/.local/state/omarchy/monitors/workspaces` จะแสดงรายการว่าจอภาพแต่ละจอมีแถบหมายเลขใด

ปุ่มลูกศรทำงานข้ามจอภาพที่มีขอบร่วมกันในเลย์เอาต์ของคุณ หน้าจอที่สัมผัสกันเพียงที่มุม หรือมีช่องว่างระหว่างกัน ไม่ถือเป็นจอที่อยู่ติดกัน ดังนั้นให้ใช้ `Ctrl + Alt + Tab` เพื่อเคลื่อนย้ายระหว่างจอเหล่านั้น

| ปุ่มลัด | ข้ามจอภาพ |
| --- | --- |
| `Super + Arrow` | ย้ายโฟกัสไปยังจอภาพด้านนั้นเมื่อไม่มีหน้าต่างเหลืออยู่ในทิศทางนั้นอีกต่อไป |
| `Super + Shift + Arrow` | สลับกับหน้าต่างบนจอภาพด้านนั้น |
| `Super + Alt + Arrow` | ย้ายหน้าต่างเข้าไปในกลุ่มบนจอภาพด้านนั้น |
| `Super + Shift + Ctrl + Arrow` | ย้ายหน้าต่างไปยังจอภาพด้านนั้น บนเวิร์กสเปซที่กำลังแสดงอยู่บนจอนั้น |
| `Super + Shift + Alt + Arrow` | ย้ายเวิร์กสเปซไปยังจอภาพด้านนั้น โดยคงหมายเลขเดิมไว้หากว่างอยู่ |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | ย้ายโฟกัสไปยังจอภาพถัดไปหรือก่อนหน้า ไม่ว่าเลย์เอาต์จะเป็นอย่างไร |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | อยู่บนจอภาพที่คุณอยู่ |

คุณยังสามารถลองดู [Hyprmon](https://github.com/erans/hyprmon/) ได้ หากคุณต้องการ TUI เพื่อช่วยจัดตำแหน่งหลายหน้าจอ

### การควบคุมความสว่าง

ความสว่างของจอภาพควบคุมด้วยปุ่มฟังก์ชันเฉพาะสำหรับเพิ่ม/ลดความสว่าง หากคุณกด Shift ค้างไว้ขณะกดปุ่มเหล่านี้ คุณจะไปที่ความสว่างสูงสุดหรือต่ำสุด ปุ่มเหล่านี้ควบคุมจอแสดงผลที่คุณกำลังโฟกัสอยู่ ดังนั้นจอภาพภายนอกที่รองรับ DDC/CI จะถูกปรับในลักษณะเดียวกับหน้าจอแล็ปท็อป

### จอแสดงผล Apple

หากคุณใช้จอแสดงผล Apple ปุ่มความสว่างบนแป้นพิมพ์ทั่วไปจะทำงานโดยอัตโนมัติเช่นกัน หากคุณกำลังโฟกัสอยู่ที่จอแสดงผล Apple สิ่งนี้ทำผ่านคำสั่ง `asdcontrol`

โปรดทราบว่าหากคุณใช้จอแสดงผล Apple 6K XDR คุณอาจเห็นหน้าจอหลอกในรายการ `hyprctl monitors` ของคุณ คุณสามารถปิดสิ่งนี้ได้ด้วยอะไรทำนอง `hl.monitor({ output = "DP-2", disabled = true })` ใน `~/.config/hypr/monitors.lua`

บนเครื่อง Intel คุณควรเชื่อมต่อกับจอแสดงผล Apple โดยใช้สาย Thunderbolt ทั่วไป บนเครื่องอื่นที่ไม่มี Thunderbolt โดยทั่วไปคุณจะต้องใช้ [สาย DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) เพื่อให้ใช้งานได้
