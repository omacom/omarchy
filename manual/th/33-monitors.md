# จอภาพ

Omarchy สันนิษฐานไว้ตามค่าเริ่มต้นว่าคุณกำลังใช้จอแสดงผลระดับ retina ที่รองรับ 2x นี่คือสิ่งที่คุณต้องมีเพื่อจะได้ฟอนต์สำหรับโปรแกรมเมอร์ที่สวยและคมชัดเหล่านั้น นี่คือสิ่งที่แล็ปท็อปพรีเมียมรุ่นใหม่เกือบทั้งหมดที่มีหน้าจอความละเอียดสูงได้รับการปรับให้เหมาะที่สุด นี่คือสิ่งที่คุณอยากใช้บนจอ 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) หรือ 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/)

แต่ถ้าคุณไม่ได้ใช้จอแสดงผลที่มี PPI ตั้งแต่ 218 ขึ้นไป คุณจะต้องเปลี่ยนการตั้งค่าจอภาพ ตัวอย่างเช่น ถ้าคุณมีจอ 4K ขนาด 27" หรือ 32" คุณสามารถเลือกสเกลแบบเศษส่วนให้จอนั้นได้จากแผงจอภาพในแถบด้านบน หรือตั้งค่าเริ่มต้นสำหรับจอภาพทุกจอโดยเปิด `~/.config/hypr/monitors.lua` แล้วเปลี่ยนไปใช้ค่าที่แนะนำสำหรับชุดนั้น:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

ถ้าคุณใช้จอแสดงผล 1080p หรือ 1440p คุณอาจอยากใช้สเกล 1x แค่นั้นพอ และใช้แบบเดียวกันกับแอป GTK และ X11 ด้วย ดังนั้นคุณสามารถใช้ได้ดังนี้:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

การเปลี่ยนแปลง `GDK_SCALE` จะมีผลกับแอปพลิเคชันที่เริ่มทำงานหลังจากการเปลี่ยนแปลง (และ GTK รองรับเฉพาะจำนวนเต็มเท่านั้น ดังนั้นให้ใช้จำนวนเต็มที่ใกล้เคียงที่สุดกับสเกลของจอภาพของคุณ) ดังนั้นอย่าลืมปิดหน้าต่างที่คุณเปิดอยู่ซึ่งมีขนาดใหญ่เกินไปหลังจากการเปลี่ยนแปลง (หรือปิดหน้าต่างทั้งหมดด้วย `Ctrl + Alt + Del`!)

คุณยังสามารถไล่เปลี่ยนอัตราส่วนสเกลหลักของจอภาพ (1x, 1.25x, 1.6x, 2x, 3x, 4x) ได้อย่างรวดเร็วโดยใช้ `Super + /` เพื่อเพิ่ม และ `Super + Alt + /` เพื่อลด หรือเลือกค่าหนึ่งจากแผงจอภาพในแถบด้านบน การเปลี่ยนแปลงเหล่านี้จะเปลี่ยนเฉพาะจอภาพที่คุณกำลังโฟกัสอยู่ ดังนั้นหน้าจอแล็ปท็อปและจอแสดงผลภายนอกจึงมีสเกลของตัวเองแยกกันได้ แผงนี้ยังตั้งค่าความละเอียดของจอภาพแต่ละจอด้วย ตัวเลือกของคุณจะถูกบันทึกไว้สำหรับจอภาพเครื่องนั้นใน `~/.local/state/omarchy/monitors/settings` ดังนั้นตัวเลือกจะยังคงอยู่หลังรีบูต และจะตามจอภาพไปไม่ว่าจะเสียบเข้ากับพอร์ตหรือ dock ใดในครั้งต่อไป ตัวเลือกเหล่านี้มีลำดับความสำคัญสูงกว่ากฎใด ๆ สำหรับจอภาพเดียวกันใน `~/.config/hypr/monitors.lua` ซึ่ง Omarchy ไม่เคยแก้ไขไฟล์นั้น ถ้าคุณอยากตั้งค่าจอภาพทั้งหมดในไฟล์นั้นแทน ให้เพิ่ม `omarchy_monitor_panel_settings = false` ลงไป และการเปลี่ยนแปลงจากแผงจะอยู่ได้จนกว่า Hyprland จะโหลดใหม่เท่านั้น เนื่องจาก `GDK_SCALE` เป็นค่าเดียวสำหรับทุกหน้าจอ สเกลที่เลือกจะตั้งค่านี้จากจอภาพที่มีสเกลต่ำที่สุด ดังนั้นแอป X11 จะออกมาเล็กไปหน่อยบนหน้าจอที่หนาแน่นกว่า แทนที่จะใหญ่เกินไปบนอีกหน้าจอหนึ่ง

### การทำให้ข้อความใหญ่ขึ้นหรือเล็กลง

สเกลของจอภาพจะเปลี่ยนขนาดของทุกอย่าง ถ้าสิ่งที่คุณต้องการมีแค่ข้อความที่ใหญ่ขึ้นหรือเล็กลง มีปุ่มปรับเพียงอย่างเดียวสำหรับเรื่องนั้น:

```
omarchy display text size 14
```

คำสั่งนั้นรับขนาดเป็นพิกเซลระหว่าง 9 ถึง 20 และจะปรับเชลล์ของ Omarchy, แอปพลิเคชัน GTK และเทอร์มินัลของคุณไปพร้อมกัน เพื่อให้เดสก์ท็อปทั้งหมดยังคงได้สัดส่วน รันคำสั่งโดยไม่ใส่ argument เพื่อดูว่าคุณอยู่ที่ค่าใด และใช้ `omarchy display text size reset` เพื่อกลับไปใช้ค่าเริ่มต้น Foot คือตัวเดียวที่ตกหล่น: มันไม่มีวิธีโหลดการตั้งค่าใหม่ ดังนั้นเทอร์มินัลที่กำลังทำงานอยู่จะยังคงใช้ขนาดเดิมจนกว่าคุณจะเปิดเทอร์มินัลใหม่

### การขยายและมิเรอร์จอแสดงผลของแล็ปท็อป

เมื่อคุณเชื่อมต่อหน้าจอภายนอกเข้ากับแล็ปท็อปของคุณ จอแสดงผลจะถูกขยายโดยอัตโนมัติ แต่คุณสามารถเปลี่ยนเป็นการมิเรอร์แทนได้โดยใช้ _Trigger > Hardware_ ในเมนู Omarchy หรือ `Super + Ctrl + Alt + Delete` ซึ่งมีประโยชน์เป็นพิเศษถ้าหน้าจอภายนอกนั้นเป็นโปรเจ็กเตอร์ และคุณต้องการแสดงบางอย่างในขณะที่ทำงานไปด้วย

เมื่อคุณกำลังขยายจอ การปิดฝาแล็ปท็อปจะปิดหน้าจอภายในโดยอัตโนมัติ การเปิดฝาจะเปิดหน้าจอกลับมาอีกครั้ง คุณยังสามารถควบคุมสิ่งนี้ด้วยตนเองได้โดยใช้ _Trigger > Hardware_ ในเมนู Omarchy หรือ `Super + Ctrl + Delete`

### การจัดเรียงหลายหน้าจอ

Hyprland ทำงานได้ดีเยี่ยมกับหลายหน้าจอ แผงจอภาพในแถบด้านบนจะวาดหน้าจอเหล่านั้นตามตำแหน่งที่พวกมันอยู่: ลากจอหนึ่งไปติดกับด้านข้างของอีกจอหนึ่งเพื่อย้ายมันไปตรงนั้น และการจัดเรียงจะถูกบันทึกไว้พร้อมกับการตั้งค่าอื่น ๆ ของจอภาพแต่ละจอ สำหรับสิ่งใดก็ตามที่แผงนี้ไม่ครอบคลุม อ่านเพิ่มเติมเกี่ยวกับวิธีจัดวางหน้าจอเหล่านั้นได้ใน [เอกสารเกี่ยวกับจอภาพของ Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/) ใน Omarchy สิ่งเหล่านี้จะอยู่ใน `~/.config/hypr/monitors.lua` เป็นรายการ `hl.monitor` — ไฟล์นี้มาพร้อมกับตัวอย่างที่ถูกคอมเมนต์ไว้สำหรับตรึงจอภาพเฉพาะจอหนึ่งไว้ที่ความละเอียด ตำแหน่ง และการหมุนที่กำหนด

จอภาพทุกจอมี workspace 1 ถึง 10 เป็นของตัวเอง ดังนั้น `Super + 1` จึงหมายถึง workspace แรกของจอภาพที่คุณอยู่เสมอ เบื้องหลัง Hyprland ยังคงกำหนดหมายเลข workspace ข้ามจอภาพทั้งหมดอยู่ดี: หน้าจอแล็ปท็อปของคุณ (หรือจอภาพแรก) จะได้หมายเลข 1–10 จอภาพถัดไปจะได้ 11–20 และไล่ต่อไปเรื่อย ๆ และจอภาพแต่ละจอจะเก็บบล็อกของมันไว้ทุกครั้งที่คุณเสียบมันเข้ามา ใช้หมายเลขเหล่านั้นถ้าคุณเขียน [กฎ workspace](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) หรือกฎหน้าต่างสำหรับจอภาพเฉพาะจอหนึ่ง ดังนั้น workspace 12 คือ workspace ที่สองของจอภาพที่สองของคุณ `~/.local/state/omarchy/monitors/workspaces` จะแสดงรายการว่าจอภาพแต่ละจอมีบล็อกใด

ปุ่มลูกศรทำงานข้ามจอภาพที่มีขอบร่วมกันในเลย์เอาต์ของคุณ หน้าจอที่แตะกันแค่ตรงมุม หรือมีช่องว่างระหว่างกัน จะไม่ถือว่าเป็นจอข้างเคียงกัน ดังนั้นให้ใช้ `Ctrl + Alt + Tab` เพื่อย้ายไปมาระหว่างหน้าจอเหล่านั้น

| Hotkey | ข้ามไปยังจอภาพอื่น |
| --- | --- |
| `Super + Arrow` | ย้ายโฟกัสไปยังจอภาพในด้านนั้น เมื่อไม่มีหน้าต่างเหลืออยู่ในทิศทางนั้นแล้ว |
| `Super + Shift + Arrow` | สลับกับหน้าต่างบนจอภาพในด้านนั้น |
| `Super + Alt + Arrow` | ย้ายหน้าต่างเข้าไปในกลุ่มบนจอภาพในด้านนั้น |
| `Super + Shift + Ctrl + Arrow` | ย้ายหน้าต่างไปยังจอภาพในด้านนั้น ไปยัง workspace ที่จอนั้นกำลังแสดงอยู่ |
| `Super + Shift + Alt + Arrow` | ย้าย workspace ไปยังจอภาพในด้านนั้น โดยคงหมายเลขเดิมไว้ถ้าหมายเลขนั้นว่างอยู่ |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | ย้ายโฟกัสไปยังจอภาพถัดไปหรือก่อนหน้า ไม่ว่าเลย์เอาต์จะเป็นอย่างไร |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | อยู่บนจอภาพที่คุณอยู่ต่อไป |

คุณสามารถลองดู [Hyprmon](https://github.com/erans/hyprmon/) ได้เช่นกัน ถ้าคุณอยากได้ TUI มาช่วยในการจัดตำแหน่งหลายหน้าจอ

### การควบคุมความสว่าง

ความสว่างของจอภาพควบคุมด้วยปุ่มฟังก์ชันเฉพาะสำหรับเพิ่ม/ลดความสว่าง ถ้าคุณกด Shift ค้างไว้ขณะกดปุ่มเหล่านี้ คุณจะไต่ไปจนถึงความสว่างสูงสุดหรือต่ำสุด ปุ่มเหล่านี้จะควบคุมจอแสดงผลที่คุณกำลังโฟกัสอยู่ ดังนั้นจอภาพภายนอกที่สื่อสารด้วย DDC/CI จึงถูกปรับในลักษณะเดียวกับหน้าจอแล็ปท็อป

### จอแสดงผล Apple

ถ้าคุณใช้จอแสดงผล Apple ปุ่มปรับความสว่างบนคีย์บอร์ดทั่วไปก็จะทำงานโดยอัตโนมัติเช่นกัน ถ้าคุณกำลังโฟกัสอยู่ที่จอแสดงผล Apple นั้น การทำงานนี้ทำผ่านคำสั่ง `asdcontrol`

โปรดทราบว่าถ้าคุณใช้จอแสดงผล Apple 6K XDR คุณอาจเห็นหน้าจอหลอกในรายการ `hyprctl monitors` ของคุณ คุณสามารถปิดสิ่งนี้ได้ด้วยอะไรอย่างเช่น `hl.monitor({ output = "DP-2", disabled = true })` ใน `~/.config/hypr/monitors.lua`

บนเครื่อง Intel คุณควรเชื่อมต่อกับจอแสดงผล Apple โดยใช้สาย Thunderbolt ทั่วไป บนเครื่องอื่นที่ไม่มี Thunderbolt โดยทั่วไปคุณจะต้องใช้ [สาย DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) เพื่อให้มันทำงานได้
