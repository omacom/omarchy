# ปุ่มลัด

คุณสามารถดูการผูกปุ่มแป้นพิมพ์หลักทั้งหมดได้ด้วย `Super + K` (การผูกปุ่มของ Tmux ด้วย `Super + Alt + K` และการผูกปุ่มของ Herdr ด้วย `Super + Ctrl + K`)

## ปุ่มลัดถูกจัดวางอย่างไร

ปุ่มลัดทุกปุ่มอยู่บนระนาบหนึ่ง ซึ่งกำหนดโดยปุ่มตัวปรับแต่งของมัน และแต่ละระนาบมีหน้าที่เดียว นั่นคือสิ่งที่ทำให้ปุ่มลัดไม่ปะปนกัน และหมายความว่าคุณมักจะเดาได้ว่าอะไรอยู่ที่ไหน

| ระนาบ | อะไรอยู่ตรงนั้น | ตัวอย่าง |
| --- | --- | --- |
| `Super + key` | ระบบ: หน้าต่าง, workspace, เลย์เอาต์ และเมนูหลัก | `Super + Space` เมนู Omarchy, `Super + W` ปิดหน้าต่าง, `Super + F` เต็มหน้าจอ |
| `Super + Shift + key` | แอป | `Super + Shift + B` เบราว์เซอร์, `Super + Shift + E` อีเมล, `Super + Shift + N` ตัวแก้ไข |
| `Super + Ctrl + key` | แผงและเมนูระบบ | `Super + Ctrl + A` เสียง, `Super + Ctrl + N` เครือข่าย, `Super + Ctrl + C` เมนูจับภาพ |
| `Super + Ctrl + Alt + key` | การดำเนินการด่วนและการแจ้งข้อมูล | `Super + Ctrl + Alt + T` แสดงเวลา, `Super + Ctrl + Alt + B` แบตเตอรี่, `Super + Ctrl + Alt + C` ภาพหน้าจอ |

การเพิ่ม `Alt` ให้กับปุ่มลัดจะให้รูปแบบที่แตกต่างกันของสิ่งเดียวกัน ไม่ใช่สิ่งที่ไม่เกี่ยวข้องกันเลย:

- `Super + Shift + B` เปิดเบราว์เซอร์; `Super + Shift + Alt + B` เปิดหน้าต่างส่วนตัว
- `Super + Shift + E` เปิดอีเมล; `Super + Shift + Alt + E` เริ่มอีเมลใหม่
- `Super + F` เข้าสู่โหมดเต็มหน้าจอ; `Super + Alt + F` เข้าสู่โหมดเต็มความกว้าง
- `Super + Ctrl + C` เปิดเมนูจับภาพ; `Super + Ctrl + Alt + C` ข้ามเมนูและถ่ายภาพหน้าจอ

เมื่อเพิ่มปุ่มลัด:

1. เลือกระนาบจากสิ่งที่มันทำ จากนั้นเลือกปุ่ม
2. อย่าย้ายปุ่มลัดที่มีอยู่เพื่อหาที่ว่าง หาปุ่มว่างบนระนาบที่ถูกต้อง
3. ใช้ `Alt` เฉพาะสำหรับรูปแบบที่แตกต่างของปุ่มลัดที่ไม่มีมันเท่านั้น

ปุ่มลัดบางปุ่มแหกกฎเหล่านี้เพราะสะดวก `Shift` ร่วมกับลูกศรหรือ `Tab` จะย้ายหรือย้อนกลับแทนที่จะเปิดแอป และ `Print`, ปุ่มสื่อ, `Alt + Tab` และ `Ctrl + Alt + Del` ทำงานเหมือนที่ทำทุกที่อื่น พวกมันเป็นข้อยกเว้น ไม่ใช่รูปแบบให้ลอกเลียน

ถ้าค่าเริ่มต้นไม่เหมาะกับคุณ (เช่น คุณต้องการ `Super + Shift + S` สำหรับภาพหน้าจอเหมือนบน Windows) ให้ผูกปุ่มใหม่ใน `~/.config/hypr/bindings.lua`

| `Super + Alt + F`                 | เต็มความกว้าง              |
| `Super + Ctrl + F`                 | เต็มหน้าจอภายในหน้าต่าง              |
| `Super + 1/2/3/4`         | ไปยัง workspace ที่ระบุบนจอที่โฟกัสอยู่ |

| `Super + Alt + S` | ย้ายหน้าต่างไปยัง scratchpad แบบเต็ม |
| `Super + Grave` | สลับคอนโซล Quake |
| `Super + Shift + Grave` | ย้ายหน้าต่างไปยังคอนโซล Quake |

| `Super + Shift + Arrow`  | สลับหน้าต่างกับอีกหน้าต่างในทิศทางของลูกศร รวมถึงหน้าต่างบนจอฝั่งนั้น |
| `Super + Minus` | ขยายหน้าต่างไปทางซ้าย |
| `Super + Equal` | หดหน้าต่างไปทางซ้าย |
| `Super + Shift + Minus` | หดหน้าต่างขึ้น |
| `Super + Shift + Equal` | ขยายหน้าต่างลง |
| `Super + Alt + Minus/Equal` | ปรับขนาดแบบเดียวกันในขั้นที่เล็กกว่า |
| `Super + Ctrl + Minus/Equal` | ปรับขนาดแบบเดียวกันในขั้นที่ใหญ่กว่า |
| `Super + Alt + Home` | บันทึกความกว้างของหน้าต่าง |
| `Super + Home` | คืนค่าความกว้างของหน้าต่างที่บันทึกไว้ |

| `Super + Right Mouse` | ปรับขนาดหน้าต่าง |

| `Super + Alt + G`               | ย้ายหน้าต่างออกจากการจัดกลุ่ม      |

| `Super + Alt + 1/2/3/4/5`               | ไปยังหน้าต่างที่ระบุในการจัดกลุ่ม      |
| `Super + Alt + Arrow`  | ย้ายหน้าต่างเข้าไปในการจัดกลุ่มในทิศทางของลูกศร รวมถึงหน้าต่างบนจอฝั่งนั้น |
| `Super + Ctrl + Left/Right`  | ย้ายระหว่างหน้าต่างภายในกลุ่มแบบเรียงต่อกัน |
| `Super + Ctrl + Z` | ซูมเข้าบนหน้าจอ (กดซ้ำเพื่อซูมมากขึ้น) |
| `Super + Ctrl + Alt + Z` | ซูมออกจากหน้าจอทั้งหมด |
| `Super + /` | เลื่อนไปข้างหน้าผ่านตัวเลือกการปรับขนาดจอ |

| `Alt + Tab` | วนสลับไปข้างหน้าผ่านหน้าต่างบน workspace ที่ใช้งานอยู่ |
| `Alt + Shift + Tab` | วนสลับย้อนกลับผ่านหน้าต่างบน workspace ที่ใช้งานอยู่ |

| `Ctrl + Alt + Shift + Tab`| วนสลับโฟกัสย้อนกลับผ่านจอต่าง ๆ |

ปุ่มลัดปรับขนาดใช้ปุ่มทางกายภาพ `code:20` และ `code:21` (XKB `<AE11>` และ `<AE12>`) ไม่ว่าตัวอักษรที่พิมพ์บนแป้นพิมพ์จะเป็นอะไร บนแป้นพิมพ์ US ปุ่มเหล่านี้คือ `-` และ `=`; บนแป้นพิมพ์ญี่ปุ่น (JIS) คือ `-` และ `^`; บนแป้นพิมพ์สเปนคือ `'` และ `¡` บน JIS, `Super + ^` คือ `Super + Equal` ขณะที่ `Super + Shift + -` (ซึ่งพิมพ์ `=`) คือ `Super + Shift + Minus`

## การจับภาพ

| ปุ่มลัด              | ฟังก์ชัน                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | ภาพหน้าจอ                      |
| `Super + Ctrl + Alt + C`            | ภาพหน้าจอ (ภาพเดียวกัน สำหรับแป้นพิมพ์ที่ไม่มีปุ่ม Print Screen) |
| `Super + Ctrl + C` | เมนูจับภาพ |
| `Alt + Print Screen`            | บันทึกหน้าจอ                     |
| `Super + Shift + Ctrl + Alt + C` | บันทึกหน้าจอโดยไม่มีเสียง ข้ามเมนู (กดอีกครั้งเพื่อหยุด) |
| `Super + Print Screen` | ตัวเลือกสี |
| `Super + Ctrl + Print Screen` | แยกข้อความไปยังคลิปบอร์ด |
| `Super + Alt + [` | ทำให้ภาพซ้อนเว็บแคมเล็กลงขณะบันทึก |
| `Super + Alt + ]` | ทำให้ภาพซ้อนเว็บแคมใหญ่ขึ้นขณะบันทึก |

สำหรับการบันทึกหน้าจอ ปุ่มลัดจะถามก่อนว่าคุณต้องการเสียงแบบใด จากนั้นจึงเริ่มบันทึก กดอีกครั้งเพื่อหยุด ดูรายละเอียดที่ [ภาพหน้าจอและการบันทึก](12-screenshots-recording.md)

ตัวเลือกการจับภาพทั้งหมดยังเข้าถึงได้ภายใต้ _Trigger > Capture_ ในเมนู Omarchy (`Super + Space`)

## Tmux

ปุ่มนำหน้าคือ `Ctrl + Space` (`Ctrl + B` ก็ใช้ได้เช่นกัน) คุณสามารถเปลี่ยนการผูกปุ่มเหล่านี้ได้ใน `~/.config/tmux/tmux.conf`

### แผงย่อย

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + v` | แยกแผงย่อยด้านข้าง (แนวตั้ง) |
| `Prefix + h` | แยกแผงย่อยด้านล่าง (แนวนอน) |
| `Prefix + x` | ปิดแผงย่อย |
| `Prefix + z` | สลับการซูมแผงย่อย (เต็มหน้าจอ) |
| `Alt + Enter` | แยกแผงย่อยด้านล่าง (ไม่ต้องใช้ปุ่มนำหน้า) |
| `Alt + Shift + Enter` | แยกแผงย่อยด้านข้าง (ไม่ต้องใช้ปุ่มนำหน้า) |
| `Alt + Escape` | ปิดแผงย่อย (ไม่ต้องใช้ปุ่มนำหน้า) |
| `Ctrl + Alt + Arrows` | ย้ายระหว่างแผงย่อย |
| `Ctrl + Alt + Shift + Arrows` | ปรับขนาดแผงย่อย |

### หน้าต่าง

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + c` | หน้าต่างใหม่ |
| `Prefix + k` | ปิดหน้าต่าง |
| `Prefix + r` | เปลี่ยนชื่อหน้าต่าง |
| `Alt + 1-9` | ไปยังหน้าต่างที่ระบุ |
| `Alt + Arrow Left/Right` | ย้ายระหว่างหน้าต่าง |
| `Alt + Shift + Arrow Left/Right` | ย้ายหน้าต่างไปซ้าย/ขวา |

### เซสชัน

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + C` | เซสชันใหม่ |
| `Prefix + K` | ปิดเซสชัน |
| `Prefix + R` | เปลี่ยนชื่อเซสชัน |
| `Prefix + N` | เซสชันถัดไป |
| `Prefix + P` | เซสชันก่อนหน้า |
| `Alt + Arrow Up/Down` | ย้ายระหว่างเซสชัน |
| `Prefix + s` | แสดงรายการเซสชัน |
| `Prefix + d` | แยกออกจากเซสชัน |

### โหมดคัดลอก (สไตล์ vi)

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + [` | เข้าสู่โหมดคัดลอก |
| `v` | เริ่มการเลือก (ในโหมดคัดลอก) |
| `y` | คัดลอกส่วนที่เลือก (ในโหมดคัดลอก) |

### ทั่วไป

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + q` | โหลดการตั้งค่าใหม่ |
| `Prefix + ?` | แสดงปุ่มลัดของ Tmux |
| `Prefix + :` | พรอมต์คำสั่ง |

### ฟังก์ชันเลย์เอาต์ของ Tmux

ฟังก์ชันเหล่านี้ต้องรันภายในเซสชัน Tmux

| คำสั่ง | ฟังก์ชัน |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | สร้างเลย์เอาต์สำหรับพัฒนาที่มีตัวแก้ไข, AI และเทอร์มินัล |
| `tdlm <ai> [<second_ai>]` | สร้างเลย์เอาต์สำหรับพัฒนาแยกตามโฟลเดอร์ย่อย |
| `tsl <count> <command>` | สร้างเลย์เอาต์ swarm แบบหลายแผงย่อย |
