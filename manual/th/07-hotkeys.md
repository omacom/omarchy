# ปุ่มลัด

คุณสามารถดูคีย์ลัดหลักทั้งหมดได้ด้วย `Super + K` (คีย์ลัด Tmux ด้วย `Super + Alt + K` และคีย์ลัด Herdr ด้วย `Super + Ctrl + K`)

## ปุ่มลัดจัดวางอย่างไร

ปุ่มลัดทุกปุ่มอยู่บนระนาบหนึ่ง ซึ่งกำหนดโดยตัวดัดแปลงของมัน และแต่ละระนาบมีหน้าที่เดียว นั่นคือสิ่งที่ทำให้ปุ่มลัดไม่ปะปนกัน และหมายความว่าคุณมักจะเดาได้ว่าอะไรอยู่ที่ไหน

| ระนาบ | สิ่งที่อยู่ที่นั่น | ตัวอย่าง |
| --- | --- | --- |
| `Super + key` | ระบบ: หน้าต่าง, เวิร์กสเปซ, เลย์เอาต์ และเมนูหลัก | `Super + Space` เมนู Omarchy, `Super + W` ปิดหน้าต่าง, `Super + F` เต็มจอ |
| `Super + Shift + key` | แอป | `Super + Shift + B` เบราว์เซอร์, `Super + Shift + E` อีเมล, `Super + Shift + N` ตัวแก้ไข |
| `Super + Ctrl + key` | แผงและเมนูระบบ | `Super + Ctrl + A` เสียง, `Super + Ctrl + N` เครือข่าย, `Super + Ctrl + C` เมนูจับภาพ |
| `Super + Ctrl + Alt + key` | การกระทำด่วนและการแจ้งเตือน | `Super + Ctrl + Alt + T` แสดงเวลา, `Super + Ctrl + Alt + B` แบตเตอรี่, `Super + Ctrl + Alt + C` ภาพหน้าจอ |

การเพิ่ม `Alt` ให้กับปุ่มลัดจะให้รูปแบบที่แตกต่างของสิ่งเดียวกัน ไม่ใช่สิ่งที่ไม่เกี่ยวข้องกันเลย:

- `Super + Shift + B` เปิดเบราว์เซอร์; `Super + Shift + Alt + B` เปิดหน้าต่างส่วนตัว
- `Super + Shift + E` เปิดอีเมล; `Super + Shift + Alt + E` เริ่มอีเมลใหม่
- `Super + F` ไปเต็มจอ; `Super + Alt + F` ไปเต็มความกว้าง
- `Super + Ctrl + C` เปิดเมนูจับภาพ; `Super + Ctrl + Alt + C` ข้ามเมนูและถ่ายภาพหน้าจอ

เมื่อเพิ่มปุ่มลัด:

1. เลือกระนาบจากสิ่งที่มันทำ จากนั้นเลือกปุ่ม
2. อย่าย้ายปุ่มลัดที่มีอยู่เพื่อเปิดทาง หาปุ่มที่ว่างบนระนาบที่เหมาะสม
3. ใช้ `Alt` เฉพาะสำหรับรูปแบบที่แตกต่างของปุ่มลัดที่ไม่มีมันเท่านั้น

ปุ่มลัดบางปุ่มแหกกฎเหล่านี้เพราะสะดวกกว่า `Shift` พร้อมลูกศรหรือ `Tab` จะย้ายหรือย้อนกลับแทนที่จะเปิดแอป และ `Print`, ปุ่มสื่อ, `Alt + Tab` และ `Ctrl + Alt + Del` ทำงานแบบเดียวกับที่อื่น ๆ ทุกที่ พวกมันเป็นข้อยกเว้น ไม่ใช่รูปแบบให้เลียนแบบ

หากค่าเริ่มต้นไม่เหมาะกับคุณ (เช่น คุณต้องการ `Super + Shift + S` สำหรับภาพหน้าจอเหมือนบน Windows) ให้ผูกใหม่ใน `~/.config/hypr/bindings.lua`

| `Super + Tab` | กระโดดไปยังเวิร์กสเปซถัดไปบนจอภาพที่โฟกัสอยู่ |
| `Super + Shift + Tab` | กระโดดไปยังเวิร์กสเปซก่อนหน้าบนจอภาพที่โฟกัสอยู่ |
| `Super + Ctrl + Tab` | กระโดดไปยังเวิร์กสเปซก่อนหน้านี้บนจอภาพที่โฟกัสอยู่ |

| `Super + S` | สลับ scratchpad แบบเต็ม |
| `Super + Alt + S` | ย้ายหน้าต่างไปยัง scratchpad แบบเต็ม |
| `Super + Grave` | สลับคอนโซล Quake |
| `Super + Shift + Grave` | ย้ายหน้าต่างไปยังคอนโซล Quake |

| `Super + Shift + Arrow`  | สลับหน้าต่างกับอีกหน้าต่างในทิศทางของลูกศร รวมถึงหน้าต่างบนจอภาพด้านนั้น |
| `Super + Minus` | ขยายหน้าต่างไปทางซ้าย |
| `Super + Equal` | หดหน้าต่างไปทางซ้าย |
| `Super + Shift + Minus` | หดหน้าต่างขึ้นด้านบน |
| `Super + Shift + Equal` | ขยายหน้าต่างลงด้านล่าง |
| `Super + Alt + Minus/Equal` | การปรับขนาดแบบเดียวกันในขั้นตอนที่เล็กกว่า |
| `Super + Ctrl + Minus/Equal` | การปรับขนาดแบบเดียวกันในขั้นตอนที่ใหญ่กว่า |
| `Super + Alt + Home` | บันทึกความกว้างของหน้าต่าง |
| `Super + Home` | คืนค่าความกว้างของหน้าต่างที่บันทึกไว้ |
| `Super + Left Mouse` | ลากหน้าต่างไปรอบ ๆ |
| `Super + Right Mouse` | ปรับขนาดหน้าต่าง |

| `Super + G`               | สลับการจัดกลุ่มหน้าต่าง      |
| `Super + Alt + G`               | ย้ายหน้าต่างออกจากการจัดกลุ่ม      |
| `Super + Alt + Tab`               | วนระหว่างหน้าต่างในการจัดกลุ่ม      |
| `Super + Alt + Shift + Tab`               | วนย้อนกลับระหว่างหน้าต่างในการจัดกลุ่ม      |
| `Super + Alt + Scroll Wheel` | วนระหว่างหน้าต่างในการจัดกลุ่ม |
| `Super + Alt + 1/2/3/4/5`               | กระโดดไปยังหน้าต่างที่ระบุในการจัดกลุ่ม      |
| `Super + Alt + Arrow`  | ย้ายหน้าต่างเข้าสู่การจัดกลุ่มในทิศทางของลูกศร รวมถึงหน้าต่างบนจอภาพด้านนั้น |
| `Super + Ctrl + Left/Right`  | ย้ายระหว่างหน้าต่างภายในกลุ่ม tiling |
| `Super + Ctrl + Z` | ซูมเข้าบนจอ (กดซ้ำเพื่อซูมมากขึ้น) |
| `Super + Ctrl + Alt + Z` | ซูมออกเต็มที่จากจอ |
| `Super + /` | ไล่ไปข้างหน้าผ่านตัวเลือกการปรับขนาดจอภาพ |
| `Super + Alt + /` | ไล่ย้อนกลับผ่านตัวเลือกการปรับขนาดจอภาพ |
| `Alt + Tab` | วนไปข้างหน้าผ่านหน้าต่างบนเวิร์กสเปซที่ใช้งานอยู่ |
| `Alt + Shift + Tab` | วนย้อนกลับผ่านหน้าต่างบนเวิร์กสเปซที่ใช้งานอยู่ |
| `Ctrl + Alt + Tab`| วนโฟกัสไปข้างหน้าผ่านจอภาพต่าง ๆ |
| `Ctrl + Alt + Shift + Tab`| วนโฟกัสย้อนกลับผ่านจอภาพต่าง ๆ |

ปุ่มลัดปรับขนาดใช้ปุ่มทางกายภาพ `code:20` และ `code:21` (XKB `<AE11>` และ `<AE12>`) ไม่ว่าจะพิมพ์ตัวอักษรอะไรไว้บนแป้นก็ตาม บนแป้นพิมพ์ US ปุ่มเหล่านี้คือ `-` และ `=`; บนแป้นพิมพ์ญี่ปุ่น (JIS) คือ `-` และ `^`; บนแป้นพิมพ์สเปนคือ `'` และ `¡` บน JIS, `Super + ^` คือ `Super + Equal` ขณะที่ `Super + Shift + -` (ซึ่งพิมพ์ `=`) คือ `Super + Shift + Minus`

## Tmux

ปุ่ม prefix คือ `Ctrl + Space` (`Ctrl + B` ก็ใช้ได้เช่นกัน) คุณสามารถเปลี่ยนการผูกปุ่มเหล่านี้ได้ใน `~/.config/tmux/tmux.conf`

### แผงย่อย

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + v` | แยกแผงย่อยไปด้านข้าง (แนวตั้ง) |
| `Prefix + h` | แยกแผงย่อยด้านล่าง (แนวนอน) |
| `Prefix + x` | ปิดแผงย่อย |
| `Prefix + z` | สลับการซูมแผงย่อย (เต็มจอ) |
| `Alt + Enter` | แยกแผงย่อยด้านล่าง (ไม่มี prefix) |
| `Alt + Shift + Enter` | แยกแผงย่อยไปด้านข้าง (ไม่มี prefix) |
| `Alt + Escape` | ปิดแผงย่อย (ไม่มี prefix) |
| `Ctrl + Alt + Arrows` | ย้ายระหว่างแผงย่อย |
| `Ctrl + Alt + Shift + Arrows` | ปรับขนาดแผงย่อย |

### หน้าต่าง

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + c` | หน้าต่างใหม่ |
| `Prefix + k` | ปิดหน้าต่าง |
| `Prefix + r` | เปลี่ยนชื่อหน้าต่าง |
| `Alt + 1-9` | ไปยังหน้าต่างที่ระบุ |
| `Alt + Arrow Left/Right` | ย้ายระหว่างหน้าต่าง |
| `Alt + Shift + Arrow Left/Right` | ย้ายหน้าต่างไปซ้าย/ขวา |

### เซสชัน

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + C` | เซสชันใหม่ |
| `Prefix + K` | ปิดเซสชัน |
| `Prefix + R` | เปลี่ยนชื่อเซสชัน |
| `Prefix + N` | เซสชันถัดไป |
| `Prefix + P` | เซสชันก่อนหน้า |
| `Alt + Arrow Up/Down` | ย้ายระหว่างเซสชัน |
| `Prefix + s` | แสดงรายการเซสชัน |
| `Prefix + d` | ถอดออกจากเซสชัน |

### โหมดคัดลอก (สไตล์ vi)

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + [` | เข้าสู่โหมดคัดลอก |
| `v` | เริ่มการเลือก (ในโหมดคัดลอก) |
| `y` | คัดลอกส่วนที่เลือก (ในโหมดคัดลอก) |

### ทั่วไป

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + q` | โหลดการกำหนดค่าใหม่ |
| `Prefix + ?` | แสดงคีย์ลัด Tmux |
| `Prefix + :` | พรอมต์คำสั่ง |

### ฟังก์ชันเลย์เอาต์ Tmux

ฟังก์ชันเหล่านี้ต้องรันภายในเซสชัน Tmux

| คำสั่ง | ฟังก์ชัน |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | สร้างเลย์เอาต์สำหรับพัฒนาที่มีตัวแก้ไข, AI และเทอร์มินัล |
| `tdlm <ai> [<second_ai>]` | สร้างเลย์เอาต์สำหรับพัฒนาแยกตามไดเรกทอรีย่อย |
| `tsl <count> <command>` | สร้างเลย์เอาต์ swarm แบบหลายแผงย่อย |
