# ปุ่มลัด

คุณดูการผูกปุ่มหลักบนแป้นพิมพ์ทั้งหมดได้ด้วย `Super + K` (การผูกปุ่ม Tmux ด้วย `Super + Alt + K` และการผูกปุ่ม Herdr ด้วย `Super + Ctrl + K`)

## วิธีจัดวางปุ่มลัด

ปุ่มลัดทุกปุ่มอยู่บนระนาบหนึ่ง ซึ่งกำหนดโดยปุ่มปรับแต่งของมัน และแต่ละระนาบมีงานเดียว นั่นคือสิ่งที่ทำให้ปุ่มลัดไม่ปะปนกัน และหมายความว่าโดยปกติคุณเดาได้ว่าอะไรอยู่ที่ไหน

| ระนาบ | สิ่งที่อยู่บนนั้น | ตัวอย่าง |
| --- | --- | --- |
| `Super + key` | ระบบ: หน้าต่าง เวิร์กสเปซ เลย์เอาต์ และเมนูหลัก | `Super + Space` เมนู Omarchy, `Super + W` ปิดหน้าต่าง, `Super + F` เต็มหน้าจอ |
| `Super + Shift + key` | แอป | `Super + Shift + B` เบราว์เซอร์, `Super + Shift + E` อีเมล, `Super + Shift + N` โปรแกรมแก้ไข |
| `Super + Ctrl + key` | แผงและเมนูระบบ | `Super + Ctrl + A` เสียง, `Super + Ctrl + N` เครือข่าย, `Super + Ctrl + C` เมนูการจับภาพ |
| `Super + Ctrl + Alt + key` | การดำเนินการด่วนและการแจ้งเตือน | `Super + Ctrl + Alt + T` แสดงเวลา, `Super + Ctrl + Alt + B` แบตเตอรี่, `Super + Ctrl + Alt + C` ภาพหน้าจอ |

การเพิ่ม `Alt` ให้ปุ่มลัดจะให้รูปแบบหนึ่งของสิ่งเดียวกัน ไม่ใช่สิ่งที่ไม่เกี่ยวข้องกันเลย:

- `Super + Shift + B` เปิดเบราว์เซอร์; `Super + Shift + Alt + B` เปิดหน้าต่างส่วนตัว
- `Super + Shift + E` เปิดอีเมล; `Super + Shift + Alt + E` เริ่มอีเมลใหม่
- `Super + F` เข้าสู่โหมดเต็มหน้าจอ; `Super + Alt + F` เข้าสู่โหมดเต็มความกว้าง
- `Super + Ctrl + C` เปิดเมนูการจับภาพ; `Super + Ctrl + Alt + C` ข้ามเมนูและถ่ายภาพหน้าจอ

เมื่อจะเพิ่มปุ่มลัด:

1. เลือกระนาบจากสิ่งที่มันทำ จากนั้นเลือกปุ่ม
2. อย่าย้ายปุ่มลัดที่มีอยู่เพื่อหาที่ว่าง หาปุ่มที่ว่างบนระนาบที่ถูกต้อง
3. ใช้ `Alt` เฉพาะสำหรับรูปแบบหนึ่งของปุ่มลัดที่ไม่มีมันเท่านั้น

ปุ่มลัดบางปุ่มฝ่าฝืนกฎเหล่านี้เพราะสะดวกกว่า `Shift` พร้อมลูกศรหรือ `Tab` จะย้ายหรือย้อนกลับแทนที่จะเปิดแอป และ `Print` ปุ่มสื่อ `Alt + Tab` และ `Ctrl + Alt + Del` ทำงานเหมือนที่ทำในที่อื่น ๆ ทุกที่ พวกมันเป็นข้อยกเว้น ไม่ใช่รูปแบบให้ลอกเลียน

หากค่าเริ่มต้นไม่เหมาะกับคุณ (เช่น คุณต้องการ `Super + Shift + S` สำหรับภาพหน้าจอเหมือนบน Windows) ให้ผูกปุ่มใหม่ใน `~/.config/hypr/bindings.lua`

บนทัชแพด การปัดด้วยสามและสี่นิ้วจะสลับเวิร์กสเปซ ย้ายหน้าต่าง และเปิดเมนูและคอนโซล Quake; ดู [แป้นพิมพ์ เมาส์ และแทร็กแพด](34-keyboard-mouse-trackpad.md) สำหรับท่าทางต่าง ๆ

ปุ่มลัดปรับขนาดใช้ปุ่มทางกายภาพ `code:20` และ `code:21` (XKB `<AE11>` และ `<AE12>`) ไม่ว่าอักขระที่พิมพ์บนแป้นพิมพ์จะเป็นอะไร บนแป้นพิมพ์ US ปุ่มเหล่านี้คือ `-` และ `=`; บนแป้นพิมพ์ญี่ปุ่น (JIS) คือ `-` และ `^`; บนแป้นพิมพ์สเปนคือ `'` และ `¡` บน JIS `Super + ^` คือ `Super + Equal` ขณะที่ `Super + Shift + -` (ซึ่งพิมพ์ `=`) คือ `Super + Shift + Minus`

สำหรับการบันทึกหน้าจอ ปุ่มลัดจะถามก่อนว่าคุณต้องการเสียงแบบใด จากนั้นจึงเริ่มบันทึก กดอีกครั้งเพื่อหยุด ดู [ภาพหน้าจอและการบันทึก](12-screenshots-recording.md) สำหรับรายละเอียด

## Tmux

ปุ่ม prefix คือ `Ctrl + Space` (`Ctrl + B` ก็ใช้ได้เช่นกัน) คุณสามารถเปลี่ยนการผูกปุ่มเหล่านี้ใน `~/.config/tmux/tmux.conf`

### แผงย่อย

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + v` | แยกแผงย่อยไปด้านข้าง (แนวตั้ง) |
| `Prefix + h` | แยกแผงย่อยด้านล่าง (แนวนอน) |
| `Prefix + x` | ปิดแผงย่อย |
| `Prefix + z` | สลับการซูมแผงย่อย (เต็มหน้าจอ) |
| `Alt + Enter` | แยกแผงย่อยด้านล่าง (ไม่มี prefix) |
| `Alt + Shift + Enter` | แยกแผงย่อยไปด้านข้าง (ไม่มี prefix) |
| `Alt + Escape` | ปิดแผงย่อย (ไม่มี prefix) |
| `Ctrl + Alt + Arrows` | ย้ายระหว่างแผงย่อย |
| `Ctrl + Alt + Shift + Arrows` | ปรับขนาดแผงย่อย |

### หน้าต่าง

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + c` | หน้าต่างใหม่ |
| `Prefix + k` | ปิดหน้าต่าง |
| `Prefix + r` | เปลี่ยนชื่อหน้าต่าง |
| `Alt + 1-9` | ไปยังหน้าต่างที่ระบุ |
| `Alt + Arrow Left/Right` | ย้ายระหว่างหน้าต่าง |
| `Alt + Shift + Arrow Left/Right` | ย้ายหน้าต่างไปซ้าย/ขวา |

### เซสชัน

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + C` | เซสชันใหม่ |
| `Prefix + K` | ปิดเซสชัน |
| `Prefix + R` | เปลี่ยนชื่อเซสชัน |
| `Prefix + N` | เซสชันถัดไป |
| `Prefix + P` | เซสชันก่อนหน้า |
| `Alt + Arrow Up/Down` | ย้ายระหว่างเซสชัน |
| `Prefix + s` | แสดงรายการเซสชัน |
| `Prefix + d` | แยกออกจากเซสชัน |

### โหมดคัดลอก (สไตล์ vi)

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + [` | เข้าสู่โหมดคัดลอก |
| `v` | เริ่มการเลือก (ในโหมดคัดลอก) |
| `y` | คัดลอกส่วนที่เลือก (ในโหมดคัดลอก) |

### ทั่วไป

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + q` | โหลดการกำหนดค่าใหม่ |
| `Prefix + ?` | แสดงการผูกปุ่ม Tmux |
| `Prefix + :` | พรอมต์คำสั่ง |

### ฟังก์ชันเลย์เอาต์ Tmux

ฟังก์ชันเหล่านี้ต้องรันภายในเซสชัน Tmux

| คำสั่ง | ฟังก์ชัน |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | สร้างเลย์เอาต์สำหรับพัฒนาที่มีโปรแกรมแก้ไข AI และเทอร์มินัล |
| `tdlm <ai> [<second_ai>]` | สร้างเลย์เอาต์สำหรับพัฒนาแยกตามไดเรกทอรีย่อย |
| `tsl <count> <command>` | สร้างเลย์เอาต์ swarm แบบหลายแผงย่อย |
