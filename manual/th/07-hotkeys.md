# ปุ่มลัด

คุณดูการผูกปุ่มคีย์บอร์ดหลักทั้งหมดได้ด้วย `Super + K` (การผูกปุ่มของ Tmux ด้วย `Super + Alt + K` และการผูกปุ่มของ Herdr ด้วย `Super + Ctrl + K`)

## วิธีจัดวางปุ่มลัด

ปุ่มลัดทุกปุ่มอยู่บนระนาบหนึ่ง ซึ่งกำหนดโดยปุ่มตัวปรับแต่งของมัน และแต่ละระนาบมีหน้าที่เดียว นั่นคือสิ่งที่ทำให้ปุ่มลัดไม่ปะปนกัน และหมายความว่าคุณมักจะเดาได้ว่าอะไรอยู่ที่ไหน

| ระนาบ | อะไรอยู่ที่นั่น | ตัวอย่าง |
| --- | --- | --- |
| `Super + key` | ระบบ: หน้าต่าง, พื้นที่ทำงาน, เลย์เอาต์ และเมนูหลัก | `Super + Space` เมนู Omarchy, `Super + W` ปิดหน้าต่าง, `Super + F` เต็มหน้าจอ |
| `Super + Shift + key` | แอป | `Super + Shift + B` เบราว์เซอร์, `Super + Shift + E` อีเมล, `Super + Shift + N` โปรแกรมแก้ไข |
| `Super + Ctrl + key` | แผงควบคุมและเมนูระบบ | `Super + Ctrl + A` เสียง, `Super + Ctrl + N` เครือข่าย, `Super + Ctrl + C` เมนูจับภาพ |
| `Super + Ctrl + Alt + key` | การดำเนินการด่วนและการแจ้งเตือน | `Super + Ctrl + Alt + T` แสดงเวลา, `Super + Ctrl + Alt + B` แบตเตอรี่, `Super + Ctrl + Alt + C` ภาพหน้าจอ |

การเพิ่ม `Alt` ให้กับปุ่มลัดจะให้รูปแบบหนึ่งของสิ่งเดียวกันกับคุณ ไม่ใช่สิ่งที่ไม่เกี่ยวข้องกันเลย:

- `Super + Shift + B` เปิดเบราว์เซอร์; `Super + Shift + Alt + B` เปิดหน้าต่างส่วนตัว
- `Super + Shift + E` เปิดอีเมล; `Super + Shift + Alt + E` เริ่มอีเมลใหม่
- `Super + F` เข้าสู่เต็มหน้าจอ; `Super + Alt + F` เข้าสู่เต็มความกว้าง
- `Super + Ctrl + C` เปิดเมนูจับภาพ; `Super + Ctrl + Alt + C` ข้ามเมนูและถ่ายภาพหน้าจอ

เมื่อเพิ่มปุ่มลัด:

1. เลือกระนาบจากสิ่งที่มันทำ จากนั้นเลือกปุ่ม
2. อย่าย้ายปุ่มลัดที่มีอยู่เพื่อหาที่ว่าง หาปุ่มที่ว่างบนระนาบที่ถูกต้อง
3. ใช้ `Alt` เฉพาะสำหรับรูปแบบหนึ่งของปุ่มลัดที่ไม่มีมันเท่านั้น

ปุ่มลัดบางปุ่มแหกกฎเหล่านี้เพราะสะดวกกว่า `Shift` พร้อมลูกศรหรือ `Tab` จะย้ายหรือย้อนกลับแทนที่จะเปิดแอป และ `Print`, ปุ่มสื่อ, `Alt + Tab` และ `Ctrl + Alt + Del` ทำงานเหมือนที่ทำในที่อื่น ๆ พวกมันเป็นข้อยกเว้น ไม่ใช่รูปแบบให้ลอกเลียนแบบ

หากค่าเริ่มต้นไม่เหมาะกับคุณ (เช่น คุณต้องการ `Super + Shift + S` สำหรับภาพหน้าจอเหมือนบน Windows) ให้ผูกปุ่มใหม่ใน `~/.config/hypr/bindings.lua`

| `Super + Shift + Tab` | ไปยังพื้นที่ทำงานก่อนหน้าบนจอภาพที่โฟกัสอยู่ |

| `Super + Alt + 1/2/3/4/5` | ไปยังหน้าต่างที่ระบุในการจัดกลุ่ม |
| `Super + Alt + Arrow` | ย้ายหน้าต่างเข้าสู่การจัดกลุ่มในทิศทางของลูกศร รวมถึงหน้าต่างบนจอภาพด้านนั้น |
| `Super + Ctrl + Left/Right` | ย้ายระหว่างหน้าต่างภายในกลุ่มแบบเรียงกระเบื้อง |
| `Super + Ctrl + Z` | ซูมเข้าบนหน้าจอ (กดซ้ำเพื่อซูมมากขึ้น) |

| `Alt + Shift + Tab` | วนย้อนกลับผ่านหน้าต่างบนพื้นที่ทำงานที่ใช้งานอยู่ |

| `Ctrl + Alt + Shift + Tab` | วนโฟกัสย้อนกลับผ่านจอภาพ |

ปุ่มลัดปรับขนาดใช้ปุ่มทางกายภาพ `code:20` และ `code:21` (XKB `<AE11>` และ `<AE12>`) ไม่ว่าตัวอักษรที่พิมพ์บนคีย์บอร์ดจะเป็นอะไร บนคีย์บอร์ด US ปุ่มเหล่านี้คือ `-` และ `=`; บนคีย์บอร์ดญี่ปุ่น (JIS) คือ `-` และ `^`; บนคีย์บอร์ดสเปนคือ `'` และ `¡` บน JIS, `Super + ^` คือ `Super + Equal` ขณะที่ `Super + Shift + -` (ซึ่งพิมพ์ `=`) คือ `Super + Shift + Minus`

## Tmux

ปุ่ม prefix คือ `Ctrl + Space` (`Ctrl + B` ก็ใช้ได้เช่นกัน) คุณสามารถเปลี่ยนการผูกปุ่มเหล่านี้ได้ใน `~/.config/tmux/tmux.conf`

### บานหน้าต่าง

| ปุ่มลัด | ฟังก์ชัน |
| ----------------------- | --------------------- |
| `Prefix + v` | แยกบานหน้าต่างไปด้านข้าง (แนวตั้ง) |
| `Prefix + h` | แยกบานหน้าต่างด้านล่าง (แนวนอน) |
| `Prefix + x` | ปิดบานหน้าต่าง |
| `Prefix + z` | สลับการซูมบานหน้าต่าง (เต็มหน้าจอ) |
| `Alt + Enter` | แยกบานหน้าต่างด้านล่าง (ไม่มี prefix) |
| `Alt + Shift + Enter` | แยกบานหน้าต่างไปด้านข้าง (ไม่มี prefix) |
| `Alt + Escape` | ปิดบานหน้าต่าง (ไม่มี prefix) |
| `Ctrl + Alt + Arrows` | ย้ายระหว่างบานหน้าต่าง |
| `Ctrl + Alt + Shift + Arrows` | ปรับขนาดบานหน้าต่าง |

### หน้าต่าง

| ปุ่มลัด | ฟังก์ชัน |
| ----------------------- | --------------------- |
| `Prefix + c` | หน้าต่างใหม่ |
| `Prefix + k` | ปิดหน้าต่าง |
| `Prefix + r` | เปลี่ยนชื่อหน้าต่าง |
| `Alt + 1-9` | ไปยังหน้าต่างที่ระบุ |
| `Alt + Arrow Left/Right` | ย้ายระหว่างหน้าต่าง |
| `Alt + Shift + Arrow Left/Right` | ย้ายหน้าต่างไปซ้าย/ขวา |

### เซสชัน

| ปุ่มลัด | ฟังก์ชัน |
| ----------------------- | --------------------- |
| `Prefix + C` | เซสชันใหม่ |
| `Prefix + K` | ปิดเซสชัน |
| `Prefix + R` | เปลี่ยนชื่อเซสชัน |
| `Prefix + N` | เซสชันถัดไป |
| `Prefix + P` | เซสชันก่อนหน้า |
| `Alt + Arrow Up/Down` | ย้ายระหว่างเซสชัน |
| `Prefix + s` | แสดงรายการเซสชัน |
| `Prefix + d` | แยกออกจากเซสชัน |

### โหมดคัดลอก (สไตล์ vi)

| ปุ่มลัด | ฟังก์ชัน |
| ----------------------- | --------------------- |
| `Prefix + [` | เข้าสู่โหมดคัดลอก |
| `v` | เริ่มการเลือก (ในโหมดคัดลอก) |
| `y` | คัดลอกส่วนที่เลือก (ในโหมดคัดลอก) |

### ทั่วไป

| ปุ่มลัด | ฟังก์ชัน |
| ----------------------- | --------------------- |
| `Prefix + q` | โหลดการกำหนดค่าใหม่ |
| `Prefix + ?` | แสดงการผูกปุ่มของ Tmux |
| `Prefix + :` | พรอมต์คำสั่ง |

### ฟังก์ชันเลย์เอาต์ของ Tmux

ฟังก์ชันเหล่านี้ต้องรันภายในเซสชัน Tmux

| คำสั่ง | ฟังก์ชัน |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | สร้างเลย์เอาต์สำหรับพัฒนาที่มีโปรแกรมแก้ไข, AI และเทอร์มินัล |
| `tdlm <ai> [<second_ai>]` | สร้างเลย์เอาต์สำหรับพัฒนาต่อไดเรกทอรีย่อย |
| `tsl <count> <command>` | สร้างเลย์เอาต์ swarm แบบหลายบานหน้าต่าง |
