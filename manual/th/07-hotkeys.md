# คีย์ลัด

คุณสามารถดูการผูกปุ่มคีย์บอร์ดหลักทั้งหมดได้ด้วย `Super + K` (การผูกปุ่มของ Tmux ด้วย `Super + Alt + K` และการผูกปุ่มของ Herdr ด้วย `Super + Ctrl + K`)

## คีย์ลัดถูกจัดวางอย่างไร

คีย์ลัดทุกตัวอยู่บนระนาบหนึ่ง ซึ่งกำหนดโดยปุ่มตัวปรับแต่งของมัน และแต่ละระนาบมีหน้าที่เดียว นั่นคือสิ่งที่ทำให้คีย์ลัดไม่ปะปนกัน และหมายความว่าคุณมักจะเดาได้ว่าอะไรอยู่ที่ไหน

| ระนาบ | สิ่งที่อยู่บนระนาบนั้น | ตัวอย่าง |
| --- | --- | --- |
| `Super + key` | ระบบ: หน้าต่าง, workspace, เลย์เอาต์ และเมนูหลัก | `Super + Space` เมนู Omarchy, `Super + W` ปิดหน้าต่าง, `Super + F` เต็มหน้าจอ |
| `Super + Shift + key` | แอป | `Super + Shift + B` เบราว์เซอร์, `Super + Shift + E` อีเมล, `Super + Shift + N` โปรแกรมแก้ไข |
| `Super + Ctrl + key` | แผงและเมนูระบบ | `Super + Ctrl + A` เสียง, `Super + Ctrl + N` เครือข่าย, `Super + Ctrl + C` เมนูจับภาพ |
| `Super + Ctrl + Alt + key` | การกระทำด่วนและข้อความแจ้ง | `Super + Ctrl + Alt + T` แสดงเวลา, `Super + Ctrl + Alt + B` แบตเตอรี่, `Super + Ctrl + Alt + C` ภาพหน้าจอ |

การเพิ่ม `Alt` ลงในคีย์ลัดจะให้รูปแบบที่ต่างออกไปของสิ่งเดียวกัน ไม่ใช่สิ่งที่ไม่เกี่ยวข้องกันเลย:

- `Super + Shift + B` เปิดเบราว์เซอร์; `Super + Shift + Alt + B` เปิดหน้าต่างส่วนตัว
- `Super + Shift + E` เปิดอีเมล; `Super + Shift + Alt + E` เริ่มอีเมลใหม่
- `Super + F` เข้าสู่เต็มหน้าจอ; `Super + Alt + F` เข้าสู่เต็มความกว้าง
- `Super + Ctrl + C` เปิดเมนูจับภาพ; `Super + Ctrl + Alt + C` ข้ามเมนูและถ่ายภาพหน้าจอ

เมื่อเพิ่มคีย์ลัด:

1. เลือกระนาบจากสิ่งที่มันทำ จากนั้นเลือกปุ่ม
2. อย่าย้ายคีย์ลัดที่มีอยู่เพื่อหาให้มีที่ว่าง หาปุ่มว่างบนระนาบที่ถูกต้อง
3. ใช้ `Alt` เฉพาะสำหรับรูปแบบที่ต่างออกไปของคีย์ลัดที่ไม่มี `Alt` เท่านั้น

คีย์ลัดบางตัวแหกกฎเหล่านี้เพราะสะดวก `Shift` พร้อมลูกศรหรือ `Tab` จะย้ายหรือย้อนกลับแทนที่จะเปิดแอป และ `Print`, ปุ่มสื่อ, `Alt + Tab` และ `Ctrl + Alt + Del` ทำงานเหมือนที่ทำทุกที่อื่น พวกมันเป็นข้อยกเว้น ไม่ใช่แบบแผนให้ลอกตาม

หากค่าเริ่มต้นไม่เหมาะกับคุณ (เช่น คุณต้องการ `Super + Shift + S` สำหรับภาพหน้าจอแบบบน Windows) ให้ผูกปุ่มใหม่ใน `~/.config/hypr/bindings.lua`

| `Super + Shift + I` | สลับภาษาป้อนข้อมูลกลับ |

บนทัชแพด การปัดด้วยสามและสี่นิ้วจะสลับ workspace, ย้ายหน้าต่าง และเปิดเมนูและคอนโซล Quake; ดู [คีย์บอร์ด เมาส์ และแทร็กแพด](34-keyboard-mouse-trackpad.md) สำหรับท่าทางต่าง ๆ

คีย์ลัดปรับขนาดใช้ปุ่มทางกายภาพ `code:20` และ `code:21` (XKB `<AE11>` และ `<AE12>`) ไม่ว่าอักขระที่พิมพ์บนคีย์บอร์ดจะเป็นอะไรก็ตาม บนคีย์บอร์ด US ปุ่มเหล่านี้คือ `-` และ `=`; บนคีย์บอร์ดญี่ปุ่น (JIS) คือ `-` และ `^`; บนคีย์บอร์ดสเปนคือ `'` และ `¡` บน JIS, `Super + ^` คือ `Super + Equal` ในขณะที่ `Super + Shift + -` (ซึ่งพิมพ์ `=`) คือ `Super + Shift + Minus`

สำหรับการบันทึกหน้าจอ คีย์ลัดจะถามก่อนว่าคุณต้องการเสียงแบบใด จากนั้นจึงเริ่มบันทึก กดอีกครั้งเพื่อหยุด ดู [ภาพหน้าจอและการบันทึกหน้าจอ](12-screenshots-recording.md) สำหรับรายละเอียด

ตัวเลือกการจับภาพทั้งหมดยังเข้าถึงได้ภายใต้ _Trigger > Capture_ ในเมนู Omarchy (`Super + Space`)

## Tmux

ปุ่ม prefix คือ `Ctrl + Space` (`Ctrl + B` ก็ใช้ได้เช่นกัน) คุณสามารถเปลี่ยนการผูกปุ่มเหล่านี้ได้ใน `~/.config/tmux/tmux.conf`
