# ปุ่มลัด

คุณสามารถดูปุ่มลัดหลักทั้งหมดได้ด้วย `Super + K` (ปุ่มลัด Tmux ด้วย `Super + Alt + K` และปุ่มลัด Herdr ด้วย `Super + Ctrl + K`)

## วิธีจัดวางปุ่มลัด

ปุ่มลัดทุกปุ่มอยู่บนระนาบหนึ่ง ซึ่งกำหนดโดยปุ่มตัวปรับแต่งของมัน และแต่ละระนาบมีหน้าที่เพียงอย่างเดียว นั่นคือสิ่งที่ทำให้ปุ่มลัดไม่ปะปนกัน และหมายความว่าคุณมักจะเดาได้ว่าอะไรอยู่ที่ไหน

| ระนาบ | สิ่งที่อยู่ตรงนั้น | ตัวอย่าง |
| --- | --- | --- |
| `Super + key` | ระบบ: หน้าต่าง, พื้นที่ทำงาน, เลย์เอาต์ และเมนูหลัก | `Super + Space` เมนู Omarchy, `Super + W` ปิดหน้าต่าง, `Super + F` เต็มหน้าจอ |
| `Super + Shift + key` | แอป | `Super + Shift + B` เบราว์เซอร์, `Super + Shift + E` อีเมล, `Super + Shift + N` โปรแกรมแก้ไข |
| `Super + Ctrl + key` | แผงควบคุมและเมนูระบบ | `Super + Ctrl + A` เสียง, `Super + Ctrl + N` เครือข่าย, `Super + Ctrl + C` เมนูจับภาพ |
| `Super + Ctrl + Alt + key` | การกระทำด่วนและข้อความแจ้ง | `Super + Ctrl + Alt + T` แสดงเวลา, `Super + Ctrl + Alt + B` แบตเตอรี่, `Super + Ctrl + Alt + C` ภาพหน้าจอ |

การเติม `Alt` ให้กับปุ่มลัดจะให้ตัวแปรของสิ่งเดียวกันกับคุณ ไม่ใช่สิ่งที่ไม่เกี่ยวข้องกันเลย:

- `Super + Shift + B` เปิดเบราว์เซอร์; `Super + Shift + Alt + B` เปิดหน้าต่างส่วนตัว
- `Super + Shift + E` เปิดอีเมล; `Super + Shift + Alt + E` เริ่มอีเมลใหม่
- `Super + F` เข้าสู่เต็มหน้าจอ; `Super + Alt + F` ขยายเต็มความกว้าง
- `Super + Ctrl + C` เปิดเมนูจับภาพ; `Super + Ctrl + Alt + C` ข้ามเมนูและถ่ายภาพหน้าจอ

เมื่อเพิ่มปุ่มลัด:

1. เลือกระนาบจากสิ่งที่มันทำ จากนั้นเลือกปุ่ม
2. อย่าย้ายปุ่มลัดที่มีอยู่เพื่อ腾ที่ว่าง หาปุ่มว่างบนระนาบที่ถูกต้อง
3. ใช้ `Alt` เฉพาะสำหรับตัวแปรของปุ่มลัดที่ไม่มีมันเท่านั้น

ปุ่มลัดบางปุ่มแหกกฎเหล่านี้เพราะมันสะดวก `Shift` กับลูกศรหรือ `Tab` จะย้ายหรือย้อนกลับแทนที่จะเปิดแอป และ `Print`, ปุ่มสื่อ, `Alt + Tab` และ `Ctrl + Alt + Del` ทำงานเหมือนที่มันทำงานในที่อื่น ๆ พวกมันเป็นข้อยกเว้น ไม่ใช่แบบแผนให้ลอกตาม

หากค่าเริ่มต้นไม่เหมาะกับคุณ (เช่น คุณต้องการ `Super + Shift + S` สำหรับภาพหน้าจอเหมือนบน Windows) ให้ผูกปุ่มใหม่ใน `~/.config/hypr/bindings.lua`

| `Super + Shift + Tab` | กระโดดไปยังพื้นที่ทำงานก่อนหน้าบนจอภาพที่โฟกัสอยู่ |

| `Super + Alt + Scroll Wheel` | วนระหว่างหน้าต่างในการจัดกลุ่ม |

| `Super + Alt + Arrow`  | ย้ายหน้าต่างเข้าไปในการจัดกลุ่มในทิศทางของลูกศร รวมถึงหน้าต่างบนจอภาพด้านนั้น |
| `Super + Ctrl + Left/Right`  | ย้ายระหว่างหน้าต่างภายในกลุ่มแบบเรียงกระเบื้อง |
| `Super + Ctrl + Z` | ซูมเข้าบนหน้าจอ (กดซ้ำเพื่อซูมมากขึ้น) |
| `Super + Ctrl + Alt + Z` | ซูมออกจนสุดจากหน้าจอ |

| `Alt + Tab` | วนไปข้างหน้าผ่านหน้าต่างบนพื้นที่ทำงานที่ใช้งานอยู่ |
| `Alt + Shift + Tab` | วนย้อนกลับผ่านหน้าต่างบนพื้นที่ทำงานที่ใช้งานอยู่ |
| `Ctrl + Alt + Tab`| วนโฟกัสไปข้างหน้าผ่านจอภาพต่าง ๆ |
| `Ctrl + Alt + Shift + Tab`| วนโฟกัสย้อนกลับผ่านจอภาพต่าง ๆ |

แป้นลัดปรับขนาดใช้ปุ่มทางกายภาพ `code:20` และ `code:21` (XKB `<AE11>` และ `<AE12>`) โดยไม่คำนึงถึงอักขระที่พิมพ์อยู่บนแป้นพิมพ์ บนแป้นพิมพ์ US ปุ่มเหล่านี้คือ `-` และ `=`; บนแป้นพิมพ์ญี่ปุ่น (JIS) คือ `-` และ `^`; บนแป้นพิมพ์สเปนคือ `'` และ `¡` บน JIS, `Super + ^` คือ `Super + Equal`, ขณะที่ `Super + Shift + -` (ซึ่งพิมพ์ `=`) คือ `Super + Shift + Minus`

| ปุ่มลัด              | ฟังก์ชัน                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | ภาพหน้าจอ                      |

## Tmux

ปุ่ม prefix คือ `Ctrl + Space` (`Ctrl + B` ก็ใช้ได้เช่นกัน) คุณสามารถเปลี่ยนการผูกปุ่มเหล่านี้ได้ใน `~/.config/tmux/tmux.conf`

### เพน

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + v` | แยกเพนไปด้านข้าง (แนวตั้ง) |
| `Prefix + h` | แยกเพนด้านล่าง (แนวนอน) |
| `Prefix + x` | ปิดเพน |
| `Prefix + z` | สลับการซูมเพน (เต็มหน้าจอ) |
| `Alt + Enter` | แยกเพนด้านล่าง (ไม่มี prefix) |
| `Alt + Shift + Enter` | แยกเพนไปด้านข้าง (ไม่มี prefix) |
| `Alt + Escape` | ปิดเพน (ไม่มี prefix) |
| `Ctrl + Alt + Arrows` | ย้ายระหว่างเพน |
| `Ctrl + Alt + Shift + Arrows` | ปรับขนาดเพน |

### หน้าต่าง

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + c` | หน้าต่างใหม่ |
| `Prefix + k` | ปิดหน้าต่าง |
| `Prefix + r` | เปลี่ยนชื่อหน้าต่าง |
| `Alt + 1-9` | ไปยังหน้าต่างที่ระบุ |
| `Alt + Arrow Left/Right` | ย้ายระหว่างหน้าต่าง |
| `Alt + Shift + Arrow Left/Right` | ย้ายหน้าต่างไปซ้าย/ขวา |

### เซสชัน

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + C` | เซสชันใหม่ |
| `Prefix + K` | ปิดเซสชัน |
| `Prefix + R` | เปลี่ยนชื่อเซสชัน |
| `Prefix + N` | เซสชันถัดไป |
| `Prefix + P` | เซสชันก่อนหน้า |
| `Alt + Arrow Up/Down` | ย้ายระหว่างเซสชัน |
| `Prefix + s` | แสดงรายการเซสชัน |
| `Prefix + d` | แยกออกจากเซสชัน |

### โหมดคัดลอก (สไตล์ vi)

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |

| `y` | คัดลอกส่วนที่เลือก (ในโหมดคัดลอก) |

### ทั่วไป

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |

### ฟังก์ชันเลย์เอาต์ Tmux

ฟังก์ชันเหล่านี้ต้องรันภายในเซสชัน Tmux

| คำสั่ง | ฟังก์ชัน |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | สร้างเลย์เอาต์สำหรับนักพัฒนาด้วยโปรแกรมแก้ไข, AI และเทอร์มินัล |
| `tdlm <ai> [<second_ai>]` | สร้างเลย์เอาต์สำหรับนักพัฒนาต่อไดเรกทอรีย่อย |
| `tsl <count> <command>` | สร้างเลย์เอาต์ swarm แบบหลายเพน |
