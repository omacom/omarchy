# ปุ่มลัด

คุณสามารถดูการผูกปุ่มหลักทั้งหมดได้ด้วย `Super + K` (การผูกปุ่ม Tmux ด้วย `Super + Alt + K` และการผูกปุ่ม Herdr ด้วย `Super + Ctrl + K`)

## การนำทาง

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Super + Space`           | เมนู Omarchy (แอปและทุกอย่างอื่น)    |
| `Super + Alt + Space` | ตารางแอป |

| `Ctrl + Alt + Tab`| วนโฟกัสไปข้างหน้าผ่านจอภาพต่าง ๆ |
| `Ctrl + Alt + Shift + Tab`| วนโฟกัสย้อนกลับผ่านจอภาพต่าง ๆ |

ปุ่มลัดสำหรับปรับขนาดใช้ปุ่มทางกายภาพ `code:20` และ `code:21` (XKB `<AE11>` และ `<AE12>`) ไม่ว่าตัวอักษรที่พิมพ์บนแป้นพิมพ์จะเป็นอะไรก็ตาม บนแป้นพิมพ์ US ปุ่มเหล่านี้คือ `-` และ `=`; บนแป้นพิมพ์ญี่ปุ่น (JIS) คือ `-` และ `^`; บนแป้นพิมพ์สเปนคือ `'` และ `¡` บน JIS `Super + ^` คือ `Super + Equal` ในขณะที่ `Super + Shift + -` (ซึ่งพิมพ์ `=`) คือ `Super + Shift + Minus`

## Tmux

ปุ่ม prefix คือ `Ctrl + Space` (`Ctrl + B` ก็ใช้ได้เช่นกัน) คุณสามารถเปลี่ยนการผูกปุ่มเหล่านี้ได้ใน `~/.config/tmux/tmux.conf`

### เพน

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + v` | แยกเพนไว้ข้าง ๆ (แนวตั้ง) |
| `Prefix + h` | แยกเพนไว้ด้านล่าง (แนวนอน) |
| `Prefix + x` | ปิดเพน |
| `Prefix + z` | สลับการซูมเพน (เต็มจอ) |
