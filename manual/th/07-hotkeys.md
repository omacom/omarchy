# ปุ่มลัด

คุณสามารถดูการผูกปุ่มบนคีย์บอร์ดหลักทั้งหมดได้ด้วย `Super + K` (การผูกปุ่ม Tmux ด้วย `Super + Alt + K` และการผูกปุ่ม Herdr ด้วย `Super + Ctrl + K`)

## วิธีการจัดวางปุ่มลัด

ปุ่มลัดทุกปุ่มอยู่บนระนาบหนึ่ง ซึ่งกำหนดโดยปุ่มประกอบของมัน และแต่ละระนาบมีงานเดียว นั่นคือสิ่งที่ทำให้ปุ่มลัดไม่ปะปนกัน และหมายความว่าโดยปกติคุณสามารถเดาได้ว่าสิ่งใดอยู่ตรงไหน

| ระนาบ | สิ่งที่อยู่บนระนาบนั้น | ตัวอย่าง |
| --- | --- | --- |
| `Super + key` | ระบบ: หน้าต่าง, พื้นที่ทำงาน, เค้าโครง และเมนูหลัก | `Super + Space` เมนู Omarchy, `Super + W` ปิดหน้าต่าง, `Super + F` เต็มจอ |
| `Super + Shift + key` | แอป | `Super + Shift + B` เบราว์เซอร์, `Super + Shift + E` อีเมล, `Super + Shift + N` โปรแกรมแก้ไข |
| `Super + Ctrl + key` | แผงควบคุมและเมนูระบบ | `Super + Ctrl + A` เสียง, `Super + Ctrl + N` เครือข่าย, `Super + Ctrl + C` เมนูจับภาพ |
| `Super + Ctrl + Alt + key` | การดำเนินการด่วนและการแจ้งเตือน | `Super + Ctrl + Alt + T` แสดงเวลา, `Super + Ctrl + Alt + B` แบตเตอรี่, `Super + Ctrl + Alt + C` ภาพหน้าจอ |

การเพิ่ม `Alt` ให้กับปุ่มลัดจะให้รูปแบบที่ต่างออกไปของสิ่งเดียวกัน ไม่ใช่สิ่งที่ไม่เกี่ยวข้องกันเลย:

- `Super + Shift + B` เปิดเบราว์เซอร์; `Super + Shift + Alt + B` เปิดหน้าต่างส่วนตัว
- `Super + Shift + E` เปิดอีเมล; `Super + Shift + Alt + E` เริ่มอีเมลใหม่
- `Super + F` เข้าสู่เต็มจอ; `Super + Alt + F` เข้าสู่เต็มความกว้าง
- `Super + Ctrl + C` เปิดเมนูจับภาพ; `Super + Ctrl + Alt + C` ข้ามเมนูและถ่ายภาพหน้าจอ

เมื่อเพิ่มปุ่มลัด:

1. เลือกระนาบจากสิ่งที่มันทำ จากนั้นเลือกปุ่ม
2. อย่าย้ายปุ่มลัดที่มีอยู่เพื่อสร้างที่ว่าง หาปุ่มที่ว่างบนระนาบที่ถูกต้อง
3. ใช้ `Alt` สำหรับรูปแบบที่ต่างออกไปของปุ่มลัดที่ไม่มีมันเท่านั้น

ปุ่มลัดบางปุ่มแหกกฎเหล่านี้เพราะสะดวกกว่า `Shift` กับลูกศรหรือ `Tab` จะย้ายหรือย้อนกลับแทนที่จะเปิดแอป และ `Print`, ปุ่มสื่อ, `Alt + Tab` และ `Ctrl + Alt + Del` ทำงานเหมือนที่พวกมันทำงานที่อื่นทุกที่ พวกมันเป็นข้อยกเว้น ไม่ใช่รูปแบบให้เลียนแบบ

หากค่าเริ่มต้นไม่เหมาะกับคุณ (เช่น คุณต้องการ `Super + Shift + S` สำหรับภาพหน้าจอเหมือนบน Windows) ให้ผูกปุ่มใหม่ใน `~/.config/hypr/bindings.lua`

บนทัชแพด การปัดด้วยสามและสี่นิ้วจะสลับพื้นที่ทำงาน ย้ายหน้าต่าง และเปิดเมนูและคอนโซล Quake ดูท่าทางต่าง ๆ ได้ที่ [คีย์บอร์ด เมาส์ และแทร็กแพด](34-keyboard-mouse-trackpad.md)

การปรับขนาดใช้สองปุ่มทางขวาของ 0 ไม่ว่าคีย์บอร์ดของคุณจะพิมพ์อะไรไว้บนปุ่มเหล่านั้น: `-` และ `=` บนคีย์บอร์ด US, `+` และ `´` บนภาษาเดนมาร์กและสวีเดน, `+` และ `\` บนภาษานอร์เวย์, `ß` และ `´` บนภาษาเยอรมัน, `'` และ `¡` บนภาษาสเปน และ `-` และ `^` บนภาษาญี่ปุ่น (JIS) `Super + K` จะแสดงรายการตามที่คีย์บอร์ดของคุณพิมพ์ไว้ บน JIS, `Super + ^` คือ `Super + Equal` ขณะที่ `Super + Shift + -` (ซึ่งพิมพ์ `=`) คือ `Super + Shift + Minus` การปรับสเกลจอภาพและโปรแกรมจัดการรหัสผ่านใช้ `/`; บนเค้าโครงที่พิมพ์ `/` ได้เฉพาะเมื่อใช้ Shift เท่านั้น อย่างเช่นเค้าโครงยุโรปส่วนใหญ่ จะใช้ปุ่มทางซ้ายของ Shift ขวาแทน (`-` บนภาษาเดนมาร์กและเยอรมัน)

โดยปกติบน Linux คุณต้องใช้ `Ctrl + Shift + C/V` เพื่อคัดลอกและวางในเทอร์มินัล และใช้ `Ctrl + C/V` เพื่อทำแบบนั้นที่อื่นทุกที่ ปุ่มลัดคลิปบอร์ดแบบรวมของ Omarchy เหล่านี้ใช้งานได้ทุกที่

## Tmux

ปุ่ม prefix คือ `Ctrl + Space` (`Ctrl + B` ก็ใช้ได้เช่นกัน) คุณสามารถเปลี่ยนการผูกปุ่มเหล่านี้ได้ใน `~/.config/tmux/tmux.conf`

### บานหน้าต่าง

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + v` | แยกบานหน้าต่างไปด้านข้าง (แนวตั้ง) |
| `Prefix + h` | แยกบานหน้าต่างไปด้านล่าง (แนวนอน) |
| `Prefix + x` | ปิดบานหน้าต่าง |
| `Prefix + z` | สลับการซูมบานหน้าต่าง (เต็มจอ) |
| `Alt + Enter` | แยกบานหน้าต่างไปด้านล่าง (ไม่ใช้ prefix) |
| `Alt + Shift + Enter` | แยกบานหน้าต่างไปด้านข้าง (ไม่ใช้ prefix) |
| `Alt + Escape` | ปิดบานหน้าต่าง (ไม่ใช้ prefix) |
| `Ctrl + Alt + Arrows` | ย้ายระหว่างบานหน้าต่าง |
| `Ctrl + Alt + Shift + Arrows` | ปรับขนาดบานหน้าต่าง |

### หน้าต่าง

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + c` | หน้าต่างใหม่ |
| `Prefix + k` | ปิดหน้าต่าง |
| `Prefix + r` | เปลี่ยนชื่อหน้าต่าง |

| `Alt + Shift + Arrow Left/Right` | ย้ายหน้าต่างไปซ้าย/ขวา |

### เซสชัน

| `Prefix + N` | เซสชันถัดไป |
| `Prefix + P` | เซสชันก่อนหน้า |
