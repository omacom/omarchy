# ปุ่มลัด

คุณสามารถดูการผูกปุ่มหลักทั้งหมดได้ด้วย `Super + K` (การผูกปุ่ม Tmux ด้วย `Super + Alt + K` และการผูกปุ่ม Herdr ด้วย `Super + Ctrl + K`)

## วิธีจัดวางปุ่มลัด

ปุ่มลัดทุกปุ่มอยู่บนระนาบหนึ่ง ซึ่งกำหนดโดยปุ่มปรับแต่งของมัน และแต่ละระนาบมีหน้าที่หนึ่งอย่าง นั่นคือสิ่งที่ทำให้ปุ่มลัดไม่ปะปนกัน และหมายความว่าโดยปกติคุณสามารถเดาได้ว่าสิ่งต่าง ๆ อยู่ที่ไหน

| ระนาบ | สิ่งที่อยู่บนระนาบนั้น | ตัวอย่าง |
| --- | --- | --- |
| `Super + key` | ระบบ: หน้าต่าง พื้นที่ทำงาน เค้าโครง และเมนูหลัก | `Super + Space` เมนู Omarchy, `Super + W` ปิดหน้าต่าง, `Super + F` เต็มหน้าจอ |
| `Super + Shift + key` | แอป | `Super + Shift + B` เบราว์เซอร์, `Super + Shift + E` อีเมล, `Super + Shift + N` ตัวแก้ไข |
| `Super + Ctrl + key` | แผงและเมนูระบบ | `Super + Ctrl + A` เสียง, `Super + Ctrl + N` เครือข่าย, `Super + Ctrl + C` เมนูการจับภาพ |
| `Super + Ctrl + Alt + key` | การดำเนินการด่วนและการแจ้งข้อมูล | `Super + Ctrl + Alt + T` แสดงเวลา, `Super + Ctrl + Alt + B` แบตเตอรี่, `Super + Ctrl + Alt + C` ภาพหน้าจอ |

การเพิ่ม `Alt` ให้กับปุ่มลัดจะให้รูปแบบที่แตกต่างของสิ่งเดียวกัน ไม่ใช่สิ่งที่ไม่เกี่ยวข้องกันเลย:

- `Super + Shift + B` เปิดเบราว์เซอร์; `Super + Shift + Alt + B` เปิดหน้าต่างส่วนตัว
- `Super + Shift + E` เปิดอีเมล; `Super + Shift + Alt + E` เริ่มอีเมลใหม่
- `Super + F` เข้าสู่เต็มหน้าจอ; `Super + Alt + F` เข้าสู่เต็มความกว้าง
- `Super + Ctrl + C` เปิดเมนูการจับภาพ; `Super + Ctrl + Alt + C` ข้ามเมนูและถ่ายภาพหน้าจอ

เมื่อเพิ่มปุ่มลัด:

1. เลือกระนาบจากสิ่งที่มันทำ จากนั้นเลือกปุ่ม
2. อย่าย้ายปุ่มลัดที่มีอยู่เพื่อสร้างที่ว่าง หาปุ่มที่ว่างบนระนาบที่ถูกต้อง
3. ใช้ `Alt` เฉพาะสำหรับรูปแบบที่แตกต่างของปุ่มลัดที่ไม่มีมันเท่านั้น

ปุ่มลัดบางปุ่มฝ่าฝืนกฎเหล่านี้เพราะสะดวก `Shift` พร้อมลูกศรหรือ `Tab` จะย้ายหรือย้อนกลับแทนที่จะเปิดแอป และ `Print`, ปุ่มสื่อ, `Alt + Tab` และ `Ctrl + Alt + Del` ทำงานเหมือนที่ทำในที่อื่น ๆ พวกมันเป็นข้อยกเว้น ไม่ใช่รูปแบบให้ลอกเลียนแบบ

หากค่าเริ่มต้นไม่เหมาะกับคุณ (เช่น คุณต้องการ `Super + Shift + S` สำหรับภาพหน้าจอเหมือนบน Windows) ให้ผูกปุ่มใหม่ใน `~/.config/hypr/bindings.lua`

| `Super + I` | สลับภาษาป้อนข้อมูล (เมื่อมีเค้าโครงหรือวิธีการป้อนข้อมูลมากกว่าหนึ่งแบบ) |
| `Super + Shift + I` | สลับภาษาป้อนข้อมูลกลับ |

บนทัชแพด การปัดด้วยสามและสี่นิ้วจะสลับพื้นที่ทำงาน ย้ายหน้าต่าง และเปิดเมนูและคอนโซล Quake; ดู [แป้นพิมพ์ เมาส์ และแทร็กแพด](34-keyboard-mouse-trackpad.md) สำหรับท่าทางต่าง ๆ

ปุ่มลัดปรับขนาดใช้ปุ่มกายภาพ `code:20` และ `code:21` (XKB `<AE11>` และ `<AE12>`) ไม่ว่าอักขระที่พิมพ์บนแป้นพิมพ์จะเป็นอะไร บนแป้นพิมพ์ US ปุ่มเหล่านี้คือ `-` และ `=`; บนแป้นพิมพ์ญี่ปุ่น (JIS) คือ `-` และ `^`; บนแป้นพิมพ์สเปนคือ `'` และ `¡` บน JIS, `Super + ^` คือ `Super + Equal` ขณะที่ `Super + Shift + -` (ซึ่งพิมพ์ `=`) คือ `Super + Shift + Minus`

## Tmux

ปุ่ม prefix คือ `Ctrl + Space` (`Ctrl + B` ก็ใช้ได้เช่นกัน) คุณสามารถเปลี่ยนการผูกปุ่มเหล่านี้ได้ใน `~/.config/tmux/tmux.conf`

### บานหน้าต่าง

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + v` | แยกบานข้าง ๆ (แนวตั้ง) |
| `Prefix + h` | แยกบานด้านล่าง (แนวนอน) |
| `Prefix + x` | ปิดบาน |
| `Prefix + z` | สลับการซูมบาน (เต็มหน้าจอ) |
| `Alt + Enter` | แยกบานด้านล่าง (ไม่ต้องใช้ prefix) |
| `Alt + Shift + Enter` | แยกบานข้าง ๆ (ไม่ต้องใช้ prefix) |
| `Alt + Escape` | ปิดบาน (ไม่ต้องใช้ prefix) |
| `Ctrl + Alt + Arrows` | ย้ายระหว่างบานต่าง ๆ |
| `Ctrl + Alt + Shift + Arrows` | ปรับขนาดบานต่าง ๆ |

### หน้าต่าง

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + c` | หน้าต่างใหม่ |
| `Prefix + k` | ปิดหน้าต่าง |
| `Prefix + r` | เปลี่ยนชื่อหน้าต่าง |
| `Alt + 1-9` | ไปยังหน้าต่างที่ระบุ |
| `Alt + Arrow Left/Right` | ย้ายระหว่างหน้าต่าง |
| `Alt + Shift + Arrow Left/Right` | ย้ายหน้าต่างไปซ้าย/ขวา |

### เซสชัน

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + C` | เซสชันใหม่ |
| `Prefix + K` | ปิดเซสชัน |
| `Prefix + R` | เปลี่ยนชื่อเซสชัน |
| `Prefix + N` | เซสชันถัดไป |
| `Prefix + P` | เซสชันก่อนหน้า |
