# ปุ่มลัด

คุณสามารถดูการผูกปุ่มคีย์บอร์ดหลักทั้งหมดได้ด้วย `Super + K` (การผูกปุ่มของ Tmux ด้วย `Super + Alt + K` และการผูกปุ่มของ Herdr ด้วย `Super + Ctrl + K`)

## การนำทาง

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Super + Space`           | เมนู Omarchy (แอปและทุกอย่างอื่น)    |
| `Super + Alt + Space` | ตารางแอป |
| `Super + Escape` | เมนูระบบ (พักเครื่อง, รีสตาร์ท ฯลฯ)  |
| `Super + Ctrl + L` | ล็อกคอมพิวเตอร์ |
| `Super + W` or `Super + Q` | ปิดหน้าต่าง             |
| `Ctrl + Alt + Del` | ปิดหน้าต่างทั้งหมด |
| `Super + T`               | สลับหน้าต่างระหว่างแบบเรียงต่อกัน/แบบลอย             |
| `Super + J` | สลับตำแหน่งหน้าต่าง (แนวนอน/แนวตั้ง) |
| `Super + O`               | สลับการดึงหน้าต่างออกมาเป็นแบบ sticky'n'floating |
| `Super + L`               | วนสลับระหว่างเลย์เอาต์ dwindle, scrolling และ floating |
| `Super + Alt + L`         | วนสลับเลย์เอาต์ในทิศทางย้อนกลับ |
| `Super + P`               | สลับสไตล์หน้าต่างแบบ pseudo (แบบธรรมชาติ v แบบยืด) |
| `Super + F`                 | เข้าสู่โหมดเต็มหน้าจอ              |
| `Super + Alt + F`                 | ขยายเต็มความกว้าง              |
| `Super + Ctrl + F`                 | เข้าสู่โหมดเต็มหน้าจอภายในหน้าต่าง              |
| `Super + 1/2/3/4`         | ข้ามไปยัง workspace ที่ระบุบนจอภาพที่โฟกัสอยู่ |
| `Super + Tab` | ข้ามไปยัง workspace ถัดไปบนจอภาพที่โฟกัสอยู่ |
| `Super + Shift + Tab` | ข้ามไปยัง workspace ก่อนหน้าบนจอภาพที่โฟกัสอยู่ |
| `Super + Ctrl + Tab` | ข้ามไปยัง workspace เดิมบนจอภาพที่โฟกัสอยู่ |
| `Super + Shift + 1/2/3/4` | ย้ายหน้าต่างไปยัง workspace บนจอภาพที่โฟกัสอยู่ |
| `Super + Shift + Alt + 1/2/3/4` | ย้ายหน้าต่างไปยัง workspace บนจอภาพที่โฟกัสอยู่โดยไม่ตามไป |
| `Super + S` | สลับ scratchpad แบบเต็มหน้าจอ |
| `Super + Alt + S` | ย้ายหน้าต่างไปยัง scratchpad แบบเต็มหน้าจอ |
| `Super + Grave` | สลับคอนโซล Quake |
| `Super + Shift + Grave` | ย้ายหน้าต่างไปยังคอนโซล Quake |
| `Super + Shift + Ctrl + Arrows` | ย้ายหน้าต่างไปยังจอภาพในทิศทางนั้น |
| `Super + Shift + Alt + Arrows` | ย้าย workspace ไปยังจอภาพในทิศทางนั้น |
| `Super + Arrow`  | ย้ายโฟกัสไปยังหน้าต่างในทิศทางของลูกศร โดยข้ามไปยังจอภาพด้านนั้นเมื่อถึงขอบหน้าจอ |
| `Super + Shift + Arrow`  | สลับหน้าต่างกับอีกหน้าต่างหนึ่งในทิศทางของลูกศร รวมถึงหน้าต่างบนจอภาพด้านนั้นด้วย |
| `Super + Minus` | ขยายหน้าต่างไปทางซ้าย |
| `Super + Equal` | ย่อหน้าต่างไปทางซ้าย |
| `Super + Shift + Minus` | ย่อหน้าต่างขึ้นด้านบน |
| `Super + Shift + Equal` | ขยายหน้าต่างลงด้านล่าง |
| `Super + Alt + Minus/Equal` | ปรับขนาดแบบเดียวกันในขั้นตอนที่เล็กกว่า |
| `Super + Ctrl + Minus/Equal` | ปรับขนาดแบบเดียวกันในขั้นตอนที่ใหญ่กว่า |
| `Super + Alt + Home` | บันทึกความกว้างของหน้าต่าง |
| `Super + Home` | คืนค่าความกว้างของหน้าต่างที่บันทึกไว้ |
| `Super + Left Mouse` | ลากหน้าต่างไปรอบ ๆ |
| `Super + Right Mouse` | ปรับขนาดหน้าต่าง |
| `Super + Scroll Wheel` | เลื่อนผ่าน workspace ต่าง ๆ บนจอภาพที่โฟกัสอยู่ |
| `Super + G`               | สลับการจัดกลุ่มหน้าต่าง      |
| `Super + Alt + G`               | ย้ายหน้าต่างออกจากการจัดกลุ่ม      |
| `Super + Alt + Tab`               | วนสลับระหว่างหน้าต่างในกลุ่ม      |
| `Super + Alt + Shift + Tab`               | วนสลับย้อนกลับระหว่างหน้าต่างในกลุ่ม      |
| `Super + Alt + Scroll Wheel` | วนสลับระหว่างหน้าต่างในกลุ่ม |
| `Super + Alt + 1/2/3/4/5`               | ข้ามไปยังหน้าต่างที่ระบุในกลุ่ม      |
| `Super + Alt + Arrow`  | ย้ายหน้าต่างเข้าไปในกลุ่มในทิศทางของลูกศร รวมถึงหน้าต่างบนจอภาพด้านนั้นด้วย |
| `Super + Ctrl + Left/Right`  | ย้ายระหว่างหน้าต่างภายในกลุ่มแบบเรียงต่อกัน |
| `Super + Ctrl + Z` | ซูมเข้าบนหน้าจอ (กดซ้ำเพื่อซูมมากขึ้น) |
| `Super + Ctrl + Alt + Z` | ซูมออกจากหน้าจอจนสุด |
| `Super + /` | เลื่อนไปข้างหน้าผ่านตัวเลือกการปรับขนาดจอภาพ |
| `Super + Alt + /` | เลื่อนย้อนกลับผ่านตัวเลือกการปรับขนาดจอภาพ |
| `Alt + Tab` | วนไปข้างหน้าผ่านหน้าต่างต่าง ๆ บน workspace ที่ใช้งานอยู่ |
| `Alt + Shift + Tab` | วนย้อนกลับผ่านหน้าต่างต่าง ๆ บน workspace ที่ใช้งานอยู่ |
| `Ctrl + Alt + Tab`| วนโฟกัสไปข้างหน้าผ่านจอภาพต่าง ๆ |
| `Ctrl + Alt + Shift + Tab`| วนโฟกัสย้อนกลับผ่านจอภาพต่าง ๆ |

## คลิปบอร์ดสากล

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Super + C`           | คัดลอก    |
| `Super + X`           | ตัด (ไม่ได้ในเทอร์มินัล)    |
| `Super + V`           | วาง    |
| `Super + Ctrl + V`           | ตัวจัดการคลิปบอร์ด    |

โดยปกติบน Linux คุณต้องใช้ `Ctrl + Shift + C/V` เพื่อ copy'n'paste ในเทอร์มินัล และใช้ `Ctrl + C/V` เพื่อทำแบบเดียวกันในที่อื่น ๆ ปุ่มลัดคลิปบอร์ดแบบรวมศูนย์ของ Omarchy เหล่านี้ใช้ได้ทุกที่

## การจับภาพ

| ปุ่มลัด              | ฟังก์ชัน                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | ภาพหน้าจอ                      |
| `Super + Ctrl + Alt + C`            | ภาพหน้าจอ (ภาพเดียวกัน สำหรับคีย์บอร์ดที่ไม่มีปุ่ม Print Screen) |
| `Super + Ctrl + C` | เมนูการจับภาพ |
| `Alt + Print Screen`            | การบันทึกหน้าจอ                     |
| `Super + Print Screen` | ตัวเลือกสี |
| `Super + Ctrl + Print Screen` | การดึงข้อความไปยังคลิปบอร์ด |
| `Super + Alt + [` | ทำให้ภาพซ้อนเว็บแคมเล็กลงขณะบันทึก |
| `Super + Alt + ]` | ทำให้ภาพซ้อนเว็บแคมใหญ่ขึ้นขณะบันทึก |
| `Alt + Shift + L` | คัดลอก URL ปัจจุบันจาก webapp หรือ Chromium |
| `Alt + Shift + D` | ดาวน์โหลดวิดีโอบนหน้าปัจจุบันไปยัง `~/Videos` |
| `Super + Ctrl + X` | เริ่ม/หยุดการพิมพ์ด้วยเสียง (ต้องใช้ _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | การพิมพ์ด้วยเสียงแบบกดเพื่อพูด (ต้องใช้ Voxtype หรือ Superwhisper) |

สำหรับการบันทึกหน้าจอ ปุ่มลัดจะถามก่อนว่าคุณต้องการเสียงแบบใด จากนั้นจึงเริ่มบันทึก กดอีกครั้งเพื่อหยุด ดูรายละเอียดได้ที่ [ภาพหน้าจอและการบันทึก](12-screenshots-recording.md)

ตัวเลือกการจับภาพทั้งหมดยังเข้าถึงได้ภายใต้ _Trigger > Capture_ ในเมนู Omarchy (`Super + Space`) ด้วย

## Tmux

ปุ่ม prefix คือ `Ctrl + Space` (`Ctrl + B` ก็ใช้ได้เช่นกัน) คุณสามารถเปลี่ยนการผูกปุ่มเหล่านี้ได้ใน `~/.config/tmux/tmux.conf`

### เพน

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + v` | แยกเพนไว้ข้าง ๆ (แนวตั้ง) |
| `Prefix + h` | แยกเพนไว้ด้านล่าง (แนวนอน) |
| `Prefix + x` | ปิดเพน |
| `Prefix + z` | สลับการซูมเพน (เต็มหน้าจอ) |
| `Alt + Enter` | แยกเพนไว้ด้านล่าง (ไม่ต้องใช้ prefix) |
| `Alt + Shift + Enter` | แยกเพนไว้ข้าง ๆ (ไม่ต้องใช้ prefix) |
| `Alt + Escape` | ปิดเพน (ไม่ต้องใช้ prefix) |
| `Ctrl + Alt + Arrows` | ย้ายระหว่างเพน |
| `Ctrl + Alt + Shift + Arrows` | ปรับขนาดเพน |

### หน้าต่าง

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + c` | หน้าต่างใหม่ |
| `Prefix + k` | ปิดหน้าต่าง |
