# ปุ่มลัด

คุณสามารถดูปุ่มลัดหลักทั้งหมดได้ด้วย `Super + K` (ปุ่มลัด Tmux ด้วย `Super + Alt + K` และปุ่มลัด Herdr ด้วย `Super + Ctrl + K`)

## วิธีจัดวางปุ่มลัด

ปุ่มลัดทุกปุ่มอยู่บนระนาบหนึ่ง ซึ่งกำหนดโดยปุ่มปรับแต่งของมัน และแต่ละระนาบมีหน้าที่หนึ่งอย่าง นั่นคือสิ่งที่ทำให้ปุ่มลัดไม่ปะปนกัน และหมายความว่าโดยปกติคุณสามารถเดาได้ว่าอะไรอยู่ที่ไหน

| ระนาบ | สิ่งที่อยู่บนระนาบนี้ | ตัวอย่าง |
| --- | --- | --- |
| `Super + key` | ระบบ: หน้าต่าง, พื้นที่ทำงาน, เลย์เอาต์, และเมนูหลัก | `Super + Space` เมนู Omarchy, `Super + W` ปิดหน้าต่าง, `Super + F` เต็มหน้าจอ |
| `Super + Shift + key` | แอป | `Super + Shift + B` เบราว์เซอร์, `Super + Shift + E` อีเมล, `Super + Shift + N` โปรแกรมแก้ไข |
| `Super + Ctrl + key` | แผงควบคุมและเมนูระบบ | `Super + Ctrl + A` เสียง, `Super + Ctrl + N` เครือข่าย, `Super + Ctrl + C` เมนูจับภาพ |
| `Super + Ctrl + Alt + key` | การกระทำด่วนและการแจ้งเตือน | `Super + Ctrl + Alt + T` แสดงเวลา, `Super + Ctrl + Alt + B` แบตเตอรี่, `Super + Ctrl + Alt + C` ภาพหน้าจอ |

การเพิ่ม `Alt` ให้กับปุ่มลัดจะให้รูปแบบหนึ่งของสิ่งเดียวกันกับคุณ ไม่ใช่สิ่งที่ไม่เกี่ยวข้องเลย:

- `Super + Shift + B` เปิดเบราว์เซอร์; `Super + Shift + Alt + B` เปิดหน้าต่างส่วนตัว
- `Super + Shift + E` เปิดอีเมล; `Super + Shift + Alt + E` เริ่มอีเมลใหม่
- `Super + F` ไปเต็มหน้าจอ; `Super + Alt + F` ไปเต็มความกว้าง
- `Super + Ctrl + C` เปิดเมนูจับภาพ; `Super + Ctrl + Alt + C` ข้ามเมนูและถ่ายภาพหน้าจอ

เมื่อจะเพิ่มปุ่มลัด:

1. เลือกระนาบจากสิ่งที่มันทำ จากนั้นเลือกปุ่ม
2. อย่าย้ายปุ่มลัดที่มีอยู่เพื่อสร้างที่ว่าง หาปุ่มว่างบนระนาบที่ถูกต้อง
3. ใช้ `Alt` เฉพาะสำหรับรูปแบบหนึ่งของปุ่มลัดที่ไม่มีมันเท่านั้น

ปุ่มลัดบางปุ่มฝ่าฝืนกฎเหล่านี้เพราะสะดวก `Shift` พร้อมลูกศรหรือ `Tab` จะย้ายหรือย้อนกลับแทนที่จะเปิดแอป และ `Print`, ปุ่มสื่อ, `Alt + Tab`, และ `Ctrl + Alt + Del` ทำงานแบบเดียวกับที่อื่นๆ ทุกที่ สิ่งเหล่านี้เป็นข้อยกเว้น ไม่ใช่รูปแบบให้ลอกเลียน

หากค่าเริ่มต้นไม่เหมาะกับคุณ (เช่น คุณต้องการ `Super + Shift + S` สำหรับภาพหน้าจอเหมือนบน Windows) ให้ผูกใหม่ใน `~/.config/hypr/bindings.lua`

| `Super + Shift + I` | สลับภาษาสำหรับป้อนข้อมูลกลับ |

บนทัชแพด การปัดสามและสี่นิ้วจะสลับพื้นที่ทำงาน ย้ายหน้าต่าง และเปิดเมนูและคอนโซล Quake; ดู [แป้นพิมพ์ เมาส์ และแทร็กแพด](34-keyboard-mouse-trackpad.md) สำหรับท่าทางต่างๆ

ปุ่มลัดปรับขนาดใช้ปุ่มทางกายภาพ `code:20` และ `code:21` (XKB `<AE11>` และ `<AE12>`) โดยไม่คำนึงถึงอักขระที่พิมพ์บนแป้นพิมพ์ บนแป้นพิมพ์ US ปุ่มเหล่านี้คือ `-` และ `=`; บนแป้นพิมพ์ญี่ปุ่น (JIS) คือ `-` และ `^`; บนแป้นพิมพ์สเปนคือ `'` และ `¡` บน JIS, `Super + ^` คือ `Super + Equal` ในขณะที่ `Super + Shift + -` (ซึ่งพิมพ์ `=`) คือ `Super + Shift + Minus`

## Tmux

ปุ่ม prefix คือ `Ctrl + Space` (`Ctrl + B` ก็ใช้งานได้เช่นกัน) คุณสามารถเปลี่ยนการผูกเหล่านี้ได้ใน `~/.config/tmux/tmux.conf`
