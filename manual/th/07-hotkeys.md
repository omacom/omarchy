# ปุ่มลัด

คุณสามารถดูปุ่มลัดหลักทั้งหมดได้ด้วย `Super + K` (ปุ่มลัด Tmux ด้วย `Super + Alt + K` และปุ่มลัด Herdr ด้วย `Super + Ctrl + K`)

## ปุ่มลัดจัดวางอย่างไร

ปุ่มลัดทุกปุ่มอยู่บนระนาบหนึ่ง ซึ่งกำหนดโดยปุ่มปรับแต่งของมัน และแต่ละระนาบมีงานเดียว นั่นคือสิ่งที่ทำให้ปุ่มลัดไม่เบลอเข้าด้วยกัน และหมายความว่าโดยปกติคุณสามารถเดาได้ว่าอะไรอยู่ที่ไหน

| ระนาบ | สิ่งที่อยู่ตรงนั้น | ตัวอย่าง |
| --- | --- | --- |
| `Super + key` | ระบบ: หน้าต่าง พื้นที่ทำงาน เลย์เอาต์ และเมนูหลัก | `Super + Space` เมนู Omarchy, `Super + W` ปิดหน้าต่าง, `Super + F` เต็มหน้าจอ |
| `Super + Shift + key` | แอป | `Super + Shift + B` เบราว์เซอร์, `Super + Shift + E` อีเมล, `Super + Shift + N` โปรแกรมแก้ไข |
| `Super + Ctrl + key` | แผงและเมนูระบบ | `Super + Ctrl + A` เสียง, `Super + Ctrl + N` เครือข่าย, `Super + Ctrl + C` เมนูการจับภาพ |
| `Super + Ctrl + Alt + key` | การดำเนินการด่วนและข้อความแจ้งเตือน | `Super + Ctrl + Alt + T` แสดงเวลา, `Super + Ctrl + Alt + B` แบตเตอรี่, `Super + Ctrl + Alt + C` ภาพหน้าจอ |

การเพิ่ม `Alt` ให้กับปุ่มลัดจะให้รูปแบบที่แตกต่างกันของสิ่งเดียวกันกับคุณ ไม่ใช่สิ่งที่ไม่เกี่ยวข้องกันเลย:

- `Super + Shift + B` เปิดเบราว์เซอร์; `Super + Shift + Alt + B` เปิดหน้าต่างส่วนตัว
- `Super + Shift + E` เปิดอีเมล; `Super + Shift + Alt + E` เริ่มอีเมลใหม่
- `Super + F` เข้าสู่โหมดเต็มหน้าจอ; `Super + Alt + F` เข้าสู่โหมดเต็มความกว้าง
- `Super + Ctrl + C` เปิดเมนูการจับภาพ; `Super + Ctrl + Alt + C` ข้ามเมนูและถ่ายภาพหน้าจอ

เมื่อเพิ่มปุ่มลัด:

1. เลือกระนาบจากสิ่งที่มันทำ จากนั้นเลือกปุ่ม
2. อย่าย้ายปุ่มลัดที่มีอยู่เพื่อ腾พื้นที่ให้ หาปุ่มที่ว่างบนระนาบที่ถูกต้อง
3. ใช้ `Alt` เฉพาะสำหรับรูปแบบที่แตกต่างของปุ่มลัดที่ไม่มีมันเท่านั้น

ปุ่มลัดบางปุ่มฝ่าฝืนกฎเหล่านี้เพราะสะดวก `Shift` พร้อมลูกศรหรือ `Tab` จะย้ายหรือย้อนกลับแทนที่จะเปิดแอป และ `Print` ปุ่มสื่อ `Alt + Tab` และ `Ctrl + Alt + Del` ทำงานในแบบที่พวกมันทำงานในที่อื่น ๆ ทุกแห่ง พวกมันเป็นข้อยกเว้น ไม่ใช่รูปแบบให้ลอกเลียนแบบ

หากค่าเริ่มต้นไม่เหมาะกับคุณ (เช่น คุณต้องการ `Super + Shift + S` สำหรับภาพหน้าจอเหมือนบน Windows) ให้ผูกมันใหม่ใน `~/.config/hypr/bindings.lua`

บนทัชแพด การปัดสามนิ้วและสี่นิ้วจะสลับพื้นที่ทำงาน ย้ายหน้าต่าง และเปิดเมนูและคอนโซล Quake ดู [แป้นพิมพ์ เมาส์ และแทร็กแพด](34-keyboard-mouse-trackpad.md) สำหรับท่าทางต่าง ๆ

การปรับขนาดใช้สองปุ่มทางขวาของ 0 ไม่ว่าคีย์บอร์ดของคุณจะพิมพ์อะไรไว้บนปุ่มเหล่านั้น: `-` และ `=` บนคีย์บอร์ด US, `+` และ `´` บนภาษาเดนมาร์กและสวีเดน, `+` และ `\` บนภาษานอร์เวย์, `ß` และ `´` บนภาษาเยอรมัน, `'` และ `¡` บนภาษาสเปน และ `-` และ `^` บนภาษาญี่ปุ่น (JIS) `Super + K` จะแสดงรายการตามที่คีย์บอร์ดของคุณพิมพ์ไว้ บน JIS, `Super + ^` คือ `Super + Equal` ในขณะที่ `Super + Shift + -` (ซึ่งพิมพ์ `=`) คือ `Super + Shift + Minus` การปรับขนาดจอภาพและตัวจัดการรหัสผ่านใช้ `/`; บนเลย์เอาต์ที่พิมพ์ `/` ได้เฉพาะเมื่อใช้ Shift เท่านั้น อย่างเช่นเลย์เอาต์ยุโรปส่วนใหญ่ พวกมันจะใช้ปุ่มทางซ้ายของ Shift ขวาแทน (`-` บนภาษาเดนมาร์กและเยอรมัน)

โดยปกติบน Linux คุณต้องใช้ `Ctrl + Shift + C/V` เพื่อคัดลอกและวางในเทอร์มินัล และใช้ `Ctrl + C/V` เพื่อทำแบบนั้นในที่อื่น ๆ ทุกแห่ง ปุ่มลัดคลิปบอร์ดแบบรวมศูนย์ของ Omarchy เหล่านี้ใช้ได้ทุกที่

## Tmux

ปุ่ม prefix คือ `Ctrl + Space` (`Ctrl + B` ก็ใช้ได้เช่นกัน) คุณสามารถเปลี่ยนการผูกปุ่มเหล่านี้ได้ใน `~/.config/tmux/tmux.conf`
