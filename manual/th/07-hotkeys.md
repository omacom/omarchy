# แป้นลัด

คุณสามารถดูการผูกแป้นคีย์บอร์ดหลักทั้งหมดได้ด้วย `Super + K` (การผูกแป้นของ Tmux ด้วย `Super + Alt + K` และการผูกแป้นของ Herdr ด้วย `Super + Ctrl + K`)

## การนำทาง

| แป้นลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Super + Space`           | เมนู Omarchy (แอปและทุกอย่างอื่น)    |
| `Super + Alt + Space` | ตารางแอป |
| `Super + Escape` | เมนูระบบ (ระงับการทำงาน, รีสตาร์ท ฯลฯ)  |
| `Super + Ctrl + L` | ล็อกคอมพิวเตอร์ |
| `Super + W` or `Super + Q` | ปิดหน้าต่าง             |
| `Ctrl + Alt + Del` | ปิดหน้าต่างทั้งหมด |
| `Super + T`               | สลับหน้าต่างระหว่างแบบเรียงกระเบื้อง/ลอย             |
| `Super + J` | สลับตำแหน่งหน้าต่าง (แนวนอน/แนวตั้ง) |
| `Super + O`               | สลับการเด้งหน้าต่างให้ติดหนึบและลอยตัว |
| `Super + L`               | วนสลับเลย์เอาต์ dwindle, scrolling และ floating |
| `Super + Alt + L`         | วนสลับเลย์เอาต์แบบย้อนกลับ |
| `Super + P`               | สลับสไตล์หน้าต่างจำลอง (แบบธรรมชาติ กับ แบบยืด) |
| `Super + F`                 | เข้าเต็มหน้าจอ              |
| `Super + Alt + F`                 | ขยายเต็มความกว้าง              |
| `Super + Ctrl + F`                 | เข้าเต็มหน้าจอภายในหน้าต่าง              |
| `Super + 1/2/3/4`         | ไปยังพื้นที่ทำงานที่ระบุบนจอภาพที่โฟกัสอยู่ |
| `Super + Tab` | ไปยังพื้นที่ทำงานถัดไปบนจอภาพที่โฟกัสอยู่ |
| `Super + Shift + Tab` | ไปยังพื้นที่ทำงานก่อนหน้าบนจอภาพที่โฟกัสอยู่ |
| `Super + Ctrl + Tab` | ไปยังพื้นที่ทำงานเดิมบนจอภาพที่โฟกัสอยู่ |
| `Super + Shift + 1/2/3/4` | ย้ายหน้าต่างไปยังพื้นที่ทำงานบนจอภาพที่โฟกัสอยู่ |
| `Super + Shift + Alt + 1/2/3/4` | ย้ายหน้าต่างไปยังพื้นที่ทำงานบนจอภาพที่โฟกัสอยู่โดยไม่ตามไปด้วย |
| `Super + S` | สลับ scratchpad แบบเต็ม |
| `Super + Alt + S` | ย้ายหน้าต่างไปยัง scratchpad แบบเต็ม |
| `Super + Grave` | สลับคอนโซล Quake |
| `Super + Shift + Grave` | ย้ายหน้าต่างไปยังคอนโซล Quake |

| `Super + Shift + Alt + Arrows` | ย้ายพื้นที่ทำงานไปยังจอภาพในทิศทางนั้น |
| `Super + Arrow`  | ย้ายโฟกัสไปยังหน้าต่างในทิศทางของลูกศร ข้ามไปยังจอภาพทางด้านนั้นเมื่อถึงขอบหน้าจอ |
| `Super + Shift + Arrow`  | สลับหน้าต่างกับอีกหน้าต่างในทิศทางของลูกศร รวมถึงหน้าต่างบนจอภาพทางด้านนั้น |

| `Super + Equal` | หดหน้าต่างจากทางซ้าย |

| `Super + Home` | คืนค่าความกว้างของหน้าต่างที่บันทึกไว้ |

| `Super + Right Mouse` | ปรับขนาดหน้าต่าง |
| `Super + Scroll Wheel` | เลื่อนผ่านพื้นที่ทำงานต่าง ๆ บนจอภาพที่โฟกัสอยู่ |
| `Super + G`               | สลับการจัดกลุ่มหน้าต่าง      |
| `Super + Alt + G`               | ย้ายหน้าต่างออกจากกลุ่ม      |
| `Super + Alt + Tab`               | วนสลับระหว่างหน้าต่างในกลุ่ม      |
| `Super + Alt + Shift + Tab`               | วนสลับย้อนกลับระหว่างหน้าต่างในกลุ่ม      |
| `Super + Alt + Scroll Wheel` | วนสลับระหว่างหน้าต่างในกลุ่ม |
| `Super + Alt + 1/2/3/4/5`               | ไปยังหน้าต่างที่ระบุในกลุ่ม      |
| `Super + Alt + Arrow`  | ย้ายหน้าต่างเข้ากลุ่มในทิศทางของลูกศร รวมถึงหน้าต่างบนจอภาพทางด้านนั้น |
| `Super + Ctrl + Left/Right`  | ย้ายระหว่างหน้าต่างภายในกลุ่มแบบเรียงกระเบื้อง |
| `Super + Ctrl + Z` | ซูมเข้าหน้าจอ (กดซ้ำเพื่อซูมมากขึ้น) |
| `Super + Ctrl + Alt + Z` | ซูมออกเต็มที่จากหน้าจอ |
| `Super + /` | เลื่อนไปข้างหน้าผ่านตัวเลือกการปรับสเกลจอภาพ |
| `Super + Alt + /` | เลื่อนย้อนกลับผ่านตัวเลือกการปรับสเกลจอภาพ |
| `Alt + Tab` | วนไปข้างหน้าผ่านหน้าต่างต่าง ๆ บนพื้นที่ทำงานที่ใช้งานอยู่ |
| `Alt + Shift + Tab` | วนย้อนกลับผ่านหน้าต่างต่าง ๆ บนพื้นที่ทำงานที่ใช้งานอยู่ |
| `Ctrl + Alt + Tab`| วนโฟกัสไปข้างหน้าผ่านจอภาพต่าง ๆ |
| `Ctrl + Alt + Shift + Tab`| วนโฟกัสย้อนกลับผ่านจอภาพต่าง ๆ |

## คลิปบอร์ดสากล

| แป้นลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Super + C`           | คัดลอก    |
| `Super + X`           | ตัด (ใช้ไม่ได้ในเทอร์มินัล)    |
| `Super + V`           | วาง    |
| `Super + Ctrl + V`           | ตัวจัดการคลิปบอร์ด    |

ปกติบน Linux คุณต้องใช้ `Ctrl + Shift + C/V` เพื่อคัดลอกและวางในเทอร์มินัล และใช้ `Ctrl + C/V` เพื่อทำเช่นนั้นในที่อื่น ๆ แป้นลัดคลิปบอร์ดแบบรวมของ Omarchy เหล่านี้ทำงานได้ทุกที่

## การจับภาพ

| แป้นลัด              | ฟังก์ชัน                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | ภาพหน้าจอ                      |
| `Super + Ctrl + Alt + C`            | ภาพหน้าจอ (ช็อตเดียวกัน สำหรับคีย์บอร์ดที่ไม่มีปุ่ม Print Screen) |
| `Super + Ctrl + C` | เมนูการจับภาพ |
| `Alt + Print Screen`            | บันทึกหน้าจอ                     |
| `Super + Print Screen` | เครื่องมือเลือกสี |
| `Super + Ctrl + Print Screen` | แยกข้อความไปยังคลิปบอร์ด |
| `Super + Alt + [` | ทำให้ภาพซ้อนเว็บแคมเล็กลงขณะบันทึก |
| `Super + Alt + ]` | ทำให้ภาพซ้อนเว็บแคมใหญ่ขึ้นขณะบันทึก |
| `Alt + Shift + L` | คัดลอก URL ปัจจุบันจากเว็บแอปหรือ Chromium |

สำหรับการบันทึกหน้าจอ แป้นลัดจะถามก่อนว่าคุณต้องการเสียงแบบใด จากนั้นจึงเริ่มบันทึก กดอีกครั้งเพื่อหยุด ดูรายละเอียดที่ [ภาพหน้าจอและการบันทึก](12-screenshots-recording.md)

ตัวเลือกการจับภาพทั้งหมดยังเข้าถึงได้ที่ _Trigger > Capture_ ในเมนู Omarchy (`Super + Space`)

## Tmux

ปุ่มนำหน้าคือ `Ctrl + Space` (`Ctrl + B` ก็ใช้งานได้เช่นกัน) คุณสามารถเปลี่ยนการผูกแป้นเหล่านี้ได้ใน `~/.config/tmux/tmux.conf`

### เพน

| แป้นลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + v` | แบ่งเพนไปด้านข้าง (แนวตั้ง) |
| `Prefix + h` | แบ่งเพนไว้ด้านล่าง (แนวนอน) |
| `Prefix + x` | ปิดเพน |
| `Prefix + z` | สลับการซูมเพน (เต็มหน้าจอ) |
| `Alt + Enter` | แบ่งเพนไว้ด้านล่าง (ไม่ต้องใช้ prefix) |
| `Alt + Shift + Enter` | แบ่งเพนไปด้านข้าง (ไม่ต้องใช้ prefix) |
| `Alt + Escape` | ปิดเพน (ไม่ต้องใช้ prefix) |
| `Ctrl + Alt + Arrows` | ย้ายระหว่างเพน |
| `Ctrl + Alt + Shift + Arrows` | ปรับขนาดเพน |

### หน้าต่าง

| แป้นลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |

### ฟังก์ชันเลย์เอาต์ของ Tmux

ฟังก์ชันเหล่านี้ต้องรันภายในเซสชัน Tmux

| คำสั่ง | ฟังก์ชัน |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | สร้างเลย์เอาต์สำหรับพัฒนาที่มีตัวแก้ไข AI และเทอร์มินัล |
| `tdlm <ai> [<second_ai>]` | สร้างเลย์เอาต์สำหรับพัฒนาตามไดเรกทอรีย่อยแต่ละอัน |
| `tsl <count> <command>` | สร้างเลย์เอาต์ swarm แบบหลายเพน |
