# ปุ่มลัด

คุณดูการผูกแป้นพิมพ์หลักทั้งหมดได้ด้วย `Super + K` (การผูก Tmux ด้วย `Super + Alt + K` และการผูก Herdr ด้วย `Super + Ctrl + K`)

## การนำทาง

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Super + Space`           | เมนู Omarchy (แอปและทุกอย่างอื่น ๆ)    |
| `Super + Alt + Space` | ตารางแอป |
| `Super + Escape` | เมนูระบบ (พักเครื่อง รีสตาร์ต ฯลฯ)  |
| `Super + Ctrl + L` | ล็อกคอมพิวเตอร์ |
| `Super + W` or `Super + Q` | ปิดหน้าต่าง             |
| `Ctrl + Alt + Del` | ปิดทุกหน้าต่าง |
| `Super + T`               | สลับหน้าต่างระหว่างเรียง/ลอย             |
| `Super + J` | สลับตำแหน่งหน้าต่าง (แนวนอน/แนวตั้ง) |
| `Super + O`               | สลับหน้าต่างให้เป็นแบบติดหนึบและลอย |
| `Super + L`               | วนผ่านเค้าโครง dwindle แบบเลื่อน และแบบลอย |
| `Super + Alt + L`         | วนผ่านเค้าโครงย้อนกลับ |
| `Super + P`               | สลับสไตล์หน้าต่างเทียม (ธรรมชาติเทียบกับยืด) |
| `Super + F`                 | ไปแบบเต็มหน้าจอ              |
| `Super + Alt + F`                 | ไปแบบเต็มความกว้าง              |
| `Super + Ctrl + F`                 | ไปแบบเต็มหน้าจอภายในหน้าต่าง              |
| `Super + 1/2/3/4`         | กระโดดไปยังพื้นที่งานเฉพาะ     |
| `Super + Tab` | กระโดดไปยังพื้นที่งานถัดไป |
| `Super + Shift + Tab` | กระโดดไปยังพื้นที่งานก่อนหน้า |
| `Super + Ctrl + Tab` | กระโดดไปยังพื้นที่งานเดิม |
| `Super + Shift + 1/2/3/4` | ย้ายหน้าต่างไปยังพื้นที่งาน |
| `Super + Shift + Alt + 1/2/3/4` | ย้ายหน้าต่างไปยังพื้นที่งานโดยไม่ตามไป |
| `Super + S` / `Super + Grave` | สลับกระดาษทด |
| `Super + Alt + S` / `Super + Shift + Grave` | ย้ายหน้าต่างไปยังกระดาษทด |
| `Super + Shift + Alt + Arrows` | ย้ายพื้นที่งานไปยังจอภาพตามทิศทาง |
| `Super + Arrow`  | ย้ายโฟกัสไปยังหน้าต่างในทิศทางของลูกศร              |
| `Super + Shift + Arrow`  | สลับหน้าต่างกับอีกหน้าต่างในทิศทางของลูกศร     |
| `Super + Minus` | ขยายหน้าต่างไปทางซ้าย |
| `Super + Equal` | ย่อหน้าต่างไปทางซ้าย |
| `Super + Shift + Minus` | ย่อหน้าต่างขึ้น |
| `Super + Shift + Equal` | ขยายหน้าต่างลง |
| `Super + Alt + Minus/Equal` | ปรับขนาดเดียวกันเป็นขั้นที่เล็กลง |
| `Super + Ctrl + Minus/Equal` | ปรับขนาดเดียวกันเป็นขั้นที่ใหญ่ขึ้น |
| `Super + Alt + Home` | บันทึกความกว้างหน้าต่าง |
| `Super + Home` | คืนค่าความกว้างหน้าต่างที่บันทึกไว้ |
| `Super + Left Mouse` | ลากหน้าต่างไปมา |
| `Super + Right Mouse` | ปรับขนาดหน้าต่าง |
| `Super + Scroll Wheel` | เลื่อนผ่านพื้นที่งาน |
| `Super + G`               | สลับการจัดกลุ่มหน้าต่าง      |
| `Super + Alt + G`               | ย้ายหน้าต่างออกจากการจัดกลุ่ม      |
| `Super + Alt + Tab`               | วนระหว่างหน้าต่างในกลุ่ม      |
| `Super + Alt + Shift + Tab`               | วนย้อนกลับระหว่างหน้าต่างในกลุ่ม      |
| `Super + Alt + 1/2/3/4/5`               | กระโดดไปยังหน้าต่างเฉพาะในกลุ่ม      |
| `Super + Alt + Arrow`  | ย้ายหน้าต่างเข้ากลุ่มในทิศทางของลูกศร  |
| `Super + Ctrl + Left/Right`  | ย้ายระหว่างหน้าต่างภายในกลุ่มการเรียง |
| `Super + Ctrl + Z` | ซูมเข้าในหน้าจอ (กดซ้ำเพื่อซูมมากขึ้น) |
| `Super + Ctrl + Alt + Z` | ซูมออกจากหน้าจออย่างเต็มที่ |
| `Super + /` | ก้าวไปข้างหน้าผ่านตัวเลือกมาตราส่วนจอภาพ |
| `Super + Alt + /` | ก้าวถอยหลังผ่านตัวเลือกมาตราส่วนจอภาพ |
| `Alt + Tab` | วนไปข้างหน้าผ่านหน้าต่างในพื้นที่งานที่ใช้งานอยู่ |
| `Alt + Shift + Tab` | วนถอยหลังผ่านหน้าต่างในพื้นที่งานที่ใช้งานอยู่ |
| `Ctrl + Alt + Tab`| วนโฟกัสไปข้างหน้าผ่านจอภาพ |
| `Ctrl + Alt + Shift + Tab`| วนโฟกัสถอยหลังผ่านจอภาพ |

## คลิปบอร์ดสากล

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Super + C`           | คัดลอก    |
| `Super + X`           | ตัด (ไม่ใช่ในเทอร์มินัล)    |
| `Super + V`           | วาง    |
| `Super + Ctrl + V`           | ตัวจัดการคลิปบอร์ด    |

โดยปกติบน Linux คุณต้องใช้ `Ctrl + Shift + C/V` เพื่อคัดลอกและวางในเทอร์มินัล และใช้ `Ctrl + C/V` เพื่อทำทุกที่อื่น ปุ่มลัดคลิปบอร์ดแบบรวมศูนย์ของ Omarchy เหล่านี้ใช้งานได้ทุกที่

## การจับภาพ

| ปุ่มลัด              | ฟังก์ชัน                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | เมนูจับภาพ (สำหรับคีย์บอร์ดที่ไม่มีปุ่ม PrintScr) |
| `Print Screen`            | ภาพหน้าจอ                      |
| `Alt + Print Screen`            | อัดหน้าจอ                     |
| `Super + Print Screen` | ตัวเลือกสี |
| `Super + Ctrl + Print Screen` | แยกข้อความไปยังคลิปบอร์ด |
| `Super + Alt + [` | ทำให้ชั้นซ้อนทับเว็บแคมเล็กลงขณะอัด |
| `Super + Alt + ]` | ทำให้ชั้นซ้อนทับเว็บแคมใหญ่ขึ้นขณะอัด |
| `Alt + Shift + L` | คัดลอก URL ปัจจุบันจากเว็บแอปหรือ Chromium |
| `Alt + Shift + D` | ดาวน์โหลดวิดีโอบนหน้าปัจจุบันไปยัง `~/Videos` |
| `Super + Ctrl + X` | เริ่ม/หยุดการพูดพิมพ์ (ต้องใช้ _ตั้งค่า > ค่าเริ่มต้น > การพูดพิมพ์_) |
| `Right Alt` / `F9` | การพูดพิมพ์แบบกดค้างไว้พูด (ต้องใช้ Voxtype หรือ Superwhisper) |

สำหรับการอัดหน้าจอ ปุ่มลัดนี้จะถามก่อนว่าคุณต้องการเสียงอะไร จากนั้นจึงเริ่มอัด กดอีกครั้งเพื่อหยุด ดู [ภาพหน้าจอและการอัด](12-screenshots-recording.md) สำหรับรายละเอียด

ตัวเลือกการจับภาพทั้งหมดยังเข้าถึงได้ภายใต้ _สั่งการ > จับภาพ_ ในเมนู Omarchy (`Super + Space`)

## Tmux

ปุ่มนำหน้าคือ `Ctrl + Space` (`Ctrl + B` ใช้ได้ด้วยเช่นกัน) คุณสามารถเปลี่ยนการผูกเหล่านี้ได้ใน `~/.config/tmux/tmux.conf`

### บานหน้าต่าง

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + v` | แยกบานหน้าต่างไปด้านข้าง (แนวตั้ง) |
| `Prefix + h` | แยกบานหน้าต่างลงข้างล่าง (แนวนอน) |
| `Prefix + x` | ปิดบานหน้าต่าง |
| `Prefix + z` | สลับการซูมบานหน้าต่าง (เต็มหน้าจอ) |
| `Alt + Enter` | แยกบานหน้าต่างลงข้างล่าง (ไม่มีปุ่มนำหน้า) |
| `Alt + Shift + Enter` | แยกบานหน้าต่างไปด้านข้าง (ไม่มีปุ่มนำหน้า) |
| `Alt + Escape` | ปิดบานหน้าต่าง (ไม่มีปุ่มนำหน้า) |
| `Ctrl + Alt + Arrows` | ย้ายระหว่างบานหน้าต่าง |
| `Ctrl + Alt + Shift + Arrows` | ปรับขนาดบานหน้าต่าง |

### หน้าต่าง

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + c` | หน้าต่างใหม่ |
| `Prefix + k` | ปิดหน้าต่าง |
| `Prefix + r` | เปลี่ยนชื่อหน้าต่าง |
| `Alt + 1-9` | ไปยังหน้าต่างเฉพาะ |
| `Alt + Arrow Left/Right` | ย้ายระหว่างหน้าต่าง |
| `Alt + Shift + Arrow Left/Right` | ย้ายหน้าต่างไปซ้าย/ขวา |

### เซสชัน

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + C` | เซสชันใหม่ |
| `Prefix + K` | ปิดเซสชัน |
| `Prefix + R` | เปลี่ยนชื่อเซสชัน |
| `Prefix + N` | เซสชันถัดไป |
| `Prefix + P` | เซสชันก่อนหน้า |
| `Alt + Arrow Up/Down` | ย้ายระหว่างเซสชัน |
| `Prefix + s` | แสดงรายการเซสชัน |
| `Prefix + d` | แยกออกจากเซสชัน |

### โหมดคัดลอก (สไตล์ vi)

| ปุ่มลัด                  | ฟังก์ชัน              |
| ----------------------- | --------------------- |
| `Prefix + [` | เข้าสู่โหมดคัดลอก |
| `v` | เริ่มการเลือก (ในโหมดคัดลอก) |
| `y` | คัดลอกสิ่งที่เลือก (ในโหมดคัดลอก) |

### ทั่วไป

### ฟังก์ชันเค้าโครง Tmux

| `tsl <count> <command>` | สร้างเค้าโครงกลุ่มหลายบานหน้าต่าง |
