# การแยกข้อความและการพูดพิมพ์ข้อความ

### การแยกข้อความ

กด `Super + Ctrl + PrtScr` เพื่อเลือกพื้นที่บนหน้าจอสำหรับการแยกข้อความ จากนั้นโมเดล OCR แบบโอเพนซอร์ส tesseract จะแปลงส่วนที่เลือกนั้นเป็นข้อความอย่างรวดเร็วและวางไว้บนคลิปบอร์ด จากนั้นคุณก็แค่กด `Super + V` เพื่อวาง

สิ่งนี้มีประโยชน์มากสำหรับการหยิบที่อยู่ออกจากส่วนท้ายของรูปภาพ หรือเบอร์โทรศัพท์ที่ฝังอยู่ในพาดหัวของเว็บไซต์

### การพูดพิมพ์ข้อความ

ในการติดตั้งใหม่ [Superwhisper](https://superwhisper.com/) เป็นแบ็กเอนด์การพูดพิมพ์ข้อความเริ่มต้น โดยใช้การประมวลผลบนคลาวด์โดยไม่ต้องดาวน์โหลดโมเดลแบบออฟไลน์ เลือก Superwhisper หรือ [Voxtype](https://voxtype.io/) ผ่าน _Setup > Defaults > Dictation_ ในเมนู Omarchy การเลือกแบ็กเอนด์จะติดตั้งให้หากจำเป็น และทำให้เป็นค่าเริ่มต้นสำหรับการพูดพิมพ์ข้อความ Voxtype จะโหลดโมเดลภาษาอังกฤษพื้นฐานที่ใช้พื้นที่ 150MB เปลี่ยนโมเดลด้วย `voxtype setup model` และตั้งค่าอื่น ๆ ผ่าน `~/.config/voxtype/config.toml` Superwhisper จะเปิดการตั้งค่าเพื่อให้เลือกการประมวลผลบนคลาวด์หรือในเครื่อง และ OPR จะคอยอัปเดตแอปพลิเคชันให้ทันสมัยอยู่เสมอ

คุณพูดพิมพ์ข้อความได้โดยกด `Right Alt` ค้างไว้ หรือสลับเปิด/ปิดด้วย `Alt + Space` และข้อความที่พูดจะปรากฏในช่องป้อนข้อมูลที่กำลังโฟกัสอยู่ ปุ่มลัดเหล่านี้ใช้แบ็กเอนด์ที่เลือกไว้ Right Alt ยังเริ่มการพูดพิมพ์ข้อความเมื่อใช้ในชุดปุ่มร่วมกับปุ่มปรับแต่งด้วย ให้ใช้ Left Alt สำหรับชุดปุ่มเหล่านั้น บนเลย์เอาต์แป้นพิมพ์ที่ Right Alt คือ AltGr ให้ใช้ `Alt + Space` เพื่อให้ AltGr ยังใช้พิมพ์ได้ตามเดิม การติดตั้งจากก่อนที่ Alt + Space จะกลายเป็นค่าเริ่มต้นจะยังใช้ `F9` สำหรับกดค้างเพื่อพูด และ `Super + Ctrl + X` สำหรับสลับเปิด/ปิด ซึ่งเพิ่มไว้ใน `~/.config/hypr/bindings.lua` ลบรายการเหล่านั้นออกที่นั่นเพื่อคืนปุ่มเหล่านั้นให้แอปพลิเคชัน

ปุ่มลัดเดียวกันใช้ได้กับทั้งสองแบ็กเอนด์ เลือกแบ็กเอนด์ของคุณผ่าน Setup > Defaults > Dictation ตัวติดตั้งแบ็กเอนด์จะกำหนดค่าและบันทึกตัวเลือกที่เลือกไว้ รัน `omarchy default dictation` เพื่อดูว่าอันไหนถูกเลือกอยู่ ตัวเลือกจะถูกบันทึกไว้ใน `~/.config/omarchy/defaults/dictation` การติดตั้งใหม่จะเลือก Superwhisper โดยอัตโนมัติ

Omarchy จะโหลดการเชื่อมต่อกับเดสก์ท็อปของแบ็กเอนด์ที่เลือกไว้โดยอัตโนมัติ ไม่จำเป็นต้องกำหนดค่า Superwhisper ใน `~/.config/hypr/`

การผูกปุ่มแบบกำหนดเองและสคริปต์สามารถใช้ `omarchy dictation start`, `omarchy dictation stop` และ `omarchy dictation toggle` ได้ แบ็กเอนด์ที่เลือกไว้จะจัดการการบันทึกและถอดเสียง การเลือก Superwhisper จะปิดปุ่มลัดแบบกดค้างดั้งเดิมของมัน และตั้งปุ่มสลับดั้งเดิมเป็น `Ctrl + Alt + Space` เพื่อแยกออกจากปุ่มบันทึกของ Omarchy Superwhisper ต้องการปุ่มลัดบันทึกดั้งเดิมอย่างน้อยหนึ่งปุ่ม และปุ่มลัดยกเลิกของมันยังคงใช้งานได้

แบ็กเอนด์เพิ่มเติมสามารถเชื่อมต่อเข้ามาได้โดยไม่ต้องเปลี่ยนแปลง Omarchy ให้เตรียมไฟล์ปฏิบัติการชื่อ `omarchy-dictation-<backend>` บน PATH ที่รับคำสั่ง `start`, `stop` และ `toggle` และส่งคืนผลทันที โดยมีสถานะไม่ใช่ศูนย์เมื่อล้มเหลว ตัวติดตั้งของมันจะกำหนดค่าผู้ให้บริการและเรียก `omarchy-dictation-use <backend>` หลังจากตั้งค่าสำเร็จ วิธีนี้จะหยุดแบ็กเอนด์ก่อนหน้าและบันทึกตัวเลือกแบบอะตอมมิก `stop` ต้องสำเร็จเมื่อผู้ให้บริการว่างหรือใช้งานไม่ได้ ชื่อแบ็กเอนด์ใช้ตัวอักษรพิมพ์เล็ก ตัวเลข และยัติภังค์ ให้เตรียม `omarchy-install-dictation-<backend>` สำหรับการตั้งค่า `omarchy default dictation <backend>` จะเปิดใช้งานมัน เพิ่มรายการเมนู Defaults ผ่านส่วนขยายเมนูของ Omarchy เพื่อเรียกตัวเลือกนั้น การเชื่อมต่อกับเดสก์ท็อปเพิ่มเติมสามารถอยู่ใน `${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua` ได้
