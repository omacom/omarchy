# การดึงข้อความและการเขียนตามคำบอก

### การดึงข้อความ

กด `Super + Ctrl + PrtScr` เพื่อเลือกพื้นที่บนหน้าจอสำหรับการดึงข้อความ จากนั้นโมเดล OCR โอเพนซอร์ส tesseract จะแปลงส่วนที่เลือกนั้นเป็นข้อความอย่างรวดเร็วและวางไว้บนคลิปบอร์ด จากนั้นคุณก็แค่กด `Super + V` เพื่อวาง

สิ่งนี้มีประโยชน์มากสำหรับการหยิบที่อยู่ออกจากส่วนท้ายของรูปภาพ หรือเบอร์โทรศัพท์ที่ฝังอยู่ในพาดหัวของเว็บไซต์

### การเขียนตามคำบอก

ในการติดตั้งใหม่ [Superwhisper](https://superwhisper.com/) คือแบ็กเอนด์การเขียนตามคำบอกเริ่มต้น โดยใช้การประมวลผลบนคลาวด์โดยไม่ต้องดาวน์โหลดโมเดลออฟไลน์ เลือก Superwhisper, [Voxtype](https://voxtype.io/) หรือ [Hex](https://anoma.ly/hex/) ผ่าน _Setup > Defaults > Dictation_ ในเมนู Omarchy การเลือกแบ็กเอนด์จะติดตั้งแบ็กเอนด์นั้นหากจำเป็น และทำให้เป็นค่าเริ่มต้นสำหรับการเขียนตามคำบอก Voxtype โหลดโมเดลภาษาอังกฤษพื้นฐานที่ใช้พื้นที่ 150MB; เปลี่ยนโมเดลด้วย `voxtype setup model` และการตั้งค่าอื่น ๆ ผ่าน `~/.config/voxtype/config.toml` Superwhisper เปิดการตั้งค่าของมันเพื่อให้เลือกการประมวลผลบนคลาวด์หรือในเครื่อง และ OPR คอยทำให้แอปพลิเคชันอัปเดตอยู่เสมอ Hex ดาวน์โหลดโมเดลเสียงพูดบนอุปกรณ์ของมันระหว่างการตั้งค่า และทำงานเป็นบริการผู้ใช้ `hex.service`; เปิดหน้าต่างของมันจากไอคอนถาดบนแถบ หรือด้วยการรัน `hex` เพื่อเปลี่ยนโมเดลและการตั้งค่าอื่น ๆ

คุณเขียนตามคำบอกได้ด้วยการกด `Right Alt` ค้างไว้ หรือด้วยการสลับด้วย `Alt + Space` และข้อความที่เขียนตามคำบอกจะปรากฏในพื้นที่ป้อนข้อมูลที่กำลังโฟกัสอยู่ ทางลัดเหล่านี้ใช้แบ็กเอนด์ที่เลือกไว้ Right Alt ยังเริ่มการเขียนตามคำบอกเมื่อใช้ในคอร์ดตัวปรับแต่งด้วย ให้ใช้ Left Alt สำหรับคอร์ดเหล่านั้น บนเลย์เอาต์แป้นพิมพ์ที่ Right Alt คือ AltGr ให้ใช้ `Alt + Space` เพื่อให้ AltGr ยังคงใช้พิมพ์ได้ต่อไป การติดตั้งจากก่อนที่ Alt + Space จะกลายเป็นค่าเริ่มต้นยังคงใช้ `F9` สำหรับกดเพื่อพูด และ `Super + Ctrl + X` สำหรับการสลับ ซึ่งเพิ่มไว้ใน `~/.config/hypr/bindings.lua`; ลบออกที่นั่นเพื่อคืนคีย์เหล่านั้นให้กับแอปพลิเคชัน

ทางลัดเดียวกันนี้ใช้ได้กับทุกแบ็กเอนด์ เลือกแบ็กเอนด์ของคุณผ่าน Setup > Defaults > Dictation โปรแกรมติดตั้งแบ็กเอนด์จะกำหนดค่าแบ็กเอนด์และบันทึกตัวเลือกนั้น รัน `omarchy default dictation` เพื่อดูว่าแบ็กเอนด์ใดถูกเลือกอยู่ ตัวเลือกจะถูกบันทึกใน `~/.config/omarchy/defaults/dictation` การติดตั้งใหม่จะเลือก Superwhisper โดยอัตโนมัติ

Omarchy โหลดการผสานรวมกับเดสก์ท็อปของแบ็กเอนด์ที่เลือกไว้โดยอัตโนมัติ ไม่จำเป็นต้องกำหนดค่า Superwhisper ใด ๆ ใน `~/.config/hypr/`

การผูกคีย์และสคริปต์แบบกำหนดเองสามารถใช้ `omarchy dictation start`, `omarchy dictation stop` และ `omarchy dictation toggle` ได้ แบ็กเอนด์ที่เลือกไว้จะจัดการการบันทึกและการถอดความ การเลือก Superwhisper จะปิดใช้งานทางลัดแบบกดค้างดั้งเดิมของมัน และตั้งค่าการสลับดั้งเดิมของมันเป็น `Ctrl + Alt + Space` เพื่อแยกออกจากคีย์บันทึกของ Omarchy Superwhisper ต้องการทางลัดการบันทึกดั้งเดิมอย่างน้อยหนึ่งทางลัด และทางลัดยกเลิกของมันยังคงใช้ได้

แบ็กเอนด์เพิ่มเติมสามารถผสานรวมได้โดยไม่ต้องเปลี่ยนแปลง Omarchy ให้จัดเตรียมไฟล์ปฏิบัติการชื่อ `omarchy-dictation-<backend>` บน PATH ที่รับ `start`, `stop` และ `toggle` และสิ้นสุดการทำงานอย่างรวดเร็ว โดยมีสถานะไม่ใช่ศูนย์เมื่อล้มเหลว โปรแกรมติดตั้งของมันจะกำหนดค่าผู้ให้บริการและเรียก `omarchy-dictation-use <backend>` หลังจากตั้งค่าสำเร็จ สิ่งนี้จะหยุดแบ็กเอนด์ก่อนหน้าและบันทึกตัวเลือกแบบอะตอมมิก; `stop` ต้องสำเร็จเมื่อผู้ให้บริการไม่ได้ทำงานอยู่หรือไม่พร้อมใช้งาน ชื่อแบ็กเอนด์ใช้ตัวอักษรพิมพ์เล็ก ตัวเลข และยัติภังค์ จัดเตรียม `omarchy-install-dictation-<backend>` สำหรับการตั้งค่า; `omarchy default dictation <backend>` จะเปิดใช้งานมัน เพิ่มรายการเมนู Defaults ผ่านส่วนขยายเมนู Omarchy เพื่อเรียกตัวเลือกนั้น การผสานรวมกับเดสก์ท็อปแบบเลือกได้สามารถอยู่ใน `${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua` ได้
