# การแยกข้อความและการสั่งงานด้วยเสียง

### การแยกข้อความ

กด `Super + Ctrl + PrtScr` เพื่อเลือกพื้นที่บนหน้าจอสำหรับการแยกข้อความ จากนั้นโมเดล OCR แบบโอเพนซอร์ส tesseract จะแปลงส่วนที่เลือกนั้นเป็นข้อความอย่างรวดเร็วและวางไว้บนคลิปบอร์ด จากนั้นคุณก็แค่กด `Super + V` เพื่อวาง

สิ่งนี้มีประโยชน์มากสำหรับการหยิบที่อยู่จากส่วนท้ายของรูปภาพ หรือเบอร์โทรศัพท์ที่ฝังอยู่ในพาดหัวของเว็บไซต์

### การสั่งงานด้วยเสียง

ในการติดตั้งใหม่ [Superwhisper](https://superwhisper.com/) คือแบ็กเอนด์การสั่งงานด้วยเสียงเริ่มต้น โดยใช้การประมวลผลบนคลาวด์โดยไม่ต้องดาวน์โหลดโมเดลสำหรับใช้งานแบบออฟไลน์ เลือก Superwhisper, [Voxtype](https://voxtype.io/) หรือ [Hex](https://anoma.ly/hex/) ผ่าน _Setup > Defaults > Dictation_ ในเมนู Omarchy การเลือกแบ็กเอนด์จะติดตั้งแบ็กเอนด์นั้นหากจำเป็น และกำหนดให้เป็นค่าเริ่มต้นสำหรับการสั่งงานด้วยเสียง Voxtype จะโหลดโมเดลภาษาอังกฤษพื้นฐานที่ใช้พื้นที่ 150MB เปลี่ยนโมเดลด้วย `voxtype setup model` และเปลี่ยนการตั้งค่าอื่น ๆ ผ่าน `~/.config/voxtype/config.toml` Superwhisper จะเปิดการตั้งค่าของตัวมันเองให้เลือกการประมวลผลบนคลาวด์หรือในเครื่อง และ OPR จะคอยอัปเดตแอปพลิเคชันให้ทันสมัย Hex จะดาวน์โหลดโมเดลเสียงพูดบนอุปกรณ์ระหว่างการติดตั้ง และทำงานเป็นบริการผู้ใช้ `hex.service` เปิดหน้าต่างของมันจากไอคอนในถาดของแถบ หรือด้วยการเรียกใช้ `hex` เพื่อเปลี่ยนโมเดลและการตั้งค่าอื่น ๆ

คุณสั่งงานด้วยเสียงโดยกด `Right Alt` ค้างไว้ หรือสลับด้วย `Alt + Space` และข้อความที่สั่งจะปรากฏในพื้นที่ป้อนข้อมูลที่กำลังโฟกัสอยู่ ทางลัดเหล่านี้ใช้แบ็กเอนด์ที่เลือกไว้ `Right Alt` ยังเริ่มการสั่งงานด้วยเสียงเมื่อใช้ในคอร์ดปุ่มปรับแต่งด้วย ให้ใช้ Left Alt สำหรับคอร์ดเหล่านั้น บนรูปแบบแป้นพิมพ์ที่ `Right Alt` คือ AltGr รวมถึงเมื่อรูปแบบดังกล่าวเป็นรูปแบบหนึ่งที่คุณสลับไปใช้ ให้กดค้างไว้เพียงปุ่มเดียวสักครู่เพื่อสั่งงานด้วยเสียง การกด AltGr พร้อมกับปุ่มอื่นยังคงพิมพ์ตัวอักษรของมัน การติดตั้งจากช่วงก่อนที่ `Alt + Space` จะกลายเป็นค่าเริ่มต้นจะยังคงใช้ `F9` สำหรับการกดค้างเพื่อพูด และ `Super + Ctrl + X` สำหรับการสลับ ซึ่งเพิ่มไว้ใน `~/.config/hypr/bindings.lua` โดยที่ `Super + Ctrl + X` นั้นจะเข้ามาแทนที่แผง agents ให้ลบรายการเหล่านั้นออกที่นั่นเพื่อคืนปุ่มเหล่านั้นให้แก่แอปพลิเคชันและแผง

ทางลัดเดียวกันนี้ใช้ได้กับทุกแบ็กเอนด์ เลือกแบ็กเอนด์ของคุณผ่าน Setup > Defaults > Dictation ตัวติดตั้งแบ็กเอนด์จะกำหนดค่าและบันทึกตัวเลือกที่เลือก เรียกใช้ `omarchy default dictation` เพื่อดูว่าแบ็กเอนด์ใดถูกเลือกไว้ ตัวเลือกที่เลือกจะถูกบันทึกใน `~/.config/omarchy/defaults/dictation` การติดตั้งใหม่จะเลือก Superwhisper โดยอัตโนมัติ

Omarchy จะโหลดการผสานรวมกับเดสก์ท็อปของแบ็กเอนด์ที่เลือกไว้โดยอัตโนมัติ ไม่จำเป็นต้องกำหนดค่า Superwhisper ใด ๆ ใน `~/.config/hypr/`

การผูกปุ่มแบบกำหนดเองและสคริปต์สามารถใช้ `omarchy dictation start`, `omarchy dictation stop` และ `omarchy dictation toggle` ได้ แบ็กเอนด์ที่เลือกไว้จะจัดการการบันทึกและการถอดเสียง การเลือก Superwhisper จะปิดใช้งานทางลัดแบบกดค้างในตัวของมัน และตั้งค่าการสลับในตัวของมันเป็น `Ctrl + Alt + Space` เพื่อแยกออกจากปุ่มบันทึกของ Omarchy Superwhisper ต้องการทางลัดการบันทึกในตัวอย่างน้อยหนึ่งรายการ และทางลัดการยกเลิกของมันจะยังคงใช้งานได้

แบ็กเอนด์เพิ่มเติมสามารถผสานรวมได้โดยไม่ต้องเปลี่ยนแปลง Omarchy ให้เตรียมไฟล์ปฏิบัติการชื่อ `omarchy-dictation-<backend>` ไว้บน PATH ที่รับคำสั่ง `start`, `stop` และ `toggle` และคืนค่ากลับมาอย่างรวดเร็ว โดยคืนสถานะที่ไม่ใช่ศูนย์เมื่อเกิดความล้มเหลว ตัวติดตั้งของมันจะกำหนดค่าผู้ให้บริการ และเรียกใช้ `omarchy-dictation-use <backend>` หลังจากการติดตั้งสำเร็จ การทำเช่นนี้จะหยุดแบ็กเอนด์ก่อนหน้าและบันทึกตัวเลือกที่เลือกแบบอะตอมมิก `stop` ต้องสำเร็จเมื่อผู้ให้บริการไม่ได้ทำงานอยู่หรือใช้งานไม่ได้ ชื่อแบ็กเอนด์ใช้ตัวอักษรพิมพ์เล็ก ตัวเลข และยัติภังค์ ให้เตรียม `omarchy-install-dictation-<backend>` สำหรับการติดตั้ง `omarchy default dictation <backend>` จะเรียกใช้ตัวติดตั้งนั้น เพิ่มรายการเมนู Defaults ผ่านส่วนขยายเมนูของ Omarchy เพื่อเรียกใช้ตัวเลือกนั้น การผสานรวมกับเดสก์ท็อปแบบไม่บังคับสามารถอยู่ใน `${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua` ได้
