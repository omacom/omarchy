# การแยกข้อความและการพูดพิมพ์

### การแยกข้อความ

กด `Super + Ctrl + PrtScr` เพื่อเลือกภูมิภาคบนหน้าจอสำหรับการแยกข้อความ โมเดล OCR โอเพนซอร์ส tesseract จะแปลงส่วนที่เลือกนั้นเป็นข้อความอย่างรวดเร็วและวางมันบนคลิปบอร์ด จากนั้นคุณแค่กด `Super + V` เพื่อวาง

สิ่งนี้ช่วยได้มากสำหรับการหยิบที่อยู่จากส่วนท้ายภาพ หรือหมายเลขโทรศัพท์ที่ฝังอยู่ในพาดหัวเว็บไซต์

### การพูดพิมพ์

ในการติดตั้งใหม่ [Superwhisper](https://superwhisper.com/) คือแบ็กเอนด์การพูดพิมพ์เริ่มต้น โดยใช้การประมวลผลบนคลาวด์โดยไม่มีการดาวน์โหลดโมเดลแบบออฟไลน์ เลือก Superwhisper หรือ [Voxtype](https://voxtype.io/) ผ่าน _ตั้งค่า > ค่าเริ่มต้น > การพูดพิมพ์_ ในเมนู Omarchy การเลือกแบ็กเอนด์จะติดตั้งมันหากจำเป็น และทำให้มันเป็นค่าเริ่มต้นสำหรับการพูดพิมพ์ Voxtype โหลดโมเดลภาษาอังกฤษพื้นฐานที่ใช้พื้นที่ 150MB เปลี่ยนโมเดลด้วย `voxtype setup model` และการตั้งค่าอื่น ๆ ผ่าน `~/.config/voxtype/config.toml` Superwhisper เปิดการตั้งค่าของมันเพื่อเลือกการประมวลผลแบบคลาวด์หรือแบบภายใน และ OPR ดูแลให้แอปพลิเคชันเป็นปัจจุบัน

คุณพูดพิมพ์โดยกด `Right Alt` หรือ `F9` ค้างไว้ หรือโดยสลับด้วย `Super + Ctrl + X` และข้อความที่พูดพิมพ์จะปรากฏในพื้นที่ป้อนข้อมูลที่โฟกัสอยู่ ปุ่มลัดเหล่านี้ใช้แบ็กเอนด์ที่เลือกไว้ Right Alt ยังเริ่มการพูดพิมพ์เมื่อใช้ในคอร์ดตัวปรับแต่งด้วย ใช้ Left Alt สำหรับคอร์ดเหล่านั้น บนเค้าโครงแป้นพิมพ์ที่ Right Alt คือ AltGr ให้ใช้ `F9` เพื่อให้ AltGr ยังคงพร้อมสำหรับการพิมพ์

ปุ่มลัดเดียวกันนี้ใช้กับแบ็กเอนด์ตัวใดตัวหนึ่งได้ เลือกแบ็กเอนด์ของคุณผ่าน ตั้งค่า > ค่าเริ่มต้น > การพูดพิมพ์ ตัวติดตั้งแบ็กเอนด์จะกำหนดค่าให้มันและบันทึกตัวเลือก รัน `omarchy default dictation` เพื่อดูว่าตัวใดถูกเลือกไว้ ตัวเลือกจัดเก็บอยู่ใน `~/.config/omarchy/defaults/dictation` การติดตั้งใหม่จะเลือก Superwhisper โดยอัตโนมัติ

Omarchy โหลดการผสานเดสก์ท็อปของแบ็กเอนด์ที่เลือกไว้ให้โดยอัตโนมัติ ไม่จำเป็นต้องกำหนดค่า Superwhisper ใน `~/.config/hypr/` เลย

การผูกและสคริปต์แบบกำหนดเองสามารถใช้ `omarchy dictation start` `omarchy dictation stop` และ `omarchy dictation toggle` แบ็กเอนด์ที่เลือกไว้จัดการการบันทึกและการถอดความ การเลือก Superwhisper จะปิดปุ่มกดค้างดั้งเดิมของมัน และตั้งตัวสลับดั้งเดิมของมันเป็น `Alt + Space` โดยแยกมันออกจากปุ่มบันทึคของ Omarchy Superwhisper ต้องการปุ่มลัดการบันทึกแบบดั้งเดิมอย่างน้อยหนึ่งปุ่ม และปุ่มลัดยกเลิกของมันยังคงพร้อมใช้งาน

แบ็กเอนด์เพิ่มเติมสามารถผสานได้โดยไม่ต้องเปลี่ยน Omarchy จัดหาไฟล์เรียกใช้ชื่อ `omarchy-dictation-<backend>` บน PATH ที่รับ `start` `stop` และ `toggle` และคืนค่าอย่างทันท่วงที โดยมีสถานะไม่เป็นศูนย์เมื่อล้มเหลว ตัวติดตั้งของมันกำหนดค่าผู้ให้บริการและเรียก `omarchy-dictation-use <backend>` หลังการตั้งค่าที่สำเร็จ สิ่งนี้หยุดแบ็กเอนด์ก่อนหน้าและบันทึกตัวเลือกอย่างอะตอมิก `stop` ต้องสำเร็จเมื่อผู้ให้บริการว่างหรือใช้งานไม่ได้ ชื่อแบ็กเอนด์ใช้ตัวอักษรเล็ก ตัวเลข และเครื่องหมายยติภังค์ จัดหา `omarchy-install-dictation-<backend>` สำหรับการตั้งค่า `omarchy default dictation <backend>` จะเรียกใช้มัน เพิ่มรายการเมนูค่าเริ่มต้นผ่านส่วนขยายเมนู Omarchy เพื่อเรียกตัวเลือกนั้น การผสานเดสก์ท็อปเสริมอยู่ใน `${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua` ได้
