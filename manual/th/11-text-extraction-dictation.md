# การดึงข้อความและการพิมพ์ด้วยเสียง

### การดึงข้อความ

กด `Super + Ctrl + PrtScr` เพื่อเลือกพื้นที่บนหน้าจอสำหรับดึงข้อความ จากนั้นโมเดล OCR แบบโอเพนซอร์ส tesseract จะแปลงส่วนที่เลือกนั้นเป็นข้อความอย่างรวดเร็วและวางไว้บนคลิปบอร์ด จากนั้นคุณก็แค่กด `Super + V` เพื่อวาง

สิ่งนี้มีประโยชน์มากสำหรับการดึงที่อยู่จากส่วนท้ายของรูปภาพ หรือเบอร์โทรศัพท์ที่ฝังอยู่ในพาดหัวเว็บไซต์

### การพิมพ์ด้วยเสียง

ในการติดตั้งใหม่ [Superwhisper](https://superwhisper.com/) คือแบ็กเอนด์การพิมพ์ด้วยเสียงเริ่มต้น โดยใช้การประมวลผลบนคลาวด์โดยไม่ต้องดาวน์โหลดโมเดลแบบออฟไลน์ เลือก Superwhisper, [Voxtype](https://voxtype.io/) หรือ [Hex](https://anoma.ly/hex/) ผ่าน _การตั้งค่า > ค่าเริ่มต้น > การพิมพ์ด้วยเสียง_ ในเมนู Omarchy การเลือกแบ็กเอนด์จะติดตั้งให้หากจำเป็น และทำให้เป็นค่าเริ่มต้นสำหรับการพิมพ์ด้วยเสียง Voxtype จะโหลดโมเดลภาษาอังกฤษพื้นฐานที่ใช้พื้นที่ 150MB; เปลี่ยนโมเดลด้วย `voxtype setup model` และการตั้งค่าอื่น ๆ ผ่าน `~/.config/voxtype/config.toml` Superwhisper จะเปิดการตั้งค่าของมันเพื่อให้เลือกการประมวลผลบนคลาวด์หรือบนเครื่อง และ OPR จะคอยอัปเดตแอปพลิเคชันให้ Hex จะดาวน์โหลดโมเดลเสียงพูดบนอุปกรณ์ระหว่างการตั้งค่า และทำงานเป็นบริการผู้ใช้ `hex.service`; เปิดหน้าต่างของมันจากไอคอนในถาดของแถบ หรือด้วยการรัน `hex` เพื่อเปลี่ยนโมเดลและการตั้งค่าอื่น ๆ

คุณพูดให้พิมพ์ได้โดยกด `Right Alt` ค้างไว้ หรือสลับเปิด/ปิดด้วย `Alt + Space` แล้วข้อความที่พูดจะปรากฏในพื้นที่ป้อนข้อมูลที่กำลังโฟกัสอยู่ ปุ่มลัดเหล่านี้ใช้แบ็กเอนด์ที่เลือกไว้ Right Alt ยังเริ่มการพิมพ์ด้วยเสียงเมื่อใช้ในชุดปุ่ม modifier ด้วย; ให้ใช้ Left Alt สำหรับชุดปุ่มเหล่านั้น บนรูปแบบแป้นพิมพ์ที่ Right Alt คือ AltGr ให้ใช้ `Alt + Space` เพื่อให้ AltGr ยังใช้พิมพ์ได้ การติดตั้งจากก่อนที่ Alt + Space จะกลายเป็นค่าเริ่มต้นยังคงเก็บ `F9` ไว้สำหรับกดค้างเพื่อพูด และ `Super + Ctrl + X` สำหรับสลับเปิด/ปิด โดยเพิ่มไว้ใน `~/.config/hypr/bindings.lua` ซึ่ง `Super + Ctrl + X` นั้นจะเข้ามาแทนที่ agents panel; ลบออกที่นั่นเพื่อคืนปุ่มเหล่านั้นให้กับแอปพลิเคชันและ panel

ปุ่มลัดเดียวกันนี้ใช้ได้กับทุกแบ็กเอนด์ เลือกแบ็กเอนด์ของคุณผ่าน การตั้งค่า > ค่าเริ่มต้น > การพิมพ์ด้วยเสียง ตัวติดตั้งแบ็กเอนด์จะกำหนดค่าให้และบันทึกตัวเลือกที่เลือกไว้ รัน `omarchy default dictation` เพื่อดูว่าอันไหนถูกเลือกอยู่ ตัวเลือกจะถูกบันทึกไว้ใน `~/.config/omarchy/defaults/dictation` การติดตั้งใหม่จะเลือก Superwhisper โดยอัตโนมัติ

Omarchy จะโหลดการเชื่อมต่อกับเดสก์ท็อปของแบ็กเอนด์ที่เลือกไว้โดยอัตโนมัติ ไม่จำเป็นต้องกำหนดค่า Superwhisper ใน `~/.config/hypr/`

การผูกปุ่มแบบกำหนดเองและสคริปต์สามารถใช้ `omarchy dictation start`, `omarchy dictation stop` และ `omarchy dictation toggle` ได้ แบ็กเอนด์ที่เลือกไว้จะจัดการการบันทึกและการถอดเสียง การเลือก Superwhisper จะปิดปุ่มลัดแบบกดค้างดั้งเดิมของมัน และตั้งค่าปุ่มสลับเปิด/ปิดดั้งเดิมเป็น `Ctrl + Alt + Space` เพื่อแยกออกจากปุ่มบันทึกของ Omarchy Superwhisper ต้องการปุ่มลัดบันทึกดั้งเดิมอย่างน้อยหนึ่งปุ่ม และปุ่มลัดสำหรับยกเลิกของมันยังคงใช้งานได้

แบ็กเอนด์เพิ่มเติมสามารถเชื่อมต่อเข้ามาได้โดยไม่ต้องแก้ไข Omarchy ให้เตรียมไฟล์ปฏิบัติการชื่อ `omarchy-dictation-<backend>` ไว้บน PATH ที่รับ `start`, `stop` และ `toggle` และคืนค่ากลับทันที โดยมีสถานะที่ไม่ใช่ศูนย์เมื่อล้มเหลว ตัวติดตั้งของมันจะกำหนดค่าผู้ให้บริการและเรียก `omarchy-dictation-use <backend>` หลังจากตั้งค่าสำเร็จ การทำเช่นนี้จะหยุดแบ็กเอนด์ก่อนหน้าและบันทึกตัวเลือกแบบอะตอมมิก; `stop` ต้องสำเร็จเมื่อผู้ให้บริการไม่ได้ทำงานอยู่หรือใช้งานไม่ได้ ชื่อแบ็กเอนด์ใช้ตัวอักษรพิมพ์เล็ก ตัวเลข และเครื่องหมายยัติภังค์ ให้เตรียม `omarchy-install-dictation-<backend>` สำหรับการตั้งค่า; `omarchy default dictation <backend>` จะเปิดใช้งานมัน เพิ่มรายการเมนู ค่าเริ่มต้น ผ่านส่วนขยายเมนู Omarchy เพื่อเรียกตัวเลือกนั้น การเชื่อมต่อกับเดสก์ท็อปที่เป็นตัวเลือกเพิ่มเติมสามารถอยู่ใน `${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua` ได้
