# Neovim

[Neovim](https://neovim.io/) เป็นการนำ [ตัวแก้ไข vi](<https://en.wikipedia.org/wiki/Vi_(text_editor)>) มาทำขึ้นใหม่ในรูปแบบสมัยใหม่ ซึ่งสร้างโดย Bill Joy ย้อนกลับไปตั้งแต่ปี 1976 มันเป็นตัวแก้ไขแบบ modal ที่โหมด insert และโหมด command แยกออกจากกัน และมันก็เป็นเหมือนพลังพิเศษอยู่เหมือนกันเมื่อคุณเรียนรู้ชุดคำสั่งคีย์ที่ลึกอย่างไม่น่าเชื่อได้แม้เพียงบางส่วน แต่มันก็มีเส้นทางการเรียนรู้ที่สูงชันอยู่ไม่น้อยเช่นกัน!

หากคุณเป็นมือใหม่โดยสิ้นเชิงกับการแก้ไขแบบสไตล์ vim ผมแนะนำให้คุณลองดู [ซีรีส์ Vim As Your Editor ของ ThePrimeagen](https://www.youtube.com/watch?v=X6AR2RMB5tE&list=PLm323Lc7iSW_wuxqmKx_xxNtJC_hJbQ7R) บน YouTube นั่นจะสอนพื้นฐานให้คุณ เพียงแต่ต้องรู้ไว้ว่า ต่างจากตัวแก้ไขกระแสหลักที่คล้ายกันมากกว่า คุณจะต้องใช้เวลานานกว่ากว่าจะได้ความชำนาญพื้นฐานกับ vim แต่เมื่อคุณทำได้ ผลตอบแทนก็ยิ่งใหญ่กว่าเช่นกัน

ตอนนี้ Neovim สามารถกำหนดค่าได้แทบไม่สิ้นสุด หากคุณอยากจัดเต็มจริง ๆ คุณสามารถสร้างการกำหนดค่า Neovim ของตัวเองขึ้นมาตั้งแต่ต้นได้ มีคอร์สที่ยอดเยี่ยมจาก [Typecraft ในเรื่องการตั้งค่า Neovim ตั้งแต่ต้น](https://www.youtube.com/watch?v=zHTeCSVAFNY) และ [ThePrimeagen ก็มีเช่นกัน](https://www.youtube.com/watch?v=w7i4amO_zaE)

แต่ Omarchy มาพร้อมกับการตั้งค่า Neovim ที่สมบูรณ์แบบ — แพ็กเกจ `omarchy-nvim` — ที่ได้รับการปรับแต่งอย่างรักใคร่เพื่อแสดงสิ่งที่ดีที่สุดเท่าที่เป็นไปได้ตั้งแต่แกะกล่อง โดยที่คุณไม่ต้องเขียนการกำหนดค่าแม้แต่บรรทัดเดียว! มันสร้างอยู่บน [LazyVim](https://www.lazyvim.org/) ซึ่งเป็นดิสทริบิวชันของปลั๊กอินและการกำหนดค่าต่าง ๆ ของ Neovim มันยอดเยี่ยมมาก

## พื้นฐาน LazyVim

อย่างที่กล่าวไป ผมจะไม่สอน vim ให้คุณในบทนำสั้น ๆ นี้ แต่ผมสามารถแสดงพื้นฐานบางอย่างของ LazyVim และวิธีใช้งานไปรอบ ๆ ให้คุณเห็นได้

ประการแรก Neovim มีแนวคิดเรื่อง leader key นั่นเป็นเหมือนประตูสู่คำสั่งทั้งหมด LazyVim ตั้งค่านั้นไว้เป็น `Space` ดังนั้นเพียงกดปุ่มนั้น รอสักวินาที และคุณจะเห็นตัวเลือกจำนวนมากที่อธิบายไว้ในบรรทัดแบบนี้:

นี่คือคำสั่งพื้นฐานบางอย่างที่ผมใช้ตลอดเวลา:

- `Space Space` - ค้นหาไฟล์ใดก็ได้ในไดเรกทอรีปัจจุบันแบบ fuzzy-find
- `Space S G` - ค้นหาไฟล์ทั้งหมดโดยใช้ grep พร้อมตัวอย่างแสดง
- `Space E` - สลับเปิด/ปิดแผนผังไฟล์
- `Ctrl + W W` - กระโดดจากแผนผังไฟล์ไปยังตัวแก้ไขและกลับมา
- `Shift + H` - เลื่อนไปทางซ้ายระหว่างแท็บที่เปิดอยู่ (vim เรียกพวกมันว่า buffers)
- `Shift + L` - เลื่อนไปทางขวาระหว่างแท็บที่เปิดอยู่
- `Space B D` - ปิดแท็บหนึ่ง
- `Space B O` - ปิดแท็บอื่น ๆ ทั้งหมดยกเว้นแท็บปัจจุบัน
- `Space G G` - เปิด LazyGit ในบานหน้าต่างแบบลอยจากไดเรกทอรีปัจจุบัน
- `Space U W` - สลับการตัดคำแบบ soft wrap

ขณะที่คุณอยู่ในแผนผังไฟล์ (`Space E` เพื่อแสดงออกมา `Ctrl + W W` เพื่อกระโดดไปที่นั่น) คุณสามารถเพิ่มไฟล์ใหม่ด้วย `a` หรือไดเรกทอรีใหม่ด้วย `A` กด `?` ขณะอยู่ในแผนผังเพื่อดูคำสั่งทั้งหมด

หากคุณต้องการเรียนรู้ภาษา vim พื้นฐาน ผมได้เขียนเกี่ยวกับ [ไวยากรณ์สามส่วน](https://world.hey.com/dhh/wonderful-vi-a1d034d3) และวิธีทำท่าคอมโบสุดเจ๋งเหล่านั้น!

คุณสามารถดูคำสั่งที่เป็นไปได้ทั้งหมดได้ที่ [หน้า Keymaps ของ LazyVim](https://www.lazyvim.org/keymaps)

## การเริ่มต้น Neovim

`Super + Shift + N` จะเปิดตัวแก้ไขเริ่มต้นของคุณ ซึ่งคือ Plain ในการติดตั้งใหม่ ให้เลือก Neovim ภายใต้ _Setup > Defaults > Editor_ เพื่อให้มันเปิด Neovim แทน แต่มันมักจะง่ายกว่าที่จะควบคุมจากเทอร์มินัล โดยนำทางไปยังไดเรกทอรีที่คุณต้องการทำงานและพิมพ์ `n` ตัว `n` คือชื่อย่อของ `nvim` ซึ่งจะใช้ไดเรกทอรีปัจจุบันเปิดขึ้นมาโดยค่าเริ่มต้น คุณสามารถเปิดไฟล์เดียวได้ด้วย `n myfile.txt`

## การใช้ Neovim สำหรับการแก้ไขด้วย sudo

หากคุณต้องการแก้ไขไฟล์ที่คุณสามารถเปลี่ยนแปลงได้ในฐานะซูเปอร์ยูสเซอร์เท่านั้น ให้รัน `sudoedit /etc/sudoers.d/00-sudo-only-file` มันจะเปิดตัวแก้ไขเริ่มต้นของคุณ ดังนั้นให้ตั้ง Neovim ภายใต้ _Setup > Defaults > Editor_ หากคุณต้องการให้มันอยู่ที่นั่นพร้อมกับปลั๊กอินทั้งหมดของคุณ
