# การนำทาง

ทุกอย่างใน Omarchy เกิดขึ้นผ่านคีย์บอร์ด — _ทุกอย่าง!_ ตอนที่ระบบเพิ่งเริ่มทำงาน คุณใช้เมาส์อย่างเดียวทำอะไรไม่ได้เลยจริง ๆ แต่คุณกด `Super + Space` เพื่อเปิด Omarchy Menu ได้ และจากตรงนั้นคุณก็ทำได้แทบทุกอย่าง

แต่ Omarchy menu ไม่ได้ถูกออกแบบมาให้เป็นวิธีหลักในการใช้งานระบบตลอดเวลาด้วยซ้ำ เราเร็วกว่านั้นได้! แอปพลิเคชันที่สำคัญที่สุดทั้งหมดถูกผูกไว้กับปุ่มลัดโดยตรง คุณเปิดเทอร์มินัลด้วย `Super + Return` และเปิดเบราว์เซอร์ด้วย `Super + Shift + Return` ลองกดทีละอันต่อกันดู แล้วคุณจะเห็นความมหัศจรรย์ของการจัดเรียงหน้าต่างแบบ tiling ของ Hyprland ทำงาน:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

จากนั้นคุณกด `Super + J` เพื่อวางพวกมันซ้อนกันแทนที่จะวางข้างกันได้:

 ![navigation-stacked](images/navigation-stacked.webp)

กด `Super + J` อีกครั้งเพื่อนำพวกมันกลับไปยังตำแหน่งข้างกัน จากนั้นลองกด `Super + Shift + Arrow Right` ขณะอยู่ในเบราว์เซอร์เพื่อสลับหน้าต่าง

ตอนนี้ลองกด `Super + Shift + T` เพื่อเปิด Activity monitor นั่นจะปรากฏเป็นหน้าต่างลอย คุณสามารถทำให้มันจัดเรียงแบบ tiling ได้ด้วย `Super + T` (และกดอีกครั้งเพื่อทำให้มันลอยอีกครั้ง) ตอนนี้กด `Super + Shift + F` เพื่อเปิดตัวจัดการไฟล์ คุณจะได้การจัดวางแบบสี่ช่องที่เรียบร้อย:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

คุณนำทางไปยังหน้าต่างที่ต้องการให้เป็นหน้าต่างที่ใช้งานอยู่ด้วย `Super + Arrow` นั่นจะสลับโฟกัสและย้ายเคอร์เซอร์ไปตรงกลางของแอปพลิเคชันใหม่ ที่ขอบของหน้าจอ มันจะไปต่อยังจอภาพในด้านนั้น

ถ้าคุณกด `Super + Shift + 2` คุณจะย้ายแอปพลิเคชันที่โฟกัสอยู่ในปัจจุบันไปยังพื้นที่ทำงานที่สอง `Super + Shift + 1` จะย้ายมันกลับมา (และ `Super + Shift + Alt + 2` จะย้ายแอปพลิเคชันที่โฟกัสอยู่ในปัจจุบันไปยังพื้นที่ทำงานที่สองโดยไม่สลับไปยังพื้นที่ทำงานนั้น)

เมื่อมีจอภาพมากกว่าหนึ่งจอ แต่ละจอจะมีพื้นที่ทำงาน 1 ถึง 10 ของตัวเอง `Super + 2` ไปยังพื้นที่ทำงานที่สองของจอที่คุณอยู่ และแถบด้านบนของแต่ละจอจะแสดงพื้นที่ทำงานของตัวเองและพื้นที่ทำงานที่กำลังแสดงอยู่ `Super + Tab` จะวนผ่านพื้นที่ทำงานบนจอที่คุณอยู่ `Super + Shift + Ctrl + Arrows` ย้ายหน้าต่างที่คุณอยู่ไปยังจอภาพในทิศทางนั้น ไปยังพื้นที่ทำงานที่จอนั้นกำลังแสดงอยู่ และ `Super + Shift + Alt + Arrows` ย้ายพื้นที่ทำงานที่คุณอยู่ไปยังจอภาพในทิศทางนั้น โดยจะใช้หมายเลขเดิมถ้าว่างอยู่ จอภาพจะเก็บพื้นที่ทำงานของมันไว้เมื่อคุณถอดปลั๊กออก: พื้นที่ทำงานเหล่านั้นจะไปรวมกับของอีกหน้าจอหนึ่ง โดยเรียงหมายเลขต่อจากที่มีอยู่แล้ว และกลับไปใช้หมายเลขเดิมเมื่อจอภาพกลับมา

ถ้าคุณกด `Super` ค้างไว้แล้วใช้เมาส์คลิกที่หน้าต่าง คุณจะจัดเรียงตำแหน่งของมันใหม่ได้ ถ้าคุณกด `Super` ค้างไว้แล้วใช้ปุ่มขวาของเมาส์ คุณสามารถปรับขนาดหน้าต่างได้อย่างอิสระ

คุณปิดหน้าต่างด้วย `Super + W` หรือ `Super + Q` (และปิดหน้าต่างทั้งหมดด้วย `Ctrl + Alt + Delete`)

คุณยังสามารถแสดงแบบเต็มจอด้วย `Super + F` หรือแม้แต่แบบเต็มความกว้างอย่างเดียว (โดยยังเก็บแถบด้านบนไว้) ด้วย `Super + Alt + F` หรือเต็มจอภายในหน้าต่างด้วย `Super + Ctrl + F` (เหมาะสำหรับ YouTube!)

### เลย์เอาต์ dwindle เทียบกับ scrolling

เลย์เอาต์เริ่มต้นของ Omarchy เรียกว่า dwindle มันทำให้หน้าต่างทั้งหมดที่คุณเปิดบนพื้นที่ทำงานเดียวมองเห็นได้ตลอดเวลา แม้ว่าจะต้องย่อขนาดพวกมันลงก็ตาม

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

แต่คุณยังสามารถเลือกเปลี่ยนพื้นที่ทำงานให้เป็นเลย์เอาต์แบบ scrolling ได้ ซึ่งหน้าต่างจะเรียงกันข้าง ๆ กัน เลยขอบที่มองเห็นได้ของจอแสดงผลออกไป คุณเปลี่ยนพื้นที่ทำงานเดียวให้เป็นเลย์เอาต์นี้ได้ด้วย `Super + L`

การกด `Super + L` อีกครั้งจะเปลี่ยนพื้นที่ทำงานให้เป็นแบบลอย ซึ่งหน้าต่างจะซ้อนทับกันอย่างอิสระและคุณวางตำแหน่งพวกมันเอง และการกดครั้งที่สามจะนำมันกลับไปเป็น dwindle `Super + Alt + L` จะวนไปในทิศทางตรงกันข้าม หน้าต่างที่ลอยอยู่แล้ว — หน้าต่างที่คุณดึงออกมาด้วย `Super + T` หรือแอปที่เปิดแบบลอยเสมอ — จะยังคงลอยอยู่เมื่อพื้นที่ทำงานกลับไปเป็นแบบ tiling แถบด้านบนจะทำเครื่องหมายพื้นที่ทำงานที่คุณอยู่ด้วยเลย์เอาต์ของมัน: สี่เหลี่ยมสำหรับ dwindle วงกลมสำหรับ scrolling และสามเหลี่ยมสำหรับแบบลอย การคลิกเครื่องหมายนั้นก็จะวนเปลี่ยนเลย์เอาต์เช่นกัน

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

การเลือกนี้เป็นแบบต่อพื้นที่ทำงาน และจะคงอยู่ ดังนั้นคุณสามารถให้พื้นที่ทำงาน 1 เป็น dwindle สำหรับการท่องเว็บ และพื้นที่ทำงาน 2 เป็น scrolling สำหรับโค้ดได้ และพวกมันจะกลับมาเป็นแบบนั้นหลังจากรีสตาร์ท

หากคุณต้องการใช้เลย์เอาต์แบบ scrolling เป็นค่าเริ่มต้น คุณสามารถตั้งค่าได้ใน `~/.config/hypr/looknfeel.lua`:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### พื้นที่ทำงานแบบลอย

พื้นที่ทำงานแบบลอยทำงานเหมือนเดสก์ท็อปแบบดั้งเดิม: หน้าต่างซ้อนทับกัน และคุณย้ายและปรับขนาดพวกมันเอง แต่ละหน้าต่างจะมีแถบชื่อเรื่องในสีของธีมของคุณ พร้อมปุ่มสำหรับย่อ ขยาย และปิด `Super + M` ก็ย่อหน้าต่างที่โฟกัสอยู่ด้วยเช่นกัน หน้าต่างที่ย่อแล้วจะรออยู่ใน dock; คลิกแอปของมันเพื่อนำมันกลับมา คลิกหน้าต่างเพื่อนำมันมาข้างหน้า ปรับขนาดมันจากขอบหรือมุมใดก็ได้ ดับเบิลคลิกแถบชื่อเรื่องเพื่อขยายหน้าต่างในขณะที่ยังมองเห็นแถบด้านบนอยู่ และอีกครั้งเพื่อกลับไปขนาดเดิมของมัน Chrome และเบราว์เซอร์อื่น ๆ ที่ใช้ Chromium เป็นพื้นฐาน Disks และ Document Viewer จะข้ามแถบชื่อเรื่องและใช้ส่วนหัวของตัวเองแทน; `Super + Alt + F` จะขยายหน้าต่างเหล่านั้น และ `Super + M` จะย่อหน้าต่างเหล่านั้น

พื้นที่ทำงานแบบลอยยังแสดง dock พร้อมแอปที่ปักหมุดไว้ ทุกอย่างที่กำลังทำงานอยู่ และตารางของทุกแอปที่อยู่หลังปุ่มแอป ซึ่ง `Super + Alt + Space` และ _Apps_ ใน Omarchy menu ก็เปิดเช่นกัน คลิกขวาที่แอปบนตาราง หรือกด `Delete` เพื่อถอนการติดตั้งมัน คลิกแอปเพื่อเปิดมัน หรือเพื่อนำหน้าต่างของมันมาข้างหน้า; คลิกอีกครั้งเพื่อวนผ่านหน้าต่างของมัน คลิกกลางเพื่อเปิดหน้าต่างใหม่ ลากไอคอนไปตาม dock เพื่อย้ายมัน; การลากแอปที่กำลังทำงานอยู่เข้าไปท่ามกลางแอปอื่น ๆ จะเก็บมันไว้ที่นั่น คลิกขวาเพื่อเก็บแอปไว้ใน dock เอามันออก หรือออกจากแอปนั้น dock จะหลีกทางให้หน้าต่างแบบเต็มจอ คลิกขวาที่ปุ่มแอปเพื่อย้าย dock ไปยังขอบอื่น หรือให้มันซ่อนจนกว่าตัวชี้จะไปถึงขอบของมัน ตำแหน่งยังอยู่ภายใต้ _Appearance > Dock > Dock Position_ และ `omarchy dock position left` และ `omarchy dock autohide on` ตั้งค่าทั้งสองอย่างจากเทอร์มินัล แอปที่คุณเก็บไว้ใน dock จะจางลงในขณะที่พวกมันไม่ได้ทำงานอยู่

พื้นที่ทำงานใหม่ และพื้นที่ทำงานใด ๆ ที่คุณยังไม่ได้กำหนดเลย์เอาต์ของตัวเองด้วย `Super + L` จะใช้เลย์เอาต์เริ่มต้น การเปลี่ยนค่าเริ่มต้นจะรีเซ็ตทุกพื้นที่ทำงานที่ไม่มีหน้าต่างให้เป็นเลย์เอาต์นั้น ในขณะที่พื้นที่ทำงานที่มีหน้าต่างอยู่บนนั้นจะเก็บเลย์เอาต์ที่มันมีอยู่ไว้ หน้าต่างที่ย่อไปยัง dock ยังคงนับเป็นหน้าต่างบนพื้นที่ทำงานที่มันจากมา เลือกมันได้ภายใต้ _Appearance > Workspace Layout_: Tiling, Scrolling หรือ Floating `omarchy-hyprland-workspace-layout-default scrolling` ตั้งค่ามันจากเทอร์มินัล

### การจัดกลุ่มหน้าต่าง

หน้าต่างสามารถจัดกลุ่มได้โดยใช้ `Super + G` เมื่อคุณอยู่ในกลุ่มแล้ว ทุกหน้าต่างที่คุณเปิดในขณะที่กลุ่มนั้นใช้งานอยู่จะอยู่ในกลุ่ม คุณสามารถย้ายระหว่างหน้าต่างที่จัดกลุ่มเหล่านี้ได้โดยใช้ `Super + Ctrl + Arrow Left/Right` หรือ `Super + Alt + 1/2/3/4` เพื่อไปยังหน้าต่างที่จัดกลุ่มตามลำดับโดยตรง

คุณสามารถย้ายหน้าต่างออกจากกลุ่มได้ด้วย `Super + Alt + G` หรือแยกกลุ่มทั้งหมดโดยกด `Super + G` อีกครั้ง สุดท้าย คุณสามารถย้ายหน้าต่างที่อยู่นอกกลุ่มเข้ามาในกลุ่มได้ด้วย `Super + Alt + Arrows`

### การดึงหน้าต่างออกมา

คุณสามารถดึงหน้าต่างออกจากการจัดสรรพื้นที่ทำงานของมันได้ด้วย `Super + O` นั่นจะปักหมุดมันเป็นหน้าต่างลอยที่ตามคุณไปไม่ว่าคุณจะไปที่พื้นที่ทำงานใด เหมาะมากสำหรับโปรแกรมเล่นวิดีโอและอะไรทำนองนั้น

 ![navigation-popped-window](images/navigation-popped-window.webp)

### พื้นที่ทำงาน scratchpad

มีพื้นที่ทำงาน scratchpad แบบเต็มขนาดพิเศษที่วางทับพื้นที่ทำงานใดก็ตามที่คุณอยู่ปัจจุบัน คุณเข้าถึงสิ่งที่อยู่บนนั้นได้โดยใช้ `Super + S` และคุณวางหน้าต่างไว้ที่นั่นโดยใช้ `Super + Alt + S`

มันเหมาะมากสำหรับส่วนควบคุมหรือเทอร์มินัลที่คุณต้องการโต้ตอบด้วยอย่างรวดเร็วโดยไม่ต้องออกจากพื้นที่ทำงานปัจจุบัน

### คอนโซล Quake

สุดท้าย มีคอนโซล Quake แบบครึ่งความสูงที่เลื่อนลงมาทับพื้นที่ทำงานใดก็ตามที่คุณอยู่ปัจจุบัน สลับเปิดปิดมันด้วย `Super + Grave` และวางหน้าต่างไว้ที่นั่นโดยใช้ `Super + Shift + Grave`

มันเปิดขึ้นพร้อมกับ agent เริ่มต้นของคุณพร้อมใช้งาน ในขณะที่คอนโซลมีหน้าต่างเดียว มันจะเลื่อนลงมาเป็นแผงที่อยู่ตรงกลางแทนที่จะขยายเต็มจอ วางแอปที่สองลงบนมันแล้วมันจะกลับไปเป็นความกว้างเต็ม เพื่อให้ทั้งสองมีพื้นที่วางข้างกัน

หากต้องการย้ายหน้าต่างออกจาก scratchpad หรือคอนโซล ให้ส่งมันไปยังพื้นที่ทำงานอื่นโดยตรงด้วยอะไรอย่างเช่น `Super + Shift + 1`

### ต้องใช้เวลาทำความคุ้นเคยสักหน่อย!

ต้องใช้เวลาสักหน่อยในการทำความคุ้นเคยกับการนำทางเดสก์ท็อปของคุณแบบนี้ แต่เมื่อคุณคุ้นเคยแล้ว จะกลับไปใช้ประสบการณ์เดสก์ท็อปแบบใช้เมาส์เป็นหลักแบบดั้งเดิมได้ยากเลย!
