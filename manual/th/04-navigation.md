# การนำทาง

ทุกอย่างใน Omarchy เกิดขึ้นผ่านแป้นพิมพ์ — _ทุกอย่าง!_ เมื่อระบบเริ่มทำงานครั้งแรก คุณทำอะไรด้วยเมาส์เพียงอย่างเดียวไม่ได้เลยจริง ๆ แต่คุณกด `Super + Space` เพื่อเปิด Omarchy Menu ได้ และจากตรงนี้คุณทำได้แทบทุกอย่าง

แต่ Omarchy menu ไม่ได้ตั้งใจให้เป็นวิธีหลักในการใช้งานระบบเกือบตลอดเวลาด้วยซ้ำ เราทำได้เร็วกว่านั้น! แอปพลิเคชันที่สำคัญที่สุดทั้งหมดถูกผูกไว้กับปุ่มลัดแต่ละปุ่มโดยตรง คุณเปิดเทอร์มินัลด้วย `Super + Return` และเปิดเบราว์เซอร์ด้วย `Super + Shift + Return` ลองทำอันหนึ่งแล้วตามด้วยอีกอัน แล้วคุณจะเห็นความมหัศจรรย์ของการเรียงหน้าต่างแบบ tiling ของ Hyprland ทำงาน:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

จากนั้นคุณกด `Super + J` เพื่อซ้อนหน้าต่างเหล่านั้นไว้ด้านบนของกันและกันแทนที่จะวางไว้ข้างกันได้:

 ![navigation-stacked](images/navigation-stacked.webp)

กด `Super + J` อีกครั้งเพื่อกลับหน้าต่างเหล่านั้นไปยังตำแหน่งข้างกัน จากนั้นลองกด `Super + Shift + Arrow Right` ขณะอยู่ที่เบราว์เซอร์เพื่อสลับหน้าต่าง

ตอนนี้ลองกด `Super + Shift + T` เพื่อเปิด Activity monitor หน้าต่างนั้นจะปรากฏเป็นหน้าต่างแบบลอย คุณสามารถเรียงมันด้วยการกด `Super + T` (และกดอีกครั้งเพื่อทำให้มันกลับไปลอยอีกครั้ง) ตอนนี้กด `Super + Shift + F` เพื่อเปิดตัวจัดการไฟล์ คุณจะได้การจัดวางแบบสี่ช่องที่เรียบร้อย:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

คุณนำทางระหว่างหน้าต่างที่คุณต้องการให้เป็นหน้าต่างที่ใช้งานอยู่ด้วย `Super + Arrow` การทำเช่นนี้จะสลับโฟกัสและย้ายเคอร์เซอร์ไปยังกึ่งกลางของแอปพลิเคชันใหม่ ที่ขอบของหน้าจอ จะดำเนินการต่อไปยังจอภาพที่อยู่ฝั่งนั้น

หากคุณกด `Super + Shift + 2` คุณจะย้ายแอปพลิเคชันที่โฟกัสอยู่ในปัจจุบันไปยังเวิร์กสเปซที่สอง `Super + Shift + 1` ย้ายมันกลับ (และ `Super + Shift + Alt + 2` จะย้ายแอปพลิเคชันที่โฟกัสอยู่ในปัจจุบันไปยังเวิร์กสเปซที่สองโดยไม่สลับไปยังเวิร์กสเปซนั้น)

เมื่อมีจอภาพมากกว่าหนึ่งจอ จอภาพทุกจอจะมีเวิร์กสเปซ 1 ถึง 10 ของตัวเอง `Super + 2` ไปยังเวิร์กสเปซที่สองของจอภาพที่คุณอยู่ และแถบด้านบนของจอภาพแต่ละจอจะแสดงเวิร์กสเปซของตัวเองและเวิร์กสเปซที่กำลังแสดงอยู่ `Super + Tab` หมุนเวียนผ่านเวิร์กสเปซต่าง ๆ บนจอภาพที่คุณอยู่ `Super + Shift + Ctrl + Arrows` ย้ายหน้าต่างที่คุณอยู่ไปยังจอภาพในทิศทางนั้น บนเวิร์กสเปซที่จอภาพนั้นกำลังแสดงอยู่ และ `Super + Shift + Alt + Arrows` ย้ายเวิร์กสเปซที่คุณอยู่ไปยังจอภาพในทิศทางนั้น โดยเวิร์กสเปซจะใช้หมายเลขเดียวกันหากหมายเลขนั้นว่าง จอภาพจะรักษาเวิร์กสเปซของมันไว้เมื่อคุณถอดปลั๊ก: เวิร์กสเปซเหล่านั้นจะเข้าร่วมกับของหน้าจออื่น โดยมีหมายเลขต่อจากเวิร์กสเปซที่หน้าจอนั้นมีอยู่แล้ว และกลับไปอยู่ภายใต้หมายเลขเดิมเมื่อจอภาพกลับมา

หากคุณกด `Super` ค้างไว้และใช้เมาส์คลิกที่หน้าต่าง คุณจะสามารถจัดเรียงตำแหน่งที่หน้าต่างอยู่ใหม่ได้ หากคุณกด `Super` ค้างไว้และใช้ปุ่มขวาบนเมาส์ คุณสามารถปรับขนาดหน้าต่างได้อย่างอิสระ

คุณปิดหน้าต่างด้วย `Super + W` หรือ `Super + Q` (และปิดหน้าต่างทั้งหมดด้วย `Ctrl + Alt + Delete`)

คุณยังสามารถแสดงแบบเต็มหน้าจอด้วย `Super + F` หรือแม้แต่แบบเต็มความกว้าง (โดยยังคงแถบด้านบนไว้) ด้วย `Super + Alt + F` หรือแบบเต็มหน้าจอภายในหน้าต่างด้วย `Super + Ctrl + F` (เหมาะสำหรับ YouTube!)

### เลย์เอาต์แบบ dwindle กับแบบ scrolling

เลย์เอาต์เริ่มต้นของ Omarchy เรียกว่า dwindle มันทำให้หน้าต่างทั้งหมดที่คุณเปิดบนเวิร์กสเปซเดียวมองเห็นได้ตลอดเวลา แม้ว่าจะต้องย่อหน้าต่างเหล่านั้นลงก็ตาม

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

แต่คุณยังสามารถเลือกเปลี่ยนเวิร์กสเปซให้เป็นเลย์เอาต์แบบ scrolling ซึ่งหน้าต่างจะเรียงกันข้าง ๆ กัน เกินขอบที่มองเห็นได้ของหน้าจอ คุณเปลี่ยนเวิร์กสเปซเดียวให้เป็นเลย์เอาต์นี้ผ่าน `Super + L`

การกด `Super + L` อีกครั้งจะเปลี่ยนเวิร์กสเปซให้เป็นแบบลอย ซึ่งหน้าต่างจะซ้อนทับกันได้อย่างอิสระและคุณวางหน้าต่างเหล่านั้นเอง และการกดครั้งที่สามจะทำให้มันกลับไปเป็น dwindle `Super + Alt + L` จะไล่ผ่านพวกมันไปในทิศทางอื่น หน้าต่างที่ลอยอยู่แล้ว — หน้าต่างที่คุณเปิดออกมาด้วย `Super + T` หรือแอปที่เปิดแบบลอยเสมอ — จะยังคงลอยอยู่เมื่อเวิร์กสเปซกลับไปเป็นแบบ tiling แถบด้านบนจะทำเครื่องหมายเวิร์กสเปซที่คุณอยู่ด้วยเลย์เอาต์ของมัน: สี่เหลี่ยมจัตุรัสสำหรับ dwindle วงกลมสำหรับ scrolling และสามเหลี่ยมสำหรับแบบลอย การคลิกเครื่องหมายนั้นก็จะหมุนเวียนเลย์เอาต์เช่นกัน

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

ตัวเลือกนี้เป็นแบบต่อเวิร์กสเปซ และมันจะคงอยู่ ดังนั้นคุณสามารถให้เวิร์กสเปซ 1 อยู่บน dwindle สำหรับการท่องเว็บ และเวิร์กสเปซ 2 อยู่บน scrolling สำหรับเขียนโค้ด และพวกมันจะกลับมาเป็นแบบนั้นหลังจากรีสตาร์ท

หากคุณต้องการใช้เลย์เอาต์แบบ scrolling เป็นค่าเริ่มต้น คุณสามารถตั้งค่าได้ใน `~/.config/hypr/looknfeel.lua`:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### เวิร์กสเปซแบบลอย

เวิร์กสเปซแบบลอยทำงานเหมือนเดสก์ท็อปแบบดั้งเดิม: หน้าต่างซ้อนทับกัน และคุณย้ายและปรับขนาดหน้าต่างเหล่านั้นเอง หน้าต่างแต่ละหน้าต่างจะมีแถบชื่อในสีของธีมของคุณ พร้อมปุ่มสำหรับย่อ ขยาย และปิด `Super + M` ก็ย่อหน้าต่างที่โฟกัสอยู่ได้เช่นกัน หน้าต่างที่ย่อแล้วจะรออยู่ใน dock คลิกแอปของมันเพื่อนำมันกลับมา คลิกหน้าต่างเพื่อนำมันมาด้านหน้า ปรับขนาดมันจากขอบหรือมุมใดก็ได้ ดับเบิลคลิกแถบชื่อเพื่อขยายหน้าต่างในขณะที่ยังคงมองเห็นแถบด้านบนไว้ และทำอีกครั้งเพื่อกลับไปเป็นขนาดเดิม

เวิร์กสเปซแบบลอยยังแสดง dock พร้อมแอปที่ปักหมุดไว้ของคุณ ทุกอย่างที่กำลังทำงานอยู่ และตารางของทุกแอปที่อยู่หลังปุ่มแอป ซึ่ง `Super + Alt + Space` และ _Apps_ ใน Omarchy menu ก็เปิดเช่นกัน คลิกขวาที่แอปบนตาราง หรือกด `Delete` เพื่อถอนการติดตั้ง คลิกแอปเพื่อเปิดแอป หรือเพื่อนำหน้าต่างของมันมาด้านหน้า คลิกอีกครั้งเพื่อหมุนเวียนผ่านหน้าต่างของมัน คลิกกลางเพื่อเปิดหน้าต่างใหม่ ลากไอคอนไปตาม dock เพื่อย้ายมัน การลากแอปที่กำลังทำงานอยู่เข้าไปรวมกับแอปอื่น ๆ จะทำให้มันอยู่ที่นั่น คลิกขวาเพื่อเก็บแอปไว้ใน dock นำมันออก หรือออกแอป dock จะหลีกทางให้กับหน้าต่างแบบเต็มหน้าจอ คลิกขวาที่ปุ่มแอปเพื่อย้าย dock ไปยังขอบอื่น หรือให้มันซ่อนจนกว่าตัวชี้จะไปถึงขอบของมัน ตำแหน่งยังอยู่ภายใต้ _Appearance > Dock > Dock Position_ ด้วย และ `omarchy dock position left` และ `omarchy dock autohide on` ตั้งค่าทั้งสองอย่างจากเทอร์มินัล แอปที่คุณเก็บไว้ใน dock จะจางลงในขณะที่ยังไม่ได้ทำงาน

เวิร์กสเปซใหม่ และเวิร์กสเปซใด ๆ ที่คุณยังไม่ได้กำหนดเลย์เอาต์ของตัวเองด้วย `Super + L` จะใช้เลย์เอาต์เริ่มต้น การเปลี่ยนค่าเริ่มต้นจะรีเซ็ตเวิร์กสเปซที่ไม่มีหน้าต่างทุกแห่งให้เป็นเลย์เอาต์นั้น ในขณะที่เวิร์กสเปซที่มีหน้าต่างอยู่จะยังคงเลย์เอาต์ที่มีอยู่ หน้าต่างที่ย่อไปยัง dock ก็ยังคงนับเป็นหน้าต่างบนเวิร์กสเปซที่มันจากมา เลือกมันภายใต้ _Appearance > Workspace Layout_: Tiling, Scrolling, หรือ Floating `omarchy-hyprland-workspace-layout-default scrolling` ตั้งค่ามันจากเทอร์มินัล

### การจัดกลุ่มหน้าต่าง

หน้าต่างสามารถจัดกลุ่มได้โดยใช้ `Super + G` เมื่อคุณอยู่ในกลุ่ม ทุกหน้าต่างที่คุณเปิดในขณะที่กลุ่มนั้นใช้งานอยู่จะอยู่ในกลุ่มนั้น คุณสามารถย้ายระหว่างหน้าต่างที่จัดกลุ่มเหล่านี้ได้โดยใช้ `Super + Ctrl + Arrow Left/Right` หรือ `Super + Alt + 1/2/3/4` เพื่อไปยังหน้าต่างที่จัดกลุ่มตามลำดับโดยตรง

คุณสามารถย้ายหน้าต่างออกจากกลุ่มด้วย `Super + Alt + G` หรือแยกกลุ่มทั้งหมดโดยกด `Super + G` อีกครั้ง สุดท้าย คุณสามารถย้ายหน้าต่างนอกกลุ่มให้เข้ามาในกลุ่มด้วย `Super + Alt + Arrows`

### การเปิดหน้าต่างออกมา

คุณสามารถเปิดหน้าต่างออกมาจากการจัดสรรเวิร์กสเปซของมันด้วย `Super + O` การทำเช่นนี้จะปักหมุดมันเป็นหน้าต่างแบบลอยที่ตามคุณไปไม่ว่าคุณจะไปยังเวิร์กสเปซใด เหมาะมากสำหรับโปรแกรมเล่นวิดีโอและสิ่งที่คล้ายกัน

 ![navigation-popped-window](images/navigation-popped-window.webp)

### เวิร์กสเปซแบบ scratchpad

มีเวิร์กสเปซแบบ scratchpad พิเศษขนาดเต็มรูปแบบที่ซ้อนทับอยู่เหนือเวิร์กสเปซใดก็ตามที่คุณกำลังอยู่ คุณเข้าถึงสิ่งที่อยู่บนเวิร์กสเปซนั้นโดยใช้ `Super + S` และคุณวางหน้าต่างไว้ที่นั่นโดยใช้ `Super + Alt + S`

มันทำงานได้ดีสำหรับตัวควบคุมหรือเทอร์มินัลที่คุณต้องการโต้ตอบด้วยอย่างรวดเร็วโดยไม่ต้องออกจากเวิร์กสเปซปัจจุบัน

### คอนโซลแบบ Quake

สุดท้าย มีคอนโซลแบบ Quake ที่มีความสูงครึ่งหนึ่งซึ่งเลื่อนลงมาเหนือเวิร์กสเปซใดก็ตามที่คุณกำลังอยู่ สลับมันด้วย `Super + Grave` และวางหน้าต่างไว้ที่นั่นโดยใช้ `Super + Shift + Grave`

มันเปิดขึ้นมาพร้อมเอเจนต์เริ่มต้นของคุณพร้อมใช้งาน ในขณะที่คอนโซลมีหน้าต่างเพียงหน้าต่างเดียว มันจะเลื่อนลงมาเป็นแผงที่อยู่กึ่งกลางแทนที่จะขยายเต็มหน้าจอ วางแอปที่สองลงบนมันแล้วมันจะกลับไปเป็นความกว้างเต็มรูปแบบ เพื่อให้ทั้งสองมีที่ว่างนั่งข้างกัน

เพื่อย้ายหน้าต่างออกจาก scratchpad หรือคอนโซล ส่งมันโดยตรงไปยังเวิร์กสเปซอื่นด้วยอะไรอย่างเช่น `Super + Shift + 1`

### มันต้องใช้เวลาทำความคุ้นเคยบ้าง!

มันต้องใช้เวลาสักหน่อยในการทำความคุ้นเคยกับการนำทางเดสก์ท็อปของคุณแบบนี้ แต่เมื่อคุณคุ้นเคยแล้ว มันจะยากที่จะกลับไปสู่ประสบการณ์เดสก์ท็อปแบบดั้งเดิมที่ขับเคลื่อนด้วยเมาส์!
