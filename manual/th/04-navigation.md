# การนำทาง

ทุกอย่างใน Omarchy เกิดขึ้นผ่านแป้นพิมพ์ — _ทุกอย่าง!_ เมื่อระบบเริ่มทำงานครั้งแรก คุณแทบทำอะไรไม่ได้เลยด้วยเมาส์เพียงอย่างเดียว แต่คุณกด `Super + Space` เพื่อเปิด Omarchy Menu ได้ และจากตรงนี้คุณทำได้แทบทุกอย่าง

แต่เมนู Omarchy ไม่ได้ถูกออกแบบมาให้เป็นวิธีหลักในการใช้งานระบบในเวลาส่วนใหญ่ด้วยซ้ำ เราเร็วกว่านั้นได้! แอปพลิเคชันที่สำคัญที่สุดทั้งหมดถูกผูกไว้กับปุ่มลัดเฉพาะโดยตรง คุณเปิดเทอร์มินัลด้วย `Super + Return` และเปิดเบราว์เซอร์ด้วย `Super + Shift + Return` ลองทำอย่างหนึ่งต่ออีกอย่าง แล้วคุณจะเห็นความมหัศจรรย์ของการเรียงหน้าต่างของ Hyprland ทำงาน:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

จากนั้นคุณกด `Super + J` เพื่อซ้อนหน้าต่างเหล่านั้นทับกันแทนที่จะวางเคียงข้างกันได้:

 ![navigation-stacked](images/navigation-stacked.webp)

กด `Super + J` อีกครั้งเพื่อนำหน้าต่างกลับไปยังตำแหน่งเคียงข้างกัน จากนั้นลองกด `Super + Shift + Arrow Right` ขณะอยู่ในเบราว์เซอร์เพื่อสลับหน้าต่าง

ตอนนี้ลองกด `Super + Shift + T` เพื่อเปิด Activity monitor หน้าต่างนั้นจะปรากฏเป็นหน้าต่างแบบลอย พร้อมแถบชื่อเรื่องให้ลากได้ และปุ่มสำหรับย่อ ขยาย และปิด หน้าต่างแบบลอยทุกบานจะมีแถบนี้ ไม่ว่าจะอยู่ที่ใด คุณสามารถเรียงมันแบบ tiling ได้ด้วย `Super + T` (และกดอีกครั้งเพื่อทำให้มันลอยอีกครั้ง) ตอนนี้กด `Super + Shift + F` เพื่อเปิดตัวจัดการไฟล์ คุณจะได้การจัดวางสี่ทางอย่างสวยงาม:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

คุณนำทางไปยังหน้าต่างที่คุณต้องการให้ใช้งานอยู่ด้วย `Super + Arrow` การทำเช่นนี้จะสลับโฟกัสและย้ายเคอร์เซอร์ไปยังกึ่งกลางของแอปพลิเคชันใหม่ ที่ขอบของหน้าจอ มันจะต่อเนื่องไปยังจอภาพที่อยู่ด้านนั้น

ถ้าคุณกด `Super + Shift + 2` คุณจะย้ายแอปพลิเคชันที่กำลังโฟกัสอยู่ในปัจจุบันไปยังพื้นที่ทำงานที่สอง `Super + Shift + 1` จะย้ายมันกลับมา (และ `Super + Shift + Alt + 2` จะย้ายแอปพลิเคชันที่กำลังโฟกัสอยู่ในปัจจุบันไปยังพื้นที่ทำงานที่สองโดยไม่สลับไปยังพื้นที่ทำงานนั้น)

เมื่อมีจอภาพมากกว่าหนึ่งจอ แต่ละจอภาพจะมีพื้นที่ทำงาน 1 ถึง 10 ของตัวเอง `Super + 2` จะไปยังพื้นที่ทำงานที่สองของจอภาพที่คุณอยู่ และแถบด้านบนของแต่ละจอภาพจะแสดงพื้นที่ทำงานของตัวเองและพื้นที่ทำงานที่กำลังแสดงอยู่ `Super + Tab` จะวนผ่านพื้นที่ทำงานต่าง ๆ บนจอภาพที่คุณอยู่ `Super + Shift + Ctrl + Arrows` จะย้ายหน้าต่างที่คุณอยู่ไปยังจอภาพในทิศทางนั้น ไปยังพื้นที่ทำงานที่จอนั้นกำลังแสดงอยู่ และ `Super + Shift + Alt + Arrows` จะย้ายพื้นที่ทำงานที่คุณอยู่ไปยังจอภาพในทิศทางนั้น โดยจะใช้หมายเลขเดียวกันถ้าว่างอยู่ จอภาพจะเก็บพื้นที่ทำงานของมันไว้เมื่อคุณถอดปลั๊ก: พื้นที่ทำงานเหล่านั้นจะไปรวมกับของอีกหน้าจอหนึ่ง โดยมีหมายเลขต่อจากที่มีอยู่แล้ว และกลับไปใช้หมายเลขเดิมเมื่อจอภาพกลับมา

ถ้าคุณกด `Super` ค้างไว้และใช้เมาส์คลิกที่หน้าต่าง คุณจะสามารถจัดเรียงตำแหน่งของมันใหม่ได้ ถ้าคุณกด `Super` ค้างไว้และใช้ปุ่มขวาของเมาส์ คุณสามารถปรับขนาดหน้าต่างได้อย่างอิสระ

คุณปิดหน้าต่างด้วย `Super + W` หรือ `Super + Q` (และปิดหน้าต่างทั้งหมดด้วย `Ctrl + Alt + Delete`)

คุณยังสามารถแสดงแบบเต็มหน้าจอด้วย `Super + F` หรือแม้แต่เพียงเต็มความกว้าง (โดยยังคงแถบด้านบนไว้) ด้วย `Super + Alt + F` หรือเต็มหน้าจอภายในหน้าต่างด้วย `Super + Ctrl + F` (เหมาะสำหรับ YouTube!)

### เลย์เอาต์ dwindle เทียบกับ scrolling

เลย์เอาต์เริ่มต้นของ Omarchy เรียกว่า dwindle มันทำให้หน้าต่างทั้งหมดที่คุณเปิดบนพื้นที่ทำงานเดียวมองเห็นได้ตลอดเวลา แม้ว่าจะต้องย่อขนาดลงก็ตาม

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

แต่คุณยังสามารถเลือกเปลี่ยนพื้นที่ทำงานให้เป็นเลย์เอาต์ scrolling ซึ่งหน้าต่างจะเรียงเคียงข้างกันเกินขอบที่มองเห็นได้ของจอแสดงผล คุณเปลี่ยนพื้นที่ทำงานเดียวให้เป็นเลย์เอาต์นี้ได้ด้วย `Super + L`

การกด `Super + L` อีกครั้งจะเปลี่ยนพื้นที่ทำงานเป็นแบบลอย ซึ่งหน้าต่างจะซ้อนทับกันอย่างอิสระและคุณวางตำแหน่งเอง และการกดครั้งที่สามจะนำมันกลับไปยัง dwindle `Super + Alt + L` จะวนผ่านเลย์เอาต์เหล่านี้ในทิศทางตรงกันข้าม หน้าต่างที่ลอยอยู่แล้ว — หน้าต่างที่คุณแยกออกมาด้วย `Super + T` หรือแอปที่เปิดแบบลอยเสมอ — จะยังคงลอยอยู่เมื่อพื้นที่ทำงานกลับไปเป็นแบบ tiling แถบด้านบนจะทำเครื่องหมายพื้นที่ทำงานที่คุณอยู่ด้วยเลย์เอาต์ของมัน: สี่เหลี่ยมจัตุรัสสำหรับ dwindle วงกลมสำหรับ scrolling และสามเหลี่ยมสำหรับ floating การคลิกเครื่องหมายนั้นจะวนเปลี่ยนเลย์เอาต์เช่นกัน และปุ่ม display บนแล็ปท็อปที่มีปุ่มนั้นก็ทำเช่นเดียวกัน

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

ตัวเลือกนี้เป็นแบบต่อพื้นที่ทำงาน และจะคงอยู่ ดังนั้นคุณสามารถให้พื้นที่ทำงาน 1 ใช้ dwindle สำหรับการท่องเว็บ และพื้นที่ทำงาน 2 ใช้ scrolling สำหรับโค้ด และพวกมันจะกลับมาเป็นแบบนั้นหลังจากรีสตาร์ท

ถ้าคุณต้องการใช้เลย์เอาต์ scrolling เป็นค่าเริ่มต้น คุณสามารถตั้งค่าได้ใน `~/.config/hypr/looknfeel.lua`:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### พื้นที่ทำงานแบบลอย

พื้นที่ทำงานแบบลอยทำงานเหมือนเดสก์ท็อปแบบดั้งเดิม: หน้าต่างซ้อนทับกัน และคุณย้ายและปรับขนาดพวกมันเอง หน้าต่างแต่ละบานจะมีแถบชื่อเรื่องในสีของธีมของคุณ พร้อมปุ่มสำหรับย่อ ขยาย และปิด `Super + M` จะย่อหน้าต่างที่กำลังโฟกัสอยู่ด้วยเช่นกัน หน้าต่างที่ถูกย่อจะรออยู่ใน dock; คลิกแอปของมันเพื่อนำกลับมา คลิกหน้าต่างเพื่อนำมันมาข้างหน้า ปรับขนาดมันจากขอบหรือมุมใดก็ได้ ดับเบิลคลิกแถบชื่อเรื่องเพื่อขยายหน้าต่างโดยยังคงแถบด้านบนให้เห็น และดับเบิลคลิกอีกครั้งเพื่อนำขนาดเดิมกลับมา Chrome และเบราว์เซอร์อื่น ๆ ที่ใช้ Chromium เป็นพื้นฐาน Disks และ Document Viewer จะข้ามแถบชื่อเรื่องและใช้ส่วนหัวของตัวเองแทน; `Super + Alt + F` จะขยายพวกมัน และ `Super + M` จะย่อพวกมัน

ทุกพื้นที่ทำงานมี dock พร้อมแอปที่คุณปักหมุดไว้ ทุกอย่างที่กำลังทำงานอยู่ และตารางของทุกแอปที่อยู่หลังปุ่มแอป ซึ่ง `Super + Alt + Space` และ _Apps_ ในเมนู Omarchy ก็เปิดเช่นกัน คลิกขวาที่แอปบนตาราง หรือกด `Delete` เพื่อถอนการติดตั้ง คลิกแอปเพื่อเปิด หรือเพื่อนำหน้าต่างของมันมาข้างหน้า; คลิกอีกครั้งเพื่อวนผ่านหน้าต่างของมัน Files จะนำกลับมาเฉพาะหน้าต่างจากพื้นที่ทำงานที่คุณอยู่ และมิฉะนั้นจะเปิดหน้าต่างใหม่ และ Terminal และ Agent จะเริ่มอีกอินสแตนซ์เสมอ แม้ว่าหน้าต่างที่ถูกย่อจะกลับมาก่อน คลิกกลางจะเปิดหน้าต่างใหม่ ลากไอคอนไปตาม dock เพื่อย้ายมัน; การลากแอปที่กำลังทำงานอยู่เข้าไปรวมกับแอปอื่น ๆ จะเก็บมันไว้ที่นั่น คลิกขวาเพื่อเก็บแอปไว้ใน dock นำมันออก หรือปิดมัน dock จะแสดงอยู่ขณะที่พื้นที่ทำงานว่างเปล่า และเมื่อพื้นที่ทำงานมีหน้าต่าง มันจะซ่อนจนกว่าตัวชี้จะไปถึงขอบของมัน หน้าต่างเต็มหน้าจอจะซ่อนมันโดยสิ้นเชิง ลากปุ่มแอปไปยังขอบอื่นของหน้าจอเพื่อย้าย dock ไปที่นั่น คลิกขวาที่มันเพื่อ _Position_ สำหรับเลือกขอบ _Layout_ สำหรับตั้งเลย์เอาต์เริ่มต้นแบบเดียวกับที่ _Appearance > Workspace Layout_ ทำ และ _Visibility_ เพื่อให้ dock เปิดอยู่เสมอ ให้แอปแรกซ่อนมัน หรือให้มันซ่อนอยู่เสมอ `omarchy dock visibility always` ตั้งค่านั้นจากเทอร์มินัล ตำแหน่งยังอยู่ภายใต้ _Appearance > Dock > Dock Position_ และ `omarchy dock position left` ตั้งค่าจากเทอร์มินัล แอปที่คุณเก็บไว้ใน dock จะจางลงขณะที่ไม่ได้ทำงานอยู่ หากต้องการจำกัด dock ให้อยู่เฉพาะพื้นที่ทำงานแบบลอย ให้ใช้ _Appearance > Dock > Dock Only on Floating_ หรือ `omarchy dock tiling off`

พื้นที่ทำงานใหม่ และพื้นที่ทำงานใด ๆ ที่คุณยังไม่ได้กำหนดเลย์เอาต์ของตัวเองด้วย `Super + L` จะใช้เลย์เอาต์เริ่มต้น การเปลี่ยนค่าเริ่มต้นจะรีเซ็ตทุกพื้นที่ทำงานที่ไม่มีหน้าต่างให้เป็นเลย์เอาต์นั้น ขณะที่พื้นที่ทำงานที่มีหน้าต่างอยู่จะเก็บเลย์เอาต์ที่มีอยู่ไว้ หน้าต่างที่ถูกย่อไปยัง dock ยังนับว่าเป็นหน้าต่างบนพื้นที่ทำงานที่มันจากมา เลือกได้ภายใต้ _Appearance > Workspace Layout_: Tiling, Scrolling หรือ Floating `omarchy hyprland workspace layout default scrolling` ตั้งค่าจากเทอร์มินัล

### การจัดกลุ่มหน้าต่าง

หน้าต่างสามารถจัดกลุ่มได้ด้วย `Super + G` เมื่อคุณอยู่ในกลุ่มแล้ว หน้าต่างทุกบานที่คุณเปิดขณะที่กลุ่มนั้นใช้งานอยู่จะเป็นของกลุ่มนั้น คุณสามารถย้ายไปมาระหว่างหน้าต่างที่จัดกลุ่มเหล่านี้ได้ด้วย `Super + Ctrl + Arrow Left/Right` หรือ `Super + Alt + 1/2/3/4` เพื่อไปยังหน้าต่างที่จัดกลุ่มตามลำดับโดยตรง

คุณสามารถย้ายหน้าต่างออกจากกลุ่มได้ด้วย `Super + Alt + G` หรือแยกกลุ่มทั้งหมดโดยกด `Super + G` อีกครั้ง สุดท้าย คุณสามารถย้ายหน้าต่างที่อยู่นอกกลุ่มเข้าไปในกลุ่มได้ด้วย `Super + Alt + Arrows`

### การแยกหน้าต่างออก

คุณสามารถแยกหน้าต่างออกจากการจัดสรรพื้นที่ทำงานของมันได้ด้วย `Super + O` การทำเช่นนี้จะปักหมุดมันเป็นหน้าต่างแบบลอยที่จะติดตามคุณไปยังพื้นที่ทำงานใดก็ตามที่คุณไป เหมาะมากสำหรับเครื่องเล่นวิดีโอและสิ่งที่คล้ายกัน

 ![navigation-popped-window](images/navigation-popped-window.webp)

### พื้นที่ทำงาน scratchpad

มีพื้นที่ทำงาน scratchpad ขนาดเต็มแบบพิเศษที่ซ้อนทับพื้นที่ทำงานใดก็ตามที่คุณอยู่ในปัจจุบัน คุณเข้าถึงสิ่งที่อยู่บนมันได้ด้วย `Super + S` และคุณวางหน้าต่างไว้ที่นั่นด้วย `Super + Alt + S`

มันทำงานได้ดีสำหรับส่วนควบคุมหรือเทอร์มินัลที่คุณต้องการโต้ตอบด้วยอย่างรวดเร็วโดยไม่ต้องออกจากพื้นที่ทำงานปัจจุบัน

### คอนโซล Quake

สุดท้าย มีคอนโซล Quake สูงครึ่งหนึ่งที่เลื่อนลงมาทับพื้นที่ทำงานใดก็ตามที่คุณอยู่ในปัจจุบัน สลับเปิดปิดมันด้วย `Super + the key above Tab` (grave บนเลย์เอาต์ US) และวางหน้าต่างไว้ที่นั่นด้วย `Super + Shift + the key above Tab`

ครั้งแรกที่มันเปิด มันจะเริ่ม agent เริ่มต้นของคุณ หรือขอให้คุณเลือกหนึ่งตัวถ้าคุณยังไม่ได้เลือก ขณะที่คอนโซลมีหน้าต่างเพียงบานเดียว มันจะเลื่อนลงมาเป็นแผงที่อยู่กึ่งกลางแทนที่จะขยายเต็มหน้าจอ วางแอปที่สองลงบนมันแล้วมันจะกลับไปเป็นความกว้างเต็ม เพื่อให้ทั้งสองมีพื้นที่วางเคียงข้างกัน

หากต้องการย้ายหน้าต่างออกจาก scratchpad หรือคอนโซล ให้ส่งมันไปยังพื้นที่ทำงานอื่นโดยตรงด้วยอะไรอย่างเช่น `Super + Shift + 1`

### ต้องใช้เวลาทำความคุ้นเคยสักหน่อย!

ต้องใช้เวลาสักเล็กน้อยในการทำความคุ้นเคยกับการนำทางเดสก์ท็อปของคุณแบบนี้ แต่เมื่อคุณคุ้นเคยแล้ว มันจะยากที่จะกลับไปสู่ประสบการณ์เดสก์ท็อปแบบดั้งเดิมที่ขับเคลื่อนด้วยเมาส์!
