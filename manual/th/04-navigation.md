# การนำทาง

ทุกอย่างใน Omarchy เกิดขึ้นผ่านแป้นพิมพ์ — _ทั้งหมด!_ เมื่อระบบเริ่มทำงานครั้งแรก คุณทำอะไรด้วยเมาส์อย่างเดียวไม่ได้เลยจริง ๆ แต่คุณกด `Super + Space` เพื่อเปิด Omarchy Menu ขึ้นมาได้ และจากตรงนี้คุณทำได้แทบทุกอย่าง

แต่เมนู Omarchy ไม่ได้ถูกตั้งใจให้เป็นวิธีหลักในการใช้งานระบบเป็นส่วนใหญ่ด้วยซ้ำ เราเร็วกว่านั้นได้! แอปพลิเคชันที่สำคัญที่สุดทั้งหมดผูกไว้กับปุ่มลัดแยกแต่ละปุ่มโดยตรง คุณเปิดเทอร์มินัลด้วย `Super + Return` และเปิดเบราว์เซอร์ด้วย `Super + Shift + Return` ลองทำอันหนึ่งตามด้วยอีกอัน แล้วคุณจะเห็นเวทมนตร์ของการจัดวางหน้าต่างแบบเรียงกระเบื้องของ Hyprland ทำงาน:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

จากนั้นคุณกด `Super + J` เพื่อซ้อนพวกมันไว้บนกันแทนที่จะวางข้างกันได้:

 ![navigation-stacked](images/navigation-stacked.webp)

กด `Super + J` อีกครั้งเพื่อคืนพวกมันกลับไปยังตำแหน่งข้างกัน จากนั้นลองกด `Super + Shift + Arrow Right` ขณะอยู่ในเบราว์เซอร์เพื่อสลับหน้าต่าง

ตอนนี้ลองกด `Super + Shift + T` เพื่อเปิด Activity monitor ขึ้นมา นั่นจะปรากฏเป็นหน้าต่างลอย คุณสามารถจัดวางมันแบบเรียงกระเบื้องได้ด้วย `Super + T` (และกดอีกครั้งเพื่อทำให้มันลอยอีกครั้ง) ตอนนี้กด `Super + Shift + F` เพื่อเปิดตัวจัดการไฟล์ คุณจะได้ชุดสี่หน้าต่างที่เรียบร้อย:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

คุณนำทางระหว่างหน้าต่างที่คุณต้องการให้เป็นหน้าต่างที่ใช้งานอยู่ด้วย `Super + Arrow` นี่จะสลับโฟกัสและย้ายเคอร์เซอร์ไปยังกึ่งกลางของแอปพลิเคชันใหม่ ที่ขอบของจอ มันจะไปต่อยังจอภาพที่อยู่ด้านนั้น

ถ้าคุณกด `Super + Shift + 2` คุณจะย้ายแอปพลิเคชันที่กำลังโฟกัสอยู่ในปัจจุบันไปยังพื้นที่ทำงานที่สอง `Super + Shift + 1` ย้ายมันกลับ (และ `Super + Shift + Alt + 2` จะย้ายแอปพลิเคชันที่กำลังโฟกัสอยู่ในปัจจุบันไปยังพื้นที่ทำงานที่สองโดยไม่สลับไปยังพื้นที่ทำงานนั้น)

เมื่อมีจอภาพมากกว่าหนึ่งจอ จอภาพทุกจอมีพื้นที่ทำงาน 1 ถึง 10 ของตัวเอง `Super + 2` ไปยังพื้นที่ทำงานที่สองของจอภาพที่คุณอยู่ และแถบบนของจอภาพแต่ละจอแสดงพื้นที่ทำงานของมันเองและพื้นที่ทำงานที่มันกำลังแสดงอยู่ `Super + Tab` วนผ่านพื้นที่ทำงานต่าง ๆ บนจอภาพที่คุณอยู่ `Super + Shift + Ctrl + Arrows` ย้ายหน้าต่างที่คุณอยู่ไปยังจอภาพในทิศทางนั้น ไปยังพื้นที่ทำงานที่จอนั้นกำลังแสดงอยู่ และ `Super + Shift + Alt + Arrows` ย้ายพื้นที่ทำงานที่คุณอยู่ไปยังจอภาพในทิศทางนั้น ซึ่งที่นั่นมันใช้หมายเลขเดียวกันถ้าว่างอยู่ จอภาพจะเก็บพื้นที่ทำงานของมันไว้เมื่อคุณถอดมันออก: พวกมันจะไปรวมกับของอีกจอหนึ่ง โดยเรียงหมายเลขต่อจากที่มีอยู่แล้ว และกลับไปอยู่ภายใต้หมายเลขเดิมเมื่อจอภาพนั้นกลับมา

ถ้าคุณกด `Super` ค้างไว้และใช้เมาส์คลิกบนหน้าต่าง คุณจะสามารถจัดเรียงตำแหน่งที่มันอยู่ใหม่ได้ ถ้าคุณกด `Super` ค้างไว้และใช้ปุ่มขวาบนเมาส์ คุณสามารถปรับขนาดหน้าต่างได้อย่างอิสระ

คุณปิดหน้าต่างด้วย `Super + W` หรือ `Super + Q` (และปิดหน้าต่างทั้งหมดด้วย `Ctrl + Alt + Delete`)

คุณยังเข้าสู่โหมดเต็มจอได้ด้วย `Super + F` หรือแม้แต่แค่เต็มความกว้าง (โดยยังเก็บแถบบนไว้) ด้วย `Super + Alt + F` หรือเต็มจอภายในหน้าต่างด้วย `Super + Ctrl + F` (ดีสำหรับ YouTube!)

### เลย์เอาต์ dwindle กับ scrolling

เลย์เอาต์เริ่มต้นของ Omarchy เรียกว่า dwindle มันให้หน้าต่างทั้งหมดที่คุณเปิดบนพื้นที่ทำงานเดียวมองเห็นได้ตลอดเวลา แม้ว่ามันจะต้องย่อพวกมันลงก็ตาม

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

แต่คุณยังเลือกเปลี่ยนพื้นที่ทำงานให้เป็นเลย์เอาต์ scrolling ได้เช่นกัน ซึ่งหน้าต่างจะเรียงแถวข้างกัน พ้นขอบที่มองเห็นของจอแสดงผลไป คุณเปลี่ยนพื้นที่ทำงานเดียวให้เป็นเลย์เอาต์นี้ผ่าน `Super + L`

การกด `Super + L` อีกครั้งจะเปลี่ยนพื้นที่ทำงานเป็นแบบลอย ซึ่งหน้าต่างซ้อนทับกันได้อย่างอิสระและคุณวางพวกมันเอง และการกดครั้งที่สามจะคืนมันกลับไปเป็น dwindle `Super + Alt + L` จะวนไปทางอื่น หน้าต่างที่ลอยอยู่แล้ว — หน้าต่างที่คุณดึงออกมาด้วย `Super + T` หรือแอปที่เปิดแบบลอยเสมอ — จะยังลอยต่อไปเมื่อพื้นที่ทำงานกลับไปเป็นการจัดวางแบบเรียงกระเบื้อง แถบบนทำเครื่องหมายพื้นที่ทำงานที่คุณอยู่ด้วยเลย์เอาต์ของมัน: สี่เหลี่ยมจัตุรัสสำหรับ dwindle วงกลมสำหรับ scrolling และสามเหลี่ยมสำหรับแบบลอย การคลิกที่เครื่องหมายนั้นก็วนเปลี่ยนเลย์เอาต์เช่นกัน และปุ่มแสดงผลบนแล็ปท็อปที่มีปุ่มนั้นก็ทำเช่นเดียวกัน

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

ตัวเลือกนี้เป็นแบบแยกตามพื้นที่ทำงาน และมันจะติดอยู่ ดังนั้นคุณสามารถเก็บพื้นที่ทำงาน 1 ไว้บน dwindle สำหรับการท่องเว็บ และพื้นที่ทำงาน 2 ไว้บน scrolling สำหรับโค้ดได้ และพวกมันจะกลับมาเป็นแบบนั้นหลังจากรีสตาร์ท

ถ้าคุณต้องการใช้เลย์เอาต์ scrolling เป็นค่าเริ่มต้น คุณสามารถตั้งค่านั้นได้ใน `~/.config/hypr/looknfeel.lua`:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### พื้นที่ทำงานแบบลอย

พื้นที่ทำงานแบบลอยทำงานเหมือนเดสก์ท็อปแบบดั้งเดิม: หน้าต่างซ้อนทับกัน และคุณย้ายและปรับขนาดพวกมันเอง หน้าต่างแต่ละบานได้รับแถบชื่อเรื่องในสีของธีมของคุณ พร้อมปุ่มสำหรับย่อให้เล็กสุด ขยายให้ใหญ่สุด และปิด `Super + M` ก็ย่อหน้าต่างที่โฟกัสอยู่ให้เล็กสุดด้วยเช่นกัน หน้าต่างที่ย่อให้เล็กสุดจะรออยู่ใน dock; คลิกแอปของมันเพื่อนำมันกลับมา คลิกหน้าต่างเพื่อนำมันมาข้างหน้า ปรับขนาดมันจากขอบหรือมุมใดก็ได้ ดับเบิลคลิกแถบชื่อเรื่องเพื่อขยายหน้าต่างให้ใหญ่สุดในขณะที่ยังมองเห็นแถบบนอยู่ และอีกครั้งเพื่อเอาขนาดเดิมของมันกลับคืนมา Chrome และเบราว์เซอร์อื่น ๆ ที่ใช้ Chromium เป็นพื้นฐาน, Disks และ Document Viewer ข้ามแถบชื่อเรื่องและใช้ส่วนหัวของพวกมันเองแทน; `Super + Alt + F` ขยายพวกมันให้ใหญ่สุด และ `Super + M` ย่อพวกมันให้เล็กสุด

พื้นที่ทำงานแบบลอยยังแสดง dock ด้วย โดยมีแอปที่คุณปักหมุดไว้ ทุกอย่างที่กำลังทำงานอยู่ และตารางกริดของทุกแอปที่อยู่เบื้องหลังปุ่มแอป ซึ่ง `Super + Alt + Space` และ _Apps_ ในเมนู Omarchy ก็เปิดเช่นกัน คลิกขวาที่แอปบนตารางกริด หรือกด `Delete` เพื่อถอนการติดตั้งมัน คลิกแอปเพื่อเปิดมัน หรือเพื่อนำหน้าต่างของมันมาข้างหน้า; คลิกอีกครั้งเพื่อวนผ่านหน้าต่างต่าง ๆ ของมัน Files จะนำกลับมาเฉพาะหน้าต่างจากพื้นที่ทำงานที่คุณอยู่ และมิฉะนั้นจะเปิดหน้าต่างใหม่ และ Terminal และ Agent จะเริ่มอีกอันเสมอ แม้ว่าหน้าต่างที่ย่อให้เล็กสุดจะกลับมาก่อน คลิกกลางเพื่อเปิดหน้าต่างใหม่ ลากไอคอนไปตาม dock เพื่อย้ายมัน; การลากแอปที่กำลังทำงานเข้าไปในหมู่แอปอื่น ๆ จะเก็บมันไว้ตรงนั้น คลิกขวาเพื่อเก็บแอปไว้ใน dock เอามันออก หรือออกจากมัน dock จะหลีกทางให้หน้าต่างเต็มจอ คลิกขวาที่ปุ่มแอปเพื่อย้าย dock ไปยังขอบอื่นหรือให้มันซ่อนจนกว่าตัวชี้จะไปถึงขอบของมัน ตำแหน่งยังอยู่ภายใต้ _Appearance > Dock > Dock Position_ และ `omarchy dock position left` และ `omarchy dock autohide on` ตั้งค่าทั้งสองจากเทอร์มินัล แอปที่คุณเก็บไว้ใน dock จะจางลงขณะที่พวกมันไม่ได้ทำงานอยู่

พื้นที่ทำงานใหม่ และพื้นที่ทำงานใด ๆ ที่คุณยังไม่ได้ให้เลย์เอาต์ของตัวเองด้วย `Super + L` จะใช้เลย์เอาต์เริ่มต้น การเปลี่ยนค่าเริ่มต้นจะรีเซ็ตพื้นที่ทำงานทุกอันที่ไม่มีหน้าต่างไปยังเลย์เอาต์นั้น ในขณะที่พื้นที่ทำงานที่มีหน้าต่างอยู่จะเก็บเลย์เอาต์ที่มันมีไว้ หน้าต่างที่ย่อให้เล็กสุดไปยัง dock ยังนับเป็นหน้าต่างบนพื้นที่ทำงานที่มันจากมา เลือกมันภายใต้ _Appearance > Workspace Layout_: Tiling, Scrolling หรือ Floating `omarchy hyprland workspace layout default scrolling` ตั้งค่ามันจากเทอร์มินัล

### การจัดกลุ่มหน้าต่าง

หน้าต่างสามารถจัดกลุ่มได้โดยใช้ `Super + G` เมื่อคุณอยู่ในกลุ่มแล้ว หน้าต่างทุกบานที่คุณเปิดขณะที่กลุ่มนั้นใช้งานอยู่จะเป็นของกลุ่มนั้น คุณสามารถย้ายระหว่างหน้าต่างที่จัดกลุ่มเหล่านี้ได้โดยใช้ `Super + Ctrl + Arrow Left/Right` หรือ `Super + Alt + 1/2/3/4` เพื่อไปยังหน้าต่างที่จัดกลุ่มตามลำดับโดยตรง

คุณสามารถย้ายหน้าต่างออกจากกลุ่มได้ด้วย `Super + Alt + G` หรือแยกกลุ่มทั้งหมดออกจากกันโดยการกด `Super + G` อีกครั้ง สุดท้าย คุณสามารถย้ายหน้าต่างนอกกลุ่มเข้าไปในกลุ่มได้ด้วย `Super + Alt + Arrows`

### การดึงหน้าต่างออก

คุณสามารถดึงหน้าต่างออกจากการจัดสรรพื้นที่ทำงานของมันได้ด้วย `Super + O` นั่นจะปักหมุดมันเป็นหน้าต่างลอยที่ตามคุณไปไม่ว่าคุณจะไปยังพื้นที่ทำงานใดก็ตาม ยอดเยี่ยมสำหรับเครื่องเล่นวิดีโอและอะไรทำนองนั้น

 ![navigation-popped-window](images/navigation-popped-window.webp)

### พื้นที่ทำงาน scratchpad

มีพื้นที่ทำงาน scratchpad ขนาดเต็มแบบพิเศษที่ซ้อนทับอยู่บนพื้นที่ทำงานใดก็ตามที่คุณอยู่ตอนนี้ คุณเข้าถึงสิ่งที่อยู่บนมันได้โดยใช้ `Super + S` และคุณวางหน้าต่างไว้ที่นั่นโดยใช้ `Super + Alt + S`

มันทำงานได้ดีสำหรับส่วนควบคุมหรือเทอร์มินัลที่คุณต้องการโต้ตอบด้วยอย่างรวดเร็วโดยไม่ต้องออกจากพื้นที่ทำงานปัจจุบัน

### คอนโซล Quake

สุดท้าย มีคอนโซล Quake สูงครึ่งหนึ่งที่เลื่อนลงมาทับพื้นที่ทำงานใดก็ตามที่คุณอยู่ตอนนี้ สลับเปิดปิดมันด้วย `Super + the key above Tab` (grave ในเลย์เอาต์ US) และวางหน้าต่างไว้ที่นั่นโดยใช้ `Super + Shift + the key above Tab`

ครั้งแรกที่มันเปิด มันจะเริ่มเอเจนต์เริ่มต้นของคุณ หรือขอให้คุณเลือกหนึ่งตัวหากคุณยังไม่ได้เลือก เมื่อคอนโซลมีหน้าต่างเพียงบานเดียว มันจะเลื่อนลงมาเป็นแผงที่อยู่ตรงกลางแทนที่จะทอดยาวเต็มจอ วางแอปตัวที่สองลงบนมันแล้วมันจะกลับไปเป็นความกว้างเต็ม เพื่อให้ทั้งสองมีพื้นที่นั่งข้างกัน

เพื่อย้ายหน้าต่างออกจาก scratchpad หรือคอนโซล ให้ส่งมันโดยตรงไปยังพื้นที่ทำงานอื่นด้วยอะไรอย่างเช่น `Super + Shift + 1`

ต้องใช้เวลาสักเล็กน้อยเพื่อทำความคุ้นเคยกับการนำทางเดสก์ท็อปของคุณแบบนี้ แต่เมื่อคุณคุ้นแล้ว มันจะยากที่จะกลับไปสู่ประสบการณ์เดสก์ท็อปแบบดั้งเดิมที่ขับเคลื่อนด้วยเมาส์!
