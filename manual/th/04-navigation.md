# การนำทาง

ทุกอย่างใน Omarchy เกิดขึ้นผ่านแป้นพิมพ์ — _ทุกอย่าง!_ เมื่อระบบเริ่มทำงานครั้งแรก คุณทำอะไรด้วยเมาส์เพียงอย่างเดียวไม่ได้เลยจริง ๆ แต่คุณกด `Super + Space` เพื่อเปิด Omarchy Menu ได้ และจากที่นี่คุณทำได้แทบทุกอย่าง

แต่ Omarchy menu ไม่ได้ถูกตั้งใจให้เป็นวิธีหลักในการใช้งานระบบในเวลาส่วนใหญ่ด้วยซ้ำ เราเร็วกว่านั้นได้! แอปพลิเคชันที่สำคัญที่สุดทั้งหมดถูกผูกไว้กับปุ่มลัดแต่ละปุ่มโดยตรง คุณเปิดเทอร์มินัลด้วย `Super + Return` และเปิดเบราว์เซอร์ด้วย `Super + Shift + Return` ลองกดทำทีละอย่างต่อเนื่องกัน แล้วคุณจะเห็นเวทมนตร์ของการจัดวางแบบไทล์ของ Hyprland ทำงาน:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

จากนั้นคุณกด `Super + J` เพื่อวางซ้อนทับกันแทนที่จะวางข้างกันได้:

 ![navigation-stacked](images/navigation-stacked.webp)

กด `Super + J` อีกครั้งเพื่อกลับไปวางข้างกันตามเดิม จากนั้นลองกด `Super + Shift + Arrow Right` ขณะอยู่ในเบราว์เซอร์เพื่อสลับหน้าต่าง

คราวนี้ลองกด `Super + Shift + T` เพื่อเปิด Activity monitor นั่นจะปรากฏเป็นหน้าต่างลอย คุณสามารถจัดวางแบบไทล์ได้ด้วย `Super + T` (และกดอีกครั้งเพื่อทำให้ลอยอีกครั้ง) ตอนนี้กด `Super + Shift + F` เพื่อเปิดตัวจัดการไฟล์ คุณจะได้การจัดวางสี่ทางที่เรียบร้อย:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

คุณนำทางระหว่างหน้าต่างที่คุณต้องการให้ใช้งานอยู่ด้วย `Super + Arrow` นั่นจะสลับโฟกัสและย้ายเคอร์เซอร์ไปยังกึ่งกลางของแอปพลิเคชันใหม่ ที่ขอบของหน้าจอ มันจะต่อเนื่องไปยังจอภาพที่อยู่ด้านนั้น

ถ้าคุณกด `Super + Shift + 2` คุณจะย้ายแอปพลิเคชันที่โฟกัสอยู่ในปัจจุบันไปยังเวิร์กสเปซที่สอง `Super + Shift + 1` จะย้ายกลับมา (และ `Super + Shift + Alt + 2` จะย้ายแอปพลิเคชันที่โฟกัสอยู่ในปัจจุบันไปยังเวิร์กสเปซที่สองโดยไม่สลับไปที่นั่น)

เมื่อมีจอภาพมากกว่าหนึ่งจอ ทุกจอภาพจะมีเวิร์กสเปซ 1 ถึง 10 เป็นของตัวเอง `Super + 2` ไปยังเวิร์กสเปซที่สองของจอภาพที่คุณอยู่ และแถบด้านบนของแต่ละจอภาพจะแสดงเวิร์กสเปซของตัวเองและเวิร์กสเปซที่กำลังแสดงอยู่ `Super + Tab` วนไปตามเวิร์กสเปซต่าง ๆ บนจอภาพที่คุณอยู่ `Super + Shift + Ctrl + Arrows` ย้ายหน้าต่างที่คุณอยู่ไปยังจอภาพในทิศทางนั้น ไปยังเวิร์กสเปซที่จอนั้นกำลังแสดงอยู่ และ `Super + Shift + Alt + Arrows` ย้ายเวิร์กสเปซที่คุณอยู่ไปยังจอภาพในทิศทางนั้น โดยจะใช้หมายเลขเดียวกันหากว่างอยู่ จอภาพจะรักษาเวิร์กสเปซของมันไว้เมื่อคุณถอดปลั๊กออก: เวิร์กสเปซเหล่านั้นจะไปรวมกับของอีกหน้าจอหนึ่ง โดยเรียงหมายเลขต่อจากที่มีอยู่แล้ว และกลับไปใช้หมายเลขเดิมเมื่อจอภาพกลับมา

ถ้าคุณกด `Super` ค้างไว้และใช้เมาส์คลิกที่หน้าต่าง คุณจะสามารถจัดเรียงตำแหน่งของมันใหม่ได้ ถ้าคุณกด `Super` ค้างไว้และใช้ปุ่มขวาบนเมาส์ คุณสามารถปรับขนาดหน้าต่างได้อย่างอิสระ

คุณปิดหน้าต่างด้วย `Super + W` หรือ `Super + Q` (และปิดหน้าต่างทั้งหมดด้วย `Ctrl + Alt + Delete`)

คุณยังสามารถแสดงแบบเต็มหน้าจอด้วย `Super + F` หรือแม้แต่แค่เต็มความกว้าง (โดยยังคงแถบด้านบนไว้) ด้วย `Super + Alt + F` หรือเต็มหน้าจอภายในหน้าต่างด้วย `Super + Ctrl + F` (ดีสำหรับ YouTube!)

### เลย์เอาต์ dwindle เทียบกับ scrolling

เลย์เอาต์เริ่มต้นของ Omarchy เรียกว่า dwindle มันทำให้หน้าต่างทั้งหมดที่คุณเปิดบนเวิร์กสเปซเดียวมองเห็นได้ตลอดเวลา แม้จะต้องย่อขนาดลงก็ตาม

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

แต่คุณยังสามารถเลือกเปลี่ยนเวิร์กสเปซให้เป็นเลย์เอาต์แบบ scrolling ได้ ซึ่งหน้าต่างจะเรียงกันอยู่ข้าง ๆ กัน เกินขอบที่มองเห็นได้ของจอแสดงผล คุณเปลี่ยนเวิร์กสเปซเดียวให้เป็นเลย์เอาต์นี้ได้ผ่าน `Super + L`

การกด `Super + L` อีกครั้งจะเปลี่ยนเวิร์กสเปซเป็นแบบลอย ซึ่งหน้าต่างจะซ้อนทับกันได้อย่างอิสระและคุณวางตำแหน่งเอง และการกดครั้งที่สามจะกลับไปเป็น dwindle `Super + Alt + L` จะวนไปตามแบบต่าง ๆ ในทิศทางตรงกันข้าม หน้าต่างที่ลอยอยู่แล้ว — หน้าต่างที่คุณดึงออกมาด้วย `Super + T` หรือแอปที่เปิดแบบลอยเสมอ — จะยังคงลอยอยู่เมื่อเวิร์กสเปซกลับไปเป็นแบบไทล์ แถบด้านบนจะทำเครื่องหมายเวิร์กสเปซที่คุณอยู่ด้วยเลย์เอาต์ของมัน: สี่เหลี่ยมจัตุรัสสำหรับ dwindle วงกลมสำหรับ scrolling และสามเหลี่ยมสำหรับแบบลอย การคลิกเครื่องหมายนั้นก็วนเปลี่ยนเลย์เอาต์ได้เช่นกัน และปุ่มแสดงผลบนแล็ปท็อปที่มีปุ่มนั้นก็ทำได้เช่นกัน

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

ตัวเลือกนี้เป็นแบบต่อเวิร์กสเปซ และจะคงอยู่ ดังนั้นคุณสามารถให้เวิร์กสเปซ 1 เป็น dwindle สำหรับการท่องเว็บและเวิร์กสเปซ 2 เป็น scrolling สำหรับโค้ดได้ และมันจะกลับมาเป็นแบบนั้นหลังจากรีสตาร์ท

ถ้าคุณต้องการใช้เลย์เอาต์แบบ scrolling เป็นค่าเริ่มต้น คุณสามารถตั้งค่าได้ใน `~/.config/hypr/looknfeel.lua`:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### เวิร์กสเปซแบบลอย

เวิร์กสเปซแบบลอยทำงานเหมือนเดสก์ท็อปแบบดั้งเดิม: หน้าต่างซ้อนทับกัน และคุณย้ายและปรับขนาดเอง แต่ละหน้าต่างจะมีแถบชื่อในสีของธีมของคุณ พร้อมปุ่มสำหรับย่อ ขยาย และปิด `Super + M` ก็ย่อหน้าต่างที่โฟกัสอยู่ได้เช่นกัน หน้าต่างที่ย่อแล้วจะรออยู่ใน dock; คลิกแอปของมันเพื่อนำกลับมา คลิกหน้าต่างเพื่อนำมาข้างหน้า ปรับขนาดได้จากขอบหรือมุมใดก็ได้ ดับเบิลคลิกแถบชื่อเพื่อขยายหน้าต่างในขณะที่ยังคงมองเห็นแถบด้านบนไว้ และดับเบิลคลิกอีกครั้งเพื่อเอาขนาดเดิมกลับมา Chrome และเบราว์เซอร์อื่น ๆ ที่ใช้ Chromium เป็นพื้นฐาน รวมทั้ง Disks และ Document Viewer จะข้ามแถบชื่อและใช้ส่วนหัวของตัวเองแทน; `Super + Alt + F` ขยายหน้าต่างเหล่านั้น และ `Super + M` ย่อหน้าต่างเหล่านั้น

เวิร์กสเปซแบบลอยยังแสดง dock ด้วย โดยมีแอปที่ปักหมุดไว้ ทุกอย่างที่กำลังทำงานอยู่ และตารางของทุกแอปที่อยู่หลังปุ่มแอป ซึ่ง `Super + Alt + Space` และ _Apps_ ใน Omarchy menu ก็เปิดได้เช่นกัน คลิกขวาที่แอปบนตาราง หรือกด `Delete` เพื่อถอนการติดตั้ง คลิกแอปเพื่อเปิด หรือเพื่อนำหน้าต่างของมันมาข้างหน้า; คลิกอีกครั้งเพื่อวนไปตามหน้าต่างของมัน Files จะนำกลับมาเฉพาะหน้าต่างจากเวิร์กสเปซที่คุณอยู่เท่านั้น และมิฉะนั้นจะเปิดหน้าต่างใหม่ และ Terminal และ Agent จะเริ่มอีกหน้าต่างหนึ่งเสมอ แม้ว่าหน้าต่างที่ย่ออยู่จะกลับมาก่อน คลิกกลางจะเปิดหน้าต่างใหม่ ลากไอคอนไปตาม dock เพื่อย้าย; การลากแอปที่กำลังทำงานอยู่เข้าไปปะปนกับแอปอื่น ๆ จะทำให้มันอยู่ที่นั่น คลิกขวาเพื่อเก็บแอปไว้ใน dock เอาออก หรือออก จากแอปนั้น dock จะหลบออกไปให้หน้าต่างเต็มหน้าจอ คลิกขวาที่ปุ่มแอปเพื่อย้าย dock ไปยังขอบอื่นหรือให้มันซ่อนจนกว่าตัวชี้จะไปถึงขอบของมัน ตำแหน่งยังอยู่ภายใต้ _Appearance > Dock > Dock Position_ และ `omarchy dock position left` และ `omarchy dock autohide on` ตั้งค่าทั้งสองอย่างจากเทอร์มินัลได้ แอปที่คุณเก็บไว้ใน dock จะจางลงในขณะที่ไม่ได้กำลังทำงานอยู่

เวิร์กสเปซใหม่ และเวิร์กสเปซใด ๆ ที่คุณไม่ได้กำหนดเลย์เอาต์ของตัวเองด้วย `Super + L` จะใช้เลย์เอาต์เริ่มต้น การเปลี่ยนค่าเริ่มต้นจะรีเซ็ตทุกเวิร์กสเปซที่ไม่มีหน้าต่างให้เป็นแบบนั้น ในขณะที่เวิร์กสเปซที่มีหน้าต่างอยู่จะรักษาเลย์เอาต์ที่มีอยู่ไว้ หน้าต่างที่ย่อไปยัง dock ยังคงนับเป็นหน้าต่างบนเวิร์กสเปซที่มันจากมา เลือกได้ภายใต้ _Appearance > Workspace Layout_: Tiling, Scrolling หรือ Floating `omarchy hyprland workspace layout default scrolling` ตั้งค่าจากเทอร์มินัลได้

### การจัดกลุ่มหน้าต่าง

หน้าต่างสามารถจัดกลุ่มได้โดยใช้ `Super + G` เมื่อคุณอยู่ในกลุ่มแล้ว ทุกหน้าต่างที่คุณเริ่มทำงานในขณะที่กลุ่มนั้นใช้งานอยู่จะอยู่ในกลุ่มนั้น คุณสามารถย้ายไปมาระหว่างหน้าต่างที่จัดกลุ่มเหล่านี้ได้โดยใช้ `Super + Ctrl + Arrow Left/Right` หรือ `Super + Alt + 1/2/3/4` เพื่อไปยังหน้าต่างที่จัดกลุ่มตามลำดับโดยตรง

คุณสามารถย้ายหน้าต่างออกจากกลุ่มได้ด้วย `Super + Alt + G` หรือแยกกลุ่มทั้งหมดได้โดยการกด `Super + G` อีกครั้ง สุดท้าย คุณสามารถย้ายหน้าต่างที่อยู่นอกกลุ่มเข้าไปในกลุ่มได้ด้วย `Super + Alt + Arrows`

### การดึงหน้าต่างออก

คุณสามารถดึงหน้าต่างออกจากการจัดสรรเวิร์กสเปซของมันได้ด้วย `Super + O` นั่นจะปักหมุดมันเป็นหน้าต่างลอยที่ตามคุณไปไม่ว่าคุณจะไปยังเวิร์กสเปซใด ดีมากสำหรับเครื่องเล่นวิดีโอและสิ่งที่คล้ายกัน

 ![navigation-popped-window](images/navigation-popped-window.webp)

### เวิร์กสเปซ scratchpad

มีเวิร์กสเปซ scratchpad ขนาดเต็มแบบพิเศษที่ซ้อนทับเหนือเวิร์กสเปซใดก็ตามที่คุณกำลังอยู่ คุณเข้าถึงสิ่งที่อยู่บนนั้นได้โดยใช้ `Super + S` และคุณวางหน้าต่างไว้ที่นั่นโดยใช้ `Super + Alt + S`

มันทำงานได้ดีสำหรับส่วนควบคุมหรือเทอร์มินัลที่คุณต้องการโต้ตอบด้วยอย่างรวดเร็วโดยไม่ต้องออกจากเวิร์กสเปซปัจจุบัน

### คอนโซล Quake

สุดท้าย มีคอนโซล Quake ความสูงครึ่งหนึ่งที่เลื่อนลงมาเหนือเวิร์กสเปซใดก็ตามที่คุณกำลังอยู่ สลับเปิดปิดได้ด้วย `Super + Grave` และวางหน้าต่างไว้ที่นั่นโดยใช้ `Super + Shift + Grave`

ครั้งแรกที่มันเปิด มันจะเริ่ม agent เริ่มต้นของคุณ หรือขอให้คุณเลือกหนึ่งตัวหากคุณยังไม่ได้เลือก ในขณะที่คอนโซลมีหน้าต่างเพียงหน้าต่างเดียว มันจะเลื่อนลงมาเป็นแผงที่อยู่กึ่งกลางแทนที่จะทอดยาวเต็มหน้าจอ วางแอปตัวที่สองลงบนมันแล้วมันจะกลับไปเป็นความกว้างเต็ม เพื่อให้ทั้งสองมีพื้นที่วางข้างกันได้

หากต้องการย้ายหน้าต่างออกจาก scratchpad หรือคอนโซล ให้ส่งมันไปยังเวิร์กสเปซอื่นโดยตรงด้วยอะไรอย่างเช่น `Super + Shift + 1`

### ต้องใช้เวลาทำความคุ้นเคยสักหน่อย!

ต้องใช้เวลาสักพักในการทำความคุ้นเคยกับการนำทางเดสก์ท็อปของคุณแบบนี้ แต่เมื่อคุณคุ้นเคยแล้ว จะยากที่จะกลับไปสู่ประสบการณ์เดสก์ท็อปแบบดั้งเดิมที่ขับเคลื่อนด้วยเมาส์!
