# การนำทาง

ทุกอย่างใน Omarchy เกิดขึ้นผ่านคีย์บอร์ด — _ทุกอย่าง!_ เมื่อระบบเริ่มทำงานครั้งแรก คุณแทบทำอะไรด้วยเมาส์เพียงอย่างเดียวไม่ได้เลย แต่คุณกด `Super + Space` เพื่อเปิด Omarchy Menu ได้ และจากตรงนั้นคุณทำได้แทบทุกอย่าง

แต่ Omarchy menu ไม่ได้ตั้งใจให้เป็นวิธีหลักในการใช้งานระบบเป็นส่วนใหญ่ด้วยซ้ำ เราเร็วกว่านั้นได้! แอปพลิเคชันสำคัญที่สุดทั้งหมดผูกตรงกับปุ่มลัดแยกกัน คุณเปิดเทอร์มินัลด้วย `Super + Return` และเบราว์เซอร์ด้วย `Super + Shift + Return` ลองทำอันหนึ่งแล้วต่อด้วยอีกอัน แล้วคุณจะเห็นเวทมนตร์ของการจัดเรียงแบบ tiling ของ Hyprland ทำงาน:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

จากนั้นคุณกด `Super + J` เพื่อวางพวกมันซ้อนกันแทนที่จะอยู่เคียงข้างกัน:

 ![navigation-stacked](images/navigation-stacked.webp)

กด `Super + J` อีกครั้งเพื่อกลับไปอยู่เคียงข้างกัน จากนั้นลอง `Super + Shift + Arrow Right` ขณะอยู่ในเบราว์เซอร์เพื่อสลับหน้าต่าง

ตอนนี้ลอง `Super + Shift + T` เพื่อเริ่ม Activity monitor มันจะปรากฏเป็นหน้าต่างลอย พร้อมแถบชื่อเรื่องให้ลาก และปุ่มสำหรับย่อ ขยาย และปิด หน้าต่างลอยทุกบานจะมีแถบแบบนี้ ไม่ว่ามันจะอยู่ที่ไหน คุณจัดเรียงมันแบบ tiling ได้ด้วย `Super + T` (และกดอีกครั้งเพื่อทำให้มันลอยอีกครั้ง) ตอนนี้กด `Super + Shift + F` เพื่อเปิดตัวจัดการไฟล์ คุณจะได้การจัดวางสี่ช่องอย่างสวยงาม:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

คุณนำทางระหว่างหน้าต่างที่คุณต้องการให้ใช้งานอยู่ด้วย `Super + Arrow` การทำเช่นนี้จะสลับโฟกัสและย้ายเคอร์เซอร์ไปตรงกลางของแอปพลิเคชันใหม่ ที่ขอบหน้าจอ มันจะต่อไปยังจอภาพด้านนั้น

หากคุณกด `Super + Shift + 2` คุณจะย้ายแอปพลิเคชันที่โฟกัสอยู่ปัจจุบันไปยังพื้นที่ทำงานที่สอง `Super + Shift + 1` จะย้ายมันกลับ (และ `Super + Shift + Alt + 2` จะย้ายแอปพลิเคชันที่โฟกัสอยู่ปัจจุบันไปยังพื้นที่ทำงานที่สองโดยไม่สลับไปที่นั่น)

เมื่อมีหลายจอภาพ แต่ละจอภาพจะมีพื้นที่ทำงาน 1 ถึง 10 ของตัวเอง `Super + 2` ไปยังพื้นที่ทำงานที่สองของจอภาพที่คุณอยู่ และแถบด้านบนของแต่ละจอภาพจะแสดงพื้นที่ทำงานของตัวเองและพื้นที่ทำงานที่กำลังแสดงอยู่ `Super + Tab` วนผ่านพื้นที่ทำงานบนจอภาพที่คุณอยู่ `Super + Shift + Ctrl + Arrows` ย้ายหน้าต่างที่คุณอยู่ไปยังจอภาพในทิศทางนั้น ไปยังพื้นที่ทำงานที่จอนั้นกำลังแสดง และ `Super + Shift + Alt + Arrows` ย้ายพื้นที่ทำงานที่คุณอยู่ไปยังจอภาพในทิศทางนั้น โดยจะใช้หมายเลขเดิมหากว่างอยู่ จอภาพจะเก็บพื้นที่ทำงานของมันไว้เมื่อคุณถอดปลั๊ก: พื้นที่ทำงานเหล่านั้นจะไปรวมกับหน้าจออื่น โดยมีหมายเลขต่อจากที่มีอยู่แล้ว และกลับไปใช้หมายเลขเดิมเมื่อจอภาพกลับมา

หากคุณกด `Super` ค้างไว้และใช้เมาส์คลิกที่หน้าต่าง คุณจะสามารถจัดเรียงตำแหน่งของมันได้ หากคุณกด `Super` ค้างไว้และใช้ปุ่มขวาของเมาส์ คุณสามารถปรับขนาดหน้าต่างได้อย่างอิสระ

คุณปิดหน้าต่างด้วย `Super + W` หรือ `Super + Q` (และปิดหน้าต่างทั้งหมดด้วย `Ctrl + Alt + Delete`)

คุณยังสามารถแสดงเต็มหน้าจอด้วย `Super + F` หรือแค่เต็มความกว้าง (โดยยังเก็บแถบด้านบนไว้) ด้วย `Super + Alt + F` หรือเต็มหน้าจอภายในหน้าต่างด้วย `Super + Ctrl + F` (เหมาะสำหรับ YouTube!)

### เลย์เอาต์ dwindle เทียบกับ scrolling

เลย์เอาต์เริ่มต้นของ Omarchy เรียกว่า dwindle มันทำให้หน้าต่างทั้งหมดที่คุณเปิดบนพื้นที่ทำงานเดียวมองเห็นได้ตลอดเวลา แม้จะต้องย่อขนาดพวกมันลงก็ตาม

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

แต่คุณยังสามารถเลือกเปลี่ยนพื้นที่ทำงานให้เป็นเลย์เอาต์ scrolling ซึ่งหน้าต่างจะเรียงกันเคียงข้างกันเลยขอบที่มองเห็นของจอแสดงผลได้ คุณเปลี่ยนพื้นที่ทำงานเดียวให้เป็นเลย์เอาต์นี้ด้วย `Super + L`

การกด `Super + L` อีกครั้งจะเปลี่ยนพื้นที่ทำงานให้เป็นแบบลอย ซึ่งหน้าต่างจะซ้อนทับกันได้อย่างอิสระและคุณวางตำแหน่งเอง และการกดครั้งที่สามจะกลับไปเป็น dwindle `Super + Alt + L` จะไล่ไปในทิศทางตรงกันข้าม หน้าต่างที่ลอยอยู่แล้ว — หน้าต่างที่คุณแยกออกมาด้วย `Super + T` หรือแอปที่เปิดแบบลอยเสมอ — จะยังคงลอยอยู่เมื่อพื้นที่ทำงานกลับไปเป็นแบบ tiling แถบด้านบนจะทำเครื่องหมายพื้นที่ทำงานที่คุณอยู่ด้วยเลย์เอาต์ของมัน: สี่เหลี่ยมจัตุรัสสำหรับ dwindle วงกลมสำหรับ scrolling และสามเหลี่ยมสำหรับแบบลอย การคลิกเครื่องหมายนั้นก็วนเปลี่ยนเลย์เอาต์ได้เช่นกัน และปุ่มแสดงผลบนแล็ปท็อปที่มีปุ่มนั้นก็ทำได้เช่นกัน

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

ตัวเลือกนี้กำหนดแยกตามพื้นที่ทำงาน และจะคงอยู่ ดังนั้นคุณสามารถให้พื้นที่ทำงาน 1 ใช้ dwindle สำหรับการท่องเว็บ และพื้นที่ทำงาน 2 ใช้ scrolling สำหรับเขียนโค้ด และพวกมันจะกลับมาเป็นแบบนั้นหลังจากรีสตาร์ท

หากคุณต้องการใช้เลย์เอาต์ scrolling เป็นค่าเริ่มต้น คุณสามารถตั้งค่าได้ใน `~/.config/hypr/looknfeel.lua`:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### พื้นที่ทำงานแบบลอย

พื้นที่ทำงานแบบลอยทำงานเหมือนเดสก์ท็อปดั้งเดิม: หน้าต่างซ้อนทับกัน และคุณย้ายและปรับขนาดเอง หน้าต่างแต่ละบานจะมีแถบชื่อเรื่องในสีของธีมของคุณ พร้อมปุ่มสำหรับย่อ ขยาย และปิด `Super + M` ก็ย่อหน้าต่างที่โฟกัสอยู่เช่นกัน หน้าต่างที่ย่อแล้วจะรออยู่ใน dock; คลิกแอปของมันเพื่อนำกลับมา คลิกหน้าต่างเพื่อนำมาข้างหน้า ปรับขนาดมันจากขอบหรือมุมใดก็ได้ ดับเบิลคลิกแถบชื่อเรื่องเพื่อขยายหน้าต่างขณะยังเห็นแถบด้านบน และทำอีกครั้งเพื่อกลับไปขนาดเดิม Chrome และเบราว์เซอร์อื่นที่ใช้ Chromium เป็นฐาน Disks และ Document Viewer จะข้ามแถบชื่อเรื่องและใช้ส่วนหัวของตัวเองแทน; `Super + Alt + F` จะขยายพวกมัน และ `Super + M` จะย่อพวกมัน

ทุกพื้นที่ทำงานจะมี dock พร้อมแอปที่คุณปักหมุดไว้ ทุกอย่างที่กำลังทำงานอยู่ และตารางของทุกแอปที่อยู่หลังปุ่มแอป ซึ่ง `Super + Alt + Space` และ _Apps_ ใน Omarchy menu ก็เปิดได้เช่นกัน คลิกขวาที่แอปบนตาราง หรือกด `Delete` เพื่อถอนการติดตั้ง คลิกแอปเพื่อเปิด หรือเพื่อนำหน้าต่างของมันมาข้างหน้า; คลิกอีกครั้งเพื่อวนผ่านหน้าต่างของมัน Files จะนำหน้าต่างกลับมาเฉพาะจากพื้นที่ทำงานที่คุณอยู่เท่านั้น และอย่างอื่นจะเปิดหน้าต่างใหม่ และ Terminal และ Agent จะเริ่มอีกอันเสมอ แม้ว่าหน้าต่างที่ย่อไว้จะกลับมาก่อน คลิกกลางเพื่อเปิดหน้าต่างใหม่ ลากไอคอนไปตาม dock เพื่อย้ายมัน; การลากแอปที่กำลังทำงานอยู่เข้าไปในกลุ่มอื่นจะเก็บมันไว้ที่นั่น คลิกขวาเพื่อเก็บแอปไว้ใน dock นำมันออก หรือออกจากแอป dock จะอยู่ให้เห็นขณะที่พื้นที่ทำงานว่าง และเมื่อพื้นที่ทำงานมีหน้าต่าง มันจะซ่อนจนกว่าตัวชี้จะไปถึงขอบของมัน หน้าต่างเต็มหน้าจอจะซ่อนมันทั้งหมด ลากปุ่มแอปไปยังขอบอื่นของหน้าจอเพื่อย้าย dock ไปที่นั่น คลิกขวาที่มันเพื่อเลือก _Position_ เพื่อเลือกขอบ และ _Layout_ เพื่อตั้งเลย์เอาต์เริ่มต้นเช่นเดียวกับที่ _Appearance > Workspace Layout_ ทำ ตำแหน่งยังอยู่ภายใต้ _Appearance > Dock > Dock Position_ และ `omarchy dock position left` จะตั้งค่าจากเทอร์มินัล แอปที่คุณเก็บไว้ใน dock จะจางลงขณะที่ไม่ได้ทำงานอยู่ หากต้องการเก็บ dock ไว้เฉพาะพื้นที่ทำงานแบบลอย ให้ใช้ _Appearance > Dock > Dock Only on Floating_ หรือ `omarchy dock tiling off`

พื้นที่ทำงานใหม่ และพื้นที่ทำงานใดที่คุณยังไม่ได้กำหนดเลย์เอาต์ของตัวเองด้วย `Super + L` จะใช้เลย์เอาต์เริ่มต้น การเปลี่ยนค่าเริ่มต้นจะรีเซ็ตทุกพื้นที่ทำงานที่ไม่มีหน้าต่างให้เป็นค่านั้น ขณะที่พื้นที่ทำงานที่มีหน้าต่างอยู่จะยังคงเลย์เอาต์ที่มีอยู่ หน้าต่างที่ย่อไปยัง dock ยังนับเป็นหน้าต่างบนพื้นที่ทำงานที่มันจากมา เลือกได้ภายใต้ _Appearance > Workspace Layout_: Tiling, Scrolling หรือ Floating `omarchy hyprland workspace layout default scrolling` จะตั้งค่าจากเทอร์มินัล

### การจัดกลุ่มหน้าต่าง

หน้าต่างสามารถจัดกลุ่มได้โดยใช้ `Super + G` เมื่อคุณอยู่ในกลุ่มแล้ว ทุกหน้าต่างที่คุณเริ่มขณะที่กลุ่มนั้นใช้งานอยู่จะเป็นของกลุ่มนั้น คุณสามารถย้ายระหว่างหน้าต่างที่จัดกลุ่มเหล่านี้ได้โดยใช้ `Super + Ctrl + Arrow Left/Right` หรือ `Super + Alt + 1/2/3/4` เพื่อไปยังหน้าต่างที่จัดกลุ่มตามลำดับโดยตรง

คุณสามารถย้ายหน้าต่างออกจากกลุ่มด้วย `Super + Alt + G` หรือแยกกลุ่มทั้งหมดโดยกด `Super + G` อีกครั้ง สุดท้าย คุณสามารถย้ายหน้าต่างนอกกลุ่มเข้าไปในกลุ่มด้วย `Super + Alt + Arrows`

### การแยกหน้าต่างออก

คุณสามารถแยกหน้าต่างออกจากการจัดสรรพื้นที่ทำงานของมันด้วย `Super + O` การทำเช่นนี้จะปักหมุดมันเป็นหน้าต่างลอยที่ตามคุณไปไม่ว่าคุณจะไปที่พื้นที่ทำงานใด เหมาะสำหรับเครื่องเล่นวิดีโอและสิ่งที่คล้ายกัน

 ![navigation-popped-window](images/navigation-popped-window.webp)

### พื้นที่ทำงาน scratchpad

มีพื้นที่ทำงาน scratchpad ขนาดเต็มพิเศษที่ซ้อนทับพื้นที่ทำงานใดก็ตามที่คุณอยู่ปัจจุบัน คุณเข้าถึงสิ่งที่อยู่บนมันด้วย `Super + S` และคุณวางหน้าต่างไว้ที่นั่นด้วย `Super + Alt + S`

มันเหมาะสำหรับส่วนควบคุมหรือเทอร์มินัลที่คุณต้องการโต้ตอบด้วยอย่างรวดเร็วโดยไม่ต้องออกจากพื้นที่ทำงานปัจจุบัน

### คอนโซล Quake

สุดท้าย มีคอนโซล Quake สูงครึ่งหนึ่งที่เลื่อนลงมาทับพื้นที่ทำงานใดก็ตามที่คุณอยู่ปัจจุบัน สลับเปิดปิดด้วย `Super + the key above Tab` (grave บนเลย์เอาต์ US) และวางหน้าต่างไว้ที่นั่นด้วย `Super + Shift + the key above Tab`

ครั้งแรกที่เปิด มันจะเริ่ม agent เริ่มต้นของคุณ หรือขอให้คุณเลือกอันหนึ่งหากคุณยังไม่ได้เลือก ขณะที่คอนโซลมีหน้าต่างเดียว มันจะเลื่อนลงมาเป็นแผงที่อยู่ตรงกลางแทนที่จะกางเต็มหน้าจอ ใส่อีกแอปเข้าไปที่มัน และมันจะกลับไปเต็มความกว้าง เพื่อให้ทั้งสองมีพื้นที่อยู่เคียงข้างกัน

หากต้องการย้ายหน้าต่างออกจาก scratchpad หรือคอนโซล ให้ส่งมันตรงไปยังพื้นที่ทำงานอื่นด้วยบางอย่างเช่น `Super + Shift + 1`

### ต้องใช้เวลาทำความคุ้นเคยสักหน่อย!

ต้องใช้เวลาสักหน่อยในการทำความคุ้นเคยกับการนำทางเดสก์ท็อปของคุณแบบนี้ แต่เมื่อคุณคุ้นเคยแล้ว มันจะยากที่จะกลับไปสู่ประสบการณ์เดสก์ท็อปแบบดั้งเดิมที่ขับเคลื่อนด้วยเมาส์!
