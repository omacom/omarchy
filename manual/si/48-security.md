# ආරක්ෂාව

Omarchy ආරක්ෂාව අතිශයින් බැරෑරුම් ලෙස සලකයි. මෙය _සැබෑ ලෝකයේ_ _සැබෑ වැඩ_ කිරීමට ඔබට භාවිත කළ හැකි මෙහෙයුම් පද්ධතියක් වීමට අදහස් කෙරේ. laptop එකක් නැතිවීම ආරක්ෂක හදිසි තත්ත්වයකට තුඩු දිය නොහැකි තැනකි. එබැවින් අප කරන්නේ මෙන්න මේවාය:

1. *පෙරනිමියෙන් සම්පූර්ණ තැටි සංකේතනය සක්‍රියයි*: ඔබේ දත්තවල භෞතික ආරක්ෂාව තහවුරු කිරීමේ වැදගත්ම පියවර මෙයයි. ඔබේ පරිගණකය නැති වුවහොත් හෝ සොරකම් කළහොත්, සම්මත LUKS (Linux Unified Key Setup) භාවිතයෙන් දත්ත සම්පූර්ණයෙන්ම සංකේතනය කර ඇත. ඉවත දැමිය හැකි යන්ත්‍ර සඳහා මෙය තෝරා නොගෙන සිටීමට ස්ථාපකය ඔබට ඉඩ දෙයි ([ආරම්භ කිරීම](02-getting-started.md) බලන්න); සංකේතනයකින් තොර ස්ථාපනයකට මෙම ආරක්ෂාවෙන් කිසිවක් නැත, තැටිය අතට ගන්නා ඕනෑම කෙනෙකුට එය කියවිය හැකිය.
2. *පෙරනිමියෙන් firewall එක සක්‍රියයි*: සියලුම ඇතුළු වන ගමනාගමනය පෙරනිමියෙන් අවහිර කර ඇත, ව්‍යතිරේක කිහිපයක් සහිතව: [LocalSend](https://localsend.org/) සඳහා port 53317; Docker විසින් එහි containers වලට ලබා දෙන පුද්ගලික ලිපින පරාසවලින් පිළිගන්නා, Docker bridge ලිපිනයේ (172.17.0.1) ඇති පරිගණකයේම resolver එක වෙත යොමු වන DNS විමසුම්; සහ මුද්‍රණ යන්ත්‍ර සහ ඔබේ ජාලයේ ඇති වෙනත් උපාංග එකිනෙක සොයා ගැනීමට ඉඩ දෙන, එහි ඔබේ පරිගණකයේ නම ද නිවේදනය කරන multicast DNS (port 5353). ඒවාට අමතරව, ping කිරීම, ඔබේ router එකෙන් ලිපිනයක් ලබා ගැනීම (DHCP), සහ UPnP සොයාගැනීම සඳහා UFW හි සම්මත අනුමැතීන් firewall එක රඳවා ගනී. ඔබ _Setup > Security > SSHD_ හරහා එය සක්‍රිය කරන තුරු ssh පවා අක්‍රියව පවතී, එමඟින් සැකසුම් ක්‍රියාවලියේ කොටසක් ලෙස port 22 විවෘත කරයි (brute force ප්‍රහාරවලට එරෙහිව අනුපාතය සීමා කර ඇත). ඔබේ containers අහම්බෙන් ලෝකයට නිරාවරණය වීම වැළැක්වීමට [ufw-docker](https://github.com/chaifeng/ufw-docker) සැකසුම භාවිතයෙන් අපි Docker ප්‍රවේශය පවා අගුලු දමමු.
3. *Arch සතුව සැමවිටම නවතම යාවත්කාලීන ඇත*: Omarchy ගොඩනගා ඇති පාදක distro එක වන Arch, rolling distribution එකකි. එනම් ඕනෑම package එකක සොයාගෙන පිළියම් කරන ලද ඕනෑම ආරක්ෂක දුර්වලතාවක් `omarchy-update` භාවිතයෙන් ස්ථාපනය සඳහා ඉක්මනින් ලබා ගත හැකිය. එමඟින් ඔබ සැමවිටම සියල්ලේම නවතම, වඩාත්ම ආරක්ෂිත අනුවාද ධාවනය කරයි.
4. *Omarchy එහිම packages සහ mirror එක පවත්වාගෙන යයි*: Omarchy පෙරනිමියෙන් රඳා පවතින්නේ Arch හිම core/extra/multilib repositories සහ එහිම Omarchy Package Repository වෙතින් ලැබෙන packages මත පමණි. ඔබට AUR වෙතින් කෙලින්ම software ස්ථාපනය කළ හැකිය, නමුත් පාදක ස්ථාපනය එසේ නොකරයි — තෙවන පාර්ශවීය browsers වැනි වෛකල්පික ස්ථාපන කිහිපයක් පමණක් AUR වෙතින් ලබා ගනී.
5. *Cloudflare අපව DDoS වලින් ආරක්ෂා කරයි*: Omarchy බෙදාහැරීමේ යටිතල පහසුකම් — ISOs, Omarchy packages, Arch mirror එක — Cloudflare හි බලවත් DDoS පලිහ පිටුපස ආරක්ෂා කර ඔවුන්ගේ CDN එකේ සත්කාරකත්වය දරයි. මෙය විශිෂ්ට ලබාගත හැකිබවක් සපයයි.

## ඔබේ මුරපද වෙනස් කිරීම

සංකේතනය කළ ස්ථාපනයක ඔබට මුරපද දෙකක් ඇත: boot කිරීමේදී තැටිය අගුලු හරින එක, සහ ඔබ පුරනය වී `sudo` සමඟ භාවිත කරන එක. Setup මඟින් ඒ දෙකම එක සමාන කරයි. Omarchy menu එකේ _Update > Password_ යටතේ ඒ දෙකම වෙනස් කළ හැකිය — පළමුවැන්න සඳහා _Drive Encryption_, දෙවැන්න සඳහා _User_. තැටියේ මුරපදය වෙනස් කිරීමේදී පළමුව වත්මන් එක ඉල්ලයි, එබැවින් එය ළඟ තබා ගන්න. වෙනස් කිරීමකට බාධා වුවහොත්, _Drive Encryption_ නැවත ධාවනය කරන්න: එය දැන් තැටිය අගුලු හරින මුරපදය ඉල්ලා වෙනස් කිරීම අවසන් කරයි.

## ඔබ දැනටමත් භාවිත කළ යන්ත්‍රයක් වෙනත් කෙනෙකුට භාර දීම

ඔබ ඔබේ යන්ත්‍රය වෙනත් කෙනෙකුට භාර දෙන්නේ නම්, එය නැවත ස්ථාපනය කිරීමට ඔබට අවශ්‍ය නැත. Omarchy menu එකේ _Remove > Factory Reset_ ධාවනය කර, තහවුරු කිරීමට `reset` ටයිප් කර, reboot කරන්න. එය සෑම user account එකක්ම සහ `/home` හි ඇති සියල්ලම මකා දමයි, ස්ථාපනයෙන් පසු ඔබ කළ සියලුම packages සහ පද්ධති වෙනස්කම් ඉවත දමයි, සහ යන්ත්‍රයේ අනන්‍යතාවය ඉවත් කරයි — network සම්බන්ධතා, host keys, සහ සියල්ලම. නැවත ආරම්භ වන්නේ පළමු boot එකේ setup wizard එකයි, එහි නව හිමිකරුට ඔවුන්ගේම නම, මුරපදය, සහ සංකේතන මුරපදය ඇතුළත් කිරීමට සූදානම්ව.

එය ක්‍රියා කරන්නේ ස්ථාපකය ගන්නා baseline snapshot එක ප්‍රතිස්ථාපනය කිරීමෙනි, එබැවින් එය ලබා ගත හැක්කේ Omarchy ISO එකෙන් ස්ථාපනය කළ යන්ත්‍රවල පමණි. සංකේතනයක් නැති තැටියක, reset එකක් යනු ආරක්ෂිතව මකා දැමීමක් නොව මකා දැමීමක් පමණි, එබැවින් දත්ත සංවේදී නම්, ඒ වෙනුවට අලුත් ස්ථාපනයක් කරන්න.

## මුරපද රහිත sudo

සමහර විට ඔබට `sudo` විමසීම නැවැත්වීමට අවශ්‍ය වේ, බොහෝ විට AI agent කෙනෙක් ඔබට දිගු කාලයක් පද්ධති වැඩ කරමින් සිටින විට. _Setup > Security > Passwordless Sudo_ ප්‍රවේශය කොපමණ කාලයක් ඉඩ දිය යුතු දැයි අසයි: **මිනිත්තු 15**, **පැය 1**, **දින 1**, හෝ **ස්ථිරවම**. ප්‍රවේශය සක්‍රියව තිබෙන අතරතුර අනෙකුත් menu bar දර්ශක අසල රතු අනතුරු ඇඟවීමේ නිරූපකයක් දිස් වේ. එය ක්ලික් කරන්න හෝ ප්‍රවේශය අක්‍රිය කිරීමට විධානය නැවත ධාවනය කරන්න. ඔබට ඔබේම මිනිත්තු ගණනක් (1 සිට 1440 දක්වා) `omarchy-sudo-passwordless 30` සමඟ යැවිය හැකිය, හෝ `omarchy-sudo-passwordless permanent` භාවිත කළ හැකිය.

කාලානුරූප ප්‍රවේශය ස්වයංක්‍රීයව කල් ඉකුත් වේ, නියමිත කාලය ඉක්මවා ගිය suspend එකකින් නැවත ආරම්භ කළ වහාම ද ඇතුළුව. පරිගණකය restart කිරීමෙන් එය කලින් අවසන් වේ. ස්ථිර ප්‍රවේශය reboots වලින් පසුව ද පවතින අතර ඔබ එය අක්‍රිය කරන තුරුම සක්‍රියව පවතී.

Omarchy හි settings package එක යාවත්කාලීන කිරීම හෝ ඉවත් කිරීම, එහි කල් ඉකුත් වීමේ සහාය වෙනස් වීමට පෙර ඕනෑම තාවකාලික ප්‍රදානයක් අවසන් කරයි. විධානය අවසර දීමේ හෝ පිරිසිදු කිරීමේ දෝෂයක් වාර්තා කරන්නේ නම්, තවත් ප්‍රදානයක් සක්‍රිය කිරීමට උත්සාහ කිරීමට පෙර එය විසඳන්න; දෝෂයක් යනු මුරපද රහිත ප්‍රවේශය අක්‍රිය බව නොවේ.

මේ ගැන පැහැදිලි ඇසින් බලන්න: එය සක්‍රියව තිබෙන අතර, ඔබේ user ලෙස ධාවනය වන ඕනෑම දෙයකට නොවිමසා root ලෙස ඕනෑම දෙයක් කළ හැකිය. එයම එහි මුළු අරමුණයි, එයම එහි මුළු අවදානම ද වේ.
