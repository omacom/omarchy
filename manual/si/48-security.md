# ආරක්ෂාව

Omarchy ආරක්ෂාව ඉතාම බැරෑරුම් ලෙස සලකයි. මෙය ඔබට _සැබෑ ලෝකයේ_ _සැබෑ වැඩ_ කිරීමට භාවිත කළ හැකි මෙහෙයුම් පද්ධතියක් වීමට අදහස් කෙරේ. ලැප්ටොප් එකක් අහිමි වීම ආරක්ෂක හදිසි අවස්ථාවකට මඟ පෑදිය නොහැකි තැනකි. එබැවින් අපි කරන්නේ මෙයයි:

1. *සම්පූර්ණ තැටි සංකේතනය පෙරනිමියෙන් ක්‍රියාත්මකයි*: ඔබේ දත්තවල භෞතික ආරක්ෂාව සුරක්ෂිත කිරීම සඳහා ඇති වැදගත්ම පියවර මෙයයි. ඔබේ පරිගණකය අහිමි වුවහොත් හෝ සොරකම් කරනු ලැබුවහොත්, සම්මත LUKS (Linux Unified Key Setup) භාවිතයෙන් දත්ත සම්පූර්ණයෙන්ම සංකේතනය කර ඇත. තාවකාලිකව භාවිත කර ඉවත දමන යන්ත්‍ර සඳහා ඉන් ඉවත් වීමට ස්ථාපකය ඔබට ඉඩ දෙයි (බලන්න [ආරම්භ කිරීම](02-getting-started.md)); සංකේතනයකින් තොරව ස්ථාපනයකට මෙම ආරක්ෂාව කිසිවක් නැත, තැටිය අතේ ඇති ඕනෑම කෙනෙකුට එය කියවිය හැකිය.
2. *ගිනි පවුර පෙරනිමියෙන් සක්‍රියයි*: ව්‍යතිරේක කිහිපයක් හැර, ඇතුළු වන සියලුම ගමනාගමනය පෙරනිමියෙන් අවහිර කෙරේ: [LocalSend](https://localsend.org/) සඳහා port 53317; Docker bridge ලිපිනයේ (172.17.0.1) ඇති පරිගණකයේම resolver වෙත DNS විමසීම්, Docker එහි containers වෙත ලබා දෙන පුද්ගලික ලිපින පරාසයන්ගෙන් පිළිගනු ලැබේ; සහ multicast DNS (port 5353), එය ඔබේ ජාලයේ මුද්‍රණ යන්ත්‍ර සහ වෙනත් උපාංග එකිනෙක සොයා ගැනීමට ඉඩ දෙන අතර ඔබේ පරිගණකයේ නමද එහි ප්‍රකාශයට පත් කරයි. මේවාට අමතරව, ping කිරීම, ඔබේ router වෙතින් ලිපිනයක් ලබා ගැනීම (DHCP) සහ UPnP discovery සඳහා UFW හි සම්මත අවසර ගිනි පවුර රඳවා ගනී. ඔබ _Setup > Security > SSHD_ හරහා එය සක්‍රිය කරන තුරු ssh පවා අක්‍රියයි, එය ඔබේ SSH යතුරට අවසර දෙයි, මුරපදයෙන් ඇතුළු වීම අක්‍රිය කරයි, ඉන් පසුව පමණක් port 22 විවෘත කරයි (brute force වලට එරෙහිව අනුපාතය සීමා කෙරේ). ඔබේ containers අහම්බෙන් ලෝකයට නිරාවරණය වීම වැළැක්වීම සඳහා [ufw-docker](https://github.com/chaifeng/ufw-docker) සැකසීම භාවිතයෙන් අපි Docker ප්‍රවේශය පවා අගුළු දමමු.
3. *Arch සතුව සැමවිටම නවතම යාවත්කාලීන ඇත*: Omarchy ගොඩනගා ඇති පාදක distro එක වන Arch යනු rolling distribution එකකි. මෙයින් අදහස් වන්නේ ඕනෑම පැකේජයක සොයාගෙන නිවැරදි කරනු ලබන ඕනෑම ආරක්ෂක දුර්වලතාවයක් `omarchy-update` භාවිතයෙන් ස්ථාපනය කිරීම සඳහා ඉක්මනින් ලබා ගත හැකි බවයි. එමඟින් ඔබ සැමවිටම සියල්ලේම නවතම, වඩාත්ම ආරක්ෂිත අනුවාද ධාවනය කරයි.
4. *Omarchy එහිම පැකේජ සහ mirror එකක් නඩත්තු කරයි*: Omarchy පෙරනිමියෙන් විශ්වාසය තබන්නේ Arch හිම core/extra/multilib repositories (ARM යන්ත්‍රවල Arch Linux ARM හි, Apple Silicon මත Asahi ALARM ද සමඟ) සහ එහිම Omarchy Package Repository වෙතින් ලැබෙන පැකේජ මත පමණි. ඔබට AUR වෙතින් කෙලින්ම මෘදුකාංග ස්ථාපනය කළ හැකිය, නමුත් පාදක ස්ථාපනය එසේ නොකරයි — තෙවන පාර්ශවීය browsers වැනි විකල්ප ස්ථාපන කිහිපයක් පමණක් AUR වෙතින් ලබා ගනී.
5. *Cloudflare අපව DDoS වලින් ආරක්ෂා කරයි*: Omarchy බෙදාහැරීමේ යටිතල පහසුකම් — ISOs, Omarchy පැකේජ, Arch mirror එක — Cloudflare හි ප්‍රබල DDoS පලිහ පිටුපස ආරක්ෂා කර ඇති අතර ඔවුන්ගේ CDN එකේ සත්කාරකත්වය ලබයි. මෙය අතිවිශිෂ්ට ලබාගත හැකිබවක් සපයයි.

## ඔබේ මුරපද වෙනස් කිරීම

සංකේතනය කළ ස්ථාපනයක ඔබට මුරපද දෙකක් ඇත: boot වීමේදී තැටිය අගුළු හරින එක, සහ ඔබ ඇතුළු වීමට සහ `sudo` සමඟ භාවිත කරන එක. Setup මඟින් ඒවා එකම මුරපදය බවට පත් කරයි. දෙකම Omarchy menu එකේ _Update > Password_ යටතේ වෙනස් කළ හැකිය — පළමුවැන්න සඳහා _Drive Encryption_, දෙවැන්න සඳහා _User_. තැටියේ මුරපදය වෙනස් කිරීමේදී පළමුව වත්මන් මුරපදය ඉල්ලයි, එබැවින් එය ළඟ තබා ගන්න. වෙනසක් අතරමඟ නතර වුවහොත්, නැවත _Drive Encryption_ ධාවනය කරන්න: එය දැන් තැටිය අගුළු හරින මුරපදය ඉල්ලන අතර වෙනස අවසන් කරයි.

## ඔබ දැනටමත් භාවිත කළ යන්ත්‍රයක් වෙනත් කෙනෙකුට භාර දීම

ඔබ ඔබේ යන්ත්‍රය වෙනත් කෙනෙකුට භාර දෙනවා නම්, එය නැවත ස්ථාපනය කිරීමට ඔබට සිදු නොවේ. Omarchy menu එකේ _Remove > Factory Reset_ ධාවනය කරන්න, තහවුරු කිරීමට `reset` type කරන්න, ඇසුවහොත් ඔබේ තැටි සංකේතන මුරපදය ඇතුළු කරන්න, සහ reboot කරන්න. එය සෑම user account එකක්ම සහ `/home` හි ඇති සියල්ලම මකා දමයි, ස්ථාපනයෙන් පසු ඔබ කළ සියලුම පැකේජ සහ system වෙනස්කම් ඉවත දමයි, සහ යන්ත්‍රයේ අනන්‍යතාවය ඉවත් කරයි — ජාල සම්බන්ධතා, host keys සහ සියල්ල. නැවත ආරම්භ වන්නේ පළමු boot එකේ setup wizard එකයි, එහි නව හිමිකරුට ඔවුන්ගේම නම, මුරපදය සහ සංකේතන මුරපදය ඇතුළු කිරීමට සූදානම්ව ඇත.

එය ක්‍රියා කරන්නේ ස්ථාපකය ගන්නා baseline snapshot එක ප්‍රතිස්ථාපනය කිරීමෙනි, එබැවින් එය ලබා ගත හැක්කේ Omarchy ISO එකෙන් ස්ථාපනය කළ යන්ත්‍රවල පමණි. සංකේතනයක් නොමැති තැටියක, reset කිරීමක් යනු ආරක්ෂිතව මකා දැමීමක් නොව මකා දැමීමක් පමණි, එබැවින් දත්ත සංවේදී නම්, ඒ වෙනුවට අලුත් ස්ථාපනයක් කරන්න.

## මුරපද රහිත sudo

සමහර විට ඔබට `sudo` විමසීම නැවැත්වීමට අවශ්‍ය වේ, බොහෝ විට AI agent කෙනෙක් ඔබ වෙනුවෙන් දිගු කාලයක් system වැඩ කරමින් සිටින විට. _Setup > Security > Passwordless Sudo_ මඟින් කොපමණ කාලයක් ප්‍රවේශය ඉඩ දිය යුතුදැයි අසයි: **විනාඩි 15**, **පැය 1**, **දින 1**, හෝ **ස්ථිරවම**. ප්‍රවේශය සක්‍රියව තිබෙන අතරතුර අනෙකුත් menu bar දර්ශක අසල රතු අනතුරු ඇඟවීමේ නිරූපකයක් දිස් වේ. එය click කරන්න හෝ ප්‍රවේශය අක්‍රිය කිරීමට විධානය නැවත ධාවනය කරන්න. ඔබට `omarchy-sudo-passwordless 30` සමඟ ඔබේම විනාඩි ගණනක් (1 සිට 1440 දක්වා) ලබා දිය හැකිය, හෝ `omarchy-sudo-passwordless permanent` භාවිත කළ හැකිය.

කාලසීමා සහිත ප්‍රවේශය ස්වයංක්‍රීයව කල් ඉකුත් වේ, අවසන් දිනය පසු කර ගිය suspend එකකින් නැවත ආරම්භ කළ වහාම ඇතුළුව. පරිගණකය නැවත ආරම්භ කිරීම එය කලින් අවසන් කරයි. ස්ථිර ප්‍රවේශය reboots වලින් පසුවද පවතින අතර ඔබ එය අක්‍රිය කරන තුරු සක්‍රියව පවතී.

Omarchy හි settings පැකේජය යාවත්කාලීන කිරීම හෝ ඉවත් කිරීම එහි කල් ඉකුත්වීමේ සහාය වෙනස් වීමට පෙර ඕනෑම තාවකාලික අවසරයක් අවසන් කරයි. විධානය authorization හෝ cleanup දෝෂයක් වාර්තා කරන්නේ නම්, තවත් අවසරයක් සක්‍රිය කිරීමට උත්සාහ කිරීමට පෙර එය විසඳන්න; දෝෂයක් යනු මුරපද රහිත ප්‍රවේශය අක්‍රිය බව නොවේ.

මේ ගැන පැහැදිලි ඇසින් බලන්න: එය ක්‍රියාත්මකව තිබෙන අතරතුර, ඔබේ user ලෙස ධාවනය වන ඕනෑම දෙයකට විමසීමකින් තොරව root ලෙස ඕනෑම දෙයක් කළ හැකිය. එයම තමයි මුළු අරමුණම, එයම තමයි මුළු අවදානමත්.
