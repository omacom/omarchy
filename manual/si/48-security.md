# ආරක්ෂාව

Omarchy ආරක්ෂාව අතිශය බැරෑරුම් ලෙස සලකයි. මෙය _සැබෑ ලෝකය_ තුළ _සැබෑ වැඩ_ කිරීමට ඔබට භාවිත කළ හැකි මෙහෙයුම් පද්ධතියක් වීමට අදහස් කෙරේ. ලැප්ටොප් එකක් නැතිවීම ආරක්ෂක හදිසි අවස්ථාවකට හේතු විය නොහැකි තැනක. ඉතින් අපි කරන්නේ මෙයයි:

1. *සම්පූර්ණ තැටි සංකේතනය පෙරනිමියෙන් ක්‍රියාත්මකයි*: ඔබේ දත්තවල භෞතික ආරක්ෂාව සුරක්ෂිත කිරීමේ වැදගත්ම පියවර මෙයයි. ඔබේ පරිගණකය නැති වුවහොත් හෝ සොරකම් කළහොත්, සම්මත LUKS (Linux Unified Key Setup) භාවිතයෙන් දත්ත සම්පූර්ණයෙන්ම සංකේතනය කර ඇත. ඉවත දමන යන්ත්‍ර සඳහා ඉවත් වීමට ස්ථාපකය ඔබට ඉඩ දෙයි ([ආරම්භ කිරීම](02-getting-started.md) බලන්න); සංකේතනය නොමැතිව ස්ථාපනය කළහොත් මෙම ආරක්ෂාවෙන් කිසිවක් නැත, තැටිය අතැති ඕනෑම කෙනෙකුට එය කියවිය හැකිය.
2. *ෆයර්වෝලය පෙරනිමියෙන් සක්‍රීය කර ඇත*: ව්‍යතිරේක කිහිපයක් හැර, ඇතුළු වන සියලුම ගමනාගමනය පෙරනිමියෙන් අවහිර කර ඇත: [LocalSend](https://localsend.org/) සඳහා 53317 වරාය; Docker එහි බහාලුම්වලට ලබා දෙන පුද්ගලික ලිපින පරාසවලින් පිළිගන්නා, Docker පාලම් ලිපිනයේ (172.17.0.1) ඇති පරිගණකයේම විසඳුම්කරු වෙත යොමු වන DNS විමසුම්; සහ ඔබේ ජාලයේ ඇති මුද්‍රණ යන්ත්‍ර සහ වෙනත් උපාංගවලට එකිනෙකා සොයා ගැනීමට ඉඩ දෙන අතර ඔබේ පරිගණකයේ නමද එහි ප්‍රකාශයට පත් කරන multicast DNS (5353 වරාය). ඒවාට අමතරව, ෆයර්වෝලය ping කිරීම, ඔබේ රවුටරයෙන් ලිපිනයක් ලබා ගැනීම (DHCP), සහ UPnP සොයා ගැනීම සඳහා UFW හි සම්මත අවසරයන් රඳවා ගනී. ඔබ _සැකසීම > ආරක්ෂාව > SSHD_ හරහා එය ක්‍රියාත්මක කරන තුරු ssh පවා අක්‍රීයයි, එය ඔබේ SSH යතුරට අවසර දෙයි, මුරපද පිවිසුම් අක්‍රීය කරයි, ඉන් පසුව පමණක් 22 වරාය විවෘත කරයි (අනුමානකාරී බලහත්කාර ප්‍රහාරවලට එරෙහිව අනුපාතය සීමා කර ඇත). ඔබේ බහාලුම් අහම්බෙන් ලෝකයට නිරාවරණය වීම වැළැක්වීමට [ufw-docker](https://github.com/chaifeng/ufw-docker) සැකසුම භාවිතයෙන් අපි Docker ප්‍රවේශය පවා අගුලු දමන්නෙමු.
3. *Arch සතුව සෑම විටම නවතම යාවත්කාලීනයන් ඇත*: Omarchy ගොඩනගා ඇති යටින් පවතින distro එක වන Arch යනු rolling distribution එකකි. මෙයින් අදහස් වන්නේ ඕනෑම පැකේජයක සොයා ගෙන නිවැරදි කරන ඕනෑම ආරක්ෂක දුර්වලතාවක් `omarchy-update` භාවිතයෙන් ස්ථාපනය කිරීමට ඉක්මනින් ලබා ගත හැකි බවයි. ඒ ආකාරයට ඔබ සැමවිටම සියල්ලෙහිම නවතම, වඩාත්ම ආරක්ෂිත අනුවාදයන් ධාවනය කරයි.
4. *Omarchy එහිම පැකේජ සහ මිරරය පවත්වාගෙන යයි*: Omarchy පෙරනිමියෙන් රඳා පවතින්නේ Arch හිම core/extra/multilib ගබඩාවලින් ලැබෙන පැකේජ (ARM යන්ත්‍රවල Arch Linux ARM, ඊට අමතරව Apple Silicon මත Asahi ALARM) සහ එහිම Omarchy Package Repository මත පමණි. ඔබට AUR වෙතින් කෙලින්ම මෘදුකාංග ස්ථාපනය කළ හැකි නමුත් මූලික ස්ථාපනය එය නොකරයි — තෙවන පාර්ශවීය බ්‍රවුසර වැනි විකල්ප ස්ථාපනයන් කිහිපයක් පමණක් AUR වෙතින් ලබා ගනී.
5. *Cloudflare අපව DDoS වලින් ආරක්ෂා කරයි*: Omarchy බෙදාහැරීමේ යටිතල පහසුකම් — ISO, Omarchy පැකේජ, Arch මිරරය — Cloudflare හි ප්‍රබල DDoS පලිහ පිටුපස ආරක්ෂා කර ඔවුන්ගේ CDN මත තබා ඇත. මෙය විශිෂ්ට ලබාගත හැකිබවක් සපයයි.

## ඔබේ මුරපද වෙනස් කිරීම

සංකේතනය කළ ස්ථාපනයක ඔබ සතුව මුරපද දෙකක් ඇත: ආරම්භයේදී තැටිය අගුළු හරින එක, සහ ඔබ පිවිසීමට සහ `sudo` සමඟ භාවිත කරන එක. සැකසීම ඒවා එක සමාන කරයි. Omarchy මෙනුවේ _යාවත්කාලීනය > මුරපදය_ දෙකම එකවර වෙනස් කරයි, එබැවින් ඒවා එක සමානව පවතී: එය වත්මන් තැටි මුරපදය ඉල්ලා සිටී, ඉන්පසු නව එක, තැටියේ එක වෙනස් කර ඉන්පසු ගැලපෙන පරිදි ඔබේ පිවිසුම් මුරපදය සකසයි. තැටි සංකේතනය නොමැතිව එය වෙනස් කරන්නේ ඔබේ පිවිසුම් මුරපදය පමණි. වෙනස් කිරීමකට බාධා වුවහොත්, _යාවත්කාලීනය > මුරපදය_ නැවත ධාවනය කරන්න: එය දැන් තැටිය අගුළු හරින මුරපදය ඉල්ලා සිටී, වෙනස් කිරීම අවසන් කරයි, සහ ඔබේ පිවිසුම් මුරපදය එයට සකසයි. වෙනත් සංකේතනය කළ තැටියක මුරපදය වෙනස් කිරීමට, ටර්මිනලයක `omarchy-drive-password` ධාවනය කරන්න.

## ඔබ දැනටමත් භාවිත කළ යන්ත්‍රයක් වෙනත් කෙනෙකුට භාර දීම

ඔබ ඔබේ යන්ත්‍රය වෙනත් කෙනෙකුට භාර දෙන්නේ නම්, ඔබට එය නැවත ස්ථාපනය කිරීමට සිදු නොවේ. Omarchy මෙනුවේ _ඉවත් කිරීම > කර්මාන්තශාලා යළි පිහිටුවීම_ ධාවනය කරන්න, තහවුරු කිරීමට `reset` ටයිප් කරන්න, ඇසුවහොත් ඔබේ තැටි සංකේතන මුරපදය ඇතුළත් කරන්න, සහ නැවත ආරම්භ කරන්න. එය සෑම පරිශීලක ගිණුමක්ම සහ `/home` හි ඇති සියල්ලම අතුගා දමයි, ස්ථාපනයෙන් පසු ඔබ කළ සියලුම පැකේජ සහ පද්ධති වෙනස්කම් ඉවත දමයි, සහ යන්ත්‍රයේ අනන්‍යතාවය — ජාල සම්බන්ධතා, host යතුරු, සහ සියල්ල — ඉවත් කරයි. නැවත ක්‍රියාත්මක වන්නේ පළමු ආරම්භයේ සැකසුම් විශාරදයයි, එහි නව හිමිකරුට තමන්ගේම නම, මුරපදය, සහ සංකේතන මුරපදය ඇතුළත් කිරීමට සූදානම්ව.

එය ක්‍රියා කරන්නේ ස්ථාපකය ගන්නා මූලික සැණෙළිය ප්‍රතිස්ථාපනය කිරීමෙනි, එබැවින් එය ලබා ගත හැක්කේ Omarchy ISO එකෙන් ස්ථාපනය කළ යන්ත්‍රවල පමණි. සහ සංකේතනය නොමැති තැටියක, යළි පිහිටුවීමක් යනු ආරක්ෂිත මකාදැමීමක් නොව මකාදැමීමක් පමණි, එබැවින් දත්ත සංවේදී නම්, ඒ වෙනුවට අලුත් ස්ථාපනයක් කරන්න.

## මුරපද රහිත sudo

සමහර විට ඔබට `sudo` විමසීම නැවැත්වීමට අවශ්‍ය වේ, බොහෝ විට AI නියෝජිතයෙකු ඔබ වෙනුවෙන් දිගු කාලයක් පද්ධති වැඩ කරමින් සිටින විට. _සැකසීම > ආරක්ෂාව > මුරපද රහිත Sudo_ ප්‍රවේශයට කොපමණ කාලයක් ඉඩ දිය යුතුදැයි අසයි: **විනාඩි 15**, **පැය 1**, **දින 1**, හෝ **ස්ථිරවම**. ප්‍රවේශය සක්‍රීයව තිබෙන අතරතුර වෙනත් මෙනු තීරු දර්ශක අසල රතු අනතුරු ඇඟවීමේ නිරූපකයක් දිස් වේ. එය ක්ලික් කරන්න හෝ ප්‍රවේශය අක්‍රීය කිරීමට විධානය නැවත ධාවනය කරන්න. ඔබට `omarchy-sudo-passwordless 30` සමඟ ඔබේම විනාඩි ගණන (1 සිට 1440 දක්වා) ලබා දිය හැකිය, නැතහොත් `omarchy-sudo-passwordless permanent` භාවිත කරන්න.

කාලානුරූප ප්‍රවේශය ස්වයංක්‍රීයව කල් ඉකුත් වේ, අවසාන දිනය පසු කළ අත්හිටුවීමකින් නැවත ආරම්භ කළ වහාම පවා. පරිගණකය නැවත ආරම්භ කිරීම එය කලින් අවසන් කරයි. ස්ථිර ප්‍රවේශය නැවත ආරම්භයන්ගෙන් බේරෙන අතර ඔබ එය අබල කරන තුරු සක්‍රීයව පවතී.

Omarchy හි සැකසුම් පැකේජය යාවත්කාලීන කිරීම හෝ ඉවත් කිරීම එහි කල් ඉකුත්වීමේ සහාය වෙනස් වීමට පෙර ඕනෑම තාවකාලික ප්‍රදානයක් අවසන් කරයි. විධානය අවසර දීමේ හෝ පිරිසිදු කිරීමේ දෝෂයක් වාර්තා කරන්නේ නම්, වෙනත් ප්‍රදානයක් සක්‍රීය කිරීමට උත්සාහ කිරීමට පෙර එය විසඳන්න; දෝෂයක් යනු මුරපද රහිත ප්‍රවේශය අක්‍රීය බව නොවේ.

මේ ගැන පැහැදිලි ඇසින් බලන්න: එය ක්‍රියාත්මකව තිබෙන අතරතුර, ඔබේ පරිශීලකයා ලෙස ධාවනය වන ඕනෑම දෙයකට විමසීමකින් තොරව root ලෙස ඕනෑම දෙයක් කළ හැකිය. එය මුළු අරමුණම වන අතර, එය මුළු අවදානමද වේ.
