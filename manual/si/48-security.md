# ආරක්ෂාව

Omarchy ආරක්ෂාව අතිශයින්ම බැරෑරුම් ලෙස සලකයි. මෙය _සැබෑ ලෝකයේ_ _සැබෑ වැඩ_ කිරීමට ඔබට භාවිත කළ හැකි මෙහෙයුම් පද්ධතියක් වීමට අදහස් කෙරේ. එහිදී ලැප්ටොප් එකක් නැති වීම ආරක්ෂක හදිසි අවස්ථාවකට තුඩු දිය නොහැක. එබැවින් අප කරන දේ මෙන්න:

1. *සම්පූර්ණ තැටි සංකේතනය අනිවාර්ය වේ*: ඔබේ දත්තවල භෞතික ආරක්ෂාව සුරක්ෂිත කිරීම සඳහා ඇති වැදගත්ම පියවර මෙයයි. ඔබේ පරිගණකය නැති වුවහොත් හෝ සොරකම් කළහොත්, සම්මත LUKS (Linux Unified Key Setup) භාවිතයෙන් දත්ත සම්පූර්ණයෙන්ම සංකේතනය කර ඇත.
2. *Firewall එක පෙරනිමියෙන් සක්‍රිය කර ඇත*: [LocalSend](https://localsend.org/) සඳහා වන port 53317 හැර, එන සියලුම ගමනාගමනය පෙරනිමියෙන් අවහිර කර ඇත. ඔබ _Setup > Security > SSHD_ හරහා එය සක්‍රිය කරන තෙක් ssh පවා අක්‍රියව පවතී. එම සැකසීමේ කොටසක් ලෙස port 22 විවෘත වේ (brute force ප්‍රහාරවලට එරෙහිව අනුපාත සීමා කර ඇත). ඔබේ containers අහම්බෙන් ලෝකයට නිරාවරණය වීම වැළැක්වීම සඳහා [ufw-docker](https://github.com/chaifeng/ufw-docker) සැකසුම භාවිතයෙන් අපි Docker ප්‍රවේශය පවා අගුළු දමමු.
3. *Arch සතුව සැමවිටම නවතම යාවත්කාලීන ඇත*: Omarchy ගොඩනගා ඇති පාදක distro එක වන Arch යනු rolling distribution එකකි. මෙයින් අදහස් වන්නේ, ඕනෑම පැකේජයක සොයා ගනු ලැබ පසුව නිවැරදි කරනු ලබන ඕනෑම ආරක්ෂක දුර්වලතාවක් `omarchy-update` භාවිතයෙන් ස්ථාපනය කිරීම සඳහා ඉක්මනින් ලබා ගත හැකි බවයි. එමඟින් ඔබ සැමවිටම සියල්ලේම නවතම, වඩාත්ම ආරක්ෂිත සංස්කරණ ධාවනය කරයි.
4. *Omarchy තමන්ගේම පැකේජ සහ mirror එකක් නඩත්තු කරයි*: Omarchy පෙරනිමියෙන් රඳා පවතින්නේ Arch හිම core/extra/multilib repositories සහ තමන්ගේම Omarchy Package Repository එකෙන් ලැබෙන පැකේජ මත පමණි. ඔබට AUR වෙතින් කෙලින්ම මෘදුකාංග ස්ථාපනය කළ හැක, නමුත් මූලික ස්ථාපනය එසේ නොකරයි — තෙවන පාර්ශවීය browsers වැනි විකල්ප ස්ථාපන කිහිපයක් පමණක් AUR වෙතින් ලබා ගනී.
5. *Cloudflare අපව DDoS වලින් ආරක්ෂා කරයි*: Omarchy බෙදාහැරීමේ යටිතල පහසුකම් — ISO, Omarchy පැකේජ, Arch mirror එක — Cloudflare හි බලවත් DDoS පලිහ පිටුපස ආරක්ෂා කර ඔවුන්ගේ CDN එකේ සත්කාරකත්වය දරයි. මෙය විශිෂ්ට ලබාගත හැකිබවක් සපයයි.

## ඔබේ මුරපද වෙනස් කිරීම

සංකේතනය කළ ස්ථාපනයක ඔබට මුරපද දෙකක් ඇත: එකක් boot කිරීමේදී drive එක අගුළු ඇරීමටත්, අනෙක ඔබ log in වීමට සහ `sudo` සමඟ භාවිත කිරීමටත් ය. Setup මඟින් ඒ දෙකම එකම මුරපදය බවට පත් කරයි. Omarchy මෙනුවේ _Update > Password_ යටතේ ඒ දෙකම වෙනස් කළ හැක — පළමුවැන්න සඳහා _Drive Encryption_, දෙවැන්න සඳහා _User_. Drive මුරපදය වෙනස් කිරීමේදී පළමුව වත්මන් මුරපදය ඉල්ලා සිටින බැවින්, එය ළඟ තබා ගන්න. වෙනස් කිරීමකට බාධා ඇති වුවහොත්, නැවත _Drive Encryption_ ධාවනය කරන්න: එය දැන් drive එක අගුළු අරින මුරපදය ඉල්ලා සිටිමින් වෙනස් කිරීම අවසන් කරයි.

## ඔබ දැනටමත් භාවිත කළ යන්ත්‍රයක් වෙනත් අයෙකුට භාර දීම

ඔබ ඔබේ යන්ත්‍රය වෙනත් අයෙකුට භාර දෙන්නේ නම්, ඔබට එය නැවත ස්ථාපනය කිරීමට සිදු නොවේ. Omarchy මෙනුවේ _Setup > Reset Computer_ ධාවනය කර, තහවුරු කිරීමට `reset` ලෙස type කර, reboot කරන්න. එය සෑම පරිශීලක ගිණුමක්ම සහ `/home` තුළ ඇති සියල්ලම මකා දමයි, ස්ථාපනයෙන් පසු ඔබ එක් කළ සියලුම පැකේජ සහ පද්ධති වෙනස්කම් ඉවත් කරයි, සහ යන්ත්‍රයේ අනන්‍යතාවය ඉවත් කරයි — ජාල සම්බන්ධතා, host keys සහ සියල්ල. නැවත ආරම්භ වන්නේ පළමු boot එකේ setup wizard එක වන අතර, එහි නව හිමිකරුට තමන්ගේම නම, මුරපදය සහ සංකේතන මුරපදය ඇතුළත් කිරීමට සූදානම්ව ඇත.

එය ක්‍රියා කරන්නේ installer එක ගන්නා baseline snapshot එක ප්‍රතිස්ථාපනය කිරීමෙනි, එබැවින් එය ලබා ගත හැක්කේ Omarchy ISO එකෙන් ස්ථාපනය කළ යන්ත්‍රවල පමණි. තවද සංකේතනය නොමැති drive එකක, reset කිරීමක් යනු secure erase එකක් නොව මකා දැමීමක් පමණි, එබැවින් දත්ත සංවේදී නම්, ඒ වෙනුවට නැවුම් ස්ථාපනයක් කරන්න.

## මුරපද රහිත sudo

සමහර විට ඔබට `sudo` ප්‍රශ්න ඇසීම නැවැත්වීමට අවශ්‍ය වේ, බොහෝ විට එය සිදුවන්නේ AI agent කෙනෙකු ඔබ වෙනුවෙන් දිගු කාලයක් පද්ධති වැඩ කරමින් සිටින විටය. _Setup > Security > Passwordless Sudo_ මඟින් කොපමණ කාලයක් ප්‍රවේශයට ඉඩ දිය යුතු දැයි අසයි: **මිනිත්තු 15**, **පැය 1**, **දින 1**, හෝ **ස්ථිරවම**. ප්‍රවේශය සක්‍රියව පවතින අතරතුර අනෙකුත් menu bar දර්ශක අසල රතු අනතුරු ඇඟවීමේ නිරූපකයක් දිස් වේ. එය click කරන්න, නැතහොත් ප්‍රවේශය අක්‍රිය කිරීමට විධානය නැවත ධාවනය කරන්න. ඔබට `omarchy-sudo-passwordless 30` සමඟ ඔබේම මිනිත්තු ගණනක් (1 සිට 1440 දක්වා) ලබා දිය හැක, නැතහොත් `omarchy-sudo-passwordless permanent` භාවිත කළ හැක.

කාලසීමා සහිත ප්‍රවේශය ස්වයංක්‍රීයව කල් ඉකුත් වේ, deadline එක පසු කරමින් suspend එකකින් resume කළ වහාමද එය සිදු වේ. පරිගණකය restart කිරීමෙන් එය ඉක්මනින් අවසන් වේ. ස්ථිර ප්‍රවේශය reboot කිරීම් වලින් පසුවත් පවතින අතර ඔබ එය අක්‍රිය කරන තෙක් සක්‍රියව පවතී.

Omarchy හි settings පැකේජය යාවත්කාලීන කිරීම හෝ ඉවත් කිරීම, එහි කල් ඉකුත්වීමේ සහාය වෙනස් වීමට පෙර ඕනෑම තාවකාලික ප්‍රදානයක් අවසන් කරයි. විධානය authorization හෝ cleanup දෝෂයක් වාර්තා කරන්නේ නම්, තවත් ප්‍රදානයක් සක්‍රිය කිරීමට උත්සාහ කිරීමට පෙර එය විසඳන්න; දෝෂයක් යනු මුරපද රහිත ප්‍රවේශය අක්‍රිය බව නොවේ.

මේ පිළිබඳව පැහැදිලිව සිතන්න: එය සක්‍රියව පවතින අතරතුර, ඔබේ පරිශීලකයා ලෙස ධාවනය වන ඕනෑම දෙයකට නොවිමසාම root ලෙස ඕනෑම දෙයක් කළ හැක. එය මෙහි සම්පූර්ණ අරමුණ වන අතර, එය මෙහි සම්පූර්ණ අවදානමද වේ.
