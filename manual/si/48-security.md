# ආරක්ෂාව

Omarchy ආරක්ෂාව අතිශයින්ම බරපතල ලෙස සලකයි. මෙය _සැබෑ ලෝකයේ_ _සැබෑ වැඩ_ කිරීමට ඔබට භාවිතා කළ හැකි මෙහෙයුම් පද්ධතියක් වීමටයි අදහස් කරන්නේ. එහිදී ලැප්ටොප් එකක් නැති වීම ආරක්ෂක හදිසි අවස්ථාවකට හේතු විය නොහැකිය. ඉතින් අපි කරන්නේ මෙන්න මේවාය:

1. *සම්පූර්ණ තැටි සංකේතනය පෙරනිමියෙන් සක්‍රියයි*: ඔබේ දත්තවල භෞතික ආරක්ෂාව සුරක්ෂිත කිරීමට ඇති වැදගත්ම පියවර මෙයයි. ඔබේ පරිගණකය නැති වුවහොත් හෝ සොරකම් කළහොත්, සම්මත LUKS (Linux Unified Key Setup) භාවිතයෙන් දත්ත සම්පූර්ණයෙන්ම සංකේතනය කර ඇත. ඉවත දමන යන්ත්‍ර සඳහා ඉන් ඉවත් වීමට ස්ථාපකය ඔබට ඉඩ දෙයි ([ආරම්භ කිරීම](02-getting-started.md) බලන්න); සංකේතනයකින් තොරව කරන ස්ථාපනයකට මෙම ආරක්ෂාවෙන් කිසිවක් නැත, එවිට drive එක අතේ ඇති ඕනෑම කෙනෙකුට එය කියවිය හැකිය.
2. *Firewall එක පෙරනිමියෙන් සක්‍රීය කර ඇත*: ව්‍යතිරේක කිහිපයක් හැර, ඇතුළු වන සියලුම ගමනාගමනය පෙරනිමියෙන් අවහිර කර ඇත: [LocalSend](https://localsend.org/) සඳහා port 53317; Docker bridge ලිපිනයේ (172.17.0.1) ඇති පරිගණකයේම resolver එකට යවන DNS විමසුම්, Docker එහි containers වලට ලබා දෙන පුද්ගලික ලිපින පරාසවලින් එන ඒවා පිළිගනු ලැබේ; සහ multicast DNS (port 5353), එය ඔබේ ජාලයේ ඇති printers සහ වෙනත් උපාංගවලට එකිනෙකා සොයා ගැනීමට ඉඩ දෙන අතර එහි ඔබේ පරිගණකයේ නමද ප්‍රකාශ කරයි. ඒවාට අමතරව, firewall එක ping සඳහා, ඔබේ router එකෙන් ලිපිනයක් ලබා ගැනීම (DHCP) සඳහා, සහ UPnP සොයා ගැනීම සඳහා UFW හි සම්මත අවසරයන් රඳවා ගනී. ඔබ _සැකසුම > ආරක්ෂාව > SSHD_ හරහා එය සක්‍රිය කරන තුරු ssh පවා අක්‍රියයි, එහිදී සැකසුමේ කොටසක් ලෙස port 22 විවෘත කරයි (brute force වලට එරෙහිව rate limited කර ඇත). ඔබේ containers අහම්බෙන් ලෝකයට නිරාවරණය වීම වැළැක්වීම සඳහා [ufw-docker](https://github.com/chaifeng/ufw-docker) සැකසුම භාවිතයෙන් අපි Docker ප්‍රවේශය පවා අගුළු දමමු.
3. *Arch සතුව සැමවිටම නවතම යාවත්කාලීනයන් ඇත*: Omarchy ගොඩනගා ඇති පාදක distro එක වන Arch යනු rolling distribution එකකි. මෙයින් අදහස් වන්නේ ඕනෑම පැකේජයක සොයා ගෙන නිවැරදි කරන ලද ඕනෑම ආරක්ෂක දුර්වලතාවයක් `omarchy-update` භාවිතයෙන් ස්ථාපනය කිරීමට ඉක්මනින් ලබා ගත හැකි බවයි. ඒ ආකාරයට ඔබ සැමවිටම සියල්ලේම නවතම, වඩාත්ම ආරක්ෂිත අනුවාදයන් ධාවනය කරයි.
4. *Omarchy තමන්ගේම පැකේජ සහ mirror එකක් පවත්වාගෙන යයි*: Omarchy පෙරනිමියෙන් රඳා පවතින්නේ Arch හිම core/extra/multilib repositories වලින් සහ තමන්ගේම Omarchy Package Repository එකෙන් ලැබෙන පැකේජ මත පමණි. ඔබට AUR එකෙන් කෙලින්ම මෘදුකාංග ස්ථාපනය කළ හැකිය, නමුත් පාදක ස්ථාපනය එසේ නොකරයි — තෙවන පාර්ශවීය browsers වැනි විකල්ප ස්ථාපනයන් කිහිපයක් පමණක් AUR එකෙන් ලබා ගනී.
5. *Cloudflare අපව DDoS වලින් ආරක්ෂා කරයි*: Omarchy බෙදාහැරීමේ යටිතල පහසුකම් — ISOs, Omarchy පැකේජ, Arch mirror එක — Cloudflare හි ප්‍රබල DDoS පලිහ පිටුපස ආරක්ෂා කර ඇති අතර ඔවුන්ගේ CDN එකේ සත්කාරකත්වය දරයි. මෙය විශිෂ්ට ලබා ගත හැකි බවක් සපයයි.

## ඔබේ මුරපද වෙනස් කිරීම

සංකේතනය කළ ස්ථාපනයක ඔබට මුරපද දෙකක් ඇත: boot එකේදී drive එක අගුළු හරින එක, සහ ඔබ log in වන සහ `sudo` සමඟ භාවිතා කරන එක. සැකසුම ඒ දෙකම එකම එක බවට පත් කරයි. Omarchy මෙනුවේ _යාවත්කාලීනය > මුරපදය_ යටතේ ඒ දෙකම වෙනස් කළ හැකිය — පළමුවැන්න සඳහා _Drive Encryption_, දෙවැන්න සඳහා _User_. Drive මුරපදය වෙනස් කිරීමේදී පළමුව වත්මන් එක ඉල්ලයි, එබැවින් එය ළඟ තබා ගන්න. වෙනසකට බාධා ඇති වුවහොත්, _Drive Encryption_ නැවත ධාවනය කරන්න: එය දැන් drive එක අගුළු හරින මුරපදය ඉල්ලා වෙනස අවසන් කරයි.

## ඔබ දැනටමත් භාවිතා කළ යන්ත්‍රයක් වෙනත් අයෙකුට ලබා දීම

ඔබ ඔබේ යන්ත්‍රය වෙනත් කෙනෙකුට භාර දෙනවා නම්, ඔබට එය නැවත ස්ථාපනය කිරීමට අවශ්‍ය නැත. Omarchy මෙනුවේ _සැකසුම > පරිගණකය යළි සකසන්න_ ධාවනය කරන්න, තහවුරු කිරීමට `reset` type කරන්න, සහ reboot කරන්න. එය සෑම user account එකක්ම සහ `/home` හි ඇති සියල්ලම මකා දමයි, ස්ථාපනයෙන් පසු ඔබ කරන ලද සියලුම පැකේජ සහ පද්ධති වෙනස්කම් ඉවත දමයි, සහ යන්ත්‍රයේ අනන්‍යතාවය ඉවත් කරයි — ජාල සම්බන්ධතා, host keys, සහ සියල්ල. නැවත ආරම්භ වන්නේ පළමු boot එකේ setup wizard එකයි, එහි නව හිමිකරුට තමන්ගේම නම, මුරපදය, සහ සංකේතන මුරපදය ඇතුළත් කිරීමට සූදානම්ව ඇත.

එය ක්‍රියා කරන්නේ ස්ථාපකය ගන්නා baseline snapshot එක ප්‍රතිෂ්ඨාපනය කිරීමෙනි, එබැවින් එය ලබා ගත හැක්කේ Omarchy ISO එකෙන් ස්ථාපනය කළ යන්ත්‍රවල පමණි. සහ සංකේතනයක් නැති drive එකක, reset කිරීමක් යනු ආරක්ෂිතව මකා දැමීමක් නොව මකා දැමීමක් පමණි, එබැවින් දත්ත සංවේදී නම්, ඒ වෙනුවට නැවුම් ස්ථාපනයක් කරන්න.

## මුරපද රහිත sudo

සමහර විට ඔබට `sudo` විමසීම නැවැත්වීමට අවශ්‍ය වේ, බොහෝ විට AI agent කෙනෙක් ඔබට දිගු කාලයක් පද්ධති වැඩ කරමින් සිටින විට. _සැකසුම > ආරක්ෂාව > මුරපද රහිත Sudo_ ප්‍රවේශයට කොපමණ කාලයක් ඉඩ දිය යුතුදැයි අසයි: **මිනිත්තු 15**, **පැය 1**, **දින 1**, හෝ **ස්ථිරවම**. ප්‍රවේශය සක්‍රියව තිබෙන අතරතුර අනෙකුත් මෙනු තීරු දර්ශක අසල රතු අනතුරු ඇඟවීමේ නිරූපකයක් දිස් වේ. එය ක්ලික් කරන්න නැතහොත් අක්‍රිය කිරීමට විධානය නැවත ධාවනය කරන්න. ඔබට `omarchy-sudo-passwordless 30` සමඟ ඔබේම මිනිත්තු ගණනක් (1 සිට 1440 දක්වා) ලබා දිය හැකිය, නැතහොත් `omarchy-sudo-passwordless permanent` භාවිතා කළ හැකිය.

කාලානුරූපී ප්‍රවේශය ස්වයංක්‍රීයව කල් ඉකුත් වේ, නියමිත කාලය ඉක්මවා ගිය suspend එකකින් නැවත ආරම්භ වූ වහාමද ඇතුළුව. පරිගණකය නැවත ආරම්භ කිරීම එය කලින් අවසන් කරයි. ස්ථිර ප්‍රවේශය reboots වලින් පසුවත් පවතින අතර ඔබ එය අක්‍රිය කරන තුරු සක්‍රීයව පවතී.

Omarchy හි settings පැකේජය යාවත්කාලීන කිරීම හෝ ඉවත් කිරීම එහි කල් ඉකුත් වීමේ සහාය වෙනස් වීමට පෙර ඕනෑම තාවකාලික අවසරයක් අවසන් කරයි. විධානය බලය පැවරීමේ හෝ පිරිසිදු කිරීමේ දෝෂයක් වාර්තා කරන්නේ නම්, තවත් අවසරයක් සක්‍රිය කිරීමට උත්සාහ කිරීමට පෙර එය විසඳන්න; දෝෂයක් යනු මුරපද රහිත ප්‍රවේශය අක්‍රීය බව නොවේ.

මේ ගැන පැහැදිලි ඇසකින් බලන්න: එය සක්‍රියව තිබෙන අතරතුර, ඔබේ user ලෙස ධාවනය වන ඕනෑම දෙයකට විමසීමකින් තොරව root ලෙස ඕනෑම දෙයක් කළ හැකිය. එය මුළු අරමුණම වන අතර, එය මුළු අවදානමමද වේ.
