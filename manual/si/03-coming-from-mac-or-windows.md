# Mac හෝ Windows සිට පැමිණෙන විට

ඔබ macOS හෝ Windows මත වසර ගණනාවක් ගත කර ඇත්නම්, ඔබේ මොළය කවදා හෝ ඉගෙන ගත් බව අමතක කර ඇති දේවල් සියයක් ඔබේ ඇඟිලි දනී. මෙම පරිච්ඡේදය පරිවර්තන ස්තරයයි: Omarchy තුළ එම සහජ බුද්ධීන් යන්නේ කොහෙටද යන්න. විශේෂාංග ගැනම වෙනත් තැන්වල ගැඹුරින් සාකච්ඡා කර ඇත — මෙය හුදෙක් සිතියම පමණි.

### Super යනු සියල්ලේ කේන්ද්‍රයයි

Cmd හෝ Windows යතුර වටා ඔබ ගොඩනඟා ඇති සියලුම මාංශපේශී මතකය එක් යතුරකට මාරු වේ: Super. එනම් PC යතුරුපුවරුවක ඇති Windows යතුරයි, එය Omarchy හි සෑම hotkey එකකටම පාහේ නැංගුරමයි.

ඔබේ Spotlight හෝ Raycast හෝ Start-menu ප්‍රතික්‍රියාව `Super + Space` බවට පත් වේ. එයින් Omarchy මෙනුව විවෘත වේ, එය යෙදුම් දියත් කරයි, සැකසීම් වෙනස් කරයි, මෘදුකාංග ස්ථාපනය කරයි, තිරය ග්‍රහණය කරයි — බොහෝ දුරට සියල්ලම. පෙරහන් කිරීමට ටයිප් කිරීම අරඹන්න. `Super + Alt + Space` මගින් Launchpad කරන ආකාරයටම එක් කොටු දැලක සෑම යෙදුමක්ම පෙන්වයි. [සංචලනය](04-navigation.md) බලන්න.

### ඩෙස්ක්ටොප් අයිකන නැත, ඔබ පා කරන්නේ නම් පමණක් dock එක මතුවේ

ඩෙස්ක්ටොපය මත සකස් කිරීමට අයිකන නැත, tiling workspace එකක dock එකක් නැත — dock එක මතුවන්නේ floating workspace එකක පමණි ([සංචලනය](04-navigation.md) බලන්න). යෙදුම් hotkey එකකින් (`Super + Return` terminal එක සඳහා, `Super + Shift + Return` browser එක සඳහා සහ සිතියම්ගත කර ඇති සියල්ලේ ලැයිස්තුවක් සඳහා `Super + K`) හෝ මෙනුවෙන් අරඹනු ලැබේ. නොනැසී පවතින එකම UI කොටස [ඉහළ තීරුව](05-the-top-bar.md) වන අතර, එය මීට පෙර menu bar, system tray සහ Notification Center ඔබට කර දුන් දේ ආවරණය කරයි — තවද එහි ඇති සෑම widget එකක්ම පාහේ වම්, දකුණු සහ මැද click එකෙන් යම් දෙයක් කරයි.

### Windows තමන්ටම ස්ථානගත වේ

විශාලතම මානසික මාරුව: ඔබ windows එහෙ මෙහෙ ඇදගෙන යන්නේ නැත, එසේම තිරයේ අර්ධවලට snap කරන්නේද නැත. window එකක් විවෘත කරන්න, එය මුළු තිරයම ගනී. දෙවැන්නක් විවෘත කරන්න, ඒවා එය බෙදා ගනී. windows අතිච්ඡාදනය නොවන නිසා ඔබ කිසිවිටක තවත් එකක් යටින් window එකක් ඇද ගන්නේ නැත.

ඔබට සැබවින්ම floating window එකක් අවශ්‍ය වන විට, `Super + T` මගින් සක්‍රිය එක tiling එකෙන් පිටතට (සහ ආපසු) මාරු කරයි. නමුත් පළමුව tiling එකට සැබෑ අවස්ථාවක් දෙන්න — එය මුළු දේහිම හදවතයි. [සංචලනය](04-navigation.md) ඔබව එය හරහා ගෙන යයි.

Workspaces ඔබට හුරුපුරුදු බවක් දැනෙනු ඇත: ඒවා macOS Spaces හෝ Windows virtual desktops වන අතර, වෙනස නම් ඔබ සැබවින්ම ඒවා භාවිතා කරනු ඇති බවයි, මන්ද `Super + 1/2/3/4` කෙලින්ම එකකට පනින අතර `Super + Shift + 1/2/3/4` සක්‍රිය window එක එහි යවයි. සජීවිකරණ ප්‍රමාදයක් නැත, ක්ෂණික පැනීම් පමණි. එනම් ඔබ මීට පෙර ඒවාට හුරුව සිටියේ නම්, ඔබට monitors කිහිපයක්වත් අවශ්‍ය නොවීමට ඉඩ ඇත.

### පිටපත් කිරීම සහ ඇලවීම හුදෙක් ක්‍රියාත්මක වේ

Mac එකේ ඔබට සෑම තැනකම Cmd + C තිබුණි. Windows වල ඔබට සෑම තැනකම Ctrl + C තිබුණි — terminal එකේදී හැර, එහිදී එය ඔබේ වැඩසටහන මරා දමයි. Omarchy ඔබට `Super + C`, `Super + X` සහ `Super + V` ලබා දෙන අතර, ඒවා terminal එක ඇතුළුව සෑම තැනකම ක්‍රියාත්මක වේ. shell එක සඳහා ඉගෙන ගැනීමට වෙනම ප්‍රතික්‍රියාවක් නැත.

Windows ජනයෙනි: ඔබේ Win + V clipboard ඉතිහාසය `Super + Ctrl + V` මත පවතින අතර, එය පෙළ මෙන්ම රූපද රඳවා ගනී. [ඒකාබද්ධ clipboard සහ ඉතිහාසය](08-unified-clipboard-history.md) බලන්න.

### සමහර දේවල් සැබවින්ම වෙනස්ය

බොහෝ සැකසීම් ඇත්තේ ඔබ click කරමින් යන පැනලවල නොව, ඔබ සංස්කරණය කරන පෙළ ගොනු තුළය. සෑම tweak එකක්ම දැකිය හැකි, ඔබේ ඊළඟ යන්ත්‍රයට පිටපත් කළ හැකි සහ version control තුළ තැබිය හැකි බව ඔබ වටහා ගන්නා තුරු එය ප්‍රාථමික බවක් ඇසට පෙනේ. _Setup_ මෙනුව ඔබව කෙලින්ම නිවැරදි ගොනුවට දමන අතර, ඔබ අවසන් කළ පසු යළි අරඹන්නට අවශ්‍ය ඕනෑම දෙයක් යළි අරඹයි.

යාවත්කාලීනයන් එක් විධානයක් හරහා පැමිණේ — _Update > Omarchy_ — එය Omarchy ද පද්ධතියේ සෑම පැකේජයක්ම යාවත්කාලීනය කරයි, පළමුව snapshot එකක් ගනිමින්. අහඹු ලෙස ඔබට කරදර කරන යෙදුමෙන් යෙදුමට වෙන් වූ updaters නැත. [යාවත්කාලීන](30-updates.md) බලන්න.

මෘදුකාංග පැමිණෙන්නේ බාගත කළ installers වලින් නොව package manager එකකිනි.

තවද ඔබ window එකක් වැසූ විට, යෙදුම සැබවින්ම ඉවත් වේ. windows කිසිවක් නොමැතිව වැඩසටහන දිගටම ක්‍රියාත්මක වන macOS limbo එකක් නැත. `Super + W` — නැතහොත් ඔබ පැමිණි ඇඟිලි මතකය එය නම් `Super + Q` — යන්නෙන් අදහස් වන්නේ එය ගොස් ඇති බවයි.

### Mac hardware මත

Omarchy Intel Macs මත හොඳින් ක්‍රියාත්මක වන අතර, Omarchy for Apple Silicon සමඟ M1, M2 සහ M3 Macs මතද ක්‍රියාත්මක වේ. [Mac සහාය](44-mac-support.md) බලන්න. තවද යතුරුපුවරුව ඔබට කරුණාවන්තය: Omarchy කිසිවක් remap කරන්නේ නැත, Linux Command යතුර Super ලෙස සලකන බැවින්, Super පවතින්නේ Cmd සැමවිටම තිබූ තැන්හිමය. ඔබේ මහපටැඟිල්ල මෙම මාරුව දකින්නේවත් නැත.

### සති දෙකක් දෙන්න

සහජ බුද්ධීන් ඔබ සිතනවාට වඩා වේගයෙන් මාරු වේ. [hotkeys](07-hotkeys.md) පරිච්ඡේදය එක් වරක් කියවා බලන්න, තවද ඔබට binding එකක් මතක නැති වන සෑම විටකම `Super + K` ඔබන්න — එය ඔබට ඒ සියල්ලම පෙන්වයි. එය ඔබට සැබවින්ම මතක තබා ගත යුතු එකම hotkey එකයි.
