# Mac හෝ Windows වෙතින් පැමිණීම

ඔබ වසර ගණනාවක් macOS හෝ Windows හි ගත කර ඇත්නම්, ඔබේ මොළය කවදා හෝ ඉගෙන ගත් බව අමතක කර ඇති දේවල් සියයක් ඔබේ ඇඟිලි දනී. මෙම පරිච්ඡේදය පරිවර්තන ස්ථරයයි: එම සහජ බුද්ධීන් Omarchy හි යන්නේ කොහෙද යන්නයි. විශේෂාංග වෙනත් තැන්වල ගැඹුරින් ආවරණය කර ඇත — මෙය සිතියම පමණි.

### Super යනු සියල්ලේ මධ්‍යස්ථානයයි

Cmd හෝ Windows යතුර වටා ඔබ ගොඩනඟා ඇති සියලුම මාංශ පේශි මතකය එක් යතුරකට මාරු වේ: Super. එය PC යතුරුපුවරුවක Windows යතුර වන අතර, එය Omarchy හි සෑම උණුසුම් යතුරකම පාහේ නැංගුරමයි.

ඔබේ Spotlight හෝ Raycast හෝ Start-menu ප්‍රතික්‍රියාව `Super + Space` බවට පත් වේ. එය යෙදුම් දියත් කරන, සැකසුම් වෙනස් කරන, මෘදුකාංග ස්ථාපනය කරන, තිරය ග්‍රහණය කරන Omarchy මෙනුව විවෘත කරයි — සියල්ලම පාහේ. පෙරීමට ටයිප් කිරීම අරඹන්න. `Super + Alt + Space` Launchpad කරන ආකාරයටම සෑම යෙදුමක්ම එක් ජාලයක පෙන්වයි. බලන්න [සංචාලනය](04-navigation.md).

### dock එකක් නැත, ඩෙස්ක්ටොප් අයිකන ද නැත

දේවල් දියත් කිරීමට ක්ලික් කිරීමට කිසිවක් නැත, ඩෙස්ක්ටොප් එකේ සකස් කිරීමට අයිකන නැත. යෙදුම් උණුසුම් යතුරකින් (ටර්මිනලය සඳහා `Super + Return`, බ්‍රවුසරය සඳහා `Super + Shift + Return`, සහ සිතියම්ගත කර ඇති සියල්ලේ ලැයිස්තුවක් සඳහා `Super + K`) හෝ මෙනුවෙන් ආරම්භ වේ. UI හි එක් ස්ථීර කොටස වන්නේ [ඉහළ තීරුව](05-the-top-bar.md) වන අතර, එය මෙනු තීරුව, පද්ධති තැටිය සහ Notification Center මීට පෙර ඔබ වෙනුවෙන් කළ දේ ආවරණය කරයි — සහ එහි ඇති සෑම විජෙට් එකක්ම පාහේ වම්, දකුණු සහ මැද ක්ලික් කිරීමෙන් යමක් කරයි.

### කවුළු තනිවම පිහිටයි

විශාලතම මානසිකත්ව වෙනස: ඔබ කවුළු ඇදගෙන යන්නේ හෝ තිර අර්ධවලට සවි කරන්නේ නැත. කවුළුවක් විවෘත කරන්න, එය මුළු තිරයම ගනී. දෙවැන්නක් විවෘත කරන්න, ඒවා එය බෙදා ගනී. කවුළු අතිච්ඡාදනය නොවන නිසා ඔබ කිසිවිටෙක තවත් එකක් යටින් කවුළුවක් ඇද ගන්නේ නැත.

ඔබට සැබවින්ම පාවෙන කවුළුවක් අවශ්‍ය වූ විට, `Super + T` ක්‍රියාකාරී එක ටයිල් කිරීමෙන් පිටතට (සහ ආපසු) මාරු කරයි. නමුත් පළමුව ටයිල් කිරීමට සැබෑ අවස්ථාවක් දෙන්න — එය මුළු දේහිම හදවතයි. [සංචාලනය](04-navigation.md) ඔබව ඒ හරහා රැගෙන යයි.

වැඩබිම් හුරුපුරුදු බවක් දැනෙනු ඇත: ඒවා macOS Spaces හෝ Windows virtual desktops වන නමුත්, `Super + 1/2/3/4` කෙලින්ම එකකට පනිමින් සහ `Super + Shift + 1/2/3/4` ක්‍රියාකාරී කවුළුව එහි යවන නිසා, ඔබ ඇත්තටම ඒවා භාවිත કરනු ඇත. සජීවිකරණ ප්‍රමාදයක් නැත, ක්ෂණික පිම්ම පමණි. මෙයින් අදහස් වන්නේ ඔබ මීට පෙර ඒ සඳහා පුරුදු වී සිටියේ නම්, ඔබට බහු මොනිටර අවශ්‍ය නොවිය හැකි බවයි.

### පිටපත් කිරීම සහ ඇලවීම තනිවම වැඩ කරයි

Mac හි ඔබට සෑම තැනකම Cmd + C තිබුණි. Windows හි ඔබට සෑම තැනකම Ctrl + C තිබුණි — එය ඔබේ වැඩසටහන මරා දමන ටර්මිනලය හැර. Omarchy ඔබට `Super + C`, `Super + X`, සහ `Super + V` ලබා දෙන අතර, ඒවා ටර්මිනලය ඇතුළුව සෑම තැනකම වැඩ කරයි. shell එක සඳහා වෙනම ප්‍රතික්‍රියාවක් ඉගෙන ගත යුතු නැත.

Windows අය: ඔබේ Win + V ක්ලිප්බෝඩ් ඉතිහාසය `Super + Ctrl + V` හි ජීවත් වන අතර, එය පෙළ මෙන්ම රූප ද රඳවා ගනී. බලන්න [ඒකාබද්ධ ක්ලිප්බෝඩය සහ ඉතිහාසය](08-unified-clipboard-history.md).

### සමහර දේවල් ඇත්තටම වෙනස්ය

බොහෝ සැකසුම් ජීවත් වන්නේ ඔබ ක්ලික් කර යන පැනලවල නොව, ඔබ සංස්කරණය කරන පෙළ ගොනුවලය. එයින් අදහස් වන්නේ සෑම වෙනස්කමක්ම දැකිය හැකි බව, ඔබේ ඊළඟ යන්ත්‍රයට පිටපත් කළ හැකි බව සහ අනුවාද පාලනයට දැමිය හැකි බව ඔබට වැටහෙන තෙක් එය ප්‍රාථමික ලෙස ඇසේ. _සැකසුම_ මෙනුව ඔබව කෙලින්ම නිවැරදි ගොනුවට දමන අතර ඔබ අවසන් කළ පසු නැවත ආරම්භ කළ යුතු දේ නැවත ආරම්භ කරයි.

යාවත්කාලීන එන්නේ එක් විධානයක් හරහාය — _යාවත්කාලීන > Omarchy_ — එය Omarchy ම සහ පද්ධතියේ සෑම පැකේජයක්ම යාවත්කාලීන කරමින්, පළමුව ඡායාරූපයක් ගනී. අහඹු ලෙස ඔබට කරදර කරන යෙදුම් අනුව යාවත්කාලීන කරන්නන් නැත. බලන්න [යාවත්කාලීන](30-updates.md).

මෘදුකාංග බාගත් ස්ථාපකයන්ගෙන් නොව පැකේජ කළමනාකරුවෙකුගෙන් එයි.

ඔබ කවුළුවක් වැසූ විට, යෙදුම ඇත්තටම ඉවත් වේ. කවුළු නොමැතිව වැඩසටහන දිගටම ධාවනය වන macOS limbo එකක් නැත. `Super + W` — හෝ ඔබ පැමිණි ඇඟිලි මතකය එය නම් `Super + Q` — යනු නැති වී ගිය බවයි.

### Mac දෘඪාංග මත

Omarchy Intel Mac මත හොඳින් ධාවනය වේ — බලන්න [Mac සහාය](44-mac-support.md). යතුරුපුවරුව ඔබට කරුණාවන්තය: Omarchy කිසිවක් නැවත සිතියම්ගත නොකරන අතර, Linux Command යතුර Super ලෙස සලකයි, එබැවින් Super හිඳින්නේ Cmd සැමවිටම සිටි තැනමයි. ඔබේ මාපටැඟිල්ල චලනය නොදකිනු ඇත.

### එයට සති දෙකක් දෙන්න

සහජ බුද්ධීන් ඔබ සිතනවාට වඩා වේගයෙන් මාරු වේ. [උණුසුම් යතුරු](07-hotkeys.md) පරිච්ඡේදය එක් වරක් කියවන්න, සහ ඔබට බන්ධනයක් මතක නැති වූ විට සෑම විටම `Super + K` ඔබන්න — එය ඒ සියල්ල ඔබට පෙන්වයි. ඔබ ඇත්තටම කටපාඩම් කළ යුතු එකම උණුසුම් යතුර එයයි.
