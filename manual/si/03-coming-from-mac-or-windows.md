# Mac හෝ Windows වෙතින් පැමිණෙන විට

ඔබ macOS හෝ Windows මත වසර ගණනාවක් ගත කර ඇත්නම්, ඔබේ මොළය කවදා හෝ ඉගෙන ගත් බව අමතක කර ඇති දේවල් සියයක් ඔබේ ඇඟිලි දනියි. මෙම පරිච්ඡේදය එම පරිවර්තන ස්ථරයයි: Omarchy තුළ එම සහජ බුද්ධි යන්නේ කොහෙද යන්නයි. අංග themselves වෙනත් තැන්වල ගැඹුරින් ආවරණය කර ඇත — මෙය හුදෙක් සිතියම පමණි.

### Super යනු සියල්ලේම කේන්ද්‍රයයි

Cmd හෝ Windows යතුර වටා ඔබ ගොඩනඟා ගත් සියලුම මාංශ මතකය එක් යතුරකට මාරු වේ: Super. එය PC යතුරුපුවරුවක ඇති Windows යතුරයි, එය Omarchy හි සෑම හොට්කීයකම පාහේ නැංගුරමයි.

ඔබේ Spotlight හෝ Raycast හෝ Start-menu ප්‍රතික්‍රියාව `Super + Space` බවට පත් වේ. එය Omarchy මෙනුව විවෘත කරයි, එය යෙදුම් දියත් කරයි, සැකසීම් වෙනස් කරයි, මෘදුකාංග ස්ථාපනය කරයි, තිරය ග්‍රහණය කරයි — සියල්ලම වාගේ. පෙරහන් කිරීමට ටයිප් කිරීම ආරම්භ කරන්න. `Super + Alt + Space` මඟින් Launchpad කරන ආකාරයටම සියලුම යෙදුම් එක් ජාලකයක පෙන්වයි. [සංචලනය](04-navigation.md) බලන්න.

### ඩෙස්ක්ටොප් අයිකන නැත, සහ ඩොක් එක ඉවත්ව පවතී

ඩෙස්ක්ටොප් එක මත සකස් කිරීමට අයිකන නැත, සහ වැඩබිමක කවුළුවක් ඇති වූ පසු ඩොක් එක සැඟවී පවතී, ඔබ පොයින්ටරය එහි තිරයේ දාරයට, ඔබ එය ගෙන නොයන්නේ නම් පහළ දාරයට, තල්ලු කරන තුරු (බලන්න [සංචලනය](04-navigation.md)). යෙදුම් ආරම්භ වන්නේ හොට්කීයකින් (`Super + Return` ටර්මිනලය සඳහා, `Super + Shift + Return` බ්‍රවුසරය සඳහා, සහ `Super + K` සිතියම්ගත කර ඇති සියල්ලේ ලැයිස්තුවක් සඳහා) හෝ මෙනුවෙන්. නොනැසී පවතින එකම UI කොටස [ඉහළ තීරුව](05-the-top-bar.md) වන අතර, එය මෙනු තීරුව, පද්ධති තැටිය, සහ Notification Center මීට පෙර ඔබට කළ දේ ආවරණය කරයි — සහ එහි ඇති සෑම විජට් එකක්ම පාහේ වම්, දකුණු, සහ මැද ක්ලික් කිරීමේදී යමක් කරයි.

### කවුළු තමන්ම ස්ථානගත වේ

විශාලතම මානසික මාරුව: ඔබ කවුළු එහෙ මෙහෙ අදිමින් තිර අර්ධවලට අලවන්නේ නැත. කවුළුවක් විවෘත කරන්න, එය මුළු තිරයම ගනී. දෙවැන්නක් විවෘත කරන්න, ඒවා එය බෙදා ගනී. කවුළු එකිනෙක මත නොවැටෙන බැවින්, ඔබ කිසිදා තවත් කවුළුවක් යටින් කවුළුවක් එළියට ගැනීමට මහන්සි වන්නේ නැත.

ඔබට සැබවින්ම පාවෙන කවුළුවක් අවශ්‍ය වූ විට, `Super + T` මඟින් සක්‍රිය කවුළුව ටයිල් කිරීමෙන් පිටතට (සහ නැවත ඇතුළට) මාරු කරයි. නමුත් පළමුව ටයිල් කිරීමට සැබෑ අවස්ථාවක් දෙන්න — එය මුළු දේහිම හදවතයි. [සංචලනය](04-navigation.md) ඔබට එහි ගමන් මඟ පෙන්වයි.

වැඩබිම් හුරුපුරුදු බවක් දැනේවි: ඒවා macOS Spaces හෝ Windows අතථ්‍ය ඩෙස්ක්ටොප් වේ, නමුත් ඔබ ඒවා සැබවින්ම භාවිතා කරනු ඇත, මන්ද `Super + 1/2/3/4` මඟින් කෙළින්ම එකකට පනින අතර `Super + Shift + 1/2/3/4` මඟින් සක්‍රිය කවුළුව එහි යවයි. සජීවිකරණ ප්‍රමාදයක් නැත, ක්ෂණික පැනීම් පමණි. මෙයින් අදහස් වන්නේ, ඔබ මීට පෙර එයට පුරුදු වී සිටියේ නම්, ඔබට බහු මොනිටර අවශ්‍ය නොවීමට පවා ඉඩ ඇති බවයි.

### පිටපත් කිරීම සහ ඇලවීම නිකම්ම වැඩ කරයි

Mac මත ඔබට සෑම තැනකම Cmd + C තිබුණි. Windows මත ඔබට සෑම තැනකම Ctrl + C තිබුණි — ටර්මිනලය හැර, එහි එය ඔබේ වැඩසටහන මරා දමයි. Omarchy ඔබට `Super + C`, `Super + X`, සහ `Super + V` ලබා දෙයි, සහ ඒවා ටර්මිනලය ඇතුළුව සෑම තැනකම වැඩ කරයි. ෂෙල් එක සඳහා වෙනම ප්‍රතික්‍රියාවක් ඉගෙන ගත යුතු නැත.

Windows වැසියනි: ඔබේ Win + V පසුරුපුවරු ඉතිහාසය `Super + Ctrl + V` මත ජීවත් වේ, සහ එය පෙළ මෙන්ම රූපද රඳවා ගනී. [ඒකාබද්ධ පසුරුපුවරුව සහ ඉතිහාසය](08-unified-clipboard-history.md) බලන්න.

### සමහර දේවල් සැබවින්ම වෙනස්ය

බොහෝ සැකසීම් ඔබ ක්ලික් කරමින් යන පැනලවල නොව, ඔබ සංස්කරණය කරන පෙළ ගොනු තුළ ජීවත් වේ. ඒවා සියල්ල දැකිය හැකි, ඔබේ ඊළඟ යන්ත්‍රයට පිටපත් කළ හැකි, සහ අනුවාද පාලනයට දැමිය හැකි බව ඔබට වැටහෙන තුරු එය ප්‍රාථමික බවක් පෙනේ. _Setup_ මෙනුව ඔබව කෙළින්ම නිවැරදි ගොනුවට දමන අතර ඔබ අවසන් වූ විට නැවත ආරම්භ කළ යුතු දේ නැවත ආරම්භ කරයි.

යාවත්කාලීනයි එක් විධානයක් හරහා පැමිණේ — _Update > Omarchy_ — එය Omarchy ම සහ පද්ධතියේ සෑම පැකේජයක්ම යාවත්කාලීන කරයි, පළමුව ස්නැප්ෂොට් එකක් ගනී. අහඹු ලෙස ඔබට කරදර කරන යෙදුමකට එක බැගින් වූ යාවත්කාල කරන්නන් නැත. [යාවත්කාලීනයි](30-updates.md) බලන්න.

මෘදුකාංග පැමිණෙන්නේ බාගත කළ ස්ථාපකවලින් නොව, පැකේජ කළමනාකරුවෙකුගෙනි.

සහ ඔබ කවුළුවක් වසන විට, යෙදුම සැබවින්ම ඉවත් වේ. වැඩසටහන කවුළු නොමැතිව දිගටම ක්‍රියාත්මක වන macOS අවිනිශ්චිත තත්ත්වයක් නැත. `Super + W` — හෝ ඔබ පැමිණියේ එම ඇඟිලි මතකය සමඟ නම් `Super + Q` — යන්නෙන් අදහස් වන්නේ ගිය එක ගිය බවයි.

### Mac දෘඪාංග මත

Omarchy Intel Macs මත, සහ Omarchy for Apple Silicon සමඟ M1, M2 සහ M3 Macs මත හොඳින් ක්‍රියා කරයි. [Mac සහාය](44-mac-support.md) බලන්න. සහ යතුරුපුවරුව ඔබට කරුණාවන්තයි: Omarchy කිසිවක් නැවත සිතියම්ගත නොකරයි, සහ Linux විසින් Command යතුර Super ලෙස සලකයි, එබැවින් Super හිඳින්නේ Cmd සැමවිටම සිටි තැනමයි. ඔබේ මාපටැඟිල්ල මෙම මාරුව නොදකිනු ඇත.

### එයට සති දෙකක් දෙන්න

සහජ බුද්ධි ඔබ සිතනවාට වඩා වේගයෙන් මාරු වේ. [කෙටි යතුරු](07-hotkeys.md) පරිච්ඡේදය වරක් කියවා බලන්න, සහ බන්ධනයක් මතක නැති වන සෑම විටම `Super + K` ඔබන්න — එය ඔබට ඒවා සියල්ල පෙන්වයි. එය ඔබ සැබවින්ම කටපාඩම් කළ යුතු එකම හොට්කීයයි.
