# Mac හෝ Windows සිට පැමිණෙන විට

ඔබ වසර ගණනාවක් macOS හෝ Windows මත ගත කර ඇත්නම්, ඔබේ මොළය කවදා හෝ ඉගෙන ගත් බව අමතක කර ඇති දේවල් සියයක් ඔබේ ඇඟිලි දනී. මෙම පරිච්ඡේදය යනු පරිවර්තන ස්ථරයයි: Omarchy තුළ එම සහජ බුද්ධීන් යන්නේ කොහෙටද යන්න. විශේෂාංග ඒවාම වෙනත් තැන්වල ගැඹුරින් ආවරණය කර ඇත — මෙය හුදෙක් සිතියම පමණි.

### Super යනු සියල්ලේම කේන්ද්‍රයයි

Cmd හෝ Windows යතුර වටා ඔබ ගොඩනඟා ගත් සියලුම මාංශ පේශී මතකය එක් යතුරකට මාරු වේ: Super. එය PC යතුරු පුවරුවක ඇති Windows යතුර වන අතර, එය Omarchy හි සෑම hotkey එකක්ම පාහේ සඳහා නැංගුරමයි.

ඔබේ Spotlight හෝ Raycast හෝ Start-menu සහජ ක්‍රියාව `Super + Space` බවට පත්වේ. එය apps දියත් කරන, settings වෙනස් කරන, software ස්ථාපනය කරන, තිරය අල්ලා ගන්නා — සියල්ලම පාහේ කරන Omarchy menu එක විවෘත කරයි. පෙරීමට ටයිප් කිරීම අරඹන්න. `Super + Alt + Space` මඟින් Launchpad කරන ආකාරයටම, සියලුම apps එක් ජාලකයක් මත පෙන්වයි. බලන්න [සංචාලනය](04-navigation.md).

### Desktop icons නැත, සහ dock එක ඈත් වී පවතී

Desktop එක මත සකස් කිරීමට icons නැත, සහ workspace එකක window එකක් ඇති වූ පසු dock එක සැඟවෙන අතර, ඔබ එය ගෙන නොයන්නේ නම් දකුණු අද්දර වන එහි තිරයේ අද්දරට ඔබ pointer එක තල්ලු කරන තුරු එය එසේ පවතී (බලන්න [සංචාලනය](04-navigation.md)). Apps ආරම්භ වන්නේ hotkey එකකින් (`Super + Return` terminal එක සඳහා, `Super + Shift + Return` browser එක සඳහා, සහ සිතියම්ගත කර ඇති සියල්ලේ ලැයිස්තුවක් සඳහා `Super + K`) හෝ menu එකෙනි. එකම ස්ථීර UI අංගය වන්නේ menu bar එක, system tray එක, සහ Notification Center එක මීට පෙර ඔබ වෙනුවෙන් කළ දේ ආවරණය කරන [ඉහළ තීරුව](05-the-top-bar.md) වන අතර, එහි ඇති සෑම widget එකක්ම පාහේ වම්, දකුණු, සහ මැද click කිරීමේදී යමක් කරයි.

### Windows තමන් විසින්ම ස්ථානගත වේ

විශාලතම මානසික මාරුව: ඔබ windows ඇදගෙන යන්නේ නැත හෝ ඒවා තිරයෙන් අඩකට snap කරන්නේ නැත. Window එකක් විවෘත කරන්න, එය මුළු තිරයම ගනී. දෙවැන්නක් විවෘත කරන්න, ඒවා එය බෙදා ගනී. ඔබට කිසි විටෙක වෙනත් එකක් යටින් window එකක් ඇද ගන්නට සිදු නොවේ, මන්ද windows එකිනෙක මත නොවැටෙන බැවිනි.

ඔබට සැබවින්ම floating window එකක් අවශ්‍ය වූ විට, `Super + T` මඟින් සක්‍රිය එක tiling වෙතින් පිටතට (සහ නැවතත්) මාරු කරයි. නමුත් පළමුව tiling වෙත සැබෑ අවස්ථාවක් දෙන්න — එය මුළු දේහිම හදවතයි. [සංචාලනය](04-navigation.md) එය හරහා ඔබව රැගෙන යයි.

Workspaces හුරුපුරුදු ලෙස දැනෙනු ඇත: ඒවා macOS Spaces හෝ Windows virtual desktops වේ, ඇරත් ඔබ ඒවා සැබවින්ම භාවිත කරනු ඇත, මන්ද `Super + 1/2/3/4` කෙලින්ම එකකට පනින අතර `Super + Shift + 1/2/3/4` සක්‍රිය window එක එහි යවන බැවිනි. Animation ප්‍රමාදයක් නැත, හුදෙක් ක්ෂණික පැනීම් පමණි. ඔබ ඊට පෙර ඒ සඳහා පුරුදු වී සිටියේ නම්, ඔබට monitors කිහිපයක්වත් අවශ්‍ය නොවිය හැකි බව මෙයින් අදහස් වේ.

### Copy සහ paste හුදෙක් ක්‍රියා කරයි

Mac මත ඔබ සෑම තැනම Cmd + C භාවිත කළා. Windows මත ඔබ සෑම තැනම Ctrl + C භාවිත කළා — terminal එක හැර, එහිදී එය ඔබේ program එක මරා දමයි. Omarchy ඔබට `Super + C`, `Super + X`, සහ `Super + V` ලබා දෙන අතර, ඒවා terminal එක ඇතුළුව සෑම තැනම ක්‍රියා කරයි. Shell එක සඳහා ඉගෙන ගැනීමට වෙනම සහජ ක්‍රියාවක් නැත.

Windows අය: ඔබේ Win + V clipboard history එක `Super + Ctrl + V` මත පවතින අතර, එය පෙළට මෙන්ම රූපද රඳවා ගනී. බලන්න [ඒකාබද්ධ clipboard සහ ඉතිහාසය](08-unified-clipboard-history.md).

### සමහර දේවල් සැබවින්ම වෙනස්ය

බොහෝ settings ඔබ ක්ලික් කරමින් යන panels වල නොව, ඔබ සංස්කරණය කරන text ගොනු වල පවතී. එයින් අදහස් වන්නේ සෑම tweak එකක්ම දැකිය හැකි, ඔබේ ඊළඟ machine එකට පිටපත් කළ හැකි, සහ version control තුළ තැබිය හැකි බව ඔබ වටහා ගන්නා තුරු එය ප්‍රාථමික ලෙස ඇසෙයි. _Setup_ menu එක ඔබව කෙලින්ම නිවැරදි ගොනුවට දමන අතර, ඔබ අවසන් වූ විට නැවත ආරම්භ කළ යුතු ඕනෑම දෙයක් නැවත ආරම්භ කරයි.

Updates එක් command එකක් හරහා පැමිණේ — _Update > Omarchy_ — එය මුලින්ම snapshot එකක් ගනිමින්, Omarchy ම සහ පද්ධතියේ සෑම package එකක්ම update කරයි. අහඹු ලෙස ඔබට කරදර කරන per-app updaters නැත. බලන්න [updates](30-updates.md).

Software පැමිණෙන්නේ බාගත කළ installers වලින් නොව, package manager එකකිනි.

තවද ඔබ window එකක් වැසූ විට, app එක සැබවින්ම ඉවත් වේ. Windows කිසිවක් නොමැතිව program එක දිගටම ක්‍රියාත්මක වන macOS limbo එකක් නැත. `Super + W` — හෝ, ඔබ පැමිණියේ එම ඇඟිලි මතකය සමඟ නම්, `Super + Q` — යනු ගිය බවයි.

### Mac hardware මත

Omarchy Intel Macs මත හොඳින් ක්‍රියා කරන අතර, Omarchy for Apple Silicon සමඟ M1, M2 සහ M3 Macs මතද ක්‍රියා කරයි. බලන්න [Mac සහාය](44-mac-support.md). තවද keyboard එක ඔබට කරුණාවන්තයි: Omarchy කිසිවක් remap කරන්නේ නැත, සහ Linux විසින් Command යතුර Super ලෙස සලකන බැවින්, Super පවතින්නේ Cmd සැමවිටම තිබූ තැනමයි. ඔබේ මහපටැඟිල්ල මාරුව නොදකිනු ඇත.

### එයට සති දෙකක් දෙන්න

සහජ බුද්ධීන් ඔබ සිතනවාට වඩා වේගයෙන් මාරු වේ. [hotkeys](07-hotkeys.md) පරිච්ඡේදය වරක් සැහැල්ලුවෙන් කියවා බලන්න, සහ binding එකක් මත blank වූ සෑම විටම, `Super + K` ඔබන්න — එය ඔබට ඒවා සියල්ලම පෙන්වයි. එය ඔබ සැබවින්ම මතක තබා ගත යුතු එකම hotkey එකයි.
