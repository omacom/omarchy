# Mac හෝ Windows සිට පැමිණෙන විට

ඔබ වසර ගණනාවක් macOS හෝ Windows මත ගත කර ඇත්නම්, ඔබේ මොළය කවදා හෝ ඉගෙන ගත් බව අමතක කර ඇති දේවල් සියයක් ඔබේ ඇඟිලි දනී. මෙම පරිච්ඡේදය ඒ පරිවර්තන ස්ථරයයි: Omarchy තුළ එම සහජ බුද්ධීන් යන්නේ කොහෙටද කියා. විශේෂාංග ගැනම වෙනත් තැන්වල ගැඹුරින් ආවරණය කර ඇත — මෙය හුදෙක් සිතියම පමණි.

### Super යනු සියල්ලේම කේන්ද්‍රයයි

Cmd හෝ Windows යතුර වටා ඔබ ගොඩනඟා ගත් සියලුම මාංශ මතකය එක් යතුරකට මාරු වේ: Super. එය PC යතුරුපුවරුවක ඇති Windows යතුරයි, එය Omarchy හි සෑම hotkey එකකටම පාහේ නැංගුරමයි.

ඔබේ Spotlight හෝ Raycast හෝ Start-menu ප්‍රතික්‍රියාව `Super + Space` බවට පත්වේ. එය Omarchy මෙනුව විවෘත කරයි, එය apps දියත් කරයි, settings වෙනස් කරයි, software ස්ථාපනය කරයි, තිරය ග්‍රහණය කරයි — සෑම දෙයක්ම පාහේ. පෙරහන් කිරීමට ටයිප් කිරීම අරඹන්න. `Super + Alt + Space` මඟින් සියලුම apps එක් ජාලකයක පෙන්වයි, Launchpad කරන ආකාරයටම. [සංචාලනය](04-navigation.md) බලන්න.

### Desktop icons නැත, ඔබ float කරන විට පමණක් dock එක මතුවේ

Desktop එක මත සකස් කිරීමට icons නැත, tiling workspace එකක dock එකක් නැත — dock එක මතුවන්නේ floating workspace එකක පමණි (බලන්න [සංචාලනය](04-navigation.md)). Apps ඇරඹෙන්නේ hotkey එකකින් (terminal එක සඳහා `Super + Return`, browser එක සඳහා `Super + Shift + Return`, සහ සිතියම්ගත කර ඇති සියල්ලේම ලැයිස්තුවක් සඳහා `Super + K`) හෝ මෙනුවෙන්. නොනැසී පවතින එකම UI කොටස [ඉහළ තීරුව](05-the-top-bar.md) වන අතර, එය ඔබට මීට පෙර menu bar, system tray, සහ Notification Center කළ දේ ආවරණය කරයි — එහි ඇති සෑම widget එකක්ම පාහේ වම් ක්ලික්, දකුණු ක්ලික්, සහ මැද ක්ලික් මත යමක් කරයි.

### Windows තමන් විසින්ම ස්ථානගත වේ

විශාලතම මානසික මාරුව: ඔබ windows එහෙ මෙහෙ අදින්නේ නැත හෝ තිර අර්ධවලට snap කරන්නේ නැත. Window එකක් විවෘත කරන්න, එය මුළු තිරයම ගනී. දෙවැන්නක් විවෘත කරන්න, ඒවා එය බෙදා ගනී. ඔබ කිසිදා තවත් එකක් යටින් window එකක් ඇද ගන්නේ නැත, මන්ද windows අතිච්ඡාදනය නොවන බැවිනි.

ඔබට සැබවින්ම floating window එකක් අවශ්‍ය වූ විට, `Super + T` සක්‍රිය එක tiling වලින් පිටතට (සහ ආපසු) මාරු කරයි. නමුත් මුලින් tiling වලට සැබෑ අවස්ථාවක් දෙන්න — එය මුළු දේහිම හදවතයි. [සංචාලනය](04-navigation.md) ඔබව එය හරහා ගෙන යයි.

Workspaces හුරුපුරුදු බවක් දැනේවි: ඒවා macOS Spaces හෝ Windows virtual desktops ය, නමුත් ඔබ ඒවා සැබවින්ම භාවිතා කරාවි, මන්ද `Super + 1/2/3/4` කෙලින්ම එකකට පනින අතර `Super + Shift + 1/2/3/4` සක්‍රිය window එක එහි යවයි. Animation ප්‍රමාදයක් නැත, ක්ෂණික පිමි පමණි. මෙයින් අදහස් වන්නේ, ඔබ මීට පෙර ඒවාට හුරු වී සිටියා නම්, ඔබට බහු monitors පවා අවශ්‍ය නොවිය හැකි බවයි.

### Copy සහ paste නිකම්ම ක්‍රියා කරයි

Mac එකේ ඔබට සෑම තැනම Cmd + C තිබුණි. Windows මත ඔබට සෑම තැනම Ctrl + C තිබුණි — terminal එක හැර, එහිදී එය ඔබේ program එක මරා දමයි. Omarchy ඔබට `Super + C`, `Super + X`, සහ `Super + V` ලබා දෙයි, ඒවා terminal එක ඇතුළුව සෑම තැනම ක්‍රියා කරයි. Shell එක සඳහා වෙනම ප්‍රතික්‍රියාවක් ඉගෙන ගැනීමට නැත.

Windows අය සඳහා: ඔබේ Win + V clipboard history `Super + Ctrl + V` මත ජීවත් වේ, එය පෙළ මෙන්ම රූපද රඳවා ගනී. [ඒකාබද්ධ clipboard සහ ඉතිහාසය](08-unified-clipboard-history.md) බලන්න.

### සමහර දේවල් සැබවින්ම වෙනස්ය

බොහෝ settings ඔබ ක්ලික් කරමින් යන panels තුළ නොව, ඔබ සංස්කරණය කරන text files තුළ ජීවත් වේ. එය ප්‍රාථමික යැයි ඇසෙයි, සෑම tweak එකක්ම දැකිය හැකි, ඔබේ ඊළඟ machine එකට පිටපත් කළ හැකි, සහ version control තුළ තැබිය හැකි බව ඔබ වටහා ගන්නා තුරු. _Setup_ මෙනුව ඔබව කෙලින්ම නිවැරදි file එකට දමයි, ඔබ අවසන් කළ විට නැවත ආරම්භ කළ යුතු ඕනෑම දෙයක් නැවත ආරම්භ කරයි.

Updates එක් command එකක් හරහා එයි — _Update > Omarchy_ — එය Omarchy ම සහ පද්ධතියේ සෑම package එකක්ම යාවත්කාලීන කරයි, මුලින්ම snapshot එකක් ගනිමින්. අහඹු ලෙස ඔබට කරදර කරන per-app updaters නැත. [යාවත්කාලීන කිරීම්](30-updates.md) බලන්න.

Software එන්නේ package manager එකකින් මිස, බාගත කළ installers වලින් නොවේ.

ඔබ window එකක් වසා දැමූ විට, app එක සැබවින්ම ඉවත් වේ. Program එක windows නැතිව දිගටම ධාවනය වන macOS limbo එකක් නැත. `Super + W` — හෝ ඔබ පැමිණියේ ඒ ඇඟිලි මතකය සමඟ නම්, `Super + Q` — යනු ගියේය යන්නයි.

### Mac hardware මත

Omarchy Intel Macs මත හොඳින් ධාවනය වේ — [Mac සහාය](44-mac-support.md) බලන්න. යතුරුපුවරුව ඔබට කරුණාවන්තය: Omarchy කිසිවක් remap කරන්නේ නැත, Linux Command යතුර Super ලෙස සලකයි, එබැවින් Super Cmd සැමවිටම තිබූ තැනම පිහිටයි. ඔබේ මහපටඟිල්ලට එම මාරුව නොදැනේවි.

### සති දෙකක් දෙන්න

සහජ බුද්ධීන් ඔබ සිතනවාට වඩා වේගයෙන් මාරු වේ. [hotkeys](07-hotkeys.md) පරිච්ඡේදය වරක් කියවා බලන්න, ඔබට binding එකක් මත blank වූ සෑම විටම, `Super + K` ඔබන්න — එය ඔබට ඒවා සියල්ල පෙන්වයි. එය ඔබ සැබවින්ම මතක තබා ගත යුතු එකම hotkey එකයි.
