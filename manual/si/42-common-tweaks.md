# පොදු ගැලපීම්

මෙය Omarchy සැකසුම සඳහා පොදු අභිරුචිකරණයන්ගේ එකතුවකි. පද්ධති යාවත්කාලීන කිරීම්වලට සමහර වින්‍යාසයන් ඒවායේ මුල් තත්ත්වයට යළි පිහිටුවීම ඉඳහිට අවශ්‍ය විය හැකි බව දැන ගන්න. මෙය සිදු වුවහොත්, ඔබේ වෙනස්කම් නැති නොවේ, නමුත් එම ඩිරෙක්ටරියේම `.bak` ගොනුවක තබනු ලැබේ.

ඔබ යමක් නරක් කළහොත්, Omarchy මෙනුවේ _යාවත්කාලීන > වින්‍යාසය_ හරහා තනි වින්‍යාසයන් ඒවායේ මුල් සැකසුමට යළි පිහිටුවිය හැකිය. ඔබ සියල්ලම _ඇත්තෙන්ම_ නරක් කළහොත්, `omarchy-reinstall` හරහා සියලු වින්‍යාසයන් යළි පිහිටුවිය හැකිය.

### සියලු ට්‍රේ අයිකන සෑම විටම හෙළි කරන්න

පෙරනිමියෙන්, Dropbox, 1password, හෝ Steam වැනි ට්‍රේ අයිකන ට්‍රේ විස්තාරක ඊතලය පිටුපස සැඟවී ඇති අතර, ඔබ එය මත සැරිසරන විට ඒවා හෙළි කරයි. ඔබ ඒවා සෑම විටම නිරාවරණය වී තිබීමට කැමති නම්, ට්‍රේ අයිකන කළමනාකරු විවෘත කිරීමට විස්තාරක ඊතලය දකුණු-ක්ලික් කරන්න, පසුව ඔබ දිගටම දිස්වීමට කැමති අයිකන අමුණන්න (ඔබට කිසි විටෙක දැකීමට අවශ්‍ය නැති ඒවා ද සැඟවිය හැකිය).

### වටකුරු කවුළු කොන්

Omarchy හි පෙරනිමි නිර්මාණය හතරැස් කොන් ය, නමුත් ඔබ එය තරමක් මෘදු කිරීමට කැමති නම්, වටකිරීම තවදුරටත් අදහස් දක්වා නොමැති වන පරිදි ඔබට `~/.config/hypr/looknfeel.lua` වෙනස් කළ හැකිය:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### කවුළු හිඩැස් ඉවත් කරන්න

ලැප්ටොප් සංදර්ශකවල, සමහර අය කවුළු හිඩැස් (හෝ `Super + Shift + Space` මගින් ඔබට අක්‍රිය කළ හැකි ඉහළ තීරුව පවා) මත කිසිදු පික්සලයක් අපතේ නොහැරීමට කැමතියි. ඔබට `Super + Shift + Backspace` මගින් සියලු හිඩැස් සහ දාර අක්‍රිය කළ හැකිය, නැතහොත් `~/.config/hypr/looknfeel.lua` හි මෙම කොටසේ අදහස් ඉවත් කිරීමෙන් ඒවා ස්ථිරවම ඉවත් කළ හැකිය:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
