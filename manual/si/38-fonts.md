# අකුරු මුහුණත්

Omarchy පෙරනිමියෙන් terminal එක සහ system font එක යන දෙකටම JetBrainsMono Nerd Font භාවිතා කරයි.

 ![fonts-jetbrainsmono](images/fonts-jetbrainsmono.webp)

Omarchy menu එකේ (`Super + Space`) _පෙනුම > අකුරු මුහුණත_ menu එක හරහා ඔබට මෙය වෙනස් කළ හැකිය. එය monospace font එක සෑම තැනකම සකසයි: terminal එක, bar එක, සහ එය ඉල්ලන වෙනත් ඕනෑම දෙයක්.

Omarchy menu එකේ _ස්ථාපනය > විලාසය > අකුරු මුහුණත_ හරහා ඔබට වෙනත් ජනප්‍රිය programming fonts ස්ථාපනය කළ හැකිය: Cascadia Mono, Meslo LG Mono, Fira Code, Victor Code, Bitstream Vera Mono, සහ Iosevka සියල්ලම එක ක්ලික් එකක් දුරින් ඇත, bar එකේ සහ terminal එකේ glyphs දිගටම ක්‍රියා කරන පරිදි ඒවායේ Nerd Font අනුවාදවලින්. එකක් ස්ථාපනය කිරීමෙන් මුළු system එකම එයට මාරු වන අතර, _පෙනුම > අකුරු මුහුණත_ යටතේ ඕනෑම වේලාවක ඔබට ආපසු මාරු විය හැකිය.

## චීන, ජපන්, සහ කොරියානු

චීන, ජපන්, සහ කොරියානු භාෂා බොහෝ අක්ෂර බෙදා ගත්තත් ඒවායින් සමහරක් වෙනස් ලෙස අඳින බැවින්, එකම අක්ෂරය එක් කියවන්නෙකුට නිවැරදි ලෙසත් තවත් අයෙකුට ආගන්තුක ලෙසත් පෙනේ. _සැකසුම > කලාපය > භාෂාව_ යටතේ මෙම භාෂාවලින් එකක් හෝ එහි input method එක තෝරා ගැනීමෙන් ගැළපෙන ආකාර සකසයි. ඒවා ඔබම තෝරා ගැනීමට, terminal එකක `omarchy font cjk jp`, `kr`, `sc`, `tc` (Taiwan), හෝ `hk` (Hong Kong) ධාවනය කරන්න; `omarchy font cjk default` මඟින් system එකේ තේරීමට ආපසු යයි, එය ජපන් ආකාර වේ. වෙබ් පිටුවක් හෝ ලේඛනයක් තමන්ගේම භාෂාවෙන් සලකුණු කරන පෙළ, සහ මුළු desktop එකම මෙම භාෂාවලින් එකක පවතින අතරතුර, එම භාෂාවේ ආකාර රඳවා ගනී.
