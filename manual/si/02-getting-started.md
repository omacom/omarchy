# ආරම්භ කිරීම

Omarchy ස්ථාපනය කරනු ලබන්නේ ISO එකක් භාවිතා කරමිනි. ඔබට සම්පූර්ණ ධාවකයම අත්පත් කර ගන්නා සම්පූර්ණ-තැටි ස්ථාපනය හෝ ධාවකයක වෙන් නොකළ ඉඩ තුළ Omarchy තබන නිදහස්-ඉඩ ස්ථාපනය අතරින් තෝරා ගත හැකිය — Windows හෝ වෙනත් OS එකක් සමඟ ද්විත්ව ඇරඹුමක් කරන්නේ එලෙසිනි ([ද්විත්ව-ඇරඹුම් ස්ථාපනය](50-dual-boot-install.md) බලන්න — ඔබ මුලින්ම Windows තුළ BitLocker අක්‍රිය කළ යුතු බව සලකන්න). ඕනෑම ආකාරයකින්, ස්ථාපනය පෙරනිමියෙන්ම සම්පූර්ණ සංකේතනයට සැකසී ඇති අතර, සම්පූර්ණ-තැටි විකල්පය තෝරාගත් ධාවකය සම්පූර්ණයෙන්ම මකා දමනු ඇත, එබැවින් දැනට පවතින ධාවකයක් භාවිතා කිරීමට පෙර අනිවාර්යයෙන්ම උපස්ථයක් ගන්න!

මුලින්ම [Omarchy ISO එක බාගත කර](https://omarchy.org/), එය USB stick එකකට දමා (Windows මත [Rufus](https://rufus.ie/), Mac මත [balenaEtcher](https://etcher.balena.io/), හෝ Linux මත [caligula](https://github.com/ifd3f/caligula) භාවිතා කරන්න), එම stick එකෙන් boot කරන්න.

ඔබ වෙනත් අයෙකු සඳහා — පවුලේ සාමාජිකයෙකු, නව සේවකයෙකු, ගැනුම්කරුවෙකු සඳහා — යන්ත්‍රයක් සකසන්නේ නම්, ඔවුන් වෙනුවෙන් පෞද්ගලික ප්‍රශ්නවලට ඔබ පිළිතුරු නොදිය යුතුය. ස්ථාපකයේ මුල්ම තිරයේ (යතුරුපුවරු තේරීමේ) `Ctrl + C` ඔබන්න, එවිට Omarchy ඒ වෙනුවට යන්ත්‍රය වෙනත් අයිතිකරුවෙකු සඳහා සූදානම් කිරීමට ඉදිරිපත් වනු ඇත. පද්ධතිය වහාම ස්ථාපනය වන නමුත්, සියලුම පෞද්ගලික සැකසුම් — යතුරුපුවරු සැකැස්ම, පරිශීලක නාමය, මුරපදය — යන්ත්‍රය පළමු වරට boot වන තෙක් කල් දමනු ලැබේ. ධාවකය තවමත් පෙරනිමියෙන්ම සංකේතනය කර ඇති අතර, නව අයිතිකරු එම පළමු boot වීමේදී තෝරා ගන්නා මුරපදය සංකේතන මුරපදයද බවට පත්වේ. (ඔබ දැනටමත් භාවිතා කරමින් සිටි යන්ත්‍රයක් නැවත ස්ථාපනය කිරීමකින් තොරවම භාර දිය හැකිය — [පරිගණකය යළි සැකසීම](48-security.md) බලන්න.)

### සංකේතනය රහිත ස්ථාපන

Omarchy පෙරනිමියෙන්ම සංකේතනය සමඟ ස්ථාපනය වේ. නැති වීමට හෝ සොරකම් වීමට ඉඩ ඇති ඕනෑම පරිගණකයක් සඳහා එය ආරක්ෂිත, වගකිවයුතු තේරීමයි. ඔබේ දෘඩාංග වෙත ප්‍රවේශය ඇති කිසිවෙකුට ඔබේ දත්ත ලබා ගැනීමට හැකි වීම ඔබ නොකැමති වනු ඇත!

නමුත් ආරක්ෂිත පරිගණකවල දුරස්ථ Omarchy ස්ථාපන හෝ සංවේදී දත්ත නොමැති ඉවත දැමිය හැකි ස්ථාපන වැනි විශේෂ අවස්ථාවලදී, ඔබට සංකේතනයකින් තොරව ස්ථාපනය කිරීමට අවශ්‍ය විය හැකිය. සංකේතනය රහිත ස්ථාපනයකට මාරු වීමට තැටිය format කිරීම තහවුරු කරන තැනදී ඔබට `Ctrl + C` එබිය හැකිය.

### භාෂාව

Omarchy භාෂා 50ක් කතා කරයි — omarchy.org හි ඇති එම කට්ටලයම වන අතර, English යනු පෙරනිමියයි. මාරු වීමට, Omarchy මෙනුව විවෘත කර _සැකසුම > කලාපය > භාෂාව_ වෙත යන්න, නැතහොත් terminal එකක `omarchy language <code>` ධාවනය කරන්න (`omarchy language list` මඟින් කේත පෙන්වයි). මෙනුව, desktop එක සහ Omarchy හිම දැනුම්දීම් වහාම භාෂාව වෙනස් කරන අතර, ඉන්පසුව ඔබ විවෘත කරන සෑම application එකක්ම ඒ අනුව හැසිරේ. දැනටමත් විවෘතව ඇති apps ඔබ ඒවා නැවත ආරම්භ කළ පසු මාරු වේ.

භාෂාව එලෙසම තබා ගනිමින් දින, වේලාවන්, අංක, මුදල්, ඒකක සහ කඩදාසි ප්‍රමාණ වෙනත් කලාපයක ආකාරයෙන් ලිවීමට (උදාහරණයක් ලෙස, යුරෝපීය දින සහ පැය 24 ඔරලෝසුවක් සහිත English), _සැකසුම > කලාපය > ආකෘති_ යටතේ කලාපයක් තෝරන්න, එහිදී සෑම තේරීමක්ම සාම්පලයක් පෙන්වයි, නැතහොත් `omarchy region formats <code>` ධාවනය කරන්න (`omarchy region formats list` මඟින් කේත පෙන්වයි). _භාෂාවට සමානම_ මඟින් භාෂාවේම ආකෘති වෙත ආපසු යයි. භාෂා මාරුවක් මෙන්ම, එය ඉන්පසුව ඔබ විවෘත කරන apps වෙත බලපායි.
