# ආරම්භ කිරීම

Omarchy ස්ථාපනය කරන්නේ ISO එකක් භාවිතා කරමිනි. ඔබට සම්පූර්ණ drive එකම අත්පත් කර ගන්නා full-disk ස්ථාපනයක් හෝ, drive එකක වෙන් නොකළ ඉඩ තුළ Omarchy තබන free-space ස්ථාපනයක් අතරින් තෝරා ගත හැකිය — Windows හෝ වෙනත් OS එකක් සමඟ dual boot කරන්නේ එලෙසිනි (බලන්න [dual-boot ස්ථාපනය](50-dual-boot-install.md) — ඔබට Windows හි BitLocker පළමුව අක්‍රිය කිරීමට අවශ්‍ය වන බව සලකන්න). කුමන ක්‍රමය තෝරා ගත්තත්, ස්ථාපනය පෙරනිමියෙන්ම සම්පූර්ණ encryption එකකට යොමු වන අතර, full-disk විකල්පය තෝරා ගත් drive එක සම්පූර්ණයෙන්ම මකා දමනු ඇත, එබැවින් දැනට පවතින එකක් භාවිතා කිරීමට පෙර backup එකක් ගැනීමට වග බලා ගන්න!

Apple Silicon Mac එකක, ඔබ ස්ථාපනය කරන්නේ macOS වෙතින් වන අතර, ISO එකක් හෝ USB stick එකක් අවශ්‍ය නොවේ. බලන්න [Apple Silicon සඳහා Omarchy](44-mac-support.md#omarchy-for-apple-silicon).

පළමුව [Omarchy ISO එක බාගන්න](https://omarchy.org/), එය USB stick එකකට දාන්න (Windows මත [Rufus](https://rufus.ie/), Mac මත [balenaEtcher](https://etcher.balena.io/), හෝ Linux මත [caligula](https://github.com/ifd3f/caligula) භාවිතා කරන්න), සහ stick එකෙන් boot කරන්න.

_ඔබ BIOS තුළ Secure Boot සහ/හෝ TPM අක්‍රිය කළ යුතුය. Omarchy ස්ථාපනය කිරීමට හැකි වීමට නම් ඔබට මේවා අක්‍රිය කළ යුතුය. ඒවා Windows සහ Microsoft සමඟ අනුබද්ධ Linux distributions සඳහා අදහස් කරන ලද Microsoft ආරක්ෂක ක්‍රමවේදයන්ය._

ඉන්පසු වින්‍යාස ප්‍රශ්නවලට පිළිතුරු දී, මේ ආකාරයට ඒවා තහවුරු කරන්න:

 ![install-config](images/install-config.webp)

ඉන්පසු ඔබේ ස්ථාපනය සඳහා drive එකක් තෝරන්න, සහ ස්ථාපන සංදර්ශනය නැරඹීමට ඉඳගන්න. වේගවත්ම නවීන යන්ත්‍රවල එය මිනිත්තුවකට අඩු කාලයකින් කළ හැකි නමුත්, පැරණි පරිගණකයක වුවද එයට මිනිත්තු 5කට වැඩි කාලයක් ගත නොවිය යුතුය.

 ![install-done](images/install-done.webp)

දැන් ඔබ Omarchy භාවිතයට සූදානම්!

### වයර් සහිත හෝ 2.4ghz keyboard එකක් භාවිතා කරන්න!

සම්පූර්ණ-disk encryption එක ආරම්භයේදී Bluetooth keyboard එකකින් password එක ඇ dimතුළත් කිරීමට ඔබට ඉඩ නොදෙනු ඇත. හරියට PC එකක BIOS එකට ඇතුළු වීමට Bluetooth keyboard එකක් භාවිතා කළ නොහැකි ආකාරයටමය. ඔබට 2.4ghz dongle එකක් හෝ cable එකක් භාවිතා කරන keyboard එකක් අවශ්‍ය වනු ඇත (කෙසේ වෙතත් latency අතින් cable එක බොහෝ සෙයින් හොඳය!). මම පෞද්ගලිකවම [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard) එකට බොහෝ සෙයින් කැමතියි!

### වෙනත් හිමිකරුවෙකු සඳහා ස්ථාපනය කිරීම

ඔබ වෙනත් කෙනෙකු සඳහා — පවුලේ සාමාජිකයෙකු, නව සේවකයෙකු, ගැනුම්කරුවෙකු සඳහා — යන්ත්‍රයක් සූදානම් කරන්නේ නම්, ඔබ ඔවුන් වෙනුවෙන් පෞද්ගලික ප්‍රශ්නවලට පිළිතුරු නොදිය යුතුය. ස්ථාපකයේ ඉතාමත් පළමු තිරයේදී (keyboard තේරීමේදී) `Ctrl + C` ඔබන්න, එවිට Omarchy ඒ වෙනුවට යන්ත්‍රය වෙනත් හිමිකරුවෙකු සඳහා සූදානම් කිරීමට ඉදිරිපත් වනු ඇත. පද්ධතිය වහාම ස්ථාපනය වන නමුත්, සියලුම පෞද්ගලික සැකසුම් — keyboard layout, username, password — යන්ත්‍රය පළමු වරට boot වන තෙක් කල් දමනු ලැබේ. Drive එක තවමත් පෙරනිමියෙන්ම encrypted වන අතර, නව හිමිකරු එම පළමු boot එකේදී තෝරා ගන්නා password එකම encryption password එක බවටද පත් වේ. (ඔබ දැනටමත් භාවිතා කරමින් සිටි යන්ත්‍රයක් නැවත ස්ථාපනයකින් තොරවද භාර දිය හැකිය — බලන්න [පරිගණකය යළි සැකසීම](48-security.md).)

### මැදිහත්වීමකින් තොර ස්ථාපනයන්

ISO එකට එහි වින්‍යාසය දෙවන drive එකකින් ලබා දුන් විට එය සම්පූර්ණයෙන්ම තනිවමද — keyboard එකක් නැත, wizard එකක් නැත — ස්ථාපනය විය හැකිය. Omarchy, VM සහ fleet යන්ත්‍ර සඳහා base image එකක් ලෙස සලකන්නේ එලෙසිනි. බලන්න [මැදිහත්වීමකින් තොර ස්ථාපනයන්](51-unattended-installs.md).

### encryption රහිත ස්ථාපනයන්

Omarchy පෙරනිමියෙන්ම encryption සමඟ ස්ථාපනය වේ. නැති වීමට හෝ සොරකම් කිරීමට ඉඩ ඇති ඕනෑම පරිගණකයක් සඳහා එය ආරක්ෂිත, වගකීම් සහිත තේරීමයි. ඔබේ දෘඩාංග වෙත ප්‍රවේශය ඇති කිසිවෙකුට ඔබේ දත්ත ලබා ගැනීමට හැකි වීම ඔබ අකමැති වනු ඇත!

නමුත් විශේෂ අවස්ථාවලදී, ආරක්ෂිත පරිගණකවල දුරස්ථ Omarchy ස්ථාපනයන් මෙන් හෝ සංවේදී දත්ත නොමැති ඉවත දැමිය හැකි ස්ථාපනයන් සඳහා, ඔබට encryption නොමැතිව ස්ථාපනය කිරීමට අවශ්‍ය විය හැකිය. encryption රහිත ස්ථාපනයකට මාරු වීමට disk formatting තහවුරු කිරීමේදී ඔබට `Ctrl + C` එබිය හැකිය.

### භාෂාව

Omarchy භාෂා 50කින් කථා කරයි — omarchy.org හි ඇති එම කට්ටලයම — සහ English පෙරනිමිය වේ. මාරු වීමට, Omarchy menu එක විවෘත කර _Setup > Region > Language_ වෙත යන්න, හෝ terminal එකක `omarchy language <code>` ධාවනය කරන්න (`omarchy language list` මඟින් codes පෙන්වයි). Menu එක, desktop එක, සහ Omarchy හිම දැනුම්දීම් වහාම භාෂාව වෙනස් කරන අතර, ඉන්පසුව ඔබ විවෘත කරන සෑම application එකක්මද එය අනුගමනය කරයි. දැනටමත් විවෘතව තිබූ Apps ඔබ ඒවා restart කළ පසු මාරු වේ.

භාෂාව එලෙසම තබා ගනිමින්, වෙනත් කලාපයක් කරන ආකාරයට දිනයන්, වේලාවන්, අංක, මුදල්, ඒකක සහ කඩදාසි ප්‍රමාණයන් ලිවීමට (උදාහරණයක් ලෙස, European දිනයන් සහ පැය 24 ඔරලෝසුවක් සහිත English), _Setup > Region > Formats_ යටතේ කලාපයක් තෝරන්න, එහිදී සෑම තේරීමක්ම සාම්පලයක් පෙන්වයි, හෝ `omarchy region formats <code>` ධාවනය කරන්න (`omarchy region formats list` මඟින් codes පෙන්වයි). _Same as language_ මඟින් භාෂාවේම formats වෙත නැවත යයි. භාෂා මාරුවක් මෙන්ම, එය ඉන්පසුව ඔබ විවෘත කරන apps වෙත ළඟා වේ.
