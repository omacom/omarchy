Omarchy ස්ථාපනය කරන්නේ ISO එකක් භාවිතා කරමිනි. සම්පූර්ණ drive එකම අත්පත් කරගන්නා සම්පූර්ණ-තැටි ස්ථාපනයක් හෝ drive එකක වෙන් නොකළ ඉඩ තුළ Omarchy තබන නිදහස්-ඉඩ ස්ථාපනයක් අතරින් ඔබට තෝරා ගත හැකිය — Windows හෝ වෙනත් OS එකක් සමඟ dual boot කරන්නේ එලෙසයි ([ද්විත්ව ඇරඹුම් ස්ථාපනය](50-dual-boot-install.md) බලන්න — පළමුව Windows තුළ BitLocker අක්‍රිය කිරීමට ඔබට සිදු වන බව සලකන්න). කෙසේ වෙතත්, ස්ථාපනය පෙරනිමියෙන් සම්පූර්ණ සංකේතනයෙන් යුතු වන අතර, සම්පූර්ණ-තැටි විකල්පය තෝරාගත් drive එක මකා දමනු ඇත, එබැවින් පවතින එකක් භාවිතා කිරීමට පෙර උපස්ථයක් ගන්නා බවට වග බලා ගන්න!

පළමුව [Omarchy ISO එක බාගන්න](https://omarchy.org/), එය USB stick එකකට දාන්න (Mac/Windows හි [balenaEtcher](https://etcher.balena.io/) හෝ Linux හි [caligula](https://github.com/ifd3f/caligula) භාවිතා කරන්න), සහ stick එකෙන් boot කරන්න.

### අධීක්ෂණයකින් තොර ස්ථාපනයන්

නමුත් ආරක්ෂිත පරිගණකවල දුරස්ථ Omarchy ස්ථාපනයන් වැනි හෝ සංවේදී දත්ත රහිත ඉවත දැමිය හැකි ස්ථාපනයන් සඳහා වැනි විශේෂ තත්ත්වයන් තුළ, සංකේතනයකින් තොරව ස්ථාපනය කිරීමට ඔබට අවශ්‍ය විය හැකිය. සංකේතනයෙන් තොර ස්ථාපනයකට මාරු වීමට ඔබට තැටි ආකෘතිකරණ තහවුරු කිරීමේදී `Ctrl + C` එබිය හැකිය.

Omarchy භාෂා 50ක් කතා කරයි — omarchy.org හි මෙන් එකම කට්ටලය — සහ ඉංග්‍රීසි පෙරනිමි භාෂාවයි. මාරු වීමට, Omarchy මෙනුව විවෘත කර _සැකසීම > භාෂාව_ වෙත යන්න, නැතහොත් terminal එකක `omarchy language <code>` ධාවනය කරන්න (`omarchy language list` මඟින් කේත පෙන්වයි). මෙනුව, desktop එක සහ Omarchy හිම දැනුම්දීම් වහාම භාෂාව වෙනස් කරන අතර, ඉන්පසුව ඔබ විවෘත කරන සෑම යෙදුමක්මද එය අනුගමනය කරයි. දැනටමත් විවෘතව තිබූ යෙදුම්, ඔබ ඒවා නැවත ආරම්භ කළ පසු මාරු වේ.
