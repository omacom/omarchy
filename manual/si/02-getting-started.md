# ආරම්භ කිරීම

Omarchy ස්ථාපනය කරන්නේ ISO එකක් භාවිතයෙනි. ඔබට සම්පූර්ණ තැටියම අත්පත් කර ගන්නා full-disk ස්ථාපනයක් හෝ, ධාවකයක වෙන් නොකළ ඉඩ තුළ Omarchy තබන free-space ස්ථාපනයක් අතරින් තෝරා ගත හැකිය — Windows හෝ වෙනත් OS එකක් සමඟ dual boot කරන්නේ එලෙසිනි (බලන්න [dual-boot ස්ථාපනය](50-dual-boot-install.md) — Windows හි BitLocker කලින් අක්‍රිය කළ යුතු බව සලකන්න). කෙසේ වුවත්, ස්ථාපනය පෙරනිමියෙන් full encryption සමඟ එන අතර, full-disk විකල්පය තෝරාගත් ධාවකය මකා දමනු ඇත, එබැවින් පවතින එකක් භාවිත කිරීමට පෙර උපස්ථයක් ගැනීමට වග බලා ගන්න!

පළමුව [Omarchy ISO එක බාගත කරන්න](https://omarchy.org/), එය USB stick එකකට දාන්න (Windows හි [Rufus](https://rufus.ie/), Mac හි [balenaEtcher](https://etcher.balena.io/), හෝ Linux හි [caligula](https://github.com/ifd3f/caligula) භාවිත කරන්න), සහ stick එකෙන් boot කරන්න.

_ඔබ BIOS හි Secure Boot සහ/හෝ TPM අක්‍රිය කළ යුතුය. Omarchy ස්ථාපනය කිරීමට හැකි වීමට නම් ඔබ මේවා අක්‍රිය කළ යුතුමය. ඒවා Windows සහ Microsoft සමඟ අනුබද්ධ Linux distributions සඳහා අදහස් කරන ලද Microsoft ආරක්ෂක ක්‍රමවේදයන්ය._

ඉන්පසු වින්‍යාස ප්‍රශ්නවලට පිළිතුරු දී, මෙලෙස ඒවා තහවුරු කරන්න:

 ![install-config](images/install-config.webp)

ඉන්පසු ඔබේ ස්ථාපනය සඳහා ධාවකයක් තෝරා, සැහැල්ලුවෙන් සිට ස්ථාපන සංදර්ශනය ඉදිරියට යන අයුරු නරඹන්න. වේගවත්ම නවීන යන්ත්‍රවල එය මිනිත්තුවකට අඩු කාලයකින් අවසන් කළ හැකි නමුත්, පැරණි පරිගණකයක වුවද එය විනාඩි 5කට වඩා ගත නොවිය යුතුය.

### වයර් සහිත හෝ 2.4ghz keyboard එකක් භාවිත කරන්න!

full-disk encryption නිසා ආරම්භයේදී Bluetooth keyboard එකකින් මුරපදය ඇතුළත් කිරීමට ඔබට ඉඩ නොලැබේ. PC එකක BIOS එකට ඇතුළු වීමට Bluetooth keyboard එකක් භාවිත කළ නොහැකිවාක් මෙනි. 2.4ghz dongle එකක් හෝ cable එකක් භාවිත කරන keyboard එකක් ඔබට අවශ්‍ය වනු ඇත (කෙසේ වුවත් ප්‍රමාදය අතින් cable එක බෙහෙවින් හොඳය!). මම පෞද්ගලිකව [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard) එකට බෙහෙවින් කැමතියි!

### වෙනත් හිමිකරුවෙකු සඳහා ස්ථාපනය කිරීම

ඔබ වෙනත් අයෙකු සඳහා — පවුලේ සාමාජිකයෙකු, නව සේවකයෙකු, ගැනුම්කරුවෙකු සඳහා — යන්ත්‍රයක් සූදානම් කරන්නේ නම්, ඔවුන් වෙනුවෙන් පුද්ගලික ප්‍රශ්නවලට පිළිතුරු නොදිය යුතුය. ස්ථාපකයේ මුල්ම තිරයේ (keyboard තේරීමේ) `Ctrl + C` ඔබන්න, එවිට Omarchy විසින් ඒ වෙනුවට වෙනත් හිමිකරුවෙකු සඳහා යන්ත්‍රය සූදානම් කිරීමට ඉදිරිපත් වනු ඇත. පද්ධතිය වහාම ස්ථාපනය වන නමුත්, සියලු පුද්ගලික සැකසුම් — keyboard layout එක, username එක, password එක — යන්ත්‍රය පළමු වරට boot වන තුරු කල් දමනු ලැබේ. ධාවකය තවමත් පෙරනිමියෙන් සංකේතනය කර ඇති අතර, එම පළමු boot එකේදී නව හිමිකරු තෝරන මුරපදය සංකේතනය සඳහා වූ මුරපදය ද බවට පත්වේ. (ඔබ දැනටමත් භාවිත කර ඇති යන්ත්‍රයක් නැවත ස්ථාපනයකින් තොරව ද භාර දිය හැකිය — බලන්න [පරිගණකය යළි සැකසීම](48-security.md).)

### මැදිහත්වීමකින් තොර ස්ථාපන

දෙවන ධාවකයකින් එහි වින්‍යාසය ලබා දුන් විට, ISO එකට සම්පූර්ණයෙන්ම තනිවම — keyboard එකක් නැත, wizard එකක් නැත — ස්ථාපනය කළ හැකිය. VMs සහ fleet යන්ත්‍ර සඳහා Omarchy මූලික image එකක් ලෙස සැලකීමට ඇති ක්‍රමය එයයි. බලන්න [මැදිහත්වීමකින් තොර ස්ථාපන](51-unattended-installs.md).

### සංකේතනයෙන් තොර ස්ථාපන

Omarchy පෙරනිමියෙන් සංකේතනය සමඟ ස්ථාපනය වේ. නැති වීමට හෝ සොරකම් වීමට හැකි ඕනෑම පරිගණකයක් සඳහා එය ආරක්ෂිත, වගකිවයුතු තේරීමයි. ඔබේ hardware එකට ප්‍රවේශය ඇති ඕනෑම කෙනෙකුට ඔබේ දත්ත ලබා ගැනීමට හැකි වීමට ඔබ කැමති නැත!

නමුත් විශේෂ අවස්ථාවලදී, ආරක්ෂිත පරිගණකවල දුරස්ථ Omarchy ස්ථාපන වැනි, හෝ සංවේදී දත්ත නොමැති ඉවත දැමිය හැකි ස්ථාපන සඳහා, ඔබට සංකේතනයකින් තොරව ස්ථාපනය කිරීමට අවශ්‍ය විය හැක. සංකේතනයෙන් තොර ස්ථාපනයකට මාරු වීමට disk formatting තහවුරු කිරීමේදී `Ctrl + C` ඔබන්න.

### භාෂාව

Omarchy භාෂා 50ක් කතා කරයි — omarchy.org හි ඇති එම කට්ටලයම — සහ English පෙරනිමියයි. මාරු කිරීමට, Omarchy menu එක විවෘත කර _Setup > Region > Language_ වෙත යන්න, හෝ terminal එකක `omarchy language <code>` ධාවනය කරන්න (`omarchy language list` මඟින් codes පෙන්වයි). menu එක, desktop එක, සහ Omarchy හිම දැනුම්දීම් වහාම භාෂාව වෙනස් කරන අතර, ඉන්පසු ඔබ විවෘත කරන සෑම application එකක්ම ද ඒ අනුව හැසිරේ. දැනටමත් විවෘත කර තිබූ Apps ඔබ ඒවා restart කළ පසු මාරු වේ.

භාෂාව එලෙසම තබාගෙන, තවත් region එකක් කරන ආකාරයට දින, වේලාවන්, අංක, මුදල්, ඒකක සහ කඩදාසි ප්‍රමාණ ලිවීමට (උදාහරණයක් ලෙස, European දින සහ පැය 24 ඔරලෝසුවක් සහිත English), _Setup > Region > Formats_ යටතේ region එකක් තෝරන්න, එහිදී සෑම තේරීමක්ම සාම්පලයක් පෙන්වයි, හෝ `omarchy region <code>` ධාවනය කරන්න (`omarchy region list` මඟින් codes පෙන්වයි). _Same as language_ මඟින් භාෂාවේම formats වෙත ආපසු යයි. භාෂා මාරුවක් මෙන්ම, එය ඉන්පසු ඔබ විවෘත කරන apps වෙත ළඟා වේ.
