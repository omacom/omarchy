# වෙනත් පැකේජයන්

Arch හි නිල ගබඩාව සහ Arch පරිශීලක ගබඩාව (AUR) අතර ඕනෑම ආකාරයක මෘදුකාංගයක් සඳහා පාහේ ලබාගත හැකි පැකේජවල විශ්මයජනක ධනයක් ඇත.

එය භාවිතා කිරීමට වඩා පහසු විය නොහැක. ඔබට Omarchy මෙනුවේ (`Super + Space`) _ස්ථාපනය > පැකේජය_ වෙත ගොස් අවශ්‍ය පැකේජය ටයිප් කිරීමෙන් නව Arch පැකේජයක් ස්ථාපනය කළ හැක. එය සියලු පැකේජවල ලැයිස්තුව ස්වයංක්‍රීයව fuzzy ලෙස පෙරනු ඇත. (ඔබට ටර්මිනලයේ `omarchy pkg add [package]` භාවිතයෙන් එය අතින්ද කළ හැක).

ඔබට AUR සමඟද එය කළ හැක, _ස්ථාපනය > AUR_ භාවිතා කරන්න. AUR එක Arch කණ්ඩායම විසින් පරීක්ෂා කරනු නොලබන බව මතක තබාගන්න. එය RubyGems හෝ npm වැනිය. ඕනෑම කෙනෙකුට උඩුගත කළ හැක.

ඔබට පැකේජයක් ඉවත් කිරීමට අවශ්‍ය නම්, ඔබට Omarchy මෙනුවෙන් _ඉවත් කරන්න > පැකේජය_ භාවිතා කළ හැක. එය පැකේජය, වින්‍යාස ගොනු, සහ පරායත්තාවයන් ඉවත් කරනු ඇත. (ඔබට `omarchy pkg drop [package]` භාවිතයෙන් එය අතින්ද කළ හැක).
