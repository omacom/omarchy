# මොනිටර

පෙරනිමියෙන්ම ඔබ 2x හැකියාව ඇති retina-ශ්‍රේණියේ තිරයක් භාවිතා කරන බව Omarchy උපකල්පනය කරයි. ලස්සන, තියුණු programmer fonts ලබා ගැනීමට ඔබට අවශ්‍ය වන්නේ එයයි. අධි-විභේදන තිර සහිත අලුත්ම premium ලැප්ටොප් සියල්ලම පාහේ ප්‍රශස්ත කර ඇත්තේ ඒ සඳහාමය. 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) හෝ 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) තිරයක ධාවනය කිරීමට ඔබට අවශ්‍ය වන්නේද එයමය.

නමුත් ඔබ PPI 218ක් හෝ ඊට වැඩි තිරයක් භාවිතා නොකරන්නේ නම්, ඔබට මොනිටර සැකසීම් වෙනස් කිරීමට අවශ්‍ය වනු ඇත. උදාහරණයක් ලෙස, ඔබට 27" හෝ 32" 4K තිරයක් තිබේ නම්, ඉහළ තීරුවේ ඇති මොනිටර පැනලයෙන් ඔබට ඒ සඳහා භාගික scale එකක් තෝරා ගත හැකිය, නැතහොත් `~/.config/hypr/monitors.lua` විවෘත කර එම සංයෝජනය සඳහා නිර්දේශයට මාරු වීමෙන් සෑම මොනිටරයක් සඳහාම පෙරනිමිය සැකසිය හැකිය:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

ඔබ 1080p හෝ 1440p තිරයක් භාවිතා කරන්නේ නම්, ඔබට බොහෝ විට අවශ්‍ය වන්නේ 1x scaling භාවිතා කිරීමට පමණි, GTK සහ X11 apps සඳහාද එසේමය, එබැවින් ඔබට මෙය භාවිතා කළ හැකිය:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

`GDK_SCALE` වෙනස් කිරීම් අදාළ වන්නේ වෙනසෙන් පසු ආරම්භ කරන ලද applications සඳහාය (සහ GTK පිළිගන්නේ පූර්ණ සංඛ්‍යා පමණි, එබැවින් එය ඔබේ මොනිටර scale එකට ළඟම පූර්ණ සංඛ්‍යාවේම තබා ගන්න). එබැවින් වෙනසෙන් පසු විශාලව වැඩි වී ඇති ඔබට ඇති windows වසා දැමීමට වග බලා ගන්න (හෝ `Ctrl + Alt + Del` සමඟ සියලුම windows වසා දමන්න!).

ඉහළ යාමට `Super + /` සහ පහළ යාමට `Super + Alt + /` භාවිතයෙන් ප්‍රධාන මොනිටර scaling අනුපාත (1x, 1.25x, 1.6x, 2x, 3x, 4x) හරහාද ඔබට ඉක්මනින් ගමන් කළ හැකිය, නැතහොත් ඉහළ තීරුවේ ඇති මොනිටර පැනලයෙන් එකක් තෝරා ගත හැකිය. මේවා වෙනස් කරන්නේ ඔබ අවධානය යොමු කර ඇති මොනිටරය පමණි, එබැවින් ලැප්ටොප් තිරයකට සහ බාහිර තිරයකට තමන්ගේම scale එක බැගින් තිබිය හැකිය. පැනලය සෑම මොනිටරයකම විභේදනයද සකසයි. ඔබේ තේරීම් එම භෞතික මොනිටරය සඳහා `~/.local/state/omarchy/monitors/settings` තුළ සුරකිනු ලැබේ, එබැවින් ඒවා reboot කළ පසුවත් පවතින අතර මොනිටරය ඊළඟට සම්බන්ධ කරන port එකට හෝ dock එකට එය අනුගමනය කරයි. Omarchy කිසිවිටක සංස්කරණය නොකරන `~/.config/hypr/monitors.lua` තුළ එම මොනිටරය සඳහාම ඇති ඕනෑම නීතියකට වඩා ඒවාට ප්‍රමුඛත්වය ලැබේ. `GDK_SCALE` සියලුම තිර සඳහා එක් අගයක් බැවින්, තෝරාගත් scale එකක් එය සකසන්නේ අඩුම scale එක ඇති මොනිටරයෙන් බැවින්, X11 apps අනෙක් තිරයේ විශාලව වැඩි වී පෙනෙනවා වෙනුවට ඝනත්වය වැඩි තිරයේ තරමක් කුඩාවට පෙනේ.

### පෙළ විශාල හෝ කුඩා කිරීම

මොනිටර scaling මඟින් සියල්ලේම ප්‍රමාණය වෙනස් වේ. ඔබට අවශ්‍ය වන්නේ විශාල හෝ කුඩා _පෙළ_ පමණක් නම්, ඒ සඳහා තනි knob එකක් ඇත:

```
omarchy display text size 14
```

එය 9 සහ 20 අතර pixel ප්‍රමාණයක් ගන්නා අතර, Omarchy shell එක, GTK applications සහ ඔබේ terminal එක එකටම ගෙන යයි, එබැවින් මුළු desktop එකම සමානුපාතිකව පවතී. ඔබ සිටින්නේ කොතැනදැයි බැලීමට argument එකක් නොමැතිව එය ධාවනය කරන්න, සහ පෙරනිමියට ආපසු යාමට `omarchy display text size reset` ධාවනය කරන්න. Foot යනු එකම පසුගාමියාය: එහි config එක නැවත පූරණය කිරීමට ක්‍රමයක් නොමැති බැවින්, ධාවනය වන terminals ඔබ අලුත් එකක් විවෘත කරන තුරුම ඒවායේ පැරණි ප්‍රමාණයම රඳවා ගනී.

### ලැප්ටොප් තිර දිගු කිරීම සහ පිළිබිඹු කිරීම

ඔබ ඔබේ ලැප්ටොප් එකට බාහිර තිරයක් සම්බන්ධ කළ විට, තිරය ස්වයංක්‍රීයව දිගු වේ. නමුත් Omarchy menu එකේ _Trigger > Hardware_ හෝ `Super + Ctrl + Alt + Delete` භාවිතයෙන් ඔබට ඒ වෙනුවට පිළිබිඹු කිරීමට එය වෙනස් කළ හැකිය. එම බාහිර තිරය projector එකක් නම්, සහ ඔබට වැඩ කරන අතරතුර යමක් පෙන්වීමට අවශ්‍ය නම් මෙය විශේෂයෙන් උපකාරී වේ.

ඔබ දිගු කරමින් සිටින විට, ලැප්ටොප් එකේ පියන වැසීමෙන් අභ්‍යන්තර තිරය ස්වයංක්‍රීයව අක්‍රිය වේ. පියන විවෘත කිරීමෙන් එය නැවත ක්‍රියාත්මක වේ. Omarchy menu එකේ _Trigger > Hardware_ හෝ `Super + Ctrl + Delete` භාවිතයෙන් ඔබට මෙය අතින්ද පාලනය කළ හැකිය.

### තිර කිහිපයක් සැකසීම

Hyprland තිර කිහිපයක් සමඟ ඉතා හොඳින් ක්‍රියා කරයි. ඉහළ තීරුවේ ඇති මොනිටර පැනලය ඒවා පිහිටා ඇති තැන ඒවා අඳියි: එකක් තවත් එකක පැත්තට ඇදගෙන ගොස් එය එතැනට ගෙන යන්න, එවිට සැකැස්ම සෑම මොනිටරයකම අනෙකුත් සැකසීම් සමඟ සුරකිනු ලැබේ. පැනලයට ආවරණය නොවන ඕනෑම දෙයක් සඳහා, ඒවා සකස් කරන ආකාරය පිළිබඳව [Hyprland මොනිටර ලියකියවිලිවල](https://wiki.hypr.land/Configuring/Basics/Monitors/) වැඩිදුර කියවන්න. Omarchy හි, මේවා `hl.monitor` ඇතුළත් කිරීම් ලෙස `~/.config/hypr/monitors.lua` තුළට යයි — නිශ්චිත මොනිටරයක් විභේදනයකට, පිහිටුමකට සහ භ්‍රමණයකට සවි කිරීම සඳහා අදහස් දක්වා ඇති උදාහරණ සමඟ ගොනුව එයි.

සෑම මොනිටරයකටම තමන්ගේම workspaces 1 සිට 10 දක්වා ඇත, එබැවින් `Super + 1` යන්නෙන් සැමවිටම අදහස් වන්නේ ඔබ සිටින මොනිටරයේ පළමු workspace එකය. තිරය පිටුපස, Hyprland තවමත් සියලුම මොනිටර හරහා workspaces අංකනය කරයි: ඔබේ ලැප්ටොප් තිරයට (හෝ පළමු මොනිටරයට) 1–10ද, ඊළඟ මොනිටරයට 11–20ද, එලෙසම ඉදිරියටද ලැබේ, සහ ඔබ එය සම්බන්ධ කරන සෑම අවස්ථාවකදීම සෑම මොනිටරයක්ම එහි block එක රඳවා ගනී. නිශ්චිත මොනිටරයක් සඳහා ඔබ [වැඩබිම් නීති](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) හෝ window නීති ලියන්නේ නම් එම අංක භාවිතා කරන්න, එවිට workspace 12 යනු ඔබේ දෙවන මොනිටරයේ දෙවන workspace එකයි. සෑම මොනිටරයකටම ඇති block එක කුමක්දැයි `~/.local/state/omarchy/monitors/workspaces` ලැයිස්තුගත කරයි.

ඊතල යතුරු ඔබේ සැකැස්මේ දාරයක් බෙදා ගන්නා මොනිටර හරහා ක්‍රියා කරයි. කොනකින් පමණක් ස්පර්ශ වන, හෝ ඒවා අතර පරතරයක් ඇති තිර අසල්වැසියන් නොවේ, එබැවින් ඒවා අතර යාමට `Ctrl + Alt + Tab` භාවිතා කරන්න.

| කෙටිමං යතුර | මොනිටර හරහා |
| --- | --- |
| `Super + Arrow` | එම දිශාවට තවත් window එකක් නොමැති වූ පසු එම පැත්තේ ඇති මොනිටරයට අවධානය ගෙන යයි |
| `Super + Shift + Arrow` | එම පැත්තේ ඇති මොනිටරයේ window එකක් සමඟ හුවමාරු වේ |
| `Super + Alt + Arrow` | එම පැත්තේ ඇති මොනිටරයේ group එකකට window එක ගෙන යයි |
| `Super + Shift + Ctrl + Arrow` | එම පැත්තේ ඇති මොනිටරයට, එය පෙන්වන workspace එක මතට window එක ගෙන යයි |
| `Super + Shift + Alt + Arrow` | එම පැත්තේ ඇති මොනිටරයට workspace එක ගෙන යයි, එය නිදහස් නම් එහි අංකය රඳවා ගනී |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | සැකැස්ම කුමක් වුවත්, ඊළඟ හෝ පෙර මොනිටරයට අවධානය ගෙන යයි |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | ඔබ සිටින මොනිටරයේම රැඳී සිටී |

තිර කිහිපයක් ස්ථානගත කිරීමට ඔබට උදව් කිරීමට TUI එකක් අවශ්‍ය නම්, ඔබට [Hyprmon](https://github.com/erans/hyprmon/)ද පරීක්ෂා කළ හැකිය.

### දීප්තිය පාලනය කිරීම

මොනිටරයේ දීප්තිය පාලනය කරනු ලබන්නේ දීප්තිය වැඩි/අඩු කිරීම සඳහා ඇති කැපවුණු function යතුරු මගිනි. ඔබ මේවා එබීමේදී shift ඔබාගෙන සිටියහොත්, ඔබ උපරිම හෝ අවම දීප්තියට යනු ඇත. යතුරු ඔබ අවධානය යොමු කර ඇති තිරය පාලනය කරයි, එබැවින් DDC/CI කතා කරන බාහිර මොනිටර ලැප්ටොප් තිරය මෙන්ම එකම ආකාරයෙන්ම සකසනු ලැබේ.

### Apple තිර

ඔබ Apple තිරයක් භාවිතා කරන්නේ නම්, ඔබ Apple තිරය වෙත අවධානය යොමු කර ඇත්නම්, සාමාන්‍ය යතුරුපුවරු දීප්ති යතුරුද ස්වයංක්‍රීයව ක්‍රියා කරනු ඇත. මෙය සිදු කරනු ලබන්නේ `asdcontrol` විධානය හරහාය.

ඔබ Apple 6K XDR තිරයක් භාවිතා කරන්නේ නම්, ඔබේ `hyprctl monitors` ලැයිස්තුවේ phantom තිරයක් ඔබට දැකිය හැකි බව සලකන්න. `~/.config/hypr/monitors.lua` තුළ `hl.monitor({ output = "DP-2", disabled = true })` වැනි දෙයක් සමඟ ඔබට මෙය අක්‍රිය කළ හැකිය.

Intel machines මත, ඔබ සාමාන්‍ය Thunderbolt කේබලයක් භාවිතයෙන් Apple තිරවලට සම්බන්ධ විය යුතුය. Thunderbolt නොමැති අනෙකුත් machines මත, එය ක්‍රියාත්මක කිරීමට ඔබට සාමාන්‍යයෙන් [DP + USB-A -> USB-C කේබලයක්](https://www.amazon.com/dp/B0BNX7MS6N) භාවිතා කිරීමට සිදු වනු ඇත.
