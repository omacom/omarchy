# මොනිටර්

Omarchy පෙරනිමියෙන් උපකල්පනය කරන්නේ ඔබ 2x-හැකි retina-මට්ටමේ සංදර්ශකයක ක්‍රියාත්මක වන බවයි. ඒ ලස්සන, තියුණු programmer fonts ලබා ගැනීමට ඔබට අවශ්‍ය වන්නේ එයයි. අධි-විභේදන තිර සහිත සියලුම පාහේ අලුත් premium ලැප්ටොප් ප්‍රශස්ත කර ඇත්තේ එය සඳහායි. 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) හෝ 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) එකක ක්‍රියාත්මක කිරීමට ඔබට අවශ්‍ය වන්නේද එයයි.

නමුත් ඔබ PPI 218ක් හෝ ඊට වැඩි සංදර්ශකයක් ක්‍රියාත්මක කරන්නේ නැත්නම්, ඔබට මොනිටර් සැකසුම් වෙනස් කිරීමට අවශ්‍ය වනු ඇත. උදාහරණයක් ලෙස, ඔබට 27" හෝ 32" 4K එකක් තිබේ නම්, ඉහළ තීරුවේ ඇති monitor panel එකෙන් ඒ සඳහා භාගික scale එකක් තෝරා ගත හැකිය, නැතහොත් `~/.config/hypr/monitors.lua` විවෘත කර එම සංයෝජනය සඳහා ඇති නිර්දේශයට මාරු වීමෙන් සෑම මොනිටරයක් සඳහාම පෙරනිමිය සැකසිය හැකිය:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

ඔබ 1080p හෝ 1440p සංදර්ශකයක් භාවිතා කරන්නේ නම්, ඔබට බොහෝ විට අවශ්‍ය වන්නේ 1x scaling භාවිතා කිරීමට පමණි, GTK සහ X11 apps සඳහාද එයම වේ, එබැවින් ඔබට මෙය භාවිතා කළ හැකිය:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

`GDK_SCALE` වෙත කරන වෙනස්කම් අදාළ වන්නේ වෙනස්කමෙන් පසු ආරම්භ කරන ලද applications සඳහාය (GTK පිළිගන්නේ පූර්ණ සංඛ්‍යා පමණක් වන බැවින්, එය ඔබේ මොනිටර් scale එකට ආසන්නතම පූර්ණ සංඛ්‍යාවේ තබා ගන්න). එබැවින් වෙනස්කමෙන් පසු ප්‍රමාණයෙන් වැඩි වී ඇති ඔබ සතුව ඇති windows වසා දැමීමට වග බලා ගන්න (නැතහොත් `Ctrl + Alt + Del` සමඟ සියලුම windows වසා දමන්න!).

ඔබට `Super + /` භාවිතයෙන් ඉහළට යාමෙන් සහ `Super + Alt + /` භාවිතයෙන් පහළට යාමෙන් ප්‍රධාන මොනිටර් scaling අනුපාතයන් (1x, 1.25x, 1.6x, 2x, 3x, 4x) හරහා වේගයෙන් ගමන් කළ හැකිය, නැතහොත් ඉහළ තීරුවේ ඇති monitor panel එකෙන් එකක් තෝරා ගත හැකිය. මේවා වෙනස් කරන්නේ ඔබ අවධානය යොමු කර ඇති මොනිටරය පමණක් වන බැවින්, ලැප්ටොප් තිරයකට සහ බාහිර සංදර්ශකයකට ඒ ඒවාට අදාළ scale එක බැගින් තිබිය හැකිය. panel එක මඟින් එක් එක් මොනිටරයේ resolution එක, refresh rate එක සහ rotation එකද සකසයි. ඔබේ තේරීම් එම භෞතික මොනිටරය සඳහා `~/.local/state/omarchy/monitors/settings` තුළ සුරකිනු ලැබේ, එබැවින් ඒවා reboot කිරීමෙන් පසුවද පවතින අතර ඊළඟට එය සම්බන්ධ කරන ඕනෑම port එකකට හෝ dock එකකට මොනිටරය සමඟම අනුගමනය කරයි. ඒවා `~/.config/hypr/monitors.lua` හි එකම මොනිටරය සඳහා ඇති ඕනෑම rule එකකට වඩා ප්‍රමුඛතාව ලැබෙන අතර, Omarchy කිසිවිටෙක එය සංස්කරණය නොකරයි. ඔබ ඔබේ මොනිටර් සම්පූර්ණයෙන්ම එම file එක තුළම සැකසීමට කැමති නම්, එයට `omarchy_monitor_panel_settings = false` එක් කරන්න, එවිට panel එකේ වෙනස්කම් පවතින්නේ Hyprland reload වන තෙක් පමණි. `GDK_SCALE` යනු සියලුම තිර සඳහා එක් value එකක් වන බැවින්, තෝරා ගත් scale එකක් එය සකසන්නේ අඩුම scale එක ඇති මොනිටරයෙන් වන අතර, එබැවින් X11 apps අනෙක් තිරයේ ප්‍රමාණයෙන් වැඩි වීම වෙනුවට ඝනත්වයෙන් වැඩි තිරයේ තරමක් කුඩා වී දිස් වේ.

### පෙළ විශාල හෝ කුඩා කිරීම

මොනිටර් scaling මඟින් සියල්ලේම ප්‍රමාණය වෙනස් කරයි. ඔබට අවශ්‍ය වන්නේ විශාල හෝ කුඩා _පෙළ_ පමණක් නම්, ඒ සඳහා එකම knob එකක් ඇත:

```
omarchy display text size 14
```

එය 9 සහ 20 අතර pixel size එකක් ගන්නා අතර, Omarchy shell එක, GTK applications සහ ඔබේ terminal එක එකට ගෙන යන බැවින්, මුළු desktop එකම අනුපාතයේ පවතී. ඔබ සිටින තැන බැලීමට argument එකක් නොමැතිව එය ධාවනය කරන්න, පෙරනිමියට යාමට `omarchy display text size reset` ධාවනය කරන්න. Foot යනු එකම පසුපසින් එන්නාය: එහි config එක reload කිරීමට ක්‍රමයක් නොමැති බැවින්, ක්‍රියාත්මක වන terminals ඔබ අලුත් එකක් විවෘත කරන තෙක් ඒවායේ පැරණි ප්‍රමාණයම රඳවා ගනී.

### ලැප්ටොප් සංදර්ශක දිගු කිරීම සහ පිළිබිඹු කිරීම

ඔබ ඔබේ ලැප්ටොප් එකට බාහිර තිරයක් සම්බන්ධ කරන විට, සංදර්ශකය ස්වයංක්‍රීයව දිගු වේ. නමුත් ඉහළ තීරුවේ ඇති monitor panel එකේ _Extend_ | _Mirror_ සමඟ, Omarchy menu එකේ _Trigger > Hardware_ සමඟ, නැතහොත් `Super + Ctrl + Alt + Delete` සමඟ ඔබට එය ඒ වෙනුවට mirroring ලෙස වෙනස් කළ හැකිය. එම බාහිර තිරය projector එකක් නම් සහ ඔබට වැඩ කරන අතරතුර යමක් පෙන්වීමට අවශ්‍ය නම් මෙය විශේෂයෙන් උපකාරී වේ.

ඔබ දිගු කරන විට, ලැප්ටොප් එකේ පියන වැසීමෙන් අභ්‍යන්තර තිරය ස්වයංක්‍රීයව අක්‍රිය වේ. පියන විවෘත කිරීමෙන් එය නැවත ක්‍රියාත්මක වේ. Omarchy menu එකේ _Trigger > Hardware_ හෝ `Super + Ctrl + Delete` භාවිතයෙන් ඔබට මෙය අතින්ද පාලනය කළ හැකිය.

ලැප්ටොප් එක සම්බන්ධ කර ඇති අතරතුර, පියන වැසීමෙන් එය කිසිවිටෙක sleep නොවන බැවින්, බාහිර තිරය කෙටි වේලාවකට විසන්ධි වුවද dock කළ ලැප්ටොප් එක අවදියෙන් පවතී. බාහිර තිරයක් සවි කර නොමැති විට, විදුලිය සම්බන්ධ කර තිබියදී පියන වැසීමෙන් එය lock වීම පමණක් සිදු වේ. Battery එකෙන් ක්‍රියාත්මක වන විට, පියන වැසීමෙන් සුපුරුදු පරිදි suspend වේ.

### තිර කිහිපයක් සැකසීම

Hyprland තිර කිහිපයක් සමඟ ඉතා හොඳින් ක්‍රියා කරයි. ඉහළ තීරුවේ ඇති monitor panel එක ඒවා පිහිටා ඇති තැන් අඳියි: එකක් තවත් එකක පැත්තට ඇද දැමීමෙන් එය එතැනට ගෙන යන්න, එවිට සැකැස්ම එක් එක් මොනිටරයේ අනෙකුත් සැකසුම් සමඟ සුරකිනු ලැබේ. panel එක ආවරණය නොකරන ඕනෑම දෙයක් සඳහා, ඒවා සැකසිය යුතු ආකාරය පිළිබඳ වැඩිදුර [Hyprland මොනිටර් ලේඛනය](https://wiki.hypr.land/Configuring/Basics/Monitors/) තුළ කියවන්න. Omarchy තුළ, මේවා `hl.monitor` entries ලෙස `~/.config/hypr/monitors.lua` තුළට යයි — එම file එක මොනිටරයක් අක්‍රියව තබා ගැනීම, panel එක ලබා නොදෙන modes, 10-bit color සහ variable refresh rate සඳහා අදහස් දක්වා ඇති examples සමඟ එයි.

සෑම මොනිටරයකටම ඔහුටම අදාළ workspaces 1 සිට 10 දක්වා ඇති බැවින්, `Super + 1` යනු සෑම විටම ඔබ සිටින මොනිටරයේ පළමු workspace එකයි. තිරය පිටුපසින්, Hyprland තවමත් සියලුම මොනිටර් හරහා workspaces අංකනය කරයි: ඔබේ ලැප්ටොප් තිරයට (හෝ පළමු මොනිටරයට) 1–10 ද, ඊළඟ මොනිටරයට 11–20 ද, ආදී වශයෙන් ද ලැබෙන අතර, ඔබ එය සම්බන්ධ කරන සෑම විටම එක් එක් මොනිටරය එහි block එක රඳවා ගනී. ඔබ නිශ්චිත මොනිටරයක් සඳහා [වැඩබිම් නීති](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) හෝ window rules ලියන්නේ නම් එම අංක භාවිතා කරන්න, එබැවින් workspace 12 යනු ඔබේ දෙවන මොනිටරයේ දෙවන workspace එකයි. `~/.local/state/omarchy/monitors/workspaces` මඟින් එක් එක් මොනිටරයට ඇති block එක ලැයිස්තුගත කරයි.

Arrow keys ඔබේ layout එකේ අද්දරක් බෙදා ගන්නා මොනිටර් හරහා ක්‍රියා කරයි. කොනකදී පමණක් ස්පර්ශ වන, නැතහොත් ඒවා අතර පරතරයක් ඇති තිර අසල්වැසියන් නොවන බැවින්, ඒවා අතර යාමට `Ctrl + Alt + Tab` භාවිතා කරන්න.

තිර කිහිපයක් ස්ථානගත කිරීමට ඔබට උපකාර කිරීමට TUI එකක් අවශ්‍ය නම්, ඔබට [Hyprmon](https://github.com/erans/hyprmon/) ද බලන්න පුළුවන්.

### දීප්තිය පාලනය කිරීම

මොනිටර් දීප්තිය පාලනය කරන්නේ දීප්තිය වැඩි/අඩු කිරීම සඳහා ඇති කැපවූ function keys මගිනි. ඔබ මේවා ඔබන අතරතුර Shift ඔබාගෙන සිටියහොත්, ඔබ උපරිම හෝ අවම දීප්තියට යනු ඇත. keys මඟින් පාලනය කරන්නේ ඔබ අවධානය යොමු කර ඇති සංදර්ශකය වන බැවින්, DDC/CI කතා කරන බාහිර මොනිටර් ලැප්ටොප් තිරය මෙන්ම එකම ආකාරයෙන් සකසනු ලැබේ.

### Apple සංදර්ශක

ඔබ Apple සංදර්ශකයක් භාවිතා කරන්නේ නම්, ඔබ Apple සංදර්ශකය මත අවධානය යොමු කර ඇත්නම්, සාමාන්‍ය keyboard brightness keys ද ස්වයංක්‍රීයව ක්‍රියා කරනු ඇත. මෙය සිදු කරන්නේ `asdcontrol` command එක හරහාය.

ඔබ Apple 6K XDR සංදර්ශකයක් භාවිතා කරන්නේ නම්, ඔබේ `hyprctl monitors` ලැයිස්තුවේ phantom තිරයක් දැක ගත හැකි බව සලකන්න. ඔබට `~/.config/hypr/monitors.lua` හි `hl.monitor({ output = "DP-2", disabled = true })` වැනි දෙයක් සමඟ මෙය අක්‍රිය කළ හැකිය.

Intel යන්ත්‍රවල, ඔබ Apple සංදර්ශකවලට සම්බන්ධ විය යුත්තේ සාමාන්‍ය Thunderbolt cable එකක් භාවිතයෙනි. Thunderbolt නොමැති වෙනත් යන්ත්‍රවල, එය ක්‍රියා කරවීමට ඔබට සාමාන්‍යයෙන් [DP + USB-A -> USB-C cable](https://www.amazon.com/dp/B0BNX7MS6N) එකක් භාවිතා කිරීමට සිදු වනු ඇත.
