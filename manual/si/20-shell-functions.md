# ෂෙල් ශ්‍රිත

පොදු කාර්යයන් සරල කිරීමට සහ සංකීර්ණ පරා미터 ඇමතුම් කැප්සියුල කිරීමට Omarchy ෂෙල් ශ්‍රිත කට්ටලයක් සමඟ පැමිණේ.

## සම්පීඩනය

- `compress [file/dir]`: ගොනුවෙන්/නාමාවලියෙන් tar.gz සංරක්ෂිතයක් සාදන්න.
- `decompress [file.tar.gz]`: tar.gz ගොනුවක් පුළුල් කරන්න.

## ධාවක

- `iso2sd [image.iso]`: යොමු කළ iso ගොනුව භාවිතයෙන් සහ අන්තර්ක්‍රියාකාරීව ධාවකය තේරීමෙන් SD කාඩ්පතක ආරම්භ කළ හැකි ධාවකයක් සාදන්න.
- `format-drive [device] [name]`: තනි exFAT කොටසක් සමඟ සම්පූර්ණ තැටියක් ආකෘතිකරණය කරන්න (එය Windows සහ macOS වලද ක්‍රියා කරයි). ලබාගත හැකි ධාවක බැලීමට තර්ක නොමැතිව එය ක්‍රියාත්මක කරන්න. ප්‍රවේශම් වන්න!

## සංවර්ධන පිරිසැලසුම්

tmux සඳහා ක්ෂණික බහු-කවුළු සංවර්ධන පිරිසැලසුම්:

- `tdl [ai]`: ඔබේ සංස්කාරකය, AI නියෝජිතයෙකු, සහ ටර්මිනලයක් සමඟ Tmux Dev Layout එකක් සාදන්න. opencode සඳහා `tdl c` හෝ Claude Code සඳහා `tdl cx` වැනි නියෝජිත අනුනාම භාවිතා කරන්න, නැතහොත් දෙකම ක්‍රියාත්මක කිරීමට `tdl c cx` වැනි දෙවන නියෝජිතයෙකු යවන්න.
- `tds`: සංස්කාරකය, diff නැරඹීම (`hunk diff --watch` හරහා), ටර්මිනලය, සහ opencode සමඟ Tmux Dev Square එකක් සාදන්න.
- `tdlm [ai]`: වත්මන් නාමාවලියේ සෑම උපනාමාවලියක් සඳහාම `tdl` කවුළුවක් සාදන්න.
- `tsl [count] [command]`: ජාලකයක ටයිල් කළ කවුළු රැසක් සාදන්න, සියල්ල එකම විධානය ක්‍රියාත්මක කරයි (AI නියෝජිතයන් සඳහා විශිෂ්ටයි).

එකම පිරිසැලසුම් Herdr සඳහා `hdl`, `hds`, `hdlm`, සහ `hsl` ලෙස ලබාගත හැක.

## Git worktrees

- `ga [branch]`: වත්මන් ගබඩාව අසල නව worktree එකක් සහ ශාඛාවක් සාදා එයට පිවිසෙන්න.
- `gd`: වත්මන් worktree එක සහ එහි ශාඛාව ඉවත් කරන්න (පළමුව තහවුරු කිරීම අසයි).

## Rsync නරඹන්නන්

- `rsw [source] [destination]`: කිසිවක් වෙනස් වන ඕනෑම අවස්ථාවක මූලාශ්‍රය ගමනාන්තයට rsync කරන පසුබිම් නරඹන්නෙකු අරඹන්න. ගමනාන්තය `rsw ~/Work/app nyc-dev:Work/app` වැනි දුරස්ථ ධාරකයක් විය හැක.
- `lsw`: ක්‍රියාකාරී නරඹන්නන් සියල්ල ලැයිස්තුගත කරන්න.
- `dsw`: ක්‍රියාකාරී නරඹන්නන් සියල්ල නවත්වන්න.

## SSH තොටුපළ යොමු කිරීම

දුරස්ථ පෙට්ටියකට එරෙහිව localhost ආරක්ෂිත-සන්දර්භ වරප්‍රසාද සමඟ වෙබ් සංවර්ධනය කිරීම සඳහා වඩාත් සුදුසුය.

- `fip`: SSH හරහා දුරස්ථ ධාරකයකින් localhost වෙත තොටුපළ එකක් හෝ වැඩි ගණනක් යොමු කරන්න.
- `dip`: යොමු කළ තොටුපළ එකක් හෝ වැඩි ගණනක් විසන්ධි කරන්න.
- `lip`: ක්‍රියාකාරී SSH තොටුපළ යොමු කිරීම් සියල්ල ලැයිස්තුගත කරන්න.

ඔබ `nyc-dev` ලෙස ප්‍රවේශ විය හැකි යන්ත්‍රයක තොටුපළ `3000` හි සංවර්ධන සේවාදායකයක් අරඹන බව කියමු, ඉන්පසු ඔබට එම තොටුපළ යොමු කිරීමට `fip nyc-dev 3000` ක්‍රියාත්මක කළ හැක, එවිට `localhost:3000` ඇත්ත වශයෙන්ම `nyc-dev:3000` වෙත ළඟාවේ, නමුත් වෙබ් සොකට් වැනි දේවල් පරීක්ෂා කිරීමට අවශ්‍ය ආරක්ෂිත සන්දර්භය ස්ථාපිත කිරීමට SSL සහතික අවශ්‍යතාවය නොමැතිව.

## SSH නැවත සම්බන්ධ වීම

`ssh` එකම, දුරස්ථ tmux එකක්, Herdr එකක්, හෝ සංස්කාරකයෙකු එය අත්පත් කරගෙන සිටියදී සම්බන්ධතාවයක් මිය ගියහොත් ටර්මිනලය පිරිසිදු කරන, ඉන්පසු අන්තර්ක්‍රියාකාරී සැසියක් වැටුණු විට ස්වයංක්‍රීයව නැවත සම්බන්ධ වන (Ctrl-C නැවත උත්සාහ කිරීමේ ලූපය නවත්වයි) ශ්‍රිතයකින් ඔතා ඇත.
