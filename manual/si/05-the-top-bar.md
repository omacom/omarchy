# ඉහළ තීරුව

ඔබේ තිරයේ ඉහළින් ඇති තීරුව Omarchy තීරුවයි. එය බෝල්ට් කළ තත්ව තීරුවක් නොව, මෙනුව, දැනුම්දීම්, OSD උත්පතන සහ අගුලු තිරය ද අඳින තනි දිගු-ධාවන Quickshell ක්‍රියාවලිය වන Omarchy shell එකේ කොටසකි. ඒ නිසා එය අනෙක් සියල්ල සමඟ පරිපූර්ණව තේමා වන අතර නව යෙදුමක් බිහි කිරීම වෙනුවට පැනලයක් ක්ෂණිකව විවෘත වන්නේ ද ඒ නිසයි.

එය සැමවිටම තිරයේ ඇති ඩෙස්ක්ටොප් එකේ එකම කොටස ද වන නිසා, එම කුඩා ග්ලිෆ් සියල්ල කරන්නේ කුමක්දැයි දැනගැනීම වටී.

## පෙරනිමියෙන් එහි ඇත්තේ කුමක්ද

තීරුවට කොටස් තුනක් ඇත. වම් පසින් Omarchy ලාංඡනය (මෙනු දියත්කය) සහ වැඩබිම් දර්ශක හිඳියි. මැදින් ඔබට තත්ව දර්ශක, ඔරලෝසුව, Elsewhen (ලෝක ඔරලෝසුවක්), කාලගුණය සහ Omarchy යාවත්කාලීන ලාංඡනයක් ලැබේ. දකුණු පසින්: යතුරුපුවරු සැකැස්ම (එකකට වඩා වින්‍යාස කර ඇති විට), පද්ධති තැටිය, නියෝජිතයන්, bluetooth, ජාලය, ශ්‍රව්‍යය, සංදර්ශකය සහ බලය.

ඒවායින් කිහිපයක් පෙනී සිටින්නේ ඒවාට පැවසීමට යමක් ඇති විට පමණි. යතුරුපුවරු සැකැස්ම දිස්වන්නේ ඔබ එකකට වඩා සැකැස්මක් වින්‍යාස කර ඇත්නම් පමණි. යාවත්කාලීන ලාංඡනය දිස්වන්නේ Omarchy යාවත්කාලීනයක් බලා සිටින විට පමණි. නියෝජිතයන්ගේ අයිකනය දිස්වන්නේ Omarchy යන්ත්‍රය මත AI කේතීකරණ භාවිතයක් ප්‍රථම වරට සොයාගත් විටය (බලන්න [AI](17-ai.md)).

## පැනල

තීරු අයිකනයක් ක්ලික් කිරීමෙන් පැනලයක් විවෘත වන අතර, එය මෙවලම් ඉඟියක් වෙනුවට ස්ලයිඩර්, ලැයිස්තු සහ යතුරුපුවරු සංචාලනය සහිත නිසි උත්පතනයකි. ඒ සෑම එකකටම උණුසුම් යතුරක් ද ඇත, එබැවින් ඔබට කිසිවිටෙක පික්සල 16 ග්ලිෆ් එකකට ඉලක්ක කිරීමට සිදු නොවේ:

පැනල කියවීම් නොවේ. ඒවා ඔබ ඇත්තටම දෙය කරන තැනයි:

- **ශ්‍රව්‍යය** හි ප්‍රධාන ශබ්ද ස්ලයිඩරයක්, ප්‍රතිදාන-උපකරණ තේරීමක් සහ යෙදුම් අනුව මික්සර් එකක් ඇත, එබැවින් ඔබට අනෙක් සියල්ල ස්පර්ශ නොකර එම එක් බ්‍රවුසර ටැබය අඩු කළ හැකිය.
- **ජාලය** Wi-Fi සඳහා ස්කෑන් කරයි, සංඥා ශක්තිය පෙන්වයි, සම්බන්ධ වේ, සහ DNS සපයන්නෙකු තෝරා ගැනීමට ඔබට ඉඩ දෙයි.
- **Bluetooth** ඔබේ උපකරණ සම්බන්ධ/විසන්ධි සහ බැටරි මට්ටම් සමඟ ලැයිස්තුගත කරයි.
- **බලය** බැටරි සංඛ්‍යාලේඛන පෙන්වයි, බල පැතිකඩවල් මාරු කරයි (එය බැටරිය සහ AC සඳහා වෙනම තේරීමක් මතක තබා ගනී), සහ සමහර පද්ධති තොරතුරු මුද්‍රණය කරයි.
- **සංදර්ශකය** දීප්ති ස්ලයිඩරයක්, පෙළ ප්‍රමාණය, මොනිටර පරිමාණ පෙරසිටුවීම් සහ — ඔබට එකකට වඩා තිර ඇති විට — මොනිටරයකට පාලන දරයි. ගැඹුරු කතාව සඳහා [මොනිටර](33-monitors.md) බලන්න.
- **ඔරලෝසුව** ISO සති අංක සහ මාස පියවර සමඟ මාස ජාලයක් විවෘත කරයි.

සෑම පැනලයක්ම මූසිකය මෙන්ම යතුරුපුවරුව ද ගනී: ඊතල චලනය වේ, Return ක්‍රියාත්මක වේ, Tab අසල්වැසි පැනලයට පියවර තබයි, සහ Escape වැසේ.

`Super + Ctrl + 1-9` දකුණු කොටසේ පැනල වමේ සිට දකුණට ගණන් කරයි, තැටියට තමන්ගේම පැනලයක් නොමැති බැවින් එය මඟ හරියි. එබැවින් අංකය ඔබ පෙන්වන අයිකනයට ගැලපේ.

### Tailscale සහ Dropbox

ඔබ **ස්ථාපනය → සේවාව** වෙතින් ගැලපෙන සේවාව ස්ථාපනය කළ විට පමණක් තවත් විජෙට් දෙකක් තීරුවේ දිස් වන අතර, ඒවා තත්වය වාර්තා කිරීමට වඩා වැඩි යමක් කරන බැවින් ඒවා දැනගැනීම වටී.

**Tailscale** පැනලය tailnet එක සම්බන්ධ කර විසන්ධි කරයි, ගිණුම් අතර මාරු වේ, සහ පිටවීමේ නෝඩයක් තෝරයි (ඔබේම යන්ත්‍ර සහ Mullvad කලාප දෙකම එම ලැයිස්තුවේ දිස් වේ). එය ඔබේ යන්ත්‍ර ද බ්‍රවුස් කරයි — සහ එකක් තෝරාගෙන ඇති විට, `s` Taildrop හරහා එයට ගොනු යවන අතර, එය ඔබේ දුරකථනයට හෝ වෙනත් ලැප්ටොප් එකකට ගොනුවක් ගෙන යාමේ වේගවත්ම ක්‍රමයයි. `c` යන්ත්‍රයේ IP එක පිටපත් කරයි, `n` එහි නම, සහ `d` එහි සම්පූර්ණ DNS නම. ඔබට ක්ලික් කිරීමට අවශ්‍ය නම් සෑම යන්ත්‍ර පේළියකම යැවීමේ බොත්තමක් ද ඇත. ටර්මිනලයෙන් එම දෙයම `omarchy tailscale send <machine> [file...]` වේ.

**Dropbox** පැනලය ලොගින් වීම හසුරුවයි, ඔබ කොපමණ ගබඩාවක් භාවිත කර ඇත්දැයි පෙන්වයි, සහ මෑතකදී සමමුහුර්ත කළ ගොනු ලැයිස්තුගත කරයි.

ඕනෑම සේවාවක් ඉවත් කිරීම එහි විජෙට් එක නැවත තීරුවෙන් ඉවත් කරයි.

## දර්ශක

මැද ඇති කුඩා පොකුර දර්ශක විජෙට් එකයි. මේවා ඔබ සක්‍රිය කර ඇති මාදිලි සඳහා තත්ව ග්ලිෆ් වේ: බාධා නොකරන්න, රාත්‍රී ආලෝකය, පෝලිමේ ඇති [මතක්කිරීමක්](09-reminders.md), ක්‍රියාකාරී තිර පටිගත කිරීමක්, අවදියෙන් සිටින්න, සහ [උච්චාරණය](11-text-extraction-dictation.md). මාදිලිය ක්‍රියාකාරී වූ විට ඒවා දැල්වෙන අතර වෙනත් ආකාරයකින් මාර්ගයෙන් ඉවත්ව සිටියි — අක්‍රිය ඒවා බැලීමට ඔරලෝසුවේ වම්පස (සිරස් තීරුවක එයට ඉහළින්) මූසිකය තබන්න. දර්ශකයක් ක්ලික් කිරීම එම මාදිලිය මාරු කරයි. තව එකක් තත්වය පමණි: යමෙක් gliff හරහා මෙම යන්ත්‍රයට සම්බන්ධ වී සිටින අතරතුර දුරස්ථ සැසියක් රතු පැහැයෙන් දැල්වේ.

ඔබ ඒවා සැමවිටම දෘශ්‍යමාන වීමට කැමති නම්, විජෙට් එකේ `alwaysShow` `true` ලෙස සැකසන්න. ඔබට ඒවායින් සමහරක් පමණක් වැදගත් නම්, ඔබට අවශ්‍ය ඒවා `items` හි ලැයිස්තුගත කරන්න: `["Dnd", "Reminder", "NightLight"]`. ඔබට එකකට වඩා දර්ශක විජෙට් එකක් තිබිය හැකි බැවින්, විවිධ කොටස්වලට විවිධ උපකුලක පෙන්විය හැකිය.

## තීරුව නැවත සැකසීම

තීරුව තනිවම වින්‍යාස වේ. දේවල් ගෙන යාමට ඔබට වින්‍යාස ගොනුවක් විවෘත කිරීමට අවශ්‍ය නැත.

මැද වටා තීරුවේ හිස් කොටසක් අල්ලා තවත් තිර දාරයක් දෙසට අදින්න, තීරුව එහි ගමන් කරනු ඇත — වම්, දකුණු, ඉහළ හෝ පහළ සියල්ලම වැඩ කරන අතර, සෑම විජෙට් එකක්ම අනුවර්තනය වේ (සිරස් තීරු සංයුක්ත අයිකන-පමණ ආකෘතිවලට යොමු වේ). ක්ලික් කර අල්ලාගැනීමකින් එම ඇදගෙන යාමම අරඹයි. තීරු පසුබිම පැහැදිලි සිට වීදුරු සිට අපාරදෘශ්‍ය දක්වා චක්‍රීය කිරීමට එම හිස් ඉඩම දෙවරක් වම්-ක්ලික් කරන්න. ඕනෑම විජෙට් එකක් නැවත පිළිවෙළට සකසීමට හෝ වෙනත් කොටසකට විසි කිරීමට එය අදින්න.

ඔබට අවශ්‍ය වුවත් සෑමවිටම දර්ශනය වීම අවශ්‍ය නැති විජෙට් එකක් තැටියේ ලාච්චුවට යා හැකිය: එය තැටිය මතට අදින්න, එවිට එය පිළිගැනීමට ලාච්චුව විවෘත වේ. එය යෙදුම් අයිකනවලින් පසුව එහි හිඳියි, ලාච්චුව දිස්වන සෑම විටම එයත් දිස් වේ, සහ එහි පැනලය විවෘතව තිබෙන තාක් කල් එහි ලාච්චුව විවෘතව තබයි. එය ආපසු තැබීමට එය නැවත තීරුව මතට අදින්න.

ඔබ මෙනුවකින් තෝරා ගැනීමට කැමති නම්, **ක්‍රියාත්මක → පෙනුම → මෙනු තීරුව** හි පිහිටුම ඇති අතර, **තීරු පසුබිම** තීරුව ඇඳෙන්නේ කෙසේද යන්න තෝරයි: **අපාරදෘශ්‍ය තීරුව**, **වීදුරු තීරුව** (පෙනෙන, පිටුපස ඇති දේ බොඳ කර ඇති), හෝ **පැහැදිලි තීරුව**.

එම දේවල්ම විධාන ඇති අතර, එය [dotfiles](31-dotfiles.md) සැකසුමක් සඳහා ඔබට අවශ්‍ය දෙයයි:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.clock --section center --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

විජෙට් එකක් සම්පූර්ණයෙන්ම එක් කිරීමට හෝ ඉවත් කිරීමට, ප්ලගින් විධාන භාවිත කරන්න. `omarchy plugin list` shell එක දන්නා සෑම විජෙට් එකක්ම එහි id එක සමඟ මුද්‍රණය කරයි, ඉන්පසු:

```bash
omarchy plugin enable omarchy.media --section center
omarchy plugin disable omarchy.weather
```

## තීරුව සැඟවීම

`Super + Shift + Space` shell එක නොමරා තීරුව අක්‍රිය කර නැවත සක්‍රිය කරයි — පැනල සහ උණුසුම් යතුරු දිගටම වැඩ කරයි, ඔබට පික්සල ආපසු ලැබේ. එය **ක්‍රියාත්මක → පෙනුම → මෙනු තීරුව → තීරුව සඟවන්න** යටතේ මෙනුවේ ද ඇත.

## වින්‍යාස ගොනුව

මේ සියල්ල `bar` යතුර යටතේ `~/.config/omarchy/shell.json` හි ගබඩා කර ඇත. මෙන්න කෙටි කළ අනුවාදයක්:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "centerAnchor": "omarchy.clock",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

සෑම විජෙට් එකක්ම සැකැස්ම අරා තුනෙන් එකක එක ප්‍රවේශයක් වන අතර, එහි සැකසුම් එම ප්‍රවේශය මතම පිහිටයි — වෙනම සැකසුම් ගොනුවක් නැත සහ `config` උප-වස්තුවක් නැත. ඔරලෝසුවේ `format`, `formatAlt` (දකුණු-ක්ලික් කිරීම චක්‍රීය කරන්නේ කුමකටද), සහ `verticalFormat` සියල්ලම එහිම `{ "id": "omarchy.clock" }` මත ජීවත් වේ.

`centerAnchor` තිරයේ නිශ්චිත මධ්‍යස්ථානයට පින් කරනු ලබන එක් මධ්‍ය විජෙට් එක නම් කරයි, අනෙක් ඒවා එහි දෙපසින්. කාලගුණය සහ යාවත්කාලීන ලාංඡනය එහා මෙහා යන විට පවා ඔරලෝසුව මැදම රැඳී සිටින්නේ එලෙසයි. එය හිස් තන්තුවක් ලෙස සැකසන්න, මධ්‍ය ලැයිස්තුව ඒ වෙනුවට කාණ්ඩයක් ලෙස මධ්‍යගත වේ.

අභ්‍යන්තරීකරණය වටින එක නියමයක්: **ඔබට ඔබේම `shell.json` එකක් ලැබුණු පසු, එය නීත්‍යානුකූලයි**. ඔබ කිසිවක් අභිරුචිකරණය කරන තෙක්, shell එක Omarchy හි පෙරනිමි ගොනුව කියවයි. ඔබ විජෙට් එකක් ඇදගෙන යන, `omarchy bar` ධාවනය කරන, හෝ ගොනුව තනිවම සංස්කරණය කරන මොහොතේදී, එය ඔබ සතුයි — ගැඹුරු ඒකාබද්ධ කිරීමක් නැත, එබැවින් අනාගත Omarchy නිකුතුවල නව පෙරනිමි විජෙට් ඔබේ තීරුවේ ස්වයංක්‍රීයව දිස් නොවනු ඇත. ඔබට පිරිසිදු ආරම්භයක් අවශ්‍ය වූ විට සෑම විටම `omarchy bar defaults` නැව්ගත කළ සැකැස්ම නැවත තබයි.

එම ගොනුවම `bar` යතුරෙන් පිටත ඉහළ මට්ටමේ ඔබේ අක්‍රිය වේලාවන් ද රඳවා ගනී: `idle.screensaver` සහ `idle.lock`, දෙකම ඔබ අක්‍රිය වූ දා සිට තත්පර වලින්. එබැවින් පෙරනිමි තිර ආරක්ෂකය තත්පර 150 කින් සහ අගුල තත්පර 300 කින් ක්‍රියාත්මක වේ.
