# ඉහළ තීරුව

ඔබේ තිරයේ ඉහළින් ඇති තීරුව Omarchy තීරුවයි. එය බෝල්ට් කර සවිකළ තත්ත්ව තීරුවක් නොව Omarchy shell එකේම කොටසකි. එය මෙනුව, දැනුම්දීම්, OSD උත්පතන සහ අගුළු තිරයද අඳින තනි, දිගු කාලයක් ක්‍රියාත්මක වන Quickshell ක්‍රියාවලියමයි. ඒ නිසාම එය අනෙක් සියල්ල සමඟම පරිපූර්ණව තේමා වන අතර, නව app එකක් ආරම්භ කරනවා වෙනුවට පැනලයක් ක්ෂණිකව විවෘත වේ.

එය සැමවිටම තිරයේ පවතින එකම desktop කොටසද වන බැවින්, එම කුඩා ග්ලිෆ් සියල්ල කරන්නේ කුමක්දැයි දැන ගැනීම වටී.

## පෙරනිමියෙන් එහි ඇත්තේ මොනවාද

තීරුවට කොටස් තුනක් ඇත. වම් පසින් Omarchy ලාංඡනය (මෙනු දියත් කරන්නා) සහ workspace දර්ශක පිහිටයි. මැදින් ඔබට තත්ත්ව දර්ශක, ඔරලෝසුව, Elsewhen (ලෝක ඔරලෝසුවක්), කාලගුණය සහ Omarchy යාවත්කාලීන ලාංඡනය ලැබේ. දකුණු පසින්: system tray එක, යතුරුපුවරු පිරිසැලසුම (එකකට වඩා වින්‍යාස කර ඇති විට), agents, bluetooth, network, audio, display සහ power.

ඒවායින් සමහරක් දිස්වන්නේ ඒවාට කීමට යමක් ඇති විට පමණි. යතුරුපුවරු පිරිසැලසුම දිස්වන්නේ ඔබ පිරිසැලසුම් එකකට වඩා වින්‍යාස කර ඇත්නම් පමණි. Omarchy යාවත්කාලීනයක් බලාපොරොත්තුවෙන් සිටින විට පමණක් යාවත්කාලීන ලාංඡනය දිස්වේ. තවද agents අයිකනය දිස්වන්නේ Omarchy විසින් යන්ත්‍රයේ AI coding භාවිතය මුල් වරට සොයා ගත් විටය (බලන්න [AI](17-ai.md)).

## පැනල

තීරු අයිකනයක් ක්ලික් කිරීමෙන් පැනලයක් විවෘත වේ. එය tooltip එකක් වෙනුවට sliders, ලැයිස්තු සහ යතුරුපුවරු සංචාලනය සහිත නිසි උත්පතනයකි. ඒ සෑම එකකටම කෙටි යතුරක්ද ඇත, එබැවින් ඔබට කිසිවිටෙක pixel 16ක ග්ලිෆයක් ඉලක්ක කිරීමට සිදු නොවේ:

| කෙටි යතුර | පැනලය |
| --- | --- |
| `Super + Ctrl + A` | Audio |
| `Super + Ctrl + N` | Network |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | Display |
| `Super + Ctrl + P` | Power |
| `Super + Ctrl + Alt + D` | Calendar |
| `Super + Ctrl + Alt + E` | World clock |
| `Super + Ctrl + 1-9` | දකුණු කොටසේ n වැනි පැනලය මාරු කරන්න |

පැනල යනු කියවීමට පමණක් ඇති දේවල් නොවේ. ඔබ සැබවින්ම දෙයක් කරන්නේ ඒවා තුළිනි:

- **Audio** හි ප්‍රධාන ශබ්ද පරිමා slider එකක්, output-device තේරීමක් සහ per-app mixer එකක් ඇත, එබැවින් අනෙක් සියල්ල ස්පර්ශ නොකර ඔබට එම එක් browser tab එකක ශබ්දය අඩු කළ හැකිය.
- **Network** Wi-Fi සඳහා පරිලෝකනය කරයි, signal ශක්තිය පෙන්වයි, සම්බන්ධ වේ, සහ DNS provider කෙනෙක් තෝරා ගැනීමට ඔබට ඉඩ දෙයි.
- **Bluetooth** ඔබේ උපාංග connect/disconnect සහ battery මට්ටම් සමඟ ලැයිස්තුගත කරයි.
- **Power** battery සංඛ්‍යාලේඛන පෙන්වයි, power profiles මාරු කරයි (එය battery සහ AC සඳහා වෙනම තේරීමක් මතක තබා ගනී), සහ යම් system තොරතුරු මුද්‍රණය කරයි.
- **Display** හි දීප්ති slider එකක්, text ප්‍රමාණය, monitor scaling presets, සහ — ඔබට තිර එකකට වඩා ඇති විට — per-monitor පාලන ඇත. ගැඹුරු කතාව සඳහා බලන්න [monitors](33-monitors.md).
- **Clock** ISO සති අංක සහ මාසය පියවරෙන් පියවර වෙනස් කිරීම සහිත මාස grid එකක් විවෘත කරයි.
- **World clock** නගරයකට එක් පේළිය බැගින් තබා ගනී, එහි කාලගුණය සහ එහි දවස ගෙවී යන ආකාරය සමඟ. සෙවීමෙන් වේලා කලාප මෙන්ම නගරද සොයා ගනී, එබැවින් Fort Lauderdale යනු Fort Lauderdale මිස New York නොවේ. ඉහළින් ඇති පේළිය වැරදි නගරය නම් කරන්නේ නම්, එය ක්ලික් කර ඔබ සිටින්නේ කොහේදැයි කියන්න; වෙනත් වේලා කලාපයක තැනක් තෝරන්න, එවිට system clock එකද එහි ගමන් කරයි, ඔබ ගමන් කරන විට එය ප්‍රයෝජනවත් වේ. නගරයක් මත hover කර person බොත්තම ක්ලික් කර එහි ජීවත් වන්නේ කවුදැයි කියන්න — සරල නම්, නැතහොත් ඔවුන්ගේ මුහුණුද රැගෙන ඒමට `@` GitHub handles.

සෑම පැනලයක්ම මූසිකය මෙන්ම යතුරුපුවරුවද ගනී: ඊතල ගමන් කරයි, Return සක්‍රිය කරයි, Tab අසල්වැසි පැනලයට පියවර තබයි, සහ Escape වසා දමයි.

`Super + Ctrl + 1-9` දකුණු කොටසේ පැනල වමේ සිට දකුණට ගණන් කරයි, tray එකට තමන්ගේම පැනලයක් නොමැති බැවින් එය මඟ හරිමින්. එබැවින් අංකය ඔබ යොමු කරන අයිකනයට ගැළපේ.

### Tailscale සහ Dropbox

තවත් විජට්ටු දෙකක් තීරුව මත දිස්වන්නේ ඔබ **Install → Service** වෙතින් ගැළපෙන සේවාව ස්ථාපනය කළ පසු පමණි, සහ ඒ දෙකම දැන ගැනීම වටී, මන්ද ඒවා තත්ත්වය වාර්තා කිරීමට වඩා වැඩි යමක් කරයි.

**Tailscale** පැනලය tailnet එක සම්බන්ධ කර විසන්ධි කරයි, ගිණුම් අතර මාරු වේ, සහ exit node එකක් තෝරයි (ඔබේම යන්ත්‍ර සහ Mullvad regions දෙකම එම ලැයිස්තුවේ දිස්වේ). එය ඔබේ යන්ත්‍රද පිරික්සයි — සහ එකක් තෝරාගෙන ඇති විට, `s` Taildrop හරහා එයට ගොනු යවයි, එය ඔබේ දුරකථනයට හෝ වෙනත් laptop එකකට ගොනුවක් ගෙන යාමේ වේගවත්ම ක්‍රමයයි. `c` යන්ත්‍රයේ IP එක පිටපත් කරයි, `n` එහි නම, සහ `d` එහි සම්පූර්ණ DNS නම. ඔබට ක්ලික් කිරීමට අවශ්‍ය නම්, සෑම යන්ත්‍ර පේළියකම send බොත්තමක්ද ඇත. Terminal එකෙන් එම දෙයම `omarchy tailscale send <machine> [file...]` වේ.

**Dropbox** පැනලය login වීම හසුරුවයි, ඔබ කොපමණ storage ප්‍රමාණයක් භාවිතා කර ඇත්දැයි පෙන්වයි, සහ මෑතකදී synced කළ ගොනු ලැයිස්තුගත කරයි.

එම සේවාවන් දෙකෙන් ඕනෑම එකක් ඉවත් කිරීමෙන් එහි විජට්ටුව තීරුවෙන් නැවත ඉවත් වේ.

## දර්ශක

මැද ඇති කුඩා පොකුර indicators විජට්ටුවයි. මේවා ඔබ සක්‍රිය කර ඇති modes සඳහා වූ තත්ත්ව ග්ලිෆ් වේ: do not disturb, night light, පෝලිමේ ඇති [මතක් කිරීමක්](09-reminders.md), සක්‍රිය screen recording එකක්, stay awake, සහ [dictation](11-text-extraction-dictation.md). Mode එක සක්‍රිය විට ඒවා දැල්වෙන අතර, එසේ නොමැති විට මඟහැරී සිටී — අක්‍රිය ඒවා දෙස බැලීමට තීරුවේ ඕනෑම තැනක hover කරන්න. දර්ශකයක් ක්ලික් කිරීමෙන් එම mode එක මාරු වේ. තවත් එකක් තත්ත්වය පමණක් පෙන්වයි: gliff හරහා යමෙක් මෙම යන්ත්‍රයට සම්බන්ධ වී සිටින අතරතුර remote session එකක් රතු පැහැයෙන් දැල්වේ.

ඔබ ඒවා සැමවිටම දිස්වීමට කැමති නම්, විජට්ටුව මත `alwaysShow` `true` ලෙස සකසන්න. ඔබ ඒවායින් සමහරක් ගැන පමණක් සැලකිලිමත් නම්, ඔබට අවශ්‍ය ඒවා `items` හි ලැයිස්තුගත කරන්න: `["Dnd", "Reminder", "NightLight"]`. ඔබට indicators විජට්ටු එකකට වඩා තිබිය හැකි බැවින්, විවිධ කොටස්වලට විවිධ උපකුලක පෙන්විය හැකිය.

## තීරුව නැවත සකස් කිරීම

තීරුව තනිවම වින්‍යාස වේ. දේවල් ගෙන යාමට ඔබට config ගොනුවක් විවෘත කිරීමට සිදු නොවේ.

මැද අවට ඇති තීරුවේ හිස් කොටසක් අල්ලා වෙනත් තිර දාරයක් දෙසට එය ඇදගෙන යන්න, එවිට තීරුව එහි ගමන් කරයි — වම, දකුණ, ඉහළ හෝ පහළ යන සියල්ල ක්‍රියා කරයි, සහ සෑම විජට්ටුවක්ම අනුවර්තනය වේ (සිරස් තීරු compact icon-only ආකෘතිවලට පෙරළේ). Click-and-hold එකකින්ද එම ඇදගෙන යාමම ආරම්භ වේ. එම හිස් ඉඩම මත double-left-click කර තීරු background එක clear සිට glassy සිට opaque දක්වා චක්‍රීය කරන්න. තවද ඕනෑම විජට්ටුවක් ඇදගෙන ගොස් එය නැවත අනුපිළිවෙළට සකසන්න හෝ වෙනත් කොටසකට එය දමන්න; එය ගොඩබසින තැන ඉඩ සෑදීමට අනෙක් විජට්ටු දෙපසට ලිස්සා යයි.

තීරුවේ මැද box එකකි: එහි ඇති ඕනෑම දෙයක් එක් කණ්ඩායමක් ලෙස මධ්‍යගතව පවතින අතර, එය දෙපස ඇති විජට්ටු එහි දාරවලින් එල්ලේ. ඔබ විජට්ටුවක් අදින අතරතුර box එක outline එකක් ලෙස පෙන්වයි, නැතහොත් එය හිස් විට තීරුව හරහා ඇති රේඛාවක් ලෙස පෙන්වයි, සහ ඔබට එය තුළට හෝ එය අසලට දැමිය හැකිය. Drop එකක් box එක තුළට වැටෙන විට, විජට්ටුව ඇතුළු කර ගැනීමට box එක වැඩේ.

ඔබට අවට තබා ගැනීමට අවශ්‍ය නමුත් සැමවිටම නොපෙනෙන විජට්ටුවක් tray එකේ drawer එකට යා හැකිය: එය tray එක මතට අදින්න, එවිට එය ඇතුළු කර ගැනීමට drawer එක විවෘත වේ. එය app අයිකනවලින් පසුව එහි හිඳී, drawer එක දිස්වන සෑම විටම දිස්වේ, සහ එහි පැනලය ඇති අතරතුර එහි drawer එක විවෘතව තබා ගනී. එය නැවත තීරුව මතටම අදින්න, එය ආපසු තැබීමට.

ඔබ මෙනුවකින් තෝරා ගැනීමට කැමති නම්, **Appearance → Menu Bar** හි පිහිටීම ඇති අතර, **Bar Background** තීරුව අඳින ආකාරය තෝරයි: **Opaque Bar**, **Glassy Bar** (පසුව ඇති දේ බොඳ කර ඇති, හරහා පෙනෙන), නැතහොත් **Clear Bar**.

එම දේවල් සඳහාම commands ද ඇත, එය [dotfiles](31-dotfiles.md) සැකසුමක් සඳහා ඔබට අවශ්‍ය දෙයයි:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

විජට්ටුවක් සම්පූර්ණයෙන්ම එක් කිරීමට හෝ ඉවත් කිරීමට, plugin commands භාවිතා කරන්න. `omarchy plugin list` shell එක දන්නා සෑම විජට්ටුවක්ම එහි id එක සමඟ මුද්‍රණය කරයි, ඉන්පසු:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## තීරුව සැඟවීම

`Super + Shift + Space` shell එක නොමරා තීරුව අක්‍රිය කර නැවත සක්‍රිය කරයි — පැනල සහ hotkeys දිගටම ක්‍රියා කරයි, ඔබට pixels නැවත ලැබෙනවා පමණි. එය මෙනුවේ **Appearance → Menu Bar → Hide Bar** යටතේද ඇත.

## Config ගොනුව

මේ සියල්ල `~/.config/omarchy/shell.json` හි, `bar` යතුර යටතේ ගබඩා කර ඇත. මෙන්න කෙටි කළ අනුවාදයක්:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

සෑම විජට්ටුවක්ම layout arrays පහෙන් එකක එක් ප්‍රවේශයක් වන අතර, එහි settings ඒ ප්‍රවේශය මතම inline ලෙස පිහිටයි — වෙනම settings ගොනුවක් නැත, `config` උප-වස්තුවක්ද නැත. Clock එකේ `format`, `formatAlt` (දකුණු ක්ලික් කිරීම චක්‍රීය කරන්නේ කුමක් වෙතද යන්න), සහ `verticalFormat` යන සියල්ල `{ "id": "omarchy.clock" }` මතම එහිම පිහිටයි.

`center` යනු තීරුවේ මැද ඇති box එකයි: එහි ඇති සියල්ල එක් කණ්ඩායමක් ලෙස තිරයේ මධ්‍යගත කරනු ලැබේ. `centerBegin` සහ `centerEnd` box එක දෙපසින් එල්ලෙන අතර, කාලගුණය සහ යාවත්කාලීන ලාංඡනය එහා මෙහා වන විට පවා clock එක නිශ්චිතවම මැද රැඳෙන්නේ එලෙසිනි. `center` හි විජට්ටු එකකට වඩා තබන්න, එවිට ඒවා එකට මධ්‍යගත වේ; එය හිස්ව තබන්න, එවිට `centerBegin` සහ `centerEnd` තීරුවේ මැදදී හමු වේ.

අභ්‍යන්තරකරණයට වටිනා එක් නීතියක්: **ඔබට ඔබේම `shell.json` එකක් ලැබුණු පසු, එය ප්‍රාමාණිකය**. ඔබ කිසිවක් අභිරුචිකරණය කරන තෙක්, shell එක Omarchy හි පෙරනිමි ගොනුව කියවයි. ඔබ විජට්ටුවක් ඇදගෙන ගිය, `omarchy bar` ධාවනය කළ, නැතහොත් ගොනුව ඔබම සංස්කරණය කළ මොහොතේ, එය ඔබ සතු වේ — deep merge එකක් නැත, එබැවින් අනාගත Omarchy නිකුතුන්හි නව පෙරනිමි විජට්ටු ඔබේ තීරුවේ ස්වයංක්‍රීයව දිස් නොවනු ඇත. ඔබට පිරිසිදු ආරම්භයක් අවශ්‍ය ඕනෑම වේලාවක `omarchy bar defaults` නැව්ගත කළ පිරිසැලසුම නැවත තබයි.

එම ගොනුවම ඉහළ මට්ටමේ, `bar` යතුරෙන් පිටත ඔබේ idle කාලයන්ද තබා ගනී: `idle.screensaver` සහ `idle.lock`, දෙකම ඔබ idle වූ පසු තත්පර වලින්. එබැවින් පෙරනිමි screensaver එක තත්පර 150දී ආරම්භ වන අතර අගුළ තත්පර 300දී ක්‍රියාත්මක වේ.
