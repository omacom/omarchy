# Windows VM

Omarchy මඟින් x86_64 යන්ත්‍රවල Docker VM එකක් හරහා Windows ධාවනය කිරීමට පහසු ක්‍රමයක් ලබා දේ. Omarchy මෙනුව (`Super + Space`) වෙතින් _ස්ථාපනය > Windows_ භාවිතා කිරීමෙන් ඔබට එය ස්ථාපනය කළ හැකිය.

මේ සඳහා ඔබේ යන්ත්‍රයට KVM virtualization අවශ්‍ය අතර, බොහෝ යන්ත්‍රවල එය ඇත — නමුත් සමහර විට එය BIOS තුළ අක්‍රිය කර ඇති අතර, එසේ නම් ස්ථාපකය ඔබට ඒ බව දැනුම් දෙනු ඇත. ඔබට තැටි ඉඩ ද අවශ්‍ය වනු ඇත: ඔබ Windows වෙත ලබා දෙන ප්‍රමාණය, ඊට අමතරව image එක සඳහාම 10GB පමණ.

ස්ථාපකය ඔබෙන් කොපමණ RAM ප්‍රමාණයක්, CPU cores කීයක්, සහ කොපමණ තැටි ඉඩක් ලබා දෙන්නේ ද යන්න අසයි (64GB හෝ ඊට වැඩි ප්‍රමාණයක් සාධාරණ අවම අගයයි), ඉන්පසු Windows පරිශීලක නාමයක් සහ මුරපදයක් අසයි. ඒවා හිස්ව තැබුවහොත් ඔබට `docker` / `admin` ලැබේ. බාගත කිරීම සඳහා ටික වේලාවක් ගත වේ — විනාඩි 10-15 ක් සාමාන්‍යය — සහ ඔබට බ්‍රවුසරයේ `http://127.0.0.1:8006` වෙතින් ප්‍රගතිය නිරීක්ෂණය කළ හැකිය. කොන්සෝලය විවෘත කිරීමට පෙර බ්‍රවුසරය එම පරිශීලක නාමය සහ මුරපදයම ඉල්ලා සිටියි.

## එය භාවිතා කිරීම

එය ස්ථාපනය කළ පසු, app launcher එකෙන් _Windows_ දියත් කරන්න. එය VM එක දැනටමත් ධාවනය නොවන්නේ නම් එය ආරම්භ කර, සම්පූර්ණ තිරය පුරා RDP හරහා ඔබව සම්බන්ධ කරයි. මුල සිට ආරම්භ කරන විට ඒ සඳහා තත්පර 15-30 ක් ලබා දෙන්න.

RDP සැසිය හරහා ශබ්දය, ඔබේ මයික්‍රෆෝනය, සහ බෙදාගත් clipboard එක ක්‍රියා කරන බැවින්, Linux සහ Windows අතර පෙළ පිටපත් කිරීම කිසිදු ගැටලුවකින් තොරව ක්‍රියාත්මක වේ. resolution එක ඔබේ කවුළුව අනුගමනය කරන අතර, Omarchy ඔබේ display scaling එක ද එය හරහා යවන බැවින්, HiDPI තිරයක වුවද එය බොඳ වූ අවුලක් බවට පත් නොවේ.

ඔබ RDP කවුළුව වැසූ විට, VM එක ස්වයංක්‍රීයව අක්‍රිය වේ. ඔබ එය ධාවනය වෙමින් තැබීමට කැමති නම් — උදාහරණයක් ලෙස එහි ඇතුළත යමක් ක්‍රියාත්මක වෙමින් පවතින්නේ නම් — ඒ වෙනුවට `omarchy windows vm launch --keep-alive` සමඟ එය දියත් කරන්න.

ඉතිරි පාලනයන් ද එම command එකේම ඇත:

```bash
omarchy windows vm status    # is it running?
omarchy windows vm stop      # shut it down
omarchy windows vm launch    # start and connect
```

## ගොනු බෙදා ගැනීම

ඔබේ home directory එකේ ඇති `~/Windows` directory එක VM එක සමඟ ස්වයංක්‍රීයව බෙදා ගනු ලැබේ. ඔබට Windows වෙත ප්‍රවේශ විය හැකි වන පරිදි ගොනු අවශ්‍ය නම් ඒවා එහි දමන්න. VM එකට ඔබේ ගොනු පද්ධතියේ වෙනත් කිසිම කොටසකට ප්‍රවේශය නැති බැවින්, Windows පැත්තෙන් එන ඕනෑම නපුරු දෙයකින් ඔබ ආරක්ෂිතය. එහිම virtual disk එක `~/.windows` හි ඇත.

එම සුපුරුදු home paths ඒවායේම filesystems මත පවතී. ඒවා ඔබට අයත් directories වෙත symlinks ද විය හැකි අතර, virtual disk එක විශාල drive එකක පිහිටා ඇති විට එය ප්‍රයෝජනවත් වේ. ස්ථාපකය නිදහස් ඉඩ මනිනු ලබන්නේ ඔබේ home directory එක අඩංගු filesystem එක මත නොව, ඇත්ත වශයෙන්ම `~/.windows` අඩංගු filesystem එක මතය.

disk සහ shared paths වෙනම, එකිනෙක අතිච්ඡාදනය නොවන directories ලෙස තබා ගන්න. ඉවත් කිරීමේදී හිතාමතාම disk directory එක හිස් කරන නමුත් shared directory එක ආරක්ෂා කරයි. මකා දැමීමට මොහොතකට පෙර, Omarchy සීමා සහිත containment පරීක්ෂාවක් සිදු කරන අතර, එම පරීක්ෂාව කල් ඉකුත් වුවහොත් හෝ එම tree දෙක වෙනම පවතින බව ඔප්පු කිරීමට නොහැකි වුවහොත් කිසිවක් ඉවත් කිරීම ප්‍රතික්ෂේප කරයි.

VM එක ආරම්භ වීමට පෙර, Omarchy එම directories දෙක විවෘත කර pin කරයි, ඉන්පසු `/var/lib/omarchy/windows/mounts` යට ඇති පෞද්ගලික per-user anchors මත නිශ්චිත directory inodes bind-mount කරයි. Docker දකින්නේ root මඟින් ආරක්ෂා කළ එම anchors පමණි. මෙය custom disk locations ආරක්ෂා කරන අතරම, privileged container එක එය භාවිතා කිරීමට පෙර ඔබ ලෙස ධාවනය වන වෙනත් ක්‍රියාවලියක් මඟින් පරීක්ෂා කළ path එක මාරු කිරීම වළක්වයි. පවතින disk සහ shared directories සංක්‍රමණය අතරතුර `0700` mode එකට තද කරන බැවින් වෙනත් local accounts වලට ඒවායේ අන්තර්ගතය පිරික්සීමට නොහැකි වේ.

VM එකේ ports localhost වෙත පමණක් බැඳ ඇති බැවින්, ඔබේ ජාලයේ සිටින කිසිවෙකුට Windows යන්ත්‍රයට ළඟා විය නොහැක. web console එකට ද වින්‍යාස කළ Windows පරිශීලක නාමය සහ මුරපදය අවශ්‍ය වන බැවින්, වෙනත් local account එකකට port 8006 හරහා VM එක පාලනය කිරීමට නොහැකි වේ.

## සීමාවන් සහ බලපත්‍රකරණය

මෙම සැකසුම සමඟ GPU passthrough නොමැති බැවින්, එය gaming හෝ video editing සඳහා සුදුසු නොවේ. Microsoft Office හෝ ඔබට අනිවාර්යයෙන්ම තිබිය යුතු වෙනත් ඕනෑම දෙයක් ධාවනය කිරීමට මෙය කදිම ක්‍රමයකි.

ස්ථාපනය වන version එක Windows 11 Pro වන අතර, එය activate කර නොමැත. gated features භාවිතා කිරීමට ඔබටම අයත් license key එකක් අවශ්‍ය වනු ඇත.

මෙම පරිගණකය Windows සමඟ නිකුත් වූ එකක් නම්, Omarchy ස්ථාපනය කිරීමෙන් පසුවද OEM key එක firmware තුළ තවමත් පවතී. `omarchy windows key` සමඟ එය මුද්‍රණය කරන්න. එම key එක මෙම යන්ත්‍රයටම බැඳී ඇත — මෙම hardware එක මත නැවත ස්ථාපනය කළ Windows එය activate කරනු ඇත, නමුත් සාමාන්‍යයෙන් VM එක activate නොකරනු ඇත.

ඔබට පසුව terminal එකක `omarchy windows vm install` ධාවනය කිරීමෙන් resource allocation එක වෙනස් කළ හැකි අතර, එය ඔබේ පිළිතුරු අනුව VM එකේ configuration එක නැවත ලියයි. compose file එකම දැන් `/var/lib/omarchy/windows/docker-compose.yml` හි පිහිටා ඇති අතර එය root සතුය — එය හිතාමතාම සිදු කළ දෙයකි, ඒ නිසා ඔබ ලෙස ධාවනය වන ක්‍රියාවලියකට එය නැවත ලිවීමටත්, privileged bring-up එක මඟින් ඔබේ සම්පූර්ණ disk එක container එක තුළට mount කිරීමටත් නොහැකි වේ. ඔබට එය අතින් edit කිරීමට අවශ්‍ය නම් (උදාහරණයක් ලෙස USB device එකක් mount කිරීමට), `sudo` සමඟ එය edit කර [Dockur Windows ව්‍යාපෘතිය](https://github.com/dockur/windows) හි ඇති සියලුම options බලන්න.

මෙම සම්පූර්ණ දෙයම ඉවත් කිරීමට, Omarchy මෙනුවෙන් _ඉවත් කිරීම > Windows_ භාවිතා කරන්න. එය `~/.windows` හි ඇති VM එකේ disk එක සහ Windows ඇතුළත ස්ථාපනය කළ සියල්ල මකා දමන බැවින්, ඔබට අවශ්‍ය ඕනෑම දෙයක් පළමුව VM එකෙන් පිටතට පිටපත් කරන්න. ඔබේ බෙදාගත් `~/Windows` folder එක එලෙසම තබනු ලැබේ.
