# යාවත්කාලීන කිරීම්

Omarchy සහ ඔබේ පැකේජ යාවත්කාලීනව පවත්වා ගනු ලබන්නේ Omarchy මෙනුවේ (`Super + Space`) _Update > Omarchy_ හරහාය.

Omarchy, [Omarchy පැකේජ ගබඩාව](https://github.com/omacom-io/omarchy-pkgs) වෙතින් සාමාන්‍ය pacman පැකේජ ලෙසම ස්ථාපනය කර ඇති බැවින්, යාවත්කාලීනයක් මඟින් [නවතම Omarchy නිකුතුව](https://github.com/omacom/omarchy/releases) ස්ථාපනය කරයි, ඔබේ පද්ධතිය නවතම තත්ත්වය සමඟ සමමුහුර්ත කිරීමට බලාපොරොත්තුවෙන් ඇති ඕනෑම සංක්‍රමණයක් ධාවනය කරයි, සහ [Omarchy Arch Mirror](https://github.com/omacom-io/omarchy-mirror) සහ [AUR](https://aur.archlinux.org/) වෙතින් සියලුම පද්ධති පැකේජ යාවත්කාලීන කරයි (ඔබ යම් AUR පැකේජ ස්ථාපනය කර ඇත්නම්).

නව නිකුතු නිකුත් කළ විට, ඔබේ ඔරලෝසුවට දකුණු පසින් රවුම් ඊතල අයිකනයක් දිස් වේ. එය ක්ලික් කරන්න, යාවත්කාලීන කිරීමේ ක්‍රියාවලිය ආරම්භ වේ.

### නාලිකා හතරක්

Omarchy නාලිකා හතරක් ඔස්සේ යාවත්කාලීන වේ: stable, RC, edge, සහ dev. නව ස්ථාපනයන් ආරම්භ වන්නේ [නිල නිකුතු](https://github.com/omacom/omarchy/releases/) අනුගමනය කරන stable නාලිකාවෙනි, එසේම නවතම තත්ත්වයට වඩා මාසයක් පසුපසින් ධාවනය වන [stable Omarchy Arch mirror](https://github.com/omacom-io/omarchy-mirror) එක ද සමඟිනි, එවිට වින්‍යාස වෙනස්කම් අවශ්‍ය වන නව නොගැළපීම් කිසිවක් මිනිසුන්ට ගැටලු ඇති කිරීමට පෙර අපට හඳුනා ගත හැක.

නමුත් එම විය හැකි ගැටලු හඳුනා ගැනීමට උදව් කිරීමට ඔබ කැමති නම්, ඔබට edge නාලිකාවෙන් ධාවනය විය හැක. එවිට ඔබේ Omarchy පැකේජ නවතම සංවර්ධන ගොඩනැගීම් අනුගමනය කරමින් පවතිනු ඇති අතර, Arch පැකේජ ලබා ගත හැකි වූ වහාම ඒවායේ නවතම අනුවාද වෙත යාවත්කාලීන වීමට ඔබට ඉඩ සලසයි. ඔබ Linux පිළිබඳ පළපුරුදු අයෙකු නම් සහ ගැටලු ඇති පද්ධතියක් යථා තත්ත්වයට පත් කරන ආකාරය දන්නේ නම් පමණක් ඔබ මෙය කළ යුතුය.

ඕනෑම නව ප්‍රධාන නිකුතුවකට පෙර, අපි RC නාලිකාව භාවිතා කර අවසාන වලංගුකරණය සිදු කරන්නෙමු. අවසාන ඔප දැමීමට උදව් කිරීමට ඔබ කැමති නම්, Discord හි #omarchy-release-candidates වෙත පැමිණ ඇසුරු කරන්න.

අවසාන වශයෙන්, edge පැකේජ සමඟ ඒකාබද්ධව, Omarchy කෙලින්ම `~/omarchy` හි ඇති මූලාශ්‍ර කේතයේ git පිටපතකට සම්බන්ධ කරන dev නාලිකාව ඇත. ඔබ පළපුරුදු Linux පරිශීලකයෙකු නම්, Omarchy මත කෙලින්ම වැඩ කරන්නේ නම්, සහ බිඳ වැටීම් ඉවසා සිටීමට කැමති නම් පමණක් ඔබ මෙම නාලිකාව භාවිතා කළ යුතුය.

Omarchy මෙනුවෙන් _Update > Channel_ භාවිතා කර (හෝ පර්යන්තයේ `omarchy channel set <stable|rc|edge|dev>` භාවිතා කර, ඔබ සිටින්නේ කොහේදැයි බැලීමට `omarchy channel current` සමඟ) ඔබට නාලිකා අතර මාරු විය හැක.

### කර්නල් මාරු කිරීම

Omarchy එහිම `linux-omarchy` කර්නලය ආරම්භ කරයි, නමුත් ඔබට සම්මත Arch `linux` කර්නලය හෝ ඔබ පරීක්ෂා කරන පර්යේෂණාත්මක ගොඩනැගීමක් වැනි වෙනත් කර්නල් ඒ අසලම ස්ථාපනය කර තබා ගත හැක. එකකට වඩා වැඩි ගණනක් ඇති විට, Omarchy මෙනුවේ _Update > Kernel_ මඟින් ඒවා ලැයිස්තුගත කරන අතර පෙරනිමියෙන් ආරම්භ වන එක අසල සලකුණක් යොදයි. වෙනත් එකක් තෝරන්න, ඔබේ මුරපදය වරක් ඇතුළත් කරන්න, එවිට එය මීළඟ නැවත ආරම්භයෙන් පසු ආරම්භ වේ. අනෙකුත් කර්නල් ආරම්භක මෙනුවේ පවතිනු ඇත, එබැවින් නව පෙරනිමිය ඔබට ගැටලු ඇති කරන්නේ නම් ඔබට තවමත් අතින් එකක් තෝරා ගත හැක. පර්යන්තයේ, වත්මන් පෙරනිමිය බැලීමට `omarchy kernel` ද, ස්ථාපනය කර ඇති දේ සඳහා `omarchy kernel list` ද, මාරු වීමට `omarchy kernel set <kernel>` ද භාවිතා කරයි.

### ස්ථිරාංග යාවත්කාලීන කිරීම්

ඔබේ පැකේජ පමණක් නොවේ යල් පැන යන්නේ. බොහෝ ලැප්ටොප් සහ පර්යන්ත උපාංග Linux Vendor Firmware Service හරහා BIOS, SSD, සහ dock ස්ථිරාංග සපයන අතර, Omarchy මෙනුවේ _Update > Firmware_ මඟින් ඔබේ දෘඩාංග සඳහා බලාපොරොත්තුවෙන් ඇති ඕනෑම දෙයක් ලබා ගෙන ස්ථාපනය කරයි. ඔබ එය පළමු වරට ධාවනය කරන විට එය `fwupd` ස්ථාපනය කරයි. බොහෝ ස්ථිරාංග ලිවිය හැක්කේ නැවත ආරම්භයක් අතරතුර පමණක් බැවින්, එකක් ඉල්ලා සිටියහොත් පුදුම නොවන්න.

ඔබටම BIOS තුළම සැකසුමක් වෙනස් කිරීමට අවශ්‍ය වූ විට, පද්ධති මෙනුවේ (`Super + Escape`) `Alt` ඔබාගෙන සිටින්න, එවිට _Reboot_ යන්න _Reboot to BIOS_ බවට හැරේ, එය ආරම්භයේදී නිවැරදි යතුර අල්ලා ගැනීමට සිදු නොවී කෙලින්ම ස්ථිරාංග සැකසුම වෙත නැවත ආරම්භ කරයි. පර්යන්තයෙන්, එය `omarchy system firmware` වේ.

### සෘජු pacman/yay යාවත්කාලීන කිරීම් පිළිබඳ අනතුරු ඇඟවීම

ඔබ දැනටමත් Arch පිළිබඳ හුරුපුරුදු නම්, ඔබටම `pacman -Syu` හෝ `yay -Syu` ධාවනය කිරීමට පෙලඹෙනු ඇත, නමුත් ඔබ එසේ කළහොත්, Omarchy නව පැකේජ සමඟ එක්ව ධාවනය කරන snapshot එක, සංක්‍රමණ, සහ වින්‍යාස යාවත්කාලීන කිරීම් ඔබට මග හැරෙනු ඇත. එබැවින් Omarchy ඇත්ත වශයෙන්ම සෘජු පද්ධති උත්ශ්‍රේණි කිරීමක් නවතා ඒ වෙනුවට `omarchy update` වෙත ඔබව යොමු කරයි. (ඔබ ඇත්ත වශයෙන්ම කරන්නේ කුමක්දැයි දන්නේ නම්, එම ආරක්ෂකය තනි ගනුදෙනුවක් සඳහා එය මග හරින ආකාරය ඔබට කියනු ඇත.)

### අයහපත් යාවත්කාලීන කිරීම් ආපසු හරවා ගැනීම

යාවත්කාලීනයක් සිදු කිරීමෙන් පසු ඔබට කවදා හෝ ගැටලුවක් ඇති වුවහොත්, යාවත්කාලීනයට පෙර ගත් snapshot එක වෙත ඔබේ පද්ධතිය ආපසු හරවා ගත හැක. සරලවම නැවත ආරම්භ කර ඔබ යාවත්කාලීනය ආරම්භ කිරීමට පෙර තිබූ snapshot එක ආරම්භක පැටවීමේ මෙනුවෙන් තෝරන්න.

කෙසේ හෝ ඔබේ වින්‍යාස ගොනු දූෂිත වී ඇත්නම්, ඔබට පර්යන්තයේ `omarchy reinstall` භාවිතා කර Omarchy නැවත ස්ථාපනයක් ද සිදු කළ හැක. මෙය සියලුම පෙරනිමි Omarchy පැකේජ නැවත ස්ථාපනය කරයි, ඔබව stable මතට (Apple Silicon මත edge) දමයි සහ අතිශයින් නව ඕනෑම පැකේජ පහත හෙලයි, සහ සියලුම වින්‍යාස ගොනු යළි සකසයි. මෙය කිරීමේදී Omarchy පෙරනිමි වෙත ඔබ කළ සියලුම පරිශීලක වින්‍යාස වෙනස්කම් උඩින් ලියැවෙන බව සලකන්න!
