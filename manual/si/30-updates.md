# යාවත්කාලීන කිරීම්

Omarchy මෙනුවේ (`Super + Space`) _යාවත්කාලීන > Omarchy_ හරහා Omarchy සහ ඔබේ පැකේජ යාවත්කාලීනව තබා ගනු ලැබේ.

Omarchy එයම [Omarchy පැකේජ ගබඩාවෙන්](https://github.com/omacom-io/omarchy-pkgs) සාමාන්‍ය pacman පැකේජ ලෙස ස්ථාපනය කර ඇති බැවින්, යාවත්කාලීනයක් [නවතම Omarchy නිකුතුව](https://github.com/omacom/omarchy/releases) ස්ථාපනය කරයි, ඔබේ පද්ධතිය නවතම එක සමඟ සමමුහුර්ත කිරීමට බලාපොරොත්තුවෙන් ඇති ඕනෑම සංක්‍රමණයක් ක්‍රියාත්මක කරයි, සහ [Omarchy Arch Mirror](https://github.com/omacom-io/omarchy-mirror) සහ [AUR](https://aur.archlinux.org/) වෙතින් (ඔබ කිසියම් AUR පැකේජ ස්ථාපනය කර ඇත්නම්) සියලුම පද්ධති පැකේජ යාවත්කාලීන කරයි.

නව නිකුතු නිකුත් කළ විට, ඔබේ ඔරලෝසුවට දකුණින් රවුම් ඊතල අයිකනයක් දිස් වනු ඇත. එය click කරන්න, එවිට යාවත්කාලීන කිරීමේ ක්‍රියාවලිය ආරම්භ වනු ඇත.

### නාලිකා හතර

Omarchy නාලිකා හතරක් ඔස්සේ යාවත්කාලීන වේ: stable, RC, edge, සහ dev. නව ස්ථාපනයන් stable නාලිකාවෙන් ආරම්භ වන අතර, එය [නිල නිකුතු](https://github.com/omacom/omarchy/releases/) මෙන්ම නවතම එකට වඩා මාසයක් පසුපසින් ධාවනය වන [ස්ථායී Omarchy Arch mirror එකද](https://github.com/omacom-io/omarchy-mirror) අනුගමනය කරයි, එබැවින් config වෙනස්කම් අවශ්‍ය වන ඕනෑම නව නොගැලපීමක් මිනිසුන්ට ගැටලු ඇති කිරීමට පෙර අපට හඳුනා ගත හැක.

එහෙත් එම විය හැකි ගැටලු හඳුනා ගැනීමට උදවු කිරීමට ඔබ කැමති නම්, ඔබට edge නාලිකාවේ ධාවනය විය හැක. එය ඔබේ Omarchy පැකේජ නවතම සංවර්ධන build අනුගමනය කරමින් තබන අතර, නවතම Arch පැකේජ ලබා ගත හැකි වූ වහාම ඒවාට යාවත්කාලීන වීමට ඔබට ඉඩ දෙයි. ඔබ Linux පිළිබඳ පළපුරුදු නම්, සහ ගැටලු ඇති පද්ධතියක් යථා තත්ත්වයට පත් කරන ආකාරය දන්නේ නම් පමණක් ඔබ මෙය කළ යුතුය.

ඕනෑම නව ප්‍රධාන නිකුතුවකට පෙර, අපි RC නාලිකාව භාවිතයෙන් අවසාන වලංගුකරණය සිදු කරන්නෙමු. අවසාන ඔප දැමීමට උදවු කිරීමට ඔබ උනන්දු නම්, Discord හි #omarchy-release-candidates වෙත පැමිණ අප සමඟ එක්වන්න.

අවසාන වශයෙන්, dev නාලිකාව ඇත, එය edge පැකේජ සමඟ ඒකාබද්ධව, `~/omarchy` හි ඇති මූලාශ්‍ර කේතයේ git checkout එකකට Omarchy සෘජුවම සම්බන්ධ කරයි. ඔබ පළපුරුදු Linux භාවිතා කරන්නෙකු නම්, Omarchy මත සෘජුවම වැඩ කරන්නේ නම්, සහ බිඳවැටීම් ඉවසීමට කැමති නම් පමණක් ඔබ මෙම නාලිකාව භාවිත කළ යුතුය.

Omarchy මෙනුවෙන් _යාවත්කාලීන > Channel_ භාවිතයෙන් (හෝ terminal එකේ `omarchy-channel-set`) ඔබට නාලිකා අතර මාරු විය හැක.

### Kernel මාරු කිරීම

Omarchy එහිම `linux-omarchy` kernel එක boot කරයි, නමුත් ඔබට stock Arch `linux` kernel එක හෝ ඔබ පරීක්ෂා කරන පර්යේෂණාත්මක build එකක් වැනි අනෙක් ඒවා ඊට යාබදව ස්ථාපනය කර තබා ගත හැක. එකකට වඩා ඇති විට, Omarchy මෙනුවේ _යාවත්කාලීන > Kernel_ ඒවා ලැයිස්තුගත කරන්නේ පෙරනිමියෙන් boot වන එක අසල check සලකුණක් සමඟිනි. වෙනත් එකක් තෝරන්න, ඔබේ මුරපදය වරක් ඇතුළත් කරන්න, එවිට එය ඊළඟ restart එකෙන් පසුව boot වනු ඇත. අනෙක් kernel boot මෙනුවේම පවතින බැවින්, නව පෙරනිමිය ඔබට කරදරයක් ලබා දෙන්නේ නම් ඔබට තවමත් අතින් එකක් තෝරා ගත හැක. Terminal එකේ, වත්මන් පෙරනිමිය බැලීමට `omarchy-kernel`, ස්ථාපනය කර ඇති දේ සඳහා `omarchy-kernel list`, සහ මාරු වීමට `omarchy-kernel set <kernel>` වේ.

### Firmware යාවත්කාලීන කිරීම්

කල් ඉකුත් වන්නේ ඔබේ පැකේජ පමණක් නොවේ. බොහෝ laptop සහ පර්යන්ත උපාංග BIOS, SSD, සහ dock firmware Linux Vendor Firmware Service හරහා ලබා දෙන අතර, Omarchy මෙනුවේ _යාවත්කාලීන > Firmware_ ඔබේ දෘඩාංගය බලාපොරොත්තුවෙන් ඇති ඕනෑම දෙයක් ලබා ගෙන ස්ථාපනය කරනු ඇත. ඔබ එය පළමු වරට ධාවනය කරන විට එය `fwupd` ස්ථාපනය කරයි. බොහෝ firmware ලිවිය හැක්කේ reboot එකක් අතරතුර පමණක් බැවින්, එකක් ඉල්ලා සිටිනු ලැබුවහොත් පුදුම නොවන්න.

ඔබට BIOS එක තුළම setting එකක් වෙනස් කිරීමට අවශ්‍ය විට, පද්ධති මෙනුවේ (`Super + Escape`) `Alt` අල්ලාගෙන සිටින්න, එවිට _නැවත ආරම්භ කරන්න_ යන්න _BIOS වෙත නැවත ආරම්භ කරන්න_ බවට පත් වේ, එය boot වන විට නිවැරදි key එක අල්ලා ගැනීමට සිදු නොවී firmware setup එකට සෘජුවම restart කරයි. Terminal එකෙන්, එය `omarchy system firmware` වේ.

### pacman/yay සෘජු යාවත්කාලීන පිළිබඳ අනතුරු ඇඟවීම

ඔබ දැනටමත් Arch පිළිබඳව හුරුපුරුදු නම්, ඔබම `pacman -Syu` හෝ `yay -Syu` ධාවනය කිරීමට ඔබ පෙළඹිය හැක, නමුත් ඔබ එසේ කළහොත්, Omarchy නව පැකේජ සමඟ එක්ව ක්‍රියාත්මක කරන snapshot එක, සංක්‍රමණ, සහ වින්‍යාස යාවත්කාලීන කිරීම් ඔබට මඟ හැරෙනු ඇත. එබැවින් Omarchy ඇත්ත වශයෙන්ම සෘජු පද්ධති උත්ශ්‍රේණි කිරීමක් නවතා, ඒ වෙනුවට `omarchy update` වෙත ඔබව යොමු කරනු ඇත. යාවත්කාලීනයක් කිරීමෙන් පසුව ඔබට කවදා හෝ ගැටලුවක් ඇති වුවහොත්, යාවත්කාලීනයට පෙර ගත් snapshot එකට ඔබේ පද්ධතිය ආපසු හරවා ගත හැක. සරලවම restart කර, ඔබ යාවත්කාලීනය ආරම්භ කිරීමට පෙර තිබූ boot loading මෙනුවේ snapshot එක තෝරන්න.

![bootloader](images/bootloader.webp)

කෙසේ හෝ ඔබේ වින්‍යාස ගොනු දූෂිත වී ඇත්නම්, terminal එකේ `omarchy reinstall` භාවිතයෙන් ඔබට Omarchy නැවත ස්ථාපනයක්ද සිදු කළ හැක. මෙය සියලුම පෙරනිමි Omarchy පැකේජ නැවත ස්ථාපනය කරයි, ඔබව stable මත තබන අතර ඉතා අලුත් ඕනෑම පැකේජයක් පහත දමයි, සහ සියලුම වින්‍යාස ගොනු යළි සකසයි. මෙය කිරීමෙන් Omarchy පෙරනිමිවලට ඔබ කළ සියලුම භාවිතා කරන්නා config වෙනස්කම් උඩින් ලියැවෙන බව සලකන්න!
