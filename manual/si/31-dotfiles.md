# ඩොට්ගොනු

Omarchy ප්‍රධාන වශයෙන් වින්‍යාස කර ඇත්තේ `~/.config` තුළ ජීවත් වන ඩොට්ගොනු ලෙස හඳුන්වන ඒවා හරහාය. ඒවා ඔබේ වෙනස්කම් සඳහා ඔබේ ගොනු ලෙස සලකනු ලැබේ. `/usr/share/omarchy` තුළ ජීවත් වන ගොනු Omarchy එකටම අයත් වන අතර, ඔබ එවා සමඟ අපහසුතාවයට පත් නොවිය යුතුය. ඔබට `/usr/share/omarchy` තුළ යමක් වෙනස් කිරීමට අවශ්‍ය නම්, ඒ වෙනුවට ඔබ `~/.config` තුළ අගය අතිමට්ටු කළ යුතුය.

ප්‍රධාන වින්‍යාස කෙලින්ම Omarchy මෙනුවෙන් (`Super + Space`) සංස්කරණය කළ හැක, _සැකසුම > මොනිටර්_, _සැකසුම > යතුරු බන්ධන_, _සැකසුම > ඇතුලත් කිරීම_, සහ _සැකසුම > වින්‍යාසය > [ගොනුව]_ වැනි. ඔබ මෙය මේ ආකාරයෙන් කරන විට, වින්‍යාස සංස්කරණයෙන් පසු නැවත ආරම්භ කිරීමට අවශ්‍ය වන ඕනෑම ක්‍රියාවලියක් ඔබ සංස්කාරකයෙන් අත්හැරීමෙන් පසු ස්වයංක්‍රීයව සිදුවනු ඇත (පෙරනිමියෙන් Neovim — මතක තබාගන්න `:wq`! — නමුත් ඔබට එය _සැකසුම > පෙරනිමි > සංස්කාරකය_ හරහා වෙනස් කළ හැක).

`~/.config` තුළ ප්‍රධාන ගොනු සහ ඒවා පාලනය කරන දේ ලැයිස්තුවක් මෙන්න:

ඔබ ඔබේම සැකසුම සුසර කිරීමට වෙනස්කම් රාශියක් අවසානයේ සිදු කරන්නේ නම්, මෙම ඩොට්ගොනු සියල්ල උපස්ථ කිරීම හොඳ අදහසකි. [එය කිරීමට Stow විශිෂ්ට ක්‍රමයකි](https://www.youtube.com/watch?v=NoFiYOqnC4o).

### සැසිය සමඟ ඔබේම යෙදුම් ආරම්භ කිරීම

ඔබ ඇතුළු වන සෑම වරම යමක් ක්‍රියාත්මක වීමට ඔබට අවශ්‍ය නම් — සමමුහුර්ත ඩීමනයක්, කතාබස් යෙදුමක්, ඔබේම ස්ක්‍රිප්ට් එකක් — එය `~/.config/hypr/autostart.lua` තුළ දාන්න:

```lua
o.launch_on_start("my-service")
```

එය සැසියේ කොටසක් ලෙස විධානය ආරම්භ කරන අතර, ඔබ නැවත පිටත් වන විට එය හරිහැටි පිරිසිදු කරනු ලැබේ.

### පද්ධති සිදුවීම් මත ස්ක්‍රිප්ට් ක්‍රියාත්මක කිරීම

Omarchy අවස්ථා අතලොස්සකදී කොකු ක්‍රියාත්මක කරන අතර, ඔබට ඔබේම ස්ක්‍රිප්ට් ඒවාට සම්බන්ධ කළ හැක. ඒවා `~/.config/omarchy/hooks/<event>.d/` තුළ ජීවත් වේ, එක් එක් සිදුවීම සඳහා එක් නාමාවලියක්, සහ එහි ඇති සෑම ක්‍රියාත්මක කළ හැකි ගොනුවක්ම එම සිදුවීම සිදුවන විට ක්‍රියාත්මක වේ:

| Event | When it runs |
| ----- | ------------ |
| `post-boot` | ඩෙස්ක්ටොප් එක ආරම්භ වූ වහාම |
| `post-update` | `omarchy update` හි අවසානය කරා, පැකේජයන්, සංක්‍රමණයන්, සහ සේවා නැවත ආරම්භ කිරීමෙන් පසු, mise මෙවලම් යාවත්කාලීන කිරීමට පෙර |
| `pre-refresh-pacman` | `omarchy refresh pacman` පැකේජ වින්‍යාසය නැවත සමමුහුර්ත කිරීමෙන් පසු, එය පැකේජයන් යාවත්කාලීන කිරීමට පෙර; නාලිකා මාරුවක් එම නැවුම් පියවරම අතරතුර එය ක්‍රියාත්මක කරයි |
| `theme-set` | තේමාව වෙනස් වීමකින් පසු (තේමාවේ නම `$1` හි) |
| `font-set` | අකුරු වෙනස් වීමකින් පසු (අකුරේ නම `$1` හි) |
| `battery-low` | බැටරිය අඩු වන විට (ප්‍රතිශතය `$1` හි) |

`pre-refresh-pacman` කොකා යනු අභිරුචි ගබඩාවන් හෝ `IgnorePkg` රේඛා අයත් වන ස්ථානයයි, මන්ද එය පැකේජ ගනුදෙනුවට පෙර ක්‍රියාත්මක වන බැවිනි. යාවත්කාලීන කිරීමට අදාළ කොකු දෙකාම Omarchy එහි හැෂ් කළ sudo අවසරය ඉවත් කිරීමෙන් පසු ඔබේ පරිශීලකයා ලෙස ක්‍රියාත්මක වන බැවින්, `sudo` භාවිතා කරන කොකාවකට තමන්ගේම අවසරය අවශ්‍ය වන අතර එය ඔබේ මුරපදය අසනු ඇත.

එම නාමාවලිවලින් සෑම එකකම දැනටමත් කොකුවක හැඩය පෙන්වන `.sample` ගොනුවක් ඇති — එය වැඩ කිරීමට යෙදීමට නමින් `.sample` ඉවත් කරන්න. ඔබ වෙනත් තැනක ලියූ ස්ක්‍රිප්ට් එකක් ස්ථාපනය කිරීමට, `omarchy hook install post-boot ~/my-hook` භාවිතා කරන්න, එය එය පිටපත් කර ක්‍රියාත්මක කළ හැකි එකක් බවට පත් කරනු ඇත.

### ඔබේම මෙනු ඇතුළත් කිරීම් එකතු කිරීම

Omarchy මෙනුව (`Super + Space`) `~/.config/omarchy/extensions/omarchy-menu.jsonc` සංස්කරණය කිරීමෙන් ඔබේම පේළි සමඟ නැවෙනු කළ හැක. ඇතුළත් කිරීම් තිත් ඉදින්කෙයකින් යතුරු කරනු ලැබෙන අතර, id එක ඒවා ගස තුළ තබන දේ වන බැවින්, `personal` මූල මෙනුවේ දිස්වන අතර `personal.notes` එහි ඇතුළත දිස්වේ:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

පවතින id එකක් නැවත භාවිතා කළ විට ඔබ නව එකක් එක් කිරීම වෙනුවට එම පේළිය අතිමට්ටු කරනු ඇත. ගොනුව ලබාගත හැකි සියලු ක්ෂේත්‍ර අදහස් දක්වීම් ලෙස ලේඛනගත කරමින් පැමිණේ.

### ඔබේම ෂෙල් අපනයනයන්, ශ්‍රිතයන්, සහ අනුනාමය එකතු කිරීම

Omarchy සෞම්‍ය අනුනාම සහ උදව්කාරී ශ්‍රිත රැසක් සමඟ පැමිණේ, නමුත් ඔබටම එකතු කිරීමට අවශ්‍ය වීම ඉතා පොදුය. ඔබ `~/.bashrc` තුළ අනුනාම, ශ්‍රිතයන්, සහ අපනයනයන් යන දෙකම එක් කළ යුතුය. මෙම ගොනුව යාවත්කාලීන කිරීම් වලදී අවලංගු නොවනු ඇත. ඔබට Omarchy පෙරනිමිවලින් ඕනෑම එකක් වෙනස් කිරීමට අවශ්‍ය නම්, ඔබට ඒවා මෙහි ආරක්ෂිතව එක් කළ හැක.

### අභ්‍යන්තර Omarchy ගොනු වෙනස් කිරීම

බලන්න, මෙය ඔබේ පරිගණකයයි. ඔබට එය සමඟ ඔබට අවශ්‍ය ඕනෑම දෙයක් කළ හැකි නමුත්, `/usr/share/omarchy` තුළ ඇති ගොනු සෘජුවම වෙනස් කිරීමට එරෙහිව මම උපදෙස් දෙමි. ඒවා Omarchy pacman පැකේජයට අයත් වන අතර, ඔබේ වෙනස්කම් ඊළඟ යාවත්කාලීනයේදී සරලව අවලංගු වනු ඇත. ඒ වෙනුවට ඔබට අකමැති ඕනෑම පෙරනිමි අගයක් `~/.config/*` අනුබෙත්ත තුළ අවලංගු කිරීම ඔබට වඩා හොඳය.

පෙරනිමි යතුරු බන්ධන වැනි, ඔබට එ ආකාරයෙන් සියල්ල පාහේ වෙනස් කළ හැක. [Obsidian](https://obsidian.md/) එක [Joplin](https://joplinapp.org/) සමඟ ආදේශ කිරීමට `~/.config/hypr/bindings.lua` සංස්කරණය කරන්න (`omarchy-pkg-add joplin-bin` සමඟ ස්ථාපනය කරන්න):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` එහි ආදේශය එක් කිරීමට පෙර පවතින බන්ධනය ඉවත් කරයි. එය දියත් කිරීමේ උපකාරකයෝ සහ බන්ධන විකල්ප ඇතුළුව `o.bind` එකේම තර්ක ගනී. බන්ධනයක් එක් කිරීමට `o.bind` භාවිතා කරන්න, නැතහොත් එය ආදේශ නොකර ඉවත් කිරීමට `hl.unbind` භාවිතා කරන්න.

ඔබ අභ්‍යන්තර Omarchy ගොනු මත අනවසර වශයෙන් විහිලුකම් කිරීමට දිගින් දිගට අදහස් කරන්නේ නම්, _යාවත්කාලීන > නාලිකාව > Dev_ හරහා dev නාලිකාවට මාරු වන්න. එය `~/omarchy` හි මූලාශ්‍ර කේතයේ git පිටපතකට Omarchy සම්බන්ධ කරන අතර, එය ඔබේ සිතට නිදහසේ වෙනස් කිරීමට ඔබට නිදහස ඇත. ඔබට කළ යුත්තේ කුමක්දැයි පැවසීමට මෙහි කිසිවෙකු නැත!

### ඕනෑම වෙනස්කම් නැවත සැකසීම

ඔබ වින්‍යාසයන් අවුල් කර අවසන් වන්නේ නම්, ඔබට සෑම විටම Omarchy මෙනුවේ _යාවත්කාලීන > වින්‍යාසය_ හරහා ඒවා පෙරනිමියන්ට ආපසු හැරවිය හැක. නැතහොත් සියල්ල යළි සැකසීමට `omarchy reinstall configs` ක්‍රියාත්මක කිරීමෙනි.
