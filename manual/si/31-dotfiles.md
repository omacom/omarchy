# ඩොට්ෆයිල්ස්

Omarchy ප්‍රධාන වශයෙන් වින්‍යාස කරනු ලබන්නේ `~/.config` තුළ පවතින ඩොට්ෆයිල්ස් ලෙස හඳුන්වන ඒවා හරහාය. ඒවා ඔබේ වෙනස්කම් සඳහා වන ඔබේම ගොනු ලෙස සැලකේ. `/usr/share/omarchy` තුළ පවතින ගොනු Omarchy එකටම අයත් වන අතර, ඔබ ඒවාට අත තැබිය යුතු නැත. `/usr/share/omarchy` තුළ යමක් වෙනස් කිරීමට ඔබට අවශ්‍ය නම්, ඒ වෙනුවට ඔබ කළ යුත්තේ `~/.config` තුළ එහි අගය උඩින් ලිවීමයි.

ප්‍රධාන වින්‍යාස Omarchy මෙනුවෙන් (`Super + Space`) කෙලින්ම සංස්කරණය කළ හැකිය, උදාහරණයක් ලෙස _Setup > Keyboard > Keybindings_, _Setup > Input_, සහ _Setup > Config > [file]_. ඔබ මෙය මේ ආකාරයෙන් කරන විට, වින්‍යාස සංස්කරණයෙන් පසු නැවත ආරම්භ කිරීමට අවශ්‍ය ඕනෑම ක්‍රියාවලියක්, ඔබ සංස්කාරකයෙන් ඉවත් වූ පසු ස්වයංක්‍රීයව නැවත ආරම්භ වනු ඇත (පෙරනිමියෙන් Neovim — `:wq`, මතකද! — නමුත් ඔබට එය _Setup > Defaults > Editor_ හරහා වෙනස් කළ හැකිය).

මෙන්න `~/.config` තුළ ඇති ප්‍රධාන ගොනු සහ ඒවා පාලනය කරන දේ පිළිබඳ ලැයිස්තුවක්:

| ගොනුව | අරමුණ |
| ----------------------- | --------------------- |

ඔබේම සැකසුම සියුම්ව සකස් කිරීම සඳහා ඔබ බොහෝ වෙනස්කම් කිරීමට සිදු වුවහොත්, මෙම සියලු ඩොට්ෆයිල්ස් උපස්ථ කිරීම හොඳ අදහසකි. [Stow ඒ සඳහා කදිම ක්‍රමයකි](https://www.youtube.com/watch?v=NoFiYOqnC4o).

### සැසිය සමඟ ඔබේම යෙදුම් ආරම්භ කිරීම

ඔබ ලොග් වන සෑම අවස්ථාවකම යමක් ධාවනය වීමට ඔබට අවශ්‍ය නම් — සමමුහුර්ත daemon එකක්, chat යෙදුමක්, ඔබේම script එකක් — එය `~/.config/hypr/autostart.lua` තුළ තබන්න:

```lua
o.launch_on_start("my-service")
```

එමගින් විධානය සැසියේ කොටසක් ලෙස ආරම්භ කරන අතර, ඔබ නැවත ඉවත් වන විට එය නිසි ලෙස පිරිසිදු කෙරේ.

### පද්ධති සිදුවීම්වලදී scripts ධාවනය කිරීම

Omarchy අවස්ථා ස්වල්පයකදී hooks ක්‍රියාත්මක කරන අතර, ඔබට ඔබේම scripts ඒවාට සම්බන්ධ කළ හැකිය. ඒවා `~/.config/omarchy/hooks/<event>.d/` තුළ පවතී, එක් සිදුවීමකට එක් නාමාවලියක් බැගින්, සහ සිදුවීම සිදු වන විට එහි ඇති සෑම ක්‍රියාත්මක කළ හැකි ගොනුවක්ම ධාවනය වේ:

| සිදුවීම | එය ධාවනය වන අවස්ථාව |
| ----- | ------------ |
| `post-boot` | ඩෙස්ක්ටොප් එක ආරම්භ වූ වහාම පසුව |
| `post-update` | පැකේජ, සංක්‍රමණ, සහ සේවා නැවත ආරම්භ කිරීමෙන් පසුව, mise මෙවලම් යාවත්කාලීන කිරීමට පෙර, `omarchy update` හි අවසානයට ආසන්නයේදී |
| `pre-refresh-pacman` | `omarchy refresh pacman` පැකේජ වින්‍යාසය නැවත සමමුහුර්ත කිරීමෙන් පසුව, එය පැකේජ යාවත්කාලීන කිරීමට පෙර; channel මාරුවක් එම refresh පියවරේදීම එය ධාවනය කරයි |
| `theme-set` | තේමා වෙනස්කමකින් පසුව (තේමා නම `$1` තුළ) |
| `font-set` | අකුරු වෙනස්කමකින් පසුව (අකුරු නම `$1` තුළ) |
| `battery-low` | බැටරිය අඩු වන විට (ප්‍රතිශතය `$1` තුළ) |

`pre-refresh-pacman` hook එක යනු අභිරුචි repositories හෝ `IgnorePkg` පේළි අයත් විය යුතු තැන වන අතර, එය පැකේජ ගනුදෙනුවට පෙර ධාවනය වේ. යාවත්කාලීන කිරීම සම්බන්ධ hooks දෙකම, Omarchy එහි හැඹිලිගත කළ sudo අවසරය ඉවත් කිරීමෙන් පසුව ඔබේ පරිශීලකයා ලෙස ධාවනය වන අතර, එබැවින් `sudo` භාවිතා කරන hook එකකට තමන්ගේම අවසරයක් අවශ්‍ය වන අතර ඔබේ මුරපදය ඉල්ලා සිටිය හැකිය.

එම නාමාවලිවලින් එකක් තුළ දැනටමත් hook එකක ආකාරය පෙන්වන `.sample` ගොනුවක් ඇති අතර — එය ක්‍රියාත්මක කිරීමට නමෙන් `.sample` ඉවත් කරන්න. ඔබ වෙනත් තැනක ලියූ script එකක් ස්ථාපනය කිරීමට, `omarchy hook install post-boot ~/my-hook` භාවිතා කරන්න, එය එය පිටපත් කර ක්‍රියාත්මක කළ හැකි බවට පත් කරයි.

### ඔබේම මෙනු ප්‍රවේශ එකතු කිරීම

Omarchy මෙනුව (`Super + Space`) `~/.config/omarchy/extensions/omarchy-menu.jsonc` සංස්කරණය කිරීමෙන් ඔබේම පේළිවලින් දිගු කළ හැකිය. ප්‍රවේශ තිත් සහිත id එකකින් යතුරුගත කර ඇති අතර, ඒවා ගස තුළ තබන්නේ එම id එක වන අතර, එබැවින් `personal` මූල මෙනුවේ දිස්වන අතර, `personal.notes` එය තුළ දිස්වේ:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

දැනට පවතින id එකක් නැවත භාවිතා කරන්න, එවිට ඔබ නව එකක් එකතු කිරීම වෙනුවට එම පේළිය උඩින් ලියනු ඇත. ගොනුව, ලබා ගත හැකි සියලුම ක්ෂේත්‍ර අදහස් ලෙස ලේඛනගත කරමින් ලබා දේ.

### ඔබේම shell exports, functions, සහ aliases එකතු කිරීම

Omarchy ergonomics අතින් පහසු aliases සහ ප්‍රයෝජනවත් functions රාශියක් සමඟ එනු ලැබේ, නමුත් ඔබට ඔබේම ඒවා එකතු කිරීමට අවශ්‍ය වීම ඉතා සුලභය. ඔබ aliases, functions, සහ exports යන දෙකම `~/.bashrc` තුළට එකතු කළ යුතුය. මෙම ගොනුව යාවත්කාලීන කිරීම්වලදී උඩින් ලියනු නොලැබේ. ඔබට Omarchy පෙරනිමිවලින් කිසිවක් වෙනස් කිරීමට අවශ්‍ය නම්, ඔබට ඒවා ද ආරක්ෂිතව මෙහි එකතු කළ හැකිය.

### ඩෙස්ක්ටොප් එක සඳහා පරිසර විචල්‍ය සැකසීම

ඩෙස්ක්ටොප් සැසි exports අයත් වන්නේ `~/.config/uwsm/env.d/` තුළටය. මෙම ගොනු ඔබේ ඩෙස්ක්ටොප් එක ආරම්භ වීමට පෙර ධාවනය වන අතර, එබැවින් shell දෝෂයක් ඔබව නැවත පිවිසුම් තිරයට යැවිය හැකිය. ඒවා සංස්කරණය කරන අතරතුර ක්‍රියා කරන terminal එකක් විවෘතව තබා ගන්න. උඩින් ලියූ දෙයක් අබල කිරීමට, එය `env.d` වෙතින් පිටතට ගෙන යන්න. වෙනස්කමක් පිවිසීම වළක්වන්නේ නම් [login recovery](45-troubleshooting.md#my-password-is-accepted-but-i-return-to-the-login-screen) බලන්න.

### අභ්‍යන්තර Omarchy ගොනු වෙනස් කිරීම

බලන්න, මේක ඔබේ පරිගණකයයි. ඔබට ඕනෑම දෙයක් ඒ සමඟ කළ හැකිය, නමුත් `/usr/share/omarchy` තුළ ඇති ගොනු සෘජුවම වෙනස් කිරීමෙන් වළකින ලෙස මම උපදෙස් දෙමි. ඒවා Omarchy pacman පැකේජයට අයත් වන අතර, එබැවින් ඔබේ වෙනස්කම් ඊළඟ යාවත්කාලීනයේදී සරලවම උඩින් ලියනු ලැබේ. ඒ වෙනුවට, ඔබ කැමති නැති ඕනෑම පෙරනිමි අගයක් `~/.config/*` ෆෝල්ඩරය තුළ උඩින් ලිවීම ඔබට වඩා හොඳය.

ඔබට පෙරනිමි යතුරු බැඳීම් වැනි, එම ආකාරයෙන් සෑම දෙයක්ම පාහේ වෙනස් කළ හැකිය. සරලවම, උදාහරණයක් ලෙස [Obsidian](https://obsidian.md/) වෙනුවට [Joplin](https://joplinapp.org/) තැබීමට `~/.config/hypr/bindings.lua` සංස්කරණය කරන්න (`omarchy-pkg-add joplin-bin` සමඟ ස්ථාපනය කරන්න):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` එහි ආදේශකය එකතු කිරීමට පෙර පවතින බැඳීම ඉවත් කරයි. එය දියත් කිරීමේ උපකාරක සහ බැඳීමේ විකල්ප ඇතුළුව `o.bind` ගන්නා එකම තර්ක ගනී. බැඳීමක් එකතු කිරීමට `o.bind` භාවිතා කරන්න, නැතහොත් එය ආදේශ කිරීමකින් තොරව ඉවත් කිරීමට `hl.unbind` භාවිතා කරන්න.

ඔබ අභ්‍යන්තර Omarchy ගොනු හැක් කිරීමට තරයේම කැමති නම්, _Update > Channel > Dev_ හරහා dev channel එකට මාරු වන්න. එමගින් Omarchy `~/omarchy` තුළ ඇති මූලාශ්‍ර කේතයේ git checkout එකකට සම්බන්ධ කරන අතර, එය ඔබේ සිතේ හැටියට වෙනස් කිරීමට ඔබට නිදහස තිබේ. ඔබට මෙහෙම කරන්න කියන්න මෙතැන කවුරුවත් නැහැ!

### ඔබ කළ වෙනස්කම් යළි පිහිටුවීම

ඔබ වින්‍යාසයන් අවුල් කර ගැනීමට සිදු වුවහොත්, ඔබට සෑම විටම Omarchy මෙනුවේ _Update > Config_ හරහා ඒවා පෙරනිමි වෙත යළි හැරවිය හැකිය. නැතහොත් සියල්ල යළි සැකසීමට `omarchy reinstall configs` ධාවනය කිරීමෙන්ද හැකිය.
