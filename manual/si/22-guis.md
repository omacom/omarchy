# GUI යෙදුම්

## Files

Files (Nautilus) යනු චිත්‍රක ගොනු කළමනාකරුයි. `Super + Shift + F` මඟින් එය විවෘත වන අතර, `Super + Shift + Alt + F` මඟින් එය ඔබේ terminal එක දැනට ඇති directory එක තුළම විවෘත වේ, එමඟින් බොහෝ ක්ලික් කිරීම් ඉතිරි වේ. `Ctrl + L` මඟින් ඔබට path එකක් type කිරීමට හැකි වන අතර, ඕනෑම ගොනුවක් මත `Space` එබීමෙන් කිසිවක් විවෘත නොකරම ඉක්මන් පෙරදසුනක් ලැබේ.

USB stick එකක් හෝ SD card එකක් සම්බන්ධ කළ විට එය ස්වයංක්‍රීයව mount වන බැවින්, එය sidebar එකේ සරලව දිස් වේ. ධාවකයක් format කිරීම, SMART health එක පරීක්ෂා කිරීම, partitions සෑදීම වැනි වඩාත් සංකීර්ණ දේවල් සඳහා, app launcher එකෙන් (`Super + Space`) _Disks_ ධාවනය කරන්න.

දෙවරක් ක්ලික් කිරීම සංවේදී පෙරනිමි අනුගමනය කරයි: පින්තූර, වීඩියෝ සහ සංගීතය Omaview තුළ, PDF Document Viewer තුළ, Markdown Omawrite තුළ, සහ සරල පෙළ _Setup > Default > Editor_ යටතේ තෝරාගත් editor එක තුළ විවෘත වේ.

## Disktree

ධාවකය පිරී ගොස්, ඉඩ කා දමන්නේ කුමක්දැයි ඔබට අදහසක් නැති විට, app launcher එකෙන් (`Super + Space`) [Disktree](https://github.com/tobi/disktree) ධාවනය කරන්න. එය ඔබේ home directory එකේ චිත්‍රක treemap එකක් පෙන්වයි. විශාල blocks වැඩි ඉඩක් ගනී; keyboard එකෙන් හෝ mouse එකෙන් directories තුළට යන්න, ඉවත් කළ යුතු දේ mark කරන්න, සහ කිසිවක් ඉවත් කිරීමට පෙර ඔබේ තේරීම් සමාලෝචනය කරන්න. සම්පූර්ණ disk එකම scan කිරීමට `disktree --disk` ධාවනය කරන්න.

## Obsidian

[Obsidian](https://obsidian.md/) යනු ගබඩා කිරීම සඳහා සරල Markdown ගොනු භාවිතා කරන, නොමිලේ ලැබෙන සහ ඉතා පුළුල් කළ හැකි සටහන් ගැනීමේ යෙදුමකි.

Obsidian පුද්ගලික, වාණිජ සහ ලාභ නොලබන භාවිතය ඇතුළුව සියලු අරමුණු සඳහා නොමිලේ ලැබේ.

Obsidian iOS සහ Android මත mobile apps සමඟ [sync කිරීම සඳහා වාණිජ add-on එකක්ද](https://obsidian.md/sync) ලබා දෙයි. (https://obsidian.md/pricing).

ඔබ `Super + Shift + O` මඟින් Obsidian ආරම්භ කරයි. theme syncing භාවිතා කිරීමට, ඔබ settings යටතේ `Omarchy` theme එක තෝරාගත යුතුය.

ඔබ `Super + Shift + W` මඟින් Omawrite ආරම්භ කරයි.

ඔබ application launcher එක (`Super + Space`) හරහා Pinta ආරම්භ කරයි.

## Aether

## LocalSend

[LocalSend](https://localsend.org/) මඟින් Apple හි AirDrop මෙන්, එම app එකම ධාවනය වන එකම network එකේ ඇති වෙනත් devices වෙත ගොනු යැවීමට ඔබට ඉඩ දෙයි. කෙසේ වෙතත්, එය cross-platform බැවින්, ඔබට Windows, macOS, Android, iOS සහ ඇත්තෙන්ම Linux වෙත සහ ඒවායින් ගොනු යෑවීමට සහ ලබාගැනීමට හැකිය.

ඔබට Share menu එක `Super + Ctrl + S` මත හෝ Omarchy menu එකේ _Trigger > Share_ යටතේ විවෘත කළ හැකිය. එය ඔබට විකල්ප හතරක් ලබා දෙයි:

- **Clipboard** ඔබ පිටපත් කළ ඕනෑම දෙයක් text file එකක් ලෙස යවයි. ඔබටම email නොකර link එකක් හෝ snippet එකක් ඔබේ phone එකට ලබාගැනීමට විශිෂ්ටයි.
- **File** ඔබට එකවර කිහිපයක් තෝරාගත හැකි file picker එකක් විවෘත කරයි.
- **Folder** සම්පූර්ණ directory එකක්ම යවයි.
- **Receive** වෙනත් device එකකට ඔබට යමක් යැවිය හැකි වන පරිදි LocalSend නිසි ලෙසම විවෘත කරයි.

එම දෙයම terminal එකෙන් `omarchy share clipboard`, `omarchy share file [path]`, සහ `omarchy share folder [path]` සමඟ ක්‍රියා කරයි. path එක ඉවත් කළ විට ඔබට picker එක ලැබේ.

ඔබට file manager එකෙන් කෙළින්ම යැවීමටද හැකිය: Nautilus තුළ ඕනෑම තේරීමක් මත right-click කර _Send via LocalSend_ තෝරන්න.

Omarchy හි firewall එක LocalSend හි port එක හැර පෙරනිමියෙන් වසා ඇති බැවින්, මෙය අලුත් install එකක කිසිදු සැකසුමකින් තොරව ක්‍රියා කරයි. [ආරක්ෂාව](48-security.md) බලන්න.

## LibreOffice

[LibreOffice](https://www.libreoffice.org/) යනු word processor, spreadsheet, presentations, drawing application සහ තවත් බොහෝ දේ සහිත සම්පූර්ණ office package එකකි. එය Microsoft Office ගොනු සමඟ අනුකූල බැවින්, එම Word documents විවෘත කිරීමට හැකි වීමට මෙය විශිෂ්ට ක්‍රමයකි.

ඔබ application launcher එක (`Super + Space`) හරහා LibreOffice ආරම්භ කරයි.

## Hype

[Hype](https://github.com/omacom/hype) යනු Omarchy හිම අතිශය සරල presentation app එකයි. ඔබේ deck එක එහි පින්තූර සහ වීඩියෝ ඒ අසලම ඇති තනි Markdown file එකකි: live preview එකක් යට එක් එක් slide එක ලියන්න, slides පිළිවෙළට drag කරන්න, ඉන්පසු fullscreen ඉදිරිපත් කරන්න හෝ PDF සහ PowerPoint වෙත export කරන්න. එය ඔබේ Omarchy theme එක පවා ලබාගනී.

ඔබ application launcher එක (`Super + Space`) හරහා Hype ආරම්භ කරයි. සෑම shortcut එකක්ම බැලීමට එහි ඇතුළත `?` ඔබන්න.

## Signed

[Signed](https://github.com/omacom/signed) යනු PDF අත්සන් කිරීමට සහ ඒවා පිරවීමට Omarchy හිම අතිශය සරල ක්‍රමයයි. ඔබ සුරකින ලද signature එක, text එක සහ අද දිනය පිටුවක ඕනෑම තැනක තබන්න, ඉන්පසු මුල් පිටපත අසල අත්සන් කළ පිටපතක් save කරන්න. කෙසේද යන්න සඳහා [PDF පුරවීම](27-filling-out-pdfs.md) බලන්න.

application launcher එකේ (`Super + Space`) ඇති Game Vibes යනු Omarchy හි කුඩා games ඇති ස්ථානයයි: Checkmate, මිතුරෙකුට එරෙහිව හෝ built-in opponent ට එරෙහිව 3D chess game එකක්; Cards, Klondike solitaire; සහ Neon Swarm, arcade shooter එකක්. සෑම එකක්ම ඔබේ theme එක අනුගමනය කරන තනි web page එකකි. arrows සහ `Enter` සමඟ එකක් තෝරන්න, සහ game එකක title screen එකෙන් `Esc` සමඟ හෝ එය paused වී ඇති විට `Q` සමඟ ලැයිස්තුවට ආපසු එන්න. එය full screen විවෘත වේ: `Super + F` එය window එකක් බවට පත් කරයි, සහ `Super + W` එය වසයි.

ඔබ agent කෙනෙකු සමඟ සාදන games ද මෙහි දිස් වේ: agents panel එකේ _Make something cool → Game_ තෝරා එකක් විස්තර කරන්න, නැතහොත් දිගටම වැඩ කිරීමට Game Vibes හි දැනටමත් ඇති game එකක් නම් කරන්න. agent එය `~/Games/vibes` වෙත copy කරයි, එහිදී එය වෙනස් කිරීම ඔබට අයිති වන අතර, එය අවසන් වූ විට එය විවෘත කරයි. ඔබට `omarchy games vibes copy <game>` සමඟ එම පිටපත ඔබම සාදාගත හැකිය. වෙනත් අයෙකු share කරන game එකක් theme එකක් මෙන් install වේ: _Install > Gaming > Game Vibes_ තෝරා එහි git address එක paste කරන්න, නැතහොත් `omarchy games vibes install <git-repo-url>` ධාවනය කරන්න. _Remove > Gaming_ එකක් නැවත ඉවත් කරයි, සහ _Update > Game Vibes Games_ නව versions ලබාගනී. Games web එකෙන් three.js load කරන බැවින්, ඒවා ආරම්භ වීමට connection එකක් අවශ්‍ය වේ.

## Omaview

[Omaview](https://github.com/omacom/omaview) යනු Omarchy හිම අතිශය සරල picture viewer එක සහ media player එකයි: ඔබේ photos, videos සහ music සඳහා එක් window එකකි. photo එකක් විවෘත කරන්න, arrow keys එහි folder එකේ ඉතිරිය හරහා යයි, `N` සහ `P` ඕනෑම දෙයක් සඳහා එය කරයි, සහ `Ctrl + M` සම්පූර්ණ folder එකම grid එකක් ලෙස පෙන්වයි. එය HEIC, AVIF සහ JPEG XL photos ද පෙන්වන අතර, දිගු ඕනෑම දෙයක ඔබ නැවැත්වූ තැනින් නැවත ලබාගනී.

fullscreen සඳහා `F`, Omasnap තුළ picture එකක් edit කිරීමට හෝ Omacut තුළ video එකක් trim කිරීමට `E`, picture එකක් print කිරීමට `Ctrl + P`, සහ ගොනුවක් Trash වෙත යැවීමට `Delete` ඔබන්න (`Ctrl + Z` එය ආපසු ගෙන එයි). සෑම shortcut එකක්ම බැලීමට එහි ඇතුළත `?` ඔබන්න.

ඔබ application launcher එක (`Super + Space`) හරහා _Media Viewer_ ලෙස Omaview ආරම්භ කරයි, නැතහොත් file manager එකේ picture එකක්, video එකක් හෝ song එකක් double-click කරයි.

## Monologue

[Monologue](https://github.com/omacom/monologue) යනු Omarchy හිම අතිශය සරල webcam recorder එකයි. ඔබේ camera එක සහ microphone එක එක් වරක් තෝරන්න, ඉන්පසු record කිරීමට `Space` ඔබන්න, සහ එම take එකම pause කිරීමට සහ resume කිරීමට නැවත ඔබන්න. එය සැමවිටම ඔබේ camera එකේ ඉහළම resolution එකෙන් record කරන අතර, ඔබ ආරම්භ කිරීමට පෙර ඔබේ levels පරීක්ෂා කිරීමට හැකි වන live microphone meter එකක් සමඟින් සිදු කරයි.

take එක නවත්වන්න, එය built-in editor එකක වහාම විවෘත වේ. clip එකක් split කිරීමට එය double-click කරන්න, එක් එක් කොටස trim කිරීමට handles drag කරන්න, සහ ඔබට අනවශ්‍ය කොටස් ඉවත් කරන්න. ඉන්පසු එය MP4 එකක් ලෙස save කරන්න. ඔබ discard කරන තෙක් ඔබේ මුල් recording එක තබාගනු ලබන බැවින්, ඔබට සැමවිටම ආපසු පැමිණ එය වෙනස් ආකාරයකින් කපාගත හැකිය.
