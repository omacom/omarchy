# GUIs

## Files

Files (Nautilus) යනු චිත්‍රක ගොනු කළමනාකරුයි. `Super + Shift + F` මඟින් එය විවෘත වන අතර, `Super + Shift + Alt + F` මඟින් එය ඔබේ terminal එක දැනට ඇති directory එක තුළ විවෘත වේ, එමඟින් බොහෝ ක්ලික් කිරීම් ඉතිරි වේ. `Ctrl + L` මඟින් ඔබට path එකක් ටයිප් කළ හැකි අතර, ඕනෑම ගොනුවක් මත `Space` එබීමෙන් කිසිවක් විවෘත නොකරම එය ඉක්මනින් පෙරදැක්මක් ලෙස බැලිය හැකිය.

USB stick එකක් හෝ SD card එකක් සම්බන්ධ කළ විට එය ස්වයංක්‍රීයවම mount වන බැවින්, එය sidebar එකේ සරලවම දිස් වේ. ඊට වඩා සංකීර්ණ ඕනෑම දෙයක් සඳහා — drive එකක් format කිරීම, SMART සෞඛ්‍යය පරීක්ෂා කිරීම, partitions සෑදීම — app launcher එකෙන් (`Super + Space`) _Disks_ දියත් කරන්න.

Double-click කිරීම සාධාරණ පෙරනිමි අනුගමනය කරයි: පින්තූර, වීඩියෝ සහ සංගීතය Omaview හිද, PDFs Document Viewer හිද, Markdown Omawrite හිද, සරල පෙළ _Setup > Default > Editor_ යටතේ තෝරා ඇති editor එකෙහිද විවෘත වේ.

## Disktree

Drive එක පිරී ගොස්, කුමක්ද එය ගිල දමමින් සිටින්නේ කියා ඔබට කිසිම අදහසක් නැති විට, app launcher එකෙන් (`Super + Space`) [Disktree](https://github.com/tobi/disktree) දියත් කරන්න. එය ඔබේ home directory එකේ චිත්‍රක treemap එකක් පෙන්වයි. විශාල blocks වැඩි ඉඩක් ගනියි; keyboard එකෙන් හෝ mouse එකෙන් directories තුළට යන්න, ඉවත් කළ යුතු දේ සලකුණු කරන්න, කිසිවක් ඉවත් කිරීමට පෙර ඔබේ තේරීම් සමාලෝචනය කරන්න. මුළු disk එකම scan කිරීමට `disktree --disk` ධාවනය කරන්න.

## Obsidian

[Obsidian](https://obsidian.md/) යනු ගබඩා කිරීම සඳහා සරල Markdown ගොනු භාවිත කරන, නොමිලේ ලැබෙන සහ ඉතා විශාල ලෙස පුළුල් කළ හැකි සටහන් ගැනීමේ application එකකි.

Obsidian පුද්ගලික, වාණිජ සහ ලාභ නොලබන භාවිතය ඇතුළුව සියලු අරමුණු සඳහා නොමිලේ ලැබේ.

Obsidian, iOS සහ Android මත mobile apps සමඟ [sync කිරීම සඳහා වාණිජ add-on එකක්](https://obsidian.md/sync) ද ලබා දෙයි. (https://obsidian.md/pricing).

ඔබ Obsidian ආරම්භ කරන්නේ `Super + Shift + O` මඟිනි. Theme syncing භාවිත කිරීමට, ඔබ settings යටතේ `Omarchy` theme එක තෝරා ගත යුතුය.

## Omawrite

[Omawrite](https://github.com/omacom-io/omawrite) යනු Omarchy හිම අතිශය සරල Markdown ලිවීමේ app එකයි. Vaults නැත, plugins නැත, සිටින්නේ ඔබ සහ වචන පමණි.

ඔබ Omawrite ආරම්භ කරන්නේ `Super + Shift + W` මඟිනි.

## Pinta

[Pinta](https://www.pinta-project.com/) යනු cropping, resizing සහ වෙනත් මූලික හැසිරවීම් සඳහා ඉතා සුදුසු මූලික image editing tool එකකි. Photoshop විකල්පයක් බලාපොරොත්තු නොවන්න. එහෙත් එයට තවමත් Magic Wand එකක් සහ layers ඇත!

ඔබ Pinta ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`).

## Aether

ඔබ Aether ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`).

## LocalSend

[LocalSend](https://localsend.org/) මඟින් Apple's AirDrop මෙන්, app එක ධාවනය වන එකම network එකේ ඇති වෙනත් devices වෙත ගොනු යැවිය හැකිය. එහෙත් එය cross-platform බැවින්, ඔබට Windows, macOS, Android, iOS සහ ඇත්තෙන්ම Linux වෙත සහ ඉන් ගොනු යැවිය හැකිය.

ඔබට Share menu එක `Super + Ctrl + S` මත හෝ Omarchy menu එකේ _Trigger > Share_ යටතේ විවෘත කළ හැකිය. එය ඔබට විකල්ප හතරක් ලබා දෙයි:

- **Clipboard** ඔබ පිටපත් කර ඇති ඕනෑම දෙයක් text file එකක් ලෙස යවයි. ඔබටම email නොකර link එකක් හෝ snippet එකක් ඔබේ phone එකට ලබා ගැනීමට ඉතා සුදුසුය.
- **File** file picker එකක් විවෘත කරන අතර එහිදී ඔබට එකවර කිහිපයක් තෝරා ගත හැකිය.
- **Folder** සම්පූර්ණ directory එකක්ම යවයි.
- **Receive** LocalSend නිසි පරිදි විවෘත කරන බැවින් වෙනත් device එකකට ඔබට යමක් යැවිය හැකිය.

Terminal එකෙන්ද එම දෙයම `omarchy share clipboard`, `omarchy share file [path]`, සහ `omarchy share folder [path]` සමඟ ක්‍රියා කරයි. Path එක නොදැමුවහොත් ඔබට picker එක ලැබේ.

ඔබට file manager එකෙන් කෙලින්ම යැවිය ද හැකිය: Nautilus හි ඕනෑම තේරීමක් මත right-click කර _Send via LocalSend_ තෝරන්න.

LocalSend හි port එක හැර Omarchy හි firewall එක පෙරනිමියෙන් වසා ඇති බැවින්, මෙය අලුත් install එකක කිසිම සැකසුමකින් තොරව ක්‍රියා කරයි. [security](48-security.md) බලන්න.

## LibreOffice

[LibreOffice](https://www.libreoffice.org/) යනු word processor, spreadsheet, presentations, drawing application සහ තවත් බොහෝ දේ සහිත සම්පූර්ණ office package එකකි. එය Microsoft Office වෙතින් ලැබෙන ගොනු සමඟ අනුකූල බැවින්, එම Word documents විවෘත කිරීමට හැකි වීමට මෙය ඉතා සුදුසු ක්‍රමයකි.

ඔබ LibreOffice ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`).

## Hype

[Hype](https://github.com/omacom/hype) යනු Omarchy හිම අතිශය සරල presentation app එකයි. ඔබේ deck එක යනු එහි images සහ videos ඊට යාබදව ඇති තනි Markdown file එකකි: සජීවී පෙරදැක්මක් යට එක් එක් slide එක ලියන්න, slides පිළිවෙළට drag කරන්න, ඉන්පසු fullscreen ඉදිරිපත් කරන්න හෝ PDF සහ PowerPoint වෙත export කරන්න. එය ඔබේ Omarchy theme එක පවා ලබා ගනියි.

ඔබ Hype ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`). සෑම shortcut එකක්ම බැලීමට එය තුළ `?` ඔබන්න.

## Signed

[Signed](https://github.com/omacom/signed) යනු PDFs අත්සන් කිරීමට සහ ඒවා පිරවීමට Omarchy හිම අතිශය සරල ක්‍රමයයි. ඔබ සුරකින ලද අත්සන, පෙළ සහ අද දිනය පිටුවේ ඕනෑම තැනක තබන්න, ඉන්පසු මුල් පිටපත අසල අත්සන් කළ පිටපතක් සුරකින්න. ආකාරය සඳහා [PDFs පුරවීම](27-filling-out-pdfs.md) බලන්න.

ඔබ Signed ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`), නැතහොත් file manager එකෙන් PDF එකක් එය සමඟ විවෘත කරන්න.

## Checkmate

[Checkmate](https://github.com/omacom/checkmate) යනු Omarchy හිම 3D chess game එකයි. එකම computer එකේ මිතුරෙකු සමඟ හෝ මට්ටම් තුනකින් යුත් built-in opponent සමඟ ක්‍රීඩා කරන්න, ඒ ඒ ආකාරයට චලනය වන මූර්තිමත් කට්ටල හතරක් මත: orbital craft, කැටයම් කළ දැව සහ ivory, වනාන්තර ජීවීන් සහ candy. Games සඳහා clock එකක් නැති අතර සෑම චලනයකින්ම පසු save වේ.

ඔබ Checkmate ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`). සෑම shortcut එකක්ම බැලීමට එය තුළ `?` ඔබන්න.

## Omacalc

[Omacalc](https://github.com/omacom-io/omacalc) යනු පාවෙන window එකක විවෘත වන, Omarchy හිම අතිශය සරල calculator එකයි.

ඔබ Omacalc ආරම්භ කරන්නේ `Super + Shift + Q` මඟිනි (හෝ ඔබේ keyboard එකේ calculator key එකක් තිබේ නම් එය මඟිනි).

## Signal

[Signal](https://signal.org/) යනු E2E encrypted messaging හි පුරෝගාමියා වන අතර, විශාල tech conglomerates එකක් හරහා යාමට අකමැති ඕනෑම කෙනෙකුට එය ඉතා සුදුසු සන්නිවේදන විකල්පයකි.

ඔබ Signal ආරම්භ කරන්නේ `Super + Shift + G` මඟිනි. එය base install එකේ කොටසක් නොවන බැවින්, ඔබ පළමු වරට එය එබූ විට, Omarchy එය ඔබට install කර දීමට ඉදිරිපත් වනු ඇත (එය Omarchy menu එකේ _Install > Service_ යටතේද ඇත).

## Omaview

[Omaview](https://github.com/omacom/omaview) යනු Omarchy හිම අතිශය සරල picture viewer එක සහ media player එකයි: ඔබේ photos, videos සහ music සඳහා තනි window එකකි. Photo එකක් විවෘත කරන්න, arrow keys එහි folder එකේ ඉතිරි ඒවා හරහා පියවරෙන් පියවර යයි, `N` සහ `P` ඕනෑම දෙයක් සඳහා එය කරයි, සහ `Ctrl + M` මුළු folder එකම grid එකක් ලෙස පෙන්වයි. එය HEIC, AVIF සහ JPEG XL photos ද පෙන්වන අතර, දිග ඕනෑම දෙයක ඔබ නැවැත්වූ තැනින් නැවත ආරම්භ කරයි.

Fullscreen සඳහා `F` ද, Omasnap හි picture එකක් edit කිරීමට හෝ Omacut හි video එකක් trim කිරීමට `E` ද, picture එකක් print කිරීමට `Ctrl + P` ද, ගොනුවක් Trash එකට යැවීමට `Delete` ද ඔබන්න (`Ctrl + Z` එය නැවත ගෙන එයි). සෑම shortcut එකක්ම බැලීමට එය තුළ `?` ඔබන්න.

ඔබ Omaview _Media Viewer_ ලෙස application launcher එක හරහා (`Super + Space`) ආරම්භ කරයි, නැතහොත් file manager එකේ picture එකක්, video එකක් හෝ song එකක් double-click කරන්න.

## Omacut

[Omacut](https://github.com/omacom-io/omacut) යනු Omarchy හිම අතිශය සරල video trimmer එකයි. ඔබට අවශ්‍ය වන්නේ clip එකක ආරම්භය සහ අවසානය කපා දැමීම පමණක් වන විට, සම්පූර්ණ video editor එකක් දියත් කිරීමට වඩා මෙය ඉතා සුදුසුය.

ඔබ Omacut ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`).

## Monologue

[Monologue](https://github.com/omacom/monologue) යනු Omarchy හිම අතිශය සරල webcam recorder එකයි. ඔබේ camera එක සහ microphone එක එක් වරක් තෝරන්න, ඉන්පසු record කිරීමට `Space` ඔබන්න, එම take එකම pause කර නැවත ආරම්භ කිරීමට නැවතත් එය ඔබන්න. එය සැමවිටම ඔබේ camera එකේ ඉහළම resolution එකෙන් record කරන අතර, ඔබ ආරම්භ කිරීමට පෙර ඔබේ levels පරීක්ෂා කළ හැකි වන පරිදි සජීවී microphone meter එකක් ඇත.

Take එක නවත්වන්න, එය built-in editor එකක වහාම විවෘත වේ. Clip එකක් බෙදීමට එය double-click කරන්න, එක් එක් කැබැල්ල trim කිරීමට handles drag කරන්න, සහ ඔබට අවශ්‍ය නැති කොටස් ඉවත් කරන්න. ඉන්පසු එය MP4 එකක් ලෙස සුරකින්න. ඔබ එය ඉවත දමන තුරු ඔබේ මුල් recording එක තබා ගන්නා බැවින්, ඔබට සැමවිටම නැවත පැමිණ එය වෙනස් ආකාරයකට කපා ගත හැකිය.

ඔබ Monologue ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`).
