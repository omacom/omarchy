# චිත්‍රක අතුරුමුහුණත් (GUIs)

## Files

Files (Nautilus) යනු චිත්‍රක ගොනු කළමනාකරුය. `Super + Shift + F` මඟින් එය විවෘත වන අතර, `Super + Shift + Alt + F` මඟින් එය ඔබේ terminal එක දැනට සිටින directory එක තුළ විවෘත වන අතර, එය ක්ලික් කිරීම් බොහොමයක් ඉතිරි කරයි. `Ctrl + L` මඟින් ඔබට path එකක් ටයිප් කළ හැකි අතර, ඕනෑම ගොනුවක් මත `Space` එබීමෙන් කිසිවක් විවෘත නොකරම එය පිළිබඳ ඉක්මන් පෙරදසුනක් ලැබේ.

USB stick එකක් හෝ SD card එකක් සම්බන්ධ කළ විට එය ස්වයංක්‍රීයවම mounted වන බැවින්, එය පැති තීරුවේ ඒ ආකාරයෙන්ම දිස් වේ. ධාවකයක් format කිරීම, SMART සෞඛ්‍යය පරීක්ෂා කිරීම, partitions සෑදීම වැනි වඩාත් සම්බන්ධ කාර්යයන් සඳහා, app launcher එකෙන් (`Super + Space`) _Disks_ දියත් කරන්න.

දෙවරක් ක්ලික් කිරීම සාධාරණ පෙරනිමි අනුගමනය කරයි: පින්තූර, වීඩියෝ සහ සංගීතය Omaview තුළද, PDFs Document Viewer තුළද, Markdown Omawrite තුළද, සාමාන්‍ය පෙළ _Setup > Default > Editor_ යටතේ තෝරාගත් editor එක තුළද විවෘත වේ.

## Disktree

ධාවකය පිරී ඔබට එය කන්නේ කුමක්දැයි කිසිදු අදහසක් නැති විට, app launcher එකෙන් (`Super + Space`) [Disktree](https://github.com/tobi/disktree) දියත් කරන්න. එය ඔබේ home directory එකේ චිත්‍රක treemap එකක් පෙන්වයි. විශාල blocks වැඩි ඉඩක් ගනී; keyboard එකෙන් හෝ mouse එකෙන් directories තුළට යන්න, ඉවත් කළ යුතු දේ සලකුණු කරන්න, සහ කිසිවක් ඉවත් කිරීමට පෙර ඔබේ තේරීම් සමාලෝචනය කරන්න. මුළු disk එකම scan කිරීමට `disktree --disk` ධාවනය කරන්න.

## Obsidian

[Obsidian](https://obsidian.md/) යනු ගබඩා කිරීම සඳහා සරල Markdown ගොනු භාවිත කරන, නොමිලේ සහ ඉතා පුළුල් කළ හැකි සටහන් ගැනීමේ යෙදුමකි.

Obsidian පුද්ගලික, වාණිජ සහ ලාභ නොලබන භාවිතයද ඇතුළුව සියලු අරමුණු සඳහා නොමිලේය.

Obsidian iOS සහ Android මත ජංගම යෙදුම් සමඟ [සමමුහුර්ත කිරීම සඳහා වාණිජ ඇඩෝනයක්](https://obsidian.md/sync) ද ලබා දෙයි. (https://obsidian.md/pricing).

ඔබ Obsidian ආරම්භ කරන්නේ `Super + Shift + O` සමඟිනි. තේමා සමමුහුර්තකරණය භාවිත කිරීමට, settings යටතේ `Omarchy` තේමාව තෝරාගත යුතුය.

## Omawrite

[Omawrite](https://github.com/omacom-io/omawrite) යනු Omarchy හිම සතුව ඇති ඉතා සරල Markdown ලිවීමේ යෙදුමයි. Vaults නැත, plugins නැත, ඔබ සහ වචන පමණයි.

ඔබ Omawrite ආරම්භ කරන්නේ `Super + Shift + W` සමඟිනි.

## Pinta

ඔබ Pinta ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`).

## Aether

[Aether](https://github.com/bjarneo/aether) යනු පසුබිම් රූපයකින් වර්ණ උපුටාගෙන ඒවා සම්පූර්ණ, සුසංයෝජිත තේමාවක් බවට පත් කළ හැකි තේමාකරණ යෙදුමකි. එය [ඔබේම තේමාවක් සෑදීමට](43-making-your-own-theme.md) ඇති පහසුම ක්‍රමයයි.

ඔබ Aether ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`).

## LocalSend

[LocalSend](https://localsend.org/) මඟින් Apple හි AirDrop මෙන්, එම යෙදුම ධාවනය වන එකම ජාලයේ ඇති වෙනත් උපාංගවලට ගොනු යැවීමට ඔබට ඉඩ දෙයි. කෙසේ වෙතත් එය cross-platform වේ, එබැවින් ඔබට Windows, macOS, Android, iOS සහ ඇත්ත වශයෙන්ම Linux වෙත සහ ඉන් ගොනු යැවිය හැකිය.

ඔබට Share මෙනුව `Super + Ctrl + S` මත හෝ Omarchy මෙනුවේ _Trigger > Share_ යටතේ විවෘත කළ හැකිය. එය ඔබට විකල්ප හතරක් ලබා දෙයි:

- **Clipboard** ඔබ පිටපත් කළ ඕනෑම දෙයක් පෙළ ගොනුවක් ලෙස යවයි. ඔබටම email නොකර සබැඳියක් හෝ කැබැල්ලක් ඔබේ දුරකථනයට ලබා ගැනීමට විශිෂ්ටයි.
- **File** එකවර කිහිපයක් තෝරාගත හැකි file picker එකක් විවෘත කරයි.
- **Folder** සම්පූර්ණ directory එකක්ම යවයි.
- **Receive** වෙනත් උපාංගයකට ඔබට යමක් යැවීමට හැකි වන පරිදි LocalSend නිසි පරිදි විවෘත කරයි.

terminal එකෙන්ද එම දෙයම `omarchy share clipboard`, `omarchy share file [path]`, සහ `omarchy share folder [path]` සමඟ ක්‍රියා කරයි. Path එක ඉවත් කරන්න, ඔබට picker එක ලැබේ.

ඔබට file manager එකෙන් කෙලින්ම යැවිය හැකිය: Nautilus තුළ ඕනෑම තේරීමක් right-click කර _Send via LocalSend_ තෝරන්න.

Omarchy හි firewall එක LocalSend හි port එක හැර පෙරනිමියෙන් වසා ඇත, එබැවින් මෙය නව ස්ථාපනයකදී ආරම්භයේදීම ක්‍රියා කරයි. [ආරක්ෂාව](48-security.md) බලන්න.

## LibreOffice

[LibreOffice](https://www.libreoffice.org/) යනු word processor, spreadsheet, presentations, drawing application සහ තවත් බොහෝ දේ සහිත සම්පූර්ණ office package එකකි. එය Microsoft Office ගොනු සමඟ අනුකූල වන බැවින්, එම Word ලේඛන විවෘත කිරීමට හැකි වීමට මෙය විශිෂ්ට ක්‍රමයකි.

ඔබ LibreOffice ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`).

## Hype

[Hype](https://github.com/omacom/hype) යනු Omarchy හිම සතුව ඇති ඉතා සරල presentation යෙදුමයි. ඔබේ deck එක යනු එහි පින්තූර සහ වීඩියෝ ඒ අසලම ඇති තනි Markdown ගොනුවකි: සජීවී පෙරදසුනක් යට එක් එක් slide එක ලියන්න, slides පිළිවෙලට drag කරන්න, පසුව fullscreen ඉදිරිපත් කරන්න හෝ PDF සහ PowerPoint වෙත export කරන්න. එය ඔබේ Omarchy තේමාව පවා ලබා ගනියි.

ඔබ Hype ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`). සෑම shortcut එකක්ම බැලීමට එහි ඇතුළත `?` ඔබන්න.

## Signed

[Signed](https://github.com/omacom/signed) යනු PDFs අත්සන් කිරීමට සහ ඒවා පුරවීමට Omarchy හිම සතුව ඇති ඉතා සරල ක්‍රමයයි. ඔබ සුරකින ලද අත්සන, පෙළ සහ අද දිනය පිටුවක ඕනෑම තැනක තබන්න, පසුව මුල් පිටපත අසල අත්සන් කළ පිටපතක් සුරකින්න. කෙසේ දැයි දැන ගැනීමට [PDFs පුරවීම](27-filling-out-pdfs.md) බලන්න.

ඔබ Signed ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`), නැතිනම් file manager එකෙන් PDF එකක් එය සමඟ විවෘත කරන්න.

## Omacalc

[Omacalc](https://github.com/omacom-io/omacalc) යනු floating window එකක විවෘත වන, Omarchy හිම සතුව ඇති ඉතා සරල calculator එකයි.

ඔබ Omacalc ආරම්භ කරන්නේ `Super + Shift + Q` සමඟිනි (හෝ ඔබේ keyboard එකේ එකක් තිබේ නම් calculator යතුර).

## Signal

[Signal](https://signal.org/) යනු E2E encrypted messaging හි පුරෝගාමියා වන අතර, විශාල තාක්ෂණික සමූහ ව්‍යාපාරවලින් එකක් හරහා යාමට අකැමැති ඕනෑම කෙනෙකුට විශිෂ්ට සන්නිවේදන විකල්පයකි.

ඔබ Signal ආරම්භ කරන්නේ `Super + Shift + G` සමඟිනි. එය base install එකේ කොටසක් නොවන බැවින්, ඔබ පළමු වරට එය එබූ විට, Omarchy එය ඔබට ස්ථාපනය කිරීමට ඉදිරිපත් වේ (එය Omarchy මෙනුවේ _Install > Service_ යටතේද ඇත).

## Omaview

[Omaview](https://github.com/omacom/omaview) යනු Omarchy හිම සතුව ඇති ඉතා සරල picture viewer සහ media player එකයි: ඔබේ ඡායාරූප, වීඩියෝ සහ සංගීතය සඳහා එක් window එකකි. ඡායාරූපයක් විවෘත කරන්න, arrow යතුරු එහි folder එකේ ඉතිරි ඒවා හරහා ගමන් කරයි, `N` සහ `P` ඕනෑම දෙයක් සඳහා එය කරයි, සහ `Ctrl + M` මුළු folder එකම grid එකක් ලෙස පෙන්වයි. එය HEIC, AVIF සහ JPEG XL ඡායාරූපද පෙන්වයි, සහ දිගු ඕනෑම දෙයක ඔබ නතර කළ තැනින් නැවත පටන් ගනියි.

Fullscreen සඳහා `F`, Omasnap තුළ පින්තූරයක් edit කිරීමට හෝ Omacut තුළ වීඩියෝවක් trim කිරීමට `E`, පින්තූරයක් print කිරීමට `Ctrl + P`, සහ ගොනුවක් Trash එකට ගෙන යාමට `Delete` ඔබන්න (`Ctrl + Z` එය නැවත ගෙන එයි). සෑම shortcut එකක්ම බැලීමට එහි ඇතුළත `?` ඔබන්න.

ඔබ Omaview _Media Viewer_ ලෙස application launcher එක හරහා (`Super + Space`) ආරම්භ කරයි, නැතිනම් file manager එකේ පින්තූරයක්, වීඩියෝවක් හෝ ගීතයක් දෙවරක් ක්ලික් කරන්න.

## Omacut

[Omacut](https://github.com/omacom-io/omacut) යනු Omarchy හිම සතුව ඇති ඉතා සරල video trimmer එකයි. ඔබට අවශ්‍ය වන්නේ clip එකක ආරම්භය සහ අවසානය කපා දැමීම පමණක් නම්, එය සම්පූර්ණ video editor එකක් දියත් කිරීමට වඩා හොඳය.

ඔබ Omacut ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`).

## Monologue

[Monologue](https://github.com/omacom/monologue) යනු Omarchy හිම සතුව ඇති ඉතා සරල webcam recorder එකයි. ඔබේ camera එක සහ microphone එක එක් වරක් තෝරන්න, පසුව record කිරීමට `Space` ඔබන්න, සහ එම take එකම pause කර නැවත ආරම්භ කිරීමට නැවත ඔබන්න. එය සැමවිටම ඔබේ camera එකේ ඉහළම resolution එකෙන් record කරයි, ඔබ ආරම්භ කිරීමට පෙර levels පරීක්ෂා කළ හැකි වන පරිදි සජීවී microphone meter එකක්ද ඇත.

Take එක නවත්වන්න, එය built-in editor එකක වහාම විවෘත වේ. Clip එකක් බෙදීමට එය දෙවරක් ක්ලික් කරන්න, එක් එක් කොටස trim කිරීමට handles drag කරන්න, සහ ඔබට අවශ්‍ය නැති කොටස් ඉවත් කරන්න. පසුව එය MP4 එකක් ලෙස සුරකින්න. ඔබ එය අතහරින තුරු ඔබේ මුල් recording එක තබා ගනු ලැබේ, එබැවින් ඔබට සැමවිටම නැවත පැමිණ එය වෙනස් ලෙස කපා ගත හැකිය.

ඔබ Monologue ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`).
