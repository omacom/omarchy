# GUI යෙදුම්

## Files

Files (Folio) යනු චිත්‍රකමය ගොනු කළමනාකරුයි. `Super + Shift + F` එය විවෘත කරයි, `Super + Shift + Alt + F` ඔබේ ටර්මිනලය සිටින නාමාවලියෙහිම එය විවෘත කරයි, එමඟින් ක්ලික් කිරීම් බොහොමයක් ඉතිරි වේ. `Ctrl + L` ඔබට path එකක් ටයිප් කිරීමට ඉඩ දෙයි, ඕනෑම ගොනුවක් මත `Space` එබීම එය විවෘත නොකර සම්පූර්ණ ප්‍රමාණයෙන් පෙරදසුන් කරයි.

USB stick එකක් හෝ SD card එකක් සම්බන්ධ කරන්න, එය ස්වයංක්‍රීයව mount වන බැවින් sidebar එකේ සරලවම දිස් වේ. වඩා සංකීර්ණ දේවල් සඳහා — ධාවකයක් format කිරීම, SMART health පරීක්ෂා කිරීම, partitions සෑදීම — app launcher එකෙන් (`Super + Space`) _Disks_ දියත් කරන්න.

ද්විත්ව-ක්ලික් කිරීම විචක්ෂණ පෙරනිමි අනුගමනය කරයි: පින්තූර, වීඩියෝ සහ සංගීතය Omaview තුළද, PDF Document Viewer තුළද, Markdown Omawrite තුළද, සාමාන්‍ය පෙළ _Setup > Default > Editor_ යටතේ තෝරාගත් editor එක තුළද විවෘත වේ.

## Disktree

ධාවකය පිරී ගොස් එය කුමක් විසින් අනුභව කරන්නේද යන්න ගැන කිසිදු අදහසක් නැති විට, app launcher එකෙන් (`Super + Space`) [Disktree](https://github.com/tobi/disktree) දියත් කරන්න. එය ඔබේ නිවසේ නාමාවලියේ චිත්‍රකමය treemap එකක් පෙන්වයි. විශාල blocksවලට වැඩි ඉඩක් ලැබේ; keyboard එකෙන් හෝ mouse එකෙන් නාමාවලි තුළට ඇවිදින්න, ඉවත් කළ යුතු දේ සලකුණු කරන්න, කිසිවක් ඉවත් කිරීමට පෙර ඔබේ තේරීම් සමාලෝචනය කරන්න. සම්පූර්ණ තැටිය scan කිරීමට `disktree --disk` ධාවනය කරන්න.

## Obsidian

[Obsidian](https://obsidian.md/) යනු ගබඩා කිරීම සඳහා සරල Markdown ගොනු භාවිතා කරන, නොමිලේ ලැබෙන සහ අධික ලෙස විස්තාරණය කළ හැකි සටහන් ගැනීමේ යෙදුමකි.

Obsidian පුද්ගලික, වාණිජ සහ ලාභ නොලබන භාවිතය ඇතුළුව සියලු අරමුණු සඳහා නොමිලේ ලැබේ.

Obsidian iOS සහ Android මත ජංගම යෙදුම් සමඟ [සමමුහුර්ත කිරීම සඳහා වාණිජ අතිරේකයක්](https://obsidian.md/sync) ද ලබා දෙයි. (https://obsidian.md/pricing).

ඔබ `Super + Shift + O` සමඟ Obsidian ආරම්භ කරයි. තේමා සමමුහුර්ත කිරීම භාවිතා කිරීමට, ඔබ settings යටතේ `Omarchy` තේමාව තෝරාගත යුතුයි.

ඔබ application launcher එක (`Super + Space`) හරහා Pinta ආරම්භ කරයි.

## LocalSend

[LocalSend](https://localsend.org/) Appleහි AirDrop මෙන්, යෙදුම ධාවනය වන එම ජාලයේම ඇති වෙනත් උපාංගවලට ගොනු යැවීමට ඔබට ඉඩ දෙයි. කෙසේ වෙතත් එය cross-platform බැවින් ඔබට Windows, macOS, Android, iOS සහ ඇත්ත වශයෙන්ම Linux සමඟ ගොනු එහා මෙහා යැවිය හැකිය.

ඔබට `Super + Ctrl + S` මත හෝ Omarchy menu එකේ _Trigger > Share_ යටතේ Share menu එක විවෘත කළ හැකිය. එය ඔබට විකල්ප හතරක් ලබා දෙයි:

- **Clipboard** ඔබ පිටපත් කර ඇති ඕනෑම දෙයක් text file එකක් ලෙස යවයි. ඔබටම email කිරීමකින් තොරව සබැඳියක් හෝ කේත කොටසක් ඔබේ දුරකථනයට ලබා ගැනීම සඳහා විශිෂ්ටයි.
- **File** එකවර කිහිපයක් තෝරාගත හැකි ගොනු තේරීමක් විවෘත කරයි.
- **Folder** සම්පූර්ණ නාමාවලියක් යවයි.
- **Receive** වෙනත් උපාංගයකට ඔබට යමක් යැවිය හැකි වන පරිදි නියම LocalSend එක විවෘත කරයි.

ටර්මිනලයෙන්ද එයම ක්‍රියා කරන්නේ `omarchy share clipboard`, `omarchy share file [path]` සහ `omarchy share folder [path]` සමඟයි. Path එක අතහරින්න, ඔබට තේරීම ලැබේ.

ඔබට ගොනු කළමනාකරුගෙන් කෙළින්මද යැවිය හැකිය: Files තුළ ඕනෑම තේරීමක් right-click කර LocalSend සමඟ එය share කරන්න.

Omarchyහි firewall එක LocalSendහි port එක හැර පෙරනිමියෙන් වසා ඇති බැවින්, මෙය අලුත් ස්ථාපනයකදී ආරම්භයේ සිටම ක්‍රියා කරයි. [ආරක්ෂාව](48-security.md) බලන්න.

## LibreOffice

[LibreOffice](https://www.libreoffice.org/) යනු word processor, spreadsheet, presentations, drawing application සහ තවත් බොහෝ දේ සහිත සම්පූර්ණ කාර්යාල පැකේජයකි. එය Microsoft Office ගොනු සමඟ අනුකූල බැවින්, එම Word documents විවෘත කිරීමට හැකි වීමට මෙය විශිෂ්ට ක්‍රමයකි.

ඔබ application launcher එක (`Super + Space`) හරහා LibreOffice ආරම්භ කරයි.

## Hype

[Hype](https://github.com/omacom/hype) යනු Omarchyහිම අතිශය සරල presentation යෙදුමයි. ඔබේ deck එක එහි රූප සහ වීඩියෝ අසල ඇති තනි Markdown ගොනුවකි: සජීවී පෙරදසුනක් යට එක් එක් slide එක ලියන්න, slides පිළිවෙළට ඇද දමන්න, ඉන්පසු fullscreen ඉදිරිපත් කරන්න හෝ PDF සහ PowerPoint වෙත export කරන්න. එය ඔබේ Omarchy තේමාව පවා ලබා ගනියි.
