# GUI යෙදුම්

## Files

Files (Nautilus) යනු චිත්‍රක ගොනු කළමනාකරුය. `Super + Shift + F` මඟින් එය විවෘත වන අතර, `Super + Shift + Alt + F` මඟින් එය විවෘත වන්නේ ඔබේ terminal එක දැනට සිටින directory එක තුළමය, එම නිසා ක්ලික් කිරීම් රාශියක් ඉතිරි වේ. `Ctrl + L` මඟින් ඔබට path එකක් ටයිප් කළ හැකි අතර, ඕනෑම ගොනුවක් මත `Space` එබීමෙන් කිසිවක් විවෘත නොකරම ඔබට ඉක්මන් පෙරදසුනක් ලැබේ.

USB stick එකක් හෝ SD card එකක් සවි කරන්න, එය ස්වයංක්‍රීයවම mount වන බැවින් එය පැති තීරුවේ ඒ ආකාරයෙන්ම දිස් වේ. ඊට වඩා සංකීර්ණ ඕනෑම දෙයක් සඳහා — drive එකක් format කිරීම, SMART සෞඛ්‍යය පරීක්ෂා කිරීම, partitions සෑදීම — app launcher එකෙන් (`Super + Space`) _Disks_ දියත් කරන්න.

ද්වි-ක්ලික් කිරීම සාධාරණ පෙරනිමි අනුගමනය කරයි: පින්තූර, වීඩියෝ සහ සංගීතය Omaview තුළද, PDFs Document Viewer තුළද, Markdown Omawrite තුළද, සහ සරල පෙළ _Setup > Default > Editor_ යටතේ තෝරාගත් editor එක තුළද විවෘත වේ.

## Disktree

Drive එක පිරී ගොස් ඇත්තේ කුමක් නිසාදැයි ඔබට කිසිම අදහසක් නැති විට, app launcher එකෙන් (`Super + Space`) [Disktree](https://github.com/tobi/disktree) දියත් කරන්න. එය ඔබේ home directory එකේ චිත්‍රක treemap එකක් පෙන්වයි. විශාල blocksවලට වැඩි ඉඩක් හිමි වේ; යතුරුපුවරුවෙන් හෝ mouse එකෙන් directories තුළට යන්න, ඉවත් කළ යුතු දේ සලකුණු කරන්න, සහ කිසිවක් ඉවත් කිරීමට පෙර ඔබේ තේරීම් සමාලෝචනය කරන්න. මුළු disk එකම scan කිරීමට `disktree --disk` ධාවනය කරන්න.

## Obsidian

[Obsidian](https://obsidian.md/) යනු ගබඩා කිරීම සඳහා සරල Markdown ගොනු භාවිත කරන, නොමිලේ ලැබෙන සහ ඉහළින්ම පුළුල් කළ හැකි සටහන් ගැනීමේ යෙදුමකි.

Obsidian පුද්ගලික, වාණිජ සහ ලාභ නොලබන භාවිතය ඇතුළුව සියලුම අරමුණු සඳහා නොමිලේය.

Obsidian iOS සහ Android මත වන ජංගම යෙදුම් සමඟ සමමුහුර්ත කිරීම සඳහා [වාණිජ අතිරේකයක්ද](https://obsidian.md/sync) පිරිනමයි. (https://obsidian.md/pricing).

ඔබ Obsidian ආරම්භ කරන්නේ `Super + Shift + O` මඟිනි. Theme syncing භාවිත කිරීමට, settings යටතේ ඔබ `Omarchy` theme එක තෝරා ගත යුතුය.

## Omawrite

[Omawrite](https://github.com/omacom-io/omawrite) යනු Omarchy හිම ඇති අතිශය සරල Markdown ලිවීමේ යෙදුමයි. Vaults නැත, plugins නැත, ඇත්තේ ඔබ සහ වචන පමණි.

ඔබ Omawrite ආරම්භ කරන්නේ `Super + Shift + W` මඟිනි.

## Pinta

[Pinta](https://www.pinta-project.com/) යනු කැපීම, ප්‍රමාණය වෙනස් කිරීම සහ වෙනත් මූලික හැසිරවීම් සඳහා විශිෂ්ට මූලික රූප සංස්කරණ මෙවලමකි. Photoshop විකල්පයක් බලාපොරොත්තු වන්න එපා. නමුත් එයට තවමත් Magic Wand එකක් සහ layers තිබේ!

ඔබ Pinta ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`).

## Aether

[Aether](https://github.com/bjarneo/aether) යනු පසුබිම් රූපයකින් වර්ණ උකහා ගෙන ඒවා සම්පූර්ණ, සමෝධානික theme එකක් බවට පත් කළ හැකි theming යෙදුමකි. එය [ඔබේම theme එකක් සාදා ගැනීමට](43-making-your-own-theme.md) ඇති පහසුම ක්‍රමයයි.

ඔබ Aether ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`).

## LocalSend

[LocalSend](https://localsend.org/) මඟින් ඔබට එම යෙදුම ධාවනය වන එකම ජාලයේ ඇති වෙනත් උපාංගවලට, Apple හි AirDrop මෙන්, ගොනු යැවිය හැක. කෙසේ වෙතත්, එය cross-platform බැවින් ඔබට Windows, macOS, Android, iOS සහ ඇත්තෙන්ම Linux වෙත සහ ඉන් පිටතට ගොනු යැවිය හැක.

ඔබට Share menu එක `Super + Ctrl + S` මත හෝ Omarchy menu එකේ _Trigger > Share_ යටතේ විවෘත කළ හැක. එය ඔබට විකල්ප හතරක් ලබා දෙයි:

- **Clipboard** මඟින් ඔබ පිටපත් කර ඇති ඕනෑම දෙයක් පෙළ ගොනුවක් ලෙස යවයි. ඔබටම email නොකර ඔබේ දුරකථනයට link එකක් හෝ snippet එකක් ලබා ගැනීම සඳහා විශිෂ්ටයි.
- **File** මඟින් ඔබට එකවර කිහිපයක් තෝරා ගත හැකි file picker එකක් විවෘත කරයි.
- **Folder** මඟින් සම්පූර්ණ directory එකක් යවයි.
- **Receive** මඟින් LocalSend ම විවෘත කරන බැවින් වෙනත් උපාංගයකට ඔබට යමක් එවිය හැක.

Terminal එකෙන්ද එම දෙයම `omarchy share clipboard`, `omarchy share file [path]` සහ `omarchy share folder [path]` සමඟ ක්‍රියා කරයි. Path එක අත්හරින්න, එවිට ඔබට picker එක ලැබේ.

ඔබට file manager එකෙන් සෘජුවමද යැවිය හැක: Nautilus හි ඕනෑම තේරීමක් මත right-click කර _Send via LocalSend_ තෝරන්න.

Omarchy හි firewall එක පෙරනිමියෙන් LocalSend හි port එක හැර වසා ඇති බැවින්, මෙය අලුත් install එකක කිසිදු සැකසීමකින් තොරවම ක්‍රියා කරයි. [ආරක්ෂාව](48-security.md) බලන්න.

## LibreOffice

[LibreOffice](https://www.libreoffice.org/) යනු word processor, spreadsheet, presentations, drawing application සහ තවත් බොහෝ දේ සහිත සම්පූර්ණ office package එකකි. එය Microsoft Office ගොනු සමඟ අනුකූල බැවින්, එම Word ලේඛන විවෘත කිරීමට හැකි වීමට මෙය විශිෂ්ට ක්‍රමයකි.

ඔබ LibreOffice ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`).

## Hype

[Hype](https://github.com/omacom/hype) යනු Omarchy හිම ඇති අතිශය සරල presentation යෙදුමයි. ඔබේ deck එක යනු එහි රූප සහ වීඩියෝ ඊට යාබදව ඇති තනි Markdown ගොනුවකි: සජීව පෙරදසුනක් පහළ එක් එක් slide එක ලියන්න, slides පිළිවෙළට drag කරන්න, පසුව fullscreen ඉදිරිපත් කරන්න හෝ PDF සහ PowerPoint වෙත export කරන්න. එය ඔබේ Omarchy theme එක පවා ලබා ගනියි.

ඔබ Hype ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`). සෑම shortcut එකක්ම බැලීමට එහි ඇතුළත `?` ඔබන්න.

## Signed

[Signed](https://github.com/omacom/signed) යනු PDFs අත්සන් කිරීමට සහ ඒවා පුරවීමට Omarchy හිම ඇති අතිශය සරල ක්‍රමයයි. ඔබේ සුරකින ලද අත්සන, පෙළ සහ අද දිනය පිටුවක ඕනෑම තැනක තබන්න, පසුව මුල් ගොනුව අසලම අත්සන් කළ පිටපතක් සුරකින්න. ආකාරය සඳහා [PDF පුරවන ආකාරය](27-filling-out-pdfs.md) බලන්න.

ඔබ Signed ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`), නැතහොත් file manager එකෙන් PDF එකක් එය සමඟ විවෘත කරන්න.

## Checkmate

[Checkmate](https://github.com/omacom/checkmate) යනු Omarchy හිම ඇති 3D chess ක්‍රීඩාවයි. එකම පරිගණකයේ මිතුරෙකු සමඟ හෝ මට්ටම් තුනක ඇති built-in ප්‍රතිවාදියාට එරෙහිව, ඒ ඒ ආකාරයෙන් චලනය වන මූර්තිමත් කට්ටල හතරක් මත ක්‍රීඩා කරන්න: orbital craft, කැටයම් කළ දැව සහ ඇත්දළ, වන සතුන් සහ candy. ක්‍රීඩාවලට clock එකක් නැති අතර සෑම move එකකින් පසුවම save වේ.

ඔබ Checkmate ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`), එහි එය Chess ලෙස ලැයිස්තුගත කර ඇත. සෑම shortcut එකක්ම බැලීමට එහි ඇතුළත `?` ඔබන්න.

## Cards

[Cards](https://github.com/omacom/cards) යනු Omarchy හිම ඇති Klondike solitaire එකයි. Passes සඳහා සීමාවක් නොමැතිව, card series හතරක් තුළ තුනක් අදින්න: එකක් ඔබේ theme එකේ වර්ණවලින් ඇඳ ඇති අතර, තුනකට තමන්ගේම පෙනුමක් ඇත. Card එකක් ක්ලික් කර පසුව එය යන තැන ක්ලික් කරන්න, එය drag කරන්න, නැතහොත් හොඳම තැනට යැවීමට double-click කරන්න. ක්‍රීඩා සෑම move එකකින් පසුවම save වේ.

ඔබ Cards ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`). සෑම shortcut එකක්ම බැලීමට එහි නම ක්ලික් කරන්න, නැතහොත් `?` ඔබන්න.

## Omacalc

[Omacalc](https://github.com/omacom-io/omacalc) යනු floating window එකක විවෘත වන, Omarchy හිම ඇති අතිශය සරල calculator එකයි.

ඔබ Omacalc ආරම්භ කරන්නේ `Super + Shift + Q` මඟිනි (නැතහොත් ඔබේ යතුරුපුවරුවේ එකක් තිබේ නම් calculator යතුර මඟිනි).

## Signal

[Signal](https://signal.org/) යනු E2E encrypted messaging හි පුරෝගාමියා වන අතර, විශාල තාක්ෂණික සමාගම් සමූහයකින් එකක් හරහා යාමට අකමැති ඕනෑම කෙනෙකු සඳහා විශිෂ්ට සන්නිවේදන විකල්පයකි.

ඔබ Signal ආරම්භ කරන්නේ `Super + Shift + G` මඟිනි. එය base install එකේ කොටසක් නොවන බැවින්, ඔබ පළමු වරට එය එබූ විට, Omarchy එය ඔබ වෙනුවෙන් install කිරීමට ඉදිරිපත් වේ (එය Omarchy menu එකේ _Install > Service_ යටතේද ඇත).

## Omaview

[Omaview](https://github.com/omacom/omaview) යනු Omarchy හිම ඇති අතිශය සරල picture viewer එක සහ media player එකයි: ඔබේ ඡායාරූප, වීඩියෝ සහ සංගීතය සඳහා එක් window එකකි. ඡායාරූපයක් විවෘත කරන්න, arrow යතුරු එහි folder එකේ ඉතිරි ඒවා හරහා පියවරෙන් පියවර යයි, `N` සහ `P` ඕනෑම දෙයක් සඳහා එය කරයි, සහ `Ctrl + M` මුළු folder එකම grid එකක් ලෙස පෙන්වයි. එය HEIC, AVIF සහ JPEG XL ඡායාරූපද පෙන්වන අතර, දිග ඕනෑම දෙයක ඔබ නතර කළ තැනින්ම නැවත ආරම්භ කරයි.

Fullscreen සඳහා `F` ද, Omasnap එකේ පින්තූරයක් edit කිරීමට හෝ Omacut එකේ වීඩියෝවක් trim කිරීමට `E` ද, පින්තූරයක් print කිරීමට `Ctrl + P` ද, සහ ගොනුවක් Trash එකට යැවීමට `Delete` ද ඔබන්න (`Ctrl + Z` එය ආපසු ගෙන එයි). සෑම shortcut එකක්ම බැලීමට එහි ඇතුළත `?` ඔබන්න.

ඔබ Omaview ආරම්භ කරන්නේ application launcher එක හරහා _Media Viewer_ ලෙසය (`Super + Space`), නැතහොත් file manager එකේ පින්තූරයක්, වීඩියෝවක් හෝ ගීතයක් double-click කරන්න.

## Omacut

[Omacut](https://github.com/omacom-io/omacut) යනු Omarchy හිම ඇති අතිශය සරල video trimmer එකයි. ඔබට අවශ්‍ය වන්නේ clip එකක ආරම්භය සහ අවසානය කපා හැරීම පමණක් වන විට, එය සම්පූර්ණ video editor එකක් දියත් කිරීමට වඩා හොඳය.

ඔබ Omacut ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`).

## Monologue

[Monologue](https://github.com/omacom/monologue) යනු Omarchy හිම ඇති අතිශය සරල webcam recorder එකයි. ඔබේ camera එක සහ microphone එක එක් වරක් තෝරන්න, පසුව record කිරීමට `Space` ඔබන්න, සහ එම take එකම pause කර නැවත ආරම්භ කිරීමට නැවත ඔබන්න. එය සෑම විටම ඔබේ camera එකේ ඉහළම resolution එකෙන් record කරන අතර, ඔබ ආරම්භ කිරීමට පෙර ඔබේ levels පරීක්ෂා කළ හැකි වන පරිදි සජීව microphone meter එකක්ද ඇත.

Take එක නවත්වන්න, එය බිල්ට් editor එකක වහාම විවෘත වේ. Clip එකක් බෙදීමට එය double-click කරන්න, එක් එක් කොටස trim කිරීමට handles drag කරන්න, සහ ඔබට අනවශ්‍ය කොටස් ඉවත් කරන්න. පසුව එය MP4 එකක් ලෙස සුරකින්න. ඔබ එය ඉවත දමන තුරු ඔබේ මුල් recording එක තබා ගන්නා බැවින්, ඔබට සෑම විටම ආපසු පැමිණ එය වෙනස් ලෙස කපා ගත හැක.

ඔබ Monologue ආරම්භ කරන්නේ application launcher එක හරහාය (`Super + Space`).
