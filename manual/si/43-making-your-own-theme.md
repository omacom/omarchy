# ඔබේම තේමාවක් සෑදීම

ඔබට ඔබේම තේමා `~/.config/omarchy/themes` වෙත එක් කළ හැකිය. දැනට පවතින එකක් පිටපත් කර පදනමක් ලෙස ගන්න (`/usr/share/omarchy/themes` තුළ බලන්න), ඉන්පසු ඔබේ කැමැත්ත පරිදි එය සකසන්න. ඔබේ තේමාව ඒ ෆෝල්ඩරය ඇතුළත තිබෙන තාක්, එය තේමා තේරීමේ මෙනුවට ඇතුළත් වනු ඇත.

ඔබට සකස් කිරීමට සිදුවන ප්‍රධාන ගොනුව `colors.toml` වේ. එය terminal (Foot/Alacritty/Ghostty/Kitty), btop, Chromium, Hyprland, Neovim, Helix, VSCode, Obsidian සහ සම්පූර්ණ Omarchy shell එක (top bar, menu, notifications, OSD සහ lock screen) සඳහා වින්‍යාසයන් ජනනය කිරීමට පසුව භාවිතා කරන වර්ණ කට්ටලය නිර්වචනය කරයි.

වර්ණ සමඟ සෙල්ලම් කිරීමට සහ පසුබිම් සෙවීමට සුන්දර GUI අතුරුමුහුණතක් භාවිතා කර නව තේමාවක් සෑදීමට ඔබට ඇතුළත් කර ඇති Aether යෙදුමද භාවිතා කළ හැකිය. `Super + Alt + Space` මත app grid එකෙන් එය ආරම්භ කරන්න.

### ස්ථාපිත තේමාවක අඩංගු විය හැකි දේ

`~/.config/omarchy/themes` තුළ ඔබම ලියන තේමාවක ඔබට කැමති ඕනෑම දෙයක් අඩංගු විය හැකිය — එය ඔබේ යන්ත්‍රය සහ ඔබේ ගොනුව වන අතර, Omarchy ඒ සියල්ලම යොදයි.

ඔබ වෙනත් අයෙකුගේ repo එකකින් `omarchy theme install` මඟින් ස්ථාපනය කරන තේමාවක් වර්ණ වන සියල්ල රඳවා ගන්නා අතර, ඔබේ යන්ත්‍රයේ කේත ධාවනය කරන ගොනු අතලොස්ස අහිමි කරයි: ඕනෑම `.lua` ගොනුවක්, terminal වින්‍යාසයන් (`alacritty.toml`, `foot.ini`, `ghostty.conf`, `kitty.conf`) සහ `vscode.json`. තේමාවක `hyprland.lua` යනු ඔබ ඇතුළු වන විට ඔබේ compositor එක ධාවනය කරන Lua වන අතර, terminal වින්‍යාසයක් ඔබේ terminal එක ආරම්භ කරන වැඩසටහන නම් කරයි, සහ `vscode.json` ස්ථාපනය කිරීමට VSCode දිගුවක් නම් කරයි. යමෙකුගේ තේමාවක් ස්ථාපනය කිරීම ඔබේ desktop එක පෙනෙන ආකාරය වෙනස් කළ යුතුය, එය ධාවනය කරන දේ කිසිවිටෙක නොවේ.

ඉතිරි සියල්ල තේමා කතුවරයා ලියූ ආකාරයටම හරියටම ක්‍රියා කරයි — `btop.theme`, `chromium.theme`, `helix.toml`, `shell.toml`, පසුබිම් සහ පෙරදසුන් සියල්ල රඳවා ගනු ලැබේ. ඉවත් කරන ලද දේ පමණක් ඔබේ යන්ත්‍රයේ `colors.toml` වෙතින් නැවත ජනනය කරනු ලැබේ.

තේමාවක් තුළ එහිම git repo එකක් තිබේද යන්නෙන් Omarchy මේ දෙක වෙන් කර හඳුනා ගනී, එය `omarchy theme install` clone කරන විට ඉතිරි කරන දෙයයි. එබැවින් ඔබ ලියූ තේමාවක් ඔබේම ලෙස පවතින අතර, ඔබ අන්තර්ජාලයෙන් ලබාගත් එකක් වර්ණ ලෙස පවතී.

### ආලෝක ප්‍රකාරය

ඔබ ආලෝක ප්‍රකාර තේමාවක් සාදන්නේ නම්, ඔබේ `colors.toml` හි ඉහළින්ම `mode = "light"` සකසන්න. එවිට එය සියලු යෙදුම් සඳහා ආලෝක ප්‍රකාරය සමඟ ස්වයංක්‍රීයව යුගලනය වනු ඇත. (ඔබේ තේමාවේ මූලයේ `light.mode` නම් හිස් ගොනුවක් දැමීමේ පැරණි ක්‍රමයද තවම ක්‍රියා කරයි.)

### අගුළු ඇරීමේ රූපය

`unlock.png` සහ `preview-unlock.png` රූප සමඟ සපයනු ලබන තේමා _පෙනුම > අගුළු ඇරීම_ යටතේ ලැයිස්තුගත වනු ඇත. ඔබේ `unlock.png` එක විනිවිද පෙනෙන png එකක් වීම වඩාත් සුදුසුය. තවද ඔබට `omarchy plymouth preview` භාවිතා කර පෙරදසුන් රූපය සෑදිය හැකිය.

### Omarchy ආවරණය නොකරන යෙදුම් තේමා කිරීම

ඔබ ඒ ලැයිස්තුවේ නැති යෙදුමක් භාවිතා කරන්නේ නම්, template එකක් සමඟ Omarchy හට එය තේමා කරන ආකාරය ඔබටම උගන්විය හැකිය. එය ජනනය කරන වින්‍යාසය අනුව නම් කරන ලද ගොනුවක් සහ `.tpl` දිගුවක් `~/.config/omarchy/themed/` තුළට දමන්න, සහ `{{ background }}`, `{{ foreground }}`, `{{ accent }}`, `{{ red }}`, `{{ color0 }}` සිට `{{ color15 }}` දක්වා සහ පුවරුවේ ඉතිරිය placeholders ලෙස භාවිතා කර වින්‍යාසය ලියන්න. ඔබ තේමා මාරු කරන සෑම අවස්ථාවකදීම, ගොනුව ඒ තේමාවේ වර්ණ සමඟ නැවත ජනනය කරනු ලැබේ.

පිටපත් කර ගැනීමට ඒ ෆෝල්ඩරයේ සම්පූර්ණයෙන්ම අදහස් දක්වා ඇති `alacritty.toml.tpl.sample` එකක් ඇත — එය ඔබට භාවිතා කළ හැකි සෑම විචල්‍යයක්ම ලැයිස්තුගත කරයි, ඊට අමතරව `#` නොමැතිව හෝ දශම RGB ලෙස තම වර්ණ අවශ්‍ය යෙදුම් සඳහා `_strip` සහ `_rgb` modifiers ද ඇත. ඔබේ templates වලට Omarchy හි ඒවාට වඩා ප්‍රමුඛතාවය ලැබේ, එබැවින් built-in යෙදුමක් තේමා කරන ආකාරය අභිබවා යාමටද ඔබට මෙය භාවිතා කළ හැකිය.

### ඔබේ තේමාව බෙදාහැරීම

ඔබේ තේමාව අන් අයට භාවිතා කළ හැකි වන පරිදි බෙදාහැරීමට ඔබට අවශ්‍ය නම්, ඔබ එය GitHub වැනි පොදු git server එකක තැබිය යුතුය. එවිට මිනිසුන්ට ඒ URL එක භාවිතා කර Omarchy මෙනුවේ _ස්ථාපනය > රටාව > තේමාව_ භාවිතයෙන් එය ස්ථාපනය කළ හැකිය. `omarchy-[themename]-theme` නම් කිරීමේ සම්මුතිය අනුගමනය කිරීම නිර්දේශ කෙරේ, මන්ද ස්ථාපනය කිරීමෙන් පසු තේමාව තේමා තේරීමේ මෙනුවේ හරියටම `[themename]` ලෙස පමණක් පෙන්වනු ඇත.

ඉතිරි වන ඒ `[themename]` එක තේමාවේ directory නාමය බවට පත්වේ, එබැවින් එය Omarchy හට ආරක්ෂිතව එහා මෙහා යැවිය හැකි එකක් විය යුතුය: එය අකුරකින්, ඉලක්කමකින් හෝ underscore එකකින් ආරම්භ විය යුතු අතර, ඉතිරියේ අකුරු, ඉලක්කම්, `.`, `_`, `+` සහ `-` අඩංගු විය හැකිය. ලොකු අකුරු ඔබ වෙනුවෙන් කුඩා අකුරු බවට පත් කරනු ලැබේ, නමුත් වෙනත් ඕනෑම දෙයක් — හිස්තැනක්, උද්ධෘත ලකුණක්, ඉංග්‍රීසි නොවන අක්ෂරයක් — directory නාමයක් බවට පත් කිරීම වෙනුවට ස්ථාපනය කරන අවස්ථාවේදීම ප්‍රතික්ෂේප කරනු ලැබේ. එබැවින් `omarchy-tokyo-night-theme`, `omarchy-flexoki_light-theme` සහ `omarchy-c++-theme` යන සියල්ල හොඳින් ස්ථාපනය වේ.

එය repo එකකින් ස්ථාපනය කළ පසු, එය සමඟ එන ඕනෑම `.lua`, terminal වින්‍යාසයක් හෝ `vscode.json` ඉවත් කරනු ලබන බව මතක තබා ගන්න, එබැවින් තේමාව ඒවා වටා ගොඩනඟන්න එපා.

[omarchy-site repo](https://github.com/omacom-io/omarchy-site) එකට pull request එකක් යැවීමෙන් ඔබට ඔබේ තේමාව [අමතර තේමා පිටුවට](https://omarchy.org/themes/) එක් කර ගත හැකිය.
