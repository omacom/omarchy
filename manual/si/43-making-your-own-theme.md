# ඔබේම තේමාවක් සෑදීම

ඔබට ඔබේම තේමා `~/.config/omarchy/themes` වෙත එක් කළ හැකිය. දැනට පවතින තේමාවක් පදනමක් ලෙස පිටපත් කර ගන්න ( `/usr/share/omarchy/themes` තුළ බලන්න), ඉන්පසු ඔබේ සතුටට අනුව එය වෙනස් කරන්න. ඔබේ තේමාව එම ෆෝල්ඩරය තුළ පවතින තාක් කල්, එය තේමා තේරීමේ මෙනුවට ඇතුළත් වනු ඇත.

ඔබ වෙනස් කළ යුතු ප්‍රධාන ගොනුව `colors.toml` ය. එය terminal එක (Foot/Alacritty/Ghostty/Kitty), btop, Chromium, Hyprland, Neovim, Helix, VSCode, Obsidian, සහ සම්පූර්ණ Omarchy shell එක (ඉහළ තීරුව, මෙනුව, දැනුම්දීම්, OSD, සහ අගුළු තිරය) සඳහා වින්‍යාස ජනනය කිරීමට පසුව භාවිත කරන වර්ණ කට්ටලය නිර්වචනය කරයි.

වර්ණ සමඟ සෙල්ලම් කිරීමට සහ පසුබිම් සෙවීමට ඇති අලංකාර GUI අතුරුමුහුණතක් භාවිත කර නව තේමාවක් සෑදීමට ඔබට ඇතුළත් කර ඇති Aether යෙදුමද භාවිත කළ හැකිය. `Super + Alt + Space` මත ඇති යෙදුම් ජාලයෙන් එය ආරම්භ කරන්න.

### ස්ථාපිත තේමාවක අඩංගු විය හැකි දේ

ඔබ විසින්ම `~/.config/omarchy/themes` තුළ ලියන තේමාවක ඔබට කැමති ඕනෑම දෙයක් අඩංගු විය හැකිය — එය ඔබේ යන්ත්‍රය සහ ඔබේ ගොනුව වන අතර, Omarchy ඒ සියල්ලම යොදයි.

ඔබ `omarchy theme install` සමඟ වෙනත් අයෙකුගේ repo එකකින් ස්ථාපනය කරන තේමාවක් වර්ණය වන සියල්ල රඳවා ගන්නා අතර, ඔබේ යන්ත්‍රයේ code ක්‍රියාත්මක කරන ගොනු අතලොස්ස අහිමි කර ගනී: ඕනෑම `.lua` ගොනුවක්, terminal වින්‍යාස (`alacritty.toml`, `foot.ini`, `ghostty.conf`, `kitty.conf`), සහ `vscode.json`. තේමාවක `hyprland.lua` යනු ඔබ පිවිසෙන විට ඔබේ compositor එක ක්‍රියාත්මක කරන Lua වන අතර, terminal වින්‍යාසයක් ඔබේ terminal එක ආරම්භ කරන වැඩසටහන නම් කරයි, සහ `vscode.json` ස්ථාපනය කළ යුතු VSCode දිගුවක් නම් කරයි. යමෙකුගේ තේමාවක් ස්ථාපනය කිරීම ඔබේ desktop එක පෙනෙන ආකාරය වෙනස් කළ යුතුය, එය ක්‍රියාත්මක කරන දේ කිසිවිටෙක නොවේ.

අනෙක් සියල්ල තේමා කතුවරයා ලියූ ආකාරයටම හරියටම ක්‍රියා කරයි — `btop.theme`, `chromium.theme`, `helix.toml`, `icons.theme`, `shell.toml`, පසුබිම් සහ පෙරදසුන් සියල්ලම රඳවා ගනු ලැබේ. ඉවත් කරන ලද දේ පමණක් ඔබේ යන්ත්‍රයේ `colors.toml` වෙතින් නැවත ජනනය කෙරේ.

Omarchy මේ දෙක වෙන්කර හඳුනා ගන්නේ තේමාවට එහි ඇතුළතම තමන්ගේම git repo එකක් තිබේද යන්න අනුවය, එය `omarchy theme install` එය clone කරන විට ඉතිරි කරන දෙයයි. එබැවින් ඔබ ලියූ තේමාවක් ඔබේම ලෙස පවතින අතර, ඔබ අන්තර්ජාලයෙන් ලබා ගත් එකක් වර්ණ ලෙස පවතී.

### Light mode

ඔබ light mode තේමාවක් සාදන්නේ නම්, ඔබේ `colors.toml` හි ඉහළින්ම `mode = "light"` ලෙස සකසන්න. එවිට එය සියලුම යෙදුම් සඳහා light mode සමඟ ස්වයංක්‍රීයව යුගලනය වනු ඇත. (ඔබේ තේමාවේ මූලයේ `light.mode` නමැති හිස් ගොනුවක් දැමීමේ පැරණි ක්‍රමයද තවමත් ක්‍රියා කරයි.)

### අයිකන වර්ණ

ඔබට ගොනු කළමනාකරුගේ අයිකන ඔබේ තේමාවට වර්ණයෙන් ගැළපීමට අවශ්‍ය නම්, ඔබට භාවිත කිරීමට අවශ්‍ය අයිකන කට්ටලයේ නම සමඟ `icons.theme` නමැති ගොනුවක් එක් කරන්න. පෙරනිමියෙන්, විකල්ප වන්නේ: `Yaru Yaru-blue Yaru-dark Yaru-magenta Yaru-olive Yaru-prussiangreen Yaru-purple Yaru-red Yaru-sage Yaru-wartybrown Yaru-yellow`.

### අගුළු හැරීමේ රූපය

`unlock.png` සහ `preview-unlock.png` රූප සමඟ සපයනු ලබන තේමා _පෙනුම > Unlock_ යටතේ ලැයිස්තුගත කෙරේ. ඔබේ `unlock.png` වඩාත් සුදුසු වන්නේ විනිවිද පෙනෙන png එකක් ලෙසය. තවද ඔබට `omarchy plymouth preview` භාවිත කර පෙරදසුන් රූපය සෑදිය හැකිය.

### Omarchy ආවරණය නොකරන යෙදුම් තේමා කිරීම

ඔබ එම ලැයිස්තුවේ නොමැති යෙදුමක් භාවිත කරන්නේ නම්, ඔබට template එකක් සමඟ එය තේමා කිරීමට Omarchy ට ඔබ විසින්ම උගන්විය හැකිය. එය ජනනය කරන වින්‍යාසය අනුව නම් කරන ලද සහ `.tpl` දිගුවක් ඇති ගොනුවක් `~/.config/omarchy/themed/` තුළ දමන්න, සහ `{{ background }}`, `{{ foreground }}`, `{{ accent }}`, `{{ red }}`, `{{ color0 }}` සිට `{{ color15 }}` දක්වා, සහ palette එකේ ඉතිරි කොටස ස්ථානධාරක ලෙස භාවිත කර වින්‍යාසය ලියන්න. ඔබ තේමා මාරු කරන සෑම විටම, ගොනුව එම තේමාවේ වර්ණ සමඟ නැවත ජනනය කෙරේ.

එතැනින් පිටපත් කර ගැනීමට එම ෆෝල්ඩරයේ සම්පූර්ණයෙන්ම විස්තර කර ඇති `alacritty.toml.tpl.sample` එකක් ඇත — එය ඔබට භාවිත කළ හැකි සෑම විචල්‍යයක්ම ලැයිස්තු කරන අතර, `#` නොමැතිව හෝ දශම RGB ලෙස තම වර්ණ අවශ්‍ය යෙදුම් සඳහා `_strip` සහ `_rgb` විකරණකාරකද ඇතුළත් කරයි. ඔබේ template Omarchy හි ඒවාට වඩා ප්‍රමුඛතාව ගනී, එබැවින් ඔබට මෙය built-in යෙදුමක් තේමා කරන ආකාරය අභිබවා යාමටද භාවිත කළ හැකිය.

### ඔබේ තේමාව බෙදා හැරීම

ඔබට ඔබේ තේමාව අන් අයට භාවිත කළ හැකි වන පරිදි බෙදා හැරීමට අවශ්‍ය නම්, ඔබ එය GitHub වැනි පොදු git server එකක තැබිය යුතුය. එවිට මිනිසුන්ට එම URL එක භාවිත කර Omarchy මෙනුවේ _ස්ථාපනය > විලාසය > තේමාව_ භාවිත කර එය ස්ථාපනය කළ හැකිය. තේමාව ස්ථාපනය කිරීමෙන් පසු තේමා තේරීමේ මෙනුවේ හුදෙක් `[themename]` ලෙස නිවැරදිව පෙන්වනු ඇති බැවින්, ඔබ `omarchy-[themename]-theme` නම් කිරීමේ සම්මුතිය අනුගමනය කිරීම නිර්දේශ කෙරේ.

එම ඉතිරි වන `[themename]` කොටස තේමාවේ නාමාවලි නාමය බවට පත්වේ, එබැවින් එය Omarchy ට ආරක්ෂිතව එහා මෙහා ගෙන යා හැකි එකක් විය යුතුය: එය අකුරකින්, ඉලක්කමකින්, හෝ යටි ඉරකින් ආරම්භ විය යුතු අතර, ඉතිරි කොටසේ අකුරු, ඉලක්කම්, `.`, `_`, `+`, සහ `-` අඩංගු විය හැකිය. කැපිටල් අකුරු ඔබ වෙනුවෙන් කුඩා අකුරු බවට පත් කෙරේ, නමුත් වෙනත් ඕනෑම දෙයක් — හිස්තැනක්, උද්ධෘත ලකුණක්, ඉංග්‍රීසි නොවන අක්ෂරයක් — නාමාවලි නාමයක් බවට පත් කරනවා වෙනුවට ස්ථාපනය කරන අවස්ථාවේදී ප්‍රතික්ෂේප කෙරේ. එබැවින් `omarchy-tokyo-night-theme`, `omarchy-flexoki_light-theme`, සහ `omarchy-c++-theme` යන සියල්ලම හොඳින් ස්ථාපනය වේ.

එය repo එකකින් ස්ථාපනය කළ පසු, එය සමඟ එවන ඕනෑම `.lua`, terminal වින්‍යාසයක් හෝ `vscode.json` ඉවත් කරනු ලබන බව මතක තබා ගන්න, එබැවින් තේමාව ඒවා වටා ගොඩනඟන්න එපා.
