# ඔබේම තේමාවක් සාදාගැනීම

ඔබට ඔබේම තේමා `~/.config/omarchy/themes` වෙත එක් කළ හැකිය. දැනට පවතින ඒවායින් එකක් පදනම ලෙස පිටපත් කරගන්න (`/usr/share/omarchy/themes` තුළ බලන්න), ඉන්පසුව ඔබේ සිත් ගත් පරිදි එය වෙනස් කරන්න. ඔබේ තේමාව එම ෆෝල්ඩරය තුළ පවතින තාක් කල්, එය තේමා තේරීමේ මෙනුවට ඇතුළත් වනු ඇත.

ඔබ වෙනස් කළ යුතු ප්‍රධාන ගොනුව `colors.toml` ය. එය, terminal එක (Foot/Alacritty/Ghostty/Kitty), btop, Chromium, Hyprland, Neovim, Helix, VSCode, Obsidian, Qt apps, යතුරුපුවරු පසුබිම් ආලෝකය, ආදාන ක්‍රමය, screen-share picker එක, app icons, AI tools කිහිපයක් (Claude, Pi, Hermes, T3 Code, Herdr), සහ මුළු Omarchy shell එකම (top bar එක, මෙනුව, දැනුම්දීම්, OSD, සහ lock screen එක) සඳහා වින්‍යාස ජනනය කිරීමට පසුව භාවිත කරන වර්ණ කට්ටලය අර්ථ දක්වයි.

වර්ණ සමඟ අත්හදා බැලීමට සහ පසුබිම් සෙවීමට ඇති අලංකාර GUI අතුරුමුහුණතක් භාවිතයෙන් නව තේමාවක් සෑදීමට, ඇතුළත් කර ඇති Aether application එකද ඔබට භාවිත කළ හැකිය. `Super + Alt + Space` මත ඇති app grid එකෙන් එය ආරම්භ කිරීම පමණක් ප්‍රමාණවත්ය.

### ස්ථාපනය කළ තේමාවක අඩංගු විය හැකි දෑ

`~/.config/omarchy/themes` තුළ ඔබ විසින්ම ලියන ලද තේමාවක ඔබට අවශ්‍ය ඕනෑම දෙයක් අඩංගු විය හැකිය — එය ඔබේ යන්ත්‍රය වන අතර ඔබේ ගොනුව වන අතර, Omarchy ඒ සියල්ලම ක්‍රියාත්මක කරයි.

`omarchy theme install` සමඟ වෙනත් පුද්ගලයෙකුගේ repo එකකින් ඔබ ස්ථාපනය කරන තේමාවක් වර්ණය වන සියල්ල රඳවා ගන්නා අතර, ඔබේ යන්ත්‍රය මත code ධාවනය කරන ගොනු ස්වල්පය අහිමි කරගනී: ඕනෑම `.lua` ගොනුවක්, terminal configs (`alacritty.toml`, `foot.ini`, `ghostty.conf`, `kitty.conf`), සහ `vscode.json`. තේමාවක `hyprland.lua` යනු ඔබ පුරනය වන විට ඔබේ compositor එක ධාවනය කරන Lua එකකි, terminal config එකක් ඔබේ terminal එක ආරම්භ කරන වැඩසටහන නම් කරයි, සහ `vscode.json` ස්ථාපනය කිරීමට VSCode extension එකක් නම් කරයි. කිසියම් පුද්ගලයෙකුගේ තේමාවක් ස්ථාපනය කිරීමෙන් ඔබේ desktop එක දිස්වන ආකාරය වෙනස් විය යුතුය, එය ධාවනය කරන දෑ කිසිවිටෙක නොවේ.

අනෙකුත් සියල්ල තවමත් තේමා කර්තෘ එය ලියා ඇති ආකාරයටම හරියටම ක්‍රියා කරයි — `btop.theme`, `chromium.theme`, `helix.toml`, `shell.toml`, පසුබිම් සහ පෙරදසුන් සියල්ල රඳවා ගනු ලැබේ. ඉවත් කරන ලද දෑ පමණක් ඔබේ යන්ත්‍රය මත `colors.toml` වෙතින් නැවත ජනනය කරනු ලැබේ.

Omarchy මෙම දෙක එකිනෙකින් වෙන්කර හඳුනාගන්නේ තේමාව තුළම එහිම git repo එකක් තිබේද යන්න මත වන අතර, එය `omarchy theme install` විසින් clone කරන විට ඉතිරි කරන දෑ වේ. එබැවින් ඔබ ලියූ තේමාවක් ඔබේම එකක් ලෙසම පවතින අතර, ඔබ අන්තර්ජාලයෙන් ලබාගත් එකක් වර්ණ පමණක් ලෙස පවතී.

### Light mode

ඔබ light mode තේමාවක් සාදන්නේ නම්, ඔබේ `colors.toml` හි ඉහළින්ම `mode = "light"` ලෙස සකසන්න. එවිට එය සියලුම apps සඳහා ස්වයංක්‍රීයව light mode සමඟ යුගල කරනු ලැබේ. (ඔබේ තේමාවේ මූලය තුළ `light.mode` නමින් හිස් ගොනුවක් දැමීමේ පැරණි ක්‍රමයද තවමත් ක්‍රියා කරයි.)

### Unlock රූපය

`unlock.png` සහ `preview-unlock.png` රූප සමඟ සපයන ලද තේමා _Appearance > Unlock_ යටතේ ලැයිස්තුගත කරනු ලැබේ. ඔබේ `unlock.png` එක වඩාත් සුදුසු වන්නේ විනිවිද පෙනෙන png එකක් වීමයි. තවද ඔබට `omarchy plymouth preview` භාවිතයෙන් පෙරදසුන් රූපය සෑදිය හැකිය.

### Omarchy ආවරණය නොකරන apps සඳහා තේමා යෙදීම

ඔබ එම ලැයිස්තුවේ නොමැති app එකක් භාවිත කරන්නේ නම්, template එකක් භාවිතයෙන් ඔබටම එය සඳහා තේමා යොදන ආකාරය Omarchy වෙත උගන්විය හැකිය. එය ජනනය කරන config එකේ නමින් නම් කළ, `.tpl` දිගුවක් සහිත ගොනුවක් `~/.config/omarchy/themed/` තුළට දමන්න, සහ `{{ background }}`, `{{ foreground }}`, `{{ accent }}`, `{{ red }}`, `{{ color0 }}` සිට `{{ color15 }}` දක්වා, සහ වර්ණ පුවරුවේ ඉතිරි කොටස placeholders ලෙස භාවිත කරමින් config එක ලියන්න. ඔබ සෑම අවස්ථාවකදීම තේමා මාරු කරන විට, එම ගොනුව එම තේමාවේ වර්ණ සමඟ නැවත ජනනය කරනු ලැබේ.

පිටපත් කරගැනීමට එම ෆෝල්ඩරය තුළ සම්පූර්ණයෙන්ම අදහස් දක්වා ඇති `alacritty.toml.tpl.sample` එකක් ඇත — එය ඔබට භාවිත කළ හැකි සෑම විචල්‍යයක්ම, ඊට අමතරව `#` නොමැතිව හෝ දශම RGB ලෙස තම වර්ණ අවශ්‍ය වන apps සඳහා වූ `_strip` සහ `_rgb` modifiers ද ලැයිස්තුගත කරයි. ඔබේ templates වලට Omarchy හිම ඒවාට වඩා ප්‍රමුඛත්වය ලැබේ, එබැවින් බිල්ට්-ඉන් app එකක් සඳහා තේමා යොදන ආකාරය අභිබවා යාමටද ඔබට මෙය භාවිත කළ හැකිය.

### ඔබේ තේමාව බෙදාහැරීම

ඔබේ තේමාව අන් අයට භාවිත කළ හැකි වන පරිදි බෙදාහැරීමට ඔබට අවශ්‍ය නම්, ඔබ එය GitHub වැනි පොදු git server එකක් මත තැබිය යුතුය. එවිට මිනිසුන්ට එම URL එක භාවිත කරමින් Omarchy මෙනුවේ _Install > Style > Theme_ භාවිතයෙන් එය ස්ථාපනය කළ හැකිය. `omarchy-[themename]-theme` යන නාමකරණ සම්මුතිය අනුගමනය කිරීම නිර්දේශ කරනු ලැබේ, මන්ද ස්ථාපනය කිරීමෙන් පසුව තේමාව, තේමා තේරීමේ මෙනුව තුළ හුදෙක් `[themename]` ලෙස නිවැරදිව පෙන්වනු ඇත.

ඉතිරි වන එම `[themename]` එක තේමාවේ directory නම බවට පත්වේ, එබැවින් එය Omarchy හට ආරක්ෂිතව හුවමාරු කළ හැකි එකක් විය යුතුය: එය අක්ෂරයකින්, ඉලක්කමකින්, හෝ underscore එකකින් ආරම්භ විය යුතු අතර, ඉතිරි කොටසේ අක්ෂර, ඉලක්කම්, `.`, `_`, `+`, සහ `-` පැවතිය හැකිය. ලොකු අකුරු ඔබ වෙනුවෙන් කුඩා අකුරු බවට පත් කරනු ලබන නමුත්, වෙනත් ඕනෑම දෙයක් — හිඩැසක්, උද්ධෘත ලකුණක්, ඉංග්‍රීසි නොවන අක්ෂරයක් — directory නමක් බවට පත් කිරීමට වෙනුවට ස්ථාපන අවස්ථාවේදීම ප්‍රතික්ෂේප කරනු ලැබේ. එබැවින් `omarchy-tokyo-night-theme`, `omarchy-flexoki_light-theme`, සහ `omarchy-c++-theme` යන සියල්ල කිසිදු ගැටළුවකින් තොරව ස්ථාපනය වේ.

මතක තබාගන්න, එය repo එකකින් ස්ථාපනය කළ පසු, එය සමඟ එන ඕනෑම `.lua`, terminal config එකක් හෝ `vscode.json` එකක් ඉවත් කරනු ලැබේ, එබැවින් එම දෑ වටා තේමාව ගොඩනගන්න එපා.

[omarchy-site repo එක](https://github.com/omacom-io/omarchy-site) වෙත pull request එකක් යැවීමෙන් ඔබට ඔබේ තේමාව [අමතර තේමා පිටුව](https://omarchy.org/themes/) වෙත එක් කරගැනීමට හැකිවනු ඇත.
