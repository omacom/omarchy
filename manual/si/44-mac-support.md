# Mac සහාය

Omarchy හි **Intel Macs** සඳහා බිල්ට්-ඉන් සහායක් ඇත. මේ මොහොතේ දන්නා සීමාවන් කිහිපයක් ඇත, නමුත් ඔබ ඒවා ගැන දැනුවත්ව සහ ඒවා සමඟ කමක් නැති තාක්; Omarchy පූරණය කිරීමෙන් ඔබට ඔබේ පැරණි Macs වලට නව ජීවයක් ලබා දිය හැකිය.

මෙම අවස්ථාවේ M-මාලාවේ Mac එකක ස්ථාපනය කිරීම කෙලින්ම සහාය නොදක්වන බව කරුණාවෙන් සලකන්න. මෙහි තත්ත්වය පිළිබඳ වැඩිදුර දැන ගැනීමට ඔබට අපගේ [Discord](https://discord.gg/tXFUdasqhY) හි #omarchy-on-other හි සොයා ගත හැකිය.

සරල පරීක්ෂණයකදී, Omarchy ස්ථාපනය කිරීමෙන් පමණක් 2019 MacBook Pro එකක 36% කාර්ය සාධන වාසි අත්කර ගැනීමට අපට හැකි විය.

### Mac හි Omarchy ස්ථාපනය කිරීම

Omarchy දැනට ස්ථාපනය කර ඇති **එකම** OS එක වීමට පමණක් සහාය දක්වයි. ස්ථාපනය අතරතුර, ධාවකය පිස දමනු ලබන අතර MacOS තවදුරටත් ආරම්භ කළ නොහැකි වනු ඇත.

ඔබ කැමති නම් පසුව Internet Recovery හරහා ඔබට එය තවමත් යළි පිහිටුවිය හැකිය.

මෙම කොටස සඳහා, ඔබ දැනටමත් [ආරම්භ කිරීම](02-getting-started.md) සමාලෝචනය කර ඔබේ USB ධාවකය සූදානම් කර ඇති බව අපි උපකල්පනය කරන්නෙමු. ඔබ එසේ කර නැතහොත් දැන් එය කරන්න.

#### Secure Boot අක්‍රිය කරන්න

ආරම්භ කළ හැකි USB එක මෙන්ම OS එක ද ආරම්භ කිරීමට Apple හි Secure Boot අක්‍රිය කිරීම අවශ්‍ය වේ. එය අක්‍රිය කිරීමට, පහත සඳහන් දෑ කරන්න:

1. ඔබේ Mac එක වසා දමන්න
2. එය ක්‍රියාත්මක කර _වහාම_ පූරණ තිරය දිස්වෙන තෙක් Command-R ඔබාගෙන සිටින්න
3. ඔබේ පරිශීලකයා තෝරා, අසන්නේ නම් ඔබේ මුරපදය ඇතුළත් කරන්න
4. ප්‍රතිසාධන තිරයට පැමිණි පසු, මෙනු තීරුවෙන් **Utilities > Startup Security Utility** තෝරන්න
5. සත්‍යාපනය කිරීමට අසන විට ඔබේ මුරපදය ඇතුළත් කරන්න
6. Secure Boot විකල්පවලින් "No Security" තෝරන්න
7. External Boot විකල්පවලින් "Allow booting from external or removable media" තෝරන්න

#### ස්ථාපනය ආරම්භ කරන්න

1. USB ධාවකය ඇතුළු කරන්න
2. ඔබේ Mac එක නැවත අරඹා ආරම්භක උපාංග තිරයක් දකින තෙක් _වහාම_ Option ඔබාගෙන සිටින්න
3. තැඹිලි EFI Boot උපාංගය තෝරන්න
4. [නිත්‍ය පරිදි ස්ථාපනය](02-getting-started.md) සමඟ ඉදිරියට යන්න

ස්ථාපකය Mac දෘඪාංග හඳුනා ගන්නා අතර අවශ්‍ය නිවැරදි කිරීම් ස්වයංක්‍රීයව යොදයි: Broadcom Wi-Fi ධාවක සහ ස්ථිරාංග, ඒවා අවශ්‍ය MacBook මාදිලිවල SPI යතුරුපුවරු ධාවකය, සහ එම මාදිලිම සඳහා NVMe අත්හිටුවීමේ නිවැරදි කිරීමක්.
