# Mac සහාය

Omarchy සතුව **Intel Macs** සඳහා බිල්ට්-ඉන් සහාය ඇත. මේ මොහොතේ දන්නා සීමාවන් කිහිපයක් ඇත, නමුත් ඔබ ඒවා ගැන දැනුවත්ව ඒවා සමඟ එකඟ නම්; Omarchy ස්ථාපනය කිරීමෙන් ඔබේ පැරණි Macs වලට අලුත් ජීවයක් ලබා දිය හැකිය.

M-series Mac එකක ස්ථාපනය කිරීම මේ අවස්ථාවේදී සෘජුවම සහාය නොදක්වන බව කරුණාකර සලකන්න. මේ පිළිබඳ තත්ත්වය ගැන වැඩි විස්තර අපගේ [Discord](https://discord.gg/tXFUdasqhY) හි #omarchy-on-other වෙතින් දැනගත හැකිය.

සරල පරීක්ෂණයකදී, Omarchy ස්ථාපනය කිරීමෙන් පමණක් 2019 MacBook Pro එකක 36% ක කාර්ය සාධන වාසියක් ලබා ගැනීමට අපට හැකි විය.

### Mac මත Omarchy ස්ථාපනය කිරීම

Omarchy දැනට සහාය දක්වන්නේ ස්ථාපනය කර ඇති **එකම** OS එක ලෙස සිටීමට පමණි. ස්ථාපනය අතරතුර, ධාවකය මකා දමනු ලබන අතර MacOS තවදුරටත් ආරම්භ කළ නොහැකි වනු ඇත.

ඔබ කැමති නම් පසුව Internet Recovery හරහා එය තවමත් ප්‍රතිසාධනය කළ හැකිය.

මෙම කොටස සඳහා, ඔබ දැනටමත් [ආරම්භ කිරීම](02-getting-started.md) සමාලෝචනය කර ඔබේ USB ධාවකය සූදානම් කර ඇති බව අපි උපකල්පනය කරමු. ඔබ එසේ කර නොමැති නම් දැන්ම ඉදිරියට ගොස් එය කරන්න.

#### Secure Boot අක්‍රිය කරන්න

ආරම්භ කළ හැකි USB එක මෙන්ම OS එකද ආරම්භ කිරීම සඳහා Apple's Secure Boot අක්‍රිය කිරීම අවශ්‍ය වේ. එය අක්‍රිය කිරීමට, පහත සඳහන් දෑ කරන්න:

1. ඔබේ Mac එක ක්‍රියා විරහිත කරන්න
2. එය ක්‍රියාත්මක කර, පැටවීමේ තිරය දිස්වන තුරු _වහාම_ Command-R ඔබාගෙන සිටින්න
3. ඔබේ පරිශීලකයා තෝරන්න, ඉල්ලුවහොත් ඔබේ මුරපදය ඇතුළත් කරන්න
4. ප්‍රතිසාධන තිරයට පැමිණි පසු, menubar එකෙන් **Utilities > Startup Security Utility** තෝරන්න
5. සත්‍යාපනය සඳහා ඉල්ලූ විට ඔබේ මුරපදය ඇතුළත් කරන්න
6. Secure Boot විකල්පවලින් "No Security" තෝරන්න
7. External Boot විකල්පවලින් "Allow booting from external or removable media" තෝරන්න

#### ස්ථාපනය ආරම්භ කරන්න

1. USB ධාවකය ඇතුළත් කරන්න
2. ඔබේ Mac එක නැවත ආරම්භ කර, ආරම්භක උපාංග තිරය දිස්වන තුරු _වහාම_ Option ඔබාගෙන සිටින්න
3. තැඹිලි පැහැති EFI Boot උපාංගය තෝරන්න
4. [සාමාන්‍ය ආකාරයට ස්ථාපනය](02-getting-started.md) සමඟ ඉදිරියට යන්න

ස්ථාපකය Mac දෘඪාංග හඳුනාගෙන අවශ්‍ය නිවැරදි කිරීම් ස්වයංක්‍රීයව යොදයි: Broadcom Wi-Fi ධාවක සහ ස්ථිරාංග, එය අවශ්‍ය MacBook මාදිලිවල SPI යතුරුපුවරු ධාවකය සහ එම මාදිලි සඳහාම වන NVMe අත්හිටුවීමේ නිවැරදි කිරීම.
