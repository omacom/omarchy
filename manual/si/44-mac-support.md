# Mac සහාය

## Apple Silicon සඳහා Omarchy

Apple Silicon සඳහා Omarchy යනු නිල Omacom විසඳුමක් වන අතර, Omarchy 4.5 සමඟ පළමුව නිකුත් විය. එය macOS අසල ස්ථාපනය වන අතර, ඔබේ Mac එක ආරම්භ වන විට ඔබ දෙක අතරින් තෝරා ගනී.

Omarchy Mac පිළිබඳ දැනුම්දීමක් ලැබුණාද? [Omarchy Mac වලින් පැමිණීම](#coming-from-omarchy-mac) වෙත යන්න.

එය මෙම Mac වල ධාවනය වේ:

| Mac | චිප්ස් |
| --- | --- |
| MacBook Air | M1, M2, M3 |
| MacBook Pro | M1, M1 Pro, M1 Max, M2, M2 Pro, M2 Max, M3, M3 Pro, M3 Max |
| MacBook Neo | A18 Pro |
| Mac mini | M1, M2, M2 Pro |
| Mac Studio | M1 Max, M1 Ultra, M2 Max, M2 Ultra |

M4 සහ ඊට නව Mac තවම සහාය නොදක්වයි. M4 සහාය edge channel එකේ පරීක්ෂා කරමින් පවතින අතර ඊළඟට පැමිණේ. ස්ථාපකය කිසිවක් වෙනස් කිරීමට පෙර ඔබේ Mac එක පරීක්ෂා කරයි.

M4 සහ ඊට නව ඒවා ඇතුළුව ඕනෑම Apple Silicon Mac එකක, [Try Omarchy](https://github.com/omacom/try-omarchy) සමඟ අතථ්‍ය යන්ත්‍රයක Omarchy ධාවනය කළ හැකිය.

### ඔබට අවශ්‍ය දේ

- macOS 15 Sequoia හෝ ඊට පසු, සහ පරිපාලක ගිණුමක්
- Omarchy සඳහා නිදහස් තැටි ඉඩ. ස්ථාපකය ප්‍රමාණයක් යෝජනා කරන අතර එය වෙනස් කිරීමට ඔබට ඉඩ දෙයි.
- ඔබේ Mac එකේ උපස්ථයක්, බලය, සහ අන්තර්ජාල සම්බන්ධතාවක්. ස්ථාපනය ගිගාබයිට් කිහිපයක් බාගත කරයි.

### ස්ථාපනය කිරීම

ඔබ macOS වලින් ස්ථාපනය කරයි. [Homebrew](https://brew.sh) සමඟ Omarchy Installer ස්ථාපනය කරන්න:

```sh
brew install omacom/mac/omarchy
```

නැතහොත් එහි [නිකුතු පිටුව](https://github.com/omacom/omarchy-mac-installer/releases) වෙතින් නවතම Omarchy Installer බාගත කර එය විවෘත කරන්න.

ස්ථාපකය ඔබේ Mac එක පරීක්ෂා කරයි, සැලැස්ම ඔබට පෙන්වයි, සහ macOS කොටස හැකිලීමෙන් Omarchy සඳහා ඉඩ සාදයි. macOS තැටියේ රැඳෙන අතර USB ධාවකයක් අවශ්‍ය නැත. පළමු අදියර අවසන් වූ විට, එය macOS Recovery තුළ සැකසීම අවසන් කිරීම හරහා ඔබව යොමු කරයි: වසා දමන්න, "Loading startup options" දිස්වන තුරු බල බොත්තම ඔබාගෙන සිටින්න, Omarchy තෝරන්න, සහ පියවර අනුගමනය කරන්න.

පළමු ආරම්භයේදී, Omarchy එහි තැටිය සංකේතනය කරන මුරපදයක් ඉල්ලා සිටියි. ප්‍රතිසාධන යතුරක් නැත: මුරපදය අමතක වුවහොත්, ඔබේ Omarchy ගොනු ප්‍රතිසාධනය කළ නොහැක.

පසුව Omarchy සහ macOS අතර මාරු වීමට, වසා දමන්න, ඉන්පසු ආරම්භක විකල්ප දිස්වන තුරු බල බොත්තම ඔබාගෙන සිට එක් එකක් තෝරන්න.

### Omarchy Mac වලින් පැමිණීම

Omarchy Mac දැන් Apple Silicon සඳහා Omarchy හි කොටසක් වන අතර, එය ධාවනය කළ සෑම Mac එකකටම සහාය දක්වයි. ඔබේ වත්මන් ස්ථාපනය දිගටම ධාවනය වන අතර, එහි පද්ධති පැකේජ තවමත් යාවත්කාලීන වන නමුත්, එයට තවදුරටත් Omarchy යාවත්කාලීන නොලැබේ. කාලසීමාවක් නැති අතර තිබෙන තැනම උත්ශ්‍රේණි කිරීමක් ද නැත: ඔබ උපස්ථ කරයි, පැරණි ස්ථාපනය ඉවත් කරයි, නැවුම්ව ස්ථාපනය කරයි, සහ ප්‍රතිසාධනය කරයි. 2 සිට 5 දක්වා පියවර macOS තුළ සිදුවන බැවින්, නැවත ආරම්භ කිරීමට පෙර මෙම පිටුව ඔබේ දුරකථනයේ විවෘත කරන්න.

1. **Omarchy වලින්, Mac එකෙන් පිටතට උපස්ථ කරන්න.** පැරණි ස්ථාපනය ඉවත් කිරීම එය මකා දමන අතර, macOS ට Omarchy තැටිය කියවිය නොහැක. SSH සහ GPG යතුරු, බ්‍රවුසර පැතිකඩවල් සහ තල්ලු නොකළ වැඩ ඇතුළුව ඔබේ මුල් ෆෝල්ඩරය බාහිර ධාවකයකට හෝ වෙනත් පරිගණකයකට පිටපත් කරන්න. `pacman -Qqe > ~/packages.txt` සමඟ ඔබේ පැකේජ ලැයිස්තුව සුරකින්න. ඉවත් කිරීම සහ ස්ථාපනය කිරීම යන දෙකම එහි තැටිය ප්‍රමාණය වෙනස් කරන බැවින් macOS ද උපස්ථ කරන්න.
2. **ඔබේ Mac එක macOS තුළ ආරම්භ කරන්න.** වසා දමන්න, ආරම්භක විකල්ප දිස්වන තුරු බල බොත්තම ඔබාගෙන සිටින්න, සහ macOS තෝරන්න.
3. **Omarchy Installer ස්ථාපනය කරන්න** [ස්ථාපනය කිරීම](#installing) හි පෙන්වා ඇති පරිදි.
4. **පැරණි ස්ථාපනය ඉවත් කරන්න.** Omarchy Installer විවෘත කර Installation > Remove Omarchy තෝරන්න. එය මකා දමන දේ පෙන්වන අතර ඉඩ macOS වෙත ආපසු ලබා දෙයි. එය ඔබේ ස්ථාපනය හඳුනා නොගන්නේ නම්, තැටිය වෙනස් නොකර නතර වේ. කොටස් අතින් මකා දැමීම වෙනුවට [Discord](https://discord.gg/tXFUdasqhY) හි උදව් ඉල්ලන්න, එය macOS මකා දැමිය හැක.
5. **Apple Silicon සඳහා Omarchy ස්ථාපනය කරන්න** ස්ථාපකය සමඟ.
6. **ඔබේ ගොනු ප්‍රතිසාධනය කරන්න.** පැරණි සිටුවම් නව පෙරනිමි අභිබවා යා හැකි බැවින්, `~/.config` සියල්ල නව පෙරනිමි මත පිටපත් කිරීම වෙනුවට ඔබේ සිටුවම් වරකට කොටස බැගින් ආපසු ගෙන එන්න.

### Mac මත Omarchy ස්ථාපනය කිරීම

Omarchy දැනට සහාය දක්වන්නේ ස්ථාපනය කළ **එකම** OS එක වීමට පමණි. ස්ථාපනය අතරතුර, ධාවකය පිසදාමනු ලබන අතර MacOS තවදුරටත් ආරම්භ කළ නොහැකි වනු ඇත.

ඔබ කැමති නම් පසුව Internet Recovery හරහා එය තවමත් ප්‍රතිසාධනය කළ හැකිය.

මෙම කොටස සඳහා, ඔබ දැනටමත් [ආරම්භ කිරීම](02-getting-started.md) සමාලෝචනය කර ඔබේ USB ධාවකය සූදානම් කර ඇති බව අපි උපකල්පනය කරන්නෙමු. නැත්නම් ඉදිරියට ගොස් දැන් එය කරන්න.

#### Secure Boot අක්‍රිය කරන්න

ආරම්භ කළ හැකි USB එක මෙන්ම OS එක ආරම්භ කිරීම සඳහා Apple හි Secure Boot අක්‍රිය කිරීම අවශ්‍ය වේ. එය අක්‍රිය කිරීමට, පහත දෑ කරන්න:

1. ඔබේ Mac එක ක්‍රියා විරහිත කරන්න
2. එය ක්‍රියාත්මක කර පැටවීමේ තිරය දිස්වන තුරු _වහාම_ Command-R ඔබාගෙන සිටින්න
3. ඔබේ පරිශීලකයා තෝරන්න සහ අසන්නේ නම් ඔබේ මුරපදය ඇතුළත් කරන්න
4. ප්‍රතිසාධන තිරයට පැමිණි පසු, මෙනු තීරුවෙන් **Utilities > Startup Security Utility** තෝරන්න
5. සත්‍යාපනය සඳහා අසන විට ඔබේ මුරපදය ඇතුළත් කරන්න
6. Secure Boot විකල්ප වලින් "No Security" තෝරන්න
7. External Boot විකල්ප වලින් "Allow booting from external or removable media" තෝරන්න

#### ස්ථාපනය ආරම්භ කරන්න

1. USB ධාවකය ඇතුළත් කරන්න
2. ඔබේ Mac එක නැවත ආරම්භ කර ආරම්භක උපාංග තිරයක් දිස්වන තුරු _වහාම_ Option ඔබාගෙන සිටින්න
3. තැඹිලි EFI Boot උපාංගය තෝරන්න
4. [සාමාන්‍ය පරිදි ස්ථාපනය](02-getting-started.md) සමඟ ඉදිරියට යන්න

ස්ථාපකය Mac දෘඩාංග හඳුනාගෙන අවශ්‍ය නිවැරදි කිරීම් ස්වයංක්‍රීයව යොදයි: Broadcom Wi-Fi ධාවක සහ ස්ථිරාංග, Broadcom 1570 ඇති යන්ත්‍රවල FaceTime HD කැමරා ධාවකය (ස්ථාපකය නොබැඳිව ක්‍රියා කරන බැවින්, එහි ස්ථිරාංග Mac එක මාර්ගගත වූ පසු Apple වෙතින් බාගත කරයි), එය අවශ්‍ය MacBook මාදිලිවල SPI යතුරුපුවරු ධාවකය, සහ එම මාදිලි සඳහාම NVMe අත්හිටුවීමේ නිවැරදි කිරීම.

### දන්නා සීමාවන්

ප්‍රජාවේ සාමාජිකයින් මෙම අභියෝග සඳහා විසඳුම් වෙනුවෙන් නිරන්තරයෙන් වැඩ කරමින් සිටින බැවින් මේවා ඔබට ගැටලුකාරී නම්, අපගේ [Discord](https://discord.gg/tXFUdasqhY) හි #omarchy-on-other හා සම්බන්ධ වී මේවා විසඳීම සඳහා යාවත්කාලීන ක්‍රම තිබේදැයි බලන්න.

#### FaceTime HD Camera

Mac එක ශිශිරතාරණය වන විට කැමරා ධාවකය පැටවී තිබේ නම් එය යන්ත්‍රය හිර කරයි, එබැවින් එය පළමුව ඉවත් කරයි. යෙදුමක් කැමරාව විවෘත කර තිබියදී එය ඉවත් කළ නොහැක, එබැවින් යෙදුම නම් කරන දැනුම්දීමක් සමඟ ශිශිරතාරණය අවලංගු කරයි: එය වසා නැවත ශිශිරතාරණය කරන්න. එයට බැටරිය අතිශය අඩු විට ස්වයංක්‍රීයව ශිශිරතාරණය වීම, සහ අත්හිටුවීමට පෙර ප්‍රතික්ෂේප කරන අත්හිටුවා-ඉන්පසු-ශිශිරතාරණය ඇතුළත් වේ. කැමරාව විවෘතව තිබියදී සාමාන්‍ය අත්හිටුවීම දැනුම්දීමක් නොමැතිව ධාවකය විසින්ම ප්‍රතික්ෂේප කරයි.

කැමරාවේ ස්ථිරාංග Apple වෙතින් බාගත කරන බැවින්, Mac එක මාර්ගගත වූ පසු පමණක් කැමරාව ක්‍රියා කරයි. බාගත කිරීම ආරම්භයේදී පටන් ගන්නා අතර ජාලය ගැටලුව පවතින අතරතුර සෑම මිනිත්තු 15 කට වරක් නැවත උත්සාහ කරයි; Apple හි ගොනුව වෙනස් වී ඇත්නම්, එය නතර වී Omarchy යාවත්කාලීනයක් එනතෙක් බලා සිටියි. කැමරාව දිස් නොවන්නේ නම්, `journalctl -u facetimehd-firmware-fetcher` හේතුව පවසයි, `sudo systemctl restart facetimehd-firmware-fetcher` නැවත උත්සාහ කරයි, සහ බාගත කිරීම අවසන් වී නමුත් කැමරාව තවමත් නොමැති නම් නැවත ආරම්භ කිරීම ධාවකය පටවයි.

- MacBook Pro අඟල් 13 (2016, Thunderbolt 3 ports හතරක්) – මාදිලිය: A1708
