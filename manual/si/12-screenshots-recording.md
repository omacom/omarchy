# තිරපිටපත් සහ පටිගත කිරීම

තිරයෙන් ලබා ගත හැකි සෑම දෙයක්ම Print Screen යතුර මත රඳා පවතී. යතුර තනිවම එබූ විට පින්තූරයක් ගන්නා අතර, වෙනස්කාරක යතුරු සමඟ එබූ විට පටිගත කිරීමක්, වර්ණයක් හෝ කලාපයක් තුළ ඇති පෙළ ලබා ගනී. ඔබේ යතුරු පුවරුවේ Print Screen යතුරක් කිසිසේත් නොමැති නම්, `Super + Ctrl + Alt + C` එම තිරපිටපතම ගන්නා අතර, `Super + Ctrl + C` මුළු කට්ටලයම මෙනුවක් ලෙස විවෘත කරයි.

| ------ | -------- |
| `Print Screen` | තිරපිටපත |
| `Super + Ctrl + Alt + C` | තිරපිටපත |
| `Alt + Print Screen` | තිර පටිගත කිරීම (හෝ දැනට ක්‍රියාත්මක වන එක නවත්වන්න) |
| `Super + Print Screen` | වර්ණ තෝරකය |
| `Super + Ctrl + Print Screen` | කලාපයකින් පෙළ උපුටා ගන්න |
| `Super + Ctrl + C` | ග්‍රහණ මෙනුව |

## තිරපිටපත්

`Print Screen` (හෝ `Super + Ctrl + Alt + C`) ඔබන්න, එවිට Omasnap එහි උඩැතිරි තට්ටුව දිස්වීමට පෙර අවධානය යොමු වූ මොනිටරය ග්‍රහණය කරයි, එබැවින් ඔබ ඉලක්ක කරන අතරතුර කිසිවක් ඔබ යටින් මාරු නොවේ. නිදහස් හැඩයකින් යුත් කලාපයක් අදින්න, කවුළුවක් ග්‍රහණය කිරීමට එය ක්ලික් කරන්න, නැතහොත් මුළු මොනිටරයම ග්‍රහණය කිරීමට විවෘත ඉඩක් ක්ලික් කරන්න. අඳීමට පෙර `S` ඔබා අනුචලනය වන කලාපයක් ග්‍රහණය කරන්න. අදහස වෙනස් වුණාද? Omasnap ඉවත් කිරීමට එම යතුරම නැවත ඔබන්න.

ඔබ ප්‍රදේශයක් තෝරාගත් පසු, Omasnap ග්‍රහණය සුරකින අතර, එය පසුරු පුවරුවට පිටපත් කරන අතර, සුරකින ලද තිර පටිගත කිරීමක් කරන ආකාරයටම එහි කුඩා රූපය සමඟ දැනුම්දීමක් පෙන්වයි. සුරකින ලද දසුන ඔබේ රූප නරඹනයේ විවෘත කිරීමට Open තෝරන්න, නැතහොත් එය සලකුණු කිරීමට Edit තෝරන්න.

සලකුණු සංස්කාරකයට ඊතල, රේඛා, හැඩ, උද්දීපනයන්, අංකිත සලකුණු, පෙළ සහ ආරක්ෂිත අඳුරු කිරීම් ඇඳිය හැකිය; රූපයේ කොටසක් කපා හැරීමට හෝ කපා ඉවත් කිරීමට හැකිය; එහි පෙළ OCR කළ හැකිය; සහ පසුබිමක් එක් කළ හැකිය. සංස්කාරකය තුළ, අවසන් කළ PNG එක පිටපත් කර සුරැකීමට `Enter` ඔබන්න, සුරැකීමකින් තොරව පිටපත් කිරීමට `Ctrl + C` ඔබන්න, නැතහොත් පිටපත් කිරීමකින් තොරව සුරැකීමට `Ctrl + S` ඔබන්න.

සුරකින ලද තිරපිටපත් පෙරනිමියෙන් `~/Pictures/Screenshots` තුළට යන අතර, `screenshot-2026-08-13_14-22-05-firefox.png` වැනි නමක් ලැබේ. වෙනත් නාමාවලියක් භාවිතා කිරීමට `OMASNAP_SCREENSHOT_DIR` සකසන්න — සැසි පරිසර විචල්‍යයන් තැබිය යුත්තේ කොතැනද යන්න සඳහා [නිති අසන පැනයන්](46-faq.md) බලන්න. Omasnap පළමු දසුන සුරකින විට නාමාවලිය සාදයි. ස්වයංක්‍රීය සුරැකීම අක්‍රිය කිරීමට `~/.config/omasnap/omasnap.conf` තුළ `[output] autosave = false` සකසන්න; එවිට ග්‍රහණයන් පිටපත් කිරීම පමණක් සිදු වන අතර, තත්පර 10ක් පෙරදසුනක පෙන්වනු ලබන අතර, එහි pin බොත්තමෙන් හෝ `Ctrl + P` මඟින් එය තිරයේ රඳවා තබා ගත හැකිය.

පර්යන්තයෙන්, `omarchy screenshot` එම උඩැතිරි තට්ටුවම විවෘත කරන අතර, ඔබට එහි ආරම්භක ප්‍රකාරය තෝරා ගත හැකිය: `omarchy capture screenshot region`, `windows`, `fullscreen`, හෝ `scroll`. `copy` හෝ `save` යන දෙවැනි තර්කය මඟින් දසුන කෙලින්ම එම ගමනාන්තයට යවයි. ප්‍රතිදානයට පෙර සංස්කරණය කිරීමට, පූර්ණ තිර සංස්කාරකයක් සඳහා `omarchy screenshot --editor=overlay` හෝ වෙනම කවුළුවක් සඳහා `omarchy screenshot --editor=window` භාවිතා කරන්න.

### යතුරු පුවරුවෙන් තෝරකය මෙහෙයවීම

තේරීම දිස්වන අතරතුර, ඔබට මූසිකය කිසිසේත් භාවිතා කිරීමට අවශ්‍ය නැත:

| යතුර | කාර්යය |
| --- | -------- |
| `S` | අනුචලනය වන කලාප ප්‍රකාරය මාරු කරන්න |
| `Super + Arrow keys` | Window ප්‍රකාරයේ කවුළු අතර ගමන් කරන්න |
| `Return` | උද්දීපනය වූ කවුළුව ග්‍රහණය කරන්න |
| `Ctrl + A` | අවධානය යොමු වූ මුළු මොනිටරයම ග්‍රහණය කරන්න |
| `R` | මෙම සැසියේ අවසන් වරට ඇඳි කලාපය ප්‍රතිසාධනය කරන්න |
| `Esc` | Omasnap ඉවත් කරන්න |

මෙම බැඳීම් පවතින්නේ Omasnap විවෘතව ඇති අතරතුර පමණි, එබැවින් ඒවාට ඔබේම වින්‍යාසයේ කිසිවක් සමඟ ගැටිය නොහැකිය.

## තිර පටිගත කිරීම

`Alt + Print Screen` මඟින් _Trigger > Capture > Screenrecord_ විවෘත වන අතර, එය ශබ්ද පටයේ ඔබට අවශ්‍ය කුමක්දැයි අසයි: ශ්‍රව්‍යය නැත, මේස පරිගණක ශ්‍රව්‍යය, මේස පරිගණකය සහ මයික්‍රෆෝනය, හෝ මේස පරිගණකය සහ මයික්‍රෆෝනය සහ වෙබ් කැමරාව. ඔබට සැබවින්ම කැමරාවක් සම්බන්ධ කර ඇත්නම් පමණක් එම අවසන් එක දිස්වේ. එකක් තෝරන්න, එවිට Omarchy හි පටිගත කිරීමේ තෝරකය මඟින් ඔබට කලාපයක් ඇඳීමට හෝ කවුළුවක් හෝ මොනිටරයක් ක්ලික් කිරීමට ඉඩ දෙයි.
