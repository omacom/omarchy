# තිරපිටපත් සහ පටිගත කිරීම

තිරයෙන් ග්‍රහණය කරගත හැකි සියල්ලම Print Screen යතුර මත රඳා පවතී. යතුර තනිවම එබූ විට පින්තූරයක් ගනී, modifier සමඟ එබූ විට පටිගතකිරීමක්, වර්ණයක්, හෝ ප්‍රදේශයක් තුළ ඇති පෙළ ලබාගනී. ඔබේ යතුරුපුවරුවේ Print Screen යතුරක් කොහොමටත් නැත්නම්, `Super + Ctrl + Alt + C` එම තිරපිටපතම ගනී, `Super + Ctrl + C` මුළු කට්ටලයම මෙනුවක් ලෙස විවෘත කරයි.

| කෙටිමං යතුර | කාර්යය |
| ------ | -------- |
| `Print Screen` | තිරපිටපත |
| `Super + Ctrl + Alt + C` | තිරපිටපත |

| `Super + Print Screen` | වර්ණ තෝරනය |
| `Super + Ctrl + Print Screen` | ප්‍රදේශයකින් පෙළ උපුටා ගන්න |

## තිරපිටපත්

`Print Screen` (හෝ `Super + Ctrl + Alt + C`) ඔබන්න, එවිට Omasnap එහි overlay එක දිස්වීමට පෙර අවධානය යොමු වූ මොනිටරය ග්‍රහණය කරයි, ඒ නිසා ඔබ ඉලක්ක කරන අතර කිසිවක් ඔබ යටින් මාරු නොවේ. නිදහස් හැඩයක ප්‍රදේශයක් අඳින්න, කවුළුවක් ග්‍රහණය කිරීමට එය ක්ලික් කරන්න, හෝ මුළු මොනිටරයම ග්‍රහණය කිරීමට විවෘත අවකාශය ක්ලික් කරන්න. අඳීමට පෙර `S` ඔබා scrolling ප්‍රදේශයක් ග්‍රහණය කරන්න. හිත වෙනස් වුණාද? Omasnap ඉවත දැමීමට එම යතුරම නැවත ඔබන්න.

ඔබ ප්‍රදේශයක් තේරූ පසු, Omasnap ග්‍රහණය සුරකියි, එය clipboard එකට පිටපත් කරයි, සහ සුරකින ලද තිර පටිගතකිරීමක් කරන ආකාරයටම එහි thumbnail එක සමඟ දැනුම්දීමක් පෙන්වයි. සුරකින ලද ඡායාරූපය ඔබේ image viewer එකෙන් බැලීමට Open තෝරන්න, හෝ එය annotate කිරීමට Edit තෝරන්න.

annotation editor එකට ඊතල, රේඛා, හැඩ, highlights, අංකිත සලකුණු, පෙළ, සහ ආරක්ෂිත redactions ඇඳිය හැකිය; රූපයේ කොටසක් crop කිරීමට හෝ කපා ඉවත් කිරීමට; එහි පෙළ OCR කිරීමට; සහ backdrop එකක් එක් කිරීමට හැකිය. editor එක තුළ, අවසන් PNG එක පිටපත් කර සුරැකීමට `Enter` ඔබන්න, සුරැකීමෙන් තොරව පිටපත් කිරීමට `Ctrl + C` ඔබන්න, හෝ පිටපත් කිරීමෙන් තොරව සුරැකීමට `Ctrl + S` ඔබන්න.

සුරකින ලද තිරපිටපත් පෙරනිමියෙන් `~/Pictures/Screenshots` වෙත යයි, `screenshot-2026-08-13_14-22-05-firefox.png` වැනි නමකින්. වෙනත් directory එකක් භාවිතා කිරීමට `OMASNAP_SCREENSHOT_DIR` සකසන්න — session environment variables තැබිය යුතු තැන සඳහා [නිතර අසන ප්‍රශ්න](46-faq.md) බලන්න. Omasnap පළමු ඡායාරූපය සුරකින විට directory එක නිර්මාණය කරයි. ස්වයංක්‍රීය සුරැකීම අක්‍රිය කිරීමට `~/.config/omasnap/omasnap.conf` හි `[output] autosave = false` සකසන්න; එවිට ග්‍රහණයන් පිටපත් කරනු ලබන්නේ පමණක් වන අතර, තත්පර 7ක් පෙන්වන preview එකක පෙන්වනු ලැබේ, එහි pin බොත්තමෙන් හෝ `Ctrl + P` වලින් එය තිරයේ රඳවා තබාගත හැකිය.

terminal එකෙන්, `omarchy screenshot` එම overlay එකම විවෘත කරයි, ඔබට එහි ආරම්භක mode එක තෝරාගත හැකිය: `omarchy capture screenshot region`, `windows`, `fullscreen`, හෝ `scroll`. `copy` හෝ `save` යන දෙවන argument එක ඡායාරූපය කෙළින්ම එම ගමනාන්තයට යවයි. ප්‍රතිදානයට පෙර edit කිරීමට, fullscreen editor එකක් සඳහා `omarchy screenshot --editor=overlay` හෝ වෙනම කවුළුවක් සඳහා `omarchy screenshot --editor=window` භාවිතා කරන්න.

### යතුරුපුවරුවෙන් picker එක මෙහෙයවීම

selection එක ක්‍රියාත්මකව ඇති අතරතුර, ඔබට මූසිකය කොහොමටත් භාවිතා කිරීමට අවශ්‍ය නැත:

| Key | කාර්යය |
| --- | -------- |
| `S` | scrolling-region mode එක මාරු කරන්න |
| `Super + Arrow keys` | Window mode එකේ කවුළු අතර ගමන් කරන්න |
| `Return` | උද්දීපනය වූ කවුළුව ග්‍රහණය කරන්න |
| `Ctrl + A` | සම්පූර්ණ අවධානය යොමු වූ මොනිටරය ග්‍රහණය කරන්න |
| `R` | මෙම session එකේ අවසානයට ඇඳි ප්‍රදේශය ප්‍රතිස්ථාපනය කරන්න |
| `Esc` | Omasnap ඉවත දමන්න |

මෙම bindings පවතින්නේ Omasnap විවෘතව ඇති අතරතුර පමණක් වන බැවින්, ඒවා ඔබේම config එකේ කිසිවක් සමඟ ගැටිය නොහැකිය.

## තිර පටිගත කිරීම

`Alt + Print Screen` _Trigger > Capture > Screenrecord_ විවෘත කරයි, එය soundtrack එකේ ඔබට අවශ්‍ය කුමක්දැයි අසයි: ශ්‍රව්‍ය නැත, desktop ශ්‍රව්‍ය, desktop සහ microphone, හෝ desktop සහ microphone සහ webcam. එම අවසාන එක දිස්වන්නේ ඔබට ඇත්තටම camera එකක් සම්බන්ධ කර ඇත්නම් පමණි. එකක් තෝරන්න, එවිට Omarchy හි recording picker එක ඔබට ප්‍රදේශයක් ඇඳීමට හෝ කවුළුවක් හෝ මොනිටරයක් ක්ලික් කිරීමට ඉඩ දෙයි.

පටිගත කිරීම gpu-screen-recorder මත ධාවනය වේ, එය GPU එක මත 60fps වලින් encode කරයි, අවශ්‍ය වුවහොත් CPU එකට ආපසු යයි; Apple Silicon වැනි එය සහාය නොදක්වන GPUs මත, Omarchy ඒ වෙනුවට wf-recorder සමඟ පටිගත කරයි. ප්‍රතිඵලය `~/Videos` හි MP4 එකක් වන අතර, එය `screenrecording-2026-08-13_14-22-05.mp4` ලෙස නම් කරනු ලැබේ. එය වෙනස් කිරීමට `OMARCHY_SCREENRECORD_DIR` සකසන්න — නමුත් screenshot directory එක මෙන් නොව, මෙම එක දැනටමත් පැවතිය යුතු බව සලකන්න, නැත්නම් පටිගත කිරීම ආරම්භ වීම ප්‍රතික්ෂේප කරයි.

ඔබ පටිගත කරන අතරතුර, bar එකේ කුඩා දර්ශකයක් දිස් වේ. එය නැවැත්වීමට එය ක්ලික් කරන්න. ඔබට `Alt + Print Screen` නැවත එබීමෙන් හෝ _Trigger > Capture > Screenrecord_ යට ඇති _Stop Screenrecording_ ප්‍රවේශයෙන්ද නැවැත්විය හැකිය, එය දිස්වන්නේ යමක් ඇත්තටම පටිගත වෙමින් පවතින අතරතුර පමණි.
