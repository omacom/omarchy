# පද්ධති නිද්‍රාව

Omarchy පෙරනිමියෙන් අත්හිටුවීම සක්‍රිය කරන අතර, එය සකසා ගත් පසු ශිශිරතද්‍යාවද සක්‍රිය කරයි, නමුත් ඔබේ යන්ත්‍රයේ ඒ දෙකෙන් ඕනෑම එකක් සමඟ ගැටලු ඇත්නම්, ඔබට ඒවා අක්‍රිය කළ හැකිය.

NVIDIA GB10 යන්ත්‍රවල, එනම් DGX Spark සහ ASUS Ascent GX10 වැනි යන්ත්‍රවල, NVIDIA හි DGX OS හි මෙන්ම අත්හිටුවීම සහ ශිශිරතද්‍යාව අක්‍රිය කර ඇත, මන්ද එම දෘඩාංග මත නිද්‍රාව ක්‍රියා කරන බව තවමත් පෙන්වා දී නොමැති බැවිනි. අත්හිටුවීමෙන් තවමත් චිපය සම්පූර්ණයෙන්ම නිද්‍රාවට පත් නොවන අතර රාත්‍රිය පුරා එල්ලා වැටිය හැකි ASUS Zenbook A16 (UX3607OA) සඳහාද එය එසේම වේ. අත්හිටුවීම සක්‍රිය/අක්‍රිය කිරීම සහ ශිශිරතද්‍යා සැකසුම එහි අදාළ නොවේ. නිද්‍රාව නැවත සක්‍රිය කිරීමට, `sudo rm` සමඟ `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf` ඉවත් කරන්න; එවිට අත්හිටුවීම මෙනුවට නැවත පැමිණෙන අතර, අනෙකුත් යන්ත්‍රවල මෙන්ම ශිශිරතද්‍යාවද සකසා ගත හැකිය. `sudo omarchy apply hardware --install-user "$USER"` ධාවනය කිරීමෙන් ගොනුව නැවත තබනු ලැබේ.

### බල පැතිකඩ

ලැප්ටොප් එකක, Omarchy ඔබේ බල පැතිකඩ ප්ලග් කර ඇති විට සහ බැටරියෙන් ක්‍රියාත්මක වන විට සඳහා වෙන වෙනම මතක තබා ගන්නා අතර, ඔබ ප්ලග් කරන විට සහ ගලවන විට ඒ දෙක අතර මාරු වේ. ආරම්භයේදීම එයින් අදහස් වන්නේ AC මත performance සහ බැටරිය මත balanced යන්නයි.

ඔබේ යන්ත්‍රය ලබා දෙන්නේ මොනවාදැයි ඔබට `omarchy powerprofiles list` සමඟ බලා ගත හැකි අතර, ඔබ දැනට සිටින තත්ත්වය සඳහා ඔබට අවශ්‍ය එක `omarchy powerprofiles set autodetect power-saver` සමඟ සැකසිය හැකිය. කිසිවක් ගලවන්නේ නැතිව අනෙක් තත්ත්වය සැකසීමට, එය කෙලින්ම නම් කරන්න: `omarchy powerprofiles set battery power-saver`. ඔබ තෝරන ඕනෑම දෙයක්, ඊළඟ වතාවේ ඔබ එම තත්ත්වයේ සිටින විට ඔබට නැවත ලැබෙනු ඇත.

### අත්හිටුවීම සක්‍රිය/අක්‍රිය කිරීම

ඔබ terminal එකෙන් `omarchy toggle suspend` ධාවනය කිරීමෙන් අත්හිටුවීම සක්‍රිය/අක්‍රිය කරයි. එය _පද්ධතිය_ (හෝ `Super + Esc`) යටතේ ඇති විකල්පය හුදෙක් පෙන්වයි/සඟවයි, එවිට එය ඔබේ පද්ධතියේ අඛණ්ඩව ක්‍රියා කරයිදැයි ඔබට බලා ගත හැකිය. එසේ නොවේ නම්, එම විධානයම සමඟ ඔබට එය නැවත සැඟවිය හැකිය.

### ශිශිරතද්‍යාව සක්‍රිය/අක්‍රිය කිරීම

ඔබ terminal එකෙන් `omarchy hibernation setup` ධාවනය කිරීමෙන් ශිශිරතද්‍යාව සකසා ගනී (එය Apple Silicon Macs මත ලබා ගත නොහැක). ශිශිරතද්‍යාව ඔබේ භෞතික RAM වෙන් කිරීමේ ප්‍රමාණයට ඔබේ boot drive එකේ /swap උප-වොලියුමයක් සාදයි, එබැවින් ඔබට ඉතිරි කිරීමට ඕනෑ තරම් ඉඩ ඇති බවට වග බලා ගන්න. 32GB යන්ත්‍රයක, මෙම වොලියුමය සඳහා ඔබට සැමවිටම 32GB+ ක් නිදහස්ව තිබිය යුතුය. ශිශිරතද්‍යාව සඳහා පෙරනිමි Limine bootloader එකද අවශ්‍ය වේ.

සකසා ගත් පසු, ඔබට _පද්ධතිය_ (හෝ `Super + Esc`) යටතේ ශිශිරතද්‍යා විකල්පය පෙනෙනු ඇත, එවිට එය ඔබේ පද්ධතියේ අඛණ්ඩව ක්‍රියා කරයිදැයි ඔබට බලා ගත හැකිය. එසේ නොවේ නම්, `omarchy hibernation remove` ධාවනය කිරීමෙන් ඔබට එය නැවත ඉවත් කළ හැකිය.
