# බ්‍රවුසර්

Omarchy සමඟ පෙරනිමි බ්‍රවුසරය ලෙස [Google Chrome](https://www.google.com/chrome/) ලැබේ. එය ඔබේ පද්ධතියේ ඉතිරි කොටසට ගැලපෙන පරිදි තේමා කර ඇති අතර, `Super + Shift + Return` (හෝ `Super + Shift + B`) මඟින් විවෘත වන්නේ එය වන අතර, `Super + Shift + Alt + B` මඟින් පුද්ගලික කවුළුවක් සඳහා වන අතර, සෑම [වෙබ් යෙදුමක්ම](25-web-apps.md) ධාවනය වන්නේද එය තුළය. එය කෙලින්ම බ්‍රවුසර් කවුළුවකට විවෘත වේ: පිළිගැනීමේ තිරයක් හෝ පුරනය වීමේ විමසුමක් නැත, භාවිත සංඛ්‍යාලේඛන සහ බිඳ වැටීම් වාර්තා Google වෙත යවනු නොලැබේ, සහ දැන්වීම් රහස්‍යතා විමසුම් අක්‍රිය කර ඇත. Sync කිරීමට අවශ්‍ය ඕනෑම වේලාවක profile බොත්තමෙන් ඔබට තවමත් ඔබේ Google ගිණුමට පුරනය විය හැක.

Chrome ඔබේ සිත් ගත්තේ නැත්නම්, ඔබට එය සමඟ සිරවී සිටීමට සිදු නොවේ. Omarchy මෙනුවේ _Install > Browser_ යටතේ ඔබට [Chromium](https://www.chromium.org/) (Chrome සෑදී ඇත්තේ එයින් වන සරල විවෘත මූලාශ්‍ර ගොඩනැගීම), Edge, Brave, Brave Origin, Firefox, [Zen](https://zen-browser.app/), සහ [Ladybird](https://ladybird.org/) හමුවනු ඇත (Edge ලැබෙන්නේ x86 යන්ත්‍රවල පමණි). එකක් තෝරන්න, එවිට Omarchy එය ස්ථාපනය කර, එහි policy directory එක සකසා, ඔබේ වත්මන් තේමාව එයට යොදනු ඇත.

## එකක් පෙරනිමිය බවට පත් කිරීම

බ්‍රවුසරයක් ස්ථාපනය කිරීමෙන් එය උසස් වන්නේ නැත. මාරු කිරීමට, _Setup > Defaults > Browser_ වෙත ගොස් එකක් තෝරන්න. වත්මන් පෙරනිමිය සලකුණකින් සලකුණු කර ඇති අතර, ඔබට තවමත් නැති බ්‍රවුසරයක් තෝරා ගැනීමෙන් එය මුලින්ම ස්ථාපනය වේ.

ටර්මිනලයෙන් එය මෙසේය:

```bash
omarchy default browser firefox
```

එය කිසිදු argument එකක් නොමැතිව ධාවනය කරන්න, එවිට එය ඔබට වත්මන් පෙරනිමිය පවසනු ඇත. මෙය XDG handler එක සකසයි, එබැවින් ඒ අනුව ක්‍රියා කරන්නේ Omarchy හි hotkeys පමණක් නොවේ — chat යෙදුමක සිට terminal විධානයක් දක්වා, සබැඳියක් විවෘත කරන ඕනෑම දෙයක් ඔබ තෝරා ගත් බ්‍රවුසරයට යනු ඇත.

## URL එක පිටපත් කිරීම සහ වීඩියෝ බාගත කිරීම

Chromium පවුලේ බ්‍රවුසර් (Chromium ම, Chrome, Edge, Brave, සහ Brave Origin) සමඟ Omarchy දිගු තුනක් ලැබේ: බ්‍රවුසරයෙන් පිටතට ඔබේ පද්ධතියේ ඉතිරි කොටස වෙත ළඟා වන දෙකක්, සහ WhatsApp පිළිවෙළට සකසන එකක්.

**Copy URL** මඟින් `Alt + Shift + L` සමඟ වත්මන් tab එකේ ලිපිනය ඔබේ clipboard එකට දමයි. එය address bar එකට click කර පිටපත් කිරීමට වඩා වේගවත් වන අතර, එය බ්‍රවුසරයේ clipboard එක වෙනුවට system clipboard එක හරහා යන නිසා, එය තහවුරු කරන Omarchy දැනුම්දීමක් ඔබට ලැබෙන අතර URL එක [clipboard ඉතිහාසයේ](08-unified-clipboard-history.md) සහ අනෙක් සෑම යෙදුමකම වහාම ලබා ගත හැක. ඔබට click කිරීමට කැමති නම්, toolbar බොත්තමක්ද ඇත.

**Download Video** මඟින් ඔබ බලා සිටින පිටුවේ වාදනය වන වීඩියෝව `Alt + Shift + D` සමඟ ලබා ගනී. එය URL එක [yt-dlp](https://github.com/yt-dlp/yt-dlp) වෙත භාර දෙයි, එබැවින් එය YouTube ට වඩා බොහෝ දේවල ක්‍රියා කරයි, සහ බාගත කිරීම `~/Videos` තුළට ලැබේ. ප්‍රගතිය දිස්වන්නේ ශබ්දය සහ දීප්තිය භාවිත කරන එම on-screen display එකේම වන අතර, දැනුම්දීම් ගොඩ ගැසීම වෙනුවට එම ස්ථානයේදීම යාවත්කාලීන වේ. ඔබට ගොනු වෙනත් තැනකට යාමට අවශ්‍ය නම් `OMARCHY_YTDLP_DIR` සකසන්න — environment variables තැබිය යුත්තේ කොතැනද යන්න සඳහා [FAQ](46-faq.md) බලන්න.

දිගු දෙකම Omarchy සමඟ සන්නිවේදනය කරන්නේ බ්‍රවුසරය සමඟම ඔබ වෙනුවෙන් ස්ථාපනය වන කුඩා native messaging host එකක් හරහාය. වෙබ් පිටුවක වීඩියෝවක් ඔබේ home directory එකට ලැබීමට සහ URL එකක් ඔබේ clipboard manager එකට ලැබීමට ඉඩ සලසන්නේ ඒ කොටස වන අතර, එය සාමාන්‍ය දිගුවකට තනිවම කළ නොහැක.

**WhatsApp Slim** මඟින් WhatsApp Web ඔබේ system තේමාව අනුගමනය කිරීමට සලසන අතර කවුළුව පටු වූ විට එහි chat ලැයිස්තුව හකුළයි.

මේවා Chromium පවුලට පමණි. Firefox සහ Zen වලට මේවා නොලැබේ.

## Firefox සහ Zen

Firefox සහ Zen යනු වෙනස් පවුලක් වන බැවින්, ඒවාට වෙනස් සැලකිල්ලක් ලැබේ: Omarchy විසින් සාධාරණ පෙරනිමි සඳහා policies ගොනුවක් ස්ථාපනය කරන අතර ඒවා native Wayland mode එකට මාරු කරයි, එය ඔබට fractional scaling සහ සුමට trackpad scrolling සඳහා අවශ්‍ය වේ.

ඒවාට ඉහත Chromium දිගු නොලැබෙන අතර, ඒවා Omarchy විසින් තේමා කරනු නොලැබේ, එබැවින් අත්දැකීමේ එම කොටස් සකස් කිරීම ඔබ සතුය.

## Ladybird

Ladybird යනු මුල සිටම ලියන ලද බ්‍රවුසරයක් වන අතර, එයට Chromium හෝ Firefox වල එන්ජිම වෙනුවට තමන්ගේම එන්ජිමක් ඇත. එය තවමත් alpha අවධියේ පවතින බැවින්, තවමත් ක්‍රියා නොකරන වෙබ් අඩවි අපේක්ෂා කරන්න, සහ Omarchy එය ලැබෙන ආකාරයටම ස්ථාපනය කරයි: දිගු නැත, තේමාවක් නැත, policies නැත. එයට පුද්ගලික කවුළුවක්ද නැත, එබැවින් `Super + Shift + Alt + B` මඟින් එය විවෘත වන්නේ ඔබ එය වැසූ විට මකා දැමෙන තාවකාලික profile එකක් සමඟය. [වෙබ් යෙදුම්](25-web-apps.md) දිගටම Chrome හෝ Chromium තුළ ධාවනය වේ.

## එකක් නැවත ඉවත් කිරීම

Chrome ද ඇතුළුව මෙම බ්‍රවුසර් වලින් ඕනෑම එකක් _Remove > Browser_ යටතේ නැවත ඉවත් කළ හැක. අනෙක් එක තවමත් ස්ථාපනය කර ඇත්නම් සබැඳි එවිට Chrome හෝ Chromium වෙත යනු ඇත.
