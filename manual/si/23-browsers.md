# බ්‍රවුසර

Omarchy සමග පෙරනිමි බ්‍රවුසරය ලෙස [Google Chrome](https://www.google.com/chrome/) ලැබේ. එය ඔබේ පද්ධතියේ ඉතිරි කොටසට ගැලපෙන පරිදි තේමා කර ඇති අතර, `Super + Shift + Return` (හෝ `Super + Shift + B`) මඟින් විවෘත වන්නේ එයයි, `Super + Shift + Alt + B` මඟින් පුද්ගලික කවුළුවක් විවෘත වේ, සහ සෑම [වෙබ් යෙදුමක්ම](25-web-apps.md) ක්‍රියාත්මක වන්නේ ද එහි ඇතුළත ය. එය කෙලින්ම බ්‍රවුසර කවුළුවකට විවෘත වේ: පිළිගැනීමේ තිරයක් හෝ පුරනය වීමේ ඉල්ලීමක් නැත, භාවිත සංඛ්‍යාලේඛන සහ බිඳවැටීම් වාර්තා Google වෙත යවන්නේ නැත, සහ දැන්වීම් පෞද්ගලිකත්ව ඉල්ලීම් අක්‍රිය කර ඇත. Sync අවශ්‍ය ඕනෑම වේලාවක profile බොත්තමෙන් ඔබට තවමත් ඔබේ Google ගිණුමට පුරනය විය හැකිය.

Chrome ඔබේ රුචියට නොගැලපේ නම්, ඔබ එය සමගම සිර වී සිටිය යුතු නැත. Omarchy මෙනුවේ _Install > Browser_ යටතේ ඔබට [Chromium](https://www.chromium.org/) (Chrome සෑදී ඇති සරල විවෘත මූලාශ්‍ර build එක), Edge, Brave, Brave Origin, Firefox, සහ [Zen](https://zen-browser.app/) හමුවේ (Edge ඇත්තේ x86 යන්ත්‍රවල පමණි). එකක් තෝරන්න, එවිට Omarchy එය ස්ථාපනය කරයි, එහි policy directory එක සකසයි, සහ ඔබේ වත්මන් තේමාව එයට යොදයි.

## එකක් පෙරනිමිය බවට පත් කිරීම

බ්‍රවුසරයක් ස්ථාපනය කිරීමෙන් එය ඉහළට ඔසවන්නේ නැත. මාරු කිරීමට, _Setup > Defaults > Browser_ වෙත ගොස් එකක් තෝරන්න. වත්මන් පෙරනිමිය සලකුණකින් සලකුණු කර ඇති අතර, ඔබට තවමත් නැති බ්‍රවුසරයක් තෝරා ගැනීමෙන් එය මුලින්ම ස්ථාපනය වේ.

Terminal එකෙන් එය මෙසේය:

```bash
omarchy default browser firefox
```

කිසිදු argument එකක් නොමැතිව එය ධාවනය කරන්න, එවිට එය වත්මන් පෙරනිමිය ඔබට කියයි. මෙය XDG handler එක සකසන බැවින්, ඒ අනුව ක්‍රියා කරන්නේ Omarchy හි hotkeys පමණක් නොවේ — chat යෙදුමක සිට terminal විධානයක් දක්වා, සබැඳියක් විවෘත කරන ඕනෑම දෙයක් ඔබ තෝරාගත් බ්‍රවුසරයටම යයි.

## URL පිටපත් කිරීම සහ වීඩියෝ බාගත කිරීම

Chromium පවුලේ බ්‍රවුසර (Chromium ම, Chrome, Edge, Brave, සහ Brave Origin) සමග Omarchy දිගු තුනක් පැමිණේ: ඉන් දෙකක් බ්‍රවුසරයෙන් පිටතට ඔබේ පද්ධතියේ ඉතිරි කොටස දක්වා ළඟා වන අතර, එකක් WhatsApp පිළිවෙලට සකසයි.

**Copy URL** මඟින් `Alt + Shift + L` සමග වත්මන් tab එකේ ලිපිනය ඔබේ clipboard එකට දමයි. එය ලිපින තීරුවට click කර පිටපත් කිරීමට වඩා වේගවත් වන අතර, එය බ්‍රවුසරයේ clipboard එක හරහා නොව පද්ධති clipboard එක හරහා යන බැවින්, එය තහවුරු කරන Omarchy දැනුම්දීමක් ඔබට ලැබෙන අතර URL එක [ක්ලිප්බෝඩ් ඉතිහාසයේ](08-unified-clipboard-history.md) සහ අනෙක් සෑම යෙදුමකම වහාම ලබා ගත හැකිය. ඔබට click කිරීමට කැමති නම් toolbar බොත්තමක් ද ඇත.

**Download Video** මඟින් `Alt + Shift + D` සමග ඔබ බලමින් සිටින පිටුවේ වාදනය වන වීඩියෝව ලබා ගනියි. එය URL එක [yt-dlp](https://github.com/yt-dlp/yt-dlp) වෙත භාර දෙන බැවින්, එය YouTube ට වඩා බොහෝ දේවල ක්‍රියාත්මක වන අතර, බාගත කිරීම `~/Videos` වෙත වැටේ. ශබ්දය සහ දීප්තිය සඳහා භාවිත කරන එම on-screen display එකෙහිම ප්‍රගතිය දිස්වන අතර, දැනුම්දීම් එක මත එක ගොඩගැසීම වෙනුවට එතැනම යාවත්කාලීන වේ. ගොනු වෙනත් තැනකට යාමට ඔබ කැමති නම් `OMARCHY_YTDLP_DIR` සකසන්න — environment variables තැබිය යුතු තැන සඳහා [FAQ](46-faq.md) බලන්න.

දිගු දෙකම කුඩා native messaging host එකක් හරහා Omarchy සමග සන්නිවේදනය කරන අතර, එය බ්‍රවුසරය සමගම ඔබට ස්ථාපනය වේ. වෙබ් පිටුවක වීඩියෝවක් ඔබේ home directory එකටත්, URL එකක් ඔබේ clipboard manager එකටත් යාමට ඉඩ දෙන්නේ එම කොටස වන අතර, එය සාමාන්‍ය දිගුවකට තනිවම කළ නොහැක.

**WhatsApp Slim** මඟින් WhatsApp Web ඔබේ පද්ධති තේමාව අනුගමනය කරන අතර, කවුළුව පටු වූ විට එහි chat ලැයිස්තුව හකුළයි.

මේවා Chromium පවුලට පමණි. Firefox සහ Zen ට ඒවා ලැබෙන්නේ නැත.

## Firefox සහ Zen

Firefox සහ Zen වෙනස් පවුලක් වන බැවින් ඒවාට ලැබෙන්නේ වෙනස් සැලකිල්ලකි: Omarchy විසින් සාධාරණ පෙරනිමි සඳහා policies ගොනුවක් ස්ථාපනය කරන අතර ඒවා native Wayland ප්‍රකාරයට මාරු කරයි, එය fractional scaling සහ සුමට trackpad scrolling සඳහා ඔබට අවශ්‍ය දේම වේ.

ඉහත Chromium දිගු ඒවාට ලැබෙන්නේ නැති අතර, ඒවා Omarchy විසින් තේමා කරන්නේ ද නැත, එබැවින් අත්දැකීමේ එම කොටස් සකසා ගැනීම ඔබට භාරය.

## එකක් නැවත ඉවත් කිරීම

Chrome ඇතුළුව මෙම බ්‍රවුසරවලින් ඕනෑම එකක් _Remove > Browser_ යටතේ නැවත ඉවත් කළ හැකිය. අනෙක් එක තවමත් ස්ථාපනය කර තිබේ නම් සබැඳි එවිට Chrome හෝ Chromium වෙත යයි.
