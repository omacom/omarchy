# බ්‍රවුසර

Omarchy සමඟ පෙරනිමි බ්‍රවුසරය ලෙස [Google Chrome](https://www.google.com/chrome/) පැමිණේ. එය ඔබේ පද්ධතියේ ඉතිරි කොටස් සමඟ ගැළපෙන පරිදි තේමා කර ඇති අතර, `Super + Shift + Return` මගින් විවෘත වන්නේත්, සෑම [වෙබ් යෙදුමක්ම](25-web-apps.md) ඇතුළත ක්‍රියාත්මක වන්නේත් එයයි. එය කෙලින්ම බ්‍රවුසර කවුළුවකට විවෘත වේ: පිළිගැනීමේ තිරයක් හෝ පුරනය වීමේ විමසීමක් නොමැත, භාවිත සංඛ්‍යාලේඛන සහ බිඳවැටීම් වාර්තා Google වෙත යවනු නොලැබේ, සහ දැන්වීම් පෞද්ගලිකත්ව විමසීම් අක්‍රිය කර ඇත. ඔබට සමමුහුර්ත කිරීම අවශ්‍ය ඕනෑම වේලාවක profile බොත්තමෙන් තවමත් ඔබේ Google ගිණුමට පුරනය විය හැකිය.

Chrome ඔබේ රුචිකත්වයට නොගැළපේ නම්, ඔබට එය සමඟම සිරවී සිටීමට සිදු නොවේ. Omarchy මෙනුවේ _Install > Browser_ යටතේ ඔබට [Chromium](https://www.chromium.org/) (Chrome සෑදී ඇති සරල විවෘත මූලාශ්‍ර build එක), Edge, Brave, Brave Origin, Firefox, සහ [Zen](https://zen-browser.app/) හමුවේ. එකක් තෝරන්න, එවිට Omarchy එය ස්ථාපනය කර, එහි policy ඩිරෙක්ටරිය සකසා, ඔබේ වත්මන් තේමාව එයට යොදයි.

## එකක් පෙරනිමිය බවට පත් කිරීම

බ්‍රවුසරයක් ස්ථාපනය කිරීමෙන් එය පෙරනිමිය බවට පත් නොවේ. එය යන්ත්‍රයේ ස්ථාපනය වූ පසු, _Setup > Defaults > Browser_ වෙත ගොස් එය තෝරන්න — මෙනුවේ ලැයිස්තුගත වන්නේ ඔබ ඇත්තටම ස්ථාපනය කර ඇති බ්‍රවුසර පමණක් වන අතර, වත්මන් පෙරනිමිය හරි ලකුණකින් සලකුණු කරයි.

ටර්මිනලයෙන් එය මෙසේය:

```bash
omarchy default browser firefox
```

එය කිසිදු argument එකක් නොමැතිව ක්‍රියාත්මක කරන්න, එවිට එය වත්මන් පෙරනිමිය ඔබට කියයි. මෙය XDG handler එක සකසන බැවින්, ඒ අනුව ක්‍රියා කරන්නේ Omarchy හි hotkeys පමණක් නොවේ — chat යෙදුමක සිට terminal විධානයක් දක්වා, සබැඳියක් විවෘත කරන ඕනෑම දෙයක් ඔබ තෝරාගත් බ්‍රවුසරය වෙත යයි.

## URL පිටපත් කිරීම සහ වීඩියෝ බාගත කිරීම

Chromium පවුලේ බ්‍රවුසර (Chromium ම, Chrome, Edge, සහ Brave) සමඟ බ්‍රවුසරයෙන් ඔබ්බට ඔබේ පද්ධතියේ ඉතිරි කොටස් වෙත ළඟා වන Omarchy දිගු දෙකක් පැමිණේ.

**Copy URL** මගින් `Alt + Shift + L` සමඟ වත්මන් ටැබයේ ලිපිනය ඔබේ clipboard එකට දමයි. එය ලිපින තීරුවට ක්ලික් කර පිටපත් කිරීමට වඩා වේගවත් වන අතර, එය බ්‍රවුසරයේ clipboard එක වෙනුවට පද්ධති clipboard එක හරහා යන බැවින්, එය තහවුරු කරමින් ඔබට Omarchy නිවේදනයක් ලැබෙන අතර URL එක [clipboard ඉතිහාසය](08-unified-clipboard-history.md) සහ අනෙක් සෑම යෙදුමකම වහාම ලබා ගත හැකිය. ඔබ ක්ලික් කිරීමට කැමති නම්, ඒ සඳහා toolbar බොත්තමක්ද ඇත.

**Download Video** මගින් `Alt + Shift + D` සමඟ ඔබ බලමින් සිටින පිටුවේ ධාවනය වන වීඩියෝව ලබා ගනී. එය URL එක [yt-dlp](https://github.com/yt-dlp/yt-dlp) වෙත භාර දෙන බැවින්, එය YouTube වලට වඩා බොහෝ දේවල ක්‍රියා කරන අතර, බාගත කිරීම `~/Videos` තුළට වැටේ. ප්‍රගතිය දිස්වන්නේ ශබ්දය සහ දීප්තිය භාවිත කරන එම තිරයේ දර්ශනයේම වන අතර, නිවේදන එක පිට එක ගොඩගැසීම වෙනුවට එතැනම යාවත්කාලීන වේ. ගොනු වෙනත් තැනකට යාමට ඔබ කැමති නම් `OMARCHY_YTDLP_DIR` සකසන්න — පරිසර විචල්‍ය තැබිය යුතු තැන සඳහා [FAQ](46-faq.md) බලන්න.

දිගු දෙකම කුඩා native messaging host එකක් හරහා Omarchy සමඟ සන්නිවේදනය කරන අතර, එය බ්‍රවුසරය සමඟම ඔබ වෙනුවෙන් ස්ථාපනය වේ. වෙබ් පිටුවක වීඩියෝවක් ඔබේ home ඩිරෙක්ටරියේ අවසන් වීමටත්, URL එකක් ඔබේ clipboard කළමනාකරු තුළට පැමිණීමටත් ඉඩ දෙන කොටස එය වන අතර, සාමාන්‍ය දිගුවකට තනිවම එය කළ නොහැකිය.

මේවා Chromium පවුලට පමණක් සීමා වේ. Firefox සහ Zen වලට ඒවා නොලැබේ.

## Firefox සහ Zen

Firefox සහ Zen වෙනස් පවුලක් බැවින්, ඒවාට වෙනස් සැලකිල්ලක් ලැබේ: Omarchy උචිත පෙරනිමි සඳහා policies ගොනුවක් ස්ථාපනය කර ඒවා native Wayland ප්‍රකාරයට මාරු කරන අතර, එය භාගික පරිමාණය සහ සුමට trackpad අනුචලනය සඳහා ඔබට අවශ්‍ය වේ.

ඒවාට ඉහත Chromium දිගු නොලැබෙන අතර, ඒවා Omarchy විසින් තේමා කරනු නොලැබේ, එබැවින් අත්දැකීමේ එම කොටස් සැකසීම ඔබට භාරය.

## එකක් නැවත ඉවත් කිරීම

Chrome ඇතුළුව මෙම ඕනෑම බ්‍රවුසරයක් _Remove > Browser_ යටතේ නැවත ඉවත් කළ හැකිය. අනෙක් බ්‍රවුසරය තවමත් ස්ථාපනය කර ඇත්නම්, සබැඳි ඉන්පසු Chrome හෝ Chromium වෙත යයි.
