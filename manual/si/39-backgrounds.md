# පසුබිම්

සෑම theme එකක් සමඟම එයටම ආවේණික පසුබිම් කට්ටලයක් ලැබෙන අතර, ඔබට ඔබේම අමතර පසුබිම් `~/.config/omarchy/backgrounds/[theme]` තුළට එක් කළ හැකිය. උදාහරණයක් ලෙස, nord theme එකට අමතර පසුබිම් රූපයක් එක් කිරීමට අවශ්‍ය නම්, ඔබ කළ යුත්තේ එම ගොනුව `~/.config/omarchy/backgrounds/nord` තුළට දැමීම පමණි.

Omarchy Menu එකේ _Install > Style > Background_ වෙත යාමෙන් ඔබට මෙය වඩාත්ම පහසුවෙන් කළ හැකිය. එම theme එක සඳහා පසුබිම් ගබඩා කර ඇති folder එක එමඟින් විවෘත වේ. තවත් file manager එකක් ආරම්භ කිරීමට `Super + Shift + F` ඔබා, ඔබේ පසුබිම සොයා, එය එතැනට පිටපත් කරන්න. දැන් එය `Super + Ctrl + W` භාවිතයෙන් ඔබට තෝරාගත හැකි පසුබිම් තේරීම් අතරට ඇතුළත් වේ.

පසුබිම්, නිශ්චල රූප මෙන්ම වීඩියෝ ද විය හැකිය. එකම folder එකට `mp4`, `m4v`, `mov`, `webm`, `mkv`, හෝ `avi` ගොනුවක් දමන්න, එවිට එය රූප සමඟින්ම දිස් වේ. වීඩියෝ වාදනය කරන්නේ OWE wallpaper engine එක විසිනි. එය සියලුම monitors සඳහා වීඩියෝව එක් වරක් decode කර, එහි ශබ්දය default audio output එක හරහා වාදනය කරන අතර, කිසිවෙකුට එය දැකිය නොහැකි සෑම විටම වාදනය නවත්වයි. එහෙම වුවත්, video wallpaper එකක් නිශ්චල රූපයකට වඩා බෙහෙවින් වැඩි බලයක් වැය කරයි.

නිශ්චල පසුබිමක් සඳහා themes වලට කෙටි intro එකක් ඇතුළත් කළ හැකිය. `backgrounds/road.webp` සඳහා, ඊට ගැලපෙන වීඩියෝව ඇත්තේ `backgrounds/intros/road.mp4` හි ය. එය boot වන විට, එම පසුබිම තෝරා ඇති theme එකකට මාරු වන විට, සහ එම පසුබිම තෝරන විට ස්වයංක්‍රීයව වාදනය වී, පසුව නිශ්චල රූපය වෙත ආපසු යයි. Intro videos පසුබිම් picker එකෙන් බැහැරව පවතින අතර කිසි විටෙක loop නොවේ.

_Appearance > Animations_ අක්‍රිය කිරීමෙන් පසුබිම් intros ද අක්‍රිය වේ. Omarchy මෙය virtual machine එකකදී default ලෙසින් සිදු කරයි. `omarchy theme bg intro toggle` විධානයෙන් intros වෙනම toggle කළ හැකිය. Theme එකක් refresh කිරීමෙන් intro එකක් වාදනය නොවේ.

විශිෂ්ට ලෙස තෝරාගත් සිසිල් පසුබිම් විශාල එකතුවක් ඔබට [dharmx/walls](https://github.com/dharmx/walls) හිදී සොයාගත හැකිය.

Lock screen එක video පසුබිමක නිශ්චල frame එකක් පෙන්වයි, animated GIF එකක නිශ්චල frame එකක් පෙන්වන ආකාරයටම.
