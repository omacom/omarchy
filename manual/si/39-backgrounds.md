# පසුබිම්

සෑම තේමාවක්ම තමන්ටම ආවේණික පසුබිම් එකතුවක් සමඟ එන අතර, ඔබට ඔබේම අමතර ඒවා `~/.config/omarchy/backgrounds/[theme]` තුළට එක් කළ හැකිය. උදාහරණයක් ලෙස, nord තේමාවට අමතර පසුබිම් රූපයක් එක් කිරීමට ඔබට අවශ්‍ය නම්, ඔබ කළ යුත්තේ එම ගොනුව `~/.config/omarchy/backgrounds/nord` තුළට දැමීම පමණි.

Omarchy Menu එකේ _Install > Style > Background_ වෙත යාමෙන් ඔබට මෙය ඉතා පහසුවෙන් කළ හැකිය. එමඟින් එම තේමාව සඳහා පසුබිම් ගබඩා කර ඇති ෆෝල්ඩරය විවෘත වනු ඇත. තවත් ගොනු කළමනාකරුවකු ආරම්භ කිරීමට `Super + Shift + F` ඔබන්න, ඔබේ පසුබිම සොයාගෙන, එය එහි පිටපත් කරන්න. දැන් එය `Super + Ctrl + W` භාවිතයෙන් ඔබට තෝරාගත හැකි පසුබිම් තේරීම් අතරට ඇතුළත් වනු ඇත.

පසුබිම් ලෙස නිශ්චල රූප මෙන්ම වීඩියෝ ද තිබිය හැකිය. `mp4`, `m4v`, `mov`, `webm`, `mkv`, හෝ `avi` ගොනුවක් එම ෆෝල්ඩරයටම දමන්න, එවිට එය රූප සමඟින් දිස්වනු ඇත. වීඩියෝ වාදනය කරනු ලබන්නේ OWE wallpaper engine එක විසිනි. එය සියලුම මොනිටර සඳහා වීඩියෝව එක් වරක් decode කරන අතර එහි ශබ්දය default audio output එක හරහා වාදනය කරයි, කිසිවකට එය දැකිය නොහැකි සෑම විටම වාදනය නවත්වයි. එසේ වුවත්, වීඩියෝ පසුබිමක් නිශ්චල එකකට වඩා බෙහෙවින් වැඩි බලයක් වැය කරයි.

තේමාවලට නිශ්චල පසුබිමක් සඳහා කෙටි intro එකක් ඇතුළත් කළ හැකිය. `backgrounds/road.webp` සඳහා, ගැළපෙන වීඩියෝව ඇත්තේ `backgrounds/intros/road.mp4` හි ය. එය boot වන විට, එම පසුබිම තෝරාගෙන ඇති තේමාවකට මාරු වන විට, සහ එම පසුබිම තෝරන විට ස්වයංක්‍රීයව වාදනය වී, පසුව නිශ්චල රූපය වෙත ආපසු යයි. Intro වීඩියෝ පසුබිම් තෝරනයෙන් පිටත පවතින අතර කිසිවිට loop නොවේ.

_Appearance > Animations_ අක්‍රිය කිරීමෙන් පසුබිම් intro ද අක්‍රිය වේ. Omarchy විසින් virtual machine එකකදී මෙය default ලෙස සිදු කරයි. `omarchy theme bg intro toggle` විධානයෙන් intro වෙනම toggle කළ හැකිය. තේමාවක් refresh කිරීමෙන් intro එකක් වාදනය නොවේ.

නිශ්චල රූපයකට loop එකක් ද තිබිය හැකිය, එය දිගටම චලනය වන එම රූපයේම නිහඬ අනුවාදයකි, එය ඇත්තේ `backgrounds/loops/road.mp4` හි ය. එය නිශ්චල රූපය වෙනුවට වාදනය වේ, intro එකක් තිබේ නම් ඊට පසුව වාදනය වේ, animations අක්‍රිය කළ විට නවතී. Loop පසුබිම් තෝරනයෙන් පිටත පවතින අතර, ඕනෑම වීඩියෝ පසුබිමක් මෙන්ම, නිශ්චල එකකට වඩා වැඩි බලයක් වැය කරයි.

ඔබට [dharmx/walls](https://github.com/dharmx/walls) තුළ හොඳින් තෝරාගත් අපූරු පසුබිම්වල විශාල එකතුවක් සොයාගත හැකිය.
