# AI

Omarchy තුළ ඔබ වෙනුවෙන් පෙරනිමියක් තෝරා නොගෙන පහත කේතකරණ නියෝජිතයන් සඳහා දියත් කරන්නන් ඇතුළත් වේ. පළමු භාවිතයේදී එහි CLI ස්ථාපනය කිරීමට විධානයක් ධාවනය කරන්න, ඉන්පසු විමසූ විට සත්‍යාපනය කරන්න. Hermes යනු ව්‍යතිරේකයයි: පළමු භාවිතයේදී එය සඳහා කිසිවක් ස්ථාපනය නොකෙරේ, එය තෝරාගැනීමෙන් Hermes Desktop ස්ථාපනය වේ, පහත _Desktop apps_ හි පැහැදිලි කර ඇති පරිදි.

### නියෝජිතයන් ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes හැර, මෙම නියෝජිතයන් mise හි lazy ස්ථාපනය භාවිතා කරයි: පළමු දියත් කිරීමේදී CLI ස්ථාපනය වන අතර, පසුව දියත් කිරීම් එය නැවත භාවිතා කරයි. mise විසින් ස්ථාපිත නියෝජිතයෙකු සඳහා නව නිකුතුවක් තිබේදැයි උපරිම වශයෙන් සෑම පැය හතරකටම වරක්, එය ආරම්භ වීමට මොහොතකට පෙර හෝ shell prompt එකක පසුබිමේ පරීක්ෂා කරයි. එම යාවත්කාලීනය අසාර්ථක වුවහොත් හෝ ඔබ නොබැඳිව සිටියහොත්, ස්ථාපිත අනුවාදය ධාවනය වේ. `omarchy update` මගින් Omarchy හි ඉතිරිය සමඟ ස්ථාපිත නියෝජිතයන් යාවත්කාලීන කරයි, සහ `mup` මගින් mise-කළමනාකරණය කරන මෙවලම් පමණක් යාවත්කාලීන කරයි.

නියෝජිතයෙකුගේම updater එක, උදාහරණයක් ලෙස `claude update`, `codex update`, හෝ යෙදුමක ඇති යාවත්කාලීන බොත්තම, mise-කළමනාකරණය කරන ස්ථාපනය යාවත්කාලීන නොකරයි. `codex update` අසාර්ථක වන අතර, `claude update` මගින් mise විසින් නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කරන අතරම සාර්ථකත්වය වාර්තා කළ හැකිය. ඔබ නියෝජිතයෙකුගේ ස්වදේශීය ස්ථාපකය සහ updater එක භාවිතා කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [පෙරස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

ඔබට ඒවා අවශ්‍ය වීමට පෙර සියලුම වින්‍යාස කළ lazy මෙවලම් ස්ථාපනය කිරීමට, `mise install --include-lazy` ධාවනය කරන්න. මෙයට නියෝජිතයන් මෙන්ම Omarchy හි අනෙකුත් පෙරනිමි CLI මෙවලම් ද ඇතුළත් වේ. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිතා කිරීම සඳහා [පෙරස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` ස්ථාපනය කරනු ලබන්නේ mise හි first-party `grok` පැකේජය හරහාය, `claude` සහ `codex` මෙන්ම. `grok` ධාවනය කරන්න, නැතහොත් _Setup > Defaults > Agent_ යටතේ එය තෝරන්න. x.ai හි ඇති `curl | bash` ස්ථාපකය මඟ හරින්න. එම මාර්ගය `~/.grok/bin` තුළ දෙවන පිටපතක් තබයි, එය `PATH` හි ඉදිරියට එක් කරයි, සහ Omarchy හි wrapper එක උඩින් ලියයි.

`dsh` එහි browser UI එක `127.0.0.1:3080` මත විවෘත කරයි, දියත් කරන නාමාවලිය එහි පෙරනිමි workspace එක ලෙස ගනී. එහි browser UI එක ආරම්භක prompt එකක් නොගන්නා බැවින්, `omarchy agent prompt` එය විවෘත කරන්නේ prompt එක ඔබේ clipboard එකේ අලවන්නට තබාගෙනය. Omarchy එය ආරම්භ කරන්නේ DeepSeek හි no-approval permission preset එක සමඟය. ඔබ එහි නිල model API එක භාවිතා කරන විට DeepSeek Harness විසින් session ලොග් DeepSeek වෙත උඩුගත කරයි; එහි browser UI එකේ _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ එයට යවන ප්‍රතිපෝෂණ ද session එක සමඟ උඩුගත වේ, ඔබ එය `DSH_TELEMETRY_MODE=DISABLED` සමඟ ආරම්භ කරන්නේ නම් මිස.

### පෙරනිමි නියෝජිතයා

`omarchy default agent <name>` සමඟ හෝ Omarchy Menu (`Super + Space`) හි _Setup > Defaults > Agent_ යටතේ ඔබේ පෙරනිමි නියෝජිතයා තෝරන්න. නියෝජිතයා තවමත් ස්ථාපනය කර නොමැති නම්, එය තෝරාගැනීමෙන් පළමුව එය ස්ථාපනය වේ. නැවුම් Omarchy එකක් එක් වරක් පමණක් දිස්වන දැනුම්දීමකින් මෙම තේරීම කිරීමට ඔබට ආරාධනා කරනු ඇත.

Claude තෝරාගැනීමෙන් Chromium, Chrome, Brave, Brave Origin, සහ Edge සඳහා එහි browser extension එක සැකසීමටද උත්සාහ කරයි. Provider කෙනෙකු සඳහා පළමු account එක ඔබේ සාමාන්‍ය browser එක හරහා, CLI සෑමවිටම බලන තැනදීම පුරනය වේ. ඉන්පසු සෑම එකක්ම private කවුළුවක් හරහා පුරනය වේ, එබැවින් ඔබේ browser එක දැනටමත් පුරනය වී ඇති account එක වැරදීමකින් තෝරා නොගැනේ; ඔබ එක් කරන account එක ලෙස එහි පුරනය වන්න, සහ ඔබ දැනටමත් විවෘත කර තිබූ ඕනෑම private කවුළුවක් පළමුව වසන්න. මෙය කිරීමට කිසිවිටෙක CLI එකෙන් ඉවත් නොවන්න: ඉවත් වීමෙන් සුරකින ලද පුරනය වීම අවලංගු වන අතර, එම account එක නැවත එක් කිරීමට සිදුවනු ඇත.

ඔබ සකසන සෑම ආකෘතියකටම නියෝජිතයන් පැනලයේ, ඔබේ subscriptions අසල, තමාගේම පේළියක් ලැබේ: එය ආරම්භ කිරීමට play, එය නවතා එහි මතකය නිදහස් කිරීමට pause, සහ ඔබේ නියෝජිතයා එය මත විවෘත කිරීමට terminal බොත්තම. ඒවා මතකය තුළ එකට ගැලපෙන විට කිහිපයක් එකවර ධාවනය විය හැකිය; එකක් නොගැලපෙන්නේ නම්, නැවැත්විය යුත්තේ ධාවනය වන කුමන ආකෘතියදැයි Omarchy කියයි. ඒවා නැවත සකස් කිරීමට පේළි අදින්න, සහ ආකෘතියක් සහ එහි බාගත කිරීම ඉවත් කිරීමට තෝරාගත් පේළියක් මත Delete ඔබන්න.

Command line එකෙන්, `omarchy agent local start <recipe>` සහ `omarchy agent local stop <recipe>` එකම දෙය කරයි, `omarchy agent local status` සෑම ආකෘතියක්ම පෙන්වයි, සහ `omarchy agent --local` ඔබේ පෙරනිමි නියෝජිතයා ඔබ අවසන් වරට ආරම්භ කළ ආකෘතිය මත විවෘත කරයි (ඔබේ පෙරනිමි නියෝජිතයාට දේශීය ආකෘතියක් භාවිතා කළ නොහැකි නම් pi). ඕනෑම OpenAI-අනුකූල client එකකටද සම්බන්ධ විය හැකිය: `status` සෑම ආකෘතියකම ලිපිනය පෙන්වයි (පළමුවැන්න `http://127.0.0.1:11435/v1`), recipe නම ආකෘතිය වන අතර, යතුර `~/.config/omarchy/agent-local/key` තුළ ඇත.

`omarchy agent local remove <recipe>` ආකෘතියක් සහ වෙනත් කිසිදු ආකෘතියක් භාවිතා නොකරන බාගත කිරීම් මකා දමයි.

තෙවන පාර්ශවීය runtimes ඒවායේ ප්‍රකාශකයා සමඟ ලේබල් කරනු ලැබේ. Omarchy සෑම ආකෘතියක්ම ජාල ප්‍රවේශයක් නොමැතිව ධාවනය කරයි.

### දේශීය LLMs

Omarchy දේශීය LLM ආකෘති ධාවනය කිරීමේ ක්‍රම දෙකක් නිර්දේශ කරයි: LM Studio සහ Ollama. LM Studio විසින් open-weight ආකෘති සොයා ගැනීමට, ඒවා ස්ථාපනය කිරීමට, සහ ඒවා ධාවනය කිරීමට GUI අතුරුමුහුණතක් සපයයි. පහසුවෙන් ආරම්භ කිරීමට එය කදිම ක්‍රමයකි. Ollama විසින් ඒ හා සමානව එසේ කිරීමට CLI එකක් පිරිනමයි. නමුත් ඔබ දේශීය ආකෘතිවලට අලුත් නම්, මම LM Studio වලින් ආරම්භ කරමි. ඔබට Omarchy Menu හි _Install > AI_ යටතේ දෙකෙන් ඕනෑම එකක් ස්ථාපනය කළ හැකිය.

### Omarchy Skill එක

Agent skills AI හට නිශ්චිත මෙවලම් නිශ්චිත ආකාරයකින් භාවිතා කිරීමට උපකාරී වන අතර, Omarchy පද්ධතිය සකස් කිරීම සඳහා පෙරනිමි skill එකක් සමඟ පැමිණේ. ඔබේ Hyprland config එක වෙනස් කිරීම, තීරුව සකස් කිරීම, හෝ මුල සිටම නව තේමාවක් නිර්මාණය කිරීම වැනි. එය Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ සෑම `~/.hermes/profiles/*/skills` එකක්ම), සහ generic `~/.agents/skills` ස්ථානය සඳහා skill නාමාවලි තුළට symlink කර ඇති බැවින්, බොහෝ harnesses එය ස්වයංක්‍රීයවම ලබා ගනී.

නමුත් ඔබ මෙම skill එක පර්යේෂණාත්මක ලෙස සැලකිය යුතුය. විවිධ ආකෘති එය විවිධ බලපෑම් සඳහා භාවිතා කරනු ඇත. පළමුව plan mode එකෙන් ධාවනය කිරීම වඩාත් හොඳය, එවිට නියෝජිතයා වෙනස් කිරීමට කැමති දේ පිළිබඳ අදහසක් ඔබට ලැබේ. තවද නියෝජිතයා සියල්ල අවුල් කරන්නේ නම්, වෙනස්කම් rollback කිරීමට හෝ `omarchy reinstall configs` පවා ක්‍රියාත්මක කිරීමට සූදානම් වන්න.
