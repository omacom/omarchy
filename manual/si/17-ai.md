# AI

Omarchy විසින් ඔබට පෙරනිමියක් තෝරා නොදී, පහත coding agents සඳහා launchers ඇතුළත් කරයි. විධානයක් ධාවනය කරන්න, එවිට එය පළමු භාවිතයේදී එහි CLI ස්ථාපනය කරයි, ඉන්පසු විමසූ විට සත්‍යාපනය කරන්න. Hermes යනු ව්‍යතිරේකයයි: එය පළමු භාවිතයේදී ඒ සඳහා කිසිවක් ස්ථාපනය නොකරයි, එය තේරීමෙන් Hermes Desktop ස්ථාපනය වේ, පහත _Desktop apps_ පැහැදිලි කරන පරිදි.

### Agents ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes හැර, මෙම agents mise හි lazy ස්ථාපනය භාවිත කරයි: පළමු දියත් කිරීමෙන් CLI ස්ථාපනය වන අතර, පසුව දියත් කිරීම් එය නැවත භාවිත කරයි. එසේම mise ස්ථාපිත agent එකක් සඳහා නව නිකුතුවක් තිබේදැයි උපරිම වශයෙන් සෑම පැය හතරකට වරක් පමණක් පරීක්ෂා කරයි, එය ආරම්භ වීමට මොහොතකට පෙර හෝ shell prompt එකකදී පසුබිමේදී. එම යාවත්කාලීනය අසාර්ථක වුවහොත් හෝ ඔබ offline නම්, ස්ථාපිත අනුවාදය ධාවනය වේ. `omarchy update` මගින් Omarchy හි ඉතිරිය සමඟ ස්ථාපිත agents යාවත්කාලීන කරන අතර, `mup` මගින් mise-කළමනාකරණය වන මෙවලම් පමණක් යාවත්කාලීන කරයි.

`claude update`, `codex update` වැනි agent එකකම updater එකක්, හෝ යෙදුමක ඇති update බොත්තමක්, mise-කළමනාකරණය වන ස්ථාපනය යාවත්කාලීන නොකරයි. `codex update` අසාර්ථක වන අතර, `claude update` මගින් සාර්ථක බව වාර්තා කරමින් mise විසින් නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කළ හැකිය. ඔබ agent එකකම native installer එක සහ updater එක භාවිත කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [Preinstalled CLI tools](18-development-tools.md#preinstalled-cli-tools) බලන්න.

ඔබට අවශ්‍ය වීමට පෙර වින්‍යාස කළ සියලුම lazy මෙවලම් ස්ථාපනය කිරීමට, `mise install --include-lazy` ධාවනය කරන්න. මෙයට agents මෙන්ම Omarchy හි අනෙක් පෙරනිමි CLI මෙවලම් ද ඇතුළත් වේ. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිත කිරීම සඳහා [Preinstalled CLI tools](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`claude` සහ `codex` ආකාරයටම, `grok` ස්ථාපනය වන්නේ mise හි first-party `grok` package එක හරහාය. `grok` ධාවනය කරන්න, හෝ එය _Setup > Defaults > Agent_ යටතේ තෝරන්න. x.ai හි `curl | bash` installer එක මඟ හරින්න. එම මාර්ගය `~/.grok/bin` තුළ දෙවන පිටපතක් තබන අතර, එය `PATH` හි ඉදිරියට දමා, Omarchy හි wrapper එක උඩින් ලියයි.

`dsh` විසින් එහි browser UI එක `127.0.0.1:3080` මත විවෘත කරන අතර, දියත් කරන directory එක එහි පෙරනිමි workspace එක වේ. එහි browser UI එක ආරම්භක prompt එකක් නොගන්නා බැවින්, `omarchy agent prompt` මගින් එය විවෘත කරන්නේ prompt එක ඔබගේ clipboard එකේ තබා ඇත්තේ paste කිරීම සඳහාය. Omarchy එය ආරම්භ කරන්නේ DeepSeek හි no-approval permission preset එක සමඟය. ඔබ එහි official model API එක භාවිත කරන විට DeepSeek Harness විසින් session logs DeepSeek වෙත upload කරයි; එහි browser UI එකේ _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ එයට යවන feedback ද session එක සමඟ upload වේ, ඔබ එය `DSH_TELEMETRY_MODE=DISABLED` සමඟ ආරම්භ නොකළහොත්.

### පෙරනිමි agent එක

`omarchy default agent <name>` සමඟ හෝ Omarchy Menu (`Super + Space`) එකේ _Setup > Defaults > Agent_ යටතේ ඔබේ පෙරනිමි agent එක තෝරන්න. agent එක තවම ස්ථාපනය කර නොමැති නම්, එය තේරීමෙන් පළමුව එය ස්ථාපනය වේ. නව Omarchy එකක් එක් වරක් පමණක් දිස්වන notification එකකින් මෙම තේරීම කිරීමට ඔබට ආරාධනා කරයි.

Claude තේරීමෙන් Chromium, Chrome, Brave, Brave Origin, සහ Edge සඳහා එහි browser extension එක සැකසීමට ද උත්සාහ කරයි. extension සැකසුම සියලුම භාවිතා කරන්නන්ට අදාළ වන අතර ඔබේ system password එක ඉල්ලා සිටිය හැකිය; අවලංගු කිරීම හෝ අසාර්ථක extension ස්ථාපනයක් වුවද Claude තෝරා ගෙන දියත් කරයි. ඔබේ browser එක restart කර, විමසුවහොත් extension එක enable කර, එය සම්බන්ධ කිරීම අවසන් කිරීමට Claude වෙත sign in වන්න. සම්බන්ධතාව පරීක්ෂා කිරීමට Claude තුළ `/chrome` ධාවනය කරන්න. Firefox සහ Zen මෙම extension එකට සහාය නොදක්වයි. මෙම සැකසුම එක් කිරීමට පෙර Claude දැනටමත් ඔබේ පෙරනිමිය වී තිබුණි නම්, extension එක ස්ථාපනය කිරීමට එය නැවත තෝරන්න.

ඔබ තෝරා ගත් පසු, `Super + Shift + Ctrl + A` මගින් පෙරනිමි agent එක කැපවූ terminal කවුළුවක දියත් කරයි (හෝ ඔබ තවම තෝරා නොමැති නම් picker එක ගෙන එයි). `omarchy agent prompt "Review this project"` සමඟ ඔබට එය කෙලින්ම කාර්යයකට දියත් කළ හැකිය. ### Crash diagnosis

Omarchy විසින් process crashes සඳහා systemd-coredump නිරීක්ෂණය කරයි. යමක් segfault වූ විට, ඔබට "Process crashed" notification එකක් ලැබෙනු ඇත — එය click කරන්න, එවිට crash එක ඔබේ පෙරනිමි agent එකට Omarchy හි diagnose-crash skill එක සමඟ භාර දෙනු ලබන අතර, එය core dump එකෙන් කරුණු තහවුරු කිරීම සහ crash එක upstream වාර්තා කිරීම වටිනවාද යන්න තීරණය කිරීම හරහා agent එකව රැගෙන යයි. ඔබට `coredumpctl list` වෙතින් ඕනෑම PID එකකට එරෙහිව `omarchy agent crash <pid>` සමඟ එය අතින් ධාවනය කළ හැකිය.

මෙම නිරීක්ෂණය පෙරනිමියෙන් on වී ඇත. එය _Trigger > Toggle > Crash Capture_ යටතේ අක්‍රිය කරන්න (හෝ `omarchy toggle crash-capture` සමඟ) එවිට notifications නතර වේ; `omarchy agent crash <pid>` තවමත් අතින් ක්‍රියා කරයි.

Crashes එක් program එක බැගින් නිශ්ශබ්ද කළ හැකි අතර, diagnosis එක අවසානයේ ඔබට පිරිනමන්නේ එයයි. `omarchy crash mute hyprland` මගින් එම program එක සඳහා පමණක් notifications නවත්වන අතර, `omarchy crash mute hyprland off` මගින් ඒවා ආපසු ගෙන එන අතර, `omarchy crash mute` තනිවම ඔබ නිශ්ශබ්ද කළ දේ ලැයිස්තුගත කරයි. එය binary එකේ path එක එහි නම තරමටම සතුටින් පිළිගන්නා බැවින්, `omarchy crash mute /usr/bin/hyprland` මගින් එකම දේ කරයි. එහි space එකක් ඇති නමක් quote කරන්න, උදාහරණයක් ලෙස `omarchy crash mute 'Some App'`. අනෙක් සියල්ල තවමත් දැනුම් දෙන අතර, නිශ්ශබ්ද කළ program එක තවමත් crash වේ — මෙය reminder එක සඟවයි, එය කිසිවක් නිවැරදි නොකරයි.

### Local LLMs

Omarchy විසින් local LLM models ධාවනය කිරීමේ ක්‍රම දෙකක් නිර්දේශ කරයි: LM Studio සහ Ollama. LM Studio විසින් open-weight models සොයා ගැනීමට, ඒවා ස්ථාපනය කිරීමට, සහ ඒවා ධාවනය කිරීමට GUI interface එකක් සපයයි. එය පහසුවෙන් ආරම්භ කිරීමට කදිම ක්‍රමයකි. Ollama විසින් ඒ හා සමානව කිරීමට CLI එකක් ලබා දෙයි. නමුත් ඔබ local models වලට අලුත් නම්, මම LM Studio සමඟ ආරම්භ කරමි. ඔබට Omarchy Menu එකේ _Install > AI_ යටතේ දෙකෙන් ඕනෑම එකක් ස්ථාපනය කළ හැකිය.

### The Omarchy Skill

Agent skills මගින් AI වලට නිශ්චිත මෙවලම් නිශ්චිත ආකාරයකින් භාවිත කිරීමට උපකාරී වන අතර, Omarchy පද්ධතිය සකස් කිරීම සඳහා පෙරනිමි skill එකක් සමඟ පැමිණේ. ඔබේ Hyprland config එක tweak කිරීම, bar එක සකස් කිරීම, හෝ මුල සිටම නව theme එකක් නිර්මාණය කිරීම වැනි. එය Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ එක් එක් `~/.hermes/profiles/*/skills`), සහ සාමාන්‍ය `~/.agents/skills` ස්ථානය සඳහා skill directories තුළට symlink කර ඇති බැවින්, බොහෝ harnesses එය ස්වයංක්‍රීයව ලබා ගනී.

නමුත් ඔබ මෙම skill එක පරීක්ෂණාත්මක එකක් ලෙස සැලකිය යුතුය. විවිධ models එය විවිධ ප්‍රතිඵල සඳහා භාවිත කරනු ඇත. agent එක වෙනස් කිරීමට කැමති දේ පිළිබඳ අදහසක් ඔබට ලැබෙන පරිදි, පළමුව plan mode එකේ ධාවනය කිරීම වඩාත් සුදුසුය. ඉන්පසු agent එක සියල්ල අවුල් කළහොත්, වෙනස්කම් rollback කිරීමට හෝ `omarchy reinstall configs` පවා භාවිත කිරීමට සූදානම් වන්න.
