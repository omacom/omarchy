# AI

Omarchy විසින් පහත කේතකරණ නියෝජිතයන් සඳහා දියත්කරණයන් ඇතුළත් කරන නමුත් ඔබට පෙරනිමියක් තෝරා දෙන්නේ නැත. පළමු භාවිතයේදී එහි CLI ස්ථාපනය කිරීමට විධානයක් ධාවනය කරන්න, පසුව අසන විට සත්‍යාපනය කරන්න. ### නියෝජිතයන් ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes සහ OpenClaw හැර, මෙම නියෝජිතයන් mise හි lazy ස්ථාපනය භාවිත කරයි: පළමු දියත් කිරීම CLI ස්ථාපනය කරයි, පසුව දියත් කිරීම් එය නැවත භාවිත කරයි. mise ද ස්ථාපිත නියෝජිතයෙකු නව නිකුතුවක් සඳහා පරීක්ෂා කරන්නේ උපරිම වශයෙන් සෑම පැය හතරකටම වරක්, එය ආරම්භ වීමට මොහොතකට පෙර හෝ shell prompt එකක පසුබිමේය. එම යාවත්කාලීන කිරීම අසාර්ථක වුවහොත් හෝ ඔබ නොබැඳි නම්, ස්ථාපිත අනුවාදය ධාවනය වේ. `omarchy update` මඟින් Omarchy හි ඉතිරිය සමඟ ස්ථාපිත නියෝජිතයන් යාවත්කාලීන කරයි, සහ `mup` මඟින් යාවත්කාලීන කරන්නේ mise-කළමනාකරණය වන මෙවලම් පමණි.

නියෝජිතයෙකුගේම updater එක, උදාහරණයක් ලෙස `claude update`, `codex update`, හෝ යෙදුමක update බොත්තම, mise-කළමනාකරණය වන ස්ථාපනය යාවත්කාලීන නොකරයි. `codex update` අසාර්ථක වේ, සහ `claude update` මඟින් සාර්ථක බව වාර්තා කරමින් mise විසින් නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කළ හැකිය. ඔබ නියෝජිතයෙකුගේ native installer සහ updater භාවිත කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [කලින් ස්ථාපනය කළ CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

ඔබට අවශ්‍ය වීමට පෙර සියලුම වින්‍යාස කළ lazy මෙවලම් ස්ථාපනය කිරීමට, `mise install --include-lazy` ධාවනය කරන්න. මෙයට නියෝජිතයන් මෙන්ම Omarchy හි අනෙකුත් පෙරනිමි CLI මෙවලම් ද ඇතුළත්ය. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිත කිරීම සඳහා [කලින් ස්ථාපනය කළ CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` ස්ථාපනය කරන්නේ mise හි first-party `grok` package හරහාය, `claude` සහ `codex` ආකාරයටමය. `grok` ධාවනය කරන්න, නැතහොත් agents පැනලයේ එයට තරුව දමන්න. x.ai හි `curl | bash` installer එක මඟ හරින්න. එම මාර්ගය `~/.grok/bin` හි දෙවන පිටපතක් තබයි, එය `PATH` මත ඉදිරියට දමයි, සහ Omarchy හි wrapper එක උඩින් ලියයි.

`dsh` එහි browser UI එක `127.0.0.1:3080` මත විවෘත කරයි, දියත් කළ directory එක එහි පෙරනිමි workspace එක ලෙසය. එහි browser UI එක ආරම්භක prompt එකක් නොගනී, එබැවින් `omarchy agent prompt` එය විවෘත කරන්නේ ඔබේ clipboard එකේ ඇති prompt එක ඇලවීමට තබාය. Omarchy එය ආරම්භ කරන්නේ DeepSeek හි no-approval permission preset එක සමඟය. DeepSeek Harness ඔබ එහි official model API එක භාවිත කරන විට session logs DeepSeek වෙත upload කරයි; එහි browser UI එකේ _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ එයට එවන Feedback ද session එක සමඟ upload කෙරේ, ඔබ එය `DSH_TELEMETRY_MODE=DISABLED` සමඟ ආරම්භ නොකළහොත්.

### පෙරනිමි නියෝජිතයා

agents පැනලයේ නියෝජිතයෙකු අසල ඇති තරුවෙන් ඔබේ පෙරනිමි නියෝජිතයා තෝරන්න, එය පෙරනිමිය මත පිරී ඇත, නැතහොත් `omarchy default agent <name>` සමඟ, එය එහි පේළියක් නැති ඕනෑම harness එකක් ද ගනී. නියෝජිතයා තවම ස්ථාපනය කර නොමැති නම්, එය තෝරා ගැනීම මුලින්ම එය ස්ථාපනය කරයි, සහ එයට app launcher එකේ Agent අසල එයටම වෙන් වූ launcher එකක් ද ලැබේ. අලුත් Omarchy එකක් එක් වරක් පමණක් එන දැනුම්දීමකින් එකක් සකසා ගැනීමට ඔබට ආරාධනා කරයි, එය agents පැනලය විවෘත කරයි.

Claude තෝරා ගැනීම Chromium, Chrome, Brave, Brave Origin, සහ Edge සඳහා එහි browser extension එක සකසා ගැනීමට ද උත්සාහ කරයි. Extension සැකසුම සියලුම පරිශීලකයන්ට අදාළ වන අතර ඔබේ system password එක ඉල්ලා සිටිය හැකිය; අවලංගු කිරීම හෝ අසාර්ථක extension ස්ථාපනයක් වුවද Claude තෝරා ගෙන දියත් කරයි. ඔබේ browser එක restart කරන්න, අසන විට extension එක enable කරන්න, සහ එය සම්බන්ධ කිරීම අවසන් කිරීමට Claude වෙත sign in කරන්න. සම්බන්ධතාව පරීක්ෂා කිරීමට Claude හි `/chrome` ධාවනය කරන්න. ඔබ සකස් කරන සෑම model එකකටම local models පැනලයේ එහිම පේළිය ලැබේ: එය ආරම්භ කිරීමට play, එය නවත්වා එහි memory එක නිදහස් කිරීමට pause, සහ ඔබේ agent එය මත විවෘත කිරීමට terminal බොත්තම. ඉහළින් පුරා, bar එකක් machine හි memory එක Omarchy ම (system එක සහ ඔබේ apps), ධාවනය වන සෑම model එකක්ම, සහ නිදහස් දේ අතර බෙදී ඇති ආකාරය පෙන්වයි. නවතා ඇති model එකක් වෙත යොමු කරන්න සහ bar එක එය ගැලපෙනවාද, නැතහොත් එය කොපමණ අඩුද යන්න පෙන්වයි. ඒවා memory එකේ එකට ගැලපෙන විට කිහිපයක් එකවර ධාවනය විය හැකිය; එකක් නොගැලපේ නම්, Omarchy නවත්විය යුතු ධාවනය වන model එක කියයි. ඒවා නැවත සකස් කිරීමට පේළි ඒවායේ logo එකෙන් drag කරන්න, සහ තෝරාගත් පේළියක Delete ඔබා model එකක් සහ එහි download එක ඉවත් කරන්න.

ඔබ සකස් කරන සෑම coding model එකකටම app launcher එකේ එහිම entry එකක් ලැබේ, model හි නම යටතේ සහ එහි නිෂ්පාදකයාගේ logo එක සමඟ, Claude, Codex හෝ Grok වෙත sign in වීම එකක් එක් කරන ආකාරයටම. එය එම model එක මත ඔබේ agent විවෘත කරයි, සහ එය ධාවනය නොවන්නේ නම් මුලින්ම model එක ආරම්භ කරයි: terminal එක එය loading වන ආකාරය පෙන්වා එය සූදානම් වූ පසු agent වෙත භාර දෙයි. model එකක් ඉවත් කිරීම එහි entry එක ඉවත් කරයි.

command line එකෙන්, `omarchy models start <recipe>` සහ `omarchy models stop <recipe>` එම දෙයම කරයි, `omarchy models status` සෑම model එකක්ම පෙන්වයි, සහ `omarchy agent --local-model <recipe>` ඔබේ පෙරනිමි නියෝජිතයා කුමක් වුවත් එම model එක pi හි විවෘත කරයි. ඔබේ local model එක agent hotkey එක, Quake console එක, සහ _Make something_ විවෘත කරන දෙය කිරීමට, `omarchy default agent local` ධාවනය කරන්න නැතහොත් agents පැනලයේ ධාවනය වන model එකකට තරුව දමන්න. pi ඔබ සකස් කළ සෑම model එකක්ම, සහ ඔබ pair කළ machines වල ඒවාද, එහිම model picker එකේ ලැයිස්තු කරයි, එබැවින් සරල `pi` ද ඒවාට ළඟා වේ. ඕනෑම OpenAI-compatible client එකකට ද සම්බන්ධ විය හැකිය: `status` සෑම model එකකම address එක පෙන්වයි (පළමුවැන්න `http://127.0.0.1:11435/v1`), recipe නම model එකයි, සහ key එක `~/.config/omarchy/agent-local/key` හි ඇත.

`omarchy models remove <recipe>` model එකක් සහ වෙනත් කිසිම model එකක් භාවිත නොකරන downloads මකා දමයි.

Third-party runtimes ඒවායේ publisher සමඟ label කෙරේ. Omarchy සෑම model එකක්ම network access නොමැතිව ධාවනය කරයි.

### දේශීය LLMs

Omarchy දේශීය LLM models ධාවනය කිරීමේ ක්‍රම දෙකක් නිර්දේශ කරයි: LM Studio සහ Ollama. LM Studio open-weight models සොයා ගැනීම, ඒවා ස්ථාපනය කිරීම, සහ ධාවනය කිරීම සඳහා GUI interface එකක් සපයයි. එය පහසුවෙන් ආරම්භ කිරීමට හොඳ ක්‍රමයකි. Agent skills AI හට නිශ්චිත tools නිශ්චිත ආකාරයකින් භාවිත කිරීමට උපකාර කරයි, සහ Omarchy ඒවායින් හතක් යවයි. omarchy skill එක system එක සකස් කිරීම ආවරණය කරයි, ඔබේ Hyprland config එක tweak කිරීම හෝ bar එක adjust කිරීම වැනි. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app, සහ omarchy-make-game අලුත් දෙයක් සෑදීම ආවරණය කරයි, omarchy-contribute bug එකක් වාර්තා කිරීම හෝ fix එකක් upstream යැවීම ආවරණය කරයි, සහ omarchy-diagnose-crash බිඳ වැටීමක core dump එක හරහා ක්‍රියා කරයි. ඒවා Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ සෑම `~/.hermes/profiles/*/skills`), සහ generic `~/.agents/skills` ස්ථානය සඳහා skill directories වලට symlink කර ඇත, එබැවින් බොහෝ harnesses ඒවා ස්වයංක්‍රීයව අල්ලා ගනී. එකම නම ඇති ඔබේම skill folder එකක් පෙරමුණ ගනී.

නමුත් ඔබ මෙම skills පර්යේෂණාත්මක ලෙස සැලකිය යුතුය. විවිධ models එය විවිධ ප්‍රතිඵල සඳහා භාවිත කරනු ඇත. නියෝජිතයා වෙනස් කිරීමට කැමති දේ පිළිබඳ අදහසක් ඔබට ඇති වන පරිදි plan mode එකේ මුලින්ම ධාවනය කිරීම වඩාත් සුදුසුය. සහ ඉන්පසු නියෝජිතයා සියල්ල අවුල් කළහොත්, වෙනස්කම් rollback කිරීමට හෝ `omarchy reinstall configs` පවා ක්‍රියාත්මක කිරීමට සූදානම් වන්න.
