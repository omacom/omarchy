# AI

Omarchy විසින් ඔබට පෙරනිමියක් තෝරා නොදී පහත කේතීකරණ නියෝජිතයන් සඳහා දියත් කරන්නන් ඇතුළත් කරයි. පළමු වරට භාවිතයේදී එහි CLI ස්ථාපනය කිරීමට විධානයක් ධාවනය කරන්න, පසුව විමසූ විට සත්‍යාපනය කරන්න. Hermes සහ OpenClaw යනු ව්‍යතිරේක වේ: mise හරහා ඒවා සඳහා කිසිවක් ස්ථාපනය නොකෙරේ, ඒ දෙකෙන් ඕනෑම එකක් තෝරා ගැනීමෙන් එහිම ස්වයං-යාවත්කාලීන වන පිටපතක් සකසනු ලැබේ, පහත _Desktop apps_ හි පැහැදිලි කර ඇති පරිදි.

### නියෝජිතයන් ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes සහ OpenClaw හැර, මෙම නියෝජිතයන් mise හි lazy ස්ථාපනය භාවිතා කරයි: පළමු දියත් කිරීමේදී CLI ස්ථාපනය වන අතර, පසුකාලීන දියත් කිරීම්වලදී එයම නැවත භාවිතා කරයි. තවද mise විසින් ස්ථාපිත නියෝජිතයෙකු සඳහා නව නිකුතුවක් තිබේදැයි උපරිම වශයෙන් සෑම පැය හතරකටම වරක්, එය ආරම්භ කිරීමට මොහොතකට පෙර හෝ shell prompt එකකදී පසුබිමෙන් පරීක්ෂා කරයි. එම යාවත්කාලීන කිරීම අසාර්ථක වුවහොත් හෝ ඔබ offline නම්, ස්ථාපිත අනුවාදය ධාවනය වේ. `omarchy update` විසින් Omarchy හි ඉතිරි කොටස් සමඟ ස්ථාපිත නියෝජිතයන් යාවත්කාලීන කරන අතර, `mup` විසින් mise මගින් කළමනාකරණය වන මෙවලම් පමණක් යාවත්කාලීන කරයි.

`claude update`, `codex update`, හෝ app එකක ඇති update බොත්තමක් වැනි නියෝජිතයෙකුගේම updater එකක්, mise මගින් කළමනාකරණය වන ස්ථාපනය යාවත්කාලීන නොකරයි. `codex update` අසාර්ථක වන අතර, `claude update` විසින් සාර්ථක බව වාර්තා කළ හැකි වුවද mise විසින් නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කළ හැකිය. ඔබ නියෝජිතයෙකුගේ native installer සහ updater එක භාවිතා කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

ඔබට අවශ්‍ය වීමට පෙර වින්‍යාස කර ඇති සියලුම lazy මෙවලම් ස්ථාපනය කිරීමට, `mise install --include-lazy` ධාවනය කරන්න. මෙයට නියෝජිතයන්ට අමතරව Omarchy හි අනෙකුත් පෙරනිමි CLI මෙවලම්ද ඇතුළත් වේ. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිතා කිරීම සඳහා [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` ස්ථාපනය කරනු ලබන්නේ mise හි first-party `grok` package එක හරහා, `claude` සහ `codex` ආකාරයටමයි. `grok` ධාවනය කරන්න, නැතහොත් agents පැනලයේ එය තරු ලකුණු කරන්න. x.ai හි ඇති `curl | bash` installer එක මඟ හරින්න. එම මාර්ගය මඟින් `~/.grok/bin` හි දෙවන පිටපතක් තබන අතර, එය `PATH` හි මුලට දමා, Omarchy හි wrapper එක උඩින් ලියයි.

`dsh` විසින් එහි browser UI එක `127.0.0.1:3080` මත විවෘත කරන අතර, දියත් කළ directory එක එහි පෙරනිමි workspace එක වේ. එහි browser UI එක ආරම්භක prompt එකක් නොගන්නා බැවින්, `omarchy agent prompt` විසින් එය විවෘත කරන්නේ prompt එක ඔබගේ clipboard එකේ අලවා ගැනීමට තබාය. Omarchy විසින් එය DeepSeek හි no-approval permission preset එක සමඟ ආරම්භ කරයි. ඔබ එහි නිල model API එක භාවිතා කරන විට DeepSeek Harness විසින් session ලොග DeepSeek වෙත උඩුගත කරයි; එහි browser UI එකේ _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ එයට එවන ප්‍රතිපෝෂණද session එක සමඟම උඩුගත කෙරේ, ඔබ එය `DSH_TELEMETRY_MODE=DISABLED` සමඟ ආරම්භ නොකළහොත් පමණි.

### පෙරනිමි නියෝජිතයා

Agents පැනලයේ නියෝජිතයෙකු අසල ඇති තරුවෙන්, පෙරනිමි නියෝජිතයා මත එය පුරවා ඇති අතර, හෝ එහි සඳහනක් නැති ඕනෑම harness එකක්ද ගන්නා `omarchy default agent <name>` මඟින් ඔබගේ පෙරනිමි නියෝජිතයා තෝරන්න. නියෝජිතයා තවම ස්ථාපනය කර නොමැති නම්, එය තෝරා ගැනීමෙන් පළමුව එය ස්ථාපනය වන අතර, එයට app launcher එකේ Agent අසලම තමන්ගේම launcher එකක්ද ලැබේ. නැවුම් Omarchy එකක් විසින් agents පැනලය විවෘත කරන එක් වරක් පමණක් දිස්වන දැනුම්දීමක් සමඟ එකක් සකසා ගන්නා ලෙස ඔබට ආරාධනා කරයි.

Claude තෝරා ගැනීමෙන් Chromium, Chrome, Brave, Brave Origin, සහ Edge සඳහා එහි browser extension එක සකසා ගැනීමටද උත්සාහ කරයි. Extension සැකසුම සියලුම පරිශීලකයන්ට අදාළ වන අතර ඔබගේ system password එක ඉල්ලා සිටිය හැකිය; අවලංගු කිරීම හෝ අසාර්ථක extension ස්ථාපනයක් වුවද Claude තෝරාගෙන දියත් කරයි. ඔබගේ browser එක නැවත ආරම්භ කරන්න, විමසුවහොත් extension එක සක්‍රිය කරන්න, සහ එය සම්බන්ධ කිරීම අවසන් කිරීමට Claude වෙත sign in වන්න. සම්බන්ධතාව පරීක්ෂා කිරීමට Claude හි `/chrome` ධාවනය කරන්න. Firefox සහ Zen මෙම extension එකට සහාය නොදක්වයි. මෙම සැකසුම එක් කිරීමට පෙර Claude දැනටමත් ඔබගේ පෙරනිමිය වී තිබුණේ නම්, extension එක ස්ථාපනය කිරීමට එය නැවත තෝරන්න.

Freebuff සහ DeepSeek Harness ආරම්භක prompt එකක් නොගන්නා බැවින්, ඒ වෙනුවට ඒවා විවෘත වන්නේ prompt එක ඔබගේ clipboard එකේ අලවා ගැනීමට තබාය. මේ ආකාරයෙන් දියත් කරන නියෝජිතයන් ඔවුන්ගේ අදාළ don't-stop-to-ask ආකාරවලින් නොසැලකිලිමත්ව ධාවනය වේ, එබැවින් ඔවුන් සැබවින්ම දේවල් කිරීමට සූදානම්ව සිටින්න! MiniMax Code හි එහි interactive sessions සඳහා එවැනි ආකාරයක් නොමැත, එබැවින් එය සුපුරුදු පරිදි අවසර ඉල්ලයි. තවද නියෝජිතයන් ඔබගේ home directory එක සඳහා trust එක මතක තබා ගැනීම ප්‍රතික්ෂේප කරන බැවින්, `$HOME` සිට කරන දියත් කිරීම් ඒ වෙනුවට `~/Work` හි ආරම්භ වේ.

### Agents පැනලය

Top bar එකේ agents නිරූපකයක් තිබේ. ඔබ නියෝජිතයෙකු සකසා ගැනීමට පෙර, එහි පැනලය ආරම්භ කිරීමට ක්‍රම තුනක් ඉදිරිපත් කරයි: Claude, Codex, Grok, Gemini, Muse, Cursor, හෝ Copilot දායකත්වයකට sign in වන්න, නැතහොත් More යටතේ OpenCode Go, MiniMax, Synthetic, හෝ Z.ai coding plan එකකට sign in වන්න; Fireworks, OpenCode Zen සහ Go, OpenRouter සමඟ pay as you go කරන්න, නැතහොත් More යටතේ DeepSeek හෝ OpenCode sign in වන වෙනත් ඕනෑම provider එකක් සමඟ, ඒ සියල්ල OpenCode හි ධාවනය වේ; නැතහොත් ඔබගේ පරිගණකයට ගැලපෙන එකක් ඇති විට, ඒ සඳහා හොඳම model එක ධාවනය කරන්න. ඔබ අවසන් කරන පළමු එක ඔබගේ පෙරනිමි නියෝජිතයා බවට පත්වන අතර, පැනලයේ ඇති + පසුවද එම තුනම ඉදිරිපත් කරයි. ඉන් පසු, පැනලය සෑම දායකත්වයක්ම එක් පිටුවක තබයි: එක් එක් නියෝජිතයා සහ ගිණුම එහි plan එක සමඟ, එහි 5-hour session සහ weekly සීමාවන් එක් එක් සඳහා meter එකක් ඒවා reset වීමට ඇති කාලය සමඟ (හරියටම ප්‍රතිශතය සඳහා hover කරන්න), නැතහොත් ඉතිරි වූ prepaid ශේෂය, ඔබ ඒ සියල්ල හරහා භාවිතා කළ දේ හරහා භ්‍රමණය වන පේළියක් යට, මෙම සතියේ tokens සහ ඔබ වැඩිපුරම භාවිතා කළ model එක වැනි. _Make something cool_ යටතේ එය ඔබගේ පෙරනිමි නියෝජිතයාට කාර්යය භාර දෙන නව theme එකක්, plugin එකක්, app එකක්, හෝ game එකක් සඳහා starter prompts ඉදිරිපත් කරයි. Apps ගොඩනගනු ලබන්නේ Omarchy හිම Hype, Monologue, සහ Omacut ආකාරයට, C++ සහ Qt Quick හි, omarchy-make-app agent skill එක අනුගමනය කරමින් වන අතර, ඔවුන්ට අවශ්‍ය compiler සහ Qt කොටස් ස්ථාපනය කර තිබේ. Games යනු omarchy-make-game agent skill එක අනුගමනය කරමින් `~/Games/vibes` හි ඇති තනි three.js පිටුවක් වන අතර, ඒ සියල්ල වත්මන් theme එකේ ඇති එක් Game Vibes launcher එකකින් විවෘත වේ; ඒවා වෙබයෙන් three.js load කරන බැවින්, ආරම්භ වීමට ඒවාට සම්බන්ධතාවක් අවශ්‍ය වේ. Claude Code, Codex, Grok, Kimi, Cursor සහ එහි Grok Bot දීමනාව, GitHub Copilot, Muse, Gemini (Antigravity හරහා), සහ Devin ඔවුන්ගේ සීමාවන් සමඟ out of the box ආවරණය කෙරේ, Kimchi එහි plan එක, prepaid credits, සහ spend budgets සමඟ, තවද Hermes, Mistral Vibe, සහ Qwen Code ඔබ ඒවා භාවිතා කළ පසු ඔවුන්ගේ sessions සහ tokens පෙන්වයි. ඔබ pi, omp, හෝ opencode හරහා භාවිතා කරන Provider plans සහ keysද දිස් වේ: OpenCode Zen සහ Go, Z.ai GLM Coding Plan එක, Ollama Cloud, MiniMax Token Plan එක, සහ Synthetic ඔවුන්ගේ සීමාවන් සමඟ; OpenRouter සහ DeepSeek ඔවුන්ගේ prepaid ශේෂයන් සමඟ; Fireworks පසුගිය දින 30 තුළ එහි වියදම සමඟ. ඔබ ඔබේම hardware මත ධාවනය කරන Coding models වලට තමන්ගේම පේළි ලැබෙන අතර, ඒවායේ tokensද එකතුවලට ගණන් ගැනේ, [දේශීය මාදිලි](#local-models) යටතේ විස්තර කර ඇති පරිදි. ඔබ එය කොපමණ harness ගණනක් හරහා ධාවනය කළද, සෑම නියෝජිතයෙකුම එක් වරක්, එයට බිල් කරන ඕනෑම අයෙකු යටතේ ගණන් ගැනේ.

### දායකත්ව කිහිපයක්

ඔබ Claude, Codex, හෝ Grok plans එකකට වැඩියෙන් ගෙවන්නේ නම් — උදාහරණයක් ලෙස පෞද්ගලික Max එකක් සහ වැඩ එකක් — Omarchy විසින් ඒවා සියල්ලම sign in කර තබාගෙන ඒ අතර මාරු විය හැකිය. Agents පැනලයේ ඇති + සමඟ දායකත්වයක් එක් කරන්න, එය එතැනින්ම ඔබව ඒ හරහා ගෙන යයි, නැතහොත් `omarchy agent account add claude Work` සමඟ (හෝ `codex`, හෝ `grok`). එම + සහ විධානයම Gemini (`gemini`) සහ OpenCode (`opencode`) වෙත sign in වන අතර, OpenCode හි Fireworks (`fireworks`) හෝ OpenRouter (`openrouter`) API key එකක් සුරකියි; එම විධානය Copilot (`copilot`), Cursor (`cursor`), සහ Muse (`muse`) වෙතද sign in වේ. ඒවා එක් එක් sign-in එකක් බැගින් තබා ගනී. CLI එක නොමැති නම් එය ස්ථාපනය කරයි. ### බිඳ වැටීම් හඳුනා ගැනීම

Omarchy විසින් process බිඳ වැටීම් සඳහා systemd-coredump නිරීක්ෂණය කරයි. ඔබ පෙරනිමි නියෝජිතයෙකු තෝරා ගත් පසු, core dump කරන ඔබගේ ඕනෑම program එකක් "Process crashed" දැනුම්දීමක් ගෙන එයි — එය click කරන්න, සහ බිඳ වැටීම ඔබගේ පෙරනිමි නියෝජිතයාට භාර දෙනු ලබන්නේ Omarchy හි omarchy-diagnose-crash skill එක සමඟිනි, එය core dump එකෙන් කරුණු තහවුරු කර ගනිමින් බිඳ වැටීම upstream වෙත වාර්තා කිරීම වටිනවාද යන්න තීරණය කිරීම හරහා නියෝජිතයා ගෙන යයි. `omarchy agent crash <pid>` සමඟ `coredumpctl list` වෙතින් ලැබෙන ඕනෑම PID එකකට එරෙහිව ඔබට එය අතින්ද ධාවනය කළ හැකිය.

මෙම නිරීක්ෂණය පෙරනිමියෙන් ක්‍රියාත්මක වේ. එය _Trigger > Toggle > Crash Capture Off_ යටතේ අක්‍රිය කරන්න (හෝ `omarchy toggle crash-capture` සමඟ) සහ දැනුම්දීම් නතර වේ; `omarchy agent crash <pid>` තවමත් අතින් ක්‍රියා කරයි.

### Desktop apps

_Install > AI_ මෙනුව තවද චිත්‍රක AI apps කිහිපයක්ද රැගෙන යයි: Amp Desktop, Antigravity Desktop, ChatGPT desktop app එක, Claude desktop app එක (Chat, Cowork, සහ Claude Code tabs සහිත Anthropic හි Linux beta එක), xAI හි models සමඟ chat කිරීමට Grok Bot, Herdr Desktop, Hermes Desktop, OpenClaw, Perplexity desktop app එක, සහ T3 Code. Grok Bot යනු desktop chat app එකයි. කේතීකරණ නියෝජිතයා යනු `grok` විධානයයි.

ඔබ එක් කරන coding model එකකට agents පැනලයේ, ඔබගේ දායකත්වයන් අසලම තමන්ගේම පේළියක් ලැබේ: එය ආරම්භ කිරීමට play, එය නවතා එහි මතකය නිදහස් කිරීමට pause, එය ධාවනය වන අතරතුර ඔබගේ tailnet එකේ අනෙකුත් machines සමඟ එය බෙදා ගැනීමට Tailscale ලකුණ, සහ ඔබගේ agent එක එහි විවෘත කිරීමට terminal බොත්තම. එහි පේළිය බාගත කිරීම, load කිරීම හෝ නතර කිරීම සිදුවන ආකාරයටම පෙන්වන අතර, එය ආරම්භ කිරීමට ප්‍රමාණවත් නිදහස් මතකයක් නොමැති විට එය එසේ කියයි, නැතහොත් එය error එකක් සමඟ නතර වූ විට එහි logs වෙත සම්බන්ධ කරයි. මතකය තුළ එකට ගැලපෙන විට කිහිපයක් එකවර ධාවනය විය හැකිය. Model එක මෙම machine එකෙන් ඉවත් කිරීමට, බාගත කිරීමද ඇතුළුව, තෝරාගත් පේළියක් මත Delete ඔබන්න; + මඟින් එය නැවත සකසා ගත හැකිය. Terminal එකකින් සකසා ඇති coding model එකක් ඔබ එය එක් කරන තුරු + යටතේ බලා සිටින අතර, ඔබ යුගල කර ඇති machine එකක් (`omarchy models pair <host>`) ධාවනය කරන modelsද එසේම වේ.

Model එකක් ඉවත් කිරීමෙන් එහි ප්‍රවේශය ඉවත් වේ.

සෑම model එකක්ම coding සඳහා නොවේ. Image, video සහ music models ඒ වෙනුවට මෙම machine එක මත ධාවනය වන model එකක් සමඟ pictures, video සහ music සෑදීමට ඇති Omarchy හි app එක වන Fantasi හි විවෘත වන අතර, එහි හෝ `omarchy models` සමඟ කළමනාකරණය කෙරේ.

Model එකක් සකසා ඇති ආකාරයටම හරියටම ධාවනය වෙමින් පවතින බැවින්, Omarchy update එකක් කිසිවිටෙක ඔබගේ agents යට එකක් නැවත ආරම්භ නොකරයි. ඔබ සකසා ඇති model එකක් සඳහා Omarchy සතුව නව runtime එකක් හෝ නව weights ඇති විට, එහි පේළිය update බොත්තමක් පෙන්වයි: එය ඔබන්න සහ model එක පසුබිමේ නැවත සකසා ගන්නා අතර, වෙනස් වූ දේ පමණක් බාගත කර, නව අනුවාදය මත නැවත ආරම්භ වේ. නවතා තිබූ model එකක් නවතා එලෙසම පවතී. `omarchy models update` terminal එකකින් සෑම model එකක් සඳහාම එයම කරයි.

Third-party runtimes ඒවායේ publisher සමඟ ලේබල් කර ඇත. Omarchy විසින් සෑම model එකක්ම network access නොමැතිව ධාවනය කරයි.

### දේශීය LLMs

Omarchy විසින් දේශීය LLM models ධාවනය කිරීමට ක්‍රම දෙකක් නිර්දේශ කරයි: LM Studio සහ Ollama. LM Studio විසින් open-weight models සොයා ගැනීමට, ඒවා ස්ථාපනය කිරීමට, සහ ඒවා ධාවනය කිරීමට GUI interface එකක් සපයයි. එය පහසුවෙන් ආරම්භ කිරීමට කදිම ක්‍රමයකි. Ollama විසින්ද ඒ හා සමානව කිරීමට CLI එකක් ඉදිරිපත් කරයි. නමුත් ඔබ local models වලට අලුත් නම්, මම LM Studio සමඟ ආරම්භ කරමි. ඔබට Omarchy Menu එකේ _Install > AI_ යටතේ ඒ දෙකෙන් ඕනෑම එකක් ස්ථාපනය කළ හැකිය.

### Omarchy skills

Agent skills මඟින් AI හට විශේෂිත මෙවලම් විශේෂිත ආකාරයකින් භාවිතා කිරීමට උපකාරී වන අතර, Omarchy ඒවායින් හතක් සපයයි. Omarchy skill එක මඟින් ඔබගේ Hyprland config එක tweak කිරීම හෝ bar එක adjust කිරීම වැනි system එක tailor කිරීම ආවරණය කරයි. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app, සහ omarchy-make-game මඟින් අලුත් දෙයක් සෑදීම ආවරණය කරන අතර, omarchy-contribute මඟින් bug එකක් වාර්තා කිරීම හෝ fix එකක් upstream වෙත යැවීම ආවරණය කරන අතර, omarchy-diagnose-crash මඟින් crash එකක core dump එක හරහා වැඩ කරයි. ඒවා Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ එක් එක් `~/.hermes/profiles/*/skills`), සහ සාමාන්‍ය `~/.agents/skills` ස්ථානය සඳහා වූ skill directories වලට symlinked කර ඇති බැවින්, බොහෝ harness ඒවා ස්වයංක්‍රීයව ලබා ගනී. එකම නම ඇති ඔබේම skill folder එකකට ප්‍රමුඛතාව ලැබේ.

නමුත් ඔබ මෙම skills අත්හදා බැලීමේ ඒවා ලෙස සැලකිය යුතුය. විවිධ models එය විවිධ ප්‍රතිඵල සඳහා භාවිතා කරනු ඇත. නියෝජිතයා වෙනස් කිරීමට කැමති දේ පිළිබඳ ඔබට අදහසක් ඇති වන පරිදි, පළමුව plan mode හි ධාවනය කිරීම වඩාත් සුදුසුය. ඉන්පසු නියෝජිතයා සියල්ල අවුල් කරතොත්, වෙනස්කම් rollback කිරීමට හෝ `omarchy reinstall configs` අමතීමට පවා සූදානම් වන්න.
