# AI

Omarchy විසින් ඔබට පෙරනිමියක් තෝරා දීමෙන් තොරව පහත කේතීකරණ ඒජන්තවරුන් සඳහා දියත් කරන්නන් ඇතුළත් කෙරේ. එහි CLI එක මුල්ම වර භාවිතයේදී ස්ථාපනය කිරීමට විධානයක් ධාවනය කරන්න, පසුව විමසූ විට සත්‍යාපනය කරන්න. Hermes සහ OpenClaw මෙයට ව්‍යතිරේකයන්ය: mise හරහා ඒවා සඳහා කිසිවක් ස්ථාපනය නොකෙරේ, ඒවා දෙකෙන් ඕනෑම එකක් තෝරාගැනීමෙන් එහිම ස්වයං-යාවත්කාලීන වන පිටපත පිහිටුවනු ලැබේ, පහත _Desktop apps_ හි පැහැදිලි කර ඇති පරිදිය.

### ඒජන්තවරුන් ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes සහ OpenClaw හැර, මෙම ඒජන්තවරු mise හි lazy ස්ථාපනය භාවිතා කරති: පළමු දියත් කිරීමේදී CLI එක ස්ථාපනය වන අතර, පසුව දියත් කිරීම්වලදී එයම නැවත භාවිතා වේ. mise විසින් ස්ථාපිත ඒජන්තයෙකු සඳහා නව නිකුතුවක් තිබේදැයි උපරිම වශයෙන් සෑම පැය හතරකට වරක්, එය ආරම්භ වීමට මොහොතකට පෙර හෝ shell prompt එකකදී පසුබිමේ පරීක්ෂා කරයි. එම යාවත්කාලීනය අසාර්ථක වුවහොත් හෝ ඔබ නොබැඳි නම්, ස්ථාපිත අනුවාදය ධාවනය වේ. `omarchy update` මගින් ස්ථාපිත ඒජන්තවරුන් Omarchy හි ඉතිරිය සමඟ යාවත්කාලීන කරයි, තවද `mup` මගින් යාවත්කාලීන කරන්නේ mise මගින් කළමනාකරණය වන මෙවලම් පමණි.

`claude update`, `codex update`, හෝ යෙදුමක ඇති update බොත්තම වැනි ඒජන්තයෙකුගේම යාවත්කාලීන කරන්නා, mise මගින් කළමනාකරණය වන ස්ථාපනය යාවත්කාලීන නොකරයි. `codex update` අසාර්ථක වන අතර, `claude update` විසින් සාර්ථක බව වාර්තා කරමින් mise විසින් නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කළ හැකිය. ඔබ ඒජන්තයෙකුගේ native installer සහ updater එක භාවිතා කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

පිහිටුවා ඇති සියලුම lazy මෙවලම් ඔබට අවශ්‍ය වීමට පෙර ස්ථාපනය කිරීමට, `mise install --include-lazy` ධාවනය කරන්න. මෙයට ඒජන්තවරුන් මෙන්ම Omarchy හි අනෙකුත් පෙරනිමි CLI මෙවලම්ද ඇතුළත් වේ. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිතා කිරීම සඳහා [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` ස්ථාපනය කරනු ලබන්නේ `claude` සහ `codex` මෙන්ම, mise හි first-party `grok` පැකේජය හරහාය. `grok` ධාවනය කරන්න, නැතහොත් එය _Agent > Harness_ යටතේ තෝරන්න. x.ai හි ඇති `curl | bash` ස්ථාපකය මඟ හරින්න. එම මාර්ගයෙන් `~/.grok/bin` හි දෙවන පිටපතක් තබන අතර, එය `PATH` හි ඉදිරියට ගෙන එමින් Omarchy හි wrapper එක උඩින් ලියනු ලැබේ.

`dsh` විසින් එහි browser UI එක `127.0.0.1:3080` මත විවෘත කරන අතර, දියත් කරන ලද නාමාවලිය එහි පෙරනිමි workspace එක වේ. එහි browser UI එක ආරම්භක prompt එකක් නොගන්නා බැවින්, `omarchy agent prompt` එය විවෘත කරන්නේ ඇලවීමට ඔබේ clipboard එකේ ඇති prompt එක සමඟය. Omarchy එය ආරම්භ කරන්නේ DeepSeek හි no-approval අවසර පෙරසිටුවම සමඟය. ඔබ එහි නිල model API එක භාවිතා කරන විට DeepSeek Harness විසින් session ලොග DeepSeek වෙත උඩුගත කරයි; එහි browser UI එකේ _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ එයට එවන ප්‍රතිපෝෂණයද session එක සමඟ උඩුගත කරනු ලැබේ, ඔබ එය `DSH_TELEMETRY_MODE=DISABLED` සමඟ ආරම්භ නොකළහොත් හැර.

### පෙරනිමි ඒජන්තයා

`omarchy default agent <name>` සමඟ හෝ Omarchy Menu එකේ (`Super + Space`) _Agent > Harness_ යටතේ ඔබේ පෙරනිමි ඒජන්තයා තෝරන්න. ඒජන්තයා තවම ස්ථාපනය කර නොමැති නම්, එය තෝරාගැනීමෙන් පළමුව එය ස්ථාපනය කරන අතර, එයට app launcher එකේ Agent අසලම එයටම වෙන් වූ දියත් කරන්නෙකුද ලැබේ. අලුත් Omarchy එකක් එක් වරක් පමණක් පෙන්වන නිවේදනයක් සමඟ මෙම තේරීම කිරීමට ඔබට ආරාධනා කරනු ඇත.

Claude තෝරාගැනීමෙන් Chromium, Chrome, Brave, Brave Origin, සහ Edge සඳහා එහි browser extension එක පිහිටුවීමටද උත්සාහ කරයි. Omarchy විසින් process බිඳවැටීම් සඳහා systemd-coredump නිරීක්ෂණය කරයි. ඔබ පෙරනිමි ඒජන්තයෙකු තෝරාගත් පසු, core dump කරන ඔබේ ඕනෑම වැඩසටහනක් “Process crashed” නිවේදනයක් ගෙන එයි — එය ක්ලික් කරන්න, එවිට බිඳවැටීම core dump එකෙන් කරුණු තහවුරු කර ගැනීම සහ බිඳවැටීම upstream වෙත වාර්තා කිරීම වටිනවාද යන්න තීරණය කිරීම හරහා ඒජන්තයා යොමු කරන Omarchy හි omarchy-diagnose-crash skill එක සමඟ ඔබේ පෙරනිමි ඒජන්තයා වෙත භාර දෙනු ලැබේ. `omarchy agent crash <pid>` සමඟ `coredumpctl list` වෙතින් ලැබෙන ඕනෑම PID එකකට එරෙහිව ඔබට එය අතින්ද ධාවනය කළ හැකිය.

මෙම නිරීක්ෂණය පෙරනිමියෙන් ක්‍රියාත්මකයි. _Trigger > Toggle > Crash Capture Off_ යටතේ (හෝ `omarchy toggle crash-capture` සමඟ) එය අක්‍රිය කළ විට නිවේදන නතර වේ; `omarchy agent crash <pid>` තවමත් අතින් ක්‍රියා කරයි.

බිඳවැටීම් එක් වැඩසටහන බැගින් නිහඬ කළද හැකිය, එය හඳුනාගැනීම අවසානයේදී ඔබට පිරිනමන්නේද එයයි. `omarchy crash mute hyprland` මගින් එම වැඩසටහන සඳහා පමණක් නිවේදන නතර කරන අතර, `omarchy crash mute hyprland off` මගින් ඒවා ආපසු ගෙන එයි, තවද `omarchy crash mute` තනිවම ඔබ නිහඬ කළ දේ ලැයිස්තුගත කරයි. එය binary එකේ නම තරමටම එහි මාර්ගයද සතුටින් භාර ගනියි, එබැවින් `omarchy crash mute /usr/bin/hyprland` ද එම දෙයම කරයි. `omarchy crash mute 'Some App'` හි මෙන්, හිස්තැනක් ඇති නමක් උද්ධෘත කරන්න. අනෙක් සියල්ල තවමත් දැනුම් දෙන අතර, නිහඬ කළ වැඩසටහන තවමත් බිඳ වැටේ — මෙයින් සැඟවෙන්නේ සිහිපත් කිරීම මිස, එය කිසිවක් නිවැරදි නොකරයි.

### Desktop apps

_Install > AI_ මෙනුව ද චිත්‍රක AI යෙදුම් කිහිපයක් රැගෙන යයි: Amp Desktop, Antigravity Desktop, ChatGPT desktop app එක, Claude desktop app එක (Chat, Cowork, සහ Claude Code tabs සමඟ Anthropic හි Linux beta එක), xAI හි models සමඟ කතාබස් කිරීමට Grok Bot, Herdr Desktop, Hermes Desktop, OpenClaw, Perplexity desktop app එක, සහ T3 Code. Grok Bot යනු desktop chat app එකයි. කේතීකරණ ඒජන්තයා යනු `grok` විධානයයි.

Hermes Desktop යනු දැනගත යුතු එකකි, මන්ද යන්ත්‍රයක එක් Hermes එකක් ඇති අතර, එය app එකේ එකයි: Hermes ස්ථාපනය කරන්නේ සෑමවිටම app එක හරහා පමණක් වන අතර, පෙරනිමි ඒජන්තයා ධාවනය කරන `hermes` විධානය වන්නේ app එකේ එකයි. පෙරනිමි ඒජන්තයා ලෙස Hermes තෝරාගැනීමෙන් ස්ථාපනය වන්නේ _Install > AI_ ප්‍රවේශයෙන් ස්ථාපනය වන එම දෙයමයි: පැකේජය, සහ Hermes හිම ස්ථාපකය මගින් පිහිටුවනු ලබන `~/.hermes` යටතේ ඇති Hermes runtime එක, එය පළමු වරට මිනිත්තු කිහිපයක් ගත වේ. එම runtime එක වන්නේ terminal `hermes` විධානය, පෙරනිමි ඒජන්තයා සහ app එක යන සියල්ලම භාවිතා කරන එකම Hermes වන අතර, එය Omarchy නිකුතුවක් එනතෙක් බලා නොසිට `hermes update` සමඟ තනිවම යාවත්කාලීන වේ. එය ස්ථාපනය කිරීමෙන් Hermes වෙත Omarchy තේමාව `omarchy` නමින් skin එකක් ලෙසද භාර දෙන අතර, ඔබ තේමා මාරු කරන විට සෑම Hermes පෘෂ්ඨයක්ම එය අනුගමනය කරයි; ඔබට එය එසේ නොවීමට අවශ්‍ය නම් Hermes හි Appearance සැකසුම් යටතේ හෝ `/skin` සමඟ වෙනත් එකක් තෝරන්න, Omarchy එම තේරීම එලෙසම තබයි. _Remove > AI_ යටතේ app එක ඉවත් කිරීමෙන් පළමුව gateway එක ඇතුළුව Hermes වසා, එම runtime එක එය සමඟ රැගෙන යන අතර, ඔබ වෙනත් ලෙස නොකියන්නේ නම් ඔබේ කතාබස්, මතකයන්, සහ Hermes විසින් තමාටම ලියන ලද skills තබාගනියි: එම දත්ත සහ ඔබේ සම්බන්ධතා සැකසුම්ද යා යුතුදැයි එය විමසන අතර, පෙරනිමිය නැත යන්නයි.

OpenClaw හි desktop අත්දැකීම වන්නේ එහිම දේශීය gateway එකකින් පිටුබල ලබන web app එකක් ලෙස විවෘත වන එහි Control UI එකයි. OpenClaw `~/.openclaw` හි ජීවත් වන අතර තනිවම යාවත්කාලීන වේ: Control UI හි “Update Gateway” බොත්තම භාවිතා කරන්න හෝ `openclaw update` ධාවනය කරන්න, එවිට gateway එක නව අනුවාදය මත නැවත ආරම්භ වේ. ඔබ පිහිටුවන සෑම model එකකටම දේශීය models පැනලයේ එයටම වෙන් වූ රේඛාවක් ලැබේ: එය ආරම්භ කිරීමට play, එය නතර කර එහි මතකය නිදහස් කිරීමට pause, සහ එය මත ඔබේ ඒජන්තයා විවෘත කිරීමට terminal බොත්තම. ඉහළින් පුරා, තීරුවක් මඟින් යන්ත්‍රයේ මතකය Omarchy ම (පද්ධතිය සහ ඔබේ apps), ධාවනය වන එක් එක් model එක, සහ නිදහස්ව ඇති දේ අතර බෙදී ඇති ආකාරය පෙන්වයි. නතර කළ model එකක් වෙත යොමු කළ විට එය ගැළපෙනවාද, නැතහොත් කොපමණ අඩුවක් තිබේදැයි තීරුව පෙන්වයි. ඒවා එකට මතකයට ගැළපෙන විට කිහිපයක් එකවර ධාවනය විය හැකිය; එකක් නොගැළපේ නම්, නවත්විය යුතු ධාවනය වන model එක කුමක්දැයි Omarchy කියයි. ඒවායේ logo එකෙන් රේඛා ඇදගෙන යාමෙන් ඒවා යළි පිළිවෙළට සකසන්න, සහ model එකක් සහ එහි බාගත කිරීම ඉවත් කිරීමට තෝරාගත් රේඛාවක් මත Delete ඔබන්න.

ඔබ පිහිටුවන සෑම කේතීකරණ model එකකටම, Claude, Codex හෝ Grok වෙත පුරනය වීමෙන් එකක් එක් කරන ආකාරයටම, එහි නිෂ්පාදකයාගේ logo එක සමඟ model එකේ නම යටතේ app launcher එකේ එයටම වෙන් වූ ප්‍රවේශයක්ද ලැබේ. එය එම model එක මත ඔබේ ඒජන්තයා විවෘත කරන අතර, එය ධාවනය නොවන්නේ නම් පළමුව model එක ආරම්භ කරයි: terminal එක එය පූරණය වන ආකාරය පෙන්වා එය සූදානම් වූ පසු ඒජන්තයා වෙත භාර දෙයි. Model එකක් ඉවත් කිරීමෙන් එහි ප්‍රවේශය ඉවත් වේ.

සෑම model එකක්ම කේතීකරණය සඳහා නොවේ. Image, video සහ music models ඒ වෙනුවට මෙම යන්ත්‍රය මත ධාවනය වන model එකකින් පින්තූර, video සහ music සෑදීම සඳහා Omarchy හි app එක වන Fantasi හි විවෘත වේ, එහි හෝ දේශීය models පැනලයේ ඒවායේ රේඛාවෙන් තෝරාගනු ලැබේ.

Model එකක් පිහිටුවූ ආකාරයටම හරියටම ධාවනය වෙමින් පවතින බැවින්, Omarchy යාවත්කාලීනයක් කිසිවිටෙක ඔබේ ඒජන්තවරුන් යට එකක් නැවත ආරම්භ නොකරයි. Omarchy සතුව ඔබ පිහිටුවා ඇති model එකක් සඳහා නව runtime එකක් හෝ නව weights ඇති විට, එහි රේඛාව update බොත්තමක් පෙන්වයි: එය ඔබන්න, එවිට model එක පසුබිමේ නැවත පිහිටුවනු ලබන අතර, වෙනස් වූ දේ පමණක් බාගත කර, නව අනුවාදය මත නැවත ආරම්භ වේ. නතර කර තිබූ model එකක් නතර කර තිබූ ආකාරයටම පවතියි. `omarchy models update` terminal එකකින් සෑම model එකක් සඳහාම එම දෙයම කරයි.

Command line එකෙන්, `omarchy models start <recipe>` සහ `omarchy models stop <recipe>` එම දෙයම කරන අතර, `omarchy models status` මගින් සෑම model එකක්ම පෙන්වයි, සහ `omarchy agent --local` මගින් ඔබේ පෙරනිමි ඒජන්තයා කුමක් වුවද, ඔබ අවසන් වරට ආරම්භ කළ model එක pi හි විවෘත කරයි. OpenCode සහ Qwen Code වලටද දේශීය model එකක් භාවිතා කළ හැකිය: `omarchy models harness opencode` හෝ `omarchy models harness qwen` මගින් ඒවා එහි විවෘත කරන අතර, `omarchy models harness pi` මගින් ආපසු යයි. pi විසින් ඔබ පිහිටුවා ඇති සෑම model එකක්ම, සහ ඔබ යුගල කළ යන්ත්‍රවල ඇති ඒවාද, එහිම model picker එකේ ලැයිස්තුගත කරන බැවින්, සරල `pi` එකකින්ද ඒවාට ළඟා විය හැකිය. ඕනෑම OpenAI-අනුකූල client එකකටද සම්බන්ධ විය හැකිය: `status` මගින් එක් එක් model එකේ ලිපිනය පෙන්වයි (පළමුවැන්න `http://127.0.0.1:11435/v1`), recipe නම model එක වන අතර, යතුර `~/.config/omarchy/agent-local/key` හි තිබේ.

`omarchy models remove <recipe>` මගින් model එකක් සහ වෙනත් කිසිම model එකක් භාවිතා නොකරන බාගත කිරීම් මකා දමයි.

Third-party runtimes ඒවායේ ප්‍රකාශකයා සමඟ ලේබල් කරනු ලැබේ. Omarchy විසින් සෑම model එකක්ම ජාල ප්‍රවේශයක් නොමැතිව ධාවනය කරයි.

### දේශීය LLMs

Omarchy විසින් දේශීය LLM models ධාවනය කිරීමේ ක්‍රම දෙකක් නිර්දේශ කරයි: LM Studio සහ Ollama. LM Studio විසින් open-weight models සොයාගැනීම, ඒවා ස්ථාපනය කිරීම, සහ ඒවා ධාවනය කිරීම සඳහා GUI අතුරුමුහුණතක් සපයයි. එය පහසුවෙන් ආරම්භ කිරීමට හොඳ ක්‍රමයකි. Ollama විසින් ඒ හා සමානව කිරීමට CLI එකක් ලබා දෙයි. නමුත් ඔබ දේශීය models වලට අලුත් නම්, මම LM Studio වලින් ආරම්භ කරමි. ඔබට Omarchy Menu එකේ _Install > AI_ යටතේ ඒවායින් ඕනෑම එකක් ස්ථාපනය කළ හැකිය.

### Omarchy skills

ඒජන්ත skills මගින් AI වලට නිශ්චිත මෙවලම් නිශ්චිත ආකාරයකින් භාවිතා කිරීමට උදවු වන අතර, Omarchy ඒවායින් හතක් සපයයි. omarchy skill එක ඔබේ Hyprland config එක වෙනස් කිරීම හෝ තීරුව සකස් කිරීම වැනි පද්ධතිය රිසිකරණය ආවරණය කරයි. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app, සහ omarchy-make-game අලුත් දෙයක් සෑදීම ආවරණය කරයි, omarchy-contribute දෝෂයක් වාර්තා කිරීම හෝ නිවැරදි කිරීමක් upstream වෙත යැවීම ආවරණය කරයි, සහ omarchy-diagnose-crash බිඳවැටීමක core dump එක හරහා ක්‍රියා කරයි. ඒවා Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ සෑම `~/.hermes/profiles/*/skills` එකක්ම), සහ generic `~/.agents/skills` ස්ථානය සඳහා skill නාමාවලි තුළට symlinks කර ඇති බැවින්, බොහෝ harness ඒවා ස්වයංක්‍රීයවම ලබාගනියි. එකම නම ඇති ඔබේම skill ෆෝල්ඩරයකට ප්‍රමුඛතාවය ලැබේ.

නමුත් ඔබ මෙම skills පර්යේෂණාත්මක ලෙස සැලකිය යුතුය. විවිධ models ඒවා විවිධ ප්‍රතිඵල සඳහා භාවිතා කරනු ඇත. ඒජන්තයා වෙනස් කිරීමට කැමති දේ පිළිබඳ ඔබට අදහසක් ඇති වන පරිදි, පළමුව plan mode එකේ ධාවනය කිරීම වඩාත් සුදුසුය. ඉන්පසු වෙනස්කම් ආපසු හැරවීමට හෝ, ඒජන්තයා සියල්ල අවුල් කර දමන්නේ නම්, `omarchy reinstall configs` ඇමතීමට පවා සූදානම් වන්න.
