# AI

Omarchy ඔබට පෙරනිමියක් තෝරා නොදී පහත කේතන නියෝජිතයන් සඳහා දියත්කරුවන් ඇතුළත්ව ලබා දෙයි. පළමු භාවිතයේදී එහි CLI එක ස්ථාපනය කිරීමට විධානයක් ධාවනය කරන්න, පසුව විමසූ විට සත්‍යාපනය කරන්න. Hermes යනු ව්‍යතිරේකයයි: පළමු භාවිතයේදී ඒ සඳහා කිසිවක් ස්ථාපනය නොවන අතර, එය තේරීමෙන් පහත _Desktop apps_ ವಿವರಿಸන පරිදි Hermes Desktop ස්ථාපනය වේ.

### නියෝජිතයන් ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes හැර, මෙම නියෝජිතයන් mise හි lazy ස්ථාපනය භාවිතා කරයි: පළමු දියත් කිරීම CLI එක ස්ථාපනය කරන අතර, පසුව දියත් කිරීම් එය නැවත භාවිතා කරයි. mise සෑම පැය හතරකටම වරකට වැඩි නැතිව, එය ආරම්භ වීමට මොහොතකට පෙර හෝ shell prompt එකක පසුබිමේ, ස්ථාපනය කළ නියෝජිතයෙකු සඳහා නව නිකුතුවක් තිබේදැයිද පරීක්ෂා කරයි. එම යාවත්කාලීනය අසාර්ථක වුවහොත් හෝ ඔබ නොබැඳි නම්, ස්ථාපනය කළ අනුවාදය ධාවනය වේ. `omarchy update` මඟින් Omarchy හි ඉතිරිය සමඟ ස්ථාපනය කළ නියෝජිතයන් යාවත්කාලීන කරන අතර, `mup` මඟින් mise මඟින් කළමනාකරණය වන මෙවලම් පමණක් යාවත්කාලීන කරයි.

`claude update`, `codex update` වැනි නියෝජිතයෙකුගේම යාවත්කාලීනකය, හෝ යෙදුමක ඇති යාවත්කාලීන බොත්තමක්, mise මඟින් කළමනාකරණය වන ස්ථාපනය යාවත්කාලීන නොකරයි. `codex update` අසාර්ථක වන අතර, `claude update` mise විසින් නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කරමින් සාර්ථක වූ බව වාර්තා කළ හැකිය. ඔබ නියෝජිතයෙකුගේම native ස්ථාපකය සහ යාවත්කාලීනකය භාවිතා කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [Preinstalled CLI tools](18-development-tools.md#preinstalled-cli-tools) බලන්න.

ඔබට අවශ්‍ය වීමට පෙර වින්‍යාස කළ සියලුම lazy මෙවලම් ස්ථාපනය කිරීමට, `mise install --include-lazy` ධාවනය කරන්න. මෙයට නියෝජිතයන් මෙන්ම Omarchy හි අනෙකුත් පෙරනිමි CLI මෙවලම්ද ඇතුළත් වේ. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිතා කිරීම සඳහා [Preinstalled CLI tools](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok`, `claude` සහ `codex` මෙන්ම, mise හි first-party `grok` පැකේජය හරහා ස්ථාපනය වේ. `grok` ධාවනය කරන්න, නැතහොත් _Agent > Harness_ යටතේ එය තෝරන්න. x.ai හි `curl | bash` ස්ථාපකය මඟ හරින්න. එම මාර්ගය `~/.grok/bin` හි දෙවන පිටපතක් තබන අතර, එය `PATH` මත ඉදිරියට දමා, Omarchy හි wrapper එක උඩින් ලියයි.

`dsh` එහි browser UI එක `127.0.0.1:3080` මත විවෘත කරන අතර, දියත් කිරීමේ නාමාවලිය එහි පෙරනිමි workspace එක ලෙස ගනී. එහි browser UI එක ආරම්භක prompt එකක් නොගන්නා බැවින්, `omarchy agent prompt` එය විවෘත කරන්නේ ඔබේ clipboard එක මත paste කිරීමට prompt එක සහිතවය. Omarchy එය DeepSeek හි no-approval අවසර preset එක සමඟ ආරම්භ කරයි. ඔබ එහි නිල ආකෘති API එක භාවිතා කරන විට DeepSeek Harness සැසි ලොග DeepSeek වෙත උඩුගත කරයි; එහි browser UI එකේ _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ එයට එවන ප්‍රතිපෝෂණද සැසිය සමඟ උඩුගත වේ, ඔබ එය `DSH_TELEMETRY_MODE=DISABLED` සමඟ ආරම්භ කළහොත් මිස.

### පෙරනිමි නියෝජිතයා

`omarchy default agent <name>` සමඟ හෝ Omarchy Menu (`Super + Space`) එකේ _Agent > Harness_ යටතේ ඔබේ පෙරනිමි නියෝජිතයා තෝරන්න. නියෝජිතයා තවම ස්ථාපනය කර නොමැති නම්, එය තේරීමෙන් පළමුව එය ස්ථාපනය වේ. නැවුම් Omarchy එකක් එක් වරක් පමණක් පෙන්වන දැනුම්දීමකින් මෙම තේරීම කිරීමට ඔබට ආරාධනා කරයි.

Claude තේරීම Chromium, Chrome, Brave, Brave Origin, සහ Edge සඳහා එහි browser extension එක පිහිටුවීමටද උත්සාහ කරයි. extension පිහිටුවීම සියලුම පරිශීලකයන්ට අදාළ වන අතර ඔබේ පද්ධති මුරපදය ඉල්ලා සිටිය හැක; extension ස්ථාපනය අවලංගු කිරීම හෝ අසාර්ථක වීම වුවද Claude තෝරාගෙන දියත් කරයි. ඔබේ browser එක නැවත ආරම්භ කරන්න, විමසුවහොත් extension එක සබල කරන්න, සහ එය සම්බන්ධ කිරීම අවසන් කිරීමට Claude වෙත පුරනය වන්න. සම්බන්ධතාව පරීක්ෂා කිරීමට Claude තුළ `/chrome` ධාවනය කරන්න. Firefox සහ Zen මෙම extension එකට සහාය නොදක්වයි. මෙම පිහිටුවීම එක් කිරීමට පෙර Claude දැනටමත් ඔබේ පෙරනිමිය වූයේ නම්, extension එක ස්ථාපනය කිරීමට එය නැවත තෝරන්න.

පවතින ගමනාන්ත අක්තපත්‍ර තබා ගනී. එහි දැනටමත් පුරනය වී ඇති මූලාශ්‍ර ගිණුමක අක්තපත්‍ර ප්‍රතිස්ථාපනය නොකර එහි නම සමමුහුර්ත කෙරේ; අනෙකුත් ගිණුම් එය අසලින් එක් කෙරේ. ගැළපෙන ගිණුම් සඳහා සුරකින ලද අක්තපත්‍ර ප්‍රතිස්ථාපනය කිරීමට, ගමනාන්තයේ එම ගිණුමේ සැසි නතර කිරීමෙන් පසු `omarchy agent account copy --replace laptop claude` භාවිතා කරන්න. නැවුම් ගමනාන්තයකට මූලාශ්‍රයේ සක්‍රිය ගිණුම සහ මාරු කිරීමේ මනාපයන්ද ලැබෙන අතර, ස්ථාපිත ගමනාන්තයක් තමාගේම ඒවා තබා ගනී.

අක්තපත්‍ර SSH හරහා ගමන් කර ගමනාන්තයේ පුද්ගලික ගොනු වල ගබඩා වන බැවින්, ඔබ විශ්වාස කරන යන්ත්‍රවලට පමණක් පිටපත් කරන්න. මෙය එක් වරක් පිටපත් කිරීමක් මිස අඛණ්ඩ සමමුහුර්ත කිරීමක් නොවේ. ක්‍රියාවලි බිඳවැටීම් සඳහා Omarchy systemd-coredump නිරීක්ෂණය කරයි. යමක් segfault වූ විට, ඔබට "Process crashed" දැනුම්දීමක් ලැබේ — එය ක්ලික් කරන්න, එවිට බිඳවැටීම ඔබේ පෙරනිමි නියෝජිතයාට core dump එකෙන් කරුණු තහවුරු කර ගැනීම සහ බිඳවැටීම upstream වෙත වාර්තා කිරීම වටීදැයි තීරණය කිරීම හරහා නියෝජිතයා රැගෙන යන Omarchy හි diagnose-crash skill එක සමඟ භාර දෙනු ලැබේ. `coredumpctl list` වෙතින් ඕනෑම PID එකකට එරෙහිව `omarchy agent crash <pid>` සමඟ ඔබට එය අතින්ද ධාවනය කළ හැකිය.

නිරීක්ෂණය පෙරනිමියෙන් සක්‍රියයි. _Trigger > Toggle > Crash Capture_ යටතේ (හෝ `omarchy toggle crash-capture` සමඟ) එය අක්‍රිය කරන්න, එවිට දැනුම්දීම් නතර වේ; `omarchy agent crash <pid>` තවමත් අතින් ක්‍රියා කරයි.

බිඳවැටීම් එක් වැඩසටහනකින් එක් වරක් නිහඬ කළ හැකි අතර, රෝග විනිශ්චය අවසානයේදී ඔබට ලබා දෙන්නේ එයයි. `omarchy crash mute hyprland` එම වැඩසටහන සඳහා පමණක් දැනුම්දීම් නතර කරයි, `omarchy crash mute hyprland off` ඒවා නැවත ගෙන එයි, සහ තනිවම `omarchy crash mute` ඔබ නිහඬ කළ දේ ලැයිස්තු කරයි. එය binary හි මාර්ගය එහි නම තරම්ම සතුටින් ගන්නා බැවින්, `omarchy crash mute /usr/bin/hyprland` එකම දෙය කරයි. `omarchy crash mute 'Some App'` හි මෙන් ඉඩක් ඇති නමක් උපුටා දක්වන්න. අනෙක් සියල්ල තවමත් දැනුම් දෙන අතර, නිහඬ කළ වැඩසටහන තවමත් බිඳ වැටේ — මෙය මතක් කිරීම සඟවන අතර, කිසිවක් නිවැරදි නොකරයි.

### Desktop යෙදුම්

_Install > AI_ මෙනුවේ චිත්‍රක AI යෙදුම් කිහිපයක්ද තිබේ: ChatGPT desktop යෙදුම, Claude desktop යෙදුම (Chat, Cowork, සහ Claude Code tabs සහිත Anthropic හි Linux beta එක), xAI හි ආකෘති සමඟ කතාබස් කිරීමට Grok Bot, Herdr Desktop, Hermes Desktop, OpenClaw, Perplexity desktop යෙදුම, සහ T3 Code. Grok Bot යනු desktop කතාබස් යෙදුමයි. කේතන නියෝජිතයා යනු `grok` විධානයයි.

Hermes Desktop යනු දැනගත යුතු එක වන අතර, එයට හේතුව යන්ත්‍රයකට එක Hermes එකක් තිබෙන අතර, එය යෙදුමට අයත් වීමයි: Hermes කිසිවිටෙක ස්ථාපනය වන්නේ යෙදුම හරහා පමණක් වන අතර, පෙරනිමි නියෝජිතයා ධාවනය කරන `hermes` විධානය යෙදුමට අයත් එකයි. Hermes පෙරනිමි නියෝජිතයා ලෙස තේරීමෙන් _Install > AI_ ප්‍රවේශය කරන එකම දෙය ස්ථාපනය වේ: පැකේජය, සහ පළමු වරට විනාඩි කිහිපයක් ගත වන Hermes හිම ස්ථාපකය මඟින් පිහිටුවන `~/.hermes` යට Hermes runtime එකක්. එම runtime එක terminal `hermes` විධානය, පෙරනිමි නියෝජිතයා සහ යෙදුම සියල්ලම භාවිතා කරන එකම Hermes වන අතර, එය Omarchy නිකුතුවක් එනතෙක් බලා නොසිට `hermes update` සමඟ තමාම යාවත්කාලීන වේ. එය ස්ථාපනය කිරීමෙන් Omarchy තේමාව `omarchy` නමින් skin එකක් ලෙස Hermes වෙත භාර දෙන අතර, ඔබ තේමා මාරු කරන විට සෑම Hermes මතුපිටක්ම එය අනුගමනය කරයි; ඔබට එය එසේ වීමට අකමැති නම් Hermes හි Appearance සැකසුම් යටතේ හෝ `/skin` සමඟ වෙනත් එකක් තෝරන්න, එවිට Omarchy එම තේරීම එලෙසම තබයි. _Remove > AI_ යටතේ යෙදුම ඉවත් කිරීමෙන් පළමුව gateway ද ඇතුළුව Hermes වසන අතර, එම runtime එක එය සමඟ ගන්නා අතර, ඔබ වෙනත් ආකාරයකින් නොකියන්නේ නම් ඔබේ කතාබස්, මතකයන්, සහ Hermes තමා සඳහාම ලියාගත් skills තබා ගනී: එම දත්ත සහ ඔබේ සම්බන්ධතා සැකසුම්ද යා යුතුදැයි එය අසන අතර, පෙරනිමිය නැත යන්නයි.

OpenClaw හි desktop අත්දැකීම එහි Control UI එක වන අතර, එය තමාගේම දේශීය gateway එකකින් පිටුබලය ලබන web යෙදුමක් ලෙස විවෘත වේ. ඔබ පිහිටුවන සෑම ආකෘතියකටම යෙදුම් දියත්කරුවේ තමාගේම ප්‍රවේශයක්ද ලැබෙන අතර, එය ආකෘතියේ නම යටතේ සහ එහි නිෂ්පාදකයාගේ ලාංඡනය සමඟ, Claude, Codex හෝ Grok වෙත පුරනය වීමෙන් එකක් එක් කරන ආකාරයටමය. එය ඔබේ නියෝජිතයා එම ආකෘතිය මත විවෘත කරන අතර, එය ධාවනය නොවන්නේ නම් පළමුව ආකෘතිය ආරම්භ කරයි: terminal එක එය පූරණය වන ආකාරය පෙන්වා, එය සූදානම් වූ පසු නියෝජිතයාට භාර දෙයි. ආකෘතියක් ඉවත් කිරීමෙන් එහි ප්‍රවේශය ඉවත් වේ.

ආකෘතියක් එය පිහිටුවූ ආකාරයටම හරියටම දිගටම ධාවනය වන බැවින්, Omarchy යාවත්කාලීනයක් කිසිවිටෙක ඔබේ නියෝජිතයන් යට එකක් නැවත ආරම්භ නොකරයි. ඔබ පිහිටුවා ඇති ආකෘතියක් සඳහා Omarchy හි නව runtime එකක් හෝ නව weights ඇති විට, එහි පේළිය යාවත්කාලීන බොත්තමක් පෙන්වයි: එය ඔබන්න, එවිට ආකෘතිය පසුබිමේ නැවත පිහිටුවනු ලබන අතර, වෙනස් වූ දේ පමණක් බාගත කර, නව අනුවාදය මත නැවත ආරම්භ වේ. නවත්වන ලද ආකෘතියක් නැවතත් නවත්වන ලද ආකාරයටම පවතී. `omarchy agent local update` terminal එකකින් සෑම ආකෘතියක් සඳහාම එකම දෙය කරයි.

විධාන පේළියෙන්, `omarchy agent local start <recipe>` සහ `omarchy agent local stop <recipe>` එකම දෙය කරයි, `omarchy agent local status` සෑම ආකෘතියක්ම පෙන්වයි, සහ `omarchy agent --local` ඔබ අවසන් වරට ආරම්භ කළ ආකෘතිය මත ඔබේ පෙරනිමි නියෝජිතයා විවෘත කරයි. pi, OpenCode සහ Qwen Code එකක් භාවිතා කළ හැක; වෙනත් ඕනෑම පෙරනිමියක් සමඟ එය pi තුළ විවෘත වේ. pi ඔබ පිහිටුවා ඇති සෑම ආකෘතියක්ම සහ ඔබ යුගල කළ යන්ත්‍රවල ඒවාද, තමාගේම ආකෘති තෝරකයේ ලැයිස්තු කරන බැවින්, සරල `pi` ද ඒවාට ළඟා වේ. ඕනෑම OpenAI-අනුකූල client එකකටද සම්බන්ධ විය හැක: `status` සෑම ආකෘතියකම ලිපිනය පෙන්වයි (පළමුවැන්න `http://127.0.0.1:11435/v1`), recipe නම ආකෘතිය වන අතර, යතුර `~/.config/omarchy/agent-local/key` හි තිබේ.

`omarchy agent local remove <recipe>` ආකෘතියක් සහ වෙනත් කිසිම ආකෘතියක් භාවිතා නොකරන බාගත කිරීම් මකා දමයි.

තෙවන පාර්ශවීය runtimes ඒවායේ ප්‍රකාශකයා සමඟ ලේබල් කර තිබේ. Omarchy සෑම ආකෘතියක්ම ජාල ප්‍රවේශයක් නොමැතිව ධාවනය කරයි.

LM Studio විවෘත-බර ආකෘති සොයා ගැනීමට, ඒවා ස්ථාපනය කිරීමට, සහ ඒවා ධාවනය කිරීමට GUI අතුරුමුහුණතක් සපයයි. එය පහසුවෙන් ආරම්භ කිරීමට කදිම ක්‍රමයකි. ### Omarchy Skill එක

නියෝජිත skills, AI හට නිශ්චිත මෙවලම් නිශ්චිත ආකාරයකින් භාවිතා කිරීමට උදවු කරන අතර, පද්ධතිය සකස් කිරීම සඳහා Omarchy පෙරනිමි skill එකක් සමඟ පැමිණේ. ඔබේ Hyprland config එක වෙනස් කිරීම, තීරුව සකස් කිරීම, හෝ මුල සිටම නව තේමාවක් නිර්මාණය කිරීම වැනි. එය Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ සෑම `~/.hermes/profiles/*/skills`), සහ සාමාන්‍ය `~/.agents/skills` ස්ථානය සඳහා skill නාමාවලි වෙත symlinked කර ඇති බැවින්, බොහෝ harness එය ස්වයංක්‍රීයව ලබා ගනී.

නමුත් ඔබ මෙම skill එක පර්යේෂණාත්මක ලෙස සැලකිය යුතුය. විවිධ ආකෘති එය විවිධ ප්‍රතිඵල සඳහා භාවිතා කරනු ඇත. නියෝජිතයා වෙනස් කිරීමට කැමති දේ පිළිබඳ අදහසක් ඔබට ඇති වන පරිදි, පළමුව plan mode එකේ එය ධාවනය කිරීම වඩාත් සුදුසුය. ඉන්පසු නියෝජිතයා සියල්ල අවුල් කළහොත්, වෙනස්කම් ආපසු හැරවීමට හෝ `omarchy reinstall configs` ඇමතීමට පවා සූදානම්ව සිටින්න.
