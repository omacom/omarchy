# AI

Omarchy ඔබට පෙරනිමි එකක් තෝරා දෙන්නේ නැතිව, පහත කේතීකරණ නියෝජිතයන් සඳහා දියත් කරන්නන් ඇතුළත් කරයි. එහි CLI එක මුල් වරට භාවිත කරන විට ස්ථාපනය කිරීමට විධානයක් ක්‍රියාත්මක කරන්න, ඉන්පසු විමසූ විට සත්‍යාපනය කරන්න. ### නියෝජිතයන් ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes හැර, මෙම නියෝජිතයන් mise හි lazy ස්ථාපනය භාවිත කරයි: මුල් දියත් කිරීමේදී CLI එක ස්ථාපනය වන අතර, පසු දියත් කිරීම් එය නැවත භාවිත කරයි. mise ද ස්ථාපිත නියෝජිතයෙකු සඳහා නව නිකුතුවක් තිබේදැයි උපරිම වශයෙන් පැය හතරකට වරක් පමණක් පරීක්ෂා කරයි, එය ආරම්භ වීමට මොහොතකට පෙර හෝ shell prompt එකකදී පසුබිමේය. එම යාවත්කාලීනය අසාර්ථක වුවහොත් හෝ ඔබ නොබැඳි නම්, ස්ථාපිත අනුවාදය ක්‍රියාත්මක වේ. `omarchy update` මඟින් ස්ථාපිත නියෝජිතයන් Omarchy හි ඉතිරි කොටස් සමඟ යාවත්කාලීන කරන අතර, `mup` මඟින් mise-කළමනාකරණය කරන මෙවලම් පමණක් යාවත්කාලීන කරයි.

`claude update`, `codex update`, හෝ යෙදුමක යාවත්කාලීන බොත්තමක් වැනි නියෝජිතයෙකුගේම යාවත්කාලීන කරන්නා, mise-කළමනාකරණය කරන ස්ථාපනය යාවත්කාලීන නොකරයි. `codex update` අසාර්ථක වන අතර, `claude update` මඟින් mise නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කරමින් සාර්ථක බව වාර්තා කළ හැක. ඔබ නියෝජිතයෙකුගේ ස්වදේශීය ස්ථාපකය සහ යාවත්කාලීන කරන්නා භාවිත කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

ඔබට අවශ්‍ය වීමට පෙර වින්‍යාස කර ඇති සියලුම lazy මෙවලම් ස්ථාපනය කිරීමට, `mise install --include-lazy` ක්‍රියාත්මක කරන්න. මෙයට නියෝජිතයන් මෙන්ම Omarchy හි අනෙකුත් පෙරනිමි CLI මෙවලම් ද ඇතුළත් වේ. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිත කිරීම සඳහා [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` ස්ථාපනය කරනු ලබන්නේ `claude` සහ `codex` ආකාරයටම, mise හි first-party `grok` පැකේජය හරහාය. `grok` ක්‍රියාත්මක කරන්න, නැතහොත් එය _Setup > Defaults > Agent_ යටතේ තෝරන්න. x.ai හි `curl | bash` ස්ථාපකය මඟ හරින්න. එම මාර්ගය `~/.grok/bin` හි දෙවන පිටපතක් තබයි, එය `PATH` මත ඉදිරියට එක් කරයි, සහ Omarchy හි wrapper එක උඩින් ලියයි.

`dsh` එහි බ්‍රවුසර UI එක `127.0.0.1:3080` මත විවෘත කරන අතර, දියත් කරන ලද නාමාවලිය එහි පෙරනිමි වැඩබිම ලෙස ගනී. එහි බ්‍රවුසර UI එක ආරම්භක prompt එකක් නොගනී, ඒ නිසා `omarchy agent prompt` එය විවෘත කරන්නේ prompt එක ඔබේ clipboard එකේ අලවන්නට තබාගෙනය. Omarchy එය DeepSeek හි no-approval අවසර පෙරසිටුවම සමඟ ආරම්භ කරයි. ඔබ එහි නිල ආකෘති API එක භාවිත කරන විට DeepSeek Harness මඟින් සැසි ලොග DeepSeek වෙත උඩුගත කරයි; එහි බ්‍රවුසර UI එකෙහි _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ එයට එවන ප්‍රතිපෝෂණ ද සැසිය සමඟ උඩුගත වේ, ඔබ එය `DSH_TELEMETRY_MODE=DISABLED` සමඟ ආරම්භ නොකළහොත් හැර.

### පෙරනිමි නියෝජිතයා

`omarchy default agent <name>` සමඟ හෝ Omarchy මෙනුවෙහි (`Super + Space`) _Setup > Defaults > Agent_ යටතේ ඔබේ පෙරනිමි නියෝජිතයා තෝරන්න. නියෝජිතයා තවම ස්ථාපනය කර නොමැති නම්, එය තෝරා ගැනීමෙන් මුලින් එය ස්ථාපනය වේ. නැවුම් Omarchy එකක් එක් වරක් පමණක් පෙන්වන දැනුම්දීමක් සමඟ මෙම තේරීම කිරීමට ඔබට ආරාධනා කරනු ඇත.

Claude තෝරා ගැනීමෙන් Chromium, Chrome, Brave, Brave Origin, සහ Edge සඳහා එහි බ්‍රවුසර දිගුව පිහිටුවීමට ද උත්සාහ කරයි. දිගුව පිහිටුවීම සියලුම පරිශීලකයන්ට අදාළ වන අතර ඔබේ පද්ධති මුරපදය ඉල්ලා සිටිය හැක; දිගු ස්ථාපනය අවලංගු කිරීම හෝ අසාර්ථක වීම වුවද Claude තෝරාගෙන දියත් කරයි. ඔබේ බ්‍රවුසරය නැවත ආරම්භ කරන්න, විමසුවහොත් දිගුව සබල කරන්න, සහ එය සම්බන්ධ කිරීම අවසන් කිරීමට Claude වෙත පුරනය වන්න. සම්බන්ධතාවය පරීක්ෂා කිරීමට Claude හි `/chrome` ක්‍රියාත්මක කරන්න. Firefox සහ Zen මෙම දිගුවට සහාය නොදක්වයි. මෙම පිහිටුවීම එක් කිරීමට පෙර සිටම Claude ඔබේ පෙරනිමිය වූයේ නම්, දිගුව ස්ථාපනය කිරීමට එය නැවත තෝරන්න.

ඔබ තෝරාගත් පසු, `Super + Shift + Ctrl + A` මඟින් පෙරනිමි නියෝජිතයා කැපවුණු terminal කවුළුවක දියත් කරයි (හෝ ඔබ තවම තෝරා නැත්නම් තේරීම්කරු ගෙන එයි). `omarchy agent prompt "Review this project"` සමඟ ඔබට එය කෙලින්ම කාර්යයකට දියත් කළ හැක. Freebuff සහ DeepSeek Harness ආරම්භක prompt එකක් නොගනී, ඒ නිසා ඒවා ඒ වෙනුවට prompt එක ඔබේ clipboard එකේ අලවන්නට තබාගෙන විවෘත වේ. මේ ආකාරයෙන් දියත් කරන ලද නියෝජිතයන් ඔවුන්ගේ අදාළ නොනැවතී නොඇසිය යුතු ආකාරයන්ගෙන් අධීක්ෂණයකින් තොරව ක්‍රියාත්මක වේ, ඒ නිසා ඔවුන් සැබවින්ම දේවල් කිරීමට සූදානම්ව සිටින්න! Terminal කෙටිමං ද ඇත: `a` වත්මන් terminal එක තුළම පෙරනිමි නියෝජිතයා ක්‍රියාත්මක කරන අතර, `c`, `cx`, සහ `cy` මඟින් OpenCode, Claude Code, සහ Codex කෙලින්ම ආරම්භ කරයි (නැවතත් ඔවුන්ගේ ස්වයංක්‍රීයව අනුමත කරන ආකාරයන්ගෙන්). තේමා වෙනස්කම් නියෝජිතයන් වෙතද සමමුහුර්ත වේ: ඔබ Omarchy තේමාව මාරු කරන විට Claude Code, Pi, OpenCode, සහ Hermes (Omarchy එය ස්ථාපනය කළ පසු) සියල්ලම ඒ සමඟ වෙනස් වේ.

### Omarchy Skill එක

නියෝජිත කුසලතා AI හට නිශ්චිත මෙවලම් නිශ්චිත ආකාරයකින් භාවිත කිරීමට උපකාර කරයි, සහ Omarchy පද්ධතිය අභිරුචිකරණය කිරීම සඳහා පෙරනිමි කුසලතාවක් සමඟ පැමිණේ. ඔබේ Hyprland config එක tweak කිරීම, තීරුව සකස් කිරීම, නැතහොත් මුල සිටම නව තේමාවක් නිර්මාණය කිරීම වැනි. එය Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ එක් එක් `~/.hermes/profiles/*/skills`), සහ පොදු `~/.agents/skills` ස්ථානය සඳහා කුසලතා නාමාවලි වෙත symlinked කර ඇති බැවින්, බොහෝ harness එය ස්වයංක්‍රීයව ලබාගනී.
