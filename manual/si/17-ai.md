# AI

Omarchy ඔබ වෙනුවෙන් පෙරනිමියක් තෝරා නොදී, පහත කේතීකරණ නියෝජිතයන් සඳහා දියත්කරණයන් ඇතුළත් කරයි. පළමු භාවිතයේදී එහි CLI ස්ථාපනය කිරීමට විධානයක් ධාවනය කරන්න, ඉන්පසු ඉල්ලා සිටින විට සත්‍යාපනය කරන්න. ### නියෝජිතයන් ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes සහ OpenClaw හැර, මෙම නියෝජිතයන් mise හි කල්දැමූ ස්ථාපනය භාවිත කරයි: පළමු දියත්කිරීමේදී CLI ස්ථාපනය කෙරෙන අතර, පසු දියත්කිරීම්වලදී එයම නැවත භාවිත කරයි. mise ද, ස්ථාපිත නියෝජිතයෙකු සඳහා නව නිකුතුවක් තිබේදැයි උපරිම වශයෙන් සෑම පැය හතරකට වරක්, එය ආරම්භ කිරීමට මොහොතකට පෙර හෝ shell විමසුමකදී පසුබිමේ පරීක්ෂා කරයි. එම යාවත්කාලීන කිරීම අසාර්ථක වුවහොත් හෝ ඔබ නොබැඳිව සිටියහොත්, ස්ථාපිත අනුවාදය ධාවනය වේ. `omarchy update` මගින් Omarchy හි ඉතිරිය සමඟ ස්ථාපිත නියෝජිතයන් යාවත්කාලීන කරයි, සහ `mup` මගින් mise විසින් කළමනාකරණය කරන මෙවලම් පමණක් යාවත්කාලීන කරයි.

`claude update`, `codex update`, හෝ යෙදුමක ඇති යාවත්කාලීන බොත්තමක් වැනි නියෝජිතයාගේම යාවත්කාලීනකරණය, mise විසින් කළමනාකරණය කරන ස්ථාපනය යාවත්කාලීන නොකරයි. `codex update` අසාර්ථක වන අතර, `claude update` සාර්ථක බව වාර්තා කළත් mise නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කළ හැකිය. ඔබ නියෝජිතයෙකුගේම ස්වදේශීය ස්ථාපකය සහ යාවත්කාලීනකරණය භාවිත කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [පෙර ස්ථාපනය කළ CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

ඔබට අවශ්‍ය වීමට පෙර සකසා ඇති සියලුම කල්දැමූ මෙවලම් ස්ථාපනය කිරීමට, `mise install --include-lazy` ධාවනය කරන්න. මෙයට නියෝජිතයන්ට අමතරව Omarchy හි අනෙක් පෙරනිමි CLI මෙවලම් ද ඇතුළත් වේ. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනයක් භාවිත කිරීම සඳහා [පෙර ස්ථාපනය කළ CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` ස්ථාපනය කෙරෙන්නේ mise හි ප්‍රථම-පාර්ශවීය `grok` පැකේජය හරහාය, `claude` සහ `codex` ආකාරයටමය. `grok` ධාවනය කරන්න, නැතහොත් එය _Agent > Harness_ යටතේ තෝරන්න. x.ai හි ඇති `curl | bash` ස්ථාපකය මඟ හරින්න. එම මාර්ගය දෙවන පිටපතක් `~/.grok/bin` හි තබයි, එය `PATH` හි මුලට දමයි, සහ Omarchy හි wrapper එක උඩින් ලියයි.

`dsh` එහි බ්‍රවුසර UI එක `127.0.0.1:3080` මත විවෘත කරන අතර, දියත් කළ නාමාවලිය එහි පෙරනිමි වැඩතලය ලෙස ගනියි. එහි බ්‍රවුසර UI එක ආරම්භක විමසුමක් නොගන්නා බැවින්, `omarchy agent prompt` මගින් එය විවෘත කරන්නේ විමසුම ඔබේ පසුරු පුවරුවේ අලවා ගැනීමට තබාය. Omarchy එය DeepSeek හි අනුමැතිය-නොමැති අවසර පෙරසිටුවීම සමඟ ආරම්භ කරයි. ඔබ එහි නිල මොඩල API එක භාවිත කරන විට DeepSeek Harness සැසි ලොග DeepSeek වෙත උඩුගත කරයි; එහි බ්‍රවුසර UI එකේ _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ එයට යවන ප්‍රතිපෝෂණ ද සැසිය සමඟම උඩුගත කෙරේ, ඔබ එය `DSH_TELEMETRY_MODE=DISABLED` සමඟ ආරම්භ නොකළහොත් මිස.

### පෙරනිමි නියෝජිතයා

`omarchy default agent <name>` සමඟ හෝ Omarchy Menu එකේ (`Super + Space`) _Agent > Harness_ යටතේ ඔබේ පෙරනිමි නියෝජිතයා තෝරන්න. නියෝජිතයා තවම ස්ථාපනය කර නොමැති නම්, එය තේරීමෙන් පළමුව එය ස්ථාපනය කෙරෙන අතර, එයට යෙදුම් දියත්කරණයේ, Agent අසලම, තමාගේම දියත්කරණයක් ද ලැබේ. අලුත් Omarchy එකක් එක් වරක් පමණක් පෙන්වන දැනුම්දීමකින් මෙම තේරීම කිරීමට ඔබට ආරාධනා කරනු ඇත.

ක්‍රියාවලි බිඳවැටීම් සඳහා Omarchy systemd-coredump නිරීක්ෂණය කරයි. ඔබ පෙරනිමි නියෝජිතයෙකු තෝරාගත් පසු, ඔබේ ඕනෑම වැඩසටහනක් core එකක් dump කළ විට "Process crashed" දැනුම්දීමක් ගෙන එයි — එය ක්ලික් කරන්න, සහ බිඳවැටීම ඔබේ පෙරනිමි නියෝජිතයාට Omarchy හි omarchy-diagnose-crash කුසලතාව සමඟ භාර දෙනු ලබන අතර, එය core dump එකෙන් කරුණු ස්ථාපිත කිරීම සහ බිඳවැටීම ඉහළට වාර්තා කිරීම වටිනවාද යන්න තීරණය කිරීම හරහා නියෝජිතයා රැගෙන යයි. `coredumpctl list` වෙතින් ඕනෑම PID එකකට එරෙහිව `omarchy agent crash <pid>` සමඟ ඔබට එය අතින් ද ධාවනය කළ හැකිය.

නිරීක්ෂණය පෙරනිමියෙන් ක්‍රියාත්මකයි. එය _Trigger > Toggle > Crash Capture Off_ යටතේ අක්‍රිය කරන්න (හෝ `omarchy toggle crash-capture` සමඟ) එවිට දැනුම්දීම් නතර වේ; `omarchy agent crash <pid>` තවමත් අතින් ක්‍රියා කරයි.

බිඳවැටීම් එක් වැඩසටහන බැගින් ද නිහඬ කළ හැකි අතර, එය රෝග විනිශ්චය අවසානයේ ඔබට ඉදිරිපත් කරන්නේ එයයි. `omarchy crash mute hyprland` එම වැඩසටහන සඳහා පමණක් දැනුම්දීම් නතර කරයි, `omarchy crash mute hyprland off` ඒවා ආපසු ගෙන එයි, සහ `omarchy crash mute` තනිවම ඔබ නිහඬ කළ දේ ලැයිස්තුගත කරයි. එය binary හි නම මෙන්ම එහි මාර්ගය ද සතුටින් ගන්නා බැවින්, `omarchy crash mute /usr/bin/hyprland` එකම දෙය කරයි. එහි ඉඩක් ඇති නමක් උද්ධෘත කරන්න, `omarchy crash mute 'Some App'` හි මෙන්. අනෙක් සියල්ල තවමත් දැනුම් දෙන අතර, නිහඬ කළ වැඩසටහන තවමත් බිඳ වැටේ — මෙය මතක් කිරීම සඟවනවා මිස කිසිවක් නිවැරදි නොකරයි.

### Desktop යෙදුම්

_Install > AI_ මෙනුව තවත් චිත්‍රක AI යෙදුම් කිහිපයක් ද දරයි: Amp Desktop, Antigravity Desktop, ChatGPT desktop යෙදුම, Claude desktop යෙදුම (Anthropic හි Linux beta එක, Chat, Cowork, සහ Claude Code පටිති සමඟ), xAI හි මොඩල සමඟ කතාබස් කිරීමට Grok Bot, Herdr Desktop, Hermes Desktop, OpenClaw, Perplexity desktop යෙදුම, සහ T3 Code. Grok Bot යනු desktop කතාබස් යෙදුමයි. කේතීකරණ නියෝජිතයා යනු `grok` විධානයයි.

Hermes Desktop යනු දැනගත යුතු එකය, මන්ද යන්ත්‍රයක එක් Hermes එකක් ඇති අතර, එය යෙදුමට අයත් වේ: Hermes සැමවිටම ස්ථාපනය කෙරෙන්නේ යෙදුම හරහා පමණක් වන අතර, පෙරනිමි නියෝජිතයා ධාවනය කරන `hermes` විධානය යෙදුමට අයත් වේ. Hermes පෙරනිමි නියෝජිතයා ලෙස තේරීමෙන් _Install > AI_ ප්‍රවේශය කරන එකම දෙයම ස්ථාපනය කරයි: පැකේජය, සහ Hermes හිම ස්ථාපකය මගින් සකසන ලද `~/.hermes` යටතේ Hermes runtime එකක්, එය පළමු වරට මිනිත්තු කිහිපයක් ගත වේ. එම runtime එක යනු terminal `hermes` විධානය, පෙරනිමි නියෝජිතයා සහ යෙදුම යන සියල්ල භාවිත කරන එකම Hermes එක වන අතර, එය Omarchy නිකුතුවක් එනතුරු නොසිට `hermes update` සමඟ තමාම යාවත්කාලීන වේ. එය ස්ථාපනය කිරීමෙන් Hermes වෙත Omarchy තේමාව `omarchy` නමින් සමක් ලෙස ද භාර දෙන අතර, ඔබ තේමා මාරු කරන විට සෑම Hermes පෘෂ්ඨයක්ම එය අනුගමනය කරයි; ඔබට එය එසේ වීමට අකමැති නම් Hermes හි Appearance සැකසුම් යටතේ හෝ `/skin` සමඟ වෙනත් එකක් තෝරන්න, එවිට Omarchy එම තේරීම ඒ අයුරින්ම තබයි. _Remove > AI_ යටතේ යෙදුම ඉවත් කිරීමෙන් පළමුව Hermes වසා දමයි, ද්වාරය ද ඇතුළුව, එම runtime එක එය සමඟ රැගෙන යයි, සහ ඔබ වෙනත් අයුරින් නොකියන්නේ නම් ඔබේ කතාබස්, මතකයන්, සහ Hermes තමා සඳහාම ලියූ කුසලතා තබා ගනියි: එම දත්ත සහ ඔබේ සම්බන්ධතා සැකසුම් ද යා යුතුදැයි එය අසන අතර, පෙරනිමිය නැත යන්නයි.

OpenClaw හි desktop අත්දැකීම එහි Control UI එක වන අතර, එය එහිම දේශීය ද්වාරයකින් පිටුබලය ලබන web යෙදුමක් ලෙස විවෘත වේ. OpenClaw `~/.openclaw` හි වෙසෙන අතර තමාම යාවත්කාලීන වේ: Control UI හි "Update Gateway" බොත්තම භාවිත කරන්න හෝ `openclaw update` ධාවනය කරන්න, එවිට ද්වාරය නව අනුවාදය මත නැවත ආරම්භ වේ. නියෝජිත කුසලතා AI හට නිශ්චිත මෙවලම් නිශ්චිත ආකාරයකින් භාවිත කිරීමට උදව් කරන අතර, Omarchy ඒවායින් හතක් යවයි. omarchy කුසලතාව ඔබේ Hyprland config එක වෙනස් කිරීම හෝ තීරුව සකස් කිරීම වැනි පද්ධතිය සකස් කිරීම ආවරණය කරයි. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app, සහ omarchy-make-game අලුත් දෙයක් සෑදීම ආවරණය කරයි, omarchy-contribute දෝෂයක් වාර්තා කිරීම හෝ නිවැරදි කිරීමක් ඉහළට යැවීම ආවරණය කරයි, සහ omarchy-diagnose-crash බිඳවැටීමක core dump එක හරහා ක්‍රියා කරයි. ඒවා Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ සෑම `~/.hermes/profiles/*/skills`), සහ සාමාන්‍ය `~/.agents/skills` ස්ථානය සඳහා වන කුසලතා නාමාවලියට symlinks කර ඇති බැවින්, බොහෝ harness ඒවා ස්වයංක්‍රීයවම ලබා ගනියි. එකම නම ඇති ඔබේම කුසලතා නාමාවලියකට ප්‍රමුඛතාව ලැබේ.

නමුත් ඔබ මෙම කුසලතා අත්හදා බැලීමේ ඒවා ලෙස සැලකිය යුතුය. විවිධ මොඩල එය විවිධ ප්‍රතිඵල සඳහා භාවිත කරනු ඇත. පළමුව plan ප්‍රකාරයෙන් ධාවනය කිරීම වඩාත් හොඳය, එවිට නියෝජිතයා වෙනස් කිරීමට කැමති දේ පිළිබඳ ඔබට අදහසක් ලැබේ. ඉන්පසු නියෝජිතයා සියල්ල අවුල් කළහොත් වෙනස්කම් ආපසු හරවීමට හෝ `omarchy reinstall configs` පවා ක්‍රියාත්මක කිරීමට සූදානම්ව සිටින්න.
