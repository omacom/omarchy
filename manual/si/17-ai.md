# AI

ඔබ වෙනුවෙන් පෙරනිමියක් තෝරා නොදී, පහත කේතීකරණ නියෝජිතයින් සඳහා වන දියත් කරන්නන් Omarchy තුළ ඇතුළත් වේ. එහි CLI එක මුල්ම වර භාවිතා කිරීමේදී ස්ථාපනය කිරීමට විධානයක් ධාවනය කරන්න, ඉන්පසු ඉල්ලූ විට සත්‍යාපනය කරන්න. Hermes යනු ව්‍යතිරේකයයි: එය මුල්ම වර භාවිතා කිරීමේදී කිසිවක් ස්ථාපනය නොවන අතර, එය තෝරා ගැනීමෙන් Hermes Desktop ස්ථාපනය වේ, පහත _ඩෙස්ක්ටොප් යෙදුම්_ හි පැහැදිලි කරන පරිදි.

### නියෝජිතයින් ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes හැර, මෙම නියෝජිතයින් mise හි lazy ස්ථාපනය භාවිතා කරයි: මුල්ම දියත් කිරීමේදී CLI එක ස්ථාපනය වන අතර, පසුව දියත් කිරීම්වලදී එයම නැවත භාවිතා වේ. ස්ථාපිත නියෝජිතයෙකු සඳහා නව නිකුතුවක් තිබේදැයි mise විසින් උපරිම වශයෙන් සෑම පැය හතරකටම වරක්, එය ආරම්භ වීමට මොහොතකට පෙර හෝ shell prompt එකකදී පසුබිමේ පරීක්ෂා කරයි. එම යාවත්කාලීනය අසාර්ථක වුවහොත් හෝ ඔබ නොබැඳිව සිටියහොත්, ස්ථාපිත අනුවාදය ධාවනය වේ. `omarchy update` මගින් Omarchy හි ඉතිරිය සමඟ ස්ථාපිත නියෝජිතයින් යාවත්කාලීන කරන අතර, `mup` මගින් යාවත්කාලීන කරන්නේ mise මගින් කළමනාකරණය වන මෙවලම් පමණි.

`claude update`, `codex update`, හෝ යෙදුමක ඇති යාවත්කාලීන බොත්තමක් වැනි නියෝජිතයෙකුගේම updater එක, mise මගින් කළමනාකරණය වන ස්ථාපනය යාවත්කාලීන නොකරයි. `codex update` අසාර්ථක වන අතර, mise විසින් ලුහුබැඳ නොයන වෙනම පිටපතක් ස්ථාපනය කරමින් `claude update` සාර්ථක වූ බව වාර්තා කළ හැකිය. ඔබ නියෝජිතයෙකුගේම ස්වදේශීය installer එක සහ updater එක භාවිතා කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [පෙර-ස්ථාපනය කළ CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

ඔබට අවශ්‍ය වීමට පෙර වින්‍යාස කළ සියලුම lazy මෙවලම් ස්ථාපනය කිරීමට, `mise install --include-lazy` ධාවනය කරන්න. මෙයට නියෝජිතයින්ට අමතරව Omarchy හි අනෙකුත් පෙරනිමි CLI මෙවලම්ද ඇතුළත් වේ. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිතා කිරීම සඳහා [පෙර-ස්ථාපනය කළ CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` ස්ථාපනය වන්නේ mise හි first-party `grok` පැකේජය හරහාය, `claude` සහ `codex` ආකාරයටමය. `grok` ධාවනය කරන්න, නැතහොත් _සැකසුම > පෙරනිමි > නියෝජිතයා_ යටතේ එය තෝරන්න. x.ai හි ඇති `curl | bash` installer එක මඟ හරින්න. එම මාර්ගය `~/.grok/bin` තුළ දෙවන පිටපතක් දමයි, එය `PATH` හි මුලට එක් කරයි, සහ Omarchy හි wrapper එක උඩින් ලියයි.

`dsh` එහි browser UI එක `127.0.0.1:3080` මත විවෘත කරයි, දියත් කළ නාමාවලිය එහි පෙරනිමි workspace එක ලෙස ගනී. එහි browser UI එක ආරම්භක prompt එකක් නොගන්නා බැවින්, `omarchy agent prompt` එය විවෘත කරන්නේ ඔබේ clipboard එකේ ඇති prompt එක අලවන්නටය. Omarchy එය ආරම්භ කරන්නේ DeepSeek හි අනුමැතිය-නොඅසන අවසර පෙරසැකසුම සමඟය. ඔබ එහි නිල ආකෘති API එක භාවිතා කරන විට DeepSeek Harness, DeepSeek වෙත සැසි log උඩුගත කරයි; එහි browser UI එකේ _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ එයට යවන ප්‍රතිපෝෂණද සැසිය සමඟම උඩුගත වේ, ඔබ එය `DSH_TELEMETRY_MODE=DISABLED` සමඟ ආරම්භ කළහොත් මිස.

### පෙරනිමි නියෝජිතයා

`omarchy default agent <name>` සමඟ හෝ Omarchy Menu එකේ (`Super + Space`) _සැකසුම > පෙරනිමි > නියෝජිතයා_ යටතේ ඔබේ පෙරනිමි නියෝජිතයා තෝරන්න. නියෝජිතයා තවම ස්ථාපනය කර නොමැති නම්, එය තෝරා ගැනීමෙන් පළමුව එය ස්ථාපනය වේ. නැවුම් Omarchy එකක් එක් වරක් පමණක් එවන දැනුම්දීමකින් මෙම තේරීම කරන ලෙස ඔබට ආරාධනා කරයි.

Claude තෝරා ගැනීමෙන් Chromium, Chrome, Brave, Brave Origin, සහ Edge සඳහා එහි browser දිගුව පිහිටුවීමටද උත්සාහ කරයි. දිගු පිහිටුවීම සියලුම පරිශීලකයින්ට අදාළ වන අතර ඔබේ පද්ධති මුරපදය අසනු ලැබිය හැකිය; දිගු ස්ථාපනය අවලංගු කිරීම හෝ අසාර්ථක වීම වුවද Claude තෝරාගෙන දියත් කරයි. ඔබේ browser එක නැවත ආරම්භ කරන්න, ඉල්ලූ නම් දිගුව සක්‍රිය කරන්න, සහ එය සම්බන්ධ කිරීම අවසන් කිරීමට Claude වෙත පුරනය වන්න. සම්බන්ධතාවය පරීක්ෂා කිරීමට Claude තුළ `/chrome` ධාවනය කරන්න. Firefox සහ Zen මෙම දිගුවට සහාය නොදක්වයි. මෙම පිහිටුවීම එක් කිරීමට පෙර සිටම Claude ඔබේ පෙරනිමිය වූයේ නම්, දිගුව ස්ථාපනය කිරීමට එය නැවත තෝරන්න.

_Install > AI_ මෙනුවේ චිත්‍රක AI යෙදුම් කිහිපයක්ද තිබේ: ChatGPT desktop app එක, Claude desktop app එක (Chat, Cowork, සහ Claude Code පටිති සහිත Anthropic හි Linux beta එක), xAI හි ආකෘති සමඟ කතාබස් කිරීමට Grok Bot, Herdr Desktop, Hermes Desktop, OpenClaw, Perplexity desktop app එක, සහ T3 Code. Grok Bot යනු desktop කතාබස් යෙදුමයි. කේතීකරණ නියෝජිතයා වන්නේ `grok` විධානයයි.

Hermes Desktop යනු දැනගත යුතු එකකි, මන්ද යන්ත්‍රයක එක් Hermes එකක් ඇති අතර, එය යෙදුමට අයත් වේ: Hermes සැමවිටම ස්ථාපනය වන්නේ යෙදුම හරහා පමණක් වන අතර, පෙරනිමි නියෝජිතයා ධාවනය කරන `hermes` විධානය යෙදුමට අයත් වේ. Hermes පෙරනිමි නියෝජිතයා ලෙස තෝරා ගැනීමෙන් _Install > AI_ ප්‍රවේශය කරන එකම දේ ස්ථාපනය වේ: පැකේජය, සහ මුල්ම වර මිනිත්තු කිහිපයක් ගතවන Hermes හිම installer එකෙන් පිහිටුවන ලද `~/.hermes` යටතේ ඇති Hermes runtime එක. terminal `hermes` විධානය, පෙරනිමි නියෝජිතයා සහ යෙදුම යන සියල්ලම භාවිතා කරන්නේ එම runtime එක වන අතර, එය Omarchy නිකුතුවක් එන තෙක් බලා නොසිට `hermes update` සමඟ තනිවම යාවත්කාලීන වේ. එය ස්ථාපනය කිරීමෙන් Hermes වෙත Omarchy තේමාව `omarchy` නම් skin එකක් ලෙසද භාර දෙන අතර, ඔබ තේමා මාරු කරන විට සෑම Hermes පෘෂ්ඨයක්ම එය අනුගමනය කරයි; ඔබට එය එසේ වීමට අකමැති නම් Hermes හි Appearance සැකසුම් යටතේ හෝ `/skin` සමඟ වෙනත් එකක් තෝරන්න, Omarchy එම තේරීම එලෙසම තබයි. _Remove > AI_ යටතේ යෙදුම ඉවත් කිරීමෙන් පළමුව gateway එක ඇතුළුව Hermes වසයි, එම runtime එක එය සමඟම ගෙන යයි, සහ ඔබ වෙනත් ආකාරයකට නොකියන්නේ නම් ඔබේ කතාබස්, මතකයන්, සහ Hermes තමාටම ලියාගත් නිපුණතා තබා ගනී: එම දත්ත සහ ඔබේ සම්බන්ධතා සැකසුම්ද යා යුතුදැයි එය අසන අතර, පෙරනිමිය නැත යන්නයි.

OpenClaw හි desktop අත්දැකීම වන්නේ එහිම දේශීය gateway එකකින් පිටුබල ලබන web යෙදුමක් ලෙස විවෘත වන එහි Control UI එකයි. Omarchy තෝරාගන්නේ නැවුම් ස්ථාපනයක් ආරම්භ වන නිකුතුව පමණි. _Remove > AI_ යටතේ OpenClaw ඉවත් කිරීමෙන් gateway සේවාව සහ යෙදුම එය සමඟම ගෙන යන අතර, ඉන්පසු `~/.openclaw` ද යා යුතුදැයි අසයි, මන්ද එහි ඔබේ කතාබස් සහ අක්තපත්‍ර OpenClaw සමඟම සහ එය බාගත කරන plugin runtimes සමඟ පවතින බැවිනි; පෙරනිමිය එය තබා ගන්නා අතර, OpenClaw නැවත ස්ථාපනය කිරීමෙන් එය නැවත ලබා ගනී.

Herdr Desktop යනු [Herdr](https://herdr.dev) desktop යෙදුමයි: ඔබ කවුළුව වැසූ විට එහි හරය තුළ දිගටම ධාවනය වන terminals සහ කේතීකරණ නියෝජිතයින්ගේ spaces, tabs, සහ panes. එය පැකේජයකින් නොව Herdr හිම installer එකෙන් පැමිණෙන බැවින්, එය `~/.local/share/herdr-app` තුළ ජීවත් වේ, ඔබට තවම එකක් නොමැති විට එහි හරය `~/.local/bin/herdr-core` තුළ ගෙන එයි, සහ දෙකම තනිවම යාවත්කාලීන කරයි. එය ප්‍රතිස්ථාපනය කිරීම වෙනුවට `Super + Ctrl + Return` මත Omarchy සපයන `herdr` විධානය අසලින් පිහිටන අතර, එම විධානයේ සෘජු යතුරු ලබා ගනී: `Alt + Return` සහ `Alt + Shift + Return` pane එකක් පහළට හෝ දකුණට බෙදයි, `Alt + Escape` එය වසයි, `Ctrl + Alt + Arrow` panes අතර ගමන් කරයි, `Alt + 1..9` සහ `Alt + Left/Right` tab එකක් තෝරයි, සහ `Alt + Up/Down` spaces අතර ගමන් කරයි. `Ctrl + 1..9` space එකක් තෝරන අතර `Alt + Shift + Up/Down` නියෝජිතයින් හරහා පියවර තබයි. යෙදුමට අනුක්‍රමයක් සඳහා සරල Ctrl යතුරක් අල්ලාගෙන සිටිය නොහැකි බැවින් `Ctrl + Space` උපසර්ග යතුරු terminal එකට පමණක් සීමා වේ. නියෝජිත නිපුණතා, AI හට නිශ්චිත මෙවලම් නිශ්චිත ආකාරයකින් භාවිතා කිරීමට උපකාර කරන අතර, පද්ධතිය රිසිකරණය කිරීම සඳහා පෙරනිමි නිපුණතාවක් සමඟ Omarchy පැමිණෙයි. ඔබේ Hyprland config එක වෙනස් කිරීම, තීරුව සකස් කිරීම, හෝ මුල සිටම නව තේමාවක් නිර්මාණය කිරීම වැනි. එය Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ සෑම `~/.hermes/profiles/*/skills`), සහ සාමාන්‍ය `~/.agents/skills` ස්ථානය සඳහා වන නිපුණතා නාමාවලිවලට symlink කර ඇති බැවින්, බොහෝ harness එය ස්වයංක්‍රීයවම ලබා ගනී.

නමුත් ඔබ මෙම නිපුණතාව පර්යේෂණාත්මක ලෙස සැලකිය යුතුය. විවිධ ආකෘති එය විවිධ ප්‍රතිඵල සඳහා භාවිතා කරනු ඇත. නියෝජිතයා වෙනස් කිරීමට කැමති දේ පිළිබඳ අදහසක් ඔබට ලැබෙන පරිදි, මුලින්ම plan ආකාරයෙන් ධාවනය කිරීම වඩාත් සුදුසුය. ඉන්පසු නියෝජිතයා සියල්ල අවුල් කරන්නේ නම්, වෙනස්කම් ආපසු හරවන්නට හෝ `omarchy reinstall configs` ඇමතීමට පවා සූදානම්ව සිටින්න.
