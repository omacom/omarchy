# AI

Omarchy, AI කේතන නියෝජිතයන් පළමු පෙළේ පුරවැසියන් ලෙස සලකයි, නමුත් එය ඔබ වෙනුවෙන් ප්‍රියතම එකක් තෝරා නොදෙයි. ඒ වෙනුවට, සෑම ප්‍රධාන කේතන-නියෝජිත CLI එකක්ම lazy-loaded launcher එකක් ලෙස කලින්ම සම්බන්ධ කර තිබේ. මෙම launcher යනු `~/.local/bin/` තුළ ඇති [mise](https://mise.jdx.dev/)-කළමනාකරණය කරන කුඩා stub වේ, එබැවින් ඔබ ඇත්ත වශයෙන්ම එකක් පළමු වරට ධාවනය කරන තෙක් කිසිවක් බාගත නොවේ. Hermes ඊට ව්‍යතිරේකයයි: ඒ සඳහා කිසිවක් stub කර නැත, එය තෝරා ගැනීමෙන් Hermes Desktop ස්ථාපනය වේ, පහත _Desktop යෙදුම්_ පැහැදිලි කරන පරිදි. මේවායින් ඕනෑම එකක් කැඳවා, අසන විට සත්‍යාපනය කරන්න:

`ori` ඊට වෙනස් එකය: එය අනිත් harness OpenRouter හි සම්පූර්ණ ආකෘති නාමාවලියට එරෙහිව ධාවනය කරයි, එබැවින් `ori claude`, `ori codex`, හෝ `ori opencode` මගින් එම නියෝජිතයන් ඔබ ඔවුන්ට යොමු කරන ඕනෑම ආකෘතියක් මත ආරම්භ කරයි, සහ `ori code` යනු Ori හිම නියෝජිතයාය.

අමතර CLI එකක් එලෙසම ඔතා ගැනීමට, `omarchy-mise-install <package> [command-name]` ධාවනය කරන්න. ඔබ `omarchy update` (හෝ `mup` අන්වර්ථය) ධාවනය කරන විට, mise කළමනාකරණය කරන අනෙක් සියල්ල සමඟ stub ද යාවත්කාලීනව පවතී.

`claude` සහ `codex` මෙන්ම, `grok` ස්ථාපනය කරනු ලබන්නේ mise හි first-party `grok` පැකේජය හරහාය. `grok` ධාවනය කරන්න, නැතිනම් _Setup > Defaults > Agent_ යටතේ එය තෝරන්න. x.ai හි ඇති `curl | bash` ස්ථාපකය මඟ හරින්න. එම මාර්ගය `~/.grok/bin` තුළ දෙවන පිටපතක් තබයි, එය `PATH` හි ඉදිරියට දමයි, සහ Omarchy හි wrapper එක උඩින් ලියයි.

### පෙරනිමි නියෝජිතයා

`omarchy default agent <name>` සමඟ හෝ Omarchy Menu (`Super + Space`) හි _Setup > Defaults > Agent_ යටතේ ඔබේ පෙරනිමි නියෝජිතයා තෝරන්න. නියෝජිතයා තවම ස්ථාපනය කර නැතිනම්, එය තෝරා ගැනීමෙන් පළමුව එය ස්ථාපනය වේ. අලුත් Omarchy එකක් එක් වරක් පමණක් දිස්වන දැනුම්දීමකින් මෙම තේරීම කිරීමට ඔබට ආරාධනා කරනු ඇත.

Claude තෝරා ගැනීමෙන් Chromium, Chrome, Brave, Brave Origin, සහ Edge සඳහා එහි browser extension එක සැකසීමට ද උත්සාහ කරයි. මෙම extension සැකසුම සියලු පරිශීලකයන්ට අදාළ වන අතර ඔබේ system password එක ඉල්ලා සිටිය හැක; extension ස්ථාපනය අවලංගු කළත් අසාර්ථක වුවත් Claude තවමත් තෝරා ගෙන දියත් කරයි. ඔබේ browser එක නැවත ආරම්භ කර, අසන විට extension එක සක්‍රිය කර, එය සම්බන්ධ කිරීම අවසන් කිරීමට Claude වෙත පිවිසෙන්න. සම්බන්ධතාව පරීක්ෂා කිරීමට Claude තුළ `/chrome` ධාවනය කරන්න. Firefox සහ Zen මෙම extension එකට සහාය නොදක්වයි. මෙම සැකසුම එක් කිරීමට පෙර සිටම Claude ඔබේ පෙරනිමිය වී තිබුණිනම්, extension එක ස්ථාපනය කිරීමට එය නැවත තෝරන්න.

[Muse Code](https://dev.meta.ai) — Meta හි `muse` — අනිත් නියෝජිතයන් මෙන් කලින් ස්ථාපනය කළ mise stub එකක් භාවිතා කරයි. එය පෙරනිමිය ලෙස තෝරා ගැනීමෙන් mise හි HTTP backend එක හරහා Meta හි නිල launcher එක ස්ථාපනය වේ. එම launcher එක ඔබේ යන්ත්‍රය සඳහා native binary එක සත්‍යාපනය කර යාවත්කාලීන කරයි.

ඔබ තෝරා ගත් පසු, `Super + Shift + Ctrl + A` මගින් පෙරනිමි නියෝජිතයා විශේෂ terminal කවුළුවක දියත් කරයි (නැතිනම් ඔබ තවම තෝරා නැතිනම් picker එක ගෙන එයි). `omarchy agent prompt "Review this project"` සමඟ ඔබට එය කෙලින්ම කාර්යයක් වෙතට ද දියත් කළ හැක. මෙලෙස දියත් කළ නියෝජිතයන් ඔවුන්ගේ අදාළ අසන්නට-නොනැවතී modes වල අධීක්ෂණයකින් තොරව ධාවනය වේ, එබැවින් ඔවුන් ඇත්ත වශයෙන්ම දේවල් කිරීමට සූදානම්ව සිටින්න! තවද, නියෝජිතයන් ඔබේ home directory එක සඳහා විශ්වාසය මතක තබා ගැනීම ප්‍රතික්ෂේප කරන බැවින්, `$HOME` වෙතින් කරන දියත් කිරීම් ඒ වෙනුවට `~/Work` තුළ ආරම්භ වේ.

Terminal කෙටිමං ද තිබේ: `a` මගින් පෙරනිමි නියෝජිතයා වත්මන් terminal එක තුළම ධාවනය කරයි, අතර `c`, `cx`, සහ `cy` මගින් OpenCode, Claude Code, සහ Codex කෙලින්ම ආරම්භ කරයි (නැවතත් ඔවුන්ගේ auto-approving modes වලින්). Theme වෙනස්කම් නියෝජිතයන් සමඟ ද සමමුහුර්ත වේ: ඔබ Omarchy theme එක මාරු කරන විට Claude Code, Pi, OpenCode, සහ Hermes (Omarchy එය ස්ථාපනය කළ පසු) යන සියල්ලම ඒ සමඟ ගමන් කරයි.

### නියෝජිත පැනලය

ඉහළ තීරුවේ නියෝජිත නිරූපකයක් තිබේ. ඔබ නියෝජිතයෙකු සැකසීමට පෙර, එහි පැනලය Claude, Codex, හෝ Grok වෙත පිවිසීම හරහා ඔබව ගෙන යයි, සහ පළමුවැන්න ඔබේ පෙරනිමි නියෝජිතයා බවට පත් වේ. ඉන් පසු, පැනලය සෑම දායකත්වයක්ම එකම පිටුවක තබයි: එහි සැලැස්ම සමඟ සෑම නියෝජිතයෙකුම සහ ගිණුමක්ම, එය නැවත සැකසෙන තෙක් ඇති කාලය සමඟ එහි පැය 5ක සැසිය සහ සතිපතා සීමාවන් එක් එක්ක සඳහා මීටරයක් (නිවැරදි ප්‍රතිශතය සඳහා hover කරන්න), නැතිනම් ඉතිරි පෙරගෙවුම් ශේෂය, ඔබ ඒ සියල්ල හරහා භාවිතා කළ දේ මාරුවෙන් මාරුවට පෙන්වන පේළියක් යට, මේ සතියේ tokens සහ ඔබ වැඩිපුරම භාවිතා කළ ආකෘතිය වැනි. _Make something_ යටතේ එය ඔබේ පෙරනිමි නියෝජිතයාට කාර්යය භාර දෙන අලුත් theme එකක්, plugin එකක්, හෝ app එකක් සඳහා ආරම්භක prompt ලබා දෙයි. Apps ගොඩනඟනු ලබන්නේ Omarchy හිම Hype, Monologue, සහ Omacut ගොඩනඟන ආකාරයටම, C++ සහ Qt Quick වලින්, omarchy-app agent skill එක අනුගමනය කරමින් වන අතර, ඔවුන්ට අවශ්‍ය compiler එක සහ Qt කොටස් ස්ථාපනය කර පැමිණේ. Claude Code, Codex, Grok, Fireworks, සහ Kimi ආරම්භයේ සිටම ආවරණය වේ. Kimi දැනට දේශීය token හෝ prompt සංඛ්‍යාලේඛන නොමැතිව ගිණුමේ quota සීමාවන් වාර්තා කරයි.

පැනලය සඳහා තීරු නිරූපකය වම්-ක්ලික් කරන්න, ඔබේ පෙරනිමි නියෝජිතයා දියත් කිරීමට දකුණු-ක්ලික් කරන්න. ඒ පිටුපස ඇති භාවිත වාර්තා සෑම විනාඩි 15කට වරක් `omarchy agent usage-update` මගින් නැවත ජනනය කරනු ලබන අතර, පැනලයට සමමුහුර්ත කළ ෆෝල්ඩරයක් හරහා ඔබේ අනෙක් යන්ත්‍රවලින් භාවිතය ඒකාබද්ධ කිරීමට පවා හැක. සම්පූර්ණ සැකසීම් සඳහා `$OMARCHY_PATH/shell/plugins/agents/` යටතේ ඇති README එක බලන්න.

### දායකත්ව කිහිපයක්

ඔබ Claude, Codex, හෝ Grok සැලැස්මකට වඩා වැඩි ගණනකට ගෙවන්නේ නම් — පුද්ගලික Max එකක් සහ රැකියා එකක් යැයි කියමු — Omarchy හට ඒ සියල්ල පිවිස තබා ඒවා අතර ගමන් කළ හැක. නියෝජිත පැනලයේ ඇති + සමඟ දායකත්වයක් එක් කරන්න, එය එතැනින්ම ඒ හරහා ඔබව ගෙන යයි, නැතිනම් `omarchy agent account add claude Work` (නැතිනම් `codex`, නැතිනම් `grok`) සමඟ එක් කරන්න. Grok Bot යනු desktop chat app එකයි. කේතන නියෝජිතයා යනු `grok` විධානයයි.

Hermes Desktop ගැන දැන ගත යුතු එකය, මන්ද යන්ත්‍රයක ඇත්තේ එක් Hermes එකක් වන අතර, එය app එකේ එකය: Hermes කවදා හෝ ස්ථාපනය කරනු ලබන්නේ app එක හරහා පමණක් වන අතර, පෙරනිමි නියෝජිතයා ධාවනය කරන `hermes` විධානය app එකේ එකය. Hermes පෙරනිමි නියෝජිතයා ලෙස තෝරා ගැනීමෙන් _Install > AI_ ඇතුළත් කිරීම කරන දෙයම ස්ථාපනය කරයි: පැකේජය, සහ පළමු වරට විනාඩි කිහිපයක් ගතවන, Hermes හිම ස්ථාපකය විසින් සකසන ලද `~/.hermes` යටතේ Hermes runtime එකක්. එම runtime එක තමයි terminal `hermes` විධානය, පෙරනිමි නියෝජිතයා සහ app එක යන සියල්ලම භාවිතා කරන එකම Hermes එක වන අතර, එය Omarchy නිකුතුවක් බලා නොසිට `hermes update` සමඟ තනිවම යාවත්කාලීන වේ. එය ස්ථාපනය කිරීමෙන් Hermes වෙත Omarchy theme එක `omarchy` නම් skin එකක් ලෙස ද භාර දෙන අතර, ඔබ theme මාරු කරන විට සෑම Hermes මතුපිටක්ම එය අනුගමනය කරයි; ඔබට එය එසේ කිරීමට අවශ්‍ය නැතිනම් Hermes හි Appearance සැකසීම් යටතේ නැතිනම් `/skin` සමඟ තවත් එකක් තෝරන්න, එවිට Omarchy එම තේරීම එලෙසම තබයි. _Remove > AI_ යටතේ app එක ඉවත් කිරීමෙන් පළමුව Hermes වසා දමයි, gateway එක ද ඇතුළුව, එම runtime එක එය සමඟම රැගෙන යයි, සහ ඔබ වෙනත් ආකාරයකින් නොකියන තෙක් ඔබේ chats, memories, සහ Hermes තමා වෙනුවෙන් ලියූ skills තබා ගනී: එම දත්ත සහ ඔබේ සම්බන්ධතා සැකසීම් ද යා යුතුදැයි එය අසයි, පෙරනිමිය නැත යන්නයි.

OpenClaw හි desktop අත්දැකීම එහි Control UI එක වන අතර, එය එයාගේම දේශීය gateway එකකින් සහාය ලබන web app එකක් ලෙස විවෘත වේ. OpenClaw වාසය කරන්නේ `~/.openclaw` තුළ වන අතර තනිවම යාවත්කාලීන වේ: Control UI හි "Update Gateway" බොත්තම භාවිතා කරන්න නැතිනම් `openclaw update` ධාවනය කරන්න, එවිට gateway එක නව අනුවාදය මත නැවත ආරම්භ වේ. Omarchy තෝරා ගන්නේ අලුත් ස්ථාපනයක් ආරම්භ වන නිකුතුව පමණි. _Remove > AI_ යටතේ OpenClaw ඉවත් කිරීමෙන් gateway සේවාව සහ app එක එය සමඟම රැගෙන යන අතර පසුව `~/.openclaw` ද යා යුතුදැයි අසයි, මන්ද එහි OpenClaw යම සහ එය බාගත කරන plugin runtimes අසලම ඔබේ chats සහ අක්තපත්‍ර ඇති බැවිනි; පෙරනිමිය එය තබා ගනී, සහ OpenClaw නැවත ස්ථාපනය කිරීමෙන් එය නැවත ලබා ගනී.

### දේශීය LLM

Omarchy දේශීය LLM ආකෘති ධාවනය කිරීමේ ක්‍රම දෙකක් නිර්දේශ කරයි: LM Studio සහ Ollama. LM Studio විවෘත-බර ආකෘති සොයා ගැනීමට, ඒවා ස්ථාපනය කිරීමට, සහ ඒවා ධාවනය කිරීමට GUI අතුරුමුහුණතක් සපයයි. එය පහසුවෙන් ආරම්භ කිරීමට හොඳ ක්‍රමයකි. Ollama ඒ හා සමානව කිරීමට CLI එකක් ලබා දෙයි. නමුත් ඔබ දේශීය ආකෘතිවලට අලුත් නම්, මම LM Studio සමඟ ආරම්භ කරමි. ඔබට Omarchy Menu හි _Install > AI_ යටතේ මේවායින් ඕනෑම එකක් ස්ථාපනය කළ හැක.

### Omarchy Skill එක

Agent skills, AI හට නිශ්චිත මෙවලම් නිශ්චිත ආකාරයකින් භාවිතා කිරීමට උපකාරී වන අතර, Omarchy පද්ධතිය සකස් කිරීම සඳහා පෙරනිමි skill එකක් සමඟ පැමිණේ. ඔබේ Hyprland config එක සකස් කිරීම, තීරුව සකස් කිරීම, නැතිනම් මුල සිටම අලුත් theme එකක් නිර්මාණය කිරීම වැනි. එය Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ සෑම `~/.hermes/profiles/*/skills`), සහ සාමාන්‍ය `~/.agents/skills` ස්ථානය සඳහා වූ skill directories තුළට symlink කර ඇත, එබැවින් බොහෝ harness එය ස්වයංක්‍රීයව ලබා ගනී.

නමුත් ඔබ මෙම skill එක පර්යේෂණාත්මක ලෙස සැලකිය යුතුය. විවිධ ආකෘති එය විවිධ බලපෑම් සඳහා භාවිතා කරනු ඇත. පළමුව plan mode එකේ ධාවනය කිරීම වඩාත් සුදුසුය, එබැවින් නියෝජිතයා වෙනස් කිරීමට කැමති දේ ගැන ඔබට අදහසක් තිබේ. ඉන්පසු නියෝජිතයා සියල්ල අවුල් කළහොත් වෙනස්කම් ආපසු හැරවීමට නැතිනම් `omarchy reinstall configs` කැඳවීමට පවා සූදානම්ව සිටින්න.
