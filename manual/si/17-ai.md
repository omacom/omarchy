# AI

Omarchy, ඔබට පෙරනිමියක් තෝරා දීමකින් තොරව, පහත කේතකරණ ඒජන්තයන් සඳහා දියත්කරන ඇතුළත් කරයි. එහි CLI එක මුල් වරට භාවිතයේදී ස්ථාපනය කිරීමට විධානයක් ධාවනය කරන්න, ඉන්පසු විමසූ විට සත්‍යාපනය කරන්න. Hermes සහ OpenClaw ව්‍යතිරේකයන්ය: ඒවා සඳහා mise හරහා කිසිවක් ස්ථාපනය නොකෙරේ, ඒවායින් එකක් තේරීමෙන් එහිම ස්වයං-යාවත්කාලීන වන පිටපත පිහිටුවනු ලැබේ, පහත _Desktop apps_ හි පැහැදිලි කර ඇති පරිදිය.

### ඒජන්තයන් ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes සහ OpenClaw හැර, මෙම ඒජන්තයන් mise හි lazy ස්ථාපනය භාවිත කරයි: පළමු දියත් කිරීමේදී CLI එක ස්ථාපනය වන අතර, පසුව දියත් කිරීම්වලදී එයම නැවත භාවිත කරයි. mise ද ස්ථාපිත ඒජන්තයක් සඳහා අලුත් නිකුතුවක් තිබේදැයි උපරිම වශයෙන් පැය හතරකට වරක්, එය ආරම්භ වීමට මොහොතකට පෙර හෝ shell විමසුමකදී පසුබිමේ පරීක්ෂා කරයි. එම යාවත්කාලීනය අසාර්ථක වුවහොත් හෝ ඔබ නොබැඳි නම්, ස්ථාපිත අනුවාදය ධාවනය වේ. `omarchy update` මගින් Omarchy හි ඉතිරිය සමඟ ස්ථාපිත ඒජන්තයන් යාවත්කාලීන කරයි, සහ `mup` මගින් mise-කළමනාකරණය වන මෙවලම් පමණක් යාවත්කාලීන කරයි.

ඒජන්තයකම යාවත්කාලිනකය, උදාහරණයක් ලෙස `claude update`, `codex update`, හෝ යෙදුමක ඇති යාවත්කාලීන බොත්තම, mise-කළමනාකරණය වන ස්ථාපනය යාවත්කාලීන නොකරයි. `codex update` අසාර්ථක වේ, සහ `claude update` විසින් සාර්ථක බව වාර්තා කළ හැකි වුවද mise විසින් නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කරයි. ඔබ ඒජන්තයකම දේශීය ස්ථාපකය සහ යාවත්කාලිනකය භාවිත කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

ඔබට අවශ්‍ය වීමට පෙර වින්‍යාස කර ඇති සියලුම lazy මෙවලම් ස්ථාපනය කිරීමට, `mise install --include-lazy` ධාවනය කරන්න. මෙයට Omarchy හි අනෙකුත් පෙරනිමි CLI මෙවලම් මෙන්ම ඒජන්තයන් ද ඇතුළත් වේ. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිත කිරීම සඳහා [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` ස්ථාපනය කරනු ලබන්නේ mise හි ප්‍රථම-පාර්ශවීය `grok` පැකේජය හරහා, `claude` සහ `codex` මෙන්මය. `grok` ධාවනය කරන්න, හෝ _Agent > Harness_ යටතේ එය තෝරන්න. x.ai හි `curl | bash` ස්ථාපකය මඟ හරින්න. එම මාර්ගය `~/.grok/bin` හි දෙවැනි පිටපතක් තබයි, එය `PATH` හි ඉදිරියට එක් කරයි, සහ Omarchy හි wrapper එක උඩින් ලියයි.

`dsh` එහි browser UI එක `127.0.0.1:3080` හි විවෘත කරයි, දියත් කරන ලද නාමාවලිය එහි පෙරනිමි වැඩතලය ලෙස ගනිමින්. එහි browser UI එක ආරම්භක විමසුමක් නොගනී, එබැවින් `omarchy agent prompt` එය විවෘත කරන්නේ ඔබේ පසුරුපුවරුවේ අලවීමට විමසුම සහිතවය. Omarchy එය ආරම්භ කරන්නේ DeepSeek හි no-approval අවසර පෙරසැකසුම සමඟය. ඔබ එහි නිල ආකෘති API එක භාවිත කරන විට DeepSeek Harness සැසි ලොග DeepSeek වෙත උඩුගත කරයි; එහි browser UI එකේ _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ එයට යවන ප්‍රතිපෝෂණ ද සැසිය සමඟ උඩුගත වේ, ඔබ එය `DSH_TELEMETRY_MODE=DISABLED` සමඟ ආරම්භ නොකළහොත්.

### පෙරනිමි ඒජන්තය

`omarchy default agent <name>` සමඟින් හෝ Omarchy Menu එකේ (`Super + Space`) _Agent > Harness_ යටතේ ඔබේ පෙරනිමි ඒජන්තය තෝරන්න. ඒජන්තය තවම ස්ථාපනය කර නොමැති නම්, එය තේරීමෙන් පළමුව එය ස්ථාපනය කරයි, සහ එයටම යෙදුම් දියත්කරනයේ, Agent අසල, එයටම වෙන් වූ දියත්කරනයක් ද ලැබේ. අලුත් Omarchy එකක් එක් වරක් පමණක් දිස්වන දැනුම්දීමකින් මෙම තේරීම කිරීමට ඔබට ආරාධනා කරයි.

Claude Code, Codex, Grok, Kimi, Cursor සහ එහි Grok Bot දීමනාව, GitHub Copilot, Muse, Antigravity, සහ Devin ඒවායේ සීමා සමඟ ආරම්භයේදීම ආවරණය වේ, Kimchi එහි සැලැස්ම, පෙරගෙවුම් ණය, සහ වියදම් අයවැය සමඟ, සහ Hermes, Mistral Vibe, සහ Qwen Code ඔබ ඒවා භාවිත කළ පසු ඒවායේ සැසි සහ tokens පෙන්වයි. ඔබ pi, omp, හෝ opencode හරහා භාවිත කරන සැපයුම්කරු සැලසුම් සහ යතුරු ද දිස් වේ: OpenCode Zen සහ Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan, සහ Synthetic ඒවායේ සීමා සමඟ; OpenRouter සහ DeepSeek ඒවායේ පෙරගෙවුම් ශේෂයන් සමඟ; Fireworks පසුගිය දින 30 තුළ එහි වියදම සමඟ. ඔබේම දෘඩාංග මත ඔබ ධාවනය කරන ආකෘතීන්ගෙන් ලැබෙන tokens ද එකතුවට ගණන් ගනී; ආකෘතීන්ටම ඒවාටම වෙන් වූ පැනලයක් ඇත, [දේශීය ආකෘති](#local-models) යටතේ විස්තර කර ඇති පරිදි. සෑම ඒජන්තයක්ම එක් වරක් ගණන් ගනු ලැබේ, එයට බිල්පත් කරන්නේ කාටද යන්න යටතේ, ඔබ එය කොපමණ harness හරහා ධාවනය කළද.

පැනලය සඳහා තීරු අයිකනය වම්-ක්ලික් කරන්න හෝ `Super + Ctrl + X` ඔබන්න, ඔබේ පෙරනිමි ඒජන්තය දියත් කිරීමට දකුණු-ක්ලික් කරන්න, සහ නැවුම් කිරීමට මැද-ක්ලික් කරන්න. එය පිටුපස ඇති භාවිත වාර්තා සෑම මිනිත්තු 15කට වරක් `omarchy agent usage update` මගින් යළි ජනනය කරනු ලැබේ, සහ පැනලයට සමමුහුර්ත කළ ෆෝල්ඩරයක් හරහා ඔබේ අනෙක් යන්ත්‍රවලින් භාවිතය ඒකාබද්ධ කිරීමට පවා හැකිය. සම්පූර්ණ සැකසුම් සඳහා `$OMARCHY_PATH/shell/plugins/agents/` යටතේ ඇති README එක බලන්න.

### දායකත්ව කිහිපයක්

ඔබ Claude, Codex, හෝ Grok සැලසුම් එකකට වැඩියෙන් ගෙවන්නේ නම් — පුද්ගලික Max එකක් සහ රැකියා එකක්, උදාහරණයක් ලෙස — Omarchy හට ඒවා සියල්ලම පුරනය වී තබා ගෙන ඒවා අතර මාරු විය හැකිය. ඒජන්ත පැනලයේ + සමඟ දායකත්වයක් එක් කරන්න, එය එතැනදීම ඔබව ඒ හරහා ගෙනයයි, හෝ `omarchy agent account add claude Work` (හෝ `codex`, හෝ `grok`) සමඟිනි. එය අස්ථානගත වී ඇත්නම් CLI එක ස්ථාපනය කරයි. සැපයුම්කරුවෙකු සඳහා පළමු ගිණුම ඔබේ සාමාන්‍ය browser එක හරහා පුරනය වේ, CLI එක සැමවිටම බලන තැනදීම. ඉන්පසු සෑම එකක්ම පුද්ගලික කවුළුවක් හරහා පුරනය වේ, එබැවින් ඔබේ browser එක දැනටමත් පුරනය වී ඇති ගිණුම වැරදියට තෝරා නොගනී; ඔබ එක් කරන ගිණුම ලෙස එහි පුරනය වන්න, සහ ඔබ දැනටමත් විවෘත කර ඇති ඕනෑම පුද්ගලික කවුළුවක් පළමුව වසන්න. මෙය කිරීමට කිසිවිට CLI එකෙන් ඉවත් නොවන්න: ඉවත් වීමෙන් සුරකින ලද පුරනය වීම අවලංගු වේ, සහ එම ගිණුම නැවත එක් කිරීමට සිදුවනු ඇත.

ඔබේ දායකත්ව පුරනය වීම් වෙනත් Omarchy යන්ත්‍රයකට SSH හරහා පිටපත් කිරීමට, `omarchy agent account copy user@laptop` ධාවනය කරන්න. ගමනාන්තයේ එකක් ස්ථාපනය කර නොමැති විට යවන්නා තාවකාලික ග්‍රාහකයක් සපයයි, එබැවින් පැරණි Omarchy යන්ත්‍රවලට යාවත්කාලීනයකින් තොරව ගිණුම් ලැබිය හැකිය. ස්ථාපිත ග්‍රාහකයන්ට ප්‍රමුඛතාව ලැබේ. මෙය සියලුම Claude, Codex, සහ Grok දායකත්ව පිටපත් කරයි; ඒවා තෝරා ගැනීමට සැපයුම්කරු නම් එක් කරන්න, `omarchy agent account copy laptop claude` හි මෙනි. ගිණුම් නම් සහ විධාන IDs මූලාශ්‍රයට ගැලපේ, ගමනාන්තයේ දැනටමත් ඇති ගිණුම් ඇතුළුව. සම්බන්ධ නොවූ ගමනාන්ත ගිණුම්වල නම් ගැටුමක් ඇත්නම් සංඛ්‍යාත්මක උපසර්ගයක් ලැබේ, සහ සැකසුම්, කුසලතා, plugins, සහ සංවාද ඉතිහාසය එක් එක් යන්ත්‍රයට දේශීයව පවතී.

පවතින ගමනාන්ත අක්තපත්‍ර තබා ගනී. එහි දැනටමත් පුරනය වී ඇති මූලාශ්‍ර ගිණුමක අක්තපත්‍ර ප්‍රතිස්ථාපනය නොකර එහි නම සමමුහුර්ත කරනු ලැබේ; අනෙකුත් ගිණුම් එයට අමතරව එක් කරනු ලැබේ. ගැලපෙන ගිණුම් සඳහා සුරකින ලද අක්තපත්‍ර ප්‍රතිස්ථාපනය කිරීමට, ගමනාන්තයේ එම ගිණුමේ සැසි නවතා දැමීමෙන් පසු `omarchy agent account copy --replace laptop claude` භාවිත කරන්න. අලුත් ගමනාන්තයකට මූලාශ්‍රයේ සක්‍රිය ගිණුම සහ මාරු කිරීමේ මනාපයන් ද ලැබේ; ස්ථාපිත ගමනාන්තයක් තමන්ගේ ඒවා තබා ගනී.

අක්තපත්‍ර SSH හරහා ගමන් කරන අතර ගමනාන්තයේ පුද්ගලික ගොනු තුළ ගබඩා වේ, එබැවින් ඔබ විශ්වාස කරන යන්ත්‍රවලට පමණක් පිටපත් කරන්න. මෙය එක් වරක් පමණක් කරන පිටපතකි, අඛණ්ඩ සමමුහුර්තකරණයක් නොවේ. Codex නැවුම් tokens වෙනත් යන්ත්‍රයකින් කරකැවිය හැකිය, පිටපත් කරන ලද පුරනය වීමක් අලුත් කිරීම අවශ්‍ය වන තත්ත්වයකට පත් කරයි; යන්ත්‍ර කිහිපයක එකවර භාවිතය සඳහා වෙනම පුරනය වීම් වඩාත්ම විශ්වාසදායක තේරීම ලෙස පවතී. ### බිඳවැටීම හඳුනාගැනීම

Omarchy ක්‍රියාවලි බිඳවැටීම් සඳහා systemd-coredump නිරීක්ෂණය කරයි. ඔබ පෙරනිමි ඒජන්තයක් තෝරාගත් පසු, core එකක් dump කරන ඔබේ ඕනෑම වැඩසටහනක් "Process crashed" දැනුම්දීමක් ගෙන එයි — එය ක්ලික් කරන්න, සහ බිඳවැටීම ඔබේ පෙරනිමි ඒජන්තයට Omarchy හි omarchy-diagnose-crash කුසලතාව සමඟ භාර දෙනු ලැබේ, එය core dump එකෙන් කරුණු තහවුරු කිරීම සහ බිඳවැටීම upstream වෙත වාර්තා කිරීම වටිනවාද යන්න තීරණය කිරීම හරහා ඒජන්තය ගෙනයයි. ඔබට `coredumpctl list` එකෙන් ඕනෑම PID එකකට එරෙහිව `omarchy agent crash <pid>` සමඟින් එය අතින් ද ධාවනය කළ හැකිය.

ඒජන්ත කුසලතා AI හට විශේෂිත මෙවලම් විශේෂිත ආකාරයකින් භාවිත කිරීමට උපකාරී වන අතර, Omarchy ඒවායින් හතක් සපයයි. omarchy කුසලතාව පද්ධතිය සකස් කිරීම ආවරණය කරයි, ඔබේ Hyprland config එක වෙනස් කිරීම හෝ තීරුව සකස් කිරීම වැනි. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app, සහ omarchy-make-game අලුත් දෙයක් සෑදීම ආවරණය කරයි, omarchy-contribute දෝෂයක් වාර්තා කිරීම හෝ upstream වෙත නිවැරදි කිරීමක් යැවීම ආවරණය කරයි, සහ omarchy-diagnose-crash බිඳවැටීමක core dump එක හරහා ක්‍රියා කරයි. ඒවා Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ එක් එක් `~/.hermes/profiles/*/skills`), සහ සාමාන්‍ය `~/.agents/skills` ස්ථානය සඳහා කුසලතා නාමාවලිවලට සම්බන්ධ කර ඇත, එබැවින් බොහෝ harness ඒවා ස්වයංක්‍රීයව ලබා ගනී. එම නමම ඇති ඔබේම කුසලතා ෆෝල්ඩරයකට ප්‍රමුඛතාව ලැබේ.

නමුත් ඔබ මෙම කුසලතා පර්යේෂණාත්මක ලෙස සැලකිය යුතුය. විවිධ ආකෘති එය විවිධ අයුරින් භාවිත කරනු ඇත. පළමුව plan ක්‍රමයෙන් ධාවනය කිරීම වඩාත් හොඳය, එබැවින් ඒජන්තයා වෙනස් කිරීමට කැමති දේ පිළිබඳ ඔබට අදහසක් ලැබේ. ඉන්පසු ඒජන්තයා සියල්ල අවුල් කරන්නේ නම්, වෙනස්කම් ආපසු හැරවීමට හෝ `omarchy reinstall configs` ඇමතීමට පවා සූදානම් වන්න.
