# AI

Omarchy මඟින් ඔබට පෙරනිමියක් තෝරා නොදී, පහත කේතීකරණ ඒජන්තයන් සඳහා ලෝන්චර් ඇතුළත් කරයි. පළමු වරට භාවිත කරන විට එහි CLI එක ස්ථාපනය කිරීමට විධානයක් ක්‍රියාත්මක කරන්න, ඉන්පසු විමසූ විට සත්‍යාපනය කරන්න. Hermes යනු ව්‍යතිරේකයයි: පළමු වරට භාවිත කරන විට එය සඳහා කිසිවක් ස්ථාපනය නොවන අතර, එය තෝරා ගැනීමෙන් Hermes Desktop ස්ථාපනය වේ, පහත _ඩෙස්ක්ටොප් යෙදුම්_ හි පැහැදිලි කර ඇති පරිදි.

### ඒජන්තයන් ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes හැර, මෙම ඒජන්තයන් mise හි lazy ස්ථාපනය භාවිත කරයි: පළමු දියත් කිරීමෙන් CLI එක ස්ථාපනය වන අතර, පසුව දියත් කිරීම් එය නැවත භාවිත කරයි. mise ද ස්ථාපිත ඒජන්තයක් සඳහා නව නිකුතුවක් තිබේදැයි උපරිම වශයෙන් සෑම පැය හතරකට වරක්, එය ආරම්භ වීමට මොහොතකට පෙර හෝ shell prompt එකක පසුබිමේ පරීක්ෂා කරයි. එම යාවත්කාලීනය අසාර්ථක වුවහොත් හෝ ඔබ නොබැඳි නම්, ස්ථාපිත අනුවාදය ක්‍රියාත්මක වේ. `omarchy update` මඟින් Omarchy හි ඉතිරිය සමඟ ස්ථාපිත ඒජන්තයන් යාවත්කාලීන කරන අතර, `mup` මඟින් යාවත්කාලීන කරන්නේ mise මඟින් කළමනාකරණය වන මෙවලම් පමණි.

ඒජන්තයෙකුගේම updater එක, උදාහරණයක් ලෙස `claude update`, `codex update`, හෝ යෙදුමක ඇති update බොත්තම, mise මඟින් කළමනාකරණය වන ස්ථාපනය යාවත්කාලීන නොකරයි. `codex update` අසාර්ථක වන අතර, `claude update` මඟින් සාර්ථක බව වාර්තා කළ හැකි වුවද mise විසින් නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කරයි. ඒ වෙනුවට ඔබ ඒජන්තයෙකුගේ ස්වදේශීය installer එක සහ updater එක භාවිත කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

ඔබට අවශ්‍ය වීමට පෙර වින්‍යාස කර ඇති සියලුම lazy මෙවලම් ස්ථාපනය කිරීමට, `mise install --include-lazy` ක්‍රියාත්මක කරන්න. මෙයට ඒජන්තයන් මෙන්ම Omarchy හි අනෙකුත් පෙරනිමි CLI මෙවලම් ද ඇතුළත් වේ. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිත කිරීම සඳහා [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` ස්ථාපනය කරන්නේ mise හි first-party `grok` පැකේජය හරහාය, `claude` සහ `codex` මෙන්මය. `grok` ක්‍රියාත්මක කරන්න, නැතහොත් _Agent > Harness_ යටතේ එය තෝරන්න. x.ai හි ඇති `curl | bash` installer එක මඟ හරින්න. එම මාර්ගය `~/.grok/bin` හි දෙවන පිටපතක් තබයි, එය `PATH` හි ඉදිරියට එක් කරයි, සහ Omarchy හි wrapper එක උඩින් ලියයි.

`dsh` එහි browser UI එක `127.0.0.1:3080` හි විවෘත කරයි, දියත් කරන නාමාවලිය එහි පෙරනිමි workspace එක ලෙස ගනී. එහි browser UI එක ආරම්භක prompt එකක් නොගන්නා බැවින්, `omarchy agent prompt` මඟින් එය විවෘත කරන්නේ ඇලවීමට ඔබේ clipboard එකේ prompt එක ඇතිවය. Omarchy එය ආරම්භ කරන්නේ DeepSeek හි අනුමැතිය-නොඅවශ්‍ය අවසර preset එකෙනි. ඔබ එහි නිල model API එක භාවිත කරන විට DeepSeek Harness විසින් session ලොග DeepSeek වෙත උඩුගත කරයි; එහි browser UI එකේ _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ එයට යවන ප්‍රතිපෝෂණ ද session එක සමඟම උඩුගත වේ, ඔබ එය `DSH_TELEMETRY_MODE=DISABLED` සමඟ ආරම්භ නොකළහොත්.

### පෙරනිමි ඒජන්තය

`omarchy default agent <name>` සමඟ හෝ Omarchy Menu එකේ (`Super + Space`) _Agent > Harness_ යටතේ ඔබේ පෙරනිමි ඒජන්තය තෝරන්න. ඒජන්තය තවම ස්ථාපනය කර නොමැති නම්, එය තෝරා ගැනීමෙන් පළමුව එය ස්ථාපනය වේ. නැවුම් Omarchy එකක් එක් වරක් පමණක් දිස්වන දැනුම්දීමකින් මෙම තේරීම කිරීමට ඔබට ආරාධනා කරනු ඇත.

Claude තෝරා ගැනීමෙන් Chromium, Chrome, Brave, Brave Origin, සහ Edge සඳහා එහි browser extension එක සැකසීමට ද උත්සාහ කරයි. ### ඒජන්ත පැනලය

ඉහළ තීරුවේ ඒජන්ත අයිකනයක් ඇත. ඔබ ඒජන්තයෙකු සකසා ගැනීමට පෙර, එහි පැනලය Claude, Codex, හෝ Grok වෙත පුරනය වීම හරහා ඔබව රැගෙන යන අතර, ඉන් පළමුවැන්න ඔබේ පෙරනිමි ඒජන්තය බවට පත්වේ. ඉන් පසු, පැනලය සෑම දායකත්වයක්ම එක් පිටුවකට ගෙන එයි: සෑම ඒජන්තයෙකු සහ ගිණුමක් එහි සැලැස්ම සමඟ, එහි සෑම පැය 5 සැසියකම සහ සතිපතා සීමාවකම මීටරයක්, එය යළි සැකසෙන තෙක් ඇති කාලය සමඟ (හරියටම ප්‍රතිශතය සඳහා උඩින් තබන්න), හෝ ඉතිරි පෙරගෙවුම් ශේෂය, ඔබ ඒ සියල්ල හරහා භාවිත කර ඇති දේ හරහා මාරු වන පේළියක් යට, උදාහරණයක් ලෙස මේ සතියේ tokens සහ ඔබ වැඩිපුරම භාවිත කළ මාදිලිය. _Make something_ යටතේ එය නව තේමාවක්, plugin එකක්, හෝ යෙදුමක් සඳහා ආරම්භක prompts ලබා දෙන අතර, එම කාර්යය ඔබේ පෙරනිමි ඒජන්තයට භාර දෙයි. යෙදුම් ගොඩනගා ඇත්තේ Omarchy හිම Hype, Monologue, සහ Omacut මෙන්, C++ සහ Qt Quick හි, omarchy-app ඒජන්ත skill එක අනුගමනය කරමින් වන අතර, ඔවුන්ට අවශ්‍ය compiler එක සහ Qt කොටස් ස්ථාපනය වී පැමිණේ. Claude Code, Codex, Grok, Kimi, Cursor සහ එහි Grok Bot දීමනාව, GitHub Copilot, Muse, Antigravity, Kimchi, සහ Devin ඔවුන්ගේ සීමාවන් සමඟ ආරම්භයේ සිටම ආවරණය වේ, සහ Hermes, Mistral Vibe, සහ Qwen Code ඔබ ඒවා භාවිත කළ පසු ඔවුන්ගේ සැසි සහ tokens පෙන්වයි. ඔබ pi, omp, හෝ opencode හරහා භාවිත කරන Provider සැලසුම් සහ යතුරු ද දිස් වේ: OpenCode Zen සහ Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan, සහ Synthetic ඔවුන්ගේ සීමාවන් සමඟ; Fireworks, OpenRouter, සහ DeepSeek ඔවුන්ගේ පෙරගෙවුම් ශේෂ සමඟ; සහ ඔබ ඔබේම දෘඩාංග මත ධාවනය කරන මාදිලි Local models යට. සෑම ඒජන්තයෙකුම එක් වරක් ගණන් ගනු ලැබේ, ඔබ එය කොපමණ harness ගණනක් හරහා ධාවනය කළද, එයට බිල් කරන්නේ කවුරුන් වුවද ඔහු යටතේය.

පැනලය සඳහා තීරු අයිකනය වම්-ක්ලික් කරන්න, ඔබේ පෙරනිමි ඒජන්තය දියත් කිරීමට දකුණු-ක්ලික් කරන්න. එය පිටුපස ඇති භාවිත වාර්තා සෑම මිනිත්තු 15 කට වරක් `omarchy agent usage-update` මඟින් නැවත ජනනය කරනු ලබන අතර, පැනලයට සමමුහුර්ත කළ ෆෝල්ඩරයක් හරහා ඔබේ අනෙකුත් යන්ත්‍රවලින් භාවිතය ඒකාබද්ධ කිරීමට පවා හැකිය. සම්පූර්ණ සැකසුම් සඳහා `$OMARCHY_PATH/shell/plugins/agents/` යටතේ ඇති README එක බලන්න.

### දායකත්ව කිහිපයක්

ඔබ Claude, Codex, හෝ Grok සැලසුම් එකකට වැඩියෙන් ගෙවන්නේ නම් — උදාහරණයක් ලෙස පුද්ගලික Max එකක් සහ වැඩ සඳහා එකක් — Omarchy මඟින් ඒ සියල්ල පුරනය වී තබා ඒ අතර මාරු විය හැක. Agents පැනලයෙහි + සමඟ දායකත්වයක් එක් කරන්න, එය එතැනම ඒ හරහා ඔබව රැගෙන යයි, නැතහොත් `omarchy agent account add claude Work` සමඟ (හෝ `codex`, හෝ `grok`). එය අස්ථානගත නම් CLI එක ස්ථාපනය කරයි. Grok Bot යනු ඩෙස්ක්ටොප් කතාබස් යෙදුමයි. කේතීකරණ ඒජන්තය යනු `grok` විධානයයි.

Hermes Desktop යනු දැනගත යුතු එකකි, මන්ද යන්ත්‍රයක එක් Hermes එකක් ඇති අතර, එය යෙදුමට අයිති එකකි: Hermes කිසිවිටෙක ස්ථාපනය වන්නේ යෙදුම හරහා පමණක් වන අතර, පෙරනිමි ඒජන්තය ක්‍රියාත්මක කරන `hermes` විධානය යෙදුමේ එකම වේ. පෙරනිමි ඒජන්තය ලෙස Hermes තෝරා ගැනීමෙන් _Install > AI_ ඇතුළත් කිරීම කරන එම දෙයම ස්ථාපනය වේ: පැකේජය, සහ Hermes හිම installer එක මඟින් සකසන ලද `~/.hermes` යටතේ Hermes runtime එකක්, එය පළමු වරට මිනිත්තු කිහිපයක් ගත වේ. එම runtime එක තමයි terminal `hermes` විධානය, පෙරනිමි ඒජන්තය සහ යෙදුම යන සියල්ල භාවිත කරන එකම Hermes එක වන අතර, එය Omarchy නිකුතුවක් එනතුරු බලා නොසිට `hermes update` සමඟ තමාම යාවත්කාලීන වේ. එය ස්ථාපනය කිරීමෙන් Hermes වෙත Omarchy තේමාව `omarchy` නමින් skin එකක් ලෙස ද ලබා දෙන අතර, ඔබ තේමා මාරු කරන විට සෑම Hermes පෘෂ්ඨයක්ම එය අනුගමනය කරයි; ඔබට එය එසේ වීමට අවශ්‍ය නැත්නම් Hermes හි Appearance සැකසුම් යටතේ හෝ `/skin` සමඟ වෙනත් එකක් තෝරන්න, එවිට Omarchy එම තේරීම එලෙසම තබයි. _Remove > AI_ යටතේ යෙදුම ඉවත් කිරීමෙන් පළමුව Hermes වසා දමයි, gateway එක ඇතුළුව, එම runtime එක එය සමඟ රැගෙන යන අතර, ඔබ වෙනත් ලෙස නොකියන්නේ නම් ඔබේ කතාබස්, මතකයන්, සහ Hermes තමා සඳහාම ලියාගත් skills තබා ගනී: එම දත්ත සහ ඔබේ සම්බන්ධතා සැකසුම් ද යා යුතුදැයි එය විමසයි, පෙරනිමිය නැහැ ලෙසය.

OpenClaw හි ඩෙස්ක්ටොප් අත්දැකීම එහි Control UI එක වන අතර, එය තමාගේම ස්ථානීය gateway එකකින් පිටුබලය ලබන web යෙදුමක් ලෙස විවෘත වේ. Omarchy තෝරා ගන්නේ නැවුම් ස්ථාපනයක් ආරම්භ වන නිකුතුව පමණි. _Remove > AI_ යටතේ OpenClaw ඉවත් කිරීමෙන් gateway සේවාව සහ යෙදුම එය සමඟ රැගෙන යන අතර පසුව `~/.openclaw` ද යා යුතුදැයි විමසයි, මන්ද එහි OpenClaw ම සහ එය බාගත කරන plugin runtimes සමඟ ඔබේ කතාබස් සහ අක්තපත්‍ර ඇති බැවිනි; පෙරනිමිය එය තබා ගන්නා අතර, OpenClaw නැවත ස්ථාපනය කිරීමෙන් එය නැවත ලබා ගනී.
