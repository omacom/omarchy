# AI

Omarchy විසින් ඔබට පෙරනිමියක් තෝරා නොදී, පහත කේත ලියන නියෝජිතයන් සඳහා දියත් කරන්නන් ඇතුළත් කරයි. පළමු වර භාවිතයේදී එහි CLI එක ස්ථාපනය කිරීමට විධානයක් ධාවනය කරන්න, ඉන්පසු අසන විට සත්‍යාපනය කරන්න. Hermes යනු ව්‍යතිරේකයයි: එය සඳහා පළමු භාවිතයේදී කිසිවක් ස්ථාපනය නොවන අතර, එය තෝරා ගැනීමෙන් Hermes Desktop ස්ථාපනය වේ, පහත _Desktop යෙදුම්_ පැහැදිලි කරන පරිදි.

### නියෝජිතයන් ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes හැර, මෙම නියෝජිතයන් mise හි lazy installation භාවිතා කරයි: පළමු දියත් කිරීමෙන් CLI එක ස්ථාපනය වන අතර, පසුකාලීන දියත් කිරීම් එයම නැවත භාවිතා කරයි. mise තවද ස්ථාපිත නියෝජිතයෙකු සඳහා නව නිකුතුවක් තිබේදැයි උපරිම වශයෙන් සෑම පැය හතරකට වරක්, එය ආරම්භ වීමට මොහොතකට පෙර හෝ shell prompt එකකදී පසුබිමේ පරීක්ෂා කරයි. එම යාවත්කාලීනය අසාර්ථක වුවහොත් හෝ ඔබ නොබැඳිව සිටියහොත්, ස්ථාපිත අනුවාදය ධාවනය වේ. `omarchy update` මඟින් Omarchy හි ඉතිරිය සමඟ ස්ථාපිත නියෝජිතයන් යාවත්කාලීන කරන අතර, `mup` mise විසින් කළමනාකරණය කරන මෙවලම් පමණක් යාවත්කාලීන කරයි.

නියෝජිතයෙකුගේම updater එක, `claude update`, `codex update`, හෝ යෙදුමක ඇති යාවත්කාලීන බොත්තම වැනි, mise විසින් කළමනාකරණය කරන ස්ථාපනය යාවත්කාලීන නොකරයි. `codex update` අසාර්ථක වන අතර, `claude update` සාර්ථක බව වාර්තා කරමින් mise විසින් නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කළ හැකිය. ඔබ නියෝජිතයෙකුගේ ස්වදේශික installer සහ updater එක භාවිතා කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [කලින් ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

සැකසූ සියලුම lazy මෙවලම් ඔබට අවශ්‍ය වීමට පෙර ස්ථාපනය කිරීමට, `mise install --include-lazy` ධාවනය කරන්න. මෙයට නියෝජිතයන් මෙන්ම Omarchy හි අනෙක් පෙරනිමි CLI මෙවලම් ද ඇතුළත් වේ. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිතා කිරීම සඳහා [කලින් ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` ස්ථාපනය වන්නේ mise හි පළමු පාර්ශ්වීය `grok` පැකේජය හරහා, `claude` සහ `codex` හා සමානවමයි. `grok` ධාවනය කරන්න, නැතහොත් _Setup > Defaults > Agent_ යටතේ එය තෝරන්න. x.ai හි ඇති `curl | bash` installer එක මඟ හරින්න. එම මාර්ගය `~/.grok/bin` තුළ දෙවන පිටපතක් තබයි, එය `PATH` හි මුලට එක් කරයි, සහ Omarchy හි wrapper එක උඩින් ලියයි.

`dsh` එහි browser UI එක `127.0.0.1:3080` මත විවෘත කරයි, දියත් කළ නාමාවලිය එහි පෙරනිමි workspace එක ලෙස ගනී. එහි browser UI එක ආරම්භක prompt එකක් නොගන්නා බැවින්, `omarchy agent prompt` එය විවෘත කරන්නේ prompt එක ඔබේ clipboard එකේ අලවන්නට ඇති පරිදිය. Omarchy එය ආරම්භ කරන්නේ DeepSeek හි අනුමැතිය-අවශ්‍ය-නැති අවසර preset එක සමඟයි. ඔබ එහි නිල ආකෘති API එක භාවිතා කරන විට DeepSeek Harness සැසි ලොග් DeepSeek වෙත උඩුගත කරයි; එහි browser UI එකේ _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ එයට යවන ප්‍රතිපෝෂණ ද සැසිය සමඟම උඩුගත වන අතර, ඔබ එය `DSH_TELEMETRY_MODE=DISABLED` සමඟ ආරම්භ කළහොත් මිස.

### පෙරනිමි නියෝජිතයා

ඔබේ පෙරනිමි නියෝජිතයා `omarchy default agent <name>` සමඟ හෝ Omarchy Menu (`Super + Space`) එකේ _Setup > Defaults > Agent_ යටතේ තෝරන්න. නියෝජිතයා තවම ස්ථාපනය කර නොමැති නම්, එය තෝරා ගැනීමෙන් පළමුව එය ස්ථාපනය වේ. අලුත් Omarchy එකක් එක් වරක් පමණක් එන දැනුම්දීමකින් මෙම තේරීම කිරීමට ඔබට ආරාධනා කරයි.

Claude තෝරා ගැනීමෙන් Chromium, Chrome, Brave, Brave Origin, සහ Edge සඳහා එහි browser extension එක සැකසීමට ද උත්සාහ කරයි. extension සැකසීම සියලුම පරිශීලකයන්ට අදාළ වන අතර ඔබේ පද්ධති මුරපදය ඉල්ලා සිටිය හැකිය; අවලංගු කිරීම හෝ අසාර්ථක extension ස්ථාපනයක් වුවද Claude තෝරාගෙන දියත් කරයි. ඔබේ browser එක නැවත ආරම්භ කරන්න, අසන විට extension එක සක්‍රිය කරන්න, සහ එය සම්බන්ධ කිරීම අවසන් කිරීමට Claude වෙත පුරනය වන්න. සම්බන්ධතාව පරීක්ෂා කිරීමට Claude තුළ `/chrome` ධාවනය කරන්න. Firefox සහ Zen මෙම extension එකට සහාය නොදක්වයි. මෙම සැකසීම එක් කිරීමට පෙර සිටම Claude ඔබේ පෙරනිමිය වී තිබුණේ නම්, extension එක ස්ථාපනය කිරීමට එය නැවත තෝරන්න.

ඔබ තෝරාගත් පසු, `Super + Shift + Ctrl + A` පෙරනිමි නියෝජිතයා වෙනමම terminal කවුළුවක දියත් කරයි (හෝ ඔබ තවම තෝරාගෙන නොමැති නම් picker එක ගෙන එයි). ඔබට `omarchy agent prompt "Review this project"` සමඟ එය කෙලින්ම කාර්යයකට දියත් කළ හැකිය. Freebuff සහ DeepSeek Harness ආරම්භක prompt එකක් නොගන්නා බැවින්, ඒ වෙනුවට ඒවා විවෘත වන්නේ prompt එක ඔබේ clipboard එකේ අලවන්නට ඇති පරිදිය. මේ ආකාරයෙන් දියත් කරන නියෝජිතයන් ඔවුන්ගේ අදාළ නවතින්න-අසන්න-එපා ආකාරවලින් අධීක්ෂණයකින් තොරව ධාවනය වන බැවින්, ඔවුන් ඇත්තටම දේවල් කිරීමට සූදානම් වන්න! MiniMax Code හි එහි අන්තර්ක්‍රියාකාරී සැසි සඳහා එවැනි ආකාරයක් නොමැති බැවින්, එය සුපුරුදු පරිදි අවසර ඉල්ලයි. සහ නියෝජිතයන් ඔබේ home නාමාවලිය සඳහා විශ්වාසය මතක තබා ගැනීම ප්‍රතික්ෂේප කරන බැවින්, `$HOME` සිට දියත් කිරීම් ඒ වෙනුවට `~/Work` තුළ ආරම්භ වේ.

terminal කෙටිමං ද ඇත: `a` වත්මන් terminal එක තුළම පෙරනිමි නියෝජිතයා ධාවනය කරන අතර, `c`, `cx`, සහ `cy` OpenCode, Claude Code, සහ Codex සෘජුවම ආරම්භ කරයි (නැවතත් ඔවුන්ගේ ස්වයංක්‍රීයව-අනුමත කරන ආකාරවලින්). තේමා වෙනස්කම් නියෝජිතයන් වෙතද සමමුහුර්ත වේ: ඔබ Omarchy තේමාව මාරු කරන විට Claude Code, Pi, OpenCode, සහ Hermes (Omarchy එය ස්ථාපනය කළ පසු) සියල්ලම ඒ අනුව හැසිරේ.

### නියෝජිතයන්ගේ පැනලය

ඉහළ තීරුවේ නියෝජිතයන්ගේ අයිකනයක් ඇත. ඔබ නියෝජිතයෙකු සැකසීමට පෙර, එහි පැනලය Claude, Codex, හෝ Grok වෙත පුරනය වීම හරහා ඔබව රැගෙන යන අතර, පළමුවැන්න ඔබේ පෙරනිමි නියෝජිතයා බවට පත්වේ. ඉන්පසු, පැනලය සෑම දායකත්වයක්ම එක් පිටුවක තබයි: එක් එක් නියෝජිතයා සහ ගිණුම එහි සැලැස්ම සමඟ, එහි පැය 5 සැසි සහ සතිපතා සීමා එකිනෙක සඳහා එය යළි සැකසෙන තෙක් ඇති කාලය සමඟ මීටරයක් (නිවැරදි ප්‍රතිශතය සඳහා hover කරන්න), හෝ ඉතිරි පෙරගෙවුම් ශේෂය, ඔබ ඒ සියල්ල හරහා භාවිතා කළ දේ හරහා මාරු වන පේළියක් යටතේ, මේ සතියේ tokens සහ ඔබ වැඩිපුරම භාවිතා කළ ආකෘතිය වැනි. _Make something_ යටතේ එය නව තේමාවක්, plugin එකක්, හෝ යෙදුමක් සඳහා ආරම්භක prompts ලබා දෙන අතර එම කාර්යය ඔබේ පෙරනිමි නියෝජිතයාට භාර දෙයි. යෙදුම් ගොඩනගන්නේ Omarchy හිම Hype, Monologue, සහ Omacut ගොඩනගා ඇති ආකාරයට, C++ සහ Qt Quick වලින්, omarchy-app agent skill එක අනුගමනය කරමින් වන අතර, ඔවුන්ට අවශ්‍ය compiler සහ Qt කොටස් ස්ථාපනය වී පැමිණේ. Claude Code, Codex, Grok, Kimi, Cursor සහ එහි Grok Bot දීමනාව, GitHub Copilot, Muse, Antigravity, Kimchi, සහ Devin ඔවුන්ගේ සීමා සමඟ මුල සිටම ආවරණය වන අතර, Hermes, Mistral Vibe, සහ Qwen Code ඔබ ඒවා භාවිතා කළ පසු ඔවුන්ගේ සැසි සහ tokens පෙන්වයි. ඔබ pi, omp, හෝ opencode හරහා භාවිතා කරන සැපයුම්කරුවන්ගේ සැලසුම් සහ යතුරු ද පෙනී යයි: OpenCode Zen සහ Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan, සහ Synthetic ඔවුන්ගේ සීමා සමඟ; Fireworks, OpenRouter, සහ DeepSeek ඔවුන්ගේ පෙරගෙවුම් ශේෂ සමඟ; සහ Local models යටතේ ඔබේම දෘඩාංග මත ඔබ ධාවනය කරන ආකෘති. සෑම නියෝජිතයෙකුම ගණන් ගනු ලබන්නේ එක් වරක් පමණි, එයට බිල් කරන්නේ කවුරුන්ද යටතේ, ඔබ එය කොපමණ harness ගණනක් හරහා ධාවනය කළත්.

ගිණුම් එකකට වඩා ඇති විට, පැනලය සෑම ගිණුමකම සීමා එක ළඟ එක පෙන්වන අතර, සක්‍රිය එක සලකුණු කරනු ලැබේ. පෙරනිමියෙන් සක්‍රිය ගිණුමක් සීමාවකින් 95% ඉක්මවන විට Omarchy ඔබට දැනුම් දෙන අතර, දැනුම්දීම ක්ලික් කිරීමෙන් වැඩිම ඉඩ ඇති ගිණුමට මාරු වේ. එය තනිවම මාරු වීමට, පැනලයේ ගිණුමක පේළිය මත hover කර Use අසල පෙනෙන Autoswitch ක්ලික් කරන්න (හෝ `m` ඔබන්න), නැතහොත් `omarchy agent account mode auto` ධාවනය කරන්න; එය ක්‍රියාත්මකව ඇති අතර, Autoswitch Use හි ස්ථානය ගන්නා අතර, එය නැවත ක්ලික් කිරීම දැනුම් දීමට ආපසු යයි. එළිපත්ත වෙනස් කිරීමට අංකයක් එක් කරන්න, `omarchy agent account mode auto 90` වල මෙන්. සෑම ගිණුමක්ම එළිපත්ත ඉක්මවා ඇත්නම්, ඔබට ඒ ගැන එක් වරක් දැනගැනීමට ලැබෙන අතර, පළමුව නිදහස් වන්නේ කුමන ගිණුමද යන්නත් සමඟය. සක්‍රිය ගිණුමක් එහි එළිපත්තෙන් ලකුණු 15ක් ඇතුළත ඇති විට (පෙරනිමියෙන් 80%), එහි සීමා සෑම 15කට වරක් වෙනුවට සෑම මිනිත්තු තුනකට වරක් පරීක්ෂා කරනු ලැබේ.

`omarchy agent account list` සෑම ගිණුමක්ම සහ එහි නවතම සීමා පෙන්වන අතර, `omarchy agent account remove work` එකක් අමතක කරන අතර, `omarchy agent account rename primary Hey` එකක් නැවත නම් කරයි (හෝ පැනලයේ ගිණුමක නම ක්ලික් කරන්න). මෙම විධාන ඔබේ පෙරනිමි නියෝජිතයාගේ ගිණුම් මත ක්‍රියා කරයි; අනෙක් සැපයුම්කරු වෙත ළඟා වීමට, පළමුව එය නම් කරන්න, `omarchy agent account use codex side` වල මෙන්. ඔබ දැනටමත් `~/.claude` හෝ `~/.codex` තුළ තිබූ පුරනය වීම _Main_ ගිණුම වන අතර එය ඇති තැනම පවතී. පැය අටකට වඩා වැඩි කාලයක් භාවිතා නොකර තැබූ ගිණුමක් _Sign-in required_ පෙන්විය හැකිය; එම ගිණුම පැනලයේදීම නැවත පුරනය කිරීමට එය ක්ලික් කරන්න, නැතහොත් එහි සැසියක් ආරම්භ කරන්න, එය තනිවම පුරනය වීම නැවත පණගන්වයි. ගිණුමක් එක් කරන විට ඔබ සතුව තිබූ MCP servers එයටද පැමිණෙන නමුත්, ඔබ පසුව `claude mcp add` සමඟ එක් කරන ඒවා ළඟා වන්නේ ඔබ ඒවා එක් කළ ගිණුමට පමණි. ### බිඳ වැටීම් හඳුනා ගැනීම

Omarchy ක්‍රියාවලි බිඳ වැටීම් සඳහා systemd-coredump නිරීක්ෂණය කරයි. යමක් segfault වූ විට, ඔබට "Process crashed" දැනුම්දීමක් ලැබෙනු ඇත — එය ක්ලික් කරන්න, එවිට බිඳ වැටීම ඔබේ පෙරනිමි නියෝජිතයාට Omarchy හි diagnose-crash skill එක සමඟ භාර දෙනු ලැබේ, එය core dump එකෙන් කරුණු ස්ථාපිත කිරීම සහ බිඳ වැටීම upstream වෙත වාර්තා කිරීම වටීදැයි තීරණය කිරීම හරහා නියෝජිතයා රැගෙන යයි. ඔබට `coredumpctl list` වෙතින් ඕනෑම PID එකකට එරෙහිව `omarchy agent crash <pid>` සමඟ එය අතින්ද ධාවනය කළ හැකිය.

නිරීක්ෂණය පෙරනිමියෙන් ක්‍රියාත්මකයි. _Trigger > Toggle > Crash Capture_ යටතේ (හෝ `omarchy toggle crash-capture` සමඟ) එය අක්‍රිය කරන්න, දැනුම්දීම් නවතී; `omarchy agent crash <pid>` තවමත් අතින් ක්‍රියා කරයි.

බිඳ වැටීම් එක් වැඩසටහන බැගින් නිහඬ කළ හැකි අතර, රෝග විනිශ්චය අවසානයේ ඔබට පිරිනමන්නේ එයයි. `omarchy crash mute hyprland` එම වැඩසටහන සඳහා පමණක් දැනුම්දීම් නවත්වන අතර, `omarchy crash mute hyprland off` ඒවා ආපසු ගෙන එන අතර, `omarchy crash mute` තනිවම ඔබ නිහඬ කළ දේ ලැයිස්තුගත කරයි. එය binary එකේ නම තරමටම එහි මාර්ගයද සතුටින් ගන්නා බැවින්, `omarchy crash mute /usr/bin/hyprland` එම දෙයම කරයි. හිස්තැනක් ඇති නමක් උපුටා දක්වන්න, `omarchy crash mute 'Some App'` වල මෙන්. අනෙක් සියල්ල තවමත් දැනුම් දෙන අතර, නිහඬ කළ වැඩසටහන තවමත් බිඳ වැටේ — මෙය මතක් කිරීම සඟවයි, එය කිසිවක් නිවැරදි නොකරයි.

### Desktop යෙදුම්

### Omarchy Skill එක

Agent skills AI හට නිශ්චිත මෙවලම් නිශ්චිත ආකාරයකින් භාවිතා කිරීමට උපකාර කරන අතර, Omarchy පද්ධතිය අභිරුචිකරණය කිරීම සඳහා පෙරනිමි skill එකක් සමඟ පැමිණේ. ඔබේ Hyprland config එක වෙනස් කිරීම, තීරුව සකස් කිරීම, හෝ මුල සිටම නව තේමාවක් නිර්මාණය කිරීම වැනි. එය Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ එක් එක් `~/.hermes/profiles/*/skills`), සහ පොදු `~/.agents/skills` ස්ථානය සඳහා skill නාමාවලි තුළට symlinked කර ඇති බැවින්, බොහෝ harness එය ස්වයංක්‍රීයවම ලබාගනී.

නමුත් ඔබ මෙම skill එක පරීක්ෂණාත්මක ලෙස සැලකිය යුතුය. විවිධ ආකෘති එය විවිධ ප්‍රතිඵල සඳහා භාවිතා කරනු ඇත. නියෝජිතයා වෙනස් කිරීමට කැමති දේ පිළිබඳ අදහසක් ඔබට ලැබෙන පරිදි, පළමුව plan mode එකෙන් ධාවනය කිරීම වඩාත් සුදුසුය. සහ නියෝජිතයා සියල්ල අවුල් කර දමන්නේ නම්, වෙනස්කම් rollback කිරීමට හෝ `omarchy reinstall configs` පවා ක්‍රියාත්මක කිරීමට සූදානම්ව සිටින්න.
