# AI

ඔබ වෙනුවෙන් පෙරනිමියක් තෝරා නොදී, පහත කේතකරණ ඒජන්ට්වරුන් සඳහා දියත්කරුවන් Omarchy හි ඇතුළත් වේ. පළමු වරට භාවිත කරන විට එහි CLI එක ස්ථාපනය කිරීමට විධානයක් ධාවනය කරන්න, ඉන්පසු විමසූ විට සත්‍යාපනය කරන්න. Hermes සහ OpenClaw යනු ව්‍යතිරේකයන්ය: mise හරහා ඒවා සඳහා කිසිවක් ස්ථාපනය නොකෙරෙන අතර, ඒවායින් එකක් තේරීමෙන් එහිම ස්වයං-යාවත්කාලීන පිටපත පිහිටුවනු ලැබේ, පහත _ඩෙස්ක්ටොප් යෙදුම්_ විස්තර කරන පරිදිය.

### ඒජන්ට්වරුන් ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes සහ OpenClaw හැර, මෙම ඒජන්ට්වරුන් mise හි කල් දැමූ ස්ථාපනය භාවිත කරයි: පළමු දියත් කිරීමේදී CLI එක ස්ථාපනය වන අතර, පසුකාලීන දියත් කිරීම්වලදී එයම නැවත භාවිත වේ. mise විසින්ද ස්ථාපිත ඒජන්ට් එකක් සඳහා නව නිකුතුවක් තිබේදැයි උපරිම වශයෙන් සෑම පැය හතරකට වරක්, එය ආරම්භ වීමට මොහොතකට පෙර හෝ shell විමසුමකදී පසුබිමේ පරීක්ෂා කරයි. එම යාවත්කාලීනය අසාර්ථක වුවහොත් හෝ ඔබ නොබැඳි නම්, ස්ථාපිත අනුවාදය ධාවනය වේ. `omarchy update` මගින් ස්ථාපිත ඒජන්ට්වරුන් Omarchy හි ඉතිරිය සමඟ යාවත්කාලීන කරන අතර, `mup` මගින් යාවත්කාලීන කරන්නේ mise-කළමනාකරණය වන මෙවලම් පමණි.

`claude update`, `codex update`, හෝ යෙදුමක ඇති යාවත්කාලීන බොත්තම වැනි ඒජන්ට් එකකම යාවත්කාලීනකාරකය, mise-කළමනාකරණය වන ස්ථාපනය යාවත්කාලීන නොකරයි. `codex update` අසාර්ථක වන අතර, `claude update` විසින් සාර්ථක බව වාර්තා කළ හැකි වුවද mise විසින් නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කළ හැකිය. ඒ වෙනුවට ඔබ ඒජන්ට් එකකම ස්වදේශීය ස්ථාපකය සහ යාවත්කාලීනකාරකය භාවිත කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

ඔබට අවශ්‍ය වීමට පෙර සකසන ලද සියලුම කල් දැමූ මෙවලම් ස්ථාපනය කිරීමට, `mise install --include-lazy` ධාවනය කරන්න. මෙයට Omarchy හි අනෙකුත් පෙරනිමි CLI මෙවලම් මෙන්ම ඒජන්ට්වරුන්ද ඇතුළත් වේ. එක් මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිත කිරීම සඳහා [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` ස්ථාපනය කරනු ලබන්නේ mise හි ප්‍රථම-පාර්ශවීය `grok` පැකේජය හරහා, `claude` සහ `codex` ආකාරයටමය. `grok` ධාවනය කරන්න, නැතහොත් ඒජන්ට් පැනලයේ එය තරු ලකුණු කරන්න. x.ai හි ඇති `curl | bash` ස්ථාපකය මඟ හරින්න. එම මාර්ගය `~/.grok/bin` හි දෙවන පිටපතක් තබන අතර, එය `PATH` හි ඉදිරියට දමා, Omarchy හි wrapper එක උඩින් ලියයි.

`dsh` විසින් එහි browser UI එක `127.0.0.1:3080` හි විවෘත කරන අතර, දියත් කරන ලද නාමාවලිය එහි පෙරනිමි වැඩබිම වේ. එහි browser UI එක ආරම්භක විමසුමක් නොගන්නා බැවින්, `omarchy agent prompt` විසින් එය විවෘත කරන්නේ ඔබේ පසුරු පුවරුවේ අලවන්නට ඇති විමසුම සමඟය. ඔබ Claude, Codex, හෝ Grok සැලසුම් එකකට වඩා ගෙවන්නේ නම් — උදාහරණයක් ලෙස පුද්ගලික Max එකක් සහ රැකියා එකක් — Omarchy විසින් ඒ සියල්ල පුරනය වී තබා ගෙන ඒවා අතර මාරු විය හැකිය. ඒජන්ට් පැනලයේ + සමඟ දායකත්වයක් එක් කරන්න, එය එතැනදීම ඔබව ඒ හරහා ගෙන යයි, නැතහොත් `omarchy agent account add claude Work` සමඟ (හෝ `codex`, හෝ `grok`). එම + සහ විධානයම Gemini (`gemini`) සහ OpenCode (`opencode`) වෙත පුරනය වන අතර, OpenCode හි Fireworks (`fireworks`) හෝ OpenRouter (`openrouter`) API යතුරක් සුරකියි; විධානය Copilot (`copilot`), Cursor (`cursor`), සහ Muse (`muse`) වෙතද පුරනය වේ. ඒවා එක බැඟින් එක් පුරනය වීමක් තබා ගනියි. එය අතුරුදහන් වී ඇත්නම් CLI එක ස්ථාපනය කරයි. සැපයුම්කරුවෙකු සඳහා වන පළමු ගිණුම ඔබේ සාමාන්‍ය browser එක හරහා, CLI එක සැමවිටම බලන තැනදීම පුරනය වේ. ඉන්පසු සෑම එකක්ම පුද්ගලික කවුළුවක් හරහා පුරනය වේ, එවිට ඔබේ browser එක දැනටමත් පුරනය වී ඇති ගිණුම වැරදීමකින් අල්ලා ගැනෙන්නේ නැත; ඔබ එක් කරන ගිණුම ලෙස එහි පුරනය වන්න, සහ ඔබ දැනටමත් විවෘත කර තිබූ ඕනෑම පුද්ගලික කවුළුවක් පළමුව වසන්න. මෙය කිරීමට කිසිවිටෙක CLI එකෙන් ඉවත් නොවන්න: ඉවත් වීමෙන් සුරකින ලද පුරනය වීම අවලංගු වන අතර, එම ගිණුම නැවත එක් කිරීමට සිදුවනු ඇත.

### ඩෙස්ක්ටොප් යෙදුම්

Hermes පෙරනිමි ඒජන්ට් එක ලෙස තේරීමෙන් _Install > AI_ ප්‍රවේශය කරන දෙයම ස්ථාපනය කරයි: පැකේජය, සහ Hermes හිම ස්ථාපකය මගින් සකසන ලද, පළමු වරට මිනිත්තු කිහිපයක් ගත වන, `~/.hermes` යටතේ Hermes runtime එකක්. එම runtime එක පර්යන්ත `hermes` විධානය, පෙරනිමි ඒජන්ට් එක සහ යෙදුම යන සියල්ල භාවිත කරන එකම Hermes එක වන අතර, එය Omarchy නිකුතුවක් එනතුරු බලා නොසිට `hermes update` සමඟ තනිවම යාවත්කාලීන වේ. එය ස්ථාපනය කිරීමෙන් Hermes වෙත Omarchy තේමාව `omarchy` නමින් skin එකක් ලෙසද භාර දෙන අතර, ඔබ තේමා මාරු කරන විට සෑම Hermes මතුපිටක්ම එය අනුගමනය කරයි; ඔබට එය එසේ වීමට අවශ්‍ය නැත්නම් Hermes හි Appearance සැකසුම් යටතේ හෝ `/skin` සමඟ වෙනත් එකක් තෝරන්න, එවිට Omarchy එම තේරීම තනිවම තබයි. _Remove > AI_ යටතේ යෙදුම ඉවත් කිරීමෙන් පළමුව Hermes, ද්වාරයද ඇතුළුව, වසා, එම runtime එක එය සමඟ රැගෙන යන අතර, ඔබ වෙනත් ලෙස නොකියන්නේ නම් ඔබේ කතාබස්, මතකයන්, සහ Hermes තමා සඳහාම ලියූ කුසලතා තබා ගනියි: එම දත්ත සහ ඔබේ සම්බන්ධතා සැකසුම්ද යා යුතුදැයි එය අසන අතර, පෙරනිමිය නැත යන්නයි.

ඔබ සකසන සෑම කේතකරණ මොඩලයකටම යෙදුම් දියත්කරුව තුළ, මොඩලයේ නම යටතේ සහ එහි නිෂ්පාදකයාගේ ලාංඡනය සමඟ, තමාගේම ප්‍රවේශයක්ද ලැබේ, Claude, Codex හෝ Grok වෙත පුරනය වීමෙන් එකක් එක් කරන ආකාරයටම. එය එම මොඩලය මත ඔබේ ඒජන්ට් එක විවෘත කරන අතර, එය ධාවනය නොවන්නේ නම් පළමුව මොඩලය ආරම්භ කරයි: පර්යන්තය එය පූරණය වන ආකාරය පෙන්වන අතර එය සූදානම් වූ පසු ඒජන්ට් එකට භාර දෙයි. මොඩලයක් ඉවත් කිරීමෙන් එහි ප්‍රවේශය ඉවත් වේ.

LM Studio විසින් විවෘත-බර මොඩල සොයා ගැනීමට, ඒවා ස්ථාපනය කිරීමට, සහ ධාවනය කිරීමට GUI අතුරුමුහුණතක් සපයයි. එය පහසුවෙන් ආරම්භ කිරීමට කදිම ක්‍රමයකි. Ollama විසින් ඒ හා සමානව කිරීමට CLI එකක් ඉදිරිපත් කරයි. නමුත් ඔබ දේශීය මොඩලවලට අලුත් නම්, මම LM Studio සමඟ ආරම්භ කරමි. ඔබට Omarchy මෙනුවේ _Install > AI_ යටතේ ඒවායින් එකක් ස්ථාපනය කළ හැකිය.

### Omarchy කුසලතා

ඒජන්ට් කුසලතා මගින් AI හට නිශ්චිත මෙවලම් නිශ්චිත ආකාරයකින් භාවිත කිරීමට උපකාරී වන අතර, Omarchy ඒවායින් හතක් සපයයි. omarchy කුසලතාව ඔබේ Hyprland config එක වෙනස් කිරීම හෝ තීරුව ගැළපීම වැනි, පද්ධතිය සකස් කිරීම ආවරණය කරයි. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app, සහ omarchy-make-game අලුත් දෙයක් සෑදීම ආවරණය කරන අතර, omarchy-contribute මගින් දෝෂයක් වාර්තා කිරීම හෝ උඩුගං වෙත නිවැරදි කිරීමක් එවීම ආවරණය කරයි, සහ omarchy-diagnose-crash බිඳවැටීමක core dump එක හරහා ක්‍රියා කරයි. ඒවා Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ සෑම `~/.hermes/profiles/*/skills`), සහ සාමාන්‍ය `~/.agents/skills` ස්ථානය සඳහා කුසලතා නාමාවලිවලට සංකේතාත්මකව සම්බන්ධ කර ඇති බැවින්, බොහෝ harness ඒවා ස්වයංක්‍රීයව ලබා ගනියි. එම නමම ඇති ඔබේම කුසලතා ෆෝල්ඩරයකට ප්‍රමුඛතාව ලැබේ.

නමුත් ඔබ මෙම කුසලතා පර්යේෂණාත්මක ලෙස සැලකිය යුතුය. විවිධ මොඩල ඒවා විවිධ බලපෑමකට භාවිත කරනු ඇත. පළමුව සැලසුම් මාදිලියේ ධාවනය කිරීම වඩාත් සුදුසුය, එවිට ඒජන්ට් එක වෙනස් කිරීමට කැමති දේ ගැන ඔබට අදහසක් ලැබේ. ඉන්පසු ඒජන්ට් එක සියල්ල අවුල් කරන්නේ නම්, වෙනස්කම් ආපසු හැරවීමට හෝ `omarchy reinstall configs` අමතන්නට පවා සූදානම් වන්න.
