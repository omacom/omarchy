# AI

Omarchy හි පහත කේතීකරණ agents සඳහා, ඔබට පෙරනිමියක් තෝරා දීමකින් තොරවම, launchers ඇතුළත් වේ. පළමු භාවිතයේදීම එහි CLI එක ස්ථාපනය කිරීමට විධානයක් ධාවනය කරන්න, ඉන්පසු විමසූ විට සත්‍යාපනය කරන්න. Hermes සහ OpenClaw යනු ව්‍යතිරේකයන්ය: ඒ කිසිවක් සඳහා mise හරහා කිසිවක් ස්ථාපනය නොකෙරෙන අතර, ඒ දෙකෙන් එකක් තෝරා ගැනීමෙන් එහිම ස්වයං-යාවත්කාලීන වන පිටපත සකසනු ලැබේ, පහත _Desktop apps_ හි විස්තර කෙරෙන පරිදි.

### Agents ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes සහ OpenClaw හැර, මෙම agents mise හි lazy ස්ථාපනය භාවිතා කරයි: පළමු දියත් කිරීමේදී CLI එක ස්ථාපනය වන අතර, පසුකාලීන දියත් කිරීම්වලදී එයම නැවත භාවිතා වේ. එසේම mise විසින් ස්ථාපිත agent එකක් සඳහා නව නිකුතුවක් තිබේදැයි, එය ආරම්භ වීමට මොහොතකට පෙර හෝ shell prompt එකකදී පසුබිමේ, උපරිම වශයෙන් සෑම පැය හතරකට වරක් පරීක්ෂා කරයි. එම යාවත්කාලීන කිරීම අසාර්ථක වුවහොත් හෝ ඔබ නොබැඳිව සිටියහොත්, ස්ථාපිත අනුවාදය ධාවනය වේ. `omarchy update` විසින් ස්ථාපිත agents Omarchy හි ඉතිරිය සමඟ යාවත්කාලීන කරන අතර, `mup` විසින් mise මගින් කළමනාකරණය වන මෙවලම් පමණක් යාවත්කාලීන කරයි.

`claude update`, `codex update` වැනි agent කෙනෙකුගේම updater එකක් හෝ app එකක ඇති update බොත්තමක් මගින් mise මගින් කළමනාකරණය වන ස්ථාපනය යාවත්කාලීන නොකෙරේ. `codex update` අසාර්ථක වන අතර, `claude update` මගින් සාර්ථක බව වාර්තා කළ හැකි වුවද mise විසින් නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කළ හැකිය. ඔබ agent කෙනෙකුගේ native installer එක සහ updater එක භාවිතා කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

ඔබට අවශ්‍ය වීමට පෙර වින්‍යාස කළ සියලුම lazy මෙවලම් ස්ථාපනය කිරීමට, `mise install --include-lazy` ධාවනය කරන්න. මෙයට agents මෙන්ම Omarchy හි අනෙකුත් පෙරනිමි CLI මෙවලම්ද ඇතුළත් වේ. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිතා කිරීම සඳහා [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` ස්ථාපනය කෙරෙන්නේ mise හි first-party `grok` package එක හරහාය, `claude` සහ `codex` මෙන්මය. `grok` ධාවනය කරන්න, නැතහොත් agents පැනලයේ එයට තරුවක් දමන්න. x.ai හි ඇති `curl | bash` installer එක මඟ හරින්න. එම මාර්ගය මගින් `~/.grok/bin` තුළ දෙවන පිටපතක් තබන අතර, එය `PATH` එකේ ඉදිරියට දමා, Omarchy හි wrapper එක උඩින් ලියනු ලැබේ.

`dsh` විසින් එහි browser UI එක `127.0.0.1:3080` මත විවෘත කරන අතර, දියත් කළ directory එක එහි පෙරනිමි workspace එක ලෙස ගනී. එහි browser UI එක ආරම්භක prompt එකක් නොගන්නා බැවින්, `omarchy agent prompt` මගින් එය විවෘත කරන්නේ prompt එක ඔබේ clipboard එක මත අලවා ගැනීම සඳහා තබාමිනි. Omarchy එය ආරම්භ කරන්නේ DeepSeek හි no-approval permission preset එක සමඟිනි. ඔබ එහි official model API එක භාවිතා කරන විට DeepSeek Harness විසින් session logs DeepSeek වෙත upload කරයි; එහි browser UI එකේ _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ එයට යවන feedback ද session එක සමඟම upload කෙරේ, ඔබ එය `DSH_TELEMETRY_MODE=DISABLED` සමඟ ආරම්භ කළහොත් හැර.

### පෙරනිමි agent

Agents පැනලයේ agent කෙනෙකු අසල ඇති තරුව මගින්, පෙරනිමියා මත එය පුරවා ඇත, නැතහොත් එහි පේළියක් නැති ඕනෑම harness එකක්ද ගන්නා `omarchy default agent <name>` මගින් ඔබේ පෙරනිමි agent තෝරන්න. Agent තවම ස්ථාපනය කර නොමැති නම්, එය තෝරා ගැනීමෙන් පළමුව එය ස්ථාපනය කෙරෙන අතර, එයට app launcher එකේ Agent අසලම තමාගේම launcher එකක්ද ලැබේ. නැවුම් Omarchy එකක් මගින් එක් වරක් පමණක් දිස්වන දැනුම්දීමකින් එය සකසා ගැනීමට ඔබට ආරාධනා කරන අතර, එය agents පැනලය විවෘත කරයි.

Claude තෝරා ගැනීමෙන් Chromium, Chrome, Brave, Brave Origin, සහ Edge සඳහා එහි browser extension එක සකසීමටද උත්සාහ කරයි. Omarchy විසින් local LLM models ධාවනය කිරීමේ ක්‍රම දෙකක් නිර්දේශ කරයි: LM Studio සහ Ollama. LM Studio විසින් open-weight models සොයා ගැනීමට, ඒවා ස්ථාපනය කිරීමට, සහ ඒවා ධාවනය කිරීමට GUI interface එකක් සපයයි. එය පහසුවෙන් ආරම්භ කිරීමට විශිෂ්ට ක්‍රමයකි. Ollama විසින්ද එලෙසම කිරීමට CLI එකක් සපයයි. නමුත් ඔබ local models වලට අලුත් නම්, මම ආරම්භ කරන්නේ LM Studio වලිනි. ඔබට Omarchy Menu එකේ _Install > AI_ යටතේ ඒ දෙකෙන් ඕනෑම එකක් ස්ථාපනය කළ හැකිය.

### Omarchy skills

Agent skills මගින් AI වලට නිශ්චිත මෙවලම් නිශ්චිත ආකාරයකින් භාවිතා කිරීමට උපකාර වන අතර, Omarchy ඒවායින් හතක් සපයයි. Omarchy skill එක මගින් ඔබේ Hyprland config එක tweak කිරීම හෝ bar එක adjust කිරීම වැනි system එක tailor කිරීම ආවරණය කරයි. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app, සහ omarchy-make-game මගින් අලුත් දෙයක් සෑදීම ආවරණය කරන අතර, omarchy-contribute මගින් bug එකක් වාර්තා කිරීම හෝ fix එකක් upstream වෙත යැවීම ආවරණය කරන අතර, omarchy-diagnose-crash මගින් crash එකක core dump එක හරහා වැඩ කරයි. ඒවා Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ සෑම `~/.hermes/profiles/*/skills` එකක්ම), සහ generic `~/.agents/skills` ස්ථානය සඳහා වන skill directories තුළට symlink කර ඇති බැවින්, බොහෝ harnesses ඒවා ස්වයංක්‍රීයවම ලබා ගනී. එම නාමයම ඇති ඔබේම skill folder එකකට ප්‍රමුඛතාව ලැබේ.

නමුත් ඔබ මෙම skills පර්යේෂණාත්මක ලෙස සැලකිය යුතුය. විවිධ models ඒවා විවිධ ප්‍රතිඵල සඳහා භාවිතා කරනු ඇත. පළමුව plan mode එකේ ධාවනය කිරීම වඩාත් සුදුසු වන අතර, එවිට agent ට වෙනස් කිරීමට අවශ්‍ය කුමක්දැයි ඔබට අදහසක් ලැබේ. ඉන්පසු agent සියල්ල අවුල් කර දමන්නේ නම්, වෙනස්කම් rollback කිරීමට හෝ `omarchy reinstall configs` පවා භාවිතා කිරීමට සූදානම්ව සිටින්න.
