# AI

Omarchy ඔබට පෙරනිමියක් තෝරා නොදී, පහත කේතීකරණ නියෝජිතයන් සඳහා දියත් කරන්නන් ඇතුළත් කරයි. පළමු වරට භාවිතයේදී එහි CLI එක ස්ථාපනය කිරීමට විධානයක් ධාවනය කරන්න, පසුව විමසූ විට සත්‍යාපනය කරන්න. Hermes සහ OpenClaw යනු ව්‍යතිරේක දෙකය: mise හරහා ඒවා සඳහා කිසිවක් ස්ථාපනය නොකෙරේ, එමෙන්ම ඒවායින් එකක් තේරීමෙන් එහිම ස්වයං-යාවත්කාලීන වන පිටපත සැකසෙයි, පහත _පරිගණක යෙදුම්_ පැහැදිලි කරන පරිදි.

### නියෝජිතයන් ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes සහ OpenClaw හැර, මෙම නියෝජිතයන් mise හි කම්මැලි ස්ථාපනය භාවිතා කරයි: පළමු දියත් කිරීම CLI එක ස්ථාපනය කරයි, පසුව දියත් කිරීම් එය නැවත භාවිතා කරයි. mise ද ස්ථාපිත නියෝජිතයෙකු සඳහා නව නිකුතුවක් උපරිම වශයෙන් සෑම පැය හතරකට වරක්, එය ආරම්භ වීමට මොහොතකට පෙර හෝ ෂෙල් විමසුමකදී පසුබිමේ පරීක්ෂා කරයි. එම යාවත්කාලීනය අසාර්ථක වුවහොත් හෝ ඔබ නොබැඳිව සිටියහොත්, ස්ථාපිත අනුවාදය ධාවනය වේ. `omarchy update` Omarchy හි ඉතිරිය සමඟ ස්ථාපිත නියෝජිතයන් යාවත්කාලීන කරයි, සහ `mup` mise-කළමනාකරණය කෙරෙන මෙවලම් පමණක් යාවත්කාලීන කරයි.

නියෝජිතයෙකුගේම යාවත්කාලීනකය, උදාහරණයක් ලෙස `claude update`, `codex update`, හෝ යෙදුමක ඇති යාවත්කාලීන බොත්තම, mise-කළමනාකරණය කෙරෙන ස්ථාපනය යාවත්කාලීන නොකරයි. `codex update` අසාර්ථක වේ, සහ `claude update` සාර්ථක බව වාර්තා කරමින් mise විසින් නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කළ හැකිය. ඔබ නියෝජිතයෙකුගේ දේශීය ස්ථාපකය සහ යාවත්කාලීනකය භාවිතා කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [කලින් ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

වින්‍යාස කළ සියලුම කම්මැලි මෙවලම් ඔබට අවශ්‍ය වීමට පෙර ස්ථාපනය කිරීමට, `mise install --include-lazy` ධාවනය කරන්න. මෙයට නියෝජිතයන් මෙන්ම Omarchy හි අනෙකුත් පෙරනිමි CLI මෙවලම් ද ඇතුළත් වේ. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිතා කිරීම සඳහා [කලින් ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` mise හි ප්‍රථම-පාර්ශ්ව `grok` පැකේජය හරහා ස්ථාපනය කෙරේ, `claude` සහ `codex` ආකාරයටමය. `grok` ධාවනය කරන්න, නැතහොත් නියෝජිත පැනලයේ එය තරු ලකුණු කරන්න. x.ai හි `curl | bash` ස්ථාපකය මඟ හරින්න. එම මාර්ගය `~/.grok/bin` හි දෙවන පිටපතක් තබයි, එය `PATH` මත ඉදිරියට දමයි, සහ Omarchy හි දවටනය උඩින් ලියයි.

`dsh` එහි බ්‍රවුසර UI එක `127.0.0.1:3080` මත විවෘත කරයි, දියත් කරන නාමාවලිය එහි පෙරනිමි වැඩබිම ලෙස ගනියි. එහි බ්‍රවුසර UI එක ආරම්භක විමසුමක් නොගන්නා බැවින්, `omarchy agent prompt` එය විමසුම ඔබේ පසුරුපුවරුවේ අලවන්නට තබා විවෘත කරයි. CLI එක අතුරුදහන් නම් එය ස්ථාපනය කරයි. සැපයුම්කරුවෙකු සඳහා පළමු ගිණුම ඔබේ සාමාන්‍ය බ්‍රවුසරය හරහා, CLI එක සැමවිටම බලන තැනම පුරනය වේ. ඉන් පසු සෑම එකක්ම පුද්ගලික කවුළුවක් හරහා පුරනය වේ, එබැවින් ඔබේ බ්‍රවුසරය දැනටමත් පුරනය වී ඇති ගිණුම වැරදීමකින් තෝරා නොගැනේ; ඔබ එක් කරන ගිණුම ලෙස එහි පුරනය වන්න, සහ ඔබ දැනටමත් විවෘත කර තිබූ ඕනෑම පුද්ගලික කවුළුවක් පළමුව වසන්න. මෙය කිරීමට කිසිවිට CLI එකෙන් ඉවත් නොවන්න: ඉවත් වීම සුරකින ලද පුරනය වීම අවලංගු කරයි, සහ එම ගිණුම නැවත එක් කිරීමට සිදු වේ.

ඔබේ දායකත්ව පුරනය වීම් SSH හරහා තවත් Omarchy යන්ත්‍රයකට පිටපත් කිරීමට, `omarchy agent account copy user@laptop` ධාවනය කරන්න. ගමනාන්තයට එකක් ස්ථාපනය කර නොමැති විට යවන්නා තාවකාලික ග්‍රාහකයෙකු සපයයි, එබැවින් පැරණි Omarchy යන්ත්‍රවලට යාවත්කාලීනයකින් තොරව ගිණුම් ලැබිය හැකිය. ස්ථාපිත ග්‍රාහකයන්ට ප්‍රමුඛතාව ලැබේ. මෙය සියලුම Claude, Codex, සහ Grok දායකත්ව පිටපත් කරයි; ඒවා තේරීමට සැපයුම්කරු නම් එක් කරන්න, `omarchy agent account copy laptop claude` හි මෙන්. ගමනාන්තයේ දැනටමත් ඇති ගිණුම් ඇතුළුව, ගිණුම් නම් සහ විධාන ID ප්‍රභවයට ගැළපේ. සම්බන්ධ නැති ගමනාන්ත ගිණුම්වල නම් ගැටේ නම් ඒවාට සංඛ්‍යාත්මක ප්‍රත්‍යයක් ලැබේ, සහ සැකසීම්, කුසලතා, ප්ලගින, සහ සංවාද ඉතිහාසය එක් එක් යන්ත්‍රයට දේශීයව පවතී.

පවතින ගමනාන්ත අක්තපත්‍ර තබා ගනී. එහි දැනටමත් පුරනය වී ඇති ප්‍රභව ගිණුමක අක්තපත්‍ර ප්‍රතිස්ථාපනය නොකර එහි නම සමමුහුර්ත කෙරේ; අනෙකුත් ගිණුම් එය අසල එක් කෙරේ. ගැළපෙන ගිණුම් සඳහා සුරකින ලද අක්තපත්‍ර ප්‍රතිස්ථාපනය කිරීමට, ගමනාන්තයේ එම ගිණුමේ සැසිවලින් ඉවත් වූ පසු `omarchy agent account copy --replace laptop claude` භාවිතා කරන්න. නැවුම් ගමනාන්තයකට ප්‍රභවයේ සක්‍රිය ගිණුම සහ මාරු කිරීමේ මනාප ද ලැබේ; ස්ථාපිත ගමනාන්තයක් තමාගේම ඒවා තබා ගනී.

අක්තපත්‍ර SSH හරහා ගමන් කරන අතර ගමනාන්තයේ පුද්ගලික ගොනුවල ගබඩා කෙරේ, එබැවින් ඔබ විශ්වාස කරන යන්ත්‍රවලට පමණක් පිටපත් කරන්න. මෙය එක් වරක් පිටපත් කිරීමකි, අඛණ්ඩ සමමුහුර්ත කිරීමක් නොවේ. ### බිඳවැටීම හඳුනා ගැනීම

නියෝජිත කුසලතා AI හට නිශ්චිත මෙවලම් නිශ්චිත ආකාරයකින් භාවිතා කිරීමට උපකාරී වන අතර, Omarchy ඒවායින් හතක් නැව්ගත කරයි. omarchy කුසලතාව ඔබේ Hyprland වින්‍යාසය වෙනස් කිරීම හෝ තීරුව සකස් කිරීම වැනි පද්ධතිය සකස් කිරීම ආවරණය කරයි. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app, සහ omarchy-make-game අලුත් දෙයක් සෑදීම ආවරණය කරයි, omarchy-contribute දෝෂයක් වාර්තා කිරීම හෝ ඉහළට නිවැරදි කිරීමක් යැවීම ආවරණය කරයි, සහ omarchy-diagnose-crash බිඳවැටීමක core dump එක හරහා වැඩ කරයි. ඒවා Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ එක් එක් `~/.hermes/profiles/*/skills`), සහ පොදු `~/.agents/skills` ස්ථානය සඳහා කුසලතා නාමාවලිවලට සංකේතාත්මකව සම්බන්ධ කර ඇත, එබැවින් බොහෝ හාර්නස් ඒවා ස්වයංක්‍රීයව ලබා ගනියි. එකම නම ඇති ඔබේම කුසලතා ෆෝල්ඩරයකට ප්‍රමුඛතාව ලැබේ.

නමුත් ඔබ මෙම කුසලතා පර්යේෂණාත්මක ලෙස සැලකිය යුතුය. විවිධ මාදිලි එය විවිධ ප්‍රතිඵල සඳහා භාවිතා කරනු ඇත. නියෝජිතයා වෙනස් කිරීමට කැමති දේ පිළිබඳ අදහසක් ඔබට ඇති වන පරිදි, පළමුව සැලසුම් මාදිලියේ ධාවනය කිරීම වඩාත් සුදුසුය. ඉන්පසු නියෝජිතයා සියල්ල අවුල් කරන්නේ නම්, වෙනස්කම් ආපසු හැරවීමට හෝ `omarchy reinstall configs` ඇමතීමට පවා සූදානම් වන්න.
