# AI

Omarchy තුළ පහත කේතීකරණ නියෝජිතයන් සඳහා දියත් කරන්නන් ඇතුළත් වන අතර ඔබට පෙරනිමියක් තෝරා දෙන්නේ නැත. පළමු වර භාවිතයේදී එහි CLI ස්ථාපනය කිරීම සඳහා විධානයක් ධාවනය කරන්න, ඉන්පසු විමසූ විට සත්‍යාපනය කරන්න. ### නියෝජිතයන් ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes හැර, මෙම නියෝජිතයන් mise හි lazy ස්ථාපනය භාවිතා කරයි: පළමු දියත් කිරීමේදී CLI ස්ථාපනය වන අතර, පසු දියත් කිරීම්වලදී එයම නැවත භාවිතා කරයි. mise ද ස්ථාපිත නියෝජිතයෙකු සඳහා නව නිකුතුවක් තිබේදැයි උපරිම වශයෙන් සෑම පැය හතරකට වරක්, එය ආරම්භ වීමට මොහොතකට පෙර හෝ shell විමසුමකදී පසුබිමේ පරීක්ෂා කරයි. එම යාවත්කාලීනය අසාර්ථක වුවහොත් හෝ ඔබ නොබැඳිව සිටියහොත්, ස්ථාපිත අනුවාදය ධාවනය වේ. `omarchy update` මගින් ස්ථාපිත නියෝජිතයන් Omarchy හි ඉතිරිය සමඟ යාවත්කාලීන කරන අතර, `mup` මගින් යාවත්කාලීන කරන්නේ mise මගින් කළමනාකරණය වන මෙවලම් පමණි.

`claude update`, `codex update` වැනි නියෝජිතයෙකුගේම යාවත්කාලීන කරන්නා, හෝ යෙදුමක ඇති යාවත්කාලීන බොත්තම, mise මගින් කළමනාකරණය වන ස්ථාපනය යාවත්කාලීන නොකරයි. `codex update` අසාර්ථක වන අතර, `claude update` මගින් mise නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කරන අතරතුර සාර්ථක වූ බව වාර්තා කළ හැකිය. ඔබ නියෝජිතයෙකුගේ ස්වදේශීය ස්ථාපකය සහ යාවත්කාලීන කරන්නා භාවිතා කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [පෙර-ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

ඔබට අවශ්‍ය වීමට පෙර වින්‍යාස කර ඇති සියලුම lazy මෙවලම් ස්ථාපනය කිරීමට, `mise install --include-lazy` ධාවනය කරන්න. මෙයට නියෝජිතයන්ට අමතරව Omarchy හි අනෙකුත් පෙරනිමි CLI මෙවලම් ද ඇතුළත් වේ. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිතා කිරීම සඳහා [පෙර-ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` ස්ථාපනය කරනු ලබන්නේ mise හි first-party `grok` පැකේජය හරහා, `claude` සහ `codex` ආකාරයටමය. `grok` ධාවනය කරන්න, හෝ _Agent > Harness_ යටතේ එය තෝරන්න. x.ai හි ඇති `curl | bash` ස්ථාපකය මඟ හරින්න. එම මාර්ගය `~/.grok/bin` හි දෙවන පිටපතක් තබන අතර, එය `PATH` හි ඉදිරියට දමා, Omarchy හි wrapper එක උඩින් ලියයි.

`dsh` එහි බ්‍රවුසර UI එක `127.0.0.1:3080` මත විවෘත කරන අතර, දියත් කළ නාමාවලිය එහි පෙරනිමි වැඩබිම ලෙස ගනී. එහි බ්‍රවුසර UI එක ආරම්භක විමසුමක් නොගන්නා බැවින්, `omarchy agent prompt` එය විවෘත කරන්නේ ඇලවීම සඳහා විමසුම ඔබේ පසුරු පුවරුවේ තබාය. Omarchy එය ආරම්භ කරන්නේ DeepSeek හි අනුමැතිය-නොමැති අවසර පෙරසැකසුම සමඟය. ඔබ එහි නිල ආකෘති API එක භාවිතා කරන විට DeepSeek Harness සැසි ලොග DeepSeek වෙත උඩුගත කරයි; එහි බ්‍රවුසර UI එකේ _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ `DSH_TELEMETRY_MODE=DISABLED` සමඟ එය ආරම්භ නොකළහොත්, ඔබ එයට යවන ප්‍රතිපෝෂණ ද සැසිය සමඟ උඩුගත වේ.

### පෙරනිමි නියෝජිතයා

`omarchy default agent <name>` සමඟ හෝ Omarchy Menu එකේ (`Super + Space`) _Agent > Harness_ යටතේ ඔබේ පෙරනිමි නියෝජිතයා තෝරන්න. නියෝජිතයා තවම ස්ථාපනය කර නොමැති නම්, එය තෝරා ගැනීමෙන් පළමුව එය ස්ථාපනය වේ. නැවුම් Omarchy එකක් එක් වරක් පමණක් පෙන්වන දැනුම්දීමකින් මෙම තේරීම කිරීමට ඔබට ආරාධනා කරනු ඇත.

SSH හරහා ඔබේ දායකත්ව පුරනය වීම් වෙනත් Omarchy යන්ත්‍රයකට පිටපත් කිරීමට, `omarchy agent account copy user@laptop` ධාවනය කරන්න. ගමනාන්තයේ එකක් ස්ථාපනය කර නොමැති විට යවන්නා තාවකාලික ග්‍රාහකයෙකු සපයන බැවින්, පැරණි Omarchy යන්ත්‍රවලට යාවත්කාලීනයකින් තොරව ගිණුම් ලැබිය හැකිය. ස්ථාපිත ග්‍රාහකයන්ට ප්‍රමුඛතාව ලැබේ. මෙය සියලුම Claude, Codex, සහ Grok දායකත්ව පිටපත් කරයි; ඒවා තේරීමට සැපයුම්කරු නම් එක් කරන්න, `omarchy agent account copy laptop claude` හි මෙන්. ගිණුම් නම් සහ විධාන ID මූලාශ්‍රයට ගැලපෙන අතර, ගමනාන්තයේ දැනටමත් ඇති ගිණුම් ද ඊට ඇතුළත් වේ. සම්බන්ධ නොවූ ගමනාන්ත ගිණුම්වල නම් ගැටෙන්නේ නම් ඒවාට සංඛ්‍යාත්මක උපසර්ගයක් ලැබෙන අතර, සැකසුම්, කුසලතා, ප්ලගින, සහ සංවාද ඉතිහාසය එක් එක් යන්ත්‍රයට දේශීයව පවතී.

පවතින ගමනාන්ත අක්තපත්‍ර තබා ගනු ලැබේ. එහි දැනටමත් පුරනය වී ඇති මූලාශ්‍ර ගිණුමක නම එහි අක්තපත්‍ර ප්‍රතිස්ථාපනය නොකර සමමුහුර්ත කරනු ලබන අතර, අනෙකුත් ගිණුම් එයට අමතරව එක් කරනු ලැබේ. ගැලපෙන ගිණුම් සඳහා සුරකින ලද අක්තපත්‍ර ප්‍රතිස්ථාපනය කිරීමට, ගමනාන්තයේ එම ගිණුමේ සැසිවලින් ඉවත් වූ පසු `omarchy agent account copy --replace laptop claude` භාවිතා කරන්න. නැවුම් ගමනාන්තයකට මූලාශ්‍රයේ සක්‍රිය ගිණුම සහ මාරු කිරීමේ මනාප ද ලැබෙන අතර, ස්ථාපිත ගමනාන්තයක් තමන්ගේම ඒවා තබා ගනී.

එකකට වඩා ගිණුම් ඇති විට, පැනලය සෑම ගිණුමකම සීමා එක ළඟ එක පෙන්වන අතර, සක්‍රිය එක සලකුණු කරනු ලැබේ. පෙරනිමියෙන් සක්‍රිය ගිණුම සීමාවකින් 95% ඉක්මවා යන විට Omarchy ඔබට දැනුම් දෙන අතර, දැනුම්දීම ක්ලික් කිරීමෙන් වැඩිම ඉඩ ඇති ගිණුමට මාරු වේ. එය ස්වයංක්‍රීයවම මාරු වීමට, ගිණුමක පේළිය උඩින් තබා Use අසල දිස්වන Autoswitch ක්ලික් කරන්න (හෝ `m` ඔබන්න), හෝ `omarchy agent account mode auto` ධාවනය කරන්න; එය ක්‍රියාත්මකව තිබියදී, Autoswitch Use හි ස්ථානය ගන්නා අතර, එය නැවත ක්ලික් කිරීමෙන් දැනුම් දීමට ආපසු යයි. සීමාව වෙනස් කිරීමට අංකයක් එක් කරන්න, `omarchy agent account mode auto 90` හි මෙන්. සෑම ගිණුමක්ම සීමාව ඉක්මවා ඇත්නම්, කුමන ගිණුම පළමුව නිදහස් වේද යන්න සමඟ ඔබට ඒ ගැන එක් වරක් අසන්නට ලැබෙනු ඇත. සක්‍රිය ගිණුමක් එහි සීමාවේ ලක්ෂ්‍ය 15 ක් ඇතුළත තිබියදී (පෙරනිමියෙන් 80%), එහි සීමා සෑම මිනිත්තු 15 කට වරක් වෙනුවට සෑම මිනිත්තු තුනකට වරක් පරීක්ෂා කරනු ලැබේ.

Codex හි එක එය ඇති තැනම පවතින අතර, තවත් ගිණුමක් සක්‍රියව තිබියදී Claude හි එක තමන්ගේම ෆෝල්ඩරයක රැඳී සිටී. පැය අටකට වඩා වැඩි කාලයක් භාවිතා නොකළ ගිණුමක් _Sign-in required_ ලෙස පෙන්විය හැකිය; පැනලය තුළම එම ගිණුමට නැවත පුරනය වීමට එය ක්ලික් කරන්න, හෝ එයට මාරු වී සැසියක් ආරම්භ කරන්න, එය තනිවම පුරනය වීම නැවුම් කරයි. ඔබ `claude mcp add` සමඟ එක් කරන MCP සේවාදායකයන් සෑම Claude ගිණුමකටම ළඟා වේ, මන්ද ඒ සියල්ල `~/.claude` තුළ ධාවනය වන බැවිනි; Codex සහ Grok සඳහා, ගිණුමක් එක් කරන විට ඔබට තිබූ සේවාදායකයන් එයට පැමිණෙන නමුත්, පසුව එක් කළ ඒවා ළඟා වන්නේ ඔබ ඒවා එක් කළ ගිණුමට පමණි. ### බිඳවැටීම් විනිශ්චය

Omarchy ක්‍රියාවලි බිඳවැටීම් සඳහා systemd-coredump නිරීක්ෂණය කරයි. යමක් segfault වූ විට, ඔබට "Process crashed" දැනුම්දීමක් ලැබෙනු ඇත — එය ක්ලික් කරන්න, එවිට බිඳවැටීම core dump එකෙන් කරුණු තහවුරු කර ගැනීම සහ බිඳවැටීම upstream වෙත වාර්තා කිරීම වටිනවාද යන්න තීරණය කිරීම හරහා නියෝජිතයා ගෙන යන Omarchy හි diagnose-crash කුසලතාව සමඟ ඔබේ පෙරනිමි නියෝජිතයාට භාර දෙනු ලැබේ. ඔබට `coredumpctl list` වෙතින් ඕනෑම PID එකකට එරෙහිව `omarchy agent crash <pid>` සමඟ එය අතින් ද ධාවනය කළ හැකිය.

නිරීක්ෂණය පෙරනිමියෙන් ක්‍රියාත්මකයි. _Trigger > Toggle > Crash Capture_ යටතේ (හෝ `omarchy toggle crash-capture` සමඟ) එය අක්‍රිය කරන්න, එවිට දැනුම්දීම් නවතිනු ඇත; `omarchy agent crash <pid>` තවමත් අතින් ක්‍රියා කරයි.

බිඳවැටීම් එක් වැඩසටහනකට බැගින් ද නිහඬ කළ හැකි අතර, විනිශ්චය අවසානයේ ඔබට ඉදිරිපත් කරන්නේ එයයි. `omarchy crash mute hyprland` එම වැඩසටහන සඳහා පමණක් දැනුම්දීම් නවත්වන අතර, `omarchy crash mute hyprland off` ඒවා ආපසු ගෙන එන අතර, `omarchy crash mute` තනිවම ඔබ නිහඬ කර ඇති දේ ලැයිස්තු කරයි. එය ද්විමය ගොනුවේ මාර්ගය එහි නම තරමටම සතුටින් ගන්නා බැවින්, `omarchy crash mute /usr/bin/hyprland` එකම දෙය කරයි. එහි ඉඩක් ඇති නමක් උපුටා දක්වන්න, `omarchy crash mute 'Some App'` හි මෙන්. අනෙක් සියල්ල තවමත් දැනුම් දෙන අතර, නිහඬ කළ වැඩසටහන තවමත් බිඳ වැටේ — මෙය මතක් කිරීම සඟවනවා මිස කිසිවක් නිවැරදි නොකරයි.

### Desktop apps

_Install > AI_ මෙනුව තවත් චිත්‍රක AI යෙදුම් කිහිපයක් ද රැගෙන යයි: ChatGPT desktop app එක, Claude desktop app එක (Chat, Cowork, සහ Claude Code ටැබ් සහිත Anthropic හි Linux beta එක), xAI හි ආකෘති සමඟ කතාබස් කිරීමට Grok Bot, Herdr Desktop, Hermes Desktop, OpenClaw, Perplexity desktop app එක, සහ T3 Code. Grok Bot යනු desktop chat app එකයි. කේතීකරණ නියෝජිතයා වන්නේ `grok` විධානයයි.

Hermes Desktop යනු දැනගත යුතු එකයි, මන්ද යන්ත්‍රයක එක් Hermes එකක් ඇති අතර, එය යෙදුමට අයත් වෙයි: Hermes ස්ථාපනය කරන්නේ කවදත් යෙදුම හරහා පමණක් වන අතර, පෙරනිමි නියෝජිතයා ධාවනය කරන `hermes` විධානය යෙදුමට අයත් වෙයි. පෙරනිමි නියෝජිතයා ලෙස Hermes තෝරා ගැනීමෙන් _Install > AI_ ඇතුළත් කිරීම කරන එකම දෙය ස්ථාපනය වේ: පැකේජය, සහ පළමු වර විනාඩි කිහිපයක් ගත වන Hermes හිම ස්ථාපකය මගින් සකසන ලද `~/.hermes` යටතේ ඇති Hermes runtime එක. එම runtime එක තමයි පර්යන්ත `hermes` විධානය, පෙරනිමි නියෝජිතයා සහ යෙදුම යන සියල්ල භාවිතා කරන එකම Hermes වන්නේ, සහ එය Omarchy නිකුතුවක් එන තෙක් බලා නොසිට `hermes update` සමඟ තනිවම යාවත්කාලීන වේ. එය ස්ථාපනය කිරීමෙන් Hermes වෙත Omarchy තේමාව `omarchy` නමින් skin එකක් ලෙස ද භාර දෙන අතර, ඔබ තේමා මාරු කරන විට සෑම Hermes පෘෂ්ඨයක්ම එය අනුගමනය කරයි; ඔබට එය එසේ වීමට අවශ්‍ය නැත්නම් Hermes හි Appearance සැකසුම් යටතේ හෝ `/skin` සමඟ වෙනත් එකක් තෝරන්න, එවිට Omarchy එම තේරීම එලෙසම තබයි. _Remove > AI_ යටතේ යෙදුම ඉවත් කිරීමෙන් පළමුව Hermes, gateway එක ද ඇතුළුව, වසා දමන අතර, එම runtime එක එය සමඟ රැගෙන යන අතර, ඔබ වෙනත් ආකාරයකට නොකියන තාක් ඔබේ කතාබස්, මතක, සහ Hermes තමා සඳහාම ලියූ කුසලතා තබා ගනී: එම දත්ත සහ ඔබේ සම්බන්ධතා සැකසුම් ද යා යුතුදැයි එය විමසන අතර, පෙරනිමිය නැත යන්නයි.

OpenClaw හි desktop අත්දැකීම වන්නේ එහි Control UI එක වන අතර, එය තමන්ගේම දේශීය gateway එකකින් පසුබලය ලබන web app එකක් ලෙස විවෘත වේ. ### The Omarchy Skill

නියෝජිත කුසලතා AI හට විශේෂිත මෙවලම් විශේෂිත ආකාරයකින් භාවිතා කිරීමට උපකාරී වන අතර, Omarchy පද්ධතිය රිසි කිරීම සඳහා පෙරනිමි කුසලතාවක් සමඟ පැමිණේ. ඔබේ Hyprland config එක වෙනස් කිරීම, තීරුව සකස් කිරීම, හෝ මුල සිටම නව තේමාවක් නිර්මාණය කිරීම වැනි. එය Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ එක් එක් `~/.hermes/profiles/*/skills`), සහ පොදු `~/.agents/skills` ස්ථානය සඳහා කුසලතා නාමාවලිවලට symlink කර ඇති බැවින්, බොහෝ harness එය ස්වයංක්‍රීයවම ලබා ගනී.
