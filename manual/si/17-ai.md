### Agents install කිරීම සහ update කිරීම

Hermes සහ OpenClaw හැර, සෑම agent එකක්ම Omarchy හිම repository එකෙන් ලැබෙන package එකකි. _Install > AI > CLI_ වෙතින් හෝ `omarchy install ai cli <command>` සමඟ එකක් install කරන්න, එය _Remove > AI > CLI_ වෙතින් නැවත ඉවත් කරන්න, එමඟින් එහි sign-ins සහ history එලෙසම පවතියි. තවම install කර නැති agent එකක් තේරීමෙන් එයද install වේ: agents panel එකේ එයට star කිරීමෙන්, `omarchy default agent <name>` සමඟ එය තේරීමෙන්, හෝ එහි subscription එකට sign in වීමෙන්. Omarchy agent එකක සෑම නව release එකක්ම පැයක් ඇතුළත, සෑම channel එකකටම ප්‍රකාශයට පත් කරන අතර, `omarchy update` එය පද්ධතියේ ඉතිරිය සමඟ install කරයි.

pacman ඒවා යාවත්කාලීනව තබා ගන්නා බැවින්, agents හිම updaters අක්‍රිය කර ඇත: `claude update` හෝ app එකක ඇති update බොත්තමකට කිරීමට කිසිවක් නැත. ඔබ agent එකක් එහිම installer එකෙන් ධාවනය කිරීමට කැමති නම්, එය භාවිතා කර Omarchy හි package එක install නොකර තබන්න; ඔබේ `PATH` එකේ දැනටමත් ඇති පිටපතක් install කර ඇති ලෙස ගණන් ගනු ලැබේ. x.ai හි `grok` සඳහා වූ installer එක වැනි, Omarchy හි පිටපතට ඉදිරියෙන් `PATH` එකේ දෙවන පිටපතක් තබන `curl | bash` installers මඟ හරින්න.

`dsh` එහි browser UI එක `127.0.0.1:3080` මත විවෘත කරන අතර, launch directory එක එහි පෙරනිමි workspace එක වේ. එහි browser UI එක ආරම්භක prompt එකක් නොගන්නා බැවින්, `omarchy agent prompt` එය විවෘත කරන්නේ prompt එක ඔබේ clipboard එකේ තබා paste කිරීමටය. Omarchy එය DeepSeek හි no-approval permission preset එක සමඟ ආරම්භ කරයි. DeepSeek Harness ඔබ එහි නිල model API එක භාවිතා කරන විට session logs DeepSeek වෙත upload කරයි; එහි browser UI එකේ _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ එයට එවන Feedback ද, ඔබ එය `DSH_TELEMETRY_MODE=DISABLED` සමඟ ආරම්භ නොකළහොත්, session එක සමඟ upload කරනු ලැබේ.

### පෙරනිමි agent

Agents panel එකේ agent එකක් අසල ඇති star එකෙන් ඔබේ පෙරනිමි agent තෝරන්න, එය පෙරනිමිය මත පිරී ඇත, හෝ `omarchy default agent <name>` සමඟ තෝරන්න, එය එහි පේළියක් නැති ඕනෑම harness එකක්ද ගනියි. Agent එක තවම install කර නැති නම්, එය තේරීමෙන් පළමුව එය install කරන අතර, එයට app launcher එකේ, Agent අසල, එයටම වෙන් වූ launcher එකක්ද ලැබේ. අලුත් Omarchy එකක් එක් වරක් පමණක් පෙන්වන notification එකකින් එකක් සකසා ගන්නා ලෙස ඔබට ආරාධනා කරයි, එය agents panel එක විවෘත කරයි.

Claude තේරීමෙන් Chromium, Chrome, Brave, Brave Origin, සහ Edge සඳහා එහි browser extension එක සකසීමටද උත්සාහ කරයි. Extension සැකසුම සියලුම users ලට අදාළ වන අතර ඔබේ system password එක ඉල්ලා සිටිය හැකිය; අවලංගු කිරීම හෝ අසාර්ථක extension install එකක් වුවද Claude තෝරා එය launch කරයි. ඔබේ browser එක restart කරන්න, අසන්නේ නම් extension එක enable කරන්න, සහ එය සම්බන්ධ කිරීම අවසන් කිරීමට Claude වෙත sign in වන්න. සම්බන්ධතාව පරීක්ෂා කිරීමට Claude තුළ `/chrome` ධාවනය කරන්න. Firefox සහ Zen මෙම extension එකට සහාය නොදක්වයි. මෙම සැකසුම එක් කිරීමට පෙර Claude දැනටමත් ඔබේ පෙරනිමියව තිබුණේ නම්, extension එක install කිරීමට එය නැවත තෝරන්න.

ඔබ තෝරා ගත් පසු, `Super + Shift + Ctrl + A` මඟින් පෙරනිමි agent කැප වූ terminal window එකක launch කරයි (හෝ ඔබ තවම තෝරා නැති නම් picker එක ගෙන එයි). `omarchy agent prompt "Review this project"` සමඟ ඔබට එය කෙලින්ම task එකකටද launch කළ හැකිය. Freebuff සහ DeepSeek Harness ආරම්භක prompt එකක් නොගන්නා බැවින්, ඒවා ඒ වෙනුවට prompt එක ඔබේ clipboard එකේ තබා paste කිරීමට විවෘත වේ. මේ ආකාරයෙන් launch කරන agents ඔවුන්ගේ අදාළ don't-stop-to-ask modes වලින් නොසැලකිලිමත්ව ධාවනය වේ, එබැවින් ඔවුන් සැබවින්ම දේවල් කිරීමට සූදානම්ව සිටින්න! MiniMax Code එහි interactive sessions සඳහා එවැනි mode එකක් නැත, එබැවින් එය සුපුරුදු පරිදි permissions ඉල්ලයි. තවද agents ඔබේ home directory එක සඳහා trust එක මතක තබා ගැනීම ප්‍රතික්ෂේප කරන බැවින්, `$HOME` වෙතින් කරන launches ඒ වෙනුවට `~/Work` තුළ ආරම්භ වේ.

Terminal shortcuts ද ඇත: `a` මඟින් පෙරනිමි agent වත්මන් terminal එකේ inline ලෙස ධාවනය වන අතර, `c`, `cx`, `cy`, සහ `ca` මඟින් OpenCode, Claude Code, Codex, සහ Antigravity කෙලින්ම ආරම්භ කරයි (නැවතත් ඔවුන්ගේ auto-approving modes වලින්). Theme වෙනස්කම් agents වෙතද sync වේ: Claude Code, Pi, OpenCode, සහ Hermes (Omarchy එය install කළ පසු) ඔබ Omarchy theme එක මාරු කරන විට එය අනුගමනය කරයි.

### Crash diagnosis

Omarchy process crashes සඳහා systemd-coredump නිරීක්ෂණය කරයි. ඔබ පෙරනිමි agent එකක් තෝරා ගත් පසු, core dump කරන ඔබේ ඕනෑම program එකක් "Process crashed" notification එකක් ගෙන එයි — එය click කරන්න, එවිට crash එක Omarchy හි omarchy-diagnose-crash skill එක සමඟ ඔබේ පෙරනිමි agent වෙත භාර දෙනු ලැබේ, එය core dump එකෙන් කරුණු තහවුරු කර crash එක upstream වාර්තා කිරීම වටිනවාද යන්න තීරණය කිරීම හරහා agent ව රැගෙන යයි. `coredumpctl list` වෙතින් ඕනෑම PID එකකට එරෙහිව `omarchy agent crash <pid>` සමඟ ඔබට එය අතින්ද ධාවනය කළ හැකිය.

නිරීක්ෂණය පෙරනිමියෙන් ක්‍රියාත්මකයි. _Trigger > Toggle > Crash Capture Off_ යටතේ (හෝ `omarchy toggle crash-capture` සමඟ) එය අක්‍රිය කරන්න, එවිට notifications නතර වේ; `omarchy agent crash <pid>` තවමත් අතින් ක්‍රියා කරයි.

Crashes එක් program එක බැගින් නිශ්ශබ්ද කිරීමටද හැකිය, එය diagnosis එක අවසානයේ ඔබට ඉදිරිපත් කරන දෙයයි. `omarchy crash mute hyprland` එම program එක සඳහා පමණක් notifications නතර කරයි, `omarchy crash mute hyprland off` ඒවා ආපසු ගෙන එයි, සහ `omarchy crash mute` තනිවම ඔබ mute කර ඇති දේ list කරයි. එය binary එකේ නම මෙන්ම එහි path එකද සතුටින් ගනියි, එබැවින් `omarchy crash mute /usr/bin/hyprland` එකම දෙය කරයි. `omarchy crash mute 'Some App'` හි මෙන්, එහි space එකක් ඇති නමක් quote කරන්න. අන් සියල්ල තවමත් දැනුම් දෙන අතර, muted program එක තවමත් crash වේ — මෙය reminder එක සඟවයි, එය කිසිවක් fix නොකරයි.

එය මෙම machine එක සඳහා හොඳම text model එක, ඔබේ agents භාවිතා කරන වර්ගය, සකසයි. Image, video සහ music models වලට ඔවුන්ටම වෙන් වූ best එකක් ඇත: `omarchy models use best image`, `video` හෝ `music`. මෙම machine එක සඳහා එක් එක් වර්ගයේ තේරීම බැලීමට `omarchy models use best` ධාවනය කරන්න.

නැතහොත් agents panel එකේ + තෝරන්න: _Use a local model_ යටතේ එය මෙම machine එකට ගැලපෙන සෑම coding model එකක්ම, නිර්දේශිත එක පළමුව, list කරයි. Models ධාවනය කරන Podman, Omarchy සමඟ පැමිණෙන අතර, NVIDIA machine එකක NVIDIA හි container toolkit එකද එසේම වන අතර, එය ඒවාට GPU එක ලබා දෙයි; ඒවායින් එකක් නැති නම්, පළමු සැකසුම එය install කරයි. ඉන්පසු Omarchy මෙම machine එක සඳහා නිර්දේශිත model එක තෝරා, එය download කර, ආරම්භ කරයි. GB දස ගණනක download එකක් සහ model එක ධාවනය වන අතරතුර machine එකේ මතකයෙන් වැඩි කොටසක් භාවිතයේ තිබීම අපේක්ෂා කරන්න: Flash Next එහි සම්පූර්ණ 256K context එක සමඟ 100 GiB පමණ භාවිතා කරයි. වෙනත් models වලට එයට අවශ්‍ය මතකය තිබේ නම්, එය නතර කර සකසා ඇති අතර, ඔබ එකක් නැවැත්වූ පසු ආරම්භ වීමට සූදානම්ව සිටියි. Model එක logout වූ විට නතර වේ; ඔබට වෙනත් දෙයක් සඳහා මතකය අවශ්‍ය වූ විට එය ඔබම නවත්වන්න.

`omarchy models list` විකල්ප පෙන්වන අතර සමහරක් නොගැලපෙන්නේ ඇයිදැයි පැහැදිලි කරයි. තවත් එකක් සකසා ගැනීමට, `omarchy models use <recipe>` ධාවනය කරන්න. අද වන විට, 128 GB Strix Halo machines සඳහා `qwen3.8-flash-next-gufo` සහ `qwen3.8-27b-gufo` ලබා ගත හැකිය; 27B එක 40 GiB පමණ ගන්නා බැවින්, එය වෙනත් වැඩ සඳහා ඉඩ තබයි. Intel හි Arc B390 සහිත 64 GB laptop එකක, `qwen3.6-35b-a3b-llamacpp` 30 GiB පමණකින් ධාවනය වේ. නව recipes සහ නිර්දේශ package එක හරහා `omarchy update` සමඟ පැමිණේ.

ඔබ එක් කරන coding model එකකට agents panel එකේ, ඔබේ subscriptions අසල, එයටම වෙන් වූ පේළියක් ලැබේ: එය ආරම්භ කිරීමට play, එය නවත්වා එහි මතකය නිදහස් කිරීමට pause, එය ධාවනය වන අතරතුර ඔබේ tailnet එකේ අනෙකුත් machines සමඟ එය බෙදා ගැනීමට Tailscale ලකුණ, සහ එය මත ඔබේ agent විවෘත කිරීමට terminal බොත්තම. එහි පේළිය download, load හෝ stop එක සිදුවන අතරතුර එය පෙන්වන අතර, එය ආරම්භ කිරීමට ප්‍රමාණවත් නිදහස් මතකයක් නැති විට එය පවසයි, නැතහොත් එය error එකක් සමඟ නැවැත්වූ විට එහි logs වෙත link කරයි. ඒවා මතකයේ එකට ගැලපෙන විට කිහිපයක් එකවර ධාවනය විය හැකිය. Machine එකෙන් model එක ඉවත් කිරීමට, download එකද ඇතුළුව, තෝරාගත් පේළියක් මත Delete ඔබන්න; + මඟින් එය නැවත සකසා ගත හැකිය. Terminal එකකින් සකසන ලද coding model එකක් ඔබ එය එක් කරන තෙක් + යටතේ බලා සිටින අතර, ඔබ යුගල කළ machine එකක් (`omarchy models pair <host>`) ධාවනය කරන models ද එසේමය.

ඔබ සකසන සෑම coding model එකකටම app launcher එකේ, model එකේ නමින් සහ එහි සාදන්නාගේ logo එක සමඟ, එයටම වෙන් වූ entry එකක් ලැබේ, Claude, Codex හෝ Grok වෙත sign in වීමෙන් එකක් එක් කරන ආකාරයටම. එය එම model එක මත ඔබේ agent විවෘත කරන අතර, එය ධාවනය නොවන්නේ නම් පළමුව model එක ආරම්භ කරයි: terminal එක එය loading වන බව පෙන්වා, එය සූදානම් වූ පසු agent වෙත භාර දෙයි. Model එකක් ඉවත් කිරීමෙන් එහි entry එක ඉවත් වේ.

සෑම model එකක්ම coding සඳහා නොවේ. Image, video සහ music models ඒ වෙනුවට Fantasi තුළ විවෘත වේ, එය මෙම machine එකේ ධාවනය වන model එකකින් pictures, video සහ music සෑදීම සඳහා වූ Omarchy හි app එක වන අතර, එහි හෝ `omarchy models` සමඟ කළමනාකරණය කරනු ලැබේ.

Model එකක් එය සකසා ඇති ආකාරයටම දිගටම ධාවනය වන බැවින්, Omarchy update එකක් කිසිවිට ඔබේ agents යට එකක් restart නොකරයි. Omarchy සතුව ඔබ සකසා ඇති model එකක් සඳහා නව runtime එකක් හෝ නව weights ඇති විට, එහි පේළිය update බොත්තමක් පෙන්වයි: එය ඔබන්න, එවිට model එක පසුබිමේ නැවත සකසනු ලැබේ, වෙනස් වූ දේ පමණක් download කර, නව version එක මත restart වේ. නතර කර තිබූ model එකක් නතර කරම පවතියි. `omarchy models update` terminal එකකින් සෑම model එකක් සඳහාම එකම දෙය කරයි.

Command line එකෙන්, `omarchy models start <recipe>` සහ `omarchy models stop <recipe>` එකම දෙය කරයි, `omarchy models status` සෑම model එකක්ම පෙන්වයි, සහ `omarchy agent --local-model <recipe>` ඔබේ පෙරනිමි agent එක කුමක් වුවද එම model එක pi තුළ විවෘත කරයි. ඔබේ local model එක agent hotkey එක, Quake console එක, සහ _Make something_ විවෘත කරන දෙය බවට පත් කිරීමට, `omarchy default agent local` ධාවනය කරන්න හෝ agents panel එකේ ධාවනය වන model එකකට star කරන්න. pi ද ඔබ සකසා ඇති සෑම model එකක්ම, සහ ඔබ යුගල කළ machines වල ඇති ඒවාද, එහිම model picker එකේ list කරන බැවින්, සරල `pi` එකකින්ද ඒවාට ළඟා විය හැකිය. ඕනෑම OpenAI-compatible client එකකටද සම්බන්ධ විය හැකිය: `status` එක් එක් model එකේ address එක පෙන්වයි (පළමු එක `http://127.0.0.1:11435/v1`), recipe නම model එක වන අතර, key එක `~/.config/omarchy/agent-local/key` තුළ ඇත.

`omarchy models remove <recipe>` model එකක් සහ වෙනත් කිසිම model එකක් භාවිතා නොකරන downloads මකා දමයි.

Third-party runtimes ඒවායේ publisher සමඟ label කර ඇත. Omarchy සෑම model එකක්ම network access එකක් නොමැතිව ධාවනය කරයි.

### Local LLMs

Omarchy local LLM models ධාවනය කිරීමට ක්‍රම දෙකක් නිර්දේශ කරයි: LM Studio සහ Ollama. LM Studio open-weight models සොයා ගැනීමට, ඒවා install කිරීමට, සහ ඒවා ධාවනය කිරීමට GUI interface එකක් සපයයි. පහසුවෙන් ආරම්භ කිරීමට එය කදිම ක්‍රමයකි. Ollama ඒ හා සමානව කිරීමට CLI එකක් ඉදිරිපත් කරයි. නමුත් ඔබ local models වලට අලුත් නම්, මම LM Studio වලින් පටන් ගන්නෙමි.
