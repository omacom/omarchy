# AI

Omarchy විසින් ඔබට පෙරනිමියක් තෝරා දීමකින් තොරව පහත coding agents සඳහා launchers ඇතුළත් කරයි. පළමු වරට භාවිතා කරන විට එහි CLI ස්ථාපනය කිරීමට විධානයක් ධාවනය කරන්න, ඉන්පසු අසන විට authenticate කරන්න. Hermes සහ OpenClaw යනු ව්‍යතිරේකයන්ය: mise හරහා ඒවා සඳහා කිසිවක් ස්ථාපනය නොකෙරේ, එමෙන්ම ඒ දෙකෙන් එකක් තෝරා ගැනීමෙන් එහිම self-updating පිටපත සකස් කෙරේ, පහත _ඩෙස්ක්ටොප් යෙදුම්_ හි විස්තර කෙරෙන පරිදි.

### agents ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes සහ OpenClaw හැර, මෙම agents mise හි lazy installation එක භාවිතා කරයි: පළමු දියත් කිරීමේදී CLI එක ස්ථාපනය වන අතර, පසු දියත් කිරීම්වලදී එයම නැවත භාවිතා කරයි. එමෙන්ම mise විසින් ස්ථාපිත agent එකක් සඳහා නව නිකුතුවක් තිබේදැයි උපරිම වශයෙන් සෑම පැය හතරකට වරක්, එය ආරම්භ වීමට මොහොතකට පෙර හෝ shell prompt එකකදී පසුබිමේ පරීක්ෂා කරයි. එම යාවත්කාලීනය අසාර්ථක වුවහොත් හෝ ඔබ offline නම්, ස්ථාපිත අනුවාදය ධාවනය වේ. `omarchy update` මඟින් Omarchy හි ඉතිරි කොටස් සමඟ ස්ථාපිත agents යාවත්කාලීන කරයි, සහ `mup` මඟින් mise මඟින් කළමනාකරණය වන මෙවලම් පමණක් යාවත්කාලීන කරයි.

`claude update`, `codex update`, හෝ යෙදුමක ඇති update බොත්තමක් වැනි agent එකකම updater එකක්, mise මඟින් කළමනාකරණය වන ස්ථාපනය යාවත්කාලීන නොකරයි. `codex update` අසාර්ථක වන අතර, `claude update` මඟින් සාර්ථක වූ බව වාර්තා කළ හැකි වුවද mise විසින් නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කරයි. ඔබ agent එකක native installer එක සහ updater එක භාවිතා කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [Preinstalled CLI tools](18-development-tools.md#preinstalled-cli-tools) බලන්න.

ඔබට අවශ්‍ය වීමට පෙර වින්‍යාස කර ඇති සියලුම lazy tools ස්ථාපනය කිරීමට, `mise install --include-lazy` ධාවනය කරන්න. මෙයට agents වලට අමතරව Omarchy හි අනෙකුත් පෙරනිමි CLI tools ද ඇතුළත් වේ. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිතා කිරීම සඳහා [Preinstalled CLI tools](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` ස්ථාපනය කෙරෙන්නේ mise හි first-party `grok` package එක හරහාය, `claude` සහ `codex` ස්ථාපනය කෙරෙන ආකාරයටමය. `grok` ධාවනය කරන්න, නැතහොත් _Agent > Harness_ යටතේ එය තෝරන්න. x.ai හි ඇති `curl | bash` installer එක මඟ හරින්න. එම මාර්ගය මඟින් `~/.grok/bin` හි දෙවැනි පිටපතක් තබන අතර, එය `PATH` මත ඉදිරියට ගෙන එමින් Omarchy හි wrapper එක උඩින් ලියයි.

`dsh` මඟින් එහි browser UI එක `127.0.0.1:3080` මත විවෘත කරන අතර, දියත් කළ directory එක එහි පෙරනිමි workspace එක වේ. එහි browser UI එක starting prompt එකක් නොගන්නා බැවින්, `omarchy agent prompt` මඟින් එය විවෘත කරන්නේ paste කිරීමට ඔබේ clipboard එක මත prompt එක සහිතවය. Omarchy එය ආරම්භ කරන්නේ DeepSeek හි no-approval permission preset එක සමඟය. ඔබ එහි official model API එක භාවිතා කරන විට DeepSeek Harness විසින් session logs DeepSeek වෙත upload කරයි; එහි browser UI එකේ _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ එයට යවන feedback ද session එක සමඟම upload කෙරේ, ඔබ එය `DSH_TELEMETRY_MODE=DISABLED` සමඟ ආරම්භ නොකළහොත්.

### පෙරනිමි agent

`omarchy default agent <name>` සමඟ හෝ Omarchy Menu එකේ (`Super + Space`) _Agent > Harness_ යටතේ ඔබේ පෙරනිමි agent තෝරන්න. agent තවම ස්ථාපනය කර නොමැති නම්, එය තෝරා ගැනීමෙන් පළමුව එය ස්ථාපනය වන අතර, එයටම app launcher එකේ Agent අසල වෙනම launcher එකක් ද ලැබේ. අලුත් Omarchy එකක් එක් වරක් පමණක් ලැබෙන notification එකකින් මෙම තේරීම කිරීමට ඔබට ආරාධනා කරයි.

Claude තෝරා ගැනීමෙන් Chromium, Chrome, Brave, Brave Origin, සහ Edge සඳහා එහි browser extension එක සකස් කිරීමට ද උත්සාහ කරයි. extension එක සැකසීම සියලුම users ලාට අදාළ වන අතර ඔබේ system password එක ඉල්ලා සිටිය හැක; extension ස්ථාපනය අවලංගු කිරීම හෝ අසාර්ථක වීම වුවද Claude තෝරා ගෙන දියත් කරයි. ඔබේ browser එක restart කරන්න, අසන්නේ නම් extension එක enable කරන්න, සහ එය සම්බන්ධ කිරීම අවසන් කිරීමට Claude වෙත sign in වන්න. සම්බන්ධතාව පරීක්ෂා කිරීමට Claude හි `/chrome` ධාවනය කරන්න. Firefox සහ Zen මෙම extension එකට සහාය නොදක්වයි. මෙම සැකසුම එක් කිරීමට පෙර සිටම Claude ඔබේ පෙරනිමිය වී තිබුණේ නම්, extension එක ස්ථාපනය කිරීමට එය නැවත තෝරන්න.

Agent skills මඟින් AI හට නිශ්චිත මෙවලම් නිශ්චිත ආකාරයකින් භාවිතා කිරීමට උපකාරී වන අතර, Omarchy ඒවායින් හතක් සපයයි. omarchy skill එක ඔබේ Hyprland config එක tweak කිරීම හෝ bar එක adjust කිරීම වැනි system එක tailor කිරීම ආවරණය කරයි. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app, සහ omarchy-make-game අලුත් දෙයක් සෑදීම ආවරණය කරන අතර, omarchy-contribute bug එකක් වාර්තා කිරීම හෝ fix එකක් upstream වෙත යැවීම ආවරණය කරන අතර, omarchy-diagnose-crash crash එකක core dump එක හරහා ක්‍රියා කරයි. ඒවා Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ සෑම `~/.hermes/profiles/*/skills` එකක්ම), සහ generic `~/.agents/skills` ස්ථානය සඳහා skill directories තුළට symlink කර ඇති බැවින්, බොහෝ harnesses ඒවා ස්වයංක්‍රීයවම ලබා ගනී. එකම නම ඇති ඔබේම skill folder එකකට ප්‍රමුඛතාව ලැබේ.

නමුත් ඔබ මෙම skills අත්හදා බැලීමේ ඒවා ලෙස සැලකිය යුතුය. විවිධ models ඒවා විවිධ බලපෑමකින් භාවිතා කරනු ඇත. agent කැමති වනු ඇත්තේ කුමක් වෙනස් කිරීමටද යන්න පිළිබඳ අදහසක් ඔබට ලැබෙන පරිදි, පළමුව plan mode එකේ ධාවනය කිරීම වඩාත් සුදුසුය. ඉන්පසු agent සියල්ල අවුල් කර දමන්නේ නම්, වෙනස්කම් rollback කිරීමට හෝ `omarchy reinstall configs` පවා invoke කිරීමට සූදානම්ව සිටින්න.
