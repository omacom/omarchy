# AI

Omarchy හි ඔබට පෙරනිමියක් තෝරා නොදී පහත කේතකරණ නියෝජිතයන් සඳහා දියත් කරන්නන් ඇතුළත් වේ. පළමු වරට භාවිත කරන විට එහි CLI ස්ථාපනය කිරීමට විධානයක් ධාවනය කරන්න, ඉන්පසු විමසූ විට සත්‍යාපනය කරන්න. Hermes ව්‍යතිරේකයයි: පළමු වරට භාවිත කරන විට ඒ සඳහා කිසිවක් ස්ථාපනය නොකෙරේ, එය තෝරා ගැනීමෙන් Hermes Desktop ස්ථාපනය වේ, පහත _ඩෙස්ක්ටොප් යෙදුම්_ පැහැදිලි කරන පරිදි.

### නියෝජිතයන් ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes හැර, මෙම නියෝජිතයන් mise හි lazy ස්ථාපනය භාවිත කරයි: පළමු දියත් කිරීමේදී CLI ස්ථාපනය වන අතර, පසුව දියත් කිරීම්වලදී එයම නැවත භාවිත කරයි. mise විසින් ස්ථාපිත නියෝජිතයෙකු සඳහා නව නිකුතුවක් තිබේදැයි ආරම්භයට මොහොතකට පෙර හෝ shell prompt එකකදී පසුබිමේ, උපරිම වශයෙන් පැය හතරකට වරක් ද පරීක්ෂා කරයි. එම යාවත්කාලීනය අසාර්ථක වුවහොත් හෝ ඔබ නොබැඳි නම්, ස්ථාපිත අනුවාදය ධාවනය වේ. `omarchy update` මගින් ස්ථාපිත නියෝජිතයන් Omarchy හි ඉතිරිය සමඟ යාවත්කාලීන කරන අතර, `mup` මගින් යාවත්කාලීන කරන්නේ mise මගින් කළමනාකරණය වන මෙවලම් පමණි.

`claude update`, `codex update` වැනි නියෝජිතයෙකුගේම updater එකක්, හෝ යෙදුමක ඇති යාවත්කාලීන බොත්තමක්, mise මගින් කළමනාකරණය වන ස්ථාපනය යාවත්කාලීන නොකරයි. `codex update` අසාර්ථක වන අතර, `claude update` මගින් සාර්ථක බව වාර්තා කළත් mise විසින් නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය විය හැක. ඔබට ඒ වෙනුවට නියෝජිතයෙකුගේ ස්වදේශීය ස්ථාපකය සහ updater එක භාවිත කිරීමට අවශ්‍ය නම්, එය `disable_tools` වෙත එක් කරන්න; [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

ඔබට අවශ්‍ය වීමට පෙර වින්‍යාස කර ඇති සියලුම lazy මෙවලම් ස්ථාපනය කිරීමට, `mise install --include-lazy` ධාවනය කරන්න. මෙයට නියෝජිතයන්ට අමතරව Omarchy හි අනෙක් පෙරනිමි CLI මෙවලම් ද ඇතුළත් වේ. එක් මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිත කිරීම සඳහා [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` ස්ථාපනය කරන්නේ `claude` සහ `codex` ආකාරයටම, mise හි first-party `grok` පැකේජය හරහාය. `grok` ධාවනය කරන්න, නැතහොත් එය _Agent > Harness_ යටතේ තෝරන්න. x.ai හි `curl | bash` ස්ථාපකය මඟ හරින්න. එම මාර්ගය `~/.grok/bin` හි දෙවන පිටපතක් තබයි, එය `PATH` හි මුලට එක් කරයි, සහ Omarchy හි wrapper එක උඩින් ලියයි.

`dsh` එහි browser UI එක `127.0.0.1:3080` මත විවෘත කරයි, දියත් කළ නාමාවලිය එහි පෙරනිමි වැඩතලය ලෙස ගනී. එහි browser UI එක ආරම්භක prompt එකක් නොගන්නා බැවින්, `omarchy agent prompt` එය විවෘත කරන්නේ prompt එක පසුරු පුවරුවේ තබා ඇලවීමට හැකි වන පරිදිය. Omarchy එය ආරම්භ කරන්නේ DeepSeek හි no-approval permission preset එක සමඟය. ඔබ එහි නිල ආකෘති API එක භාවිත කරන විට DeepSeek Harness විසින් සැසි ලොග DeepSeek වෙත උඩුගත කරයි; එහි browser UI එකේ _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ එයට යවන ප්‍රතිපෝෂණ ද සැසිය සමඟම උඩුගත කෙරේ, ඔබ එය `DSH_TELEMETRY_MODE=DISABLED` සමඟ ආරම්භ නොකළහොත් මිස.

### පෙරනිමි නියෝජිතයා

ඔබේ පෙරනිමි නියෝජිතයා `omarchy default agent <name>` සමඟ හෝ Omarchy Menu එකේ (`Super + Space`) _Agent > Harness_ යටතේ තෝරන්න. නියෝජිතයා තවම ස්ථාපනය කර නොමැති නම්, එය තෝරා ගැනීමෙන් පළමුව එය ස්ථාපනය වේ. නැවුම් Omarchy එකක් එක් වරක් පමණක් පෙන්වන දැනුම්දීමකින් මෙම තේරීම කිරීමට ඔබට ආරාධනා කරයි.

Omarchy ක්‍රියාවලි බිඳවැටීම් සඳහා systemd-coredump නිරීක්ෂණය කරයි. යමක් segfault වූ විට, ඔබට "Process crashed" දැනුම්දීමක් ලැබෙනු ඇත — එය click කරන්න, සහ බිඳවැටීම ඔබේ පෙරනිමි නියෝජිතයාට Omarchy හි diagnose-crash skill එක සමඟ භාර දෙනු ලැබේ, එය core dump එකෙන් කරුණු තහවුරු කර ගැනීම සහ බිඳවැටීම upstream වෙත වාර්තා කිරීම වටිනවාද යන්න තීරණය කිරීම හරහා නියෝජිතයාට මඟ පෙන්වයි. `coredumpctl list` වෙතින් ලැබෙන ඕනෑම PID එකකට එරෙහිව `omarchy agent crash <pid>` සමඟ ඔබට එය අතින් ද ධාවනය කළ හැක.

නිරීක්ෂණය පෙරනිමියෙන් ක්‍රියාත්මක වේ. එය _Trigger > Toggle > Crash Capture_ යටතේ (නැතහොත් `omarchy toggle crash-capture` සමඟ) අක්‍රිය කරන්න, එවිට දැනුම්දීම් නතර වේ; `omarchy agent crash <pid>` තවමත් අතින් ක්‍රියා කරයි.

බිඳවැටීම් එක් වැඩසටහනකට එකක් බැගින් ද නිහඬ කළ හැක, එය රෝග විනිශ්චය අවසානයේ ඔබට පිරිනමන්නේ එයයි. `omarchy crash mute hyprland` එම වැඩසටහන සඳහා පමණක් දැනුම්දීම් නතර කරයි, `omarchy crash mute hyprland off` ඒවා ආපසු ගෙන එයි, සහ `omarchy crash mute` තනිවම ඔබ නිහඬ කර ඇති දේ ලැයිස්තුගත කරයි. එය binary එකේ නම මෙන්ම එහි මාර්ගය ද සතුටින් ගනී, එබැවින් `omarchy crash mute /usr/bin/hyprland` ද එයම කරයි. එහි හිඩැසක් ඇති නමක් උපුටා දක්වන්න, `omarchy crash mute 'Some App'` හි මෙන්. අනෙක් සියල්ල තවමත් දැනුම් දෙයි, සහ නිහඬ කළ වැඩසටහන තවමත් බිඳ වැටේ — මෙය මතක් කිරීම සඟවයි, එය කිසිවක් නිවැරදි නොකරයි.

### ඩෙස්ක්ටොප් යෙදුම්

_Install > AI_ මෙනුවේ ග්‍රැෆික් AI යෙදුම් කිහිපයක් ද ඇත: Antigravity Desktop, ChatGPT desktop app එක, Claude desktop app එක (Chat, Cowork, සහ Claude Code පටිති සහිත Anthropic හි Linux beta එක), xAI හි ආකෘති සමඟ කතාබස් කිරීමට Grok Bot, Herdr Desktop, Hermes Desktop, OpenClaw, Perplexity desktop app එක, සහ T3 Code. Grok Bot යනු desktop chat යෙදුමයි. කේතකරණ නියෝජිතයා `grok` විධානයයි.

Hermes Desktop යනු දැනගත යුතු එකයි, මන්ද යන්ත්‍රයක එක් Hermes එකක් ඇති අතර, එය යෙදුමට අයත් එකයි: Hermes කිසිවිටෙක ස්ථාපනය කරන්නේ යෙදුම හරහා පමණක් වන අතර, පෙරනිමි නියෝජිතයා ධාවනය කරන `hermes` විධානය යෙදුමට අයත් එකයි. Hermes පෙරනිමි නියෝජිතයා ලෙස තෝරා ගැනීමෙන් _Install > AI_ ඇතුළත් කිරීම කරන එයම ස්ථාපනය වේ: පැකේජය, සහ Hermes හිම ස්ථාපකය මගින් සකසා ඇති `~/.hermes` යටතේ ඇති Hermes runtime එකක්, පළමු වරට විනාඩි කිහිපයක් ගත වේ. එම runtime එක terminal `hermes` විධානය, පෙරනිමි නියෝජිතයා සහ යෙදුම යන සියල්ලම භාවිත කරන එකම Hermes එක වන අතර, එය Omarchy නිකුතුවක් එනතුරු බලා නොසිට `hermes update` සමඟ එයම යාවත්කාලීන වේ. එය ස්ථාපනය කිරීමෙන් Hermes වෙත Omarchy තේමාව `omarchy` නම් skin එකක් ලෙස ද භාර දෙන අතර, ඔබ තේමා මාරු කරන විට සෑම Hermes පෘෂ්ඨයක්ම එය අනුගමනය කරයි; ඔබට එය එසේ නොවීමට අවශ්‍ය නම් Hermes හි Appearance සැකසුම් යටතේ හෝ `/skin` සමඟ තවත් එකක් තෝරන්න, එවිට Omarchy එම තේරීම එලෙසම තබයි. _Remove > AI_ යටතේ යෙදුම ඉවත් කිරීමෙන් පළමුව Hermes වසයි, gateway එකද ඇතුළුව, එම runtime එක ඒ සමඟ රැගෙන යයි, සහ ඔබ වෙනත් ලෙස නොකියන්නේ නම් ඔබේ කතාබස්, මතකයන්, සහ Hermes විසින් තමාටම ලියාගත් skills තබා ගනී: එම දත්ත සහ ඔබේ සම්බන්ධතා සැකසුම් ද යා යුතුදැයි එය අසයි, පෙරනිමිය නැත යන්නයි.

OpenClaw හි desktop අත්දැකීම එහි Control UI එක වන අතර, එය එහිම දේශීය gateway එකකින් පිටුබලය ලබන web යෙදුමක් ලෙස විවෘත වේ. OpenClaw `~/.openclaw` හි ජීවත් වන අතර එයම යාවත්කාලීන වේ: Control UI හි "Update Gateway" බොත්තම භාවිත කරන්න නැතහොත් `openclaw update` ධාවනය කරන්න, එවිට gateway එක නව අනුවාදය මත නැවත ආරම්භ වේ. ඔබ සකසන සෑම ආකෘතියකටම යෙදුම් launcher එකේ එහිම ඇතුළත් කිරීමක් ද ලැබේ, ආකෘතියේ නම යටතේ සහ එහි නිෂ්පාදකයාගේ ලාංඡනය සමඟ, Claude, Codex හෝ Grok වෙත පුරනය වීමෙන් එකක් එක් වන ආකාරයටම. එය එම ආකෘතිය මත ඔබේ නියෝජිතයා විවෘත කරන අතර, එය ධාවනය නොවන්නේ නම් පළමුව ආකෘතිය ආරම්භ කරයි: terminal එක එය පූරණය වන අයුරු පෙන්වා එය සූදානම් වූ පසු නියෝජිතයාට භාර දෙයි. ආකෘතියක් ඉවත් කිරීමෙන් එහි ඇතුළත් කිරීම ඉවත් වේ.

ආකෘතියක් එය සකසා ඇති ආකාරයටම හරියටම ධාවනය වෙමින් පවතී, එබැවින් Omarchy යාවත්කාලීනයක් කිසිවිටෙක ඔබේ නියෝජිතයන් යටතේ එකක් නැවත ආරම්භ නොකරයි. ඔබ සකසා ඇති ආකෘතියක් සඳහා Omarchy සතුව නව runtime එකක් හෝ නව weights ඇති විට, එහි පේළිය යාවත්කාලීන බොත්තමක් පෙන්වයි: එය ඔබන්න, එවිට ආකෘතිය පසුබිමේ නැවත සකසනු ලැබේ, වෙනස් වූ දේ පමණක් බාගත කරමින්, සහ නව අනුවාදය මත නැවත ආරම්භ වේ. නතර කර තිබූ ආකෘතියක් නතර වී ම පවතී. `omarchy agent local update` terminal එකකින් සෑම ආකෘතියක් සඳහාම එයම කරයි.

විධාන පේළියෙන්, `omarchy agent local start <recipe>` සහ `omarchy agent local stop <recipe>` එයම කරයි, `omarchy agent local status` සෑම ආකෘතියක්ම පෙන්වයි, සහ `omarchy agent --local` ඔබ අවසන් වරට ආරම්භ කළ ආකෘතිය මත ඔබේ පෙරනිමි නියෝජිතයා විවෘත කරයි. pi, OpenCode සහ Qwen Code එකක් භාවිත කළ හැක; වෙනත් ඕනෑම පෙරනිමියක් සමඟ එය pi හි විවෘත වේ. pi විසින් ඔබ සකසා ඇති සෑම ආකෘතියක්ම, සහ ඔබ යුගල කර ඇති යන්ත්‍රවල ඇති ඒවා ද, එහිම model picker එකේ ලැයිස්තුගත කරයි, එබැවින් සරල `pi` ද ඒවාට ළඟා වේ. ඕනෑම OpenAI-අනුකූල client එකකට ද සම්බන්ධ විය හැක: `status` සෑම ආකෘතියකම ලිපිනය පෙන්වයි (පළමුවැන්න `http://127.0.0.1:11435/v1`), recipe නම ආකෘතිය වන අතර, යතුර `~/.config/omarchy/agent-local/key` හි ඇත.

`omarchy agent local remove <recipe>` ආකෘතියක් සහ වෙනත් කිසිදු ආකෘතියක් භාවිත නොකරන බාගත කිරීම් මකා දමයි.

තෙවන පාර්ශවීය runtimes ඒවායේ ප්‍රකාශකයා සමඟ ලේබල් කර ඇත. Omarchy සෑම ආකෘතියක්ම ජාල ප්‍රවේශයක් නොමැතිව ධාවනය කරයි.

### The Omarchy Skill

Agent skills, AI හට නිශ්චිත මෙවලම් නිශ්චිත ආකාරයකින් භාවිත කිරීමට උපකාරී වන අතර, Omarchy පද්ධතිය සකස් කිරීම සඳහා පෙරනිමි skill එකක් සමඟ පැමිණේ. ඔබේ Hyprland config එක වෙනස් කිරීම, තීරුව සකස් කිරීම, නැතහොත් මුල සිටම නව තේමාවක් නිර්මාණය කිරීම වැනි. එය Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ සෑම `~/.hermes/profiles/*/skills`), සහ සාමාන්‍ය `~/.agents/skills` ස්ථානය සඳහා skill නාමාවලිවලට symlinked කර ඇති බැවින්, බොහෝ harness එය ස්වයංක්‍රීයවම ලබා ගනී.

නමුත් ඔබ මෙම skill එක පර්යේෂණාත්මක ලෙස සැලකිය යුතුය. විවිධ ආකෘති එය විවිධ බලපෑම් සඳහා භාවිත කරනු ඇත. නියෝජිතයා වෙනස් කිරීමට කැමති දේ පිළිබඳ ඔබට අදහසක් ලැබෙන පරිදි, පළමුව plan mode හි ධාවනය කිරීම වඩාත් සුදුසුය. ඉන්පසු නියෝජිතයා සියල්ල අවුල් කරන්නේ නම්, වෙනස්කම් rollback කිරීමට හෝ `omarchy reinstall configs` ඇමතීමට පවා සූදානම්ව සිටින්න.
