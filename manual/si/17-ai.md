# AI

Omarchy ඔබට පෙරනිමියක් තෝරා නොදී පහත කේතකරණ නියෝජිතයින් සඳහා දියත් කරන්නන් ඇතුළත් කරයි. පළමු වරට භාවිතා කරන විට එහි CLI එක ස්ථාපනය කිරීම සඳහා විධානයක් ක්‍රියාත්මක කරන්න, ඉන්පසු විමසූ විට සත්‍යාපනය කරන්න. Hermes සහ OpenClaw යනු ව්‍යතිරේකයන්ය: ඒවා සඳහා mise හරහා කිසිවක් ස්ථාපනය නොකෙරෙන අතර, එම දෙකෙන් එකක් තේරීමෙන් එහිම ස්වයං-යාවත්කාලීන වන පිටපත සකස් කරනු ලැබේ, පහත _Desktop apps_ කොටසේ පැහැදිලි කර ඇති පරිදි.

### නියෝජිතයින් ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes සහ OpenClaw හැර, මෙම නියෝජිතයින් mise හි කල්දැමූ ස්ථාපනය භාවිතා කරයි: පළමු දියත් කිරීමේදී CLI එක ස්ථාපනය වන අතර, පසු දියත් කිරීම්වලදී එයම නැවත භාවිතා කරයි. එසේම mise ස්ථාපිත නියෝජිතයෙකු සඳහා නව නිකුතුවක් තිබේදැයි උපරිම වශයෙන් සෑම පැය හතරකටම වරක්, එය ආරම්භ වීමට මොහොතකට පෙර හෝ shell විමසුමකදී පසුබිමේ පරීක්ෂා කරයි. එම යාවත්කාලීනය අසාර්ථක වුවහොත් හෝ ඔබ නොබැඳි නම්, ස්ථාපිත අනුවාදය ක්‍රියාත්මක වේ. `omarchy update` මගින් Omarchy හි ඉතිරි කොටස් සමග ස්ථාපිත නියෝජිතයින් යාවත්කාලීන කරන අතර, `mup` මගින් යාවත්කාලීන කරන්නේ mise මගින් කළමනාකරණය වන මෙවලම් පමණි.

`claude update`, `codex update`, හෝ යෙදුමක ඇති යාවත්කාලීන බොත්තමක් වැනි නියෝජිතයෙකුගේම යාවත්කාලීනය මගින් mise මගින් කළමනාකරණය වන ස්ථාපනය යාවත්කාලීන නොකෙරේ. `codex update` අසාර්ථක වන අතර, `claude update` මගින් සාර්ථක වූ බව වාර්තා කළ හැකි වුවත් mise විසින් නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කරයි. ඔබ ඒ වෙනුවට නියෝජිතයෙකුගේ ස්වදේශීය ස්ථාපකය සහ යාවත්කාලීනය භාවිතා කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [පෙර-ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

ඔබට ඒවා අවශ්‍ය වීමට පෙර වින්‍යාස කර ඇති සියලුම කල්දැමූ මෙවලම් ස්ථාපනය කිරීමට, `mise install --include-lazy` ක්‍රියාත්මක කරන්න. මෙයට නියෝජිතයින්ට අමතරව Omarchy හි අනෙකුත් පෙරනිමි CLI මෙවලම් ද ඇතුළත් වේ. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනය භාවිතා කිරීම සඳහා [පෙර-ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` ස්ථාපනය කරනු ලබන්නේ mise හි පළමු-පාර්ශ්වීය `grok` පැකේජය හරහා, `claude` සහ `codex` මෙන්මය. `grok` ක්‍රියාත්මක කරන්න, නැතහොත් එය _Agent > Harness_ යටතේ තෝරන්න. x.ai හි ඇති `curl | bash` ස්ථාපකය මග හරින්න. එම මාර්ගය `~/.grok/bin` තුළ දෙවන පිටපතක් තබන අතර, එය `PATH` එකේ ඉදිරියට එක් කර, Omarchy හි wrapper එක උඩින් ලියයි.

`dsh` එහි බ්‍රවුසර UI එක `127.0.0.1:3080` මත විවෘත කරන අතර, දියත් කළ නාමාවලිය එහි පෙරනිමි වැඩතලය ලෙස ගනී. එහි බ්‍රවුසර UI එක ආරම්භක විමසුමක් නොගන්නා බැවින්, `omarchy agent prompt` මගින් එය විවෘත කරන්නේ විමසුම ඔබේ පසුරු පුවරුවේ අලවා ගැනීමට තබාය. ### බිඳ වැටීම් හඳුනා ගැනීම

Omarchy ක්‍රියාවලි බිඳ වැටීම් සඳහා systemd-coredump නිරීක්ෂණය කරයි. ඔබ පෙරනිමි නියෝජිතයෙකු තෝරාගත් පසු, ඔබේ ඕනෑම වැඩසටහනක් core ඉවත් කළහොත් "Process crashed" දැනුම්දීමක් ගෙන එයි — එය ක්ලික් කරන්න, එවිට බිඳ වැටීම ඔබේ පෙරනිමි නියෝජිතයා වෙත Omarchy හි omarchy-diagnose-crash කුසලතාව සමග භාර දෙන අතර, එය core dump එකෙන් කරුණු තහවුරු කර ගනිමින් සහ බිඳ වැටීම ඉහළට වාර්තා කිරීම වටිනවාද යන්න තීරණය කරමින් නියෝජිතයා රැගෙන යයි. ඔබට එය `coredumpctl list` වෙතින් ලැබෙන ඕනෑම PID එකකට එරෙහිව `omarchy agent crash <pid>` මගින් අතින් ද ක්‍රියාත්මක කළ හැක.

නිරීක්ෂණය පෙරනිමියෙන් සක්‍රියය. එය _Trigger > Toggle > Crash Capture Off_ යටතේ අක්‍රිය කරන්න (හෝ `omarchy toggle crash-capture` මගින්) එවිට දැනුම්දීම් නවතිනු ඇත; `omarchy agent crash <pid>` තවමත් අතින් ක්‍රියා කරයි.

බිඳ වැටීම් එක් වැඩසටහන බැගින් නිශ්ශබ්ද කළ හැකි අතර, එය රෝග විනිශ්චය අවසානයේ ඔබට ඉදිරිපත් කරන්නේ ද එයයි. `omarchy crash mute hyprland` මගින් එම වැඩසටහන සඳහා පමණක් දැනුම්දීම් නවත්වන අතර, `omarchy crash mute hyprland off` මගින් ඒවා නැවත ගෙන එන අතර, `omarchy crash mute` තනිවම ඔබ නිශ්ශබ්ද කර ඇති දේ ලැයිස්තුගත කරයි. එය ද්විමය ගොනුවේ මාර්ගය එහි නම තරම්ම සතුටින් ගන්නා බැවින්, `omarchy crash mute /usr/bin/hyprland` ද එයම කරයි. එහි ඉඩක් ඇති නමක් උද්ධෘත කරන්න, උදාහරණයක් ලෙස `omarchy crash mute 'Some App'`. අන් සියල්ල තවමත් දැනුම් දෙන අතර, නිශ්ශබ්ද කළ වැඩසටහන තවමත් බිඳ වැටේ — මෙය මතක් කිරීම සඟවයි, එය කිසිවක් නිවැරදි නොකරයි.

### ඩෙස්ක්ටොප් යෙදුම්

Hermes පෙරනිමි නියෝජිතයා ලෙස තේරීමෙන් _Install > AI_ අයිතමය කරන දෙයම ස්ථාපනය කරයි: පැකේජය, සහ Hermes හිම ස්ථාපකය මගින් සකසන ලද `~/.hermes` යටතේ ඇති Hermes ධාවන කාලය, එයට පළමු වරට විනාඩි කිහිපයක් ගත වේ. එම ධාවන කාලය යනු පර්යන්ත `hermes` විධානය, පෙරනිමි නියෝජිතයා සහ යෙදුම යන සියල්ලම භාවිතා කරන එක් Hermes එක වන අතර, එය Omarchy නිකුතුවක් එනතුරු බලා නොසිට `hermes update` මගින් තනිවම යාවත්කාලීන වේ. එය ස්ථාපනය කිරීමෙන් Hermes වෙත Omarchy තේමාව `omarchy` නම් සමක් ලෙස ද භාර දෙන අතර, ඔබ තේමා මාරු කරන විට සෑම Hermes මතුපිටක්ම එය අනුගමනය කරයි; ඔබට එය එසේ නොවීමට අවශ්‍ය නම් Hermes හි Appearance සැකසුම් යටතේ හෝ `/skin` මගින් වෙන එකක් තෝරන්න, එවිට Omarchy එම තේරීම එලෙසම තබයි. _Remove > AI_ යටතේ යෙදුම ඉවත් කිරීමෙන් පළමුව Hermes වසා දමයි, ද්වාරය ද ඇතුළත්ව, එම ධාවන කාලය එය සමගම රැගෙන යයි, සහ ඔබ වෙනත් ලෙස නොකියන්නේ නම් ඔබේ කතාබස්, මතක, සහ Hermes එය වෙනුවෙන්ම ලියා ගත් කුසලතා තබා ගනී: එම දත්ත සහ ඔබේ සම්බන්ධතා සැකසුම් ද යා යුතු දැයි එය අසයි, පෙරනිමිය නැත යන්නයි.

විධාන රේඛාවෙන්, `omarchy models start <recipe>` සහ `omarchy models stop <recipe>` එයම කරන අතර, `omarchy models status` මගින් සෑම ආකෘතියක්ම පෙන්වන අතර, `omarchy agent --local` මගින් ඔබේ පෙරනිමි නියෝජිතයා ඔබ අවසන් වරට ආරම්භ කළ ආකෘතිය මත විවෘත කරයි. pi, OpenCode සහ Qwen Code එකක් භාවිතා කළ හැක; වෙනත් ඕනෑම පෙරනිමියක් සමග එය pi තුළ විවෘත වේ, නැතහොත් ඔබට pi නොමැති නම් OpenCode තුළ. pi ඔබ සකසා ඇති සෑම ආකෘතියක්ම, සහ ඔබ යුගල කර ඇති යන්ත්‍රවල ඇති ඒවා ද, එහිම ආකෘති තේරීම්කාරකය තුළ ලැයිස්තුගත කරන බැවින්, සාමාන්‍ය `pi` එකට ද ඒවා වෙත ළඟා විය හැක. ඕනෑම OpenAI-අනුකූල සේවාදායකයකට ද සම්බන්ධ විය හැක: `status` මගින් සෑම ආකෘතියකම ලිපිනය පෙන්වයි (පළමු එක `http://127.0.0.1:11435/v1`), වට්ටෝරුවේ නම ආකෘතිය වන අතර, යතුර `~/.config/omarchy/agent-local/key` තුළ තිබේ.

`omarchy models remove <recipe>` මගින් ආකෘතියක් සහ වෙනත් කිසිම ආකෘතියක් භාවිතා නොකරන බාගත කිරීම් මකා දමයි.

තෙවන පාර්ශ්ව ධාවන කාල ඒවායේ ප්‍රකාශකයා සමග ලේබල් කර ඇත. Omarchy සෑම ආකෘතියක්ම ජාල ප්‍රවේශයකින් තොරව ක්‍රියාත්මක කරයි.

Omarchy දේශීය LLM ආකෘති ක්‍රියාත්මක කිරීමට ක්‍රම දෙකක් නිර්දේශ කරයි: LM Studio සහ Ollama. LM Studio විවෘත-බර ආකෘති සොයා ගැනීමට, ඒවා ස්ථාපනය කිරීමට, සහ ඒවා ක්‍රියාත්මක කිරීමට GUI අතුරුමුහුණතක් සපයයි. එය පහසුවෙන් ආරම්භ කිරීමට කදිම ක්‍රමයකි. Ollama ද එලෙසම කිරීමට CLI එකක් ඉදිරිපත් කරයි. නමුත් ඔබ දේශීය ආකෘතිවලට අලුත් නම්, මම LM Studio වලින් ආරම්භ කරමි. ඔබට Omarchy Menu එකේ _Install > AI_ යටතේ ඒ දෙකෙන් ඕනෑම එකක් ස්ථාපනය කළ හැක.

### Omarchy කුසලතා

නියෝජිත කුසලතා AI හට නිශ්චිත මෙවලම් නිශ්චිත ආකාරයකින් භාවිතා කිරීමට උපකාරී වන අතර, Omarchy ඒවායින් හතක් සපයයි. omarchy කුසලතාව ඔබේ Hyprland වින්‍යාසය වෙනස් කිරීම හෝ තීරුව සකස් කිරීම වැනි පද්ධතිය සකස් කිරීම ආවරණය කරයි. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app, සහ omarchy-make-game අලුත් දෙයක් සෑදීම ආවරණය කරන අතර, omarchy-contribute දෝෂයක් වාර්තා කිරීම හෝ ඉහළට නිවැරදි කිරීමක් යැවීම ආවරණය කරන අතර, omarchy-diagnose-crash බිඳ වැටීමක core dump එක හරහා ක්‍රියා කරයි. ඒවා Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ සෑම `~/.hermes/profiles/*/skills` එකක්ම), සහ සාමාන්‍ය `~/.agents/skills` ස්ථානය සඳහා වන කුසලතා නාමාවලි තුළට symlink කර ඇති බැවින්, බොහෝ harness ඒවා ස්වයංක්‍රීයවම අල්ලා ගනී. එකම නම ඇති ඔබේම කුසලතා ෆෝල්ඩරයකට ප්‍රමුඛතාවය ලැබේ.

නමුත් ඔබ මෙම කුසලතා පර්යේෂණාත්මක ලෙස සැලකිය යුතුය. විවිධ ආකෘති එය විවිධ බලපෑමකට භාවිතා කරනු ඇත. නියෝජිතයා වෙනස් කිරීමට කැමති දේ පිළිබඳ අදහසක් ඔබට ලැබෙන පරිදි, පළමුව සැලසුම් ප්‍රකාරයේ ක්‍රියාත්මක කිරීම වඩාත් සුදුසුය. ඉන්පසු නියෝජිතයා සියල්ල අවුල් කරන්නේ නම්, වෙනස්කම් ආපසු හැරවීමට හෝ `omarchy reinstall configs` ඇමතීමට පවා සූදානම් වන්න.
