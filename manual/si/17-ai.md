# AI

Omarchy ඔබට පෙරනිමියක් තෝරා නොදී, පහත කේතකරණ නියෝජිතයන් සඳහා දියත් කරන්නන් ඇතුළත් කරයි. පළමු වරට භාවිත කරන විට එහි CLI ස්ථාපනය කිරීමට විධානයක් ධාවනය කරන්න, ඉන්පසු විමසූ විට සත්‍යාපනය කරන්න. Hermes සහ OpenClaw ව්‍යතිරේක වේ: mise හරහා ඒවා සඳහා කිසිවක් ස්ථාපනය නොකෙරෙන අතර, ඒවායින් එකක් තේරීමෙන් එයටම අයත් ස්වයං-යාවත්කාලීන වන පිටපතක් පිහිටුවනු ලැබේ, පහත _Desktop apps_ යටතේ පැහැදිලි කර ඇති පරිදි.

### නියෝජිතයන් ස්ථාපනය කිරීම සහ යාවත්කාලීන කිරීම

Hermes සහ OpenClaw හැර, මෙම නියෝජිතයන් mise හි lazy ස්ථාපනය භාවිත කරයි: පළමු දියත් කිරීමේදී CLI ස්ථාපනය වන අතර, පසු දියත් කිරීම්වලදී එයම නැවත භාවිත වේ. එමෙන්ම mise ස dip ස්ථාපිත නියෝජිතයෙකු සඳහා නව නිකුතුවක් තිබේදැයි උපරිම වශයෙන් සෑම පැය හතරකටම වරක්, එය ආරම්භ වීමට මොහොතකට පෙර හෝ පසුබිමේ shell prompt එකකදී පරීක්ෂා කරයි. එම යාවත්කාලීනය අසාර්ථක වුවහොත් හෝ ඔබ නොබැඳිව සිටියහොත්, ස්ථාපිත අනුවාදය ධාවනය වේ. `omarchy update` මඟින් ස්ථාපිත නියෝජිතයන් Omarchy හි ඉතිරිය සමඟ යාවත්කාලීන වන අතර, `mup` මඟින් යාවත්කාලීන වන්නේ mise මඟින් කළමනාකරණය වන මෙවලම් පමණි.

`claude update`, `codex update` වැනි නියෝජිතයෙකුගේම යාවත්කාලීනයකින් හෝ යෙදුමක ඇති යාවත්කාලීන බොත්තමකින් mise මඟින් කළමනාකරණය වන ස්ථාපනය යාවත්කාලීන නොවේ. `codex update` අසාර්ථක වන අතර, `claude update` සාර්ථක බව වාර්තා කළ හැකි වුවත්, mise නිරීක්ෂණය නොකරන වෙනම පිටපතක් ස්ථාපනය කරනු ඇත. ඔබ ඒ වෙනුවට නියෝජිතයෙකුගේම ස්වදේශීය ස්ථාපකය සහ යාවත්කාලීනය භාවිත කිරීමට කැමති නම්, එය `disable_tools` වෙත එක් කරන්න; [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

ඔබට අවශ්‍ය වීමට පෙර වින්‍යාස කර ඇති සියලුම lazy මෙවලම් ස්ථාපනය කිරීමට, `mise install --include-lazy` ධාවනය කරන්න. මෙයට නියෝජිතයන් මෙන්ම Omarchy හි අනෙක් පෙරනිමි CLI මෙවලම් ද ඇතුළත් වේ. තනි මෙවලමක් ස්ථාපනය කිරීම හෝ ඔබේම ස්ථාපනයක් භාවිත කිරීම සඳහා [පෙර ස්ථාපිත CLI මෙවලම්](18-development-tools.md#preinstalled-cli-tools) බලන්න.

`grok` ස්ථාපනය වන්නේ mise හි පළමු-පාර්ශ්වීය `grok` package එක හරහා, `claude` සහ `codex` මෙන්මය. `grok` ධාවනය කරන්න, නැතහොත් එය _Agent > Harness_ යටතේ තෝරන්න. x.ai හි ඇති `curl | bash` ස්ථාපකය මඟ හරින්න. එම මාර්ගය `~/.grok/bin` හි දෙවන පිටපතක් තබන අතර, එය `PATH` හි ඉදිරියට දමා, Omarchy හි wrapper එක උඩින් ලියනු ලබයි.

`dsh` එහි browser UI එක `127.0.0.1:3080` මත විවෘත කරන අතර, දියත් කරන ලද නාමාවලිය එහි පෙරනිමි workspace එක වේ. එහි browser UI එක ආරම්භක prompt එකක් නොගන්නා බැවින්, `omarchy agent prompt` එය විවෘත කරන්නේ prompt එක අලවන්න ඔබේ clipboard එකේ තබාය. Omarchy එය ආරම්භ කරන්නේ DeepSeek හි no-approval permission preset එක සමඟය. ඔබ එහි නිල model API එක භාවිත කරන විට DeepSeek Harness සැසි ලොග DeepSeek වෙත උඩුගත කරයි; එහි browser UI එකේ _Settings > General > Upload Session Log_ යටතේ එය අක්‍රිය කරන්න. ඔබ එයට එවන ප්‍රතිපෝෂණ ද සැසිය සමඟම උඩුගත කරනු ලැබේ, ඔබ එය `DSH_TELEMETRY_MODE=DISABLED` සමඟ ආරම්භ නොකළොත් මිස.

### පෙරනිමි නියෝජිතයා

`omarchy default agent <name>` සමඟ හෝ Omarchy Menu (`Super + Space`) එකේ _Agent > Harness_ යටතේ ඔබේ පෙරනිමි නියෝජිතයා තෝරන්න. නියෝජිතයා තවම ස්ථාපනය කර නොමැති නම්, එය තේරීමෙන් පළමුව එය ස්ථාපනය වන අතර, එයට app launcher එකේ Agent අසලම එයටම අයත් දියත් කරන්නෙකුත් ලැබේ. අලුත් Omarchy එකක් එක් වරක් පමණක් පෙන්වන දැනුම්දීමක් සමඟ මෙම තේරීම කරන ලෙස ඔබට ආරාධනා කරනු ඇත.

### බිඳවැටීම් රෝග විනිශ්චය

`omarchy models remove <recipe>` model එකක් සහ වෙනත් කිසිම model එකක් භාවිත නොකරන බාගත කිරීම් මකා දමයි.

Third-party runtimes ඒවායේ ප්‍රකාශකයා සමඟ ලේබල් කර ඇත. Omarchy සෑම model එකක්ම ජාල ප්‍රවේශයක් නොමැතිව ධාවනය කරයි.

### දේශීය LLMs

Omarchy දේශීය LLM models ධාවනය කිරීමේ ක්‍රම දෙකක් නිර්දේශ කරයි: LM Studio සහ Ollama. LM Studio විවෘත-weight models සොයා ගැනීම, ඒවා ස්ථාපනය කිරීම, සහ ඒවා ධාවනය කිරීම සඳහා GUI අතුරුමුහුණතක් සපයයි. එය පහසුවෙන් ආරම්භ කිරීමට හොඳ ක්‍රමයකි. Ollama ඒ හා සමානව කිරීමට CLI එකක් ලබා දෙයි. නමුත් ඔබ දේශීය models වලට අලුත් නම්, මම LM Studio වලින් ආරම්භ කරමි. ඔබට Omarchy Menu එකේ _Install > AI_ යටතේ දෙකෙන් එකක් ස්ථාපනය කළ හැකිය.

### Omarchy skills

Agent skills, AI වලට නිශ්චිත මෙවලම් නිශ්චිත ආකාරයකින් භාවිත කිරීමට උපකාරී වන අතර, Omarchy ඒවායින් හතක් සපයයි. omarchy skill එක ඔබේ Hyprland config එක tweak කිරීම හෝ තීරුව සකස් කිරීම වැනි පද්ධතිය සියුම් ලෙස සකස් කිරීම ආවරණය කරයි. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app, සහ omarchy-make-game අලුත් දෙයක් සෑදීම ආවරණය කරන අතර, omarchy-contribute දෝෂයක් වාර්තා කිරීම හෝ upstream වෙත නිවැරදි කිරීමක් යැවීම ආවරණය කරයි, සහ omarchy-diagnose-crash බිඳවැටීමක core dump එක හරහා වැඩ කරයි. ඒවා Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ සෑම `~/.hermes/profiles/*/skills` එකක්ම), සහ generic `~/.agents/skills` ස්ථානය සඳහා skill නාමාවලිවලට symlink කර ඇති බැවින්, බොහෝ harness ඒවා ස්වයංක්‍රීයව ලබා ගනියි. එකම නම ඇති ඔබේම skill folder එකකට ප්‍රමුඛතාව ලැබේ.

නමුත් ඔබ මෙම skills පර්යේෂණාත්මක ලෙස සැලකිය යුතුය. විවිධ models එය විවිධ ප්‍රතිඵල සඳහා භාවිත කරනු ඇත. පළමුව plan mode එකේ ධාවනය කිරීම වඩාත් හොඳය, එවිට නියෝජිතයා වෙනස් කිරීමට කැමති දේ පිළිබඳ ඔබට අදහසක් ලැබේ. ඉන්පසු නියෝජිතයා සියල්ල අවුල් කර දමන්නේ නම්, වෙනස්කම් rollback කිරීමට හෝ `omarchy reinstall configs` අමතීමට පවා සූදානම්ව සිටින්න.
