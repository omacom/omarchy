# ජාලකරණය

Omarchy හි ජාලකරණය හසුරුවන්නේ NetworkManager විසිනි, ඔබ එය පාලනය කරන්නේ [ඉහළ තීරුවේ](05-the-top-bar.md) ඇති ජාල අයිකනයෙන් හෝ `Super + Ctrl + N` සමඟිනි.

එම පැනලය Wi-Fi ජාල සඳහා පිරික්සයි, සංඥා ශක්තිය පෙන්වයි, සම්බන්ධ ද වේ. Ethernet සඳහා කිසිවක්ම අවශ්‍ය නැත — එය සවි කරන්න, එපමණයි, එය ක්‍රියා කරයි. ඔබ terminal එකේම රැඳී සිටීමට කැමති නම්, `nmtui` ඔබට එම පාලනම ලබා දෙයි, `omarchy network` විධාන කාණ්ඩයක් ද තිබේ.

## ඔබේ Wi-Fi එක බෙදා ගැනීම

දිගු මුරපදයක් හඬ නඟා කියා දෙනවා වෙනුවට, ඔබ Wi-Fi එකේ සිටින අතරතුර _Setup > Network > QR Code_ ධාවනය කරන්න. එවිට ඕනෑම දුරකථන කැමරාවකට ස්කෑන් කර සම්බන්ධ විය හැකි QR කේතයක් තිරය මත දිස් වේ. එය තිබෙන බව දැනගත් පසු ඔබ අපේක්ෂා කරනවාට වඩා බොහෝ සෙයින් භාවිතා කිරීමට පෙළඹෙන දේවල්වලින් එකකි එය.

ඔබට ඇත්තටම මුරපදයම අවශ්‍ය නම්, `omarchy network password <interface>` එය මුද්‍රණය කරයි.

## DNS

Omarchy භාවිතා කරන්නේ ඔබේ ජාලය DHCP ඔස්සේ ලබා දෙන ඕනෑම DNS එකකි. ඔබට එය මුළු යන්ත්‍රය සඳහාම _Setup > Network > DNS_ යටතේ අභිබවා සැකසිය හැකි අතර, එහිදී Cloudflare සහ Google ඇත්තේ එක් ක්ලික් එකක් දුරිනි. ඔබේම servers ඇතුළත් කිරීමට _Custom_ තෝරන්න.

Terminal එකෙන්, `omarchy dns` වත්මන් සැපයුම්කරුවා මුද්‍රණය කරන අතර `omarchy dns Cloudflare` එකක් සකසයි.

## Wi-Fi කලාපය ස්ථිරව සකසා ගැනීම

ඔබේ router එක 2.4GHz, 5GHz, සහ 6GHz එකම ජාල නාමය යටතේ තබන්නේ නම්, ඔබේ laptop එක සමහර විට සෙමින් ක්‍රියා කරන එකේම එල්ලී සිටිනු ඇත. `omarchy network band` ඔබ සිටින්නේ කුමන කලාපයේදැයි පෙන්වන අතර, `omarchy network band 5` එය ස්ථිරව සකසයි. එයට නැවත තෝරා ගැනීමට ඉඩ දීමට `auto` භාවිතා කරන්න.

මෙය ස්ථිරව සකසන්නේ නිශ්චිත access point එකක් නොව කලාපය බැවින්, ඔබ සාමාන්‍ය පරිදි APs අතර roaming කරමින් සිටියි.

## එය කොතරම් වේගවත්ද?

_Trigger > Speed Test > Network Speed Test_ ඩයල් යුගලයකින් ඔබේ සැබෑ up සහ down වේගය මනිනු ලබයි. Terminal එකෙන් එය `omarchy network speedtest down` හෝ `up` ය. (ඔබ අනෙක් බාධාව benchmark කරන්නේ නම්, එම මෙනුවේම එය අසල disk වේග පරීක්ෂණයක් ද තිබේ.)

## Firewall එක

Firewall එක පෙරනිමියෙන් සක්‍රියව තිබෙන අතර ලැබෙන සියලුම traffic අවහිර කරයි, එක් ව්‍යතිරේකයක් සමඟ: port 53317, එවිට [LocalSend](22-guis.md) ආරම්භයේ සිටම කිසිදු අමතර සැකසුමකින් තොරව ක්‍රියා කරයි.

ඔබ _Setup > Security > SSHD_ සමඟ එය සක්‍රිය කරන තෙක් SSH අක්‍රියව පවතින අතර, එය daemon එක ආරම්භ කරයි, brute force වලට එරෙහිව rate-limit කරන ලද port 22 විවෘත කරයි, සහ යතුරක් අනුමත කරයි. Docker ද අගුළු දමා ඇත, එබැවින් containers වලට අහම්බෙන් ලෝකයට නිරාවරණය විය නොහැක. මුළු කතාවම සඳහා [ආරක්ෂාව](48-security.md) බලන්න.

## Tailscale

[Tailscale](https://tailscale.com/) යනු අන්තර්ජාලය හරහා ඔබේ සියලුම පරිගණක සහ servers වෙත ළඟා වීම සරල සහ ආරක්ෂිත කරන mesh VPN එකකි. එය _Install > Service > Tailscale_ සමඟ ස්ථාපනය කරන්න.

එයින් ඔබට තීරුවේ Tailscale පැනලයක් ලැබෙන අතර, එය tailnet එක සම්බන්ධ සහ විසන්ධි කරයි, ගිණුම් මාරු කරයි, සහ exit node එකක් තෝරයි — ඔබේම යන්ත්‍ර සහ Mullvad regions දෙකම ලැයිස්තුවේ දිස් වේ. එය ඔබේ යන්ත්‍ර හරහා ද බ්‍රවුස් කරන අතර, Taildrop ජීවත් වන්නේ එතැනයි: යන්ත්‍රයක් තෝරා එයට ගොනු යැවීමට `s` ඔබන්න, නැතහොත් එහි IP, නම, හෝ සම්පූර්ණ DNS නම පිටපත් කිරීමට `c`, `n`, සහ `d` ඔබන්න. Terminal එකේ ඊට සමාන දෙය `omarchy tailscale send <machine> [file...]` වන අතර, ඔබට එවන ලද ගොනු ස්වයංක්‍රීයව `~/Downloads` තුළට ලැබේ. පැමිණීම දැනුම් දෙන දැනුම්දීම ඔබ එය ක්ලික් කර විවෘත කරන තෙක් හෝ ඉවත් කරන තෙක් රැඳී සිටියි, එබැවින් ඔබ යන්ත්‍රයෙන් බැහැරව සිටින අතරතුර පැමිණෙන ගොනුවක් ඔබ ආපසු එන විට පිළිතුරු දීමට තවමත් එහි තිබේ.

එය ස්ථාපනය කිරීමෙන් Tailscale admin console එක සඳහා web app එකක් ද එක් වේ.

## එය ක්‍රියා කිරීම නැවතුණු විට

Reboot කිරීමට පෙර, ගැටලුව ඇති කොටස පමණක් නැවත ආරම්භ කර බලන්න. _Update > Hardware_ තුළ Wi-Fi, Bluetooth, Audio, සහ Trackpad ඇති අතර, ඉන් එකක් නැවත පූරණය කිරීමෙන් බොහෝ "මිනිත්තු පහකට පෙර එය ක්‍රියා කළා" වැනි තත්ත්වයන් නිරාකරණය වේ. [දෝෂ නිරාකරණය](45-troubleshooting.md) බලන්න.
