# සංචාලනය

Omarchy තුළ හැමදේම වෙන්නේ යතුරුපුවරුවෙන් — _හැමදේම!_ පද්ධතිය මුලින්ම පටන් ගත්තම, මවුසයෙන් විතරක් ඔබට ඇත්තටම කිසිම දෙයක් කරන්න බෑ. හැබැයි `Super + Space` ගහලා Omarchy Menu එක පෙන්වන්න පුළුවන්, එතන ඉඳන් ඔබට ඕනෑම දෙයක් වගේ කරන්න පුළුවන්.

නමුත් බොහෝ වෙලාවට පද්ධතිය පාවිච්චි කරන ප්‍රධාන ක්‍රමය වෙන්න Omarchy menu එක අදහස් කරලාවත් නෑ. අපට ඊට වඩා වේගවත් වෙන්න පුළුවන්! වැදගත්ම applications ඔක්කොම කෙලින්ම වෙන වෙනම hotkeys වලට බැඳලා තියෙනවා. ඔබ terminal එක පටන් ගන්නේ `Super + Return` වලින්, browser එකක් `Super + Shift + Return` වලින්. එක පිට එක කරලා බලන්න, Hyprland හි tiling එකේ මැජික් එක ක්‍රියාවෙන්ම පෙනෙයි:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

ඊට පස්සේ `Super + J` ගහලා ඒවා පැත්තෙන් පැත්ත තියනවා වෙනුවට එක උඩ එක තියන්න පුළුවන්:

 ![navigation-stacked](images/navigation-stacked.webp)

`Super + J` ආයෙත් ගහලා ඒවා ආපහු පැත්තෙන් පැත්ත තිබ්බ තැන්වලටම ගේන්න. ඊට පස්සේ browser එක ඇතුළේ ඉද්දි `Super + Shift + Arrow Right` ගහලා කවුළු මාරු කරලා බලන්න.

දැන් `Super + Shift + T` ගහලා Activity monitor එක පටන් ගන්න. ඒක පාවෙන කවුළුවක් විදියට එයි, ඇදගෙන යන්න titlebar එකකුයි, minimize, maximize, සහ close කරන්න බොත්තම් ටිකකුයි එක්ක. පාවෙන හැම කවුළුවකටම, ඒක කොහෙ තිබ්බත්, එකක් ලැබෙනවා. `Super + T` වලින් ඔබට ඒක tile කරන්න පුළුවන් (ආයෙත් ඒක ගැහුවම ඒක ආපහු පාවෙන එකක් වෙනවා). දැන් `Super + Shift + F` ඔබලා file manager එක අරින්න. ඔබට පිළිවෙළ සිව්-ආකාර සැකසුමක් ලැබෙයි:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

ඔබට active වෙන්න ඕන කවුළුව අතර ගමන් කරන්නේ `Super + Arrow` වලින්. ඒකෙන් focus එක මාරු වෙලා cursor එක අලුත් application එකේ මැදට යනවා. තිරයක අයිනේදි, ඒක ඒ පැත්තේ තියෙන monitor එකට දිගටම යනවා.

`Super + Shift + 2` ගැහුවොත්, ඔබ දැන් focus කරලා තියෙන application එක දෙවෙනි workspace එකට යනවා. `Super + Shift + 1` වලින් ඒක ආපහු ගේනවා. (ඒ වගේම `Super + Shift + Alt + 2` වලින් දැන් focus කරලා තියෙන application එක, ඒ workspace එකට මාරු නොවී, දෙවෙනි workspace එකට යවන්න පුළුවන්).

monitor එකකට වඩා තියෙනවා නම්, හැම monitor එකකටම තමන්ගේම 1 සිට 10 දක්වා workspaces තියෙනවා. `Super + 2` යන්නේ ඔබ ඉන්න monitor එකේ දෙවෙනි workspace එකට, හැම monitor එකකම top bar එකේ ඒකෙ තමන්ගේ workspaces ටිකයි ඒක දැනට පෙන්වන එකයි පෙන්වනවා. `Super + Tab` ඔබ ඉන්න monitor එකේ workspaces අතර චක්‍රීයව යනවා. `Super + Shift + Ctrl + Arrows` ඔබ ඉන්න කවුළුව ඒ දිශාවේ තියෙන monitor එකට, ඒක දැනට පෙන්වන workspace එකට යවනවා, `Super + Shift + Alt + Arrows` ඔබ ඉන්න workspace එක ඒ දිශාවේ තියෙන monitor එකට ගෙනියනවා, එතන ඒ අංකයම හිස් නම් ඒක ඒ අංකය ගන්නවා. ඔබ monitor එකක් ගලවපුවාම ඒක තමන්ගේ workspaces තියාගන්නවා: ඒවා අනිත් තිරයක ඒවාට එකතු වෙනවා, ඒකට දැනටමත් තියෙන ඒවාට පස්සේ අංක ලැබිලා, monitor එක ආපහු ආවාම ඒවා තමන්ගේ පරණ අංක යටටම ආපහු යනවා.

ඔබ `Super` අල්ලගෙන ඉඳලා මවුසයෙන් කවුළුවක් click කළොත්, ඒක තියෙන තැන වෙනස් කරන්න පුළුවන් වෙයි. ඔබ `Super` අල්ලගෙන මවුසයේ දකුණු බොත්තම පාවිච්චි කළොත්, කවුළුව නිදහසේ resize කරන්න පුළුවන්.

ඔබ කවුළුවක් වහන්නේ `Super + W` හෝ `Super + Q` වලින් (කවුළු ඔක්කොම වහන්නේ `Ctrl + Alt + Delete` වලින්).

ඔබට `Super + F` වලින් full screen යන්නත්, `Super + Alt + F` වලින් top bar එක තියාගෙන full-width විතරක් යන්නත්, නැත්නම් `Super + Ctrl + F` වලින් කවුළුවක් ඇතුළේ full-screen යන්නත් පුළුවන් (YouTube වලට හොඳයි!).

### Dwindle එදිරිව scrolling සැකැස්ම

Omarchy හි පෙරනිමි සැකැස්මට කියන්නේ dwindle කියලා. ඔබ තනි workspace එකක අරින කවුළු ඔක්කොම, ඒවා කුඩා කරන්න වුණත්, හැම වෙලාවෙම පේන්න තියනවා.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

නමුත් ඔබට workspace එකක් scrolling සැකැස්මට හරවන්නත් තෝරන්න පුළුවන්, එතන කවුළු display එකේ පේන අයිනෙන් එහාට, පැත්තෙන් පැත්ත පෙළ ගැහිලා තියෙනවා. ඔබ තනි workspace එකක් `Super + L` වලින් මේ සැකැස්මට හරවනවා.

`Super + L` ආයෙත් ඔබපුවාම workspace එක floating වෙනවා, එතන කවුළු නිදහසේ එක උඩ එක වැටිලා තියෙනවා, ඔබම ඒවා තියන තැන් තීරණය කරනවා, තුන්වෙනි පාර ඔබපුවාම ඒක ආපහු dwindle එකට එනවා. `Super + Alt + L` ඒවා අතර අනිත් දිශාවට යනවා. කොහොමත් පාවෙන කවුළුවක් — ඔබ `Super + T` වලින් පිටතට ගත්ත එකක්, හෝ හැමදාම පාවෙමින් අරින app එකක් — workspace එක ආපහු tiling වෙත ගියාමත් දිගටම පාවෙනවා. Top bar එක ඔබ ඉන්න workspace එකේ සැකැස්ම ලකුණකින් පෙන්වනවා: dwindle වලට හතරැස් කොටුවක්, scrolling වලට රවුමක්, floating වලට ත්‍රිකෝණයක්. ඒ ලකුණ click කළාමත් සැකැස්ම චක්‍රීයව මාරු වෙනවා, ඒ වගේම එහෙම එකක් තියෙන laptops වල display key එකෙනුත් ඒකම වෙනවා.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

තේරීම workspace එකින් එකට වෙනස්, ඒක එහෙමම තියෙනවා. ඒ නිසා ඔබට workspace 1 browsing වලට dwindle වලත්, workspace 2 code වලට scrolling වලත් තියාගන්න පුළුවන්, restart එකකට පස්සෙත් ඒවා ආපහු එන්නේ එහෙමමයි.

scrolling සැකැස්ම පෙරනිමිය විදියට පාවිච්චි කරන්න ඕන නම්, ඒක `~/.config/hypr/looknfeel.lua` තුළ සකසන්න පුළුවන්:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### පාවෙන workspaces

පාවෙන workspace එකක් සාම්ප්‍රදායික desktop එකක් වගේ වැඩ කරනවා: කවුළු එක උඩ එක වැටෙනවා, ඔබම ඒවා එහා මෙහා ගෙනියනවා සහ ඒවායේ size එක හදනවා. හැම කවුළුවකටම ඔබේ theme එකේ පාටවලින් titlebar එකක් ලැබෙනවා, minimize, maximize, සහ close කරන බොත්තම් එක්ක. `Super + M` වලින් focus කරලා තියෙන කවුළුවත් minimize වෙනවා. Minimize කරපු කවුළුවක් dock එකේ ඉන්නවා; ඒක ආපහු ගේන්න ඒකෙ app එක click කරන්න. කවුළුවක් ඉස්සරහට ගේන්න ඒක click කරන්න. ඕනෑම අයිනකින් හෝ කොනකින් ඒක resize කරන්න. Top bar එක පේන ගමන් කවුළුව maximize කරන්න titlebar එක double-click කරන්න, පරණ size එක ආපහු ගන්න ආයෙත් එහෙම කරන්න. Chrome සහ අනිත් Chromium මත පදනම් වුණු browsers, Disks සහ Document Viewer titlebar එක මඟහැරලා ඒ වෙනුවට තමන්ගේම header එක පාවිච්චි කරනවා; `Super + Alt + F` ඒවා maximize කරනවා, `Super + M` ඒවා minimize කරනවා.

හැම workspace එකකටම dock එකක් තියෙනවා, ඔබ pin කරපු apps, දැනට run වෙන හැමදේම, ඒ වගේම apps බොත්තම පිටුපස හැම app එකකම grid එකක් එක්ක, ඒක `Super + Alt + Space` වලින් සහ Omarchy menu එකේ _Apps_ වලින්ද අරින්න පුළුවන්. Grid එකේ app එකක් uninstall කරන්න ඒක right-click කරන්න, නැත්නම් `Delete` ඔබන්න. App එකක් අරින්න, නැත්නම් ඒකෙ කවුළුව ඉස්සරහට ගේන්න ඒක click කරන්න; ඒකෙ කවුළු අතර චක්‍රීයව යන්න ආයෙත් click කරන්න. Files ආපහු ගේන්නේ ඔබ ඉන්න workspace එකේ කවුළුවක් විතරයි, නැත්නම් අලුත් එකක් අරිනවා, Terminal සහ Agent හැමදාම තව එකක් පටන් ගන්නවා, හැබැයි minimize කරපු කවුළුවක් තියෙනවා නම් ඒක මුලින් ආපහු එනවා. Middle-click අලුත් කවුළුවක් අරිනවා. Icon එකක් එහා මෙහා ගෙනියන්න ඒක dock එක දිගේ ඇදගෙන යන්න; run වෙන app එකක් අනිත් ඒවා අතරට ඇදගෙන ගියොත් ඒක එතනම තියෙනවා. App එකක් dock එකේ තියාගන්න, ඒකෙන් අයින් කරන්න, නැත්නම් ඒක quit කරන්න right-click කරන්න. Workspace එක හිස් වෙලාවට dock එක එළියේ තියෙනවා, workspace එකට කවුළුවක් ආවට පස්සේ pointer එක ඒකෙ අයිනට එනකම් ඒක හැංගෙනවා. Fullscreen කවුළුවක් ඒක සම්පූර්ණයෙන්ම හංගනවා. Dock එක එතනට ගෙනියන්න apps බොත්තම තිරයේ අනිත් අයිනක් දිහාවට ඇදගෙන යන්න. අයිනක් තෝරන්න _Position_ සඳහාත්, _Appearance > Workspace Layout_ කරනවා වගේ පෙරනිමි සැකැස්ම සකසන්න _Layout_ සඳහාත් ඒක right-click කරන්න. Position එක _Appearance > Dock > Dock Position_ යටතේත් තියෙනවා, `omarchy dock position left` terminal එකකින් ඒක සකසනවා. ඔබ dock එකේ තියාගන්න apps, ඒවා run වෙන්නේ නැති වෙලාවට මങ്ങ වෙලා තියෙනවා. Dock එක පාවෙන workspaces වලට විතරක් තියාගන්න, _Appearance > Dock > Dock Only on Floating_ හෝ `omarchy dock tiling off` පාවිච්චි කරන්න.

අලුත් workspaces, සහ ඔබ `Super + L` වලින් තමන්ගේම සැකැස්මක් දීලා නැති ඕනෑම එකක්, පෙරනිමි සැකැස්ම පාවිච්චි කරනවා. පෙරනිමිය වෙනස් කළාම කවුළු නැති හැම workspace එකක්ම ඒකට reset වෙනවා, කවුළු තියෙන එකක් තමන්ට තියෙන සැකැස්මම තියාගන්නවා. Dock එකට minimize කරපු කවුළුවක් තාමත් ඒක ගිය workspace එකේ කවුළුවක් විදියටම ගණන් ගන්නවා. ඒක _Appearance > Workspace Layout_ යටතේ තෝරන්න: Tiling, Scrolling, හෝ Floating. `omarchy hyprland workspace layout default scrolling` terminal එකකින් ඒක සකසනවා.

### කවුළු සමූහගත කිරීම

කවුළු `Super + G` වලින් සමූහගත කරන්න පුළුවන්. ඔබ සමූහයකට ඇතුළු වුණාට පස්සේ, ඒක active වෙලා තියෙද්දි ඔබ පටන් ගන්න හැම කවුළුවක්ම ඒ සමූහයට අයිති වෙනවා. ඔබට මේ සමූහගත කරපු කවුළු අතර `Super + Ctrl + Arrow Left/Right` වලින් යන්න පුළුවන්, නැත්නම් `Super + Alt + 1/2/3/4` වලින් පිළිවෙළට සමූහගත කවුළු වලට කෙලින්ම යන්න පුළුවන්.

ඔබට කවුළුවක් `Super + Alt + G` වලින් සමූහයෙන් පිටතට ගෙනියන්න පුළුවන්, නැත්නම් `Super + G` ආයෙත් ගහලා මුළු සමූහයම විසුරුවන්න පුළුවන්. අන්තිමට, ඔබට සමූහයෙන් පිටත කවුළු `Super + Alt + Arrows` වලින් ඒක ඇතුළට ගෙනියන්න පුළුවන්.

### කවුළු පිටතට ගැනීම

ඔබට කවුළුවක් `Super + O` වලින් ඒකෙ workspace වෙන්කිරීමෙන් පිටතට ගන්න පුළුවන්. ඒකෙන් ඒක පාවෙන කවුළුවක් විදියට pin වෙනවා, ඔබ යන ඕනෑම workspace එකකට ඒක ඔබ පස්සේ එනවා. Video players වගේ දේවල් වලට නියමයි.

### Scratchpad workspace

ඔබ දැනට ඉන්න workspace එක උඩින් වැටෙන විශේෂ full-size scratchpad workspace එකක් තියෙනවා. ඒකෙ තියෙන දේවල් වලට ඔබ යන්නේ `Super + S` වලින්, ඔබ කවුළු එතන තියන්නේ `Super + Alt + S` වලින්.

දැනට ඉන්න workspace එකෙන් නොගිහින් ඉක්මනින් වැඩ කරන්න ඕන controls හෝ terminal එකක් සඳහා ඒක හොඳට වැඩ කරනවා.

### Quake console

අන්තිමට, ඔබ දැනට ඉන්න workspace එක උඩින් පහළට වැටෙන අර්ධ-උස Quake console එකක් තියෙනවා. `Super + the key above Tab` වලින් ඒක toggle කරන්න (US layouts වල grave), `Super + Shift + the key above Tab` වලින් කවුළුවක් එතන තියන්න.

ඒක මුලින්ම අරින වෙලාවට, ඒක ඔබේ පෙරනිමි agent පටන් ගන්නවා, නැත්නම් ඔබ තාම එකක් තෝරලා නැත්නම් එකක් තෝරන්න කියනවා. Console එකේ තනි කවුළුවක් විතරක් තියෙද්දි, ඒක තිරය පුරා විහිදෙනවා වෙනුවට මැදට වෙන්න panel එකක් විදියට පහළට වැටෙනවා. ඒකට දෙවෙනි app එකක් දාන්න, ඒක ආපහු full width එකට යනවා, එතකොට දෙකටම පැත්තෙන් පැත්ත ඉන්න ඉඩ තියෙනවා.

කවුළුවක් scratchpad එකෙන් හෝ console එකෙන් එහාට ගෙනියන්න, `Super + Shift + 1` වගේ දෙයකින් ඒක කෙලින්ම අනිත් workspace එකකට යවන්න.

### පුරුදු වෙන්න ටිකක් කල් යනවා!

ඔබේ desktop එක මේ විදියට සංචාලනය කරන්න පුරුදු වෙන්න ටිකක් කල් යනවා, හැබැයි පුරුදු වුණාට පස්සේ, සාම්ප්‍රදායික මවුසයෙන් ධාවනය වෙන desktop අත්දැකීමකට ආපහු යන්න අමාරු වෙයි!
