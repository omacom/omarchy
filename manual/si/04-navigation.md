# සංචාලනය

Omarchy තුළ හැම දෙයක්ම වෙන්නේ යතුරුපුවරුව හරහායි — _හැම දෙයක්ම!_ පද්ධතිය මුලින්ම ආරම්භ වන විට, මූසිකයෙන් විතරක් ඔබට වචනයේ පරිසමාප්ත අර්ථයෙන්ම කිසිම දෙයක් කරන්න බෑ. හැබැයි ඔබට `Super + Space` ඔබලා Omarchy Menu එක හෙළි කරන්න පුළුවන්, මෙතැන ඉඳන් ඔබට ඕනෑම දෙයක් වගේ කරන්න පුළුවන්.

හැබැයි Omarchy මෙනුව බොහෝ වෙලාවට පද්ධතිය ක්‍රියාත්මක කරන ප්‍රධාන ක්‍රමය වෙන්න අදහස් කරලාවත් නෑ. අපට ඊට වඩා වේගවත් වෙන්න පුළුවන්! වැදගත්ම යෙදුම් ඔක්කොම කෙළින්ම තනි තනි hotkey වලට බැඳලා තියෙනවා. ඔබ terminal එක පටන් ගන්නේ `Super + Return` වලින්, බ්‍රවුසරයක් `Super + Shift + Return` වලින්. එකක් පිටිපස්සේ එකක් කරලා බලන්න, එතකොට Hyprland tiling එකේ මැජික් එක ක්‍රියාවෙන්ම පෙනේවි:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

ඊට පස්සේ ඔබට `Super + J` ඔබලා ඒවා එක ළඟ එක වෙනුවට එකක් උඩ එකක් විදියට අහුරන්න පුළුවන්:

 ![navigation-stacked](images/navigation-stacked.webp)

ඒවා ආයෙත් එක ළඟ එක තිබුණු තැන්වලට ගේන්න ආයෙත් `Super + J` ඔබන්න. ඊට පස්සේ බ්‍රවුසරයේ ඉන්න ගමන් `Super + Shift + Arrow Right` ඔබලා කවුළු මාරු කරලා බලන්න.

දැන් `Super + Shift + T` ඔබලා Activity monitor එක පටන් ගන්න උත්සාහ කරන්න. ඒක පාවෙන කවුළුවක් විදියට එයි, අදින්න පුළුවන් titlebar එකක් සහ minimize, maximize, close කරන්න බොත්තම් එක්ක. හැම පාවෙන කවුළුවකටම එකක් ලැබෙනවා, ඒක කොහේ තිබුණත්. ඔබට `Super + T` පාවිච්චි කරලා ඒක tile කරන්න පුළුවන් (ආයෙත් ඒකම ඔබලා ආයෙත් පාවෙන විදියට හදන්නත් පුළුවන්). දැන් `Super + Shift + F` ඔබලා ගොනු කළමනාකරු අරින්න. ඔබට පිළිවෙළ හතර අතට සැකසුමක් ලැබේවි:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

ඔබ සක්‍රිය වෙන්න ඕන කවුළුව අතර සංචාලනය කරන්නේ `Super + Arrow` වලින්. ඒකෙන් focus එක මාරු වෙනවා, cursor එක අලුත් යෙදුමේ මැදට යනවා. තිරයක අද්දරකදී, ඒක ඒ පැත්තේ මොනිටරයටම ඒ විදියටම ඉදිරියට යනවා.

ඔබ `Super + Shift + 2` එබුවොත්, දැනට focus වෙලා තියෙන යෙදුම දෙවෙනි වැඩ අවකාශයට ගෙන යනවා. `Super + Shift + 1` ඒක ආපහු ගේනවා. (තවද `Super + Shift + Alt + 2`, දැනට focus වෙලා තියෙන යෙදුම ඊට මාරු නොවී දෙවෙනි වැඩ අවකාශයට ගෙන යනවා).

මොනිටර එකකට වැඩිය තියෙන විට, හැම මොනිටරයකටම එයාටම අයිති වැඩ අවකාශ 1 සිට 10 දක්වා තියෙනවා. `Super + 2` යන්නේ ඔබ ඉන්න මොනිටරයේ දෙවෙනි වැඩ අවකාශයටයි, හැම මොනිටරයකම උඩ බාර් එක එයාගේම වැඩ අවකාශ සහ ඒක පෙන්වමින් ඉන්න එක පෙන්වනවා. `Super + Tab`, ඔබ ඉන්න මොනිටරයේ වැඩ අවකාශ අතර චක්‍රාකාරව යනවා. `Super + Shift + Ctrl + Arrows`, ඔබ ඉන්න කවුළුව ඒ දිශාවේ මොනිටරයට, ඒක පෙන්වමින් ඉන්න වැඩ අවකාශයටම ගෙන යනවා, සහ `Super + Shift + Alt + Arrows`, ඔබ ඉන්න වැඩ අවකාශය ඒ දිශාවේ මොනිටරයට ගෙන යනවා, එහිදී ඒ අංකයම එය නිදහස් නම් ගන්නවා. මොනිටරයක් ඔබ ගලවපුවාම ඒක තමන්ගේ වැඩ අවකාශ තියාගන්නවා: ඒවා වෙන තිරයක ඒවට එකතු වෙනවා, ඒකට දැනටමත් තියෙන ඒවට පස්සේ අංක ගහලා, මොනිටරය ආපහු ආවාම ඒවායේ පරණ අංක යටතේ ආපහු යනවා.

ඔබ `Super` අල්ලගෙන මූසිකයෙන් කවුළුවක් click කළොත්, ඒක තියෙන තැන නැවත සකසන්න පුළුවන් වෙයි. ඔබ `Super` අල්ලගෙන මූසිකයේ දකුණු බොත්තම පාවිච්චි කළොත්, ඔබට කවුළුව නිදහසේ resize කරන්න පුළුවන්.

ඔබ කවුළුවක් වහන්නේ `Super + W` හෝ `Super + Q` වලින් (කවුළු ඔක්කොම වහන්නේ `Ctrl + Alt + Delete` වලින්).

ඔබට `Super + F` වලින් full screen යන්නත් පුළුවන්, නැත්නම් `Super + Alt + F` වලින් හුදෙක් full-width (උඩ බාර් එක තියාගෙන) යන්නත්, `Super + Ctrl + F` වලින් කවුළුවක් ඇතුළේ full-screen යන්නත් පුළුවන් (YouTube වලට හොඳයි!).

### Dwindle vs scrolling layout

Omarchy එකේ පෙරනිමි පිරිසැලසුම dwindle කියලා කියනවා. ඒක තනි වැඩ අවකාශයක් මත ඔබ අරින කවුළු ඔක්කොම හැම වෙලේම පෙනෙන්න තියනවා, ඒවා කුඩා කරන්න සිද්ධ වුණත්.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

හැබැයි ඔබට වැඩ අවකාශයක් scrolling පිරිසැලසුමට හරවන්නත් තෝරන්න පුළුවන්, එහිදී කවුළු එක ළඟ එක පෙළගැහිලා තියෙන්නේ, සංදර්ශකයේ පෙනෙන අද්දරින් එහාට. ඔබ තනි වැඩ අවකාශයක් මේ පිරිසැලසුමට හරවන්නේ `Super + L` හරහායි.

ආයෙත් `Super + L` එබුවාම වැඩ අවකාශය floating කරනවා, එහිදී කවුළු නිදහසේ එක උඩ එක වැටෙනවා, ඔබ ඒවා ඔබම තබනවා, තුන්වෙනි සැරේ එබුවාම ඒක ආපහු dwindle එකට එනවා. `Super + Alt + L`, ඒවා හරහා අනික් අතට යනවා. කොහොමත් පාවෙන කවුළුවක් — ඔබ `Super + T` වලින් එළියට ගත්ත එකක්, හෝ හැම වෙලේම floating විදියට අරින app එකක් — වැඩ අවකාශය ආපහු tiling වෙත ගියත් පාවෙමින්ම තියෙනවා. උඩ බාර් එක ඔබ ඉන්න වැඩ අවකාශය ඒකේ පිරිසැලසුමෙන් සලකුණු කරනවා: dwindle සඳහා හතරැස් එකක්, scrolling සඳහා රවුමක්, සහ floating සඳහා ත්‍රිකෝණයක්. ඒ සලකුණ click කිරීමත් පිරිසැලසුම චක්‍රාකාරව මාරු කරනවා, ඒක තියෙන laptops වල display යතුරත් එහෙමයි.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

තේරීම වැඩ අවකාශයකට එක බැගින්, ඒක එහෙමම රැඳෙනවා. ඒ නිසා ඔබට වැඩ අවකාශය 1 browsing සඳහා dwindle මත, වැඩ අවකාශය 2 code සඳහා scrolling මත තියාගන්න පුළුවන්, restarts එකකට පස්සේ ඒවා ඒ විදියටම ආපහු එයි.

ඔබට scrolling පිරිසැලසුම පෙරනිමිය විදියට පාවිච්චි කරන්න ඕන නම්, ඔබට ඒක `~/.config/hypr/looknfeel.lua` තුළ සකසන්න පුළුවන්:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### Floating workspaces

Floating වැඩ අවකාශයක් සාම්ප්‍රදායික desktop එකක් වගේ වැඩ කරනවා: කවුළු එක උඩ එක වැටෙනවා, ඔබ ඒවා ගෙන යනවා සහ ප්‍රමාණය ඔබම සකසනවා. හැම කවුළුවකටම ඔබේ තේමාවේ පාටින් titlebar එකක් ලැබෙනවා, minimize, maximize, සහ close කරන්න බොත්තම් එක්ක. `Super + M` එකත් focus වෙලා තියෙන කවුළුව minimize කරනවා. Minimize වෙලා තියෙන කවුළුවක් dock එකේ බලාගෙන ඉන්නවා; ඒක ආපහු ගේන්න එයාගේ app එක click කරන්න. කවුළුවක් ඉදිරියට ගේන්න ඒක click කරන්න. ඕනෑම අද්දරකින් හෝ කොනකින් ඒක resize කරන්න. උඩ බාර් එක දිස් වෙමින් තියෙද්දීම කවුළුව maximize කරන්න titlebar එකක් double-click කරන්න, ඒකේ පරණ ප්‍රමාණය ආපහු ගන්න ආයෙත් එහෙම කරන්න. Chrome සහ වෙනත් Chromium-පාදක බ්‍රවුසර, Disks සහ Document Viewer, titlebar එක මඟහැරලා ඒ වෙනුවට එයාලගේම header එක පාවිච්චි කරනවා; `Super + Alt + F` ඒවා maximize කරනවා, සහ `Super + M` ඒවා minimize කරනවා.

හැම වැඩ අවකාශයකම dock එකක් තියෙනවා, ඔබ pin කරපු app, දැනට දුවමින් තියෙන හැම දෙයක්ම, සහ apps බොත්තම පිටිපස්සේ හැම app එකකම grid එකක් එක්ක, ඒක `Super + Alt + Space` සහ Omarchy මෙනුවේ _Apps_ එකත් අරිනවා. Grid එකේ app එකක් uninstall කරන්න ඒක right-click කරන්න, නැත්නම් `Delete` ඔබන්න. App එකක් අරින්න, නැත්නම් ඒකේ කවුළුව ඉදිරියට ගේන්න ඒක click කරන්න; එයාගේ කවුළු අතර චක්‍රාකාරව යන්න ආයෙත් click කරන්න. Files, ඔබ ඉන්න වැඩ අවකාශයෙන් විතරයි කවුළුවක් ආපහු ගේන්නේ, නැත්නම් අලුත් එකක් අරිනවා, සහ Terminal සහ Agent හැම වෙලේම තව එකක් පටන් ගන්නවා, හැබැයි minimize වෙලා තියෙන කවුළුවක් මුලින්ම ආපහු එනවා. Middle-click එක අලුත් කවුළුවක් අරිනවා. Icon එකක් dock එක දිගේ අදින්න ඒක ගෙන යන්න; දුවමින් තියෙන app එකක් අනික් ඒවා අතරට ඇදගෙන යෑමෙන් ඒක එතැනම තියෙනවා. App එකක් dock එකේ තියාගන්න, ඒක එළියට ගන්න, නැත්නම් ඒකෙන් ඉවත් වෙන්න right-click කරන්න. වැඩ අවකාශයක් හිස්ව තියෙන තාක් dock එක එළියේ තියෙනවා, වැඩ අවකාශයකට කවුළුවක් ආවාම pointer එක ඒකේ අද්දරට එන තුරු ඒක හැංගෙනවා. Fullscreen කවුළුවක් ඒක මුළුමනින්ම හංගනවා. Dock එක එතැනට ගෙන යන්න apps බොත්තම තිරයේ වෙනත් අද්දරක් දෙසට අදින්න. අද්දරක් තෝරන්න _Position_ සඳහාත්, පෙරනිමි පිරිසැලසුම _Appearance > Workspace Layout_ කරන විදියටම සකසන්න _Layout_ සඳහාත්, dock එක හැම වෙලේම on එකේ තියන්න, පළවෙනි app එක ඒක හංගන්න, නැත්නම් ඒක හැම වෙලේම හැංගිලා තියන්න _Visibility_ සඳහාත් ඒක right-click කරන්න. `omarchy dock visibility always` ඒක terminal එකකින් සකසනවා. පිහිටීමත් _Appearance > Dock > Dock Position_ යටතේ තියෙනවා, සහ `omarchy dock position left` ඒක terminal එකකින් සකසනවා. ඔබ dock එකේ තියාගන්න app, ඒවා දුවන්නේ නැති වෙලාවට මැකිලා පෙනෙනවා. Dock එක floating වැඩ අවකාශ වලට විතරක් තියාගන්න, _Appearance > Dock > Dock Only on Floating_ හෝ `omarchy dock tiling off` පාවිච්චි කරන්න.

අලුත් වැඩ අවකාශ, සහ ඔබ `Super + L` වලින් එයාලටම අයිති පිරිසැලසුමක් දීලා නැති ඕනෑම එකක්, පෙරනිමි පිරිසැලසුම පාවිච්චි කරනවා. පෙරනිමිය වෙනස් කිරීමෙන් කවුළු නැති හැම වැඩ අවකාශයක්ම ඊට reset වෙනවා, කවුළු තියෙන එකක් ඒකට තියෙන පිරිසැලසුමම තියාගන්න අතරේ. Dock එකට minimize වෙලා තියෙන කවුළුවක් තාමත් ඒක හැර ගිය වැඩ අවකාශයේ කවුළුවක් විදියට ගණන් ගන්නවා. ඒක _Appearance > Workspace Layout_ යටතේ තෝරන්න: Tiling, Scrolling, හෝ Floating. `omarchy hyprland workspace layout default scrolling` ඒක terminal එකකින් සකසනවා.

### Grouping windows

කවුළු `Super + G` පාවිච්චි කරලා කණ්ඩායම් කරන්න පුළුවන්. ඔබ කණ්ඩායමකට ආවාම, ඒක සක්‍රියව තියෙන ගමන් ඔබ පටන් ගන්න හැම කවුළුවක්ම ඒ කණ්ඩායමට අයිති වෙනවා. ඔබට මේ කණ්ඩායම් වෙලා තියෙන කවුළු අතර `Super + Ctrl + Arrow Left/Right` පාවිච්චි කරලා යන්න පුළුවන්, නැත්නම් පිළිවෙළට කණ්ඩායම් වෙලා තියෙන කවුළු වලට කෙළින්ම යන්න `Super + Alt + 1/2/3/4` පාවිච්චි කරන්න පුළුවන්.

ඔබට `Super + Alt + G` වලින් කවුළුවක් grouping එකෙන් එළියට ගෙන යන්න පුළුවන්, නැත්නම් ආයෙත් `Super + G` ඔබලා මුළු කණ්ඩායමම විසුරුවා හරින්න පුළුවන්. අවසානයේ, ඔබට `Super + Alt + Arrows` වලින් කණ්ඩායමෙන් පිටත තියෙන කවුළු ඒක ඇතුළට ගෙන යන්න පුළුවන්.

### Popping windows

ඔබට `Super + O` වලින් කවුළුවක් ඒකේ වැඩ අවකාශ වෙන්කිරීමෙන් එළියට pop කරන්න පුළුවන්. ඒකෙන් ඒක ඔබ යන ඕනෑම වැඩ අවකාශයක ඔබ පස්සේ එන පාවෙන කවුළුවක් විදියට pin වෙනවා. Video player සහ ඒ වගේ ඒවට නියමයි.

### Scratchpad workspace

ඔබ දැනට ඉන්න ඕනෑම වැඩ අවකාශයක් උඩින් වැටෙන විශේෂ full-size scratchpad වැඩ අවකාශයක් තියෙනවා. ඔබ ඒකේ තියෙන දේට ප්‍රවේශ වෙන්නේ `Super + S` පාවිච්චි කරලා, ඔබ කවුළු එහි තබන්නේ `Super + Alt + S` පාවිච්චි කරලා.

ඒක වත්මන් වැඩ අවකාශය හැර නොගොස් ඉක්මනින් අන්තර් ක්‍රියා කරන්න ඕන පාලන හෝ terminal එකක් සඳහා හොඳින් වැඩ කරනවා.

### Quake console

අවසානයේ, ඔබ දැනට ඉන්න ඕනෑම වැඩ අවකාශයක් උඩින් පහළට වැටෙන half-height Quake console එකක් තියෙනවා. ඒක `Super + the key above Tab` (US පිරිසැලසුම් වල grave) වලින් toggle කරන්න, සහ `Super + Shift + the key above Tab` පාවිච්චි කරලා කවුළුවක් එහි තබන්න.

ඒක මුලින්ම ඇරෙන වෙලාවේ, ඒක ඔබේ පෙරනිමි agent පටන් ගන්නවා, නැත්නම් ඔබ තාම එකක් තෝරලා නැත්නම් එකක් තෝරන්න කියනවා. Console එක තනි කවුළුවක් දරාගෙන ඉන්න අතරතුර, ඒක තිරය පුරා පැතිරෙනවා වෙනුවට මැදට වෙලා තියෙන panel එකක් විදියට පහළට වැටෙනවා. ඒකට දෙවෙනි app එකක් දාන්න, ඒක ආපහු සම්පූර්ණ පළලට යනවා, ඒ නිසා දෙකට එක ළඟ එක ඉන්න ඉඩ තියෙනවා.

Scratchpad එකෙන් හෝ console එකෙන් කවුළුවක් ගෙන යන්න, ඒක `Super + Shift + 1` වගේ දෙයක් එක්ක කෙළින්ම වෙනත් වැඩ අවකාශයකට යවන්න.

### It takes some getting used to!

මේ විදියට ඔබේ desktop එකේ සංචාලනය කරන්න පුරුදු වෙන්න ටික කාලයක් යනවා, හැබැයි ඔබ එහෙම කළාම, සාම්ප්‍රදායික මූසිකයෙන් ධාවනය වන desktop අත්දැකීමකට ආපහු යන්න අමාරු වෙයි!
