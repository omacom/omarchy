# නොපැමිණි ස්ථාපනයන්

Omarchy ISO එකට යතුරුපුවරුවේ කිසිවෙකු නැතිවම තමන්ම ස්ථාපනය කළ හැකිය. ස්ථාපකයට එහි වින්‍යාස ගොනු රැගෙන `cidata` ලෙස ලේබල් කරන ලද දෙවන ධාවකයක් හමු වුවහොත්, එය ඒවා පිටපත් කරයි, සැකසුම් විශාරදයා සම්පූර්ණයෙන්ම මඟ හරියි, සහ තනිවම අවසන් කරන ලද පද්ධතියට නැවත අරඹයි. විශේෂ ISO ගොඩනැගීමක් නැත, අතිරේක ආරම්භක මෙනු ප්‍රවේශයක් නැත — එවැනි ධාවකයක් සම්බන්ධ කර නැතිව, කිසිවක් වෙනස් නොවන අතර ඔබට සාමාන්‍ය විශාරදයා ලැබේ.

මෙය Omarchy ඉවත දැමිය හැකි සංවර්ධන පරිසරයන් සඳහා මූලික රූපයක් ලෙස විශිෂ්ට කරයි: Proxmox හි හෝ Packer සමඟ VM එකක් සාදන්න, එය ආරම්භ කරන්න, ඉවත්ව යන්න, SSH හරහා ඇතුළු වන්න. `cidata` යනු cloud-init `NoCloud` ලේබලයයි, එබැවින් සියලුම පොදු අතථ්‍යකරණ මෙවලම්වලට එවැනි ධාවකයක් සම්බන්ධ කරන ආකාරය දැනටමත් දනී.

## වින්‍යාස ගොනු

ගොනු හරියටම ස්ථාපකයේම විශාරදයා ලියන දේමයි, එබැවින් ආරම්භක කට්ටලයක් ලබා ගැනීමට පහසුම ක්‍රමය වන්නේ එක් අන්තර්ක්‍රියාකාරී ස්ථාපනයක් (VM එකක මෙන්) ක්‍රියාත්මක කර එය `/root` එකට ලියූ දේ පිටපත් කිරීමයි:

| ගොනුව | අවශ්‍යද | අරමුණ |
|------|----------|---------|
| `user_configuration.json` | ඔව් | තැටිය, ධාරක නාමය, වේලා කලාපය, යතුරුපුවරුව |
| `user_credentials.json` | ඔව් | පරිශීලක නාමය සහ මුරපද හැෂ් |
| `user_full_name.txt` | නැත | Git සම්පූර්ණ නම |
| `user_email_address.txt` | නැත | Git විද්‍යුත් තැපෑල |
| `user_encrypt_installation.txt` | නැත | වින්‍යාසය `disk_encryption` බ්ලොක් එකක් ගෙන යන විට `true` |
| `authorized_keys` | නැත | SSH පොදු යතුරු, පේළියකට එකක් |
| `tailscale_authkey` | නැත | පළමු ආරම්භයේදී ඔබේ ටේල්නෙට් එකට එක්වීම සඳහා Tailscale අත්සන් යතුර |

`user_credentials.json` සඳහා මුරපද හැෂ් එක `openssl passwd -6 "yourpassword"` මගින් ජනනය කරන්න.

ඔබට `user_credentials.json` වෙනුවට `defer-provisioning` නම් හිස් ගොනුවක් ද දැමිය හැකිය. එය ඔබට අන්තර්ක්‍රියාකාරීව ක්‍රියාත්මක කළ හැකි එම [වෙනත් හිමියෙකු සඳහා සූදානම් කිරීමේ ස්ථාපනයම](02-getting-started.md) ක්‍රියාත්මක කරයි: යන්ත්‍රය කිසිදු පුද්ගලික තොරතුරක් නොමැතිව ස්ථාපනය වන අතර, එය පළමුව ආරම්භ කරන ඕනෑම කෙනෙකු ඔවුන්ගේ යතුරුපුවරුව තෝරා ඔවුන්ගේ පරිශීලකයා සාදයි. එය ධාවකය කිසිවෙකුගේ අක්තපත්‍ර කිසි සේත්ම නොගෙන යා යුතු රූප රිග් සඳහා වන ප්‍රකාරයයි.

## SSH ප්‍රවේශය

`authorized_keys` පවතින විට, ස්ථාපනය එම යතුරු පරිශීලකයාගේ `~/.ssh/authorized_keys` ලෙස සකසයි, `sshd` සක්‍රිය කරයි, සහ ඒ සඳහා ෆයර්වෝලය විවෘත කරයි. (සාමාන්‍ය Omarchy ස්ථාපනයක් සේවාව අක්‍රිය කර පෝට් එක වසා openssh එවනු ලබන අතර, එසේ නොමැතිනම් නොපැමිණි යන්ත්‍රයක් ළඟා විය නොහැකි වනු ඇත.) ස්ථාපනය ඔබේ යතුරු පමණක් එක් කරයි — එය SSH ඩීමනයේ වෙනත් කිසිදු සත්‍යාපන සැකසුමක් ලිහිල් නොකරයි.

`tailscale_authkey` පවතින විට, යන්ත්‍රය ඒ වෙනුවට පළමු ආරම්භයේදී ඔබේ ටේල්නෙට් එකට එක් වේ: Tailscale ISO හි බණ්ඩල් කරන ලද පැකේජවලින් ස්ථාපනය කරයි, ෆයර්වෝලය ටේල්නෙට් අතුරුමුහුණතට ඉඩ දෙයි, සහ පසුබිම් කාර්යයක් යන්ත්‍රයට ඇත්තටම ජාලය ලැබුණු සැණින් සම්බන්ධ කිරීම ක්‍රියාත්මක කරන අතර, එය සාර්ථක වන තුරු නැවත උත්සාහ කරයි. එක් ධාවක රූපයකට බොහෝ යන්ත්‍රවලට සේවය කළ හැකි වන පරිදි නැවත භාවිතා කළ හැකි, පෙර අවසර ලත් යතුරක් භාවිතා කරන්න.

## cidata ධාවකය ගොඩනැගීම

නිවැරදි ලේබලය සහිත ඕනෑම ගොනු පද්ධතියක් ක්‍රියා කරයි. කුඩා ISO එකක් පහසු ක්‍රමයයි:

```bash
mkdir cidata
cp user_configuration.json user_credentials.json authorized_keys cidata/
genisoimage -output cidata.iso -volid cidata -joliet -rock cidata/
```

පසුව එය Omarchy ISO එක සමඟ VM එකට සම්බන්ධ කරන්න. මෙන්න සම්පූර්ණ Proxmox උදාහරණයක්:

```bash
qm create 101 --name my-omarchy \
  --bios ovmf --machine q35 --cpu host --cores 4 --memory 8192 \
  --ostype l26 --scsihw virtio-scsi-single \
  --efidisk0 local-lvm:0,efitype=4m,pre-enrolled-keys=0 \
  --scsi0 local-lvm:40,discard=on,iothread=1 \
  --net0 virtio,bridge=vmbr0 --vga virtio --serial0 socket \
  --ide2 local:iso/omarchy.iso,media=cdrom \
  --ide3 local:iso/cidata.iso,media=cdrom \
  --boot order='scsi0;ide2'

qm start 101
```

ආරම්භක අනුපිළිවෙල හිතාමතාම තැටිය පළමුව ලැයිස්තු කළ අයුරු: හිස් තැටිය පළමු ආරම්භයේදී ISO එකට වැටෙන අතර, ස්ථාපනය කළ පද්ධතිය සෑම විටම තැටියෙන් ආරම්භ වේ.

## ව්‍යතිරේක දෙකක්

සංකේතනය කරන ලද නොපැමිණි ස්ථාපනයන් සම්පූර්ණයෙන්ම නොපැමිණියන් නොවේ — පළමු ආරම්භයේදී LUKS මුරපද වාක්‍ය ඛණ්ඩය යමෙකු තවමත් ටයිප් කළ යුතුය. තවද `user_configuration.json` හි `disk_encryption` බ්ලොක් එක එම මුරපද වාක්‍ය ඛණ්ඩය සරල පෙළින් ගෙන යයි, එබැවින් සංකේතනය කරන ලද ස්ථාපනයකින් ගොඩනගා ඇති cidata ධාවකයක් එය වන රහස ලෙස සලකන්න.
