# පෙළ උපුටා ගැනීම සහ කටහඬින් ලිවීම

### පෙළ උපුටා ගැනීම

පෙළ උපුටා ගැනීම සඳහා තිරයේ ප්‍රදේශයක් තෝරීමට `Super + Ctrl + PrtScr` ඔබන්න. ඉන්පසු tesseract විවෘත මූලාශ්‍ර OCR ආකෘතිය එම තේරීම ඉක්මනින් පෙළ බවට පරිවර්තනය කර එය පසුරු පුවරුවේ තබනු ඇත. එවිට ඔබ කළ යුත්තේ ඇලවීමට `Super + V` එබීම පමණි.

රූපවල පාද සටහන්වලින් ලිපින හෝ වෙබ් අඩවි ශීර්ෂවල තැන්පත් කර ඇති දුරකථන අංක ලබා ගැනීමට මෙය ඉතා ප්‍රයෝජනවත් වේ.

### කටහඬින් ලිවීම

නව ස්ථාපනවල, offline ආකෘති බාගත කිරීම් නොමැතිව cloud සැකසුම් භාවිත කරන [Superwhisper](https://superwhisper.com/) යනු පෙරනිමි කටහඬින් ලිවීමේ backend එකයි. Omarchy මෙනුවේ _Setup > Defaults > Dictation_ හරහා Superwhisper, [Voxtype](https://voxtype.io/), හෝ [Hex](https://anoma.ly/hex/) තෝරන්න. backend එකක් තෝරා ගැනීමෙන් එය අවශ්‍ය නම් එය ස්ථාපනය කර කටහඬින් ලිවීම සඳහා පෙරනිමිය බවට පත් කරයි. Voxtype විසින් 150MB ක් ගන්නා මූලික ඉංග්‍රීසි ආකෘතියක් පූරණය කරයි; `voxtype setup model` සමඟ ආකෘතිය සහ `~/.config/voxtype/config.toml` හරහා වෙනත් සැකසුම් වෙනස් කරන්න. Superwhisper එහි සැකසුම් විවෘත කරන්නේ cloud හෝ local සැකසුම් තෝරා ගැනීමට වන අතර, OPR යෙදුම යාවත්කාලීනව තබයි. සැකසීමේදී Hex එහි උපාංගය තුළම ක්‍රියාත්මක වන කථන ආකෘතිය බාගත කරන අතර `hex.service` user service එක ලෙස ක්‍රියාත්මක වේ; ආකෘතිය සහ වෙනත් සැකසුම් වෙනස් කිරීමට තීරුවේ tray අයිකනයෙන් එහි කවුළුව විවෘත කරන්න හෝ `hex` ධාවනය කරන්න.

ඔබ කටහඬින් ලියවන්නේ `Right Alt` ඔබාගෙන සිටීමෙන්, හෝ `Alt + Space` සමඟ මාරු කිරීමෙන් වන අතර, කටහඬින් කී පෙළ අවධානය යොමු වී ඇති ආදාන ප්‍රදේශයේ දිස් වනු ඇත. මෙම කෙටිමං තෝරාගත් backend එක භාවිත කරයි. modifier chord එකක භාවිත කරන විටද Right Alt කටහඬින් ලිවීම ආරම්භ කරයි; එවැනි chords සඳහා Left Alt භාවිත කරන්න. Right Alt යනු AltGr වන යතුරුපුවරු පිරිසැලසුම්වල, ඔබ මාරු වන පිරිසැලසුමක් එවැන්නක් වන විටද ඇතුළුව, කටහඬින් ලිවීමට මොහොතක් එය තනිවම ඔබාගෙන සිටින්න; වෙනත් යතුරක් සමඟ එක්ව එබූ AltGr තවමත් එහි අක්ෂරය ලියයි. Alt + Space පෙරනිමිය වීමට පෙර සිදු කළ ස්ථාපනවල push-to-talk සඳහා `F9` සහ මාරු කිරීමට `Super + Ctrl + X` රඳවා තබා ගනී, ඒවා `~/.config/hypr/bindings.lua` වෙත එක් කර ඇති අතර, එහිදී එම `Super + Ctrl + X` agents පැනලයේ ස්ථානය ගනී; එම යතුරු යෙදුම්වලට සහ පැනලයට ආපසු ලබා දීමට ඒවා එහිදී ඉවත් කරන්න.

එම කෙටිමං සෑම backend එකක් සමඟම ක්‍රියා කරයි. Setup > Defaults > Dictation හරහා ඔබේ backend එක තෝරන්න. backend ස්ථාපකය එය වින්‍යාස කර තේරීම සුරකියි. කුමන එක තෝරාගෙන ඇත්දැයි බැලීමට `omarchy default dictation` ධාවනය කරන්න. තේරීම `~/.config/omarchy/defaults/dictation` හි සුරකිනු ලැබේ. නව ස්ථාපන ස්වයංක්‍රීයව Superwhisper තෝරා ගනී.

Omarchy විසින් තෝරාගත් backend එකේ desktop ඒකාබද්ධතාව ස්වයංක්‍රීයව පූරණය කරයි. `~/.config/hypr/` තුළ Superwhisper වින්‍යාසයක් අවශ්‍ය නොවේ.

අභිරුචි බැඳීම්වලට සහ ස්ක්‍රිප්ට්වලට `omarchy dictation start`, `omarchy dictation stop`, සහ `omarchy dictation toggle` භාවිත කළ හැක. තෝරාගත් backend එක පටිගත කිරීම සහ පිටපත් කිරීම හසුරුවයි. Superwhisper තෝරා ගැනීමෙන් එහි සහජ අල්ලාගෙන සිටීමේ කෙටිමඟ අක්‍රීය කර එහි සහජ මාරු කිරීම `Ctrl + Alt + Space` ලෙස සකසන අතර, එය Omarchy හි පටිගත කිරීමේ යතුරුවලින් වෙන්ව තබයි. Superwhisper සඳහා අවම වශයෙන් එක් සහජ පටිගත කිරීමේ කෙටිමඟක්වත් අවශ්‍ය වන අතර, එහි අවලංගු කිරීමේ කෙටිමඟ තවමත් ලබා ගත හැක.

Omarchy වෙනස් නොකර අමතර backends ඒකාබද්ධ විය හැක. PATH මත `start`, `stop`, සහ `toggle` පිළිගන්නා, ඉක්මනින් ආපසු එන, අසාර්ථක වූ විට ශුන්‍ය නොවන තත්ත්වයක් ලබා දෙන `omarchy-dictation-<backend>` නමැති ක්‍රියාත්මක කළ හැකි ගොනුවක් සපයන්න. එහි ස්ථාපකය සැපයුම්කරු වින්‍යාස කර සාර්ථක සැකසීමෙන් පසු `omarchy-dictation-use <backend>` අමතයි. මෙය පෙර backend එක නවතා තේරීම පරමාණුකව සුරකියි; සැපයුම්කරු අක්‍රීයව හෝ ලබා ගත නොහැකිව ඇති විට `stop` සාර්ථක විය යුතුය. Backend නම් සඳහා කුඩා අකුරු, ඉලක්කම් සහ හයිෆන් භාවිත කරයි. සැකසීම සඳහා `omarchy-install-dictation-<backend>` සපයන්න; `omarchy default dictation <backend>` එය දියත් කරයි. එම තේරීම්කරු ඇමතීමට Omarchy මෙනු දිගුවක් හරහා Defaults මෙනු අයිතමයක් එක් කරන්න. විකල්ප desktop ඒකාබද්ධතාව `${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua` තුළ තිබිය හැක.
