# මාරු කිරීම්, අක්‍රිය සහ තිර ආරක්ෂකය

ඔබ දිනපතා වෙනස් කරන බොහෝ දේ ඇත්තටම සැකසුමක් නොවේ. එය පැයක් සක්‍රිය කර නැවත අක්‍රිය කරන මාදිලියකි: ඔබ ප්‍රමාද වන තුරු වැඩ කරන අතරතුර රාත්‍රී ආලෝකය, ඔබ ඉදිරිපත් කරන අතරතුර බාධා නොකරන්න, ඔබ යමක් නරඹන අතරතුර අවදියෙන් සිටින්න. Omarchy ඒවා මාරු කිරීම් ලෙස හඳුන්වන අතර, ඒවා සියල්ලම එකම ආකාරයකින් වැඩ කරයි — උණුසුම් යතුරක්, මෙනු ප්‍රවේශයක් සහ විධානයක්, සියල්ලම එකම ස්විචයට වදී.

### මාරු කිරීමේ මෙනුව

`Super + Ctrl + O` _ක්‍රියාත්මක > සක්‍රිය/අක්‍රිය_ කෙලින්ම විවෘත කරයි, නැතහොත් ඔබට Omarchy මෙනුවේ (`Super + Space`) සිට එහි ඇවිද යා හැකිය. එම ලැයිස්තුවේ ඇති සියල්ල තත්වය ජීවත් වන්නේ කොහේදැයි නොසිතා ඔබට මාරු කළ හැකි ස්විචයකි. ඩෙස්ක්ටොප් එක පෙනෙන ආකාරය සඳහා ස්විච එහි අසලින්, _ක්‍රියාත්මක > පෙනුම_ යටතේ හිඳියි.

ටර්මිනලයෙන්, එම ස්විචම `omarchy toggle <thing>` වේ. සමස්ත කාණ්ඩයම බැලීමට `omarchy toggle` තනිවම ධාවනය කරන්න.

| මාරු කිරීම | උණුසුම් යතුර | විධානය |
| ------ | ------ | ------- |
| රාත්‍රී ආලෝකය | `Super + Ctrl + N` | `omarchy toggle nightlight` |
| දැනුම්දීම් නිහඬ කරන්න | `Super + Ctrl + ,` | `omarchy toggle notification silencing` |
| අවදියෙන් සිටින්න (අක්‍රිය අගුල නැත) | `Super + Ctrl + I` | `omarchy toggle idle` |
| බිඳවැටීම් ග්‍රහණය | — | `omarchy toggle crash-capture` |
| තිර ආරක්ෂකය | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) තේමා සමමුහුර්තය | — | `omarchy toggle theme sync` |
| මෙනු තීරුව | `Super + Shift + Space` | `omarchy toggle bar` |
| ටච්පෑඩය | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| ස්පර්ශ තිරය | — | `omarchy toggle touchscreen` |
| අත්හිටුවන්න | — | `omarchy toggle suspend` |
| දෙමුහුන් GPU | — | `omarchy toggle hybrid gpu` |

ටච්පෑඩ්, ස්පර්ශ තිර සහ දෙමුහුන් GPU ස්විච මාරු කිරීම යටතේ නොව _ක්‍රියාත්මක > දෘඪාංග_ (`Super + Ctrl + H`) යටතේ ජීවත් වන්නේ, ඒවා දිස්වන්නේ ඔබට ඇත්තටම එම දෘඪාංගය ඇති විට පමණක් බැවිනි. ටච්පෑඩ් සහ ස්පර්ශ තිර ඒවා Hyprland නැවත පූරණයකින් බේරී සිටියි — අක්‍රිය කළ උපාංගයේ නම Hyprland ආරම්භයේදී එය නැවත අක්‍රිය කිරීමට කියවන කුඩා තත්ව ගොනුවකට සුරකිනු ලැබේ.

_ක්‍රියාත්මක > පෙනුම_ මෙනු තීරුව සහ සජීවිකරණ රඳවා ගනී, ඊට අමතරව `omarchy toggle` විධාන නොව නමුත් එලෙසම ක්‍රියා කරන දේවල් කිහිපයක්: තීරුවේ බැටරි ප්‍රතිශතය, පෙරනිමි වැඩබිම් සැකැස්ම, කවුළු හිඩැස් (`Super + Shift + Backspace`), සහ කවුළු 1 චතුරස්‍ර අනුපාතය (`Super + Ctrl + Backspace`).

මේවායින් බොහොමයක් `~/.local/state/omarchy/toggles/` යටතේ ඇති ධජ ගොනුවක් පමණි. ඔබට ස්ක්‍රිප්ට් එකක එකක් මත අතු බෙදීමට අවශ්‍ය නම්, `omarchy-toggle-enabled` ඔබව සොයන්නට සලස්වනවා වෙනුවට පිටවීමේ කේතයක් ලබා දෙයි:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

ධජ අක්‍රිය තත්වය සඳහා නම් කර ඇත — `screensaver-off`, `suspend-off`, `bar-off` — එබැවින් ඒවායේ පැවැත්ම යනු විශේෂාංගය අක්‍රිය කර ඇති බවයි.

### තීරුවේ දර්ශක

මාදිලියක් සක්‍රිය කළ විට, ඔබට ඔරලෝසුව අසල ඉහළ තීරුවේ මැද කුඩා ග්ලිෆ් එකක් ලැබේ. එය දර්ශක විජෙට් එක වන අතර, එය උච්චාරණය, තිර පටිගත කිරීම, එල්ලෙන මතක්කිරීම්, රාත්‍රී ආලෝකය, බාධා නොකරන්න, සහ අවදියෙන් සිටින්න දරයි.

අක්‍රිය දර්ශක සැඟවී ඇත. ඒවා වටා ඇති ප්‍රදේශයන්හි මූසිකය තබන්න, ඒවා අඳුරුව මැකී එනු ඇත, එබැවින් ඔබට එහි උණුසුම් යතුර නොදැන එකක් සක්‍රිය කිරීමට ක්ලික් කළ හැකිය. ක්‍රියාකාරී එකක් ක්ලික් කිරීම එය නැවත අක්‍රිය කරයි. ඔබ ඒවා සියල්ලම සෑම විටම දැකීමට කැමති නම්, `~/.config/omarchy/shell.json` හි `omarchy.indicators` ප්‍රවේශයේ `alwaysShow` `true` ලෙස සැකසන්න — තීරු විජෙට් වින්‍යාස කරන ආකාරය සඳහා [ඉහළ තීරුව](05-the-top-bar.md) බලන්න.

### රාත්‍රී ආලෝකය

`Super + Ctrl + N` තිරය 4000K දක්වා උණුසුම් කරයි, නැවත එය එබීමෙන් එය 6500K වෙත ආපසු ගෙන එයි. එය ධාවනය වන්නේ නැති නම් මාරු කිරීම ඔබට ආරම්භ කර දෙන hyprsunset මගින් ධාවනය වේ.

පෙරනිමියෙන් hyprsunset ඔබේ තිරයට කිසිවක් නොකරයි. `~/.config/hypr/hyprsunset.conf` ඔබ උණුසුම්බව ඉල්ලන තුරු සංදර්ශකය නොස්පර්ශව පවතින පරිදි අනන්‍යතා පැතිකඩක් සමඟ නැව්ගත වේ. ඔබ එය ඔරලෝසුව අනුව මාරු වීමට කැමති නම්, එය වේලා පැතිකඩක් සමඟ ප්‍රතිස්ථාපනය කරන්න:

```
profile {
    time = 20:00
    temperature = 4000
}
```

ඉන්පසු `~/.config/hypr/autostart.lua` වෙත `o.launch_on_start("hyprsunset")` එක් කිරීමෙන් ලොග් වීමේදී hyprsunset ආරම්භ කරන්න. මාරු කිරීම භාවිතා කරන 4000K/6500K යුගලය ස්ථාවර බැවින්, ඔබට වෙනස් උෂ්ණත්වයක් අවශ්‍ය නම් වින්‍යාස ගොනුව ඔබ යන තැනයි.

### බාධා නොකරන්න

`Super + Ctrl + ,` දැනුම්දීම් නිහඬ කරයි. එය සක්‍රියව තිබියදී කිසිදු ටෝස්ට් එකක් දිස් නොවන අතර, ඩෙස්ක්ටොප් එක නිහඬ වූයේ මන්දැයි ඔබට මතක් කිරීමට හරස් කළ බෙල් දර්ශකය තීරුවේ හිඳියි.

කෙසේ වෙතත් කිසිවක් නැති නොවේ. නිහඬ කළ දැනුම්දීමක් ඔබ ආපසු පැමිණ ඔබට මග හැරුණේ කුමක්දැයි අසන විට ඔබට අවශ්‍යම වාර්තාව වන ඔබේ දැනුම්දීම් ඉතිහාසයට කෙලින්ම ලියා ඇත. එය `Super + Shift + Alt + ,` සමඟ විවෘත කරන්න. දැනුම්දීම් කතාවේ ඉතිරිය සඳහා [දැනුම්දීම්](10-notices.md) බලන්න.

පණිවිඩ වර්ග දෙකක් තවමත් හරහා යයි: ඔබ දැන් කළ දෙයක් සඳහා Omarchy හිම තහවුරු කිරීමේ ටෝස්ට් ("තේමාව වෙනස් විය", "තිර රුව සුරකින ලදී"), සහ විධාන රේඛාවෙන් යවන ලද බරපතල ඇඟවීම්. ඔබ ඉදිරියට බලහත්කාරයෙන් පැමිණීමට සියල්ල බරපතල ලෙස සලකුණු කරන කතාබස් යෙදුම් සුදුසුකම් නොලබයි.

### අක්‍රිය

Omarchy shell එක අක්‍රිය හැසිරීම හිමිකර ගන්නා අතර, වේලාවන් `~/.config/omarchy/shell.json` හි ඉහළ මට්ටමේ `idle` කොටසකි:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

අංක දෙකම ඔබ අක්‍රිය වූ මොහොතේ සිට ගණන් කරන තත්පර වේ — එකිනෙකාගෙන් නොවේ. එබැවින් පෙරනිමි සමඟ, තිර ආරක්ෂකය මිනිත්තු දෙකහමාරකට පසුව පැමිණෙන අතර අගුලු තිරය තිර ආරක්ෂකය ධාවනය වූවාද නැද්ද යන්න නොසලකා මිනිත්තු පහකින් අත්පත් කර ගනී. ගොනුව සුරකින්න, shell එක නව වේලාවන් වහාම ලබා ගනී.

ඔබ අගුලු කාලසීමාවට පෙර තිර ආරක්ෂකය ඉවත් කළහොත්, එය ක්‍රියාකාරකමක් ලෙස ගණන් ගන්නා අතර εκක‍්‍රෙමෙන අගුල අවලංගු වේ. ඔබේ යන්ත්‍රය දෙස බැලීම නිසා ඔබ අගුලු වැටෙන්නේ නැත.

අක්‍රිය විට අගුලු දැමීම සම්පූර්ණයෙන්ම නැවැත්වීමට, `Super + Ctrl + I` — නැතහොත් `omarchy toggle idle` — අවදියෙන් සිටීම සක්‍රිය කරයි, සහ කෝපි කෝප්ප දර්ශකය තීරුවේ දිස් වේ. දිගු ඉදිරිපත් කිරීමකට හෝ ඔබ නැරඹීමට අවශ්‍ය ගොඩනැගීමකට පෙර එය එබිය යුතු එකයි. සාමාන්‍ය තත්වයට ආපසු යාමට එය නැවත ඔබන්න. ඔබට එය ස්ක්‍රිප්ට් එකකින් අවශ්‍ය නම් `omarchy toggle idle status` වත්මන් තත්වය JSON ලෙස මුද්‍රණය කරයි.

මෙය අගුලු දැමීම සහ තිර ආරක්ෂකය ගැන මිස බලය ගැන නොවේ. අත්හිටුවීම සහ ශිශිරතරණයට [පද්ධති නින්ද](36-system-sleep.md) හි තමන්ගේම සැකසුම ඇත.

### තිර ආරක්ෂකය

Omarchy හි තිර ආරක්ෂකය අහඹු පෙළ ප්‍රයෝග හරහා ධාවනය වන ASCII කලාවකි, මොනිටරයකට එක් අවස්ථාව බැගින්. ඕනෑම යතුරක් හෝ මූසික චලනයක් එයින් පිටත් වේ.

ඔබ අක්‍රිය තිර ආරක්ෂකය අක්‍රිය කර තිබුණද එය බලහත්කාරයෙන් ඉහළට ගෙන එන _පද්ධතිය > තිර ආරක්ෂකය_ (`Super + Esc`) වෙතින් ඔබට එය ඉල්ලීම මත ආරම්භ කළ හැකිය. පෙරනිමියෙන් එයට බැඳුණු උණුසුම් යතුරක් නැත.

`omarchy toggle screensaver` යනු ඔබ වැඩ කිරීමේ සිට අගුලු වැටීමට කෙලින්ම යාමට කැමති නම් අක්‍රිය එක අක්‍රිය කරන දෙයයි. එය වින්‍යාස කරන්නේ කෙසේදැයි දන්නා ටර්මිනලයක් අවශ්‍ය වේ — Alacritty, Foot, Ghostty, හෝ Kitty — සහ ඔබේ පෙරනිමි ටර්මිනලය වෙනත් දෙයක් නම් එය ඔබට පවසනු ඇත.

එය අඳින ලාංඡනය ඔබේම වෙනස් කිරීමට වන අතර, _විලාසය > තිර ආරක්ෂකය_ යටතේ. png හෝ svg එකක් උඩුගත කරන්න, Omarchy එය ASCII බවට පරිවර්තනය කරයි. [බ්‍රෑන්ඩිං](41-branding.md) බලන්න.

### අගුලු තිරය

`Super + Ctrl + L` යන්ත්‍රය අගුලු දායි. එය Omarchy shell එකෙන් අගුලු තිරය ධාවනය කරයි, සංදර්ශකය හිස් කරයි, ඔබ වැරදි අක්ෂර මාලාවකින් ඔබේ මුරපදය ටයිප් නොකරන පරිදි ඔබේ යතුරුපුවරු සැකැස්ම පළමු එකට යළි පිහිටුවයි, සහ — ඔබ එය ධාවනය කරන්නේ නම් — පිටත් වන මාර්ගයේදී 1Password අගුලු දායි.

අගුලු තිරය මුරපදයක් ගන්නා අතර, ඔබ එකක් සකසා ගත් පසු එය ඇඟිලි සලකුණක් ද ගනු ඇත. එය, සහ සත්‍යාපනය කිරීමේ අනෙකුත් ක්‍රම, [දෘඪාංග සත්‍යාපනය](37-hardware-authentication.md) හි ආවරණය කර ඇත.
