# ටොගල්, අක්‍රියතාව සහ ස්ක්‍රීන්සේවර් එක

දිනෙන් දින ඔබ වෙනස් කරන බොහෝ දේ ඇත්තටම සැකසුමක් නෙවෙයි. ඒක පැයක් වෙලා ක්‍රියාත්මක කරලා ආයෙත් නිවා දමන ප්‍රකාරයක්: රෑ දිගට වැඩ කරන විට රාත්‍රී ආලෝකය, ඉදිරිපත් කරන විට බාධා නොකරන්න, යමක් නරඹන විට අවදියෙන් සිටීම. Omarchy ඒවාට ටොගල් කියලා කියනවා, ඒ ඔක්කොම වැඩ කරන්නේ එකම විදිහටයි — හොට්කීයක්, මෙනු ඇතුළත් කිරීමක් සහ විධානයක්, ඔක්කොම එකම ස්විචයටයි පහර දෙන්නේ.

### ටොගල් මෙනුව

`Super + Ctrl + O` _Trigger > Toggle_ කෙලින්ම විවෘත කරනවා, නැත්නම් Omarchy මෙනුවෙන් (`Super + Space`) ඔබට එතැනට යන්න පුළුවන්. එම ලැයිස්තුවේ හැම දෙයක්ම තත්වය කොහේ තියෙනවද කියලා හිතන්නේ නැතිව පෙරළා දාන්න පුළුවන් ස්විචයක්. ඩෙස්ක්ටොප් එක පෙනෙන විදිහ වෙනස් කරන ස්විච ඊට යාබදව, _Appearance_ යටතේ තියෙනවා.

ටර්මිනලයෙන්, එම ස්විචම තමයි `omarchy toggle <thing>`. කණ්ඩායමම බලාගන්න `omarchy toggle` තනිවම ධාවනය කරන්න.

| ටොගලය | හොට්කීය | විධානය |
| ------ | ------ | ------- |
| රාත්‍රී ආලෝකය | — | `omarchy toggle nightlight` |
| දැනුම්දීම් නිහඬ කිරීම | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| අවදියෙන් සිටීම (අක්‍රිය අගුළ නැත) | `Super + Ctrl + I` | `omarchy toggle idle` |
| බිඳවැටීම් ග්‍රහණය | — | `omarchy toggle crash-capture` |
| ස්ක්‍රීන්සේවර් | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) තේමා සමමුහුර්තය | — | `omarchy toggle theme sync` |
| මෙනු තීරුව | `Super + Shift + Space` | `omarchy toggle bar` |
| Touchpad | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| ස්පර්ශ තිරය | — | `omarchy toggle touchscreen` |
| අත්හිටුවීම | — | `omarchy toggle suspend` |
| Hybrid GPU | — | `omarchy toggle hybrid gpu` |

Touchpad, ස්පර්ශ තිර සහ Hybrid GPU ස්විච තියෙන්නේ Toggle යටතේ නෙවෙයි, _Trigger > Hardware_ (`Super + Ctrl + H`) යටතේයි, මොකද ඒවා පෙන්වන්නේ ඔබට ඇත්තටම එම දෘඪාංග තියෙන විට විතරයි. Touchpad සහ ස්පර්ශ තිර ස්විච Hyprland එක නැවත පූරණය කළත් රැඳෙනවා — අක්‍රිය කළ උපාංගයේ නම කුඩා තත්ව ගොනුවකට සුරකිනවා, ආරම්භයේදී Hyprland ඒක කියවලා එය නැවත අක්‍රිය කරනවා.

_Appearance_ තුළ මෙනු තීරුව සහ සජීවිකරණ, තව `omarchy toggle` විධාන නොවුණත් ඒ ආකාරයටම හැසිරෙන දේවල් කිහිපයක් තියෙනවා: තීරුවේ බැටරි ප්‍රතිශතය, පෙරනිමි වැඩබිම් පිරිසැලසුම, සහ _Windows_ යටතේ, කවුළු හිඩැස් (`Super + Shift + Backspace`) සහ කවුළු 1ක හතරැස් ආකාර අනුපාතය (`Super + Ctrl + Backspace`).

මේවායින් බොහොමයක් ඇත්තේ `~/.local/state/omarchy/toggles/` යටතේ ඇති ධජ ගොනුවක් විතරයි. ස්ක්‍රිප්ට් එකකදී එකක් මත අතු බෙදන්න ඕන නම්, ඔබව හොයන්න යවන්නේ නැතිව `omarchy-toggle-enabled` මඟින් පිටත්වීමේ කේතයක් ලැබෙනවා:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

ධජ නම් කරලා තියෙන්නේ නිවා ඇති තත්වයටයි — `screensaver-off`, `suspend-off`, `bar-off` — ඒ නිසා ඒවා තිබීමෙන් කියවෙන්නේ විශේෂාංගය අක්‍රිය කරලා කියලයි.

### තීරුවේ දර්ශක

ප්‍රකාරයක් ක්‍රියාත්මක විට, ඔරලෝසුව ළඟ ඉහළ තීරුවේ මැද කුඩා ග්ලිෆයක් ලැබෙනවා. ඒ තමයි දර්ශක විජට් එක, එහි ඩික්ටේෂන්, තිර පටිගත කිරීම, බලාපොරොත්තුවෙන් ඇති මතක් කිරීම්, රාත්‍රී ආලෝකය, බාධා නොකරන්න සහ අවදියෙන් සිටීම තියෙනවා.

අක්‍රිය දර්ශක සඟවලා තියෙනවා. තීරුවේ කොතැනක හෝ උඩින් ගෙනගිය විට ඒවා අඳුරු වෙලා පෙනෙනවා, ඒ නිසා හොට්කීය දන්නේ නැතිව වුණත් එකක් ක්ලික් කරලා ක්‍රියාත්මක කරන්න පුළුවන්. ක්‍රියාත්මක එකක් ක්ලික් කළොත් එය ආයෙත් නිවා දමනවා. ඒ ඔක්කොම හැම වෙලේම පේන්න ඕන නම්, `~/.config/omarchy/shell.json` හි `omarchy.indicators` ඇතුළත් කිරීමේ `alwaysShow` එක `true` ලෙස සකසන්න — තීරු විජට් වින්‍යාස කරන විදිහ සඳහා [ඉහළ තීරුව](05-the-top-bar.md) බලන්න.

### රාත්‍රී ආලෝකය

රාත්‍රී ආලෝකය තිරය 4000K දක්වා උණුසුම් කරනවා, නැවත ටොගල් කළොත් එය 6500K වෙත ආපසු යනවා. ටොගල් මෙනුවෙන් (`Super + Ctrl + O`) හෝ `omarchy toggle nightlight` මඟින් එය පෙරළන්න. එය ධාවනය කරන්නේ hyprsunset මඟින්, එය දැනටමත් ධාවනය නොවෙනවා නම් ටොගලය ඔබ වෙනුවෙන් එය ආරම්භ කරනවා.

පෙරනිමියෙන් hyprsunset ඔබේ තිරයට කිසිම දෙයක් කරන්නේ නැහැ. `~/.config/hypr/hyprsunset.conf` අනන්‍යතා පැතිකඩක් සමඟම එන්නේ ඔබ උණුසුම ඉල්ලන තුරු සංදර්ශකය ස්පර්ශ නොවී තියෙන්නටයි. ඒ වෙනුවට ඔරලෝසුව අනුව මාරු වෙන්න ඕන නම්, ඒක කාල පැතිකඩකින් ප්‍රතිස්ථාපනය කරන්න:

```
profile {
    time = 20:00
    temperature = 4000
}
```

ඊට පස්සේ `~/.config/hypr/autostart.lua` වෙත `o.launch_on_start("hyprsunset")` එකතු කරලා පිවිසීමේදී hyprsunset ආරම්භ කරන්න. ටොගලය භාවිතා කරන 4000K/6500K යුගලය ස්ථාවරයි, ඒ නිසා වෙනස් උෂ්ණත්වයක් ඕන නම් යන්න ඕන තැන තමයි වින්‍යාස ගොනුව.

### බාධා නොකරන්න

`Super + Ctrl + Alt + ,` දැනුම්දීම් නිහඬ කරනවා. එය ක්‍රියාත්මක විට කිසිම ටෝස්ට් එකක් උත්පතනය වෙන්නේ නැහැ, ඩෙස්ක්ටොප් එක නිහඬ වුණේ ඇයි කියලා මතක් කරන්න කපා දැමූ සීනු දර්ශකය තීරුවේ ඉන්නවා.

ඒත් කිසිම දෙයක් නැති වෙන්නේ නැහැ. නිහඬ කළ දැනුම්දීම් රඳවා තබනවා: අන්තිම කිහිපය `Super + Shift + Alt + ,` මඟින් නැවත තිරයට දාන්න. ඉතිරිය සඳහා [දැනුම්දීම්](10-notices.md) බලන්න.

පණිවිඩ වර්ග දෙකක් තවමත් හරහා එනවා: ඔබ දැන් කළ දෙයක් සඳහා Omarchy හිම තහවුරු කිරීමේ ටෝස්ට් ("Theme changed", "Screenshot saved"), සහ විධාන පේළියෙන් එවන තීරණාත්මක ඇඟවීම්. හැම දෙයක්ම තීරණාත්මක ලෙස සලකුණු කරලා ඔබ ඉදිරියට බලෙන් එන්න හදන කතාබස් යෙදුම් සුදුසුකම් ලබන්නේ නැහැ.

### අක්‍රියතාව

Omarchy කවචය අක්‍රිය හැසිරීම හිමි කරගන්නවා, වේලාවන් තියෙන්නේ `~/.config/omarchy/shell.json` හි ඉහළ මට්ටමේ `idle` කොටසකයි:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

අංක දෙකම ඔබ අක්‍රිය වූ මොහොතේ සිට ගණන් කරන තත්පර — එකිනෙකගෙන් නෙවෙයි. ඒ නිසා පෙරනිමි සමඟ, විනාඩි දෙකහමාරකට පස්සේ ස්ක්‍රීන්සේවර් එක එනවා, ස්ක්‍රීන්සේවර් එක ධාවනය වුණත් නැතත් විනාඩි පහට අගුළු තිරය භාරගන්නවා. ගොනුව සුරකින්න, කවචය අලුත් වේලාවන් වහාම අරගන්නවා.

අගුළු අවසන් වේලාවට කලින් ස්ක්‍රීන්සේවර් එක ඉවත් කළොත්, ඒක ක්‍රියාකාරකමක් ලෙස ගණන් ගන්නවා, බලාපොරොත්තුවෙන් ඇති අගුළ අවලංගු වෙනවා. ඔබේ යන්ත්‍රය දිහා එබී බැලුවාට ඔබ අගුළු වැටෙන්නේ නැහැ.

අක්‍රියතාව මත අගුළු දැමීම සම්පූර්ණයෙන්ම නවත්වන්න, `Super + Ctrl + I` — නැත්නම් `omarchy toggle idle` — අවදියෙන් සිටීම ක්‍රියාත්මක කරනවා, කෝපි කෝප්ප දර්ශකය තීරුවේ පෙනෙනවා. දිගු ඉදිරිපත් කිරීමකට හෝ ඔබට බලන්න ඕන බිල්ඩ් එකකට කලින් ඔබන්න ඕන එක තමයි ඒක. සාමාන්‍ය තත්වයට ආපසු යන්න එය නැවත ඔබන්න. ස්ක්‍රිප්ට් එකකින් ඕන නම් `omarchy toggle idle status` වත්මන් තත්වය JSON ලෙස මුද්‍රණය කරනවා.

මේක බලය ගැන නෙවෙයි, අගුළු දැමීම සහ ස්ක්‍රීන්සේවර් එක ගැනයි. අත්හිටුවීමට සහ හිදීකරණයට ඒවාටම අදාළ සැකසුම [පද්ධති නින්ද](36-system-sleep.md) තුළ තියෙනවා.

### ස්ක්‍රීන්සේවර් එක

Omarchy හි ස්ක්‍රීන්සේවර් එක අහඹු පෙළ ප්‍රයෝග හරහා ධාවනය වන ASCII කලාවක්, මොනිටරයකට එක බැගින්. ඕනෑම යතුරක් හෝ මූසික චලනයක් එයින් පිටත් වෙනවා.

අක්‍රිය ස්ක්‍රීන්සේවර් එක නිවා දාලා තිබුණත් එය බලෙන් උඩට ගේන _System > Screensaver_ (`Super + Esc`) මඟින් ඔබට එය ඉල්ලුම මත ආරම්භ කරන්න පුළුවන්. පෙරනිමියෙන් එයට හොට්කීයක් බැඳලා නැහැ.

ඔබට වැඩ කිරීමේ සිට කෙලින්ම අගුළු වැටුණු තත්වයට යන්න ඕන නම්, අක්‍රිය එක නිවා දාන්නේ `omarchy toggle screensaver` තමයි. ඕනෑම යතුරක්, ක්ලික් කිරීමක්, අනුචලනයක් හෝ මූසික චලනයක් එය වහනවා.

එය අඳින ලාංඡනය වෙනස් කිරීම ඔබ සතුයි, _Appearance > Branding > Screensaver_ යටතේ. png හෝ svg එකක් උඩුගත කරන්න, Omarchy එය ASCII බවට පරිවර්තනය කරනවා. [සන්නාමකරණය](41-branding.md) බලන්න.

### අගුළු තිරය

`Super + Ctrl + L` යන්ත්‍රය අගුළු දමනවා. ඒක Omarchy කවචයෙන් අගුළු තිරය ධාවනය කරනවා, සංදර්ශකය හිස් කරනවා, ඔබ වැරදි හෝඩියකින් මුරපදය ලියන්නේ නැති වෙන්න ඔබේ යතුරුපුවරු පිරිසැලසුම පළමුවැන්නට නැවත සකසනවා, සහ — ඔබ එය ධාවනය කරගෙන ඉන්නවා නම් — පිටත් වන විට 1Password අගුළු දමනවා.

අගුළු තිරය මුරපදයක් ගන්නවා, ඔබ එකක් සකසලා තිබුණොත් ඇඟිලි සලකුණකුත් ගන්නවා. ඒක සහ සත්‍යාපනය කරන අනිත් විදි [දෘඪාංග සත්‍යාපනය](37-hardware-authentication.md) තුළ ආවරණය වෙනවා.
