# ටොගල්, අක්‍රියතාව සහ තිර සුරැකුම

ඔබ දිනපතා වෙනස් කරන බොහෝ දේ ඇත්තෙන්ම සැකසීම් නොවේ. ඒවා පැයක් පමණ ක්‍රියාත්මක කර නැවත අක්‍රිය කරන මාදිලි ය: රෑ වන තුරු වැඩ කරන විට රාත්‍රී ආලෝකය, ඉදිරිපත් කිරීමක් කරන විට බාධා නොකරන්න, යමක් නරඹන විට අවදියෙන් සිටීම. Omarchy ඒවා ටොගල් ලෙස හඳුන්වන අතර, ඒවා සියල්ලම එකම ආකාරයෙන් ක්‍රියා කරයි — හොට්කීයක්, මෙනු ඇතුළත් කිරීමක් සහ විධානයක්, සියල්ලම එකම ස්විචයටම පහර දෙයි.

### ටොගල් මෙනුව

`Super + Ctrl + O` මඟින් _Trigger > Toggle_ කෙලින්ම විවෘත වේ, නැතහොත් Omarchy මෙනුවෙන් (`Super + Space`) ඔබට එතැනට යා හැකිය. ඒ ලැයිස්තුවේ ඇති සියල්ලම, තත්ත්වය කොහේ තිබේදැයි නොසිතා ඔබට පෙරළා දැමිය හැකි ස්විචයන් ය. ඩෙස්ක්ටොප් එකේ පෙනුම සම්බන්ධ ස්විච ඊට යාබදව, _Appearance_ යටතේ තිබේ.

ටර්මිනලයෙන්, එකම ස්විචයන් වන්නේ `omarchy toggle <thing>` ය. මුළු කණ්ඩායමම බැලීමට `omarchy toggle` තනිවම ධාවනය කරන්න.

| ටොගලය | හොට්කීය | විධානය |
| ------ | ------ | ------- |
| රාත්‍රී ආලෝකය | — | `omarchy toggle nightlight` |
| දැනුම්දීම නිහඬ කිරීම | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| අවදියෙන් සිටීම (අක්‍රිය අගුල නැත) | `Super + Ctrl + I` | `omarchy toggle idle` |
| බිඳවැටීම් අල්ලා ගැනීම | — | `omarchy toggle crash-capture` |
| තිර සුරැකුම | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) තේමා සමමුහුර්තය | — | `omarchy toggle theme sync` |
| මෙනු තීරුව | `Super + Shift + Space` | `omarchy toggle bar` |
| ටච්පෑඩය | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| ස්පර්ශ තිරය | — | `omarchy toggle touchscreen` |
| අත්හිටුවීම | — | `omarchy toggle suspend` |
| දෙමුහුන් GPU | — | `omarchy toggle hybrid gpu` |

ටච්පෑඩ, ස්පර්ශ තිර සහ දෙමුහුන් GPU ස්විච _Trigger > Hardware_ (`Super + Ctrl + H`) යටතේ මිස Toggle යටතේ නොතිබෙන්නේ, ඒවා පෙන්වන්නේ ඔබට ඇත්තටම ඒ දෘඪාංගය ඇති විට පමණක් බැවිනි. ටච්පෑඩ සහ ස්පර්ශ තිර ස්විච Hyprland නැවත පූරණයකින් පසුවත් රැඳී සිටියි — අක්‍රිය කළ උපාංගයේ නාමය කුඩා තත්ත්ව ගොනුවකට සුරකින අතර, එය නැවත අක්‍රිය කිරීමට Hyprland ආරම්භයේදී එය කියවයි.

_Appearance_ තුළ මෙනු තීරුව සහ සජීවිකරණ අඩංගු වන අතර, `omarchy toggle` විධාන නොවූවත් එකම ආකාරයෙන් හැසිරෙන තවත් දේ කිහිපයක් ද අඩංගු වේ: තීරුවේ බැටරි ප්‍රතිශතය, පෙරනිමි වැඩබිම් පිරිසැලසුම, සහ _Windows_ යටතේ, කවුළු හිඩැස් (`Super + Shift + Backspace`) සහ කවුළු 1ක හතරැස් ආස්ථානය (`Super + Ctrl + Backspace`).

මේවායින් බොහොමයක් ඇත්තේ `~/.local/state/omarchy/toggles/` යටතේ ඇති ධජ ගොනුවක් පමණි. ස්ක්‍රිප්ට් එකක ඒවායින් එකක් මත ශාඛා වීමට ඔබට අවශ්‍ය නම්, එය සොයන්නට යාම වෙනුවට `omarchy-toggle-enabled` මඟින් ඔබට පිටත්වීමේ කේතයක් ලබා දෙයි:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

ධජ නම් කර ඇත්තේ අක්‍රිය තත්ත්වය අනුව ය — `screensaver-off`, `suspend-off`, `bar-off` — එබැවින් ඒවා තිබීම යනු අංගය අක්‍රිය කර ඇති බවයි.

### තීරුවේ දර්ශක

මාදිලියක් ක්‍රියාත්මක වූ විට, ඔරලෝසුව අසල ඉහළ තීරුවේ මැද කුඩා ග්ලිෆයක් ඔබට ලැබේ. එය දර්ශක විජට් එක වන අතර, එය උච්චාරණ නියෝග, තිර පටිගත කිරීම, බලාපොරොත්තු වන මතක් කිරීම්, රාත්‍රී ආලෝකය, බාධා නොකරන්න සහ අවදියෙන් සිටීම රැගෙන යයි.

අක්‍රිය දර්ශක සැඟවී තිබේ. තීරුව මත ඕනෑම තැනක රැඳී සිටින්න, එවිට ඒවා අඳුරු වී මතුවේ, එබැවින් එහි හොට්කීය නොදැන වුවද ඔබට එකක් ක්ලික් කර එය ක්‍රියාත්මක කළ හැකිය. ක්‍රියාත්මක එකක් ක්ලික් කිරීමෙන් එය නැවත අක්‍රිය වේ. ඒවා සියල්ලම හැම විටම බැලීමට ඔබට අවශ්‍ය නම්, `~/.config/omarchy/shell.json` තුළ ඇති `omarchy.indicators` ඇතුළත් කිරීමේ `alwaysShow` අගය `true` ලෙස සකසන්න — තීරු විජට් වින්‍යාස කරන ආකාරය සඳහා [ඉහළ තීරුව](05-the-top-bar.md) බලන්න.

### රාත්‍රී ආලෝකය

රාත්‍රී ආලෝකය තිරය 4000K දක්වා උණුසුම් කරන අතර, එය නැවත ටොගල් කිරීමෙන් එය 6500K වෙත යළි ගෙන එයි. ටොගල් මෙනුවෙන් (`Super + Ctrl + O`) හෝ `omarchy toggle nightlight` මඟින් එය පෙරළන්න. එය ධාවනය වන්නේ hyprsunset මඟින් වන අතර, එය දැනටමත් ධාවනය නොවන්නේ නම් ටොගලය එය ඔබට ආරම්භ කර දෙයි.

පෙරනිමියෙන් hyprsunset ඔබේ තිරයට කිසිවක්ම නොකරයි. සංදර්ශකය ඔබ උණුසුම ඉල්ලන තුරු ස්පර්ශ නොවී තැබීමට හරියටම අනන්‍යතා පැතිකඩක් සමඟ `~/.config/hypr/hyprsunset.conf` එයි. ඔරලෝසුව අනුව එය මාරු වීමට ඔබට අවශ්‍ය නම්, එය කාල පැතිකඩකින් ප්‍රතිස්ථාපනය කරන්න:

```
profile {
    time = 20:00
    temperature = 4000
}
```

ඉන්පසු `~/.config/hypr/autostart.lua` වෙත `o.launch_on_start("hyprsunset")` එක් කිරීමෙන් පිවිසීමේදී hyprsunset ආරම්භ කරන්න. ටොගලය භාවිත කරන 4000K/6500K යුගලය ස්ථාවර බැවින්, ඔබට වෙනස් උෂ්ණත්වයක් අවශ්‍ය නම් යා යුතු තැන වින්‍යාස ගොනුවයි.

### බාධා නොකරන්න

`Super + Ctrl + Alt + ,` මඟින් දැනුම්දීම නිහඬ වේ. එය ක්‍රියාත්මකව තිබෙන විට කිසිදු ටෝස්ට් එකක් මතුවන්නේ නැති අතර, ඩෙස්ක්ටොප් එක නිහඬ වූයේ ඇයිදැයි ඔබට මතක් කිරීමට කුරුසියෙන් කපා දැමූ සිංහලු දර්ශකය තීරුවේ සිටියි.

කෙසේ වෙතත්, කිසිවක් නැතිවන්නේ නැත. නිහඬ කළ දැනුම්දීම රඳවා තබා ගනී: අවසන් කිහිපය `Super + Shift + Alt + ,` මඟින් නැවත තිරයට ගෙන එන්න. ඉතිරිය සඳහා [දැනුම්දීම්](10-notices.md) බලන්න.

පණිවිඩ වර්ග දෙකක් තවමත් හරහා එයි: ඔබ දැන් කළ දෙයක් සඳහා Omarchy හිම තහවුරු කිරීමේ ටෝස්ට් ("Theme changed", "Screenshot saved"), සහ විධාන පේළියෙන් එවන තීරණාත්මක ඇඟවීම්. ඔබ ඉදිරියට බලෙන් ඒම සඳහා සියල්ල තීරණාත්මක ලෙස සලකුණු කරන කතාබස් යෙදුම් සුදුසුකම් නොලබයි.

### අක්‍රියතාව

Omarchy කවචය අක්‍රිය හැසිරීම හිමිකර ගන්නා අතර, කාලයන් `~/.config/omarchy/shell.json` තුළ ඉහළ මට්ටමේ `idle` කොටසකි:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

අංක දෙකම ඔබ අක්‍රිය වූ මොහොතේ සිට ගණන් කරන තත්පර වේ — එකිනෙකින් නොවේ. එබැවින් පෙරනිමි සමඟ, තිර සුරැකුම විනාඩි දෙකහමාරකට පසුව මතුවන අතර, තිර සුරැකුම ධාවනය වූවා වුවද නැත වුවද, අගුලු තිරය විනාඩි පහකදී අත්පත් කර ගනී. ගොනුව සුරකින්න, එවිට කවචය නව කාලයන් වහාම ලබා ගනී.

අගුලු කාලසීමාවට පෙර ඔබ තිර සුරැකුම ඉවත දැමුවහොත්, එය ක්‍රියාකාරකමක් ලෙස ගණන් ගන්නා අතර බලාපොරොත්තු වන අගුල අවලංගු වේ. ඔබේ යන්ත්‍රය දෙස බැලූ පමණින් ඔබ අගුලු වැටෙන්නේ නැත.

අක්‍රියතාව මත අගුලු දැමීම සම්පූර්ණයෙන්ම නැවැත්වීමට, `Super + Ctrl + I` — හෝ `omarchy toggle idle` — මඟින් අවදියෙන් සිටීම ක්‍රියාත්මක වන අතර, කෝපි කෝප්ප දර්ශකය තීරුවේ දිස් වේ. දිගු ඉදිරිපත් කිරීමකට හෝ ඔබට නැරඹීමට අවශ්‍ය ගොඩනැගීමකට පෙර පහර දිය යුතු එක එයයි. සාමාන්‍ය තත්ත්වයට යළි යාමට එය නැවත පහර දෙන්න. ඔබට එය ස්ක්‍රිප්ට් එකකින් අවශ්‍ය නම්, `omarchy toggle idle status` වත්මන් තත්ත්වය JSON ලෙස මුද්‍රණය කරයි.

මෙය බලය ගැන නොව, අගුලු දැමීම සහ තිර සුරැකුම ගැනය. අත්හිටුවීම සහ ශිශිරතාරණය සඳහා [පද්ධති නින්ද](36-system-sleep.md) තුළ ඒවාටම වෙන් වූ සැකසුම තිබේ.

### තිර සුරැකුම

Omarchy හි තිර සුරැකුම යනු සසම්භාවී පෙළ ප්‍රයෝග හරහා ධාවනය වන ASCII කලාවකි, එක් මොනිටරයකට එක් අවස්ථාවකි. ඕනෑම යතුරක් හෝ මූසික චලනයක් එයින් ඉවත්ව යයි.

ඔබ අක්‍රිය තිර සුරැකුම අක්‍රිය කර තිබුණද බලෙන් එය මතුවන පරිදි, _System > Screensaver_ (`Super + Esc`) වෙතින් ඔබට එය ඉල්ලුම මත ආරම්භ කළ හැකිය. පෙරනිමියෙන් එයට හොට්කීයක් බැඳී නැත.

ඔබට වැඩ කිරීමේ සිට කෙලින්ම අගුලු වැටීමට යාමට අවශ්‍ය නම්, අක්‍රිය එක අක්‍රිය කරන්නේ `omarchy toggle screensaver` ය. එය වින්‍යාස කරන ආකාරය දන්නා ටර්මිනලයක් අවශ්‍ය වේ — Alacritty, Foot, Ghostty, හෝ Kitty — ඔබේ පෙරනිමි ටර්මිනලය වෙනත් දෙයක් නම් එය ඔබට එසේ කියනු ඇත.

එය අඳින ලාංඡනය වෙනස් කිරීම ඔබ සතු වන අතර, එය _Appearance > Branding > Screensaver_ යටතේ තිබේ. png හෝ svg එකක් උඩුගත කරන්න, එවිට Omarchy එය ASCII බවට පරිවර්තනය කරයි. [සන්නාමකරණය](41-branding.md) බලන්න.

### අගුලු තිරය

`Super + Ctrl + L` යන්ත්‍රය අගුලු දමයි. එය Omarchy කවචයෙන් අගුලු තිරය ධාවනය කරයි, සංදර්ශකය හිස් කරයි, ඔබ වැරදි අකාරාදියකින් ඔබේ මුරපදය ටයිප් නොකරන පරිදි ඔබේ යතුරුපුවරු පිරිසැලසුම පළමුවැන්නට යළි සකසයි, සහ — ඔබ එය ධාවනය කරමින් සිටී නම් — පිටත් වන විට 1Password අගුලු දමයි.

අගුලු තිරය මුරපදයක් ගන්නා අතර, ඔබ එකක් සකසා ගත් පසු ඇඟිලි සලකුණක් ද ගනු ඇත. එය සහ සත්‍යාපනය කිරීමේ අනෙකුත් ක්‍රම, [දෘඪාංග සත්‍යාපනය](37-hardware-authentication.md) තුළ ආවරණය වේ.
