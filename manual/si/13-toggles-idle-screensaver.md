# ටොගල්, අක්‍රිය තත්ත්වය සහ තිර සුරකින්නා

ඔබ දිනපතා වෙනස් කරන බොහෝ දේ ඇත්ත වශයෙන්ම සැකසුමක් නොවේ. එය පැයකට සක්‍රිය කර නැවත අක්‍රිය කරන මාදිලියකි: රෑ වන තුරු වැඩ කරන විට රාත්‍රී ආලෝකය, ඉදිරිපත් කරන විට බාධා නොකරන්න, යමක් නරඹන විට අවදිව සිටීම. Omarchy ඒවා ටොගල් ලෙස හඳුන්වයි, ඒවා සියල්ලම එකම ආකාරයට ක්‍රියා කරයි — හොට්කීයක්, මෙනු ප්‍රවේශයක් සහ විධානයක්, සියල්ලම එකම ස්විචයම ක්‍රියාත්මක කරයි.

### ටොගල් මෙනුව

`Super + Ctrl + O` මඟින් _Trigger > Toggle_ කෙලින්ම විවෘත කරයි, නැතහොත් ඔබට Omarchy මෙනුවෙන් (`Super + Space`) එහි යා හැකිය. එම ලැයිස්තුවේ ඇති සියල්ලම, තත්ත්වය පවතින්නේ කොහේදැයි නොසිතා ඔබට පෙරළිය හැකි ස්විච වේ. ඩෙස්ක්ටොප් එක පෙනෙන ආකාරය සඳහා වූ ස්විච ඊට යාබදව, _Appearance_ යටතේ පිහිටයි.

ටර්මිනලයෙන්, එම ස්විචම `omarchy toggle <thing>` වේ. මුළු කණ්ඩායමම බැලීමට `omarchy toggle` තනිවම ධාවනය කරන්න.

| ටොගලය | හොට්කීය | විධානය |
| ------ | ------ | ------- |
| රාත්‍රී ආලෝකය | — | `omarchy toggle nightlight` |
| දැනුම්දීම් නිහඬ කිරීම | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| අවදිව සිටීම (අක්‍රිය අගුලු දැමීම නැත) | `Super + Ctrl + I` | `omarchy toggle idle` |
| බිඳවැටීම් අල්ලා ගැනීම | — | `omarchy toggle crash-capture` |
| තිර සුරකින්නා | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) තේමා සමමුහුර්තය | — | `omarchy toggle theme sync` |
| මෙනු තීරුව | `Super + Shift + Space` | `omarchy toggle bar` |
| ටච්පෑඩය | `XF86TouchpadToggle` | `omarchy device touchpad` |
| ස්පර්ශ තිරය | — | `omarchy device touchscreen` |
| අත්හිටුවීම | — | `omarchy toggle suspend` |
| දෙමුහුන් GPU | — | `omarchy toggle hybrid gpu` |

ටච්පෑඩය, ස්පර්ශ තිරය සහ දෙමුහුන් GPU ස්විච පවතින්නේ Toggle යටතේ නොව _Trigger > Hardware_ (`Super + Ctrl + H`) යටතේය, මන්ද ඒවා දිස්වන්නේ ඔබට ඇත්තටම එම දෘඪාංගය ඇති විට පමණි. ටච්පෑඩ සහ ස්පර්ශ තිර ඒවා Hyprland නැවත පූරණයකින් පසුවත් පවතී — අක්‍රිය කළ උපාංගයේ නම කුඩා state ගොනුවකට සුරකින අතර, Hyprland ආරම්භයේදී එය කියවා එම උපාංගය නැවත අක්‍රිය කරයි.

_Appearance_ තුළ මෙනු තීරුව සහ සජීවිකරණ අඩංගු වන අතර, `omarchy toggle` විධාන නොවූවත් එකම ආකාරයට හැසිරෙන තවත් දේ කිහිපයක්ද අඩංගු වේ: තීරුවේ බැටරි ප්‍රතිශතය, පෙරනිමි වැඩතල පිරිසැලසුම, සහ _Windows_ යටතේ, කවුළු හිඩැස් (`Super + Shift + Backspace`) සහ කවුළු 1ක හතරැස් අනුපාතය (`Super + Ctrl + Backspace`).

Hyprland ට ඇඳීමට GPU එකක් නොමැතිව ඒ වෙනුවට CPU එක මත රෙන්ඩර් කරන විට (llvmpipe), උදාහරණයක් ලෙස GPU එක තවම සහාය නොදක්වන Mac වල, බොහෝ virtual machine වල, හෝ graphics driver එකක් පූරණය වීමට අසමත් වන විට, Omarchy එම සැසිය සඳහා සජීවිකරණ, blur සහ shadows අක්‍රිය කර, දැනුම්දීමකින් ඒ බව ඔබට එක් වරක් කියයි. _Appearance > Animations On_ මඟින් ඒවා ආපසු ගෙන එයි, සහ Omarchy පසු සැසි සඳහාද එය මතක තබා ගනී.

මේවායින් බොහොමයක් ඇත්තේ `~/.local/state/omarchy/toggles/` යටතේ ඇති flag ගොනුවක් පමණි. script එකක ඒවායින් එකක් මත branch කිරීමට ඔබට අවශ්‍ය නම්, එය සොයන්නට යාම වෙනුවට `omarchy-toggle-enabled` මඟින් ඔබට exit code එකක් ලබා දෙයි:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

flags නම් කර ඇත්තේ off තත්ත්වය අනුවයි — `screensaver-off`, `suspend-off`, `bar-off` — එබැවින් ඒවා තිබීම යනු එම අංගය අක්‍රිය කර ඇති බවයි.

### තීරුවේ දර්ශක

මාදිලියක් සක්‍රිය විට, ඔරලෝසුව අසල ඉහළ තීරුවේ මැද කුඩා glyph එකක් ඔබට ලැබේ. එය indicators widget එක වන අතර, එය හඬින් ලිවීම, තිර පටිගත කිරීම, බලාපොරොත්තු වන මතක් කිරීම්, රාත්‍රී ආලෝකය, බාධා නොකරන්න, සහ අවදිව සිටීම රැගෙන යයි.

අක්‍රිය දර්ශක සඟවා ඇත. තීරුව මත ඕනෑම තැනක hover කරන්න, එවිට ඒවා අඳුරු වී මතුවේ, එවිට එහි හොට්කීය නොදැන වුවද එකක් ක්ලික් කර එය සක්‍රිය කළ හැකිය. සක්‍රිය එකක් ක්ලික් කිරීමෙන් එය නැවත අක්‍රිය වේ. ඒවා සියල්ලම සෑම විටම බැලීමට ඔබට අවශ්‍ය නම්, `~/.config/omarchy/shell.json` හි `omarchy.indicators` ප්‍රවේශයේ `alwaysShow` `true` ලෙස සකසන්න — bar widget වින්‍යාස කරන ආකාරය සඳහා [ඉහළ තීරුව](05-the-top-bar.md) බලන්න.

### රාත්‍රී ආලෝකය

රාත්‍රී ආලෝකය තිරය 4000K දක්වා උණුසුම් කරයි, එය නැවත ටොගල් කිරීමෙන් එය 6500K වෙත ආපසු ගෙන එයි. ටොගල් මෙනුවෙන් (`Super + Ctrl + O`) හෝ `omarchy toggle nightlight` සමඟ එය පෙරළන්න. එය hyprsunset මඟින් ධාවනය වන අතර, එය දැනටමත් ධාවනය නොවන්නේ නම් ටොගලය ඔබ වෙනුවෙන් එය ආරම්භ කරයි.

පෙරනිමියෙන් hyprsunset ඔබේ තිරයට කිසිවක්ම නොකරයි. `~/.config/hypr/hyprsunset.conf` identity profile එකක් සමඟ එන්නේ ඔබ උණුසුම ඉල්ලන තුරු සංදර්ශකය ස්පර්ශ නොවී තැබීමටයි. ඔබට එය ඔරලෝසුව අනුව මාරු වීමට අවශ්‍ය නම්, එය time profile එකකින් ප්‍රතිස්ථාපනය කරන්න:

```
profile {
    time = 20:00
    temperature = 4000
}
```

ඉන්පසු `~/.config/hypr/autostart.lua` වෙත `o.launch_on_start("hyprsunset")` එක් කිරීමෙන් පිවිසීමේදී hyprsunset ආරම්භ කරන්න. ටොගලය භාවිතා කරන 4000K/6500K යුගලය ස්ථාවරය, එබැවින් ඔබට වෙනස් උෂ්ණත්වයක් අවශ්‍ය නම් ඔබ යා යුත්තේ config ගොනුවටයි.

### බාධා නොකරන්න

`Super + Ctrl + Alt + ,` දැනුම්දීම් නිහඬ කරයි. එය සක්‍රියව තිබියදී කිසිදු toast එකක් මතුවන්නේ නැත, සහ ඩෙස්ක්ටොප් එක නිහඬ වූයේ ඇයිදැයි ඔබට මතක් කිරීමට හරස් කළ සීනු දර්ශකය තීරුවේ රැඳේ.

කිසිවක් නැති වන්නේ නැත. නිහඬ කළ දැනුම්දීම් රඳවා ගනියි: අවසාන කිහිපය `Super + Shift + Alt + ,` සමඟ නැවත තිරයට දමන්න. ඉතිරිය සඳහා [දැනුම්දීම්](10-notices.md) බලන්න.

පණිවිඩ වර්ග දෙකක් තවමත් හරහා එයි: ඔබ දැන් කළ දෙයක් සඳහා Omarchy හිම තහවුරු කිරීමේ toast ("Theme changed", "Screenshot saved"), සහ විධාන පේළියෙන් එවන critical alerts. සියල්ල critical ලෙස සලකුණු කර ඔබ ඉදිරියට බලහත්කාරයෙන් එන chat apps සුදුසුකම් නොලබයි.

### අක්‍රිය තත්ත්වය

Omarchy shell එක අක්‍රිය හැසිරීම හිමිකර ගනී, සහ වේලාවන් `~/.config/omarchy/shell.json` හි ඉහළ මට්ටමේ `idle` block එකකි:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

අංක දෙකම ඔබ අක්‍රිය වූ මොහොතේ සිට ගණනය කරන තත්පර වේ — එකිනෙකින් නොවේ. එබැවින් පෙරනිමියන් සමඟ, තිර සුරකින්නා මිනිත්තු දෙකහමාරකට පසු මතුවන අතර අගුලු තිරය මිනිත්තු පහකදී භාර ගනී, තිර සුරකින්නා ධාවනය වූවත් නැතත්. ගොනුව සුරකින්න, එවිට shell එක නව වේලාවන් වහාම ලබා ගනී.

අගුලු දැමීමේ අවසන් වේලාවට පෙර ඔබ තිර සුරකින්නා ඉවත් කළහොත්, එය ක්‍රියාකාරකමක් ලෙස ගණන් ගනී සහ බලාපොරොත්තු වන අගුලු දැමීම අවලංගු වේ. ඔබේ යන්ත්‍රය දෙස බැලූ පමණින් ඔබ අගුලු දැමී නොයයි.

අක්‍රිය තත්ත්වය මත අගුලු දැමීම සම්පූර්ණයෙන්ම නැවැත්වීමට, `Super + Ctrl + I` — හෝ `omarchy toggle idle` — stay awake සක්‍රිය කරයි, සහ කෝපි කෝප්ප දර්ශකය තීරුවේ දිස්වේ. දිගු ඉදිරිපත් කිරීමකට හෝ ඔබට නැරඹීමට අවශ්‍ය build එකකට පෙර ඔබන්නට ඇත්තේ එයයි. සාමාන්‍ය තත්ත්වයට ආපසු යාමට එය නැවත ඔබන්න. ඔබට script එකකින් එය අවශ්‍ය නම් `omarchy toggle idle status` වත්මන් තත්ත්වය JSON ලෙස මුද්‍රණය කරයි.

මෙය අගුලු දැමීම සහ තිර සුරකින්නා ගැන මිස බලය ගැන නොවේ. අත්හිටුවීම සහ ශිශිරතාරනය සඳහා ඒවාටම ආවේණික සැකසුම [පද්ධති නින්ද](36-system-sleep.md) හි ඇත.

### තිර සුරකින්නා

Omarchy හි තිර සුරකින්නා යනු monitor එකකට එක් instance එක බැගින්, අහඹු text effects හරහා ධාවනය වන ASCII art එකකි. ඕනෑම යතුරක් හෝ mouse චලනයක් එයින් පිටත් වේ.

ඔබට _System > Screensaver_ (`Super + Esc`) වෙතින් ඉල්ලුම මත එය ආරම්භ කළ හැකි අතර, ඔබ අක්‍රිය තිර සුරකින්නා අක්‍රිය කර තිබුණත් එය බලහත්කාරයෙන් මතුවේ. පෙරනිමියෙන් එයට හොට්කීයක් බැඳී නැත.

ඔබට වැඩ කිරීමෙන් කෙලින්ම අගුලු දැමූ තත්ත්වයට යාමට අවශ්‍ය නම්, අක්‍රිය එක අක්‍රිය කරන්නේ `omarchy toggle screensaver` යි. ඕනෑම යතුරක්, ක්ලික් එකක්, scroll කිරීමක් හෝ mouse චලනයක් එය වසා දමයි.

එය අඳින logo එක වෙනස් කිරීම ඔබ සතුය, _Appearance > Branding > Screensaver_ යටතේ. png හෝ svg එකක් upload කරන්න, එවිට Omarchy එය ASCII බවට පරිවර්තනය කරයි. [වෙළඳනාමකරණය](41-branding.md) බලන්න.

### අගුලු තිරය

`Super + Ctrl + L` යන්ත්‍රය අගුලු දමයි. එය Omarchy shell එකෙන් අගුලු තිරය ධාවනය කරයි, සංදර්ශකය හිස් කරයි, ඔබ ඔබේ මුරපදය වැරදි අකාරාදියකින් ටයිප් නොකිරීමට යතුරුපුවරු පිරිසැලසුම පළමු එකට යළි සකසයි, සහ — ඔබ එය ධාවනය කරන්නේ නම් — පිටත් වන විට 1Password අගුලු දමයි.

අගුලු තිරය මුරපදයක් ගනී, සහ ඔබ එකක් සකසා ගත් පසු ඇඟිලි සලකුණක්ද ගනී. එය සහ සත්‍යාපනය කිරීමේ අනෙකුත් ක්‍රම, [දෘඪාංග සත්‍යාපනය](37-hardware-authentication.md) හි ආවරණය කෙරේ.
