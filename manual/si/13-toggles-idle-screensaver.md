# ටොගල්, නිෂ්ක්‍රීයත්වය සහ තිර සුරකින්නා

දිනපතා ඔබ වෙනස් කරන බොහෝ දේ ඇත්තටම සැකසුමක් නොවේ. එය පැයකට ක්‍රියාත්මක කර නැවත අක්‍රිය කරන ආකාරයකි: රෑ වන තුරු වැඩ කරන විට රාත්‍රී ආලෝකය, ඉදිරිපත් කරන විට බාධා නොකරන්න, යමක් නරඹන විට අවදියෙන් සිටීම. Omarchy ඒවා ටොගල් ලෙස හඳුන්වයි, ඒ සියල්ලම ක්‍රියා කරන්නේ එකම ආකාරයකටයි — හොට්කීයක්, මෙනු ඇතුළත් කිරීමක් සහ විධානයක්, සියල්ලම එකම ස්විචයටම පහර දෙයි.

### ටොගල් මෙනුව

`Super + Ctrl + O` මගින් _Trigger > Toggle_ කෙලින්ම විවෘත වේ, නැතහොත් Omarchy මෙනුවෙන් (`Super + Space`) ඔබට එතැනට යා හැකිය. එම ලැයිස්තුවේ ඇති සියල්ලම තත්ත්වය කොහේ තිබෙනවාද යන්න ගැන නොසිතා ඔබට මාරු කළ හැකි ස්විචයකි. ඩෙස්ක්ටොප් එක පෙනෙන ආකාරය සඳහා වූ ස්විච ඊට යාබදව, _Appearance_ යටතේ තිබේ.

ටර්මිනලයෙන්, එම ස්විචම `omarchy toggle <thing>` වේ. මුළු කණ්ඩායමම බැලීමට `omarchy toggle` තනිවම ධාවනය කරන්න.

| ටොගලය | හොට්කීය | විධානය |
| ------ | ------ | ------- |
| රාත්‍රී ආලෝකය | — | `omarchy toggle nightlight` |
| දැනුම්දීම් නිහඬ කරන්න | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| අවදියෙන් සිටින්න (නිෂ්ක්‍රීය අගුල නැත) | `Super + Ctrl + I` | `omarchy toggle idle` |
| බිඳවැටීම් ග්‍රහණය | — | `omarchy toggle crash-capture` |
| තිර සුරකින්නා | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) තේමා සමමුහුර්තය | — | `omarchy toggle theme sync` |
| මෙනු තීරුව | `Super + Shift + Space` | `omarchy toggle bar` |
| ටච්පෑඩය | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| ස්පර්ශ තිරය | — | `omarchy toggle touchscreen` |
| අත්හිටුවීම | — | `omarchy toggle suspend` |
| දෙමුහුන් GPU | — | `omarchy toggle hybrid gpu` |

ටච්පෑඩය, ස්පර්ශ තිරය සහ දෙමුහුන් GPU ස්විච _Trigger > Hardware_ (`Super + Ctrl + H`) යටතේ තිබෙන්නේ Toggle යටතේ නොව, මන්ද ඒවා දිස් වන්නේ ඔබට ඇත්තටම එම දෘඪාංගය ඇති විට පමණයි. ටච්පෑඩ සහ ස්පර්ශ තිර ස්විච Hyprland යළි පූරණයකින් පසුවත් පවතී — අක්‍රිය කළ උපාංගයේ නම කුඩා තත්ත්ව ගොනුවකට සුරකින අතර, එය නැවත අක්‍රිය කිරීමට Hyprland ආරම්භයේදී එය කියවයි.

_Appearance_ හි මෙනු තීරුව සහ සජීවිකරණ අඩංගුයි, තවද `omarchy toggle` විධාන නොවූවත් එලෙසම හැසිරෙන දේ කිහිපයක්ද අඩංගුයි: තීරුවේ බැටරි ප්‍රතිශතය, පෙරනිමි වැඩබිම් සැකැස්ම, සහ _Windows_ යටතේ, කවුළු හිඩැස් (`Super + Shift + Backspace`) සහ කවුළු-1 චතුරස්‍රාකාර පැතිකඩ අනුපාතය (`Super + Ctrl + Backspace`).

ඇඳීමට Hyprland ට GPU එකක් නොමැතිව ඒ වෙනුවට CPU එක මත රෙන්ඩර් කරන විට (llvmpipe), තවමත් GPU එක සඳහා සහය නොදක්වන Mac මත මෙන්, බොහෝ අතථ්‍ය යන්ත්‍රවල, හෝ ග්‍රැෆික් ධාවකයක් පූරණය වීමට අසමත් වන විට, Omarchy එම සැසිය සඳහා සජීවිකරණ, බොඳ කිරීම සහ සෙවණැලි අක්‍රිය කර දැනුම්දීමකින් ඒ බව ඔබට එක් වරක් කියයි. _Appearance > Animations On_ ඒවා ආපසු ගෙන එයි, පසු සැසි සඳහාද Omarchy එය මතක තබා ගනී.

මේවායින් බොහොමයක් `~/.local/state/omarchy/toggles/` යටතේ ඇති ධජ ගොනුවක් පමණයි. ස්ක්‍රිප්ටයක එකක් මත කොන්දේසියක් යෙදීමට ඔබට අවශ්‍ය නම්, එය සොයන්නට ඔබව යොමු නොකර `omarchy-toggle-enabled` ඔබට පිටත්වීමේ කේතයක් දෙයි:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

ධජ නම් කර ඇත්තේ අක්‍රිය තත්ත්වය සඳහායි — `screensaver-off`, `suspend-off`, `bar-off` — එබැවින් ඒවා තිබීම යනු විශේෂාංගය අක්‍රිය කර ඇති බවයි.

### තීරුවේ දර්ශක

ආකාරයක් ක්‍රියාත්මක වූ විට, ඔරලෝසුව අසල ඉහළ තීරුව මැද ඔබට කුඩා ග්ලිෆයක් ලැබේ. එය දර්ශක විජටයයි, එයට උච්චාරණයෙන් ලිවීම, තිරය පටිගත කිරීම, බලාපොරොත්තු වන මතක් කිරීම්, රාත්‍රී ආලෝකය, බාධා නොකරන්න සහ අවදියෙන් සිටීම ඇතුළත් වේ.

අක්‍රිය දර්ශක සඟවා ඇත. තීරුවේ ඕනෑම තැනක් මත කර්සරය තබන්න, එවිට ඒවා අඳුරු වී දිස් වේ, එබැවින් එහි හොට්කීය නොදැන වුවත් ඔබට එකක් ක්ලික් කර ක්‍රියාත්මක කළ හැකිය. සක්‍රිය එකක් ක්ලික් කිරීමෙන් එය නැවත අක්‍රිය වේ. ඔබට ඒ සියල්ල සෑම විටම බැලීමට අවශ්‍ය නම්, `~/.config/omarchy/shell.json` හි `omarchy.indicators` ඇතුළත් කිරීම මත `alwaysShow` `true` ලෙස සකසන්න — තීරු විජට සකසන ආකාරය සඳහා [ඉහළ තීරුව](05-the-top-bar.md) බලන්න.

### රාත්‍රී ආලෝකය

රාත්‍රී ආලෝකය තිරය 4000K දක්වා උණුසුම් කරයි, සහ එය නැවත ටොගල් කිරීමෙන් එය 6500K වෙත ආපසු යයි. ටොගල් මෙනුවෙන් (`Super + Ctrl + O`) හෝ `omarchy toggle nightlight` සමඟ එය මාරු කරන්න. එය ධාවනය වන්නේ hyprsunset මගිනි, එය දැනටමත් ක්‍රියාත්මක නොවන්නේ නම් ටොගලය ඔබ වෙනුවෙන් එය ආරම්භ කරයි.

පෙරනිමියෙන් hyprsunset ඔබේ තිරයට කිසිම දෙයක් නොකරයි. `~/.config/hypr/hyprsunset.conf` අනන්‍යතා පැතිකඩක් සමඟ එන්නේ ඔබ උණුසුම ඉල්ලන තුරු සංදර්ශකය ස්පර්ශ නොවී තැබීමටමයි. ඔබට එය ඔරලෝසුව අනුව මාරු වීමට අවශ්‍ය නම්, එය වේලා පැතිකඩක් සමඟ ප්‍රතිස්ථාපනය කරන්න:

```
profile {
    time = 20:00
    temperature = 4000
}
```

ඉන්පසු `~/.config/hypr/autostart.lua` වෙත `o.launch_on_start("hyprsunset")` එක් කිරීමෙන් පිවිසීමේදී hyprsunset ආරම්භ කරන්න. ටොගලය භාවිත කරන 4000K/6500K යුගලය ස්ථාවරයි, එබැවින් ඔබට වෙනත් උෂ්ණත්වයක් අවශ්‍ය නම් යා යුත්තේ වින්‍යාස ගොනුවටයි.

### බාධා නොකරන්න

`Super + Ctrl + Alt + ,` දැනුම්දීම් නිහඬ කරයි. එය ක්‍රියාත්මකව තිබියදී කිසිම ටෝස්ටයක් උත්පතනය නොවේ, සහ ඩෙස්ක්ටොප් එක නිහඬ වූයේ ඇයි දැයි ඔබට මතක් කිරීමට හරස් අඳින ලද සීනු දර්ශකය තීරුවේ වාඩි වී සිටී.

කෙසේ වුවද, කිසිම දෙයක් අහිමි නොවේ. නිහඬ කළ දැනුම්දීම් රඳවා තබා ගනී: `Super + Shift + Alt + ,` සමඟ අවසාන කිහිපය නැවත තිරය මත තබන්න. ඉතිරිය සඳහා [දැන්වීම්](10-notices.md) බලන්න.

පණිවිඩ වර්ග දෙකක් තවමත් ඒමට සමත් වේ: ඔබ දැන් කළ දෙයක් සඳහා Omarchy හිම තහවුරු කිරීමේ ටෝස්ට් ("තේමාව වෙනස් විය", "තිර රුව සුරකින ලදී"), සහ විධාන රේඛාවෙන් යවන ලද තීරණාත්මක ඇඟවීම්. ඔබ ඉදිරියට බලෙන් ඒමට සියල්ල තීරණාත්මක ලෙස සලකුණු කරන චැට් යෙදුම් සුදුසුකම් නොලබයි.

### නිෂ්ක්‍රීයත්වය

Omarchy ෂෙලයට නිෂ්ක්‍රීය හැසිරීම අයත් වේ, සහ වේලාවන් `~/.config/omarchy/shell.json` හි ඉහළ මට්ටමේ `idle` කොටසකි:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

අංක දෙකම ඔබ නිෂ්ක්‍රීය වූ මොහොතේ සිට ගණන් කරන තත්පර වේ — එකිනෙකින් නොවේ. එබැවින් පෙරනිමි සමඟ, මිනිත්තු දෙකහමාරකට පසු තිර සුරකින්නා එයි, තිර සුරකින්නා ක්‍රියාත්මක වූවාද නැද්ද යන්න නොසලකා මිනිත්තු පහෙන් අගුළු තිරය භාර ගනී. ගොනුව සුරකින්න, එවිට ෂෙලය නව වේලාවන් වහාම ලබා ගනී.

අගුළු නියමිත වේලාවට පෙර ඔබ තිර සුරකින්නා ඉවත් කළහොත්, එය ක්‍රියාකාරකමක් ලෙස ගණන් ගන්නා අතර බලාපොරොත්තු වන අගුල අවලංගු වේ. ඔබේ යන්ත්‍රය දෙස බැලූ පමණින් ඔබ අගුළු වැටෙන්නේ නැත.

නිෂ්ක්‍රීයව සිටීම මත අගුළු දැමීම සම්පූර්ණයෙන්ම නැවැත්වීමට, `Super + Ctrl + I` — හෝ `omarchy toggle idle` — අවදියෙන් සිටීම ක්‍රියාත්මක කරයි, සහ කෝපි කෝප්ප දර්ශකය තීරුවේ දිස් වේ. දිගු ඉදිරිපත් කිරීමකට පෙර හෝ ඔබට නැරඹීමට අවශ්‍ය ගොඩනැගීමකට පෙර ඔබන්න ඕනෑ එක එයයි. සාමාන්‍ය තත්ත්වයට ආපසු යාමට එය නැවත ඔබන්න. ඔබට එය ස්ක්‍රිප්ටයකින් අවශ්‍ය නම් `omarchy toggle idle status` වත්මන් තත්ත්වය JSON ලෙස මුද්‍රණය කරයි.

මෙය අගුළු දැමීම සහ තිර සුරකින්නා ගැනය, බලය ගැන නොවේ. අත්හිටුවීමට සහ ශිශිරතරණයට [පද්ධති නින්ද](36-system-sleep.md) තුළ ඒවාටම වූ සැකසුම ඇත.

### තිර සුරකින්නා

Omarchy හි තිර සුරකින්නා අහඹු පෙළ ප්‍රයෝග හරහා ධාවනය වන ASCII කලාවකි, මොනිටරයකට එක බැගිනි. ඕනෑම යතුරක් හෝ මූසික චලනයක් එයින් පිටත් වේ.

_System > Screensaver_ (`Super + Esc`) වෙතින් ඔබට එය ඉල්ලීම මත ආරම්භ කළ හැකිය, ඔබ නිෂ්ක්‍රීය තිර සුරකින්නා අක්‍රිය කර තිබුණත් එය බලෙන් ඉදිරියට ගෙන එයි. පෙරනිමියෙන් එයට හොට්කීයක් බැඳී නැත.

ඔබට වැඩ කිරීමේ සිට කෙලින්ම අගුළු වැටීමට යාමට අවශ්‍ය නම්, නිෂ්ක්‍රීය එක අක්‍රිය කරන්නේ `omarchy toggle screensaver` ය. ඕනෑම යතුරක්, ක්ලික් කිරීමක්, අනුචලනයක් හෝ මූසික චලනයක් එය වසා දමයි.

එය අඳින ලාංඡනය වෙනස් කිරීම ඔබ සතුයි, _Appearance > Branding > Screensaver_ යටතේ. png හෝ svg එකක් උඩුගත කරන්න, සහ Omarchy එය ASCII බවට පරිවර්තනය කරයි. [සන්නාමකරණය](41-branding.md) බලන්න.

### අගුළු තිරය

`Super + Ctrl + L` යන්ත්‍රය අගුළු දමයි. එමගින් Omarchy ෂෙලයෙන් අගුළු තිරය ධාවනය කරයි, සංදර්ශකය හිස් කරයි, ඔබ වැරදි අකාරාදියකින් ඔබේ මුරපදය ටයිප් නොකරන ලෙස ඔබේ යතුරුපුවරු සැකැස්ම පළමුවැන්නට යළි සකසයි, සහ — ඔබ එය ධාවනය කරන්නේ නම් — පිටත් වන විටම 1Password අගුළු දමයි.

අගුළු තිරය මුරපදයක් ගනී, සහ ඔබ එකක් සකසා ගත් පසු එය ඇඟිලි සලකුණක්ද ගනී. එය, සහ සත්‍යාපනය කිරීමේ අනෙකුත් ක්‍රම, [දෘඪාංග සත්‍යාපනය](37-hardware-authentication.md) තුළ ආවරණය කෙරේ.
