# Dual Boot ස්ථාපනය

ඔබට Windows හෝ වෙනත් ස්ථාපනයන් සමඟ එක ළඟ, තනි partition එකක් මත Omarchy ස්ථාපනය කළ හැකිය.

මෙම ස්ථාපන ක්‍රමය සමඟ තවමත් පෙරනිමියෙන් partition එක සඳහා LUKS සංකේතනය ලැබෙන බැවින්, එය ප්‍රායෝගිකව සම්පූර්ණ drive එකම භාවිතා කරන ස්ථාපනයට වඩා වෙනස් නොවන අතර, අවශ්‍ය වන්නේ disk එකේ නිදහස් ඉඩ තිබීම පමණි.

## Windows හි ඉඩ සෑදීම

Windows සමඟ එක ළඟ ස්ථාපනය කිරීමට, start menu එකේ `disk management` ලෙස type කර **Hard disk partitions සාදා format කරන්න** සඳහා වන විකල්පය තෝරන්න.

 ![dual-boot-1](images/dual-boot-1.webp)

සුදුසු partition එක සොයා, right click කර, **Shrink Volume** තෝරන්න.

![dual-boot-2](images/dual-boot-2.webp)

 ඔබ shrink කිරීමට කැමති ප්‍රමාණය ඇතුළත් කරන්න. මෙය boot partition එකද ඇතුළුව ඔබේ අනාගත Omarchy ස්ථාපනයේ ප්‍රමාණය වන බව සලකන්න.

 ![dual-boot-3](images/dual-boot-3.webp)

ඔබ අවසන් කළ පසු, මෙම උදාහරණයේ අප Omarchy ස්ථාපනය කරන ස්ථානය වන 50GB කොටස ඇති මෙවැනි දෙයක් ඔබට පෙනිය යුතුය.

 ![dual-boot-4](images/dual-boot-4.webp)

## Omarchy ස්ථාපනය කිරීම

Omarchy සඳහා ස්ථාපන ක්‍රියාවලිය ප්‍රායෝගිකව සාමාන්‍ය ක්‍රියාවලියම වේ. ඔබ ඔබේ disk එක තේරූ පසු, ඔබට **නිදහස් ඉඩේ ස්ථාපනය** යන විකල්පය ලැබෙනු ඇත. සම්පූර්ණ disk එකම මකා දැමීම වැළැක්වීමට එම විකල්පය තෝරන්න.

 ![dual-boot-5](images/dual-boot-5.webp)

සියල්ල හොඳින් පෙනෙන බව තහවුරු කර, සාමාන්‍ය පරිදි ස්ථාපනය අවසන් වන තෙක් රැඳී සිටින්න. සම්පූර්ණ drive එකක ස්ථාපනය කරන විට මෙන්ම, සංකේතනය නොකර ස්ථාපනය කිරීමට (නිර්දේශ නොකෙරේ) තෝරාගත හැක්කේද මෙහිදීය.
 ![dual-boot-6](images/dual-boot-6.webp)

## වෙනත් ස්ථාපනයන් Bootloader එකට එක් කිරීම

ඔබ ඔබේ Omarchy ස්ථාපනය අවසන් කළ විට, දැන් පෙරනිමි bootloader එක Limine බව ඔබට පෙනෙනු ඇත. මෙය සමඟ, Windows වැනි ඔබේ වෙනත් ස්ථාපනයන් සඳහාද Limine වෙත විකල්ප එක් කළ හැකිය.

වෙනත් මෙහෙයුම් පද්ධති එක් කිරීමට, `limine-scan` ධාවනය කර, ඔබට අවශ්‍ය ප්‍රවේශයන් ඔබේ Limine config එකට එක් කිරීමට උපදෙස් අනුගමනය කරන්න. Boot menu එක පෙරනිමියෙන් සැඟවී පවතින අතර තත්පර එකකට පසු Omarchy ආරම්භ වේ. Windows හෝ වෙනත් ප්‍රවේශයක් තේරීමට, Limine ආරම්භ වූ වහාම ඕනෑම key එකක් ඔබන්න; menu එක දිස් වූ විට, ප්‍රවේශයක් තේරීමට arrow keys භාවිතා කර Enter ඔබන්න. ඔබ key එකක් ඔබන්නට පෙර Omarchy ආරම්භ වුවහොත්, restart කර නැවත උත්සාහ කරන්න.

## Bitlocker

මෙම ස්ථාපන ක්‍රමය Bitlocker සමඟ නොගැලපෙන බව සැලකීම වැදගත්ය, මන්ද එය සංකේතනය කරන්නේ partition එක පමණක් නොව, සම්පූර්ණ drive එකමය. Bitlocker සක්‍රිය කර ඇති බව සඳහන් දෝෂයක් ඔබට හමු වුවහොත්, Windows වෙත boot කර, **Settings -> Privacy & Security -> Device encryption** වෙත ගොස් Bitlocker අක්‍රිය කරන්න. Drive එක විසංකේතනය කිරීමට යම් කාලයක් ගත විය හැකිය.

 ![dual-boot-7](images/dual-boot-7.webp)

## Windows නැවත ස්ථාපනය කිරීම

මෙම පරිගණකය Windows සමඟ ආවේ නම්, එහි product key එක firmware එකේ ගබඩා කර ඇත. එය මුද්‍රණය කිරීමට `omarchy windows key` ධාවනය කරන්න, එවිට ඔබ කවදා හෝ මෙම යන්ත්‍රයේ Windows නැවත ස්ථාපනය කළහොත් එය නැවත activate කළ හැකිය.
