# ද්විත්ව ආරම්භක ස්ථාපනය

ඔබට Windows හෝ වෙනත් ස්ථාපනයන් සමඟින් තනි කොටසක් මත Omarchy ස්ථාපනය කළ හැකිය.

මෙම ස්ථාපන ක්‍රමය සමඟ තවමත් පෙරනිමියෙන්ම කොටස සඳහා LUKS සංකේතනය ලැබෙන නිසා, එය සම්පූර්ණ ධාවකයම භාවිතා කරන ස්ථාපනයට වඩා ඵලදායී ලෙස වෙනස් නොවන අතර, හුදෙක් තැටියේ නිදහස් ඉඩක් තිබීම පමණක් අවශ්‍ය වේ.

## Windows මත ඉඩ සකස් කිරීම

Windows සමඟ ස්ථාපනය කිරීමට, start menu එකේ `disk management` යැයි ටයිප් කර **Create and format hard disk partitions** සඳහා ඇති විකල්පය තෝරන්න.

 ![dual-boot-1](images/dual-boot-1.webp)

සුදුසු කොටස සොයාගෙන, දකුණු-ක්ලික් කර, **Shrink Volume** තෝරන්න.

![dual-boot-2](images/dual-boot-2.webp)

 ඔබ හැකිළීමට කැමති ප්‍රමාණය ඇතුළත් කරන්න. මෙය boot කොටසත් ඇතුළත්ව ඔබේ අනාගත Omarchy ස්ථාපනයේ ප්‍රමාණය වන බව සලකන්න.

 ![dual-boot-3](images/dual-boot-3.webp)

ඔබ අවසන් කළ පසු, මෙම උදාහරණයේ අපි Omarchy ස්ථාපනය කරන 50GB කොටස ඇති තැන මෙවැනි දෙයක් ඔබට දැකිය යුතුය.

 ![dual-boot-4](images/dual-boot-4.webp)

## Omarchy ස්ථාපනය කිරීම

Omarchy ස්ථාපන ක්‍රියාවලිය ඵලදායී ලෙස සාමාන්‍ය ක්‍රියාවලියම වේ. ඔබ ඔබේ තැටිය තේරූ පසු, ඔබට **Free space install** විකල්පය ලැබෙනු ඇත. සම්පූර්ණ තැටියම මැකී යාම වැළැක්වීමට එම විකල්පය තෝරන්න.

 ![dual-boot-5](images/dual-boot-5.webp)

සියල්ල හොඳින් පෙනෙන බව තහවුරු කර, සාමාන්‍ය පරිදි ස්ථාපනය අවසන් වන තෙක් රැඳී සිටින්න. සම්පූර්ණ ධාවක ස්ථාපනයකදී මෙන්ම, සංකේතනය නොකළ ස්ථාපනයක් තෝරා ගැනීමට (නිර්දේශ නොකෙරේ) ඔබට හැකි වන්නේද මෙහිදීය.
 ![dual-boot-6](images/dual-boot-6.webp)

## වෙනත් ස්ථාපනයන් Bootloader එකට එක් කිරීම

ඔබේ Omarchy ස්ථාපනය අවසන් කළ විට, Limine bootloader එක දැන් පෙරනිමිය බව ඔබට පෙනෙනු ඇත. මෙය සමඟ, Windows වැනි ඔබේ වෙනත් ස්ථාපනයන් සඳහා විකල්ප Limine වෙත එක් කළ හැකිය.

වෙනත් මෙහෙයුම් පද්ධති එක් කිරීමට, `limine-scan` ධාවනය කර, ඔබට අවශ්‍ය ඇතුළත් කිරීම් ඔබේ Limine config එකට එක් කිරීමට උපදෙස් අනුගමනය කරන්න. boot මෙනුව පෙරනිමියෙන් සැඟවී පවතින අතර තත්පරයකට පසු Omarchy ආරම්භ වේ. Windows හෝ වෙනත් ඇතුළත් කිරීමක් තේරීමට, Limine ආරම්භ වූ වහාම ඕනෑම යතුරක් ඔබන්න; මෙනුව දිස් වූ විට, ඇතුළත් කිරීමක් තේරීමට arrow යතුරු භාවිතා කර Enter ඔබන්න. ඔබ යතුරක් ඔබන්නට පෙර Omarchy ආරම්භ වුවහොත්, නැවත ආරම්භ කර යළි උත්සාහ කරන්න.

## Bitlocker

මෙම ස්ථාපන ක්‍රමය Bitlocker සමඟ අනුකූල නොවන බව සැලකිල්ලට ගැනීම වැදගත්ය, මන්ද එය සංකේතනය කරන්නේ කොටස පමණක් නොව සම්පූර්ණ ධාවකයමය. Bitlocker සක්‍රිය කර ඇති බව සඳහන් දෝෂයක් ඔබට හමු වුවහොත්, Windows වෙත boot කර, **Settings -> Privacy & Security -> Device encryption** වෙත ගොස් Bitlocker අක්‍රිය කරන්න. ධාවකය විසංකේතනය කිරීමට යම් කාලයක් ගත විය හැකිය.
