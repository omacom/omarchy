# ඒකාබද්ධ පසුරු පුවරුව සහ ඉතිහාසය

සාමාන්‍යයෙන් Linux වල, ටර්මිනලය තුළ පිටපත් කර ඇලවීමට `Ctrl + Shift + C/V` ද, අනෙක් සෑම තැනකදීම එය කිරීමට `Ctrl + C/V` ද අවශ්‍ය වේ. Linux වලම ඉපදී හැදී වැඩුණු කෙනෙකු නොවන ඕනෑම කෙනෙකුට එයට හුරු වීම අමාරුයි! Mac එකෙන් එන කෙනෙකුට super සිට ctrl වෙත මාරු වීමත් එසේමයි.

Omarchy මෙම ගැටලු දෙකම (සෑම තැනකම පාහේ) ක්‍රියා කරන ඒකාබද්ධ පසුරු පුවරු කෙටියතුරු සමඟින් විසඳයි. ඒවා නම්:

| කෙටියතුර | විධානය |
| ------- | ----------- |
| Super + A | සියල්ල තෝරන්න |
| Super + C | පිටපත් කරන්න |
| Super + X | කපන්න |
| Super + V | අලවන්න |
| Super + Ctrl + V | පසුරු පුවරු ඉතිහාසය |

_බොහෝ agent harness රූප ඇලවීමට `Ctrl + V` භාවිතා කරන නමුත්, පෙළ ඇලවීමට `Super + V` භාවිතා කරන බව සලකන්න._

අවධානය යොමු වූ පෙළ ක්ෂේත්‍රයක හෝ `Ctrl + A` සඳහා සහය දක්වන වෙනත් යෙදුමක ඇති සියල්ල පිටපත් කිරීමට `Super + A`, ඉන්පසු `Super + C` භාවිතා කරන්න. ටර්මිනලයක, `Ctrl + A` එහි පෙළ තේරීම වෙනුවට විධාන රේඛාවේ ආරම්භයට යයි.

### පසුරු පුවරු ඉතිහාසය

පසුරු පුවරු ඉතිහාසය Omarchy shell එක මඟින් සපයන අතර එය පෙළ සහ රූප යන දෙකටම ක්‍රියා කරයි. `Super + Ctrl + V` මඟින් ඔබ එය ක්‍රියාත්මක කර return යතුරෙන් ඔබේ ඇතුළත් කිරීම තෝරන්න, එවිට එය ඔබ සිටි යෙදුම තුළට කෙළින්ම අලවනු ලැබේ. එය පසුරු පුවරුවට පමණක් පිටපත් කිරීමට `Shift + Return` ද, එය විවෘත කිරීමට `Alt + Return` ද, එය ඉතිහාසයෙන් ඉවත් කිරීමට `Delete` ද, මුළු ඉතිහාසයම හිස් කිරීමට `Shift + Delete` ද භාවිතා කරන්න.
