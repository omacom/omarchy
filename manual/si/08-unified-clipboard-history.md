# ඒකාබද්ධ ක්ලිප්බෝඩය සහ ඉතිහාසය

සාමාන්‍යයෙන් Linux හි, ටර්මිනලයේ පිටපත් කර ඇලවීමට ඔබට `Ctrl + Shift + C/V` අවශ්‍ය වන අතර අනෙක් සෑම තැනකම එය කිරීමට `Ctrl + C/V` අවශ්‍ය වේ. Linux මත උපත ලබා හැදී වැඩී නැති ඕනෑම කෙනෙකුට එයට හුරුවීම අපහසුයි! ඔබ Mac එකෙන් එන්නේ නම් super සිට ctrl දක්වා මාරුවීම ද එසේමයි.

Omarchy ගැටලු දෙකම (පාහේ) සෑම තැනකම වැඩ කරන ඒකාබද්ධ ක්ලිප්බෝඩ් උණුසුම් යතුරු සමඟ විසඳයි. ඒවා නම්:

| උණුසුම් යතුර | විධානය |
| ------- | ----------- |
| Super + C | පිටපත් කරන්න |
| Super + X | කපන්න |
| Super + V | අලවන්න |
| Super + Ctrl + V | ක්ලිප්බෝඩ් ඉතිහාසය |

_බොහෝ නියෝජිත පද්ධති රූප ඇලවීම සඳහා `Ctrl + V` භාවිත කරන නමුත්, පෙළ ඇලවීම සඳහා `Super + V` භාවිත කරන බව සලකන්න._

### ක්ලිප්බෝඩ් ඉතිහාසය

ක්ලිප්බෝඩ් ඉතිහාසය Omarchy shell එක මගින් සපයනු ලබන අතර පෙළ සහ රූප දෙකම සඳහා වැඩ කරයි. ඔබ එය `Super + Ctrl + V` මගින් ප්‍රේරණය කරයි, return සමඟ ඔබේ ප්‍රවේශය තෝරයි, ඉන්පසු එය `Super + V` හි ඇලවීමට සූදානම් ක්ලිප්බෝඩය මත තබනු ලැබේ.
