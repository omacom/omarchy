# වෙබ් යෙදුම්

Omarchy මෙනුවේ (`Super + Space`) _Install > Web App_ භාවිතයෙන් ඔබට ඔබේම වෙබ් යෙදුම් එක් කළ හැකිය. එයට favicon හරහා එය ලබා ගත නොහැකි නම්, එය ඔබෙන් යෙදුමේ නම, යෙදුමේ URL එක සහ අයිකනයේ URL එක ඉල්ලනු ඇත. බොහෝ ජනප්‍රිය වෙබ් යෙදුම් සඳහා විශිෂ්ට PNG අයිකන ඔබට [Dashboard Icons](https://dashboardicons.com) වෙතින් ලබා ගත හැකිය.

ඉන්පසු ඒවාට යෙදුම් දියත් කරන්නා (`Super + Space`) හරහා පිවිසිය හැකි අතර, ඒවා අලංකාර රාමුවක් රහිත වෙබ්-යෙදුම් කවුළුව භාවිත කරනු ඇත.

ඔබට වෙබ් යෙදුමක් ඉවත් කිරීමට අවශ්‍ය නම්, Omarchy මෙනුවේ _Remove > Web App_ වෙත යන්න.

වෙබ් යෙදුම් කෙටිමං භාවිත කිරීමට පෙර සාමාන්‍ය බ්‍රවුසරයක් භාවිතයෙන් ඔබේ සියලුම ගිණුම්වලට පුරනය වීම වඩාත් හොඳය. තුනී wrapper රාමුව 1password සමඟ හොඳින් ක්‍රියා නොකරන බැවින්, කලින් සෘජුවම පුරනය වී තිබීම වඩා පහසුය.

මෙම වෙබ් යෙදුම් සඳහා වන සියලුම යතුරුපුවරු hotkeys `~/.config/hypr/bindings.lua` තුළ වෙනස් කළ හැකිය.

ඔබ වෙබ් යෙදුමක් තුළ සිටින විට, `Shift + Alt + L` භාවිතයෙන් වත්මන් URL එක පිටපත් පුවරුවට පිටපත් කළ හැකිය.

පෙරනිමියෙන්, Omarchy දැනටමත් පෙරනිමි යෙදුම් එකතුවක් සමඟ පැමිණේ:

## HEY

ඔබට `Super + Shift + E` භාවිතයෙන් HEY Email ආරම්භ කිරීමට, `Super + Shift + Alt + E` භාවිතයෙන් සෘජුවම නව විද්‍යුත් තැපෑලක් ලිවීමට යාමට සහ `Super + Shift + C` භාවිතයෙන් HEY Calendar ආරම්භ කිරීමට හැකිය.

## Basecamp

[Basecamp](https://basecamp.com/) යනු කුඩා කණ්ඩායම්වලට වේගයෙන් ගමන් කිරීමට සහ වැඩි ප්‍රගතියක් ලබා ගැනීමට උපකාර කරන ව්‍යාපෘති කළමනාකරණ සේවාවකි. Trello, Slack, Asana, Notion හෝ වෙනත් ඕනෑම දෙයක නොගැලපෙන මිශ්‍රණයක් එකට අලවනවා වෙනුවට, Basecamp සමඟ සියල්ල එකම තැනක ලබා ගත හැකිය. එය නිර්මාණය කර ඇත්තේ Omarchy ආරම්භ වූ [37signals](https://37signals.com/) විසිනි.

## Google යෙදුම්

## Microsoft යෙදුම්

Outlook, Word, Excel, PowerPoint, Teams සහ OneDrive වෙබ් යෙදුම් ලෙස එක් කිරීමට _Install > Service > Microsoft_ තෝරන්න. සෑම යෙදුමකටම තමන්ගේම දියත් කරන්නෙකු ඇති අතර, වාණිජ Microsoft 365 URLs සහ ඔබේ පවතින බ්‍රවුසර් පැතිකඩ භාවිත කරමින් එය සෘජුවම විවෘත වේ. ඒවා Omarchy හි අනෙකුත් වෙබ් යෙදුම් මෙන්ම එකම බ්‍රවුසර් යෙදුම් කවුළුවල විවෘත වේ; ඒවා වෙනම Teams for Linux සේවාදායකයා ස්ථාපනය නොකරයි.

කට්ටලය _Remove > Services > Microsoft_ සමඟ ඉවත් කරන්න, නැතහොත් තනි යෙදුම් _Remove > Web App_ සමඟ ඉවත් කරන්න. ඔබට අවශ්‍ය යෙදුම් පමණක් _Install > Web App_ හරහා ස්ථාපනය ද කළ හැකිය.

රජයේ හෝ ස්වෛරී cloud එකක් සඳහා, ඔබේ සංවිධානය විසින් සපයන ලද URL එක භාවිත කරමින්, `~/.local/share/applications/` යටතේ ඇති අදාළ දියත් කරන්නාගේ, උදාහරණයක් ලෙස `Microsoft Teams.desktop` හි, `Exec=` පේළියේ ඇති URL එක සංස්කරණය කරන්න. එම පේළියේ ඇති ඕනෑම සෘජු `%` අක්ෂරයක් `%%` ලෙස ලියන්න. වෙනස්කම් ඊළඟ දියත් කිරීමේදී අදාළ වේ. කට්ටල ස්ථාපකය නැවත ධාවනය කිරීම එහි දියත් කරන්නන් පෙරනිමි URLs සමඟ ප්‍රතිස්ථාපනය කරයි.

වැඩ සඳහා වන පුරනය වීම් වෙන්ව තබා ගැනීමට, සෑම දියත් කරන්නෙකුගේම `Exec=` පේළියට බ්‍රවුසර් දත්ත නාමාවලියක් එකතු කරන්න:

```ini
Exec=omarchy-launch-webapp "https://teams.cloud.microsoft/" --user-data-dir=/absolute/path/to/work-browser-profile
```

උදාහරණ නාමාවලිය ඔබ කැමති නිරපේක්ෂ මාර්ගයකින් ප්‍රතිස්ථාපනය කර, වැඩ සඳහා වන පුරනය වීම් ඒවා අතර බෙදා ගැනීමට දියත් කරන්නන් හයම සඳහා එකම මාර්ගය භාවිත කරන්න. වෙබ් යෙදුම් Omarchy විසින් තෝරාගත්, සහාය දක්වන බ්‍රවුසරය භාවිත කරන අතර, පෙරනිමි බ්‍රවුසරයට සහාය නොදක්වන විට Chrome වෙත ආපසු වැටේ.
