# සංවර්ධන මෙවලම්

## විකල්ප සංස්කාරක

නව ස්ථාපනවලදී Omarchy පෙරනිමි සංස්කාරකය ලෙස Plain සමඟ එන අතර [Neovim](https://neovim.io/) ද පෙර ස්ථාපනය කර ඇත, නමුත් ඔබට තරමක් වඩා ප්‍රධාන ධාරාවේ සහ හුරුපුරුදු දෙයක් අවශ්‍ය නම්, ඔබට Omarchy Menu (`Super + Space`) ධාවනය කර _ස්ථාපනය > සංස්කාරකය_ යටතේ ඇති විකල්ප දැකිය හැකිය. එහි VSCode, Cursor, Zed, Sublime Text, Helix, Vim සහ Emacs අපි ලැයිස්තුගත කර ඇත්තෙමු. ඔබ සොයන දේ ඔබට එහි නොලැබුණහොත්, _ස්ථාපනය > පැකේජය_ පරීක්ෂා කර බලන්න, එය Arch පැකේජයක නැති දැයි බලන්න (නැති නම්, AUR පරීක්ෂා කිරීමට _ස්ථාපනය > AUR_ උත්සාහ කරන්න).

මුල් `vi` සංස්කාරකය ද පෙට්ටියෙන් එළියට එන විටම ලබා ගත හැකිය. ටර්මිනලයේ ගොනුවක් සංස්කරණය කිරීමට `vi filename` ධාවනය කරන්න.

`VSCode`, `Cursor`, `VSCodium` සහ `Helix` සඳහා තේමා ගැලපීම ලබා දෙයි.

පද්ධති-ව්‍යාප්ත පෙරනිමි සංස්කාරකය ඔබට `Setup > Defaults > Editor` යටතේ සැකසිය හැකිය.

## පරිසරය

Omarchy Menu (`Super + Space`) හි _ස්ථාපනය > සංවර්ධනය_ කොටස හරහා සංවර්ධන පරිසරයන් රාශියක්ම සැකසීමට Omarchy සහාය දක්වයි. ඔබට ඇත්ත වශයෙන්ම _Ruby on Rails_ සොයාගත හැකි වනු ඇත, නමුත් JavaScript සඳහා වන ප්‍රධාන ධාවන කාල තුනම (Node.js, Bun, Deno) මෙන්ම Laravel සහ Symfony වැනි ජනප්‍රිය PHP රාමු ද ලැබෙනු ඇත. අහෝ, Go, Rust, Python, Java, Elixir (Phoenix සමඟ), .NET, OCaml, Zig, Clojure සහ Scala ද ඇත. එය ඉතා පුළුල් තේරීමකි!

මෙම පරිසරයන්ගෙන් බහුතරයක් කළමනාකරණය කරනු ලබන්නේ [Mise](https://mise.jdx.dev/) විසිනි. එය එකම යන්ත්‍රයේ වැඩසටහන් භාෂාවක බහු අනුවාද ස්ථාපනය කර ධාවනය කිරීමට ඔබට ඉඩ දෙන මෙවලමකි. එය Ruby සඳහා rbenv හෝ rvm මෙන් හෝ Python සඳහා virtualenv මෙන් වුවද, එය විවිධ පරිසරයන් රාශියක් සඳහා ක්‍රියා කරයි.

උදාහරණයක් ලෙස Ruby ස්ථාපනය කිරීමට, ඔබ `mise use -g ruby` ධාවනය කරනු ඇත, එය Ruby ස්ථාපනය කරන අතරම එය ගෝලීය පෙරනිමිය ලෙස ද සකසනු ඇත. නැතහොත්, ඔබේ ව්‍යාපෘතියේ .ruby-version ගොනුවක් තිබේ නම්, එම ව්‍යාපෘතියේ මූලයේ `mise i` ධාවනය කළ හැකිය.

## පෙර ස්ථාපනය කර ඇති CLI මෙවලම්

`uv`, Node.js සහ `playwright-cli` (ස්ථාපනය කර ඇති Chrome භාවිතා කරමින්, ඒජන්තයන්ට බ්‍රවුසරයක් ධාවනය කිරීමට) පැකේජ ලෙස ස්ථාපනය කර ඇති අතර, `omarchy update` මඟින් ඒවා පද්ධතියේ ඉතිරි කොටස සමඟම යාවත්කාලීනව තබයි. `ghui`, [Hunk](https://github.com/modem-dev/hunk) සහ Basecamp, Cloudflare සහ HEY CLI _ස්ථාපනය > CLI_ යටතේ තේරීමේ දුරින් ඇති අතර, [coding agents](17-ai.md) _ස්ථාපනය > AI > CLI_ යටතේ ඇත.

mise කළමනාකරණය කරන්නේ ඔබ _ස්ථාපනය > සංවර්ධනය_ වෙතින් සකසන ධාවන කාල පමණි; Omarchy තනිවම එය හරහා කිසිවක් ස්ථාපනය නොකරයි. ඒවා Omarchy හි ඉතිරි කොටස සමඟ යාවත්කාලීන කිරීමට `omarchy update` ධාවනය කරන්න; `mup` අනුනාමය යාවත්කාලීන කරන්නේ mise විසින් කළමනාකරණය කරන මෙවලම් පමණි. ඔබේම වින්‍යාසයට තවත් මෙවලමක් එක් කිරීමට, `mise use -g <tool>` භාවිතා කරන්න.

## Docker

[Docker](https://www.docker.com/) සඳහා හැඳින්වීමක් අවශ්‍යම නැති තරම්ය. එය හුදකලා බහාලුම් ධාවනය කිරීමට ඔබට ඉඩ දෙන අතර, Docker ම සහ [Docker Compose](https://docs.docker.com/compose/) ඇතුළුව එය හොඳින් ධාවනය කිරීමට අවශ්‍ය සියල්ල Omarchy ස්ථාපනය කරයි.

පෙරනිමියෙන් ඔබේ පරිශීලකයා `docker` කණ්ඩායමේ *නොවේ*. එම කණ්ඩායම සැබවින්ම මුරපද රහිත root වේ — එහි ඇති ඕනෑම දෙයකට `docker run -v /:/host` කර යන්ත්‍රය අත්පත් කර ගත හැකිය — එබැවින් ඔබ ලෙස ධාවනය වන තනි අසත්කාර ස්ක්‍රිප්ට් එකක් හෝ පරායත්තතාවක් වෙනත් ආකාරයකින් root වෙතින් එක් විධානයක් එපිටින් සිටිනු ඇත. එබැවින් විධාන රේඛාවේ ඔබ Docker ධාවනය කරන්නේ `sudo` සමඟිනි (`sudo docker ps`, `sudo docker compose up`), සහ ඩීමනය සමඟ කතා කරන චිත්‍රක මෙවලම් — Windows VM එක — ඒවාට අවශ්‍ය වූ විට ඔබෙන් අවසරය ඉල්ලයි. ඔබට කණ්ඩායම් රහිත සැකසුමේ පහසුව නැවත අවශ්‍ය නම් සහ හුවමාරුව තේරුම් ගන්නේ නම්, **සැකසුම > ආරක්ෂාව > Sudoless Docker** වෙතින් එය සබල කරන්න (හෝ `omarchy-setup-security-sudoless-docker` ධාවනය කරන්න), එය අනතුරු ඇඟවීමකින් පසුව ඔබව `docker` කණ්ඩායමට එක් කරයි; එවිට සරල `docker` සහ `d` අනුනාමය `sudo` නොමැතිව නැවත ක්‍රියා කරයි.

Omarchy මෙනුවේ _ස්ථාපනය > සංවර්ධනය > Docker DB_ භාවිතා කරමින් දේශීය සංවර්ධනය සඳහා පොදු දත්ත සමුදායන් Docker තුළ ඔබට සැකසිය හැකිය.

## GitHub CLI

[GitHub CLI](https://cli.github.com/) යනු `gh` වන අතර, ටර්මිනලයෙන් ගබඩාවන්, ගැටලු සහ අදින්න ඉල්ලීම් සමඟ වැඩ කිරීමටය. _සැකසුම > Git_ මඟින් ඔබ එහි GitHub වෙත පුරනය වීමට තෝරා ගන්නා විට එය ස්ථාපනය කරයි, පසුව `gh repo clone org/repo` මඟින් ගබඩාවක් ක්ලෝන කරයි. එහි විධාන ගවේෂණය කිරීමට `gh --help` ධාවනය කරන්න.

_ස්ථාපනය > CLI > GitHub_ මඟින් GitHub CLI, `gh`, සමඟ අදින්න ඉල්ලීම් සඳහා ටර්මිනල් අතුරුමුහුණතක් වන `ghui` ද ස්ථාපනය කරයි. Git සමඟම වැඩ කිරීමට [Lazygit](https://github.com/jesseduffield/lazygit) පෙර ස්ථාපනය කර ඇත.
