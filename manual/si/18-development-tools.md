# සංවර්ධන මෙවලම්

## විකල්ප සංස්කාරකයන්

Omarchy පෙරනිමියෙන් [Neovim](https://neovim.io/) සමඟ පැමිණේ, නමුත් ඔබට ඊට වඩා ටිකක් ප්‍රධාන ධාරාවේ සහ හුරුපුරුදු දෙයක් අවශ්‍ය නම්, ඔබට Omarchy මෙනුව (`Super + Space`) ක්‍රියාත්මක කර _ස්ථාපනය > සංස්කාරකය_ යටතේ ඇති විකල්ප දැකගත හැක. එහි VSCode, Cursor, Zed, Sublime Text, Helix, Vim, සහ Emacs අප ලැයිස්තුගත කර ඇත. ඔබ සොයන්නේ එය නොමැති නම්, _ස්ථාපනය > පැකේජය_ පරීක්ෂා කර, එය Arch පැකේජයක නොමැතිදැයි බලන්න (එසේ නොවේ නම්, AUR එක පරීක්ෂා කිරීමට _ස්ථාපනය > AUR_ උත්සාහ කරන්න).

මුල් `vi` සංස්කාරකයද පිටතින්ම ලබාගත හැක. ටර්මිනලයේ ගොනුවක් සංස්කරණය කිරීමට `vi filename` ක්‍රියාත්මක කරන්න.

`VSCode`, `Cursor`, `VSCodium`, සහ `Helix` සඳහා තේමාව ගැලපීම ලබාදේ.

ඔබට පද්ධති මට්ටමේ පෙරනිමි සංස්කාරකය `සැකසුම > පෙරනිමි > සංස්කාරකය` යටතේ සැකසිය හැක.

## පරිසරය

Omarchy මෙනුවේ (`Super + Space`) _ස්ථාපනය > සංවර්ධනය_ අංශය හරහා සංවර්ධන පරිසර රැසක් සැකසීමට Omarchy සහාය දක්වයි. ඇත්ත වශයෙන්ම ඔබට _Ruby on Rails_ හමුවනු ඇත, එසේම JavaScript සඳහා ප්‍රධාන ධාවන කාලයන් තුනම (Node.js, Bun, Deno), සහ Laravel සහ Symfony වැනි ජනප්‍රිය PHP රාමුද හමුවනු ඇත. ඔව්, තව Go, Rust, Python, Java, Elixir (Phoenix සමඟ), .NET, OCaml, Zig, Clojure, සහ Scala ද ඇත. එය ඉතා පුළුල් තේරීමකි!

මෙම පරිසරයන්ගෙන් බහුතරය [Mise](https://mise.jdx.dev/) විසින් කළමනාකරණය කරනු ලැබේ. එය එකම යන්ත්‍රයේ ක්‍රමලේඛන භාෂාවක අනුවාද කිහිපයක් ස්ථාපනය කිරීමට සහ ක්‍රියාත්මක කිරීමට ඉඩ සලසන මෙවලමකි. එය Ruby සඳහා rbenv හෝ rvm හෝ Python සඳහා virtualenv වැනිය, නමුත් එය විවිධ පරිසර රැසක් සඳහා ක්‍රියා කරයි.

උදාහරණයක් ලෙස Ruby ස්ථාපනය කිරීමට, ඔබ `mise use -g ruby` ක්‍රියාත්මක කළ යුතු අතර, එය Ruby ස්ථාපනය කර ගෝලීය පෙරනිමිය ලෙසද සැකසනු ඇත. නැතහොත්, ඔබේ ව්‍යාපෘතියේ .ruby-version ගොනුවක් තිබේ නම්, එම ව්‍යාපෘතියේ මූලයේ `mise i` ක්‍රියාත්මක කළ හැක.

## Docker

[Docker](https://www.docker.com/) සඳහා හැඳින්වීමක් අවශ්‍ය නැති තරම්ය. එය හුදකලා බහාලුම් ක්‍රියාත්මක කිරීමට ඉඩ සලසන අතර, Omarchy විසින් Docker එකම සහ [Docker Compose](https://docs.docker.com/compose/) ඇතුළු එය හොඳින් ක්‍රියාත්මක කිරීමට අවශ්‍ය සියල්ල ස්ථාපනය කරයි.

පෙරනිමියෙන් ඔබේ පරිශීලකයා `docker` කණ්ඩායමේ *නොමැත*. එම කණ්ඩායම ඇත්ත වශයෙන්ම මුරපද නොමැති root ය — එහි ඇති ඕනෑම දෙයකට `docker run -v /:/host` කර යන්ත්‍රය අත්පත් කරගත හැක — එබැවින් ඔබ ලෙස ක්‍රියාත්මක වන තනි අනිෂ්ට ස්ක්‍රිප්ට් එකක් හෝ පරායත්තතාවයක් root වෙත එක් විධානයක් දුරින් පවතිනු ඇත. එබැවින් විධාන රේඛාවේ ඔබ Docker එක `sudo` සමඟ ක්‍රියාත්මක කරයි (`sudo docker ps`, `sudo docker compose up`), සහ ඩීමනය සමඟ කතා කරන චිත්‍රක මෙවලම් — Windows VM එක — අවශ්‍ය වූ විට අවසරය ඉල්ලයි. ඔබට කණ්ඩායම් නොමැති සැකසුමක පහසුව නැවත අවශ්‍ය නම් සහ සම්මුතිය තේරුම් ගන්නේ නම්, **සැකසුම > ආරක්ෂාව > Sudoless Docker** වෙතින් එය සක්‍රීය කරන්න (හෝ `omarchy-setup-security-sudoless-docker` ක්‍රියාත්මක කරන්න), එය අනතුරු ඇඟවීමකින් පසු ඔබව `docker` කණ්ඩායමට එක් කරයි; ඉන්පසු සරල `docker` සහ `d` අනුනාමය නැවත `sudo` නොමැතිව ක්‍රියා කරයි.

Omarchy මෙනුවේ _ස්ථාපනය > සංවර්ධනය > Docker DB_ භාවිතයෙන් දේශීය සංවර්ධනය සඳහා පොදු දත්ත සමුදායන් Docker හි සැකසිය හැක.

## GitHub CLI

[GitHub CLI](https://cli.github.com/) මඟින් ඔබට ඔබේ GitHub ගිණුම සමඟ සත්‍යාපනය කිරීමට සහ එය භාවිතයෙන් පෞද්ගලික ගබඩාවන් ක්ලෝන කිරීමට ඉඩ සලසයි. එය lazy-loading mise ස්ටබ් එකක් ලෙස සම්බන්ධ කර ඇති බැවින්, ඔබ පළමු වරට `gh` ක්‍රියාත්මක කරන විට, එය තනිවම ස්ථාපනය වේ. සත්‍යාපනය කිරීමට, `gh auth login` ක්‍රියාත්මක කරන්න. ඉන්පසු ඔබට `gh repo clone org/repo` භාවිතයෙන් පෞද්ගලික ගබඩාවන් පරීක්ෂා කළ හැක.

මෙම විධානය භාවිතයෙන් ඔබට වෙනත් GitHub ක්‍රියාකාරකම් රැසක්ද සිදු කළ හැක. කළ හැකි සියල්ල බැලීමට `gh` ක්‍රියාත්මක කරන්න.

TUI එකක ඔබේ pull requests කළමනාකරණය කිරීම සඳහා `ghui` සඳහා lazy-installing ස්ටබ් එකක්ද ඇත. ඔබට git එකම TUI එකකින්ද ධාවනය කිරීමට අවශ්‍ය නම්, [lazygit](https://github.com/jesseduffield/lazygit) පෙර ස්ථාපනය කර ඇත.
