# සංවර්ධන මෙවලම්

## විකල්ප සංස්කාරක

නව ස්ථාපනයන්හි පෙරනිමි සංස්කාරකය ලෙස Plain සමඟ Omarchy එන අතර [Neovim](https://neovim.io/) පූර්ව ස්ථාපනය කර ඇත, නමුත් ඔබට තරමක් වඩා ප්‍රධාන ධාරාවේ සහ හුරුපුරුදු දෙයක් අවශ්‍ය නම්, ඔබට Omarchy Menu එක (`Super + Space`) ධාවනය කර _Install > Editor_ යටතේ ඇති විකල්ප දැකිය හැකිය. එහි VSCode, Cursor, Zed, Sublime Text, Helix, Vim, සහ Emacs ලැයිස්තුගත කර ඇත. ඔබ සොයන දේ ඔබට හමු නොවන්නේ නම්, _Install > Package_ වෙත ගොස්, එය Arch පැකේජයක නැත්දැයි බලන්න (නැත්නම්, AUR එක පරීක්ෂා කිරීමට _Install > AUR_ උත්සාහ කරන්න).

මුල් `vi` සංස්කාරකය ද මුල සිටම ලබා ගත හැකිය. ටර්මිනලයේ ගොනුවක් සංස්කරණය කිරීමට `vi filename` ධාවනය කරන්න.

තේමා ගැළපීම `VSCode`, `Cursor`, `VSCodium`, සහ `Helix` සඳහා පිරිනැමේ.

ඔබට `Setup > Defaults > Editor` යටතේ පද්ධතිය පුරා පෙරනිමි සංස්කාරකය සැකසිය හැකිය.

## පරිසරය

Omarchy Menu එකේ (`Super + Space`) _Install > Development_ කොටස හරහා සංවර්ධන පරිසරයන් මුළු රාශියක්ම පිහිටුවීමට Omarchy සහාය දක්වයි. ඇත්ත වශයෙන්ම ඔබට එහි _Ruby on Rails_ හමු වේ, නමුත් JavaScript සඳහා ප්‍රධාන ධාවන කාල තුනම (Node.js, Bun, Deno) ද, Laravel සහ Symfony වැනි ජනප්‍රිය PHP රාමු ද ඇත. ඕ, තවද Go, Rust, Python, Java, Elixir (Phoenix සමඟ), .NET, OCaml, Zig, Clojure, සහ Scala ද ඇත. එය ඉතා පුළුල් තේරීමකි!

මෙම පරිසරයන්ගෙන් බහුතරයක් කළමනාකරණය කරනු ලබන්නේ [Mise](https://mise.jdx.dev/) විසිනි. එය එකම යන්ත්‍රයක ක්‍රමලේඛන භාෂාවක බහු අනුවාද ස්ථාපනය කිරීමට සහ ධාවනය කිරීමට ඔබට ඉඩ දෙන මෙවලමකි. එය Ruby සඳහා rbenv හෝ rvm හෝ Python සඳහා virtualenv වැනිය, නමුත් එය විවිධ පරිසරයන් රාශියක් සඳහා ක්‍රියා කරයි.

උදාහරණයක් ලෙස Ruby ස්ථාපනය කිරීමට, ඔබ `mise use -g ruby` ධාවනය කරනු ඇත, එය Ruby ස්ථාපනය කරන අතරම එය ගෝලීය පෙරනිමිය ලෙසද සකසයි. නැතහොත්, ඔබේ ව්‍යාපෘතියේ .ruby-version ගොනුවක් තිබේ නම්, එම ව්‍යාපෘතියේ මූලයේ `mise i` ධාවනය කිරීම පමණක් ප්‍රමාණවත්ය.

## පූර්ව ස්ථාපිත CLI මෙවලම්

Omarchy විසින් `gh`, `uv` වැනි මෙවලම් සහ බොහෝ [කේතීකරණ නියෝජිතයින්](17-ai.md) [mise හි lazy ස්ථාපනය](https://mise.jdx.dev/dev-tools/shims.html#lazy-tools) හරහා ලබා ගත හැකි කරයි. ඔබ පළමු වරට එකක් ධාවනය කරන විට, mise එය ස්ථාපනය කරයි. කේතීකරණ නියෝජිතයින් පසුව ධාවනය වීමට පෙර, උපරිම වශයෙන් සෑම පැය හතරකට වරක්, යාවත්කාලීනයක් සඳහා පරීක්ෂා කරයි; `gh` සහ `uv` වැනි අනෙකුත් මෙවලම්, ඔබ යාවත්කාලීන කරන තුරු ස්ථාපිත අනුවාදය නැවත භාවිතා කරයි.

ඔබට පෙරනිමි පරීක්ෂා කිරීමට හෝ ඒවා කල්තියා ස්ථාපනය කිරීමටද හැකිය:

```bash
mise ls --current              # List the tools configured for this directory
mise install gh               # Install one tool now
mise install --include-lazy    # Install all configured tools, including lazy tools
```

Omarchy හි ඉතිරිය සමඟ ස්ථාපිත මෙවලම් යාවත්කාලීන කිරීමට `omarchy update` ධාවනය කරන්න. `mup` අනුනාමය mise මගින් කළමනාකරණය වන මෙවලම් පමණක් යාවත්කාලීන කරයි. ඔබේම වින්‍යාසයට වෙනත් මෙවලමක් එක් කිරීමට, `mise use -g <tool>` භාවිතා කරන්න.

Python පිහිටුවීම mise හරහා `uv` ද ස්ථාපනය කරයි. Python සංවර්ධන පරිසරය ඉවත් කිරීමෙන් `uv` ස්වාධීන මෙවලමක් ලෙස ලබා ගත හැකිව පවතී.

### ඔබේම ස්ථාපනය භාවිතා කිරීම

mise හි විධාන `PATH` හි `~/.local/bin` ට පෙර එන බැවින්, උදාහරණයක් ලෙස Claude Code හි හෝ Cursor හිම ස්ථාපකය සමඟ ඔබ විසින්ම ස්ථාපනය කළ මෙවලමක් වුවද, තවමත් ධාවනය වන්නේ mise හි පිටපතය. ඩෙස්ක්ටොප් එකෙන් දියත් කරන යෙදුම්වලටද පද්ධති පැකේජවලට පෙර mise හි විධාන හමු වේ, එබැවින් `gh` ධාවනය කරන යෙදුමකට, ඔබ pacman සමඟ `github-cli` ස්ථාපනය කර තිබුණද mise හි පිටපත ලැබේ, සහ mise පළමු වරට එම පිටපත ස්ථාපනය කරයි. ඒ වෙනුවට ඔබේ එක භාවිතා කිරීමට, `~/.config/mise/config.toml` හි mise හි පිටපත අබල කරන්න. උදාහරණයක් ලෙස, ඔබ Cursor CLI ඔබ විසින්ම ස්ථාපනය කළේ නම්:

```toml
[settings]
disable_tools = ["cursor-agent"]
```

ඔබට දැනටමත් `[settings]` වගුවක් තිබේ නම්, එහි ඇතුළත් කිරීම එක් කරන්න; පවතින `disable_tools` ලැයිස්තුවක් ප්‍රතිස්ථාපනය කිරීම වෙනුවට එය දිගු කරන්න. ඔබේ ස්ථාපනය `PATH` හි ඇති බවට වග බලා ගන්න. විධානයෙන් වෙනස් විය හැකි mise මෙවලම් නාමය භාවිතා කරන්න: උදාහරණයක් ලෙස `oh-my-pi` විසින් `omp` සපයයි. පෙරනිමි නියෝජිත දියත්කරණයද `~/.local/bin` හි පරිශීලකයා විසින් ස්ථාපනය කළ Cursor හෝ Muse කැමති වේ.

### පෙරනිමි ඉවත් කිරීම සහ යළි පිහිටුවීම

_Remove > Preinstalls_ මගින් Omarchy හි පූර්ව ස්ථාපිත වෙබ් යෙදුම්, TUI සහ යෙදුම් ඉවත් කරන අතර, ඒවා ඔබේ පරිශීලකයා සඳහා Omarchy හි මෙවලම් ප්‍රකාශයන් මඟ හැරීමට mise ට සැලැස්වීම සඳහා ඒවා `~/.config/mise/miserc.toml` හි `ignored_config_paths` වෙත එක් කරයි. _Install > Preinstalls_ මගින් ඒවා නැවත ගෙන එන අතර එම පේළිය නැවත ඉවත් කරයි. ඔබේම වින්‍යාසයක හෝ ව්‍යාපෘතියක `mise.toml` හි ඔබ විසින්ම ප්‍රකාශ කරන මෙවලම්, ඕනෑම ආකාරයකින් දිගටම ක්‍රියා කරයි. පූර්ව ස්ථාපන ඉවත් කිරීමෙන් පසු ඔබ පෙරනිමි නියෝජිතයෙකු තෝරා ගන්නේ නම් හෝ Python පිහිටුවන්නේ නම්, එම මෙවලම ඔබේම වින්‍යාසයට එක් වේ. mise සැකසුම අදාළ වන්නේ ඔබේ පරිශීලකයාට පමණි, සහ අනෙකුත් පරිශීලකයින් තමන්ගේම තේරීම රඳවා ගනී; නමුත් යෙදුම් පැකේජ වන බැවින්, ඒවා ඉවත් කිරීම හෝ යළි පිහිටුවීම යන්ත්‍රයේ සිටින සියල්ලන්ටම ඒවා වෙනස් කරයි.

## Docker

[Docker](https://www.docker.com/) ගැන අමුතුවෙන් හඳුන්වා දීමක් අවශ්‍ය නැති තරම්ය. එය හුදකලා බහාලුම් ධාවනය කිරීමට ඔබට ඉඩ දෙයි, සහ Omarchy විසින් Docker ම සහ [Docker Compose](https://docs.docker.com/compose/) ඇතුළුව එය හොඳින් ධාවනය කිරීමට අවශ්‍ය සියල්ල ස්ථාපනය කරයි.

පෙරනිමියෙන් ඔබේ පරිශීලකයා `docker` කණ්ඩායමේ *නැත*. එම කණ්ඩායම ඵලදායී ලෙස මුරපද රහිත root වේ — එහි සිටින ඕනෑම කෙනෙකුට `docker run -v /:/host` ධාවනය කර යන්ත්‍රය අත්පත් කර ගත හැකිය — එබැවින් ඔබ ලෙස ධාවනය වන එකම දුෂ්ට ස්ක්‍රිප්ටයක් හෝ පරායත්තතාවයක් වෙනත් ආකාරයකින් root වෙත එක් විධානයක් දුරින් සිටිනු ඇත. එබැවින් විධාන පේළියේ ඔබ Docker `sudo` සමඟ ධාවනය කරයි (`sudo docker ps`, `sudo docker compose up`), සහ ඩේමනය සමඟ කතා කරන චිත්‍රක මෙවලම් — Windows VM එක — අවශ්‍ය වූ විට ඔබෙන් අවසරය ඉල්ලයි. ඔබට කණ්ඩායම් රහිත පිහිටුවීමේ පහසුව නැවත අවශ්‍ය නම් සහ හුවමාරුව තේරුම් ගන්නේ නම්, **Setup > Security > Sudoless Docker** වෙතින් එය සබල කරන්න (හෝ `omarchy-setup-security-sudoless-docker` ධාවනය කරන්න), එය අනතුරු ඇඟවීමකින් පසු ඔබව `docker` කණ්ඩායමට එක් කරයි; එවිට සරල `docker` සහ `d` අනුනාමය `sudo` නොමැතිව නැවත ක්‍රියා කරයි.

ඔබට Omarchy මෙනුවේ _Install > Development > Docker DB_ භාවිතයෙන් දේශීය සංවර්ධනය සඳහා පොදු දත්ත සමුදායන් Docker තුළ පිහිටුවිය හැකිය.

## GitHub CLI

[GitHub CLI](https://cli.github.com/) ටර්මිනලයෙන් ගබඩා, ගැටලු, සහ pull request සමඟ වැඩ කිරීමට `gh` ලෙස ලබා ගත හැකිය. පළමු භාවිතයේදී එය ස්ථාපනය කර සත්‍යාපනය වීමට `gh auth login` ධාවනය කරන්න, ඉන්පසු ගබඩාවක් ක්ලෝන කිරීමට `gh repo clone org/repo` ධාවනය කරන්න. එහි විධාන ගවේෂණය කිරීමට `gh --help` ධාවනය කරන්න.

pull request සඳහා ටර්මිනල් අතුරු මුහුණතක් සඳහා, `ghui` ධාවනය කරන්න; mise එයද පළමු භාවිතයේදී ස්ථාපනය කරයි. Git සමඟම වැඩ කිරීම සඳහා [Lazygit](https://github.com/jesseduffield/lazygit) පූර්ව ස්ථාපනය කර ඇත.
