# සංවර්ධන මෙවලම්

## විකල්ප සංස්කාරක

Omarchy පෙරනිමියෙන් [Neovim](https://neovim.io/) සමඟ එන නමුත්, ඔබට ටිකක් වඩා ප්‍රධාන ධාරාවේ සහ හුරුපුරුදු දෙයක් අවශ්‍ය නම්, ඔබට Omarchy Menu (`Super + Space`) ධාවනය කර _Install > Editor_ යටතේ ඇති විකල්ප දැකිය හැකිය. එහි අප සතුව VSCode, Cursor, Zed, Sublime Text, Helix, Vim සහ Emacs ලැයිස්තුගත කර ඇත. ඔබ සොයන දේ ඔබට හමු නොවන්නේ නම්, _Install > Package_ පරීක්ෂා කර, එය Arch package එකක නැත්දැයි බලන්න (එසේ නැත්නම්, AUR එක පරීක්ෂා කිරීමට _Install > AUR_ උත්සාහ කරන්න).

මුල් `vi` සංස්කාරකයත් පෙට්ටියෙන් පිටතම ලබා ගත හැකිය. පර්යන්තයේ ගොනුවක් සංස්කරණය කිරීමට `vi filename` ධාවනය කරන්න.

`VSCode`, `Cursor`, `VSCodium` සහ `Helix` සඳහා theme ගැලපීම පිරිනැමේ.

ඔබට `Setup > Defaults > Editor` යටතේ පද්ධතිය පුරා පෙරනිමි සංස්කාරකය සැකසිය හැකිය.

## පරිසරය

Omarchy Menu (`Super + Space`) හි _Install > Development_ කොටස හරහා සංවර්ධන පරිසර රාශියක්ම සැකසීමට Omarchy සහාය දක්වයි. ඔබට ඇත්ත වශයෙන්ම _Ruby on Rails_ හමුවනු ඇති නමුත්, JavaScript සඳහා වන ප්‍රධාන ධාවන පරිසර තුනම (Node.js, Bun, Deno), මෙන්ම Laravel සහ Symfony වැනි ජනප්‍රිය PHP රාමුද ඇත. අහෝ, Go, Rust, Python, Java, Elixir (Phoenix සමඟ), .NET, OCaml, Zig, Clojure සහ Scala ද ඇත. එය ඉතා පුළුල් තේරීමකි!

මෙම පරිසරවලින් බහුතරයක් කළමනාකරණය කරනු ලබන්නේ [Mise](https://mise.jdx.dev/) විසිනි. එය එකම යන්ත්‍රයේ ක්‍රමලේඛන භාෂාවක අනුවාද කිහිපයක් ස්ථාපනය කිරීමට සහ ධාවනය කිරීමට ඔබට ඉඩ දෙන මෙවලමකි. එය Ruby සඳහා rbenv හෝ rvm වැනි, නැතහොත් Python සඳහා virtualenv වැනි දෙයකි, නමුත් එය විවිධ පරිසර රාශියක් සඳහා ක්‍රියා කරයි.

උදාහරණයක් ලෙස, Ruby ස්ථාපනය කිරීමට, ඔබ `mise use -g ruby` ධාවනය කරනු ඇත, එමඟින් Ruby ස්ථාපනය කර එය ගෝලීය පෙරනිමිය ලෙසද සැකසෙනු ඇත. නැතහොත්, ඔබේ ව්‍යාපෘතියේ .ruby-version ගොනුවක් තිබේ නම්, ඔබට එම ව්‍යාපෘතියේ මූලයේ `mise i` ධාවනය කිරීම පමණක් ප්‍රමාණවත්ය.

## පෙර ස්ථාපිත CLI මෙවලම්

Omarchy විසින් `gh`, `uv` වැනි මෙවලම් සහ බොහෝ [කේතන නියෝජිතයන්](17-ai.md) [Mise හි lazy installation](https://mise.jdx.dev/dev-tools/shims.html#lazy-tools) හරහා ලබා ගත හැකි පරිදි සලසයි. ඔබ පළමු වරට එකක් ධාවනය කරන විට, mise එය ස්ථාපනය කරයි. පසුකාලීන ධාවනයන් ස්ථාපිත අනුවාදය නැවත භාවිතා කරයි; ඒවා සෑම දියත් කිරීමකදීම යාවත්කාලීනයක් සඳහා පරීක්ෂා නොකරයි.

ඔබට පෙරනිමි පරීක්ෂා කිරීමට හෝ ඒවා කල්තියා ස්ථාපනය කිරීමටද හැකිය:

```bash
mise ls --current              # List the tools configured for this directory
mise install gh               # Install one tool now
mise install --include-lazy    # Install all configured tools, including lazy tools
```

ඉතිරි Omarchy සමඟ ස්ථාපිත මෙවලම් යාවත්කාලීන කිරීමට `omarchy update` ධාවනය කරන්න. `mup` අනුනාමය mise මගින් කළමනාකරණය වන මෙවලම් පමණක් යාවත්කාලීන කරයි. ඔබේම වින්‍යාසයට තවත් මෙවලමක් එක් කිරීමට, `mise use -g <tool>` භාවිතා කරන්න.

Python සැකසුම මගින් mise හරහා `uv` ද ස්ථාපනය කරයි. Python සංවර්ධන පරිසරය ඉවත් කිරීමෙන් `uv` ස්වාධීන මෙවලමක් ලෙස ලබා ගත හැකිව පවතී.

### ඔබේම ස්ථාපනය භාවිතා කිරීම

mise හි විධාන `PATH` මත `~/.local/bin` ට පෙර එන බැවින්, ඔබ විසින්ම ස්ථාපනය කළ මෙවලමක්, උදාහරණයක් ලෙස Claude Code හි හෝ Cursor හිම ස්ථාපකය සමඟ ස්ථාපනය කළ එකක්, වුවද තවමත් ධාවනය වන්නේ mise හි පිටපතයි. ඩෙස්ක්ටොප් එකෙන් දියත් කරන යෙදුම්වලටද පද්ධති පැකේජවලට පෙර mise හි විධාන හමු වන බැවින්, `gh` ධාවනය කරන යෙදුමකට, ඔබ pacman සමඟ `github-cli` ස්ථාපනය කර තිබුණත් mise හි පිටපත ලැබෙන අතර, mise එම පිටපත පළමු වරට ස්ථාපනය කරයි. ඒ වෙනුවට ඔබේ එක භාවිතා කිරීමට, `~/.config/mise/config.toml` හි mise හි පිටපත අක්‍රිය කරන්න. උදාහරණයක් ලෙස, ඔබ Cursor CLI ඔබම ස්ථාපනය කළේ නම්:

```toml
[settings]
disable_tools = ["cursor-agent"]
```

ඔබට දැනටමත් `[settings]` වගුවක් තිබේ නම්, එම ප්‍රවේශය එහි එක් කරන්න; පවතින `disable_tools` ලැයිස්තුවක් ප්‍රතිස්ථාපනය නොකර එය දීර්ඝ කරන්න. ඔබේ ස්ථාපනය `PATH` මත ඇති බවට වග බලා ගන්න. එහි විධානයෙන් වෙනස් විය හැකි mise මෙවලම් නාමය භාවිතා කරන්න: උදාහරණයක් ලෙස, `oh-my-pi` විසින් `omp` සපයයි. පෙරනිමි නියෝජිත දියත්කරුවාද `~/.local/bin` හි පරිශීලකයා ස්ථාපනය කළ Cursor හෝ Muse එකකට මනාපය දක්වයි.

### පෙරනිමි ඉවත් කිරීම සහ ප්‍රතිසාධනය කිරීම

_Remove Preinstalls_ විසින් mise හට ඔබේ පරිශීලකයා සඳහා Omarchy හි මෙවලම් ප්‍රකාශයන් මඟ හැරීමට සලස්වනු ලබන්නේ, ඒවා `~/.config/mise/miserc.toml` හි `ignored_config_paths` වෙත එක් කිරීමෙනි. _Restore Preinstalls_ එම පේළිය නැවත ඉවත් කරයි. ඔබ විසින්ම ප්‍රකාශ කරන මෙවලම්, ඔබේම වින්‍යාසයේ හෝ ව්‍යාපෘතියක `mise.toml` හි වුවත්, එලෙසම ක්‍රියා කරයි. පෙර ස්ථාපනයන් ඉවත් කිරීමෙන් පසුව ඔබ පෙරනිමි නියෝජිතයෙකු තෝරා ගත්තොත් හෝ Python සැකසුවොත්, එම මෙවලම ඔබේම වින්‍යාසයට එක් කෙරේ. දෙකම අදාළ වන්නේ ඔබේ පරිශීලකයාට පමණි; යන්ත්‍රයේ සිටින අනෙකුත් පරිශීලකයන් ඔවුන්ගේම තේරීම රඳවා ගනී.

## Docker

[Docker](https://www.docker.com/) ට හැඳින්වීමක් අවශ්‍යම නැති තරම්ය. එය හුදකලා බහාලුම් ධාවනය කිරීමට ඔබට ඉඩ දෙන අතර, Omarchy එය හොඳින් ධාවනය කිරීමට අවශ්‍ය සියල්ල ස්ථාපනය කරයි, Docker ම සහ [Docker Compose](https://docs.docker.com/compose/) ද ඇතුළුව.

පෙරනිමියෙන් ඔබේ පරිශීලකයා `docker` කණ්ඩායමේ *නැත*. එම කණ්ඩායම ඵලදායී ලෙස මුරපද රහිත root එකකි — එහි සිටින ඕනෑම දෙයකට `docker run -v /:/host` ධාවනය කර යන්ත්‍රය අත්පත් කර ගත හැකිය — එබැවින් ඔබ ලෙස ධාවනය වන තනි අනිෂ්ට script එකක් හෝ dependency එකක්, එසේ නොවුවහොත්, root වෙත ළඟා වීමට ඇත්තේ එක් විධානයක් පමණි. එබැවින් විධාන රේඛාවේ ඔබ Docker ධාවනය කරන්නේ `sudo` සමඟය (`sudo docker ps`, `sudo docker compose up`), සහ daemon එක සමඟ කතා කරන චිත්‍රක මෙවලම් — Windows VM එක — අවශ්‍ය විට අවසරය ඉල්ලයි. ඔබට කණ්ඩායම් රහිත සැකසුමේ පහසුව නැවත අවශ්‍ය නම් සහ එහි හුවමාරුව තේරුම් ගන්නේ නම්, **Setup > Security > Sudoless Docker** වෙතින් එය සක්‍රිය කරන්න (හෝ `omarchy-setup-security-sudoless-docker` ධාවනය කරන්න), එය අනතුරු ඇඟවීමකින් පසුව ඔබව `docker` කණ්ඩායමට එක් කරයි; ඉන්පසු සරල `docker` සහ `d` අනුනාමය `sudo` නොමැතිව නැවත ක්‍රියා කරයි.

ඔබට Omarchy menu එකේ _Install > Development > Docker DB_ භාවිතයෙන් දේශීය සංවර්ධනය සඳහා පොදු දත්ත සමුදායන් Docker තුළ සැකසිය හැකිය.

## GitHub CLI

[GitHub CLI](https://cli.github.com/) පර්යන්තයෙන් repositories, issues සහ pull requests සමඟ වැඩ කිරීමට `gh` ලෙස ලබා ගත හැකිය. පළමු භාවිතයේදී එය ස්ථාපනය කර සත්‍යාපනය කිරීමට `gh auth login` ධාවනය කරන්න, ඉන්පසු repository එකක් clone කිරීමට `gh repo clone org/repo` ධාවනය කරන්න. එහි විධාන ගවේෂණය කිරීමට `gh --help` ධාවනය කරන්න.

pull requests සඳහා පර්යන්ත අතුරුමුහුණතක් සඳහා, `ghui` ධාවනය කරන්න; mise එයත් පළමු භාවිතයේදී ස්ථාපනය කරයි. Git සමඟම වැඩ කිරීම සඳහා [Lazygit](https://github.com/jesseduffield/lazygit) පෙර ස්ථාපනය කර ඇත.
