# පද්ධති ස්නැප්ෂොට්

සෑම Omarchy යාවත්කාලීනයකදීම අපි ස්වයංක්‍රීයව ස්නැප්ෂොට් සාදන්නෙමු, නමුත් ඔබට ඔබේම එකක් සාදා ගැනීමට අවශ්‍ය නම්, ඔබට `omarchy-snapshot create` භාවිතා කළ හැකිය.

ස්නැප්ෂොට් එකක් boot කර ප්‍රතිස්ථාපනය කිරීමට, ඔබ එය Limine boot loader එකෙන් තෝරන්න. Boot මෙනුව පෙරනිමියෙන් සැඟවී පවතී, එබැවින් එය පෙන්වීමට Limine ආරම්භ වූ වහාම ඕනෑම යතුරක් ඔබන්න.

එම තිරයෙන්, දිනය සහ අනුවාදය මත පදනම්ව ඔබට boot කිරීමට අවශ්‍ය ස්නැප්ෂොට් එක තෝරන්න. ස්නැප්ෂොට් එක ගත් අවස්ථාවේ තිබූ Omarchy අනුවාදය පහළ වම් කෙළවරේ දැකිය හැකිය.

 ![snapshots-bootloader](images/snapshots-bootloader.webp)

ඔබ ඇතුළට පැමිණි විට, ඔබ boot කළ හැකි ස්නැප්ෂොට් එකක සිටින බව දැනුම් දෙන දැනුම්දීමක් popup වනු ඇත, ඔබ එය click කළහොත්, ප්‍රතිස්ථාපන ක්‍රියාවලිය ආරම්භ වනු ඇත. විකල්පයක් ලෙස, ඔබට `omarchy-snapshot restore` භාවිතා කළ හැකිය.

 ![snapshots-restore](images/snapshots-restore.webp)

මෙය ඔබේ root filesystem එක ප්‍රතිස්ථාපනය කරනු ඇත, නමුත් ඔබේ `/home` එක නොවේ. එබැවින් එය බිඳ වැටුණු පද්ධති යාවත්කාලීනයක් ආපසු හැරවීමට ක්‍රියා කරයි, නමුත් නැතිවූ පුද්ගලික ගොනු නැවත ලබා ගැනීමට නොවේ.

මෙයින් අදහස් වන්නේ ඔබේ `~/.config` ඩිරෙක්ටරිය එලෙසම පවතින බවයි. එබැවින් ඔබ නව ආකෘතියකින් configuration ගොනු ගබඩා කරන library එකක හෝ application එකක පෙර අනුවාදයකට ආපසු යන්නේ නම්, එය අතින්ම විසඳා ගැනීමට ඔබට සිදු වනු ඇත.

දැනටමත් ධාවනය වී ඇති migrations පිළිබඳ Omarchy හිම සටහනටද එයම අදාළ වේ: එය ඔබේ home ඩිරෙක්ටරියේ පවතී, එබැවින් එය ප්‍රතිස්ථාපනයෙන් පසුවද ඉතිරි වේ. Root filesystem එකට ඔවුන් කළ වෙනස්කම් ආපසු හරවා තිබුණත්, ස්නැප්ෂොට් එකෙන් පසු ධාවනය වූ migrations සිදු කර අවසන් ලෙස සලකුණු වී පවතී, ඊළඟ `omarchy update` එක ඒවා නැවත ධාවනය නොකරනු ඇත. එබැවින් ප්‍රතිස්ථාපනයකින් පසු ඔබ නැවත යාවත්කාලීන කළ විට පෙර යාවත්කාලීනයකින් සකසා තිබූ යමක් තවමත් නොමැති නම්, එය බොහෝ විට ඊට හේතුව විය හැකිය.

_සටහන: මෙම විශේෂාංගය ලබා ගත හැක්කේ Limine boot loader එක භාවිතා කරන ස්ථාපනයන් සඳහා පමණි, එය Omarchy 2.0 සිට පෙරනිමිය වී ඇත. ඔබ GRUB හෝ systemd-boot මත සිටී නම් එය ලබා ගත නොහැක._
