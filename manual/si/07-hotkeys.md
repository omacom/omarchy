# උණුසුම් යතුරු

ඔබට ප්‍රධාන යතුරු බැඳීම් සියල්ල `Super + K` සමඟින් දැකිය හැකිය (Tmux බැඳීම් `Super + Alt + K` සමඟින් සහ Herdr බැඳීම් `Super + Ctrl + K` සමඟින්).

## උණුසුම් යතුරු සකසා ඇති ආකාරය

සෑම උණුසුම් යතුරක්ම තලයක පිහිටා ඇති අතර, එය එහි modifiers මඟින් සකසනු ලැබේ, සහ සෑම තලයකටම එක් කාර්යයක් ඇත. උණුසුම් යතුරු එකිනෙක ගැටීමෙන් වළක්වා ගන්නේ එයයි, එසේම යමක් සාමාන්‍යයෙන් කොහි තිබේදැයි ඔබට අනුමාන කිරීමට හැකි වන්නේද එයයි.

| --- | --- | --- |
| `Super + key` | පද්ධතිය: කවුළු, වැඩබිම්, පිරිසැලසුම්, සහ මූලික මෙනු | `Super + Space` Omarchy මෙනුව, `Super + W` කවුළුව වසන්න, `Super + F` සම්පූර්ණ තිරය |
| `Super + Shift + key` | යෙදුම් | `Super + Shift + B` බ්‍රවුසරය, `Super + Shift + E` විද්‍යුත් තැපෑල, `Super + Shift + N` සංස්කාරකය |
| `Super + Ctrl + key` | පැනල සහ පද්ධති මෙනු | `Super + Ctrl + A` ශ්‍රව්‍ය, `Super + Ctrl + N` ජාලය, `Super + Ctrl + C` අල්ලාගැනීමේ මෙනුව |
| `Super + Ctrl + Alt + key` | ඉක්මන් ක්‍රියා සහ නිවේදන | `Super + Ctrl + Alt + T` වේලාව පෙන්වන්න, `Super + Ctrl + Alt + B` බැටරිය, `Super + Ctrl + Alt + C` තිරපිටපත |

උණුසුම් යතුරකට `Alt` එකතු කිරීමෙන් ඔබට එම දෙයෙහිම ප්‍රභේදයක් ලැබේ, කිසිවිටෙකත් අදාළ නොවන දෙයක් නොවේ:

- `Super + Shift + B` බ්‍රවුසරය විවෘත කරයි; `Super + Shift + Alt + B` පෞද්ගලික කවුළුවක් විවෘත කරයි
- `Super + Shift + E` විද්‍යුත් තැපෑල විවෘත කරයි; `Super + Shift + Alt + E` නව එකක් ආරම්භ කරයි
- `Super + F` සම්පූර්ණ තිරයට යයි; `Super + Alt + F` සම්පූර්ණ පළලට යයි
- `Super + Ctrl + C` අල්ලාගැනීමේ මෙනුව විවෘත කරයි; `Super + Ctrl + Alt + C` මෙනුව මඟ හැර තිරපිටපතක් ගනියි

උණුසුම් යතුරක් එකතු කරන විට:

1. එය කරන දෙය අනුව තලය තෝරන්න, ඉන්පසු යතුර තෝරන්න.
2. ඉඩ ලබා ගැනීම සඳහා පවතින උණුසුම් යතුරක් වෙනත් තැනකට නොයවන්න. නිවැරදි තලයේ නිදහස් යතුරක් සොයන්න.
3. `Alt` භාවිතා කරන්න එය නොමැති උණුසුම් යතුරේ ප්‍රභේදයක් සඳහා පමණි.

පහසු නිසා උණුසුම් යතුරු කිහිපයක් මෙම නීති කඩයි. ඊතලයක් හෝ `Tab` සමඟ `Shift` යෙදුමක් විවෘත කිරීම වෙනුවට ගෙනයයි හෝ ආපසු හරවයි, සහ `Print`, මාධ්‍ය යතුරු, `Alt + Tab`, සහ `Ctrl + Alt + Del` සෑම තැනකම ක්‍රියාත්මක වන ආකාරයටම ක්‍රියා කරයි. ඒවා ව්‍යතිරේකයන් මිස අනුකරණය කළ යුතු රටා නොවේ.

පෙරනිමියක් ඔබට නොගැලපේ නම් (උදාහරණයක් ලෙස Windows හි මෙන් තිරපිටපත් සඳහා `Super + Shift + S` අවශ්‍ය නම්), එය `~/.config/hypr/bindings.lua` තුළ නැවත බඳින්න.

ප්‍රමාණය වෙනස් කිරීමේ කෙටිමං, යතුරුපුවරුවේ මුද්‍රණය කර ඇති අක්ෂර නොසලකා, භෞතික යතුරු `code:20` සහ `code:21` (XKB `<AE11>` සහ `<AE12>`) භාවිතා කරයි. US යතුරුපුවරුවල මෙම යතුරු `-` සහ `=` වේ; ජපන් (JIS) යතුරුපුවරුවල ඒවා `-` සහ `^` වේ; ස්පාඤ්ඤ යතුරුපුවරුවල ඒවා `'` සහ `¡` වේ. JIS හි, `Super + ^` යනු `Super + Equal` වන අතර, `Super + Shift + -` (එය `=` ටයිප් කරයි) යනු `Super + Shift + Minus` වේ.
