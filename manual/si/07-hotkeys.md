# හොට්කී

ඔබට ප්‍රධාන යතුරුපුවරු බන්ධන සියල්ල `Super + K` සමඟින් දැකිය හැකිය (Tmux බන්ධන `Super + Alt + K` සමඟින් සහ Herdr බන්ධන `Super + Ctrl + K` සමඟින්).

## හොට්කී සකසා ඇති ආකාරය

සෑම හොට්කීයක්ම එහි modifiers අනුව තීරණය වන තලයක පිහිටා ඇති අතර, සෑම තලයකටම එක කාර්යයක් ඇත. හොට්කී එකිනෙකට නොපැටලී පවතින්නේ ඒ නිසා වන අතර, සාමාන්‍යයෙන් යමක් පිහිටා ඇත්තේ කොතැනදැයි ඔබට අනුමාන කළ හැකි වන්නේ ද ඒ නිසාය.

| තලය | එහි ඇති දේ | උදාහරණ |
| --- | --- | --- |
| `Super + key` | පද්ධතිය: කවුළු, වැඩ අවකාශ, පිරිසැලසුම් සහ මූලික මෙනු | `Super + Space` Omarchy මෙනුව, `Super + W` කවුළුව වසන්න, `Super + F` සම්පූර්ණ තිරය |
| `Super + Shift + key` | යෙදුම් | `Super + Shift + B` බ්‍රවුසරය, `Super + Shift + E` විද්‍යුත් තැපෑල, `Super + Shift + N` සංස්කාරකය |
| `Super + Ctrl + key` | පැනල සහ පද්ධති මෙනු | `Super + Ctrl + A` ශ්‍රව්‍ය, `Super + Ctrl + N` ජාලය, `Super + Ctrl + C` ග්‍රහණ මෙනුව |
| `Super + Ctrl + Alt + key` | ඉක්මන් ක්‍රියා සහ නිවේදන | `Super + Ctrl + Alt + T` වේලාව පෙන්වන්න, `Super + Ctrl + Alt + B` බැටරිය, `Super + Ctrl + Alt + C` තිර රූපය |

හොට්කීයකට `Alt` එක් කිරීමෙන් ඔබට ලැබෙන්නේ එම දෙයෙහිම ප්‍රභේදයක් මිස, කිසිදා සම්බන්ධයක් නැති දෙයක් නොවේ:

- `Super + Shift + B` බ්‍රවුසරය විවෘත කරයි; `Super + Shift + Alt + B` පෞද්ගලික කවුළුවක් විවෘත කරයි
- `Super + Shift + E` විද්‍යුත් තැපෑල විවෘත කරයි; `Super + Shift + Alt + E` අලුත් එකක් ආරම්භ කරයි
- `Super + F` සම්පූර්ණ තිරයට යයි; `Super + Alt + F` සම්පූර්ණ පළලට යයි
- `Super + Ctrl + C` ග්‍රහණ මෙනුව විවෘත කරයි; `Super + Ctrl + Alt + C` මෙනුව මඟ හැර තිර රූපයක් ගනියි

හොට්කීයක් එක් කරන විට:

1. එය කරන දේ අනුව තලය තෝරා, පසුව යතුර තෝරන්න.
2. ඉඩ ලබා ගැනීම සඳහා පවතින හොට්කීයක් වෙනත් තැනකට නොයවන්න. නිවැරදි තලයේ නිදහස් යතුරක් සොයන්න.
3. `Alt` භාවිතා කරන්න එය නොමැති හොට්කීයෙහි ප්‍රභේදයක් සඳහා පමණි.

හොට්කී කිහිපයක් මෙම නීති කඩ කරන්නේ ඒවා පහසු නිසාය. ඊතලයක් හෝ `Tab` සමඟ `Shift` යෙදීම යෙදුමක් විවෘත කිරීම වෙනුවට ගෙනයාම හෝ ආපසු හැරවීම සිදු කරයි, සහ `Print`, මාධ්‍ය යතුරු, `Alt + Tab` සහ `Ctrl + Alt + Del` අනෙක් සෑම තැනකදීම මෙන්ම ක්‍රියා කරයි. ඒවා ව්‍යතිරේක මිස, අනුගමනය කළ යුතු රටා නොවේ.

ඔබට පෙරනිමිය නොගැලපේ නම් (ඔබට Windows වල මෙන් තිර රූප සඳහා `Super + Shift + S` අවශ්‍ය යැයි සිතමු), එය `~/.config/hypr/bindings.lua` තුළ නැවත බඳින්න.

JIS හි, `Super + ^` යනු `Super + Equal` වන අතර, `Super + Shift + -` (එය `=` ටයිප් කරයි) යනු `Super + Shift + Minus` වේ.
