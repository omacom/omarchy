# යතුරු කෙටිමං

ඔබට සියලු ප්‍රධාන යතුරු බැඳීම් `Super + K` සමඟින් දැකිය හැකිය (Tmux බැඳීම් `Super + Alt + K` සමඟින් සහ Herdr බැඳීම් `Super + Ctrl + K` සමඟින්).
