# ඉක්මන් යතුරු

ඔබට `Super + K` සමඟ ප්‍රධාන යතුරුපුවරු බැඳීම් සියල්ල දැකිය හැකිය (Tmux බැඳීම් `Super + Alt + K` සමඟ සහ Herdr බැඳීම් `Super + Ctrl + K` සමඟ).

## ඉක්මන් යතුරු සකසා ඇති ආකාරය

සෑම ඉක්මන් යතුරක්ම එහි modifiers මඟින් සකසන ලද තලයක පිහිටා ඇති අතර, සෑම තලයකටම එක් කාර්යයක් ඇත. ඉක්මන් යතුරු එකිනෙක නොගැටී තබා ගන්නේ එයයි, එමෙන්ම යමක් සාමාන්‍යයෙන් පිහිටා ඇත්තේ කොතැනදැයි ඔබට අනුමාන කළ හැක්කේද එය නිසාය.

| තලය | එහි ඇති දේවල් | උදාහරණ |
| --- | --- | --- |
| `Super + key` | පද්ධතිය: කවුළු, වැඩබිම්, පිරිසැලසුම් සහ මූලික මෙනු | `Super + Space` Omarchy මෙනුව, `Super + W` කවුළුව වසන්න, `Super + F` සම්පූර්ණ තිරය |
| `Super + Shift + key` | යෙදුම් | `Super + Shift + B` බ්‍රවුසරය, `Super + Shift + E` ඊමේල්, `Super + Shift + N` සංස්කාරකය |

ඉක්මන් යතුරකට `Alt` එක් කිරීමෙන් ඔබට ලැබෙන්නේ එම දෙයේම ප්‍රභේදයක් මිස, කිසිසේත්ම සම්බන්ධ නැති දෙයක් නොවේ:

- `Super + Shift + B` බ්‍රවුසරය විවෘත කරයි; `Super + Shift + Alt + B` පුද්ගලික කවුළුවක් විවෘත කරයි
- `Super + Shift + E` ඊමේල් විවෘත කරයි; `Super + Shift + Alt + E` අලුත් එකක් ආරම්භ කරයි
- `Super + F` සම්පූර්ණ තිරයට යයි; `Super + Alt + F` සම්පූර්ණ පළලට යයි
- `Super + Ctrl + C` ග්‍රහණ මෙනුව විවෘත කරයි; `Super + Ctrl + Alt + C` මෙනුව මඟ හැර තිරපිටපතක් ගනියි

ඉක්මන් යතුරක් එක් කරන විට:

1. එය කරන දේ අනුව තලය තෝරන්න, ඉන්පසු යතුර තෝරන්න.
2. ඉඩ ලබා ගැනීමට දැනට ඇති ඉක්මන් යතුරක් ගෙන නොයන්න. නිවැරදි තලයේ නිදහස් යතුරක් සොයන්න.
3. `Alt` භාවිතා කරන්න එය නැති ඉක්මන් යතුරේ ප්‍රභේදයක් සඳහා පමණි.

ඉක්මන් යතුරු කිහිපයක් පහසු නිසා මෙම නීති කඩයි. ඊතලයක් හෝ `Tab` සමඟ `Shift` යෙදුමක් විවෘත කරනවා වෙනුවට ගෙන යයි හෝ ආපසු හරවයි, සහ `Print`, මාධ්‍ය යතුරු, `Alt + Tab`, සහ `Ctrl + Alt + Del` අනෙක් සෑම තැනකම මෙන් ක්‍රියා කරයි. ඒවා ව්‍යතිරේක මිස, පිටපත් කළ යුතු රටා නොවේ.

පෙරනිමියක් ඔබට නොගැළපේ නම් (ඔබට Windows වල මෙන් තිරපිටපත් සඳහා `Super + Shift + S` අවශ්‍ය යැයි සිතමු), එය `~/.config/hypr/bindings.lua` හි නැවත බඳින්න.

US යතුරුපුවරු වල මෙම යතුරු `-` සහ `=` ය; ජපන් (JIS) යතුරුපුවරු වල ඒවා `-` සහ `^` ය; ස්පාඤ්ඤ යතුරුපුවරු වල ඒවා `'` සහ `¡` ය. JIS හි, `Super + ^` යනු `Super + Equal` වන අතර, `Super + Shift + -` (එය `=` ටයිප් කරයි) යනු `Super + Shift + Minus` වේ.
