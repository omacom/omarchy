# හොට්කීස්

ඔබට ප්‍රධාන යතුරුපුවරු බැඳීම් සියල්ල `Super + K` වලින් දැකිය හැකිය (Tmux බැඳීම් `Super + Alt + K` වලින් සහ Herdr බැඳීම් `Super + Ctrl + K` වලින්).

ප්‍රමාණය වෙනස් කිරීමේ කෙටිමං, යතුරුපුවරුවේ මුද්‍රණය කර ඇති අක්ෂර නොසලකා, භෞතික යතුරු `code:20` සහ `code:21` (XKB `<AE11>` සහ `<AE12>`) භාවිතා කරයි. US යතුරුපුවරු වල මෙම යතුරු `-` සහ `=` වේ; ජපන් (JIS) යතුරුපුවරු වල ඒවා `-` සහ `^` වේ; ස්පාඤ්ඤ යතුරුපුවරු වල ඒවා `'` සහ `¡` වේ. JIS වල, `Super + ^` යනු `Super + Equal` වන අතර, `Super + Shift + -` (එය `=` ටයිප් කරයි) යනු `Super + Shift + Minus` වේ.
