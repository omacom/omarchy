# කෙටිමං යතුරු

ඔබට ප්‍රධාන යතුරුපුවරු බන්ධන සියල්ල `Super + K` සමඟින් දැකිය හැක (Tmux බන්ධන `Super + Alt + K` සමඟින් සහ Herdr බන්ධන `Super + Ctrl + K` සමඟින්).

## කෙටිමං යතුරු සකසා ඇති ආකාරය

සෑම කෙටිමං යතුරක්ම එහි විකරණයන්ගෙන් තීරණය වන තලයක පිහිටා ඇති අතර, සෑම තලයකටම ඇත්තේ එක් කාර්යයකි. කෙටිමං යතුරු එකිනෙක පටලැවීමෙන් වළක්වන්නේ එයයි, එමෙන්ම යමක් සාමාන්‍යයෙන් කොහේ තිබේදැයි ඔබට අනුමාන කළ හැකි වන්නේද එයයි.

| තලය | එහි තිබෙන්නේ කුමක්ද | උදාහරණ |
| --- | --- | --- |
| `Super + key` | පද්ධතිය: කවුළු, වැඩබිම්, පිරිසැලසුම්, සහ මූලික මෙනු | `Super + Space` Omarchy මෙනුව, `Super + W` කවුළුව වසන්න, `Super + F` සම්පූර්ණ තිරය |
| `Super + Shift + key` | යෙදුම් | `Super + Shift + B` බ්‍රවුසරය, `Super + Shift + E` ඊමේලය, `Super + Shift + N` සංස්කාරකය |
| `Super + Ctrl + key` | පැනල සහ පද්ධති මෙනු | `Super + Ctrl + A` ශ්‍රව්‍ය, `Super + Ctrl + N` ජාලය, `Super + Ctrl + C` අල්ලාගැනීමේ මෙනුව |
| `Super + Ctrl + Alt + key` | ඉක්මන් ක්‍රියා සහ නිවේදන | `Super + Ctrl + Alt + T` වේලාව පෙන්වන්න, `Super + Ctrl + Alt + B` බැටරිය, `Super + Ctrl + Alt + C` තිරපිටපත |

කෙටිමං යතුරකට `Alt` එකතු කිරීමෙන් ඔබට ලැබෙන්නේ එම දෙයෙහිම ප්‍රභේදයක් මිස, සම්බන්ධයක් නැති වෙනත් දෙයක් නොවේ:

- `Super + Shift + B` බ්‍රවුසරය විවෘත කරයි; `Super + Shift + Alt + B` පෞද්ගලික කවුළුවක් විවෘත කරයි
- `Super + Shift + E` ඊමේලය විවෘත කරයි; `Super + Shift + Alt + E` අලුත් එකක් ආරම්භ කරයි
- `Super + F` සම්පූර්ණ තිරයට යයි; `Super + Alt + F` සම්පූර්ණ පළලට යයි
- `Super + Ctrl + C` අල්ලාගැනීමේ මෙනුව විවෘත කරයි; `Super + Ctrl + Alt + C` මෙනුව මඟහැර තිරපිටපතක් ගනියි

කෙටිමං යතුරක් එක් කරන විට:

1. එය කරන දෙය අනුව තලය තෝරන්න, ඉන්පසු යතුර තෝරන්න.
2. ඉඩ ලබා ගැනීම සඳහා පවතින කෙටිමං යතුරක් වෙනත් තැනකට නොයවන්න. නිවැරදි තලයේ නිදහස් යතුරක් සොයන්න.
3. `Alt` භාවිතා කරන්න එය නොමැති කෙටිමං යතුරේ ප්‍රභේදයක් සඳහා පමණි.

පහසුව නිසා කෙටිමං යතුරු කිහිපයක් මෙම නීති කඩයි. ඊතලයක් හෝ `Tab` සමඟ `Shift` යෙදුමක් විවෘත කිරීම වෙනුවට ගෙනයයි හෝ ආපසු හරවයි, එමෙන්ම `Print`, මාධ්‍ය යතුරු, `Alt + Tab`, සහ `Ctrl + Alt + Del` අනෙක් සෑම තැනකම ක්‍රියා කරන ආකාරයටම ක්‍රියා කරයි. ඒවා ව්‍යතිරේක මිස, පිටපත් කළ යුතු රටා නොවේ.

පෙරනිමියක් ඔබට නොගැලපේ නම් (උදාහරණයක් ලෙස Windows හි මෙන් තිරපිටපත් සඳහා `Super + Shift + S` අවශ්‍ය නම්), එය `~/.config/hypr/bindings.lua` තුළ නැවත බඳින්න.
