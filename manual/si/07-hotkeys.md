# යතුරුපුවරු කෙටිමං

ප්‍රධාන යතුරුපුවරු බැඳීම් සියල්ල `Super + K` වලින් දැක ගත හැකිය (Tmux බැඳීම් `Super + Alt + K` වලින් සහ Herdr බැඳීම් `Super + Ctrl + K` වලින්).

## යතුරුපුවරු කෙටිමං සකසා ඇති ආකාරය

සෑම යතුරුපුවරු කෙටිමඟක්ම එහි modifiers මගින් තීරණය වන තලයක පිහිටා ඇති අතර, සෑම තලයකටම එක් කාර්යයක් ඇත. යතුරුපුවරු කෙටිමං එකිනෙක පටලැවීම වළක්වන්නේ එයයි, එමෙන්ම යමක් සාමාන්‍යයෙන් පිහිටන්නේ කොහේදැයි අනුමාන කිරීමටද එය ඔබට ඉඩ දෙයි.

යතුරුපුවරු කෙටිමඟකට `Alt` එක් කිරීමෙන් ඔබට ලැබෙන්නේ එම දෙයේම ප්‍රභේදයක් මිස, සම්බන්ධයක් නැති දෙයක් කිසිවිටෙක නොවේ:

- `Super + Shift + B` බ්‍රවුසරය විවෘත කරයි; `Super + Shift + Alt + B` පුද්ගලික කවුළුවක් විවෘත කරයි
- `Super + Shift + E` විද්‍යුත් තැපෑල විවෘත කරයි; `Super + Shift + Alt + E` අලුත් එකක් ආරම්භ කරයි
- `Super + F` සම්පූර්ණ තිරයට යයි; `Super + Alt + F` සම්පූර්ණ පළලට යයි
- `Super + Ctrl + C` අල්ලා ගැනීමේ මෙනුව විවෘත කරයි; `Super + Ctrl + Alt + C` මෙනුව මඟ හරින අතර තිරපිටපතක් ගනියි

යතුරුපුවරු කෙටිමඟක් එක් කිරීමේදී:

1. එය කරන දෙය අනුව තලය තෝරන්න, ඉන්පසු යතුර තෝරන්න.
2. ඉඩ ලබා ගැනීම සඳහා පවතින යතුරුපුවරු කෙටිමඟක් ගෙන නොයන්න. නිවැරදි තලයේ නිදහස් යතුරක් සොයන්න.
3. `Alt` භාවිතා කරන්න එය නොමැති යතුරුපුවරු කෙටිමඟේ ප්‍රභේදයක් සඳහා පමණි.

යතුරුපුවරු කෙටිමං කිහිපයක් පහසුව සඳහා මෙම නීති කඩ කරයි. ඊතලයක් හෝ `Tab` සමඟ `Shift` යෙදුමක් විවෘත කිරීම වෙනුවට ගෙන යයි හෝ ආපසු හරවයි, එමෙන්ම `Print`, මාධ්‍ය යතුරු, `Alt + Tab` සහ `Ctrl + Alt + Del` අන් සෑම තැනකදීම මෙන් ක්‍රියා කරයි. ඒවා ව්‍යතිරේක මිස, පිටපත් කළ යුතු රටා නොවේ.

පෙරනිමියක් ඔබට නොගැලපේ නම් (උදාහරණයක් ලෙස Windows වල මෙන් තිරපිටපත් සඳහා `Super + Shift + S` ඔබට අවශ්‍ය නම්), එය `~/.config/hypr/bindings.lua` තුළ නැවත බඳින්න.
