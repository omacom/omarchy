# උණුසුම් යතුරු

ඔබට ප්‍රධාන යතුරු පුවරු බන්ධන සියල්ල `Super + K` සමඟින් දැකිය හැකිය (Tmux බන්ධන `Super + Alt + K` සමඟින් සහ Herdr බන්ධන `Super + Ctrl + K` සමඟින්).

## හොට්කී සකසා ඇති ආකාරය

සෑම හොට්කී එකක්ම එහි විකරණයන්ගෙන් සැකසෙන තලයක් මත පිහිටා ඇති අතර, සෑම තලයකටම එක කාර්යයක් ඇත. හොට්කී එකිනෙක අතර ගැටීමෙන් වළක්වා ගන්නේ එයයි, එයින් අදහස් වන්නේ යමක් සාමාන්‍යයෙන් කොහේ තිබේදැයි ඔබට අනුමාන කළ හැකි බවයි.

| තලය | එහි තිබෙන්නේ කුමක්ද | උදාහරණ |
| --- | --- | --- |
| `Super + key` | පද්ධතිය: කවුළු, වැඩබිම්, පිරිසැලසුම් සහ මූලික මෙනු | `Super + Space` Omarchy මෙනුව, `Super + W` කවුළුව වසන්න, `Super + F` සම්පූර්ණ තිරය |
| `Super + Shift + key` | යෙදුම් | `Super + Shift + B` බ්‍රවුසරය, `Super + Shift + E` ඊමේල්, `Super + Shift + N` සංස්කාරකය |

| `Super + Ctrl + Alt + key` | ඉක්මන් ක්‍රියා සහ දැන්වීම් | `Super + Ctrl + Alt + T` වේලාව පෙන්වන්න, `Super + Ctrl + Alt + B` බැටරිය, `Super + Ctrl + Alt + C` තිර රුව |

හොට්කී එකකට `Alt` එක් කිරීමෙන් ඔබට ලැබෙන්නේ එම දෙයේම ප්‍රභේදයක් මිස, සම්බන්ධයක් නැති කිසිවක් නොවේ:

- `Super + Shift + B` බ්‍රවුසරය විවෘත කරයි; `Super + Shift + Alt + B` පුද්ගලික කවුළුවක් විවෘත කරයි
- `Super + Shift + E` ඊමේල් විවෘත කරයි; `Super + Shift + Alt + E` අලුත් එකක් ආරම්භ කරයි
- `Super + F` සම්පූර්ණ තිරයට යයි; `Super + Alt + F` සම්පූර්ණ පළලට යයි
- `Super + Ctrl + C` අල්ලගැනීමේ මෙනුව විවෘත කරයි; `Super + Ctrl + Alt + C` මෙනුව මඟ හැර තිර රුවක් ගනියි

හොට්කී එකක් එක් කරන විට:

1. එය කරන දෙය අනුව තලය තෝරන්න, ඉන්පසු යතුර තෝරන්න.
2. ඉඩ ලබා ගැනීම සඳහා පවතින හොට්කී එකක් ගෙන නොයන්න. නිවැරදි තලය මත නිදහස් යතුරක් සොයන්න.
3. එය නැති හොට්කී එකේ ප්‍රභේදයක් සඳහා පමණක් `Alt` භාවිත කරන්න.

හොට්කී කිහිපයක් පහසු නිසා මෙම නීති කඩ කරයි. ඊතලයක් හෝ `Tab` සමඟ `Shift` යනු යෙදුමක් විවෘත කරනවා වෙනුවට ගෙන යාම හෝ ආපසු හැරවීම වන අතර, `Print`, මාධ්‍ය යතුරු, `Alt + Tab` සහ `Ctrl + Alt + Del` අනෙක් සෑම තැනකම මෙන්ම ක්‍රියා කරයි. ඒවා ව්‍යතිරේකයන් මිස, පිටපත් කළ යුතු රටා නොවේ.

පෙරනිමියක් ඔබට නොගැලපේ නම් (උදාහරණයක් ලෙස Windows මත මෙන් තිර රූ සඳහා ඔබට `Super + Shift + S` අවශ්‍යයි යැයි කියමු), එය `~/.config/hypr/bindings.lua` තුළ නැවත බඳින්න.

ප්‍රමාණය වෙනස් කිරීමේ කෙටිමං භෞතික යතුරු `code:20` සහ `code:21` (XKB `<AE11>` සහ `<AE12>`) භාවිත කරයි, යතුරු පුවරුව මත මුද්‍රණය කර ඇති අක්ෂර මොනවාද යන්න නොසලකා. US යතුරු පුවරු මත මෙම යතුරු `-` සහ `=`; ජපන් (JIS) යතුරු පුවරු මත ඒවා `-` සහ `^`; ස්පාඤ්ඤ යතුරු පුවරු මත ඒවා `'` සහ `¡`. JIS මත, `Super + ^` යනු `Super + Equal` වන අතර, `Super + Shift + -` (එය `=` ටයිප් කරයි) යනු `Super + Shift + Minus` වේ.
