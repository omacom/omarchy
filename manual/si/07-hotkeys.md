# යතුරු කෙටිමං

ඔබට සියලුම ප්‍රධාන යතුරුපුවරු බැඳීම් `Super + K` සමඟින් දැකිය හැකිය (Tmux බැඳීම් `Super + Alt + K` සමඟින් සහ Herdr බැඳීම් `Super + Ctrl + K` සමඟින්).
