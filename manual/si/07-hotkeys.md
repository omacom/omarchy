# හොට්කීස්

ප්‍රධාන යතුරුපුවරු බන්ධන සියල්ල `Super + K` සමඟින් ඔබට දැකිය හැකිය (Tmux බන්ධන `Super + Alt + K` සමඟින් ද Herdr බන්ධන `Super + Ctrl + K` සමඟින් ද).
