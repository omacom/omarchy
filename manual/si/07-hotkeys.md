# කෙටිමං යතුරු

ඔබට සියලුම ප්‍රධාන යතුරුපුවරු බන්ධන `Super + K` සමඟින් දැකිය හැකිය (Tmux බන්ධන `Super + Alt + K` සමඟින් සහ Herdr බන්ධන `Super + Ctrl + K` සමඟින්).

## කෙටිමං යතුරු සකසා ඇති ආකාරය

සෑම කෙටිමං යතුරක්ම එහි modifiers අනුව තීරණය වන තලයක පිහිටා ඇති අතර, සෑම තලයකටම එක කාර්යයක් ඇත. කෙටිමං යතුරු එකිනෙක අතර දියවී යාම වළක්වන්නේ එයයි, එසේම සාමාන්‍යයෙන් යමක් කොහෙදැයි ඔබට අනුමාන කළ හැකි වන්නේද එය නිසාමය.

| තලය | එහි ඇති දේ | උදාහරණ |
| --- | --- | --- |
| `Super + key` | පද්ධතිය: කවුළු, වැඩබිම්, පිරිසැලසුම්, සහ මූලික මෙනු | `Super + Space` Omarchy මෙනුව, `Super + W` කවුළුව වසන්න, `Super + F` පූර්ණ තිරය |
| `Super + Shift + key` | යෙදුම් | `Super + Shift + B` බ්‍රවුසරය, `Super + Shift + E` ඊමේල්, `Super + Shift + N` සංස්කාරකය |
| `Super + Ctrl + key` | පැනල සහ පද්ධති මෙනු | `Super + Ctrl + A` ශ්‍රව්‍ය, `Super + Ctrl + N` ජාලය, `Super + Ctrl + C` ග්‍රහණ මෙනුව |
| `Super + Ctrl + Alt + key` | ඉක්මන් ක්‍රියා සහ දැනුම්දීම් | `Super + Ctrl + Alt + T` වේලාව පෙන්වන්න, `Super + Ctrl + Alt + B` බැටරිය, `Super + Ctrl + Alt + C` තිර රුව |

කෙටිමං යතුරකට `Alt` එකතු කිරීමෙන් ඔබට ලැබෙන්නේ එම දෙයෙහිම ප්‍රභේදයක් මිස, සම්බන්ධයක් නැති වෙනත් දෙයක් නොවේ:

- `Super + Shift + B` බ්‍රවුසරය විවෘත කරයි; `Super + Shift + Alt + B` පෞද්ගලික කවුළුවක් විවෘත කරයි
- `Super + Shift + E` ඊමේල් විවෘත කරයි; `Super + Shift + Alt + E` නව එකක් ආරම්භ කරයි
- `Super + F` පූර්ණ තිරයට යයි; `Super + Alt + F` පූර්ණ පළලට යයි
- `Super + Ctrl + C` ග්‍රහණ මෙනුව විවෘත කරයි; `Super + Ctrl + Alt + C` මෙනුව මඟහැර තිර රුවක් ගනියි

කෙටිමං යතුරක් එක් කරන විට:

1. එය කරන දේ අනුව තලය තෝරන්න, ඉන්පසු යතුර තෝරන්න.
2. ඉඩ සෑදීම සඳහා පවතින කෙටිමං යතුරක් ගෙන නොයන්න. නිවැරදි තලය මත නිදහස් යතුරක් සොයන්න.
3. `Alt` භාවිතා කරන්න එය නොමැති කෙටිමං යතුරෙහි ප්‍රභේදයක් සඳහා පමණි.

පහසුතාව නිසා කෙටිමං යතුරු කිහිපයක් මෙම නීති කඩ කරයි. ඊතලයක් හෝ `Tab` සමඟ `Shift` යෙදීම යෙදුමක් විවෘත කිරීම වෙනුවට දෙයක් ගෙන යයි හෝ ක්‍රියාව ආපසු හරවයි, එමෙන්ම `Print`, මාධ්‍ය යතුරු, `Alt + Tab`, සහ `Ctrl + Alt + Del` අනෙක් සෑම තැනකම ක්‍රියා කරන ආකාරයටම ක්‍රියා කරයි. ඒවා ව්‍යතිරේක මිස, අනුගමනය කළ යුතු රටා නොවේ.

පෙරනිමියක් ඔබට නොගැලපේ නම් (උදාහරණයක් ලෙස Windows හි මෙන් තිර රූ සඳහා `Super + Shift + S` අවශ්‍ය නම්), එය `~/.config/hypr/bindings.lua` තුළ නැවත බඳින්න.

ප්‍රමාණය වෙනස් කිරීම සඳහා 0 ට දකුණින් ඇති යතුරු දෙක භාවිතා කරයි, ඔබේ යතුරුපුවරුව ඒවා මත මුද්‍රණය කර ඇත්තේ කුමක් වුවද: US යතුරුපුවරු මත `-` සහ `=`, ඩෙන්මාර්ක සහ ස්වීඩන් මත `+` සහ `´`, නෝර්වීජියානු මත `+` සහ `\`, ජර්මානු මත `ß` සහ `´`, ස්පාඤ්ඤ මත `'` සහ `¡`, සහ ජපන් (JIS) මත `-` සහ `^`. `Super + K` ඒවා ඔබේ යතුරුපුවරුව මුද්‍රණය කරන ආකාරයට ලැයිස්තුගත කරයි. JIS මත, `Super + ^` යනු `Super + Equal` වන අතර, `Super + Shift + -` (එය `=` ටයිප් කරයි) යනු `Super + Shift + Minus` වේ. මොනිටර පරිමාණය සහ මුරපද කළමනාකරු `/` භාවිතා කරයි; බොහෝ යුරෝපීය පිරිසැලසුම් මෙන් Shift සමඟ පමණක් `/` ටයිප් කරන පිරිසැලසුම් මත, ඒවා ඒ වෙනුවට දකුණු Shift එකට වමෙන් ඇති යතුර භාවිතා කරයි (ඩෙන්මාර්ක සහ ජර්මානු මත `-`).
