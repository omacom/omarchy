# යතුරු කෙටිමං

ඔබට `Super + K` සමඟ ප්‍රධාන යතුරුපුවරු බන්ධන සියල්ල දැකිය හැකිය (Tmux බන්ධන `Super + Alt + K` සමඟ සහ Herdr බන්ධන `Super + Ctrl + K` සමඟ).

## යතුරු කෙටිමං සකසා ඇති ආකාරය

සෑම යතුරු කෙටිමං එකක්ම එහි විකරණයන් අනුව තීරණය වන තලයක පිහිටා ඇති අතර, සෑම තලයකටම එක කාර්යයක් ඇත. යතුරු කෙටිමං එකිනෙක ගැටීම වළක්වන්නේ එය වන අතර, ඒ නිසා සාමාන්‍යයෙන් යමක් කොහි තිබේදැයි ඔබට අනුමාන කළ හැකිය.

| --- | --- | --- |
| `Super + key` | පද්ධතිය: කවුළු, වැඩබිම්, පිරිසැලසුම් සහ මූලික මෙනු | `Super + Space` Omarchy මෙනුව, `Super + W` කවුළුව වසන්න, `Super + F` සම්පූර්ණ තිරය |
| `Super + Shift + key` | යෙදුම් | `Super + Shift + B` බ්‍රවුසරය, `Super + Shift + E` ඊමේල්, `Super + Shift + N` සංස්කාරකය |
| `Super + Ctrl + key` | පැනල සහ පද්ධති මෙනු | `Super + Ctrl + A` ශ්‍රව්‍ය, `Super + Ctrl + N` ජාලය, `Super + Ctrl + C` අල්ලාගැනීමේ මෙනුව |
| `Super + Ctrl + Alt + key` | ඉක්මන් ක්‍රියා සහ දැනුම්දීම් | `Super + Ctrl + Alt + T` වේලාව පෙන්වන්න, `Super + Ctrl + Alt + B` බැටරිය, `Super + Ctrl + Alt + C` තිරපිටපත |

යතුරු කෙටිමං එකකට `Alt` එකතු කිරීමෙන් ඔබට ලැබෙන්නේ එම දෙයේම ප්‍රභේදයක් මිස, කිසිදා සම්බන්ධ නැති දෙයක් නොවේ:

- `Super + Shift + B` බ්‍රවුසරය විවෘත කරයි; `Super + Shift + Alt + B` පුද්ගලික කවුළුවක් විවෘත කරයි
- `Super + Shift + E` ඊමේල් විවෘත කරයි; `Super + Shift + Alt + E` අලුත් එකක් ආරම්භ කරයි
- `Super + F` සම්පූර්ණ තිරයට යයි; `Super + Alt + F` සම්පූර්ණ පළලට යයි
- `Super + Ctrl + C` අල්ලාගැනීමේ මෙනුව විවෘත කරයි; `Super + Ctrl + Alt + C` මෙනුව මඟහැර තිරපිටපතක් ගනියි

යතුරු කෙටිමං එකක් එකතු කිරීමේදී:

1. එය කරන දෙය අනුව තලය තෝරන්න, ඉන්පසු යතුර තෝරන්න.
2. ඉඩ ලබා ගැනීම සඳහා පවතින යතුරු කෙටිමං එකක් ගෙන නොයන්න. නිවැරදි තලයේ නිදහස් යතුරක් සොයන්න.
3. `Alt` භාවිතා කරන්න එය නොමැති යතුරු කෙටිමං එකේ ප්‍රභේදයක් සඳහා පමණි.

යතුරු කෙටිමං කිහිපයක් පහසුව නිසා මෙම නීති කඩ කරයි. ඊතලයක් හෝ `Tab` සමඟ `Shift` යෙදුමක් විවෘත කිරීම වෙනුවට ගෙන යයි හෝ ආපසු හරවයි, තවද `Print`, මාධ්‍ය යතුරු, `Alt + Tab`, සහ `Ctrl + Alt + Del` අනෙක් සෑම තැනකම මෙන්ම ක්‍රියා කරයි. ඒවා ව්‍යතිරේකයන් මිස අනුගමනය කළ යුතු රටා නොවේ.

පෙරනිමියක් ඔබට නොගැලපේ නම් (ඔබ Windows හි මෙන් තිරපිටපත් සඳහා `Super + Shift + S` අවශ්‍ය යැයි සිතමු), එය `~/.config/hypr/bindings.lua` තුළ නැවත බඳින්න.

ප්‍රමාණය වෙනස් කිරීම සඳහා 0 ට දකුණින් ඇති යතුරු දෙක භාවිතා කරයි, ඔබේ යතුරුපුවරුව ඒවා මත කුමක් මුද්‍රණය කර තිබුණත්: US යතුරුපුවරුවල `-` සහ `=`, ඩෙන්මාර්ක සහ ස්වීඩන් භාෂාවල `+` සහ `´`, නෝර්වීජියානු භාෂාවේ `+` සහ `\`, ජර්මානු භාෂාවේ `ß` සහ `´`, ස්පාඤ්ඤ භාෂාවේ `'` සහ `¡`, සහ ජපන් (JIS) භාෂාවේ `-` සහ `^`. `Super + K` ඒවා ඔබේ යතුරුපුවරුව මුද්‍රණය කරන ආකාරයට ලැයිස්තුගත කරයි. JIS හි, `Super + ^` යනු `Super + Equal` වන අතර, `Super + Shift + -` (එය `=` ටයිප් කරයි) යනු `Super + Shift + Minus` වේ. මොනිටර පරිමාණය සහ මුරපද කළමනාකරුව `/` භාවිතා කරයි; බොහෝ යුරෝපීය පිරිසැලසුම් මෙන් `/` Shift සමඟ පමණක් ටයිප් කරන පිරිසැලසුම්වල, ඒවා ඒ වෙනුවට දකුණු Shift එකට වමෙන් ඇති යතුර භාවිතා කරයි (ඩෙන්මාර්ක සහ ජර්මානු භාෂාවල `-`).
