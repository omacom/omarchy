# නිතර අසන ප්‍රශ්න

### යතුරුපුවරු පිරිසැලසුම් අතර මාරු වන්නේ කෙසේද?

ඔබේ `~/.config/hypr/input.lua` ගොනුව සංස්කරණය කර, `Left Alt + Right Alt` මඟින් පිරිසැලසුම් අතර මාරු වීමට මෙය එක් කරන්න:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

ඔබට පිරිසැලසුම් කිහිපයක් වින්‍යාස කර ඇති විට බාර්එක ඔබේ වත්මන් යතුරුපුවරු පිරිසැලසුම ස්වයංක්‍රීයව පෙන්වනු ඇත (එය ක්ලික් කර මාරු වීමටත් ඔබට හැක).

### ඔරලෝසු ආකෘතිය පැය 12 ආකෘතියට වෙනස් කරන්නේ කෙසේද?

පොදු ආකෘති අතර, පැය 12 ආකෘතිද ඇතුළුව, මාරු වීමට බාර්එකේ ඔරලෝසුව මත දකුණු-ක්ලික් කරන්න. ඔබට ආකෘතිය සෘජුවමද සැකසිය හැකිය:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

මෙය ඉරිදා 10:55 AM ලෙස පෙන්වනු ඇත.

### මගේ වේලා කලාපය වෙනස් කරන්නේ කෙසේද?

Omarchy මෙනුවේ _Update > Timezone_ ධාවනය කර ලැයිස්තුවෙන් තෝරන්න. වේලා කලාපය නිවැරදි වුවත් ඔරලෝසුවම ඉස්සරහට හෝ පස්සට ගොස් ඇත්නම්, _Update > Time_ ඔබ වෙනුවෙන් වේලාව සමමුහුර්ත කිරීම නැවත ආරම්භ කරයි.

### මගේ DNS වෙනස් කිරීම, මගේ Wi-Fi බෙදා ගැනීම, හෝ මගේ සම්බන්ධතා වේගය පරීක්ෂා කරන්නේ කෙසේද?

ඒ සියල්ල [ජාලකරණය](35-networking.md) තුළ ඇත.

### මගේ තැටිය කොතරම් වේගවත්දැයි පරීක්ෂා කරන්නේ කෙසේද?

_Trigger > Speed Test > Disk Speed Test_ ඔබේ ධාවකයේ සජීවී කියවීමේ සහ ලිවීමේ වේගය මනිනු ඇත, නැතහොත් ටර්මිනලයෙන් `omarchy disk speedtest` භාවිතා කරන්න.

### මුද්‍රණ යන්ත්‍රයක් එක් කරන්නේ කෙසේද?

මුද්‍රණය පෙට්ටියෙන් එළියට ගත් වහාම සකසා ක්‍රියා කරමින් පවතී, ඔබ එක් එක් මුද්‍රණ යන්ත්‍රය ඔබම එක් කරන්නේ යෙදුම් දියත් කරන්නාගේ (`Super + Space`) _Print Settings_ වෙතිනි.

_Add_ තෝරා, එය සොයන තෙක් මොහොතක් දෙන්න: USB හරහා සම්බන්ධ කළ මුද්‍රණ යන්ත්‍රයක් සහ බොහෝ ජාල මුද්‍රණ යන්ත්‍ර ඔබ වෙනුවෙන් සොයා ගනු ලැබේ. ඔබේ එක ලැයිස්තුවේ නැත්නම්, _Network Printer > Internet Printing Protocol (ipp)_ තෝරා එහි ලිපිනය ඇතුළත් කරන්න — එය කුමක්දැයි මුද්‍රණ යන්ත්‍රයේම තිරය හෝ එහි වෙබ් පිටුව ඔබට කියනු ඇත, සාමාන්‍යයෙන් `ipp/print` පෝලිමක් සහිත `192.168.1.50` වැනි දෙයක්. ඉන්පසු _Forward_ ධාවකයක් ලබා දෙන අතර, එහිදී නවීන මුද්‍රණ යන්ත්‍රයක් ධාවක රහිත _IPP Everywhere_ පැතිකඩ සමඟ හොඳින්ම ක්‍රියා කරන අතර පැරණි එකකට එම මාදිලියේම ධාවකය අවශ්‍ය වේ.

මුද්‍රණ යන්ත්‍රයක් මත දකුණු-ක්ලික් කර, ඔබේ යෙදුම් මුලින්ම ළඟා විය යුත්තේ කුමන එකටදැයි තේරීමට _Set as Default_ ද, කඩදාසි ප්‍රමාණය, duplex සහ ගුණාත්මකභාවය සැකසීමට _Properties_ ද තෝරන්න.

ජාලයේ මුද්‍රණ යන්ත්‍ර එක් නොකරම දිස්වන ස්වයංක්‍රීය සොයාගැනීම, එය නැවත වැඩ කරන අතරතුර තාවකාලිකව අක්‍රිය කර ඇත, එබැවින් ඉහත පළමු පියවර ස්වයංක්‍රීය නොව ඔබ විසින් කළ යුත්තකි. කිසිදු මුද්‍රණ යන්ත්‍රයක්ම නොමැතිව PDF ගොනුවකට මුද්‍රණය කිරීම ක්‍රියා කරයි.

### තිරපිටපත් හෝ තිරපටිගත කිරීම් සුරකින ස්ථානය වෙනස් කරන්නේ කෙසේද?

සුරකින ලද තිරපිටපත් පෙරනිමියෙන් `~/Pictures/Screenshots` වෙත යයි. වෙනත් නාමාවලියක් භාවිතා කිරීමට, `~/.config/uwsm/env.d/` යටතේ ඇති ගොනුවකට (`~/.config/uwsm/env.d/capture` වැනි) මෙය එක් කරන්න:

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

`OMARCHY_SCREENRECORD_DIR` භාවිතයෙන් තිරපටිගත කිරීම් සඳහාද ඔබට එසේම කළ හැකිය.

Omasnap එහි තිරපිටපත් නාමාවලිය ස්වයංක්‍රීයව නිර්මාණය කරයි. තිරපටිගත කිරීමේ නාමාවලිය ඔබම නිර්මාණය කරන්න, ඉන්පසු පරිසර වෙනස්කම් දෙකෙන් ඕනෑම එකක් ක්‍රියාත්මක වීමට Omarchy නැවත අරඹන්න.

### මගේ Apple Studio Display එකේ ස්පීකර් + වෙබ් කැමරාව ක්‍රියා කරවන්නේ කෙසේද?

USB C සම්බන්ධ කිරීමෙන්ම ඒ සියල්ල ක්‍රියා කරයි කියා ඔබට සිතෙනු ඇත, නමුත් අවාසනාවකට එය එසේ නොවේ. එය විශ්වාසදායක ලෙස ක්‍රියා කරවීමට මා සොයාගත් පිළියම වන්නේ [WJESOG DisplayPort + USB-A => USB-C කේබලය](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) භාවිතා කිරීමයි. එවිට ස්පීකර් සහ වෙබ් කැමරාව අපූරුවට ක්‍රියා කරයි.

සාමාන්‍ය යතුරුපුවරු දීප්තිය බොත්තම් භාවිතයෙන්, Apple Displays (Studio සහ XDR දෙකම) සඳහා Omarchy තුළම ගොඩනගා ඇති දීප්තිය පාලනය ඔබට ඇති බව මතක තබා ගන්න.

### සියලුම අමතර මෘදුකාංග ඉවත් කරන්නේ කෙසේද?

ඔබට Obsidian හෝ LibreOffice වැනි වැඩසටහන් හෝ වෙනත් පෙර ස්ථාපිත කිසිවක් අවශ්‍ය නැත්නම්, ඔබට ඒවා ඉතා පහසුවෙන් ඉවත් කළ හැකිය.

ස්ථාපිත සෑම පැකේජයක්ම බැලීමට _Remove > Package_ ධාවනය කරන්න. ඉන්පසු ඔබට ඉවත් කිරීමට අවශ්‍ය ඕනෑම පැකේජයක් tab මඟින් තෝරා, ඔබ තේරූ සියල්ල return මඟින් ඉවත් කිරීම ආරම්භ කළ හැකිය.

ඔබට අවශ්‍ය නැති පෙර ස්ථාපිත වෙබ් යෙදුම්වලින් ඕනෑම එකක් ඉවත් කිරීමට Omarchy මෙනුවෙන් _Remove > Web App_ ද භාවිතා කළ හැකිය.

නැතහොත් සියලුම පෙර ස්ථාපිත අමතර දෑ — වෙබ් යෙදුම්, TUIs සහ විකල්ප යෙදුම් — එකවර අතුගා දැමීමට _Remove > Preinstalls_ ධාවනය කරන්න. ඒවා දියත් කළ හොට්කී ඒ සමඟම ඉවත් වේ, එබැවින් `~/.config/hypr/bindings.lua` තුළ ඔබේම ඒවා යෙදීමට බන්ධනවල පිරිසිදු හිස් පිටුවක් ඔබට ඉතිරි වේ.
