# නිතර අසන ප්‍රශ්න (FAQ)

### යතුරුපුවරු පිරිසැලසුම් අතර මාරු වෙන්නේ කොහොමද?

ඔබේ `~/.config/hypr/input.lua` ගොනුව සංස්කරණය කර, `Left Alt + Right Alt` වලින් පිරිසැලසුම් අතර මාරු වෙන්න මෙය එක් කරන්න:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

ඔබ පිරිසැලසුම් කිහිපයක් වින්‍යාස කරගත් පසු බාර් එක ඔබේ වත්මන් යතුරුපුවරු පිරිසැලසුම ස්වයංක්‍රීයව පෙන්වයි (ඔබට එය ක්ලික් කර මාරු වෙන්නත් පුළුවන්).

### ඔරලෝසු ආකෘතිය පැය 12 ආකෘතියට වෙනස් කරන්නේ කොහොමද?

පැය 12 ආකෘති ඇතුළු පොදු ආකෘති අතර චක්‍රීයව මාරු වීමට බාර් එකේ ඔරලෝසුව මත දකුණු-ක්ලික් කරන්න. ඔබට ආකෘතිය කෙලින්ම සැකසියත් පුළුවන්:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

මෙය ඉරිදා 10:55 AM ලෙස පෙන්වයි.

### මගේ වේලා කලාපය වෙනස් කරන්නේ කොහොමද?

Omarchy මෙනුවේ _Setup > Region > Timezone_ ධාවනය කර ලැයිස්තුවෙන් තෝරන්න. වේලා කලාපය හරි වුණත් ඔරලෝසුවම අපගමනය වී ඇත්නම්, _Update > Time_ ඔබ වෙනුවෙන් වේලාව සමමුහුර්ත කිරීම නැවත ආරම්භ කරයි.

### මගේ DNS වෙනස් කරන්නේ, මගේ Wi-Fi බෙදා ගන්නේ, හෝ මගේ සම්බන්ධතා වේගය පරීක්ෂා කරන්නේ කොහොමද?

ඒ සියල්ල [ජාලකරණයේ](35-networking.md) ඇත.

### මගේ තැටිය කොච්චර වේගවත්ද කියලා පරීක්ෂා කරන්නේ කොහොමද?

_Trigger > Speed Test > Disk Speed Test_ ඔබේ ධාවකයේ සජීවී කියවීමේ සහ ලිවීමේ වේගය මනියි, නැත්නම් අන්තයෙන් `omarchy disk speedtest` භාවිතා කරන්න.

### මුද්‍රණ යන්ත්‍රයක් එක් කරන්නේ කොහොමද?

මුද්‍රණය මුල සිටම සැකසී ක්‍රියාත්මක වන අතර, ඔබ එක් එක් මුද්‍රණ යන්ත්‍රය යෙදුම් දියත් කරන්නාගේ (`Super + Alt + Space`) _Print Settings_ වෙතින් ඔබම එක් කරයි.

_Add_ තෝරා, එයට සොයන්න මොහොතක් දෙන්න: USB හරහා සවි කළ මුද්‍රණ යන්ත්‍රයක් සහ බොහෝ ජාල මුද්‍රණ යන්ත්‍ර ඔබ වෙනුවෙන් සොයා ගනු ලැබේ. ඔබේ එක ලැයිස්තුවේ නැත්නම්, _Network Printer > Internet Printing Protocol (ipp)_ තෝරා එහි ලිපිනය ඇතුළත් කරන්න — එය කුමක්ද කියා මුද්‍රණ යන්ත්‍රයේම සංදර්ශකය හෝ එහි වෙබ් පිටුව ඔබට කියනු ඇත, සාමාන්‍යයෙන් `192.168.1.50` වැනි එකක් වන අතර `ipp/print` නම් පෝලිමක් ඇත. ඉන්පසු _Forward_ ධාවකයක් ඉදිරිපත් කරයි, එහි නූතන මුද්‍රණ යන්ත්‍රයක් ධාවක රහිත _IPP Everywhere_ පැතිකඩින් හොඳින්ම වැඩ කරන අතර පැරණි එකකට එම මොඩලයේම ධාවකය අවශ්‍ය වේ.

මුද්‍රණ යන්ත්‍රයක් මත දකුණු-ක්ලික් කර, ඔබේ යෙදුම් මුලින්ම යොමු විය යුත්තේ කුමන එකටද කියා තෝරා ගැනීමට _Set as Default_ තෝරන්න, සහ කඩදාසි ප්‍රමාණය, duplex සහ ගුණාත්මකභාවය සැකසීමට _Properties_ තෝරන්න.

ජාලයේ මුද්‍රණ යන්ත්‍ර එක් නොකරම දිස්වන ස්වයංක්‍රීය සොයාගැනීම, එය නැවත සකසන අතරතුර තාවකාලිකව අක්‍රිය කර ඇති නිසා, ඉහත පළමු පියවර ස්වයංක්‍රීය නොවී ඔබේ වී ඇත. කිසිම මුද්‍රණ යන්ත්‍රයක් නැතුවම PDF ගොනුවකට මුද්‍රණය කිරීම වැඩ කරයි.

### තිරපිටපත් හෝ තිර පටිගත කිරීම් සුරැකෙන තැන වෙනස් කරන්නේ කොහොමද?

සුරැකෙන තිරපිටපත් පෙරනිමියෙන් `~/Pictures/Screenshots` වෙත යයි. වෙනත් නාමාවලියක් භාවිතා කිරීමට, `~/.config/uwsm/env.d/` යටතේ ඇති ගොනුවකට (`~/.config/uwsm/env.d/capture` වැනි) මෙය එක් කරන්න:

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

තිර පටිගත කිරීම් සඳහාත් `OMARCHY_SCREENRECORD_DIR` භාවිතා කර එසේම කළ පුළුවන්.

Omasnap එහි තිරපිටපත් නාමාවලිය ස්වයංක්‍රීයව සාදයි. තිර පටිගත කිරීමේ නාමාවලිය ඔබම සාදා, ඕනෑම පරිසර වෙනසක් ක්‍රියාත්මක වීමට Omarchy නැවත ආරම්භ කරන්න.

### මගේ Apple Studio Display එකේ ස්පීකර සහ වෙබ් කැමරාව වැඩ කරවන්නේ කොහොමද?

USB C එක සවි කළ පමණින් සියල්ල වැඩ කරයි කියා ඔබට හිතෙන්න පුළුවන්, නමුත් අවාසනාවකට එහෙම නැහැ. එය විශ්වාසදායක ලෙස වැඩ කරවීමට මට සොයාගත හැකි වූ විසඳුම වන්නේ [WJESOG DisplayPort + USB-A => USB-C කේබලය](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) භාවිතා කිරීමයි. එවිට ස්පීකර සහ වෙබ් කැමරාව අපූරුවට වැඩ කරයි.

සාමාන්‍ය යතුරුපුවරු දීප්ති බොත්තම් භාවිතා කරමින් Apple Displays (Studio සහ XDR දෙකම) සඳහා සාදන ලද දීප්ති පාලනය Omarchy තුළ ඔබට ඇති බව මතක තබා ගන්න.

### අමතර මෘදුකාංග සියල්ල ඉවත් කරන්නේ කොහොමද?

Obsidian හෝ LibreOffice හෝ වෙනත් පෙර ස්ථාපිත දේවල් වැනි වැඩසටහන් ඔබට එපා නම්, ඔබට ඒවා ඉතා පහසුවෙන් ඉවත් කළ පුළුවන්.

ස්ථාපිත සෑම පැකේජයක්ම බැලීමට _Remove > Package_ ධාවනය කරන්න. ඉන්පසු ඔබට tab යතුරින් ඉවත් කිරීමට අවශ්‍ය ඕනෑම පැකේජයක් තෝරා, return යතුරින් ඔබ තෝරාගත් සියල්ල ඉවත් කිරීම ආරම්භ කළ පුළුවන්.

ඔබට එපා වූ ඕනෑම පෙර ස්ථාපිත වෙබ් යෙදුමක් ඉවත් කිරීමට Omarchy මෙනුවෙන් _Remove > Web App_ භාවිතා කළ පුළුවන්.

නැත්නම් පෙර ස්ථාපිත අමතර දෑ සියල්ල — වෙබ් යෙදුම්, TUIs සහ විකල්ප යෙදුම් — එකවර අතුගා දැමීමට _Remove > Preinstalls_ ධාවනය කරන්න. ඒවා දියත් කළ හොට්කී ද ඒවා සමගම නැති වී යන නිසා, `~/.config/hypr/bindings.lua` තුළ ඔබේම ඒවායින් පුරවන්න පිරිසිදු බැඳීම් ලැයිස්තුවක් ඔබට ඉතිරි වේ.
