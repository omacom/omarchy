# නිතර අසන ප්‍රශ්න

### යතුරුපුවරු පිරිසැලසුම් අතර මාරු වන්නේ කෙසේද?

ඔබේ `~/.config/hypr/input.lua` ගොනුව සංස්කරණය කර `Left Alt + Right Alt` මඟින් පිරිසැලසුම් අතර මාරු වීමට මෙය එක් කරන්න:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

ඔබ පිරිසැලසුම් කිහිපයක් වින්‍යාස කළ පසු තීරුව ඔබේ වත්මන් යතුරුපුවරු පිරිසැලසුම ස්වයංක්‍රීයව පෙන්වනු ඇත (එමෙන්ම එය ක්ලික් කර මාරු වීමටද ඔබට හැකිය).

### ඔරලෝසු ආකෘතිය පැය 12 බවට වෙනස් කරන්නේ කෙසේද?

පැය 12 ඒවා ඇතුළුව පොදු ආකෘති අතර මාරු වීමට තීරුවේ ඇති ඔරලෝසුව මත දකුණු-ක්ලික් කරන්න. ඔබට ආකෘතිය සෘජුවමද සැකසිය හැකිය:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

මෙය ඉරිදා 10:55 AM ලෙස පෙන්වනු ඇත.

### මගේ වේලා කලාපය වෙනස් කරන්නේ කෙසේද?

Omarchy මෙනුවේ _Setup > Region > Timezone_ ක්‍රියාත්මක කර ලැයිස්තුවෙන් තෝරන්න. වේලා කලාපය නිවැරදි වුවත් ඔරලෝසුවම අපගමනය වී ඇත්නම්, _Update > Time_ ඔබ වෙනුවෙන් වේලාව සමමුහුර්ත කිරීම නැවත ආරම්භ කරයි.

### මගේ DNS වෙනස් කරන්නේ, මගේ Wi-Fi බෙදා ගන්නේ, හෝ මගේ සම්බන්ධතා වේගය පරීක්ෂා කරන්නේ කෙසේද?

ඒ සියල්ල [ජාලකරණය](35-networking.md) තුළ ඇත.

### මගේ තැටිය කොපමණ වේගවත්දැයි පරීක්ෂා කරන්නේ කෙසේද?

_Trigger > Speed Test > Disk Speed Test_ ඔබේ ධාවකයේ සජීවී කියවීමේ සහ ලිවීමේ වේගය මනිනු ඇත, නැතහොත් පර්යන්තයෙන් `omarchy disk speedtest` භාවිතා කරන්න.

### මුද්‍රණ යන්ත්‍රයක් එක් කරන්නේ කෙසේද?

මුද්‍රණය පෙට්ටියෙන් පිටතටම සකසා ක්‍රියාත්මක වන අතර, යෙදුම් දියත් කරන්නා (`Super + Space`) තුළ ඇති _Print Settings_ වෙතින් සෑම මුද්‍රණ යන්ත්‍රයක්ම ඔබ ඔබම එක් කරයි.

_Add_ තෝරන්න, එය සොයන තෙක් මොහොතක් දෙන්න: USB හරහා සම්බන්ධ කළ මුද්‍රණ යන්ත්‍රයක් සහ බොහෝ ජාල මුද්‍රණ යන්ත්‍ර ඔබ වෙනුවෙන් සොයා ගනු ලැබේ. ඔබේ එක ලැයිස්තුවේ නැත්නම්, _Network Printer > Internet Printing Protocol (ipp)_ තෝරා එහි ලිපිනය ඇතුළත් කරන්න — මුද්‍රණ යන්ත්‍රයේම සංදර්ශකය හෝ එහි වෙබ් පිටුව එය කුමක්දැයි ඔබට කියනු ඇත, සාමාන්‍යයෙන් `192.168.1.50` වැනි දෙයක්, `ipp/print` නමැති පෝලිමක් සහිතව. එවිට _Forward_ ධාවකයක් ඉදිරිපත් කරයි, එහිදී නවීන මුද්‍රණ යන්ත්‍රයක් ධාවක රහිත _IPP Everywhere_ පැතිකඩ මත හොඳින්ම ක්‍රියා කරන අතර පැරණි එකකට එම මාදිලියේම ධාවකය අවශ්‍ය වේ.

මුද්‍රණ යන්ත්‍රයක් මත දකුණු-ක්ලික් කර ඔබේ යෙදුම් පළමුව ළඟා විය යුතු එක තේරීමට _Set as Default_ තෝරන්න, කඩදාසි ප්‍රමාණය, duplex සහ ගුණාත්මකභාවය සැකසීමට _Properties_ තෝරන්න.

ජාලයේ ඇති මුද්‍රණ යන්ත්‍ර එක් නොකරම දිස්වන ස්වයංක්‍රීය සොයාගැනීම, එය නැවත වැඩ කෙරෙන අතරතුර තාවකාලිකව අක්‍රිය කර ඇති අතර, අන්න ඒ නිසා ඉහත පළමු පියවර ස්වයංක්‍රීය නොව ඔබේ අතින් කළ යුත්තකි. කිසිදු මුද්‍රණ යන්ත්‍රයක්ම නොමැතිව වුවද PDF ගොනුවකට මුද්‍රණය කිරීම ක්‍රියා කරයි.

### තිරපිටපත් හෝ තිර පටිගත කිරීම් සුරකින ස්ථානය වෙනස් කරන්නේ කෙසේද?

සුරකින ලද තිරපිටපත් පෙරනිමියෙන් `~/Pictures/Screenshots` වෙත යයි. වෙනත් නාමාවලියක් භාවිතා කිරීමට, `~/.config/uwsm/env.d/` යටතේ ඇති ගොනුවකට (`~/.config/uwsm/env.d/capture` වැනි) මෙය එක් කරන්න:

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

`OMARCHY_SCREENRECORD_DIR` භාවිතයෙන් තිර පටිගත කිරීම් සඳහාද ඔබට එසේ කළ හැකිය.

Omasnap එහි තිරපිටපත් නාමාවලිය ස්වයංක්‍රීයව සාදයි. තිර පටිගත කිරීමේ නාමාවලිය ඔබම සාදන්න, ඉන්පසු පරිසර වෙනස්කම් දෙකෙන් ඕනෑම එකක් ක්‍රියාත්මක වීමට Omarchy නැවත ආරම්භ කරන්න.

### මගේ Apple Studio Display එකේ ස්පීකර් + වෙබ් කැමරාව ක්‍රියා කරවන්නේ කෙසේද?

USB C සම්බන්ධ කළ පමණින් ඒ සියල්ල ක්‍රියා කළ යුතු යැයි ඔබ සිතනු ඇත, නමුත් අවාසනාවකට එය එසේ නොවේ. එය විශ්වාසදායක ලෙස ක්‍රියා කරවීමට මා සොයාගත් විසඳුම වන්නේ [the WJESOG DisplayPort + USB-A => USB-C cable](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) භාවිතා කිරීමයි. එවිට ස්පීකර් සහ වෙබ් කැමරාව කිසිම කරදරයක් නැතිව ක්‍රියා කරයි.

සාමාන්‍ය යතුරුපුවරු දීප්ති බොත්තම් භාවිතයෙන් Apple Displays (Studio සහ XDR දෙකම) සඳහා දීප්තිය පාලනය කිරීම Omarchy තුළම ඇති බව මතක තබා ගන්න.

### අමතර මෘදුකාංග සියල්ල ඉවත් කරන්නේ කෙසේද?

Obsidian හෝ LibreOffice හෝ වෙනත් පෙර ස්ථාපිත දේවල් වැනි වැඩසටහන් ඔබට එපා නම්, ඔබට ඒවා ඉතා පහසුවෙන් ඉවත් කළ හැකිය.

ස්ථාපිත සෑම පැකේජයක්ම බැලීමට _Remove > Package_ ක්‍රියාත්මක කරන්න. ඉන්පසු tab මඟින් ඔබට ඉවත් කිරීමට අවශ්‍ය ඕනෑම පැකේජයක් තෝරාගත හැකි අතර, return මඟින් ඔබ තෝරාගත් සියල්ල ඉවත් කිරීම ආරම්භ කළ හැකිය.

ඔබට අවශ්‍ය නැති පෙර ස්ථාපිත වෙබ් යෙදුම් කිසිවක් ඉවත් කිරීමට Omarchy මෙනුවෙන් _Remove > Web App_ ද භාවිතා කළ හැකිය.

නැතහොත් පෙර ස්ථාපිත අමතර සියල්ල — වෙබ් යෙදුම්, TUIs සහ විකල්ප යෙදුම් — එකවර අතුගා ඉවත් කිරීමට _Remove > Preinstalls_ ක්‍රියාත්මක කරන්න. ඒවා දියත් කළ හොට්කී ද ඒවා සමඟම ඉවත් වන බැවින්, `~/.config/hypr/bindings.lua` තුළ ඔබේම ඒවා පුරවා ගැනීමට පිරිසිදු බන්ධන පුවරුවක් ඔබට ඉතිරි වේ.
