# නිතර අසන ප්‍රශ්න

### මම යතුරුපුවරු සැකැස්ම අතර මාරු වන්නේ කෙසේද?

ඔබේ `~/.config/hypr/input.lua` ගොනුව සංස්කරණය කර `Left Alt + Right Alt` හි සැකැස්ම අතර මාරු වීමට මෙය එක් කරන්න:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

ඔබ සැකසූ සැකැස්ම කිහිපයක් තිබූ විට තීරුව ඔබේ වත්මන් යතුරුපුවරු සැකැස්ම ස්වයංක්‍රීයව පෙන්වනු ඇත (ඔබට එය ක්ලික් කර මාරු වීමටද හැකිය).

### මම ඔරලෝසු ආකෘතිය පැය 12ට වෙනස් කරන්නේ කෙසේද?

පැය 12 ආකෘති ඇතුළුව පොදු ආකෘති හරහා චක්‍ර කිරීමට තීරුවේ ඔරලෝසුව දකුණු-ක්ලික් කරන්න. ඔබට ආකෘතිය කෙලින්ම ද සැකසිය හැකිය:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

මෙය Sunday 10:55 AM ලෙස පෙන්වනු ඇත.

### මම මගේ වේලා කලාපය වෙනස් කරන්නේ කෙසේද?

Omarchy මෙනුවේ _යාවත්කාලීන > වේලා කලාපය_ ක්‍රියාත්මක කර ලැයිස්තුවෙන් තෝරන්න. වේලා කලාපය නිවැරදි නමුත් ඔරලෝසුවම අපතේ ගොස් ඇත්නම්, _යාවත්කාලීන > වේලාව_ ඔබ වෙනුවෙන් වේලා සමමුහුර්තකරණය නැවත අරඹයි.

### මම මගේ DNS වෙනස් කරන්නේ, මගේ Wi-Fi බෙදා ගන්නේ, හෝ මගේ සම්බන්ධතා වේගය පරීක්ෂා කරන්නේ කෙසේද?

ඒ සියල්ල [ජාලකරණය](35-networking.md) හි ජීවත් වේ.

### මගේ තැටිය කොතරම් වේගවත්දැයි මම පරීක්ෂා කරන්නේ කෙසේද?

_ක්‍රියාත්මක > වේග පරීක්ෂණය > තැටි වේග පරීක්ෂණය_ ඔබේ ධාවකයේ සජීවී කියවීමේ සහ ලිවීමේ වේගය මනියි, නැතහොත් ටර්මිනලයෙන් `omarchy disk speedtest`.

### මට Chromium හි මගේ Google ගිණුමට පුරනය විය නොහැකි ඇයි?

සරල විවෘත මූලාශ්‍ර Chromium ගොඩනැගීම Google ගිණුම් පුරනය වීම සඳහා අවශ්‍ය කරන OAuth අක්තපත්‍ර සමඟ පැමිණෙන්නේ නැත. ඒවා එක් කිරීමට Omarchy මෙනුවේ _ස්ථාපනය > සේවා > Chromium Account_ ක්‍රියාත්මක කරන්න, බ්‍රවුසරය නැවත අරඹන්න, සහ පුරනය වීම සිදු වනු ඇත.

### මම මුද්‍රණ යන්ත්‍රයක් එක් කරන්නේ කෙසේද?

මුද්‍රණය කෙලින්ම සකසා ක්‍රියාත්මක වේ, ඔබ සෑම මුද්‍රණ යන්ත්‍රයක්ම යෙදුම් දියත්කරණියේ (`Super + Space`) _Print Settings_ වෙතින් ඔබම එක් කරයි.

_Add_ තෝරන්න, සහ බැලීමට මොහොතක් දෙන්න: USB හරහා සම්බන්ධ කර ඇති මුද්‍රණ යන්ත්‍රයක්, සහ බොහෝ ජාල මුද්‍රණ යන්ත්‍ර, ඔබ වෙනුවෙන් සොයා ගනු ලැබේ. ඔබේ එක ලැයිස්තුවේ නැතහොත්, _Network Printer > Internet Printing Protocol (ipp)_ තෝරා එහි ලිපිනය ඇතුළත් කරන්න — මුද්‍රණ යන්ත්‍රයේම සංදර්ශකය හෝ එහි වෙබ් පිටුව එය කුමක්දැයි ඔබට කියනු ඇත, සාමාන්‍යයෙන් `ipp/print` පෝලිමක් සමඟ `192.168.1.50` වැනි දෙයක්. _Forward_ පසුව ධාවකයක් පිරිනමයි, එහි නවීන මුද්‍රණ යන්ත්‍රයක් ධාවක රහිත _IPP Everywhere_ පැතිකඩ මත හොඳින්ම ක්‍රියා කරන අතර පැරණි එකකට මාදිලියේම ධාවකය අවශ්‍ය වේ.

ඔබේ යෙදුම් මුලින්ම ළඟා වන්නේ කුමන එකටදැයි තේරීමට මුද්‍රණ යන්ත්‍රයක් දකුණු-ක්ලික් කර _Set as Default_ තෝරන්න, සහ කඩදාසි ප්‍රමාණය, ඩුප්ලෙක්ස් සහ ගුණාත්මකභාවය සැකසීමට _Properties_.

ජාලයේ මුද්‍රණ යන්ත්‍ර එකතු නොකර දිස්වෙන ස්වයංක්‍රීය සොයාගැනීම, එය නැවත සකසන අතරතුර තාවකාලිකව අක්‍රිය කර ඇත, එයට හේතුව ඉහත පළමු පියවර ස්වයංක්‍රීය වෙනුවට ඔබේම වීමයි. කිසිදු මුද්‍රණ යන්ත්‍රයක් නැතිව PDF ගොනුවකට මුද්‍රණය කිරීම ක්‍රියා කරයි.

### තිර රූ හෝ තිර පටිගත කිරීම් සුරකින ස්ථානය මම වෙනස් කරන්නේ කෙසේද?

සුරකින ලද තිර රූ පෙරනිමියෙන් `~/Pictures/Screenshots` වෙත යයි. වෙනත් ඩිරෙක්ටරියක් භාවිතා කිරීමට, මෙය `~/.config/uwsm/env.d/` යටතේ ගොනුවකට එක් කරන්න (`~/.config/uwsm/env.d/capture` වැනි):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

`OMARCHY_SCREENRECORD_DIR` භාවිතා කර තිර පටිගත කිරීම් සඳහා ද ඔබට එසේ කළ හැකිය.

Omasnap එහි තිර රූ ඩිරෙක්ටරිය ස්වයංක්‍රීයව සාදයි. තිර පටිගත කිරීමේ ඩිරෙක්ටරිය ඔබම සාදන්න, පසුව පරිසර වෙනස්කම් දෙකෙන් එකක් ක්‍රියාත්මක වීමට Omarchy නැවත අරඹන්න.

### මගේ Apple Studio Display හි ස්පීකර් + වෙබ්කැමය ක්‍රියා කරවන්නේ කෙසේද?

USB C සම්බන්ධ කිරීමෙන් පමණක් සියල්ල ක්‍රියා කළ යුතු යැයි ඔබ සිතනු ඇත, නමුත් අවාසනාවකට එසේ නොවේ. එය විශ්වාසදායී ලෙස ක්‍රියා කරවීමට මට හමු වූ විසඳුම [WJESOG DisplayPort + USB-A => USB-C කේබලය](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) භාවිතා කිරීමයි. පසුව ස්පීකර් සහ වෙබ්කැමය ඉන්ද්‍රජාලයක් මෙන් ක්‍රියා කරයි.

සාමාන්‍ය යතුරුපුවරු දීප්තිමත් බොත්තම් භාවිතා කර Apple Displays (Studio සහ XDR දෙකම) සඳහා Omarchy හි ඔබට බිල්ට්-ඉන් දීප්තිමත් පාලනයක් ඇති බව මතක තබා ගන්න.

### අතිරේක මෘදුකාංග සියල්ල ඉවත් කරන්නේ කෙසේද?

ඔබට Obsidian හෝ LibreOffice හෝ වෙනත් පෙර ස්ථාපනය කරන ලද දේවල් වැනි වැඩසටහන් අවශ්‍ය නැතහොත්, ඔබට එය ඉතා පහසුවෙන් ඉවත් කළ හැකිය.

ස්ථාපනය කර ඇති සෑම පැකේජයක්ම බැලීමට _ඉවත් කරන්න > පැකේජය_ ක්‍රියාත්මක කරන්න. පසුව ඔබට tab මගින් ඉවත් කිරීමට අවශ්‍ය ඕනෑම පැකේජයක් තෝරා ගත හැකි අතර, return මගින් ඔබ තෝරාගත් සියල්ල ඉවත් කිරීම ආරම්භ කළ හැකිය.

තවද ඕනෑම පෙර ස්ථාපනය කරන ලද වෙබ් යෙදුම් ඔබට අවශ්‍ය නැතහොත් ඉවත් කිරීමට ඔබට Omarchy මෙනුවෙන් _ඉවත් කරන්න > වෙබ් යෙදුම_ භාවිතා කළ හැකිය.

නැතහොත් පෙර ස්ථාපනය කරන ලද සියලු අතිරේක — වෙබ් යෙදුම්, TUIs, සහ විකල්ප යෙදුම් — එකවරම ඉවත් කිරීමට _ඉවත් කරන්න > පෙර ස්ථාපනයන්_ ක්‍රියාත්මක කරන්න. ඒවා දියත් කළ හොට්කී ඒවා සමඟ අතුරුදන් වේ, එබැවින් `~/.config/hypr/bindings.lua` හි ඔබේම ඒවා පුරවා ගැනීමට ශුද්ධ බන්ධන පුවරුවක් ඔබට ඉතිරි වේ.
