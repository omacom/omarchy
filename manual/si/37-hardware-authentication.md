# දෘඪාංග සත්‍යාපනය

### ඇඟිලි සලකුණු සත්‍යාපනය

ලැප්ටොප් පරිගණක බොහොමයක් සත්‍යාපනය කිරීමට ඇඟිලි සලකුණු සංවේදකයක් සමඟ එයි. Omarchy මෙනුව තුළ (`Super + Space`) _Setup > Security > Fingerprint_ ධාවනය කිරීමෙන් ඔබට Omarchy සමඟ මෙය භාවිතා කළ හැකිය.

එය ඇඟිලි සලකුණු පැකේජය ස්ථාපනය කර, ඔබේ ඇඟිලි සලකුණ ලබාගෙන, එය සත්‍යාපනය කරනු ඇත, එවිට අගුළු තිරයෙන් අගුළු හැරීමට (ඔබට `Super + Ctrl + L` සමඟ එය ක්‍රියාරම්භ කළ හැකිය), sudo ප්‍රකාරයට ඇතුළු වීමට සහ පද්ධති විමසුම් අනුමත කිරීමට ඔබේ ඇඟිලි සලකුණ භාවිතා කිරීමට ඔබට සූදානම් වනු ඇත.

අගුළු තිරය ප්‍රදර්ශනය අක්‍රිය කළ පසු, සංවේදකය විදුලිය ඉතිරි කරගැනීම සඳහා විවේක ගනී, එබැවින් එය ස්පර්ශ කිරීමට පෙර ඕනෑම යතුරකින් හෝ ටච්පෑඩයෙන් තිරය අවදි කරන්න.

ඔබේ ලැප්ටොප් පරිගණකයේ පියන වසා ඇති විට, ඇඟිලි සලකුණු විමසුම ස්වයංක්‍රීයව මඟ හැරේ, එබැවින් ඔබට ළඟා විය නොහැකි සංවේදකයක් එනතුරු බලා නොසිට කෙලින්ම මුරපද විමසුමට යා හැකිය. නොඑසේනම් ඔබට සංවේදකයක් නැති බාහිර යතුරු පුවරුවක වැඩ කිරීමට අවශ්‍ය නම්, `sudo` අතරතුර ඔබේ ඇඟිලි සලකුණ සඳහා විමසන විට `CTRL + C` ඔබන්න පමණි.

Omarchy මෙනුව තුළ _Remove > Security > Fingerprint_ යටතේ ඔබට ඇඟිලි සලකුණු සත්‍යාපනය ඉවත් කළ හැකිය.

### Fido2 සත්‍යාපනය

ඔබ Fido2 උපාංගයක් භාවිතා කරන්නේ නම්, Omarchy මෙනුව තුළ (`Super + Space`) _Setup > Security > Fido2_ භාවිතා කිරීමෙන් ඔබට `sudo` සත්‍යාපනය සඳහා එය සැකසිය හැකිය. කෙසේවෙතත් එය ඔබේ පරිගණකයේ අගුළු හැරීම නොව, `sudo` සහ පද්ධති අනුමැති විමසුම් ආවරණය කරයි.

Omarchy මෙනුව තුළ _Remove > Security > Fido2_ යටතේ ඔබට fido2 සත්‍යාපනය ඉවත් කළ හැකිය.
