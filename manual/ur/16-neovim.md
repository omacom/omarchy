# Neovim

[Neovim](https://neovim.io/) [vi ایڈیٹر](<https://en.wikipedia.org/wiki/Vi_(text_editor)>) کا ایک جدید نفاذ ہے، جسے Bill Joy نے آج سے کہیں پہلے، 1976 میں بنایا تھا۔ یہ ایک موڈل ایڈیٹر ہے جس میں insert موڈ اور command موڈ الگ الگ ہوتے ہیں، اور جب آپ اس کے ناقابلِ یقین حد تک گہرے key کمانڈ سیٹ کا ایک چھوٹا سا حصہ بھی سیکھ لیں تو یہ کسی سپر پاور سے کم نہیں لگتا۔ لیکن اسے سیکھنے کا راستہ بھی واقعی کافی مشکل ہے!

اگر آپ vim طرز کی ایڈیٹنگ میں بالکل نئے ہیں تو میری تجویز ہے کہ YouTube پر [ThePrimeagen کی Vim As Your Editor سیریز](https://www.youtube.com/watch?v=X6AR2RMB5tE&list=PLm323Lc7iSW_wuxqmKx_xxNtJC_hJbQ7R) ضرور دیکھیں۔ اس سے آپ کو بنیادی باتیں سمجھ آ جائیں گی۔ بس یہ جان لیں کہ زیادہ مانوس مین اسٹریم ایڈیٹرز کے برعکس، vim میں بنیادی مہارت حاصل کرنے میں آپ کو زیادہ وقت لگے گا۔ لیکن جب آپ اسے سیکھ لیں گے تو فائدہ بھی اتنا ہی بڑا ہوگا۔

اب Neovim بنیادی طور پر لامحدود حد تک قابلِ ترتیب ہے۔ اگر آپ واقعی حد ہی کر دینا چاہتے ہیں تو آپ اپنی Neovim کنفیگریشن شروع سے خود بنا سکتے ہیں۔ [Typecraft کا Neovim کو شروع سے سیٹ اپ کرنے کا بہترین کورس](https://www.youtube.com/watch?v=zHTeCSVAFNY) موجود ہے۔ اور [ThePrimeagen کا بھی ایک کورس ہے](https://www.youtube.com/watch?v=w7i4amO_zaE)۔

لیکن Omarchy ایک مکمل Neovim سیٹ اپ کے ساتھ آتا ہے — `omarchy-nvim` پیکج — جسے بڑی محبت سے اس طرح ترتیب دیا گیا ہے کہ آپ کو بغیر کنفیگریشن کی ایک بھی لائن لکھے، فوراً ہی بہترین ممکنہ تجربہ مل جائے۔ یہ [LazyVim](https://www.lazyvim.org/) پر مبنی ہے، جو Neovim پلگ انز اور کنفیگریشنز کی ایک ڈسٹری بیوشن ہے۔ یہ زبردست ہے۔

## LazyVim کی بنیادی باتیں

جیسا کہ بتایا، اس مختصر تعارف میں میں آپ کو vim نہیں سکھاؤں گا، لیکن LazyVim کی چند بنیادی باتیں اور اس میں اِدھر اُدھر جانے کا طریقہ ضرور دکھا سکتا ہوں۔

سب سے پہلے، Neovim میں لیڈر key کا تصور ہوتا ہے۔ یہ بنیادی طور پر تمام کمانڈز تک پہنچنے کا دروازہ ہے۔ LazyVim نے اسے `Space` پر سیٹ کیا ہے۔ تو بس اسے دبائیں، ایک لمحہ انتظار کریں، اور آپ کو اسی طرح ان لائن وضاحت کے ساتھ بہت سارے اختیارات نظر آئیں گے:

یہ چند بنیادی کمانڈز ہیں جو میں ہر وقت استعمال کرتا ہوں:

- `Space Space` - موجودہ ڈائریکٹری میں کوئی بھی فائل فزی طریقے سے تلاش کریں۔
- `Space S G` - پری ویو کے ساتھ grep استعمال کر کے تمام فائلیں تلاش کریں۔
- `Space E` - فائل ٹری کو آن/آف کریں۔
- `Ctrl + W W` - فائل ٹری سے ایڈیٹر اور واپس ایڈیٹر سے فائل ٹری تک جائیں۔
- `Shift + H` - کھلے ہوئے ٹیبز (vim انہیں buffers کہتا ہے) کے درمیان بائیں طرف جائیں۔
- `Shift + L` - کھلے ہوئے ٹیبز کے درمیان دائیں طرف جائیں۔
- `Space B D` - ایک ٹیب بند کریں۔
- `Space B O` - موجودہ ٹیب کے سوا تمام دوسرے ٹیبز بند کریں۔
- `Space G G` - موجودہ ڈائریکٹری سے ایک فلوٹنگ پین میں LazyGit شروع کریں۔
- `Space U W` - سوفٹ ریپ کو آن/آف کریں۔

جب آپ فائل ٹری میں ہوں (اسے ظاہر کرنے کے لیے `Space E`، وہاں جانے کے لیے `Ctrl + W W`)، تو آپ `a` سے نئی فائل یا `A` سے نئی ڈائریکٹری شامل کر سکتے ہیں۔ ٹری میں ہوتے ہوئے تمام کمانڈز دیکھنے کے لیے `?` دبائیں۔

اگر آپ بنیادی vim زبان سیکھنا چاہتے ہیں تو میں نے [اس تین حصوں والے نحو](https://world.hey.com/dhh/wonderful-vi-a1d034d3) کے بارے میں اور یہ کہ وہ شاندار کمبو چالیں کیسے چلائی جاتی ہیں، اس پر لکھا ہے!

آپ تمام ممکنہ کمانڈز [LazyVim Keymaps صفحے](https://www.lazyvim.org/keymaps) پر دیکھ سکتے ہیں۔

## Neovim شروع کرنا

`Super + Shift + N` آپ کا ڈیفالٹ ایڈیٹر شروع کرتا ہے، جو نئی انسٹالیشنز پر Plain ہوتا ہے؛ اس کے بجائے Neovim شروع کرنے کے لیے _Setup > Defaults > Editor_ میں Neovim منتخب کریں۔ لیکن اسے ٹرمینل سے چلانا عام طور پر آسان ہوتا ہے: جس ڈائریکٹری میں آپ کام کرنا چاہتے ہیں وہاں جائیں اور `n` لکھیں۔ `n`، `nvim` کا ایلیاس ہے، جو بطورِ ڈیفالٹ موجودہ ڈائریکٹری کو کھولے گا۔ آپ `n myfile.txt` کے ساتھ ایک فائل بھی کھول سکتے ہیں۔

## sudo ایڈٹس کے لیے Neovim استعمال کرنا

اگر آپ کو ایسی فائلیں ایڈٹ کرنی ہوں جنہیں آپ صرف سپر یوزر کے طور پر تبدیل کر سکتے ہیں تو `sudoedit /etc/sudoers.d/00-sudo-only-file` چلائیں۔ یہ آپ کا ڈیفالٹ ایڈیٹر کھولتا ہے، اس لیے اگر آپ وہاں اپنے تمام پلگ انز کے ساتھ Neovim چاہتے ہیں تو _Setup > Defaults > Editor_ میں Neovim سیٹ کر دیں۔
