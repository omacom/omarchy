# پرامپٹ

Omarchy طے شدہ طور پر ایک سادہ [Starship](https://starship.rs/) پرامپٹ کے ساتھ آتا ہے۔ مجھے اپنا پرامپٹ اسی طرح رکھنا پسند ہے۔ مجھے صارف جاننے کی ضرورت نہیں، کیونکہ یہ ہمیشہ میں ہی ہوتا ہوں، اور مجھے وقت جاننے کی ضرورت نہیں، کیونکہ یہ ہمیشہ اوپر ہوتا ہے۔

 ![prompt](images/prompt.webp)

اگر آپ کو مزید معلومات یا اسٹائل چاہیے تو آپ `~/.config/starship.toml` میں [Starship.rs](https://starship.rs/) کی کنفگریشن بدل سکتے ہیں۔ بہت کچھ کر سکتے ہیں آپ۔ بس حد سے نہ بڑھیں (یا حد سے بڑھ جائیں، جو چاہیں کریں، یہ آپ کا کمپیوٹر ہے!)
