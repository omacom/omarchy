# متحدہ کلپ بورڈ اور تاریخ

عام طور پر Linux پر، آپ کو ٹرمینل میں کاپی اینڈ پیسٹ کرنے کے لیے `Ctrl + Shift + C/V` اور ہر دوسری جگہ ایسا کرنے کے لیے `Ctrl + C/V` کی ضرورت ہوتی ہے۔ اس کی عادت ڈالنا اس شخص کے لیے مشکل ہے جو Linux پر پیدا اور پرورش نہیں پایا! اسی طرح super سے ctrl کی طرف جانا بھی، اگر آپ Mac سے آ رہے ہیں۔

Omarchy دونوں مسائل کو متحدہ کلپ بورڈ ہاٹ کیز کے ذریعے حل کرتا ہے جو (تقریباً) ہر جگہ کام کرتی ہیں۔ وہ یہ ہیں:

| ہاٹ کی | کمانڈ |
| ------- | ----------- |
| Super + C | کاپی |
| Super + X | کٹ |
| Super + V | پیسٹ |
| Super + Ctrl + V | کلپ بورڈ کی تاریخ |

_یاد رکھیں کہ زیادہ تر agent harnesses تصاویر چسپاں کرنے کے لیے `Ctrl + V` استعمال کریں گے، لیکن متن چسپاں کرنے کے لیے `Super + V` استعمال کریں گے۔_

### کلپ بورڈ کی تاریخ

کلپ بورڈ کی تاریخ Omarchy shell فراہم کرتا ہے اور یہ متن اور تصاویر دونوں کے لیے کام کرتا ہے۔ آپ اسے `Super + Ctrl + V` سے ٹرِگر کرتے ہیں، return کے ساتھ اپنا اندراج منتخب کرتے ہیں، اور پھر وہ کلپ بورڈ پر رکھا جائے گا جو `Super + V` پر پیسٹ ہونے کے لیے تیار ہو گا۔
