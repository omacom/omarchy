# متحد کلپ بورڈ اور ہسٹری

عام طور پر Linux پر، آپ کو ٹرمینل میں کاپی اینڈ پیسٹ کرنے کے لیے `Ctrl + Shift + C/V` اور ہر دوسری جگہ یہی کام کرنے کے لیے `Ctrl + C/V` استعمال کرنا پڑتا ہے۔ جس شخص نے Linux پر ہی آنکھ نہ کھولی ہو، اس کے لیے اس کی عادت ڈالنا مشکل ہے! اگر آپ Mac سے آ رہے ہیں تو super سے ctrl پر منتقل ہونا بھی اتنا ہی مشکل ہے۔

Omarchy ان دونوں مسائل کو متحد کلپ بورڈ ہاٹ کیز کے ساتھ حل کرتا ہے جو (تقریباً) ہر جگہ کام کرتی ہیں۔ وہ یہ ہیں:

| ہاٹ کی | کمانڈ |
| ------- | ----------- |
| Super + A | تمام منتخب کریں |
| Super + C | کاپی کریں |
| Super + X | کاٹیں |
| Super + V | پیسٹ کریں |
| Super + Ctrl + V | کلپ بورڈ ہسٹری |

_نوٹ کریں کہ زیادہ تر agent harnesses تصاویر پیسٹ کرنے کے لیے `Ctrl + V` استعمال کریں گے، لیکن متن پیسٹ کرنے کے لیے `Super + V` استعمال کریں گے۔_

کسی فوکس شدہ ٹیکسٹ فیلڈ یا کسی اور app میں، جو `Ctrl + A` کی حمایت کرتی ہو، سب کچھ کاپی کرنے کے لیے `Super + A` اور پھر `Super + C` استعمال کریں۔ ٹرمینل میں، `Ctrl + A` متن منتخب کرنے کے بجائے کمانڈ لائن کے آغاز پر لے جاتا ہے۔

### کلپ بورڈ ہسٹری

کلپ بورڈ ہسٹری Omarchy shell فراہم کرتا ہے اور یہ متن اور تصاویر دونوں کے لیے کام کرتی ہے۔ آپ اسے `Super + Ctrl + V` سے کھولتے ہیں اور return کے ساتھ اپنا اندراج منتخب کرتے ہیں، جو اسے سیدھا اسی app میں پیسٹ کر دیتا ہے جس میں آپ تھے۔ اسے صرف کلپ بورڈ پر کاپی کرنے کے لیے `Shift + Return`، اسے کھولنے کے لیے `Alt + Return`، اسے ہسٹری سے ہٹانے کے لیے `Delete` اور پوری ہسٹری صاف کرنے کے لیے `Shift + Delete` استعمال کریں۔
