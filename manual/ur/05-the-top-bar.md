# اوپری بار

آپ کی اسکرین کے اوپر والی پٹی Omarchy بار ہے۔ یہ اوپر سے لگایا ہوا اسٹیٹس بار نہیں بلکہ Omarchy shell کا حصہ ہے، وہ واحد طویل عرصے تک چلنے والا Quickshell عمل جو مینیو، نوٹیفکیشنز، OSD پاپ اپس اور لاک اسکرین بھی بناتا ہے۔ یہی وجہ ہے کہ یہ ہر چیز کے ساتھ بالکل تھیم لیتا ہے اور یہی وجہ ہے کہ پینل نئی ایپ شروع کرنے کے بجائے فوراً کھل جاتا ہے۔

یہ ڈیسک ٹاپ کا وہ واحد حصہ بھی ہے جو ہمیشہ اسکرین پر ہوتا ہے، لہٰذا یہ جاننا مفید ہے کہ وہ تمام چھوٹے نشانات (glyphs) کیا کرتے ہیں۔

## ڈیفالٹ کے طور پر اس پر کیا ہے

بار کے تین حصے ہیں۔ بائیں طرف Omarchy لوگو (مینیُو لانچر) اور ورک اسپیس اشارے ہیں۔ مرکز میں آپ کو اسٹیٹس اشارے، گھڑی، Elsewhen (ایک ورلڈ کلاک)، موسم اور Omarchy اپ ڈیٹ بیج ملتے ہیں۔ دائیں طرف: کی بورڈ لے آؤٹ (جب ایک سے زیادہ کنفیگر ہو)، سسٹم ٹرے، ایجنٹس، bluetooth، نیٹ ورک، آڈیو، ڈسپلے اور پاور۔

ان میں سے کچھ صرف اس وقت ظاہر ہوتے ہیں جب ان کے پاس کہنے کو کچھ ہو۔ کی بورڈ لے آؤٹ صرف اس صورت میں ظاہر ہوتا ہے اگر آپ نے ایک سے زیادہ لے آؤٹ کنفیگر کیا ہو۔ اپ ڈیٹ بیج صرف اس وقت ظاہر ہوتا ہے جب Omarchy اپ ڈیٹ منتظر ہو۔ اور ایجنٹس آئیکن پہلی بار تب ظاہر ہوتا ہے جب Omarchy کو مشین پر AI کوڈنگ کے استعمال کا پتہ چلتا ہے ([AI](17-ai.md) دیکھیں)۔

## ارد گرد کلک کرنا

تقریباً ہر وِجِٹ بائیں، دائیں اور درمیانی کلک پر کچھ کرتا ہے، اور کئی اسکرولنگ پر بھی رد عمل دیتے ہیں۔ یہی وہ حصہ ہے جو لوگوں سے رہ جاتا ہے — دائیں اور درمیانی بٹن وہ جگہ ہیں جہاں بہت سی اچھی چیزیں چھپی ہیں۔

| وِجِٹ | بایاں | دایاں | درمیانی / اسکرول |
| --- | --- | --- | --- |
| مینیُو | Omarchy مینیُو | نیا ٹرمینل | — |
| ورک اسپیسز | اس ورک اسپیس پر فوکس | — | اسکرول: اگلا/پچھلا ورک اسپیس |
| گھڑی | کیلنڈر پاپ اپ | لیبل فارمیٹ کا چکر | درمیانی: ٹائم زون منتخب کنندہ |
| موسم | پیشن گوئی پاپ اپ | مکمل موسم بطور نوٹیفکیشن | درمیانی: ریفریش |
| آڈیو | آڈیو پینل | خاموش (میوٹ) | درمیانی: پینل · اسکرول: والیوم |
| مائکروفون | مائک خاموش | — | درمیانی: آڈیو پینل · اسکرول: ان پٹ والیوم |
| نیٹ ورک | نیٹ ورک پینل | — | — |
| Bluetooth | Bluetooth پینل | ریڈیو ٹوگل | — |
| ڈسپلے | ڈسپلے پینل | — | اسکرول: چمک |
| پاور | پاور پینل | بیٹری فیصد ٹوگل | — |
| میڈیا | پلے/پاز | کور آرٹ پاپ اپ | درمیانی: اگلا · اسکرول: پچھلا/اگلا |
| ایجنٹس | ایجنٹس پینل | اپنا ایجنٹ لانچ کریں | درمیانی: اگلی سبسکرپشن |
| ٹرے | دراز ظاہر کرنے کے لیے ہوور | مینیج کرنے کے لیے شیوران پر دایاں | — |
| Omarchy اپ ڈیٹ | اپ ڈیٹ چلائیں | — | — |

اس جدول میں سب کچھ باکس سے باہر آپ کے بار پر نہیں ہے۔ میڈیا وِجِٹ (MPRIS نو پلےئنگ، اسکرولنگ ٹریک اور آرٹسٹ کے ساتھ) اور مائکروفون وِجِٹ دونوں بلٹ ان ہیں لیکن ڈیفالٹ کے طور پر بند ہیں — اگر آپ چاہتے ہیں تو انہیں شامل کریں، جیسا کہ نیچے بیان کیا گیا ہے۔

## پینلز

بار آئیکن پر کلک کرنے سے پینل کھلتا ہے، جو ٹول ٹِپ کے بجائے سلائیڈرز، فہرستوں اور کی بورڈ نیویگیشن کے ساتھ ایک بالکل اصل پاپ اپ ہے۔ ہر ایک کی ہاٹ کی بھی ہے، لہٰذا آپ کو کبھی بھی 16 پکسل نشان کا نشانہ نہیں لگانا پڑتا:

| ہاٹ کی | پینل |
| --- | --- |
| `Super + Ctrl + A` | آڈیو |
| `Super + Ctrl + W` | نیٹ ورک |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | ڈسپلے |
| `Super + Ctrl + P` | پاور |
| `Super + Ctrl + Alt + D` | کیلنڈر |
| `Super + Ctrl + Alt + E` | عالمی گھڑی |
| `Super + Ctrl + 1-9` | دائیں حصے میں n-واں پینل ٹوگل کریں |

پینلز صرف ریڈ آؤٹ نہیں ہیں۔ وہی وہ جگہ ہیں جہاں آپ واقعی کام کرتے ہیں:

- **آڈیو** میں ماسٹر والیوم سلائیڈر، آؤٹ پُٹ ڈیوائس منتخب کنندہ، اور فی ایپ مکسر ہے، تاکہ آپ ہر چیز کو چھوئے بغیر اس ایک براؤزر ٹیب کی آواز کم کر سکیں۔
- **نیٹ ورک** Wi-Fi کے لیے اسکین کرتا ہے، سگنل کی طاقت دکھاتا ہے، کنیکٹ کرتا ہے، اور آپ کو DNS فراہم کنندہ منتخب کرنے دیتا ہے۔
- **Bluetooth** آپ کے آلات کو کنیکٹ/ڈس کنیکٹ اور بیٹری لیولز کے ساتھ فہرست بند کرتا ہے۔
- **پاور** بیٹری کے اعداد و شمار دکھاتا ہے، پاور پروفائلز تبدیل کرتا ہے (یہ بیٹری اور AC کے لیے الگ انتخاب یاد رکھتا ہے)، اور کچھ سسٹم کی معلومات چھاپتا ہے۔
- **ڈسپلے** میں چمک کا سلائیڈر، متن کا سائز، مانیٹر اسکیلنگ پری سیٹ، اور — جب آپ کے پاس ایک سے زیادہ اسکرین ہو — فی مانیٹر کنٹرولز ہوتے ہیں۔ گہری کہانی کے لیے [مانیٹرز](33-monitors.md) دیکھیں۔
- **گھڑی** ISO ہفتوں کے اعداد اور مہینے کے آگے بڑھنے کے ساتھ ماہانہ گرڈ کھولتی ہے۔

ہر پینل ماؤس کے ساتھ کی بورڈ بھی لیتا ہے: تیر (arrows) حرکت کرتے ہیں، Return فعال کرتا ہے، Tab پڑوسی پینل کی طرف قدم رکھتا ہے، اور Escape بند کرتا ہے۔

`Super + Ctrl + 1-9` دائیں حصے میں پینلز کو بائیں سے دائیں گنتا ہے، ٹرے کو چھوڑ کر کیونکہ اس کا اپنا کوئی پینل نہیں۔ لہٰذا نمبر اس آئیکن سے ملتا ہے جس کی طرف آپ اشارہ کریں گے۔

### Tailscale اور Dropbox

دو مزید وِجِٹس بار پر تبھی ظاہر ہوتے ہیں جب آپ **انسٹال کریں → Service** سے مطابق سروس انسٹال کرتے ہیں، اور دونوں کے بارے میں جاننا مفید ہے کیونکہ وہ صرف حالت بتانے سے زیادہ کرتے ہیں۔

**Tailscale** پینل ٹیل نیٹ کو کنیکٹ اور ڈس کنیکٹ کرتا ہے، اکاؤنٹس کے درمیان تبدیل کرتا ہے، اور ایگزٹ نوڈ منتخب کرتا ہے (آپ کی اپنی مشینیں اور Mullvad کے علاقے دونوں اس فہرست میں ظاہر ہوتے ہیں)۔ یہ آپ کی مشینیں بھی براؤز کرتا ہے — اور ایک منتخب ہونے کے باعث، `s` اس پر Taildrop کے ذریعے فائلیں بھیجتا ہے، جو آپ کے فون یا کسی اور لیپ ٹاپ پر فائل منتقل کرنے کا تیز ترین طریقہ ہے۔ `c` مشین کا IP کاپی کرتا ہے، `n` اس کا نام، اور `d` اس کا مکمل DNS نام۔ ہر مشین کی قطار پر بھیجنے کا بٹن بھی ہے، اگر آپ کلک کرنا پسند کرتے ہیں۔ ٹرمینل سے یہی چیز `omarchy tailscale send <machine> [file...]` ہے۔

**Dropbox** پینل لاگ ان سنبھالتا ہے، دکھاتا ہے کہ آپ نے کتنی اسٹوریج استعمال کی ہے، اور حال ہی میں سنک شدہ فائلز کی فہرست دیتا ہے۔

کسی بھی سروس کو ہٹانا اس کے وِجِٹ کو بار سے واپس لے جاتا ہے۔

## اشارے

مرکز میں چھوٹا جھرمٹ اشاروں والا وِجِٹ ہے۔ یہ آپ کے چالو کیے ہوۓ موڈز کے اسٹیٹس نشانات ہیں: ڈسٹرب نہ کریں، نائٹ لائٹ، قطار میں لگی [یاد دہانی](09-reminders.md)، فعال اسکرین ریکارڈنگ، جاگتے رہیں، اور [املا](11-text-extraction-dictation.md)۔ جب موڈ فعال ہو تو وہ روشن ہوتے ہیں ورنہ راستے سے ہٹ کر رہتے ہیں — غیر فعال والوں کو جھانکنے کے لیے گھڑی کے بائیں طرف (عمودی بار پر اس کے اوپر) ہوور کریں۔ اشارے پر کلک کرنے سے وہ موڈ ٹوگل ہو جاتا ہے۔ ایک اور صرف حالت ہے: جب کوئی gliff کے ذریعے اس مشین سے جڑا ہو تو ریموٹ سیشن سرخ روش ہوتا ہے۔

اگر آپ چاہتے ہیں کہ وہ ہمیشہ نظر آئیں تو، وِجِٹ پر `alwaysShow` کو `true` پر سیٹ کریں۔ اور اگر آپ کو ان میں سے صرف کچھ کی پروا ہے تو، جنہیں آپ چاہتے ہیں انہیں `items` میں فہرست بند کریں: `["Dnd", "Reminder", "NightLight"]`۔ آپ کے پاس ایک سے زیادہ اشاروں والا وِجِٹ ہو سکتا ہے، لہٰذا مختلف حصے مختلف ذیلی سیٹ دکھا سکتے ہیں۔

## بار کو دوبارہ ترتیب دینا

بار خود کو کنفیگر کرتا ہے۔ چیزیں منتقل کرنے کے لیے آپ کو کانفیگ فائل کھولنے کی ضرورت نہیں۔

مرکز کے گرد بار کا خالی حصہ پکڑ کر اسکرین کے دوسرے کنارے کی طرف گھسیٹیں، اور بار وہاں چلا جاتا ہے — بایاں، دایاں، اوپر یا نیچے سب کام کرتے ہیں، اور ہر وِجِٹ ڈھل جاتا ہے (عمودی بار کمپیکٹ صرف آئیکن والی شکلوں پر واپس آ جاتے ہیں)۔ کلک اور دبائے رکھنا بھی یہی ڈریگ شروع کرتا ہے۔ اسی خالی جگہ پر ڈبل بائیں کلک کر کے بار کے پس منظر کو صاف سے شیشہ نما سے غیر شفاف تک چکر لگائیں۔ اور کسی بھی وِجِٹ کو دوبارہ ترتیب دینے یا اسے دوسرے حصے میں پھینکنے کے لیے گھسیٹیں۔

جو وِجِٹ آپ اپنے پاس تو رکھنا چاہتے ہیں مگر ہمیشہ نظر کے سامنے نہیں، وہ ٹرے کے دراز میں جا سکتا ہے: اسے ٹرے پر گھسیٹیں، اور دراز اسے لینے کے لیے کھل جاتا ہے۔ یہ وہاں ایپ آئیکنز کے بعد بیٹھا رہتا ہے، جب بھی دراز ظاہر ہو یہ بھی نظر آتا ہے، اور جب اس کا پینل کھلا ہو تو اپنے دراز کو کھلا رکھتا ہے۔ اسے واپس رکھنے کے لیے بار پر دوبارہ گھسیٹ کر نکالیں۔

اگر آپ مینیُو سے منتخب کرنا پسند کرتے ہیں تو، **ٹریگر → ظاہری شکل → مینیُو بار** میں جگہ ہے، اور **بار کا پس منظر** منتخب کرتا ہے کہ بار کیسے بنایا جاتا ہے: **غیر شفاف بار**، **شیشہ نما بار** (شفاف، جس کے پیچھے جو کچھ ہے وہ دھندلا ہے)، یا **شفاف بار**۔

انہی چیزوں کی کمانڈز بھی ہیں، جو آپ [dotfiles](31-dotfiles.md) سیٹ اپ کے لیے چاہتے ہیں:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.clock --section center --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

وِجِٹ کو مکمل طور پر شامل یا ہٹانے کے لیے، پلگ ان کمانڈز استعمال کریں۔ `omarchy plugin list` ہر وِجِٹ کو چھاپتا ہے جسے شیل اس کی آئی ڈی کے ساتھ جانتا ہے، اور پھر:

```bash
omarchy plugin enable omarchy.media --section center
omarchy plugin disable omarchy.weather
```

## بار چھپانا

`Super + Shift + Space` شیل کو ختم کیے بغیر بار کو بند اور دوبارہ آن ٹوگل کرتا ہے — پینلز اور ہاٹ کیز کام کرتی رہتی ہیں، بس آپ کو پکسلز واپس مل جاتے ہیں۔ یہ مینیُو میں **ٹریگر → ظاہری شکل → مینیُو بار → بار چھپائیں** کے تحت بھی ہے۔

## کانفیگ فائل

یہ سب کچھ `~/.config/omarchy/shell.json` میں، `bar` کی کے تحت محفوظ ہے۔ یہ ایک مختصر شدہ ورژن ہے:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "centerAnchor": "omarchy.clock",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

ہر وِجِٹ تین لے آؤٹ Arrays میں سے ایک میں ایک اندراج ہے، اور اس کی سیٹنگز اسی اندراج پر ان لائن ہوتی ہیں — کوئی علیحدہ سیٹنگز فائل نہیں اور کوئی `config` ذیلی آبجیکٹ نہیں۔ گھڑی کا `format`، `formatAlt` (دائیں کلک جس پر چکر لگاتا ہے)، اور `verticalFormat` سب بالکل وہیں `{ "id": "omarchy.clock" }` پر رہتے ہیں۔

`centerAnchor` اس ایک مرکزی وِجِٹ کا نام رکھتا ہے جو اسکرین کے عین مرکز پر پِن ہو جاتا ہے، دوسرے اس کے اطراف میں۔ اسی طرح گھڑی بالکل مرکز میں رہتی ہے چاہے موسم اور اپ ڈیٹ بیج آتے جاتے رہیں۔ اسے خالی سٹرنگ پر سیٹ کریں اور مرکزی فہرست اس کے بجائے صرف گروپ کے طور پر مرکز میں ہوتی ہے۔

ایک اصول جو ذہن نشین کرنے کے قابل ہے: **ایک بار جب آپ کے پاس اپنا `shell.json` ہو جاتا ہے تو، یہ مستند (canonical) ہے**۔ جب تک آپ کچھ بھی کسٹمائز نہیں کرتے، شیل Omarchy کی ڈیفالٹ فائل پڑھتا ہے۔ جیسے ہی آپ وِجِٹ گھسیٹتے ہیں، `omarchy bar` چلاتے ہیں، یا فائل میں خود ترمیم کرتے ہیں، یہ آپ کا ہے — کوئی گہرا انضمام نہیں، لہٰذا مستقبل کی Omarchy ریلیزز میں نئے ڈیفالٹ وِجِٹس آپ کے بار پر خود بخود ظاہر نہیں ہوں گے۔ جب چاہیں صاف سلیٹ ہو، `omarchy bar defaults` فراہم کردہ لے آؤٹ واپس رکھ دیتا ہے۔

یہی فائل آپ کے بیکار (idle) اوقات بھی اعلیٰ سطح پر، `bar` کی کے باہر رکھتی ہے: `idle.screensaver` اور `idle.lock`، دونوں سیکنڈز میں جب سے آپ بیکار ہوئے۔ لہٰذا ڈیفالٹ اسکرین سیور 150 سیکنڈ پر اور لاک 300 پر داخل ہوتا ہے۔
