# اوپری بار

آپ کی اسکرین کے اوپر والی پٹی Omarchy بار ہے۔ یہ کوئی باہر سے جوڑی گئی اسٹیٹس بار نہیں ہے بلکہ Omarchy شیل کا حصہ ہے، وہی ایک واحد طویل عرصے تک چلنے والا Quickshell پروسیس جو مینیو، نوٹیفیکیشنز، OSD پاپ اپس اور لاک اسکرین بھی بناتا ہے۔ اسی لیے یہ باقی ہر چیز کے ساتھ بالکل ہم آہنگ تھیم رکھتا ہے اور اسی لیے کوئی پینل کسی نئے ایپ کو شروع کرنے کے بجائے فوراً کھل جاتا ہے۔

یہ ڈیسک ٹاپ کا وہ واحد حصہ بھی ہے جو ہمیشہ اسکرین پر رہتا ہے، اس لیے یہ جاننا فائدہ مند ہے کہ وہ تمام چھوٹے چھوٹے نشانات کیا کرتے ہیں۔

## ڈیفالٹ طور پر اس پر کیا ہوتا ہے

بار کے تین حصے ہیں۔ بائیں طرف Omarchy لوگو (مینی Low launcher) اور ورک اسپیس انڈیکیٹرز ہوتے ہیں۔ درمیان میں آپ کو اسٹیٹس انڈیکیٹرز، گھڑی، Elsewhen (ایک عالمی گھڑی)، موسم اور Omarchy اپ ڈیٹ بیج ملتا ہے۔ دائیں طرف: سسٹم ٹرے، کی بورڈ لے آؤٹ (جب ایک سے زیادہ لے آؤٹ یا ان پٹ میتھڈ ترتیب دیا گیا ہو)، ایجنٹس، بلوٹوتھ، نیٹ ورک، آڈیو، ڈسپلے اور پاور۔

ان میں سے چند صرف اسی وقت نظر آتے ہیں جب ان کے پاس کہنے کو کچھ ہو۔ کی بورڈ لے آؤٹ صرف اسی وقت نظر آتا ہے جب آپ نے ایک سے زیادہ لے آؤٹ یا ان پٹ میتھڈ ترتیب دیا ہو۔ اپ ڈیٹ بیج صرف اسی وقت نظر آتا ہے جب کوئی Omarchy اپ ڈیٹ منتظر ہو۔

## اِدھر اُدھر کلک کرنا

تقریباً ہر وِجٹ بائیں، دائیں اور درمیانی کلک پر کچھ کرتا ہے، اور کئی اسکرولنگ پر بھی ردعمل دیتے ہیں۔ یہی وہ حصہ ہے جو لوگوں سے رہ جاتا ہے — دائیں اور درمیانی بٹن ہی وہ جگہ ہیں جہاں بہت سی اچھی چیزیں چھپی ہوتی ہیں۔

## پینلز

بار کے کسی آئیکن پر کلک کرنے سے ایک پینل کھلتا ہے، جو ٹول ٹِپ کے بجائے سلائیڈرز، فہرستوں اور کی بورڈ نیویگیشن کے ساتھ ایک باقاعدہ پاپ اپ ہوتا ہے۔ ہر ایک کی ایک ہاٹ کی بھی ہے، تاکہ آپ کو کبھی 16 پکسل کے نشان پر نشانہ نہ باندھنا پڑے:

| ہاٹ کی | پینل |
| --- | --- |
| `Super + Ctrl + A` | آڈیو |
| `Super + Ctrl + N` | نیٹ ورک |
| `Super + Ctrl + B` | بلوٹوتھ |
| `Super + Ctrl + D` | ڈسپلے |
| `Super + Ctrl + P` | پاور |
| `Super + Ctrl + Alt + D` | کیلنڈر |
| `Super + Ctrl + Alt + E` | عالمی گھڑی |
| `Super + Ctrl + X` | ایجنٹس |
| `Super + Ctrl + 1-9` | دائیں حصے میں نواں پینل آن/آف کریں |

پینلز صرف معلومات دکھانے کے لیے نہیں ہیں۔ یہ وہ جگہ ہیں جہاں آپ اصل کام کرتے ہیں:

- **آڈیو** میں ایک ماسٹر والیوم سلائیڈر، ایک آؤٹ پٹ ڈیوائس منتخب کنندہ اور فی ایپ مکسر ہوتا ہے، تاکہ آپ باقی ہر چیز کو چھوئے بغیر اس ایک براؤزر ٹیب کی آواز کم کر سکیں۔
- **نیٹ ورک** Wi-Fi تلاش کرتا ہے، سگنل کی طاقت دکھاتا ہے، منسلک ہوتا ہے اور آپ کو DNS فراہم کنندہ منتخب کرنے دیتا ہے۔
- **بلوٹوتھ** آپ کی ڈیوائسز کو کنیکٹ/ڈسکنیکٹ اور بیٹری لیولز کے ساتھ درج کرتا ہے۔
- **پاور** بیٹری کے اعداد و شمار دکھاتا ہے، پاور پروفائلز تبدیل کرتا ہے (یہ بیٹری اور AC کے لیے الگ الگ انتخاب یاد رکھتا ہے) اور کچھ سسٹم معلومات دکھاتا ہے۔
- **ڈسپلے** میں چمک کا سلائیڈر، متن کا سائز، مانیٹر اسکیلنگ پری سیٹس اور — جب آپ کے پاس ایک سے زیادہ اسکرین ہو — فی مانیٹر کنٹرولز ہوتے ہیں۔ گہری تفصیل کے لیے [مانیٹرز](33-monitors.md) دیکھیں۔
- **گھڑی** ISO ہفتہ نمبروں اور مہینے آگے پیچھے کرنے کے ساتھ ایک ماہانہ گرڈ کھولتی ہے۔
- **عالمی گھڑی** ہر شہر کے لیے ایک قطار رکھتی ہے، اس کے موسم اور اس کا دن کیسا گزر رہا ہے اس کے ساتھ۔ تلاش قصبوں کے ساتھ ساتھ ٹائم زونز بھی تلاش کرتی ہے، اس لیے Fort Lauderdale، Fort Lauderdale ہی ہے نہ کہ New York۔ اگر اوپر والی سطر غلط شہر کا نام بتائے تو اس پر کلک کریں اور بتائیں کہ آپ کہاں ہیں؛ کسی دوسرے ٹائم زون پر کوئی جگہ منتخب کریں تو سسٹم گھڑی بھی وہاں منتقل ہو جاتی ہے، جو سفر کے دوران کارآمد ہے۔ کسی شہر پر ہوور کریں اور فرد والے بٹن پر کلک کر کے بتائیں کہ وہاں کون رہتا ہے — سادہ نام، یا `@` GitHub ہینڈلز تاکہ ان کی صورتیں بھی ساتھ آ جائیں۔

ہر پینل ماؤس کے ساتھ ساتھ کی بورڈ بھی استعمال کرتا ہے: تیر حرکت کرتے ہیں، Return فعال کرتا ہے، Tab پڑوسی پینل پر لے جاتا ہے اور Escape بند کر دیتا ہے۔

`Super + Ctrl + 1-9` دائیں حصے میں پینلز کو بائیں سے دائیں گنتا ہے، ٹرے کو چھوڑ کر کیونکہ اس کا اپنا کوئی پینل نہیں ہے۔ اس لیے نمبر اسی آئیکن سے میل کھاتا ہے جس کی طرف آپ اشارہ کرتے۔

### Tailscale اور Dropbox

دو مزید وِجٹس بار پر صرف اسی وقت نظر آتے ہیں جب آپ **Install → Service** سے متعلقہ سروس انسٹال کر لیں، اور دونوں کے بارے میں جاننا فائدہ مند ہے کیونکہ یہ صرف اسٹیٹس بتانے سے زیادہ کام کرتے ہیں۔

**Tailscale** پینل ٹیل نیٹ کو منسلک اور منقطع کرتا ہے، اکاؤنٹس کے درمیان تبدیل کرتا ہے اور ایک ایگزٹ نوڈ منتخب کرتا ہے (آپ کی اپنی مشینیں اور Mullvad ریجنز دونوں اس فہرست میں نظر آتے ہیں)۔ یہ آپ کی مشینیں بھی براؤز کرتا ہے — اور ایک منتخب ہونے پر، `s` Taildrop کے ذریعے اسے فائلیں بھیجتا ہے، جو کسی فائل کو آپ کے فون یا کسی دوسرے لیپ ٹاپ پر منتقل کرنے کا تیز ترین طریقہ ہے۔ `c` مشین کا IP کاپی کرتا ہے، `n` اس کا نام اور `d` اس کا مکمل DNS نام۔ ہر مشین کی قطار پر ایک بھیجنے کا بٹن بھی ہے، اگر آپ اس کے بجائے کلک کرنا پسند کریں۔ ٹرمینل سے یہی کام `omarchy tailscale send <machine> [file...]` ہے۔

**Dropbox** پینل لاگ اِن سنبھالتا ہے، دکھاتا ہے کہ آپ نے کتنی اسٹوریج استعمال کی ہے اور حال ہی میں ہم آہنگ شدہ فائلیں درج کرتا ہے۔

کسی بھی سروس کو ہٹانے سے اس کا وِجٹ بار سے واپس ہٹ جاتا ہے۔

## انڈیکیٹرز

درمیان میں موجود چھوٹا سا جھرمٹ انڈیکیٹرز وِجٹ ہے۔ یہ ان موڈز کے لیے اسٹیٹس نشانات ہیں جنہیں آپ نے آن کیا ہے: ڈسٹرب نہ کریں، نائٹ لائٹ، ایک قطار میں موجود [یاد دہانی](09-reminders.md)، ایک فعال اسکرین ریکارڈنگ اور بیدار رہیں، اس کے علاوہ انتباہات جب پاس ورڈ کے بغیر sudo آن ہو یا کوئی ریموٹ سیشن سے منسلک ہو۔ جب موڈ فعال ہوتا ہے تو یہ روشن ہو جاتے ہیں اور بصورت دیگر راستے سے ہٹے رہتے ہیں — غیر فعال والوں کو جھانک کر دیکھنے کے لیے ان کے بالکل پاس ہوور کریں، جہاں غیر فعال والے موجود ہوتے۔ کسی انڈیکیٹر پر کلک کرنے سے وہ موڈ آن/آف ہو جاتا ہے۔ ایک اور صرف اسٹیٹس کے لیے ہے: ریموٹ سیشن سرخ روشن ہو جاتا ہے جب کوئی gliff کے ذریعے اس مشین سے منسلک ہوتا ہے۔

اگر آپ چاہتے ہیں کہ یہ ہمیشہ نظر آئیں تو وِجٹ پر `alwaysShow` کو `true` پر سیٹ کریں۔ اور اگر آپ کو صرف ان میں سے چند کی پرواہ ہے تو جنہیں آپ چاہتے ہیں انہیں `items` میں درج کریں: `["Dnd", "Reminder", "NightLight"]`۔ آپ کے پاس ایک سے زیادہ انڈیکیٹرز وِجٹ ہو سکتے ہیں، تاکہ مختلف حصے مختلف ذیلی سیٹ دکھا سکیں۔

## بار کو دوبارہ ترتیب دینا

بار خود کو ترتیب دیتی ہے۔ چیزوں کو حرکت دینے کے لیے آپ کو کوئی کنفگ فائل کھولنے کی ضرورت نہیں ہے۔

بار کے درمیان کے آس پاس کسی خالی جگہ کو پکڑیں اور اسے اسکرین کے کسی دوسرے کنارے کی طرف گھسیٹیں، اور بار وہاں منتقل ہو جاتی ہے — بائیں، دائیں، اوپر یا نیچے سب کام کرتے ہیں، اور ہر وِجٹ خود کو ڈھال لیتا ہے (عمودی بارز کمپیکٹ صرف آئیکن والی شکلوں پر واپس آ جاتی ہیں)۔ کلک کر کے تھامے رکھنے سے بھی یہی ڈریگ شروع ہوتا ہے۔ اسی خالی جگہ پر ڈبل بایاں کلک کریں تو بار کا پس منظر صاف سے شیشے جیسا اور پھر مبہم ہونے تک بدلتا ہے۔ اور کسی بھی وِجٹ کو گھسیٹ کر اسے دوبارہ ترتیب دیں یا کسی دوسرے حصے میں پھینک دیں؛ دوسرے وِجٹس سلائیڈ کر کے الگ ہو جاتے ہیں تاکہ وہاں جگہ بن جائے جہاں یہ اترے گا۔

بار کا درمیان ایک باکس ہے: جو کچھ بھی اس میں ہوتا ہے وہ ایک گروپ کے طور پر درمیان میں رہتا ہے، اور اس کے دونوں طرف کے وِجٹس اس کے کناروں سے لٹکے ہوتے ہیں۔ جب آپ کوئی وِجٹ گھسیٹتے ہیں تو باکس ایک آؤٹ لائن کے طور پر نظر آتا ہے، یا جب یہ خالی ہو تو بار کے آر پار ایک لکیر کے طور پر، اور آپ اس میں یا اس کے پاس چھوڑ سکتے ہیں۔ جب کوئی ڈراپ باکس میں اترنے والا ہوتا ہے تو باکس وِجٹ کو اپنے اندر لینے کے لیے بڑھ جاتا ہے۔

کوئی وِجٹ جسے آپ ارد گرد تو چاہتے ہیں لیکن ہمیشہ نظر میں نہیں، وہ ٹرے کی دراز میں جا سکتا ہے: اسے ٹرے پر گھسیٹیں، اور دراز اسے لینے کے لیے کھل جاتی ہے۔ یہ وہاں ایپ آئیکنز کے بعد بیٹھتا ہے، جب بھی دراز آتی ہے نظر آتا ہے اور جب اس کا پینل کھلا ہوتا ہے تو اپنی دراز کو کھلا رکھتا ہے۔ اسے واپس بار پر گھسیٹ کر باہر لائیں تاکہ یہ واپس آ جائے۔

اگر آپ اس کے بجائے مینیو سے منتخب کرنا پسند کریں تو **Appearance → Menu Bar** میں پوزیشن ہے، اور **Bar Background** منتخب کرتا ہے کہ بار کیسے بنائی جائے: **Opaque Bar**، **Glassy Bar** (پار دیکھنے والی، اس کے پیچھے جو کچھ ہے اسے دھندلا کر)، یا **Clear Bar**۔

انہی چیزوں کے لیے کمانڈز بھی ہیں، جو آپ کو [dotfiles](31-dotfiles.md) سیٹ اپ کے لیے چاہئیں:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

کسی وِجٹ کو مکمل طور پر شامل یا ہٹانے کے لیے پلگ اِن کمانڈز استعمال کریں۔ `omarchy plugin list` شیل کو معلوم ہر وِجٹ کو اس کی id کے ساتھ پرنٹ کرتا ہے، اور پھر:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## بار کو چھپانا

`Super + Shift + Space` شیل کو ختم کیے بغیر بار کو بند اور واپس آن کرتا ہے — پینلز اور ہاٹ کیز کام کرتی رہتی ہیں، بس آپ کو پکسلز واپس مل جاتے ہیں۔ یہ مینیو میں **Appearance → Menu Bar → Hide Bar** کے تحت بھی ہے۔

## کنفگ فائل

یہ سب `~/.config/omarchy/shell.json` میں، `bar` کلید کے تحت محفوظ ہوتا ہے۔ یہ رہا ایک مختصر شدہ ورژن:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

ہر وِجٹ پانچ لے آؤٹ ارے میں سے کسی ایک میں ایک اندراج ہے، اور اس کی ترتیبات اسی اندراج پر اِن لائن بیٹھتی ہیں — کوئی الگ ترتیبات فائل نہیں ہے اور کوئی `config` ذیلی آبجیکٹ نہیں ہے۔ گھڑی کا `format`، `formatAlt` (جس پر دایاں کلک سائیکل کرتا ہے) اور `verticalFormat` سب وہیں `{ "id": "omarchy.clock" }` پر رہتے ہیں۔

`center` بار کے درمیان والا باکس ہے: اس میں موجود ہر چیز ایک گروپ کے طور پر اسکرین پر درمیان میں ہوتی ہے۔ `centerBegin` اور `centerEnd` باکس کے دونوں طرف لٹکتے ہیں، یہی طریقہ ہے کہ موسم اور اپ ڈیٹ بیج کے آتے جاتے رہنے کے باوجود گھڑی بالکل درمیان میں رہتی ہے۔ `center` میں ایک سے زیادہ وِجٹ ڈالیں تو وہ ایک ساتھ درمیان میں ہوتے ہیں؛ اسے خالی چھوڑ دیں تو `centerBegin` اور `centerEnd` بار کے درمیان میں آپس میں مل جاتے ہیں۔

ایک قاعدہ جو ذہن نشین کرنے کے قابل ہے: **ایک بار جب آپ کے پاس اپنی `shell.json` ہو جائے تو وہی مستند ہے**۔ جب تک آپ کسی چیز کو اپنی پسند کے مطابق نہیں بناتے، شیل Omarchy کی ڈیفالٹ فائل پڑھتا ہے۔ جس لمحے آپ کوئی وِجٹ گھسیٹتے ہیں، `omarchy bar` چلاتے ہیں یا فائل خود ترمیم کرتے ہیں، آپ اس کے مالک بن جاتے ہیں — کوئی گہرا انضمام نہیں ہوتا، اس لیے مستقبل کی Omarchy ریلیزز میں نئے ڈیفالٹ وِجٹس آپ کی بار پر خود بخود نظر نہیں آئیں گے۔ `omarchy bar defaults` جب بھی آپ صاف آغاز چاہیں بھیجی گئی ترتیب کو واپس رکھ دیتا ہے۔

یہی فائل `bar` کلید سے باہر، اوپری سطح پر آپ کے غیر فعال اوقات بھی رکھتی ہے: `idle.screensaver` اور `idle.lock`، دونوں آپ کے غیر فعال ہونے کے بعد سیکنڈز میں۔ اس لیے ڈیفالٹ اسکرین سیور 150 سیکنڈ پر شروع ہوتا ہے اور لاک 300 پر۔
