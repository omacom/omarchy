# اوپر والی پٹی

آپ کی اسکرین کے اوپر والی پٹی Omarchy بار ہے۔ یہ کوئی باہر سے جوڑی گئی اسٹیٹس بار نہیں ہے بلکہ Omarchy شیل کا حصہ ہے، وہی واحد دیرپا چلنے والا Quickshell پروسیس جو مینیو، اطلاعات، OSD پاپ اپس، اور لاک اسکرین بھی بناتا ہے۔ اسی لیے یہ باقی ہر چیز کے ساتھ مکمل طور پر تھیم کے مطابق ہو جاتی ہے اور اسی لیے کوئی پینل نئی ایپ شروع کرنے کے بجائے فوراً کھل جاتا ہے۔

یہ ڈیسک ٹاپ کا وہ واحد حصہ بھی ہے جو ہمیشہ اسکرین پر رہتا ہے، اس لیے یہ جاننا فائدہ مند ہے کہ وہ تمام چھوٹی چھوٹی علامتیں کیا کرتی ہیں۔

## پہلے سے اس پر کیا ہوتا ہے

بار کے تین حصے ہیں۔ بائیں طرف Omarchy لوگو (مینیو لانچر) اور ورک اسپیس اشارے ہوتے ہیں۔ درمیان میں آپ کو اسٹیٹس اشارے، گھڑی، Elsewhen (ایک عالمی گھڑی)، موسم، اور Omarchy اپ ڈیٹ بیج ملتا ہے۔ دائیں طرف: سسٹم ٹرے، کی بورڈ لے آؤٹ (جب ایک سے زیادہ ترتیب دیا گیا ہو)، ایجنٹس، bluetooth، نیٹ ورک، آڈیو، ڈسپلے، اور پاور۔

ان میں سے چند صرف اسی وقت ظاہر ہوتے ہیں جب ان کے پاس کہنے کو کچھ ہو۔ کی بورڈ لے آؤٹ صرف اسی وقت ظاہر ہوتا ہے جب آپ نے ایک سے زیادہ لے آؤٹ ترتیب دیا ہو۔ اپ ڈیٹ بیج صرف اسی وقت ظاہر ہوتا ہے جب کوئی Omarchy اپ ڈیٹ منتظر ہو۔ اور ایجنٹس آئیکن پہلی بار اس وقت ظاہر ہوتا ہے جب Omarchy کو مشین پر AI کوڈنگ کا استعمال ملتا ہے (دیکھیں [AI](17-ai.md))۔

## یہاں وہاں کلک کرنا

تقریباً ہر ویجیٹ بائیں، دائیں، اور درمیانی کلک پر کچھ کرتا ہے، اور کئی اسکرولنگ پر بھی ردعمل دیتے ہیں۔ یہی وہ حصہ ہے جو لوگوں سے رہ جاتا ہے — دائیں اور درمیانی بٹنوں میں ہی بہت سی اچھی چیزیں چھپی ہوتی ہیں۔

| ویجیٹ | بایاں | دایاں | درمیانی / اسکرول |

| Clock | کیلنڈر پاپ اپ | لیبل کے فارمیٹ کو آگے بڑھائیں | درمیانی: ٹائم زون منتخب کرنے والا |
| Weather | پیش گوئی کا پاپ اپ | مکمل موسم بطور اطلاع | درمیانی: تازہ کریں |
| Audio | آڈیو پینل | خاموش کریں | درمیانی: پینل · اسکرول: آواز |
| Microphone | مائیک خاموش کریں | — | درمیانی: آڈیو پینل · اسکرول: ان پٹ آواز |
| Network | نیٹ ورک پینل | — | — |
| Bluetooth | Bluetooth پینل | ریڈیو آن/آف کریں | — |

| Tray | دراز ظاہر کرنے کے لیے ہوور کریں | نظم کرنے کے لیے شیورون پر دایاں کلک کریں | — |

اس جدول میں موجود ہر چیز آپ کی بار پر شروع سے موجود نہیں ہے۔ میڈیا ویجیٹ (MPRIS now-playing، اسکرول ہوتے ٹریک اور فنکار کے ساتھ) اور مائیکروفون ویجیٹ دونوں built in ہیں لیکن پہلے سے بند ہیں — اگر آپ انہیں چاہتے ہیں تو انہیں شامل کر لیں، جیسا کہ نیچے بیان کیا گیا ہے۔

## پینلز

کسی بار آئیکن پر کلک کرنے سے ایک پینل کھلتا ہے، جو سلائیڈرز، فہرستوں، اور کی بورڈ نیویگیشن کے ساتھ ایک باقاعدہ پاپ اپ ہوتا ہے، نہ کہ کوئی ٹول ٹپ۔ ہر ایک کی ایک ہاٹ کی بھی ہے، اس لیے آپ کو کبھی 16-pixel علامت پر نشانہ نہیں باندھنا پڑتا:

| Hotkey | Panel |
| --- | --- |
| `Super + Ctrl + A` | Audio |
| `Super + Ctrl + N` | Network |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | Display |
| `Super + Ctrl + P` | Power |
| `Super + Ctrl + Alt + D` | Calendar |
| `Super + Ctrl + Alt + E` | World clock |
| `Super + Ctrl + 1-9` | دائیں حصے میں nth پینل کو آن/آف کریں |

پینلز صرف معلومات دکھانے کے لیے نہیں ہیں۔ یہیں سے آپ اصل کام کرتے ہیں:

- **Audio** میں ایک ماسٹر والیوم سلائیڈر، ایک آؤٹ پٹ ڈیوائس منتخب کرنے والا، اور فی ایپ مکسچر ہے، اس لیے آپ باقی ہر چیز کو چھیڑے بغیر اس ایک براؤزر ٹیب کی آواز کم کر سکتے ہیں۔
- **Network** Wi-Fi تلاش کرتا ہے، سگنل کی طاقت دکھاتا ہے، کنیکٹ کرتا ہے، اور آپ کو DNS فراہم کنندہ منتخب کرنے دیتا ہے۔
- **Bluetooth** آپ کی ڈیوائسز کو connect/disconnect اور بیٹری لیولز کے ساتھ فہرست میں دکھاتا ہے۔
- **Power** بیٹری کے اعداد و شمار دکھاتا ہے، پاور پروفائلز بدلتا ہے (یہ بیٹری اور AC کے لیے الگ الگ انتخاب یاد رکھتا ہے)، اور کچھ سسٹم معلومات دکھاتا ہے۔
- **Display** میں چمک کا سلائیڈر، متن کا سائز، مانیٹر اسکیلنگ کے پہلے سے طے شدہ انداز، اور — جب آپ کے پاس ایک سے زیادہ اسکرین ہو — فی مانیٹر کنٹرولز ہوتے ہیں۔ گہری تفصیل کے لیے دیکھیں [مانیٹرز](33-monitors.md)۔
- **Clock** ISO ہفتہ نمبروں اور مہینہ آگے پیچھے کرنے کے ساتھ ایک مہینے کا گرڈ کھولتا ہے۔
- **World clock** ہر شہر کے لیے ایک قطار رکھتا ہے، اس کے موسم اور اس کا دن کیسا گزر رہا ہے اس کے ساتھ۔ تلاش شہروں کے ساتھ ساتھ ٹائم زونز بھی ڈھونڈتی ہے، اس لیے Fort Lauderdale، Fort Lauderdale ہی ہے، New York نہیں۔ اگر اوپر والی سطر میں غلط شہر کا نام آئے تو اس پر کلک کریں اور بتائیں کہ آپ کہاں ہیں؛ کسی دوسرے ٹائم زون کی جگہ منتخب کریں تو سسٹم گھڑی بھی وہیں منتقل ہو جاتی ہے، جو سفر کے دوران کارآمد ہے۔ کسی شہر پر ہوور کریں اور person بٹن پر کلک کر کے بتائیں کہ وہاں کون رہتا ہے — سادہ نام، یا ان کے چہرے ساتھ لانے کے لیے `@` GitHub ہینڈلز۔

ہر پینل ماؤس کے ساتھ ساتھ کی بورڈ بھی قبول کرتا ہے: تیر حرکت کرتے ہیں، Return فعال کرتا ہے، Tab پڑوسی پینل پر لے جاتا ہے، اور Escape بند کر دیتا ہے۔

`Super + Ctrl + 1-9` دائیں حصے میں پینلز کو بائیں سے دائیں گنتا ہے، ٹرے کو چھوڑ کر کیونکہ اس کا اپنا کوئی پینل نہیں ہے۔ اس لیے نمبر اسی آئیکن سے ملتا ہے جس کی طرف آپ اشارہ کرتے۔

### Tailscale اور Dropbox

دو مزید ویجیٹس بار پر صرف اسی وقت ظاہر ہوتے ہیں جب آپ **Install → Service** سے متعلقہ سروس انسٹال کر لیتے ہیں، اور دونوں کو جاننا اس لیے فائدہ مند ہے کیونکہ یہ صرف اسٹیٹس بتانے سے زیادہ کام کرتے ہیں۔

**Tailscale** پینل tailnet کو کنیکٹ اور ڈس کنیکٹ کرتا ہے، اکاؤنٹس کے درمیان بدلتا ہے، اور ایک exit node منتخب کرتا ہے (آپ کی اپنی مشینیں اور Mullvad خطے دونوں اس فہرست میں ظاہر ہوتے ہیں)۔ یہ آپ کی مشینیں بھی براؤز کرتا ہے — اور کسی ایک کو منتخب کر کے، `s` اسے Taildrop کے ذریعے فائلیں بھیجتا ہے، جو کسی فائل کو آپ کے فون یا کسی دوسرے لیپ ٹاپ پر منتقل کرنے کا تیز ترین طریقہ ہے۔ `c` مشین کا IP کاپی کرتا ہے، `n` اس کا نام، اور `d` اس کا مکمل DNS نام۔ ہر مشین کی قطار پر ایک بھیجنے کا بٹن بھی ہے، اگر آپ کلک کرنا پسند کریں۔ ٹرمینل سے یہی کام `omarchy tailscale send <machine> [file...]` ہے۔

**Dropbox** پینل لاگ ان سنبھالتا ہے، دکھاتا ہے کہ آپ نے کتنی اسٹوریج استعمال کی ہے، اور حال ہی میں sync ہوئی فائلیں فہرست میں دکھاتا ہے۔

کسی بھی سروس کو ہٹانے سے اس کا ویجیٹ بار سے واپس ہٹ جاتا ہے۔

## اشارے

درمیان میں موجود چھوٹا سا جھرمٹ اشاروں والا ویجیٹ ہے۔ یہ ان موڈز کے لیے اسٹیٹس علامتیں ہیں جو آپ نے آن کیے ہیں: do not disturb، night light، قطار میں لگی [یاد دہانی](09-reminders.md)، فعال اسکرین ریکارڈنگ، stay awake، اور [ڈکٹیشن](11-text-extraction-dictation.md)۔ جب موڈ فعال ہو تو یہ روشن ہو جاتے ہیں اور ورنہ راستے سے ہٹے رہتے ہیں — ان کے بالکل پاس، جہاں غیر فعال والے ہوتے، ہوور کر کے انہیں جھانک کر دیکھیں۔ کسی اشارے پر کلک کرنے سے وہ موڈ آن/آف ہو جاتا ہے۔ ایک اور صرف اسٹیٹس کے لیے ہے: جب کوئی gliff کے ذریعے اس مشین سے جڑا ہو تو remote session سرخ روشن ہو جاتا ہے۔

اگر آپ چاہتے ہیں کہ یہ ہمیشہ نظر آئیں تو ویجیٹ پر `alwaysShow` کو `true` پر سیٹ کر دیں۔ اور اگر آپ کو صرف ان میں سے کچھ کی پرواہ ہے تو جو چاہتے ہیں انہیں `items` میں درج کریں: `["Dnd", "Reminder", "NightLight"]`۔ آپ کے پاس ایک سے زیادہ اشاروں والے ویجیٹس ہو سکتے ہیں، اس لیے مختلف حصے مختلف ذیلی مجموعے دکھا سکتے ہیں۔

## بار کو دوبارہ ترتیب دینا

بار خود کو ترتیب دے لیتی ہے۔ چیزوں کو ادھر ادھر کرنے کے لیے آپ کو کوئی config فائل کھولنے کی ضرورت نہیں ہے۔

بار کے درمیان کے آس پاس کسی خالی جگہ کو پکڑیں اور اسے اسکرین کے کسی دوسرے کنارے کی طرف گھسیٹیں، اور بار وہاں منتقل ہو جاتی ہے — بائیں، دائیں، اوپر، یا نیچے سب چلتا ہے، اور ہر ویجیٹ خود کو ڈھال لیتا ہے (عمودی بارز سکڑ کر صرف آئیکن والی شکلوں میں آ جاتی ہیں)۔ کلک کر کے پکڑے رکھنے سے بھی یہی گھسیٹنا شروع ہو جاتا ہے۔ اسی خالی جگہ پر ڈبل بایاں کلک کر کے بار کے پس منظر کو clear سے glassy سے opaque تک آگے بڑھائیں۔ اور کسی بھی ویجیٹ کو گھسیٹ کر اس کی ترتیب بدلیں یا اسے کسی دوسرے حصے میں پھینک دیں؛ دوسرے ویجیٹس جہاں وہ آئے گا وہاں جگہ بنانے کے لیے الگ الگ سرک جاتے ہیں۔

بار کا درمیان ایک ڈبہ ہے: اس میں جو کچھ بھی ہو وہ ایک گروپ کے طور پر درمیان میں رہتا ہے، اور اس کے دونوں طرف کے ویجیٹس اس کے کناروں سے لٹکتے ہیں۔ جب آپ کسی ویجیٹ کو گھسیٹتے ہیں تو ڈبہ ایک خاکے کے طور پر نظر آتا ہے، یا جب خالی ہو تو بار کے آر پار ایک لکیر کے طور پر، اور آپ اس میں یا اس کے پاس چھوڑ سکتے ہیں۔ جب چھوڑنا ڈبے میں پڑنے والا ہو تو ڈبہ ویجیٹ کو اپنے اندر لینے کے لیے بڑھ جاتا ہے۔

جس ویجیٹ کو آپ آس پاس رکھنا چاہتے ہیں لیکن ہمیشہ نظر میں نہیں، وہ ٹرے کی دراز میں جا سکتا ہے: اسے ٹرے پر گھسیٹیں، اور دراز اسے لینے کے لیے کھل جاتی ہے۔ یہ وہاں ایپ آئیکنز کے بعد بیٹھتا ہے، جب بھی دراز آتی ہے تب ظاہر ہوتا ہے، اور جب اس کا پینل کھلا ہو تو اپنی دراز کو کھلا رکھتا ہے۔ اسے واپس رکھنے کے لیے اسے گھسیٹ کر بار پر واپس لے آئیں۔

اگر آپ مینیو سے منتخب کرنا پسند کرتے ہیں تو **Appearance → Menu Bar** میں پوزیشن ہے، اور **Bar Background** منتخب کرتا ہے کہ بار کیسے بنائی جائے: **Opaque Bar**، **Glassy Bar** (پارदर्शी، اس کے پیچھے جو کچھ ہے وہ دھندلا ہوا)، یا **Clear Bar**۔

انہی چیزوں کے کمانڈز بھی ہیں، جو آپ کو [dotfiles](31-dotfiles.md) سیٹ اپ کے لیے چاہئیں:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

کسی ویجیٹ کو مکمل طور پر شامل یا ہٹانے کے لیے plugin کمانڈز استعمال کریں۔ `omarchy plugin list` شیل کے معلوم ہر ویجیٹ کو اس کی id کے ساتھ چھاپتا ہے، اور پھر:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## بار کو چھپانا

`Super + Shift + Space` شیل کو ختم کیے بغیر بار کو بند اور واپس آن کرتا ہے — پینلز اور ہاٹ کیز کام کرتی رہتی ہیں، بس آپ کو pixels واپس مل جاتے ہیں۔ یہ مینیو میں **Appearance → Menu Bar → Hide Bar** کے تحت بھی ہے۔

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

ہر ویجیٹ پانچ layout arrays میں سے کسی ایک میں ایک اندراج ہے، اور اس کی ترتیبات اسی اندراج پر inline بیٹھی ہیں — کوئی الگ ترتیبات فائل نہیں ہے اور کوئی `config` ذیلی آبجیکٹ نہیں ہے۔ گھڑی کا `format`، `formatAlt` (جس پر دایاں کلک آگے بڑھتا ہے)، اور `verticalFormat` سب وہیں `{ "id": "omarchy.clock" }` پر رہتے ہیں۔

`center` بار کے درمیان والا ڈبہ ہے: اس میں موجود ہر چیز اسکرین پر ایک گروپ کے طور پر درمیان میں رہتی ہے۔ `centerBegin` اور `centerEnd` ڈبے کے دونوں طرف لٹکتے ہیں، اسی طرح گھڑی بالکل درمیان میں رہتی ہے چاہے موسم اور اپ ڈیٹ بیج آتے جاتے رہیں۔ `center` میں ایک سے زیادہ ویجیٹ ڈالیں تو وہ ایک ساتھ درمیان میں آتے ہیں؛ اسے خالی چھوڑ دیں تو `centerBegin` اور `centerEnd` بار کے درمیان میں مل جاتے ہیں۔

ایک اصول جو ذہن نشین کرنے کے قابل ہے: **ایک بار جب آپ کے پاس اپنی `shell.json` ہو جائے تو وہی حتمی ہے**۔ جب تک آپ کسی چیز کو اپنی مرضی کے مطابق نہیں کرتے، شیل Omarchy کی default فائل پڑھتا ہے۔ جس لمحے آپ کوئی ویجیٹ گھسیٹتے ہیں، `omarchy bar` چلاتے ہیں، یا فائل خود ترمیم کرتے ہیں، وہ آپ کی ہو جاتی ہے — کوئی deep merge نہیں ہوتا، اس لیے مستقبل کی Omarchy ریلیزز میں نئے default ویجیٹس آپ کی بار پر خود بخود ظاہر نہیں ہوں گے۔ جب بھی آپ صاف سلیٹ چاہیں تو `omarchy bar defaults` بھیجا گیا لے آؤٹ واپس رکھ دیتا ہے۔

اسی فائل میں اعلیٰ سطح پر، `bar` key کے باہر، آپ کے idle اوقات بھی ہوتے ہیں: `idle.screensaver` اور `idle.lock`، دونوں آپ کے idle ہونے کے بعد سے سیکنڈز میں۔ اس لیے default screensaver 150 سیکنڈ پر شروع ہوتا ہے اور lock 300 پر۔
