# اوپری پٹی

آپ کی اسکرین کے اوپر والی پٹی Omarchy بار ہے۔ یہ کوئی اوپر سے جوڑی گئی اسٹیٹس بار نہیں ہے بلکہ Omarchy شیل کا حصہ ہے، وہ واحد دیر تک چلنے والا Quickshell پروسیس جو مینو، اطلاعات، OSD پاپ اپس، اور لاک اسکرین بھی بناتا ہے۔ اسی لیے یہ ہر چیز کے ساتھ بالکل موزوں تھیم اختیار کرتی ہے اور اسی لیے کوئی پینل کسی نئی ایپ کو شروع کرنے کے بجائے فوراً کھل جاتا ہے۔

یہ ڈیسک ٹاپ کا وہ واحد حصہ بھی ہے جو ہمیشہ اسکرین پر رہتا ہے، اس لیے یہ جاننا فائدہ مند ہے کہ وہ تمام چھوٹی چھوٹی علامات کیا کرتی ہیں۔

## بطور ڈیفالٹ اس پر کیا ہوتا ہے

بار کے تین حصے ہیں۔ بائیں طرف Omarchy لوگو (مینو لانچر) اور ورک اسپیس اشارے ہوتے ہیں۔ درمیان میں آپ کو اسٹیٹس اشارے، گھڑی، Elsewhen (ایک عالمی گھڑی)، موسم، اور Omarchy اپ ڈیٹ بیج ملتا ہے۔ دائیں طرف: سسٹم ٹرے، کی بورڈ لے آؤٹ (جب ایک سے زیادہ ترتیب دی گئی ہو)، ایجنٹس، بلوٹوتھ، نیٹ ورک، آڈیو، ڈسپلے، اور پاور۔

ان میں سے چند صرف اسی وقت ظاہر ہوتے ہیں جب ان کے پاس کہنے کو کچھ ہو۔ کی بورڈ لے آؤٹ صرف اسی وقت ظاہر ہوتا ہے اگر آپ نے ایک سے زیادہ لے آؤٹ ترتیب دیا ہو۔ اپ ڈیٹ بیج صرف اسی وقت ظاہر ہوتا ہے جب کوئی Omarchy اپ ڈیٹ منتظر ہو۔ اور ایجنٹس آئیکن پہلی بار اس وقت ظاہر ہوتا ہے جب Omarchy کو مشین پر AI کوڈنگ کا استعمال ملتا ہے (دیکھیں [AI](17-ai.md))۔

## پینلز

کسی بار آئیکن پر کلک کرنے سے ایک پینل کھلتا ہے، جو ٹول ٹِپ کے بجائے سلائیڈرز، فہرستوں، اور کی بورڈ نیویگیشن والا باقاعدہ پاپ اپ ہوتا ہے۔ ہر ایک کی ایک ہاٹ کی بھی ہے، اس لیے آپ کو کبھی 16 پکسل والی علامت پر نشانہ نہیں باندھنا پڑتا:

| ہاٹ کی | پینل |
| --- | --- |
| `Super + Ctrl + A` | آڈیو |
| `Super + Ctrl + N` | نیٹ ورک |
| `Super + Ctrl + B` | بلوٹوتھ |
| `Super + Ctrl + D` | ڈسپلے |
| `Super + Ctrl + P` | پاور |
| `Super + Ctrl + Alt + D` | کیلنڈر |
| `Super + Ctrl + Alt + E` | عالمی گھڑی |
| `Super + Ctrl + 1-9` | دائیں حصے میں واں پینل آن/آف کریں |

پینلز صرف ریڈ آؤٹ نہیں ہیں۔ یہ وہ جگہ ہیں جہاں آپ اصل کام کرتے ہیں:

- **Audio** میں ایک ماسٹر والیوم سلائیڈر، ایک آؤٹ پٹ ڈیوائس منتخب کنندہ، اور فی ایپ مِکسر ہوتا ہے، اس لیے آپ باقی سب کو چھوئے بغیر اس ایک براؤزر ٹیب کی آواز کم کر سکتے ہیں۔
- **Network** Wi-Fi تلاش کرتا ہے، سگنل کی طاقت دکھاتا ہے، منسلک ہوتا ہے، اور آپ کو DNS فراہم کنندہ منتخب کرنے دیتا ہے۔
- **Bluetooth** آپ کی ڈیوائسز کو منسلک/منقطع کرنے اور بیٹری کی سطحوں کے ساتھ درج کرتا ہے۔
- **Power** بیٹری کے اعداد و شمار دکھاتا ہے، پاور پروفائلز بدلتا ہے (یہ بیٹری اور AC کے لیے الگ انتخاب یاد رکھتا ہے)، اور کچھ سسٹم معلومات دکھاتا ہے۔
- **Display** میں چمک کا سلائیڈر، متن کا سائز، مانیٹر اسکیلنگ کی پیش سیٹیں، اور — جب آپ کے پاس ایک سے زیادہ اسکرین ہو — فی مانیٹر کنٹرول ہوتے ہیں۔ مزید تفصیلی کہانی کے لیے دیکھیں [مانیٹرز](33-monitors.md)۔
- **Clock** ISO ہفتہ نمبروں اور مہینوں میں آگے پیچھے جانے کے ساتھ ایک ماہانہ گرڈ کھولتا ہے۔
- **World clock** فی شہر ایک قطار رکھتا ہے، اس کے موسم اور اس کا دن کیسا گزر رہا ہے اس کے ساتھ۔ تلاش میں صرف ٹائم زونز نہیں بلکہ قصبے بھی ملتے ہیں، اس لیے Fort Lauderdale، Fort Lauderdale ہی ہے New York نہیں۔ اگر اوپر والی سطر غلط شہر کا نام لیتی ہے تو اس پر کلک کریں اور بتائیں کہ آپ کہاں ہیں؛ کسی دوسرے ٹائم زون کی جگہ منتخب کریں اور سسٹم گھڑی بھی وہیں چلی جاتی ہے، جو سفر کے دوران کارآمد ہے۔ کسی شہر پر ہوور کریں اور شخص والے بٹن پر کلک کر کے بتائیں کہ وہاں کون رہتا ہے — سادہ نام، یا `@` GitHub ہینڈلز تاکہ ان کے چہرے بھی ساتھ آ جائیں۔

ہر پینل ماؤس کے ساتھ ساتھ کی بورڈ بھی قبول کرتا ہے: تیر حرکت کرتے ہیں، Return فعال کرتا ہے، Tab ہمسایہ پینل پر لے جاتا ہے، اور Escape بند کر دیتا ہے۔

`Super + Ctrl + 1-9` دائیں حصے میں پینلز کو بائیں سے دائیں گنتا ہے، ٹرے کو چھوڑ کر کیونکہ اس کا اپنا کوئی پینل نہیں ہے۔ اس لیے نمبر اسی آئیکن سے میل کھاتا ہے جس کی طرف آپ اشارہ کرتے۔

### Tailscale اور Dropbox

دو مزید وِجٹس بار پر صرف اسی وقت ظاہر ہوتے ہیں جب آپ **Install → Service** سے متعلقہ سروس انسٹال کرتے ہیں، اور دونوں کے بارے میں جاننا فائدہ مند ہے کیونکہ یہ صرف حالت رپورٹ کرنے سے زیادہ کام کرتے ہیں۔

**Tailscale** پینل ٹیل نیٹ کو منسلک اور منقطع کرتا ہے، اکاؤنٹس کے درمیان بدلتا ہے، اور ایگزٹ نوڈ منتخب کرتا ہے (آپ کی اپنی مشینیں اور Mullvad خطے دونوں اس فہرست میں ظاہر ہوتے ہیں)۔ یہ آپ کی مشینیں بھی براؤز کرتا ہے — اور ایک منتخب ہونے پر، `s` Taildrop کے ذریعے اسے فائلیں بھیجتا ہے، جو کسی فائل کو آپ کے فون یا دوسرے لیپ ٹاپ پر منتقل کرنے کا تیز ترین طریقہ ہے۔ `c` مشین کا IP کاپی کرتا ہے، `n` اس کا نام، اور `d` اس کا مکمل DNS نام۔ ہر مشین کی قطار پر بھیجنے کا بٹن بھی ہے، اگر آپ اس کے بجائے کلک کرنا پسند کریں۔ ٹرمینل سے یہی کام `omarchy tailscale send <machine> [file...]` ہے۔

**Dropbox** پینل لاگ اِن سنبھالتا ہے، دکھاتا ہے کہ آپ نے کتنی اسٹوریج استعمال کی ہے، اور حال ہی میں ہم آہنگ کی گئی فائلیں درج کرتا ہے۔

کسی بھی سروس کو ہٹانے سے اس کا وِجٹ بار سے واپس ہٹ جاتا ہے۔

## اشارے

درمیان میں چھوٹا سا جھرمٹ اشاروں والا وِجٹ ہے۔ یہ ان طریقوں کے لیے اسٹیٹس علامات ہیں جنہیں آپ نے آن کیا ہے: پریشان نہ کریں، رات کی روشنی، قطار میں لگی [یاد دہانی](09-reminders.md)، فعال اسکرین ریکارڈنگ، بیدار رہیں، اور [ڈکٹیشن](11-text-extraction-dictation.md)۔ یہ اس وقت روشن ہوتے ہیں جب وہ موڈ فعال ہو اور ورنہ راستے سے ہٹے رہتے ہیں — غیر فعال والوں کو جھانک کر دیکھنے کے لیے بار پر کہیں بھی ہوور کریں۔ کسی اشارے پر کلک کرنے سے وہ موڈ آن/آف ہو جاتا ہے۔ ایک اور صرف اسٹیٹس کے لیے ہے: جب کوئی gliff کے ذریعے اس مشین سے منسلک ہوتا ہے تو ریموٹ سیشن سرخ روشن ہو جاتا ہے۔

اگر آپ چاہتے ہیں کہ یہ ہمیشہ نظر آئیں تو وِجٹ پر `alwaysShow` کو `true` پر سیٹ کریں۔ اور اگر آپ کو صرف ان میں سے کچھ کی پرواہ ہے تو جنہیں آپ چاہتے ہیں انہیں `items` میں درج کریں: `["Dnd", "Reminder", "NightLight"]`۔ آپ کے پاس ایک سے زیادہ اشاروں والے وِجٹ ہو سکتے ہیں، اس لیے مختلف حصے مختلف ذیلی سیٹ دکھا سکتے ہیں۔

## بار کو دوبارہ ترتیب دینا

بار خود کو ترتیب دیتی ہے۔ چیزیں ادھر ادھر کرنے کے لیے آپ کو کوئی کنفگ فائل کھولنے کی ضرورت نہیں۔

بار کے درمیان کے آس پاس کسی خالی جگہ کو پکڑیں اور اسے اسکرین کے کسی اور کنارے کی طرف گھسیٹیں، اور بار وہاں چلی جاتی ہے — بائیں، دائیں، اوپر، یا نیچے سب کام کرتے ہیں، اور ہر وِجٹ ڈھل جاتا ہے (عمودی بارز مختصر صرف آئیکن والی شکلوں پر واپس آ جاتی ہیں)۔ کلک کر کے پکڑے رہنا بھی وہی گھسیٹنا شروع کرتا ہے۔ اسی خالی جگہ پر ڈبل بائیں کلک کر کے بار کے پس منظر کو صاف سے شیشے جیسا اور پھر مبہم تک چکر دیں۔ اور کسی بھی وِجٹ کو گھسیٹ کر دوبارہ ترتیب دیں یا اسے کسی اور حصے میں پھینک دیں؛ دوسرے وِجٹس پھسل کر الگ ہو جاتے ہیں تاکہ جہاں یہ اترے گا وہاں جگہ بن جائے۔

بار کا درمیان ایک ڈبہ ہے: جو کچھ اس میں ہے وہ ایک گروپ کے طور پر درمیان میں رہتا ہے، اور اس کے دونوں طرف کے وِجٹس اس کے کناروں سے لٹکتے ہیں۔ جب آپ کوئی وِجٹ گھسیٹتے ہیں تو ڈبہ ایک آؤٹ لائن کے طور پر نظر آتا ہے، یا جب خالی ہو تو بار کے آر پار ایک لکیر کے طور پر، اور آپ اس میں یا اس کے پاس گرا سکتے ہیں۔ جب کوئی گرائی گئی چیز ڈبے میں اترنے والی ہو تو ڈبہ بڑھ کر وِجٹ کو اپنے اندر لے لیتا ہے۔

جو وِجٹ آپ آس پاس چاہتے ہیں لیکن ہمیشہ نظر میں نہیں، وہ ٹرے کی دراز میں جا سکتا ہے: اسے ٹرے پر گھسیٹیں، اور دراز اسے لینے کے لیے کھل جاتی ہے۔ یہ ایپ آئیکنز کے بعد وہاں بیٹھتا ہے، جب بھی دراز آتی ہے تب ظاہر ہوتا ہے، اور جب اس کا پینل اوپر ہو تو اپنی دراز کو کھلا رکھتا ہے۔ اسے واپس بار پر گھسیٹ کر باہر نکالیں اور واپس رکھ دیں۔

اگر آپ اس کے بجائے مینو سے منتخب کرنا پسند کریں تو **Appearance → Menu Bar** میں مقام ہے، اور **Bar Background** منتخب کرتا ہے کہ بار کیسے بنائی جائے: **Opaque Bar**، **Glassy Bar** (پار دیکھنے والی، جس کے پیچھے جو ہے وہ دھندلا)، یا **Clear Bar**۔

انہی چیزوں کے کمانڈز بھی ہیں، جو آپ کو [dotfiles](31-dotfiles.md) سیٹ اپ کے لیے چاہئیں:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

کسی وِجٹ کو مکمل طور پر شامل یا ہٹانے کے لیے پلگ اِن کمانڈز استعمال کریں۔ `omarchy plugin list` ہر اس وِجٹ کو اس کی id کے ساتھ چھاپتا ہے جسے شیل جانتا ہے، اور پھر:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## بار کو چھپانا

`Super + Shift + Space` شیل کو ختم کیے بغیر بار کو بند اور واپس آن کرتا ہے — پینلز اور ہاٹ کیز کام کرتی رہتی ہیں، آپ کو بس پکسلز واپس مل جاتے ہیں۔ یہ مینو میں **Appearance → Menu Bar → Hide Bar** کے تحت بھی ہے۔

## کنفگ فائل

یہ سب `~/.config/omarchy/shell.json` میں، `bar` کلید کے تحت محفوظ ہے۔ یہ رہا ایک مختصر ورژن:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

ہر وِجٹ پانچ لے آؤٹ صفوں میں سے کسی ایک میں ایک اندراج ہے، اور اس کی ترتیبات اسی اندراج پر اِن لائن بیٹھتی ہیں — کوئی الگ ترتیبات فائل نہیں ہے اور کوئی `config` ذیلی آبجیکٹ نہیں ہے۔ گھڑی کی `format`، `formatAlt` (جس پر دائیں کلک چکر دیتا ہے)، اور `verticalFormat` سب وہیں `{ "id": "omarchy.clock" }` پر رہتی ہیں۔

`center` بار کے درمیان والا ڈبہ ہے: اس میں موجود ہر چیز اسکرین پر ایک گروپ کے طور پر درمیان میں ہوتی ہے۔ `centerBegin` اور `centerEnd` ڈبے کے دونوں طرف لٹکتے ہیں، اسی طرح گھڑی بالکل درمیان میں رہتی ہے چاہے موسم اور اپ ڈیٹ بیج آتے جاتے رہیں۔ `center` میں ایک سے زیادہ وِجٹ رکھیں اور وہ ایک ساتھ درمیان میں آ جاتے ہیں؛ اسے خالی چھوڑ دیں اور `centerBegin` اور `centerEnd` بار کے درمیان میں مل جاتے ہیں۔

ایک اصول جو ذہن نشین کرنے کے قابل ہے: **ایک بار جب آپ کے پاس اپنی `shell.json` ہو جائے تو یہی مستند ہے**۔ جب تک آپ کسی چیز کو اپنی مرضی کے مطابق نہیں بناتے، شیل Omarchy کی ڈیفالٹ فائل پڑھتا ہے۔ جس لمحے آپ کوئی وِجٹ گھسیٹتے ہیں، `omarchy bar` چلاتے ہیں، یا فائل خود ترمیم کرتے ہیں، آپ اس کے مالک بن جاتے ہیں — کوئی گہرا انضمام نہیں ہے، اس لیے آئندہ Omarchy ریلیزز میں نئے ڈیفالٹ وِجٹس آپ کی بار پر خود بخود ظاہر نہیں ہوں گے۔ `omarchy bar defaults` جب بھی آپ صاف سلیٹ چاہیں بھیجی گئی ترتیب واپس رکھ دیتا ہے۔

یہی فائل آپ کے سست اوقات کو بھی اعلیٰ سطح پر، `bar` کلید سے باہر رکھتی ہے: `idle.screensaver` اور `idle.lock`، دونوں آپ کے سست ہونے کے بعد سے سیکنڈز میں۔ اس لیے ڈیفالٹ اسکرین سیور 150 سیکنڈ پر شروع ہوتا ہے اور لاک 300 پر۔
