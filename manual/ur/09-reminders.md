# یاد دہانیاں

Omarchy میں کاؤنٹ ڈاؤن ٹائمر اور پیغام کے ساتھ سادہ یاد دہانیاں سیٹ کرنے کا بلٹ ان طریقہ موجود ہے۔ آپ یہ `Super + Ctrl + R` کے ذریعے کر سکتے ہیں، سیٹ کی ہوئی تمام یاد دہانیاں `Super + Ctrl + Alt + R` کے ذریعے دیکھ سکتے ہیں، اور `Super + Ctrl + Shift + R` کے ذریعے سب صاف کر سکتے ہیں۔ یہ سب کچھ _ٹریگر > Reminder_ کے ذریعے بھی قابل رسائی ہے۔ آپ `omarchy reminder 7 'Tea ready'` کے ساتھ cli بھی استعمال کر سکتے ہیں۔
