# نیٹ ورکنگ

Omarchy میں نیٹ ورکنگ NetworkManager کے ذریعے سنبھالی جاتی ہے، اور آپ اسے [ٹاپ بار](05-the-top-bar.md) میں موجود نیٹ ورک آئیکن سے یا `Super + Ctrl + N` کے ساتھ چلاتے ہیں۔

یہ پینل Wi-Fi نیٹ ورکس تلاش کرتا ہے، سگنل کی طاقت دکھاتا ہے، اور کنیکٹ کرتا ہے۔ Ethernet کو بالکل کسی چیز کی ضرورت نہیں — اسے لگائیں اور یہ کام کرے گا۔ اگر آپ ٹرمینل میں ہی رہنا پسند کرتے ہیں، تو `nmtui` آپ کو وہی کنٹرولز دیتا ہے، اور ایک `omarchy network` کمانڈ گروپ بھی موجود ہے۔

## اپنا Wi-Fi شیئر کرنا

ایک لمبا پاس ورڈ بلند آواز میں پڑھنے کے بجائے، جب آپ Wi-Fi پر ہوں تو _Setup > Network > QR Code_ چلائیں۔ اس سے اسکرین پر ایک QR کوڈ آ جاتا ہے جسے کوئی بھی فون کیمرا اسکین کر کے شامل ہو سکتا ہے۔ یہ ان چیزوں میں سے ایک ہے جسے آپ جاننے کے بعد توقع سے زیادہ استعمال کریں گے۔

اگر آپ کو واقعی پاس ورڈ ہی چاہیے، تو `omarchy network password <interface>` اسے پرنٹ کر دیتا ہے۔

## DNS

Omarchy وہی DNS استعمال کرتا ہے جو آپ کا نیٹ ورک DHCP کے ذریعے دیتا ہے۔ آپ _Setup > Network > DNS_ کے تحت پوری مشین کے لیے اسے اوور رائیڈ کر سکتے ہیں، جہاں Cloudflare اور Google ایک کلک کی دوری پر ہیں۔ اپنے سرورز ٹائپ کرنے کے لیے _Custom_ منتخب کریں۔

ٹرمینل سے، `omarchy dns` موجودہ پرووائیڈر پرنٹ کرتا ہے اور `omarchy dns Cloudflare` ایک سیٹ کرتا ہے۔

## Wi-Fi بینڈ کو پن کرنا

اگر آپ کا راؤٹر 2.4GHz، 5GHz، اور 6GHz کو ایک ہی نیٹ ورک نام پر رکھتا ہے، تو آپ کا لیپ ٹاپ کبھی کبھی سست والے سے چمٹا رہے گا۔ `omarchy network band` دکھاتا ہے کہ آپ کس بینڈ پر ہیں، اور `omarchy network band 5` اسے پن کر دیتا ہے۔ اسے دوبارہ خود منتخب کرنے دینے کے لیے `auto` استعمال کریں۔

یہ کسی مخصوص ایکسیس پوائنٹ کے بجائے بینڈ کو پن کرتا ہے، اس لیے آپ APs کے درمیان معمول کے مطابق روم کرتے رہتے ہیں۔

## یہ کتنا تیز ہے؟

_Trigger > Speed Test > Network Speed Test_ دو ڈائلز کے ساتھ آپ کی اصل اپ اور ڈاؤن اسپیڈ ناپتا ہے۔ ٹرمینل سے یہ `omarchy network speedtest down` یا `up` ہے۔ یہ Omarchy کی اپنی سروس کے مقابلے میں ناپتا ہے اور صرف اس کی ٹیسٹ ٹرانسفرز کو گنتا ہے۔ دوسری ڈاؤن لوڈز بینڈوڈتھ کے لیے مقابلہ کر سکتی ہیں، لیکن انہیں اسپیڈ ٹیسٹ کے نتیجے میں شامل نہیں کیا جاتا۔ (اس مینو میں اس کے ساتھ ہی ایک ڈسک اسپیڈ ٹیسٹ بھی موجود ہے، اگر آپ دوسری رکاوٹ کو بینچ مارک کر رہے ہوں۔)

## فائر وال

فائر وال بائی ڈیفالٹ آن ہوتی ہے اور تمام آنے والی ٹریفک کو بلاک کرتی ہے، ایک استثنا کے ساتھ: پورٹ 53317، تاکہ [LocalSend](22-guis.md) فوراً کام کرے۔

SSH اس وقت تک آف رہتا ہے جب تک آپ اسے _Setup > Security > SSHD_ سے آن نہ کریں، جو ڈیمن شروع کرتا ہے، brute force کے خلاف ریٹ لمیٹ کے ساتھ پورٹ 22 کھولتا ہے، اور ایک key کو اجازت دیتا ہے۔ Docker بھی لاک ڈاؤن ہے، تاکہ کنٹینرز حادثاتی طور پر خود کو دنیا کے سامنے ظاہر نہ کر سکیں۔ پوری کہانی کے لیے [security](48-security.md) دیکھیں۔

## Tailscale

[Tailscale](https://tailscale.com/) ایک میش VPN ہے جو انٹرنیٹ پر آپ کے تمام کمپیوٹرز اور سرورز تک پہنچنا آسان اور محفوظ بناتا ہے۔ اسے _Install > Service > Tailscale_ سے انسٹال کریں۔

اس سے آپ کو بار میں ایک Tailscale پینل ملتا ہے، جو tailnet کو کنیکٹ اور ڈس کنیکٹ کرتا ہے، اکاؤنٹس بدلتا ہے، اور ایک ایگزٹ نوڈ منتخب کرتا ہے — آپ کی اپنی مشینیں اور Mullvad ریجنز دونوں فہرست میں ظاہر ہوتے ہیں۔ یہ آپ کی مشینوں کو براؤز بھی کرتا ہے، اور یہیں Taildrop رہتا ہے: ایک مشین منتخب کریں اور اسے فائلیں بھیجنے کے لیے `s` دبائیں، یا اس کا IP، نام، یا مکمل DNS نام کاپی کرنے کے لیے `c`، `n`، اور `d` دبائیں۔ ٹرمینل میں اس کے برابر `omarchy tailscale send <machine> [file...]` ہے، اور آپ کو بھیجی گئی فائلیں خود بخود `~/Downloads` میں آتی ہیں۔ آمد کا اعلان کرنے والی نوٹیفکیشن اس وقت تک انتظار کرتی ہے جب تک آپ اسے کھولنے کے لیے کلک نہ کریں یا اسے ختم نہ کر دیں، اس لیے جو فائل آپ کے مشین سے دور ہونے کے دوران آئے وہ آپ کے واپس آنے پر جواب دینے کے لیے اب بھی وہیں موجود ہوتی ہے۔

اسے انسٹال کرنے سے Tailscale ایڈمن کنسول کے لیے ایک ویب ایپ بھی شامل ہو جاتی ہے۔

## جب یہ کام کرنا بند کر دے

ری بوٹ کرنے سے پہلے، خراب جز کو الگ سے دوبارہ شروع کرنے کی کوشش کریں۔ _Update > Hardware_ میں Wi-Fi، Bluetooth، Audio، اور Trackpad موجود ہیں، اور ان میں سے کسی ایک کو دوبارہ لوڈ کرنا زیادہ تر "پانچ منٹ پہلے یہ کام کر رہا تھا" والی صورتحال کو ٹھیک کر دیتا ہے۔ [troubleshooting](45-troubleshooting.md) دیکھیں۔
