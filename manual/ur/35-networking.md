# نیٹ ورکنگ

Omarchy میں نیٹ ورکنگ NetworkManager کے ذریعے سنبھالی جاتی ہے، اور آپ اسے [اوپری بار](05-the-top-bar.md) میں موجود نیٹ ورک آئیکن سے یا `Super + Ctrl + N` کے ساتھ چلاتے ہیں۔

وہ پینل Wi-Fi نیٹ ورکس تلاش کرتا ہے، سگنل کی طاقت دکھاتا ہے، اور کنیکٹ کرتا ہے۔ Ethernet کو بالکل کسی چیز کی ضرورت نہیں — بس اسے لگائیں اور یہ کام کرے گا۔ اگر آپ ٹرمینل میں ہی رہنا پسند کرتے ہیں تو `nmtui` آپ کو وہی کنٹرولز دیتا ہے، اور ایک `omarchy network` کمانڈ گروپ بھی موجود ہے۔

## اپنا Wi-Fi شیئر کرنا

ایک لمبا پاس ورڈ زور سے پڑھ کر سنانے کے بجائے، جب آپ Wi-Fi پر ہوں تو _سیٹ اپ > نیٹ ورک > QR Code_ چلائیں۔ اس سے اسکرین پر ایک QR code آ جاتا ہے جسے کوئی بھی فون کیمرا اسکین کر کے شامل ہو سکتا ہے۔ یہ ان چیزوں میں سے ایک ہے جسے، ایک بار پتہ چل جائے کہ یہ موجود ہے، آپ توقع سے زیادہ استعمال کریں گے۔

اگر آپ کو واقعی خود پاس ورڈ ہی چاہیے تو `omarchy network password <interface>` اسے پرنٹ کر دیتا ہے۔

## DNS

Omarchy وہی DNS استعمال کرتا ہے جو آپ کا نیٹ ورک DHCP کے ذریعے فراہم کرتا ہے۔ آپ _سیٹ اپ > نیٹ ورک > DNS_ کے تحت پوری مشین کے لیے اسے تبدیل کر سکتے ہیں، جہاں Cloudflare اور Google صرف ایک کلک کی دوری پر ہیں۔ اپنے سرورز خود لکھنے کے لیے _کسٹم_ منتخب کریں۔

ٹرمینل سے، `omarchy dns` موجودہ پرووائیڈر پرنٹ کرتا ہے اور `omarchy dns Cloudflare` ایک سیٹ کر دیتا ہے۔

## Wi-Fi بینڈ کو پن کرنا

اگر آپ کا راؤٹر 2.4GHz، 5GHz، اور 6GHz کو ایک ہی نیٹ ورک نام پر رکھتا ہے تو آپ کا لیپ ٹاپ کبھی کبھی سست والے سے چمٹا رہے گا۔ `omarchy network band` دکھاتا ہے کہ آپ کس بینڈ پر ہیں، اور `omarchy network band 5` اسے پن کر دیتا ہے۔ اسے دوبارہ خود منتخب کرنے دینے کے لیے `auto` استعمال کریں۔

یہ کسی مخصوص ایکسیس پوائنٹ کے بجائے بینڈ کو پن کرتا ہے، اس لیے آپ معمول کے مطابق APs کے درمیان گھومتے رہتے ہیں۔

## یہ کتنا تیز ہے؟

_ٹرگر > اسپیڈ ٹیسٹ > نیٹ ورک اسپیڈ ٹیسٹ_ آپ کی اصل اپ اور ڈاؤن اسپیڈ کو ڈائلز کے ایک جوڑے کے ساتھ ناپتا ہے۔ ٹرمینل سے یہ `omarchy network speedtest down` یا `up` ہے۔ (اس مینو میں اس کے بالکل ساتھ ایک ڈسک اسپیڈ ٹیسٹ بھی موجود ہے، اگر آپ دوسری رکاوٹ کو بینچ مارک کر رہے ہیں۔)

## فائر وال

فائر وال بطور ڈیفالٹ آن ہوتی ہے اور تمام آنے والی ٹریفک کو روکتی ہے، ایک استثنا کے ساتھ: پورٹ 53317، تاکہ [LocalSend](22-guis.md) بغیر کسی اضافی سیٹ اپ کے کام کرے۔

SSH اس وقت تک آف رہتا ہے جب تک آپ اسے _سیٹ اپ > سیکیورٹی > SSHD_ کے ساتھ آن نہ کریں، جو ڈیمن شروع کرتا ہے، brute force کے خلاف rate-limited پورٹ 22 کھولتا ہے، اور ایک key کو اجازت دیتا ہے۔ Docker بھی لاک ڈاؤن ہے، تاکہ containers غلطی سے خود کو دنیا کے سامنے ظاہر نہ کر دیں۔ پوری کہانی کے لیے [سیکیورٹی](48-security.md) دیکھیں۔

## Tailscale

[Tailscale](https://tailscale.com/) ایک mesh VPN ہے جو انٹرنیٹ پر آپ کے تمام کمپیوٹرز اور سرورز تک پہنچنا آسان اور محفوظ بناتا ہے۔ اسے _انسٹال > سروس > Tailscale_ کے ساتھ انسٹال کریں۔

اس سے آپ کو بار میں ایک Tailscale پینل مل جاتا ہے، جو tailnet کو کنیکٹ اور ڈس کنیکٹ کرتا ہے، اکاؤنٹس بدلتا ہے، اور ایک exit node منتخب کرتا ہے — آپ کی اپنی مشینیں اور Mullvad کے علاقے دونوں فہرست میں نظر آتے ہیں۔ یہ آپ کی مشینوں کو بھی براؤز کرتا ہے، اور یہی وہ جگہ ہے جہاں Taildrop رہتا ہے: ایک مشین منتخب کریں اور اسے فائلیں بھیجنے کے لیے `s` دبائیں، یا اس کا IP، نام، یا مکمل DNS نام کاپی کرنے کے لیے `c`، `n`، اور `d` دبائیں۔ ٹرمینل میں اس کے مساوی `omarchy tailscale send <machine> [file...]` ہے، اور آپ کو بھیجی گئی فائلیں خود بخود `~/Downloads` میں آ جاتی ہیں۔ آمد کی اطلاع دینے والا نوٹیفکیشن اس وقت تک انتظار کرتا ہے جب تک آپ اسے کھولنے کے لیے کلک نہ کریں یا اسے مسترد نہ کر دیں، اس لیے جو فائل آپ کے مشین سے دور ہونے کے دوران آئے وہ واپس آنے پر جواب دینے کے لیے اب بھی وہیں موجود ہوتی ہے۔

اسے انسٹال کرنے سے Tailscale ایڈمن کنسول کے لیے ایک ویب ایپ بھی شامل ہو جاتی ہے۔

## جب یہ کام کرنا بند کر دے

ری بوٹ کرنے سے پہلے، خرابی پیدا کرنے والے حصے کو الگ سے دوبارہ شروع کر کے دیکھیں۔ _اپ ڈیٹ > ہارڈویئر_ میں Wi-Fi، Bluetooth، Audio، اور Trackpad موجود ہیں، اور ان میں سے کسی ایک کو دوبارہ لوڈ کرنے سے زیادہ تر "یہ پانچ منٹ پہلے کام کر رہا تھا" والی صورتحال ٹھیک ہو جاتی ہے۔ [خرابیوں کا ازالہ](45-troubleshooting.md) دیکھیں۔
