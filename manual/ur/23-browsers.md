# براؤزرز

Omarchy [Chromium](https://www.chromium.org/) کے ساتھ ڈیفالٹ براؤزر کے طور پر آتا ہے। یہ سادی اوپن سورس بلڈ ہے، جو آپ کے باقی سسٹم سے میل کھانے کے لیے تھیم شدہ ہے، اور یہی وہ چیز ہے جسے `Super + Shift + Return` کھولتا ہے اور جس کے اندر ہر [ویب ایپ](25-web-apps.md) چلتی ہے।

اگر Chromium آپ کے مزاج کے مطابق نہیں ہے تو آپ اس کے ساتھ پھنسے نہیں ہیں۔ Omarchy مینو میں _انسٹال کریں > براؤزر_ کے تحت آپ کو Chrome، Edge، Brave، Brave Origin، Firefox اور [Zen](https://zen-browser.app/) ملیں گے। ایک منتخب کریں اور Omarchy اسے انسٹال کرے گا، اس کی پالیسی ڈائریکٹری ترتیب دے گا، اور اس پر آپ کی موجودہ تھیم لاگو کرے گا।

## کسی ایک کو ڈیفالٹ بنانا

براؤزر انسٹال کرنے سے وہ ترقی یافتہ نہیں ہو جاتا۔ جب یہ مشین پر آ جائے تو _سیٹ اپ > ڈیفالٹس > براؤزر_ پر جائیں اور اسے منتخب کریں — مینو صرف انہی براؤزرز کی فہرست بناتا ہے جو آپ نے اصل میں انسٹال کیے ہوئے ہوں، اور موجودہ ڈیفالٹ کو چیک نشان سے ظاہر کرتا ہے।

ٹرمینل سے یہ اس طرح ہے:

```bash
omarchy default browser firefox
```

اسے بغیر کسی آرگومنٹ کے چلائیں اور یہ آپ کو موجودہ ڈیفالٹ بتا देگا। یہ XDG ہینڈلر مقرر کرتا है، لہٰذا یہ صرف Omarchy کے ہاٹ کیز نہیں جو اس کی پیروی کرتے ہیں — جو بھی چیز لنک کھولتی ہے، چیٹ ایپ سے لے کر ٹرمینل کمانڈ تک، وہ آپ کے منتخب براؤزر کی طرف جاتی ہے।

## URL کاپی کریں اور ویڈیو ڈاؤن لوڈ کریں

Chromium خاندان کے براؤزرز (خود Chromium، Chrome، Edge اور Brave) Omarchy کی دو ایسی ایکسٹینشنز کے ساتھ آتے ہیں جو براؤزر سے باہر نکل کر آپ کے باقی سسٹم تک पहنچتی ہیں।

**URL کاپی کریں** `Alt + Shift + L` سے موجودہ ٹیب کا پتہ آپ کے کلپ بورڈ پر رکھتا ہے। یہ ایڈریس بار میں کلک کر کے کاپی کرنے سے تیز ہے، اور چونکہ یہ براؤزر کے بجائے سسٹم کلپ بورڈ سے گزرتا ہے، اس لیے آپ کو اس کی تصدیق کرتی Omarchy اطلاع ملتی ہے اور URL فوری طور پر [کلپ بورڈ ہسٹری](08-unified-clipboard-history.md) اور ہر دیگر ایپ میں دستیاب ہو جاتا ہے। ٹول بار بٹن بھی موجود ہے، اگر آپ کلک کرنا پسند کریں।

**ویڈیو ڈاؤن لوڈ کریں** `Alt + Shift + D` سے اس صفحے پر چلنے والی ویڈیو کو حاصل کرتا ہے جسے آپ دیکھ رہے ہیں। یہ URL کو [yt-dlp](https://github.com/yt-dlp/yt-dlp) کے حوالے کرتا ہے، لہٰذا یہ YouTube سے کہیں زیادہ پر کام کرتا ہے، اور ڈاؤن لوڈ `~/Videos` میں گرتی ہے। پیشرفت اسی آن اسکرین ڈسپلے میں ظاہر ہوتی ہے جسے آواز اور چمک استعمال کرتے ہیں، اطلاعات کا ڈھیر لگانے کے بجائے اسی جگہ اپ ڈیٹ ہوتی ہوئی। اگر آپ چاہیں کہ فائلیں کہیں اور جائیں تو `OMARCHY_YTDLP_DIR` مقرر کریں — ماحولیاتی متغیرات کہاں رکھنے ہیں اس کے لیے [عمومی سوالات](46-faq.md) دیکھیں।

دونوں ایکسٹینشنز ایک چھوٹے مقامی میسجنگ ہوسٹ کے ذریعے Omarchy سے بات کرتی ہیں، جو براؤزر کے साथ آپ کے لیے انسٹال ہو جاتا ہے। یہی وہ ٹکڑا ہے جو ویب پیج کی ویڈیو کو آپ کی ہوم ڈائریکٹری میں اور URL کو آپ کے کلپ بورڈ مینیجر میں پہنچنے دیتا ہے، جو ایک عام ایکسٹینشن خود سے نہیں کر سکتی।

یہ صرف Chromium خاندان کے لیے ہیں। Firefox اور Zen کو یہ نہیں ملتیں।

## Firefox اور Zen

Firefox اور Zen ایک مختلف خاندان ہیں، لہٰذا انہیں مختلف سلوک मिलता है: Omarchy معقول ڈیفالٹس کے لیے پالیسی فائل انسٹال کرتا ہے اور انہیں مقامی Wayland موڈ میں بدل دیتا है، جو آپ کو فریکشنل اسکیلنگ اور ہموار ٹریک پیڈ اسکرولنگ کے لیے چاہیے।

انہیں اوپر والی Chromium ایکسٹینشنز نہیں ملتیں، اور یہ Omarchy کے ذریعے تھیم بھی نہیں ہوتیں، لہٰذا تجربے کے وہ حصے ترتیب دینا آپ کے ذمے है।

## کسی ایک کو دوبارہ ہٹانا

یہاں آپ نے جو کچھ بھی انسٹال کیا ہے اسے _ہٹائیں > براؤزر_ کے تحت واپس اتارا جا سکتا है। Chromium اس فہرست میں नहीं है — یہ بنیادی سسٹم کا حصہ ہے।
