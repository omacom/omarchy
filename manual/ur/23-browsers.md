# براؤزرز

Omarchy بطور ڈیفالٹ براؤزر [Google Chrome](https://www.google.com/chrome/) کے ساتھ آتا ہے۔ اسے آپ کے باقی سسٹم سے میل کھانے کے لیے تھیم کیا گیا ہے، اور یہی وہ براؤزر ہے جو `Super + Shift + Return` (یا `Super + Shift + B`) سے کھلتا ہے، پرائیویٹ ونڈو کے لیے `Super + Shift + Alt + B` کے ساتھ، اور جس کے اندر ہر [ویب ایپ](25-web-apps.md) چلتی ہے۔ یہ سیدھا براؤزر ونڈو پر کھلتا ہے: کوئی ویلکم اسکرین یا سائن ان پرامپٹ نہیں ہے، استعمال کے اعداد و شمار اور کریش رپورٹس Google کو نہیں بھیجی جاتیں، اور اشتہاری پرائیویسی پرامپٹس بند کر دیے گئے ہیں۔ جب بھی آپ سنک چاہیں، آپ پروفائل بٹن سے اپنے Google اکاؤنٹ میں سائن ان کر سکتے ہیں۔

اگر Chrome آپ کے ذوق کے مطابق نہیں ہے، تو آپ اسی کے ساتھ پھنسے نہیں ہیں۔ Omarchy مینو میں _انسٹال > براؤزر_ کے تحت آپ کو [Chromium](https://www.chromium.org/) (وہ سادہ اوپن سورس بلڈ جس سے Chrome بنایا گیا ہے)، Edge، Brave، Brave Origin، Firefox، [Zen](https://zen-browser.app/)، اور [Ladybird](https://ladybird.org/) ملیں گے (Edge صرف x86 مشینوں پر)۔ کوئی ایک منتخب کریں اور Omarchy اسے انسٹال کر دے گا، اس کی پالیسی ڈائریکٹری سیٹ اپ کرے گا، اور اس پر آپ کی موجودہ تھیم لاگو کرے گا۔

## کسی ایک کو ڈیفالٹ بنانا

براؤزر انسٹال کرنے سے وہ ڈیفالٹ نہیں بن جاتا۔ تبدیل کرنے کے لیے _سیٹ اپ > ڈیفالٹس > براؤزر_ پر جائیں اور کوئی ایک منتخب کریں۔ موجودہ ڈیفالٹ پر چیک کا نشان لگا ہوتا ہے، اور ایسا براؤزر منتخب کرنا جو آپ کے پاس ابھی نہیں ہے، پہلے اسے انسٹال کر دے گا۔

ٹرمینل سے یہ اس طرح ہے:

```bash
omarchy default browser firefox
```

اسے بغیر کسی آرگومنٹ کے چلائیں اور یہ آپ کو موجودہ ڈیفالٹ بتا دے گا۔ یہ XDG ہینڈلر سیٹ کرتا ہے، اس لیے صرف Omarchy کی ہاٹ کیز ہی اس کی پیروی نہیں کرتیں — کوئی بھی چیز جو لنک کھولتی ہے، چاہے چیٹ ایپ ہو یا ٹرمینل کمانڈ، اسی براؤزر پر جاتی ہے جسے آپ نے منتخب کیا ہے۔

## Copy URL اور Download Video

Chromium خاندان کے براؤزرز (خود Chromium، Chrome، Edge، Brave، اور Brave Origin) تین Omarchy ایکسٹینشنز کے ساتھ آتے ہیں: دو جو براؤزر سے باہر نکل کر آپ کے باقی سسٹم تک پہنچتی ہیں، اور ایک جو WhatsApp کو سنوارتی ہے۔

**Copy URL** `Alt + Shift + L` کے ساتھ موجودہ ٹیب کا ایڈریس آپ کے کلپ بورڈ پر رکھ دیتا ہے۔ یہ ایڈریس بار میں کلک کر کے کاپی کرنے سے تیز تر ہے، اور چونکہ یہ براؤزر کے بجائے سسٹم کلپ بورڈ کے ذریعے جاتا ہے، آپ کو Omarchy کی طرف سے اس کی تصدیق کرنے والی اطلاع ملتی ہے اور URL فوراً [کلپ بورڈ ہسٹری](08-unified-clipboard-history.md) اور ہر دوسری ایپ میں دستیاب ہو جاتا ہے۔ اگر آپ کلک کرنا پسند کرتے ہیں تو ٹول بار بٹن بھی موجود ہے۔

**Download Video** `Alt + Shift + D` کے ساتھ اس صفحے پر چل رہی ویڈیو کو حاصل کر لیتا ہے جسے آپ دیکھ رہے ہیں۔ یہ URL [yt-dlp](https://github.com/yt-dlp/yt-dlp) کے حوالے کر دیتا ہے، اس لیے یہ صرف YouTube تک محدود نہیں بلکہ اس سے کہیں زیادہ پر کام کرتا ہے، اور ڈاؤن لوڈ `~/Videos` میں اترتا ہے۔ پیش رفت اسی آن اسکرین ڈسپلے میں نظر آتی ہے جو والیم اور برائٹنیس استعمال کرتے ہیں، اطلاعات کا ڈھیر لگانے کے بجائے وہیں اپ ڈیٹ ہوتی رہتی ہے۔ اگر آپ چاہتے ہیں کہ فائلیں کہیں اور جائیں تو `OMARCHY_YTDLP_DIR` سیٹ کریں — ماحولیاتی ویری ایبلز کہاں رکھنے ہیں اس کے لیے [FAQ](46-faq.md) دیکھیں۔

دونوں ایکسٹینشنز ایک چھوٹے native messaging host کے ذریعے Omarchy سے بات کرتی ہیں، جو براؤزر کے ساتھ آپ کے لیے انسٹال ہو جاتا ہے۔ یہی وہ حصہ ہے جو ویب صفحے کی ویڈیو کو آپ کی ہوم ڈائریکٹری میں اور URL کو آپ کے کلپ بورڈ مینیجر میں پہنچنے دیتا ہے، جو ایک عام ایکسٹینشن اکیلے نہیں کر سکتی۔

**WhatsApp Slim** WhatsApp Web کو آپ کی سسٹم تھیم کی پیروی کرنے پر لگا دیتا ہے اور ونڈو تنگ ہونے پر اس کی چیٹ فہرست کو سمیٹ دیتا ہے۔

یہ صرف Chromium خاندان کے لیے ہیں۔ Firefox اور Zen کو یہ نہیں ملتیں۔

## Firefox اور Zen

Firefox اور Zen ایک مختلف خاندان ہیں، اس لیے ان کے ساتھ مختلف سلوک ہوتا ہے: Omarchy سمجھدار ڈیفالٹس کے لیے ایک پالیسیز فائل انسٹال کرتا ہے اور انہیں native Wayland موڈ میں سوئچ کر دیتا ہے، جو آپ فریکشنل اسکیلنگ اور ہموار ٹریک پیڈ اسکرولنگ کے لیے چاہتے ہیں۔

انہیں اوپر والی Chromium ایکسٹینشنز نہیں ملتیں، اور انہیں Omarchy تھیم بھی نہیں کرتا، اس لیے تجربے کے وہ حصے آپ کو خود سیٹ اپ کرنے ہیں۔

## Ladybird

Ladybird ایک براؤزر ہے جو شروع سے لکھا گیا ہے، Chromium یا Firefox کے انجن کے بجائے اس کا اپنا انجن ہے۔ یہ ابھی الفا میں ہے، اس لیے ایسی سائٹس کی توقع رکھیں جو ابھی کام نہیں کرتیں، اور Omarchy اسے جیسا ہے ویسا ہی انسٹال کرتا ہے: کوئی ایکسٹینشن نہیں، کوئی تھیم نہیں، کوئی پالیسی نہیں۔ اس میں پرائیویٹ ونڈو بھی نہیں ہے، اس لیے `Super + Shift + Alt + B` اسے ایک عارضی پروفائل کے ساتھ کھولتا ہے جو آپ کے اسے بند کرتے ہی حذف ہو جاتی ہے۔ [ویب ایپس](25-web-apps.md) Chrome یا Chromium میں چلتی رہتی ہیں۔

## کسی ایک کو دوبارہ ہٹانا

ان براؤزرز میں سے کسی کو بھی، Chrome سمیت، _ہٹائیں > براؤزر_ کے تحت واپس اتارا جا سکتا ہے۔ پھر لنکس Chrome یا Chromium پر جائیں گے اگر دوسرا ابھی انسٹال ہو۔
