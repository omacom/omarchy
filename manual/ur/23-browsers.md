# براؤزرز

Omarchy ڈیفالٹ براؤزر کے طور پر [Google Chrome](https://www.google.com/chrome/) کے ساتھ آتا ہے۔ اسے آپ کے باقی سسٹم سے ہم آہنگ تھیم دی گئی ہے، اور یہی وہ براؤزر ہے جو `Super + Shift + Return` سے کھلتا ہے اور جس کے اندر ہر [ویب ایپ](25-web-apps.md) چلتی ہے۔ یہ سیدھا براؤزر ونڈو میں کھلتا ہے: نہ کوئی ویلکم اسکرین ہے اور نہ سائن ان کا پیغام، استعمال کے اعداد و شمار اور کریش رپورٹس Google کو نہیں بھیجی جاتیں، اور اشتہاری پرائیویسی کے پیغامات بند کیے گئے ہیں۔ جب بھی آپ کو سنک درکار ہو، آپ پروفائل بٹن سے اپنے Google اکاؤنٹ میں سائن ان کر سکتے ہیں۔

اگر Chrome آپ کے مزاج کے مطابق نہیں ہے تو آپ اسی پر پھنسے نہیں ہیں۔ Omarchy مینیو میں _Install > Browser_ کے تحت آپ کو [Chromium](https://www.chromium.org/) (سادہ اوپن سورس بلڈ جس سے Chrome بنایا گیا ہے)، Edge، Brave، Brave Origin، Firefox، اور [Zen](https://zen-browser.app/) ملیں گے۔ کوئی ایک منتخب کریں اور Omarchy اسے انسٹال کر دیتا ہے، اس کی پالیسی ڈائریکٹری ترتیب دیتا ہے، اور اس پر آپ کی موجودہ تھیم لاگو کر دیتا ہے۔

## کسی ایک کو ڈیفالٹ بنانا

براؤزر انسٹال کرنا اسے ڈیفالٹ نہیں بناتا۔ جب وہ مشین پر آ جائے تو _Setup > Defaults > Browser_ میں جائیں اور اسے منتخب کریں — مینیو صرف وہی براؤزر دکھاتا ہے جو آپ نے واقعی انسٹال کیے ہیں، اور موجودہ ڈیفالٹ کو چیک کے نشان سے ظاہر کرتا ہے۔

ٹرمینل سے یہ اس طرح ہے:

```bash
omarchy default browser firefox
```

اسے بغیر کسی آرگومنٹ کے چلائیں اور یہ آپ کو موجودہ ڈیفالٹ بتا دیتا ہے۔ یہ XDG ہینڈلر سیٹ کرتا ہے، اس لیے صرف Omarchy کی ہاٹ کیز ہی اس کی پیروی نہیں کرتیں — جو بھی چیز کوئی لنک کھولتی ہے، چیٹ ایپ سے لے کر ٹرمینل کمانڈ تک، وہ اسی براؤزر میں جاتی ہے جسے آپ نے منتخب کیا ہے۔

## Copy URL اور Download Video

Chromium خاندان کے براؤزرز (خود Chromium، Chrome، Edge، اور Brave) دو Omarchy ایکسٹینشنز کے ساتھ آتے ہیں جو براؤزر سے باہر نکل کر آپ کے باقی سسٹم تک پہنچتی ہیں۔

**Copy URL** موجودہ ٹیب کا ایڈریس `Alt + Shift + L` سے آپ کے کلپ بورڈ پر رکھ دیتا ہے۔ یہ ایڈریس بار میں کلک کر کے کاپی کرنے سے تیز تر ہے، اور چونکہ یہ براؤزر کے بجائے سسٹم کلپ بورڈ سے گزرتا ہے، اس لیے آپ کو اس کی تصدیق کرنے والی Omarchy نوٹیفکیشن ملتی ہے اور URL فوراً [کلپ بورڈ ہسٹری](08-unified-clipboard-history.md) اور ہر دوسری ایپ میں دستیاب ہو جاتا ہے۔ اگر آپ کلک کرنا پسند کرتے ہیں تو اس کے لیے ٹول بار بٹن بھی موجود ہے۔

**Download Video** اس صفحے پر چل رہی ویڈیو کو `Alt + Shift + D` سے حاصل کر لیتا ہے جسے آپ دیکھ رہے ہیں۔ یہ URL [yt-dlp](https://github.com/yt-dlp/yt-dlp) کو سونپ دیتا ہے، اس لیے یہ صرف YouTube سے کہیں زیادہ پر کام کرتا ہے، اور ڈاؤن لوڈ `~/Videos` میں آتا ہے۔ پیش رفت اسی آن اسکرین ڈسپلے میں نظر آتی ہے جو والیوم اور چمک کے لیے استعمال ہوتا ہے، اور نوٹیفکیشنز کے انبار لگانے کے بجائے وہیں اپ ڈیٹ ہوتی رہتی ہے۔ اگر آپ چاہتے ہیں کہ فائلیں کہیں اور جائیں تو `OMARCHY_YTDLP_DIR` سیٹ کریں — ماحولیاتی متغیرات کہاں رکھنے ہیں اس کے لیے [FAQ](46-faq.md) دیکھیں۔

دونوں ایکسٹینشنز ایک چھوٹے نیٹو میسجنگ ہوسٹ کے ذریعے Omarchy سے بات کرتی ہیں، جو براؤزر کے ساتھ آپ کے لیے انسٹال ہو جاتا ہے۔ یہی وہ حصہ ہے جو کسی ویب صفحے کی ویڈیو کو آپ کی ہوم ڈائریکٹری میں اور کسی URL کو آپ کے کلپ بورڈ مینیجر میں پہنچنے دیتا ہے، جو کوئی عام ایکسٹینشن اپنے طور پر نہیں کر سکتی۔

یہ صرف Chromium خاندان کے لیے ہیں۔ Firefox اور Zen کو یہ نہیں ملتیں۔

## Firefox اور Zen

Firefox اور Zen ایک مختلف خاندان ہیں، اس لیے ان کے ساتھ مختلف سلوک کیا جاتا ہے: Omarchy مناسب ڈیفالٹس کے لیے ایک پالیسیز فائل انسٹال کرتا ہے اور انہیں نیٹو Wayland موڈ میں بدل دیتا ہے، جو آپ کو فریکشنل اسکیلنگ اور ہموار ٹریک پیڈ اسکرولنگ کے لیے چاہیے ہوتا ہے۔

انہیں اوپر والی Chromium ایکسٹینشنز نہیں ملتیں، اور انہیں Omarchy تھیم بھی نہیں کرتا، اس لیے تجربے کے وہ حصے ترتیب دینا آپ کا کام ہے۔

## کسی ایک کو دوبارہ ہٹانا

ان میں سے کوئی بھی براؤزر، Chrome سمیت، _Remove > Browser_ کے تحت دوبارہ ہٹایا جا سکتا ہے۔ پھر لنکس Chrome یا Chromium میں جاتے ہیں اگر دوسرا اب بھی انسٹال شدہ ہو۔
