# براؤزرز

Omarchy ڈیفالٹ براؤزر کے طور پر [Google Chrome](https://www.google.com/chrome/) کے ساتھ آتا ہے۔ اسے آپ کے باقی سسٹم سے ہم آہنگ تھیم دی گئی ہے، اور یہی وہ براؤزر ہے جو `Super + Shift + Return` (یا `Super + Shift + B`) سے کھلتا ہے، جبکہ `Super + Shift + Alt + B` پرائیویٹ ونڈو کے لیے ہے، اور ہر [ویب ایپ](25-web-apps.md) اسی کے اندر چلتی ہے۔ یہ سیدھا براؤزر ونڈو پر کھلتا ہے: کوئی ویلکم اسکرین یا سائن ان پرامپٹ نہیں ہے، استعمال کے اعداد و شمار اور کریش رپورٹس Google کو نہیں بھیجی جاتیں، اور اشتہاری پرائیویسی پرامپٹس بند ہیں۔ اگر آپ چاہیں تو پروفائل بٹن سے کسی بھی وقت اپنے Google اکاؤنٹ میں سائن ان کر کے ہم آہنگی حاصل کر سکتے ہیں۔

اگر Chrome آپ کے ذوق کے مطابق نہیں ہے تو آپ اسی پر مجبور نہیں ہیں۔ Omarchy مینو میں _انسٹال > براؤزر_ کے تحت آپ کو [Chromium](https://www.chromium.org/) (وہ سادہ اوپن سورس بلڈ جس سے Chrome بنایا گیا ہے)، Edge، Brave، Brave Origin، Firefox، اور [Zen](https://zen-browser.app/) ملیں گے (Edge صرف x86 مشینوں پر)۔ کسی ایک کو منتخب کریں اور Omarchy اسے انسٹال کر دیتا ہے، اس کی پالیسی ڈائریکٹری ترتیب دیتا ہے، اور آپ کی موجودہ تھیم اس پر لاگو کر دیتا ہے۔

## کسی ایک کو ڈیفالٹ بنانا

کسی براؤزر کو انسٹال کرنا اسے ڈیفالٹ نہیں بنا دیتا۔ تبدیل کرنے کے لیے _سیٹ اپ > ڈیفالٹس > براؤزر_ پر جائیں اور کسی ایک کو منتخب کریں۔ موجودہ ڈیفالٹ پر نشان لگا ہوتا ہے، اور اگر آپ ایسا براؤزر منتخب کریں جو ابھی آپ کے پاس نہیں ہے تو وہ پہلے انسٹال ہو جائے گا۔

ٹرمینل سے یہ ہے:

```bash
omarchy default browser firefox
```

اسے بغیر کسی آرگیومنٹ کے چلائیں تو یہ آپ کو موجودہ ڈیفالٹ بتا دیتا ہے۔ یہ XDG ہینڈلر سیٹ کرتا ہے، اس لیے صرف Omarchy کی ہاٹ کیز ہی اس کی پیروی نہیں کرتیں — جو بھی چیز کوئی لنک کھولے، چاہے وہ چیٹ ایپ ہو یا ٹرمینل کمانڈ، وہ اسی براؤزر میں جائے گی جسے آپ نے منتخب کیا ہے۔

## URL کاپی کرنا اور ویڈیو ڈاؤن لوڈ کرنا

Chromium خاندان کے براؤزرز (خود Chromium، Chrome، Edge، Brave، اور Brave Origin) تین Omarchy ایکسٹینشنز کے ساتھ آتے ہیں: دو جو براؤزر سے باہر نکل کر آپ کے باقی سسٹم تک پہنچتی ہیں، اور ایک جو WhatsApp کو سنوارتی ہے۔

**Copy URL** موجودہ ٹیب کا پتہ `Alt + Shift + L` کے ساتھ آپ کے کلپ بورڈ پر رکھ دیتا ہے۔ یہ ایڈریس بار میں کلک کر کے کاپی کرنے سے زیادہ تیز ہے، اور چونکہ یہ براؤزر کے بجائے سسٹم کلپ بورڈ کے ذریعے جاتا ہے، اس لیے آپ کو Omarchy کی اطلاع ملتی ہے جو اس کی تصدیق کرتی ہے اور URL فوراً [کلپ بورڈ ہسٹری](08-unified-clipboard-history.md) اور ہر دوسری ایپ میں دستیاب ہو جاتا ہے۔ اگر آپ کلک کرنا پسند کرتے ہیں تو ٹول بار بٹن بھی موجود ہے۔

**Download Video** اس صفحے پر چل رہی ویڈیو کو `Alt + Shift + D` کے ساتھ حاصل کر لیتا ہے جسے آپ دیکھ رہے ہیں۔ یہ URL [yt-dlp](https://github.com/yt-dlp/yt-dlp) کے حوالے کر دیتا ہے، اس لیے یہ YouTube سے کہیں زیادہ جگہوں پر کام کرتا ہے، اور ڈاؤن لوڈ `~/Videos` میں آ جاتا ہے۔ پیش رفت اسی آن اسکرین ڈسپلے میں نظر آتی ہے جو والیوم اور چمک کے لیے استعمال ہوتا ہے، اور اطلاعات کے ڈھیر لگانے کے بجائے وہیں اپڈیٹ ہوتی رہتی ہے۔ اگر آپ چاہتے ہیں کہ فائلیں کہیں اور جائیں تو `OMARCHY_YTDLP_DIR` سیٹ کریں — ماحولیاتی متغیرات کہاں رکھنے ہیں اس کے لیے [FAQ](46-faq.md) دیکھیں۔

دونوں ایکسٹینشنز ایک چھوٹے native messaging host کے ذریعے Omarchy سے بات کرتی ہیں، جو براؤزر کے ساتھ آپ کے لیے انسٹال ہو جاتا ہے۔ یہی وہ حصہ ہے جو کسی ویب صفحے کی ویڈیو کو آپ کی ہوم ڈائریکٹری میں اور URL کو آپ کے کلپ بورڈ مینیجر میں پہنچنے دیتا ہے، جو کوئی عام ایکسٹینشن خود نہیں کر سکتی۔

**WhatsApp Slim** WhatsApp Web کو آپ کی سسٹم تھیم کے مطابق بنا دیتا ہے اور جب ونڈو تنگ ہو تو اس کی چیٹ لسٹ سکیڑ دیتا ہے۔

یہ صرف Chromium خاندان کے لیے ہیں۔ Firefox اور Zen کو یہ نہیں ملتیں۔

## Firefox اور Zen

Firefox اور Zen ایک مختلف خاندان ہیں، اس لیے ان کے ساتھ مختلف سلوک ہوتا ہے: Omarchy معقول ڈیفالٹس کے لیے ایک policies فائل انسٹال کرتا ہے اور انہیں native Wayland موڈ میں بدل دیتا ہے، جو آپ کو fractional scaling اور ہموار ٹریک پیڈ اسکرولنگ کے لیے چاہیے ہوتا ہے۔

انہیں اوپر والی Chromium ایکسٹینشنز نہیں ملتیں، اور Omarchy انہیں تھیم بھی نہیں دیتا، اس لیے تجربے کے یہ حصے آپ کو خود ترتیب دینے ہیں۔

## کسی ایک کو دوبارہ ہٹانا

ان میں سے کوئی بھی براؤزر، Chrome سمیت، _ہٹائیں > براؤزر_ کے تحت دوبارہ اتارا جا سکتا ہے۔ پھر لنکس Chrome یا Chromium میں جائیں گے اگر دوسرا والا اب بھی انسٹال شدہ ہو۔
