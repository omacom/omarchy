# اکثر پوچھے جانے والے سوالات

### میں کی بورڈ لے آؤٹس کے درمیان کیسے سوئچ کروں؟

اپنی `~/.config/hypr/input.lua` فائل میں ترمیم کریں اور `Left Alt + Right Alt` پر لے آؤٹس کے درمیان سوئچ کرنے کے لیے یہ شامل کریں:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

جب آپ کے پاس متعدد لے آؤٹس ترتیب شدہ ہوں گے تو بار خودکار طور پر آپ کا موجودہ کی بورڈ لے آؤٹ دکھائے گا (اور آپ سوئچ کرنے کے لیے اس پر کلک بھی کر سکتے ہیں)۔

### میں گھڑی کا فارمیٹ 12-hour میں کیسے تبدیل کروں؟

عام فارمیٹس میں چکر لگانے کے لیے بار میں گھڑی پر دائیں کلک کریں، جن میں 12-hour والے بھی شامل ہیں۔ آپ فارمیٹ براہِ راست بھی سیٹ کر سکتے ہیں:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

یہ اتوار 10:55 AM دکھائے گا۔

### میں اپنا timezone کیسے تبدیل کروں؟

Omarchy مینیو میں _اپ ڈیٹ > Timezone_ چلائیں اور فہرست میں سے منتخب کریں۔ اگر timezone درست ہے لیکن گھڑی خود پیچھے رہ گئی ہے، تو _اپ ڈیٹ > Time_ آپ کے لیے وقت کی ہم وقت سازی دوبارہ شروع کر دیتا ہے۔

### میں اپنا DNS کیسے تبدیل کروں، اپنا Wi-Fi کیسے شیئر کروں، یا اپنے کنکشن کی رفتار کیسے چیک کروں؟

یہ سب [نیٹ ورکنگ](35-networking.md) میں موجود ہیں۔

### میں کیسے چیک کروں کہ میری disk کتنی تیز ہے؟

_ٹرگر > Speed Test > Disk Speed Test_ آپ کی ڈرائیو پر لائیو پڑھنے اور لکھنے کی رفتار ناپتا ہے، یا ٹرمینل سے `omarchy disk speedtest` چلائیں۔

### میں پرنٹر کیسے شامل کروں؟

پرنٹنگ باکس سے باہر ہی سیٹ اپ اور چل رہی ہوتی ہے، اور آپ ہر پرنٹر خود ایپ لانچر (`Super + Space`) میں _Print Settings_ سے شامل کرتے ہیں۔

_Add_ منتخب کریں، اور اسے تلاش کرنے کے لیے ایک لمحہ دیں: USB کے ذریعے لگایا گیا پرنٹر، اور زیادہ تر نیٹ ورک پرنٹرز، آپ کے لیے خود مل جاتے ہیں۔ اگر آپ کا پرنٹر فہرست میں نہیں ہے، تو _Network Printer > Internet Printing Protocol (ipp)_ منتخب کریں اور اس کا پتہ درج کریں — پرنٹر کی اپنی ڈسپلے یا اس کا ویب پیج آپ کو بتائے گا کہ وہ کیا ہے، عام طور پر کچھ ایسا جیسے `192.168.1.50` جس کی queue `ipp/print` ہو۔ پھر _Forward_ ایک ڈرائیور پیش کرتا ہے، جہاں جدید پرنٹر ڈرائیور لیس _IPP Everywhere_ پروفائل پر بہترین کام کرتا ہے اور پرانے پرنٹر کو اس ماڈل کا اپنا ڈرائیور چاہیے ہوتا ہے۔

کسی پرنٹر پر دائیں کلک کریں اور یہ منتخب کرنے کے لیے کہ آپ کی ایپس پہلے کس پرنٹر تک پہنچیں _Set as Default_ منتخب کریں، اور کاغذ کا سائز، duplex اور معیار سیٹ کرنے کے لیے _Properties_ منتخب کریں۔

خودکار دریافت، جہاں نیٹ ورک پر پرنٹرز شامل کیے بغیر ظاہر ہو جاتے ہیں، عارضی طور پر بند ہے جب کہ اس پر دوبارہ کام ہو رہا ہے، اسی لیے اوپر والا پہلا قدم خودکار ہونے کے بجائے آپ کا ہے۔ کسی بھی پرنٹر کے بغیر بھی PDF فائل پر پرنٹ کرنا کام کرتا ہے۔

### میں اسکرین شاٹس یا اسکرین ریکارڈنگز کے محفوظ ہونے کی جگہ کیسے تبدیل کروں؟

محفوظ کردہ اسکرین شاٹس بطور ڈیفالٹ `~/Pictures/Screenshots` میں جاتے ہیں۔ کوئی اور ڈائرکٹری استعمال کرنے کے لیے، یہ `~/.config/uwsm/env.d/` کے تحت ایک فائل (جیسے `~/.config/uwsm/env.d/capture`) میں شامل کریں:

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

آپ اسکرین ریکارڈنگز کے لیے بھی `OMARCHY_SCREENRECORD_DIR` استعمال کر کے ایسا ہی کر سکتے ہیں۔

Omasnap اپنی اسکرین شاٹ ڈائرکٹری خودکار طور پر بنا دیتا ہے۔ اسکرین ریکارڈنگ ڈائرکٹری خود بنائیں، پھر انوائرنمنٹ کی کسی بھی تبدیلی کے اثر کے لیے Omarchy کو دوبارہ شروع کریں۔

### میں اپنے Apple Studio Display پر اسپیکرز + ویب کیم کیسے چلاؤں؟

آپ سوچیں گے کہ USB C لگانے سے سب کام کر جائے گا، لیکن بدقسمتی سے ایسا نہیں ہے۔ مجھے اسے قابلِ اعتماد طریقے سے چلانے کے لیے جو حل ملا ہے وہ [WJESOG DisplayPort + USB-A => USB-C کیبل](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) استعمال کرنا ہے۔ پھر اسپیکرز اور ویب کیم شاندار طریقے سے کام کرتے ہیں۔

یاد رکھیں کہ Omarchy میں آپ کو Apple Displays (Studio اور XDR دونوں) کے لیے بلٹ ان برائٹنس کنٹرول ملتا ہے، عام کی بورڈ برائٹنس بٹنز استعمال کر کے۔

### میں تمام اضافی سافٹ ویئر سے کیسے چھٹکارا پاؤں؟

اگر آپ Obsidian یا LibreOffice جیسے پروگرامز یا کوئی اور پہلے سے نصب شدہ چیز نہیں چاہتے، تو آپ اسے بہت آسانی سے ہٹا سکتے ہیں۔

نصب شدہ ہر پیکیج دیکھنے کے لیے _Remove > Package_ چلائیں۔ پھر آپ tab کے ساتھ کوئی بھی پیکیج منتخب کر سکتے ہیں جسے آپ ہٹانا چاہتے ہیں، اور return کے ساتھ منتخب کردہ سب کچھ ہٹانا شروع کر سکتے ہیں۔

اور آپ Omarchy مینیو سے _Remove > Web App_ استعمال کر کے پہلے سے نصب شدہ کوئی بھی web app ہٹا سکتے ہیں جو آپ نہیں چاہتے۔

یا پہلے سے نصب شدہ تمام اضافی چیزوں — web apps، TUIs، اور اختیاری ایپلیکیشنز — کو ایک ہی بار میں صاف کرنے کے لیے _Remove > Preinstalls_ چلائیں۔ انہیں لانچ کرنے والی hotkeys بھی ان کے ساتھ چلی جاتی ہیں، لہٰذا آپ کے پاس `~/.config/hypr/bindings.lua` میں اپنی پسند سے بھرنے کے لیے بائنڈنگز کی صاف ستھری سلیٹ رہ جاتی ہے۔
