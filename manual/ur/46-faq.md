# عام سوالات

### میں کی بورڈ لے آؤٹس کے درمیان کیسے بدلوں؟

اپنی `~/.config/hypr/input.lua` فائل میں ترمیم کریں اور `Left Alt + Right Alt` پر لے آؤٹس کے درمیان بدلنے کے لیے یہ شامل کریں:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

ایک بار جب آپ کے پاس متعدد لے آؤٹس کنفگر ہو جائیں گے تو بار خود بخود آپ کا موجودہ کی بورڈ لے آؤٹ دکھائے گی (اور آپ بدلنے کے لیے اس پر کلک بھی کر سکتے ہیں)۔

### میں گھڑی کی شکل 12-گھنٹے میں کیسے بدلوں؟

عام اشکال میں گردش کرنے کے لیے بار میں گھڑی پر دایاں کلک کریں، جس میں 12-گھنٹے والی بھی شامل ہیں۔ آپ شکل براہ راست بھی لگا سکتے ہیں:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

یہ اتوار 10:55 AM دکھائے گی۔

### میں اپنا ٹائم زون کیسے بدلوں؟

Omarchy مینیو میں _اپ ڈیٹ کریں > Timezone_ چلائیں اور فہرست سے منتخب کریں۔ اگر ٹائم زون درست ہے لیکن گھڑی خود بہہ گئی ہے تو _اپ ڈیٹ کریں > Time_ آپ کے لیے وقت کی ہم آہنگی دوبارہ شروع کرتا ہے۔

### میں اپنا DNS کیسے بدلوں، اپنا Wi-Fi کیسے شیئر کروں، یا اپنی کنکشن رفتار کیسے جانچوں؟

وہ سب [نیٹ ورکنگ](35-networking.md) میں رہتے ہیں۔

### میں کیسے جانچوں کہ میری ڈسک کتنی تیز ہے؟

_ٹریگر > رفتار ٹیسٹ > ڈسک رفتار ٹیسٹ_ آپ کی ڈرائیو پر لائیو پڑھنے اور لکھنے کی رفتار ناپتا ہے، یا ٹرمینل سے `omarchy disk speedtest`۔

### میں Chromium میں اپنے Google اکاؤنٹ میں سائن ان کیوں نہیں کر سکتا؟

سادہ اوپن سورس Chromium بلڈ وہ OAuth اسناد کے ساتھ نہیں آتی جو Google کو اکاؤنٹ سائن ان کے لیے درکار ہیں۔ انہیں شامل کرنے کے لیے Omarchy مینیو میں _انسٹال کریں > Service > Chromium Account_ چلائیں، براؤزر دوبارہ شروع کریں، اور سائن ان ہو جائے گا۔

### میں پرنٹر کیسے شامل کروں؟

پرنٹنگ فوری طور پر لگی ہوئی اور چل رہی ہے، اور آپ ہر پرنٹر خود ایپ لانچر (`Super + Space`) میں _Print Settings_ سے شامل کرتے ہیں۔

_Add_ منتخب کریں، اور اسے دیکھنے کے لیے ایک لمحہ دیں: USB سے لگا پرنٹر، اور زیادہ تر نیٹ ورک پرنٹرز، آپ کے لیے تلاش کر لیے جاتے ہیں۔ اگر آپ کا فہرست میں نہیں ہے تو _Network Printer > Internet Printing Protocol (ipp)_ منتخب کریں اور اس کا پتہ درج کریں — پرنٹر کی اپنی ڈسپلے یا اس کا ویب صفحہ آپ کو بتائے گا کہ یہ کیا ہے، عام طور پر `ipp/print` قطار کے ساتھ کچھ `192.168.1.50` جیسا۔ _Forward_ پھر ایک ڈرائیور پیش کرتا ہے، جہاں جدید پرنٹر ڈرائیور کے بغیر _IPP Everywhere_ پروفائل پر سب سے اچھا کام کرتا ہے اور پرانا ماڈل کا اپنا ڈرائیور چاہتا ہے۔

پرنٹر پر دایاں کلک کریں اور یہ منتخب کرنے کے لیے _Set as Default_ چنیں کہ آپ کی ایپس پہلے کس کی طرف جائیں، اور کاغذ کا سائز، ڈوپلیکس اور معیار لگانے کے لیے _Properties_ چنیں۔

خودکار دریافت، جہاں نیٹ ورک پر پرنٹرز شامل کیے بغیر نظر آتے ہیں، جب تک اسے دوبارہ بنایا جا رہا ہے عارضی طور پر آف ہے، اسی لیے اوپر والا پہلا قدم خودکار ہونے کے بجائے آپ کا ہے۔ PDF فائل میں پرنٹ کرنا کسی پرنٹر کے بغیر بھی کام کرتا ہے۔

### میں اسکرین شاٹس یا اسکرین ریکارڈنگز کہاں محفوظ ہوں یہ کیسے بدلوں؟

محفوظ کردہ اسکرین شاٹس طے شدہ طور پر `~/Pictures/Screenshots` میں جاتے ہیں۔ دوسری ڈائرکٹری استعمال کرنے کے لیے، اسے `~/.config/uwsm/env.d/` کے تحت ایک فائل میں شامل کریں (جیسے `~/.config/uwsm/env.d/capture`):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

آپ `OMARCHY_SCREENRECORD_DIR` استعمال کر کے اسکرین ریکارڈنگز کے لیے بھی ایسا ہی کر سکتے ہیں۔

Omasnap اپنی اسکرین شاٹ ڈائرکٹری خود بخود بناتا ہے۔ اسکرین ریکارڈنگ ڈائرکٹری خود بنائیں، پھر کسی بھی ماحول تبدیلی کے نافذ ہونے کے لیے Omarchy دوبارہ شروع کریں۔

### میں اپنے Apple Studio Display پر اسپیکرز + ویب کیم کیسے چلاؤں؟

آپ سوچیں گے کہ یہ سب بس USB C لگانے سے کام کرنا چاہیے، لیکن بدقسمتی سے ایسا نہیں ہے۔ مجھے جو حل اسے قابل بھروسہ طریقے سے چلانے کے لیے ملا وہ [WJESOG DisplayPort + USB-A => USB-C کیبل](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) استعمال کرنا ہے۔ پھر اسپیکرز اور ویب کیم جادو کی طرح کام کرتے ہیں۔

یاد رکھیں کہ آپ کے پاس معمول کے کی بورڈ برائٹنیس بٹن استعمال کر کے Apple Displays (Studio اور XDR دونوں) کے لیے Omarchy میں اندرونی برائٹنیس کنٹرول بھی ہے۔

### میں تمام اضافی سافٹ ویئر سے کیسے چھٹکارا پاؤں؟

اگر آپ Obsidian یا LibreOffice یا دیگر پہلے سے انسٹال شدہ سامان جیسے پروگرام نہیں چاہتے تو آپ انہیں بہت آسانی سے ہٹا سکتے ہیں۔

ہر انسٹال شدہ پیکیج دیکھنے کے لیے _ہٹائیں > Package_ چلائیں۔ پھر آپ tab کے ساتھ جو بھی پیکیج ہٹانا چاہتے ہیں اسے منتخب کر سکتے ہیں، اور return کے ساتھ منتخب کردہ سب کچھ ہٹانا شروع کر سکتے ہیں۔

اور آپ Omarchy مینیو سے _ہٹائیں > Web App_ استعمال کر کے کوئی بھی پہلے سے انسٹال شدہ ویب ایپ ہٹا سکتے ہیں جسے آپ نہیں چاہتے۔

یا تمام پہلے سے انسٹال شدہ اضافے — ویب ایپس، TUIs، اور اختیاری ایپلیکیشنز — ایک ساتھ صاف کرنے کے لیے _ہٹائیں > Preinstalls_ چلائیں۔ انہیں شروع کرنے والے شارٹ کٹ بھی ان کے ساتھ ختم ہو جاتے ہیں، لہٰذا آپ کے پاس `~/.config/hypr/bindings.lua` میں اپنے شارٹ کٹ بھرنے کے لیے ایک صاف تختی رہ جاتی ہے۔
