# اکثر پوچھے جانے والے سوالات

### میں کی بورڈ لے آؤٹس کے درمیان کیسے سوئچ کروں؟

اپنی `~/.config/hypr/input.lua` فائل میں ترمیم کریں اور `Left Alt + Right Alt` پر لے آؤٹس کے درمیان سوئچ کرنے کے لیے یہ شامل کریں:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

جب آپ کے پاس متعدد لے آؤٹس کنفیگر ہو جائیں گے تو بار خود بخود آپ کا موجودہ کی بورڈ لے آؤٹ دکھائے گا (اور آپ سوئچ کرنے کے لیے اس پر کلک بھی کر سکتے ہیں)۔

### میں گھڑی کا فارمیٹ 12 گھنٹے میں کیسے تبدیل کروں؟

عام فارمیٹس، بشمول 12 گھنٹے والے فارمیٹس، میں یکے بعد دیگرے چکر لگانے کے لیے بار میں گھڑی پر دائیں کلک کریں۔ آپ فارمیٹ براہ راست بھی سیٹ کر سکتے ہیں:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

یہ اتوار 10:55 AM دکھائے گا۔

### میں اپنا ٹائم زون کیسے تبدیل کروں؟

Omarchy مینو میں _سیٹ اپ > علاقہ > ٹائم زون_ چلائیں اور فہرست سے منتخب کریں۔ اگر ٹائم زون درست ہے لیکن گھڑی خود پیچھے رہ گئی ہے تو _اپ ڈیٹ > وقت_ آپ کے لیے وقت کی ہم آہنگی دوبارہ شروع کر دیتا ہے۔

### میں اپنا DNS کیسے تبدیل کروں، اپنا Wi-Fi کیسے شیئر کروں، یا اپنے کنکشن کی رفتار کیسے چیک کروں؟

یہ سب [نیٹ ورکنگ](35-networking.md) میں موجود ہیں۔

### میں کیسے چیک کروں کہ میری ڈسک کتنی تیز ہے؟

_ٹرگر > اسپیڈ ٹیسٹ > ڈسک اسپیڈ ٹیسٹ_ آپ کی ڈرائیو پر لائیو پڑھنے اور لکھنے کی رفتار ناپتا ہے، یا ٹرمینل سے `omarchy disk speedtest` چلائیں۔

### میں پرنٹر کیسے شامل کروں؟

پرنٹنگ پہلے سے سیٹ اپ اور چلتی ہوئی ملتی ہے، اور آپ ہر پرنٹر خود ایپ لانچر (`Super + Alt + Space`) میں _پرنٹ سیٹنگز_ سے شامل کرتے ہیں۔

_شامل کریں_ منتخب کریں، اور اسے تلاش کرنے کے لیے ایک لمحہ دیں: USB کے ذریعے لگا ہوا پرنٹر، اور زیادہ تر نیٹ ورک پرنٹرز، آپ کے لیے خود مل جاتے ہیں۔ اگر آپ کا پرنٹر فہرست میں نہیں ہے تو _نیٹ ورک پرنٹر > Internet Printing Protocol (ipp)_ منتخب کریں اور اس کا پتہ درج کریں — پرنٹر کی اپنی ڈسپلے یا اس کا ویب پیج آپ کو بتائے گا کہ وہ کیا ہے، عام طور پر کچھ ایسا جیسے `192.168.1.50` جس کی قطار `ipp/print` ہو۔ پھر _آگے بڑھیں_ ایک ڈرائیور پیش کرتا ہے، جہاں جدید پرنٹر بغیر ڈرائیور والے _IPP Everywhere_ پروفائل پر بہترین کام کرتا ہے اور پرانا پرنٹر اس ماڈل کا اپنا ڈرائیور چاہتا ہے۔

کسی پرنٹر پر دائیں کلک کریں اور یہ منتخب کرنے کے لیے کہ آپ کی ایپس سب سے پہلے کس پرنٹر تک پہنچیں _ڈیفالٹ کے طور پر سیٹ کریں_ منتخب کریں، اور کاغذ کا سائز، ڈوپلیکس اور معیار سیٹ کرنے کے لیے _خصوصیات_ منتخب کریں۔

خودکار دریافت، جہاں نیٹ ورک پر موجود پرنٹرز شامل کیے بغیر ظاہر ہو جاتے ہیں، عارضی طور پر بند ہے جبکہ اس پر دوبارہ کام ہو رہا ہے، اسی لیے اوپر والا پہلا قدم خودکار ہونے کے بجائے آپ کا ہے۔ PDF فائل میں پرنٹ کرنا بغیر کسی پرنٹر کے بالکل کام کرتا ہے۔

### میں یہ کیسے تبدیل کروں کہ اسکرین شاٹس یا اسکرین ریکارڈنگز کہاں محفوظ ہوں؟

محفوظ شدہ اسکرین شاٹس بطور ڈیفالٹ `~/Pictures/Screenshots` میں جاتے ہیں۔ کوئی دوسری ڈائریکٹری استعمال کرنے کے لیے، یہ `~/.config/uwsm/env.d/` کے تحت ایک فائل (جیسے `~/.config/uwsm/env.d/capture`) میں شامل کریں:

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

آپ `OMARCHY_SCREENRECORD_DIR` استعمال کر کے اسکرین ریکارڈنگز کے لیے بھی یہی کر سکتے ہیں۔

Omasnap اپنی اسکرین شاٹ ڈائریکٹری خود بخود بناتا ہے۔ اسکرین ریکارڈنگ ڈائریکٹری خود بنائیں، پھر ماحول کی کسی بھی تبدیلی کے اثر انداز ہونے کے لیے Omarchy دوبارہ شروع کریں۔

### میں اپنے Apple Studio Display پر اسپیکرز + ویب کیم کیسے چلاؤں؟

آپ سمجھیں گے کہ بس USB C لگانے سے سب کام کر جانا چاہیے، لیکن بدقسمتی سے ایسا نہیں ہے۔ اسے قابل اعتماد طریقے سے چلانے کے لیے مجھے جو حل ملا ہے وہ [the WJESOG DisplayPort + USB-A => USB-C cable](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) استعمال کرنا ہے۔ پھر اسپیکرز اور ویب کیم شاندار طریقے سے کام کرتے ہیں۔

یاد رکھیں کہ Omarchy میں آپ کے پاس Apple Displays (Studio اور XDR دونوں) کے لیے باقاعدہ کی بورڈ برائٹنس بٹنوں کا استعمال کرتے ہوئے بلٹ ان برائٹنس کنٹرول موجود ہے۔

### میں تمام اضافی سافٹ ویئر سے کیسے چھٹکارا پاؤں؟

اگر آپ Obsidian یا LibreOffice جیسے پروگرامز یا پہلے سے انسٹال شدہ کوئی اور سامان نہیں چاہتے تو آپ اسے بہت آسانی سے ہٹا سکتے ہیں۔

انسٹال شدہ ہر پیکج دیکھنے کے لیے _ہٹائیں > پیکج_ چلائیں۔ پھر آپ tab کے ساتھ کوئی بھی پیکج منتخب کر سکتے ہیں جسے آپ ہٹانا چاہتے ہیں، اور return کے ساتھ وہ سب ہٹانا شروع کر سکتے ہیں جو آپ نے منتخب کیا ہے۔

اور آپ Omarchy مینو سے _ہٹائیں > ویب ایپ_ استعمال کر کے پہلے سے انسٹال شدہ کوئی بھی ویب ایپ ہٹا سکتے ہیں جو آپ نہیں چاہتے۔

یا پہلے سے انسٹال شدہ تمام اضافی چیزیں — ویب ایپس، TUIs، اور اختیاری ایپلیکیشنز — ایک ہی بار میں صاف کرنے کے لیے _ہٹائیں > پہلے سے انسٹال شدہ چیزیں_ چلائیں۔ انہیں لانچ کرنے والی ہاٹ کیز بھی ان کے ساتھ ختم ہو جاتی ہیں، اس لیے آپ کے پاس بائنڈنگز کی ایک صاف تختی رہ جاتی ہے جسے آپ `~/.config/hypr/bindings.lua` میں اپنی بائنڈنگز سے بھر سکتے ہیں۔
