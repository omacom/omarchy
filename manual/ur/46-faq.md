# اکثر پوچھے جانے والے سوالات

### میں کی بورڈ لے آؤٹس کے درمیان کیسے سوئچ کروں؟

اپنی `~/.config/hypr/input.lua` فائل میں ترمیم کریں اور `Left Alt + Right Alt` پر لے آؤٹس کے درمیان سوئچ کرنے کے لیے یہ شامل کریں:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

جب آپ متعدد لے آؤٹس ترتیب دے لیں گے تو بار خود بخود آپ کا موجودہ کی بورڈ لے آؤٹ دکھائے گا (اور آپ سوئچ کرنے کے لیے اس پر کلک بھی کر سکتے ہیں)۔

### میں گھڑی کے فارمیٹ کو 12-hour میں کیسے تبدیل کروں؟

عام فارمیٹس، بشمول 12-hour والوں، میں باری باری جانے کے لیے بار میں گھڑی پر دائیں کلک کریں۔ آپ فارمیٹ براہِ راست بھی مقرر کر سکتے ہیں:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

اس سے اتوار 10:55 AM دکھایا جائے گا۔

### میں اپنا ٹائم زون کیسے تبدیل کروں؟

Omarchy مینیو میں _Setup > Region > Timezone_ چلائیں اور فہرست سے منتخب کریں۔ اگر ٹائم زون درست ہو لیکن گھڑی خود ہی آگے پیچھے ہو گئی ہو، تو _Update > Time_ آپ کے لیے وقت کی ہم آہنگی دوبارہ شروع کر دیتا ہے۔

### میں اپنا DNS کیسے تبدیل کروں، اپنا Wi-Fi کیسے شیئر کروں، یا اپنے کنکشن کی رفتار کیسے چیک کروں؟

یہ سب [نیٹ ورکنگ](35-networking.md) میں موجود ہیں۔

### میں کیسے چیک کروں کہ میری ڈسک کتنی تیز ہے؟

_Trigger > Speed Test > Disk Speed Test_ آپ کی ڈرائیو پر براہِ راست پڑھنے اور لکھنے کی رفتار ناپتا ہے، یا ٹرمینل سے `omarchy disk speedtest` چلائیں۔

### میں ایک پرنٹر کیسے شامل کروں؟

پرنٹنگ پہلے سے ترتیب شدہ اور چلتی ہوئی ملتی ہے، اور آپ ہر پرنٹر خود ایپ لانچر (`Super + Space`) میں _Print Settings_ سے شامل کرتے ہیں۔

_Add_ منتخب کریں، اور اسے تلاش کرنے کے لیے تھوڑا وقت دیں: USB کے ذریعے لگایا گیا پرنٹر، اور بیشتر نیٹ ورک پرنٹرز، آپ کے لیے خود ہی مل جاتے ہیں۔ اگر آپ کا پرنٹر فہرست میں نہ ہو، تو _Network Printer > Internet Printing Protocol (ipp)_ منتخب کریں اور اس کا پتہ درج کریں — پرنٹر کی اپنی ڈسپلے اسکرین یا اس کا ویب پیج آپ کو بتائے گا کہ وہ کیا ہے، عام طور پر کچھ ایسا جیسے `192.168.1.50` جس کی قطار `ipp/print` ہو۔ پھر _Forward_ ایک ڈرائیور پیش کرتا ہے، جہاں ایک جدید پرنٹر ڈرائیور کے بغیر والے _IPP Everywhere_ پروفائل پر بہترین کام کرتا ہے اور ایک پرانا پرنٹر اس ماڈل کا اپنا ڈرائیور چاہتا ہے۔

کسی پرنٹر پر دائیں کلک کریں اور یہ منتخب کرنے کے لیے کہ آپ کی ایپس سب سے پہلے کس پرنٹر تک پہنچیں _Set as Default_ منتخب کریں، اور کاغذ کا سائز، ڈوپلیکس اور معیار مقرر کرنے کے لیے _Properties_ منتخب کریں۔

خودکار دریافت، جہاں نیٹ ورک پر موجود پرنٹرز شامل کیے بغیر ظاہر ہو جاتے ہیں، اس وقت عارضی طور پر بند ہے جبکہ اسے دوبارہ بنایا جا رہا ہے، اسی لیے اوپر والا پہلا قدم خودکار ہونے کے بجائے آپ کا ہے۔ کسی PDF فائل میں پرنٹ کرنا کسی بھی پرنٹر کے بغیر بالکل کام کرتا ہے۔

### میں اسکرین شاٹس یا اسکرین ریکارڈنگز کے محفوظ ہونے کی جگہ کیسے تبدیل کروں؟

محفوظ شدہ اسکرین شاٹس بطور ڈیفالٹ `~/Pictures/Screenshots` میں جاتے ہیں۔ کوئی دوسری ڈائریکٹری استعمال کرنے کے لیے، یہ `~/.config/uwsm/env.d/` کے تحت ایک فائل (جیسے `~/.config/uwsm/env.d/capture`) میں شامل کریں:

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

آپ `OMARCHY_SCREENRECORD_DIR` استعمال کر کے اسکرین ریکارڈنگز کے لیے بھی یہی کر سکتے ہیں۔

Omasnap اپنی اسکرین شاٹ ڈائریکٹری خود بخود بناتا ہے۔ اسکرین ریکارڈنگ ڈائریکٹری خود بنائیں، پھر ماحول کی کسی بھی تبدیلی کے اثر انداز ہونے کے لیے Omarchy دوبارہ شروع کریں۔

### میں اپنے Apple Studio Display پر اسپیکرز + ویب کیم کیسے چلاؤں؟

آپ سمجھیں گے کہ بس USB C لگانے سے یہ سب کام کر جائے گا، لیکن بدقسمتی سے ایسا نہیں ہے۔ مجھے جو حل اسے قابلِ اعتماد طریقے سے چلانے کے لیے ملا ہے وہ [WJESOG DisplayPort + USB-A => USB-C کیبل](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) استعمال کرنا ہے۔ پھر اسپیکرز اور ویب کیم شاندار طریقے سے کام کرتے ہیں۔

یاد رکھیں کہ آپ کو Omarchy میں Apple Displays (Studio اور XDR دونوں) کے لیے باقاعدہ کی بورڈ برائٹنس بٹنوں سے بلٹ اِن برائٹنس کنٹرول ملتا ہے۔

### میں تمام اضافی سافٹ ویئر سے کیسے جان چھڑاؤں؟

اگر آپ Obsidian یا LibreOffice جیسے پروگرامز یا کوئی اور پہلے سے انسٹال شدہ چیزیں نہیں چاہتے، تو آپ انہیں بہت آسانی سے ہٹا سکتے ہیں۔

انسٹال شدہ ہر پیکیج دیکھنے کے لیے _Remove > Package_ چلائیں۔ پھر آپ tab سے کوئی بھی پیکیج منتخب کر سکتے ہیں جسے آپ ہٹانا چاہتے ہیں، اور return سے منتخب کردہ سب کچھ ہٹانا شروع کر سکتے ہیں۔

اور آپ ان پہلے سے انسٹال شدہ ویب ایپس کو ہٹانے کے لیے Omarchy مینیو سے _Remove > Web App_ استعمال کر سکتے ہیں جنہیں آپ نہیں چاہتے۔

یا پہلے سے انسٹال شدہ تمام اضافی چیزوں — ویب ایپس، TUIs، اور اختیاری ایپلیکیشنز — کو یکبارگی صاف کرنے کے لیے _Remove > Preinstalls_ چلائیں۔ انہیں لانچ کرنے والی ہاٹ کیز بھی ان کے ساتھ ختم ہو جاتی ہیں، لہٰذا آپ کے پاس `~/.config/hypr/bindings.lua` میں اپنی پسند سے بھرنے کے لیے بائنڈنگز کی ایک صاف ستھری تختی رہ جاتی ہے۔
