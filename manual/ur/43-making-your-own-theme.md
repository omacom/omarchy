# اپنی خود کی تھیم بنانا

آپ `~/.config/omarchy/themes` میں اپنی خود کی تھیمز شامل کر سکتے ہیں۔ بس موجودہ تھیمز میں سے کسی ایک کو بنیاد کے طور پر کاپی کریں ( `/usr/share/omarchy/themes` میں دیکھیں)، پھر اپنی پسند کے مطابق اس میں تبدیلیاں کریں۔ جب تک آپ کی تھیم اس فولڈر کے اندر ہے، یہ تھیم منتخب کرنے کے مینیو میں شامل رہے گی۔

اہم فائل جس میں آپ کو تبدیلی کرنی ہے وہ `colors.toml` ہے۔ یہ اس رنگوں کے سیٹ کی تعریف کرتی ہے جو پھر ٹرمینل (Foot/Alacritty/Ghostty/Kitty)، btop، Chromium، Hyprland، Neovim، Helix، VSCode، Obsidian، اور پوری Omarchy shell (ٹاپ بار، مینیو، اطلاعات، OSD، اور لاک اسکرین) کے لیے کنفیگریشنز بنانے کے لیے استعمال ہوتا ہے۔

آپ شامل Aether ایپلیکیشن کو بھی ایک نئی تھیم بنانے کے لیے استعمال کر سکتے ہیں، جس میں رنگوں کے ساتھ کھیلنے اور پس منظر تلاش کرنے کے لیے ایک خوبصورت GUI انٹرفیس موجود ہے۔ بس اسے `Super + Alt + Space` پر ایپ گرڈ سے شروع کریں۔

### ایک انسٹال شدہ تھیم میں کیا ہو سکتا ہے

جو تھیم آپ خود `~/.config/omarchy/themes` میں لکھتے ہیں اس میں جو چاہیں رکھ سکتے ہیں — یہ آپ کی مشین اور آپ کی فائل ہے، اور Omarchy اس سب کو لاگو کرتا ہے۔

جو تھیم آپ کسی اور کی repo سے `omarchy theme install` کے ساتھ انسٹال کرتے ہیں وہ ہر وہ چیز برقرار رکھتی ہے جو رنگ ہے، اور ان چند فائلوں کو کھو دیتی ہے جو آپ کی مشین پر کوڈ چلائیں گی: کوئی بھی `.lua` فائل، ٹرمینل کنفیگز (`alacritty.toml`, `foot.ini`, `ghostty.conf`, `kitty.conf`)، اور `vscode.json`۔ کسی تھیم کی `hyprland.lua` وہ Lua ہے جسے آپ کا compositor لاگ ان کے وقت چلاتا ہے، ٹرمینل کنفیگ اس پروگرام کا نام بتاتی ہے جسے آپ کا ٹرمینل شروع کرتا ہے، اور `vscode.json` انسٹال کرنے کے لیے ایک VSCode ایکسٹینشن کا نام بتاتی ہے۔ کسی کی تھیم انسٹال کرنے سے یہ بدلنا چاہیے کہ آپ کا ڈیسک ٹاپ کیسا دکھتا ہے، یہ کبھی نہیں کہ وہ کیا چلاتا ہے۔

باقی سب کچھ بالکل اسی طرح کام کرتا رہتا ہے جیسے تھیم کے مصنف نے لکھا تھا — `btop.theme`, `chromium.theme`, `helix.toml`, `icons.theme`, `shell.toml`، پس منظر اور پیش منظر، سب برقرار رہتے ہیں۔ صرف جو کچھ ہٹایا گیا تھا وہ آپ کی مشین پر `colors.toml` سے دوبارہ بنایا جاتا ہے۔

Omarchy دونوں میں فرق اس بات سے کرتا ہے کہ آیا تھیم کے اندر اس کی اپنی git repo موجود ہے، جو وہی ہے جو `omarchy theme install` کلون کرتے وقت پیچھے چھوڑتا ہے۔ تو جو تھیم آپ نے لکھی ہے وہ آپ کی ہی رہتی ہے، اور جو آپ نے انٹرنیٹ سے حاصل کی ہے وہ رنگ ہی رہتی ہے۔

### Light mode

اگر آپ light mode تھیم بنا رہے ہیں تو اپنی `colors.toml` کے اوپر `mode = "light"` سیٹ کریں۔ پھر یہ خود بخود تمام ایپس کے لیے light mode کے ساتھ جوڑ دی جائے گی۔ (آپ کی تھیم کی جڑ میں `light.mode` نامی ایک خالی فائل رکھنے کا پرانا طریقہ اب بھی کام کرتا ہے۔)

### آئیکن کے رنگ

اگر آپ فائل مینیجر کے آئیکنز کو اپنی تھیم کے ساتھ رنگ میں ہم آہنگ کرنا چاہتے ہیں تو `icons.theme` نامی ایک فائل شامل کریں جس میں اس آئیکن سیٹ کا نام ہو جسے آپ استعمال کرنا چاہتے ہیں۔ بطور ڈیفالٹ، اختیارات یہ ہیں: `Yaru Yaru-blue Yaru-dark Yaru-magenta Yaru-olive Yaru-prussiangreen Yaru-purple Yaru-red Yaru-sage Yaru-wartybrown Yaru-yellow`۔

### ان لاک تصویر

`unlock.png` اور `preview-unlock.png` تصاویر کے ساتھ فراہم کی گئی تھیمز _ظاہری شکل > Unlock_ کے تحت درج ہوں گی۔ آپ کی `unlock.png` ترجیحاً ایک شفاف png ہونی چاہیے۔ اور آپ `omarchy plymouth preview` استعمال کر کے پیش منظر کی تصویر بنا سکتے ہیں۔

### ان ایپس کی تھیمنگ جن کا Omarchy احاطہ نہیں کرتا

اگر آپ کوئی ایسی ایپ استعمال کرتے ہیں جو اس فہرست میں نہیں ہے تو آپ ایک ٹیمپلیٹ کے ساتھ Omarchy کو خود اسے تھیم کرنا سکھا سکتے ہیں۔ `~/.config/omarchy/themed/` میں ایک فائل رکھیں جس کا نام اس کنفیگ کے نام پر ہو جو یہ بناتی ہے جمع ایک `.tpl` ایکسٹینشن، اور کنفیگ کو `{{ background }}`, `{{ foreground }}`, `{{ accent }}`, `{{ red }}`, `{{ color0 }}` سے `{{ color15 }}` تک، اور پیلیٹ کے باقی حصے کو بطور پلیس ہولڈرز لکھیں۔ ہر بار جب آپ تھیمز تبدیل کرتے ہیں تو فائل اس تھیم کے رنگوں کے ساتھ دوبارہ بنائی جاتی ہے۔

اس فولڈر میں ایک مکمل تبصرہ شدہ `alacritty.toml.tpl.sample` موجود ہے جس سے کاپی کی جا سکتی ہے — یہ ہر وہ متغیر درج کرتی ہے جسے آپ استعمال کر سکتے ہیں، علاوہ ازیں ان ایپس کے لیے `_strip` اور `_rgb` موڈیفائرز جو اپنے رنگ `#` کے بغیر یا اعشاری RGB کے طور پر چاہتی ہیں۔ آپ کے ٹیمپلیٹس کو Omarchy کے اپنے ٹیمپلیٹس پر ترجیح حاصل ہے، لہٰذا آپ اسے یہ طے کرنے کے لیے بھی استعمال کر سکتے ہیں کہ کسی بلٹ ان ایپ کو کیسے تھیم کیا جائے۔

### اپنی تھیم تقسیم کرنا

اگر آپ اپنی تھیم تقسیم کرنا چاہتے ہیں تاکہ دوسرے اسے استعمال کر سکیں تو آپ کو اسے کسی عوامی git سرور، جیسے GitHub، پر رکھنا ہوگا۔ پھر لوگ اس URL کو استعمال کر کے Omarchy مینیو میں _انسٹال > Style > Theme_ کے ذریعے اسے انسٹال کر سکتے ہیں۔ یہ تجویز کیا جاتا ہے کہ آپ `omarchy-[themename]-theme` کے نام رکھنے کے اصول کی پیروی کریں، کیونکہ انسٹالیشن کے بعد تھیم انتخاب کے مینیو میں تھیم درست طور پر صرف `[themename]` کے طور پر دکھے گی۔

وہ بچا ہوا `[themename]` تھیم کے ڈائریکٹری نام بن جاتا ہے، لہٰذا یہ ایسا ہونا چاہیے جسے Omarchy محفوظ طریقے سے ادھر ادھر منتقل کر سکے: اسے ایک حرف، ایک ہندسے، یا ایک انڈر اسکور سے شروع ہونا چاہیے، اور باقی حصے میں حروف، ہندسے، `.`, `_`, `+`، اور `-` ہو سکتے ہیں۔ بڑے حروف آپ کے لیے چھوٹے حروف میں بدل دیے جاتے ہیں، لیکن اس کے علاوہ کچھ بھی — ایک خلا، ایک اقتباسی نشان، ایک غیر انگریزی حرف — انسٹال کے وقت مسترد کر دیا جاتا ہے بجائے اس کے کہ اسے ڈائریکٹری نام میں بدلا جائے۔ تو `omarchy-tokyo-night-theme`, `omarchy-flexoki_light-theme`، اور `omarchy-c++-theme` سب ٹھیک سے انسٹال ہوتے ہیں۔

یاد رکھیں کہ ایک بار جب یہ کسی repo سے انسٹال ہو جائے تو اس کے ساتھ آنے والی کوئی بھی `.lua`، ٹرمینل کنفیگ یا `vscode.json` ہٹا دی جاتی ہے، لہٰذا تھیم کو ان کے گرد نہ بنائیں۔

آپ [omarchy-site repo](https://github.com/omacom-io/omarchy-site) کو ایک pull request بھیج کر اپنی تھیم کو [اضافی تھیمز کے صفحے](https://omarchy.org/themes/) میں شامل کروا سکتے ہیں۔
