# Mac یا Windows سے آ رہے ہیں

اگر آپ نے برسوں macOS یا Windows پر گزارے ہیں، تو آپ کی انگلیاں سو چیزیں جانتی ہیں جو آپ کا دماغ بھول چکا ہے کہ اس نے کبھی سیکھی تھیں۔ یہ باب ترجمے کی تہہ ہے: Omarchy میں وہ عادتیں کہاں جاتی ہیں۔ خصوصیات خود کہیں اور تفصیل سے بیان کی گئی ہیں — یہ بس نقشہ ہے۔

### Super سب کچھ کا مرکز ہے

Cmd یا Windows key کے گرد بنائی گئی تمام پٹھوں کی یادداشت ایک ہی key پر منتقل ہو جاتی ہے: Super۔ یہ PC کی بورڈ پر Windows key ہے، اور یہ Omarchy میں تقریباً ہر hotkey کا مرکز ہے۔

آپ کی Spotlight یا Raycast یا Start-menu والی عادت `Super + Space` بن جاتی ہے۔ یہ Omarchy مینو کھولتا ہے، جو ایپس لانچ کرتا ہے، سیٹنگز بدلتا ہے، سافٹ ویئر انسٹال کرتا ہے، اسکرین کیپچر کرتا ہے — تقریباً سب کچھ۔ فلٹر کرنے کے لیے بس ٹائپ کرنا شروع کر دیں۔ `Super + Alt + Space` ہر ایپ کو ایک گرڈ پر دکھاتا ہے، جس طرح Launchpad کرتا ہے۔ دیکھیں [نیویگیشن](04-navigation.md)۔

### ڈیسک ٹاپ آئیکنز نہیں، اور dock راستے سے ہٹا رہتا ہے

ڈیسک ٹاپ پر ترتیب دینے کے لیے کوئی آئیکنز نہیں ہیں، اور جب کسی workspace میں کوئی ونڈو آ جاتی ہے تو dock چھپ جاتا ہے، یہاں تک کہ آپ پوائنٹر کو اسکرین کے اس کے کنارے تک دھکیلیں، دائیں والے کنارے تک جب تک آپ اسے منتقل نہ کر دیں (دیکھیں [نیویگیشن](04-navigation.md))۔ ایپس کسی hotkey سے شروع ہوتی ہیں (`Super + Return` ٹرمینل کے لیے، `Super + Shift + Return` براؤزر کے لیے، اور `Super + K` ہر اس چیز کی فہرست کے لیے جو میپ کی گئی ہے) یا مینو سے۔ UI کا ایک مستقل حصہ [ٹاپ بار](05-the-top-bar.md) ہے، جو وہ سب سنبھالتا ہے جو پہلے مینو بار، سسٹم ٹرے، اور Notification Center آپ کے لیے کرتے تھے — اور اس پر موجود تقریباً ہر widget بائیں، دائیں، اور درمیانی کلک پر کچھ نہ کچھ کرتا ہے۔

### ونڈوز خود اپنی جگہ بنا لیتی ہیں

ذہنیت کی سب سے بڑی تبدیلی: آپ ونڈوز کو ادھر ادھر نہیں گھسیٹتے اور نہ ہی انہیں اسکرین کے آدھے حصوں پر سنیپ کرتے ہیں۔ ایک ونڈو کھولیں اور یہ پوری اسکرین لے لیتی ہے۔ دوسری کھولیں اور وہ اسے تقسیم کر لیتی ہیں۔ آپ کبھی کسی ونڈو کو دوسری کے نیچے سے نکالنے کی کوشش نہیں کرتے، کیونکہ ونڈوز ایک دوسرے پر چڑھتی ہی نہیں ہیں۔

جب آپ کو واقعی کسی floating ونڈو کی ضرورت ہو، تو `Super + T` فعال ونڈو کو tiling سے باہر نکال دیتا ہے (اور واپس بھی لے آتا ہے)۔ لیکن پہلے tiling کو ایک حقیقی موقع دیں — یہی اس پورے نظام کا دل ہے۔ [نیویگیشن](04-navigation.md) آپ کو اس میں سے گزارتا ہے۔

Workspaces مانوس لگیں گے: یہ macOS Spaces یا Windows virtual desktops ہیں، فرق صرف یہ ہے کہ آپ انہیں واقعی استعمال کریں گے، کیونکہ `Super + 1/2/3/4` سیدھا کسی ایک پر لے جاتا ہے اور `Super + Shift + 1/2/3/4` فعال ونڈو کو وہاں بھیج دیتا ہے۔ کوئی اینیمیشن تاخیر نہیں، بس فوری چھلانگیں۔ اس کا مطلب یہ ہے کہ شاید آپ کو متعدد مانیٹرز کی ضرورت ہی نہ پڑے، اگر آپ پہلے اس کے عادی تھے۔

### کاپی اور پیسٹ بس کام کرتے ہیں

Mac پر آپ کے پاس ہر جگہ Cmd + C تھا۔ Windows پر آپ کے پاس ہر جگہ Ctrl + C تھا — ٹرمینل کے سوا، جہاں یہ آپ کے پروگرام کو ختم کر دیتا ہے۔ Omarchy آپ کو `Super + C`، `Super + X`، اور `Super + V` دیتا ہے، اور یہ ہر جگہ کام کرتے ہیں، ٹرمینل سمیت۔ شیل کے لیے کوئی الگ عادت سیکھنے کی ضرورت نہیں۔

Windows والو: آپ کی Win + V کلپ بورڈ ہسٹری `Super + Ctrl + V` پر رہتی ہے، اور یہ متن کے ساتھ ساتھ تصاویر بھی رکھتی ہے۔ دیکھیں [متحد کلپ بورڈ اور ہسٹری](08-unified-clipboard-history.md)۔

### کچھ چیزیں واقعی مختلف ہیں

بہت سی سیٹنگز متن فائلوں میں رہتی ہیں جنہیں آپ ایڈٹ کرتے ہیں، ان پینلز میں نہیں جن میں آپ کلک کرتے پھرتے ہیں۔ یہ قدیم لگتا ہے یہاں تک کہ آپ کو احساس ہو کہ اس کا مطلب ہے کہ ہر تبدیلی دیکھی جا سکتی ہے، آپ کی اگلی مشین پر کاپی کی جا سکتی ہے، اور version control میں رکھی جا سکتی ہے۔ _Setup_ مینو آپ کو سیدھا درست فائل میں چھوڑ دیتا ہے اور جب آپ کام مکمل کر لیتے ہیں تو جس چیز کو دوبارہ شروع کرنے کی ضرورت ہو اسے دوبارہ شروع کر دیتا ہے۔

اپ ڈیٹس ایک ہی کمانڈ کے ذریعے آتی ہیں — _Update > Omarchy_ — جو Omarchy کو خود اور سسٹم پر موجود ہر پیکج کو اپ ڈیٹ کرتی ہے، پہلے ایک اسنیپ شاٹ لے کر۔ ہر ایپ کے الگ اپ ڈیٹرز آپ کو بے ترتیب پریشان نہیں کرتے۔ دیکھیں [اپ ڈیٹس](30-updates.md)۔

سافٹ ویئر ڈاؤن لوڈ کیے گئے انسٹالرز سے نہیں، ایک package manager سے آتا ہے۔

اور جب آپ کوئی ونڈو بند کرتے ہیں، تو ایپ واقعی بند ہو جاتی ہے۔ macOS والی وہ لٹکی ہوئی حالت نہیں ہے جہاں پروگرام بغیر کسی ونڈو کے چلتا رہتا ہے۔ `Super + W` — یا `Super + Q`، اگر یہی وہ انگلیوں کی یادداشت ہے جس کے ساتھ آپ آئے تھے — کا مطلب ہے ختم۔

### Mac ہارڈ ویئر پر

Omarchy Intel Macs پر اچھی طرح چلتا ہے، اور Omarchy for Apple Silicon کے ساتھ M1، M2 اور M3 Macs پر بھی۔ دیکھیں [Mac سپورٹ](44-mac-support.md)۔ اور کی بورڈ آپ کے ساتھ مہربان ہے: Omarchy کچھ بھی remap نہیں کرتا، اور Linux Command key کو Super کے طور پر لیتا ہے، اس لیے Super بالکل وہیں بیٹھتا ہے جہاں Cmd ہمیشہ تھا۔ آپ کا انگوٹھا اس تبدیلی کو محسوس ہی نہیں کرے گا۔

### اسے دو ہفتے دیں

عادتیں آپ کی توقع سے زیادہ تیزی سے منتقل ہو جاتی ہیں۔ [ہاٹ کیز](07-hotkeys.md) والے باب کو ایک بار سرسری دیکھ لیں، اور جب بھی کسی binding پر دماغ خالی ہو جائے، `Super + K` دبائیں — یہ آپ کو وہ سب دکھا دیتا ہے۔ یہی واحد hotkey ہے جو آپ کو واقعی یاد کرنی ہے۔
