# Mac یا Windows سے آنا

اگر آپ نے macOS یا Windows پر برسوں گزارے ہیں، تو آپ کی انگلیاں سو ایسی چیزیں جانتی ہیں جنہیں سیکھنا آپ کا دماغ کب کا بھول چکا ہے۔ یہ باب ترجمے کی تہہ ہے: Omarchy میں وہ عادتیں کہاں جاتی ہیں۔ خصوصیات خود دوسری جگہ تفصیل سے بیان کی گئی ہیں — یہ صرف نقشہ ہے۔

### Super ہی ہر چیز کا مرکز ہے

Cmd یا Windows key کے گرد آپ نے جو بھی عضلاتی یادداشت بنائی ہے، وہ سب ایک ہی key پر منتقل ہو جاتی ہے: Super۔ یہ PC کی بورڈ پر Windows key ہے، اور یہ Omarchy میں تقریباً ہر hotkey کا مرکز ہے۔

آپ کی Spotlight یا Raycast یا Start-menu والی عادت `Super + Space` بن جاتی ہے۔ اس سے Omarchy مینیو کھلتا ہے، جو ایپس لانچ کرتا ہے، ترتیبات بدلتا ہے، سافٹ ویئر انسٹال کرتا ہے، اسکرین کیپچر کرتا ہے — تقریباً ہر چیز۔ فلٹر کرنے کے لیے بس ٹائپ کرنا شروع کر دیں۔ `Super + Alt + Space` تمام ایپس کو ایک ہی گرڈ پر دکھاتا ہے، بالکل Launchpad کی طرح۔ دیکھیں [نیویگیشن](04-navigation.md)۔

### کوئی ڈیسک ٹاپ آئیکن نہیں، اور dock راستے سے ہٹا رہتا ہے

ڈیسک ٹاپ پر سجانے کے لیے کوئی آئیکن نہیں، اور جب کسی workspace میں کوئی ونڈو آ جائے تو dock چھپ جاتا ہے، یہاں تک کہ آپ پوائنٹر کو اسکرین کے اس کے کنارے تک دھکیلیں، نچلے کنارے تک جب تک آپ اسے ہٹا نہ دیں (دیکھیں [نیویگیشن](04-navigation.md))۔ ایپس hotkey سے شروع ہوتی ہیں (ٹرمینل کے لیے `Super + Return`، براؤزر کے لیے `Super + Shift + Return`، اور ہر mapped چیز کی فہرست کے لیے `Super + K`) یا مینیو سے۔ UI کا واحد مستقل حصہ [اوپری بار](05-the-top-bar.md) ہے، جو وہ سب سنبھالتی ہے جو پہلے menu bar، system tray، اور Notification Center آپ کے لیے کرتے تھے — اور اس پر موجود تقریباً ہر widget بائیں، دائیں، اور درمیانی کلک پر کچھ نہ کچھ کرتا ہے۔

### ونڈوز خود اپنی جگہ بنا لیتی ہیں

سب سے بڑی ذہنی تبدیلی: آپ ونڈوز کو گھسیٹ کر ادھر ادھر نہیں کرتے اور نہ انہیں اسکرین کے آدھے حصوں پر snap کرتے ہیں۔ ایک ونڈو کھولیں اور وہ پوری اسکرین لے لیتی ہے۔ دوسری کھولیں اور وہ اسے تقسیم کر لیتی ہیں۔ آپ کبھی کسی ونڈو کو دوسری کے نیچے سے نکالنے کی کوشش نہیں کرتے، کیونکہ ونڈوز ایک دوسرے پر چڑھتی ہی نہیں۔

جب آپ کو واقعی floating ونڈو چاہیے ہو، تو `Super + T` فعال ونڈو کو tiling سے باہر (اور واپس اندر) لے آتا ہے۔ لیکن پہلے tiling کو ایک اصل موقع دیں — یہی پوری چیز کا دل ہے۔ [نیویگیشن](04-navigation.md) آپ کو اس میں سے گزار کر لے جاتا ہے۔

Workspaces مانوس لگیں گے: یہ macOS Spaces یا Windows virtual desktops ہیں، فرق صرف یہ ہے کہ آپ انہیں اصل میں استعمال کریں گے، کیونکہ `Super + 1/2/3/4` سیدھا کسی ایک پر لے جاتا ہے اور `Super + Shift + 1/2/3/4` فعال ونڈو کو وہاں بھیج دیتا ہے۔ کوئی اینیمیشن تاخیر نہیں، بس فوری چھلانگیں۔ اس کا مطلب ہے کہ آپ کو شاید متعدد مانیٹرز کی بھی ضرورت نہ پڑے، اگر آپ پہلے اس کے عادی تھے۔

### کاپی اور پیسٹ بس کام کرتے ہیں

Mac پر آپ کے پاس ہر جگہ Cmd + C تھا۔ Windows پر آپ کے پاس ہر جگہ Ctrl + C تھا — سوائے ٹرمینل کے، جہاں یہ آپ کے پروگرام کو ختم کر دیتا ہے۔ Omarchy آپ کو `Super + C`، `Super + X`، اور `Super + V` دیتا ہے، اور یہ ہر جگہ کام کرتے ہیں، ٹرمینل سمیت۔ shell کے لیے کوئی الگ عادت سیکھنے کی ضرورت نہیں۔

Windows والو: آپ کی Win + V clipboard history `Super + Ctrl + V` پر موجود ہے، اور یہ متن کے ساتھ ساتھ تصاویر بھی رکھتی ہے۔ دیکھیں [متحد کلپ بورڈ اور تاریخ](08-unified-clipboard-history.md)۔

### ترجمے کی جدول

| آپ ہاتھ بڑھاتے ہیں | Omarchy میں |
| ------------- | ---------- |
| Spotlight / Raycast / Start menu | `Super + Space` — Omarchy مینیو |
| AirDrop | LocalSend، بذریعہ `Super + Ctrl + S` — دیکھیں [GUIs](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` یا `Print Screen` — دیکھیں [اسکرین شاٹس اور ریکارڈنگ](12-screenshots-recording.md) |
| Notification Center | `Super + Shift + Alt + ,` پر اطلاعات کی تاریخ |
| Time Machine (سسٹم کے لیے) | ہر اپ ڈیٹ پر خودکار [سسٹم اسنیپ شاٹس](47-system-snapshots.md) |
| App Store / کوئی انسٹالر ڈاؤن لوڈ کرنا | مینیو میں _Install_، یا `omarchy pkg add` — دیکھیں [دیگر پیکجز](29-other-packages.md) |
| System Settings / Control Panel | مینیو میں _Setup_، جو سادہ config فائلوں میں ترمیم کرتا ہے — دیکھیں [dotfiles](31-dotfiles.md) |
| Finder / File Explorer | Files، `Super + Shift + F` پر — دیکھیں [GUIs](22-guis.md) |
| Safari / Edge | Google Chrome `Super + Shift + Return` پر؛ کوئی اور _Setup > Defaults > Browser_ کے تحت منتخب کریں — دیکھیں [براؤزرز](23-browsers.md) |
| Preview / Photos | تصاویر، ویڈیو اور موسیقی کے لیے Omaview، PDFs کے لیے Document Viewer — دیکھیں [GUIs](22-guis.md) |
| TextEdit / Notepad | Plain، `Super + Shift + N` پر؛ کوئی اور _Setup > Defaults > Editor_ کے تحت منتخب کریں |

### کچھ چیزیں واقعی مختلف ہیں

بہت سی ترتیبات متن فائلوں میں رہتی ہیں جن میں آپ ترمیم کرتے ہیں، ان پینلز میں نہیں جن پر آپ کلک کرتے پھرتے ہیں۔ یہ قدیم لگتا ہے یہاں تک کہ آپ کو احساس ہو کہ اس کا مطلب ہے ہر تبدیلی دیکھی جا سکتی ہے، آپ کی اگلی مشین پر کاپی کی جا سکتی ہے، اور version control میں رکھی جا سکتی ہے۔ _Setup_ مینیو آپ کو سیدھا درست فائل میں ڈال دیتا ہے اور جب آپ کام مکمل کر لیں تو جو کچھ دوبارہ شروع کرنے کی ضرورت ہو اسے دوبارہ شروع کر دیتا ہے۔

اپ ڈیٹس ایک ہی کمانڈ سے آتی ہیں — _Update > Omarchy_ — جو Omarchy خود اور سسٹم پر موجود ہر پیکج کو اپ ڈیٹ کرتی ہے، پہلے اسنیپ شاٹ لے کر۔ کوئی فی ایپ اپ ڈیٹر بے ترتیب آپ کو تنگ نہیں کرتا۔ دیکھیں [اپ ڈیٹس](30-updates.md)۔

سافٹ ویئر package manager سے آتا ہے، ڈاؤن لوڈ کیے گئے انسٹالرز سے نہیں۔

اور جب آپ کوئی ونڈو بند کرتے ہیں، تو ایپ اصل میں بند ہو جاتی ہے۔ کوئی macOS والی لِمبو نہیں جہاں پروگرام بغیر کسی ونڈو کے چلتا رہتا ہے۔ `Super + W` — یا `Super + Q`، اگر یہی انگلیوں کی یادداشت لے کر آپ آئے تھے — کا مطلب ہے ختم۔

### Mac ہارڈ ویئر پر

Omarchy Intel Macs پر، اور Omarchy for Apple Silicon کے ساتھ M1، M2 اور M3 Macs پر اچھی طرح چلتا ہے۔ دیکھیں [Mac سپورٹ](44-mac-support.md)۔ اور کی بورڈ آپ کے ساتھ مہربان ہے: Omarchy کچھ بھی remap نہیں کرتا، اور Linux Command key کو Super کے طور پر لیتا ہے، تو Super بالکل وہیں بیٹھتا ہے جہاں Cmd ہمیشہ تھا۔ آپ کے انگوٹھے کو یہ تبدیلی محسوس بھی نہیں ہوگی۔

### اسے دو ہفتے دیں

عادتیں آپ کی سوچ سے زیادہ تیزی سے منتقل ہو جاتی ہیں۔ [hotkeys](07-hotkeys.md) والا باب ایک بار سرسری دیکھ لیں، اور جب بھی کوئی binding بھول جائے، `Super + K` دبائیں — یہ آپ کو وہ سب دکھاتا ہے۔ یہی واحد hotkey ہے جو آپ کو اصل میں یاد کرنی ہے۔
