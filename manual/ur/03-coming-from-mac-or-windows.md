# Mac یا Windows سے آنا

اگر آپ نے برسوں macOS یا Windows پر گزارے ہیں تو آپ کی انگلیاں سو چیزیں جانتی ہیں جنہیں آپ کا دماغ کب کا بھول چکا ہے کہ اس نے کبھی سیکھی بھی تھیں۔ یہ باب وہ ترجمے کی تہہ ہے: Omarchy میں وہ عادتیں کہاں جاتی ہیں۔ خصوصیات خود دوسری جگہ تفصیل سے بیان کی گئی ہیں — یہ صرف نقشہ ہے۔

### Super ہر چیز کا مرکز ہے

Cmd یا Windows key کے گرد بنی آپ کی تمام پٹھوں کی یادداشت ایک ہی key پر منتقل ہو جاتی ہے: Super۔ یہ PC کی بورڈ پر Windows key ہے، اور یہ Omarchy میں تقریباً ہر hotkey کا مرکز ہے۔

Spotlight یا Raycast یا Start-menu کی طرف آپ کا ردِعمل `Super + Space` بن جاتا ہے۔ اس سے Omarchy menu کھلتا ہے، جو ایپس چلاتا ہے، ترتیبات بدلتا ہے، سافٹ ویئر انسٹال کرتا ہے، اسکرین کیپچر کرتا ہے — تقریباً ہر چیز۔ فلٹر کرنے کے لیے بس لکھنا شروع کر دیں۔ `Super + Alt + Space` تمام ایپس کو ایک گرڈ پر دکھاتا ہے، بالکل Launchpad کی طرح۔ دیکھیں [navigation](04-navigation.md)۔

### کوئی ڈیسک ٹاپ آئیکن نہیں، اور dock صرف اس وقت نظر آتا ہے جب آپ float کریں

ڈیسک ٹاپ پر سجانے کے لیے کوئی آئیکن نہیں، اور tiling workspace پر کوئی dock نہیں — dock صرف floating workspace پر نظر آتا ہے (دیکھیں [navigation](04-navigation.md))۔ ایپس کسی hotkey سے شروع ہوتی ہیں (`Super + Return` ٹرمینل کے لیے، `Super + Shift + Return` براؤزر کے لیے، اور `Super + K` ہر اس چیز کی فہرست کے لیے جو mapped ہے) یا menu سے۔ UI کا واحد مستقل حصہ [the top bar](05-the-top-bar.md) ہے، جو وہ سب سنبھالتا ہے جو پہلے آپ کے لیے menu bar، system tray، اور Notification Center کرتے تھے — اور اس پر موجود تقریباً ہر widget بائیں، دائیں اور درمیانی کلک پر کچھ نہ کچھ کرتا ہے۔

### ونڈوز خود اپنی جگہ بناتی ہیں

سب سے بڑی ذہنی تبدیلی: آپ ونڈوز کو گھسیٹ کر ادھر ادھر نہیں کرتے اور نہ انہیں اسکرین کے آدھے حصوں پر snap کرتے ہیں۔ ایک ونڈو کھولیں اور وہ پوری اسکرین لے لیتی ہے۔ دوسری کھولیں اور وہ اسے تقسیم کر دیتی ہیں۔ آپ کبھی کسی ونڈو کو دوسری کے نیچے سے نکالنے کی کوشش نہیں کرتے، کیونکہ ونڈوز ایک دوسرے پر چڑھتی ہی نہیں۔

جب آپ کو واقعی floating window کی ضرورت ہو تو `Super + T` فعال ونڈو کو tiling سے باہر نکالتا ہے (اور واپس بھی لاتا ہے)۔ لیکن پہلے tiling کو ایک حقیقی موقع دیں — یہی پوری چیز کا دل ہے۔ [Navigation](04-navigation.md) آپ کو اس سے گزار کر لے جاتا ہے۔

Workspaces مانوس لگیں گے: یہ macOS Spaces یا Windows virtual desktops ہیں، فرق صرف یہ ہے کہ آپ انہیں اصل میں استعمال کریں گے، کیونکہ `Super + 1/2/3/4` سیدھا کسی ایک پر لے جاتا ہے اور `Super + Shift + 1/2/3/4` فعال ونڈو کو وہاں بھیج دیتا ہے۔ کوئی اینیمیشن تاخیر نہیں، بس فوری چھلانگ۔ اس کا مطلب ہے کہ شاید آپ کو متعدد مانیٹرز کی ضرورت ہی نہ پڑے، اگر آپ پہلے اس کے عادی تھے۔

### Copy اور paste بس کام کرتے ہیں

Mac پر آپ کے پاس ہر جگہ Cmd + C تھا۔ Windows پر آپ کے پاس ہر جگہ Ctrl + C تھا — سوائے ٹرمینل کے، جہاں یہ آپ کے پروگرام کو ختم کر دیتا ہے۔ Omarchy آپ کو `Super + C`، `Super + X`، اور `Super + V` دیتا ہے، اور یہ ہر جگہ کام کرتے ہیں، ٹرمینل سمیت۔ شیل کے لیے الگ ردِعمل سیکھنے کی کوئی ضرورت نہیں۔

Windows والو: آپ کی Win + V clipboard history `Super + Ctrl + V` پر رہتی ہے، اور اس میں متن کے ساتھ تصاویر بھی رہتی ہیں۔ دیکھیں [unified clipboard & history](08-unified-clipboard-history.md)۔

### ترجمے کی جدول

| آپ جس کی طرف ہاتھ بڑھاتے ہیں | Omarchy میں |
| ------------- | ---------- |
| Spotlight / Raycast / Start menu | `Super + Space` — Omarchy menu |
| AirDrop | LocalSend، بذریعہ `Super + Ctrl + S` — دیکھیں [GUIs](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` یا `Print Screen` — دیکھیں [screenshots & recording](12-screenshots-recording.md) |
| Notification Center | Notification history، `Super + Shift + Alt + ,` پر |
| Time Machine (سسٹم کے لیے) | ہر اپڈیٹ پر خودکار [system snapshots](47-system-snapshots.md) |
| App Store / کوئی installer ڈاؤن لوڈ کرنا | menu میں _Install_، یا `omarchy pkg add` — دیکھیں [other packages](29-other-packages.md) |
| System Settings / Control Panel | menu میں _Setup_، جو سادہ config files میں ترمیم کرتا ہے — دیکھیں [dotfiles](31-dotfiles.md) |
| Finder / File Explorer | Files، `Super + Shift + F` پر — دیکھیں [GUIs](22-guis.md) |
| Safari / Edge | Google Chrome، `Super + Shift + Return` پر؛ کوئی اور منتخب کریں _Setup > Defaults > Browser_ کے تحت — دیکھیں [browsers](23-browsers.md) |
| Preview / Photos | تصاویر، ویڈیو اور موسیقی کے لیے Omaview، PDFs کے لیے Document Viewer — دیکھیں [GUIs](22-guis.md) |
| TextEdit / Notepad | Plain، `Super + Shift + N` پر؛ کوئی اور منتخب کریں _Setup > Defaults > Editor_ کے تحت |

### کچھ چیزیں واقعی مختلف ہیں

بہت سی ترتیبات متن فائلوں میں رہتی ہیں جن میں آپ ترمیم کرتے ہیں، نہ کہ ان پینلز میں جن پر آپ کلک کرتے پھرتے ہیں۔ یہ قدیم لگتا ہے جب تک آپ کو احساس نہ ہو کہ اس کا مطلب ہے ہر تبدیلی دیکھی جا سکتی ہے، آپ کی اگلی مشین پر کاپی کی جا سکتی ہے، اور version control میں رکھی جا سکتی ہے۔ _Setup_ menu آپ کو سیدھا درست فائل میں چھوڑ دیتا ہے اور جب آپ کام مکمل کر لیتے ہیں تو جس چیز کو دوبارہ شروع کرنے کی ضرورت ہو اسے دوبارہ شروع کر دیتا ہے۔

اپڈیٹس ایک ہی کمانڈ سے آتی ہیں — _Update > Omarchy_ — جو Omarchy کو خود اور سسٹم پر موجود ہر package کو اپڈیٹ کرتی ہے، پہلے snapshot لے کر۔ کوئی فی-ایپ updaters بے ترتیب اوقات میں آپ کو تنگ نہیں کرتے۔ دیکھیں [updates](30-updates.md)۔

سافٹ ویئر کسی package manager سے آتا ہے، ڈاؤن لوڈ کیے گئے installers سے نہیں۔

اور جب آپ کوئی ونڈو بند کرتے ہیں تو ایپ اصل میں بند ہو جاتی ہے۔ کوئی macOS والا مخمصہ نہیں جہاں پروگرام بغیر کسی ونڈو کے چلتا رہے۔ `Super + W` — یا `Super + Q`، اگر یہی وہ انگلیوں کی یادداشت ہے جس کے ساتھ آپ آئے تھے — کا مطلب ہے ختم۔

### Mac hardware پر

Omarchy Intel Macs پر اچھی طرح چلتا ہے — دیکھیں [Mac support](44-mac-support.md)۔ اور کی بورڈ آپ کے ساتھ مہربان ہے: Omarchy کسی چیز کو remap نہیں کرتا، اور Linux Command key کو Super کے طور پر لیتا ہے، لہٰذا Super بالکل وہیں بیٹھتا ہے جہاں Cmd ہمیشہ تھا۔ آپ کے انگوٹھے کو یہ تبدیلی محسوس ہی نہیں ہوگی۔

### اسے دو ہفتے دیں

عادتیں آپ کی توقع سے زیادہ تیزی سے منتقل ہو جاتی ہیں۔ [hotkeys](07-hotkeys.md) والے باب کو ایک بار سرسری دیکھ لیں، اور جب بھی کوئی binding بھول جائے تو `Super + K` دبائیں — یہ آپ کو وہ سب دکھا دیتا ہے۔ بس یہی ایک hotkey ہے جو آپ کو اصل میں یاد کرنی ہے۔
