# Mac یا Windows سے آنا

اگر آپ نے macOS یا Windows پر برسوں گزارے ہیں تو، آپ کی انگلیاں سو ایسی چیزیں جانتی ہیں جو آپ کا دماغ یہ بھول چکا ہے کہ اس نے کبھی سیکھی تھیں۔ یہ باب ترجمے کی پرت ہے: Omarchy میں وہ جبلتیں کہاں جاتی ہیں۔ فیچرز خود کہیں اور گہرائی میں بیان کیے گئے ہیں — یہ صرف نقشہ ہے۔

### Super ہر چیز کا مرکز ہے

Cmd یا Windows key کے گرد آپ نے جو بھی مسل میموری بنائی ہے وہ ایک key پر منتقل ہو جاتی ہے: Super۔ PC کی بورڈ پر یہ Windows key ہے، اور یہ Omarchy میں تقریباً ہر ہاٹ کی کا لنگر ہے۔

آپ کی Spotlight یا Raycast یا Start-menu جبلت `Super + Space` بن جاتی ہے۔ یہ Omarchy مینیو کھولتا ہے، جو ایپس لانچ کرتا ہے، سیٹنگز بدلتا ہے، سافٹ ویئر انسٹال کرتا ہے، اسکرین کیپچر کرتا ہے — تقریباً ہر چیز۔ فلٹر کرنے کے لیے ٹائپ کرنا شروع کریں۔ `Super + Alt + Space` ہر ایپ کو ایک گرڈ پر دکھاتا ہے، جس طرح Launchpad کرتا ہے۔ [نیویگیشن](04-navigation.md) دیکھیں۔

### کوئی ڈاک نہیں اور کوئی ڈیسک ٹاپ آئیکون نہیں

چیزیں لانچ کرنے کے لیے کلک کرنے کو کچھ نہیں، ڈیسک ٹاپ پر ترتیب دینے کو کوئی آئیکون نہیں۔ ایپس ہاٹ کی سے شروع ہوتی ہیں (ٹرمینل کے لیے `Super + Return`، براؤزر کے لیے `Super + Shift + Return`، اور ہر اس چیز کی فہرست کے لیے `Super + K` جو میپ کی ہوئی ہے) یا مینیو سے۔ UI کا ایک مستقل حصہ [اوپری بار](05-the-top-bar.md) ہے، جو وہ کچھ پورا کرتا ہے جو مینیو بار، سسٹم ٹرے اور Notification Center پہلے آپ کے لیے کرتے تھے — اور اس پر تقریباً ہر وِجِٹ بائیں، دائیں اور درمیانی کلک پر کچھ کرتا ہے۔

### ونڈوز خود جگہ پاتی ہیں

سوچ کی سب سے بڑی تبدیلی: آپ ونڈوز کو گھسیٹتے نہیں یا انہیں اسکرین کے نصف حصوں پر اسنیپ نہیں کرتے۔ ایک ونڈو کھولیں اور یہ پوری اسکرین لے لیتی ہے۔ دوسری کھولیں اور وہ اسے تقسیم کر لیتی ہیں۔ آپ کبھی کسی ونڈو کو دوسری کے نیچے سے نکال کر تلاش نہیں کرتے، کیونکہ ونڈوز ایک دوسرے پر نہیں چڑھتیں۔

جب آپ کو واقعی ایک تیرتی ہوئی ونڈو چاہیے تو، `Super + T` فعال ونڈو کو ٹائلنگ سے باہر (اور واپس) ٹوگل کرتا ہے۔ لیکن پہلے ٹائلنگ کو ایک حقیقی موقع دیں — یہ پوری چیز کا دل ہے۔ [نیویگیشن](04-navigation.md) آپ کو اس میں لے جاتا ہے۔

ورک اسپیسز مانوس لگیں گی: وہ macOS Spaces یا Windows ورچوئل ڈیسک ٹاپس ہیں، سوائے اس کے کہ آپ انہیں واقعی استعمال کریں گے، کیونکہ `Super + 1/2/3/4` سیدھا کسی ایک پر چھلانگ لگاتا ہے اور `Super + Shift + 1/2/3/4` فعال ونڈو کو وہاں بھیجتا ہے۔ اینیمیشن کی کوئی تاخیر نہیں، بس فوری چھلانگیں۔ اس کا مطلب ہے کہ اگر آپ اس سے پہلے اس کے عادی تھے تو، آپ کو متعدد مانیٹرز کی ضرورت بھی نہیں پڑ سکتی۔

### کاپی اور پیسٹ بس کام کرتے ہیں

Mac پر آپ کے پاس ہر جگہ Cmd + C تھا۔ Windows پر آپ کے پاس ہر جگہ Ctrl + C تھا — سوائے ٹرمینل کے، جہاں یہ آپ کے پروگرام کو ختم کر دیتا ہے۔ Omarchy آپ کو `Super + C`، `Super + X` اور `Super + V` دیتا ہے، اور وہ ہر جگہ کام کرتے ہیں، بشمول ٹرمینل۔ شیل کے لیے سیکھنے کو کوئی علیحدہ جبلت نہیں۔

Windows والو: آپ کی Win + V کلپ بورڈ تاریخ `Super + Ctrl + V` پر ہے، اور اس میں متن کے ساتھ تصاویر بھی شامل ہیں۔ [متحدہ کلپ بورڈ اور تاریخ](08-unified-clipboard-history.md) دیکھیں۔

### ترجمے کی جدول

| آپ جس تک پہنچتے ہیں | Omarchy میں |
| ------------- | ---------- |
| Spotlight / Raycast / Start menu | `Super + Space` — Omarchy مینیو |
| AirDrop | LocalSend، `Super + Ctrl + S` کے ذریعے — [GUIs](22-guis.md) دیکھیں |
| Cmd + Shift + 4 / Win + Shift + S | `Print Screen` — [اسکرین شاٹس اور ریکارڈنگ](12-screenshots-recording.md) دیکھیں |
| Notification Center | نوٹیفکیشن تاریخ `Super + Shift + Alt + ,` پر |
| Time Machine (سسٹم کے لیے) | ہر اپ ڈیٹ پر خودکار [سسٹم اسنیپ شاٹس](47-system-snapshots.md) |
| App Store / انسٹالر ڈاؤن لوڈ کرنا | مینیو میں _انسٹال کریں_، یا `omarchy pkg add` — [دیگر پیکیجز](29-other-packages.md) دیکھیں |
| System Settings / Control Panel | مینیو میں _سیٹ اپ_، جو سادہ کانفیگ فائلز میں ترمیم کرتا ہے — [dotfiles](31-dotfiles.md) دیکھیں |

### کچھ چیزیں واقعی مختلف ہیں

بہت سی سیٹنگز ٹیکسٹ فائلز میں موجود ہیں جن میں آپ ترمیم کرتے ہیں، ایسے پینلز میں نہیں جن پر آپ کلک کرتے پھرتے ہیں۔ یہ قدیم لگتا ہے جب تک آپ یہ محسوس نہیں کرتے کہ اس کا مطلب ہے کہ ہر ٹویک دیکھی جا سکتی ہے، آپ کی اگلی مشین پر کاپی کی جا سکتی ہے، اور ورژن کنٹرول میں رکھی جا سکتی ہے۔ _سیٹ اپ_ مینیو آپ کو سیدھا درست فائل میں ڈال دیتا ہے اور جب آپ مکمل کر لیتے ہیں تو جسے بھی ری اسٹارٹ کرنے کی ضرورت ہو اسے ری اسٹارٹ کر دیتا ہے۔

اپ ڈیٹس ایک کمانڈ کے ذریعے آتی ہیں — _اپ ڈیٹ کریں > Omarchy_ — جو Omarchy خود کو اور سسٹم کے ہر پیکیج کو اپ ڈیٹ کرتا ہے، پہلے ایک اسنیپ شاٹ لیتا ہے۔ کوئی فی ایپ اپ ڈیٹر آپ کو بے ترتیبی سے تنگ نہیں کرتا۔ [اپ ڈیٹس](30-updates.md) دیکھیں۔

سافٹ ویئر پیکیج مینیجر سے آتا ہے، ڈاؤن لوڈ شدہ انسٹالرز سے نہیں۔

اور جب آپ ونڈو بند کرتے ہیں تو ایپ واقعی بند ہو جاتی ہے۔ کوئی macOS لمبو نہیں جہاں پروگرام بغیر کسی ونڈو کے چلتا رہتا ہے۔ `Super + W` — یا `Super + Q`، اگر یہ انگلیوں کی وہ یادداشت ہے جس کے ساتھ آپ آئے ہیں — کا مطلب ہے ختم۔

### Mac ہارڈ ویئر پر

Omarchy Intel Macs پر اچھا چلتا ہے — [Mac سپورٹ](44-mac-support.md) دیکھیں۔ اور کی بورڈ آپ کے ساتھ مہربان ہے: Omarchy کچھ بھی ری میپ نہیں کرتا، اور Linux Command key کو Super مانتا ہے، لہٰذا Super بالکل وہیں بیٹھتا ہے جہاں Cmd ہمیشہ تھا۔ آپ کے انگوٹھے کو حرکت محسوس نہیں ہو گی۔

### اسے دو ہفتے دیں

جبلتیں آپ کی سوچ سے زیادہ تیزی سے منتقل ہوتی ہیں۔ [ہاٹ کیز](07-hotkeys.md) کے باب کو ایک بار سرسری دیکھ لیں، اور جب بھی آپ کوئی بائنڈنگ بھول جائیں، `Super + K` دبائیں — یہ آپ کو سب دکھاتا ہے۔ یہ واحد ہاٹ کی ہے جو آپ کو واقعی یاد کرنی پڑتی ہے۔
