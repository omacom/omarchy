# Mac یا Windows سے آنا

اگر آپ نے macOS یا Windows پر برسوں گزارے ہیں، تو آپ کی انگلیاں سو ایسی چیزیں جانتی ہیں جنہیں سیکھنا آپ کا دماغ کب کا بھول چکا ہے۔ یہ باب وہی ترجمے کی تہہ ہے: Omarchy میں وہ جبلتیں کہاں جاتی ہیں۔ خصوصیات خود دوسری جگہ تفصیل سے بیان کی گئی ہیں — یہ بس نقشہ ہے۔

### Super ہر چیز کا مرکز ہے

Cmd یا Windows key کے گرد بنی تمام پٹھوں کی یادداشت ایک ہی key پر منتقل ہو جاتی ہے: Super۔ PC keyboard پر یہی Windows key ہے، اور Omarchy میں تقریباً ہر hotkey کا مرکز یہی ہے۔

آپ کی Spotlight یا Raycast یا Start-menu والی جبلت `Super + Space` بن جاتی ہے۔ اس سے Omarchy menu کھلتا ہے، جو apps لانچ کرتا ہے، settings بدلتا ہے، software انسٹال کرتا ہے، screen capture کرتا ہے — تقریباً سب کچھ۔ فلٹر کرنے کے لیے ٹائپ کرنا شروع کر دیں۔ `Super + Alt + Space` تمام apps کو ایک grid پر دکھاتا ہے، جیسے Launchpad کرتا ہے۔ دیکھیں [نیویگیشن](04-navigation.md)۔

### ڈیسکٹاپ آئیکنز نہیں، اور dock صرف تب ظاہر ہوتا ہے جب آپ float کرتے ہیں

ڈیسکٹاپ پر ترتیب دینے کے لیے کوئی آئیکنز نہیں، اور tiling workspace پر کوئی dock نہیں — dock صرف floating workspace پر ظاہر ہوتا ہے (دیکھیں [نیویگیشن](04-navigation.md))۔ Apps کسی hotkey سے شروع ہوتی ہیں (`Super + Return` terminal کے لیے، `Super + Shift + Return` browser کے لیے، اور `Super + K` ہر اس چیز کی فہرست کے لیے جو mapped ہے) یا menu سے۔ UI کا واحد مستقل حصہ [اوپری بار](05-the-top-bar.md) ہے، جو وہ سب سنبھالتا ہے جو پہلے menu bar، system tray، اور Notification Center آپ کے لیے کرتے تھے — اور اس پر موجود تقریباً ہر widget بائیں، دائیں، اور درمیانی click پر کچھ نہ کچھ کرتا ہے۔

### ونڈوز خود اپنی جگہ بناتی ہیں

سب سے بڑی ذہنی تبدیلی: آپ ونڈوز کو گھسیٹ کر ادھر ادھر نہیں کرتے اور نہ انہیں screen کے آدھے حصوں پر snap کرتے ہیں۔ ایک ونڈو کھولیں اور وہ پوری screen لے لیتی ہے۔ دوسری کھولیں اور وہ اسے تقسیم کر دیتی ہیں۔ آپ کبھی کسی ونڈو کو دوسری کے نیچے سے نکالنے کی جھنجھٹ نہیں کرتے، کیونکہ ونڈوز ایک دوسرے پر چڑھتی نہیں ہیں۔

جب آپ کو واقعی ایک floating window چاہیے ہو، تو `Super + T` فعال ونڈو کو tiling سے باہر نکالتا ہے (اور واپس بھی لاتا ہے)۔ لیکن پہلے tiling کو ایک حقیقی موقع دیں — یہی پوری چیز کا دل ہے۔ [نیویگیشن](04-navigation.md) آپ کو اس میں سے گزارتا ہے۔

Workspaces مانوس لگیں گے: یہ macOS Spaces یا Windows virtual desktops ہیں، بس فرق یہ ہے کہ آپ انہیں واقعی استعمال کریں گے، کیونکہ `Super + 1/2/3/4` سیدھا کسی ایک پر لے جاتا ہے اور `Super + Shift + 1/2/3/4` فعال ونڈو کو وہاں بھیج دیتا ہے۔ کوئی animation تاخیر نہیں، بس فوری چھلانگیں۔ اس کا مطلب ہے کہ آپ کو شاید ایک سے زیادہ monitors کی ضرورت ہی نہ پڑے، اگر آپ پہلے اس کے عادی تھے۔

### کاپی اور پیسٹ بس کام کرتے ہیں

Mac پر آپ کو ہر جگہ Cmd + C ملتا تھا۔ Windows پر آپ کو ہر جگہ Ctrl + C ملتا تھا — سوائے terminal کے، جہاں یہ آپ کے program کو ختم کر دیتا ہے۔ Omarchy آپ کو `Super + C`، `Super + X`، اور `Super + V` دیتا ہے، اور یہ ہر جگہ کام کرتے ہیں، terminal سمیت۔ shell کے لیے الگ جبلت سیکھنے کی ضرورت نہیں۔

Windows والو: آپ کی Win + V clipboard history `Super + Ctrl + V` پر رہتی ہے، اور یہ متن کے ساتھ تصاویر بھی رکھتی ہے۔ دیکھیں [متحد clipboard اور history](08-unified-clipboard-history.md)۔

### ترجمے کی جدول

| آپ کس چیز کی طرف ہاتھ بڑھاتے ہیں | Omarchy میں |
| ------------- | ---------- |
| Spotlight / Raycast / Start menu | `Super + Space` — Omarchy menu |
| AirDrop | LocalSend، بذریعہ `Super + Ctrl + S` — دیکھیں [GUIs](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` یا `Print Screen` — دیکھیں [اسکرین شاٹس اور ریکارڈنگ](12-screenshots-recording.md) |
| Notification Center | Notification history `Super + Shift + Alt + ,` پر |
| Time Machine (system کے لیے) | ہر update پر خودکار [system snapshots](47-system-snapshots.md) |
| App Store / installer download کرنا | menu میں _Install_، یا `omarchy pkg add` — دیکھیں [دیگر packages](29-other-packages.md) |
| System Settings / Control Panel | menu میں _Setup_، جو سادہ config files میں ترمیم کرتا ہے — دیکھیں [dotfiles](31-dotfiles.md) |
| Finder / File Explorer | Files، `Super + Shift + F` پر — دیکھیں [GUIs](22-guis.md) |
| Safari / Edge | Google Chrome `Super + Shift + Return` پر؛ کوئی اور _Setup > Defaults > Browser_ کے تحت منتخب کریں — دیکھیں [براؤزرز](23-browsers.md) |
| Preview / Photos | تصاویر، video اور music کے لیے Omaview، PDFs کے لیے Document Viewer — دیکھیں [GUIs](22-guis.md) |
| TextEdit / Notepad | Plain، `Super + Shift + N` پر؛ کوئی اور _Setup > Defaults > Editor_ کے تحت منتخب کریں |

### کچھ چیزیں واقعی مختلف ہیں

بہت سی settings ان text files میں رہتی ہیں جن میں آپ ترمیم کرتے ہیں، ان panels میں نہیں جن میں آپ کلک کرتے پھرتے ہیں۔ یہ بات قدیم لگتی ہے جب تک آپ کو احساس نہ ہو کہ اس کا مطلب ہے ہر تبدیلی دیکھی جا سکتی ہے، آپ کی اگلی machine پر copy کی جا سکتی ہے، اور version control میں رکھی جا سکتی ہے۔ _Setup_ menu آپ کو سیدھا درست file میں لے جاتا ہے اور جب آپ فارغ ہو جائیں تو جس چیز کو restart کرنے کی ضرورت ہو اسے restart کر دیتا ہے۔

Updates ایک ہی command سے آتی ہیں — _Update > Omarchy_ — جو Omarchy کو خود بھی اور system پر موجود ہر package کو بھی update کرتی ہے، پہلے ایک snapshot لے کر۔ کوئی per-app updaters بے ترتیب وقت پر آپ کو تنگ نہیں کرتے۔ دیکھیں [اپ ڈیٹس](30-updates.md)۔

Software کسی package manager سے آتا ہے، download کیے گئے installers سے نہیں۔

اور جب آپ کوئی ونڈو بند کرتے ہیں، تو app واقعی بند ہو جاتی ہے۔ کوئی macOS والی لٹکی ہوئی حالت نہیں جہاں program بغیر ونڈوز کے چلتا رہے۔ `Super + W` — یا `Super + Q`، اگر آپ اسی انگلیوں کی یادداشت کے ساتھ آئے ہیں — کا مطلب ہے ختم۔

### Mac hardware پر

Omarchy Intel Macs پر، اور Omarchy for Apple Silicon کے ساتھ M1، M2 اور M3 Macs پر اچھی طرح چلتا ہے۔ دیکھیں [Mac معاونت](44-mac-support.md)۔ اور keyboard آپ کے لیے مہربان ہے: Omarchy کسی چیز کو remap نہیں کرتا، اور Linux Command key کو Super کے طور پر لیتا ہے، اس لیے Super بالکل وہیں بیٹھتا ہے جہاں Cmd ہمیشہ تھا۔ آپ کے انگوٹھے کو یہ تبدیلی محسوس ہی نہیں ہوگی۔

### اسے دو ہفتے دیں

جبلتیں آپ کی توقع سے زیادہ تیزی سے منتقل ہو جاتی ہیں۔ [ہاٹ کیز](07-hotkeys.md) والا باب ایک بار سرسری دیکھ لیں، اور جب بھی کوئی binding بھول جائے، `Super + K` دبائیں — یہ آپ کو سب دکھا دیتا ہے۔ یہی واحد hotkey ہے جو آپ کو واقعی یاد کرنا ہے۔
