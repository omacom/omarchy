# دوہری بوٹ انسٹال

آپ Omarchy کو Windows یا دیگر انسٹالیشنز کے ساتھ ساتھ ایک ہی پارٹیشن پر انسٹال کر سکتے ہیں۔

یہ انسٹالیشن طریقہ طے شدہ طور پر پارٹیشن کے لیے LUKS خفیہ کاری کے ساتھ بھی آتا ہے لہٰذا یہ عملی طور پر مکمل ڈرائیو سے مختلف نہیں ہے اور صرف یہ درکار ہے کہ ڈسک پر خالی جگہ دستیاب ہو۔

## Windows پر جگہ بنانا

Windows کے ساتھ ساتھ انسٹال کرنے کے لیے، اسٹارٹ مینیو میں `disk management` لکھیں اور **Create and format hard disk partitions** کے لیے آپشن منتخب کریں۔

 ![dual-boot-1](images/dual-boot-1.webp)

مناسب پارٹیشن تلاش کریں، دایاں کلک کریں، اور **Shrink Volume** منتخب کریں۔

![dual-boot-2](images/dual-boot-2.webp)

 وہ مقدار درج کریں جتنا آپ والیوم کو سکڑانا چاہتے ہیں۔ نوٹ کریں کہ یہ بوٹ پارٹیشن سمیت آپ کے مستقبل کی Omarchy انسٹال کا سائز ہو گا۔

 ![dual-boot-3](images/dual-boot-3.webp)

جب آپ ختم کر لیں تو آپ کو کچھ اس جیسا نظر آنا چاہیے جہاں 50GB والا حصہ وہ ہے جہاں ہم اس مثال میں Omarchy انسٹال کریں گے۔

 ![dual-boot-4](images/dual-boot-4.webp)

## Omarchy انسٹال کرنا

Omarchy کا انسٹال عمل عملی طور پر معمول جیسا ہی ہے۔ آپ اپنی ڈسک منتخب کرنے کے بعد، آپ کو **Free space install** کا آپشن دیا جائے گا۔ مکمل ڈسک صاف ہونے سے روکنے کے لیے وہ آپشن منتخب کریں۔

 ![dual-boot-5](images/dual-boot-5.webp)

تصدیق کریں کہ سب کچھ اچھا لگ رہا ہے اور انسٹال کے ختم ہونے کا معمول کے مطابق انتظار کریں۔ یہیں آپ مکمل ڈرائیو انسٹال کی طرح بغیر خفیہ کاری انسٹال کرنے کا انتخاب بھی کر سکتے ہیں (تجویز کردہ نہیں)۔
 ![dual-boot-6](images/dual-boot-6.webp)

## بوٹ لوڈر میں دیگر انسٹالز شامل کرنا

جب آپ اپنی Omarchy انسٹال مکمل کر لیں گے تو آپ دیکھیں گے کہ اب Limine بوٹ لوڈر طے شدہ ہے۔ اس کے ساتھ، آپ اپنی دیگر انسٹالز جیسے Windows کے لیے بھی Limine میں آپشنز شامل کر سکتے ہیں۔

ایسا کرنے کے لیے، `limine-scan` چلائیں اور اپنی limine کنفگ میں جو بھی آئٹمز شامل کرنا چاہتے ہیں ان کے لیے اشاروں کی پیروی کریں۔ پھر جب آپ بوٹ کریں گے تو آپ کو Omarchy کے لیے اپنے معمول کے آپشنز، نیز Windows Boot Manager یا دیگر نظر آئیں گے۔

## Bitlocker

یہ نوٹ کرنا اہم ہے کہ یہ انسٹال طریقہ Bitlocker کے ساتھ ہم آہنگ نہیں ہے کیونکہ یہ صرف پارٹیشن نہیں بلکہ پوری ڈرائیو کو خفیہ کرتا ہے۔ اگر آپ کو ایسی غلطی آئے جس میں بیان ہو کہ Bitlocker فعال ہے تو Windows میں بوٹ کریں، **Settings -> Privacy & Security -> Device encryption** پر جائیں اور Bitlocker آف کر دیں۔ ڈرائیو ڈی کریپٹ کرنے میں کچھ وقت لگ سکتا ہے۔
