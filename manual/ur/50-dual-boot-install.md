# ڈوئل بوٹ انسٹال

آپ Omarchy کو Windows یا دیگر انسٹالیشنز کے ساتھ ایک ہی پارٹیشن میں انسٹال کر سکتے ہیں۔

اس انسٹالیشن طریقے میں بھی پارٹیشن کے لیے بطور ڈیفالٹ LUKS انکرپشن شامل ہوتی ہے، اس لیے یہ عملی طور پر مکمل ڈرائیو انسٹال سے مختلف نہیں ہے اور اس کے لیے بس ڈسک پر خالی جگہ دستیاب ہونا ضروری ہے۔

## Windows پر جگہ بنانا

Windows کے ساتھ انسٹال کرنے کے لیے، اسٹارٹ مینو میں `disk management` ٹائپ کریں اور **Create and format hard disk partitions** کا آپشن منتخب کریں۔

 ![dual-boot-1](images/dual-boot-1.webp)

مناسب پارٹیشن تلاش کریں، اس پر رائٹ کلک کریں اور **Shrink Volume** منتخب کریں۔

![dual-boot-2](images/dual-boot-2.webp)

 وہ مقدار درج کریں جس قدر آپ والیوم کو سکڑنا چاہتے ہیں۔ نوٹ کریں کہ یہی آپ کے مستقبل کے Omarchy انسٹال کا سائز ہوگا، جس میں بوٹ پارٹیشن بھی شامل ہوگی۔

 ![dual-boot-3](images/dual-boot-3.webp)

جب آپ مکمل کر لیں تو آپ کو کچھ اس طرح کا منظر نظر آنا چاہیے، جہاں اس مثال میں 50GB والا حصہ وہ جگہ ہے جہاں ہم Omarchy انسٹال کریں گے۔

 ![dual-boot-4](images/dual-boot-4.webp)

## Omarchy انسٹال کرنا

Omarchy کا انسٹالیشن عمل عملی طور پر عام عمل جیسا ہی ہے۔ اپنی ڈسک منتخب کرنے کے بعد، آپ کو **Free space install** کا آپشن دیا جائے گا۔ مکمل ڈسک کو مٹائے جانے سے روکنے کے لیے وہ آپشن منتخب کریں۔

 ![dual-boot-5](images/dual-boot-5.webp)

تصدیق کریں کہ سب کچھ درست نظر آ رہا ہے اور معمول کے مطابق انسٹال مکمل ہونے کا انتظار کریں۔ یہی وہ جگہ بھی ہے جہاں آپ مکمل ڈرائیو انسٹال کی طرح بغیر انکرپشن کے انسٹال کرنے کا انتخاب کر سکتے ہیں (تجویز نہیں کیا جاتا)۔
 ![dual-boot-6](images/dual-boot-6.webp)

## دیگر انسٹالیشنز کو بوٹ لوڈر میں شامل کرنا

جب آپ Omarchy انسٹال مکمل کر لیں گے تو آپ دیکھیں گے کہ اب Limine بوٹ لوڈر ڈیفالٹ ہے۔ اس کے ذریعے آپ اپنی دیگر انسٹالیشنز، جیسے Windows، کے لیے بھی Limine میں آپشنز شامل کر سکتے ہیں۔

دیگر آپریٹنگ سسٹمز شامل کرنے کے لیے `limine-scan` چلائیں اور ہدایات پر عمل کرتے ہوئے اپنی Limine کنفیگریشن میں مطلوبہ اندراجات شامل کریں۔ بوٹ مینو بطور ڈیفالٹ چھپا رہتا ہے اور ایک سیکنڈ بعد Omarchy شروع ہو جاتا ہے۔ Windows یا کوئی اور اندراج منتخب کرنے کے لیے، Limine شروع ہوتے ہی کوئی بھی کنجی دبائیں؛ جب مینو ظاہر ہو تو تیر والی کنجیوں سے ایک اندراج منتخب کریں اور Enter دبائیں۔ اگر کنجی دبانے سے پہلے ہی Omarchy شروع ہو جائے تو دوبارہ شروع کر کے پھر کوشش کریں۔

## Bitlocker

یہ نوٹ کرنا اہم ہے کہ یہ انسٹالیشن طریقہ Bitlocker کے ساتھ مطابقت نہیں رکھتا، کیونکہ یہ صرف پارٹیشن کو نہیں بلکہ پوری ڈرائیو کو انکرپٹ کرتا ہے۔ اگر آپ کو یہ خرابی موصول ہو کہ Bitlocker فعال ہے تو Windows میں بوٹ کریں، **Settings -> Privacy & Security -> Device encryption** پر جائیں اور Bitlocker کو آف کر دیں۔ ڈرائیو کو ڈی کرپٹ ہونے میں کچھ وقت لگ سکتا ہے۔
