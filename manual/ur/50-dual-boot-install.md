# ڈوئل بوٹ انسٹال

آپ Omarchy کو Windows یا دیگر انسٹالیشنز کے ساتھ ایک ہی پارٹیشن پر انسٹال کر سکتے ہیں۔

اس انسٹالیشن طریقے میں بھی پارٹیشن کے لیے بطور ڈیفالٹ LUKS انکرپشن شامل ہوتی ہے، اس لیے یہ مؤثر طور پر پوری ڈرائیو والی انسٹالیشن سے مختلف نہیں ہے اور اس کے لیے صرف ڈسک پر خالی جگہ دستیاب ہونا ضروری ہے۔

## Windows پر جگہ بنانا

Windows کے ساتھ انسٹال کرنے کے لیے، اسٹارٹ مینو میں `disk management` ٹائپ کریں اور **ہارڈ ڈسک پارٹیشنز بنائیں اور فارمیٹ کریں** کا آپشن منتخب کریں۔

 ![dual-boot-1](images/dual-boot-1.webp)

مناسب پارٹیشن تلاش کریں، اس پر رائٹ کلک کریں، اور **والیوم سکڑائیں** منتخب کریں۔

![dual-boot-2](images/dual-boot-2.webp)

 وہ مقدار درج کریں جس قدر آپ والیوم کو سکڑانا چاہتے ہیں۔ نوٹ کریں کہ یہی آپ کی مستقبل کی Omarchy انسٹالیشن کا سائز ہوگا، جس میں بوٹ پارٹیشن بھی شامل ہے۔

 ![dual-boot-3](images/dual-boot-3.webp)

جب آپ کام مکمل کر لیں، تو آپ کو اس جیسی کوئی چیز نظر آنی چاہیے جہاں 50GB والا حصہ وہ جگہ ہے جہاں ہم اس مثال میں Omarchy انسٹال کریں گے۔

 ![dual-boot-4](images/dual-boot-4.webp)

## Omarchy انسٹال کرنا

Omarchy کی انسٹالیشن کا عمل مؤثر طور پر معمول جیسا ہی ہے۔ جب آپ اپنی ڈسک منتخب کر لیں گے، تو آپ کو **خالی جگہ پر انسٹال** کا آپشن دیا جائے گا۔ پوری ڈسک کو مٹانے سے بچنے کے لیے وہ آپشن منتخب کریں۔

 ![dual-boot-5](images/dual-boot-5.webp)

تصدیق کریں کہ سب کچھ درست نظر آ رہا ہے اور معمول کے مطابق انسٹالیشن مکمل ہونے کا انتظار کریں۔ یہی وہ جگہ بھی ہے جہاں آپ پوری ڈرائیو والی انسٹالیشن کی طرح غیر انکرپٹڈ انسٹال کرنے کا انتخاب کر سکتے ہیں (تجویز نہیں کیا جاتا)۔
 ![dual-boot-6](images/dual-boot-6.webp)

## دیگر انسٹالیشنز کو بوٹ لوڈر میں شامل کرنا

جب آپ اپنی Omarchy انسٹالیشن مکمل کر لیں گے، تو آپ دیکھیں گے کہ اب Limine بوٹ لوڈر ڈیفالٹ ہے۔ اس کے ساتھ، آپ Limine میں اپنی دیگر انسٹالیشنز، جیسے Windows، کے لیے آپشنز بھی شامل کر سکتے ہیں۔

دیگر آپریٹنگ سسٹمز شامل کرنے کے لیے، `limine-scan` چلائیں اور اپنی Limine کنفیگ میں مطلوبہ اندراجات شامل کرنے کے لیے ہدایات پر عمل کریں۔ بوٹ مینو بطور ڈیفالٹ چھپا رہتا ہے اور ایک سیکنڈ کے بعد Omarchy شروع کر دیتا ہے۔ Windows یا کوئی اور اندراج منتخب کرنے کے لیے، Limine شروع ہوتے ہی کوئی بھی کی دبائیں؛ جب مینو ظاہر ہو جائے، تو اندراج منتخب کرنے کے لیے ایرو کیز استعمال کریں اور Enter دبائیں۔ اگر آپ کے کی دبانے سے پہلے Omarchy شروع ہو جائے، تو دوبارہ شروع کریں اور پھر کوشش کریں۔

## Bitlocker

یہ نوٹ کرنا اہم ہے کہ یہ انسٹالیشن طریقہ Bitlocker کے ساتھ مطابقت نہیں رکھتا، کیونکہ یہ صرف پارٹیشن کو نہیں بلکہ پوری ڈرائیو کو انکرپٹ کرتا ہے۔ اگر آپ کو یہ بتانے والی خرابی موصول ہو کہ Bitlocker فعال ہے، تو Windows میں بوٹ کریں، **Settings -> Privacy & Security -> Device encryption** پر جائیں اور Bitlocker کو آف کر دیں۔ ڈرائیو کو ڈی کرپٹ ہونے میں کچھ وقت لگ سکتا ہے۔

 ![dual-boot-7](images/dual-boot-7.webp)

## Windows دوبارہ انسٹال کرنا

اگر یہ کمپیوٹر Windows کے ساتھ آیا تھا، تو اس کی پروڈکٹ کی فرم ویئر میں محفوظ ہے۔ اسے پرنٹ کرنے کے لیے `omarchy windows key` چلائیں، تاکہ اگر آپ کبھی اس مشین پر Windows دوبارہ انسٹال کریں تو آپ اسے دوبارہ فعال کر سکیں۔
