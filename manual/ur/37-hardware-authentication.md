# ہارڈویئر تصدیق

### انگلی کے نشان کی تصدیق

بہت سے لیپ ٹاپ تصدیق کے لیے انگلی کے نشان کے سینسر کے ساتھ آتے ہیں۔ آپ Omarchy مینیو (`Super + Space`) میں _Setup > Security > Fingerprint_ چلا کر Omarchy کے ساتھ اسے استعمال کر سکتے ہیں۔

اس سے انگلی کے نشان کا پیکیج انسٹال ہو جائے گا، آپ کا نشان لیا جائے گا، اس کی تصدیق کی جائے گی، اور پھر آپ تیار ہو جائیں گے کہ انگلی کے نشان سے لاک اسکرین کو ان لاک کریں (جسے آپ `Super + Ctrl + L` سے فعال کر سکتے ہیں)، sudo موڈ میں داخل ہوں، اور سسٹم پرامپٹس کی اجازت دیں۔

جب لاک اسکرین ڈسپلے بند کر دیتی ہے تو سینسر بجلی بچانے کے لیے آرام کی حالت میں چلا جاتا ہے، لہٰذا اسے چھونے سے پہلے کسی بھی کلید یا ٹچ پیڈ سے اسکرین کو جگا لیں۔

جب آپ کے لیپ ٹاپ کا ڈھکن بند ہو تو انگلی کے نشان کا پرامپٹ خود بخود چھوڑ دیا جاتا ہے، اس لیے آپ اس سینسر کا انتظار کرنے کے بجائے سیدھا پاس ورڈ پرامپٹ پر جاتے ہیں جس تک آپ پہنچ ہی نہیں سکتے۔ اگر بصورتِ دیگر آپ کو کسی بیرونی کی بورڈ پر کام کرنا پڑے جس میں سینسر نہ ہو، تو `sudo` کے دوران جب آپ سے انگلی کا نشان مانگا جائے تو بس `CTRL + C` دبا دیں۔

آپ Omarchy مینیو میں _Remove > Security > Fingerprint_ کے تحت انگلی کے نشان کی تصدیق ہٹا سکتے ہیں۔

### Fido2 تصدیق

اگر آپ Fido2 ڈیوائس استعمال کر رہے ہیں تو آپ Omarchy مینیو (`Super + Space`) میں _Setup > Security > Fido2_ استعمال کر کے اسے `sudo` تصدیق کے لیے سیٹ کر سکتے ہیں۔ البتہ اس میں `sudo` اور سسٹم کی اجازت کے پرامپٹ شامل ہیں، آپ کے کمپیوٹر کو ان لاک کرنا شامل نہیں ہے۔

آپ Omarchy مینیو میں _Remove > Security > Fido2_ کے تحت fido2 تصدیق ہٹا سکتے ہیں۔
