# ہارڈ ویئر کی تصدیق

### فنگر پرنٹ کی تصدیق

بہت سے لیپ ٹاپ تصدیق کے لیے فنگر پرنٹ سینسر کے ساتھ آتے ہیں۔ آپ Omarchy مینو (`Super + Space`) میں _Setup > Security > Fingerprint_ چلا کر اسے Omarchy کے ساتھ استعمال کر سکتے ہیں۔

اس سے ایک فل اسکرین فنگر پرنٹ کھلتا ہے جو سینسر کو چھوتے ہی بھرنے لگتا ہے۔ پس منظر میں، Omarchy فنگر پرنٹ پیکیج انسٹال کرے گا، آپ کا پرنٹ حاصل کرے گا، اس کی تصدیق کرے گا، اور آپ لاک اسکرین سے ان لاک کرنے (جسے آپ `Super + Ctrl + L` سے فعال کر سکتے ہیں)، sudo موڈ میں داخل ہونے، اور سسٹم پرامپٹس کی اجازت دینے کے لیے اپنا فنگر پرنٹ استعمال کرنے کے لیے تیار ہو جائیں گے۔

جب لاک اسکرین ڈسپلے بند کر دیتی ہے تو سینسر بجلی بچانے کے لیے آرام کی حالت میں چلا جاتا ہے، لہٰذا اسے چھونے سے پہلے کسی بھی کلید یا ٹچ پیڈ سے اسکرین کو جگا لیں۔

جب آپ کے لیپ ٹاپ کا ڈھکن بند ہو تو فنگر پرنٹ پرامپٹ خود بخود چھوڑ دیا جاتا ہے، لہٰذا آپ کسی ایسے سینسر کا انتظار کرنے کے بجائے جس تک آپ پہنچ ہی نہیں سکتے، سیدھا پاس ورڈ پرامپٹ پر چلے جاتے ہیں۔ اگر آپ کو کسی ایسے بیرونی کی بورڈ پر کام کرنا پڑے جس میں سینسر نہ ہو، تو `sudo` کے دوران جب آپ سے فنگر پرنٹ مانگا جائے تو بس `CTRL + C` دبا دیں۔

آپ Omarchy مینو میں _Remove > Security > Fingerprint_ کے تحت فنگر پرنٹ کی تصدیق ختم کر سکتے ہیں۔

### Fido2 کی تصدیق

اگر آپ Fido2 ڈیوائس استعمال کر رہے ہیں تو آپ Omarchy مینو (`Super + Space`) میں _Setup > Security > Fido2_ استعمال کر کے اسے `sudo` کی تصدیق کے لیے سیٹ اپ کر سکتے ہیں۔ تاہم، یہ `sudo` اور سسٹم کی اجازت کے پرامپٹس کا احاطہ کرتا ہے، آپ کے کمپیوٹر کو ان لاک کرنے کا نہیں۔

آپ Omarchy مینو میں _Remove > Security > Fido2_ کے تحت fido2 کی تصدیق ختم کر سکتے ہیں۔
