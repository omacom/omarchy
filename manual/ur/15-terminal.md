# ٹرمینل

[Foot](https://codeberg.org/dnkl/foot) Omarchy کے لیے ڈیفالٹ ٹرمینل ہے۔ یہ تیز، ہلکا پھلکا ہے اور پرانے کمپیوٹرز کے ساتھ بھی ہم آہنگ ہے۔ تاہم یہ نیٹو ٹیبز یا اسپلٹس کی حمایت نہیں کرتا۔

اگر آپ Tmux استعمال کرتے ہیں تو آپ کو پروا نہیں ہو گی، لیکن اگر نہیں تو ہم اختیارات کے طور پر _Alacritty_، _Ghostty_ اور _Kitty_ کی بھی مکمل حمایت کرتے ہیں۔ Omarchy مینیو میں _انسٹال کریں > Terminal_ کے نیچے اپنی ترجیح منتخب کریں۔

آپ `Super + Return` استعمال کر کے نیا ٹرمینل شروع کرتے ہیں۔ (یہ بائنڈنگ خود بخود اسی ٹرمینل کی طرف اشارہ کرے گی جو آپ نے _انسٹال کریں > Terminal_ کے ذریعے انسٹال کیا ہو گا، اور آپ انسٹال شدہ ٹرمینلز کے درمیان _سیٹ اپ > Defaults > Terminal_ کے نیچے تبدیلی کر سکتے ہیں۔)

## Tmux

Tmux آپ کے ٹرمینل سے قطع نظر، پینز، ونڈوز (جسے ٹیبز بھی کہا جاتا ہے)، اور دوبارہ شروع ہونے کے قابل سیشنز کے لیے ایک مستقل، پروگرام کے قابل انٹرفیس فراہم کرتا ہے۔ یہ ریموٹ ہوسٹس پر بھی کام کرتا ہے، لہٰذا جب آپ سرور میں SSH کر رہے ہوں تو آپ وہی طریقہ استعمال کر سکتے ہیں۔

آپ `Super + Alt + Return` استعمال کر کے نئے ٹرمینل میں نیا Tmux سیشن شروع کرتے ہیں، اور چونکہ Tmux ایک مستقل عمل ہے، لہٰذا اگر آپ وہ ٹرمینل بند بھی کر دیں تو اپنا سیشن دوبارہ شروع کر سکتے ہیں۔ اپنے تمام فعال سیشنز دیکھنے کے لیے بس `Ctrl + Space` (جسے پریفکس کی کہا جاتا ہے) پھر `s` دبائیں۔

Omarchy ارگونومک طور پر آپٹیمائز شدہ Tmux کنفیگریشن کے ساتھ آتا ہے، جس میں سیکھنے کے لیے بہت سی کی بائنڈنگز ہیں، لہٰذا [چیٹ شیٹ ہاتھ میں رکھیں](07-hotkeys.md#tmux)۔

## Tmux لے آؤٹ فنکشنز

چونکہ Tmux پروگرام کے قابل ہے، ہم لے آؤٹس بنانے کے لیے فنکشنز استعمال کر سکتے ہیں۔ Omarchy عام ڈویلپر لے آؤٹس کے لیے چار مختلف فنکشنز کے ساتھ آتا ہے۔

`tdl [agent]` تین طرفہ اسپلٹ IDE جیسا انٹرفیس شروع کرتا ہے جس میں بائیں طرف `$EDITOR`، دائیں طرف آپ کا منتخب AI ایجنٹ (جیسے opencode کے لیے `c` یا Claude کے لیے `cx` یا OpenAI کے لیے `codex`)، اور پھر نیچے ایک ٹرمینل ہوتا ہے۔

لہٰذا `tdl c` یہ شروع کرے گا (یا صرف `ic`):

 ![tmux-tdl](images/tmux-tdl.webp)

آپ `tdl c cx` (opencode + claude) سے دوسرا ایجنٹ بھی شروع کر سکتے ہیں (یا صرف `icx`):

 ![tmux-tdl2](images/tmux-tdl2.webp)

`tds` بھی ہے، جو چار طرفہ مربع شروع کرتا ہے جس میں ایڈیٹر اوپر بائیں، لائیو ڈِف واچر اوپر دائیں، ٹرمینل نیچے بائیں، اور opencode نیچے دائیں ہوتا ہے۔

آپ `tdlm [agent]` استعمال کر کے موجودہ ڈائریکٹری میں ہر سب ڈائریکٹری کے لیے یہ لے آؤٹ کنفیگریشن بھی شروع کر سکتے ہیں، پھر `alt + 1/2/3/4/5/...` استعمال کر کے نیویگیٹ کر سکتے ہیں:

 ![tmux-tdlm](images/tmux-tdlm.webp)

آخر میں، آپ `tsl [panes] [command]` استعمال کر کے ایجنٹس کا ایک جھنڈ شروع کر سکتے ہیں۔ لہٰذا `tsl 4 c` آپ کو opencode ایجنٹس کی چار طرفہ گرڈ دے گا:

 ![tmux-tsl](images/tmux-tsl.webp)
