# نیویگیشن

Omarchy میں ہر کام کی بورڈ کے ذریعے ہوتا ہے — _ہر چیز!_ جب سسٹم پہلی بار شروع ہوتا ہے تو آپ لفظی طور پر صرف ماؤس سے کچھ نہیں کر سکتے۔ لیکن آپ `Super + Space` دبا کر Omarchy Menu ظاہر کر سکتے ہیں اور یہاں سے آپ تقریباً ہر کام کر سکتے ہیں۔

لیکن Omarchy مینیو کو زیادہ تر وقت سسٹم چلانے کا مرکزی طریقہ بنانا مقصود ہی نہیں ہے۔ ہم اس سے بھی تیز ہو سکتے ہیں! تمام اہم ترین ایپلیکیشنز براہ راست انفرادی ہاٹ کیز سے منسلک ہیں۔ آپ `Super + Return` سے ٹرمینل شروع کرتے ہیں اور `Super + Shift + Return` سے براؤزر۔ ایک کے بعد دوسرا کر کے دیکھیں، اور آپ کو Hyprland کی ٹائلنگ کا جادو عملی طور پر نظر آئے گا:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

پھر آپ `Super + J` دبا کر انہیں ساتھ ساتھ رکھنے کے بجائے ایک دوسرے کے اوپر رکھ سکتے ہیں:

 ![navigation-stacked](images/navigation-stacked.webp)

`Super + J` دوبارہ دبائیں تو وہ اپنی ساتھ ساتھ والی جگہوں پر واپس آ جائیں گی۔ پھر براؤزر میں ہوتے ہوئے `Super + Shift + Arrow Right` دبا کر ونڈوز کو آپس میں بدل کر دیکھیں۔

اب `Super + Shift + T` دبا کر Activity monitor شروع کر کے دیکھیں۔ وہ ایک فلوٹنگ ونڈو کے طور پر ظاہر ہوگا، جس میں اسے گھسیٹنے کے لیے titlebar اور اسے minimize، maximize اور بند کرنے کے بٹن ہوں گے۔ ہر فلوٹنگ ونڈو کو ایک ملتا ہے، وہ جہاں بھی ہو۔ آپ `Super + T` سے اسے tile کر سکتے ہیں (اور اسے دوبارہ دبانے سے وہ پھر فلوٹنگ ہو جائے گا)۔ اب file manager کھولنے کے لیے `Super + Shift + F` دبائیں۔ آپ کے پاس ایک صاف ستھری چار طرفہ ترتیب ہوگی:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

آپ `Super + Arrow` سے اس ونڈو کے درمیان نیویگیٹ کرتے ہیں جسے آپ فعال کرنا چاہتے ہیں۔ اس سے فوکس بدل جاتا ہے اور کرسر نئی ایپلیکیشن کے مرکز میں چلا جاتا ہے۔ اسکرین کے کنارے پر یہ اسی سمت والے monitor پر آگے بڑھ جاتا ہے۔

اگر آپ `Super + Shift + 2` دبائیں تو آپ موجودہ فوکس شدہ ایپلیکیشن کو دوسرے ورک اسپیس پر منتقل کر دیں گے۔ `Super + Shift + 1` اسے واپس لے آتا ہے۔ (اور `Super + Shift + Alt + 2` موجودہ فوکس شدہ ایپلیکیشن کو دوسرے ورک اسپیس پر منتقل کر دے گا بغیر خود اس پر جائے۔)

ایک سے زیادہ monitor کے ساتھ، ہر monitor کے اپنے ورک اسپیس 1 سے 10 ہوتے ہیں۔ `Super + 2` آپ کے موجودہ monitor کے دوسرے ورک اسپیس پر جاتا ہے، اور ہر monitor کی top bar اس کے اپنے ورک اسپیسز اور وہ ورک اسپیس دکھاتی ہے جو وہ دکھا رہا ہے۔ `Super + Tab` آپ کے موجودہ monitor کے ورک اسپیسز میں چکر لگاتا ہے۔ `Super + Shift + Ctrl + Arrows` آپ کی موجودہ ونڈو کو اس سمت والے monitor پر، اس ورک اسپیس پر جو وہ دکھا رہا ہے، منتقل کرتا ہے، اور `Super + Shift + Alt + Arrows` آپ کے موجودہ ورک اسپیس کو اس سمت والے monitor پر لے جاتا ہے، جہاں اگر وہی نمبر خالی ہو تو یہ وہی نمبر لے لیتا ہے۔ جب آپ monitor کو ان پلگ کرتے ہیں تو وہ اپنے ورک اسپیسز برقرار رکھتا ہے: وہ دوسری اسکرین کے ورک اسپیسز میں شامل ہو جاتے ہیں، اس کے پہلے سے موجود ورک اسپیسز کے بعد نمبر لے کر، اور جب monitor واپس آتا ہے تو اپنے پرانے نمبروں کے تحت واپس چلے جاتے ہیں۔

اگر آپ `Super` دبائے رکھیں اور ماؤس سے کسی ونڈو پر کلک کریں تو آپ اس کی جگہ دوبارہ ترتیب دے سکیں گے۔ اگر آپ `Super` دبائے رکھیں اور ماؤس کا دایاں بٹن استعمال کریں تو آپ ونڈو کا سائز آزادانہ بدل سکتے ہیں۔

آپ ونڈو کو `Super + W` یا `Super + Q` سے بند کرتے ہیں (اور تمام ونڈوز کو `Ctrl + Alt + Delete` سے بند کرتے ہیں)۔

آپ `Super + F` سے full screen بھی جا سکتے ہیں یا `Super + Alt + F` سے صرف full-width (top bar برقرار رکھتے ہوئے) یا `Super + Ctrl + F` سے کسی ونڈو کے اندر full-screen بھی جا سکتے ہیں (YouTube کے لیے بہترین!)۔

### Dwindle بمقابلہ scrolling لی آؤٹ

Omarchy کا default لی آؤٹ dwindle کہلاتا ہے۔ یہ آپ کی کھولی گئی تمام ونڈوز کو ایک ہی ورک اسپیس پر ہر وقت نظر آنے دیتا ہے، چاہے اس کے لیے انہیں چھوٹا ہی کیوں نہ کرنا پڑے۔

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

لیکن آپ کسی ورک اسپیس کو scrolling لی آؤٹ میں بدلنے کا انتخاب بھی کر سکتے ہیں جہاں ونڈوز ساتھ ساتھ قطار میں لگی ہوتی ہیں، ڈسپلے کے دکھائی دینے والے کنارے سے آگے تک۔ آپ `Super + L` کے ذریعے کسی ایک ورک اسپیس کو اس لی آؤٹ میں بدلتے ہیں۔

`Super + L` دوبارہ دبانے سے ورک اسپیس فلوٹنگ ہو جاتا ہے، جہاں ونڈوز آزادانہ ایک دوسرے پر چڑھتی ہیں اور آپ خود انہیں رکھتے ہیں، اور تیسری بار دبانے سے یہ dwindle پر واپس آ جاتا ہے۔ `Super + Alt + L` اسی سلسلے میں دوسری سمت جاتا ہے۔ جو ونڈو ویسے ہی فلوٹ ہوتی ہے — جسے آپ نے `Super + T` سے باہر نکالا ہو، یا کوئی ایسی ایپ جو ہمیشہ فلوٹنگ کھلتی ہو — وہ اس وقت بھی فلوٹ کرتی رہتی ہے جب ورک اسپیس ٹائلنگ پر واپس جاتا ہے۔ top bar آپ کے موجودہ ورک اسپیس کو اس کے لی آؤٹ کے ساتھ نشان زد کرتی ہے: dwindle کے لیے مربع، scrolling کے لیے دائرہ، اور فلوٹنگ کے لیے تکون۔ اس نشان پر کلک کرنے سے بھی لی آؤٹ بدلتا ہے، اور جن لیپ ٹاپس میں display key ہوتی ہے ان پر وہ بھی یہی کام کرتی ہے۔

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

یہ انتخاب فی ورک اسپیس ہوتا ہے، اور یہ برقرار رہتا ہے۔ چنانچہ آپ ورک اسپیس 1 کو براؤزنگ کے لیے dwindle پر اور ورک اسپیس 2 کو کوڈ کے لیے scrolling پر رکھ سکتے ہیں، اور restart کے بعد بھی وہ اسی طرح واپس آئیں گے۔

اگر آپ scrolling لی آؤٹ کو default کے طور پر استعمال کرنا چاہتے ہیں تو آپ اسے `~/.config/hypr/looknfeel.lua` میں سیٹ کر سکتے ہیں:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### فلوٹنگ ورک اسپیسز

فلوٹنگ ورک اسپیس روایتی ڈیسک ٹاپ کی طرح کام کرتا ہے: ونڈوز ایک دوسرے پر چڑھی ہوتی ہیں، اور آپ خود انہیں حرکت دیتے اور ان کا سائز بدلتے ہیں۔ ہر ونڈو کو آپ کی تھیم کے رنگوں میں ایک titlebar ملتا ہے، جس میں minimize، maximize اور بند کرنے کے بٹن ہوتے ہیں۔ `Super + M` فوکس شدہ ونڈو کو بھی minimize کرتا ہے۔ minimize کی گئی ونڈو dock میں انتظار کرتی ہے؛ اس کی ایپ پر کلک کریں تو وہ واپس آ جاتی ہے۔ کسی ونڈو پر کلک کریں تو وہ آگے آ جاتی ہے۔ اس کا سائز کسی بھی کنارے یا کونے سے بدلیں۔ titlebar پر ڈبل کلک کریں تو ونڈو maximize ہو جاتی ہے جبکہ top bar نظر آتا رہتا ہے، اور دوبارہ ڈبل کلک کریں تو اس کا پرانا سائز واپس مل جاتا ہے۔ Chrome اور دیگر Chromium پر مبنی براؤزرز، Disks اور Document Viewer titlebar کو چھوڑ دیتے ہیں اور اس کے بجائے اپنا header استعمال کرتے ہیں؛ `Super + Alt + F` انہیں maximize کرتا ہے، اور `Super + M` انہیں minimize کرتا ہے۔

ہر ورک اسپیس میں ایک dock ہوتا ہے، جس میں آپ کی pin کی گئی ایپس، چلنے والی تمام ایپس، اور apps بٹن کے پیچھے ہر ایپ کی ایک grid ہوتی ہے، جسے `Super + Alt + Space` اور Omarchy مینیو میں _Apps_ بھی کھولتے ہیں۔ grid پر کسی ایپ پر دائیں کلک کریں، یا `Delete` دبائیں، تو اسے uninstall کر دیں۔ کسی ایپ پر کلک کریں تو وہ کھل جاتی ہے، یا اس کی ونڈو آگے آ جاتی ہے؛ دوبارہ کلک کریں تو اس کی ونڈوز میں چکر لگائیں۔ Files صرف اسی ورک اسپیس سے ونڈو واپس لاتا ہے جس پر آپ ہیں اور ورنہ نئی ونڈو کھولتا ہے، اور Terminal اور Agent ہمیشہ ایک اور شروع کرتے ہیں، البتہ minimize کی گئی ونڈو پہلے واپس آتی ہے۔ درمیانی کلک سے نئی ونڈو کھلتی ہے۔ کسی آئیکن کو dock کے ساتھ گھسیٹ کر اسے حرکت دیں؛ چلتی ہوئی ایپ کو دوسروں کے درمیان گھسیٹ کر رکھنے سے وہ وہیں رہتی ہے۔ دائیں کلک کریں تو ایپ کو dock میں رکھیں، اسے نکالیں، یا اسے بند کریں۔ dock اس وقت باہر رہتا ہے جب ورک اسپیس خالی ہو، اور جیسے ہی ورک اسپیس میں کوئی ونڈو آتی ہے تو یہ چھپ جاتا ہے جب تک pointer اس کے کنارے تک نہ پہنچے۔ fullscreen ونڈو اسے مکمل طور پر چھپا دیتی ہے۔ apps بٹن کو اسکرین کے کسی اور کنارے کی طرف گھسیٹیں تو dock وہاں منتقل ہو جاتا ہے۔ اس پر دائیں کلک کریں تو _Position_ سے کنارہ منتخب کریں، _Layout_ سے default لی آؤٹ اسی طرح سیٹ کریں جیسے _Appearance > Workspace Layout_ کرتا ہے، اور _Visibility_ سے dock کو ہمیشہ آن رکھیں، پہلی ایپ سے اسے چھپائیں، یا اسے ہمیشہ چھپا رکھیں۔ `omarchy dock visibility always` اسے ٹرمینل سے سیٹ کرتا ہے۔ یہ پوزیشن _Appearance > Dock > Dock Position_ کے تحت بھی ہے، اور `omarchy dock position left` اسے ٹرمینل سے سیٹ کرتا ہے۔ جو ایپس آپ dock میں رکھتے ہیں وہ اس وقت مدھم نظر آتی ہیں جب وہ چل نہیں رہی ہوتیں۔ dock کو صرف فلوٹنگ ورک اسپیسز تک محدود رکھنے کے لیے _Appearance > Dock > Dock Only on Floating_ یا `omarchy dock tiling off` استعمال کریں۔

نئے ورک اسپیسز، اور کوئی بھی ایسا ورک اسپیس جسے آپ نے `Super + L` سے اس کا اپنا لی آؤٹ نہ دیا ہو، default لی آؤٹ استعمال کرتے ہیں۔ default بدلنے سے بغیر ونڈوز والا ہر ورک اسپیس اس پر reset ہو جاتا ہے، جبکہ جس ورک اسپیس پر ونڈوز ہوں وہ اپنا موجودہ لی آؤٹ برقرار رکھتا ہے۔ dock میں minimize کی گئی ونڈو اب بھی اس ورک اسپیس کی ونڈو شمار ہوتی ہے جسے اس نے چھوڑا تھا۔ اسے _Appearance > Workspace Layout_ کے تحت منتخب کریں: Tiling، Scrolling، یا Floating۔ `omarchy hyprland workspace layout default scrolling` اسے ٹرمینل سے سیٹ کرتا ہے۔

### ونڈوز کو گروپ کرنا

ونڈوز کو `Super + G` سے گروپ کیا جا سکتا ہے۔ جب آپ کسی گروپ میں ہوں تو اس کے فعال ہوتے ہوئے آپ جو بھی ونڈو شروع کریں گے وہ اس گروپ سے تعلق رکھے گی۔ آپ `Super + Ctrl + Arrow Left/Right` سے ان گروپ شدہ ونڈوز کے درمیان حرکت کر سکتے ہیں یا `Super + Alt + 1/2/3/4` سے ترتیب کے مطابق براہ راست گروپ شدہ ونڈوز پر جا سکتے ہیں۔

آپ `Super + Alt + G` سے کسی ونڈو کو گروپ سے باہر نکال سکتے ہیں یا `Super + G` دوبارہ دبا کر پورا گروپ ختم کر سکتے ہیں۔ آخر میں، آپ `Super + Alt + Arrows` سے گروپ سے باہر کی ونڈوز کو اس میں منتقل کر سکتے ہیں۔

### ونڈوز کو باہر نکالنا

آپ `Super + O` سے کسی ونڈو کو اس کی ورک اسپیس تقسیم سے باہر نکال سکتے ہیں۔ اس سے وہ ایک فلوٹنگ ونڈو کے طور پر pin ہو جائے گی جو آپ جس بھی ورک اسپیس پر جائیں وہاں آپ کے ساتھ چلے گی۔ video players اور اس جیسی چیزوں کے لیے بہترین۔

 ![navigation-popped-window](images/navigation-popped-window.webp)

### اسکریچ پیڈ ورک اسپیس

ایک خاص full-size اسکریچ پیڈ ورک اسپیس ہے جو آپ کے موجودہ ورک اسپیس پر اوپر آ جاتا ہے۔ آپ `Super + S` سے اس پر موجود چیزوں تک رسائی حاصل کرتے ہیں، اور `Super + Alt + S` سے وہاں ونڈوز رکھتے ہیں۔

یہ controls یا کسی ٹرمینل کے لیے بہت اچھا کام کرتا ہے جس کے ساتھ آپ موجودہ ورک اسپیس چھوڑے بغیر تیزی سے تعامل کرنا چاہتے ہیں۔

### Quake کنسول

آخر میں، ایک آدھی اونچائی والا Quake کنسول ہے جو آپ کے موجودہ ورک اسپیس پر نیچے گر کر آ جاتا ہے۔ اسے `Super + the key above Tab` (US لی آؤٹس پر grave) سے toggle کریں، اور `Super + Shift + the key above Tab` سے وہاں کوئی ونڈو رکھیں۔

پہلی بار کھلنے پر یہ آپ کا default agent شروع کرتا ہے، یا اگر آپ نے ابھی تک کوئی منتخب نہیں کیا تو آپ سے ایک منتخب کرنے کو کہتا ہے۔ جب کنسول میں صرف ایک ونڈو ہوتی ہے تو یہ اسکرین پر پھیلنے کے بجائے مرکز میں ایک panel کے طور پر نیچے آتا ہے۔ اس پر دوسری ایپ رکھیں تو یہ واپس پوری چوڑائی پر چلا جاتا ہے، تاکہ دونوں کو ساتھ ساتھ بیٹھنے کی جگہ ملے۔

کسی ونڈو کو اسکریچ پیڈ یا کنسول دونوں میں سے کسی سے بھی ہٹانے کے لیے اسے `Super + Shift + 1` جیسی کسی ترکیب سے براہ راست دوسرے ورک اسپیس پر بھیج دیں۔

اپنے ڈیسک ٹاپ کو اس طرح نیویگیٹ کرنے کی عادت پڑنے میں تھوڑا وقت لگتا ہے، لیکن جب پڑ جائے گی تو روایتی ماؤس سے چلنے والے ڈیسک ٹاپ تجربے پر واپس جانا مشکل ہو جائے گا!
