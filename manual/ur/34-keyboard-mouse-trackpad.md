# کی بورڈ، ماؤس، ٹریک پیڈ

Hyprland آپ کو اپنے تمام ان پٹس کو بہت تفصیل سے ترتیب دینے کی سہولت دیتا ہے۔ آپ کی بورڈ ریپیٹ کو سپر سونک حد تک تیز کر سکتے ہیں یا ٹریک پیڈ سے نیچرل اسکرولنگ کروا سکتے ہیں۔ آپ یہ سب کچھ `~/.config/hypr/input.lua` میں تبدیل کرتے ہیں، جہاں آپ Omarchy مینیو (`Super + Space`) میں _سیٹ اپ > ان پٹ_ کے ذریعے بھی پہنچ سکتے ہیں۔ وہاں آپ جو کچھ بھی مقرر کریں گے وہ Omarchy کی طے شدہ ترتیبات کی جگہ لے لے گا۔

یہ رہی ایک مثال:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

آپ ان پٹس کے لیے Hyprland ویکی پر [تمام ان پٹ آپشنز دیکھ سکتے ہیں](https://wiki.hypr.land/Configuring/Basics/Variables/#input)۔

CapsLock معمول کی Caps Lock کے طور پر کام کرتا ہے، اور `Shift + CapsLock` [فوری ایموجیز](07-hotkeys.md#quick-emojis) اور [دیگر تکمیلات](07-hotkeys.md#quick-completions) کے لیے کمپوز کی ہے۔ اگر آپ کمپوز کی کہیں اور رکھنا پسند کریں تو `kb_options` میں `omarchy:shift_caps_compose` کو تبدیل کر دیں۔ مثال کے طور پر، یہ کمپوز کی کو Right Alt پر منتقل کر دیتا ہے:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### فنکشن کیز

لیپ ٹاپ کی بورڈ کی سب سے اوپر والی قطار بطورِ طے شدہ میڈیا کیز (والیوم، چمک وغیرہ) بھیجتی ہے، اور `Fn` دبائے رکھنے سے F1-F12 ملتے ہیں؛ `Fn + Esc` اسے الٹا کر کے لاک کر دیتا ہے جب تک آپ اسے دوبارہ نہ دبائیں۔ زیادہ تر کی بورڈز اس لاک کو خود یاد رکھتے ہیں۔ ASUS لیپ ٹاپس اور Apple طرز کے کی بورڈز یہ کام Linux پر چھوڑ دیتے ہیں، جو ہر بوٹ پر انہیں میڈیا کیز پر شروع کرتا ہے۔ اس کے بجائے انہیں F1-F12 پر شروع کرنے کے لیے `omarchy device keyboard toprow fnkeys` چلائیں (اور واپس جانے کے لیے `omarchy device keyboard toprow mediakeys`)؛ کچھ لیپ ٹاپس پر یہ دوبارہ بوٹ کے بعد اثر کرتا ہے۔ Apple Silicon Macs اپنی الگ ترتیب برقرار رکھتے ہیں۔

### ٹریک پیڈ اشارے

ڈیسک ٹاپ پر اِدھر اُدھر جانے کے لیے ٹریک پیڈ پر سوائپ کریں:

| اشارہ | عمل |
| --- | --- |
| تین انگلیاں بائیں / دائیں | پچھلا / اگلا ورک اسپیس، خالی ورک اسپیسز سمیت |
| تین انگلیاں اوپر | AI کنسول ٹوگل کریں |
| تین انگلیاں نیچے | Omarchy مینیو کھولیں |
| چار انگلیاں بائیں / دائیں | فعال ونڈو کو پچھلے / اگلے ورک اسپیس پر منتقل کریں |
| چار انگلیاں نیچے | فل اسکرین ٹوگل کریں |

کسی ایک کو تبدیل کرنے کے لیے، اپنا [ٹچ پیڈ اشارہ](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/) شامل کرنے سے پہلے اسے `~/.config/hypr/input.lua` میں غیر مقرر کر دیں، کیونکہ Hyprland ایک ہی انگلیوں اور ایک ہی سمت پر دو اشارے قبول نہیں کرے گا:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Omarchy کے تمام اشارے بند کرنے کے لیے، Omarchy کی طے شدہ ترتیبات لوڈ ہونے سے پہلے، `~/.config/hypr/hyprland.lua` کے بالائی حصے کے قریب `omarchy_default_gestures = false` مقرر کر دیں۔

ہیپٹک ٹچ پیڈ والے Dell XPS لیپ ٹاپس پر، آپ _ٹرگر > ہارڈویئر > ٹچ پیڈ ہیپٹکس_ میں کلک کی قوت کو کم، درمیانی یا زیادہ پر بھی مقرر کر سکتے ہیں۔

### چینی، جاپانی اور دیگر زبانوں میں ٹائپنگ

جب انسٹالر آپ سے آپ کے کی بورڈ کے بارے میں پوچھے تو جاپانی، کوریائی، چینی (آسان، Pinyin)، تائیوان (Zhuyin) یا ہانگ کانگ (Cangjie) منتخب کریں۔ Omarchy کی بورڈ اور اس سے میل کھاتا ان پٹ انجن خود بخود ترتیب دے دیتی ہے، بشمول آف لائن پہلے بوٹ کے سیٹ اپ کے دوران۔ جاپانی Mozc استعمال کرتی ہے، کوریائی معیاری دو سیٹوں والی Hangul استعمال کرتی ہے، آسان چینی Pinyin استعمال کرتی ہے، تائیوان Chewing کی معیاری Zhuyin ترتیب استعمال کرتا ہے، اور ہانگ کانگ ہانگ کانگ کے حروف کی شکلوں کے ساتھ Cangjie استعمال کرتا ہے۔ جاپانی (US کی بورڈ) US کی بورڈ لے آؤٹ کے ساتھ Mozc فراہم کرتی ہے۔ Hangul، Zhuyin اور Cangjie کی کیز اپنی معیاری جگہوں پر ہی رہتی ہیں، چاہے آپ Dvorak، Colemak یا AZERTY کے ساتھ لاطینی حروف ٹائپ کریں۔ اگر آپ نے اس سے پہلے Hangul یا Chewing شامل کیا تھا تو اس کی کیز وہاں منتقل کرنے کے لیے اسے _سیٹ اپ > کی بورڈ > ان پٹ میتھڈز_ میں غیر منتخب کر کے دوبارہ منتخب کریں؛ Omarchy اس انجن کو چھیڑتی نہیں جس سے آپ پہلے ہی ٹائپ کر رہے ہوں۔

ٹائپنگ لاطینی موڈ میں شروع ہوتی ہے۔ ترتیب شدہ ان پٹ میتھڈز کے درمیان چکر لگانے کے لیے `Super + I` دبائیں، اور واپس چکر لگانے کے لیے `Super + Shift + I` دبائیں۔ صرف `Shift` کو تھپتھپائیں تو آپ Pinyin جیسے ان پٹ میتھڈ سے باہر نکل کر لاطینی حروف میں آ جاتے ہیں، اور اسے دوبارہ تھپتھپانے سے واپس چلے جاتے ہیں، بالکل اسی طرح جیسے Sogou، Microsoft Pinyin اور macOS میں ہوتا ہے؛ `Shift` اور کوئی حرف مل کر اب بھی بڑا حرف ٹائپ کرتے ہیں۔ جاپانی کی بورڈز پر، 全角/半角 ان پٹ کو ٹوگل کرتا ہے، 変換 اسے آن کرتا ہے، اور 無変換 اسے آف کرتا ہے۔ کوریائی کے ساتھ، 한/영 Hangul کو سوئچ کرتا ہے اور 한자 Hanja میں تبدیل کرتا ہے، چاہے آپ کے کی بورڈ میں اس کے لیے مخصوص کیز ہوں یا وہ ان کے لیے Right Alt اور Right Ctrl بھیجتا ہو، جیسا کہ بہت سے لیپ ٹاپ کرتے ہیں، اس لیے وہاں Right Alt اور Right Ctrl سادہ موڈیفائر نہیں ہوتے؛ اس کے بجائے ڈکٹیشن Alt + Space سے ٹوگل ہوتی ہے۔ `Ctrl + Space` Tmux اور Herdr کے لیے دستیاب رہتا ہے؛ `Shift + CapsLock` کمپوز کی ہی رہتی ہے۔

جب آپ کے پاس متعدد کی بورڈ لے آؤٹس یا ان پٹ میتھڈز ہوں تو کی بورڈ انڈیکیٹر بار کے دائیں طرف ظاہر ہوتا ہے۔ ان پٹ زبانیں سوئچ کرنے کے لیے اس پر کلک کریں؛ جاپانی میں ہیراگانا کے لیے あ دکھایا جاتا ہے۔ جاپانی حروف کے انتخاب کے لیے جاپانی پر سوئچ کریں، کوئی لفظ جیسے `nihongo` ٹائپ کریں، پھر Space دو بار دبائیں۔ اپنا انتخاب قبول کرنے کے لیے Enter دبائیں۔ اگر آپ کے پاس متعدد کی بورڈ لے آؤٹس بھی ہیں تو ان کے درمیان چکر لگانے کے لیے انڈیکیٹر پر رائٹ کلک کریں۔

انگریزی اور فرانسیسی جیسے لے آؤٹس منتخب کرنے کے لیے _سیٹ اپ > کی بورڈ > کی بورڈ ان پٹس_ استعمال کریں، انسٹالیشن کے دوران پیش کیے گئے انہی انتخابوں میں سے۔ کون سے کمپوزیشن انجن فعال ہیں یہ منتخب کرنے کے لیے _سیٹ اپ > کی بورڈ > ان پٹ میتھڈز_ استعمال کریں۔ دونوں چنندے Omarchy مینیو کے اندر کھلتے ہیں اور آپ کے موجودہ انتخابوں پر نشان لگا ہوتا ہے۔ کسی انتخاب کو ٹوگل کرنے کے لیے کلک کریں یا Enter دبائیں؛ ہر تبدیلی فوری طور پر لاگو ہو جاتی ہے۔ کسی ان پٹ میتھڈ کو غیر منتخب کرنے سے وہ اسے انسٹال ختم کیے بغیر چکر سے نکل جاتا ہے؛ کی بورڈ دستیاب رہتا ہے۔

وہی چنندے کھولنے کے لیے `omarchy setup keyboard` یا `omarchy setup input` چلائیں۔ کمانڈ لائن سے ایک زبان شامل کرنے کے لیے `omarchy setup input mozc`، `hangul`، `pinyin`، `chewing` یا `cangjie5` استعمال کریں۔ Quick، Boshiamy اور Array Cangjie ہی کے پیکج میں آتے ہیں اور ان پٹ میتھڈز چنندے میں ظاہر ہوتے ہیں۔ آپ کی حسبِ منشا سوئچنگ کیز محفوظ رہتی ہیں۔ متبادل انجن لے آؤٹس یا کیز کے لیے، `omarchy pkg add fcitx5-configtool` کے ساتھ `fcitx5-configtool` انسٹال کریں اور اسے ٹرمینل سے لانچ کریں۔ ان پٹ زبان منتخب کرنے سے ڈیسک ٹاپ کی زبان تبدیل نہیں ہوتی۔ جب آپ کے پاس ابھی کوئی ان پٹ میتھڈ نہ ہو تو _سیٹ اپ > ریجن > زبان_ میں جاپانی، کوریائی یا چینی منتخب کرنے سے اس کا ان پٹ میتھڈ شامل ہو جاتا ہے۔

ان پٹ میتھڈز یا کی بورڈ لے آؤٹس کے درمیان چکر لگانے کے لیے `Super + I` استعمال کریں، اور دوسری طرف واپس جانے کے لیے `Super + Shift + I` استعمال کریں، اس لیے تین ترتیب شدہ ہونے پر آپ دو پڑوسیوں کے درمیان آ جا سکتے ہیں۔ ان پٹ انڈیکیٹر بار کے دائیں طرف صرف اسی وقت ظاہر ہوتا ہے جب ایک سے زیادہ ان پٹ میتھڈ یا لے آؤٹ ترتیب شدہ ہو۔ یہ ڈیسک ٹاپ بائنڈنگ آپ کی موجودہ Fcitx سوئچنگ کیز کے ساتھ ساتھ کام کرتی ہے؛ آپ اسے `~/.config/hypr/bindings.lua` میں اوور رائیڈ کر سکتے ہیں۔ ان پٹ انجن اور کمپوز تسلسل ہر سیشن میں پہلے سے چل رہی [Fcitx5](https://fcitx-im.org/) سروس استعمال کرتے ہیں۔

### ALT کو SUPER کے طور پر استعمال کریں

کچھ کی بورڈز پر، بنیادی میٹا کی (Windows/cmd کی) کو SUPER کے طور پر استعمال کرنا آسان نہیں ہوتا۔ آپ اس تبدیلی کے ذریعے اس کے بجائے ALT استعمال کر سکتے ہیں:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
