# کی بورڈ، ماؤس، ٹریک پیڈ

Hyprland آپ کو اپنے تمام ان پٹس کو بڑی تفصیل سے ترتیب دینے دیتا ہے۔ آپ کی بورڈ ریپیٹ کو سپرسانک حد تک تیز کر سکتے ہیں یا ٹریک پیڈ کو نیچرل اسکرولنگ استعمال کرنے پر لگا سکتے ہیں۔ آپ یہ سب کچھ `~/.config/hypr/input.lua` میں تبدیل کرتے ہیں، جہاں آپ Omarchy مینو (`Super + Space`) میں _سیٹ اپ > ان پٹ_ کے ذریعے بھی پہنچ سکتے ہیں۔ وہاں آپ جو کچھ بھی مقرر کریں گے وہ Omarchy کی ڈیفالٹس کی جگہ لے لے گا۔

یہاں ایک مثال ہے:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

آپ ان پٹس کے لیے Hyprland وکی پر [تمام ان پٹ آپشنز دیکھ سکتے ہیں](https://wiki.hypr.land/Configuring/Basics/Variables/#input)۔

CapsLock عام Caps Lock کے طور پر کام کرتا ہے، اور `Shift + CapsLock` [فوری ایموجیز](07-hotkeys.md#quick-emojis) اور [دیگر تکمیلات](07-hotkeys.md#quick-completions) کے لیے کموز کی ہے۔ اگر آپ کموز کی کو کہیں اور رکھنا چاہتے ہیں تو `kb_options` میں `omarchy:shift_caps_compose` کی جگہ لے دیں۔ مثال کے طور پر، اس سے کموز کی Right Alt پر منتقل ہو جاتی ہے:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### فنکشن کیز

لیپ ٹاپ کی بورڈ کی اوپر والی قطار بطور ڈیفالٹ میڈیا کیز (والیوم، برائٹنیس وغیرہ) بھیجتی ہے، اور `Fn` کو دبائے رکھنے سے F1-F12 ملتی ہیں؛ `Fn + Esc` اسے الٹا لاک کر دیتا ہے جب تک کہ آپ اسے دوبارہ نہ دبائیں۔ زیادہ تر کی بورڈز وہ لاک خود یاد رکھتے ہیں۔ ASUS لیپ ٹاپس اور Apple طرز کے کی بورڈز یہ معاملہ Linux پر چھوڑ دیتے ہیں، جو ہر بوٹ پر انہیں میڈیا کیز سے شروع کرتا ہے۔ اس کے بجائے انہیں F1-F12 سے شروع کرانے کے لیے `omarchy device keyboard toprow fnkeys` چلائیں (اور واپس جانے کے لیے `omarchy device keyboard toprow mediakeys`)؛ کچھ لیپ ٹاپس پر یہ ری بوٹ کے بعد اثر کرتا ہے۔ Apple Silicon Macs اپنی الگ ترتیب برقرار رکھتے ہیں۔

### ٹریک پیڈ جیسچرز

ڈیسک ٹاپ پر اِدھر اُدھر جانے کے لیے ٹریک پیڈ پر سوائپ کریں:

| اشارہ | عمل |
| --- | --- |
| تین انگلیاں بائیں / دائیں | پچھلا / اگلا ورک اسپیس، خالی ورک اسپیسز سمیت |
| تین انگلیاں اوپر | AI کنسول ٹوگل کریں |
| تین انگلیاں نیچے | Omarchy مینو کھولیں |
| چار انگلیاں بائیں / دائیں | فعال ونڈو کو پچھلے / اگلے ورک اسپیس پر منتقل کریں |
| چار انگلیاں نیچے | فل اسکرین ٹوگل کریں |

کسی ایک کو تبدیل کرنے کے لیے، اپنی خود کی [touchpad gesture](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/) شامل کرنے سے پہلے اسے `~/.config/hypr/input.lua` میں ان سیٹ کر دیں، کیونکہ Hyprland ایک ہی انگلیوں اور سمت پر دو جیسچرز قبول نہیں کرے گا:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Omarchy کے تمام جیسچرز بند کرنے کے لیے، Omarchy کی ڈیفالٹس لوڈ ہونے سے پہلے، `~/.config/hypr/hyprland.lua` کے بالائی حصے کے قریب `omarchy_default_gestures = false` مقرر کر دیں۔

ہیپٹک ٹچ پیڈ والے Dell XPS لیپ ٹاپس پر، آپ _ٹرگر > ہارڈ ویئر > ٹچ پیڈ ہیپٹکس_ کے تحت کلک کی قوت کو low، mid یا high پر بھی مقرر کر سکتے ہیں۔

### چینی، جاپانی اور دیگر زبانوں میں ٹائپنگ

جب انسٹالر آپ کے کی بورڈ کے بارے میں پوچھے تو جاپانی، کورین، چینی (آسان کردہ، Pinyin)، تائیوان (Zhuyin) یا ہانگ کانگ (Cangjie) منتخب کریں۔ Omarchy کی بورڈ اور مطابقت رکھنے والے ان پٹ انجن کو خودکار طور پر ترتیب دیتا ہے، بشمول آف لائن پہلے بوٹ کے سیٹ اپ کے دوران۔ جاپانی Mozc استعمال کرتی ہے، کورین معیاری دو سیٹ Hangul استعمال کرتی ہے، آسان کردہ چینی Pinyin استعمال کرتی ہے، تائیوان Chewing کی معیاری Zhuyin ترتیب استعمال کرتا ہے، اور ہانگ کانگ ہانگ کانگ کردار صورتوں کے ساتھ Cangjie استعمال کرتا ہے۔ جاپانی (US کی بورڈ) US کی بورڈ لے آؤٹ کے ساتھ Mozc فراہم کرتی ہے۔ Hangul، Zhuyin اور Cangjie کیز اپنی معیاری جگہوں پر ہی رہتی ہیں، چاہے آپ Dvorak، Colemak یا AZERTY کے ساتھ لاطینی حروف ٹائپ کریں۔ اگر آپ نے اس سے پہلے Hangul یا Chewing شامل کی تھی تو اس کی کیز وہاں منتقل کرنے کے لیے _سیٹ اپ > کی بورڈ > ان پٹ میتھڈز_ کے تحت اسے غیر منتخب کر کے دوبارہ منتخب کریں؛ Omarchy اس انجن کو ہاتھ نہیں لگاتا جس سے آپ پہلے ہی ٹائپ کر رہے ہوں۔

ٹائپنگ لاطینی موڈ میں شروع ہوتی ہے۔ ترتیب شدہ ان پٹ میتھڈز میں آگے بڑھنے کے لیے `Super + I` دبائیں، اور پیچھے کی طرف آنے کے لیے `Super + Shift + I` دبائیں۔ Pinyin جیسے ان پٹ میتھڈ سے باہر نکل کر لاطینی حروف میں جانے کے لیے `Shift` کو اکیلے تھپتھپائیں، اور واپس جانے کے لیے اسے دوبارہ تھپتھپائیں، بالکل اسی طرح جیسے Sogou، Microsoft Pinyin اور macOS کام کرتے ہیں؛ `Shift` جمع کوئی حرف اب بھی بڑا حرف ٹائپ کرتا ہے۔ جاپانی کی بورڈز پر، 全角/半角 ان پٹ کو ٹوگل کرتا ہے، 変換 اسے آن کرتا ہے، اور 無変換 اسے آف کرتا ہے۔ کورین کے ساتھ، 한/영 Hangul بدلتا ہے اور 한자 Hanja میں تبدیل کرتا ہے، چاہے آپ کے کی بورڈ میں مخصوص کیز ہوں یا وہ ان کے لیے Right Alt اور Right Ctrl بھیجتا ہو، جیسا کہ بہت سے لیپ ٹاپس کرتے ہیں، اس لیے وہاں Right Alt اور Right Ctrl سادہ موڈیفائرز نہیں ہیں؛ اس کے بجائے ڈکٹیشن Alt + Space سے ٹوگل ہوتی ہے۔ `Ctrl + Space` Tmux اور Herdr کے لیے دستیاب رہتا ہے؛ `Shift + CapsLock` کموز کی ہی رہتا ہے۔

جب آپ کے پاس متعدد کی بورڈ لے آؤٹس یا ان پٹ میتھڈز ہوں تو کی بورڈ انڈیکیٹر بار کے دائیں طرف ظاہر ہوتا ہے۔ ان پٹ زبانیں بدلنے کے لیے اس پر کلک کریں؛ جاپانی ہیراگانا کے لیے あ دکھاتی ہے۔ جاپانی کردار کے انتخاب کے لیے، جاپانی پر سوئچ کریں، کوئی لفظ جیسے `nihongo` ٹائپ کریں، پھر Space دو بار دبائیں۔ اپنا انتخاب قبول کرنے کے لیے Enter دبائیں۔ اگر آپ کے پاس متعدد کی بورڈ لے آؤٹس بھی ہوں تو ان میں آگے بڑھنے کے لیے انڈیکیٹر پر رائٹ کلک کریں۔

انگریزی اور فرانسیسی جیسے لے آؤٹس منتخب کرنے کے لیے _سیٹ اپ > کی بورڈ > کی بورڈ ان پٹس_ استعمال کریں، انہی انتخابوں میں سے جو انسٹالیشن کے دوران پیش کیے گئے تھے۔ کون سے کمپوزیشن انجن فعال ہیں یہ منتخب کرنے کے لیے _سیٹ اپ > کی بورڈ > ان پٹ میتھڈز_ استعمال کریں۔ دونوں پکرز Omarchy مینو کے اندر آپ کے موجودہ انتخابوں کو چیک شدہ دکھا کر کھلتے ہیں۔ کسی انتخاب کو ٹوگل کرنے کے لیے کلک کریں یا Enter دبائیں؛ ہر تبدیلی فوری طور پر نافذ ہوتی ہے۔ کسی ان پٹ میتھڈ کو غیر منتخب کرنے سے وہ اسے اَن انسٹال کیے بغیر سائیکل سے ہٹ جاتا ہے؛ کی بورڈ دستیاب رہتا ہے۔

یہی پکرز کھولنے کے لیے `omarchy setup keyboard` یا `omarchy setup input` چلائیں۔ کمانڈ لائن سے ایک زبان شامل کرنے کے لیے `omarchy setup input mozc`، `hangul`، `pinyin`، `chewing` یا `cangjie5` استعمال کریں۔ Quick، Boshiamy اور Array اسی پیکیج میں آتے ہیں جس میں Cangjie آتا ہے اور ان پٹ میتھڈز پکر میں ظاہر ہوتے ہیں۔ آپ کی حسب ضرورت سوئچنگ کیز محفوظ رہتی ہیں۔ متبادل انجن لے آؤٹس یا کیز کے لیے، `omarchy pkg add fcitx5-configtool` کے ساتھ `fcitx5-configtool` انسٹال کریں اور اسے ٹرمینل سے لانچ کریں۔ ان پٹ زبان منتخب کرنے سے ڈیسک ٹاپ کی زبان نہیں بدلتی۔ جب آپ کے پاس ابھی کوئی ان پٹ میتھڈ نہ ہو تو _سیٹ اپ > زبان_ کے تحت جاپانی، کورین یا چینی منتخب کرنے سے اس کا ان پٹ میتھڈ شامل ہو جاتا ہے۔

ان پٹ میتھڈز یا کی بورڈ لے آؤٹس میں آگے بڑھنے کے لیے `Super + I` استعمال کریں، اور دوسری سمت واپس جانے کے لیے `Super + Shift + I` استعمال کریں، تو تین ترتیب شدہ ہونے کی صورت میں آپ دو پڑوسیوں کے درمیان آ جا سکتے ہیں۔ ان پٹ انڈیکیٹر بار کے دائیں طرف صرف اسی وقت ظاہر ہوتا ہے جب ایک سے زیادہ ان پٹ میتھڈ یا لے آؤٹ ترتیب شدہ ہو۔ یہ ڈیسک ٹاپ بائنڈنگ آپ کی موجودہ Fcitx سوئچنگ کیز کے ساتھ ساتھ کام کرتی ہے؛ آپ اسے `~/.config/hypr/bindings.lua` میں اوور رائیڈ کر سکتے ہیں۔ ان پٹ انجن اور کموز سیکوینسز ہر سیشن میں پہلے سے چل رہی [Fcitx5](https://fcitx-im.org/) سروس استعمال کرتے ہیں۔

### ALT کو SUPER کے طور پر استعمال کریں

کچھ کی بورڈز پر، بنیادی میٹا کی (Windows/cmd کی) کو SUPER کے طور پر استعمال کرنا آسان نہیں ہوتا۔ آپ اس تبدیلی کے ذریعے اس کے بجائے ALT استعمال کرنے کے لیے اسے بدل سکتے ہیں:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
