# AI

Omarchy AI کوڈنگ ایجنٹس کو فرسٹ کلاس شہری سمجھتا ہے، لیکن یہ آپ کے لیے کوئی پسندیدہ منتخب نہیں کرتا۔ اس کے بجائے، ہر بڑا کوڈنگ ایجنٹ CLI لیزی لوڈ ہونے والے لانچر کے طور پر پہلے سے منسلک آتا ہے۔ یہ لانچرز `~/.local/bin/` میں [mise](https://mise.jdx.dev/) کے زیر انتظام چھوٹے اسٹبز ہیں، اس لیے جب تک آپ پہلی بار ان میں سے کوئی اصل میں چلائیں، کچھ بھی ڈاؤن لوڈ نہیں ہوتا۔ Hermes اس کی استثنائی صورت ہے: اس کے لیے کچھ بھی اسٹب نہیں کیا گیا، اور اسے منتخب کرنے سے Hermes Desktop انسٹال ہو جاتا ہے، جیسا کہ ذیل میں _Desktop apps_ بیان کرتا ہے۔ ان میں سے کسی کو بھی چلائیں اور جب کہا جائے تو تصدیق کریں:

| کمانڈ | ایجنٹ |
|------------|------------------------------------------------------------------|
| `claude` | [Claude Code](https://code.claude.com/docs/en/overview) |
| `codex` | [OpenAI Codex](https://github.com/openai/codex) |
| `opencode` | [OpenCode](https://opencode.ai/) |
| `agy` | [Google Antigravity CLI](https://github.com/google-antigravity/antigravity-cli) |
| `copilot` | [GitHub Copilot CLI](https://github.com/github/copilot-cli) |
| `crush` | [Crush](https://github.com/charmbracelet/crush) |
| `grok` | xAI کی جانب سے [Grok Build](https://x.ai/build) |
| `kimi` | [Kimi Code](https://www.kimi.com/code/docs/en/) |
| `pi` | [Mario Zechner کا Pi](https://github.com/badlogic/pi-mono) |
| `omp` | [Oh My Pi](https://github.com/can1357/oh-my-pi) |
| `ori` | [Ori](https://openrouter.ai/docs/guides/ori/harness)، OpenRouter کا ہارنس |
| `hermes` | [Hermes](https://hermes-agent.nousresearch.com/)، Nous Research کا ایجنٹ |
| `muse` | [Muse Code](https://dev.meta.ai)، Meta کا کوڈنگ ایجنٹ |
| `cursor-agent` | [Cursor CLI](https://cursor.com/cli) |

`ori` ان سب سے الگ ہے: یہ دوسرے ہارنسز کو OpenRouter کے پورے ماڈل کیٹلاگ کے خلاف چلاتا ہے، اس لیے `ori claude`، `ori codex`، یا `ori opencode` ان ایجنٹس کو جس ماڈل کی طرف بھی آپ اشارہ کریں اس پر شروع کرتے ہیں، اور `ori code` Ori کا اپنا ایجنٹ ہے۔

کسی اضافی CLI کو اسی طرح لپیٹنے کے لیے، `omarchy-mise-install <package> [command-name]` چلائیں۔ جب آپ `omarchy update` (یا `mup` عرف) چلاتے ہیں تو اسٹبز کو mise کے زیر انتظام ہر چیز کے ساتھ تازہ رکھا جاتا ہے۔

`grok` mise کے فرسٹ پارٹی `grok` پیکج کے ذریعے انسٹال ہوتا ہے، بالکل اسی طرح جیسے `claude` اور `codex`۔ `grok` چلائیں، یا اسے _Setup > Defaults > Agent_ کے تحت منتخب کریں۔ x.ai پر موجود `curl | bash` انسٹالر کو چھوڑ دیں۔ وہ راستہ `~/.grok/bin` میں دوسری کاپی ڈال دیتا ہے، اسے `PATH` پر پہلے لگا دیتا ہے، اور Omarchy کے ریپر کو اوور رائٹ کر دیتا ہے۔

### ڈیفالٹ ایجنٹ

اپنا ڈیفالٹ ایجنٹ `omarchy default agent <name>` کے ساتھ یا Omarchy Menu (`Super + Space`) میں _Setup > Defaults > Agent_ کے تحت منتخب کریں۔ اگر ایجنٹ ابھی انسٹال نہیں ہوا ہے، تو اسے منتخب کرنے سے وہ پہلے انسٹال ہو جاتا ہے۔ ایک تازہ Omarchy آپ کو ایک بار کی اطلاع کے ساتھ یہ انتخاب کرنے کی دعوت دے گا۔

Claude کو منتخب کرنے سے Chromium، Chrome، Brave، Brave Origin، اور Edge کے لیے اس کی براؤزر ایکسٹینشن ترتیب دینے کی بھی کوشش کی جاتی ہے۔ ایکسٹینشن کی ترتیب تمام صارفین پر لاگو ہوتی ہے اور آپ کا سسٹم پاس ورڈ مانگ سکتی ہے؛ منسوخ کرنے یا ایکسٹینشن انسٹال ناکام ہونے پر بھی Claude منتخب اور لانچ ہو جاتا ہے۔ اپنا براؤزر دوبارہ شروع کریں، اگر کہا جائے تو ایکسٹینشن فعال کریں، اور اسے منسلک کرنا مکمل کرنے کے لیے Claude میں سائن ان کریں۔ کنکشن جانچنے کے لیے Claude میں `/chrome` چلائیں۔ Firefox اور Zen اس ایکسٹینشن کو سپورٹ نہیں کرتے۔ اگر اس ترتیب کے شامل ہونے سے پہلے Claude پہلے ہی آپ کا ڈیفالٹ تھا، تو ایکسٹینشن انسٹال کرنے کے لیے اسے دوبارہ منتخب کریں۔

[Muse Code](https://dev.meta.ai) — Meta کا `muse` — دوسرے ایجنٹس کی طرح پہلے سے انسٹال شدہ mise اسٹب استعمال کرتا ہے۔ اسے ڈیفالٹ کے طور پر منتخب کرنے سے mise کے HTTP بیک اینڈ کے ذریعے Meta کا آفیشل لانچر انسٹال ہو جاتا ہے۔ یہ لانچر آپ کی مشین کے لیے نیٹو بائنری کی تصدیق اور اسے اپ ڈیٹ کرتا ہے۔

جب آپ منتخب کر لیں، تو `Super + Shift + Ctrl + A` ڈیفالٹ ایجنٹ کو ایک وقف شدہ ٹرمینل ونڈو میں لانچ کرتا ہے (یا اگر آپ نے ابھی منتخب نہیں کیا ہے تو پکر سامنے لاتا ہے)۔ آپ اسے `omarchy agent prompt "Review this project"` کے ساتھ سیدھا کسی کام میں بھی لانچ کر سکتے ہیں۔ اس طرح لانچ کیے गए ایجنٹس اپنے متعلقہ رک کر پوچھنے سے گریز والے موڈز میں بغیر نگرانی کے چلتے ہیں، اس لیے ان کے اصل میں کچھ کرنے کے لیے تیار رہیں! اور چونکہ ایجنٹس آپ کی ہوم ڈائریکٹری کے لیے اعتماد یاد رکھنے سے انکار کرتے ہیں، اس لیے `$HOME` سے لانچ اس کے بجائے `~/Work` میں شروع ہوتے ہیں۔

ٹرمینل شارٹ کٹس بھی ہیں: `a` موجودہ ٹرمینل میں ڈیفالٹ ایجنٹ کو ان لائن چلاتا ہے، جبکہ `c`، `cx`، اور `cy` OpenCode، Claude Code، اور Codex کو براہ راست شروع کرتے ہیں (ایک بار پھر ان کے خودکار منظوری والے موڈز میں)۔ تھیم کی تبدیلیاں ایجنٹس کے ساتھ بھی ہم آہنگ ہوتی ہیں: Claude Code، Pi، OpenCode، اور Hermes (جب Omarchy اسے انسٹال کر لے) سب اس وقت ساتھ چلتے ہیں جب آپ Omarchy تھیم تبدیل کرتے ہیں۔

### ایجنٹس پینل

اوپر والی بار میں ایک ایجنٹس آئیکن ہے۔ اس سے پہلے کہ آپ نے کوئی ایجنٹ ترتیب دیا ہو، اس کا پینل آپ کو Claude، Codex، یا Grok میں سائن ان کرنے کے مراحل سے گزارتا ہے، اور پہلا آپ کا ڈیفالٹ ایجنٹ بن جاتا ہے۔ اس کے بعد، پینل ہر سبسکرپشن کو ایک صفحے پر رکھ دیتا ہے: ہر ایجنٹ اور اکاؤنٹ اس کے پلان کے ساتھ، اس کی 5 گھنٹے کی سیشن اور ہفتہ وار حدود میں سے ہر ایک کے لیے ایک میٹر جس کے ساتھ اس کے ری سیٹ ہونے تک کا وقت ہو (درست فیصد کے لیے ہوور کریں)، یا باقی پری پیڈ بیلنس، ایک لائن کے نیچے جو ان سب میں آپ کے استعمال کی گئی چیزوں میں گھومتی ہے، جیسے اس ہفتے کے ٹوکنز اور آپ کا سب سے زیادہ استعمال شدہ ماڈل۔ _Make something_ کے تحت یہ نئی تھیم، پلگ ان، یا ایپ کے لیے ابتدائی پرامپٹس پیش کرتا ہے جو کام آپ کے ڈیفالٹ ایجنٹ کے حوالے کرتے ہیں۔ ایپس اسی طرح بنائی جاتی ہیں جس طرح Omarchy کی اپنی Hype، Monologue، اور Omacut ہیں، C++ اور Qt Quick میں، omarchy-app ایجنٹ اسکل کی پیروی کرتے ہوئے، اور انہیں درکار کمپائلر اور Qt کے اجزاء انسٹال شدہ آتے ہیں۔ Claude Code، Codex، Grok، Fireworks، اور Kimi باکس سے باہر ہی شامل ہیں۔ Kimi فی الحال مقامی ٹوکن یا پرامپٹ کے اعداد و شمار کے بغیر اکاؤنٹ کوٹا حدود کی اطلاع دیتا ہے۔

پینل کے لیے بار آئیکن پر بائیں کلک کریں، اپنے ڈیفالٹ ایجنٹ کو لانچ کرنے کے لیے دائیں کلک کریں۔ اس کے پیچھے استعمال کے ریکارڈز ہر 15 منٹ میں `omarchy agent usage-update` کے ذریعے دوبارہ تیار کیے جاتے ہیں، اور پینل ایک ہم آہنگ فولڈر کے ذریعے آپ کی دوسری مشینوں سے استعمال کو ضم بھی کر سکتا ہے۔ مکمل ترتیبات کے لیے `$OMARCHY_PATH/shell/plugins/agents/` کے تحت README دیکھیں۔

### کئی سبسکرپشنز

اگر آپ ایک سے زیادہ Claude، Codex، یا Grok پلان کے لیے ادائیگی کرتے ہیں — مثال کے طور پر ایک ذاتی Max اور ایک کام کا — تو Omarchy ان سب کو سائن ان رکھ سکتا ہے اور ان کے درمیان منتقل ہو سکتا ہے۔ ایجنٹس پینل میں + کے ساتھ سبسکرپشن شامل کریں، جو آپ کو وہیں اس کے مراحل سے گزارتا ہے، یا `omarchy agent account add claude Work` (یا `codex`، یا `grok`) کے ساتھ۔ اگر CLI غائب ہے تو یہ اسے انسٹال کر دیتا ہے۔ کسی پرووائیڈر کے لیے پہلا اکاؤنٹ آپ کے عام براؤزر کے ذریعے سائن ان ہوتا ہے، بالکل وہیں جہاں CLI ہمیشہ دیکھتا ہے۔ اس کے بعد ہر ایک پرائیویٹ ونڈو کے ذریعے سائن ان ہوتا ہے، تاکہ آپ کا براؤزر جس اکاؤنٹ میں پہلے سے سائن ان ہے وہ غلطی سے نہ منتخب ہو جائے؛ وہاں اس اکاؤنٹ کے طور پر سائن ان کریں جسے آپ شامل کر رہے ہیں، اور پہلے سے کھلی ہوئی کوئی بھی پرائیویٹ ونڈو پہلے بند کر دیں۔ اس کے لیے کبھی بھی CLI سے لاگ آؤٹ نہ کریں: لاگ آؤٹ کرنے سے محفوظ شدہ سائن ان منسوخ ہو جاتا ہے، اور اس اکاؤنٹ کو دوبارہ شامل کرنا پڑے گا۔

SSH پر اپنی سبسکرپشن لاگ انز کو دوسری Omarchy مشین پر کاپی کرنے کے لیے، `omarchy agent account copy user@laptop` چلائیں۔ جب منزل پر کوئی انسٹال نہ ہو تو بھیجنے والا ایک عارضی وصول کنندہ فراہم کرتا ہے، اس لیے پرانی Omarchy مشینیں اپ ڈیٹ کے بغیر اکاؤنٹس وصول کر سکتی ہیں۔ انسٹال شدہ وصول کنندگان کو ترجیح ملتی ہے۔ یہ تمام Claude، Codex، اور Grok سبسکرپشنز کاپی کرتا ہے؛ انہیں منتخب کرنے کے لیے پرووائیڈر کے نام شامل کریں، جیسے `omarchy agent account copy laptop claude` میں۔ اکاؤنٹ کے نام اور کمانڈ IDs ماخذ سے ملتے ہیں، بشمول منزل پر پہلے سے موجود اکاؤنٹس کے۔ غیر متعلقہ منزل اکاؤنٹس کو عددی لاحقہ ملتا ہے اگر ان کے ناموں میں تصادم ہو، اور ترتیبات، اسکلز، پلگ انز، اور گفتگو کی تاریخ ہر مشین کے لیے مقامی رہتی ہے۔

موجودہ منزل کی اسناد برقرار رکھی جاتی ہیں۔ وہ ماخذ اکاؤنٹ جو وہاں پہلے سے سائن ان ہے اس کے نام کو اس کی اسناد بدلے بغیر ہم آہنگ کیا جاتا ہے؛ دوسرے اکاؤنٹس اس کے ساتھ شامل کیے جاتے ہیں۔ مماثل اکاؤنٹس کے لیے محفوظ شدہ اسناد بدلنے کے لیے، منزل پر اس اکاؤنٹ کے سیشنز بند کرنے کے بعد `omarchy agent account copy --replace laptop claude` استعمال کریں۔ ایک تازہ منزل کو ماخذ کا فعال اکاؤنٹ اور سوئچنگ ترجیحات بھی ملتی ہیں؛ ایک قائم شدہ منزل اپنی ترجیحات برقرار رکھتی ہے۔

اسناد SSH کے ذریعے سفر کرتی ہیں اور منزل پر نجی فائلوں میں محفوظ ہوتی ہیں، اس لیے صرف ان مشینوں پر کاپی کریں جن پر آپ کو اعتماد ہے۔ یہ ایک بار کی کاپی ہے، جاری ہم آہنگی نہیں۔ Codex ریفریش ٹوکنز کو دوسری مشین گھما سکتی ہے، جس سے کاپی شدہ لاگ ان کو تجدید کی ضرورت پڑ جاتی ہے؛ کئی مشینوں پر ایک ساتھ استعمال کے لیے الگ سائن انز سب سے قابل اعتماد انتخاب رہتے ہیں۔ [Codex کی اکاؤنٹ تصدیق کی رہنمائی](https://developers.openai.com/codex/auth/ci-cd-auth) دیکھیں۔

فی پرووائیڈر ایک اکاؤنٹ فعال ہوتا ہے، اور ہر نیا سیشن اسی کے طور پر شروع ہوتا ہے: `cx`، `cy`، ایک سادہ `claude`، `codex`، یا `grok`، `omarchy agent` کے ذریعے لانچ کی گئی کوئی بھی چیز، اور اسکرپٹس یا ایڈیٹرز جو CLI کو `PATH` پر تلاش کرتے ہیں۔ `omarchy agent account use work` کے ساتھ تبدیل کریں (اور `omarchy agent account use main` کے ساتھ واپس)، یا پینل میں اکاؤنٹ کا نمبر دبا کر پھر `Enter` دبا کر (یا اس کے Use بٹن پر کلک کر کے)۔ پہلے سے چل رہے سیشنز اسی اکاؤنٹ پر رہتے ہیں جس کے ساتھ وہ شروع ہوئے تھے۔ گفتگو کی تاریخ، ترتیبات، اسکلز، اور پلگ انز اکاؤنٹس میں مشترکہ ہوتی ہیں، اس لیے اسی فولڈر میں `claude --continue` نئے اکاؤنٹ پر وہیں سے شروع کرتا ہے جہاں آپ نے چھوڑا تھا۔

ایک سے زیادہ اکاؤنٹ کے ساتھ، پینل ہر اکاؤنٹ کی حدود ساتھ ساتھ دکھاتا ہے، جس میں فعال اکاؤنٹ نمایاں ہوتا ہے۔ ڈیفالٹ طور پر Omarchy آپ کو مطلع کرتا ہے جب فعال اکاؤنٹ کسی حد کے 95% سے گزر جاتا ہے، اور اطلاع پر کلک کرنے سے سب سے زیادہ گنجائش والے اکاؤنٹ پر تبدیل ہو جاتا ہے۔ پینل میں اکاؤنٹ کی لائن پر ہوور کریں اور Use کے ساتھ ظاہر ہونے والے Autoswitch پر کلک کریں (یا `m` دبائیں)، یا `omarchy agent account mode auto` چلائیں، تاکہ اس کے بجائے یہ خود تبدیل ہو جائے؛ جب یہ آن ہو، تو Autoswitch Use کی جگہ لے لیتا ہے، اور اس پر دوبارہ کلک کرنے سے اطلاع دینے کی طرف واپس چلا جاتا ہے۔ حد تبدیل کرنے کے لیے نمبر شامل کریں، جیسے `omarchy agent account mode auto 90` میں۔ اگر ہر اکاؤنٹ حد سے اوپر ہے، تو آپ کو اس کے بارے میں ایک بار سنا جائے گا، اس کے ساتھ کہ کون سا اکاؤنٹ سب سے پہلے آزاد ہوتا ہے۔ جب کہ ایک فعال اکاؤنٹ اپنی حد کے 15 پوائنٹس کے اندر ہو (ڈیفالٹ پر 80%)، اس کی حدود ہر 15 کے بجائے ہر تین منٹ میں جانچی جاتی ہیں۔

`omarchy agent account list` ہر اکاؤنٹ اور اس کی تازہ ترین حدود دکھاتا ہے، `omarchy agent account remove work` ایک کو بھول جاتا ہے، اور `omarchy agent account rename primary Hey` ایک کا نام بدل دیتا ہے (یا پینل میں اکاؤنٹ کے نام پر کلک کریں)۔ یہ کمانڈز آپ کے ڈیفالٹ ایجنٹ کے اکاؤنٹس پر کام کرتی ہیں؛ دوسرے پرووائیڈر تک پہنچنے کے لیے، پہلے اس کا نام لیں، جیسے `omarchy agent account use codex side` میں۔ وہ لاگ ان جو آپ کے پاس `~/.claude` یا `~/.codex` میں پہلے سے تھا وہ _Main_ اکاؤنٹ ہے اور وہیں رہتا ہے جہاں ہے۔ تقریباً آٹھ گھنٹے سے زیادہ غیر استعمال شدہ اکاؤنٹ _Sign-in required_ دکھا سکتا ہے؛ اس اکاؤنٹ کو پینل میں ہی دوبارہ سائن ان کرنے کے لیے اس پر کلک کریں، یا اس میں سیشن شروع کریں، جو خود ہی سائن ان کو تازہ کر دیتا ہے۔ جب اکاؤنٹ شامل کیا گیا تھا اس وقت آپ کے پاس موجود MCP سرورز اس کے ساتھ آتے ہیں، لیکن جنہیں آپ بعد میں `claude mcp add` کے ساتھ شامل کرتے ہیں وہ صرف اسی اکاؤنٹ تک پہنچتے ہیں جس میں آپ نے انہیں شامل کیا تھا۔ Claude Desktop اور CLI بائنری کے مطلق راستے کے ساتھ تشکیل شدہ ٹولز اس تبدیلی کی پیروی نہیں کرتے۔ ایک واضح `CLAUDE_CONFIG_DIR`، `CODEX_HOME`، یا `GROK_HOME` منتخب اکاؤنٹ پر ترجیح لیتا ہے۔

### کریش کی تشخیص

Omarchy عمل کے کریشز کے لیے systemd-coredump کو دیکھتا ہے۔ جب کچھ segfault ہوتا ہے، تو آپ کو "Process crashed" اطلاع ملے گی — اس پر کلک کریں، اور کریش آپ کے ڈیفالٹ ایجنٹ کے حوالے کر دیا جاتا ہے Omarchy کی diagnose-crash اسکل کے ساتھ، جو ایجنٹ کو کور ڈمپ سے حقائق قائم کرنے اور یہ فیصلہ کرنے کے مراحل سے گزارتی ہے کہ آیا کریش اپ اسٹریم رپورٹ کرنے کے قابل ہے۔ آپ اسے `coredumpctl list` سے کسی بھی PID کے خلاف `omarchy agent crash <pid>` کے ساتھ ہاتھ سے بھی چلا سکتے ہیں۔

یہ نگرانی ڈیفالٹ طور پر آن ہوتی ہے۔ اسے _Trigger > Toggle > Crash Capture_ کے تحت (یا `omarchy toggle crash-capture` کے ساتھ) بند کر دیں اور اطلاعات رک جاتی ہیں؛ `omarchy agent crash <pid>` پھر بھی ہاتھ سے کام کرتا ہے۔

کریشز کو ایک وقت میں ایک پروگرام کے لیے بھی خاموش کیا جا سکتا ہے، جو تشخیص آخر میں آپ کو پیش کرتی ہے۔ `omarchy crash mute hyprland` صرف اس پروگرام کے لیے اطلاعات روک دیتا ہے، `omarchy crash mute hyprland off` انہیں واپس لاتا ہے، اور `omarchy crash mute` اکیلے اس کی فہرست دیتا ہے جو آپ نے خاموش کیا ہے۔ یہ بائنری کا راستہ اس کے نام کی طرح خوشی سے لیتا ہے، اس لیے `omarchy crash mute /usr/bin/hyprland` بھی وہی کام کرتا ہے۔ جس نام میں خالی جگہ ہو اسے اقتباس میں رکھیں، جیسے `omarchy crash mute 'Some App'` میں۔ باقی سب کچھ پھر بھی مطلع کرتا ہے، اور خاموش کیا گیا پروگرام پھر بھی کریش ہوتا ہے — یہ یاد دہانی کو چھپاتا ہے، یہ کچھ بھی ٹھیک نہیں کرتا۔

### ڈیسک ٹاپ ایپس

_Install > AI_ مینو میں چند گرافیکل AI ایپس بھی ہیں: ChatGPT ڈیسک ٹاپ ایپ، Claude ڈیسک ٹاپ ایپ (Anthropic کا Linux بیٹا، Chat، Cowork، اور Claude Code ٹیبز کے ساتھ)، xAI کے ماڈلز کے ساتھ بات چیت کے لیے Grok Bot، Hermes Desktop، OpenClaw، اور Perplexity ڈیسک ٹاپ ایپ۔ Grok Bot ڈیسک ٹاپ چیٹ ایپ ہے۔ کوڈنگ ایجنٹ `grok` کمانڈ ہے۔

Hermes Desktop وہ ہے جس کے بارے میں جاننا ضروری ہے، کیونکہ ایک مشین میں ایک Hermes ہوتا ہے، اور وہ ایپ کا ہوتا ہے: Hermes صرف ایپ کے ذریعے ہی انسٹال ہوتا ہے، اور ڈیفالٹ ایجنٹ جو `hermes` کمانڈ چلاتا ہے وہ ایپ کی ہے۔ Hermes کو ڈیفالٹ ایجنٹ کے طور پر منتخب کرنے سے وہی چیز انسٹال ہوتی ہے جو _Install > AI_ اندراج کرتا ہے: پیکج، اور `~/.hermes` کے تحت ایک Hermes رن ٹائم جو Hermes کے اپنے انسٹالر کے ذریعے ترتیب دیا گیا ہو، جس میں پہلی بار چند منٹ لگتے ہیں۔ وہ رن ٹائم وہ واحد Hermes ہے جسے ٹرمینل `hermes` کمانڈ، ڈیفالٹ ایجنٹ اور ایپ سب استعمال کرتے ہیں، اور یہ Omarchy ریلیز کا انتظار کرنے کے بجائے `hermes update` کے ساتھ خود کو اپ ڈیٹ کرتا ہے۔ اسے انسٹال کرنے سے Hermes کو Omarchy تھیم بھی `omarchy` نامی اسکن کے طور پر مل جاتی ہے، جس کی پیروی ہر Hermes سطح کرتی ہے جب آپ تھیمز تبدیل کرتے ہیں؛ اگر آپ چاہتے ہیں کہ ایسا نہ ہو تو Hermes کی Appearance ترتیبات کے تحت یا `/skin` کے ساتھ کوئی اور منتخب کریں، اور Omarchy اس انتخاب کو چھوڑ دیتا ہے۔ _Remove > AI_ کے تحت ایپ کو ہٹانے سے پہلے Hermes بند ہو جاتا ہے، گیٹ وے سمیت، وہ رن ٹائم بھی اس کے ساتھ چلا جاتا ہے، اور آپ کی چیٹس، یادیں، اور وہ اسکلز جو Hermes نے اپنے لیے لکھی تھیں برقرار رہتی ہیں جب تک کہ آپ اسے دوسری صورت میں نہ کہیں: یہ پوچھता ہے، ڈیفالٹ طور پر نہیں، کہ آیا وہ ڈیٹا اور آپ کی کنکشن ترتیبات بھی جانی چاہئیں۔

OpenClaw کا ڈیسک ٹاپ تجربہ اس کا Control UI ہے، جو اس کے اپنے مقامی گیٹ وے کی پشت پناہی سے ویب ایپ کے طور پر کھلتا ہے۔ OpenClaw `~/.openclaw` میں رہتا ہے اور خود کو اپ ڈیٹ کرتا ہے: Control UI کا "Update Gateway" بٹن استعمال کریں یا `openclaw update` چلائیں، اور گیٹ وے نئے ورژن پر دوبارہ شروع ہو جاتا ہے۔ Omarchy صرف اس ریلیز کا انتخاب کرتا ہے جس سے تازہ انسٹال شروع ہوتا ہے۔ _Remove > AI_ کے تحت OpenClaw کو ہٹانے سے گیٹ وے سروس اور ایپ اس کے ساتھ چلی جاتی ہے اور پھر پوچھا جاتا ہے کہ آیا `~/.openclaw` بھی جانا چاہیے، کیونکہ اس میں OpenClaw خود اور اس کے ڈاؤن لوڈ کردہ پلگ ان رن ٹائمز کے ساتھ آپ کی چیٹس اور اسناد بھی ہوتی ہیں؛ ڈیفالٹ اسے برقرار رکھتا ہے، اور OpenClaw کو دوبارہ انسٹال کرنے سے یہ اسے دوبارہ اٹھا لیتا ہے۔

### مقامی LLMs

Omarchy مقامی LLM ماڈلز چلانے کے دو طریقے تجویز کرتا ہے: LM Studio اور Ollama۔ LM Studio اوپن ویٹ ماڈلز تلاش کرنے، انہیں انسٹال کرنے، اور انہیں چلانے کے لیے GUI انٹرفیس فراہم کرتا ہے۔ آسانی سے شروع کرنے کا یہ ایک بہترین طریقہ ہے۔ Ollama اسی طرح کرنے کے لیے CLI پیش کرتا ہے۔ لیکن اگر آپ مقامی ماڈلز میں نئے ہیں، تو میں LM Studio سے شروع کروں گا۔ آپ Omarchy Menu میں _Install > AI_ کے تحت کسی کو بھی انسٹال کر سکتے ہیں۔

### Omarchy اسکل

ایجنٹ اسکلز AI کو مخصوص طریقے سے مخصوص ٹولز استعمال کرنے میں مدد کرتی ہیں، اور Omarchy سسٹم کو موزوں بنانے کے لیے ڈیفالٹ اسکل کے ساتھ آتا ہے۔ جیسے اپنی Hyprland کنفگ کو ٹھیک کرنا، بار کو ایڈجسٹ کرنا، یا یہاں تک کہ شروع سے نئی تھیم بنانا۔ یہ Claude Code (`~/.claude/skills`)، Codex (`~/.codex/skills`)، Pi (`~/.pi/agent/skills`)، Antigravity (`~/.gemini/config/skills`)، Hermes (`~/.hermes/skills` اور ہر `~/.hermes/profiles/*/skills`)، اور عام `~/.agents/skills` مقام کے لیے اسکل ڈائریکٹریوں میں سم لنک شدہ ہے، اس لیے زیادہ تر ہارنسز اسے خودکار طور پر اٹھا لیتے ہیں۔

لیکن آپ کو اس اسکل کو تجرباتی سمجھنا چاہیے۔ مختلف ماڈلز اسے مختلف اثر کے ساتھ استعمال کریں گے۔ بہتر ہے کہ پہلے پلان موڈ میں چلائیں، تاکہ آپ کو اندازہ ہو کہ ایجنٹ کیا تبدیل کرنا چاہے گا۔ اور پھر تبدیلیاں واپس کرنے یا یہاں تک کہ `omarchy reinstall configs` چلانے کے لیے تیار رہیں، اگر ایجنٹ ہر چیز کا گڑبڑ کر دے۔
