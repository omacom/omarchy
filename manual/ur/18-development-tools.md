# ڈویلپمنٹ ٹولز

## متبادل ایڈیٹرز

Omarchy بطور ڈیفالٹ [Neovim](https://neovim.io/) کے ساتھ آتا ہے، لیکن اگر آپ کو کچھ زیادہ روایتی اور مانوس چاہیے تو آپ Omarchy مینو (`Super + Space`) چلا کر _انسٹال کریں > ایڈیٹر_ کے تحت اختیارات دیکھ سکتے ہیں۔ وہاں ہمارے پاس VSCode، Cursor، Zed، Sublime Text، Helix، Vim اور Emacs درج ہیں۔ اگر آپ کو جو مطلوب ہے وہ نہ ملے تو _انسٹال کریں > پیکیج_ دیکھیں، اور دیکھیں کہ کیا وہ کسی Arch پیکیج میں موجود نہیں ہے (اور اگر نہ ملے تو AUR جانچنے کے لیے _انسٹال کریں > AUR_ آزمائیں)۔

اصل `vi` ایڈیٹر بھی ڈبے سے نکلتے ہی دستیاب ہے۔ ٹرمینل میں فائل میں ترمیم کرنے کے لیے `vi filename` چلائیں۔

`VSCode`، `Cursor`، `VSCodium` اور `Helix` کے لیے تھیم مطابقت پیش کی जाती ہے۔

آپ `سیٹ اپ > ڈیفالٹس > ایڈیٹر` کے تحت سسٹم گیر ڈیفالٹ ایڈیٹر مقرر کر سکتے ہیں۔

## ماحول

Omarchy، Omarchy مینو (`Super + Space`) کے _انسٹال کریں > ڈویلپمنٹ_ حصے کے ذریعے ڈویلپمنٹ ماحول کی ایک پوری فہرست ترتیب دینے کی سہولت دیتا ہے۔ ظاہر ہے آپ کو _Ruby on Rails_ ملے گا، لیکن اس کے ساتھ JavaScript کے تینوں بڑے رن ٹائم (Node.js، Bun، Deno)، نیز Laravel اور Symfony جیسے مقبول PHP فریم ورک بھی ملیں گے۔ اور ہاں، Go، Rust، Python، Java، Elixir (Phoenix کے ساتھ)، .NET، OCaml، Zig، Clojure اور Scala بھی موجود ہیں۔ یہ انتخاب بہت وسیع ہے!

ان میں سے زیادہ تر ماحول [Mise](https://mise.jdx.dev/) کے ذریعے زیر انتظام ہیں۔ یہ ایک ایسا ٹول ہے جو آپ کو ایک ہی مشین پر کسی پروگرامنگ زبان کے متعدد ورژن انسٹال اور چلانے دیتا ہے۔ یہ Ruby کے لیے rbenv یا rvm یا Python کے لیے virtualenv جیسا ہے، لیکن یہ کئی مختلف ماحول کے لیے کام کرتا ہے۔

مثلاً Ruby انسٹال کرنے کے لیے آپ `mise use -g ruby` چلائیں گے، جو Ruby انسٹال بھی کرے گا اور اسے عالمی ڈیفالٹ کے طور پر مقرر بھی کر دے گا۔ یا اگر آپ کے پروجیکٹ میں .ruby-version فائل ہو تو آپ بس اس پروجیکٹ کی جڑ میں `mise i` چلا سکتے ہیں۔

## Docker

[Docker](https://www.docker.com/) کو شاید ہی کسی تعارف کی ضرورت ہو۔ یہ آپ کو الگ تھلگ کنٹینرز چلانے دیتا ہے، اور Omarchy اسے اچھی طرح چلانے کے لیے درکار ہر چیز انسٹال کرتا ہے، جس میں خود Docker اور [Docker Compose](https://docs.docker.com/compose/) بھی شامل ہے۔

بطور ڈیفالٹ آپ کا صارف `docker` گروپ میں *نहीं* ہوتا۔ یہ گروپ درحقیقت پاس ورڈ کے بغیر root کے برابر ہے — اس میں موجود کوئی بھی چیز `docker run -v /:/host` چلا کر مشین پر قبضہ کر سکتی ہے — لہٰذا آپ کے طور پر چلنے والا کوئی ایک بے ضابطہ اسکرپٹ یا ڈیپنڈنسی بصورت دیگر root سے محض ایک کمانڈ کی دوری پر ہوگا۔ اس لیے کمانڈ لائن پر آپ Docker کو `sudo` کے ساتھ چلاتے ہیں (`sudo docker ps`، `sudo docker compose up`)، اور جو گرافیکل ٹولز ڈیمن سے بات کرتے ہیں — Windows VM — وہ ضرورت پڑنے پر اجازت طلب کرتے ہیں۔ اگر آپ کو گروپ سے خالی سیٹ اپ کی سہولت دوبارہ چاہیے اور آپ اس سودے کو سمجھتے ہیں تو اسے **سیٹ اپ > سیکیورٹی > Sudoless Docker** سے فعال کریں (یا `omarchy-setup-security-sudoless-docker` چلائیں)، جو انتباہ کے بعد آپ کو `docker` گروپ میں شامل کر देता ہے؛ اس کے بعد سادہ `docker` اور `d` عرف دوبارہ `sudo` کے بغیر کام کریں گے۔

آپ Omarchy مینو میں _انسٹال کریں > ڈویلپمنٹ > Docker DB_ استعمال کر کے مقامی ڈویلپمنٹ کے لیے عام ڈیٹا بیسز Docker میں ترتیب दे سکتے ہیں۔

## GitHub CLI

[GitHub CLI](https://cli.github.com/) آپ کو اپنے GitHub اکاؤنٹ سے توثیق کرنے اور اس کا استعمال کر کے نجی ریپازٹریز کلون کرنے देता है۔ یہ سست لوڈ ہونے والے mise اسٹبس میں سے ایک کے طور پر جڑا ہوا ہے، لہٰذا پہلی बार جب آپ `gh` چلائیں گے تو یہ خود کو انسٹال کر لے گا۔ توثیق کرنے کے لیے `gh auth login` چلائیں۔ اس کے بعد آپ `gh repo clone org/repo` استعمال کر کے نجی ریپازٹریز چیک آؤٹ کر سکتے ہیں۔

آپ اس کمانڈ کے ذریعے بہت سے دیگر GitHub اعمال بھی انجام दे سکتے ہیں۔ جو کچھ ممکن ہے وہ سب دیکھنے کے لیے بس `gh` چلائیں۔

TUI میں اپنی پل درخواستوں کے انتظام کے لیے `ghui` کے لیے بھی ایک سست انسٹال ہونے والا اسٹب موجود ہے۔ اور [lazygit](https://github.com/jesseduffield/lazygit) پہلے سے انسٹال ہے، اگر آپ git کو بھی TUI سے چلانا چاہیں۔
