# ڈیولپمنٹ ٹولز

## متبادل ایڈیٹرز

Omarchy بطور ڈیفالٹ [Neovim](https://neovim.io/) کے ساتھ آتا ہے، لیکن اگر آپ کو کچھ زیادہ مین اسٹریم اور مانوس چاہیے تو آپ Omarchy Menu (`Super + Space`) چلا کر _Install > Editor_ کے تحت آپشنز دیکھ سکتے ہیں۔ وہاں ہمارے پاس VSCode، Cursor، Zed، Sublime Text، Helix، Vim، اور Emacs درج ہیں۔ اگر آپ کو وہ نہیں ملتا جس کی آپ تلاش کر رہے ہیں تو _Install > Package_ دیکھیں، اور دیکھیں کہ آیا وہ کسی Arch پیکیج میں نہیں ہے (اور اگر نہیں ہے تو AUR چیک کرنے کے لیے _Install > AUR_ آزمائیں)۔

اصل `vi` ایڈیٹر بھی شروع سے دستیاب ہے۔ ٹرمینل میں کسی فائل میں ترمیم کرنے کے لیے `vi filename` چلائیں۔

`VSCode`، `Cursor`، `VSCodium`، اور `Helix` کے لیے تھیم میچنگ کی سہولت پیش کی جاتی ہے۔

آپ `Setup > Defaults > Editor` کے تحت پورے سسٹم کے لیے ڈیفالٹ ایڈیٹر مقرر کر سکتے ہیں۔

## ماحول

Omarchy، Omarchy Menu (`Super + Space`) کے _Install > Development_ سیکشن کے ذریعے ڈیولپمنٹ ماحول کی پوری ایک میزبانی سیٹ اپ کرنے کی حمایت کرتا ہے۔ آپ کو یقیناً _Ruby on Rails_ ملے گا، لیکن JavaScript کے تینوں بڑے رن ٹائمز (Node.js، Bun، Deno) بھی ملیں گے، نیز Laravel اور Symfony جیسے مقبول PHP فریم ورکس بھی۔ اوہ، اور Go، Rust، Python، Java، Elixir (بمع Phoenix)، .NET، OCaml، Zig، Clojure، اور Scala بھی ہیں۔ یہ بہت وسیع انتخاب ہے!

ان میں سے بیشتر ماحول [Mise](https://mise.jdx.dev/) کے ذریعے منظم کیے جاتے ہیں۔ یہ ایک ایسا ٹول ہے جو آپ کو ایک ہی مشین پر کسی پروگرامنگ زبان کے متعدد ورژن انسٹال اور چلانے دیتا ہے۔ یہ Ruby کے لیے rbenv یا rvm یا Python کے لیے virtualenv کی طرح ہے، لیکن یہ بہت سے مختلف ماحول کے لیے کام کرتا ہے۔

مثال کے طور پر Ruby انسٹال کرنے کے لیے، آپ `mise use -g ruby` چلائیں گے، جو Ruby انسٹال بھی کرے گا اور اسے عالمی ڈیفالٹ کے طور پر بھی مقرر کرے گا۔ یا، اگر آپ کے پروجیکٹ میں .ruby-version فائل ہے تو آپ اس پروجیکٹ کی روٹ میں بس `mise i` چلا سکتے ہیں۔

## پہلے سے انسٹال شدہ CLI ٹولز

Omarchy، [mise کی لیزی انسٹالیشن](https://mise.jdx.dev/dev-tools/shims.html#lazy-tools) کے ذریعے `gh`، `uv`، اور بیشتر [کوڈنگ ایجنٹس](17-ai.md) جیسے ٹولز دستیاب کرتا ہے۔ پہلی بار جب آپ ان میں سے کوئی چلائیں گے تو mise اسے انسٹال کر دے گا۔ بعد کی بار چلانے پر انسٹال شدہ ورژن ہی دوبارہ استعمال ہوگا؛ وہ ہر لانچ پر اپ ڈیٹ کی جانچ نہیں کرتے۔

آپ ڈیفالٹس کا معائنہ بھی کر سکتے ہیں یا انہیں پہلے سے انسٹال بھی کر سکتے ہیں:

```bash
mise ls --current              # List the tools configured for this directory
mise install gh               # Install one tool now
mise install --include-lazy    # Install all configured tools, including lazy tools
```

باقی Omarchy کے ساتھ انسٹال شدہ ٹولز کو اپ ڈیٹ کرنے کے لیے `omarchy update` چلائیں۔ `mup` ایلیاس صرف mise کے زیر انتظام ٹولز کو اپ ڈیٹ کرتا ہے۔ اپنی کنفیگریشن میں کوئی اور ٹول شامل کرنے کے لیے `mise use -g <tool>` استعمال کریں۔

Python سیٹ اپ، mise کے ذریعے `uv` بھی انسٹال کرتا ہے۔ Python ڈیولپمنٹ ماحول ہٹانے سے `uv` ایک آزاد ٹول کے طور پر دستیاب رہتا ہے۔

### اپنی انسٹالیشن کا استعمال

mise کے کمانڈز `PATH` پر `~/.local/bin` سے پہلے آتے ہیں، اس لیے جو ٹول آپ نے خود انسٹال کیا ہو، مثال کے طور پر Claude Code کے یا Cursor کے اپنے انسٹالر کے ساتھ، پھر بھی mise کی کاپی چلے گی۔ ڈیسک ٹاپ سے لانچ کی گئی ایپس کو بھی سسٹم پیکیجز سے پہلے mise کے کمانڈز ملتے ہیں، اس لیے جو ایپ `gh` چلاتی ہے اسے mise کی کاپی ملتی ہے خواہ آپ نے pacman کے ساتھ `github-cli` انسٹال کیا ہو، اور mise پہلی بار اس کاپی کو انسٹال کرتا ہے۔ اس کے بجائے اپنا استعمال کرنے کے لیے، `~/.config/mise/config.toml` میں mise کی کاپی غیر فعال کریں۔ مثال کے طور پر، اگر آپ نے Cursor CLI خود انسٹال کیا ہے:

```toml
[settings]
disable_tools = ["cursor-agent"]
```

اگر آپ کے پاس پہلے سے `[settings]` ٹیبل موجود ہے تو انٹری وہیں شامل کریں؛ موجودہ `disable_tools` فہرست کو بدلنے کے بجائے اسے بڑھائیں۔ یقینی بنائیں کہ آپ کی انسٹالیشن `PATH` پر ہے۔ mise ٹول کا نام استعمال کریں، جو اس کی کمانڈ سے مختلف ہو سکتا ہے: مثال کے طور پر `oh-my-pi`، `omp` فراہم کرتا ہے۔ ڈیفالٹ ایجنٹ لانچر بھی `~/.local/bin` میں صارف کے انسٹال کردہ Cursor یا Muse کو ترجیح دیتا ہے۔

### ڈیفالٹس کو ہٹانا اور بحال کرنا

_Remove Preinstalls_ میں mise آپ کے صارف کے لیے Omarchy کے ٹول اعلانات کو چھوڑ دیتا ہے، انہیں `~/.config/mise/miserc.toml` میں `ignored_config_paths` میں شامل کر کے۔ _Restore Preinstalls_ اس لائن کو دوبارہ ہٹا دیتا ہے۔ جو ٹولز آپ خود اعلان کرتے ہیں، اپنی کنفیگریشن میں یا کسی پروجیکٹ کی `mise.toml` میں، وہ دونوں صورتوں میں کام کرتے رہتے ہیں۔ اگر آپ پری انسٹالز ہٹانے کے بعد کوئی ڈیفالٹ ایجنٹ منتخب کرتے ہیں یا Python سیٹ اپ کرتے ہیں تو وہ ٹول آپ کی اپنی کنفیگریشن میں شامل کر دیا جاتا ہے۔ دونوں کا اطلاق صرف آپ کے صارف پر ہوتا ہے؛ مشین پر موجود دیگر صارفین اپنا انتخاب برقرار رکھتے ہیں۔

## Docker

[Docker](https://www.docker.com/) کو شاید ہی کسی تعارف کی ضرورت ہو۔ یہ آپ کو الگ تھلگ کنٹینرز چلانے دیتا ہے، اور Omarchy اسے اچھی طرح چلانے کے لیے درکار ہر چیز انسٹال کرتا ہے، بشمول Docker بذات خود اور [Docker Compose](https://docs.docker.com/compose/)۔

بطور ڈیفالٹ آپ کا صارف `docker` گروپ میں *نہیں* ہے۔ وہ گروپ درحقیقت پاس ورڈ کے بغیر root ہے — اس میں موجود کوئی بھی `docker run -v /:/host` کر کے مشین پر قبضہ کر سکتا ہے — اس لیے کوئی ایک بدمعاش اسکرپٹ یا ڈپینڈینسی جو آپ کے طور پر چل رہی ہو، ورنہ root سے صرف ایک کمانڈ دور ہوگی۔ اس لیے کمانڈ لائن پر آپ Docker کو `sudo` کے ساتھ چلاتے ہیں (`sudo docker ps`، `sudo docker compose up`)، اور گرافیکل ٹولز جو ڈیمن سے بات کرتے ہیں — Windows VM — ضرورت پڑنے پر آپ سے اجازت مانگتے ہیں۔ اگر آپ بغیر گروپ والے سیٹ اپ کی سہولت واپس چاہتے ہیں اور اس سمجھوتے کو سمجھتے ہیں تو اسے **Setup > Security > Sudoless Docker** سے فعال کریں (یا `omarchy-setup-security-sudoless-docker` چلائیں)، جو انتباہ کے بعد آپ کو `docker` گروپ میں شامل کر دیتا ہے؛ پھر سادہ `docker` اور `d` ایلیاس دوبارہ `sudo` کے بغیر کام کریں گے۔

آپ Omarchy مینو میں _Install > Development > Docker DB_ استعمال کر کے مقامی ڈیولپمنٹ کے لیے عام ڈیٹا بیسز Docker میں سیٹ اپ کر سکتے ہیں۔

## GitHub CLI

[GitHub CLI](https://cli.github.com/) ٹرمینل سے ریپوزٹریز، ایشوز اور پل ریکویسٹس کے ساتھ کام کرنے کے لیے `gh` کے طور پر دستیاب ہے۔ اسے پہلے استعمال پر انسٹال کرنے اور تصدیق کرنے کے لیے `gh auth login` چلائیں، پھر کسی ریپوزٹری کو کلون کرنے کے لیے `gh repo clone org/repo` چلائیں۔ اس کے کمانڈز دریافت کرنے کے لیے `gh --help` چلائیں۔

پل ریکویسٹس کے لیے ٹرمینل انٹرفیس کے لیے `ghui` چلائیں؛ mise اسے بھی پہلے استعمال پر انسٹال کرتا ہے۔ Git کے ساتھ کام کرنے کے لیے [Lazygit](https://github.com/jesseduffield/lazygit) پہلے سے انسٹال ہے۔
