# ڈیولپمنٹ ٹولز

## متبادل ایڈیٹرز

Omarchy نئی انسٹالیشنز پر بطور ڈیفالٹ ایڈیٹر Plain کے ساتھ آتا ہے اور [Neovim](https://neovim.io/) پہلے سے انسٹال ہوتا ہے، لیکن اگر آپ کو کچھ زیادہ مرکزی دھارے کا اور مانوس چاہیے تو آپ Omarchy Menu (`Super + Space`) چلا کر _Install > Editor_ کے تحت آپشنز دیکھ سکتے ہیں۔ وہاں ہمارے پاس VSCode، Cursor، Zed، Sublime Text، Helix، Vim اور Emacs درج ہیں۔ اگر آپ کو وہ نہیں ملتا جس کی آپ کو تلاش ہے تو _Install > Package_ دیکھیں، اور دیکھیں کہ آیا وہ کسی Arch پیکیج میں ہے یا نہیں (اور اگر نہیں ہے تو AUR چیک کرنے کے لیے _Install > AUR_ آزمائیں)۔

اصل `vi` ایڈیٹر بھی شروع سے دستیاب ہے۔ ٹرمینل میں کسی فائل میں ترمیم کرنے کے لیے `vi filename` چلائیں۔

`VSCode`، `Cursor`، `VSCodium` اور `Helix` کے لیے تھیم میچنگ پیش کی جاتی ہے۔

آپ `Setup > Defaults > Editor` کے تحت سسٹم بھر کے لیے ڈیفالٹ ایڈیٹر سیٹ کر سکتے ہیں۔

## ماحول

Omarchy، Omarchy Menu (`Super + Space`) کے _Install > Development_ سیکشن کے ذریعے ڈیولپمنٹ ماحولوں کی ایک پوری بڑی تعداد سیٹ اپ کرنے کی سہولت دیتا ہے۔ بلاشبہ آپ کو وہاں _Ruby on Rails_ ملے گا، لیکن JavaScript کے تینوں بڑے رن ٹائمز (Node.js، Bun، Deno) بھی ملیں گے، نیز Laravel اور Symfony جیسے مقبول PHP فریم ورکس بھی۔ اوہ، اور Go، Rust، Python، Java، Elixir (Phoenix کے ساتھ)، .NET، OCaml، Zig، Clojure اور Scala بھی ہیں۔ یہ بہت وسیع انتخاب ہے!

ان میں سے بیشتر ماحول [Mise](https://mise.jdx.dev/) کے ذریعے منظم کیے جاتے ہیں۔ یہ ایک ایسا ٹول ہے جو آپ کو ایک ہی مشین پر کسی پروگرامنگ زبان کے متعدد ورژن انسٹال اور چلانے دیتا ہے۔ یہ Ruby کے لیے rbenv یا rvm، یا Python کے لیے virtualenv جیسا ہے، لیکن یہ بہت سے مختلف ماحولوں کے لیے کام کرتا ہے۔

مثال کے طور پر Ruby انسٹال کرنے کے لیے آپ `mise use -g ruby` چلائیں گے، جو Ruby انسٹال بھی کر دے گا اور اسے عالمی ڈیفالٹ کے طور پر سیٹ بھی کر دے گا۔ یا، اگر آپ کے پروجیکٹ میں .ruby-version فائل ہے تو آپ اس پروجیکٹ کی روٹ میں صرف `mise i` چلا سکتے ہیں۔

## پہلے سے انسٹال شدہ CLI ٹولز

`uv`، Node.js اور `playwright-cli` (ایجنٹس کے لیے انسٹال شدہ Chrome استعمال کرتے ہوئے براؤزر چلانے کے لیے) پیکیجز کے طور پر انسٹال آتے ہیں، اور `omarchy update` انہیں باقی سسٹم کے ساتھ اپ ٹو ڈیٹ رکھتا ہے۔ `ghui`، [Hunk](https://github.com/modem-dev/hunk) اور Basecamp، Cloudflare اور HEY CLIs _Install > CLI_ کے تحت ایک انتخاب کی دوری پر ہیں، اور [coding agents](17-ai.md) _Install > AI > CLI_ کے تحت ہیں۔

mise صرف ان رن ٹائمز کو منظم کرتا ہے جنہیں آپ _Install > Development_ سے سیٹ اپ کرتے ہیں؛ Omarchy اس کے ذریعے خود سے کچھ بھی انسٹال نہیں کرتا۔ انہیں باقی Omarchy کے ساتھ اپڈیٹ کرنے کے لیے `omarchy update` چلائیں؛ `mup` ایلیاس صرف mise کے زیر انتظام ٹولز کو اپڈیٹ کرتا ہے۔ اپنی کنفیگریشن میں کوئی اور ٹول شامل کرنے کے لیے `mise use -g <tool>` استعمال کریں۔

## Docker

[Docker](https://www.docker.com/) کو شاید ہی کسی تعارف کی ضرورت ہو۔ یہ آپ کو الگ تھلگ کنٹینرز چلانے دیتا ہے، اور Omarchy اسے اچھی طرح چلانے کے لیے درکار ہر چیز انسٹال کرتا ہے، بشمول خود Docker اور [Docker Compose](https://docs.docker.com/compose/)۔

بطور ڈیفالٹ آپ کا صارف `docker` گروپ میں *نہیں* ہوتا۔ وہ گروپ درحقیقت بغیر پاس ورڈ کے root ہے — اس میں موجود کوئی بھی چیز `docker run -v /:/host` چلا کر مشین پر قبضہ کر سکتی ہے — اس لیے آپ کے طور پر چلنے والا کوئی ایک آوارہ اسکرپٹ یا ڈیپنڈنسی بصورت دیگر root سے صرف ایک کمانڈ کی دوری پر ہوگا۔ اس لیے کمانڈ لائن پر آپ Docker کو `sudo` کے ساتھ چلاتے ہیں (`sudo docker ps`، `sudo docker compose up`)، اور ڈیمن سے بات کرنے والے گرافیکل ٹولز — Windows VM — ضرورت پڑنے پر آپ سے اجازت مانگتے ہیں۔ اگر آپ گروپ کے بغیر سیٹ اپ کی سہولت واپس چاہتے ہیں اور اس سودے کو سمجھتے ہیں تو اسے **Setup > Security > Sudoless Docker** سے فعال کریں (یا `omarchy-setup-security-sudoless-docker` چلائیں)، جو انتباہ کے بعد آپ کو `docker` گروپ میں شامل کر دیتا ہے؛ پھر سادہ `docker` اور `d` ایلیاس دوبارہ `sudo` کے بغیر کام کرتے ہیں۔

آپ Omarchy مینو میں _Install > Development > Docker DB_ استعمال کر کے Docker میں مقامی ڈیولپمنٹ کے لیے عام ڈیٹا بیسز سیٹ اپ کر سکتے ہیں۔

## GitHub CLI

[GitHub CLI](https://cli.github.com/) یعنی `gh`، ٹرمینل سے ریپوزٹریز، ایشوز اور پل ریکویسٹس کے ساتھ کام کرنے کے لیے ہے۔ _Setup > Git_ اسے اس وقت انسٹال کرتا ہے جب آپ وہاں GitHub میں سائن ان کرنے کا انتخاب کرتے ہیں، پھر `gh repo clone org/repo` کسی ریپوزٹری کو کلون کرتا ہے۔ اس کی کمانڈز دریافت کرنے کے لیے `gh --help` چلائیں۔

_Install > CLI > GitHub_، GitHub CLI یعنی `gh` کو `ghui` کے ساتھ انسٹال کرتا ہے، جو پل ریکویسٹس کے لیے ایک ٹرمینل انٹرفیس ہے۔ [Lazygit](https://github.com/jesseduffield/lazygit) خود Git کے ساتھ کام کرنے کے لیے پہلے سے انسٹال آتا ہے۔
