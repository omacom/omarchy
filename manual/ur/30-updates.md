# اپ ڈیٹس

Omarchy اور آپ کے پیکجز کو Omarchy مینیو (`Super + Space`) میں _Update > Omarchy_ کے ذریعے اپ ٹو ڈیٹ رکھا جاتا ہے۔

Omarchy خود [Omarchy Package Repository](https://github.com/omacom-io/omarchy-pkgs) سے باقاعدہ pacman پیکجز کے طور پر انسٹال ہوتا ہے، اس لیے اپ ڈیٹ [تازہ ترین Omarchy ریلیز](https://github.com/omacom/omarchy/releases) انسٹال کرتی ہے، آپ کے سسٹم کو تازہ ترین کے ساتھ ہم آہنگ کرنے کے لیے کوئی بھی زیر التوا مائیگریشنز چلاتی ہے، اور [Omarchy Arch Mirror](https://github.com/omacom-io/omarchy-mirror) اور [AUR](https://aur.archlinux.org/) سے تمام سسٹم پیکجز اپ ڈیٹ کرتی ہے (اگر آپ نے کوئی AUR پیکجز انسٹال کیے ہوں)۔

جب نئی ریلیزز جاری ہوتی ہیں، تو آپ کی گھڑی کے دائیں طرف ایک دائرہ نما تیر کا آئیکن ظاہر ہوگا۔ اس پر کلک کریں اور اپ ڈیٹ کا عمل شروع ہو جائے گا۔

![update-available](images/update-available.webp)

### چار چینلز

Omarchy کو چار چینلز کے ساتھ اپ ڈیٹ کیا جاتا ہے: stable، RC، edge، اور dev۔ نئی انسٹالیشنز stable چینل سے شروع ہوتی ہیں، جو [سرکاری ریلیزز](https://github.com/omacom/omarchy/releases/) کے ساتھ ساتھ [مستحکم Omarchy Arch مرر](https://github.com/omacom-io/omarchy-mirror) کو بھی فالو کرتا ہے جو تازہ ترین سے ایک ماہ پیچھے چل رہا ہے، تاکہ ہم کسی بھی نئی عدم مطابقت کو، جس کے لیے کنفگ میں تبدیلیوں کی ضرورت ہو، لوگوں کے لیے مسائل پیدا کرنے سے پہلے ہی پکڑ سکیں۔

لیکن اگر آپ ان ممکنہ مسائل کو تلاش کرنے میں مدد کرنا چاہتے ہیں، تو آپ edge چینل پر چل سکتے ہیں۔ اس سے آپ کے Omarchy پیکجز تازہ ترین ڈویلپمنٹ بلڈز کو فالو کرتے رہیں گے، اور آپ تازہ ترین Arch پیکجز دستیاب ہوتے ہی ان پر اپ ڈیٹ کر سکیں گے۔ آپ کو یہ صرف اسی صورت میں کرنا چاہیے جب آپ Linux کے تجربہ کار ہوں، اور جانتے ہوں کہ مسائل کا شکار سسٹم کو کیسے بحال کیا جائے۔

کسی بھی نئی بڑی ریلیز سے پہلے، ہم RC چینل کا استعمال کرتے ہوئے حتمی جانچ کریں گے۔ اگر آپ حتمی پالش میں مدد کرنے میں دلچسپی رکھتے ہیں، تو Discord پر #omarchy-release-candidates میں آ کر ہمارے ساتھ شامل ہوں۔

آخر میں، dev چینل ہے، جو Omarchy کو براہ راست `~/omarchy` میں سورس کوڈ کے git چیک آؤٹ سے جوڑتا ہے، edge پیکجز کے ساتھ ملا کر۔ آپ کو یہ چینل صرف اسی صورت میں استعمال کرنا چاہیے جب آپ تجربہ کار Linux صارف ہوں، براہ راست Omarchy پر کام کر رہے ہوں، اور خرابی برداشت کرنے کے لیے تیار ہوں۔

آپ Omarchy مینیو سے _Update > Channel_ کا استعمال کرتے ہوئے (یا ٹرمینل میں `omarchy-channel-set` کے ذریعے) چینلز کے درمیان سوئچ کر سکتے ہیں۔

### کرنلز تبدیل کرنا

Omarchy اپنا `linux-omarchy` کرنل بوٹ کرتا ہے، لیکن آپ اس کے ساتھ دوسرے کرنلز بھی انسٹال رکھ سکتے ہیں، جیسے اسٹاک Arch `linux` کرنل یا کوئی تجرباتی بلڈ جسے آپ آزما رہے ہوں۔ جب ایک سے زیادہ کرنل موجود ہوں، تو Omarchy مینیو میں _Update > Kernel_ انہیں فہرست میں دکھاتا ہے اور جو بطور ڈیفالٹ بوٹ ہوتا ہے اس کے ساتھ ایک چیک کا نشان ہوتا ہے۔ کوئی دوسرا منتخب کریں، ایک بار اپنا پاس ورڈ درج کریں، اور یہ اگلی ری اسٹارٹ کے بعد بوٹ ہو جائے گا۔ دوسرے کرنلز بوٹ مینیو میں موجود رہتے ہیں، اس لیے اگر نیا ڈیفالٹ آپ کو پریشانی دے تو آپ پھر بھی دستی طور پر کوئی ایک منتخب کر سکتے ہیں۔ ٹرمینل میں، موجودہ ڈیفالٹ دیکھنے کے لیے `omarchy-kernel`، جو انسٹال ہیں ان کی فہرست کے لیے `omarchy-kernel list`، اور تبدیل کرنے کے لیے `omarchy-kernel set <kernel>` استعمال کریں۔

### فرم ویئر اپ ڈیٹس

صرف آپ کے پیکجز ہی پرانے نہیں ہوتے۔ بہت سے لیپ ٹاپس اور پیریفرلز BIOS، SSD، اور ڈاک فرم ویئر Linux Vendor Firmware Service کے ذریعے فراہم کرتے ہیں، اور Omarchy مینیو میں _Update > Firmware_ آپ کے ہارڈویئر کے لیے جو کچھ بھی منتظر ہوگا اسے حاصل کر کے انسٹال کر دے گا۔ یہ پہلی بار چلانے پر `fwupd` انسٹال کرتا ہے۔ بہت سا فرم ویئر صرف ری بوٹ کے دوران ہی لکھا جا سکتا ہے، اس لیے اگر آپ سے ری بوٹ کا کہا جائے تو حیران نہ ہوں۔

### براہ راست pacman/yay اپ ڈیٹس کے بارے میں انتباہ

اگر آپ پہلے سے Arch سے واقف ہیں، تو آپ کو خود `pacman -Syu` یا `yay -Syu` چلانے کا لالچ ہو سکتا ہے، لیکن اگر آپ ایسا کرتے ہیں، تو آپ اسنیپ شاٹ، مائیگریشنز، اور کنفیگریشن اپ ڈیٹس سے محروم رہ جائیں گے جو Omarchy نئے پیکجز کے ساتھ مل کر چلاتا ہے۔ اسی لیے Omarchy درحقیقت براہ راست سسٹم اپ گریڈ کو روک دے گا اور اس کے بجائے آپ کو `omarchy update` کی طرف بھیجے گا۔ (اگر آپ واقعی جانتے ہیں کہ آپ کیا کر رہے ہیں، تو گارڈ آپ کو بتائے گا کہ ایک ہی ٹرانزیکشن کے لیے اسے کیسے بائی پاس کیا جائے۔)

### خراب اپ ڈیٹس کو واپس لینا

اگر اپ ڈیٹ کرنے کے بعد آپ کو کبھی کوئی مسئلہ پیش آئے، تو آپ اپنے سسٹم کو اپ ڈیٹ سے پہلے لیے گئے اسنیپ شاٹ پر واپس لے جا سکتے ہیں۔ بس ری اسٹارٹ کریں اور بوٹ لوڈنگ مینیو میں اپ ڈیٹ شروع کرنے سے پہلے والا اسنیپ شاٹ منتخب کریں۔

![bootloader](images/bootloader.webp)

اگر کسی طرح آپ کی کنفیگریشن فائلیں خراب ہو گئی ہوں، تو آپ ٹرمینل میں `omarchy reinstall` کا استعمال کرتے ہوئے Omarchy کو دوبارہ انسٹال بھی کر سکتے ہیں۔ یہ تمام ڈیفالٹ Omarchy پیکجز دوبارہ انسٹال کر دے گا، آپ کو stable پر ڈال دے گا اور جو پیکجز بہت نئے ہوں انہیں ڈاؤن گریڈ کر دے گا، اور تمام کنفیگریشن فائلیں ری سیٹ کر دے گا۔ نوٹ کریں کہ ایسا کرنے سے Omarchy ڈیفالٹس میں آپ کی کی گئی تمام صارف کنفگ تبدیلیاں اوور رائٹ ہو جائیں گی!
