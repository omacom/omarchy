# اپ ڈیٹ کریں

Omarchy اور آپ کے پیکیجز کو Omarchy مینو (`Super + Space`) میں _اپ ڈیٹ کریں > Omarchy_ کے ذریعے اپ ڈیٹ رکھا جاتا ہے۔

Omarchy خود [Omarchy پیکیج ریپازٹری](https://github.com/omacom-io/omarchy-pkgs) سے باقاعدہ pacman پیکیجز کے طور پر انسٹال होता ہے، لہٰذا اپ ڈیٹ [تازہ ترین Omarchy ریلیز](https://github.com/omacom/omarchy/releases) انسٹال کرتا ہے، آپ کے سسٹم کو تازہ ترین کے ساتھ ہم وقت رکھنے کے لیے زیر التوا کوئی بھی مائیگریشن چلاتا ہے، اور [Omarchy Arch مرر](https://github.com/omacom-io/omarchy-mirror) اور [AUR](https://aur.archlinux.org/) سے تمام سسٹم پیکیجز کو اپ ڈیٹ کرتا ہے (اگر آپ نے کوئی AUR پیکیج انسٹال کر رکھا ہو)۔

جب نئی ریلیزیں تیار ہوتی ہیں تو آپ کی گھڑی کے دائیں جانب دائرے کے تیر کا آئیکن ظاہر ہوگا۔ اس پر کلک کریں اور اپ ڈیٹ کا عمل شروع ہو جائے گا۔

![update-available](images/update-available.webp)

### چار چینلز

Omarchy کو چار چینلز کے ساتھ اپ ڈیٹ کیا جاتا ہے: مستحکم، RC، ایج اور ڈیویلپمنٹ۔ نئے انسٹالیشنز مستحکم چینل پر شروع ہوتے ہیں، جو [سرکاری ریلیزز](https://github.com/omacom/omarchy/releases/) کی پیروی کرتا ہے، نیز [مستحکم Omarchy Arch مرر](https://github.com/omacom-io/omarchy-mirror) جو تازہ ترین سے ایک مہینہ پیچھے چل رہا ہے، تاکہ ہم کسی بھی نئی عدم موافقت کو پکڑ سکیں جو دیگر ترتیب تبدیلیوں کی ضرورت رکھتی ہو اس سے پہلے کہ وہ لوگوں کے لیے مسائل کا سبب بنے۔

لیکن اگر آپ ان ممکنہ مسائل کو دیکھنے میں مدد کرنا چاہتے ہیں تو آپ ایج چینل پر چل سکتے ہیں۔ یہ آپ کے Omarchy پیکیجز کو تازہ ترین ڈویلپمنٹ بلڈز کی پیروی کرتے رکھے گا، اور آپ کو تازہ ترین Arch پیکیجز دستیاب ہوتے ہی اپ ڈیٹ کرنے دے گا۔ آپ کو یہ صرف اسی وقت کرنا چاہیے جب آپ Linux سے تجربہ رکھتے ہوں، اور جانتے ہوں کہ مسائل کا شکار نظام کو کیسے بحال کرنا ہے।

کسی بھی نئی بڑی ریلیز سے پہلے، ہم RC چینل استعمال کرتے ہوئے حتمی توثیق کر رہے ہوں گے۔ اگر آپ حتمی نिखار میں مدد کرنے میں دلچسپی رکھتے ہیں تو Discord پر #omarchy-release-candidates میں آئیں۔

آخر میں، ڈیویلپمنٹ چینل ہے، جو Omarchy کو `~/omarchy` میں سورس کوڈ کے git چیک آؤٹ سے براہِ راست جوڑتا ہے، ایج پیکیجز کے ساتھ مل کر۔ آپ کو یہ چینل صرف اسی وقت استعمال करना چاہیے جب آپ تجربہ کار Linux صارف ہوں، براہِ راست Omarchy پر کام کر رہے ہوں، اور ٹूट-फूट کو برداشت کرنے کے لیے تیار ہوں।

آپ Omarchy مینو سے _اپ ڈیٹ کریں > چینل_ استعمال کرتے ہوئے (یا ٹرمینل میں `omarchy-channel-set`) چینلز کے درمیان سوئچ کر سکتے ہیں।

### فرم ویئر اپ ڈیٹ

آپ کے پیکیجز صرف وہ چیز نہیں ہیں جو پرانی پڑتی ہیں। کئی لیپ ٹاپ اور پیریفیرلز Linux Vendor Firmware Service के ذریعے BIOS، SSD اور ڈاک فرم ویئر بھیجتے ہیں، اور Omarchy مینو میں _اپ ڈیٹ کریں > فرم ویئر_ جو کچھ آپ کے ہارڈویئر کے پاس انتظار کر रहा ہوگا اسے حاصل کر کے انسٹال کر دے گا। پہلی بار جب آپ اسے چلاتے ہیں تو یہ `fwupd` انسٹال کرتا है। بہت سارے فرم ویئر کو صرف ری بوٹ کے دوران ہی لکھا जा سکتا ہے، لہٰذا اگر آپ سے ایک کی درخواست کی جائے تو حیران نہ ہوں।

### براہِ راست pacman/yay اپ ڈیٹ کے بارے میں انتباہ

اگر آپ پہلے ہی Arch سے واقفیت رکھتے ہیں تو آپ لالچ میں آ سکتے ہیں کہ بس خود `pacman -Syu` یا `yay -Syu` چلا لیں، لیکن اگر آپ ایسا کرتے ہیں تو آپ اس سنیپ شاٹ، مائیگریشنز اور ترتیب اپ ڈیٹ سے محروم رہ جائیں گے جو Omarchy نئے پیکیجز کے ساتھ چلاتا ہے। اسی لیے Omarchy اصل میں براہِ راست نظام اپ گریڈ کو روک کر اس کی جگہ آپ کو `omarchy update` کی طرف اشارہ کرے گا। (اگر آپ اصل میں جانتے ہیں کہ آپ کیا کر رہے ہیں تو محافظ آپ کو بتائے گا کہ اسے ایک لین دین کے لیے کیسے بائی پاس کرنا ہے)۔

### خراب اپ ڈیٹ کو واپس لوٹانا

اگر کبھی آپ کو اپ ڈیٹ کرنے کے بعد کوئی مسئلہ درپیش ہو تو آپ اپنے سسٹم کو اپ ڈیٹ سے پہلے لی گئی تصویر پر واپس لوٹا سکتے ہیں। بس دوبارہ شروع کریں اور اپ ڈیٹ شروع کرنے سے پہلے بوٹ لوڈنگ مینو میں موجود اس سنیپ شاٹ کو منتخب کریں۔

![bootloader](images/bootloader.webp)

اگر کسی طرح آپ کی ترتیب فائلیں خراب ہو گئی ہیں تو آپ ٹرمینل میں `omarchy reinstall` استعمال کرتے ہوئے Omarchy کی دوبارہ انسٹالیشن بھی انجام दे سکتے हैं। یہ Omarchy کے تمام ڈیفالٹ پیکیجز کو دوبارہ انسٹال کرے گا، آپ کو مستحکم پر رکھے گا اور بہت نئے کسی بھی پیکیج کو کم درجہ کر دے گا، اور تمام ترتیب فائلوں کو دوبارہ مقرر کرے گا। نوٹ کریں کہ ایسا کرتے ہوئے Omarchy ڈیفالٹس میں آپ کی تمام صارف ترتیب تبدیلیاں مٹا دی جائیں گی!
