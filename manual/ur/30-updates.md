# اپ ڈیٹس

Omarchy اور آپ کے پیکیجز کو Omarchy مینیو (`Super + Space`) میں _اپ ڈیٹ > Omarchy_ کے ذریعے اپ ٹو ڈیٹ رکھا جاتا ہے۔

Omarchy بذاتِ خود [Omarchy Package Repository](https://github.com/omacom-io/omarchy-pkgs) سے باقاعدہ pacman پیکیجز کے طور پر انسٹال ہوتا ہے، اس لیے ایک اپ ڈیٹ [تازہ ترین Omarchy ریلیز](https://github.com/omacom/omarchy/releases) انسٹال کرتی ہے، آپ کے سسٹم کو تازہ ترین کے ساتھ ہم آہنگ کرنے کے لیے کوئی بھی زیرِ التواء مائیگریشنز چلاتی ہے، اور [Omarchy Arch Mirror](https://github.com/omacom-io/omarchy-mirror) اور [AUR](https://aur.archlinux.org/) سے تمام سسٹم پیکیجز اپ ڈیٹ کرتی ہے (اگر آپ نے کوئی AUR پیکیجز انسٹال کیے ہوں)۔

جب نئی ریلیزز آتی ہیں، تو آپ کی گھڑی کے دائیں جانب ایک دائرے والے تیر کا آئیکن ظاہر ہوگا۔ اس پر کلک کریں اور اپ ڈیٹ کا عمل شروع ہو جائے گا۔

![update-available](images/update-available.webp)

### چار چینلز

Omarchy کو چار چینلز کے ساتھ اپ ڈیٹ کیا جاتا ہے: stable، RC، edge، اور dev۔ نئی انسٹالیشنز stable چینل سے شروع ہوتی ہیں، جو [سرکاری ریلیزز](https://github.com/omacom/omarchy/releases/) کے ساتھ ساتھ [stable Omarchy Arch mirror](https://github.com/omacom-io/omarchy-mirror) کی پیروی کرتا ہے جو تازہ ترین سے ایک ماہ پیچھے چلتا ہے، تاکہ ہم کسی بھی نئی عدم مطابقت کو جو کنفیگ میں تبدیلیوں کی متقاضی ہو، لوگوں کے لیے مسائل بننے سے پہلے پکڑ سکیں۔

لیکن اگر آپ ان ممکنہ مسائل کو تلاش کرنے میں مدد کرنا چاہتے ہیں، تو آپ edge چینل پر چل سکتے ہیں۔ یہ آپ کے Omarchy پیکیجز کو تازہ ترین ڈیولپمنٹ بلڈز کی پیروی میں رکھے گا، اور آپ کو تازہ ترین Arch پیکیجز دستیاب ہوتے ہی ان پر اپ ڈیٹ کرنے دے گا۔ آپ کو یہ صرف اسی صورت میں کرنا چاہیے اگر آپ Linux کے تجربہ کار ہیں، اور جانتے ہیں کہ مسائل کا شکار سسٹم کو کیسے بحال کیا جائے۔

کسی بھی نئی بڑی ریلیز سے پہلے، ہم RC چینل استعمال کرتے ہوئے حتمی جانچ کریں گے۔ اگر آپ حتمی نکھار میں مدد کرنے میں دلچسپی رکھتے ہیں، تو Discord پر #omarchy-release-candidates میں آ کر ہمارے ساتھ شامل ہوں۔

آخر میں، dev چینل ہے، جو Omarchy کو براہِ راست `~/omarchy` میں سورس کوڈ کے git چیک آؤٹ سے جوڑتا ہے، edge پیکیجز کے ساتھ ملا کر۔ آپ کو یہ چینل صرف اسی صورت میں استعمال کرنا چاہیے اگر آپ تجربہ کار Linux صارف ہیں، براہِ راست Omarchy پر کام کر رہے ہیں، اور ٹوٹ پھوٹ برداشت کرنے کے لیے تیار ہیں۔

آپ Omarchy مینیو سے _اپ ڈیٹ > Channel_ استعمال کر کے (یا ٹرمینل میں `omarchy-channel-set`) چینلز کے درمیان تبدیل کر سکتے ہیں۔

### کرنلز تبدیل کرنا

Omarchy اپنا `linux-omarchy` کرنل بوٹ کرتا ہے، لیکن آپ اس کے ساتھ ساتھ دوسرے بھی انسٹال رکھ سکتے ہیں، جیسے اسٹاک Arch `linux` کرنل یا کوئی تجرباتی بلڈ جسے آپ آزما رہے ہیں۔ جب ایک سے زیادہ موجود ہوں، تو Omarchy مینیو میں _اپ ڈیٹ > Kernel_ انہیں اس کے ساتھ ایک نشان کے ساتھ فہرست میں دکھاتا ہے جو بطورِ ڈیفالٹ بوٹ ہوتا ہے۔ کوئی دوسرا منتخب کریں، ایک بار اپنا پاس ورڈ درج کریں، اور یہ اگلی ری اسٹارٹ کے بعد بوٹ ہوگا۔ دیگر کرنلز بوٹ مینیو میں موجود رہتے ہیں، لہٰذا اگر نیا ڈیفالٹ آپ کو پریشان کرے تو آپ پھر بھی دستی طور پر ایک منتخب کر سکتے ہیں۔ ٹرمینل میں، موجودہ ڈیفالٹ دیکھنے کے لیے `omarchy-kernel` ہے، جو انسٹال ہے اس کے لیے `omarchy-kernel list`، اور تبدیل کرنے کے لیے `omarchy-kernel set <kernel>`۔

### فرم ویئر اپ ڈیٹس

صرف آپ کے پیکیجز ہی پرانے نہیں ہوتے۔ بہت سے لیپ ٹاپس اور پیریفرلز Linux Vendor Firmware Service کے ذریعے BIOS، SSD، اور ڈاک فرم ویئر بھیجتے ہیں، اور Omarchy مینیو میں _اپ ڈیٹ > Firmware_ جو کچھ بھی آپ کے ہارڈویئر کے لیے منتظر ہے اسے حاصل کر کے انسٹال کر دے گا۔ پہلی بار چلانے پر یہ `fwupd` انسٹال کرتا ہے۔ بہت سا فرم ویئر صرف ری بوٹ کے دوران ہی لکھا جا سکتا ہے، اس لیے اگر آپ سے ری بوٹ کے لیے کہا جائے تو حیران نہ ہوں۔

جب آپ کو خود BIOS میں کوئی سیٹنگ تبدیل کرنی ہو، تو سسٹم مینیو (`Super + Escape`) میں `Alt` دبا کر رکھیں اور _ری بوٹ_، _BIOS پر ری بوٹ_ میں بدل جاتا ہے، جو بوٹ کے وقت صحیح کلید دبانے کی کوشش کیے بغیر سیدھا فرم ویئر سیٹ اپ میں ری اسٹارٹ کرتا ہے۔ ٹرمینل سے، یہ `omarchy system firmware` ہے۔

### براہِ راست pacman/yay اپ ڈیٹس کے بارے میں انتباہ

اگر آپ پہلے سے Arch سے واقف ہیں، تو آپ خود ہی `pacman -Syu` یا `yay -Syu` چلانے کی طرف مائل ہو سکتے ہیں، لیکن اگر آپ ایسا کرتے ہیں، تو آپ اسنیپ شاٹ، مائیگریشنز، اور کنفیگریشن اپ ڈیٹس سے محروم رہ جائیں گے جو Omarchy نئے پیکیجز کے ساتھ مل کر چلاتا ہے۔ یہی وجہ ہے کہ Omarchy درحقیقت براہِ راست سسٹم اپ گریڈ کو روک دے گا اور اس کے بجائے آپ کو `omarchy update` کی طرف بھیجے گا۔ (اگر آپ واقعی جانتے ہیں کہ آپ کیا کر رہے ہیں، تو گارڈ آپ کو بتائے گا کہ ایک ہی ٹرانزیکشن کے لیے اسے کیسے نظرانداز کیا جائے۔)

### خراب اپ ڈیٹس کو واپس پلٹنا

اگر اپ ڈیٹ کرنے کے بعد آپ کو کبھی کوئی مسئلہ درپیش ہو، تو آپ اپنے سسٹم کو اپ ڈیٹ سے پہلے لیے گئے اسنیپ شاٹ پر واپس لے جا سکتے ہیں۔ بس ری اسٹارٹ کریں اور بوٹ لوڈنگ مینیو میں اپ ڈیٹ شروع کرنے سے پہلے والا اسنیپ شاٹ منتخب کریں۔

![bootloader](images/bootloader.webp)

اگر کسی طرح آپ کی کنفیگریشن فائلیں خراب ہو گئی ہیں، تو آپ ٹرمینل میں `omarchy reinstall` استعمال کر کے Omarchy کو دوبارہ انسٹال بھی کر سکتے ہیں۔ یہ تمام ڈیفالٹ Omarchy پیکیجز دوبارہ انسٹال کرے گا، آپ کو stable پر ڈال دے گا اور جو پیکیجز بہت نئے ہیں انہیں ڈاؤن گریڈ کر دے گا، اور تمام کنفیگریشن فائلیں ری سیٹ کر دے گا۔ نوٹ کریں کہ ایسا کرنے سے Omarchy ڈیفالٹس میں آپ کی تمام صارف کنفیگ تبدیلیاں اوور رائٹ ہو جائیں گی!
