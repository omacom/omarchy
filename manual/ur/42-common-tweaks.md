# عام تبدیلیاں

یہ Omarchy سیٹ اپ میں عام حسبِ ضرورت تبدیلیوں کا مجموعہ ہے۔ یہ جان لیں کہ سسٹم اپڈیٹس کے لیے کبھی کبھار بعض کنفگز کو ان کی اصل حالت میں بحال کرنا ضروری ہو سکتا ہے۔ اگر ایسا ہو تو آپ کی تبدیلیاں ضائع نہیں ہوں گی، بلکہ اصل فائل کے ساتھ `.bak.<timestamp>` فائل میں رکھ دی جائیں گی۔

اگر آپ کچھ بگاڑ دیں تو آپ Omarchy مینو میں _Update > Config_ کے ذریعے انفرادی کنفگز کو ان کے اصل سیٹ اپ پر بحال کر سکتے ہیں۔ اگر آپ _واقعی_ سب کچھ بگاڑ دیں تو آپ `omarchy reinstall configs` کے ذریعے تمام کنفگز ری سیٹ کر سکتے ہیں، یا `omarchy reinstall` کے ساتھ ہر ڈیفالٹ پیکج اور کنفگ دوبارہ انسٹال کر سکتے ہیں۔

### تمام ٹرے آئیکنز ہر وقت ظاہر کریں

بطور ڈیفالٹ، ٹرے آئیکنز، جیسے Dropbox، 1password یا Steam، ٹرے ایکسپینڈر تیر کے پیچھے چھپے ہوتے ہیں، جو آپ کے اس پر ہوور کرنے پر انہیں ظاہر کر دیتا ہے۔ اگر آپ چاہتے ہیں کہ وہ ہر وقت ظاہر رہیں تو ٹرے آئیکن مینیجر کھولنے کے لیے ایکسپینڈر تیر پر دائیں کلک کریں، پھر جن آئیکنز کو آپ نظر آنے والا رکھنا چاہتے ہیں انہیں پن کر دیں (آپ انہیں بھی چھپا سکتے ہیں جنہیں آپ کبھی دیکھنا ہی نہیں چاہتے)۔

### گول ونڈو کونے

Omarchy کا ڈیفالٹ ڈیزائن چوکور کونوں والا ہے، لیکن اگر آپ اسے تھوڑا نرم کرنا چاہتے ہیں تو Omarchy مینو میں _Appearance > Windows > Window Corners > Rounded Corners_ منتخب کریں، یا `omarchy hyprland corners rounded` چلائیں۔ _Theme Corners_ اس پر واپس چلا جاتا ہے جو تھیم استعمال کرتی ہے۔ اپنا ریڈیس خود منتخب کرنے کے لیے _Theme Corners_ (`omarchy hyprland corners theme`) پر ہی رہیں، کیونکہ Rounded اور Sharp آپ کی کنفگ کے بعد لوڈ ہوتے ہیں اور اسے اوور رائیڈ کر دیتے ہیں، اور `~/.config/hypr/looknfeel.lua` میں rounding کو ان کمنٹ کریں:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### ونڈو گیپس ختم کریں

لیپ ٹاپ ڈسپلے پر کچھ لوگ ونڈو گیپس پر کوئی پکسل ضائع نہ کرنے کو ترجیح دیتے ہیں (یا حتیٰ کہ ٹاپ بار پر بھی نہیں، جسے آپ `Super + Shift + Space` کے ساتھ بند کر سکتے ہیں)۔ آپ `Super + Shift + Backspace` کے ساتھ تمام گیپس اور بارڈرز بند کر سکتے ہیں، یا `~/.config/hypr/looknfeel.lua` کے اس سیکشن میں کمنٹس ہٹا کر انہیں مستقل طور پر ختم کر سکتے ہیں:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
