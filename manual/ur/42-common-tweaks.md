# عام تبدیلیاں

یہ Omarchy سیٹ اپ کی عام موافقتوں کا مجموعہ ہے۔ جان لیں کہ سسٹم اپ ڈیٹس کے لیے کبھی کبھار کچھ کنفگس کو ان کی اصل حالت میں بحال کرنا ضروری ہو سکتا ہے۔ اگر ایسا ہوتا ہے تو آپ کی تبدیلیاں ضائع نہیں ہوں گی، بلکہ اسی ڈائرکٹری میں ایک `.bak` فائل میں رکھ دی جائیں گی۔

اگر آپ کچھ خراب کر دیں تو آپ Omarchy مینیو میں _اپ ڈیٹ کریں > Config_ کے ذریعے انفرادی کنفگس کو ان کے اصل سیٹ اپ میں بحال کر سکتے ہیں۔ اگر آپ _واقعی_ سب کچھ خراب کر دیں تو آپ `omarchy-reinstall` کے ذریعے تمام کنفگس دوبارہ لگا سکتے ہیں۔

### تمام ٹرے آئیکن ہمیشہ ظاہر کریں

طے شدہ طور پر، ٹرے آئیکن، جیسے Dropbox، 1password، یا Steam، ٹرے پھیلانے والے تیر کے پیچھے چھپے ہوتے ہیں، جو اس پر گُھمانے پر انہیں ظاہر کرتا ہے۔ اگر آپ چاہتے ہیں کہ یہ ہمیشہ سامنے رہیں تو ٹرے آئیکن منیجر کھولنے کے لیے پھیلانے والے تیر پر دایاں کلک کریں، پھر جن آئیکنز کو آپ نظر آتے رکھنا چاہتے ہیں انہیں لگا دیں (آپ ان کو بھی چھپا سکتے ہیں جنہیں آپ کبھی نہیں دیکھنا چاہتے)۔

### گول ونڈو کونے

Omarchy کا طے شدہ ڈیزائن چوکور کونوں کا ہے، لیکن اگر آپ اسے تھوڑا نرم کرنا پسند کرتے ہیں تو آپ `~/.config/hypr/looknfeel.lua` بدل سکتے ہیں تاکہ rounding اب تبصرے میں نہ رہے:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### ونڈو فاصلے ہٹائیں

لیپ ٹاپ ڈسپلے پر، کچھ لوگ ونڈو فاصلوں پر (یا حتی کہ مینیُو بار پر، جسے آپ `Super + Shift + Space` سے ٹوگل آف کر سکتے ہیں) کوئی پکسل ضائع نہ کرنا پسند کرتے ہیں۔ آپ `Super + Shift + Backspace` سے تمام فاصلے اور بارڈرز ٹوگل آف کر سکتے ہیں، یا `~/.config/hypr/looknfeel.lua` کے اس حصے میں تبصرے ہٹا کر انہیں مستقل طور پر ہٹا سکتے ہیں:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
