# ٹوگلز، آئیڈل اور اسکرین سیور

روزمرہ آپ جو کچھ بدلتے ہیں، اس کا بڑا حصہ اصل میں کوئی سیٹنگ نہیں ہوتا۔ یہ ایک ایسا موڈ ہوتا ہے جسے آپ ایک گھنٹے کے لیے آن کرتے ہیں اور پھر آف کر دیتے ہیں: دیر تک کام کرتے ہوئے نائٹ لائٹ، پریزنٹیشن دیتے ہوئے ڈسٹرب نہ کریں، کچھ دیکھتے ہوئے بیدار رہنا۔ Omarchy انہیں ٹوگلز کہتا ہے، اور یہ سب ایک ہی طرح کام کرتے ہیں — ایک ہاٹ کی، ایک مینو انٹری، اور ایک کمانڈ، سب ایک ہی سوئچ کو دباتے ہیں۔

### ٹوگل مینو

`Super + Ctrl + O` براہِ راست _ٹرگر > ٹوگل_ کھولتا ہے، یا آپ Omarchy مینو (`Super + Space`) سے وہاں جا سکتے ہیں۔ اس فہرست میں موجود ہر چیز ایک ایسا سوئچ ہے جسے آپ یہ سوچے بغیر پلٹ سکتے ہیں کہ اس کی حالت کہاں محفوظ ہے۔ ڈیسک ٹاپ کیسا نظر آتا ہے، اس کے سوئچ اس کے ساتھ ہی، _ظاہری شکل_ کے تحت بیٹھے ہیں۔

ٹرمینل سے، وہی سوئچ `omarchy toggle <thing>` ہیں۔ پورا گروپ دیکھنے کے لیے اکیلا `omarchy toggle` چلائیں۔

| ٹوگل | ہاٹ کی | کمانڈ |
| ------ | ------ | ------- |
| نائٹ لائٹ | — | `omarchy toggle nightlight` |
| اطلاعات خاموش کرنا | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| بیدار رہنا (آئیڈل لاک نہیں) | `Super + Ctrl + I` | `omarchy toggle idle` |
| کریش کیپچر | — | `omarchy toggle crash-capture` |
| اسکرین سیور | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) تھیم سنک | — | `omarchy toggle theme sync` |
| مینو بار | `Super + Shift + Space` | `omarchy toggle bar` |
| مکمل اسکرین ڈیسک ٹاپ (نہ بار، نہ گیپس) | `Super + Ctrl + Alt + F` | `omarchy toggle fullscreen desktop` |
| اینیمیٹشنز، بلر اور سائے | — | `omarchy toggle animations` |
| ٹچ پیڈ | `XF86TouchpadToggle` | `omarchy device touchpad` |
| ٹچ اسکرین | — | `omarchy device touchscreen` |
| سسپینڈ | — | `omarchy toggle suspend` |
| ہائبرڈ GPU | — | `omarchy device gpu hybrid` |

ٹچ پیڈ، ٹچ اسکرین، اور ہائبرڈ GPU سوئچ _ٹرگر > ہارڈویئر_ (`Super + Ctrl + H`) کے تحت رہتے ہیں نہ کہ ٹوگل کے تحت، کیونکہ یہ صرف تبھی نظر آتے ہیں جب آپ کے پاس واقعی وہ ہارڈویئر موجود ہو۔ ٹچ پیڈ اور ٹچ اسکرین والے سوئچ Hyprland ری لوڈ کے بعد بھی برقرار رہتے ہیں — غیر فعال ڈیوائس کا نام ایک چھوٹی اسٹیٹ فائل میں محفوظ کر دیا جاتا ہے جسے Hyprland اسٹارٹ اپ پر پڑھتا ہے تاکہ اسے دوبارہ غیر فعال کر دے۔

_ظاہری شکل_ میں مینو بار اور اینیمیٹشنز ہیں، اس کے علاوہ چند ایسی چیزیں بھی جو `omarchy toggle` کمانڈز نہیں ہیں لیکن اسی طرح برتاؤ کرتی ہیں: بار میں بیٹری کا فیصد، ڈیفالٹ ورک اسپیس لے آؤٹ، اور _ونڈوز_ کے تحت، ونڈو گیپس (`Super + Shift + Backspace`) اور 1-ونڈو مربع پہلو تناسب (`Super + Ctrl + Backspace`)۔

جب Hyprland کے پاس ڈرا کرنے کے لیے کوئی GPU نہ ہو اور وہ اس کے بجائے CPU پر رینڈر کرے (llvmpipe)، جیسے ان Macs پر جن کا GPU ابھی سپورٹ نہیں ہوتا، زیادہ تر ورچوئل مشینوں میں، یا جب کوئی گرافکس ڈرائیور لوڈ نہ ہو پائے، تو Omarchy اس سیشن کے لیے اینیمیٹشنز، بلر اور سائے بند کر دیتا ہے اور ایک اطلاع کے ساتھ آپ کو ایک بار بتا دیتا ہے۔ _ظاہری شکل > اینیمیٹشنز آن_ انہیں واپس لے آتا ہے، اور Omarchy اسے بعد کے سیشنز کے لیے بھی یاد رکھتا ہے۔

ان میں سے زیادہ تر صرف `~/.local/state/omarchy/toggles/` کے تحت ایک فلیگ فائل ہیں۔ اگر آپ کسی اسکرپٹ میں ان پر برانچ کرنا چاہتے ہیں، تو `omarchy-toggle-enabled` آپ کو تلاش کرنے پر مجبور کرنے کے بجائے ایک ایگزٹ کوڈ دیتا ہے:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

فلیگز کے نام آف حالت کے لیے رکھے گئے ہیں — `screensaver-off`، `suspend-off`، `bar-off` — اس لیے ان کی موجودگی کا مطلب ہے کہ فیچر غیر فعال ہے۔

### بار میں انڈیکیٹرز

جب کوئی موڈ آن ہوتا ہے، تو آپ کو اوپری بار کے بیچ میں گھڑی کے ساتھ ایک چھوٹا گلائف ملتا ہے۔ یہی انڈیکیٹرز وِجٹ ہے، اور یہ اسکرین ریکارڈنگ، زیرِ التوا ریمائنڈرز، نائٹ لائٹ، ڈسٹرب نہ کریں، اور بیدار رہنا رکھتا ہے، اس کے علاوہ جب پاس ورڈ کے بغیر sudo آن ہو یا کوئی ریموٹ سیشن سے جڑا ہو تو انتباہات بھی دیتا ہے۔

غیر فعال انڈیکیٹرز چھپے رہتے ہیں۔ بار پر کہیں بھی ہوور کریں اور یہ مدھم ہو کر نمودار ہو جاتے ہیں، تاکہ آپ اس کی ہاٹ کی جانے بغیر کسی ایک کو آن کرنے کے لیے کلک کر سکیں۔ کسی فعال انڈیکیٹر پر کلک کرنے سے وہ دوبارہ آف ہو جاتا ہے۔ اگر آپ چاہتے ہیں کہ یہ سب ہر وقت نظر آئیں، تو `~/.config/omarchy/shell.json` میں `omarchy.indicators` انٹری پر `alwaysShow` کو `true` پر سیٹ کریں — بار وِجٹس کیسے ترتیب دیے جاتے ہیں، اس کے لیے [اوپری بار](05-the-top-bar.md) دیکھیں۔

### نائٹ لائٹ

نائٹ لائٹ اسکرین کو 4000K تک گرم کر دیتی ہے، اور اسے دوبارہ ٹوگل کرنے سے یہ واپس 6500K پر آ جاتی ہے۔ اسے ٹوگل مینو (`Super + Ctrl + O`) سے یا `omarchy toggle nightlight` کے ساتھ پلٹیں۔ یہ hyprsunset کے ذریعے چلتی ہے، جسے ٹوگل آپ کے لیے شروع کر دیتا ہے اگر یہ پہلے سے نہ چل رہی ہو۔

بائی ڈیفالٹ hyprsunset آپ کی اسکرین کے ساتھ بالکل کچھ نہیں کرتی۔ `~/.config/hypr/hyprsunset.conf` ایک شناختی پروفائل کے ساتھ آتی ہے، خاص اس لیے کہ ڈسپلے اس وقت تک اچھوتا رہے جب تک آپ گرمجوشی نہ مانگیں۔ اگر آپ چاہتے ہیں کہ یہ گھڑی کے حساب سے بدلے، تو اسے ایک ٹائم پروفائل سے بدل دیں:

```
profile {
    time = 20:00
    temperature = 4000
}
```

پھر `~/.config/hypr/autostart.lua` میں `o.launch_on_start("hyprsunset")` شامل کر کے لاگ ان پر hyprsunset شروع کریں۔ ٹوگل کے ذریعے استعمال ہونے والی 4000K/6500K جوڑی طے شدہ ہے، اس لیے اگر آپ کوئی مختلف درجہ حرارت چاہتے ہیں تو کنفگ فائل ہی وہ جگہ ہے جہاں جانا ہے۔

### ڈسٹرب نہ کریں

`Super + Ctrl + Alt + ,` اطلاعات کو خاموش کر دیتا ہے۔ جب یہ آن ہو تو کوئی ٹوسٹ پاپ اپ نہیں ہوتا، اور کاٹا ہوا گھنٹی والا انڈیکیٹر بار میں بیٹھا آپ کو یاد دلاتا ہے کہ ڈیسک ٹاپ خاموش کیوں ہو گیا ہے۔

تاہم، کچھ بھی ضائع نہیں ہوتا۔ خاموش کی گئی اطلاعات کو روک لیا جاتا ہے: آخری چند کو `Super + Shift + Alt + ,` کے ساتھ واپس اسکرین پر رکھیں۔ باقی کے لیے [نوٹسز](10-notices.md) دیکھیں۔

تین قسم کے پیغامات پھر بھی گزر جاتے ہیں: کسی ایسی کارروائی کے لیے Omarchy کے اپنے تصدیقی ٹوسٹس جو آپ نے ابھی کی ہے (“تھیم تبدیل ہو گئی”، “اسکرین شاٹ محفوظ ہو گیا”)، کمانڈ لائن سے بھیجے گئے اہم الرٹس، اور تصدیقی کوڈز۔ چیٹ ایپس جو ہر چیز کو اہم نشان زد کر کے آپ کے سامنے زبردستی آنے کی کوشش کرتی ہیں، وہ اہل نہیں ہیں۔

### آئیڈل

Omarchy شیل آئیڈل برتاؤ کی مالک ہے، اور اوقات `~/.config/omarchy/shell.json` میں ایک ٹاپ لیول `idle` بلاک ہیں:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

دونوں نمبر اس لمحے سے گنے گئے سیکنڈ ہیں جب آپ آئیڈل ہوئے — ایک دوسرے سے نہیں۔ اس لیے ڈیفالٹس کے ساتھ، اسکرین سیور ڈھائی منٹ بعد آتا ہے اور لاک اسکرین پانچ منٹ پر قابض ہو جاتی ہے، چاہے اسکرین سیور چلا ہو یا نہ چلا ہو۔ فائل محفوظ کریں اور شیل فوراً نئے اوقات اٹھا لیتی ہے۔

اگر آپ لاک کی آخری حد سے پہلے اسکرین سیور کو برخاست کر دیتے ہیں، تو یہ سرگرمی شمار ہوتی ہے اور زیرِ التوا لاک منسوخ ہو جاتی ہے۔ آپ کو اپنی مشین پر ایک نظر ڈالنے پر لاک آؤٹ نہیں کیا جاتا۔

آئیڈل پر لاک کرنا مکمل طور پر روکنے کے لیے، `Super + Ctrl + I` — یا `omarchy toggle idle` — بیدار رہنا آن کر دیتا ہے، اور کافی کپ والا انڈیکیٹر بار میں نمودار ہو جاتا ہے۔ یہی وہ ہے جسے ایک لمبی پریزنٹیشن یا ایک بلڈ سے پہلے دبانا چاہیے جسے آپ دیکھنا چاہتے ہیں۔ معمول پر واپس جانے کے لیے اسے دوبارہ دبائیں۔ `omarchy toggle idle status` موجودہ حالت کو JSON کے طور پر پرنٹ کرتا ہے اگر آپ کو کسی اسکرپٹ سے اس کی ضرورت ہو۔

یہ لاک کرنے اور اسکرین سیور کے بارے میں ہے، پاور کے بارے میں نہیں۔ سسپینڈ اور ہائبرنیشن کی اپنی سیٹ اپ [سسٹم سلیپ](36-system-sleep.md) میں ہے۔

### اسکرین سیور

Omarchy کا اسکرین سیور ASCII آرٹ ہے جو بے ترتیب ٹیکسٹ افیکٹس سے گزرتا ہے، ہر مانیٹر پر ایک انسٹنس۔ کوئی بھی کلید یا ماؤس کی حرکت اس سے باہر نکال دیتی ہے۔

آپ اسے _سسٹم > اسکرین سیور_ (`Super + Esc`) سے مانگ پر شروع کر سکتے ہیں، جو اسے زبردستی اوپر لے آتا ہے چاہے آپ نے آئیڈل اسکرین سیور آف کر رکھا ہو۔ بائی ڈیفالٹ اس کے ساتھ کوئی ہاٹ کی بندھی ہوئی نہیں ہے۔

`omarchy toggle screensaver` وہ ہے جو آئیڈل والے کو آف کرتا ہے، اگر آپ کام کرنے سے سیدھا لاک ہونے کی طرف جانا پسند کریں۔ کوئی بھی کلید، کلک، اسکرول یا ماؤس کی حرکت اسے بند کر دیتی ہے۔

یہ جو لوگو ڈرا کرتا ہے، اسے بدلنا آپ کے اختیار میں ہے، _ظاہری شکل > برانڈنگ > اسکرین سیور_ کے تحت۔ ایک png یا svg اپ لوڈ کریں اور Omarchy اسے ASCII میں تبدیل کر دیتا ہے۔ [برانڈنگ](41-branding.md) دیکھیں۔

### لاک اسکرین

`Super + Ctrl + L` مشین کو لاک کر دیتا ہے۔ یہ Omarchy شیل سے لاک اسکرین چلاتا ہے، ڈسپلے کو خالی کر دیتا ہے، آپ کے کی بورڈ لے آؤٹ کو پہلے والے پر ری سیٹ کر دیتا ہے تاکہ آپ غلط حروف تہجی میں اپنا پاس ورڈ نہ ٹائپ کر رہے ہوں، اور — اگر آپ نے اسے چلا رکھا ہے — باہر جاتے ہوئے 1Password کو لاک کر دیتا ہے۔

لاک اسکرین ایک پاس ورڈ لیتی ہے، اور ایک بار جب آپ نے فنگر پرنٹ سیٹ اپ کر لیا ہو تو یہ فنگر پرنٹ بھی لے گی۔ یہ، اور تصدیق کے دیگر طریقے، [ہارڈویئر تصدیق](37-hardware-authentication.md) میں شامل ہیں۔
