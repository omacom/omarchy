# ٹوگلز، آئیڈل اور اسکرین سیور

روزمرہ میں آپ جو کچھ بدلتے ہیں، اس کا بڑا حصہ اصل میں کوئی سیٹنگ نہیں ہوتا۔ یہ ایک موڈ ہوتا ہے جسے آپ ایک گھنٹے کے لیے آن کرتے ہیں اور پھر آف کر دیتے ہیں: دیر تک کام کرتے ہوئے نائٹ لائٹ، پریزنٹیشن دیتے ہوئے ڈو ناٹ ڈسٹرب، کچھ دیکھتے ہوئے جاگتے رہنا۔ Omarchy انھیں ٹوگلز کہتا ہے، اور یہ سب ایک ہی طرح کام کرتے ہیں — ایک ہاٹ کی، ایک مینو انٹری، اور ایک کمانڈ، تینوں ایک ہی سوئچ کو چلاتے ہیں۔

### ٹوگل مینو

`Super + Ctrl + O` براہِ راست _Trigger > Toggle_ کھولتا ہے، یا آپ Omarchy مینو (`Super + Space`) سے وہاں جا سکتے ہیں۔ اس فہرست میں موجود ہر چیز ایک سوئچ ہے جسے آپ یہ سوچے بغیر فلپ کر سکتے ہیں کہ اس کی حالت کہاں محفوظ ہے۔ ڈیسک ٹاپ کی شکل سے متعلق سوئچز اس کے ساتھ ہی، _Appearance_ کے تحت موجود ہیں۔

ٹرمینل سے، وہی سوئچز `omarchy toggle <thing>` ہیں۔ پورا گروپ دیکھنے کے لیے اکیلے `omarchy toggle` چلائیں۔

| ٹوگل | ہاٹ کی | کمانڈ |
| ------ | ------ | ------- |
| نائٹ لائٹ | — | `omarchy toggle nightlight` |
| نوٹیفکیشنز خاموش کریں | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| جاگتے رہیں (کوئی آئیڈل لاک نہیں) | `Super + Ctrl + I` | `omarchy toggle idle` |
| کریش کیپچر | — | `omarchy toggle crash-capture` |
| اسکرین سیور | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) تھیم سنک | — | `omarchy toggle theme sync` |
| مینو بار | `Super + Shift + Space` | `omarchy toggle bar` |
| ٹچ پیڈ | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| ٹچ اسکرین | — | `omarchy toggle touchscreen` |
| سسپینڈ | — | `omarchy toggle suspend` |
| ہائبرڈ GPU | — | `omarchy toggle hybrid gpu` |

ٹچ پیڈ، ٹچ اسکرین، اور ہائبرڈ GPU سوئچز Toggle کے بجائے _Trigger > Hardware_ (`Super + Ctrl + H`) کے تحت موجود ہیں، کیونکہ یہ صرف تبھی نظر آتے ہیں جب آپ کے پاس واقعی وہ ہارڈویئر موجود ہو۔ ٹچ پیڈ اور ٹچ اسکرین والے Hyprland ری لوڈ کے بعد بھی برقرار رہتے ہیں — غیر فعال ڈیوائس کا نام ایک چھوٹی اسٹیٹ فائل میں محفوظ کر دیا جاتا ہے جسے Hyprland اسٹارٹ اپ پر پڑھ کر اسے دوبارہ غیر فعال کر دیتا ہے۔

_Appearance_ میں مینو بار اور اینیمیشنز موجود ہیں، اس کے علاوہ چند ایسی چیزیں بھی جو `omarchy toggle` کمانڈز نہیں ہیں لیکن اسی طرح برتاؤ کرتی ہیں: بار میں بیٹری فیصد، ڈیفالٹ ورک اسپیس لے آؤٹ، اور _Windows_ کے تحت، ونڈو گیپس (`Super + Shift + Backspace`) اور 1-ونڈو اسکوائر اسپیکٹ (`Super + Ctrl + Backspace`)۔

ان میں سے زیادہ تر صرف `~/.local/state/omarchy/toggles/` کے تحت ایک فلیگ فائل ہیں۔ اگر آپ کسی اسکرپٹ میں ان پر منحصر برانچ کرنا چاہتے ہیں، تو `omarchy-toggle-enabled` آپ کو تلاش کرنے کی زحمت کے بغیر ایک ایگزٹ کوڈ دیتا ہے:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

فلیگز کے نام آف حالت کے لیے رکھے گئے ہیں — `screensaver-off`، `suspend-off`، `bar-off` — لہٰذا ان کی موجودگی کا مطلب ہے کہ فیچر غیر فعال ہے۔

### بار میں انڈیکیٹرز

جب کوئی موڈ آن ہوتا ہے، تو آپ کو گھڑی کے ساتھ اوپری بار کے وسط میں ایک چھوٹا گلِف نظر آتا ہے۔ یہ انڈیکیٹرز وِجٹ ہے، اور اس میں ڈکٹیشن، اسکرین ریکارڈنگ، زیرِ التوا ریمائنڈرز، نائٹ لائٹ، ڈو ناٹ ڈسٹرب، اور جاگتے رہنا شامل ہیں۔

غیر فعال انڈیکیٹرز چھپے رہتے ہیں۔ بار پر کہیں بھی ہوور کریں اور یہ مدھم ہو کر ظاہر ہو جاتے ہیں، تاکہ آپ اس کی ہاٹ کی جانے بغیر کسی ایک پر کلک کر کے اسے آن کر سکیں۔ کسی فعال انڈیکیٹر پر کلک کرنے سے وہ دوبارہ آف ہو جاتا ہے۔ اگر آپ ان سب کو ہر وقت دیکھنا پسند کریں، تو `~/.config/omarchy/shell.json` میں `omarchy.indicators` انٹری پر `alwaysShow` کو `true` پر سیٹ کریں — بار وِجٹس کو کیسے ترتیب دیا جاتا ہے، اس کے لیے [اوپری بار](05-the-top-bar.md) دیکھیں۔

### نائٹ لائٹ

نائٹ لائٹ اسکرین کو 4000K تک گرم کر دیتی ہے، اور اسے دوبارہ ٹوگل کرنے سے یہ واپس 6500K پر آ جاتی ہے۔ اسے ٹوگل مینو (`Super + Ctrl + O`) سے یا `omarchy toggle nightlight` کے ساتھ فلپ کریں۔ یہ hyprsunset کے ذریعے چلتی ہے، جسے اگر یہ پہلے سے نہ چل رہا ہو تو ٹوگل آپ کے لیے شروع کر دیتا ہے۔

بائی ڈیفالٹ hyprsunset آپ کی اسکرین کے ساتھ کچھ بھی نہیں کرتا۔ `~/.config/hypr/hyprsunset.conf` ایک شناختی پروفائل کے ساتھ آتا ہے، بالکل اس لیے کہ جب تک آپ گرمائش نہ مانگیں، ڈسپلے اچھوتا رہے۔ اگر آپ اس کے بجائے یہ چاہتے ہیں کہ یہ گھڑی کے حساب سے سوئچ ہو، تو اسے ایک ٹائم پروفائل سے بدل دیں:

```
profile {
    time = 20:00
    temperature = 4000
}
```

پھر `~/.config/hypr/autostart.lua` میں `o.launch_on_start("hyprsunset")` شامل کر کے hyprsunset کو لاگ اِن پر شروع کریں۔ ٹوگل کے ذریعے استعمال ہونے والی 4000K/6500K جوڑی طے شدہ ہے، لہٰذا اگر آپ کوئی مختلف درجہ حرارت چاہتے ہیں تو کنفگ فائل ہی وہ جگہ ہے جہاں آپ کو جانا ہوگا۔

### ڈو ناٹ ڈسٹرب

`Super + Ctrl + Alt + ,` نوٹیفکیشنز کو خاموش کر دیتا ہے۔ جب یہ آن ہو تو کوئی ٹوسٹ ظاہر نہیں ہوتا، اور بار میں کاٹی ہوئی گھنٹی والا انڈیکیٹر آپ کو یاد دلاتا رہتا ہے کہ ڈیسک ٹاپ خاموش کیوں ہو گیا ہے۔

تاہم، کچھ بھی ضائع نہیں ہوتا۔ خاموش کی گئی نوٹیفکیشنز روک لی جاتی ہیں: آخری چند کو `Super + Shift + Alt + ,` کے ساتھ واپس اسکرین پر لائیں۔ باقی تفصیل کے لیے [نوٹسز](10-notices.md) دیکھیں۔

دو قسم کے پیغامات پھر بھی گزر جاتے ہیں: آپ کے ابھی کیے گئے کسی عمل کے لیے Omarchy کے اپنے تصدیقی ٹوسٹس ("Theme changed"، "Screenshot saved")، اور کمانڈ لائن سے بھیجے گئے اہم الرٹس۔ چیٹ ایپس جو ہر چیز کو اہم نشان زد کر کے زبردستی آپ کے سامنے آنے کی کوشش کرتی ہیں، وہ اس کے اہل نہیں ہیں۔

### آئیڈل

Omarchy شیل آئیڈل رویے کی مالک ہے، اور اوقات `~/.config/omarchy/shell.json` میں ایک ٹاپ لیول `idle` بلاک ہیں:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

دونوں نمبر آپ کے آئیڈل ہونے کے لمحے سے گنے گئے سیکنڈ ہیں — ایک دوسرے سے نہیں۔ لہٰذا ڈیفالٹس کے ساتھ، اسکرین سیور ڈھائی منٹ کے بعد آتا ہے اور لاک اسکرین پانچ منٹ پر قابض ہو جاتی ہے، چاہے اسکرین سیور چلا ہو یا نہ چلا ہو۔ فائل محفوظ کریں اور شیل فوراً نئے اوقات اپنا لیتی ہے۔

اگر آپ لاک کی آخری حد سے پہلے اسکرین سیور کو برخاست کر دیتے ہیں، تو یہ سرگرمی شمار ہوتا ہے اور زیرِ التوا لاک منسوخ ہو جاتا ہے۔ آپ کو اپنی مشین پر ایک نظر ڈالنے پر لاک آؤٹ نہیں کیا جاتا۔

آئیڈل پر لاک کرنا مکمل طور پر روکنے کے لیے، `Super + Ctrl + I` — یا `omarchy toggle idle` — جاگتے رہنا آن کر دیتا ہے، اور بار میں کافی کپ انڈیکیٹر ظاہر ہو جاتا ہے۔ یہی وہ ہے جسے آپ کو ایک لمبی پریزنٹیشن یا اس بلڈ سے پہلے دبانا چاہیے جسے آپ دیکھنا چاہتے ہیں۔ معمول پر واپس جانے کے لیے اسے دوبارہ دبائیں۔ اگر آپ کو کسی اسکرپٹ سے اس کی ضرورت ہو تو `omarchy toggle idle status` موجودہ حالت کو JSON کے طور پر پرنٹ کرتا ہے۔

یہ لاک کرنے اور اسکرین سیور کے بارے میں ہے، پاور کے بارے میں نہیں۔ سسپینڈ اور ہائبرنیشن کی اپنی ترتیب [سسٹم سلیپ](36-system-sleep.md) میں ہے۔

### اسکرین سیور

Omarchy کا اسکرین سیور ASCII آرٹ ہے جو بے ترتیب ٹیکسٹ ایفیکٹس کے ساتھ چلتا ہے، فی مانیٹر ایک انسٹنس۔ کوئی بھی کی یا ماؤس کی حرکت اس سے باہر نکال دیتی ہے۔

آپ اسے _System > Screensaver_ (`Super + Esc`) سے عندالطلب شروع کر سکتے ہیں، جو اسے زبردستی اوپر لے آتا ہے چاہے آپ نے آئیڈل اسکرین سیور آف کر رکھا ہو۔ بائی ڈیفالٹ اس کے لیے کوئی ہاٹ کی باؤنڈ نہیں ہے۔

`omarchy toggle screensaver` آئیڈل والے کو آف کرتا ہے، اگر آپ کام سے سیدھا لاک ہونے کو ترجیح دیں۔ کوئی بھی کی، کلک، اسکرول یا ماؤس کی حرکت اسے بند کر دیتی ہے۔

یہ جو لوگو بناتا ہے، اسے بدلنا آپ کے اختیار میں ہے، _Appearance > Branding > Screensaver_ کے تحت۔ ایک png یا svg اپ لوڈ کریں اور Omarchy اسے ASCII میں بدل دیتا ہے۔ [برانڈنگ](41-branding.md) دیکھیں۔

### لاک اسکرین

`Super + Ctrl + L` مشین کو لاک کر دیتا ہے۔ یہ Omarchy شیل سے لاک اسکرین چلاتا ہے، ڈسپلے کو خالی کر دیتا ہے، آپ کے کی بورڈ لے آؤٹ کو پہلے والے پر ری سیٹ کر دیتا ہے تاکہ آپ غلط حروفِ تہجی میں اپنا پاس ورڈ نہ ٹائپ کر رہے ہوں، اور — اگر آپ نے اسے چلا رکھا ہو — تو جاتے جاتے 1Password کو لاک کر دیتا ہے۔

لاک اسکرین ایک پاس ورڈ لیتی ہے، اور جب آپ فنگر پرنٹ ترتیب دے لیں گے تو یہ فنگر پرنٹ بھی لے گی۔ اس، اور تصدیق کے دیگر طریقوں، کا احاطہ [ہارڈویئر تصدیق](37-hardware-authentication.md) میں کیا گیا ہے۔
