# ٹوگلز، Idle اور اسکرین سیور

روزمرہ میں آپ جو بہت کچھ بدلتے ہیں وہ اصل میں کوئی سیٹنگ نہیں ہوتی۔ یہ ایک موڈ ہوتا ہے جسے آپ ایک گھنٹے کے لیے آن کرتے ہیں اور پھر آف کر دیتے ہیں: دیر تک کام کرتے ہوئے نائٹ لائٹ، پریزنٹیشن دیتے ہوئے ڈسٹرب نہ کریں، کچھ دیکھتے ہوئے جاگتے رہیں۔ Omarchy انہیں ٹوگلز کہتا ہے، اور یہ سب ایک ہی طرح کام کرتے ہیں — ایک ہاٹ کی، ایک مینو انٹری، اور ایک کمانڈ، تینوں ایک ہی سوئچ کو چھوتے ہیں۔

### ٹوگل مینو

`Super + Ctrl + O` براہِ راست _ٹرگر > ٹوگل_ کھولتا ہے، یا آپ Omarchy مینو (`Super + Space`) سے چل کر وہاں پہنچ سکتے ہیں۔ اس فہرست میں موجود ہر چیز ایک ایسا سوئچ ہے جسے آپ یہ سوچے بغیر پلٹ سکتے ہیں کہ اس کی حالت کہاں محفوظ ہے۔ ڈیسک ٹاپ کیسا دکھتا ہے اس کے سوئچ اس کے ساتھ ہی، _ظاہری شکل_ کے تحت بیٹھے ہیں۔

ٹرمینل سے، وہی سوئچ `omarchy toggle <thing>` ہیں۔ پورا گروپ دیکھنے کے لیے اکیلا `omarchy toggle` چلائیں۔

| ٹوگل | ہاٹ کی | کمانڈ |
| ------ | ------ | ------- |
| نائٹ لائٹ | — | `omarchy toggle nightlight` |
| اطلاعات خاموش کریں | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| جاگتے رہیں (کوئی idle لاک نہیں) | `Super + Ctrl + I` | `omarchy toggle idle` |
| کریش کیپچر | — | `omarchy toggle crash-capture` |
| اسکرین سیور | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) تھیم سنک | — | `omarchy toggle theme sync` |
| مینو بار | `Super + Shift + Space` | `omarchy toggle bar` |
| ٹچ پیڈ | `XF86TouchpadToggle` | `omarchy device touchpad` |
| ٹچ اسکرین | — | `omarchy device touchscreen` |
| سسپینڈ | — | `omarchy toggle suspend` |
| ہائبرڈ GPU | — | `omarchy toggle hybrid gpu` |

ٹچ پیڈ، ٹچ اسکرین، اور ہائبرڈ GPU سوئچ ٹوگل کے بجائے _ٹرگر > ہارڈویئر_ (`Super + Ctrl + H`) کے تحت رہتے ہیں، کیونکہ یہ صرف تبھی نظر آتے ہیں جب آپ کے پاس واقعی وہ ہارڈویئر موجود ہو۔ ٹچ پیڈ اور ٹچ اسکرین والے Hyprland ری لوڈ کے بعد بھی برقرار رہتے ہیں — غیر فعال ڈیوائس کا نام ایک چھوٹی اسٹیٹ فائل میں محفوظ کر دیا جاتا ہے جسے Hyprland اسٹارٹ اپ پر پڑھ کر اسے دوبارہ غیر فعال کر دیتا ہے۔

_ظاہری شکل_ میں مینو بار اور اینیمیشنز ہیں، اس کے علاوہ چند ایسی چیزیں بھی جو `omarchy toggle` کمانڈز نہیں ہیں مگر ویسا ہی برتاؤ کرتی ہیں: بار میں بیٹری کا فیصد، ڈیفالٹ ورک اسپیس لے آؤٹ، اور _ونڈوز_ کے تحت، ونڈو گیپس (`Super + Shift + Backspace`) اور 1-ونڈو مربع اسپیکٹ (`Super + Ctrl + Backspace`)۔

جب Hyprland کے پاس ڈرا کرنے کے لیے کوئی GPU نہ ہو اور وہ اس کے بجائے CPU پر رینڈر کرے (llvmpipe)، جیسے ان Macs پر جن کا GPU ابھی سپورٹ نہیں ہوتا، زیادہ تر ورچوئل مشینوں میں، یا جب کوئی گرافکس ڈرائیور لوڈ ہونے میں ناکام ہو جائے، تو Omarchy اس سیشن کے لیے اینیمیشنز، بلر اور شیڈوز بند کر دیتا ہے اور ایک اطلاع کے ساتھ آپ کو ایک بار بتا دیتا ہے۔ _ظاہری شکل > اینیمیشنز آن_ انہیں واپس لے آتا ہے، اور Omarchy اسے بعد کے سیشنز کے لیے بھی یاد رکھتا ہے۔

ان میں سے زیادہ تر بس `~/.local/state/omarchy/toggles/` کے تحت ایک فلیگ فائل ہیں۔ اگر آپ کسی اسکرپٹ میں کسی ایک پر برانچ کرنا چاہیں تو `omarchy-toggle-enabled` آپ کو تلاش کرنے پر مجبور کرنے کے بجائے ایک ایگزٹ کوڈ دیتا ہے:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

فلیگز کے نام آف حالت کے لیے رکھے گئے ہیں — `screensaver-off`، `suspend-off`، `bar-off` — لہٰذا ان کی موجودگی کا مطلب ہے کہ فیچر غیر فعال ہے۔

### بار میں انڈیکیٹرز

جب کوئی موڈ آن ہو تو آپ کو بالائی بار کے وسط میں گھڑی کے ساتھ ایک چھوٹا گلِف ملتا ہے۔ یہ انڈیکیٹرز ویجیٹ ہے، اور اس میں ڈکٹیشن، اسکرین ریکارڈنگ، زیرِ التوا ریمائنڈرز، نائٹ لائٹ، ڈسٹرب نہ کریں، اور جاگتے رہیں شامل ہیں۔

غیر فعال انڈیکیٹرز چھپے رہتے ہیں۔ بار پر کہیں بھی ہوور کریں اور یہ مدھم ہو کر نمودار ہو جاتے ہیں، تاکہ آپ اس کی ہاٹ کی جانے بغیر کسی ایک کو آن کرنے کے لیے اس پر کلک کر سکیں۔ کسی فعال انڈیکیٹر پر کلک کرنے سے وہ واپس آف ہو جاتا ہے۔ اگر آپ انہیں ہر وقت سارے دیکھنا پسند کریں تو `~/.config/omarchy/shell.json` میں `omarchy.indicators` انٹری پر `alwaysShow` کو `true` پر سیٹ کریں — بار ویجیٹس کو کیسے کنفیگر کیا جاتا ہے اس کے لیے [بالائی بار](05-the-top-bar.md) دیکھیں۔

### نائٹ لائٹ

نائٹ لائٹ اسکرین کو 4000K تک گرم کرتی ہے، اور اسے دوبارہ ٹوگل کرنے سے یہ واپس 6500K پر آ جاتی ہے۔ اسے ٹوگل مینو (`Super + Ctrl + O`) سے یا `omarchy toggle nightlight` کے ساتھ پلٹیں۔ اسے hyprsunset چلاتا ہے، جسے ٹوگل آپ کے لیے شروع کر دیتا ہے اگر وہ پہلے سے چل نہ رہا ہو۔

بطورِ ڈیفالٹ hyprsunset آپ کی اسکرین کے ساتھ بالکل کچھ نہیں کرتا۔ `~/.config/hypr/hyprsunset.conf` ایک شناختی پروفائل کے ساتھ آتی ہے، ٹھیک اس لیے کہ ڈسپلے اس وقت تک اچھوتا رہے جب تک آپ گرمجوشی نہ مانگیں۔ اگر آپ اس کے بجائے اسے گھڑی کے حساب سے سوئچ کرانا چاہیں تو اسے ٹائم پروفائل سے بدل دیں:

```
profile {
    time = 20:00
    temperature = 4000
}
```

پھر `~/.config/hypr/autostart.lua` میں `o.launch_on_start("hyprsunset")` شامل کر کے hyprsunset کو لاگ ان پر شروع کریں۔ ٹوگل کے زیرِ استعمال 4000K/6500K جوڑا طے شدہ ہے، لہٰذا اگر آپ مختلف درجہ حرارت چاہتے ہیں تو کنفگ فائل ہی وہ جگہ ہے جہاں جانا ہے۔

### ڈسٹرب نہ کریں

`Super + Ctrl + Alt + ,` اطلاعات کو خاموش کر دیتا ہے۔ جب یہ آن ہو تو کوئی ٹوسٹ نمودار نہیں ہوتا، اور کراس شدہ گھنٹی والا انڈیکیٹر بار میں بیٹھا آپ کو یاد دلاتا رہتا ہے کہ ڈیسک ٹاپ خاموش کیوں ہو گیا ہے۔

کچھ بھی ضائع نہیں ہوتا، البتہ۔ خاموش کی گئی اطلاعات روک لی جاتی ہیں: `Super + Shift + Alt + ,` کے ساتھ آخری چند کو واپس اسکرین پر رکھیں۔ باقی کے لیے [نوٹسز](10-notices.md) دیکھیں۔

دو قسم کے پیغامات پھر بھی گزر جاتے ہیں: آپ نے ابھی جو کچھ کیا اس کے لیے Omarchy کے اپنے تصدیقی ٹوسٹس ("تھیم تبدیل ہو گئی"، "اسکرین شاٹ محفوظ ہو گیا")، اور کمانڈ لائن سے بھیجے گئے اہم الرٹس۔ چیٹ ایپس جو آپ کے سامنے زبردستی آنے کے لیے ہر چیز کو اہم نشان زد کرتی ہیں وہ اس کے اہل نہیں ہیں۔

### Idle

Omarchy شیل idle رویے کا مالک ہے، اور اوقات `~/.config/omarchy/shell.json` میں ایک اعلیٰ سطحی `idle` بلاک ہیں:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

دونوں نمبر اس لمحے سے گنے گئے سیکنڈز ہیں جب آپ idle ہوئے — ایک دوسرے سے نہیں۔ لہٰذا ڈیفالٹس کے ساتھ، اسکرین سیور ڈھائی منٹ بعد آتا ہے اور لاک اسکرین پانچ منٹ پر قابض ہو جاتی ہے، چاہے اسکرین سیور چلا ہو یا نہ چلا ہو۔ فائل محفوظ کریں اور شیل فوراً نئے اوقات اٹھا لیتا ہے۔

اگر آپ لاک کی آخری حد سے پہلے اسکرین سیور کو برخاست کر دیں تو یہ سرگرمی شمار ہوتی ہے اور زیرِ التوا لاک منسوخ ہو جاتا ہے۔ آپ اپنی مشین پر ایک نظر ڈالنے پر لاک آؤٹ نہیں ہوتے۔

idle ہونے پر لاکنگ کو مکمل طور پر روکنے کے لیے، `Super + Ctrl + I` — یا `omarchy toggle idle` — جاگتے رہیں کو آن کر دیتا ہے، اور کافی کپ انڈیکیٹر بار میں نمودار ہو جاتا ہے۔ یہ وہی ہے جسے ایک لمبی پریزنٹیشن یا اس بلڈ سے پہلے دبانا ہے جسے آپ دیکھنا چاہتے ہیں۔ معمول پر واپس جانے کے لیے اسے دوبارہ دبائیں۔ `omarchy toggle idle status` موجودہ حالت کو JSON کے طور پر پرنٹ کرتا ہے اگر آپ کو کسی اسکرپٹ سے اس کی ضرورت ہو۔

یہ لاکنگ اور اسکرین سیور کے بارے میں ہے، پاور کے بارے میں نہیں۔ سسپینڈ اور ہائبرنیشن کی اپنی سیٹ اپ [سسٹم سلیپ](36-system-sleep.md) میں ہے۔

### اسکرین سیور

Omarchy کا اسکرین سیور بے ترتیب ٹیکسٹ ایفیکٹس سے گزرتی ASCII آرٹ ہے، فی مانیٹر ایک انسٹنس۔ کوئی بھی کلید یا ماؤس کی حرکت اس سے باہر نکال دیتی ہے۔

آپ اسے _سسٹم > اسکرین سیور_ (`Super + Esc`) سے عندالطلب شروع کر سکتے ہیں، جو اسے زبردستی اوپر لے آتا ہے چاہے آپ نے idle اسکرین سیور آف کر رکھا ہو۔ بطورِ ڈیفالٹ اس کے ساتھ کوئی ہاٹ کی بندھی نہیں ہے۔

`omarchy toggle screensaver` وہ ہے جو idle والے کو آف کرتا ہے، اگر آپ کام سے سیدھا لاک ہونے تک جانا پسند کریں۔ کوئی بھی کلید، کلک، اسکرول یا ماؤس کی حرکت اسے بند کر دیتی ہے۔

یہ جو لوگو ڈرا کرتا ہے وہ آپ کا ہے بدلنے کے لیے، _ظاہری شکل > برانڈنگ > اسکرین سیور_ کے تحت۔ ایک png یا svg اپ لوڈ کریں اور Omarchy اسے ASCII میں بدل دیتا ہے۔ [برانڈنگ](41-branding.md) دیکھیں۔

### لاک اسکرین

`Super + Ctrl + L` مشین کو لاک کرتا ہے۔ یہ Omarchy شیل سے لاک اسکرین چلاتا ہے، ڈسپلے کو خالی کرتا ہے، آپ کے کی بورڈ لے آؤٹ کو پہلے والے پر ری سیٹ کرتا ہے تاکہ آپ غلط حروفِ تہجی میں اپنا پاس ورڈ ٹائپ نہ کر رہے ہوں، اور — اگر آپ نے اسے چلا رکھا ہو — باہر نکلتے ہوئے 1Password کو لاک کر دیتا ہے۔

لاک اسکرین ایک پاس ورڈ لیتی ہے، اور ایک بار آپ نے فنگر پرنٹ سیٹ اپ کر لیا تو یہ فنگر پرنٹ بھی لے گی۔ یہ، اور تصدیق کے دیگر طریقے، [ہارڈویئر تصدیق](37-hardware-authentication.md) میں شامل ہیں۔
