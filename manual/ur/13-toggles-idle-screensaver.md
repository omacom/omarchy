# ٹوگلز، آئیڈل اور اسکرین سیور

روزمرہ جو بہت کچھ آپ تبدیل کرتے ہیں وہ واقعی سیٹنگ نہیں ہوتی۔ یہ ایک موڈ ہے جو آپ ایک گھنٹے کے لیے آن کرتے ہیں اور پھر آف کر دیتے ہیں: دیر تک کام کرتے ہوئے نائٹ لائٹ، پیش کرتے ہوئے ڈسٹرب نہ کریں، کچھ دیکھتے ہوئے جاگتے رہیں۔ Omarchy انہیں ٹوگلز کہتا ہے، اور وہ سب ایک ہی طرح کام کرتے ہیں — ایک ہاٹ کی، ایک مینیو انٹری، اور ایک کمانڈ، سب ایک ہی سوئچ کو مارتے ہیں۔

### ٹوگل مینیو

`Super + Ctrl + O` براہ راست _ٹریگر > Toggle_ کھولتا ہے، یا آپ Omarchy مینیو (`Super + Space`) سے وہاں چل سکتے ہیں۔ اس فہرست میں موجود ہر چیز ایک سوئچ ہے جسے آپ یہ سوچے بغیر پلٹ سکتے ہیں کہ ریاست کہاں رہتی ہے۔ ڈیسک ٹاپ کیسا نظر آتا ہے اس کے لیے سوئچ اس کے ساتھ، _ٹریگر > ظاہری شکل_ کے تحت ہیں۔

ٹرمینل سے، وہی سوئچ `omarchy toggle <thing>` ہیں۔ پورا گروپ دیکھنے کے لیے `omarchy toggle` کو اکیلے چلائیں۔

| ٹوگل | ہاٹ کی | کمانڈ |
| ------ | ------ | ------- |
| نائٹ لائٹ | `Super + Ctrl + N` | `omarchy toggle nightlight` |
| نوٹیفکیشنز خاموش کریں | `Super + Ctrl + ,` | `omarchy toggle notification silencing` |
| جاگتے رہیں (کوئی آئیڈل لاک نہیں) | `Super + Ctrl + I` | `omarchy toggle idle` |
| کریش کیپچر | — | `omarchy toggle crash-capture` |
| اسکرین سیور | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) تھیم سنک | — | `omarchy toggle theme sync` |
| مینیُو بار | `Super + Shift + Space` | `omarchy toggle bar` |
| ٹچ پیڈ | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| ٹچ اسکرین | — | `omarchy toggle touchscreen` |
| معطل | — | `omarchy toggle suspend` |
| ہائبرڈ GPU | — | `omarchy toggle hybrid gpu` |

ٹچ پیڈ، ٹچ اسکرین اور ہائبرڈ GPU سوئچ Toggle کے بجائے _ٹریگر > Hardware_ (`Super + Ctrl + H`) کے تحت رہتے ہیں، کیونکہ وہ صرف اس وقت ظاہر ہوتے ہیں جب آپ کے پاس واقعی وہ ہارڈ ویئر ہو۔ ٹچ پیڈ اور ٹچ اسکرین والے Hyprland ری لوڈ کے بعد بھی برقرار رہتے ہیں — غیر فعال آلے کا نام ایک چھوٹی اسٹیٹ فائل میں محفوظ ہے جسے Hyprland اسٹارٹ اپ پر پڑھ کر اسے دوبارہ غیر فعال کرتا ہے۔

_ٹریگر > ظاہری شکل_ میں مینیُو بار اور اینیمیشنز ہیں، علاوہ کچھ ایسی چیزیں جو `omarchy toggle` کمانڈز نہیں ہیں لیکن ایک جیسا سلوک کرتی ہیں: بار میں بیٹری فیصد، ڈیفالٹ ورک اسپیس لے آؤٹ، ونڈو گیپس (`Super + Shift + Backspace`)، اور 1 ونڈو والا مربع پہلو (`Super + Ctrl + Backspace`)۔

ان میں سے زیادہ تر `~/.local/state/omarchy/toggles/` کے تحت بس فلیگ فائل ہیں۔ اگر آپ اسکرپٹ میں کسی ایک پر برانچ کرنا چاہتے ہیں تو، `omarchy-toggle-enabled` آپ کو تلاش کرنے کے بجائے ایگزٹ کوڈ دیتا ہے:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

فلیگز بند حالت کے نام پر ہیں — `screensaver-off`، `suspend-off`، `bar-off` — لہٰذا ان کی موجودگی کا مطلب ہے فیچر غیر فعال ہے۔

### بار میں اشارے

جب کوئی موڈ آن ہو تو، آپ کو گھڑی کے ساتھ اوپری بار کے وسط میں ایک چھوٹا نشان ملتا ہے۔ یہ اشاروں والا وِجِٹ ہے، اور اس میں املا، اسکرین ریکارڈنگ، زیر التوا یاد دہانیاں، نائٹ لائٹ، ڈسٹرب نہ کریں، اور جاگتے رہیں شامل ہیں۔

غیر فعال اشارے چھپے ہوتے ہیں۔ ان کے ارد گرد کے علاقے پر ہوور کریں اور وہ مدھم ہو کر ظاہر ہو جاتے ہیں، تاکہ آپ اس کی ہاٹ کی جانے بغیر کسی ایک پر کلک کر کے اسے آن کر سکیں۔ فعال اشارے پر کلک کرنے سے وہ آف ہو جاتا ہے۔ اگر آپ ان سب کو ہر وقت دیکھنا پسند کرتے ہیں تو، `~/.config/omarchy/shell.json` میں `omarchy.indicators` اندراج پر `alwaysShow` کو `true` پر سیٹ کریں — بار وِجِٹس کیسے کنفیگر ہوتے ہیں اس کے لیے [اوپری بار](05-the-top-bar.md) دیکھیں۔

### نائٹ لائٹ

`Super + Ctrl + N` اسکرین کو 4000K پر گرم کرتا ہے، اور اسے دوبارہ دبانے سے یہ 6500K پر واپس آ جاتا ہے۔ یہ hyprsunset سے چلتا ہے، جسے ٹوگل آپ کے لیے شروع کر دیتا ہے اگر یہ پہلے سے نہ چل رہا ہو۔

بطور ڈیفالٹ hyprsunset آپ کی اسکرین کے ساتھ کچھ نہیں کرتا۔ `~/.config/hypr/hyprsunset.conf` ایک شناختی پروفائل کے ساتھ آتا ہے بالکل اس لیے تاکہ ڈسپلے اس وقت تک اچھوتا رہے جب تک آپ گرمی نہ مانگیں۔ اگر آپ چاہتے ہیں کہ یہ گھڑی کے حساب سے تبدیل ہو تو، اسے وقت پروفائل سے بدل دیں:

```
profile {
    time = 20:00
    temperature = 4000
}
```

پھر `~/.config/hypr/autostart.lua` میں `o.launch_on_start("hyprsunset")` شامل کر کے لاگ ان پر hyprsunset شروع کریں۔ ٹوگل کے ذریعے استعمال ہونے والا 4000K/6500K جوڑا طے شدہ ہے، لہٰذا کانفیگ فائل وہ جگہ ہے جہاں آپ جاتے ہیں اگر آپ مختلف درجہ حرارت چاہتے ہیں۔

### ڈسٹرب نہ کریں

`Super + Ctrl + ,` نوٹیفکیشنز خاموش کر دیتا ہے۔ جب یہ آن ہو تو کوئی ٹوسٹ نہیں آتا، اور کٹی ہوئی گھنٹی والا اشارہ بار میں بیٹھا آپ کو یاد دلاتا ہے کہ ڈیسک ٹاپ کیوں خاموش ہو گیا ہے۔

یقیناً کچھ بھی ضائع نہیں ہوتا۔ خاموش کی گئی نوٹیفکیشن سیدھا آپ کی نوٹیفکیشن تاریخ میں لکھی جاتی ہے، جو بالکل وہی ریکارڈ ہے جو آپ اس وقت چاہتے ہیں جب آپ واپس آئیں اور سوچیں کہ آپ کیا بھول گئے۔ اسے `Super + Shift + Alt + ,` سے کھولیں۔ نوٹیفکیشن کی باقی کہانی کے لیے [نوٹس](10-notices.md) دیکھیں۔

دو قسم کے پیغامات اب بھی گزر جاتے ہیں: آپ نے جو کچھ ابھی کیا اس کے لیے Omarchy کے اپنے تصدیقی ٹوسٹ ("Theme changed"، "Screenshot saved")، اور کمانڈ لائن سے بھیجے گئے اہم (critical) انتباہات۔ چیٹ ایپس جو آپ کے سامنے زبردستی آنے کے لیے ہر چیز کو اہم نشان زد کرتی ہیں، اہل نہیں ہوتیں۔

### آئیڈل

Omarchy shell آئیڈل رویے کا مالک ہے، اور اوقات `~/.config/omarchy/shell.json` میں اعلیٰ سطح کا `idle` بلاک ہیں:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

دونوں اعداد اس لمحے سے گنے گئے سیکنڈز ہیں جب آپ آئیڈل ہوئے — ایک دوسرے سے نہیں۔ لہٰذا ڈیفالٹس کے ساتھ، اسکرین سیور ڈھائی منٹ بعد آتا ہے اور لاک اسکرین پانچ منٹ پر قبضہ کر لیتی ہے، چاہے اسکرین سیور چلا ہو یا نہیں۔ فائل محفوظ کریں اور شیل نئے اوقات فوراً اپنا لیتا ہے۔

اگر آپ لاک کی آخری تاریخ سے پہلے اسکرین سیور خارج کر دیتے ہیں تو، یہ سرگرمی شمار ہوتی ہے اور زیر التوا لاک منسوخ ہو جاتا ہے۔ آپ اپنی مشین کی طرف ایک نظر دیکھنے پر لاک آؤٹ نہیں ہوتے۔

آئیڈل پر مکمل طور پر لاک کرنا روکنے کے لیے، `Super + Ctrl + I` — یا `omarchy toggle idle` — جاگتے رہیں آن کر دیتا ہے، اور کافی کپ کا اشارہ بار میں ظاہر ہوتا ہے۔ یہ وہ ہے جسے طویل پیشکش یا اس بلڈ سے پہلے دبانا چاہیے جسے آپ دیکھنا چاہتے ہیں۔ معمول پر واپس جانے کے لیے اسے دوبارہ دبائیں۔ `omarchy toggle idle status` موجودہ حالت کو JSON کے طور پر چھاپتا ہے اگر آپ کو اسکرپٹ سے اس کی ضرورت ہو۔

یہ لاکنگ اور اسکرین سیور کے بارے میں ہے، پاور کے بارے میں نہیں۔ معطل اور ہائبرنیشن کا اپنا سیٹ اپ [سسٹم سلیپ](36-system-sleep.md) میں ہے۔

### اسکرین سیور

Omarchy کا اسکرین سیور ASCII آرٹ ہے جو بے ترتیب ٹیکسٹ ایفیکٹس میں چلتا ہے، فی مانیٹر ایک مثال۔ کوئی بھی کی یا ماؤس کی حرکت اس سے باہر نکال دیتی ہے۔

آپ اسے _سسٹم > اسکرین سیور_ (`Super + Esc`) سے مانگ کے مطابق شروع کر سکتے ہیں، جو اسے زبردستی اوپر لے آتا ہے چاہے آپ نے آئیڈل اسکرین سیور آف کر دیا ہو۔ بطور ڈیفالٹ اس کے ساتھ کوئی ہاٹ کی منسلک نہیں۔

`omarchy toggle screensaver` آئیڈل والے کو آف کرتا ہے، اگر آپ کام کرنے سے سیدھا لاک پر جانا پسند کریں تو۔ اسے ایک ایسا ٹرمینل چاہیے جسے یہ کنفیگر کرنا جانتا ہو — Alacritty، Foot، Ghostty، یا Kitty — اور اگر آپ کا ڈیفالٹ ٹرمینل کچھ اور ہے تو آپ کو بتائے گا۔

اس کا کھینچا ہوا لوگو آپ کا ہے بدلنے کے لیے، _اسٹائل > Screensaver_ کے تحت۔ png یا svg اپ لوڈ کریں اور Omarchy اسے ASCII میں تبدیل کر دیتا ہے۔ [برینڈنگ](41-branding.md) دیکھیں۔

### لاک اسکرین

`Super + Ctrl + L` مشین لاک کر دیتا ہے۔ یہ Omarchy shell سے لاک اسکرین چلاتا ہے، ڈسپلے خالی کر دیتا ہے، آپ کے کی بورڈ لے آؤٹ کو پہلے والے پر ری سیٹ کرتا ہے تاکہ آپ غلط حروف تہجی میں اپنا پاس ورڈ نہ ٹائپ کریں، اور — اگر آپ اسے چلا رہے ہیں — باہر نکلتے ہوئے 1Password لاک کر دیتا ہے۔

لاک اسکرین پاس ورڈ لیتی ہے، اور ایک بار جب آپ فنگر پرنٹ سیٹ اپ کر لیں تو یہ وہ بھی لے گی۔ وہ، اور تصدیق کے دیگر طریقے، [ہارڈ ویئر تصدیق](37-hardware-authentication.md) میں بیان کیے گئے ہیں۔
