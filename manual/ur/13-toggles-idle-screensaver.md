# ٹوگلز، آئیڈل اور اسکرین سیور

روزمرہ آپ جو کچھ بدلتے ہیں، اس کا بڑا حصہ اصل میں کوئی سیٹنگ نہیں ہوتا۔ یہ ایک موڈ ہوتا ہے جسے آپ ایک گھنٹے کے لیے آن کرتے ہیں اور پھر آف کر دیتے ہیں: دیر سے کام کرتے ہوئے نائٹ لائٹ، پریزنٹیشن دیتے ہوئے ڈو ناٹ ڈسٹرب، کچھ دیکھتے ہوئے جاگتے رہنا۔ Omarchy انہیں ٹوگلز کہتا ہے، اور یہ سب ایک ہی طرح کام کرتے ہیں — ایک ہاٹ کی، ایک مینو انٹری، اور ایک کمانڈ، تینوں ایک ہی سوئچ کو نشانہ بناتے ہیں۔

### ٹوگل مینو

`Super + Ctrl + O` براہ راست _ٹرگر > ٹوگل_ کھولتا ہے، یا آپ Omarchy مینو (`Super + Space`) سے چل کر وہاں پہنچ سکتے ہیں۔ اس فہرست میں موجود ہر چیز ایک ایسا سوئچ ہے جسے آپ یہ سوچے بغیر پلٹ سکتے ہیں کہ اس کی حالت کہاں رہتی ہے۔ ڈیسک ٹاپ کی ظاہری شکل سے متعلق سوئچ اس کے ساتھ ہی، _ظاہری شکل_ کے تحت بیٹھے ہیں۔

ٹرمینل سے، یہی سوئچ `omarchy toggle <thing>` ہیں۔ پورا گروپ دیکھنے کے لیے اکیلا `omarchy toggle` چلائیں۔

| ٹوگل | ہاٹ کی | کمانڈ |
| ------ | ------ | ------- |
| نائٹ لائٹ | — | `omarchy toggle nightlight` |
| اطلاعات خاموش کریں | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| جاگتے رہیں (کوئی آئیڈل لاک نہیں) | `Super + Ctrl + I` | `omarchy toggle idle` |
| کریش کیپچر | — | `omarchy toggle crash-capture` |
| اسکرین سیور | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) تھیم مطابقت پذیری | — | `omarchy toggle theme sync` |
| مینو بار | `Super + Shift + Space` | `omarchy toggle bar` |
| ٹچ پیڈ | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| ٹچ اسکرین | — | `omarchy toggle touchscreen` |
| سسپینڈ | — | `omarchy toggle suspend` |
| ہائبرڈ GPU | — | `omarchy toggle hybrid gpu` |

ٹچ پیڈ، ٹچ اسکرین، اور ہائبرڈ GPU سوئچ ٹوگل کے بجائے _ٹرگر > ہارڈویئر_ (`Super + Ctrl + H`) کے تحت رہتے ہیں، کیونکہ یہ صرف اسی وقت نظر آتے ہیں جب آپ کے پاس واقعی وہ ہارڈویئر ہو۔ ٹچ پیڈ اور ٹچ اسکرین والے Hyprland ری لوڈ کے بعد بھی برقرار رہتے ہیں — غیر فعال ڈیوائس کا نام ایک چھوٹی اسٹیٹ فائل میں محفوظ ہو جاتا ہے جسے Hyprland اسٹارٹ اپ پر پڑھ کر اسے دوبارہ غیر فعال کر دیتا ہے۔

_ظاہری شکل_ میں مینو بار اور اینیمیشنز ہیں، اس کے علاوہ چند ایسی چیزیں بھی جو `omarchy toggle` کمانڈز نہیں ہیں لیکن اسی طرح برتاؤ کرتی ہیں: بار میں بیٹری کا فیصد، ڈیفالٹ ورک اسپیس لے آؤٹ، اور _ونڈوز_ کے تحت، ونڈو گیپس (`Super + Shift + Backspace`) اور 1-ونڈو مربع تناسب (`Super + Ctrl + Backspace`)۔

جب Hyprland کے پاس ڈرا کرنے کے لیے کوئی GPU نہ ہو اور وہ اس کے بجائے CPU پر رینڈر کرے (llvmpipe)، جیسے ان Macs پر جن کا GPU ابھی سپورٹڈ نہیں ہے، زیادہ تر ورچوئل مشینوں میں، یا جب کوئی گرافکس ڈرائیور لوڈ ہونے میں ناکام ہو جائے، تو Omarchy اس سیشن کے لیے اینیمیشنز، بلر اور شیڈوز بند کر دیتا ہے اور ایک اطلاع کے ساتھ آپ کو ایک بار یہ بتا دیتا ہے۔ _ظاہری شکل > اینیمیشنز آن_ انہیں واپس لے آتا ہے، اور Omarchy اسے بعد کے سیشنز کے لیے بھی یاد رکھتا ہے۔

ان میں سے زیادہ تر بس `~/.local/state/omarchy/toggles/` کے تحت ایک فلیگ فائل ہیں۔ اگر آپ کسی اسکرپٹ میں ان میں سے کسی ایک پر برانچ کرنا چاہتے ہیں، تو `omarchy-toggle-enabled` آپ کو خود تلاش کرنے کے بجائے ایک ایگزٹ کوڈ دیتا ہے:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

فلیگز کے نام آف حالت کے لیے رکھے گئے ہیں — `screensaver-off`، `suspend-off`، `bar-off` — لہذا ان کی موجودگی کا مطلب ہے کہ فیچر غیر فعال ہے۔

### بار میں انڈیکیٹرز

جب کوئی موڈ آن ہو، تو آپ کو اوپر والی بار کے درمیان گھڑی کے ساتھ ایک چھوٹا سا نشان ملتا ہے۔ یہ انڈیکیٹرز ویجیٹ ہے، اور اس میں ڈکٹیشن، اسکرین ریکارڈنگ، زیر التوا یاد دہانیاں، نائٹ لائٹ، ڈو ناٹ ڈسٹرب، اور جاگتے رہنا شامل ہیں۔

غیر فعال انڈیکیٹرز چھپے رہتے ہیں۔ بار پر کہیں بھی ہوور کریں اور یہ مدھم ہو کر ظاہر ہو جاتے ہیں، تاکہ آپ اس کی ہاٹ کی جانے بغیر کسی ایک کو کلک کر کے آن کر سکیں۔ کسی فعال کو کلک کرنے سے وہ واپس آف ہو جاتا ہے۔ اگر آپ انہیں ہر وقت سارے دیکھنا پسند کرتے ہیں، تو `~/.config/omarchy/shell.json` میں `omarchy.indicators` انٹری پر `alwaysShow` کو `true` پر سیٹ کریں — بار ویجیٹس کو کیسے ترتیب دیا جاتا ہے، اس کے لیے [اوپر والی بار](05-the-top-bar.md) دیکھیں۔

### نائٹ لائٹ

نائٹ لائٹ اسکرین کو 4000K تک گرم کرتی ہے، اور اسے دوبارہ ٹوگل کرنے سے یہ واپس 6500K پر آ جاتی ہے۔ اسے ٹوگل مینو (`Super + Ctrl + O`) سے یا `omarchy toggle nightlight` کے ساتھ پلٹیں۔ اسے hyprsunset چلاتا ہے، جسے ٹوگل آپ کے لیے شروع کر دیتا ہے اگر وہ پہلے سے نہ چل رہا ہو۔

بائی ڈیفالٹ hyprsunset آپ کی اسکرین کے ساتھ بالکل کچھ نہیں کرتا۔ `~/.config/hypr/hyprsunset.conf` ایک شناختی پروفائل کے ساتھ آتی ہے، ٹھیک اس لیے کہ ڈسپلے اس وقت تک اچھوتا رہے جب تک آپ گرمجوشی نہ مانگیں۔ اگر آپ اس کے بجائے اسے گھڑی کے حساب سے سوئچ کروانا چاہتے ہیں، تو اسے ایک ٹائم پروفائل سے بدل دیں:

```
profile {
    time = 20:00
    temperature = 4000
}
```

پھر `~/.config/hypr/autostart.lua` میں `o.launch_on_start("hyprsunset")` شامل کر کے لاگ ان پر hyprsunset شروع کریں۔ ٹوگل کے ذریعے استعمال ہونے والی 4000K/6500K جوڑی طے شدہ ہے، لہذا اگر آپ کوئی مختلف درجہ حرارت چاہتے ہیں تو کانفگ فائل ہی وہ جگہ ہے جہاں آپ جاتے ہیں۔

### ڈو ناٹ ڈسٹرب

`Super + Ctrl + Alt + ,` اطلاعات کو خاموش کر دیتا ہے۔ جب یہ آن ہو تو کوئی ٹوسٹ نہیں ابھرتا، اور کاٹا ہوا گھنٹی والا انڈیکیٹر بار میں بیٹھا آپ کو یاد دلاتا رہتا ہے کہ ڈیسک ٹاپ خاموش کیوں ہو گیا ہے۔

البتہ کچھ بھی ضائع نہیں ہوتا۔ خاموش کی گئی اطلاعات روک کر رکھی جاتی ہیں: آخری چند کو `Super + Shift + Alt + ,` کے ساتھ واپس اسکرین پر رکھیں۔ باقی کے لیے [اطلاعات](10-notices.md) دیکھیں۔

دو قسم کے پیغامات پھر بھی گزر جاتے ہیں: آپ نے ابھی جو کچھ کیا اس کے لیے Omarchy کے اپنے تصدیقی ٹوسٹس ("تھیم تبدیل ہو گئی"، "اسکرین شاٹ محفوظ ہو گیا")، اور کمانڈ لائن سے بھیجے گئے اہم الرٹس۔ چیٹ ایپس جو ہر چیز کو اہم نشان زد کر کے زبردستی آپ کے سامنے آنے کی کوشش کرتی ہیں، وہ اہل نہیں ہیں۔

### آئیڈل

Omarchy شیل آئیڈل برتاؤ کی مالک ہے، اور اوقات `~/.config/omarchy/shell.json` میں ایک سرفہرست `idle` بلاک ہیں:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

دونوں نمبر اس لمحے سے گنے گئے سیکنڈ ہیں جب آپ آئیڈل ہوئے — ایک دوسرے سے نہیں۔ لہذا ڈیفالٹس کے ساتھ، اسکرین سیور ڈھائی منٹ کے بعد آتا ہے اور لاک اسکرین پانچ منٹ پر قابض ہو جاتی ہے، چاہے اسکرین سیور چلا ہو یا نہ چلا ہو۔ فائل محفوظ کریں اور شیل فوراً نئے اوقات اٹھا لیتی ہے۔

اگر آپ لاک کی آخری حد سے پہلے اسکرین سیور کو برخاست کر دیتے ہیں، تو یہ سرگرمی شمار ہوتی ہے اور زیر التوا لاک منسوخ ہو جاتا ہے۔ آپ اپنی مشین پر ایک نظر ڈالنے کی وجہ سے لاک آؤٹ نہیں ہوتے۔

آئیڈل پر لاک کرنا مکمل طور پر روکنے کے لیے، `Super + Ctrl + I` — یا `omarchy toggle idle` — جاگتے رہنا آن کر دیتا ہے، اور کافی کپ والا انڈیکیٹر بار میں ظاہر ہو جاتا ہے۔ لمبی پریزنٹیشن یا ایسی بلڈ سے پہلے جسے آپ دیکھنا چاہتے ہیں، یہی دبانے والا ہے۔ معمول پر واپس جانے کے لیے اسے دوبارہ دبائیں۔ اگر آپ کو کسی اسکرپٹ سے اس کی ضرورت ہو تو `omarchy toggle idle status` موجودہ حالت کو JSON کے طور پر پرنٹ کرتا ہے۔

یہ لاک کرنے اور اسکرین سیور کے بارے میں ہے، پاور کے بارے میں نہیں۔ سسپینڈ اور ہائبرنیشن کا اپنا سیٹ اپ [سسٹم سلیپ](36-system-sleep.md) میں ہے۔

### اسکرین سیور

Omarchy کا اسکرین سیور ASCII آرٹ ہے جو بے ترتیب ٹیکسٹ ایفیکٹس سے گزرتا ہے، ہر مانیٹر کے لیے ایک انسٹینس۔ کوئی بھی کلید یا ماؤس کی حرکت اس سے باہر لے آتی ہے۔

آپ اسے _سسٹم > اسکرین سیور_ (`Super + Esc`) سے مانگ پر شروع کر سکتے ہیں، جو اسے زبردستی اوپر لے آتا ہے چاہے آپ نے آئیڈل اسکرین سیور بند ہی کیوں نہ کر دیا ہو۔ بائی ڈیفالٹ اس کے ساتھ کوئی ہاٹ کی بندھی ہوئی نہیں ہے۔

`omarchy toggle screensaver` وہ ہے جو آئیڈل والے کو بند کرتا ہے، اگر آپ کام کرنے سے سیدھا لاک ہونے کی طرف جانا پسند کرتے ہیں۔ کوئی بھی کلید، کلک، اسکرول یا ماؤس کی حرکت اسے بند کر دیتی ہے۔

یہ جو لوگو بناتا ہے وہ آپ کا ہے کہ آپ اسے بدلیں، _ظاہری شکل > برانڈنگ > اسکرین سیور_ کے تحت۔ ایک png یا svg اپ لوڈ کریں اور Omarchy اسے ASCII میں تبدیل کر دیتا ہے۔ [برانڈنگ](41-branding.md) دیکھیں۔

### لاک اسکرین

`Super + Ctrl + L` مشین کو لاک کرتا ہے۔ یہ Omarchy شیل سے لاک اسکرین چلاتا ہے، ڈسپلے کو خالی کرتا ہے، آپ کے کی بورڈ لے آؤٹ کو پہلے والے پر ری سیٹ کرتا ہے تاکہ آپ غلط حروف تہجی میں اپنا پاس ورڈ نہ ٹائپ کر رہے ہوں، اور — اگر آپ نے اسے چلا رکھا ہے — باہر جاتے ہوئے 1Password کو لاک کرتا ہے۔

لاک اسکرین پاس ورڈ لیتی ہے، اور جب آپ نے فنگر پرنٹ سیٹ اپ کر لیا ہو تو یہ فنگر پرنٹ بھی لے گی۔ یہ، اور تصدیق کے دوسرے طریقے، [ہارڈویئر تصدیق](37-hardware-authentication.md) میں شامل ہیں۔
