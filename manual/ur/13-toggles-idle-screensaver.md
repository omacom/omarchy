# ٹوگلز، آئیڈل اور اسکرین سیور

روزمرہ آپ جو کچھ بدلتے ہیں اس کا زیادہ تر حصہ اصل میں کوئی سیٹنگ نہیں ہوتا۔ یہ ایک موڈ ہوتا ہے جسے آپ ایک گھنٹے کے لیے آن کرتے ہیں اور پھر آف کر دیتے ہیں: دیر تک کام کرتے ہوئے نائٹ لائٹ، پریزنٹیشن دیتے ہوئے ڈو ناٹ ڈسٹرب، کچھ دیکھتے ہوئے جاگتے رہنا۔ Omarchy انہیں ٹوگلز کہتا ہے، اور یہ سب ایک ہی طرح کام کرتے ہیں — ایک ہاٹ کی، ایک مینو انٹری، اور ایک کمانڈ، سب ایک ہی سوئچ کو نشانہ بناتے ہیں۔

### ٹوگل مینو

`Super + Ctrl + O` براہِ راست _Trigger > Toggle_ کھولتا ہے، یا آپ Omarchy مینو (`Super + Space`) سے چل کر وہاں پہنچ سکتے ہیں۔ اس فہرست میں موجود ہر چیز ایک سوئچ ہے جسے آپ یہ سوچے بغیر پلٹ سکتے ہیں کہ اسٹیٹ کہاں رہتی ہے۔ ڈیسک ٹاپ کیسا دکھتا ہے اس کے سوئچ اس کے بالکل ساتھ، _Appearance_ کے تحت بیٹھے ہیں۔

ٹرمینل سے، یہی سوئچ `omarchy toggle <thing>` ہیں۔ پورا گروپ دیکھنے کے لیے `omarchy toggle` کو اکیلے چلائیں۔

| ٹوگل | ہاٹ کی | کمانڈ |
| ------ | ------ | ------- |
| نائٹ لائٹ | — | `omarchy toggle nightlight` |
| نوٹیفکیشنز خاموش کریں | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| جاگتے رہیں (کوئی آئیڈل لاک نہیں) | `Super + Ctrl + I` | `omarchy toggle idle` |
| کریش کیپچر | — | `omarchy toggle crash-capture` |
| اسکرین سیور | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) تھیم سنک | — | `omarchy toggle theme sync` |
| مینو بار | `Super + Shift + Space` | `omarchy toggle bar` |
| ٹچ پیڈ | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| ٹچ اسکرین | — | `omarchy toggle touchscreen` |
| سسپینڈ | — | `omarchy toggle suspend` |
| Hybrid GPU | — | `omarchy toggle hybrid gpu` |

ٹچ پیڈ، ٹچ اسکرین، اور Hybrid GPU سوئچ Toggle کے بجائے _Trigger > Hardware_ (`Super + Ctrl + H`) کے تحت رہتے ہیں، کیونکہ یہ صرف اسی وقت ظاہر ہوتے ہیں جب آپ کے پاس واقعی وہ ہارڈویئر موجود ہو۔ ٹچ پیڈ اور ٹچ اسکرین والے Hyprland ری لوڈ کے بعد بھی برقرار رہتے ہیں — غیر فعال ڈیوائس کا نام ایک چھوٹی اسٹیٹ فائل میں محفوظ کر دیا جاتا ہے جسے Hyprland اسٹارٹ اپ پر پڑھ کر اسے دوبارہ غیر فعال کر دیتا ہے۔

_Appearance_ میں مینو بار اور اینیمیشنز ہیں، نیز چند ایسی چیزیں جو `omarchy toggle` کمانڈز نہیں ہیں لیکن ویسا ہی برتاؤ کرتی ہیں: بار میں بیٹری کی فیصد، ڈیفالٹ ورک اسپیس لے آؤٹ، اور _Windows_ کے تحت، ونڈو گیپس (`Super + Shift + Backspace`) اور 1-ونڈو اسکوائر اسپیکٹ (`Super + Ctrl + Backspace`)۔

ان میں سے زیادہ تر صرف `~/.local/state/omarchy/toggles/` کے تحت ایک فلیگ فائل ہیں۔ اگر آپ کسی اسکرپٹ میں کسی ایک پر برانچ کرنا چاہتے ہیں، تو `omarchy-toggle-enabled` آپ کو تلاش کرنے پر مجبور کرنے کے بجائے ایک ایگزٹ کوڈ دیتا ہے:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

فلیگز کے نام آف اسٹیٹ کے لیے رکھے گئے ہیں — `screensaver-off`، `suspend-off`، `bar-off` — لہٰذا ان کی موجودگی کا مطلب ہے کہ فیچر غیر فعال ہے۔

### بار میں انڈیکیٹرز

جب کوئی موڈ آن ہوتا ہے، تو آپ کو اوپر والی بار کے درمیان گھڑی کے ساتھ ایک چھوٹا سا گلِف ملتا ہے۔ یہ انڈیکیٹرز ویجٹ ہے، اور اس میں ڈکٹیشن، اسکرین ریکارڈنگ، زیرِ التوا ریمائنڈرز، نائٹ لائٹ، ڈو ناٹ ڈسٹرب، اور جاگتے رہنا شامل ہیں۔

غیر فعال انڈیکیٹرز چھپے رہتے ہیں۔ بار پر کہیں بھی ہوور کریں اور یہ مدھم ہو کر ظاہر ہو جاتے ہیں، تاکہ آپ اس کی ہاٹ کی جانے بغیر کسی ایک کو کلک کر کے آن کر سکیں۔ فعال انڈیکیٹر پر کلک کرنے سے وہ دوبارہ آف ہو جاتا ہے۔ اگر آپ انہیں ہر وقت سارے دیکھنا پسند کریں، تو `~/.config/omarchy/shell.json` میں `omarchy.indicators` انٹری پر `alwaysShow` کو `true` پر سیٹ کریں — بار ویجٹس کو کنفیگر کرنے کے طریقے کے لیے [اوپر والی بار](05-the-top-bar.md) دیکھیں۔

### نائٹ لائٹ

نائٹ لائٹ اسکرین کو 4000K تک گرم کر دیتی ہے، اور اسے دوبارہ ٹوگل کرنے سے یہ واپس 6500K پر آ جاتی ہے۔ اسے ٹوگل مینو (`Super + Ctrl + O`) سے یا `omarchy toggle nightlight` کے ساتھ پلٹیں۔ یہ hyprsunset کے ذریعے چلتی ہے، جسے ٹوگل اگر پہلے سے نہ چل رہا ہو تو آپ کے لیے شروع کر دیتا ہے۔

بطورِ ڈیفالٹ hyprsunset آپ کی اسکرین کے ساتھ بالکل کچھ نہیں کرتا۔ `~/.config/hypr/hyprsunset.conf` ایک آئیڈینٹٹی پروفائل کے ساتھ آتی ہے، خاص اس لیے کہ ڈسپلے اس وقت تک اچھوتا رہے جب تک آپ گرمی نہ مانگیں۔ اگر آپ اس کے بجائے چاہتے ہیں کہ یہ گھڑی کے حساب سے سوئچ ہو، تو اسے ٹائم پروفائل سے بدل دیں:

```
profile {
    time = 20:00
    temperature = 4000
}
```

پھر `~/.config/hypr/autostart.lua` میں `o.launch_on_start("hyprsunset")` شامل کر کے لاگ ان پر hyprsunset شروع کریں۔ ٹوگل کے ذریعے استعمال ہونے والی 4000K/6500K جوڑی طے شدہ ہے، لہٰذا اگر آپ کوئی مختلف درجہ حرارت چاہتے ہیں تو کنفگ فائل ہی وہ جگہ ہے جہاں آپ جائیں گے۔

### ڈو ناٹ ڈسٹرب

`Super + Ctrl + Alt + ,` نوٹیفکیشنز کو خاموش کر دیتا ہے۔ جب یہ آن ہو تو کوئی ٹوسٹ ظاہر نہیں ہوتا، اور کاٹا ہوا گھنٹی والا انڈیکیٹر بار میں بیٹھا آپ کو یاد دلاتا ہے کہ ڈیسک ٹاپ خاموش کیوں ہو گیا ہے۔

تاہم کچھ بھی ضائع نہیں ہوتا۔ خاموش کیے گئے نوٹیفکیشنز روک لیے جاتے ہیں: آخری چند کو `Super + Shift + Alt + ,` کے ساتھ واپس اسکرین پر رکھیں۔ باقی کے لیے [notices](10-notices.md) دیکھیں۔

دو قسم کے پیغامات پھر بھی نکل آتے ہیں: آپ کے ابھی کیے گئے کسی کام کے لیے Omarchy کے اپنے تصدیقی ٹوسٹس ("Theme changed"، "Screenshot saved")، اور کمانڈ لائن سے بھیجے گئے اہم الرٹس۔ چیٹ ایپس جو ہر چیز کو اہم نشان زد کر کے زبردستی آپ کے سامنے آنے کی کوشش کرتی ہیں، وہ اس کے اہل نہیں ہیں۔

### آئیڈل

Omarchy شیل آئیڈل برتاؤ کی مالک ہے، اور اوقات `~/.config/omarchy/shell.json` میں ایک ٹاپ لیول `idle` بلاک ہیں:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

دونوں نمبر آپ کے آئیڈل ہونے کے لمحے سے گنے گئے سیکنڈ ہیں — ایک دوسرے سے نہیں۔ لہٰذا ڈیفالٹس کے ساتھ، اسکرین سیور ڈھائی منٹ بعد آتا ہے اور لاک اسکرین پانچ منٹ پر قابض ہو جاتی ہے، چاہے اسکرین سیور چلا ہو یا نہ چلا ہو۔ فائل محفوظ کریں اور شیل فوراً نئے اوقات اٹھا لیتی ہے۔

اگر آپ لاک کی آخری حد سے پہلے اسکرین سیور کو ختم کر دیتے ہیں، تو یہ سرگرمی شمار ہوتی ہے اور زیرِ التوا لاک منسوخ ہو جاتا ہے۔ اپنی مشین پر ایک نظر ڈالنے کی وجہ سے آپ لاک آؤٹ نہیں ہوتے۔

آئیڈل پر لاک ہونا مکمل طور پر روکنے کے لیے، `Super + Ctrl + I` — یا `omarchy toggle idle` — جاگتے رہنا آن کر دیتا ہے، اور بار میں کافی کے کپ والا انڈیکیٹر ظاہر ہو جاتا ہے۔ کسی لمبی پریزنٹیشن یا ایسی بلڈ سے پہلے جسے آپ دیکھنا چاہتے ہیں، یہی دبانے والا ہے۔ معمول پر واپس جانے کے لیے اسے دوبارہ دبائیں۔ اگر آپ کو کسی اسکرپٹ سے اس کی ضرورت ہو تو `omarchy toggle idle status` موجودہ اسٹیٹ کو JSON کے طور پر پرنٹ کرتا ہے۔

یہ لاک ہونے اور اسکرین سیور کے بارے میں ہے، پاور کے بارے میں نہیں۔ سسپینڈ اور ہائبرنیشن کی اپنی سیٹ اپ [system sleep](36-system-sleep.md) میں ہے۔

### اسکرین سیور

Omarchy کا اسکرین سیور ASCII آرٹ ہے جو بے ترتیب ٹیکسٹ ایفیکٹس سے گزرتا ہے، فی مانیٹر ایک انسٹینس۔ کوئی بھی کی یا ماؤس کی حرکت اس سے باہر نکال دیتی ہے۔

آپ اسے _System > Screensaver_ (`Super + Esc`) سے طلب پر شروع کر سکتے ہیں، جو اسے زبردستی اوپر لے آتا ہے چاہے آپ نے آئیڈل اسکرین سیور آف کر رکھا ہو۔ بطورِ ڈیفالٹ اس کے ساتھ کوئی ہاٹ کی بندھی ہوئی نہیں ہے۔

`omarchy toggle screensaver` وہ ہے جو آئیڈل والے کو آف کرتا ہے، اگر آپ کام کرنے سے سیدھا لاک ہونے تک جانا پسند کریں۔ اسے ایک ایسا ٹرمینل درکار ہے جسے یہ کنفیگر کرنا جانتا ہو — Alacritty، Foot، Ghostty، یا Kitty — اور اگر آپ کا ڈیفالٹ ٹرمینل کچھ اور ہے تو یہ آپ کو بتا دے گا۔

یہ جو لوگو بناتا ہے وہ آپ کا ہے بدلنے کے لیے، _Appearance > Branding > Screensaver_ کے تحت۔ ایک png یا svg اپ لوڈ کریں اور Omarchy اسے ASCII میں بدل دیتا ہے۔ [branding](41-branding.md) دیکھیں۔

### لاک اسکرین

`Super + Ctrl + L` مشین کو لاک کر دیتا ہے۔ یہ Omarchy شیل سے لاک اسکرین چلاتا ہے، ڈسپلے کو خالی کر دیتا ہے، آپ کے کی بورڈ لے آؤٹ کو واپس پہلے والے پر ری سیٹ کر دیتا ہے تاکہ آپ غلط حروفِ تہجی میں اپنا پاس ورڈ ٹائپ نہ کر رہے ہوں، اور — اگر آپ نے اسے چلا رکھا ہو — باہر نکلتے ہوئے 1Password کو لاک کر دیتا ہے۔

لاک اسکرین پاس ورڈ لیتی ہے، اور جب آپ نے فنگر پرنٹ سیٹ اپ کر لیا ہو تو یہ فنگر پرنٹ بھی لے گی۔ یہ، اور تصدیق کے دیگر طریقے، [hardware authentication](37-hardware-authentication.md) میں شامل ہیں۔
