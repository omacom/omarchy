# دیگر پیکیجز

Arch کے پاس سرکاری ریپازٹری اور Arch یوزر ریپازٹری (AUR) کے درمیان تقریباً کسی بھی قسم کی سافٹ ویئر کے لیے پیکیجز کی ناقابل یقین دولت دستیاب ہے।

اس کا استعمال اس سے آسان نہیں ہو سکتا۔ آپ Omarchy مینو (`Super + Space`) میں _انسٹال کریں > پیکیج_ پر جا کر اور مطلوبہ پیکیج ٹائپ کر کے نیا Arch پیکیج انسٹال کرتے ہیں۔ یہ تمام پیکیجز کی فہرست کو خودکار طور پر فزی چھان دے گا۔ (آپ اسے ٹرمینل میں `omarchy pkg add [package]` استعمال کرتے ہوئے دستی طور پر بھی کر سکتے ہیں)۔

آپ AUR کے ساتھ بھی یہی کر سکتے ہیں، بس _انسٹال کریں > AUR_ استعمال کریں۔ بس یاد رکھیں کہ AUR کو Arch ٹیم کے ذریعے جانچا-پرکھا نہیں جاتا۔ یہ RubyGems یا npm جیسا ہے۔ کوئی بھی اپ لوڈ کر سکتا ہے।

اگر آپ کسی پیکیج کو ہٹانا چاہتے ہیں تو آپ Omarchy مینو سے _ہٹائیں > پیکیج_ استعمال कर سکتے ہیں۔ یہ پیکیج، ترتیب فائلوں اور ڈیپنڈنسیز کو ہٹا دے گا۔ (آپ اسے `omarchy pkg drop [package]` استعمال کر के دستی طور پر بھی کر سکتے ہیں)۔
