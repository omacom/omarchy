# برانڈنگ

Omarchy آپ کو بوٹ کھولنے، اسکرین سیور، اور بارے میں اسکرین کے لیے اپنی کمپنی کا لوگو یا ذاتی تصویر لگانے کی اجازت دیتا ہے۔

### بوٹ کھولنا

آپ دیکھنے کے لیے `omarchy plymouth preview` استعمال کر سکتے ہیں کہ آپ کا اپنی مرضی کا لوگو اور رنگ کیسے لگیں گے۔ اسے ایک پس منظر رنگ، ایک متن رنگ، ایک لوگو png، اور پیش نظارہ تصویر کے لیے ایک راستہ درکار ہے:

```
omarchy plymouth preview '#1d2021' '#ebdbb2' logo.png preview.png
```

پھر سیٹ اپ کو `omarchy plymouth set '#1d2021' '#ebdbb2' logo.png` سے نافذ کریں، جو SDDM لاگ ان اسکرین کو بھی وہی رنگ اور لوگو دے گا۔ اگر آپ واپس جانا چاہتے ہیں تو آپ `omarchy plymouth reset` استعمال کر سکتے ہیں۔

 ![branding-plymouth-shopify](images/branding-plymouth-shopify.webp)

### اسکرین سیور

آپ _اسٹائل > اسکرین سیور_ کے تحت اسکرین سیور کے لیے استعمال ہونے والا لوگو بدل سکتے ہیں۔ یہ ایک ASCII لوگو ہے، لہٰذا آپ متن براہ راست ترمیم کر سکتے ہیں، لیکن آپ اسے png یا svg تصویر بھی دے سکتے ہیں، اور ہم اسے ASCII میں بدل دیں گے۔ یہ کافی دلچسپ لگتا ہے۔

 ![branding-screensaver](images/branding-screensaver.webp)

اس مینیو میں تین اندراج ہیں:

- **متن بدلیں** `~/.config/omarchy/branding/screensaver.txt` آپ کے ایڈیٹر میں کھولتا ہے۔ جو چاہیں لکھیں یا چسپاں کریں — ASCII آرٹ، آپ کا نام، کوئی بدتمیزی والا لفظ۔ محفوظ کریں اور باہر نکلیں، اور اسکرین سیور فوراً شروع ہو جائے گا تاکہ آپ اسے دیکھ سکیں۔
- **تصویر سے لگائیں** png یا svg کے لیے ایک فائل منتخب کنندہ کھولتا ہے، اسے ASCII میں بدلتا ہے، اور آپ کو نتیجہ دکھاتا ہے۔ واضح خاکے والے لوگو تصاویر کے مقابلے کہیں اچھے کام کرتے ہیں۔
- **طے شدہ بحال کریں** Omarchy لوگو واپس لگا دیتا ہے۔

### بارے میں اسکرین

Omarchy مینیو سے ملنے والی _بارے میں_ اسکرین کے لیے وہی تین آپشن _اسٹائل > بارے میں_ کے تحت ہیں، اور یہ بالکل اسی طرح کام کرتے ہیں — فائل `~/.config/omarchy/branding/about.txt` ہے، اور ہر تبدیلی کے بعد بارے میں ونڈو کھل جاتی ہے۔ بارے میں آرٹ اسکرین سیور کے مقابلے چھوٹے سائز میں بدلتا ہے، کیونکہ اسے آپ کی ڈسپلے بھرنے کے بجائے ایک ونڈو میں سمانا ہوتا ہے۔

جب ونڈو کھلی ہو تو ہر چند سیکنڈ میں سبز چمک آرٹ کے پار جھکتی ہے اور پھر اسے دوبارہ ساکن چھوڑ دیتی ہے۔ آپ کے اپنے آرٹ کو بھی یہ ملتی ہے، بشرطیکہ اس کا ہر حرف ایک کالم چوڑا ہو — _تصویر سے لگائیں_ جو بھی بناتا ہے وہ ایسا ہی ہوتا ہے۔ Emoji یا دوہری چوڑائی والے حروف سے بنا آرٹ اس کے بجائے ساکن رہتا ہے، اور اسکرین بھی اگر آپ اپنی fastfetch کنفگ رکھیں تو: ان صورتوں میں ساکن لوگو اینیمیشن کے ناکام ہونے کے بجائے راستے سے ہٹ کر رہنا ہے، کیونکہ ان پر چمک پھانسلانے سے باقی سطر غلط جگہ پر آ جائے گی۔

 ![branding-about](images/branding-about.webp)

### تصاویر خود بدلنا

دونوں _تصویر سے لگائیں_ آپشنز بس `omarchy transcode ascii` کو پکار رہے ہیں، جسے آپ براہ راست چلا سکتے ہیں اگر آپ تبدیلی پر کنٹرول چاہتے ہیں:

```
omarchy transcode ascii ~/logo.svg ~/.config/omarchy/branding/screensaver.txt --width 100
```

اسے ٹرمینل کالمز اور صفوں میں `--width` اور `--height`، `braille` (`طے شدہ، اور کہیں باریک) یا `block` میں سے ایک `--mode`، یہ فیصلہ کرنے کے لیے کہ کون سے پکسل لوگو کا حصہ شمار ہوں ایک `--threshold` فیصد، اور جب آپ کا لوگو گہرے پس منظر پر ہلکا ہو تو `--invert` درکار ہے۔ اگر کوئی تبدیلی دھبے جیسی آئے تو حدِ فاصل عام طور پر وہ گھنڈی ہے جسے گھمانا ہے۔

### لوگو کے بجائے الفاظ

`omarchy ascii` Delta Corps Priest 1 میں متن بناتا ہے، وہ FIGlet فونٹ جس میں خود Omarchy کا ورڈ مارک بنایا گیا ہے، تاکہ اسکرین سیور تصویر دکھانے کے بجائے کچھ کہہ سکے:

```
omarchy ascii "Back in five" > ~/.config/omarchy/branding/screensaver.txt
```

یہ متن کو دلائل کے طور پر لیتا ہے، یا جب کوئی نہ دیا گیا ہو تو اسے پائپ سے پڑھتا ہے۔ فونٹ صرف حروف اور وقفے رکھتا ہے — یہ اعداد یا اوقاف کے بغیر بنایا گیا تھا — لہٰذا باقی کچھ بھی خاموشی سے نگلنے کے بجائے چھوڑ دیا جاتا ہے اور stderr پر نام دیا جاتا ہے۔
