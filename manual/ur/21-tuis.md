# TUIs

## Lazygit

[Lazygit](https://github.com/jesseduffield/lazygit) GitHub Desktop جیسی ایپلیکیشن کا ایک دلچسپ متبادل ہے، اور یہ ٹرمینل کے اندر چلتا ہے۔

آپ اسے براہ راست چلا سکتے ہیں، کسی بھی ایسی ڈائریکٹری میں جا کر جو git کے زیر انتظام ہو اور `lazygit` چلا کر۔ یا آپ اسے Neovim کے اندر چلا سکتے ہیں جہاں اسے `Space G G` سے شروع کیا جا سکتا ہے۔

آپ `Tab` استعمال کر کے مختلف پینز کے درمیان منتقل ہوتے ہیں۔ Files پین میں، آپ `Space` استعمال کر کے اسٹیجنگ کے لیے فائلیں منتخب کرتے ہیں، اور پھر آپ `c` استعمال کر کے ایک نیا commit بنا سکتے ہیں۔ آپ `?` استعمال کر کے دستیاب تمام کمانڈز دیکھ سکتے ہیں۔

## Btop

[Btop](https://github.com/aristocratos/btop) ایک خوبصورت ریسورس مینیجر ہے جو میموری، CPU، ڈسک اور نیٹ ورک کا استعمال دکھاتا ہے۔ یہ تمام فعال پروسیسز کی فہرست بھی دکھاتا ہے، اور آپ کو انہیں منظم کرنے کی اجازت دیتا ہے۔

Omarchy اسے Activity کہتا ہے، اور آپ اسے `Super + Shift + T` دبا کر شروع کرتے ہیں۔ یہ ایک فلوٹنگ ونڈو کے طور پر کھلتا ہے، جسے آپ `Super + T` سے ٹائل کر سکتے ہیں۔

## Herdr

[Herdr](https://github.com/omacom-io/herdr) ایک ٹرمینل ورک اسپیس مینیجر ہے جو آپ کو ورک اسپیسز، ٹیبز اور پینز دیتا ہے، اور ان سب کو ایک مستقل سیشن میں چلتا رکھتا ہے جس سے آپ الگ ہو کر بعد میں واپس آ سکتے ہیں۔

آپ اسے `Super + Ctrl + Return` سے شروع کرتے ہیں (یا اپنے موجودہ سیشن سے دوبارہ منسلک ہوتے ہیں)۔ Omarchy ایک Herdr کنفیگریشن فراہم کرتا ہے جو اس کی Tmux کنفیگ کی عکاسی کرتی ہے، اس لیے یہاں بھی پریفکس کی `Ctrl + Space` ہے۔ آپ `Super + Ctrl + K` سے تمام کی بائنڈنگز دیکھ سکتے ہیں۔

## Fastfetch

[Fastfetch](https://github.com/fastfetch-cli/fastfetch) سسٹم کی معلومات دکھاتا ہے، جیسے کرنل ورژن، اپ ٹائم، تھیم، CPU، میموری، اور مزید۔ یہ مشہور neofetch ٹول کا جانشین ہے۔

Omarchy نے اسے Omarchy مینو (`Super + Space`) میں _About_ کے طور پر پیک کیا ہے۔

## Cliamp

[Cliamp](https://www.cliamp.stream/) Winamp 2.x سے متاثر ایک ریٹرو ٹرمینل میوزک پلیئر ہے، جو lo-fi beats کے لیے بلٹ ان ریڈیو اسٹیشنز کے ساتھ مکمل ہے۔ اسے `Super + Shift + Alt + M` سے، یا Omarchy مینو میں _Apps_ کے تحت لانچ کریں۔ مکمل کی بائنڈنگ فہرست کے لیے `?` دبائیں۔

## Wi-Fi اور Bluetooth کا کیا؟

آپ کو Wi-Fi اور Bluetooth کے لیے TUIs نہیں ملیں گے — یہ کام Omarchy شیل کے ہیں۔ نیٹ ورکس دیکھنے اور منسلک ہونے کے لیے اوپر والی بار میں Wi-Fi آئیکن پر کلک کریں (یا `Super + Ctrl + N` دبائیں)، اور ڈیوائسز کو پیئر کرنے اور منسلک کرنے کے لیے Bluetooth آئیکن پر کلک کریں (یا `Super + Ctrl + B` دبائیں)۔ مکمل تفصیل کے لیے [نیٹ ورکنگ](35-networking.md) دیکھیں۔

## اپنا خود کا شامل کرنا

کوئی بھی ٹرمینل پروگرام مکمل ایپ جیسا سلوک حاصل کر سکتا ہے۔ Omarchy مینو (`Super + Space`) میں _Install > TUI_ پر جائیں، اسے ایک نام، ایک لانچ کمانڈ، ایک ونڈو اسٹائل اور ایک آئیکن دیں، اور یہ کسی بھی دوسری ایپلیکیشن کی طرح ایپ لانچر میں نظر آئے گا۔ آپ اسے _Remove > TUI_ کے تحت دوبارہ ہٹا سکتے ہیں۔
