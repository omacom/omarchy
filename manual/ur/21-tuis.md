# TUIs

## Lazygit

[Lazygit](https://github.com/jesseduffield/lazygit) GitHub Desktop جیسی ایپلیکیشن کا ایک دلچسپ متبادل ہے، اور یہ ٹرمینل کے اندر چلتا ہے۔

آپ اسے براہ راست چلا سکتے ہیں، git کے زیر انتظام کسی بھی ڈائریکٹری میں جا کر `lazygit` چلا کر۔ یا آپ اسے Neovim کے اندر چلا سکتے ہیں جہاں اسے `Space G G` سے شروع کیا جا سکتا ہے۔

آپ `Tab` استعمال کر کے مختلف پینز کے درمیان آ جا سکتے ہیں۔ Files پین میں، آپ `Space` استعمال کر کے اسٹیجنگ کے لیے فائلیں منتخب کرتے ہیں، اور پھر `c` استعمال کر کے نیا commit بنا سکتے ہیں۔ آپ `?` استعمال کر کے تمام دستیاب کمانڈز دیکھ سکتے ہیں۔

## Btop

[Btop](https://github.com/aristocratos/btop) ایک خوبصورت ریسورس مینیجر ہے جو میموری، CPU، ڈسک اور نیٹ ورک کے استعمال کو دکھاتا ہے۔ یہ تمام فعال پروسیسز کی فہرست بھی دیتا ہے، اور آپ کو انہیں منظم کرنے کی اجازت دیتا ہے۔

Omarchy اسے Activity Monitor کہتا ہے، اور آپ اسے ایپ لانچر سے یا `Super + Shift + T` دبا کر شروع کرتے ہیں۔ یہ ایک تیرتی ہوئی ونڈو کے طور پر کھلتا ہے، جسے آپ `Super + T` سے ٹائل کر سکتے ہیں۔

## Herdr

[Herdr](https://herdr.dev) ایک ٹرمینل ورک اسپیس مینیجر ہے جو آپ کو ورک اسپیسز، ٹیبز اور پینز دیتا ہے، اور ان سب کو ایک مستقل سیشن میں چلتا رکھتا ہے جس سے آپ الگ ہو کر بعد میں واپس آ سکتے ہیں۔

آپ اسے (یا اپنے موجودہ سیشن سے دوبارہ منسلک ہونے کو) ایپ لانچر سے یا `Super + Ctrl + Return` سے شروع کرتے ہیں۔ Omarchy ایک Herdr کنفیگریشن فراہم کرتا ہے جو اس کی Tmux کنفیگ کی عکاسی کرتی ہے، اس لیے یہاں بھی پریفکس کی `Ctrl + Space` ہے۔ آپ `Super + Ctrl + K` سے تمام کی بائنڈنگز دیکھ سکتے ہیں۔

## Fastfetch

[Fastfetch](https://github.com/fastfetch-cli/fastfetch) سسٹم کی معلومات دکھاتا ہے، جیسے کرنل ورژن، اپ ٹائم، تھیم، CPU، میموری، اور مزید بہت کچھ۔ یہ مقبول neofetch ٹول کا جانشین ہے۔

Omarchy نے اسے Omarchy مینیو (`Super + Space`) میں _System > About_ کے طور پر پیک کیا ہے۔

## Cliamp

[Cliamp](https://www.cliamp.stream/) Winamp 2.x سے متاثر ایک ریٹرو ٹرمینل میوزک پلیئر ہے، جس میں lo-fi beats کے لیے بلٹ ان ریڈیو اسٹیشنز بھی شامل ہیں۔ اسے `Super + Shift + Alt + M` سے لانچ کریں، یا Omarchy مینیو میں _Apps_ کے تحت سے۔ مکمل کی بائنڈنگ فہرست کے لیے `?` دبائیں۔

## Wi-Fi اور Bluetooth کے بارے میں کیا خیال ہے؟

آپ کو Wi-Fi اور Bluetooth کے لیے TUIs نہیں ملیں گے — یہ کام Omarchy شیل کے ہیں۔ نیٹ ورکس دیکھنے اور منسلک ہونے کے لیے اوپر والی بار میں Wi-Fi آئیکن پر کلک کریں (یا `Super + Ctrl + N` دبائیں)، اور ڈیوائسز کو پیئر اور منسلک کرنے کے لیے Bluetooth آئیکن پر کلک کریں (یا `Super + Ctrl + B` دبائیں)۔ مکمل تفصیل کے لیے [نیٹ ورکنگ](35-networking.md) دیکھیں۔

## اپنا خود کا شامل کرنا

کوئی بھی ٹرمینل پروگرام مکمل ایپ والا درجہ حاصل کر سکتا ہے۔ Omarchy مینیو (`Super + Space`) میں _Install > TUI_ پر جائیں، اسے ایک نام، ایک لانچ کمانڈ، ایک ونڈو اسٹائل اور ایک آئیکن دیں، اور یہ ایپ لانچر میں کسی بھی دوسری ایپلیکیشن کی طرح ظاہر ہو جائے گا۔ آپ اسے _Remove > TUI_ کے تحت دوبارہ ہٹا سکتے ہیں۔
