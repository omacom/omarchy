# TUI

## Lazygit

[Lazygit](https://github.com/jesseduffield/lazygit) GitHub ڈیسک ٹاپ ایپلیکیشن جیسی چیز کا دلکش متبادل ہے، اور یہ ٹرمینل کے اندر چلتا ہے۔

آپ اسے براہِ راست چلا سکتے ہیں، git کے زیر انتظام کسی بھی ڈائریکٹری میں جا کر `lazygit` چلا کر۔ یا آپ اسے Neovim کے اندر چلا سکتے ہیں جہاں اسے `Space G G` سے شروع کیا جا سکتا ہے۔

آپ `Tab` استعمال کر کے مختلف پینز کے درمیان چھلانگ لگاتے ہیں۔ فائلز پین میں، آپ `Space` استعمال کر کے اسٹیجنگ کے لیے فائلیں منتخب کرتے ہیں، اور پھر آپ `c` استعمال کر کے نیا کمٹ بنا سکتے ہیں۔ آپ `?` استعمال کر کے دستیاب تمام کمانڈز دیکھ سکتے ہیں۔

## Btop

[Btop](https://github.com/aristocratos/btop) ایک خوبصورت ریسورس مینیجر ہے جو میموری، CPU، ڈسک اور نیٹ ورک کے استعمال کو دکھاتا ہے۔ یہ تمام فعال پراسیسز کی فہرست بھی بناتا ہے، اور آپ کو ان کا انتظام کرنے دیتا ہے۔

Omarchy اسے سرگرمی کہتا ہے، اور آپ اسے `Super + Ctrl + T` دبا کر شروع کرتے ہیں۔ یہ ایک تیرتی ہوئی ونڈو کے طور پر کھلتا ہے، جسے آپ `Super + T` سے ٹائل کر سکتے ہیں۔

## Herdr

[Herdr](https://github.com/omacom-io/herdr) ایک ٹرمینل ورک اسپیس مینیجر ہے جو آپ کو ورک اسپیسز، ٹیبز اور پینز دیتا ہے، اور ان سب کو ایک پائیدار سیشن میں چلاتے رکھتا ہے جس سے آپ الگ ہو کر بعد میں واپس آ سکتے ہیں۔

آپ اسے (یا اپنے موجودہ سیشن سے دوبارہ جڑنے کے لیے) `Super + Ctrl + Return` سے شروع کرتے ہیں۔ Omarchy ایک Herdr ترتیب فراہم करता ہے جو اس کی Tmux ترتیب کی عکاسی کرتی ہے، لہٰذا یہاں بھی پریفکس کلید `Ctrl + Space` ہے۔ آپ `Super + Ctrl + K` سے تمام کلیدی شارٹ کٹ دیکھ سکتے ہیں۔

## Fastfetch

[Fastfetch](https://github.com/fastfetch-cli/fastfetch) سسٹم کی معلومات دکھاتا ہے، جیسے کرنل ورژن، اپ ٹائم، تھیم، CPU، میموری اور مزید۔ یہ مقبول neofetch ٹول کا جانشین ہے۔

Omarchy نے اسے Omarchy مینو (`Super + Space`) میں _بارے میں_ کے طور پر پیک کیا ہوا ہے۔

## Cliamp

[Cliamp](https://www.cliamp.stream/) Winamp 2.x سے متاثر ایک پرانی طرز کا ٹرمینل میوزک پلیئر ہے، جس میں لو فائی دھنوں کے لیے بلٹ ان ریڈیو اسٹیشن مکمل ہیں۔ اسے `Super + Shift + Alt + M` سے، یا Omarchy مینو میں _ایپس_ کے تحت شروع کریں۔ مکمل کلیدی شارٹ کٹ فہرست کے لیے `?` دبائیں۔

## Wi-Fi اور Bluetooth کا کیا؟

آپ کو Wi-Fi اور Bluetooth کے لیے TUI نہیں ملیں گے — یہ کام Omarchy شیل کے ذمے ہیں۔ اوپری بار میں Wi-Fi آئیکن پر کلک کریں (یا `Super + Ctrl + W` دبائیں) نیٹ ورک دیکھنے اور جڑنے کے لیے، اور آلات کی جوڑی بنانے اور جڑنے کے لیے Bluetooth آئیکن پر کلک کریں (یا `Super + Ctrl + B` دبائیں)۔ پوری کہانی کے لیے [نیٹ ورکنگ](35-networking.md) دیکھیں۔

## اپنا اضافہ کرنا

کوئی بھی ٹرمینل پروگرام مکمل ایپ سلوک حاصل کر سکتا ہے۔ Omarchy مینو (`Super + Space`) میں _انسٹال کریں > TUI_ پر جائیں، اسے ایک نام، ایک آغاز کمانڈ، ایک ونڈو اسٹائل اور ایک آئیکن دیں، اور یہ ایپ لانچر میں کسی بھی دیگر ایپلیکیشن کی طرح ظاہر ہوگا۔ آپ اسے دوبارہ _ہٹائیں > TUI_ کے تحت ہٹا سکتے ہیں۔
