# سسٹم سنیپ شاٹس

ہم ہر Omarchy اپ ڈیٹ پر خود بخود سنیپ شاٹس بناتے ہیں، لیکن اگر آپ اپنا بنانا چاہتے ہیں تو آپ `omarchy-snapshot create` استعمال کر سکتے ہیں۔

سنیپ شاٹ بوٹ کرنے اور بحال کرنے کے لیے، آپ اسے Limine بوٹ لوڈر سے منتخب کرتے ہیں۔ (اگر آپ اس وقت سیدھا Omarchy ڈکرپشن اسکرین میں بوٹ کر رہے ہیں تو آپ کو پہلے BIOS کے ذریعے Limine کو بوٹ آپشن کے طور پر منتخب کرنا ہو گا)۔

اس اسکرین سے، تاریخ اور ورژن کی بنیاد پر وہ سنیپ شاٹ چنیں جس میں آپ بوٹ کرنا چاہتے ہیں۔ سنیپ شاٹ کے وقت Omarchy کا ورژن نیچے بائیں کونے میں دیکھا جا سکتا ہے۔

 ![snapshots-bootloader](images/snapshots-bootloader.webp)

جب آپ اندر پہنچیں گے تو ایک اطلاع ظاہر ہو گی جس میں آپ کو بتایا جائے گا کہ آپ بوٹ کے قابل سنیپ شاٹ میں ہیں اور اگر آپ اس پر کلک کریں تو یہ بحالی عمل شروع کر دے گی۔ متبادل طور پر، آپ `omarchy-snapshot restore` استعمال کر سکتے ہیں۔

 ![snapshots-restore](images/snapshots-restore.webp)

یہ آپ کے روٹ فائل سسٹم کو بحال کرے گا، لیکن آپ کے `/home` کو نہیں۔ لہٰذا یہ خراب سسٹم اپ ڈیٹ کو واپس لانے کے لیے کام کرتا ہے، لیکن گمشدہ ذاتی فائلوں کو بازیافت کرنے کے لیے نہیں۔

اس کا یہ بھی مطلب ہے کہ آپ کی `~/.config` ڈائرکٹری جیسی ہے ویسی رہتی ہے۔ لہٰذا اگر آپ کسی لائبریری یا ایپلیکیشن کے پرانے ورژن پر واپس جا رہے ہیں جو کنفگریشن فائلیں نئی شکل میں محفوظ کرتی ہے تو آپ کو یہ دستی طور پر ٹھیک کرنا ہو گا۔

_نوٹ: یہ فیچر صرف ان انسٹالیشنز پر دستیاب ہے جو Limine بوٹ لوڈر استعمال کر رہی ہیں، جو Omarchy 2.0 سے طے شدہ ہے۔ یہ اس صورت میں دستیاب نہیں اگر آپ GRUB یا systemd-boot پر ہیں۔_

### بوٹ مینیو چھوڑنا

اگر آپ بوٹ مینیو کو کبھی نہیں چھوتے اور بس چاہتے ہیں کہ مشین سیدھا ڈکرپشن اسکرین پر جائے تو Omarchy مینیو میں _سیٹ اپ > Direct Boot_ چلائیں۔ یہ Omarchy کی طرف براہ راست اشارہ کرنے والا ایک EFI اندراج شامل کرتا ہے، تاکہ فرم ویئر Limine پر رکے بغیر اسے بوٹ کرے۔

توازن وہی ہے جو اوپر بیان ہوا ہے: ڈائریکٹ بوٹ آن ہونے پر، سنیپ شاٹ تک پہنچنے کا مطلب پہلے اپنے BIOS بوٹ مینیو سے Limine چننا ہے۔ اندراج ہٹانے اور Limine کے ذریعے بوٹ کرنے پر واپس جانے کے لیے _سیٹ اپ > Direct Boot_ دوبارہ چلائیں۔ کچھ فرم ویئر اپنی مرضی کے EFI اندراجات کو پسند نہیں کرتے، لہٰذا سیٹ اپ American Megatrends اور Apple فرم ویئر پر چلنے سے انکار کر دیتا ہے۔
