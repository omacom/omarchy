# سسٹم اسنیپ شاٹس

ہم ہر Omarchy اپ ڈیٹ پر خودکار طور پر اسنیپ شاٹس بناتے ہیں، لیکن اگر آپ اپنا خود کا اسنیپ شاٹ بنانا چاہیں تو آپ `omarchy-snapshot create` استعمال کر سکتے ہیں۔

کسی اسنیپ شاٹ کو بوٹ اور بحال کرنے کے لیے، آپ اسے Limine بوٹ لوڈر سے منتخب کرتے ہیں۔ بوٹ مینو بطور ڈیفالٹ چھپا رہتا ہے، اس لیے جیسے ہی Limine شروع ہو، اسے ظاہر کرنے کے لیے کوئی بھی کی دبائیں۔

اس اسکرین سے، تاریخ اور ورژن کی بنیاد پر وہ اسنیپ شاٹ منتخب کریں جس میں آپ بوٹ کرنا چاہتے ہیں۔ اسنیپ شاٹ کے وقت Omarchy کا ورژن نیچے بائیں کونے میں دیکھا جا سکتا ہے۔

 ![snapshots-bootloader](images/snapshots-bootloader.webp)

جب آپ اندر پہنچ جائیں گے تو ایک نوٹیفکیشن ظاہر ہوگا جو آپ کو اطلاع دے گا کہ آپ ایک بوٹ ایبل اسنیپ شاٹ میں ہیں اور اگر آپ اس پر کلک کریں گے تو بحالی کا عمل شروع ہو جائے گا۔ متبادل طور پر، آپ `omarchy-snapshot restore` استعمال کر سکتے ہیں۔

 ![snapshots-restore](images/snapshots-restore.webp)

یہ آپ کے روٹ فائل سسٹم کو بحال کرے گا، لیکن آپ کے `/home` کو نہیں۔ لہٰذا یہ خراب سسٹم اپ ڈیٹ کو واپس پلٹنے کے لیے کام کرتا ہے، لیکن کھوئی ہوئی ذاتی فائلوں کی بازیابی کے لیے نہیں۔

اس کا یہ بھی مطلب ہے کہ آپ کی `~/.config` ڈائریکٹری جیسی ہے ویسی ہی رہتی ہے۔ لہٰذا اگر آپ کسی لائبریری یا ایپلیکیشن کے پرانے ورژن پر واپس جا رہے ہیں جو کنفیگریشن فائلوں کو نئے فارمیٹ میں محفوظ کرتا ہے، تو آپ کو اسے خود ہی ٹھیک کرنا ہوگا۔

یہی بات Omarchy کے اپنے اس ریکارڈ پر بھی لاگو ہوتی ہے کہ کون سی مائیگریشنز پہلے ہی چل چکی ہیں: یہ آپ کی ہوم ڈائریکٹری میں رہتا ہے، اس لیے یہ بحالی کے بعد بھی باقی رہتا ہے۔ اسنیپ شاٹ لیے جانے کے بعد چلنے والی مائیگریشنز مکمل کے طور پر نشان زد رہتی ہیں، اگرچہ روٹ فائل سسٹم میں ان کی کی گئی تبدیلیاں واپس پلٹ دی گئی ہوں، اور اگلی `omarchy update` انہیں دوبارہ نہیں چلائے گی۔ لہٰذا اگر آپ بحالی کے بعد دوبارہ اپ ڈیٹ کریں اور کوئی چیز جو پچھلی اپ ڈیٹ نے ترتیب دی تھی اب بھی غائب ہو، تو غالباً یہی اس کی وجہ ہے۔

_نوٹ: یہ فیچر صرف ان انسٹالیشنز پر دستیاب ہے جو Limine بوٹ لوڈر استعمال کرتی ہیں، جو Omarchy 2.0 کے بعد سے ڈیفالٹ ہے۔ اگر آپ GRUB یا systemd-boot پر ہیں تو یہ دستیاب نہیں ہے۔_
