# ڈاٹ فائلز

Omarchy بنیادی طور پر ان نام نہاد ڈاٹ فائلز کے ذریعے کنفیگر کیا جاتا ہے جو `~/.config` میں رہتی ہیں۔ انھیں آپ کی تبدیلیوں کے لیے آپ کی فائلز سمجھا جاتا ہے۔ جو فائلز `/usr/share/omarchy` میں رہتی ہیں وہ خود Omarchy کی ہیں، اور آپ کو ان کے ساتھ چھیڑ چھاڑ نہیں کرنی چاہیے۔ اگر آپ کو `/usr/share/omarchy` میں کچھ بھی تبدیل کرنے کی ضرورت ہو تو اس کے بجائے آپ کو `~/.config` میں ویلیو کو اوور رائٹ کرنا چاہیے۔

اہم کنفگز کو Omarchy مینیو (`Super + Space`) سے براہِ راست ایڈٹ کیا جا سکتا ہے، جیسے _Setup > Keybindings_، _Setup > Input_، اور _Setup > Config > [file]_۔ جب آپ اس طریقے سے کرتے ہیں تو کوئی بھی پروسیس جسے کنفگ ایڈٹس کے بعد ری اسٹارٹ کرنے کی ضرورت ہوتی ہے وہ ایڈیٹر چھوڑنے کے بعد خود بخود ہو جائے گا (Neovim بطور ڈیفالٹ — `:wq`، یاد رکھیں! — لیکن آپ اسے _Setup > Defaults > Editor_ کے ذریعے تبدیل کر سکتے ہیں)۔

یہ `~/.config` میں اہم فائلز کی فہرست ہے اور وہ کیا کنٹرول کرتی ہیں:

| File                  | Purpose              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | مرکزی Hyprland کنفگ۔ Omarchy ڈیفالٹس کے علاوہ نیچے دی گئی آپ کی اوور رائڈ فائلز لوڈ کرتی ہے۔ [Hyprland کنفگز کے بارے میں مزید جانیں](https://wiki.hypr.land/Configuring/)۔  |
| `~/.config/hypr/bindings.lua` | آپ کی اپنی کی بائنڈنگز اور ڈیفالٹس کی اوور رائڈز۔ |
| `~/.config/hypr/monitors.lua` | مانیٹر سیٹنگز جو مانیٹر پینل کور نہیں کرتا، جیسے روٹیشن، اضافی موڈز، یا مانیٹر بند رکھنا۔ |
| `~/.config/hypr/input.lua` | آپ کے کی بورڈ لے آؤٹ، ماؤس، اور ٹریک پیڈ سیٹنگز کنٹرول کرتی ہے۔ |
| `~/.config/hypr/looknfeel.lua` | گیپس، بارڈرز، اینیمیشنز، اور باقی تمام لک کنٹرول کرتی ہے۔ |
| `~/.config/hypr/autostart.lua` | سیشن کے ساتھ شروع ہونے والے اضافی پروسیسز کنٹرول کرتی ہے۔ |
| `~/.config/omarchy/shell.json` | Omarchy شیل کنٹرول کرتی ہے: بار پوزیشن، لے آؤٹ، اور وِجٹس، نیز اسکرین سیور، لاک، اور آئیڈل ٹائمنگز۔ |
| `~/.config/foot/foot.ini` | آپ کا ٹرمینل کنٹرول کرتی ہے (foot ڈیفالٹ ہے)۔ |
| `~/.XCompose` | آپ کے فوری رسائی والے ایموجی اور نام/ای میل آٹو کمپلیٹ کی تعریف کرتی ہے۔ تبدیلیاں کرنے کے بعد `omarchy-restart-xcompose` چلانا یقینی بنائیں۔ |

اگر آپ اپنے سیٹ اپ کو ٹویک کرنے کے لیے بہت سی تبدیلیاں کر ڈالتے ہیں تو ان تمام ڈاٹ فائلز کا بیک اپ لینا اچھا خیال ہے۔ [Stow اس کے لیے بہترین طریقہ ہے](https://www.youtube.com/watch?v=NoFiYOqnC4o)۔

### سیشن کے ساتھ اپنی ایپس شروع کرنا

اگر آپ چاہتے ہیں کہ ہر بار لاگ ان ہونے پر کچھ چلے — ایک سنک ڈیمن، ایک چیٹ ایپ، آپ کی اپنی اسکرپٹ — تو اسے `~/.config/hypr/autostart.lua` میں ڈالیں:

```lua
o.launch_on_start("my-service")
```

یہ کمانڈ کو سیشن کے حصے کے طور پر شروع کر دیتا ہے، اس لیے جب آپ دوبارہ لاگ آؤٹ کرتے ہیں تو یہ صحیح طریقے سے صاف ہو جاتا ہے۔

### سسٹم ایونٹس پر اسکرپٹس چلانا

Omarchy چند مخصوص لمحات پر ہُکس فائر کرتا ہے، اور آپ اپنی اسکرپٹس ان پر لٹکا سکتے ہیں۔ وہ `~/.config/omarchy/hooks/<event>.d/` میں رہتے ہیں، ہر ایونٹ کے لیے ایک ڈائریکٹری، اور وہاں موجود ہر ایگزیکیوٹیبل فائل ایونٹ ہونے پر چلتی ہے:

| Event | When it runs |
| ----- | ------------ |
| `post-boot` | ڈیسک ٹاپ شروع ہونے کے فوراً بعد |
| `post-update` | `omarchy update` کے اختتام کے قریب، پیکجز، مائیگریشنز، اور سروس ری اسٹارٹس کے بعد، mise ٹولز اپ ڈیٹ ہونے سے پہلے |
| `pre-refresh-pacman` | `omarchy refresh pacman` کے پیکج کنفگ کو دوبارہ سنک کرنے کے بعد، پیکجز اپ ڈیٹ کرنے سے پہلے؛ چینل سوئچ اسی ریفریش مرحلے کے دوران اسے چلاتا ہے |
| `theme-set` | تھیم تبدیل ہونے کے بعد (تھیم کا نام `$1` میں) |
| `font-set` | فونٹ تبدیل ہونے کے بعد (فونٹ کا نام `$1` میں) |
| `battery-low` | جب بیٹری کم ہو جائے (فیصد `$1` میں) |

`pre-refresh-pacman` ہُک وہ جگہ ہے جہاں کسٹم ریپوزٹریز یا `IgnorePkg` لائنز ہونی چاہئیں، کیونکہ یہ پیکج ٹرانزیکشن سے پہلے چلتا ہے۔ دونوں اپ ڈیٹ سے متعلق ہُکس Omarchy کے اپنے کیشڈ sudo اجازت صاف کرنے کے بعد آپ کے یوزر کے طور پر چلتے ہیں، اس لیے جو ہُک `sudo` استعمال کرتا ہے اسے اپنی اجازت درکار ہوتی ہے اور وہ آپ سے آپ کا پاس ورڈ مانگ سکتا ہے۔

ان میں سے ہر ڈائریکٹری میں پہلے سے ایک `.sample` فائل موجود ہے جو ہُک کی شکل دکھاتی ہے — اسے کام پر لگانے کے لیے نام سے `.sample` ہٹا دیں۔ کہیں اور لکھی گئی اسکرپٹ انسٹال کرنے کے لیے `omarchy hook install post-boot ~/my-hook` استعمال کریں، جو اسے کاپی کر کے ایگزیکیوٹیبل بنا دیتا ہے۔

### اپنے مینیو اندراجات شامل کرنا

Omarchy مینیو (`Super + Space`) کو `~/.config/omarchy/extensions/omarchy-menu.jsonc` ایڈٹ کر کے اپنی قطاروں کے ساتھ بڑھایا جا سکتا ہے۔ اندراجات ڈاٹ والی id کے ذریعے کلید بند ہوتے ہیں، اور id ہی انھیں ٹری میں رکھتی ہے، اس لیے `personal` روٹ مینیو پر ظاہر ہوتا ہے اور `personal.notes` اس کے اندر ظاہر ہوتا ہے:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

موجودہ id دوبارہ استعمال کریں تو آپ نئی قطار شامل کرنے کے بجائے اس قطار کو اوور رائڈ کر دیتے ہیں۔ فائل میں تمام دستیاب فیلڈز تبصروں کے طور پر دستاویز شدہ آتی ہیں۔

### اپنی شیل ایکسپورٹس، فنکشنز، اور ایلیئسز شامل کرنا

Omarchy بہت سے ارگونومک ایلیئسز اور مددگار فنکشنز کے ساتھ آتا ہے، لیکن اپنے شامل کرنا بہت عام ہے۔ آپ کو ایلیئسز، فنکشنز، اور ایکسپورٹس سب کو `~/.bashrc` میں شامل کرنا چاہیے۔ یہ فائل اپ ڈیٹس پر اوور رائٹ نہیں ہوگی۔ اگر آپ Omarchy ڈیفالٹس میں سے کوئی تبدیل کرنا چاہتے ہیں تو آپ انھیں یہاں بھی محفوظ طریقے سے شامل کر سکتے ہیں۔

### اندرونی Omarchy فائلز تبدیل کرنا

دیکھیں، یہ آپ کا کمپیوٹر ہے۔ آپ اس کے ساتھ جو چاہیں کر سکتے ہیں، لیکن میں `/usr/share/omarchy` میں فائلز میں براہِ راست تبدیلیاں کرنے کے خلاف مشورہ دوں گا۔ وہ Omarchy pacman پیکج سے تعلق رکھتی ہیں، اس لیے آپ کی تبدیلیاں اگلی اپ ڈیٹ پر بس اوور رائٹ ہو جائیں گی۔ اس کے بجائے آپ کے لیے بہتر ہے کہ جن ڈیفالٹ ویلیوز کو آپ پسند نہیں کرتے انھیں `~/.config/*` فولڈر میں اوور رائٹ کر دیں۔

آپ اس طریقے سے تقریباً ہر چیز تبدیل کر سکتے ہیں، جیسے ڈیفالٹ کی بائنڈنگز۔ بس `~/.config/hypr/bindings.lua` ایڈٹ کر کے، مثال کے طور پر، [Obsidian](https://obsidian.md/) کو [Joplin](https://joplinapp.org/) سے بدل دیں ( `omarchy-pkg-add joplin-bin` کے ساتھ انسٹال کریں):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` موجودہ بائنڈنگ کو اس کی جگہ شامل کرنے سے پہلے ہٹا دیتا ہے۔ یہ `o.bind` جیسے ہی آرگومنٹس لیتا ہے، بشمول لانچ ہیلپرز اور بائنڈنگ آپشنز۔ بائنڈنگ شامل کرنے کے لیے `o.bind` استعمال کریں، یا اسے بدلے بغیر ہٹانے کے لیے `hl.unbind` استعمال کریں۔

اگر آپ اندرونی Omarchy فائلز پر ہیکنگ پر اصرار کرتے ہیں تو _Update > Channel > Dev_ کے ذریعے dev چینل پر سوئچ کر لیں۔ یہ Omarchy کو `~/omarchy` میں سورس کوڈ کے git چیک آؤٹ سے لنک کر دیتا ہے، جسے آپ دل چاہے جتنا تبدیل کر سکتے ہیں۔ یہاں آپ کو بتانے والا کوئی نہیں ہے کہ کیا کرنا ہے!

### کسی بھی تبدیلی کو ری سیٹ کرنا

اگر آپ کنفیگریشنز کی گڑبڑ کر بیٹھتے ہیں تو آپ Omarchy مینیو میں _Update > Config_ کے ذریعے انھیں ہمیشہ ڈیفالٹس پر واپس لا سکتے ہیں۔ یا سب کچھ ری سیٹ کرنے کے لیے `omarchy reinstall configs` چلا کر۔
