# ڈاٹ فائلیں

Omarchy کو بنیادی طور پر نام نہاد ڈاٹ فائلوں کے ذریعے ترتیب दिया जाता ہے جو `~/.config` میں رہتی ہیں۔ یہ آپ کی تبدیلیوں کے لیے آپ کی فائلیں मانی جاتی ہیں۔ جو فائلیں `/usr/share/omarchy` میں رہتی ہیں وہ خود Omarchy سے تعلق رکھتی ہیں، اور آپ کو ان کے ساتھ چھیڑ چھاڑ نہیں کرنی چاہیے। اگر آپ کو `/usr/share/omarchy` میں کچھ بھی تبدیل کرنا ہو تو اس کی جگہ آپ کو `~/.config` میں قدر کو تبدیل کرنا چاہیے।

کلیدی ترتیبات میں Omarchy مینو (`Super + Space`) سے براہِ راست ترمیم کی جا سکتی ہے، جیسے _سیٹ اپ > مانیٹرز_، _سیٹ اپ > کلیدی شارٹ کٹ_، _سیٹ اپ > ان پٹ_، اور _سیٹ اپ > ترتیب > [فائل]_۔ جب آپ اس طریقے سے کرتے ہیں تو ترتیب ترمیمات کے بعد جس بھی عمل کو دوبارہ شروع کرنے की आवश्यकता ہوگی وہ ایڈیٹر چھوڑنے کے بعد خودکار طور پر ہو جائے گا (بطور ڈیفالٹ Neovim — `:wq`، یاد رکھیں! — لیکن آپ اسے _سیٹ اپ > ڈیفالٹس > ایڈیٹر_ کے ذریعے تبدیل کر سکتے ہیں)۔

یہاں `~/.config` میں کلیدی فائلوں اور ان کے قابو کی فہرست ہے:

| فائل                  | مقصد              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | مرکزی Hyprland ترتیب۔ Omarchy ڈیفالٹس کے ساتھ ذیل میں آپ کی اووررائڈ فائلیں لوڈ کرتی ہے۔ [Hyprland ترتیبات کے بارے میں مزید جانیں](https://wiki.hypr.land/Configuring/)۔  |
| `~/.config/hypr/bindings.lua` | آپ کی اپنی کلیدی شارٹ کٹ اور ڈیفالٹس کی اووررائڈ۔ |
| `~/.config/hypr/monitors.lua` | آپ کے مانیٹرز، ریزولوشن اور جگہ کو قابو کرتی ہے۔ |
| `~/.config/hypr/input.lua` | آپ کے کی بورڈ لے آؤٹ، ماؤس اور ٹریک پیڈ ترتیبات کو قابو کرتی है। |
| `~/.config/hypr/looknfeel.lua` | خالی جگہوں، بارڈرز، اینیمیشنز اور باقی ظاہری شکل کو قابو کرتی ہے। |
| `~/.config/hypr/autostart.lua` | سیشن کے ساتھ شروع کیے جانے والے اضافی عمل کو قابو کرتی ہے۔ |
| `~/.config/omarchy/shell.json` | Omarchy شیل کو قابو کرتی ہے: بار کی جگہ، لے آؤٹ اور ویجیٹس، نیز اسکرین سیور، لاک اور بیکار اوقات। |
| `~/.config/foot/foot.ini` | آپ کے ٹرمینل کو قابو کرتی ہے (foot ڈیفالٹ ہے)। |
| `~/.XCompose` | آپ کے فوری رسائی ایموجی اور نام/ای میل آٹو کمپلیٹ کی تعریف کرتی ہے। تبدیلیوں کے بعد `omarchy-restart-xcompose` ضرور چلائیں۔ |

اگر آپ اپنے ذاتی سیٹ اپ میں ترمیم کرنے کے لیے بہت ساری تبدیلیاں کرنے لگیں تو ان تمام ڈاٹ فائلوں کا بیک اپ لینا عمدہ خیال है। [اسٹو ایسا کرنے کا عمدہ طریقہ ہے](https://www.youtube.com/watch?v=NoFiYOqnC4o)۔

### سیشن کے ساتھ اپنی ذاتی ایپس شروع کرنا

اگر آپ چاہتے ہیں کہ جب بھی آپ لاگ ان کریں کچھ چلے — ہم وقت سازی ڈیمن، چیٹ ایپ، آپ کا ذاتی اسکرپٹ — تو اسے `~/.config/hypr/autostart.lua` میں رکھیں:

```lua
o.launch_on_start("my-service")
```

یہ کمانڈ کو سیشن کے حصے کے طور پر شروع کرتا ہے، لہٰذا جب آپ دوبارہ لاگ آؤٹ کریں تو یہ مناسب طریقے سے صاف ہو جاتا ہے।

### سسٹم واقعات پر اسکرپٹ چلانا

Omarchy مٹھی بھر لمحات پر ہک فائر کرتا ہے، اور آپ اپنے ذاتی اسکرپٹ ان پر لٹکا سکتے ہیں। یہ `~/.config/omarchy/hooks/<event>.d/` میں رہتے ہیں، فی واقعہ ایک ڈائریکٹری، اور اس میں موجود ہر قابل عمل فائل جب وہ واقعہ رونما ہوتی ہے تو چلتی ہے:

| واقعہ | یہ کب چلتا है |
| ----- | ------------ |
| `post-boot` | ڈیسک ٹاپ شروع ہونے کے فوراً بعد |
| `post-update` | `omarchy update` کے اختتام کے قریب، پیکیجز، مائیگریشنز اور سروس دوبارہ آغاز کے بعد، mise ٹولز کے اپ ڈیٹ ہونے سے پہلے |
| `pre-refresh-pacman` | `omarchy refresh pacman` کے پیکیج ترتیب کو دوبارہ ہم وقت کرنے کے بعد، پیکیجز کو اپ ڈیٹ کرنے سے پہلے؛ چینل کی تبدیلی اسی تازہ کاری مرحلے کے دوران اسے چلاتی ہے |
| `theme-set` | تھیم تبدیلی کے بعد (تھیم کا نام `$1` میں) |
| `font-set` | فونٹ تبدیلی کے بعد (فونٹ کا نام `$1` میں) |
| `battery-low` | جب بیٹری کم پڑے (فیصد `$1` میں) |

`pre-refresh-pacman` ہک وہ جگہ ہے جہاں اپنی مرضی کے ریپازٹری یا `IgnorePkg` لائنیں thuộc ہیں، کیونکہ یہ پیکیج لین دین سے پہلے چلتا है। دونوں اپ ڈیٹ سے متعلق ہک آپ کے صارف کے طور پر چلاتے ہیں جب Omarchy اپنی کیش شدہ sudo اجازت کو صاف کر چکا ہو، لہٰذا `sudo` استعمال کرنے والے ہک کو اپنی ذاتی اجازت کی ضرورت ہوتی है اور یہ آپ سے پاس ورڈ پوچھ سکتا ہے।

ان میں سے ہر ڈائریکٹری میں پہلے سے ہی `.sample` فائل ہے جو ہک کی شکل دکھاتی ہے — اسے کام میں لانے کے لیے نام سے `.sample` हٹا दें। کسی ایسی اسکرپٹ کو انسٹال کرنے کے لیے جو آپ نے کہیں اور لکھی ہو، `omarchy hook install post-boot ~/my-hook` استعمال کریں، جو اسے نقل کر کے قابل عمل بنا دیتا ہے।

### اپنی ذاتی مینو اندراج شامل کرنا

Omarchy مینو (`Super + Space`) کو `~/.config/omarchy/extensions/omarchy-menu.jsonc` میں ترمیم کر کے اپنی ذاتی قطاروں کے ساتھ توسیع دیا جا سکتا ہے। اندراج کو بندھی آئی ڈی کے ذریعے کلید کیا جاتا ہے، اور آئی ڈی انہیں ٹری میں رکھتی ہے، لہٰذا `personal` جڑ کے مینو پر ظاہر होता ہے اور `personal.notes` اس کے اندر ظاہر होता ہے:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

موجودہ آئی ڈی دوبارہ استعمال کریں اور آپ نئی شامل کرنے کے بجائے اسی قطار کو اووررائڈ کر دیں گے۔ فائل تمام دستیاب فیلڈز کو تبصروں کی صورت میں درج کر کے بھیجی جاتی ہے۔

### اپنے ذاتی شیل ایکسپورٹ، فنکشنز اور عرف شامل کرنا

Omarchy کئی ارگونومک عرف اور مددگار فنکشنز کے ساتھ آتا ہے، لیکن اپنی ذاتی چیزیں شامل کرنا چاہنا بہت عام بات ہے। آپ کو عرف، فنکشنز اور ایکسپورٹ دونوں کو `~/.bashrc` میں شامل کرنا چاہیے। یہ فائل اپ ڈیٹ پر مٹائی نہیں جائے گی। اگر آپ Omarchy ڈیفالٹس میں سے کسی کو بھی تبدیل کرنا چاہتے ہیں تو آپ انہیں محفوظ طریقے سے یہاں بھی شامل کر سکتے ہیں।

### اندرونی Omarchy فائلیں تبدیل کرنا

دیکھو، یہ آپ کا کمپیوٹر ہے। آپ اس کے ساتھ جو چاہے کر سکتے ہیں، لیکن میں آپ کو مشورہ دوں گا کہ `/usr/share/omarchy` میں موجود فائلوں میں براہِ راست تبدیلیاں نہ کریں। یہ Omarchy pacman پیکیج سے تعلق رکھتی ہیں، لہٰذا آپ کی تبدیلیاں اگلے اپ ڈیٹ میں آسانی سے مٹا दी جائیں گی। اس کی جگہ آپ کے لیے بہتر یہی ہے کہ آپ `~/.config/*` فولڈر میں جو ڈیفالٹ قدریں آپ کو پسند نہیں ہیں انہیں تبدیل कर دیں।

آپ اس طریقے سے تقریباً ہر چیز تبدیل کر سکتے ہیں، جیسے ڈیفالٹ کلیدی شارٹ کٹ۔ بس `~/.config/hypr/bindings.lua` میں ترمیم کر کے، مثلاً، [Obsidian](https://obsidian.md/) کو [Joplin](https://joplinapp.org/) سے بدل دیں (`omarchy-pkg-add joplin-bin` کے ساتھ انسٹال کریں):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` اپنی تبدیلی شامل کرنے سے پہلے موجودہ بائنڈنگ کو ہٹا دیتا ہے۔ یہ `o.bind` جیسی ہی آرگومنٹ لیتا ہے، جس میں لانچ مددگار اور بائنڈنگ اختیارات شامل ہیں। بائنڈنگ شامل کرنے کے لیے `o.bind` استعمال کریں، یا اسے बदले بغیر ہٹانے کے لیے `hl.unbind` استعمال کریں।

اگر آپ اندرونی Omarchy فائلوں پر چھیڑ چھاڑ کرنے پر مصر ہیں تو _اپ ڈیٹ کریں > چینل > ڈیویلپمنٹ_ کے ذریعے ڈیویلپمنٹ چینل میں بدل جائیں। یہ Omarchy کو `~/omarchy` میں سورس کوڈ کے git چیک آؤٹ سے جوڑتا ہے، جسے آپ دل بھر کر تبدیل کر سکتے ہیں। یہاں آپ کو کچھ بتانے والا کوئی नहीं ہے!

### کسی بھی تبدیلی کو دوبارہ مقرر کرنا

اگر آپ ترتیبات کی خرابی کا سامنا کر لیں تو آپ ہمیشہ Omarchy مینو میں _اپ ڈیٹ کریں > ترتیب_ کے ذریعے انہیں ڈیفالٹس پر واپس لے جا سکتے ہیں। یا سب کچھ دوبارہ مقرر کرنے کے لیے `omarchy reinstall configs` چلا سکتے ہیں।
