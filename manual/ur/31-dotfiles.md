# ڈاٹ فائلز

Omarchy بنیادی طور پر ان نام نہاد ڈاٹ فائلز کے ذریعے ترتیب دیا جاتا ہے جو `~/.config` میں رہتی ہیں۔ یہ آپ کی تبدیلیوں کے لیے آپ کی فائلز سمجھی جاتی ہیں۔ جو فائلز `/usr/share/omarchy` میں رہتی ہیں وہ خود Omarchy کی ہیں، اور آپ کو ان کے ساتھ چھیڑ چھاڑ نہیں کرنی چاہیے۔ اگر آپ کو `/usr/share/omarchy` میں کچھ بھی تبدیل کرنا ہو تو اس کے بجائے آپ کو اس کی قدر کو `~/.config` میں اوور رائٹ کرنا چاہیے۔

اہم کنفگز کو براہ راست Omarchy مینو (`Super + Space`) سے ترمیم کیا جا سکتا ہے، جیسے _سیٹ اپ > کی بائنڈنگز_، _سیٹ اپ > ان پٹ_، اور _سیٹ اپ > کنفگ > [file]_۔ جب آپ اس طریقے سے کرتے ہیں تو کوئی بھی پروسیس جسے کنفگ ترامیم کے بعد دوبارہ شروع کرنے کی ضرورت ہوگی وہ ایڈیٹر سے باہر نکلنے کے بعد خود بخود ہو جائے گا (طے شدہ طور پر Neovim — `:wq`، یاد رکھیں! — لیکن آپ اسے _سیٹ اپ > ڈیفالٹس > ایڈیٹر_ کے ذریعے تبدیل کر سکتے ہیں)۔

یہاں `~/.config` میں موجود اہم فائلز اور وہ کن چیزوں کو کنٹرول کرتی ہیں اس کی ایک فہرست ہے:

| فائل | مقصد |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | اصل Hyprland کنفگ۔ Omarchy کے ڈیفالٹس کے ساتھ نیچے دی گئی آپ کی اوور رائڈ فائلز کو لوڈ کرتی ہے۔ [Hyprland کنفگز کے بارے میں مزید جانیں](https://wiki.hypr.land/Configuring/)۔  |
| `~/.config/hypr/bindings.lua` | آپ کی اپنی کی بائنڈنگز اور ڈیفالٹس کی اوور رائڈز۔ |
| `~/.config/hypr/monitors.lua` | مانیٹر کی وہ ترتیبات جن کا مانیٹر پینل احاطہ نہیں کرتا، جیسے گھماؤ، اضافی موڈز، یا کسی مانیٹر کو بند رکھنا۔ |
| `~/.config/hypr/input.lua` | آپ کے کی بورڈ لے آؤٹ، ماؤس اور ٹریک پیڈ کی ترتیبات کو کنٹرول کرتی ہے۔ |
| `~/.config/hypr/looknfeel.lua` | گیپس، بارڈرز، اینیمیشنز اور باقی ظاہری شکل کو کنٹرول کرتی ہے۔ |
| `~/.config/hypr/autostart.lua` | سیشن کے ساتھ شروع ہونے والے اضافی پروسیسز کو کنٹرول کرتی ہے۔ |
| `~/.config/omarchy/shell.json` | Omarchy شیل کو کنٹرول کرتی ہے: بار کی پوزیشن، لے آؤٹ اور ویجٹس، نیز اسکرین سیور، لاک اور آئیڈل کے اوقات۔ |
| `~/.config/foot/foot.ini` | آپ کے ٹرمینل کو کنٹرول کرتی ہے (foot طے شدہ ہے)۔ |
| `~/.XCompose` | آپ کے فوری رسائی والے ایموجی اور نام/ای میل کی خودکار تکمیل کی تعریف کرتی ہے۔ تبدیلیاں کرنے کے بعد `omarchy-restart-xcompose` چلانا یقینی بنائیں۔ |

اگر آپ اپنی سیٹ اپ کو ٹھیک کرنے کے لیے بہت ساری تبدیلیاں کر بیٹھتے ہیں تو ان تمام ڈاٹ فائلز کا بیک اپ لینا ایک اچھا خیال ہے۔ [Stow اس کے لیے ایک بہترین طریقہ ہے](https://www.youtube.com/watch?v=NoFiYOqnC4o)۔

### سیشن کے ساتھ اپنی ایپس شروع کرنا

اگر آپ چاہتے ہیں کہ ہر بار لاگ ان ہونے پر کچھ چلے — ایک سنک ڈیمن، ایک چیٹ ایپ، آپ کی اپنی اسکرپٹ — تو اسے `~/.config/hypr/autostart.lua` میں ڈالیں:

```lua
o.launch_on_start("my-service")
```

یہ کمانڈ کو سیشن کے حصے کے طور پر شروع کرتا ہے، اس لیے جب آپ دوبارہ لاگ آؤٹ ہوتے ہیں تو اسے ٹھیک طرح سے صاف کر دیا جاتا ہے۔

### سسٹم ایونٹس پر اسکرپٹس چلانا

Omarchy چند لمحات پر ہکس فائر کرتا ہے، اور آپ اپنی اسکرپٹس کو ان سے جوڑ سکتے ہیں۔ یہ `~/.config/omarchy/hooks/<event>.d/` میں رہتے ہیں، ہر ایونٹ کے لیے ایک ڈائریکٹری، اور وہاں موجود ہر قابلِ اجرا فائل ایونٹ ہونے پر چلتی ہے:

| ایونٹ | یہ کب چلتا ہے |
| ----- | ------------ |
| `post-boot` | ڈیسک ٹاپ شروع ہونے کے فوراً بعد |
| `post-update` | `omarchy update` کے اختتام کے قریب، پیکیجز، مائیگریشنز اور سروس ری اسٹارٹس کے بعد، mise ٹولز اپ ڈیٹ ہونے سے پہلے |
| `pre-refresh-pacman` | `omarchy refresh pacman` کے پیکیج کنفگ کو دوبارہ سنک کرنے کے بعد، پیکیجز اپ ڈیٹ کرنے سے پہلے؛ چینل کی تبدیلی اسی ریفریش مرحلے کے دوران اسے چلاتی ہے |
| `theme-set` | تھیم کی تبدیلی کے بعد (تھیم کا نام `$1` میں) |
| `font-set` | فونٹ کی تبدیلی کے بعد (فونٹ کا نام `$1` میں) |
| `battery-low` | جب بیٹری کم ہو جائے (فیصد `$1` میں) |

`pre-refresh-pacman` ہک وہ جگہ ہے جہاں حسبِ ضرورت ریپوزٹریز یا `IgnorePkg` لائنیں ہونی چاہئیں، کیونکہ یہ پیکیج ٹرانزیکشن سے پہلے چلتا ہے۔ اپ ڈیٹ سے متعلق دونوں ہکس آپ کے صارف کے طور پر اس کے بعد چلتے ہیں جب Omarchy اپنی کیش شدہ sudo اجازت صاف کر دیتا ہے، اس لیے جو ہک `sudo` استعمال کرتا ہے اسے اپنی اجازت درکار ہوگی اور وہ آپ سے آپ کا پاس ورڈ مانگ سکتا ہے۔

ان میں سے ہر ڈائریکٹری میں پہلے سے ایک `.sample` فائل موجود ہے جو ہک کی شکل دکھاتی ہے — اسے کام پر لگانے کے لیے نام سے `.sample` ہٹا دیں۔ کسی ایسی اسکرپٹ کو انسٹال کرنے کے لیے جو آپ نے کہیں اور لکھی ہو، `omarchy hook install post-boot ~/my-hook` استعمال کریں، جو اسے اندر کاپی کر دیتا ہے اور اسے قابلِ اجرا بنا دیتا ہے۔

### اپنے مینو اندراجات شامل کرنا

Omarchy مینو (`Super + Space`) کو `~/.config/omarchy/extensions/omarchy-menu.jsonc` میں ترمیم کر کے اپنی قطاروں کے ساتھ بڑھایا جا سکتا ہے۔ اندراجات کو ایک ڈاٹ والے آئی ڈی سے کلید بند کیا جاتا ہے، اور آئی ڈی ہی انہیں درخت میں رکھتا ہے، اس لیے `personal` روٹ مینو پر ظاہر ہوتا ہے اور `personal.notes` اس کے اندر ظاہر ہوتا ہے:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

موجودہ آئی ڈی کو دوبارہ استعمال کریں اور آپ نئی قطار شامل کرنے کے بجائے اس قطار کو اوور رائڈ کر دیں گے۔ فائل میں تمام دستیاب فیلڈز تبصروں کے طور پر دستاویزی شکل میں موجود ہیں۔

### اپنے شیل ایکسپورٹس، فنکشنز اور ایلائسز شامل کرنا

Omarchy بہت سے آسان ایلائسز اور مددگار فنکشنز کے ساتھ آتا ہے، لیکن اپنے شامل کرنا چاہنا بہت عام بات ہے۔ آپ کو ایلائسز، فنکشنز اور ایکسپورٹس دونوں کو `~/.bashrc` میں شامل کرنا چاہیے۔ یہ فائل اپ ڈیٹس پر اوور رائٹ نہیں ہوگی۔ اگر آپ Omarchy کے کسی ڈیفالٹ کو تبدیل کرنا چاہتے ہیں تو آپ انہیں یہاں بھی محفوظ طریقے سے شامل کر سکتے ہیں۔

### ڈیسک ٹاپ کے لیے ماحولیاتی متغیرات سیٹ کرنا

ڈیسک ٹاپ سیشن ایکسپورٹس `~/.config/uwsm/env.d/` میں ہوتے ہیں۔ یہ فائلز آپ کے ڈیسک ٹاپ کے شروع ہونے سے پہلے چلتی ہیں، اس لیے شیل کی خرابی آپ کو واپس لاگ ان اسکرین پر بھیج سکتی ہے۔ ان میں ترمیم کرتے وقت ایک چلتا ہوا ٹرمینل کھلا رکھیں۔ کسی اوور رائڈ کو غیر فعال کرنے کے لیے اسے `env.d` سے باہر منتقل کر دیں۔ اگر کوئی تبدیلی لاگ ان کو روک دے تو [لاگ ان کی بحالی](45-troubleshooting.md#my-password-is-accepted-but-i-return-to-the-login-screen) دیکھیں۔

### اندرونی Omarchy فائلز کو تبدیل کرنا

دیکھو، یہ تمہارا کمپیوٹر ہے۔ تم اس کے ساتھ جو چاہو کر سکتے ہو، لیکن میں `/usr/share/omarchy` میں موجود فائلز میں براہ راست تبدیلیاں کرنے کے خلاف مشورہ دوں گا۔ وہ Omarchy pacman پیکیج سے تعلق رکھتی ہیں، اس لیے تمہاری تبدیلیاں اگلی اپ ڈیٹ پر بس اوور رائٹ ہو جائیں گی۔ اس کے بجائے تمہارے لیے بہتر یہی ہے کہ جن ڈیفالٹ قدروں کو تم پسند نہیں کرتے انہیں `~/.config/*` فولڈر میں اوور رائٹ کر دو۔

تم اس طریقے سے تقریباً ہر چیز تبدیل کر سکتے ہو، جیسے طے شدہ کی بائنڈنگز۔ بس `~/.config/hypr/bindings.lua` میں ترمیم کر کے، مثال کے طور پر، [Obsidian](https://obsidian.md/) کو [Joplin](https://joplinapp.org/) سے بدل دو (`omarchy-pkg-add joplin-bin` کے ساتھ انسٹال کریں):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` اپنی جگہ لینے والی بائنڈنگ شامل کرنے سے پہلے موجودہ بائنڈنگ کو ہٹا دیتا ہے۔ یہ `o.bind` جیسے ہی دلائل لیتا ہے، جن میں لانچ مددگار اور بائنڈنگ آپشنز شامل ہیں۔ بائنڈنگ شامل کرنے کے لیے `o.bind` استعمال کریں، یا اسے بدلے بغیر ہٹانے کے لیے `hl.unbind` استعمال کریں۔

اگر تم اندرونی Omarchy فائلز پر ہیکنگ کرنے پر ہی بضد ہو تو _اپ ڈیٹ > چینل > Dev_ کے ذریعے dev چینل پر سوئچ کر لو۔ یہ Omarchy کو `~/omarchy` میں سورس کوڈ کے ایک git چیک آؤٹ سے جوڑ دیتا ہے، جسے تم اپنے دل کی تسلی تک تبدیل کرنے کے لیے آزاد ہو۔ یہاں کوئی تمہیں بتانے والا نہیں کہ کیا کرنا ہے!

### کسی بھی تبدیلی کو ری سیٹ کرنا

اگر تم کنفیگریشنز کا بیڑا غرق کر بیٹھو تو تم انہیں Omarchy مینو میں _اپ ڈیٹ > کنفگ_ کے ذریعے ہمیشہ ڈیفالٹس پر واپس لا سکتے ہو۔ یا سب کچھ ری سیٹ کرنے کے لیے `omarchy reinstall configs` چلا کر۔
