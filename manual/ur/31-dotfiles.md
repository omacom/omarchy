# ڈاٹ فائلز

Omarchy بنیادی طور پر نام نہاد dotfiles کے ذریعے ترتیب دیا جاتا ہے جو `~/.config` میں رہتی ہیں۔ وہ آپ کی تبدیلیوں کے لیے آپ کی فائلیں سمجھی جاتی ہیں۔ جو فائلیں `/usr/share/omarchy` میں رہتی ہیں وہ خود Omarchy کی ہیں، اور آپ کو ان کے ساتھ چھیڑ چھاڑ نہیں کرنی چاہیے۔ اگر آپ کو `/usr/share/omarchy` میں کچھ بھی تبدیل کرنے کی ضرورت ہے، تو اس کے بجائے آپ کو `~/.config` میں قدر کو اوور رائٹ کرنا چاہیے۔

کلیدی ترتیبات کو Omarchy مینو (`Super + Space`) سے براہ راست ترمیم کیا جا سکتا ہے، جیسے _سیٹ اپ > کی بورڈ > کی بائنڈنگز_، _سیٹ اپ > ان پٹ_، اور _سیٹ اپ > کنفگ > [file]_۔ جب آپ اس طرح کرتے ہیں، تو کوئی بھی عمل جسے ترتیب میں ترمیم کے بعد دوبارہ شروع کرنے کی ضرورت ہو، ایڈیٹر چھوڑنے کے بعد خود بخود ہو جائے گا (بذریعہ ڈیفالٹ Neovim — `:wq`، یاد رکھیں! — لیکن آپ اسے _سیٹ اپ > ڈیفالٹس > ایڈیٹر_ کے ذریعے تبدیل کر سکتے ہیں)۔

یہاں `~/.config` میں کلیدی فائلوں کی فہرست ہے اور وہ کیا کنٹرول کرتی ہیں:

| فائل                  | مقصد              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | مرکزی Hyprland کنفگ۔ Omarchy کے ڈیفالٹس کے علاوہ نیچے آپ کی اوور رائڈ فائلیں لوڈ کرتا ہے۔ [Hyprland کنفگز کے بارے میں مزید جانیں](https://wiki.hypr.land/Configuring/)۔  |
| `~/.config/hypr/bindings.lua` | آپ کی اپنی کی بائنڈنگز اور ڈیفالٹس کی اوور رائڈز۔ |
| `~/.config/hypr/monitors.lua` | مانیٹر کی وہ ترتیبات جن کا مانیٹر پینل احاطہ نہیں کرتا، جیسے گردش، اضافی موڈز، یا کسی مانیٹر کو بند رکھنا۔ |
| `~/.config/hypr/input.lua` | آپ کے کی بورڈ لے آؤٹ، ماؤس، اور ٹریک پیڈ کی ترتیبات کو کنٹرول کرتا ہے۔ |
| `~/.config/hypr/looknfeel.lua` | گیپس، بارڈرز، اینیمیشنز، اور باقی ظاہری شکل کو کنٹرول کرتا ہے۔ |
| `~/.config/hypr/autostart.lua` | سیشن کے ساتھ شروع کیے گئے اضافی عمل کو کنٹرول کرتا ہے۔ |
| `~/.config/omarchy/shell.json` | Omarchy شیل کو کنٹرول کرتا ہے: بار کی پوزیشن، لے آؤٹ، اور وِجٹس، علاوہ ازیں اسکرین سیور، لاک، اور آئیڈل کے اوقات۔ |
| `~/.config/foot/foot.ini` | آپ کے ٹرمینل کو کنٹرول کرتا ہے (foot ڈیفالٹ ہے)۔ |
| `~/.XCompose` | آپ کے فوری رسائی والے ایموجی اور نام/ای میل خودکار تکمیل کی تعریف کرتا ہے۔ تبدیلیاں کرنے کے بعد `omarchy-restart-xcompose` چلانا یقینی بنائیں۔ |

اگر آپ اپنے سیٹ اپ کو بہتر بنانے کے لیے بہت سی تبدیلیاں کر لیتے ہیں، تو ان تمام dotfiles کا بیک اپ لینا اچھا خیال ہے۔ [Stow ایسا کرنے کا ایک بہترین طریقہ ہے](https://www.youtube.com/watch?v=NoFiYOqnC4o)۔

### سیشن کے ساتھ اپنی ایپس شروع کرنا

اگر آپ چاہتے ہیں کہ ہر بار لاگ ان ہونے پر کچھ چلے — ایک سنک ڈیمن، ایک چیٹ ایپ، آپ کی اپنی اسکرپٹ — تو اسے `~/.config/hypr/autostart.lua` میں ڈالیں:

```lua
o.launch_on_start("my-service")
```

یہ کمانڈ کو سیشن کے حصے کے طور پر شروع کرتا ہے، اس لیے جب آپ دوبارہ لاگ آؤٹ کرتے ہیں تو اسے درست طریقے سے صاف کر دیا جاتا ہے۔

### سسٹم ایونٹس پر اسکرپٹس چلانا

Omarchy چند لمحات پر hooks فائر کرتا ہے، اور آپ اپنی اسکرپٹس کو ان سے جوڑ سکتے ہیں۔ وہ `~/.config/omarchy/hooks/<event>.d/` میں رہتے ہیں، ہر ایونٹ کے لیے ایک ڈائریکٹری، اور وہاں موجود ہر وہ فائل جو `.sample` پر ختم نہیں ہوتی، ایونٹ ہونے پر bash کے ساتھ چلتی ہے:

| ایونٹ | یہ کب چلتا ہے |
| ----- | ------------ |
| `post-boot` | ڈیسک ٹاپ شروع ہونے کے فوراً بعد |
| `post-update` | `omarchy update` کے اختتام کے قریب، پیکجز، مائیگریشنز، اور سروس دوبارہ شروع ہونے کے بعد، mise ٹولز اپ ڈیٹ ہونے سے پہلے |
| `pre-refresh-pacman` | `omarchy refresh pacman` کے پیکج کنفگ کو دوبارہ سنک کرنے کے بعد، اس کے پیکجز اپ ڈیٹ کرنے سے پہلے؛ چینل کی تبدیلی اسی ریفریش مرحلے کے دوران اسے چلاتی ہے |
| `theme-set` | تھیم کی تبدیلی کے بعد (تھیم کا نام `$1` میں) |
| `font-set` | فونٹ کی تبدیلی کے بعد (فونٹ کا نام `$1` میں) |
| `battery-low` | جب بیٹری کم ہو جائے (فیصد `$1` میں) |

`pre-refresh-pacman` ہک وہ جگہ ہے جہاں کسٹم ریپوزٹریز یا `IgnorePkg` لائنیں ہونی چاہئیں، کیونکہ یہ پیکج ٹرانزیکشن سے پہلے چلتا ہے۔ دونوں آپ کے صارف کے طور پر چلتے ہیں۔ `post-update` اس وقت چلتا ہے جب `omarchy update` کی sudo اجازت ابھی تازہ ہوتی ہے، اس لیے جو ہک `sudo` استعمال کرتا ہے وہ آپ سے دوبارہ پاس ورڈ نہیں مانگے گا؛ `pre-refresh-pacman` اس کے فوراً بعد چلتا ہے جب `omarchy refresh pacman` خود sudo استعمال کر چکا ہوتا ہے۔

ان میں سے ہر ڈائریکٹری میں پہلے سے ایک `.sample` فائل موجود ہے جو ہک کی شکل دکھاتی ہے — اسے کام پر لگانے کے لیے نام سے `.sample` ہٹا دیں۔ کسی اور جگہ لکھی گئی اسکرپٹ انسٹال کرنے کے لیے `omarchy hook install post-boot ~/my-hook` استعمال کریں، جو اسے اندر کاپی کر دیتا ہے اور اسے قابلِ اجرا بنا دیتا ہے۔

### اپنے مینو اندراجات شامل کرنا

Omarchy مینو (`Super + Space`) کو `~/.config/omarchy/extensions/omarchy-menu.jsonc` میں ترمیم کر کے اپنی قطاروں کے ساتھ بڑھایا جا سکتا ہے۔ اندراجات ایک ڈاٹ والے id کے تحت ہوتے ہیں، اور id ہی انہیں درخت میں رکھتا ہے، اس لیے `personal` روٹ مینو پر ظاہر ہوتا ہے اور `personal.notes` اس کے اندر ظاہر ہوتا ہے:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

موجودہ id کو دوبارہ استعمال کریں اور آپ نئی قطار شامل کرنے کے بجائے اس قطار کو اوور رائڈ کر دیتے ہیں۔ فائل تمام دستیاب فیلڈز کے ساتھ تبصروں کے طور پر دستاویزی شکل میں آتی ہے۔

### اپنے شیل ایکسپورٹس، فنکشنز، اور ایلیئسز شامل کرنا

Omarchy بہت سے ایرگونومک ایلیئسز اور مددگار فنکشنز کے ساتھ آتا ہے، لیکن اپنے شامل کرنا چاہنا بہت عام بات ہے۔ آپ کو ایلیئسز، فنکشنز، اور ایکسپورٹس سب `~/.bashrc` میں شامل کرنے چاہئیں۔ یہ فائل اپ ڈیٹس پر اوور رائٹ نہیں ہوگی۔ اگر آپ Omarchy کے کسی ڈیفالٹ کو تبدیل کرنا چاہتے ہیں، تو انہیں بھی یہاں محفوظ طریقے سے شامل کر سکتے ہیں۔

### ڈیسک ٹاپ کے لیے ماحول کے متغیرات ترتیب دینا

ڈیسک ٹاپ سیشن ایکسپورٹس `~/.config/uwsm/env.d/` میں ہوتے ہیں۔ یہ فائلیں آپ کے ڈیسک ٹاپ کے شروع ہونے سے پہلے چلتی ہیں، اس لیے شیل کی خرابی آپ کو واپس لاگ ان اسکرین پر بھیج سکتی ہے۔ ان میں ترمیم کرتے وقت ایک کام کرتا ٹرمینل کھلا رکھیں۔ اوور رائڈ کو غیر فعال کرنے کے لیے، اسے `env.d` سے باہر منتقل کر دیں۔ اگر کوئی تبدیلی لاگ ان کو روک دے تو [لاگ ان کی بحالی](45-troubleshooting.md#my-password-is-accepted-but-i-return-to-the-login-screen) دیکھیں۔

### اندرونی Omarchy فائلیں تبدیل کرنا

دیکھیں، یہ آپ کا کمپیوٹر ہے۔ آپ اس کے ساتھ جو چاہیں کر سکتے ہیں، لیکن میں `/usr/share/omarchy` میں فائلوں میں براہ راست تبدیلیاں کرنے کے خلاف مشورہ دوں گا۔ وہ Omarchy pacman پیکج سے تعلق رکھتی ہیں، اس لیے آپ کی تبدیلیاں اگلی اپ ڈیٹ پر بس اوور رائٹ ہو جائیں گی۔ اس کے بجائے آپ کے لیے بہتر یہی ہے کہ جن ڈیفالٹ اقدار کو آپ پسند نہیں کرتے انہیں `~/.config/*` فولڈر میں اوور رائٹ کر دیں۔

آپ اس طرح تقریباً ہر چیز تبدیل کر سکتے ہیں، جیسے ڈیفالٹ کی بائنڈنگز۔ بس `~/.config/hypr/bindings.lua` میں ترمیم کر کے، مثال کے طور پر، [Obsidian](https://obsidian.md/) کو [Joplin](https://joplinapp.org/) سے بدل دیں (`omarchy-pkg-add joplin-bin` کے ساتھ انسٹال کریں):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` اپنی تبدیلی شامل کرنے سے پہلے موجودہ بائنڈنگ کو ہٹا دیتا ہے۔ یہ `o.bind` جیسے ہی دلائل لیتا ہے، بشمول لانچ ہیلپرز اور بائنڈنگ آپشنز۔ بائنڈنگ شامل کرنے کے لیے `o.bind` استعمال کریں، یا اسے بدلے بغیر ہٹانے کے لیے `hl.unbind` استعمال کریں۔

اگر آپ اندرونی Omarchy فائلوں پر ہیکنگ کرنے پر اصرار کرتے ہیں، تو _اپ ڈیٹ > چینل > Dev_ کے ذریعے dev چینل پر سوئچ کریں۔ یہ Omarchy کو `~/omarchy` میں سورس کوڈ کے git چیک آؤٹ سے جوڑ دیتا ہے، جسے آپ دل بھر کر تبدیل کرنے کے لیے آزاد ہیں۔ یہاں کوئی آپ کو بتانے والا نہیں کہ کیا کرنا ہے!

### کوئی بھی تبدیلی ری سیٹ کرنا

اگر آپ ترتیبات کا گڑبڑ کر لیتے ہیں، تو آپ انہیں Omarchy مینو میں _اپ ڈیٹ > کنفگ_ کے ذریعے ہمیشہ ڈیفالٹس پر واپس لا سکتے ہیں۔ یا سب کچھ ری سیٹ کرنے کے لیے `omarchy reinstall configs` چلا کر۔
