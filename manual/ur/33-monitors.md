# مانیٹر

Omarchy بطور ڈیفالٹ یہ فرض کرتا ہے کہ آپ 2x کی صلاحیت رکھنے والی retina-class ڈسپلے استعمال کر رہے ہیں۔ یہی وہ چیز ہے جس کی آپ کو وہ اچھے، کرسپ پروگرامر فونٹس حاصل کرنے کے لیے ضرورت ہے۔ یہی وہ چیز ہے جس کے لیے تقریباً تمام نئی پریمیم لیپ ٹاپس جن میں ہائی ریزولوشن اسکرینیں ہیں، آپٹمائزڈ ہیں۔ یہی وہ چیز ہے جسے آپ 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) یا 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) پر چلانا چاہیں گے۔

لیکن اگر آپ ایسی ڈسپلے استعمال نہیں کر رہے جس کا PPI 218 یا اس سے زیادہ ہو، تو آپ مانیٹر سیٹنگز تبدیل کرنا چاہیں گے۔ مثال کے طور پر، اگر آپ کے پاس 27" یا 32" 4K ہے، تو آپ `~/.config/hypr/monitors.lua` کھول کر (Omarchy مینو میں _سیٹ اپ > مانیٹرز_ کے ذریعے) fractional scaling استعمال کر سکتے ہیں اور اس کمبی نیشن کے لیے تجویز کردہ سیٹنگ پر سوئچ کر سکتے ہیں:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

اگر آپ 1080p یا 1440p ڈسپلے استعمال کر رہے ہیں، تو آپ غالباً صرف 1x scaling استعمال کرنا چاہیں گے، لہٰذا آپ یہ استعمال کر سکتے ہیں:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

`GDK_SCALE` میں تبدیلیاں اس تبدیلی کے بعد شروع کی گئی ایپلیکیشنز پر لاگو ہوتی ہیں (اور GTK صرف مکمل اعداد کو قبول کرتا ہے، لہٰذا اسے اپنے مانیٹر اسکیل کے قریب ترین صحیح عدد پر رکھیں)۔ لہٰذا یقینی بنائیں کہ تبدیلی کے بعد آپ ان ونڈوز کو بند کر دیں جو آپ کے پاس بڑی سائز کی ہیں (یا `Ctrl + Alt + Del` کے ساتھ تمام ونڈوز بند کر دیں!)۔

آپ `Super + /` استعمال کر کے اوپر جانے اور `Super + Alt + /` استعمال کر کے نیچے جانے کے ذریعے بھی اہم مانیٹر اسکیلنگ تناسبات (1x، 1.25x، 1.6x، 2x، 3x، 4x) میں تیزی سے آگے بڑھ سکتے ہیں۔ اگر آپ کے پاس ڈیفالٹ کنفیگریشن ہے، تو یہ تبدیلیاں ری بوٹ کے بعد بھی برقرار رہیں گی۔

### متن کو بڑا یا چھوٹا کرنا

مانیٹر اسکیلنگ ہر چیز کا سائز تبدیل کر دیتی ہے۔ اگر آپ صرف بڑا یا چھوٹا _متن_ چاہتے ہیں، تو اس کے لیے ایک ہی نوب ہے:

```
omarchy display text size 14
```

یہ 9 اور 20 کے درمیان ایک پکسل سائز لیتا ہے، اور Omarchy شیل، GTK ایپلیکیشنز، اور آپ کے ٹرمینل کو ایک ساتھ منتقل کرتا ہے، تاکہ پورا ڈیسک ٹاپ تناسب میں رہے۔ یہ دیکھنے کے لیے کہ آپ اس وقت کہاں ہیں، اسے بغیر کسی آرگیومنٹ کے چلائیں، اور ڈیفالٹ پر واپس جانے کے لیے `omarchy display text size reset` چلائیں۔ Foot واحد پیچھے رہ جانے والا ہے: اس کے پاس اپنی کنفیگ کو دوبارہ لوڈ کرنے کا کوئی طریقہ نہیں ہے، لہٰذا چلتے ہوئے ٹرمینلز اپنے پرانے سائز کو اس وقت تک برقرار رکھتے ہیں جب تک آپ نیا ٹرمینل نہ کھولیں۔

### لیپ ٹاپ ڈسپلےز کو بڑھانا اور مرر کرنا

جب آپ اپنے لیپ ٹاپ سے ایکسٹرنل اسکرین منسلک کرتے ہیں، تو ڈسپلے خود بخود بڑھ جاتی ہے۔ لیکن آپ Omarchy مینو میں _ٹرگر > ہارڈ ویئر_ استعمال کر کے یا `Super + Ctrl + Alt + Delete` استعمال کر کے اسے اس کے بجائے مررنگ میں تبدیل کر سکتے ہیں۔ یہ خاص طور پر مددگار ہے اگر وہ ایکسٹرنل اسکرین کوئی پروجیکٹر ہو، اور آپ کام کرتے ہوئے کچھ دکھانا چاہتے ہوں۔

جب آپ ایکسٹینڈ کر رہے ہوں، تو لیپ ٹاپ کا ڈھکن بند کرنے سے اندرونی اسکرین خود بخود بند ہو جائے گی۔ ڈھکن کھولنے سے یہ دوبارہ آن ہو جائے گی۔ آپ Omarchy مینو میں _ٹرگر > ہارڈ ویئر_ استعمال کر کے یا `Super + Ctrl + Delete` استعمال کر کے اسے دستی طور پر بھی کنٹرول کر سکتے ہیں۔

### متعدد اسکرینوں کو ترتیب دینا

Hyprland متعدد اسکرینوں کے ساتھ بہت اچھا کام کرتا ہے۔ انہیں ترتیب دینے کے طریقے کے بارے میں [Hyprland مانیٹر دستاویزات](https://wiki.hypr.land/Configuring/Basics/Monitors/) میں مزید پڑھیں۔ Omarchy میں، یہ `~/.config/hypr/monitors.lua` میں `hl.monitor` اندراجات کے طور پر جاتی ہیں — فائل میں کسی مخصوص مانیٹر کو ریزولوشن، پوزیشن، اور گردش کے ساتھ پن کرنے کے لیے کمنٹ شدہ مثالیں شامل ہیں۔

ہر مانیٹر کے اپنے ورک اسپیسز 1 سے 10 تک ہوتے ہیں، لہٰذا `Super + 1` کا ہمیشہ مطلب ہوتا ہے اس مانیٹر کا پہلا ورک اسپیس جس پر آپ ہیں۔ پردے کے پیچھے، Hyprland اب بھی تمام مانیٹرز میں ورک اسپیسز کو نمبر دیتا ہے: آپ کی لیپ ٹاپ اسکرین (یا پہلا مانیٹر) کو 1–10 ملتے ہیں، اگلے مانیٹر کو 11–20 ملتے ہیں، اور اسی طرح آگے، اور ہر مانیٹر ہر بار جب آپ اسے پلگ ان کرتے ہیں اپنا بلاک برقرار رکھتا ہے۔ اگر آپ کسی مخصوص مانیٹر کے لیے [ورک اسپیس رولز](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) یا ونڈو رولز لکھتے ہیں تو ان نمبروں کا استعمال کریں، تاکہ ورک اسپیس 12 آپ کے دوسرے مانیٹر کا دوسرا ورک اسپیس ہو۔ `~/.local/state/omarchy/monitor-workspaces` درج کرتا ہے کہ ہر مانیٹر کے پاس کون سا بلاک ہے۔

ایرو کیز ان مانیٹرز میں کام کرتی ہیں جو آپ کی ترتیب میں ایک کنارہ साझा کرتے ہیں۔ وہ اسکرینیں جو صرف ایک کونے پر چھوتی ہیں، یا جن کے درمیان فاصلہ ہوتا ہے، پڑوسی نہیں ہوتیں، لہٰذا ان کے درمیان جانے کے لیے `Ctrl + Alt + Tab` استعمال کریں۔

| ہاٹ کی | مانیٹرز کے درمیان |
| --- | --- |
| `Super + Arrow` | جب اس سمت میں کوئی ونڈو باقی نہ رہے تو فوکس کو اس طرف والے مانیٹر پر منتقل کر دیتی ہے |
| `Super + Shift + Arrow` | اس طرف والے مانیٹر پر موجود ونڈو کے ساتھ تبادلہ کرتی ہے |
| `Super + Alt + Arrow` | ونڈو کو اس طرف والے مانیٹر پر کسی گروپ میں منتقل کر دیتی ہے |
| `Super + Shift + Ctrl + Arrow` | ونڈو کو اس طرف والے مانیٹر پر، اس ورک اسپیس پر منتقل کر دیتی ہے جو وہ دکھا رہا ہے |
| `Super + Shift + Alt + Arrow` | ورک اسپیس کو اس طرف والے مانیٹر پر منتقل کر دیتی ہے، اگر اس کا نمبر خالی ہو تو اسے برقرار رکھتی ہے |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | ترتیب کچھ بھی ہو، فوکس کو اگلے یا پچھلے مانیٹر پر منتقل کر دیتی ہے |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | اسی مانیٹر پر رہتی ہیں جس پر آپ ہیں |

آپ [Hyprmon](https://github.com/erans/hyprmon/) بھی دیکھ سکتے ہیں، اگر آپ متعدد اسکرینوں کی پوزیشننگ میں مدد کے لیے TUI چاہتے ہیں۔

### چمک کو کنٹرول کرنا

مانیٹر کی چمک چمک بڑھانے/کم کرنے کے لیے مخصوص فنکشن کیز کے ذریعے کنٹرول کی جاتی ہے۔ اگر آپ انہیں دباتے ہوئے shift کو دبائے رکھتے ہیں، تو آپ زیادہ سے زیادہ یا کم سے کم چمک پر چلے جائیں گے۔ کیز اس ڈسپلے کو کنٹرول کرتی ہیں جس پر آپ فوکس کیے ہوئے ہیں، لہٰذا DDC/CI بولنے والے ایکسٹرنل مانیٹرز کو بھی لیپ ٹاپ اسکرین کی طرح ایڈجسٹ کیا جاتا ہے۔

### Apple ڈسپلےز

اگر آپ Apple ڈسپلے استعمال کر رہے ہیں، تو باقاعدہ کی بورڈ برائٹنس کیز بھی خود بخود کام کریں گی، اگر آپ Apple ڈسپلے پر فوکس کیے ہوئے ہیں۔ یہ `asdcontrol` کمانڈ کے ذریعے کیا جاتا ہے۔

نوٹ کریں کہ اگر آپ Apple 6K XDR ڈسپلے استعمال کر رہے ہیں، تو آپ کو اپنی `hyprctl monitors` فہرست میں ایک فینٹم اسکرین نظر آ سکتی ہے۔ آپ _سیٹ اپ > مانیٹرز_ کے ذریعے `hl.monitor({ output = "DP-2", disabled = true })` جیسی کسی چیز کے ساتھ اسے بند کر سکتے ہیں۔

Intel مشینوں پر، آپ کو باقاعدہ Thunderbolt کیبل استعمال کر کے Apple ڈسپلےز سے منسلک ہونا چاہیے۔ Thunderbolt کے بغیر دیگر مشینوں پر، آپ کو اسے کام کرنے کے لیے عام طور پر [DP + USB-A -> USB-C کیبل](https://www.amazon.com/dp/B0BNX7MS6N) استعمال کرنا ہوگا۔
