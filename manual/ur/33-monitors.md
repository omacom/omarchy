# مانیٹر

Omarchy طے شدہ طور پر فرض کرتا ہے کہ آپ 2x کی اہلیت رکھنے والے retina-class ڈسپلے پر چلا رہے ہیں۔ ان عمدہ، صاف شفاف پروگرامر فونٹس کو حاصل کرنے کے لیے آپ کو یہی چاہیے۔ تقریباً تمام نئے پریمیم لیپ ٹاپس جن میں ہائی ریزولوشن اسکرینیں ہیں، اسی کے لیے بہتر بنائے گئے ہیں۔ یہی آپ 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) یا 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) پر چلانا چاہیں گے۔

لیکن اگر آپ 218 یا اس سے زیادہ PPI والے ڈسپلے پر نہیں چلا رہے تو آپ مانیٹر کی ترتیبات تبدیل کرنا چاہیں گے۔ مثال کے طور پر، اگر آپ کے پاس 27" یا 32" 4K ہے تو آپ اوپر والے بار میں موجود مانیٹر پینل سے اس کے لیے کسری اسکیل منتخب کر سکتے ہیں، یا `~/.config/hypr/monitors.lua` کھول کر اور اس مجموعے کے لیے تجویز پر تبدیل کر کے ہر مانیٹر کے لیے طے شدہ قدر مقرر کر سکتے ہیں:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

اگر آپ 1080p یا 1440p ڈسپلے استعمال کر رہے ہیں تو آپ شاید صرف 1x اسکیلنگ استعمال کرنا چاہیں گے، اور GTK اور X11 ایپس کے لیے بھی یہی، تو آپ یہ استعمال کر سکتے ہیں:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

`GDK_SCALE` میں تبدیلیاں اس تبدیلی کے بعد شروع کی گئی ایپلیکیشنز پر لاگو ہوتی ہیں (اور GTK صرف صحیح اعداد کو مانتا ہے، اس لیے اسے اپنے مانیٹر اسکیل کے قریب ترین صحیح عدد پر رکھیں)۔ اس لیے یقینی بنائیں کہ تبدیلی کے بعد آپ کے پاس جو ونڈوز حد سے زیادہ بڑی ہیں آپ انہیں بند کر دیں (یا `Ctrl + Alt + Del` سے تمام ونڈوز بند کر دیں!)۔

آپ `Super + /` استعمال کر کے اونچا جانے اور `Super + Alt + /` استعمال کر کے نیچا جانے کے ذریعے بڑے مانیٹر اسکیلنگ تناسبات (1x, 1.25x, 1.6x, 2x, 3x, 4x) میں سے بھی تیزی سے گزر سکتے ہیں، یا اوپر والے بار میں موجود مانیٹر پینل سے ایک منتخب کر سکتے ہیں۔ یہ صرف اس مانیٹر کو تبدیل کرتے ہیں جس پر آپ کا فوکس ہے، اس لیے لیپ ٹاپ کی اسکرین اور بیرونی ڈسپلے ہر ایک کا اپنا اسکیل ہو سکتا ہے۔ یہ پینل ہر مانیٹر کی ریزولوشن، ریفریش ریٹ اور گردش بھی مقرر کرتا ہے۔ آپ کے انتخاب اس طبعی مانیٹر کے لیے `~/.local/state/omarchy/monitors/settings` میں محفوظ ہوتے ہیں، اس لیے وہ ری بوٹ کے بعد بھی برقرار رہتے ہیں اور اگلی بار مانیٹر جس پورٹ یا ڈاک میں بھی لگایا جائے اس کے ساتھ جاتے ہیں۔ وہ `~/.config/hypr/monitors.lua` میں اسی مانیٹر کے لیے کسی بھی اصول پر فوقیت رکھتے ہیں، جسے Omarchy کبھی ترمیم نہیں کرتا۔ اگر آپ اپنے مانیٹر مکمل طور پر اسی فائل میں مقرر کرنا پسند کریں تو اس میں `omarchy_monitor_panel_settings = false` شامل کر دیں، اور پینل کی تبدیلیاں صرف اس وقت تک رہیں گی جب تک Hyprland دوبارہ لوڈ نہ ہو۔ چونکہ `GDK_SCALE` تمام اسکرینوں کے لیے ایک ہی قدر ہے، اس لیے منتخب کردہ اسکیل اسے سب سے کم اسکیل والے مانیٹر سے مقرر کرتا ہے، اس لیے X11 ایپس دوسری اسکرین پر حد سے زیادہ بڑی ہونے کے بجائے زیادہ گھنی اسکرین پر تھوڑی چھوٹی نکلتی ہیں۔

### متن کو بڑا یا چھوٹا کرنا

مانیٹر اسکیلنگ ہر چیز کا سائز تبدیل کرتی ہے۔ اگر آپ صرف بڑا یا چھوٹا _text_ چاہتے ہیں تو اس کے لیے ایک ہی نوب ہے:

```
omarchy display text size 14
```

یہ 9 اور 20 کے درمیان پکسل سائز لیتا ہے، اور Omarchy شیل، GTK ایپلیکیشنز، اور آپ کے ٹرمینل کو ایک ساتھ حرکت دیتا ہے، اس لیے پورا ڈیسک ٹاپ تناسب میں رہتا ہے۔ آپ کہاں ہیں یہ دیکھنے کے لیے اسے بغیر کسی آرگیومنٹ کے چلائیں، اور طے شدہ پر واپس جانے کے لیے `omarchy display text size reset` چلائیں۔ Foot واحد پیچھے رہ جانے والا ہے: اس کے پاس اپنی ترتیب کو دوبارہ لوڈ کرنے کا کوئی طریقہ نہیں ہے، اس لیے چلتے ہوئے ٹرمینل اپنا پرانا سائز برقرار رکھتے ہیں جب تک آپ نیا نہ کھولیں۔

### لیپ ٹاپ ڈسپلے کو پھیلانا اور اس کی عکس بندی کرنا

جب آپ اپنے لیپ ٹاپ سے بیرونی اسکرین منسلک کرتے ہیں تو ڈسپلے خود بخود پھیل جاتا ہے۔ لیکن آپ Omarchy مینیو میں _Trigger > Hardware_ یا `Super + Ctrl + Alt + Delete` استعمال کر کے اسے اس کے بجائے عکس بندی میں تبدیل کر سکتے ہیں۔ یہ خاص طور پر مددگار ہے اگر وہ بیرونی اسکرین پروجیکٹر ہو، اور آپ کام کرتے ہوئے کچھ دکھانا چاہتے ہوں۔

جب آپ پھیلا رہے ہوں تو لیپ ٹاپ کا ڈھکن بند کرنے سے اندرونی اسکرین خود بخود بند ہو جائے گی۔ ڈھکن کھولنے سے وہ دوبارہ آن ہو جائے گی۔ آپ Omarchy مینیو میں _Trigger > Hardware_ یا `Super + Ctrl + Delete` استعمال کر کے اسے دستی طور پر بھی کنٹرول کر سکتے ہیں۔

### متعدد اسکرینوں کو ترتیب دینا

Hyprland متعدد اسکرینوں کے ساتھ بہت اچھا کام کرتا ہے۔ اوپر والے بار میں موجود مانیٹر پینل انہیں وہیں کھینچتا ہے جہاں وہ بیٹھی ہیں: کسی ایک کو دوسری کے کنارے کے خلاف گھسیٹ کر وہاں منتقل کریں، اور یہ ترتیب ہر مانیٹر کی دیگر ترتیبات کے ساتھ محفوظ ہو جاتی ہے۔ پینل جس چیز کا احاطہ نہیں کرتا، اس کے لیے انہیں ترتیب دینے کے بارے میں مزید [Hyprland مانیٹر دستاویزات](https://wiki.hypr.land/Configuring/Basics/Monitors/) میں پڑھیں۔ Omarchy میں، یہ `~/.config/hypr/monitors.lua` میں `hl.monitor` اندراجات کے طور پر جاتے ہیں — فائل مانیٹر کو بند رکھنے، پینل جو موڈ پیش نہیں کرتا، 10-bit رنگ، اور متغیر ریفریش ریٹ کے لیے تبصرہ شدہ مثالوں کے ساتھ آتی ہے۔

ہر مانیٹر کے اپنے ورک اسپیس 1 تا 10 ہوتے ہیں، اس لیے `Super + 1` کا ہمیشہ مطلب اس مانیٹر کا پہلا ورک اسپیس ہوتا ہے جس پر آپ ہیں۔ پردے کے پیچھے، Hyprland اب بھی تمام مانیٹروں میں ورک اسپیسز کو نمبر دیتا ہے: آپ کی لیپ ٹاپ اسکرین (یا پہلے مانیٹر) کو 1–10 ملتے ہیں، اگلے مانیٹر کو 11–20، اور اسی طرح آگے، اور ہر مانیٹر جب بھی آپ اسے لگاتے ہیں اپنا بلاک برقرار رکھتا ہے۔ اگر آپ کسی مخصوص مانیٹر کے لیے [ورک اسپیس قوانین](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) یا ونڈو کے قوانین لکھتے ہیں تو وہ نمبر استعمال کریں، اس لیے ورک اسپیس 12 آپ کے دوسرے مانیٹر کا دوسرا ورک اسپیس ہے۔ `~/.local/state/omarchy/monitors/workspaces` فہرست دیتا ہے کہ ہر مانیٹر کے پاس کون سا بلاک ہے۔

تیر والی کلیدیں ان مانیٹروں کے درمیان کام کرتی ہیں جو آپ کی ترتیب میں ایک کنارا مشترک رکھتے ہیں۔ وہ اسکرینیں جو صرف کونے پر چھوتی ہیں، یا جن کے درمیان فاصلہ ہے، پڑوسی نہیں ہیں، اس لیے ان کے درمیان جانے کے لیے `Ctrl + Alt + Tab` استعمال کریں۔

| Hotkey | مانیٹروں کے درمیان |
| --- | --- |
| `Super + Arrow` | اس طرف کے مانیٹر پر فوکس منتقل کرتا ہے جب اس سمت میں کوئی ونڈو باقی نہ رہے |
| `Super + Shift + Arrow` | اس طرف کے مانیٹر پر موجود ونڈو کے ساتھ تبادلہ کرتا ہے |
| `Super + Alt + Arrow` | ونڈو کو اس طرف کے مانیٹر پر موجود گروپ میں منتقل کرتا ہے |
| `Super + Shift + Ctrl + Arrow` | ونڈو کو اس طرف کے مانیٹر پر، اس ورک اسپیس پر منتقل کرتا ہے جو وہ دکھا رہا ہے |
| `Super + Shift + Alt + Arrow` | ورک اسپیس کو اس طرف کے مانیٹر پر منتقل کرتا ہے، اگر وہ خالی ہو تو اس کا نمبر برقرار رکھتا ہے |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | ترتیب کچھ بھی ہو، اگلے یا پچھلے مانیٹر پر فوکس منتقل کرتا ہے |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | آپ جس مانیٹر پر ہیں اسی پر رہتے ہیں |

آپ [Hyprmon](https://github.com/erans/hyprmon/) بھی دیکھ سکتے ہیں، اگر آپ متعدد اسکرینوں کی پوزیشننگ میں مدد کے لیے TUI چاہتے ہیں۔

### چمک کو کنٹرول کرنا

مانیٹر کی چمک چمک بڑھانے/کم کرنے کے لیے مخصوص فنکشن کلیدوں سے کنٹرول کی جاتی ہے۔ اگر آپ انہیں دباتے وقت shift کو دبائے رکھیں تو آپ زیادہ سے زیادہ یا کم سے کم چمک پر چلے جائیں گے۔ یہ کلیدیں اس ڈسپلے کو کنٹرول کرتی ہیں جس پر آپ کا فوکس ہے، اس لیے DDC/CI بولنے والے بیرونی مانیٹر لیپ ٹاپ اسکرین کی طرح ہی ایڈجسٹ ہوتے ہیں۔

### Apple ڈسپلے

اگر آپ Apple ڈسپلے استعمال کر رہے ہیں تو باقاعدہ کی بورڈ برائٹنس کلیدیں بھی خود بخود کام کریں گی، اگر آپ کا فوکس Apple ڈسپلے پر ہو۔ یہ `asdcontrol` کمانڈ کے ذریعے کیا جاتا ہے۔

نوٹ کریں کہ اگر آپ Apple 6K XDR ڈسپلے استعمال کر رہے ہیں تو آپ کو اپنی `hyprctl monitors` فہرست میں ایک بھوت اسکرین نظر آ سکتی ہے۔ آپ اسے `~/.config/hypr/monitors.lua` میں `hl.monitor({ output = "DP-2", disabled = true })` جیسی کسی چیز سے بند کر سکتے ہیں۔

Intel مشینوں پر، آپ کو Apple ڈسپلے کو باقاعدہ Thunderbolt کیبل استعمال کر کے منسلک کرنا چاہیے۔ Thunderbolt کے بغیر دیگر مشینوں پر، آپ کو عام طور پر اسے کام کرنے کے لیے [DP + USB-A -> USB-C کیبل](https://www.amazon.com/dp/B0BNX7MS6N) استعمال کرنا پڑے گی۔
