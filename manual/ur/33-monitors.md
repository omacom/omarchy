# مانیٹرز

Omarchy بطور ڈیفالٹ یہ فرض کرتا ہے کہ آپ 2x کی اہلیت رکھنے والی retina کلاس ڈسپلے چلا رہے ہیں۔ آپ کو وہ عمدہ، کرسپ پروگرامر فونٹس حاصل کرنے کے لیے یہی درکار ہے۔ یہی وہ چیز ہے جس کے لیے ہائی ریزولوشن اسکرینوں والے تقریباً تمام نئے پریمیم لیپ ٹاپس آپٹمائز کیے گئے ہیں۔ یہی وہ چیز ہے جو آپ 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) یا 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) پر چلانا چاہیں گے۔

لیکن اگر آپ 218 یا اس سے زیادہ PPI والی ڈسپلے نہیں چلا رہے تو آپ مانیٹر کی سیٹنگز تبدیل کرنا چاہیں گے۔ مثال کے طور پر، اگر آپ کے پاس 27" یا 32" 4K ہے تو آپ ٹاپ بار میں موجود مانیٹر پینل سے اس کے لیے فریکشنل اسکیل منتخب کر سکتے ہیں، یا `~/.config/hypr/monitors.lua` کھول کر اور اس کمبی نیشن کے لیے تجویز کردہ آپشن پر سوئچ کر کے ہر مانیٹر کے لیے ڈیفالٹ مقرر کر سکتے ہیں:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

اگر آپ 1080p یا 1440p ڈسپلے استعمال کر رہے ہیں تو غالباً آپ بس 1x اسکیلنگ استعمال کرنا چاہیں گے، اور GTK اور X11 ایپس کے لیے بھی یہی، لہٰذا آپ یہ استعمال کر سکتے ہیں:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

`GDK_SCALE` میں تبدیلیاں اس تبدیلی کے بعد شروع کی جانے والی ایپلیکیشنز پر لاگو ہوتی ہیں (اور GTK صرف مکمل اعداد کو مانتا ہے، لہٰذا اسے اپنے مانیٹر اسکیل کے قریب ترین صحیح عدد پر رکھیں)۔ لہٰذا یقینی بنائیں کہ تبدیلی کے بعد آپ کے پاس جو ونڈوز ضرورت سے زیادہ بڑی ہیں، آپ انہیں بند کر دیں (یا `Ctrl + Alt + Del` کے ساتھ تمام ونڈوز بند کر دیں!)۔

آپ اوپر جانے کے لیے `Super + /` اور نیچے آنے کے لیے `Super + Alt + /` استعمال کر کے اہم مانیٹر اسکیلنگ تناسبات (1x، 1.25x، 1.6x، 2x، 3x، 4x) میں تیزی سے مرحلہ وار آگے بھی بڑھ سکتے ہیں، یا ٹاپ بار میں موجود مانیٹر پینل سے کوئی ایک منتخب کر سکتے ہیں۔ یہ صرف اس مانیٹر کو تبدیل کرتے ہیں جس پر آپ فوکس کیے ہوئے ہیں، لہٰذا لیپ ٹاپ اسکرین اور بیرونی ڈسپلے ہر ایک کا اپنا اسکیل ہو سکتا ہے۔ پینل ہر مانیٹر کی ریزولوشن، ریفریش ریٹ اور روٹیشن بھی مقرر کرتا ہے۔ آپ کے انتخاب اس فزیکل مانیٹر کے لیے `~/.local/state/omarchy/monitors/settings` میں محفوظ کیے جاتے ہیں، لہٰذا وہ ری بوٹ کے بعد بھی برقرار رہتے ہیں اور مانیٹر کے ساتھ اس پورٹ یا ڈاک تک جاتے ہیں جس میں اسے آگے لگایا جائے۔ وہ `~/.config/hypr/monitors.lua` میں اسی مانیٹر کے لیے کسی بھی رول پر فوقیت رکھتے ہیں، جسے Omarchy کبھی ایڈٹ نہیں کرتا۔ اگر آپ اپنے مانیٹرز مکمل طور پر اسی فائل میں مقرر کرنا پسند کریں تو اس میں `omarchy_monitor_panel_settings = false` شامل کر دیں، اور پینل کی تبدیلیاں صرف اس وقت تک رہیں گی جب تک Hyprland ری لوڈ نہ ہو جائے۔ چونکہ `GDK_SCALE` تمام اسکرینوں کے لیے ایک ہی قدر ہے، لہٰذا منتخب کردہ اسکیل اسے سب سے کم اسکیل والے مانیٹر سے مقرر کرتا ہے، لہٰذا X11 ایپس دوسری اسکرین پر ضرورت سے زیادہ بڑی ہونے کے بجائے زیادہ گھنی اسکرین پر کچھ چھوٹی نکلتی ہیں۔

### متن کو بڑا یا چھوٹا کرنا

مانیٹر اسکیلنگ ہر چیز کا سائز تبدیل کرتی ہے۔ اگر آپ بس بڑا یا چھوٹا _متن_ چاہتے ہیں تو اس کے لیے ایک ہی نوب ہے:

```
omarchy display text size 14
```

یہ 9 اور 20 کے درمیان پکسل سائز لیتا ہے، اور Omarchy شیل، GTK ایپلیکیشنز اور آپ کے ٹرمینل کو ایک ساتھ منتقل کرتا ہے، لہٰذا پورا ڈیسک ٹاپ تناسب میں رہتا ہے۔ آپ اس وقت کہاں ہیں، یہ دیکھنے کے لیے اسے بغیر کسی آرگیومنٹ کے چلائیں، اور ڈیفالٹ پر واپس جانے کے لیے `omarchy display text size reset` چلائیں۔ Foot واحد پیچھے رہ جانے والا ہے: اس کے پاس اپنی کنفگ کو ری لوڈ کرنے کا کوئی طریقہ نہیں ہے، لہٰذا چلتے ہوئے ٹرمینلز اپنا پرانا سائز اس وقت تک برقرار رکھتے ہیں جب تک آپ نیا نہ کھولیں۔

### لیپ ٹاپ ڈسپلے کو توسیع دینا اور مرر کرنا

جب آپ اپنے لیپ ٹاپ سے بیرونی اسکرین جوڑتے ہیں تو ڈسپلے خود بخود توسیع پا جاتی ہے۔ لیکن آپ ٹاپ بار میں موجود مانیٹر پینل میں _Extend_ | _Mirror_، Omarchy مینو میں _Trigger > Hardware_، یا `Super + Ctrl + Alt + Delete` کے ساتھ اس کے بجائے اسے مررنگ میں تبدیل کر سکتے ہیں۔ یہ خاص طور پر مددگار ہے اگر وہ بیرونی اسکرین کوئی پروجیکٹر ہو، اور آپ کام کرتے ہوئے کچھ دکھانا چاہتے ہوں۔

جب آپ توسیع دے رہے ہوں تو لیپ ٹاپ کا ڈھکن بند کرنے سے اندرونی اسکرین خود بخود بند ہو جائے گی۔ ڈھکن کھولنے سے وہ دوبارہ آن ہو جائے گی۔ آپ Omarchy مینو میں _Trigger > Hardware_ یا `Super + Ctrl + Delete` استعمال کر کے اسے دستی طور پر بھی کنٹرول کر سکتے ہیں۔

جب لیپ ٹاپ پلگ ان ہو تو ڈھکن بند کرنے سے وہ کبھی سلیپ میں نہیں جاتا، لہٰذا ڈاک شدہ لیپ ٹاپ بیدار رہتا ہے چاہے بیرونی اسکرین مختصر طور پر منقطع ہی کیوں نہ ہو جائے۔ کوئی بیرونی اسکرین منسلک نہ ہو تو پاور پر ڈھکن بند کرنے سے وہ بس لاک ہو جاتا ہے۔ بیٹری پر، ڈھکن بند کرنے سے حسبِ معمول سسپینڈ ہو جاتا ہے۔

### متعدد اسکرینوں کو ترتیب دینا

Hyprland متعدد اسکرینوں کے ساتھ بہت اچھا کام کرتا ہے۔ ٹاپ بار میں موجود مانیٹر پینل انہیں وہیں کھینچتا ہے جہاں وہ بیٹھتی ہیں: کسی ایک کو دوسری کے کنارے کے ساتھ گھسیٹ کر وہاں منتقل کریں، اور ترتیب ہر مانیٹر کی دیگر سیٹنگز کے ساتھ محفوظ ہو جاتی ہے۔ پینل جس چیز کا احاطہ نہیں کرتا، اس کے لیے انہیں ترتیب دینے کے طریقے کے بارے میں [Hyprland مانیٹر دستاویزات](https://wiki.hypr.land/Configuring/Basics/Monitors/) میں مزید پڑھیں۔ Omarchy میں، یہ `hl.monitor` اندراجات کے طور پر `~/.config/hypr/monitors.lua` میں جاتی ہیں — فائل مانیٹر کو بند رکھنے، پینل جو موڈز پیش نہیں کرتا، 10-bit رنگ، اور متغیر ریفریش ریٹ کے لیے تبصرہ شدہ مثالوں کے ساتھ آتی ہے۔

ہر مانیٹر کے اپنے ورک اسپیس 1 سے 10 تک ہوتے ہیں، لہٰذا `Super + 1` کا ہمیشہ مطلب اس مانیٹر کا پہلا ورک اسپیس ہوتا ہے جس پر آپ ہیں۔ پردے کے پیچھے، Hyprland اب بھی تمام مانیٹرز میں ورک اسپیسز کو نمبر دیتا ہے: آپ کی لیپ ٹاپ اسکرین (یا پہلے مانیٹر) کو 1–10 ملتے ہیں، اگلے مانیٹر کو 11–20، اور اسی طرح آگے، اور ہر مانیٹر ہر بار جب آپ اسے لگاتے ہیں اپنا بلاک برقرار رکھتا ہے۔ اگر آپ کسی مخصوص مانیٹر کے لیے [ورک اسپیس رولز](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) یا ونڈو رولز لکھیں تو وہ نمبر استعمال کریں، لہٰذا ورک اسپیس 12 آپ کے دوسرے مانیٹر کا دوسرا ورک اسپیس ہے۔ `~/.local/state/omarchy/monitors/workspaces` فہرست دیتا ہے کہ ہر مانیٹر کے پاس کون سا بلاک ہے۔

ایرو کیز ان مانیٹرز کے درمیان کام کرتی ہیں جو آپ کی ترتیب میں ایک کنارہ साझा کرتی ہیں۔ وہ اسکرینیں جو صرف کسی کونے پر چھوتی ہیں، یا جن کے درمیان فاصلہ ہے، پڑوسی نہیں ہیں، لہٰذا ان کے درمیان جانے کے لیے `Ctrl + Alt + Tab` استعمال کریں۔

| ہاٹ کی | مانیٹرز کے پار |
| --- | --- |
| `Super + Arrow` | اس سمت میں کوئی ونڈو باقی نہ رہنے پر اس طرف والے مانیٹر پر فوکس منتقل کرتا ہے |
| `Super + Shift + Arrow` | اس طرف والے مانیٹر پر موجود ونڈو کے ساتھ تبادلہ کرتا ہے |
| `Super + Alt + Arrow` | ونڈو کو اس طرف والے مانیٹر پر موجود کسی گروپ میں منتقل کرتا ہے |
| `Super + Shift + Ctrl + Arrow` | ونڈو کو اس طرف والے مانیٹر پر، اس ورک اسپیس پر منتقل کرتا ہے جو وہ دکھا رہا ہے |
| `Super + Shift + Alt + Arrow` | ورک اسپیس کو اس طرف والے مانیٹر پر منتقل کرتا ہے، اگر اس کا نمبر خالی ہو تو اسے برقرار رکھتا ہے |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | ترتیب کچھ بھی ہو، فوکس کو اگلے یا پچھلے مانیٹر پر منتقل کرتا ہے |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | اسی مانیٹر پر رہتے ہیں جس پر آپ ہیں |

اگر آپ متعدد اسکرینوں کی پوزیشننگ میں مدد کے لیے TUI چاہتے ہیں تو آپ [Hyprmon](https://github.com/erans/hyprmon/) بھی دیکھ سکتے ہیں۔

### چمک کو کنٹرول کرنا

مانیٹر کی چمک چمک بڑھانے/کم کرنے کے لیے مخصوص فنکشن کیز کے ذریعے کنٹرول کی جاتی ہے۔ اگر آپ انہیں دباتے ہوئے shift کو دبائے رکھیں تو آپ زیادہ سے زیادہ یا کم سے کم چمک پر چلے جائیں گے۔ یہ کیز اس ڈسپلے کو کنٹرول کرتی ہیں جس پر آپ فوکس کیے ہوئے ہیں، لہٰذا DDC/CI بولنے والے بیرونی مانیٹرز بھی لیپ ٹاپ اسکرین کی طرح ہی ایڈجسٹ ہوتے ہیں۔

### Apple ڈسپلے

اگر آپ Apple ڈسپلے استعمال کر رہے ہیں تو کی بورڈ کی باقاعدہ چمک والی کیز بھی خود بخود کام کریں گی، اگر آپ Apple ڈسپلے پر فوکس کیے ہوئے ہوں۔ یہ `asdcontrol` کمانڈ کے ذریعے کیا جاتا ہے۔

نوٹ کریں کہ اگر آپ Apple 6K XDR ڈسپلے استعمال کر رہے ہیں تو آپ کو اپنی `hyprctl monitors` فہرست میں کوئی فینٹم اسکرین نظر آ سکتی ہے۔ آپ `~/.config/hypr/monitors.lua` میں `hl.monitor({ output = "DP-2", disabled = true })` جیسی کسی چیز کے ساتھ اسے بند کر سکتے ہیں۔

Intel مشینوں پر، آپ کو باقاعدہ Thunderbolt کیبل استعمال کر کے Apple ڈسپلے سے جڑنا چاہیے۔ Thunderbolt کے بغیر دیگر مشینوں پر، اسے کام کرنے کے لیے آپ کو عام طور پر [DP + USB-A -> USB-C cable](https://www.amazon.com/dp/B0BNX7MS6N) استعمال کرنا پڑے گا۔
