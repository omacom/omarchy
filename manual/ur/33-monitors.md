# مانیٹرز

Omarchy بطور ڈیفالٹ یہ فرض کرتا ہے کہ آپ 2x کی صلاحیت رکھنے والے retina-کلاس ڈسپلے پر چل رہے ہیں۔ یہی وہ چیز ہے جو آپ کو وہ اچھے، کرسپ پروگرامر فونٹس حاصل کرنے کے لیے چاہیے۔ یہی وہ چیز ہے جس کے لیے تقریباً تمام نئے پریمیم لیپ ٹاپس اعلیٰ ریزولوشن اسکرینوں کے ساتھ آپٹیمائز کیے گئے ہیں۔ یہی وہ چیز ہے جو آپ 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) یا 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) پر چلانا چاہیں گے۔

لیکن اگر آپ 218 یا اس سے زیادہ PPI والے ڈسپلے پر نہیں چل رہے، تو آپ مانیٹر سیٹنگز تبدیل کرنا چاہیں گے۔ مثال کے طور پر، اگر آپ کے پاس 27" یا 32" 4K ہے، تو آپ `~/.config/hypr/monitors.lua` (Omarchy مینیو میں _Setup > Monitors_ کے ذریعے) کھول کر اور اس کمبی نیشن کے لیے تجویز پر سوئچ کر کے فریکشنل اسکیلنگ استعمال کر سکتے ہیں:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

اگر آپ 1080p یا 1440p ڈسپلے استعمال کر رہے ہیں، تو آپ شاید صرف 1x اسکیلنگ استعمال کرنا چاہیں گے، لہٰذا آپ یہ استعمال کر سکتے ہیں:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

`GDK_SCALE` میں تبدیلیاں تبدیلی کے بعد شروع کی گئی ایپلیکیشنز پر لاگو ہوتی ہیں (اور GTK صرف مکمل اعداد کی قدر کرتا ہے، لہٰذا اسے اپنے مانیٹر اسکیل کے قریب ترین صحیح عدد پر رکھیں)۔ لہٰذا اس بات کو یقینی بنائیں کہ تبدیلی کے بعد آپ وہ ونڈوز بند کر دیں جو بڑے سائز کی ہیں (یا `Ctrl + Alt + Del` سے تمام ونڈوز بند کر دیں!)۔

آپ `Super + /` استعمال کر کے اوپر جانے اور `Super + Alt + /` استعمال کر کے نیچے آنے کے ذریعے، یا اوپر والی بار میں مانیٹر پینل سے ایک منتخب کر کے، بڑے مانیٹر اسکیلنگ تناسبات (1x, 1.25x, 1.6x, 2x, 3x, 4x) میں سے بھی تیزی سے گزر سکتے ہیں۔ یہ صرف اس مانیٹر کو تبدیل کرتے ہیں جس پر آپ فوکس کر رہے ہیں، لہٰذا لیپ ٹاپ اسکرین اور بیرونی ڈسپلے ہر ایک کا اپنا اسکیل ہو سکتا ہے۔ انتخاب اس مانیٹر کے لیے `hl.monitor` رول کے طور پر `~/.config/hypr/monitors.lua` میں محفوظ ہو جاتا ہے، لہٰذا یہ ری بوٹ کے بعد بھی برقرار رہتا ہے اور `omarchy_monitor_scale` پر فوقیت رکھتا ہے، جو ہر اس مانیٹر کے لیے اسکیل کے طور پر باقی رہتا ہے جس کا اپنا کوئی رول نہیں ہے۔ چونکہ `GDK_SCALE` تمام اسکرینوں کے لیے ایک ہی قدر ہے، اس لیے یہ تبدیلیاں اسے سب سے کم اسکیل والے مانیٹر سے سیٹ کرتی ہیں، لہٰذا X11 ایپس گھنی اسکرین پر کچھ چھوٹی نکلیں گی بجائے اس کے کہ دوسری پر بڑے سائز کی نکلیں۔

### متن کو بڑا یا چھوٹا کرنا

مانیٹر اسکیلنگ ہر چیز کا سائز تبدیل کرتی ہے۔ اگر آپ صرف بڑا یا چھوٹا _متن_ چاہتے ہیں، تو اس کے لیے ایک ہی نوب ہے:

```
omarchy display text size 14
```

یہ 9 اور 20 کے درمیان ایک پکسل سائز لیتا ہے، اور Omarchy شیل، GTK ایپلیکیشنز، اور آپ کے ٹرمینل کو ایک ساتھ منتقل کرتا ہے، لہٰذا پورا ڈیسک ٹاپ تناسب میں رہتا ہے۔ آپ کہاں پر ہیں یہ دیکھنے کے لیے اسے بغیر کسی آرگومنٹ کے چلائیں، اور ڈیفالٹ پر واپس جانے کے لیے `omarchy display text size reset` چلائیں۔ Foot واحد پیچھے رہ جانے والا ہے: اس کے پاس اپنی کنفگ کو دوبارہ لوڈ کرنے کا کوئی طریقہ نہیں ہے، لہٰذا چل رہے ٹرمینلز اپنا پرانا سائز برقرار رکھتے ہیں جب تک آپ نیا نہ کھولیں۔

### لیپ ٹاپ ڈسپلے کو بڑھانا اور مرر کرنا

جب آپ اپنے لیپ ٹاپ سے بیرونی اسکرین جوڑتے ہیں، تو ڈسپلے خود بخود بڑھ جاتا ہے۔ لیکن آپ Omarchy مینیو میں _Trigger > Hardware_ یا `Super + Ctrl + Alt + Delete` استعمال کر کے اسے اس کے بجائے مررنگ میں تبدیل کر سکتے ہیں۔ یہ خاص طور پر مددگار ہے اگر وہ بیرونی اسکرین ایک پروجیکٹر ہے، اور آپ کام کرتے ہوئے کچھ دکھانا چاہتے ہیں۔

جب آپ بڑھا رہے ہوں، تو لیپ ٹاپ کا ڈھکن بند کرنے سے اندرونی اسکرین خود بخود بند ہو جائے گی۔ ڈھکن کھولنے سے یہ دوبارہ آن ہو جائے گی۔ آپ Omarchy مینیو میں _Trigger > Hardware_ یا `Super + Ctrl + Delete` استعمال کر کے اسے دستی طور پر بھی کنٹرول کر سکتے ہیں۔

### متعدد اسکرینوں کو ترتیب دینا

Hyprland متعدد اسکرینوں کے ساتھ بہت اچھا کام کرتا ہے۔ انہیں کیسے ترتیب دینا ہے اس کے بارے میں [Hyprland مانیٹر دستاویزات](https://wiki.hypr.land/Configuring/Basics/Monitors/) میں مزید پڑھیں۔ Omarchy میں، یہ `hl.monitor` اندراجات کے طور پر `~/.config/hypr/monitors.lua` میں جاتے ہیں — فائل کسی مخصوص مانیٹر کو ایک ریزولوشن، پوزیشن، اور گردش پر مقرر کرنے کے لیے تبصرہ شدہ مثالوں کے ساتھ آتی ہے۔

ہر مانیٹر کے اپنے 1 سے 10 تک ورک اسپیس ہوتے ہیں، لہٰذا `Super + 1` کا ہمیشہ مطلب اس مانیٹر کا پہلا ورک اسپیس ہوتا ہے جس پر آپ ہیں۔ پردے کے پیچھے، Hyprland پھر بھی تمام مانیٹروں میں ورک اسپیسوں کو نمبر دیتا ہے: آپ کی لیپ ٹاپ اسکرین (یا پہلا مانیٹر) کو 1–10 ملتے ہیں، اگلے مانیٹر کو 11–20، اور اسی طرح آگے، اور ہر مانیٹر ہر بار جب آپ اسے لگاتے ہیں اپنا بلاک برقرار رکھتا ہے۔ اگر آپ کسی مخصوص مانیٹر کے لیے [ورک اسپیس رولز](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) یا ونڈو رولز لکھتے ہیں تو وہ نمبر استعمال کریں، لہٰذا ورک اسپیس 12 آپ کے دوسرے مانیٹر کا دوسرا ورک اسپیس ہے۔ `~/.local/state/omarchy/monitor-workspaces` درج کرتا ہے کہ کس مانیٹر کے پاس کون سا بلاک ہے۔

ایرو کیز ان مانیٹروں کے درمیان کام کرتی ہیں جو آپ کی ترتیب میں ایک کنارہ साझा کرتے ہیں۔ وہ اسکرینیں جو صرف ایک کونے پر چھوتی ہیں، یا جن کے درمیان خلا ہے، پڑوسی نہیں ہیں، لہٰذا ان کے درمیان جانے کے لیے `Ctrl + Alt + Tab` استعمال کریں۔

| Hotkey | مانیٹروں کے درمیان |
| --- | --- |
| `Super + Arrow` | اس سمت میں کوئی ونڈو باقی نہ رہنے پر اس طرف کے مانیٹر پر فوکس منتقل کرتا ہے |
| `Super + Shift + Arrow` | اس طرف کے مانیٹر پر موجود ونڈو کے ساتھ تبادلہ کرتا ہے |
| `Super + Alt + Arrow` | ونڈو کو اس طرف کے مانیٹر پر موجود گروپ میں منتقل کرتا ہے |
| `Super + Shift + Ctrl + Arrow` | ونڈو کو اس طرف کے مانیٹر پر، اس ورک اسپیس پر منتقل کرتا ہے جو وہ دکھا رہا ہے |
| `Super + Shift + Alt + Arrow` | ورک اسپیس کو اس طرف کے مانیٹر پر منتقل کرتا ہے، اگر اس کا نمبر خالی ہو تو اسے برقرار رکھتا ہے |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | ترتیب کچھ بھی ہو، اگلے یا پچھلے مانیٹر پر فوکس منتقل کرتا ہے |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | آپ جس مانیٹر پر ہیں اسی پر رہتے ہیں |

اگر آپ متعدد اسکرینوں کی پوزیشننگ میں مدد کے لیے ایک TUI چاہتے ہیں، تو آپ [Hyprmon](https://github.com/erans/hyprmon/) بھی دیکھ سکتے ہیں۔

### چمک کو کنٹرول کرنا

مانیٹر کی چمک چمک بڑھانے/کم کرنے کے لیے مخصوص فنکشن کیز سے کنٹرول ہوتی ہے۔ اگر آپ انہیں دباتے وقت shift کو دبا کر رکھتے ہیں، تو آپ زیادہ سے زیادہ یا کم سے کم چمک پر چلے جائیں گے۔ کیز اس ڈسپلے کو کنٹرول کرتی ہیں جس پر آپ فوکس کر رہے ہیں، لہٰذا DDC/CI بولنے والے بیرونی مانیٹر اسی طرح ایڈجسٹ ہوتے ہیں جیسے لیپ ٹاپ اسکرین۔

### Apple ڈسپلے

اگر آپ Apple ڈسپلے استعمال کر رہے ہیں، تو معمول کی کی بورڈ چمک والی کیز بھی خود بخود کام کریں گی، اگر آپ Apple ڈسپلے پر فوکس کر رہے ہیں۔ یہ `asdcontrol` کمانڈ کے ذریعے کیا جاتا ہے۔

نوٹ کریں کہ اگر آپ Apple 6K XDR ڈسپلے استعمال کر رہے ہیں، تو آپ کو اپنی `hyprctl monitors` فہرست میں ایک خیالی اسکرین نظر آ سکتی ہے۔ آپ _Setup > Monitors_ کے ذریعے `hl.monitor({ output = "DP-2", disabled = true })` جیسی کسی چیز سے اسے بند کر سکتے ہیں۔

Intel مشینوں پر، آپ کو Apple ڈسپلے سے ایک معمول کی Thunderbolt کیبل استعمال کر کے جڑنا چاہیے۔ Thunderbolt کے بغیر دیگر مشینوں پر، آپ کو عام طور پر اسے کام کرنے کے لیے ایک [DP + USB-A -> USB-C cable](https://www.amazon.com/dp/B0BNX7MS6N) استعمال کرنا ہوگا۔
