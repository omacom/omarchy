# مانیٹرز

Omarchy فرض करता ہے کہ آپ بطور ڈیفالٹ 2x کے قابل ریٹنا کلاس ڈسپلے پر چل رہے ہیں। یہی چیز آپ کو ان کھلی، واضح پروگرامر فانٹس کو حاصل کرنے کے لیے درکار ہے۔ یہ تقریباً تمام نئی پریمیم لیپ ٹاپس کے لیے بہتر ہے جن کی اسکرینیں اعلیٰ ریزولوشن رکھتی ہیں۔ یہی کچھ آپ 27" 5K [Apple اسٹوڈیو ڈسپلے](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) یا 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) پر چلانا چاہیں گے।

لیکن اگر آپ 218 یا اس سے زیادہ PPI والے ڈسپلے کو نہیں چلا رہے تو آپ مانیٹر ترتیبات تبدیل کرنا چاہیں گے। مثال کے طور پر، اگر آپ کے پاس 27" یا 32" 4K ہے تو آپ `~/.config/hypr/monitors.lua` کھول کر (Omarchy مینو میں _سیٹ اپ > مانیٹرز_ کے ذریعے) اور اس کمبو کے لیے سفارش پر بدل کر فریکشنل اسکیلنگ استعمال کر سکتے ہیں:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

اگر آپ 1080p یا 1440p ڈسپلے استعمال کر रहे ہیں تو آپ کو شاید بس 1x اسکیلنگ استعمال کرنی چاہیے، لہٰذا آپ یہ استعمال कर सकते ہیں:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

`GDK_SCALE` میں تبدیلیاں تبدیلی کے بعد شروع ہونے والی ایپلیکیشنز پر لاگو ہوتی ہیں (اور GTK صرف پورے نمبروں کو ہی عزت دیتا ہے، لہٰذا اسے اپنے مانیٹر اسکیل کے قریب ترین عدد پر رکھیں)। لہٰذا اس بات کو یقینی بنائیں کہ تبدیلی کے بعد آپ ان ونڈوز کو بند کر دیں جو بڑی ہو گئی ہیں (یا `Ctrl + Alt + Del` سے تمام ونڈوز بند کر دیں!)۔

آپ `Super + /` سے زیادہ بلندی کی طرف اور `Super + Alt + /` سے کمی کی طرف جا کر مانیٹر اسکیلنگ کی بڑی نسبتوں (1x، 1.25x، 1.6x، 2x، 3x، 4x) میں تیزی سے قدم بڑھا بھی सकते ہیں। اگر آپ کے پاس ڈیفالٹ ترتیب ہو تو یہ تبدیلیاں ری بوٹ کے بعد بھی باقی رہیں گی।

### متن کو بڑا یا چھوٹا بنانا

مانیٹر اسکیلنگ ہر چیز کا आकार بدل دیتی ہے। اگر آپ کو بس بڑا یا چھوٹا _متن_ چاہیے تو اس کے لیے ایک ہی ناب ہے:

```
omarchy display text size 14
```

یہ 9 اور 20 کے درمیان پکسل کا आकार لیتا ہے، اور Omarchy شیل، GTK ایپلیکیشنز، اور آپ کے ٹرمینل کو ایک ساتھ حرکت دیتا ہے، لہٰذا پورا ڈیسک ٹاپ تناسب میں رہتا ہے। آپ کہاں ہیں یہ دیکھنے کے لیے بغیر آرگومنٹ کے چلائیں، اور ڈیفالٹ کی طرف لوٹنے کے لیے `omarchy display text size reset` چلائیں। Foot ایک ہی پیچھے رہ جانے والا ہے: اس کے پاس اپنی ترتیب دوبارہ لوڈ کرنے کا کوئی طریقہ نہیں ہے، لہٰذا چل رہے ٹرمینلز پرانے आकार کو اس وقت تک برقرار رکھتے ہیں جب تک آپ نیا نہ کھول لیں।

### لیپ ٹاپ ڈسپلے کو بڑھانا اور عکاسی کرنا

جب آپ اپنے لیپ ٹاپ سے بیرونی اسکرین جوڑتے ہیں تو ڈسپلے خودکار طور پر بڑھ جاتی ہے। لیکن آپ اسے Omarchy مینو میں _ٹریگر > ہارڈویئر_ یا `Super + Ctrl + Alt + Delete` استعمال کر کے اس کی جگہ عکاسی پر تبدیل कर سکتے ہیں। یہ خاص طور پر مددگار ہے اگر وہ بیرونی اسکرین پروجیکٹر ہو، اور آپ کام کرتے ہوئے کچھ دکھانا چاہیں।

جب آپ توسیع کر رہے ہوں تو لیپ ٹاپ پر ढक्कन بند کرنے سے اندرونی اسکرین خودکار طور پر بند ہو جائے گی। ढक्कन کھولنے سے یہ دوبارہ آن ہو جائے گی। آپ اسے Omarchy مینو میں _ٹریگر > ہارڈویئر_ یا `Super + Ctrl + Delete` استعمال کر के دستی طور پر بھی قابو کر سکتے ہیں।

### متعدد اسکرینوں کو ترتیب دینا

Hyprland متعدد اسکرینوں کے ساتھ عمدہ کام کرتا ہے। انہیں ترتیب دینے کے طریقے کے بارے میں [Hyprland مانیٹر دستاویزات](https://wiki.hypr.land/Configuring/Basics/Monitors/) میں مزید پڑھیں। آپ [مخصوص ورک اسپیسز کو مخصوص مانیٹرز سے جوڑ بھی سکتے ہیں](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/)۔ Omarchy میں، یہ قواعد `hl.monitor` اندراجات کے طور پر `~/.config/hypr/monitors.lua` میں جاتے ہیں — فائل مشخص مانیٹر کو کسی ریزولوشن، جگہ اور گھماؤ پر پن کرنے کے لیے تبصرے والے مثالیں لے کر بھیجی जाती ہے।

آپ [Hyprmon](https://github.com/erans/hyprmon/) بھی دیکھ سکتے ہیں، اگر آپ چاہتے ہیں کہ کوئی TUI متعدد اسکرینوں کی جگہ کے تعین میں آپ کی مدد کرے।

### چمک کو قابو کرنا

مانیٹر کی چمک چمک اوپر/نیچے کے لیے مخصوص فنکشن کلیدوں کے ذریعے قابو کی जाती ہے। اگر آپ انہیں دباتے ہوئے shift دبائے رکھیں تو آپ زیادہ سے زیادہ یا کم سے کم چمک کی طرف جائیں گے। کلیدیں اس ڈسپلے کو قابو کرتی ہیں جس پر آپ کی توجہ مرکوز ہے، لہٰذا DDC/CI بولنے والے بیرونی مانیٹرز کو لیپ ٹاپ اسکرین کی طرح ہی درست کیا جاتا ہے।

### Apple ڈسپلے

اگر آپ Apple ڈسپلے استعمال کرتے ہیں تو باقاعدہ کی بورڈ چمک کلیدیں بھی خودکار طور پر کام کر جائیں گی، اگر آپ کی توجہ Apple ڈسپلے پر ہو۔ یہ `asdcontrol` کمانڈ کے ذریعے کیا جاتا ہے।

نوٹ کریں کہ اگر آپ Apple 6K XDR ڈسپلے استعمال کرتے ہیں تو آپ کو اپنی `hyprctl monitors` فہرست میں ایک фанٹم اسکرین دکھائی دے سکتی ہے। آپ اسے _سیٹ اپ > مانیٹرز_ کے ذریعے `hl.monitor({ output = "DP-2", disabled = true })` جیسی کسی چیز سے بند कर सकते हैं।

انٹیل مشینوں پر، آپ کو باقاعدہ تھنڈربولٹ کیبل استعمال کر کے Apple ڈسپلے سے جوڑنا چاہیے। Thunderbolt کے بغیر دیگر مشینوں پر، آپ کو عام طور پر اسے درست کرنے کے لیے [DP + USB-A -> USB-C کیبل](https://www.amazon.com/dp/B0BNX7MS6N) استعمال کرنی ہوگی।
