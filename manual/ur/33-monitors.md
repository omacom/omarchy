# مانیٹرز

Omarchy بائی ڈیفالٹ یہ فرض کرتا ہے کہ آپ 2x صلاحیت والی retina-class ڈسپلے چلا رہے ہیں۔ وہ اچھے، صاف اور واضح programmer fonts حاصل کرنے کے لیے آپ کو اسی کی ضرورت ہوتی ہے۔ تقریباً تمام نئے premium لیپ ٹاپس جن میں high-resolution اسکرینیں ہیں، اسی کے لیے optimized ہیں۔ آپ اسے 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) یا 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) پر چلانا چاہیں گے۔

لیکن اگر آپ 218 یا اس سے زیادہ PPI والی ڈسپلے نہیں چلا رہے تو آپ مانیٹر کی سیٹنگز تبدیل کرنا چاہیں گے۔ مثال کے طور پر، اگر آپ کے پاس 27" یا 32" 4K ہے تو آپ `~/.config/hypr/monitors.lua` کھول کر (Omarchy مینیو میں _Setup > Monitors_ کے ذریعے) fractional scaling استعمال کر سکتے ہیں اور اس کمبی نیشن کے لیے تجویز کردہ سیٹنگ پر سوئچ کر سکتے ہیں:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

اگر آپ 1080p یا 1440p ڈسپلے استعمال کر رہے ہیں تو غالباً آپ صرف 1x scaling استعمال کرنا چاہیں گے، اس لیے آپ یہ استعمال کر سکتے ہیں:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

`GDK_SCALE` میں تبدیلیاں تبدیلی کے بعد شروع کی گئی ایپلیکیشنز پر لاگو ہوتی ہیں (اور GTK صرف مکمل اعداد ہی قبول کرتا ہے، اس لیے اسے اپنے مانیٹر اسکیل کے قریب ترین مکمل عدد پر رکھیں)۔ اس لیے یقینی بنائیں کہ تبدیلی کے بعد آپ وہ ونڈوز بند کر دیں جو بڑے سائز کی ہیں (یا `Ctrl + Alt + Del` کے ساتھ تمام ونڈوز بند کر دیں!)۔

آپ `Super + /` استعمال کر کے بڑے مانیٹر اسکیلنگ ratios (1x, 1.25x, 1.6x, 2x, 3x, 4x) میں تیزی سے اوپر اور `Super + Alt + /` استعمال کر کے نیچے بھی جا سکتے ہیں، یا اوپر والے بار میں مانیٹر پینل سے کوئی ایک منتخب کر سکتے ہیں۔ یہ صرف اسی مانیٹر کو تبدیل کرتے ہیں جس پر آپ فوکس کیے ہوئے ہیں، اس لیے لیپ ٹاپ اسکرین اور بیرونی ڈسپلے ہر ایک کا اپنا اسکیل ہو سکتا ہے۔ یہ انتخاب `~/.config/hypr/monitors.lua` میں اس مانیٹر کے لیے ایک `hl.monitor` رول کے طور پر محفوظ ہو جاتا ہے، اس لیے یہ reboot کے بعد بھی برقرار رہتا ہے اور `omarchy_monitor_scale` پر فوقیت رکھتا ہے، جو ہر اس مانیٹر کا اسکیل رہتا ہے جس کا اپنا کوئی رول نہیں ہے۔

### متن کو بڑا یا چھوٹا کرنا

مانیٹر اسکیلنگ ہر چیز کا سائز تبدیل کرتی ہے۔ اگر آپ صرف بڑا یا چھوٹا _متن_ چاہتے ہیں تو اس کے لیے ایک ہی نوب ہے:

```
omarchy display text size 14
```

یہ 9 اور 20 کے درمیان pixel سائز لیتا ہے، اور Omarchy shell، GTK ایپلیکیشنز، اور آپ کے ٹرمینل کو ایک ساتھ منتقل کرتا ہے، اس لیے پورا ڈیسک ٹاپ تناسب میں رہتا ہے۔ آپ کہاں ہیں یہ دیکھنے کے لیے اسے بغیر کسی argument کے چلائیں، اور ڈیفالٹ پر واپس جانے کے لیے `omarchy display text size reset` چلائیں۔ Foot واحد پیچھے رہ جانے والا ہے: اس کے پاس اپنی config دوبارہ لوڈ کرنے کا کوئی طریقہ نہیں ہے، اس لیے چلتے ہوئے ٹرمینلز اپنا پرانا سائز برقرار رکھتے ہیں جب تک آپ نیا ٹرمینل نہ کھولیں۔

### لیپ ٹاپ ڈسپلے کو توسیع دینا اور مرر کرنا

جب آپ اپنے لیپ ٹاپ سے بیرونی اسکرین جوڑتے ہیں تو ڈسپلے خودکار طور پر توسیع پا جاتی ہے۔ لیکن آپ Omarchy مینیو میں _Trigger > Hardware_ یا `Super + Ctrl + Alt + Delete` استعمال کر کے اسے اس کے بجائے mirroring میں تبدیل کر سکتے ہیں۔ یہ خاص طور پر مددگار ہے اگر وہ بیرونی اسکرین ایک projector ہو، اور آپ کام کرتے ہوئے کچھ دکھانا چاہتے ہوں۔

جب آپ توسیع دے رہے ہوں تو لیپ ٹاپ کا ڈھکن بند کرنے سے اندرونی اسکرین خودکار طور پر بند ہو جائے گی۔ ڈھکن کھولنے سے یہ دوبارہ آن ہو جائے گی۔ آپ Omarchy مینیو میں _Trigger > Hardware_ یا `Super + Ctrl + Delete` استعمال کر کے اسے دستی طور پر بھی کنٹرول کر سکتے ہیں۔

### متعدد اسکرینوں کو ترتیب دینا

Hyprland متعدد اسکرینوں کے ساتھ بہت اچھا کام کرتا ہے۔ انہیں ترتیب دینے کے طریقے کے بارے میں [Hyprland مانیٹر دستاویزات](https://wiki.hypr.land/Configuring/Basics/Monitors/) میں مزید پڑھیں۔ Omarchy میں، یہ `~/.config/hypr/monitors.lua` میں `hl.monitor` اندراجات کے طور پر جاتے ہیں — فائل کسی مخصوص مانیٹر کو ایک resolution، position، اور rotation پر مقرر کرنے کے لیے commented مثالوں کے ساتھ آتی ہے۔

ہر مانیٹر کے اپنے workspaces 1 سے 10 تک ہوتے ہیں، اس لیے `Super + 1` کا ہمیشہ مطلب اس مانیٹر کا پہلا workspace ہوتا ہے جس پر آپ ہیں۔ پس پردہ، Hyprland پھر بھی تمام مانیٹرز میں workspaces کو نمبر دیتا ہے: آپ کی لیپ ٹاپ اسکرین (یا پہلا مانیٹر) کو 1–10 ملتے ہیں، اگلے مانیٹر کو 11–20، اور اسی طرح آگے، اور ہر مانیٹر جب بھی آپ اسے لگاتے ہیں اپنا بلاک برقرار رکھتا ہے۔ اگر آپ کسی مخصوص مانیٹر کے لیے [workspace rules](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) یا window rules لکھیں تو وہ نمبر استعمال کریں، اس لیے workspace 12 آپ کے دوسرے مانیٹر کا دوسرا workspace ہے۔ `~/.local/state/omarchy/monitor-workspaces` فہرست دیتا ہے کہ کس مانیٹر کے پاس کون سا بلاک ہے۔

Arrow کیز ان مانیٹرز کے درمیان کام کرتی ہیں جو آپ کی ترتیب میں ایک کنارا साझा کرتے ہیں۔ وہ اسکرینیں جو صرف ایک کونے پر چھوتی ہیں، یا جن کے درمیان خلا ہے، پڑوسی نہیں ہیں، اس لیے ان کے درمیان جانے کے لیے `Ctrl + Alt + Tab` استعمال کریں۔

| ہاٹ کی | مانیٹرز کے درمیان |
| --- | --- |
| `Super + Arrow` | جب اس سمت میں کوئی ونڈو باقی نہ رہے تو فوکس کو اس طرف والے مانیٹر پر منتقل کرتا ہے |
| `Super + Shift + Arrow` | اس طرف والے مانیٹر پر موجود ونڈو کے ساتھ تبادلہ کرتا ہے |
| `Super + Alt + Arrow` | ونڈو کو اس طرف والے مانیٹر پر موجود کسی گروپ میں منتقل کرتا ہے |
| `Super + Shift + Ctrl + Arrow` | ونڈو کو اس طرف والے مانیٹر پر، اس workspace پر منتقل کرتا ہے جو وہ دکھا رہا ہے |
| `Super + Shift + Alt + Arrow` | workspace کو اس طرف والے مانیٹر پر منتقل کرتا ہے، اگر خالی ہو تو اس کا نمبر برقرار رکھتا ہے |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | ترتیب کچھ بھی ہو، فوکس کو اگلے یا پچھلے مانیٹر پر منتقل کرتا ہے |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | اسی مانیٹر پر رہتے ہیں جس پر آپ ہیں |

آپ [Hyprmon](https://github.com/erans/hyprmon/) بھی دیکھ سکتے ہیں، اگر آپ متعدد اسکرینوں کی پوزیشننگ میں مدد کے لیے ایک TUI چاہتے ہیں۔

### چمک کو کنٹرول کرنا

مانیٹر کی چمک چمک بڑھانے/کم کرنے کے لیے مخصوص function کیز سے کنٹرول ہوتی ہے۔ اگر آپ انہیں دباتے وقت Shift دبائے رکھیں تو آپ زیادہ سے زیادہ یا کم سے کم چمک پر چلے جائیں گے۔ کیز اس ڈسپلے کو کنٹرول کرتی ہیں جس پر آپ فوکس کیے ہوئے ہیں، اس لیے DDC/CI بولنے والے بیرونی مانیٹرز بھی اسی طرح ایڈجسٹ ہوتے ہیں جیسے لیپ ٹاپ اسکرین۔

### Apple Displays

اگر آپ Apple ڈسپلے استعمال کر رہے ہیں تو باقاعدہ کی بورڈ چمک کیز بھی خودکار طور پر کام کریں گی، اگر آپ Apple ڈسپلے پر فوکس کیے ہوئے ہیں۔ یہ `asdcontrol` کمانڈ کے ذریعے کیا جاتا ہے۔

نوٹ کریں کہ اگر آپ Apple 6K XDR ڈسپلے استعمال کر رہے ہیں تو آپ کو اپنی `hyprctl monitors` فہرست میں ایک phantom اسکرین نظر آ سکتی ہے۔ آپ _Setup > Monitors_ کے ذریعے `hl.monitor({ output = "DP-2", disabled = true })` جیسی کسی چیز کے ساتھ اسے بند کر سکتے ہیں۔

Intel مشینوں پر، آپ کو Apple ڈسپلے سے باقاعدہ Thunderbolt کیبل استعمال کر کے جڑنا چاہیے۔ Thunderbolt کے بغیر دیگر مشینوں پر، اسے کام کرنے کے لیے آپ کو عام طور پر ایک [DP + USB-A -> USB-C کیبل](https://www.amazon.com/dp/B0BNX7MS6N) استعمال کرنا پڑے گی۔
