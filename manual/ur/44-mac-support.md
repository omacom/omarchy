# Mac کے لیے سپورٹ

## Apple Silicon کے لیے Omarchy

Omarchy for Apple Silicon ایک باضابطہ Omacom حل ہے، جو پہلی بار Omarchy 4.5 کے ساتھ جاری ہوا۔ یہ macOS کے ساتھ ساتھ انسٹال ہوتا ہے، اور جب آپ کا Mac اسٹارٹ ہوتا ہے تو آپ دونوں میں سے انتخاب کرتے ہیں۔

Omarchy Mac کے بارے میں کوئی نوٹس ملا ہے؟ [Omarchy Mac سے آنا](#coming-from-omarchy-mac) پر جائیں۔

یہ ان Macs پر چلتا ہے:

| Mac | چپس |
| --- | --- |
| MacBook Air | M1, M2, M3 |
| MacBook Pro | M1, M1 Pro, M1 Max, M2, M2 Pro, M2 Max, M3, M3 Pro, M3 Max |
| MacBook Neo | A18 Pro |
| Mac mini | M1, M2, M2 Pro |
| Mac Studio | M1 Max, M1 Ultra, M2 Max, M2 Ultra |
| iMac | M1, M3 |
| Mac Pro | M2 Ultra |

M4 اور اس سے نئے Macs ابھی سپورٹ نہیں کیے جاتے۔ M4 سپورٹ edge channel پر جانچی جا رہی ہے اور اگلی آئے گی۔ انسٹالر کسی بھی چیز میں تبدیلی کرنے سے پہلے آپ کے Mac کی جانچ کرتا ہے۔

کسی بھی Apple Silicon Mac پر، بشمول M4 اور اس سے نئے، آپ [Try Omarchy](https://github.com/omacom/try-omarchy) کے ساتھ ایک ورچوئل مشین میں Omarchy چلا سکتے ہیں۔

### آپ کو کیا چاہیے

- macOS 15 Sequoia یا بعد کا ورژن، اور ایک administrator اکاؤنٹ
- Omarchy کے لیے خالی ڈسک جگہ۔ انسٹالر ایک سائز تجویز کرتا ہے اور آپ کو اسے تبدیل کرنے دیتا ہے۔
- اپنے Mac کا بیک اپ، پاور، اور ایک انٹرنیٹ کنکشن۔ انسٹال کئی گیگا بائٹس ڈاؤن لوڈ کرتی ہے۔

### انسٹال کرنا

آپ macOS سے انسٹال کرتے ہیں۔ [Homebrew](https://brew.sh) کے ساتھ Omarchy Installer انسٹال کریں:

```sh
brew install omacom/mac/omarchy
```

یا جدید ترین Omarchy Installer اس کے [ریلیزز پیج](https://github.com/omacom/omarchy-mac-installer/releases) سے ڈاؤن لوڈ کریں اور اسے کھولیں۔

انسٹالر آپ کے Mac کی جانچ کرتا ہے، آپ کو منصوبہ دکھاتا ہے، اور macOS پارٹیشن کو سکڑ کر Omarchy کے لیے جگہ بناتا ہے۔ macOS ڈسک پر رہتا ہے اور کسی USB ڈرائیو کی ضرورت نہیں ہے۔ جب پہلا مرحلہ مکمل ہو جائے، تو یہ آپ کو macOS Recovery میں سیٹ اپ مکمل کرنے کا طریقہ بتاتا ہے: شٹ ڈاؤن کریں، پاور بٹن کو تب تک دبا کر رکھیں جب تک "Loading startup options" ظاہر نہ ہو، Omarchy منتخب کریں، اور مراحل پر عمل کریں۔

پہلی بوٹ پر، Omarchy ایک پاس ورڈ مانگتا ہے جو اس کی ڈسک کو خفیہ کرتا ہے۔ کوئی recovery key نہیں ہے: اگر آپ پاس ورڈ بھول جائیں، تو آپ کی Omarchy فائلیں بازیافت نہیں ہو سکتیں۔

بعد میں Omarchy اور macOS کے درمیان سوئچ کرنے کے لیے، شٹ ڈاؤن کریں، پھر پاور بٹن کو تب تک دبا کر رکھیں جب تک اسٹارٹ اپ آپشنز ظاہر نہ ہوں اور ایک منتخب کریں۔

### Omarchy Mac سے آنا

Omarchy Mac اب Omarchy for Apple Silicon کا حصہ ہے، اور ہر وہ Mac جو اسے چلاتا تھا سپورٹ کیا جاتا ہے۔ آپ کی موجودہ انسٹال چلتی رہتی ہے، اور اس کے سسٹم پیکیجز اب بھی اپ ڈیٹ ہوتے ہیں، لیکن اسے مزید Omarchy اپ ڈیٹس نہیں ملتیں۔ کوئی آخری تاریخ نہیں ہے اور کوئی in-place اپ گریڈ نہیں ہے: آپ بیک اپ لیتے ہیں، پرانی انسٹال ہٹاتے ہیں، تازہ انسٹال کرتے ہیں، اور بحال کرتے ہیں۔ مراحل 2 سے 5 macOS میں ہوتے ہیں، اس لیے دوبارہ اسٹارٹ کرنے سے پہلے یہ صفحہ اپنے فون پر کھول لیں۔

1. **Omarchy سے، Mac سے باہر بیک اپ لیں۔** پرانی انسٹال ہٹانے سے یہ مٹ جاتی ہے، اور macOS Omarchy ڈسک کو پڑھ نہیں سکتا۔ اپنے ہوم فولڈر کو ایک بیرونی ڈرائیو یا دوسرے کمپیوٹر پر کاپی کریں، بشمول SSH اور GPG keys، براؤزر پروفائلز اور وہ کام جو ابھی پش نہیں ہوا۔ `pacman -Qqe > ~/packages.txt` کے ساتھ اپنی پیکیج فہرست محفوظ کریں۔ macOS کا بھی بیک اپ لیں، کیونکہ ہٹانا اور انسٹال کرنا دونوں اس کی ڈسک کا سائز تبدیل کرتے ہیں۔
2. **اپنے Mac کو macOS میں اسٹارٹ کریں۔** شٹ ڈاؤن کریں، پاور بٹن کو تب تک دبا کر رکھیں جب تک اسٹارٹ اپ آپشنز ظاہر نہ ہوں، اور macOS منتخب کریں۔
3. **Omarchy Installer انسٹال کریں** جیسا کہ [انسٹال کرنا](#installing) میں دکھایا گیا ہے۔
4. **پرانی انسٹال ہٹائیں۔** Omarchy Installer کھولیں اور Installation > Remove Omarchy منتخب کریں۔ یہ دکھاتا ہے کہ یہ کیا حذف کرے گا اور جگہ macOS کو واپس کر دیتا ہے۔ اگر یہ آپ کی انسٹال کو نہیں پہچانتا، تو یہ ڈسک میں تبدیلی کیے بغیر رک جاتا ہے۔ پارٹیشنز کو ہاتھ سے حذف کرنے کے بجائے، جو macOS کو مٹا سکتا ہے، [Discord](https://discord.gg/tXFUdasqhY) میں مدد مانگیں۔
5. **Omarchy for Apple Silicon انسٹال کریں** انسٹالر کے ساتھ۔
6. **اپنی فائلیں بحال کریں۔** اپنی ترتیبات کو `~/.config` کو مکمل طور پر نئے ڈیفالٹس پر کاپی کرنے کے بجائے ایک ایک کر کے واپس لائیں، کیونکہ پرانی ترتیبات ان پر فوقیت لے سکتی ہیں۔

### جاننا مفید ہے

- M1 اور M2 MacBooks پر، ڈھکن کھول کر یا پاور بٹن دبا کر نیند سے جگائیں۔
- سوالات یا مسائل: ہمارے [Discord](https://discord.gg/tXFUdasqhY) میں پوچھیں۔

[انسٹالر کا README](https://github.com/omacom/omarchy-mac-installer#readme) ریلیز چینلز، انسٹالر کو اپ ڈیٹ کرنے اور Omarchy ہٹانے کا احاطہ کرتا ہے۔

 ![macbook-omarchy](images/macbook-omarchy.webp)

### Mac پر Omarchy انسٹال کرنا

Omarchy اس وقت صرف **واحد** انسٹال شدہ OS ہونے کی سپورٹ کرتا ہے۔ انسٹالیشن کے دوران، ڈرائیو صاف ہو جائے گی اور MacOS مزید بوٹ ایبل نہیں رہے گا۔

اگر آپ چاہیں تو آپ بعد میں بھی Internet Recovery کے ذریعے اسے بحال کر سکتے ہیں۔

اس حصے کی خاطر، ہم فرض کریں گے کہ آپ پہلے ہی [شروع کرنا](02-getting-started.md) کا جائزہ لے چکے ہیں اور آپ کی USB ڈرائیو تیار ہے۔ اگر نہیں، تو آگے بڑھیں اور ابھی یہ کریں۔

#### Secure Boot غیر فعال کریں

بوٹ ایبل USB، اور OS کو بھی بوٹ کرنے کے لیے Apple کے Secure Boot کو غیر فعال کرنا ضروری ہے۔ اسے غیر فعال کرنے کے لیے، درج ذیل کریں:

1. اپنے Mac کو بند کریں
2. اسے آن کریں اور _فوری طور پر_ Command-R دبا کر رکھیں جب تک آپ کو لوڈنگ اسکرین ظاہر نہ ہو
3. اپنے صارف کو منتخب کریں اور اگر کہا جائے تو اپنا پاس ورڈ درج کریں
4. ریکوری اسکرین میں آنے کے بعد، مینیو بار سے **Utilities > Startup Security Utility** منتخب کریں
5. تصدیق کے لیے کہا جانے پر اپنا پاس ورڈ درج کریں
6. Secure Boot آپشنز سے "No Security" منتخب کریں
7. External Boot آپشنز سے "Allow booting from external or removable media" منتخب کریں

#### انسٹالیشن شروع کریں

1. USB ڈرائیو داخل کریں
2. اپنے Mac کو دوبارہ اسٹارٹ کریں اور _فوری طور پر_ Option دبا کر رکھیں جب تک آپ کو بوٹ ڈیوائسز کی اسکرین نظر نہ آئے
3. نارنجی EFI Boot ڈیوائس منتخب کریں
4. [معمول کے مطابق انسٹال](02-getting-started.md) کے ساتھ آگے بڑھیں

انسٹالر Mac ہارڈویئر کا پتہ لگاتا ہے اور مطلوبہ اصلاحات خود بخود لاگو کرتا ہے: Broadcom Wi-Fi ڈرائیورز اور فرم ویئر، Broadcom 1570 والی مشینوں پر FaceTime HD کیمرا ڈرائیور (اس کا فرم ویئر Apple سے ڈاؤن لوڈ ہوتا ہے جب Mac آن لائن ہو جاتا ہے، کیونکہ انسٹالر آف لائن کام کرتا ہے)، ان MacBook ماڈلز پر SPI کی بورڈ ڈرائیور جنہیں اس کی ضرورت ہوتی ہے، اور انہی ماڈلز کے لیے ایک NVMe suspend اصلاح۔

### معلوم حدود

کمیونٹی کے اراکین ان چیلنجز کے حل پر مسلسل کام کر رہے ہیں، اس لیے اگر یہ آپ کے لیے مسئلہ ہیں، تو ہمارے [Discord](https://discord.gg/tXFUdasqhY) میں #omarchy-on-other میں شامل ہوں اور دیکھیں کہ آیا ان کو حل کرنے کے لیے کوئی تازہ ترین طریقے موجود ہیں۔

#### FaceTime HD Camera

کیمرا ڈرائیور مشین کو ہینگ کر دیتا ہے اگر یہ اس وقت لوڈ ہو جب Mac ہائبرنیٹ ہوتا ہے، اس لیے اسے پہلے ان لوڈ کیا جاتا ہے۔ اسے اس وقت ان لوڈ نہیں کیا جا سکتا جب کسی ایپ نے کیمرا کھول رکھا ہو، اس لیے ہائبرنیشن ایک نوٹیفکیشن کے ساتھ منسوخ کر دی جاتی ہے جس میں ایپ کا نام ہوتا ہے: اسے بند کریں اور دوبارہ ہائبرنیٹ کریں۔ اس میں کریٹیکل بیٹری پر خود بخود ہائبرنیٹ ہونا، اور suspend-then-hibernate شامل ہے، جسے suspend ہونے سے پہلے مسترد کر دیا جاتا ہے۔ عام suspend کو خود ڈرائیور مسترد کر دیتا ہے جب کیمرا کھلا ہو، بغیر کسی نوٹیفکیشن کے۔

کیمرے کا فرم ویئر Apple سے ڈاؤن لوڈ ہوتا ہے، اس لیے کیمرا صرف اسی وقت کام کرتا ہے جب Mac آن لائن ہو چکا ہو۔ ڈاؤن لوڈ بوٹ پر شروع ہوتا ہے اور جب تک نیٹ ورک مسئلہ ہو ہر 15 منٹ بعد دوبارہ کوشش کی جاتی ہے؛ اگر Apple کی فائل تبدیل ہو گئی ہو، تو یہ رک جاتا ہے اور Omarchy اپ ڈیٹ کا انتظار کرتا ہے۔ اگر کیمرا ظاہر نہ ہو، تو `journalctl -u facetimehd-firmware-fetcher` بتاتا ہے کیوں، `sudo systemctl restart facetimehd-firmware-fetcher` دوبارہ کوشش کرتا ہے، اور ایک ری بوٹ ڈرائیور کو لوڈ کرتا ہے اگر ڈاؤن لوڈ مکمل ہو گیا ہو لیکن کیمرا پھر بھی موجود نہ ہو۔

#### T1 Chip والے ڈیوائسز

Apple T1 chip 2016 کے آخر میں متعارف کرائی گئی تھی اور خصوصی طور پر Touch Bar والے پہلی نسل کے MacBook Pro ماڈلز میں استعمال ہوئی تھی۔
- MacBook Pro 13-inch (2016, two Thunderbolt 3 ports) – Model: A1706
- MacBook Pro 13-inch (2016, four Thunderbolt 3 ports) – Model: A1708
- MacBook Pro 15-inch (2016) – Model: A1707

#### معلوم مسائل

- Touch Bar کام نہیں کرتا
- آواز کام نہیں کر رہی

#### T2 Chip والے ڈیوائسز

Apple T2 Security Chip 2017 میں متعارف کرائی گئی تھی۔ T2 chip کو 2020 سے شروع ہونے والی Apple silicon (M-series chips) کی طرف منتقلی کے ساتھ بند کر دیا گیا تھا۔

- iMac Pro (2017) – Model: A1862
- MacBook Pro 13-inch (2018, four Thunderbolt 3 ports) – Model: A1989
- MacBook Pro 15-inch (2018) – Model: A1990
- MacBook Air (Retina, 13-inch, 2018) – Model: A1932
- Mac mini (2018) – Model: A1998
- MacBook Pro 13-inch (2019, two Thunderbolt 3 ports) – Model: A2159
- MacBook Pro 13-inch (2019, four Thunderbolt 3 ports) – Model: A2178
- MacBook Pro 15-inch (2019) – Model: A1990
- iMac (Retina 5K, 27-inch, 2020) – Model: A2115 (iMac20,1 and iMac20,2)
- MacBook Pro 13-inch (2020, two Thunderbolt 3 ports) – Model: A2265
- MacBook Pro 15-inch (2020) – Model: A1990

ان ماڈلز پر، انسٹالر خود بخود patched `linux-t2` kernel، T2 آڈیو کنفیگریشن، Apple کا Broadcom Wi-Fi/Bluetooth فرم ویئر، اور `t2fanrd` کے ذریعے فین کنٹرول سیٹ اپ کرتا ہے۔ Touch Bar kernel کی بلٹ ان Boot Camp طرز کی سپورٹ پر چلتا ہے۔

#### iMac Retina 5K (2017)

2017 کے 27-inch iMac میں کوئی T2 chip نہیں ہے، اس لیے انسٹالر اسے دوسرے Intel Macs کی طرح سیٹ اپ کرتا ہے۔

- iMac (Retina 5K, 27-inch, 2017) – Model: A1419

#### معلوم مسائل

- ڈسپلے اپنے مقامی 5120×2880 پر نہیں چلتا: پینل دو ٹائلز ہیں، اور اسٹاک ڈرائیور صرف ایک کو روشن کرتا ہے
- آواز کام نہیں کر رہی
- چمک کا کنٹرول کوئی اثر نہیں کرتا
- نیند مشین کو ہینگ کر دیتی ہے؛ صرف پاور سائیکل اسے بحال کرتا ہے

اس ماڈل کے لیے ایک کمیونٹی patcher ڈسپلے، آواز اور چمک کو ٹھیک کرتا ہے: [omarchy-imac18-3](https://github.com/ahmadtv/omarchy-imac18-3).
