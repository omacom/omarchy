# ہاٹ کیز

آپ `Super + K` کے ساتھ تمام اہم کی بورڈ بائنڈنگز دیکھ سکتے ہیں (Tmux بائنڈنگز `Super + Alt + K` کے ساتھ اور Herdr بائنڈنگز `Super + Ctrl + K` کے ساتھ)۔

## نیویگیشن

| ہاٹ کی                  | فنکشن              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy مینو (ایپس اور باقی سب کچھ)    |
| `Super + Alt + Space` | ایپ گرڈ |
| `Super + Escape` | سسٹم مینو (معطل کریں، دوبارہ شروع کریں، وغیرہ)  |
| `Super + Ctrl + L` | کمپیوٹر لاک کریں |
| `Super + W` or `Super + Q` | ونڈو بند کریں             |
| `Ctrl + Alt + Del` | تمام ونڈوز بند کریں |
| `Super + T`               | ونڈو کو ٹائلنگ/فلوٹنگ کے درمیان ٹوگل کریں             |
| `Super + J` | ونڈو کی پوزیشن ٹوگل کریں (افقی/عمودی) |
| `Super + O`               | ونڈو کو sticky'n'floating میں پاپ کرنا ٹوگل کریں |
| `Super + L`               | dwindle، scrolling، اور floating لے آؤٹس میں چکر لگائیں |
| `Super + Alt + L`         | لے آؤٹس میں الٹی ترتیب سے چکر لگائیں |

| `Super + 1/2/3/4`         | فوکس شدہ مانیٹر پر مخصوص ورک اسپیس پر جائیں |

| `Super + S` | فل اسکریچ پیڈ ٹوگل کریں |
| `Super + Alt + S` | ونڈو کو فل اسکریچ پیڈ پر منتقل کریں |

| `Super + Shift + Grave` | ونڈو کو Quake کنسول پر منتقل کریں |
| `Super + Shift + Ctrl + Arrows` | ونڈو کو اس سمت والے مانیٹر پر منتقل کریں |

| `Super + G`               | ونڈو گروپنگ ٹوگل کریں      |

| `Super + Alt + /` | مانیٹر اسکیلنگ کے اختیارات میں پیچھے جائیں |

| `Alt + Shift + Tab` | فعال ورک اسپیس پر ونڈوز میں پیچھے چکر لگائیں |

### Tmux لے آؤٹ فنکشنز

یہ فنکشنز Tmux سیشن کے اندر چلائے جانے چاہئیں۔

| کمانڈ | فنکشن |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | ایڈیٹر، AI، اور ٹرمینل کے ساتھ ڈیو لے آؤٹ بنائیں |
| `tdlm <ai> [<second_ai>]` | فی ذیلی ڈائرکٹری ڈیو لے آؤٹ بنائیں |
| `tsl <count> <command>` | ملٹی پین سوارم لے آؤٹ بنائیں |
