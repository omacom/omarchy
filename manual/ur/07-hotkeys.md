# ہاٹ کیز

آپ تمام اہم کی بورڈ بائنڈنگز `Super + K` سے دیکھ سکتے ہیں (Tmux بائنڈنگز `Super + Alt + K` سے اور Herdr بائنڈنگز `Super + Ctrl + K` سے)۔

## ہاٹ کیز کی ترتیب کیسے ہے

ہر ہاٹ کی اپنے موڈیفائرز کے ذریعے طے شدہ ایک سطح پر ہوتی ہے، اور ہر سطح کا ایک ہی کام ہوتا ہے۔ یہی چیز ہاٹ کیز کو آپس میں گڈمڈ ہونے سے روکتی ہے، اور اس کا مطلب ہے کہ آپ عام طور پر اندازہ لگا سکتے ہیں کہ کوئی چیز کہاں ملے گی۔

| سطح | وہاں کیا ہوتا ہے | مثالیں |
| --- | --- | --- |
| `Super + key` | سسٹم: ونڈوز، ورک اسپیسز، لے آؤٹس، اور بنیادی مینیوز | `Super + Space` Omarchy مینیو، `Super + W` ونڈو بند کریں، `Super + F` فل اسکرین |
| `Super + Shift + key` | ایپس | `Super + Shift + B` براؤزر، `Super + Shift + E` ای میل، `Super + Shift + N` ایڈیٹر |
| `Super + Ctrl + key` | پینلز اور سسٹم مینیوز | `Super + Ctrl + A` آڈیو، `Super + Ctrl + N` نیٹ ورک، `Super + Ctrl + C` کیپچر مینیو |
| `Super + Ctrl + Alt + key` | فوری اعمال اور نوٹسز | `Super + Ctrl + Alt + T` وقت دکھائیں، `Super + Ctrl + Alt + B` بیٹری، `Super + Ctrl + Alt + C` اسکرین شاٹ |

کسی ہاٹ کی میں `Alt` شامل کرنے سے آپ کو اسی چیز کی ایک مختلف شکل ملتی ہے، کبھی کوئی غیر متعلق چیز نہیں:

- `Super + Shift + B` براؤزر کھولتا ہے؛ `Super + Shift + Alt + B` نجی ونڈو کھولتا ہے
- `Super + Shift + E` ای میل کھولتا ہے؛ `Super + Shift + Alt + E` نئی ای میل شروع کرتا ہے
- `Super + F` فل اسکرین ہوتا ہے؛ `Super + Alt + F` فل چوڑائی ہوتا ہے
- `Super + Ctrl + C` کیپچر مینیو کھولتا ہے؛ `Super + Ctrl + Alt + C` مینیو چھوڑ کر اسکرین شاٹ لیتا ہے

ہاٹ کی شامل کرتے وقت:

1. یہ کیا کرتی ہے اس سے سطح چنیں، پھر کی چنیں۔
2. جگہ بنانے کے لیے موجودہ ہاٹ کی کو نہ ہٹائیں۔ درست سطح پر کوئی خالی کی تلاش کریں۔
3. `Alt` صرف اس ہاٹ کی کی مختلف شکل کے لیے استعمال کریں جس میں یہ نہ ہو۔

چند ہاٹ کیز ان اصولوں کو توڑتی ہیں کیونکہ وہ آسان ہیں۔ تیر یا `Tab` کے ساتھ `Shift` ایپ کھولنے کے بجائے حرکت کرتا یا الٹا کرتا ہے، اور `Print`، میڈیا کیز، `Alt + Tab`، اور `Ctrl + Alt + Del` ہر جگہ کی طرح ہی کام کرتے ہیں۔ یہ استثنائی صورتیں ہیں، نقل کرنے کے نمونے نہیں۔

اگر کوئی ڈیفالٹ آپ کو مناسب نہ لگے (مثلاً آپ Windows کی طرح اسکرین شاٹس کے لیے `Super + Shift + S` چاہتے ہیں)، تو اسے `~/.config/hypr/bindings.lua` میں دوبارہ باندھیں۔

ٹچ پیڈ پر، تین اور چار انگلیوں کے سوائپس ورک اسپیسز بدلتے ہیں، ونڈوز حرکت دیتے ہیں، اور مینیو اور Quake کنسول کھولتے ہیں؛ اشاروں کے لیے [کی بورڈ، ماؤس، اور ٹریک پیڈ](34-keyboard-mouse-trackpad.md) دیکھیں۔

سائز بدلنے میں 0 کے دائیں جانب والی دو کیز استعمال ہوتی ہیں، آپ کا کی بورڈ ان پر جو بھی چھاپتا ہو: US کی بورڈز پر `-` اور `=`، ڈینش اور سویڈش پر `+` اور `´`، نارویجن پر `+` اور `\`، جرمن پر `ß` اور `´`، ہسپانوی پر `'` اور `¡`، اور جاپانی (JIS) پر `-` اور `^`۔ `Super + K` انہیں ویسے ہی دکھاتا ہے جیسے آپ کے کی بورڈ پر چھپی ہیں۔ JIS پر، `Super + ^`، `Super + Equal` ہے، جبکہ `Super + Shift + -` (جو `=` ٹائپ کرتا ہے) `Super + Shift + Minus` ہے۔ مانیٹر اسکیلنگ اور پاس ورڈ مینیجر `/` استعمال کرتے ہیں؛ ان لے آؤٹس پر جو `/` صرف Shift کے ساتھ ٹائپ کرتے ہیں، جیسا کہ زیادہ تر یورپی لے آؤٹس کرتے ہیں، وہ اس کے بجائے دائیں Shift کے بائیں جانب والی کی استعمال کرتے ہیں (ڈینش اور جرمن پر `-`)۔

## یونیورسل کلپ بورڈ

| `Alt + Space` | ڈکٹیشن شروع/روکیں (درکار ہے _سیٹ اپ > ڈیفالٹس > ڈکٹیشن_) |

اسکرین ریکارڈنگز کے ساتھ، ہاٹ کی پہلے پوچھتی ہے کہ آپ کو کون سی آڈیو چاہیے، پھر ریکارڈنگ شروع کرتی ہے۔ روکنے کے لیے اسے دوبارہ دبائیں۔ تفصیلات کے لیے [اسکرین شاٹس اور ریکارڈنگ](12-screenshots-recording.md) دیکھیں۔

تمام کیپچر آپشنز Omarchy مینیو (`Super + Space`) میں _ٹرگر > کیپچر_ کے تحت بھی دستیاب ہیں۔
