# ہاٹ کیز

آپ تمام اہم کی بورڈ بائنڈنگز `Super + K` کے ساتھ دیکھ سکتے ہیں (Tmux بائنڈنگز `Super + Alt + K` کے ساتھ اور Herdr بائنڈنگز `Super + Ctrl + K` کے ساتھ)۔

## ہاٹ کیز کی ترتیب کیسی ہے

ہر ہاٹ کی ایک سطح پر بیٹھتی ہے، جو اس کے موڈیفائرز سے طے ہوتی ہے، اور ہر سطح کا ایک کام ہے۔ اسی سے ہاٹ کیز آپس میں گڈمڈ نہیں ہوتیں، اور اس کا مطلب ہے کہ آپ عام طور پر اندازہ لگا سکتے ہیں کہ کوئی چیز کہاں رہتی ہے۔

| سطح | وہاں کیا رہتا ہے | مثالیں |
| --- | --- | --- |
| `Super + key` | نظام: ونڈوز، ورک اسپیسز، لے آؤٹس، اور بنیادی مینوز | `Super + Space` Omarchy مینو، `Super + W` ونڈو بند کریں، `Super + F` فل اسکرین |
| `Super + Shift + key` | ایپس | `Super + Shift + B` براؤزر، `Super + Shift + E` ای میل، `Super + Shift + N` ایڈیٹر |
| `Super + Ctrl + key` | پینلز اور سسٹم مینوز | `Super + Ctrl + A` آڈیو، `Super + Ctrl + N` نیٹ ورک، `Super + Ctrl + C` کیپچر مینو |
| `Super + Ctrl + Alt + key` | فوری اعمال اور نوٹسز | `Super + Ctrl + Alt + T` وقت دکھائیں، `Super + Ctrl + Alt + B` بیٹری، `Super + Ctrl + Alt + C` اسکرین شاٹ |

ہاٹ کی میں `Alt` شامل کرنے سے آپ کو اسی چیز کی ایک قسم ملتی ہے، کبھی کوئی غیر متعلق چیز نہیں:

- `Super + Shift + B` براؤزر کھولتا ہے؛ `Super + Shift + Alt + B` پرائیویٹ ونڈو کھولتا ہے
- `Super + Shift + E` ای میل کھولتا ہے؛ `Super + Shift + Alt + E` نئی ای میل شروع کرتا ہے
- `Super + F` فل اسکرین پر جاتا ہے؛ `Super + Alt + F` فل وڈتھ پر جاتا ہے
- `Super + Ctrl + C` کیپچر مینو کھولتا ہے؛ `Super + Ctrl + Alt + C` مینو چھوڑ کر اسکرین شاٹ لیتا ہے

ہاٹ کی شامل کرتے وقت:

1. یہ کیا کرتا ہے اس سے سطح چنیں، پھر کی چنیں۔
2. جگہ بنانے کے لیے موجودہ ہاٹ کی کو نہ ہٹائیں۔ صحیح سطح پر خالی کی تلاش کریں۔
3. `Alt` صرف اسی ہاٹ کی کی ایک قسم کے لیے استعمال کریں جس میں یہ نہ ہو۔

چند ہاٹ کیز ان اصولوں کو توڑتی ہیں کیونکہ وہ آسان ہیں۔ ایرو یا `Tab` کے ساتھ `Shift` ایپ کھولنے کے بجائے منتقل کرتا ہے یا الٹا کرتا ہے، اور `Print`، میڈیا کیز، `Alt + Tab`، اور `Ctrl + Alt + Del` ویسے ہی کام کرتے ہیں جیسے وہ ہر جگہ کرتے ہیں۔ یہ استثنائیں ہیں، نقل کرنے کے نمونے نہیں۔

اگر کوئی ڈیفالٹ آپ کو مناسب نہ لگے (مثلاً آپ Windows کی طرح اسکرین شاٹس کے لیے `Super + Shift + S` چاہتے ہیں)، تو اسے `~/.config/hypr/bindings.lua` میں دوبارہ باندھیں۔

## یونیورسل کلپ بورڈ

| ہاٹ کی                  | فنکشن              |
| ----------------------- | --------------------- |
| `Super + A`           | ان ایپس میں سب منتخب کریں جو `Ctrl + A` کو سپورٹ کرتی ہیں    |
| `Super + C`           | کاپی    |
| `Super + X`           | کٹ (ٹرمینل میں نہیں)    |
| `Super + V`           | پیسٹ    |
| `Super + Ctrl + V`           | کلپ بورڈ مینیجر    |

عام طور پر Linux پر، آپ کو ٹرمینل میں کاپی اینڈ پیسٹ کے لیے `Ctrl + Shift + C/V` اور ہر دوسری جگہ کرنے کے لیے `Ctrl + C/V` کی ضرورت ہوتی ہے۔ یہ Omarchy یونیفائیڈ کلپ بورڈ ہاٹ کیز ہر جگہ کام کرتی ہیں۔

| `Super + Backspace` | ونڈو پر شفافیت ٹوگل کریں |
| `Super + Ctrl + Backspace` | سنگل ونڈو مربع تناسب ٹوگل کریں |

اضافی بیک گراؤنڈ تصاویر `~/.config/omarchy/backgrounds/<theme name>` میں رہتی ہیں۔ Omarchy مینو میں _انسٹال > اسٹائل > بیک گراؤنڈ_ کے ذریعے بھی دستیاب ہیں۔

تمام اسٹائل آپشنز Omarchy مینو (`Super + Space`) میں _اسٹائل_ کے تحت بھی قابل رسائی ہیں۔
