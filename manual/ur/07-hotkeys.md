# ہاٹ کیز

آپ تمام اہم کی بورڈ بائنڈنگز `Super + K` کے ساتھ دیکھ سکتے ہیں (Tmux بائنڈنگز `Super + Alt + K` کے ساتھ اور Herdr بائنڈنگز `Super + Ctrl + K` کے ساتھ)۔

## ہاٹ کیز کی ترتیب کیسے ہے

ہر ہاٹ کی ایک سطح پر ہوتی ہے، جو اس کے موڈیفائرز سے طے ہوتی ہے، اور ہر سطح کا ایک کام ہوتا ہے۔ اسی سے ہاٹ کیز آپس میں گڈمڈ نہیں ہوتیں، اور اس کا مطلب ہے کہ آپ عام طور پر اندازہ لگا سکتے ہیں کہ کوئی چیز کہاں ہوگی۔

| سطح | وہاں کیا ہوتا ہے | مثالیں |
| --- | --- | --- |
| `Super + key` | سسٹم: ونڈوز، ورک اسپیسز، لے آؤٹس، اور بنیادی مینوز | `Super + Space` Omarchy مینو، `Super + W` ونڈو بند کریں، `Super + F` فل اسکرین |
| `Super + Shift + key` | ایپس | `Super + Shift + B` براؤزر، `Super + Shift + E` ای میل، `Super + Shift + N` ایڈیٹر |
| `Super + Ctrl + key` | پینلز اور سسٹم مینوز | `Super + Ctrl + A` آڈیو، `Super + Ctrl + N` نیٹ ورک، `Super + Ctrl + C` کیپچر مینو |
| `Super + Ctrl + Alt + key` | فوری اقدامات اور نوٹس | `Super + Ctrl + Alt + T` وقت دکھائیں، `Super + Ctrl + Alt + B` بیٹری، `Super + Ctrl + Alt + C` اسکرین شاٹ |

کسی ہاٹ کی میں `Alt` شامل کرنے سے آپ کو اسی چیز کی ایک مختلف شکل ملتی ہے، کبھی کوئی غیر متعلق چیز نہیں:

- `Super + Shift + B` براؤزر کھولتا ہے؛ `Super + Shift + Alt + B` پرائیویٹ ونڈو کھولتا ہے
- `Super + Shift + E` ای میل کھولتا ہے؛ `Super + Shift + Alt + E` نئی ای میل شروع کرتا ہے
- `Super + F` فل اسکرین پر جاتا ہے؛ `Super + Alt + F` فل چوڑائی پر جاتا ہے
- `Super + Ctrl + C` کیپچر مینو کھولتا ہے؛ `Super + Ctrl + Alt + C` مینو کو چھوڑ کر اسکرین شاٹ لیتا ہے

ہاٹ کی شامل کرتے وقت:

1. یہ کیا کرتا ہے اس سے سطح منتخب کریں، پھر کی منتخب کریں۔
2. جگہ بنانے کے لیے موجودہ ہاٹ کی کو منتقل نہ کریں۔ درست سطح پر خالی کی تلاش کریں۔
3. `Alt` صرف اس ہاٹ کی کی مختلف شکل کے لیے استعمال کریں جس میں یہ نہیں ہے۔

کچھ ہاٹ کیز ان اصولوں کو توڑتی ہیں کیونکہ وہ آسان ہیں۔ تیر یا `Tab` کے ساتھ `Shift` ایپ کھولنے کے بجائے منتقل یا الٹا کرتا ہے، اور `Print`، میڈیا کیز، `Alt + Tab`، اور `Ctrl + Alt + Del` ویسے ہی کام کرتے ہیں جیسے وہ ہر جگہ کرتے ہیں۔ یہ استثنائیں ہیں، نقل کرنے کے نمونے نہیں۔

اگر کوئی ڈیفالٹ آپ کو پسند نہیں (کہیے آپ Windows کی طرح اسکرین شاٹس کے لیے `Super + Shift + S` چاہتے ہیں)، تو اسے `~/.config/hypr/bindings.lua` میں دوبارہ باندھیں۔

ٹچ پیڈ پر، تین اور چار انگلیوں کے سوائپس ورک اسپیسز بدلتے ہیں، ونڈوز منتقل کرتے ہیں، اور مینو اور Quake کنسول کھولتے ہیں؛ اشاروں کے لیے [کی بورڈ، ماؤس، اور ٹریک پیڈ](34-keyboard-mouse-trackpad.md) دیکھیں۔

سائز تبدیل کرنا 0 کے دائیں طرف والی دو کیز استعمال کرتا ہے، آپ کے کی بورڈ پر ان پر جو بھی چھپا ہو: امریکی کی بورڈز پر `-` اور `=`، ڈینش اور سویڈش پر `+` اور `´`، نارویجن پر `+` اور `\`، جرمن پر `ß` اور `´`، ہسپانوی پر `'` اور `¡`، اور جاپانی (JIS) پر `-` اور `^`۔ `Super + K` انہیں ویسے درج کرتا ہے جیسے آپ کے کی بورڈ پر چھپی ہیں۔ JIS پر، `Super + ^` یعنی `Super + Equal` ہے، جبکہ `Super + Shift + -` (جو `=` ٹائپ کرتا ہے) یعنی `Super + Shift + Minus` ہے۔ مانیٹر اسکیلنگ اور پاس ورڈ مینیجر `/` استعمال کرتے ہیں؛ ان لے آؤٹس پر جو `/` صرف Shift کے ساتھ ٹائپ کرتے ہیں، جیسا کہ زیادہ تر یورپی کرتے ہیں، وہ اس کے بجائے دائیں Shift کے بائیں طرف والی کی استعمال کرتے ہیں (ڈینش اور جرمن پر `-`)۔

| `Super + Ctrl + Print Screen` | کلپ بورڈ پر متن نکالنا |
| `Super + Alt + [` | ریکارڈنگ کے دوران ویب کیم اوورلے کو چھوٹا کریں |
| `Super + Alt + ]` | ریکارڈنگ کے دوران ویب کیم اوورلے کو بڑا کریں |
| `Alt + Shift + L` | ویب ایپ یا براؤزر سے موجودہ URL کاپی کریں |
| `Alt + Shift + D` | موجودہ صفحے پر موجود ویڈیو کو `~/Videos` میں ڈاؤن لوڈ کریں |
| `Alt + Space` | ڈکٹیشن شروع/بند کریں (درکار ہے _Setup > Defaults > Dictation_) |
| `Right Alt` | ڈکٹیشن کے لیے پکڑے رکھیں (درکار ہے _Setup > Defaults > Dictation_) |

اسکرین ریکارڈنگز کے ساتھ، ہاٹ کی پہلے پوچھتی ہے کہ آپ کون سی آڈیو چاہتے ہیں، پھر ریکارڈنگ شروع کرتی ہے۔ رکنے کے لیے اسے دوبارہ دبائیں۔ تفصیلات کے لیے [اسکرین شاٹس اور ریکارڈنگ](12-screenshots-recording.md) دیکھیں۔

تمام کیپچر اختیارات Omarchy مینو (`Super + Space`) میں _Trigger > Capture_ کے تحت بھی دستیاب ہیں۔
