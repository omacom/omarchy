# ہاٹ کیز

آپ تمام اہم کی بورڈ بائنڈنگز `Super + K` کے ساتھ دیکھ سکتے ہیں (Tmux بائنڈنگز `Super + Alt + K` کے ساتھ اور Herdr بائنڈنگز `Super + Ctrl + K` کے ساتھ)۔

## ہاٹ کیز کی ترتیب کیسی ہے

ہر ہاٹ کی ایک سطح پر ہوتی ہے، جو اس کے ماڈیفائرز سے طے ہوتی ہے، اور ہر سطح کا ایک کام ہوتا ہے۔ اسی سے ہاٹ کیز آپس میں گڈمڈ نہیں ہوتیں، اور اس کا مطلب ہے کہ آپ عام طور پر اندازہ لگا سکتے ہیں کہ کوئی چیز کہاں ہوگی۔

| سطح | وہاں کیا ہوتا ہے | مثالیں |
| --- | --- | --- |
| `Super + key` | سسٹم: ونڈوز، ورک اسپیسز، لے آؤٹس، اور بنیادی مینوز | `Super + Space` Omarchy مینو، `Super + W` ونڈو بند کریں، `Super + F` فل اسکرین |
| `Super + Shift + key` | ایپس | `Super + Shift + B` براؤزر، `Super + Shift + E` ای میل، `Super + Shift + N` ایڈیٹر |
| `Super + Ctrl + key` | پینلز اور سسٹم مینوز | `Super + Ctrl + A` آڈیو، `Super + Ctrl + N` نیٹ ورک، `Super + Ctrl + C` کیپچر مینو |
| `Super + Ctrl + Alt + key` | فوری اقدامات اور اطلاعات | `Super + Ctrl + Alt + T` وقت دکھائیں، `Super + Ctrl + Alt + B` بیٹری، `Super + Ctrl + Alt + C` اسکرین شاٹ |

کسی ہاٹ کی میں `Alt` شامل کرنے سے آپ کو اسی چیز کی ایک قسم ملتی ہے، کبھی کوئی غیر متعلق چیز نہیں:

- `Super + Shift + B` براؤزر کھولتا ہے؛ `Super + Shift + Alt + B` پرائیویٹ ونڈو کھولتا ہے
- `Super + Shift + E` ای میل کھولتا ہے؛ `Super + Shift + Alt + E` نئی ای میل شروع کرتا ہے
- `Super + F` فل اسکرین کرتا ہے؛ `Super + Alt + F` فل چوڑائی کرتا ہے
- `Super + Ctrl + C` کیپچر مینو کھولتا ہے؛ `Super + Ctrl + Alt + C` مینو چھوڑ کر اسکرین شاٹ لیتا ہے

ہاٹ کی شامل کرتے وقت:

1. وہ کیا کرتی ہے اس سے سطح منتخب کریں، پھر کی منتخب کریں۔
2. جگہ بنانے کے لیے موجودہ ہاٹ کی کو نہ ہٹائیں۔ درست سطح پر خالی کی تلاش کریں۔
3. `Alt` صرف اس ہاٹ کی کی قسم کے لیے استعمال کریں جس میں یہ نہیں ہے۔

چند ہاٹ کیز ان اصولوں کو توڑتی ہیں کیونکہ وہ آسان ہیں۔ تیر یا `Tab` کے ساتھ `Shift` ایپ کھولنے کے بجائے منتقل یا الٹا کرتا ہے، اور `Print`، میڈیا کیز، `Alt + Tab`، اور `Ctrl + Alt + Del` اسی طرح کام کرتے ہیں جیسے وہ ہر دوسری جگہ کرتے ہیں۔ یہ استثنٰی ہیں، نقل کرنے کے نمونے نہیں۔

اگر کوئی ڈیفالٹ آپ کو پسند نہ آئے (مثلاً آپ Windows کی طرح اسکرین شاٹس کے لیے `Super + Shift + S` چاہتے ہیں)، تو اسے `~/.config/hypr/bindings.lua` میں دوبارہ بائنڈ کریں۔

ٹچ پیڈ پر، تین اور چار انگلیوں کے سوائپ ورک اسپیسز بدلتے ہیں، ونڈوز منتقل کرتے ہیں، اور مینو اور Quake کنسول کھولتے ہیں؛ اشاروں کے لیے [کی بورڈ، ماؤس، اور ٹریک پیڈ](34-keyboard-mouse-trackpad.md) دیکھیں۔

سائز تبدیل کرنے کے شارٹ کٹس فزیکل کیز `code:20` اور `code:21` (XKB `<AE11>` اور `<AE12>`) استعمال کرتے ہیں، قطع نظر اس کے کہ کی بورڈ پر کون سے حروف چھپے ہیں۔ US کی بورڈز پر یہ کیز `-` اور `=` ہیں؛ جاپانی (JIS) کی بورڈز پر یہ `-` اور `^` ہیں؛ ہسپانوی کی بورڈز پر یہ `'` اور `¡` ہیں۔ JIS پر، `Super + ^` یعنی `Super + Equal` ہے، جبکہ `Super + Shift + -` (جو `=` ٹائپ کرتا ہے) یعنی `Super + Shift + Minus` ہے۔

اسکرین ریکارڈنگز کے ساتھ، ہاٹ کی پہلے پوچھتی ہے کہ آپ کو کون سی آڈیو چاہیے، پھر ریکارڈنگ شروع کرتی ہے۔ روکنے کے لیے اسے دوبارہ دبائیں۔ تفصیلات کے لیے [اسکرین شاٹس اور ریکارڈنگ](12-screenshots-recording.md) دیکھیں۔

تمام کیپچر اختیارات Omarchy مینو (`Super + Space`) میں _Trigger > Capture_ کے تحت بھی دستیاب ہیں۔
