# ہاٹ کیز

آپ تمام اہم کی بورڈ بائنڈنگز `Super + K` کے ساتھ دیکھ سکتے ہیں (Tmux بائنڈنگز `Super + Alt + K` کے ساتھ اور Herdr بائنڈنگز `Super + Ctrl + K` کے ساتھ)۔

## ہاٹ کیز کی ترتیب کیسی ہے

ہر ہاٹ کی ایک سطح پر ہوتی ہے، جو اس کے موڈیفائرز سے طے ہوتی ہے، اور ہر سطح کا ایک ہی کام ہوتا ہے۔ یہی چیز ہاٹ کیز کو آپس میں گڈمڈ ہونے سے بچاتی ہے، اور اس کا مطلب ہے کہ آپ عام طور پر اندازہ لگا سکتے ہیں کہ کوئی چیز کہاں ملے گی۔

| سطح | وہاں کیا رہتا ہے | مثالیں |
| --- | --- | --- |
| `Super + key` | سسٹم: ونڈوز، ورک اسپیسز، لے آؤٹس، اور بنیادی مینوز | `Super + Space` Omarchy مینو، `Super + W` ونڈو بند کریں، `Super + F` فل اسکرین |
| `Super + Shift + key` | ایپس | `Super + Shift + B` براؤزر، `Super + Shift + E` ای میل، `Super + Shift + N` ایڈیٹر |
| `Super + Ctrl + key` | پینلز اور سسٹم مینوز | `Super + Ctrl + A` آڈیو، `Super + Ctrl + N` نیٹ ورک، `Super + Ctrl + C` کیپچر مینو |
| `Super + Ctrl + Alt + key` | فوری اقدامات اور اطلاعات | `Super + Ctrl + Alt + T` وقت دکھائیں، `Super + Ctrl + Alt + B` بیٹری، `Super + Ctrl + Alt + C` اسکرین شاٹ |

کسی ہاٹ کی میں `Alt` شامل کرنے سے آپ کو اسی چیز کی ایک مختلف شکل ملتی ہے، کبھی کوئی غیر متعلق چیز نہیں:

- `Super + Shift + B` براؤزر کھولتا ہے؛ `Super + Shift + Alt + B` پرائیویٹ ونڈو کھولتا ہے
- `Super + Shift + E` ای میل کھولتا ہے؛ `Super + Shift + Alt + E` نئی ای میل شروع کرتا ہے
- `Super + F` فل اسکرین پر جاتا ہے؛ `Super + Alt + F` فل وڈتھ پر جاتا ہے
- `Super + Ctrl + C` کیپچر مینو کھولتا ہے؛ `Super + Ctrl + Alt + C` مینو کو چھوڑ کر اسکرین شاٹ لیتا ہے

ہاٹ کی شامل کرتے وقت:

1. یہ کیا کرتی ہے اس کی بنیاد پر سطح منتخب کریں، پھر کی منتخب کریں۔
2. جگہ بنانے کے لیے موجودہ ہاٹ کی کو منتقل نہ کریں۔ صحیح سطح پر کوئی خالی کی تلاش کریں۔
3. `Alt` صرف اس ہاٹ کی کی مختلف شکل کے لیے استعمال کریں جس میں یہ نہیں ہے۔

چند ہاٹ کیز ان اصولوں کو توڑتی ہیں کیونکہ وہ آسان ہیں۔ ایرو یا `Tab` کے ساتھ `Shift` ایپ کھولنے کے بجائے منتقل کرتا ہے یا الٹا کرتا ہے، اور `Print`، میڈیا کیز، `Alt + Tab`، اور `Ctrl + Alt + Del` اسی طرح کام کرتے ہیں جیسے وہ ہر جگہ کام کرتے ہیں۔ یہ استثنٰی ہیں، نقل کرنے کے نمونے نہیں۔

اگر کوئی ڈیفالٹ آپ کے لیے مناسب نہیں ہے (مثلاً آپ Windows کی طرح اسکرین شاٹس کے لیے `Super + Shift + S` چاہتے ہیں)، تو اسے `~/.config/hypr/bindings.lua` میں دوبارہ بائنڈ کریں۔

ری سائز شارٹ کٹس فزیکل کیز `code:20` اور `code:21` (XKB `<AE11>` اور `<AE12>`) استعمال کرتے ہیں، قطع نظر اس کے کہ کی بورڈ پر کون سے حروف چھپے ہیں۔ امریکی کی بورڈز پر یہ کیز `-` اور `=` ہیں؛ جاپانی (JIS) کی بورڈز پر یہ `-` اور `^` ہیں؛ ہسپانوی کی بورڈز پر یہ `'` اور `¡` ہیں۔ JIS پر، `Super + ^`، `Super + Equal` ہے، جب کہ `Super + Shift + -` (جو `=` ٹائپ کرتا ہے) `Super + Shift + Minus` ہے۔

## یونیورسل کلپ بورڈ

| ہاٹ کی | فنکشن |
| ----------------------- | --------------------- |
| `Super + A` | ان ایپس میں سب منتخب کریں جو `Ctrl + A` کو سپورٹ کرتی ہیں |
| `Super + C` | کاپی |
| `Super + X` | کٹ (ٹرمینل میں نہیں) |
| `Super + V` | پیسٹ |
| `Super + Ctrl + V` | کلپ بورڈ مینیجر |

عام طور پر Linux پر، آپ کو ٹرمینل میں کاپی'n'پیسٹ کے لیے `Ctrl + Shift + C/V` اور باقی ہر جگہ اس کے لیے `Ctrl + C/V` کی ضرورت ہوتی ہے۔ یہ Omarchy یونیفائیڈ کلپ بورڈ ہاٹ کیز ہر جگہ کام کرتی ہیں۔

## اسٹائل

| ہاٹ کی | فنکشن |
| ----------------------- | --------------------- |
| `Super + Ctrl + T` | نئی تھیم منتخب کریں (نیز `Super + Ctrl + Shift + Space`) |

اضافی پس منظر کی تصاویر `~/.config/omarchy/backgrounds/<theme name>` میں رہتی ہیں۔ Omarchy مینو میں _Install > Style > Background_ کے ذریعے بھی دستیاب ہیں۔

تمام اسٹائل آپشنز Omarchy مینو (`Super + Space`) میں _Style_ کے تحت بھی قابل رسائی ہیں۔

## ٹوگلز

| ہاٹ کی | فنکشن |
| ----------------------- | --------------------- |
| `Super + Ctrl + I` | بیکار ہونے پر لاک کرنا ٹوگل کریں |
| `Super + Ctrl + Delete` | لیپ ٹاپ ڈسپلے آن/آف ٹوگل کریں |
| `Super + Ctrl + Alt + Delete` | لیپ ٹاپ ڈسپلے مررنگ ٹوگل کریں |
| `Super + Shift + Space` | اوپری بار ٹوگل کریں |
| `Shift + Mute` | اگلے آڈیو آؤٹ پٹ پر سوئچ کریں |
| `Shift + Play` | اگلے میڈیا ماخذ پر سوئچ کریں |
| `Super + Shift + Backspace` | ونڈو کے فاصلے ٹوگل کریں |
| `Super + Ctrl + Alt + F` | فل اسکرین ڈیسک ٹاپ ٹوگل کریں (اوپری بار + ونڈو کے فاصلے) |

## ریمائنڈرز

| `Super + Ctrl + Shift + R` | تمام ریمائنڈرز صاف کریں |

## Tmux

پریفکس کی `Ctrl + Space` ہے (`Ctrl + B` بھی کام کرتا ہے)۔ آپ ان بائنڈنگز کو `~/.config/tmux/tmux.conf` میں تبدیل کر سکتے ہیں۔

### پینز

| ہاٹ کی | فنکشن |
| ----------------------- | --------------------- |
| `Prefix + v` | ساتھ میں پین تقسیم کریں (عمودی) |
| `Prefix + h` | نیچے پین تقسیم کریں (افقی) |
| `Prefix + x` | پین ختم کریں |
| `Prefix + z` | پین زوم ٹوگل کریں (فل اسکرین) |
| `Alt + Enter` | نیچے پین تقسیم کریں (بغیر پریفکس کے) |
| `Alt + Shift + Enter` | ساتھ میں پین تقسیم کریں (بغیر پریفکس کے) |
| `Alt + Escape` | پین ختم کریں (بغیر پریفکس کے) |
| `Ctrl + Alt + Arrows` | پینز کے درمیان جائیں |
| `Ctrl + Alt + Shift + Arrows` | پینز کا سائز تبدیل کریں |

### ونڈوز

| ہاٹ کی | فنکشن |
| ----------------------- | --------------------- |
| `Prefix + c` | نئی ونڈو |
| `Prefix + k` | ونڈو ختم کریں |
| `Prefix + r` | ونڈو کا نام تبدیل کریں |
| `Alt + 1-9` | مخصوص ونڈو پر جائیں |
| `Alt + Arrow Left/Right` | ونڈوز کے درمیان جائیں |
| `Alt + Shift + Arrow Left/Right` | ونڈو بائیں/دائیں منتقل کریں |

### سیشنز

| ہاٹ کی | فنکشن |
| ----------------------- | --------------------- |
| `Prefix + C` | نیا سیشن |
| `Prefix + K` | سیشن ختم کریں |
| `Prefix + R` | سیشن کا نام تبدیل کریں |
| `Prefix + N` | اگلا سیشن |
| `Prefix + P` | پچھلا سیشن |
| `Alt + Arrow Up/Down` | سیشنز کے درمیان جائیں |
| `Prefix + s` | سیشنز کی فہرست بنائیں |
| `Prefix + d` | سیشن سے الگ ہو جائیں |

### کاپی موڈ (vi-اسٹائل)

| ہاٹ کی | فنکشن |
| ----------------------- | --------------------- |
| `Prefix + [` | کاپی موڈ میں داخل ہوں |
| `v` | انتخاب شروع کریں (کاپی موڈ میں) |
| `y` | انتخاب کاپی کریں (کاپی موڈ میں) |

### عمومی

| ہاٹ کی | فنکشن |
| ----------------------- | --------------------- |
| `Prefix + q` | کنفگ دوبارہ لوڈ کریں |
| `Prefix + ?` | Tmux کی بائنڈنگز دکھائیں |
| `Prefix + :` | کمانڈ پرامپٹ |

### Tmux لے آؤٹ فنکشنز

یہ فنکشنز Tmux سیشن کے اندر چلائے جانے چاہئیں۔

| کمانڈ | فنکشن |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | ایڈیٹر، AI، اور ٹرمینل کے ساتھ ڈیو لے آؤٹ بنائیں |
| `tdlm <ai> [<second_ai>]` | فی سب ڈائریکٹری ڈیو لے آؤٹ بنائیں |
| `tsl <count> <command>` | ملٹی پین سوارم لے آؤٹ بنائیں |

| `Ctrl + Shift + T` | نیا ٹیب |
| `Ctrl + Shift + Arrows` | ٹیبز کے درمیان جائیں |
| `Alt + Numbers` | مخصوص ٹیب پر جائیں |
| `Shift + Pg Up/Down` | تاریخ اسکرول کریں |
| `Ctrl + Left mouse` | براؤزر میں لنک کھولیں |
