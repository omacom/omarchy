# ہاٹ کیز

آپ تمام اہم کی بورڈ بائنڈنگز `Super + K` کے ساتھ دیکھ سکتے ہیں (Tmux بائنڈنگز `Super + Alt + K` کے ساتھ اور Herdr بائنڈنگز `Super + Ctrl + K` کے ساتھ)۔

| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy مینیو (ایپس اور باقی سب کچھ)    |
| `Super + Alt + Space` | ایپ گرڈ |
| `Super + Escape` | سسٹم مینیو (معطل کریں، دوبارہ شروع کریں، وغیرہ)  |

| `Super + T`               | ونڈو کو ٹائلنگ/فلوٹنگ کے درمیان ٹوگل کریں             |
| `Super + J` | ونڈو کی پوزیشن ٹوگل کریں (افقی/عمودی) |

| `Super + 1/2/3/4`         | فوکس شدہ مانیٹر پر مخصوص ورک اسپیس پر جائیں |

| `Super + Alt + /` | مانیٹر اسکیلنگ کے اختیارات میں پیچھے جائیں |

| `Alt + Shift + Tab` | فعال ورک اسپیس پر ونڈوز میں پیچھے چکر لگائیں |
| `Ctrl + Alt + Tab`| مانیٹرز میں فوکس آگے چکر لگائیں |
| `Ctrl + Alt + Shift + Tab`| مانیٹرز میں فوکس پیچھے چکر لگائیں |

سائز تبدیل کرنے والے شارٹ کٹس طبعی کیز `code:20` اور `code:21` (XKB `<AE11>` اور `<AE12>`) استعمال کرتے ہیں، قطع نظر اس کے کہ کی بورڈ پر کون سے حروف چھپے ہیں۔ امریکی کی بورڈز پر یہ کیز `-` اور `=` ہیں؛ جاپانی (JIS) کی بورڈز پر یہ `-` اور `^` ہیں؛ ہسپانوی کی بورڈز پر یہ `'` اور `¡` ہیں۔ JIS پر، `Super + ^`، `Super + Equal` ہے، جبکہ `Super + Shift + -` (جو `=` ٹائپ کرتا ہے) `Super + Shift + Minus` ہے۔

## یونیورسل کلپ بورڈ

| ہاٹ کی                  | فنکشن              |
| ----------------------- | --------------------- |
| `Super + A`           | ان ایپس میں سب منتخب کریں جو `Ctrl + A` کو سپورٹ کرتی ہیں    |
| `Super + C`           | کاپی    |
