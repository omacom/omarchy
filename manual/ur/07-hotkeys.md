# ہاٹ کیز

آپ `Super + K` سے تمام اہم کی بورڈ بائنڈنگز دیکھ سکتے ہیں (Tmux بائنڈنگز `Super + Alt + K` سے اور Herdr بائنڈنگز `Super + Ctrl + K` سے)۔

## نیویگیٹ کرنا

| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy مینیُو (ایپس اور سب کچھ اور)    |
| `Super + Alt + Space` | ایپ گرڈ |

## عالمگیر کلپ بورڈ

| ہاٹ کی                  | فنکشن              |
| ----------------------- | --------------------- |
| `Super + C`           | کاپی    |
| `Super + X`           | کٹ (ٹرمینل میں نہیں)    |
| `Super + V`           | پیسٹ    |
| `Super + Ctrl + V`           | کلپ بورڈ مینیجر    |

عام طور پر Linux پر، آپ کو ٹرمینل میں کاپی اینڈ پیسٹ کے لیے `Ctrl + Shift + C/V` اور ہر جگہ یہی کرنے کے لیے `Ctrl + C/V` کی ضرورت ہوتی ہے۔ یہ Omarchy کی متحدہ کلپ بورڈ ہاٹ کیز ہر جگہ کام کرتی ہیں۔

| `Prefix + v` | پین ساتھ تقسیم کریں (عمودی) |

### Tmux لے آؤٹ فنکشنز

یہ فنکشنز Tmux سیشن کے اندر چلائے جانے چاہئیں۔

| کمانڈ | فنکشن |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | ایڈیٹر، AI اور ٹرمینل کے ساتھ ڈیولپمنٹ لے آؤٹ بنائیں |
| `tdlm <ai> [<second_ai>]` | فی سب ڈائریکٹری ڈیولپمنٹ لے آؤٹ بنائیں |
| `tsl <count> <command>` | متعدد پین والا جھنڈ لے آؤٹ بنائیں |
