# ہاٹ کیز

آپ `Super + K` کے ساتھ تمام اہم کی بورڈ بائنڈنگز دیکھ سکتے ہیں (Tmux بائنڈنگز `Super + Alt + K` کے ساتھ اور Herdr بائنڈنگز `Super + Ctrl + K` کے ساتھ)۔

## ہاٹ کیز کس طرح ترتیب دی گئی ہیں

ہر ہاٹ کی ایک سطح پر ہوتی ہے، جو اس کے ماڈیفائرز سے طے ہوتی ہے، اور ہر سطح کا ایک ہی کام ہوتا ہے۔ اسی وجہ سے ہاٹ کیز آپس میں گڈمڈ نہیں ہوتیں، اور اس کا مطلب ہے کہ آپ عام طور پر اندازہ لگا سکتے ہیں کہ کوئی چیز کہاں ملے گی۔

| سطح | وہاں کیا رہتا ہے | مثالیں |
| --- | --- | --- |
| `Super + key` | سسٹم: ونڈوز، ورک اسپیسز، لے آؤٹس، اور بنیادی مینیوز | `Super + Space` Omarchy مینیو، `Super + W` ونڈو بند کریں، `Super + F` فل اسکرین |
| `Super + Shift + key` | ایپس | `Super + Shift + B` براؤزر، `Super + Shift + E` ای میل، `Super + Shift + N` ایڈیٹر |
| `Super + Ctrl + key` | پینلز اور سسٹم مینیوز | `Super + Ctrl + A` آڈیو، `Super + Ctrl + N` نیٹ ورک، `Super + Ctrl + C` کیپچر مینیو |
| `Super + Ctrl + Alt + key` | فوری اعمال اور نوٹسز | `Super + Ctrl + Alt + T` وقت دکھائیں، `Super + Ctrl + Alt + B` بیٹری، `Super + Ctrl + Alt + C` اسکرین شاٹ |

کسی ہاٹ کی میں `Alt` شامل کرنے سے آپ کو اسی چیز کی ایک مختلف شکل ملتی ہے، کبھی کوئی غیر متعلق چیز نہیں:

- `Super + Shift + B` براؤزر کھولتا ہے؛ `Super + Shift + Alt + B` پرائیویٹ ونڈو کھولتا ہے
- `Super + Shift + E` ای میل کھولتا ہے؛ `Super + Shift + Alt + E` نئی ای میل شروع کرتا ہے
- `Super + F` فل اسکرین پر جاتا ہے؛ `Super + Alt + F` فل وڈتھ پر جاتا ہے
- `Super + Ctrl + C` کیپچر مینیو کھولتا ہے؛ `Super + Ctrl + Alt + C` مینیو کو چھوڑ کر اسکرین شاٹ لیتا ہے

ہاٹ کی شامل کرتے وقت:

1. وہ کیا کرتی ہے اس سے سطح منتخب کریں، پھر کی منتخب کریں۔
2. جگہ بنانے کے لیے کسی موجودہ ہاٹ کی کو نہ ہٹائیں۔ درست سطح پر کوئی خالی کی تلاش کریں۔
3. `Alt` صرف اسی ہاٹ کی کی مختلف شکل کے لیے استعمال کریں جس میں یہ نہیں ہے۔

کچھ ہاٹ کیز ان اصولوں کو توڑتی ہیں کیونکہ وہ آسان ہیں۔ تیر یا `Tab` کے ساتھ `Shift` ایپ کھولنے کے بجائے حرکت کرتا ہے یا سمت الٹ دیتا ہے، اور `Print`، میڈیا کیز، `Alt + Tab`، اور `Ctrl + Alt + Del` اسی طرح کام کرتے ہیں جیسے وہ ہر جگہ کرتے ہیں۔ وہ استثنائیں ہیں، نقل کرنے کے نمونے نہیں۔

اگر کوئی ڈیفالٹ آپ کو مناسب نہ لگے (مثلاً آپ Windows کی طرح اسکرین شاٹس کے لیے `Super + Shift + S` چاہتے ہیں)، تو اسے `~/.config/hypr/bindings.lua` میں دوبارہ بائنڈ کریں۔

ٹچ پیڈ پر، تین اور چار انگلیوں کے سوائپس ورک اسپیسز تبدیل کرتے ہیں، ونڈوز منتقل کرتے ہیں، اور مینیو اور Quake کنسول کھولتے ہیں؛ اشاروں کے لیے [کی بورڈ، ماؤس، اور ٹریک پیڈ](34-keyboard-mouse-trackpad.md) دیکھیں۔

سائز تبدیل کرنے کے شارٹ کٹس فزیکل کیز `code:20` اور `code:21` (XKB `<AE11>` اور `<AE12>`) استعمال کرتے ہیں، قطع نظر اس کے کہ کی بورڈ پر کون سے حروف چھپے ہیں۔ US کی بورڈز پر یہ کیز `-` اور `=` ہیں؛ جاپانی (JIS) کی بورڈز پر وہ `-` اور `^` ہیں؛ ہسپانوی کی بورڈز پر وہ `'` اور `¡` ہیں۔ JIS پر، `Super + ^` دراصل `Super + Equal` ہے، جب کہ `Super + Shift + -` (جو `=` ٹائپ کرتا ہے) دراصل `Super + Shift + Minus` ہے۔

اسکرین ریکارڈنگز کے ساتھ، ہاٹ کی پہلے پوچھتی ہے کہ آپ کون سی آڈیو چاہتے ہیں، پھر ریکارڈنگ شروع کرتی ہے۔ روکنے کے لیے اسے دوبارہ دبائیں۔ تفصیلات کے لیے [اسکرین شاٹس اور ریکارڈنگ](12-screenshots-recording.md) دیکھیں۔

تمام کیپچر اختیارات Omarchy مینیو (`Super + Space`) میں _Trigger > Capture_ کے تحت بھی قابل رسائی ہیں۔
