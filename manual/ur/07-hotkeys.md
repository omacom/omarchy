# ہاٹ کیز

آپ `Super + K` کے ساتھ تمام اہم کی بورڈ بائنڈنگز دیکھ سکتے ہیں (Tmux بائنڈنگز `Super + Alt + K` کے ساتھ اور Herdr بائنڈنگز `Super + Ctrl + K` کے ساتھ)۔

## ہاٹ کیز کس طرح ترتیب دی گئی ہیں

ہر ہاٹ کی ایک سطح پر ہوتی ہے، جو اس کے موڈیفائرز سے طے ہوتی ہے، اور ہر سطح کا ایک ہی کام ہوتا ہے۔ یہی چیز ہاٹ کیز کو آپس میں گڈمڈ ہونے سے روکتی ہے، اور اس کا مطلب ہے کہ آپ عام طور پر اندازہ لگا سکتے ہیں کہ کوئی چیز کہاں ملے گی۔

| سطح | وہاں کیا ہوتا ہے | مثالیں |
| --- | --- | --- |
| `Super + key` | سسٹم: ونڈوز، ورک اسپیسز، لے آؤٹس، اور بنیادی مینوز | `Super + Space` Omarchy مینو، `Super + W` ونڈو بند کریں، `Super + F` فل اسکرین |
| `Super + Shift + key` | ایپس | `Super + Shift + B` براؤزر، `Super + Shift + E` ای میل، `Super + Shift + N` ایڈیٹر |
| `Super + Ctrl + key` | پینلز اور سسٹم مینوز | `Super + Ctrl + A` آڈیو، `Super + Ctrl + N` نیٹ ورک، `Super + Ctrl + C` کیپچر مینو |
| `Super + Ctrl + Alt + key` | فوری اقدامات اور نوٹسز | `Super + Ctrl + Alt + T` وقت دکھائیں، `Super + Ctrl + Alt + B` بیٹری، `Super + Ctrl + Alt + C` اسکرین شاٹ |

کسی ہاٹ کی میں `Alt` شامل کرنے سے آپ کو اسی چیز کی ایک مختلف شکل ملتی ہے، کبھی کوئی غیر متعلق چیز نہیں:

- `Super + Shift + B` براؤزر کھولتا ہے؛ `Super + Shift + Alt + B` پرائیویٹ ونڈو کھولتا ہے
- `Super + Shift + E` ای میل کھولتا ہے؛ `Super + Shift + Alt + E` نئی ای میل شروع کرتا ہے
- `Super + F` فل اسکرین پر جاتا ہے؛ `Super + Alt + F` فل وڈتھ پر جاتا ہے
- `Super + Ctrl + C` کیپچر مینو کھولتا ہے؛ `Super + Ctrl + Alt + C` مینو کو چھوڑ کر اسکرین شاٹ لے لیتا ہے

ہاٹ کی شامل کرتے وقت:

1. وہ کیا کرتی ہے اس سے سطح منتخب کریں، پھر کی منتخب کریں۔
2. جگہ بنانے کے لیے موجودہ ہاٹ کی کو نہ ہٹائیں۔ درست سطح پر کوئی خالی کی تلاش کریں۔
3. `Alt` صرف اس ہاٹ کی کی مختلف شکل کے لیے استعمال کریں جس میں یہ نہیں ہے۔

کچھ ہاٹ کیز ان اصولوں کو توڑتی ہیں کیونکہ وہ آسان ہیں۔ تیر یا `Tab` کے ساتھ `Shift` ایپ کھولنے کے بجائے منتقل یا الٹا کرتا ہے، اور `Print`، میڈیا کیز، `Alt + Tab`، اور `Ctrl + Alt + Del` اسی طرح کام کرتے ہیں جیسے وہ ہر جگہ کرتے ہیں۔ یہ استثنٰی ہیں، نقل کرنے کے نمونے نہیں۔

اگر کوئی ڈیفالٹ آپ کے لیے موزوں نہیں (فرض کریں آپ Windows کی طرح اسکرین شاٹس کے لیے `Super + Shift + S` چاہتے ہیں)، تو اسے `~/.config/hypr/bindings.lua` میں دوبارہ بائنڈ کریں۔

## یونیورسل کلپ بورڈ

| ہاٹ کی | فنکشن |
| ----------------------- | --------------------- |
| `Super + A` | ان ایپس میں سب منتخب کریں جو `Ctrl + A` کی حمایت کرتی ہیں |
| `Super + C` | کاپی کریں |
| `Super + X` | کاٹیں (ٹرمینل میں نہیں) |
| `Super + V` | پیسٹ کریں |
| `Super + Ctrl + V` | کلپ بورڈ مینیجر |

عام طور پر Linux پر، آپ کو ٹرمینل میں copy'n'paste کے لیے `Ctrl + Shift + C/V` اور ہر دوسری جگہ اس کے لیے `Ctrl + C/V` کی ضرورت ہوتی ہے۔ یہ Omarchy متحد کلپ بورڈ ہاٹ کیز ہر جگہ کام کرتی ہیں۔

## Tmux

prefix کی `Ctrl + Space` ہے (`Ctrl + B` بھی کام کرتا ہے)۔ آپ ان بائنڈنگز کو `~/.config/tmux/tmux.conf` میں تبدیل کر سکتے ہیں۔

### پینز

| ہاٹ کی | فنکشن |
| ----------------------- | --------------------- |
| `Prefix + v` | برابر میں پین تقسیم کریں (عمودی) |
| `Prefix + h` | نیچے پین تقسیم کریں (افقی) |
| `Prefix + x` | پین ختم کریں |
| `Prefix + z` | پین زوم ٹوگل کریں (فل اسکرین) |
| `Alt + Enter` | نیچے پین تقسیم کریں (prefix کے بغیر) |
| `Alt + Shift + Enter` | برابر میں پین تقسیم کریں (prefix کے بغیر) |
| `Alt + Escape` | پین ختم کریں (prefix کے بغیر) |
| `Ctrl + Alt + Arrows` | پینز کے درمیان جائیں |
| `Ctrl + Alt + Shift + Arrows` | پینز کا سائز تبدیل کریں |

### ونڈوز

| ہاٹ کی | فنکشن |
| ----------------------- | --------------------- |
| `Prefix + c` | نئی ونڈو |
| `Prefix + k` | ونڈو ختم کریں |
| `Prefix + r` | ونڈو کا نام تبدیل کریں |
| `Alt + 1-9` | مخصوص ونڈو پر جائیں |
| `Alt + Arrow Left/Right` | ونڈوز کے درمیان جائیں |
| `Alt + Shift + Arrow Left/Right` | ونڈو بائیں/دائیں منتقل کریں |

### سیشنز

| ہاٹ کی | فنکشن |
| ----------------------- | --------------------- |
| `Prefix + C` | نیا سیشن |
| `Prefix + K` | سیشن ختم کریں |
| `Prefix + R` | سیشن کا نام تبدیل کریں |
| `Prefix + N` | اگلا سیشن |
| `Prefix + P` | پچھلا سیشن |
| `Alt + Arrow Up/Down` | سیشنز کے درمیان جائیں |
| `Prefix + s` | سیشنز کی فہرست |
| `Prefix + d` | سیشن سے الگ ہو جائیں |

### کاپی موڈ (vi-style)

| ہاٹ کی | فنکشن |
| ----------------------- | --------------------- |
| `Prefix + [` | کاپی موڈ میں داخل ہوں |
| `v` | انتخاب شروع کریں (کاپی موڈ میں) |
| `y` | انتخاب کاپی کریں (کاپی موڈ میں) |

### عمومی

| ہاٹ کی | فنکشن |
| ----------------------- | --------------------- |
| `Prefix + q` | config دوبارہ لوڈ کریں |
| `Prefix + ?` | Tmux کی بائنڈنگز دکھائیں |
| `Prefix + :` | کمانڈ پرامپٹ |

### Tmux لے آؤٹ فنکشنز

یہ فنکشنز Tmux سیشن کے اندر چلائے جانے چاہئیں۔

| کمانڈ | فنکشن |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | ایڈیٹر، AI، اور ٹرمینل کے ساتھ dev لے آؤٹ بنائیں |
| `tdlm <ai> [<second_ai>]` | فی ذیلی ڈائرکٹری dev لے آؤٹ بنائیں |
| `tsl <count> <command>` | کثیر پین swarm لے آؤٹ بنائیں |
