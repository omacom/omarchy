# ہاٹ کیز

آپ `Super + K` کے ساتھ تمام اہم کی بورڈ بائنڈنگز دیکھ سکتے ہیں (Tmux بائنڈنگز `Super + Alt + K` کے ساتھ اور Herdr بائنڈنگز `Super + Ctrl + K` کے ساتھ)۔

## یونیورسل کلپ بورڈ

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + C`           | کاپی    |
| `Super + X`           | کاٹیں (ٹرمینل میں نہیں)    |
| `Super + V`           | پیسٹ    |
| `Super + Ctrl + V`           | کلپ بورڈ مینیجر    |

عام طور پر Linux پر، آپ کو ٹرمینل میں کاپی و پیسٹ کرنے کے لیے `Ctrl + Shift + C/V` اور باقی ہر جگہ ایسا کرنے کے لیے `Ctrl + C/V` کی ضرورت ہوتی ہے۔ یہ Omarchy متحد کلپ بورڈ ہاٹ کیز ہر جگہ کام کرتی ہیں۔
