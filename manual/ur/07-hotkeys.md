# ہاٹ کیز

آپ `Super + K` کے ساتھ تمام اہم کی بورڈ بائنڈنگز دیکھ سکتے ہیں (Tmux بائنڈنگز `Super + Alt + K` کے ساتھ اور Herdr بائنڈنگز `Super + Ctrl + K` کے ساتھ)۔

## ہاٹ کیز کی ترتیب کیسی ہے

ہر ہاٹ کی اپنے موڈیفائرز کے ذریعے طے شدہ ایک سطح پر ہوتی ہے، اور ہر سطح کا ایک ہی کام ہوتا ہے۔ اسی وجہ سے ہاٹ کیز آپس میں گڈمڈ نہیں ہوتیں، اور اس کا مطلب ہے کہ آپ عام طور پر اندازہ لگا سکتے ہیں کہ کوئی چیز کہاں ملے گی۔

| سطح | وہاں کیا ہوتا ہے | مثالیں |
| --- | --- | --- |
| `Super + key` | سسٹم: ونڈوز، ورک اسپیسز، لے آؤٹس، اور بنیادی مینوز | `Super + Space` Omarchy مینو، `Super + W` ونڈو بند کریں، `Super + F` فل اسکرین |
| `Super + Shift + key` | ایپس | `Super + Shift + B` براؤزر، `Super + Shift + E` ای میل، `Super + Shift + N` ایڈیٹر |
| `Super + Ctrl + key` | پینلز اور سسٹم مینوز | `Super + Ctrl + A` آڈیو، `Super + Ctrl + N` نیٹ ورک، `Super + Ctrl + C` کیپچر مینو |
| `Super + Ctrl + Alt + key` | فوری اعمال اور نوٹسز | `Super + Ctrl + Alt + T` وقت دکھائیں، `Super + Ctrl + Alt + B` بیٹری، `Super + Ctrl + Alt + C` اسکرین شاٹ |

کسی ہاٹ کی میں `Alt` شامل کرنے سے آپ کو اسی چیز کی ایک مختلف شکل ملتی ہے، کبھی کوئی غیر متعلق چیز نہیں ملتی:

- `Super + Shift + B` براؤزر کھولتا ہے؛ `Super + Shift + Alt + B` پرائیویٹ ونڈو کھولتا ہے
- `Super + Shift + E` ای میل کھولتا ہے؛ `Super + Shift + Alt + E` نئی ای میل شروع کرتا ہے
- `Super + F` فل اسکرین پر جاتا ہے؛ `Super + Alt + F` فل وڈتھ پر جاتا ہے
- `Super + Ctrl + C` کیپچر مینو کھولتا ہے؛ `Super + Ctrl + Alt + C` مینو کو چھوڑ کر اسکرین شاٹ لیتا ہے

ہاٹ کی شامل کرتے وقت:

1. اس کے کام کی بنیاد پر سطح منتخب کریں، پھر کی منتخب کریں۔
2. جگہ بنانے کے لیے کسی موجودہ ہاٹ کی کو نہ ہٹائیں۔ درست سطح پر کوئی خالی کی تلاش کریں۔
3. `Alt` صرف اسی ہاٹ کی کی مختلف شکل کے لیے استعمال کریں جس میں یہ شامل نہ ہو۔

چند ہاٹ کیز ان اصولوں کو توڑتی ہیں کیونکہ وہ آسان ہیں۔ تیر یا `Tab` کے ساتھ `Shift` ایپ کھولنے کے بجائے حرکت کرتا ہے یا سمت الٹ دیتا ہے، اور `Print`، میڈیا کیز، `Alt + Tab`، اور `Ctrl + Alt + Del` ویسے ہی کام کرتے ہیں جیسے وہ ہر جگہ کرتے ہیں۔ یہ استثنائی صورتیں ہیں، نقل کرنے کے نمونے نہیں۔

اگر کوئی ڈیفالٹ آپ کے لیے موزوں نہ ہو (مثلاً آپ Windows کی طرح اسکرین شاٹس کے لیے `Super + Shift + S` چاہتے ہیں)، تو اسے `~/.config/hypr/bindings.lua` میں دوبارہ بائنڈ کریں۔

ٹچ پیڈ پر، تین اور چار انگلیوں کے سوائپس ورک اسپیسز تبدیل کرتے ہیں، ونڈوز منتقل کرتے ہیں، اور مینو اور Quake کنسول کھولتے ہیں؛ اشاروں کے لیے [کی بورڈ، ماؤس، اور ٹریک پیڈ](34-keyboard-mouse-trackpad.md) دیکھیں۔

سائز تبدیل کرنے میں 0 کے دائیں جانب موجود دو کیز استعمال ہوتی ہیں، آپ کے کی بورڈ پر ان پر کچھ بھی چھپا ہو: US کی بورڈز پر `-` اور `=`، Danish اور Swedish پر `+` اور `´`، Norwegian پر `+` اور `\`، German پر `ß` اور `´`، Spanish پر `'` اور `¡`، اور Japanese (JIS) پر `-` اور `^`۔ `Super + K` انہیں ویسے ہی درج کرتا ہے جیسے آپ کے کی بورڈ پر چھپی ہیں۔ JIS پر، `Super + ^` یعنی `Super + Equal` ہے، جبکہ `Super + Shift + -` (جو `=` ٹائپ کرتا ہے) یعنی `Super + Shift + Minus` ہے۔ مانیٹر اسکیلنگ اور پاس ورڈ مینیجر `/` استعمال کرتے ہیں؛ ان لے آؤٹس پر جو `/` صرف Shift کے ساتھ ٹائپ کرتے ہیں، جیسا کہ زیادہ تر یورپی لے آؤٹس کرتے ہیں، وہ اس کے بجائے دائیں Shift کے بائیں جانب موجود کی استعمال کرتے ہیں (Danish اور German پر `-`)۔

| `Alt + Shift + D` | موجودہ صفحے پر موجود ویڈیو کو `~/Videos` میں ڈاؤن لوڈ کریں |
| `Alt + Space` | ڈکٹیشن شروع/بند کریں (درکار ہے _Setup > Defaults > Dictation_) |
| `Right Alt` | ڈکٹیٹ کرنے کے لیے پکڑے رکھیں (درکار ہے _Setup > Defaults > Dictation_) |

اسکرین ریکارڈنگز کے ساتھ، ہاٹ کی پہلے پوچھتی ہے کہ آپ کو کون سی آڈیو چاہیے، پھر ریکارڈنگ شروع کرتی ہے۔ روکنے کے لیے اسے دوبارہ دبائیں۔ تفصیلات کے لیے [اسکرین شاٹس اور ریکارڈنگ](12-screenshots-recording.md) دیکھیں۔

تمام کیپچر اختیارات Omarchy مینو (`Super + Space`) میں _Trigger > Capture_ کے تحت بھی قابل رسائی ہیں۔
