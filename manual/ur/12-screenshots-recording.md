# اسکرین شاٹس اور ریکارڈنگ

اسکرین سے آپ جو کچھ بھی حاصل کر سکتے ہیں وہ سب Print Screen کی سے جڑا ہے۔ اکیلی کی ایک تصویر لیتی ہے، اور موڈیفائرز ایک ریکارڈنگ، ایک رنگ، یا کسی حصے کے اندر موجود متن کو لیتے ہیں۔ اگر آپ کے کی بورڈ میں Print Screen کی موجود ہی نہیں ہے تو `Super + Ctrl + Alt + C` وہی اسکرین شاٹ لیتا ہے، اور `Super + Ctrl + C` پورے سیٹ کو بطور مینیو کھول دیتی ہے۔

| ہاٹ کی | فنکشن |
| ------ | -------- |
| `Print Screen` | اسکرین شاٹ |
| `Super + Ctrl + Alt + C` | اسکرین شاٹ |
| `Alt + Print Screen` | اسکرین ریکارڈ (یا چل رہی ریکارڈنگ روک دیں) |
| `Super + Print Screen` | رنگ چُننے والا |
| `Super + Ctrl + Print Screen` | کسی حصے سے متن نکالیں |
| `Super + Ctrl + C` | کیپچر مینیو |
| `Super + Ctrl + .` | تصویر یا ویڈیو کو ٹرانس کوڈ کریں |

## اسکرین شاٹس

`Print Screen` (یا `Super + Ctrl + Alt + C`) دبائیں اور Omasnap اس کا اوورلے ظاہر ہونے سے پہلے فوکس شدہ مانیٹر کو کیپچر کر لیتا ہے، تاکہ جب آپ نشانہ لگا رہے ہوں تو آپ کے نیچے کچھ بھی نہ ہلے۔ آزادانہ حصہ گھسیٹ کر منتخب کریں، کسی ونڈو پر کلک کر کے اسے کیپچر کریں، یا کھلی جگہ پر کلک کر کے پورا مانیٹر کیپچر کریں۔ اسکرولنگ حصہ کیپچر کرنے کے لیے ڈرائنگ سے پہلے `S` دبائیں۔ ارادہ بدل گیا؟ Omasnap کو بند کرنے کے لیے وہی کی دوبارہ دبائیں۔

حصہ منتخب کرنے کے بعد، Omasnap کیپچر کو محفوظ کرتا ہے، اسے کلپ بورڈ پر کاپی کرتا ہے، اور اس کے تھمب نیل کے ساتھ ایک اطلاع دکھاتا ہے، بالکل اسی طرح جیسے محفوظ شدہ اسکرین ریکارڈنگ کرتی ہے۔ محفوظ شدہ تصویر کو اپنے امیج ویوئر میں دیکھنے کے لیے Open منتخب کریں، یا اس پر تشریح شامل کرنے کے لیے Edit منتخب کریں۔

تشریحی ایڈیٹر تیر، لکیریں، شکلیں، نمایاں کاری، نمبر والے نشانات، متن، اور محفوظ چھپائی بنا سکتا ہے؛ تصویر کے کسی حصے کو تراش یا کاٹ سکتا ہے؛ اس کے متن پر OCR کر سکتا ہے؛ اور پس منظر شامل کر سکتا ہے۔ ایڈیٹر میں، تیار شدہ PNG کو کاپی اور محفوظ کرنے کے لیے `Enter` دبائیں، محفوظ کیے بغیر کاپی کرنے کے لیے `Ctrl + C` دبائیں، یا کاپی کیے بغیر محفوظ کرنے کے لیے `Ctrl + S` دبائیں۔

محفوظ شدہ اسکرین شاٹس بطور ڈیفالٹ `~/Pictures/Screenshots` میں جاتے ہیں، جن کا نام کچھ اس طرح ہوتا ہے جیسے `screenshot-2026-08-13_14-22-05-firefox.png`۔ دوسری ڈائریکٹری استعمال کرنے کے لیے `OMASNAP_SCREENSHOT_DIR` سیٹ کریں — سیشن کے ماحولیاتی متغیرات کہاں رکھنے ہیں اس کے لیے [عمومی سوالات](46-faq.md) دیکھیں۔ Omasnap جب پہلی تصویر محفوظ کرتا ہے تو ڈائریکٹری بنا دیتا ہے۔ خودکار محفوظ کاری کو غیر فعال کرنے کے لیے `~/.config/omasnap/omasnap.conf` میں `[output] autosave = false` سیٹ کریں؛ پھر کیپچرز صرف کاپی کیے جاتے ہیں، اور 7 سیکنڈ کے لیے ایک پیش منظر میں دکھائے جاتے ہیں جسے آپ اس کے پن بٹن یا `Ctrl + P` سے اسکرین پر رکھ سکتے ہیں۔

ٹرمینل سے، `omarchy screenshot` وہی اوورلے کھولتا ہے، اور آپ اس کا ابتدائی موڈ منتخب کر سکتے ہیں: `omarchy capture screenshot region`، `windows`، `fullscreen`، یا `scroll`۔ `copy` یا `save` کا دوسرا آرگومنٹ تصویر کو سیدھا اسی منزل تک بھیج دیتا ہے۔ آؤٹ پٹ سے پہلے ترمیم کرنے کے لیے، فل اسکرین ایڈیٹر کے لیے `omarchy screenshot --editor=overlay` یا الگ ونڈو کے لیے `omarchy screenshot --editor=window` استعمال کریں۔

### کی بورڈ سے پکر کو چلانا

جب سلیکشن ظاہر ہو، آپ کو ماؤس استعمال کرنے کی بالکل ضرورت نہیں:

| کی | فنکشن |
| --- | -------- |
| `S` | اسکرولنگ حصے کے موڈ کو ٹوگل کریں |
| `Super + Arrow keys` | Window موڈ میں ونڈوز کے درمیان حرکت کریں |
| `Return` | نمایاں ونڈو کو کیپچر کریں |
| `Ctrl + A` | پورے فوکس شدہ مانیٹر کو کیپچر کریں |
| `R` | اس سیشن میں آخری بار بنایا گیا حصہ بحال کریں |
| `Esc` | Omasnap کو بند کریں |

یہ بائنڈنگز صرف اسی وقت موجود ہوتی ہیں جب Omasnap کھلا ہو، اس لیے وہ آپ کی اپنی کنفگ میں کسی بھی چیز سے ٹکرا نہیں سکتیں۔

## اسکرین ریکارڈنگ

`Alt + Print Screen` _Trigger > Capture > Screenrecord_ کھولتی ہے، جو پوچھتی ہے کہ آپ ساؤنڈ ٹریک پر کیا چاہتے ہیں: کوئی آڈیو نہیں، ڈیسک ٹاپ آڈیو، ڈیسک ٹاپ کے ساتھ مائیکروفون، یا ڈیسک ٹاپ کے ساتھ مائیکروفون کے ساتھ ویب کیم۔ آخری آپشن صرف اسی وقت ظاہر ہوتا ہے جب آپ کے پاس واقعی کیمرہ لگا ہوا ہو۔ ایک منتخب کریں اور Omarchy کا ریکارڈنگ پکر آپ کو کوئی حصہ گھسیٹ کر منتخب کرنے یا کسی ونڈو یا مانیٹر پر کلک کرنے دیتا ہے۔

ریکارڈنگ gpu-screen-recorder پر چلتی ہے، جو GPU پر 60fps پر انکوڈ کرتا ہے اور اگر ضرورت پڑے تو CPU پر واپس آ جاتا ہے؛ جن GPU کو یہ سپورٹ نہیں کرتا، جیسے Apple Silicon کے، ان پر Omarchy اس کے بجائے wf-recorder سے ریکارڈ کرتا ہے۔ نتیجہ `~/Videos` میں ایک MP4 ہوتا ہے، جس کا نام `screenrecording-2026-08-13_14-22-05.mp4` ہوتا ہے۔ اسے تبدیل کرنے کے لیے `OMARCHY_SCREENRECORD_DIR` سیٹ کریں — لیکن نوٹ کریں کہ اسکرین شاٹ ڈائریکٹری کے برعکس، اس کا پہلے سے موجود ہونا ضروری ہے، ورنہ ریکارڈنگ شروع ہونے سے انکار کر دیتی ہے۔

جب آپ ریکارڈ کر رہے ہوتے ہیں تو بار میں ایک چھوٹا سا اشارہ ظاہر ہوتا ہے۔ روکنے کے لیے اس پر کلک کریں۔ آپ `Alt + Print Screen` دوبارہ دبا کر بھی روک سکتے ہیں، یا _Trigger > Capture > Screenrecord_ کے تحت _Stop Screenrecording_ اندراج سے بھی، جو صرف اسی وقت ظاہر ہوتا ہے جب واقعی کچھ ریکارڈ ہو رہا ہو۔

روکنا آپ کو فائل دینے سے پہلے تھوڑی سی صفائی کرتا ہے: پہلا فریم تراش دیا جاتا ہے، اور اگر آڈیو ہے تو اسے -14 LUFS پر نارملائز کر دیا جاتا ہے اور بالکل شروع میں PipeWire کیپچر کی آواز کو خاموش کر دیا جاتا ہے۔ پھر ریکارڈنگ کے تھمب نیل کے ساتھ ایک اطلاع ظاہر ہوتی ہے۔ فائل کو Omaview میں چلانے کے لیے _Open_ منتخب کریں، یا اسے Omacut میں تراشنے کے لیے _Cut_ منتخب کریں۔

### ویب کیم اوورلے

جب آپ ویب کیم کے ساتھ ریکارڈ کرتے ہیں تو کیمرہ آپ جو بھی ریکارڈ کر رہے ہیں اس کے نیچے دائیں کونے میں ایک پن شدہ، تراشی ہوئی پورٹریٹ ونڈو کے طور پر ظاہر ہوتا ہے۔ اگر یہ کسی ایسی چیز کے اوپر آ گیا ہے جس کی آپ کو ضرورت ہے تو اسے موقع پر ہی سائز تبدیل کریں:

| ہاٹ کی | فنکشن |
| ------ | -------- |
| `Super + Alt + [` | ویب کیم اوورلے کو چھوٹا کریں |
| `Super + Alt + ]` | ویب کیم اوورلے کو بڑا کریں |

تین سائز ہیں — چھوٹا، درمیانہ، اور بڑا — اور ہاٹ کیز ان کے درمیان قدم بہ قدم لے جاتی ہیں۔ درمیانہ ڈیفالٹ ہے۔ یہ ریکارڈنگ کے تناسب سے ہوتے ہیں، اس لیے کیمرہ فریم کا اتنا ہی حصہ لیتا ہے چاہے آپ 1080p مانیٹر ریکارڈ کر رہے ہوں یا 6K مانیٹر۔ اور اگر آپ نے پورے ڈسپلے کے بجائے کوئی حصہ ریکارڈ کیا ہے تو اوورلے مانیٹر کے کونے کے بجائے اس حصے کے کونے سے جڑتا ہے، تاکہ یہ تصویر کے اندر ہی رہے۔

آپ اسے براہ راست `omarchy-capture-webcam-resize small` سے بھی کال کر سکتے ہیں، یا درمیانے پر واپس جانے کے لیے `reset` استعمال کر سکتے ہیں۔

## متن، QR کوڈز، اور رنگ

`Super + Ctrl + Print Screen` ایک حصہ منتخب کرتی ہے اور اس پر OCR کر کے کلپ بورڈ پر بھیج دیتی ہے۔ اس کا مناسب احاطہ [متن نکالنا اور ڈکٹیشن](11-text-extraction-dictation.md) میں کیا گیا ہے۔

_Trigger > Capture > QR Code_ QR کوڈز کے لیے یہی چال کرتا ہے۔ جس حصے میں کوڈ ہے اسے منتخب کریں، اور ڈی کوڈ شدہ قدر کلپ بورڈ پر چلی جاتی ہے۔ یہ صرف QR کوڈز تلاش کرتا ہے — ورنہ گھنی اسکرین مواد کی عادت ہے کہ وہ غلطی سے بارکوڈ سمجھی جائے۔ جاننا ضروری ہے: ڈی کوڈ شدہ قدر کلپ بورڈ پر جاتی ہے اور کہیں اور نہیں جاتی۔ یہ پرنٹ نہیں ہوتی، یہ اطلاع میں نہیں ہوتی، اور اسے حساس کے طور پر نشان زد کیا جاتا ہے تاکہ یہ [کلپ بورڈ ہسٹری](08-unified-clipboard-history.md) میں نہ ٹھہرے۔ QR کوڈز معمول کے مطابق راز لے کر چلتے ہیں — مثال کے طور پر 2FA سیٹ اپ کوڈ کے پیچھے موجود `otpauth://` URI — اور آپ نہیں چاہتے کہ وہ کسی لاگ میں ہو۔ پیسٹ کرنا پھر بھی ٹھیک کام کرتا ہے۔

`Super + Print Screen` (یا _Trigger > Capture > Color_) کرسر کو آئی ڈراپر میں بدل دیتی ہے۔ اسکرین پر کسی بھی چیز پر کلک کریں اور رنگ کلپ بورڈ پر آ جاتا ہے۔ منتخب کیے بغیر واپس جانے کے لیے ہاٹ کی دوبارہ دبائیں۔

## شیئر کرنے سے پہلے ٹرانس کوڈنگ

4K اسکرین ریکارڈنگ یا آپ کے فون سے لی گئی خام HEIC اکثر اتنی بڑی ہوتی ہے کہ بس بھیجی نہیں جا سکتی۔ `Super + Ctrl + .` (یا _Trigger > Transcode_) اسے ٹھیک کرتی ہے۔ یہ آپ کو `~/Pictures` اور `~/Videos` پر ایک فزی فائل پکر پیش کرتی ہے، پھر فارمیٹ اور سائز پوچھتی ہے۔

تصاویر high، medium، یا low پر jpg یا png میں جاتی ہیں، جو چوڑائی کو بالترتیب 3160، 2160، اور 1080 پکسلز تک محدود کرتی ہیں۔ ویڈیوز 4k، 1080p، یا 720p پر mp4 یا متحرک gif میں جاتی ہیں۔ تبدیل شدہ فائل اصل کے ساتھ ہی لکھی جاتی ہے اور اس کے نام میں ریزولوشن ہوتا ہے — `demo-1080p.mp4` — اور راستہ بطور فائل URI کلپ بورڈ پر کاپی ہو جاتا ہے، تاکہ آپ اسے براہ راست کسی ایسی ایپ میں پیسٹ کر سکیں جو فائل ڈراپ لیتی ہے۔

یہ ٹرمینل سے بھی کام کرتا ہے، اگر آپ پہلے سے جانتے ہیں کہ آپ کیا چاہتے ہیں: `omarchy transcode ~/Videos/demo.mov mp4 1080p`۔ `omarchy transcode ascii` بھی ہے، جو تصویر کو ASCII آرٹ میں بدل دیتا ہے — وہ زیادہ تر [برینڈنگ](41-branding.md) کے لیے ہے۔
