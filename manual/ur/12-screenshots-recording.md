# اسکرین شاٹس اور ریکارڈنگ

اسکرین سے جو کچھ بھی اٹھا سکتے ہیں، وہ سب Print Screen کی پر ٹکا ہوا ہے۔ اکیلی یہ کی تصویر لیتی ہے، اور اس کے ساتھ لگنے والے ماڈیفائرز ریکارڈنگ، رنگ، یا کسی خطے کے اندر موجود متن لیتے ہیں۔ اگر آپ کے کی بورڈ میں Print Screen کی ہے ہی نہیں، تو `Super + Ctrl + Alt + C` وہی اسکرین شاٹ لیتا ہے، اور `Super + Ctrl + C` پوری سیٹ کو مینیو کے طور پر کھولتا ہے۔

| ہاٹ کی | فنکشن |
| ------ | -------- |
| `Print Screen` | اسکرین شاٹ |
| `Super + Ctrl + Alt + C` | اسکرین شاٹ |
| `Alt + Print Screen` | اسکرین ریکارڈنگ (یا چل رہی ریکارڈنگ روکیں) |
| `Super + Print Screen` | رنگ چننے والا |
| `Super + Ctrl + Print Screen` | کسی خطے سے متن نکالیں |
| `Super + Ctrl + C` | کیپچر مینیو |
| `Super + Ctrl + .` | تصویر یا ویڈیو کو ٹرانس کوڈ کریں |

## اسکرین شاٹس

`Print Screen` (یا `Super + Ctrl + Alt + C`) دبائیں اور Omasnap اپنے اوورلے کے ظاہر ہونے سے پہلے فوکس شدہ مانیٹر کو کیپچر کر لیتا ہے، تاکہ نشانہ لیتے ہوئے آپ کے نیچے کچھ بھی نہ ہلے۔ آزاد مرضی کا خطہ گھسیٹ کر بنائیں، کسی ونڈو پر کلک کر کے اسے کیپچر کریں، یا خالی جگہ پر کلک کر کے پورا مانیٹر کیپچر کریں۔ کھینچنا شروع کرنے سے پہلے اسکرولنگ خطہ کیپچر کرنے کے لیے `S` دبائیں۔ ارادہ بدل گیا؟ اسی کی کو دوبارہ دبا کر Omasnap ہٹا دیں۔

خطہ منتخب کرنے کے بعد، Omasnap کیپچر محفوظ کرتا ہے، اسے کلپ بورڈ پر کاپی کرتا ہے، اور محفوظ شدہ اسکرین ریکارڈنگ کی طرح اس کے تھمب نیل کے ساتھ نوٹیفکیشن دکھاتا ہے۔ محفوظ شدہ شاٹ کو اپنے امیج ویوئر میں دیکھنے کے لیے Open منتخب کریں، یا اس میں نوٹ لکھنے کے لیے Edit منتخب کریں۔

تشریحی ایڈیٹر تیر، لکیریں، شکلیں، نمایاں کاریاں، نمبر والے نشان، متن، اور محفوظ چھپائی کر سکتا ہے؛ تصویر کے کسی حصے کو تراش یا کاٹ سکتا ہے؛ اس کے متن کا OCR کر سکتا ہے؛ اور پس منظر جوڑ سکتا ہے۔ ایڈیٹر میں، تیار PNG کو کاپی اور محفوظ کرنے کے لیے `Enter` دبائیں، محفوظ کیے بغیر کاپی کرنے کے لیے `Ctrl + C`، یا کاپی کیے بغیر محفوظ کرنے کے لیے `Ctrl + S` دبائیں۔

محفوظ شدہ اسکرین شاٹس بطور ڈیفالٹ `~/Pictures/Screenshots` میں جاتے ہیں، ایسے نام کے ساتھ جیسے `screenshot-2026-08-13_14-22-05-firefox.png`۔ دوسری ڈائریکٹری استعمال کرنے کے لیے `OMASNAP_SCREENSHOT_DIR` مقرر کریں — سیشن انوائرنمنٹ ویری ایبل کہاں رکھنے ہیں، اس کے لیے [عمومی سوالات](46-faq.md) دیکھیں۔ Omasnap پہلا شاٹ محفوظ کرتے وقت ڈائریکٹری بنا دیتا ہے۔ خودکار محفوظ کاری بند کرنے کے لیے `~/.config/omasnap/omasnap.conf` میں `[output] autosave = false` مقرر کریں؛ پھر کیپچرز صرف کاپی ہوں گے، اور 10 سیکنڈ کے لیے پیش منظر میں دکھائے جائیں گے، جسے آپ اس کے پن بٹن یا `Ctrl + P` سے اسکرین پر روکے رکھ سکتے ہیں۔

ٹرمینل سے، `omarchy screenshot` وہی اوورلے کھولتا ہے، اور آپ اس کے ابتدائی موڈ کا انتخاب کر سکتے ہیں: `omarchy capture screenshot region`، `windows`، `fullscreen`، یا `scroll`۔ `copy` یا `save` کا دوسرا آرگومنٹ شاٹ کو سیدھا اسی منزل پر بھیج دیتا ہے۔ آؤٹ پٹ سے پہلے ترمیم کرنے کے لیے، فل اسکرین ایڈیٹر کے لیے `omarchy screenshot --editor=overlay` یا الگ ونڈو کے لیے `omarchy screenshot --editor=window` استعمال کریں۔

### کی بورڈ سے چننے والا چلانا

جب انتخاب سامنے ہو، تو آپ کو ماؤس استعمال کرنے کی بالکل ضرورت نہیں:

| کی | فنکشن |
| --- | -------- |
| `S` | اسکرولنگ خطے والا موڈ ٹوگل کریں |
| `Super + Arrow keys` | Window موڈ میں ونڈوز کے درمیان جائیں |
| `Return` | نمایاں ونڈو کیپچر کریں |
| `Ctrl + A` | پورا فوکس شدہ مانیٹر کیپچر کریں |
| `R` | اس سیشن میں آخری بار کھینچا گیا خطہ بحال کریں |
| `Esc` | Omasnap ہٹائیں |

یہ بائنڈنگز صرف تب موجود ہوتی ہیں جب Omasnap کھلا ہو، اس لیے یہ آپ کی اپنی کنفگ میں کسی بھی چیز سے ٹکرا نہیں سکتیں۔

## اسکرین ریکارڈنگ

`Alt + Print Screen` _Trigger > Capture > Screenrecord_ کھولتا ہے، جو پوچھتا ہے کہ ساؤنڈ ٹریک پر آپ کو کیا چاہیے: کوئی آڈیو نہیں، ڈیسک ٹاپ آڈیو، ڈیسک ٹاپ کے ساتھ مائیکروفون، یا ڈیسک ٹاپ کے ساتھ مائیکروفون اور ویب کیم۔ آخری والا صرف تب نظر آتا ہے جب واقعی آپ کے پاس کیمرہ لگا ہوا ہو۔ کوئی ایک منتخب کریں اور Omarchy کا ریکارڈنگ چننے والا آپ کو خطہ گھسیٹنے یا ونڈو یا مانیٹر پر کلک کرنے دیتا ہے۔

ریکارڈنگ gpu-screen-recorder پر چلتی ہے، جو GPU پر 60fps پر انکوڈ کرتا ہے اور ضرورت پڑنے پر CPU پر واپس آ جاتا ہے۔ نتیجہ `~/Videos` میں ایک MP4 ہوتا ہے، جس کا نام `screenrecording-2026-08-13_14-22-05.mp4` ہوتا ہے۔ اسے بدلنے کے لیے `OMARCHY_SCREENRECORD_DIR` مقرر کریں — لیکن نوٹ کریں کہ اسکرین شاٹ ڈائریکٹری کے برعکس، یہ والی پہلے سے موجود ہونی چاہیے، ورنہ ریکارڈنگ شروع ہونے سے انکار کر دے گی۔

جب آپ ریکارڈنگ کر رہے ہوں، بار میں ایک چھوٹا سا اشارہ نمودار ہو جاتا ہے۔ روکنے کے لیے اس پر کلک کریں۔ آپ `Alt + Print Screen` دوبارہ دبا کر بھی روک سکتے ہیں، یا _Trigger > Capture > Screenrecord_ کے نیچے موجود _Stop Screenrecording_ اندراج سے بھی، جو صرف تب ظاہر ہوتا ہے جب واقعی کچھ ریکارڈ ہو رہا ہو۔

روکنا فائل آپ کے حوالے کرنے سے پہلے تھوڑی سی صفائی ستھرائی کرتا ہے: پہلا فریم تراش دیا جاتا ہے، اور اگر آڈیو ہو تو اسے -14 LUFS پر نارملائز کر دیا جاتا ہے، بالکل شروع میں PipeWire کیپچر کی پھٹنے والی آواز خاموش کر کے۔ پھر ریکارڈنگ سے لیے گئے تھمب نیل کے ساتھ ایک نوٹیفکیشن ظاہر ہوتا ہے۔ فائل کو Omaview میں چلانے کے لیے اس پر کلک کریں۔

### ویب کیم اوورلے

جب آپ ویب کیم کے ساتھ ریکارڈنگ کرتے ہیں، تو کیمرہ آپ جو بھی ریکارڈ کر رہے ہیں اس کے نیچے دائیں کونے میں پن شدہ، تراشی ہوئی پورٹریٹ ونڈو کے طور پر ظاہر ہوتا ہے۔ اگر یہ آپ کو درکار کسی چیز کے اوپر آ گیا ہو، تو اس کا سائز موقع پر ہی بدل دیں:

| ہاٹ کی | فنکشن |
| ------ | -------- |
| `Super + Alt + [` | ویب کیم اوورلے چھوٹا کریں |
| `Super + Alt + ]` | ویب کیم اوورلے بڑا کریں |

تین سائز ہیں — چھوٹا، درمیانہ، اور بڑا — اور ہاٹ کیز ان کے درمیان قدم بہ قدم لے جاتی ہیں۔ درمیانہ ڈیفالٹ ہے۔ یہ ریکارڈنگ کے متناسب ہوتے ہیں، اس لیے کیمرہ فریم کا اتنا ہی حصہ لیتا ہے چاہے آپ 1080p مانیٹر ریکارڈ کر رہے ہوں یا 6K والا۔ اور اگر آپ نے پوری ڈسپلے کے بجائے کوئی خطہ ریکارڈ کیا ہو، تو اوورلے مانیٹر کے بجائے اس خطے کے کونے سے جڑتا ہے، تاکہ وہ شاٹ کے اندر ہی رہے۔

آپ اسے براہِ راست `omarchy-capture-webcam-resize small` سے بھی بلا سکتے ہیں، یا درمیانے پر واپس جانے کے لیے `reset` استعمال کر سکتے ہیں۔

## متن، QR کوڈز، اور رنگ

`Super + Ctrl + Print Screen` ایک خطہ منتخب کرتا ہے اور اس کا OCR کر کے کلپ بورڈ پر بھیج دیتا ہے۔ اس کا مناسب احاطہ [متن نکالنا اور ڈکٹیشن](11-text-extraction-dictation.md) میں کیا گیا ہے۔

_Trigger > Capture > QR Code_ QR کوڈز کے لیے بھی یہی چال چلتا ہے۔ وہ خطہ منتخب کریں جس میں کوڈ ہو، اور ڈی کوڈ شدہ قدر کلپ بورڈ پر چلی جاتی ہے۔ یہ صرف QR کوڈز تلاش کرتا ہے — ورنہ گھنی اسکرین مواد کی عادت ہوتی ہے کہ وہ غلطی سے بارکوڈ سمجھ لیا جائے۔ جاننے کے قابل بات: ڈی کوڈ شدہ قدر کلپ بورڈ پر جاتی ہے اور کہیں اور نہیں۔ یہ نہ چھپتی ہے، نہ نوٹیفکیشن میں ہوتی ہے، اور اسے حساس نشان زد کیا جاتا ہے تاکہ یہ [کلپ بورڈ کی تاریخ](08-unified-clipboard-history.md) میں ٹکی نہ رہے۔ QR کوڈز عام طور پر راز لیے پھرتے ہیں — ایک مثال کے طور پر، 2FA سیٹ اپ کوڈ کے پیچھے موجود `otpauth://` URI — اور آپ نہیں چاہتے کہ یہ کسی لاگ میں پڑا رہے۔ چسپاں کرنا پھر بھی ٹھیک کام کرتا ہے۔

`Super + Print Screen` (یا _Trigger > Capture > Color_) کرسر کو آنکھ سے رنگ اٹھانے والے آلے میں بدل دیتا ہے۔ اسکرین پر کسی بھی چیز پر کلک کریں اور رنگ کلپ بورڈ پر آ جاتا ہے۔ چنے بغیر باہر نکلنے کے لیے ہاٹ کی دوبارہ دبائیں۔

## شیئر کرنے سے پہلے ٹرانس کوڈنگ

4K اسکرین ریکارڈنگ یا آپ کے فون سے آئی خام HEIC اکثر اتنی بڑی ہوتی ہے کہ اسے بس ایسے ہی بھیج دیا جائے۔ `Super + Ctrl + .` (یا _Trigger > Transcode_) اسے ٹھیک کر دیتا ہے۔ یہ آپ کو `~/Pictures` اور `~/Videos` پر ایک مبہم فائل چننے والا پیش کرتا ہے، پھر فارمیٹ اور سائز پوچھتا ہے۔

تصاویر jpg یا png میں اعلیٰ، درمیانی، یا ادنیٰ پر جاتی ہیں، جو چوڑائی کو 3160، 2160، اور 1080 پکسلز پر محدود کر دیتی ہیں۔ ویڈیوز mp4 یا متحرک gif میں 4k، 1080p، یا 720p پر جاتی ہیں۔ تبدیل شدہ فائل اصل کے ساتھ ہی لکھی جاتی ہے اور نام میں ریزولوشن ہوتا ہے — `demo-1080p.mp4` — اور راستہ فائل URI کے طور پر کلپ بورڈ پر کاپی ہو جاتا ہے، تاکہ آپ اسے براہِ راست کسی ایسی ایپ میں چسپاں کر سکیں جو فائل ڈراپ لیتی ہو۔

یہ ٹرمینل سے بھی کام کرتا ہے، اگر آپ پہلے سے جانتے ہوں کہ آپ کو کیا چاہیے: `omarchy transcode ~/Videos/demo.mov mp4 1080p`۔ ایک اور بھی ہے `omarchy transcode ascii`، جو تصویر کو ASCII آرٹ میں بدل دیتا ہے — وہ زیادہ تر [برانڈنگ](41-branding.md) کے لیے ہے۔

## اسے کہیں بھیجنا

جب فائل مل جائے، تو `Super + Ctrl + S` شیئر مینیو کھولتا ہے اور اسے LocalSend کے ذریعے آپ کے نیٹ ورک پر موجود کسی دوسرے آلے پر بھیج دیتا ہے۔ اس کے لیے [GUIs](22-guis.md) دیکھیں۔
