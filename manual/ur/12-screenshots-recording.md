# اسکرین شاٹس اور ریکارڈنگ

اسکرین سے جو کچھ بھی آپ حاصل کر سکتے ہیں وہ Print Screen key سے جڑا ہے۔ ایک key اپنے آپ میں تصویر لیتی ہے، اور موڈیفائرز ریکارڈنگ، رنگ، یا کسی حصے کے اندر متن لیتے ہیں۔ اگر آپ کے کی بورڈ میں Print Screen key بالکل نہیں ہے تو، `Super + Ctrl + C` اسی سیٹ کو بطور مینیو کھولتا ہے۔

| ہاٹ کی | فنکشن |
| ------ | -------- |
| `Print Screen` | اسکرین شاٹ |
| `Alt + Print Screen` | اسکرین ریکارڈ (یا جو چل رہا ہے اسے روکیں) |
| `Super + Print Screen` | رنگ منتخب کنندہ |
| `Super + Ctrl + Print Screen` | حصے سے متن نکالیں |
| `Super + Ctrl + C` | کیپچر مینیو |
| `Super + Ctrl + .` | تصویر یا ویڈیو ٹرانس کوڈ کریں |

## اسکرین شاٹس

`Print Screen` دبائیں اور Omasnap اپنے اوورلے کے ظاہر ہونے سے پہلے فوکس شدہ مانیٹر کو کیپچر کرتا ہے، تاکہ آپ کے نشانہ لگانے کے دوران آپ کے نیچے کچھ نہ ہلے۔ فریفارم حصہ گھسیٹیں، اسے کیپچر کرنے کے لیے ونڈو پر کلک کریں، یا پورے مانیٹر کو کیپچر کرنے کے لیے کھلی جگہ پر کلک کریں۔ اسکرولنگ حصہ کیپچر کرنے کے لیے ڈرائنگ سے پہلے `S` دبائیں۔ ارادہ بدل گیا؟ Omasnap کو خارج کرنے کے لیے دوبارہ `Print Screen` دبائیں۔

آپ کے حصہ منتخب کرنے کے بعد، Omasnap کیپچر محفوظ کرتا ہے، اسے کلپ بورڈ پر کاپی کرتا ہے، اور 10 سیکنڈز کے لیے پیش نظارہ دکھاتا ہے۔ اسے اسکرین پر برقرار رکھنے کے لیے پیش نظارے کا پِن بٹن یا `Ctrl + P` استعمال کریں، یا اس پر نوٹ لکھنے کے لیے Edit منتخب کریں۔

اینوٹیشن ایڈیٹر تیر، لکیریں، شکلیں، نمایاں نشانیاں، نمبر دار مارکرز، متن اور محفوظ تحریرات (redactions) کھینچ سکتا ہے؛ تصویر کے حصے کو کاپ (crop) یا کٹ آؤٹ کر سکتا ہے؛ اس کے متن کا OCR کر سکتا ہے؛ اور پس منظر شامل کر سکتا ہے۔ ایڈیٹر میں، مکمل PNG کاپی اور محفوظ کرنے کے لیے `Enter` دبائیں، محفوظ کیے بغیر کاپی کرنے کے لیے `Ctrl + C`، یا کاپی کیے بغیر محفوظ کرنے کے لیے `Ctrl + S` دبائیں۔

محفوظ شدہ اسکرین شاٹس بطور ڈیفالٹ `~/Pictures/Screenshots` میں آتے ہیں، جس کا نام `screenshot-2026-08-13_14-22-05-firefox.png` جیسا ہوتا ہے۔ دوسری ڈائریکٹری استعمال کرنے کے لیے `OMASNAP_SCREENSHOT_DIR` سیٹ کریں — سیشن انوائرانمنٹ متغیرات کہاں رکھیں اس کے لیے [FAQ](46-faq.md) دیکھیں۔ Omasnap جب پہلا شاٹ محفوظ کرتا ہے تو ڈائریکٹری بناتا ہے۔ خودکار محفوظ کرنا غیر فعال کرنے کے لیے `~/.config/omasnap/omasnap.conf` میں `[output] autosave = false` سیٹ کریں۔

ٹرمینل سے، `omarchy screenshot` یہی اوورلے کھولتا ہے، اور آپ اس کا ابتدائی موڈ منتخب کر سکتے ہیں: `omarchy capture screenshot region`، `windows`، `fullscreen`، یا `scroll`۔ `copy` یا `save` کا دوسرا آرگومینٹ پیش نظارہ چھوڑ کر شاٹ سیدھا اس منزل پر بھیجتا ہے۔ آؤٹ پُٹ سے پہلے ترمیم کرنے کے لیے، فل اسکرین ایڈیٹر کے لیے `omarchy screenshot --editor=overlay` یا علیحدہ ونڈو کے لیے `omarchy screenshot --editor=window` استعمال کریں۔

### کی بورڈ سے پِکر چلانا

جب انتخاب اوپر ہو تو، آپ کو ماؤس استعمال کرنے کی بالکل ضرورت نہیں ہوتی:

| Key | فنکشن |
| --- | -------- |
| `S` | اسکرولنگ حصہ موڈ ٹوگل کریں |
| `Super + Arrow keys` | Window موڈ میں ونڈوز کے درمیان حرکت کریں |
| `Return` | نمایاں شدہ ونڈو کیپچر کریں |
| `Ctrl + A` | مکمل فوکس شدہ مانیٹر کیپچر کریں |
| `R` | اس سیشن میں کھینچا گیا آخری حصہ بحال کریں |
| `Esc` | Omasnap خارج کریں |

یہ بائنڈنگز صرف اس وقت موجود ہوتی ہیں جب Omasnap کھلا ہو، لہٰذا یہ آپ کے اپنے کانفیگ میں کسی چیز سے ٹکرا نہیں سکتیں۔

## اسکرین ریکارڈنگ

`Alt + Print Screen` _ٹریگر > Capture > Screenrecord_ کھولتا ہے، جو پوچھتا ہے کہ آپ ساؤنڈ ٹریک پر کیا چاہتے ہیں: کوئی آڈیو نہیں، ڈیسک ٹاپ آڈیو، ڈیسک ٹاپ پلس مائکروفون، یا ڈیسک ٹاپ پلس مائکروفون پلس ویب کیم۔ آخری والا صرف اس وقت ظاہر ہوتا ہے اگر آپ کے پاس واقعی کیمرہ پلگ ان ہو۔ ایک منتخب کریں اور Omarchy کا ریکارڈنگ پِکر آپ کو حصہ گھسیٹنے یا ونڈو یا مانیٹر پر کلک کرنے دیتا ہے۔

ریکارڈنگ gpu-screen-recorder پر چلتی ہے، جو GPU پر 60fps پر انکوڈ کرتا ہے اور ضرورت پڑنے پر CPU پر واپس آ جاتا ہے۔ نتیجہ `~/Videos` میں ایک MP4 ہے، جس کا نام `screenrecording-2026-08-13_14-22-05.mp4` ہے۔ اسے تبدیل کرنے کے لیے `OMARCHY_SCREENRECORD_DIR` سیٹ کریں — لیکن یاد رکھیں کہ اسکرین شاٹ ڈائریکٹری کے برعکس، اسے پہلے سے موجود ہونا چاہیے، ورنہ ریکارڈنگ شروع ہونے سے انکار کر دیتی ہے۔

جب آپ ریکارڈ کر رہے ہوں تو، بار میں چھوٹا سا اشارہ ظاہر ہوتا ہے۔ رکنے کے لیے اس پر کلک کریں۔ آپ دوبارہ `Alt + Print Screen` سے بھی رک سکتے ہیں، یا _ٹریگر > Capture > Screenrecord_ کے تحت _Stop Screenrecording_ انٹری سے بھی، جو صرف اس وقت ظاہر ہوتی ہے جب واقعی کچھ ریکارڈ ہو رہا ہو۔

روکنے سے فائل آپ کے حوالے کرنے سے پہلے تھوڑی صفائی ہوتی ہے: پہلا فریم ٹرم ہے ہے ہے، اور اگر آڈیو ہو تو اسے -14 LUFS پر نارملائز کیا جاتا ہے اور بالکل شروع میں PipeWire کیپچر پاپ کو خاموش کر دیا جاتا ہے۔ پھر ریکارڈنگ سے تھمب نیل کے ساتھ نوٹیفکیشن ظاہر ہوتا ہے۔ فائل کو mpv میں چلانے کے لیے اس پر کلک کریں۔

### ویب کیم اوورلے

جب آپ ویب کیم کے ساتھ ریکارڈ کرتے ہیں تو، کیمرہ آپ جو کچھ بھی ریکارڈ کر رہے ہیں اس کے نیچے دائیں کونے میں پِن شدہ، کراپ شدہ پورٹریٹ ونڈو کے طور پر ظاہر ہوتا ہے۔ اگر یہ کسی ایسی چیز کے اوپر بیٹھا ہو جس کی آپ کو ضرورت ہے تو، فوراً اس کا سائز تبدیل کریں:

| ہاٹ کی | فنکشن |
| ------ | -------- |
| `Super + Alt + [` | ویب کیم اوورلے کو چھوٹا کریں |
| `Super + Alt + ]` | ویب کیم اوورلے کو بڑا کریں |

تین سائز ہیں — چھوٹا، درمیانی اور بڑا — اور ہاٹ کیز ان کے درمیان آگے بڑھتی ہیں۔ درمیانی ڈیفالٹ ہے۔ وہ ریکارڈنگ کے متناسب ہیں، لہٰذا چاہے آپ 1080p مانیٹر ریکارڈ کر رہے ہوں یا 6K، کیمرہ فریم کا ایک ہی حصہ لیتا ہے۔ اور اگر آپ نے پورے ڈسپلے کے بجائے حصہ ریکارڈ کیا ہو تو، اوورلے مانیٹر کے بجائے اس حصے کے کونے پر لنگر انداز ہوتا ہے، لہٰذا یہ شاٹ کے اندر رہتا ہے۔

آپ اسے براہ راست `omarchy-capture-webcam-resize small` سے بھی کال کر سکتے ہیں، یا درمیانی پر واپس جانے کے لیے `reset`۔

## متن، QR کوڈز اور رنگ

`Super + Ctrl + Print Screen` ایک حصہ منتخب کرتا ہے اور اسے OCR کر کے کلپ بورڈ پر بھیجتا ہے۔ یہ [متن نکالنا اور املا](11-text-extraction-dictation.md) میں ٹھیک طریقے سے بیان کیا گیا ہے۔

_ٹریگر > Capture > QR Code_ QR کوڈز کے لیے بھی یہی تدبیر کرتا ہے۔ جس حصے میں کوڈ ہے اسے منتخب کریں، اور ڈی کوڈ شدہ قدر کلپ بورڈ پر چلی جاتی ہے۔ یہ صرف QR کوڈز تلاش کرتا ہے — ورنہ گھنے اسکرین مواد کو بار کوڈ کے طور پر غلط پہچاننے کی عادت ہوتی ہے۔ یہ جاننا اہم ہے: ڈی کوڈ شدہ قدر کلپ بورڈ پر جاتی ہے اور کہیں اور نہیں۔ یہ چھپتی نہیں، یہ نوٹیفکیشن میں نہیں، اور اسے حساس نشان زد کیا گیا ہے تاکہ یہ [کلپ بورڈ کی تاریخ](08-unified-clipboard-history.md) میں چپکی نہ رہے۔ QR کوڈز باقاعدگی سے راز رکھتے ہیں — مثال کے طور پر 2FA سیٹ اپ کوڈ کے پیچھے `otpauth://` URI — اور آپ نہیں چاہتے کہ یہ لاگ میں رہے۔ پیسٹ کرنا اب بھی ٹھیک کام کرتا ہے۔

`Super + Print Screen` (یا _ٹریگر > Capture > Color_) کرسر کو آئی ڈراپر میں تبدیل کر دیتا ہے۔ اسکرین پر کسی بھی چیز پر کلک کریں اور رنگ کلپ بورڈ پر آ جاتا ہے۔ چنے بغیر باہر نکلنے کے لیے ہاٹ کی دوبارہ دبائیں۔

## شیئر کرنے سے پہلے ٹرانس کوڈنگ

4K اسکرین ریکارڈنگ یا آپ کے فون سے خام HEIC اکثر بھیجنے کے لیے بہت بڑا ہوتا ہے۔ `Super + Ctrl + .` (یا _ٹریگر > Transcode_) اسے ٹھیک کرتا ہے۔ یہ آپ کو `~/Pictures` اور `~/Videos` پر فزی فائل پِکر پیش کرتا ہے، پھر فارمیٹ اور سائز پوچھتا ہے۔

تصاویر jpg یا png میں اعلیٰ، درمیانی یا کم پر جاتی ہیں، جو چوڑائی کو 3160، 2160 اور 1080 پکسلز پر محدود کرتی ہیں۔ ویڈیوز mp4 یا اینیمیٹڈ gif میں 4k، 1080p یا 720p پر جاتی ہیں۔ تبدیل شدہ فائل اصل کے ساتھ نام میں ریزولوشن کے ساتھ لکھی جاتی ہے — `demo-1080p.mp4` — اور راستہ فائل URI کے طور پر کلپ بورڈ پر کاپی ہوتا ہے، تاکہ آپ اسے براہ راست ایسی ایپ میں پیسٹ کر سکیں جو فائل ڈراپس لیتی ہو۔

یہ ٹرمینل سے بھی کام کرتا ہے، اگر آپ پہلے سے جانتے ہیں کہ آپ کیا چاہتے ہیں: `omarchy transcode ~/Videos/demo.mov mp4 1080p`۔ `omarchy transcode ascii` بھی ہے، جو تصویر کو ASCII آرٹ میں تبدیل کرتا ہے — وہ زیادہ تر [برینڈنگ](41-branding.md) کے لیے ہے۔
