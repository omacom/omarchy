# اسکرین شاٹس اور ریکارڈنگ

اسکرین سے جو کچھ بھی حاصل کیا جا سکتا ہے، وہ سب Print Screen کلید سے جڑا ہے۔ اکیلی یہی کلید تصویر لیتی ہے، اور موڈیفائرز ریکارڈنگ، رنگ، یا کسی حصے کے اندر موجود متن لیتے ہیں۔ اگر آپ کے کی بورڈ میں Print Screen کلید ہے ہی نہیں، تو `Super + Ctrl + Alt + C` وہی اسکرین شاٹ لیتا ہے، اور `Super + Ctrl + C` پورے سیٹ کو بطور مینو کھولتا ہے۔

| ہاٹ کی | فنکشن |
| ------ | -------- |
| `Print Screen` | اسکرین شاٹ |
| `Super + Ctrl + Alt + C` | اسکرین شاٹ |
| `Alt + Print Screen` | اسکرین ریکارڈ (یا چل رہی ریکارڈنگ روکیں) |
| `Super + Print Screen` | رنگ منتخب کرنے والا |
| `Super + Ctrl + Print Screen` | کسی حصے سے متن نکالیں |
| `Super + Ctrl + C` | کیپچر مینو |
| `Super + Ctrl + .` | تصویر یا ویڈیو کو ٹرانس کوڈ کریں |

## اسکرین شاٹس

`Print Screen` (یا `Super + Ctrl + Alt + C`) دبائیں اور Omasnap اپنے اوورلے کے ظاہر ہونے سے پہلے فوکس شدہ مانیٹر کو کیپچر کر لیتا ہے، لہٰذا جب آپ نشانہ باندھ رہے ہوں تو آپ کے نیچے کچھ بھی حرکت نہیں کرتا۔ آزادانہ حصہ گھسیٹ کر منتخب کریں، کیپچر کرنے کے لیے کسی ونڈو پر کلک کریں، یا پورا مانیٹر کیپچر کرنے کے لیے خالی جگہ پر کلک کریں۔ اسکرول کرنے والا حصہ کیپچر کرنے کے لیے ڈرائنگ سے پہلے `S` دبائیں۔ ارادہ بدل گیا؟ Omasnap کو بند کرنے کے لیے وہی کلید دوبارہ دبائیں۔

کسی حصے کو منتخب کرنے کے بعد، Omasnap کیپچر کو محفوظ کرتا ہے، اسے کلپ بورڈ پر کاپی کرتا ہے، اور اس کے تھمب نیل کے ساتھ ایک اطلاع دکھاتا ہے، بالکل اسی طرح جیسے محفوظ شدہ اسکرین ریکارڈنگ میں ہوتا ہے۔ محفوظ شدہ شاٹ کو اپنے امیج ویوئر میں دیکھنے کے لیے Open منتخب کریں، یا اس پر تشریح کرنے کے لیے Edit منتخب کریں۔

تشریحی ایڈیٹر تیر، لکیریں، شکلیں، نمایاں کاری، نمبر شدہ نشانات، متن، اور محفوظ ترمیمات بنا سکتا ہے؛ تصویر کے کسی حصے کو کاٹ یا تراش سکتا ہے؛ اس کے متن کو OCR کر سکتا ہے؛ اور پس منظر شامل کر سکتا ہے۔ ایڈیٹر میں، تیار PNG کو کاپی اور محفوظ کرنے کے لیے `Enter` دبائیں، محفوظ کیے بغیر کاپی کرنے کے لیے `Ctrl + C` دبائیں، یا کاپی کیے بغیر محفوظ کرنے کے لیے `Ctrl + S` دبائیں۔

محفوظ شدہ اسکرین شاٹس بطور ڈیفالٹ `~/Pictures/Screenshots` میں جاتے ہیں، ایسے نام کے ساتھ جیسے `screenshot-2026-08-13_14-22-05-firefox.png`۔ دوسری ڈائریکٹری استعمال کرنے کے لیے `OMASNAP_SCREENSHOT_DIR` سیٹ کریں — سیشن ماحول کے متغیرات کہاں رکھنے ہیں، اس کے لیے [اکثر پوچھے جانے والے سوالات](46-faq.md) دیکھیں۔ Omasnap پہلا شاٹ محفوظ کرتے وقت ڈائریکٹری بنا دیتا ہے۔ خودکار محفوظ کاری کو غیر فعال کرنے کے لیے `~/.config/omasnap/omasnap.conf` میں `[output] autosave = false` سیٹ کریں؛ پھر کیپچرز صرف کاپی ہوں گے، اور 10 سیکنڈ کے لیے ایک پیش منظر میں دکھائے جائیں گے جسے آپ اس کے پن بٹن یا `Ctrl + P` کے ذریعے اسکرین پر رکھ سکتے ہیں۔

ٹرمینل سے، `omarchy screenshot` وہی اوورلے کھولتا ہے، اور آپ اس کا ابتدائی موڈ منتخب کر سکتے ہیں: `omarchy capture screenshot region`، `windows`، `fullscreen`، یا `scroll`۔ `copy` یا `save` کی دوسری دلیل شاٹ کو سیدھا اسی منزل پر بھیج دیتی ہے۔ آؤٹ پٹ سے پہلے ترمیم کرنے کے لیے، فل اسکرین ایڈیٹر کے لیے `omarchy screenshot --editor=overlay` یا علیحدہ ونڈو کے لیے `omarchy screenshot --editor=window` استعمال کریں۔

### کی بورڈ سے پکر چلانا

جب انتخاب سامنے ہو، تو آپ کو ماؤس استعمال کرنے کی بالکل ضرورت نہیں:

| کلید | فنکشن |
| --- | -------- |
| `S` | اسکرولنگ ریجن موڈ کو ٹوگل کریں |
| `Super + Arrow keys` | Window موڈ میں ونڈوز کے درمیان حرکت کریں |
| `Return` | نمایاں ونڈو کو کیپچر کریں |
| `Ctrl + A` | پورا فوکس شدہ مانیٹر کیپچر کریں |
| `R` | اس سیشن میں آخری بنایا گیا حصہ بحال کریں |
| `Esc` | Omasnap بند کریں |

یہ بائنڈنگز صرف اس وقت موجود ہوتی ہیں جب Omasnap کھلا ہو، اس لیے یہ آپ کی اپنی ترتیب میں کسی بھی چیز سے ٹکرا نہیں سکتیں۔

## اسکرین ریکارڈنگ

`Alt + Print Screen` _Trigger > Capture > Screenrecord_ کھولتا ہے، جو پوچھتا ہے کہ آپ ساؤنڈ ٹریک پر کیا چاہتے ہیں: کوئی آڈیو نہیں، ڈیسک ٹاپ آڈیو، ڈیسک ٹاپ کے ساتھ مائیکروفون، یا ڈیسک ٹاپ کے ساتھ مائیکروفون کے ساتھ ویب کیم۔ یہ آخری والا صرف اسی وقت ظاہر ہوتا ہے اگر آپ کے پاس واقعی کیمرا لگا ہوا ہو۔ ایک منتخب کریں اور Omarchy کا ریکارڈنگ پکر آپ کو کوئی حصہ گھسیٹ کر منتخب کرنے یا کسی ونڈو یا مانیٹر پر کلک کرنے دیتا ہے۔

ریکارڈنگ gpu-screen-recorder پر چلتی ہے، جو GPU پر 60fps پر انکوڈ کرتی ہے اور مجبوراً ضرورت پڑنے پر CPU پر واپس آ جاتی ہے۔ نتیجہ `~/Videos` میں ایک MP4 ہوتا ہے، جس کا نام `screenrecording-2026-08-13_14-22-05.mp4` ہوتا ہے۔ اسے تبدیل کرنے کے لیے `OMARCHY_SCREENRECORD_DIR` سیٹ کریں — لیکن نوٹ کریں کہ اسکرین شاٹ ڈائریکٹری کے برعکس، یہ پہلے سے موجود ہونی چاہیے، ورنہ ریکارڈنگ شروع ہونے سے انکار کر دے گی۔

جب آپ ریکارڈنگ کر رہے ہوں، تو بار میں ایک چھوٹا سا اشارہ ظاہر ہوتا ہے۔ روکنے کے لیے اس پر کلک کریں۔ آپ `Alt + Print Screen` دوبارہ دبا کر بھی روک سکتے ہیں، یا _Trigger > Capture > Screenrecord_ کے تحت موجود _Stop Screenrecording_ اندراج کے ذریعے بھی، جو صرف اسی وقت ظاہر ہوتا ہے جب واقعی کچھ ریکارڈ ہو رہا ہو۔

روکنے سے پہلے فائل آپ کے حوالے کرنے سے قبل تھوڑی سی صفائی کی جاتی ہے: پہلا فریم تراش دیا جاتا ہے، اور اگر آڈیو ہو تو اسے -14 LUFS پر نارملائز کر دیا جاتا ہے اور بالکل شروع میں موجود PipeWire کیپچر کی پاپ آواز خاموش کر دی جاتی ہے۔ پھر ریکارڈنگ کے تھمب نیل کے ساتھ ایک اطلاع ظاہر ہوتی ہے۔ فائل کو mpv میں چلانے کے لیے اس پر کلک کریں۔

### ویب کیم اوورلے

جب آپ ویب کیم کے ساتھ ریکارڈ کرتے ہیں، تو کیمرا آپ کی ریکارڈنگ کے نیچے دائیں کونے میں پن شدہ، تراشی ہوئی پورٹریٹ ونڈو کے طور پر ظاہر ہوتا ہے۔ اگر یہ کسی ایسی چیز کے اوپر آ گیا ہو جس کی آپ کو ضرورت ہے، تو اسے فوری طور پر چھوٹا بڑا کریں:

| ہاٹ کی | فنکشن |
| ------ | -------- |
| `Super + Alt + [` | ویب کیم اوورلے کو چھوٹا کریں |
| `Super + Alt + ]` | ویب کیم اوورلے کو بڑا کریں |

تین سائز ہیں — چھوٹا، درمیانہ، اور بڑا — اور ہاٹ کیز ان کے درمیان قدم بہ قدم لے جاتی ہیں۔ درمیانہ بطور ڈیفالٹ ہے۔ یہ ریکارڈنگ کے متناسب ہیں، اس لیے کیمرا فریم کا اتنا ہی حصہ لیتا ہے چاہے آپ 1080p مانیٹر ریکارڈ کر رہے ہوں یا 6K مانیٹر۔ اور اگر آپ نے پوری ڈسپلے کے بجائے کوئی حصہ ریکارڈ کیا تھا، تو اوورلے مانیٹر کے کونے کے بجائے اس حصے کے کونے سے جڑتا ہے، اس لیے یہ شاٹ کے اندر ہی رہتا ہے۔

آپ اسے براہ راست `omarchy-capture-webcam-resize small` سے بھی کال کر سکتے ہیں، یا درمیانے پر واپس جانے کے لیے `reset` استعمال کر سکتے ہیں۔

## متن، QR کوڈز، اور رنگ

`Super + Ctrl + Print Screen` کوئی حصہ منتخب کرتا ہے اور اسے OCR کر کے کلپ بورڈ پر بھیج دیتا ہے۔ اس کا مناسب احاطہ [متن نکالنا اور ڈکٹیشن](11-text-extraction-dictation.md) میں کیا گیا ہے۔

_Trigger > Capture > QR Code_ QR کوڈز کے لیے وہی چال کرتا ہے۔ جس حصے میں کوڈ ہو اسے منتخب کریں، اور ڈی کوڈ شدہ قدر کلپ بورڈ پر چلی جاتی ہے۔ یہ صرف QR کوڈز تلاش کرتا ہے — ورنہ گھنی اسکرین مواد میں بارکوڈ کے طور پر غلط شناخت ہونے کی عادت ہوتی ہے۔ جاننا ضروری ہے: ڈی کوڈ شدہ قدر کلپ بورڈ پر جاتی ہے اور کہیں اور نہیں۔ یہ چھپتی نہیں، یہ اطلاع میں نہیں ہوتی، اور یہ حساس کے طور پر نشان زد ہوتی ہے تاکہ یہ [کلپ بورڈ ہسٹری](08-unified-clipboard-history.md) میں باقی نہ رہے۔ QR کوڈز معمول کے مطابق راز لے کر چلتے ہیں — مثال کے طور پر، 2FA سیٹ اپ کوڈ کے پیچھے موجود `otpauth://` URI — اور آپ نہیں چاہتے کہ یہ کسی لاگ میں جائے۔ پیسٹ کرنا پھر بھی بالکل ٹھیک کام کرتا ہے۔

`Super + Print Screen` (یا _Trigger > Capture > Color_) کرسر کو آئی ڈراپر میں بدل دیتا ہے۔ اسکرین پر کسی بھی چیز پر کلک کریں اور رنگ کلپ بورڈ پر آ جائے گا۔ منتخب کیے بغیر واپس آنے کے لیے ہاٹ کی دوبارہ دبائیں۔

## شیئر کرنے سے پہلے ٹرانس کوڈنگ

4K اسکرین ریکارڈنگ یا آپ کے فون سے لی گئی خام HEIC اکثر اتنی بڑی ہوتی ہے کہ اسے بس بھیج دیا جائے۔ `Super + Ctrl + .` (یا _Trigger > Transcode_) یہ ٹھیک کر دیتا ہے۔ یہ آپ کو `~/Pictures` اور `~/Videos` پر ایک مبہم فائل پکر پیش کرتا ہے، پھر فارمیٹ اور سائز پوچھتا ہے۔

تصاویر high، medium، یا low پر jpg یا png میں جاتی ہیں، جو چوڑائی کو بالترتیب 3160، 2160، اور 1080 پکسلز تک محدود کرتی ہیں۔ ویڈیوز 4k، 1080p، یا 720p پر mp4 یا متحرک gif میں جاتی ہیں۔ تبدیل شدہ فائل اصل کے ساتھ ہی لکھی جاتی ہے اور اس کے نام میں ریزولوشن شامل ہوتا ہے — `demo-1080p.mp4` — اور راستہ فائل URI کے طور پر کلپ بورڈ پر کاپی ہو جاتا ہے، تاکہ آپ اسے سیدھا کسی ایسی ایپ میں پیسٹ کر سکیں جو فائل ڈراپس لیتی ہو۔

یہ ٹرمینل سے بھی کام کرتا ہے، اگر آپ پہلے سے جانتے ہوں کہ آپ کو کیا چاہیے: `omarchy transcode ~/Videos/demo.mov mp4 1080p`۔ `omarchy transcode ascii` بھی ہے، جو تصویر کو ASCII آرٹ میں بدل دیتا ہے — یہ زیادہ تر [برانڈنگ](41-branding.md) کے لیے ہے۔
