# اسکرین شاٹس اور ریکارڈنگ

اسکرین سے جو کچھ بھی اٹھا سکتے ہیں، وہ سب Print Screen کی پر منحصر ہے۔ اکیلی یہ کی اپنے طور پر ایک تصویر لیتی ہے، اور موڈیفائرز ریکارڈنگ، کوئی رنگ، یا کسی حصے کے اندر موجود متن لیتے ہیں۔ اگر آپ کے کی بورڈ میں Print Screen کی بالکل موجود ہی نہیں، تو `Super + Ctrl + Alt + C` وہی اسکرین شاٹ لیتا ہے، اور `Super + Ctrl + C` پورا سیٹ ایک مینیو کے طور پر کھولتا ہے۔

| ہاٹ کی | کام |
| ------ | -------- |
| `Print Screen` | اسکرین شاٹ |
| `Super + Ctrl + Alt + C` | اسکرین شاٹ |
| `Alt + Print Screen` | اسکرین ریکارڈ (یا جو چل رہی ہے اسے روکیں) |
| `Super + Print Screen` | رنگ منتخب کرنے والا |
| `Super + Ctrl + Print Screen` | کسی حصے سے متن نکالیں |
| `Super + Ctrl + C` | کیپچر مینیو |
| `Super + Ctrl + .` | کسی تصویر یا ویڈیو کو ٹرانس کوڈ کریں |

## اسکرین شاٹس

`Print Screen` (یا `Super + Ctrl + Alt + C`) دبائیں اور Omasnap اپنے اوورلے کے ظاہر ہونے سے پہلے فوکس شدہ مانیٹر کو کیپچر کر لیتا ہے، اس لیے نشانہ باندھتے وقت آپ کے نیچے کچھ بھی حرکت نہیں کرتا۔ آزادانہ انداز میں کوئی حصہ گھسیٹ کر بنائیں، کسی ونڈو پر کلک کر کے اسے کیپچر کریں، یا خالی جگہ پر کلک کر کے پورا مانیٹر کیپچر کریں۔ کھینچنے سے پہلے `S` دبائیں تا کہ اسکرولنگ حصہ کیپچر ہو۔ خیال بدل گیا؟ Omasnap کو ختم کرنے کے لیے وہی کی دوبارہ دبائیں۔

حصہ منتخب کرنے کے بعد، Omasnap کیپچر کو محفوظ کرتا ہے، اسے کلپ بورڈ پر کاپی کرتا ہے، اور 10 سیکنڈ کے لیے ایک پیش منظر دکھاتا ہے۔ اسے اسکرین پر برقرار رکھنے کے لیے پیش منظر کا پن بٹن یا `Ctrl + P` استعمال کریں، یا اس پر تشریحات لگانے کے لیے Edit منتخب کریں۔

تشریحی ایڈیٹر تیر، لکیریں، شکلیں، نمایاں کاریاں، نمبر والے نشانات، متن، اور محفوظ اخفاء بنا سکتا ہے؛ تصویر کے کسی حصے کو تراش یا کاٹ سکتا ہے؛ اس کے متن کو OCR کر سکتا ہے؛ اور ایک پس منظر شامل کر سکتا ہے۔ ایڈیٹر میں، مکمل PNG کاپی اور محفوظ کرنے کے لیے `Enter` دبائیں، محفوظ کیے بغیر کاپی کرنے کے لیے `Ctrl + C` دبائیں، یا کاپی کیے بغیر محفوظ کرنے کے لیے `Ctrl + S` دبائیں۔

محفوظ شدہ اسکرین شاٹس بطور ڈیفالٹ `~/Pictures/Screenshots` میں جاتے ہیں، ایسے نام کے ساتھ جیسے `screenshot-2026-08-13_14-22-05-firefox.png`۔ کوئی اور ڈائریکٹری استعمال کرنے کے لیے `OMASNAP_SCREENSHOT_DIR` مقرر کریں — سیشن کے ماحولیاتی متغیرات کہاں رکھنے ہیں، اس کے لیے [اکثر پوچھے گئے سوالات](46-faq.md) دیکھیں۔ Omasnap پہلا شاٹ محفوظ کرتے وقت ڈائریکٹری بنا دیتا ہے۔ خودکار محفوظ کاری غیر فعال کرنے کے لیے `~/.config/omasnap/omasnap.conf` میں `[output] autosave = false` مقرر کریں۔

ٹرمینل سے، `omarchy screenshot` وہی اوورلے کھولتا ہے، اور آپ اس کا ابتدائی موڈ منتخب کر سکتے ہیں: `omarchy capture screenshot region`، `windows`، `fullscreen`، یا `scroll`۔ `copy` یا `save` کی دوسری دلیل پیش منظر کو چھوڑ دیتی ہے اور شاٹ کو سیدھا اس منزل تک بھیج دیتی ہے۔ آؤٹ پٹ سے پہلے ترمیم کرنے کے لیے، فل اسکرین ایڈیٹر کے لیے `omarchy screenshot --editor=overlay` یا الگ ونڈو کے لیے `omarchy screenshot --editor=window` استعمال کریں۔

### کی بورڈ سے پکر چلانا

جب سلیکشن کھلا ہو، تو آپ کو ماؤس بالکل بھی استعمال نہیں کرنا پڑتا:

| کی | کام |
| --- | -------- |
| `S` | اسکرولنگ حصے کا موڈ ٹوگل کریں |
| `Super + Arrow keys` | Window موڈ میں ونڈوز کے درمیان حرکت کریں |
| `Return` | نمایاں ونڈو کو کیپچر کریں |
| `Ctrl + A` | پورا فوکس شدہ مانیٹر کیپچر کریں |
| `R` | اس سیشن میں آخری بار بنایا گیا حصہ بحال کریں |
| `Esc` | Omasnap کو ختم کریں |

یہ بائنڈنگز صرف اسی وقت موجود ہوتی ہیں جب Omasnap کھلا ہو، اس لیے یہ آپ کی اپنی کنفیگ میں کسی بھی چیز سے ٹکرا نہیں سکتیں۔

## اسکرین ریکارڈنگ

`Alt + Print Screen` _Trigger > Capture > Screenrecord_ کھولتا ہے، جو پوچھتا ہے کہ آپ ساؤنڈ ٹریک پر کیا چاہتے ہیں: کوئی آڈیو نہیں، ڈیسک ٹاپ آڈیو، ڈیسک ٹاپ کے ساتھ مائیکروفون، یا ڈیسک ٹاپ کے ساتھ مائیکروفون اور ویب کیم۔ آخری والا صرف تبھی ظاہر ہوتا ہے جب واقعی آپ کے پاس کیمرہ لگا ہوا ہو۔ ایک منتخب کریں اور Omarchy کا ریکارڈنگ پکر آپ کو کوئی حصہ گھسیٹنے یا کسی ونڈو یا مانیٹر پر کلک کرنے دیتا ہے۔

ریکارڈنگ gpu-screen-recorder پر چلتی ہے، جو GPU پر 60fps پر انکوڈ کرتا ہے اور اگر اسے کرنا پڑے تو CPU پر واپس آ جاتا ہے۔ نتیجہ `~/Videos` میں ایک MP4 ہوتا ہے، جس کا نام `screenrecording-2026-08-13_14-22-05.mp4` ہوتا ہے۔ اسے بدلنے کے لیے `OMARCHY_SCREENRECORD_DIR` مقرر کریں — لیکن نوٹ کریں کہ اسکرین شاٹ ڈائریکٹری کے برعکس، اس کا پہلے سے موجود ہونا ضروری ہے، ورنہ ریکارڈنگ شروع ہونے سے انکار کر دے گی۔

جب آپ ریکارڈ کر رہے ہوں، تو بار میں ایک چھوٹا سا اشارہ ظاہر ہوتا ہے۔ اسے روکنے کے لیے اس پر کلک کریں۔ آپ اسے دوبارہ `Alt + Print Screen` سے بھی روک سکتے ہیں، یا _Trigger > Capture > Screenrecord_ کے تحت _Stop Screenrecording_ اندراج سے بھی، جو صرف اسی وقت ظاہر ہوتا ہے جب واقعی کچھ ریکارڈ ہو رہا ہو۔

روکنے پر فائل آپ کے حوالے کرنے سے پہلے تھوڑی سی صفائی کی جاتی ہے: پہلا فریم تراش دیا جاتا ہے، اور اگر آڈیو موجود ہو تو اسے -14 LUFS پر نارملائز کیا جاتا ہے اور بالکل شروع میں موجود PipeWire کیپچر پاپ کو خاموش کر دیا جاتا ہے۔ پھر ریکارڈنگ کے ایک تھمب نیل کے ساتھ ایک اطلاع ظاہر ہوتی ہے۔ فائل کو mpv میں چلانے کے لیے اس پر کلک کریں۔

### ویب کیم اوورلے

جب آپ ویب کیم کے ساتھ ریکارڈ کرتے ہیں، تو کیمرہ جس چیز کو بھی آپ ریکارڈ کر رہے ہوں اس کے نیچے دائیں کونے میں ایک پن شدہ، تراشی ہوئی پورٹریٹ ونڈو کے طور پر ظاہر ہوتا ہے۔ اگر یہ کسی ایسی چیز کے اوپر بیٹھا ہے جس کی آپ کو ضرورت ہے، تو اس کا سائز موقع پر ہی بدلیں:

| ہاٹ کی | کام |
| ------ | -------- |
| `Super + Alt + [` | ویب کیم اوورلے کو چھوٹا کریں |
| `Super + Alt + ]` | ویب کیم اوورلے کو بڑا کریں |

تین سائز ہیں — چھوٹا، درمیانہ، اور بڑا — اور ہاٹ کیز ان کے درمیان قدم بہ قدم بڑھتی ہیں۔ درمیانہ بطور ڈیفالٹ ہے۔ یہ ریکارڈنگ کے متناسب ہیں، اس لیے کیمرہ فریم کا اتنا ہی حصہ لیتا ہے چاہے آپ 1080p مانیٹر ریکارڈ کر رہے ہوں یا 6K مانیٹر۔ اور اگر آپ نے پورے ڈسپلے کے بجائے کوئی حصہ ریکارڈ کیا ہے، تو اوورلے مانیٹر کے کونے کے بجائے اس حصے کے کونے سے جڑتا ہے، اس لیے یہ شاٹ کے اندر ہی رہتا ہے۔

آپ اسے براہ راست `omarchy-capture-webcam-resize small` سے بھی بلا سکتے ہیں، یا درمیانے پر واپس جانے کے لیے `reset` استعمال کر سکتے ہیں۔

## متن، QR کوڈز، اور رنگ

`Super + Ctrl + Print Screen` کوئی حصہ منتخب کرتا ہے اور اسے OCR کر کے کلپ بورڈ پر بھیج دیتا ہے۔ اس کا مناسب احاطہ [متن نکالنا اور ڈکٹیشن](11-text-extraction-dictation.md) میں کیا گیا ہے۔

_Trigger > Capture > QR Code_ QR کوڈز کے لیے یہی چال چلتا ہے۔ کوڈ والے حصے کو منتخب کریں، اور ڈی کوڈ شدہ قدر کلپ بورڈ پر چلی جاتی ہے۔ یہ صرف QR کوڈز ہی تلاش کرتا ہے — ورنہ گھنے اسکرین مواد کی عادت ہے کہ وہ بارکوڈ کے طور پر غلط مثبت نتیجہ دے دیتا ہے۔ یہ جاننا مفید ہے: ڈی کوڈ شدہ قدر کلپ بورڈ پر جاتی ہے اور کہیں اور نہیں۔ یہ چھاپی نہیں جاتی، یہ اطلاع میں نہیں ہوتی، اور یہ حساس کے طور پر نشان زد ہوتی ہے تاکہ یہ [کلپ بورڈ ہسٹری](08-unified-clipboard-history.md) میں ٹکی نہ رہے۔ QR کوڈز معمول کے مطابق راز اٹھائے پھرتے ہیں — مثال کے طور پر 2FA سیٹ اپ کوڈ کے پیچھے موجود `otpauth://` URI — اور آپ نہیں چاہتے کہ یہ کسی لاگ میں پڑا ہو۔ پیسٹ کرنا پھر بھی بالکل ٹھیک کام کرتا ہے۔

`Super + Print Screen` (یا _Trigger > Capture > Color_) کرسر کو آئی ڈراپر میں بدل دیتا ہے۔ اسکرین پر کسی بھی چیز پر کلک کریں اور رنگ کلپ بورڈ پر آ جاتا ہے۔ منتخب کیے بغیر واپس جانے کے لیے ہاٹ کی دوبارہ دبائیں۔

## شیئر کرنے سے پہلے ٹرانس کوڈنگ

4K اسکرین ریکارڈنگ یا آپ کے فون سے آئی ہوئی خام HEIC اکثر اتنی بڑی ہوتی ہے کہ اسے بس بھیج دیا جائے۔ `Super + Ctrl + .` (یا _Trigger > Transcode_) یہ درست کرتا ہے۔ یہ آپ کو `~/Pictures` اور `~/Videos` پر ایک فزی فائل پکر پیش کرتا ہے، پھر ایک فارمیٹ اور ایک سائز پوچھتا ہے۔

تصاویر jpg یا png میں اعلیٰ، درمیانی، یا کم درجے پر جاتی ہیں، جو چوڑائی کو 3160، 2160، اور 1080 پکسلز تک محدود کرتے ہیں۔ ویڈیوز mp4 یا متحرک gif میں 4k، 1080p، یا 720p پر جاتی ہیں۔ تبدیل شدہ فائل اصل کے ساتھ ہی لکھی جاتی ہے اور اس کے نام میں ریزولوشن شامل ہوتا ہے — `demo-1080p.mp4` — اور راستہ ایک فائل URI کے طور پر کلپ بورڈ پر کاپی ہو جاتا ہے، اس لیے آپ اسے براہ راست کسی ایسی ایپ میں پیسٹ کر سکتے ہیں جو فائل ڈراپس لیتی ہو۔

یہ ٹرمینل سے بھی کام کرتا ہے، اگر آپ پہلے سے جانتے ہیں کہ آپ کیا چاہتے ہیں: `omarchy transcode ~/Videos/demo.mov mp4 1080p`۔ `omarchy transcode ascii` بھی ہے، جو کسی تصویر کو ASCII آرٹ میں بدل دیتا ہے — یہ زیادہ تر [برانڈنگ](41-branding.md) کے لیے ہے۔
