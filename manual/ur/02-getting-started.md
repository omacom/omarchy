# شروعات

Omarchy ایک ISO کے ذریعے انسٹال کیا جاتا ہے۔ آپ فل ڈسک انسٹال کے درمیان انتخاب کر سکتے ہیں، جو پوری ڈرائیو پر قبضہ کر لیتا ہے، یا فری اسپیس انسٹال، جو Omarchy کو ڈرائیو کی غیر مختص شدہ جگہ میں رکھتا ہے — اسی طرح آپ Windows یا کسی دوسرے OS کے ساتھ ڈوئل بوٹ کرتے ہیں (دیکھیں [ڈوئل بوٹ انسٹال](50-dual-boot-install.md) — نوٹ کریں کہ آپ کو پہلے Windows میں BitLocker بند کرنا ہوگا)۔ دونوں صورتوں میں، انسٹالیشن بطور ڈیفالٹ مکمل انکرپشن کے ساتھ ہوتی ہے، اور فل ڈسک آپشن منتخب ڈرائیو کو صاف کر دے گا، لہٰذا موجودہ ڈرائیو استعمال کرنے سے پہلے بیک اپ ضرور لے لیں!

پہلے [Omarchy ISO ڈاؤن لوڈ کریں](https://omarchy.org/)، اسے USB اسٹک پر ڈالیں (Windows پر [Rufus](https://rufus.ie/)، Mac پر [balenaEtcher](https://etcher.balena.io/)، یا Linux پر [caligula](https://github.com/ifd3f/caligula) استعمال کریں)، اور اسٹک سے بوٹ کریں۔

_آپ کو BIOS میں Secure Boot اور/یا TPM بند کرنا ہوگا۔ Omarchy انسٹال کرنے کے قابل ہونے کے لیے آپ کو یہ بند کرنے ہوں گے۔ یہ Microsoft کی سیکیورٹی اسکیمیں ہیں جو Windows اور Microsoft سے وابستہ Linux ڈسٹری بیوشنز کے لیے بنائی گئی ہیں۔_

پھر کنفیگریشن کے سوالات کے جواب دیں، اور ان کی اس طرح تصدیق کریں:

 ![install-config](images/install-config.webp)

پھر اپنی انسٹالیشن کے لیے ایک ڈرائیو منتخب کریں، اور آرام سے بیٹھ کر انسٹالیشن کا شو دیکھیں۔ تیز ترین جدید مشینوں پر یہ ایک منٹ سے بھی کم میں مکمل ہو سکتا ہے، لیکن پرانے کمپیوٹر پر بھی اسے 5 منٹ سے زیادہ نہیں لگنے چاہئیں۔

اب آپ Omarchy کے لیے تیار ہیں!

### وائرڈ یا 2.4ghz کی بورڈ استعمال کریں!

فل ڈسک انکرپشن آپ کو اسٹارٹ اپ پر Bluetooth کی بورڈ سے پاس ورڈ درج نہیں کرنے دے گی۔ بالکل اسی طرح جیسے آپ PC پر BIOS میں داخل ہونے کے لیے Bluetooth کی بورڈ استعمال نہیں کر سکتے۔ آپ کو ایسا کی بورڈ چاہیے ہوگا جو یا تو 2.4ghz ڈونگل استعمال کرے یا کیبل والا ہو (جو ویسے بھی لیٹنسی کے لیے بہت بہتر ہے!)۔ مجھے ذاتی طور پر [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard) بہت پسند ہے!

### کسی دوسرے مالک کے لیے انسٹال کرنا

اگر آپ کسی اور کے لیے مشین سیٹ اپ کر رہے ہیں — خاندان کا کوئی فرد، کوئی نیا ملازم، کوئی خریدار — تو آپ کو ان کی طرف سے ذاتی سوالات کے جواب نہیں دینے چاہئیں۔ انسٹالر کی بالکل پہلی اسکرین (کی بورڈ کا انتخاب) پر `Ctrl + C` دبائیں، اور Omarchy اس کے بجائے مشین کو کسی دوسرے مالک کے لیے تیار کرنے کی پیشکش کرے گا۔ سسٹم فوراً انسٹال ہو جاتا ہے، لیکن تمام ذاتی سیٹ اپ — کی بورڈ لے آؤٹ، صارف نام، پاس ورڈ — اس وقت تک مؤخر کر دیا جاتا ہے جب تک مشین پہلی بار بوٹ نہ ہو۔ ڈرائیو بطور ڈیفالٹ پھر بھی انکرپٹڈ رہتی ہے، اور نیا مالک اس پہلے بوٹ پر جو پاس ورڈ منتخب کرتا ہے وہی انکرپشن پاس ورڈ بھی بن جاتا ہے۔ (جس مشین کو آپ پہلے سے استعمال کر رہے ہیں اسے بھی دوبارہ انسٹال کیے بغیر حوالے کیا جا سکتا ہے — دیکھیں [کمپیوٹر ری سیٹ کرنا](48-security.md)۔)

### غیر نگرانی شدہ انسٹالز

ISO مکمل طور پر خود بھی انسٹال ہو سکتا ہے — نہ کی بورڈ، نہ وزرڈ — جب اسے دوسری ڈرائیو پر اس کی کنفیگریشن فراہم کر دی جائے۔ VMs اور فلیٹ مشینوں کے لیے Omarchy کو بیس امیج کے طور پر استعمال کرنے کا یہی طریقہ ہے۔ دیکھیں [غیر نگرانی شدہ انسٹالز](51-unattended-installs.md)۔

### انکرپشن کے بغیر انسٹالیشنز

Omarchy بطور ڈیفالٹ انکرپشن کے ساتھ انسٹال ہوتا ہے۔ کسی بھی ایسے کمپیوٹر کے لیے جو ممکنہ طور پر گم ہو سکتا ہے یا چوری ہو سکتا ہے، یہ محفوظ اور ذمہ دارانہ انتخاب ہے۔ آپ نہیں چاہتے کہ آپ کے ہارڈ ویئر تک رسائی رکھنے والا کوئی بھی شخص آپ کا ڈیٹا حاصل کر سکے!

لیکن خاص حالات میں، جیسے محفوظ کمپیوٹرز پر ریموٹ Omarchy انسٹالز یا حساس ڈیٹا کے بغیر عارضی انسٹالیشنز کے لیے، آپ انکرپشن کے بغیر انسٹال کرنا چاہ سکتے ہیں۔ آپ انکرپشن کے بغیر انسٹالیشن پر سوئچ کرنے کے لیے ڈسک فارمیٹنگ کی تصدیق پر `Ctrl + C` دبا سکتے ہیں۔

### زبان

Omarchy 50 زبانیں بولتا ہے — omarchy.org جیسی ہی سیٹ — اور انگریزی ڈیفالٹ ہے۔ تبدیل کرنے کے لیے، Omarchy مینو کھولیں اور _Setup > Language_ پر جائیں، یا ٹرمینل میں `omarchy language <code>` چلائیں (`omarchy language list` کوڈز دکھاتا ہے)۔ مینو، ڈیسک ٹاپ، اور Omarchy کی اپنی اطلاعات فوراً زبان بدل لیتی ہیں، اور اس کے بعد آپ جو بھی ایپلیکیشن کھولتے ہیں وہ بھی اسی کی پیروی کرتی ہے۔ جو ایپس پہلے سے کھلی تھیں وہ آپ کے انہیں دوبارہ شروع کرنے پر بدل جاتی ہیں۔

اگر آپ پھنس جائیں، تو آپ کو عام طور پر [کمیونٹی Discord](https://omarchy.org/discord) پر _#omarchy-help_ چینل میں مدد کے لیے تیار کوئی نہ کوئی مل جائے گا۔
