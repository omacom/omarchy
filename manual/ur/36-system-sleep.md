# سسٹم سلیپ

Omarchy پہلے سے طے شدہ طور پر سسپینڈ فعال کرتا ہے، اور ہائبرنیشن کو اس کے سیٹ اپ ہونے کے بعد، لیکن اگر آپ کی مشین پر آپ کو ان میں سے کسی کے ساتھ بھی مسائل ہوں تو آپ انہیں بند کر سکتے ہیں۔

NVIDIA GB10 مشینوں پر، جیسے DGX Spark اور ASUS Ascent GX10، سسپینڈ اور ہائبرنیشن بند ہوتے ہیں، جیسا کہ NVIDIA کے DGX OS میں بھی ہوتا ہے، کیونکہ اس ہارڈویئر پر سلیپ کا ابھی تک کام کرنا ثابت نہیں ہوا۔ یہی بات ASUS Zenbook A16 (UX3607OA) پر بھی لاگو ہوتی ہے، جہاں سسپینڈ ابھی چپ کو پوری طرح سلاتا نہیں ہے اور رات بھر میں ہینگ ہو سکتا ہے۔ وہاں سسپینڈ ٹوگل اور ہائبرنیشن سیٹ اپ لاگو نہیں ہوتے۔ سلیپ کو دوبارہ آن کرنے کے لیے، `sudo rm` کے ساتھ `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf` کو ہٹا دیں؛ پھر Suspend مینیو میں واپس آ جائے گا، اور ہائبرنیشن کو دوسری مشینوں کی طرح سیٹ اپ کیا جا سکتا ہے۔ `sudo omarchy apply hardware --install-user "$USER"` چلانے سے فائل واپس آ جاتی ہے۔

### پاور پروفائلز

لیپ ٹاپ پر، Omarchy آپ کے پاور پروفائل کو پلگ ان ہونے اور بیٹری پر چلنے کے لیے الگ الگ یاد رکھتا ہے، اور جب آپ پلگ لگاتے اور نکالتے ہیں تو ان دونوں کے درمیان سوئچ کرتا ہے۔ باکس سے نکلتے ہی اس کا مطلب ہے AC پر performance اور بیٹری پر balanced۔

آپ `omarchy powerprofiles list` کے ساتھ دیکھ سکتے ہیں کہ آپ کی مشین کیا پیش کرتی ہے، اور `omarchy powerprofiles set autodetect power-saver` کے ساتھ اس حالت کے لیے، جس میں آپ اس وقت ہیں، اپنی پسند کا پروفائل سیٹ کر سکتے ہیں۔ بغیر کچھ ان پلگ کیے دوسری حالت کو سیٹ کرنے کے لیے، اسے براہ راست نام سے بتائیں: `omarchy powerprofiles set battery power-saver`۔ آپ جو بھی منتخب کریں گے، اگلی بار اس حالت میں ہونے پر آپ کو وہی واپس ملے گا۔

### سسپینڈ ٹوگل کریں

آپ ٹرمینل سے `omarchy toggle suspend` چلا کر سسپینڈ کو ٹوگل کرتے ہیں۔ یہ صرف _System_ کے تحت (یا `Super + Esc`) آپشن کو ظاہر/چھپاتا ہے، اور پھر آپ دیکھ سکتے ہیں کہ آیا یہ آپ کے سسٹم پر مستقل طور پر کام کرتا ہے۔ اگر نہیں، تو آپ اسی کمانڈ کے ساتھ اسے دوبارہ چھپا سکتے ہیں۔

### ہائبرنیشن ٹوگل کریں

آپ ٹرمینل سے `omarchy hibernation setup` چلا کر ہائبرنیشن سیٹ اپ کرتے ہیں (یہ Apple Silicon Macs پر دستیاب نہیں ہے)۔ ہائبرنیشن آپ کی بوٹ ڈرائیو پر آپ کی فزیکل RAM کی مختص مقدار کے سائز کا ایک /swap سب والیوم بناتا ہے، اس لیے یقینی بنائیں کہ آپ کے پاس کافی جگہ خالی ہو۔ 32GB مشین پر، آپ کو اس والیوم کے لیے ہمیشہ 32GB+ جگہ خالی درکار ہوگی۔ ہائبرنیشن کے لیے پہلے سے طے شدہ Limine bootloader بھی درکار ہے۔

سیٹ اپ ہونے پر، آپ کو _System_ کے تحت (یا `Super + Esc`) ہائبرنیٹ کا آپشن نظر آئے گا، اور پھر آپ دیکھ سکتے ہیں کہ آیا یہ آپ کے سسٹم پر مستقل طور پر کام کرتا ہے۔ اگر نہیں، تو آپ `omarchy hibernation remove` چلا کر اسے دوبارہ ہٹا سکتے ہیں۔
