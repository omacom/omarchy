# سسٹم نیند

Omarchy طے شدہ طور پر معطلی اور ہائبرنیشن فعال کرتا ہے، لیکن اگر آپ کی مشین پر ان میں سے کسی کے ساتھ مسائل ہیں تو آپ انہیں آف کر سکتے ہیں۔

### پاور پروفائل

لیپ ٹاپ پر، Omarchy آپ کے لیے پلگ لگے ہونے اور بیٹری پر چلنے کے پاور پروفائل الگ الگ یاد رکھتا ہے، اور پلگ لگانے اور ہٹانے پر ان دونوں کے درمیان بدل جاتا ہے۔ فوری طور پر اس کا مطلب AC پر کارکردگی اور بیٹری پر متوازن ہے۔

آپ `omarchy powerprofiles list` کے ساتھ دیکھ سکتے ہیں کہ آپ کی مشین کیا پیش کرتی ہے، اور جس حالت میں آپ اس وقت ہیں اس کے لیے مطلوبہ پروفائل `omarchy powerprofiles set autodetect power-saver` سے لگا سکتے ہیں۔ بغیر کچھ ان پلگ کیے دوسری حالت لگانے کے لیے، اسے براہ راست نام دیں: `omarchy powerprofiles set battery power-saver`۔ آپ جو بھی چنتے ہیں، اگلی بار جب آپ اس حالت میں ہوں گے تو آپ کو وہی واپس ملے گا۔

### معطلی ٹوگل کریں

آپ ٹرمینل سے `omarchy toggle suspend` چلا کر معطلی ٹوگل کرتے ہیں۔ یہ صرف _سسٹم_ کے تحت (یا `Super + Esc` سے) آپشن کو ظاہر/چھپا کرتا ہے، اور پھر آپ دیکھ سکتے ہیں کہ یہ آپ کے سسٹم پر مسلسل کام کرتا ہے یا نہیں۔ اگر نہیں تو آپ اسی کمانڈ سے اسے دوبارہ چھپا سکتے ہیں۔

### ہائبرنیشن ٹوگل کریں

آپ ٹرمینل سے `omarchy hibernation setup` چلا کر ہائبرنیشن سیٹ اپ کرتے ہیں۔ ہائبرنیشن آپ کی بوٹ ڈرائیو پر آپ کی جسمانی RAM مختص مقدار کے سائز کا ایک /swap سب والیوم بناتی ہے، لہٰذا اس بات کو یقینی بنائیں کہ آپ کے پاس کافی جگہ بچائے رکھنے کے لیے موجود ہو۔ 32GB والی مشین پر، آپ کو اس والیوم کے لیے ہمیشہ 32GB+ خالی درکار ہو گی۔ ہائبرنیشن کے لیے طے شدہ Limine بوٹ لوڈر بھی درکار ہے۔

جب سیٹ اپ ہو جائے گا تو آپ کو _سسٹم_ کے تحت (یا `Super + Esc` سے) ہائبرنیٹ آپشن نظر آئے گا، اور پھر آپ دیکھ سکتے ہیں کہ یہ آپ کے سسٹم پر مسلسل کام کرتا ہے یا نہیں۔ اگر نہیں تو آپ `omarchy hibernation remove` چلا کر اسے دوبارہ ہٹا سکتے ہیں۔
