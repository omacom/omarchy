# سسٹم سلیپ

Omarchy بطور ڈیفالٹ سسپینڈ اور ہائبرنیشن کو فعال کرتا ہے، لیکن اگر آپ کو اپنی مشین پر ان میں سے کسی کے ساتھ مسائل درپیش ہیں تو آپ انہیں بند کر سکتے ہیں۔

NVIDIA GB10 مشینوں پر، جیسے کہ DGX Spark اور ASUS Ascent GX10، سسپینڈ اور ہائبرنیشن بند ہوتے ہیں، جیسا کہ NVIDIA کے DGX OS میں ہوتا ہے، کیونکہ اس ہارڈویئر پر سلیپ کا ٹھیک سے کام کرنا ابھی ثابت نہیں ہوا ہے۔ یہی حال ASUS Zenbook A16 (UX3607OA) کا ہے، جہاں سسپینڈ ابھی چپ کو مکمل طور پر سلیپ میں نہیں ڈالتا اور رات بھر میں ہینگ ہو سکتا ہے۔ وہاں سسپینڈ ٹوگل اور ہائبرنیشن سیٹ اپ لاگو نہیں ہوتے۔ سلیپ کو دوبارہ آن کرنے کے لیے، `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf` کو `sudo rm` کے ساتھ ہٹا دیں؛ اس کے بعد Suspend مینیو میں واپس آ جائے گا، اور ہائبرنیشن کو دوسری مشینوں کی طرح سیٹ اپ کیا جا سکتا ہے۔ `sudo omarchy apply hardware --install-user "$USER"` چلانے سے فائل واپس آ جاتی ہے۔

### پاور پروفائلز

لیپ ٹاپ پر، Omarchy آپ کے پاور پروفائل کو پلگ ان ہونے اور بیٹری پر چلنے کے لیے الگ الگ یاد رکھتا ہے، اور جب آپ پلگ لگاتے اور نکالتے ہیں تو ان دونوں کے درمیان سوئچ کرتا رہتا ہے۔ بکس سے باہر اس کا مطلب ہے AC پر performance اور بیٹری پر balanced۔

آپ دیکھ سکتے ہیں کہ آپ کی مشین کیا پیش کرتی ہے `omarchy powerprofiles list` کے ساتھ، اور جس حالت میں آپ اس وقت ہیں اس کے لیے اپنی پسند کا پروفائل `omarchy powerprofiles set autodetect power-saver` کے ساتھ سیٹ کر سکتے ہیں۔ بغیر کچھ ان پلگ کیے دوسری حالت کو سیٹ کرنے کے لیے، اسے براہ راست نام دیں: `omarchy powerprofiles set battery power-saver`۔ آپ جو بھی منتخب کریں گے، اگلی بار جب آپ اس حالت میں ہوں گے تو آپ کو وہی واپس ملے گا۔

### سسپینڈ کو ٹوگل کریں

آپ ٹرمینل سے `omarchy toggle suspend` چلا کر سسپینڈ کو ٹوگل کرتے ہیں۔ یہ صرف _System_ (یا `Super + Esc`) کے تحت آپشن کو ظاہر/چھپاتا ہے، اور پھر آپ دیکھ سکتے ہیں کہ آیا یہ آپ کے سسٹم پر مستقل طور پر کام کرتا ہے۔ اگر نہیں، تو آپ اسی کمانڈ کے ساتھ اسے دوبارہ چھپا سکتے ہیں۔

### ہائبرنیشن کو ٹوگل کریں

آپ ٹرمینل سے `omarchy hibernation setup` چلا کر ہائبرنیشن سیٹ اپ کرتے ہیں۔ ہائبرنیشن آپ کی بوٹ ڈرائیو پر آپ کی فزیکل RAM مختص کے سائز کا ایک /swap سب والیوم بناتا ہے، اس لیے یقینی بنائیں کہ آپ کے پاس کافی جگہ خالی ہے۔ 32GB مشین پر، آپ کو اس والیوم کے لیے ہمیشہ 32GB+ خالی جگہ درکار ہوگی۔ ہائبرنیشن کے لیے ڈیفالٹ Limine بوٹ لوڈر بھی درکار ہے۔

سیٹ اپ ہو جانے پر، آپ کو _System_ (یا `Super + Esc`) کے تحت ہائبرنیٹ کا آپشن نظر آئے گا، اور پھر آپ دیکھ سکتے ہیں کہ آیا یہ آپ کے سسٹم پر مستقل طور پر کام کرتا ہے۔ اگر نہیں، تو آپ `omarchy hibernation remove` چلا کر اسے دوبارہ ہٹا سکتے ہیں۔
