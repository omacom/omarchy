# سسٹم سلیپ

Omarchy بطور ڈیفالٹ سسپینڈ اور ہائبرنیشن کو فعال کرتا ہے، لیکن اگر آپ کو اپنی مشین پر ان میں سے کسی کے ساتھ مسائل درپیش ہیں تو آپ انہیں بند کر سکتے ہیں۔

NVIDIA GB10 مشینوں پر، جیسے DGX Spark اور ASUS Ascent GX10، سسپینڈ اور ہائبرنیشن بند ہوتے ہیں، جیسا کہ NVIDIA کے DGX OS میں بھی ہوتا ہے، کیونکہ اس ہارڈویئر پر سلیپ کے کام کرنے کا ابھی مظاہرہ نہیں ہوا ہے۔ وہاں سسپینڈ ٹوگل اور ہائبرنیشن سیٹ اپ لاگو نہیں ہوتے۔ سلیپ کو دوبارہ آن کرنے کے لیے، `sudo rm` کے ساتھ `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf` کو حذف کر دیں؛ پھر سسپینڈ مینو میں واپس آ جائے گا، اور ہائبرنیشن کو دیگر مشینوں کی طرح سیٹ اپ کیا جا سکتا ہے۔ `sudo omarchy apply hardware --install-user "$USER"` چلانے سے فائل واپس آ جاتی ہے۔

### پاور پروفائلز

لیپ ٹاپ پر، Omarchy آپ کے پاور پروفائل کو پلگ ان ہونے اور بیٹری پر چلنے کے لیے الگ الگ یاد رکھتا ہے، اور پلگ لگانے اور نکالنے پر دونوں کے درمیان سوئچ کرتا رہتا ہے۔ شروع سے ہی اس کا مطلب ہے AC پر performance اور بیٹری پر balanced۔

آپ `omarchy powerprofiles list` کے ساتھ دیکھ سکتے ہیں کہ آپ کی مشین کیا پیش کرتی ہے، اور `omarchy powerprofiles set autodetect power-saver` کے ساتھ اس حالت کے لیے مطلوبہ پروفائل سیٹ کر سکتے ہیں جس میں آپ اس وقت ہیں۔ کچھ بھی ان پلگ کیے بغیر دوسری حالت سیٹ کرنے کے لیے، اسے براہ راست نام دیں: `omarchy powerprofiles set battery power-saver`۔ آپ جو بھی منتخب کریں گے، اگلی بار اسی حالت میں ہونے پر آپ کو وہی واپس ملے گا۔

### سسپینڈ کو ٹوگل کریں

آپ ٹرمینل سے `omarchy toggle suspend` چلا کر سسپینڈ کو ٹوگل کرتے ہیں۔ یہ صرف _سسٹم_ (یا `Super + Esc`) کے تحت آپشن کو ظاہر/چھپاتا ہے، اور پھر آپ دیکھ سکتے ہیں کہ آیا یہ آپ کے سسٹم پر مستقل طور پر کام کرتا ہے۔ اگر نہیں، تو آپ اسی کمانڈ کے ساتھ اسے دوبارہ چھپا سکتے ہیں۔

### ہائبرنیشن کو ٹوگل کریں

آپ ٹرمینل سے `omarchy hibernation setup` چلا کر ہائبرنیشن سیٹ اپ کرتے ہیں۔ ہائبرنیشن آپ کی بوٹ ڈرائیو پر آپ کی فزیکل RAM الاکیشن کے سائز کا ایک /swap سب والیوم بناتا ہے، اس لیے یقینی بنائیں کہ آپ کے پاس کافی خالی جگہ موجود ہے۔ 32GB مشین پر، آپ کو اس والیوم کے لیے ہمیشہ 32GB+ خالی جگہ درکار ہوگی۔ ہائبرنیشن کے لیے ڈیفالٹ Limine بوٹ لوڈر بھی درکار ہوتا ہے۔

سیٹ اپ ہو جانے پر، آپ کو _سسٹم_ (یا `Super + Esc`) کے تحت ہائبرنیٹ آپشن نظر آئے گا، اور پھر آپ دیکھ سکتے ہیں کہ آیا یہ آپ کے سسٹم پر مستقل طور پر کام کرتا ہے۔ اگر نہیں، تو آپ `omarchy hibernation remove` چلا کر اسے دوبارہ ہٹا سکتے ہیں۔
