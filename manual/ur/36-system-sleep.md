# سسٹم سلیپ

Omarchy بطور ڈیفالٹ سسپینڈ کو فعال کرتا ہے، اور سیٹ اپ ہو جانے کے بعد ہائبرنیشن کو بھی، لیکن اگر آپ کو اپنی مشین پر ان دونوں میں سے کسی کے ساتھ بھی مسائل پیش آ رہے ہوں تو آپ انہیں بند کر سکتے ہیں۔

NVIDIA GB10 مشینوں پر، جیسے DGX Spark اور ASUS Ascent GX10، سسپینڈ اور ہائبرنیشن بند ہوتے ہیں، جیسا کہ NVIDIA کے DGX OS میں بھی ہوتا ہے، کیونکہ اس ہارڈویئر پر سلیپ کا ٹھیک کام کرنا ابھی تک ثابت نہیں ہوا۔ سسپینڈ ٹوگل اور ہائبرنیشن سیٹ اپ وہاں لاگو نہیں ہوتے۔ سلیپ کو دوبارہ آن کرنے کے لیے، `sudo rm` کے ساتھ `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf` کو ہٹا دیں؛ اس کے بعد Suspend مینو میں واپس آ جائے گا، اور ہائبرنیشن کو دوسری مشینوں کی طرح سیٹ اپ کیا جا سکے گا۔ `sudo omarchy apply hardware --install-user "$USER"` چلانے سے فائل واپس آ جاتی ہے۔

### پاور پروفائلز

لیپ ٹاپ پر، Omarchy آپ کے پاور پروفائل کو پلگ ان ہونے اور بیٹری پر چلنے کے لیے الگ الگ یاد رکھتا ہے، اور پلگ لگانے اور نکالنے پر ان دونوں کے درمیان سوئچ کرتا ہے۔ باکس سے نکلتے ہی اس کا مطلب ہے AC پر performance اور بیٹری پر balanced۔

آپ `omarchy powerprofiles list` کے ساتھ دیکھ سکتے ہیں کہ آپ کی مشین کیا پیش کرتی ہے، اور `omarchy powerprofiles set autodetect power-saver` کے ساتھ اپنی موجودہ حالت کے لیے مطلوبہ پروفائل سیٹ کر سکتے ہیں۔ کچھ بھی ان پلگ کیے بغیر دوسری حالت سیٹ کرنے کے لیے، اسے براہ راست نام سے بتائیں: `omarchy powerprofiles set battery power-saver`۔ جو کچھ بھی آپ منتخب کریں گے، اگلی بار اس حالت میں ہونے پر آپ کو وہی واپس ملے گا۔

### سسپینڈ ٹوگل کریں

آپ ٹرمینل سے `omarchy toggle suspend` چلا کر سسپینڈ کو ٹوگل کرتے ہیں۔ اس سے بس _System_ (یا `Super + Esc`) کے تحت آپشن ظاہر/غائب ہوتا ہے، اور پھر آپ دیکھ سکتے ہیں کہ آیا یہ آپ کے سسٹم پر مستقل طور پر کام کرتا ہے۔ اگر نہیں، تو آپ اسی کمانڈ کے ساتھ اسے دوبارہ چھپا سکتے ہیں۔

### ہائبرنیشن ٹوگل کریں

آپ ٹرمینل سے `omarchy hibernation setup` چلا کر ہائبرنیشن سیٹ اپ کرتے ہیں (یہ Apple Silicon Macs پر دستیاب نہیں ہے)۔ ہائبرنیشن آپ کی بوٹ ڈرائیو پر آپ کی فزیکل RAM مختص مقدار کے سائز کا ایک /swap سب والیوم بناتا ہے، لہٰذا یقینی بنائیں کہ آپ کے پاس کافی جگہ خالی ہے۔ 32GB مشین پر، اس والیوم کے لیے آپ کو ہمیشہ 32GB+ خالی جگہ درکار ہوگی۔ ہائبرنیشن کے لیے ڈیفالٹ Limine بوٹ لوڈر بھی درکار ہے۔

سیٹ اپ ہو جانے پر، آپ کو _System_ (یا `Super + Esc`) کے تحت ہائبرنیٹ آپشن نظر آئے گا، اور پھر آپ دیکھ سکتے ہیں کہ آیا یہ آپ کے سسٹم پر مستقل طور پر کام کرتا ہے۔ اگر نہیں، تو آپ `omarchy hibernation remove` چلا کر اسے دوبارہ ہٹا سکتے ہیں۔
