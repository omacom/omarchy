# Prompt

Omarchy dilengkapi dengan prompt [Starship](https://starship.rs/) yang minimal secara bawaan. Begitulah saya suka menjaga prompt saya. Saya tidak perlu tahu penggunanya, karena itu selalu saya, dan saya tidak perlu tahu waktunya, karena itu selalu ada di atas.

 ![prompt](images/prompt.webp)

Jika kamu ingin lebih banyak informasi atau gaya, kamu bisa mengubah konfigurasi [Starship.rs](https://starship.rs/) di `~/.config/starship.toml`. Ada banyak yang bisa kamu lakukan. Hanya saja jangan berlebihan (atau berlebihan saja, lakukan apa pun yang kamu mau, ini komputermu!)
