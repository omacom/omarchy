### Menginstal dan memperbarui agen

Kecuali Hermes dan OpenClaw, agen-agen ini menggunakan instalasi lazy dari mise: peluncuran pertama menginstal CLI, dan peluncuran berikutnya menggunakannya kembali. mise juga memeriksa apakah ada rilis baru untuk agen yang terinstal paling banyak sekali setiap empat jam, tepat sebelum agen dimulai atau di latar belakang pada prompt shell. Jika pembaruan itu gagal atau Anda sedang offline, versi yang terinstal yang dijalankan. `omarchy update` memperbarui agen yang terinstal bersama seluruh Omarchy, dan `mup` hanya memperbarui alat yang dikelola mise.

Pembaru milik agen sendiri, seperti `claude update`, `codex update`, atau tombol pembaruan di sebuah aplikasi, tidak memperbarui instalasi yang dikelola mise. `codex update` gagal, dan `claude update` dapat melaporkan berhasil sambil menginstal salinan terpisah yang tidak dilacak mise. Jika Anda lebih suka menggunakan installer dan pembaru bawaan agen, tambahkan agen itu ke `disable_tools`; lihat [Alat CLI yang sudah terinstal](18-development-tools.md#preinstalled-cli-tools).

Untuk menginstal semua alat lazy yang dikonfigurasi sebelum Anda membutuhkannya, jalankan `mise install --include-lazy`. Ini mencakup alat CLI default Omarchy lainnya serta agen-agen tersebut. Lihat [Alat CLI yang sudah terinstal](18-development-tools.md#preinstalled-cli-tools) untuk menginstal satu alat atau menggunakan instalasi Anda sendiri.

`grok` diinstal melalui paket `grok` first-party dari mise, dengan cara yang sama seperti `claude` dan `codex`. Jalankan `grok`, atau beri bintang di panel agen. Lewati installer `curl | bash` di x.ai. Jalur itu menempatkan salinan kedua di `~/.grok/bin`, mendahulukannya di `PATH`, dan menimpa wrapper Omarchy.

`dsh` membuka UI browsernya di `127.0.0.1:3080`, dengan direktori peluncuran sebagai workspace default-nya. UI browsernya tidak menerima prompt awal, jadi `omarchy agent prompt` membukanya dengan prompt di clipboard Anda untuk ditempel. Omarchy memulainya dengan preset izin no-approval dari DeepSeek. DeepSeek Harness mengunggah log sesi ke DeepSeek saat Anda menggunakan API model resminya; matikan itu di bawah _Settings > General > Upload Session Log_ di UI browsernya. Masukan yang Anda kirimkan kepadanya juga diunggah bersama sesi tersebut, kecuali Anda memulainya dengan `DSH_TELEMETRY_MODE=DISABLED`.

### Agen default

Pilih agen default Anda dengan bintang di samping agen di panel agen, yang terisi pada agen default, atau dengan `omarchy default agent <name>`, yang juga menerima harness apa pun yang tidak memiliki baris di sana. Jika agen belum terinstal, memilihnya akan menginstalnya terlebih dahulu, dan agen itu juga mendapatkan peluncurnya sendiri di peluncur aplikasi, di samping Agent. Omarchy yang baru dipasang mengundang Anda untuk menyiapkannya dengan notifikasi satu kali, yang membuka panel agen.

Memilih Claude juga berupaya menyiapkan ekstensi browsernya untuk Chromium, Chrome, Brave, Brave Origin, dan Edge. Penyiapan ekstensi berlaku untuk semua pengguna dan mungkin meminta kata sandi sistem Anda; membatalkan atau gagal menginstal ekstensi tetap akan memilih dan meluncurkan Claude. Mulai ulang browser Anda, aktifkan ekstensi jika diminta, dan masuk ke Claude untuk menyelesaikan menghubungkannya. Jalankan `/chrome` di Claude untuk memeriksa koneksinya. Firefox dan Zen tidak mendukung ekstensi ini. Jika Claude sudah menjadi default Anda sebelum penyiapan ini ditambahkan, pilih lagi untuk menginstal ekstensi.

Setelah Anda memilih, `Super + Shift + Ctrl + A` meluncurkan agen default di jendela terminal khusus (atau memunculkan pemilih jika Anda belum memilih). Anda juga dapat meluncurkannya langsung ke sebuah tugas dengan `omarchy agent prompt "Review this project"`. Freebuff dan DeepSeek Harness tidak menerima prompt awal, jadi keduanya dibuka dengan prompt di clipboard Anda untuk ditempel sebagai gantinya. Agen yang diluncurkan dengan cara ini berjalan tanpa pengawasan dalam mode don't-stop-to-ask masing-masing, jadi bersiaplah karena mereka benar-benar akan melakukan sesuatu! MiniMax Code tidak memiliki mode seperti itu untuk sesi interaktifnya, jadi ia meminta izin seperti biasa. Dan karena agen menolak mengingat kepercayaan untuk direktori home Anda, peluncuran dari `$HOME` dimulai di `~/Work` sebagai gantinya.

Ada juga pintasan terminal: `a` menjalankan agen default secara inline di terminal saat ini, sementara `c`, `cx`, dan `cy` memulai OpenCode, Claude Code, dan Codex secara langsung (lagi-lagi dalam mode persetujuan otomatis mereka). Perubahan tema juga tersinkron ke agen: Claude Code, Pi, OpenCode, dan Hermes (setelah Omarchy menginstalnya) semuanya mengikuti saat Anda beralih tema Omarchy.

### Instruksi agen Anda

Aturan pribadi untuk setiap agen berada di `~/.agents/AGENTS.md`, di samping skill bersama di `~/.agents/skills`. Buka dengan ikon dokumen di samping + di panel agen, atau `omarchy agent instructions --edit`, yang juga menautkannya ke setiap harness yang menyimpan file globalnya sendiri: `~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.pi/agent/AGENTS.md`, `~/.config/opencode/AGENTS.md`, `~/.copilot/copilot-instructions.md` milik Copilot, dan seterusnya. Crush dan Amp membaca tautan `~/.config/AGENTS.md`, sementara omp, Kimi, dan DeepSeek Harness membaca `~/.agents/AGENTS.md` secara langsung. Memilih agen default juga menautkannya. File instruksi yang sudah Anda miliki menjadi file bersama jika belum ada; jika sudah ada, file itu disimpan di samping tautan sebagai `.bak`. Jalankan `omarchy agent instructions` untuk menautkan ulang setelah menginstal agen lain.

### Panel agen

Bilah atas memiliki ikon agen. Sebelum Anda menyiapkan agen, panelnya menawarkan tiga cara untuk memulai: masuk ke langganan Claude, Codex, Grok, Gemini, Muse, Cursor, atau Copilot, atau di bawah More sebuah paket coding OpenCode Go, MiniMax, Synthetic, atau Z.ai; bayar sesuai pemakaian dengan Fireworks, OpenCode Zen and Go, OpenRouter, atau di bawah More DeepSeek atau penyedia lain mana pun yang dapat dimasuki OpenCode, semuanya berjalan di OpenCode; atau jalankan model terbaik untuk komputer Anda, saat ada yang cocok dengannya. Yang pertama Anda selesaikan menjadi agen default Anda, dan + di panel, atau _Agent > Add_ di Menu Omarchy, menawarkan tiga hal yang sama kemudian. Setelah itu, panel menempatkan setiap langganan di satu halaman: setiap agen dan akun beserta paketnya, meter untuk setiap batas sesi 5 jam dan batas mingguannya beserta waktu hingga batas itu direset (arahkan kursor untuk persentase pastinya), atau sisa saldo prabayar, di bawah sebuah baris yang berganti-ganti menampilkan apa yang telah Anda gunakan di semua itu, seperti token minggu ini dan model yang paling sering Anda gunakan. Di bawah _Buat sesuatu yang keren_ ia menawarkan prompt pemula untuk tema, plugin, aplikasi, atau game baru yang menyerahkan tugas itu ke agen default Anda. Aplikasi dibangun dengan cara yang sama seperti Hype, Monologue, dan Omacut milik Omarchy sendiri, dalam C++ dan Qt Quick, mengikuti skill agen omarchy-make-app, dan compiler serta komponen Qt yang mereka butuhkan sudah terinstal. Game adalah satu halaman three.js di `~/Games/vibes`, mengikuti skill agen omarchy-make-game, dan semuanya dibuka dari satu peluncur Game Vibes dalam tema saat ini; mereka memuat three.js dari web, jadi mereka memerlukan koneksi untuk memulai. Claude Code, Codex, Grok, Kimi, Cursor dan jatah Grok Bot-nya, GitHub Copilot, Muse, Gemini (melalui Antigravity), dan Devin tercakup langsung dengan batas-batas mereka, Kimchi dengan paket, kredit prabayar, dan anggaran pengeluarannya, dan Hermes, Mistral Vibe, dan Qwen Code menampilkan sesi dan token mereka setelah Anda menggunakannya. Paket dan kunci penyedia yang Anda gunakan melalui pi, omp, atau opencode juga muncul: OpenCode Zen and Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan, dan Synthetic dengan batas-batas mereka; OpenRouter dan DeepSeek dengan saldo prabayar mereka; Fireworks dengan pengeluarannya selama 30 hari terakhir. Token dari model yang Anda jalankan di perangkat keras Anda sendiri juga dihitung dalam total; model-model itu sendiri memiliki panel sendiri, yang dijelaskan di bawah [Model lokal](#local-models). Setiap agen dihitung sekali, di bawah pihak yang menagihnya, berapa pun banyaknya harness yang Anda gunakan untuk menjalankannya.

Klik kiri ikon bilah atau tekan `Super + Ctrl + X` untuk panel, klik kanan untuk meluncurkan agen default Anda, dan klik tengah untuk menyegarkan. Catatan penggunaan di belakangnya dibuat ulang setiap 15 menit oleh `omarchy agent usage update`, dan panel bahkan dapat menggabungkan penggunaan dari mesin Anda yang lain melalui folder yang disinkronkan. Lihat README di bawah `$OMARCHY_PATH/shell/plugins/agents/` untuk pengaturan lengkapnya.

### Beberapa langganan

Jika Anda membayar lebih dari satu paket Claude, Codex, atau Grok — misalnya Max pribadi dan satu untuk pekerjaan — Omarchy dapat menjaga semuanya tetap masuk dan berpindah di antaranya. Tambahkan langganan dengan + di panel agen, yang memandu Anda langsung di sana, atau dengan `omarchy agent account add claude Work` (atau `codex`, atau `grok`). + dan perintah yang sama masuk ke Gemini (`gemini`) dan OpenCode (`opencode`), dan menyimpan kunci API Fireworks (`fireworks`) atau OpenRouter (`openrouter`) di OpenCode; perintah itu juga masuk ke Copilot (`copilot`), Cursor (`cursor`), dan Muse (`muse`). Masing-masing dari itu menyimpan satu kali masuk saja. Ia menginstal CLI jika belum ada. Akun pertama untuk sebuah penyedia masuk melalui browser normal Anda, tepat di tempat CLI selalu mencarinya. Setiap akun setelah itu masuk melalui jendela pribadi, sehingga akun yang sudah dimasuki browser Anda tidak terambil secara tidak sengaja; masuk di sana sebagai akun yang Anda tambahkan, dan tutup jendela pribadi apa pun yang sudah Anda buka terlebih dahulu. Jangan pernah keluar dari CLI untuk melakukan ini: keluar mencabut data masuk yang disimpan, dan akun itu harus ditambahkan lagi.

Untuk menyalin login langganan Anda ke mesin Omarchy lain melalui SSH, jalankan `omarchy agent account copy user@laptop`. Pengirim menyediakan penerima sementara saat tujuan belum memiliki yang terinstal, sehingga mesin Omarchy yang lebih lama dapat menerima akun tanpa pembaruan. Penerima yang terinstal diutamakan. Ini menyalin semua langganan Claude, Codex, dan Grok; tambahkan nama penyedia untuk memilihnya, seperti dalam `omarchy agent account copy laptop claude`. Nama akun dan ID perintah cocok dengan sumber, termasuk akun yang sudah ada di tujuan. Akun tujuan yang tidak terkait menerima akhiran numerik jika namanya bertabrakan, dan pengaturan, skill, plugin, dan riwayat percakapan tetap lokal di setiap mesin.

Kredensial tujuan yang ada tetap dipertahankan. Akun sumber yang sudah masuk di sana namanya disinkronkan tanpa mengganti kredensialnya; akun lain ditambahkan di sampingnya. Untuk mengganti kredensial yang disimpan untuk akun yang cocok, gunakan `omarchy agent account copy --replace laptop claude` setelah keluar dari sesi akun itu di tujuan. Tujuan yang masih baru juga mendapatkan akun aktif dan preferensi peralihan dari sumber; tujuan yang sudah mapan mempertahankan miliknya sendiri.

Kredensial berjalan melalui SSH dan disimpan dalam file pribadi di tujuan, jadi salin hanya ke mesin yang Anda percayai. Ini adalah salinan satu kali, bukan sinkronisasi berkelanjutan. Token refresh Codex dapat dirotasi oleh mesin lain, membuat salinan login memerlukan pembaruan; login terpisah tetap menjadi pilihan paling andal untuk penggunaan bersamaan di beberapa mesin. Lihat [Panduan autentikasi akun Codex](https://developers.openai.com/codex/auth/ci-cd-auth).

Satu akun per penyedia aktif, dan setiap sesi baru dimulai sebagai akun itu: `cx`, `cy`, `claude`, `codex`, atau `grok` biasa, apa pun yang diluncurkan melalui `omarchy agent`, dan skrip atau editor yang menemukan CLI di `PATH`. Beralih dengan `omarchy agent account use work` (dan kembali dengan `omarchy agent account use main`), atau di panel dengan menekan nomor akun lalu `Enter` (atau mengklik bintangnya). Sesi Claude yang sedang berjalan juga beralih, mulai pesan berikutnya: setiap sesi Claude berjalan di `~/.claude`, yang selalu menyimpan data masuk akun aktif. Sesi Claude yang dimulai di folder akun sendiri oleh Omarchy yang lebih lama menyimpan data masuk itu hingga ia keluar, jadi peralihan menyebutkan sesi-sesi tersebut dan selesai dengan sendirinya setelah mereka hilang. Sesi Codex dan Grok yang sedang berjalan tetap pada akun tempat mereka dimulai. Riwayat percakapan, pengaturan, skill, dan plugin dibagikan di antara akun, jadi `claude --continue` di folder yang sama melanjutkan dari tempat Anda berhenti di akun baru.

Dengan lebih dari satu akun, panel menampilkan batas setiap akun berdampingan, dengan bintang terisi pada akun yang digunakan. Omarchy memberi tahu Anda saat akun aktif melewati 95% dari sebuah batas, dan mengklik notifikasi beralih ke akun dengan ruang tersisa paling banyak. Ia tidak pernah beralih dengan sendirinya. Ubah ambang batas dengan `omarchy agent account threshold 90`. Jika setiap akun melebihi ambang batas, Anda akan mendengarnya sekali, beserta akun mana yang lebih dulu bebas. Sementara akun aktif berada dalam 15 poin dari ambang batasnya (80% pada default), batasnya diperiksa setiap tiga menit, bukan setiap 15 menit.

`omarchy agent account list` menampilkan setiap akun dan batas terbarunya, `omarchy agent account remove work` melupakan satu akun, dan `omarchy agent account rename primary Hey` mengganti nama satu akun (atau klik nama akun di panel). Perintah-perintah ini bekerja pada akun agen default Anda; untuk menjangkau penyedia lain, sebutkan namanya terlebih dahulu, seperti dalam `omarchy agent account use codex side`. Login yang sudah Anda miliki di `~/.claude` atau `~/.codex` adalah akun _Main_. Akun Codex tetap di tempatnya; akun Claude menunggu di foldernya sendiri sementara akun lain aktif. Akun yang tidak digunakan selama lebih dari sekitar delapan jam dapat menampilkan _Sign-in required_; klik untuk masuk ke akun itu lagi langsung di panel, atau beralih ke akun itu dan mulai sesi, yang menyegarkan data masuk dengan sendirinya. Server MCP yang Anda tambahkan dengan `claude mcp add` menjangkau setiap akun Claude, karena semuanya berjalan di `~/.claude`; untuk Codex dan Grok, server yang Anda miliki saat sebuah akun ditambahkan ikut ke akun itu, tetapi server yang ditambahkan kemudian hanya menjangkau akun tempat Anda menambahkannya. Claude Desktop menyimpan data masuknya sendiri, dan alat Codex atau Grok yang dikonfigurasi dengan jalur absolut ke biner CLI tidak mengikuti peralihan. `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, atau `GROK_HOME` eksplisit diutamakan di atas akun yang dipilih.

### Diagnosis crash

Omarchy memantau systemd-coredump untuk crash proses. Setelah Anda memilih agen default, program Anda mana pun yang melakukan dump core memunculkan notifikasi "Process crashed" — klik notifikasi itu, dan crash diserahkan ke agen default Anda bersama skill omarchy-diagnose-crash milik Omarchy, yang memandu agen melalui penetapan fakta dari core dump dan memutuskan apakah crash tersebut layak dilaporkan ke upstream. Anda juga dapat menjalankannya secara manual terhadap PID apa pun dari `coredumpctl list` dengan `omarchy agent crash <pid>`.

Pemantauan ini aktif secara default. Matikan di bawah _Trigger > Toggle > Crash Capture Off_ (atau dengan `omarchy toggle crash-capture`) dan notifikasi berhenti; `omarchy agent crash <pid>` tetap bekerja secara manual.

Crash juga dapat dibisukan satu program pada satu waktu, yang ditawarkan diagnosis kepada Anda di akhir. `omarchy crash mute hyprland` menghentikan notifikasi hanya untuk program itu, `omarchy crash mute hyprland off` memunculkannya kembali, dan `omarchy crash mute` sendiri mencantumkan apa yang telah Anda bisukan. Ia menerima jalur biner sama senangnya seperti namanya, jadi `omarchy crash mute /usr/bin/hyprland` melakukan hal yang sama. Kutip nama yang mengandung spasi, seperti dalam `omarchy crash mute 'Some App'`. Semua hal lain tetap memberi notifikasi, dan program yang dibisukan tetap crash — ini menyembunyikan pengingat, bukan memperbaiki apa pun.

### Aplikasi desktop

Menu _Install > AI_ juga membawa beberapa aplikasi AI grafis: Amp Desktop, Antigravity Desktop, aplikasi desktop ChatGPT, aplikasi desktop Claude (beta Linux dari Anthropic, dengan tab Chat, Cowork, dan Claude Code), Grok Bot untuk mengobrol dengan model xAI, Herdr Desktop, Hermes Desktop, OpenClaw, aplikasi desktop Perplexity, dan T3 Code. Grok Bot adalah aplikasi obrolan desktop. Agen coding-nya adalah perintah `grok`.

Hermes Desktop adalah yang perlu diketahui, karena sebuah mesin memiliki satu Hermes, dan itu milik aplikasi: Hermes hanya pernah diinstal melalui aplikasi, dan perintah `hermes` yang dijalankan agen default adalah milik aplikasi. Memilih Hermes sebagai agen default menginstal hal yang sama seperti yang dilakukan entri _Install > AI_: paketnya, dan runtime Hermes di bawah `~/.hermes` yang disiapkan oleh installer Hermes sendiri, yang memerlukan beberapa menit pada kali pertama. Runtime itu adalah satu-satunya Hermes yang digunakan perintah `hermes` terminal, agen default, dan aplikasi, dan ia memperbarui dirinya sendiri dengan `hermes update` alih-alih menunggu rilis Omarchy. Menginstalnya juga memberikan Hermes tema Omarchy sebagai skin bernama `omarchy`, yang diikuti setiap permukaan Hermes saat Anda beralih tema; pilih yang lain di bawah pengaturan Appearance Hermes atau dengan `/skin` jika Anda lebih suka tidak, dan Omarchy membiarkan pilihan itu. Menghapus aplikasi di bawah _Remove > AI_ menutup Hermes terlebih dahulu, termasuk gateway, mengambil runtime itu bersamanya, dan menyimpan obrolan, memori, dan skill yang ditulis Hermes untuk dirinya sendiri kecuali Anda menyuruhnya sebaliknya: ia bertanya, dengan default tidak, apakah data itu dan pengaturan koneksi Anda juga harus dihapus.

Pengalaman desktop OpenClaw adalah Control UI-nya, yang dibuka sebagai aplikasi web yang didukung oleh gateway lokalnya sendiri. OpenClaw tinggal di `~/.openclaw` dan memperbarui dirinya sendiri: gunakan tombol "Update Gateway" di Control UI atau jalankan `openclaw update`, dan gateway dimulai ulang pada versi baru. Omarchy hanya memilih rilis tempat instalasi baru dimulai. OpenClaw juga dapat menjadi agen default Anda: memilihnya di bawah _Agent > Harness_ menyiapkan salinan yang sama itu di `~/.openclaw`, dan agen membuka UI terminal OpenClaw yang terhubung ke gateway-nya. Menghapus OpenClaw di bawah _Remove > AI_ mengambil layanan gateway dan aplikasi bersamanya lalu bertanya apakah `~/.openclaw` juga harus dihapus, karena di sana tersimpan obrolan dan kredensial Anda di samping OpenClaw itu sendiri dan runtime plugin yang diunduhnya; default-nya menyimpannya, dan menginstal OpenClaw lagi akan mengambilnya kembali.

Herdr Desktop adalah aplikasi desktop [Herdr](https://herdr.dev): spaces, tab, dan pane terminal dan agen coding yang terus berjalan di core-nya saat Anda menutup jendela. Ia berasal dari installer Herdr sendiri alih-alih sebuah paket, jadi ia tinggal di `~/.local/share/herdr-app`, membawa core-nya di `~/.local/bin/herdr-core` saat Anda belum memilikinya, dan memperbarui keduanya sendiri. Ia berada di samping perintah `herdr` yang disertakan Omarchy pada `Super + Ctrl + Return` alih-alih menggantikannya, dan mendapatkan tombol langsung perintah itu: `Alt + Return` dan `Alt + Shift + Return` membagi pane ke bawah atau ke kanan, `Alt + Escape` menutupnya, `Ctrl + Alt + Arrow` berpindah antar pane, `Alt + 1..9` dan `Alt + Left/Right` memilih tab, dan `Alt + Up/Down` berpindah antar spaces. `Ctrl + 1..9` memilih space dan `Alt + Shift + Up/Down` melangkah melalui agen. Tombol awalan `Ctrl + Space` tetap hanya untuk terminal, karena aplikasi tidak dapat menahan tombol Ctrl biasa untuk sebuah urutan. Omarchy menulis ini ke `~/.config/herdr-app/keys.json`, dan `omarchy-refresh-herdr-app` mengembalikannya. Menginstalnya memilih tema Omarchy Herdr, yang mengikuti tema Omarchy Anda sejak saat itu. Herdr menyimpan satu tema untuk mode terang dan satu untuk mode gelap, jadi setelah beralih antara tema Omarchy gelap dan terang, pilih Omarchy di pemilih tema Herdr sekali lagi untuk mode lainnya.

T3 Code berjalan dari rilis AppImage resminya di `~/.local/share/t3code` alih-alih dari sebuah paket, jadi ia memperbarui dirinya sendiri. Menginstalnya menanyakan apakah akan memulai pada saluran Stable atau Nightly; beralih kemudian di pengaturan T3 Code. Thread dan pengaturan Anda tinggal di `~/.t3`, dan menghapus T3 Code di bawah _Remove > AI_ mengambilnya bersamanya.

### Model lokal

Jalankan model terbuka di mesin Anda sendiri untuk agen coding Anda. Prompt dan kode Anda tetap di mesin; tidak ada yang dikirim ke model yang meninggalkannya. Mulai dengan:

```bash
omarchy models use best text
```

Itu menyiapkan model teks terbaik untuk mesin ini, jenis yang digunakan agen Anda. Model gambar, video, dan musik memiliki yang terbaiknya sendiri: `omarchy models use best image`, `video` atau `music`. Jalankan `omarchy models use best` untuk melihat pilihan setiap jenis untuk mesin ini.

Atau buka panel model lokal dari ikon sparkles-nya di bilah atas, di samping ikon agen, atau dengan Super + Ctrl + Alt + X, dan pilih +. Ikon muncul saat sebuah model cocok dengan mesin ini. Podman, yang menjalankan model, disertakan dengan Omarchy, begitu juga toolkit container NVIDIA pada mesin NVIDIA, yang memberi mereka GPU; jika salah satunya hilang, penyiapan pertama menginstalnya. Omarchy kemudian memilih model yang direkomendasikan untuk mesin ini, mengunduhnya, dan memulainya. Harapkan unduhan puluhan GB dan sebagian besar memori mesin digunakan saat model berjalan: Flash Next menggunakan sekitar 100 GiB dengan konteks penuh 256K-nya. Jika model lain menahan memori yang dibutuhkannya, ia disiapkan dalam keadaan berhenti, siap dimulai setelah Anda menghentikan salah satunya. Model berhenti saat logout; hentikan sendiri saat Anda memerlukan memori untuk hal lain.

`omarchy models list` menampilkan pilihan dan menjelaskan mengapa beberapa tidak cocok. Untuk menyiapkan yang lain, jalankan `omarchy models use <recipe>`. Hari ini, `qwen3.8-flash-next-gufo` dan `qwen3.8-27b-gufo` tersedia untuk mesin Strix Halo 128 GB; 27B menggunakan sekitar 40 GiB, jadi ia menyisakan ruang untuk pekerjaan lain. Pada laptop 64 GB dengan Arc B390 Intel, `qwen3.6-35b-a3b-llamacpp` berjalan dalam sekitar 30 GiB. Resep dan rekomendasi baru tiba dengan `omarchy update`, melalui paket.

Setiap model yang Anda siapkan mendapatkan barisnya sendiri di panel model lokal: play untuk memulainya, pause untuk menghentikannya dan membebaskan memorinya, dan tombol terminal untuk membuka agen Anda di model itu. Di bagian atas, sebuah bilah menunjukkan bagaimana memori mesin dibagi antara Omarchy itu sendiri (sistem dan aplikasi Anda), setiap model yang berjalan, dan yang bebas. Arahkan ke model yang berhenti dan bilah menunjukkan apakah ia cocok, atau berapa kekurangannya. Beberapa dapat berjalan sekaligus saat mereka cocok dalam memori bersama; jika satu tidak cocok, Omarchy menyebutkan model berjalan mana yang harus dihentikan. Seret baris berdasarkan logonya untuk mengurutkannya kembali, dan tekan Delete pada baris yang dipilih untuk menghapus model dan unduhannya.

Setiap model coding yang Anda siapkan juga mendapatkan entrinya sendiri di peluncur aplikasi, di bawah nama model dan dengan logo pembuatnya, seperti cara masuk ke Claude, Codex atau Grok menambahkannya. Ia membuka agen Anda pada model itu, dan memulai model terlebih dahulu jika belum berjalan: terminal menunjukkan model sedang dimuat dan menyerahkan ke agen setelah model aktif. Menghapus model menghapus entrinya.

Tidak setiap model untuk coding. Model gambar, video, dan musik dibuka di Fantasi sebagai gantinya, aplikasi Omarchy untuk membuat gambar, video, dan musik dengan model yang berjalan di mesin ini, dipilih di sana atau dari barisnya di panel model lokal.

Sebuah model tetap berjalan persis seperti saat disiapkan, jadi pembaruan Omarchy tidak pernah memulai ulang model di bawah agen Anda. Saat Omarchy memiliki runtime yang lebih baru atau bobot yang lebih baru untuk model yang telah Anda siapkan, barisnya menampilkan tombol pembaruan: tekan dan model disiapkan lagi di latar belakang, hanya mengunduh yang berubah, dan dimulai ulang pada versi baru. Model yang berhenti tetap berhenti. `omarchy models update` melakukan hal yang sama untuk setiap model dari terminal.

Dari baris perintah, `omarchy models start <recipe>` dan `omarchy models stop <recipe>` melakukan hal yang sama, `omarchy models status` menampilkan setiap model, dan `omarchy agent --local-model <recipe>` membuka model itu di pi, apa pun agen default Anda. Untuk menjadikan model lokal Anda sebagai yang dibuka oleh hotkey agen, konsol Quake, dan _Buat sesuatu_, jalankan `omarchy default agent local` atau pilih _Model lokal_ di bawah _Agent > Harness_. pi juga mencantumkan setiap model yang telah Anda siapkan, dan yang ada di mesin yang telah Anda pasangkan, dalam pemilih modelnya sendiri, jadi `pi` biasa juga dapat menjangkaunya. Klien apa pun yang kompatibel dengan OpenAI juga dapat terhubung: `status` menunjukkan alamat setiap model (yang pertama adalah `http://127.0.0.1:11435/v1`), nama resep adalah modelnya, dan kuncinya ada di `~/.config/omarchy/agent-local/key`.

`omarchy models remove <recipe>` menghapus model dan unduhan yang tidak digunakan model lain.

Runtime pihak ketiga diberi label dengan penerbitnya. Omarchy menjalankan setiap model tanpa akses jaringan.

### LLM lokal

Omarchy merekomendasikan dua cara menjalankan model LLM lokal: LM Studio dan Ollama. LM Studio menyediakan antarmuka GUI untuk menemukan model open-weight, menginstalnya, dan menjalankannya. Ini cara yang bagus untuk memulai dengan mudah. Ollama menawarkan CLI untuk melakukan hal serupa. Tetapi jika Anda baru mengenal model lokal, saya akan mulai dengan LM Studio. Anda dapat menginstal salah satunya di bawah _Install > AI_ di Menu Omarchy.

### Skill Omarchy

Skill agen membantu AI menggunakan alat tertentu dengan cara tertentu, dan Omarchy menyertakan tujuh di antaranya. Skill omarchy mencakup menyesuaikan sistem, seperti mengubah config Hyprland Anda atau menyesuaikan bilah. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app, dan omarchy-make-game mencakup membuat sesuatu yang baru, omarchy-contribute mencakup melaporkan bug atau mengirim perbaikan ke upstream, dan omarchy-diagnose-crash bekerja melalui core dump sebuah crash. Mereka disymlink ke direktori skill untuk Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` dan setiap `~/.hermes/profiles/*/skills`), dan lokasi generik `~/.agents/skills`, jadi sebagian besar harness mengambilnya secara otomatis. Folder skill Anda sendiri dengan nama yang sama diutamakan.

Namun Anda harus memperlakukan skill ini sebagai eksperimental. Model yang berbeda akan menggunakannya dengan efek yang berbeda. Sebaiknya jalankan dalam mode plan terlebih dahulu, sehingga Anda memiliki gambaran tentang apa yang ingin diubah agen. Lalu bersiaplah untuk mengembalikan perubahan atau bahkan menjalankan `omarchy reinstall configs`, jika agen membuat semuanya berantakan.
