### Menginstal dan memperbarui agen

Kecuali Hermes dan OpenClaw, agen-agen ini menggunakan instalasi lazy dari mise: peluncuran pertama menginstal CLI, dan peluncuran berikutnya menggunakannya kembali. mise juga memeriksa apakah agen yang terinstal memiliki rilis baru paling banyak sekali setiap empat jam, tepat sebelum agen dimulai atau di latar belakang pada prompt shell. Jika pembaruan itu gagal atau Anda sedang offline, versi yang terinstal yang dijalankan. `omarchy update` memperbarui agen yang terinstal bersama seluruh Omarchy lainnya, dan `mup` hanya memperbarui alat yang dikelola mise.

Alat pembaruan milik agen sendiri, seperti `claude update`, `codex update`, atau tombol pembaruan di sebuah aplikasi, tidak memperbarui instalasi yang dikelola mise. `codex update` gagal, dan `claude update` dapat melaporkan berhasil sambil menginstal salinan terpisah yang tidak dilacak mise. Jika Anda lebih suka menggunakan installer dan alat pembaruan bawaan agen, tambahkan agen itu ke `disable_tools`; lihat [Alat CLI yang sudah terinstal](18-development-tools.md#preinstalled-cli-tools).

Untuk menginstal semua alat lazy yang dikonfigurasi sebelum Anda membutuhkannya, jalankan `mise install --include-lazy`. Ini mencakup alat CLI default Omarchy lainnya selain para agen. Lihat [Alat CLI yang sudah terinstal](18-development-tools.md#preinstalled-cli-tools) untuk menginstal satu alat atau menggunakan instalasi Anda sendiri.

`grok` diinstal melalui paket `grok` pihak pertama dari mise, dengan cara yang sama seperti `claude` dan `codex`. Jalankan `grok`, atau beri bintang di panel agen. Lewati installer `curl | bash` di x.ai. Jalur itu menaruh salinan kedua di `~/.grok/bin`, mendahulukannya di `PATH`, dan menimpa wrapper Omarchy.

`dsh` membuka UI browsernya di `127.0.0.1:3080`, dengan direktori peluncuran sebagai workspace default-nya. UI browsernya tidak menerima prompt awal, jadi `omarchy agent prompt` membukanya dengan prompt di clipboard Anda untuk ditempel. Omarchy memulainya dengan preset izin tanpa persetujuan dari DeepSeek. DeepSeek Harness mengunggah log sesi ke DeepSeek ketika Anda menggunakan API model resminya; matikan itu di bawah _Settings > General > Upload Session Log_ di UI browsernya. Masukan yang Anda kirimkan kepadanya juga diunggah bersama sesi tersebut, kecuali Anda memulainya dengan `DSH_TELEMETRY_MODE=DISABLED`.

### Agen default

Pilih agen default Anda dengan bintang di samping agen di panel agen, yang terisi pada agen default, atau dengan `omarchy default agent <name>`, yang juga menerima harness apa pun yang tidak memiliki baris di sana. Jika agen belum terinstal, memilihnya akan menginstalnya terlebih dahulu, dan agen itu juga mendapatkan peluncurnya sendiri di peluncur aplikasi, di samping Agent. Omarchy yang baru mengundang Anda untuk menyiapkan satu agen dengan notifikasi satu kali, yang membuka panel agen.

Memilih Claude juga berusaha menyiapkan ekstensi browsernya untuk Chromium, Chrome, Brave, Brave Origin, dan Edge. Penyiapan ekstensi berlaku untuk semua pengguna dan mungkin meminta kata sandi sistem Anda; membatalkan atau gagalnya instalasi ekstensi tetap memilih dan meluncurkan Claude. Mulai ulang browser Anda, aktifkan ekstensi jika diminta, dan masuk ke Claude untuk menyelesaikan penyambungannya. Jalankan `/chrome` di Claude untuk memeriksa koneksi. Firefox dan Zen tidak mendukung ekstensi ini. Jika Claude sudah menjadi default Anda sebelum penyiapan ini ditambahkan, pilih lagi untuk menginstal ekstensi.

Setelah Anda memilih, `Super + Shift + Ctrl + A` meluncurkan agen default di jendela terminal khusus (atau memunculkan pemilih jika Anda belum memilih). Anda juga dapat meluncurkannya langsung ke sebuah tugas dengan `omarchy agent prompt "Review this project"`. Freebuff dan DeepSeek Harness tidak menerima prompt awal, jadi keduanya terbuka dengan prompt di clipboard Anda untuk ditempel sebagai gantinya. Agen yang diluncurkan dengan cara ini berjalan tanpa pengawasan dalam mode jangan-berhenti-untuk-bertanya masing-masing, jadi bersiaplah karena mereka benar-benar akan melakukan sesuatu! MiniMax Code tidak memiliki mode seperti itu untuk sesi interaktifnya, jadi ia meminta izin seperti biasa. Dan karena agen menolak mengingat kepercayaan untuk direktori home Anda, peluncuran dari `$HOME` dimulai di `~/Work` sebagai gantinya.

Ada juga pintasan terminal: `a` menjalankan agen default secara inline di terminal saat ini, sedangkan `c`, `cx`, `cy`, dan `ca` memulai OpenCode, Claude Code, Codex, dan Antigravity secara langsung (lagi-lagi dalam mode menyetujui-otomatis mereka). Perubahan tema juga tersinkron ke para agen: Claude Code, Pi, OpenCode, dan Hermes (setelah Omarchy menginstalnya) semuanya mengikuti ketika Anda mengganti tema Omarchy.

### Instruksi agen Anda

Aturan pribadi untuk setiap agen dimasukkan ke `~/.agents/AGENTS.md`, di samping skill bersama di `~/.agents/skills`. Buka file itu dengan ikon dokumen di samping + di panel agen, atau `omarchy agent instructions --edit`, yang juga menautkannya ke setiap harness yang menyimpan file globalnya sendiri: `~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.pi/agent/AGENTS.md`, `~/.config/opencode/AGENTS.md`, `~/.copilot/copilot-instructions.md` milik Copilot, dan seterusnya. Crush dan Amp membaca tautan `~/.config/AGENTS.md`, sedangkan omp, Kimi, dan DeepSeek Harness membaca `~/.agents/AGENTS.md` secara langsung. Memilih agen default juga menautkannya. File instruksi yang sudah Anda miliki menjadi file bersama jika belum ada file bersama; jika sudah ada, file itu disimpan di samping tautan sebagai `.bak`. Jalankan `omarchy agent instructions` untuk menautkan ulang setelah menginstal agen lain.

### Panel agen

Bilah atas memiliki ikon agen. Sebelum Anda menyiapkan agen, panelnya menawarkan tiga cara untuk memulai: masuk ke langganan Claude, Codex, Grok, Gemini, Muse, Cursor, atau Copilot, atau di bawah More sebuah paket coding OpenCode Go, MiniMax, Synthetic, atau Z.ai; membayar sesuai pemakaian dengan Fireworks, OpenCode Zen dan Go, OpenRouter, atau di bawah More DeepSeek atau provider lain mana pun yang dapat dimasuki OpenCode, semuanya berjalan di OpenCode; atau menjalankan model terbaik untuk komputer Anda, ketika ada yang cocok untuknya. Yang pertama Anda selesaikan menjadi agen default Anda, dan + di panel menawarkan tiga pilihan yang sama di kemudian hari. Setelah itu, panel menempatkan setiap langganan di satu halaman: setiap agen dan akun dengan paketnya, meteran untuk masing-masing batas sesi 5 jam dan batas mingguannya beserta waktu hingga batas itu direset (arahkan kursor untuk persentase pastinya), atau sisa saldo prabayar, di bawah sebuah baris yang berganti-ganti menampilkan apa yang telah Anda gunakan di semua agen itu, seperti token minggu ini dan model yang paling sering Anda gunakan. Di bawah _Make something cool_ panel menawarkan prompt pemula untuk tema, plugin, aplikasi, atau game baru yang menyerahkan tugasnya kepada agen default Anda. Aplikasi dibangun dengan cara yang sama seperti Hype, Monologue, dan Omacut milik Omarchy sendiri, dalam C++ dan Qt Quick, mengikuti skill agen omarchy-make-app, dan compiler serta potongan Qt yang mereka butuhkan sudah terinstal. Game adalah satu halaman three.js di `~/Games/vibes`, mengikuti skill agen omarchy-make-game, dan semuanya terbuka dari satu peluncur Game Vibes dalam tema saat ini; mereka memuat three.js dari web, jadi mereka memerlukan koneksi untuk memulai. Claude Code, Codex, Grok, Kimi, Cursor dan jatah Grok Bot-nya, GitHub Copilot, Muse, Gemini (melalui Antigravity), dan Devin tercakup sejak awal dengan batas-batasnya, Kimchi dengan paketnya, kredit prabayar, dan anggaran pengeluarannya, dan Hermes, Mistral Vibe, dan Qwen Code menampilkan sesi dan token mereka setelah Anda menggunakannya. Paket dan kunci provider yang Anda gunakan melalui pi, omp, atau opencode juga muncul: OpenCode Zen dan Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan, dan Synthetic dengan batas-batasnya; OpenRouter dan DeepSeek dengan saldo prabayarnya; Fireworks dengan pengeluarannya selama 30 hari terakhir. Model coding yang Anda jalankan di perangkat keras Anda sendiri mendapatkan barisnya sendiri, dan token mereka juga dihitung ke dalam total, seperti dijelaskan di bawah [Model lokal](#local-models). Setiap agen dihitung sekali, di bawah siapa pun yang menagihnya, melalui berapa pun harness Anda menjalankannya.

Klik kiri ikon bilah atau tekan `Super + Ctrl + X` untuk panel, klik kanan untuk meluncurkan agen default Anda, dan klik tengah untuk menyegarkan. Catatan penggunaan di baliknya dibuat ulang setiap 15 menit oleh `omarchy agent usage update`, dan panel bahkan dapat menggabungkan penggunaan dari mesin Anda yang lain melalui folder yang tersinkron. Lihat README di bawah `$OMARCHY_PATH/shell/plugins/agents/` untuk pengaturan lengkapnya.

### Beberapa langganan

Jika Anda membayar lebih dari satu paket Claude, Codex, atau Grok — misalnya Max pribadi dan satu untuk pekerjaan — Omarchy dapat menjaga semuanya tetap masuk dan berpindah di antara mereka. Tambahkan langganan dengan + di panel agen, yang memandu Anda melewatinya langsung di sana, atau dengan `omarchy agent account add claude Work` (atau `codex`, atau `grok`). Tombol + dan perintah yang sama membuat Anda masuk ke Gemini (`gemini`) dan OpenCode (`opencode`), dan menyimpan kunci API Fireworks (`fireworks`) atau OpenRouter (`openrouter`) di OpenCode; perintah itu juga membuat Anda masuk ke Copilot (`copilot`), Cursor (`cursor`), dan Muse (`muse`). Masing-masing dari mereka menyimpan satu kali masuk saja. Perintah itu menginstal CLI jika belum ada. Akun pertama untuk sebuah provider masuk melalui browser normal Anda, tepat di tempat CLI selalu mencarinya. Setiap akun setelah itu masuk melalui jendela pribadi, sehingga akun yang sudah dimasuki browser Anda tidak terambil secara tidak sengaja; masuk di sana sebagai akun yang sedang Anda tambahkan, dan tutup jendela pribadi apa pun yang sudah Anda buka sebelumnya. Jangan pernah keluar dari CLI untuk melakukan ini: keluar akan mencabut sesi masuk yang tersimpan, dan akun itu harus ditambahkan lagi.

Untuk menyalin login langganan Anda ke mesin Omarchy lain melalui SSH, jalankan `omarchy agent account copy user@laptop`. Pengirim menyediakan penerima sementara ketika tujuan tidak memiliki penerima yang terinstal, sehingga mesin Omarchy yang lebih lama dapat menerima akun tanpa pembaruan. Penerima yang terinstal didahulukan. Ini menyalin semua langganan Claude, Codex, dan Grok; tambahkan nama provider untuk memilihnya, seperti pada `omarchy agent account copy laptop claude`. Nama akun dan ID perintah cocok dengan sumbernya, termasuk akun yang sudah ada di tujuan. Akun tujuan yang tidak terkait menerima akhiran angka jika namanya bertabrakan, dan pengaturan, skill, plugin, serta riwayat percakapan tetap lokal di setiap mesin.

Kredensial tujuan yang ada tetap disimpan. Akun sumber yang sudah masuk di sana namanya disinkronkan tanpa mengganti kredensialnya; akun lain ditambahkan di sampingnya. Untuk mengganti kredensial tersimpan untuk akun yang cocok, gunakan `omarchy agent account copy --replace laptop claude` setelah menutup sesi akun tersebut di tujuan. Tujuan yang masih baru juga mendapatkan akun aktif dan preferensi peralihan dari sumber; tujuan yang sudah mapan mempertahankan miliknya sendiri.

Kredensial berjalan melalui SSH dan disimpan dalam file pribadi di tujuan, jadi salin hanya ke mesin yang Anda percaya. Ini adalah penyalinan satu kali, bukan sinkronisasi yang berkelanjutan. Token refresh Codex dapat dirotasi oleh mesin lain, sehingga login hasil salinan membutuhkan pembaruan; sesi masuk terpisah tetap menjadi pilihan paling andal untuk penggunaan serentak di beberapa mesin. Lihat [panduan autentikasi akun Codex](https://developers.openai.com/codex/auth/ci-cd-auth).

Satu akun per provider aktif, dan setiap sesi baru dimulai sebagai akun itu: `cx`, `cy`, `claude`, `codex`, atau `grok` biasa, apa pun yang diluncurkan melalui `omarchy agent`, dan skrip atau editor yang menemukan CLI di `PATH`. Beralih dengan `omarchy agent account use work` (dan kembali dengan `omarchy agent account use main`), atau di panel dengan menekan nomor sebuah akun lalu `Enter` (atau mengklik bintangnya). Sesi Claude yang sedang berjalan juga beralih, mulai pesan berikutnya: setiap sesi Claude berjalan di `~/.claude`, yang selalu menyimpan sesi masuk akun aktif. Sesi Claude yang dimulai di folder milik akun itu sendiri oleh Omarchy yang lebih lama menyimpan sesi masuk tersebut hingga ia berhenti, jadi peralihan menyebutkan nama sesi-sesi itu dan selesai dengan sendirinya setelah mereka hilang. Sesi Codex dan Grok yang sedang berjalan tetap pada akun tempat mereka dimulai. Riwayat percakapan, pengaturan, skill, dan plugin dibagikan lintas akun, jadi `claude --continue` di folder yang sama melanjutkan dari tempat Anda berhenti di akun baru.

Dengan lebih dari satu akun, panel menampilkan batas setiap akun secara berdampingan, dengan bintang terisi pada akun yang sedang digunakan. Omarchy memberi tahu Anda ketika akun aktif melewati 95% dari sebuah batas, dan mengklik notifikasi beralih ke akun dengan ruang tersisa paling banyak. Ia tidak pernah beralih dengan sendirinya. Ubah ambang batasnya dengan `omarchy agent account threshold 90`. Jika setiap akun melampaui ambang batas, Anda akan mendengarnya sekali, beserta akun mana yang lebih dulu bebas. Selama akun aktif berada dalam 15 poin dari ambang batasnya (80% pada default), batasnya diperiksa setiap tiga menit, bukan setiap 15 menit.

`omarchy agent account list` menampilkan setiap akun dan batas terbarunya, `omarchy agent account remove work` melupakan satu akun, dan `omarchy agent account rename primary Hey` mengganti nama satu akun (atau klik nama akun di panel). Perintah-perintah ini bekerja pada akun agen default Anda; untuk menjangkau provider lain, sebutkan namanya terlebih dahulu, seperti pada `omarchy agent account use codex side`. Login yang sudah Anda miliki di `~/.claude` atau `~/.codex` adalah akun _Main_. Akun Codex tetap di tempatnya; akun Claude menunggu di foldernya sendiri selama akun lain aktif. Akun yang tidak digunakan selama lebih dari sekitar delapan jam dapat menampilkan _Sign-in required_; klik akun itu untuk memasukkan akun tersebut lagi langsung di panel, atau beralih kepadanya dan mulai sebuah sesi, yang menyegarkan sesi masuknya dengan sendirinya. Server MCP yang Anda tambahkan dengan `claude mcp add` menjangkau setiap akun Claude, karena semuanya berjalan di `~/.claude`; untuk Codex dan Grok, server yang Anda miliki ketika sebuah akun ditambahkan ikut serta ke akun itu, tetapi server setelahnya hanya menjangkau akun tempat Anda menambahkannya. Claude Desktop menyimpan sesi masuknya sendiri, dan alat Codex atau Grok yang dikonfigurasi dengan jalur absolut ke biner CLI tidak mengikuti peralihan. `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, atau `GROK_HOME` yang eksplisit didahulukan atas akun yang dipilih.

### Diagnosis crash

Omarchy mengawasi systemd-coredump untuk crash proses. Setelah Anda memilih agen default, program Anda mana pun yang melakukan dump core memunculkan notifikasi "Process crashed" — klik notifikasi itu, dan crash diserahkan kepada agen default Anda beserta skill omarchy-diagnose-crash milik Omarchy, yang memandu agen menetapkan fakta dari core dump dan memutuskan apakah crash itu layak dilaporkan ke upstream. Anda juga dapat menjalankannya secara manual terhadap PID mana pun dari `coredumpctl list` dengan `omarchy agent crash <pid>`.

Pengawasan ini aktif secara default. Matikan di bawah _Trigger > Toggle > Crash Capture Off_ (atau dengan `omarchy toggle crash-capture`) dan notifikasi berhenti; `omarchy agent crash <pid>` tetap bekerja secara manual.

Crash juga dapat dibungkam satu program pada satu waktu, yang merupakan hal yang ditawarkan diagnosis kepada Anda di akhir. `omarchy crash mute hyprland` menghentikan notifikasi untuk program itu saja, `omarchy crash mute hyprland off` mengembalikannya, dan `omarchy crash mute` sendiri menampilkan daftar apa yang telah Anda bungkam. Ia menerima jalur biner sama senangnya seperti namanya, jadi `omarchy crash mute /usr/bin/hyprland` melakukan hal yang sama. Kutip nama yang mengandung spasi, seperti pada `omarchy crash mute 'Some App'`. Segala sesuatu yang lain tetap memberi notifikasi, dan program yang dibungkam tetap crash — ini menyembunyikan pengingat, bukan memperbaiki apa pun.

### Aplikasi desktop

Menu _Install > AI_ juga membawa beberapa aplikasi AI grafis: Amp Desktop, Antigravity Desktop, aplikasi desktop ChatGPT, aplikasi desktop Claude (beta Linux dari Anthropic, dengan tab Chat, Cowork, dan Claude Code), Grok Bot untuk mengobrol dengan model xAI, Herdr Desktop, Hermes Desktop, OpenClaw, aplikasi desktop Perplexity, dan T3 Code. Grok Bot adalah aplikasi chat desktop. Agen coding adalah perintah `grok`.

Hermes Desktop adalah yang perlu diketahui, karena sebuah mesin memiliki satu Hermes, dan Hermes itu milik aplikasi: Hermes hanya pernah diinstal melalui aplikasi, dan perintah `hermes` yang dijalankan agen default adalah milik aplikasi. Memilih Hermes sebagai agen default menginstal hal yang sama seperti yang dilakukan entri _Install > AI_: paketnya, dan runtime Hermes di bawah `~/.hermes` yang disiapkan oleh installer Hermes sendiri, yang membutuhkan beberapa menit pada kali pertama. Runtime itulah satu-satunya Hermes yang digunakan perintah terminal `hermes`, agen default, dan aplikasi, dan ia memperbarui dirinya sendiri dengan `hermes update` alih-alih menunggu rilis Omarchy. Menginstalnya juga menyerahkan tema Omarchy kepada Hermes sebagai skin bernama `omarchy`, yang diikuti setiap permukaan Hermes saat Anda mengganti tema; pilih yang lain di bawah pengaturan Appearance Hermes atau dengan `/skin` jika Anda lebih suka ia tidak mengikutinya, dan Omarchy membiarkan pilihan itu sendiri. Menghapus aplikasi di bawah _Remove > AI_ menutup Hermes terlebih dahulu, termasuk gateway, membawa runtime itu pergi bersamanya, dan menyimpan chat, memori, dan skill yang ditulis Hermes untuk dirinya sendiri kecuali Anda menyuruhnya lain: ia bertanya, dengan default tidak, apakah data itu dan pengaturan koneksi Anda juga harus dihapus.

Pengalaman desktop OpenClaw adalah Control UI-nya, yang terbuka sebagai aplikasi web yang didukung oleh gateway lokalnya sendiri. OpenClaw tinggal di `~/.openclaw` dan memperbarui dirinya sendiri: gunakan tombol "Update Gateway" di Control UI atau jalankan `openclaw update`, dan gateway dimulai ulang pada versi baru. Omarchy hanya memilih rilis tempat instalasi baru dimulai. OpenClaw juga dapat menjadi agen default Anda: memilihnya dengan `omarchy default agent openclaw` menyiapkan salinan yang sama itu di `~/.openclaw`, dan agen membuka UI terminal OpenClaw yang terhubung ke gateway-nya. Menghapus OpenClaw di bawah _Remove > AI_ membawa layanan gateway dan aplikasi bersamanya lalu bertanya apakah `~/.openclaw` juga harus dihapus, karena di situlah chat dan kredensial Anda disimpan bersama OpenClaw itu sendiri dan runtime plugin yang diunduhnya; default-nya menyimpannya, dan menginstal OpenClaw lagi mengambilnya kembali.

Herdr Desktop adalah aplikasi desktop [Herdr](https://herdr.dev): ruang, tab, dan panel terminal dan agen coding yang tetap berjalan di core-nya ketika Anda menutup jendela. Ia berasal dari installer Herdr sendiri alih-alih paket, jadi ia tinggal di `~/.local/share/herdr-app`, membawa core-nya di `~/.local/bin/herdr-core` ketika Anda belum memilikinya, dan memperbarui keduanya sendiri. Ia berada di samping perintah `herdr` yang disertakan Omarchy pada `Super + Ctrl + Return` alih-alih menggantikannya, dan mendapatkan tombol langsung perintah itu: `Alt + Return` dan `Alt + Shift + Return` membagi panel ke bawah atau ke kanan, `Alt + Escape` menutupnya, `Ctrl + Alt + Arrow` berpindah antar panel, `Alt + 1..9` dan `Alt + Left/Right` memilih tab, dan `Alt + Up/Down` berpindah antar ruang. `Ctrl + 1..9` memilih ruang dan `Alt + Shift + Up/Down` melangkah melalui agen. Tombol awalan `Ctrl + Space` tetap khusus terminal, karena aplikasi tidak dapat menahan tombol Ctrl biasa untuk sebuah urutan. Omarchy menulis ini ke `~/.config/herdr-app/keys.json`, dan `omarchy-refresh-herdr-app` mengembalikannya. Menginstalnya memilih tema Omarchy Herdr, yang mengikuti tema Omarchy Anda sejak saat itu. Herdr menyimpan satu tema untuk mode terang dan satu untuk mode gelap, jadi setelah beralih antara tema Omarchy gelap dan terang, pilih Omarchy di pemilih tema Herdr sekali lagi untuk mode lainnya.

T3 Code berjalan dari rilis AppImage resminya di `~/.local/share/t3code` alih-alih dari paket, jadi ia memperbarui dirinya sendiri. Menginstalnya bertanya apakah akan memulai di kanal Stable atau Nightly; beralih nanti di pengaturan T3 Code. Thread dan pengaturan Anda tinggal di `~/.t3`, dan menghapus T3 Code di bawah _Remove > AI_ membawa mereka pergi bersamanya.

### Model lokal

Jalankan model terbuka di mesin Anda sendiri untuk agen coding Anda. Prompt dan kode Anda tetap di mesin; tidak ada yang dikirim ke model yang meninggalkannya. Mulai dengan:

```bash
omarchy models use best text
```

Itu menyiapkan model teks terbaik untuk mesin ini, jenis yang digunakan agen Anda. Model gambar, video, dan musik memiliki model terbaiknya sendiri: `omarchy models use best image`, `video`, atau `music`. Jalankan `omarchy models use best` untuk melihat pilihan setiap jenis untuk mesin ini.

Atau pilih + di panel agen: di bawah _Use a local model_ ia mencantumkan setiap model coding yang cocok untuk mesin ini, yang direkomendasikan pertama. Podman, yang menjalankan model, disertakan dengan Omarchy, begitu juga toolkit container NVIDIA pada mesin NVIDIA, yang memberi mereka GPU; jika salah satu hilang, penyiapan pertama menginstalnya. Omarchy kemudian memilih model yang direkomendasikan untuk mesin ini, mengunduhnya, dan memulainya. Harapkan unduhan berukuran puluhan GB dan sebagian besar memori mesin digunakan selama model berjalan: Flash Next menggunakan sekitar 100 GiB dengan konteks 256K penuhnya. Jika model lain memegang memori yang dibutuhkannya, model itu disiapkan dalam keadaan berhenti, siap dimulai setelah Anda menghentikan satu model. Model berhenti saat logout; hentikan sendiri ketika Anda membutuhkan memori untuk hal lain.

`omarchy models list` menampilkan pilihan dan menjelaskan mengapa beberapa tidak cocok. Untuk menyiapkan model lain, jalankan `omarchy models use <recipe>`. Saat ini, `qwen3.8-flash-next-gufo` dan `qwen3.8-27b-gufo` tersedia untuk mesin Strix Halo 128 GB; 27B menggunakan sekitar 40 GiB, jadi ia menyisakan ruang untuk pekerjaan lain. Pada laptop 64 GB dengan Arc B390 dari Intel, `qwen3.6-35b-a3b-llamacpp` berjalan dalam sekitar 30 GiB. Resep dan rekomendasi baru tiba dengan `omarchy update`, melalui paket.

Model coding yang Anda tambahkan mendapatkan barisnya sendiri di panel agen, di samping langganan Anda: putar untuk memulainya, jeda untuk menghentikannya dan membebaskan memorinya, tanda Tailscale untuk membagikannya dengan mesin lain di tailnet Anda selama ia berjalan, dan tombol terminal untuk membuka agen Anda padanya. Barisnya menunjukkan unduhan, pemuatan, atau penghentian saat berlangsung, dan menyatakan demikian ketika tidak ada cukup memori bebas untuk memulainya, atau menautkan ke log-nya ketika ia berhenti dengan error. Beberapa dapat berjalan sekaligus ketika mereka cocok bersama dalam memori. Tekan Delete pada baris yang dipilih untuk menghapus model dari mesin ini, termasuk unduhannya; + dapat menyiapkannya lagi. Model coding yang disiapkan dari terminal menunggu di bawah + sampai Anda menambahkannya, begitu juga model yang dijalankan mesin yang telah Anda pasangkan (`omarchy models pair <host>`).

Setiap model coding yang Anda siapkan juga mendapatkan entrinya sendiri di peluncur aplikasi, di bawah nama model dan dengan logo pembuatnya, dengan cara yang sama seperti masuk ke Claude, Codex, atau Grok menambahkan satu entri. Ia membuka agen Anda pada model tersebut, dan memulai model terlebih dahulu jika belum berjalan: terminal menampilkan model sedang dimuat dan menyerahkan kepada agen setelah model aktif. Menghapus model menghapus entrinya.

Tidak setiap model untuk coding. Model gambar, video, dan musik terbuka di Fantasi sebagai gantinya, aplikasi Omarchy untuk membuat gambar, video, dan musik dengan model yang berjalan di mesin ini, dan dikelola di sana atau dengan `omarchy models`.

Model tetap berjalan persis seperti saat disiapkan, jadi pembaruan Omarchy tidak pernah memulai ulang model di bawah agen Anda. Ketika Omarchy memiliki runtime yang lebih baru atau bobot yang lebih baru untuk model yang telah Anda siapkan, barisnya menampilkan tombol pembaruan: tekan tombol itu dan model disiapkan lagi di latar belakang, hanya mengunduh apa yang berubah, dan dimulai ulang pada versi baru. Model yang telah berhenti tetap berhenti. `omarchy models update` melakukan hal yang sama untuk setiap model dari terminal.

Dari baris perintah, `omarchy models start <recipe>` dan `omarchy models stop <recipe>` melakukan hal yang sama, `omarchy models status` menampilkan setiap model, dan `omarchy agent --local-model <recipe>` membuka model itu di pi, apa pun agen default Anda. Untuk menjadikan model lokal Anda sebagai yang dibuka hotkey agen, konsol Quake, dan _Make something_, jalankan `omarchy default agent local` atau beri bintang pada model yang sedang berjalan di panel agen. pi juga mencantumkan setiap model yang telah Anda siapkan, dan model di mesin yang telah Anda pasangkan, di pemilih modelnya sendiri, jadi `pi` biasa juga dapat menjangkau mereka. Klien yang kompatibel dengan OpenAI apa pun juga dapat terhubung: `status` menampilkan alamat setiap model (yang pertama adalah `http://127.0.0.1:11435/v1`), nama resep adalah modelnya, dan kuncinya ada di `~/.config/omarchy/agent-local/key`.

`omarchy models remove <recipe>` menghapus sebuah model dan unduhan yang tidak digunakan model lain.

Runtime pihak ketiga diberi label dengan penerbitnya. Omarchy menjalankan setiap model tanpa akses jaringan.

### LLM lokal

Omarchy merekomendasikan dua cara menjalankan model LLM lokal: LM Studio dan Ollama. LM Studio menyediakan antarmuka GUI untuk menemukan model open-weight, menginstalnya, dan menjalankannya. Ini cara yang bagus untuk memulai dengan mudah. Ollama menawarkan CLI untuk melakukan hal serupa. Tetapi jika Anda baru mengenal model lokal, saya akan mulai dengan LM Studio. Anda dapat menginstal salah satunya di bawah _Install > AI_ di Menu Omarchy.

### Skill Omarchy

Skill agen membantu AI menggunakan alat tertentu dengan cara tertentu, dan Omarchy menyertakan tujuh di antaranya. Skill omarchy mencakup penyesuaian sistem, seperti mengutak-atik konfigurasi Hyprland Anda atau menyesuaikan bilah. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app, dan omarchy-make-game mencakup pembuatan sesuatu yang baru, omarchy-contribute mencakup pelaporan bug atau pengiriman perbaikan ke upstream, dan omarchy-diagnose-crash mengerjakan core dump sebuah crash. Mereka ditautkan secara simbolis ke direktori skill untuk Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` dan setiap `~/.hermes/profiles/*/skills`), dan lokasi generik `~/.agents/skills`, jadi sebagian besar harness mengambil mereka secara otomatis. Folder skill milik Anda sendiri dengan nama yang sama didahulukan.

Tetapi Anda harus memperlakukan skill-skill ini sebagai eksperimental. Model yang berbeda akan menggunakannya dengan efek yang berbeda. Sebaiknya jalankan dalam mode rencana terlebih dahulu, sehingga Anda memiliki gambaran tentang apa yang ingin diubah agen. Lalu bersiaplah untuk mengembalikan perubahan atau bahkan menjalankan `omarchy reinstall configs`, jika agen mengacaukan segalanya.
