### Menginstal dan memperbarui agen

Kecuali Hermes dan OpenClaw, agen-agen ini menggunakan instalasi lazy dari mise: peluncuran pertama menginstal CLI, dan peluncuran berikutnya menggunakan kembali instalasi tersebut. mise juga memeriksa agen yang terinstal untuk rilis baru paling banyak sekali setiap empat jam, tepat sebelum ia dimulai atau di latar belakang pada prompt shell. Jika pembaruan itu gagal atau Anda sedang offline, versi yang terinstal yang berjalan. `omarchy update` memperbarui agen yang terinstal bersama seluruh Omarchy lainnya, dan `mup` memperbarui hanya alat yang dikelola mise.

Pembaru milik agen sendiri, seperti `claude update`, `codex update`, atau tombol pembaruan di sebuah aplikasi, tidak memperbarui instalasi yang dikelola mise. `codex update` gagal, dan `claude update` dapat melaporkan berhasil sambil menginstal salinan terpisah yang tidak dilacak oleh mise. Jika Anda lebih suka menggunakan installer dan pembaru bawaan agen, tambahkan ia ke `disable_tools`; lihat [Alat CLI yang sudah terinstal](18-development-tools.md#preinstalled-cli-tools).

Untuk menginstal semua alat lazy yang dikonfigurasi sebelum Anda membutuhkannya, jalankan `mise install --include-lazy`. Ini mencakup alat CLI default Omarchy lainnya serta agen-agen tersebut. Lihat [Alat CLI yang sudah terinstal](18-development-tools.md#preinstalled-cli-tools) untuk menginstal satu alat atau menggunakan instalasi Anda sendiri.

`grok` diinstal melalui paket `grok` first-party dari mise, dengan cara yang sama seperti `claude` dan `codex`. Jalankan `grok`, atau beri bintang di panel agen. Lewati installer `curl | bash` di x.ai. Jalur itu menaruh salinan kedua di `~/.grok/bin`, mendahulukannya di `PATH`, dan menimpa wrapper Omarchy.

`dsh` membuka UI browsernya di `127.0.0.1:3080`, dengan direktori peluncuran sebagai workspace default-nya. UI browsernya tidak menerima prompt awal, jadi `omarchy agent prompt` membukanya dengan prompt di clipboard Anda untuk ditempel. Omarchy memulainya dengan preset izin no-approval dari DeepSeek. DeepSeek Harness mengunggah log sesi ke DeepSeek saat Anda menggunakan API model resminya; matikan itu di bawah _Settings > General > Upload Session Log_ di UI browsernya. Feedback yang Anda kirimkan kepadanya juga diunggah bersama sesi, kecuali Anda memulainya dengan `DSH_TELEMETRY_MODE=DISABLED`.

### Agen default

Pilih agen default Anda dengan bintang di samping agen di panel agen, yang terisi pada yang default, atau dengan `omarchy default agent <name>`, yang juga menerima harness apa pun tanpa baris di sana. Jika agen belum terinstal, memilihnya akan menginstalnya terlebih dahulu, dan ia juga mendapatkan peluncurnya sendiri di peluncur aplikasi, di samping Agent. Omarchy yang baru terinstal mengundang Anda untuk menyiapkan satu dengan notifikasi satu kali, yang membuka panel agen.

Memilih Claude juga mencoba menyiapkan ekstensi browsernya untuk Chromium, Chrome, Brave, Brave Origin, dan Edge. Penyiapan ekstensi berlaku untuk semua pengguna dan mungkin meminta kata sandi sistem Anda; membatalkan atau instalasi ekstensi yang gagal tetap memilih dan meluncurkan Claude. Restart browser Anda, aktifkan ekstensi jika diminta, dan masuk ke Claude untuk menyelesaikan penyambungannya. Jalankan `/chrome` di Claude untuk memeriksa koneksi. Firefox dan Zen tidak mendukung ekstensi ini. Jika Claude sudah menjadi default Anda sebelum penyiapan ini ditambahkan, pilih lagi untuk menginstal ekstensi.

Setelah Anda memilih, `Super + Shift + Ctrl + A` meluncurkan agen default di jendela terminal khusus (atau memunculkan pemilih jika Anda belum memilih). Anda juga dapat meluncurkannya langsung ke sebuah tugas dengan `omarchy agent prompt "Review this project"`. Freebuff dan DeepSeek Harness tidak menerima prompt awal, jadi keduanya terbuka dengan prompt di clipboard Anda untuk ditempel sebagai gantinya. Agen yang diluncurkan dengan cara ini berjalan tanpa pengawasan dalam mode don't-stop-to-ask masing-masing, jadi bersiaplah karena mereka benar-benar akan melakukan sesuatu! MiniMax Code tidak memiliki mode seperti itu untuk sesi interaktifnya, jadi ia meminta izin seperti biasa. Dan karena agen menolak mengingat kepercayaan untuk direktori home Anda, peluncuran dari `$HOME` dimulai di `~/Work` sebagai gantinya.

Ada juga pintasan terminal: `a` menjalankan agen default secara inline di terminal saat ini, sementara `c`, `cx`, dan `cy` memulai OpenCode, Claude Code, dan Codex secara langsung (lagi-lagi dalam mode auto-approving mereka). Perubahan tema juga tersinkron ke agen: Claude Code, Pi, OpenCode, dan Hermes (setelah Omarchy menginstalnya) semuanya mengikuti saat Anda mengganti tema Omarchy.

### Instruksi agen Anda

Aturan pribadi untuk setiap agen ada di `~/.agents/AGENTS.md`, di samping skill bersama di `~/.agents/skills`. Buka dengan ikon dokumen di samping + di panel agen, atau `omarchy agent instructions --edit`, yang juga menautkannya ke setiap harness yang menyimpan file globalnya sendiri: `~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.pi/agent/AGENTS.md`, `~/.config/opencode/AGENTS.md`, `~/.copilot/copilot-instructions.md` milik Copilot, dan seterusnya. Crush dan Amp membaca tautan `~/.config/AGENTS.md`, sementara omp, Kimi, dan DeepSeek Harness membaca `~/.agents/AGENTS.md` secara langsung. Memilih agen default juga menautkannya. File instruksi yang sudah Anda miliki menjadi yang bersama jika belum ada; jika sudah ada, file itu disimpan di samping tautan sebagai `.bak`. Jalankan `omarchy agent instructions` untuk menautkan ulang setelah menginstal agen lain.

### Panel agen

Bar atas memiliki ikon agen. Sebelum Anda menyiapkan agen, panelnya menawarkan tiga cara untuk memulai: masuk ke langganan Claude, Codex, Grok, Gemini, Muse, Cursor, atau Copilot, atau di bawah More sebuah paket coding OpenCode Go, MiniMax, Synthetic, atau Z.ai; bayar sesuai pemakaian dengan Fireworks, OpenCode Zen and Go, OpenRouter, atau di bawah More DeepSeek atau provider lain mana pun yang dapat dimasuki OpenCode, semuanya berjalan di OpenCode; atau jalankan model terbaik untuk komputer Anda, saat ada yang cocok dengannya. Yang pertama Anda selesaikan menjadi agen default Anda, dan + di panel menawarkan tiga cara yang sama di kemudian hari. Setelah itu, panel menaruh setiap langganan di satu halaman: setiap agen dan akun beserta paketnya, sebuah meter untuk masing-masing batas sesi 5 jam dan batas mingguannya beserta waktu hingga ia direset (arahkan kursor untuk persentase pastinya), atau sisa saldo prabayar, di bawah sebuah baris yang berganti-ganti melalui apa yang telah Anda gunakan di semua itu, seperti token minggu ini dan model yang paling sering Anda gunakan. Di bawah _Make something cool_ ia menawarkan prompt pemula untuk tema, plugin, aplikasi, atau game baru yang menyerahkan tugas kepada agen default Anda. Aplikasi dibangun dengan cara yang sama seperti Hype, Monologue, dan Omacut milik Omarchy sendiri, dalam C++ dan Qt Quick, mengikuti skill agen omarchy-make-app, dan compiler serta bagian Qt yang mereka butuhkan sudah terinstal. Game adalah satu halaman three.js di `~/Games/vibes`, mengikuti skill agen omarchy-make-game, dan semuanya terbuka dari satu peluncur Game Vibes dalam tema saat ini; mereka memuat three.js dari web, jadi mereka membutuhkan koneksi untuk memulai. Claude Code, Codex, Grok, Kimi, Cursor dan jatah Grok Bot-nya, GitHub Copilot, Muse, Gemini (melalui Antigravity), dan Devin tercakup sejak awal beserta batasnya, Kimchi beserta paketnya, kredit prabayar, dan anggaran pengeluarannya, dan Hermes, Mistral Vibe, dan Qwen Code menunjukkan sesi dan token mereka setelah Anda menggunakannya. Paket dan kunci provider yang Anda gunakan melalui pi, omp, atau opencode juga muncul: OpenCode Zen and Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan, dan Synthetic beserta batasnya; OpenRouter dan DeepSeek beserta saldo prabayarnya; Fireworks beserta pengeluarannya selama 30 hari terakhir. Model coding yang Anda jalankan di hardware Anda sendiri mendapatkan barisnya sendiri, dan token mereka juga dihitung ke total, seperti yang dijelaskan di bawah [Model lokal](#local-models). Setiap agen dihitung sekali, di bawah siapa pun yang menagihnya, berapa pun banyaknya harness yang Anda gunakan untuk menjalankannya.

Klik kiri ikon bar atau tekan `Super + Ctrl + X` untuk panel, klik kanan untuk meluncurkan agen default Anda, dan klik tengah untuk menyegarkan. Catatan penggunaan di baliknya dibuat ulang setiap 15 menit oleh `omarchy agent usage update`, dan panel bahkan dapat menggabungkan penggunaan dari mesin Anda yang lain melalui folder yang disinkronkan. Lihat README di bawah `$OMARCHY_PATH/shell/plugins/agents/` untuk pengaturan lengkapnya.

### Beberapa langganan

Jika Anda membayar lebih dari satu paket Claude, Codex, atau Grok — misalnya Max pribadi dan satu untuk pekerjaan — Omarchy dapat menjaga semuanya tetap masuk dan berpindah di antaranya. Tambahkan langganan dengan + di panel agen, yang memandu Anda melewatinya langsung di sana, atau dengan `omarchy agent account add claude Work` (atau `codex`, atau `grok`). + dan perintah yang sama juga masuk ke Gemini (`gemini`) dan OpenCode (`opencode`), dan menyimpan kunci API Fireworks (`fireworks`) atau OpenRouter (`openrouter`) di OpenCode; perintah itu juga masuk ke Copilot (`copilot`), Cursor (`cursor`), dan Muse (`muse`). Itu masing-masing hanya menyimpan satu kali masuk. Ia menginstal CLI jika belum ada. Akun pertama untuk sebuah provider masuk melalui browser normal Anda, tepat di tempat CLI selalu mencarinya. Setiap akun setelah itu masuk melalui jendela pribadi, sehingga akun yang sudah dimasuki browser Anda tidak terambil secara tidak sengaja; masuk di sana sebagai akun yang sedang Anda tambahkan, dan tutup dulu jendela pribadi mana pun yang sudah Anda buka. Jangan pernah keluar dari CLI untuk melakukan ini: keluar akan mencabut sesi masuk yang tersimpan, dan akun itu harus ditambahkan lagi.

Untuk menyalin login langganan Anda ke mesin Omarchy lain melalui SSH, jalankan `omarchy agent account copy user@laptop`. Pengirim menyediakan penerima sementara saat tujuan tidak memiliki yang terinstal, sehingga mesin Omarchy yang lebih lama dapat menerima akun tanpa pembaruan. Penerima yang terinstal lebih diutamakan. Ini menyalin semua langganan Claude, Codex, dan Grok; tambahkan nama provider untuk memilihnya, seperti dalam `omarchy agent account copy laptop claude`. Nama akun dan ID perintah cocok dengan sumber, termasuk akun yang sudah ada di tujuan. Akun tujuan yang tidak terkait menerima akhiran numerik jika namanya bertabrakan, dan pengaturan, skill, plugin, dan riwayat percakapan tetap lokal di setiap mesin.

Kredensial tujuan yang sudah ada tetap disimpan. Akun sumber yang sudah masuk di sana namanya disinkronkan tanpa mengganti kredensialnya; akun lain ditambahkan di sampingnya. Untuk mengganti kredensial tersimpan untuk akun yang cocok, gunakan `omarchy agent account copy --replace laptop claude` setelah menghentikan sesi akun itu di tujuan. Tujuan yang masih baru juga mendapatkan akun aktif dan preferensi perpindahan dari sumber; tujuan yang sudah lama digunakan mempertahankan miliknya sendiri.

Kredensial berjalan melalui SSH dan disimpan dalam file pribadi di tujuan, jadi salin hanya ke mesin yang Anda percayai. Ini adalah salinan satu kali, bukan sinkronisasi berkelanjutan. Token refresh Codex dapat dirotasi oleh mesin lain, sehingga login yang disalin memerlukan pembaruan; sesi masuk terpisah tetap menjadi pilihan paling andal untuk penggunaan serentak di beberapa mesin. Lihat [panduan autentikasi akun dari Codex](https://developers.openai.com/codex/auth/ci-cd-auth).

Satu akun per provider yang aktif, dan setiap sesi baru dimulai sebagai akun itu: `cx`, `cy`, `claude`, `codex`, atau `grok` biasa, apa pun yang diluncurkan melalui `omarchy agent`, dan skrip atau editor yang menemukan CLI di `PATH`. Berpindahlah dengan `omarchy agent account use work` (dan kembali dengan `omarchy agent account use main`), atau di panel dengan menekan nomor akun lalu `Enter` (atau mengklik bintangnya). Sesi Claude yang sedang berjalan juga berpindah, mulai pesan berikutnya: setiap sesi Claude berjalan di `~/.claude`, yang selalu menyimpan sesi masuk akun aktif. Sesi Claude yang dimulai di folder akunnya sendiri oleh Omarchy yang lebih lama menyimpan sesi masuk itu hingga ia berhenti, jadi perpindahan menyebutkan sesi-sesi tersebut dan selesai dengan sendirinya setelah mereka hilang. Sesi Codex dan Grok yang sedang berjalan tetap pada akun yang mereka mulai dengannya. Riwayat percakapan, pengaturan, skill, dan plugin dibagikan antar akun, jadi `claude --continue` di folder yang sama melanjutkan dari tempat Anda berhenti di akun baru.

Dengan lebih dari satu akun, panel menampilkan batas setiap akun berdampingan, dengan bintang terisi pada yang sedang digunakan. Omarchy memberi tahu Anda saat akun aktif melewati 95% dari sebuah batas, dan mengklik notifikasi berpindah ke akun dengan ruang paling longgar. Ia tidak pernah berpindah dengan sendirinya. Ubah ambang batas dengan `omarchy agent account threshold 90`. Jika setiap akun melewati ambang batas, Anda akan mendengarnya sekali, beserta akun mana yang lebih dulu terbebas. Saat akun aktif berada dalam jarak 15 poin dari ambang batasnya (80% pada default), batasnya diperiksa setiap tiga menit, bukan setiap 15 menit.

`omarchy agent account list` menampilkan setiap akun dan batas terbarunya, `omarchy agent account remove work` melupakan satu akun, dan `omarchy agent account rename primary Hey` mengganti nama satu akun (atau klik nama akun di panel). Perintah-perintah ini bekerja pada akun agen default Anda; untuk mencapai provider lain, sebutkan namanya terlebih dahulu, seperti dalam `omarchy agent account use codex side`. Login yang sudah Anda miliki di `~/.claude` atau `~/.codex` adalah akun _Main_. Punya Codex tetap di tempatnya; punya Claude menunggu di foldernya sendiri saat akun lain aktif. Akun yang dibiarkan tidak digunakan selama lebih dari sekitar delapan jam dapat menampilkan _Sign-in required_; klik akun itu untuk masuk kembali ke akun tersebut langsung di panel, atau berpindah ke akun itu dan mulai sesi, yang menyegarkan sesi masuk dengan sendirinya. Server MCP yang Anda tambahkan dengan `claude mcp add` mencapai setiap akun Claude, karena mereka semua berjalan di `~/.claude`; untuk Codex dan Grok, server yang Anda miliki saat akun ditambahkan ikut ke akun itu, tetapi server setelahnya hanya mencapai akun tempat Anda menambahkannya. Claude Desktop menyimpan sesi masuknya sendiri, dan alat Codex atau Grok yang dikonfigurasi dengan path absolut ke binari CLI tidak mengikuti perpindahan. `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, atau `GROK_HOME` yang eksplisit lebih diutamakan daripada akun yang dipilih.

### Diagnosis crash

Omarchy mengawasi systemd-coredump untuk crash proses. Setelah Anda memilih agen default, program Anda mana pun yang melakukan dump core akan memunculkan notifikasi "Process crashed" — klik notifikasi itu, dan crash diserahkan kepada agen default Anda beserta skill omarchy-diagnose-crash dari Omarchy, yang memandu agen melalui penetapan fakta dari core dump dan memutuskan apakah crash tersebut layak dilaporkan ke upstream. Anda juga dapat menjalankannya secara manual terhadap PID mana pun dari `coredumpctl list` dengan `omarchy agent crash <pid>`.

Pengawasan ini aktif secara default. Matikan di bawah _Trigger > Toggle > Crash Capture Off_ (atau dengan `omarchy toggle crash-capture`) dan notifikasi berhenti; `omarchy agent crash <pid>` tetap bekerja secara manual.

Crash juga dapat dibungkam satu program pada satu waktu, yang merupakan hal yang ditawarkan diagnosis kepada Anda di akhir. `omarchy crash mute hyprland` menghentikan notifikasi hanya untuk program itu, `omarchy crash mute hyprland off` mengembalikannya, dan `omarchy crash mute` sendiri menampilkan apa yang telah Anda bungkam. Ia menerima path binari sama senangnya seperti namanya, jadi `omarchy crash mute /usr/bin/hyprland` melakukan hal yang sama. Kutip nama yang mengandung spasi, seperti dalam `omarchy crash mute 'Some App'`. Semua yang lain tetap memberi notifikasi, dan program yang dibungkam tetap crash — ini menyembunyikan pengingat, ini tidak memperbaiki apa pun.

### Aplikasi desktop

Menu _Install > AI_ juga membawa beberapa aplikasi AI grafis: Amp Desktop, Antigravity Desktop, aplikasi desktop ChatGPT, aplikasi desktop Claude (beta Linux dari Anthropic, dengan tab Chat, Cowork, dan Claude Code), Grok Bot untuk mengobrol dengan model xAI, Herdr Desktop, Hermes Desktop, OpenClaw, aplikasi desktop Perplexity, dan T3 Code. Grok Bot adalah aplikasi obrolan desktop. Agen coding adalah perintah `grok`.

Hermes Desktop adalah yang perlu diketahui, karena sebuah mesin memiliki satu Hermes, dan Hermes itu adalah milik aplikasi: Hermes hanya pernah diinstal melalui aplikasi, dan perintah `hermes` yang dijalankan agen default adalah milik aplikasi. Memilih Hermes sebagai agen default menginstal hal yang sama seperti yang dilakukan entri _Install > AI_: paketnya, dan runtime Hermes di bawah `~/.hermes` yang disiapkan oleh installer Hermes sendiri, yang memakan waktu beberapa menit pada kali pertama. Runtime itu adalah satu-satunya Hermes yang digunakan perintah terminal `hermes`, agen default, dan aplikasi, dan ia memperbarui dirinya sendiri dengan `hermes update` daripada menunggu rilis Omarchy. Menginstalnya juga memberikan Hermes tema Omarchy sebagai skin bernama `omarchy`, yang diikuti setiap permukaan Hermes saat Anda mengganti tema; pilih yang lain di bawah pengaturan Appearance Hermes atau dengan `/skin` jika Anda lebih suka ia tidak melakukannya, dan Omarchy membiarkan pilihan itu. Menghapus aplikasi di bawah _Remove > AI_ menutup Hermes terlebih dahulu, termasuk gateway, membawa runtime itu bersamanya, dan menyimpan obrolan, memori, dan skill yang ditulis Hermes untuk dirinya sendiri kecuali Anda menyuruhnya sebaliknya: ia bertanya, dengan default tidak, apakah data itu dan pengaturan koneksi Anda juga harus dihapus.

Pengalaman desktop OpenClaw adalah Control UI-nya, yang terbuka sebagai aplikasi web yang didukung oleh gateway lokalnya sendiri. OpenClaw tinggal di `~/.openclaw` dan memperbarui dirinya sendiri: gunakan tombol "Update Gateway" di Control UI atau jalankan `openclaw update`, dan gateway restart pada versi baru. Omarchy hanya memilih rilis tempat instalasi baru dimulai. OpenClaw juga dapat menjadi agen default Anda: memilihnya dengan `omarchy default agent openclaw` menyiapkan salinan yang sama itu di `~/.openclaw`, dan agen membuka UI terminal OpenClaw yang terhubung ke gateway-nya. Menghapus OpenClaw di bawah _Remove > AI_ membawa layanan gateway dan aplikasi bersamanya lalu bertanya apakah `~/.openclaw` juga harus dihapus, karena di sana tersimpan obrolan dan kredensial Anda di samping OpenClaw itu sendiri dan runtime plugin yang ia unduh; default-nya menyimpannya, dan menginstal OpenClaw lagi akan mengambilnya kembali.

Herdr Desktop adalah aplikasi desktop [Herdr](https://herdr.dev): space, tab, dan pane dari terminal dan agen coding yang terus berjalan di core-nya saat Anda menutup jendela. Ia berasal dari installer Herdr sendiri daripada sebuah paket, jadi ia tinggal di `~/.local/share/herdr-app`, membawa core-nya di `~/.local/bin/herdr-core` saat Anda belum memilikinya, dan memperbarui keduanya sendiri. Ia berada di samping perintah `herdr` yang dikirim Omarchy pada `Super + Ctrl + Return` daripada menggantikannya, dan mendapatkan tombol langsung perintah itu: `Alt + Return` dan `Alt + Shift + Return` membagi pane ke bawah atau ke kanan, `Alt + Escape` menutupnya, `Ctrl + Alt + Arrow` berpindah antar pane, `Alt + 1..9` dan `Alt + Left/Right` memilih tab, dan `Alt + Up/Down` berpindah antar space. `Ctrl + 1..9` memilih space dan `Alt + Shift + Up/Down` melangkah melalui agen. Tombol awalan `Ctrl + Space` tetap hanya untuk terminal, karena aplikasi tidak dapat menahan tombol Ctrl biasa untuk sebuah urutan. Omarchy menulis ini ke `~/.config/herdr-app/keys.json`, dan `omarchy-refresh-herdr-app` mengembalikannya. Menginstalnya memilih tema Omarchy dari Herdr, yang mengikuti tema Omarchy Anda sejak saat itu. Herdr menyimpan satu tema untuk mode terang dan satu untuk mode gelap, jadi setelah berpindah antara tema Omarchy gelap dan terang, pilih Omarchy di pemilih tema Herdr sekali lagi untuk mode lainnya.

T3 Code berjalan dari rilis AppImage resminya di `~/.local/share/t3code` daripada dari sebuah paket, jadi ia memperbarui dirinya sendiri. Menginstalnya bertanya apakah akan memulai pada saluran Stable atau Nightly; berpindahlah nanti di pengaturan T3 Code. Thread dan pengaturan Anda tinggal di `~/.t3`, dan menghapus T3 Code di bawah _Remove > AI_ membawanya bersamanya.

### Model lokal

Jalankan model terbuka di mesin Anda sendiri untuk agen coding Anda. Prompt dan kode Anda tetap di mesin; tidak ada yang dikirim ke model yang meninggalkannya. Mulai dengan:

```bash
omarchy models use best text
```

Itu menyiapkan model teks terbaik untuk mesin ini, jenis yang digunakan agen Anda. Model gambar, video, dan musik memiliki yang terbaiknya sendiri: `omarchy models use best image`, `video` atau `music`. Jalankan `omarchy models use best` untuk melihat pilihan setiap jenis untuk mesin ini.

Atau pilih + di panel agen: di bawah _Use a local model_ ia menampilkan setiap model coding yang cocok dengan mesin ini, yang direkomendasikan pertama. Podman, yang menjalankan model, disertakan dengan Omarchy, begitu juga toolkit container NVIDIA di mesin NVIDIA, yang memberi mereka GPU; jika salah satunya hilang, penyiapan pertama menginstalnya. Omarchy lalu memilih model yang direkomendasikan untuk mesin ini, mengunduhnya, dan memulainya. Harapkan unduhan puluhan GB dan sebagian besar memori mesin digunakan saat model berjalan: Flash Next menggunakan sekitar 100 GiB dengan konteks 256K penuhnya. Jika model lain menahan memori yang ia butuhkan, ia disiapkan dalam keadaan berhenti, siap dimulai setelah Anda menghentikan satu model. Model berhenti saat logout; hentikan sendiri saat Anda membutuhkan memori untuk hal lain.

`omarchy models list` menampilkan pilihan dan menjelaskan mengapa beberapa tidak cocok. Untuk menyiapkan yang lain, jalankan `omarchy models use <recipe>`. Saat ini, `qwen3.8-flash-next-gufo` dan `qwen3.8-27b-gufo` tersedia untuk mesin Strix Halo 128 GB; yang 27B memakai sekitar 40 GiB, jadi ia menyisakan ruang untuk pekerjaan lain. Di laptop 64 GB dengan Arc B390 dari Intel, `qwen3.6-35b-a3b-llamacpp` berjalan dalam sekitar 30 GiB. Resep dan rekomendasi baru tiba dengan `omarchy update`, melalui paket.

Model coding yang Anda tambahkan mendapatkan barisnya sendiri di panel agen, di samping langganan Anda: putar untuk memulainya, jeda untuk menghentikannya dan membebaskan memorinya, tanda Tailscale untuk membagikannya dengan mesin lain di tailnet Anda saat ia berjalan, dan tombol terminal untuk membuka agen Anda di model itu. Barisnya menampilkan unduhan, pemuatan, atau penghentian saat berlangsung, dan menyatakan demikian saat tidak ada cukup memori bebas untuk memulainya, atau menautkan ke lognya saat ia berhenti dengan error. Beberapa dapat berjalan sekaligus saat mereka cocok di memori bersama-sama. Tekan Delete pada baris yang dipilih untuk menghapus model dari mesin ini, unduhan dan semuanya; + dapat menyiapkannya lagi. Model coding yang disiapkan dari terminal menunggu di bawah + hingga Anda menambahkannya, begitu juga model yang dijalankan mesin yang telah Anda pasangkan (`omarchy models pair <host>`).

Setiap model coding yang Anda siapkan juga mendapatkan entrinya sendiri di peluncur aplikasi, di bawah nama model dan dengan logo pembuatnya, dengan cara yang sama seperti masuk ke Claude, Codex, atau Grok menambahkan satu. Ia membuka agen Anda pada model itu, dan memulai model terlebih dahulu jika belum berjalan: terminal menampilkan ia sedang dimuat dan menyerahkan kepada agen setelah ia siap. Menghapus model menghapus entrinya.

Tidak setiap model untuk coding. Model gambar, video, dan musik terbuka di Fantasi sebagai gantinya, aplikasi Omarchy untuk membuat gambar, video, dan musik dengan model yang berjalan di mesin ini, dan dikelola di sana atau dengan `omarchy models`.

Sebuah model tetap berjalan persis seperti saat ia disiapkan, jadi pembaruan Omarchy tidak pernah merestart satu model di bawah agen Anda. Saat Omarchy memiliki runtime yang lebih baru atau bobot yang lebih baru untuk model yang telah Anda siapkan, barisnya menampilkan tombol pembaruan: tekan tombol itu dan model disiapkan lagi di latar belakang, hanya mengunduh apa yang berubah, dan restart pada versi baru. Model yang berhenti tetap berhenti. `omarchy models update` melakukan hal yang sama untuk setiap model dari terminal.

Dari baris perintah, `omarchy models start <recipe>` dan `omarchy models stop <recipe>` melakukan hal yang sama, `omarchy models status` menampilkan setiap model, dan `omarchy agent --local-model <recipe>` membuka model itu di pi, apa pun agen default Anda. Untuk menjadikan model lokal Anda apa yang dibuka oleh hotkey agen, konsol Quake, dan _Make something_, jalankan `omarchy default agent local` atau beri bintang pada model yang sedang berjalan di panel agen. pi juga menampilkan setiap model yang telah Anda siapkan, dan yang ada di mesin yang telah Anda pasangkan, di pemilih modelnya sendiri, jadi `pi` biasa juga dapat mencapainya. Klien yang kompatibel dengan OpenAI mana pun juga dapat terhubung: `status` menampilkan alamat setiap model (yang pertama adalah `http://127.0.0.1:11435/v1`), nama resep adalah modelnya, dan kuncinya ada di `~/.config/omarchy/agent-local/key`.

`omarchy models remove <recipe>` menghapus sebuah model dan unduhan yang tidak digunakan model lain.

Runtime pihak ketiga diberi label dengan penerbitnya. Omarchy menjalankan setiap model tanpa akses jaringan.

### LLM lokal

Omarchy merekomendasikan dua cara menjalankan model LLM lokal: LM Studio dan Ollama. LM Studio menyediakan antarmuka GUI untuk menemukan model open-weight, menginstalnya, dan menjalankannya. Itu cara yang bagus untuk memulai dengan mudah. Ollama menawarkan CLI untuk melakukan hal serupa. Tetapi jika Anda baru mengenal model lokal, saya akan mulai dengan LM Studio. Anda dapat menginstal salah satunya di bawah _Install > AI_ di Omarchy Menu.

### Skill Omarchy

Skill agen membantu AI menggunakan alat tertentu dengan cara tertentu, dan Omarchy mengirimkan tujuh di antaranya. Skill omarchy mencakup penyesuaian sistem, seperti mengutak-atik config Hyprland Anda atau menyesuaikan bar. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app, dan omarchy-make-game mencakup membuat sesuatu yang baru, omarchy-contribute mencakup melaporkan bug atau mengirim perbaikan ke upstream, dan omarchy-diagnose-crash menelusuri core dump dari sebuah crash. Mereka disymlink ke direktori skill untuk Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` dan setiap `~/.hermes/profiles/*/skills`), dan lokasi generik `~/.agents/skills`, jadi sebagian besar harness mengambilnya secara otomatis. Folder skill Anda sendiri dengan nama yang sama lebih diutamakan.

Tetapi Anda harus memperlakukan skill-skill ini sebagai eksperimental. Model yang berbeda akan menggunakannya dengan efek yang berbeda. Sebaiknya jalankan dalam mode plan terlebih dahulu, agar Anda memiliki gambaran tentang apa yang ingin diubah oleh agen. Lalu bersiaplah untuk mengembalikan perubahan atau bahkan menjalankan `omarchy reinstall configs`, jika agen membuat semuanya berantakan.
