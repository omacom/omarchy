### Menginstal dan memperbarui agen

Selain Hermes, agen-agen ini menggunakan instalasi lazy dari mise: peluncuran pertama menginstal CLI, dan peluncuran berikutnya menggunakannya kembali. mise juga memeriksa apakah ada rilis baru untuk agen yang terinstal paling banyak sekali setiap empat jam, tepat sebelum agen dimulai atau di latar belakang pada prompt shell. Jika pembaruan itu gagal atau Anda sedang offline, versi yang terinstal yang dijalankan. `omarchy update` memperbarui agen yang terinstal bersama dengan bagian Omarchy lainnya, dan `mup` hanya memperbarui tool yang dikelola mise.

Updater bawaan agen itu sendiri, seperti `claude update`, `codex update`, atau tombol update di sebuah aplikasi, tidak memperbarui instalasi yang dikelola mise. `codex update` gagal, dan `claude update` dapat melaporkan berhasil sambil menginstal salinan terpisah yang tidak dilacak mise. Jika Anda lebih suka menggunakan installer dan updater bawaan agen, tambahkan ke `disable_tools`; lihat [Tool CLI yang sudah terinstal sebelumnya](18-development-tools.md#preinstalled-cli-tools).

Untuk menginstal semua tool lazy yang dikonfigurasi sebelum Anda membutuhkannya, jalankan `mise install --include-lazy`. Ini termasuk tool CLI default Omarchy lainnya serta agen-agen tersebut. Lihat [Tool CLI yang sudah terinstal sebelumnya](18-development-tools.md#preinstalled-cli-tools) untuk menginstal satu tool atau menggunakan instalasi Anda sendiri.

`grok` diinstal melalui package `grok` pihak-pertama dari mise, dengan cara yang sama seperti `claude` dan `codex`. Jalankan `grok`, atau pilih di bawah _Agent > Harness_. Lewati installer `curl | bash` di x.ai. Jalur itu menempatkan salinan kedua di `~/.grok/bin`, menambahkannya di awal `PATH`, dan menimpa wrapper Omarchy.

`dsh` membuka UI browser-nya di `127.0.0.1:3080`, dengan direktori peluncuran sebagai workspace default-nya. UI browser-nya tidak menerima prompt awal, jadi `omarchy agent prompt` membukanya dengan prompt di clipboard Anda untuk ditempel. Omarchy memulainya dengan preset izin no-approval dari DeepSeek. DeepSeek Harness mengunggah log sesi ke DeepSeek ketika Anda menggunakan API model resminya; matikan itu di bawah _Settings > General > Upload Session Log_ di UI browser-nya. Feedback yang Anda kirimkan kepadanya juga diunggah bersama sesi, kecuali Anda memulainya dengan `DSH_TELEMETRY_MODE=DISABLED`.

### Agen default

Pilih agen default Anda dengan `omarchy default agent <name>` atau di bawah _Agent > Harness_ di Omarchy Menu (`Super + Space`). Jika agen belum terinstal, memilihnya akan menginstalnya terlebih dahulu. Omarchy baru akan mengundang Anda untuk membuat pilihan ini dengan notifikasi satu kali.

Memilih Claude juga mencoba menyiapkan ekstensi browser-nya untuk Chromium, Chrome, Brave, Brave Origin, dan Edge. Penyiapan ekstensi berlaku untuk semua pengguna dan mungkin meminta kata sandi sistem Anda; membatalkan atau gagal menginstal ekstensi tetap akan memilih dan meluncurkan Claude. Restart browser Anda, aktifkan ekstensi jika diminta, dan masuk ke Claude untuk menyelesaikan penyambungannya. Jalankan `/chrome` di Claude untuk memeriksa koneksinya. Firefox dan Zen tidak mendukung ekstensi ini. Jika Claude sudah menjadi default Anda sebelum penyiapan ini ditambahkan, pilih lagi untuk menginstal ekstensinya.

Setelah Anda memilih, `Super + Shift + Ctrl + A` meluncurkan agen default di jendela terminal khusus (atau memunculkan pemilih jika Anda belum memilih). Anda juga dapat meluncurkannya langsung ke sebuah tugas dengan `omarchy agent prompt "Review this project"`. Freebuff dan DeepSeek Harness tidak menerima prompt awal, jadi keduanya dibuka dengan prompt di clipboard Anda untuk ditempel sebagai gantinya. Agen yang diluncurkan dengan cara ini berjalan tanpa pengawasan dalam mode don't-stop-to-ask masing-masing, jadi bersiaplah karena mereka benar-benar akan melakukan sesuatu! MiniMax Code tidak memiliki mode seperti itu untuk sesi interaktifnya, jadi ia meminta izin seperti biasa. Dan karena agen menolak mengingat kepercayaan untuk direktori home Anda, peluncuran dari `$HOME` dimulai di `~/Work` sebagai gantinya.

Ada juga pintasan terminal: `a` menjalankan agen default secara inline di terminal saat ini, sementara `c`, `cx`, dan `cy` memulai OpenCode, Claude Code, dan Codex secara langsung (lagi-lagi dalam mode auto-approving mereka). Perubahan tema juga tersinkron ke agen: Claude Code, Pi, OpenCode, dan Hermes (setelah Omarchy menginstalnya) semuanya mengikuti ketika Anda mengganti tema Omarchy.

### Instruksi agen Anda

Aturan pribadi untuk setiap agen dimasukkan ke `~/.agents/AGENTS.md`, di samping skill bersama di `~/.agents/skills`. Buka di bawah _Agent > Instructions_, yang juga menautkannya ke setiap harness yang menyimpan file globalnya sendiri: `~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.pi/agent/AGENTS.md`, `~/.config/opencode/AGENTS.md`, `~/.copilot/copilot-instructions.md` milik Copilot, dan seterusnya. Crush dan Amp membaca tautan `~/.config/AGENTS.md`, sementara omp, Kimi, dan DeepSeek Harness membaca `~/.agents/AGENTS.md` secara langsung. Memilih agen default juga menautkannya. File instruksi yang sudah Anda miliki menjadi file bersama jika belum ada; jika tidak, file itu disimpan di samping tautan sebagai `.bak`. Jalankan `omarchy agent instructions` untuk menautkan ulang setelah menginstal agen lain.

### Panel agen

Bar atas memiliki ikon agen. Sebelum Anda menyiapkan agen, panelnya memandu Anda untuk masuk ke Claude, Codex, atau Grok, dan yang pertama menjadi agen default Anda. Setelah itu, panel menempatkan setiap langganan dalam satu halaman: setiap agen dan akun dengan paketnya, meter untuk setiap batas sesi 5 jam dan batas mingguannya beserta waktu hingga reset (arahkan kursor untuk persentase pastinya), atau sisa saldo prabayar, di bawah baris yang berganti-ganti menampilkan apa yang telah Anda gunakan di semua agen, seperti token minggu ini dan model yang paling sering Anda gunakan. Di bawah _Make something_ panel menawarkan prompt pemula untuk tema, plugin, atau aplikasi baru yang menyerahkan tugas tersebut ke agen default Anda. Aplikasi dibuat dengan cara yang sama seperti Hype, Monologue, dan Omacut milik Omarchy sendiri, dalam C++ dan Qt Quick, mengikuti skill agen omarchy-app, dan compiler serta komponen Qt yang mereka butuhkan sudah terinstal. Claude Code, Codex, Grok, Kimi, Cursor dan jatah Grok Bot-nya, GitHub Copilot, Muse, Antigravity, Kimchi, dan Devin tercakup langsung dengan batas-batasnya, dan Hermes, Mistral Vibe, dan Qwen Code menampilkan sesi dan token mereka setelah Anda menggunakannya. Paket provider dan key yang Anda gunakan melalui pi, omp, atau opencode juga muncul: OpenCode Zen dan Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan, dan Synthetic dengan batas-batasnya; Fireworks, OpenRouter, dan DeepSeek dengan saldo prabayarnya; dan model yang Anda jalankan di hardware Anda sendiri di bawah Local models. Setiap agen dihitung sekali, di bawah pihak yang menagihnya, berapa pun harness yang Anda gunakan untuk menjalankannya.

Klik kiri ikon bar untuk panel, klik kanan untuk meluncurkan agen default Anda. Catatan penggunaan di baliknya dibuat ulang setiap 15 menit oleh `omarchy agent usage-update`, dan panel bahkan dapat menggabungkan penggunaan dari mesin Anda yang lain melalui folder yang disinkronkan. Lihat README di bawah `$OMARCHY_PATH/shell/plugins/agents/` untuk pengaturan lengkapnya.

### Beberapa langganan

Jika Anda membayar lebih dari satu paket Claude, Codex, atau Grok — misalnya Max pribadi dan satu untuk pekerjaan — Omarchy dapat menjaga semuanya tetap masuk dan berpindah di antaranya. Tambahkan langganan dengan + di panel agen, yang memandu Anda langsung di sana, atau dengan `omarchy agent account add claude Work` (atau `codex`, atau `grok`). Ia menginstal CLI jika belum ada. Akun pertama untuk sebuah provider masuk melalui browser normal Anda, tepat di tempat CLI selalu mencarinya. Setiap akun setelah itu masuk melalui jendela privat, sehingga akun yang sudah Anda gunakan untuk masuk di browser tidak terambil secara tidak sengaja; masuk di sana sebagai akun yang Anda tambahkan, dan tutup dulu jendela privat yang sudah Anda buka. Jangan pernah keluar dari CLI untuk melakukan ini: keluar akan mencabut login yang tersimpan, dan akun itu harus ditambahkan lagi.

Untuk menyalin login langganan Anda ke mesin Omarchy lain melalui SSH, jalankan `omarchy agent account copy user@laptop`. Pengirim menyediakan receiver sementara ketika tujuan tidak memilikinya terinstal, sehingga mesin Omarchy yang lebih lama dapat menerima akun tanpa pembaruan. Receiver yang terinstal didahulukan. Ini menyalin semua langganan Claude, Codex, dan Grok; tambahkan nama provider untuk memilihnya, seperti dalam `omarchy agent account copy laptop claude`. Nama akun dan ID perintah cocok dengan sumber, termasuk akun yang sudah ada di tujuan. Akun tujuan yang tidak terkait menerima akhiran numerik jika namanya konflik, dan pengaturan, skill, plugin, serta riwayat percakapan tetap lokal di setiap mesin.

Kredensial tujuan yang sudah ada tetap disimpan. Akun sumber yang sudah masuk di sana namanya disinkronkan tanpa mengganti kredensialnya; akun lain ditambahkan di sampingnya. Untuk mengganti kredensial tersimpan untuk akun yang cocok, gunakan `omarchy agent account copy --replace laptop claude` setelah keluar dari sesi akun tersebut di tujuan. Tujuan baru juga mendapatkan akun aktif sumber dan preferensi perpindahannya; tujuan yang sudah mapan mempertahankan miliknya sendiri.

Kredensial berjalan melalui SSH dan disimpan dalam file privat di tujuan, jadi salin hanya ke mesin yang Anda percayai. Ini adalah salinan satu kali, bukan sinkronisasi berkelanjutan. Token refresh Codex dapat dirotasi oleh mesin lain, sehingga login hasil salinan perlu diperbarui; login terpisah tetap menjadi pilihan paling andal untuk penggunaan bersamaan di beberapa mesin. Lihat [panduan autentikasi akun Codex](https://developers.openai.com/codex/auth/ci-cd-auth).

Satu akun per provider aktif, dan setiap sesi baru dimulai sebagai akun itu: `cx`, `cy`, `claude`, `codex`, atau `grok` biasa, apa pun yang diluncurkan melalui `omarchy agent`, dan skrip atau editor yang menemukan CLI di `PATH`. Berpindahlah dengan `omarchy agent account use work` (dan kembali dengan `omarchy agent account use main`), atau di panel dengan menekan nomor akun lalu `Enter` (atau mengklik tombol Use-nya). Sesi yang sudah berjalan tetap pada akun tempat mereka dimulai. Riwayat percakapan, pengaturan, skill, dan plugin dibagikan antar akun, jadi `claude --continue` di folder yang sama melanjutkan dari tempat Anda berhenti di akun baru.

Dengan lebih dari satu akun, panel menampilkan batas setiap akun secara berdampingan, dengan akun aktif ditandai. Secara default Omarchy memberi tahu Anda ketika akun aktif melewati 95% dari sebuah batas, dan mengklik notifikasi beralih ke akun dengan ruang tersisa paling banyak. Arahkan kursor ke baris akun di panel dan klik Autoswitch yang muncul di samping Use (atau tekan `m`), atau jalankan `omarchy agent account mode auto`, agar ia beralih sendiri sebagai gantinya; selagi aktif, Autoswitch menggantikan posisi Use, dan mengkliknya lagi kembali ke mode pemberitahuan. Tambahkan angka untuk mengubah ambang batas, seperti dalam `omarchy agent account mode auto 90`. Jika setiap akun melewati ambang batas, Anda akan mendengarnya sekali, beserta akun mana yang bebas terlebih dahulu. Selagi akun aktif berada dalam 15 poin dari ambang batasnya (80% pada default), batasnya diperiksa setiap tiga menit, bukan setiap 15.

`omarchy agent account list` menampilkan setiap akun dan batas terbarunya, `omarchy agent account remove work` melupakan satu akun, dan `omarchy agent account rename primary Hey` mengganti nama satu akun (atau klik nama akun di panel). Perintah-perintah ini bekerja pada akun agen default Anda; untuk menjangkau provider lain, sebutkan namanya terlebih dahulu, seperti dalam `omarchy agent account use codex side`. Login yang sudah Anda miliki di `~/.claude` atau `~/.codex` adalah akun _Main_ dan tetap di tempatnya. Akun yang tidak digunakan selama lebih dari sekitar delapan jam dapat menampilkan _Sign-in required_; klik untuk masuk ke akun itu lagi langsung di panel, atau mulai sesi di dalamnya, yang menyegarkan login dengan sendirinya. Server MCP yang Anda miliki ketika sebuah akun ditambahkan ikut bersamanya, tetapi server yang Anda tambahkan nanti dengan `claude mcp add` hanya mencapai akun tempat Anda menambahkannya. Claude Desktop dan tool yang dikonfigurasi dengan path absolut ke binary CLI tidak mengikuti perpindahan. `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, atau `GROK_HOME` eksplisit didahulukan daripada akun yang dipilih.

### Diagnosis crash

Omarchy memantau systemd-coredump untuk crash proses. Ketika sesuatu mengalami segfault, Anda akan mendapatkan notifikasi "Process crashed" — klik, dan crash diserahkan ke agen default Anda bersama dengan skill diagnose-crash Omarchy, yang memandu agen untuk menetapkan fakta dari core dump dan memutuskan apakah crash layak dilaporkan ke upstream. Anda juga dapat menjalankannya secara manual terhadap PID apa pun dari `coredumpctl list` dengan `omarchy agent crash <pid>`.

Pemantauan aktif secara default. Matikan di bawah _Trigger > Toggle > Crash Capture_ (atau dengan `omarchy toggle crash-capture`) dan notifikasi berhenti; `omarchy agent crash <pid>` tetap bekerja secara manual.

Crash juga dapat dibisukan satu program pada satu waktu, yang ditawarkan diagnosis kepada Anda di bagian akhir. `omarchy crash mute hyprland` menghentikan notifikasi untuk program itu saja, `omarchy crash mute hyprland off` mengembalikannya, dan `omarchy crash mute` sendiri menampilkan apa yang telah Anda bisukan. Ia menerima path binary sama senangnya seperti namanya, jadi `omarchy crash mute /usr/bin/hyprland` melakukan hal yang sama. Kutip nama yang mengandung spasi, seperti dalam `omarchy crash mute 'Some App'`. Semua yang lain tetap memberi notifikasi, dan program yang dibisukan tetap crash — ini menyembunyikan pengingat, bukan memperbaiki apa pun.

### Aplikasi desktop

Menu _Install > AI_ juga membawa beberapa aplikasi AI grafis: aplikasi desktop ChatGPT, aplikasi desktop Claude (beta Linux dari Anthropic, dengan tab Chat, Cowork, dan Claude Code), Grok Bot untuk mengobrol dengan model xAI, Herdr Desktop, Hermes Desktop, OpenClaw, aplikasi desktop Perplexity, dan T3 Code. Grok Bot adalah aplikasi chat desktop. Agen coding adalah perintah `grok`.

Hermes Desktop adalah yang perlu diketahui, karena sebuah mesin memiliki satu Hermes, dan itu milik aplikasi: Hermes hanya pernah diinstal melalui aplikasi, dan perintah `hermes` yang dijalankan agen default adalah milik aplikasi. Memilih Hermes sebagai agen default menginstal hal yang sama seperti yang dilakukan entri _Install > AI_: package, dan runtime Hermes di bawah `~/.hermes` yang disiapkan oleh installer Hermes sendiri, yang memakan waktu beberapa menit pada pertama kali. Runtime itu adalah satu Hermes yang digunakan perintah `hermes` di terminal, agen default, dan aplikasi, dan ia memperbarui dirinya sendiri dengan `hermes update` daripada menunggu rilis Omarchy. Menginstalnya juga memberikan Hermes tema Omarchy sebagai skin bernama `omarchy`, yang diikuti setiap permukaan Hermes ketika Anda mengganti tema; pilih yang lain di bawah pengaturan Appearance Hermes atau dengan `/skin` jika Anda lebih suka tidak, dan Omarchy membiarkan pilihan itu. Menghapus aplikasi di bawah _Remove > AI_ menutup Hermes terlebih dahulu, termasuk gateway, mengambil runtime itu bersamanya, dan menyimpan chat, memori, dan skill yang Hermes tulis untuk dirinya sendiri kecuali Anda menyuruhnya sebaliknya: ia bertanya, dengan default tidak, apakah data itu dan pengaturan koneksi Anda juga harus dihapus.

Pengalaman desktop OpenClaw adalah Control UI-nya, yang terbuka sebagai aplikasi web yang didukung oleh gateway lokalnya sendiri. OpenClaw tinggal di `~/.openclaw` dan memperbarui dirinya sendiri: gunakan tombol "Update Gateway" di Control UI atau jalankan `openclaw update`, dan gateway restart pada versi baru. Omarchy hanya memilih rilis tempat instalasi baru dimulai. Menghapus OpenClaw di bawah _Remove > AI_ mengambil service gateway dan aplikasi bersamanya lalu bertanya apakah `~/.openclaw` juga harus dihapus, karena di sana tersimpan chat dan kredensial Anda di samping OpenClaw itu sendiri dan runtime plugin yang diunduhnya; default menyimpannya, dan menginstal OpenClaw lagi akan mengambilnya kembali.

Herdr Desktop adalah aplikasi desktop [Herdr](https://herdr.dev): spaces, tabs, dan panes terminal dan agen coding yang terus berjalan di core-nya ketika Anda menutup jendela. Ia berasal dari installer Herdr sendiri bukan dari package, jadi tinggal di `~/.local/share/herdr-app`, membawa core-nya di `~/.local/bin/herdr-core` ketika Anda belum memilikinya, dan memperbarui keduanya sendiri. Ia berada di samping perintah `herdr` yang dikirim Omarchy pada `Super + Ctrl + Return` daripada menggantikannya, dan mendapatkan key langsung perintah itu: `Alt + Return` dan `Alt + Shift + Return` membagi pane ke bawah atau ke kanan, `Alt + Escape` menutupnya, `Ctrl + Alt + Arrow` berpindah antar pane, `Alt + 1..9` dan `Alt + Left/Right` memilih tab, dan `Alt + Up/Down` berpindah antar spaces. `Ctrl + 1..9` memilih space dan `Alt + Shift + Up/Down` melangkah melalui agen. Key prefix `Ctrl + Space` tetap khusus terminal, karena aplikasi tidak dapat menahan key Ctrl biasa untuk sebuah urutan. Omarchy menulis ini ke `~/.config/herdr-app/keys.json`, dan `omarchy-refresh-herdr-app` mengembalikannya. Menginstalnya memilih tema Omarchy Herdr, yang mengikuti tema Omarchy Anda sejak saat itu. Herdr menyimpan satu tema untuk mode terang dan satu untuk mode gelap, jadi setelah beralih antara tema Omarchy gelap dan terang, pilih Omarchy di pemilih tema Herdr sekali lagi untuk mode lainnya.

T3 Code berjalan dari rilis AppImage resminya di `~/.local/share/t3code` daripada dari package, jadi ia memperbarui dirinya sendiri. Menginstalnya bertanya apakah akan memulai pada channel Stable atau Nightly; beralih nanti di pengaturan T3 Code. Thread dan pengaturan Anda tinggal di `~/.t3`, dan menghapus T3 Code di bawah _Remove > AI_ mengambilnya bersamanya.

### Model lokal

Jalankan model terbuka di mesin Anda sendiri untuk agen coding Anda. Prompt dan kode Anda tetap di mesin; tidak ada yang dikirim ke model yang meninggalkannya. Mulailah dengan:

```bash
omarchy agent local use best
```

Atau, di panel agen di bar atas, pilih + lalu Local AI, yang muncul ketika sebuah model cocok dengan mesin ini. Pertama kali, ini menginstal Podman, yang menjalankan model, dan pada mesin NVIDIA toolkit container NVIDIA, yang memberi mereka GPU. Omarchy kemudian memilih model yang direkomendasikan untuk mesin ini, mengunduhnya, dan memulainya. Harapkan unduhan puluhan GB dan sebagian besar memori mesin digunakan selagi model berjalan: Flash Next menggunakan sekitar 100 GiB dengan konteks 256K penuhnya. Jika model lain menahan memori yang dibutuhkannya, ia disiapkan dalam keadaan berhenti, siap dimulai setelah Anda menghentikan satu. Model berhenti saat logout; hentikan sendiri ketika Anda membutuhkan memori untuk hal lain.

`omarchy agent local list` menampilkan pilihan dan menjelaskan mengapa beberapa tidak cocok. Untuk menyiapkan yang lain, jalankan `omarchy agent local use <recipe>`. Saat ini, `qwen3.8-flash-next-gufo` dan `qwen3.8-27b-gufo` tersedia untuk mesin Strix Halo 128 GB; 27B menggunakan sekitar 40 GiB, jadi menyisakan ruang untuk pekerjaan lain. Recipe dan rekomendasi baru tiba dengan `omarchy update`, melalui package.

Setiap model yang Anda siapkan mendapatkan barisnya sendiri di panel agen, di sebelah langganan Anda: play untuk memulainya, pause untuk menghentikannya dan membebaskan memorinya, dan tombol terminal untuk membuka agen Anda di atasnya. Beberapa dapat berjalan sekaligus ketika mereka cocok di memori bersama; jika satu tidak cocok, Omarchy menyebutkan model berjalan mana yang harus dihentikan. Seret baris untuk mengurutkannya kembali, dan tekan Delete pada baris terpilih untuk menghapus model dan unduhannya.

Dari baris perintah, `omarchy agent local start <recipe>` dan `omarchy agent local stop <recipe>` melakukan hal yang sama, `omarchy agent local status` menampilkan setiap model, dan `omarchy agent --local` membuka agen default Anda pada model terakhir yang Anda mulai. pi, OpenCode dan Qwen Code dapat menggunakan satu; dengan default lain ia terbuka di pi. pi juga menampilkan setiap model yang telah Anda siapkan, dan yang ada di mesin yang telah Anda pasangkan, di pemilih modelnya sendiri, sehingga `pi` biasa juga menjangkaunya. Klien kompatibel OpenAI apa pun juga dapat terhubung: `status` menampilkan alamat setiap model (yang pertama adalah `http://127.0.0.1:11435/v1`), nama recipe adalah modelnya, dan key ada di `~/.config/omarchy/agent-local/key`.

`omarchy agent local remove <recipe>` menghapus model dan unduhan yang tidak digunakan model lain.

Runtime pihak ketiga diberi label dengan penerbitnya. Omarchy menjalankan setiap model tanpa akses jaringan.

### LLM lokal

Omarchy merekomendasikan dua cara menjalankan model LLM lokal: LM Studio dan Ollama. LM Studio menyediakan antarmuka GUI untuk menemukan model open-weight, menginstalnya, dan menjalankannya. Ini cara yang bagus untuk memulai dengan mudah. Ollama menawarkan CLI untuk melakukan hal serupa. Tetapi jika Anda baru mengenal model lokal, saya akan mulai dengan LM Studio. Anda dapat menginstal keduanya di bawah _Install > AI_ di Omarchy Menu.

### Skill Omarchy

Skill agen membantu AI menggunakan tool tertentu dengan cara tertentu, dan Omarchy dikirim dengan skill default untuk menyesuaikan sistem. Seperti mengubah config Hyprland Anda, menyesuaikan bar, atau bahkan membuat tema baru dari awal. Ia ditautkan secara symlink ke direktori skill untuk Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` dan setiap `~/.hermes/profiles/*/skills`), dan lokasi generik `~/.agents/skills`, sehingga sebagian besar harness mengambilnya secara otomatis.

Tetapi Anda harus memperlakukan skill ini sebagai eksperimental. Model yang berbeda akan menggunakannya dengan efek yang berbeda. Sebaiknya jalankan dalam mode plan terlebih dahulu, sehingga Anda memiliki gambaran tentang apa yang ingin diubah agen. Lalu bersiaplah untuk mengembalikan perubahan atau bahkan menjalankan `omarchy reinstall configs`, jika agen membuat semuanya berantakan.
