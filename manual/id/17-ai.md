### Memasang dan memperbarui agen

Kecuali Hermes dan OpenClaw, agen-agen ini menggunakan pemasangan lazy dari mise: peluncuran pertama memasang CLI, dan peluncuran berikutnya menggunakannya kembali. mise juga memeriksa apakah ada rilis baru untuk agen yang terpasang paling banyak sekali setiap empat jam, tepat sebelum agen dimulai atau di latar belakang pada prompt shell. Jika pembaruan itu gagal atau Anda sedang offline, versi yang terpasanglah yang dijalankan. `omarchy update` memperbarui agen yang terpasang bersama seluruh Omarchy lainnya, dan `mup` hanya memperbarui alat yang dikelola mise.

Pembaru bawaan agen itu sendiri, seperti `claude update`, `codex update`, atau tombol pembaruan di sebuah aplikasi, tidak memperbarui instalasi yang dikelola mise. `codex update` gagal, dan `claude update` bisa melaporkan keberhasilan sambil memasang salinan terpisah yang tidak dilacak mise. Jika Anda lebih suka menggunakan pemasang dan pembaru bawaan agen, tambahkan agen itu ke `disable_tools`; lihat [Alat CLI yang sudah terpasang](18-development-tools.md#preinstalled-cli-tools).

Untuk memasang semua alat lazy yang dikonfigurasi sebelum Anda membutuhkannya, jalankan `mise install --include-lazy`. Ini mencakup alat CLI default Omarchy lainnya serta agen-agen tersebut. Lihat [Alat CLI yang sudah terpasang](18-development-tools.md#preinstalled-cli-tools) untuk memasang satu alat atau menggunakan instalasi Anda sendiri.

`grok` dipasang melalui paket `grok` resmi dari mise, dengan cara yang sama seperti `claude` dan `codex`. Jalankan `grok`, atau pilih di bawah _Agent > Harness_. Lewati pemasang `curl | bash` di x.ai. Jalur itu menaruh salinan kedua di `~/.grok/bin`, menempatkannya di awal `PATH`, dan menimpa wrapper Omarchy.

`dsh` membuka UI browsernya di `127.0.0.1:3080`, dengan direktori peluncuran sebagai workspace defaultnya. UI browsernya tidak menerima prompt awal, jadi `omarchy agent prompt` membukanya dengan prompt di clipboard Anda untuk ditempel. Omarchy memulainya dengan preset izin tanpa persetujuan dari DeepSeek. DeepSeek Harness mengunggah log sesi ke DeepSeek saat Anda menggunakan API model resminya; matikan itu di bawah _Settings > General > Upload Session Log_ di UI browsernya. Masukan yang Anda kirimkan kepadanya juga diunggah bersama sesi tersebut, kecuali Anda memulainya dengan `DSH_TELEMETRY_MODE=DISABLED`.

### Agen default

Pilih agen default Anda dengan `omarchy default agent <name>` atau di bawah _Agent > Harness_ di Omarchy Menu (`Super + Space`). Jika agen belum terpasang, memilihnya akan memasangnya terlebih dahulu, dan agen itu juga mendapatkan peluncurnya sendiri di peluncur aplikasi, di sebelah Agent. Omarchy baru akan mengundang Anda membuat pilihan ini dengan notifikasi satu kali.

Memilih Claude juga mencoba menyiapkan ekstensi browsernya untuk Chromium, Chrome, Brave, Brave Origin, dan Edge. Penyiapan ekstensi berlaku untuk semua pengguna dan mungkin meminta kata sandi sistem Anda; membatalkan atau gagal memasang ekstensi tetap memilih dan meluncurkan Claude. Mulai ulang browser Anda, aktifkan ekstensi jika diminta, dan masuk ke Claude untuk menyelesaikan penyambungannya. Jalankan `/chrome` di Claude untuk memeriksa sambungan tersebut. Firefox dan Zen tidak mendukung ekstensi ini. Jika Claude sudah menjadi default Anda sebelum penyiapan ini ditambahkan, pilih lagi untuk memasang ekstensi tersebut.

Setelah Anda memilih, `Super + Shift + Ctrl + A` meluncurkan agen default di jendela terminal khusus (atau memunculkan pemilih jika Anda belum memilih). Anda juga bisa meluncurkannya langsung ke sebuah tugas dengan `omarchy agent prompt "Review this project"`. Freebuff dan DeepSeek Harness tidak menerima prompt awal, jadi keduanya dibuka dengan prompt di clipboard Anda untuk ditempel sebagai gantinya. Agen yang diluncurkan dengan cara ini berjalan tanpa pengawasan dalam mode jangan-berhenti-untuk-bertanya masing-masing, jadi bersiaplah karena mereka benar-benar akan melakukan sesuatu! MiniMax Code tidak memiliki mode seperti itu untuk sesi interaktifnya, jadi ia meminta izin seperti biasa. Dan karena agen menolak mengingat kepercayaan untuk direktori home Anda, peluncuran dari `$HOME` dimulai di `~/Work` sebagai gantinya.

Ada pintasan terminal juga: `a` menjalankan agen default secara inline di terminal saat ini, sedangkan `c`, `cx`, dan `cy` memulai OpenCode, Claude Code, dan Codex secara langsung (sekali lagi dalam mode persetujuan otomatis mereka). Perubahan tema juga tersinkron ke agen: Claude Code, Pi, OpenCode, dan Hermes (setelah Omarchy memasangnya) semuanya mengikuti saat Anda mengganti tema Omarchy.

### Instruksi agen Anda

Aturan pribadi untuk setiap agen ditempatkan di `~/.agents/AGENTS.md`, di sebelah skill bersama di `~/.agents/skills`. Buka di bawah _Agent > Instructions_, yang juga menautkannya ke setiap harness yang menyimpan berkas globalnya sendiri: `~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.pi/agent/AGENTS.md`, `~/.config/opencode/AGENTS.md`, `~/.copilot/copilot-instructions.md` milik Copilot, dan seterusnya. Crush dan Amp membaca tautan `~/.config/AGENTS.md`, sedangkan omp, Kimi, dan DeepSeek Harness membaca `~/.agents/AGENTS.md` secara langsung. Memilih agen default juga menautkannya. Berkas instruksi yang sudah Anda miliki menjadi berkas bersama jika belum ada; jika tidak, berkas itu disimpan di sebelah tautan sebagai `.bak`. Jalankan `omarchy agent instructions` untuk menautkan ulang setelah memasang agen lain.

### Panel agen

Bar atas memiliki ikon agen. Sebelum Anda menyiapkan agen, panelnya memandu Anda masuk ke Claude, Codex, atau Grok, dan yang pertama menjadi agen default Anda. Setelah itu, panel menempatkan setiap langganan dalam satu halaman: setiap agen dan akun dengan paketnya, pengukur untuk setiap batas sesi 5 jam dan batas mingguannya beserta waktu hingga batas itu direset (arahkan kursor untuk melihat persentase pastinya), atau sisa saldo prabayar, di bawah baris yang bergantian menampilkan apa yang telah Anda gunakan di semuanya, seperti token minggu ini dan model yang paling sering Anda gunakan. Di bawah _Make something cool_ panel ini menawarkan prompt pemula untuk tema, plugin, aplikasi, atau game baru yang menyerahkan tugas tersebut kepada agen default Anda. Aplikasi dibuat dengan cara yang sama seperti Hype, Monologue, dan Omacut milik Omarchy sendiri, dalam C++ dan Qt Quick, mengikuti skill agen omarchy-make-app, dan compiler serta komponen Qt yang dibutuhkannya sudah terpasang. Game adalah satu halaman three.js di `~/Games/vibes`, mengikuti skill agen omarchy-make-game, dan semuanya dibuka dari satu peluncur Game Vibes dalam tema saat ini; game memuat three.js dari web, jadi memerlukan sambungan untuk dimulai. Claude Code, Codex, Grok, Kimi, Cursor dan jatah Grok Bot-nya, GitHub Copilot, Muse, Antigravity, dan Devin tercakup sejak awal dengan batas-batasnya, Kimchi dengan paketnya, kredit prabayar, dan anggaran pengeluarannya, dan Hermes, Mistral Vibe, dan Qwen Code menampilkan sesi dan tokennya setelah Anda menggunakannya. Paket dan kunci provider yang Anda gunakan melalui pi, omp, atau opencode juga muncul: OpenCode Zen dan Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan, dan Synthetic dengan batas-batasnya; OpenRouter dan DeepSeek dengan saldo prabayarnya; Fireworks dengan pengeluarannya selama 30 hari terakhir; dan model yang Anda jalankan pada perangkat keras Anda sendiri di bawah Local models. Setiap agen dihitung sekali, di bawah siapa pun yang menagihnya, berapa pun banyaknya harness yang Anda gunakan untuk menjalankannya.

Klik kiri ikon bar atau tekan `Super + Ctrl + X` untuk panel, klik kanan untuk meluncurkan agen default Anda, dan klik tengah untuk menyegarkan. Catatan penggunaan di baliknya dibuat ulang setiap 15 menit oleh `omarchy agent usage update`, dan panel bahkan bisa menggabungkan penggunaan dari mesin Anda yang lain melalui folder yang tersinkron. Lihat README di bawah `$OMARCHY_PATH/shell/plugins/agents/` untuk pengaturan lengkapnya.

### Beberapa langganan

Jika Anda membayar lebih dari satu paket Claude, Codex, atau Grok — misalnya Max pribadi dan satu untuk pekerjaan — Omarchy bisa menjaga semuanya tetap masuk dan berpindah di antaranya. Tambahkan langganan dengan + di panel agen, yang memandu Anda langsung di sana, atau dengan `omarchy agent account add claude Work` (atau `codex`, atau `grok`). Perintah itu memasang CLI jika belum ada. Akun pertama untuk sebuah provider masuk melalui browser normal Anda, tepat di tempat CLI selalu mencarinya. Setiap akun setelah itu masuk melalui jendela pribadi, sehingga akun yang sudah dimasuki browser Anda tidak terambil secara tidak sengaja; masuklah di sana sebagai akun yang Anda tambahkan, dan tutup dulu jendela pribadi apa pun yang sudah Anda buka. Jangan pernah keluar dari CLI untuk melakukan ini: keluar akan mencabut sesi masuk yang tersimpan, dan akun itu harus ditambahkan lagi.

Untuk menyalin login langganan Anda ke mesin Omarchy lain melalui SSH, jalankan `omarchy agent account copy user@laptop`. Pengirim menyediakan penerima sementara ketika tujuan belum memilikinya terpasang, sehingga mesin Omarchy yang lebih lama bisa menerima akun tanpa pembaruan. Penerima yang terpasang diutamakan. Ini menyalin semua langganan Claude, Codex, dan Grok; tambahkan nama provider untuk memilihnya, seperti pada `omarchy agent account copy laptop claude`. Nama akun dan ID perintah sesuai dengan sumber, termasuk akun yang sudah ada di tujuan. Akun tujuan yang tidak terkait menerima akhiran angka jika namanya bentrok, dan pengaturan, skill, plugin, serta riwayat percakapan tetap lokal di setiap mesin.

Kredensial tujuan yang ada tetap dipertahankan. Akun sumber yang sudah masuk di sana namanya disinkronkan tanpa mengganti kredensialnya; akun lain ditambahkan di sampingnya. Untuk mengganti kredensial tersimpan untuk akun yang cocok, gunakan `omarchy agent account copy --replace laptop claude` setelah menutup sesi akun tersebut di tujuan. Tujuan baru juga mendapatkan akun aktif dan preferensi perpindahan dari sumber; tujuan yang sudah mapan mempertahankan miliknya sendiri.

Kredensial berjalan melalui SSH dan disimpan dalam berkas pribadi di tujuan, jadi salin hanya ke mesin yang Anda percayai. Ini adalah penyalinan satu kali, bukan sinkronisasi berkelanjutan. Token refresh Codex bisa diputar oleh mesin lain, sehingga login hasil salinan perlu diperbarui; sesi masuk terpisah tetap menjadi pilihan paling andal untuk penggunaan serentak di beberapa mesin. Lihat [panduan autentikasi akun Codex](https://developers.openai.com/codex/auth/ci-cd-auth).

Satu akun per provider aktif, dan setiap sesi baru dimulai sebagai akun itu: `cx`, `cy`, `claude`, `codex`, atau `grok` biasa, apa pun yang diluncurkan melalui `omarchy agent`, serta skrip atau editor yang menemukan CLI di `PATH`. Berpindahlah dengan `omarchy agent account use work` (dan kembali dengan `omarchy agent account use main`), atau di panel dengan menekan nomor akun lalu `Enter` (atau mengklik tombol Use-nya). Sesi Claude yang sedang berjalan juga berpindah, mulai dari pesan berikutnya: setiap sesi Claude berjalan di `~/.claude`, yang selalu menyimpan sesi masuk akun aktif. Sesi Claude yang dimulai di folder akunnya sendiri oleh Omarchy lama menyimpan sesi masuk itu hingga berhenti, jadi perpindahan menyebutkan nama sesi-sesi tersebut dan selesai dengan sendirinya setelah sesi-sesi itu hilang. Sesi Codex dan Grok yang sedang berjalan tetap pada akun yang digunakan saat memulainya. Riwayat percakapan, pengaturan, skill, dan plugin dibagikan antar akun, jadi `claude --continue` di folder yang sama melanjutkan dari tempat Anda berhenti pada akun baru.

Dengan lebih dari satu akun, panel menampilkan batas setiap akun secara berdampingan, dengan yang aktif ditandai. Secara default Omarchy memberi tahu Anda saat akun aktif melewati 95% dari sebuah batas, dan mengklik notifikasi berpindah ke akun dengan ruang tersisa paling banyak. Arahkan kursor ke baris akun di panel dan klik Autoswitch yang muncul di sebelah Use (atau tekan `m`), atau jalankan `omarchy agent account mode auto`, agar perpindahan terjadi dengan sendirinya; saat aktif, Autoswitch menggantikan tempat Use, dan mengkliknya lagi kembali ke pemberitahuan. Tambahkan angka untuk mengubah ambangnya, seperti pada `omarchy agent account mode auto 90`. Jika setiap akun melewati ambang, Anda akan mendengarnya sekali, beserta akun mana yang lebih dulu bebas. Saat akun aktif berada dalam jarak 15 poin dari ambangnya (80% pada default), batasnya diperiksa setiap tiga menit, bukan setiap 15 menit.

`omarchy agent account list` menampilkan setiap akun dan batas terbarunya, `omarchy agent account remove work` melupakan satu akun, dan `omarchy agent account rename primary Hey` mengganti nama satu akun (atau klik nama akun di panel). Perintah-perintah ini bekerja pada akun agen default Anda; untuk menjangkau provider lain, sebutkan namanya terlebih dahulu, seperti pada `omarchy agent account use codex side`. Login yang sudah Anda miliki di `~/.claude` atau `~/.codex` adalah akun _Main_. Milik Codex tetap di tempatnya; milik Claude menunggu di foldernya sendiri saat akun lain aktif. Akun yang dibiarkan tidak digunakan selama lebih dari sekitar delapan jam bisa menampilkan _Sign-in required_; klik akun itu untuk memasukkan akun tersebut lagi langsung di panel, atau berpindah kepadanya dan mulai sebuah sesi, yang menyegarkan sesi masuk dengan sendirinya. Server MCP yang Anda tambahkan dengan `claude mcp add` menjangkau setiap akun Claude, karena semuanya berjalan di `~/.claude`; untuk Codex dan Grok, server yang Anda miliki saat sebuah akun ditambahkan ikut ke akun itu, tetapi server berikutnya hanya menjangkau akun tempat Anda menambahkannya. Claude Desktop menyimpan sesi masuknya sendiri, dan alat Codex atau Grok yang dikonfigurasi dengan jalur absolut ke binary CLI tidak mengikuti perpindahan. `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, atau `GROK_HOME` eksplisit diutamakan daripada akun yang dipilih.

### Diagnosis crash

Omarchy mengawasi systemd-coredump untuk crash proses. Setelah Anda memilih agen default, program Anda apa pun yang melakukan dump core memunculkan notifikasi "Process crashed" — klik notifikasi itu, dan crash diserahkan kepada agen default Anda bersama skill omarchy-diagnose-crash dari Omarchy, yang memandu agen menetapkan fakta dari core dump dan memutuskan apakah crash layak dilaporkan ke upstream. Anda juga bisa menjalankannya secara manual terhadap PID apa pun dari `coredumpctl list` dengan `omarchy agent crash <pid>`.

Pengawasan aktif secara default. Matikan di bawah _Trigger > Toggle > Crash Capture Off_ (atau dengan `omarchy toggle crash-capture`) dan notifikasi berhenti; `omarchy agent crash <pid>` tetap bekerja secara manual.

Crash juga bisa dibisukan satu program pada satu waktu, yang ditawarkan diagnosis kepada Anda di bagian akhir. `omarchy crash mute hyprland` menghentikan notifikasi hanya untuk program itu, `omarchy crash mute hyprland off` memunculkannya kembali, dan `omarchy crash mute` sendiri menampilkan apa yang telah Anda bisukan. Perintah itu menerima jalur binary sama senangnya seperti namanya, jadi `omarchy crash mute /usr/bin/hyprland` melakukan hal yang sama. Kutip nama yang mengandung spasi, seperti pada `omarchy crash mute 'Some App'`. Semuanya yang lain tetap memberi notifikasi, dan program yang dibisukan tetap crash — ini menyembunyikan pengingat, bukan memperbaiki apa pun.

### Aplikasi desktop

Menu _Install > AI_ juga membawa beberapa aplikasi AI grafis: Amp Desktop, Antigravity Desktop, aplikasi desktop ChatGPT, aplikasi desktop Claude (beta Linux dari Anthropic, dengan tab Chat, Cowork, dan Claude Code), Grok Bot untuk mengobrol dengan model xAI, Herdr Desktop, Hermes Desktop, OpenClaw, aplikasi desktop Perplexity, dan T3 Code. Grok Bot adalah aplikasi obrolan desktop. Agen coding adalah perintah `grok`.

Hermes Desktop adalah yang perlu diketahui, karena sebuah mesin memiliki satu Hermes, dan itu adalah milik aplikasi: Hermes hanya pernah dipasang melalui aplikasi, dan perintah `hermes` yang dijalankan agen default adalah milik aplikasi. Memilih Hermes sebagai agen default memasang hal yang sama seperti yang dipasang entri _Install > AI_: paketnya, dan runtime Hermes di bawah `~/.hermes` yang disiapkan oleh pemasang Hermes sendiri, yang memerlukan beberapa menit pada kali pertama. Runtime itu adalah satu-satunya Hermes yang digunakan perintah terminal `hermes`, agen default, dan aplikasi, dan ia memperbarui dirinya sendiri dengan `hermes update` daripada menunggu rilis Omarchy. Memasangnya juga memberikan tema Omarchy kepada Hermes sebagai skin bernama `omarchy`, yang diikuti setiap permukaan Hermes saat Anda mengganti tema; pilih yang lain di bawah pengaturan Appearance Hermes atau dengan `/skin` jika Anda tidak ingin begitu, dan Omarchy membiarkan pilihan itu sendiri. Menghapus aplikasi di bawah _Remove > AI_ menutup Hermes terlebih dahulu, termasuk gateway, membawa runtime itu bersamanya, dan mempertahankan obrolan, memori, serta skill yang ditulis Hermes untuk dirinya sendiri kecuali Anda menyuruhnya lain: ia bertanya, dengan default tidak, apakah data itu dan pengaturan sambungan Anda juga harus dihapus.

Pengalaman desktop OpenClaw adalah Control UI-nya, yang dibuka sebagai aplikasi web yang didukung gateway lokalnya sendiri. OpenClaw tinggal di `~/.openclaw` dan memperbarui dirinya sendiri: gunakan tombol "Update Gateway" di Control UI atau jalankan `openclaw update`, dan gateway dimulai ulang pada versi baru. Omarchy hanya memilih rilis yang menjadi titik awal instalasi baru. OpenClaw juga bisa menjadi agen default Anda: memilihnya di bawah _Agent > Harness_ menyiapkan salinan yang sama di `~/.openclaw`, dan agen membuka UI terminal OpenClaw yang terhubung ke gateway-nya. Menghapus OpenClaw di bawah _Remove > AI_ membawa layanan gateway dan aplikasinya, lalu bertanya apakah `~/.openclaw` juga harus dihapus, karena di sana tersimpan obrolan dan kredensial Anda bersama OpenClaw itu sendiri dan runtime plugin yang diunduhnya; default mempertahankannya, dan memasang OpenClaw lagi mengambilnya kembali.

Herdr Desktop adalah aplikasi desktop [Herdr](https://herdr.dev): ruang, tab, dan panel terminal serta agen coding yang tetap berjalan di core-nya saat Anda menutup jendela. Ia berasal dari pemasang Herdr sendiri, bukan dari sebuah paket, jadi tinggal di `~/.local/share/herdr-app`, membawa core-nya di `~/.local/bin/herdr-core` saat Anda belum memilikinya, dan memperbarui keduanya sendiri. Ia berada di sebelah perintah `herdr` yang disertakan Omarchy pada `Super + Ctrl + Return` daripada menggantikannya, dan mendapatkan tombol langsung perintah itu: `Alt + Return` dan `Alt + Shift + Return` membagi panel ke bawah atau ke kanan, `Alt + Escape` menutupnya, `Ctrl + Alt + Arrow` berpindah antar panel, `Alt + 1..9` dan `Alt + Left/Right` memilih tab, dan `Alt + Up/Down` berpindah antar ruang. `Ctrl + 1..9` memilih ruang dan `Alt + Shift + Up/Down` melangkah melalui agen. Tombol awalan `Ctrl + Space` tetap hanya untuk terminal, karena aplikasi tidak bisa menahan tombol Ctrl biasa untuk sebuah urutan. Omarchy menulis ini ke `~/.config/herdr-app/keys.json`, dan `omarchy-refresh-herdr-app` mengembalikannya. Memasangnya memilih tema Omarchy dari Herdr, yang mengikuti tema Omarchy Anda sejak saat itu. Herdr menyimpan satu tema untuk mode terang dan satu untuk mode gelap, jadi setelah berpindah antara tema Omarchy gelap dan terang, pilih Omarchy di pemilih tema Herdr sekali lagi untuk mode lainnya.

T3 Code berjalan dari rilis AppImage resminya di `~/.local/share/t3code` daripada dari sebuah paket, jadi ia memperbarui dirinya sendiri. Memasangnya bertanya apakah akan memulai pada saluran Stable atau Nightly; berpindahlah nanti di pengaturan T3 Code. Thread dan pengaturan Anda tinggal di `~/.t3`, dan menghapus T3 Code di bawah _Remove > AI_ membawanya.

### Model lokal

Jalankan model terbuka pada mesin Anda sendiri untuk agen coding Anda. Prompt dan kode Anda tetap di mesin; tidak ada yang dikirim ke model meninggalkan mesin itu. Mulailah dengan:

```bash
omarchy models use best text
```

Atau, di panel agen di bar atas, pilih + lalu Local AI, yang muncul saat sebuah model cocok untuk mesin ini. Podman, yang menjalankan model, disertakan dengan Omarchy, begitu juga toolkit container NVIDIA pada mesin NVIDIA, yang memberi mereka GPU; jika salah satunya hilang, penyiapan pertama memasangnya. Omarchy kemudian memilih model yang direkomendasikan untuk mesin ini, mengunduhnya, dan memulainya. Harapkan unduhan berukuran puluhan GB dan sebagian besar memori mesin digunakan saat model berjalan: Flash Next menggunakan sekitar 100 GiB dengan konteks penuh 256K-nya. Jika model lain menahan memori yang dibutuhkannya, model itu disiapkan dalam keadaan berhenti, siap dimulai setelah Anda menghentikan salah satunya. Model berhenti saat logout; hentikan sendiri saat Anda membutuhkan memori untuk hal lain.

`omarchy models list` menampilkan opsi dan menjelaskan mengapa beberapa tidak cocok. Untuk menyiapkan model lain, jalankan `omarchy models use <recipe>`. Saat ini, `qwen3.8-flash-next-gufo` dan `qwen3.8-27b-gufo` tersedia untuk mesin Strix Halo 128 GB; 27B menggunakan sekitar 40 GiB, jadi menyisakan ruang untuk pekerjaan lain. Pada laptop 64 GB dengan Arc B390 dari Intel, `qwen3.6-35b-a3b-llamacpp` berjalan dalam sekitar 30 GiB. Resep dan rekomendasi baru tiba dengan `omarchy update`, melalui paket.

Setiap model yang Anda siapkan mendapatkan barisnya sendiri di panel agen, di sebelah langganan Anda: putar untuk memulainya, jeda untuk menghentikannya dan membebaskan memorinya, dan tombol terminal untuk membuka agen Anda pada model itu. Beberapa bisa berjalan sekaligus saat semuanya muat bersama di memori; jika satu tidak muat, Omarchy memberi tahu model yang sedang berjalan mana yang harus dihentikan. Seret baris untuk menyusun ulang, dan tekan Delete pada baris yang dipilih untuk menghapus model dan unduhannya.

Setiap model yang Anda siapkan juga mendapatkan entrinya sendiri di peluncur aplikasi, dengan nama model dan logo pembuatnya, seperti masuk ke Claude, Codex, atau Grok menambahkan satu. Entri itu membuka agen Anda pada model tersebut, dan memulai model terlebih dahulu jika belum berjalan: terminal menampilkannya sedang dimuat dan menyerahkan ke agen setelah siap. Menghapus model menghapus entrinya.

Tidak setiap model untuk coding. Model gambar, video, dan musik dibuka di Fantasi sebagai gantinya, aplikasi Omarchy untuk membuat gambar, video, dan musik dengan model yang berjalan di mesin ini, dari entri peluncurnya dan dari barisnya di panel agen.

Sebuah model tetap berjalan persis seperti saat disiapkan, jadi pembaruan Omarchy tidak pernah memulai ulang model di bawah agen Anda. Saat Omarchy memiliki runtime yang lebih baru atau bobot yang lebih baru untuk model yang telah Anda siapkan, barisnya menampilkan tombol pembaruan: tekan tombol itu dan model disiapkan lagi di latar belakang, hanya mengunduh yang berubah, dan dimulai ulang pada versi baru. Model yang telah berhenti tetap berhenti. `omarchy models update` melakukan hal yang sama untuk setiap model dari terminal.

Dari baris perintah, `omarchy models start <recipe>` dan `omarchy models stop <recipe>` melakukan hal yang sama, `omarchy models status` menampilkan setiap model, dan `omarchy agent --local` membuka agen default Anda pada model terakhir yang Anda mulai. pi, OpenCode, dan Qwen Code bisa menggunakan satu; dengan default lain apa pun ia membuka di pi, atau di OpenCode jika Anda tidak memiliki pi. pi juga mencantumkan setiap model yang telah Anda siapkan, dan model pada mesin yang telah Anda pasangkan, dalam pemilih modelnya sendiri, jadi `pi` biasa juga bisa menjangkaunya. Klien apa pun yang kompatibel dengan OpenAI juga bisa terhubung: `status` menampilkan alamat setiap model (yang pertama adalah `http://127.0.0.1:11435/v1`), nama resep adalah modelnya, dan kuncinya ada di `~/.config/omarchy/agent-local/key`.

`omarchy models remove <recipe>` menghapus model dan unduhan yang tidak digunakan model lain.

Runtime pihak ketiga diberi label dengan penerbitnya. Omarchy menjalankan setiap model tanpa akses jaringan.

### LLM lokal

Omarchy merekomendasikan dua cara menjalankan model LLM lokal: LM Studio dan Ollama. LM Studio menyediakan antarmuka GUI untuk menemukan model open-weight, memasangnya, dan menjalankannya. Ini cara yang bagus untuk memulai dengan mudah. Ollama menawarkan CLI untuk melakukan hal serupa. Tetapi jika Anda baru mengenal model lokal, saya akan mulai dengan LM Studio. Anda bisa memasang salah satunya di bawah _Install > AI_ di Omarchy Menu.

### Skill Omarchy

Skill agen membantu AI menggunakan alat tertentu dengan cara tertentu, dan Omarchy menyertakan tujuh di antaranya. Skill omarchy mencakup menyesuaikan sistem, seperti mengutak-atik konfigurasi Hyprland Anda atau menyesuaikan bar. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app, dan omarchy-make-game mencakup membuat sesuatu yang baru, omarchy-contribute mencakup melaporkan bug atau mengirim perbaikan ke upstream, dan omarchy-diagnose-crash mengerjakan core dump sebuah crash. Skill-skill itu ditautkan secara simbolis ke direktori skill untuk Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` dan setiap `~/.hermes/profiles/*/skills`), dan lokasi generik `~/.agents/skills`, jadi sebagian besar harness mengambilnya secara otomatis. Folder skill Anda sendiri dengan nama yang sama diutamakan.

Tetapi Anda harus memperlakukan skill-skill ini sebagai eksperimental. Model yang berbeda akan menggunakannya dengan efek yang berbeda. Sebaiknya jalankan dalam mode rencana terlebih dahulu, agar Anda memiliki gambaran tentang apa yang ingin diubah agen. Lalu bersiaplah untuk mengembalikan perubahan atau bahkan menjalankan `omarchy reinstall configs`, jika agen mengacaukan semuanya.
