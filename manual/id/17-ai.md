### Menginstal dan memperbarui agen

Kecuali Hermes, agen-agen ini menggunakan instalasi lazy dari mise: peluncuran pertama menginstal CLI, dan peluncuran berikutnya menggunakannya kembali. mise juga memeriksa agen yang terinstal untuk rilis baru paling banyak sekali setiap empat jam, tepat sebelum agen dimulai atau di latar belakang pada prompt shell. Jika pembaruan itu gagal atau kamu sedang offline, versi yang terinstal yang dijalankan. `omarchy update` memperbarui agen yang terinstal bersama seluruh Omarchy, dan `mup` hanya memperbarui alat yang dikelola mise.

Pembaru bawaan agen, seperti `claude update`, `codex update`, atau tombol pembaruan di dalam aplikasi, tidak memperbarui instalasi yang dikelola mise. `codex update` gagal, dan `claude update` bisa melaporkan sukses sambil menginstal salinan terpisah yang tidak dilacak mise. Jika kamu lebih suka menggunakan installer dan pembaru bawaan agen, tambahkan agen itu ke `disable_tools`; lihat [Alat CLI yang sudah terinstal](18-development-tools.md#preinstalled-cli-tools).

Untuk menginstal semua alat lazy yang dikonfigurasi sebelum kamu membutuhkannya, jalankan `mise install --include-lazy`. Ini mencakup alat CLI default Omarchy lainnya selain para agen. Lihat [Alat CLI yang sudah terinstal](18-development-tools.md#preinstalled-cli-tools) untuk menginstal satu alat atau menggunakan instalasimu sendiri.

`grok` diinstal melalui paket pihak pertama `grok` dari mise, dengan cara yang sama seperti `claude` dan `codex`. Jalankan `grok`, atau pilih di bawah _Setup > Defaults > Agent_. Lewati installer `curl | bash` di x.ai. Cara itu menaruh salinan kedua di `~/.grok/bin`, mendahulukannya di `PATH`, dan menimpa wrapper Omarchy.

`dsh` membuka UI browser-nya di `127.0.0.1:3080`, dengan direktori peluncuran sebagai workspace default-nya. UI browser-nya tidak menerima prompt awal, jadi `omarchy agent prompt` membukanya dengan prompt di clipboard untuk kamu tempel. Omarchy menjalankannya dengan preset izin no-approval dari DeepSeek. DeepSeek Harness mengunggah log sesi ke DeepSeek saat kamu menggunakan API model resminya; matikan itu di bawah _Settings > General > Upload Session Log_ di UI browser-nya. Feedback yang kamu kirimkan ke sana juga diunggah bersama sesi, kecuali kamu menjalankannya dengan `DSH_TELEMETRY_MODE=DISABLED`.

### Agen default

Pilih agen default-mu dengan `omarchy default agent <name>` atau di bawah _Setup > Defaults > Agent_ di Omarchy Menu (`Super + Space`). Jika agennya belum terinstal, memilihnya akan menginstalnya terlebih dahulu. Omarchy yang baru akan mengundangmu untuk membuat pilihan ini dengan notifikasi satu kali.

Memilih Claude juga berusaha menyiapkan ekstensi browser-nya untuk Chromium, Chrome, Brave, Brave Origin, dan Edge. Penyiapan ekstensi berlaku untuk semua pengguna dan mungkin meminta kata sandi sistemmu; membatalkan atau gagal menginstal ekstensi tetap memilih dan meluncurkan Claude. Mulai ulang browser-mu, aktifkan ekstensi jika diminta, dan masuk ke Claude untuk menyelesaikan penyambungannya. Jalankan `/chrome` di Claude untuk memeriksa koneksinya. Firefox dan Zen tidak mendukung ekstensi ini. Jika Claude sudah menjadi default-mu sebelum penyiapan ini ditambahkan, pilih lagi untuk menginstal ekstensinya.

Setelah kamu memilih, `Super + Shift + Ctrl + A` meluncurkan agen default di jendela terminal khusus (atau memunculkan pemilih jika kamu belum memilih). Kamu juga bisa meluncurkannya langsung ke sebuah tugas dengan `omarchy agent prompt "Review this project"`. Freebuff dan DeepSeek Harness tidak menerima prompt awal, jadi keduanya dibuka dengan prompt di clipboard untuk kamu tempel sebagai gantinya. Agen yang diluncurkan dengan cara ini berjalan tanpa pengawasan dalam mode jangan-berhenti-untuk-bertanya masing-masing, jadi bersiaplah karena mereka benar-benar akan melakukan sesuatu! MiniMax Code tidak punya mode seperti itu untuk sesi interaktifnya, jadi ia meminta izin seperti biasa. Dan karena agen menolak mengingat kepercayaan untuk direktori home-mu, peluncuran dari `$HOME` dimulai di `~/Work` sebagai gantinya.

Ada pintasan terminal juga: `a` menjalankan agen default secara inline di terminal saat ini, sementara `c`, `cx`, dan `cy` memulai OpenCode, Claude Code, dan Codex secara langsung (lagi-lagi dalam mode auto-approving mereka). Perubahan tema juga tersinkron ke para agen: Claude Code, Pi, OpenCode, dan Hermes (setelah Omarchy menginstalnya) semuanya mengikuti saat kamu mengganti tema Omarchy.

### Panel agen

Bar atas memiliki ikon agen. Sebelum kamu menyiapkan agen, panelnya memandumu masuk ke Claude, Codex, atau Grok, dan yang pertama menjadi agen default-mu. Setelah itu, panel menaruh setiap langganan di satu halaman: setiap agen dan akun dengan paketnya, meter untuk masing-masing batas sesi 5 jam dan batas mingguannya beserta waktu hingga reset (arahkan kursor untuk persentase persisnya), atau sisa saldo prabayar, di bawah baris yang bergilir menampilkan apa yang telah kamu gunakan di semuanya, seperti token minggu ini dan model yang paling sering kamu gunakan. Di bawah _Make something_ ia menawarkan prompt starter untuk tema, plugin, atau aplikasi baru yang menyerahkan tugasnya ke agen default-mu. Aplikasi dibangun dengan cara yang sama seperti Hype, Monologue, dan Omacut milik Omarchy sendiri, dalam C++ dan Qt Quick, mengikuti skill agen omarchy-app, dan compiler serta komponen Qt yang mereka butuhkan sudah terinstal. Claude Code, Codex, Grok, Kimi, Cursor dan jatah Grok Bot-nya, GitHub Copilot, Muse, Antigravity, Kimchi, dan Devin dicakup sejak awal dengan batas-batasnya, dan Hermes, Mistral Vibe, dan Qwen Code menunjukkan sesi dan token mereka setelah kamu menggunakannya. Paket dan kunci provider yang kamu gunakan melalui pi, omp, atau opencode juga muncul: OpenCode Zen dan Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan, dan Synthetic dengan batas-batasnya; Fireworks, OpenRouter, dan DeepSeek dengan saldo prabayarnya; dan model yang kamu jalankan di perangkat kerasmu sendiri di bawah Local models. Setiap agen dihitung sekali, di bawah pihak yang menagihnya, berapa pun banyaknya harness yang kamu jalankan melaluinya.

Klik kiri ikon bar untuk panel, klik kanan untuk meluncurkan agen default-mu. Rekaman penggunaan di baliknya dibuat ulang setiap 15 menit oleh `omarchy agent usage-update`, dan panel bahkan bisa menggabungkan penggunaan dari mesinmu yang lain melalui folder yang disinkronkan. Lihat README di bawah `$OMARCHY_PATH/shell/plugins/agents/` untuk pengaturan lengkapnya.

### Beberapa langganan

Jika kamu membayar lebih dari satu paket Claude, Codex, atau Grok — misalnya Max pribadi dan satu untuk pekerjaan — Omarchy bisa membuat semuanya tetap masuk dan berpindah di antaranya. Tambahkan langganan dengan + di panel agen, yang memandumu langsung di sana, atau dengan `omarchy agent account add claude Work` (atau `codex`, atau `grok`). Ia menginstal CLI jika belum ada. Akun pertama untuk sebuah provider masuk melalui browser normalmu, tepat di tempat CLI selalu mencarinya. Setiap akun setelah itu masuk melalui jendela privat, agar akun yang sudah masuk di browser-mu tidak terambil secara tidak sengaja; masuklah di sana sebagai akun yang sedang kamu tambahkan, dan tutup jendela privat yang sudah terbuka terlebih dahulu. Jangan pernah keluar dari CLI untuk melakukan ini: keluar akan mencabut login yang tersimpan, dan akun itu harus ditambahkan lagi.

Untuk menyalin login langgananmu ke mesin Omarchy lain melalui SSH, jalankan `omarchy agent account copy user@laptop`. Pengirim menyediakan penerima sementara ketika tujuan belum memasangnya, jadi mesin Omarchy yang lebih lama bisa menerima akun tanpa pembaruan. Penerima yang terinstal didahulukan. Ini menyalin semua langganan Claude, Codex, dan Grok; tambahkan nama provider untuk memilihnya, seperti dalam `omarchy agent account copy laptop claude`. Nama akun dan ID perintah cocok dengan sumbernya, termasuk akun yang sudah ada di tujuan. Akun tujuan yang tidak terkait menerima akhiran numerik jika namanya bentrok, dan pengaturan, skill, plugin, serta riwayat percakapan tetap lokal di setiap mesin.

Kredensial tujuan yang sudah ada dipertahankan. Akun sumber yang sudah masuk di sana namanya disinkronkan tanpa mengganti kredensialnya; akun lain ditambahkan di sampingnya. Untuk mengganti kredensial tersimpan untuk akun yang cocok, gunakan `omarchy agent account copy --replace laptop claude` setelah keluar dari sesi akun tersebut di tujuan. Tujuan yang masih baru juga mendapatkan akun aktif dan preferensi peralihan dari sumber; tujuan yang sudah mapan mempertahankan miliknya sendiri.

Kredensial berjalan melalui SSH dan disimpan dalam file privat di tujuan, jadi salin hanya ke mesin yang kamu percaya. Ini adalah penyalinan satu kali, bukan sinkronisasi berkelanjutan. Token refresh Codex bisa dirotasi oleh mesin lain, membuat login yang tersalin membutuhkan pembaruan; login terpisah tetap menjadi pilihan paling andal untuk penggunaan bersamaan di beberapa mesin. Lihat [panduan autentikasi akun Codex](https://developers.openai.com/codex/auth/ci-cd-auth).

Satu akun per provider aktif, dan setiap sesi baru dimulai sebagai akun itu: `cx`, `cy`, `claude`, `codex`, atau `grok` biasa, apa pun yang diluncurkan melalui `omarchy agent`, dan skrip atau editor yang menemukan CLI di `PATH`. Beralih dengan `omarchy agent account use work` (dan kembali dengan `omarchy agent account use main`), atau di panel dengan menekan nomor akun lalu `Enter` (atau mengklik tombol Use-nya). Sesi yang sudah berjalan tetap pada akun yang mereka mulai. Riwayat percakapan, pengaturan, skill, dan plugin dibagikan antarakun, jadi `claude --continue` di folder yang sama melanjutkan dari tempat terakhir kamu tinggalkan di akun baru.

Dengan lebih dari satu akun, panel menunjukkan batas setiap akun berdampingan, dengan akun aktif ditandai. Secara default Omarchy memberitahumu saat akun aktif melewati 95% dari sebuah batas, dan mengklik notifikasi beralih ke akun dengan ruang tersisa paling banyak. Arahkan kursor ke baris akun di panel dan klik Autoswitch yang muncul di samping Use (atau tekan `m`), atau jalankan `omarchy agent account mode auto`, agar ia beralih sendiri sebagai gantinya; saat aktif, Autoswitch menggantikan Use, dan mengkliknya lagi kembali ke mode pemberitahuan. Tambahkan angka untuk mengubah ambangnya, seperti dalam `omarchy agent account mode auto 90`. Jika setiap akun melewati ambang, kamu akan diberitahu sekali, beserta akun mana yang bebas terlebih dahulu. Saat akun aktif berada dalam 15 poin dari ambangnya (80% pada default), batasnya diperiksa setiap tiga menit, bukan setiap 15 menit.

`omarchy agent account list` menunjukkan setiap akun dan batas terbarunya, `omarchy agent account remove work` melupakan satu akun, dan `omarchy agent account rename primary Hey` mengganti nama satu akun (atau klik nama akun di panel). Perintah-perintah ini bekerja pada akun agen default-mu; untuk menjangkau provider lain, sebutkan namanya terlebih dahulu, seperti dalam `omarchy agent account use codex side`. Login yang sudah kamu miliki di `~/.claude` atau `~/.codex` adalah akun _Main_ dan tetap di tempatnya. Akun yang tidak digunakan lebih dari sekitar delapan jam bisa menunjukkan _Sign-in required_; klik untuk masuk ke akun itu lagi langsung di panel, atau mulai sesi di dalamnya, yang menyegarkan login dengan sendirinya. Server MCP yang kamu miliki saat akun ditambahkan ikut ke akun itu, tetapi server yang kamu tambahkan nanti dengan `claude mcp add` hanya mencapai akun tempat kamu menambahkannya. Claude Desktop dan alat yang dikonfigurasi dengan path absolut ke biner CLI tidak mengikuti peralihan. `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, atau `GROK_HOME` yang eksplisit didahulukan atas akun yang dipilih.

### Diagnosis crash

Omarchy mengawasi systemd-coredump untuk crash proses. Saat sesuatu mengalami segfault, kamu akan mendapat notifikasi "Process crashed" — klik notifikasi itu, dan crash diserahkan ke agen default-mu beserta skill diagnose-crash dari Omarchy, yang memandu agen menetapkan fakta dari core dump dan memutuskan apakah crash itu layak dilaporkan ke upstream. Kamu juga bisa menjalankannya secara manual terhadap PID apa pun dari `coredumpctl list` dengan `omarchy agent crash <pid>`.

Pengawasan ini aktif secara default. Matikan di bawah _Trigger > Toggle > Crash Capture_ (atau dengan `omarchy toggle crash-capture`) dan notifikasi berhenti; `omarchy agent crash <pid>` tetap bekerja secara manual.

Crash juga bisa dibisukan satu program pada satu waktu, yang ditawarkan diagnosis kepadamu di akhir. `omarchy crash mute hyprland` menghentikan notifikasi hanya untuk program itu, `omarchy crash mute hyprland off` mengembalikannya, dan `omarchy crash mute` sendiri mencantumkan apa yang telah kamu bisukan. Ia menerima path biner sama senangnya seperti namanya, jadi `omarchy crash mute /usr/bin/hyprland` melakukan hal yang sama. Beri tanda kutip pada nama yang mengandung spasi, seperti dalam `omarchy crash mute 'Some App'`. Semua yang lain tetap memberi notifikasi, dan program yang dibisukan tetap crash — ini menyembunyikan pengingat, bukan memperbaiki apa pun.

### Aplikasi desktop

Menu _Install > AI_ juga membawa beberapa aplikasi AI grafis: aplikasi desktop ChatGPT, aplikasi desktop Claude (beta Linux dari Anthropic, dengan tab Chat, Cowork, dan Claude Code), Grok Bot untuk mengobrol dengan model xAI, Hermes Desktop, OpenClaw, aplikasi desktop Perplexity, dan T3 Code. Grok Bot adalah aplikasi obrolan desktop. Agen coding-nya adalah perintah `grok`.

Hermes Desktop adalah yang perlu kamu ketahui, karena sebuah mesin memiliki satu Hermes, dan Hermes itu milik aplikasi: Hermes hanya pernah diinstal melalui aplikasi, dan perintah `hermes` yang dijalankan agen default adalah milik aplikasi. Memilih Hermes sebagai agen default menginstal hal yang sama seperti entri _Install > AI_: paketnya, dan runtime Hermes di bawah `~/.hermes` yang disiapkan oleh installer Hermes sendiri, yang memakan waktu beberapa menit pada kali pertama. Runtime itu adalah satu-satunya Hermes yang digunakan perintah terminal `hermes`, agen default, dan aplikasi, dan ia memperbarui dirinya sendiri dengan `hermes update` daripada menunggu rilis Omarchy. Menginstalnya juga memberi Hermes tema Omarchy sebagai skin bernama `omarchy`, yang diikuti setiap permukaan Hermes saat kamu mengganti tema; pilih yang lain di pengaturan Appearance Hermes atau dengan `/skin` jika kamu lebih suka tidak, dan Omarchy membiarkan pilihan itu. Menghapus aplikasi di bawah _Remove > AI_ menutup Hermes terlebih dahulu, termasuk gateway, membawa runtime itu pergi, dan menyimpan obrolan, memori, dan skill yang ditulis Hermes untuk dirinya sendiri kecuali kamu menyuruh sebaliknya: ia bertanya, dengan default tidak, apakah data itu dan pengaturan koneksimu juga harus dihapus.

Pengalaman desktop OpenClaw adalah Control UI-nya, yang terbuka sebagai aplikasi web yang didukung oleh gateway lokalnya sendiri. OpenClaw tinggal di `~/.openclaw` dan memperbarui dirinya sendiri: gunakan tombol "Update Gateway" di Control UI atau jalankan `openclaw update`, dan gateway dimulai ulang pada versi baru. Omarchy hanya memilih rilis tempat instalasi baru dimulai. Menghapus OpenClaw di bawah _Remove > AI_ membawa layanan gateway dan aplikasinya pergi, lalu bertanya apakah `~/.openclaw` juga harus dihapus, karena itu menyimpan obrolan dan kredensialmu bersama OpenClaw itu sendiri dan runtime plugin yang diunduhnya; default-nya menyimpannya, dan menginstal OpenClaw lagi akan mengambilnya kembali.

T3 Code berjalan dari rilis AppImage resminya di `~/.local/share/t3code` daripada dari sebuah paket, jadi ia memperbarui dirinya sendiri. Menginstalnya bertanya apakah akan memulai di kanal Stable atau Nightly; ganti nanti di pengaturan T3 Code. Thread dan pengaturanmu tinggal di `~/.t3`, dan menghapus T3 Code di bawah _Remove > AI_ membawanya pergi.

### LLM lokal

Omarchy merekomendasikan dua cara menjalankan model LLM lokal: LM Studio dan Ollama. LM Studio menyediakan antarmuka GUI untuk menemukan model open-weight, menginstalnya, dan menjalankannya. Ini cara yang bagus untuk memulai dengan mudah. Ollama menawarkan CLI untuk melakukan hal serupa. Tetapi jika kamu baru mengenal model lokal, saya akan mulai dengan LM Studio. Kamu bisa menginstal salah satunya di bawah _Install > AI_ di Omarchy Menu.

### Skill Omarchy

Skill agen membantu AI menggunakan alat tertentu dengan cara tertentu, dan Omarchy dilengkapi dengan skill default untuk menyesuaikan sistem. Seperti mengubah konfigurasi Hyprland-mu, menyesuaikan bar, atau bahkan membuat tema baru dari awal. Ia ditautkan secara simbolis ke direktori skill untuk Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` dan setiap `~/.hermes/profiles/*/skills`), dan lokasi generik `~/.agents/skills`, jadi sebagian besar harness mengambilnya secara otomatis.

Tetapi kamu harus memperlakukan skill ini sebagai eksperimental. Model yang berbeda akan menggunakannya dengan efek yang berbeda. Sebaiknya jalankan dalam mode plan terlebih dahulu, agar kamu punya gambaran tentang apa yang ingin diubah agen. Lalu bersiaplah untuk melakukan rollback perubahan atau bahkan menjalankan `omarchy reinstall configs`, jika agen mengacaukan segalanya.
