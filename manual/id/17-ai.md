# AI

Omarchy memperlakukan agen coding AI sebagai warga kelas satu, tetapi ia tidak memilihkan favorit untukmu. Sebaliknya, setiap CLI agen coding utama sudah terhubung sejak awal sebagai peluncur yang dimuat secara lazy. Peluncur-peluncur ini adalah stub kecil yang dikelola [mise](https://mise.jdx.dev/) di `~/.local/bin/`, jadi tidak ada yang diunduh sampai pertama kali kamu benar-benar menjalankannya. Hermes adalah pengecualian: tidak ada stub untuknya, dan memilihnya akan memasang Hermes Desktop, seperti yang dijelaskan di _Desktop apps_ di bawah. Jalankan salah satu dari ini dan lakukan autentikasi saat diminta:

| Perintah   | Agen                                                             |
|------------|------------------------------------------------------------------|
| `claude`   | [Claude Code](https://code.claude.com/docs/en/overview)          |
| `codex`    | [OpenAI Codex](https://github.com/openai/codex)                  |
| `opencode` | [OpenCode](https://opencode.ai/)                                 |
| `agy`      | [Google Antigravity CLI](https://github.com/google-antigravity/antigravity-cli) |
| `copilot`  | [GitHub Copilot CLI](https://github.com/github/copilot-cli)      |
| `crush`    | [Crush](https://github.com/charmbracelet/crush)                  |
| `grok`     | [Grok Build](https://x.ai/build) dari xAI                        |
| `kimi`     | [Kimi Code](https://www.kimi.com/code/docs/en/)                  |
| `pi`       | [Pi dari Mario Zechner](https://github.com/badlogic/pi-mono)     |
| `omp`      | [Oh My Pi](https://github.com/can1357/oh-my-pi)                  |
| `ori`      | [Ori](https://openrouter.ai/docs/guides/ori/harness), harness milik OpenRouter |
| `hermes`   | [Hermes](https://hermes-agent.nousresearch.com/), agen milik Nous Research  |
| `muse`     | [Muse Code](https://dev.meta.ai), agen coding milik Meta         |
| `cursor-agent` | [Cursor CLI](https://cursor.com/cli)                         |

`ori` adalah yang berbeda dari yang lain: ia menjalankan harness lain terhadap seluruh katalog model OpenRouter, jadi `ori claude`, `ori codex`, atau `ori opencode` memulai agen-agen tersebut pada model apa pun yang kamu tunjukkan kepadanya, dan `ori code` adalah agen Ori sendiri.

Untuk membungkus CLI tambahan dengan cara yang sama, jalankan `omarchy-mise-install <package> [command-name]`. Stub-stub tersebut diperbarui bersama semua hal lain yang dikelola mise saat kamu menjalankan `omarchy update` (atau alias `mup`).

`grok` dipasang melalui paket `grok` first-party dari mise, dengan cara yang sama seperti `claude` dan `codex`. Jalankan `grok`, atau pilih di bawah _Setup > Defaults > Agent_. Lewati installer `curl | bash` di x.ai. Jalur itu meletakkan salinan kedua di `~/.grok/bin`, menempatkannya di depan pada `PATH`, dan menimpa wrapper milik Omarchy.

### Agen bawaan

Pilih agen bawaanmu dengan `omarchy default agent <name>` atau di bawah _Setup > Defaults > Agent_ di Omarchy Menu (`Super + Space`). Jika agen belum terpasang, memilihnya akan memasangnya terlebih dahulu. Omarchy yang baru akan mengundangmu membuat pilihan ini dengan notifikasi satu kali.

Memilih Claude juga mencoba menyiapkan ekstensi browser-nya untuk Chromium, Chrome, Brave, Brave Origin, dan Edge. Penyiapan ekstensi berlaku untuk semua pengguna dan mungkin meminta kata sandi sistemmu; membatalkan atau pemasangan ekstensi yang gagal tetap akan memilih dan meluncurkan Claude. Mulai ulang browser-mu, aktifkan ekstensi jika diminta, dan masuk ke Claude untuk menyelesaikan penyambungannya. Jalankan `/chrome` di Claude untuk memeriksa koneksi. Firefox dan Zen tidak mendukung ekstensi ini. Jika Claude sudah menjadi bawaanmu sebelum penyiapan ini ditambahkan, pilih lagi untuk memasang ekstensinya.

[Muse Code](https://dev.meta.ai) — `muse` milik Meta — menggunakan stub mise yang sudah terpasang seperti agen lainnya. Memilihnya sebagai bawaan akan memasang peluncur resmi Meta melalui backend HTTP mise. Peluncur tersebut memverifikasi dan memperbarui biner native untuk mesinmu.

Setelah kamu memilih, `Super + Shift + Ctrl + A` meluncurkan agen bawaan di jendela terminal khusus (atau memunculkan pemilih jika kamu belum memilih). Kamu juga bisa meluncurkannya langsung ke sebuah tugas dengan `omarchy agent prompt "Review this project"`. Agen yang diluncurkan dengan cara ini berjalan tanpa pengawasan dalam mode jangan-berhenti-untuk-bertanya mereka masing-masing, jadi siap-siaplah mereka benar-benar melakukan sesuatu! Dan karena agen menolak mengingat kepercayaan untuk direktori home-mu, peluncuran dari `$HOME` akan dimulai di `~/Work` sebagai gantinya.

Ada juga pintasan terminal: `a` menjalankan agen bawaan secara inline di terminal saat ini, sementara `c`, `cx`, dan `cy` memulai OpenCode, Claude Code, dan Codex secara langsung (lagi-lagi dalam mode persetujuan otomatis mereka). Perubahan tema juga tersinkron ke para agen: Claude Code, Pi, OpenCode, dan Hermes (setelah Omarchy memasangnya) semuanya ikut serta saat kamu mengganti tema Omarchy.

### Panel agen

Bilah atas memiliki ikon agen. Sebelum kamu menyiapkan sebuah agen, panelnya memandumu masuk ke Claude, Codex, atau Grok, dan yang pertama menjadi agen bawaanmu. Setelah itu, panel menempatkan setiap langganan dalam satu halaman: setiap agen dan akun beserta paketnya, meteran untuk masing-masing batas sesi 5 jam dan batas mingguan beserta waktu sampai batas itu diatur ulang (arahkan kursor untuk persentase pastinya), atau sisa saldo prabayar, di bawah sebuah baris yang berganti-ganti menampilkan apa yang telah kamu gunakan di semuanya, seperti token minggu ini dan model yang paling sering kamu gunakan. Di bawah _Make something_ panel menawarkan prompt pemula untuk tema, plugin, atau aplikasi baru yang menyerahkan tugasnya kepada agen bawaanmu. Aplikasi dibangun dengan cara yang sama seperti Hype, Monologue, dan Omacut milik Omarchy sendiri, dalam C++ dan Qt Quick, mengikuti skill agen omarchy-app, dan compiler serta bagian-bagian Qt yang mereka butuhkan sudah terpasang. Claude Code, Codex, Grok, Fireworks, dan Kimi didukung langsung dari awal. Kimi saat ini melaporkan batas kuota akun tanpa statistik token atau prompt lokal.

Klik kiri ikon bilah untuk panel, klik kanan untuk meluncurkan agen bawaanmu. Catatan penggunaan di belakangnya dibuat ulang setiap 15 menit oleh `omarchy agent usage-update`, dan panel bahkan bisa menggabungkan penggunaan dari mesin lain milikmu melalui folder yang tersinkron. Lihat README di bawah `$OMARCHY_PATH/shell/plugins/agents/` untuk pengaturan lengkapnya.

### Beberapa langganan

Jika kamu membayar lebih dari satu paket Claude, Codex, atau Grok — misalnya Max pribadi dan satu untuk pekerjaan — Omarchy bisa membuat semuanya tetap masuk dan berpindah di antara mereka. Tambahkan langganan dengan + di panel agen, yang memandumu langsung di sana, atau dengan `omarchy agent account add claude Work` (atau `codex`, atau `grok`). Ini memasang CLI jika belum ada. Akun pertama untuk sebuah penyedia masuk melalui browser normalmu, tepat di tempat CLI selalu mencarinya. Setiap akun setelahnya masuk melalui jendela pribadi, supaya akun yang sudah masuk di browser-mu tidak terambil secara tidak sengaja; masuklah di sana sebagai akun yang sedang kamu tambahkan, dan tutup jendela pribadi apa pun yang sudah terbuka terlebih dahulu. Jangan pernah keluar dari CLI untuk melakukan ini: keluar akan mencabut proses masuk yang tersimpan, dan akun itu harus ditambahkan lagi.

Untuk menyalin login langgananmu ke mesin Omarchy lain melalui SSH, jalankan `omarchy agent account copy user@laptop`. Pengirim menyediakan penerima sementara ketika tujuan belum memilikinya terpasang, jadi mesin Omarchy yang lebih lama bisa menerima akun tanpa pembaruan. Penerima yang terpasang lebih diutamakan. Ini menyalin semua langganan Claude, Codex, dan Grok; tambahkan nama penyedia untuk memilihnya, seperti pada `omarchy agent account copy laptop claude`. Nama akun dan ID perintah sesuai dengan sumbernya, termasuk akun yang sudah ada di tujuan. Akun tujuan yang tidak terkait menerima akhiran numerik jika namanya bertabrakan, dan pengaturan, skill, plugin, serta riwayat percakapan tetap lokal di setiap mesin.

Kredensial tujuan yang sudah ada tetap dipertahankan. Sebuah akun sumber yang sudah masuk di sana namanya akan disinkronkan tanpa mengganti kredensialnya; akun lainnya ditambahkan di sampingnya. Untuk mengganti kredensial tersimpan untuk akun yang cocok, gunakan `omarchy agent account copy --replace laptop claude` setelah menutup sesi akun tersebut di tujuan. Tujuan yang masih baru juga mendapatkan akun aktif dan preferensi pergantian milik sumber; tujuan yang sudah mapan mempertahankan miliknya sendiri.

Kredensial berpindah melalui SSH dan disimpan dalam berkas pribadi di tujuan, jadi salinlah hanya ke mesin yang kamu percaya. Ini adalah penyalinan satu kali, bukan sinkronisasi yang berkelanjutan. Token refresh Codex bisa dirotasi oleh mesin lain, sehingga login yang disalin perlu diperbarui; proses masuk yang terpisah tetap menjadi pilihan paling andal untuk penggunaan serentak di beberapa mesin. Lihat [panduan autentikasi akun Codex](https://developers.openai.com/codex/auth/ci-cd-auth).

Satu akun per penyedia aktif, dan setiap sesi baru dimulai sebagai akun tersebut: `cx`, `cy`, `claude`, `codex`, atau `grok` biasa, apa pun yang diluncurkan melalui `omarchy agent`, serta skrip atau editor yang menemukan CLI di `PATH`. Beralihlah dengan `omarchy agent account use work` (dan kembali dengan `omarchy agent account use main`), atau di panel dengan menekan nomor akun lalu `Enter` (atau mengklik tombol Use-nya). Sesi yang sudah berjalan tetap pada akun yang mereka gunakan saat mulai. Riwayat percakapan, pengaturan, skill, dan plugin dibagikan antarakun, jadi `claude --continue` di folder yang sama melanjutkan dari tempat kamu berhenti di akun baru.

Dengan lebih dari satu akun, panel menampilkan batas setiap akun berdampingan, dengan akun aktif ditandai. Secara bawaan Omarchy memberi tahumu ketika akun aktif melewati 95% dari sebuah batas, dan mengklik notifikasi akan beralih ke akun dengan ruang kosong terbanyak. Arahkan kursor ke baris sebuah akun di panel dan klik Autoswitch yang muncul di samping Use (atau tekan `m`), atau jalankan `omarchy agent account mode auto`, untuk membuatnya beralih dengan sendirinya; selagi aktif, Autoswitch mengambil tempat Use, dan mengkliknya lagi akan kembali ke pemberian notifikasi. Tambahkan angka untuk mengubah ambang batas, seperti pada `omarchy agent account mode auto 90`. Jika setiap akun berada di atas ambang batas, kamu akan mendengarnya sekali, beserta akun mana yang kosong lebih dulu. Ketika akun aktif berada dalam 15 poin dari ambang batasnya (80% pada bawaan), batasnya diperiksa setiap tiga menit alih-alih setiap 15 menit.

`omarchy agent account list` menampilkan setiap akun dan batas terbarunya, `omarchy agent account remove work` melupakan satu akun, dan `omarchy agent account rename primary Hey` mengganti nama satu akun (atau klik nama akun di panel). Perintah-perintah ini bekerja pada akun agen bawaanmu; untuk menjangkau penyedia lain, sebutkan namanya terlebih dahulu, seperti pada `omarchy agent account use codex side`. Login yang sudah kamu miliki di `~/.claude` atau `~/.codex` adalah akun _Main_ dan tetap di tempatnya. Akun yang tidak digunakan selama lebih dari sekitar delapan jam dapat menunjukkan _Sign-in required_; klik untuk memasukkan akun tersebut lagi langsung di panel, atau mulai sesi di dalamnya, yang akan menyegarkan proses masuk dengan sendirinya. Server MCP yang kamu miliki ketika sebuah akun ditambahkan ikut bersamanya, tetapi server yang kamu tambahkan kemudian dengan `claude mcp add` hanya mencapai akun tempat kamu menambahkannya. Claude Desktop dan alat yang dikonfigurasi dengan jalur absolut ke biner CLI tidak mengikuti pergantian. `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, atau `GROK_HOME` yang eksplisit lebih diutamakan daripada akun yang dipilih.

### Diagnosis crash

Omarchy mengawasi systemd-coredump untuk crash proses. Ketika sesuatu mengalami segfault, kamu akan mendapatkan notifikasi "Process crashed" — klik notifikasi itu, dan crash tersebut diserahkan kepada agen bawaanmu bersama skill diagnose-crash milik Omarchy, yang memandu agen menetapkan fakta dari core dump dan memutuskan apakah crash tersebut layak dilaporkan ke upstream. Kamu juga bisa menjalankannya secara manual terhadap PID apa pun dari `coredumpctl list` dengan `omarchy agent crash <pid>`.

Pengawasan aktif secara bawaan. Matikan di bawah _Trigger > Toggle > Crash Capture_ (atau dengan `omarchy toggle crash-capture`) dan notifikasi akan berhenti; `omarchy agent crash <pid>` tetap berfungsi secara manual.

Crash juga bisa dibungkam satu program pada satu waktu, itulah yang ditawarkan diagnosis kepadamu di akhir. `omarchy crash mute hyprland` menghentikan notifikasi hanya untuk program tersebut, `omarchy crash mute hyprland off` memunculkannya kembali, dan `omarchy crash mute` dengan sendirinya mencantumkan apa yang telah kamu bungkam. Ia menerima jalur biner se senang namanya, jadi `omarchy crash mute /usr/bin/hyprland` melakukan hal yang sama. Kutip nama yang memiliki spasi di dalamnya, seperti pada `omarchy crash mute 'Some App'`. Semua hal lainnya tetap memberi notifikasi, dan program yang dibungkam tetap crash — ini menyembunyikan pengingatnya, tidak memperbaiki apa pun.

### Aplikasi desktop

Menu _Install > AI_ juga membawa beberapa aplikasi AI grafis: aplikasi desktop ChatGPT, aplikasi desktop Claude (beta Linux dari Anthropic, dengan tab Chat, Cowork, dan Claude Code), Grok Bot untuk mengobrol dengan model xAI, Hermes Desktop, OpenClaw, dan aplikasi desktop Perplexity. Grok Bot adalah aplikasi obrolan desktop. Agen coding-nya adalah perintah `grok`.

Hermes Desktop adalah satu-satunya yang perlu diketahui, karena sebuah mesin memiliki satu Hermes, dan itu milik aplikasi ini: Hermes hanya pernah dipasang melalui aplikasi, dan perintah `hermes` yang dijalankan agen bawaan adalah milik aplikasi ini. Memilih Hermes sebagai agen bawaan memasang hal yang sama seperti entri _Install > AI_: paketnya, dan runtime Hermes di bawah `~/.hermes` yang disiapkan oleh installer Hermes sendiri, yang memakan waktu beberapa menit untuk pertama kali. Runtime tersebut adalah satu-satunya Hermes yang digunakan perintah `hermes` di terminal, agen bawaan, dan aplikasi, dan ia memperbarui dirinya sendiri dengan `hermes update` alih-alih menunggu rilis Omarchy. Memasangnya juga memberikan kepada Hermes tema Omarchy sebagai skin bernama `omarchy`, yang diikuti setiap permukaan Hermes saat kamu berganti tema; pilih yang lain di bawah pengaturan Appearance Hermes atau dengan `/skin` jika kamu tidak menginginkannya, dan Omarchy membiarkan pilihan itu sendiri. Menghapus aplikasi di bawah _Remove > AI_ menutup Hermes terlebih dahulu, termasuk gateway, membawa runtime tersebut bersamanya, dan mempertahankan obrolanmu, ingatanmu, serta skill yang ditulis Hermes untuk dirinya sendiri kecuali kamu menyuruhnya sebaliknya: ia bertanya, dengan bawaan tidak, apakah data tersebut dan pengaturan koneksimu juga harus ikut dibuang.

Pengalaman desktop OpenClaw adalah Control UI-nya, yang terbuka sebagai aplikasi web yang didukung oleh gateway lokalnya sendiri. OpenClaw berada di `~/.openclaw` dan memperbarui dirinya sendiri: gunakan tombol "Update Gateway" di Control UI atau jalankan `openclaw update`, dan gateway memulai ulang pada versi baru. Omarchy hanya memilih rilis tempat pemasangan baru dimulai. Menghapus OpenClaw di bawah _Remove > AI_ membawa layanan gateway dan aplikasi bersamanya, lalu bertanya apakah `~/.openclaw` juga harus dibuang, karena tempat itu menyimpan obrolan dan kredensialmu di samping OpenClaw itu sendiri dan runtime plugin yang diunduhnya; bawaannya mempertahankannya, dan memasang OpenClaw lagi akan mengambilnya kembali.

### LLM lokal

Omarchy merekomendasikan dua cara menjalankan model LLM lokal: LM Studio dan Ollama. LM Studio menyediakan antarmuka GUI untuk menemukan model open-weight, memasangnya, dan menjalankannya. Ini cara yang bagus untuk memulai dengan mudah. Ollama menawarkan CLI untuk melakukan hal yang sama. Tetapi jika kamu baru mengenal model lokal, saya sarankan mulai dengan LM Studio. Kamu bisa memasang salah satunya di bawah _Install > AI_ di Omarchy Menu.

### Skill Omarchy

Skill agen membantu AI menggunakan alat-alat spesifik dengan cara yang spesifik, dan Omarchy hadir dengan skill bawaan untuk menyesuaikan sistem. Seperti mengutak-atik konfigurasi Hyprland-mu, menyesuaikan bilah, atau bahkan membuat tema baru dari nol. Ia di-symlink ke dalam direktori skill untuk Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` dan setiap `~/.hermes/profiles/*/skills`), dan lokasi generik `~/.agents/skills`, jadi kebanyakan harness mengambilnya secara otomatis.

Namun, kamu harus memperlakukan skill ini sebagai eksperimental. Model yang berbeda akan menggunakannya dengan efek yang berbeda. Cara terbaik adalah menjalankan mode rencana terlebih dahulu, supaya kamu punya gambaran tentang apa yang ingin diubah oleh agen. Lalu siaplah untuk mengembalikan perubahan atau bahkan menjalankan `omarchy reinstall configs`, jika agen mengacaukan semuanya.
