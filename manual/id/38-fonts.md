# Font

Omarchy menggunakan JetBrainsMono Nerd Font sebagai font terminal sekaligus font sistem secara default.

 ![fonts-jetbrainsmono](images/fonts-jetbrainsmono.webp)

Anda dapat mengubahnya melalui menu _Appearance > Font_ di menu Omarchy (`Super + Space`). Itu mengatur font monospace di mana saja: terminal, bar, dan apa pun lainnya yang memintanya.

Anda dapat menginstal font pemrograman populer lainnya melalui _Install > Style > Font_ di menu Omarchy: Cascadia Mono, Meslo LG Mono, Fira Code, Victor Code, Bitstream Vera Mono, dan Iosevka semuanya hanya berjarak satu klik, dalam versi Nerd Font-nya agar glyph di bar dan terminal tetap berfungsi. Menginstal salah satunya juga akan mengalihkan seluruh sistem ke font tersebut, dan Anda dapat beralih kembali kapan saja di _Appearance > Font_.

## Tionghoa, Jepang, dan Korea

Bahasa Tionghoa, Jepang, dan Korea berbagi banyak karakter tetapi menggambar sebagian di antaranya secara berbeda, sehingga karakter yang sama terlihat tepat bagi satu pembaca dan asing bagi pembaca lain. Memilih salah satu bahasa ini di _Setup > Region > Language_, atau metode inputnya, akan menetapkan bentuk yang sesuai. Untuk memilihnya sendiri, jalankan `omarchy font cjk jp`, `kr`, `sc`, `tc` (Taiwan), atau `hk` (Hong Kong) di terminal; `omarchy font cjk default` kembali ke pilihan sistem, yaitu bentuk Jepang. Teks yang ditandai oleh halaman web atau dokumen dengan bahasanya sendiri, dan seluruh desktop selama berada dalam salah satu bahasa ini, tetap menggunakan bentuk bahasa tersebut.
