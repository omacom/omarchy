# Font

Omarchy menggunakan JetBrainsMono Nerd Font sebagai font terminal sekaligus font sistem secara bawaan.

 ![fonts-jetbrainsmono](images/fonts-jetbrainsmono.webp)

Kamu bisa mengubahnya melalui menu _Gaya > Font_ di menu Omarchy (`Super + Space`). Itu mengatur font monospace di mana-mana: terminal, bilah, dan apa pun lagi yang memintanya.

Kamu bisa memasang font pemrograman populer lainnya melalui _Pasang > Gaya > Font_ di menu Omarchy: Cascadia Mono, Meslo LG Mono, Fira Code, Victor Code, Bitstream Vera Mono, dan Iosevka semuanya hanya berjarak satu klik, dalam versi Nerd Font-nya sehingga glif di bilah dan terminal tetap berfungsi. Setelah memasang salah satunya, pilih di _Gaya > Font_.
