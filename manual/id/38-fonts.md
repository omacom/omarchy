# Font

Omarchy menggunakan JetBrainsMono Nerd Font sebagai font terminal dan sistem secara default.

 ![fonts-jetbrainsmono](images/fonts-jetbrainsmono.webp)

Anda dapat mengubahnya melalui menu _Appearance > Font_ di menu Omarchy (`Super + Space`). Itu mengatur font monospace di mana-mana: terminal, bar, dan apa pun lainnya yang memintanya.

Anda dapat menginstal font pemrograman populer lainnya melalui _Install > Style > Font_ di menu Omarchy: Cascadia Mono, Meslo LG Mono, Fira Code, Victor Code, Bitstream Vera Mono, dan Iosevka semuanya hanya berjarak satu klik, dalam versi Nerd Font mereka agar glif di bar dan terminal tetap berfungsi. Setelah menginstal salah satunya, pilih font tersebut di _Appearance > Font_.

## Tionghoa, Jepang, dan Korea

Bahasa Tionghoa, Jepang, dan Korea berbagi banyak karakter tetapi menggambar beberapa di antaranya secara berbeda, sehingga karakter yang sama terlihat tepat bagi satu pembaca dan asing bagi pembaca lain. Memilih salah satu bahasa ini di _Setup > Region > Language_, atau metode inputnya, akan mengatur bentuk yang sesuai. Untuk memilihnya sendiri, jalankan `omarchy font cjk jp`, `kr`, `sc`, `tc` (Taiwan), atau `hk` (Hong Kong) di terminal; `omarchy font cjk default` kembali ke pilihan sistem, yaitu bentuk Jepang. Teks yang ditandai halaman web atau dokumen dengan bahasanya sendiri, dan seluruh desktop selama berada dalam salah satu bahasa ini, tetap menggunakan bentuk bahasa tersebut.
