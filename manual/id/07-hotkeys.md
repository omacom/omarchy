# Hotkey

Anda dapat melihat semua binding keyboard utama dengan `Super + K` (binding Tmux dengan `Super + Alt + K` dan binding Herdr dengan `Super + Ctrl + K`).

## Menavigasi

| Hotkey                  | Fungsi              |
| ----------------------- | --------------------- |
| `Super + Space`           | Menu Omarchy (aplikasi dan segala hal lain)    |
| `Super + Alt + Space` | Kisi aplikasi |

| `Super + Alt + F`                 | Lebar penuh              |
| `Super + Ctrl + F`                 | Layar penuh di dalam jendela              |
| `Super + 1/2/3/4`         | Lompat ke ruang kerja tertentu     |

## Papan klip universal

| Hotkey                  | Fungsi              |
| ----------------------- | --------------------- |
| `Super + C`           | Salin    |
| `Super + X`           | Potong (tidak di terminal)    |
| `Super + V`           | Tempel    |
| `Super + Ctrl + V`           | Manajer papan klip    |

Biasanya di Linux, Anda memerlukan `Ctrl + Shift + C/V` untuk salin-tempel di terminal dan `Ctrl + C/V` untuk melakukannya di mana-mana. Hotkey papan klip terpadu Omarchy ini berfungsi di mana-mana.

## Tangkap

| Hotkey              | Fungsi                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Menu tangkap (untuk keyboard tanpa tombol PrintScr) |
| `Print Screen`            | Tangkapan layar                      |
| `Alt + Print Screen`            | Rekam layar                     |
| `Super + Print Screen` | Pemilih warna |
| `Super + Ctrl + Print Screen` | Ekstraksi teks ke papan klip |
| `Super + Alt + [` | Perkecil overlay webcam saat merekam |
| `Super + Alt + ]` | Perbesar overlay webcam saat merekam |
| `Alt + Shift + L` | Salin URL saat ini dari webapp atau Chromium |
| `Alt + Shift + D` | Unduh video pada halaman saat ini ke `~/Videos` |
| `Super + Ctrl + X` | Mulai/hentikan dikte (memerlukan _Pengaturan > Bawaan > Dikte_) |
| `Right Alt` / `F9` | Dikte push-to-talk (memerlukan Voxtype atau Superwhisper) |

Dengan perekaman layar, hotkey terlebih dahulu menanyakan audio mana yang Anda inginkan, lalu memulai perekaman. Tekan lagi untuk berhenti. Lihat [tangkapan layar dan perekaman](12-screenshots-recording.md) untuk detailnya.

Semua opsi tangkap juga dapat diakses di bawah _Pemicu > Tangkap_ dalam menu Omarchy (`Super + Space`).

## Tmux

Tombol awalan adalah `Ctrl + Space` (`Ctrl + B` juga berfungsi). Anda dapat mengubah binding ini dalam `~/.config/tmux/tmux.conf`.

### Pane

| Hotkey                  | Fungsi              |
| ----------------------- | --------------------- |
| `Prefix + v` | Pisah pane di samping (vertikal) |
| `Prefix + h` | Pisah pane di bawah (horizontal) |
| `Prefix + x` | Matikan pane |
| `Prefix + z` | Alihkan zoom pane (layar penuh) |
| `Alt + Enter` | Pisah pane di bawah (tanpa awalan) |
| `Alt + Shift + Enter` | Pisah pane di samping (tanpa awalan) |
| `Alt + Escape` | Matikan pane (tanpa awalan) |
| `Ctrl + Alt + Arrows` | Berpindah di antara pane |
| `Ctrl + Alt + Shift + Arrows` | Ubah ukuran pane |

### Jendela

| Hotkey                  | Fungsi              |
| ----------------------- | --------------------- |
| `Prefix + c` | Jendela baru |
| `Prefix + k` | Matikan jendela |
| `Prefix + r` | Ganti nama jendela |
| `Alt + 1-9` | Pergi ke jendela tertentu |
| `Alt + Arrow Left/Right` | Berpindah di antara jendela |
| `Alt + Shift + Arrow Left/Right` | Pindahkan jendela kiri/kanan |

### Sesi

| Hotkey                  | Fungsi              |
| ----------------------- | --------------------- |
| `Prefix + C` | Sesi baru |
| `Prefix + K` | Matikan sesi |
| `Prefix + R` | Ganti nama sesi |
| `Prefix + N` | Sesi berikutnya |
| `Prefix + P` | Sesi sebelumnya |
| `Alt + Arrow Up/Down` | Berpindah di antara sesi |
| `Prefix + s` | Daftar sesi |
| `Prefix + d` | Lepas dari sesi |

### Mode salin (gaya vi)

| Hotkey                  | Fungsi              |
| ----------------------- | --------------------- |
| `Prefix + [` | Masuk mode salin |
| `v` | Mulai pilihan (dalam mode salin) |
| `y` | Salin pilihan (dalam mode salin) |

### Umum

| Hotkey                  | Fungsi              |
| ----------------------- | --------------------- |
| `Prefix + q` | Muat ulang konfigurasi |
| `Prefix + ?` | Tampilkan keybinding Tmux |
| `Prefix + :` | Prompt perintah |

### Fungsi tata letak Tmux

Fungsi-fungsi ini harus dijalankan di dalam sesi Tmux.

| Perintah | Fungsi |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Buat tata letak dev dengan editor, AI, dan terminal |
| `tdlm <ai> [<second_ai>]` | Buat tata letak dev per subdirektori |
| `tsl <count> <command>` | Buat tata letak kawanan multi-pane |
