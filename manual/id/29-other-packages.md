# Paket Lainnya

Arch memiliki kekayaan paket yang luar biasa yang tersedia untuk hampir semua jenis perangkat lunak antara repositori resmi dan Arch User Repository (AUR).

Itu tidak bisa lebih mudah untuk digunakan juga. Kamu memasang paket Arch baru dengan pergi ke _Pasang > Package_ di menu Omarchy (`Super + Space`) dan mengetik paket yang kamu inginkan. Itu akan secara otomatis memfilter secara fuzzy daftar semua paket. (Kamu juga dapat melakukannya secara manual menggunakan `omarchy pkg add [package]` di terminal).

Kamu dapat melakukan hal yang sama dengan AUR, cukup gunakan _Pasang > AUR_. Ingat saja bahwa AUR tidak diperiksa oleh tim Arch. Ini seperti RubyGems atau npm. Siapa pun dapat mengunggah.

Jika kamu ingin menghapus paket, kamu dapat menggunakan _Hapus > Package_ dari menu Omarchy. Itu akan menghapus paket, berkas konfigurasi, dan dependensi. (Kamu juga dapat melakukannya secara manual menggunakan `omarchy pkg drop [package]`).
