# Pengingat

Omarchy memiliki cara bawaan untuk mengatur pengingat sederhana berdasarkan pengatur waktu hitung mundur dan dengan pesan. Anda dapat melakukan ini melalui `Super + Ctrl + R`, melihat semua yang telah diatur melalui `Super + Ctrl + Alt + R`, dan menghapus semua melalui `Super + Ctrl + Shift + R`. Semuanya juga dapat diakses melalui _Pemicu > Pengingat_. Anda juga dapat menggunakan cli dengan `omarchy reminder 7 'Tea ready'`.
