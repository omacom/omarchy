# अक्सर पूछे जाने वाले प्रश्न

### मैं कीबोर्ड लेआउट के बीच कैसे स्विच करूँ?

अपनी `~/.config/hypr/input.lua` फ़ाइल संपादित करें और `Left Alt + Right Alt` पर लेआउट के बीच स्विच करने के लिए यह जोड़ें:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

एक से अधिक लेआउट कॉन्फ़िगर कर लिए जाने पर बार अपने आप आपका वर्तमान कीबोर्ड लेआउट दिखाएगी (और आप स्विच करने के लिए उस पर क्लिक भी कर सकते हैं)।

### मैं घड़ी का फ़ॉर्मैट 12-घंटे में कैसे बदलूँ?

सामान्य फ़ॉर्मैट के बीच बारी-बारी से बदलने के लिए बार में घड़ी पर राइट-क्लिक करें, जिनमें 12-घंटे वाले फ़ॉर्मैट भी शामिल हैं। आप फ़ॉर्मैट सीधे भी सेट कर सकते हैं:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

यह रविवार 10:55 AM प्रदर्शित करेगा।

### मैं अपना टाइमज़ोन कैसे बदलूँ?

Omarchy मेनू में _Update > Timezone_ चलाएँ और सूची से चुनें। यदि टाइमज़ोन सही है लेकिन घड़ी स्वयं भटक गई है, तो _Update > Time_ आपके लिए समय सिंक्रनाइज़ेशन को फिर से शुरू कर देता है।

### मैं अपना DNS कैसे बदलूँ, अपना Wi-Fi कैसे साझा करूँ, या अपने कनेक्शन की गति कैसे जाँचूँ?

वे सभी [नेटवर्किंग](35-networking.md) में मिलते हैं।

### मैं यह कैसे जाँचूँ कि मेरी डिस्क कितनी तेज़ है?

_Trigger > Speed Test > Disk Speed Test_ आपके ड्राइव पर लाइव पढ़ने और लिखने की गति मापता है, या टर्मिनल से `omarchy disk speedtest` चलाएँ।

### मैं प्रिंटर कैसे जोड़ूँ?

प्रिंटिंग पहले से सेट अप और चलती हुई मिलती है, और आप प्रत्येक प्रिंटर को स्वयं ऐप लॉन्चर (`Super + Space`) में _Print Settings_ से जोड़ते हैं।

_Add_ चुनें, और इसे खोजने के लिए एक पल दें: USB से जुड़ा हुआ प्रिंटर, और अधिकांश नेटवर्क प्रिंटर, आपके लिए खोज लिए जाते हैं। यदि आपका प्रिंटर सूची में नहीं है, तो _Network Printer > Internet Printing Protocol (ipp)_ चुनें और उसका पता दर्ज करें — प्रिंटर की अपनी डिस्प्ले या उसका वेब पेज आपको बताएगा कि वह क्या है, आमतौर पर `192.168.1.50` जैसा कुछ, जिसकी कतार `ipp/print` होती है। इसके बाद _Forward_ एक ड्राइवर पेश करता है, जहाँ एक आधुनिक प्रिंटर ड्राइवररहित _IPP Everywhere_ प्रोफ़ाइल पर सबसे अच्छा काम करता है और एक पुराना प्रिंटर मॉडल के अपने ड्राइवर को चाहता है।

किसी प्रिंटर पर राइट-क्लिक करें और यह चुनने के लिए कि आपके ऐप्स पहले किसे इस्तेमाल करें, _Set as Default_ चुनें, और कागज़ का आकार, डुप्लेक्स और गुणवत्ता सेट करने के लिए _Properties_ चुनें।

स्वचालित खोज, जिसमें नेटवर्क पर मौजूद प्रिंटर बिना जोड़े ही दिखाई देते हैं, अस्थायी रूप से बंद है जबकि इसे फिर से बनाया जा रहा है, यही कारण है कि ऊपर दिया गया पहला कदम स्वचालित होने के बजाय आपका है। किसी भी प्रिंटर के बिना भी PDF फ़ाइल में प्रिंट करना काम करता है।

### मैं स्क्रीनशॉट या स्क्रीनरिकॉर्डिंग कहाँ सहेजी जाएँ, यह कैसे बदलूँ?

सहेजे गए स्क्रीनशॉट डिफ़ॉल्ट रूप से `~/Pictures/Screenshots` में जाते हैं। किसी अन्य डायरेक्टरी का उपयोग करने के लिए, `~/.config/uwsm/env.d/` के अंतर्गत किसी फ़ाइल (जैसे `~/.config/uwsm/env.d/capture`) में यह जोड़ें:

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

आप `OMARCHY_SCREENRECORD_DIR` का उपयोग करके स्क्रीनरिकॉर्डिंग के लिए भी ऐसा ही कर सकते हैं।

Omasnap आपकी स्क्रीनशॉट डायरेक्टरी अपने आप बना देता है। स्क्रीनरिकॉर्डिंग डायरेक्टरी स्वयं बनाएँ, फिर किसी भी एनवायरनमेंट परिवर्तन के प्रभावी होने के लिए Omarchy को फिर से शुरू करें।

### मैं अपने Apple Studio Display पर स्पीकर + वेबकैम कैसे काम करवाऊँ?

आपको लगेगा कि केवल USB C लगाते ही सब कुछ काम करना चाहिए, लेकिन दुर्भाग्य से ऐसा नहीं है। मुझे जो समाधान विश्वसनीय रूप से काम करता हुआ मिला है, वह है [WJESOG DisplayPort + USB-A => USB-C केबल](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) का उपयोग करना। फिर स्पीकर और वेबकैम बिल्कुल बढ़िया काम करते हैं।

याद रखें कि Omarchy में Apple डिस्प्ले (Studio और XDR दोनों) के लिए नियमित कीबोर्ड ब्राइटनेस बटन का उपयोग करके बिल्ट-इन ब्राइटनेस नियंत्रण मौजूद है।

### मैं सारा अतिरिक्त सॉफ़्टवेयर कैसे हटाऊँ?

यदि आप Obsidian या LibreOffice जैसे प्रोग्राम या पहले से इंस्टॉल अन्य किसी भी चीज़ को नहीं चाहते, तो आप उसे बहुत आसानी से हटा सकते हैं।

इंस्टॉल किए गए हर पैकेज को देखने के लिए _Remove > Package_ चलाएँ। फिर आप tab दबाकर कोई भी पैकेज चुन सकते हैं जिसे आप हटाना चाहते हैं, और return दबाकर चुनी गई हर चीज़ को हटाना शुरू कर सकते हैं।

और आप Omarchy मेनू से _Remove > Web App_ का उपयोग करके उन पहले से इंस्टॉल वेब ऐप्स में से किसी को भी हटा सकते हैं जिन्हें आप नहीं चाहते।

या पहले से इंस्टॉल सभी अतिरिक्त चीज़ों — वेब ऐप्स, TUI, और वैकल्पिक एप्लिकेशन — को एक बार में साफ़ करने के लिए _Remove > Preinstalls_ चलाएँ। उन्हें लॉन्च करने वाले हॉटकी उनके साथ ही चले जाते हैं, इसलिए आपके पास `~/.config/hypr/bindings.lua` में अपने स्वयं के बाइंडिंग भरने के लिए एक साफ़ स्लेट बचती है।
