# डेवलपमेंट टूल

## वैकल्पिक एडिटर

Omarchy नए इंस्टॉल पर डिफ़ॉल्ट एडिटर के रूप में Plain के साथ आता है और [Neovim](https://neovim.io/) पहले से इंस्टॉल रहता है, लेकिन अगर आप कुछ थोड़ा ज़्यादा मुख्यधारा वाला और परिचित चाहते हैं, तो आप Omarchy Menu (`Super + Space`) चला सकते हैं और _इंस्टॉल > एडिटर_ के तहत विकल्प देख सकते हैं। वहाँ VSCode, Cursor, Zed, Sublime Text, Helix, Vim और Emacs सूचीबद्ध हैं। अगर आपको वह नहीं मिलता जो आप ढूँढ रहे हैं, तो _इंस्टॉल > पैकेज_ देखें, और देखें कि क्या वह किसी Arch पैकेज में नहीं है (और अगर नहीं है, तो AUR देखने के लिए _इंस्टॉल > AUR_ आज़माएँ)।

मूल `vi` एडिटर भी बिल्कुल शुरू से उपलब्ध है। टर्मिनल में किसी फ़ाइल को एडिट करने के लिए `vi filename` चलाएँ।

`VSCode`, `Cursor`, `VSCodium` और `Helix` के लिए थीम मिलान की सुविधा दी जाती है।

आप सिस्टम-व्यापी डिफ़ॉल्ट एडिटर को `Setup > Defaults > Editor` के तहत सेट कर सकते हैं।

## एनवायरनमेंट

Omarchy, Omarchy Menu (`Super + Space`) के _इंस्टॉल > डेवलपमेंट_ सेक्शन के ज़रिए ढेर सारे डेवलपमेंट एनवायरनमेंट सेट अप करने का समर्थन करता है। आपको वहाँ _Ruby on Rails_ तो मिलेगा ही, लेकिन JavaScript के तीनों प्रमुख रनटाइम (Node.js, Bun, Deno) भी मिलेंगे, साथ ही Laravel और Symfony जैसे लोकप्रिय PHP फ़्रेमवर्क भी। अरे, और Go, Rust, Python, Java, Elixir (Phoenix के साथ), .NET, OCaml, Zig, Clojure और Scala भी हैं। यह बहुत ही व्यापक चयन है!

इनमें से अधिकांश एनवायरनमेंट [Mise](https://mise.jdx.dev/) द्वारा मैनेज किए जाते हैं। यह एक ऐसा टूल है जो आपको एक ही मशीन पर किसी प्रोग्रामिंग भाषा के कई वर्शन इंस्टॉल करके चलाने देता है। यह Ruby के लिए rbenv या rvm जैसा या Python के लिए virtualenv जैसा है, लेकिन यह कई अलग-अलग एनवायरनमेंट के लिए काम करता है।

उदाहरण के लिए, Ruby इंस्टॉल करने के लिए आप `mise use -g ruby` चलाएँगे, जो Ruby को इंस्टॉल भी करेगा और उसे ग्लोबल डिफ़ॉल्ट के रूप में सेट भी करेगा। या, अगर आपके प्रोजेक्ट में .ruby-version फ़ाइल है, तो आप उस प्रोजेक्ट के रूट में बस `mise i` चला सकते हैं।

## पहले से इंस्टॉल किए गए CLI टूल

`uv`, Node.js और `playwright-cli` (एजेंटों के लिए इंस्टॉल किए गए Chrome का उपयोग करके ब्राउज़र चलाने के लिए) पैकेज के रूप में इंस्टॉल होकर आते हैं, और `omarchy update` उन्हें बाकी सिस्टम के साथ अप-टू-डेट रखता है। `ghui`, [Hunk](https://github.com/modem-dev/hunk) और Basecamp, Cloudflare और HEY CLI _इंस्टॉल > CLI_ के तहत बस एक चुनाव दूर हैं, और [कोडिंग एजेंट](17-ai.md) _इंस्टॉल > AI > CLI_ के तहत हैं।

mise केवल उन रनटाइम को मैनेज करता है जिन्हें आप _इंस्टॉल > डेवलपमेंट_ से सेट अप करते हैं; Omarchy इसके ज़रिए अपने आप कुछ भी इंस्टॉल नहीं करता। उन्हें बाकी Omarchy के साथ अपडेट करने के लिए `omarchy update` चलाएँ; `mup` एलियास केवल mise द्वारा मैनेज किए गए टूल को अपडेट करता है। अपने खुद के कॉन्फ़िगरेशन में कोई और टूल जोड़ने के लिए `mise use -g <tool>` का उपयोग करें।

## Docker

[Docker](https://www.docker.com/) को परिचय की शायद ही कोई ज़रूरत है। यह आपको अलग-थलग कंटेनर चलाने देता है, और Omarchy इसे अच्छी तरह चलाने के लिए ज़रूरी सब कुछ इंस्टॉल करता है, जिसमें Docker खुद और [Docker Compose](https://docs.docker.com/compose/) शामिल हैं।

डिफ़ॉल्ट रूप से आपका उपयोगकर्ता `docker` ग्रुप में *नहीं* होता है। वह ग्रुप असल में बिना पासवर्ड वाला root है — उसमें मौजूद कोई भी चीज़ `docker run -v /:/host` चला सकती है और मशीन पर कब्ज़ा कर सकती है — इसलिए आपके रूप में चलने वाली कोई एक दुष्ट स्क्रिप्ट या डिपेंडेंसी अन्यथा root से बस एक कमांड दूर होती। इसलिए कमांड लाइन पर आप Docker को `sudo` के साथ चलाते हैं (`sudo docker ps`, `sudo docker compose up`), और डेमन से बात करने वाले ग्राफ़िकल टूल — Windows VM — ज़रूरत पड़ने पर आपसे अनुमति माँगते हैं। अगर आप ग्रुप-रहित सेटअप की सुविधा वापस चाहते हैं और इसके बदले होने वाले समझौते को समझते हैं, तो इसे **सेटअप > सुरक्षा > Sudoless Docker** से सक्षम करें (या `omarchy-setup-security-sudoless-docker` चलाएँ), जो एक चेतावनी के बाद आपको `docker` ग्रुप में जोड़ देता है; फिर सादा `docker` और `d` एलियास फिर से बिना `sudo` के काम करते हैं।

आप Omarchy मेनू में _इंस्टॉल > डेवलपमेंट > Docker DB_ का उपयोग करके स्थानीय डेवलपमेंट के लिए आम डेटाबेस सेट अप कर सकते हैं।

## GitHub CLI

[GitHub CLI](https://cli.github.com/) यानी `gh`, टर्मिनल से रिपॉज़िटरी, इश्यू और पुल रिक्वेस्ट के साथ काम करने के लिए है। _सेटअप > Git_ इसे तब इंस्टॉल करता है जब आप वहाँ GitHub में साइन इन करना चुनते हैं, फिर `gh repo clone org/repo` किसी रिपॉज़िटरी को क्लोन करता है। इसके कमांड देखने के लिए `gh --help` चलाएँ।

_इंस्टॉल > CLI > GitHub_ GitHub CLI, `gh`, को `ghui` के साथ इंस्टॉल करता है, जो पुल रिक्वेस्ट के लिए एक टर्मिनल इंटरफ़ेस है। Git के साथ खुद काम करने के लिए [Lazygit](https://github.com/jesseduffield/lazygit) पहले से इंस्टॉल है।
