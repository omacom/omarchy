# Dual Boot Install

आप Windows या अन्य इंस्टॉलेशन के साथ-साथ एक ही पार्टीशन पर Omarchy इंस्टॉल कर सकते हैं।

यह इंस्टॉलेशन विधि अभी भी डिफ़ॉल्ट रूप से पार्टीशन के लिए LUKS एन्क्रिप्शन के साथ आती है इसलिए यह प्रभावी रूप से पूर्ण ड्राइव से अलग नहीं है और बस डिस्क पर खाली जगह उपलब्ध होने की आवश्यकता है।

## Windows पर जगह बनाना

Windows के साथ-साथ इंस्टॉल करने के लिए, स्टार्ट मेनू में `disk management` टाइप करें और **Create and format hard disk partitions** के विकल्प का चयन करें।

 ![dual-boot-1](images/dual-boot-1.webp)

उपयुक्त पार्टीशन खोजें, राइट क्लिक करें, और **Shrink Volume** चुनें।

![dual-boot-2](images/dual-boot-2.webp)

 वह मात्रा डालें जिससे आप वॉल्यूम को सिकोड़ना चाहते हैं। ध्यान दें कि यह बूट पार्टीशन सहित आपके भविष्य के Omarchy इंस्टॉल का आकार होगा।

 ![dual-boot-3](images/dual-boot-3.webp)

जब आप समाप्त कर लें, तो आपको ऐसा कुछ दिखाई देना चाहिए जहाँ 50GB खंड वह है जहाँ हम इस उदाहरण में Omarchy इंस्टॉल करेंगे।

 ![dual-boot-4](images/dual-boot-4.webp)

## Omarchy इंस्टॉल करना

Omarchy की इंस्टॉल प्रक्रिया प्रभावी रूप से सामान्य जैसी ही है। अपनी डिस्क चुनने के बाद, आपको **Free space install** का विकल्प दिया जाएगा। पूरी डिस्क को मिटाने से बचने के लिए उस विकल्प का चयन करें।

 ![dual-boot-5](images/dual-boot-5.webp)

पुष्टि करें कि सब कुछ अच्छा लग रहा है और सामान्य की तरह इंस्टॉल समाप्त होने की प्रतीक्षा करें। यह वह जगह भी है जहाँ आप पूर्ण-ड्राइव इंस्टॉल की तरह ही बिना एन्क्रिप्ट किए इंस्टॉल करना चुन सकते हैं (अनुशंसित नहीं)।
 ![dual-boot-6](images/dual-boot-6.webp)

## अन्य इंस्टॉल को बूटलोडर में जोड़ना

जब आप अपना Omarchy इंस्टॉल समाप्त कर लेंगे, तो आप देखेंगे कि Limine बूटलोडर अब डिफ़ॉल्ट है। इसके साथ, आप अपने अन्य इंस्टॉल जैसे Windows के लिए Limine में विकल्प भी जोड़ सकते हैं।

ऐसा करने के लिए, `limine-scan` चलाएँ और अपने limine कॉन्फ़िग में जो भी आइटम आप चाहते हैं उन्हें जोड़ने के लिए संकेतों का पालन करें। फिर जब आप बूट करेंगे, तो आपको Omarchy के लिए अपने सामान्य विकल्प, साथ ही Windows Boot Manager या अन्य दिखाई देंगे।

## Bitlocker

यह ध्यान रखना महत्वपूर्ण है कि यह इंस्टॉल विधि Bitlocker के साथ संगत नहीं है क्योंकि यह सिर्फ़ पार्टीशन नहीं, पूरी ड्राइव को एन्क्रिप्ट करता है। अगर आपको कोई त्रुटि मिलती है जो कहती है कि Bitlocker सक्षम है, तो Windows पर बूट करें, **Settings -> Privacy & Security -> Device encryption** पर जाएँ और Bitlocker बंद कर दें। ड्राइव को डिक्रिप्ट करने में कुछ समय लग सकता है।
