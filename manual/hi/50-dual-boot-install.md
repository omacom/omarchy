# डुअल बूट इंस्टॉल

आप Windows या अन्य इंस्टॉलेशन के साथ-साथ एक ही पार्टीशन पर Omarchy इंस्टॉल कर सकते हैं।

इस इंस्टॉलेशन विधि में भी पार्टीशन के लिए डिफ़ॉल्ट रूप से LUKS एन्क्रिप्शन मिलता है, इसलिए यह प्रभावी रूप से पूरी ड्राइव पर इंस्टॉल करने से अलग नहीं है और इसके लिए बस डिस्क पर मुफ़्त स्थान उपलब्ध होना चाहिए।

## Windows पर स्थान बनाना

Windows के साथ-साथ इंस्टॉल करने के लिए, स्टार्ट मेन्यू में `disk management` टाइप करें और **Create and format hard disk partitions** का विकल्प चुनें।

 ![dual-boot-1](images/dual-boot-1.webp)

उचित पार्टीशन खोजें, राइट-क्लिक करें, और **Shrink Volume** चुनें।

![dual-boot-2](images/dual-boot-2.webp)

 वह मात्रा दर्ज करें जितना आप वॉल्यूम को छोटा करना चाहते हैं। ध्यान दें कि यही आपके भविष्य के Omarchy इंस्टॉल का आकार होगा, जिसमें बूट पार्टीशन भी शामिल है।

 ![dual-boot-3](images/dual-boot-3.webp)

जब आप काम पूरा कर लें, तो आपको कुछ ऐसा दिखना चाहिए जहाँ इस उदाहरण में 50GB वाला भाग वह जगह है जहाँ हम Omarchy इंस्टॉल करेंगे।

 ![dual-boot-4](images/dual-boot-4.webp)

## Omarchy इंस्टॉल करना

Omarchy की इंस्टॉल प्रक्रिया प्रभावी रूप से सामान्य प्रक्रिया जैसी ही है। अपनी डिस्क चुनने के बाद, आपको **Free space install** का विकल्प मिलेगा। पूरी डिस्क को मिटाने से रोकने के लिए वह विकल्प चुनें।

 ![dual-boot-5](images/dual-boot-5.webp)

पुष्टि करें कि सब कुछ ठीक लग रहा है और सामान्य तरीके से इंस्टॉल पूरा होने की प्रतीक्षा करें। यहीं पर आप पूरी ड्राइव पर इंस्टॉल करने की तरह ही बिना एन्क्रिप्शन के इंस्टॉल करना भी चुन सकते हैं (अनुशंसित नहीं है)।
 ![dual-boot-6](images/dual-boot-6.webp)

## बूटलोडर में अन्य इंस्टॉल जोड़ना

जब आप अपना Omarchy इंस्टॉल पूरा कर लेंगे, तो आप देखेंगे कि अब Limine बूटलोडर डिफ़ॉल्ट है। इसके साथ, आप अपने अन्य इंस्टॉल, जैसे Windows, के लिए भी Limine में विकल्प जोड़ सकते हैं।

अन्य ऑपरेटिंग सिस्टम जोड़ने के लिए, `limine-scan` चलाएँ और अपनी Limine कॉन्फ़िग में मनचाही प्रविष्टियाँ जोड़ने के लिए दिए गए निर्देशों का पालन करें। बूट मेन्यू डिफ़ॉल्ट रूप से छिपा रहता है और एक सेकंड बाद Omarchy शुरू हो जाता है। Windows या कोई अन्य प्रविष्टि चुनने के लिए, Limine शुरू होते ही कोई भी कुंजी दबाएँ; जब मेन्यू दिखाई दे, तो किसी प्रविष्टि को चुनने के लिए एरो कुंजियों का उपयोग करें और Enter दबाएँ। यदि आपके कुंजी दबाने से पहले ही Omarchy शुरू हो जाए, तो रीस्टार्ट करें और फिर से प्रयास करें।

## Bitlocker

यह ध्यान रखना महत्वपूर्ण है कि यह इंस्टॉल विधि Bitlocker के साथ संगत नहीं है, क्योंकि यह केवल पार्टीशन को नहीं, बल्कि पूरी ड्राइव को एन्क्रिप्ट करता है। यदि आपको यह बताने वाली त्रुटि मिलती है कि Bitlocker सक्षम है, तो Windows में बूट करें, **Settings -> Privacy & Security -> Device encryption** पर जाएँ और Bitlocker को बंद कर दें। ड्राइव को डिक्रिप्ट करने में कुछ समय लग सकता है।

 ![dual-boot-7](images/dual-boot-7.webp)

## Windows को फिर से इंस्टॉल करना

यदि यह कंप्यूटर Windows के साथ आया था, तो इसकी उत्पाद कुंजी फ़र्मवेयर में संग्रहीत होती है। इसे प्रिंट करने के लिए `omarchy windows key` चलाएँ, ताकि यदि आप कभी इस मशीन पर Windows को फिर से इंस्टॉल करें तो आप उसे फिर से सक्रिय कर सकें।
