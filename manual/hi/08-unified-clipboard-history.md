# एकीकृत क्लिपबोर्ड और इतिहास

आमतौर पर Linux पर, टर्मिनल में copy'n'paste करने के लिए आपको `Ctrl + Shift + C/V` और बाकी हर जगह ऐसा करने के लिए `Ctrl + C/V` की ज़रूरत पड़ती है। जो व्यक्ति Linux पर ही जन्मा और पला-बढ़ा नहीं है, उसके लिए इसकी आदत डालना मुश्किल है! अगर आप Mac से आ रहे हैं, तो super से ctrl पर स्विच करना भी उतना ही मुश्किल है।

Omarchy दोनों समस्याओं को एकीकृत क्लिपबोर्ड हॉटकीज़ के साथ हल करता है, जो (लगभग) हर जगह काम करती हैं। वे हैं:

| हॉटकी | कमांड |
| ------- | ----------- |
| Super + A | सब कुछ चुनें |
| Super + C | कॉपी करें |
| Super + X | कट करें |
| Super + V | पेस्ट करें |
| Super + Ctrl + V | क्लिपबोर्ड इतिहास |

_ध्यान दें कि अधिकांश agent harness इमेज पेस्ट करने के लिए `Ctrl + V` का उपयोग करेंगे, लेकिन टेक्स्ट पेस्ट करने के लिए `Super + V` का।_

किसी फ़ोकस किए गए टेक्स्ट फ़ील्ड या किसी अन्य ऐप में, जो `Ctrl + A` का समर्थन करता है, सब कुछ कॉपी करने के लिए `Super + A`, फिर `Super + C` का उपयोग करें। टर्मिनल में, `Ctrl + A` टेक्स्ट चुनने के बजाय कमांड लाइन की शुरुआत में ले जाता है।

### क्लिपबोर्ड इतिहास

क्लिपबोर्ड इतिहास Omarchy shell द्वारा प्रदान किया जाता है और यह टेक्स्ट और इमेज दोनों के लिए काम करता है। आप इसे `Super + Ctrl + V` से शुरू करते हैं और return के साथ अपनी एंट्री चुनते हैं, जिससे वह सीधे उस ऐप में पेस्ट हो जाती है जिसमें आप थे। इसे केवल क्लिपबोर्ड में कॉपी करने के लिए `Shift + Return`, इसे खोलने के लिए `Alt + Return`, इसे इतिहास से हटाने के लिए `Delete`, और पूरा इतिहास साफ़ करने के लिए `Shift + Delete` का उपयोग करें।
