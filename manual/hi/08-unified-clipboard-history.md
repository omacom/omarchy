# एकत्रित क्लिपबोर्ड & इतिहास

आमतौर पर Linux पर, आपको टर्मिनल में कॉपी-पेस्ट करने के लिए `Ctrl + Shift + C/V` और बाकी हर जगह ऐसा करने के लिए `Ctrl + C/V` की ज़रूरत होती है। यह किसी ऐसे व्यक्ति के लिए आदत डालना कठिन है जो Linux पर पैदा और पला-बढ़ा न हो! ऐसा ही Mac से आ रहे लोगों के लिए super से ctrl में बदलने के साथ भी है।

Omarchy दोनों समस्याओं को एकत्रित क्लिपबोर्ड हॉटकी से हल करता है जो (लगभग) हर जगह काम करती हैं। वे हैं:

| हॉटकी | कमांड |
| ------- | ----------- |
| Super + C | कॉपी करें |
| Super + X | काटें |
| Super + V | चिपकाएँ |
| Super + Ctrl + V | क्लिपबोर्ड इतिहास |

_ध्यान दें कि ज़्यादातर एजेंट हार्नेस इमेज चिपकाने के लिए `Ctrl + V` का इस्तेमाल करेंगे, लेकिन टेक्स्ट चिपकाने के लिए `Super + V` का इस्तेमाल करेंगे।_

### क्लिपबोर्ड इतिहास

क्लिपबोर्ड इतिहास Omarchy शेल द्वारा प्रदान किया जाता है और यह टेक्स्ट और इमेज दोनों के लिए काम करता है। आप इसे `Super + Ctrl + V` से ट्रिगर करते हैं, return के साथ अपनी प्रविष्टि चुनते हैं, और फिर वह `Super + V` पर चिपकाने के लिए तैयार क्लिपबोर्ड पर रख दी जाएगी।
