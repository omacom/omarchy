# Mac या Windows से आ रहे हैं

यदि आपने सालों macOS या Windows पर बिताए हैं, तो आपकी उंगलियों को सौ चीज़ें याद हैं, जिन्हें कभी सीखा था यह आपका दिमाग भूल चुका है। यह अध्याय अनुवाद की परत है: Omarchy में वे सहज प्रवृत्तियाँ कहाँ जाती हैं। सुविधाओं को स्वयं अन्यत्र विस्तार से बताया गया है — यह बस नक्शा है।

### Super हर चीज़ का केंद्र है

Cmd या Windows कुंजी के इर्द-गिर्द बनी आपकी सारी मांसपेशीय स्मृति एक कुंजी पर स्थानांतरित हो जाती है: Super। यह PC कीबोर्ड पर Windows कुंजी है, और यह Omarchy में लगभग हर हॉटकी का आधार है।

आपकी Spotlight या Raycast या Start-मेनू वाली सहज प्रतिक्रिया `Super + Space` बन जाती है। इससे Omarchy मेनू खुलता है, जो ऐप्स लॉन्च करता है, सेटिंग्स बदलता है, सॉफ़्टवेयर इंस्टॉल करता है, स्क्रीन कैप्चर करता है — लगभग सब कुछ। फ़िल्टर करने के लिए टाइप करना शुरू करें। `Super + Alt + Space` हर ऐप को एक ग्रिड पर दिखाता है, ठीक Launchpad की तरह। देखें [नेविगेशन](04-navigation.md)।

### कोई डॉक नहीं है और कोई डेस्कटॉप आइकन नहीं हैं

चीज़ों को लॉन्च करने के लिए क्लिक करने को कुछ नहीं है, डेस्कटॉप पर व्यवस्थित करने के लिए कोई आइकन नहीं हैं। ऐप्स हॉटकी से शुरू होते हैं (टर्मिनल के लिए `Super + Return`, ब्राउज़र के लिए `Super + Shift + Return`, और मैप की गई हर चीज़ की सूची के लिए `Super + K`) या मेनू से। UI का एकमात्र स्थायी हिस्सा [टॉप बार](05-the-top-bar.md) है, जो वह सब संभालता है जो पहले मेनू बार, सिस्टम ट्रे और Notification Center आपके लिए करते थे — और उस पर मौजूद लगभग हर विजेट बाएँ, दाएँ और मध्य क्लिक पर कुछ करता है।

### विंडो स्वयं अपनी जगह लेती हैं

सबसे बड़ा मानसिक बदलाव: आप विंडो को इधर-उधर नहीं खींचते और न ही उन्हें स्क्रीन के आधे हिस्सों में स्नैप करते हैं। एक विंडो खोलें और वह पूरी स्क्रीन ले लेती है। दूसरी खोलें और वे उसे बाँट लेती हैं। आपको कभी किसी विंडो को दूसरी विंडो के नीचे से खोजकर नहीं निकालना पड़ता, क्योंकि विंडो एक-दूसरे को ओवरलैप नहीं करतीं।

जब आपको सचमुच फ़्लोटिंग विंडो की ज़रूरत हो, तो `Super + T` सक्रिय विंडो को टाइलिंग से बाहर (और वापस) करता है। लेकिन पहले टाइलिंग को एक असली मौका दें — यही पूरी चीज़ का दिल है। [नेविगेशन](04-navigation.md) आपको इससे परिचित कराता है।

वर्कस्पेस परिचित लगेंगे: वे macOS Spaces या Windows वर्चुअल डेस्कटॉप हैं, बस फ़र्क यह है कि आप वास्तव में उनका उपयोग करेंगे, क्योंकि `Super + 1/2/3/4` सीधे किसी एक पर ले जाता है और `Super + Shift + 1/2/3/4` सक्रिय विंडो को वहाँ भेज देता है। कोई एनिमेशन विलंब नहीं, बस तुरंत छलांग। इसका मतलब है कि आपको शायद कई मॉनिटरों की भी ज़रूरत न पड़े, यदि पहले आपकी आदत वैसी रही हो।

### कॉपी और पेस्ट बस काम करते हैं

Mac पर आपके पास हर जगह Cmd + C था। Windows पर आपके पास हर जगह Ctrl + C था — टर्मिनल को छोड़कर, जहाँ यह आपके प्रोग्राम को समाप्त कर देता है। Omarchy आपको `Super + C`, `Super + X` और `Super + V` देता है, और वे हर जगह काम करते हैं, टर्मिनल समेत। शेल के लिए कोई अलग सहज प्रतिक्रिया सीखने की ज़रूरत नहीं है।

Windows वालों: आपका Win + V क्लिपबोर्ड इतिहास `Super + Ctrl + V` पर रहता है, और यह टेक्स्ट के साथ-साथ इमेज भी रखता है। देखें [एकीकृत क्लिपबोर्ड और इतिहास](08-unified-clipboard-history.md)।

### अनुवाद तालिका

| आप जिसकी ओर हाथ बढ़ाते हैं | Omarchy में |
| ------------- | ---------- |
| Spotlight / Raycast / Start मेनू | `Super + Space` — Omarchy मेनू |
| AirDrop | LocalSend, `Super + Ctrl + S` के माध्यम से — देखें [GUIs](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` या `Print Screen` — देखें [स्क्रीनशॉट और रिकॉर्डिंग](12-screenshots-recording.md) |
| Notification Center | `Super + Shift + Alt + ,` पर नोटिफ़िकेशन इतिहास |
| Time Machine (सिस्टम के लिए) | हर अपडेट पर स्वचालित [सिस्टम स्नैपशॉट](47-system-snapshots.md) |
| App Store / कोई इंस्टॉलर डाउनलोड करना | मेनू में _Install_, या `omarchy pkg add` — देखें [अन्य पैकेज](29-other-packages.md) |
| System Settings / Control Panel | मेनू में _Setup_, जो सादी कॉन्फ़िग फ़ाइलों को संपादित करता है — देखें [डॉटफ़ाइल्स](31-dotfiles.md) |

### कुछ चीज़ें वास्तव में अलग हैं

बहुत-सी सेटिंग्स उन टेक्स्ट फ़ाइलों में रहती हैं जिन्हें आप संपादित करते हैं, उन पैनलों में नहीं जिनमें आप क्लिक करते फिरते हैं। यह तब तक पुराना तरीका लगता है जब तक आपको एहसास नहीं होता कि इसका मतलब है हर बदलाव को देखा जा सकता है, आपकी अगली मशीन पर कॉपी किया जा सकता है और वर्शन कंट्रोल में रखा जा सकता है। _Setup_ मेनू आपको सीधे सही फ़ाइल में पहुँचा देता है और काम पूरा होने पर जो कुछ भी दोबारा शुरू करने की ज़रूरत होती है, उसे दोबारा शुरू कर देता है।

अपडेट एक कमांड के माध्यम से आते हैं — _Update > Omarchy_ — जो Omarchy को स्वयं और सिस्टम पर मौजूद हर पैकेज को अपडेट करता है, और पहले एक स्नैपशॉट लेता है। कोई प्रति-ऐप अपडेटर बेतरतीब समय पर आपको परेशान नहीं करता। देखें [अपडेट](30-updates.md)।

सॉफ़्टवेयर किसी पैकेज मैनेजर से आता है, डाउनलोड किए गए इंस्टॉलरों से नहीं।

और जब आप कोई विंडो बंद करते हैं, तो ऐप वास्तव में बंद हो जाता है। कोई macOS वाली अधर-स्थिति नहीं है जहाँ प्रोग्राम बिना किसी विंडो के चलता रहे। `Super + W` — या `Super + Q`, यदि आप उसी उंगली-स्मृति के साथ आए हैं — का मतलब है गया।

### Mac हार्डवेयर पर

Omarchy Intel Macs पर अच्छी तरह चलता है — देखें [Mac समर्थन](44-mac-support.md)। और कीबोर्ड आपके प्रति दयालु है: Omarchy कुछ भी रीमैप नहीं करता, और Linux Command कुंजी को Super मानता है, इसलिए Super ठीक वहीं बैठता है जहाँ Cmd हमेशा था। आपके अँगूठे को यह बदलाव महसूस भी नहीं होगा।

### इसे दो सप्ताह दें

सहज प्रवृत्तियाँ आपकी सोच से तेज़ी से स्थानांतरित हो जाती हैं। [हॉटकीज़](07-hotkeys.md) अध्याय को एक बार सरसरी तौर पर देखें, और जब भी कोई बाइंडिंग याद न आए, `Super + K` दबाएँ — यह आपको वे सभी दिखा देता है। यही एकमात्र हॉटकी है जिसे आपको वास्तव में याद करना है।
