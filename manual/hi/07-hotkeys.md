# हॉटकी

आप सभी मुख्य कीबोर्ड बाइंडिंग `Super + K` से देख सकते हैं (Tmux बाइंडिंग `Super + Alt + K` से और Herdr बाइंडिंग `Super + Ctrl + K` से)।

## हॉटकी कैसे व्यवस्थित हैं

हर हॉटकी एक प्लेन पर रहती है, जो उसके मॉडिफ़ायर से तय होता है, और हर प्लेन का एक काम होता है। यही हॉटकी को आपस में घुलने-मिलने से रोकता है, और इसका मतलब है कि आप आमतौर पर अंदाज़ा लगा सकते हैं कि कोई चीज़ कहाँ रहती है।

| प्लेन | वहाँ क्या रहता है | उदाहरण |
| --- | --- | --- |
| `Super + key` | सिस्टम: विंडो, वर्कस्पेस, लेआउट और मुख्य मेनू | `Super + Space` Omarchy मेनू, `Super + W` विंडो बंद करें, `Super + F` फुल स्क्रीन |
| `Super + Shift + key` | ऐप्स | `Super + Shift + B` ब्राउज़र, `Super + Shift + E` ईमेल, `Super + Shift + N` एडिटर |
| `Super + Ctrl + key` | पैनल और सिस्टम मेनू | `Super + Ctrl + A` ऑडियो, `Super + Ctrl + N` नेटवर्क, `Super + Ctrl + C` कैप्चर मेनू |
| `Super + Ctrl + Alt + key` | त्वरित कार्रवाइयाँ और सूचनाएँ | `Super + Ctrl + Alt + T` समय दिखाएँ, `Super + Ctrl + Alt + B` बैटरी, `Super + Ctrl + Alt + C` स्क्रीनशॉट |

किसी हॉटकी में `Alt` जोड़ने से आपको उसी चीज़ का एक रूप मिलता है, कभी कोई असंबंधित चीज़ नहीं:

- `Super + Shift + B` ब्राउज़र खोलता है; `Super + Shift + Alt + B` निजी विंडो खोलता है
- `Super + Shift + E` ईमेल खोलता है; `Super + Shift + Alt + E` नया ईमेल शुरू करता है
- `Super + F` फुल स्क्रीन पर जाता है; `Super + Alt + F` फुल चौड़ाई पर जाता है
- `Super + Ctrl + C` कैप्चर मेनू खोलता है; `Super + Ctrl + Alt + C` मेनू को छोड़कर स्क्रीनशॉट लेता है

हॉटकी जोड़ते समय:

1. वह क्या करता है, उससे प्लेन चुनें, फिर कुंजी चुनें।
2. जगह बनाने के लिए मौजूदा हॉटकी को न हटाएँ। सही प्लेन पर खाली कुंजी खोजें।
3. `Alt` का उपयोग केवल उसके बिना वाली हॉटकी के रूप के लिए करें।

कुछ हॉटकी इन नियमों को तोड़ती हैं क्योंकि वे सुविधाजनक हैं। तीर या `Tab` के साथ `Shift` ऐप खोलने के बजाय ले जाता है या उलटता है, और `Print`, मीडिया कुंजियाँ, `Alt + Tab` और `Ctrl + Alt + Del` वैसे ही काम करते हैं जैसे वे हर जगह करते हैं। वे अपवाद हैं, नकल करने के पैटर्न नहीं।

अगर कोई डिफ़ॉल्ट आपको ठीक न लगे (मान लीजिए आप Windows की तरह स्क्रीनशॉट के लिए `Super + Shift + S` चाहते हैं), तो उसे `~/.config/hypr/bindings.lua` में फिर से बाँधें।

## नेविगेट करना

| हॉटकी | कार्य |
| ----------------------- | --------------------- |

| `Super + Alt + Space` | ऐप ग्रिड |
| `Super + Escape` | सिस्टम मेनू (सस्पेंड, रीस्टार्ट, आदि) |
| `Super + Ctrl + L` | कंप्यूटर लॉक करें |
| `Super + W` or `Super + Q` | विंडो बंद करें |
| `Ctrl + Alt + Del` | सभी विंडो बंद करें |
| `Super + K` | सभी हॉटकी दिखाएँ |

| `Super + Ctrl + K` | herdr हॉटकी दिखाएँ |
| `Super + M` | विंडो को डॉक में मिनिमाइज़ करें |
| `Super + T` | विंडो को टाइलिंग/फ़्लोटिंग के बीच टॉगल करें |

| `Super + O` | विंडो को sticky'n'floating में पॉप करना टॉगल करें |

| `Super + Alt + L` | लेआउट में उल्टे क्रम में चक्र करें |

| `Super + F` | फुल स्क्रीन पर जाएँ |
| `Super + Alt + F` | फुल चौड़ाई पर जाएँ |
| `Super + Ctrl + F` | विंडो के अंदर फुल स्क्रीन पर जाएँ |
| `Super + 1…9/0` | फ़ोकस किए गए मॉनिटर पर विशिष्ट वर्कस्पेस पर जाएँ (0 यानी 10) |
| `Super + Tab` | फ़ोकस किए गए मॉनिटर पर अगले वर्कस्पेस पर जाएँ |
| `Super + Shift + Tab` | फ़ोकस किए गए मॉनिटर पर पिछले वर्कस्पेस पर जाएँ |
| `Super + Ctrl + Tab` | फ़ोकस किए गए मॉनिटर पर पूर्व वर्कस्पेस पर जाएँ |
| `Super + Shift + 1…9/0` | विंडो को फ़ोकस किए गए मॉनिटर पर वर्कस्पेस में ले जाएँ |
| `Super + Shift + Alt + 1…9/0` | विंडो को फ़ोकस किए गए मॉनिटर पर वर्कस्पेस में बिना पीछे जाए ले जाएँ |
| `Super + S` | फुल scratchpad टॉगल करें |
| `Super + Alt + S` | विंडो को फुल scratchpad में ले जाएँ |
| `Super + Grave` | Quake कंसोल टॉगल करें |
| `Super + Shift + Grave` | विंडो को Quake कंसोल में ले जाएँ |
| `Super + Shift + Ctrl + Arrows` | विंडो को उस दिशा के मॉनिटर पर ले जाएँ |
| `Super + Shift + Alt + Arrows` | वर्कस्पेस को उस दिशा के मॉनिटर पर ले जाएँ |
| `Super + Arrow` | फ़ोकस को तीर की दिशा वाली विंडो पर ले जाएँ, स्क्रीन के किनारे पर उस ओर के मॉनिटर पर पार करते हुए |
| `Super + Shift + Arrow` | विंडो को तीर की दिशा वाली दूसरी विंडो से बदलें, उस ओर के मॉनिटर पर मौजूद विंडो समेत |
| `Super + Minus` | विंडो को बाईं ओर फैलाएँ |
| `Super + Equal` | विंडो को बाईं ओर सिकोड़ें |
| `Super + Shift + Minus` | विंडो को ऊपर की ओर सिकोड़ें |
| `Super + Shift + Equal` | विंडो को नीचे की ओर फैलाएँ |
| `Super + Alt + Minus/Equal` | छोटे चरणों में वही आकार बदलना |
| `Super + Ctrl + Minus/Equal` | बड़े चरणों में वही आकार बदलना |
| `Super + Alt + Home` | विंडो की चौड़ाई सहेजें |
| `Super + Home` | सहेजी गई विंडो की चौड़ाई वापस लाएँ |
| `Super + Left Mouse` | विंडो को इधर-उधर खींचें |
| `Super + Right Mouse` | विंडो का आकार बदलें |
| `Super + Scroll Wheel` | फ़ोकस किए गए मॉनिटर पर वर्कस्पेस में स्क्रॉल करें |
| `Super + G` | विंडो ग्रुपिंग टॉगल करें |
| `Super + Alt + G` | विंडो को ग्रुपिंग से बाहर ले जाएँ |
| `Super + Alt + Tab` | ग्रुपिंग में विंडो के बीच चक्र करें |
| `Super + Alt + Shift + Tab` | ग्रुपिंग में विंडो के बीच पीछे की ओर चक्र करें |
| `Super + Alt + Scroll Wheel` | ग्रुपिंग में विंडो के बीच चक्र करें |
| `Super + Alt + 1/2/3/4/5` | ग्रुपिंग में विशिष्ट विंडो पर जाएँ |
| `Super + Alt + Arrow` | विंडो को तीर की दिशा में ग्रुपिंग में ले जाएँ, उस ओर के मॉनिटर पर मौजूद विंडो समेत |
| `Super + Ctrl + Left/Right` | टाइलिंग ग्रुप के अंदर विंडो के बीच जाएँ |
| `Super + Ctrl + Z` | स्क्रीन पर ज़ूम इन करें (अधिक ज़ूम के लिए दोहराएँ) |
| `Super + Ctrl + Alt + Z` | स्क्रीन से पूरी तरह ज़ूम आउट करें |
| `Super + /` | मॉनिटर स्केलिंग विकल्पों में आगे बढ़ें |
| `Super + Alt + /` | मॉनिटर स्केलिंग विकल्पों में पीछे बढ़ें |
| `Alt + Tab` | सक्रिय वर्कस्पेस पर विंडो में आगे चक्र करें |
| `Alt + Shift + Tab` | सक्रिय वर्कस्पेस पर विंडो में पीछे चक्र करें |
| `Ctrl + Alt + Tab` | मॉनिटर के बीच फ़ोकस आगे चक्र करें |
| `Ctrl + Alt + Shift + Tab` | मॉनिटर के बीच फ़ोकस पीछे चक्र करें |
| `Super + I` | इनपुट भाषा बदलें (एक से अधिक लेआउट या इनपुट विधि होने पर) |
| `Super + Shift + I` | इनपुट भाषा वापस बदलें |

टचपैड पर, तीन और चार उंगलियों के स्वाइप वर्कस्पेस बदलते हैं, विंडो ले जाते हैं, और मेनू और Quake कंसोल खोलते हैं; हाव-भाव के लिए [कीबोर्ड, माउस और ट्रैकपैड](34-keyboard-mouse-trackpad.md) देखें।

आकार बदलने के शॉर्टकट भौतिक कुंजियों `code:20` और `code:21` (XKB `<AE11>` और `<AE12>`) का उपयोग करते हैं, कीबोर्ड पर छपे अक्षरों की परवाह किए बिना। US कीबोर्ड पर ये कुंजियाँ `-` और `=` हैं; जापानी (JIS) कीबोर्ड पर वे `-` और `^` हैं; स्पेनिश कीबोर्ड पर वे `'` और `¡` हैं। JIS पर, `Super + ^` यानी `Super + Equal` है, जबकि `Super + Shift + -` (जो `=` टाइप करता है) यानी `Super + Shift + Minus` है।

## सार्वभौमिक क्लिपबोर्ड

| हॉटकी | कार्य |
| ----------------------- | --------------------- |
| `Super + A` | उन ऐप्स में सब चुनें जो `Ctrl + A` का समर्थन करते हैं |
| `Super + C` | कॉपी करें |
| `Super + X` | कट करें (टर्मिनल में नहीं) |
| `Super + V` | पेस्ट करें |
| `Super + Ctrl + V` | क्लिपबोर्ड मैनेजर |

आमतौर पर Linux पर, टर्मिनल में copy'n'paste के लिए आपको `Ctrl + Shift + C/V` और बाकी हर जगह के लिए `Ctrl + C/V` की ज़रूरत होती है। ये Omarchy एकीकृत क्लिपबोर्ड हॉटकी हर जगह काम करती हैं।

| `Super + Alt + ]` | रिकॉर्डिंग के दौरान वेबकैम ओवरले बड़ा करें |
| `Alt + Shift + L` | वेबऐप या ब्राउज़र से वर्तमान URL कॉपी करें |
| `Alt + Shift + D` | वर्तमान पेज पर मौजूद वीडियो को `~/Videos` में डाउनलोड करें |
| `Alt + Space` | डिक्टेशन शुरू/बंद करें (इसके लिए _Setup > Defaults > Dictation_ आवश्यक है) |
| `Right Alt` | डिक्टेट करने के लिए पकड़े रखें (इसके लिए _Setup > Defaults > Dictation_ आवश्यक है) |

स्क्रीनरिकॉर्डिंग के साथ, हॉटकी पहले पूछती है कि आपको कौन सा ऑडियो चाहिए, फिर रिकॉर्डिंग शुरू करती है। रोकने के लिए इसे फिर दबाएँ। विवरण के लिए [स्क्रीनशॉट और रिकॉर्डिंग](12-screenshots-recording.md) देखें।

सभी कैप्चर विकल्प Omarchy मेनू (`Super + Space`) में _Trigger > Capture_ के अंतर्गत भी उपलब्ध हैं।

## Tmux

प्रीफ़िक्स कुंजी `Ctrl + Space` है (`Ctrl + B` भी काम करता है)। आप इन बाइंडिंग को `~/.config/tmux/tmux.conf` में बदल सकते हैं।

### पेन

| हॉटकी | कार्य |
| ----------------------- | --------------------- |
| `Prefix + v` | पेन को बगल में विभाजित करें (ऊर्ध्वाधर) |
| `Prefix + h` | पेन को नीचे विभाजित करें (क्षैतिज) |
| `Prefix + x` | पेन समाप्त करें |
| `Prefix + z` | पेन ज़ूम टॉगल करें (फुलस्क्रीन) |
| `Alt + Enter` | पेन को नीचे विभाजित करें (बिना प्रीफ़िक्स के) |
| `Alt + Shift + Enter` | पेन को बगल में विभाजित करें (बिना प्रीफ़िक्स के) |
| `Alt + Escape` | पेन समाप्त करें (बिना प्रीफ़िक्स के) |
| `Ctrl + Alt + Arrows` | पेन के बीच जाएँ |
| `Ctrl + Alt + Shift + Arrows` | पेन का आकार बदलें |

### विंडो

| हॉटकी | कार्य |
| ----------------------- | --------------------- |
| `Prefix + c` | नई विंडो |
| `Prefix + k` | विंडो समाप्त करें |
| `Prefix + r` | विंडो का नाम बदलें |
| `Alt + 1-9` | विशिष्ट विंडो पर जाएँ |
| `Alt + Arrow Left/Right` | विंडो के बीच जाएँ |
| `Alt + Shift + Arrow Left/Right` | विंडो को बाएँ/दाएँ ले जाएँ |

### सत्र

| हॉटकी | कार्य |
| ----------------------- | --------------------- |
| `Prefix + C` | नया सत्र |
| `Prefix + K` | सत्र समाप्त करें |

| `Prefix + N` | अगला सत्र |

### Tmux लेआउट फ़ंक्शन

ये फ़ंक्शन Tmux सत्र के अंदर चलाए जाने चाहिए।
