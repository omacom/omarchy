# हॉटकीज़

आप सभी मुख्य कीबोर्ड बाइंडिंग `Super + K` से देख सकते हैं (Tmux बाइंडिंग `Super + Alt + K` से और Herdr बाइंडिंग `Super + Ctrl + K` से)।

## हॉटकीज़ कैसे व्यवस्थित हैं

हर हॉटकी एक प्लेन पर होती है, जो उसके मॉडिफ़ायर से तय होता है, और हर प्लेन का एक ही काम होता है। इसी से हॉटकीज़ आपस में घुलती-मिलती नहीं हैं, और इसका मतलब है कि आप आमतौर पर अंदाज़ा लगा सकते हैं कि कोई चीज़ कहाँ मिलेगी।

| प्लेन | वहाँ क्या रहता है | उदाहरण |
| --- | --- | --- |
| `Super + key` | सिस्टम: विंडो, वर्कस्पेस, लेआउट और कोर मेनू | `Super + Space` Omarchy मेनू, `Super + W` विंडो बंद करें, `Super + F` पूर्ण स्क्रीन |
| `Super + Shift + key` | ऐप्स | `Super + Shift + B` ब्राउज़र, `Super + Shift + E` ईमेल, `Super + Shift + N` एडिटर |
| `Super + Ctrl + key` | पैनल और सिस्टम मेनू | `Super + Ctrl + A` ऑडियो, `Super + Ctrl + N` नेटवर्क, `Super + Ctrl + C` कैप्चर मेनू |
| `Super + Ctrl + Alt + key` | त्वरित कार्रवाइयाँ और नोटिस | `Super + Ctrl + Alt + T` समय दिखाएँ, `Super + Ctrl + Alt + B` बैटरी, `Super + Ctrl + Alt + C` स्क्रीनशॉट |

किसी हॉटकी में `Alt` जोड़ने से आपको उसी चीज़ का एक वेरिएंट मिलता है, कभी कोई असंबंधित चीज़ नहीं:

- `Super + Shift + B` ब्राउज़र खोलता है; `Super + Shift + Alt + B` एक प्राइवेट विंडो खोलता है
- `Super + Shift + E` ईमेल खोलता है; `Super + Shift + Alt + E` एक नया ईमेल शुरू करता है
- `Super + F` पूर्ण स्क्रीन पर जाता है; `Super + Alt + F` पूर्ण चौड़ाई पर जाता है
- `Super + Ctrl + C` कैप्चर मेनू खोलता है; `Super + Ctrl + Alt + C` मेनू को छोड़कर स्क्रीनशॉट लेता है

हॉटकी जोड़ते समय:

1. वह क्या करती है, उससे प्लेन चुनें, फिर कुंजी चुनें।
2. जगह बनाने के लिए किसी मौजूदा हॉटकी को न हटाएँ। सही प्लेन पर कोई खाली कुंजी खोजें।
3. `Alt` का इस्तेमाल केवल उसके बिना वाली हॉटकी के वेरिएंट के लिए ही करें।

कुछ हॉटकीज़ ये नियम तोड़ती हैं क्योंकि वे सुविधाजनक हैं। तीर या `Tab` के साथ `Shift` ऐप खोलने के बजाय ले जाता है या उलट देता है, और `Print`, मीडिया कुंजियाँ, `Alt + Tab`, और `Ctrl + Alt + Del` वैसे ही काम करते हैं जैसे वे हर दूसरी जगह करते हैं। वे अपवाद हैं, नकल करने के पैटर्न नहीं।

यदि कोई डिफ़ॉल्ट आपको ठीक न लगे (मान लीजिए आप Windows की तरह स्क्रीनशॉट के लिए `Super + Shift + S` चाहते हैं), तो उसे `~/.config/hypr/bindings.lua` में फिर से बाँधें।

आकार बदलने वाले शॉर्टकट भौतिक कुंजियाँ `code:20` और `code:21` (XKB `<AE11>` और `<AE12>`) इस्तेमाल करते हैं, कीबोर्ड पर छपे अक्षरों की परवाह किए बिना। US कीबोर्ड पर ये कुंजियाँ `-` और `=` हैं; जापानी (JIS) कीबोर्ड पर ये `-` और `^` हैं; स्पेनिश कीबोर्ड पर ये `'` और `¡` हैं। JIS पर, `Super + ^` ही `Super + Equal` है, जबकि `Super + Shift + -` (जो `=` टाइप करता है) ही `Super + Shift + Minus` है।

## यूनिवर्सल क्लिपबोर्ड

| हॉटकी                  | कार्य              |
| ----------------------- | --------------------- |
| `Super + A`           | उन ऐप्स में सब चुनें जो `Ctrl + A` का समर्थन करते हैं    |
| `Super + C`           | कॉपी करें    |
| `Super + X`           | कट करें (टर्मिनल में नहीं)    |
| `Super + V`           | पेस्ट करें    |
| `Super + Ctrl + V`           | क्लिपबोर्ड मैनेजर    |

आमतौर पर Linux पर, टर्मिनल में copy'n'paste के लिए आपको `Ctrl + Shift + C/V` चाहिए होता है और बाकी हर जगह करने के लिए `Ctrl + C/V`। ये Omarchy यूनिफ़ाइड क्लिपबोर्ड हॉटकीज़ हर जगह काम करती हैं।

स्क्रीनरिकॉर्डिंग के साथ, हॉटकी पहले पूछती है कि आप कौन-सा ऑडियो चाहते हैं, फिर रिकॉर्डिंग शुरू करती है। रोकने के लिए उसे फिर दबाएँ। विवरण के लिए [स्क्रीनशॉट और रिकॉर्डिंग](12-screenshots-recording.md) देखें।

सभी कैप्चर विकल्प Omarchy मेनू (`Super + Space`) में _Trigger > Capture_ के अंतर्गत भी उपलब्ध हैं।

| `Super + Shift + ,` | सभी सूचनाएँ खारिज करें |
| `Super + Ctrl + ,` | कीबोर्ड से सूचनाओं को नियंत्रित करें  |
| `Super + Alt + ,` | नवीनतम सूचना खारिज करें  |
| `Super + Shift + Alt + ,` | सूचना इतिहास खोलें  |
| `Super + Ctrl + Alt + ,` | सूचनाओं को शांत करना टॉगल करें  |

## स्टाइल

| हॉटकी                  | कार्य              |
| ----------------------- | --------------------- |
| `Super + Ctrl + T` | नई थीम चुनें (यह भी `Super + Ctrl + Shift + Space`) |
| `Super + Ctrl + W` | थीम बैकग्राउंड चुनें (यह भी `Super + Ctrl + Space`) |
| `Super + Backspace` | किसी विंडो पर पारदर्शिता टॉगल करें |
| `Super + Ctrl + Backspace` | एकल-विंडो चौकोर अनुपात टॉगल करें |

अतिरिक्त बैकग्राउंड इमेज `~/.config/omarchy/backgrounds/<theme name>` में रहती हैं। Omarchy मेनू में _Install > Style > Background_ के ज़रिए भी उपलब्ध हैं।

सभी स्टाइल विकल्प Omarchy मेनू (`Super + Space`) में _Style_ के अंतर्गत भी उपलब्ध हैं।

## Tmux

प्रीफ़िक्स कुंजी `Ctrl + Space` है (`Ctrl + B` भी काम करता है)। आप इन बाइंडिंग को `~/.config/tmux/tmux.conf` में बदल सकते हैं।

### पेन

| हॉटकी                  | कार्य              |
| ----------------------- | --------------------- |
| `Prefix + v` | बगल में पेन बाँटें (वर्टिकल) |
| `Prefix + h` | नीचे पेन बाँटें (हॉरिज़ॉन्टल) |
| `Prefix + x` | पेन समाप्त करें |
| `Prefix + z` | पेन ज़ूम टॉगल करें (पूर्ण स्क्रीन) |
| `Alt + Enter` | नीचे पेन बाँटें (बिना प्रीफ़िक्स) |
| `Alt + Shift + Enter` | बगल में पेन बाँटें (बिना प्रीफ़िक्स) |
| `Alt + Escape` | पेन समाप्त करें (बिना प्रीफ़िक्स) |
| `Ctrl + Alt + Arrows` | पेन के बीच जाएँ |
| `Ctrl + Alt + Shift + Arrows` | पेन का आकार बदलें |

### विंडो

| हॉटकी                  | कार्य              |
| ----------------------- | --------------------- |
| `Prefix + c` | नई विंडो |
| `Prefix + k` | विंडो समाप्त करें |
| `Prefix + r` | विंडो का नाम बदलें |
| `Alt + 1-9` | विशिष्ट विंडो पर जाएँ |
| `Alt + Arrow Left/Right` | विंडो के बीच जाएँ |
| `Alt + Shift + Arrow Left/Right` | विंडो को बाएँ/दाएँ ले जाएँ |

### सेशन

| हॉटकी                  | कार्य              |
| ----------------------- | --------------------- |
| `Prefix + C` | नया सेशन |
| `Prefix + K` | सेशन समाप्त करें |
| `Prefix + R` | सेशन का नाम बदलें |
| `Prefix + N` | अगला सेशन |
| `Prefix + P` | पिछला सेशन |
| `Alt + Arrow Up/Down` | सेशन के बीच जाएँ |
| `Prefix + s` | सेशन की सूची देखें |
| `Prefix + d` | सेशन से अलग हों |

### कॉपी मोड (vi-स्टाइल)

| हॉटकी                  | कार्य              |
| ----------------------- | --------------------- |
| `Prefix + [` | कॉपी मोड में प्रवेश करें |
| `v` | चयन शुरू करें (कॉपी मोड में) |
| `y` | चयन कॉपी करें (कॉपी मोड में) |

### सामान्य

| हॉटकी                  | कार्य              |
| ----------------------- | --------------------- |
| `Prefix + q` | कॉन्फ़िग फिर से लोड करें |
| `Prefix + ?` | Tmux कीबाइंडिंग दिखाएँ |
| `Prefix + :` | कमांड प्रॉम्प्ट |

### Tmux लेआउट फ़ंक्शन

ये फ़ंक्शन किसी Tmux सेशन के अंदर ही चलाए जाने चाहिए।

| कमांड | कार्य |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | एडिटर, AI, और टर्मिनल के साथ dev लेआउट बनाएँ |
| `tdlm <ai> [<second_ai>]` | प्रत्येक सबडायरेक्टरी के अनुसार dev लेआउट बनाएँ |
| `tsl <count> <command>` | मल्टी-पेन swarm लेआउट बनाएँ |
