# हॉटकीज़

आप `Super + K` से सभी मुख्य कीबोर्ड बाइंडिंग देख सकते हैं (`Super + Alt + K` से Tmux बाइंडिंग और `Super + Ctrl + K` से Herdr बाइंडिंग)।

## हॉटकीज़ कैसे व्यवस्थित हैं

हर हॉटकी एक प्लेन पर रहती है, जो उसके मॉडिफ़ायर से तय होता है, और हर प्लेन का एक ही काम होता है। इसी से हॉटकीज़ आपस में घुलती-मिलती नहीं हैं, और इसी का मतलब है कि आप आमतौर पर अंदाज़ा लगा सकते हैं कि कोई चीज़ कहाँ रहती है।

| प्लेन | वहाँ क्या रहता है | उदाहरण |
| --- | --- | --- |
| `Super + key` | सिस्टम: विंडो, वर्कस्पेस, लेआउट और मुख्य मेनू | `Super + Space` Omarchy मेनू, `Super + W` विंडो बंद करें, `Super + F` फुल स्क्रीन |
| `Super + Shift + key` | ऐप्स | `Super + Shift + B` ब्राउज़र, `Super + Shift + E` ईमेल, `Super + Shift + N` एडिटर |
| `Super + Ctrl + key` | पैनल और सिस्टम मेनू | `Super + Ctrl + A` ऑडियो, `Super + Ctrl + N` नेटवर्क, `Super + Ctrl + C` कैप्चर मेनू |
| `Super + Ctrl + Alt + key` | त्वरित कार्रवाइयाँ और सूचनाएँ | `Super + Ctrl + Alt + T` समय दिखाएँ, `Super + Ctrl + Alt + B` बैटरी, `Super + Ctrl + Alt + C` स्क्रीनशॉट |

किसी हॉटकी में `Alt` जोड़ने से आपको उसी चीज़ का एक रूप मिलता है, कभी कोई असंबंधित चीज़ नहीं:

- `Super + Shift + B` ब्राउज़र खोलता है; `Super + Shift + Alt + B` एक प्राइवेट विंडो खोलता है
- `Super + Shift + E` ईमेल खोलता है; `Super + Shift + Alt + E` एक नया ईमेल शुरू करता है
- `Super + F` फुल स्क्रीन करता है; `Super + Alt + F` फुल विड्थ करता है
- `Super + Ctrl + C` कैप्चर मेनू खोलता है; `Super + Ctrl + Alt + C` मेनू को छोड़कर सीधे स्क्रीनशॉट लेता है

हॉटकी जोड़ते समय:

1. वह क्या करती है, उससे प्लेन चुनें, फिर कुंजी चुनें।
2. जगह बनाने के लिए किसी मौजूदा हॉटकी को न हटाएँ। सही प्लेन पर कोई खाली कुंजी खोजें।
3. `Alt` का उपयोग केवल उसके बिना वाली हॉटकी के एक रूप के लिए ही करें।

कुछ हॉटकीज़ इन नियमों को तोड़ती हैं क्योंकि वे सुविधाजनक हैं। तीर या `Tab` के साथ `Shift` ऐप खोलने के बजाय ले जाता है या उलट देता है, और `Print`, मीडिया कुंजियाँ, `Alt + Tab` और `Ctrl + Alt + Del` हर जगह की तरह ही काम करते हैं। वे अपवाद हैं, नकल करने के पैटर्न नहीं।

अगर कोई डिफ़ॉल्ट आपको ठीक न लगे (मान लीजिए आप Windows की तरह स्क्रीनशॉट के लिए `Super + Shift + S` चाहते हैं), तो उसे `~/.config/hypr/bindings.lua` में फिर से बाँधें।

| `Super + Shift + Tab` | फ़ोकस किए गए मॉनीटर पर पिछले वर्कस्पेस पर जाएँ |

| `Super + Minus` | विंडो को बाईं ओर फैलाएँ |
| `Super + Equal` | विंडो को बाईं ओर सिकोड़ें |
| `Super + Shift + Minus` | विंडो को ऊपर की ओर सिकोड़ें |
| `Super + Shift + Equal` | विंडो को नीचे की ओर फैलाएँ |
| `Super + Alt + Minus/Equal` | छोटे चरणों में वही आकार बदलना |
| `Super + Ctrl + Minus/Equal` | बड़े चरणों में वही आकार बदलना |
| `Super + Alt + Home` | विंडो की चौड़ाई सहेजें |
| `Super + Home` | सहेजी गई विंडो चौड़ाई पुनर्स्थापित करें |
| `Super + Left Mouse` | विंडो को इधर-उधर खींचें |
| `Super + Right Mouse` | विंडो का आकार बदलें |
| `Super + Scroll Wheel` | फ़ोकस किए गए मॉनीटर पर वर्कस्पेस में स्क्रॉल करें |
| `Super + G` | विंडो समूहन टॉगल करें |
| `Super + Alt + G` | विंडो को समूहन से बाहर ले जाएँ |
| `Super + Alt + Tab` | समूहन में विंडो के बीच चक्र चलाएँ |
| `Super + Alt + Shift + Tab` | समूहन में विंडो के बीच पीछे की ओर चक्र चलाएँ |
| `Super + Alt + Scroll Wheel` | समूहन में विंडो के बीच चक्र चलाएँ |
| `Super + Alt + 1/2/3/4/5` | समूहन में विशिष्ट विंडो पर जाएँ |
| `Super + Alt + Arrow` | विंडो को तीर की दिशा में समूहन में ले जाएँ, उस ओर के मॉनीटर पर मौजूद विंडो सहित |
| `Super + Ctrl + Left/Right` | टाइलिंग समूह के अंदर विंडो के बीच जाएँ |
| `Super + Ctrl + Z` | स्क्रीन पर ज़ूम इन करें (अधिक ज़ूम के लिए दोहराएँ) |
| `Super + Ctrl + Alt + Z` | स्क्रीन से पूरी तरह ज़ूम आउट करें |
| `Super + /` | मॉनीटर स्केलिंग विकल्पों में आगे बढ़ें |
| `Super + Alt + /` | मॉनीटर स्केलिंग विकल्पों में पीछे बढ़ें |
| `Alt + Tab` | सक्रिय वर्कस्पेस पर विंडो में आगे की ओर चक्र चलाएँ |
| `Alt + Shift + Tab` | सक्रिय वर्कस्पेस पर विंडो में पीछे की ओर चक्र चलाएँ |
| `Ctrl + Alt + Tab` | मॉनीटर में फ़ोकस आगे की ओर चक्र चलाएँ |
| `Ctrl + Alt + Shift + Tab` | मॉनीटर में फ़ोकस पीछे की ओर चक्र चलाएँ |

आकार बदलने के शॉर्टकट भौतिक कुंजियों `code:20` और `code:21` (XKB `<AE11>` और `<AE12>`) का उपयोग करते हैं, कीबोर्ड पर छपे अक्षरों की परवाह किए बिना। US कीबोर्ड पर ये कुंजियाँ `-` और `=` हैं; जापानी (JIS) कीबोर्ड पर ये `-` और `^` हैं; स्पेनिश कीबोर्ड पर ये `'` और `¡` हैं। JIS पर, `Super + ^` ही `Super + Equal` है, जबकि `Super + Shift + -` (जो `=` टाइप करता है) ही `Super + Shift + Minus` है।

## यूनिवर्सल क्लिपबोर्ड

| हॉटकी | कार्य |
| ----------------------- | --------------------- |
| `Super + A` | उन ऐप्स में सब चुनें जो `Ctrl + A` का समर्थन करते हैं |
| `Super + C` | कॉपी करें |
| `Super + X` | कट करें (टर्मिनल में नहीं) |
| `Super + V` | पेस्ट करें |
| `Super + Ctrl + V` | क्लिपबोर्ड मैनेजर |

आमतौर पर Linux पर, टर्मिनल में कॉपी'n'पेस्ट करने के लिए आपको `Ctrl + Shift + C/V` और हर दूसरी जगह ऐसा करने के लिए `Ctrl + C/V` की ज़रूरत होती है। ये Omarchy एकीकृत क्लिपबोर्ड हॉटकीज़ हर जगह काम करती हैं।

## कैप्चर

| हॉटकी | कार्य |
| ------------------- | ------------------------------ |
| `Print Screen` | स्क्रीनशॉट |
| `Super + Ctrl + Alt + C` | स्क्रीनशॉट (वही शॉट, उन कीबोर्ड के लिए जिनमें Print Screen कुंजी नहीं है) |

| `Super + Print Screen` | कलर पिकर |
| `Super + Ctrl + Print Screen` | क्लिपबोर्ड पर टेक्स्ट निष्कर्षण |
| `Super + Alt + [` | रिकॉर्डिंग के दौरान वेबकैम ओवरले छोटा करें |
| `Super + Alt + ]` | रिकॉर्डिंग के दौरान वेबकैम ओवरले बड़ा करें |
| `Alt + Shift + L` | वेबऐप या ब्राउज़र से वर्तमान URL कॉपी करें |

| `Alt + Space` | डिक्टेशन शुरू/बंद करें (_Setup > Defaults > Dictation_ आवश्यक है) |

स्क्रीनरिकॉर्डिंग के साथ, हॉटकी पहले पूछती है कि आप कौन सा ऑडियो चाहते हैं, फिर रिकॉर्डिंग शुरू करती है। रोकने के लिए उसे फिर दबाएँ। विवरण के लिए [स्क्रीनशॉट और रिकॉर्डिंग](12-screenshots-recording.md) देखें।

सभी कैप्चर विकल्प Omarchy मेनू (`Super + Space`) में _Trigger > Capture_ के अंतर्गत भी उपलब्ध हैं।

## शैली

| हॉटकी | कार्य |
| ----------------------- | --------------------- |
| `Super + Ctrl + T` | नई थीम चुनें (`Super + Ctrl + Shift + Space` भी) |
| `Super + Ctrl + W` | थीम पृष्ठभूमि चुनें (`Super + Ctrl + Space` भी) |
| `Super + Backspace` | किसी विंडो पर पारदर्शिता टॉगल करें |
| `Super + Ctrl + Backspace` | एकल-विंडो वर्ग पहलू टॉगल करें |

अतिरिक्त पृष्ठभूमि छवियाँ `~/.config/omarchy/backgrounds/<theme name>` में रहती हैं। Omarchy मेनू में _Install > Style > Background_ के माध्यम से भी उपलब्ध हैं।

सभी शैली विकल्प Omarchy मेनू (`Super + Space`) में _Style_ के अंतर्गत भी उपलब्ध हैं।

## Tmux

प्रीफ़िक्स कुंजी `Ctrl + Space` है (`Ctrl + B` भी काम करता है)। आप इन बाइंडिंग को `~/.config/tmux/tmux.conf` में बदल सकते हैं।

### पेन

| हॉटकी | कार्य |
| ----------------------- | --------------------- |
| `Prefix + v` | पेन को बगल में विभाजित करें (ऊर्ध्वाधर) |
| `Prefix + h` | पेन को नीचे विभाजित करें (क्षैतिज) |
| `Prefix + x` | पेन समाप्त करें |
| `Prefix + z` | पेन ज़ूम टॉगल करें (फुलस्क्रीन) |
| `Alt + Enter` | पेन को नीचे विभाजित करें (कोई प्रीफ़िक्स नहीं) |
| `Alt + Shift + Enter` | पेन को बगल में विभाजित करें (कोई प्रीफ़िक्स नहीं) |
| `Alt + Escape` | पेन समाप्त करें (कोई प्रीफ़िक्स नहीं) |
| `Ctrl + Alt + Arrows` | पेन के बीच जाएँ |
| `Ctrl + Alt + Shift + Arrows` | पेन का आकार बदलें |

### विंडो

| हॉटकी | कार्य |
| ----------------------- | --------------------- |
| `Prefix + c` | नई विंडो |
| `Prefix + k` | विंडो समाप्त करें |
| `Prefix + r` | विंडो का नाम बदलें |
| `Alt + 1-9` | विशिष्ट विंडो पर जाएँ |
| `Alt + Arrow Left/Right` | विंडो के बीच जाएँ |
| `Alt + Shift + Arrow Left/Right` | विंडो को बाएँ/दाएँ ले जाएँ |

### सत्र

| हॉटकी | कार्य |
| ----------------------- | --------------------- |
| `Prefix + C` | नया सत्र |
| `Prefix + K` | सत्र समाप्त करें |
| `Prefix + R` | सत्र का नाम बदलें |
| `Prefix + N` | अगला सत्र |
| `Prefix + P` | पिछला सत्र |
| `Alt + Arrow Up/Down` | सत्रों के बीच जाएँ |
| `Prefix + s` | सत्रों की सूची देखें |
| `Prefix + d` | सत्र से अलग हों |

### कॉपी मोड (vi-शैली)

| हॉटकी | कार्य |
| ----------------------- | --------------------- |
| `Prefix + [` | कॉपी मोड में प्रवेश करें |
| `v` | चयन शुरू करें (कॉपी मोड में) |
| `y` | चयन कॉपी करें (कॉपी मोड में) |

### सामान्य

| हॉटकी | कार्य |
| ----------------------- | --------------------- |
| `Prefix + q` | कॉन्फ़िग फिर से लोड करें |
| `Prefix + ?` | Tmux कुंजीबाइंडिंग दिखाएँ |
| `Prefix + :` | कमांड प्रॉम्प्ट |

### Tmux लेआउट फ़ंक्शन

ये फ़ंक्शन Tmux सत्र के अंदर ही चलाए जाने चाहिए।

| कमांड | कार्य |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | एडिटर, AI और टर्मिनल के साथ dev लेआउट बनाएँ |
| `tdlm <ai> [<second_ai>]` | प्रति उपनिर्देशिका dev लेआउट बनाएँ |
| `tsl <count> <command>` | बहु-पेन स्वार्म लेआउट बनाएँ |
