# हॉटकी

आप सभी मुख्य कीबोर्ड बाइंडिंग को `Super + K` से देख सकते हैं (Tmux बाइंडिंग `Super + Alt + K` से और Herdr बाइंडिंग `Super + Ctrl + K` से)।

## नेविगेट करना

| हॉटकी                  | कार्य              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy मेनू (ऐप्स और बाकी सब कुछ)    |
| `Super + Alt + Space` | ऐप ग्रिड |
| `Super + Escape` | सिस्टम मेनू (सस्पेंड, रीबूट, आदि)  |
| `Super + Ctrl + L` | कंप्यूटर लॉक करें |
| `Super + W` or `Super + Q` | विंडो बंद करें             |
| `Ctrl + Alt + Del` | सभी विंडो बंद करें |
| `Super + T`               | विंडो को टाइलिंग/फ़्लोटिंग के बीच टॉगल करें             |
| `Super + J` | विंडो स्थिति टॉगल करें (क्षैतिज/ऊर्ध्वाधर) |
| `Super + O`               | विंडो को चिपकी हुई और तैरती में निकालना टॉगल करें |

| `Super + Ctrl + F`                 | विंडो के अंदर पूरी स्क्रीन करें              |
| `Super + 1/2/3/4`         | विशिष्ट वर्कस्पेस पर जाएँ     |

| `Super + Equal` | विंडो को बाईं ओर छोटा करें |
| `Super + Shift + Minus` | विंडो को ऊपर छोटा करें |
| `Super + Shift + Equal` | विंडो को नीचे फैलाएँ |
| `Super + Alt + Minus/Equal` | छोटे चरणों में वही आकार बदलना |
| `Super + Ctrl + Minus/Equal` | बड़े चरणों में वही आकार बदलना |
| `Super + Alt + Home` | विंडो चौड़ाई सेव करें |
| `Super + Home` | सेव की गई विंडो चौड़ाई बहाल करें |

| `Alt + Tab` | सक्रिय वर्कस्पेस पर विंडोज़ में आगे चक्र लगाएँ |

| `Ctrl + Alt + Tab`| मॉनिटरों में फ़ोकस आगे चक्र लगाएँ |

## सार्वभौम क्लिपबोर्ड

| हॉटकी                  | कार्य              |
| ----------------------- | --------------------- |
| `Super + C`           | कॉपी करें    |
| `Super + X`           | काटें (टर्मिनल में नहीं)    |
| `Super + V`           | चिपकाएँ    |
| `Super + Ctrl + V`           | क्लिपबोर्ड मैनेजर    |

आमतौर पर Linux पर, आपको टर्मिनल में कॉपी-पेस्ट करने के लिए `Ctrl + Shift + C/V` और बाकी हर जगह ऐसा करने के लिए `Ctrl + C/V` की ज़रूरत होती है। ये Omarchy एकत्रित क्लिपबोर्ड हॉटकी हर जगह काम करती हैं।

## कैप्चर

| हॉटकी              | कार्य                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | कैप्चर मेनू (बिना PrintScr बटन वाले कीबोर्ड के लिए) |
| `Print Screen`            | स्क्रीनशॉट                      |
| `Alt + Print Screen`            | स्क्रीन रिकॉर्ड                     |
| `Super + Print Screen` | रंग चयनकर्ता |
| `Super + Ctrl + Print Screen` | क्लिपबोर्ड पर टेक्स्ट निष्कर्षण |
| `Super + Alt + [` | रिकॉर्डिंग करते समय वेबकैम ओवरले छोटा करें |
| `Super + Alt + ]` | रिकॉर्डिंग करते समय वेबकैम ओवरले बड़ा करें |
| `Alt + Shift + L` | वेबऐप या Chromium से वर्तमान URL कॉपी करें |
| `Alt + Shift + D` | वर्तमान पेज पर वीडियो को `~/Videos` में डाउनलोड करें |
| `Super + Ctrl + X` | डिक्टेशन शुरू/बंद करें (_Setup > Defaults > Dictation_ आवश्यक है) |
| `Right Alt` / `F9` | पुश-टू-टॉक डिक्टेशन (Voxtype या Superwhisper आवश्यक है) |

स्क्रीन रिकॉर्डिंग के साथ, हॉटकी पहले पूछती है कि आप कौन सा ऑडियो चाहते हैं, फिर रिकॉर्डिंग शुरू करती है। रोकने के लिए फिर दबाएँ। विवरण के लिए देखें [स्क्रीनशॉट और रिकॉर्डिंग](12-screenshots-recording.md)।

सभी कैप्चर विकल्प Omarchy मेनू (`Super + Space`) में _Trigger > Capture_ के तहत भी उपलब्ध हैं।

## Tmux

प्रीफ़िक्स कुंजी `Ctrl + Space` है (`Ctrl + B` भी काम करता है)। आप इन बाइंडिंग को `~/.config/tmux/tmux.conf` में बदल सकते हैं।

### पैन

| हॉटकी                  | कार्य              |
| ----------------------- | --------------------- |
| `Prefix + v` | पैन को बगल में बाँटें (ऊर्ध्वाधर) |
| `Prefix + h` | पैन को नीचे बाँटें (क्षैतिज) |
| `Prefix + x` | पैन बंद करें |
| `Prefix + z` | पैन ज़ूम टॉगल करें (फ़ुलस्क्रीन) |
| `Alt + Enter` | पैन को नीचे बाँटें (बिना प्रीफ़िक्स के) |
| `Alt + Shift + Enter` | पैन को बगल में बाँटें (बिना प्रीफ़िक्स के) |
| `Alt + Escape` | पैन बंद करें (बिना प्रीफ़िक्स के) |
| `Ctrl + Alt + Arrows` | पैनों के बीच जाएँ |
| `Ctrl + Alt + Shift + Arrows` | पैनों का आकार बदलें |

### विंडोज़

| हॉटकी                  | कार्य              |
| ----------------------- | --------------------- |
| `Prefix + c` | नई विंडो |
| `Prefix + k` | विंडो बंद करें |
| `Prefix + r` | विंडो का नाम बदलें |
| `Alt + 1-9` | विशिष्ट विंडो पर जाएँ |
| `Alt + Arrow Left/Right` | विंडोज़ के बीच जाएँ |
| `Alt + Shift + Arrow Left/Right` | विंडो को बाएँ/दाएँ ले जाएँ |

### सेशन

### Tmux लेआउट फ़ंक्शन

ये फ़ंक्शन Tmux सेशन के अंदर चलाए जाने चाहिए।

| कमांड | कार्य |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | एडिटर, AI और टर्मिनल के साथ देव लेआउट बनाएँ |
