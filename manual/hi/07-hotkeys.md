# हॉटकीज़

आप सभी मुख्य कीबोर्ड बाइंडिंग `Super + K` से देख सकते हैं (Tmux बाइंडिंग `Super + Alt + K` से और Herdr बाइंडिंग `Super + Ctrl + K` से)।

## हॉटकीज़ कैसे व्यवस्थित हैं

हर हॉटकी एक प्लेन पर होती है, जो उसके मॉडिफ़ायर से तय होता है, और हर प्लेन का एक ही काम होता है। इसी वजह से हॉटकीज़ आपस में घुलती-मिलती नहीं हैं, और इसका मतलब है कि आप आमतौर पर अंदाज़ा लगा सकते हैं कि कोई चीज़ कहाँ मिलेगी।

| प्लेन | वहाँ क्या रहता है | उदाहरण |
| --- | --- | --- |
| `Super + key` | सिस्टम: विंडो, वर्कस्पेस, लेआउट, और मुख्य मेनू | `Super + Space` Omarchy मेनू, `Super + W` विंडो बंद करें, `Super + F` फ़ुल स्क्रीन |
| `Super + Shift + key` | ऐप्स | `Super + Shift + B` ब्राउज़र, `Super + Shift + E` ईमेल, `Super + Shift + N` एडिटर |
| `Super + Ctrl + key` | पैनल और सिस्टम मेनू | `Super + Ctrl + A` ऑडियो, `Super + Ctrl + N` नेटवर्क, `Super + Ctrl + C` कैप्चर मेनू |
| `Super + Ctrl + Alt + key` | त्वरित कार्रवाइयाँ और सूचनाएँ | `Super + Ctrl + Alt + T` समय दिखाएँ, `Super + Ctrl + Alt + B` बैटरी, `Super + Ctrl + Alt + C` स्क्रीनशॉट |

किसी हॉटकी में `Alt` जोड़ने से आपको उसी चीज़ का एक वेरिएंट मिलता है, कभी कोई असंबंधित चीज़ नहीं:

- `Super + Shift + B` ब्राउज़र खोलता है; `Super + Shift + Alt + B` निजी विंडो खोलता है
- `Super + Shift + E` ईमेल खोलता है; `Super + Shift + Alt + E` नया ईमेल शुरू करता है
- `Super + F` फ़ुल स्क्रीन पर जाता है; `Super + Alt + F` फ़ुल चौड़ाई पर जाता है
- `Super + Ctrl + C` कैप्चर मेनू खोलता है; `Super + Ctrl + Alt + C` मेनू छोड़कर स्क्रीनशॉट लेता है

हॉटकी जोड़ते समय:

1. वह क्या करती है, उससे प्लेन चुनें, फिर कुंजी चुनें।
2. जगह बनाने के लिए किसी मौजूदा हॉटकी को न हटाएँ। सही प्लेन पर कोई खाली कुंजी खोजें।
3. `Alt` का इस्तेमाल सिर्फ़ उसके बिना वाली हॉटकी के वेरिएंट के लिए करें।

कुछ हॉटकीज़ इन नियमों को तोड़ती हैं क्योंकि वे सुविधाजनक हैं। तीर या `Tab` के साथ `Shift` ऐप खोलने के बजाय ले जाता है या उलट देता है, और `Print`, मीडिया कुंजियाँ, `Alt + Tab`, और `Ctrl + Alt + Del` वैसे ही काम करते हैं जैसे वे हर दूसरी जगह करते हैं। वे अपवाद हैं, नकल करने के पैटर्न नहीं।

अगर कोई डिफ़ॉल्ट आपको नहीं जमता (मान लीजिए आप Windows की तरह स्क्रीनशॉट के लिए `Super + Shift + S` चाहते हैं), तो उसे `~/.config/hypr/bindings.lua` में रीबाइंड करें।

| `Super + Shift + I` | इनपुट भाषा वापस बदलें |

टचपैड पर, तीन- और चार-उंगली स्वाइप वर्कस्पेस बदलते हैं, विंडो ले जाते हैं, और मेनू तथा Quake कंसोल खोलते हैं; जेस्चर के लिए [कीबोर्ड, माउस, और ट्रैकपैड](34-keyboard-mouse-trackpad.md) देखें।

आकार बदलने के शॉर्टकट भौतिक कुंजियों `code:20` और `code:21` (XKB `<AE11>` और `<AE12>`) का इस्तेमाल करते हैं, कीबोर्ड पर छपे अक्षरों की परवाह किए बिना। US कीबोर्ड पर ये कुंजियाँ `-` और `=` हैं; जापानी (JIS) कीबोर्ड पर वे `-` और `^` हैं; स्पेनिश कीबोर्ड पर वे `'` और `¡` हैं। JIS पर, `Super + ^` ही `Super + Equal` है, जबकि `Super + Shift + -` (जो `=` टाइप करता है) ही `Super + Shift + Minus` है।

## सार्वभौमिक क्लिपबोर्ड

| हॉटकी                  | कार्य              |
| ----------------------- | --------------------- |
| `Super + A`           | उन ऐप्स में सब चुनें जो `Ctrl + A` का समर्थन करते हैं    |
| `Super + C`           | कॉपी करें    |
| `Super + X`           | काटें (टर्मिनल में नहीं)    |
| `Super + V`           | पेस्ट करें    |
| `Super + Ctrl + V`           | क्लिपबोर्ड मैनेजर    |

आमतौर पर Linux पर, टर्मिनल में copy'n'paste करने के लिए आपको `Ctrl + Shift + C/V` चाहिए और हर दूसरी जगह ऐसा करने के लिए `Ctrl + C/V` चाहिए। ये Omarchy एकीकृत क्लिपबोर्ड हॉटकीज़ हर जगह काम करती हैं।

| `Alt + Shift + D` | वर्तमान पेज पर मौजूद वीडियो को `~/Videos` में डाउनलोड करें |

स्क्रीनरिकॉर्डिंग के साथ, हॉटकी पहले पूछती है कि आप कौन-सा ऑडियो चाहते हैं, फिर रिकॉर्डिंग शुरू करती है। रोकने के लिए इसे फिर दबाएँ। विवरण के लिए [स्क्रीनशॉट और रिकॉर्डिंग](12-screenshots-recording.md) देखें।

सभी कैप्चर विकल्प Omarchy मेनू (`Super + Space`) में _Trigger > Capture_ के अंतर्गत भी उपलब्ध हैं।

## Tmux

प्रीफ़िक्स कुंजी `Ctrl + Space` है (`Ctrl + B` भी काम करता है)। आप इन बाइंडिंग को `~/.config/tmux/tmux.conf` में बदल सकते हैं।

### पेन

| हॉटकी                  | कार्य              |
| ----------------------- | --------------------- |
| `Prefix + v` | पेन को बगल में विभाजित करें (ऊर्ध्वाधर) |
| `Prefix + h` | पेन को नीचे विभाजित करें (क्षैतिज) |
| `Prefix + x` | पेन बंद करें |
| `Prefix + z` | पेन ज़ूम टॉगल करें (फ़ुलस्क्रीन) |
| `Alt + Enter` | पेन को नीचे विभाजित करें (बिना प्रीफ़िक्स) |
| `Alt + Shift + Enter` | पेन को बगल में विभाजित करें (बिना प्रीफ़िक्स) |
| `Alt + Escape` | पेन बंद करें (बिना प्रीफ़िक्स) |
| `Ctrl + Alt + Arrows` | पेन के बीच जाएँ |
| `Ctrl + Alt + Shift + Arrows` | पेन का आकार बदलें |

### विंडो

| हॉटकी                  | कार्य              |
| ----------------------- | --------------------- |
| `Prefix + c` | नई विंडो |
| `Prefix + k` | विंडो बंद करें |
| `Prefix + r` | विंडो का नाम बदलें |
| `Alt + 1-9` | विशिष्ट विंडो पर जाएँ |
| `Alt + Arrow Left/Right` | विंडो के बीच जाएँ |
| `Alt + Shift + Arrow Left/Right` | विंडो को बाएँ/दाएँ ले जाएँ |

### सत्र

| हॉटकी                  | कार्य              |
| ----------------------- | --------------------- |
| `Prefix + C` | नया सत्र |
| `Prefix + K` | सत्र समाप्त करें |
| `Prefix + R` | सत्र का नाम बदलें |
| `Prefix + N` | अगला सत्र |
| `Prefix + P` | पिछला सत्र |
| `Alt + Arrow Up/Down` | सत्रों के बीच जाएँ |
| `Prefix + s` | सत्रों की सूची देखें |
| `Prefix + d` | सत्र से अलग हों |

### कॉपी मोड (vi-शैली)

| हॉटकी                  | कार्य              |
| ----------------------- | --------------------- |
| `Prefix + [` | कॉपी मोड में प्रवेश करें |
| `v` | चयन शुरू करें (कॉपी मोड में) |
| `y` | चयन कॉपी करें (कॉपी मोड में) |

### सामान्य

| हॉटकी                  | कार्य              |
| ----------------------- | --------------------- |
| `Prefix + q` | कॉन्फ़िग फिर से लोड करें |

| `Prefix + :` | कमांड प्रॉम्प्ट |

### Tmux लेआउट फ़ंक्शन

इन फ़ंक्शन को Tmux सत्र के अंदर चलाया जाना चाहिए।

| कमांड | कार्य |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | एडिटर, AI, और टर्मिनल के साथ डेव लेआउट बनाएँ |
| `tdlm <ai> [<second_ai>]` | प्रत्येक सबडायरेक्टरी के लिए डेव लेआउट बनाएँ |
| `tsl <count> <command>` | मल्टी-पेन स्वार्म लेआउट बनाएँ |
