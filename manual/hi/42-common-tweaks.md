# Common tweaks

यह Omarchy सेटअप के लिए सामान्य अनुकूलनों का एक संग्रह है। जान लें कि सिस्टम अपडेट के लिए कभी-कभी कुछ कॉन्फ़िग को उनकी मूल स्थिति में बहाल करना आवश्यक हो सकता है। अगर ऐसा होता है, तो आपके बदलाव खो नहीं जाएँगे, बल्कि उसी डायरेक्टरी में एक `.bak` फ़ाइल में रख दिए जाएँगे।

अगर आप कुछ गड़बड़ कर देते हैं, तो आप Omarchy मेनू में _Update > Config_ के ज़रिए अलग-अलग कॉन्फ़िग को उनके मूल सेटअप में बहाल कर सकते हैं। अगर आप _वास्तव में_ सब कुछ गड़बड़ कर देते हैं, तो आप `omarchy-reinstall` के ज़रिए सभी कॉन्फ़िग रीसेट कर सकते हैं।

### सभी ट्रे आइकन हर समय दिखाएँ

डिफ़ॉल्ट रूप से, Dropbox, 1password या Steam जैसे ट्रे आइकन, ट्रे एक्सपैंडर तीर के पीछे छिपे होते हैं, जो आपके उस पर होवर करने पर उन्हें प्रकट करता है। अगर आप उन्हें हर समय उजागर रखना चाहते हैं, तो ट्रे आइकन मैनेजर खोलने के लिए एक्सपैंडर तीर पर राइट-क्लिक करें, फिर उन आइकनों को पिन करें जिन्हें आप दृश्य रखना चाहते हैं (आप उन आइकनों को भी छिपा सकते हैं जिन्हें आप कभी नहीं देखना चाहते)।

### गोल विंडो कोने

Omarchy का डिफ़ॉल्ट डिज़ाइन चौकोर कोनों वाला है, लेकिन अगर आप उसे थोड़ा नरम करना पसंद करते हैं, तो आप `~/.config/hypr/looknfeel.lua` बदल सकते हैं ताकि राउंडिंग अब कमेंट आउट न हो:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### विंडो गैप हटाएँ

लैपटॉप डिस्प्ले पर, कुछ लोग विंडो गैप (या यहाँ तक कि टॉप बार, जिसे आप `Super + Shift + Space` से बंद कर सकते हैं) पर कोई पिक्सेल बर्बाद न करना पसंद करते हैं। आप `Super + Shift + Backspace` से सभी गैप और बॉर्डर बंद कर सकते हैं, या `~/.config/hypr/looknfeel.lua` के इस खंड में कमेंट हटाकर उन्हें स्थायी रूप से हटा सकते हैं:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
