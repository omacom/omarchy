# Omarchy में आपका स्वागत है!

Omarchy एक [omakase](https://manuals.omamix.org/3/omacom/76/omakase-computing) Linux distribution है, जो [Arch](https://archlinux.org/), tiling window manager [Hyprland](https://hypr.land/), और desktop construction-kit [Quickshell](https://quickshell.org/) पर आधारित है। इसमें वह सब कुछ पहले से मौजूद है जिसकी एक आधुनिक, समझदार computer उपयोगकर्ता को तुरंत उत्पादक बनने के लिए ज़रूरत होती है। [Neovim](https://neovim.io/) (btw) से लेकर Google Chrome तक, [Obsidian](https://obsidian.md/) से लेकर LibreOffice तक, और [Hype](https://github.com/omacom/hype) से लेकर [Monologue](https://github.com/omacom/monologue) तक। अरे, एक retro Winamp-style music player भी मौजूद है!

हालाँकि, यह सिर्फ़ पहले से install किए गए packages की एक बेतरतीब थैली भर नहीं है। यह एक संपूर्ण system है जिसे aesthetics और productivity दोनों को ध्यान में रखकर design किया गया है। क्योंकि एक _सुंदर_ system एक _प्रेरित करने वाला_ system होता है, और productivity हमेशा [motivation से ही उपजती है](https://world.hey.com/dhh/beautiful-motivations-6fef7c73)। यहाँ बिल्कुल कोई bloat नहीं है: बस वह सब कुछ जो मैं उपयोग करता हूँ।

यह सच है कि Omarchy जैसे TUI-heavy, theme-delighted, tiling-window-managed system की सुंदरता को परखने की नज़र विकसित करना एक अर्जित रुचि हो सकती है। लेकिन आप यहाँ इसीलिए तो हैं, है न? अपने comfort zone से थोड़ा बाहर निकलकर कुछ अनुभव करने के लिए? Computers के साथ काम करने के एक नए तरीके की एक छोटी-सी adventure पर निकलने के लिए? मुझे ऐसी ही उम्मीद है।

Omarchy Windows जैसा नहीं है और यह macOS जैसा भी नहीं है। यह जितना संभव हो उतना परिचित बनने की कोशिश भी नहीं कर रहा है। यह सुंदर और _बेहतर_ बनने की कोशिश कर रहा है। इसकी Linux-ness को अपनाइए। कुछ config files को manually edit करना, बिल्कुल। Terminal का भरपूर उपयोग, निश्चित रूप से।

चलिए basics से शुरुआत करते हैं।
