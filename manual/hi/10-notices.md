# सूचनाएँ

आप हॉटकी नोटिस का उपयोग करके तारीख और समय, बैटरी स्थिति और वर्तमान मौसम तक तुरंत पहुँच सकते हैं।

### तारीख और समय

`Super + Ctrl + Alt + T`

 ![notice-datetime](images/notice-datetime.webp)

### मौसम

`Super + Ctrl + Alt + W`

 ![notice-weather](images/notice-weather.webp)

स्थान आपके IP पते से पहचाना जाता है, जो आमतौर पर पर्याप्त सटीक होता है, लेकिन हमेशा नहीं। आप इसे `omarchy weather location --set Malibu` से तय कर सकते हैं, या निर्देशांक जोड़कर बिल्कुल सटीक हो सकते हैं: `omarchy weather location --set Malibu 34.0259,-118.7798`। यह देखने के लिए कि वह आपको कहाँ समझता है, अकेले `omarchy weather location` चलाएँ, और स्वचालित पहचान पर वापस जाने के लिए `--clear` चलाएँ।
