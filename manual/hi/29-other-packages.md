# अन्य पैकेज

Arch के पास आधिकारिक रिपॉज़िटरी और Arch User Repository (AUR) के बीच लगभग किसी भी प्रकार के सॉफ़्टवेयर के लिए उपलब्ध पैकेजों की अद्भुत संपत्ति है।

इसका उपयोग करना इससे आसान नहीं हो सकता। आप Omarchy मेनू (`Super + Space`) में _Install > Package_ पर जाकर और वांछित पैकेज टाइप करके नया Arch पैकेज इंस्टॉल करते हैं। यह सभी पैकेजों की सूची को स्वतः फ़ज़ी फ़िल्टर करेगा। (आप इसे टर्मिनल में `omarchy pkg add [package]` का उपयोग करके मैन्युअल रूप से भी कर सकते हैं)।

आप AUR के साथ भी यही कर सकते हैं, बस _Install > AUR_ का उपयोग करें। बस याद रखें कि AUR की जाँच Arch टीम द्वारा नहीं की जाती। यह RubyGems या npm जैसा है। कोई भी अपलोड कर सकता है।

अगर आप कोई पैकेज हटाना चाहते हैं, तो आप Omarchy मेनू से _Remove > Package_ का उपयोग कर सकते हैं। यह पैकेज, कॉन्फ़िग फ़ाइलें और डिपेंडेंसी हटा देगा। (आप इसे `omarchy pkg drop [package]` का उपयोग करके मैन्युअल रूप से भी कर सकते हैं)।
