# Genvejstaster

Du kan se alle de vigtigste tastaturbindinger med `Super + K` (Tmux-bindinger med `Super + Alt + K` og Herdr-bindinger med `Super + Ctrl + K`).

| `Super + Alt + G`               | Flyt vindue ud af gruppering      |

| `Super + Alt + /` | Gå tilbage gennem indstillinger for skærmskalering |

| `Alt + Shift + Tab` | Skift baglæns gennem vinduer på det aktive arbejdsområde |
| `Ctrl + Alt + Tab`| Skift fokus fremad gennem skærme |
| `Ctrl + Alt + Shift + Tab`| Skift fokus baglæns gennem skærme |

Genveje til ændring af størrelse bruger de fysiske taster `code:20` og `code:21` (XKB `<AE11>` og `<AE12>`), uanset hvilke tegn der er trykt på tastaturet. På amerikanske tastaturer er disse taster `-` og `=`; på japanske (JIS) tastaturer er de `-` og `^`; på spanske tastaturer er de `'` og `¡`. På JIS er `Super + ^` lig med `Super + Equal`, mens `Super + Shift + -` (som skriver `=`) er `Super + Shift + Minus`.

## Universel udklipsholder

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + A`           | Markér alt i apps, der understøtter `Ctrl + A`    |
| `Super + C`           | Kopiér    |
| `Super + X`           | Klip (ikke i terminalen)    |
| `Super + V`           | Sæt ind    |
| `Super + Ctrl + V`           | Udklipsholderhåndtering    |

Normalt på Linux skal du bruge `Ctrl + Shift + C/V` for at kopiere og sætte ind i terminalen og `Ctrl + C/V` for at gøre det alle andre steder. Disse samlede Omarchy-genveje til udklipsholderen virker overalt.
