# Tastaturgenveje

Du kan se alle de vigtigste tastaturbindinger med `Super + K` (Tmux-bindinger med `Super + Alt + K` og Herdr-bindinger med `Super + Ctrl + K`).

## Navigation

| Genvejstast                  | Funktion              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy-menu (apps og alt andet)    |
| `Super + Alt + Space` | Appgitter |
| `Super + Escape` | Systemmenu (hvile, genstart osv.)  |
| `Super + Ctrl + L` | Lås computeren |
| `Super + W` eller `Super + Q` | Luk vindue             |
| `Ctrl + Alt + Del` | Luk alle vinduer |
| `Super + T`               | Skift vindue mellem fliselægning/flydende             |
| `Super + J` | Skift vinduesposition (vandret/lodret) |
| `Super + O`               | Skift vindue til klæbrigt og flydende |
| `Super + L`               | Bladr igennem layouterne dwindle, rulning og flydende |
| `Super + Alt + L`         | Bladr igennem layouterne baglæns |
| `Super + P`               | Skift pseudo-vinduesstil (naturlig vs. strakt) |
| `Super + F`                 | Gå i fuld skærm              |
| `Super + Alt + F`                 | Gå i fuld bredde              |
| `Super + Ctrl + F`                 | Gå i fuld skærm inde i vinduet              |
| `Super + 1/2/3/4`         | Hop til et bestemt arbejdsområde     |
| `Super + Tab` | Hop til næste arbejdsområde |
| `Super + Shift + Tab` | Hop til forrige arbejdsområde |
| `Super + Ctrl + Tab` | Hop til tidligere arbejdsområde |
| `Super + Shift + 1/2/3/4` | Flyt vindue til arbejdsområde |
| `Super + Shift + Alt + 1/2/3/4` | Flyt vindue til arbejdsområde uden at følge med |
| `Super + S` / `Super + Grave` | Slå kladde til/fra |
| `Super + Alt + S` / `Super + Shift + Grave` | Flyt vindue til kladde |
| `Super + Shift + Alt + Arrows` | Flyt arbejdsområder til skærm i pilens retning |
| `Super + Arrow`  | Flyt fokus til vindue i pilens retning              |
| `Super + Shift + Arrow`  | Byt vindue med et andet i pilens retning     |
| `Super + Minus` | Udvid vindue til venstre |
| `Super + Equal` | Krymp vindue til venstre |
| `Super + Shift + Minus` | Krymp vindue opad |
| `Super + Shift + Equal` | Udvid vindue nedad |
| `Super + Alt + Minus/Equal` | Samme tilpasning i mindre trin |
| `Super + Ctrl + Minus/Equal` | Samme tilpasning i større trin |
| `Super + Alt + Home` | Gem vinduesbredde |
| `Super + Home` | Gendan gemt vinduesbredde |
| `Super + Left Mouse` | Træk vindue rundt |
| `Super + Right Mouse` | Tilpas vindue |
| `Super + Scroll Wheel` | Rul igennem arbejdsområder |
| `Super + G`               | Slå vinduesgruppering til/fra      |
| `Super + Alt + G`               | Flyt vindue ud af gruppering      |
| `Super + Alt + Tab`               | Bladr mellem vinduer i gruppering      |
| `Super + Alt + Shift + Tab`               | Bladr baglæns mellem vinduer i gruppering      |
| `Super + Alt + 1/2/3/4/5`               | Hop til et bestemt vindue i gruppering      |
| `Super + Alt + Arrow`  | Flyt vindue ind i gruppering i pilens retning  |
| `Super + Ctrl + Left/Right`  | Bevæg dig mellem vinduer i en fliselægningsgruppe |
| `Super + Ctrl + Z` | Zoom ind på skærmen (gentag for mere zoom) |
| `Super + Ctrl + Alt + Z` | Zoom helt ud fra skærmen |
| `Super + /` | Træd frem gennem indstillinger for skærmskalering |
| `Super + Alt + /` | Træd tilbage gennem indstillinger for skærmskalering |
| `Alt + Tab` | Bladr frem gennem vinduer på det aktive arbejdsområde |
| `Alt + Shift + Tab` | Bladr tilbage gennem vinduer på det aktive arbejdsområde |
| `Ctrl + Alt + Tab`| Bladr fokus frem gennem skærme |
| `Ctrl + Alt + Shift + Tab`| Bladr fokus tilbage gennem skærme |

## Universel udklipsholder

| Genvejstast                  | Funktion              |
| ----------------------- | --------------------- |
| `Super + C`           | Kopiér    |
| `Super + X`           | Klip (ikke i terminalen)    |
| `Super + V`           | Indsæt    |
| `Super + Ctrl + V`           | Udklipsholderhåndtering    |

Normalt på Linux skal du bruge `Ctrl + Shift + C/V` til at kopiér-og-indsætte i terminalen og `Ctrl + C/V` til at gøre det alle andre steder. Disse samlede Omarchy-udklipsholdergenveje virker overalt.

## Optag

| Genvejstast              | Funktion                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Optagelsesmenu (til tastaturer uden PrintScr-knap) |
| `Print Screen`            | Skærmbillede                      |
| `Alt + Print Screen`            | Skærmoptagelse                     |
| `Super + Print Screen` | Farvevælger |
| `Super + Ctrl + Print Screen` | Tekstudtræk til udklipsholderen |
| `Super + Alt + [` | Gør webcam-overlægningen mindre under optagelse |
| `Super + Alt + ]` | Gør webcam-overlægningen større under optagelse |
| `Alt + Shift + L` | Kopiér current URL from webapp or Chromium |
| `Alt + Shift + D` | Hent videoen på den aktuelle side til `~/Videos` |
| `Super + Ctrl + X` | Start/stop diktering (kræver _Opsætning > Standarder > Diktering_) |
| `Right Alt` / `F9` | Push-to-talk-diktering (kræver Voxtype eller Superwhisper) |

Ved skærmoptagelser spørger genvejstasten først, hvilken lyd du ønsker, og starter derefter optagelsen. Tryk på den igen for at stoppe. Se [skærmbilleder og optagelse](12-screenshots-recording.md) for detaljerne.

Alle optagelsesmuligheder er også tilgængelige under _Udløs > Optag_ i Omarchy-menuen (`Super + Space`).

## Stil

| Genvejstast                  | Funktion              |
| ----------------------- | --------------------- |
| `Super + Ctrl + Shift + Space` | Vælg et nyt tema  |
| `Super + Ctrl + Space` | Vælg temabaggrund |
| `Super + Backspace` | Slå gennemsigtighed til/fra på et vindue |
| `Super + Ctrl + Backspace` | Slå kvadratisk format til/fra for enkeltvindue |

Ekstra baggrundsbilleder bor i `~/.config/omarchy/backgrounds/<theme name>`. Også tilgængelige via _Installer > Stil > Baggrund_ i Omarchy-menuen.

Alle stilmuligheder er også tilgængelige under _Stil_ i Omarchy-menuen (`Super + Space`).

## Tmux

Præfiksnøglen er `Ctrl + Space` (`Ctrl + B` virker også). Du kan ændre disse bindinger i `~/.config/tmux/tmux.conf`.

### Paneler

| Genvejstast                  | Funktion              |
| ----------------------- | --------------------- |
| `Prefix + v` | Del panel ved siden af (lodret) |
| `Prefix + h` | Del panel nedenunder (vandret) |
| `Prefix + x` | Dræb panel |
| `Prefix + z` | Slå panelzoom til/fra (fuld skærm) |
| `Alt + Enter` | Del panel nedenunder (intet præfiks) |
| `Alt + Shift + Enter` | Del panel ved siden af (intet præfiks) |
| `Alt + Escape` | Dræb panel (no prefix) |
| `Ctrl + Alt + Arrows` | Bevæg dig mellem paneler |
| `Ctrl + Alt + Shift + Arrows` | Tilpas paneler |

### Vinduer

| Genvejstast                  | Funktion              |
| ----------------------- | --------------------- |
| `Prefix + c` | Nyt vindue |
| `Prefix + k` | Dræb vindue |
| `Prefix + r` | Omdøb vindue |
| `Alt + 1-9` | Gå til et bestemt vindue |
| `Alt + Arrow Left/Right` | Bevæg dig mellem vinduer |
| `Alt + Shift + Arrow Left/Right` | Flyt vindue til venstre/højre |

### Sessioner

| Genvejstast                  | Funktion              |
| ----------------------- | --------------------- |
| `Prefix + C` | Ny session |
| `Prefix + K` | Dræb session |
| `Prefix + R` | Omdøb session |
| `Prefix + N` | Næste session |
| `Prefix + P` | Forrige session |
| `Alt + Arrow Up/Down` | Bevæg dig mellem sessioner |
| `Prefix + s` | Vis sessioner |
| `Prefix + d` | Kobl fra session |

### Kopitilstand (vi-stil)

| Genvejstast                  | Funktion              |
| ----------------------- | --------------------- |
| `Prefix + [` | Gå ind i kopitilstand |
| `v` | Begynd markering (i kopitilstand) |
| `y` | Kopiér selection (in copy mode) |

### Generelt

| Genvejstast                  | Funktion              |
| ----------------------- | --------------------- |
| `Prefix + q` | Genindlæs konfiguration |
| `Prefix + ?` | Vis Tmux-tastebindinger |
| `Prefix + :` | Kommandoprompt |

### Tmux-layoutfunktioner

Disse funktioner skal køres inde i en Tmux-session.

| Kommando | Funktion |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Opret udviklerlayout med editor, AI og terminal |
| `tdlm <ai> [<second_ai>]` | Opret udviklerlayout pr. undermappe |
| `tsl <count> <command>` | Opret sværmlayout med flere paneler |

## Neovim (m/ lazyvim)

### Navigation

| Genvejstast                   | Funktion                        |
| ------------------------ | ------------------------------- |

| `Shift + H`                      | Gå til venstre filfane             |
| `Shift + L`                      | Gå til højre filfane            |

### Mens du er i sidebjælken

| Genvejstast                   | Funktion                        |
| ------------------------ | ------------------------------- |
| `A`                        | Tilføj ny fil i overordnet mappe      |
| `Shift + A`                | Tilføj ny undermappe i overordnet mappe    |

| `R`                        | Omdøb fremhævet fil/mappe     |

[Se alle de Neovim-genvejstaster, der er konfigureret af LazyVim](https://www.lazyvim.org/keymaps).
