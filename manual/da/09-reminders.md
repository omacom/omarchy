# Påmindelser

Omarchy har en indbygget måde at oprette enkle påmindelser baseret på en nedtællingstimer og med en besked. Du kan gøre det via `Super + Ctrl + R`, se alle dem, der er oprettet, via `Super + Ctrl + Alt + R` og rydde alle via `Super + Ctrl + Shift + R`. Alt sammen også tilgængeligt via _Udløs > Påmindelse_. Du kan også bruge CLI'en med `omarchy reminder 7 'Tea ready'`.
