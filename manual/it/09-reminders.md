# Promemoria

Omarchy ha un modo integrato per impostare semplici promemoria basati su un conto alla rovescia e con un messaggio. Puoi farlo tramite `Super + Ctrl + R`, vedere tutti quelli impostati tramite `Super + Ctrl + Alt + R` e cancellarli tutti tramite `Super + Ctrl + Shift + R`. Tutto accessibile anche tramite _Azioni > Promemoria_. Puoi anche usare la CLI con `omarchy reminder 7 'Tea ready'`.
