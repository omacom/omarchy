# Altri pacchetti

Arch ha una straordinaria ricchezza di pacchetti disponibili per quasi qualsiasi tipo di software tra il repository ufficiale e l'Arch User Repository (AUR).

E non potrebbe essere più semplice da usare. Installi un nuovo pacchetto Arch andando in _Installa > Pacchetto_ nel menu Omarchy (`Super + Space`) e digitando il pacchetto che vuoi. Filtrerà automaticamente in modo fuzzy l'elenco di tutti i pacchetti. (Puoi anche farlo manualmente usando `omarchy pkg add [package]` nel terminale).

Puoi fare lo stesso con l'AUR, usa semplicemente _Installa > AUR_. Ricorda solo che l'AUR non è controllato dal team Arch. È come RubyGems o npm. Chiunque può caricare.

Se vuoi rimuovere un pacchetto, puoi usare _Rimuovi > Pacchetto_ dal menu Omarchy. Rimuoverà pacchetto, file di configurazione e dipendenze. (Puoi anche farlo manualmente usando `omarchy pkg drop [package]`).
