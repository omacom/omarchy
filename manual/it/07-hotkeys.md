# Scorciatoie

Puoi vedere tutte le principali combinazioni da tastiera con `Super + K` (combinazioni Tmux con `Super + Alt + K` e combinazioni Herdr con `Super + Ctrl + K`).

## Navigazione

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Super + Space`           | Menu Omarchy (app e tutto il resto)    |
| `Super + Alt + Space` | Griglia app |
| `Super + Escape` | Menu di sistema (sospendi, riavvia, ecc.)  |
| `Super + Ctrl + L` | Blocca computer |
| `Super + W` or `Super + Q` | Chiudi finestra             |
| `Ctrl + Alt + Del` | Chiudi tutte le finestre |
| `Super + T`               | Attiva/disattiva finestra tra affiancata/flottante             |
| `Super + J` | Attiva/disattiva posizione finestra (orizzontale/verticale) |
| `Super + O`               | Attiva/disattiva estrazione finestra in fissa e flottante |
| `Super + L`               | Scorre i layout dwindle, scorrimento e flottante |
| `Super + Alt + L`         | Scorre i layout al contrario |
| `Super + P`               | Attiva/disattiva stile pseudo-finestra (naturale contro allungato) |
| `Super + F`                 | Vai a schermo intero              |
| `Super + Alt + F`                 | Vai a piena larghezza              |
| `Super + Ctrl + F`                 | Vai a schermo intero dentro la finestra              |
| `Super + 1/2/3/4`         | Salta a workspace specifico     |
| `Super + Tab` | Salta al workspace successivo |
| `Super + Shift + Tab` | Salta al workspace precedente |
| `Super + Ctrl + Tab` | Salta al workspace precedente in cronologia |
| `Super + Shift + 1/2/3/4` | Sposta finestra su workspace |
| `Super + Shift + Alt + 1/2/3/4` | Sposta finestra su workspace senza seguirla |
| `Super + S` / `Super + Grave` | Attiva/disattiva scratchpad |
| `Super + Alt + S` / `Super + Shift + Grave` | Sposta finestra su scratchpad |
| `Super + Shift + Alt + Arrows` | Sposta workspace sul monitor direzionale |
| `Super + Arrow`  | Sposta focus sulla finestra nella direzione della freccia              |
| `Super + Shift + Arrow`  | Scambia finestra con un'altra nella direzione della freccia     |
| `Super + Minus` | Espandi finestra a sinistra |
| `Super + Equal` | Restringi finestra a sinistra |
| `Super + Shift + Minus` | Restringi finestra in alto |
| `Super + Shift + Equal` | Espandi finestra in basso |
| `Super + Alt + Minus/Equal` | Stesso ridimensionamento a passi più piccoli |
| `Super + Ctrl + Minus/Equal` | Stesso ridimensionamento a passi più grandi |
| `Super + Alt + Home` | Salva larghezza finestra |
| `Super + Home` | Ripristina larghezza finestra salvata |
| `Super + Left Mouse` | Trascina finestra in giro |
| `Super + Right Mouse` | Ridimensiona finestra |
| `Super + Scroll Wheel` | Scorri tra i workspace |
| `Super + G`               | Attiva/disattiva raggruppamento finestre      |
| `Super + Alt + G`               | Sposta finestra fuori dal gruppo      |
| `Super + Alt + Tab`               | Scorre tra le finestre del gruppo      |
| `Super + Alt + Shift + Tab`               | Scorre all'indietro tra le finestre del gruppo      |
| `Super + Alt + 1/2/3/4/5`               | Salta a finestra specifica nel gruppo      |
| `Super + Alt + Arrow`  | Sposta finestra nel gruppo nella direzione della freccia  |
| `Super + Ctrl + Left/Right`  | Spostati tra finestre dentro un gruppo affiancato |
| `Super + Ctrl + Z` | Ingrandisci sullo schermo (ripeti per più zoom) |
| `Super + Ctrl + Alt + Z` | Rimpicciolisci completamente dallo schermo |
| `Super + /` | Avanza tra le opzioni di scalatura monitor |
| `Super + Alt + /` | Indietreggia tra le opzioni di scalatura monitor |
| `Alt + Tab` | Scorre in avanti tra le finestre sul workspace attivo |
| `Alt + Shift + Tab` | Scorre all'indietro tra le finestre sul workspace attivo |
| `Ctrl + Alt + Tab`| Scorre il focus in avanti tra i monitor |
| `Ctrl + Alt + Shift + Tab`| Scorre il focus all'indietro tra i monitor |

## Appunti universali

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Super + C`           | Copia    |
| `Super + X`           | Taglia (non nel terminale)    |
| `Super + V`           | Incolla    |
| `Super + Ctrl + V`           | Gestore appunti    |

Di solito su Linux, serve `Ctrl + Shift + C/V` per copiare e incollare nel terminale e `Ctrl + C/V` per farlo ovunque altro. Queste scorciatoie appunti unificate di Omarchy funzionano ovunque.

## Cattura

| Scorciatoia              | Funzione                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Menu Cattura (per tastiere senza tasto PrintScr) |
| `Print Screen`            | Schermata                      |
| `Alt + Print Screen`            | Registra schermo                     |
| `Super + Print Screen` | Selettore colore |
| `Super + Ctrl + Print Screen` | Estrazione testo negli appunti |
| `Super + Alt + [` | Rendi più piccolo l'overlay webcam durante la registrazione |
| `Super + Alt + ]` | Rendi più grande l'overlay webcam durante la registrazione |
| `Alt + Shift + L` | Copia URL corrente da webapp o Chromium |
| `Alt + Shift + D` | Scarica il video sulla pagina corrente in `~/Videos` |
| `Super + Ctrl + X` | Avvia/ferma dettatura (richiede _Impostazioni > Predefiniti > Dettatura_) |
| `Right Alt` / `F9` | Dettatura push-to-talk (richiede Voxtype o Superwhisper) |

Con le registrazioni schermo, la scorciatoia chiede prima quale audio vuoi, poi avvia la registrazione. Premila di nuovo per fermare. Vedi [schermate e registrazione](12-screenshots-recording.md) per i dettagli.

Tutte le opzioni di cattura sono accessibili anche sotto _Azioni > Cattura_ nel menu Omarchy (`Super + Space`).

## Tmux

Il tasto prefisso è `Ctrl + Space` (funziona anche `Ctrl + B`). Puoi cambiare queste combinazioni in `~/.config/tmux/tmux.conf`.

### Pannelli

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Prefix + v` | Dividi pannello accanto (verticale) |
| `Prefix + h` | Dividi pannello sotto (orizzontale) |
| `Prefix + x` | Uccidi pannello |
| `Prefix + z` | Attiva/disattiva zoom pannello (schermo intero) |
| `Alt + Enter` | Dividi pannello sotto (senza prefisso) |
| `Alt + Shift + Enter` | Dividi pannello accanto (senza prefisso) |
| `Alt + Escape` | Uccidi pannello (senza prefisso) |
| `Ctrl + Alt + Arrows` | Spostati tra i pannelli |
| `Ctrl + Alt + Shift + Arrows` | Ridimensiona pannelli |

### Finestre

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Prefix + c` | Nuova finestra |
| `Prefix + k` | Uccidi finestra |
| `Prefix + r` | Rinomina finestra |
| `Alt + 1-9` | Vai a finestra specifica |
| `Alt + Arrow Left/Right` | Spostati tra le finestre |
| `Alt + Shift + Arrow Left/Right` | Sposta finestra a sinistra/destra |

### Sessioni

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Prefix + C` | Nuova sessione |
| `Prefix + K` | Uccidi sessione |
| `Prefix + R` | Rinomina sessione |
| `Prefix + N` | Sessione successiva |
| `Prefix + P` | Sessione precedente |
| `Alt + Arrow Up/Down` | Spostati tra le sessioni |
| `Prefix + s` | Elenca sessioni |
| `Prefix + d` | Staccati dalla sessione |

### Modalità copia (stile vi)

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Prefix + [` | Entra in modalità copia |
| `v` | Inizia selezione (in modalità copia) |
| `y` | Copia selezione (in modalità copia) |

### Generale

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Prefix + q` | Ricarica configurazione |
| `Prefix + ?` | Mostra scorciatoie Tmux |
| `Prefix + :` | Prompt comandi |

### Funzioni layout Tmux

Queste funzioni devono essere eseguite dentro una sessione Tmux.

| Comando | Funzione |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Crea layout di sviluppo con editor, AI e terminale |
| `tdlm <ai> [<second_ai>]` | Crea layout di sviluppo per sottocartella |
| `tsl <count> <command>` | Crea layout sciame multi-pannello |
