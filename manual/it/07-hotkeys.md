# Scorciatoie da tastiera

Puoi vedere tutte le principali combinazioni di tasti con `Super + K` (combinazioni Tmux con `Super + Alt + K` e combinazioni Herdr con `Super + Ctrl + K`).

## Navigazione

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Super + Space`           | Menu Omarchy (app e tutto il resto)    |
| `Super + Alt + Space` | Griglia delle app |
| `Super + Escape` | Menu di sistema (sospendi, riavvia, ecc.)  |
| `Super + Ctrl + L` | Blocca il computer |
| `Super + W` or `Super + Q` | Chiudi finestra             |
| `Ctrl + Alt + Del` | Chiudi tutte le finestre |
| `Super + T`               | Alterna finestra tra tiling/floating             |
| `Super + J` | Alterna posizione della finestra (orizzontale/verticale) |
| `Super + O`               | Alterna finestra a comparsa in sticky'n'floating |
| `Super + L`               | Scorri tra i layout dwindle, scrolling e floating |
| `Super + Alt + L`         | Scorri tra i layout in ordine inverso |
| `Super + P`               | Alterna stile finestra pseudo (natural v stretch) |
| `Super + F`                 | Vai a schermo intero              |
| `Super + Alt + F`                 | Vai a larghezza intera              |
| `Super + Ctrl + F`                 | Vai a schermo intero dentro la finestra              |
| `Super + 1/2/3/4`         | Vai allo workspace specifico sul monitor attivo |
| `Super + Tab` | Vai allo workspace successivo sul monitor attivo |
| `Super + Shift + Tab` | Vai allo workspace precedente sul monitor attivo |
| `Super + Ctrl + Tab` | Vai allo workspace precedente sul monitor attivo |
| `Super + Shift + 1/2/3/4` | Sposta finestra nello workspace sul monitor attivo |
| `Super + Shift + Alt + 1/2/3/4` | Sposta finestra nello workspace sul monitor attivo senza seguirla |
| `Super + S` | Attiva/disattiva lo scratchpad completo |
| `Super + Alt + S` | Sposta finestra nello scratchpad completo |
| `Super + Grave` | Attiva/disattiva la console Quake |
| `Super + Shift + Grave` | Sposta finestra nella console Quake |
| `Super + Shift + Ctrl + Arrows` | Sposta finestra sul monitor in quella direzione |
| `Super + Shift + Alt + Arrows` | Sposta workspace sul monitor in quella direzione |
| `Super + Arrow`  | Sposta il focus sulla finestra nella direzione della freccia, passando al monitor su quel lato al bordo dello schermo |
| `Super + Shift + Arrow`  | Scambia finestra con un'altra nella direzione della freccia, inclusa una sul monitor su quel lato |
| `Super + Minus` | Espandi finestra a sinistra |
| `Super + Equal` | Riduci finestra a sinistra |
| `Super + Shift + Minus` | Riduci finestra in alto |
| `Super + Shift + Equal` | Espandi finestra in basso |
| `Super + Alt + Minus/Equal` | Stesso ridimensionamento a passi più piccoli |
| `Super + Ctrl + Minus/Equal` | Stesso ridimensionamento a passi più grandi |
| `Super + Alt + Home` | Salva larghezza della finestra |
| `Super + Home` | Ripristina larghezza della finestra salvata |
| `Super + Left Mouse` | Trascina la finestra |
| `Super + Right Mouse` | Ridimensiona finestra |
| `Super + Scroll Wheel` | Scorri tra gli workspace sul monitor attivo |
| `Super + G`               | Attiva/disattiva raggruppamento finestre      |
| `Super + Alt + G`               | Sposta finestra fuori dal raggruppamento      |
| `Super + Alt + Tab`               | Scorri tra le finestre nel raggruppamento      |
| `Super + Alt + Shift + Tab`               | Scorri all'indietro tra le finestre nel raggruppamento      |
| `Super + Alt + Scroll Wheel` | Scorri tra le finestre nel raggruppamento |
| `Super + Alt + 1/2/3/4/5`               | Vai alla finestra specifica nel raggruppamento      |
| `Super + Alt + Arrow`  | Sposta finestra nel raggruppamento nella direzione della freccia, inclusa una sul monitor su quel lato |
| `Super + Ctrl + Left/Right`  | Spostati tra le finestre dentro un gruppo tiling |
| `Super + Ctrl + Z` | Ingrandisci sullo schermo (ripeti per ingrandire di più) |
| `Super + Ctrl + Alt + Z` | Riduci completamente lo zoom dallo schermo |
| `Super + /` | Avanza tra le opzioni di ridimensionamento del monitor |
| `Super + Alt + /` | Torna indietro tra le opzioni di ridimensionamento del monitor |
| `Alt + Tab` | Scorri in avanti tra le finestre nello workspace attivo |
| `Alt + Shift + Tab` | Scorri all'indietro tra le finestre nello workspace attivo |
| `Ctrl + Alt + Tab`| Scorri il focus in avanti tra i monitor |
| `Ctrl + Alt + Shift + Tab`| Scorri il focus all'indietro tra i monitor |

## Appunti universali

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Super + C`           | Copia    |
| `Super + X`           | Taglia (non nel terminale)    |
| `Super + V`           | Incolla    |
| `Super + Ctrl + V`           | Gestore appunti    |

Di solito su Linux serve `Ctrl + Shift + C/V` per copiare e incollare nel terminale e `Ctrl + C/V` per farlo ovunque il resto. Queste scorciatoie universali per gli appunti di Omarchy funzionano ovunque.

## Cattura

| Scorciatoia              | Funzione                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Screenshot                      |
| `Super + Ctrl + Alt + C`            | Screenshot (stessa azione, per tastiere senza tasto Print Screen) |
| `Super + Ctrl + C` | Menu di cattura |
| `Alt + Print Screen`            | Registrazione schermo                     |
| `Super + Print Screen` | Selettore colore |
| `Super + Ctrl + Print Screen` | Estrazione testo negli appunti |
| `Super + Alt + [` | Rimpicciolisci l'overlay della webcam durante la registrazione |
| `Super + Alt + ]` | Ingrandisci l'overlay della webcam durante la registrazione |
| `Alt + Shift + L` | Copia l'URL corrente da webapp o Chromium |
| `Alt + Shift + D` | Scarica il video nella pagina corrente in `~/Videos` |
| `Super + Ctrl + X` | Avvia/interrompi dettatura (richiede _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | Dettatura push-to-talk (richiede Voxtype o Superwhisper) |

Con le registrazioni schermo, la scorciatoia chiede prima quale audio vuoi, poi avvia la registrazione. Premila di nuovo per interromperla. Vedi [screenshot e registrazione](12-screenshots-recording.md) per i dettagli.

Tutte le opzioni di cattura sono accessibili anche sotto _Trigger > Capture_ nel menu Omarchy (`Super + Space`).

## Stile

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Super + Ctrl + T` | Scegli un nuovo tema (anche `Super + Ctrl + Shift + Space`) |
| `Super + Ctrl + W` | Scegli lo sfondo del tema (anche `Super + Ctrl + Space`) |

Le immagini di sfondo extra si trovano in `~/.config/omarchy/backgrounds/<theme name>`. Disponibili anche tramite _Install > Style > Background_ nel menu Omarchy.

Tutte le opzioni di stile sono accessibili anche sotto _Style_ nel menu Omarchy (`Super + Space`).

## Tmux

Il tasto prefisso è `Ctrl + Space` (funziona anche `Ctrl + B`). Puoi cambiare queste combinazioni in `~/.config/tmux/tmux.conf`.

### Pannelli

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Prefix + v` | Dividi pannello a fianco (verticale) |
| `Prefix + h` | Dividi pannello sotto (orizzontale) |
| `Prefix + x` | Chiudi pannello |
| `Prefix + z` | Attiva/disattiva zoom pannello (schermo intero) |
| `Alt + Enter` | Dividi pannello sotto (senza prefisso) |
| `Alt + Shift + Enter` | Dividi pannello a fianco (senza prefisso) |
| `Alt + Escape` | Chiudi pannello (senza prefisso) |
| `Ctrl + Alt + Arrows` | Spostati tra i pannelli |
| `Ctrl + Alt + Shift + Arrows` | Ridimensiona i pannelli |

### Finestre

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Prefix + c` | Nuova finestra |
| `Prefix + k` | Chiudi finestra |
| `Prefix + r` | Rinomina finestra |
| `Alt + 1-9` | Vai alla finestra specifica |
| `Alt + Arrow Left/Right` | Spostati tra le finestre |
| `Alt + Shift + Arrow Left/Right` | Sposta finestra a sinistra/destra |

### Sessioni

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Prefix + C` | Nuova sessione |
| `Prefix + K` | Chiudi sessione |
| `Prefix + R` | Rinomina sessione |
| `Prefix + N` | Sessione successiva |
| `Prefix + P` | Sessione precedente |
| `Alt + Arrow Up/Down` | Spostati tra le sessioni |
| `Prefix + s` | Elenca sessioni |
| `Prefix + d` | Scollegati dalla sessione |

### Modalità copia (stile vi)

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Prefix + [` | Entra in modalità copia |
| `v` | Inizia selezione (in modalità copia) |
| `y` | Copia selezione (in modalità copia) |

### Generale

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Prefix + q` | Ricarica configurazione |
| `Prefix + ?` | Mostra combinazioni Tmux |
| `Prefix + :` | Prompt dei comandi |

### Funzioni di layout Tmux

Queste funzioni devono essere eseguite dentro una sessione Tmux.

| Comando | Funzione |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Crea layout di sviluppo con editor, AI e terminale |
| `tdlm <ai> [<second_ai>]` | Crea layout di sviluppo per sottodirectory |
| `tsl <count> <command>` | Crea layout swarm multi-pannello |
