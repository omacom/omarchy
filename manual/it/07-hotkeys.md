# Scorciatoie

Puoi vedere tutti i binding principali della tastiera con `Super + K` (i binding di Tmux con `Super + Alt + K` e quelli di Herdr con `Super + Ctrl + K`).

## Navigazione

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Super + Space`           | Menu di Omarchy (app e tutto il resto)    |
| `Super + Alt + Space` | Menu delle applicazioni |
| `Super + Escape` | Menu di sistema (sospensione, riavvio, ecc.)  |
| `Super + Ctrl + L` | Blocca il computer |
| `Super + W` o `Super + Q` | Chiudi la finestra             |
| `Ctrl + Alt + Del` | Chiudi tutte le finestre |
| `Super + T`               | Commuta la finestra tra tassellata/flottante             |
| `Super + J` | Commuta la posizione della finestra (orizzontale/verticale) |
| `Super + O`               | Commuta la finestra in "poppata", fissa e flottante |
| `Super + L`               | Commuta tra layout dwindle e scrolling |
| `Super + P`               | Commuta lo stile pseudo-finestra (naturale vs stretch) |
| `Super + F`                 | Vai a schermo intero              |
| `Super + Alt + F`                 | Vai a tutta larghezza              |
| `Super + Ctrl + F`                 | Schermo intero dentro la finestra              |
| `Super + 1/2/3/4`         | Salta a un workspace specifico     |
| `Super + Tab` | Vai al workspace successivo |
| `Super + Shift + Tab` | Vai al workspace precedente |
| `Super + Ctrl + Tab` | Torna al workspace usato prima |
| `Super + Shift + 1/2/3/4` | Sposta la finestra su un workspace |
| `Super + Shift + Alt + 1/2/3/4` | Sposta la finestra su un workspace senza seguirla |
| `Super + S` / `Super + Grave` | Attiva/disattiva lo scratchpad |
| `Super + Alt + S` / `Super + Shift + Grave` | Sposta la finestra sullo scratchpad |
| `Super + Shift + Alt + Arrows` | Sposta i workspace sul monitor nella direzione |
| `Super + Arrow`  | Sposta il focus sulla finestra nella direzione della freccia              |
| `Super + Shift + Arrow`  | Scambia la finestra con un'altra nella direzione della freccia     |
| `Super + Minus` | Espandi la finestra verso sinistra |
| `Super + Equal` | Riduci la finestra verso sinistra |
| `Super + Shift + Minus` | Riduci la finestra verso l'alto |
| `Super + Shift + Equal` | Espandi la finestra verso il basso |
| `Super + Alt + Minus/Equal` | Stesso ridimensionamento a passi più piccoli |
| `Super + Ctrl + Minus/Equal` | Stesso ridimensionamento a passi più grandi |
| `Super + Alt + Home` | Salva la larghezza della finestra |
| `Super + Home` | Ripristina la larghezza salvata della finestra |
| `Super + Left Mouse` | Trascina la finestra |
| `Super + Right Mouse` | Ridimensiona la finestra |
| `Super + Scroll Wheel` | Scorri tra i workspace |
| `Super + G`               | Attiva/disattiva il raggruppamento delle finestre      |
| `Super + Alt + G`               | Fai uscire la finestra dal gruppo      |
| `Super + Alt + Tab`               | Cicla tra le finestre del gruppo      |
| `Super + Alt + Shift + Tab`               | Cicla all'indietro tra le finestre del gruppo      |
| `Super + Alt + 1/2/3/4/5`               | Salta a una finestra specifica del gruppo      |
| `Super + Alt + Arrow`  | Sposta la finestra nel gruppo nella direzione della freccia  |
| `Super + Ctrl + Left/Right`  | Spostati tra le finestre dentro un gruppo tassellato |
| `Super + Ctrl + Z` | Zoom avanti sullo schermo (ripeti per ingrandire ancora) |
| `Super + Ctrl + Alt + Z` | Rimuovi completamente lo zoom dallo schermo |
| `Super + /` | Avanza tra le opzioni di scalatura del monitor |
| `Super + Alt + /` | Torna indietro tra le opzioni di scalatura del monitor |
| `Alt + Tab` | Cicla in avanti tra le finestre del workspace attivo |
| `Alt + Shift + Tab` | Cicla all'indietro tra le finestre del workspace attivo |
| `Ctrl + Alt + Tab`| Cicla il focus in avanti tra i monitor |
| `Ctrl + Alt + Shift + Tab`| Cicla il focus all'indietro tra i monitor |

## Appunti universali

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Super + C`           | Copia    |
| `Super + X`           | Taglia (non nel terminale)    |
| `Super + V`           | Incolla    |
| `Super + Ctrl + V`           | Gestore degli appunti    |

Di solito su Linux ti servono `Ctrl + Shift + C/V` per copiare e incollare nel terminale e `Ctrl + C/V` per farlo ovunque altrove. Queste scorciatoie unificate per gli appunti di Omarchy funzionano ovunque.

## Cattura

| Scorciatoia              | Funzione                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Menu di cattura (per tastiere senza tasto PrintScr) |
| `Print Screen`            | Screenshot                      |
| `Alt + Print Screen`            | Registrazione schermo                     |
| `Super + Print Screen` | Selettore di colore |
| `Super + Ctrl + Print Screen` | Estrazione del testo negli appunti |
| `Super + Alt + [` | Rimpicciolisci l'overlay della webcam durante la registrazione |
| `Super + Alt + ]` | Ingrandisci l'overlay della webcam durante la registrazione |
| `Alt + Shift + L` | Copia l'URL corrente dalla webapp o da Chromium |
| `Alt + Shift + D` | Scarica il video della pagina corrente in `~/Videos` |
| `Super + Ctrl + X` | Avvia/ferma la dettatura (richiede _Install > AI > Dictation_) |
| `F9` | Dettatura push-to-talk (richiede _Install > AI > Dictation_) |

Con le registrazioni dello schermo, la scorciatoia chiede prima quale audio vuoi, poi avvia la registrazione. Premila di nuovo per fermarla. Vedi [screenshot e registrazione](../12-screenshots-recording.md) per i dettagli.

Tutte le opzioni di cattura sono accessibili anche sotto _Trigger > Capture_ nel menu di Omarchy (`Super + Space`).

## Tmux

Il tasto prefix è `Ctrl + Space` (funziona anche `Ctrl + B`). Puoi modificare questi binding in `~/.config/tmux/tmux.conf`.

### Pannelli

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Prefix + v` | Dividi il pannello a fianco (verticale) |
| `Prefix + h` | Dividi il pannello sotto (orizzontale) |
| `Prefix + x` | Chiudi il pannello |
| `Prefix + z` | Attiva/disattiva lo zoom del pannello (schermo intero) |
| `Alt + Enter` | Dividi il pannello sotto (senza prefix) |
| `Alt + Shift + Enter` | Dividi il pannello a fianco (senza prefix) |
| `Alt + Escape` | Chiudi il pannello (senza prefix) |
| `Ctrl + Alt + Arrows` | Spostati tra i pannelli |
| `Ctrl + Alt + Shift + Arrows` | Ridimensiona i pannelli |

### Finestre

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Prefix + c` | Nuova finestra |
| `Prefix + k` | Chiudi la finestra |
| `Prefix + r` | Rinomina la finestra |
| `Alt + 1-9` | Vai a una finestra specifica |
| `Alt + Arrow Left/Right` | Spostati tra le finestre |
| `Alt + Shift + Arrow Left/Right` | Sposta la finestra a sinistra/destra |

### Sessioni

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Prefix + C` | Nuova sessione |
| `Prefix + K` | Chiudi la sessione |
| `Prefix + R` | Rinomina la sessione |
| `Prefix + N` | Sessione successiva |
| `Prefix + P` | Sessione precedente |
| `Alt + Arrow Up/Down` | Spostati tra le sessioni |
| `Prefix + s` | Elenca le sessioni |
| `Prefix + d` | Staccati dalla sessione |

### Modalità copia (stile vi)

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Prefix + [` | Entra nella modalità copia |
| `v` | Inizia la selezione (in modalità copia) |
| `y` | Copia la selezione (in modalità copia) |

### Generale

| Scorciatoia                  | Funzione              |
| ----------------------- | --------------------- |
| `Prefix + q` | Ricarica la configurazione |
| `Prefix + ?` | Mostra le scorciatoie di Tmux |
| `Prefix + :` | Prompt dei comandi |

### Funzioni di layout di Tmux

Queste funzioni vanno eseguite dentro una sessione Tmux.

| Comando | Funzione |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Crea un layout di sviluppo con editor, AI e terminale |
| `tdlm <ai> [<second_ai>]` | Crea un layout di sviluppo per ogni sottodirectory |
| `tsl <count> <command>` | Crea un layout a sciame multi-pannello |
