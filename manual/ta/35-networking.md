# வலையமைப்பு

Omarchy இல் வலையமைப்பை NetworkManager கையாள்கிறது, அதை நீங்கள் [மேல் பட்டியில்](05-the-top-bar.md) உள்ள நெட்வொர்க் ஐகானிலிருந்தோ அல்லது `Super + Ctrl + N` மூலமோ இயக்கலாம்.

அந்தப் பலகம் Wi-Fi நெட்வொர்க்குகளைத் தேடி, சிக்னல் வலிமையைக் காட்டி, இணைக்கிறது. Ethernet க்கு எதுவுமே தேவையில்லை — செருகினால் போதும், அது வேலை செய்யும். நீங்கள் டெர்மினலிலேயே இருக்க விரும்பினால், `nmtui` அதே கட்டுப்பாடுகளைத் தருகிறது, அதோடு `omarchy network` கட்டளைக் குழுவும் உள்ளது.

## உங்கள் Wi-Fi ஐப் பகிர்தல்

நீண்ட கடவுச்சொல்லைச் சத்தமாகப் படிப்பதற்குப் பதிலாக, நீங்கள் Wi-Fi இல் இருக்கும்போது _Setup > Network > QR Code_ ஐ இயக்குங்கள். அது திரையில் ஒரு QR code ஐக் காட்டும், எந்த ஃபோன் கேமராவும் அதை ஸ்கேன் செய்து இணைய முடியும். அது இருப்பது தெரிந்த பிறகு, நீங்கள் எதிர்பார்ப்பதை விட அதிகமாகப் பயன்படுத்தும் விஷயங்களில் இதுவும் ஒன்று.

உங்களுக்கு உண்மையிலேயே கடவுச்சொல் தான் தேவை என்றால், `omarchy network password <interface>` அதை அச்சிடும்.

## DNS

Omarchy உங்கள் நெட்வொர்க் DHCP வழியாக வழங்கும் DNS ஐயே பயன்படுத்துகிறது. _Setup > Network > DNS_ இன் கீழ் முழு இயந்திரத்திற்கும் அதை மாற்றியமைக்கலாம், அங்கு Cloudflare மற்றும் Google ஒரே கிளிக் தொலைவில் உள்ளன. உங்கள் சொந்த சர்வர்களைத் தட்டச்சு செய்ய _Custom_ ஐத் தேர்ந்தெடுக்கவும்.

டெர்மினலில் இருந்து, `omarchy dns` தற்போதைய வழங்குநரை அச்சிடும், `omarchy dns Cloudflare` ஒன்றை அமைக்கும்.

## Wi-Fi பேண்டை நிலைநிறுத்துதல்

உங்கள் ரௌட்டர் 2.4GHz, 5GHz, மற்றும் 6GHz ஐ ஒரே நெட்வொர்க் பெயரில் வைத்தால், உங்கள் லேப்டாப் சில நேரங்களில் மெதுவான ஒன்றையே பிடித்துக் கொண்டிருக்கும். `omarchy network band` நீங்கள் எந்த பேண்டில் இருக்கிறீர்கள் என்பதைக் காட்டும், `omarchy network band 5` அதை நிலைநிறுத்தும். அது மீண்டும் தானே தேர்ந்தெடுக்க `auto` ஐப் பயன்படுத்தவும்.

இது ஒரு குறிப்பிட்ட அணுகல் புள்ளியை அல்ல, பேண்டை நிலைநிறுத்துகிறது, எனவே நீங்கள் APகளுக்கு இடையே வழக்கம் போலவே சுற்றித் திரியலாம்.

## இது எவ்வளவு வேகமானது?

_Trigger > Speed Test > Network Speed Test_ ஒரு ஜோடி டயல்கள் மூலம் உங்கள் உண்மையான அப் மற்றும் டவுன் வேகத்தை அளவிடுகிறது. டெர்மினலில் இருந்து இது `omarchy network speedtest down` அல்லது `up`. இது Omarchy இன் சொந்த சேவைக்கு எதிராக அளவிடுகிறது மற்றும் அதன் சோதனைப் பரிமாற்றங்களை மட்டுமே கணக்கிடுகிறது. பிற பதிவிறக்கங்கள் பேண்ட்விட்த்துக்காகப் போட்டியிடலாம், ஆனால் அவை வேகச் சோதனை முடிவில் சேர்க்கப்படாது. (நீங்கள் மற்ற தடையை பெஞ்ச்மார்க் செய்கிறீர்கள் என்றால், அந்த மெனுவில் அதற்கு அடுத்ததாகவே ஒரு டிஸ்க் வேகச் சோதனையும் அமர்ந்திருக்கிறது.)

## ஃபயர்வால்

ஃபயர்வால் இயல்பாகவே இயக்கத்தில் இருக்கும் மற்றும் உள்வரும் அனைத்து டிராஃபிக்கையும் தடுக்கும், ஒரே ஒரு விதிவிலக்குடன்: போர்ட் 53317, எனவே [LocalSend](22-guis.md) தொடக்கத்திலிருந்தே வேலை செய்யும்.

_Setup > Security > SSHD_ மூலம் நீங்கள் அதை இயக்கும் வரை SSH அணைக்கப்பட்டிருக்கும், அது டீமனைத் தொடங்கி, brute force க்கு எதிராக வீத வரம்புடன் போர்ட் 22 ஐத் திறந்து, ஒரு விசையை அங்கீகரிக்கிறது. Docker உம் பூட்டப்பட்டுள்ளது, எனவே கண்டெய்னர்கள் தற்செயலாகத் தங்களை உலகிற்கு வெளிப்படுத்திக் கொள்ள முடியாது. முழுக் கதைக்கும் [பாதுகாப்பைப்](48-security.md) பார்க்கவும்.

## Tailscale

[Tailscale](https://tailscale.com/) என்பது இணையம் வழியாக உங்கள் அனைத்து கணினிகளையும் சர்வர்களையும் அடைவதை எளிமையாகவும் பாதுகாப்பாகவும் மாற்றும் ஒரு மெஷ் VPN ஆகும். _Install > Service > Tailscale_ மூலம் அதை நிறுவவும்.

அது உங்களுக்கு பட்டியில் ஒரு Tailscale பலகத்தைத் தருகிறது, அது டெயில்நெட்டை இணைத்துத் துண்டிக்கிறது, கணக்குகளை மாற்றுகிறது, மற்றும் ஒரு எக்ஸிட் நோடைத் தேர்ந்தெடுக்கிறது — உங்கள் சொந்த இயந்திரங்களும் Mullvad பகுதிகளும் பட்டியலில் தோன்றும். அது உங்கள் இயந்திரங்களையும் உலாவுகிறது, Taildrop வாழ்வது அங்குதான்: ஒரு இயந்திரத்தைத் தேர்ந்தெடுத்து அதற்குக் கோப்புகளை அனுப்ப `s` ஐ அழுத்தவும், அல்லது அதன் IP, பெயர், அல்லது முழு DNS பெயரை நகலெடுக்க `c`, `n`, மற்றும் `d` ஐ அழுத்தவும். டெர்மினலில் இதற்குச் சமமானது `omarchy tailscale send <machine> [file...]`, மற்றும் உங்களுக்கு அனுப்பப்படும் கோப்புகள் தானாகவே `~/Downloads` இல் வந்து சேரும். வருகையை அறிவிக்கும் அறிவிப்பு, நீங்கள் அதைக் கிளிக் செய்து திறக்கும் வரை அல்லது நிராகரிக்கும் வரை காத்திருக்கும், எனவே நீங்கள் இயந்திரத்திலிருந்து விலகி இருக்கும்போது ஒரு கோப்பு வந்தால், நீங்கள் திரும்பி வரும்போது பதிலளிக்க அது இன்னும் அங்கேயே இருக்கும்.

அதை நிறுவுவது Tailscale நிர்வாக கன்சோலுக்கான ஒரு வலை செயலியையும் சேர்க்கிறது.

## அது வேலை செய்வதை நிறுத்தும்போது

மறுதொடக்கம் செய்வதற்கு முன், சிக்கலான பகுதியை மட்டும் தனியாக மறுதொடக்கம் செய்து பாருங்கள். _Update > Hardware_ இல் Wi-Fi, Bluetooth, Audio, மற்றும் Trackpad உள்ளன, அவற்றில் ஒன்றை மீண்டும் ஏற்றுவது பெரும்பாலான \"ஐந்து நிமிடங்களுக்கு முன்பு வேலை செய்ததே\" சூழ்நிலைகளைச் சரிசெய்துவிடும். [சரிசெய்தலைப்](45-troubleshooting.md) பார்க்கவும்.
