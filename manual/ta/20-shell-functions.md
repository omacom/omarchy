# Shell செயல்பாடுகள்

பொதுவான பணிகளை எளிதாக்கவும் சிக்கலான அளவுரு அழைப்புகளை உறைபனி செய்யவும் Omarchy ஒரு தொகுப்பு shell செயல்பாடுகளுடன் வருகிறது.

## சுருக்கம்

- `compress [file/dir]`: கோப்பு/கோப்பகத்திலிருந்து tar.gz காப்பகத்தை உருவாக்கவும்.
- `decompress [file.tar.gz]`: tar.gz கோப்பை விரிக்கவும்.

## இயக்ககங்கள்

- `iso2sd [image.iso]`: குறிப்பிடப்பட்ட iso கோப்பைப் பயன்படுத்தி, இயக்ககத்தை ஊடாடும் வகையில் தேர்ந்தெடுத்து SD அட்டையில் துவக்கக்கூடிய இயக்ககத்தை உருவாக்கவும்.
- `format-drive [device] [name]`: முழு வட்டையும் ஒற்றை exFAT பகிர்வுடன் வடிவமைக்கவும் (இது Windows மற்றும் macOS இலும் வேலை செய்கிறது). கிடைக்கக்கூடிய இயக்ககங்களைப் பார்க்க அளவுருக்கள் இல்லாமல் இயக்கவும். கவனமாக இருங்கள்!

## மேம்பாட்டு அமைப்புகள்

tmux க்கான உடனடி பல பலக மேம்பாட்டு அமைப்புகள்:

- `tdl [ai]`: உங்கள் திருத்தி, ஒரு AI agent மற்றும் ஒரு முனையத்துடன் Tmux Dev Layout ஐ உருவாக்கவும். opencode க்கு `tdl c` அல்லது Claude Code க்கு `tdl cx` போன்ற agent மாற்றுப்பெயர்களைப் பயன்படுத்தவும், அல்லது இரண்டையும் இயக்க இரண்டாவது agent ஐ அனுப்பவும், எடுத்துக்காட்டாக `tdl c cx`.
- `tds`: திருத்தி, வேறுபாடு கண்காணிப்பு (`hunk diff --watch` வழியாக), முனையம் மற்றும் opencode உடன் Tmux Dev Square ஐ உருவாக்கவும்.
- `tdlm [ai]`: தற்போதைய கோப்பகத்தில் உள்ள ஒவ்வொரு துணைக்கோப்பகத்திற்கும் ஒரு `tdl` சாளரத்தை உருவாக்கவும்.
- `tsl [count] [command]`: அனைத்தும் ஒரே கட்டளையை இயக்கும் வகையில் கட்டத்தில் அடுக்கப்பட்ட பலகங்களின் கூட்டத்தை உருவாக்கவும் (AI agent களுக்குச் சிறந்தது).

அதே அமைப்புகள் Herdr க்கு `hdl`, `hds`, `hdlm` மற்றும் `hsl` என்று கிடைக்கின்றன.

## Git worktree கள்

- `ga [branch]`: தற்போதைய களஞ்சியத்திற்கு அருகில் ஒரு புதிய worktree மற்றும் கிளையை உருவாக்கி அதில் தாவவும்.
- `gd`: தற்போதைய worktree மற்றும் அதன் கிளையை அகற்றவும் (முதலில் உறுதிப்படுத்தல் கேட்கும்).

## Rsync கண்காணிப்பாளர்கள்

- `rsw [source] [destination]`: ஏதாவது மாறும்போதெல்லாம் மூலத்திலிருந்து இலக்கிற்கு rsync செய்யும் பின்னணி கண்காணிப்பாளரைத் தொடங்கவும். இலக்கு ஒரு தொலைநிலை ஹோஸ்ட்டாக இருக்கலாம், எடுத்துக்காட்டாக `rsw ~/Work/app nyc-dev:Work/app`.
- `lsw`: அனைத்து செயலில் உள்ள கண்காணிப்பாளர்களையும் பட்டியலிடவும்.
- `dsw`: அனைத்து செயலில் உள்ள கண்காணிப்பாளர்களையும் நிறுத்தவும்.

## SSH போர்ட் பகிர்தல்

தொலைநிலைப் பெட்டிக்கு எதிராக localhost பாதுகாப்பான சூழல் சலுகைகளுடன் வலை மேம்பாடு செய்ய ஏற்றது.

- `fip`: SSH வழியாக ஒரு தொலைநிலை ஹோஸ்ட்டிலிருந்து localhost க்கு ஒன்று அல்லது அதற்கு மேற்பட்ட போர்ட்களை அனுப்பவும்.
- `dip`: அனுப்பப்பட்ட ஒன்று அல்லது அதற்கு மேற்பட்ட போர்ட்களைத் துண்டிக்கவும்.
- `lip`: அனைத்து செயலில் உள்ள SSH போர்ட் பகிர்தல்களையும் பட்டியலிடவும்.

`nyc-dev` என்று அணுகக்கூடிய இயந்திரத்தில் போர்ட் `3000` இல் ஒரு dev சேவையகத்தைத் தொடங்குகிறீர்கள் என்று வைத்துக் கொள்வோம், பின்னர் அந்தப் போர்ட்டை அனுப்ப `fip nyc-dev 3000` என்று இயக்கலாம், எனவே `localhost:3000` உண்மையில் `nyc-dev:3000` ஐ அடைகிறது, ஆனால் web socket களையோ அது போன்றவற்றையோ சோதிக்கத் தேவையான பாதுகாப்பான சூழலை நிறுவ SSL சான்றிதழ்கள் தேவையில்லாமல்.

## SSH மறு இணைப்பு

`ssh` தானே ஒரு செயல்பாட்டில் மூடப்பட்டுள்ளது, இது ஒரு தொலைநிலை tmux, Herdr அல்லது திருத்தி முனையத்தைக் கோரியிருக்கும்போது இணைப்பு இறந்தால் முனையத்தைச் சுத்தம் செய்கிறது, பின்னர் ஒரு ஊடாடும் அமர்வு துண்டிக்கப்படும்போது தானாகவே மீண்டும் இணைகிறது (Ctrl-C மறுமுயற்சி வளையத்தை நிறுத்துகிறது).
