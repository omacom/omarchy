# உலாவிகள்

Omarchy இயல்புநிலை உலாவியாக [Chromium](https://www.chromium.org/) உடன் வருகிறது. இது எளிய திறந்த மூலக் கட்டமைப்பு, உங்கள் கணினியின் மீதமுள்ள பகுதிகளுடன் பொருந்தும் வகையில் தீம் செய்யப்பட்டது, மேலும் இதுதான் `Super + Shift + Return` திறப்பதும், ஒவ்வொரு [வலைச் செயலியும்](25-web-apps.md) இதற்குள் இயங்குவதும் ஆகும்.

Chromium உங்கள் விருப்பம் இல்லை என்றால், நீங்கள் அதில் சிக்கிக் கொள்ளவில்லை. Omarchy மெனுவில் _நிறுவு > Browser_ க்குக் கீழ் Chrome, Edge, Brave, Brave Origin, Firefox மற்றும் [Zen](https://zen-browser.app/) ஆகியவற்றைக் காண்பீர்கள். ஒன்றைத் தேர்ந்தெடுத்தால் Omarchy அதை நிறுவி, அதன் கொள்கைக் கோப்பகத்தை அமைத்து, உங்கள் தற்போதைய தீமை அதில் பயன்படுத்தும்.

## ஒன்றை இயல்புநிலையாக்குதல்

ஒரு உலாவியை நிறுவுவது அதை உயர்த்தாது. அது இயந்திரத்தில் வந்ததும், _அமைப்பு > இயல்புநிலைகள் > Browser_ க்குச் சென்று அதைத் தேர்ந்தெடுக்கவும் — மெனு நீங்கள் உண்மையில் நிறுவிய உலாவிகளை மட்டுமே பட்டியலிடுகிறது, மேலும் தற்போதைய இயல்புநிலையைச் சரிபார்ப்புக் குறியுடன் குறிக்கிறது.

முனையத்தில் இருந்து:

```bash
omarchy default browser firefox
```

அளவுரு இல்லாமல் அதை இயக்கினால் தற்போதைய இயல்புநிலையைச் சொல்லும். இது XDG handler ஐ அமைக்கிறது, எனவே Omarchy இன் hotkey கள் மட்டுமல்ல பின்பற்றுவது — அரட்டைச் செயலியிலிருந்து முனையக் கட்டளை வரை, இணைப்பைத் திறக்கும் எதுவும் நீங்கள் தேர்ந்தெடுத்த உலாவிக்குச் செல்லும்.

## URL ஐ நகலெடு மற்றும் வீடியோவைப் பதிவிறக்கு

Chromium குடும்ப உலாவிகள் (Chromium தானே, Chrome, Edge மற்றும் Brave) உலாவிக்கு வெளியே சென்று உங்கள் கணினியின் மீதமுள்ள பகுதிகளை அடையும் இரண்டு Omarchy நீட்டிப்புகளுடன் வருகின்றன.

**Copy URL** தற்போதைய தாவலின் முகவரியை `Alt + Shift + L` உடன் உங்கள் கிளிப்போர்டில் வைக்கிறது. முகவரிப் பட்டையில் கிளிக் செய்து நகலெடுப்பதை விட இது வேகமானது, மேலும் இது உலாவியின் கிளிப்போர்டுக்குப் பதிலாகக் கணினி கிளிப்போர்டு வழியாகச் செல்வதால், அதை உறுதிப்படுத்தும் Omarchy அறிவிப்பைப் பெறுவீர்கள், URL உடனடியாக [கிளிப்போர்டு வரலாறு](08-unified-clipboard-history.md) மற்றும் மற்ற ஒவ்வொரு செயலியிலும் கிடைக்கும். கிளிக் செய்ய விரும்பினால் கருவிப்பட்டை பொத்தானும் உள்ளது.

**Download Video** நீங்கள் பார்த்துக் கொண்டிருக்கும் பக்கத்தில் இயங்கும் வீடியோவை `Alt + Shift + D` உடன் பெறுகிறது. இது URL ஐ [yt-dlp](https://github.com/yt-dlp/yt-dlp) க்கு அனுப்புகிறது, எனவே இது YouTube ஐ விட அதிகமாக வேலை செய்கிறது, மேலும் பதிவிறக்கம் `~/Videos` இல் வரும். ஒலியளவும் பிரகாசமும் பயன்படுத்தும் அதே திரைக் காட்சியில் முன்னேற்றம் தோன்றும், அறிவிப்புகளை அடுக்குவதற்குப் பதிலாக இடத்திலேயே புதுப்பிக்கப்படும். கோப்புகள் வேறு எங்காவது செல்ல வேண்டுமென்றால் `OMARCHY_YTDLP_DIR` ஐ அமைக்கவும் — சூழல் மாறிகளை எங்கு வைப்பது என்பதற்கு [FAQ](46-faq.md) ஐப் பார்க்கவும்.

இரண்டு நீட்டிப்புகளும் ஒரு சிறிய native messaging host வழியாக Omarchy உடன் பேசுகின்றன, இது உலாவியுடன் உங்களுக்காக நிறுவப்படுகிறது. வலைப் பக்கத்தின் வீடியோ உங்கள் வீட்டுக் கோப்பகத்தில் முடிவடையவும், URL உங்கள் கிளிப்போர்டு மேலாளரில் முடிவடையவும் உதவும் பகுதி அதுதான், இதை ஒரு சாதாரண நீட்டிப்பு தனியாகச் செய்ய முடியாது.

இவை Chromium குடும்பத்திற்கு மட்டுமே. Firefox மற்றும் Zen க்கு இவை கிடைக்காது.

## Firefox மற்றும் Zen

Firefox மற்றும் Zen வேறு குடும்பம், எனவே அவை வேறு சிகிச்சையைப் பெறுகின்றன: Omarchy புத்திசாலித்தனமான இயல்புநிலைகளுக்காக ஒரு கொள்கைக் கோப்பை நிறுவி அவற்றை native Wayland பயன்முறைக்கு மாற்றுகிறது, இது fractional scaling மற்றும் மென்மையான trackpad உருட்டலுக்கு நீங்கள் விரும்புவது.

அவற்றுக்கு மேலே உள்ள Chromium நீட்டிப்புகள் கிடைக்காது, மேலும் அவை Omarchy ஆல் தீம் செய்யப்படுவதில்லை, எனவே அனுபவத்தின் அந்தப் பகுதிகள் நீங்கள் அமைக்க வேண்டியவை.

## ஒன்றை மீண்டும் அகற்றுதல்

இங்கு நீங்கள் நிறுவிய எதையும் _நீக்கு > Browser_ க்குக் கீழ் அகற்றலாம். Chromium அந்தப் பட்டியலில் இல்லை — இது அடிப்படைக் கணினியின் பகுதி.
