# உலாவிகள்

Omarchy, இயல்புநிலை உலாவியாக [Google Chrome](https://www.google.com/chrome/) உடன் வருகிறது. இது உங்கள் கணினியின் மற்ற பகுதிகளுடன் பொருந்தும் வகையில் தீம் செய்யப்பட்டுள்ளது, மேலும் `Super + Shift + Return` (அல்லது `Super + Shift + B`) திறப்பது இதைத்தான், `Super + Shift + Alt + B` ஒரு தனிப்பட்ட சாளரத்திற்கானது, மேலும் ஒவ்வொரு [இணையப் பயன்பாடும்](25-web-apps.md) இதற்குள்ளேயே இயங்குகிறது. இது நேரடியாக ஒரு உலாவி சாளரத்திற்குத் திறக்கிறது: வரவேற்புத் திரையோ உள்நுழைவு அறிவுறுத்தலோ இல்லை, பயன்பாட்டுப் புள்ளிவிவரங்களும் செயலிழப்பு அறிக்கைகளும் Google க்கு அனுப்பப்படுவதில்லை, விளம்பரத் தனியுரிமை அறிவுறுத்தல்கள் முடக்கப்பட்டுள்ளன. ஒத்திசைவு வேண்டுமென்றால், சுயவிவரப் பொத்தானிலிருந்து எப்போது வேண்டுமானாலும் உங்கள் Google கணக்கில் உள்நுழையலாம்.

Chrome உங்கள் விருப்பத்திற்கு ஏற்றதாக இல்லாவிட்டால், அதிலேயே நீங்கள் சிக்கிக்கொள்ள வேண்டியதில்லை. Omarchy மெனுவில் _Install > Browser_ இன் கீழ் [Chromium](https://www.chromium.org/) (Chrome உருவாக்கப்பட்டுள்ள எளிய திறந்த மூலப் பதிப்பு), Edge, Brave, Brave Origin, Firefox, [Zen](https://zen-browser.app/), மற்றும் [Ladybird](https://ladybird.org/) ஆகியவற்றைக் காண்பீர்கள் (Edge x86 கணினிகளில் மட்டும்). ஒன்றைத் தேர்ந்தெடுங்கள், Omarchy அதை நிறுவி, அதன் கொள்கை அடைவை அமைத்து, உங்கள் தற்போதைய தீமை அதற்குப் பயன்படுத்தும்.

## ஒன்றை இயல்புநிலையாக்குதல்

ஒரு உலாவியை நிறுவுவது அதை இயல்புநிலையாக உயர்த்திவிடாது. மாற்றுவதற்கு, _Setup > Defaults > Browser_ க்குச் சென்று ஒன்றைத் தேர்ந்தெடுங்கள். தற்போதைய இயல்புநிலை ஒரு சரிக்குறியால் குறிக்கப்பட்டிருக்கும், மேலும் உங்களிடம் இன்னும் இல்லாத ஒரு உலாவியைத் தேர்ந்தெடுத்தால் அது முதலில் நிறுவப்படும்.

முனையத்திலிருந்து இது:

```bash
omarchy default browser firefox
```

எந்த வாதமும் இல்லாமல் இதை இயக்கினால், தற்போதைய இயல்புநிலையை அது உங்களுக்குத் தெரிவிக்கும். இது XDG கையாளியை அமைக்கிறது, எனவே Omarchy இன் விசைப்பலகை குறுக்குவழிகள் மட்டும் இதைப் பின்பற்றாது — ஒரு அரட்டைப் பயன்பாடு முதல் ஒரு முனையக் கட்டளை வரை, ஒரு இணைப்பைத் திறக்கும் எதுவும் நீங்கள் தேர்ந்தெடுத்த உலாவிக்கே செல்லும்.

## URL ஐ நகலெடு மற்றும் வீடியோவைப் பதிவிறக்கு

Chromium குடும்ப உலாவிகள் (Chromium தானே, Chrome, Edge, Brave, மற்றும் Brave Origin) மூன்று Omarchy நீட்டிப்புகளுடன் வருகின்றன: இரண்டு உலாவியிலிருந்து வெளியே, உங்கள் கணினியின் மற்ற பகுதிகளை அடைகின்றன, ஒன்று WhatsApp ஐ ஒழுங்குபடுத்துகிறது.

**Copy URL** தற்போதைய தாவலின் முகவரியை `Alt + Shift + L` மூலம் உங்கள் கிளிப்போர்டில் வைக்கிறது. முகவரிப் பட்டியில் சொடுக்கி நகலெடுப்பதை விட இது வேகமானது, மேலும் இது உலாவியின் கிளிப்போர்டு வழியாக அல்லாமல் கணினி கிளிப்போர்டு வழியாகச் செல்வதால், அதை உறுதிப்படுத்தும் ஒரு Omarchy அறிவிப்பைப் பெறுவீர்கள், மேலும் URL உடனடியாக [கிளிப்போர்டு வரலாற்றிலும்](08-unified-clipboard-history.md) மற்ற ஒவ்வொரு பயன்பாட்டிலும் கிடைக்கும். சொடுக்குவதை விரும்பினால், ஒரு கருவிப்பட்டி பொத்தானும் உள்ளது.

**Download Video** நீங்கள் பார்த்துக்கொண்டிருக்கும் பக்கத்தில் இயங்கும் வீடியோவை `Alt + Shift + D` மூலம் எடுக்கிறது. இது URL ஐ [yt-dlp](https://github.com/yt-dlp/yt-dlp) இடம் ஒப்படைக்கிறது, எனவே இது YouTube ஐ விட மிக அதிகமானவற்றில் செயல்படுகிறது, மேலும் பதிவிறக்கம் `~/Videos` இல் வந்து சேர்கிறது. முன்னேற்றம், ஒலியளவும் திரை ஒளியும் பயன்படுத்தும் அதே திரைக் காட்சியில் தோன்றுகிறது, அறிவிப்புகளை அடுக்கிக்கொண்டே போகாமல் அதே இடத்தில் புதுப்பிக்கப்படுகிறது. கோப்புகள் வேறு எங்காவது செல்ல வேண்டுமென்றால் `OMARCHY_YTDLP_DIR` ஐ அமையுங்கள் — சூழல் மாறிகளை எங்கே வைப்பது என்பதற்கு [FAQ](46-faq.md) ஐப் பாருங்கள்.

இரண்டு நீட்டிப்புகளும் ஒரு சிறிய நேட்டிவ் செய்தியனுப்பும் ஹோஸ்ட் வழியாக Omarchy உடன் பேசுகின்றன, அது உலாவியுடன் சேர்த்து உங்களுக்காக நிறுவப்படுகிறது. ஒரு இணையப் பக்கத்தின் வீடியோ உங்கள் முகப்பு அடைவில் வந்து சேரவும், ஒரு URL உங்கள் கிளிப்போர்டு மேலாளரில் வந்து சேரவும் அனுமதிக்கும் பகுதி அதுதான், இதை ஒரு சாதாரண நீட்டிப்பால் தனியாகச் செய்ய முடியாது.

**WhatsApp Slim** WhatsApp Web ஐ உங்கள் கணினி தீமைப் பின்பற்றச் செய்கிறது, மேலும் சாளரம் குறுகலாக இருக்கும்போது அதன் அரட்டைப் பட்டியலைச் சுருக்குகிறது.

இவை Chromium குடும்பத்திற்கு மட்டுமே. Firefox க்கும் Zen க்கும் இவை கிடைக்காது.

## Firefox மற்றும் Zen

Firefox மற்றும் Zen ஒரு வேறு குடும்பம், எனவே அவற்றுக்கு வேறுபட்ட அணுகுமுறை கிடைக்கிறது: Omarchy, sensible இயல்புநிலைகளுக்காக ஒரு கொள்கைகள் கோப்பை நிறுவி, அவற்றை நேட்டிவ் Wayland பயன்முறைக்கு மாற்றுகிறது, பின்ன அளவிடுதலுக்கும் மென்மையான டிராக்பேடு உருட்டலுக்கும் நீங்கள் விரும்புவது அதுதான்.

மேலே உள்ள Chromium நீட்டிப்புகள் அவற்றுக்குக் கிடைக்காது, மேலும் அவை Omarchy ஆல் தீம் செய்யப்படுவதில்லை, எனவே அனுபவத்தின் அந்தப் பகுதிகளை அமைப்பது உங்கள் பொறுப்பு.

## Ladybird

Ladybird என்பது புதிதாக எழுதப்பட்ட ஒரு உலாவி, Chromium இன் அல்லது Firefox இன் எஞ்சினுக்குப் பதிலாக அதற்கெனத் தனி எஞ்சினைக் கொண்டது. இது இன்னும் ஆல்ஃபாவில் உள்ளது, எனவே இன்னும் செயல்படாத தளங்களை எதிர்பாருங்கள், மேலும் Omarchy அதை வருவது போலவே நிறுவுகிறது: நீட்டிப்புகள் இல்லை, தீம் இல்லை, கொள்கைகள் இல்லை. அதற்குத் தனிப்பட்ட சாளரமும் இல்லை, எனவே `Super + Shift + Alt + B` அதை ஒரு தற்காலிக சுயவிவரத்துடன் திறக்கிறது, நீங்கள் அதை மூடும்போது அது நீக்கப்படும். [இணையப் பயன்பாடுகள்](25-web-apps.md) Chrome அல்லது Chromium இல் தொடர்ந்து இயங்குகின்றன.

## ஒன்றை மீண்டும் நீக்குதல்

Chrome உட்பட இந்த உலாவிகளில் எதையும் _Remove > Browser_ இன் கீழ் மீண்டும் நீக்கலாம். மற்றொன்று இன்னும் நிறுவப்பட்டிருந்தால், இணைப்புகள் பின்னர் Chrome க்கு அல்லது Chromium க்குச் செல்லும்.
