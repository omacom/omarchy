# உலாவிகள்

Omarchy [Google Chrome](https://www.google.com/chrome/) ஐ இயல்புநிலை உலாவியாகக் கொண்டு வருகிறது. இது உங்கள் கணினியின் மற்ற பகுதிகளுடன் பொருந்தும் வகையில் தீம் செய்யப்பட்டுள்ளது, மேலும் இதைத்தான் `Super + Shift + Return` திறக்கிறது, இதற்குள்தான் ஒவ்வொரு [இணையச் செயலியும்](25-web-apps.md) இயங்குகிறது. இது நேரடியாக உலாவி சாளரத்திலேயே திறக்கும்: வரவேற்புத் திரையோ உள்நుழைவுக் கோரிக்கையோ இல்லை, பயன்பாட்டுப் புள்ளிவிவரங்களும் செயலிழப்பு அறிக்கைகளும் Google-க்கு அனுப்பப்படுவதில்லை, விளம்பரத் தனியுரிமைக் கோரிக்கைகள் அணைக்கப்பட்டுள்ளன. ஒத்திசைவு வேண்டுமென்றால் எப்போது வேண்டுமானாலும் சுயவிவரப் பொத்தானிலிருந்து உங்கள் Google கணக்கில் உள்நுழையலாம்.

Chrome உங்கள் விருப்பமாக இல்லையென்றால், அதிலேயே சிக்கிக் கொள்ள வேண்டியதில்லை. Omarchy மெனுவில் _நிறுவு > உலாவி_ என்பதன் கீழ் [Chromium](https://www.chromium.org/) (Chrome உருவாக்கப்பட்ட சாதாரண திறந்த மூலப் பதிப்பு), Edge, Brave, Brave Origin, Firefox மற்றும் [Zen](https://zen-browser.app/) ஆகியவற்றைக் காண்பீர்கள். ஒன்றைத் தேர்ந்தெடுங்கள், Omarchy அதை நிறுவும், அதற்கான கொள்கை அடைவை அமைக்கும், உங்கள் தற்போதைய தீமை அதற்குப் பொருத்தும்.

## ஒன்றை இயல்புநிலையாக்குதல்

ஒரு உலாவியை நிறுவுவது அதை மேல்நிலைக்கு உயர்த்தாது. அது கணினியில் வந்ததும், _அமைப்பு > இயல்புநிலைகள் > உலாவி_ என்பதற்குச் சென்று அதைத் தேர்ந்தெடுங்கள் — நீங்கள் உண்மையில் நிறுவியுள்ள உலாவிகளை மட்டுமே மெனு பட்டியலிடும், தற்போதைய இயல்புநிலையை ஒரு சரி குறியால் குறிக்கும்.

முனையத்திலிருந்து இப்படிச் செய்யலாம்:

```bash
omarchy default browser firefox
```

எந்த வாதமும் இல்லாமல் இதை இயக்கினால் தற்போதைய இயல்புநிலை எது என்று சொல்லும். இது XDG கையாளுநரை அமைக்கிறது, எனவே Omarchy-இன் விசைப்பலகைக் குறுக்குவழிகள் மட்டும் இதைப் பின்பற்றாது — அரட்டைச் செயலியிலிருந்து முனையக் கட்டளை வரை, இணைப்பைத் திறக்கும் எதுவும் நீங்கள் தேர்ந்தெடுத்த உலாவிக்கே செல்லும்.

## Copy URL மற்றும் Download Video

Chromium குடும்ப உலாவிகள் (Chromium-ஏ தான், Chrome, Edge மற்றும் Brave) உலாவியைத் தாண்டி உங்கள் கணினியின் மற்ற பகுதிகளுக்குள் செல்லும் இரண்டு Omarchy நீட்டிப்புகளுடன் வருகின்றன.

**Copy URL** தற்போதைய தாவலின் முகவரியை `Alt + Shift + L` மூலம் உங்கள் கிளிப்போர்டில் வைக்கிறது. முகவரிப் பட்டியில் சொடுக்கி நகலெடுப்பதை விட இது வேகமானது, மேலும் இது உலாவியின் கிளிப்போர்டு வழியாகச் செல்லாமல் கணினியின் கிளிப்போர்டு வழியாகச் செல்வதால், அதை உறுதிப்படுத்தும் Omarchy அறிவிப்பைப் பெறுவீர்கள், அந்த URL உடனடியாக [கிளிப்போர்டு வரலாற்றிலும்](08-unified-clipboard-history.md) மற்ற ஒவ்வொரு செயலியிலும் கிடைக்கும். சொடுக்குவதையே விரும்பினால், அதற்கான கருவிப்பட்டிப் பொத்தானும் உள்ளது.

**Download Video** நீங்கள் பார்த்துக் கொண்டிருக்கும் பக்கத்தில் இயங்கும் வீடியோவை `Alt + Shift + D` மூலம் எடுக்கிறது. இது அந்த URL-ஐ [yt-dlp](https://github.com/yt-dlp/yt-dlp)-க்குக் கொடுக்கிறது, எனவே இது YouTube-ஐ விட மிக அதிகமானவற்றில் வேலை செய்யும், பதிவிறக்கம் `~/Videos` இல் வந்து சேரும். முன்னேற்றம், ஒலியளவும் பிரகாசமும் பயன்படுத்தும் அதே திரைக் காட்சியிலேயே தோன்றும், அறிவிப்புகளைக் குவித்துக் கொண்டே போகாமல் அதே இடத்தில் புதுப்பிக்கப்படும். கோப்புகள் வேறு எங்காவது செல்ல வேண்டுமென்றால் `OMARCHY_YTDLP_DIR` ஐ அமையுங்கள் — சூழல் மாறிகளை எங்கு வைப்பது என்பதற்கு [FAQ](46-faq.md) ஐப் பாருங்கள்.

இரண்டு நீட்டிப்புகளும் ஒரு சிறிய நேட்டிவ் செய்தியனுப்பும் ஹோஸ்டு வழியாக Omarchy-உடன் பேசுகின்றன, அது உலாவியுடன் சேர்த்து உங்களுக்காக நிறுவப்படும். ஒரு வலைப் பக்கத்தின் வீடியோ உங்கள் முகப்பு அடைவில் வந்து சேரவும், ஒரு URL உங்கள் கிளிப்போர்டு மேலாளரில் வந்து சேரவும் வழி செய்யும் பகுதி அதுதான், சாதாரண நீட்டிப்பால் தனியாக அதைச் செய்ய முடியாது.

இவை Chromium குடும்பத்திற்கு மட்டுமே. Firefox மற்றும் Zen-க்கு இவை கிடைக்காது.

## Firefox மற்றும் Zen

Firefox மற்றும் Zen வேறு குடும்பத்தைச் சேர்ந்தவை, எனவே அவற்றுக்கு வேறு மாதிரியான அணுகுமுறை கிடைக்கிறது: நியாயமான இயல்புநிலைகளுக்காக Omarchy ஒரு கொள்கைகள் கோப்பை நிறுவி, அவற்றை நேட்டிவ் Wayland பயன்முறைக்கு மாற்றுகிறது, பின்ன அளவிடுதலுக்கும் மென்மையான டிராக்பேட் உருட்டலுக்கும் இதுதான் உங்களுக்கு வேண்டும்.

அவற்றுக்கு மேலே உள்ள Chromium நீட்டிப்புகள் கிடைக்காது, அவை Omarchy-ஆல் தீம் செய்யப்படுவதுமில்லை, எனவே அனுபவத்தின் அந்தப் பகுதிகளை நீங்களே அமைத்துக் கொள்ள வேண்டும்.

## ஒன்றை மீண்டும் நீக்குதல்

Chrome உட்பட இந்த உலாவிகளில் எதையும் _நீக்கு > உலாவி_ என்பதன் கீழ் மீண்டும் நீக்கிவிடலாம். பிறகு மற்றொன்று இன்னும் நிறுவப்பட்டிருந்தால் இணைப்புகள் Chrome அல்லது Chromium-க்குச் செல்லும்.
