# உலாவிகள்

Omarchy [Google Chrome](https://www.google.com/chrome/) ஐ இயல்புநிலை உலாவியாகக் கொண்டு வருகிறது. உங்கள் கணினியின் மற்ற பகுதிகளுடன் பொருந்தும்படி அது தீம் செய்யப்பட்டுள்ளது, மேலும் `Super + Shift + Return` (அல்லது `Super + Shift + B`) திறப்பது அதைத்தான், `Super + Shift + Alt + B` தனிப்பட்ட சாளரத்திற்கானது, மேலும் ஒவ்வொரு [வலை பயன்பாடும்](25-web-apps.md) அதற்குள்ளேயே இயங்கும். அது நேரடியாக உலாவி சாளரத்திற்குத் திறக்கும்: வரவேற்புத் திரையோ உள்நுழைவு அறிவுறுத்தலோ இல்லை, பயன்பாட்டுப் புள்ளிவிவரங்களும் செயலிழப்பு அறிக்கைகளும் Google-க்கு அனுப்பப்படுவதில்லை, விளம்பரத் தனியுரிமை அறிவுறுத்தல்கள் அணைக்கப்பட்டுள்ளன. ஒத்திசைவு வேண்டும்போதெல்லாம் சுயவிவரப் பொத்தானிலிருந்து உங்கள் Google கணக்கில் நீங்கள் இன்னும் உள்நுழையலாம்.

Chrome உங்கள் விருப்பத்திற்கு ஏற்றதாக இல்லையென்றால், அதிலேயே நீங்கள் சிக்கிக் கொள்ளவில்லை. Omarchy மெனுவில் _Install > Browser_ இன் கீழ் [Chromium](https://www.chromium.org/) (Chrome உருவாக்கப்பட்ட அதே எளிய திறந்த மூல உருவாக்கம்), Edge, Brave, Brave Origin, Firefox, மற்றும் [Zen](https://zen-browser.app/) ஆகியவற்றைக் காண்பீர்கள் (Edge x86 கணினிகளில் மட்டும்). ஒன்றைத் தேர்ந்தெடுங்கள், Omarchy அதை நிறுவும், அதன் policy கோப்பகத்தை அமைக்கும், உங்கள் தற்போதைய தீமை அதற்குப் பயன்படுத்தும்.

## ஒன்றை இயல்புநிலையாக்குதல்

உலாவியை நிறுவுவது அதை உயர்த்திவிடாது. மாற்ற, _Setup > Defaults > Browser_ க்குச் சென்று ஒன்றைத் தேர்ந்தெடுங்கள். தற்போதைய இயல்புநிலை ஒரு சரிக்குறியால் குறிக்கப்பட்டிருக்கும், இன்னும் உங்களிடம் இல்லாத உலாவியைத் தேர்ந்தெடுத்தால் அது முதலில் நிறுவப்படும்.

முனையத்திலிருந்து இது:

```bash
omarchy default browser firefox
```

வாதம் எதுவும் இல்லாமல் அதை இயக்கினால், தற்போதைய இயல்புநிலையை அது உங்களுக்குச் சொல்லும். இது XDG handler-ஐ அமைக்கிறது, எனவே Omarchy-இன் hotkey-கள் மட்டும் அதைப் பின்பற்றாது — இணைப்பைத் திறக்கும் எதுவும், அரட்டைச் செயலியிலிருந்து முனையக் கட்டளை வரை, நீங்கள் தேர்ந்தெடுத்த உலாவிக்கே செல்லும்.

## Copy URL மற்றும் Download Video

Chromium குடும்ப உலாவிகள் (Chromium-ஏ தான், Chrome, Edge, Brave, மற்றும் Brave Origin) மூன்று Omarchy நீட்டிப்புகளுடன் வருகின்றன: இரண்டு உலாவியிலிருந்து வெளியே உங்கள் கணினியின் மற்ற பகுதிகளை அடைகின்றன, ஒன்று WhatsApp-ஐ ஒழுங்குபடுத்துகிறது.

**Copy URL** தற்போதைய தாவலின் முகவரியை `Alt + Shift + L` மூலம் உங்கள் clipboard-இல் வைக்கிறது. முகவரிப் பட்டையில் சொடுக்கி நகலெடுப்பதை விட அது வேகமானது, மேலும் அது உலாவியின் clipboard வழியாக அல்லாமல் கணினி clipboard வழியாகச் செல்வதால், அதை உறுதிப்படுத்தும் Omarchy அறிவிப்பைப் பெறுவீர்கள், URL உடனடியாக [clipboard வரலாற்றிலும்](08-unified-clipboard-history.md) மற்ற ஒவ்வொரு செயலியிலும் கிடைக்கும். சொடுக்குவதையே விரும்பினால், toolbar பொத்தானும் உள்ளது.

**Download Video** நீங்கள் பார்த்துக் கொண்டிருக்கும் பக்கத்தில் இயங்கும் காணொளியை `Alt + Shift + D` மூலம் பிடிக்கிறது. அது URL-ஐ [yt-dlp](https://github.com/yt-dlp/yt-dlp)-க்குக் கொடுக்கிறது, எனவே அது YouTube-ஐ விட மிக அதிகமானவற்றில் செயல்படும், பதிவிறக்கம் `~/Videos`-இல் வந்து சேரும். முன்னேற்றம், ஒலியளவும் பிரகாசமும் பயன்படுத்தும் அதே திரைக் காட்சியிலேயே காட்டப்படும், அறிவிப்புகளை அடுக்காமல் அதே இடத்தில் புதுப்பிக்கப்படும். கோப்புகள் வேறு எங்காவது செல்ல விரும்பினால் `OMARCHY_YTDLP_DIR`-ஐ அமைக்கவும் — சூழல் மாறிகளை எங்கு வைப்பது என்பதற்கு [FAQ](46-faq.md)-ஐப் பார்க்கவும்.

இரண்டு நீட்டிப்புகளும் ஒரு சிறிய native messaging host வழியாக Omarchy-உடன் பேசுகின்றன, அது உலாவியுடன் சேர்த்து உங்களுக்காக நிறுவப்படும். வலைப் பக்கத்தின் காணொளி உங்கள் home கோப்பகத்தில் வந்து சேரவும், URL உங்கள் clipboard மேலாளரில் வந்து சேரவும் அனுமதிக்கும் பகுதி அதுதான், சாதாரண நீட்டிப்பால் தனியாகச் செய்ய முடியாதது.

**WhatsApp Slim** WhatsApp Web உங்கள் கணினி தீமைப் பின்பற்றச் செய்கிறது, சாளரம் குறுகலாக இருக்கும்போது அதன் அரட்டைப் பட்டியலைச் சுருக்குகிறது.

இவை Chromium குடும்பத்திற்கு மட்டுமே. Firefox-க்கும் Zen-க்கும் இவை கிடைக்காது.

## Firefox மற்றும் Zen

Firefox-உம் Zen-உம் வேறு குடும்பம், எனவே அவற்றுக்கு வேறு மாதிரியான அணுகுமுறை கிடைக்கிறது: Omarchy விவேகமான இயல்புநிலைகளுக்காக policies கோப்பை நிறுவுகிறது, அவற்றை native Wayland பயன்முறைக்கு மாற்றுகிறது, பின்ன அளவிடுதலுக்கும் மென்மையான trackpad உருட்டலுக்கும் நீங்கள் விரும்புவது அதுதான்.

மேலே உள்ள Chromium நீட்டிப்புகள் அவற்றுக்குக் கிடைக்காது, Omarchy-ஆல் அவை தீம் செய்யப்படுவதில்லை, எனவே அனுபவத்தின் அந்தப் பகுதிகளை நீங்களே அமைத்துக் கொள்ள வேண்டும்.

## மீண்டும் ஒன்றை நீக்குதல்

Chrome உட்பட இந்த உலாவிகளில் எதையும் _Remove > Browser_ இன் கீழ் மீண்டும் நீக்கிவிடலாம். மற்றொன்று இன்னும் நிறுவப்பட்டிருந்தால், இணைப்புகள் பின்னர் Chrome-க்கோ Chromium-க்கோ செல்லும்.
