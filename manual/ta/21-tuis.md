# TUIs

## Lazygit

[Lazygit](https://github.com/jesseduffield/lazygit) என்பது GitHub Desktop பயன்பாடு போன்ற ஒன்றுக்கு மகிழ்ச்சியான மாற்றாகும், மேலும் இது terminal-இன் உள்ளே இயங்குகிறது.

நீங்கள் அதை நேரடியாக இயக்கலாம்; git ஆல் நிர்வகிக்கப்படும் எந்த directory-க்கும் சென்று `lazygit` என்று இயக்கினால் போதும். அல்லது Neovim-இன் உள்ளே அதை இயக்கலாம், அங்கு அதை `Space G G` என்பதன் மூலம் தொடங்கலாம்.

வெவ்வேறு pane-களுக்கு இடையே `Tab` ஐப் பயன்படுத்தி நீங்கள் தாவலாம். Files pane-இல், `Space` ஐப் பயன்படுத்தி staging-க்காக கோப்புகளைத் தேர்ந்தெடுக்கலாம், பின்னர் `c` ஐப் பயன்படுத்தி புதிய commit ஒன்றை உருவாக்கலாம். கிடைக்கும் அனைத்து கட்டளைகளையும் `?` ஐப் பயன்படுத்திப் பார்க்கலாம்.

## Btop

[Btop](https://github.com/aristocratos/btop) என்பது நினைவகம், CPU, disk மற்றும் நெட்வொர்க் பயன்பாட்டைக் காட்டும் ஒரு அழகான வள மேலாளர். இது செயலில் உள்ள அனைத்து செயல்முறைகளையும் பட்டியலிடுகிறது, மேலும் அவற்றை நிர்வகிக்கவும் உங்களை அனுமதிக்கிறது.

Omarchy இதை Activity Monitor என்று அழைக்கிறது, மேலும் நீங்கள் அதை app launcher-இல் இருந்து அல்லது `Super + Shift + T` ஐ அழுத்துவதன் மூலம் தொடங்கலாம். இது மிதக்கும் சாளரமாகத் திறக்கும், அதை நீங்கள் `Super + T` மூலம் tile செய்யலாம்.

## Herdr

[Herdr](https://herdr.dev) என்பது உங்களுக்கு workspace-கள், tab-கள் மற்றும் pane-களை வழங்கும் ஒரு terminal workspace மேலாளர், மேலும் நீங்கள் பிரிந்து சென்று பின்னர் மீண்டும் வரக்கூடிய ஒரு நீடித்த session-இல் அவை அனைத்தையும் தொடர்ந்து இயங்க வைக்கிறது.

நீங்கள் அதை app launcher-இல் இருந்து அல்லது `Super + Ctrl + Return` மூலம் தொடங்கலாம் (அல்லது உங்கள் ஏற்கனவே உள்ள session உடன் மீண்டும் இணையலாம்). Omarchy அதன் Tmux config ஐப் பிரதிபலிக்கும் ஒரு Herdr உள்ளமைவை வழங்குகிறது, எனவே இங்கும் prefix key `Ctrl + Space` ஆகும். அனைத்து keybinding-களையும் `Super + Ctrl + K` மூலம் நீங்கள் உலாவலாம்.

## Fastfetch

[Fastfetch](https://github.com/fastfetch-cli/fastfetch) கர்னல் பதிப்பு, இயக்க நேரம், theme, CPU, நினைவகம் மற்றும் பலவற்றைப் போன்ற கணினித் தகவல்களைக் காட்டுகிறது. இது பிரபலமான neofetch கருவியின் வாரிசு.

Omarchy இதை Omarchy மெனுவில் (`Super + Space`) _System > About_ என தொகுத்துள்ளது.

## Cliamp

[Cliamp](https://www.cliamp.stream/) என்பது Winamp 2.x ஆல் ஈர்க்கப்பட்ட ஒரு ரெட்ரோ terminal இசை பிளேயர், lo-fi beats-க்கான உள்ளமைக்கப்பட்ட வானொலி நிலையங்களுடன் முழுமையாக வருகிறது. அதை `Super + Shift + Alt + M` மூலம் அல்லது Omarchy மெனுவில் _Apps_ இன் கீழ் இருந்து தொடங்குங்கள். முழு keybinding பட்டியலுக்கு `?` ஐ அழுத்துங்கள்.

## Wi-Fi மற்றும் Bluetooth பற்றி என்ன?

Wi-Fi மற்றும் Bluetooth-க்கான TUI-களை நீங்கள் காண மாட்டீர்கள் — அந்த வேலைகள் Omarchy shell-க்கு உரியவை. நெட்வொர்க்குகளைப் பார்க்கவும் இணைக்கவும் மேல் பட்டியில் உள்ள Wi-Fi ஐகானைக் கிளிக் செய்யுங்கள் (அல்லது `Super + Ctrl + N` ஐ அழுத்துங்கள்), மேலும் சாதனங்களை இணைக்கவும் இணைப்பை ஏற்படுத்தவும் Bluetooth ஐகானைக் கிளிக் செய்யுங்கள் (அல்லது `Super + Ctrl + B` ஐ அழுத்துங்கள்). முழு விவரத்திற்கு [நெட்வொர்க்கிங்](35-networking.md) ஐப் பார்க்கவும்.

## உங்களுடையதைச் சேர்த்தல்

எந்த terminal நிரலும் முழு app அந்தஸ்தைப் பெறலாம். Omarchy மெனுவில் (`Super + Space`) _Install > TUI_ க்குச் சென்று, அதற்கு ஒரு பெயர், ஒரு launch கட்டளை, ஒரு window பாணி மற்றும் ஒரு ஐகானைக் கொடுங்கள், அது மற்ற எந்த பயன்பாட்டைப் போலவே app launcher-இல் தோன்றும். அதை மீண்டும் _Remove > TUI_ இன் கீழ் நீக்கலாம்.
