# TUIs

## Lazygit

[Lazygit](https://github.com/jesseduffield/lazygit) என்பது GitHub Desktop போன்ற ஒரு செயலிக்கு மகிழ்ச்சியான மாற்றாகும், மேலும் இது டெர்மினலுக்குள் இயங்குகிறது.

நீங்கள் அதை நேரடியாக இயக்கலாம், git ஆல் நிர்வகிக்கப்படும் எந்தக் கோப்பகத்திற்கும் சென்று `lazygit` ஐ இயக்குவதன் மூலம். அல்லது நீங்கள் அதை Neovim க்குள் இயக்கலாம், அங்கு அதை `Space G G` கொண்டு தொடங்கலாம்.

நீங்கள் `Tab` ஐப் பயன்படுத்தி வெவ்வேறு பேன்களுக்கு இடையில் தாவுகிறீர்கள். Files பேனில், நீங்கள் `Space` ஐப் பயன்படுத்தி ஸ்டேஜிங்கிற்குக் கோப்புகளைத் தேர்ந்தெடுக்கிறீர்கள், பின்னர் `c` ஐப் பயன்படுத்தி புதிய கமிட்டை உருவாக்கலாம். `?` ஐப் பயன்படுத்தி கிடைக்கக்கூடிய அனைத்து கட்டளைகளையும் நீங்கள் காணலாம்.

## Btop

[Btop](https://github.com/aristocratos/btop) என்பது நினைவகம், CPU, வட்டு மற்றும் நெட்வொர்க் பயன்பாட்டைக் காட்டும் அழகான வள மேலாளர். இது செயலில் உள்ள அனைத்து செயல்முறைகளையும் பட்டியலிடுகிறது, மேலும் அவற்றை நிர்வகிக்க உங்களை அனுமதிக்கிறது.

Omarchy இதை Activity Monitor என்று அழைக்கிறது, மேலும் நீங்கள் அதை செயலி துவக்கியிலிருந்து அல்லது `Super + Shift + T` ஐ அழுத்துவதன் மூலம் தொடங்குகிறீர்கள். இது மிதக்கும் சாளரமாகத் திறக்கிறது, அதை நீங்கள் `Super + T` கொண்டு டைல் செய்யலாம்.

## Herdr

[Herdr](https://github.com/omacom-io/herdr) என்பது உங்களுக்குப் பணியிடங்கள், தாவல்கள் மற்றும் பேன்களை வழங்கும் டெர்மினல் பணியிட மேலாளர் ஆகும், மேலும் அவற்றை நீங்கள் பிரிந்து பின்னர் மீண்டும் வரக்கூடிய நிலையான அமர்வில் இயங்க வைக்கிறது.

நீங்கள் அதைத் தொடங்குகிறீர்கள் (அல்லது உங்கள் இருக்கும் அமர்வில் மீண்டும் இணைகிறீர்கள்) `Super + Ctrl + Return` கொண்டு. Omarchy அதன் Tmux கட்டமைப்பைப் பிரதிபலிக்கும் Herdr கட்டமைப்பை வழங்குகிறது, எனவே இங்கும் முன்னொட்டு விசை `Ctrl + Space` ஆகும். நீங்கள் `Super + Ctrl + K` கொண்டு அனைத்து விசைபிணைப்புகளையும் உலாவலாம்.

## Fastfetch

[Fastfetch](https://github.com/fastfetch-cli/fastfetch) கர்னல் பதிப்பு, இயக்க நேரம், தீம், CPU, நினைவகம் மற்றும் பல போன்ற கணினி தகவல்களைக் காட்டுகிறது. இது பிரபலமான neofetch கருவியின் வாரிசு ஆகும்.

Omarchy இதை Omarchy மெனுவில் (`Super + Space`) _About_ ஆகத் தொகுத்துள்ளது.

## Cliamp

[Cliamp](https://www.cliamp.stream/) என்பது Winamp 2.x ஆல் ஈர்க்கப்பட்ட ரெட்ரோ டெர்மினல் இசை பிளேயர் ஆகும், lo-fi பீட்களுக்கான உள்ளமைக்கப்பட்ட ரேடியோ நிலையங்களுடன் முழுமையானது. அதை `Super + Shift + Alt + M` கொண்டு, அல்லது Omarchy மெனுவில் _Apps_ கீழ் தொடங்கவும். முழு விசைபிணைப்புப் பட்டியலுக்கு `?` ஐ அழுத்தவும்.

## Wi-Fi மற்றும் Bluetooth பற்றி என்ன?

Wi-Fi மற்றும் Bluetooth க்கான TUIs ஐ நீங்கள் காண மாட்டீர்கள் — அந்த வேலைகள் Omarchy ஷெல்லுக்கு உரியவை. நெட்வொர்க்குகளைக் கண்டு இணைக்க மேல் பட்டியில் உள்ள Wi-Fi ஐகானைக் கிளிக் செய்யவும் (அல்லது `Super + Ctrl + N` ஐ அழுத்தவும்), மேலும் சாதனங்களை இணைத்து இணைக்க Bluetooth ஐகானைக் கிளிக் செய்யவும் (அல்லது `Super + Ctrl + B` ஐ அழுத்தவும்). முழுக் கதைக்கும் [நெட்வொர்க்கிங்](35-networking.md) ஐப் பார்க்கவும்.

## உங்களுடையதைச் சேர்த்தல்

எந்த டெர்மினல் நிரலும் முழு செயலி அந்தஸ்தைப் பெறலாம். Omarchy மெனுவில் (`Super + Space`) _Install > TUI_ க்குச் சென்று, அதற்கு ஒரு பெயர், தொடக்கக் கட்டளை, சாளர பாணி மற்றும் ஐகானைக் கொடுங்கள், அது மற்ற எந்தச் செயலியைப் போலவே செயலி துவக்கியில் தோன்றும். நீங்கள் அதை மீண்டும் _Remove > TUI_ கீழ் நீக்கலாம்.
