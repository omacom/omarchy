# TUI கள்

## Lazygit

[Lazygit](https://github.com/jesseduffield/lazygit) என்பது GitHub Desktop செயலி போன்ற ஒன்றிற்கு மகிழ்ச்சியான மாற்றாகும், மேலும் இது முனையத்திற்குள் இயங்குகிறது.

git ஆல் நிர்வகிக்கப்படும் எந்தக் கோப்பகத்திற்கும் சென்று `lazygit` என்று இயக்குவதன் மூலம் அதை நேரடியாக இயக்கலாம். அல்லது Neovim க்குள் அதை இயக்கலாம், அங்கு `Space G G` உடன் அதைத் தொடங்கலாம்.

`Tab` ஐப் பயன்படுத்தி வெவ்வேறு பலகங்களுக்கு இடையே தாவுகிறீர்கள். Files பலகத்தில், `Space` ஐப் பயன்படுத்தி நிலைப்படுத்துவதற்கான கோப்புகளைத் தேர்ந்தெடுக்கிறீர்கள், பின்னர் `c` ஐப் பயன்படுத்தி ஒரு புதிய commit ஐ உருவாக்கலாம். கிடைக்கக்கூடிய அனைத்துக் கட்டளைகளையும் `?` ஐப் பயன்படுத்திப் பார்க்கலாம்.

## Btop

[Btop](https://github.com/aristocratos/btop) என்பது நினைவகம், CPU, வட்டு மற்றும் வலையமைப்புப் பயன்பாட்டைக் காட்டும் ஒரு அழகான வள மேலாளர். இது அனைத்து செயலில் உள்ள செயல்முறைகளையும் பட்டியலிடுகிறது, மேலும் அவற்றை நிர்வகிக்க உதவுகிறது.

Omarchy இதை Activity என்று அழைக்கிறது, `Super + Ctrl + T` ஐ அழுத்துவதன் மூலம் அதைத் தொடங்குகிறீர்கள். இது மிதக்கும் சாளரமாகத் திறக்கிறது, அதை `Super + T` உடன் அடுக்கலாம்.

## Herdr

[Herdr](https://github.com/omacom-io/herdr) என்பது பணியிடங்கள், தாவல்கள் மற்றும் பலகங்களைத் தரும் ஒரு முனைய பணியிட மேலாளர், மேலும் அவை அனைத்தையும் நீங்கள் பிரிந்து பின்னர் திரும்பி வரக்கூடிய தொடர்ச்சியான அமர்வில் இயங்க வைக்கிறது.

`Super + Ctrl + Return` உடன் அதைத் தொடங்குகிறீர்கள் (அல்லது உங்கள் தற்போதைய அமர்வுடன் மீண்டும் இணைகிறீர்கள்). Omarchy அதன் Tmux கட்டமைப்பைப் பிரதிபலிக்கும் Herdr கட்டமைப்பை வழங்குகிறது, எனவே இங்கும் முன்னொட்டு விசை `Ctrl + Space` ஆகும். `Super + Ctrl + K` உடன் அனைத்து விசைப்பிணைப்புகளையும் பார்க்கலாம்.

## Fastfetch

[Fastfetch](https://github.com/fastfetch-cli/fastfetch) கர்னல் பதிப்பு, இயக்க நேரம், தீம், CPU, நினைவகம் மற்றும் பலவற்றைப் போன்ற கணினி தகவல்களைக் காட்டுகிறது. இது பிரபலமான neofetch கருவியின் வாரிசு.

Omarchy மெனுவில் (`Super + Space`) இதை Omarchy _பற்றி_ என்று தொகுத்துள்ளது.

## Cliamp

[Cliamp](https://www.cliamp.stream/) என்பது Winamp 2.x ஆல் ஈர்க்கப்பட்ட ஒரு ரெட்ரோ முனைய இசை இயக்கி, lo-fi beats க்கான உள்ளமைக்கப்பட்ட வானொலி நிலையங்களுடன் முழுமையானது. `Super + Shift + Alt + M` உடன் அல்லது Omarchy மெனுவில் _செயலிகள்_ க்குக் கீழ் அதைத் தொடங்கவும். முழு விசைப்பிணைப்புப் பட்டியலுக்கு `?` ஐ அழுத்தவும்.

## Wi-Fi மற்றும் Bluetooth பற்றி என்ன?

Wi-Fi மற்றும் Bluetooth க்கான TUI களை நீங்கள் காண மாட்டீர்கள் — அந்த வேலைகள் Omarchy shell க்குரியவை. வலையமைப்புகளைப் பார்த்து இணைக்க மேல் பட்டையில் உள்ள Wi-Fi ஐகானைக் கிளிக் செய்யவும் (அல்லது `Super + Ctrl + W` ஐ அழுத்தவும்), சாதனங்களை இணைத்து இணைக்க Bluetooth ஐகானைக் கிளிக் செய்யவும் (அல்லது `Super + Ctrl + B` ஐ அழுத்தவும்). முழு கதைக்கு [வலையமைப்பு](35-networking.md) ஐப் பார்க்கவும்.

## உங்கள் சொந்தத்தைச் சேர்த்தல்

எந்த முனைய நிரலும் முழு செயலி சிகிச்சையைப் பெறலாம். Omarchy மெனுவில் (`Super + Space`) _நிறுவு > TUI_ க்குச் சென்று, அதற்கு ஒரு பெயர், ஒரு தொடக்கக் கட்டளை, ஒரு சாளர பாணி மற்றும் ஒரு ஐகானைக் கொடுங்கள், அது மற்ற எந்தச் செயலியையும் போல செயலி தொடக்கியில் தோன்றும். _நீக்கு > TUI_ க்குக் கீழ் அதை மீண்டும் அகற்றலாம்.
