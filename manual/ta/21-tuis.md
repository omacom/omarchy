# TUIs

## Lazygit

[Lazygit](https://github.com/jesseduffield/lazygit) என்பது GitHub Desktop போன்ற செயலிக்கான ஒரு மகிழ்ச்சியான மாற்றாகும், மேலும் இது டெர்மினலுக்குள் இயங்குகிறது.

நீங்கள் அதை நேரடியாக இயக்கலாம்; git மூலம் நிர்வகிக்கப்படும் எந்த கோப்பகத்திற்கும் சென்று `lazygit` என்று இயக்கினால் போதும். அல்லது Neovim-க்குள் இயக்கலாம்; அங்கு அதை `Space G G` மூலம் தொடங்கலாம்.

`Tab` ஐப் பயன்படுத்தி நீங்கள் பல்வேறு பலகங்களுக்கு இடையே செல்கிறீர்கள். Files பலகத்தில், `Space` ஐப் பயன்படுத்தி staging-க்காக கோப்புகளைத் தேர்ந்தெடுக்கிறீர்கள், பின்னர் `c` ஐப் பயன்படுத்தி ஒரு புதிய commit ஐ உருவாக்கலாம். `?` ஐப் பயன்படுத்தி கிடைக்கக்கூடிய அனைத்து கட்டளைகளையும் பார்க்கலாம்.

## Btop

[Btop](https://github.com/aristocratos/btop) என்பது நினைவகம், CPU, வட்டு மற்றும் வலையமைப்பு பயன்பாட்டை காட்டும் ஒரு அழகான வள மேலாளர். இது செயலில் உள்ள அனைத்து செயல்முறைகளையும் பட்டியலிடுகிறது, மேலும் அவற்றை நிர்வகிக்க உங்களை அனுமதிக்கிறது.

Omarchy இதை Activity என்று அழைக்கிறது, மேலும் நீங்கள் அதை `Super + Shift + T` ஐ அழுத்துவதன் மூலம் தொடங்குகிறீர்கள். இது ஒரு மிதக்கும் சாளரமாகத் திறக்கிறது; அதை நீங்கள் `Super + T` மூலம் டைல் செய்யலாம்.

## Herdr

[Herdr](https://github.com/omacom-io/herdr) என்பது உங்களுக்கு workspaces, tabs மற்றும் panes ஐ வழங்கும் ஒரு டெர்மினல் workspace மேலாளர் ஆகும், மேலும் அவை அனைத்தையும், நீங்கள் பிரிந்து சென்று பின்னர் மீண்டும் வரக்கூடிய ஒரு நிலையான அமர்வில் இயங்க வைக்கிறது.

நீங்கள் அதைத் தொடங்கலாம் (அல்லது உங்கள் தற்போதைய அமர்வில் மீண்டும் இணையலாம்) `Super + Ctrl + Return` மூலம். Omarchy தனது Tmux config-ஐ பிரதிபலிக்கும் ஒரு Herdr configuration-ஐ வழங்குகிறது, எனவே இங்கும் prefix விசை `Ctrl + Space` தான். `Super + Ctrl + K` மூலம் அனைத்து keybindings-ஐயும் உலாவலாம்.

## Fastfetch

[Fastfetch](https://github.com/fastfetch-cli/fastfetch) என்பது kernel பதிப்பு, uptime, theme, CPU, நினைவகம் மற்றும் பலவற்றைப் போன்ற கணினித் தகவல்களைக் காட்டுகிறது. இது பிரபலமான neofetch கருவியின் வாரிசு ஆகும்.

Omarchy இதை Omarchy மெனுவில் (`Super + Space`) _About_ ஆகத் தொகுத்துள்ளது.

## Cliamp

[Cliamp](https://www.cliamp.stream/) என்பது Winamp 2.x-ஆல் ஈர்க்கப்பட்ட ஒரு ரெட்ரோ டெர்மினல் இசை பிளேயர் ஆகும்; lo-fi beats-க்கான உள்ளமைக்கப்பட்ட வானொலி நிலையங்களுடன் இது முழுமையாக வருகிறது. இதை `Super + Shift + Alt + M` மூலம் தொடங்கவும், அல்லது Omarchy மெனுவில் _Apps_ என்பதன் கீழ் இருந்து தொடங்கவும். முழு keybinding பட்டியலுக்கு `?` ஐ அழுத்தவும்.

## Wi-Fi மற்றும் Bluetooth பற்றி என்ன?

Wi-Fi மற்றும் Bluetooth-க்கான TUIs-ஐ நீங்கள் காண மாட்டீர்கள் — அந்த வேலைகள் Omarchy shell-க்கு உரியவை. வலையமைப்புகளைப் பார்க்கவும் இணைக்கவும் மேல் பட்டியில் உள்ள Wi-Fi ஐகானைக் கிளிக் செய்யவும் (அல்லது `Super + Ctrl + N` ஐ அழுத்தவும்), மேலும் சாதனங்களை இணைத்து connect செய்ய Bluetooth ஐகானைக் கிளிக் செய்யவும் (அல்லது `Super + Ctrl + B` ஐ அழுத்தவும்). முழு விவரத்திற்கு [வலையமைப்பு](35-networking.md) ஐப் பார்க்கவும்.

## உங்களுடையதைச் சேர்த்தல்

எந்த டெர்மினல் நிரலும் முழு செயலி அங்கீகாரத்தைப் பெற முடியும். Omarchy மெனுவில் (`Super + Space`) _Install > TUI_ என்பதற்குச் சென்று, அதற்கு ஒரு பெயர், ஒரு தொடக்க கட்டளை, ஒரு சாளர பாணி மற்றும் ஒரு ஐகானைக் கொடுங்கள்; அது மற்ற எந்த செயலியையும் போலவே செயலி தொடக்கியில் தோன்றும். _Remove > TUI_ என்பதன் கீழ் அதை மீண்டும் நீக்கலாம்.
