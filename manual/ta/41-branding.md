# பிராண்டிங்

Omarchy, துவக்கத் திறப்பு, திரைச்சேமிப்பான் மற்றும் பற்றிய திரை ஆகியவற்றுக்கு உங்கள் நிறுவன லோகோவையோ அல்லது தனிப்பட்ட படத்தையோ அமைக்க உங்களை அனுமதிக்கிறது.

### துவக்கத் திறப்பு

உங்கள் தனிப்பயன் லோகோவும் வண்ணங்களும் எப்படி இருக்கும் என்பதைப் பார்க்க நீங்கள் `omarchy plymouth preview` ஐப் பயன்படுத்தலாம். இதற்கு ஒரு பின்னணி வண்ணம், ஒரு உரை வண்ணம், ஒரு லோகோ png மற்றும் முன்னோட்டப் படத்திற்கான ஒரு path தேவை:

```
omarchy plymouth preview '#1d2021' '#ebdbb2' logo.png preview.png
```

பிறகு `omarchy plymouth set '#1d2021' '#ebdbb2' logo.png` மூலம் அமைப்பைப் பயன்படுத்துங்கள்; இது SDDM உள்நுழைவுத் திரைக்கும் அதே வண்ணங்களையும் லோகோவையும் கொடுக்கும். மீட்டமைக்க விரும்பினால், நீங்கள் `omarchy plymouth reset` ஐப் பயன்படுத்தலாம்.

 ![branding-plymouth-shopify](images/branding-plymouth-shopify.webp)

### திரைச்சேமிப்பான்

திரைச்சேமிப்பானுக்குப் பயன்படுத்தப்படும் லோகோவை _தோற்றம் > பிராண்டிங் > திரைச்சேமிப்பான்_ என்பதன் கீழ் மாற்றலாம். இது ஒரு ASCII லோகோ, எனவே நீங்கள் உரையை நேரடியாகத் திருத்தலாம், ஆனால் நீங்கள் அதற்கு ஒரு png அல்லது svg படத்தையும் கொடுக்கலாம், நாங்கள் அதை ASCII ஆக மாற்றுவோம். இது மிகவும் அருமையாக இருக்கும்.

 ![branding-screensaver](images/branding-screensaver.webp)

அந்த மெனுவில் மூன்று உள்ளீடுகள் உள்ளன:

- **உரையைத் திருத்து** என்பது `~/.config/omarchy/branding/screensaver.txt` ஐ உங்கள் எடிட்டரில் திறக்கும். நீங்கள் விரும்பும் எதையும் தட்டச்சு செய்யுங்கள் அல்லது ஒட்டுங்கள் — ASCII ஆர்ட், உங்கள் பெயர், ஒரு மோசமான வார்த்தை. சேமித்துவிட்டு வெளியேறுங்கள், நீங்கள் அதைப் பார்க்கும் வகையில் திரைச்சேமிப்பான் உடனடியாக இயங்கத் தொடங்கும்.
- **படத்திலிருந்து அமை** என்பது ஒரு png அல்லது svg க்கான கோப்புத் தேர்வியைத் திறந்து, அதை ASCII ஆக மாற்றி, முடிவை உங்களுக்குக் காட்டும். தெளிவான வெளிப்புற வடிவம் கொண்ட லோகோக்கள் புகைப்படங்களை விட மிகச் சிறப்பாக வேலை செய்யும்.
- **இயல்புநிலையை மீட்டமை** என்பது Omarchy லோகோவை மீண்டும் வைக்கும்.

### பற்றிய திரை

Omarchy மெனுவிலிருந்து நீங்கள் பெறும் _பற்றி_ திரைக்கு அதே மூன்று விருப்பங்களும் _தோற்றம் > பிராண்டிங் > பற்றி_ என்பதன் கீழ் உள்ளன, அவை ஒரே மாதிரியாகவே வேலை செய்யும் — கோப்பு `~/.config/omarchy/branding/about.txt`, மற்றும் ஒவ்வொரு மாற்றத்திற்குப் பிறகும் About சாளரம் தோன்றும். About ஆர்ட் திரைச்சேமிப்பானுடையதை விடச் சிறிய அளவிற்கு மாற்றப்படுகிறது, ஏனெனில் அது உங்கள் திரையை நிரப்புவதற்குப் பதிலாக ஒரு சாளரத்திற்குள் பொருந்த வேண்டும்.

சாளரம் திறந்திருக்கும்போது, ஒவ்வொரு சில வினாடிகளுக்கும் ஒரு பச்சை ஒளிக்கீற்று ஆர்ட்டின் குறுக்கே சாய்ந்து சென்று, பின்னர் அதை மீண்டும் அசையாமல் விட்டுவிடும். உங்கள் சொந்த ஆர்ட்டுக்கும் அது கிடைக்கும், அதில் உள்ள ஒவ்வொரு எழுத்தும் ஒரு நெடுவரிசை அகலமாக இருக்கும் வரை — _படத்திலிருந்து அமை_ உருவாக்கும் எதுவும் அப்படித்தான் இருக்கும். emoji அல்லது இரட்டை அகல எழுத்துகளிலிருந்து கட்டப்பட்ட ஆர்ட் அதற்குப் பதிலாக அசையாமல் இருக்கும், நீங்கள் உங்கள் சொந்த fastfetch config ஐ வைத்திருந்தால் திரையும் அப்படியே இருக்கும்: அந்த நேரங்களில் அசையாத லோகோ என்பது அனிமேஷன் தோல்வியடைவதற்குப் பதிலாக வழிவிட்டு விலகி இருப்பதாகும், ஏனெனில் அவற்றின் குறுக்கே ஒரு ஒளிக்கீற்றை நகர்த்தினால் வரியின் மீதமுள்ள பகுதி தவறான இடத்தில் விழும்.

### படங்களை நீங்களே மாற்றுதல்

இரண்டு _படத்திலிருந்து அமை_ விருப்பங்களும் வெறுமனே `omarchy transcode ascii` ஐத்தான் அழைக்கின்றன; மாற்றத்தின் மீது கட்டுப்பாடு வேண்டுமென்றால் நீங்கள் அதை நேரடியாகவே இயக்கலாம்:

```
omarchy transcode ascii ~/logo.svg ~/.config/omarchy/branding/screensaver.txt --width 100
```

இதற்கு terminal நெடுவரிசைகள் மற்றும் வரிசைகளில் `--width` மற்றும் `--height`, `braille` (இயல்புநிலை, மிகவும் நுட்பமானது) அல்லது `block` ஆகியவற்றில் ஒன்றான ஒரு `--mode`, எந்த pixels லோகோவின் பகுதியாகக் கணக்கிடப்படும் என்பதைத் தீர்மானிப்பதற்கான ஒரு `--threshold` சதவீதம், மற்றும் உங்கள் லோகோ அடர் பின்னணியில் வெளிர் நிறத்தில் இருக்கும்போதான `--invert` ஆகியவை தேவை. ஒரு மாற்றம் ஒரு கட்டியாக வந்தால், threshold பொதுவாகத் திருப்ப வேண்டிய பொத்தானாகும்.

### லோகோவிற்குப் பதிலாக வார்த்தைகள்

`omarchy ascii` உரையை Delta Corps Priest 1 இல் வரைகிறது; அது Omarchy wordmark அதுவே வரையப்பட்டுள்ள FIGlet font, எனவே ஒரு திரைச்சேமிப்பான் ஒரு படத்தைக் காட்டுவதற்குப் பதிலாக ஏதாவது சொல்ல முடியும்:

```
omarchy ascii "Back in five" > ~/.config/omarchy/branding/screensaver.txt
```

இது உரையை arguments ஆக எடுத்துக்கொள்கிறது, அல்லது எதுவும் கொடுக்கப்படாதபோது ஒரு pipe இலிருந்து அதைப் படிக்கிறது. அந்த font எழுத்துக்களையும் இடைவெளிகளையும் மட்டுமே கொண்டுள்ளது — அது இலக்கங்கள் அல்லது நிறுத்தற்குறிகள் இல்லாமல் வரையப்பட்டது — எனவே வேறு எதுவும் அமைதியாக விழுங்கப்படாமல் நீக்கப்பட்டு stderr இல் பெயரிடப்படும்.
