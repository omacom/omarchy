# பிராண்டிங்

Omarchy உங்கள் நிறுவன லோகோவையோ தனிப்பட்ட படத்தையோ துவக்கத் திறப்பு, திரைசேமிப்பு, பற்றித் திரை மூன்றிற்கும் அமைக்க அனுமதிக்கிறது.

### துவக்கத் திறப்பு

உங்கள் தனிப்பயன் லோகோவும் நிறங்களும் எப்படி இருக்கும் என்று பார்க்க `omarchy plymouth preview` என்பதைப் பயன்படுத்தலாம். அது ஒரு பின்னணி நிறம், ஓர் உரை நிறம், ஒரு லோகோ png, முன்னோட்டப் படத்திற்கான பாதை ஆகியவற்றை எடுக்கிறது:

```
omarchy plymouth preview '#1d2021' '#ebdbb2' logo.png preview.png
```

பிறகு `omarchy plymouth set '#1d2021' '#ebdbb2' logo.png` என்பதைக் கொண்டு அமைப்பைப் பயன்படுத்துங்கள், அது SDDM உள்நுழைவுத் திரைக்கும் அதே நிறங்களையும் லோகோவையும் தரும். மாற்றியதைத் திரும்பப் பெற விரும்பினால், `omarchy plymouth reset` என்பதைப் பயன்படுத்தலாம்.

 ![branding-plymouth-shopify](images/branding-plymouth-shopify.webp)

### திரைசேமிப்பு

_பாணி > திரைசேமிப்பு_ என்பதன் கீழ் திரைசேமிப்பிற்குப் பயன்படும் லோகோவை மாற்றலாம். அது ஒரு ASCII லோகோ, எனவே உரையை நேரடியாகத் திருத்தலாம், ஆனால் அதற்கு ஒரு png அல்லது svg படத்தையும் தரலாம், நாங்கள் அதை ASCII-ஆக மாற்றுவோம். அது மிகவும் அழகாகத் தெரிகிறது.

 ![branding-screensaver](images/branding-screensaver.webp)

அந்த மெனுவில் மூன்று உள்ளீடுகள் உள்ளன:

- **Edit Text** உங்கள் எடிட்டரில் `~/.config/omarchy/branding/screensaver.txt` என்பதைத் திறக்கிறது. விருப்பமானதைத் தட்டச்சு செய்யுங்கள் அல்லது ஒட்டுங்கள் — ASCII ஓவியம், உங்கள் பெயர், ஒரு கடுமையான சொல். சேமித்து வெளியேறுங்கள், திரைசேமிப்பு உடனே தொடங்கும், எனவே அதைக் காணலாம்.
- **Set From Image** ஒரு png அல்லது svg-க்குக் கோப்புத் தேர்வியைத் திறந்து, அதை ASCII-ஆக மாற்றி, முடிவைக் காட்டுகிறது. தெளிவான நிழல் வடிவம் கொண்ட லோகோக்கள் புகைப்படங்களை விட மிகச் சிறப்பாக வேலை செய்கின்றன.
- **Restore Default** Omarchy லோகோவை மீண்டும் வைக்கிறது.

### பற்றித் திரை

Omarchy மெனுவிலிருந்து கிடைக்கும் _பற்றி_ திரைக்கு அதே மூன்று விருப்பங்களும் _பாணி > பற்றி_ என்பதன் கீழ் உள்ளன, அவை அப்படியே வேலை செய்கின்றன — கோப்பு `~/.config/omarchy/branding/about.txt`, ஒவ்வொரு மாற்றத்திற்குப் பிறகும் பற்றிச் சாளரம் தோன்றும். பற்றி ஓவியம் திரைசேமிப்பின் ஓவியத்தை விடச் சிறிய அளவிற்கு மாற்றப்படுகிறது, ஏனென்றால் அது உங்கள் திரையை நிரப்புவதற்குப் பதிலாக ஒரு சாளரத்தில் பொருந்த வேண்டும்.

சாளரம் திறந்திருக்கும்போது, ஒவ்வொரு சில விநாடிகளுக்கும் ஒரு பச்சை மின்னொளி ஓவியத்தின் குறுக்கே சாய்ந்து, பிறகு அதை மீண்டும் அசையாமல் விட்டுவிடும். உங்கள் சொந்த ஓவியத்திற்கும் அது கிடைக்கும், அதில் உள்ள ஒவ்வோர் எழுத்தும் ஒரு நெடுவரிசை அகலமாக இருக்கும் வரை — _Set From Image_ உருவாக்குவது அனைத்தும் அப்படியே. Emoji அல்லது இரட்டை அகல எழுத்துகளால் கட்டப்பட்ட ஓவியம் அதற்குப் பதிலாக அசையாமல் இருக்கும், நீங்கள் உங்கள் சொந்த fastfetch உள்ளமைவை வைத்திருந்தால் திரையும் அப்படியே: அந்தச் சூழல்களில் ஒரு நிலை லோகோ என்பது அசைவூட்டம் தோல்வியடைவதற்குப் பதிலாக வழியை விட்டு விலகி நிற்பதாகும், ஏனென்றால் அவற்றின் குறுக்கே மின்னொளியைச் சறுக்கினால் வரியின் மீதம் தவறான இடத்தில் இறங்கும்.

 ![branding-about](images/branding-about.webp)

### படங்களை நீங்களே மாற்றுதல்

இரண்டு _Set From Image_ விருப்பங்களும் `omarchy transcode ascii` என்பதை அழைக்கின்றன, மாற்றத்தின் மீது கட்டுப்பாடு வேண்டுமென்றால் அதை நேரடியாக இயக்கலாம்:

```
omarchy transcode ascii ~/logo.svg ~/.config/omarchy/branding/screensaver.txt --width 100
```

அது முனைய நெடுவரிசைகள் மற்றும் வரிசைகளில் `--width` மற்றும் `--height`, `braille` (இயல்புநிலை, மிகவும் நுண்ணியது) அல்லது `block` என்ற `--mode`, எந்தப் பிக்சல்கள் லோகோவின் பகுதியாகக் கணக்கிடப்படும் என்பதை முடிவு செய்ய ஒரு `--threshold` சதவீதம், உங்கள் லோகோ இருண்ட பின்னணியில் வெளிர் நிறமாக இருந்தால் `--invert` ஆகியவற்றை எடுக்கிறது. ஒரு மாற்றம் ஒரு கட்டியாக வந்தால், வழக்கமாகத் திருப்ப வேண்டிய குமிழ் threshold தான்.

### லோகோவிற்குப் பதிலாகச் சொற்கள்

`omarchy ascii` Delta Corps Priest 1-இல் உரையை வரைகிறது, Omarchy சொல் அடையாளமே வரையப்பட்டிருக்கும் FIGlet எழுத்துரு, எனவே ஒரு திரைசேமிப்பு ஒரு படத்தைக் காட்டுவதற்குப் பதிலாக ஏதாவது சொல்லமுடியும்:

```
omarchy ascii "Back in five" > ~/.config/omarchy/branding/screensaver.txt
```

அது உரையை வாதங்களாக எடுக்கிறது, அல்லது எதுவும் தராதபோது அதை ஒரு குழாயிலிருந்து படிக்கிறது. எழுத்துரு எழுத்துகளையும் இடைவெளிகளையும் மட்டுமே கொண்டுள்ளது — அது இலக்கங்களோ நிறுத்தற்குறிகளோ இல்லாமல் வரையப்பட்டது — எனவே வேறு எதுவும் அமைதியாக விழுங்கப்படாமல் நீக்கப்பட்டு stderr-இல் பெயரிடப்படும்.
