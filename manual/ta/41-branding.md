# பிராண்டிங்

Omarchy, boot அன்லாக், ஸ்கிரீன்சேவர் மற்றும் About திரை ஆகியவற்றுக்கு உங்கள் நிறுவன லோகோவையோ தனிப்பட்ட படத்தையோ அமைக்க உங்களை அனுமதிக்கிறது.

### Boot அன்லாக்

உங்கள் தனிப்பயன் லோகோவும் வண்ணங்களும் எப்படித் தோன்றும் என்பதைப் பார்க்க `omarchy plymouth preview` ஐப் பயன்படுத்தலாம். இது ஒரு பின்னணி வண்ணம், ஒரு உரை வண்ணம், ஒரு logo png மற்றும் முன்னோட்டப் படத்துக்கான ஒரு பாதை ஆகியவற்றை எடுத்துக்கொள்கிறது:

```
omarchy plymouth preview '#1d2021' '#ebdbb2' logo.png preview.png
```

பிறகு `omarchy plymouth set '#1d2021' '#ebdbb2' logo.png` கொண்டு அமைப்பைப் பயன்படுத்துங்கள், இது SDDM உள்நுழைவுத் திரைக்கும் அதே வண்ணங்களையும் லோகோவையும் கொடுக்கும். மீட்டமைக்க விரும்பினால், `omarchy plymouth reset` ஐப் பயன்படுத்தலாம்.

 ![branding-plymouth-shopify](images/branding-plymouth-shopify.webp)

### ஸ்கிரீன்சேவர்

_தோற்றம் > பிராண்டிங் > ஸ்கிரீன்சேவர்_ என்பதன் கீழ் ஸ்கிரீன்சேவருக்குப் பயன்படுத்தப்படும் லோகோவை மாற்றலாம். இது ஒரு ASCII லோகோ, எனவே உரையை நேரடியாகத் திருத்தலாம், ஆனால் ஒரு png அல்லது svg படத்தையும் அதிடம் கொடுக்கலாம், நாங்கள் அதை ASCII ஆக மாற்றுவோம். இது மிகவும் அருமையாகத் தோன்றும்.

 ![branding-screensaver](images/branding-screensaver.webp)

அந்த மெனுவில் மூன்று உள்ளீடுகள் உள்ளன:

- **உரையைத் திருத்து** உங்கள் எடிட்டரில் `~/.config/omarchy/branding/screensaver.txt` ஐத் திறக்கும். நீங்கள் விரும்பும் எதையும் தட்டச்சு செய்யுங்கள் அல்லது ஒட்டுங்கள் — ASCII கலை, உங்கள் பெயர், ஒரு மோசமான வார்த்தை. சேமித்து வெளியேறுங்கள், நீங்கள் அதைப் பார்க்க ஸ்கிரீன்சேவர் உடனடியாகத் தொடங்கிவிடும்.
- **படத்திலிருந்து அமை** ஒரு png அல்லது svg க்கான கோப்புத் தேர்வியைத் திறந்து, அதை ASCII ஆக மாற்றி, முடிவை உங்களுக்குக் காட்டும். தெளிவான உருவவடிவம் கொண்ட லோகோக்கள் புகைப்படங்களை விட மிகச் சிறப்பாகச் செயல்படும்.
- **இயல்புநிலையை மீட்டமை** Omarchy லோகோவைத் திரும்ப வைக்கும்.

### About திரை

Omarchy மெனுவிலிருந்து நீங்கள் பெறும் _About_ திரைக்கு அதே மூன்று விருப்பங்களும் _தோற்றம் > பிராண்டிங் > About_ என்பதன் கீழ் உள்ளன, அவை ஒரே மாதிரியாகவே செயல்படும் — கோப்பு `~/.config/omarchy/branding/about.txt`, ஒவ்வொரு மாற்றத்துக்குப் பிறகும் About சாளரம் தோன்றும். About கலை ஸ்கிரீன்சேவரின் கலையை விடச் சிறிய அளவுக்கு மாற்றப்படுகிறது, ஏனெனில் அது உங்கள் திரையை நிரப்புவதற்குப் பதிலாக ஒரு சாளரத்துக்குள் பொருந்த வேண்டும்.

சாளரம் திறந்திருக்கும் போது, பிரகாசமான வெள்ளை ஒளியின் ஒரு பட்டை ஒவ்வொரு சில விநாடிகளுக்கும் கலையின் குறுக்கே சாய்ந்து சென்று, பிறகு அதை மீண்டும் அசையாமல் விட்டுவிடும். உங்கள் சொந்தக் கலையும் அதைப் பெறும், அதில் உள்ள ஒவ்வொரு எழுத்தும் ஒரு நெடுவரிசை அகலம் கொண்டதாக இருக்கும் வரை — _படத்திலிருந்து அமை_ உருவாக்கும் எதுவும் அப்படித்தான். emoji அல்லது இரட்டை அகல எழுத்துக்களால் உருவாக்கப்பட்ட கலை அதற்குப் பதிலாக அசையாமல் இருக்கும், நீங்கள் சொந்தமாக ஒரு fastfetch config ஐ வைத்திருந்தால் திரையும் அப்படித்தான் இருக்கும்: அந்த நேர்வுகளில் அசையாத லோகோ என்பது அனிமேஷன் தோல்வியடைவது அல்ல, வழியை விட்டு விலகி இருப்பது ஆகும், ஏனெனில் அவற்றின் குறுக்கே ஒரு பளபளப்பை நகர்த்தினால் வரியின் மீதமுள்ள பகுதி தவறான இடத்தில் விழும்.

### படங்களை நீங்களே மாற்றுதல்

இரண்டு _படத்திலிருந்து அமை_ விருப்பங்களும் வெறுமனே `omarchy transcode ascii` ஐத்தான் அழைக்கின்றன, மாற்றத்தின் மீது கட்டுப்பாடு வேண்டுமெனில் அதை நேரடியாக இயக்கலாம்:

```
omarchy transcode ascii ~/logo.svg ~/.config/omarchy/branding/screensaver.txt --width 100
```

இது terminal நெடுவரிசைகள் மற்றும் வரிசைகளில் `--width` மற்றும் `--height` ஐயும், `braille` (இயல்புநிலை, மிகவும் நுணுக்கமானது) அல்லது `block` ஆகியவற்றில் ஒன்றான `--mode` ஐயும், எந்தப் பிக்சல்கள் லோகோவின் பகுதியாகக் கணக்கிடப்படும் என்பதைத் தீர்மானிக்க ஒரு `--threshold` சதவீதத்தையும், உங்கள் லோகோ இருண்ட பின்னணியில் வெளிர் நிறத்தில் இருக்கும் போதுக்கான `--invert` ஐயும் எடுத்துக்கொள்கிறது. ஒரு மாற்றம் ஒரு கட்டியாக வந்தால், வழக்கமாகத் திருப்ப வேண்டிய குமிழ் threshold தான்.

### லோகோவுக்குப் பதிலாக வார்த்தைகள்

`omarchy ascii` உரையை Delta Corps Priest 1 இல் வரைகிறது, Omarchy சொல் அடையாளமே வரையப்பட்டுள்ள FIGlet எழுத்துரு அது, எனவே ஒரு ஸ்கிரீன்சேவர் ஒரு படத்தைக் காட்டுவதற்குப் பதிலாக ஏதாவது சொல்ல முடியும்:

```
omarchy ascii "Back in five" > ~/.config/omarchy/branding/screensaver.txt
```

இது உரையை வாதங்களாக எடுத்துக்கொள்கிறது, அல்லது எதுவும் கொடுக்கப்படாத போது ஒரு pipe இலிருந்து அதைப் படிக்கிறது. அந்த எழுத்துரு எழுத்துக்களையும் இடைவெளிகளையும் மட்டுமே கொண்டுள்ளது — அது இலக்கங்கள் அல்லது நிறுத்தற்குறிகள் இல்லாமல் வரையப்பட்டது — எனவே வேறு எதுவும் அமைதியாக விழுங்கப்படாமல் நீக்கப்பட்டு stderr இல் பெயரிடப்படும்.
