# பாதுகாப்பு

Omarchy பாதுகாப்பை மிகவும் தீவிரமாக எடுத்துக்கொள்கிறது. இது _உண்மையான உலகில்_ _உண்மையான வேலையைச்_ செய்ய நீங்கள் பயன்படுத்தக்கூடிய ஒரு இயங்குதளமாக இருக்க வேண்டும் என்பதே நோக்கம். ஒரு மடிக்கணினியைத் தொலைப்பது ஒரு பாதுகாப்பு அவசரநிலைக்கு வழிவகுக்க முடியாத இடத்தில். எனவே நாங்கள் செய்வது இதுதான்:

1. *முழு வட்டு குறியாக்கம் கட்டாயம்*: உங்கள் தரவின் நேரடிப் பாதுகாப்பைப் பாதுகாப்பதில் இதுவே மிக முக்கியமான படியாகும். உங்கள் கணினி தொலைந்து போனாலோ திருடப்பட்டாலோ, தரவு நிலையான LUKS (Linux Unified Key Setup) ஐப் பயன்படுத்தி முழுமையாகக் குறியாக்கம் செய்யப்பட்டிருக்கும்.
2. *Firewall இயல்பாகவே இயக்கப்பட்டிருக்கும்*: [LocalSend](https://localsend.org/) க்கான port 53317 ஐத் தவிர, அனைத்து உள்வரும் போக்குவரத்தும் இயல்பாகவே தடுக்கப்படும். நீங்கள் _அமைப்பு > பாதுகாப்பு > SSHD_ வழியாக அதை இயக்கும் வரை ssh கூட அணைக்கப்பட்டிருக்கும்; அது அமைப்பின் ஒரு பகுதியாக port 22 ஐத் திறக்கிறது (முரட்டு வழி முயற்சிகளுக்கு எதிராக விகிதம் வரையறுக்கப்பட்டுள்ளது). உங்கள் containers தற்செயலாக உலகிற்கு வெளிப்படுவதைத் தடுக்க, [ufw-docker](https://github.com/chaifeng/ufw-docker) அமைப்பைப் பயன்படுத்தி Docker அணுகலைக் கூட நாங்கள் கட்டுப்படுத்துகிறோம்.
3. *Arch எப்போதும் சமீபத்திய புதுப்பிப்புகளைக் கொண்டிருக்கும்*: Omarchy கட்டமைக்கப்பட்டுள்ள அடிப்படை distro வான Arch, ஒரு rolling distribution ஆகும். அதாவது, எந்தவொரு package இலும் கண்டறியப்பட்டு சரிசெய்யப்படும் எந்தவொரு பாதுகாப்பு பாதிப்பும் `omarchy-update` ஐப் பயன்படுத்தி நிறுவுவதற்கு விரைவாகக் கிடைக்கும். அந்த வழியில் நீங்கள் எப்போதும் எல்லாவற்றின் சமீபத்திய, மிகவும் பாதுகாப்பான பதிப்புகளையே இயக்குகிறீர்கள்.
4. *Omarchy தனது சொந்த packages மற்றும் mirror ஐப் பராமரிக்கிறது*: Omarchy இயல்பாக Arch இன் சொந்த core/extra/multilib repositories மற்றும் அதன் சொந்த Omarchy Package Repository இலிருந்து வரும் packages ஐ மட்டுமே நம்பியிருக்கிறது. நீங்கள் AUR இலிருந்து நேரடியாக மென்பொருளை நிறுவலாம், ஆனால் அடிப்படை நிறுவல் அவ்வாறு செய்வதில்லை — மூன்றாம் தரப்பு browsers போன்ற சில விருப்ப நிறுவல்கள் மட்டுமே AUR இலிருந்து பெறுகின்றன.
5. *Cloudflare எங்களை DDoS இலிருந்து பாதுகாக்கிறது*: Omarchy விநியோக உள்கட்டமைப்பு — ISOகள், Omarchy packages, Arch mirror — Cloudflare இன் வலிமையான DDoS கவசத்திற்குப் பின்னால் பாதுகாக்கப்பட்டு, அவர்களின் CDN இல் வழங்கப்படுகிறது. இது மிகச்சிறந்த கிடைக்கும்தன்மையை வழங்குகிறது.

## உங்கள் கடவுச்சொற்களை மாற்றுதல்

குறியாக்கம் செய்யப்பட்ட நிறுவலில் உங்களிடம் இரண்டு கடவுச்சொற்கள் உள்ளன: ஒன்று boot நேரத்தில் drive ஐத் திறக்கிறது, மற்றொன்று நீங்கள் உள்நுழையவும் `sudo` உடன் பயன்படுத்தவும் உதவுகிறது. அமைப்பு அவை இரண்டையும் ஒன்றாகவே வைக்கிறது. இரண்டையும் Omarchy மெனுவில் _புதுப்பிப்பு > கடவுச்சொல்_ என்பதன் கீழ் மாற்றலாம் — முதலாவதற்கு _வட்டு குறியாக்கம்_, இரண்டாவதற்கு _பயனர்_. வட்டுக் கடவுச்சொல்லை மாற்றுவது முதலில் தற்போதைய கடவுச்சொல்லைக் கேட்கும், எனவே அதைக் கையில் தயாராக வைத்திருங்கள். ஒரு மாற்றம் இடையில் தடைபட்டால், _வட்டு குறியாக்கத்தை_ மீண்டும் இயக்கவும்: அது இப்போது வட்டைத் திறக்கும் கடவுச்சொல்லைக் கேட்டு, மாற்றத்தை முடித்து வைக்கும்.

## நீங்கள் ஏற்கனவே பயன்படுத்திய ஒரு கணினியை வேறொருவரிடம் கொடுத்தல்

உங்கள் கணினியை வேறொருவரிடம் ஒப்படைக்கிறீர்கள் என்றால், அதை நீங்கள் மீண்டும் நிறுவ வேண்டியதில்லை. Omarchy மெனுவில் _அமைப்பு > கணினியை மீட்டமை_ என்பதை இயக்கவும், உறுதிப்படுத்த `reset` என்று தட்டச்சு செய்யவும், பின்னர் மீண்டும் தொடங்கவும். அது ஒவ்வொரு பயனர் கணக்கையும் `/home` இல் உள்ள அனைத்தையும் அழிக்கிறது, நிறுவியதிலிருந்து நீங்கள் செய்த அனைத்து packages மற்றும் system மாற்றங்களையும் தூக்கி எறிகிறது, மேலும் கணினியின் அடையாளத்தை — network connections, host keys, எல்லாவற்றையும் — நீக்குகிறது. மீண்டும் தொடங்குவது முதல் boot இலிருந்து வந்த அமைப்பு வழிகாட்டி ஆகும்; அதன் புதிய உரிமையாளர் தங்கள் சொந்தப் பெயர், கடவுச்சொல் மற்றும் குறியாக்கக் கடவுச்சொல்லை உள்ளிட அது தயாராக இருக்கும்.

இது நிறுவி எடுக்கும் அடிப்படை snapshot ஐ மீட்டமைப்பதன் மூலம் செயல்படுகிறது, எனவே இது Omarchy ISO இலிருந்து நிறுவப்பட்ட கணினிகளில் மட்டுமே கிடைக்கும். மேலும் குறியாக்கம் இல்லாத ஒரு வட்டில், மீட்டமைப்பு என்பது பாதுகாப்பான அழிப்பு அல்ல, வெறும் நீக்கம் மட்டுமே; எனவே தரவு முக்கியமானதாக இருந்தால், அதற்குப் பதிலாக ஒரு புதிய நிறுவலைச் செய்யவும்.

## கடவுச்சொல் இல்லாத sudo

சில நேரங்களில் `sudo` கேட்பதை நிறுத்த வேண்டும் என்று நீங்கள் விரும்புவீர்கள்; பெரும்பாலும் ஒரு AI agent உங்களுக்காக நீண்ட நேரம் system வேலையைச் செய்யும்போது இது நிகழும். _அமைப்பு > பாதுகாப்பு > கடவுச்சொல் இல்லாத Sudo_ எவ்வளவு நேரம் அணுகலை அனுமதிக்க வேண்டும் என்று கேட்கிறது: **15 நிமிடங்கள்**, **1 மணிநேரம்**, **1 நாள்**, அல்லது **நிரந்தரமாக**. அணுகல் செயலில் இருக்கும்போது மற்ற மெனு பட்டைக் குறிகாட்டிகளுக்கு அருகில் ஒரு சிவப்பு எச்சரிக்கைச் சின்னம் தோன்றும். அதைக் கிளிக் செய்யவும் அல்லது அணுகலை அணைக்க அந்தக் கட்டளையை மீண்டும் இயக்கவும். `omarchy-sudo-passwordless 30` உடன் உங்கள் சொந்த நிமிடங்களின் எண்ணிக்கையையும் (1 முதல் 1440 வரை) நீங்கள் வழங்கலாம், அல்லது `omarchy-sudo-passwordless permanent` ஐப் பயன்படுத்தலாம்.

நேரம் வரையறுக்கப்பட்ட அணுகல், காலக்கெடுவைத் தாண்டிய ஒரு suspend இலிருந்து மீண்டும் தொடங்கிய உடனேயே உட்பட, தானாகவே காலாவதியாகிவிடும். கணினியை மீண்டும் தொடங்குவது அதை முன்கூட்டியே முடித்துவிடும். நிரந்தர அணுகல் reboots இலும் நீடிக்கும், நீங்கள் அதை முடக்கும் வரை இயக்கப்பட்டே இருக்கும்.

Omarchy இன் settings package ஐப் புதுப்பிப்பது அல்லது அகற்றுவது, அதன் காலாவதி ஆதரவு மாறுவதற்கு முன்பே எந்தவொரு தற்காலிக அனுமதியையும் முடித்துவிடும். அந்தக் கட்டளை ஒரு அங்கீகாரம் அல்லது சுத்திகரிப்புப் பிழையைத் தெரிவித்தால், மற்றொரு அனுமதியை இயக்க முயற்சிக்கும் முன் அதைத் தீர்க்கவும்; ஒரு பிழை என்பது கடவுச்சொல் இல்லாத அணுகல் செயலற்று இருக்கிறது என்று அர்த்தமல்ல.

இதைப் பற்றித் தெளிவாக இருங்கள்: இது இயக்கத்தில் இருக்கும்போது, உங்கள் பயனராக இயங்கும் எதுவும் கேட்கப்படாமலேயே root ஆக எதையும் செய்ய முடியும். அதுதான் முழு நோக்கமும், அதுதான் முழு ஆபத்தும் கூட.

## கையொப்ப விசைகள்

அனைத்து ISO கையொப்பங்கள் மற்றும் Omarchy repo package க்கான பொது விசை `40DFB630FF42BCFFB047046CF0134EE680CAC571` ஆகும் ([openpgp.org இல் சரிபார்க்கவும்](https://keys.openpgp.org/search?q=pkgs%40omarchy.org)). `omarchy/omarchy-keyring` package இதையும் கொண்டுள்ளது, மேலும் எந்தவொரு சாத்தியமான புதுப்பிப்புகளையும் தடையின்றி வெளியிட இது பயன்படுத்தப்படும்.

எந்தவொரு ISO வெளியீட்டிற்கும், `https://iso.omarchy.org/omarchy-x.x.x.iso.sig` போல, அதன் URL இல் `.sig` ஐச் சேர்ப்பதன் மூலம் கையொப்பத்தை நீங்கள் கண்டறியலாம்.
