# Neovim

[Neovim](https://neovim.io/) என்பது 1976-இல் Bill Joy உருவாக்கிய [vi எடிட்டரின்](<https://en.wikipedia.org/wiki/Vi_(text_editor)>) நவீன செயலாக்கம். இது insert mode மற்றும் command mode தனித்தனியாகப் பிரிக்கப்பட்ட modal editor, நம்பமுடியாத அளவுக்கு ஆழமான key command தொகுப்பின் ஒரு சிறு பகுதியை மட்டும் நீங்கள் கற்றால்கூட அது ஒரு வகை superpower தான். ஆனால் கற்கும் வளைவும் அதற்கேற்ப செங்குத்தானது!

நீங்கள் vim-பாணி editing-க்கு முற்றிலும் புதியவர் என்றால், YouTube-இல் [ThePrimeagen-இன் Vim As Your Editor தொடரைப்](https://www.youtube.com/watch?v=X6AR2RMB5tE&list=PLm323Lc7iSW_wuxqmKx_xxNtJC_hJbQ7R) பார்க்க பரிந்துரைக்கிறேன். அது உங்களுக்கு அடிப்படைகளைக் கற்றுத்தரும். ஒன்றை மட்டும் தெரிந்துகொள்ளுங்கள்: அதிகம் போலவே இருக்கும் mainstream editor-களைப் போலன்றி, vim-இல் அடிப்படைத் தேர்ச்சி பெற உங்களுக்கு அதிக நேரம் எடுக்கும். ஆனால் ஒருமுறை கற்றுவிட்டால், பலனும் அதிகமாகவே இருக்கும்.

இப்போது Neovim அடிப்படையில் எல்லையின்றி configure செய்யக்கூடியது. உண்மையிலேயே முழு வீச்சில் இறங்க விரும்பினால், உங்கள் சொந்த Neovim configuration-ஐ புதிதாக உருவாக்கலாம். [புதிதாக Neovim-ஐ அமைப்பது குறித்த Typecraft-இன் சிறந்த பாடநெறி ஒன்று உள்ளது](https://www.youtube.com/watch?v=zHTeCSVAFNY). [ThePrimeagen-க்கும் ஒன்று உள்ளது](https://www.youtube.com/watch?v=w7i4amO_zaE).

ஆனால் Omarchy முழுமையான Neovim அமைப்புடன் வருகிறது — `omarchy-nvim` package — நீங்கள் ஒரு வரி configuration கூட எழுத வேண்டியதில்லாமல், box-இலிருந்து எடுத்தவுடனே சாத்தியமானவற்றில் சிறந்ததைக் காட்ட அன்புடன் நேர்த்தியாக்கப்பட்டது. இது Neovim plugin-கள் மற்றும் configuration-களின் distribution ஆன [LazyVim](https://www.lazyvim.org/) மீது கட்டமைக்கப்பட்டுள்ளது. இது அருமை.

## LazyVim அடிப்படைகள்

குறிப்பிட்டது போல, இந்தச் சிறு அறிமுகத்தில் நான் உங்களுக்கு vim கற்றுத்தரப் போவதில்லை, ஆனால் LazyVim-இன் சில அடிப்படைகளையும், எப்படி சுற்றி வருவது என்பதையும் காட்ட முடியும்.

முதலில், Neovim-இல் leader key என்ற கருத்து உள்ளது. அது அடிப்படையில் எல்லா command-களுக்குமான நுழைவாயில். LazyVim அதை `Space` என அமைத்துள்ளது. எனவே அதை அழுத்தி, ஒரு வினாடி காத்திருங்கள், இது போல inline-ஆக விளக்கப்பட்ட ஏராளமான option-களைக் காண்பீர்கள்:

நான் எப்போதும் பயன்படுத்தும் சில அடிப்படை command-கள் இங்கே:

- `Space Space` - தற்போதைய directory-இல் உள்ள எந்த file-ஐயும் Fuzzy-find செய்யவும்.
- `Space S G` - preview உடன் grep பயன்படுத்தி எல்லா file-களையும் தேடவும்.
- `Space E` - file tree-ஐக் காட்ட/மறைக்கவும்.
- `Ctrl + W W` - file tree-இலிருந்து editor-க்கும் திரும்பவும் தாவவும்.
- `Shift + H` - திறந்த tab-களுக்கு (vim அவற்றை buffers என்று அழைக்கிறது) இடையே இடதுபுறம் நகரவும்.
- `Shift + L` - திறந்த tab-களுக்கு இடையே வலதுபுறம் நகரவும்.
- `Space B D` - ஒரு tab-ஐ மூடவும்.
- `Space B O` - தற்போதையதைத் தவிர மற்ற எல்லா tab-களையும் மூடவும்.
- `Space G G` - தற்போதைய directory-இலிருந்து floating pane-இல் LazyGit-ஐத் தொடங்கவும்.
- `Space U W` - soft wrap-ஐ மாற்றவும்.

நீங்கள் file tree-இல் இருக்கும்போது (வெளிப்படுத்த `Space E`, அங்கே தாவ `Ctrl + W W`), `a` மூலம் புதிய file-ஐயோ அல்லது `A` மூலம் புதிய directory-ஐயோ சேர்க்கலாம். எல்லா command-களையும் காண tree-இல் இருக்கும்போது `?` அழுத்தவும்.

அடிப்படை vim மொழியைக் கற்றுக்கொள்ள விரும்பினால், [மூன்று பகுதி தொடரியல்](https://world.hey.com/dhh/wonderful-vi-a1d034d3) பற்றியும் அந்த அட்டகாசமான combo நகர்வுகளை எப்படிச் செய்வது என்பது பற்றியும் நான் எழுதியுள்ளேன்!

சாத்தியமான எல்லா command-களையும் [LazyVim Keymaps பக்கத்தில்](https://www.lazyvim.org/keymaps) காணலாம்.

## Neovim-ஐத் தொடங்குதல்

`Super + Shift + N` உங்கள் default editor-ஐத் தொடங்கும், புதிய நிறுவல்களில் அது Plain; அதற்குப் பதிலாக Neovim தொடங்க, _Setup > Defaults > Editor_ கீழ் Neovim-ஐத் தேர்ந்தெடுக்கவும். ஆனால் வழக்கமாக terminal-இலிருந்து இயக்குவதே எளிது: நீங்கள் வேலை செய்ய விரும்பும் directory-க்குச் சென்று `n` என type செய்யவும். `n` என்பது `nvim`-க்கான alias, அது default-ஆக தற்போதைய directory-ஐப் பயன்படுத்தித் திறக்கும். `n myfile.txt` மூலம் ஒற்றை file-ஐத் திறக்கலாம்.

## sudo திருத்தங்களுக்கு Neovim-ஐப் பயன்படுத்துதல்

super user ஆக மட்டுமே மாற்றக்கூடிய file-களைத் திருத்த வேண்டுமென்றால், `sudoedit /etc/sudoers.d/00-sudo-only-file` ஐ இயக்கவும். அது உங்கள் default editor-ஐத் திறக்கும், எனவே உங்கள் எல்லா plugin-களுடன் அங்கே Neovim வேண்டுமென்றால் _Setup > Defaults > Editor_ கீழ் Neovim-ஐ அமைக்கவும்.
