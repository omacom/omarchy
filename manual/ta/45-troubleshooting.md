# சிக்கல் தீர்த்தல்

### புதுப்பிப்பால் எனது அமைப்பை உடைத்துவிட்டேன்!

முதலில் உங்கள் சமீபத்திய புதுப்பிப்புக்கு முந்தைய பதிப்புக்கு [உங்கள் அமைப்பை மீட்டமைக்க](47-system-snapshots.md) முயற்சிக்கவும். அது வேலை செய்யவில்லை என்றால், Discord இல் #omarchy-help இல் உங்கள் சிக்கலைப் பகிர `omarchy-debug` ஐப் பயன்படுத்தவும். அவை அனைத்தும் தோல்வியடைந்தால், `omarchy-reinstall` ஐப் பயன்படுத்தி இயல்புநிலை உள்ளமைவுகளையும் தொகுப்புகளையும் மீண்டும் நிறுவலாம்.

### எனது திரையில் சில செயலிகள் ஏன் இவ்வளவு பெரிதாகத் தெரிகின்றன?

Omarchy 2x உயர் தெளிவுத்திறன் திரையை எதிர்பார்க்கிறது, இதற்கு `~/.config/hypr/monitors.lua` இல் `GDK_SCALE` ஐ 2 ஆக அமைக்க வேண்டும். ஆனால் நீங்கள் 1x திரையில் இருந்தால், `local omarchy_gdk_scale = 2` ஐ 1 ஆக மாற்றலாம் (பின்னர் மிகப் பெரிதாகத் தெரியும் எந்தச் செயலியையும் மறுதொடக்கம் செய்யவும்). [monitors பற்றிய கையேட்டைப்](33-monitors.md) பார்க்கவும்.

Spotify க்கு, UI ஐச் சுருக்க `Ctrl + Minus` ஐப் பயன்படுத்தலாம் (பெரிதாக்க `Ctrl + Plus`).

### எனது Super key binds அனைத்தும் ஏன் வேலை செய்வதை நிறுத்திவிட்டன?

சில ASUS ROG மற்றும் TUF மடிக்கணினிகளில், `Fn + Super` என்பது கவனிக்கத் தவற எளிதான ஒரு கலவையாகும், இது firmware Windows-key lock ஐ மாற்றுகிறது (விளையாடும்போது தற்செயலாக விளையாட்டிலிருந்து வெளியேறாமல் இருக்க வடிவமைக்கப்பட்டது). அது நடந்தது என்று திரையில் எதுவும் உங்களுக்குச் சொல்லாது. lock இயக்கத்தில் இருக்கும்போது, Super எதையும் வெளியிடாது — எனவே Super ஐப் பயன்படுத்தும் ஒவ்வொரு Omarchy bind உம் நின்றுவிடும், Hyprland உடைந்துவிட்டது போல் தோன்றும்.

`~/.config/hypr/` க்குள் தேடுவதற்கு முன் `Fn + Super` ஐ ஒருமுறை அழுத்தவும், அது Super ஐத் திரும்பக் கொண்டுவரவில்லை என்றால், lock ஐ இயக்கத்தில் விட்டுவிடாமல் இருக்க மீண்டும் அதை அழுத்தவும். இது Fn-lock அல்ல, அது F-key வரிசை என்ன செய்கிறது என்பதை மட்டுமே மாற்றுகிறது.

### எனது Wi-Fi, Bluetooth, audio, அல்லது trackpad திடீரென வேலை செய்வதை நிறுத்திவிட்டது

மறுதொடக்கம் செய்வதற்கு முன், பாதிக்கப்பட்ட துணை அமைப்பை மட்டும் தனியாக மறுதொடக்கம் செய்ய முயற்சிக்கவும். Omarchy menu இல் உள்ள _Update > Hardware_ இல் Wi-Fi, Bluetooth, Audio, மற்றும் Trackpad உள்ளன, அவற்றில் ஒன்றை மீண்டும் ஏற்றுவது பெரும்பாலான "ஐந்து நிமிடங்களுக்கு முன் வேலை செய்தது" சூழ்நிலைகளைத் தீர்க்கிறது — மீண்டும் இணைக்க மறுக்கும் Bluetooth headset, suspend க்குப் பிறகு செயலிழந்த trackpad, monitor ஐத் துண்டித்தபோது மறைந்த ஒலி.

### எனது வெளிப்புற speakers ஏன் ஒலிக்கவில்லை?

அநேகமாக அவை முதன்மை வெளியீடாக அமைக்கப்படாததால் இருக்கலாம். bar இன் வலது பக்கத்தில் உள்ள speaker icon ஐக் கிளிக் செய்யவும், அது volume popup ஐத் திறக்கும், அங்கு நீங்கள் வெளியீட்டு சாதனத்தைத் தேர்ந்தெடுக்கலாம் (செயலி வாரியான ஒலியளவுகளையும் கலக்கலாம்).

### எனது மடிக்கணினி speakers ஒலி வித்தியாசமாக இருக்கிறது

சில மடிக்கணினிகளில், உள்ளமைக்கப்பட்ட speakers இன் frequency response ஐச் சரிசெய்யும் speaker tuning ஐ Omarchy தானாகவே பயன்படுத்துகிறது. உங்கள் கணினியில் ஒன்று செயலில் உள்ளதா என்பதை `omarchy audio tuning status` உங்களுக்குச் சொல்லும், speakers இன் இயல்பான ஒலியைக் கேட்க விரும்பினால் `omarchy audio tuning off` அதை அணைக்கும்.

### எனது கடவுச்சொல்லால் ஏன் login அல்லது sudo செய்ய முடியவில்லை?

அநேகமாக நீங்கள் அதை பலமுறை தவறாகத் தட்டச்சு செய்து பூட்டப்பட்டிருக்கலாம். இது lock screen இல் நடந்தால், புதிய TTY ஐத் தொடங்க `CTRL + ALT + F2` ஐ அழுத்தலாம், அங்கு root ஆக login செய்யலாம், பின்னர் `faillock --reset --user [your-username]` ஐ இயக்கவும். அது lockout ஐ மீட்டமைக்கும், நீங்கள் தொடரலாம்.

### 1Password SSH Agent / CLI க்கான எனது 1Password அங்கீகாரத் தூண்டல்கள் ஏன் தோன்றவில்லை?

இது 2 காரணங்களால் நடக்கலாம்:

வளமான ஒப்புதல் தூண்டல் தோன்ற, Settings > Advanced > Use Hardware Acceleration இயக்கப்பட்டிருக்க வேண்டும். _குறிப்பு: இது வேலை செய்யத் தொடங்க மறுதொடக்கம் தேவை._

 ![troubleshooting-1password](images/troubleshooting-1password.webp)

அல்லது தொடங்கியதிலிருந்து 1Password ஐத் தொடங்கவில்லை என்றால், தூண்டல் தோன்றாது.
