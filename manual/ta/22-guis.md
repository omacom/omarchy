# GUIகள்

## Files

Files (Nautilus) என்பது வரைகலை கோப்பு மேலாளர். `Super + Shift + F` இதைத் திறக்கும், மேலும் `Super + Shift + Alt + F` உங்கள் terminal உள்ள directory-இல் இதைத் திறக்கும், இது நிறைய சொடுக்குவதை மிச்சப்படுத்தும். `Ctrl + L` ஒரு path-ஐ தட்டச்சு செய்ய உங்களை அனுமதிக்கிறது, மேலும் எந்தவொரு கோப்பிலும் `Space` அழுத்தினால் எதையும் திறக்காமல் விரைவான முன்னோட்டம் கிடைக்கும்.

USB stick அல்லது SD card-ஐ செருகினால் அது தானாகவே mount செய்யப்படும், எனவே அது பக்கப்பட்டியில் வெறுமனே தோன்றும். இன்னும் சிக்கலான எதற்கும் — drive-ஐ format செய்வது, SMART ஆரோக்கியத்தைச் சரிபார்ப்பது, partitionகளை உருவாக்குவது — app launcher-இலிருந்து (`Super + Space`) _Disks_ ஐ இயக்குங்கள்.

இருமுறை சொடுக்குவது புத்திசாலித்தனமான இயல்புநிலைகளைப் பின்பற்றுகிறது: படங்கள், வீடியோக்கள் மற்றும் இசை Omaview-இல் திறக்கும், PDFகள் Document Viewer-இல், Markdown Omawrite-இல், மற்றும் எளிய உரை _Setup > Default > Editor_ இன் கீழ் தேர்ந்தெடுக்கப்பட்ட editor-இல் திறக்கும்.

## Disktree

drive நிரம்பும்போது அதை என்ன தின்றுகொண்டிருக்கிறது என்று உங்களுக்குத் தெரியாதபோது, app launcher-இலிருந்து (`Super + Space`) [Disktree](https://github.com/tobi/disktree) ஐ இயக்குங்கள். இது உங்கள் home directory-இன் வரைகலை treemap-ஐக் காட்டுகிறது. பெரிய தொகுதிகள் அதிக இடத்தை எடுக்கும்; keyboard அல்லது mouse கொண்டு directoryகளுக்குள் செல்லுங்கள், எவை போகவேண்டும் என்று குறியுங்கள், மேலும் எதையும் அகற்றுவதற்கு முன் உங்கள் தேர்வுகளை மதிப்பாய்வு செய்யுங்கள். முழு disk-ஐயும் scan செய்ய `disktree --disk` ஐ இயக்குங்கள்.

## Obsidian

[Obsidian](https://obsidian.md/) என்பது சேமிப்பிற்கு எளிய Markdown கோப்புகளைப் பயன்படுத்தும் இலவச மற்றும் மிகவும் விரிவாக்கக்கூடிய குறிப்பு எடுக்கும் பயன்பாடு.

Obsidian தனிப்பட்ட, வணிக மற்றும் இலாப நோக்கற்ற பயன்பாடு உட்பட அனைத்து நோக்கங்களுக்கும் இலவசம்.

Obsidian iOS மற்றும் Android-இல் உள்ள mobile appகளுடன் ஒத்திசைப்பதற்கான [வணிக கூடுதல் வசதியையும்](https://obsidian.md/sync) வழங்குகிறது. (https://obsidian.md/pricing).

நீங்கள் `Super + Shift + O` கொண்டு Obsidian-ஐத் தொடங்குகிறீர்கள். theme ஒத்திசைவைப் பயன்படுத்த, settings-இன் கீழ் `Omarchy` theme-ஐத் தேர்ந்தெடுக்க வேண்டும்.

## Omawrite

[Omawrite](https://github.com/omacom-io/omawrite) என்பது Omarchy-இன் சொந்த மிக எளிமையான Markdown எழுதும் app. vaultகள் இல்லை, pluginகள் இல்லை, வெறும் நீங்களும் வார்த்தைகளும் மட்டுமே.

நீங்கள் `Super + Shift + W` கொண்டு Omawrite-ஐத் தொடங்குகிறீர்கள்.

## Pinta

[Pinta](https://www.pinta-project.com/) என்பது cropping, resizing மற்றும் பிற அடிப்படை கையாளுதல்களுக்கு சிறந்த அடிப்படை படத் திருத்தக் கருவி. Photoshop மாற்றை மட்டும் எதிர்பார்க்காதீர்கள். ஆனால் இதில் இன்னும் Magic Wand மற்றும் layerகள் உள்ளன!

நீங்கள் application launcher (`Super + Space`) வழியாக Pinta-வைத் தொடங்குகிறீர்கள்.

## Aether

[Aether](https://github.com/bjarneo/aether) என்பது ஒரு பின்னணிப் படத்திலிருந்து வண்ணங்களைப் பிரித்தெடுத்து அவற்றை முழுமையான, ஒத்திசைவான theme ஆக மாற்றக்கூடிய theming பயன்பாடு. [உங்கள் சொந்த theme-ஐ உருவாக்க](43-making-your-own-theme.md) இதுவே எளிதான வழி.

நீங்கள் application launcher (`Super + Space`) வழியாக Aether-ஐத் தொடங்குகிறீர்கள்.

## LocalSend

[LocalSend](https://localsend.org/) Apple-இன் AirDrop போல, அதே network-இல் app-ஐ இயக்கும் பிற சாதனங்களுக்கு கோப்புகளை அனுப்ப உங்களை அனுமதிக்கிறது. ஆனால் இது cross-platform, எனவே நீங்கள் Windows, macOS, Android, iOS மற்றும் நிச்சயமாக Linux-க்கு இடையே கோப்புகளை அனுப்பலாம் மற்றும் பெறலாம்.

நீங்கள் `Super + Ctrl + S` இல் அல்லது Omarchy menu-இல் _Trigger > Share_ இன் கீழ் Share menu-வைத் திறக்கலாம். இது உங்களுக்கு நான்கு விருப்பங்களை வழங்குகிறது:

- **Clipboard** நீங்கள் நகலெடுத்ததை ஒரு உரைக் கோப்பாக அனுப்புகிறது. உங்களுக்கே மின்னஞ்சல் அனுப்பாமல் ஒரு link அல்லது ஒரு துணுக்கை உங்கள் phone-இல் கொண்டுசெல்ல சிறந்தது.
- **File** நீங்கள் ஒரே நேரத்தில் பலவற்றைத் தேர்ந்தெடுக்கக்கூடிய file picker-ஐத் திறக்கிறது.
- **Folder** முழு directory-ஐயும் அனுப்புகிறது.
- **Receive** LocalSend-ஐயே திறக்கிறது, இதனால் மற்றொரு சாதனம் உங்களுக்கு ஏதாவது அனுப்ப முடியும்.

terminal-இலிருந்தும் அதே விஷயம் `omarchy share clipboard`, `omarchy share file [path]` மற்றும் `omarchy share folder [path]` கொண்டு செயல்படுகிறது. path-ஐ விட்டுவிட்டால் picker கிடைக்கும்.

file manager-இலிருந்தும் நேரடியாக அனுப்பலாம்: Nautilus-இல் எந்தத் தேர்வின் மீதும் வலது சொடுக்கு செய்து _Send via LocalSend_ ஐத் தேர்ந்தெடுக்கவும்.

Omarchy-இன் firewall இயல்பாகவே LocalSend-இன் port-ஐத் தவிர மூடப்பட்டிருக்கும், எனவே இது புதிய நிறுவலில் அப்படியே செயல்படும். [பாதுகாப்பு](48-security.md) ஐப் பார்க்கவும்.

## LibreOffice

[LibreOffice](https://www.libreoffice.org/) என்பது word processor, spreadsheet, presentations, drawing application மற்றும் பலவற்றுடன் கூடிய முழுமையான office தொகுப்பு. இது Microsoft Office கோப்புகளுடன் இணக்கமானது, எனவே அந்த Word documentகளைத் திறக்க முடிய இது சிறந்த வழி.

நீங்கள் application launcher (`Super + Space`) வழியாக LibreOffice-ஐத் தொடங்குகிறீர்கள்.

## Hype

[Hype](https://github.com/omacom/hype) என்பது Omarchy-இன் சொந்த மிக எளிமையான presentation app. உங்கள் deck என்பது அதன் படங்கள் மற்றும் வீடியோக்கள் அருகில் உள்ள ஒற்றை Markdown கோப்பு: நேரடி முன்னோட்டத்தின் கீழ் ஒவ்வொரு slide-ஐயும் எழுதுங்கள், slideகளை வரிசைக்கு இழுக்கவும், பின்னர் fullscreen-இல் வழங்கவும் அல்லது PDF மற்றும் PowerPoint-க்கு ஏற்றுமதி செய்யவும். இது உங்கள் Omarchy theme-ஐக் கூட எடுத்துக்கொள்கிறது.

நீங்கள் application launcher (`Super + Space`) வழியாக Hype-ஐத் தொடங்குகிறீர்கள். ஒவ்வொரு shortcut-ஐயும் பார்க்க அதற்குள் `?` அழுத்தவும்.

## Signed

[Signed](https://github.com/omacom/signed) என்பது PDFகளில் கையொப்பமிடவும் அவற்றை நிரப்பவும் Omarchy-இன் சொந்த மிக எளிமையான வழி. உங்கள் சேமித்த கையொப்பம், உரை மற்றும் இன்றைய தேதியை ஒரு பக்கத்தில் எங்கும் வைத்து, பின்னர் அசலின் அருகில் கையொப்பமிட்ட நகலைச் சேமிக்கவும். எப்படி என்பதற்கு [PDFகளை நிரப்புதல்](27-filling-out-pdfs.md) ஐப் பார்க்கவும்.

நீங்கள் application launcher (`Super + Space`) வழியாக Signed-ஐத் தொடங்குகிறீர்கள், அல்லது file manager-இலிருந்து அதைக் கொண்டு PDF-ஐத் திறக்கவும்.

## Checkmate

[Checkmate](https://github.com/omacom/checkmate) என்பது Omarchy-இன் சொந்த 3D chess விளையாட்டு. அதே கணினியில் ஒரு நண்பருடன் அல்லது மூன்று நிலைகளில் உள்ளமைக்கப்பட்ட எதிராளியுடன், ஒவ்வொன்றும் தனது சொந்த முறையில் நகரும் நான்கு செதுக்கப்பட்ட தொகுப்புகளில் விளையாடுங்கள்: orbital craft, செதுக்கப்பட்ட மரம் மற்றும் தந்தம், காட்டு உயிரினங்கள் மற்றும் மிட்டாய். விளையாட்டுகளுக்கு clock இல்லை மற்றும் ஒவ்வொரு நகர்வுக்குப் பிறகும் சேமிக்கப்படும்.

நீங்கள் application launcher (`Super + Space`) வழியாக Checkmate-ஐத் தொடங்குகிறீர்கள், அங்கு இது Chess எனப் பட்டியலிடப்பட்டுள்ளது. ஒவ்வொரு shortcut-ஐயும் பார்க்க அதற்குள் `?` அழுத்தவும்.

## Cards

[Cards](https://github.com/omacom/cards) என்பது Omarchy-இன் சொந்த Klondike solitaire. மூன்றை எடுங்கள், passகளுக்கு வரம்பு இல்லை, நான்கு card தொடர்களில்: ஒன்று உங்கள் theme-இன் வண்ணங்களில் வரையப்பட்டது, மற்றும் மூன்று தமக்கென தனித் தோற்றத்துடன். ஒரு card-ஐச் சொடுக்கி பின்னர் அது எங்கு செல்கிறதோ அங்கு சொடுக்கவும், அதை இழுக்கவும், அல்லது சிறந்த இடத்திற்கு அனுப்ப இருமுறை சொடுக்கவும். விளையாட்டுகள் ஒவ்வொரு நகர்வுக்குப் பிறகும் சேமிக்கப்படும்.

நீங்கள் application launcher (`Super + Space`) வழியாக Cards-ஐத் தொடங்குகிறீர்கள். ஒவ்வொரு shortcut-ஐயும் பார்க்க அதன் பெயரைச் சொடுக்கவும், அல்லது `?` அழுத்தவும்.

## Omacalc

[Omacalc](https://github.com/omacom-io/omacalc) என்பது Omarchy-இன் சொந்த மிக எளிமையான calculator, இது மிதக்கும் சாளரத்தில் திறக்கும்.

நீங்கள் `Super + Shift + Q` கொண்டு Omacalc-ஐத் தொடங்குகிறீர்கள் (அல்லது உங்கள் keyboard-இல் ஒன்று இருந்தால் calculator key).

## Signal

[Signal](https://signal.org/) என்பது E2E encrypted செய்தியனுப்பலின் முன்னோடி, மேலும் பெரிய tech குழுமங்களில் ஒன்றின் வழியாகச் செல்ல விரும்பாத எவருக்கும் சிறந்த தகவல்தொடர்பு விருப்பம்.

நீங்கள் `Super + Shift + G` கொண்டு Signal-ஐத் தொடங்குகிறீர்கள். இது அடிப்படை நிறுவலின் ஒரு பகுதி அல்ல, எனவே நீங்கள் முதல் முறை அதை அழுத்தும்போது, Omarchy அதை உங்களுக்காக நிறுவ முன்வரும் (இது Omarchy menu-இல் _Install > Service_ இன் கீழும் உள்ளது).

## Omaview

[Omaview](https://github.com/omacom/omaview) என்பது Omarchy-இன் சொந்த மிக எளிமையான படக் காட்சியாளர் மற்றும் media player: உங்கள் புகைப்படங்கள், வீடியோக்கள் மற்றும் இசைக்கான ஒரே சாளரம். ஒரு புகைப்படத்தைத் திறந்தால் arrow keyகள் அதன் folder-இன் மீதமுள்ளவற்றின் வழியாகப் படிப்படியாகச் செல்லும், `N` மற்றும் `P` எதற்கும் அதையே செய்யும், மற்றும் `Ctrl + M` முழு folder-ஐயும் grid ஆகக் காட்டுகிறது. இது HEIC, AVIF மற்றும் JPEG XL புகைப்படங்களையும் காட்டுகிறது, மேலும் நீண்ட எதிலும் நீங்கள் விட்ட இடத்திலிருந்து தொடர்கிறது.

fullscreen-க்கு `F`, ஒரு படத்தை Omasnap-இல் திருத்த அல்லது வீடியோவை Omacut-இல் trim செய்ய `E`, ஒரு படத்தை அச்சிட `Ctrl + P`, மற்றும் ஒரு கோப்பை Trash-க்கு நகர்த்த `Delete` அழுத்தவும் (`Ctrl + Z` அதை மீண்டும் கொண்டுவரும்). ஒவ்வொரு shortcut-ஐயும் பார்க்க அதற்குள் `?` அழுத்தவும்.

நீங்கள் application launcher (`Super + Space`) வழியாக _Media Viewer_ ஆக Omaview-வைத் தொடங்குகிறீர்கள், அல்லது file manager-இல் ஒரு படம், வீடியோ அல்லது பாடலை வெறுமனே இருமுறை சொடுக்கவும்.

## Omacut

[Omacut](https://github.com/omacom-io/omacut) என்பது Omarchy-இன் சொந்த மிக எளிமையான video trimmer. ஒரு clip-இன் தொடக்கத்தையும் முடிவையும் வெட்டுவது மட்டுமே உங்களுக்குத் தேவைப்படும்போது, முழு video editor-ஐ இயக்குவதை விட இது மேலானது.

நீங்கள் application launcher (`Super + Space`) வழியாக Omacut-ஐத் தொடங்குகிறீர்கள்.

## Monologue

[Monologue](https://github.com/omacom/monologue) என்பது Omarchy-இன் சொந்த மிக எளிமையான webcam recorder. உங்கள் camera மற்றும் microphone-ஐ ஒருமுறை தேர்ந்தெடுங்கள், பின்னர் பதிவு செய்ய `Space` அழுத்தவும், மீண்டும் அதே take-ஐ இடைநிறுத்தி மீண்டும் தொடங்கவும். இது எப்போதும் உங்கள் camera-இன் மிக உயர்ந்த resolution-இல் பதிவு செய்கிறது, நீங்கள் தொடங்குவதற்கு முன் உங்கள் levelகளைச் சரிபார்க்க நேரடி microphone meter உடன்.

take-ஐ நிறுத்தினால் இது உள்ளமைக்கப்பட்ட editor-இல் உடனடியாகத் திறக்கும். ஒரு clip-ஐப் பிரிக்க அதை இருமுறை சொடுக்கவும், ஒவ்வொரு துண்டையும் trim செய்ய handleகளை இழுக்கவும், மற்றும் உங்களுக்கு வேண்டாத பகுதிகளை அகற்றவும். பின்னர் அதை MP4 ஆகச் சேமிக்கவும். உங்கள் அசல் பதிவு நீங்கள் அதை நிராகரிக்கும் வரை வைக்கப்படும், எனவே நீங்கள் எப்போதும் திரும்பி வந்து அதை வேறுவிதமாக வெட்டலாம்.

நீங்கள் application launcher (`Super + Space`) வழியாக Monologue-ஐத் தொடங்குகிறீர்கள்.
