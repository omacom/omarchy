# GUIs

## Files

Files (Nautilus) தான் வரைகலை கோப்பு மேலாளர். `Super + Shift + F` அதைத் திறக்கும், உங்கள் terminal தற்போது இருக்கும் கோப்பகத்தில் அதை `Super + Shift + Alt + F` திறக்கும்; இது நிறைய கிளிக்குகளை மிச்சப்படுத்தும். `Ctrl + L` ஒரு பாதையைத் தட்டச்சு செய்ய உங்களை அனுமதிக்கும், எந்தக் கோப்பின் மீதும் `Space` ஐ அழுத்தினால் எதையும் திறக்காமலேயே விரைவான முன்னோட்டம் கிடைக்கும்.

ஒரு USB stick அல்லது SD card ஐச் செருகினால் அது தானாகவே மவுண்ட் செய்யப்படும், எனவே அது பக்கப்பட்டியில் அப்படியே தோன்றும். இதைவிடச் சிக்கலான வேலைகளுக்கு — ஒரு டிரைவை ஃபார்மட் செய்வது, SMART ஆரோக்கியத்தைச் சரிபார்ப்பது, பகிர்வுகளை உருவாக்குவது — app launcher (`Super + Space`) இலிருந்து _Disks_ ஐ இயக்கவும்.

இருமுறை கிளிக் செய்வது நியாயமான இயல்புநிலைகளைப் பின்பற்றுகிறது: படங்கள், வீடியோக்கள் மற்றும் இசை Omaview இல் திறக்கும், PDFகள் Document Viewer இல் திறக்கும், Markdown Omawrite இல் திறக்கும், சாதாரண உரை _Setup > Default > Editor_ இன் கீழ் தேர்ந்தெடுக்கப்பட்ட எடிட்டரில் திறக்கும்.

## Disktree

டிரைவ் நிரம்பிவிட்டபோது, எது அதைத் தின்றுகொண்டிருக்கிறது என்று உங்களுக்குத் துளியும் தெரியாதபோது, app launcher (`Super + Space`) இலிருந்து [Disktree](https://github.com/tobi/disktree) ஐ இயக்கவும். இது உங்கள் முகப்புக் கோப்பகத்தின் வரைகலை ட்ரீமேப்பைக் காட்டுகிறது. பெரிய தொகுதிகள் அதிக இடத்தை எடுக்கும்; விசைப்பலகை அல்லது சுட்டியால் கோப்பகங்களுக்குள் செல்லவும், போக வேண்டியவற்றைக் குறிக்கவும், எதையும் நீக்கும் முன் உங்கள் தேர்வுகளை மதிப்பாய்வு செய்யவும். முழு டிஸ்க்கையும் ஸ்கேன் செய்ய `disktree --disk` ஐ இயக்கவும்.

## Obsidian

[Obsidian](https://obsidian.md/) என்பது சேமிப்பிற்கு எளிய Markdown கோப்புகளைப் பயன்படுத்தும், இலவசமான மற்றும் மிகவும் நீட்டிக்கக்கூடிய குறிப்பு எடுக்கும் பயன்பாடு.

தனிப்பட்ட, வணிக மற்றும் இலாப நோக்கற்ற பயன்பாடு உட்பட அனைத்து நோக்கங்களுக்கும் Obsidian இலவசம்.

Obsidian, iOS மற்றும் Android இல் உள்ள மொபைல் பயன்பாடுகளுடன் ஒத்திசைப்பதற்கான [வணிகக் கூடுதல் அம்சத்தையும்](https://obsidian.md/sync) வழங்குகிறது. (https://obsidian.md/pricing).

நீங்கள் Obsidian ஐ `Super + Shift + O` கொண்டு தொடங்குவீர்கள். தீம் ஒத்திசைவைப் பயன்படுத்த, அமைப்புகளின் கீழ் `Omarchy` தீமைத் தேர்ந்தெடுக்க வேண்டும்.

## Omawrite

[Omawrite](https://github.com/omacom-io/omawrite) என்பது Omarchy இன் சொந்த, மிக எளிய Markdown எழுதும் பயன்பாடு. வால்ட்டுகள் இல்லை, செருகுநிரல்கள் இல்லை, நீங்களும் வார்த்தைகளும் மட்டுமே.

நீங்கள் Omawrite ஐ `Super + Shift + W` கொண்டு தொடங்குவீர்கள்.

## Pinta

[Pinta](https://www.pinta-project.com/) என்பது வெட்டுவதற்கும், அளவை மாற்றுவதற்கும், பிற அடிப்படை மாற்றங்களுக்கும் சிறந்த ஒரு அடிப்படைப் படத் திருத்தக் கருவி. Photoshop க்கு மாற்றாக இருக்கும் என்று மட்டும் எதிர்பார்க்காதீர்கள். ஆனால் இதில் இன்னும் Magic Wand உம் அடுக்குகளும் உள்ளன!

நீங்கள் Pinta வை application launcher (`Super + Space`) வழியாகத் தொடங்குவீர்கள்.

## Aether

[Aether](https://github.com/bjarneo/aether) என்பது ஒரு பின்னணிப் படத்திலிருந்து வண்ணங்களைப் பிரித்தெடுத்து, அவற்றை முழுமையான, ஒத்திசைவான தீமாக மாற்றக்கூடிய ஒரு தீமிங் பயன்பாடு. [உங்கள் சொந்த தீமை உருவாக்குவதற்கான](43-making-your-own-theme.md) எளிதான வழி இதுவே.

நீங்கள் Aether ஐ application launcher (`Super + Space`) வழியாகத் தொடங்குவீர்கள்.

## LocalSend

[LocalSend](https://localsend.org/) அதே நெட்வொர்க்கில் இந்தப் பயன்பாட்டை இயக்கும் பிற சாதனங்களுக்குக் கோப்புகளை அனுப்ப உங்களை அனுமதிக்கிறது, Apple இன் AirDrop போல. ஆனால் இது பல தளங்களில் இயங்கக்கூடியது, எனவே நீங்கள் Windows, macOS, Android, iOS மற்றும் நிச்சயமாக Linux ஆகியவற்றுக்கு இடையே கோப்புகளை அனுப்பலாம்.

நீங்கள் Share மெனுவை `Super + Ctrl + S` இல் அல்லது Omarchy மெனுவில் _Trigger > Share_ இன் கீழ் திறக்கலாம். இது உங்களுக்கு நான்கு விருப்பங்களைத் தருகிறது:

- **Clipboard** நீங்கள் நகலெடுத்த எதையும் ஒரு உரைக் கோப்பாக அனுப்புகிறது. உங்களுக்கே மின்னஞ்சல் அனுப்பாமல் ஒரு இணைப்பையோ அல்லது ஒரு துணுக்கையோ உங்கள் தொலைபேசிக்குக் கொண்டு செல்லச் சிறந்தது.
- **File** நீங்கள் ஒரே நேரத்தில் பலவற்றைத் தேர்ந்தெடுக்கக்கூடிய ஒரு கோப்புத் தேர்வியைத் திறக்கிறது.
- **Folder** ஒரு முழுக் கோப்பகத்தையும் அனுப்புகிறது.
- **Receive** LocalSend ஐ முறையாகத் திறக்கிறது, இதன் மூலம் மற்றொரு சாதனம் உங்களுக்கு எதையாவது அனுப்ப முடியும்.

இதே வேலையை terminal இலிருந்து `omarchy share clipboard`, `omarchy share file [path]` மற்றும் `omarchy share folder [path]` கொண்டும் செய்யலாம். பாதையை விட்டுவிட்டால் தேர்வி கிடைக்கும்.

கோப்பு மேலாளரிலிருந்தும் நீங்கள் நேரடியாக அனுப்பலாம்: Nautilus இல் எந்தத் தேர்வின் மீதும் வலது கிளிக் செய்து _Send via LocalSend_ ஐத் தேர்ந்தெடுக்கவும்.

Omarchy இன் ஃபயர்வால் LocalSend இன் போர்ட்டைத் தவிர இயல்பாகவே மூடப்பட்டிருக்கும், எனவே புதிய நிறுவலில் இது அப்படியே வேலை செய்யும். [பாதுகாப்பைப்](48-security.md) பார்க்கவும்.

## LibreOffice

[LibreOffice](https://www.libreoffice.org/) என்பது சொல் செயலி, விரிதாள், விளக்கக்காட்சிகள், வரைதல் பயன்பாடு மற்றும் பலவற்றைக் கொண்ட ஒரு முழுமையான அலுவலகத் தொகுப்பு. இது Microsoft Office இன் கோப்புகளுடன் இணக்கமானது, எனவே அந்த Word ஆவணங்களைத் திறக்க முடிவதற்கு இது ஒரு சிறந்த வழி.

நீங்கள் LibreOffice ஐ application launcher (`Super + Space`) வழியாகத் தொடங்குவீர்கள்.

## Hype

[Hype](https://github.com/omacom/hype) என்பது Omarchy இன் சொந்த, மிக எளிய விளக்கக்காட்சிப் பயன்பாடு. உங்கள் டெக் என்பது அதன் படங்களும் வீடியோக்களும் அருகில் இருக்கும் ஒற்றை Markdown கோப்பு: நேரடி முன்னோட்டத்தின் கீழ் ஒவ்வொரு ஸ்லைடையும் எழுதவும், ஸ்லைடுகளை வரிசைக்கு இழுக்கவும், பின்னர் முழுத்திரையில் வழங்கவும் அல்லது PDF மற்றும் PowerPoint க்கு ஏற்றுமதி செய்யவும். இது உங்கள் Omarchy தீமையும் எடுத்துக்கொள்ளும்.

நீங்கள் Hype ஐ application launcher (`Super + Space`) வழியாகத் தொடங்குவீர்கள். ஒவ்வொரு குறுக்குவழியையும் காண அதற்குள் `?` ஐ அழுத்தவும்.

## Signed

[Signed](https://github.com/omacom/signed) என்பது PDFகளில் கையொப்பமிடவும் அவற்றை நிரப்பவும் Omarchy இன் சொந்த, மிக எளிய வழி. உங்கள் சேமித்த கையொப்பம், உரை மற்றும் இன்றைய தேதியை ஒரு பக்கத்தில் எங்கு வேண்டுமானாலும் வைக்கவும், பின்னர் அசலுக்கு அருகில் கையொப்பமிட்ட நகலைச் சேமிக்கவும். எப்படி என்பதற்கு [PDFகளை நிரப்புவதைப](27-filling-out-pdfs.md) பார்க்கவும்.

நீங்கள் Signed ஐ application launcher (`Super + Space`) வழியாகத் தொடங்குவீர்கள், அல்லது கோப்பு மேலாளரிலிருந்து ஒரு PDF ஐ அதைக் கொண்டு திறப்பீர்கள்.

## Checkmate

[Checkmate](https://github.com/omacom/checkmate) என்பது Omarchy இன் சொந்த 3D சதுரங்க விளையாட்டு. ஒரே கணினியில் ஒரு நண்பருடன் அல்லது மூன்று நிலைகளில் உள்ள உள்ளமைக்கப்பட்ட எதிராளியுடன் விளையாடவும், ஒவ்வொன்றும் தனக்கே உரிய முறையில் நகரும் நான்கு செதுக்கப்பட்ட தொகுப்புகளில்: சுற்றுப்பாதை விண்கலங்கள், செதுக்கிய மரமும் தந்தமும், காட்டுயிரிகள் மற்றும் மிட்டாய். விளையாட்டுகளுக்குக் கடிகாரம் இல்லை, ஒவ்வொரு நகர்வுக்குப் பிறகும் அவை சேமிக்கப்படும்.

நீங்கள் Checkmate ஐ application launcher (`Super + Space`) வழியாகத் தொடங்குவீர்கள், அங்கு அது Chess என்று பட்டியலிடப்பட்டிருக்கும். ஒவ்வொரு குறுக்குவழியையும் காண அதற்குள் `?` ஐ அழுத்தவும்.

## Omacalc

[Omacalc](https://github.com/omacom-io/omacalc) என்பது மிதக்கும் சாளரத்தில் திறக்கும் Omarchy இன் சொந்த, மிக எளிய கணிப்பான்.

நீங்கள் Omacalc ஐ `Super + Shift + Q` கொண்டு தொடங்குவீர்கள் (அல்லது உங்கள் விசைப்பலகையில் கணிப்பான் விசை இருந்தால் அதைக் கொண்டு).

## Signal

[Signal](https://signal.org/) என்பது E2E குறியாக்கம் செய்யப்பட்ட செய்தியனுப்பலின் முன்னோடி, பெரிய தொழில்நுட்ப நிறுவனக் கூட்டமைப்புகளில் ஒன்றின் வழியாகச் செல்ல விரும்பாத எவருக்கும் இது ஒரு சிறந்த தகவல்தொடர்பு விருப்பம்.

நீங்கள் Signal ஐ `Super + Shift + G` கொண்டு தொடங்குவீர்கள். இது அடிப்படை நிறுவலின் பகுதி அல்ல, எனவே முதல் முறை அதை அழுத்தும்போது, Omarchy அதை உங்களுக்காக நிறுவ முன்வரும் (இது Omarchy மெனுவில் _Install > Service_ இன் கீழும் உள்ளது).

## Omaview

[Omaview](https://github.com/omacom/omaview) என்பது Omarchy இன் சொந்த, மிக எளிய படக் காட்சியாளர் மற்றும் ஊடக இயக்கி: உங்கள் புகைப்படங்கள், வீடியோக்கள் மற்றும் இசைக்கான ஒரே சாளரம். ஒரு புகைப்படத்தைத் திறந்தால் அம்பு விசைகள் அதன் கோப்புறையின் மீதியை ஒன்றன் பின் ஒன்றாகக் காட்டும், எதற்கும் `N` மற்றும் `P` அதையே செய்யும், `Ctrl + M` முழுக் கோப்புறையையும் ஒரு கட்டமாகக் காட்டும். இது HEIC, AVIF மற்றும் JPEG XL புகைப்படங்களையும் காட்டுகிறது, நீளமான எதிலும் நீங்கள் விட்ட இடத்திலிருந்து தொடர்கிறது.

முழுத்திரைக்கு `F` ஐ அழுத்தவும், ஒரு படத்தை Omasnap இல் திருத்த அல்லது ஒரு வீடியோவை Omacut இல் வெட்ட `E` ஐ அழுத்தவும், ஒரு படத்தை அச்சிட `Ctrl + P` ஐ அழுத்தவும், ஒரு கோப்பை Trash க்கு நகர்த்த `Delete` ஐ அழுத்தவும் (`Ctrl + Z` அதை மீண்டும் கொண்டு வரும்). ஒவ்வொரு குறுக்குவழியையும் காண அதற்குள் `?` ஐ அழுத்தவும்.

நீங்கள் Omaview வை application launcher (`Super + Space`) வழியாக _Media Viewer_ ஆகத் தொடங்குவீர்கள், அல்லது கோப்பு மேலாளரில் ஒரு படம், வீடியோ அல்லது பாடலின் மீது இருமுறை கிளிக் செய்வீர்கள்.

## Omacut

[Omacut](https://github.com/omacom-io/omacut) என்பது Omarchy இன் சொந்த, மிக எளிய வீடியோ வெட்டி. ஒரு கிளிப்பின் தொடக்கத்தையும் முடிவையும் வெட்டுவது மட்டுமே உங்களுக்குத் தேவை என்றால், முழு வீடியோ எடிட்டரை இயக்குவதை இது வெல்லும்.

நீங்கள் Omacut ஐ application launcher (`Super + Space`) வழியாகத் தொடங்குவீர்கள்.

## Monologue

[Monologue](https://github.com/omacom/monologue) என்பது Omarchy இன் சொந்த, மிக எளிய வெப்கேம் பதிவி. உங்கள் கேமராவையும் மைக்ரோஃபோனையும் ஒருமுறை தேர்ந்தெடுக்கவும், பின்னர் பதிவு செய்ய `Space` ஐ அழுத்தவும், அதே டேக்கை இடைநிறுத்தி மீண்டும் தொடர மீண்டும் அழுத்தவும். நீங்கள் தொடங்கும் முன் உங்கள் அளவுகளைச் சரிபார்க்க நேரடி மைக்ரோஃபோன் மீட்டருடன், இது எப்போதும் உங்கள் கேமராவின் மிக உயர்ந்த தெளிவுத்திறனில் பதிவு செய்கிறது.

டேக்கை நிறுத்தினால் அது உடனடியாக உள்ளமைக்கப்பட்ட எடிட்டரில் திறக்கும். ஒரு கிளிப்பைப் பிரிக்க அதன் மீது இருமுறை கிளிக் செய்யவும், ஒவ்வொரு துண்டையும் வெட்ட கைப்பிடிகளை இழுக்கவும், உங்களுக்கு வேண்டாத பகுதிகளை நீக்கவும். பின்னர் அதை ஒரு MP4 ஆகச் சேமிக்கவும். நீங்கள் அதை நிராகரிக்கும் வரை உங்கள் அசல் பதிவு வைக்கப்படும், எனவே நீங்கள் எப்போதும் திரும்பி வந்து அதை வேறுவிதமாக வெட்டலாம்.

நீங்கள் Monologue ஐ application launcher (`Super + Space`) வழியாகத் தொடங்குவீர்கள்.
