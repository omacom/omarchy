# நிலைமாற்றிகள், செயலற்ற நிலை மற்றும் திரைக்காவல்

நீங்கள் அன்றாடம் மாற்றுபவற்றில் பல உண்மையில் ஒரு அமைப்பு அல்ல. அது ஒரு மணி நேரம் இயக்கிவிட்டு மீண்டும் அணைக்கும் ஒரு பயன்முறை: இரவு தாமதமாக வேலை செய்யும் போது இரவு ஒளி, விளக்கக்காட்சி அளிக்கும் போது தொந்தரவு செய்ய வேண்டாம், ஏதாவது பார்த்துக் கொண்டிருக்கும் போது விழித்திருத்தல். Omarchy அவற்றை நிலைமாற்றிகள் என்று அழைக்கிறது, அவை அனைத்தும் ஒரே மாதிரியாகவே செயல்படுகின்றன — ஒரு விசைப்பலகை குறுக்குவழி, ஒரு மெனு உள்ளீடு, ஒரு கட்டளை, அனைத்தும் ஒரே நிலைமாற்றியைத் தாக்குகின்றன.

### நிலைமாற்றி மெனு

`Super + Ctrl + O` _Trigger > Toggle_ ஐ நேரடியாகத் திறக்கிறது, அல்லது Omarchy மெனுவிலிருந்து (`Super + Space`) அங்கு நடந்து செல்லலாம். அந்தப் பட்டியலில் உள்ள அனைத்தும், நிலை எங்கே வாழ்கிறது என்று யோசிக்காமல் நீங்கள் மாற்றக்கூடிய ஒரு நிலைமாற்றியே. டெஸ்க்டாப் எப்படி தோற்றமளிக்கிறது என்பதற்கான நிலைமாற்றிகள் அதற்கு அருகிலேயே, _Appearance_ இன் கீழ் அமர்ந்துள்ளன.

முனையத்திலிருந்து, அதே நிலைமாற்றிகள் `omarchy toggle <thing>` ஆகும். முழுக் குழுவையும் காண `omarchy toggle` ஐத் தனியாக இயக்கவும்.

| நிலைமாற்றி | விசைப்பலகை குறுக்குவழி | கட்டளை |
| ------ | ------ | ------- |
| இரவு ஒளி | — | `omarchy toggle nightlight` |
| அறிவிப்புகளை அமைதிப்படுத்து | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| விழித்திரு (செயலற்ற பூட்டு இல்லை) | `Super + Ctrl + I` | `omarchy toggle idle` |
| செயலிழப்புப் பதிவு | — | `omarchy toggle crash-capture` |
| திரைக்காவல் | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) தீம் ஒத்திசைவு | — | `omarchy toggle theme sync` |
| மெனு பட்டை | `Super + Shift + Space` | `omarchy toggle bar` |
| தொடுதிட்டு | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| தொடுதிரை | — | `omarchy toggle touchscreen` |
| இடைநிறுத்து | — | `omarchy toggle suspend` |
| கலப்பு GPU | — | `omarchy toggle hybrid gpu` |

தொடுதிட்டு, தொடுதிரை மற்றும் கலப்பு GPU நிலைமாற்றிகள் Toggle இன் கீழ் அல்லாமல் _Trigger > Hardware_ (`Super + Ctrl + H`) இன் கீழ் வாழ்கின்றன, ஏனெனில் அந்த வன்பொருள் உங்களிடம் உண்மையிலேயே இருக்கும் போது மட்டுமே அவை தோன்றும். தொடுதிட்டு மற்றும் தொடுதிரை நிலைமாற்றிகள் Hyprland மறுஏற்றத்திற்குப் பிறகும் நிலைத்திருக்கும் — முடக்கப்பட்ட சாதனத்தின் பெயர் ஒரு சிறிய நிலைக் கோப்பில் சேமிக்கப்படுகிறது, தொடக்கத்தில் Hyprland அதைப் படித்து அதை மீண்டும் முடக்கும்.

_Appearance_ மெனு பட்டையையும் அசைவூட்டங்களையும் கொண்டுள்ளது, அதோடு `omarchy toggle` கட்டளைகள் அல்லாத ஆனால் அதே போல நடந்து கொள்ளும் சில விஷயங்களையும் கொண்டுள்ளது: பட்டையில் மின்கல சதவீதம், இயல்புநிலை பணியிட அமைப்பு, மற்றும் _Windows_ இன் கீழ், சாளர இடைவெளிகள் (`Super + Shift + Backspace`) மற்றும் 1-சாளர சதுர விகிதம் (`Super + Ctrl + Backspace`).

வரைவதற்கு Hyprland இடம் GPU இல்லாத போது அதற்குப் பதிலாக CPU இல் வரையும் போது (llvmpipe), GPU இன்னும் ஆதரிக்கப்படாத Mac களில், பெரும்பாலான மெய்நிகர் இயந்திரங்களில், அல்லது ஒரு வரைகலை இயக்கி ஏற்றப்படத் தவறும் போது போல, Omarchy அந்த அமர்வுக்கு அசைவூட்டங்கள், மங்கல் மற்றும் நிழல்களை அணைத்துவிட்டு, ஒரு அறிவிப்பின் மூலம் ஒரு முறை அதை உங்களுக்குச் சொல்லும். _Appearance > Animations On_ அவற்றை மீண்டும் கொண்டு வருகிறது, மேலும் Omarchy அதைப் பின்வரும் அமர்வுகளுக்கும் நினைவில் வைத்துக் கொள்கிறது.

இவற்றில் பெரும்பாலானவை `~/.local/state/omarchy/toggles/` இன் கீழ் உள்ள ஒரு கொடிக் கோப்பு மட்டுமே. ஒரு ஸ்கிரிப்டில் ஒன்றைக் கொண்டு கிளை பிரிக்க விரும்பினால், நீங்களே தேடிச் செல்வதற்குப் பதிலாக `omarchy-toggle-enabled` உங்களுக்கு ஒரு வெளியேற்றக் குறியீட்டைத் தருகிறது:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

கொடிகள் அணைந்த நிலைக்காகப் பெயரிடப்பட்டுள்ளன — `screensaver-off`, `suspend-off`, `bar-off` — எனவே அவை இருப்பது அந்த அம்சம் முடக்கப்பட்டுள்ளது என்று பொருள்.

### பட்டையில் உள்ள குறிகாட்டிகள்

ஒரு பயன்முறை இயக்கத்தில் இருக்கும் போது, கடிகாரத்திற்கு அருகில் மேல் பட்டையின் நடுவில் ஒரு சிறிய கிளிஃப் கிடைக்கும். அதுதான் குறிகாட்டிகள் விட்ஜெட், அது கட்டளை எழுத்தாக்கம், திரைப் பதிவு, நிலுவையில் உள்ள நினைவூட்டல்கள், இரவு ஒளி, தொந்தரவு செய்ய வேண்டாம் மற்றும் விழித்திருத்தல் ஆகியவற்றைக் கொண்டுள்ளது.

செயலற்ற குறிகாட்டிகள் மறைக்கப்பட்டுள்ளன. பட்டையில் எங்காவது வட்டமிடுங்கள், அவை மங்கலாகத் தோன்றும், எனவே அதன் விசைப்பலகை குறுக்குவழியை அறியாமலேயே ஒன்றைக் கிளிக் செய்து இயக்கலாம். செயலில் உள்ள ஒன்றைக் கிளிக் செய்வது அதை மீண்டும் அணைக்கும். அவை அனைத்தையும் எல்லா நேரத்திலும் காண விரும்பினால், `~/.config/omarchy/shell.json` இல் உள்ள `omarchy.indicators` உள்ளீட்டில் `alwaysShow` ஐ `true` என அமைக்கவும் — பட்டை விட்ஜெட்கள் எப்படி உள்ளமைக்கப்படுகின்றன என்பதற்கு [மேல் பட்டையைப்](05-the-top-bar.md) பார்க்கவும்.

### இரவு ஒளி

இரவு ஒளி திரையை 4000K க்கு வெப்பமாக்குகிறது, அதை மீண்டும் நிலைமாற்றுவது அதை 6500K க்குத் திருப்புகிறது. நிலைமாற்றி மெனுவிலிருந்து (`Super + Ctrl + O`) அல்லது `omarchy toggle nightlight` கொண்டு அதை மாற்றவும். அது hyprsunset ஆல் இயக்கப்படுகிறது, அது ஏற்கனவே இயங்கவில்லை என்றால் நிலைமாற்றி அதை உங்களுக்காகத் தொடங்கும்.

இயல்பாக hyprsunset உங்கள் திரைக்கு எதுவும் செய்வதில்லை. நீங்கள் வெப்பத்தைக் கேட்கும் வரை காட்சி தீண்டப்படாமல் இருக்கவே, `~/.config/hypr/hyprsunset.conf` ஒரு அடையாள சுயவிவரத்துடன் வருகிறது. அதைக் கடிகாரத்தின் படி மாற்ற விரும்பினால், அதை ஒரு நேர சுயவிவரத்தால் மாற்றவும்:

```
profile {
    time = 20:00
    temperature = 4000
}
```

பின்னர் `~/.config/hypr/autostart.lua` இல் `o.launch_on_start("hyprsunset")` ஐச் சேர்ப்பதன் மூலம் உள்நுழைவில் hyprsunset ஐத் தொடங்கவும். நிலைமாற்றி பயன்படுத்தும் 4000K/6500K இணை நிலையானது, எனவே வேறு வெப்பநிலை வேண்டுமென்றால் உள்ளமைவுக் கோப்பிற்குத்தான் செல்ல வேண்டும்.

### தொந்தரவு செய்ய வேண்டாம்

`Super + Ctrl + Alt + ,` அறிவிப்புகளை அமைதிப்படுத்துகிறது. அது இயக்கத்தில் இருக்கும் போது எந்த டோஸ்டுகளும் தோன்றாது, டெஸ்க்டாப் ஏன் அமைதியாகிவிட்டது என்பதை நினைவூட்ட குறுக்குக் கோடிட்ட மணி குறிகாட்டி பட்டையில் அமர்ந்திருக்கும்.

ஆனால் எதுவும் இழக்கப்படுவதில்லை. அமைதிப்படுத்தப்பட்ட அறிவிப்புகள் தடுத்து வைக்கப்படுகின்றன: கடைசி சிலவற்றை `Super + Shift + Alt + ,` கொண்டு மீண்டும் திரையில் வைக்கவும். மீதமுள்ளவற்றிற்கு [அறிவிப்புகளைப்](10-notices.md) பார்க்கவும்.

இரண்டு வகையான செய்திகள் இன்னும் ஊடுருவி வரும்: நீங்கள் இப்போது செய்த ஒன்றுக்கான Omarchy இன் சொந்த உறுதிப்படுத்தல் டோஸ்டுகள் ("தீம் மாற்றப்பட்டது", "திரைப்பிடிப்பு சேமிக்கப்பட்டது"), மற்றும் கட்டளை வரியிலிருந்து அனுப்பப்படும் முக்கியமான எச்சரிக்கைகள். உங்கள் முன் தங்களைத் திணித்துக் கொள்ள எல்லாவற்றையும் முக்கியமானது என்று குறிக்கும் அரட்டை செயலிகள் தகுதி பெறாது.

### செயலற்ற நிலை

Omarchy ஷெல் செயலற்ற நடத்தையைச் சொந்தமாகக் கொண்டுள்ளது, நேரங்கள் `~/.config/omarchy/shell.json` இல் ஒரு மேல்நிலை `idle` தொகுதியாகும்:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

இரண்டு எண்களும் நீங்கள் செயலற்றுப் போன தருணத்திலிருந்து கணக்கிடப்படும் வினாடிகள் — ஒன்றிலிருந்து மற்றொன்று அல்ல. எனவே இயல்புநிலைகளுடன், திரைக்காவல் இரண்டரை நிமிடங்களுக்குப் பிறகு வரும், திரைக்காவல் இயங்கினாலும் இயங்காவிட்டாலும் பூட்டுத் திரை ஐந்து நிமிடங்களில் பொறுப்பேற்கும். கோப்பைச் சேமியுங்கள், ஷெல் புதிய நேரங்களை உடனடியாக எடுத்துக் கொள்ளும்.

பூட்டு காலக்கெடுவிற்கு முன் திரைக்காவலை நீக்கினால், அது செயல்பாடாகக் கணக்கிடப்படும், நிலுவையில் உள்ள பூட்டு ரத்து செய்யப்படும். உங்கள் இயந்திரத்தை எட்டிப் பார்த்ததற்காக நீங்கள் பூட்டப்பட மாட்டீர்கள்.

செயலற்ற நிலையில் பூட்டுவதை முற்றிலும் நிறுத்த, `Super + Ctrl + I` — அல்லது `omarchy toggle idle` — விழித்திருத்தலை இயக்குகிறது, காபி கோப்பை குறிகாட்டி பட்டையில் தோன்றும். நீண்ட விளக்கக்காட்சிக்கு முன் அல்லது நீங்கள் பார்க்க விரும்பும் ஒரு உருவாக்கத்திற்கு முன் அழுத்த வேண்டியது அதுதான். இயல்பு நிலைக்குத் திரும்ப அதை மீண்டும் அழுத்தவும். ஒரு ஸ்கிரிப்டிலிருந்து தேவைப்பட்டால் `omarchy toggle idle status` தற்போதைய நிலையை JSON ஆக அச்சிடும்.

இது பூட்டுதல் மற்றும் திரைக்காவலைப் பற்றியது, மின்சாரத்தைப் பற்றியது அல்ல. இடைநிறுத்தம் மற்றும் உறக்கநிலைக்கு [கணினி உறக்கத்தில்](36-system-sleep.md) அவற்றுக்கெனத் தனி அமைப்பு உள்ளது.

### திரைக்காவல்

Omarchy இன் திரைக்காவல் சீரற்ற உரை விளைவுகள் வழியாக ஓடும் ASCII கலை, ஒரு மானிட்டருக்கு ஒரு நிகழ்வு. எந்த விசையும் அல்லது சுட்டி அசைவும் அதிலிருந்து வெளியேறும்.

செயலற்ற திரைக்காவலை அணைத்திருந்தாலும் கூட அதை வலுக்கட்டாயமாகக் கொண்டு வரும் _System > Screensaver_ (`Super + Esc`) இலிருந்து தேவைப்படும் போது அதைத் தொடங்கலாம். இயல்பாக அதற்கு எந்த விசைப்பலகை குறுக்குவழியும் பிணைக்கப்படவில்லை.

வேலையிலிருந்து நேராகப் பூட்டப்பட்ட நிலைக்குச் செல்ல விரும்பினால், செயலற்ற திரைக்காவலை அணைப்பது `omarchy toggle screensaver` தான். எந்த விசை, கிளிக், உருட்டல் அல்லது சுட்டி அசைவும் அதை மூடும்.

அது வரையும் லோகோவை _Appearance > Branding > Screensaver_ இன் கீழ் நீங்கள் மாற்றலாம். ஒரு png அல்லது svg ஐப் பதிவேற்றுங்கள், Omarchy அதை ASCII ஆக மாற்றும். [அடையாள வடிவமைப்பைப்](41-branding.md) பார்க்கவும்.

### பூட்டுத் திரை

`Super + Ctrl + L` இயந்திரத்தைப் பூட்டுகிறது. அது Omarchy ஷெல்லிலிருந்து பூட்டுத் திரையை இயக்குகிறது, காட்சியை வெறுமையாக்குகிறது, தவறான எழுத்து வடிவத்தில் உங்கள் கடவுச்சொல்லைத் தட்டச்சு செய்யாதிருக்க உங்கள் விசைப்பலகை அமைப்பை முதலாவதற்கு மீட்டமைக்கிறது, மேலும் — நீங்கள் அதை இயக்கிக் கொண்டிருந்தால் — வெளியேறும் வழியில் 1Password ஐப் பூட்டுகிறது.

பூட்டுத் திரை ஒரு கடவுச்சொல்லை ஏற்கும், நீங்கள் ஒன்றை அமைத்தவுடன் ஒரு கைரேகையையும் ஏற்கும். அது, மற்றும் அங்கீகரிப்பதற்கான பிற வழிகள், [வன்பொருள் அங்கீகாரத்தில்](37-hardware-authentication.md) விவரிக்கப்பட்டுள்ளன.
