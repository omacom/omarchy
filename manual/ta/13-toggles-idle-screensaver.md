# மாற்றுவிசைகள், செயலற்ற நிலை & திரைக்காப்பு

நீங்கள் அன்றாடம் மாற்றுவதில் பெரும்பாலானவை உண்மையில் ஒரு அமைப்பு அல்ல. அது நீங்கள் ஒரு மணிநேரம் இயக்கிவிட்டு மீண்டும் அணைக்கும் ஒரு பயன்முறை: நீங்கள் இரவு தாமதமாக வேலை செய்யும்போது இரவு ஒளி, நீங்கள் விளக்கக்காட்சி அளிக்கும்போது தொந்தரவு செய்ய வேண்டாம், நீங்கள் ஏதாவது பார்த்துக்கொண்டிருக்கும்போது விழித்திருத்தல். Omarchy அவற்றை மாற்றுவிசைகள் என்று அழைக்கிறது, அவை அனைத்தும் ஒரே மாதிரிதான் செயல்படுகின்றன — ஒரு ஹாட்கீ, ஒரு மெனு உள்ளீடு, ஒரு கட்டளை, அனைத்தும் ஒரே சுவிட்சைத் தாக்குகின்றன.

### மாற்றுவிசை மெனு

`Super + Ctrl + O` _தூண்டு > மாற்றுவிசை_ ஐ நேரடியாகத் திறக்கும், அல்லது Omarchy மெனுவிலிருந்து (`Super + Space`) நீங்கள் அங்கே செல்லலாம். அந்தப் பட்டியலில் உள்ள அனைத்தும், நிலை எங்கே இருக்கிறது என்று சிந்திக்காமல் நீங்கள் மாற்றக்கூடிய ஒரு சுவிட்ச். டெஸ்க்டாப் எப்படித் தோன்றுகிறது என்பதற்கான சுவிட்சுகள் அதற்கு அருகில், _தோற்றம்_ இன் கீழ் அமர்ந்திருக்கின்றன.

டெர்மினலில் இருந்து, அதே சுவிட்சுகள் `omarchy toggle <thing>` ஆகும். முழுக் குழுவையும் காண `omarchy toggle` ஐத் தனியாக இயக்கவும்.

| மாற்றுவிசை | ஹாட்கீ | கட்டளை |
| ------ | ------ | ------- |
| இரவு ஒளி | — | `omarchy toggle nightlight` |
| அறிவிப்புகளை அமைதிப்படுத்து | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| விழித்திரு (செயலற்ற பூட்டு இல்லை) | `Super + Ctrl + I` | `omarchy toggle idle` |
| செயலிழப்புப் பதிவு | — | `omarchy toggle crash-capture` |
| திரைக்காப்பு | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) தீம் ஒத்திசைவு | — | `omarchy toggle theme sync` |
| மெனு பட்டி | `Super + Shift + Space` | `omarchy toggle bar` |
| டச்பேட் | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| தொடுதிரை | — | `omarchy toggle touchscreen` |
| இடைநிறுத்தம் | — | `omarchy toggle suspend` |
| Hybrid GPU | — | `omarchy toggle hybrid gpu` |

டச்பேட், தொடுதிரை மற்றும் Hybrid GPU சுவிட்சுகள் மாற்றுவிசையின் கீழ் இல்லாமல் _தூண்டு > வன்பொருள்_ (`Super + Ctrl + H`) இன் கீழ் வாழ்கின்றன, ஏனெனில் அந்த வன்பொருள் உங்களிடம் உண்மையில் இருக்கும்போது மட்டுமே அவை தோன்றும். டச்பேட் மற்றும் தொடுதிரை சுவிட்சுகள் Hyprland மறுஏற்றத்திற்குப் பிறகும் நிலைத்திருக்கும் — முடக்கப்பட்ட சாதனத்தின் பெயர் ஒரு சிறிய நிலைக் கோப்பில் சேமிக்கப்படுகிறது, தொடக்கத்தில் Hyprland அதைப் படித்து அதை மீண்டும் முடக்குகிறது.

_தோற்றம்_ மெனு பட்டி மற்றும் அனிமேஷன்களைக் கொண்டுள்ளது, மேலும் `omarchy toggle` கட்டளைகள் அல்லாத ஆனால் அதே போல் செயல்படும் சில விஷயங்களையும் கொண்டுள்ளது: பட்டியில் பேட்டரி சதவீதம், இயல்புநிலை பணியிட அமைப்பு, மற்றும் _சாளரங்கள்_ இன் கீழ், சாளர இடைவெளிகள் (`Super + Shift + Backspace`) மற்றும் 1-சாளர சதுர விகிதம் (`Super + Ctrl + Backspace`).

இவற்றில் பெரும்பாலானவை `~/.local/state/omarchy/toggles/` இன் கீழ் உள்ள ஒரு கொடிக் கோப்பு மட்டுமே. ஒரு ஸ்கிரிப்டில் ஒன்றை வைத்துக் கிளை பிரிக்க விரும்பினால், நீங்களே தேடிச் செல்ல வைக்காமல் `omarchy-toggle-enabled` உங்களுக்கு ஒரு வெளியேற்றக் குறியீட்டைக் கொடுக்கிறது:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

கொடிகள் அணைந்த நிலைக்குப் பெயரிடப்பட்டுள்ளன — `screensaver-off`, `suspend-off`, `bar-off` — எனவே அவை இருப்பது என்றால் அந்த அம்சம் முடக்கப்பட்டுள்ளது என்று பொருள்.

### பட்டியில் உள்ள குறிகாட்டிகள்

ஒரு பயன்முறை இயக்கத்தில் இருக்கும்போது, கடிகாரத்திற்கு அடுத்ததாக மேல் பட்டியின் நடுவில் ஒரு சிறிய கிளிஃபைப் பெறுவீர்கள். அதுதான் குறிகாட்டிகள் விட்ஜெட், அது கட்டளையிட்டு எழுதுதல், திரைப் பதிவு, நிலுவையில் உள்ள நினைவூட்டல்கள், இரவு ஒளி, தொந்தரவு செய்ய வேண்டாம் மற்றும் விழித்திருத்தல் ஆகியவற்றைக் கொண்டு செல்கிறது.

செயலற்ற குறிகாட்டிகள் மறைக்கப்படும். பட்டியில் எங்காவது சுட்டியை வைத்தால் அவை மங்கலாகத் தோன்றும், எனவே அதன் ஹாட்கீயை அறியாமலேயே ஒன்றைக் கிளிக் செய்து இயக்கலாம். செயலில் உள்ள ஒன்றைக் கிளிக் செய்வது அதை மீண்டும் அணைக்கிறது. அவை அனைத்தையும் எப்போதும் காண விரும்பினால், `~/.config/omarchy/shell.json` இல் உள்ள `omarchy.indicators` உள்ளீட்டில் `alwaysShow` ஐ `true` என அமைக்கவும் — பட்டி விட்ஜெட்கள் எப்படி உள்ளமைக்கப்படுகின்றன என்பதற்கு [மேல் பட்டி](05-the-top-bar.md) ஐப் பார்க்கவும்.

### இரவு ஒளி

இரவு ஒளி திரையை 4000K க்கு சூடாக்குகிறது, அதை மீண்டும் மாற்றுவது அதை 6500K க்குத் திரும்பக் கொண்டுவருகிறது. மாற்றுவிசை மெனுவிலிருந்து (`Super + Ctrl + O`) அல்லது `omarchy toggle nightlight` கொண்டு அதை மாற்றவும். இது hyprsunset ஆல் இயக்கப்படுகிறது, அது ஏற்கனவே இயங்கவில்லை என்றால் மாற்றுவிசை அதை உங்களுக்காகத் தொடங்கும்.

இயல்பாக hyprsunset உங்கள் திரைக்கு எதுவுமே செய்யாது. `~/.config/hypr/hyprsunset.conf` ஒரு அடையாள சுயவிவரத்துடன் வருகிறது, துல்லியமாக நீங்கள் சூட்டைக் கேட்கும் வரை காட்சி தீண்டப்படாமல் இருக்கும். அதற்குப் பதிலாக அது கடிகாரத்தின் படி மாற விரும்பினால், அதை ஒரு நேர சுயவிவரத்தால் மாற்றவும்:

```
profile {
    time = 20:00
    temperature = 4000
}
```

பின்னர் `~/.config/hypr/autostart.lua` இல் `o.launch_on_start("hyprsunset")` ஐச் சேர்ப்பதன் மூலம் உள்நுழைவில் hyprsunset ஐத் தொடங்கவும். மாற்றுவிசை பயன்படுத்தும் 4000K/6500K ஜோடி நிலையானது, எனவே வேறு வெப்பநிலை வேண்டுமென்றால் நீங்கள் செல்ல வேண்டிய இடம் உள்ளமைவுக் கோப்புதான்.

### தொந்தரவு செய்ய வேண்டாம்

`Super + Ctrl + Alt + ,` அறிவிப்புகளை அமைதிப்படுத்துகிறது. அது இயக்கத்தில் இருக்கும்போது எந்த டோஸ்டும் தோன்றாது, டெஸ்க்டாப் ஏன் அமைதியாகிவிட்டது என்பதை உங்களுக்கு நினைவூட்ட குறுக்குக்கோடு போட்ட மணி குறிகாட்டி பட்டியில் அமர்ந்திருக்கும்.

ஆனால் எதுவும் இழக்கப்படுவதில்லை. அமைதிப்படுத்தப்பட்ட அறிவிப்புகள் தடுத்து வைக்கப்படுகின்றன: கடைசி சிலவற்றை `Super + Shift + Alt + ,` கொண்டு மீண்டும் திரையில் வைக்கவும். மீதமுள்ளவற்றுக்கு [அறிவிப்புகள்](10-notices.md) ஐப் பார்க்கவும்.

இரண்டு வகையான செய்திகள் இன்னும் கடந்து வருகின்றன: நீங்கள் இப்போது செய்த ஒன்றுக்கான Omarchy இன் சொந்த உறுதிப்படுத்தல் டோஸ்ட்கள் ("தீம் மாற்றப்பட்டது", "ஸ்கிரீன்ஷாட் சேமிக்கப்பட்டது"), மற்றும் கட்டளை வரியிலிருந்து அனுப்பப்படும் முக்கியமான எச்சரிக்கைகள். உங்கள் முன் தங்களை வலுக்கட்டாயமாகக் கொண்டுவர எல்லாவற்றையும் முக்கியமானது என்று குறிக்கும் அரட்டை பயன்பாடுகள் தகுதி பெறாது.

### செயலற்ற நிலை

Omarchy ஷெல் செயலற்ற நடத்தையைச் சொந்தமாகக் கொண்டுள்ளது, நேரங்கள் `~/.config/omarchy/shell.json` இல் உள்ள உயர்மட்ட `idle` தொகுதி ஆகும்:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

இரண்டு எண்களும் நீங்கள் செயலற்ற நிலைக்குச் சென்ற தருணத்திலிருந்து எண்ணப்படும் வினாடிகள் — ஒன்றிலிருந்து மற்றொன்று அல்ல. எனவே இயல்புநிலைகளுடன், திரைக்காப்பு இரண்டரை நிமிடங்களுக்குப் பிறகு வரும், திரைக்காப்பு இயங்கினாலும் இல்லாவிட்டாலும் பூட்டுத் திரை ஐந்து நிமிடங்களில் பொறுப்பேற்கும். கோப்பைச் சேமிக்கவும், ஷெல் புதிய நேரங்களை உடனடியாக எடுத்துக்கொள்ளும்.

பூட்டு காலக்கெடுவிற்கு முன் நீங்கள் திரைக்காப்பை நீக்கினால், அது செயல்பாடாகக் கணக்கிடப்படும், நிலுவையில் உள்ள பூட்டு ரத்து செய்யப்படும். உங்கள் கணினியை ஒரு பார்வை பார்த்ததற்காக நீங்கள் பூட்டப்பட மாட்டீர்கள்.

செயலற்ற நிலையில் பூட்டுவதை முற்றிலும் நிறுத்த, `Super + Ctrl + I` — அல்லது `omarchy toggle idle` — விழித்திருத்தலை இயக்குகிறது, காபி கோப்பை குறிகாட்டி பட்டியில் தோன்றும். நீண்ட விளக்கக்காட்சிக்கு முன் அல்லது நீங்கள் பார்க்க விரும்பும் ஒரு உருவாக்கத்திற்கு முன் அடிக்க வேண்டியது அதுதான். இயல்பு நிலைக்குத் திரும்ப அதை மீண்டும் அடிக்கவும். ஒரு ஸ்கிரிப்டிலிருந்து உங்களுக்குத் தேவைப்பட்டால் `omarchy toggle idle status` தற்போதைய நிலையை JSON ஆக அச்சிடும்.

இது பூட்டுதல் மற்றும் திரைக்காப்பு பற்றியது, மின்சாரம் பற்றியது அல்ல. இடைநிறுத்தம் மற்றும் உறக்கநிலைக்கு [அமைப்பு தூக்கம்](36-system-sleep.md) இல் அவற்றின் சொந்த அமைப்பு உள்ளது.

### திரைக்காப்பு

Omarchy இன் திரைக்காப்பு சீரற்ற உரை விளைவுகள் வழியாக இயங்கும் ASCII கலை, ஒரு மானிட்டருக்கு ஒரு நிகழ்வு. எந்த விசை அல்லது சுட்டி அசைவும் அதிலிருந்து வெளியேறும்.

நீங்கள் செயலற்ற திரைக்காப்பை அணைத்திருந்தாலும் கூட அதை வலுக்கட்டாயமாகக் கொண்டுவரும் _அமைப்பு > திரைக்காப்பு_ (`Super + Esc`) இலிருந்து தேவைக்கேற்ப அதைத் தொடங்கலாம். இயல்பாக அதற்கு எந்த ஹாட்கீயும் பிணைக்கப்படவில்லை.

நீங்கள் வேலையிலிருந்து நேரடியாகப் பூட்டப்பட்ட நிலைக்குச் செல்ல விரும்பினால், செயலற்ற திரைக்காப்பை அணைப்பது `omarchy toggle screensaver` தான். எந்த விசை, கிளிக், உருட்டல் அல்லது சுட்டி அசைவும் அதை மூடும்.

அது வரையும் லோகோவை மாற்றுவது உங்களுடையது, _தோற்றம் > பிராண்டிங் > திரைக்காப்பு_ இன் கீழ். ஒரு png அல்லது svg ஐப் பதிவேற்றவும், Omarchy அதை ASCII ஆக மாற்றும். [பிராண்டிங்](41-branding.md) ஐப் பார்க்கவும்.

### பூட்டுத் திரை

`Super + Ctrl + L` கணினியைப் பூட்டுகிறது. அது Omarchy ஷெல்லிலிருந்து பூட்டுத் திரையை இயக்குகிறது, காட்சியை வெறுமையாக்குகிறது, உங்கள் கடவுச்சொல்லை தவறான எழுத்துக்களில் தட்டச்சு செய்யாமல் இருக்க உங்கள் விசைப்பலகை அமைப்பை முதல் அமைப்புக்கு மீட்டமைக்கிறது, மேலும் — நீங்கள் அதை இயக்கிக்கொண்டிருந்தால் — வெளியேறும் வழியில் 1Password ஐப் பூட்டுகிறது.

பூட்டுத் திரை ஒரு கடவுச்சொல்லை ஏற்கும், நீங்கள் ஒன்றை அமைத்தவுடன் அது ஒரு கைரேகையையும் ஏற்கும். அதுவும், அங்கீகரிப்பதற்கான பிற வழிகளும், [வன்பொருள் அங்கீகாரம்](37-hardware-authentication.md) இல் விவரிக்கப்பட்டுள்ளன.
