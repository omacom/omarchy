# மாற்றங்கள், செயலற்ற நிலை & திரைசேமிப்பு

நீங்கள் நாளுக்கு நாள் மாற்றும் நிறைய விஷயங்கள் உண்மையில் ஒரு அமைப்பு அல்ல. அது ஒரு மணி நேரம் இயக்கி மீண்டும் அணைக்கும் ஒரு பயன்முறை: நீங்கள் தாமதமாக வேலை செய்யும் போது இரவு விளக்கு, நீங்கள் வழங்கும் போது தொந்தரவு செய்யாதே, நீங்கள் ஏதாவது பார்க்கும் போது விழித்திரு. Omarchy அவற்றை மாற்றங்கள் என்று அழைக்கிறது, மேலும் அவை அனைத்தும் அதே வழியில் வேலை செய்கின்றன — ஒரு ஹாட்கீ, ஒரு மெனு பதிவு, மற்றும் ஒரு கட்டளை, அனைத்தும் அதே சுவிட்சை அடிக்கின்றன.

### மாற்று மெனு

`Super + Ctrl + O` நேரடியாக _தூண்டு > மாற்று_ ஐத் திறக்கிறது, அல்லது Omarchy மெனுவிலிருந்து (`Super + Space`) அங்கே நடக்கலாம். அந்தப் பட்டியலில் உள்ள அனைத்தும் நிலை எங்கே உள்ளது என்று யோசிக்காமல் நீங்கள் புரட்டக்கூடிய ஒரு சுவிட்ச். டெஸ்க்டாப் எப்படித் தெரிகிறது என்பதற்கான சுவிட்சுகள் _தூண்டு > தோற்றம்_ இன் கீழ் அதற்கு அடுத்ததாக உள்ளன.

டெர்மினலிலிருந்து, அதே சுவிட்சுகள் `omarchy toggle <thing>` ஆகும். முழு குழுவையும் பார்க்க `omarchy toggle` ஐத் தனியாக இயக்கவும்.

| மாற்று | ஹாட்கீ | கட்டளை |
| ------ | ------ | ------- |
| இரவு விளக்கு | `Super + Ctrl + N` | `omarchy toggle nightlight` |
| அறிவிப்புகளை அமைதிப்படுத்து | `Super + Ctrl + ,` | `omarchy toggle notification silencing` |
| விழித்திரு (செயலற்ற பூட்டு இல்லை) | `Super + Ctrl + I` | `omarchy toggle idle` |
| செயலிழப்பு பதிவு | — | `omarchy toggle crash-capture` |
| திரைசேமிப்பு | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) தீம் ஒத்திசைவு | — | `omarchy toggle theme sync` |
| மெனு பட்டை | `Super + Shift + Space` | `omarchy toggle bar` |
| தொடுதளம் | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| தொடுதிரை | — | `omarchy toggle touchscreen` |
| இடைநிறுத்து | — | `omarchy toggle suspend` |
| Hybrid GPU | — | `omarchy toggle hybrid gpu` |

தொடுதளம், தொடுதிரை, மற்றும் hybrid GPU சுவிட்சுகள் மாற்று இன் கீழ் இல்லாமல் _தூண்டு > வன்பொருள்_ (`Super + Ctrl + H`) இன் கீழ் உள்ளன, ஏனெனில் அவை உங்களிடம் உண்மையில் அந்த வன்பொருள் இருக்கும் போது மட்டுமே தோன்றும். தொடுதளம் மற்றும் தொடுதிரை ஆகியவை Hyprland மறுஏற்றத்தில் தப்பிப்பிழைக்கின்றன — முடக்கப்பட்ட சாதனத்தின் பெயர் ஒரு சிறிய நிலை கோப்பில் சேமிக்கப்படுகிறது, அதை Hyprland தொடக்கத்தில் படித்து அதை மீண்டும் முடக்குகிறது.

_தூண்டு > தோற்றம்_ மெனு பட்டை மற்றும் அசைவூட்டங்களை வைத்திருக்கிறது, மேலும் `omarchy toggle` கட்டளைகள் அல்லாத ஆனால் அதே போல் செயல்படும் சில விஷயங்களையும் வைத்திருக்கிறது: பட்டையில் மின்கல சதவீதம், இயல்புநிலை பணியிட அமைப்பு, சாளர இடைவெளி (`Super + Shift + Backspace`), மற்றும் 1-சாளர சதுர அம்சம் (`Super + Ctrl + Backspace`).

இவற்றில் பெரும்பாலானவை `~/.local/state/omarchy/toggles/` இன் கீழ் ஒரு கொடி கோப்பு மட்டுமே. ஒரு ஸ்கிரிப்டில் ஒன்றில் கிளைக்க விரும்பினால், `omarchy-toggle-enabled` உங்களைத் தேட வைப்பதற்கு பதிலாக ஒரு வெளியேறும் குறியீட்டைத் தருகிறது:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

கொடிகள் ஆஃப் நிலைக்காகப் பெயரிடப்பட்டுள்ளன — `screensaver-off`, `suspend-off`, `bar-off` — எனவே அவற்றின் இருப்பு என்றால் அம்சம் முடக்கப்பட்டுள்ளது.

### பட்டையில் குறிகாட்டிகள்

ஒரு பயன்முறை இயக்கத்தில் இருக்கும் போது, ​​கடிகாரத்திற்கு அடுத்ததாக மேல் பட்டையின் நடுவில் ஒரு சிறிய கிளிஃபைப் பெறுகிறீர்கள். அது குறிகாட்டிகள் விட்ஜெட், மேலும் அது கட்டளையிடல், திரைப்பதிவு, நிலுவையில் உள்ள நினைவூட்டல்கள், இரவு விளக்கு, தொந்தரவு செய்யாதே, மற்றும் விழித்திரு ஆகியவற்றைக் கொண்டுள்ளது.

செயலற்ற குறிகாட்டிகள் மறைக்கப்பட்டுள்ளன. அவற்றைச் சுற்றியுள்ள பகுதியில் மிதக்கவும், அவை மங்கலாக மறைகின்றன, எனவே அதன் ஹாட்கீயை அறியாமல் அதை இயக்க ஒன்றைக் கிளிக் செய்யலாம். செயலில் உள்ள ஒன்றைக் கிளிக் செய்வது அதை மீண்டும் அணைக்கிறது. அவை அனைத்தையும் எல்லா நேரமும் பார்க்க விரும்பினால், `~/.config/omarchy/shell.json` இல் உள்ள `omarchy.indicators` பதிவில் `alwaysShow` ஐ `true` ஆக அமைக்கவும் — பட்டை விட்ஜெட்டுகள் எப்படிக் கட்டமைக்கப்படுகின்றன என்பதற்கு [மேல் பட்டை](05-the-top-bar.md) பார்க்கவும்.

### இரவு விளக்கு

`Super + Ctrl + N` திரையை 4000K க்கு வெப்பமாக்குகிறது, மேலும் அதை மீண்டும் அழுத்துவது அதை 6500K க்குத் திருப்புகிறது. இது hyprsunset ஆல் இயக்கப்படுகிறது, இது ஏற்கனவே இயங்கவில்லை என்றால் மாற்று உங்களுக்காகத் தொடங்குகிறது.

இயல்பாக hyprsunset உங்கள் திரைக்கு எதுவும் செய்யாது. `~/.config/hypr/hyprsunset.conf` ஒரு அடையாள சுயவிவரத்துடன் வருகிறது, துல்லியமாக நீங்கள் வெப்பத்தைக் கேட்கும் வரை காட்சி தொடப்படாமல் இருக்கும். நீங்கள் அதை கடிகாரத்தால் மாற்ற விரும்பினால், அதை ஒரு நேர சுயவிவரத்தால் மாற்றவும்:

```
profile {
    time = 20:00
    temperature = 4000
}
```

பிறகு `~/.config/hypr/autostart.lua` இல் `o.launch_on_start("hyprsunset")` ஐச் சேர்ப்பதன் மூலம் உள்நுழைவில் hyprsunset-ஐத் தொடங்கவும். மாற்று பயன்படுத்தும் 4000K/6500K ஜோடி நிலையானது, எனவே நீங்கள் வேறு வெப்பநிலையை விரும்பினால் கட்டமைப்பு கோப்புதான் நீங்கள் செல்லும் இடம்.

### தொந்தரவு செய்யாதே

`Super + Ctrl + ,` அறிவிப்புகளை அமைதிப்படுத்துகிறது. அது இயக்கத்தில் இருக்கும் போது எந்த டோஸ்ட்களும் தோன்றாது, மேலும் டெஸ்க்டாப் ஏன் அமைதியாகிவிட்டது என்பதை உங்களுக்கு நினைவூட்ட குறுக்கே-வெளியே மணி குறிகாட்டி பட்டையில் உள்ளது.

இருப்பினும், எதுவும் இழக்கப்படவில்லை. ஒரு அமைதிப்படுத்தப்பட்ட அறிவிப்பு நேரடியாக உங்கள் அறிவிப்பு வரலாற்றில் எழுதப்படுகிறது, இது நீங்கள் திரும்பி வந்து என்ன தவறவிட்டீர்கள் என்று ஆச்சரியப்படும் போது நீங்கள் விரும்பும் சரியான பதிவு. `Super + Shift + Alt + ,` மூலம் அதைத் திறக்கவும். அறிவிப்பு கதையின் மீதிக்கு [அறிவிப்புகள்](10-notices.md) பார்க்கவும்.

இரண்டு வகையான செய்திகள் இன்னும் வருகின்றன: நீங்கள் இப்போது செய்த ஒன்றிற்கான Omarchy-இன் சொந்த உறுதிப்படுத்தல் டோஸ்ட்கள் ("Theme changed", "Screenshot saved"), மற்றும் கட்டளை வரியிலிருந்து அனுப்பப்படும் முக்கியமான எச்சரிக்கைகள். உங்கள் முன் தங்களை வற்புறுத்த எல்லாவற்றையும் முக்கியமானதாகக் குறிக்கும் அரட்டை செயலிகள் தகுதி பெறாது.

### செயலற்ற நிலை

Omarchy ஷெல் செயலற்ற நடத்தையைச் சொந்தமாக்குகிறது, மேலும் நேரங்கள் `~/.config/omarchy/shell.json` இல் ஒரு மேல்-நிலை `idle` தொகுதி:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

இரண்டு எண்களும் நீங்கள் செயலற்ற நிலைக்குச் சென்ற தருணத்திலிருந்து கணக்கிடப்படும் வினாடிகள் — ஒன்றிலிருந்து மற்றொன்று அல்ல. எனவே இயல்புநிலைகளுடன், திரைசேமிப்பு இரண்டரை நிமிடங்களுக்குப் பிறகு வருகிறது மற்றும் பூட்டுத் திரை ஐந்து நிமிடங்களில் எடுத்துக் கொள்கிறது, திரைசேமிப்பு இயங்கினாலும் இல்லாவிட்டாலும். கோப்பைச் சேமிக்கவும், ஷெல் புதிய நேரங்களை உடனடியாக எடுக்கும்.

பூட்டு காலக்கெடுவிற்கு முன் திரைசேமிப்பை நிராகரித்தால், அது செயல்பாடாகக் கணக்கிடப்படுகிறது மற்றும் நிலுவையில் உள்ள பூட்டு ரத்து செய்யப்படுகிறது. உங்கள் இயந்திரத்தைப் பார்ப்பதற்காக நீங்கள் பூட்டப்பட மாட்டீர்கள்.

செயலற்ற நிலையில் பூட்டுவதை முழுவதுமாக நிறுத்த, `Super + Ctrl + I` — அல்லது `omarchy toggle idle` — விழித்திருவை இயக்குகிறது, மேலும் காபி கோப்பை குறிகாட்டி பட்டையில் தோன்றும். ஒரு நீண்ட விளக்கக்காட்சிக்கு முன் அல்லது நீங்கள் பார்க்க விரும்பும் ஒரு உருவாக்கத்திற்கு முன் அழுத்த வேண்டியது அதுதான். இயல்பு நிலைக்குத் திரும்ப அதை மீண்டும் அழுத்தவும். `omarchy toggle idle status` ஒரு ஸ்கிரிப்டிலிருந்து உங்களுக்குத் தேவைப்பட்டால் தற்போதைய நிலையை JSON ஆக அச்சிடுகிறது.

இது பூட்டுதல் மற்றும் திரைசேமிப்பு பற்றியது, மின்சக்தி பற்றியது அல்ல. இடைநிறுத்தம் மற்றும் உறக்கம் ஆகியவற்றுக்கு [கணினி உறக்கம்](36-system-sleep.md) இல் சொந்த அமைப்பு உள்ளது.

### திரைசேமிப்பு

Omarchy-இன் திரைசேமிப்பு என்பது சீரற்ற உரை விளைவுகள் வழியாக இயங்கும் ASCII கலை, ஒரு திரைக்கு ஒரு நிகழ்வு. எந்த விசை அல்லது சுட்டி இயக்கமும் அதிலிருந்து வெளியேறுகிறது.

_கணினி > திரைசேமிப்பு_ (`Super + Esc`) இலிருந்து தேவைக்கேற்ப அதைத் தொடங்கலாம், இது நீங்கள் செயலற்ற திரைசேமிப்பை அணைத்திருந்தாலும் அதை வற்புறுத்துகிறது. இயல்பாக அதற்கு எந்த ஹாட்கீயும் பிணைக்கப்படவில்லை.

`omarchy toggle screensaver` என்பது செயலற்ற ஒன்றை அணைக்கிறது, நீங்கள் வேலையிலிருந்து நேரடியாகப் பூட்டப்பட்ட நிலைக்குச் செல்ல விரும்பினால். அதற்கு அது கட்டமைக்கத் தெரிந்த ஒரு டெர்மினல் தேவை — Alacritty, Foot, Ghostty, அல்லது Kitty — மேலும் உங்கள் இயல்புநிலை டெர்மினல் வேறு ஏதாவது என்றால் அது உங்களுக்குச் சொல்லும்.

அது வரையும் லோகோ _பாணி > திரைசேமிப்பு_ இன் கீழ் மாற்ற உங்களுடையது. ஒரு png அல்லது svg ஐப் பதிவேற்றவும், Omarchy அதை ASCII ஆக மாற்றுகிறது. [பிராண்டிங்](41-branding.md) பார்க்கவும்.

### பூட்டுத் திரை

`Super + Ctrl + L` இயந்திரத்தைப் பூட்டுகிறது. அது Omarchy ஷெல்லிலிருந்து பூட்டுத் திரையை இயக்குகிறது, காட்சியை வெறுமையாக்குகிறது, உங்கள் விசைப்பலகை தளவமைப்பை முதலாவதாக மீட்டமைக்கிறது, எனவே நீங்கள் உங்கள் கடவுச்சொல்லை தவறான எழுத்துக்களில் தட்டச்சு செய்யவில்லை, மேலும் — நீங்கள் அதை இயக்கினால் — வெளியேறும் வழியில் 1Password-ஐப் பூட்டுகிறது.

பூட்டுத் திரை ஒரு கடவுச்சொல்லை எடுக்கிறது, மேலும் நீங்கள் ஒன்றை அமைத்தவுடன் அது ஒரு கைரேகையையும் எடுக்கும். அது, மற்றும் அங்கீகரிக்கும் பிற வழிகள், [வன்பொருள் அங்கீகாரம்](37-hardware-authentication.md) இல் விவரிக்கப்பட்டுள்ளன.
