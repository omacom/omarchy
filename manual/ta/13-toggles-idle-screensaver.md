# நிலைமாற்றிகள், செயலில்லா நிலை & திரைக்காப்பு

நாள்தோறும் நீங்கள் மாற்றும் பலவும் உண்மையில் அமைப்பு அல்ல. ஒரு மணி நேரம் இயக்கிவிட்டு மீண்டும் அணைக்கும் ஒரு பயன்முறை அது: தாமதமாக வேலை செய்யும்போது இரவு ஒளி, விளக்கக்காட்சி அளிக்கும்போது தொந்தரவு செய்யாதே, எதையாவது பார்த்துக் கொண்டிருக்கும்போது விழித்திரு. Omarchy இவற்றை நிலைமாற்றிகள் என்று அழைக்கிறது, அவை அனைத்தும் ஒரே மாதிரிதான் செயல்படும் — ஒரு விசைச்சுருக்கம், ஒரு பட்டி உள்ளீடு, ஒரு கட்டளை, அனைத்தும் ஒரே நிலைமாற்றியைத்தான் தட்டும்.

### நிலைமாற்றிப் பட்டி

`Super + Ctrl + O` _Trigger > Toggle_ ஐ நேரடியாகத் திறக்கும், அல்லது Omarchy பட்டியிலிருந்து (`Super + Space`) நடந்து அங்கு செல்லலாம். அந்தப் பட்டியலில் உள்ள அனைத்தும், நிலை எங்கு வாழ்கிறது என்று யோசிக்காமலேயே நீங்கள் மாற்றக்கூடிய நிலைமாற்றிகள். மேசைத்தளம் எப்படித் தோற்றமளிக்கிறது என்பதற்கான நிலைமாற்றிகள் அதற்கு அருகிலேயே, _Appearance_ கீழ் அமர்ந்திருக்கும்.

முனையத்திலிருந்து, அதே நிலைமாற்றிகள் `omarchy toggle <thing>` ஆகும். முழுக் குழுவையும் காண `omarchy toggle` ஐத் தனியாக இயக்கவும்.

| நிலைமாற்றி | விசைச்சுருக்கம் | கட்டளை |
| ------ | ------ | ------- |
| இரவு ஒளி | — | `omarchy toggle nightlight` |
| அறிவிப்புகளை அமைதிப்படுத்துதல் | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| விழித்திரு (செயலில்லா பூட்டு இல்லை) | `Super + Ctrl + I` | `omarchy toggle idle` |
| செயலிழப்பு பதிவு | — | `omarchy toggle crash-capture` |
| திரைக்காப்பு | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) தீம் ஒத்திசைவு | — | `omarchy toggle theme sync` |
| பட்டிப் பட்டை | `Super + Shift + Space` | `omarchy toggle bar` |
| தொடுதட்டு | `XF86TouchpadToggle` | `omarchy device touchpad` |
| தொடுதிரை | — | `omarchy device touchscreen` |
| இடைநிறுத்தம் | — | `omarchy toggle suspend` |
| கலப்பு GPU | — | `omarchy toggle hybrid gpu` |

தொடுதட்டு, தொடுதிரை மற்றும் கலப்பு GPU நிலைமாற்றிகள் Toggle கீழ் அல்லாமல் _Trigger > Hardware_ (`Super + Ctrl + H`) கீழ் வாழ்கின்றன, ஏனெனில் அந்த வன்பொருள் உண்மையில் உங்களிடம் இருக்கும்போது மட்டுமே அவை தோன்றும். தொடுதட்டு மற்றும் தொடுதிரை நிலைமாற்றிகள் Hyprland மறுஏற்றத்திற்குப் பிறகும் நிலைக்கும் — முடக்கப்பட்ட சாதனத்தின் பெயர் ஒரு சிறிய நிலைக் கோப்பில் சேமிக்கப்படும், தொடக்கத்தில் Hyprland அதைப் படித்து அதை மீண்டும் முடக்கும்.

_Appearance_ பட்டிப் பட்டையையும் அசைவூட்டங்களையும் வைத்திருக்கிறது, அத்துடன் `omarchy toggle` கட்டளைகள் அல்லாத ஆனால் அதே போல் நடந்துகொள்ளும் சில விஷயங்களையும்: பட்டையில் மின்கல சதவீதம், இயல்புநிலை பணியிட அமைப்பு, மற்றும் _Windows_ கீழ், சாளர இடைவெளிகள் (`Super + Shift + Backspace`) மற்றும் 1-சாளர சதுர விகிதம் (`Super + Ctrl + Backspace`).

Hyprland க்கு வரைய GPU இல்லாமல் CPU இல் வரையும்போது (llvmpipe), GPU இன்னும் ஆதரிக்கப்படாத Macs களில், பெரும்பாலான மெய்நிகர் இயந்திரங்களில், அல்லது வரைகலை இயக்கி ஏற்றத் தவறும்போது போல, Omarchy அந்த அமர்வுக்கு அசைவூட்டங்கள், மங்கல் மற்றும் நிழல்களை அணைத்துவிட்டு, ஒரு அறிவிப்பின் மூலம் ஒருமுறை அதை உங்களுக்குச் சொல்லும். _Appearance > Animations On_ அவற்றை மீண்டும் கொண்டுவரும், பிற்கால அமர்வுகளுக்கும் Omarchy அதை நினைவில் வைத்திருக்கும்.

இவற்றில் பெரும்பாலானவை `~/.local/state/omarchy/toggles/` கீழ் உள்ள ஒரு கொடிக் கோப்பு மட்டுமே. ஒரு ஸ்கிரிப்டில் ஒன்றை வைத்துக் கிளை பிரிக்க விரும்பினால், நீங்களே தேடிச் செல்ல வைக்காமல் `omarchy-toggle-enabled` உங்களுக்கு ஒரு வெளியேற்றக் குறியீட்டைக் கொடுக்கும்:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

கொடிகள் அணைந்த நிலைக்காகப் பெயரிடப்பட்டுள்ளன — `screensaver-off`, `suspend-off`, `bar-off` — எனவே அவை இருப்பதே அந்த அம்சம் முடக்கப்பட்டுள்ளது என்று பொருள்.

### பட்டையில் குறிகாட்டிகள்

ஒரு பயன்முறை இயக்கத்தில் இருக்கும்போது, மேல் பட்டையின் நடுவில் கடிகாரத்திற்கு அருகில் ஒரு சிறிய குறியீட்டைப் பெறுவீர்கள். அதுதான் குறிகாட்டிகள் விட்ஜெட், அது பேச்செழுத்து, திரைப் பதிவு, நிலுவையில் உள்ள நினைவூட்டல்கள், இரவு ஒளி, தொந்தரவு செய்யாதே மற்றும் விழித்திரு ஆகியவற்றைக் கொண்டு செல்கிறது.

செயலற்ற குறிகாட்டிகள் மறைக்கப்பட்டிருக்கும். பட்டையில் எங்காவது வட்டமிட்டால் அவை மங்கலாகத் தோன்றும், எனவே அதன் விசைச்சுருக்கத்தை அறியாமலேயே ஒன்றைச் சொடுக்கி இயக்கலாம். செயலில் உள்ள ஒன்றைச் சொடுக்கினால் அது மீண்டும் அணையும். அவை அனைத்தையும் எப்போதும் காண விரும்பினால், `~/.config/omarchy/shell.json` இல் உள்ள `omarchy.indicators` உள்ளீட்டில் `alwaysShow` ஐ `true` என அமைக்கவும் — பட்டை விட்ஜெட்கள் எப்படி உள்ளமைக்கப்படுகின்றன என்பதற்கு [மேல் பட்டை](05-the-top-bar.md) ஐப் பார்க்கவும்.

### இரவு ஒளி

இரவு ஒளி திரையை 4000K க்குச் சூடாக்குகிறது, மீண்டும் நிலைமாற்றினால் அது 6500K க்குத் திரும்பும். நிலைமாற்றிப் பட்டியிலிருந்து (`Super + Ctrl + O`) அல்லது `omarchy toggle nightlight` கொண்டு அதை மாற்றவும். இது hyprsunset ஆல் இயக்கப்படுகிறது, அது ஏற்கனவே இயங்கவில்லை என்றால் நிலைமாற்றி அதை உங்களுக்காகத் தொடங்கும்.

இயல்பாக hyprsunset உங்கள் திரைக்கு எதுவுமே செய்யாது. `~/.config/hypr/hyprsunset.conf` ஒரு அடையாள சுயவிவரத்துடன் வருகிறது, நீங்கள் சூடு கேட்கும் வரை காட்சி தீண்டப்படாமல் இருக்கவேண்டும் என்பதற்காகவே. கடிகாரப்படி அது மாறுவதை விரும்பினால், அதை ஒரு நேர சுயவிவரத்தால் மாற்றவும்:

```
profile {
    time = 20:00
    temperature = 4000
}
```

பிறகு `~/.config/hypr/autostart.lua` இல் `o.launch_on_start("hyprsunset")` ஐச் சேர்த்து உள்நுழைவில் hyprsunset ஐத் தொடங்கவும். நிலைமாற்றி பயன்படுத்தும் 4000K/6500K இணை நிலையானது, எனவே வேறு வெப்பநிலை வேண்டுமென்றால் உள்ளமைவுக் கோப்புக்குத்தான் செல்ல வேண்டும்.

### தொந்தரவு செய்யாதே

`Super + Ctrl + Alt + ,` அறிவிப்புகளை அமைதிப்படுத்தும். அது இயக்கத்தில் இருக்கும்போது எந்த மேல்தோன்றலும் வராது, மேசைத்தளம் ஏன் அமைதியாகிவிட்டது என்பதை நினைவூட்ட குறிக்கப்பட்ட மணி குறிகாட்டி பட்டையில் அமர்ந்திருக்கும்.

ஆனால் எதுவும் இழக்கப்படுவதில்லை. அமைதிப்படுத்தப்பட்ட அறிவிப்புகள் தடுத்து வைக்கப்படும்: கடைசி சிலவற்றை `Super + Shift + Alt + ,` கொண்டு மீண்டும் திரையில் வைக்கவும். மீதிக்கு [அறிவிப்புகள்](10-notices.md) ஐப் பார்க்கவும்.

இரண்டு வகை செய்திகள் இன்னும் ஊடுருவி வரும்: நீங்கள் இப்போதுதான் செய்த ஒன்றுக்கான Omarchy இன் சொந்த உறுதிப்படுத்தல் மேல்தோன்றல்கள் ("தீம் மாற்றப்பட்டது", "திரைப்படம் சேமிக்கப்பட்டது"), மற்றும் கட்டளை வரியிலிருந்து அனுப்பப்படும் முக்கியமான எச்சரிக்கைகள். உங்கள் முன் வலுக்கட்டாயமாக வருவதற்காக எல்லாவற்றையும் முக்கியமானது எனக் குறிக்கும் அரட்டை செயலிகள் தகுதி பெறாது.

### செயலில்லா நிலை

Omarchy ஷெல் செயலில்லா நடத்தையைச் சொந்தமாக வைத்திருக்கிறது, நேரங்கள் `~/.config/omarchy/shell.json` இல் மேல்நிலை `idle` தொகுதியாக உள்ளன:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

இரண்டு எண்களும் நீங்கள் செயலில்லாமல் ஆன தருணத்திலிருந்து கணக்கிடப்படும் வினாடிகள் — ஒன்றிலிருந்து மற்றொன்று அல்ல. எனவே இயல்புநிலைகளுடன், இரண்டரை நிமிடங்களுக்குப் பிறகு திரைக்காப்பு வரும், ஐந்து நிமிடங்களில் பூட்டுத் திரை எடுத்துக்கொள்ளும், திரைக்காப்பு இயங்கியிருந்தாலும் இல்லாவிட்டாலும். கோப்பைச் சேமித்தால் ஷெல் புதிய நேரங்களை உடனடியாக எடுத்துக்கொள்ளும்.

பூட்டுக் காலக்கெடுவுக்கு முன் திரைக்காப்பை நீக்கினால், அது செயல்பாடாகக் கணக்கிடப்படும், நிலுவையில் உள்ள பூட்டு ரத்து செய்யப்படும். உங்கள் இயந்திரத்தை ஒரு பார்வை பார்த்ததற்காக நீங்கள் பூட்டப்பட மாட்டீர்கள்.

செயலில்லா நிலையில் பூட்டுவதை முற்றிலும் நிறுத்த, `Super + Ctrl + I` — அல்லது `omarchy toggle idle` — விழித்திருவை இயக்கும், காபி கோப்பை குறிகாட்டி பட்டையில் தோன்றும். நீண்ட விளக்கக்காட்சிக்கு முன் அல்லது நீங்கள் பார்க்க விரும்பும் ஒரு உருவாக்கத்திற்கு முன் தட்ட வேண்டியது அதுதான். இயல்புக்குத் திரும்ப மீண்டும் தட்டவும். ஒரு ஸ்கிரிப்டிலிருந்து தேவைப்பட்டால் `omarchy toggle idle status` தற்போதைய நிலையை JSON ஆக அச்சிடும்.

இது பூட்டுதல் மற்றும் திரைக்காப்பு பற்றியது, மின்சாரம் பற்றியது அல்ல. இடைநிறுத்தம் மற்றும் ஆழ்உறக்கத்திற்கு [கணினி உறக்கம்](36-system-sleep.md) இல் அவற்றுக்கான தனி அமைப்பு உள்ளது.

### திரைக்காப்பு

Omarchy இன் திரைக்காப்பு என்பது சீரற்ற உரை விளைவுகள் வழியாக ஓடும் ASCII கலை, ஒவ்வொரு திரைக்கும் ஒரு நிகழ்வு. எந்த விசையும் அல்லது சுட்டி அசைவும் அதிலிருந்து வெளியேற்றும்.

நீங்கள் அதை _System > Screensaver_ (`Super + Esc`) இலிருந்து தேவைப்படும்போது தொடங்கலாம், செயலில்லா திரைக்காப்பை அணைத்திருந்தாலும் அது அதை வலுக்கட்டாயமாகக் கொண்டுவரும். இயல்பாக அதற்கு எந்த விசைச்சுருக்கமும் இணைக்கப்படவில்லை.

`omarchy toggle screensaver` தான் செயலில்லா ஒன்றை அணைக்கும், வேலையிலிருந்து நேரடியாகப் பூட்டப்பட்ட நிலைக்குச் செல்ல விரும்பினால். எந்த விசையும், சொடுக்கும், உருட்டலும் அல்லது சுட்டி அசைவும் அதை மூடும்.

அது வரையும் இலச்சினை உங்களால் மாற்றக்கூடியது, _Appearance > Branding > Screensaver_ கீழ். ஒரு png அல்லது svg ஐப் பதிவேற்றவும், Omarchy அதை ASCII ஆக மாற்றும். [முத்திரையிடல்](41-branding.md) ஐப் பார்க்கவும்.

### பூட்டுத் திரை

`Super + Ctrl + L` இயந்திரத்தைப் பூட்டும். அது Omarchy ஷெல்லிலிருந்து பூட்டுத் திரையை இயக்கும், காட்சியை வெறுமையாக்கும், தவறான எழுத்துக்களில் உங்கள் கடவுச்சொல்லைத் தட்டச்சு செய்யாதிருக்க உங்கள் விசைப்பலகை அமைப்பை முதல் ஒன்றுக்கு மீட்டமைக்கும், மேலும் — அது இயங்கிக் கொண்டிருந்தால் — வெளியேறும் வழியில் 1Password ஐப் பூட்டும்.

பூட்டுத் திரை ஒரு கடவுச்சொல்லை ஏற்கும், நீங்கள் ஒன்றை அமைத்தவுடன் கைரேகையையும் ஏற்கும். அதுவும், அங்கீகரிக்கும் பிற வழிகளும், [வன்பொருள் அங்கீகாரம்](37-hardware-authentication.md) இல் விவரிக்கப்பட்டுள்ளன.
