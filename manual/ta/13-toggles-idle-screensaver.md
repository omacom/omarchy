# நிலைமாற்றிகள், செயலற்ற நிலை & திரைக்காப்பு

நீங்கள் நாள்தோறும் மாற்றுவதில் பெரும்பாலானவை உண்மையில் ஒரு அமைப்பு அல்ல. அது ஒரு மணி நேரம் இயக்கிவிட்டு மீண்டும் அணைக்கும் ஒரு பயன்முறை: இரவு தாமதமாக வேலை செய்யும்போது இரவு ஒளி, விளக்கக்காட்சி அளிக்கும்போது தொந்தரவு செய்யாதே, ஏதாவது பார்த்துக்கொண்டிருக்கும்போது விழித்திருத்தல். Omarchy அவற்றை நிலைமாற்றிகள் என்று அழைக்கிறது, அவை அனைத்தும் ஒரே மாதிரியாகவே வேலை செய்கின்றன — ஒரு சுருக்குவிசை, ஒரு மெனு உள்ளீடு, ஒரு கட்டளை, அனைத்தும் ஒரே சுவிட்சைத் தட்டுகின்றன.

### நிலைமாற்றி மெனு

`Super + Ctrl + O` நேரடியாக _Trigger > Toggle_ ஐத் திறக்கிறது, அல்லது Omarchy மெனுவிலிருந்து (`Super + Space`) அங்கு நடந்து செல்லலாம். அந்தப் பட்டியலில் உள்ள அனைத்தும், நிலை எங்கு வாழ்கிறது என்று சிந்திக்காமலேயே நீங்கள் மாற்றக்கூடிய ஒரு சுவிட்ச். மேசைக்கணினி எப்படித் தோற்றமளிக்கிறது என்பதற்கான சுவிட்சுகள் அதற்கு அடுத்தபடியாக, _Appearance_ இன் கீழ் அமர்ந்திருக்கின்றன.

முனையத்திலிருந்து, அதே சுவிட்சுகள் `omarchy toggle <thing>`. முழுக் குழுவையும் காண `omarchy toggle` ஐத் தனியாக இயக்கவும்.

| நிலைமாற்றி | சுருக்குவிசை | கட்டளை |
| ------ | ------ | ------- |
| இரவு ஒளி | — | `omarchy toggle nightlight` |
| அறிவிப்புகளை அமைதிப்படுத்து | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| விழித்திரு (செயலற்ற பூட்டு இல்லை) | `Super + Ctrl + I` | `omarchy toggle idle` |
| செயலிழப்பு பதிவு | — | `omarchy toggle crash-capture` |
| திரைக்காப்பு | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) தீம் ஒத்திசைவு | — | `omarchy toggle theme sync` |
| மெனு பட்டை | `Super + Shift + Space` | `omarchy toggle bar` |
| டச்பேட் | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| டச்ஸ்கிரீன் | — | `omarchy toggle touchscreen` |
| இடைநிறுத்தம் | — | `omarchy toggle suspend` |
| Hybrid GPU | — | `omarchy toggle hybrid gpu` |

டச்பேட், டச்ஸ்கிரீன், மற்றும் Hybrid GPU சுவிட்சுகள் Toggle இன் கீழ் அல்லாமல் _Trigger > Hardware_ (`Super + Ctrl + H`) இன் கீழ் வாழ்கின்றன, ஏனெனில் அந்த வன்பொருள் உங்களிடம் உண்மையில் இருக்கும்போது மட்டுமே அவை தோன்றும். டச்பேட் மற்றும் டச்ஸ்கிரீன் சுவிட்சுகள் Hyprland மறுஏற்றத்திற்குப் பிறகும் நிலைத்திருக்கும் — முடக்கப்பட்ட சாதனத்தின் பெயர் ஒரு சிறிய நிலைக் கோப்பில் சேமிக்கப்படுகிறது, அதை Hyprland தொடக்கத்தில் படித்து அதை மீண்டும் முடக்குகிறது.

_Appearance_ மெனு பட்டையையும் அசைவூட்டங்களையும் வைத்திருக்கிறது, அத்துடன் `omarchy toggle` கட்டளைகள் அல்ல என்றாலும் அதே போல செயல்படும் சில விஷயங்களையும் வைத்திருக்கிறது: பட்டையில் மின்கல சதவீதம், இயல்புநிலை பணியிட தளவமைப்பு, மற்றும் _Windows_ இன் கீழ், சாளர இடைவெளிகள் (`Super + Shift + Backspace`) மற்றும் 1-சாளர சதுர விகிதம் (`Super + Ctrl + Backspace`).

இவற்றில் பெரும்பாலானவை `~/.local/state/omarchy/toggles/` இன் கீழ் உள்ள வெறும் ஒரு கொடிக் கோப்புதான். ஒரு ஸ்கிரிப்டில் ஒன்றைக் கொண்டு கிளை பிரிக்க விரும்பினால், நீங்களே தேடிச் செல்ல வைக்காமல் `omarchy-toggle-enabled` உங்களுக்கு ஒரு வெளியேற்றக் குறியீட்டைக் கொடுக்கிறது:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

கொடிகள் அணைந்த நிலைக்காகப் பெயரிடப்பட்டுள்ளன — `screensaver-off`, `suspend-off`, `bar-off` — எனவே அவை இருப்பது என்றால் அந்த அம்சம் முடக்கப்பட்டுள்ளது என்று பொருள்.

### பட்டையில் உள்ள குறிகாட்டிகள்

ஒரு பயன்முறை இயங்கும்போது, கடிகாரத்திற்கு அடுத்தபடியாக மேல் பட்டையின் நடுவில் ஒரு சிறிய கிளிஃப் உங்களுக்குக் கிடைக்கிறது. அதுதான் குறிகாட்டிகள் விட்ஜெட், அது டிக்டேஷன், திரைப் பதிவு, நிலுவையில் உள்ள நினைவூட்டல்கள், இரவு ஒளி, தொந்தரவு செய்யாதே, மற்றும் விழித்திருத்தல் ஆகியவற்றைக் கொண்டுள்ளது.

செயலற்ற குறிகாட்டிகள் மறைக்கப்படும். பட்டையின் மீது எங்காவது வட்டமிடுங்கள், அவை மங்கலாக மறைவிலிருந்து தோன்றும், எனவே அதன் சுருக்குவிசையை அறியாமலேயே ஒன்றைக் கிளிக் செய்து இயக்கலாம். செயலில் உள்ள ஒன்றைக் கிளிக் செய்வது அதை மீண்டும் அணைக்கிறது. அவை அனைத்தையும் எல்லா நேரமும் காண விரும்பினால், `~/.config/omarchy/shell.json` இல் உள்ள `omarchy.indicators` உள்ளீட்டில் `alwaysShow` ஐ `true` என அமைக்கவும் — பட்டை விட்ஜெட்கள் எப்படி உள்ளமைக்கப்படுகின்றன என்பதற்கு [மேல் பட்டையைப்](05-the-top-bar.md) பார்க்கவும்.

### இரவு ஒளி

இரவு ஒளி திரையை 4000K க்கு சூடாக்குகிறது, அதை மீண்டும் நிலைமாற்றுவது அதை 6500K க்குத் திருப்புகிறது. நிலைமாற்றி மெனுவிலிருந்து (`Super + Ctrl + O`) அல்லது `omarchy toggle nightlight` கொண்டு அதை மாற்றவும். இது hyprsunset ஆல் இயக்கப்படுகிறது, அது ஏற்கனவே இயங்கவில்லை என்றால் நிலைமாற்றி உங்களுக்காக அதைத் தொடங்குகிறது.

இயல்பாக hyprsunset உங்கள் திரைக்கு எதுவுமே செய்வதில்லை. `~/.config/hypr/hyprsunset.conf` ஒரு அடையாள சுயவிவரத்துடன் வருகிறது, துல்லியமாக அதனால்தான் நீங்கள் சூட்டைக் கேட்கும் வரை காட்சி தீண்டப்படாமல் இருக்கிறது. அது கடிகாரத்தின்படி மாறுவதை நீங்கள் விரும்பினால், அதை ஒரு நேர சுயவிவரத்தால் மாற்றவும்:

```
profile {
    time = 20:00
    temperature = 4000
}
```

பின்னர் `~/.config/hypr/autostart.lua` இல் `o.launch_on_start("hyprsunset")` ஐச் சேர்ப்பதன் மூலம் உள்நுழைவில் hyprsunset ஐத் தொடங்கவும். நிலைமாற்றி பயன்படுத்தும் 4000K/6500K ஜோடி நிலையானது, எனவே வேறு வெப்பநிலை வேண்டுமென்றால் உள்ளமைவுக் கோப்புதான் நீங்கள் செல்ல வேண்டிய இடம்.

### தொந்தரவு செய்யாதே

`Super + Ctrl + Alt + ,` அறிவிப்புகளை அமைதிப்படுத்துகிறது. அது இயங்கும்போது எந்த டோஸ்டுகளும் தோன்றாது, மேசைக்கணினி ஏன் அமைதியாகிவிட்டது என்பதை உங்களுக்கு நினைவூட்ட குறுக்குக் கோடிட்ட மணி குறிகாட்டி பட்டையில் அமர்ந்திருக்கும்.

ஆனால் எதுவும் இழக்கப்படுவதில்லை. அமைதிப்படுத்தப்பட்ட அறிவிப்புகள் தடுத்து வைக்கப்படுகின்றன: கடைசி சிலவற்றை `Super + Shift + Alt + ,` கொண்டு மீண்டும் திரையில் வைக்கவும். மீதமுள்ளவற்றுக்கு [அறிவிப்புகளைப்](10-notices.md) பார்க்கவும்.

இரண்டு வகையான செய்திகள் இன்னும் கடந்து வருகின்றன: நீங்கள் இப்போதுதான் செய்த ஒன்றுக்கான Omarchy இன் சொந்த உறுதிப்படுத்தல் டோஸ்டுகள் ("Theme changed", "Screenshot saved"), மற்றும் கட்டளை வரியிலிருந்து அனுப்பப்படும் முக்கியமான எச்சரிக்கைகள். உங்கள் முன்னால் தங்களை வலுக்கட்டாயமாகக் கொண்டுவர எல்லாவற்றையும் முக்கியமானது எனக் குறிக்கும் அரட்டை பயன்பாடுகள் தகுதி பெறாது.

### செயலற்ற நிலை

Omarchy ஷெல் செயலற்ற நடத்தையைச் சொந்தமாகக் கொண்டுள்ளது, நேரங்கள் `~/.config/omarchy/shell.json` இல் ஒரு மேல்நிலை `idle` தொகுதியாக உள்ளன:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

இரண்டு எண்களும் நீங்கள் செயலற்றுப் போன தருணத்திலிருந்து கணக்கிடப்படும் வினாடிகள் — ஒன்றிலிருந்து மற்றொன்று அல்ல. எனவே இயல்புநிலைகளுடன், திரைக்காப்பு இரண்டரை நிமிடங்களுக்குப் பிறகு வருகிறது, திரைக்காப்பு இயங்கினாலும் இல்லாவிட்டாலும் பூட்டுத் திரை ஐந்து நிமிடங்களில் பொறுப்பேற்கிறது. கோப்பைச் சேமியுங்கள், ஷெல் புதிய நேரங்களை உடனடியாக எடுத்துக்கொள்கிறது.

பூட்டு காலக்கெடுவுக்கு முன்பே திரைக்காப்பை நிராகரித்தால், அது செயல்பாடாகக் கணக்கிடப்படுகிறது, நிலுவையில் உள்ள பூட்டு ரத்து செய்யப்படுகிறது. உங்கள் கணினியை ஒரு பார்வை பார்த்ததற்காக நீங்கள் பூட்டப்பட மாட்டீர்கள்.

செயலற்ற நிலையில் பூட்டுவதை முற்றிலும் நிறுத்த, `Super + Ctrl + I` — அல்லது `omarchy toggle idle` — விழித்திருத்தலை இயக்குகிறது, காபி கோப்பை குறிகாட்டி பட்டையில் தோன்றுகிறது. நீண்ட விளக்கக்காட்சிக்கு முன்போ அல்லது நீங்கள் பார்க்க விரும்பும் ஒரு உருவாக்கத்திற்கு முன்போ தட்ட வேண்டியது அதுதான். இயல்புநிலைக்குத் திரும்ப அதை மீண்டும் தட்டவும். ஒரு ஸ்கிரிப்டிலிருந்து உங்களுக்குத் தேவைப்பட்டால் `omarchy toggle idle status` தற்போதைய நிலையை JSON ஆக அச்சிடுகிறது.

இது பூட்டுதல் மற்றும் திரைக்காப்பு பற்றியது, மின்சாரம் பற்றியது அல்ல. இடைநிறுத்தம் மற்றும் உறக்கநிலைக்கு [கணினி உறக்கத்தில்](36-system-sleep.md) அவற்றுக்கான சொந்த அமைப்பு உள்ளது.

### திரைக்காப்பு

Omarchy இன் திரைக்காப்பு சீரற்ற உரை விளைவுகள் வழியாக இயங்கும் ASCII கலை, ஒரு கணினித்திரைக்கு ஒரு நிகழ்வு. எந்த விசையும் அல்லது சுட்டி அசைவும் அதிலிருந்து வெளியேறுகிறது.

செயலற்ற திரைக்காப்பை நீங்கள் அணைத்திருந்தாலும் கூட அதை வலுக்கட்டாயமாகக் கொண்டுவரும் _System > Screensaver_ (`Super + Esc`) இலிருந்து தேவைப்படும்போது அதைத் தொடங்கலாம். இயல்பாக அதற்கு எந்த சுருக்குவிசையும் கட்டப்படவில்லை.

நீங்கள் வேலையிலிருந்து நேரடியாகப் பூட்டப்பட்ட நிலைக்குச் செல்ல விரும்பினால், செயலற்ற திரைக்காப்பை அணைப்பது `omarchy toggle screensaver` தான். அதற்கு எப்படி உள்ளமைப்பது என்று தெரிந்த ஒரு முனையம் தேவை — Alacritty, Foot, Ghostty, அல்லது Kitty — உங்கள் இயல்புநிலை முனையம் வேறு ஏதாவது என்றால் அது உங்களிடம் அப்படியே சொல்லும்.

அது வரையும் லோகோவை மாற்றுவது உங்களுடையது, _Appearance > Branding > Screensaver_ இன் கீழ். ஒரு png அல்லது svg ஐப் பதிவேற்றவும், Omarchy அதை ASCII ஆக மாற்றுகிறது. [பிராண்டிங்கைப்](41-branding.md) பார்க்கவும்.

### பூட்டுத் திரை

`Super + Ctrl + L` கணினியைப் பூட்டுகிறது. அது Omarchy ஷெல்லிலிருந்து பூட்டுத் திரையை இயக்குகிறது, காட்சியை வெறுமையாக்குகிறது, உங்கள் கடவுச்சொல்லைத் தவறான எழுத்துகளில் தட்டச்சு செய்யாமல் இருக்க உங்கள் விசைப்பலகை தளவமைப்பை முதலாவதற்கு மீட்டமைக்கிறது, மேலும் — நீங்கள் அதை இயக்கிக் கொண்டிருந்தால் — வெளியேறும் வழியில் 1Password ஐப் பூட்டுகிறது.

பூட்டுத் திரை ஒரு கடவுச்சொல்லை ஏற்கிறது, நீங்கள் ஒன்றை அமைத்தவுடன் அது ஒரு கைரேகையையும் ஏற்கும். அது, மற்றும் அங்கீகரிப்பதற்கான பிற வழிகள், [வன்பொருள் அங்கீகாரத்தில்](37-hardware-authentication.md) விவரிக்கப்பட்டுள்ளன.
