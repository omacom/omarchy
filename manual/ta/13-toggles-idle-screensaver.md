# மாற்றுநிலைகள், செயலறுநிலை & திரைக்காவல்

நீங்கள் நாள்தோறும் மாற்றுவவற்றில் பெரும்பாலானவை உண்மையில் அமைப்புகளே அல்ல. அவை ஒரு மணி நேரம் இயக்கிவிட்டு, பிறகு அணைத்துவிடும் ஒரு பயன்முறை: தாமதமாக வேலை செய்யும்போது இரவு விளக்கு, விளக்கக்காட்சி அளிக்கும்போது தொந்தரவு செய்யாதே, எதையாவது பார்த்துக் கொண்டிருக்கும்போது விழித்திரு. Omarchy அவற்றை மாற்றுநிலைகள் என்று அழைக்கிறது, அவை எல்லாம் ஒரே மாதிரிதான் செயல்படும் — ஒரு ஹாட்கீ, ஒரு மெனு உள்ளீடு, ஒரு கட்டளை, மூன்றும் ஒரே சுவிட்சையே தட்டும்.

### மாற்றுநிலை மெனு

`Super + Ctrl + O` ஆனது _Trigger > Toggle_-ஐ நேரடியாகத் திறக்கும், அல்லது Omarchy மெனுவிலிருந்து (`Super + Space`) நீங்கள் அங்கு நடந்து செல்லலாம். அந்தப் பட்டியலில் உள்ள அனைத்தும் நிலை எங்கு வாழ்கிறது என்று சிந்திக்காமலேயே நீங்கள் மாற்றக்கூடிய சுவிட்சுகள். டெஸ்க்டாப் எப்படித் தோற்றமளிக்கிறது என்பதற்கான சுவிட்சுகள் அதற்கு அருகிலேயே, _Appearance_-இன் கீழ் அமர்ந்திருக்கும்.

டெர்மினலிலிருந்து, அதே சுவிட்சுகள் `omarchy toggle <thing>` ஆகும். முழுக் குழுவையும் பார்க்க `omarchy toggle`-ஐத் தனியாக இயக்கவும்.

| மாற்றுநிலை | ஹாட்கீ | கட்டளை |
| ------ | ------ | ------- |
| இரவு விளக்கு | — | `omarchy toggle nightlight` |
| அறிவிப்புகளை அமைதிப்படுத்து | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| விழித்திரு (செயலறுநிலை பூட்டு இல்லை) | `Super + Ctrl + I` | `omarchy toggle idle` |
| செயலிழப்புப் பதிவு | — | `omarchy toggle crash-capture` |
| திரைக்காவல் | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) தீம் ஒத்திசைவு | — | `omarchy toggle theme sync` |
| மெனு பட்டை | `Super + Shift + Space` | `omarchy toggle bar` |
| முழுத்திரை டெஸ்க்டாப் (பட்டை இல்லை, இடைவெளிகள் இல்லை) | `Super + Ctrl + Alt + F` | `omarchy toggle fullscreen desktop` |
| அனிமேஷன்கள், மங்கல் மற்றும் நிழல்கள் | — | `omarchy toggle animations` |
| டச்பேட் | `XF86TouchpadToggle` | `omarchy device touchpad` |
| தொடுதிரை | — | `omarchy device touchscreen` |
| இடைநிறுத்தம் | — | `omarchy toggle suspend` |
| கலப்பு GPU | — | `omarchy device gpu hybrid` |

டச்பேட், தொடுதிரை மற்றும் கலப்பு GPU சுவிட்சுகள் Toggle-இன் கீழ் அல்லாமல் _Trigger > Hardware_ (`Super + Ctrl + H`)-இன் கீழ் வாழ்கின்றன, ஏனெனில் அந்த வன்பொருள் உங்களிடம் உண்மையில் இருக்கும்போது மட்டுமே அவை தோன்றும். டச்பேட் மற்றும் தொடுதிரை சுவிட்சுகள் Hyprland மறுஏற்றத்தையும் தாண்டி நிலைத்திருக்கும் — முடக்கப்பட்ட சாதனத்தின் பெயர் ஒரு சிறிய நிலைக் கோப்பில் சேமிக்கப்படுகிறது, தொடக்கத்தில் Hyprland அதைப் படித்து அதை மீண்டும் முடக்கும்.

_Appearance_ ஆனது மெனு பட்டையையும் அனிமேஷன்களையும் வைத்திருக்கிறது, அதோடு `omarchy toggle` கட்டளைகள் அல்ல என்றாலும் அதே போல் நடந்துகொள்ளும் சில விஷயங்களையும் வைத்திருக்கிறது: பட்டையில் பேட்டரி சதவீதம், இயல்புநிலை பணியிட அமைப்பு, மற்றும் _Windows_-இன் கீழ், சாளர இடைவெளிகள் (`Super + Shift + Backspace`) மற்றும் 1-சாளர சதுர விகிதம் (`Super + Ctrl + Backspace`).

Hyprland-இடம் வரைவதற்கு GPU இல்லாமல் அதற்குப் பதிலாக CPU-இல் ரெண்டர் செய்யும்போது (llvmpipe), GPU இன்னும் ஆதரிக்கப்படாத Mac-களில், பெரும்பாலான மெய்நிகர் இயந்திரங்களில், அல்லது ஒரு கிராபிக்ஸ் இயக்கி ஏற்றப்படத் தவறும்போது போல, Omarchy அந்த அமர்வுக்கு அனிமேஷன்கள், மங்கல் மற்றும் நிழல்களை அணைத்துவிட்டு, ஒரு அறிவிப்பு மூலம் ஒருமுறை உங்களுக்குச் சொல்லும். _Appearance > Animations On_ அவற்றைத் திரும்பக் கொண்டுவரும், பிற்கால அமர்வுகளுக்கும் Omarchy அதை நினைவில் வைத்திருக்கும்.

இவற்றில் பெரும்பாலானவை `~/.local/state/omarchy/toggles/`-இன் கீழ் உள்ள வெறும் ஒரு கொடிக் கோப்புதான். ஒரு ஸ்கிரிப்டில் ஒன்றை வைத்துக் கிளை பிரிக்க விரும்பினால், நீங்களே தேடிச் செல்ல வைக்காமல் `omarchy-toggle-enabled` உங்களுக்கு ஒரு வெளியேறும் குறியீட்டைத் தரும்:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

கொடிகள் அணைந்த நிலைக்காகப் பெயரிடப்பட்டுள்ளன — `screensaver-off`, `suspend-off`, `bar-off` — எனவே அவை இருப்பது என்றால் அந்த அம்சம் முடக்கப்பட்டுள்ளது என்று அர்த்தம்.

### பட்டையில் குறிகாட்டிகள்

ஒரு பயன்முறை இயக்கத்தில் இருக்கும்போது, கடிகாரத்திற்கு அருகில் மேல் பட்டையின் நடுவில் ஒரு சிறிய கிளிஃப் உங்களுக்குக் கிடைக்கும். அதுதான் குறிகாட்டிகள் விட்ஜெட், அது திரைப் பதிவு, நிலுவையில் உள்ள நினைவூட்டல்கள், இரவு விளக்கு, தொந்தரவு செய்யாதே மற்றும் விழித்திரு ஆகியவற்றைச் சுமக்கிறது, அதோடு கடவுச்சொல் இல்லாத sudo இயக்கத்தில் இருக்கும்போது அல்லது யாராவது ஒரு தொலைநிலை அமர்வுடன் இணைந்திருக்கும்போது எச்சரிக்கைகளையும் சுமக்கிறது.

செயலற்ற குறிகாட்டிகள் மறைக்கப்பட்டிருக்கும். பட்டையில் எங்காவது வட்டமிடுங்கள், அவை மங்கலாகத் தோன்றும், எனவே அதன் ஹாட்கீ தெரியாமலேயே ஒன்றைக் கிளிக் செய்து இயக்கலாம். செயலில் உள்ள ஒன்றைக் கிளிக் செய்தால் அது மீண்டும் அணைந்துவிடும். அவை எல்லாவற்றையும் எல்லா நேரமும் பார்க்க விரும்பினால், `~/.config/omarchy/shell.json`-இல் உள்ள `omarchy.indicators` உள்ளீட்டில் `alwaysShow`-ஐ `true` என அமைக்கவும் — பட்டை விட்ஜெட்கள் எப்படி உள்ளமைக்கப்படுகின்றன என்பதற்கு [மேல் பட்டை](05-the-top-bar.md)-ஐப் பார்க்கவும்.

### இரவு விளக்கு

இரவு விளக்கு திரையை 4000K-க்கு சூடாக்குகிறது, அதை மீண்டும் மாற்றினால் 6500K-க்குத் திரும்ப வைக்கிறது. மாற்றுநிலை மெனுவிலிருந்து (`Super + Ctrl + O`) அல்லது `omarchy toggle nightlight` மூலம் அதை மாற்றவும். இது hyprsunset ஆல் இயக்கப்படுகிறது, அது ஏற்கனவே இயங்கவில்லை என்றால் மாற்றுநிலை அதை உங்களுக்காகத் தொடங்கும்.

இயல்பாக hyprsunset உங்கள் திரைக்கு எதுவுமே செய்யாது. நீங்கள் சூட்சுமத்தைக் கேட்கும் வரை காட்சி தீண்டப்படாமல் இருக்கவேண்டும் என்பதற்காகவே `~/.config/hypr/hyprsunset.conf` ஒரு அடையாள சுயவிவரத்துடன் வருகிறது. அதற்குப் பதிலாக அது கடிகாரப்படி மாற விரும்பினால், அதை ஒரு நேர சுயவிவரத்தால் மாற்றவும்:

```
profile {
    time = 20:00
    temperature = 4000
}
```

பிறகு `~/.config/hypr/autostart.lua`-இல் `o.launch_on_start("hyprsunset")`-ஐச் சேர்ப்பதன் மூலம் உள்நுழைவில் hyprsunset-ஐத் தொடங்கவும். மாற்றுநிலை பயன்படுத்தும் 4000K/6500K இணை நிலையானது, எனவே வேறு வெப்பநிலை வேண்டுமென்றால் நீங்கள் செல்ல வேண்டிய இடம் உள்ளமைவுக் கோப்புதான்.

### தொந்தரவு செய்யாதே

`Super + Ctrl + Alt + ,` அறிவிப்புகளை அமைதிப்படுத்துகிறது. அது இயக்கத்தில் இருக்கும்போது எந்த டோஸ்டுகளும் தோன்றாது, டெஸ்க்டாப் ஏன் அமைதியாகிவிட்டது என்பதை நினைவூட்ட குறுக்குக்கோடு போட்ட மணி குறிகாட்டி பட்டையில் அமர்ந்திருக்கும்.

ஆனால் எதுவும் தொலைந்துபோகாது. அமைதிப்படுத்தப்பட்ட அறிவிப்புகள் தடுத்து வைக்கப்படுகின்றன: கடைசி சிலவற்றை `Super + Shift + Alt + ,` மூலம் திரைக்குத் திரும்ப வைக்கவும். மீதமுள்ளவற்றுக்கு [அறிவிப்புகள்](10-notices.md)-ஐப் பார்க்கவும்.

மூன்று வகையான செய்திகள் இன்னும் ஊடுருவி வரும்: நீங்கள் இப்போது செய்த ஒன்றுக்கான Omarchy-இன் சொந்த உறுதிப்படுத்தல் டோஸ்டுகள் ("Theme changed", "Screenshot saved"), கட்டளை வரியிலிருந்து அனுப்பப்படும் முக்கியமான எச்சரிக்கைகள், மற்றும் சரிபார்ப்புக் குறியீடுகள். உங்கள் முன் தங்களைத் திணிக்க எல்லாவற்றையும் முக்கியமானது என்று குறிக்கும் அரட்டைச் செயலிகள் தகுதி பெறாது.

### செயலறுநிலை

Omarchy ஷெல் செயலறுநிலை நடத்தையைச் சொந்தமாக வைத்திருக்கிறது, நேரங்கள் `~/.config/omarchy/shell.json`-இல் ஒரு மேல்நிலை `idle` தொகுதியாகும்:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

இரண்டு எண்களும் நீங்கள் செயலற்றுப் போன தருணத்திலிருந்து கணக்கிடப்படும் வினாடிகள் — ஒன்றிலிருந்து மற்றொன்று அல்ல. எனவே இயல்புநிலைகளுடன், இரண்டரை நிமிடங்களுக்குப் பிறகு திரைக்காவல் வரும், திரைக்காவல் இயங்கினாலும் இல்லாவிட்டாலும் ஐந்து நிமிடங்களில் பூட்டுத் திரை பொறுப்பேற்கும். கோப்பைச் சேமியுங்கள், ஷெல் புதிய நேரங்களை உடனடியாக எடுத்துக்கொள்ளும்.

பூட்டு காலக்கெடுவுக்கு முன் திரைக்காவலை நீக்கிவிட்டால், அது செயல்பாடாகக் கணக்கிடப்பட்டு நிலுவையில் உள்ள பூட்டு ரத்து செய்யப்படும். உங்கள் இயந்திரத்தை ஒரு பார்வை பார்த்ததற்காக நீங்கள் பூட்டப்படமாட்டீர்கள்.

செயலறுநிலையில் பூட்டுவதை முற்றிலும் நிறுத்த, `Super + Ctrl + I` — அல்லது `omarchy toggle idle` — விழித்திருப்பை இயக்கும், காபி கோப்பை குறிகாட்டி பட்டையில் தோன்றும். நீண்ட விளக்கக்காட்சிக்கு முன் அல்லது நீங்கள் பார்க்க விரும்பும் ஒரு பில்டுக்கு முன் தட்ட வேண்டியது அதுதான். இயல்புக்குத் திரும்ப அதை மீண்டும் தட்டவும். ஒரு ஸ்கிரிப்டிலிருந்து உங்களுக்குத் தேவைப்பட்டால் `omarchy toggle idle status` தற்போதைய நிலையை JSON ஆக அச்சிடும்.

இது பூட்டுவது மற்றும் திரைக்காவல் பற்றியது, மின்சாரம் பற்றியது அல்ல. இடைநிறுத்தம் மற்றும் உறக்கநிலைக்கு [கணினி உறக்கம்](36-system-sleep.md)-இல் அவற்றுக்கெனத் தனி அமைப்பு உள்ளது.

### திரைக்காவல்

Omarchy-இன் திரைக்காவல் என்பது சீரற்ற உரை விளைவுகள் வழியாக ஓடும் ASCII கலை, ஒரு மானிட்டருக்கு ஒரு நிகழ்வு. எந்த விசையும் அல்லது சுட்டி அசைவும் அதிலிருந்து வெளியேறும்.

செயலறுநிலை திரைக்காவலை அணைத்திருந்தாலும் கூட அதை வலுக்கட்டாயமாக ஏற்றும் _System > Screensaver_ (`Super + Esc`)-இலிருந்து தேவைக்கேற்ப அதைத் தொடங்கலாம். இயல்பாக அதற்கு எந்த ஹாட்கீயும் கட்டப்படவில்லை.

வேலையிலிருந்து நேராகப் பூட்டப்பட்ட நிலைக்குச் செல்ல விரும்பினால், செயலறுநிலை திரைக்காவலை அணைப்பது `omarchy toggle screensaver` தான். எந்த விசை, கிளிக், உருட்டல் அல்லது சுட்டி அசைவும் அதை மூடும்.

அது வரையும் லோகோவை மாற்றுவது உங்களுடையது, _Appearance > Branding > Screensaver_-இன் கீழ். ஒரு png அல்லது svg-ஐப் பதிவேற்றுங்கள், Omarchy அதை ASCII ஆக மாற்றும். [முத்திரையாக்கம்](41-branding.md)-ஐப் பார்க்கவும்.

### பூட்டுத் திரை

`Super + Ctrl + L` இயந்திரத்தைப் பூட்டும். அது Omarchy ஷெல்லிலிருந்து பூட்டுத் திரையை இயக்கும், காட்சியை வெறுமையாக்கும், தவறான எழுத்துமுறையில் உங்கள் கடவுச்சொல்லைத் தட்டச்சு செய்யாதபடி உங்கள் விசைப்பலகை அமைப்பை முதலாவதற்கு மீட்டமைக்கும், மேலும் — நீங்கள் அதை இயக்கி வைத்திருந்தால் — வெளியேறும் வழியில் 1Password-ஐப் பூட்டும்.

பூட்டுத் திரை ஒரு கடவுச்சொல்லை ஏற்கும், நீங்கள் ஒன்றை அமைத்தவுடன் அது ஒரு கைரேகையையும் ஏற்கும். அது, மற்றும் அங்கீகரிப்பதற்கான மற்ற வழிகள், [வன்பொருள் அங்கீகாரம்](37-hardware-authentication.md)-இல் விவரிக்கப்பட்டுள்ளன.
