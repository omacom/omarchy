# விசைப்பலகை, மவுஸ், டிராக்பேட்

Hyprland உங்கள் அனைத்து உள்ளீடுகளையும் மிக விரிவாக உள்ளமைக்க உங்களை அனுமதிக்கிறது. விசைப்பலகை மீண்டும் அழுத்தப்படுவதை மீயொலி வேகமாக மாற்றலாம் அல்லது டிராக்பேட்டை இயற்கை உருட்டலைப் பயன்படுத்தச் செய்யலாம். இவற்றையெல்லாம் `~/.config/hypr/input.lua`-இல் மாற்றுகிறீர்கள், Omarchy மெனுவில் (`Super + Space`) _Setup > Input_ வழியாகவும் அதை அடையலாம். அங்கு நீங்கள் அமைப்பது எதுவும் Omarchy-இன் இயல்புநிலைகளை மாற்றிவிடும்.

இதோ ஒரு எடுத்துக்காட்டு:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

உள்ளீடுகளுக்கான Hyprland wiki-இல் [அனைத்து உள்ளீட்டு விருப்பங்களையும் காணலாம்](https://wiki.hypr.land/Configuring/Basics/Variables/#input).

CapsLock ஒரு சாதாரண Caps Lock ஆகச் செயல்படுகிறது, மேலும் `Shift + CapsLock` என்பது [விரைவு எமோஜிகளுக்கான](07-hotkeys.md#quick-emojis) மற்றும் [பிற நிறைவுகளுக்கான](07-hotkeys.md#quick-completions) compose விசையாகும். compose விசை வேறு இடத்தில் இருக்க வேண்டும் என்று நீங்கள் விரும்பினால், `kb_options`-இல் `omarchy:shift_caps_compose`-ஐ மாற்றவும். எடுத்துக்காட்டாக, இது compose விசையை Right Alt-க்கு நகர்த்துகிறது:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### செயல்பாட்டு விசைகள்

மடிக்கணினி விசைப்பலகையின் மேல் வரிசை இயல்பாகவே மீடியா விசைகளை (ஒலியளவு, பிரகாசம் போன்றவை) அனுப்புகிறது, `Fn`-ஐ அழுத்திப் பிடித்தால் F1-F12 கிடைக்கும்; `Fn + Esc` நீங்கள் அதை மீண்டும் அழுத்தும் வரை அதை எதிர்மாறாகப் பூட்டுகிறது. பெரும்பாலான விசைப்பலகைகள் அந்தப் பூட்டைத் தாங்களே நினைவில் வைத்திருக்கின்றன. ASUS மடிக்கணினிகளும் Apple பாணி விசைப்பலகைகளும் அதை Linux-இடம் விட்டுவிடுகின்றன, அது ஒவ்வொரு துவக்கத்திலும் அவற்றை மீடியா விசைகளில் தொடங்குகிறது. அதற்குப் பதிலாக அவை F1-F12-இல் தொடங்க வேண்டும் என்றால், `omarchy keyboard toprow fnkeys`-ஐ இயக்கவும் (திரும்பச் செல்ல `omarchy keyboard toprow mediakeys`); சில மடிக்கணினிகளில் மறுதொடக்கத்திற்குப் பிறகு அது நடைமுறைக்கு வரும். Apple Silicon Mac-கள் தங்கள் சொந்த அமைப்பை வைத்திருக்கின்றன.

### டிராக்பேட் சைகைகள்

டெஸ்க்டாப்பில் சுற்றி நகர டிராக்பேட்டில் தேய்க்கவும்:

| சைகை | செயல் |
| --- | --- |
| மூன்று விரல்கள் இடது / வலது | முந்தைய / அடுத்த பணியிடம், வெற்றுப் பணியிடங்கள் உட்பட |
| மூன்று விரல்கள் மேலே | AI கன்சோலை நிலைமாற்றவும் |
| மூன்று விரல்கள் கீழே | Omarchy மெனுவைத் திறக்கவும் |
| நான்கு விரல்கள் இடது / வலது | செயலில் உள்ள சாளரத்தை முந்தைய / அடுத்த பணியிடத்திற்கு நகர்த்தவும் |
| நான்கு விரல்கள் கீழே | முழுத்திரையை நிலைமாற்றவும் |

ஒன்றை மாற்ற, உங்கள் சொந்த [டிராக்பேட் சைகையை](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/) சேர்ப்பதற்கு முன் அதை `~/.config/hypr/input.lua`-இல் நீக்கவும், ஏனெனில் Hyprland ஒரே விரல்களிலும் திசையிலும் இரண்டு சைகைகளை ஏற்காது:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Omarchy-இன் அனைத்து சைகைகளையும் அணைக்க, Omarchy-இன் இயல்புநிலைகள் ஏற்றப்படுவதற்கு முன், `~/.config/hypr/hyprland.lua`-இன் மேற்பகுதிக்கு அருகில் `omarchy_default_gestures = false` என அமைக்கவும்.

haptic டச்பேட் கொண்ட Dell XPS மடிக்கணினிகளில், _Trigger > Hardware > Touchpad Haptics_ என்பதன் கீழ் கிளிக் வலிமையை low, mid, அல்லது high எனவும் அமைக்கலாம்.

### சீனம், ஜப்பானியம் மற்றும் பிற மொழிகளில் தட்டச்சு செய்தல்

நிறுவி உங்கள் விசைப்பலகையைப் பற்றிக் கேட்கும்போது ஜப்பானியம், கொரியம், சீனம் (Simplified, Pinyin), Taiwan (Zhuyin), அல்லது Hong Kong (Cangjie) ஆகியவற்றைத் தேர்ந்தெடுக்கவும். ஆஃப்லைன் முதல்-துவக்க அமைப்பின் போதும் உட்பட, Omarchy விசைப்பலகையையும் பொருந்தும் உள்ளீட்டு இயந்திரத்தையும் தானாகவே உள்ளமைக்கிறது. ஜப்பானியம் Mozc-ஐப் பயன்படுத்துகிறது, கொரியம் நிலையான இரண்டு-தொகுப்பு Hangul-ஐப் பயன்படுத்துகிறது, Simplified Chinese Pinyin-ஐப் பயன்படுத்துகிறது, Taiwan Chewing-இன் நிலையான Zhuyin அமைப்பைப் பயன்படுத்துகிறது, Hong Kong Hong Kong எழுத்து வடிவங்களுடன் Cangjie-ஐப் பயன்படுத்துகிறது. Japanese (US keyboard) US விசைப்பலகை அமைப்புடன் Mozc-ஐ வழங்குகிறது. நீங்கள் Dvorak, Colemak, அல்லது AZERTY கொண்டு லத்தீன் எழுத்துக்களைத் தட்டச்சு செய்யும்போதும் Hangul, Zhuyin, மற்றும் Cangjie விசைகள் அவற்றின் நிலையான நிலைகளிலேயே இருக்கும். இதற்கு முன் நீங்கள் Hangul அல்லது Chewing-ஐச் சேர்த்திருந்தால், அதன் விசைகளை அங்கே நகர்த்த _Setup > Keyboard > Input Methods_ என்பதன் கீழ் அதைத் தேர்வுநீக்கிவிட்டு மீண்டும் தேர்ந்தெடுக்கவும்; நீங்கள் ஏற்கனவே தட்டச்சு செய்யும் இயந்திரத்தை Omarchy தனியாக விட்டுவிடும்.

தட்டச்சு லத்தீன் பயன்முறையில் தொடங்குகிறது. உள்ளமைக்கப்பட்ட உள்ளீட்டு முறைகள் வழியாகச் சுழல `Super + I`-ஐ அழுத்தவும், பின்னோக்கிச் சுழல `Super + Shift + I`-ஐ அழுத்தவும். Sogou, Microsoft Pinyin, மற்றும் macOS செயல்படும் விதத்திலேயே, Pinyin போன்ற ஒரு உள்ளீட்டு முறையிலிருந்து லத்தீன் எழுத்துக்களுக்கு வெளியேற `Shift`-ஐத் தனியாகத் தட்டவும், திரும்பச் செல்ல மீண்டும் தட்டவும்; `Shift` மற்றும் ஒரு எழுத்து இன்னும் ஒரு பெரிய எழுத்தைத் தட்டச்சு செய்கிறது. ஜப்பானிய விசைப்பலகைகளில், 全角/半角 உள்ளீட்டை நிலைமாற்றுகிறது, 変換 அதை இயக்குகிறது, மற்றும் 無変換 அதை அணைக்கிறது. கொரியத்தில், 한/영 Hangul-ஐ மாற்றுகிறது மற்றும் 한자 Hanja-வாக மாற்றுகிறது, உங்கள் விசைப்பலகையில் பிரத்யேக விசைகள் இருந்தாலும் அல்லது பல மடிக்கணினிகள் செய்வது போல அவற்றுக்கு Right Alt மற்றும் Right Ctrl-ஐ அனுப்பினாலும், எனவே Right Alt மற்றும் Right Ctrl அங்கு வெறும் மாற்றிகள் அல்ல; அதற்குப் பதிலாக குரல்வழி உள்ளீடு Alt + Space கொண்டு நிலைமாற்றுகிறது. `Ctrl + Space` Tmux மற்றும் Herdr-க்குக் கிடைக்கிறது; `Shift + CapsLock` compose விசையாகவே இருக்கிறது.

உங்களிடம் பல விசைப்பலகை அமைப்புகள் அல்லது உள்ளீட்டு முறைகள் இருக்கும்போது விசைப்பலகை காட்டி பட்டியின் வலதுபுறத்தில் தோன்றும். உள்ளீட்டு மொழிகளை மாற்ற அதைக் கிளிக் செய்யவும்; ஜப்பானியம் hiragana-வுக்கு あ எனக் காட்டுகிறது. ஜப்பானிய எழுத்துத் தேர்வுகளுக்கு, ஜப்பானியத்திற்கு மாறி, `nihongo` போன்ற ஒரு சொல்லைத் தட்டச்சு செய்து, பின்னர் Space-ஐ இருமுறை அழுத்தவும். உங்கள் தேர்வை ஏற்க Enter-ஐ அழுத்தவும். உங்களிடம் பல விசைப்பலகை அமைப்புகளும் இருந்தால், அவற்றின் வழியாகச் சுழல காட்டியை வலது-கிளிக் செய்யவும்.

நிறுவலின் போது வழங்கப்பட்ட அதே தேர்வுகளிலிருந்து English மற்றும் French போன்ற அமைப்புகளைத் தேர்ந்தெடுக்க _Setup > Keyboard > Keyboard Inputs_-ஐப் பயன்படுத்தவும். எந்த composition இயந்திரங்கள் செயலில் உள்ளன என்பதைத் தேர்ந்தெடுக்க _Setup > Keyboard > Input Methods_-ஐப் பயன்படுத்தவும். இரண்டு தேர்விகளும் Omarchy மெனுவிற்குள் உங்கள் தற்போதைய தேர்வுகள் தேர்ந்தெடுக்கப்பட்ட நிலையில் திறக்கும். ஒரு தேர்வை நிலைமாற்ற கிளிக் செய்யவும் அல்லது Enter-ஐ அழுத்தவும்; ஒவ்வொரு மாற்றமும் உடனடியாக நடைமுறைக்கு வரும். ஒரு உள்ளீட்டு முறையைத் தேர்வுநீக்குவது அதை நிறுவல்நீக்காமல் சுழற்சியிலிருந்து நீக்குகிறது; விசைப்பலகை தொடர்ந்து கிடைக்கும்.

அதே தேர்விகளைத் திறக்க `omarchy setup keyboard` அல்லது `omarchy setup input`-ஐ இயக்கவும். கட்டளை வரியிலிருந்து ஒரு மொழியைச் சேர்க்க, `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing`, அல்லது `cangjie5`-ஐப் பயன்படுத்தவும். Quick, Boshiamy, மற்றும் Array ஆகியவை Cangjie உடன் அதே தொகுப்பில் வருகின்றன மற்றும் Input Methods தேர்வியில் தோன்றும். உங்கள் தனிப்பயன் மாற்று விசைகள் பாதுகாக்கப்படும். மாற்று இயந்திர அமைப்புகள் அல்லது விசைகளுக்கு, `omarchy pkg add fcitx5-configtool` கொண்டு `fcitx5-configtool`-ஐ நிறுவி டெர்மினலிலிருந்து அதைத் தொடங்கவும். ஒரு உள்ளீட்டு மொழியைத் தேர்ந்தெடுப்பது டெஸ்க்டாப் மொழியை மாற்றாது. _Setup > Language_ என்பதன் கீழ் ஜப்பானியம், கொரியம், அல்லது சீனத்தைத் தேர்ந்தெடுப்பது உங்களிடம் இன்னும் எதுவும் இல்லாதபோது அதன் உள்ளீட்டு முறையைச் சேர்க்கிறது.

உள்ளீட்டு முறைகள் அல்லது விசைப்பலகை அமைப்புகள் வழியாகச் சுழல `Super + I`-ஐயும், எதிர்த் திசையில் திரும்பச் செல்ல `Super + Shift + I`-ஐயும் பயன்படுத்தவும், எனவே மூன்று உள்ளமைக்கப்பட்டிருந்தால் இரண்டு அண்டை நிலைகளுக்கு இடையே நகரலாம். ஒன்றுக்கு மேற்பட்ட உள்ளீட்டு முறை அல்லது அமைப்பு உள்ளமைக்கப்பட்டிருக்கும்போது மட்டுமே உள்ளீட்டுக் காட்டி பட்டியின் வலதுபுறத்தில் தோன்றும். இந்த டெஸ்க்டாப் பிணைப்பு உங்கள் தற்போதைய Fcitx மாற்று விசைகளுடன் சேர்ந்து செயல்படுகிறது; அதை `~/.config/hypr/bindings.lua`-இல் மேலெழுதலாம். உள்ளீட்டு இயந்திரங்களும் compose வரிசைகளும் ஒவ்வொரு அமர்விலும் ஏற்கனவே இயங்கும் [Fcitx5](https://fcitx-im.org/) சேவையைப் பயன்படுத்துகின்றன.

### ALT-ஐ SUPER ஆகப் பயன்படுத்தவும்

சில விசைப்பலகைகளில், முதன்மை meta விசையை (Windows/cmd விசை) SUPER ஆகப் பயன்படுத்துவது வசதியாக இல்லை. இந்த மாற்றத்தைக் கொண்டு அதற்குப் பதிலாக ALT-ஐப் பயன்படுத்த இதை மாற்றலாம்:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
