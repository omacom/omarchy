# விசைப்பலகை, சுட்டி, Trackpad

Hyprland உங்கள் அனைத்து உள்ளீடுகளையும் மிக விரிவாகக் கட்டமைக்க உதவுகிறது. விசைப்பலகை மீண்டும் வருவதை மிதமிஞ்சிய வேகமாக மாற்றலாம் அல்லது trackpad இயற்கையான உருட்டலைப் பயன்படுத்தச் செய்யலாம். அனைத்தையும் `~/.config/hypr/input.lua` இல் மாற்றுகிறீர்கள், அதை Omarchy மெனுவில் (`Super + Space`) _அமைப்பு > உள்ளீடு_ வழியாகவும் அடையலாம். அங்கு நீங்கள் அமைக்கும் எதுவும் Omarchy இன் இயல்புநிலைகளை மாற்றுகிறது.

இங்கே ஒரு எடுத்துக்காட்டு:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

உள்ளீடுகளுக்கான Hyprland wiki இல் [அனைத்து உள்ளீட்டு விருப்பங்களையும் காணலாம்](https://wiki.hypr.land/Configuring/Basics/Variables/#input).

CapsLock சாதாரண Caps Lock ஆக வேலை செய்கிறது, மேலும் `Shift + CapsLock` என்பது [விரைவு emoji கள்](07-hotkeys.md#quick-emojis) மற்றும் [பிற நிறைவுகளுக்கான](07-hotkeys.md#quick-completions) compose விசை. compose விசை வேறு எங்காவது இருக்க விரும்பினால், `kb_options` இல் `omarchy:shift_caps_compose` ஐ மாற்றவும். எடுத்துக்காட்டாக, இது compose விசையை வலது Alt க்கு நகர்த்துகிறது:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Trackpad சைகைகள்

மூன்று விரல்களால் swipe செய்து பணியிடங்களை மாற்றுவது போன்ற [touchpad சைகைகளையும்](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/) இயக்கலாம்:

```lua
hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })
```

haptic touchpad உடன் கூடிய Dell XPS மடிக்கணினிகளில், _தூண்டு > வன்பொருள் > தொடுதள அதிர்வு_ க்குக் கீழ் கிளிக் வலிமையைக் குறைவு, நடுத்தரம் அல்லது அதிகம் என்று அமைக்கலாம்.

### சீன, ஜப்பானிய மற்றும் பிற மொழிகளில் தட்டச்சு செய்தல்

நிறுவி உங்கள் விசைப்பலகையைக் கேட்கும்போது Japanese, Korean, Chinese (Simplified, Pinyin) அல்லது Chinese (Traditional, Zhuyin) ஐத் தேர்ந்தெடுக்கவும். offline முதல் துவக்க அமைப்பின் போது உட்பட, Omarchy விசைப்பலகை மற்றும் பொருந்தும் உள்ளீட்டு இயந்திரத்தைத் தானாகவே கட்டமைக்கிறது. Japanese Mozc ஐப் பயன்படுத்துகிறது, Korean நிலையான இரண்டு தொகுப்பு Hangul ஐப் பயன்படுத்துகிறது, Simplified Chinese Pinyin ஐப் பயன்படுத்துகிறது, Traditional Chinese Chewing இன் நிலையான Zhuyin ஏற்பாட்டைப் பயன்படுத்துகிறது. Japanese (US keyboard) US விசைப்பலகை அமைப்புடன் Mozc ஐ வழங்குகிறது.

தட்டச்சு Latin பயன்முறையில் தொடங்குகிறது. கட்டமைக்கப்பட்ட உள்ளீட்டு முறைகள் வழியாகச் சுழற்சி செய்ய `Super + I` ஐயும், திரும்பச் சுழற்சி செய்ய `Super + Shift + I` ஐயும் அழுத்தவும். Pinyin போன்ற உள்ளீட்டு முறையிலிருந்து Latin எழுத்துகளுக்கு வெளியேற `Shift` ஐத் தனியாகத் தட்டவும், Sogou, Microsoft Pinyin மற்றும் macOS வேலை செய்யும் விதத்தில் திரும்பச் செல்ல மீண்டும் தட்டவும்; `Shift` மற்றும் ஒரு எழுத்து இன்னும் பெரிய எழுத்தைத் தட்டச்சு செய்கிறது. Japanese விசைப்பலகைகளில், 全角/半角 உள்ளீட்டை மாற்றுகிறது, 変換 அதை இயக்குகிறது, 無変換 அதை அணைக்கிறது. Korean விசைப்பலகை அமைப்பில், பிரத்யேக 한/영 மற்றும் 한자 விசைகள் Hangul ஐ மாற்றி Hanja வாக மாற்றுகின்றன. `Ctrl + Space` Tmux மற்றும் Herdr க்குக் கிடைக்கிறது; `Shift + CapsLock` compose விசையாகவே இருக்கிறது.

உங்களிடம் பல விசைப்பலகை அமைப்புகள் அல்லது உள்ளீட்டு முறைகள் இருக்கும்போது விசைப்பலகைக் குறிகாட்டி பட்டையின் வலதுபுறத்தில் தோன்றும். உள்ளீட்டு மொழிகளை மாற்ற அதைக் கிளிக் செய்யவும்; Japanese hiragana க்கு あ ஐக் காட்டுகிறது. Japanese எழுத்துத் தேர்வுகளுக்கு, Japanese க்கு மாறி, `nihongo` போன்ற ஒரு வார்த்தையைத் தட்டச்சு செய்து, பின்னர் Space ஐ இரண்டு முறை அழுத்தவும். உங்கள் தேர்வை ஏற்க Enter ஐ அழுத்தவும். உங்களிடம் பல விசைப்பலகை அமைப்புகளும் இருந்தால், அவற்றைச் சுழற்சி செய்ய குறிகாட்டியை வலது கிளிக் செய்யவும்.

நிறுவலின் போது வழங்கப்படும் அதே தேர்வுகளிலிருந்து English மற்றும் French போன்ற அமைப்புகளைத் தேர்ந்தெடுக்க _அமைப்பு > தட்டச்சு > விசைப்பலகை அமைப்புகள்_ ஐப் பயன்படுத்தவும். எந்த composition இயந்திரங்கள் செயலில் உள்ளன என்பதைத் தேர்ந்தெடுக்க _அமைப்பு > தட்டச்சு > உள்ளீட்டு முறைகள்_ ஐப் பயன்படுத்தவும். இரண்டு picker களும் உங்கள் தற்போதைய தேர்வுகள் சரிபார்க்கப்பட்டு Omarchy மெனுவிற்குள் திறக்கின்றன. தேர்வை மாற்ற கிளிக் செய்யவும் அல்லது Enter ஐ அழுத்தவும்; ஒவ்வொரு மாற்றமும் உடனடியாகப் பொருந்தும். உள்ளீட்டு முறையைத் தேர்வுநீக்குவது அதை நிறுவல் நீக்காமல் சுழற்சியிலிருந்து அகற்றுகிறது; விசைப்பலகை கிடைக்கிறது.

அதே picker களைத் திறக்க `omarchy setup keyboard` அல்லது `omarchy setup input` ஐ இயக்கவும். கட்டளை வரியிலிருந்து ஒரு மொழியைச் சேர்க்க, `omarchy setup input mozc`, `hangul`, `pinyin` அல்லது `chewing` ஐப் பயன்படுத்தவும். உங்கள் தனிப்பயன் மாற்று விசைகள் பாதுகாக்கப்படுகின்றன. மாற்று இயந்திர அமைப்புகள் அல்லது விசைகளுக்கு, `omarchy pkg add fcitx5-configtool` உடன் `fcitx5-configtool` ஐ நிறுவி முனையத்தில் இருந்து அதைத் தொடங்கவும். உள்ளீட்டு மொழியைத் தேர்ந்தெடுப்பது டெஸ்க்டாப் மொழியை மாற்றாது.

உள்ளீட்டு முறைகள் அல்லது விசைப்பலகை அமைப்புகள் வழியாகச் சுழற்சி செய்ய `Super + I` ஐயும், வேறு வழியில் திரும்பச் செல்ல `Super + Shift + I` ஐயும் பயன்படுத்தவும், எனவே மூன்று கட்டமைக்கப்பட்டவற்றுடன் இரண்டு அண்டை நாடுகளுக்கு இடையே நகரலாம். ஒன்றுக்கு மேற்பட்ட உள்ளீட்டு முறை அல்லது அமைப்பு கட்டமைக்கப்படும்போது மட்டுமே உள்ளீட்டுக் குறிகாட்டி பட்டையின் வலதுபுறத்தில் தோன்றும். இந்த டெஸ்க்டாப் பிணைப்பு உங்கள் தற்போதைய Fcitx மாற்று விசைகளுடன் சேர்ந்து வேலை செய்கிறது; அதை `~/.config/hypr/bindings.lua` இல் மேலெழுதலாம். உள்ளீட்டு இயந்திரங்கள் மற்றும் compose வரிசைகள் ஒவ்வொரு அமர்விலும் ஏற்கனவே இயங்கும் [Fcitx5](https://fcitx-im.org/) சேவையைப் பயன்படுத்துகின்றன.

### ALT ஐ SUPER ஆகப் பயன்படுத்தவும்

சில விசைப்பலகைகளில், முதன்மை meta விசையை (Windows/cmd விசை) SUPER ஆகப் பயன்படுத்துவது வசதியாக இல்லை. இந்த மாற்றத்தைப் பயன்படுத்தி அதற்குப் பதிலாக இதை ALT ஆக மாற்றலாம்:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
