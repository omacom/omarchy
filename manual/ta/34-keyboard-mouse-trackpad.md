# விசைப்பலகை, சுட்டி, Trackpad

Hyprland உங்கள் அனைத்து உள்ளீடுகளையும் மிக விரிவாக உள்ளமைக்க உங்களை அனுமதிக்கிறது. விசைப்பலகை மீண்டும் மீண்டும் அழுத்தப்படுவதை ஒலியை விட வேகமாக மாற்றலாம் அல்லது Trackpad இயல்பான உருட்டலைப் பயன்படுத்தச் செய்யலாம். இவை அனைத்தையும் `~/.config/hypr/input.lua` இல் மாற்றுகிறீர்கள்; இதை Omarchy பட்டியலில் (`Super + Space`) _அமைப்பு > உள்ளீடு_ வழியாகவும் அடையலாம். அங்கு நீங்கள் அமைப்பது எதுவும் Omarchy இன் இயல்புநிலைகளுக்கு மாற்றாக அமையும்.

இதோ ஒரு எடுத்துக்காட்டு:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

உள்ளீடுகளுக்கான Hyprland wiki இல் [அனைத்து உள்ளீட்டு விருப்பங்களையும் காணலாம்](https://wiki.hypr.land/Configuring/Basics/Variables/#input).

CapsLock ஒரு சாதாரண Caps Lock ஆகவே செயல்படுகிறது, மேலும் `Shift + CapsLock` என்பது [விரைவான இமோஜிகளுக்கான](07-hotkeys.md#quick-emojis) மற்றும் [பிற நிறைவுகளுக்கான](07-hotkeys.md#quick-completions) compose விசையாகும். compose விசை வேறு இடத்தில் இருக்க வேண்டும் என்று நீங்கள் விரும்பினால், `kb_options` இல் உள்ள `omarchy:shift_caps_compose` ஐ மாற்றவும். எடுத்துக்காட்டாக, இது compose விசையை Right Alt க்கு நகர்த்துகிறது:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### செயல்பாட்டு விசைகள்

மடிக்கணினி விசைப்பலகையின் மேல் வரிசை இயல்பாகவே ஊடக விசைகளை (ஒலியளவு, பிரகாசம் போன்றவை) அனுப்புகிறது, மேலும் `Fn` ஐப் பிடித்திருப்பது F1-F12 ஐத் தருகிறது; `Fn + Esc` அதை எதிர்மாறாகப் பூட்டுகிறது, நீங்கள் அதை மீண்டும் அழுத்தும் வரை. பெரும்பாலான விசைப்பலகைகள் அந்தப் பூட்டைத் தாமே நினைவில் வைத்திருக்கின்றன. ASUS மடிக்கணினிகளும் Apple பாணி விசைப்பலகைகளும் அதை Linux இடம் விட்டுவிடுகின்றன, இது ஒவ்வொரு துவக்கத்திலும் அவற்றை ஊடக விசைகளில் தொடங்குகிறது. அதற்குப் பதிலாக அவை F1-F12 இல் தொடங்க வேண்டும் எனில், `omarchy device keyboard toprow fnkeys` ஐ இயக்கவும் (திரும்பச் செல்ல `omarchy device keyboard toprow mediakeys`); சில மடிக்கணினிகளில் மறுதுவக்கத்திற்குப் பிறகே இது நடைமுறைக்கு வரும். Apple Silicon Mac கள் தங்கள் சொந்த அமைப்பையே வைத்திருக்கின்றன.

### Trackpad சைகைகள்

பணிமேடையைச் சுற்றி நகர Trackpad இல் தேய்க்கவும்:

| சைகை | செயல் |
| --- | --- |
| மூன்று விரல்கள் இடது / வலது | காலியானவை உட்பட முந்தைய / அடுத்த workspace |
| மூன்று விரல்கள் மேலே | AI console ஐ மாற்று |
| மூன்று விரல்கள் கீழே | Omarchy பட்டியலைத் திற |
| நான்கு விரல்கள் இடது / வலது | செயலில் உள்ள சாளரத்தை முந்தைய / அடுத்த workspace க்கு நகர்த்து |
| நான்கு விரல்கள் கீழே | முழுத்திரையை மாற்று |

ஒன்றை மாற்ற, உங்கள் சொந்த [touchpad சைகையைச்](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/) சேர்ப்பதற்கு முன் `~/.config/hypr/input.lua` இல் அதை நீக்கவும், ஏனெனில் Hyprland ஒரே விரல்களிலும் திசையிலும் இரண்டு சைகைகளை ஏற்காது:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Omarchy இன் அனைத்து சைகைகளையும் அணைக்க, Omarchy இன் இயல்புநிலைகள் ஏற்றப்படுவதற்கு முன், `~/.config/hypr/hyprland.lua` இன் மேற்பகுதிக்கு அருகில் `omarchy_default_gestures = false` என அமைக்கவும்.

haptic touchpad கொண்ட Dell XPS மடிக்கணினிகளில், _தூண்டுதல் > வன்பொருள் > Touchpad Haptics_ கீழ் சொடுக்கு வலிமையைக் குறைவு, நடுத்தரம் அல்லது அதிகம் எனவும் அமைக்கலாம்.

### சீனம், ஜப்பானியம் மற்றும் பிற மொழிகளில் தட்டச்சு செய்தல்

நிறுவி உங்கள் விசைப்பலகையைக் கேட்கும்போது ஜப்பானியம், கொரியம், சீனம் (எளிமைப்படுத்தப்பட்டது, Pinyin), Taiwan (Zhuyin) அல்லது Hong Kong (Cangjie) ஐத் தேர்ந்தெடுக்கவும். ஆஃப்லைன் முதல்-துவக்க அமைப்பின் போதும் உட்பட, Omarchy விசைப்பலகையையும் பொருந்தும் உள்ளீட்டு இயந்திரத்தையும் தானாகவே உள்ளமைக்கிறது. ஜப்பானியம் Mozc ஐப் பயன்படுத்துகிறது, கொரியம் நிலையான இரண்டு-தொகுப்பு Hangul ஐப் பயன்படுத்துகிறது, எளிமைப்படுத்தப்பட்ட சீனம் Pinyin ஐப் பயன்படுத்துகிறது, Taiwan Chewing இன் நிலையான Zhuyin அமைப்பைப் பயன்படுத்துகிறது, மேலும் Hong Kong Hong Kong எழுத்து வடிவங்களுடன் Cangjie ஐப் பயன்படுத்துகிறது. ஜப்பானியம் (US விசைப்பலகை) US விசைப்பலகை அமைப்புடன் Mozc ஐ வழங்குகிறது. Dvorak, Colemak அல்லது AZERTY உடன் நீங்கள் Latin எழுத்துக்களைத் தட்டச்சு செய்யும்போதும் கூட Hangul, Zhuyin மற்றும் Cangjie விசைகள் அவற்றின் நிலையான இடங்களிலேயே இருக்கும். இதற்கு முன் Hangul அல்லது Chewing ஐச் சேர்த்திருந்தால், அதன் விசைகளை அங்கு நகர்த்த _அமைப்பு > விசைப்பலகை > உள்ளீட்டு முறைகள்_ கீழ் அதைத் தேர்வுநீக்கி மீண்டும் தேர்ந்தெடுக்கவும்; நீங்கள் ஏற்கனவே தட்டச்சு செய்யும் ஒரு இயந்திரத்தை Omarchy அப்படியே விட்டுவிடுகிறது.

தட்டச்சு Latin முறையில் தொடங்குகிறது. உள்ளமைக்கப்பட்ட உள்ளீட்டு முறைகளுக்கிடையே சுழல `Super + I` ஐ அழுத்தவும், பின்னோக்கிச் சுழல `Super + Shift + I` ஐ அழுத்தவும். Pinyin போன்ற ஒரு உள்ளீட்டு முறையிலிருந்து Latin எழுத்துக்களுக்கு வெளியேற `Shift` ஐத் தனியாகத் தட்டவும், திரும்பச் செல்ல அதை மீண்டும் தட்டவும், Sogou, Microsoft Pinyin மற்றும் macOS செயல்படும் விதமே இது; `Shift` உடன் ஒரு எழுத்து இன்னும் பெரிய எழுத்தையே தட்டச்சு செய்கிறது. ஜப்பானிய விசைப்பலகைகளில், 全角/半角 உள்ளீட்டை மாற்றுகிறது, 変換 அதை இயக்குகிறது, மேலும் 無変換 அதை அணைக்கிறது. கொரியத்தில், 한/영 Hangul ஐ மாற்றுகிறது மற்றும் 한자 Hanja ஆக மாற்றுகிறது, உங்கள் விசைப்பலகையில் அதற்கென தனி விசைகள் இருந்தாலும் அல்லது பல மடிக்கணினிகள் செய்வது போல அவற்றுக்காக Right Alt மற்றும் Right Ctrl ஐ அனுப்பினாலும், எனவே Right Alt மற்றும் Right Ctrl அங்கு வெறும் மாற்று விசைகள் அல்ல; அதற்குப் பதிலாக கட்டளையிடுதல் Alt + Space உடன் மாறுகிறது. `Ctrl + Space` Tmux மற்றும் Herdr க்குக் கிடைக்கும்படியே இருக்கிறது; `Shift + CapsLock` compose விசையாகவே இருக்கிறது.

உங்களிடம் பல விசைப்பலகை அமைப்புகள் அல்லது உள்ளீட்டு முறைகள் இருக்கும்போது விசைப்பலகைக் காட்டி பட்டையின் வலதுபுறத்தில் தோன்றும். உள்ளீட்டு மொழிகளை மாற்ற அதைச் சொடுக்கவும்; ஜப்பானியம் hiragana க்கு あ ஐக் காட்டுகிறது. ஜப்பானிய எழுத்துத் தேர்வுகளுக்கு, ஜப்பானியத்திற்கு மாறி, `nihongo` போன்ற ஒரு சொல்லைத் தட்டச்சு செய்து, பின்னர் Space ஐ இரண்டு முறை அழுத்தவும். உங்கள் தேர்வை ஏற்க Enter ஐ அழுத்தவும். உங்களிடம் பல விசைப்பலகை அமைப்புகளும் இருந்தால், அவற்றுக்கிடையே சுழல காட்டியை வலது-சொடுக்கவும்.

நிறுவலின் போது வழங்கப்பட்ட அதே தேர்வுகளிலிருந்து, ஆங்கிலம் மற்றும் பிரெஞ்சு போன்ற அமைப்புகளைத் தேர்ந்தெடுக்க _அமைப்பு > விசைப்பலகை > விசைப்பலகை உள்ளீடுகள்_ ஐப் பயன்படுத்தவும். எந்தத் தொகுப்பு இயந்திரங்கள் செயலில் உள்ளன என்பதைத் தேர்ந்தெடுக்க _அமைப்பு > விசைப்பலகை > உள்ளீட்டு முறைகள்_ ஐப் பயன்படுத்தவும். இரண்டு தேர்விகளும் உங்கள் தற்போதைய தேர்வுகள் குறிக்கப்பட்ட நிலையில் Omarchy பட்டியலுக்குள்ளேயே திறக்கும். ஒரு தேர்வை மாற்ற சொடுக்கவும் அல்லது Enter ஐ அழுத்தவும்; ஒவ்வொரு மாற்றமும் உடனடியாக நடைமுறைக்கு வரும். ஒரு உள்ளீட்டு முறையைத் தேர்வுநீக்குவது அதை நிறுவல்நீக்காமல் சுழற்சியிலிருந்து நீக்குகிறது; விசைப்பலகை தொடர்ந்து கிடைக்கும்.

அதே தேர்விகளைத் திறக்க `omarchy setup keyboard` அல்லது `omarchy setup input` ஐ இயக்கவும். கட்டளை வரியிலிருந்து ஒரு மொழியைச் சேர்க்க, `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` அல்லது `cangjie5` ஐப் பயன்படுத்தவும். Quick, Boshiamy மற்றும் Array ஆகியவை Cangjie உடன் அதே தொகுப்பிலேயே வருகின்றன மற்றும் உள்ளீட்டு முறைகள் தேர்வியில் தோன்றுகின்றன. உங்கள் தனிப்பயன் மாற்று விசைகள் பாதுகாக்கப்படுகின்றன. மாற்று இயந்திர அமைப்புகள் அல்லது விசைகளுக்கு, `omarchy pkg add fcitx5-configtool` உடன் `fcitx5-configtool` ஐ நிறுவி, அதை ஒரு terminal இலிருந்து தொடங்கவும். ஒரு உள்ளீட்டு மொழியைத் தேர்ந்தெடுப்பது பணிமேடை மொழியை மாற்றாது. உங்களிடம் இன்னும் எதுவும் இல்லாதபோது _அமைப்பு > பகுதி > மொழி_ கீழ் ஜப்பானியம், கொரியம் அல்லது சீனத்தைத் தேர்ந்தெடுப்பது அதன் உள்ளீட்டு முறையைச் சேர்க்கிறது.

உள்ளீட்டு முறைகள் அல்லது விசைப்பலகை அமைப்புகளுக்கிடையே சுழல `Super + I` ஐப் பயன்படுத்தவும், மற்ற திசையில் திரும்பச் செல்ல `Super + Shift + I` ஐப் பயன்படுத்தவும், எனவே மூன்று உள்ளமைக்கப்பட்டிருந்தால் இரண்டு அண்டை நிலைகளுக்கிடையே நகரலாம். ஒன்றுக்கு மேற்பட்ட உள்ளீட்டு முறை அல்லது அமைப்பு உள்ளமைக்கப்பட்டிருக்கும்போது மட்டுமே உள்ளீட்டுக் காட்டி பட்டையின் வலதுபுறத்தில் தோன்றும். இந்தப் பணிமேடைப் பிணைப்பு உங்கள் தற்போதைய Fcitx மாற்று விசைகளுடன் சேர்ந்து செயல்படுகிறது; அதை `~/.config/hypr/bindings.lua` இல் மாற்றியமைக்கலாம். உள்ளீட்டு இயந்திரங்களும் compose தொடர்களும் ஒவ்வொரு அமர்விலும் ஏற்கனவே இயங்கும் [Fcitx5](https://fcitx-im.org/) சேவையைப் பயன்படுத்துகின்றன.

### ALT ஐ SUPER ஆகப் பயன்படுத்தவும்

சில விசைப்பலகைகளில், முதன்மை meta விசையை (Windows/cmd விசை) SUPER ஆகப் பயன்படுத்துவது வசதியாக இருக்காது. இந்த மாற்றத்தைப் பயன்படுத்தி அதற்குப் பதிலாக இதை ALT ஆக மாற்றலாம்:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
