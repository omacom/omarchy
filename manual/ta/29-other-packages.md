# பிற தொகுப்புகள்

அதிகாரப்பூர்வ களஞ்சியம் மற்றும் Arch User Repository (AUR) இடையே ஏறக்குறைய எந்த வகை மென்பொருளுக்கும் Arch இல் அற்புதமான செல்வம் உள்ளது.

இரண்டையும் பயன்படுத்துவது இதை விட எளிதாக இருக்க முடியாது. Omarchy மெனுவில் (`Super + Space`) _நிறுவு > Package_ க்குச் சென்று நீங்கள் விரும்பும் தொகுப்பைத் தட்டச்சு செய்வதன் மூலம் புதிய Arch தொகுப்பை நிறுவுகிறீர்கள். இது அனைத்து தொகுப்புகளின் பட்டியலையும் தானாகவே fuzzy முறையில் வடிகட்டும். (முனையத்தில் `omarchy pkg add [package]` ஐப் பயன்படுத்தி அதைக் கையாலும் செய்யலாம்).

AUR உடனும் அதையே செய்யலாம், வெறும் _நிறுவு > AUR_ ஐப் பயன்படுத்தவும். AUR Arch குழுவால் சரிபார்க்கப்படவில்லை என்பதை நினைவில் கொள்ளவும். இது RubyGems அல்லது npm போன்றது. எவரும் பதிவேற்றலாம்.

ஒரு தொகுப்பை அகற்ற விரும்பினால், Omarchy மெனுவில் இருந்து _நீக்கு > Package_ ஐப் பயன்படுத்தலாம். இது தொகுப்பு, கட்டமைப்புக் கோப்புகள் மற்றும் சார்புகளை அகற்றும். (`omarchy pkg drop [package]` ஐப் பயன்படுத்தி அதைக் கையாலும் செய்யலாம்).
