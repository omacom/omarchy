# புதுப்பிப்புகள்

Omarchy மெனுவில் (`Super + Space`) _புதுப்பி > Omarchy_ வழியாக Omarchy மற்றும் உங்கள் தொகுப்புகள் புதுப்பித்த நிலையில் வைக்கப்படுகின்றன.

Omarchy தானே [Omarchy Package Repository](https://github.com/omacom-io/omarchy-pkgs) இலிருந்து வழக்கமான pacman தொகுப்புகளாக நிறுவப்பட்டுள்ளது, எனவே ஒரு புதுப்பிப்பு [சமீபத்திய Omarchy வெளியீட்டை](https://github.com/omacom/omarchy/releases) நிறுவி, உங்கள் கணினியைச் சமீபத்தியதுடன் ஒத்திசைக்க நிலுவையில் உள்ள இடம்பெயர்வுகளை இயக்கி, [Omarchy Arch Mirror](https://github.com/omacom-io/omarchy-mirror) மற்றும் [AUR](https://aur.archlinux.org/) இலிருந்து அனைத்து கணினித் தொகுப்புகளையும் புதுப்பிக்கிறது (நீங்கள் ஏதேனும் AUR தொகுப்புகளை நிறுவியிருந்தால்).

புதிய வெளியீடுகள் செய்யப்படும்போது, உங்கள் கடிகாரத்திற்கு வலதுபுறத்தில் ஒரு வட்ட அம்பு ஐகான் தோன்றும். அதைக் கிளிக் செய்தால் புதுப்பிப்பு செயல்முறை தொடங்கும்.

### நான்கு சேனல்கள்

Omarchy நான்கு சேனல்களில் புதுப்பிக்கப்படுகிறது: stable, RC, edge மற்றும் dev. புதிய நிறுவல்கள் stable சேனலில் தொடங்குகின்றன, இது [அதிகாரப்பூர்வ வெளியீடுகளை](https://github.com/omacom/omarchy/releases/) கண்காணிக்கிறது, அத்துடன் சமீபத்தியதை விட ஒரு மாதம் பின்தங்கிய [stable Omarchy Arch mirror](https://github.com/omacom-io/omarchy-mirror) ஐயும் கண்காணிக்கிறது, எனவே கட்டமைப்பு மாற்றங்கள் தேவைப்படும் புதிய இணக்கமின்மைகள் மக்களுக்குச் சிக்கல்களை ஏற்படுத்துவதற்கு முன்பு அவற்றைப் பிடிக்கலாம்.

ஆனால் அந்தச் சாத்தியமான சிக்கல்களைக் கண்டறிய உதவ விரும்பினால், edge சேனலில் இயக்கலாம். அது உங்கள் Omarchy தொகுப்புகளைச் சமீபத்திய மேம்பாட்டுக் கட்டமைப்புகளைக் கண்காணிக்கும், மேலும் சமீபத்திய Arch தொகுப்புகள் கிடைத்தவுடன் அவற்றுக்குப் புதுப்பிக்க உதவும். நீங்கள் Linux இல் அனுபவம் வாய்ந்தவராக இருந்தால், சிக்கல்கள் உள்ள கணினியை எப்படி மீட்பது என்று தெரிந்தால் மட்டுமே இதைச் செய்ய வேண்டும்.

எந்தப் புதிய பெரிய வெளியீட்டிற்கும் முன், RC சேனலைப் பயன்படுத்தி இறுதிச் சரிபார்ப்பைச் செய்வோம். இறுதி மெருகூட்டலுக்கு உதவ ஆர்வமாக இருந்தால், Discord இல் #omarchy-release-candidates இல் வந்து பழகவும்.

இறுதியாக, dev சேனல் உள்ளது, இது Omarchy ஐ `~/omarchy` இல் உள்ள மூலக் குறியீட்டின் git checkout உடன் நேரடியாக இணைக்கிறது, edge தொகுப்புகளுடன் இணைந்து. நீங்கள் அனுபவம் வாய்ந்த Linux பயனராக இருந்தால், நேரடியாக Omarchy இல் வேலை செய்தால், உடைப்பைப் பொறுத்துக் கொள்ளத் தயாராக இருந்தால் மட்டுமே இந்தச் சேனலைப் பயன்படுத்த வேண்டும்.

Omarchy மெனுவில் இருந்து _புதுப்பி > Channel_ ஐப் பயன்படுத்தி (அல்லது முனையத்தில் `omarchy-channel-set`) சேனல்களுக்கு இடையே மாறலாம்.

### Firmware புதுப்பிப்புகள்

உங்கள் தொகுப்புகள் மட்டுமே பழையதாகும் விஷயம் அல்ல. பல மடிக்கணினிகள் மற்றும் துணைக்கருவிகள் Linux Vendor Firmware Service வழியாக BIOS, SSD மற்றும் dock firmware ஐ அனுப்புகின்றன, மேலும் Omarchy மெனுவில் _புதுப்பி > Firmware_ உங்கள் வன்பொருள் காத்திருக்கும் எதையும் பெற்று நிறுவும். முதல் முறை அதை இயக்கும்போது இது `fwupd` ஐ நிறுவுகிறது. நிறைய firmware மறுதொடக்கத்தின் போது மட்டுமே எழுத முடியும், எனவே ஒன்றைக் கேட்கப்படும்போது ஆச்சரியப்பட வேண்டாம்.

### நேரடி pacman/yay புதுப்பிப்புகள் பற்றிய எச்சரிக்கை

உங்களுக்கு ஏற்கனவே Arch பழக்கமாக இருந்தால், நீங்களே `pacman -Syu` அல்லது `yay -Syu` என்று இயக்க ஆசைப்படலாம், ஆனால் அப்படிச் செய்தால், Omarchy புதிய தொகுப்புகளுடன் சேர்ந்து இயக்கும் snapshot, இடம்பெயர்வுகள் மற்றும் கட்டமைப்புப் புதுப்பிப்புகளைத் தவறவிடுவீர்கள். அதனால்தான் Omarchy உண்மையில் நேரடி கணினி மேம்படுத்தலை நிறுத்தி, அதற்குப் பதிலாக `omarchy update` ஐச் சுட்டிக்காட்டும். (நீங்கள் உண்மையில் என்ன செய்கிறீர்கள் என்று உங்களுக்குத் தெரிந்தால், ஒற்றைப் பரிமாற்றத்திற்கு அதை எப்படித் தவிர்ப்பது என்று காவலர் உங்களுக்குச் சொல்வார்.)

### மோசமான புதுப்பிப்புகளைத் திரும்பப் பெறுதல்

புதுப்பிப்பைச் செய்த பிறகு எப்போதாவது சிக்கல் ஏற்பட்டால், புதுப்பிப்புக்கு முன் எடுக்கப்பட்ட snapshot க்கு உங்கள் கணினியைத் திரும்பப் பெறலாம். வெறுமனே மறுதொடக்கம் செய்து, நீங்கள் புதுப்பிப்பைத் தொடங்குவதற்கு முன்பிருந்த boot loading மெனுவில் snapshot ஐத் தேர்ந்தெடுக்கவும்.

![bootloader](images/bootloader.webp)

எப்படியோ உங்கள் கட்டமைப்புக் கோப்புகள் சிதைந்திருந்தால், முனையத்தில் `omarchy reinstall` ஐப் பயன்படுத்தி Omarchy மறு நிறுவலையும் செய்யலாம். இது அனைத்து இயல்புநிலை Omarchy தொகுப்புகளையும் மீண்டும் நிறுவி, உங்களை stable இல் வைத்து, மிகவும் புதிய தொகுப்புகளைத் தரமிறக்கி, அனைத்து கட்டமைப்புக் கோப்புகளையும் மீட்டமைக்கும். இதைச் செய்வதன் மூலம் Omarchy இயல்புநிலைகளில் உங்கள் அனைத்து பயனர் கட்டமைப்பு மாற்றங்களும் மேலெழுதப்படும் என்பதை நினைவில் கொள்ளவும்!
