# புதுப்பிப்புகள்

Omarchy மெனுவில் உள்ள _புதுப்பிப்பு > Omarchy_ வழியாக Omarchy-யும் உங்கள் பேக்கேஜ்களும் புதுப்பித்த நிலையில் வைக்கப்படும் (`Super + Space`).

Omarchy தானே [Omarchy Package Repository](https://github.com/omacom-io/omarchy-pkgs)-இலிருந்து சாதாரண pacman பேக்கேஜ்களாக நிறுவப்படுவதால், ஒரு புதுப்பிப்பு [சமீபத்திய Omarchy வெளியீட்டை](https://github.com/omacom/omarchy/releases) நிறுவும், உங்கள் கணினியை சமீபத்திய நிலையுடன் ஒத்திசையில் வைக்க நிலுவையில் உள்ள எந்த இடம்பெயர்வுகளையும் இயக்கும், மேலும் [Omarchy Arch Mirror](https://github.com/omacom-io/omarchy-mirror) மற்றும் [AUR](https://aur.archlinux.org/)-இலிருந்து அனைத்து கணினி பேக்கேஜ்களையும் புதுப்பிக்கும் (நீங்கள் ஏதேனும் AUR பேக்கேஜ்களை நிறுவியிருந்தால்).

புதிய வெளியீடுகள் வந்ததும், உங்கள் கடிகாரத்திற்கு வலதுபுறம் ஒரு வட்ட அம்புக்குறி ஐகான் தோன்றும். அதைக் கிளிக் செய்யுங்கள், புதுப்பிப்புச் செயல்முறை தொடங்கும்.

### நான்கு சேனல்கள்

Omarchy stable, RC, edge மற்றும் dev எனும் நான்கு சேனல்கள் வழியாகப் புதுப்பிக்கப்படுகிறது. புதிய நிறுவல்கள் stable சேனலில் தொடங்கும்; அது [அதிகாரப்பூர்வ வெளியீடுகளைத்](https://github.com/omacom/omarchy/releases/) தொடர்வதுடன், ஒரு மாதம் பின்தங்கி இயங்கும் [stable Omarchy Arch mirror](https://github.com/omacom-io/omarchy-mirror)-ஐயும் தொடரும், எனவே கட்டமைப்பு மாற்றங்கள் தேவைப்படும் புதிய பொருந்தாமைகள் ஏதேனும் இருந்தால், அவை மக்களுக்குப் பிரச்சினைகளை ஏற்படுத்தும் முன்பே எங்களால் அவற்றைக் கண்டறிய முடியும்.

ஆனால் அந்தச் சாத்தியமான பிரச்சினைகளைக் கண்டறிய உதவ விரும்பினால், நீங்கள் edge சேனலில் இயங்கலாம். அது உங்கள் Omarchy பேக்கேஜ்களை சமீபத்திய மேம்பாட்டு உருவாக்கங்களைத் தொடர வைக்கும், மேலும் சமீபத்திய Arch பேக்கேஜ்கள் கிடைத்தவுடன் அவற்றுக்குப் புதுப்பிக்க உங்களை அனுமதிக்கும். நீங்கள் Linux-இல் அனுபவம் உள்ளவராகவும், பிரச்சினைகள் உள்ள ஒரு கணினியை எப்படி மீட்பது என்று தெரிந்தவராகவும் இருந்தால் மட்டுமே இதைச் செய்ய வேண்டும்.

எந்தவொரு புதிய பெரிய வெளியீட்டிற்கும் முன்பு, RC சேனலைப் பயன்படுத்தி இறுதிச் சரிபார்ப்பைச் செய்வோம். இறுதி மெருகூட்டலில் உதவ ஆர்வமாக இருந்தால், Discord-இல் #omarchy-release-candidates-இல் வந்து நேரம் செலவிடுங்கள்.

இறுதியாக, dev சேனல் உள்ளது; அது edge பேக்கேஜ்களுடன் சேர்த்து, `~/omarchy`-இல் உள்ள மூலக் குறியீட்டின் git செக்அவுட்டுடன் Omarchy-ஐ நேரடியாக இணைக்கிறது. நீங்கள் அனுபவம் வாய்ந்த Linux பயனராகவும், Omarchy-இல் நேரடியாகப் பணிபுரிபவராகவும், உடைவுகளைச் சகித்துக்கொள்ளத் தயாராகவும் இருந்தால் மட்டுமே இந்தச் சேனலைப் பயன்படுத்த வேண்டும்.

Omarchy மெனுவில் உள்ள _புதுப்பிப்பு > சேனல்_ வழியாக (அல்லது டெர்மினலில் `omarchy channel set <stable|rc|edge|dev>` என்பதன் வழியாக, நீங்கள் எங்கு இருக்கிறீர்கள் என்பதைப் பார்க்க `omarchy channel current` உடன்) நீங்கள் சேனல்களுக்கு இடையே மாறலாம்.

### கர்னல்களை மாற்றுதல்

Omarchy தனது சொந்த `linux-omarchy` கர்னலைப் பூட் செய்கிறது, ஆனால் அதற்கு அருகில் மற்றவற்றையும் நிறுவி வைத்திருக்கலாம், உதாரணமாக வழக்கமான Arch `linux` கர்னல் அல்லது நீங்கள் சோதித்துக்கொண்டிருக்கும் ஒரு சோதனை உருவாக்கம். ஒன்றுக்கு மேற்பட்டவை இருக்கும்போது, Omarchy மெனுவில் உள்ள _புதுப்பிப்பு > கர்னல்_ அவற்றைப் பட்டியலிடும், இயல்பாகப் பூட் ஆகும் ஒன்றுக்கு அருகில் ஒரு சரிகுறி இருக்கும். வேறொன்றைத் தேர்ந்தெடுத்து, உங்கள் கடவுச்சொல்லை ஒருமுறை உள்ளிடுங்கள், அடுத்த மறுதொடக்கத்திற்குப் பிறகு அது பூட் ஆகும். மற்ற கர்னல்கள் பூட் மெனுவிலேயே இருக்கும், எனவே புதிய இயல்புநிலை உங்களுக்குப் பிரச்சினை தந்தால் நீங்களாகவே ஒன்றைத் தேர்ந்தெடுக்கலாம். டெர்மினலில், தற்போதைய இயல்புநிலையைப் பார்க்க `omarchy kernel`, நிறுவப்பட்டுள்ளவற்றைப் பார்க்க `omarchy kernel list`, மாற்ற `omarchy kernel set <kernel>` ஆகும்.

### ஃபர்ம்வேர் புதுப்பிப்புகள்

உங்கள் பேக்கேஜ்கள் மட்டுமே காலாவதியாகும் விஷயம் அல்ல. பல மடிக்கணினிகளும் புறச்சாதனங்களும் Linux Vendor Firmware Service வழியாக BIOS, SSD மற்றும் டாக் ஃபர்ம்வேரை வழங்குகின்றன, மேலும் Omarchy மெனுவில் உள்ள _புதுப்பிப்பு > ஃபர்ம்வேர்_ உங்கள் வன்பொருளுக்குக் காத்திருக்கும் எதையும் பெற்று நிறுவும். நீங்கள் அதை முதல்முறை இயக்கும்போது அது `fwupd`-ஐ நிறுவும். ஏராளமான ஃபர்ம்வேரை மறுதொடக்கத்தின் போது மட்டுமே எழுத முடியும், எனவே அப்படி ஒன்றைக் கேட்கப்பட்டால் ஆச்சரியப்படாதீர்கள்.

BIOS-இலேயே ஒரு அமைப்பை மாற்ற வேண்டியிருக்கும்போது, கணினி மெனுவில் (`Super + Escape`) `Alt`-ஐ அழுத்திப் பிடியுங்கள், _மறுதொடக்கம்_ என்பது _BIOS-க்கு மறுதொடக்கம்_ என மாறும்; அது பூட்டின் போது சரியான விசையைப் பிடிக்க வேண்டிய அவசியமின்றி நேரடியாக ஃபர்ம்வேர் அமைப்பிற்குள் மறுதொடக்கம் செய்யும். டெர்மினலில், அது `omarchy system firmware` ஆகும்.

### நேரடி pacman/yay புதுப்பிப்புகள் பற்றிய எச்சரிக்கை

நீங்கள் ஏற்கனவே Arch-ஐ நன்கு அறிந்திருந்தால், நீங்களே `pacman -Syu` அல்லது `yay -Syu`-ஐ இயக்கத் தூண்டப்படலாம், ஆனால் அப்படிச் செய்தால், புதிய பேக்கேஜ்களுடன் சேர்த்து Omarchy இயக்கும் ஸ்னாப்ஷாட், இடம்பெயர்வுகள் மற்றும் கட்டமைப்புப் புதுப்பிப்புகளை நீங்கள் தவறவிடுவீர்கள். அதனால்தான் Omarchy உண்மையில் ஒரு நேரடி கணினி மேம்படுத்தலை நிறுத்தி, அதற்குப் பதிலாக `omarchy update`-ஐ நோக்கி உங்களைச் சுட்டிக்காட்டும். (நீங்கள் செய்வது என்ன என்று உண்மையிலேயே உங்களுக்குத் தெரிந்தால், ஒற்றைப் பரிவர்த்தனைக்கு அதை எப்படித் தவிர்ப்பது என்று அந்தப் பாதுகாப்பு உங்களுக்குச் சொல்லும்.)

### மோசமான புதுப்பிப்புகளைப் பின்னுக்குத் திருப்புதல்

புதுப்பிப்பு செய்த பிறகு உங்களுக்கு எப்போதாவது பிரச்சினை ஏற்பட்டால், புதுப்பிப்புக்கு முன்பு எடுக்கப்பட்ட ஸ்னாப்ஷாட்டிற்கு உங்கள் கணினியைத் திரும்பக் கொண்டு செல்லலாம். மறுதொடக்கம் செய்து, புதுப்பிப்பைத் தொடங்குவதற்கு முன்பு இருந்த ஸ்னாப்ஷாட்டை பூட் ஏற்றல் மெனுவில் தேர்ந்தெடுங்கள்.

![bootloader](images/bootloader.webp)

எப்படியாவது உங்கள் கட்டமைப்புக் கோப்புகள் சேதமடைந்திருந்தால், டெர்மினலில் `omarchy reinstall`-ஐப் பயன்படுத்தி Omarchy மறுநிறுவலையும் செய்யலாம். இது அனைத்து இயல்புநிலை Omarchy பேக்கேஜ்களையும் மீண்டும் நிறுவும், உங்களை stable-இல் வைக்கும் (Apple Silicon-இல் edge) மற்றும் மிகவும் புதிய பேக்கேஜ்கள் எதையும் தரமிறக்கும், மேலும் அனைத்து கட்டமைப்புக் கோப்புகளையும் மீட்டமைக்கும். இதைச் செய்வதால் Omarchy இயல்புநிலைகளில் நீங்கள் செய்த அனைத்து பயனர் கட்டமைப்பு மாற்றங்களும் மேலெழுதப்படும் என்பதைக் கவனியுங்கள்!
