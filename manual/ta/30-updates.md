# புதுப்பிப்புகள்

Omarchy மற்றும் உங்கள் தொகுப்புகள் Omarchy மெனுவில் (`Super + Space`) உள்ள _புதுப்பிப்பு > Omarchy_ வழியாகப் புதுப்பித்த நிலையில் வைக்கப்படுகின்றன.

Omarchy தானே [Omarchy தொகுப்பு களஞ்சியத்திலிருந்து](https://github.com/omacom-io/omarchy-pkgs) வழக்கமான pacman தொகுப்புகளாக நிறுவப்படுகிறது, எனவே ஒரு புதுப்பிப்பு [சமீபத்திய Omarchy வெளியீட்டை](https://github.com/omacom/omarchy/releases) நிறுவும், உங்கள் கணினியைச் சமீபத்திய நிலையுடன் ஒத்திசைவில் வைக்க நிலுவையில் உள்ள எந்த இடம்பெயர்வுகளையும் இயக்கும், மேலும் [Omarchy Arch Mirror](https://github.com/omacom-io/omarchy-mirror) மற்றும் [AUR](https://aur.archlinux.org/) இலிருந்து அனைத்து கணினித் தொகுப்புகளையும் புதுப்பிக்கும் (நீங்கள் ஏதேனும் AUR தொகுப்புகளை நிறுவியிருந்தால்).

புதிய வெளியீடுகள் வரும்போது, உங்கள் கடிகாரத்தின் வலதுபுறத்தில் ஒரு வட்ட அம்புக்குறி சின்னம் தோன்றும். அதைக் கிளிக் செய்தால் புதுப்பிப்புச் செயல்முறை தொடங்கும்.

### நான்கு சேனல்கள்

Omarchy நான்கு சேனல்களில் புதுப்பிக்கப்படுகிறது: stable, RC, edge, மற்றும் dev. புதிய நிறுவல்கள் stable சேனலில் தொடங்குகின்றன, இது [அதிகாரப்பூர்வ வெளியீடுகளையும்](https://github.com/omacom/omarchy/releases/), அத்துடன் சமீபத்தியதை விட ஒரு மாதம் பின்தங்கி இயங்கும் [stable Omarchy Arch mirror](https://github.com/omacom-io/omarchy-mirror) ஐயும் பின்தொடர்கிறது, எனவே உள்ளமைவு மாற்றங்கள் தேவைப்படும் புதிய பொருந்தாமைகள் மக்களுக்குப் பிரச்சினைகளை ஏற்படுத்துவதற்கு முன்பே அவற்றை நாங்கள் பிடித்துவிட முடியும்.

ஆனால் அந்தச் சாத்தியமான பிரச்சினைகளைக் கண்டறிய நீங்கள் உதவ விரும்பினால், edge சேனலில் இயங்கலாம். அது உங்கள் Omarchy தொகுப்புகளைச் சமீபத்திய மேம்பாட்டு உருவாக்கங்களைப் பின்தொடர வைக்கும், மேலும் சமீபத்திய Arch தொகுப்புகள் கிடைத்தவுடனேயே அவற்றுக்குப் புதுப்பிக்க உங்களை அனுமதிக்கும். நீங்கள் Linux இல் அனுபவம் வாய்ந்தவராகவும், பிரச்சினைகள் உள்ள கணினியை எப்படி மீட்பது என்று தெரிந்தவராகவும் இருந்தால் மட்டுமே இதைச் செய்ய வேண்டும்.

எந்தவொரு புதிய பெரிய வெளியீட்டுக்கும் முன்பு, RC சேனலைப் பயன்படுத்தி இறுதிச் சரிபார்ப்பைச் செய்வோம். இறுதி மெருகூட்டலில் உதவ ஆர்வமாக இருந்தால், Discord இல் #omarchy-release-candidates இல் வந்து கலந்துகொள்ளுங்கள்.

இறுதியாக, dev சேனல் உள்ளது, இது edge தொகுப்புகளுடன் இணைந்து, `~/omarchy` இல் உள்ள மூலக் குறியீட்டின் git checkout உடன் Omarchy ஐ நேரடியாக இணைக்கிறது. நீங்கள் அனுபவம் வாய்ந்த Linux பயனராகவும், Omarchy இல் நேரடியாகப் பணிபுரிபவராகவும், உடைவுகளைப் பொறுத்துக்கொள்ளத் தயாராகவும் இருந்தால் மட்டுமே இந்தச் சேனலைப் பயன்படுத்த வேண்டும்.

Omarchy மெனுவிலிருந்து _புதுப்பிப்பு > Channel_ ஐப் பயன்படுத்தி (அல்லது டெர்மினலில் `omarchy-channel-set`) சேனல்களுக்கு இடையே மாறலாம்.

### கர்னல்களை மாற்றுதல்

Omarchy தனது சொந்த `linux-omarchy` கர்னலைத் துவக்குகிறது, ஆனால் அதற்கு அருகிலேயே மற்றவற்றையும் நிறுவி வைத்திருக்கலாம், அதாவது இயல்பான Arch `linux` கர்னல் அல்லது நீங்கள் சோதித்துக்கொண்டிருக்கும் ஒரு சோதனை உருவாக்கம் போன்றவற்றை. ஒன்றுக்கு மேற்பட்டவை இருக்கும்போது, Omarchy மெனுவில் உள்ள _புதுப்பிப்பு > Kernel_ அவற்றைப் பட்டியலிடும், இயல்பாகத் துவங்கும் ஒன்றுக்கு அருகில் ஒரு சரிக்குறி இருக்கும். மற்றொன்றைத் தேர்ந்தெடுத்து, உங்கள் கடவுச்சொல்லை ஒருமுறை உள்ளிடுங்கள், அடுத்த மறுதொடக்கத்திற்குப் பிறகு அது துவங்கும். மற்ற கர்னல்கள் துவக்க மெனுவில் தொடர்ந்து இருக்கும், எனவே புதிய இயல்புநிலை உங்களுக்குச் சிக்கலைத் தந்தால் நீங்கள் இன்னும் கைமுறையாக ஒன்றைத் தேர்ந்தெடுக்கலாம். டெர்மினலில், தற்போதைய இயல்புநிலையைப் பார்க்க `omarchy-kernel`, நிறுவப்பட்டுள்ளவற்றுக்கு `omarchy-kernel list`, மாற்றுவதற்கு `omarchy-kernel set <kernel>`.

### Firmware புதுப்பிப்புகள்

காலாவதியாவது உங்கள் தொகுப்புகள் மட்டுமல்ல. பல மடிக்கணினிகளும் புறச்சாதனங்களும் Linux Vendor Firmware Service வழியாக BIOS, SSD, மற்றும் dock firmware ஐ வழங்குகின்றன, மேலும் Omarchy மெனுவில் உள்ள _புதுப்பிப்பு > Firmware_ உங்கள் வன்பொருளுக்குக் காத்திருக்கும் எதையும் பெற்று நிறுவும். நீங்கள் அதை முதல் முறை இயக்கும்போது அது `fwupd` ஐ நிறுவும். ஏராளமான firmware ஐ மறுதொடக்கத்தின் போது மட்டுமே எழுத முடியும், எனவே ஒன்று கேட்கப்பட்டால் ஆச்சரியப்படாதீர்கள்.

BIOS இலேயே ஒரு அமைப்பை மாற்ற வேண்டியிருக்கும்போது, கணினி மெனுவில் (`Super + Escape`) `Alt` ஐப் பிடித்திருங்கள், _மறுதொடக்கம்_ ஆனது _BIOS க்கு மறுதொடக்கம் செய்_ ஆக மாறும், இது துவக்கத்தில் சரியான விசையைப் பிடிக்க வேண்டிய அவசியமின்றி நேரடியாக firmware அமைப்புக்குள் மறுதொடக்கம் செய்யும். டெர்மினலிலிருந்து, அது `omarchy system firmware`.

### நேரடி pacman/yay புதுப்பிப்புகள் பற்றிய எச்சரிக்கை

உங்களுக்கு ஏற்கனவே Arch பரிச்சயமாக இருந்தால், நீங்களே `pacman -Syu` அல்லது `yay -Syu` ஐ இயக்கத் தூண்டப்படலாம், ஆனால் அப்படிச் செய்தால், புதிய தொகுப்புகளுடன் Omarchy ஒன்றாக இயக்கும் snapshot, இடம்பெயர்வுகள், மற்றும் உள்ளமைவுப் புதுப்பிப்புகளை நீங்கள் தவறவிடுவீர்கள். அதனால்தான் Omarchy உண்மையில் ஒரு நேரடிக் கணினி மேம்படுத்தலை நிறுத்தி, அதற்குப் பதிலாக `omarchy update` க்கு உங்களைச் சுட்டிக்காட்டும். (நீங்கள் என்ன செய்கிறீர்கள் என்று உண்மையிலேயே உங்களுக்குத் தெரிந்தால், அந்தக் காவல் ஒரு ஒற்றைப் பரிவர்த்தனைக்கு அதை எப்படித் தவிர்ப்பது என்று உங்களுக்குச் சொல்லும்.)

### மோசமான புதுப்பிப்புகளைத் திரும்பப் பெறுதல்

புதுப்பிப்பு செய்த பிறகு உங்களுக்கு எப்போதாவது பிரச்சினை ஏற்பட்டால், புதுப்பிப்புக்கு முன் எடுக்கப்பட்ட snapshot க்கு உங்கள் கணினியைத் திரும்பக் கொண்டு செல்லலாம். மறுதொடக்கம் செய்து, நீங்கள் புதுப்பிப்பைத் தொடங்குவதற்கு முந்தைய துவக்க ஏற்றல் மெனுவில் உள்ள snapshot ஐத் தேர்ந்தெடுத்தால் போதும்.

![bootloader](images/bootloader.webp)

எப்படியோ உங்கள் உள்ளமைவுக் கோப்புகள் சிதைந்துவிட்டால், டெர்மினலில் `omarchy reinstall` ஐப் பயன்படுத்தி Omarchy மறுநிறுவலையும் செய்யலாம். இது அனைத்து இயல்புநிலை Omarchy தொகுப்புகளையும் மீண்டும் நிறுவும், உங்களை stable இல் வைக்கும், மிகவும் புதியதாக உள்ள எந்தத் தொகுப்புகளையும் தரமிறக்கும், மேலும் அனைத்து உள்ளமைவுக் கோப்புகளையும் மீட்டமைக்கும். இதைச் செய்வதால் Omarchy இயல்புநிலைகளில் நீங்கள் செய்த அனைத்து பயனர் உள்ளமைவு மாற்றங்களும் மேலெழுதப்படும் என்பதைக் கவனத்தில் கொள்ளவும்!
