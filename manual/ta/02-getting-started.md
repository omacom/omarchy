# தொடங்குவது

Omarchy ஒரு ISO ஐப் பயன்படுத்தி நிறுவப்படுகிறது. முழு இயக்ககத்தையும் எடுத்துக்கொள்ளும் முழு-வட்டு நிறுவலுக்கும், ஒரு இயக்ககத்தில் ஒதுக்கப்படாத இடத்தில் Omarchy ஐ வைக்கும் காலி-இட நிறுவலுக்கும் இடையே நீங்கள் தேர்வு செய்யலாம் — Windows அல்லது வேறொரு OS இன் அருகில் dual boot செய்வது அப்படித்தான் (பார்க்க [dual-boot நிறுவல்](50-dual-boot-install.md) — முதலில் Windows இல் BitLocker ஐ அணைக்க வேண்டும் என்பதைக் கவனியுங்கள்). எப்படி இருந்தாலும், நிறுவல் இயல்பாகவே முழு encryption உடன் வருகிறது, மேலும் முழு-வட்டு விருப்பம் தேர்ந்தெடுக்கப்பட்ட இயக்ககத்தை அழித்துவிடும், எனவே ஏற்கெனவே உள்ள ஒன்றைப் பயன்படுத்துவதற்கு முன் கண்டிப்பாக backup எடுத்துக்கொள்ளுங்கள்!

முதலில் [Omarchy ISO ஐப் பதிவிறக்கவும்](https://omarchy.org/), அதை ஒரு USB stick இல் போடவும் (Windows இல் [Rufus](https://rufus.ie/) ஐ, Mac இல் [balenaEtcher](https://etcher.balena.io/) ஐ, அல்லது Linux இல் [caligula](https://github.com/ifd3f/caligula) ஐப் பயன்படுத்தவும்), பிறகு அந்த stick இலிருந்து boot செய்யவும்.

_BIOS இல் Secure Boot மற்றும்/அல்லது TPM ஐ நீங்கள் அணைக்க வேண்டும். Omarchy ஐ நிறுவ முடிய வேண்டுமென்றால் இவற்றை அணைக்கத்தான் வேண்டும். அவை Windows மற்றும் Microsoft உடன் இணைந்த Linux distributions களுக்காக உருவாக்கப்பட்ட Microsoft பாதுகாப்புத் திட்டங்கள்._

பிறகு configuration கேள்விகளுக்குப் பதிலளித்து, இப்படி அவற்றை உறுதிப்படுத்தவும்:

 ![install-config](images/install-config.webp)

பிறகு உங்கள் நிறுவலுக்கு ஒரு இயக்ககத்தைத் தேர்ந்தெடுத்து, நிம்மதியாக உட்கார்ந்து நிறுவல் நிகழ்ச்சி நடப்பதைப் பாருங்கள். மிக வேகமான நவீன கணினிகளில் இது ஒரு நிமிடத்திற்குள் முடிந்துவிடும், ஆனால் பழைய கணினியில் கூட இதற்கு 5 நிமிடங்களுக்கு மேல் ஆகக்கூடாது.

 ![install-done](images/install-done.webp)

இப்போது நீங்கள் Omarchy க்குத் தயார்!

### கம்பி இணைப்புள்ள அல்லது 2.4ghz keyboard ஐப் பயன்படுத்தவும்!

முழு-வட்டு encryption, தொடக்கத்தில் Bluetooth keyboard இலிருந்து password ஐ உள்ளிட உங்களை அனுமதிக்காது. ஒரு PC இல் BIOS க்குள் நுழைய Bluetooth keyboard ஐப் பயன்படுத்த முடியாதது போலத்தான். 2.4ghz dongle ஐப் பயன்படுத்தும் அல்லது cable ஐப் பயன்படுத்தும் keyboard உங்களுக்குத் தேவைப்படும் (latency க்கு cable எப்படியும் மிகவும் நல்லது!). தனிப்பட்ட முறையில் எனக்கு [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard) மிகவும் பிடிக்கும்!

### வேறொரு உரிமையாளருக்காக நிறுவுதல்

நீங்கள் வேறொருவருக்காக — ஒரு குடும்ப உறுப்பினர், ஒரு புதிய பணியாளர், ஒரு வாங்குபவர் — ஒரு கணினியை அமைக்கிறீர்கள் என்றால், அவர்கள் சார்பாகத் தனிப்பட்ட கேள்விகளுக்கு நீங்கள் பதிலளிக்கக் கூடாது. நிறுவியின் மிக முதல் திரையில் (keyboard தேர்வு) `Ctrl + C` ஐ அழுத்தவும், அதற்குப் பதிலாக கணினியை வேறொரு உரிமையாளருக்காகத் தயாரிக்க Omarchy முன்வரும். System உடனடியாக நிறுவப்படும், ஆனால் அனைத்துத் தனிப்பட்ட அமைப்புகளும் — keyboard layout, username, password — கணினி முதல் முறையாக boot ஆகும் வரை ஒத்திவைக்கப்படும். இயக்ககம் இன்னும் இயல்பாகவே encrypted ஆக இருக்கும், மேலும் அந்த முதல் boot இல் புதிய உரிமையாளர் தேர்ந்தெடுக்கும் password தான் encryption password உம் ஆகும். (நீங்கள் ஏற்கெனவே பயன்படுத்தி வந்த கணினியை மீண்டும் நிறுவாமலேயே ஒப்படைக்கவும் முடியும் — பார்க்க [கணினியை மீட்டமைத்தல்](48-security.md).)

### கவனிப்பில்லா நிறுவல்கள்

ISO க்கு அதன் configuration இரண்டாவது இயக்ககத்தில் கொடுக்கப்பட்டால், அது முழுவதுமாகத் தானாகவே — keyboard இல்லாமல், wizard இல்லாமல் — நிறுவவும் முடியும். VM கள் மற்றும் fleet கணினிகளுக்கு Omarchy ஐ ஒரு base image ஆகக் கருதுவதற்கான வழி அதுதான். பார்க்க [கவனிப்பில்லா நிறுவல்கள்](51-unattended-installs.md).

### encryption இல்லாத நிறுவல்கள்

Omarchy இயல்பாக encryption உடன் நிறுவப்படுகிறது. தொலைந்து போகவோ திருடப்படவோ கூடிய எந்தக் கணினிக்கும் அதுதான் பாதுகாப்பான, பொறுப்பான தேர்வு. உங்கள் hardware ஐ அணுகக்கூடிய எவரும் உங்கள் data ஐப் பெற முடிவதை நீங்கள் விரும்ப மாட்டீர்கள்!

ஆனால் பாதுகாக்கப்பட்ட கணினிகளில் தொலைவிலிருந்து செய்யப்படும் Omarchy நிறுவல்கள் போன்ற சிறப்புச் சூழ்நிலைகளில், அல்லது முக்கியமான data இல்லாத தூக்கி எறியக்கூடிய நிறுவல்களுக்கு, நீங்கள் encryption இல்லாமல் நிறுவ விரும்பலாம். encryption இல்லாத நிறுவலுக்கு மாற, disk formatting உறுதிப்படுத்தலில் `Ctrl + C` ஐ அழுத்தலாம்.

### மொழி

Omarchy 50 மொழிகள் பேசுகிறது — omarchy.org இல் உள்ள அதே தொகுப்பு — மேலும் English தான் இயல்புநிலை. மாற்ற, Omarchy menu ஐத் திறந்து _அமைப்பு > பிராந்தியம் > மொழி_ க்குச் செல்லவும், அல்லது ஒரு terminal இல் `omarchy language <code>` ஐ இயக்கவும் (`omarchy language list` குறியீடுகளைக் காட்டுகிறது). Menu, desktop, மற்றும் Omarchy இன் சொந்த அறிவிப்புகள் உடனடியாக மொழியை மாற்றும், மேலும் அதன் பிறகு நீங்கள் திறக்கும் ஒவ்வொரு application உம் அதைப் பின்பற்றும். ஏற்கெனவே திறந்திருந்த Apps, நீங்கள் அவற்றை மறுதொடக்கம் செய்தவுடன் மாறும்.

மொழியை அப்படியே வைத்துக்கொண்டு, தேதிகள், நேரங்கள், எண்கள், பணம், அலகுகள் மற்றும் காகித அளவுகளை வேறொரு பிராந்தியம் செய்வது போல எழுத (எடுத்துக்காட்டாக, ஐரோப்பிய தேதிகள் மற்றும் 24-hour clock உடன் English), _அமைப்பு > பிராந்தியம் > வடிவங்கள்_ இன் கீழ் ஒரு பிராந்தியத்தைத் தேர்ந்தெடுக்கவும், அங்கு ஒவ்வொரு தேர்வும் ஒரு மாதிரியைக் காட்டுகிறது, அல்லது `omarchy region <code>` ஐ இயக்கவும் (`omarchy region list` குறியீடுகளைக் காட்டுகிறது). _மொழியைப் போலவே_ என்பது மொழியின் சொந்த formats க்குத் திரும்புகிறது. ஒரு மொழி மாற்றத்தைப் போலவே, இதுவும் அதன் பிறகு நீங்கள் திறக்கும் apps ஐச் சென்றடைகிறது.

### நீங்கள் சிக்கிக்கொண்டால் உதவி

நீங்கள் சிக்கிக்கொண்டால், [சமூக Discord](https://omarchy.org/discord) இல் உள்ள _#omarchy-help_ channel இல் உதவத் தயாராக இருக்கும் ஒருவரை வழக்கமாகக் கண்டுபிடிக்கலாம்.
