# தொடங்குதல்

Omarchy ஒரு ISO-வைப் பயன்படுத்தி நிறுவப்படுகிறது. முழு வட்டையும் எடுத்துக்கொள்ளும் முழு-வட்டு நிறுவலுக்கும், ஒரு வட்டில் ஒதுக்கப்படாத இடத்தில் Omarchy-ஐ வைக்கும் காலி-இட நிறுவலுக்கும் இடையே நீங்கள் தேர்வு செய்யலாம் — Windows அல்லது மற்றொரு OS-உடன் சேர்த்து dual boot செய்வது அப்படித்தான் (பார்க்கவும் [இரட்டை-துவக்க நிறுவல்](50-dual-boot-install.md) — முதலில் Windows-இல் BitLocker-ஐ அணைக்க வேண்டும் என்பதைக் கவனத்தில் கொள்ளவும்). எப்படியிருந்தாலும், நிறுவல் இயல்பாகவே முழு குறியாக்கத்துடன் வருகிறது, முழு-வட்டு விருப்பம் தேர்ந்தெடுக்கப்பட்ட வட்டை அழித்துவிடும், எனவே ஏற்கனவே உள்ள ஒன்றைப் பயன்படுத்துவதற்கு முன் காப்புப்பிரதி எடுத்துக்கொள்வதை உறுதிப்படுத்திக் கொள்ளுங்கள்!

முதலில் [Omarchy ISO-வைப் பதிவிறக்கி](https://omarchy.org/), அதை ஒரு USB குச்சியில் வையுங்கள் (Windows-இல் [Rufus](https://rufus.ie/), Mac-இல் [balenaEtcher](https://etcher.balena.io/), அல்லது Linux-இல் [caligula](https://github.com/ifd3f/caligula) பயன்படுத்தவும்), பின்னர் அந்தக் குச்சியிலிருந்து துவக்கவும்.

_நீங்கள் BIOS-இல் Secure Boot மற்றும்/அல்லது TPM-ஐ அணைக்க வேண்டும். Omarchy-ஐ நிறுவ முடிவதற்கு இவற்றை அணைக்க வேண்டும். அவை Windows மற்றும் Microsoft-உடன் இணைந்த Linux விநியோகங்களுக்காக வடிவமைக்கப்பட்ட Microsoft பாதுகாப்புத் திட்டங்கள்._

பின்னர் உள்ளமைவுக் கேள்விகளுக்குப் பதிலளித்து, இதுபோல அவற்றை உறுதிப்படுத்தவும்:

 ![install-config](images/install-config.webp)

பின்னர் உங்கள் நிறுவலுக்கு ஒரு வட்டைத் தேர்ந்தெடுத்து, நிதானமாக அமர்ந்து நிறுவல் நிகழ்ச்சியைப் பாருங்கள். வேகமான நவீன கணினிகளில் இது ஒரு நிமிடத்திற்குள் முடிந்துவிடும், ஆனால் பழைய கணினியில் கூட இது 5 நிமிடங்களுக்கு மேல் எடுக்கக்கூடாது.

 ![install-done](images/install-done.webp)

இப்போது நீங்கள் Omarchy-க்குத் தயார்!

### கம்பி இணைப்பு அல்லது 2.4ghz விசைப்பலகையைப் பயன்படுத்துங்கள்!

முழு-வட்டு குறியாக்கம் தொடக்கத்தில் Bluetooth விசைப்பலகையிலிருந்து கடவுச்சொல்லை உள்ளிட உங்களை அனுமதிக்காது. ஒரு PC-இல் BIOS-ஐ உள்ளிட Bluetooth விசைப்பலகையைப் பயன்படுத்த முடியாதது போலவேதான் இதுவும். 2.4ghz டாங்கிள் அல்லது கேபிளைப் பயன்படுத்தும் விசைப்பலகை உங்களுக்குத் தேவைப்படும் (எப்படியும் தாமதத்திற்கு கேபிள் மிகவும் சிறந்தது!). தனிப்பட்ட முறையில் எனக்கு [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard) மிகவும் பிடிக்கும்!

### மற்றொரு உரிமையாளருக்காக நிறுவுதல்

நீங்கள் வேறொருவருக்காக — ஒரு குடும்ப உறுப்பினர், ஒரு புதிய ஊழியர், ஒரு வாங்குபவர் — ஒரு கணினியை அமைக்கிறீர்கள் என்றால், அவர்கள் சார்பாகத் தனிப்பட்ட கேள்விகளுக்கு நீங்கள் பதிலளிக்கக்கூடாது. நிறுவியின் மிக முதல் திரையில் (விசைப்பலகைத் தேர்வு) `Ctrl + C` அழுத்தவும், அதற்குப் பதிலாக கணினியை மற்றொரு உரிமையாளருக்காகத் தயார் செய்ய Omarchy முன்வரும். கணினி உடனடியாக நிறுவப்படும், ஆனால் அனைத்துத் தனிப்பட்ட அமைப்புகளும் — விசைப்பலகை தளவமைப்பு, பயனர்பெயர், கடவுச்சொல் — கணினி முதல் முறையாகத் துவங்கும் வரை ஒத்திவைக்கப்படும். வட்டு இன்னும் இயல்பாகவே குறியாக்கம் செய்யப்படுகிறது, அந்த முதல் துவக்கத்தில் புதிய உரிமையாளர் தேர்ந்தெடுக்கும் கடவுச்சொல்லே குறியாக்கக் கடவுச்சொல்லாகவும் மாறுகிறது. (நீங்கள் ஏற்கனவே பயன்படுத்தி வந்த கணினியையும் மறுநிறுவல் இல்லாமல் ஒப்படைக்கலாம் — பார்க்கவும் [கணினியை மீட்டமைத்தல்](48-security.md).)

### கவனிப்பு தேவையில்லாத நிறுவல்கள்

ISO தனது உள்ளமைவை இரண்டாவது வட்டில் பெறும்போது, முழுமையாகத் தானாகவே — விசைப்பலகை இல்லாமல், வழிகாட்டி இல்லாமல் — நிறுவவும் முடியும். VM-கள் மற்றும் பல கணினிகளுக்கு Omarchy-ஐ ஒரு அடிப்படைப் படிமமாகக் கருதுவது அப்படித்தான். பார்க்கவும் [கவனிப்பு தேவையில்லாத நிறுவல்கள்](51-unattended-installs.md).

### குறியாக்கம் இல்லாத நிறுவல்கள்

Omarchy இயல்பாகவே குறியாக்கத்துடன் நிறுவப்படுகிறது. தொலைந்து போகவோ திருடப்படவோ வாய்ப்புள்ள எந்தக் கணினிக்கும் இதுவே பாதுகாப்பான, பொறுப்பான தேர்வு. உங்கள் வன்பொருளை அணுகக்கூடிய எவரும் உங்கள் தரவைப் பெறுவதை நீங்கள் விரும்ப மாட்டீர்கள்!

ஆனால் சிறப்புச் சூழ்நிலைகளில், பாதுகாக்கப்பட்ட கணினிகளில் தொலைநிலை Omarchy நிறுவல்கள் போன்றவற்றில் அல்லது முக்கியத் தரவு இல்லாத தூக்கி எறியக்கூடிய நிறுவல்களுக்கு, குறியாக்கம் இல்லாமல் நிறுவ நீங்கள் விரும்பலாம். குறியாக்கம் இல்லாத நிறுவலுக்கு மாற, வட்டு வடிவமைப்பு உறுதிப்படுத்தலில் `Ctrl + C` அழுத்தலாம்.

### மொழி

Omarchy 50 மொழிகள் பேசுகிறது — omarchy.org-இல் உள்ள அதே தொகுப்பு — ஆங்கிலமே இயல்புநிலை. மாற்ற, Omarchy பட்டியைத் திறந்து _Setup > Region > Language_ செல்லவும், அல்லது ஒரு முனையத்தில் `omarchy language <code>` இயக்கவும் (`omarchy language list` குறியீடுகளைக் காட்டுகிறது). பட்டி, மேசைத்தளம் மற்றும் Omarchy-இன் சொந்த அறிவிப்புகள் உடனடியாக மொழியை மாற்றுகின்றன, அதன் பிறகு நீங்கள் திறக்கும் ஒவ்வொரு பயன்பாடும் அதைப் பின்பற்றுகிறது. ஏற்கனவே திறந்திருந்த பயன்பாடுகள், நீங்கள் அவற்றை மறுதொடக்கம் செய்தவுடன் மாறுகின்றன.

மொழியை அப்படியே வைத்துக்கொண்டு, தேதிகள், நேரங்கள், எண்கள், பணம், அலகுகள் மற்றும் காகித அளவுகளை மற்றொரு பிராந்தியம் செய்வதுபோல எழுத (எடுத்துக்காட்டாக, ஐரோப்பியத் தேதிகள் மற்றும் 24-மணி நேரக் கடிகாரத்துடன் ஆங்கிலம்), ஒவ்வொரு தேர்வும் ஒரு மாதிரியைக் காட்டும் _Setup > Region > Formats_ இன் கீழ் ஒரு பிராந்தியத்தைத் தேர்ந்தெடுக்கவும், அல்லது `omarchy region formats <code>` இயக்கவும் (`omarchy region formats list` குறியீடுகளைக் காட்டுகிறது). _Same as language_ மொழியின் சொந்த வடிவங்களுக்குத் திரும்புகிறது. ஒரு மொழி மாற்றத்தைப் போலவே, இது அதன் பிறகு நீங்கள் திறக்கும் பயன்பாடுகளைச் சென்றடைகிறது.
