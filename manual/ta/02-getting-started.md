# தொடங்குதல்

Omarchy ஒரு ISO ஐப் பயன்படுத்தி நிறுவப்படுகிறது. முழு drive ஐயும் கைப்பற்றும் full-disk நிறுவல் அல்லது ஒரு drive இல் ஒதுக்கப்படாத இடத்தில் Omarchy ஐ வைக்கும் free-space நிறுவல் ஆகியவற்றில் ஒன்றை நீங்கள் தேர்வு செய்யலாம் — Windows அல்லது வேறொரு OS உடன் dual boot செய்வது அப்படித்தான் (பார்க்க [dual-boot நிறுவல்](50-dual-boot-install.md) — முதலில் Windows இல் BitLocker ஐ அணைக்க வேண்டும் என்பதைக் கவனிக்கவும்). எப்படி இருந்தாலும், நிறுவல் இயல்பாகவே முழு encryption ஐக் கொண்டிருக்கும், மேலும் full-disk விருப்பம் தேர்ந்தெடுக்கப்பட்ட drive ஐ முற்றிலும் அழித்துவிடும், எனவே ஏற்கனவே உள்ள ஒன்றைப் பயன்படுத்துவதற்கு முன் கண்டிப்பாக backup எடுத்துக்கொள்ளுங்கள்!

முதலில் [Omarchy ISO ஐப் பதிவிறக்கவும்](https://omarchy.org/), அதை ஒரு USB stick இல் போடவும் (Mac/Windows இல் [balenaEtcher](https://etcher.balena.io/) அல்லது Linux இல் [caligula](https://github.com/ifd3f/caligula) பயன்படுத்தவும்), பிறகு அந்த stick இலிருந்து boot செய்யவும்.

_BIOS இல் Secure Boot மற்றும்/அல்லது TPM ஐ அணைக்க வேண்டும். Omarchy ஐ நிறுவ முடிய வேண்டுமென்றால் இவற்றை அணைத்தாக வேண்டும். இவை Windows மற்றும் Microsoft உடன் இணைந்த Linux distributions க்காக வடிவமைக்கப்பட்ட Microsoft பாதுகாப்புத் திட்டங்கள்._

பிறகு உள்ளமைவுக் கேள்விகளுக்குப் பதில் சொல்லி, இப்படி அவற்றை உறுதிப்படுத்தவும்:

 ![install-config](images/install-config.webp)

பிறகு உங்கள் நிறுவலுக்கு ஒரு drive ஐத் தேர்ந்தெடுத்து, சாய்ந்து உட்கார்ந்து நிறுவல் காட்சியைப் பாருங்கள். மிக வேகமான நவீன இயந்திரங்களில் இது ஒரு நிமிடத்திற்குள் முடிந்துவிடும், ஆனால் பழைய கணினியில் கூட 5 நிமிடங்களுக்கு மேல் ஆகக் கூடாது.

 ![install-done](images/install-done.webp)

இப்போது நீங்கள் Omarchy செய்யத் தயார்!

### கம்பி உள்ள அல்லது 2.4ghz keyboard பயன்படுத்தவும்!

தொடக்கத்தில் Bluetooth keyboard இலிருந்து password ஐ உள்ளிட full-disk encryption அனுமதிக்காது. ஒரு PC இல் BIOS க்குள் நுழைய Bluetooth keyboard ஐப் பயன்படுத்த முடியாததைப் போலவே. 2.4ghz dongle அல்லது கம்பி பயன்படுத்தும் keyboard உங்களுக்குத் தேவைப்படும் (எப்படியும் latency க்கு அது மிகவும் சிறந்தது!). தனிப்பட்ட முறையில் எனக்கு [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard) மிகவும் பிடிக்கும்!

### மற்றொரு உரிமையாளருக்காக நிறுவுதல்

நீங்கள் வேறொருவருக்காக — ஒரு குடும்ப உறுப்பினர், ஒரு புதிய ஊழியர், ஒரு வாங்குபவர் — ஒரு இயந்திரத்தை அமைக்கிறீர்கள் என்றால், அவர்கள் சார்பாகத் தனிப்பட்ட கேள்விகளுக்கு நீங்கள் பதில் சொல்லக் கூடாது. நிறுவியின் மிக முதல் திரையில் (keyboard தேர்வு) `Ctrl + C` ஐ அழுத்துங்கள், மற்றொரு உரிமையாளருக்காக இயந்திரத்தைத் தயார் செய்ய Omarchy முன்வரும். கணினி உடனடியாக நிறுவப்படும், ஆனால் அனைத்துத் தனிப்பட்ட அமைப்பும் — keyboard layout, username, password — இயந்திரம் முதல் முறையாக boot ஆகும் வரை ஒத்திவைக்கப்படும். drive இன்னும் இயல்பாகவே encrypted ஆக இருக்கும், மேலும் அந்த முதல் boot இல் புதிய உரிமையாளர் தேர்ந்தெடுக்கும் password தான் encryption password ஆகவும் மாறும். (நீங்கள் ஏற்கனவே பயன்படுத்தி வந்த இயந்திரத்தையும் மீண்டும் நிறுவாமல் ஒப்படைக்க முடியும் — பார்க்க [கணினியை மீட்டமைத்தல்](48-security.md).)

### கண்காணிப்பு இல்லாத நிறுவல்கள்

ISO தானாகவே முழுமையாக நிறுவவும் முடியும் — keyboard இல்லை, wizard இல்லை — இரண்டாவது drive இல் அதன் உள்ளமைவு அதிடம் ஒப்படைக்கப்படும்போது. Omarchy ஐ VMs மற்றும் fleet இயந்திரங்களுக்கான அடிப்படை image ஆகக் கருதுவதற்கான வழி அதுதான். பார்க்க [கண்காணிப்பு இல்லாத நிறுவல்கள்](51-unattended-installs.md).

### encryption இல்லாத நிறுவல்கள்

Omarchy இயல்பாகவே encryption உடன் நிறுவப்படுகிறது. தொலைந்து போகவோ திருடப்படவோ வாய்ப்புள்ள எந்தக் கணினிக்கும் இது பாதுகாப்பான, பொறுப்பான தேர்வு. உங்கள் hardware ஐ அணுகக்கூடிய எவரும் உங்கள் தரவைப் பெற முடிய வேண்டும் என்று நீங்கள் விரும்ப மாட்டீர்கள்!

ஆனால் சிறப்புச் சூழ்நிலைகளில், பாதுகாக்கப்பட்ட கணினிகளில் தொலைநிலை Omarchy நிறுவல்கள் போல, அல்லது முக்கியமான தரவு இல்லாத தூக்கி எறியக்கூடிய நிறுவல்களுக்கு, encryption இல்லாமல் நிறுவ நீங்கள் விரும்பலாம். disk formatting உறுதிப்படுத்தலில் `Ctrl + C` ஐ அழுத்தி encryption இல்லாத நிறுவலுக்கு மாறலாம்.

### மொழி

Omarchy 50 மொழிகள் பேசுகிறது — omarchy.org இன் அதே தொகுப்பு — மேலும் English தான் இயல்புநிலை. மாற்ற, Omarchy menu ஐத் திறந்து _Setup > Language_ க்குச் செல்லவும், அல்லது terminal இல் `omarchy language <code>` ஐ இயக்கவும் (`omarchy language list` குறியீடுகளைக் காட்டுகிறது). menu, desktop மற்றும் Omarchy இன் சொந்த அறிவிப்புகள் உடனடியாக மொழியை மாற்றும், மேலும் அதற்குப் பிறகு நீங்கள் திறக்கும் ஒவ்வொரு application உம் அதைப் பின்பற்றும். ஏற்கனவே திறந்திருந்த apps நீங்கள் அவற்றை மீண்டும் தொடங்கியதும் மாறும்.
