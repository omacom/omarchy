# வலைச் செயலிகள்

Omarchy மெனுவில் (`Super + Space`) _நிறுவு > Web App_ ஐப் பயன்படுத்தி உங்கள் சொந்த வலைச் செயலிகளைச் சேர்க்கலாம். செயலியின் பெயர், செயலி URL மற்றும் ஐகான் URL ஐ favicon வழியாக மீட்டெடுக்க முடியாவிட்டால் அது கேட்கும். பல பிரபலமான வலைச் செயலிகளுக்கான சிறந்த PNG ஐகான்களை [Dashboard Icons](https://dashboardicons.com) இல் பெறலாம்.

பின்னர் அவை செயலி தொடக்கி (`Super + Space`) வழியாக அணுகக்கூடியவையாக இருக்கும், மேலும் அழகான frameless வலைச் செயலி சாளரத்தைப் பயன்படுத்தும்.

வலைச் செயலியை அகற்ற விரும்பினால், Omarchy மெனுவில் _நீக்கு > Web App_ க்குச் செல்லவும்.

வலைச் செயலி குறுக்குவழிகளைப் பயன்படுத்துவதற்கு முன் வழக்கமான உலாவியைப் பயன்படுத்தி உங்கள் அனைத்து கணக்குகளிலும் உள்நுழைவது சிறந்தது. மெல்லிய wrapper frame 1password உடன் நன்றாக வேலை செய்யாது, எனவே முதலில் நேரடியாக உள்நுழைவது எளிது.

இந்த வலைச் செயலிகளுக்கான அனைத்து விசைப்பலகை hotkey களையும் `~/.config/hypr/bindings.lua` இல் மாற்றலாம்.

நீங்கள் வலைச் செயலியில் இருக்கும்போது, `Shift + Alt + L` ஐப் பயன்படுத்தித் தற்போதைய URL ஐ கிளிப்போர்டுக்கு நகலெடுக்கலாம்.

இயல்பாக, Omarchy ஏற்கனவே இயல்புநிலைச் செயலிகளின் தொகுப்புடன் வருகிறது:

## HEY

[HEY](https://www.hey.com/) என்பது Gmail, Outlook அல்லது Apple Mail இல் சோர்ந்தவர்களுக்குச் சிறந்த மாற்றாகச் செயல்படும் மின்னஞ்சல் மற்றும் நாள்காட்டிச் சேவை. இது Omarchy தோன்றிய [37signals](https://37signals.com/) ஆல் உருவாக்கப்பட்டது.

`Super + Shift + E` ஐப் பயன்படுத்தி HEY Email ஐத் தொடங்கலாம், `Super + Shift + Alt + E` ஐப் பயன்படுத்தி நேரடியாகப் புதிய மின்னஞ்சலை எழுதச் செல்லலாம், மேலும் `Super + Shift + C` ஐப் பயன்படுத்தி HEY Calendar ஐத் தொடங்கலாம்.

## Basecamp

[Basecamp](https://basecamp.com/) என்பது சிறிய குழுக்கள் வேகமாகச் செல்லவும் அதிக முன்னேற்றம் அடையவும் உதவும் ஒரு திட்ட மேலாண்மைச் சேவை. Trello, Slack, Asana, Notion அல்லது எதுவாயினும் கலவையை ஒன்றாக இணைப்பதற்குப் பதிலாக, Basecamp உடன் அனைத்தையும் ஒரே இடத்தில் வைத்திருக்கலாம். இது Omarchy தோன்றிய [37signals](https://37signals.com/) ஆல் உருவாக்கப்பட்டது.

செயலி தொடக்கியைப் (`Super + Space`) பயன்படுத்தி Basecamp ஐத் தொடங்கலாம்

## ChatGPT

[ChatGPT](https://chatgpt.com) என்பது உலகின் மிகவும் பிரபலமான AI அரட்டை bot.

`Super + Shift + A` ஐப் பயன்படுத்தி ChatGPT ஐத் தொடங்கலாம்.

## Grok

[Grok](https://grok.com) என்பது xAI இன் அரட்டை bot.

`Super + Shift + Alt + A` ஐப் பயன்படுத்தி Grok ஐத் தொடங்கலாம்.

## WhatsApp

[WhatsApp](https://www.whatsapp.com/) என்பது உலகின் மிகவும் பிரபலமான செய்தியிடல் சேவைகளில் ஒன்று, மேலும் வலைப் பதிப்பு Linux க்கு ஒரு சிறந்த விருப்பம்.

`Super + Shift + Alt + G` ஐப் பயன்படுத்தி WhatsApp ஐத் தொடங்கலாம்.

## Google செயலிகள்

Google Messages, Google Photos, Google Maps மற்றும் Google Contacts அனைத்தும் வலைச் செயலிகளாகவும் சேர்க்கப்பட்டுள்ளன.

`Super + Shift + Ctrl + G` ஐப் பயன்படுத்தி Google Messages ஐயும், `Super + Shift + P` ஐப் பயன்படுத்தி Google Photos ஐயும், `Super + Shift + S` ஐப் பயன்படுத்தி Google Maps ஐயும் தொடங்கலாம். Google Contacts செயலி தொடக்கி (`Super + Space`) வழியாகக் கிடைக்கிறது.

## X

X என்பது செய்திகள் உடைக்கும் இடம்.

`Super + Shift + X` ஐப் பயன்படுத்தி X ஐத் தொடங்கலாம், `Super + Shift + Alt + X` உடன் நேரடியாகப் புதிய இடுகையை எழுதச் செல்லலாம்.

## YouTube

[YouTube](https://youtube.com/) என்பது உலகின் மிகவும் பிரபலமான வீடியோ தளம்.

`Super + Shift + Y` ஐப் பயன்படுத்தி YouTube ஐத் தொடங்கலாம்.

## Zoom

[Zoom](https://zoom.us/) என்பது அமெரிக்காவில் பயன்படுத்தப்படும் மிகவும் பிரபலமான வீடியோ அரட்டை அமைப்பு. உலகம் முழுவதும் சிறந்த இணைப்புகள். மேலும் கட்டணக் கணக்கு இல்லாமல் 40 நிமிடக் கூட்டங்களை நடத்தலாம். Omarchy Zoom இன் வலை client ஐ மூடுகிறது, மேலும் zoom கூட்ட இணைப்புகள் நேரடியாக அதில் திறக்கும்.

செயலி தொடக்கியைப் (`Super + Space`) பயன்படுத்தி Zoom ஐத் தொடங்குகிறீர்கள்.

## Discord

[Discord](https://discord.com/) என்பது [Omarchy இன் சொந்தம்](https://discord.gg/tXFUdasqhY) உட்பட, பெரும்பாலான gaming மற்றும் திறந்த மூல சமூகங்கள் சந்திக்கும் இடம்.

செயலி தொடக்கியைப் (`Super + Space`) பயன்படுத்தி Discord ஐத் தொடங்குகிறீர்கள்.

## Microsoft செயலிகள்

Outlook, Word, Excel, PowerPoint, Teams மற்றும் OneDrive ஐ வலைச் செயலிகளாகச் சேர்க்க _நிறுவு > Service > Microsoft_ ஐத் தேர்ந்தெடுக்கவும். ஒவ்வொரு செயலிக்கும் அதன் சொந்த தொடக்கி உள்ளது, வணிக Microsoft 365 URL கள் மற்றும் உங்கள் தற்போதைய உலாவி சுயவிவரத்தைப் பயன்படுத்தி நேரடியாகத் திறக்கிறது. அவை Omarchy இன் பிற வலைச் செயலிகளைப் போல அதே உலாவி செயலி சாளரங்களில் திறக்கின்றன; அவை தனி Teams for Linux client ஐ நிறுவுவதில்லை.

_நீக்கு > Service > Microsoft_ உடன் bundle ஐ அகற்றவும், அல்லது _நீக்கு > Web App_ உடன் தனிப்பட்ட செயலிகளை அகற்றவும். _நிறுவு > Web App_ மூலம் நீங்கள் விரும்பும் செயலிகளை மட்டும் நிறுவலாம்.

அரசு அல்லது இறையாண்மை கிளவுடுக்கு, உங்கள் நிறுவனம் வழங்கிய URL ஐப் பயன்படுத்தி, `~/.local/share/applications/` க்குக் கீழ் உள்ள தொடர்புடைய தொடக்கியில், எடுத்துக்காட்டாக `Microsoft Teams.desktop` இல், `Exec=` வரியில் உள்ள URL ஐத் திருத்தவும். அந்த வரியில் உள்ள எந்த நேரடி `%` ஐயும் `%%` என்று எழுதவும். மாற்றங்கள் அடுத்த தொடக்கத்தில் பொருந்தும். bundle நிறுவியை மீண்டும் இயக்குவது அதன் தொடக்கிகளை இயல்புநிலை URL களுடன் மாற்றுகிறது.

பணி உள்நுழைவுகளைத் தனியாக வைக்க, ஒவ்வொரு தொடக்கியின் `Exec=` வரியிலும் ஒரு உலாவித் தரவுக் கோப்பகத்தைச் சேர்க்கவும்:

```ini
Exec=omarchy-launch-webapp "https://teams.cloud.microsoft/" --user-data-dir=/absolute/path/to/work-browser-profile
```

எடுத்துக்காட்டுக் கோப்பகத்தை உங்கள் விருப்பப்படி முழுமையான பாதையுடன் மாற்றவும், பணி உள்நுழைவுகளை அவற்றுக்கு இடையே பகிர ஆறு தொடக்கிகளுக்கும் அதே பாதையைப் பயன்படுத்தவும். வலைச் செயலிகள் Omarchy இன் தேர்ந்தெடுக்கப்பட்ட ஆதரிக்கப்படும் உலாவியைப் பயன்படுத்துகின்றன, இயல்புநிலை உலாவி ஆதரிக்கப்படாதபோது Chromium க்குத் திரும்பும்.
