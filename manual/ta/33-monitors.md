# திரைகள்

Omarchy நீங்கள் இயல்பாக 2x திறன் கொண்ட retina வகுப்புக் காட்சியில் இயங்குகிறீர்கள் என்று கருதுகிறது. அந்த அழகான, மிருதுவான நிரலாளர் எழுத்துருக்களைப் பெற இதுதான் உங்களுக்குத் தேவை. உயர் தெளிவுத்திறன் திரைகளுடன் கூடிய ஏறக்குறைய அனைத்து புதிய premium மடிக்கணினிகளும் இதற்காகவே மேம்படுத்தப்பட்டுள்ளன. 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) அல்லது 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) இல் நீங்கள் இயக்க விரும்புவது இதுதான்.

ஆனால் 218 அல்லது அதற்கு மேற்பட்ட PPI உடன் காட்சியை நீங்கள் இயக்கவில்லை என்றால், திரை அமைப்புகளை மாற்ற விரும்புவீர்கள். எடுத்துக்காட்டாக, உங்களிடம் 27" அல்லது 32" 4K இருந்தால், `~/.config/hypr/monitors.lua` ஐத் (Omarchy மெனுவில் _அமைப்பு > திரைகள்_ வழியாக) திறந்து அந்தச் சேர்க்கைக்கான பரிந்துரைக்கு மாறுவதன் மூலம் fractional scaling ஐப் பயன்படுத்தலாம்:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

1080p அல்லது 1440p காட்சியைப் பயன்படுத்தினால், நீங்கள் 1x scaling ஐப் பயன்படுத்த விரும்புவீர்கள், எனவே பயன்படுத்தலாம்:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

`GDK_SCALE` க்கான மாற்றங்கள் மாற்றத்திற்குப் பிறகு தொடங்கப்பட்ட செயலிகளுக்குப் பொருந்தும் (மேலும் GTK முழு எண்களை மட்டுமே மதிக்கிறது, எனவே அதை உங்கள் திரை அளவின் மிக நெருக்கமான முழு எண்ணில் வைக்கவும்). எனவே மாற்றத்திற்குப் பிறகு பெரிதாக உள்ள சாளரங்களை விட்டு வெளியேறுவதை உறுதிப்படுத்தவும் (அல்லது `Ctrl + Alt + Del` உடன் அனைத்து சாளரங்களையும் மூடவும்!).

`Super + /` ஐப் பயன்படுத்தி உயரவும், `Super + Alt + /` ஐப் பயன்படுத்திக் குறையவும் முக்கிய திரை அளவிடல் விகிதங்கள் (1x, 1.25x, 1.6x, 2x, 3x, 4x) வழியாகவும் விரைவாகச் செல்லலாம். உங்களிடம் இயல்புநிலை கட்டமைப்பு இருந்தால், இந்த மாற்றங்கள் மறுதொடக்கத்திற்குப் பிறகும் நீடிக்கும்.

### உரையைப் பெரிதாக்குதல் அல்லது சிறிதாக்குதல்

திரை அளவிடல் எல்லாவற்றின் அளவையும் மாற்றுகிறது. நீங்கள் விரும்புவது பெரிய அல்லது சிறிய _உரை_ மட்டுமே என்றால், அதற்கு ஒற்றைக் குமிழி உள்ளது:

```
omarchy display text size 14
```

அது 9 முதல் 20 வரையிலான pixel அளவை எடுத்து, Omarchy shell, GTK செயலிகள் மற்றும் உங்கள் முனையத்தை ஒன்றாக நகர்த்துகிறது, எனவே முழு டெஸ்க்டாப்பும் விகிதத்தில் இருக்கும். நீங்கள் எங்கே இருக்கிறீர்கள் என்பதைப் பார்க்க அளவுரு இல்லாமல் அதை இயக்கவும், இயல்புநிலைக்குத் திரும்ப `omarchy display text size reset` ஐ இயக்கவும். Foot தான் ஒரே பின்தங்கியது: அதன் கட்டமைப்பை மீண்டும் ஏற்ற வழி இல்லை, எனவே நீங்கள் புதிய ஒன்றைத் திறக்கும் வரை இயங்கும் முனையங்கள் அவற்றின் பழைய அளவை வைத்திருக்கும்.

### மடிக்கணினிக் காட்சிகளை நீட்டித்தல் மற்றும் பிரதிபலித்தல்

உங்கள் மடிக்கணினியுடன் வெளிப்புறத் திரையை இணைக்கும்போது, காட்சி தானாகவே நீட்டிக்கப்படும். ஆனால் Omarchy மெனுவில் _தூண்டு > வன்பொருள்_ அல்லது `Super + Ctrl + Alt + Delete` ஐப் பயன்படுத்தி அதற்குப் பதிலாகப் பிரதிபலிப்பிற்கு அதை மாற்றலாம். அந்த வெளிப்புறத் திரை projector ஆக இருந்து, வேலை செய்யும் போது ஏதாவது காட்ட விரும்பினால் இது குறிப்பாக உதவியாக இருக்கும்.

நீங்கள் நீட்டிக்கும்போது, மடிக்கணினியின் மூடியை மூடுவது உள் திரையைத் தானாகவே அணைக்கும். மூடியைத் திறப்பது அதை மீண்டும் இயக்கும். Omarchy மெனுவில் _தூண்டு > வன்பொருள்_ அல்லது `Super + Ctrl + Delete` ஐப் பயன்படுத்தி இதைக் கையாலும் கட்டுப்படுத்தலாம்.

### பல திரைகளை ஏற்பாடு செய்தல்

Hyprland பல திரைகளுடன் சிறப்பாக வேலை செய்கிறது. [Hyprland திரை ஆவணத்தில்](https://wiki.hypr.land/Configuring/Basics/Monitors/) அவற்றை எப்படி அமைப்பது என்பது பற்றி மேலும் படிக்கவும். [குறிப்பிட்ட பணியிடங்களைக் குறிப்பிட்ட திரைகளுடன் பிணைக்கலாம்](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/). Omarchy இல், இந்த விதிகள் `hl.monitor` உள்ளீடுகளாக `~/.config/hypr/monitors.lua` இல் செல்கின்றன — குறிப்பிட்ட திரையைத் தெளிவுத்திறன், நிலை மற்றும் சுழற்சிக்குப் பின் செய்வதற்கான கருத்துரைக்கப்பட்ட எடுத்துக்காட்டுகளுடன் கோப்பு வருகிறது.

பல திரைகளின் நிலைப்படுத்தலுக்கு TUI உதவ விரும்பினால், [Hyprmon](https://github.com/erans/hyprmon/) ஐயும் பார்க்கலாம்.

### பிரகாசத்தைக் கட்டுப்படுத்துதல்

திரை பிரகாசம் பிரகாசம் மேல்/கீழ் என்பதற்கான பிரத்யேக செயல்பாட்டு விசைகளால் கட்டுப்படுத்தப்படுகிறது. இவற்றை அழுத்தும்போது shift ஐப் பிடித்தால், அதிகபட்ச அல்லது குறைந்தபட்ச பிரகாசத்திற்குச் செல்வீர்கள். விசைகள் நீங்கள் கவனம் செலுத்தும் காட்சியைக் கட்டுப்படுத்துகின்றன, எனவே DDC/CI பேசும் வெளிப்புறத் திரைகள் மடிக்கணினித் திரையைப் போலவே சரிசெய்யப்படுகின்றன.

### Apple காட்சிகள்

Apple காட்சியைப் பயன்படுத்தினால், Apple காட்சியில் நீங்கள் கவனம் செலுத்தினால் வழக்கமான விசைப்பலகை பிரகாச விசைகளும் தானாகவே வேலை செய்யும். இது `asdcontrol` கட்டளை வழியாகச் செய்யப்படுகிறது.

Apple 6K XDR காட்சியைப் பயன்படுத்தினால், உங்கள் `hyprctl monitors` பட்டியலில் ஒரு phantom திரையைக் காணலாம் என்பதை நினைவில் கொள்ளவும். _அமைப்பு > திரைகள்_ வழியாக `hl.monitor({ output = "DP-2", disabled = true })` போன்ற ஒன்றைக் கொண்டு இதை அணைக்கலாம்.

Intel இயந்திரங்களில், வழக்கமான Thunderbolt கேபிளைப் பயன்படுத்தி Apple காட்சிகளுடன் இணைக்க வேண்டும். Thunderbolt இல்லாத மற்ற இயந்திரங்களில், அதை வேலை செய்ய பொதுவாக [DP + USB-A -> USB-C கேபிளைப்](https://www.amazon.com/dp/B0BNX7MS6N) பயன்படுத்த வேண்டும்.
