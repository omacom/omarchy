# மானிட்டர்கள்

Omarchy நீங்கள் இயல்பாகவே 2x திறன் கொண்ட retina-class காட்சித் திரையில் இயங்குகிறீர்கள் என்று கருதுகிறது. அந்த அழகான, தெளிவான programmer எழுத்துருக்களைப் பெற உங்களுக்குத் தேவையானது இதுதான். உயர் தெளிவுத்திறன் கொண்ட திரைகளைக் கொண்ட கிட்டத்தட்ட எல்லா புதிய premium மடிக்கணினிகளும் இதற்காகவே மேம்படுத்தப்பட்டுள்ளன. 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) அல்லது 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) ஆகியவற்றில் நீங்கள் இயக்க விரும்புவதும் இதுதான்.

ஆனால் நீங்கள் 218 அல்லது அதற்கு மேற்பட்ட PPI கொண்ட காட்சித் திரையைப் பயன்படுத்தவில்லை என்றால், மானிட்டர் அமைப்புகளை மாற்ற வேண்டியிருக்கும். உதாரணமாக, உங்களிடம் 27" அல்லது 32" 4K இருந்தால், மேல் பட்டியில் உள்ள monitor panel-இல் இருந்து அதற்கான fractional scale-ஐத் தேர்ந்தெடுக்கலாம், அல்லது `~/.config/hypr/monitors.lua` ஐத் திறந்து அந்தக் கலவைக்கான பரிந்துரைக்கு மாற்றுவதன் மூலம் ஒவ்வொரு மானிட்டருக்கும் இயல்புநிலையை அமைக்கலாம்:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

நீங்கள் 1080p அல்லது 1440p காட்சித் திரையைப் பயன்படுத்துகிறீர்கள் என்றால், நீங்கள் பெரும்பாலும் 1x scaling-ஐயே பயன்படுத்த விரும்புவீர்கள், GTK மற்றும் X11 செயலிகளுக்கும் அதையே பயன்படுத்த விரும்புவீர்கள், எனவே நீங்கள் இதைப் பயன்படுத்தலாம்:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

`GDK_SCALE`-இல் செய்யப்படும் மாற்றங்கள், மாற்றத்திற்குப் பிறகு தொடங்கப்படும் செயலிகளுக்குப் பொருந்தும் (மேலும் GTK முழு எண்களை மட்டுமே ஏற்கும், எனவே அதை உங்கள் மானிட்டர் அளவீட்டிற்கு மிக நெருக்கமான முழு எண்ணில் வைத்திருங்கள்). எனவே மாற்றத்திற்குப் பிறகு அளவுக்கு மீறி பெரிதாக உள்ள சாளரங்களை நீங்கள் நிச்சயமாக மூடிவிடுங்கள் (அல்லது `Ctrl + Alt + Del` மூலம் எல்லா சாளரங்களையும் மூடிவிடுங்கள்!).

`Super + /` ஐப் பயன்படுத்தி அதிகமாக்கவும், `Super + Alt + /` ஐப் பயன்படுத்தி குறைக்கவும் முக்கிய மானிட்டர் அளவீட்டு விகிதங்களுக்கு (1x, 1.25x, 1.6x, 2x, 3x, 4x) இடையே விரைவாகப் படிப்படியாக மாறலாம், அல்லது மேல் பட்டியில் உள்ள monitor panel-இல் இருந்து ஒன்றைத் தேர்ந்தெடுக்கலாம். இவை நீங்கள் கவனம் செலுத்தியுள்ள மானிட்டரை மட்டுமே மாற்றும், எனவே ஒரு மடிக்கணினித் திரையும் ஒரு வெளிப்புறக் காட்சித் திரையும் ஒவ்வொன்றும் அதனதன் அளவீட்டைக் கொண்டிருக்கலாம். இந்த panel ஒவ்வொரு மானிட்டரின் தெளிவுத்திறனையும் அமைக்கிறது. உங்கள் தேர்வுகள் அந்த இயற்பியல் மானிட்டருக்காக `~/.local/state/omarchy/monitors/settings` இல் சேமிக்கப்படும், எனவே அவை reboot-க்குப் பிறகும் நீடிக்கும், மேலும் அடுத்து அது எந்த port அல்லது dock-இல் செருகப்பட்டாலும் மானிட்டரைப் பின்தொடரும். Omarchy ஒருபோதும் திருத்தாத `~/.config/hypr/monitors.lua` இல் அதே மானிட்டருக்கான எந்த விதியையும் விட அவை முன்னுரிமை பெறும். `GDK_SCALE` எல்லாத் திரைகளுக்கும் ஒரே ஒரு மதிப்பாக இருப்பதால், தேர்ந்தெடுக்கப்பட்ட அளவீடு, மிகக் குறைந்த அளவீடு கொண்ட மானிட்டரில் இருந்து அதை அமைக்கிறது, எனவே X11 செயலிகள் மற்றொன்றில் அளவுக்கு மீறி பெரிதாக வருவதற்குப் பதிலாக, அடர்த்தியான திரையில் சற்று சிறிதாக வரும்.

### உரையைப் பெரிதாக்குதல் அல்லது சிறிதாக்குதல்

மானிட்டர் அளவீடு எல்லாவற்றின் அளவையும் மாற்றுகிறது. நீங்கள் விரும்புவது பெரிய அல்லது சிறிய _உரை_ மட்டுமே என்றால், அதற்கு ஒரே ஒரு குமிழ் உள்ளது:

```
omarchy display text size 14
```

அது 9 முதல் 20 வரையிலான pixel அளவை எடுக்கும், மேலும் Omarchy shell, GTK செயலிகள் மற்றும் உங்கள் terminal ஆகியவற்றை ஒன்றாக நகர்த்தும், எனவே முழு desktop-உம் விகிதாச்சாரத்தில் இருக்கும். நீங்கள் எங்கே இருக்கிறீர்கள் என்பதைப் பார்க்க அதை வாதம் இல்லாமல் இயக்கவும், இயல்புநிலைக்குத் திரும்ப `omarchy display text size reset` ஐ இயக்கவும். Foot மட்டுமே பின்தங்கிய ஒன்று: அதன் config-ஐ மீண்டும் ஏற்ற அதற்கு எந்த வழியும் இல்லை, எனவே நீங்கள் புதிய ஒன்றைத் திறக்கும் வரை இயங்கும் terminal-கள் அவற்றின் பழைய அளவையே வைத்திருக்கும்.

### மடிக்கணினி காட்சித் திரைகளை நீட்டித்தல் மற்றும் பிரதிபலித்தல்

நீங்கள் ஒரு வெளிப்புறத் திரையை உங்கள் மடிக்கணினியுடன் இணைக்கும்போது, காட்சித் திரை தானாகவே நீட்டிக்கப்படும். ஆனால் Omarchy menu-வில் _Trigger > Hardware_ ஐப் பயன்படுத்தியோ அல்லது `Super + Ctrl + Alt + Delete` ஐப் பயன்படுத்தியோ அதற்குப் பதிலாக mirroring-க்கு அதை மாற்றலாம். அந்த வெளிப்புறத் திரை ஒரு projector ஆக இருந்து, நீங்கள் வேலை செய்யும்போது எதையாவது காட்ட விரும்பினால் இது குறிப்பாக உதவியாக இருக்கும்.

நீங்கள் நீட்டிக்கும்போது, மடிக்கணினியின் மூடியை மூடுவது உள் திரையைத் தானாகவே அணைத்துவிடும். மூடியைத் திறப்பது அதை மீண்டும் இயக்கும். Omarchy menu-வில் _Trigger > Hardware_ ஐப் பயன்படுத்தியோ அல்லது `Super + Ctrl + Delete` ஐப் பயன்படுத்தியோ இதை நீங்கள் கைமுறையாகவும் கட்டுப்படுத்தலாம்.

### பல திரைகளை ஒழுங்கமைத்தல்

Hyprland பல திரைகளுடன் சிறப்பாகச் செயல்படும். மேல் பட்டியில் உள்ள monitor panel அவை அமர்ந்திருக்கும் இடத்தில் அவற்றை வரையும்: ஒன்றை மற்றொன்றின் பக்கத்திற்கு எதிராக இழுத்து அதை அங்கே நகர்த்தவும், அந்த ஒழுங்கமைப்பு ஒவ்வொரு மானிட்டரின் மற்ற அமைப்புகளுடன் சேமிக்கப்படும். இந்த panel உள்ளடக்காத எதற்கும், அவற்றை எப்படி அமைப்பது என்பது பற்றி [Hyprland monitor ஆவணத்தில்](https://wiki.hypr.land/Configuring/Basics/Monitors/) மேலும் படிக்கவும். Omarchy-இல், இவை `~/.config/hypr/monitors.lua` இல் `hl.monitor` உள்ளீடுகளாகச் செல்லும் — ஒரு குறிப்பிட்ட மானிட்டரை ஒரு தெளிவுத்திறன், நிலை மற்றும் சுழற்சிக்கு நிலைநிறுத்துவதற்கான கருத்துரைக்கப்பட்ட எடுத்துக்காட்டுகளுடன் இந்தக் கோப்பு வருகிறது.

ஒவ்வொரு மானிட்டருக்கும் அதனதன் பணியிடங்கள் 1 முதல் 10 வரை உள்ளன, எனவே `Super + 1` என்பது எப்போதும் நீங்கள் இருக்கும் மானிட்டரின் முதல் பணியிடத்தையே குறிக்கும். திரைக்குப் பின்னால், Hyprland இன்னும் எல்லா மானிட்டர்களிலும் பணியிடங்களை எண்ணுகிறது: உங்கள் மடிக்கணினித் திரைக்கு (அல்லது முதல் மானிட்டருக்கு) 1–10 கிடைக்கும், அடுத்த மானிட்டருக்கு 11–20, இப்படியே தொடரும், மேலும் ஒவ்வொரு மானிட்டரும் நீங்கள் அதைச் செருகும் ஒவ்வொரு முறையும் அதன் தொகுதியை வைத்திருக்கும். ஒரு குறிப்பிட்ட மானிட்டருக்காக [பணியிட விதிகள்](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) அல்லது சாளர விதிகளை நீங்கள் எழுதினால் அந்த எண்களைப் பயன்படுத்தவும், எனவே பணியிடம் 12 என்பது உங்கள் இரண்டாவது மானிட்டரின் இரண்டாவது பணியிடமாகும். எந்த மானிட்டருக்கு எந்தத் தொகுதி உள்ளது என்பதை `~/.local/state/omarchy/monitors/workspaces` பட்டியலிடுகிறது.

உங்கள் அமைப்பில் ஒரு விளிம்பைப் பகிர்ந்து கொள்ளும் மானிட்டர்களுக்கு இடையே அம்புக்குறி விசைகள் செயல்படும். ஒரு மூலையில் மட்டும் தொடும், அல்லது அவற்றுக்கு இடையே இடைவெளி கொண்ட திரைகள் அண்டைத் திரைகள் அல்ல, எனவே அவற்றுக்கு இடையே செல்ல `Ctrl + Alt + Tab` ஐப் பயன்படுத்தவும்.

| ஹாட்கீ | மானிட்டர்களுக்கு இடையே |
| --- | --- |
| `Super + Arrow` | அந்தத் திசையில் இனி சாளரம் எதுவும் இல்லாததும் அந்தப் பக்கத்தில் உள்ள மானிட்டருக்குக் கவனத்தை நகர்த்தும் |
| `Super + Shift + Arrow` | அந்தப் பக்கத்தில் உள்ள மானிட்டரில் உள்ள ஒரு சாளரத்துடன் இடமாற்றம் செய்யும் |
| `Super + Alt + Arrow` | சாளரத்தை அந்தப் பக்கத்தில் உள்ள மானிட்டரில் உள்ள ஒரு குழுவிற்குள் நகர்த்தும் |
| `Super + Shift + Ctrl + Arrow` | சாளரத்தை அந்தப் பக்கத்தில் உள்ள மானிட்டருக்கு, அது காட்டும் பணியிடத்தின் மீது நகர்த்தும் |
| `Super + Shift + Alt + Arrow` | பணியிடத்தை அந்தப் பக்கத்தில் உள்ள மானிட்டருக்கு நகர்த்தும், அது காலியாக இருந்தால் அதன் எண்ணை வைத்திருக்கும் |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | அமைப்பு எதுவாக இருந்தாலும், அடுத்த அல்லது முந்தைய மானிட்டருக்குக் கவனத்தை நகர்த்தும் |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | நீங்கள் இருக்கும் மானிட்டரிலேயே இருக்கும் |

பல திரைகளின் நிலைப்படுத்தலில் உங்களுக்கு உதவ ஒரு TUI வேண்டுமென்று நீங்கள் விரும்பினால், நீங்கள் [Hyprmon](https://github.com/erans/hyprmon/) ஐயும் பார்க்கலாம்.

### பிரகாசத்தைக் கட்டுப்படுத்துதல்

மானிட்டர் பிரகாசம், பிரகாசத்தை அதிகரிப்பதற்கு/குறைப்பதற்கான பிரத்யேக function விசைகளால் கட்டுப்படுத்தப்படுகிறது. இவற்றை அழுத்தும்போது நீங்கள் shift ஐ அழுத்திப் பிடித்தால், நீங்கள் அதிகபட்ச அல்லது குறைந்தபட்ச பிரகாசத்திற்குச் செல்வீர்கள். இந்த விசைகள் நீங்கள் கவனம் செலுத்தியுள்ள காட்சித் திரையைக் கட்டுப்படுத்தும், எனவே DDC/CI பேசும் வெளிப்புற மானிட்டர்கள் மடிக்கணினித் திரையைப் போலவே சரிசெய்யப்படும்.

### Apple காட்சித் திரைகள்

நீங்கள் ஒரு Apple காட்சித் திரையைப் பயன்படுத்துகிறீர்கள் என்றால், நீங்கள் Apple காட்சித் திரையில் கவனம் செலுத்தியிருந்தால், வழக்கமான விசைப்பலகை பிரகாச விசைகளும் தானாகவே செயல்படும். இது `asdcontrol` கட்டளை மூலம் செய்யப்படுகிறது.

நீங்கள் ஒரு Apple 6K XDR காட்சித் திரையைப் பயன்படுத்துகிறீர்கள் என்றால், உங்கள் `hyprctl monitors` பட்டியலில் ஒரு மாயத் திரையைக் காணலாம் என்பதைக் கவனத்தில் கொள்ளவும். `~/.config/hypr/monitors.lua` இல் `hl.monitor({ output = "DP-2", disabled = true })` போன்ற ஒன்றைக் கொண்டு இதை அணைக்கலாம்.

Intel கணினிகளில், நீங்கள் ஒரு வழக்கமான Thunderbolt கேபிளைப் பயன்படுத்தி Apple காட்சித் திரைகளுடன் இணைக்க வேண்டும். Thunderbolt இல்லாத மற்ற கணினிகளில், அதைச் செயல்பட வைக்க நீங்கள் பொதுவாக ஒரு [DP + USB-A -> USB-C கேபிளைப்](https://www.amazon.com/dp/B0BNX7MS6N) பயன்படுத்த வேண்டியிருக்கும்.
