# மானிட்டர்கள்

Omarchy இயல்பாகவே நீங்கள் 2x திறன் கொண்ட retina-வகை டிஸ்பிளேவில் இயங்குவதாகக் கருதுகிறது. அந்த அழகான, தெளிவான programmer ஃபான்டுகளைப் பெற உங்களுக்குத் தேவையானது இதுதான். உயர் தெளிவுத்திறன் திரைகளைக் கொண்ட கிட்டத்தட்ட அனைத்து புதிய premium மடிக்கணினிகளும் இதற்காகவே உகந்ததாக்கப்பட்டுள்ளன. 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) அல்லது 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) இல் நீங்கள் இயக்க விரும்புவதும் இதுதான்.

ஆனால் 218 அல்லது அதற்கு மேற்பட்ட PPI கொண்ட டிஸ்பிளேவை நீங்கள் இயக்கவில்லை என்றால், மானிட்டர் அமைப்புகளை மாற்ற விரும்புவீர்கள். எடுத்துக்காட்டாக, உங்களிடம் 27" அல்லது 32" 4K இருந்தால், `~/.config/hypr/monitors.lua` ஐத் திறந்து (Omarchy மெனுவில் _Setup > Monitors_ வழியாக) அந்தக் கலவைக்கான பரிந்துரைக்கு மாறுவதன் மூலம் fractional scaling ஐப் பயன்படுத்தலாம்:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

நீங்கள் 1080p அல்லது 1440p டிஸ்பிளேவைப் பயன்படுத்துகிறீர்கள் என்றால், பெரும்பாலும் 1x scaling ஐயே பயன்படுத்த விரும்புவீர்கள், எனவே நீங்கள் இதைப் பயன்படுத்தலாம்:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

`GDK_SCALE` இல் செய்யப்படும் மாற்றங்கள் மாற்றத்திற்குப் பிறகு தொடங்கப்படும் பயன்பாடுகளுக்குப் பொருந்தும் (மேலும் GTK முழு எண்களை மட்டுமே ஏற்கும், எனவே அதை உங்கள் மானிட்டர் அளவிற்கு மிக அருகிலுள்ள முழு எண்ணிலேயே வைத்திருங்கள்). எனவே மாற்றத்திற்குப் பிறகு மிகப் பெரிதாக உள்ள சாளரங்களை நிச்சயம் மூடிவிடுங்கள் (அல்லது `Ctrl + Alt + Del` கொண்டு அனைத்து சாளரங்களையும் மூடுங்கள்!).

`Super + /` கொண்டு உயர்வாகவும் `Super + Alt + /` கொண்டு தாழ்வாகவும் சென்று முக்கிய மானிட்டர் scaling விகிதங்கள் (1x, 1.25x, 1.6x, 2x, 3x, 4x) வழியாக விரைவாகப் படிப்படியாக மாறலாம், அல்லது மேல் பட்டியில் உள்ள மானிட்டர் panel இலிருந்து ஒன்றைத் தேர்ந்தெடுக்கலாம். இவை நீங்கள் கவனம் செலுத்தியுள்ள மானிட்டரை மட்டுமே மாற்றும், எனவே மடிக்கணினித் திரையும் வெளிப்புற டிஸ்பிளேவும் தனித்தனி அளவைக் கொண்டிருக்கலாம். தேர்வு அந்த மானிட்டருக்கான `hl.monitor` விதியாக `~/.config/hypr/monitors.lua` இல் சேமிக்கப்படுகிறது, எனவே இது மறுதொடக்கத்திற்குப் பிறகும் நீடிக்கும், மேலும் `omarchy_monitor_scale` ஐ விட முன்னுரிமை பெறும்; `omarchy_monitor_scale` தனக்கென விதி இல்லாத ஒவ்வொரு மானிட்டருக்கான அளவாகவே இருக்கும்.

### உரையைப் பெரிதாக்குதல் அல்லது சிறிதாக்குதல்

மானிட்டர் scaling அனைத்தின் அளவையும் மாற்றுகிறது. உங்களுக்கு வேண்டியது பெரிய அல்லது சிறிய _உரை_ மட்டுமென்றால், அதற்கென ஒரே ஒரு knob உள்ளது:

```
omarchy display text size 14
```

அது 9 முதல் 20 வரையிலான pixel அளவை ஏற்கும், மேலும் Omarchy shell, GTK பயன்பாடுகள் மற்றும் உங்கள் terminal ஐ ஒன்றாக நகர்த்தும், எனவே முழு desktop உம் விகிதாச்சாரத்தில் இருக்கும். நீங்கள் எங்கே இருக்கிறீர்கள் என்று பார்க்க வாதம் இல்லாமல் அதை இயக்குங்கள், இயல்புநிலைக்குத் திரும்ப `omarchy display text size reset` ஐ இயக்குங்கள். Foot தான் ஒரே பின்தங்கியது: அதன் config ஐ மீண்டும் ஏற்ற வழியே இல்லை, எனவே நீங்கள் புதிய ஒன்றைத் திறக்கும் வரை இயங்கும் terminalகள் அவற்றின் பழைய அளவையே வைத்திருக்கும்.

### மடிக்கணினி டிஸ்பிளேக்களை நீட்டித்தல் மற்றும் பிரதிபலித்தல்

உங்கள் மடிக்கணினியுடன் வெளிப்புறத் திரையை இணைக்கும்போது, டிஸ்பிளே தானாகவே நீட்டிக்கப்படும். ஆனால் Omarchy மெனுவில் _Trigger > Hardware_ ஐப் பயன்படுத்தி அல்லது `Super + Ctrl + Alt + Delete` கொண்டு அதை mirroring ஆக மாற்றலாம். அந்த வெளிப்புறத் திரை ஒரு projector ஆக இருந்து, வேலை செய்யும் போது எதையாவது காட்ட விரும்பினால் இது குறிப்பாக உதவியாக இருக்கும்.

நீங்கள் நீட்டிக்கும்போது, மடிக்கணினியின் மூடியை மூடுவது உள் திரையைத் தானாகவே அணைத்துவிடும். மூடியைத் திறப்பது அதை மீண்டும் இயக்கும். Omarchy மெனுவில் _Trigger > Hardware_ ஐப் பயன்படுத்தி அல்லது `Super + Ctrl + Delete` கொண்டு இதைக் கைமுறையாகவும் கட்டுப்படுத்தலாம்.

### பல திரைகளை ஒழுங்கமைத்தல்

Hyprland பல திரைகளுடன் சிறப்பாகச் செயல்படுகிறது. அவற்றை எப்படி அமைப்பது என்பது பற்றி [Hyprland மானிட்டர் ஆவணங்களில்](https://wiki.hypr.land/Configuring/Basics/Monitors/) மேலும் படியுங்கள். Omarchy இல், இவை `~/.config/hypr/monitors.lua` இல் `hl.monitor` உள்ளீடுகளாகச் செல்லும் — ஒரு குறிப்பிட்ட மானிட்டரை ஒரு தெளிவுத்திறன், நிலை மற்றும் சுழற்சிக்கு நிலைநிறுத்துவதற்கான கருத்துரைக்கப்பட்ட எடுத்துக்காட்டுகளுடன் கோப்பு வருகிறது.

ஒவ்வொரு மானிட்டருக்கும் அதற்கென workspaces 1 முதல் 10 வரை உள்ளன, எனவே `Super + 1` என்பது எப்போதும் நீங்கள் இருக்கும் மானிட்டரின் முதல் workspace ஐக் குறிக்கும். திரைக்குப் பின்னால், Hyprland இன்னும் அனைத்து மானிட்டர்களிலும் workspaces ஐ எண்ணுகிறது: உங்கள் மடிக்கணினித் திரைக்கு (அல்லது முதல் மானிட்டருக்கு) 1–10 கிடைக்கும், அடுத்த மானிட்டருக்கு 11–20, இப்படியே தொடரும், மேலும் நீங்கள் அதை ஒவ்வொரு முறை இணைக்கும்போதும் ஒவ்வொரு மானிட்டரும் அதன் தொகுதியை வைத்திருக்கும். ஒரு குறிப்பிட்ட மானிட்டருக்கான [workspace விதிகள்](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) அல்லது சாளர விதிகளை நீங்கள் எழுதினால் அந்த எண்களைப் பயன்படுத்துங்கள், எனவே workspace 12 என்பது உங்கள் இரண்டாவது மானிட்டரின் இரண்டாவது workspace ஆகும். எந்த மானிட்டருக்கு எந்தத் தொகுதி உள்ளது என்பதை `~/.local/state/omarchy/monitor-workspaces` பட்டியலிடுகிறது.

உங்கள் அமைப்பில் ஒரு விளிம்பைப் பகிரும் மானிட்டர்களுக்கு இடையே அம்புக்குறி விசைகள் செயல்படும். ஒரு மூலையில் மட்டுமே தொடும், அல்லது இடையே இடைவெளி கொண்ட திரைகள் அண்டைத் திரைகள் அல்ல, எனவே அவற்றுக்கு இடையே செல்ல `Ctrl + Alt + Tab` ஐப் பயன்படுத்துங்கள்.

| ஹாட்கீ | மானிட்டர்களுக்கு இடையே |
| --- | --- |
| `Super + Arrow` | அந்தத் திசையில் இனி சாளரம் இல்லாததும் அந்தப் பக்கத்தில் உள்ள மானிட்டருக்குக் கவனத்தை நகர்த்துகிறது |
| `Super + Shift + Arrow` | அந்தப் பக்கத்தில் உள்ள மானிட்டரில் உள்ள சாளரத்துடன் மாற்றிக்கொள்கிறது |
| `Super + Alt + Arrow` | அந்தப் பக்கத்தில் உள்ள மானிட்டரில் உள்ள ஒரு குழுவிற்குள் சாளரத்தை நகர்த்துகிறது |
| `Super + Shift + Ctrl + Arrow` | அந்தப் பக்கத்தில் உள்ள மானிட்டருக்கு, அது காட்டிக்கொண்டிருக்கும் workspace மீது சாளரத்தை நகர்த்துகிறது |
| `Super + Shift + Alt + Arrow` | அந்தப் பக்கத்தில் உள்ள மானிட்டருக்கு workspace ஐ நகர்த்துகிறது, அது காலியாக இருந்தால் அதன் எண்ணை வைத்திருக்கிறது |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | அமைப்பு எதுவாக இருந்தாலும், அடுத்த அல்லது முந்தைய மானிட்டருக்குக் கவனத்தை நகர்த்துகிறது |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | நீங்கள் இருக்கும் மானிட்டரிலேயே இருக்கும் |

பல திரைகளின் நிலையை அமைப்பதில் உங்களுக்கு உதவ ஒரு TUI வேண்டும் என்றால், நீங்கள் [Hyprmon](https://github.com/erans/hyprmon/) ஐயும் பார்க்கலாம்.

### பிரகாசத்தைக் கட்டுப்படுத்துதல்

மானிட்டர் பிரகாசம் பிரகாசம் மேல்/கீழ் என்பதற்கான பிரத்யேக function விசைகளால் கட்டுப்படுத்தப்படுகிறது. இவற்றை அழுத்தும் போது shift ஐ அழுத்திப் பிடித்தால், அதிகபட்ச அல்லது குறைந்தபட்ச பிரகாசத்திற்குச் செல்வீர்கள். விசைகள் நீங்கள் கவனம் செலுத்தியுள்ள டிஸ்பிளேவைக் கட்டுப்படுத்தும், எனவே DDC/CI பேசும் வெளிப்புற மானிட்டர்கள் மடிக்கணினித் திரையைப் போலவே சரிசெய்யப்படும்.

### Apple டிஸ்பிளேக்கள்

நீங்கள் Apple டிஸ்பிளேவைப் பயன்படுத்துகிறீர்கள் என்றால், நீங்கள் Apple டிஸ்பிளேவில் கவனம் செலுத்தியிருந்தால், வழக்கமான விசைப்பலகை பிரகாச விசைகளும் தானாகவே செயல்படும். இது `asdcontrol` கட்டளை மூலம் செய்யப்படுகிறது.

நீங்கள் Apple 6K XDR டிஸ்பிளேவைப் பயன்படுத்துகிறீர்கள் என்றால், உங்கள் `hyprctl monitors` பட்டியலில் ஒரு phantom திரையைக் காணலாம் என்பதைக் கவனியுங்கள். _Setup > Monitors_ வழியாக `hl.monitor({ output = "DP-2", disabled = true })` போன்ற ஒன்றைக் கொண்டு இதை அணைக்கலாம்.

Intel இயந்திரங்களில், வழக்கமான Thunderbolt கேபிளைப் பயன்படுத்தி Apple டிஸ்பிளேக்களுடன் இணைக்க வேண்டும். Thunderbolt இல்லாத பிற இயந்திரங்களில், இது செயல்படப் பொதுவாக நீங்கள் [DP + USB-A -> USB-C கேபிளை](https://www.amazon.com/dp/B0BNX7MS6N) பயன்படுத்த வேண்டியிருக்கும்.
