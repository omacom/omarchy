# மானிட்டர்கள்

Omarchy இயல்பாகவே நீங்கள் 2x-திறன் கொண்ட retina-வகை காட்சித்திரையில் இயங்குகிறீர்கள் என்று கருதுகிறது. அந்த அழகான, தெளிவான நிரலாளர் எழுத்துருக்கள் கிடைக்க உங்களுக்கு இது தேவை. கிட்டத்தட்ட அனைத்து புதிய உயர்தர மடிக்கணினிகளின் உயர்-தெளிவுத்திறன் திரைகளும் இதற்காகவே மேம்படுத்தப்பட்டுள்ளன. 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) அல்லது 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) ஆகியவற்றில் நீங்கள் இயக்க விரும்புவதும் இதுதான்.

ஆனால் 218 அல்லது அதற்கு மேற்பட்ட PPI கொண்ட காட்சித்திரையில் நீங்கள் இயங்கவில்லை என்றால், மானிட்டர் அமைப்புகளை மாற்ற விரும்புவீர்கள். எடுத்துக்காட்டாக, உங்களிடம் 27" அல்லது 32" 4K இருந்தால், `~/.config/hypr/monitors.lua` ஐத் திறந்து (Omarchy மெனுவில் _Setup > Monitors_ வழியாக) அந்தக் கலவைக்கான பரிந்துரைக்கு மாற்றுவதன் மூலம் பின்ன அளவிடுதலைப் பயன்படுத்தலாம்:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

1080p அல்லது 1440p காட்சித்திரையைப் பயன்படுத்துகிறீர்கள் என்றால், பெரும்பாலும் நீங்கள் 1x அளவிடுதலையே பயன்படுத்த விரும்புவீர்கள், எனவே நீங்கள் இதைப் பயன்படுத்தலாம்:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

`GDK_SCALE` இல் செய்யப்படும் மாற்றங்கள் மாற்றத்திற்குப் பிறகு தொடங்கப்படும் பயன்பாடுகளுக்குப் பொருந்தும் (மேலும் GTK முழு எண்களை மட்டுமே ஏற்கும், எனவே அதை உங்கள் மானிட்டர் அளவிற்கு மிக நெருக்கமான முழு எண்ணிலேயே வைத்திருங்கள்). எனவே மாற்றத்திற்குப் பிறகு அளவுக்கு மீறி பெரிதாக இருக்கும் சாளரங்களை நீங்கள் மூடுவதை உறுதிப்படுத்திக் கொள்ளுங்கள் (அல்லது `Ctrl + Alt + Del` கொண்டு அனைத்து சாளரங்களையும் மூடுங்கள்!).

`Super + /` ஐப் பயன்படுத்தி உயர்வாகவும் `Super + Alt + /` ஐப் பயன்படுத்தி குறைவாகவும் முக்கிய மானிட்டர் அளவிடுதல் விகிதங்களில் (1x, 1.25x, 1.6x, 2x, 3x, 4x) விரைவாகவும் நீங்கள் படிப்படியாக மாறலாம். இயல்புநிலை உள்ளமைவு உங்களிடம் இருந்தால், இந்த மாற்றங்கள் மறுதொடக்கத்திற்குப் பிறகும் நீடிக்கும்.

### உரையைப் பெரிதாக்குதல் அல்லது சிறிதாக்குதல்

மானிட்டர் அளவிடுதல் எல்லாவற்றின் அளவையும் மாற்றுகிறது. நீங்கள் விரும்புவதெல்லாம் பெரிய அல்லது சிறிய _உரை_ மட்டுமே என்றால், அதற்கு ஒரே ஒரு குமிழ் உள்ளது:

```
omarchy display text size 14
```

அது 9 முதல் 20 வரையிலான பிக்சல் அளவை எடுக்கும், மேலும் Omarchy shell, GTK பயன்பாடுகள் மற்றும் உங்கள் terminal ஆகியவற்றை ஒன்றாக நகர்த்தும், எனவே முழு டெஸ்க்டாப்பும் விகிதாசாரத்திலேயே இருக்கும். நீங்கள் எங்கே இருக்கிறீர்கள் என்பதைப் பார்க்க அதை வாதம் இல்லாமல் இயக்குங்கள், இயல்புநிலைக்குத் திரும்ப `omarchy display text size reset` ஐ இயக்குங்கள். Foot தான் ஒரே பின்தங்கியது: அதன் config ஐ மீண்டும் ஏற்ற எந்த வழியும் அதற்கு இல்லை, எனவே நீங்கள் புதிய ஒன்றைத் திறக்கும் வரை இயங்கும் terminals அவற்றின் பழைய அளவையே வைத்திருக்கும்.

### மடிக்கணினி காட்சித்திரைகளை நீட்டித்தல் மற்றும் பிரதிபலித்தல்

உங்கள் மடிக்கணினியுடன் வெளிப்புறத் திரையை இணைக்கும்போது, காட்சித்திரை தானாகவே நீட்டிக்கப்படுகிறது. ஆனால் Omarchy மெனுவில் _Trigger > Hardware_ ஐப் பயன்படுத்தியோ அல்லது `Super + Ctrl + Alt + Delete` ஐப் பயன்படுத்தியோ அதைப் பிரதிபலிப்பதாக மாற்றலாம். அந்த வெளிப்புறத் திரை ஒரு projector ஆக இருந்து, நீங்கள் வேலை செய்யும் போது எதையாவது காட்ட விரும்பினால் இது குறிப்பாக உதவியாக இருக்கும்.

நீங்கள் நீட்டிக்கும்போது, மடிக்கணினியின் மூடியை மூடுவது உள் திரையைத் தானாகவே அணைத்துவிடும். மூடியைத் திறப்பது அதை மீண்டும் இயக்கும். Omarchy மெனுவில் _Trigger > Hardware_ ஐப் பயன்படுத்தியோ அல்லது `Super + Ctrl + Delete` ஐப் பயன்படுத்தியோ இதை கைமுறையாகவும் கட்டுப்படுத்தலாம்.

### பல திரைகளை அமைத்தல்

Hyprland பல திரைகளுடன் சிறப்பாகச் செயல்படுகிறது. அவற்றை எப்படி அமைப்பது என்பது பற்றி [Hyprland மானிட்டர் ஆவணங்களில்](https://wiki.hypr.land/Configuring/Basics/Monitors/) மேலும் படியுங்கள். Omarchy இல், இவை `~/.config/hypr/monitors.lua` இல் `hl.monitor` உள்ளீடுகளாகச் செல்கின்றன — ஒரு குறிப்பிட்ட மானிட்டரை ஒரு resolution, position மற்றும் rotation க்கு நிலைநிறுத்துவதற்கான கருத்துரைக்கப்பட்ட எடுத்துக்காட்டுகளுடன் இந்தக் கோப்பு வருகிறது.

ஒவ்வொரு மானிட்டருக்கும் அதற்கே உரிய 1 முதல் 10 வரையிலான workspaces உள்ளன, எனவே `Super + 1` என்பது எப்போதும் நீங்கள் இருக்கும் மானிட்டரின் முதல் workspace ஐக் குறிக்கிறது. திரைக்குப் பின்னால், Hyprland இன்னும் அனைத்து மானிட்டர்களிலும் workspaces ஐ எண்ணுகிறது: உங்கள் மடிக்கணினித் திரைக்கு (அல்லது முதல் மானிட்டருக்கு) 1–10 கிடைக்கிறது, அடுத்த மானிட்டருக்கு 11–20, இப்படியே தொடர்கிறது, மேலும் நீங்கள் அதைச் செருகும் ஒவ்வொரு முறையும் ஒவ்வொரு மானிட்டரும் அதன் தொகுதியை வைத்திருக்கிறது. ஒரு குறிப்பிட்ட மானிட்டருக்காக [workspace விதிகளை](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) அல்லது window விதிகளை எழுதினால் அந்த எண்களைப் பயன்படுத்துங்கள், எனவே workspace 12 என்பது உங்கள் இரண்டாவது மானிட்டரின் இரண்டாவது workspace ஆகும். எந்த மானிட்டருக்கு எந்தத் தொகுதி உள்ளது என்பதை `~/.local/state/omarchy/monitor-workspaces` பட்டியலிடுகிறது.

அம்புக்குறி விசைகள் உங்கள் தளவமைப்பில் ஒரு விளிம்பைப் பகிரும் மானிட்டர்களுக்கு இடையே செயல்படுகின்றன. ஒரு மூலையில் மட்டுமே தொடும் திரைகள், அல்லது அவற்றுக்கு இடையே இடைவெளி இருக்கும் திரைகள் அண்டைத் திரைகள் அல்ல, எனவே அவற்றுக்கு இடையே செல்ல `Ctrl + Alt + Tab` ஐப் பயன்படுத்துங்கள்.

| ஹாட்கீ | மானிட்டர்களுக்கு இடையே |
| --- | --- |
| `Super + Arrow` | அந்தத் திசையில் இனி சாளரம் இல்லாதவுடன் அந்தப் பக்கத்தில் உள்ள மானிட்டருக்கு கவனத்தை நகர்த்துகிறது |
| `Super + Shift + Arrow` | அந்தப் பக்கத்தில் உள்ள மானிட்டரில் உள்ள ஒரு சாளரத்துடன் மாற்றிக்கொள்கிறது |
| `Super + Alt + Arrow` | சாளரத்தை அந்தப் பக்கத்தில் உள்ள மானிட்டரில் உள்ள ஒரு குழுவிற்குள் நகர்த்துகிறது |
| `Super + Shift + Ctrl + Arrow` | சாளரத்தை அந்தப் பக்கத்தில் உள்ள மானிட்டருக்கு, அது காட்டும் workspace க்கு நகர்த்துகிறது |
| `Super + Shift + Alt + Arrow` | workspace ஐ அந்தப் பக்கத்தில் உள்ள மானிட்டருக்கு நகர்த்துகிறது, அது காலியாக இருந்தால் அதன் எண்ணையே வைத்திருக்கிறது |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | தளவமைப்பு எதுவாக இருந்தாலும், கவனத்தை அடுத்த அல்லது முந்தைய மானிட்டருக்கு நகர்த்துகிறது |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | நீங்கள் இருக்கும் மானிட்டரிலேயே இருக்கும் |

பல திரைகளை நிலைநிறுத்துவதில் உங்களுக்கு உதவ ஒரு TUI வேண்டுமென்றால், [Hyprmon](https://github.com/erans/hyprmon/) ஐயும் நீங்கள் பார்க்கலாம்.

### பிரகாசத்தைக் கட்டுப்படுத்துதல்

மானிட்டர் பிரகாசம் பிரகாசத்தைக் கூட்ட/குறைக்க என்ற பிரத்யேக செயல்பாட்டு விசைகளால் கட்டுப்படுத்தப்படுகிறது. இவற்றை அழுத்தும்போது shift ஐ அழுத்திப் பிடித்தால், நீங்கள் அதிகபட்ச அல்லது குறைந்தபட்ச பிரகாசத்திற்குச் செல்வீர்கள். விசைகள் நீங்கள் கவனம் செலுத்தும் காட்சித்திரையைக் கட்டுப்படுத்துகின்றன, எனவே DDC/CI பேசும் வெளிப்புற மானிட்டர்கள் மடிக்கணினித் திரையைப் போலவே சரிசெய்யப்படுகின்றன.

### Apple காட்சித்திரைகள்

நீங்கள் ஒரு Apple காட்சித்திரையைப் பயன்படுத்துகிறீர்கள் என்றால், நீங்கள் Apple காட்சித்திரையில் கவனம் செலுத்தியிருந்தால், வழக்கமான விசைப்பலகை பிரகாச விசைகளும் தானாகவே செயல்படும். இது `asdcontrol` கட்டளை மூலம் செய்யப்படுகிறது.

நீங்கள் ஒரு Apple 6K XDR காட்சித்திரையைப் பயன்படுத்துகிறீர்கள் என்றால், உங்கள் `hyprctl monitors` பட்டியலில் ஒரு போலித் திரையைக் காணலாம் என்பதை நினைவில் கொள்ளுங்கள். _Setup > Monitors_ வழியாக `hl.monitor({ output = "DP-2", disabled = true })` போன்ற ஒன்றைக் கொண்டு இதை அணைக்கலாம்.

Intel கணினிகளில், நீங்கள் ஒரு வழக்கமான Thunderbolt கேபிளைப் பயன்படுத்தி Apple காட்சித்திரைகளுடன் இணைக்க வேண்டும். Thunderbolt இல்லாத பிற கணினிகளில், இது வேலை செய்ய நீங்கள் பொதுவாக ஒரு [DP + USB-A -> USB-C கேபிளைப்](https://www.amazon.com/dp/B0BNX7MS6N) பயன்படுத்த வேண்டியிருக்கும்.
