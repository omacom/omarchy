# மானிட்டர்கள்

இயல்புநிலையாக, நீங்கள் 2x திறன் கொண்ட retina-வகுப்பு டிஸ்ப்ளேவில் இயங்குகிறீர்கள் என்று Omarchy கருதுகிறது. அந்த அழகான, தெளிவான நிரலாளர் எழுத்துருக்களைப் பெற உங்களுக்கு இதுதான் தேவை. உயர் தெளிவுத்திறன் கொண்ட திரைகளைக் கொண்ட கிட்டத்தட்ட அனைத்து புதிய பிரீமியம் மடிக்கணினிகளும் இதற்காகவே உகந்ததாக்கப்பட்டுள்ளன. 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) அல்லது 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) இல் நீங்கள் இயக்க விரும்புவதும் இதுதான்.

ஆனால் 218 அல்லது அதற்கு மேற்பட்ட PPI கொண்ட டிஸ்ப்ளேவில் நீங்கள் இயங்கவில்லை என்றால், மானிட்டர் அமைப்புகளை மாற்ற விரும்புவீர்கள். எடுத்துக்காட்டாக, உங்களிடம் 27" அல்லது 32" 4K இருந்தால், மேல் பட்டியில் உள்ள மானிட்டர் பேனலில் இருந்து அதற்கு ஒரு பின்ன அளவைத் தேர்ந்தெடுக்கலாம், அல்லது `~/.config/hypr/monitors.lua` ஐத் திறந்து அந்தக் கலவைக்கான பரிந்துரைக்கு மாற்றுவதன் மூலம் ஒவ்வொரு மானிட்டருக்கும் இயல்புநிலையை அமைக்கலாம்:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

நீங்கள் 1080p அல்லது 1440p டிஸ்ப்ளேவைப் பயன்படுத்துகிறீர்கள் என்றால், நீங்கள் 1x அளவீட்டை மட்டுமே பயன்படுத்த விரும்புவீர்கள், GTK மற்றும் X11 பயன்பாடுகளுக்கும் அதுவே பொருந்தும், எனவே நீங்கள் இதைப் பயன்படுத்தலாம்:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

`GDK_SCALE` இல் செய்யப்படும் மாற்றங்கள், மாற்றத்திற்குப் பிறகு தொடங்கப்படும் பயன்பாடுகளுக்குப் பொருந்தும் (மேலும் GTK முழு எண்களை மட்டுமே ஏற்கும், எனவே அதை உங்கள் மானிட்டர் அளவின் மிக அருகிலுள்ள முழு எண்ணில் வைத்திருங்கள்). எனவே மாற்றத்திற்குப் பிறகு அளவு அதிகமாக உள்ள சாளரங்களை விட்டு வெளியேறுவதை உறுதிப்படுத்திக் கொள்ளுங்கள் (அல்லது `Ctrl + Alt + Del` மூலம் அனைத்து சாளரங்களையும் மூடுங்கள்!).

`Super + /` ஐப் பயன்படுத்தி உயர்வாகச் செல்லவும், `Super + Alt + /` ஐப் பயன்படுத்தி குறைவாகச் செல்லவும் முக்கிய மானிட்டர் அளவீட்டு விகிதங்களில் (1x, 1.25x, 1.6x, 2x, 3x, 4x) விரைவாகப் படிப்படியாகச் செல்லலாம், அல்லது மேல் பட்டியில் உள்ள மானிட்டர் பேனலில் இருந்து ஒன்றைத் தேர்ந்தெடுக்கலாம். இவை நீங்கள் கவனம் செலுத்தும் மானிட்டரை மட்டுமே மாற்றும், எனவே மடிக்கணினித் திரையும் வெளிப்புற டிஸ்ப்ளேவும் ஒவ்வொன்றும் தங்களுக்கான அளவைக் கொண்டிருக்கலாம். பேனல் ஒவ்வொரு மானிட்டரின் தெளிவுத்திறனையும் அமைக்கிறது. உங்கள் தேர்வுகள் அந்த இயற்பியல் மானிட்டருக்காக `~/.local/state/omarchy/monitors/settings` இல் சேமிக்கப்படும், எனவே அவை மறுதொடக்கத்திற்குப் பிறகும் நீடிக்கும், அடுத்து அது எந்த போர்ட் அல்லது டாக்கில் செருகப்பட்டாலும் மானிட்டரைப் பின்தொடரும். அவை `~/.config/hypr/monitors.lua` இல் அதே மானிட்டருக்கான எந்த விதியையும் விட முன்னுரிமை பெறுகின்றன, அதை Omarchy ஒருபோதும் திருத்துவதில்லை. உங்கள் மானிட்டர்களை முழுவதுமாக அந்தக் கோப்பிலேயே அமைக்க விரும்பினால், அதில் `omarchy_monitor_panel_settings = false` ஐச் சேர்க்கவும், பேனலின் மாற்றங்கள் Hyprland மீண்டும் ஏற்றப்படும் வரை மட்டுமே நீடிக்கும். `GDK_SCALE` என்பது அனைத்துத் திரைகளுக்கும் ஒரே மதிப்பு என்பதால், தேர்ந்தெடுக்கப்பட்ட அளவு அதை மிகக் குறைந்த அளவு கொண்ட மானிட்டரில் இருந்து அமைக்கிறது, எனவே X11 பயன்பாடுகள் மற்றொன்றில் அளவு அதிகமாக வருவதற்குப் பதிலாக அடர்த்தியான திரையில் சற்று சிறியதாக வரும்.

### உரையைப் பெரிதாக்குதல் அல்லது சிறிதாக்குதல்

மானிட்டர் அளவீடு எல்லாவற்றின் அளவையும் மாற்றுகிறது. நீங்கள் விரும்புவது பெரிய அல்லது சிறிய _உரை_ மட்டுமே என்றால், அதற்கு ஒரே ஒரு கட்டுப்பாடு உள்ளது:

```
omarchy display text size 14
```

அது 9 முதல் 20 வரையிலான பிக்சல் அளவை எடுக்கும், மேலும் Omarchy ஷெல், GTK பயன்பாடுகள் மற்றும் உங்கள் டெர்மினலை ஒன்றாக நகர்த்தும், எனவே முழு டெஸ்க்டாப்பும் விகிதத்தில் இருக்கும். நீங்கள் எங்கு இருக்கிறீர்கள் என்பதைப் பார்க்க அதை வாதம் இல்லாமல் இயக்கவும், இயல்புநிலைக்குத் திரும்ப `omarchy display text size reset` ஐ இயக்கவும். Foot மட்டுமே பின்தங்கியது: அதன் உள்ளமைவை மீண்டும் ஏற்ற அதற்கு வழி இல்லை, எனவே இயங்கும் டெர்மினல்கள் நீங்கள் புதிய ஒன்றைத் திறக்கும் வரை அவற்றின் பழைய அளவையே வைத்திருக்கும்.

### மடிக்கணினி டிஸ்ப்ளேக்களை நீட்டித்தல் மற்றும் பிரதிபலித்தல்

உங்கள் மடிக்கணினியுடன் வெளிப்புறத் திரையை இணைக்கும்போது, டிஸ்ப்ளே தானாகவே நீட்டிக்கப்படும். ஆனால் Omarchy மெனுவில் _Trigger > Hardware_ ஐப் பயன்படுத்தி அல்லது `Super + Ctrl + Alt + Delete` ஐப் பயன்படுத்தி அதற்குப் பதிலாக பிரதிபலிப்பதாக அதை மாற்றலாம். அந்த வெளிப்புறத் திரை ஒரு ப்ரொஜெக்டராக இருந்து, வேலை செய்யும் போது எதையாவது காட்ட விரும்பினால் இது குறிப்பாக உதவியாக இருக்கும்.

நீங்கள் நீட்டிக்கும்போது, மடிக்கணினியின் மூடியை மூடுவது உள் திரையைத் தானாகவே அணைத்துவிடும். மூடியைத் திறப்பது அதை மீண்டும் இயக்கும். Omarchy மெனுவில் _Trigger > Hardware_ ஐப் பயன்படுத்தி அல்லது `Super + Ctrl + Delete` ஐப் பயன்படுத்தி இதை கைமுறையாகவும் கட்டுப்படுத்தலாம்.

### பல திரைகளை ஏற்பாடு செய்தல்

Hyprland பல திரைகளுடன் சிறப்பாகச் செயல்படுகிறது. மேல் பட்டியில் உள்ள மானிட்டர் பேனல் அவை அமர்ந்திருக்கும் இடத்தில் அவற்றை வரைகிறது: ஒன்றை மற்றொன்றின் பக்கத்திற்கு எதிராக இழுத்து அங்கே நகர்த்தவும், ஏற்பாடு ஒவ்வொரு மானிட்டரின் மற்ற அமைப்புகளுடன் சேமிக்கப்படும். பேனல் உள்ளடக்காத எதற்கும், அவற்றை எப்படி அமைப்பது என்பது பற்றி [Hyprland மானிட்டர் ஆவணங்களில்](https://wiki.hypr.land/Configuring/Basics/Monitors/) மேலும் படிக்கவும். Omarchy இல், இவை `~/.config/hypr/monitors.lua` இல் `hl.monitor` உள்ளீடுகளாகச் செல்லும் — குறிப்பிட்ட மானிட்டரை ஒரு தெளிவுத்திறன், நிலை மற்றும் சுழற்சிக்கு நிலைநிறுத்துவதற்கான கருத்துரைக்கப்பட்ட எடுத்துக்காட்டுகளுடன் கோப்பு வருகிறது.

ஒவ்வொரு மானிட்டருக்கும் அதற்கே உரிய 1 முதல் 10 வரையிலான பணியிடங்கள் உள்ளன, எனவே `Super + 1` என்பது எப்போதும் நீங்கள் இருக்கும் மானிட்டரின் முதல் பணியிடத்தையே குறிக்கும். திரைக்குப் பின்னால், Hyprland இன்னும் அனைத்து மானிட்டர்களிலும் பணியிடங்களுக்கு எண்ணிடுகிறது: உங்கள் மடிக்கணினித் திரை (அல்லது முதல் மானிட்டர்) 1–10 ஐப் பெறுகிறது, அடுத்த மானிட்டர் 11–20 ஐப் பெறுகிறது, இப்படியே தொடரும், மேலும் ஒவ்வொரு மானிட்டரும் நீங்கள் அதைச் செருகும் ஒவ்வொரு முறையும் அதன் தொகுதியை வைத்திருக்கும். குறிப்பிட்ட மானிட்டருக்காக [பணியிட விதிகளை](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) அல்லது சாளர விதிகளை எழுதினால் அந்த எண்களைப் பயன்படுத்தவும், எனவே பணியிடம் 12 என்பது உங்கள் இரண்டாவது மானிட்டரின் இரண்டாவது பணியிடம் ஆகும். ஒவ்வொரு மானிட்டருக்கும் எந்தத் தொகுதி உள்ளது என்பதை `~/.local/state/omarchy/monitors/workspaces` பட்டியலிடுகிறது.

உங்கள் அமைப்பில் விளிம்பைப் பகிரும் மானிட்டர்கள் முழுவதும் அம்புக்குறி விசைகள் செயல்படும். ஒரு மூலையில் மட்டுமே தொடும், அல்லது அவற்றுக்கு இடையே இடைவெளி கொண்ட திரைகள் அண்டைத் திரைகள் அல்ல, எனவே அவற்றுக்கு இடையே செல்ல `Ctrl + Alt + Tab` ஐப் பயன்படுத்தவும்.

| ஹாட்கீ | மானிட்டர்களுக்கு இடையே |
| --- | --- |
| `Super + Arrow` | அந்தத் திசையில் இனி சாளரம் இல்லாதவுடன் அந்தப் பக்கத்தில் உள்ள மானிட்டருக்குக் கவனத்தை நகர்த்துகிறது |
| `Super + Shift + Arrow` | அந்தப் பக்கத்தில் உள்ள மானிட்டரில் உள்ள சாளரத்துடன் இடமாற்றம் செய்கிறது |
| `Super + Alt + Arrow` | சாளரத்தை அந்தப் பக்கத்தில் உள்ள மானிட்டரில் உள்ள குழுவிற்குள் நகர்த்துகிறது |
| `Super + Shift + Ctrl + Arrow` | சாளரத்தை அந்தப் பக்கத்தில் உள்ள மானிட்டருக்கு, அது காட்டும் பணியிடத்திற்கு நகர்த்துகிறது |
| `Super + Shift + Alt + Arrow` | பணியிடத்தை அந்தப் பக்கத்தில் உள்ள மானிட்டருக்கு நகர்த்துகிறது, அது காலியாக இருந்தால் அதன் எண்ணை வைத்திருக்கிறது |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | அமைப்பு எப்படி இருந்தாலும், அடுத்த அல்லது முந்தைய மானிட்டருக்குக் கவனத்தை நகர்த்துகிறது |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | நீங்கள் இருக்கும் மானிட்டரிலேயே இருக்கும் |

பல திரைகளின் நிலைப்பாட்டில் உங்களுக்கு உதவ ஒரு TUI வேண்டுமென்றால், [Hyprmon](https://github.com/erans/hyprmon/) ஐயும் நீங்கள் பார்க்கலாம்.

### பிரகாசத்தைக் கட்டுப்படுத்துதல்

மானிட்டர் பிரகாசம் பிரகாசம் மேல்/கீழ் என்பதற்கான பிரத்யேக செயல்பாட்டு விசைகளால் கட்டுப்படுத்தப்படுகிறது. இவற்றை அழுத்தும் போது Shift ஐ அழுத்திப் பிடித்தால், நீங்கள் அதிகபட்ச அல்லது குறைந்தபட்ச பிரகாசத்திற்குச் செல்வீர்கள். விசைகள் நீங்கள் கவனம் செலுத்தும் டிஸ்ப்ளேவைக் கட்டுப்படுத்துகின்றன, எனவே DDC/CI பேசும் வெளிப்புற மானிட்டர்கள் மடிக்கணினித் திரையைப் போலவே சரிசெய்யப்படுகின்றன.

### Apple டிஸ்ப்ளேக்கள்

நீங்கள் Apple டிஸ்ப்ளேவைப் பயன்படுத்துகிறீர்கள் என்றால், நீங்கள் Apple டிஸ்ப்ளேவில் கவனம் செலுத்தினால், வழக்கமான விசைப்பலகை பிரகாச விசைகளும் தானாகவே செயல்படும். இது `asdcontrol` கட்டளை மூலம் செய்யப்படுகிறது.

நீங்கள் Apple 6K XDR டிஸ்ப்ளேவைப் பயன்படுத்துகிறீர்கள் என்றால், உங்கள் `hyprctl monitors` பட்டியலில் ஒரு மாயத் திரையைக் காணலாம் என்பதைக் கவனத்தில் கொள்ளவும். `~/.config/hypr/monitors.lua` இல் `hl.monitor({ output = "DP-2", disabled = true })` போன்ற ஒன்றைக் கொண்டு இதை அணைக்கலாம்.

Intel இயந்திரங்களில், நீங்கள் வழக்கமான Thunderbolt கேபிளைப் பயன்படுத்தி Apple டிஸ்ப்ளேக்களுடன் இணைக்க வேண்டும். Thunderbolt இல்லாத பிற இயந்திரங்களில், அது வேலை செய்ய நீங்கள் பொதுவாக [DP + USB-A -> USB-C கேபிளைப்](https://www.amazon.com/dp/B0BNX7MS6N) பயன்படுத்த வேண்டியிருக்கும்.
