# மானிட்டர்கள்

இயல்பாகவே, நீங்கள் 2x திறன் கொண்ட retina-தரத் திரையில் இயங்குகிறீர்கள் என்று Omarchy கருதுகிறது. அந்த அழகான, தெளிவான நிரலாளர் எழுத்துருக்கள் உங்களுக்குக் கிடைக்க இதுதான் தேவை. புதிய premium மடிக்கணினிகள் அனைத்துமே கிட்டத்தட்ட உயர் தெளிவுத்திறன் திரைகளுக்கு உகந்ததாகவே உள்ளன. 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) அல்லது 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) இல் இயக்க நீங்கள் விரும்புவதும் இதுதான்.

ஆனால் PPI 218 அல்லது அதற்கு மேல் உள்ள திரையில் நீங்கள் இயங்கவில்லை என்றால், மானிட்டர் அமைப்புகளை மாற்ற வேண்டியிருக்கும். எடுத்துக்காட்டாக, உங்களிடம் 27" அல்லது 32" 4K இருந்தால், `~/.config/hypr/monitors.lua` ஐத் திறந்து (Omarchy மெனுவில் _Setup > Monitors_ வழியாக) அந்தக் கலவைக்கான பரிந்துரைக்கு மாறுவதன் மூலம் பின்ன அளவீட்டைப் பயன்படுத்தலாம்:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

நீங்கள் 1080p அல்லது 1440p திரையைப் பயன்படுத்தினால், பெரும்பாலும் 1x அளவீட்டையே பயன்படுத்த விரும்புவீர்கள், எனவே இதைப் பயன்படுத்தலாம்:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

`GDK_SCALE` இல் செய்யப்படும் மாற்றங்கள், மாற்றத்திற்குப் பிறகு தொடங்கப்படும் பயன்பாடுகளுக்குப் பொருந்தும் (மேலும் GTK முழு எண்களை மட்டுமே ஏற்கும், எனவே அதை உங்கள் மானிட்டர் அளவீட்டிற்கு மிக அருகிலுள்ள முழு எண்ணிலேயே வைத்திருங்கள்). எனவே மாற்றத்திற்குப் பிறகு மிகப் பெரிதாக உள்ள சாளரங்களை நீங்கள் மூடுவதை உறுதிப்படுத்திக் கொள்ளுங்கள் (அல்லது `Ctrl + Alt + Del` மூலம் எல்லா சாளரங்களையும் மூடுங்கள்!).

முக்கிய மானிட்டர் அளவீட்டு விகிதங்கள் (1x, 1.25x, 1.6x, 2x, 3x, 4x) வழியாக, அதிகமாகச் செல்ல `Super + /` ஐயும் குறைவாகச் செல்ல `Super + Alt + /` ஐயும் பயன்படுத்தி விரைவாகப் படிப்படியாக மாறலாம், அல்லது மேல் பட்டியில் உள்ள மானிட்டர் பேனலில் இருந்து ஒன்றைத் தேர்ந்தெடுக்கலாம். இவை நீங்கள் கவனம் செலுத்தியுள்ள மானிட்டரை மட்டுமே மாற்றும், எனவே மடிக்கணினித் திரையும் வெளிப்புறத் திரையும் தங்களுக்கெனத் தனித்தனி அளவீட்டைக் கொண்டிருக்க முடியும். இந்தத் தேர்வு அந்த மானிட்டருக்கான `hl.monitor` விதியாக `~/.config/hypr/monitors.lua` இல் சேமிக்கப்படும், எனவே மறுதொடக்கத்திற்குப் பிறகும் அது நீடிக்கும், மேலும் தனக்கென எந்த விதியும் இல்லாத ஒவ்வொரு மானிட்டருக்கும் அளவீடாகத் தொடரும் `omarchy_monitor_scale` ஐ விட முன்னுரிமை பெறும். `GDK_SCALE` என்பது எல்லாத் திரைகளுக்கும் ஒரே ஒரு மதிப்பு என்பதால், இந்த மாற்றங்கள் அதை மிகக் குறைந்த அளவீடு கொண்ட மானிட்டரில் இருந்து அமைக்கும், எனவே X11 பயன்பாடுகள் மற்றொன்றில் மிகப் பெரிதாக வருவதற்குப் பதிலாக, அடர்த்தியான திரையில் சற்று சிறிதாக வரும்.

### உரையைப் பெரிதாக்குதல் அல்லது சிறிதாக்குதல்

மானிட்டர் அளவீடு எல்லாவற்றின் அளவையும் மாற்றும். நீங்கள் விரும்புவது பெரிய அல்லது சிறிய _உரை_ மட்டுமே என்றால், அதற்கு ஒரே ஒரு கட்டுப்பாடு உள்ளது:

```
omarchy display text size 14
```

அது 9 முதல் 20 வரையிலான பிக்சல் அளவை எடுக்கும், மேலும் Omarchy ஷெல், GTK பயன்பாடுகள் மற்றும் உங்கள் டெர்மினலை ஒன்றாக நகர்த்தும், எனவே முழு டெஸ்க்டாப்பும் விகிதாச்சாரத்தில் இருக்கும். நீங்கள் தற்போது எங்கு இருக்கிறீர்கள் என்பதைப் பார்க்க அதை எந்த ஆர்குமென்டும் இல்லாமல் இயக்குங்கள், மேலும் இயல்புநிலைக்குத் திரும்ப `omarchy display text size reset` ஐ இயக்குங்கள். Foot மட்டுமே பின்தங்கியது: அதன் உள்ளமைவை மீண்டும் ஏற்ற அதற்கு வழி இல்லை, எனவே நீங்கள் புதிய ஒன்றைத் திறக்கும் வரை இயங்கும் டெர்மினல்கள் அவற்றின் பழைய அளவையே வைத்திருக்கும்.

### மடிக்கணினித் திரைகளை நீட்டித்தல் மற்றும் பிரதிபலித்தல்

நீங்கள் உங்கள் மடிக்கணினியுடன் வெளிப்புறத் திரையை இணைக்கும்போது, திரை தானாகவே நீட்டிக்கப்படும். ஆனால் Omarchy மெனுவில் _Trigger > Hardware_ ஐப் பயன்படுத்தி அல்லது `Super + Ctrl + Alt + Delete` மூலம் அதைப் பிரதிபலிப்பதாக மாற்றலாம். அந்த வெளிப்புறத் திரை ஒரு புரொஜெக்டராக இருந்து, வேலை செய்யும்போது எதையாவது காட்ட விரும்பினால் இது குறிப்பாக உதவியாக இருக்கும்.

நீங்கள் நீட்டிக்கும்போது, மடிக்கணினியின் மூடியை மூடுவது உள் திரையைத் தானாகவே அணைத்துவிடும். மூடியைத் திறப்பது அதை மீண்டும் இயக்கும். Omarchy மெனுவில் _Trigger > Hardware_ ஐப் பயன்படுத்தி அல்லது `Super + Ctrl + Delete` மூலம் இதைக் கைமுறையாகவும் கட்டுப்படுத்தலாம்.

### பல திரைகளை ஒழுங்கமைத்தல்

Hyprland பல திரைகளுடன் சிறப்பாகச் செயல்படும். அவற்றை எப்படி அமைப்பது என்பது பற்றி [Hyprland மானிட்டர் ஆவணத்தில்](https://wiki.hypr.land/Configuring/Basics/Monitors/) மேலும் படியுங்கள். Omarchy இல், இவை `hl.monitor` உள்ளீடுகளாக `~/.config/hypr/monitors.lua` இல் செல்லும் — குறிப்பிட்ட மானிட்டரை ஒரு தெளிவுத்திறன், நிலை மற்றும் சுழற்சிக்கு நிலைநிறுத்துவதற்கான கருத்துரைக்கப்பட்ட எடுத்துக்காட்டுகளுடன் இந்தக் கோப்பு வரும்.

ஒவ்வொரு மானிட்டருக்கும் அதற்கென 1 முதல் 10 வரையிலான பணியிடங்கள் உள்ளன, எனவே `Super + 1` என்பது எப்போதும் நீங்கள் இருக்கும் மானிட்டரின் முதல் பணியிடத்தையே குறிக்கும். திரைக்குப் பின்னால், Hyprland இன்னும் எல்லா மானிட்டர்களிலும் பணியிடங்களை எண்ணிடும்: உங்கள் மடிக்கணினித் திரைக்கு (அல்லது முதல் மானிட்டருக்கு) 1–10 கிடைக்கும், அடுத்த மானிட்டருக்கு 11–20 கிடைக்கும், இப்படியே தொடரும், மேலும் நீங்கள் அதைச் செருகும் ஒவ்வொரு முறையும் ஒவ்வொரு மானிட்டரும் அதன் தொகுதியை வைத்திருக்கும். குறிப்பிட்ட மானிட்டருக்கான [பணியிட விதிகள்](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) அல்லது சாளர விதிகளை எழுதினால் அந்த எண்களைப் பயன்படுத்துங்கள், எனவே பணியிடம் 12 என்பது உங்கள் இரண்டாவது மானிட்டரின் இரண்டாவது பணியிடம் ஆகும். எந்த மானிட்டருக்கு எந்தத் தொகுதி உள்ளது என்பதை `~/.local/state/omarchy/monitor-workspaces` பட்டியலிடும்.

உங்கள் அமைப்பில் விளிம்பைப் பகிரும் மானிட்டர்களுக்கு இடையே அம்புக்குறி விசைகள் செயல்படும். மூலையில் மட்டுமே தொடும் திரைகள், அல்லது அவற்றுக்கு இடையே இடைவெளி உள்ள திரைகள், அண்டைத் திரைகள் அல்ல, எனவே அவற்றுக்கு இடையே செல்ல `Ctrl + Alt + Tab` ஐப் பயன்படுத்துங்கள்.

| விசைப்பலகை குறுக்குவழி | மானிட்டர்களுக்கு இடையே |
| --- | --- |
| `Super + Arrow` | அந்தத் திசையில் இனி சாளரம் எதுவும் இல்லை என்றானதும், அந்தப் பக்கத்தில் உள்ள மானிட்டருக்கு கவனத்தை நகர்த்தும் |
| `Super + Shift + Arrow` | அந்தப் பக்கத்தில் உள்ள மானிட்டரில் உள்ள ஒரு சாளரத்துடன் மாற்றிக்கொள்ளும் |
| `Super + Alt + Arrow` | அந்தப் பக்கத்தில் உள்ள மானிட்டரில் உள்ள ஒரு குழுவிற்குள் சாளரத்தை நகர்த்தும் |
| `Super + Shift + Ctrl + Arrow` | அந்தப் பக்கத்தில் உள்ள மானிட்டருக்கு, அது காட்டும் பணியிடத்திற்கு, சாளரத்தை நகர்த்தும் |
| `Super + Shift + Alt + Arrow` | அந்தப் பக்கத்தில் உள்ள மானிட்டருக்குப் பணியிடத்தை நகர்த்தும், அது காலியாக இருந்தால் அதன் எண்ணை வைத்திருக்கும் |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | அமைப்பு எப்படி இருந்தாலும், அடுத்த அல்லது முந்தைய மானிட்டருக்கு கவனத்தை நகர்த்தும் |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | நீங்கள் இருக்கும் மானிட்டரிலேயே இருக்கும் |

பல திரைகளை நிலைநிறுத்த உதவும் TUI வேண்டுமென்றால், [Hyprmon](https://github.com/erans/hyprmon/) ஐயும் பாருங்கள்.

### பிரகாசத்தைக் கட்டுப்படுத்துதல்

மானிட்டர் பிரகாசம், பிரகாசத்தை அதிகரிக்க/குறைக்க அர்ப்பணிக்கப்பட்ட செயல்பாட்டு விசைகளால் கட்டுப்படுத்தப்படும். இவற்றை அழுத்தும்போது shift ஐ அழுத்திப் பிடித்தால், நீங்கள் அதிகபட்ச அல்லது குறைந்தபட்ச பிரகாசத்திற்குச் செல்வீர்கள். இந்த விசைகள் நீங்கள் கவனம் செலுத்தியுள்ள திரையைக் கட்டுப்படுத்தும், எனவே DDC/CI பேசும் வெளிப்புற மானிட்டர்கள் மடிக்கணினித் திரையைப் போலவே சரிசெய்யப்படும்.

### Apple திரைகள்

நீங்கள் Apple திரையைப் பயன்படுத்தினால், நீங்கள் Apple திரையில் கவனம் செலுத்தியிருந்தால், வழக்கமான விசைப்பலகை பிரகாச விசைகளும் தானாகவே செயல்படும். இது `asdcontrol` கட்டளை மூலம் செய்யப்படும்.

நீங்கள் Apple 6K XDR திரையைப் பயன்படுத்தினால், உங்கள் `hyprctl monitors` பட்டியலில் ஒரு மாயத் திரையைக் காணலாம் என்பதை நினைவில் கொள்ளுங்கள். _Setup > Monitors_ வழியாக `hl.monitor({ output = "DP-2", disabled = true })` போன்ற ஒன்றைக் கொண்டு இதை அணைக்கலாம்.

Intel கணினிகளில், வழக்கமான Thunderbolt கேபிளைப் பயன்படுத்தி Apple திரைகளுடன் இணைக்க வேண்டும். Thunderbolt இல்லாத பிற கணினிகளில், இது செயல்பட, பொதுவாக நீங்கள் [DP + USB-A -> USB-C கேபிள்](https://www.amazon.com/dp/B0BNX7MS6N) ஐப் பயன்படுத்த வேண்டியிருக்கும்.
