# மேல் பட்டை

உங்கள் திரையின் மேலே உள்ள பட்டைதான் Omarchy பட்டை. அது மேலே ஒட்டவைக்கப்பட்ட நிலைப் பட்டை அல்ல, ஆனால் Omarchy shell-இன் ஒரு பகுதி, மெனு, அறிவிப்புகள், OSD பாப்அப்கள் மற்றும் பூட்டுத் திரையையும் வரையும் ஒரே நீண்ட நேரம் இயங்கும் Quickshell செயல்முறை. அதனால்தான் அது மற்ற எல்லாவற்றுடனும் மிகச் சரியாகத் தீம் ஆகிறது, மேலும் ஒரு பேனல் புதிய ஆப்பைத் தொடங்குவதற்குப் பதிலாக உடனடியாகத் திறக்கிறது.

அது எப்போதும் திரையில் இருக்கும் ஒரே டெஸ்க்டாப் பகுதியும் கூட, எனவே அந்தச் சிறிய குறியீடுகள் அனைத்தும் என்ன செய்கின்றன என்பதை அறிந்து கொள்வது மதிப்புக்குரியது.

## இயல்பாக அதில் என்ன இருக்கும்

பட்டையில் மூன்று பிரிவுகள் உள்ளன. இடதுபுறம் Omarchy லோகோ (மெனு லாஞ்சர்) மற்றும் பணியிடக் குறிகாட்டிகள் அமர்ந்திருக்கின்றன. நடுவில் நிலைக் குறிகாட்டிகள், கடிகாரம், Elsewhen (ஒரு உலக கடிகாரம்), வானிலை மற்றும் Omarchy புதுப்பிப்பு பேட்ஜ் கிடைக்கும். வலதுபுறம்: சிஸ்டம் ட்ரே, விசைப்பலகை தளவமைப்பு (ஒன்றுக்கு மேற்பட்ட தளவமைப்பு அல்லது உள்ளீட்டு முறை கட்டமைக்கப்பட்டிருக்கும்போது), ஏஜெண்டுகள், Bluetooth, நெட்வொர்க், ஆடியோ, டிஸ்ப்ளே மற்றும் பவர்.

அவற்றில் சில சொல்வதற்கு ஏதாவது இருக்கும்போது மட்டுமே தோன்றும். நீங்கள் ஒன்றுக்கு மேற்பட்ட தளவமைப்பு அல்லது உள்ளீட்டு முறையைக் கட்டமைத்திருந்தால் மட்டுமே விசைப்பலகை தளவமைப்பு தோன்றும். Omarchy புதுப்பிப்பு காத்திருக்கும்போது மட்டுமே புதுப்பிப்பு பேட்ஜ் தோன்றும்.

## சுற்றி கிளிக் செய்தல்

கிட்டத்தட்ட ஒவ்வொரு விட்ஜெட்டும் இடது, வலது மற்றும் நடு கிளிக்கில் ஏதாவது செய்யும், மேலும் பல உருட்டலுக்கும் பதிலளிக்கும். இதுதான் மக்கள் தவறவிடும் பகுதி — வலது மற்றும் நடு பொத்தான்களில்தான் நல்ல விஷயங்கள் நிறைய ஒளிந்திருக்கின்றன.

## பேனல்கள்

பட்டை ஐகானைக் கிளிக் செய்வது ஒரு பேனலைத் திறக்கும், அது ஒரு கருவிக்குறிப்புக்குப் பதிலாக ஸ்லைடர்கள், பட்டியல்கள் மற்றும் விசைப்பலகை வழிசெலுத்தலுடன் கூடிய முறையான பாப்அப். ஒவ்வொன்றுக்கும் ஒரு ஹாட்கீயும் உள்ளது, எனவே நீங்கள் ஒருபோதும் 16-பிக்சல் குறியீட்டைக் குறிவைக்க வேண்டியதில்லை:

| Hotkey | பேனல் |
| --- | --- |
| `Super + Ctrl + A` | ஆடியோ |
| `Super + Ctrl + N` | நெட்வொர்க் |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | டிஸ்ப்ளே |
| `Super + Ctrl + P` | பவர் |
| `Super + Ctrl + Alt + D` | காலண்டர் |
| `Super + Ctrl + Alt + E` | உலக கடிகாரம் |
| `Super + Ctrl + X` | ஏஜெண்டுகள் |
| `Super + Ctrl + 1-9` | வலது பிரிவில் n-வது பேனலை மாற்று |

பேனல்கள் வெறும் படிப்புகள் அல்ல. நீங்கள் உண்மையிலேயே வேலையைச் செய்யும் இடம் அவைதான்:

- **Audio**-இல் ஒரு முதன்மை ஒலியளவு ஸ்லைடர், ஒரு வெளியீட்டு-சாதனத் தேர்வி மற்றும் ஆப் வாரியான மிக்சர் உள்ளது, எனவே மற்ற எல்லாவற்றையும் தொடாமல் அந்த ஒரு பிரவுசர் டேபை மட்டும் குறைக்கலாம்.
- **Network** Wi-Fi-ஐ ஸ்கேன் செய்கிறது, சிக்னல் வலிமையைக் காட்டுகிறது, இணைக்கிறது, மேலும் ஒரு DNS வழங்குநரைத் தேர்ந்தெடுக்க உங்களை அனுமதிக்கிறது.
- **Bluetooth** உங்கள் சாதனங்களை இணைப்பு/துண்டிப்பு மற்றும் பேட்டரி நிலைகளுடன் பட்டியலிடுகிறது.
- **Power** பேட்டரி புள்ளிவிவரங்களைக் காட்டுகிறது, பவர் சுயவிவரங்களை மாற்றுகிறது (பேட்டரி மற்றும் AC-க்கு தனித்தனி தேர்வை அது நினைவில் வைத்திருக்கும்), மேலும் சில சிஸ்டம் தகவல்களை அச்சிடுகிறது.
- **Display**-இல் பிரகாச ஸ்லைடர், உரை அளவு, மானிட்டர் அளவிடல் முன்னமைவுகள் மற்றும் — உங்களிடம் ஒன்றுக்கு மேற்பட்ட திரை இருக்கும்போது — மானிட்டர் வாரியான கட்டுப்பாடுகள் உள்ளன. ஆழமான கதைக்கு [மானிட்டர்கள்](33-monitors.md) பார்க்கவும்.
- **Clock** ISO வார எண்கள் மற்றும் மாத நகர்வுடன் ஒரு மாதக் கட்டத்தைத் திறக்கிறது.
- **World clock** ஒவ்வொரு நகரத்திற்கும் ஒரு வரிசையை வைத்திருக்கிறது, அதன் வானிலை மற்றும் அதன் நாள் எப்படி போகிறது என்பதுடன். தேடல் நேர மண்டலங்களைப் போலவே நகரங்களையும் கண்டுபிடிக்கிறது, எனவே Fort Lauderdale என்பது Fort Lauderdale தான், New York அல்ல. மேலே உள்ள வரி தவறான நகரத்தைக் குறிப்பிட்டால், அதைக் கிளிக் செய்து நீங்கள் எங்கே இருக்கிறீர்கள் என்று சொல்லுங்கள்; வேறொரு நேர மண்டலத்தில் உள்ள இடத்தைத் தேர்ந்தெடுங்கள், சிஸ்டம் கடிகாரமும் அங்கே நகரும், நீங்கள் பயணம் செய்யும்போது அது கைக்கு வரும். ஒரு நகரத்தின் மேல் நகர்த்தி நபர் பொத்தானைக் கிளிக் செய்து அங்கே யார் வசிக்கிறார்கள் என்று சொல்லுங்கள் — வெறும் பெயர்கள், அல்லது அவர்களின் முகங்களையும் கொண்டுவர `@` GitHub கைப்பிடிகள்.

ஒவ்வொரு பேனலும் மவுஸைப் போலவே விசைப்பலகையையும் ஏற்கிறது: அம்புகள் நகரும், Return செயல்படுத்தும், Tab அருகிலுள்ள பேனலுக்கு நகரும், Escape மூடும்.

`Super + Ctrl + 1-9` வலது பிரிவில் பேனல்களை இடமிருந்து வலமாக எண்ணுகிறது, ட்ரேக்கு சொந்தமாக பேனல் இல்லாததால் அதைத் தவிர்க்கிறது. எனவே எண் நீங்கள் சுட்டிக்காட்டும் ஐகானுடன் பொருந்துகிறது.

### Tailscale மற்றும் Dropbox

**Install → Service**-இலிருந்து பொருந்தும் சேவையை நிறுவிய பிறகு மட்டுமே மேலும் இரண்டு விட்ஜெட்கள் பட்டையில் தோன்றும், மேலும் இரண்டையும் பற்றி தெரிந்து கொள்வது மதிப்புக்குரியது, ஏனெனில் அவை நிலையைத் தெரிவிப்பதை விட அதிகம் செய்கின்றன.

**Tailscale** பேனல் tailnet-ஐ இணைக்கிறது மற்றும் துண்டிக்கிறது, கணக்குகளுக்கு இடையில் மாறுகிறது, மேலும் ஒரு வெளியேறும் முனையைத் தேர்ந்தெடுக்கிறது (உங்கள் சொந்த இயந்திரங்கள் மற்றும் Mullvad பகுதிகள் இரண்டும் அந்தப் பட்டியலில் தோன்றும்). அது உங்கள் இயந்திரங்களையும் உலாவுகிறது — மேலும் ஒன்றைத் தேர்ந்தெடுத்தவுடன், `s` Taildrop வழியாக அதற்குக் கோப்புகளை அனுப்புகிறது, இது உங்கள் ஃபோனுக்கோ மற்றொரு லேப்டாப்புக்கோ கோப்பை நகர்த்துவதற்கான வேகமான வழி. `c` இயந்திரத்தின் IP-ஐ நகலெடுக்கிறது, `n` அதன் பெயரை, மற்றும் `d` அதன் முழு DNS பெயரை. நீங்கள் கிளிக் செய்ய விரும்பினால், ஒவ்வொரு இயந்திர வரிசையிலும் ஒரு அனுப்பு பொத்தானும் உள்ளது. டெர்மினலில் இருந்து அதே விஷயம் `omarchy tailscale send <machine> [file...]`.

**Dropbox** பேனல் உள்நுழைவைக் கையாளுகிறது, நீங்கள் எவ்வளவு சேமிப்பகத்தைப் பயன்படுத்தியுள்ளீர்கள் என்பதைக் காட்டுகிறது, மேலும் சமீபத்தில் ஒத்திசைக்கப்பட்ட கோப்புகளைப் பட்டியலிடுகிறது.

எந்தச் சேவையையும் நீக்குவது அதன் விட்ஜெட்டைப் பட்டையிலிருந்து மீண்டும் எடுத்துவிடும்.

## குறிகாட்டிகள்

நடுவில் உள்ள சிறிய கொத்துதான் குறிகாட்டிகள் விட்ஜெட். இவை நீங்கள் இயக்கிய பயன்முறைகளுக்கான நிலைக் குறியீடுகள்: தொந்தரவு செய்யாதே, இரவு ஒளி, வரிசையில் உள்ள [நினைவூட்டல்](09-reminders.md), செயலில் உள்ள திரைப் பதிவு மற்றும் விழித்திரு, மேலும் கடவுச்சொல் இல்லாத sudo இயக்கத்தில் இருக்கும்போது அல்லது யாராவது தொலைநிலை அமர்வுடன் இணைந்திருக்கும்போது எச்சரிக்கைகள். பயன்முறை செயலில் இருக்கும்போது அவை ஒளிர்கின்றன, இல்லையெனில் வழியில் இல்லாமல் இருக்கின்றன — செயலற்றவை அமரும் இடத்தில், அவற்றுக்கு அருகில் நகர்த்தி அவற்றை எட்டிப் பாருங்கள். ஒரு குறிகாட்டியைக் கிளிக் செய்வது அந்தப் பயன்முறையை மாற்றும். இன்னொன்று நிலை மட்டுமே: gliff வழியாக யாராவது இந்த இயந்திரத்துடன் இணைந்திருக்கும்போது தொலைநிலை அமர்வு சிவப்பாக ஒளிரும்.

அவை எப்போதும் தெரிய வேண்டும் என்று நீங்கள் விரும்பினால், விட்ஜெட்டில் `alwaysShow`-ஐ `true` என அமைக்கவும். மேலும் அவற்றில் சிலவற்றை மட்டுமே நீங்கள் கவனித்தால், நீங்கள் விரும்புபவற்றை `items`-இல் பட்டியலிடுங்கள்: `["Dnd", "Reminder", "NightLight"]`. உங்களிடம் ஒன்றுக்கு மேற்பட்ட குறிகாட்டிகள் விட்ஜெட் இருக்கலாம், எனவே வெவ்வேறு பிரிவுகள் வெவ்வேறு துணைக்குழுக்களைக் காட்டலாம்.

## பட்டையை மறுசீரமைத்தல்

பட்டை தன்னைத்தானே கட்டமைத்துக் கொள்கிறது. விஷயங்களை நகர்த்த நீங்கள் ஒரு கட்டமைப்புக் கோப்பைத் திறக்க வேண்டியதில்லை.

பட்டையின் நடுப்பகுதியைச் சுற்றியுள்ள ஒரு வெற்று இடத்தைப் பிடித்து மற்றொரு திரை விளிம்பை நோக்கி இழுக்கவும், பட்டை அங்கே நகரும் — இடது, வலது, மேல் அல்லது கீழ் அனைத்தும் வேலை செய்யும், மேலும் ஒவ்வொரு விட்ஜெட்டும் தகவமைத்துக் கொள்ளும் (செங்குத்துப் பட்டைகள் சிறிய ஐகான்-மட்டும் வடிவங்களுக்குத் திரும்பும்). கிளிக்-செய்து-பிடிப்பது அதே இழுவையைத் தொடங்கும். அதே வெற்று இடத்தை இரட்டை-இடது-கிளிக் செய்து பட்டையின் பின்னணியை தெளிவானதிலிருந்து கண்ணாடி போன்றதிலிருந்து ஒளிபுகாதது வரை சுழற்சியாக மாற்றுங்கள். மேலும் எந்த விட்ஜெட்டையும் இழுத்து அதை மறுவரிசைப்படுத்துங்கள் அல்லது வேறொரு பிரிவுக்குள் எறியுங்கள்; அது எங்கே விழும் என்பதற்கு இடம் ஒதுக்க மற்ற விட்ஜெட்கள் விலகி நகரும்.

பட்டையின் நடுப்பகுதி ஒரு பெட்டி: அதில் உள்ள எதுவும் ஒரே குழுவாக மையத்தில் இருக்கும், மேலும் அதன் இருபுறமும் உள்ள விட்ஜெட்கள் அதன் விளிம்புகளில் தொங்கும். நீங்கள் ஒரு விட்ஜெட்டை இழுக்கும்போது பெட்டி ஒரு வெளிக்கோடாகக் காட்டப்படும், அல்லது அது காலியாக இருக்கும்போது பட்டையின் குறுக்கே ஒரு கோடாகக் காட்டப்படும், மேலும் நீங்கள் அதற்குள் அல்லது அதற்கு அருகில் விடலாம். ஒரு விடுதல் பெட்டியில் விழும்போது, பெட்டி விட்ஜெட்டை உள்ளே எடுக்க வளரும்.

உங்களைச் சுற்றி இருக்க வேண்டும் ஆனால் எப்போதும் பார்வையில் இருக்க வேண்டாம் என்று நீங்கள் விரும்பும் விட்ஜெட் ட்ரேயின் டிராயருக்குள் செல்லலாம்: அதை ட்ரே மீது இழுக்கவும், டிராயர் அதை எடுக்கத் திறக்கும். அது ஆப் ஐகான்களுக்குப் பிறகு அங்கே அமரும், டிராயர் வரும்போதெல்லாம் தோன்றும், மேலும் அதன் பேனல் மேலே இருக்கும்போது அதன் டிராயரைத் திறந்தே வைத்திருக்கும். அதை மீண்டும் பட்டையில் வைக்க அதை வெளியே இழுக்கவும்.

நீங்கள் ஒரு மெனுவிலிருந்து தேர்ந்தெடுக்க விரும்பினால், **Appearance → Menu Bar**-இல் நிலை உள்ளது, மேலும் **Bar Background** பட்டை எப்படி வரையப்படுகிறது என்பதைத் தேர்ந்தெடுக்கிறது: **Opaque Bar**, **Glassy Bar** (ஊடுருவக்கூடியது, அதன் பின்னால் உள்ளது மங்கலாக்கப்பட்டது), அல்லது **Clear Bar**.

அதே விஷயங்களுக்கு கட்டளைகள் உள்ளன, இது ஒரு [dotfiles](31-dotfiles.md) அமைப்புக்கு நீங்கள் விரும்புவது:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

ஒரு விட்ஜெட்டை முழுவதுமாகச் சேர்க்க அல்லது நீக்க, ப்ளகின் கட்டளைகளைப் பயன்படுத்தவும். `omarchy plugin list` shell அறிந்த ஒவ்வொரு விட்ஜெட்டையும் அதன் id-உடன் அச்சிடுகிறது, பின்னர்:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## பட்டையை மறைத்தல்

`Super + Shift + Space` shell-ஐக் கொல்லாமல் பட்டையை அணைத்து மீண்டும் இயக்கும் — பேனல்கள் மற்றும் ஹாட்கீகள் தொடர்ந்து வேலை செய்யும், உங்களுக்கு பிக்சல்கள் மட்டும் திரும்பக் கிடைக்கும். அது மெனுவிலும் **Appearance → Menu Bar → Hide Bar**-இன் கீழ் உள்ளது.

## கட்டமைப்புக் கோப்பு

அனைத்தும் `~/.config/omarchy/shell.json`-இல், `bar` விசையின் கீழ் சேமிக்கப்படுகிறது. இதோ ஒரு சுருக்கப்பட்ட பதிப்பு:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

ஒவ்வொரு விட்ஜெட்டும் ஐந்து தளவமைப்பு வரிசைகளில் ஒன்றில் ஒரு உள்ளீடு, மேலும் அதன் அமைப்புகள் அந்த உள்ளீட்டிலேயே உள்ளன — தனி அமைப்புகள் கோப்பு இல்லை மற்றும் `config` துணை-பொருள் இல்லை. கடிகாரத்தின் `format`, `formatAlt` (வலது கிளிக் எதற்கு சுழற்சியாக மாறும்) மற்றும் `verticalFormat` அனைத்தும் `{ "id": "omarchy.clock" }`-இல் அங்கேயே வசிக்கின்றன.

`center` என்பது பட்டையின் நடுவில் உள்ள பெட்டி: அதில் உள்ள அனைத்தும் திரையில் ஒரே குழுவாக மையப்படுத்தப்படுகின்றன. `centerBegin` மற்றும் `centerEnd` பெட்டியின் இருபுறமும் தொங்குகின்றன, இப்படித்தான் வானிலை மற்றும் புதுப்பிப்பு பேட்ஜ் வந்து போகும்போதும் கடிகாரம் சரியாக நடுவில் இருக்கிறது. `center`-இல் ஒன்றுக்கு மேற்பட்ட விட்ஜெட்டை வைக்கவும், அவை ஒன்றாக மையப்படுத்தப்படும்; அதைக் காலியாக விடவும், `centerBegin` மற்றும் `centerEnd` பட்டையின் நடுவில் சந்திக்கும்.

உள்வாங்கிக் கொள்ள வேண்டிய ஒரு விதி: **உங்களிடம் சொந்த `shell.json` இருந்தவுடன், அதுதான் நியமனமானது**. நீங்கள் எதையும் தனிப்பயனாக்கும் வரை, shell Omarchy-யின் இயல்புநிலைக் கோப்பைப் படிக்கிறது. நீங்கள் ஒரு விட்ஜெட்டை இழுத்தவுடன், `omarchy bar`-ஐ இயக்கியவுடன், அல்லது கோப்பை நீங்களே திருத்தியவுடன், நீங்கள்தான் அதன் உரிமையாளர் — ஆழமான இணைப்பு இல்லை, எனவே எதிர்கால Omarchy வெளியீடுகளில் புதிய இயல்புநிலை விட்ஜெட்கள் உங்கள் பட்டையில் தானாகத் தோன்றாது. நீங்கள் ஒரு சுத்தமான தொடக்கத்தை விரும்பும்போதெல்லாம் `omarchy bar defaults` வழங்கப்பட்ட தளவமைப்பை மீண்டும் வைக்கிறது.

அதே கோப்பு உங்கள் செயலற்ற நேரங்களையும் மேல் நிலையில், `bar` விசைக்கு வெளியே வைத்திருக்கிறது: `idle.screensaver` மற்றும் `idle.lock`, இரண்டும் நீங்கள் செயலற்றுப் போனதிலிருந்து வினாடிகளில். எனவே இயல்புநிலை ஸ்கிரீன்சேவர் 150 வினாடிகளில் தொடங்கும், பூட்டு 300-இல்.
