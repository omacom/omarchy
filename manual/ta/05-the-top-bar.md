# மேல் பட்டை

உங்கள் திரையின் மேல் பகுதியில் உள்ள பட்டை Omarchy பட்டை. இது பொருத்தப்பட்ட நிலைப் பட்டை அல்ல, ஆனால் Omarchy ஷெல்லின் ஒரு பகுதி, மெனு, அறிவிப்புகள், OSD பாப்அப்கள், மற்றும் பூட்டுத் திரையை வரையும் ஒற்றை நீண்ட-இயங்கும் Quickshell செயல்முறை. அதனால்தான் அது மற்ற அனைத்துடனும் சரியாக தீம் ஆகிறது மற்றும் ஒரு புதிய செயலியை உருவாக்குவதற்கு பதிலாக ஒரு பேனல் உடனடியாகத் திறக்கிறது.

அது எப்போதும் திரையில் இருக்கும் டெஸ்க்டாப்பின் ஒரே பகுதியும் கூட, எனவே அந்த சிறிய கிளிஃப்கள் அனைத்தும் என்ன செய்கின்றன என்பதை அறிவது மதிப்பு.

## இயல்பாக அதில் என்ன இருக்கிறது

பட்டையில் மூன்று பிரிவுகள் உள்ளன. இடதுபுறத்தில் Omarchy லோகோ (மெனு தொடக்கி) மற்றும் பணியிட குறிகாட்டிகள் உள்ளன. மையத்தில் நிலை குறிகாட்டிகள், கடிகாரம், Elsewhen (ஒரு உலக கடிகாரம்), வானிலை, மற்றும் ஒரு Omarchy புதுப்பிப்பு பேட்ஜ் ஆகியவற்றைப் பெறுகிறீர்கள். வலதுபுறத்தில்: விசைப்பலகை தளவமைப்பு (ஒன்றுக்கு மேற்பட்டவை கட்டமைக்கப்படும் போது), அமைப்பு தட்டு, Agent-கள், bluetooth, வலையமைப்பு, ஒலி, காட்சி, மற்றும் மின்சக்தி.

அவற்றில் சில சொல்ல ஏதாவது இருக்கும் போது மட்டுமே தோன்றும். நீங்கள் ஒன்றுக்கு மேற்பட்ட தளவமைப்பைக் கட்டமைத்திருந்தால் மட்டுமே விசைப்பலகை தளவமைப்பு தோன்றும். ஒரு Omarchy புதுப்பிப்பு காத்திருக்கும் போது மட்டுமே புதுப்பிப்பு பேட்ஜ் தோன்றும். மேலும் Omarchy இயந்திரத்தில் AI குறியீட்டு பயன்பாட்டை முதல் முறையாகக் கண்டறியும் போது Agent-கள் ஐகான் தோன்றும் ([AI](17-ai.md) பார்க்கவும்).

## சுற்றி கிளிக் செய்தல்

கிட்டத்தட்ட ஒவ்வொரு விட்ஜெட்டும் இடது, வலது, மற்றும் நடு கிளிக்கில் ஏதாவது செய்கிறது, மேலும் பல உருட்டலுக்கும் பதிலளிக்கின்றன. இது மக்கள் தவறவிடும் பகுதி — வலது மற்றும் நடு பொத்தான்கள் தான் நிறைய நல்ல விஷயங்கள் மறைந்திருக்கும் இடம்.

| விட்ஜெட் | இடது | வலது | நடு / உருட்டு |
| --- | --- | --- | --- |

| கடிகாரம் | நாள்காட்டி பாப்அப் | லேபிள் வடிவத்தைச் சுழற்று | நடு: நேர மண்டல தேர்வாளர் |

அந்த அட்டவணையில் உள்ள அனைத்தும் பெட்டியிலிருந்து வெளியே உங்கள் பட்டையில் இல்லை. மீடியா விட்ஜெட் (MPRIS இப்போது-இயங்குகிறது, ஒரு உருட்டல் டிராக் மற்றும் கலைஞருடன்) மற்றும் மைக்ரோஃபோன் விட்ஜெட் இரண்டும் உள்ளமைக்கப்பட்டவை ஆனால் இயல்பாகவே ஆஃப் — கீழே விவரிக்கப்பட்டுள்ளபடி, நீங்கள் விரும்பினால் அவற்றைச் சேர்க்கவும்.

## பேனல்கள்

ஒரு பட்டை ஐகானைக் கிளிக் செய்வது ஒரு பேனலைத் திறக்கிறது, இது ஒரு கருவிப்பட்டிக்கு பதிலாக ஸ்லைடர்கள், பட்டியல்கள், மற்றும் விசைப்பலகை வழிசெலுத்தலுடன் கூடிய ஒரு சரியான பாப்அப். ஒவ்வொன்றிற்கும் ஒரு ஹாட்கீயும் உள்ளது, எனவே நீங்கள் ஒருபோதும் 16-பிக்சல் கிளிஃபை குறிவைக்க வேண்டியதில்லை:

| ஹாட்கீ | பேனல் |
| --- | --- |
| `Super + Ctrl + A` | ஒலி |
| `Super + Ctrl + W` | வலையமைப்பு |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | காட்சி |
| `Super + Ctrl + P` | மின்சக்தி |
| `Super + Ctrl + Alt + D` | நாள்காட்டி |
| `Super + Ctrl + Alt + E` | உலக கடிகாரம் |
| `Super + Ctrl + 1-9` | வலது பிரிவில் n-வது பேனலை மாற்று |

பேனல்கள் படிப்புகள் அல்ல. அவைதான் நீங்கள் உண்மையில் அந்த விஷயத்தைச் செய்யும் இடம்:

- **ஒலி** ஒரு முதன்மை ஒலியளவு ஸ்லைடர், ஒரு வெளியீட்டு-சாதன தேர்வாளர், மற்றும் ஒரு செயலி-வாரியான மிக்சர் ஆகியவற்றைக் கொண்டுள்ளது, எனவே மற்ற அனைத்தையும் தொடாமல் அந்த ஒரு உலாவி தாவலைக் குறைக்கலாம்.
- **வலையமைப்பு** Wi-Fi க்காக ஸ்கேன் செய்கிறது, சிக்னல் வலிமையைக் காட்டுகிறது, இணைக்கிறது, மேலும் ஒரு DNS வழங்குநரைத் தேர்ந்தெடுக்க உங்களை அனுமதிக்கிறது.
- **Bluetooth** இணைப்பு/துண்டிப்பு மற்றும் மின்கல நிலைகளுடன் உங்கள் சாதனங்களைப் பட்டியலிடுகிறது.
- **மின்சக்தி** மின்கல புள்ளிவிவரங்களைக் காட்டுகிறது, மின்சக்தி சுயவிவரங்களை மாற்றுகிறது (இது மின்கலம் மற்றும் AC க்கு தனி தேர்வை நினைவில் வைத்திருக்கிறது), மற்றும் சில அமைப்பு தகவல்களை அச்சிடுகிறது.
- **காட்சி** ஒரு பிரகாச ஸ்லைடர், உரை அளவு, திரை அளவிடல் முன்னமைவுகள், மற்றும் — உங்களிடம் ஒன்றுக்கு மேற்பட்ட திரை இருக்கும் போது — திரை-வாரியான கட்டுப்பாடுகளைக் கொண்டுள்ளது. ஆழமான கதைக்கு [திரைகள்](33-monitors.md) பார்க்கவும்.
- **கடிகாரம்** ISO வார எண்கள் மற்றும் மாத படிநிலையுடன் ஒரு மாத கட்டத்தைத் திறக்கிறது.

ஒவ்வொரு பேனலும் சுட்டியுடன் விசைப்பலகையையும் எடுக்கிறது: அம்புகள் நகர்கின்றன, Return செயல்படுத்துகிறது, Tab அண்டை பேனலுக்குச் செல்கிறது, மற்றும் Escape மூடுகிறது.

`Super + Ctrl + 1-9` வலது பிரிவில் இடமிருந்து வலமாக பேனல்களைக் கணக்கிடுகிறது, தட்டைத் தவிர்க்கிறது, ஏனெனில் அதற்கு சொந்த பேனல் இல்லை. எனவே எண் நீங்கள் சுட்டிக்காட்டும் ஐகானுடன் பொருந்துகிறது.

### Tailscale மற்றும் Dropbox

**நிறுவு → சேவை** யிலிருந்து பொருந்தும் சேவையை நிறுவியவுடன் மட்டுமே இன்னும் இரண்டு விட்ஜெட்டுகள் பட்டையில் தோன்றும், மேலும் இரண்டும் அறிந்து கொள்ளத் தகுந்தவை, ஏனெனில் அவை நிலையைப் புகாரளிப்பதை விட அதிகம் செய்கின்றன.

**Tailscale** பேனல் tailnet-ஐ இணைக்கிறது மற்றும் துண்டிக்கிறது, கணக்குகளுக்கு இடையே மாறுகிறது, மற்றும் ஒரு வெளியேறும் முனையைத் தேர்ந்தெடுக்கிறது (உங்கள் சொந்த இயந்திரங்கள் மற்றும் Mullvad பகுதிகள் இரண்டும் அந்தப் பட்டியலில் தோன்றும்). இது உங்கள் இயந்திரங்களையும் உலாவுகிறது — மேலும் ஒன்று தேர்ந்தெடுக்கப்பட்டால், `s` Taildrop மூலம் அதற்கு கோப்புகளை அனுப்புகிறது, இது உங்கள் தொலைபேசி அல்லது வேறொரு மடிக்கணினிக்கு ஒரு கோப்பை நகர்த்த வேகமான வழி. `c` இயந்திரத்தின் IP-ஐ நகலெடுக்கிறது, `n` அதன் பெயரை, மற்றும் `d` அதன் முழு DNS பெயரை. நீங்கள் கிளிக் செய்ய விரும்பினால், ஒவ்வொரு இயந்திர வரிசையிலும் ஒரு அனுப்பு பொத்தானும் உள்ளது. டெர்மினலிலிருந்து அதே விஷயம் `omarchy tailscale send <machine> [file...]` ஆகும்.

**Dropbox** பேனல் உள்நுழைவைக் கையாளுகிறது, நீங்கள் எவ்வளவு சேமிப்பகத்தைப் பயன்படுத்தியுள்ளீர்கள் என்பதைக் காட்டுகிறது, மற்றும் சமீபத்தில் ஒத்திசைக்கப்பட்ட கோப்புகளைப் பட்டியலிடுகிறது.

எந்த சேவையையும் நீக்குவது அதன் விட்ஜெட்டை பட்டையிலிருந்து திரும்ப எடுக்கிறது.

## குறிகாட்டிகள்

மையத்தில் உள்ள சிறிய கொத்து குறிகாட்டிகள் விட்ஜெட். இவை நீங்கள் இயக்கிய பயன்முறைகளுக்கான நிலை கிளிஃப்கள்: தொந்தரவு செய்யாதே, இரவு விளக்கு, வரிசைப்படுத்தப்பட்ட [நினைவூட்டல்](09-reminders.md), ஒரு செயலில் உள்ள திரைப்பதிவு, விழித்திரு, மற்றும் [கட்டளையிடல்](11-text-extraction-dictation.md). பயன்முறை செயலில் இருக்கும் போது அவை ஒளிர்கின்றன, இல்லையெனில் வழியிலிருந்து விலகி இருக்கின்றன — செயலற்றவற்றை எட்டிப் பார்க்க கடிகாரத்தின் இடதுபுறம் (செங்குத்து பட்டையில் அதற்கு மேலே) மிதக்கவும். ஒரு குறிகாட்டியைக் கிளிக் செய்வது அந்த பயன்முறையை மாற்றுகிறது. இன்னொன்று நிலை மட்டுமே: gliff மூலம் யாராவது இந்த இயந்திரத்துடன் இணைக்கப்பட்டிருக்கும் போது ஒரு தொலைநிலை அமர்வு சிவப்பு நிறத்தில் ஒளிர்கிறது.

அவை எப்போதும் தெரிய வேண்டும் என்று நீங்கள் விரும்பினால், விட்ஜெட்டில் `alwaysShow` ஐ `true` ஆக அமைக்கவும். மேலும் அவற்றில் சிலவற்றைப் பற்றி மட்டுமே நீங்கள் கவலைப்படுகிறீர்கள் என்றால், நீங்கள் விரும்புவதை `items` இல் பட்டியலிடவும்: `["Dnd", "Reminder", "NightLight"]`. நீங்கள் ஒன்றுக்கு மேற்பட்ட குறிகாட்டிகள் விட்ஜெட்டை வைத்திருக்கலாம், எனவே வெவ்வேறு பிரிவுகள் வெவ்வேறு துணைத் தொகுப்புகளைக் காட்டலாம்.

## பட்டையை மறுஒழுங்கமைத்தல்

பட்டை தன்னைத்தானே கட்டமைக்கிறது. விஷயங்களை நகர்த்த நீங்கள் ஒரு கட்டமைப்பு கோப்பைத் திறக்க வேண்டியதில்லை.

மையத்தைச் சுற்றி பட்டையின் ஒரு வெற்றுப் பகுதியைப் பிடித்து மற்றொரு திரை விளிம்பை நோக்கி இழுக்கவும், பட்டை அங்கே நகர்கிறது — இடது, வலது, மேல், அல்லது கீழ் அனைத்தும் வேலை செய்கின்றன, மேலும் ஒவ்வொரு விட்ஜெட்டும் தகவமைக்கிறது (செங்குத்து பட்டைகள் சுருக்கமான ஐகான்-மட்டும் வடிவங்களுக்குத் திரும்புகின்றன). ஒரு கிளிக்-மற்றும்-பிடி அதே இழுவையைத் தொடங்குகிறது. பட்டை பின்னணியை தெளிவானதிலிருந்து கண்ணாடி வழியாக ஒளிபுகாதாகச் சுழற்ற அதே வெற்று இடத்தை இரட்டை-இடது-கிளிக் செய்யவும். மேலும் எந்த விட்ஜெட்டையும் மறுஒழுங்கமைக்க அல்லது மற்றொரு பிரிவில் எறிய இழுக்கவும்.

எப்போதும் கண்ணில் படாமல், ஆனால் கையில் வைத்திருக்க விரும்பும் ஒரு விட்ஜெட்டை தட்டின் டிராயரில் வைக்கலாம்: அதை தட்டின் மீது இழுக்கவும், டிராயர் திறந்து அதை ஏற்றுக்கொள்ளும். அது செயலி ஐகான்களுக்குப் பிறகு அங்கேயே இருக்கும், டிராயர் தோன்றும் போதெல்லாம் தோன்றும், மேலும் அதன் பேனல் திறந்திருக்கும் போது அதன் டிராயரைத் திறந்தே வைத்திருக்கும். அதை மீண்டும் பட்டையின் மீது இழுத்து வெளியே கொண்டு வந்து திரும்ப வைக்கவும்.

நீங்கள் ஒரு மெனுவிலிருந்து தேர்ந்தெடுக்க விரும்பினால், **தூண்டு → தோற்றம் → மெனு பட்டை** நிலையைக் கொண்டுள்ளது, மேலும் **பட்டை பின்னணி** பட்டை எப்படி வரையப்படுகிறது என்பதைத் தேர்ந்தெடுக்கிறது: **ஒளிபுகா பட்டை**, **கண்ணாடி பட்டை** (பின்னால் உள்ளது மங்கலாக்கப்பட்டு, ஊடாகப் பார்க்கக்கூடியது), அல்லது **தெளிவான பட்டை**.

அதே விஷயங்களுக்கு கட்டளைகள் உள்ளன, இது ஒரு [dotfiles](31-dotfiles.md) அமைப்பிற்கு நீங்கள் விரும்புவது:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.clock --section center --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

ஒரு விட்ஜெட்டை முழுவதுமாகச் சேர்க்க அல்லது நீக்க, செருகுநிரல் கட்டளைகளைப் பயன்படுத்தவும். `omarchy plugin list` ஷெல் அறிந்த ஒவ்வொரு விட்ஜெட்டையும் அதன் ஐடியுடன் அச்சிடுகிறது, பிறகு:

```bash
omarchy plugin enable omarchy.media --section center
omarchy plugin disable omarchy.weather
```

## பட்டையை மறைத்தல்

`Super + Shift + Space` ஷெல்லைக் கொல்லாமல் பட்டையை ஆஃப் மற்றும் திரும்ப ஆன் செய்கிறது — பேனல்கள் மற்றும் ஹாட்கீகள் தொடர்ந்து வேலை செய்கின்றன, நீங்கள் வெறுமனே பிக்சல்களைத் திரும்பப் பெறுகிறீர்கள். இது மெனுவில் **தூண்டு → தோற்றம் → மெனு பட்டை → பட்டையை மறை** இன் கீழும் உள்ளது.

## கட்டமைப்பு கோப்பு

இவை அனைத்தும் `~/.config/omarchy/shell.json` இல், `bar` விசையின் கீழ் சேமிக்கப்படுகின்றன. இங்கே ஒரு வெட்டப்பட்ட பதிப்பு:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "centerAnchor": "omarchy.clock",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

ஒவ்வொரு விட்ஜெட்டும் மூன்று தளவமைப்பு வரிசைகளில் ஒன்றில் ஒரு பதிவு, மேலும் அதன் அமைப்புகள் அந்த பதிவில் இன்லைனில் உள்ளன — தனி அமைப்புகள் கோப்பு இல்லை மற்றும் `config` துணை-பொருள் இல்லை. கடிகாரத்தின் `format`, `formatAlt` (வலது-கிளிக் எதற்குச் சுழற்றுகிறது), மற்றும் `verticalFormat` அனைத்தும் `{ "id": "omarchy.clock" }` இல் அங்கேயே உள்ளன.

`centerAnchor` திரையின் சரியான மையத்தில் பொருத்தப்படும் ஒரு மைய விட்ஜெட்டைப் பெயரிடுகிறது, மற்றவை அதைச் சூழ்ந்திருக்கும். வானிலை மற்றும் புதுப்பிப்பு பேட்ஜ் வந்து போகும் போதும் கடிகாரம் எப்படி மையத்தில் இருக்கிறது என்பது அதுதான். அதை ஒரு வெற்று சரமாக அமைக்கவும், மையப் பட்டியல் அதற்கு பதிலாக ஒரு குழுவாக மையப்படுத்தப்படும்.

உள்வாங்கத் தகுந்த ஒரு விதி: **உங்களுக்கு சொந்தமாக `shell.json` கிடைத்ததும், அது நியமனமானது**. நீங்கள் எதையும் தனிப்பயனாக்கும் வரை, ஷெல் Omarchy-இன் இயல்புநிலை கோப்பைப் படிக்கிறது. நீங்கள் ஒரு விட்ஜெட்டை இழுக்கும் தருணம், `omarchy bar` ஐ இயக்கவும், அல்லது கோப்பை நீங்களே திருத்தவும், நீங்கள் அதைச் சொந்தமாக்குகிறீர்கள் — ஆழமான ஒன்றிணைப்பு இல்லை, எனவே எதிர்கால Omarchy வெளியீடுகளில் புதிய இயல்புநிலை விட்ஜெட்டுகள் உங்கள் பட்டையில் தானாகவே தோன்றாது. `omarchy bar defaults` நீங்கள் ஒரு சுத்தமான நிலையை விரும்பும் போதெல்லாம் அனுப்பப்பட்ட தளவமைப்பைத் திரும்ப வைக்கிறது.

அதே கோப்பு உங்கள் செயலற்ற நேரங்களையும் `bar` விசைக்கு வெளியே, மேல் நிலையில் வைத்திருக்கிறது: `idle.screensaver` மற்றும் `idle.lock`, இரண்டும் நீங்கள் செயலற்ற நிலைக்குச் சென்றதிலிருந்து வினாடிகளில். எனவே இயல்புநிலை திரைசேமிப்பு 150 வினாடிகளில் தொடங்குகிறது மற்றும் பூட்டு 300 இல் தொடங்குகிறது.
