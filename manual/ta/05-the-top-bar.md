# மேல் பட்டை

உங்கள் திரையின் மேல்புறம் உள்ள பட்டைதான் Omarchy பட்டை. இது பின்னால் பொருத்தப்பட்ட ஒரு status bar அல்ல, மாறாக Omarchy shell இன் ஒரு பகுதி; அந்த ஒற்றை, நீண்ட நேரம் இயங்கும் Quickshell process தான் மெனு, அறிவிப்புகள், OSD popups மற்றும் lock screen ஆகியவற்றையும் வரைகிறது. அதனால்தான் இது மற்ற எல்லாவற்றுடனும் மிகச் சரியாக theme ஆகிறது, மேலும் ஒரு புதிய app ஐத் தொடங்குவதற்குப் பதிலாக ஒரு panel உடனடியாகத் திறக்கிறது.

இது எப்போதும் திரையில் இருக்கும் ஒரே desktop பகுதியும் கூட, எனவே அந்தச் சிறிய glyphs எல்லாம் என்ன செய்கின்றன என்பதை அறிந்து கொள்வது மதிப்புக்குரியது.

## இயல்பாக இதில் என்ன இருக்கும்

பட்டையில் மூன்று பிரிவுகள் உள்ளன. இடதுபுறத்தில் Omarchy logo (மெனு launcher) மற்றும் workspace குறிகாட்டிகள் அமர்ந்திருக்கின்றன. நடுவில் நிலைமைக் குறிகாட்டிகள், கடிகாரம், Elsewhen (ஒரு world clock), வானிலை மற்றும் Omarchy update badge ஆகியவற்றைப் பெறுகிறீர்கள். வலதுபுறத்தில்: system tray, keyboard layout (ஒன்றுக்கு மேற்பட்டவை உள்ளமைக்கப்பட்டிருக்கும்போது), agents, bluetooth, network, audio, display மற்றும் power.

அவற்றில் சில, சொல்வதற்கு ஏதாவது இருக்கும்போது மட்டுமே தோன்றும். நீங்கள் ஒன்றுக்கு மேற்பட்ட layout ஐ உள்ளமைத்திருந்தால் மட்டுமே keyboard layout தோன்றும். Omarchy update ஒன்று காத்திருக்கும்போது மட்டுமே update badge தோன்றும். மேலும் Omarchy முதன்முறையாக அந்தக் கணினியில் AI coding பயன்பாட்டைக் கண்டறியும்போது agents ஐகான் தோன்றும் (பார்க்கவும் [AI](17-ai.md)).

## Panels

ஒரு bar ஐகானைக் கிளிக் செய்தால் ஒரு panel திறக்கும்; அது ஒரு tooltip அல்ல, sliders, பட்டியல்கள் மற்றும் keyboard navigation உடன் கூடிய முறையான ஒரு popup. ஒவ்வொன்றுக்கும் ஒரு hotkey உம் உண்டு, எனவே நீங்கள் ஒருபோதும் 16-pixel glyph ஐக் குறிவைக்க வேண்டியதில்லை:

| Hotkey | Panel |
| --- | --- |
| `Super + Ctrl + A` | Audio |
| `Super + Ctrl + N` | Network |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | Display |
| `Super + Ctrl + P` | Power |
| `Super + Ctrl + Alt + D` | Calendar |
| `Super + Ctrl + Alt + E` | World clock |
| `Super + Ctrl + 1-9` | வலது பிரிவில் உள்ள nth panel ஐ toggle செய்யும் |

Panels வெறும் படித்துக் காட்டுபவை அல்ல. நீங்கள் உண்மையில் அந்த வேலையைச் செய்யும் இடம் அவைதான்:

- **Audio** இல் ஒரு master volume slider, ஒரு output-device picker மற்றும் per-app mixer உள்ளன, எனவே மற்ற எல்லாவற்றையும் தொடாமல் அந்த ஒரு browser tab ஐக் குறைக்கலாம்.
- **Network** Wi-Fi க்காக scan செய்கிறது, signal strength ஐக் காட்டுகிறது, இணைக்கிறது, மேலும் ஒரு DNS provider ஐத் தேர்ந்தெடுக்க உங்களை அனுமதிக்கிறது.
- **Bluetooth** உங்கள் சாதனங்களை connect/disconnect மற்றும் battery அளவுகளுடன் பட்டியலிடுகிறது.
- **Power** battery புள்ளிவிவரங்களைக் காட்டுகிறது, power profiles ஐ மாற்றுகிறது (battery மற்றும் AC க்கான தனித்தனி தேர்வை இது நினைவில் வைத்திருக்கும்), மேலும் சில system தகவல்களை அச்சிடுகிறது.
- **Display** ஒரு brightness slider, text size, monitor scaling presets ஆகியவற்றையும் — உங்களிடம் ஒன்றுக்கு மேற்பட்ட திரை இருக்கும்போது — per-monitor கட்டுப்பாடுகளையும் கொண்டுள்ளது. ஆழமான கதைக்கு [monitors](33-monitors.md) ஐப் பார்க்கவும்.
- **Clock** ISO week எண்கள் மற்றும் மாதம் வாரியாக நகரும் வசதியுடன் ஒரு மாத grid ஐத் திறக்கிறது.
- **World clock** ஒவ்வொரு நகரத்திற்கும் ஒரு வரிசையை வைத்திருக்கிறது, அதன் வானிலை மற்றும் அதன் நாள் எப்படிப் போகிறது என்பதுடன். Search, time zones மட்டுமல்லாமல் நகரங்களையும் கண்டறியும், எனவே Fort Lauderdale என்பது Fort Lauderdale தான், New York அல்ல. மேலே உள்ள வரி தவறான நகரத்தைக் குறிப்பிட்டால், அதைக் கிளிக் செய்து நீங்கள் எங்கே இருக்கிறீர்கள் என்று சொல்லுங்கள்; வேறொரு time zone இல் உள்ள இடத்தைத் தேர்ந்தெடுத்தால் system clock உம் அங்கே நகரும், நீங்கள் பயணம் செய்யும்போது இது எளிதாக இருக்கும். ஒரு நகரத்தின் மீது hover செய்து, அங்கே யார் வசிக்கிறார்கள் என்று சொல்ல person பொத்தானைக் கிளிக் செய்யவும் — வெறும் பெயர்கள், அல்லது அவர்களின் முகங்களையும் கொண்டு வர `@` GitHub handles.

ஒவ்வொரு panel உம் mouse மட்டுமல்லாமல் keyboard ஐயும் ஏற்கும்: அம்புக்குறிகள் நகர்த்தும், Return செயல்படுத்தும், Tab அருகில் உள்ள panel க்குச் செல்லும், Escape மூடும்.

`Super + Ctrl + 1-9` வலது பிரிவில் panels ஐ இடமிருந்து வலமாக எண்ணுகிறது, tray க்குத் தனியாக ஒரு panel இல்லாததால் அதைத் தவிர்த்து விடுகிறது. எனவே நீங்கள் சுட்டிக்காட்டும் ஐகானுடன் எண் பொருந்துகிறது.

### Tailscale மற்றும் Dropbox

பொருந்தும் service ஐ **Install → Service** இலிருந்து நிறுவிய பிறகே மேலும் இரண்டு widgets பட்டையில் தோன்றும், மேலும் இரண்டும் வெறும் நிலைமையை அறிவிப்பதை விட அதிகம் செய்வதால் அவற்றைப் பற்றி அறிந்து கொள்வது மதிப்புக்குரியது.

**Tailscale** panel tailnet ஐ இணைத்துத் துண்டிக்கிறது, கணக்குகளுக்கு இடையே மாறுகிறது, மேலும் ஒரு exit node ஐத் தேர்ந்தெடுக்கிறது (உங்கள் சொந்தக் கணினிகளும் Mullvad பகுதிகளும் அந்தப் பட்டியலில் தோன்றும்). இது உங்கள் கணினிகளை உலாவவும் செய்கிறது — ஒன்றைத் தேர்ந்தெடுத்த நிலையில், `s` Taildrop வழியாக அதற்குக் கோப்புகளை அனுப்புகிறது, இது உங்கள் phone க்கோ அல்லது இன்னொரு laptop க்கோ ஒரு கோப்பை நகர்த்துவதற்கான வேகமான வழியாகும். `c` கணினியின் IP ஐ நகலெடுக்கிறது, `n` அதன் பெயரை, மற்றும் `d` அதன் முழு DNS பெயரை. நீங்கள் கிளிக் செய்ய விரும்பினால் ஒவ்வொரு machine வரிசையிலும் ஒரு send பொத்தானும் உண்டு. terminal இலிருந்து அதே விஷயம் `omarchy tailscale send <machine> [file...]` ஆகும்.

**Dropbox** panel login ஐக் கையாளுகிறது, நீங்கள் எவ்வளவு storage பயன்படுத்தியுள்ளீர்கள் என்பதைக் காட்டுகிறது, மேலும் சமீபத்தில் sync செய்யப்பட்ட கோப்புகளைப் பட்டியலிடுகிறது.

எந்த service ஐயும் நீக்குவது அதன் widget ஐப் பட்டையிலிருந்து மீண்டும் எடுத்து விடும்.

## குறிகாட்டிகள்

நடுவில் உள்ள சிறிய குழுதான் indicators widget. நீங்கள் இயக்கியுள்ள பயன்முறைகளுக்கான நிலைமை glyphs இவை: do not disturb, night light, வரிசையில் உள்ள ஒரு [நினைவூட்டல்](09-reminders.md), செயலில் உள்ள screen recording, stay awake மற்றும் [dictation](11-text-extraction-dictation.md). அந்தப் பயன்முறை செயலில் இருக்கும்போது அவை ஒளிரும், இல்லையெனில் வழியில் இல்லாமல் இருக்கும் — செயலில் இல்லாதவற்றை எட்டிப் பார்க்க பட்டையில் எங்காவது hover செய்யவும். ஒரு குறிகாட்டியைக் கிளிக் செய்வது அந்தப் பயன்முறையை toggle செய்யும். இன்னொன்று வெறும் நிலைமைக்கு மட்டுமே: gliff வழியாக யாராவது இந்தக் கணினியுடன் இணைந்திருக்கும் வரை ஒரு remote session சிவப்பாக ஒளிரும்.

அவை எப்போதும் தெரிய வேண்டும் என்று நீங்கள் விரும்பினால், widget இல் `alwaysShow` ஐ `true` என அமைக்கவும். மேலும் அவற்றில் சிலவற்றைப் பற்றி மட்டுமே நீங்கள் கவலைப்பட்டால், உங்களுக்கு வேண்டியவற்றை `items` இல் பட்டியலிடவும்: `["Dnd", "Reminder", "NightLight"]`. நீங்கள் ஒன்றுக்கு மேற்பட்ட indicators widgets ஐ வைத்திருக்கலாம், எனவே வெவ்வேறு பிரிவுகள் வெவ்வேறு உள்தொகுப்புகளைக் காட்டலாம்.

## பட்டையை மறுசீரமைத்தல்

பட்டை தன்னைத்தானே உள்ளமைத்துக் கொள்கிறது. விஷயங்களை நகர்த்த நீங்கள் ஒரு config கோப்பைத் திறக்க வேண்டியதில்லை.

நடுப்பகுதியைச் சுற்றியுள்ள பட்டையின் காலியான இடத்தைப் பிடித்து இன்னொரு திரை விளிம்பை நோக்கி இழுத்தால், பட்டை அங்கே நகரும் — இடது, வலது, மேல் அல்லது கீழ் எல்லாம் வேலை செய்யும், மேலும் ஒவ்வொரு widget உம் தன்னைத் தகவமைத்துக் கொள்ளும் (செங்குத்துப் பட்டைகள் சிறிய, ஐகான்-மட்டும் வடிவங்களுக்குத் திரும்பும்). கிளிக் செய்து பிடித்திருப்பதும் அதே இழுவையைத் தொடங்கும். அதே காலியான இடத்தில் double-left-click செய்வது பட்டையின் பின்னணியை clear இலிருந்து glassy க்கும் பிறகு opaque க்கும் சுழற்றும். மேலும் எந்த widget ஐயும் இழுத்து அதை மறுவரிசைப்படுத்தவும் அல்லது இன்னொரு பிரிவுக்குள் எறியவும்; அது தரையிறங்கும் இடத்தில் இடம் உருவாக்க மற்ற widgets விலகி நகரும்.

பட்டையின் நடுப்பகுதி ஒரு box: அதற்குள் உள்ளவை எல்லாம் ஒரே குழுவாக நடுவில் இருக்கும், அதன் இருபுறமும் உள்ள widgets அதன் விளிம்புகளில் தொங்கும். நீங்கள் ஒரு widget ஐ இழுக்கும்போது box ஒரு outline ஆகக் காட்டப்படும், அல்லது அது காலியாக இருக்கும்போது பட்டையின் குறுக்கே ஒரு கோடாகக் காட்டப்படும், மேலும் நீங்கள் அதற்குள்ளும் விடலாம் அல்லது அதன் அருகிலும் விடலாம். ஒரு விடுதல் box இல் தரையிறங்கும்போது, widget ஐ உள்ளே எடுத்துக் கொள்ள box வளரும்.

உங்களைச் சுற்றி இருக்க வேண்டும் ஆனால் எப்போதும் பார்வையில் இருக்க வேண்டியதில்லை என்ற ஒரு widget tray இன் drawer க்குள் செல்லலாம்: அதை tray மீது இழுக்கவும், drawer அதை எடுத்துக் கொள்ளத் திறக்கும். அது app ஐகான்களுக்குப் பிறகு அங்கே அமர்ந்திருக்கும், drawer தோன்றும் போதெல்லாம் தோன்றும், மேலும் அதன் panel திறந்திருக்கும் வரை தனது drawer ஐத் திறந்தே வைத்திருக்கும். அதை மீண்டும் பட்டை மீது இழுத்து வெளியே எடுத்து மீண்டும் வைக்கவும்.

நீங்கள் ஒரு மெனுவிலிருந்து தேர்ந்தெடுக்க விரும்பினால், **Appearance → Menu Bar** இல் நிலை உள்ளது, மேலும் **Bar Background** பட்டை எப்படி வரையப்படுகிறது என்பதைத் தேர்ந்தெடுக்கிறது: **Opaque Bar**, **Glassy Bar** (வெளிப்படையானது, அதன் பின்னால் உள்ளவை மங்கலாக்கப்பட்டிருக்கும்), அல்லது **Clear Bar**.

அதே விஷயங்களுக்கு commands உம் உண்டு, இது ஒரு [dotfiles](31-dotfiles.md) அமைப்புக்கு நீங்கள் விரும்புவது:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

ஒரு widget ஐ முழுவதுமாகச் சேர்க்க அல்லது நீக்க, plugin commands ஐப் பயன்படுத்தவும். `omarchy plugin list` shell அறிந்த ஒவ்வொரு widget ஐயும் அதன் id உடன் அச்சிடுகிறது, பிறகு:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## பட்டையை மறைத்தல்

`Super + Shift + Space` shell ஐ அழிக்காமல் பட்டையை அணைத்து மீண்டும் இயக்குகிறது — panels மற்றும் hotkeys தொடர்ந்து வேலை செய்யும், உங்களுக்கு pixels மட்டும் திரும்பக் கிடைக்கும். இது மெனுவில் **Appearance → Menu Bar → Hide Bar** இன் கீழும் உள்ளது.

## Config கோப்பு

இவை எல்லாம் `~/.config/omarchy/shell.json` இல், `bar` key இன் கீழ் சேமிக்கப்படுகின்றன. இதோ ஒரு சுருக்கப்பட்ட பதிப்பு:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

ஒவ்வொரு widget உம் ஐந்து layout வரிசைகளில் ஒன்றில் ஒரு உள்ளீடு, மேலும் அதன் அமைப்புகள் அந்த உள்ளீட்டிலேயே inline ஆக அமர்ந்திருக்கும் — தனியாக ஒரு settings கோப்பு இல்லை, மேலும் ஒரு `config` துணை-பொருளும் இல்லை. கடிகாரத்தின் `format`, `formatAlt` (right-click எதற்குச் சுழல்கிறதோ அது) மற்றும் `verticalFormat` எல்லாம் `{ "id": "omarchy.clock" }` இல் அங்கேயே இருக்கின்றன.

`center` என்பது பட்டையின் நடுவில் உள்ள box: அதில் உள்ள எல்லாமே திரையில் ஒரே குழுவாக நடுவில் வைக்கப்படும். `centerBegin` மற்றும் `centerEnd` box இன் இருபுறமும் தொங்கும், இப்படித்தான் வானிலை மற்றும் update badge வரும்போதும் போகும்போதும் கூட கடிகாரம் மிகச் சரியாக நடுவில் இருக்கிறது. `center` இல் ஒன்றுக்கு மேற்பட்ட widget ஐ வைத்தால் அவை ஒன்றாக நடுவில் வைக்கப்படும்; அதைக் காலியாக விட்டால் `centerBegin` மற்றும் `centerEnd` பட்டையின் நடுவில் சந்திக்கும்.

உள்வாங்கிக் கொள்ள வேண்டிய ஒரு விதி: **உங்களுக்கென சொந்த `shell.json` கிடைத்தவுடன், அதுதான் canonical**. நீங்கள் எதையும் தனிப்பயனாக்கும் வரை, shell Omarchy இன் இயல்புநிலைக் கோப்பைப் படிக்கிறது. நீங்கள் ஒரு widget ஐ இழுத்த கணம், `omarchy bar` ஐ இயக்கிய கணம், அல்லது கோப்பை நீங்களே திருத்திய கணம், நீங்கள்தான் அதற்குப் பொறுப்பு — ஆழமான merge எதுவும் இல்லை, எனவே எதிர்கால Omarchy வெளியீடுகளில் வரும் புதிய இயல்புநிலை widgets உங்கள் பட்டையில் தானாகத் தோன்றாது. நீங்கள் சுத்தமான ஒரு தொடக்கத்தை விரும்பும் போதெல்லாம் `omarchy bar defaults` வழங்கப்பட்ட layout ஐ மீண்டும் வைக்கும்.

அதே கோப்பு உங்கள் idle நேரங்களையும் மேல் மட்டத்தில், `bar` key க்கு வெளியே வைத்திருக்கிறது: `idle.screensaver` மற்றும் `idle.lock`, இரண்டுமே நீங்கள் idle ஆனதிலிருந்து வினாடிகளில். எனவே இயல்புநிலை screensaver 150 வினாடிகளில் தொடங்குகிறது, lock 300 வினாடிகளில் தொடங்குகிறது.
