# மேல் பட்டை

உங்கள் திரையின் மேற்பகுதியில் நீளும் பட்டைதான் Omarchy பட்டை. அது மேலே ஒட்டப்பட்ட ஒரு நிலைப் பட்டை அல்ல; மெனு, அறிவிப்புகள், OSD பாப்அப்கள் மற்றும் பூட்டுத் திரையையும் வரையும் ஒற்றை, நீண்ட நேரம் இயங்கும் Quickshell செயல்முறையான Omarchy ஷெல்லின் ஒரு பகுதி அது. அதனால்தான் அது மற்ற எல்லாவற்றுடனும் கச்சிதமாகத் தீம் செய்யப்படுகிறது, மேலும் ஒரு பேனல் புதிய செயலியை உருவாக்குவதற்குப் பதிலாக உடனடியாகத் திறக்கிறது.

அது எப்போதும் திரையில் இருக்கும் ஒரே டெஸ்க்டாப் பகுதியும் கூட, எனவே அந்தச் சிறிய சின்னங்கள் எல்லாம் என்ன செய்கின்றன என்பதைத் தெரிந்துகொள்வது மதிப்புக்குரியது.

## இயல்பாக அதில் என்ன இருக்கும்

பட்டையில் மூன்று பிரிவுகள் உள்ளன. இடதுபுறம் Omarchy லோகோ (மெனு தொடக்கி) மற்றும் பணியிடக் குறிகாட்டிகள் அமர்ந்துள்ளன. நடுவில் நிலைக் குறிகாட்டிகள், கடிகாரம், Elsewhen (ஒரு உலகக் கடிகாரம்), வானிலை மற்றும் ஒரு Omarchy புதுப்பிப்பு பேட்ஜ் ஆகியவை கிடைக்கும். வலதுபுறம்: சிஸ்டம் ட்ரே, விசைப்பலகை தளவமைப்பு (ஒன்றுக்கு மேற்பட்டவை கட்டமைக்கப்பட்டிருக்கும்போது), agents, bluetooth, network, audio, display மற்றும் power.

அவற்றில் சில, சொல்வதற்கு ஏதாவது இருக்கும்போது மட்டுமே தோன்றும். நீங்கள் ஒன்றுக்கு மேற்பட்ட தளவமைப்புகளைக் கட்டமைத்திருந்தால் மட்டுமே விசைப்பலகை தளவமைப்பு தோன்றும். Omarchy புதுப்பிப்பு காத்திருக்கும்போது மட்டுமே புதுப்பிப்பு பேட்ஜ் தோன்றும். மேலும் இயந்திரத்தில் AI கோடிங் பயன்பாட்டை Omarchy முதன்முறையாகக் கண்டறியும்போது agents ஐகான் தோன்றும் ([AI](17-ai.md) ஐப் பார்க்கவும்).

## பேனல்கள்

பட்டையில் உள்ள ஐகானைக் கிளிக் செய்தால் ஒரு பேனல் திறக்கும்; அது டூல்டிப்பிற்குப் பதிலாக ஸ்லைடர்கள், பட்டியல்கள் மற்றும் விசைப்பலகை வழிசெலுத்தலுடன் கூடிய முறையான பாப்அப். ஒவ்வொன்றுக்கும் ஒரு ஹாட்கீயும் உண்டு, எனவே நீங்கள் ஒருபோதும் 16-பிக்சல் சின்னத்தைக் குறிவைக்க வேண்டியதில்லை:

| Hotkey | Panel |
| --- | --- |
| `Super + Ctrl + A` | Audio |
| `Super + Ctrl + N` | Network |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | Display |
| `Super + Ctrl + P` | Power |
| `Super + Ctrl + Alt + D` | Calendar |
| `Super + Ctrl + Alt + E` | World clock |
| `Super + Ctrl + 1-9` | வலது பிரிவில் உள்ள n-வது பேனலை மாற்று |

பேனல்கள் வெறும் வாசிப்புத் தகவல்கள் அல்ல. நீங்கள் உண்மையிலேயே அந்த வேலையைச் செய்யும் இடம் அவைதான்:

- **Audio** இல் ஒரு முதன்மை ஒலியளவு ஸ்லைடர், ஒரு வெளியீட்டு-சாதனத் தேர்வி மற்றும் ஒரு செயலி-வாரியான மிக்சர் உள்ளது, எனவே மற்ற எல்லாவற்றையும் தொடாமல் அந்த ஒரு browser டேப்பை மட்டும் குறைக்கலாம்.
- **Network** Wi-Fi க்காகத் தேடும், சிக்னல் வலிமையைக் காட்டும், இணைக்கும், மேலும் ஒரு DNS வழங்குநரைத் தேர்ந்தெடுக்க உங்களை அனுமதிக்கும்.
- **Bluetooth** உங்கள் சாதனங்களை இணைப்பு/துண்டிப்பு மற்றும் பேட்டரி அளவுகளுடன் பட்டியலிடும்.
- **Power** பேட்டரி புள்ளிவிவரங்களைக் காட்டும், power profileகளை மாற்றும் (பேட்டரி மற்றும் AC க்குத் தனித்தனி தேர்வை அது நினைவில் வைத்திருக்கும்), மேலும் சில சிஸ்டம் தகவல்களை அச்சிடும்.
- **Display** ஒரு பிரகாச ஸ்லைடர், உரை அளவு, மானிட்டர் அளவிடல் முன்னமைப்புகள், மேலும் — உங்களிடம் ஒன்றுக்கு மேற்பட்ட திரைகள் இருக்கும்போது — மானிட்டர்-வாரியான கட்டுப்பாடுகள் ஆகியவற்றைக் கொண்டுள்ளது. ஆழமான கதைக்கு [மானிட்டர்கள்](33-monitors.md) ஐப் பார்க்கவும்.
- **Clock** ISO வார எண்கள் மற்றும் மாத முன்னேற்றத்துடன் ஒரு மாதக் கட்டத்தைத் திறக்கும்.
- **World clock** ஒவ்வொரு நகரத்திற்கும், அதன் வானிலை மற்றும் அதன் நாள் எப்படிப் போகிறது என்பதுடன், ஒரு வரிசையை வைத்திருக்கும். தேடல் நேர மண்டலங்களைப் போலவே நகரங்களையும் கண்டறியும், எனவே Fort Lauderdale என்பது Fort Lauderdale தான், New York அல்ல. மேலே உள்ள வரி தவறான நகரத்தைக் குறிப்பிட்டால், அதைக் கிளிக் செய்து நீங்கள் எங்கே இருக்கிறீர்கள் என்று சொல்லுங்கள்; வேறொரு நேர மண்டலத்தில் உள்ள இடத்தைத் தேர்ந்தெடுத்தால் சிஸ்டம் கடிகாரமும் அங்கே நகரும், நீங்கள் பயணம் செய்யும்போது அது கைக்கு உதவியாக இருக்கும். ஒரு நகரத்தின் மீது வட்டமிட்டு, அங்கே யார் வசிக்கிறார்கள் என்று சொல்ல நபர் பொத்தானைக் கிளிக் செய்யுங்கள் — எளிய பெயர்கள், அல்லது அவர்களின் முகங்களையும் கொண்டுவர `@` GitHub கைப்பிடிகள்.

ஒவ்வொரு பேனலும் மவுஸைப் போலவே விசைப்பலகையையும் ஏற்கும்: அம்புகள் நகரும், Return செயல்படுத்தும், Tab அருகிலுள்ள பேனலுக்குச் செல்லும், Escape மூடும்.

`Super + Ctrl + 1-9` வலது பிரிவில் உள்ள பேனல்களை இடமிருந்து வலமாக எண்ணும், ட்ரேக்குத் தனியாகப் பேனல் இல்லை என்பதால் அதைத் தவிர்க்கும். எனவே எண் நீங்கள் சுட்டிக்காட்டும் ஐகானுடன் பொருந்தும்.

### Tailscale மற்றும் Dropbox

**Install → Service** இலிருந்து பொருந்தும் சேவையை நீங்கள் நிறுவிய பிறகு மட்டுமே மேலும் இரண்டு விட்ஜெட்டுகள் பட்டையில் தோன்றும், மேலும் இரண்டுமே வெறுமனே நிலையை அறிவிப்பதை விட அதிகம் செய்வதால் அவற்றைத் தெரிந்துகொள்வது மதிப்புக்குரியது.

**Tailscale** பேனல் tailnet ஐ இணைக்கும் மற்றும் துண்டிக்கும், கணக்குகளுக்கு இடையே மாற்றும், மேலும் ஒரு exit node ஐத் தேர்ந்தெடுக்கும் (உங்கள் சொந்த இயந்திரங்கள் மற்றும் Mullvad பகுதிகள் இரண்டுமே அந்தப் பட்டியலில் தோன்றும்). அது உங்கள் இயந்திரங்களையும் உலாவும் — மேலும் ஒன்றைத் தேர்ந்தெடுத்திருக்கும்போது, `s` அதற்கு Taildrop வழியாகக் கோப்புகளை அனுப்பும், உங்கள் தொலைபேசிக்கு அல்லது மற்றொரு லேப்டாப்பிற்கு ஒரு கோப்பை நகர்த்துவதற்கான வேகமான வழி அதுதான். `c` இயந்திரத்தின் IP ஐ நகலெடுக்கும், `n` அதன் பெயரை, மற்றும் `d` அதன் முழு DNS பெயரை. நீங்கள் கிளிக் செய்வதையே விரும்பினால், ஒவ்வொரு இயந்திர வரிசையிலும் ஒரு அனுப்பு பொத்தானும் உண்டு. Terminal இலிருந்து அதே விஷயம் `omarchy tailscale send <machine> [file...]`.

**Dropbox** பேனல் உள்நுழைவைக் கையாளும், நீங்கள் எவ்வளவு சேமிப்பகத்தைப் பயன்படுத்தியுள்ளீர்கள் என்பதைக் காட்டும், மேலும் சமீபத்தில் ஒத்திசைக்கப்பட்ட கோப்புகளைப் பட்டியலிடும்.

ஏதேனும் ஒரு சேவையை நீக்குவது அதன் விட்ஜெட்டைப் பட்டையிலிருந்து மீண்டும் எடுத்துவிடும்.

## குறிகாட்டிகள்

நடுவில் உள்ள சிறிய குழுதான் indicators விட்ஜெட். நீங்கள் இயக்கியுள்ள பயன்முறைகளுக்கான நிலைச் சின்னங்கள் இவை: தொந்தரவு செய்யாதே, இரவு விளக்கு, வரிசையில் உள்ள [நினைவூட்டல்](09-reminders.md), செயலில் உள்ள திரைப் பதிவு, விழித்திரு, மற்றும் [வாய்மொழி உள்ளீடு](11-text-extraction-dictation.md). பயன்முறை செயலில் இருக்கும்போது அவை ஒளிரும், இல்லையெனில் வழியில் இல்லாமல் இருக்கும் — செயலற்றவை அமர்ந்திருக்கும் இடத்திற்கு அருகில் வட்டமிட்டு அவற்றைப் பார்க்கலாம். ஒரு குறிகாட்டியைக் கிளிக் செய்வது அந்தப் பயன்முறையை மாற்றும். இன்னொன்று நிலை மட்டுமே: யாராவது gliff வழியாக இந்த இயந்திரத்துடன் இணைக்கப்பட்டிருக்கும்போது ஒரு தொலைநிலை அமர்வு சிவப்பாக ஒளிரும்.

அவை எப்போதும் தெரிய வேண்டும் என்று நீங்கள் விரும்பினால், விட்ஜெட்டில் `alwaysShow` ஐ `true` என அமைக்கவும். மேலும் அவற்றில் சிலவற்றைப் பற்றி மட்டுமே நீங்கள் அக்கறை கொண்டால், நீங்கள் விரும்புவதை `items` இல் பட்டியலிடவும்: `["Dnd", "Reminder", "NightLight"]`. உங்களிடம் ஒன்றுக்கு மேற்பட்ட indicators விட்ஜெட்டுகள் இருக்கலாம், எனவே வெவ்வேறு பிரிவுகள் வெவ்வேறு துணைத் தொகுப்புகளைக் காட்டலாம்.

## பட்டையை மறுஒழுங்கு செய்தல்

பட்டை தன்னைத்தானே கட்டமைத்துக் கொள்ளும். விஷயங்களை நகர்த்த நீங்கள் ஒரு கட்டமைப்புக் கோப்பைத் திறக்க வேண்டியதில்லை.

நடுப்பகுதியைச் சுற்றியுள்ள பட்டையின் ஒரு வெற்றுப் பகுதியைப் பிடித்து மற்றொரு திரை விளிம்பை நோக்கி இழுத்தால், பட்டை அங்கே நகரும் — இடது, வலது, மேல் அல்லது கீழ் அனைத்தும் வேலை செய்யும், மேலும் ஒவ்வொரு விட்ஜெட்டும் தகவமைத்துக் கொள்ளும் (செங்குத்துப் பட்டைகள் கச்சிதமான ஐகான்-மட்டும் வடிவங்களுக்குத் திரும்பும்). கிளிக்-செய்து-பிடிப்பதும் அதே இழுவையைத் தொடங்கும். அதே வெற்று இடத்தில் இருமுறை-இடது-கிளிக் செய்து பட்டையின் பின்னணியைத் தெளிவிலிருந்து கண்ணாடி போன்றதாக, பின்னர் ஒளிபுகாததாகச் சுழற்றுங்கள். மேலும் எந்த விட்ஜெட்டையும் இழுத்து அதை மறுஒழுங்கு செய்யுங்கள் அல்லது மற்றொரு பிரிவிற்குள் வீசுங்கள்; மற்ற விட்ஜெட்டுகள் அது விழும் இடத்தில் இடம் கொடுக்க விலகிச் செல்லும்.

பட்டையின் நடுப்பகுதி ஒரு பெட்டி: அதில் உள்ளதெல்லாம் ஒரே குழுவாக நடுவில் இருக்கும், மேலும் அதன் இருபுறமும் உள்ள விட்ஜெட்டுகள் அதன் விளிம்புகளில் தொங்கும். நீங்கள் ஒரு விட்ஜெட்டை இழுக்கும்போது பெட்டி ஒரு வெளிக்கோடாகவும், அல்லது அது காலியாக இருக்கும்போது பட்டையின் குறுக்கே ஒரு கோடாகவும் காட்டப்படும், மேலும் நீங்கள் அதற்குள் அல்லது அதற்கு அருகில் விடலாம். ஒரு விடுதல் பெட்டியில் விழும்போது, பெட்டி விட்ஜெட்டை உள்ளே எடுத்துக்கொள்ள வளரும்.

நீங்கள் அருகில் வைத்திருக்க விரும்பும், ஆனால் எப்போதும் காட்சியில் இருக்க வேண்டாம் என்ற ஒரு விட்ஜெட் ட்ரேயின் டிராயருக்குள் செல்லலாம்: அதை ட்ரே மீது இழுக்கவும், டிராயர் அதை எடுத்துக்கொள்ளத் திறக்கும். அது செயலி ஐகான்களுக்குப் பிறகு அங்கே அமரும், டிராயர் தோன்றும்போதெல்லாம் தோன்றும், மேலும் அதன் பேனல் மேலே இருக்கும்போது அதன் டிராயரைத் திறந்து வைத்திருக்கும். அதை மீண்டும் பட்டையில் வைக்க வெளியே பட்டைக்கு இழுக்கவும்.

நீங்கள் ஒரு மெனுவிலிருந்து தேர்ந்தெடுப்பதை விரும்பினால், **Appearance → Menu Bar** இல் நிலை உள்ளது, மற்றும் **Bar Background** பட்டை எவ்வாறு வரையப்படுகிறது என்பதைத் தேர்ந்தெடுக்கும்: **Opaque Bar**, **Glassy Bar** (ஊடுருவக்கூடியது, அதன் பின்னால் உள்ளது மங்கலாக்கப்பட்டு), அல்லது **Clear Bar**.

அதே விஷயங்களுக்குக் கட்டளைகளும் உள்ளன, [dotfiles](31-dotfiles.md) அமைப்பிற்கு நீங்கள் விரும்புவது அதுதான்:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

ஒரு விட்ஜெட்டை முழுவதுமாகச் சேர்க்க அல்லது நீக்க, plugin கட்டளைகளைப் பயன்படுத்தவும். `omarchy plugin list` ஷெல்லுக்குத் தெரிந்த ஒவ்வொரு விட்ஜெட்டையும் அதன் id உடன் அச்சிடும், பின்னர்:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## பட்டையை மறைத்தல்

`Super + Shift + Space` ஷெல்லைக் கொல்லாமல் பட்டையை அணைத்து மீண்டும் இயக்கும் — பேனல்கள் மற்றும் ஹாட்கீகள் தொடர்ந்து வேலை செய்யும், உங்களுக்குப் பிக்சல்கள் மட்டும் திரும்பக் கிடைக்கும். அது மெனுவில் **Appearance → Menu Bar → Hide Bar** இன் கீழும் உள்ளது.

## கட்டமைப்புக் கோப்பு

இவை அனைத்தும் `~/.config/omarchy/shell.json` இல், `bar` விசையின் கீழ் சேமிக்கப்படும். இதோ ஒரு சுருக்கப்பட்ட பதிப்பு:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

ஒவ்வொரு விட்ஜெட்டும் ஐந்து தளவமைப்பு வரிசைகளில் ஒன்றில் ஒரு உள்ளீடு, மேலும் அதன் அமைப்புகள் அந்த உள்ளீட்டிலேயே உள்ளன — தனியான அமைப்புகள் கோப்பு இல்லை, மேலும் `config` துணை-பொருளும் இல்லை. கடிகாரத்தின் `format`, `formatAlt` (வலது-கிளிக் எதற்குச் சுழல்கிறது), மற்றும் `verticalFormat` அனைத்தும் `{ "id": "omarchy.clock" }` இலேயே உள்ளன.

`center` என்பது பட்டையின் நடுவில் உள்ள பெட்டி: அதில் உள்ள எல்லாமுமே திரையில் ஒரே குழுவாக நடுவில் அமைக்கப்படும். `centerBegin` மற்றும் `centerEnd` பெட்டியின் இருபுறமும் தொங்கும், வானிலை மற்றும் புதுப்பிப்பு பேட்ஜ் வந்து போகும்போதும் கடிகாரம் சரியாக நடுவில் இருப்பது இப்படித்தான். `center` இல் ஒன்றுக்கு மேற்பட்ட விட்ஜெட்டுகளை வைத்தால் அவை ஒன்றாக நடுவில் அமையும்; அதைக் காலியாக விட்டால் `centerBegin` மற்றும் `centerEnd` பட்டையின் நடுவில் சந்திக்கும்.

உள்வாங்கிக் கொள்ள வேண்டிய ஒரு விதி: **உங்களுக்கென்று சொந்த `shell.json` இருந்துவிட்டால், அதுதான் அதிகாரப்பூர்வமானது**. நீங்கள் எதையும் தனிப்பயனாக்கும் வரை, ஷெல் Omarchy இன் இயல்புநிலைக் கோப்பைப் படிக்கும். நீங்கள் ஒரு விட்ஜெட்டை இழுத்த, `omarchy bar` ஐ இயக்கிய, அல்லது கோப்பை நீங்களே திருத்திய தருணத்திலிருந்து, அது உங்களுடையது — ஆழமான ஒன்றிணைப்பு இல்லை, எனவே எதிர்கால Omarchy வெளியீடுகளில் உள்ள புதிய இயல்புநிலை விட்ஜெட்டுகள் உங்கள் பட்டையில் தானாகவே தோன்றாது. நீங்கள் ஒரு சுத்தமான தொடக்கத்தை விரும்பும்போதெல்லாம் `omarchy bar defaults` வழங்கப்பட்ட தளவமைப்பை மீண்டும் வைக்கும்.

அதே கோப்பு உங்கள் செயலற்ற நேரங்களையும் மேல் மட்டத்தில், `bar` விசைக்கு வெளியே, வைத்திருக்கும்: `idle.screensaver` மற்றும் `idle.lock`, இரண்டும் நீங்கள் செயலற்றுப் போனதிலிருந்து விநாடிகளில். எனவே இயல்புநிலை ஸ்கிரீன்சேவர் 150 விநாடிகளில் தொடங்கும், பூட்டு 300 இல்.
