# அடிக்கடி கேட்கப்படும் கேள்விகள்

### விசைப்பலகை தளவமைப்புகளுக்கு இடையே நான் எப்படி மாறுவது?

உங்கள் `~/.config/hypr/input.lua` கோப்பைத் திருத்தி, `Left Alt + Right Alt` மூலம் தளவமைப்புகளுக்கு இடையே மாற இதைச் சேர்க்கவும்:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

உங்களிடம் பல தளவமைப்புகள் கட்டமைக்கப்பட்டிருந்தால், பட்டை உங்கள் தற்போதைய விசைப்பலகை தளவமைப்பைத் தானாகவே காண்பிக்கும் (மேலும் மாறுவதற்கு அதைக் கிளிக் செய்யவும் முடியும்).

### கடிகார வடிவமைப்பை 12 மணி நேர வடிவமைப்பிற்கு நான் எப்படி மாற்றுவது?

12 மணி நேர வடிவமைப்புகள் உட்பட, பொதுவான வடிவமைப்புகள் வழியாகச் சுழற்சியாக மாற பட்டையில் உள்ள கடிகாரத்தின் மீது வலது-கிளிக் செய்யவும். வடிவமைப்பை நேரடியாகவும் அமைக்கலாம்:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

இது ஞாயிறு 10:55 AM என்று காண்பிக்கும்.

### எனது நேர மண்டலத்தை நான் எப்படி மாற்றுவது?

Omarchy மெனுவில் _Update > Timezone_ ஐ இயக்கிப் பட்டியலிலிருந்து தேர்ந்தெடுக்கவும். நேர மண்டலம் சரியாக இருந்தும் கடிகாரமே விலகிவிட்டால், _Update > Time_ உங்களுக்காக நேர ஒத்திசைவை மறுதொடக்கம் செய்யும்.

### எனது DNS ஐ மாற்றுவது, எனது Wi-Fi ஐப் பகிர்வது, அல்லது எனது இணைப்பு வேகத்தைச் சரிபார்ப்பது எப்படி?

அவை அனைத்தும் [நெட்வொர்க்கிங்](35-networking.md) இல் உள்ளன.

### எனது வட்டு எவ்வளவு வேகமானது என்பதை நான் எப்படிச் சரிபார்ப்பது?

_Trigger > Speed Test > Disk Speed Test_ உங்கள் இயக்ககத்தில் நேரடி வாசிப்பு மற்றும் எழுதும் வேகத்தை அளவிடும், அல்லது முனையத்திலிருந்து `omarchy disk speedtest` ஐப் பயன்படுத்தவும்.

### நான் எப்படி ஒரு அச்சுப்பொறியைச் சேர்ப்பது?

அச்சிடுதல் பெட்டியைத் திறந்தவுடனேயே அமைக்கப்பட்டு இயங்கிக்கொண்டிருக்கும், மேலும் ஒவ்வொரு அச்சுப்பொறியையும் நீங்களே பயன்பாட்டுத் துவக்கியில் (`Super + Space`) உள்ள _Print Settings_ இலிருந்து சேர்க்கலாம்.

_Add_ ஐத் தேர்ந்தெடுத்து, அது தேட சிறிது நேரம் கொடுக்கவும்: USB வழியாக இணைக்கப்பட்ட அச்சுப்பொறியும், பெரும்பாலான நெட்வொர்க் அச்சுப்பொறிகளும் உங்களுக்காகக் கண்டறியப்படும். உங்களுடையது பட்டியலில் இல்லையெனில், _Network Printer > Internet Printing Protocol (ipp)_ ஐத் தேர்ந்தெடுத்து அதன் முகவரியை உள்ளிடவும் — அது என்ன என்பதை அச்சுப்பொறியின் சொந்தக் காட்சித் திரையோ அல்லது அதன் வலைப் பக்கமோ உங்களுக்குச் சொல்லும், பொதுவாக `ipp/print` என்ற வரிசையுடன் `192.168.1.50` போன்ற ஏதாவது ஒன்றாக இருக்கும். பின்னர் _Forward_ ஒரு இயக்கியை வழங்கும், அங்கு ஒரு நவீன அச்சுப்பொறி இயக்கி இல்லாத _IPP Everywhere_ சுயவிவரத்தில் சிறப்பாகச் செயல்படும், பழைய ஒன்றுக்கு அந்த மாடலின் சொந்த இயக்கி தேவைப்படும்.

உங்கள் பயன்பாடுகள் முதலில் எதை நாட வேண்டும் என்பதைத் தேர்ந்தெடுக்க ஒரு அச்சுப்பொறியின் மீது வலது-கிளிக் செய்து _Set as Default_ ஐத் தேர்ந்தெடுக்கவும், மேலும் காகித அளவு, இருபக்க அச்சு மற்றும் தரத்தை அமைக்க _Properties_ ஐத் தேர்ந்தெடுக்கவும்.

நெட்வொர்க்கில் உள்ள அச்சுப்பொறிகள் சேர்க்கப்படாமலேயே தோன்றும் தானியங்கு கண்டறிதல், அது மறுவேலை செய்யப்படும் வரை தற்காலிகமாக முடக்கப்பட்டுள்ளது, அதனால்தான் மேலே உள்ள முதல் படி தானியங்காக இல்லாமல் உங்களுடையதாக உள்ளது. PDF கோப்பில் அச்சிடுவது எந்த அச்சுப்பொறியும் இல்லாமலேயே செயல்படும்.

### திரைப்பிடிப்புகள் அல்லது திரைப் பதிவுகள் எங்கு சேமிக்கப்படுகின்றன என்பதை நான் எப்படி மாற்றுவது?

சேமிக்கப்பட்ட திரைப்பிடிப்புகள் இயல்பாக `~/Pictures/Screenshots` க்குச் செல்லும். வேறொரு அடைவைப் பயன்படுத்த, `~/.config/uwsm/env.d/` இன் கீழ் உள்ள ஒரு கோப்பில் (`~/.config/uwsm/env.d/capture` போன்ற) இதைச் சேர்க்கவும்:

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

`OMARCHY_SCREENRECORD_DIR` ஐப் பயன்படுத்தித் திரைப் பதிவுகளுக்கும் இதையே செய்யலாம்.

Omasnap அதன் திரைப்பிடிப்பு அடைவைத் தானாகவே உருவாக்கும். திரைப் பதிவு அடைவை நீங்களே உருவாக்கவும், பின்னர் இரண்டு சூழல் மாற்றங்களில் ஏதேனும் ஒன்று நடைமுறைக்கு வர Omarchy ஐ மறுதொடக்கம் செய்யவும்.

### எனது Apple Studio Display இல் ஒலிபெருக்கிகள் + வெப்கேமை நான் எப்படிச் செயல்பட வைப்பது?

USB C ஐச் செருகினாலே அனைத்தும் செயல்பட வேண்டும் என்று நீங்கள் நினைப்பீர்கள், ஆனால் துரதிர்ஷ்டவசமாக அப்படி இல்லை. அது நம்பகமாகச் செயல்பட நான் கண்டறிந்த தீர்வு [WJESOG DisplayPort + USB-A => USB-C கேபிளைப்](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) பயன்படுத்துவதுதான். பின்னர் ஒலிபெருக்கிகளும் வெப்கேமும் மிகச் சிறப்பாகச் செயல்படும்.

வழக்கமான விசைப்பலகை பிரகாசப் பொத்தான்களைப் பயன்படுத்தி Apple Displays க்கு (Studio மற்றும் XDR இரண்டும்) Omarchy இல் உள்ளமைக்கப்பட்ட பிரகாசக் கட்டுப்பாடு உங்களிடம் உள்ளது என்பதை நினைவில் கொள்ளவும்.

### கூடுதல் மென்பொருள் அனைத்தையும் நான் எப்படி அகற்றுவது?

Obsidian அல்லது LibreOffice போன்ற நிரல்களோ அல்லது முன்பே நிறுவப்பட்ட வேறு எந்தப் பொருட்களோ உங்களுக்கு வேண்டாம் என்றால், அதை மிக எளிதாக அகற்றலாம்.

நிறுவப்பட்டுள்ள ஒவ்வொரு தொகுப்பையும் பார்க்க _Remove > Package_ ஐ இயக்கவும். பின்னர் நீங்கள் அகற்ற விரும்பும் எந்தத் தொகுப்பையும் tab மூலம் தேர்ந்தெடுக்கலாம், மேலும் நீங்கள் தேர்ந்தெடுத்த அனைத்தையும் return மூலம் அகற்றத் தொடங்கலாம்.

மேலும் நீங்கள் விரும்பாத முன்பே நிறுவப்பட்ட வலைப் பயன்பாடுகளில் எதையும் அகற்ற Omarchy மெனுவிலிருந்து _Remove > Web App_ ஐப் பயன்படுத்தலாம்.

அல்லது முன்பே நிறுவப்பட்ட கூடுதல் அனைத்தையும் — வலைப் பயன்பாடுகள், TUIs, மற்றும் விருப்பப் பயன்பாடுகள் — ஒரே முறையில் அகற்ற _Remove > Preinstalls_ ஐ இயக்கவும். அவற்றைத் துவக்கிய ஹாட்கீகளும் அவற்றுடன் போய்விடும், எனவே `~/.config/hypr/bindings.lua` இல் உங்களுடையவற்றை நிரப்புவதற்கான சுத்தமான காலி பிணைப்புகள் உங்களிடம் மீதமிருக்கும்.
