# அடிக்கடி கேட்கப்படும் கேள்விகள்

### விசைப்பலகைத் தளவமைப்புகளுக்கு இடையே எப்படி மாறுவது?

உங்கள் `~/.config/hypr/input.lua` கோப்பைத் திருத்தி `Left Alt + Right Alt`-இல் தளவமைப்புகளுக்கு இடையே மாற இதைச் சேர்க்கவும்:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

நீங்கள் பல தளவமைப்புகளை உள்ளமைத்தவுடன் பட்டை தானாகவே உங்கள் தற்போதைய விசைப்பலகைத் தளவமைப்பைக் காட்டும் (அதைச் சொடுக்கி மாற்றவும் முடியும்).

### கடிகார வடிவத்தை 12-மணிக்கு எப்படி மாற்றுவது?

12-மணி வடிவங்கள் உட்பட பொதுவான வடிவங்களில் சுற்றி வரப் பட்டையில் உள்ள கடிகாரத்தின் மீது வலது சொடுக்கு செய்யுங்கள். வடிவத்தை நேரடியாகவும் அமைக்கலாம்:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

இது Sunday 10:55 AM என்று காட்டும்.

### என் நேர மண்டலத்தை எப்படி மாற்றுவது?

Omarchy மெனுவில் _புதுப்பி > நேர மண்டலம்_ என்பதை இயக்கிப் பட்டியலிலிருந்து தேர்ந்தெடுங்கள். நேர மண்டலம் சரியாக இருந்தும் கடிகாரமே விலகிச் சென்றிருந்தால், _புதுப்பி > நேரம்_ உங்களுக்காக நேர ஒத்திசைவை மறுதொடக்கம் செய்யும்.

### என் DNS-ஐ எப்படி மாற்றுவது, என் Wi-Fi-ஐப் பகிர்வது அல்லது என் இணைப்பு வேகத்தைச் சரிபார்ப்பது எப்படி?

அவை அனைத்தும் [வலையமைப்பில்](35-networking.md) வாழ்கின்றன.

### என் வட்டு எவ்வளவு வேகமாக இருக்கிறது என்பதை எப்படிச் சரிபார்ப்பது?

_தூண்டு > வேக சோதனை > வட்டு வேக சோதனை_ உங்கள் இயக்ககத்தில் நேரடிப் படிப்பு மற்றும் எழுது வேகத்தை அளவிடுகிறது, அல்லது முனையத்திலிருந்து `omarchy disk speedtest`.

### ஏன் Chromium-இல் என் Google கணக்கில் உள்நுழைய முடியவில்லை?

வெற்றுத் திறந்த மூல Chromium கட்டுமானம், கணக்கு உள்நுழைவிற்கு Google தேவைப்படுத்தும் OAuth சான்றுகளுடன் வருவதில்லை. அவற்றைச் சேர்க்க Omarchy மெனுவில் _நிறுவு > சேவை > Chromium கணக்கு_ என்பதை இயக்கி, உலாவியை மறுதொடக்கம் செய்யுங்கள், உள்நுழைவு முடிந்துவிடும்.

### ஒரு அச்சுப்பொறியை எப்படிச் சேர்ப்பது?

அச்சிடுதல் அப்படியே அமைக்கப்பட்டு இயங்குகிறது, செயலி ஏவியில் (`Super + Space`) உள்ள _Print Settings_-இலிருந்து ஒவ்வோர் அச்சுப்பொறியையும் நீங்களே சேர்க்கிறீர்கள்.

_Add_ என்பதைத் தேர்ந்தெடுத்து, அது பார்க்க ஒரு நொடி கொடுங்கள்: USB வழியே செருகப்பட்ட அச்சுப்பொறியும், பெரும்பாலான வலையமைப்பு அச்சுப்பொறிகளும் உங்களுக்காகக் கண்டுபிடிக்கப்படுகின்றன. உங்கள் அச்சுப்பொறி பட்டியலில் இல்லையென்றால், _Network Printer > Internet Printing Protocol (ipp)_ என்பதைத் தேர்ந்தெடுத்து அதன் முகவரியை உள்ளிடுங்கள் — அச்சுப்பொறியின் சொந்தத் திரையோ அதன் வலைப் பக்கமோ அது என்ன என்பதைச் சொல்லும், வழக்கமாக `192.168.1.50` போன்றதும் `ipp/print` என்ற வரிசையும். _Forward_ பிறகு ஓர் இயக்கியை வழங்கும், அங்கு ஒரு நவீன அச்சுப்பொறி இயக்கி இல்லாத _IPP Everywhere_ சுயவிவரத்திலும் பழைய ஒன்று மாதிரியின் சொந்த இயக்கியிலும் சிறப்பாக வேலை செய்யும்.

ஓர் அச்சுப்பொறியின் மீது வலது சொடுக்கு செய்து, உங்கள் செயலிகள் முதலில் எதை அடைய வேண்டும் என்பதைத் தேர்ந்தெடுக்க _Set as Default_ என்பதையும், தாள் அளவு, இருபக்கம், தரம் ஆகியவற்றை அமைக்க _Properties_ என்பதையும் தேர்ந்தெடுங்கள்.

வலையமைப்பில் உள்ள அச்சுப்பொறிகள் சேர்க்கப்படாமல் தோன்றும் தானியங்குக் கண்டறிதல், அது மீண்டும் வடிவமைக்கப்படும் வரை தற்காலிகமாக முடக்கப்பட்டுள்ளது, அதனால்தான் மேலே உள்ள முதல் படி தானியங்குவதற்குப் பதிலாக உங்களுடையது. PDF கோப்பில் அச்சிடுதல் எந்த அச்சுப்பொறியும் இல்லாமல் வேலை செய்யும்.

### திரைப்பிடிப்புகள் அல்லது திரைப்பதிவுகள் எங்கு சேமிக்கப்படும் என்பதை எப்படி மாற்றுவது?

சேமிக்கப்பட்ட திரைப்பிடிப்புகள் இயல்பாகவே `~/Pictures/Screenshots`-க்குச் செல்கின்றன. மற்றொரு கோப்பகத்தைப் பயன்படுத்த, `~/.config/uwsm/env.d/`-இன் கீழ் உள்ள ஒரு கோப்பில் (`~/.config/uwsm/env.d/capture` போல) இதைச் சேர்க்கவும்:

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

`OMARCHY_SCREENRECORD_DIR`-ஐப் பயன்படுத்தித் திரைப்பதிவுகளுக்கும் அதையே செய்யலாம்.

Omasnap தன் திரைப்பிடிப்புக் கோப்பகத்தைத் தானாகவே உருவாக்குகிறது. திரைப்பதிவுக் கோப்பகத்தை நீங்களே உருவாக்கி, பிறகு எந்தச் சூழல் மாற்றமும் நடைமுறைக்கு வர Omarchy-ஐ மறுதொடக்கம் செய்யுங்கள்.

### என் Apple Studio Display-இல் ஸ்பீக்கர்கள் + வெப்கேமை எப்படிச் செயல்பட வைப்பது?

USB C-ஐச் செருகினாலே எல்லாம் வேலை செய்ய வேண்டும் என்று நினைப்பீர்கள், ஆனால் துரதிர்ஷ்டவசமாக அப்படியல்ல. அதை நம்பகமாகச் செயல்பட வைக்க நான் கண்டறிந்த தீர்வு [WJESOG DisplayPort + USB-A => USB-C கேபிளை](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) பயன்படுத்துவது. பிறகு ஸ்பீக்கர்களும் வெப்கேமும் அழகாக வேலை செய்கின்றன.

வழக்கமான விசைப்பலகை பிரகாசப் பொத்தான்களைப் பயன்படுத்தி Apple Displays (Studio-வும் XDR-உம்) ஆகிய இரண்டிற்கும் Omarchy-இல் உள்ளமைந்த பிரகாசக் கட்டுப்பாடு உள்ளது என்பதை நினைவில் கொள்ளுங்கள்.

### கூடுதல் மென்பொருள் அனைத்தையும் எப்படி அகற்றுவது?

Obsidian அல்லது LibreOffice அல்லது வேறு எந்த முன்னிறுவப்பட்ட பொருளும் வேண்டாமென்றால், அதை மிக எளிதாக நீக்கலாம்.

நிறுவப்பட்ட ஒவ்வொரு தொகுப்பையும் காண _நீக்கு > தொகுப்பு_ என்பதை இயக்குங்கள். பிறகு tab-ஐக் கொண்டு நீக்க விரும்பும் எந்தத் தொகுப்பையும் தேர்ந்தெடுத்து, return-ஐக் கொண்டு நீங்கள் தேர்ந்தெடுத்த எல்லாவற்றையும் நீக்கத் தொடங்கலாம்.

உங்களுக்கு வேண்டாத எந்த முன்னிறுவப்பட்ட வலைச் செயலிகளையும் நீக்க Omarchy மெனுவிலிருந்து _நீக்கு > வலைச் செயலி_ என்பதைப் பயன்படுத்தலாம்.

அல்லது முன்னிறுவப்பட்ட அனைத்து கூடுதல்களையும் — வலைச் செயலிகள், TUI-கள், விருப்பச் செயலிகள் — ஒரே நேரத்தில் துடைத்தெடுக்க _நீக்கு > முன்னிறுவல்கள்_ என்பதை இயக்குங்கள். அவற்றைத் தொடங்கிய விசைப்பிணைப்புகள் அவற்றுடன் சென்றுவிடும், எனவே `~/.config/hypr/bindings.lua`-இல் உங்கள் சொந்தப் பிணைப்புகளால் நிரப்பச் சுத்தமான தொடக்கம் உங்களுக்குக் கிடைக்கும்.
