# அடிக்கடி கேட்கப்படும் கேள்விகள்

### விசைப்பலகை தளவமைப்புகளுக்கு இடையே நான் எப்படி மாறுவது?

உங்கள் `~/.config/hypr/input.lua` கோப்பைத் திருத்தி, `Left Alt + Right Alt` இல் தளவமைப்புகளுக்கு இடையே மாற இதைச் சேர்க்கவும்:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

பல தளவமைப்புகளை நீங்கள் உள்ளமைத்தவுடன் பட்டி உங்கள் தற்போதைய விசைப்பலகை தளவமைப்பைத் தானாகவே காண்பிக்கும் (மாற்றுவதற்கு அதைக் கிளிக் செய்யவும் முடியும்).

### கடிகார வடிவமைப்பை 12 மணி நேர வடிவமைப்பிற்கு நான் எப்படி மாற்றுவது?

பொதுவான வடிவமைப்புகளுக்கு இடையே, 12 மணி நேர வடிவமைப்புகள் உட்பட, சுழற்சி செய்ய பட்டியில் உள்ள கடிகாரத்தின் மீது வலது-கிளிக் செய்யவும். வடிவமைப்பை நேரடியாகவும் அமைக்கலாம்:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

இது ஞாயிற்றுக்கிழமை 10:55 AM எனக் காண்பிக்கும்.

### எனது நேர மண்டலத்தை நான் எப்படி மாற்றுவது?

Omarchy பட்டியலில் _அமைப்பு > பகுதி > நேர மண்டலம்_ என்பதை இயக்கி, பட்டியலிலிருந்து தேர்ந்தெடுக்கவும். நேர மண்டலம் சரியாக இருந்தும் கடிகாரமே விலகிவிட்டிருந்தால், _புதுப்பிப்பு > நேரம்_ உங்களுக்காக நேர ஒத்திசைவை மறுதொடக்கம் செய்யும்.

### எனது DNS ஐ நான் எப்படி மாற்றுவது, எனது Wi-Fi ஐப் பகிர்வது, அல்லது எனது இணைப்பு வேகத்தைச் சரிபார்ப்பது?

அவை அனைத்தும் [பிணையமாக்கத்தில்](35-networking.md) உள்ளன.

### எனது வட்டு எவ்வளவு வேகமாக உள்ளது என்பதை நான் எப்படிச் சரிபார்ப்பது?

_தூண்டு > வேகச் சோதனை > வட்டு வேகச் சோதனை_ உங்கள் இயக்ககத்தில் நேரடி படிப்பு மற்றும் எழுத்து வேகத்தை அளவிடும், அல்லது முனையத்திலிருந்து `omarchy disk speedtest` என்பதைப் பயன்படுத்தவும்.

### அச்சுப்பொறியை நான் எப்படிச் சேர்ப்பது?

அச்சிடுதல் ஏற்கனவே அமைக்கப்பட்டு இயங்கிக் கொண்டிருக்கிறது, ஒவ்வொரு அச்சுப்பொறியையும் நீங்களே பயன்பாட்டுத் தொடக்கியில் (`Super + Alt + Space`) உள்ள _அச்சு அமைப்புகள்_ இலிருந்து சேர்க்கவும்.

_சேர்_ என்பதைத் தேர்ந்தெடுத்து, அது தேடுவதற்குச் சிறிது நேரம் கொடுக்கவும்: USB வழியாகச் செருகப்பட்ட அச்சுப்பொறியும், பெரும்பாலான பிணைய அச்சுப்பொறிகளும் உங்களுக்காகக் கண்டறியப்படும். உங்களுடையது பட்டியலில் இல்லையென்றால், _பிணைய அச்சுப்பொறி > Internet Printing Protocol (ipp)_ என்பதைத் தேர்ந்தெடுத்து அதன் முகவரியை உள்ளிடவும் — அது என்ன என்பதை அச்சுப்பொறியின் சொந்தத் திரையோ அல்லது அதன் வலைப் பக்கமோ உங்களுக்குச் சொல்லும், வழக்கமாக `ipp/print` என்ற வரிசையுடன் `192.168.1.50` போன்ற ஒன்று. பின்னர் _முன்னோக்கு_ ஒரு இயக்கியை வழங்கும், அங்கு நவீன அச்சுப்பொறி இயக்கி இல்லாத _IPP Everywhere_ சுயவிவரத்தில் சிறப்பாகச் செயல்படும், பழைய ஒன்று அந்த மாதிரியின் சொந்த இயக்கியை விரும்பும்.

அச்சுப்பொறியின் மீது வலது-கிளிக் செய்து, உங்கள் பயன்பாடுகள் முதலில் எதை அணுக வேண்டும் என்பதைத் தேர்ந்தெடுக்க _இயல்புநிலையாக அமை_ என்பதையும், காகித அளவு, இருபக்க அச்சு மற்றும் தரத்தை அமைக்க _பண்புகள்_ என்பதையும் தேர்ந்தெடுக்கவும்.

பிணையத்தில் உள்ள அச்சுப்பொறிகள் சேர்க்கப்படாமலேயே தோன்றும் தானியங்கு கண்டறிதல், அது மறுவேலை செய்யப்படும் வரை தற்காலிகமாக அணைக்கப்பட்டுள்ளது, அதனால்தான் மேலே உள்ள முதல் படி தானியங்காக இல்லாமல் உங்களுடையதாக உள்ளது. எந்த அச்சுப்பொறியும் இல்லாமலேயே PDF கோப்பிற்கு அச்சிடுவது செயல்படும்.

### திரைப்பிடிப்புகள் அல்லது திரைப் பதிவுகள் எங்கு சேமிக்கப்படுகின்றன என்பதை நான் எப்படி மாற்றுவது?

சேமிக்கப்பட்ட திரைப்பிடிப்புகள் இயல்பாக `~/Pictures/Screenshots` க்குச் செல்லும். வேறொரு கோப்பகத்தைப் பயன்படுத்த, `~/.config/uwsm/env.d/` இன் கீழ் உள்ள ஒரு கோப்பில் (`~/.config/uwsm/env.d/capture` போன்ற) இதைச் சேர்க்கவும்:

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

திரைப் பதிவுகளுக்கும் `OMARCHY_SCREENRECORD_DIR` ஐப் பயன்படுத்தி அதையே செய்யலாம்.

Omasnap தனது திரைப்பிடிப்பு கோப்பகத்தைத் தானாகவே உருவாக்கும். திரைப் பதிவு கோப்பகத்தை நீங்களே உருவாக்கி, பின்னர் எந்தவொரு சூழல் மாற்றமும் நடைமுறைக்கு வர Omarchy ஐ மறுதொடக்கம் செய்யவும்.

### எனது Apple Studio Display இல் ஒலிபெருக்கிகள் + வெப்கேமை நான் எப்படிச் செயல்பட வைப்பது?

USB C ஐச் செருகினாலே அனைத்தும் செயல்படும் என்று நீங்கள் நினைப்பீர்கள், ஆனால் துரதிர்ஷ்டவசமாக அப்படி இல்லை. அது நம்பகமாகச் செயல்பட நான் கண்டறிந்த தீர்வு [WJESOG DisplayPort + USB-A => USB-C கேபிளைப்](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) பயன்படுத்துவதுதான். பின்னர் ஒலிபெருக்கிகளும் வெப்கேமும் கச்சிதமாகச் செயல்படும்.

வழக்கமான விசைப்பலகை பிரகாசப் பொத்தான்களைப் பயன்படுத்தி Apple Displays (Studio மற்றும் XDR இரண்டிற்கும்) க்கான உள்ளமைக்கப்பட்ட பிரகாசக் கட்டுப்பாடு Omarchy இல் உங்களுக்கு உள்ளது என்பதை நினைவில் கொள்ளவும்.

### அனைத்துக் கூடுதல் மென்பொருள்களையும் நான் எப்படி அகற்றுவது?

Obsidian அல்லது LibreOffice போன்ற நிரல்களோ அல்லது முன்பே நிறுவப்பட்ட பிற பொருட்களோ உங்களுக்கு வேண்டாம் என்றால், அவற்றை மிக எளிதாக அகற்றலாம்.

நிறுவப்பட்ட ஒவ்வொரு தொகுப்பையும் காண _அகற்று > தொகுப்பு_ என்பதை இயக்கவும். பின்னர் நீங்கள் அகற்ற விரும்பும் எந்தத் தொகுப்பையும் tab மூலம் தேர்ந்தெடுக்கலாம், தேர்ந்தெடுத்த அனைத்தையும் return மூலம் அகற்றத் தொடங்கலாம்.

நீங்கள் விரும்பாத முன்பே நிறுவப்பட்ட வலைப் பயன்பாடுகள் எதையும் அகற்ற Omarchy பட்டியலிலிருந்து _அகற்று > வலைப் பயன்பாடு_ என்பதைப் பயன்படுத்தலாம்.

அல்லது முன்பே நிறுவப்பட்ட அனைத்துக் கூடுதல்களையும் — வலைப் பயன்பாடுகள், TUI, மற்றும் விருப்பப் பயன்பாடுகள் — ஒரே முறையில் அகற்ற _அகற்று > முன்நிறுவல்கள்_ என்பதை இயக்கவும். அவற்றைத் தொடங்கிய ஹாட்கீகளும் அவற்றுடன் போய்விடும், எனவே `~/.config/hypr/bindings.lua` இல் உங்கள் சொந்தவற்றால் நிரப்புவதற்குச் சுத்தமான பிணைப்புகள் உங்களிடம் மீதமிருக்கும்.
