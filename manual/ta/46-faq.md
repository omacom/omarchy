# அடிக்கடி கேட்கப்படும் கேள்விகள்

### விசைப்பலகை தளவமைப்புகளுக்கு இடையே மாறுவது எப்படி?

உங்கள் `~/.config/hypr/input.lua` கோப்பைத் திருத்தி, `Left Alt + Right Alt` இல் தளவமைப்புகளுக்கு இடையே மாற இதைச் சேர்க்கவும்:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

நீங்கள் பல தளவமைப்புகளை உள்ளமைத்தவுடன் பட்டி உங்கள் தற்போதைய விசைப்பலகை தளவமைப்பைத் தானாகவே காட்டும் (அதைக் கிளிக் செய்தும் மாற்றலாம்).

### கடிகார வடிவமைப்பை 12 மணி நேர வடிவமைப்பிற்கு மாற்றுவது எப்படி?

12 மணி நேர வடிவமைப்புகள் உட்பட பொதுவான வடிவமைப்புகளுக்கு இடையே மாற பட்டியில் உள்ள கடிகாரத்தை வலது கிளிக் செய்யவும். வடிவமைப்பை நேரடியாகவும் அமைக்கலாம்:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

இது ஞாயிறு 10:55 AM என்று காட்டும்.

### எனது நேர மண்டலத்தை மாற்றுவது எப்படி?

Omarchy மெனுவில் _Setup > Region > Timezone_ ஐ இயக்கிப் பட்டியலிலிருந்து தேர்ந்தெடுக்கவும். நேர மண்டலம் சரியாக இருந்தும் கடிகாரமே தள்ளிப்போயிருந்தால், _Update > Time_ உங்களுக்காக நேர ஒத்திசைவை மறுதொடக்கம் செய்யும்.

### எனது DNS ஐ மாற்றுவது, எனது Wi-Fi ஐப் பகிர்வது, அல்லது எனது இணைப்பு வேகத்தைச் சரிபார்ப்பது எப்படி?

அவை அனைத்தும் [வலையமைப்பில்](35-networking.md) உள்ளன.

### எனது வட்டு எவ்வளவு வேகமானது என்று சரிபார்ப்பது எப்படி?

_Trigger > Speed Test > Disk Speed Test_ உங்கள் இயக்ககத்தில் நேரடி படிப்பு மற்றும் எழுத்து வேகத்தை அளவிடும், அல்லது முனையத்திலிருந்து `omarchy disk speedtest` என்று இயக்கவும்.

### அச்சுப்பொறியைச் சேர்ப்பது எப்படி?

அச்சிடுதல் ஏற்கனவே அமைக்கப்பட்டு இயங்கிக்கொண்டிருக்கிறது, ஒவ்வொரு அச்சுப்பொறியையும் app launcher (`Super + Space`) இல் உள்ள _Print Settings_ இலிருந்து நீங்களே சேர்க்கலாம்.

_Add_ ஐத் தேர்ந்தெடுத்து, அது தேடுவதற்குச் சிறிது நேரம் கொடுங்கள்: USB வழியாகச் சொருகப்பட்ட அச்சுப்பொறியும், பெரும்பாலான பிணைய அச்சுப்பொறிகளும் உங்களுக்காகக் கண்டறியப்படும். உங்களுடையது பட்டியலில் இல்லையென்றால், _Network Printer > Internet Printing Protocol (ipp)_ ஐத் தேர்ந்தெடுத்து அதன் முகவரியை உள்ளிடவும் — அது என்ன என்பதை அச்சுப்பொறியின் சொந்தக் காட்சித்திரை அல்லது அதன் வலைப் பக்கம் உங்களுக்குச் சொல்லும், வழக்கமாக `ipp/print` என்ற வரிசையுடன் `192.168.1.50` போன்ற ஒன்றாக இருக்கும். பிறகு _Forward_ ஒரு இயக்கியை வழங்கும், அங்கு நவீன அச்சுப்பொறி இயக்கி இல்லாத _IPP Everywhere_ சுயவிவரத்தில் சிறப்பாக வேலை செய்யும், பழைய ஒன்றுக்கு அந்த மாதிரியின் சொந்த இயக்கி தேவைப்படும்.

அச்சுப்பொறியை வலது கிளிக் செய்து, உங்கள் பயன்பாடுகள் முதலில் எதை நாட வேண்டும் என்பதைத் தேர்ந்தெடுக்க _Set as Default_ ஐயும், காகித அளவு, இருபுற அச்சு மற்றும் தரத்தை அமைக்க _Properties_ ஐயும் தேர்ந்தெடுக்கவும்.

பிணையத்தில் உள்ள அச்சுப்பொறிகள் சேர்க்கப்படாமலேயே தோன்றும் தானியங்கு கண்டறிதல், அது மறுவேலை செய்யப்படும்போது தற்காலிகமாக முடக்கப்பட்டுள்ளது, அதனால்தான் மேலே உள்ள முதல் படி தானியங்காக இல்லாமல் உங்களுடையதாக இருக்கிறது. எந்த அச்சுப்பொறியும் இல்லாமலேயே PDF கோப்பில் அச்சிடுவது வேலை செய்யும்.

### திரைப்பிடிப்புகள் அல்லது திரைப்பதிவுகள் சேமிக்கப்படும் இடத்தை மாற்றுவது எப்படி?

சேமிக்கப்பட்ட திரைப்பிடிப்புகள் இயல்பாக `~/Pictures/Screenshots` க்குச் செல்லும். வேறொரு கோப்பகத்தைப் பயன்படுத்த, `~/.config/uwsm/env.d/` இன் கீழ் உள்ள ஒரு கோப்பில் (`~/.config/uwsm/env.d/capture` போன்று) இதைச் சேர்க்கவும்:

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

`OMARCHY_SCREENRECORD_DIR` ஐப் பயன்படுத்தித் திரைப்பதிவுகளுக்கும் இதையே செய்யலாம்.

Omasnap அதன் திரைப்பிடிப்புக் கோப்பகத்தைத் தானாகவே உருவாக்கும். திரைப்பதிவுக் கோப்பகத்தை நீங்களே உருவாக்கி, பிறகு இரு சூழல் மாற்றங்களில் ஏதேனும் ஒன்று நடைமுறைக்கு வர Omarchy ஐ மறுதொடக்கம் செய்யவும்.

### எனது Apple Studio Display இல் ஒலிபெருக்கிகள் + webcam வேலை செய்ய வைப்பது எப்படி?

USB C ஐச் சொருகினாலே அனைத்தும் வேலை செய்ய வேண்டும் என்று நீங்கள் நினைப்பீர்கள், ஆனால் துரதிர்ஷ்டவசமாக அப்படி இல்லை. அது நம்பகமாக வேலை செய்ய நான் கண்டறிந்த தீர்வு [WJESOG DisplayPort + USB-A => USB-C கேபிளைப்](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) பயன்படுத்துவதுதான். பிறகு ஒலிபெருக்கிகளும் webcam உம் அருமையாக வேலை செய்யும்.

வழக்கமான விசைப்பலகை பிரகாசப் பொத்தான்களைப் பயன்படுத்தி Apple Displays (Studio மற்றும் XDR இரண்டும்) க்கான உள்ளமைக்கப்பட்ட பிரகாசக் கட்டுப்பாடு Omarchy இல் உங்களிடம் உள்ளது என்பதை நினைவில் கொள்ளவும்.

### அனைத்து கூடுதல் மென்பொருளையும் அகற்றுவது எப்படி?

Obsidian அல்லது LibreOffice போன்ற நிரல்கள் அல்லது முன்பே நிறுவப்பட்ட வேறு எதுவும் உங்களுக்கு வேண்டாம் என்றால், அதை மிக எளிதாக அகற்றலாம்.

நிறுவப்பட்ட ஒவ்வொரு தொகுப்பையும் பார்க்க _Remove > Package_ ஐ இயக்கவும். பிறகு நீங்கள் அகற்ற விரும்பும் எந்தத் தொகுப்பையும் tab ஐப் பயன்படுத்தித் தேர்ந்தெடுக்கலாம், நீங்கள் தேர்ந்தெடுத்த அனைத்தையும் return ஐப் பயன்படுத்தி அகற்றத் தொடங்கலாம்.

நீங்கள் விரும்பாத முன்பே நிறுவப்பட்ட எந்த வலைப் பயன்பாடுகளையும் அகற்ற Omarchy மெனுவிலிருந்து _Remove > Web App_ ஐயும் பயன்படுத்தலாம்.

அல்லது முன்பே நிறுவப்பட்ட அனைத்து கூடுதல்களையும் — வலைப் பயன்பாடுகள், TUIs, மற்றும் விருப்பப் பயன்பாடுகள் — ஒரே நேரத்தில் அகற்ற _Remove > Preinstalls_ ஐ இயக்கவும். அவற்றைத் தொடங்கிய விரைவு விசைகள் அவற்றுடன் போய்விடும், எனவே `~/.config/hypr/bindings.lua` இல் உங்கள் சொந்தவற்றால் நிரப்புவதற்குச் சுத்தமான பிணைப்புகள் உங்களிடம் எஞ்சியிருக்கும்.
