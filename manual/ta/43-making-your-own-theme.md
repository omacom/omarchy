# உங்கள் சொந்த தீமை உருவாக்குதல்

`~/.config/omarchy/themes` இல் உங்கள் சொந்த தீம்களைச் சேர்க்கலாம். ஏற்கனவே உள்ளவற்றில் ஒன்றை அடிப்படையாக நகலெடுத்து (`/usr/share/omarchy/themes` இல் பார்க்கவும்), பிறகு உங்கள் விருப்பப்படி மாற்றியமைக்கவும். உங்கள் தீம் அந்தக் கோப்புறைக்குள் இருக்கும் வரை, அது தீம் தேர்வு மெனுவில் சேர்க்கப்படும்.

நீங்கள் மாற்றியமைக்க வேண்டிய முக்கியக் கோப்பு `colors.toml` ஆகும். அது வரையறுக்கும் வண்ணத் தொகுப்புதான் பின்னர் terminal (Foot/Alacritty/Ghostty/Kitty), btop, Chromium, Hyprland, Neovim, Helix, VSCode, Obsidian மற்றும் முழு Omarchy shell (மேல் பட்டை, மெனு, அறிவிப்புகள், OSD மற்றும் பூட்டுத் திரை) ஆகியவற்றுக்கான உள்ளமைவுகளை உருவாக்கப் பயன்படுத்தப்படுகிறது.

அழகான GUI இடைமுகத்தைப் பயன்படுத்தி வண்ணங்களுடன் விளையாடவும் பின்னணிகளைத் தேடவும் ஒரு புதிய தீமை உருவாக்க, உள்ளடக்கப்பட்டுள்ள Aether பயன்பாட்டையும் நீங்கள் பயன்படுத்தலாம். `Super + Alt + Space` இல் உள்ள app grid இலிருந்து அதைத் தொடங்கினால் போதும்.

### நிறுவப்பட்ட தீமில் என்னென்ன இருக்கலாம்

`~/.config/omarchy/themes` இல் நீங்களே எழுதும் தீமில் நீங்கள் விரும்பும் எதுவும் இருக்கலாம் — அது உங்கள் கணினி, உங்கள் கோப்பு, Omarchy அவை அனைத்தையும் பயன்படுத்தும்.

`omarchy theme install` மூலம் வேறொருவரின் repo இலிருந்து நீங்கள் நிறுவும் தீம், வண்ணம் சார்ந்த அனைத்தையும் வைத்திருக்கும், ஆனால் உங்கள் கணினியில் code ஐ இயக்கும் சில கோப்புகளை இழக்கும்: எந்தவொரு `.lua` கோப்பும், terminal உள்ளமைவுகளும் (`alacritty.toml`, `foot.ini`, `ghostty.conf`, `kitty.conf`), மற்றும் `vscode.json`. ஒரு தீமின் `hyprland.lua` என்பது உள்நுழையும்போது உங்கள் compositor இயக்கும் Lua, ஒரு terminal உள்ளமைவு உங்கள் terminal தொடங்கும் நிரலைப் பெயரிடுகிறது, மற்றும் `vscode.json` நிறுவ வேண்டிய ஒரு VSCode நீட்டிப்பைப் பெயரிடுகிறது. ஒருவரின் தீமை நிறுவுவது உங்கள் desktop எப்படித் தோற்றமளிக்கிறது என்பதை மாற்ற வேண்டும், அது எதை இயக்குகிறது என்பதை ஒருபோதும் மாற்றக் கூடாது.

மற்ற அனைத்தும் தீம் ஆசிரியர் எழுதியபடியே சரியாகச் செயல்படும் — `btop.theme`, `chromium.theme`, `helix.toml`, `shell.toml`, பின்னணிகள் மற்றும் முன்னோட்டங்கள் அனைத்தும் வைத்திருக்கப்படும். நீக்கப்பட்டவை மட்டுமே உங்கள் கணினியில் `colors.toml` இலிருந்து மீண்டும் உருவாக்கப்படும்.

அந்தத் தீமுக்குள் அதற்கெனச் சொந்த git repo உள்ளதா என்பதை வைத்தே Omarchy இரண்டையும் வேறுபடுத்துகிறது, அதைத்தான் `omarchy theme install` clone செய்யும்போது விட்டுச் செல்கிறது. எனவே நீங்கள் எழுதிய தீம் உங்களுடையதாகவே இருக்கும், இணையத்திலிருந்து நீங்கள் இழுத்த ஒன்று வண்ணங்களாகவே இருக்கும்.

### வெளிர் பயன்முறை

நீங்கள் வெளிர் பயன்முறை தீம் ஒன்றை உருவாக்குகிறீர்கள் என்றால், உங்கள் `colors.toml` இன் மேற்பகுதியில் `mode = "light"` என அமைக்கவும். பின்னர் அது அனைத்துப் பயன்பாடுகளுக்கும் தானாகவே வெளிர் பயன்முறையுடன் இணைக்கப்படும். (உங்கள் தீமின் மூலத்தில் `light.mode` என்ற வெற்றுக் கோப்பைப் போடும் பழைய முறையும் இன்னும் செயல்படும்.)

### பூட்டுநீக்கப் படம்

`unlock.png` மற்றும் `preview-unlock.png` படங்களுடன் வழங்கப்படும் தீம்கள் _தோற்றம் > பூட்டுநீக்கு_ என்பதன் கீழ் பட்டியலிடப்படும். உங்கள் `unlock.png` முன்னுரிமையாக ஒரு transparent png ஆக இருக்க வேண்டும். மேலும் `omarchy plymouth preview` ஐப் பயன்படுத்தி முன்னோட்டப் படத்தை நீங்கள் உருவாக்கலாம்.

### Omarchy உள்ளடக்காத பயன்பாடுகளுக்கு தீம் அமைத்தல்

அந்தப் பட்டியலில் இல்லாத ஒரு பயன்பாட்டை நீங்கள் பயன்படுத்தினால், ஒரு template மூலம் அதற்கு தீம் அமைக்க Omarchy க்கு நீங்களே கற்றுக் கொடுக்கலாம். `~/.config/omarchy/themed/` இல், அது உருவாக்கும் உள்ளமைவின் பெயருடன் `.tpl` நீட்டிப்பைச் சேர்த்த பெயரில் ஒரு கோப்பைப் போட்டு, `{{ background }}`, `{{ foreground }}`, `{{ accent }}`, `{{ red }}`, `{{ color0 }}` முதல் `{{ color15 }}` வரை மற்றும் palette இன் மீதமுள்ளவற்றை placeholders ஆகப் பயன்படுத்தி உள்ளமைவை எழுதவும். ஒவ்வொரு முறை நீங்கள் தீம்களை மாற்றும்போதும், அந்தக் கோப்பு அந்தத் தீமின் வண்ணங்களுடன் மீண்டும் உருவாக்கப்படும்.

அந்தக் கோப்புறையில் நகலெடுக்க முழுமையாகக் கருத்துகள் இடப்பட்ட `alacritty.toml.tpl.sample` ஒன்று உள்ளது — நீங்கள் பயன்படுத்தக்கூடிய ஒவ்வொரு மாறியையும், அதோடு தங்கள் வண்ணங்களை `#` இல்லாமல் அல்லது decimal RGB ஆக விரும்பும் பயன்பாடுகளுக்கான `_strip` மற்றும் `_rgb` மாற்றிகளையும் அது பட்டியலிடுகிறது. உங்கள் templates Omarchy இன் சொந்த templates ஐ விட முன்னுரிமை பெறும், எனவே உள்ளமைக்கப்பட்ட ஒரு பயன்பாடு எப்படி தீம் செய்யப்படுகிறது என்பதை மீறவும் இதை நீங்கள் பயன்படுத்தலாம்.

### உங்கள் தீமை விநியோகித்தல்

உங்கள் தீமை மற்றவர்களும் பயன்படுத்தும் வகையில் விநியோகிக்க விரும்பினால், அதை GitHub போன்ற ஒரு பொது git server இல் வைக்க வேண்டும். பின்னர் மக்கள் அந்த URL ஐப் பயன்படுத்தி Omarchy மெனுவில் _நிறுவு > பாணி > தீம்_ வழியாக அதை நிறுவலாம். `omarchy-[themename]-theme` என்ற பெயரிடும் மரபைப் பின்பற்றுவது பரிந்துரைக்கப்படுகிறது, ஏனெனில் நிறுவிய பிறகு தீம் தேர்வு மெனுவில் தீம் வெறும் `[themename]` என்று சரியாகக் காட்டப்படும்.

மீதமுள்ள அந்த `[themename]` தீமின் directory பெயராக மாறுகிறது, எனவே அது Omarchy பாதுகாப்பாகக் கையாளக்கூடிய ஒன்றாக இருக்க வேண்டும்: அது ஒரு எழுத்து, ஒரு இலக்கம் அல்லது ஒரு underscore உடன் தொடங்க வேண்டும், மீதமுள்ள பகுதியில் எழுத்துகள், இலக்கங்கள், `.`, `_`, `+`, மற்றும் `-` இருக்கலாம். பெரிய எழுத்துகள் உங்களுக்காகச் சிறிய எழுத்துகளாக மாற்றப்படும், ஆனால் மற்ற எதுவும் — ஒரு இடைவெளி, ஒரு மேற்கோள் குறி, ஆங்கிலம் அல்லாத ஒரு எழுத்து — directory பெயராக மாற்றப்படாமல் நிறுவும் நேரத்தில் மறுக்கப்படும். எனவே `omarchy-tokyo-night-theme`, `omarchy-flexoki_light-theme`, மற்றும் `omarchy-c++-theme` ஆகிய அனைத்தும் நன்றாக நிறுவப்படும்.

ஒரு repo இலிருந்து அது நிறுவப்பட்டவுடன், அது கொண்டு வரும் எந்த `.lua`, terminal உள்ளமைவு அல்லது `vscode.json` உம் நீக்கப்படும் என்பதை நினைவில் கொள்ளவும், எனவே அவற்றைச் சுற்றி தீமை உருவாக்காதீர்கள்.

[omarchy-site repo](https://github.com/omacom-io/omarchy-site) க்கு ஒரு pull request அனுப்புவதன் மூலம் உங்கள் தீமை [கூடுதல் தீம்கள் பக்கத்தில்](https://omarchy.org/themes/) சேர்க்கலாம்.
