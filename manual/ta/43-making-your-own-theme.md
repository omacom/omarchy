# உங்கள் சொந்த தீமை உருவாக்குதல்

`~/.config/omarchy/themes`-இல் உங்கள் சொந்த தீம்களைச் சேர்க்கலாம். இருக்கும் ஒன்றை அடித்தளமாக நகலெடுங்கள் (`/usr/share/omarchy/themes`-இல் பாருங்கள்), பிறகு மகிழ்ச்சிக்கு ஏற்ப மாற்றுங்கள். உங்கள் தீம் அந்தக் கோப்புறைக்குள் இருக்கும் வரை, அது தீம் தேர்வு மெனுவில் சேர்க்கப்படும்.

நீங்கள் மாற்ற வேண்டிய முதன்மைக் கோப்பு `colors.toml`. அது வண்ணத் தொகுப்பை வரையறுக்கிறது, பிறகு அது முனையம் (Foot/Alacritty/Ghostty/Kitty), btop, Chromium, Hyprland, Neovim, Helix, VSCode, Obsidian, முழு Omarchy ஷெல் (மேல் பட்டை, மெனு, அறிவிப்புகள், OSD, பூட்டுத் திரை) ஆகியவற்றிற்கான உள்ளமைவுகளை உருவாக்கப் பயன்படுத்தப்படுகிறது.

வண்ணங்களுடன் விளையாடவும் பின்னணிகளைத் தேடவும் அழகான GUI இடைமுகத்தைக் கொண்டு ஒரு புதிய தீமை உருவாக்கச் சேர்க்கப்பட்ட Aether செயலியையும் பயன்படுத்தலாம். அதை `Super + Alt + Space`-இல் செயலிப் பட்டியலிலிருந்து தொடங்குங்கள்.

### நிறுவப்பட்ட தீம் என்ன கொண்டிருக்க முடியும்

`~/.config/omarchy/themes`-இல் நீங்களே எழுதிய தீம் விருப்பமான எதையும் கொண்டிருக்கலாம் — அது உங்கள் கணினி, உங்கள் கோப்பு, Omarchy அனைத்தையும் பயன்படுத்துகிறது.

`omarchy theme install` என்பதைக் கொண்டு வேறொருவரின் களஞ்சியத்திலிருந்து நீங்கள் நிறுவும் தீம் வண்ணமாக இருக்கும் எல்லாவற்றையும் வைத்துக்கொண்டு, உங்கள் கணினியில் குறியீட்டை இயக்கும் சில கோப்புகளை இழக்கிறது: எந்த `.lua` கோப்பும், முனைய உள்ளமைவுகள் (`alacritty.toml`, `foot.ini`, `ghostty.conf`, `kitty.conf`), `vscode.json`. ஒரு தீமின் `hyprland.lua` என்பது உள்நுழையும்போது உங்கள் கம்போசிட்டர் இயக்கும் Lua, ஒரு முனைய உள்ளமைவு உங்கள் முனையம் தொடங்கும் நிரலைப் பெயரிடுகிறது, `vscode.json` நிறுவ வேண்டிய VSCode நீட்டிப்பைப் பெயரிடுகிறது. வேறொருவரின் தீமை நிறுவுவது உங்கள் டெஸ்க்டாப் எப்படித் தெரிகிறது என்பதை மாற்ற வேண்டும், அது என்ன இயக்குகிறது என்பதையல்ல.

மற்றவை அனைத்தும் தீம் ஆசிரியர் எழுதியது போலவே வேலை செய்கின்றன — `btop.theme`, `chromium.theme`, `helix.toml`, `icons.theme`, `shell.toml`, பின்னணிகளும் முன்னோட்டங்களும் அனைத்தும் வைக்கப்படுகின்றன. நீக்கப்பட்டவை மட்டும் உங்கள் கணினியில் `colors.toml`-இலிருந்து மீண்டும் உருவாக்கப்படும்.

Omarchy இரண்டையும் வேறுபடுத்துவது தீமிற்குள் அதற்குச் சொந்தமான git களஞ்சியம் இருக்கிறதா என்பதைக் கொண்டுதான், அது `omarchy theme install` குளோன் செய்யும்போது விட்டுச் செல்வது. எனவே நீங்கள் எழுதிய தீம் உங்களுடையதாகவே இருக்கும், இணையத்திலிருந்து இழுத்த ஒன்று வண்ணங்களாகவே இருக்கும்.

### ஒளி பயன்முறை

நீங்கள் ஓர் ஒளி பயன்முறை தீமை உருவாக்குகிறீர்கள் என்றால், உங்கள் `colors.toml`-இன் மேலே `mode = "light"` என்று அமைக்கவும். பிறகு அது எல்லாச் செயலிகளுக்கும் ஒளி பயன்முறையுடன் தானாகவே இணைக்கப்படும். (உங்கள் தீமின் அடிப்படையில் `light.mode` என்ற வெற்றுக் கோப்பைப் போடும் பழைய வழியும் இன்னும் வேலை செய்கிறது.)

### சின்ன வண்ணங்கள்

கோப்பு மேலாளர் சின்னங்களை உங்கள் தீமுடன் வண்ணப் பொருத்தம் செய்ய விரும்பினால், நீங்கள் பயன்படுத்த விரும்பும் சின்னத் தொகுப்பின் பெயருடன் `icons.theme` என்ற கோப்பைச் சேர்க்கவும். இயல்பாக, விருப்பங்கள்: `Yaru Yaru-blue Yaru-dark Yaru-magenta Yaru-olive Yaru-prussiangreen Yaru-purple Yaru-red Yaru-sage Yaru-wartybrown Yaru-yellow`.

### திறப்புப் படம்

`unlock.png` மற்றும் `preview-unlock.png` படங்களுடன் வழங்கப்படும் தீம்கள் _பாணி > திற_ என்பதன் கீழ் பட்டியலிடப்படும். உங்கள் `unlock.png` முன்னுரிமையாக ஒரு ஒளிபுகும் png ஆக இருக்க வேண்டும். `omarchy plymouth preview` என்பதைக் கொண்டு முன்னோட்டப் படத்தை உருவாக்கலாம்.

### Omarchy உள்ளடக்காத செயலிகளுக்குத் தீம் வைத்தல்

அந்தப் பட்டியலில் இல்லாத செயலியைப் பயன்படுத்தினால், ஒரு வார்ப்புருவைக் கொண்டு அதற்குத் தீம் வைக்க Omarchy-க்கு நீங்களே கற்பிக்கலாம். அது உருவாக்கும் உள்ளமைவின் பெயருடன் ஒரு `.tpl` நீட்டிப்பைச் சேர்த்து `~/.config/omarchy/themed/`-இல் ஒரு கோப்பைப் போட்டு, `{{ background }}`, `{{ foreground }}`, `{{ accent }}`, `{{ red }}`, `{{ color0 }}` முதல் `{{ color15 }}` வரை, மற்றும் மீதி வண்ணத்தட்டை இடப்பெயர்வுகளாகக் கொண்டு உள்ளமைவை எழுதுங்கள். ஒவ்வொரு முறை தீம்களை மாற்றும்போதும், கோப்பு அந்த தீமின் வண்ணங்களுடன் மீண்டும் உருவாக்கப்படும்.

அந்தக் கோப்புறையில் நகலெடுக்க முழுமையாகக் கருத்து தெரிவிக்கப்பட்ட `alacritty.toml.tpl.sample` உள்ளது — அது நீங்கள் பயன்படுத்தக்கூடிய ஒவ்வொரு மாறியையும், நிறங்களை `#` இல்லாமலோ தசம RGB-ஆகவோ விரும்பும் செயலிகளுக்கான `_strip` மற்றும் `_rgb` மாற்றிகளையும் பட்டியலிடுகிறது. உங்கள் வார்ப்புருக்கள் Omarchy-இன் சொந்த வார்ப்புருக்களை விட முன்னுரிமை பெறுகின்றன, எனவே உள்ளமைந்த செயலி எப்படித் தீம் வைக்கப்படுகிறது என்பதை மாற்றவும் இதைப் பயன்படுத்தலாம்.

### உங்கள் தீமை விநியோகித்தல்

மற்றவர்கள் பயன்படுத்தும் வகையில் உங்கள் தீமை விநியோகிக்க விரும்பினால், அதை GitHub போன்ற பொது git சேவையகத்தில் வைக்க வேண்டும். பிறகு மக்கள் அந்த URL-ஐப் பயன்படுத்தி Omarchy மெனுவில் _நிறுவு > பாணி > தீம்_ என்பதைக் கொண்டு அதை நிறுவலாம். `omarchy-[themename]-theme` என்ற பெயரிடும் மரபைப் பின்பற்றப் பரிந்துரைக்கப்படுகிறது, நிறுவிய பிறகு தீம் தேர்வு மெனுவில் தீம் சரியாக `[themename]` என்று மட்டுமே தோன்றும்.

அந்த மீதி `[themename]` தீமின் கோப்பகப் பெயராகிறது, எனவே அது Omarchy பாதுகாப்பாகக் கையாளக்கூடிய ஒன்றாக இருக்க வேண்டும்: அது ஓர் எழுத்து, இலக்கம் அல்லது அடிக்கோடுடன் தொடங்க வேண்டும், மீதி எழுத்துகள், இலக்கங்கள், `.`, `_`, `+`, `-` ஆகியவற்றைக் கொண்டிருக்கலாம். பெரிய எழுத்துகள் உங்களுக்காகச் சிறிய எழுத்துகளாக்கப்படுகின்றன, ஆனால் வேறு எதுவும் — ஒரு இடைவெளி, ஒரு மேற்கோள், ஆங்கிலமல்லாத எழுத்து — கோப்பகப் பெயராக மாற்றப்படுவதற்குப் பதிலாக நிறுவும் நேரத்தில் நிராகரிக்கப்படும். எனவே `omarchy-tokyo-night-theme`, `omarchy-flexoki_light-theme`, `omarchy-c++-theme` அனைத்தும் நன்றாக நிறுவப்படும்.

ஒரு களஞ்சியத்திலிருந்து நிறுவப்பட்டவுடன், அது அனுப்பும் எந்த `.lua`, முனைய உள்ளமைவு அல்லது `vscode.json` நீக்கப்படும் என்பதை நினைவில் கொள்ளுங்கள், எனவே தீமை அவற்றைச் சுற்றிக் கட்டாதீர்கள்.

[omarchy-site களஞ்சியத்திற்கு](https://github.com/omacom-io/omarchy-site) ஒரு pull request அனுப்புவதன் மூலம் உங்கள் தீமை [கூடுதல் தீம்கள் பக்கத்தில்](https://omarchy.org/themes/) சேர்க்கலாம்.
