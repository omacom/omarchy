# உங்கள் சொந்த தீமை உருவாக்குதல்

உங்கள் சொந்த தீம்களை `~/.config/omarchy/themes` இல் சேர்க்கலாம். ஏற்கனவே உள்ள ஒன்றை அடிப்படையாக நகலெடுத்து ( `/usr/share/omarchy/themes` இல் பார்க்கவும்), பிறகு உங்கள் விருப்பப்படி மாற்றியமைக்கவும். உங்கள் தீம் அந்தக் கோப்புறையின் உள்ளே இருக்கும் வரை, அது தீம் தேர்வு மெனுவில் சேர்க்கப்படும்.

நீங்கள் முக்கியமாக மாற்ற வேண்டிய கோப்பு `colors.toml`. அதுதான் வண்ணத் தொகுப்பை வரையறுக்கிறது; பிறகு அது terminal (Foot/Alacritty/Ghostty/Kitty), btop, Chromium, Hyprland, Neovim, Helix, VSCode, Obsidian மற்றும் முழு Omarchy shell (மேல் பட்டை, மெனு, அறிவிப்புகள், OSD மற்றும் lock screen) ஆகியவற்றுக்கான உள்ளமைவுகளை உருவாக்கப் பயன்படுகிறது.

சேர்க்கப்பட்டுள்ள Aether பயன்பாட்டையும் பயன்படுத்தி, வண்ணங்களோடு விளையாடவும் பின்னணிகளைத் தேடவும் அழகான GUI இடைமுகத்தைக் கொண்டு புதிய தீமை உருவாக்கலாம். `Super + Alt + Space` இல் உள்ள app grid இலிருந்து அதைத் தொடங்கவும்.

### நிறுவப்பட்ட தீம் எவற்றைக் கொண்டிருக்கலாம்

`~/.config/omarchy/themes` இல் நீங்களே எழுதும் தீம் நீங்கள் விரும்பும் எதையும் கொண்டிருக்கலாம் — இது உங்கள் கணினியும் உங்கள் கோப்பும், Omarchy அனைத்தையும் பயன்படுத்தும்.

வேறொருவரின் repo இலிருந்து `omarchy theme install` கொண்டு நிறுவும் தீம், வண்ணம் சார்ந்த அனைத்தையும் வைத்திருக்கும்; உங்கள் கணினியில் code ஐ இயக்கக்கூடிய சில கோப்புகளை இழக்கும்: எந்த `.lua` கோப்பும், terminal உள்ளமைவுகளும் (`alacritty.toml`, `foot.ini`, `ghostty.conf`, `kitty.conf`), மற்றும் `vscode.json`. ஒரு தீமின் `hyprland.lua` என்பது நீங்கள் உள்நுழையும்போது உங்கள் compositor இயக்கும் Lua; terminal உள்ளமைவு உங்கள் terminal எந்த program ஐத் தொடங்கும் என்பதைப் பெயரிடுகிறது; `vscode.json` நிறுவ வேண்டிய VSCode நீட்டிப்பைப் பெயரிடுகிறது. வேறொருவரின் தீமை நிறுவுவது உங்கள் desktop எப்படி இருக்கும் என்பதை மாற்ற வேண்டுமே தவிர, அது எதை இயக்கும் என்பதை ஒருபோதும் மாற்றக்கூடாது.

மற்ற அனைத்தும் தீம் ஆசிரியர் எழுதியபடியே சரியாகச் செயல்படும் — `btop.theme`, `chromium.theme`, `helix.toml`, `icons.theme`, `shell.toml`, பின்னணிகள் மற்றும் முன்னோட்டங்கள் அனைத்தும் வைக்கப்படும். நீக்கப்பட்டவை மட்டுமே உங்கள் கணினியில் `colors.toml` இலிருந்து மீண்டும் உருவாக்கப்படும்.

தீமுக்கு உள்ளே அதன் சொந்த git repo உள்ளதா என்பதைக் கொண்டு Omarchy இவ்விரண்டையும் வேறுபடுத்துகிறது; `omarchy theme install` clone செய்யும்போது அதைதான் விட்டுச் செல்கிறது. எனவே நீங்கள் எழுதிய தீம் உங்களுடையதாகவே இருக்கும்; இணையத்திலிருந்து எடுத்த தீம் வண்ணங்களாகவே இருக்கும்.

### Light mode

Light mode தீமை உருவாக்குகிறீர்கள் என்றால், உங்கள் `colors.toml` இன் மேலே `mode = "light"` என அமைக்கவும். பிறகு அது அனைத்து apps க்கும் தானாகவே light mode உடன் இணைக்கப்படும். (உங்கள் தீமின் root இல் `light.mode` என்ற வெற்றுக் கோப்பை விடும் பழைய முறையும் இன்னும் செயல்படும்.)

### Icon வண்ணங்கள்

File manager icon களை உங்கள் தீமுடன் வண்ணப் பொருத்தம் செய்ய விரும்பினால், நீங்கள் பயன்படுத்த விரும்பும் icon தொகுப்பின் பெயருடன் `icons.theme` என்ற கோப்பைச் சேர்க்கவும். இயல்பாக, விருப்பங்கள் இவை: `Yaru Yaru-blue Yaru-dark Yaru-magenta Yaru-olive Yaru-prussiangreen Yaru-purple Yaru-red Yaru-sage Yaru-wartybrown Yaru-yellow`.

### Unlock படம்

`unlock.png` மற்றும் `preview-unlock.png` படங்களுடன் வழங்கப்படும் தீம்கள் _Appearance > Unlock_ இன் கீழ் பட்டியலிடப்படும். உங்கள் `unlock.png` முன்னுரிமையாக transparent png ஆக இருக்க வேண்டும். `omarchy plymouth preview` ஐப் பயன்படுத்தி முன்னோட்டப் படத்தை உருவாக்கலாம்.

### Omarchy உள்ளடக்காத apps ஐ தீம் செய்தல்

அந்தப் பட்டியலில் இல்லாத app ஐப் பயன்படுத்தினால், ஒரு template ஐக் கொண்டு அதைத் தீம் செய்ய Omarchy க்கு நீங்களே கற்பிக்கலாம். அது உருவாக்கும் config இன் பெயருடன் `.tpl` நீட்டிப்பைக் கொண்ட கோப்பை `~/.config/omarchy/themed/` இல் விட்டு, `{{ background }}`, `{{ foreground }}`, `{{ accent }}`, `{{ red }}`, `{{ color0 }}` முதல் `{{ color15 }}` வரை மற்றும் மீதமுள்ள palette ஐ placeholders ஆகக் கொண்டு config ஐ எழுதவும். ஒவ்வொரு முறை நீங்கள் தீம்களை மாற்றும்போதும், கோப்பு அந்த தீமின் வண்ணங்களுடன் மீண்டும் உருவாக்கப்படும்.

அந்தக் கோப்புறையில் முழுமையாகக் குறிப்புகளுடன் கூடிய `alacritty.toml.tpl.sample` உள்ளது; அதிலிருந்து நகலெடுக்கலாம் — நீங்கள் பயன்படுத்தக்கூடிய ஒவ்வொரு variable ஐயும், `#` இல்லாமல் வண்ணங்களை விரும்பும் அல்லது decimal RGB ஆக விரும்பும் apps க்கான `_strip` மற்றும் `_rgb` modifiers ஐயும் அது பட்டியலிடுகிறது. உங்கள் templates Omarchy இன் சொந்த templates ஐ விட முன்னுரிமை பெறும்; எனவே built-in app எப்படி தீம் செய்யப்படுகிறது என்பதை மீறவும் இதைப் பயன்படுத்தலாம்.

### உங்கள் தீமை விநியோகித்தல்

மற்றவர்கள் பயன்படுத்தும் வகையில் உங்கள் தீமை விநியோகிக்க விரும்பினால், அதை GitHub போன்ற பொது git server இல் வைக்க வேண்டும். பிறகு அந்த URL ஐப் பயன்படுத்தி Omarchy மெனுவில் _Install > Style > Theme_ வழியாக மக்கள் அதை நிறுவலாம். `omarchy-[themename]-theme` என்ற பெயரிடும் மரபைப் பின்பற்றுவது பரிந்துரைக்கப்படுகிறது; ஏனெனில் நிறுவிய பிறகு தீம் தேர்வு மெனுவில் தீம் `[themename]` என்று மட்டுமே சரியாகக் காட்டப்படும்.

மீதமுள்ள அந்த `[themename]` தான் தீமின் directory பெயராக மாறுகிறது; எனவே Omarchy பாதுகாப்பாக அங்கும் இங்கும் கொடுக்கக்கூடிய ஒன்றாக அது இருக்க வேண்டும்: அது ஒரு எழுத்து, ஒரு இலக்கம் அல்லது underscore உடன் தொடங்க வேண்டும்; மீதியில் எழுத்துகள், இலக்கங்கள், `.`, `_`, `+` மற்றும் `-` இருக்கலாம். பெரிய எழுத்துகள் உங்களுக்காகச் சிறிய எழுத்துகளாக மாற்றப்படும்; ஆனால் வேறு எதுவும் — இடைவெளி, மேற்கோள் குறி, ஆங்கிலம் அல்லாத எழுத்து — directory பெயராக மாற்றப்படாமல் நிறுவும் நேரத்திலேயே மறுக்கப்படும். எனவே `omarchy-tokyo-night-theme`, `omarchy-flexoki_light-theme` மற்றும் `omarchy-c++-theme` அனைத்தும் நன்றாக நிறுவப்படும்.

Repo இலிருந்து நிறுவப்பட்ட பிறகு, அது கொண்டுவரும் எந்த `.lua`, terminal config அல்லது `vscode.json` உம் நீக்கப்படும் என்பதை நினைவில் கொள்ளவும்; எனவே அவற்றைச் சுற்றி தீமை உருவாக்காதீர்கள்.

[the omarchy-site repo](https://github.com/omacom-io/omarchy-site) க்கு pull request அனுப்புவதன் மூலம் உங்கள் தீமை [கூடுதல் தீம்கள் பக்கத்தில்](https://omarchy.org/themes/) சேர்க்கச் செய்யலாம்.
