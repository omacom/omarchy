# உங்கள் சொந்த தீமை உருவாக்குதல்

`~/.config/omarchy/themes` இல் உங்கள் சொந்த தீம்களைச் சேர்க்கலாம். ஏற்கனவே உள்ள ஒன்றை அடிப்படையாக நகலெடுத்து ( `/usr/share/omarchy/themes` இல் பார்க்கவும்), பிறகு உங்கள் விருப்பத்திற்கு ஏற்ப மாற்றியமைத்தால் போதும். உங்கள் தீம் அந்தக் கோப்புறைக்குள் இருக்கும் வரை, அது தீம் தேர்வு மெனுவில் சேர்க்கப்படும்.

நீங்கள் முக்கியமாக மாற்றியமைக்க வேண்டிய கோப்பு `colors.toml` ஆகும். அதுதான் வண்ணத் தொகுப்பை வரையறுக்கிறது; அதிலிருந்து terminal (Foot/Alacritty/Ghostty/Kitty), btop, Chromium, Hyprland, Neovim, Helix, VSCode, Obsidian, Qt பயன்பாடுகள், keyboard backlight, input method, screen-share picker, app icons, பல AI கருவிகள் (Claude, Pi, Hermes, T3 Code, Herdr) மற்றும் முழு Omarchy shell (top bar, menu, notifications, OSD மற்றும் lock screen) ஆகியவற்றுக்கான உள்ளமைவுகள் உருவாக்கப்படும்.

வண்ணங்களுடன் விளையாடவும் பின்னணிகளைத் தேடவும் இனிமையான GUI இடைமுகத்தைப் பயன்படுத்தி புதிய தீம் உருவாக்க, உடன் வரும் Aether பயன்பாட்டையும் பயன்படுத்தலாம். `Super + Alt + Space` இல் உள்ள app grid இலிருந்து அதைத் தொடங்கினால் போதும்.

### நிறுவப்பட்ட தீம் எவற்றைக் கொண்டிருக்கலாம்

`~/.config/omarchy/themes` இல் நீங்களே எழுதும் தீம் நீங்கள் விரும்பும் எதையும் கொண்டிருக்கலாம் — இது உங்கள் கணினி மற்றும் உங்கள் கோப்பு, அவை அனைத்தையும் Omarchy செயல்படுத்தும்.

`omarchy theme install` மூலம் வேறொருவரின் repo-விலிருந்து நீங்கள் நிறுவும் தீம் வண்ணம் சார்ந்த அனைத்தையும் தக்கவைத்துக்கொள்கிறது, உங்கள் கணினியில் குறியீட்டை இயக்கக்கூடிய சில கோப்புகளை இழக்கிறது: எந்த `.lua` கோப்பும், terminal உள்ளமைவுகளும் (`alacritty.toml`, `foot.ini`, `ghostty.conf`, `kitty.conf`), மற்றும் `vscode.json`. ஒரு தீமின் `hyprland.lua` என்பது உள்நுழையும்போது உங்கள் compositor இயக்கும் Lua, terminal உள்ளமைவு உங்கள் terminal தொடங்கும் நிரலைப் பெயரிடுகிறது, `vscode.json` நிறுவ வேண்டிய VSCode நீட்டிப்பைப் பெயரிடுகிறது. வேறொருவரின் தீமை நிறுவுவது உங்கள் desktop எப்படி இருக்கிறது என்பதை மாற்ற வேண்டுமே தவிர, அது எதை இயக்குகிறது என்பதை ஒருபோதும் மாற்றக்கூடாது.

மற்ற அனைத்தும் தீம் ஆசிரியர் எழுதியபடியே சரியாகச் செயல்படும் — `btop.theme`, `chromium.theme`, `helix.toml`, `shell.toml`, பின்னணிகள் மற்றும் முன்னோட்டங்கள் அனைத்தும் தக்கவைக்கப்படும். நீக்கப்பட்டவை மட்டுமே உங்கள் கணினியில் `colors.toml` இலிருந்து மீண்டும் உருவாக்கப்படும்.

ஒரு தீமுக்கு அதன் சொந்த git repo உள்ளே இருக்கிறதா என்பதை வைத்து Omarchy இவ்விரண்டையும் வேறுபடுத்துகிறது; `omarchy theme install` clone செய்யும்போது விட்டுச்செல்வது அதுதான். எனவே நீங்கள் எழுதிய தீம் உங்களுடையதாகவே இருக்கும், இணையத்திலிருந்து நீங்கள் எடுத்த ஒன்று வண்ணங்களாக மட்டுமே இருக்கும்.

### Light mode

நீங்கள் light mode தீம் உருவாக்குகிறீர்கள் என்றால், உங்கள் `colors.toml` இன் மேலே `mode = "light"` என அமைக்கவும். பிறகு அது எல்லா பயன்பாடுகளுக்கும் light mode உடன் தானாகவே இணைக்கப்படும். (உங்கள் தீமின் மூலத்தில் `light.mode` என்ற வெற்றுக் கோப்பைப் போடும் பழைய முறையும் இன்னும் செயல்படும்.)

### Boot மற்றும் login திரைகள்

boot நேரத்தில் drive கடவுச்சொல்லைக் கேட்கும் திரையும், login திரையும், உங்கள் தீமின் `background` மீது அதன் `accent` வண்ணத்தில் Omarchy லோகோவை வரைகின்றன; கடவுச்சொல் புலம் அதன் `foreground` இலும், தவறான கடவுச்சொல்லுக்கு `red` இலும் இருக்கும். அவற்றுக்காக கூடுதலாக எதையும் அனுப்ப வேண்டியதில்லை: Omarchy இனி ஒரு தீமின் `unlock.png` அல்லது `preview-unlock.png` ஐப் பயன்படுத்துவதில்லை. Apple Silicon Macs இல், drive கடவுச்சொல் திரை தீம் எதுவாக இருந்தாலும் Omarchy இன் இயல்புநிலை தோற்றத்தையே தக்கவைத்துக்கொள்கிறது.

### Omarchy உள்ளடக்காத பயன்பாடுகளைத் தீம் செய்தல்

அந்தப் பட்டியலில் இல்லாத பயன்பாட்டை நீங்கள் பயன்படுத்தினால், ஒரு template மூலம் அதைத் தீம் செய்ய Omarchy-க்கு நீங்களே கற்பிக்கலாம். அது உருவாக்கும் உள்ளமைவின் பெயருடன் `.tpl` நீட்டிப்பைச் சேர்த்து பெயரிடப்பட்ட கோப்பை `~/.config/omarchy/themed/` இல் போட்டு, `{{ background }}`, `{{ foreground }}`, `{{ accent }}`, `{{ red }}`, `{{ color0 }}` முதல் `{{ color15 }}` வரையும், palette இன் மீதியையும் placeholders ஆகப் பயன்படுத்தி உள்ளமைவை எழுதவும். நீங்கள் ஒவ்வொரு முறை தீம்களை மாற்றும்போதும், அந்தக் கோப்பு அந்தத் தீமின் வண்ணங்களுடன் மீண்டும் உருவாக்கப்படும்.

அந்தக் கோப்புறையில் முழுமையாகக் கருத்துகளுடன் கூடிய `alacritty.toml.tpl.sample` ஒன்று இருக்கிறது, அதிலிருந்து நகலெடுக்கலாம் — நீங்கள் பயன்படுத்தக்கூடிய ஒவ்வொரு மாறியையும், தங்கள் வண்ணங்களை `#` இல்லாமல் அல்லது தசம RGB ஆக விரும்பும் பயன்பாடுகளுக்கான `_strip` மற்றும் `_rgb` மாற்றிகளையும் அது பட்டியலிடுகிறது. உங்கள் templates Omarchy இன் சொந்த templates ஐ விட முன்னுரிமை பெறுகின்றன, எனவே உள்ளமைக்கப்பட்ட பயன்பாடு எப்படித் தீம் செய்யப்படுகிறது என்பதை மேலெழுதவும் இதைப் பயன்படுத்தலாம்.

### உங்கள் தீமை விநியோகித்தல்

மற்றவர்கள் பயன்படுத்தும் வகையில் உங்கள் தீமை விநியோகிக்க விரும்பினால், அதை GitHub போன்ற பொதுவான git server இல் வைக்க வேண்டும். பிறகு மக்கள் அந்த URL ஐப் பயன்படுத்தி Omarchy மெனுவில் _Install > Style > Theme_ மூலம் அதை நிறுவலாம். `omarchy-[themename]-theme` என்ற பெயரிடும் மரபைப் பின்பற்றுவது பரிந்துரைக்கப்படுகிறது, ஏனெனில் நிறுவிய பிறகு தீம் தேர்வு மெனுவில் தீம் வெறும் `[themename]` என்று சரியாகக் காண்பிக்கும்.

எஞ்சிய அந்த `[themename]` தீமின் directory பெயராக மாறுகிறது, எனவே அது Omarchy பாதுகாப்பாகப் புழக்கத்தில் விடக்கூடிய ஒன்றாக இருக்க வேண்டும்: அது ஒரு எழுத்து, இலக்கம் அல்லது underscore உடன் தொடங்க வேண்டும், மீதிப் பகுதியில் எழுத்துகள், இலக்கங்கள், `.`, `_`, `+` மற்றும் `-` இருக்கலாம். பெரிய எழுத்துகள் உங்களுக்காகச் சிறிய எழுத்துகளாக மாற்றப்படும், ஆனால் வேறு எதுவும் — இடைவெளி, மேற்கோள் குறி, ஆங்கிலம் அல்லாத எழுத்து — directory பெயராக மாற்றப்படாமல் நிறுவும் நேரத்திலேயே மறுக்கப்படும். எனவே `omarchy-tokyo-night-theme`, `omarchy-flexoki_light-theme` மற்றும் `omarchy-c++-theme` அனைத்தும் சிக்கலின்றி நிறுவப்படும்.

repo-விலிருந்து நிறுவப்பட்டதும், அது அனுப்பும் எந்த `.lua`, terminal உள்ளமைவு அல்லது `vscode.json` உம் நீக்கப்படும் என்பதை நினைவில் கொள்ளுங்கள், எனவே தீமை அவற்றைச் சுற்றிக் கட்டமைக்காதீர்கள்.

[omarchy-site repo](https://github.com/omacom-io/omarchy-site) இற்கு pull request அனுப்புவதன் மூலம் உங்கள் தீமை [கூடுதல் தீம்கள் பக்கத்தில்](https://omarchy.org/themes/) சேர்க்கலாம்.
