# உங்கள் சொந்த தீமை உருவாக்குதல்

உங்கள் சொந்த தீம்களை `~/.config/omarchy/themes` இல் சேர்க்கலாம். ஏற்கனவே உள்ளவற்றில் ஒன்றை அடிப்படையாக நகலெடுத்துக் கொள்ளுங்கள் (`/usr/share/omarchy/themes` இல் பாருங்கள்), பிறகு உங்கள் விருப்பப்படி மாற்றியமையுங்கள். உங்கள் தீம் அந்தக் கோப்புறைக்குள் இருக்கும் வரை, அது தீம் தேர்வு மெனுவில் சேர்க்கப்படும்.

நீங்கள் முக்கியமாக மாற்ற வேண்டிய கோப்பு `colors.toml`. அது வரையறுக்கும் வண்ணத் தொகுப்புதான் பிறகு terminal (Foot/Alacritty/Ghostty/Kitty), btop, Chromium, Hyprland, Neovim, Helix, VSCode, Obsidian, Qt apps, விசைப்பலகை பின்னொளி, உள்ளீட்டு முறை, screen-share picker, app ஐகான்கள், பல AI கருவிகள் (Claude, Pi, Hermes, T3 Code, Herdr), மற்றும் முழு Omarchy shell (மேல் பட்டி, மெனு, அறிவிப்புகள், OSD, மற்றும் பூட்டுத் திரை) ஆகியவற்றுக்கான உள்ளமைவுகளை உருவாக்கப் பயன்படுகிறது.

சேர்க்கப்பட்டுள்ள Aether application-ஐப் பயன்படுத்தி, வண்ணங்களுடன் விளையாடவும் பின்னணிகளைத் தேடவும் ஒரு அழகான GUI இடைமுகத்தின் மூலம் புதிய தீமையும் உருவாக்கலாம். `Super + Alt + Space` இல் உள்ள app grid இலிருந்து அதைத் தொடங்குங்கள்.

### நிறுவப்பட்ட தீமில் என்னென்ன இருக்கலாம்

`~/.config/omarchy/themes` இல் நீங்களே எழுதும் தீமில் நீங்கள் விரும்பும் எதுவும் இருக்கலாம் — இது உங்கள் கணினி, உங்கள் கோப்பு, Omarchy அனைத்தையும் பயன்படுத்தும்.

`omarchy theme install` மூலம் வேறொருவரின் repo இலிருந்து நிறுவும் தீம், வண்ணம் சார்ந்த அனைத்தையும் வைத்துக் கொள்ளும், உங்கள் கணினியில் code ஐ இயக்கும் ஒரு சில கோப்புகளை இழக்கும்: எந்த `.lua` கோப்பும், terminal உள்ளமைவுகளும் (`alacritty.toml`, `foot.ini`, `ghostty.conf`, `kitty.conf`), மற்றும் `vscode.json`. ஒரு தீமின் `hyprland.lua` என்பது உள்நுழையும்போது உங்கள் compositor இயக்கும் Lua, ஒரு terminal உள்ளமைவு உங்கள் terminal தொடங்கும் program ஐக் குறிப்பிடுகிறது, மற்றும் `vscode.json` நிறுவ வேண்டிய VSCode நீட்டிப்பைக் குறிப்பிடுகிறது. வேறொருவரின் தீமை நிறுவுவது உங்கள் desktop எப்படித் தோற்றமளிக்கிறது என்பதை மாற்ற வேண்டும், அது எதை இயக்குகிறது என்பதை ஒருபோதும் மாற்றக் கூடாது.

மற்ற அனைத்தும் தீம் ஆசிரியர் எழுதியபடியே சரியாகச் செயல்படும் — `btop.theme`, `chromium.theme`, `helix.toml`, `shell.toml`, பின்னணிகள் மற்றும் முன்னோட்டங்கள் அனைத்தும் வைத்துக் கொள்ளப்படும். நீக்கப்பட்டவை மட்டுமே உங்கள் கணினியில் `colors.toml` இலிருந்து மீண்டும் உருவாக்கப்படும்.

ஒரு தீமுக்கு அதற்குள்ளேயே சொந்த git repo இருக்கிறதா என்பதை வைத்து Omarchy இரண்டையும் வேறுபடுத்துகிறது, `omarchy theme install` clone செய்யும்போது விட்டுச் செல்வது அதுதான். எனவே நீங்கள் எழுதிய தீம் உங்களுடையதாகவே இருக்கும், இணையத்திலிருந்து நீங்கள் எடுத்த ஒன்று வண்ணங்களாகவே இருக்கும்.

### Light mode

நீங்கள் light mode தீமை உருவாக்குகிறீர்கள் என்றால், உங்கள் `colors.toml` இன் மேலே `mode = "light"` என அமையுங்கள். பிறகு அது அனைத்து app-களுக்கும் தானாகவே light mode உடன் இணைக்கப்படும். (உங்கள் தீமின் root இல் `light.mode` என்ற வெற்றுக் கோப்பைப் போடும் பழைய முறையும் இன்னும் செயல்படும்.)

### Unlock image

`unlock.png` மற்றும் `preview-unlock.png` படங்களுடன் வழங்கப்படும் தீம்கள் _Appearance > Unlock_ இன் கீழ் பட்டியலிடப்படும். உங்கள் `unlock.png` முன்னுரிமையாக ஒரு ஒளிபுகு png ஆக இருக்க வேண்டும். மேலும் `omarchy plymouth preview` ஐப் பயன்படுத்தி முன்னோட்டப் படத்தை உருவாக்கலாம்.

### Omarchy கவனிக்காத app-களைத் தீம் செய்தல்

அந்தப் பட்டியலில் இல்லாத ஒரு app ஐ நீங்கள் பயன்படுத்தினால், ஒரு template மூலம் அதைத் தீம் செய்ய Omarchy க்கு நீங்களே கற்றுக் கொடுக்கலாம். `~/.config/omarchy/themed/` இல், அது உருவாக்கும் உள்ளமைவின் பெயருடன் `.tpl` நீட்டிப்பையும் சேர்த்து ஒரு கோப்பைப் போட்டு, `{{ background }}`, `{{ foreground }}`, `{{ accent }}`, `{{ red }}`, `{{ color0 }}` முதல் `{{ color15 }}` வரை, மற்றும் palette இன் மீதமுள்ளவற்றை placeholders ஆகப் பயன்படுத்தி உள்ளமைவை எழுதுங்கள். நீங்கள் தீம்களை மாற்றும் ஒவ்வொரு முறையும், அந்தக் கோப்பு அந்தத் தீமின் வண்ணங்களுடன் மீண்டும் உருவாக்கப்படும்.

அந்தக் கோப்புறையில் முழுமையாகக் கருத்துகள் எழுதப்பட்ட `alacritty.toml.tpl.sample` ஒன்று நகலெடுக்கக் கிடைக்கிறது — நீங்கள் பயன்படுத்தக்கூடிய ஒவ்வொரு variable ஐயும், தங்கள் வண்ணங்களை `#` இல்லாமல் அல்லது தசம RGB ஆக விரும்பும் app-களுக்கான `_strip` மற்றும் `_rgb` modifiers ஐயும் அது பட்டியலிடுகிறது. உங்கள் template-கள் Omarchy இன் சொந்த template-களை விட முன்னுரிமை பெறும், எனவே உள்ளமைக்கப்பட்ட app எப்படித் தீம் செய்யப்படுகிறது என்பதை மீறவும் இதைப் பயன்படுத்தலாம்.

### உங்கள் தீமை விநியோகித்தல்

மற்றவர்கள் பயன்படுத்தும் வகையில் உங்கள் தீமை விநியோகிக்க விரும்பினால், அதை GitHub போன்ற ஒரு பொது git server இல் வைக்க வேண்டும். பிறகு மக்கள் அந்த URL ஐப் பயன்படுத்தி Omarchy மெனுவில் _Install > Style > Theme_ மூலம் அதை நிறுவலாம். `omarchy-[themename]-theme` என்ற பெயரிடும் மரபைப் பின்பற்றுவது பரிந்துரைக்கப்படுகிறது, ஏனெனில் நிறுவிய பிறகு தீம் தேர்வு மெனுவில் தீம் சரியாக `[themename]` என்று மட்டுமே காட்டப்படும்.

மீதமுள்ள அந்த `[themename]` தீமின் directory பெயராக மாறும், எனவே அது Omarchy பாதுகாப்பாகக் கையாளக்கூடிய ஒன்றாக இருக்க வேண்டும்: அது ஒரு எழுத்து, ஒரு இலக்கம், அல்லது ஒரு underscore உடன் தொடங்க வேண்டும், மீதமுள்ள பகுதியில் எழுத்துகள், இலக்கங்கள், `.`, `_`, `+`, மற்றும் `-` இருக்கலாம். பெரிய எழுத்துகள் உங்களுக்காகச் சிறிய எழுத்துகளாக மாற்றப்படும், ஆனால் வேறு எதுவும் — ஒரு இடைவெளி, ஒரு மேற்கோள் குறி, ஆங்கிலம் அல்லாத ஒரு எழுத்து — directory பெயராக மாற்றப்படாமல் நிறுவும் நேரத்திலேயே மறுக்கப்படும். எனவே `omarchy-tokyo-night-theme`, `omarchy-flexoki_light-theme`, மற்றும் `omarchy-c++-theme` அனைத்தும் நன்றாக நிறுவப்படும்.

ஒரு repo இலிருந்து நிறுவப்பட்ட பிறகு, அது வழங்கும் எந்த `.lua`, terminal உள்ளமைவு அல்லது `vscode.json` நீக்கப்படும் என்பதை நினைவில் கொள்ளுங்கள், எனவே தீமை அவற்றைச் சுற்றிக் கட்டமைக்காதீர்கள்.

[omarchy-site repo](https://github.com/omacom-io/omarchy-site) க்கு ஒரு pull request அனுப்புவதன் மூலம் உங்கள் தீமை [கூடுதல் தீம்கள் பக்கத்தில்](https://omarchy.org/themes/) சேர்க்கலாம்.
