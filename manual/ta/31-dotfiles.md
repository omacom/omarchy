# டாட்ஃபைல்கள்

Omarchy முதன்மையாக `~/.config` இல் உள்ள டாட்ஃபைல்கள் என்று அழைக்கப்படுபவற்றின் மூலம் உள்ளமைக்கப்படுகிறது. அவை உங்கள் மாற்றங்களுக்கான உங்கள் கோப்புகளாகக் கருதப்படுகின்றன. `/usr/share/omarchy` இல் உள்ள கோப்புகள் Omarchy-க்கே சொந்தமானவை, நீங்கள் அவற்றில் கை வைக்கக் கூடாது. `/usr/share/omarchy` இல் எதையாவது மாற்ற வேண்டுமென்றால், அதற்குப் பதிலாக `~/.config` இல் அந்த மதிப்பை மேலெழுத வேண்டும்.

முக்கிய உள்ளமைவுகளை Omarchy மெனுவிலிருந்தே (`Super + Space`) நேரடியாகத் திருத்தலாம், எடுத்துக்காட்டாக _அமைப்பு > Keyboard > Keybindings_, _அமைப்பு > Input_, மற்றும் _அமைப்பு > Config > [file]_. இந்த வழியில் செய்யும்போது, உள்ளமைவுத் திருத்தங்களுக்குப் பிறகு மறுதொடக்கம் தேவைப்படும் எந்தச் செயல்முறையும், நீங்கள் எடிட்டரிலிருந்து வெளியேறிய பிறகு தானாகவே மறுதொடக்கம் செய்யப்படும் (இயல்புநிலையில் Neovim — `:wq`, நினைவிருக்கிறதா! — ஆனால் _அமைப்பு > Defaults > Editor_ வழியாக அதை மாற்றலாம்).

`~/.config` இல் உள்ள முக்கிய கோப்புகளின் பட்டியலும் அவை எதைக் கட்டுப்படுத்துகின்றன என்பதும் இங்கே:

| கோப்பு | நோக்கம் |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | முதன்மை Hyprland உள்ளமைவு. Omarchy இயல்புநிலைகளையும் கீழே உள்ள உங்கள் மேலெழுதும் கோப்புகளையும் ஏற்றுகிறது. [Hyprland உள்ளமைவுகள் பற்றி மேலும் அறிக](https://wiki.hypr.land/Configuring/). |
| `~/.config/hypr/bindings.lua` | உங்கள் சொந்த keybindings மற்றும் இயல்புநிலைகளின் மேலெழுதல்கள். |
| `~/.config/hypr/monitors.lua` | சுழற்சி, கூடுதல் பயன்முறைகள், அல்லது ஒரு monitor-ஐ அணைத்து வைத்திருப்பது போன்ற, monitor பேனல் உள்ளடக்காத monitor அமைப்புகள். |
| `~/.config/hypr/input.lua` | உங்கள் keyboard தளவமைப்பு, mouse, மற்றும் trackpad அமைப்புகளைக் கட்டுப்படுத்துகிறது. |
| `~/.config/hypr/looknfeel.lua` | இடைவெளிகள், எல்லைகள், அனிமேஷன்கள் மற்றும் தோற்றத்தின் மற்ற அனைத்தையும் கட்டுப்படுத்துகிறது. |
| `~/.config/hypr/autostart.lua` | அமர்வுடன் தொடங்கப்படும் கூடுதல் செயல்முறைகளைக் கட்டுப்படுத்துகிறது. |
| `~/.config/omarchy/shell.json` | Omarchy shell-ஐக் கட்டுப்படுத்துகிறது: bar நிலை, தளவமைப்பு மற்றும் widgets, மேலும் screensaver, lock, மற்றும் idle நேரங்கள். |
| `~/.config/foot/foot.ini` | உங்கள் terminal-ஐக் கட்டுப்படுத்துகிறது (foot தான் இயல்புநிலை). |
| `~/.XCompose` | உங்கள் விரைவு அணுகல் emoji மற்றும் பெயர்/email தானியங்கு நிரப்புதலை வரையறுக்கிறது. மாற்றங்களைச் செய்த பிறகு `omarchy-restart-xcompose` ஐ இயக்குவதை உறுதிப்படுத்திக் கொள்ளுங்கள். |

உங்கள் சொந்த அமைப்பை மாற்றியமைக்க நிறைய மாற்றங்களைச் செய்ய நேர்ந்தால், இந்த டாட்ஃபைல்கள் அனைத்தையும் காப்புப் பிரதி எடுப்பது நல்ல யோசனை. [Stow அதைச் செய்வதற்கான சிறந்த வழி](https://www.youtube.com/watch?v=NoFiYOqnC4o).

### உங்கள் சொந்த பயன்பாடுகளை அமர்வுடன் தொடங்குதல்

ஒவ்வொரு முறை நீங்கள் உள்நுழையும்போதும் ஏதாவது இயங்க வேண்டுமென்றால் — ஒரு ஒத்திசைவு டீமான், ஒரு அரட்டை பயன்பாடு, உங்கள் சொந்த ஸ்கிரிப்ட் — அதை `~/.config/hypr/autostart.lua` இல் வைக்கவும்:

```lua
o.launch_on_start("my-service")
```

அது கட்டளையை அமர்வின் ஒரு பகுதியாகத் தொடங்குகிறது, எனவே நீங்கள் மீண்டும் வெளியேறும்போது அது முறையாகச் சுத்தம் செய்யப்படும்.

### கணினி நிகழ்வுகளில் ஸ்கிரிப்ட்களை இயக்குதல்

Omarchy ஒரு சில தருணங்களில் ஹூக்குகளைத் தூண்டுகிறது, உங்கள் சொந்த ஸ்கிரிப்ட்களை அவற்றில் இணைக்கலாம். அவை `~/.config/omarchy/hooks/<event>.d/` இல் உள்ளன, ஒவ்வொரு நிகழ்வுக்கும் ஒரு கோப்பகம், மற்றும் நிகழ்வு நடக்கும்போது `.sample` இல் முடிவடையாத அங்குள்ள ஒவ்வொரு கோப்பும் bash உடன் இயங்கும்:

| நிகழ்வு | எப்போது இயங்கும் |
| ----- | ------------ |
| `post-boot` | டெஸ்க்டாப் தொடங்கிய உடனேயே |
| `post-update` | `omarchy update` இன் இறுதிக்கு அருகில், தொகுப்புகள், இடம்பெயர்வுகள் மற்றும் சேவை மறுதொடக்கங்களுக்குப் பிறகு, mise கருவிகள் புதுப்பிக்கப்படுவதற்கு முன்பு |
| `pre-refresh-pacman` | `omarchy refresh pacman` தொகுப்பு உள்ளமைவை மீண்டும் ஒத்திசைத்த பிறகு, அது தொகுப்புகளைப் புதுப்பிப்பதற்கு முன்பு; ஒரு சேனல் மாற்றம் அதே புதுப்பிப்பு படியின்போது அதை இயக்குகிறது |
| `theme-set` | தீம் மாற்றத்திற்குப் பிறகு (`$1` இல் தீம் பெயர்) |
| `font-set` | எழுத்துரு மாற்றத்திற்குப் பிறகு (`$1` இல் எழுத்துரு பெயர்) |
| `battery-low` | பேட்டரி குறையும்போது (`$1` இல் சதவீதம்) |

`pre-refresh-pacman` ஹூக் தான் தனிப்பயன் களஞ்சியங்கள் அல்லது `IgnorePkg` வரிகள் இருக்க வேண்டிய இடம், ஏனெனில் அது தொகுப்பு பரிவர்த்தனைக்கு முன்பு இயங்கும். இரண்டும் உங்கள் பயனராகவே இயங்கும். `omarchy update` இன் sudo அங்கீகாரம் இன்னும் புதியதாக இருக்கும்போதே `post-update` இயங்கும், எனவே `sudo` ஐப் பயன்படுத்தும் ஒரு ஹூக் உங்கள் கடவுச்சொல்லை மீண்டும் கேட்காது; `omarchy refresh pacman` தானே sudo ஐப் பயன்படுத்திய உடனேயே `pre-refresh-pacman` இயங்கும்.

அந்தக் கோப்பகங்கள் ஒவ்வொன்றிலும் ஏற்கனவே ஒரு ஹூக்கின் வடிவத்தைக் காட்டும் ஒரு `.sample` கோப்பு உள்ளது — அதை வேலைக்கு வைக்க பெயரிலிருந்து `.sample` ஐ நீக்குங்கள். நீங்கள் வேறு இடத்தில் எழுதிய ஸ்கிரிப்ட்டை நிறுவ, `omarchy hook install post-boot ~/my-hook` ஐப் பயன்படுத்துங்கள், அது அதை உள்ளே நகலெடுத்து செயல்படுத்தக்கூடியதாக மாற்றும்.

### உங்கள் சொந்த மெனு உள்ளீடுகளைச் சேர்த்தல்

Omarchy மெனுவை (`Super + Space`) `~/.config/omarchy/extensions/omarchy-menu.jsonc` ஐத் திருத்துவதன் மூலம் உங்கள் சொந்த வரிசைகளுடன் விரிவாக்கலாம். உள்ளீடுகள் புள்ளியிடப்பட்ட id மூலம் விசையிடப்படுகின்றன, மற்றும் அந்த id தான் அவற்றை மரத்தில் வைக்கிறது, எனவே `personal` மூல மெனுவில் தோன்றும் மற்றும் `personal.notes` அதன் உள்ளே தோன்றும்:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

ஏற்கனவே உள்ள id-ஐ மீண்டும் பயன்படுத்தினால், புதிய ஒன்றைச் சேர்ப்பதற்குப் பதிலாக அந்த வரிசையை மேலெழுதுவீர்கள். கிடைக்கக்கூடிய அனைத்து புலங்களும் கருத்துகளாக ஆவணப்படுத்தப்பட்டு அந்தக் கோப்பு வருகிறது.

### உங்கள் சொந்த shell ஏற்றுமதிகள், செயல்பாடுகள் மற்றும் மாற்றுப்பெயர்களைச் சேர்த்தல்

Omarchy பல வசதியான மாற்றுப்பெயர்கள் மற்றும் உதவிகரமான செயல்பாடுகளுடன் வருகிறது, ஆனால் உங்கள் சொந்தவற்றைச் சேர்க்க விரும்புவது மிகவும் பொதுவானது. மாற்றுப்பெயர்கள், செயல்பாடுகள் மற்றும் ஏற்றுமதிகள் அனைத்தையும் `~/.bashrc` இல் சேர்க்க வேண்டும். இந்தக் கோப்பு புதுப்பிப்புகளில் மேலெழுதப்படாது. Omarchy இயல்புநிலைகளில் எதையாவது மாற்ற விரும்பினால், அவற்றையும் இங்கே பாதுகாப்பாகச் சேர்க்கலாம்.

### டெஸ்க்டாப்பிற்கான சூழல் மாறிகளை அமைத்தல்

டெஸ்க்டாப் அமர்வு ஏற்றுமதிகள் `~/.config/uwsm/env.d/` க்குச் சொந்தமானவை. இந்தக் கோப்புகள் உங்கள் டெஸ்க்டாப் தொடங்குவதற்கு முன்பு இயங்கும், எனவே ஒரு shell பிழை உங்களை உள்நுழைவுத் திரைக்குத் திருப்பி அனுப்பக்கூடும். அவற்றைத் திருத்தும்போது வேலை செய்யும் ஒரு terminal-ஐத் திறந்து வைத்திருங்கள். ஒரு மேலெழுதலை முடக்க, அதை `env.d` இலிருந்து வெளியே நகர்த்துங்கள். ஒரு மாற்றம் உள்நுழைவைத் தடுத்தால் [உள்நுழைவு மீட்பைப்](45-troubleshooting.md#my-password-is-accepted-but-i-return-to-the-login-screen) பார்க்கவும்.

### உள் Omarchy கோப்புகளை மாற்றுதல்

பாருங்கள், இது உங்கள் கணினி. அதில் நீங்கள் விரும்பிய எதையும் செய்யலாம், ஆனால் `/usr/share/omarchy` இல் உள்ள கோப்புகளில் நேரடியாக மாற்றங்கள் செய்வதற்கு எதிராக நான் அறிவுறுத்துவேன். அவை Omarchy pacman தொகுப்புக்குச் சொந்தமானவை, எனவே உங்கள் மாற்றங்கள் அடுத்த புதுப்பிப்பில் வெறுமனே மேலெழுதப்படும். அதற்குப் பதிலாக உங்களுக்குப் பிடிக்காத எந்த இயல்புநிலை மதிப்புகளையும் `~/.config/*` கோப்புறையில் மேலெழுதுவதே உங்களுக்கு நல்லது.

இயல்புநிலை keybindings போல, கிட்டத்தட்ட எல்லாவற்றையும் அந்த வழியில் மாற்றலாம். எடுத்துக்காட்டாக, [Obsidian](https://obsidian.md/) க்குப் பதிலாக [Joplin](https://joplinapp.org/) ஐ வைக்க (`omarchy-pkg-add joplin-bin` உடன் நிறுவவும்) `~/.config/hypr/bindings.lua` ஐத் திருத்துங்கள்:

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` அதன் மாற்றீட்டைச் சேர்ப்பதற்கு முன்பு ஏற்கனவே உள்ள binding-ஐ நீக்குகிறது. அது ஏவுதல் உதவியாளர்கள் மற்றும் binding விருப்பங்கள் உட்பட `o.bind` இன் அதே வாதங்களை எடுக்கும். ஒரு binding-ஐச் சேர்க்க `o.bind` ஐப் பயன்படுத்துங்கள், அல்லது அதை மாற்றாமல் ஒன்றை நீக்க `hl.unbind` ஐப் பயன்படுத்துங்கள்.

உள் Omarchy கோப்புகளில் ஹேக் செய்வதில் நீங்கள் பிடிவாதமாக இருந்தால், _புதுப்பிப்பு > Channel > Dev_ வழியாக dev சேனலுக்கு மாறுங்கள். அது Omarchy-ஐ `~/omarchy` இல் உள்ள மூலக் குறியீட்டின் ஒரு git checkout உடன் இணைக்கிறது, அதை உங்கள் இதயம் விரும்பும் அளவுக்கு மாற்ற நீங்கள் சுதந்திரமாக இருக்கிறீர்கள். நீங்கள் என்ன செய்ய வேண்டும் என்று சொல்ல இங்கே யாரும் இல்லை!

### எந்த மாற்றங்களையும் மீட்டமைத்தல்

உள்ளமைவுகளைக் குழப்பி வைக்க நேர்ந்தால், Omarchy மெனுவில் _புதுப்பிப்பு > Config_ வழியாக அவற்றை எப்போதும் இயல்புநிலைகளுக்குத் திருப்பலாம். அல்லது எல்லாவற்றையும் மீட்டமைக்க `omarchy reinstall configs` ஐ இயக்குவதன் மூலம்.
