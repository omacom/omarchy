# Dotfiles

Omarchy முதன்மையாக `~/.config` இல் வாழும் dotfiles என்று அழைக்கப்படுபவற்றின் மூலம் கட்டமைக்கப்படுகிறது. அவை உங்கள் மாற்றங்களுக்கான உங்கள் கோப்புகளாகக் கருதப்படுகின்றன. `/usr/share/omarchy` இல் வாழும் கோப்புகள் Omarchy க்கே சொந்தமானவை, நீங்கள் அவற்றைக் குழப்பக்கூடாது. `/usr/share/omarchy` இல் எதையாவது மாற்ற வேண்டும் என்றால், அதற்குப் பதிலாக `~/.config` இல் மதிப்பை மேலெழுத வேண்டும்.

முக்கிய கட்டமைப்புகளை Omarchy மெனுவில் (`Super + Space`) இருந்து நேரடியாகத் திருத்தலாம், எடுத்துக்காட்டாக _அமைப்பு > திரைகள்_, _அமைப்பு > விசைப்பிணைப்புகள்_, _அமைப்பு > உள்ளீடு_ மற்றும் _அமைப்பு > Config > [file]_. இந்த வழியில் செய்யும்போது, கட்டமைப்புத் திருத்தங்களுக்குப் பிறகு மறுதொடக்கம் தேவைப்படும் எந்தச் செயல்முறையும், நீங்கள் திருத்தியிலிருந்து வெளியேறிய பிறகு தானாகவே மறுதொடக்கம் செய்யப்படும் (இயல்பாக Neovim — `:wq`, நினைவில் கொள்ளுங்கள்! — ஆனால் அதை _அமைப்பு > இயல்புநிலைகள் > Editor_ வழியாக மாற்றலாம்).

`~/.config` இல் உள்ள முக்கிய கோப்புகள் மற்றும் அவை கட்டுப்படுத்துவது பற்றிய பட்டியல் இங்கே:

| File                  | Purpose              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | முக்கிய Hyprland கட்டமைப்பு. Omarchy இயல்புநிலைகள் மற்றும் கீழே உள்ள உங்கள் மேலெழுதும் கோப்புகளை ஏற்றுகிறது. [Hyprland கட்டமைப்புகள் பற்றி மேலும் அறிக](https://wiki.hypr.land/Configuring/).  |
| `~/.config/hypr/bindings.lua` | உங்கள் சொந்த விசைப்பிணைப்புகள் மற்றும் இயல்புநிலைகளின் மேலெழுதுதல்கள். |
| `~/.config/hypr/monitors.lua` | உங்கள் திரைகள், தெளிவுத்திறன் மற்றும் நிலையைக் கட்டுப்படுத்துகிறது. |
| `~/.config/hypr/input.lua` | உங்கள் விசைப்பலகை அமைப்பு, சுட்டி மற்றும் trackpad அமைப்புகளைக் கட்டுப்படுத்துகிறது. |
| `~/.config/hypr/looknfeel.lua` | இடைவெளிகள், எல்லைகள், அசைவூட்டங்கள் மற்றும் தோற்றத்தின் மீதமுள்ளவற்றைக் கட்டுப்படுத்துகிறது. |
| `~/.config/hypr/autostart.lua` | அமர்வுடன் தொடங்கப்பட்ட கூடுதல் செயல்முறைகளைக் கட்டுப்படுத்துகிறது. |
| `~/.config/omarchy/shell.json` | Omarchy shell ஐக் கட்டுப்படுத்துகிறது: பட்டை நிலை, அமைப்பு மற்றும் widget கள், மேலும் திரைசேமிப்பு, பூட்டு மற்றும் செயலற்ற நேரங்கள். |
| `~/.config/foot/foot.ini` | உங்கள் முனையத்தைக் கட்டுப்படுத்துகிறது (foot இயல்புநிலை). |
| `~/.XCompose` | உங்கள் விரைவு அணுகல் emoji மற்றும் பெயர்/மின்னஞ்சல் தானியங்கு நிறைவை வரையறுக்கிறது. மாற்றங்களைச் செய்த பிறகு `omarchy-restart-xcompose` ஐ இயக்குவதை உறுதிப்படுத்தவும். |

உங்கள் சொந்த அமைப்பை மாற்றியமைக்க நிறைய மாற்றங்களைச் செய்தால், இந்த dotfiles அனைத்தையும் காப்புப்பிரதி எடுப்பது நல்லது. [Stow அதைச் செய்ய ஒரு சிறந்த வழி](https://www.youtube.com/watch?v=NoFiYOqnC4o).

### அமர்வுடன் உங்கள் சொந்தச் செயலிகளைத் தொடங்குதல்

ஒவ்வொரு முறை உள்நுழையும்போதும் ஏதாவது இயங்க வேண்டுமென்றால் — ஒத்திசைவு டீமன், அரட்டைச் செயலி, உங்கள் சொந்த ஸ்கிரிப்ட் — அதை `~/.config/hypr/autostart.lua` இல் வைக்கவும்:

```lua
o.launch_on_start("my-service")
```

அது கட்டளையை அமர்வின் ஒரு பகுதியாகத் தொடங்குகிறது, எனவே நீங்கள் மீண்டும் வெளியேறும்போது அது சரியாகச் சுத்தம் செய்யப்படும்.

### கணினி நிகழ்வுகளில் ஸ்கிரிப்ட்களை இயக்குதல்

Omarchy ஒரு சில தருணங்களில் hook களைச் சுடுகிறது, உங்கள் சொந்த ஸ்கிரிப்ட்களை அவற்றில் தொங்கவிடலாம். அவை `~/.config/omarchy/hooks/<event>.d/` இல் வாழ்கின்றன, நிகழ்வுக்கு ஒரு கோப்பகம், மேலும் நிகழ்வு நிகழும்போது அங்குள்ள ஒவ்வொரு இயக்கக்கூடிய கோப்பும் இயங்கும்:

| Event | When it runs |
| ----- | ------------ |
| `post-boot` | டெஸ்க்டாப் தொடங்கிய உடனேயே |
| `post-update` | `omarchy update` இன் முடிவில், தொகுப்புகள், இடம்பெயர்வுகள் மற்றும் சேவை மறுதொடக்கங்களுக்குப் பிறகு, mise கருவிகள் புதுப்பிக்கப்படுவதற்கு முன் |
| `pre-refresh-pacman` | `omarchy refresh pacman` தொகுப்பு கட்டமைப்பை மீண்டும் ஒத்திசைத்த பிறகு, அது தொகுப்புகளைப் புதுப்பிப்பதற்கு முன்; சேனல் மாற்றம் அதே refresh படியின் போது அதை இயக்குகிறது |
| `theme-set` | தீம் மாற்றத்திற்குப் பிறகு (`$1` இல் தீம் பெயர்) |
| `font-set` | எழுத்துரு மாற்றத்திற்குப் பிறகு (`$1` இல் எழுத்துரு பெயர்) |
| `battery-low` | மின்கலம் குறையும்போது (`$1` இல் சதவீதம்) |

`pre-refresh-pacman` hook தான் தனிப்பயன் களஞ்சியங்கள் அல்லது `IgnorePkg` வரிகள் இருக்க வேண்டிய இடம், ஏனெனில் இது தொகுப்புப் பரிமாற்றத்திற்கு முன் இயங்குகிறது. Omarchy அதன் தற்காலிகமாகச் சேமிக்கப்பட்ட sudo அங்கீகாரத்தை அழித்த பிறகு இரண்டு புதுப்பிப்பு தொடர்பான hook களும் உங்கள் பயனராக இயங்குகின்றன, எனவே `sudo` ஐப் பயன்படுத்தும் hook க்கு அதன் சொந்த அங்கீகாரம் தேவை, உங்கள் கடவுச்சொல்லைக் கேட்கலாம்.

அந்தக் கோப்பகங்கள் ஒவ்வொன்றிலும் ஏற்கனவே hook இன் வடிவத்தைக் காட்டும் `.sample` கோப்பு உள்ளது — அதை வேலையில் அமர்த்த பெயரிலிருந்து `.sample` ஐ நீக்கவும். நீங்கள் வேறு எங்கோ எழுதிய ஸ்கிரிப்ட்டை நிறுவ, `omarchy hook install post-boot ~/my-hook` ஐப் பயன்படுத்தவும், இது அதை நகலெடுத்து இயக்கக்கூடியதாக்குகிறது.

### உங்கள் சொந்த மெனு உள்ளீடுகளைச் சேர்த்தல்

`~/.config/omarchy/extensions/omarchy-menu.jsonc` ஐத் திருத்துவதன் மூலம் Omarchy மெனுவை (`Super + Space`) உங்கள் சொந்த வரிசைகளுடன் விரிவாக்கலாம். உள்ளீடுகள் புள்ளியிடப்பட்ட id ஆல் விசையிடப்படுகின்றன, மேலும் id தான் அவற்றை மரத்தில் வைக்கிறது, எனவே `personal` மூல மெனுவில் தோன்றும், `personal.notes` அதற்குள் தோன்றும்:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

இருக்கும் id ஐ மீண்டும் பயன்படுத்தினால் புதிய ஒன்றைச் சேர்ப்பதற்குப் பதிலாக அந்த வரிசையை மேலெழுதுகிறீர்கள். கிடைக்கக்கூடிய அனைத்து புலங்களும் கருத்துகளாக ஆவணப்படுத்தப்பட்டு கோப்பு வருகிறது.

### உங்கள் சொந்த shell exports, செயல்பாடுகள் மற்றும் மாற்றுப்பெயர்களைச் சேர்த்தல்

Omarchy ஒரு தொகுப்பு ergonomic மாற்றுப்பெயர்கள் மற்றும் உதவிகரமான செயல்பாடுகளுடன் வருகிறது, ஆனால் உங்கள் சொந்தத்தைச் சேர்க்க விரும்புவது மிகவும் பொதுவானது. மாற்றுப்பெயர்கள், செயல்பாடுகள் மற்றும் exports இரண்டையும் `~/.bashrc` இல் சேர்க்க வேண்டும். புதுப்பிப்புகளில் இந்தக் கோப்பு மேலெழுதப்படாது. Omarchy இயல்புநிலைகளில் எதையாவது மாற்ற விரும்பினால், அவற்றையும் இங்கே பாதுகாப்பாகச் சேர்க்கலாம்.

### உள் Omarchy கோப்புகளை மாற்றுதல்

பாருங்கள், இது உங்கள் கணினி. அதில் நீங்கள் விரும்பியதைச் செய்யலாம், ஆனால் `/usr/share/omarchy` இல் உள்ள கோப்புகளில் நேரடியாக மாற்றங்களைச் செய்ய வேண்டாம் என்று நான் அறிவுறுத்துவேன். அவை Omarchy pacman தொகுப்புக்குச் சொந்தமானவை, எனவே உங்கள் மாற்றங்கள் அடுத்த புதுப்பிப்பில் வெறுமனே மேலெழுதப்படும். அதற்குப் பதிலாக `~/.config/*` கோப்புறையில் உங்களுக்குப் பிடிக்காத எந்த இயல்புநிலை மதிப்புகளையும் மேலெழுதுவது சிறந்தது.

இயல்புநிலை விசைப்பிணைப்புகளைப் போல, அந்த வழியில் ஏறக்குறைய எல்லாவற்றையும் மாற்றலாம். எடுத்துக்காட்டாக, [Obsidian](https://obsidian.md/) ஐ [Joplin](https://joplinapp.org/) உடன் மாற்ற `~/.config/hypr/bindings.lua` ஐத் திருத்தவும் (`omarchy-pkg-add joplin-bin` உடன் நிறுவவும்):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` அதன் மாற்றைச் சேர்ப்பதற்கு முன் இருக்கும் பிணைப்பை அகற்றுகிறது. இது `o.bind` போன்ற அதே அளவுருக்களை எடுக்கிறது, launch helpers மற்றும் பிணைப்பு விருப்பங்கள் உட்பட. பிணைப்பைச் சேர்க்க `o.bind` ஐப் பயன்படுத்தவும், அல்லது அதை மாற்றாமல் ஒன்றை அகற்ற `hl.unbind` ஐப் பயன்படுத்தவும்.

உள் Omarchy கோப்புகளில் hack செய்ய வலியுறுத்தினால், _புதுப்பி > Channel > Dev_ வழியாக dev சேனலுக்கு மாறவும். அது Omarchy ஐ `~/omarchy` இல் உள்ள மூலக் குறியீட்டின் git checkout உடன் இணைக்கிறது, அதை உங்கள் இதயத்தின் உள்ளடக்கத்திற்கு மாற்ற நீங்கள் சுதந்திரமாக இருக்கிறீர்கள். என்ன செய்ய வேண்டும் என்று சொல்ல இங்கே யாரும் இல்லை!

### எந்த மாற்றங்களையும் மீட்டமைத்தல்

கட்டமைப்புகளில் குழப்பத்தை ஏற்படுத்தினால், Omarchy மெனுவில் _புதுப்பி > Config_ வழியாக அவற்றை எப்போதும் இயல்புநிலைகளுக்குத் திருப்பலாம். அல்லது எல்லாவற்றையும் மீட்டமைக்க `omarchy reinstall configs` ஐ இயக்குவதன் மூலம்.
