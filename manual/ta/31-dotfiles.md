# Dotfiles

Omarchy முதன்மையாக `~/.config`-இல் இருக்கும் dotfiles என்று சொல்லப்படுபவற்றின் மூலமே கட்டமைக்கப்படுகிறது. அவை உங்கள் மாற்றங்களுக்கான உங்கள் கோப்புகளாகக் கருதப்படுகின்றன. `/usr/share/omarchy`-இல் இருக்கும் கோப்புகள் Omarchy-க்கே சொந்தமானவை, அவற்றில் நீங்கள் கை வைக்கக் கூடாது. `/usr/share/omarchy`-இல் எதையாவது மாற்ற வேண்டுமென்றால், அதற்குப் பதிலாக `~/.config`-இல் அந்த மதிப்பை மேலெழுத வேண்டும்.

முக்கிய கட்டமைப்புகளை Omarchy மெனுவிலிருந்தே (`Super + Space`) நேரடியாகத் திருத்தலாம், எடுத்துக்காட்டாக _Setup > Keybindings_, _Setup > Input_, மற்றும் _Setup > Config > [file]_. இப்படிச் செய்யும்போது, கட்டமைப்புத் திருத்தங்களுக்குப் பிறகு மறுதொடக்கம் தேவைப்படும் எந்தவொரு செயல்முறையும், நீங்கள் எடிட்டரிலிருந்து வெளியேறிய பிறகு தானாகவே மறுதொடக்கம் ஆகும் (இயல்பாக Neovim — `:wq`, நினைவிருக்கிறதா! — ஆனால் _Setup > Defaults > Editor_ வழியாக அதை மாற்றலாம்).

`~/.config`-இல் உள்ள முக்கிய கோப்புகள் மற்றும் அவை எதைக் கட்டுப்படுத்துகின்றன என்பதன் பட்டியல் இங்கே:

| File                  | Purpose              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | முதன்மையான Hyprland கட்டமைப்பு. Omarchy இயல்புநிலைகளையும் கீழே உள்ள உங்கள் மேலெழுதும் கோப்புகளையும் ஏற்றுகிறது. [Hyprland கட்டமைப்புகள் பற்றி மேலும் அறிக](https://wiki.hypr.land/Configuring/).  |
| `~/.config/hypr/bindings.lua` | உங்கள் சொந்த விசைப்பிணைப்புகள் மற்றும் இயல்புநிலைகளின் மேலெழுதல்கள். |
| `~/.config/hypr/monitors.lua` | சுழற்சி, கூடுதல் பயன்முறைகள், அல்லது ஒரு மானிட்டரை அணைத்து வைத்திருத்தல் போன்ற, மானிட்டர் பேனல் உள்ளடக்காத மானிட்டர் அமைப்புகள். |
| `~/.config/hypr/input.lua` | உங்கள் விசைப்பலகை தளவமைப்பு, மவுஸ், மற்றும் டிராக்பேட் அமைப்புகளைக் கட்டுப்படுத்துகிறது. |
| `~/.config/hypr/looknfeel.lua` | இடைவெளிகள், விளிம்புகள், அசைவூட்டங்கள், மற்றும் தோற்றத்தின் மற்ற அனைத்தையும் கட்டுப்படுத்துகிறது. |
| `~/.config/hypr/autostart.lua` | அமர்வுடன் தொடங்கப்படும் கூடுதல் செயல்முறைகளைக் கட்டுப்படுத்துகிறது. |
| `~/.config/omarchy/shell.json` | Omarchy ஷெல்லைக் கட்டுப்படுத்துகிறது: பட்டையின் நிலை, தளவமைப்பு, மற்றும் விட்ஜெட்கள், மேலும் ஸ்கிரீன்சேவர், பூட்டு, மற்றும் செயலற்ற நேரங்கள். |
| `~/.config/foot/foot.ini` | உங்கள் டெர்மினலைக் கட்டுப்படுத்துகிறது (foot என்பதே இயல்புநிலை). |
| `~/.XCompose` | உங்கள் விரைவு-அணுகல் ஈமோஜி மற்றும் பெயர்/மின்னஞ்சல் தானியங்கு நிறைவை வரையறுக்கிறது. மாற்றங்கள் செய்த பிறகு `omarchy-restart-xcompose` ஐ இயக்க மறக்காதீர்கள். |

உங்கள் சொந்த அமைப்பைச் சரிசெய்ய நிறைய மாற்றங்களைச் செய்துவிட்டீர்கள் என்றால், இந்த dotfiles அனைத்தையும் காப்புப் பிரதி எடுப்பது நல்ல யோசனை. [Stow அதற்கு ஒரு சிறந்த வழி](https://www.youtube.com/watch?v=NoFiYOqnC4o).

### அமர்வுடன் உங்கள் சொந்த பயன்பாடுகளைத் தொடங்குதல்

நீங்கள் உள்நுழையும் ஒவ்வொரு முறையும் ஏதாவது இயங்க வேண்டும் என்றால் — ஒரு ஒத்திசைவு டீமான், ஒரு அரட்டை பயன்பாடு, உங்கள் சொந்த ஸ்கிரிப்ட் — அதை `~/.config/hypr/autostart.lua`-இல் போடுங்கள்:

```lua
o.launch_on_start("my-service")
```

அது கட்டளையை அமர்வின் ஒரு பகுதியாகத் தொடங்குகிறது, எனவே நீங்கள் மீண்டும் வெளியேறும்போது அது முறையாகச் சுத்தம் செய்யப்படும்.

### கணினி நிகழ்வுகளில் ஸ்கிரிப்ட்களை இயக்குதல்

Omarchy ஒரு சில தருணங்களில் hooks ஐத் தூண்டுகிறது, நீங்கள் உங்கள் சொந்த ஸ்கிரிப்ட்களை அவற்றில் தொங்கவிடலாம். அவை `~/.config/omarchy/hooks/<event>.d/`-இல் இருக்கின்றன, ஒவ்வொரு நிகழ்வுக்கும் ஒரு கோப்பகம், நிகழ்வு நடக்கும்போது அங்குள்ள இயக்கக்கூடிய ஒவ்வொரு கோப்பும் இயங்கும்:

| Event | When it runs |
| ----- | ------------ |
| `post-boot` | டெஸ்க்டாப் தொடங்கிய உடனேயே |
| `post-update` | `omarchy update`-இன் முடிவுக்கு அருகில், தொகுப்புகள், இடம்பெயர்வுகள், மற்றும் சேவை மறுதொடக்கங்களுக்குப் பிறகு, mise கருவிகள் புதுப்பிக்கப்படுவதற்கு முன்பு |
| `pre-refresh-pacman` | `omarchy refresh pacman` தொகுப்பு கட்டமைப்பை மீண்டும் ஒத்திசைத்த பிறகு, அது தொகுப்புகளைப் புதுப்பிப்பதற்கு முன்பு; ஒரு சேனல் மாற்றம் அதே புதுப்பிப்புப் படியின்போது அதை இயக்குகிறது |
| `theme-set` | ஒரு தீம் மாற்றத்திற்குப் பிறகு (தீம் பெயர் `$1`-இல்) |
| `font-set` | ஒரு எழுத்துரு மாற்றத்திற்குப் பிறகு (எழுத்துரு பெயர் `$1`-இல்) |
| `battery-low` | பேட்டரி குறையும்போது (சதவீதம் `$1`-இல்) |

`pre-refresh-pacman` hook என்பது தனிப்பயன் களஞ்சியங்கள் அல்லது `IgnorePkg` வரிகள் சேர வேண்டிய இடம், ஏனெனில் அது தொகுப்பு பரிவர்த்தனைக்கு முன்பு இயங்குகிறது. புதுப்பிப்பு தொடர்பான இரண்டு hooks-களும் Omarchy தனது தற்காலிகமாகச் சேமித்த sudo அங்கீகாரத்தை அழித்த பிறகு உங்கள் பயனராக இயங்குகின்றன, எனவே `sudo` ஐப் பயன்படுத்தும் ஒரு hook-க்கு அதன் சொந்த அங்கீகாரம் தேவை, அது உங்கள் கடவுச்சொல்லைக் கேட்கலாம்.

அந்தக் கோப்பகங்கள் ஒவ்வொன்றும் ஏற்கனவே ஒரு hook-இன் வடிவத்தைக் காட்டும் ஒரு `.sample` கோப்பை வைத்திருக்கின்றன — அதை வேலைக்கு வைக்க பெயரிலிருந்து `.sample` ஐ நீக்குங்கள். நீங்கள் வேறு எங்காவது எழுதிய ஒரு ஸ்கிரிப்டை நிறுவ, `omarchy hook install post-boot ~/my-hook` ஐப் பயன்படுத்துங்கள், அது அதை உள்ளே நகலெடுத்து இயக்கக்கூடியதாக ஆக்கும்.

### உங்கள் சொந்த மெனு உள்ளீடுகளைச் சேர்த்தல்

Omarchy மெனுவை (`Super + Space`) `~/.config/omarchy/extensions/omarchy-menu.jsonc` ஐத் திருத்துவதன் மூலம் உங்கள் சொந்த வரிசைகளைக் கொண்டு விரிவாக்கலாம். உள்ளீடுகள் ஒரு புள்ளியிடப்பட்ட id-ஆல் குறியிடப்படுகின்றன, அந்த id தான் அவற்றை மரத்தில் வைக்கிறது, எனவே `personal` மூல மெனுவில் தோன்றும், `personal.notes` அதற்குள் தோன்றும்:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

ஏற்கனவே உள்ள id-ஐ மீண்டும் பயன்படுத்தினால், புதிய ஒன்றைச் சேர்ப்பதற்குப் பதிலாக அந்த வரிசையை மேலெழுதுவீர்கள். கிடைக்கக்கூடிய அனைத்து புலங்களும் கருத்துகளாக ஆவணப்படுத்தப்பட்ட நிலையில் கோப்பு வருகிறது.

### உங்கள் சொந்த ஷெல் ஏற்றுமதிகள், செயல்பாடுகள், மற்றும் மாற்றுப்பெயர்களைச் சேர்த்தல்

Omarchy எளிதான பயன்பாட்டிற்கான ஏகப்பட்ட மாற்றுப்பெயர்கள் மற்றும் பயனுள்ள செயல்பாடுகளுடன் வருகிறது, ஆனால் உங்கள் சொந்தவற்றைச் சேர்க்க விரும்புவது மிகவும் பொதுவானது. மாற்றுப்பெயர்கள், செயல்பாடுகள், மற்றும் ஏற்றுமதிகள் இரண்டையும் `~/.bashrc`-இல் சேர்க்க வேண்டும். இந்தக் கோப்பு புதுப்பிப்புகளில் மேலெழுதப்படாது. Omarchy இயல்புநிலைகள் எதையாவது மாற்ற விரும்பினால், அவற்றையும் இங்கே பாதுகாப்பாகச் சேர்க்கலாம்.

### டெஸ்க்டாப்பிற்கான சூழல் மாறிகளை அமைத்தல்

டெஸ்க்டாப் அமர்வு ஏற்றுமதிகள் `~/.config/uwsm/env.d/`-இல் சேர வேண்டும். இந்தக் கோப்புகள் உங்கள் டெஸ்க்டாப் தொடங்குவதற்கு முன்பு இயங்குகின்றன, எனவே ஒரு ஷெல் பிழை உங்களை உள்நுழைவுத் திரைக்கே திருப்பி அனுப்பலாம். அவற்றைத் திருத்தும்போது வேலை செய்யும் ஒரு டெர்மினலைத் திறந்து வைத்திருங்கள். ஒரு மேலெழுதலை முடக்க, அதை `env.d`-இலிருந்து வெளியே நகர்த்துங்கள். ஒரு மாற்றம் உள்நுழைவைத் தடுத்தால் [உள்நுழைவு மீட்பைப்](45-troubleshooting.md#my-password-is-accepted-but-i-return-to-the-login-screen) பார்க்கவும்.

### உள் Omarchy கோப்புகளை மாற்றுதல்

பாருங்கள், இது உங்கள் கணினி. அதில் நீங்கள் விரும்பியதைச் செய்யலாம், ஆனால் `/usr/share/omarchy`-இல் உள்ள கோப்புகளில் நேரடியாக மாற்றங்கள் செய்ய வேண்டாம் என்று நான் அறிவுறுத்துவேன். அவை Omarchy pacman தொகுப்புக்குச் சொந்தமானவை, எனவே உங்கள் மாற்றங்கள் அடுத்த புதுப்பிப்பில் வெறுமனே மேலெழுதப்படும். அதற்குப் பதிலாக உங்களுக்குப் பிடிக்காத எந்த இயல்புநிலை மதிப்புகளையும் `~/.config/*` கோப்புறையில் மேலெழுதுவதே உங்களுக்கு நல்லது.

இயல்புநிலை விசைப்பிணைப்புகள் போல, கிட்டத்தட்ட எல்லாவற்றையும் அப்படி மாற்றலாம். எடுத்துக்காட்டாக, [Obsidian](https://obsidian.md/) ஐ [Joplin](https://joplinapp.org/) கொண்டு மாற்ற `~/.config/hypr/bindings.lua` ஐத் திருத்துங்கள் (`omarchy-pkg-add joplin-bin` கொண்டு நிறுவவும்):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` அதன் மாற்றீட்டைச் சேர்ப்பதற்கு முன்பு ஏற்கனவே உள்ள பிணைப்பை நீக்குகிறது. அது தொடக்க உதவிகள் மற்றும் பிணைப்பு விருப்பங்கள் உட்பட, `o.bind` போன்ற அதே வாதங்களை எடுக்கிறது. ஒரு பிணைப்பைச் சேர்க்க `o.bind` ஐப் பயன்படுத்துங்கள், அல்லது அதை மாற்றாமல் ஒன்றை நீக்க `hl.unbind` ஐப் பயன்படுத்துங்கள்.

உள் Omarchy கோப்புகளில் ஹேக் செய்ய வேண்டும் என்று நீங்கள் பிடிவாதமாக இருந்தால், _Update > Channel > Dev_ வழியாக dev சேனலுக்கு மாறுங்கள். அது Omarchy-ஐ `~/omarchy`-இல் உள்ள மூலக் குறியீட்டின் ஒரு git செக்அவுட்டுடன் இணைக்கிறது, அதை உங்கள் இதயம் விரும்பும் அளவுக்கு மாற்ற நீங்கள் சுதந்திரமாக இருக்கிறீர்கள். உங்களுக்கு என்ன செய்ய வேண்டும் என்று சொல்ல இங்கே யாரும் இல்லை!

### எந்த மாற்றங்களையும் மீட்டமைத்தல்

கட்டமைப்புகளை நீங்கள் குழப்பிவிட்டீர்கள் என்றால், Omarchy மெனுவில் _Update > Config_ வழியாக அவற்றை எப்போதும் இயல்புநிலைகளுக்குத் திருப்பலாம். அல்லது எல்லாவற்றையும் மீட்டமைக்க `omarchy reinstall configs` ஐ இயக்குவதன் மூலம்.
