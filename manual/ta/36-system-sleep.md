# கணினி உறக்கம்

Omarchy இயல்பாகவே இடைநிறுத்தம் மற்றும் உறக்கநிலையை இயக்குகிறது, ஆனால் உங்கள் கணினியில் இவற்றில் ஏதேனும் ஒன்றில் சிக்கல் இருந்தால், அவற்றை நிறுத்தலாம்.

### ஆற்றல் சுயவிவரங்கள்

மடிக்கணினியில், Omarchy உங்கள் ஆற்றல் சுயவிவரத்தை செருகிய நிலைக்கும் மின்கலத்தில் இயங்குவதற்கும் தனித்தனியாக நினைவில் வைத்து, நீங்கள் செருகும்போதும் கழற்றும்போதும் இரண்டிற்கும் இடையே மாறும். அப்படியே கிடைப்பது AC-இல் செயல்திறன், மின்கலத்தில் சமநிலை என்பதாகும்.

`omarchy powerprofiles list` என்பதைக் கொண்டு உங்கள் கணினி என்ன தருகிறது என்பதைப் பார்க்கலாம், தற்போது நீங்கள் இருக்கும் நிலைக்கு வேண்டியதை `omarchy powerprofiles set autodetect power-saver` என்பதைக் கொண்டு அமைக்கலாம். எதையும் கழற்றாமல் மற்ற நிலையை அமைக்க, அதை நேரடியாகப் பெயரிடுங்கள்: `omarchy powerprofiles set battery power-saver`. நீங்கள் எதைத் தேர்ந்தெடுத்தாலும் அடுத்து அந்த நிலையில் இருக்கும்போது அதுவே கிடைக்கும்.

### இடைநிறுத்தத்தை மாற்றுதல்

முனையத்திலிருந்து `omarchy toggle suspend` என்பதை இயக்குவதன் மூலம் இடைநிறுத்தத்தை மாற்றுகிறீர்கள். அது _கணினி_ என்பதன் கீழ் (அல்லது `Super + Esc`) விருப்பத்தைக் காட்டவும் மறைக்கவுமே செய்கிறது, பிறகு உங்கள் கணினியில் அது தொடர்ந்து வேலை செய்கிறதா என்று பார்க்கலாம். இல்லையென்றால், அதே கட்டளையைக் கொண்டு அதை மீண்டும் மறைக்கலாம்.

### உறக்கநிலையை மாற்றுதல்

முனையத்திலிருந்து `omarchy hibernation setup` என்பதை இயக்குவதன் மூலம் உறக்கநிலையை அமைக்கிறீர்கள். உறக்கநிலை உங்கள் துவக்க இயக்ககத்தில் உங்கள் இயற்பியல் RAM ஒதுக்கீட்டின் அளவுடைய ஒரு /swap துணைத்தொகுதியை உருவாக்குகிறது, எனவே நிறைய இடம் இருப்பதை உறுதிப்படுத்துங்கள். 32GB கணினியில், இந்தத் தொகுதிக்கு எப்போதும் 32GB+ இலவச இடம் வேண்டும். உறக்கநிலைக்கு இயல்புநிலை Limine துவக்க ஏற்றியும் தேவை.

அமைத்தவுடன், _கணினி_ என்பதன் கீழ் (அல்லது `Super + Esc`) உறக்கநிலை விருப்பத்தைக் காண்பீர்கள், பிறகு உங்கள் கணினியில் அது தொடர்ந்து வேலை செய்கிறதா என்று பார்க்கலாம். இல்லையென்றால், `omarchy hibernation remove` என்பதை இயக்குவதன் மூலம் அதை மீண்டும் நீக்கலாம்.
