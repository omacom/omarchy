# கணினி உறக்க நிலை

Omarchy இயல்பாகவே suspend மற்றும் hibernation ஐ இயக்குகிறது, ஆனால் உங்கள் கணினியில் இவற்றில் ஏதேனும் ஒன்றில் உங்களுக்கு சிக்கல்கள் இருந்தால், அவற்றை அணைக்கலாம்.

DGX Spark மற்றும் ASUS Ascent GX10 போன்ற NVIDIA GB10 கணினிகளில், NVIDIA இன் DGX OS இல் உள்ளது போலவே suspend மற்றும் hibernation அணைக்கப்பட்டுள்ளன, ஏனெனில் அந்த வன்பொருளில் உறக்க நிலை இன்னும் செயல்படுவதாகக் காட்டப்படவில்லை. suspend ஐ நிலைமாற்றும் விருப்பமும் hibernation அமைப்பும் அங்கு பொருந்தாது. உறக்க நிலையை மீண்டும் இயக்க, `sudo rm` கொண்டு `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf` ஐ அகற்றவும்; அப்போது Suspend மெனுவுக்குத் திரும்பும், மற்ற கணினிகளில் உள்ளது போலவே hibernation ஐயும் அமைக்கலாம். `sudo omarchy apply hardware --install-user "$USER"` ஐ இயக்கினால் அந்தக் கோப்பு மீண்டும் வைக்கப்படும்.

### ஆற்றல் சுயவிவரங்கள்

மடிக்கணினியில், Omarchy உங்கள் ஆற்றல் சுயவிவரத்தை மின்சாரத்தில் செருகப்பட்ட நிலைக்கும் பேட்டரியில் இயங்கும் நிலைக்கும் தனித்தனியாக நினைவில் வைத்திருக்கும், நீங்கள் செருகும்போதும் கழற்றும்போதும் அவ்விரண்டுக்கும் இடையே மாறும். தொடக்கத்திலேயே இதன் பொருள் AC இல் performance மற்றும் பேட்டரியில் balanced என்பதாகும்.

உங்கள் கணினி எவற்றை வழங்குகிறது என்பதை `omarchy powerprofiles list` கொண்டு பார்க்கலாம், நீங்கள் தற்போது இருக்கும் நிலைக்கு விரும்பும் ஒன்றை `omarchy powerprofiles set autodetect power-saver` கொண்டு அமைக்கலாம். எதையும் கழற்றாமல் மற்ற நிலையை அமைக்க, அதை நேரடியாகப் பெயரிடவும்: `omarchy powerprofiles set battery power-saver`. நீங்கள் எதைத் தேர்ந்தெடுத்தாலும், அடுத்த முறை நீங்கள் அந்த நிலையில் இருக்கும்போது உங்களுக்குக் கிடைப்பது அதுவே ஆகும்.

### suspend ஐ நிலைமாற்றுதல்

முனையத்திலிருந்து `omarchy toggle suspend` ஐ இயக்குவதன் மூலம் suspend ஐ நிலைமாற்றலாம். அது _System_ இன் கீழ் உள்ள விருப்பத்தை வெறுமனே வெளிப்படுத்துகிறது/மறைக்கிறது (அல்லது `Super + Esc`), பின்னர் அது உங்கள் கணினியில் தொடர்ந்து செயல்படுகிறதா என்பதைப் பார்க்கலாம். இல்லையெனில், அதே கட்டளையைக் கொண்டு அதை மீண்டும் மறைக்கலாம்.

### hibernation ஐ நிலைமாற்றுதல்

முனையத்திலிருந்து `omarchy hibernation setup` ஐ இயக்குவதன் மூலம் hibernation ஐ அமைக்கலாம். Hibernation உங்கள் நேரடி RAM ஒதுக்கீட்டின் அளவில் உங்கள் boot இயக்ககத்தில் /swap துணைத் தொகுதி ஒன்றை உருவாக்குகிறது, எனவே உங்களிடம் ஏராளமான இடம் மீதம் இருப்பதை உறுதிப்படுத்திக் கொள்ளவும். 32GB கணினியில், இந்தத் தொகுதிக்கு உங்களுக்கு எப்போதும் 32GB+ இடம் தேவைப்படும். Hibernation க்கு இயல்புநிலை Limine bootloader ம் தேவை.

அமைக்கப்பட்டதும், _System_ இன் கீழ் hibernate விருப்பத்தைக் காண்பீர்கள் (அல்லது `Super + Esc`), பின்னர் அது உங்கள் கணினியில் தொடர்ந்து செயல்படுகிறதா என்பதைப் பார்க்கலாம். இல்லையெனில், `omarchy hibernation remove` ஐ இயக்குவதன் மூலம் அதை மீண்டும் அகற்றலாம்.
