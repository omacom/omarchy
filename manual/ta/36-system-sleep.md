# கணினி உறக்கம்

Omarchy இயல்பாகவே suspend-ஐ இயக்குகிறது, அமைத்த பிறகு hibernation-ஐயும் இயக்குகிறது, ஆனால் உங்கள் கணினியில் இவற்றில் ஏதேனும் ஒன்றில் சிக்கல்கள் இருந்தால், அவற்றை முடக்கலாம்.

NVIDIA GB10 கணினிகளில், எடுத்துக்காட்டாக DGX Spark மற்றும் ASUS Ascent GX10 ஆகியவற்றில், NVIDIA-வின் DGX OS-இல் இருப்பதைப் போலவே suspend மற்றும் hibernation முடக்கப்பட்டுள்ளன, ஏனெனில் அந்த வன்பொருளில் உறக்கம் இன்னும் செயல்படுவது நிரூபிக்கப்படவில்லை. ASUS Zenbook A16 (UX3607OA)-க்கும் இதுவே பொருந்தும்; அங்கு suspend இன்னும் chip-ஐ முழுமையாக உறக்க நிலைக்குக் கொண்டு செல்லாது, இரவு முழுவதும் சிக்கிக் கொள்ளலாம். suspend நிலைமாற்றமும் hibernation அமைப்பும் அங்கு பொருந்தாது. உறக்கத்தை மீண்டும் இயக்க, `sudo rm` கொண்டு `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf`-ஐ நீக்கவும்; பின்னர் Suspend மெனுவுக்குத் திரும்பும், மற்ற கணினிகளில் உள்ளதைப் போலவே hibernation-ஐ அமைக்கலாம். `sudo omarchy apply hardware --install-user "$USER"`-ஐ இயக்கினால் கோப்பு மீண்டும் வைக்கப்படும்.

### மின் சுயவிவரங்கள்

மடிக்கணினியில், Omarchy உங்கள் மின் சுயவிவரத்தை மின்னிணைப்பில் இணைக்கப்பட்ட நிலைக்கும் battery-இல் இயங்கும் நிலைக்கும் தனித்தனியாக நினைவில் வைத்திருக்கும், நீங்கள் இணைக்கும்போதும் துண்டிக்கும்போதும் இரண்டுக்கும் இடையே மாறும். பெட்டியிலிருந்து எடுத்தவுடனேயே, அது AC-இல் performance என்றும் battery-இல் balanced என்றும் பொருள்.

உங்கள் கணினி வழங்குவதை `omarchy powerprofiles list` கொண்டு பார்க்கலாம், நீங்கள் தற்போது இருக்கும் நிலைக்கு வேண்டியதை `omarchy powerprofiles set autodetect power-saver` கொண்டு அமைக்கலாம். எதையும் துண்டிக்காமல் மற்ற நிலையை அமைக்க, அதை நேரடியாகக் குறிப்பிடவும்: `omarchy powerprofiles set battery power-saver`. நீங்கள் தேர்ந்தெடுப்பதே அடுத்த முறை அந்த நிலையில் இருக்கும்போது உங்களுக்குக் கிடைக்கும்.

### suspend நிலைமாற்றம்

terminal-இலிருந்து `omarchy toggle suspend`-ஐ இயக்குவதன் மூலம் suspend-ஐ நிலைமாற்றலாம். அது _System_-இன் கீழ் (அல்லது `Super + Esc`) அந்த விருப்பத்தை வெளிப்படுத்தும்/மறைக்கும், பின்னர் அது உங்கள் கணினியில் தொடர்ந்து செயல்படுகிறதா என்று பார்க்கலாம். இல்லையெனில், அதே கட்டளையைக் கொண்டு அதை மீண்டும் மறைக்கலாம்.

### hibernation நிலைமாற்றம்

terminal-இலிருந்து `omarchy hibernation setup`-ஐ இயக்குவதன் மூலம் hibernation-ஐ அமைக்கலாம் (இது Apple Silicon Macs-இல் கிடைக்காது). Hibernation உங்கள் boot drive-இல் உங்கள் physical RAM ஒதுக்கீட்டின் அளவுக்கு ஒரு /swap subvolume-ஐ உருவாக்கும், எனவே உங்களிடம் ஏராளமான காலி இடம் இருப்பதை உறுதிப்படுத்திக் கொள்ளவும். 32GB கணினியில், இந்த volume-க்கு உங்களுக்கு எப்போதும் 32GB+ காலி இடம் தேவைப்படும். Hibernation-க்கு இயல்புநிலை Limine bootloader-ம் தேவை.

அமைத்தவுடன், _System_-இன் கீழ் (அல்லது `Super + Esc`) hibernate விருப்பத்தைக் காண்பீர்கள், பின்னர் அது உங்கள் கணினியில் தொடர்ந்து செயல்படுகிறதா என்று பார்க்கலாம். இல்லையெனில், `omarchy hibernation remove`-ஐ இயக்குவதன் மூலம் அதை மீண்டும் நீக்கலாம்.
