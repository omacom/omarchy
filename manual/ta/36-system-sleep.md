# கணினி உறக்கம்

Omarchy இயல்பாகவே suspend-ஐ இயக்குகிறது, அது அமைக்கப்பட்டவுடன் hibernation-ஐயும் இயக்குகிறது, ஆனால் உங்கள் கணினியில் இவற்றில் ஏதேனும் ஒன்றில் உங்களுக்கு சிக்கல்கள் இருந்தால், அவற்றை அணைத்துவிடலாம்.

DGX Spark மற்றும் ASUS Ascent GX10 போன்ற NVIDIA GB10 கணினிகளில், NVIDIA-இன் DGX OS-இல் இருப்பதைப் போலவே, suspend மற்றும் hibernation அணைக்கப்பட்டுள்ளன, ஏனெனில் அந்த வன்பொருளில் உறக்கம் இன்னும் வேலை செய்வதாகக் காட்டப்படவில்லை. suspend மாற்றி மற்றும் hibernation அமைப்பு அங்கு பொருந்தாது. உறக்கத்தை மீண்டும் இயக்க, `sudo rm` கொண்டு `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf` ஐ அகற்றவும்; பின்னர் Suspend மெனுவிற்குத் திரும்பும், மற்றும் hibernation-ஐ மற்ற கணினிகளில் உள்ளதைப் போலவே அமைக்கலாம். `sudo omarchy apply hardware --install-user "$USER"` ஐ இயக்குவது கோப்பை மீண்டும் வைக்கும்.

### ஆற்றல் சுயவிவரங்கள்

ஒரு மடிக்கணினியில், Omarchy உங்கள் ஆற்றல் சுயவிவரத்தை செருகப்பட்ட நிலைக்கும் பேட்டரியில் இயங்கும் நிலைக்கும் தனித்தனியாக நினைவில் வைத்திருக்கிறது, மேலும் நீங்கள் செருகும்போதும் அகற்றும்போதும் இரண்டிற்கும் இடையே மாறுகிறது. பெட்டியிலிருந்து எடுத்தவுடனேயே அதன் பொருள் AC-இல் performance மற்றும் பேட்டரியில் balanced என்பதாகும்.

உங்கள் கணினி எதை வழங்குகிறது என்பதை `omarchy powerprofiles list` கொண்டு பார்க்கலாம், மேலும் நீங்கள் தற்போது இருக்கும் நிலைக்கு விரும்பும் ஒன்றை `omarchy powerprofiles set autodetect power-saver` கொண்டு அமைக்கலாம். எதையும் அகற்றாமல் மற்ற நிலையை அமைக்க, அதை நேரடியாகப் பெயரிடவும்: `omarchy powerprofiles set battery power-saver`. நீங்கள் எதைத் தேர்ந்தெடுத்தாலும், அடுத்த முறை நீங்கள் அந்த நிலையில் இருக்கும்போது அதையே திரும்பப் பெறுவீர்கள்.

### Suspend-ஐ மாற்றுதல்

முனையத்திலிருந்து `omarchy toggle suspend` ஐ இயக்குவதன் மூலம் suspend-ஐ மாற்றலாம். அது _System_ (அல்லது `Super + Esc`) கீழ் உள்ள விருப்பத்தை வெளிப்படுத்துகிறது/மறைக்கிறது, பின்னர் அது உங்கள் கணினியில் தொடர்ந்து வேலை செய்கிறதா என்று பார்க்கலாம். இல்லையெனில், அதே கட்டளையைக் கொண்டு அதை மீண்டும் மறைக்கலாம்.

### Hibernation-ஐ மாற்றுதல்

முனையத்திலிருந்து `omarchy hibernation setup` ஐ இயக்குவதன் மூலம் hibernation-ஐ அமைக்கலாம் (இது Apple Silicon Macs-இல் கிடைக்காது). Hibernation உங்கள் துவக்க இயக்ககத்தில் உங்கள் physical RAM ஒதுக்கீட்டின் அளவில் ஒரு /swap subvolume-ஐ உருவாக்குகிறது, எனவே உங்களிடம் ஏராளமான இடம் மீதம் இருப்பதை உறுதிப்படுத்திக் கொள்ளவும். 32GB கணினியில், இந்த volume-க்கு உங்களுக்கு எப்போதும் 32GB+ இலவச இடம் தேவைப்படும். Hibernation-க்கு இயல்புநிலை Limine bootloader-ம் தேவை.

அமைக்கப்பட்டதும், _System_ (அல்லது `Super + Esc`) கீழ் hibernate விருப்பத்தைக் காண்பீர்கள், பின்னர் அது உங்கள் கணினியில் தொடர்ந்து வேலை செய்கிறதா என்று பார்க்கலாம். இல்லையெனில், `omarchy hibernation remove` ஐ இயக்குவதன் மூலம் அதை மீண்டும் அகற்றலாம்.
