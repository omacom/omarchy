# Mac ஆதரவு

## Apple Silicon-க்கான Omarchy

Apple Silicon-க்கான Omarchy என்பது Omacom-இன் அதிகாரப்பூர்வ தீர்வு; முதலில் Omarchy 4.5 உடன் வெளியிடப்பட்டது. இது macOS-க்கு அருகிலேயே நிறுவப்படும்; உங்கள் Mac தொடங்கும்போது இரண்டில் ஒன்றை நீங்கள் தேர்வு செய்யலாம்.

Omarchy Mac பற்றிய அறிவிப்பு கிடைத்ததா? [Omarchy Mac-இலிருந்து வருதல்](#coming-from-omarchy-mac) என்பதற்குச் செல்லவும்.

இது இந்த Mac-களில் இயங்கும்:

| Mac | சிப்கள் |
| --- | --- |
| MacBook Air | M1, M2, M3 |
| MacBook Pro | M1, M1 Pro, M1 Max, M2, M2 Pro, M2 Max, M3, M3 Pro, M3 Max |
| MacBook Neo | A18 Pro |
| Mac mini | M1, M2, M2 Pro |
| Mac Studio | M1 Max, M1 Ultra, M2 Max, M2 Ultra |
| iMac | M1, M3 |
| Mac Pro | M2 Ultra |

M4 மற்றும் அதற்குப் பிந்தைய Mac-கள் இன்னும் ஆதரிக்கப்படவில்லை. M4 ஆதரவு edge சேனலில் சோதனையில் உள்ளது; அடுத்து வரும். எதையும் மாற்றுவதற்கு முன் நிறுவி உங்கள் Mac-ஐச் சரிபார்க்கும்.

M4 மற்றும் அதற்குப் பிந்தையவை உட்பட எந்த Apple Silicon Mac-இலும், [Try Omarchy](https://github.com/omacom/try-omarchy) கொண்டு Omarchy-ஐ ஒரு மெய்நிகர் இயந்திரத்தில் இயக்கலாம்.

### உங்களுக்குத் தேவையானவை

- macOS 15 Sequoia அல்லது அதற்குப் பிந்தையது, மற்றும் ஒரு நிர்வாகி கணக்கு
- Omarchy-க்கான காலி வட்டு இடம். நிறுவி ஒரு அளவைப் பரிந்துரைக்கும்; அதை நீங்கள் மாற்றவும் முடியும்.
- உங்கள் Mac-இன் காப்புப்பிரதி, மின்சாரம், மற்றும் ஒரு இணைய இணைப்பு. நிறுவல் பல ஜிகாபைட்களைப் பதிவிறக்கும்.

### நிறுவுதல்

நீங்கள் macOS-இலிருந்து நிறுவுகிறீர்கள். [Homebrew](https://brew.sh) கொண்டு Omarchy Installer-ஐ நிறுவவும்:

```sh
brew install omacom/mac/omarchy
```

அல்லது அதன் [வெளியீடுகள் பக்கத்திலிருந்து](https://github.com/omacom/omarchy-mac-installer/releases) புதிய Omarchy Installer-ஐப் பதிவிறக்கி அதைத் திறக்கவும்.

நிறுவி உங்கள் Mac-ஐச் சரிபார்த்து, திட்டத்தை உங்களுக்குக் காட்டி, macOS பகிர்வைச் சுருக்கி Omarchy-க்கு இடம் ஒதுக்கும். macOS வட்டில் அப்படியே இருக்கும்; USB டிரைவ் தேவையில்லை. முதல் கட்டம் முடிந்ததும், macOS Recovery-இல் அமைப்பை முடிப்பதற்கு அது உங்களை வழிநடத்தும்: அணைக்கவும், "Loading startup options" தோன்றும் வரை பவர் பொத்தானைப் பிடித்திருக்கவும், Omarchy-ஐத் தேர்வு செய்து படிகளைப் பின்பற்றவும்.

முதல் துவக்கத்தில், அதன் வட்டை மறையாக்கம் செய்யும் கடவுச்சொல்லை Omarchy கேட்கும். மீட்பு விசை எதுவும் இல்லை: கடவுச்சொல்லை மறந்தால், உங்கள் Omarchy கோப்புகளை மீட்க முடியாது.

பிறகு Omarchy-க்கும் macOS-க்கும் இடையே மாற, அணைக்கவும், பின்னர் தொடக்க விருப்பங்கள் தோன்றும் வரை பவர் பொத்தானைப் பிடித்திருந்து ஒன்றைத் தேர்வு செய்யவும்.

### Omarchy Mac-இலிருந்து வருதல்

Omarchy Mac இப்போது Apple Silicon-க்கான Omarchy-இன் பகுதியாக உள்ளது; அதை இயக்கிய ஒவ்வொரு Mac-உம் ஆதரிக்கப்படுகிறது. உங்கள் தற்போதைய நிறுவல் தொடர்ந்து இயங்கும்; அதன் கணினி தொகுப்புகள் இன்னும் புதுப்பிக்கப்படும்; ஆனால் அதற்கு மேலும் Omarchy புதுப்பிப்புகள் எதுவும் கிடைக்காது. காலக்கெடு எதுவும் இல்லை; அதே இடத்தில் மேம்படுத்தலும் இல்லை: நீங்கள் காப்புப்பிரதி எடுக்கிறீர்கள், பழைய நிறுவலை நீக்குகிறீர்கள், புதிதாக நிறுவுகிறீர்கள், மீட்டமைக்கிறீர்கள். 2 முதல் 5 வரையிலான படிகள் macOS-இல் நடக்கும்; எனவே மீண்டும் தொடங்குவதற்கு முன் உங்கள் தொலைபேசியில் இந்தப் பக்கத்தைத் திறக்கவும்.

1. **Omarchy-இலிருந்து, Mac-க்கு வெளியே காப்புப்பிரதி எடுக்கவும்.** பழைய நிறுவலை நீக்குவது அதை அழித்துவிடும்; macOS-ஆல் Omarchy வட்டைப் படிக்க முடியாது. SSH மற்றும் GPG விசைகள், உலாவி சுயவிவரங்கள், மற்றும் தள்ளப்படாத வேலை உட்பட உங்கள் முகப்பு கோப்புறையை ஒரு வெளிப்புற டிரைவிற்கு அல்லது மற்றொரு கணினிக்கு நகலெடுக்கவும். `pacman -Qqe > ~/packages.txt` கொண்டு உங்கள் தொகுப்பு பட்டியலைச் சேமிக்கவும். நீக்குதலும் நிறுவுதலும் அதன் வட்டின் அளவை மாற்றுவதால், macOS-ஐயும் காப்புப்பிரதி எடுக்கவும்.
2. **உங்கள் Mac-ஐ macOS-இல் தொடங்கவும்.** அணைக்கவும், தொடக்க விருப்பங்கள் தோன்றும் வரை பவர் பொத்தானைப் பிடித்திருக்கவும், macOS-ஐத் தேர்வு செய்யவும்.
3. **[நிறுவுதல்](#installing) இல் காட்டியபடி Omarchy Installer-ஐ நிறுவவும்.**
4. **பழைய நிறுவலை நீக்கவும்.** Omarchy Installer-ஐத் திறந்து Installation > Remove Omarchy என்பதைத் தேர்வு செய்யவும். அது எதை நீக்கும் என்பதைக் காட்டி, இடத்தை macOS-க்குத் திருப்பித் தரும். உங்கள் நிறுவலை அது அடையாளம் காணவில்லை என்றால், வட்டை மாற்றாமல் அது நிற்கும். பகிர்வுகளைக் கையால் நீக்குவதற்குப் பதிலாக [Discord](https://discord.gg/tXFUdasqhY) இல் உதவி கேட்கவும்; அது macOS-ஐ அழித்துவிடக் கூடும்.
5. **நிறுவியைக் கொண்டு Apple Silicon-க்கான Omarchy-ஐ நிறுவவும்.**
6. **உங்கள் கோப்புகளை மீட்டமைக்கவும்.** `~/.config` முழுவதையும் புதிய இயல்புநிலைகளின் மேல் நகலெடுப்பதற்குப் பதிலாக, உங்கள் அமைப்புகளை ஒவ்வொன்றாகத் திரும்பக் கொண்டு வரவும்; பழைய அமைப்புகள் அவற்றை மேலெழுதக் கூடும்.

### தெரிந்து கொள்ள வேண்டியவை

- M1 மற்றும் M2 MacBook-களில், மூடியைத் திறப்பதால் அல்லது பவர் பொத்தானை அழுத்துவதால் தூக்கத்திலிருந்து விழிக்கவும்.
- கேள்விகள் அல்லது சிக்கல்கள்: எங்கள் [Discord](https://discord.gg/tXFUdasqhY) இல் கேட்கவும்.

[நிறுவியின் README](https://github.com/omacom/omarchy-mac-installer#readme) வெளியீட்டு சேனல்கள், நிறுவியைப் புதுப்பித்தல், மற்றும் Omarchy-ஐ நீக்குதல் ஆகியவற்றை உள்ளடக்கும்.

## Intel Mac-கள்

ஒரு எளிய சோதனையில், Omarchy-ஐ நிறுவியதாலேயே 2019 MacBook Pro-இல் 36% செயல்திறன் மேம்பாட்டை எங்களால் அடைய முடிந்தது.

 ![macbook-omarchy](images/macbook-omarchy.webp)

### Mac-இல் Omarchy-ஐ நிறுவுதல்

தற்போது நிறுவப்படும் **ஒரே** OS ஆக இருப்பதை மட்டுமே Omarchy ஆதரிக்கிறது. நிறுவலின் போது, டிரைவ் அழிக்கப்படும்; MacOS இனி துவக்க முடியாததாகிவிடும்.

நீங்கள் விரும்பினால் பிறகு Internet Recovery வழியாக அதை இன்னும் மீட்டமைக்கலாம்.

இந்தப் பகுதிக்காக, நீங்கள் ஏற்கனவே [தொடங்குதல்](02-getting-started.md) என்பதைப் பார்த்து, உங்கள் USB டிரைவைத் தயாராக வைத்திருப்பதாகக் கொள்வோம். இல்லையெனில் இப்போதே அதைச் செய்யவும்.

#### Secure Boot-ஐ முடக்குதல்

துவக்க முடியும் USB-ஐயும், OS-ஐயும் துவக்குவதற்கு Apple-இன் Secure Boot-ஐ முடக்குவது அவசியம். அதை முடக்க, பின்வருவனவற்றைச் செய்யவும்:

1. உங்கள் Mac-ஐ அணைக்கவும்
2. அதை இயக்கி, ஏற்றுதல் திரை தோன்றும் வரை _உடனடியாக_ Command-R ஐ அழுத்திப் பிடிக்கவும்
3. உங்கள் பயனரைத் தேர்வு செய்து, கேட்கப்பட்டால் உங்கள் கடவுச்சொல்லை உள்ளிடவும்
4. மீட்புத் திரையில் நுழைந்ததும், மெனுபட்டியிலிருந்து **Utilities > Startup Security Utility** என்பதைத் தேர்வு செய்யவும்
5. அங்கீகரிக்குமாறு கேட்கப்படும்போது உங்கள் கடவுச்சொல்லை உள்ளிடவும்
6. Secure Boot விருப்பங்களிலிருந்து "No Security" என்பதைத் தேர்வு செய்யவும்
7. External Boot விருப்பங்களிலிருந்து "Allow booting from external or removable media" என்பதைத் தேர்வு செய்யவும்

#### நிறுவலைத் தொடங்குதல்

1. USB டிரைவைச் செருகவும்
2. உங்கள் Mac-ஐ மீண்டும் தொடங்கி, துவக்க சாதனங்களின் திரை தெரியும் வரை _உடனடியாக_ Option ஐ அழுத்திப் பிடிக்கவும்
3. ஆரஞ்சு நிற EFI Boot சாதனத்தைத் தேர்வு செய்யவும்
4. [வழக்கம்போல் நிறுவலுடன்](02-getting-started.md) தொடரவும்

நிறுவி Mac வன்பொருளைக் கண்டறிந்து தேவையான திருத்தங்களைத் தானாகவே பயன்படுத்துகிறது: Broadcom Wi-Fi இயக்கிகள் மற்றும் ஃபர்ம்வேர், Broadcom 1570 கொண்ட இயந்திரங்களில் FaceTime HD கேமரா இயக்கி (நிறுவி ஆஃப்லைனில் வேலை செய்வதால், Mac ஆன்லைனுக்கு வந்ததும் அதன் ஃபர்ம்வேர் Apple-இலிருந்து பதிவிறக்கப்படும்), அவை தேவைப்படும் MacBook மாடல்களில் SPI விசைப்பலகை இயக்கி, மற்றும் அதே மாடல்களுக்கான NVMe இடைநிறுத்தத் திருத்தம்.

### அறியப்பட்ட வரம்புகள்

சமூக உறுப்பினர்கள் இந்தச் சவால்களுக்குத் தீர்வுகளைத் தொடர்ந்து உருவாக்கி வருகிறார்கள்; எனவே இவை உங்களுக்குச் சிக்கலாக இருந்தால், எங்கள் [Discord](https://discord.gg/tXFUdasqhY) இல் #omarchy-on-other சேனலில் சேர்ந்து, இவற்றைத் தீர்க்க ஏதேனும் புதுப்பித்த முறைகள் உள்ளனவா என்று பார்க்கவும்.

#### FaceTime HD கேமரா

Mac நீளுறக்கத்திற்குச் செல்லும்போது கேமரா இயக்கி ஏற்றப்பட்டிருந்தால் அது இயந்திரத்தைச் செயலிழக்கச் செய்யும்; எனவே அது முதலில் இறக்கப்படும். ஒரு பயன்பாடு கேமராவைத் திறந்து வைத்திருக்கும்போது அதை இறக்க முடியாது; எனவே அந்தப் பயன்பாட்டின் பெயரைக் குறிப்பிடும் அறிவிப்புடன் நீளுறக்கம் ரத்து செய்யப்படும்: அதை மூடிவிட்டு மீண்டும் நீளுறக்கத்திற்குச் செல்லவும். பேட்டரி மிகக் குறைவாக இருக்கும்போது தானாக நீளுறக்கத்திற்குச் செல்வதும் இதில் அடங்கும்; மற்றும் இடைநிறுத்தம்-பின்-நீளுறக்கம், அது இடைநிறுத்தப்படுவதற்கு முன்பே மறுக்கப்படும். கேமரா திறந்திருக்கும்போது சாதாரண இடைநிறுத்தத்தை இயக்கியே, அறிவிப்பு இல்லாமல், மறுக்கும்.

கேமராவின் ஃபர்ம்வேர் Apple-இலிருந்து பதிவிறக்கப்படும்; எனவே Mac ஆன்லைனுக்கு வந்த பிறகே கேமரா வேலை செய்யும். பதிவிறக்கம் துவக்கத்தில் தொடங்கும்; நெட்வொர்க்தான் சிக்கல் என்றால் ஒவ்வொரு 15 நிமிடங்களுக்கும் மீண்டும் முயற்சிக்கப்படும்; Apple-இன் கோப்பு மாறியிருந்தால், அது நின்று Omarchy புதுப்பிப்பிற்காகக் காத்திருக்கும். கேமரா தோன்றவில்லை என்றால், `journalctl -u facetimehd-firmware-fetcher` ஏன் என்று சொல்லும், `sudo systemctl restart facetimehd-firmware-fetcher` மீண்டும் முயற்சிக்கும், மற்றும் பதிவிறக்கம் முடிந்தும் கேமரா இன்னும் அங்கு இல்லை என்றால் மறுதுவக்கம் இயக்கியை ஏற்றும்.
