# Mac ஆதரவு

## Apple Silicon-க்கான Omarchy

Apple Silicon-க்கான Omarchy என்பது Omacom-இன் அதிகாரப்பூர்வ தீர்வு; Omarchy 4.5 உடன் முதன்முதலில் வெளியிடப்பட்டது. இது macOS-க்கு அருகில் நிறுவப்படும், உங்கள் Mac தொடங்கும்போது இரண்டில் ஒன்றைத் தேர்ந்தெடுக்கலாம்.

Omarchy Mac பற்றிய அறிவிப்பு வந்ததா? [Omarchy Mac-இலிருந்து வருதல்](#coming-from-omarchy-mac) பகுதிக்குச் செல்லவும்.

இது இந்த Mac-களில் இயங்கும்:

| Mac | சிப்கள் |
| --- | --- |
| MacBook Air | M1, M2, M3 |
| MacBook Pro | M1, M1 Pro, M1 Max, M2, M2 Pro, M2 Max, M3, M3 Pro, M3 Max |
| MacBook Neo | A18 Pro |
| Mac mini | M1, M2, M2 Pro |
| Mac Studio | M1 Max, M1 Ultra, M2 Max, M2 Ultra |
| iMac | M1, M3 |
| Mac Pro | M2 Ultra |

M4 மற்றும் அதற்குப் பிந்தைய Mac-கள் இன்னும் ஆதரிக்கப்படவில்லை. M4 ஆதரவு edge சேனலில் சோதனையில் உள்ளது, அடுத்து வரும். நிறுவி எதையும் மாற்றுவதற்கு முன் உங்கள் Mac-ஐச் சரிபார்க்கும்.

M4 மற்றும் அதற்குப் பிந்தையவை உட்பட எந்த Apple Silicon Mac-இலும், [Try Omarchy](https://github.com/omacom/try-omarchy) மூலம் மெய்நிகர் இயந்திரத்தில் Omarchy-ஐ இயக்கலாம்.

### உங்களுக்குத் தேவையானவை

- macOS 15 Sequoia அல்லது அதற்குப் பிந்தையது, மற்றும் நிர்வாகி கணக்கு
- Omarchy-க்கான இலவச வட்டு இடம். நிறுவி ஒரு அளவைப் பரிந்துரைக்கும், அதை மாற்றவும் அனுமதிக்கும்.
- உங்கள் Mac-இன் காப்புப்பிரதி, மின்சாரம், மற்றும் இணைய இணைப்பு. நிறுவல் பல ஜிகாபைட்களைப் பதிவிறக்கும்.

### நிறுவுதல்

நீங்கள் macOS-இலிருந்து நிறுவுகிறீர்கள். [Homebrew](https://brew.sh) மூலம் Omarchy Installer-ஐ நிறுவவும்:

```sh
brew install omacom/mac/omarchy
```

அல்லது அதன் [வெளியீடுகள் பக்கத்திலிருந்து](https://github.com/omacom/omarchy-mac-installer/releases) புதிய Omarchy Installer-ஐப் பதிவிறக்கி திறக்கவும்.

நிறுவி உங்கள் Mac-ஐச் சரிபார்த்து, திட்டத்தைக் காட்டி, macOS பகிர்வைச் சுருக்கி Omarchy-க்கு இடம் ஒதுக்கும். macOS வட்டில் அப்படியே இருக்கும், USB டிரைவ் தேவையில்லை. முதல் கட்டம் முடிந்ததும், macOS Recovery-இல் அமைப்பை முடிக்க அது உங்களுக்கு வழிகாட்டும்: அணைத்துவிட்டு, "Loading startup options" தோன்றும் வரை பவர் பொத்தானை அழுத்திப் பிடித்து, Omarchy-ஐத் தேர்ந்தெடுத்து, படிகளைப் பின்பற்றவும்.

முதல் முறை தொடங்கும்போது, Omarchy அதன் வட்டை மறையாக்கம் செய்யும் கடவுச்சொல்லைக் கேட்கும். மீட்பு விசை எதுவும் இல்லை: கடவுச்சொல்லை மறந்துவிட்டால், உங்கள் Omarchy கோப்புகளை மீட்க முடியாது.

பின்னர் Omarchy மற்றும் macOS இடையே மாற, அணைத்துவிட்டு, தொடக்க விருப்பங்கள் தோன்றும் வரை பவர் பொத்தானை அழுத்திப் பிடித்து, ஒன்றைத் தேர்ந்தெடுக்கவும்.

### Omarchy Mac-இலிருந்து வருதல்

Omarchy Mac இப்போது Apple Silicon-க்கான Omarchy-இன் ஒரு பகுதி, அதை இயக்கிய ஒவ்வொரு Mac-ம் ஆதரிக்கப்படுகிறது. உங்கள் தற்போதைய நிறுவல் தொடர்ந்து இயங்கும், அதன் சிஸ்டம் தொகுப்புகள் இன்னும் புதுப்பிக்கப்படும், ஆனால் அதற்கு மேலும் Omarchy புதுப்பிப்புகள் கிடைக்காது. காலக்கெடு எதுவும் இல்லை, இடத்திலேயே மேம்படுத்தலும் இல்லை: காப்புப்பிரதி எடுத்து, பழைய நிறுவலை நீக்கி, புதிதாக நிறுவி, மீட்டமைக்க வேண்டும். 2 முதல் 5 வரையிலான படிகள் macOS-இல் நடக்கும், எனவே மறுதொடக்கம் செய்வதற்கு முன் இந்தப் பக்கத்தை உங்கள் தொலைபேசியில் திறக்கவும்.

1. **Omarchy-இலிருந்து, Mac-க்கு வெளியே காப்புப்பிரதி எடுக்கவும்.** பழைய நிறுவலை நீக்குவது அதை அழித்துவிடும், macOS-ஆல் Omarchy வட்டைப் படிக்க முடியாது. SSH மற்றும் GPG விசைகள், உலாவி சுயவிவரங்கள் மற்றும் தள்ளப்படாத வேலை உட்பட உங்கள் home கோப்புறையை வெளிப்புற டிரைவ் அல்லது மற்றொரு கணினிக்கு நகலெடுக்கவும். `pacman -Qqe > ~/packages.txt` மூலம் உங்கள் தொகுப்பு பட்டியலைச் சேமிக்கவும். நீக்குவதும் நிறுவுவதும் அதன் வட்டின் அளவை மாற்றும் என்பதால் macOS-ஐயும் காப்புப்பிரதி எடுக்கவும்.
2. **உங்கள் Mac-ஐ macOS-இல் தொடங்கவும்.** அணைத்துவிட்டு, தொடக்க விருப்பங்கள் தோன்றும் வரை பவர் பொத்தானை அழுத்திப் பிடித்து, macOS-ஐத் தேர்ந்தெடுக்கவும்.
3. [நிறுவுதல்](#installing) பகுதியில் காட்டியபடி **Omarchy Installer-ஐ நிறுவவும்**.
4. **பழைய நிறுவலை நீக்கவும்.** Omarchy Installer-ஐத் திறந்து Installation > Remove Omarchy என்பதைத் தேர்ந்தெடுக்கவும். அது எதை நீக்கும் என்பதைக் காட்டி, இடத்தை macOS-க்குத் திருப்பித் தரும். உங்கள் நிறுவலை அது அடையாளம் காணவில்லை என்றால், வட்டை மாற்றாமல் நின்றுவிடும். பகிர்வுகளைக் கையால் நீக்குவதற்குப் பதிலாக [Discord](https://discord.gg/tXFUdasqhY)-இல் உதவி கேட்கவும்; அது macOS-ஐ அழித்துவிடக்கூடும்.
5. நிறுவி மூலம் **Apple Silicon-க்கான Omarchy-ஐ நிறுவவும்**.
6. **உங்கள் கோப்புகளை மீட்டமைக்கவும்.** `~/.config` முழுவதையும் புதிய இயல்புநிலைகள் மீது நகலெடுப்பதற்குப் பதிலாக உங்கள் அமைப்புகளை ஒவ்வொன்றாகத் திரும்பக் கொண்டு வரவும், ஏனெனில் பழைய அமைப்புகள் அவற்றை மீறிவிடக்கூடும்.

### தெரிந்து கொள்ள வேண்டியவை

- M1 மற்றும் M2 MacBook-களில், மூடியைத் திறப்பதன் மூலம் அல்லது பவர் பொத்தானை அழுத்துவதன் மூலம் உறக்கத்திலிருந்து எழுப்பவும்.
- கேள்விகள் அல்லது சிக்கல்கள்: எங்கள் [Discord](https://discord.gg/tXFUdasqhY)-இல் கேட்கவும்.

[நிறுவியின் README](https://github.com/omacom/omarchy-mac-installer#readme) வெளியீட்டு சேனல்கள், நிறுவியைப் புதுப்பித்தல் மற்றும் Omarchy-ஐ நீக்குதல் ஆகியவற்றை உள்ளடக்கும்.

## Intel Mac-கள்

ஒரு எளிய சோதனையில், Omarchy-ஐ நிறுவுவதன் மூலமே 2019 MacBook Pro-இல் 36% செயல்திறன் மேம்பாட்டை எங்களால் அடைய முடிந்தது.

 ![macbook-omarchy](images/macbook-omarchy.webp)

### Mac-இல் Omarchy-ஐ நிறுவுதல்

Omarchy தற்போது நிறுவப்படும் **ஒரே** OS ஆக இருப்பதை மட்டுமே ஆதரிக்கிறது. நிறுவலின்போது, டிரைவ் முழுவதும் அழிக்கப்படும், MacOS இனி தொடங்க முடியாது.

நீங்கள் விரும்பினால் பின்னர் Internet Recovery மூலம் அதை இன்னும் மீட்டமைக்கலாம்.

இந்தப் பகுதிக்காக, நீங்கள் ஏற்கனவே [தொடங்குதல்](02-getting-started.md) பகுதியைப் பார்த்துவிட்டீர்கள், உங்கள் USB டிரைவ் தயாராக உள்ளது என்று கருதுவோம். இல்லையென்றால் இப்போதே அதைச் செய்யவும்.

#### Secure Boot-ஐ முடக்கவும்

தொடங்கக்கூடிய USB-ஐயும், OS-ஐயும் தொடங்க Apple-இன் Secure Boot-ஐ முடக்குவது அவசியம். அதை முடக்க, பின்வருவனவற்றைச் செய்யவும்:

1. உங்கள் Mac-ஐ அணைக்கவும்
2. அதை இயக்கி, ஏற்றும் திரை தோன்றும் வரை _உடனடியாக_ Command-R-ஐ அழுத்திப் பிடிக்கவும்
3. உங்கள் பயனரைத் தேர்ந்தெடுத்து, கேட்கப்பட்டால் உங்கள் கடவுச்சொல்லை உள்ளிடவும்
4. மீட்புத் திரையில் வந்ததும், மெனுபாரிலிருந்து **Utilities > Startup Security Utility** என்பதைத் தேர்ந்தெடுக்கவும்
5. அங்கீகரிக்கக் கேட்கப்படும்போது உங்கள் கடவுச்சொல்லை உள்ளிடவும்
6. Secure Boot விருப்பங்களிலிருந்து "No Security" என்பதைத் தேர்ந்தெடுக்கவும்
7. External Boot விருப்பங்களிலிருந்து "Allow booting from external or removable media" என்பதைத் தேர்ந்தெடுக்கவும்

#### நிறுவலைத் தொடங்கவும்

1. USB டிரைவைச் செருகவும்
2. உங்கள் Mac-ஐ மறுதொடக்கம் செய்து, தொடக்க சாதனங்களின் திரையைக் காணும் வரை _உடனடியாக_ Option-ஐ அழுத்திப் பிடிக்கவும்
3. ஆரஞ்சு நிற EFI Boot சாதனத்தைத் தேர்ந்தெடுக்கவும்
4. [வழக்கம்போல் நிறுவலைத்](02-getting-started.md) தொடரவும்

நிறுவி Mac வன்பொருளைக் கண்டறிந்து தேவையான திருத்தங்களைத் தானாகவே பயன்படுத்தும்: Broadcom Wi-Fi இயக்கிகள் மற்றும் நிலைபொருள், அது தேவைப்படும் MacBook மாடல்களில் SPI விசைப்பலகை இயக்கி, அதே மாடல்களுக்கான NVMe இடைநிறுத்தத் திருத்தம்.

### அறியப்பட்ட வரம்புகள்

சமூக உறுப்பினர்கள் இந்தச் சவால்களுக்கான தீர்வுகளில் தொடர்ந்து பணியாற்றி வருகிறார்கள், எனவே இவை உங்களுக்குச் சிக்கலாக இருந்தால், எங்கள் [Discord](https://discord.gg/tXFUdasqhY)-இல் #omarchy-on-other இல் சேர்ந்து, இவற்றைத் தீர்க்க ஏதேனும் நவீன முறைகள் உள்ளனவா என்று பார்க்கவும்.

#### T1 சிப் கொண்ட சாதனங்கள்

Apple T1 சிப் 2016 இறுதியில் அறிமுகப்படுத்தப்பட்டது, Touch Bar கொண்ட முதல் தலைமுறை MacBook Pro மாடல்களில் மட்டுமே பயன்படுத்தப்பட்டது.
- MacBook Pro 13-இன்ச் (2016, இரண்டு Thunderbolt 3 போர்ட்கள்) – மாடல்: A1706
- MacBook Pro 13-இன்ச் (2016, நான்கு Thunderbolt 3 போர்ட்கள்) – மாடல்: A1708
- MacBook Pro 15-இன்ச் (2016) – மாடல்: A1707

#### அறியப்பட்ட சிக்கல்கள்

- Touch Bar செயல்படாது
