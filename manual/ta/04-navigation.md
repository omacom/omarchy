# வழிசெலுத்தல்

Omarchy-இல் அனைத்தும் விசைப்பலகை வழியாகவே நடக்கிறது — _அனைத்தும்!_ கணினி முதலில் தொடங்கும்போது, mouse-ஐ மட்டும் வைத்து உங்களால் உண்மையிலேயே எதுவுமே செய்ய முடியாது. ஆனால் `Super + Space` அழுத்தி Omarchy Menu-வைக் காட்டலாம், இங்கிருந்து கிட்டத்தட்ட எதையும் செய்யலாம்.

ஆனால் பெரும்பாலான நேரங்களில் கணினியை இயக்கும் முக்கிய வழியாக இருக்க Omarchy menu வடிவமைக்கப்படவே இல்லை. அதைவிட வேகமாக நாம் செயல்பட முடியும்! மிக முக்கியமான பயன்பாடுகள் அனைத்தும் தனித்தனி hotkey-களுடன் நேரடியாக இணைக்கப்பட்டுள்ளன. `Super + Return` அழுத்தி terminal-ஐயும், `Super + Shift + Return` அழுத்தி ஒரு browser-ஐயும் தொடங்குகிறீர்கள். ஒன்றன் பின் ஒன்றாக இரண்டையும் செய்து பாருங்கள், Hyprland-இன் tiling மாயாஜாலம் செயல்படுவதைக் காண்பீர்கள்:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

பிறகு `Super + J` அழுத்தி, அவற்றை அருகருகே வைப்பதற்குப் பதிலாக ஒன்றின் மேல் ஒன்றாக அடுக்கலாம்:

 ![navigation-stacked](images/navigation-stacked.webp)

மீண்டும் `Super + J` அழுத்தி அவற்றை அருகருகே இருந்த நிலைக்குத் திரும்பக் கொண்டு வாருங்கள். பிறகு browser-இல் இருக்கும்போது `Super + Shift + Arrow Right` முயற்சித்து, சாளரங்களை இடமாற்றுங்கள்.

இப்போது `Super + Shift + T` அழுத்தி Activity monitor-ஐத் தொடங்கிப் பாருங்கள். அது ஒரு floating சாளரமாகத் தோன்றும். `Super + T` பயன்படுத்தி அதை tile செய்யலாம் (மீண்டும் அதையே அழுத்தினால் அது மீண்டும் floating ஆகிவிடும்). இப்போது `Super + Shift + F` அழுத்தி file manager-ஐத் திறங்கள். உங்களுக்கு நேர்த்தியான நான்கு பிரிவு அமைப்பு கிடைக்கும்:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

`Super + Arrow` பயன்படுத்தி, நீங்கள் செயலில் வைத்திருக்க விரும்பும் சாளரத்திற்கு இடையே செல்கிறீர்கள். இது focus-ஐ மாற்றி cursor-ஐ புதிய பயன்பாட்டின் மையத்திற்கு நகர்த்தும். ஒரு திரையின் விளிம்பில், அது அந்தப் பக்கத்தில் உள்ள monitor-க்குத் தொடர்ந்து செல்லும்.

`Super + Shift + 2` அழுத்தினால், தற்போது focus-இல் உள்ள பயன்பாட்டை இரண்டாவது workspace-க்கு நகர்த்துவீர்கள். `Super + Shift + 1` அதைத் திரும்பக் கொண்டு வரும். (மேலும் `Super + Shift + Alt + 2` என்பது தற்போது focus-இல் உள்ள பயன்பாட்டை இரண்டாவது workspace-க்கு அங்கு மாறாமலேயே நகர்த்தும்).

ஒன்றுக்கு மேற்பட்ட monitor-கள் இருக்கும்போது, ஒவ்வொரு monitor-க்கும் அதற்கே உரிய 1 முதல் 10 வரையிலான workspace-கள் உள்ளன. `Super + 2` நீங்கள் இருக்கும் monitor-இன் இரண்டாவது workspace-க்குச் செல்லும், ஒவ்வொரு monitor-இன் மேல் பட்டியும் அதன் சொந்த workspace-களையும் அது காட்டிக் கொண்டிருக்கும் ஒன்றையும் காட்டும். `Super + Tab` நீங்கள் இருக்கும் monitor-இல் உள்ள workspace-களுக்கு இடையே சுழற்சி செய்யும். `Super + Shift + Ctrl + Arrows` நீங்கள் இருக்கும் சாளரத்தை அந்தத் திசையில் உள்ள monitor-க்கு, அது காட்டிக் கொண்டிருக்கும் workspace-இன் மீது நகர்த்தும், மேலும் `Super + Shift + Alt + Arrows` நீங்கள் இருக்கும் workspace-ஐ அந்தத் திசையில் உள்ள monitor-க்கு நகர்த்தும், அங்கு அது காலியாக இருந்தால் அதே எண்ணையே எடுத்துக்கொள்ளும். ஒரு monitor-ஐ நீங்கள் துண்டிக்கும்போது அது அதன் workspace-களைத் தக்கவைத்துக் கொள்ளும்: அவை மற்றொரு திரையின் workspace-களுடன், அதில் ஏற்கெனவே உள்ளவற்றுக்குப் பிறகு எண்ணிடப்பட்டு இணையும், monitor திரும்பி வரும்போது அவற்றின் பழைய எண்களின் கீழ் திரும்பிச் செல்லும்.

`Super`-ஐப் பிடித்துக்கொண்டு mouse-ஐப் பயன்படுத்தி ஒரு சாளரத்தைக் கிளிக் செய்தால், அது அமர்ந்திருக்கும் இடத்தை மறுசீரமைக்க முடியும். `Super`-ஐப் பிடித்துக்கொண்டு mouse-இல் வலது பொத்தானைப் பயன்படுத்தினால், சாளரத்தைத் தடையின்றி resize செய்யலாம்.

`Super + W` அல்லது `Super + Q` கொண்டு ஒரு சாளரத்தை மூடுகிறீர்கள் (மேலும் `Ctrl + Alt + Delete` கொண்டு எல்லா சாளரங்களையும் மூடுகிறீர்கள்).

`Super + F` கொண்டு முழுத் திரைக்கும் செல்லலாம், அல்லது `Super + Alt + F` கொண்டு முழு அகலத்திற்கு மட்டும் (மேல் பட்டியைத் தக்கவைத்து) செல்லலாம், அல்லது `Super + Ctrl + F` கொண்டு ஒரு சாளரத்திற்குள் முழுத் திரைக்குச் செல்லலாம் (YouTube-க்கு நல்லது!).

### Dwindle எதிர் scrolling அமைப்பு

Omarchy-இன் இயல்புநிலை அமைப்பு dwindle என்று அழைக்கப்படுகிறது. நீங்கள் ஒரே workspace-இல் திறக்கும் எல்லா சாளரங்களையும், அவற்றைச் சுருக்க வேண்டியிருந்தாலும், எல்லா நேரங்களிலும் தெரியும்படி இது வைத்திருக்கும்.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

ஆனால் சாளரங்கள் அருகருகே வரிசைப்படுத்தப்பட்டு, display-இன் காணக்கூடிய விளிம்புக்கு அப்பால் செல்லும் scrolling அமைப்பாக ஒரு workspace-ஐ மாற்றவும் நீங்கள் தேர்வு செய்யலாம். `Super + L` வழியாக ஒற்றை workspace-ஐ இந்த அமைப்பாக மாற்றுகிறீர்கள்.

மீண்டும் `Super + L` அழுத்துவது workspace-ஐ floating ஆக்குகிறது, அங்கு சாளரங்கள் தடையின்றி ஒன்றின்மீது ஒன்று மேலடுக்கி வரும், நீங்களே அவற்றை வைக்கிறீர்கள், மூன்றாவது முறை அழுத்துவது அதை dwindle-க்குத் திரும்பக் கொண்டு வருகிறது. `Super + Alt + L` அவற்றின் வழியாக வேறு திசையில் செல்கிறது. எப்படியும் floating ஆக இருக்கும் ஒரு சாளரம் — `Super + T` கொண்டு நீங்கள் வெளியே எடுத்த ஒன்று, அல்லது எப்போதும் floating ஆகவே திறக்கும் ஒரு app — workspace மீண்டும் tiling-க்குச் செல்லும்போது floating ஆகவே இருக்கும். மேல் பட்டி நீங்கள் இருக்கும் workspace-ஐ அதன் அமைப்புடன் குறிக்கிறது: dwindle-க்கு ஒரு சதுரம், scrolling-க்கு ஒரு வட்டம், floating-க்கு ஒரு முக்கோணம். அந்தக் குறியைக் கிளிக் செய்வதும் அமைப்பைச் சுழற்சி செய்யும்.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

இந்தத் தேர்வு ஒவ்வொரு workspace-க்கும் தனித்தனியானது, அது நிலைத்திருக்கும். எனவே workspace 1-ஐ உலாவுவதற்கு dwindle-இலும் workspace 2-ஐ code-க்கு scrolling-இலும் வைத்திருக்கலாம், மறுதொடக்கத்திற்குப் பிறகும் அவை அப்படியே திரும்பி வரும்.

Scrolling அமைப்பை இயல்புநிலையாகப் பயன்படுத்த விரும்பினால், அதை `~/.config/hypr/looknfeel.lua`-இல் அமைக்கலாம்:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### Floating workspace-கள்

ஒரு floating workspace பாரம்பரிய desktop போல செயல்படுகிறது: சாளரங்கள் ஒன்றின்மீது ஒன்று மேலடுக்கி வரும், நீங்களே அவற்றை நகர்த்தி அளவிடுகிறீர்கள். ஒவ்வொரு சாளரத்திற்கும் உங்கள் theme-இன் வண்ணங்களில் ஒரு titlebar கிடைக்கிறது, minimize, maximize மற்றும் close செய்வதற்கான பொத்தான்களுடன். `Super + M` focus-இல் உள்ள சாளரத்தையும் minimize செய்கிறது. Minimize செய்யப்பட்ட சாளரம் dock-இல் காத்திருக்கிறது; அதன் app-ஐக் கிளிக் செய்து அதைத் திரும்பக் கொண்டு வாருங்கள். ஒரு சாளரத்தை முன்னுக்குக் கொண்டு வர அதைக் கிளிக் செய்யுங்கள். எந்த விளிம்பு அல்லது மூலையிலிருந்தும் அதை resize செய்யுங்கள். மேல் பட்டியைப் பார்வையில் வைத்தபடி சாளரத்தை maximize செய்ய titlebar-ஐ இருமுறை கிளிக் செய்யுங்கள், அதன் பழைய அளவைத் திரும்பப் பெற மீண்டும் செய்யுங்கள். Chrome மற்றும் பிற Chromium அடிப்படையிலான browser-கள், Disks மற்றும் Document Viewer ஆகியவை titlebar-ஐத் தவிர்த்துவிட்டு அதற்குப் பதிலாக அவற்றின் சொந்த header-ஐப் பயன்படுத்துகின்றன; `Super + Alt + F` அவற்றை maximize செய்கிறது, மேலும் `Super + M` அவற்றை minimize செய்கிறது.

ஒரு floating workspace ஒரு dock-ஐயும் காட்டுகிறது, உங்கள் pinned app-கள், இயங்கிக் கொண்டிருக்கும் அனைத்தும், மேலும் apps பொத்தானுக்குப் பின்னால் ஒவ்வொரு app-இன் grid-உடன், இதை `Super + Alt + Space` மற்றும் Omarchy menu-வில் உள்ள _Apps_ ஆகியவையும் திறக்கும். Grid-இல் ஒரு app-மீது வலது கிளிக் செய்யுங்கள், அல்லது `Delete` அழுத்தி, அதை நிறுவல் நீக்கம் செய்யுங்கள். ஒரு app-ஐத் திறக்க, அல்லது அதன் சாளரத்தை முன்னுக்குக் கொண்டு வர அதைக் கிளிக் செய்யுங்கள்; அதன் சாளரங்களுக்கு இடையே சுழற்சி செய்ய மீண்டும் கிளிக் செய்யுங்கள். நடு கிளிக் ஒரு புதிய சாளரத்தைத் திறக்கிறது. ஒரு icon-ஐ நகர்த்த அதை dock வழியாக இழுங்கள்; இயங்கிக் கொண்டிருக்கும் app-ஐ மற்றவற்றுக்கிடையே இழுப்பது அதை அங்கேயே வைத்திருக்கும். ஒரு app-ஐ dock-இல் வைத்திருக்கவும், அதை வெளியே எடுக்கவும், அல்லது அதை quit செய்யவும் வலது கிளிக் செய்யுங்கள். Dock ஒரு fullscreen சாளரத்திற்கு வழிவிட்டு ஒதுங்குகிறது. Dock-ஐ மற்றொரு விளிம்புக்கு நகர்த்த அல்லது pointer அதன் விளிம்பை அடையும் வரை அதை மறைந்திருக்க வைக்க apps பொத்தானில் வலது கிளிக் செய்யுங்கள். இந்த நிலை _Appearance > Dock > Dock Position_ கீழும் உள்ளது, மேலும் `omarchy dock position left` மற்றும் `omarchy dock autohide on` ஆகியவை இரண்டையும் ஒரு terminal-இலிருந்து அமைக்கின்றன. நீங்கள் dock-இல் வைத்திருக்கும் app-கள் அவை இயங்காமல் இருக்கும்போது மங்கலாக இருக்கும்.

புதிய workspace-களும், `Super + L` கொண்டு அவற்றுக்கெனத் தனி அமைப்பை நீங்கள் இன்னும் வழங்காதவையும், இயல்புநிலை அமைப்பைப் பயன்படுத்துகின்றன. இயல்புநிலையை மாற்றுவது சாளரங்கள் இல்லாத ஒவ்வொரு workspace-ஐயும் அதற்கு மீட்டமைக்கிறது, அதே நேரத்தில் சாளரங்கள் உள்ள ஒன்று தன்னிடம் உள்ள அமைப்பையே தக்கவைத்துக் கொள்ளும். Dock-க்கு minimize செய்யப்பட்ட சாளரம் அது விட்டுச் சென்ற workspace-இல் உள்ள ஒரு சாளரமாகவே இன்னும் கணக்கிடப்படுகிறது. அதை _Appearance > Workspace Layout_ கீழ் தேர்ந்தெடுங்கள்: Tiling, Scrolling, அல்லது Floating. `omarchy-hyprland-workspace-layout-default scrolling` அதை ஒரு terminal-இலிருந்து அமைக்கிறது.

### சாளரங்களைக் குழுவாக்குதல்

`Super + G` பயன்படுத்தி சாளரங்களைக் குழுவாக்கலாம். நீங்கள் ஒரு குழுவிற்குள் வந்தவுடன், அது செயலில் இருக்கும்போது நீங்கள் தொடங்கும் ஒவ்வொரு சாளரமும் அந்தக் குழுவைச் சேர்ந்ததாக இருக்கும். `Super + Ctrl + Arrow Left/Right` பயன்படுத்தி இந்தக் குழுவாக்கப்பட்ட சாளரங்களுக்கு இடையே நகரலாம் அல்லது `Super + Alt + 1/2/3/4` பயன்படுத்தி வரிசையில் உள்ள குழுவாக்கப்பட்ட சாளரங்களுக்கு நேரடியாகச் செல்லலாம்.

`Super + Alt + G` கொண்டு ஒரு சாளரத்தைக் குழுவாக்கலில் இருந்து வெளியே நகர்த்தலாம் அல்லது மீண்டும் `Super + G` அழுத்தி முழுக் குழுவையும் கலைக்கலாம். இறுதியாக, `Super + Alt + Arrows` கொண்டு குழுவிற்கு வெளியே உள்ள சாளரங்களை அதற்குள் நகர்த்தலாம்.

### சாளரங்களை வெளியே எடுத்தல்

`Super + O` கொண்டு ஒரு சாளரத்தை அதன் workspace ஒதுக்கீட்டில் இருந்து வெளியே எடுக்கலாம். அது நீங்கள் எந்த workspace-க்குச் சென்றாலும் உங்களைப் பின்தொடரும் ஒரு floating சாளரமாக அதை pin செய்யும். Video player-கள் போன்றவற்றுக்கு மிகச் சிறந்தது.

### Scratchpad workspace

நீங்கள் தற்போது இருக்கும் workspace எதன் மீதும் மேலடுக்கி வரும் ஒரு சிறப்பு முழு அளவு scratchpad workspace உள்ளது. அதில் உள்ளவற்றை `Super + S` பயன்படுத்தி அணுகுகிறீர்கள், மேலும் `Super + Alt + S` பயன்படுத்தி அங்கு சாளரங்களை வைக்கிறீர்கள்.

தற்போதைய workspace-ஐ விட்டு வெளியேறாமல் விரைவாகத் தொடர்புகொள்ள விரும்பும் கட்டுப்பாடுகள் அல்லது ஒரு terminal-க்கு இது நன்றாக வேலை செய்கிறது.

### Quake console

இறுதியாக, நீங்கள் தற்போது இருக்கும் workspace எதன் மீதும் கீழே இறங்கி வரும் ஒரு பாதி உயர Quake console உள்ளது. அதை `Super + Grave` கொண்டு மாற்றுங்கள், மேலும் `Super + Shift + Grave` பயன்படுத்தி அங்கு ஒரு சாளரத்தை வையுங்கள்.

இது உங்கள் இயல்புநிலை agent தயாராக இருக்கத் திறக்கிறது. Console ஒற்றை சாளரத்தை வைத்திருக்கும்போது, அது திரையை நிறைப்பதற்குப் பதிலாக ஒரு மையப்படுத்தப்பட்ட panel ஆகக் கீழே இறங்குகிறது. அதில் இரண்டாவது app-ஐ வைத்தால் அது முழு அகலத்திற்குத் திரும்பிச் செல்கிறது, அப்போது இரண்டுக்கும் அருகருகே அமர இடம் கிடைக்கிறது.

ஒரு சாளரத்தை scratchpad அல்லது console இரண்டில் எதிலிருந்தும் நகர்த்த, `Super + Shift + 1` போன்ற ஒன்றைக் கொண்டு அதை நேரடியாக மற்றொரு workspace-க்கு அனுப்புங்கள்.

### இதற்குப் பழக சிறிது காலம் எடுக்கும்!

உங்கள் desktop-இல் இப்படி வழிசெலுத்தப் பழக சிறிது காலம் எடுக்கும், ஆனால் நீங்கள் பழகிவிட்டால், பாரம்பரிய mouse-ஆல் இயக்கப்படும் desktop அனுபவத்திற்குத் திரும்பிச் செல்வது கடினமாக இருக்கும்!
