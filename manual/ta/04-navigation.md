# வழிசெலுத்தல்

Omarchy-இல் எல்லாம் விசைப்பலகை வழியாகவே நடக்கிறது — _எல்லாமே!_ அமைப்பு முதலில் தொடங்கும்போது, சுட்டியை மட்டும் வைத்து உங்களால் உண்மையிலேயே எதுவுமே செய்ய முடியாது. ஆனால் நீங்கள் `Super + Space` அழுத்தி Omarchy Menu-வை வெளிப்படுத்தலாம், இங்கிருந்து கிட்டத்தட்ட எல்லாவற்றையும் செய்யலாம்.

ஆனால் Omarchy மெனு பெரும்பாலான நேரங்களில் அமைப்பை இயக்குவதற்கான முக்கிய வழியாக இருக்க வேண்டும் என்று கூட நோக்கம் கொள்ளப்படவில்லை. அதைவிட வேகமாக நாம் செயல்பட முடியும்! மிக முக்கியமான பயன்பாடுகள் அனைத்தும் தனித்தனி ஹாட்கீகளுடன் நேரடியாக இணைக்கப்பட்டுள்ளன. நீங்கள் `Super + Return` மூலம் டெர்மினலைத் தொடங்குகிறீர்கள், `Super + Shift + Return` மூலம் உலாவியைத் தொடங்குகிறீர்கள். ஒன்றன் பின் ஒன்றாக முயற்சி செய்து பாருங்கள், Hyprland-இன் டைலிங்கின் மாயாஜாலம் செயல்படுவதை நீங்கள் காண்பீர்கள்:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

பின்னர் நீங்கள் `Super + J` அழுத்தி, அவற்றை அருகருகே வைப்பதற்குப் பதிலாக ஒன்றின் மேல் ஒன்றாக அடுக்கலாம்:

 ![navigation-stacked](images/navigation-stacked.webp)

அவற்றை மீண்டும் அருகருகே உள்ள நிலைகளுக்குக் கொண்டு வர `Super + J` ஐ மீண்டும் அழுத்துங்கள். பின்னர் உலாவியில் இருக்கும்போது சாளரங்களை மாற்றிக் கொள்ள `Super + Shift + Arrow Right` ஐ முயற்சி செய்யுங்கள்.

இப்போது Activity கண்காணிப்பானைத் தொடங்க `Super + Shift + T` ஐ முயற்சி செய்யுங்கள். அது மிதக்கும் சாளரமாகத் தோன்றும். `Super + T` பயன்படுத்தி அதை டைல் செய்யலாம் (அதையே மீண்டும் அழுத்தினால் அது மீண்டும் மிதக்கும்). இப்போது கோப்பு மேலாளரைத் திறக்க `Super + Shift + F` அழுத்துங்கள். உங்களுக்கு நேர்த்தியான நான்கு பிரிவு அமைப்பு கிடைக்கும்:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

நீங்கள் செயலில் இருக்க விரும்பும் சாளரத்திற்கு இடையே `Super + Arrow` மூலம் செல்கிறீர்கள். இது கவனத்தை மாற்றி, கர்சரை புதிய பயன்பாட்டின் மையத்திற்கு நகர்த்தும். திரையின் விளிம்பில், அது அந்தப் பக்கத்தில் உள்ள மானிட்டருக்குத் தொடர்ந்து செல்லும்.

நீங்கள் `Super + Shift + 2` அழுத்தினால், தற்போது கவனத்தில் உள்ள பயன்பாட்டை இரண்டாவது பணியிடத்திற்கு நகர்த்துவீர்கள். `Super + Shift + 1` அதைத் திரும்ப நகர்த்தும். (`Super + Shift + Alt + 2` தற்போது கவனத்தில் உள்ள பயன்பாட்டை, அதற்கு மாறாமலேயே, இரண்டாவது பணியிடத்திற்கு நகர்த்தும்).

ஒன்றுக்கு மேற்பட்ட மானிட்டர்கள் இருக்கும்போது, ஒவ்வொரு மானிட்டருக்கும் சொந்தமாக 1 முதல் 10 வரையிலான பணியிடங்கள் உள்ளன. `Super + 2` நீங்கள் இருக்கும் மானிட்டரின் இரண்டாவது பணியிடத்திற்குச் செல்லும், ஒவ்வொரு மானிட்டரின் மேல் பட்டையும் அதன் சொந்த பணியிடங்களையும் அது காட்டிக் கொண்டிருக்கும் பணியிடத்தையும் காட்டும். `Super + Tab` நீங்கள் இருக்கும் மானிட்டரில் உள்ள பணியிடங்களுக்கு இடையே சுழலும். `Super + Shift + Ctrl + Arrows` நீங்கள் இருக்கும் சாளரத்தை அந்தத் திசையில் உள்ள மானிட்டருக்கு, அது காட்டிக் கொண்டிருக்கும் பணியிடத்திற்கு நகர்த்தும், `Super + Shift + Alt + Arrows` நீங்கள் இருக்கும் பணியிடத்தை அந்தத் திசையில் உள்ள மானிட்டருக்கு நகர்த்தும், அங்கு அது காலியாக இருந்தால் அதே எண்ணையே எடுத்துக் கொள்ளும். நீங்கள் மானிட்டரைத் துண்டிக்கும்போது அது அதன் பணியிடங்களை வைத்துக் கொள்ளும்: அவை இன்னொரு திரையின் பணியிடங்களுடன் சேர்ந்து, அதில் ஏற்கனவே உள்ளவற்றுக்குப் பிறகு எண்ணிடப்படும், மானிட்டர் திரும்ப வரும்போது அவற்றின் பழைய எண்களுக்குக் கீழ் திரும்பச் செல்லும்.

நீங்கள் `Super` ஐ அழுத்திப் பிடித்து சுட்டியால் ஒரு சாளரத்தைக் கிளிக் செய்தால், அது அமர்ந்திருக்கும் இடத்தை மறுசீரமைக்க முடியும். நீங்கள் `Super` ஐ அழுத்திப் பிடித்து சுட்டியின் வலது பொத்தானைப் பயன்படுத்தினால், சாளரத்தைத் தடையின்றி மறுஅளவு செய்ய முடியும்.

ஒரு சாளரத்தை `Super + W` அல்லது `Super + Q` மூலம் மூடுகிறீர்கள் (எல்லா சாளரங்களையும் `Ctrl + Alt + Delete` மூலம் மூடுகிறீர்கள்).

நீங்கள் `Super + F` மூலம் முழுத்திரைக்கும் செல்லலாம், அல்லது `Super + Alt + F` மூலம் முழு அகலத்திற்கு மட்டும் (மேல் பட்டையை வைத்துக் கொண்டு) செல்லலாம், அல்லது `Super + Ctrl + F` மூலம் ஒரு சாளரத்திற்குள் முழுத்திரைக்குச் செல்லலாம் (YouTube-க்கு நல்லது!).

### Dwindle vs scrolling தளவமைப்பு

Omarchy-இன் இயல்புநிலை தளவமைப்பு dwindle என்று அழைக்கப்படுகிறது. நீங்கள் ஒரே பணியிடத்தில் திறக்கும் எல்லா சாளரங்களையும் அது எல்லா நேரங்களிலும் தெரியும்படி வைக்கிறது, அதற்காக அவற்றைச் சுருக்க வேண்டியிருந்தாலும் கூட.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

ஆனால் சாளரங்கள் காட்சியின் தெரியும் விளிம்பைத் தாண்டி அருகருகே வரிசைப்படுத்தப்படும் scrolling தளவமைப்பாக ஒரு பணியிடத்தை மாற்றவும் நீங்கள் தேர்வு செய்யலாம். `Super + L` வழியாக ஒரே ஒரு பணியிடத்தை இந்தத் தளவமைப்பாக மாற்றுகிறீர்கள்.

`Super + L` ஐ மீண்டும் அழுத்தினால் பணியிடம் மிதக்கும் நிலைக்கு மாறும், அங்கு சாளரங்கள் தடையின்றி ஒன்றின் மேல் ஒன்று அமையும், நீங்களே அவற்றை வைக்கிறீர்கள், மூன்றாவது முறை அழுத்தினால் அது dwindle-க்குத் திரும்பும். `Super + Alt + L` மற்ற திசையில் அவற்றின் வழியே செல்லும். எப்படியும் மிதக்கும் ஒரு சாளரம் — `Super + T` மூலம் நீங்கள் வெளியே எடுத்த ஒன்று, அல்லது எப்போதும் மிதந்தபடி திறக்கும் ஒரு பயன்பாடு — பணியிடம் டைலிங்கிற்குத் திரும்பும்போது தொடர்ந்து மிதக்கும். மேல் பட்டை நீங்கள் இருக்கும் பணியிடத்தை அதன் தளவமைப்புடன் குறிக்கிறது: dwindle-க்கு ஒரு சதுரம், scrolling-க்கு ஒரு வட்டம், மிதப்பதற்கு ஒரு முக்கோணம். அந்தக் குறியைக் கிளிக் செய்வதும் தளவமைப்பைச் சுழற்றும், அதுபோலவே அப்படிப்பட்ட விசை உள்ள மடிக்கணினிகளில் display விசையும் செய்யும்.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

இந்தத் தேர்வு ஒவ்வொரு பணியிடத்திற்கும் தனித்தனியானது, அது அப்படியே நிலைக்கும். ஆகவே நீங்கள் பணியிடம் 1 ஐ உலாவுவதற்கு dwindle-இலும், பணியிடம் 2 ஐ குறியீட்டிற்கு scrolling-இலும் வைக்கலாம், மறுதொடக்கத்திற்குப் பிறகும் அவை அப்படியே திரும்ப வரும்.

scrolling தளவமைப்பை இயல்புநிலையாகப் பயன்படுத்த விரும்பினால், அதை `~/.config/hypr/looknfeel.lua`-இல் அமைக்கலாம்:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### மிதக்கும் பணியிடங்கள்

மிதக்கும் பணியிடம் பாரம்பரிய டெஸ்க்டாப் போல செயல்படும்: சாளரங்கள் ஒன்றின் மேல் ஒன்று அமையும், நீங்களே அவற்றை நகர்த்தி அளவு மாற்றுகிறீர்கள். ஒவ்வொரு சாளரத்திற்கும் உங்கள் தீமின் வண்ணங்களில் ஒரு தலைப்புப் பட்டை கிடைக்கும், அதில் சிறிதாக்க, பெரிதாக்க, மூட பொத்தான்கள் இருக்கும். `Super + M` கவனத்தில் உள்ள சாளரத்தையும் சிறிதாக்கும். சிறிதாக்கப்பட்ட சாளரம் dock-இல் காத்திருக்கும்; அதைத் திரும்பக் கொண்டுவர அதன் பயன்பாட்டைக் கிளிக் செய்யுங்கள். ஒரு சாளரத்தை முன்னால் கொண்டுவர அதைக் கிளிக் செய்யுங்கள். எந்த விளிம்பு அல்லது மூலையிலிருந்தும் அதை மறுஅளவு செய்யுங்கள். மேல் பட்டையைப் பார்வையில் வைத்துக் கொண்டே சாளரத்தைப் பெரிதாக்க தலைப்புப் பட்டையை இருமுறை கிளிக் செய்யுங்கள், அதன் பழைய அளவைத் திரும்பப் பெற மீண்டும் செய்யுங்கள். Chrome மற்றும் பிற Chromium அடிப்படையிலான உலாவிகள், Disks மற்றும் Document Viewer தலைப்புப் பட்டையைத் தவிர்த்து அதற்குப் பதிலாக அவற்றின் சொந்த தலைப்பைப் பயன்படுத்துகின்றன; `Super + Alt + F` அவற்றைப் பெரிதாக்கும், `Super + M` அவற்றைச் சிறிதாக்கும்.

மிதக்கும் பணியிடம் ஒரு dock-ஐயும் காட்டும், அதில் உங்கள் பின் செய்யப்பட்ட பயன்பாடுகள், இயங்கிக் கொண்டிருக்கும் எல்லாம், apps பொத்தானுக்குப் பின்னால் ஒவ்வொரு பயன்பாட்டின் கட்டமும் இருக்கும், அதை `Super + Alt + Space` மற்றும் Omarchy மெனுவில் உள்ள _Apps_ ஆகியவையும் திறக்கும். அதை நிறுவல் நீக்க, கட்டத்தில் ஒரு பயன்பாட்டை வலது-கிளிக் செய்யுங்கள், அல்லது `Delete` அழுத்துங்கள். ஒரு பயன்பாட்டைத் திறக்க, அல்லது அதன் சாளரத்தை முன்னால் கொண்டுவர அதைக் கிளிக் செய்யுங்கள்; அதன் சாளரங்களுக்கு இடையே சுழல மீண்டும் கிளிக் செய்யுங்கள். Files நீங்கள் இருக்கும் பணியிடத்திலிருந்து ஒரு சாளரத்தை மட்டுமே திரும்பக் கொண்டுவரும், இல்லையெனில் புதிய ஒன்றைத் திறக்கும், Terminal மற்றும் Agent எப்போதும் இன்னொன்றைத் தொடங்கும், இருப்பினும் சிறிதாக்கப்பட்ட சாளரம் முதலில் திரும்ப வரும். நடு-கிளிக் புதிய சாளரத்தைத் திறக்கும். ஒரு ஐகானை dock வழியே இழுத்து அதை நகர்த்துங்கள்; இயங்கும் ஒரு பயன்பாட்டை மற்றவற்றின் இடையே இழுத்து விடுவது அதை அங்கேயே வைக்கும். ஒரு பயன்பாட்டை dock-இல் வைத்திருக்க, அதை வெளியே எடுக்க, அல்லது அதிலிருந்து வெளியேற வலது-கிளிக் செய்யுங்கள். dock முழுத்திரை சாளரத்திற்கு வழி விட்டு விலகும். dock-ஐ இன்னொரு விளிம்பிற்கு நகர்த்த, அல்லது கர்சர் அதன் விளிம்பை அடையும் வரை அது மறைந்திருக்கும்படி செய்ய apps பொத்தானை வலது-கிளிக் செய்யுங்கள். அந்த நிலை _Appearance > Dock > Dock Position_ கீழும் உள்ளது, `omarchy dock position left` மற்றும் `omarchy dock autohide on` ஆகியவை இரண்டையும் டெர்மினலில் இருந்து அமைக்கின்றன. நீங்கள் dock-இல் வைத்திருக்கும் பயன்பாடுகள் இயங்காதபோது மங்கலாக இருக்கும்.

புதிய பணியிடங்கள், மற்றும் `Super + L` மூலம் சொந்த தளவமைப்பு எதையும் நீங்கள் கொடுக்காத எவையும், இயல்புநிலை தளவமைப்பைப் பயன்படுத்தும். இயல்புநிலையை மாற்றுவது சாளரங்கள் இல்லாத ஒவ்வொரு பணியிடத்தையும் அதற்கு மீட்டமைக்கும், அதே நேரத்தில் சாளரங்களைக் கொண்ட ஒன்று அதில் உள்ள தளவமைப்பையே வைத்துக் கொள்ளும். dock-க்கு சிறிதாக்கப்பட்ட சாளரம் இன்னும் அது விட்டுச் சென்ற பணியிடத்தில் உள்ள சாளரமாகவே கணக்கிடப்படும். அதை _Appearance > Workspace Layout_ கீழ் தேர்ந்தெடுங்கள்: Tiling, Scrolling, அல்லது Floating. `omarchy hyprland workspace layout default scrolling` அதை டெர்மினலில் இருந்து அமைக்கிறது.

### சாளரங்களைக் குழுவாக்குதல்

`Super + G` பயன்படுத்தி சாளரங்களைக் குழுவாக்கலாம். நீங்கள் ஒரு குழுவில் இருந்தவுடன், அது செயலில் இருக்கும்போது நீங்கள் தொடங்கும் ஒவ்வொரு சாளரமும் அந்தக் குழுவைச் சேர்ந்ததாக இருக்கும். `Super + Ctrl + Arrow Left/Right` பயன்படுத்தி இந்தக் குழுவாக்கப்பட்ட சாளரங்களுக்கு இடையே நகரலாம், அல்லது `Super + Alt + 1/2/3/4` பயன்படுத்தி வரிசையில் குழுவாக்கப்பட்ட சாளரங்களுக்கு நேரடியாகச் செல்லலாம்.

நீங்கள் `Super + Alt + G` மூலம் ஒரு சாளரத்தைக் குழுவாக்கத்திலிருந்து வெளியே நகர்த்தலாம், அல்லது `Super + G` ஐ மீண்டும் அழுத்தி முழு குழுவையும் கலைக்கலாம். இறுதியாக, `Super + Alt + Arrows` மூலம் குழுவிற்கு வெளியே உள்ள சாளரங்களை அதற்குள் நகர்த்தலாம்.

### சாளரங்களை வெளியே எடுத்தல்

`Super + O` மூலம் ஒரு சாளரத்தை அதன் பணியிட ஒதுக்கீட்டிலிருந்து வெளியே எடுக்கலாம். அது அதை நீங்கள் எந்தப் பணியிடத்திற்குச் சென்றாலும் உங்களைப் பின்தொடரும் மிதக்கும் சாளரமாகப் பின் செய்யும். வீடியோ பிளேயர்கள் போன்றவற்றுக்கு சிறந்தது.

### Scratchpad பணியிடம்

நீங்கள் தற்போது இருக்கும் எந்தப் பணியிடத்தின் மீதும் மேலோட்டமாக அமையும் சிறப்பு முழு அளவிலான scratchpad பணியிடம் ஒன்று உள்ளது. அதில் உள்ளதை `Super + S` பயன்படுத்தி அணுகுகிறீர்கள், `Super + Alt + S` பயன்படுத்தி அங்கு சாளரங்களை வைக்கிறீர்கள்.

தற்போதைய பணியிடத்தை விட்டு வெளியேறாமல் விரைவாக நீங்கள் தொடர்பு கொள்ள விரும்பும் கட்டுப்பாடுகள் அல்லது டெர்மினலுக்கு இது நன்றாக வேலை செய்யும்.

### Quake கன்சோல்

இறுதியாக, நீங்கள் தற்போது இருக்கும் எந்தப் பணியிடத்தின் மீதும் கீழே இறங்கும் அரை-உயர Quake கன்சோல் ஒன்று உள்ளது. அதை `Super + the key above Tab` (US தளவமைப்புகளில் grave) மூலம் மாற்றுங்கள், `Super + Shift + the key above Tab` பயன்படுத்தி அங்கு ஒரு சாளரத்தை வையுங்கள்.

அது முதல் முறை திறக்கும்போது, உங்கள் இயல்புநிலை agent-ஐத் தொடங்கும், அல்லது நீங்கள் இன்னும் ஒன்றைத் தேர்வு செய்யவில்லை என்றால் ஒன்றைத் தேர்ந்தெடுக்கும்படி கேட்கும். கன்சோல் ஒரே ஒரு சாளரத்தை வைத்திருக்கும்போது, திரை முழுவதும் விரிவதற்குப் பதிலாக அது மையப்படுத்தப்பட்ட பலகமாகக் கீழே இறங்கும். அதில் இரண்டாவது பயன்பாட்டை வையுங்கள், அது முழு அகலத்திற்குத் திரும்பும், இதனால் இரண்டும் அருகருகே அமர இடம் கிடைக்கும்.

scratchpad அல்லது கன்சோல் இரண்டிலிருந்தும் ஒரு சாளரத்தை நகர்த்த, `Super + Shift + 1` போன்ற ஒன்றைக் கொண்டு அதை இன்னொரு பணியிடத்திற்கு நேரடியாக அனுப்புங்கள்.

### பழகிக் கொள்ள கொஞ்சம் நேரம் எடுக்கும்!

இப்படி உங்கள் டெஸ்க்டாப்பில் வழிசெலுத்தப் பழகிக் கொள்ள கொஞ்சம் நேரம் எடுக்கும், ஆனால் நீங்கள் பழகிவிட்டால், பாரம்பரிய சுட்டியால் இயக்கப்படும் டெஸ்க்டாப் அனுபவத்திற்குத் திரும்பச் செல்வது கடினமாக இருக்கும்!
