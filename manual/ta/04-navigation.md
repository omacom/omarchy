# வழிசெலுத்தல்

Omarchy-இல் எல்லாமே விசைப்பலகை வழியாகவே நடக்கும் — _எல்லாமே!_ கணினி முதலில் தொடங்கும்போது, சுட்டியை மட்டும் வைத்து உங்களால் உண்மையிலேயே எதுவுமே செய்ய முடியாது. ஆனால் `Super + Space` ஐ அழுத்தி Omarchy Menu-வை வெளிப்படுத்தலாம், இங்கிருந்து கிட்டத்தட்ட எல்லாவற்றையும் செய்யலாம்.

ஆனால் பெரும்பாலான நேரங்களில் கணினியை இயக்குவதற்கான முக்கிய வழியாக இருக்க வேண்டும் என்ற நோக்கம்கூட Omarchy மெனுவுக்கு இல்லை. அதைவிட வேகமாகச் செயல்பட முடியும்! மிக முக்கியமான பயன்பாடுகள் அனைத்தும் தனித்தனி விரைவு விசைகளுடன் நேரடியாக இணைக்கப்பட்டுள்ளன. `Super + Return` மூலம் டெர்மினலையும், `Super + Shift + Return` மூலம் உலாவியையும் தொடங்கலாம். ஒன்றன் பின் ஒன்றாக முயற்சி செய்து பாருங்கள், Hyprland-இன் டைலிங்கின் மாயாஜாலம் செயல்படுவதைக் காண்பீர்கள்:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

பின்னர் `Super + J` ஐ அழுத்தி அவற்றை அருகருகே வைப்பதற்குப் பதிலாக ஒன்றின் மீது ஒன்றாக அடுக்கலாம்:

 ![navigation-stacked](images/navigation-stacked.webp)

`Super + J` ஐ மீண்டும் அழுத்தினால் அவை அருகருகே இருந்த நிலைக்குத் திரும்பும். பின்னர் உலாவியில் இருக்கும்போது `Super + Shift + Arrow Right` ஐ அழுத்தி சாளரங்களை இடமாற்றிப் பாருங்கள்.

இப்போது `Super + Shift + T` ஐ அழுத்தி Activity மானிட்டரைத் தொடங்குங்கள். அது ஒரு மிதக்கும் சாளரமாகத் தோன்றும். `Super + T` மூலம் அதை டைல் செய்யலாம் (மீண்டும் அழுத்தினால் அது மீண்டும் மிதக்கும்). இப்போது `Super + Shift + F` ஐ அழுத்தி கோப்பு மேலாளரைத் திறக்கவும். உங்களுக்கு நேர்த்தியான நான்கு பிரிவு அமைப்பு கிடைக்கும்:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

எந்த சாளரம் செயலில் இருக்க வேண்டும் என்பதை `Super + Arrow` மூலம் மாற்றிச் செல்லலாம். இது கவனத்தை மாற்றி, கர்சரை புதிய பயன்பாட்டின் மையத்திற்கு நகர்த்தும். திரையின் விளிம்பில், அது அந்தப் பக்கத்தில் உள்ள மானிட்டருக்குத் தொடர்ந்து செல்லும்.

`Super + Shift + 2` ஐ அழுத்தினால், தற்போது கவனத்தில் உள்ள பயன்பாட்டை இரண்டாவது பணியிடத்திற்கு நகர்த்தலாம். `Super + Shift + 1` அதைத் திரும்பக் கொண்டு வரும். (மேலும் `Super + Shift + Alt + 2` என்பது தற்போது கவனத்தில் உள்ள பயன்பாட்டை இரண்டாவது பணியிடத்திற்கு, அதற்கு மாறாமலேயே நகர்த்தும்).

ஒன்றுக்கு மேற்பட்ட மானிட்டர்கள் இருக்கும்போது, ஒவ்வொரு மானிட்டருக்கும் தனக்கென 1 முதல் 10 வரையிலான பணியிடங்கள் உள்ளன. `Super + 2` நீங்கள் இருக்கும் மானிட்டரின் இரண்டாவது பணியிடத்திற்குச் செல்லும், ஒவ்வொரு மானிட்டரின் மேல் பட்டியும் அதன் சொந்த பணியிடங்களையும் அது காட்டிக் கொண்டிருக்கும் பணியிடத்தையும் காட்டும். `Super + Tab` நீங்கள் இருக்கும் மானிட்டரில் உள்ள பணியிடங்களுக்கு இடையே சுழற்றும். `Super + Shift + Ctrl + Arrows` நீங்கள் இருக்கும் சாளரத்தை அந்தத் திசையில் உள்ள மானிட்டருக்கு, அது காட்டிக் கொண்டிருக்கும் பணியிடத்திற்கு நகர்த்தும், மேலும் `Super + Shift + Alt + Arrows` நீங்கள் இருக்கும் பணியிடத்தை அந்தத் திசையில் உள்ள மானிட்டருக்கு நகர்த்தும், அங்கு அது காலியாக இருந்தால் அதே எண்ணை எடுத்துக் கொள்ளும். நீங்கள் ஒரு மானிட்டரைத் துண்டிக்கும்போது அது அதன் பணியிடங்களை வைத்திருக்கும்: அவை மற்றொரு திரையின் பணியிடங்களுடன் இணையும், அதற்கு ஏற்கனவே உள்ளவற்றுக்குப் பிறகு எண்ணிடப்படும், மானிட்டர் திரும்பும்போது அவற்றின் பழைய எண்களின் கீழ் திரும்பிச் செல்லும்.

`Super` ஐ அழுத்திப் பிடித்துக் கொண்டு சுட்டியால் ஒரு சாளரத்தைக் கிளிக் செய்தால், அது அமரும் இடத்தை மறுசீரமைக்க முடியும். `Super` ஐ அழுத்திப் பிடித்துக் கொண்டு சுட்டியில் வலது பொத்தானைப் பயன்படுத்தினால், சாளரத்தைத் தடையின்றி அளவு மாற்ற முடியும்.

ஒரு சாளரத்தை `Super + W` அல்லது `Super + Q` மூலம் மூடலாம் (எல்லா சாளரங்களையும் `Ctrl + Alt + Delete` மூலம் மூடலாம்).

`Super + F` மூலம் முழுத் திரைக்கும் செல்லலாம் அல்லது `Super + Alt + F` மூலம் முழு அகலத்திற்கு மட்டும் (மேல் பட்டியை வைத்துக் கொண்டு) செல்லலாம் அல்லது `Super + Ctrl + F` மூலம் ஒரு சாளரத்திற்குள் முழுத் திரையில் காட்டலாம் (YouTube-க்கு ஏற்றது!).

### Dwindle எதிர் scrolling அமைப்பு

Omarchy-இன் இயல்புநிலை அமைப்பு dwindle என்று அழைக்கப்படுகிறது. ஒரே பணியிடத்தில் நீங்கள் திறக்கும் எல்லா சாளரங்களையும் எப்போதும் காணும்படி அது வைத்திருக்கும், அதற்காக அவற்றைச் சுருக்க வேண்டியிருந்தாலும் கூட.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

ஆனால் சாளரங்கள் அருகருகே, திரையின் காணக்கூடிய விளிம்புக்கு அப்பால் வரிசைப்படுத்தப்படும் scrolling அமைப்பாக ஒரு பணியிடத்தை மாற்றவும் நீங்கள் தேர்வு செய்யலாம். `Super + L` வழியாக ஒரு தனி பணியிடத்தை இந்த அமைப்பாக மாற்றலாம்.

`Super + L` ஐ மீண்டும் அழுத்தினால் பணியிடம் மிதக்கும் நிலைக்கு மாறும், அங்கு சாளரங்கள் தடையின்றி ஒன்றின் மீது ஒன்று படியும், நீங்களே அவற்றை வைப்பீர்கள், மூன்றாவது முறை அழுத்தினால் அது dwindle-க்குத் திரும்பும். `Super + Alt + L` அவற்றின் வழியே மறு திசையில் செல்லும். எப்படியும் மிதக்கும் ஒரு சாளரம் — `Super + T` மூலம் நீங்கள் வெளியே எடுத்த ஒன்று, அல்லது எப்போதும் மிதந்தபடி திறக்கும் ஒரு பயன்பாடு — பணியிடம் டைலிங்கிற்குத் திரும்பும்போது தொடர்ந்து மிதந்து கொண்டிருக்கும். நீங்கள் இருக்கும் பணியிடத்தை மேல் பட்டி அதன் அமைப்புடன் குறிக்கும்: dwindle-க்கு ஒரு சதுரம், scrolling-க்கு ஒரு வட்டம், மிதக்கும் நிலைக்கு ஒரு முக்கோணம். அந்தக் குறியைக் கிளிக் செய்வதும் அமைப்பைச் சுழற்றும், அத்தகைய விசை உள்ள மடிக்கணினிகளில் display விசையும் அதையே செய்யும்.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

இந்தத் தேர்வு ஒவ்வொரு பணியிடத்திற்கும் தனித்தனியானது, அது நிலைத்திருக்கும். எனவே பணியிடம் 1-ஐ உலாவலுக்காக dwindle-இலும், பணியிடம் 2-ஐ குறியீட்டிற்காக scrolling-இலும் வைத்திருக்கலாம், மறுதொடக்கத்திற்குப் பிறகும் அவை அப்படியே திரும்பி வரும்.

scrolling அமைப்பை இயல்புநிலையாகப் பயன்படுத்த விரும்பினால், அதை `~/.config/hypr/looknfeel.lua` இல் அமைக்கலாம்:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### மிதக்கும் பணியிடங்கள்

ஒரு மிதக்கும் பணியிடம் ஒரு பாரம்பரிய டெஸ்க்டாப் போல செயல்படும்: சாளரங்கள் ஒன்றின் மீது ஒன்று படியும், நீங்களே அவற்றை நகர்த்தி அளவு மாற்றுவீர்கள். ஒவ்வொரு சாளரத்திற்கும் உங்கள் தீமின் வண்ணங்களில் ஒரு தலைப்புப் பட்டி கிடைக்கும், அதில் சிறிதாக்க, பெரிதாக்க, மூடுவதற்கான பொத்தான்கள் இருக்கும். `Super + M` கவனத்தில் உள்ள சாளரத்தையும் சிறிதாக்கும். சிறிதாக்கப்பட்ட சாளரம் dock-இல் காத்திருக்கும்; அதைத் திரும்பக் கொண்டு வர அதன் பயன்பாட்டைக் கிளிக் செய்யவும். ஒரு சாளரத்தை முன்னுக்குக் கொண்டு வர அதைக் கிளிக் செய்யவும். எந்த விளிம்பிலிருந்தும் அல்லது மூலையிலிருந்தும் அதை அளவு மாற்றவும். மேல் பட்டியைப் பார்வையில் வைத்துக் கொண்டே சாளரத்தைப் பெரிதாக்க தலைப்புப் பட்டியை இருமுறை கிளிக் செய்யவும், அதன் பழைய அளவைத் திரும்பப் பெற மீண்டும் செய்யவும். Chrome மற்றும் பிற Chromium அடிப்படையிலான உலாவிகள், Disks மற்றும் Document Viewer ஆகியவை தலைப்புப் பட்டியைத் தவிர்த்து அதற்குப் பதிலாகத் தங்கள் சொந்த தலைப்பைப் பயன்படுத்தும்; `Super + Alt + F` அவற்றைப் பெரிதாக்கும், `Super + M` அவற்றைச் சிறிதாக்கும்.

ஒரு மிதக்கும் பணியிடம் ஒரு dock-ஐயும் காட்டும், அதில் உங்கள் பின் செய்யப்பட்ட பயன்பாடுகள், இயங்கிக் கொண்டிருக்கும் எல்லாமே, apps பொத்தானுக்குப் பின்னால் ஒவ்வொரு பயன்பாட்டின் கட்டமும் இருக்கும், அதை `Super + Alt + Space` மற்றும் Omarchy மெனுவில் உள்ள _Apps_ ஆகியவையும் திறக்கும். கட்டத்தில் ஒரு பயன்பாட்டை வலது-கிளிக் செய்வதன் மூலம், அல்லது `Delete` ஐ அழுத்துவதன் மூலம், அதை நிறுவல் நீக்கலாம். ஒரு பயன்பாட்டைத் திறக்க, அல்லது அதன் சாளரத்தை முன்னுக்குக் கொண்டு வர அதைக் கிளிக் செய்யவும்; அதன் சாளரங்களுக்கு இடையே சுழற்ற மீண்டும் கிளிக் செய்யவும். Files நீங்கள் இருக்கும் பணியிடத்திலிருந்து மட்டுமே ஒரு சாளரத்தைத் திரும்பக் கொண்டு வரும், இல்லையெனில் புதிய ஒன்றைத் திறக்கும், Terminal மற்றும் Agent எப்போதும் மற்றொன்றைத் தொடங்கும், இருப்பினும் சிறிதாக்கப்பட்ட சாளரம் முதலில் திரும்பி வரும். நடு-கிளிக் புதிய சாளரத்தைத் திறக்கும். dock வழியே ஒரு ஐகானை இழுத்து அதை நகர்த்தவும்; இயங்கும் ஒரு பயன்பாட்டை மற்றவற்றுக்கு இடையே இழுப்பது அதை அங்கேயே வைத்திருக்கும். ஒரு பயன்பாட்டை dock-இல் வைத்திருக்க, வெளியே எடுக்க, அல்லது அதிலிருந்து வெளியேற வலது-கிளிக் செய்யவும். முழுத்திரை சாளரத்திற்கு dock வழிவிட்டு விலகும். dock-ஐ மற்றொரு விளிம்புக்கு நகர்த்த அல்லது சுட்டி அதன் விளிம்பை அடையும் வரை அதை மறைந்திருக்க வைக்க apps பொத்தானை வலது-கிளிக் செய்யவும். அந்த நிலை _தோற்றம் > Dock > Dock நிலை_ என்பதன் கீழும் உள்ளது, மேலும் `omarchy dock position left` மற்றும் `omarchy dock autohide on` ஆகியவை இரண்டையும் ஒரு டெர்மினலிலிருந்து அமைக்கும். dock-இல் நீங்கள் வைத்திருக்கும் பயன்பாடுகள் இயங்காதபோது மங்கலாக இருக்கும்.

புதிய பணியிடங்கள், மற்றும் `Super + L` மூலம் தமக்கென ஒரு அமைப்பை நீங்கள் வழங்காத எந்த பணியிடங்களும், இயல்புநிலை அமைப்பைப் பயன்படுத்தும். இயல்புநிலையை மாற்றுவது சாளரங்கள் இல்லாத ஒவ்வொரு பணியிடத்தையும் அதற்கு மீட்டமைக்கும், அதே நேரத்தில் சாளரங்களைக் கொண்ட ஒன்று அதற்கு உள்ள அமைப்பை வைத்திருக்கும். dock-க்குச் சிறிதாக்கப்பட்ட சாளரம், அது விட்டுச் சென்ற பணியிடத்தில் உள்ள சாளரமாகவே இன்னும் கணக்கிடப்படும். அதை _தோற்றம் > பணியிட அமைப்பு_ என்பதன் கீழ் தேர்ந்தெடுக்கவும்: Tiling, Scrolling, அல்லது Floating. `omarchy hyprland workspace layout default scrolling` அதை ஒரு டெர்மினலிலிருந்து அமைக்கும்.

### சாளரங்களைக் குழுவாக்குதல்

`Super + G` ஐப் பயன்படுத்தி சாளரங்களைக் குழுவாக்கலாம். நீங்கள் ஒரு குழுவில் இருக்கும்போது, அது செயலில் இருக்கும்போது நீங்கள் தொடங்கும் ஒவ்வொரு சாளரமும் அந்தக் குழுவைச் சேர்ந்ததாக இருக்கும். `Super + Ctrl + Arrow Left/Right` ஐப் பயன்படுத்தி அல்லது வரிசையில் குழுவாக்கப்பட்ட சாளரங்களுக்கு நேரடியாகச் செல்ல `Super + Alt + 1/2/3/4` ஐப் பயன்படுத்தி இந்தக் குழுவாக்கப்பட்ட சாளரங்களுக்கு இடையே நகரலாம்.

ஒரு சாளரத்தை `Super + Alt + G` மூலம் குழுவிலிருந்து வெளியே நகர்த்தலாம் அல்லது `Super + G` ஐ மீண்டும் அழுத்தி முழுக் குழுவையும் கலைக்கலாம். இறுதியாக, குழுவுக்கு வெளியே உள்ள சாளரங்களை `Super + Alt + Arrows` மூலம் அதற்குள் நகர்த்தலாம்.

### சாளரங்களை வெளியே எடுத்தல்

`Super + O` மூலம் ஒரு சாளரத்தை அதன் பணியிட ஒதுக்கீட்டிலிருந்து வெளியே எடுக்கலாம். அது அதை நீங்கள் எந்த பணியிடத்திற்குச் சென்றாலும் உங்களைப் பின்தொடரும் மிதக்கும் சாளரமாகப் பின் செய்யும். வீடியோ பிளேயர்கள் போன்றவற்றுக்கு ஏற்றது.

### Scratchpad பணியிடம்

நீங்கள் தற்போது இருக்கும் எந்த பணியிடத்தின் மீதும் படியும் ஒரு சிறப்பு முழு அளவு scratchpad பணியிடம் உள்ளது. அதில் உள்ளதை `Super + S` ஐப் பயன்படுத்தி அணுகலாம், மேலும் அங்கு சாளரங்களை `Super + Alt + S` ஐப் பயன்படுத்தி வைக்கலாம்.

தற்போதைய பணியிடத்தை விட்டு வெளியேறாமல் விரைவாகத் தொடர்பு கொள்ள விரும்பும் கட்டுப்பாடுகள் அல்லது ஒரு டெர்மினலுக்கு இது நன்றாக வேலை செய்யும்.

### Quake கன்சோல்

இறுதியாக, நீங்கள் தற்போது இருக்கும் எந்த பணியிடத்தின் மீதும் கீழிறங்கும் அரை உயர Quake கன்சோல் ஒன்று உள்ளது. அதை `Super + Grave` மூலம் மாற்றவும், மேலும் அங்கு ஒரு சாளரத்தை `Super + Shift + Grave` ஐப் பயன்படுத்தி வைக்கவும்.

அது முதலில் திறக்கும்போது, உங்கள் இயல்புநிலை agent-ஐத் தொடங்கும், அல்லது நீங்கள் இன்னும் ஒன்றைத் தேர்வு செய்யவில்லை என்றால் ஒன்றைத் தேர்ந்தெடுக்கும்படி கேட்கும். கன்சோல் ஒரே ஒரு சாளரத்தை வைத்திருக்கும்போது, அது திரை முழுவதும் பரவுவதற்குப் பதிலாக மையப்படுத்தப்பட்ட பேனலாகக் கீழிறங்கும். அதில் இரண்டாவது பயன்பாட்டை வைத்தால் அது முழு அகலத்திற்குத் திரும்பும், எனவே இரண்டுக்கும் அருகருகே அமர இடம் கிடைக்கும்.

scratchpad அல்லது கன்சோலிலிருந்து ஒரு சாளரத்தை நகர்த்த, அதை `Super + Shift + 1` போன்ற ஒன்றைக் கொண்டு மற்றொரு பணியிடத்திற்கு நேரடியாக அனுப்பவும்.
