# வழிசெலுத்தல்

Omarchy-இல் எல்லாம் விசைப்பலகை வழியாகவே நடக்கும் — _எல்லாமே!_ அமைப்பு முதலில் தொடங்கும்போது, மவுஸை மட்டும் கொண்டு நீங்கள் உண்மையிலேயே எதையும் செய்ய முடியாது. ஆனால் `Super + Space` ஐ அழுத்தி Omarchy Menu-வைக் காட்டலாம், இங்கிருந்து கிட்டத்தட்ட எல்லாவற்றையும் செய்யலாம்.

ஆனால் பெரும்பாலான நேரங்களில் அமைப்பை இயக்குவதற்கான முக்கிய வழியாக இருக்க வேண்டும் என்று Omarchy menu கூட நோக்கம் கொண்டதல்ல. அதைவிட வேகமாகச் செய்ய முடியும்! மிக முக்கியமான பயன்பாடுகள் அனைத்தும் தனித்தனி ஹாட்கீகளுடன் நேரடியாகப் பிணைக்கப்பட்டுள்ளன. `Super + Return` கொண்டு டெர்மினலையும் `Super + Shift + Return` கொண்டு உலாவியையும் தொடங்குவீர்கள். ஒன்றன் பின் ஒன்றாகச் செய்து பாருங்கள், Hyprland-இன் டைலிங்கின் மாயாஜாலம் செயலில் இருப்பதைக் காண்பீர்கள்:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

பிறகு `Super + J` ஐ அழுத்தி அவற்றை அருகருகே வைப்பதற்குப் பதிலாக ஒன்றன் மேல் ஒன்றாக அடுக்கலாம்:

 ![navigation-stacked](images/navigation-stacked.webp)

`Super + J` ஐ மீண்டும் அழுத்தினால் அவை அருகருகே இருந்த நிலைக்குத் திரும்பும். பிறகு உலாவியில் இருக்கும்போது `Super + Shift + Arrow Right` ஐ முயற்சித்து சாளரங்களை இடமாற்றுங்கள்.

இப்போது `Super + Shift + T` ஐ முயற்சித்து Activity monitor-ஐத் தொடங்குங்கள். அது ஒரு மிதக்கும் சாளரமாகத் தோன்றும், அதை இழுப்பதற்கு ஒரு தலைப்புப் பட்டியும், அதைச் சிறிதாக்க, பெரிதாக்க மற்றும் மூடுவதற்கான பொத்தான்களும் இருக்கும். ஒவ்வொரு மிதக்கும் சாளரத்திற்கும், அது எங்கிருந்தாலும், ஒன்று கிடைக்கும். `Super + T` ஐப் பயன்படுத்தி அதை டைல் செய்யலாம் (மீண்டும் அதையே அழுத்தினால் அது மீண்டும் மிதக்கும்). இப்போது `Super + Shift + F` ஐ அழுத்தி கோப்பு மேலாளரைத் திறங்கள். உங்களுக்கு ஒரு நேர்த்தியான நான்கு பக்க அமைப்பு கிடைக்கும்:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

எந்தச் சாளரம் செயலில் இருக்க வேண்டும் என்பதற்கு இடையே `Super + Arrow` கொண்டு செல்வீர்கள். இது கவனத்தை மாற்றி, கர்சரைப் புதிய பயன்பாட்டின் மையத்திற்கு நகர்த்தும். ஒரு திரையின் விளிம்பில், அது அந்தப் பக்கத்தில் உள்ள மானிட்டருக்குத் தொடர்ந்து செல்லும்.

`Super + Shift + 2` ஐ அழுத்தினால், தற்போது கவனத்தில் உள்ள பயன்பாட்டை இரண்டாவது பணியிடத்திற்கு நகர்த்துவீர்கள். `Super + Shift + 1` அதைத் திரும்ப நகர்த்தும். (மேலும் `Super + Shift + Alt + 2` தற்போது கவனத்தில் உள்ள பயன்பாட்டை அதற்கு மாறாமலேயே இரண்டாவது பணியிடத்திற்கு நகர்த்தும்).

ஒன்றுக்கு மேற்பட்ட மானிட்டர்கள் இருக்கும்போது, ஒவ்வொரு மானிட்டருக்கும் 1 முதல் 10 வரையிலான தனித்தனி பணியிடங்கள் உள்ளன. `Super + 2` நீங்கள் இருக்கும் மானிட்டரின் இரண்டாவது பணியிடத்திற்குச் செல்லும், ஒவ்வொரு மானிட்டரின் மேல் பட்டியும் அதன் சொந்தப் பணியிடங்களையும் அது காட்டிக் கொண்டிருக்கும் பணியிடத்தையும் காட்டும். `Super + Tab` நீங்கள் இருக்கும் மானிட்டரில் உள்ள பணியிடங்களுக்கு இடையே சுழற்சி செய்யும். `Super + Shift + Ctrl + Arrows` நீங்கள் இருக்கும் சாளரத்தை அந்தத் திசையில் உள்ள மானிட்டருக்கு, அது காட்டிக் கொண்டிருக்கும் பணியிடத்திற்கு நகர்த்தும், மேலும் `Super + Shift + Alt + Arrows` நீங்கள் இருக்கும் பணியிடத்தை அந்தத் திசையில் உள்ள மானிட்டருக்கு நகர்த்தும், அங்கு அது காலியாக இருந்தால் அதே எண்ணை எடுத்துக் கொள்ளும். நீங்கள் ஒரு மானிட்டரைத் துண்டித்தாலும் அது அதன் பணியிடங்களை வைத்திருக்கும்: அவை மற்றொரு திரையின் பணியிடங்களுடன் சேர்ந்து கொள்ளும், அதற்கு ஏற்கனவே உள்ளவற்றுக்குப் பிறகு எண்ணிடப்படும், மானிட்டர் திரும்ப வரும்போது அவற்றின் பழைய எண்களின் கீழ் திரும்பச் செல்லும்.

`Super` ஐ அழுத்திப் பிடித்து, மவுஸைப் பயன்படுத்தி ஒரு சாளரத்தின் மீது கிளிக் செய்தால், அது அமர்ந்திருக்கும் இடத்தை மறுசீரமைக்க முடியும். `Super` ஐ அழுத்திப் பிடித்து, மவுஸின் வலது பொத்தானைப் பயன்படுத்தினால், சாளரத்தை சுதந்திரமாக மறுஅளவிடலாம்.

ஒரு சாளரத்தை `Super + W` அல்லது `Super + Q` கொண்டு மூடுவீர்கள் (எல்லா சாளரங்களையும் `Ctrl + Alt + Delete` கொண்டு மூடுவீர்கள்).

`Super + F` கொண்டு முழுத் திரைக்கும் செல்லலாம், அல்லது `Super + Alt + F` கொண்டு வெறும் முழு அகலத்திற்கு (மேல் பட்டியை வைத்துக் கொண்டு) செல்லலாம், அல்லது `Super + Ctrl + F` கொண்டு ஒரு சாளரத்திற்குள் முழுத் திரைக்குச் செல்லலாம் (YouTube-க்கு நல்லது!).

### Dwindle vs scrolling தளவமைப்பு

Omarchy-இன் இயல்புநிலை தளவமைப்பு dwindle என்று அழைக்கப்படுகிறது. நீங்கள் ஒரே பணியிடத்தில் திறக்கும் எல்லா சாளரங்களையும் அது எல்லா நேரங்களிலும் தெரியும்படி வைத்திருக்கும், அவற்றைச் சுருக்க வேண்டியிருந்தாலும் கூட.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

ஆனால் ஒரு பணியிடத்தை, சாளரங்கள் அருகருகே வரிசைப்படுத்தப்பட்டு, காட்சியின் தெரியும் விளிம்புக்கு அப்பால் செல்லும் scrolling தளவமைப்பாக மாற்றவும் நீங்கள் தேர்வு செய்யலாம். `Super + L` வழியாக ஒரு தனி பணியிடத்தை இந்தத் தளவமைப்பாக மாற்றுவீர்கள்.

`Super + L` ஐ மீண்டும் அழுத்தினால் பணியிடம் மிதப்பதாக மாறும், அங்கு சாளரங்கள் சுதந்திரமாக ஒன்றன் மேல் ஒன்று இருக்கும், அவற்றை நீங்களே வைப்பீர்கள், மூன்றாவது முறை அழுத்தினால் அது dwindle-க்குத் திரும்பும். `Super + Alt + L` அவற்றின் வழியாக மற்ற திசையில் செல்லும். எப்படியும் மிதக்கும் ஒரு சாளரம் — `Super + T` கொண்டு நீங்கள் வெளியே எடுத்த ஒன்று, அல்லது எப்போதும் மிதந்து திறக்கும் ஒரு செயலி — பணியிடம் டைலிங்கிற்குத் திரும்பும்போது தொடர்ந்து மிதக்கும். மேல் பட்டி, நீங்கள் இருக்கும் பணியிடத்தை அதன் தளவமைப்புடன் குறிக்கும்: dwindle-க்கு ஒரு சதுரம், scrolling-க்கு ஒரு வட்டம், மிதப்பதற்கு ஒரு முக்கோணம். அந்தக் குறியைக் கிளிக் செய்தாலும் தளவமைப்பு சுழலும், அது உள்ள மடிக்கணினிகளில் உள்ள display விசையை அழுத்தினாலும் அதே நடக்கும்.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

இந்தத் தேர்வு ஒவ்வொரு பணியிடத்திற்கும் தனித்தனி, அது நிலைத்திருக்கும். எனவே பணியிடம் 1-ஐ உலாவலுக்கு dwindle-இலும், பணியிடம் 2-ஐ குறியீட்டிற்கு scrolling-இலும் வைத்திருக்கலாம், மறுதொடக்கத்திற்குப் பிறகு அவை அப்படியே திரும்ப வரும்.

scrolling தளவமைப்பை இயல்புநிலையாகப் பயன்படுத்த விரும்பினால், அதை `~/.config/hypr/looknfeel.lua`-இல் அமைக்கலாம்:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### மிதக்கும் பணியிடங்கள்

ஒரு மிதக்கும் பணியிடம் பாரம்பரிய டெஸ்க்டாப் போல செயல்படும்: சாளரங்கள் ஒன்றன் மேல் ஒன்று இருக்கும், அவற்றை நீங்களே நகர்த்தி அளவிடுவீர்கள். ஒவ்வொரு சாளரத்திற்கும் உங்கள் தீமின் வண்ணங்களில் ஒரு தலைப்புப் பட்டி கிடைக்கும், அதில் சிறிதாக்க, பெரிதாக்க மற்றும் மூடுவதற்கான பொத்தான்கள் இருக்கும். `Super + M` கவனத்தில் உள்ள சாளரத்தையும் சிறிதாக்கும். சிறிதாக்கப்பட்ட சாளரம் dock-இல் காத்திருக்கும்; அதன் செயலியைக் கிளிக் செய்து அதைத் திரும்பக் கொண்டு வாருங்கள். ஒரு சாளரத்தை முன்னால் கொண்டு வர அதைக் கிளிக் செய்யுங்கள். எந்த விளிம்பிலிருந்தோ மூலையிலிருந்தோ அதை மறுஅளவிடுங்கள். மேல் பட்டியைப் பார்வையில் வைத்துக் கொண்டே சாளரத்தைப் பெரிதாக்க ஒரு தலைப்புப் பட்டியை இருமுறை கிளிக் செய்யுங்கள், அதன் பழைய அளவைத் திரும்பப் பெற மீண்டும் அப்படியே செய்யுங்கள். Chrome மற்றும் பிற Chromium அடிப்படையிலான உலாவிகள், Disks மற்றும் Document Viewer தலைப்புப் பட்டியைத் தவிர்த்து, அதற்குப் பதிலாக அவற்றின் சொந்தத் தலைப்பைப் பயன்படுத்தும்; `Super + Alt + F` அவற்றைப் பெரிதாக்கும், `Super + M` அவற்றைச் சிறிதாக்கும்.

ஒவ்வொரு பணியிடத்திற்கும் ஒரு dock உள்ளது, அதில் உங்கள் பின் செய்த செயலிகள், இயங்கிக் கொண்டிருக்கும் எல்லாம், மற்றும் apps பொத்தானுக்குப் பின்னால் உள்ள ஒவ்வொரு செயலியின் கிரிட்டும் இருக்கும், அதை `Super + Alt + Space` மற்றும் Omarchy menu-வில் உள்ள _Apps_ ஆகியவையும் திறக்கும். கிரிட்டில் உள்ள ஒரு செயலியை நிறுவல் நீக்க, அதன் மீது வலது கிளிக் செய்யுங்கள் அல்லது `Delete` ஐ அழுத்துங்கள். ஒரு செயலியைத் திறக்க, அல்லது அதன் சாளரத்தை முன்னால் கொண்டு வர, அதைக் கிளிக் செய்யுங்கள்; அதன் சாளரங்களுக்கு இடையே சுழற்சி செய்ய மீண்டும் கிளிக் செய்யுங்கள். Files நீங்கள் இருக்கும் பணியிடத்திலிருந்து மட்டுமே ஒரு சாளரத்தைத் திரும்பக் கொண்டு வரும், இல்லையெனில் புதிய ஒன்றைத் திறக்கும், மேலும் Terminal மற்றும் Agent எப்போதும் மற்றொன்றைத் தொடங்கும், என்றாலும் சிறிதாக்கப்பட்ட சாளரம் முதலில் திரும்ப வரும். நடு-கிளிக் ஒரு புதிய சாளரத்தைத் திறக்கும். ஒரு ஐகானை dock வழியாக இழுத்து அதை நகர்த்துங்கள்; இயங்கும் ஒரு செயலியை மற்றவற்றுக்கு இடையே இழுப்பது அதை அங்கேயே வைத்திருக்கும். ஒரு செயலியை dock-இல் வைத்திருக்க, அதை வெளியே எடுக்க, அல்லது அதிலிருந்து வெளியேற வலது கிளிக் செய்யுங்கள். ஒரு பணியிடம் காலியாக இருக்கும்போது dock வெளியே இருக்கும், பணியிடத்தில் ஒரு சாளரம் வந்தவுடன் சுட்டி அதன் விளிம்பை அடையும் வரை அது மறைந்திருக்கும். ஒரு முழுத்திரை சாளரம் அதை முற்றிலும் மறைத்து விடும். dock-ஐ அங்கு நகர்த்த, apps பொத்தானைத் திரையின் மற்றொரு விளிம்பை நோக்கி இழுங்கள். ஒரு விளிம்பைத் தேர்ந்தெடுக்க _Position_, _Appearance > Workspace Layout_ செய்வது போல இயல்புநிலை தளவமைப்பை அமைக்க _Layout_, மற்றும் dock-ஐ எப்போதும் இயக்கத்தில் வைத்திருக்க, முதல் செயலி அதை மறைக்கும்படி செய்ய, அல்லது அதை எப்போதும் மறைந்திருக்கும்படி வைக்க _Visibility_ ஆகியவற்றுக்காக அதன் மீது வலது கிளிக் செய்யுங்கள். `omarchy dock visibility always` அதை ஒரு டெர்மினலிலிருந்து அமைக்கும். இந்த இடமும் _Appearance > Dock > Dock Position_ கீழ் உள்ளது, `omarchy dock position left` அதை ஒரு டெர்மினலிலிருந்து அமைக்கும். dock-இல் நீங்கள் வைத்திருக்கும் செயலிகள் இயங்காதபோது மங்கலாக இருக்கும். dock-ஐ மிதக்கும் பணியிடங்களுக்கு மட்டும் வைத்திருக்க, _Appearance > Dock > Dock Only on Floating_ அல்லது `omarchy dock tiling off` ஐப் பயன்படுத்துங்கள்.

புதிய பணியிடங்களும், `Super + L` கொண்டு நீங்கள் சொந்த தளவமைப்பு கொடுக்காத எவையும், இயல்புநிலை தளவமைப்பைப் பயன்படுத்தும். இயல்புநிலையை மாற்றினால் சாளரங்கள் இல்லாத ஒவ்வொரு பணியிடமும் அதற்கு மீட்டமைக்கப்படும், அதே நேரத்தில் சாளரங்கள் உள்ள ஒன்று தனக்கு உள்ள தளவமைப்பை வைத்திருக்கும். dock-க்குச் சிறிதாக்கப்பட்ட ஒரு சாளரம், அது விட்டுச் சென்ற பணியிடத்தில் உள்ள ஒரு சாளரமாகவே இன்னும் கணக்கிடப்படும். அதை _Appearance > Workspace Layout_ கீழ் தேர்ந்தெடுங்கள்: Tiling, Scrolling, அல்லது Floating. `omarchy hyprland workspace layout default scrolling` அதை ஒரு டெர்மினலிலிருந்து அமைக்கும்.

### சாளரங்களைக் குழுக்களாக்குதல்

`Super + G` ஐப் பயன்படுத்தி சாளரங்களைக் குழுக்களாக்கலாம். நீங்கள் ஒரு குழுவில் இருந்தவுடன், அது செயலில் இருக்கும்போது நீங்கள் தொடங்கும் ஒவ்வொரு சாளரமும் அந்தக் குழுவைச் சேர்ந்ததாக இருக்கும். `Super + Ctrl + Arrow Left/Right` ஐப் பயன்படுத்தி இந்தக் குழுவாக்கப்பட்ட சாளரங்களுக்கு இடையே செல்லலாம், அல்லது `Super + Alt + 1/2/3/4` ஐப் பயன்படுத்தி வரிசையில் குழுவாக்கப்பட்ட சாளரங்களுக்கு நேரடியாகச் செல்லலாம்.

`Super + Alt + G` கொண்டு ஒரு சாளரத்தைக் குழுவிலிருந்து வெளியே நகர்த்தலாம், அல்லது `Super + G` ஐ மீண்டும் அழுத்தி முழுக் குழுவையும் கலைக்கலாம். இறுதியாக, `Super + Alt + Arrows` கொண்டு குழுவுக்கு வெளியே உள்ள சாளரங்களை அதற்குள் நகர்த்தலாம்.

### சாளரங்களை வெளியே எடுத்தல்

`Super + O` கொண்டு ஒரு சாளரத்தை அதன் பணியிட ஒதுக்கீட்டிலிருந்து வெளியே எடுக்கலாம். அது, நீங்கள் எந்தப் பணியிடத்திற்குச் சென்றாலும் உங்களைப் பின்தொடரும் ஒரு மிதக்கும் சாளரமாக அதைப் பின் செய்யும். வீடியோ பிளேயர்கள் போன்றவற்றுக்குச் சிறந்தது.

### Scratchpad பணியிடம்

நீங்கள் தற்போது இருக்கும் பணியிடத்தின் மீது மேலடுக்காக வரும் ஒரு சிறப்பு முழு அளவிலான scratchpad பணியிடம் உள்ளது. அதில் உள்ளவற்றை `Super + S` ஐப் பயன்படுத்தி அணுகுவீர்கள், `Super + Alt + S` ஐப் பயன்படுத்தி அங்கு சாளரங்களை வைப்பீர்கள்.

தற்போதைய பணியிடத்தை விட்டு வெளியேறாமல் விரைவாகத் தொடர்பு கொள்ள விரும்பும் கட்டுப்பாடுகளுக்கோ அல்லது ஒரு டெர்மினலுக்கோ இது நன்றாக வேலை செய்யும்.

### Quake console

இறுதியாக, நீங்கள் தற்போது இருக்கும் பணியிடத்தின் மீது கீழே இறங்கும் அரை உயரமான Quake console ஒன்று உள்ளது. `Super + the key above Tab` (US தளவமைப்புகளில் grave) கொண்டு அதை மாற்றுங்கள், `Super + Shift + the key above Tab` ஐப் பயன்படுத்தி அங்கு ஒரு சாளரத்தை வையுங்கள்.

அது முதல் முறை திறக்கும்போது, உங்கள் இயல்புநிலை agent-ஐத் தொடங்கும், அல்லது நீங்கள் இன்னும் ஒன்றைத் தேர்வு செய்யவில்லை என்றால் ஒன்றைத் தேர்வு செய்யச் சொல்லும். console ஒரே ஒரு சாளரத்தை வைத்திருக்கும்போது, அது திரை முழுவதும் பரவாமல், மையப்படுத்தப்பட்ட பேனலாகக் கீழே இறங்கும். அதில் இரண்டாவது செயலியை வையுங்கள், அது முழு அகலத்திற்குத் திரும்பச் செல்லும், இதனால் இரண்டுக்கும் அருகருகே அமர இடம் கிடைக்கும்.

ஒரு சாளரத்தை scratchpad-இலிருந்தோ அல்லது console-இலிருந்தோ வெளியே நகர்த்த, `Super + Shift + 1` போன்ற ஒன்றைக் கொண்டு அதை நேரடியாக மற்றொரு பணியிடத்திற்கு அனுப்புங்கள்.

### பழகுவதற்குக் கொஞ்சம் நேரம் ஆகும்!

இப்படி உங்கள் டெஸ்க்டாப்பில் செல்வதற்குப் பழகுவதற்குக் கொஞ்சம் நேரம் ஆகும், ஆனால் நீங்கள் பழகி விட்டால், பாரம்பரிய மவுஸ் சார்ந்த டெஸ்க்டாப் அனுபவத்திற்குத் திரும்பிச் செல்வது கடினமாக இருக்கும்!
