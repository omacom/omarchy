# வழிசெலுத்தல்

Omarchy-இல் எல்லாமே விசைப்பலகை வழியாகத்தான் நடக்கும் — _எல்லாமும்!_ கணினி முதலில் தொடங்கும்போது, மவுஸை மட்டும் வைத்து உங்களால் உண்மையிலேயே எதுவும் செய்ய முடியாது. ஆனால் `Super + Space` அழுத்தி Omarchy Menu-வைக் காட்டலாம், இங்கிருந்து கிட்டத்தட்ட எல்லாவற்றையும் செய்யலாம்.

ஆனால் பெரும்பாலான நேரங்களில் கணினியை இயக்குவதற்கான முக்கிய வழியாக Omarchy menu இருக்க வேண்டும் என்பதே நோக்கமல்ல. அதைவிட வேகமாகச் செய்ய முடியும்! மிக முக்கியமான பயன்பாடுகள் அனைத்தும் நேரடியாக தனித்தனி விரைவு விசைகளுடன் இணைக்கப்பட்டுள்ளன. `Super + Return` மூலம் முனையத்தைத் தொடங்குகிறீர்கள், `Super + Shift + Return` மூலம் உலாவியைத் தொடங்குகிறீர்கள். ஒன்றன் பின் ஒன்றாகச் செய்து பாருங்கள், Hyprland-இன் tiling மாயாஜாலம் செயல்படுவதைக் காண்பீர்கள்:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

பிறகு `Super + J` அழுத்தி, அவற்றை அருகருகே வைப்பதற்குப் பதிலாக ஒன்றன் மேல் ஒன்றாக அடுக்கலாம்:

 ![navigation-stacked](images/navigation-stacked.webp)

மீண்டும் `Super + J` அழுத்தினால் அவை அருகருகே உள்ள நிலைகளுக்குத் திரும்பும். பிறகு உலாவியில் இருக்கும்போது `Super + Shift + Arrow Right` முயற்சித்து சாளரங்களை இடமாற்றுங்கள்.

இப்போது `Super + Shift + T` முயற்சித்து Activity monitor-ஐத் தொடங்குங்கள். அது மிதக்கும் சாளரமாகத் தோன்றும். `Super + T` மூலம் அதை tile செய்யலாம் (மீண்டும் அதையே அழுத்தினால் அது மீண்டும் மிதக்கும்). இப்போது `Super + Shift + F` அழுத்தி files manager-ஐத் திறங்கள். உங்களுக்கு அழகான நான்கு வழி அமைப்பு கிடைக்கும்:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

`Super + Arrow` மூலம் எந்த சாளரம் செயலில் இருக்க வேண்டும் என்பதற்கு இடையே செல்கிறீர்கள். இது கவனத்தை மாற்றி, கர்சரை புதிய பயன்பாட்டின் மையத்திற்கு நகர்த்தும். திரையின் விளிம்பில், அது அந்தப் பக்கத்தில் உள்ள monitor-க்குத் தொடரும்.

`Super + Shift + 2` அழுத்தினால், தற்போது கவனத்தில் உள்ள பயன்பாட்டை இரண்டாவது பணியிடத்திற்கு நகர்த்துவீர்கள். `Super + Shift + 1` அதைத் திரும்ப நகர்த்தும். (மேலும் `Super + Shift + Alt + 2` தற்போது கவனத்தில் உள்ள பயன்பாட்டை இரண்டாவது பணியிடத்திற்கு, அதற்கு மாறாமலேயே நகர்த்தும்).

ஒன்றுக்கு மேற்பட்ட monitor இருந்தால், ஒவ்வொரு monitor-க்கும் அதற்கே உரிய 1 முதல் 10 வரையிலான பணியிடங்கள் உள்ளன. `Super + 2` நீங்கள் இருக்கும் monitor-இன் இரண்டாவது பணியிடத்திற்குச் செல்லும், ஒவ்வொரு monitor-இன் மேல் பட்டியும் அதன் சொந்த பணியிடங்களையும் அது காட்டிக் கொண்டிருக்கும் பணியிடத்தையும் காட்டும். `Super + Tab` நீங்கள் இருக்கும் monitor-இல் உள்ள பணியிடங்களுக்கு இடையே சுழலும். `Super + Shift + Ctrl + Arrows` நீங்கள் இருக்கும் சாளரத்தை அந்த திசையில் உள்ள monitor-க்கு, அது காட்டிக் கொண்டிருக்கும் பணியிடத்திற்கு நகர்த்தும், மேலும் `Super + Shift + Alt + Arrows` நீங்கள் இருக்கும் பணியிடத்தை அந்த திசையில் உள்ள monitor-க்கு நகர்த்தும், அங்கு அது காலியாக இருந்தால் அதே எண்ணை எடுத்துக் கொள்ளும். ஒரு monitor-ஐ நீங்கள் துண்டிக்கும்போது அது அதன் பணியிடங்களை வைத்திருக்கும்: அவை மற்றொரு திரையின் பணியிடங்களுடன், அதற்கு ஏற்கனவே உள்ளவற்றுக்குப் பிறகு எண்ணிடப்பட்டு இணையும், monitor திரும்பும்போது அவற்றின் பழைய எண்களின் கீழ் திரும்பச் செல்லும்.

`Super`-ஐ அழுத்திப் பிடித்து மவுஸால் ஒரு சாளரத்தைக் கிளிக் செய்தால், அது எங்கு அமர்கிறது என்பதை மறுசீரமைக்க முடியும். `Super`-ஐ அழுத்திப் பிடித்து மவுஸில் வலது பொத்தானைப் பயன்படுத்தினால், சாளரத்தை சுதந்திரமாக அளவுமாற்றம் செய்யலாம்.

`Super + W` அல்லது `Super + Q` மூலம் ஒரு சாளரத்தை மூடுகிறீர்கள் (மேலும் `Ctrl + Alt + Delete` மூலம் எல்லா சாளரங்களையும் மூடுகிறீர்கள்).

`Super + F` மூலம் முழுத் திரைக்கும் செல்லலாம் அல்லது `Super + Alt + F` மூலம் முழு அகலத்திற்கு மட்டும் (மேல் பட்டியை வைத்து) செல்லலாம் அல்லது `Super + Ctrl + F` மூலம் ஒரு சாளரத்திற்குள் முழுத் திரைக்குச் செல்லலாம் (YouTube-க்கு நல்லது!).

### Dwindle vs scrolling அமைப்பு

Omarchy-இன் இயல்புநிலை அமைப்பு dwindle என்று அழைக்கப்படுகிறது. நீங்கள் ஒரு பணியிடத்தில் திறக்கும் எல்லா சாளரங்களையும், அவற்றை சுருக்க வேண்டியிருந்தாலும், எல்லா நேரமும் அது தெரியும்படி வைத்திருக்கும்.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

ஆனால் சாளரங்கள் அருகருகே, காட்சியின் தெரியும் விளிம்புக்கு அப்பால் வரிசையாக அமைக்கப்படும் scrolling அமைப்பாக ஒரு பணியிடத்தை மாற்றவும் நீங்கள் தேர்வு செய்யலாம். `Super + L` வழியாக ஒரே ஒரு பணியிடத்தை இந்த அமைப்பாக மாற்றுகிறீர்கள்.

மீண்டும் `Super + L` அழுத்தினால் பணியிடம் மிதக்கும் நிலைக்கு மாறும், அங்கு சாளரங்கள் சுதந்திரமாக ஒன்றன் மேல் ஒன்று அமையும், அவற்றை நீங்களே வைப்பீர்கள், மூன்றாவது முறை அழுத்தினால் அது dwindle-க்குத் திரும்பும். `Super + Alt + L` அவற்றின் வழியாக மற்ற திசையில் செல்லும். எப்படியிருந்தாலும் மிதக்கும் ஒரு சாளரம் — `Super + T` மூலம் நீங்கள் வெளியே எடுத்த ஒன்று, அல்லது எப்போதும் மிதந்தபடி திறக்கும் ஒரு பயன்பாடு — பணியிடம் tiling-க்குத் திரும்பும்போது மிதந்தபடியே இருக்கும். மேல் பட்டி நீங்கள் இருக்கும் பணியிடத்தை அதன் அமைப்புடன் குறிக்கும்: dwindle-க்கு ஒரு சதுரம், scrolling-க்கு ஒரு வட்டம், மிதப்பதற்கு ஒரு முக்கோணம். அந்தக் குறியைக் கிளிக் செய்வதும் அமைப்பைச் சுழற்றும்.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

இந்தத் தேர்வு ஒவ்வொரு பணியிடத்திற்கும் தனியானது, அது நிலைத்திருக்கும். எனவே பணியிடம் 1-ஐ உலாவுவதற்கு dwindle-இலும் பணியிடம் 2-ஐ குறியீட்டிற்கு scrolling-இலும் வைத்திருக்கலாம், மறுதொடக்கத்திற்குப் பிறகும் அவை அப்படியே திரும்பி வரும்.

scrolling அமைப்பை இயல்புநிலையாகப் பயன்படுத்த விரும்பினால், அதை `~/.config/hypr/looknfeel.lua`-இல் அமைக்கலாம்:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### மிதக்கும் பணியிடங்கள்

ஒரு மிதக்கும் பணியிடம் பாரம்பரிய டெஸ்க்டாப் போல செயல்படும்: சாளரங்கள் ஒன்றன் மேல் ஒன்று அமையும், அவற்றை நீங்களே நகர்த்தி அளவுமாற்றம் செய்வீர்கள். ஒவ்வொரு சாளரத்திற்கும் உங்கள் தீமின் வண்ணங்களில் ஒரு தலைப்புப் பட்டி கிடைக்கும், சிறிதாக்க, பெரிதாக்க, மூடுவதற்கான பொத்தான்களுடன். `Super + M` கவனத்தில் உள்ள சாளரத்தையும் சிறிதாக்கும். சிறிதாக்கப்பட்ட சாளரம் dock-இல் காத்திருக்கும்; அதைத் திரும்பக் கொண்டு வர அதன் பயன்பாட்டைக் கிளிக் செய்யுங்கள். ஒரு சாளரத்தை முன்னால் கொண்டு வர அதைக் கிளிக் செய்யுங்கள். எந்த விளிம்பிலிருந்தும் அல்லது மூலையிலிருந்தும் அதை அளவுமாற்றம் செய்யுங்கள். மேல் பட்டியைப் பார்வையில் வைத்தபடி சாளரத்தைப் பெரிதாக்க தலைப்புப் பட்டியை இருமுறை கிளிக் செய்யுங்கள், அதன் பழைய அளவைத் திரும்பப் பெற மீண்டும் செய்யுங்கள்.

ஒரு மிதக்கும் பணியிடம் dock-ஐயும் காட்டும், உங்கள் பின் செய்யப்பட்ட பயன்பாடுகள், இயங்கிக் கொண்டிருக்கும் எல்லாம், மற்றும் apps பொத்தானுக்குப் பின்னால் உள்ள ஒவ்வொரு பயன்பாட்டின் கட்டமும் அதில் இருக்கும், அதை `Super + Alt + Space` மற்றும் Omarchy menu-வில் உள்ள _Apps_ ஆகியவையும் திறக்கும். கட்டத்தில் ஒரு பயன்பாட்டை வலது கிளிக் செய்யுங்கள், அல்லது `Delete` அழுத்துங்கள், அதை நிறுவல் நீக்கம் செய்ய. ஒரு பயன்பாட்டைத் திறக்க, அல்லது அதன் சாளரத்தை முன்னால் கொண்டு வர அதைக் கிளிக் செய்யுங்கள்; அதன் சாளரங்களுக்கு இடையே சுழல மீண்டும் கிளிக் செய்யுங்கள். நடு கிளிக் ஒரு புதிய சாளரத்தைத் திறக்கும். ஒரு ஐகானை dock வழியாக இழுத்து அதை நகர்த்துங்கள்; இயங்கும் பயன்பாட்டை மற்றவற்றுக்கு இடையே இழுப்பது அதை அங்கேயே வைத்திருக்கும். ஒரு பயன்பாட்டை dock-இல் வைத்திருக்க, அதை வெளியே எடுக்க, அல்லது அதிலிருந்து வெளியேற வலது கிளிக் செய்யுங்கள். dock முழுத்திரை சாளரத்திற்கு வழிவிட்டு விலகும். dock-ஐ மற்றொரு விளிம்பிற்கு நகர்த்த அல்லது சுட்டி அதன் விளிம்பை அடையும் வரை அதை மறைந்திருக்கச் செய்ய apps பொத்தானை வலது கிளிக் செய்யுங்கள். அந்த நிலை _Appearance > Dock > Dock Position_ கீழும் உள்ளது, மேலும் `omarchy dock position left` மற்றும் `omarchy dock autohide on` ஆகியவை இரண்டையும் ஒரு முனையத்திலிருந்து அமைக்கும். நீங்கள் dock-இல் வைத்திருக்கும் பயன்பாடுகள் அவை இயங்காதபோது மங்கலாக இருக்கும்.

புதிய பணியிடங்கள், மற்றும் `Super + L` மூலம் நீங்கள் சொந்தமாக ஒரு அமைப்பை வழங்காத எவையும், இயல்புநிலை அமைப்பைப் பயன்படுத்தும். இயல்புநிலையை மாற்றுவது சாளரங்கள் இல்லாத ஒவ்வொரு பணியிடத்தையும் அதற்கு மீட்டமைக்கும், அதே நேரத்தில் அதில் சாளரங்கள் உள்ள ஒன்று அதற்கு உள்ள அமைப்பை வைத்திருக்கும். dock-க்கு சிறிதாக்கப்பட்ட சாளரம் அது விட்டுச் சென்ற பணியிடத்தில் உள்ள சாளரமாகவே இன்னும் கணக்கிடப்படும். அதை _Appearance > Workspace Layout_ கீழ் தேர்ந்தெடுங்கள்: Tiling, Scrolling, அல்லது Floating. `omarchy-hyprland-workspace-layout-default scrolling` அதை ஒரு முனையத்திலிருந்து அமைக்கும்.

### சாளரங்களைக் குழுவாக்குதல்

`Super + G` பயன்படுத்தி சாளரங்களைக் குழுவாக்கலாம். நீங்கள் ஒரு குழுவில் இருந்தவுடன், அது செயலில் இருக்கும்போது நீங்கள் தொடங்கும் ஒவ்வொரு சாளரமும் அந்தக் குழுவைச் சேரும். `Super + Ctrl + Arrow Left/Right` பயன்படுத்தி அல்லது வரிசையில் நேரடியாகக் குழுவாக்கப்பட்ட சாளரத்திற்குச் செல்ல `Super + Alt + 1/2/3/4` பயன்படுத்தி இந்தக் குழுவாக்கப்பட்ட சாளரங்களுக்கு இடையே நகரலாம்.

`Super + Alt + G` மூலம் ஒரு சாளரத்தைக் குழுவிலிருந்து வெளியே நகர்த்தலாம் அல்லது மீண்டும் `Super + G` அழுத்தி முழுக் குழுவையும் கலைக்கலாம். இறுதியாக, `Super + Alt + Arrows` மூலம் குழுவிற்கு வெளியே உள்ள சாளரங்களை அதற்குள் நகர்த்தலாம்.

### சாளரங்களை வெளியே எடுத்தல்

`Super + O` மூலம் ஒரு சாளரத்தை அதன் பணியிட ஒதுக்கீட்டிலிருந்து வெளியே எடுக்கலாம். அது அதை நீங்கள் எந்த பணியிடத்திற்குச் சென்றாலும் உங்களைப் பின்தொடரும் மிதக்கும் சாளரமாகப் பின் செய்யும். வீடியோ பிளேயர்கள் போன்றவற்றுக்கு மிகச் சிறந்தது.

### Scratchpad பணியிடம்

நீங்கள் தற்போது இருக்கும் எந்த பணியிடத்தின் மீதும் மேலடுக்காக அமையும் ஒரு சிறப்பு முழு அளவு scratchpad பணியிடம் உள்ளது. `Super + S` பயன்படுத்தி அதில் உள்ளதை அணுகுகிறீர்கள், மேலும் `Super + Alt + S` பயன்படுத்தி அங்கு சாளரங்களை வைக்கிறீர்கள்.

தற்போதைய பணியிடத்தை விட்டு வெளியேறாமல் விரைவாக தொடர்பு கொள்ள விரும்பும் கட்டுப்பாடுகள் அல்லது ஒரு முனையத்திற்கு இது நன்றாக வேலை செய்யும்.

### Quake console

இறுதியாக, நீங்கள் தற்போது இருக்கும் எந்த பணியிடத்தின் மீதும் கீழே இறங்கும் அரை உயர Quake console ஒன்று உள்ளது. `Super + Grave` மூலம் அதை மாற்றுங்கள், மேலும் `Super + Shift + Grave` பயன்படுத்தி அங்கு ஒரு சாளரத்தை வைக்கவும்.

அது உங்கள் இயல்புநிலை agent தயாராக இருக்கத் திறக்கும். console ஒரே ஒரு சாளரத்தை வைத்திருக்கும்போது, அது திரையை நிரப்புவதற்குப் பதிலாக மையப்படுத்தப்பட்ட பேனலாக கீழே இறங்கும். அதில் இரண்டாவது பயன்பாட்டை வையுங்கள், அது முழு அகலத்திற்குத் திரும்பும், அதனால் இரண்டுக்கும் அருகருகே அமர இடம் கிடைக்கும்.

scratchpad அல்லது console இரண்டிலிருந்தும் ஒரு சாளரத்தை நகர்த்த, `Super + Shift + 1` போன்ற ஒன்றைக் கொண்டு அதை நேரடியாக மற்றொரு பணியிடத்திற்கு அனுப்புங்கள்.

### பழகிக் கொள்ள கொஞ்சம் நேரம் ஆகும்!

உங்கள் டெஸ்க்டாப்பில் இப்படிச் செல்வதற்குப் பழகிக் கொள்ள கொஞ்சம் நேரம் ஆகும், ஆனால் நீங்கள் பழகிவிட்டால், பாரம்பரிய மவுஸ்-இயக்க டெஸ்க்டாப் அனுபவத்திற்குத் திரும்பிச் செல்வது கடினமாக இருக்கும்!
