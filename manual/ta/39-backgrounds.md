# பின்னணிகள்

ஒவ்வொரு theme-உம் அதற்கே உரிய பின்னணிகளின் தொகுப்புடன் வருகிறது, மேலும் உங்களுக்கான கூடுதல் பின்னணிகளை `~/.config/omarchy/backgrounds/[theme]` இல் நீங்கள் சேர்க்கலாம். எடுத்துக்காட்டாக, nord theme-இற்கு ஒரு கூடுதல் பின்னணிப் படத்தைச் சேர்க்க விரும்பினால், கோப்பை `~/.config/omarchy/backgrounds/nord` இல் போட்டால் போதும்.

Omarchy Menu-வில் _Install > Style > Background_ என்பதற்குச் செல்வதன் மூலம் இதை மிக எளிதாகச் செய்யலாம். அந்த theme-இன் பின்னணிகள் சேமிக்கப்பட்டுள்ள கோப்புறையை அது திறக்கும். இன்னொரு file manager-ஐத் தொடங்க `Super + Shift + F` ஐ அழுத்தி, உங்கள் பின்னணியைக் கண்டுபிடித்து, அதை நகலெடுத்து அங்கே போடுங்கள். இப்போது அது `Super + Ctrl + W` ஐப் பயன்படுத்தி நீங்கள் தேர்ந்தெடுக்கக்கூடிய பின்னணிகளின் தேர்வுகளில் சேர்க்கப்படும்.

பின்னணிகள் நிலையான படங்களாக மட்டுமல்லாமல் வீடியோக்களாகவும் இருக்கலாம். அதே கோப்புறையில் ஒரு `mp4`, `m4v`, `mov`, `webm`, `mkv`, அல்லது `avi` கோப்பைப் போடுங்கள்; அது படங்களுடன் சேர்ந்து தோன்றும். வீடியோக்கள் OWE wallpaper engine ஆல் இயக்கப்படுகின்றன. இது எல்லா monitors-க்கும் சேர்த்து வீடியோவை ஒரே முறை decode செய்கிறது, அதன் ஒலியை default audio output வழியாக இயக்குகிறது, எதுவும் அதைப் பார்க்க முடியாதபோதெல்லாம் இயக்கத்தை நிறுத்துகிறது. ஒரு வீடியோ wallpaper ஒரு நிலையான wallpaper-ஐ விட இன்னும் மிக அதிக மின்சாரத்தைச் செலவழிக்கிறது.

Theme-கள் ஒரு நிலையான பின்னணிக்கான குறுகிய intro-வைக் கொண்டிருக்கலாம். `backgrounds/road.webp` க்கு, அதற்குப் பொருந்தும் வீடியோ `backgrounds/intros/road.mp4` இல் இருக்கும். இது boot நேரத்திலும், அந்தப் பின்னணி தேர்ந்தெடுக்கப்பட்ட theme-க்கு மாறும்போதும், அந்தப் பின்னணியைத் தேர்ந்தெடுக்கும்போதும் தானாகவே இயங்கி, பின்னர் நிலையான படத்திற்குத் திரும்பும். Intro வீடியோக்கள் background picker-இல் வராது, ஒருபோதும் loop ஆகாது.

_Appearance > Animations_ ஐ அணைப்பது பின்னணி intro-க்களையும் அணைக்கும். ஒரு virtual machine-இல் Omarchy இதை default ஆகச் செய்கிறது. `omarchy theme bg intro toggle` கட்டளை intro-க்களைத் தனியாக மாற்றியமைக்க முடியும். ஒரு theme-ஐ refresh செய்வது intro-வை இயக்காது.

கவனமாகத் தேர்ந்தெடுக்கப்பட்ட அருமையான பின்னணிகளின் மிகப் பெரிய தொகுப்பை [dharmx/walls](https://github.com/dharmx/walls) இல் காணலாம்.

Lock screen ஒரு animated GIF-இன் நிலையான frame-ஐக் காட்டும் அதே வழியில், ஒரு வீடியோ பின்னணியின் நிலையான frame-ஐக் காட்டுகிறது.
