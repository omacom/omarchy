# பின்னணிகள்

ஒவ்வொரு தீமும் அதற்கான சொந்தப் பின்னணிகளின் தொகுப்புடன் வருகிறது, மேலும் உங்களுடைய கூடுதல் பின்னணிகளை நீங்கள் `~/.config/omarchy/backgrounds/[theme]` இல் சேர்க்கலாம். எடுத்துக்காட்டாக, nord தீமில் ஒரு கூடுதல் பின்னணிப் படத்தைச் சேர்க்க விரும்பினால், அந்தக் கோப்பை `~/.config/omarchy/backgrounds/nord` இல் போட்டால் போதும்.

Omarchy Menu வில் _Install > Style > Background_ க்குச் செல்வதே இதைச் செய்வதற்கான மிக எளிதான வழி. அது அந்தத் தீமுக்கான பின்னணிகள் சேமிக்கப்பட்டிருக்கும் கோப்புறையைக் கொண்டுவரும். மற்றொரு file manager ஐத் தொடங்க `Super + Shift + F` ஐ அழுத்தி, உங்கள் பின்னணியைக் கண்டுபிடித்து, அதை அங்கே நகலெடுங்கள். இப்போது அது `Super + Ctrl + W` ஐப் பயன்படுத்தி நீங்கள் தேர்ந்தெடுக்கக்கூடிய பின்னணி விருப்பங்களில் சேர்க்கப்படும்.

பின்னணிகள் நிலையான படங்களாக மட்டுமல்லாமல் வீடியோக்களாகவும் இருக்கலாம். ஒரு `mp4`, `m4v`, `mov`, `webm`, `mkv`, அல்லது `avi` கோப்பை அதே கோப்புறையில் போடுங்கள், அது படங்களுடன் சேர்ந்து தோன்றும். வீடியோக்களை OWE wallpaper engine இயக்குகிறது. இது எல்லா மானிட்டர்களுக்கும் சேர்த்து வீடியோவை ஒரே முறை decode செய்கிறது, அதன் ஒலியை இயல்புநிலை audio output வழியாக இயக்குகிறது, மேலும் அதை எதுவும் பார்க்க முடியாதபோதெல்லாம் இயக்கத்தை நிறுத்திவிடுகிறது. ஒரு வீடியோ wallpaper இன்னமும் நிலையான ஒன்றைவிட மிக அதிக மின்சாரத்தைச் செலவழிக்கிறது.

தீம்களில் ஒரு நிலையான பின்னணிக்கான குறுகிய intro இருக்கலாம். `backgrounds/road.webp` க்கு, அதற்குப் பொருந்தும் வீடியோ `backgrounds/intros/road.mp4` இல் உள்ளது. இது boot செய்யும்போதும், அந்தப் பின்னணி தேர்ந்தெடுக்கப்பட்ட தீமுக்கு மாறும்போதும், அந்தப் பின்னணியைத் தேர்ந்தெடுக்கும்போதும் தானாகவே இயங்கி, பின்னர் நிலையான படத்திற்குத் திரும்பும். Intro வீடியோக்கள் background picker இல் இடம்பெறாது, ஒருபோதும் loop ஆகாது.

_Appearance > Animations Off_ ஐத் தேர்ந்தெடுப்பது பின்னணி intro க்களையும் அணைத்துவிடும். Omarchy ஒரு virtual machine இல் இயல்பாகவே இதைச் செய்கிறது. `omarchy theme bg intro toggle` கட்டளை intro க்களைத் தனியாக மாற்றியமைக்க முடியும். ஒரு தீமைப் புதுப்பிப்பது intro வை இயக்காது.

ஒரு நிலையான படத்திற்கு, தொடர்ந்து அசைந்துகொண்டிருக்கும் அதே படத்தின் அமைதியான பதிப்பான ஒரு loop உம் `backgrounds/loops/road.mp4` இல் இருக்கலாம். இது நிலையான படத்தின் இடத்தில், அதற்கு intro இருந்தால் அதற்குப் பிறகு இயங்கும், மேலும் animations அணைக்கப்படும்போது நின்றுவிடும். Battery இல் இருக்கும்போது, அதற்குப் பதிலாக நிலையான படம் தெரியும், நீங்கள் மின்சாரத்தில் இணைத்தவுடன் loop திரும்பிவிடும். Loop க்கள் background picker இல் இடம்பெறாது.

குளிர்ச்சியான, கவனமாகத் தேர்ந்தெடுக்கப்பட்ட பின்னணிகளின் மிகப் பெரிய தொகுப்பை நீங்கள் [dharmx/walls](https://github.com/dharmx/walls) இல் காணலாம்.

Lock screen ஒரு வீடியோ பின்னணியின் நிலையான frame ஐக் காட்டுகிறது, அது ஒரு animated GIF இன் நிலையான frame ஐக் காட்டும் அதே விதத்தில்.
