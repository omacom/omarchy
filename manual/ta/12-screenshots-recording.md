# திரைப்பிடிப்புகள் & பதிவு செய்தல்

திரையில் இருந்து நீங்கள் பிடிக்கக்கூடிய அனைத்தும் Print Screen விசையில்தான் தொங்கிக் கொண்டிருக்கிறது. விசையை மட்டும் அழுத்தினால் ஒரு படம் கிடைக்கும், மாற்று விசைகளுடன் சேர்த்தால் ஒரு பதிவு, ஒரு நிறம், அல்லது ஒரு பகுதிக்குள் இருக்கும் உரை கிடைக்கும். உங்கள் விசைப்பலகையில் Print Screen விசையே இல்லையென்றால், `Super + Ctrl + Alt + C` அதே திரைப்பிடிப்பை எடுக்கும், `Super + Ctrl + C` முழுத் தொகுப்பையும் ஒரு மெனுவாகத் திறக்கும்.

| விசைச்சேர்க்கை | செயல்பாடு |
| ------ | -------- |
| `Print Screen` | திரைப்பிடிப்பு |
| `Super + Ctrl + Alt + C` | திரைப்பிடிப்பு |
| `Alt + Print Screen` | திரைப்பதிவு (அல்லது இயங்கிக் கொண்டிருப்பதை நிறுத்து) |
| `Super + Print Screen` | நிறம் தேர்ந்தெடுப்பான் |
| `Super + Ctrl + Print Screen` | ஒரு பகுதியில் இருந்து உரையைப் பிரித்தெடு |
| `Super + Ctrl + C` | பிடிப்பு மெனு |
| `Super + Ctrl + .` | ஒரு படத்தையோ காணொளியையோ வடிவம் மாற்று |

## திரைப்பிடிப்புகள்

`Print Screen` (அல்லது `Super + Ctrl + Alt + C`) அழுத்துங்கள்; Omasnap அதன் மேலடுக்குத் தோன்றுவதற்கு முன்பே கவனத்தில் உள்ள திரையைப் பிடித்துவிடும், எனவே நீங்கள் குறி வைக்கும்போது உங்களுக்குக் கீழே எதுவும் நகராது. கட்டற்ற வடிவில் ஒரு பகுதியை இழுத்து வரையுங்கள், ஒரு சாளரத்தைச் சொடுக்கி அதைப் பிடியுங்கள், அல்லது வெற்று இடத்தைச் சொடுக்கி முழுத் திரையையும் பிடியுங்கள். உருட்டக்கூடிய பகுதியைப் பிடிக்க, வரைவதற்கு முன் `S` அழுத்துங்கள். மனம் மாறிவிட்டதா? அதே விசையை மீண்டும் அழுத்தி Omasnap-ஐ மூடிவிடுங்கள்.

ஒரு பகுதியைத் தேர்ந்தெடுத்த பிறகு, Omasnap பிடிப்பைச் சேமிக்கிறது, அதை கிளிப்போர்டுக்கு நகலெடுக்கிறது, சேமிக்கப்பட்ட திரைப்பதிவு செய்வது போலவே அதன் சிறுபடத்துடன் ஒரு அறிவிப்பைக் காட்டுகிறது. சேமித்த படத்தை உங்கள் படப் பார்வையாளரில் பார்க்க திற என்பதைத் தேர்ந்தெடுங்கள், அல்லது அதில் குறிப்புகள் சேர்க்க திருத்து என்பதைத் தேர்ந்தெடுங்கள்.

குறிப்பு திருத்தி அம்புகள், கோடுகள், வடிவங்கள், சிறப்பம்சங்கள், எண்ணிடப்பட்ட குறிப்பான்கள், உரை மற்றும் பாதுகாப்பான மறைப்புகளை வரைய முடியும்; படத்தின் ஒரு பகுதியை வெட்டவோ அறுத்து எடுக்கவோ முடியும்; அதன் உரையை OCR செய்ய முடியும்; ஒரு பின்னணியையும் சேர்க்க முடியும். திருத்தியில், முடிந்த PNG-ஐ நகலெடுத்துச் சேமிக்க `Enter` அழுத்துங்கள், சேமிக்காமல் நகலெடுக்க `Ctrl + C` அழுத்துங்கள், அல்லது நகலெடுக்காமல் சேமிக்க `Ctrl + S` அழுத்துங்கள்.

சேமிக்கப்பட்ட திரைப்பிடிப்புகள் இயல்பாக `~/Pictures/Screenshots` இல் வந்து சேரும், `screenshot-2026-08-13_14-22-05-firefox.png` போன்ற பெயருடன். வேறு கோப்பகத்தைப் பயன்படுத்த `OMASNAP_SCREENSHOT_DIR` அமையுங்கள் — அமர்வு சூழல் மாறிகளை எங்கே வைப்பது என்பதற்கு [அடிக்கடி கேட்கப்படும் கேள்விகளைப்](46-faq.md) பாருங்கள். முதல் படத்தைச் சேமிக்கும்போது Omasnap கோப்பகத்தை உருவாக்குகிறது. தானாகச் சேமிப்பதை முடக்க `~/.config/omasnap/omasnap.conf` இல் `[output] autosave = false` அமையுங்கள்; அப்போது பிடிப்புகள் நகலெடுக்கப்பட மட்டுமே செய்யும், மேலும் 10 வினாடிகளுக்கு ஒரு முன்னோட்டத்தில் காட்டப்படும், அதன் பின் பொத்தானாலோ அல்லது `Ctrl + P` ஆலோ அதைத் திரையிலேயே வைத்திருக்கலாம்.

முனையத்தில் இருந்து, `omarchy screenshot` அதே மேலடுக்கைத் திறக்கிறது, அதன் தொடக்க நிலையையும் நீங்கள் தேர்ந்தெடுக்கலாம்: `omarchy capture screenshot region`, `windows`, `fullscreen`, அல்லது `scroll`. `copy` அல்லது `save` என்ற இரண்டாவது வாதம் படத்தை நேரடியாக அந்த இலக்குக்கு அனுப்புகிறது. வெளியீட்டுக்கு முன் திருத்த, முழுத்திரை திருத்திக்கு `omarchy screenshot --editor=overlay` பயன்படுத்துங்கள் அல்லது தனி சாளரத்துக்கு `omarchy screenshot --editor=window` பயன்படுத்துங்கள்.

### விசைப்பலகையில் இருந்து தேர்ந்தெடுப்பானை இயக்குதல்

தேர்வு தோன்றியிருக்கும்போது, நீங்கள் சுட்டியைப் பயன்படுத்தவே வேண்டியதில்லை:

| விசை | செயல்பாடு |
| --- | -------- |
| `S` | உருட்டக்கூடிய பகுதி நிலையை மாற்று |
| `Super + Arrow keys` | சாளர நிலையில் சாளரங்களுக்கு இடையே நகரு |
| `Return` | சிறப்பிக்கப்பட்ட சாளரத்தைப் பிடி |
| `Ctrl + A` | கவனத்தில் உள்ள முழுத் திரையையும் பிடி |
| `R` | இந்த அமர்வில் கடைசியாக வரைந்த பகுதியை மீட்டமை |
| `Esc` | Omasnap-ஐ மூடு |

இந்த விசைச்சேர்க்கைகள் Omasnap திறந்திருக்கும்போது மட்டுமே இருக்கும், எனவே அவை உங்கள் சொந்த உள்ளமைவில் உள்ள எதனுடனும் மோத முடியாது.

## திரைப்பதிவு

`Alt + Print Screen` _Trigger > Capture > Screenrecord_ ஐத் திறக்கிறது, அது ஒலிப்பதிவில் உங்களுக்கு என்ன வேண்டும் என்று கேட்கிறது: ஒலி இல்லை, டெஸ்க்டாப் ஒலி, டெஸ்க்டாப்புடன் ஒலிவாங்கி, அல்லது டெஸ்க்டாப்புடன் ஒலிவாங்கியும் வெப்கேமும். உங்களிடம் உண்மையிலேயே ஒரு கேமரா செருகப்பட்டிருந்தால் மட்டுமே அந்தக் கடைசி விருப்பம் தோன்றும். ஒன்றைத் தேர்ந்தெடுங்கள்; Omarchy-இன் பதிவு தேர்ந்தெடுப்பான் ஒரு பகுதியை இழுக்கவோ அல்லது ஒரு சாளரத்தையோ திரையையோ சொடுக்கவோ உங்களை அனுமதிக்கிறது.

பதிவு gpu-screen-recorder இல் இயங்குகிறது, அது GPU இல் 60fps இல் குறியாக்கம் செய்கிறது, வேண்டியிருந்தால் CPU க்குத் திரும்பிவிடும். இதன் விளைவாக `~/Videos` இல் ஒரு MP4 கிடைக்கிறது, `screenrecording-2026-08-13_14-22-05.mp4` என்ற பெயருடன். அதை மாற்ற `OMARCHY_SCREENRECORD_DIR` அமையுங்கள் — ஆனால் திரைப்பிடிப்பு கோப்பகத்தைப் போலல்லாமல், இது ஏற்கனவே இருக்க வேண்டும், இல்லையென்றால் பதிவு தொடங்க மறுக்கும் என்பதைக் கவனியுங்கள்.

நீங்கள் பதிவு செய்து கொண்டிருக்கும்போது, பட்டியில் ஒரு சிறிய குறிப்பான் தோன்றும். நிறுத்த அதைச் சொடுக்குங்கள். `Alt + Print Screen` ஐ மீண்டும் அழுத்தியும் நிறுத்தலாம், அல்லது _Trigger > Capture > Screenrecord_ இன் கீழ் உள்ள _Stop Screenrecording_ உள்ளீட்டாலும் நிறுத்தலாம், அது ஏதாவது உண்மையிலேயே பதிவாகிக் கொண்டிருக்கும்போது மட்டுமே தோன்றும்.

நிறுத்துவது கோப்பை உங்களிடம் ஒப்படைப்பதற்கு முன் கொஞ்சம் ஒழுங்குபடுத்துகிறது: முதல் சட்டகம் வெட்டி நீக்கப்படுகிறது, ஒலி இருந்தால் அது -14 LUFS க்கு இயல்பாக்கப்படுகிறது, மிகத் தொடக்கத்தில் உள்ள PipeWire பிடிப்பு ஒலி மௌனமாக்கப்படுகிறது. பிறகு பதிவில் இருந்து ஒரு சிறுபடத்துடன் ஒரு அறிவிப்பு தோன்றும். கோப்பை Omaview இல் இயக்க அதைச் சொடுக்குங்கள்.

### வெப்கேம் மேலடுக்கு

வெப்கேமுடன் பதிவு செய்யும்போது, நீங்கள் பதிவு செய்யும் எதன் கீழ்-வலது மூலையிலும் கேமரா பொருத்தப்பட்ட, வெட்டப்பட்ட உருவப்பட சாளரமாகத் தோன்றும். அது உங்களுக்குத் தேவையான ஒன்றின் மேல் அமர்ந்திருந்தால், அப்போதே அதன் அளவை மாற்றுங்கள்:

| விசைச்சேர்க்கை | செயல்பாடு |
| ------ | -------- |
| `Super + Alt + [` | வெப்கேம் மேலடுக்கைச் சிறியதாக்கு |
| `Super + Alt + ]` | வெப்கேம் மேலடுக்கைப் பெரியதாக்கு |

மூன்று அளவுகள் உள்ளன — சிறியது, நடுத்தரம், பெரியது — விசைச்சேர்க்கைகள் அவற்றுக்கு இடையே படிப்படியாக நகரும். நடுத்தரம் இயல்பானது. அவை பதிவுக்கு விகிதாசாரமானவை, எனவே நீங்கள் 1080p திரையைப் பதிவு செய்தாலும் 6K திரையைப் பதிவு செய்தாலும் கேமரா சட்டகத்தில் அதே பங்கை எடுத்துக்கொள்ளும். முழுக் காட்சிக்குப் பதிலாக ஒரு பகுதியைப் பதிவு செய்திருந்தால், மேலடுக்கு திரையின் மூலையில் இருப்பதற்குப் பதிலாக அந்தப் பகுதியின் மூலையில் நங்கூரமிடும், எனவே அது படத்துக்குள்ளேயே இருக்கும்.

`omarchy-capture-webcam-resize small` என்று நேரடியாகவும் அதை அழைக்கலாம், அல்லது நடுத்தரத்துக்குத் திரும்ப `reset` என்றும் அழைக்கலாம்.

## உரை, QR குறியீடுகள், மற்றும் நிறங்கள்

`Super + Ctrl + Print Screen` ஒரு பகுதியைத் தேர்ந்தெடுத்து அதை OCR செய்து கிளிப்போர்டுக்கு அனுப்புகிறது. அது [உரை பிரித்தெடுத்தல் & வாய்மொழி உள்ளீடு](11-text-extraction-dictation.md) இல் முறையாக விவரிக்கப்பட்டுள்ளது.

_Trigger > Capture > QR Code_ QR குறியீடுகளுக்கும் அதே தந்திரத்தைச் செய்கிறது. குறியீடு உள்ள பகுதியைத் தேர்ந்தெடுங்கள், மறைகுறியாக்கம் நீக்கப்பட்ட மதிப்பு கிளிப்போர்டுக்குச் செல்லும். அது QR குறியீடுகளை மட்டுமே தேடுகிறது — இல்லையென்றால் அடர்த்தியான திரை உள்ளடக்கம் பார்கோடாகத் தவறாகக் கண்டறியப்படும் பழக்கம் கொண்டது. தெரிந்து கொள்ள வேண்டியது: மறைகுறியாக்கம் நீக்கப்பட்ட மதிப்பு கிளிப்போர்டுக்கு மட்டுமே செல்கிறது, வேறு எங்கும் இல்லை. அது அச்சிடப்படுவதில்லை, அறிவிப்பில் இல்லை, மேலும் அது உணர்திறன் மிக்கதாகக் குறிக்கப்படுகிறது, எனவே அது [கிளிப்போர்டு வரலாற்றில்](08-unified-clipboard-history.md) தங்கிவிடாது. QR குறியீடுகள் வழக்கமாக ரகசியங்களைக் கொண்டு செல்கின்றன — எடுத்துக்காட்டாக, 2FA அமைப்புக் குறியீட்டுக்குப் பின்னால் உள்ள `otpauth://` URI — அது ஒரு பதிவில் இருப்பதை நீங்கள் விரும்ப மாட்டீர்கள். ஒட்டுவது இன்னும் நன்றாக வேலை செய்கிறது.

`Super + Print Screen` (அல்லது _Trigger > Capture > Color_) கர்சரை ஒரு நிறம் உறிஞ்சியாக மாற்றுகிறது. திரையில் எதையாவது சொடுக்குங்கள், நிறம் கிளிப்போர்டில் வந்து சேரும். தேர்ந்தெடுக்காமல் பின்வாங்க விசைச்சேர்க்கையை மீண்டும் அழுத்துங்கள்.

## பகிர்வதற்கு முன் வடிவம் மாற்றுதல்

4K திரைப்பதிவோ அல்லது உங்கள் தொலைபேசியில் இருந்து வந்த பதப்படுத்தப்படாத HEIC-ஓ பெரும்பாலும் அப்படியே அனுப்ப முடியாத அளவுக்குப் பெரியதாக இருக்கும். `Super + Ctrl + .` (அல்லது _Trigger > Transcode_) அதைச் சரிசெய்கிறது. அது `~/Pictures` மற்றும் `~/Videos` மீது ஒரு தெளிவற்ற கோப்புத் தேர்ந்தெடுப்பானை உங்களுக்கு வழங்குகிறது, பிறகு ஒரு வடிவத்தையும் அளவையும் கேட்கிறது.

படங்கள் உயர், நடுத்தர, அல்லது குறைந்த அளவில் jpg அல்லது png க்குச் செல்கின்றன, அவை அகலத்தை 3160, 2160, மற்றும் 1080 பிக்சல்களாகக் கட்டுப்படுத்துகின்றன. காணொளிகள் 4k, 1080p, அல்லது 720p இல் mp4 அல்லது அசையும் gif க்குச் செல்கின்றன. மாற்றப்பட்ட கோப்பு அசலுக்கு அருகிலேயே பெயரில் தெளிவுத்திறனுடன் எழுதப்படுகிறது — `demo-1080p.mp4` — மேலும் பாதை ஒரு கோப்பு URI ஆக கிளிப்போர்டுக்கு நகலெடுக்கப்படுகிறது, எனவே கோப்பு வீழ்த்துதல்களை ஏற்கும் ஒரு செயலியில் அதை நேரடியாக ஒட்டலாம்.

உங்களுக்கு என்ன வேண்டும் என்று ஏற்கனவே தெரிந்தால், முனையத்தில் இருந்தும் இது வேலை செய்கிறது: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. `omarchy transcode ascii` என்றும் ஒன்று உள்ளது, அது ஒரு படத்தை ASCII கலையாக மாற்றுகிறது — அது பெரும்பாலும் [பிராண்டிங்கிற்காக](41-branding.md).

## அதை எங்காவது அனுப்புதல்

கோப்பு கிடைத்தவுடன், `Super + Ctrl + S` பகிர் மெனுவைத் திறந்து LocalSend வழியாக உங்கள் வலையமைப்பில் உள்ள மற்றொரு சாதனத்துக்கு அதை அனுப்புகிறது. அதற்கு [GUIs](22-guis.md) ஐப் பாருங்கள்.
