# திரைப்பிடிப்புகள் & பதிவு செய்தல்

திரையிலிருந்து நீங்கள் பிடிக்கக்கூடிய அனைத்தும் Print Screen விசையிலிருந்து தொடங்குகிறது. தனியாக அந்த விசை ஒரு படத்தை எடுக்கிறது, மாற்று விசைகள் ஒரு பதிவை, ஒரு நிறத்தை, அல்லது ஒரு பகுதிக்குள் உள்ள உரையை எடுக்கின்றன. உங்கள் விசைப்பலகையில் Print Screen விசையே இல்லையென்றால், `Super + Ctrl + Alt + C` அதே திரைப்பிடிப்பை எடுக்கிறது, `Super + Ctrl + C` முழுத் தொகுப்பையும் ஒரு பட்டியலாகத் திறக்கிறது.

| விசைச்சேர்க்கை | செயல்பாடு |
| ------ | -------- |
| `Print Screen` | திரைப்பிடிப்பு |
| `Super + Ctrl + Alt + C` | திரைப்பிடிப்பு |
| `Alt + Print Screen` | திரைப்பதிவு (அல்லது இயங்கிக்கொண்டிருப்பதை நிறுத்து) |
| `Super + Print Screen` | நிறத் தேர்வி |
| `Super + Ctrl + Print Screen` | ஒரு பகுதியிலிருந்து உரையைப் பிரித்தெடு |
| `Super + Ctrl + C` | பிடிப்புப் பட்டியல் |
| `Super + Ctrl + .` | ஒரு படத்தை அல்லது காணொளியை வடிவமாற்று |

## திரைப்பிடிப்புகள்

`Print Screen` (அல்லது `Super + Ctrl + Alt + C`) ஐ அழுத்துங்கள்; Omasnap அதன் மேலடுக்கு தோன்றும் முன்பே கவனத்தில் உள்ள திரையைப் பிடிக்கிறது, எனவே நீங்கள் குறிவைக்கும்போது உங்களுக்குக் கீழே எதுவும் நகராது. கட்டற்ற வடிவில் ஒரு பகுதியை இழுக்கவும், அதைப் பிடிக்க ஒரு சாளரத்தைச் சொடுக்கவும், அல்லது முழுத் திரையையும் பிடிக்க வெற்று இடத்தைச் சொடுக்கவும். வரைவதற்கு முன் `S` ஐ அழுத்தி உருளும் பகுதியைப் பிடிக்கவும். மனம் மாறிவிட்டதா? Omasnap ஐ நீக்க அதே விசையை மீண்டும் அழுத்துங்கள்.

ஒரு பகுதியைத் தேர்ந்த பிறகு, Omasnap பிடிப்பைச் சேமிக்கிறது, அதை கிளிப்போர்டுக்கு நகலெடுக்கிறது, 10 வினாடிகளுக்கு ஒரு முன்னோட்டத்தைக் காட்டுகிறது. அதைத் திரையில் வைத்திருக்க முன்னோட்டத்தின் பின் பொத்தானை அல்லது `Ctrl + P` ஐப் பயன்படுத்துங்கள், அல்லது அதில் குறிப்புகள் சேர்க்க Edit ஐத் தேர்ந்தெடுங்கள்.

குறிப்புத் திருத்தி அம்புகள், கோடுகள், வடிவங்கள், முக்கியப்படுத்தல்கள், எண்ணிடப்பட்ட குறிப்பான்கள், உரை மற்றும் பாதுகாப்பான மறைப்புகளை வரைய முடியும்; படத்தின் ஒரு பகுதியைச் செதுக்கவோ வெட்டி எடுக்கவோ முடியும்; அதன் உரையை OCR செய்ய முடியும்; ஒரு பின்னணியைச் சேர்க்க முடியும். திருத்தியில், முடிந்த PNG ஐ நகலெடுத்துச் சேமிக்க `Enter` ஐயும், சேமிக்காமல் நகலெடுக்க `Ctrl + C` ஐயும், நகலெடுக்காமல் சேமிக்க `Ctrl + S` ஐயும் அழுத்துங்கள்.

சேமிக்கப்பட்ட திரைப்பிடிப்புகள் இயல்பாக `~/Pictures/Screenshots` இல் வந்து சேரும், `screenshot-2026-08-13_14-22-05-firefox.png` போன்ற பெயருடன். வேறொரு கோப்பகத்தைப் பயன்படுத்த `OMASNAP_SCREENSHOT_DIR` ஐ அமைக்கவும் — அமர்வுச் சூழல் மாறிகளை எங்கே வைப்பது என்பதற்கு [அடிக்கடி கேட்கப்படும் கேள்விகளைப்](46-faq.md) பார்க்கவும். முதல் படத்தைச் சேமிக்கும்போது Omasnap கோப்பகத்தை உருவாக்குகிறது. தானாகச் சேமிப்பதை முடக்க `~/.config/omasnap/omasnap.conf` இல் `[output] autosave = false` என அமைக்கவும்.

முனையத்திலிருந்து, `omarchy screenshot` அதே மேலடுக்கைத் திறக்கிறது, அதன் தொடக்கப் பயன்முறையை நீங்கள் தேர்வு செய்யலாம்: `omarchy capture screenshot region`, `windows`, `fullscreen`, அல்லது `scroll`. `copy` அல்லது `save` என்ற இரண்டாவது கொடுப்பு முன்னோட்டத்தைத் தவிர்த்து, படத்தை நேராக அந்த இடத்திற்கு அனுப்பும். வெளியீட்டிற்கு முன் திருத்த, முழுத்திரைத் திருத்திக்கு `omarchy screenshot --editor=overlay` ஐயும், தனிச் சாளரத்திற்கு `omarchy screenshot --editor=window` ஐயும் பயன்படுத்துங்கள்.

### விசைப்பலகையிலிருந்து தேர்வியை இயக்குதல்

தேர்வு தோன்றியிருக்கும்போது, நீங்கள் சுட்டியைப் பயன்படுத்தவே வேண்டியதில்லை:

| விசை | செயல்பாடு |
| --- | -------- |
| `S` | உருளும் பகுதிப் பயன்முறையை மாற்று |
| `Super + Arrow keys` | சாளரப் பயன்முறையில் சாளரங்களுக்கு இடையே நகர் |
| `Return` | முக்கியப்படுத்தப்பட்ட சாளரத்தைப் பிடி |
| `Ctrl + A` | கவனத்தில் உள்ள முழுத் திரையையும் பிடி |
| `R` | இந்த அமர்வில் கடைசியாக வரைந்த பகுதியை மீட்டமை |
| `Esc` | Omasnap ஐ நீக்கு |

இந்தப் பிணைப்புகள் Omasnap திறந்திருக்கும்போது மட்டுமே இருக்கும், எனவே அவை உங்கள் சொந்த உள்ளமைவில் உள்ள எதனுடனும் மோத முடியாது.

## திரைப் பதிவு

`Alt + Print Screen` _Trigger > Capture > Screenrecord_ ஐத் திறக்கிறது, அது ஒலிப்பதிவில் என்ன வேண்டும் என்று கேட்கிறது: ஒலி இல்லை, மேசைக்கணினி ஒலி, மேசைக்கணினி மற்றும் ஒலிவாங்கி, அல்லது மேசைக்கணினி மற்றும் ஒலிவாங்கி மற்றும் வெப்கேம். கடைசி ஒன்று, உண்மையிலேயே ஒரு படப்பிடிப்புக் கருவி இணைக்கப்பட்டிருந்தால் மட்டுமே தோன்றும். ஒன்றைத் தேர்ந்தெடுங்கள்; Omarchy இன் பதிவுத் தேர்வி ஒரு பகுதியை இழுக்கவோ ஒரு சாளரத்தை அல்லது திரையைச் சொடுக்கவோ உங்களை அனுமதிக்கிறது.

பதிவு gpu-screen-recorder இல் இயங்குகிறது, அது GPU இல் 60fps இல் குறியாக்கம் செய்கிறது, தேவைப்பட்டால் CPU க்குத் திரும்புகிறது. இதன் விளைவு `~/Videos` இல் ஒரு MP4, `screenrecording-2026-08-13_14-22-05.mp4` எனப் பெயரிடப்பட்டது. அதை மாற்ற `OMARCHY_SCREENRECORD_DIR` ஐ அமைக்கவும் — ஆனால் திரைப்பிடிப்புக் கோப்பகத்தைப் போலல்லாமல், இது ஏற்கனவே இருக்க வேண்டும், இல்லையெனில் பதிவு தொடங்க மறுக்கும் என்பதைக் கவனியுங்கள்.

நீங்கள் பதிவு செய்யும்போது, பட்டியில் ஒரு சிறு குறிப்பான் தோன்றுகிறது. நிறுத்த அதைச் சொடுக்குங்கள். மீண்டும் `Alt + Print Screen` ஐ அழுத்தியும் நிறுத்தலாம், அல்லது _Trigger > Capture > Screenrecord_ இன் கீழ் உள்ள _Stop Screenrecording_ உருப்படியாலும் நிறுத்தலாம், அது ஏதாவது உண்மையில் பதிவாகிக்கொண்டிருக்கும்போது மட்டுமே தோன்றும்.

நிறுத்துவது கோப்பை உங்களிடம் ஒப்படைக்கும் முன் கொஞ்சம் ஒழுங்குபடுத்துகிறது: முதல் சட்டகம் வெட்டி நீக்கப்படுகிறது, ஒலி இருந்தால் அது -14 LUFS க்கு இயல்பாக்கப்படுகிறது, மிகத் தொடக்கத்தில் உள்ள PipeWire பிடிப்பு வெடிப்பொலி மௌனமாக்கப்படுகிறது. பிறகு பதிவிலிருந்து ஒரு சிறுபடத்துடன் ஒரு அறிவிப்பு தோன்றுகிறது. கோப்பை mpv இல் இயக்க அதைச் சொடுக்குங்கள்.

### வெப்கேம் மேலடுக்கு

வெப்கேமுடன் பதிவு செய்யும்போது, நீங்கள் பதிவு செய்வதன் கீழ்-வலது மூலையில் படப்பிடிப்புக் கருவி பின் செய்யப்பட்ட, செதுக்கப்பட்ட உருவப்படச் சாளரமாகத் தோன்றுகிறது. அது உங்களுக்குத் தேவையான ஒன்றின் மேல் அமர்ந்திருந்தால், பறக்கும் போதே அதன் அளவை மாற்றுங்கள்:

| விசைச்சேர்க்கை | செயல்பாடு |
| ------ | -------- |
| `Super + Alt + [` | வெப்கேம் மேலடுக்கைச் சிறிதாக்கு |
| `Super + Alt + ]` | வெப்கேம் மேலடுக்கைப் பெரிதாக்கு |

சிறியது, நடுத்தரம், பெரியது என மூன்று அளவுகள் உள்ளன, விசைச்சேர்க்கைகள் அவற்றுக்கு இடையே படிப்படியாக நகர்கின்றன. நடுத்தரம் இயல்புநிலை. அவை பதிவிற்கு விகிதாசாரமானவை, எனவே நீங்கள் 1080p திரையைப் பதிவு செய்தாலும் 6K திரையைப் பதிவு செய்தாலும் படப்பிடிப்புக் கருவி சட்டகத்தில் அதே பங்கை எடுத்துக்கொள்கிறது. முழுக் காட்சிக்குப் பதிலாக ஒரு பகுதியைப் பதிவு செய்திருந்தால், மேலடுக்கு திரையின் மூலைக்குப் பதிலாக அந்தப் பகுதியின் மூலையில் நங்கூரமிடுகிறது, எனவே அது படத்திற்குள்ளேயே இருக்கிறது.

`omarchy-capture-webcam-resize small` என்றும் அதை நேரடியாக அழைக்கலாம், அல்லது நடுத்தரத்திற்குத் திரும்ப `reset` என்றும் அழைக்கலாம்.

## உரை, QR குறியீடுகள், மற்றும் நிறங்கள்

`Super + Ctrl + Print Screen` ஒரு பகுதியைத் தேர்ந்து அதை OCR செய்து கிளிப்போர்டுக்கு அனுப்புகிறது. அது [உரை பிரித்தெடுத்தல் & கட்டளையிட்டு எழுதுதலில்](11-text-extraction-dictation.md) முறையாக விளக்கப்பட்டுள்ளது.

_Trigger > Capture > QR Code_ QR குறியீடுகளுக்கும் அதே தந்திரத்தைச் செய்கிறது. குறியீடு உள்ள பகுதியைத் தேர்ந்தெடுங்கள், குறியீடு நீக்கப்பட்ட மதிப்பு கிளிப்போர்டுக்குச் செல்கிறது. அது QR குறியீடுகளை மட்டுமே தேடுகிறது — அடர்த்தியான திரை உள்ளடக்கம் இல்லையெனில் பார்கோடாகத் தவறாகக் கண்டறியப்படும் பழக்கம் கொண்டது. தெரிந்துகொள்ள வேண்டியது: குறியீடு நீக்கப்பட்ட மதிப்பு கிளிப்போர்டுக்கு மட்டுமே செல்கிறது, வேறு எங்கும் செல்வதில்லை. அது அச்சிடப்படுவதில்லை, அறிவிப்பில் இல்லை, உணர்திறன் மிக்கதாகக் குறிக்கப்படுவதால் [கிளிப்போர்டு வரலாற்றில்](08-unified-clipboard-history.md) ஒட்டிக்கொண்டிருப்பதில்லை. QR குறியீடுகள் வழக்கமாக இரகசியங்களைக் கொண்டிருக்கின்றன — எடுத்துக்காட்டாக, 2FA அமைப்புக் குறியீட்டின் பின்னால் உள்ள `otpauth://` URI — அது ஒரு பதிவில் இருப்பதை நீங்கள் விரும்பமாட்டீர்கள். ஒட்டுவது இன்னும் நன்றாக வேலை செய்கிறது.

`Super + Print Screen` (அல்லது _Trigger > Capture > Color_) கர்சரை ஒரு சொட்டுக் கருவியாக மாற்றுகிறது. திரையில் எதையாவது சொடுக்குங்கள், நிறம் கிளிப்போர்டில் வந்து சேரும். தேர்வு செய்யாமல் வெளியேற விசைச்சேர்க்கையை மீண்டும் அழுத்துங்கள்.

## பகிரும் முன் வடிவமாற்றம்

4K திரைப் பதிவோ உங்கள் தொலைபேசியிலிருந்து வந்த மூல HEIC ஒன்றோ பெரும்பாலும் அப்படியே அனுப்ப முடியாத அளவுக்குப் பெரிதாக இருக்கும். `Super + Ctrl + .` (அல்லது _Trigger > Transcode_) அதைச் சரிசெய்கிறது. அது `~/Pictures` மற்றும் `~/Videos` மீது ஒரு தெளிவற்ற தேடல் கொண்ட கோப்புத் தேர்வியை உங்களுக்கு வழங்குகிறது, பிறகு ஒரு வடிவத்தையும் ஒரு அளவையும் கேட்கிறது.

படங்கள் உயர், நடுத்தர, அல்லது குறைந்த தரத்தில் jpg அல்லது png க்குச் செல்கின்றன, அவை அகலத்தை 3160, 2160, மற்றும் 1080 பிக்சல்களாகக் கட்டுப்படுத்துகின்றன. காணொளிகள் 4k, 1080p, அல்லது 720p இல் mp4 அல்லது அசையும் gif க்குச் செல்கின்றன. மாற்றப்பட்ட கோப்பு, பெயரில் தெளிவுத்திறனுடன் மூலக் கோப்பிற்கு அருகிலேயே எழுதப்படுகிறது — `demo-1080p.mp4` — மற்றும் பாதை ஒரு கோப்பு URI ஆக கிளிப்போர்டுக்கு நகலெடுக்கப்படுகிறது, எனவே கோப்பு வீழ்த்தல்களை ஏற்கும் ஒரு செயலியில் அதை நேரடியாக ஒட்டலாம்.

உங்களுக்கு என்ன வேண்டும் என்று ஏற்கனவே தெரிந்தால், அது முனையத்திலிருந்தும் வேலை செய்கிறது: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. `omarchy transcode ascii` என்றும் ஒன்று உள்ளது, அது ஒரு படத்தை ASCII கலையாக மாற்றுகிறது — அது பெரும்பாலும் [பிராண்டிங்கிற்கானது](41-branding.md).

## அதை எங்காவது அனுப்புதல்

கோப்பு கிடைத்தவுடன், `Super + Ctrl + S` Share பட்டியலைத் திறந்து, அதை LocalSend வழியாக உங்கள் வலையமைப்பில் உள்ள மற்றொரு சாதனத்திற்கு அனுப்புகிறது. அதற்கு [GUIகளைப்](22-guis.md) பார்க்கவும்.
