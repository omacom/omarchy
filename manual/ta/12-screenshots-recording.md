# திரைக்காட்சிகள் & பதிவு செய்தல்

திரையில் இருந்து பிடிக்கக்கூடிய அனைத்தும் Print Screen விசையில் தொங்குகிறது. அந்த விசை மட்டும் தனியாக ஒரு படத்தை எடுக்கும், மாற்று விசைகள் சேர்ந்தால் ஒரு பதிவை, ஒரு நிறத்தை, அல்லது ஒரு பகுதிக்குள் இருக்கும் உரையை எடுக்கும். உங்கள் விசைப்பலகையில் Print Screen விசையே இல்லையென்றால், `Super + Ctrl + Alt + C` அதே திரைக்காட்சியை எடுக்கும், மேலும் `Super + Ctrl + C` முழுத் தொகுப்பையும் ஒரு பட்டியலாகத் திறக்கும்.

| விசைக் குறுக்குவழி | செயல்பாடு |
| ------ | -------- |
| `Print Screen` | திரைக்காட்சி |
| `Super + Ctrl + Alt + C` | திரைக்காட்சி |
| `Alt + Print Screen` | திரைப்பதிவு (அல்லது இயங்கிக் கொண்டிருப்பதை நிறுத்து) |
| `Super + Print Screen` | நிறம் தேர்ந்தெடுப்பான் |
| `Super + Ctrl + Print Screen` | ஒரு பகுதியில் இருந்து உரையைப் பிரித்தெடு |
| `Super + Ctrl + C` | பிடிப்புப் பட்டியல் |
| `Super + Ctrl + .` | ஒரு படம் அல்லது காணொளியை மாற்றியமை |

## திரைக்காட்சிகள்

`Print Screen` (அல்லது `Super + Ctrl + Alt + C`) ஐ அழுத்தினால், Omasnap அதன் மேலடுக்கு தோன்றுவதற்கு முன்பே கவனத்தில் உள்ள திரையைப் பிடிக்கிறது, எனவே நீங்கள் குறிவைக்கும்போது உங்களுக்குக் கீழே எதுவும் நகராது. கட்டற்ற வடிவிலான ஒரு பகுதியை இழுத்து வரையவும், ஒரு சாளரத்தைப் பிடிக்க அதைச் சொடுக்கவும், அல்லது முழுத் திரையையும் பிடிக்க திறந்த வெளியைச் சொடுக்கவும். வரைவதற்கு முன் `S` ஐ அழுத்தினால் உருளும் பகுதியைப் பிடிக்கலாம். மனம் மாறிவிட்டதா? அதே விசையை மீண்டும் அழுத்தி Omasnap ஐ மூடிவிடுங்கள்.

நீங்கள் ஒரு பகுதியைத் தேர்ந்தெடுத்த பிறகு, சேமிக்கப்பட்ட திரைப்பதிவு செய்வது போலவே, Omasnap அந்தப் பிடிப்பைச் சேமித்து, அதை கிளிப்போர்டுக்கு நகலெடுத்து, அதன் சிறுபடத்துடன் ஒரு அறிவிப்பைக் காட்டும். உங்கள் படப் பார்வையாளரில் சேமித்த படத்தைப் பார்க்க Open ஐத் தேர்ந்தெடுக்கவும், அல்லது அதில் குறிப்புகள் எழுத Edit ஐத் தேர்ந்தெடுக்கவும்.

குறிப்பு தொகுப்பானால் அம்புகள், கோடுகள், வடிவங்கள், சிறப்பம்சங்கள், எண்ணிடப்பட்ட குறிப்பான்கள், உரை, மற்றும் பாதுகாப்பான மறைப்புகளை வரைய முடியும்; படத்தின் ஒரு பகுதியைச் செதுக்கவோ வெட்டி எடுக்கவோ முடியும்; அதன் உரையை OCR செய்ய முடியும்; மேலும் ஒரு பின்னணியைச் சேர்க்க முடியும். தொகுப்பானில், முடிந்த PNG ஐ நகலெடுத்துச் சேமிக்க `Enter` ஐ அழுத்தவும், சேமிக்காமல் நகலெடுக்க `Ctrl + C` ஐ அழுத்தவும், அல்லது நகலெடுக்காமல் சேமிக்க `Ctrl + S` ஐ அழுத்தவும்.

சேமிக்கப்பட்ட திரைக்காட்சிகள் இயல்பாக `~/Pictures/Screenshots` இல் வந்து சேரும், `screenshot-2026-08-13_14-22-05-firefox.png` போன்ற பெயருடன். வேறு கோப்பகத்தைப் பயன்படுத்த `OMASNAP_SCREENSHOT_DIR` ஐ அமைக்கவும் — அமர்வு சூழல் மாறிகளை எங்கே வைப்பது என்பதற்கு [அடிக்கடி கேட்கப்படும் கேள்விகளைப்](46-faq.md) பார்க்கவும். Omasnap முதல் படத்தைச் சேமிக்கும்போது அந்தக் கோப்பகத்தை உருவாக்கும். தானாகச் சேமிப்பதை முடக்க `~/.config/omasnap/omasnap.conf` இல் `[output] autosave = false` என அமைக்கவும்; அப்போது பிடிப்புகள் நகலெடுக்கப்பட மட்டுமே செய்யும், மேலும் 7 வினாடிகளுக்கு ஒரு முன்னோட்டத்தில் காட்டப்படும், அதன் பின் பொத்தான் அல்லது `Ctrl + P` கொண்டு அதைத் திரையிலேயே வைத்திருக்கலாம்.

முனையத்தில் இருந்து, `omarchy screenshot` அதே மேலடுக்கைத் திறக்கும், மேலும் அதன் தொடக்கப் பயன்முறையை நீங்கள் தேர்ந்தெடுக்கலாம்: `omarchy capture screenshot region`, `windows`, `fullscreen`, அல்லது `scroll`. `copy` அல்லது `save` என்ற இரண்டாவது வாதம் படத்தை நேரடியாக அந்த இலக்குக்கு அனுப்பும். வெளியீட்டிற்கு முன் தொகுக்க, முழுத்திரை தொகுப்பானுக்கு `omarchy screenshot --editor=overlay` ஐயும், தனிச் சாளரத்திற்கு `omarchy screenshot --editor=window` ஐயும் பயன்படுத்தவும்.

### விசைப்பலகையில் இருந்தே தேர்வியை இயக்குதல்

தேர்வு திரையில் இருக்கும்போது, நீங்கள் சுட்டியைச் சிறிதும் பயன்படுத்த வேண்டியதில்லை:

| விசை | செயல்பாடு |
| --- | -------- |
| `S` | உருளும்-பகுதி பயன்முறையை மாற்று |
| `Super + Arrow keys` | Window பயன்முறையில் சாளரங்களுக்கு இடையே நகரவும் |
| `Return` | சிறப்பிக்கப்பட்ட சாளரத்தைப் பிடி |
| `Ctrl + A` | கவனத்தில் உள்ள முழுத் திரையையும் பிடி |
| `R` | இந்த அமர்வில் கடைசியாக வரைந்த பகுதியை மீட்டமை |
| `Esc` | Omasnap ஐ மூடு |

இந்த விசைப் பிணைப்புகள் Omasnap திறந்திருக்கும்போது மட்டுமே இருக்கும், எனவே அவை உங்கள் சொந்த உள்ளமைவில் உள்ள எதனுடனும் மோத முடியாது.

## திரைப் பதிவு

`Alt + Print Screen` _Trigger > Capture > Screenrecord_ ஐத் திறக்கும், அது ஒலித்தடத்தில் உங்களுக்கு என்ன வேண்டும் என்று கேட்கும்: ஒலி இல்லை, பணிமேசை ஒலி, பணிமேசை மற்றும் ஒலிவாங்கி, அல்லது பணிமேசை மற்றும் ஒலிவாங்கி மற்றும் வலைக்கேமரா. கடைசியானது, நீங்கள் உண்மையிலேயே ஒரு கேமராவை இணைத்திருந்தால் மட்டுமே தோன்றும். ஒன்றைத் தேர்ந்தெடுங்கள், Omarchy இன் பதிவுத் தேர்வி ஒரு பகுதியை இழுக்கவோ அல்லது ஒரு சாளரம் அல்லது திரையைச் சொடுக்கவோ உங்களை அனுமதிக்கும்.

பதிவு gpu-screen-recorder இல் இயங்குகிறது, அது GPU இல் 60fps இல் குறியாக்கம் செய்கிறது, தேவைப்பட்டால் CPU க்குத் திரும்பி விடுகிறது; அது ஆதரிக்காத GPU களில், Apple Silicon இன் GPU கள் போன்றவற்றில், Omarchy அதற்குப் பதிலாக wf-recorder கொண்டு பதிவு செய்கிறது. இதன் விளைவு `~/Videos` இல் உள்ள ஒரு MP4, `screenrecording-2026-08-13_14-22-05.mp4` எனப் பெயரிடப்பட்டது. அதை மாற்ற `OMARCHY_SCREENRECORD_DIR` ஐ அமைக்கவும் — ஆனால் திரைக்காட்சிக் கோப்பகத்தைப் போலன்றி, இது ஏற்கனவே இருக்க வேண்டும் என்பதைக் கவனத்தில் கொள்ளுங்கள், இல்லையென்றால் பதிவு தொடங்க மறுக்கும்.

நீங்கள் பதிவு செய்து கொண்டிருக்கும்போது, பட்டியில் ஒரு சிறிய காட்டி தோன்றும். நிறுத்த அதைச் சொடுக்கவும். நீங்கள் `Alt + Print Screen` ஐ மீண்டும் அழுத்தியும் நிறுத்தலாம், அல்லது _Trigger > Capture > Screenrecord_ இன் கீழ் உள்ள _Stop Screenrecording_ உள்ளீட்டைக் கொண்டும் நிறுத்தலாம், அது உண்மையில் ஏதாவது பதிவாகிக் கொண்டிருக்கும்போது மட்டுமே தோன்றும்.

நிறுத்துவது கோப்பை உங்களிடம் ஒப்படைப்பதற்கு முன் சிறிது சுத்திகரிப்பு செய்கிறது: முதல் சட்டகம் வெட்டி நீக்கப்படுகிறது, ஒலி இருந்தால் அது -14 LUFS க்கு இயல்பாக்கப்படுகிறது, மிகத் தொடக்கத்தில் உள்ள PipeWire பிடிப்பு ஒலி மறைக்கப்படுகிறது. பிறகு பதிவில் இருந்து ஒரு சிறுபடத்துடன் ஒரு அறிவிப்பு தோன்றும். Omaview இல் கோப்பை இயக்க _Open_ ஐத் தேர்ந்தெடுக்கவும், அல்லது Omacut இல் அதை வெட்ட _Cut_ ஐத் தேர்ந்தெடுக்கவும்.

### வலைக்கேமரா மேலடுக்கு

நீங்கள் வலைக்கேமராவுடன் பதிவு செய்யும்போது, நீங்கள் பதிவு செய்வதன் கீழ்-வலது மூலையில் கேமரா பொருத்தப்பட்ட, செதுக்கப்பட்ட ஒரு நிமிர்ந்த சாளரமாகத் தோன்றும். அது உங்களுக்குத் தேவையான ஒன்றின் மேல் அமர்ந்திருந்தால், உடனடியாக அதன் அளவை மாற்றவும்:

| விசைக் குறுக்குவழி | செயல்பாடு |
| ------ | -------- |
| `Super + Alt + [` | வலைக்கேமரா மேலடுக்கைச் சிறிதாக்கு |
| `Super + Alt + ]` | வலைக்கேமரா மேலடுக்கைப் பெரிதாக்கு |

மூன்று அளவுகள் உள்ளன — சிறியது, நடுத்தரம், மற்றும் பெரியது — மேலும் விசைக் குறுக்குவழிகள் அவற்றுக்கு இடையே படிப்படியாக நகரும். நடுத்தரம் இயல்புநிலை. அவை பதிவுக்கு விகிதாசாரமானவை, எனவே நீங்கள் 1080p திரையைப் பதிவு செய்தாலும் அல்லது 6K திரையைப் பதிவு செய்தாலும் கேமரா சட்டகத்தில் அதே பங்கை எடுத்துக் கொள்ளும். மேலும் நீங்கள் முழுக் காட்சியையும் அல்லாமல் ஒரு பகுதியைப் பதிவு செய்திருந்தால், மேலடுக்கு திரையின் மூலைக்குப் பதிலாக அந்தப் பகுதியின் மூலையில் நங்கூரமிடும், எனவே அது படத்திற்குள்ளேயே இருக்கும்.

நீங்கள் அதை `omarchy-capture-webcam-resize small` கொண்டு நேரடியாகவும் அழைக்கலாம், அல்லது நடுத்தரத்திற்குத் திரும்ப `reset` கொண்டும் அழைக்கலாம்.

## உரை, QR குறியீடுகள், மற்றும் நிறங்கள்

`Super + Ctrl + Print Screen` ஒரு பகுதியைத் தேர்ந்தெடுத்து அதை கிளிப்போர்டுக்கு OCR செய்கிறது. அது [உரைப் பிரித்தெடுத்தல் & சொல்லக் கேட்டு எழுதுதலில்](11-text-extraction-dictation.md) முறையாக விவரிக்கப்பட்டுள்ளது.

_Trigger > Capture > QR Code_ QR குறியீடுகளுக்கும் அதே தந்திரத்தைச் செய்கிறது. குறியீடு உள்ள பகுதியைத் தேர்ந்தெடுக்கவும், குறியீடு நீக்கப்பட்ட மதிப்பு கிளிப்போர்டுக்குச் செல்லும். அது QR குறியீடுகளை மட்டுமே தேடுகிறது — இல்லையென்றால் அடர்த்தியான திரை உள்ளடக்கம் பார்கோடு எனத் தவறாகக் கண்டறியப்படும் பழக்கம் இருக்கிறது. தெரிந்து கொள்ள வேண்டியது: குறியீடு நீக்கப்பட்ட மதிப்பு கிளிப்போர்டுக்கு மட்டுமே செல்கிறது, வேறு எங்கும் செல்லாது. அது அச்சிடப்படுவதில்லை, அது அறிவிப்பில் இல்லை, மேலும் அது [கிளிப்போர்டு வரலாற்றில்](08-unified-clipboard-history.md) தங்காதபடி உணர்திறன் கொண்டதாகக் குறிக்கப்படுகிறது. QR குறியீடுகள் வழக்கமாக இரகசியங்களைக் கொண்டு செல்கின்றன — உதாரணமாக, 2FA அமைப்புக் குறியீட்டின் பின்னால் உள்ள `otpauth://` URI — மேலும் அது ஒரு பதிவில் இருப்பதை நீங்கள் விரும்ப மாட்டீர்கள். ஒட்டுவது இன்னும் நன்றாக வேலை செய்கிறது.

`Super + Print Screen` (அல்லது _Trigger > Capture > Color_) குறிப்பானை ஒரு நிறம் உறிஞ்சியாக மாற்றுகிறது. திரையில் எதையும் சொடுக்கவும், அந்த நிறம் கிளிப்போர்டில் வந்து சேரும். தேர்ந்தெடுக்காமல் பின்வாங்க அந்த விசைக் குறுக்குவழியை மீண்டும் அழுத்தவும்.

## பகிர்வதற்கு முன் மாற்றியமைத்தல்

4K திரைப் பதிவு அல்லது உங்கள் தொலைபேசியில் இருந்து வந்த மூல HEIC பெரும்பாலும் அப்படியே அனுப்ப முடியாத அளவுக்குப் பெரியதாக இருக்கும். `Super + Ctrl + .` (அல்லது _Trigger > Transcode_) அதைச் சரிசெய்கிறது. அது `~/Pictures` மற்றும் `~/Videos` மீது ஒரு தெளிவற்ற கோப்புத் தேர்வியை உங்களுக்கு வழங்குகிறது, பிறகு ஒரு வடிவத்தையும் ஒரு அளவையும் கேட்கிறது.

படங்கள் jpg அல்லது png க்கு, உயர், நடுத்தர, அல்லது குறைவு எனச் செல்கின்றன, அவை அகலத்தை 3160, 2160, மற்றும் 1080 பிக்சல்களில் கட்டுப்படுத்துகின்றன. காணொளிகள் mp4 அல்லது அசைவூட்டப்பட்ட gif க்கு, 4k, 1080p, அல்லது 720p இல் செல்கின்றன. மாற்றப்பட்ட கோப்பு பெயரில் தெளிவுத்திறனுடன் மூலக் கோப்புக்கு அருகிலேயே எழுதப்படுகிறது — `demo-1080p.mp4` — மேலும் அந்தப் பாதை கிளிப்போர்டுக்கு ஒரு கோப்பு URI ஆக நகலெடுக்கப்படுகிறது, எனவே கோப்பு வீழ்ச்சிகளை ஏற்கும் ஒரு பயன்பாட்டில் அதை நேரடியாக ஒட்டலாம்.

உங்களுக்கு என்ன வேண்டும் என்பது ஏற்கனவே தெரிந்தால், அது முனையத்தில் இருந்தும் வேலை செய்கிறது: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. `omarchy transcode ascii` என்பதும் உள்ளது, அது ஒரு படத்தை ASCII கலையாக மாற்றுகிறது — அது பெரும்பாலும் [பிராண்டிங்கிற்காகத்தான்](41-branding.md).

## அதை எங்காவது அனுப்புதல்

உங்களிடம் கோப்பு கிடைத்ததும், `Super + Ctrl + S` Share பட்டியலைத் திறந்து, அதை LocalSend வழியாக உங்கள் வலையமைப்பில் உள்ள மற்றொரு சாதனத்திற்கு அனுப்புகிறது. அதற்கு [GUIகளைப்](22-guis.md) பார்க்கவும்.
