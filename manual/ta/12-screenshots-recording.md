# திரைப்பிடிப்புகள் & பதிவு

திரையிலிருந்து நீங்கள் பிடிக்கக்கூடிய அனைத்தும் Print Screen விசையிலிருந்து தொங்குகிறது. ஒரு விசை தனியாக ஒரு படத்தை எடுக்கிறது, மேலும் மாற்றிகள் ஒரு பதிவு, ஒரு நிறம், அல்லது ஒரு பகுதிக்குள் உள்ள உரையை எடுக்கின்றன. உங்கள் விசைப்பலகையில் Print Screen விசையே இல்லை என்றால், `Super + Ctrl + C` அதே தொகுப்பை ஒரு மெனுவாகத் திறக்கிறது.

| ஹாட்கீ | செயல்பாடு |
| ------ | -------- |
| `Print Screen` | திரைப்பிடிப்பு |
| `Alt + Print Screen` | திரைப்பதிவு (அல்லது இயங்கிக் கொண்டிருப்பதை நிறுத்து) |
| `Super + Print Screen` | நிறம் தேர்வாளர் |
| `Super + Ctrl + Print Screen` | ஒரு பகுதியிலிருந்து உரையைப் பிரித்தெடு |
| `Super + Ctrl + C` | பதிவு மெனு |
| `Super + Ctrl + .` | ஒரு படம் அல்லது வீடியோவை மாற்றுக்குறியீடு செய் |

## திரைப்பிடிப்புகள்

`Print Screen` ஐ அழுத்தவும், Omasnap அதன் மேலடுக்கு தோன்றுவதற்கு முன் கவனம் செலுத்தப்பட்ட திரையைப் பிடிக்கிறது, எனவே நீங்கள் குறிவைக்கும் போது உங்களுக்குக் கீழ் எதுவும் மாறாது. ஒரு சுதந்திரப் பகுதியை இழுக்கவும், அதைப் பிடிக்க ஒரு சாளரத்தைக் கிளிக் செய்யவும், அல்லது முழு திரையையும் பிடிக்க திறந்த இடத்தைக் கிளிக் செய்யவும். ஒரு உருட்டல் பகுதியைப் பிடிக்க வரைவதற்கு முன் `S` ஐ அழுத்தவும். உங்கள் மனதை மாற்றிவிட்டீர்களா? Omasnap-ஐ நிராகரிக்க `Print Screen` ஐ மீண்டும் அழுத்தவும்.

நீங்கள் ஒரு பகுதியைத் தேர்ந்தெடுத்த பிறகு, Omasnap பிடிப்பைச் சேமிக்கிறது, அதை கிளிப்போர்டுக்கு நகலெடுக்கிறது, மற்றும் 10 வினாடிகளுக்கு ஒரு முன்னோட்டத்தைக் காட்டுகிறது. அதைத் திரையில் வைத்திருக்க முன்னோட்டத்தின் பின் பொத்தானை அல்லது `Ctrl + P` ஐப் பயன்படுத்தவும், அல்லது அதைக் குறிக்க திருத்து என்பதைத் தேர்ந்தெடுக்கவும்.

குறிப்பு எடிட்டர் அம்புகள், கோடுகள், வடிவங்கள், சிறப்பம்சங்கள், எண்ணிடப்பட்ட குறிப்பான்கள், உரை, மற்றும் பாதுகாப்பான திருத்தங்களை வரைய முடியும்; படத்தின் ஒரு பகுதியை வெட்ட அல்லது வெட்டி எடுக்க முடியும்; அதன் உரையை OCR செய்ய முடியும்; மற்றும் ஒரு பின்னணியைச் சேர்க்க முடியும். எடிட்டரில், முடிக்கப்பட்ட PNG-ஐ நகலெடுத்துச் சேமிக்க `Enter` ஐ அழுத்தவும், சேமிக்காமல் அதை நகலெடுக்க `Ctrl + C` ஐ அழுத்தவும், அல்லது நகலெடுக்காமல் அதைச் சேமிக்க `Ctrl + S` ஐ அழுத்தவும்.

சேமிக்கப்பட்ட திரைப்பிடிப்புகள் இயல்பாகவே `~/Pictures/Screenshots` இல் தரையிறங்குகின்றன, `screenshot-2026-08-13_14-22-05-firefox.png` போன்ற பெயருடன். மற்றொரு கோப்பகத்தைப் பயன்படுத்த `OMASNAP_SCREENSHOT_DIR` ஐ அமைக்கவும் — அமர்வு சூழல் மாறிகளை எங்கே வைப்பது என்பதற்கு [அடிக்கடி கேட்கப்படும் கேள்விகள்](46-faq.md) பார்க்கவும். Omasnap முதல் ஷாட்டைச் சேமிக்கும் போது கோப்பகத்தை உருவாக்குகிறது. தானியங்கு சேமிப்பை முடக்க `~/.config/omasnap/omasnap.conf` இல் `[output] autosave = false` ஐ அமைக்கவும்.

டெர்மினலிலிருந்து, `omarchy screenshot` அதே மேலடுக்கைத் திறக்கிறது, மேலும் அதன் தொடக்க பயன்முறையைத் தேர்ந்தெடுக்கலாம்: `omarchy capture screenshot region`, `windows`, `fullscreen`, அல்லது `scroll`. `copy` அல்லது `save` என்ற இரண்டாவது வாதம் முன்னோட்டத்தைத் தவிர்த்து ஷாட்டை நேரடியாக அந்த இலக்கிற்கு அனுப்புகிறது. வெளியீட்டிற்கு முன் திருத்த, ஒரு முழுத்திரை எடிட்டருக்கு `omarchy screenshot --editor=overlay` அல்லது ஒரு தனி சாளரத்திற்கு `omarchy screenshot --editor=window` ஐப் பயன்படுத்தவும்.

### விசைப்பலகையிலிருந்து தேர்வாளரை இயக்குதல்

தேர்வு இருக்கும் போது, ​​நீங்கள் சுட்டியைப் பயன்படுத்தவே வேண்டியதில்லை:

| விசை | செயல்பாடு |
| --- | -------- |
| `S` | உருட்டல்-பகுதி பயன்முறையை மாற்று |
| `Super + Arrow keys` | சாளர பயன்முறையில் சாளரங்களுக்கு இடையே நகரவும் |
| `Return` | தனிப்படுத்தப்பட்ட சாளரத்தைப் பிடி |
| `Ctrl + A` | முழு கவனம் செலுத்தப்பட்ட திரையைப் பிடி |
| `R` | இந்த அமர்வில் வரையப்பட்ட கடைசி பகுதியை மீட்டமை |
| `Esc` | Omasnap-ஐ நிராகரி |

இந்த பிணைப்புகள் Omasnap திறந்திருக்கும் போது மட்டுமே உள்ளன, எனவே அவை உங்கள் சொந்த கட்டமைப்பில் எதனுடனும் மோத முடியாது.

## திரைப்பதிவு

`Alt + Print Screen` _தூண்டு > பதிவு செய் > திரைப்பதிவு_ ஐத் திறக்கிறது, இது சவுண்ட்டிராக்கில் நீங்கள் விரும்புவதைக் கேட்கிறது: ஒலி இல்லை, டெஸ்க்டாப் ஒலி, டெஸ்க்டாப் மற்றும் மைக்ரோஃபோன், அல்லது டெஸ்க்டாப் மற்றும் மைக்ரோஃபோன் மற்றும் வெப்கேம். கடைசியானது நீங்கள் உண்மையில் ஒரு கேமரா சொருகப்பட்டிருந்தால் மட்டுமே தோன்றும். ஒன்றைத் தேர்ந்தெடுக்கவும், Omarchy-இன் பதிவு தேர்வாளர் ஒரு பகுதியை இழுக்க அல்லது ஒரு சாளரம் அல்லது திரையைக் கிளிக் செய்ய உங்களை அனுமதிக்கிறது.

பதிவு gpu-screen-recorder-இல் இயங்குகிறது, இது GPU-இல் 60fps-இல் குறியாக்குகிறது மற்றும் தேவைப்பட்டால் CPU-க்குத் திரும்புகிறது. விளைவு `~/Videos` இல் ஒரு MP4, `screenrecording-2026-08-13_14-22-05.mp4` எனப் பெயரிடப்பட்டது. அதை மாற்ற `OMARCHY_SCREENRECORD_DIR` ஐ அமைக்கவும் — ஆனால் திரைப்பிடிப்பு கோப்பகத்தைப் போலல்லாமல், இது ஏற்கனவே இருக்க வேண்டும் என்பதைக் கவனியுங்கள், அல்லது பதிவு தொடங்க மறுக்கும்.

நீங்கள் பதிவு செய்யும் போது, ​​பட்டையில் ஒரு சிறிய குறிகாட்டி தோன்றும். நிறுத்த அதைக் கிளிக் செய்யவும். `Alt + Print Screen` மூலம் மீண்டும் நிறுத்தலாம், அல்லது _தூண்டு > பதிவு செய் > திரைப்பதிவு_ இன் கீழ் உள்ள _திரைப்பதிவை நிறுத்து_ பதிவு மூலம் நிறுத்தலாம், இது உண்மையில் ஏதாவது பதிவு செய்யும் போது மட்டுமே தோன்றும்.

நிறுத்துவது கோப்பை உங்களிடம் ஒப்படைப்பதற்கு முன் சிறிது சுத்தம் செய்கிறது: முதல் பிரேம் வெட்டப்படுகிறது, மேலும் ஒலி இருந்தால் அது -14 LUFS-க்கு இயல்பாக்கப்படுகிறது, தொடக்கத்திலேயே PipeWire பிடிப்பு பாப் மியூட் செய்யப்படுகிறது. பிறகு பதிவிலிருந்து ஒரு சிறுபடத்துடன் ஒரு அறிவிப்பு தோன்றும். mpv-இல் கோப்பை இயக்க அதைக் கிளிக் செய்யவும்.

### வெப்கேம் மேலடுக்கு

நீங்கள் ஒரு வெப்கேம் மூலம் பதிவு செய்யும் போது, ​​கேமரா நீங்கள் பதிவு செய்வதன் கீழ்-வலது மூலையில் ஒரு பொருத்தப்பட்ட, வெட்டப்பட்ட உருவப்பட சாளரமாகத் தோன்றும். அது உங்களுக்குத் தேவையான ஒன்றின் மேல் அமர்ந்திருந்தால், பறந்து கொண்டே அதை மறுஅளவிடவும்:

| ஹாட்கீ | செயல்பாடு |
| ------ | -------- |
| `Super + Alt + [` | வெப்கேம் மேலடுக்கை சிறியதாக்கு |
| `Super + Alt + ]` | வெப்கேம் மேலடுக்கை பெரியதாக்கு |

மூன்று அளவுகள் உள்ளன — சிறியது, நடுத்தரம், மற்றும் பெரியது — மேலும் ஹாட்கீகள் அவற்றுக்கு இடையே படிப்படியாகச் செல்கின்றன. நடுத்தரம் இயல்புநிலை. அவை பதிவுக்கு விகிதாசாரமாக உள்ளன, எனவே நீங்கள் 1080p திரையைப் பதிவு செய்கிறீர்களா அல்லது 6K திரையைப் பதிவு செய்கிறீர்களா என்பதைப் பொருட்படுத்தாமல் கேமரா பிரேமின் அதே பங்கை எடுக்கிறது. மேலும் நீங்கள் ஒரு முழு காட்சிக்கு பதிலாக ஒரு பகுதியைப் பதிவு செய்திருந்தால், மேலடுக்கு திரையின் மூலைக்கு பதிலாக அந்தப் பகுதியின் மூலையில் நங்கூரமிடுகிறது, எனவே அது ஷாட்டுக்குள் இருக்கும்.

`omarchy-capture-webcam-resize small` மூலம் அதை நேரடியாகவும் அழைக்கலாம், அல்லது நடுத்தரத்திற்குத் திரும்ப `reset` மூலம் அழைக்கலாம்.

## உரை, QR குறியீடுகள், மற்றும் நிறங்கள்

`Super + Ctrl + Print Screen` ஒரு பகுதியைத் தேர்ந்தெடுத்து அதை கிளிப்போர்டுக்கு OCR செய்கிறது. அது [உரை பிரித்தெடுத்தல் & கட்டளையிடல்](11-text-extraction-dictation.md) இல் சரியாக விவரிக்கப்பட்டுள்ளது.

_தூண்டு > பதிவு செய் > QR குறியீடு_ QR குறியீடுகளுக்கு அதே தந்திரத்தைச் செய்கிறது. குறியீடு உள்ள பகுதியைத் தேர்ந்தெடுக்கவும், மறைகுறியாக்கம் நீக்கப்பட்ட மதிப்பு கிளிப்போர்டுக்குச் செல்கிறது. இது QR குறியீடுகளை மட்டுமே தேடுகிறது — அடர்த்தியான திரை உள்ளடக்கம் இல்லையெனில் ஒரு பார்கோடாக தவறாக-நேர்மறையாகும் பழக்கத்தைக் கொண்டுள்ளது. அறிந்து கொள்ளத் தகுந்தது: மறைகுறியாக்கம் நீக்கப்பட்ட மதிப்பு கிளிப்போர்டுக்குச் செல்கிறது, வேறு எங்கும் இல்லை. அது அச்சிடப்படவில்லை, அது அறிவிப்பில் இல்லை, மேலும் அது உணர்திறன் மிக்கதாகக் குறிக்கப்பட்டுள்ளது, எனவே அது [கிளிப்போர்டு வரலாற்றில்](08-unified-clipboard-history.md) தொடர்ந்து இருக்காது. QR குறியீடுகள் வழக்கமாக ரகசியங்களைக் கொண்டு செல்கின்றன — ஒரு 2FA அமைப்பு குறியீட்டின் பின்னால் உள்ள `otpauth://` URI, எடுத்துக்காட்டாக — மேலும் அதை ஒரு பதிவில் நீங்கள் விரும்பவில்லை. ஒட்டுதல் இன்னும் நன்றாக வேலை செய்கிறது.

`Super + Print Screen` (அல்லது _தூண்டு > பதிவு செய் > நிறம்_) கர்சரை ஒரு கண்சொட்டியாக மாற்றுகிறது. திரையில் எதையும் கிளிக் செய்யவும், நிறம் கிளிப்போர்டில் தரையிறங்குகிறது. தேர்ந்தெடுக்காமல் பின்வாங்க ஹாட்கீயை மீண்டும் அழுத்தவும்.

## பகிர்வதற்கு முன் மாற்றுக்குறியீடு செய்தல்

ஒரு 4K திரைப்பதிவு அல்லது உங்கள் தொலைபேசியிலிருந்து ஒரு மூல HEIC பெரும்பாலும் அனுப்ப மிகப் பெரியதாக இருக்கும். `Super + Ctrl + .` (அல்லது _தூண்டு > மாற்றுக்குறியீடு_) அதைச் சரிசெய்கிறது. இது `~/Pictures` மற்றும் `~/Videos` மீது ஒரு தெளிவற்ற கோப்பு தேர்வாளரை உங்களுக்கு வழங்குகிறது, பிறகு ஒரு வடிவம் மற்றும் ஒரு அளவைக் கேட்கிறது.

படங்கள் உயர், நடுத்தர, அல்லது குறைந்த அளவில் jpg அல்லது png க்குச் செல்கின்றன, இது அகலத்தை 3160, 2160, மற்றும் 1080 பிக்சல்களாகக் கட்டுப்படுத்துகிறது. வீடியோக்கள் 4k, 1080p, அல்லது 720p இல் mp4 அல்லது ஒரு அனிமேஷன் gif க்குச் செல்கின்றன. மாற்றப்பட்ட கோப்பு அசலுக்கு அடுத்ததாக பெயரில் தெளிவுத்திறனுடன் எழுதப்படுகிறது — `demo-1080p.mp4` — மேலும் பாதை ஒரு கோப்பு URI ஆக கிளிப்போர்டுக்கு நகலெடுக்கப்படுகிறது, எனவே கோப்பு வீழ்ச்சிகளை எடுக்கும் ஒரு செயலியில் அதை நேரடியாக ஒட்டலாம்.

நீங்கள் விரும்புவது ஏற்கனவே தெரிந்தால், இது டெர்மினலிலிருந்தும் கூட வேலை செய்கிறது: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. `omarchy transcode ascii` உம் உள்ளது, இது ஒரு படத்தை ASCII கலையாக மாற்றுகிறது — அது பெரும்பாலும் [பிராண்டிங்](41-branding.md) க்காக.

## அதை எங்காவது அனுப்புதல்

கோப்பு கிடைத்ததும், `Super + Ctrl + S` பகிர் மெனுவைத் திறந்து LocalSend வழியாக உங்கள் வலையமைப்பில் உள்ள மற்றொரு சாதனத்திற்கு அனுப்புகிறது. அதற்கு [GUIs](22-guis.md) பார்க்கவும்.
