# திரைப்பிடிப்புகள் & பதிவு செய்தல்

திரையில் இருந்து நீங்கள் பிடிக்கக்கூடிய அனைத்தும் Print Screen விசையிலிருந்தே தொடங்குகிறது. அந்த விசை மட்டும் ஒரு படத்தை எடுக்கும், மாற்று விசைகள் ஒரு பதிவை, ஒரு வண்ணத்தை, அல்லது ஒரு பகுதிக்குள் உள்ள உரையை எடுக்கும். உங்கள் விசைப்பலகையில் Print Screen விசையே இல்லையென்றால், `Super + Ctrl + Alt + C` அதே திரைப்பிடிப்பை எடுக்கும், `Super + Ctrl + C` முழுத் தொகுப்பையும் ஒரு மெனுவாகத் திறக்கும்.

| குறுக்குவிசை | செயல்பாடு |
| ------ | -------- |
| `Print Screen` | திரைப்பிடிப்பு |
| `Super + Ctrl + Alt + C` | திரைப்பிடிப்பு |
| `Alt + Print Screen` | திரைப்பதிவு (அல்லது இயங்கிக் கொண்டிருப்பதை நிறுத்து) |
| `Super + Print Screen` | வண்ணத் தேர்வி |
| `Super + Ctrl + Print Screen` | ஒரு பகுதியிலிருந்து உரையைப் பிரித்தெடு |
| `Super + Ctrl + C` | பிடிப்பு மெனு |
| `Super + Ctrl + .` | ஒரு படத்தையோ வீடியோவையோ வடிவமாற்றம் செய் |

## திரைப்பிடிப்புகள்

`Print Screen` (அல்லது `Super + Ctrl + Alt + C`) ஐ அழுத்தினால், Omasnap அதன் மேலடுக்கு தோன்றுவதற்கு முன்பே கவனத்தில் உள்ள மானிட்டரைப் பிடிக்கும், எனவே நீங்கள் குறிவைக்கும்போது உங்களுக்குக் கீழே எதுவும் மாறாது. சுதந்திர வடிவப் பகுதியை இழுத்து வரையுங்கள், ஒரு சாளரத்தைப் பிடிக்க அதைக் கிளிக் செய்யுங்கள், அல்லது முழு மானிட்டரையும் பிடிக்க வெற்று இடத்தைக் கிளிக் செய்யுங்கள். உருளும் பகுதியைப் பிடிக்க, வரைவதற்கு முன் `S` ஐ அழுத்துங்கள். மனம் மாறிவிட்டதா? Omasnap ஐ மூட அதே விசையை மீண்டும் அழுத்துங்கள்.

நீங்கள் ஒரு பகுதியைத் தேர்ந்த பிறகு, Omasnap அந்தப் பிடிப்பைச் சேமித்து, கிளிப்போர்டுக்கு நகலெடுத்து, சேமிக்கப்பட்ட திரைப்பதிவு செய்வது போலவே அதன் சிறுபடத்துடன் ஒரு அறிவிப்பைக் காட்டும். சேமிக்கப்பட்ட படத்தை உங்கள் படக் காட்சியில் பார்க்க Open ஐத் தேர்ந்தெடுங்கள், அல்லது அதில் குறிப்புகள் சேர்க்க Edit ஐத் தேர்ந்தெடுங்கள்.

குறிப்புகள் சேர்க்கும் திருத்தி அம்புகள், கோடுகள், வடிவங்கள், சிறப்பம்சங்கள், எண்ணிடப்பட்ட குறிப்பான்கள், உரை மற்றும் பாதுகாப்பான மறைப்புகளை வரைய முடியும்; படத்தின் ஒரு பகுதியை வெட்டவோ வெட்டி எடுக்கவோ முடியும்; அதன் உரையை OCR செய்ய முடியும்; ஒரு பின்னணியையும் சேர்க்க முடியும். திருத்தியில், முடிந்த PNG ஐ நகலெடுத்துச் சேமிக்க `Enter` ஐ அழுத்துங்கள், சேமிக்காமல் நகலெடுக்க `Ctrl + C` ஐ அழுத்துங்கள், அல்லது நகலெடுக்காமல் சேமிக்க `Ctrl + S` ஐ அழுத்துங்கள்.

சேமிக்கப்பட்ட திரைப்பிடிப்புகள் இயல்பாக `~/Pictures/Screenshots` இல் வந்து சேரும், `screenshot-2026-08-13_14-22-05-firefox.png` போன்ற பெயருடன். வேறொரு கோப்பகத்தைப் பயன்படுத்த `OMASNAP_SCREENSHOT_DIR` ஐ அமையுங்கள் — அமர்வு சூழல் மாறிகளை எங்கே வைப்பது என்பதற்கு [அடிக்கடி கேட்கப்படும் கேள்விகளைப்](46-faq.md) பாருங்கள். முதல் படத்தைச் சேமிக்கும்போது Omasnap அந்தக் கோப்பகத்தை உருவாக்கும். தானாகச் சேமிப்பதை முடக்க `~/.config/omasnap/omasnap.conf` இல் `[output] autosave = false` என அமையுங்கள்; அப்போது பிடிப்புகள் நகலெடுக்கப்படுவது மட்டுமே செய்யப்பட்டு, 10 வினாடிகளுக்கு ஒரு முன்னோட்டத்தில் காட்டப்படும், அதை அதன் பின் பொத்தானாலோ `Ctrl + P` ஆலோ திரையிலேயே வைத்திருக்கலாம்.

முனையத்திலிருந்து, `omarchy screenshot` அதே மேலடுக்கைத் திறக்கும், அதன் தொடக்க நிலையையும் நீங்கள் தேர்ந்தெடுக்கலாம்: `omarchy capture screenshot region`, `windows`, `fullscreen`, அல்லது `scroll`. `copy` அல்லது `save` என்ற இரண்டாவது வாதம் படத்தை நேரடியாக அந்த இலக்குக்கு அனுப்பும். வெளியீட்டுக்கு முன் திருத்த, முழுத்திரை திருத்திக்கு `omarchy screenshot --editor=overlay` ஐயோ தனிச் சாளரத்துக்கு `omarchy screenshot --editor=window` ஐயோ பயன்படுத்துங்கள்.

### தேர்வியை விசைப்பலகையிலிருந்து இயக்குதல்

தேர்வு திரையில் இருக்கும்போது, நீங்கள் சுட்டியைப் பயன்படுத்தவே வேண்டியதில்லை:

| விசை | செயல்பாடு |
| --- | -------- |
| `S` | உருளும் பகுதி நிலையை மாற்று |
| `Super + Arrow keys` | Window நிலையில் சாளரங்களுக்கு இடையே நகரு |
| `Return` | சிறப்பிக்கப்பட்ட சாளரத்தைப் பிடி |
| `Ctrl + A` | கவனத்தில் உள்ள முழு மானிட்டரையும் பிடி |
| `R` | இந்த அமர்வில் கடைசியாக வரையப்பட்ட பகுதியை மீட்டமை |
| `Esc` | Omasnap ஐ மூடு |

இந்த விசைப்பிணைப்புகள் Omasnap திறந்திருக்கும்போது மட்டுமே இருக்கும், எனவே அவை உங்கள் சொந்த உள்ளமைவில் உள்ள எதனுடனும் மோத முடியாது.

## திரைப்பதிவு

`Alt + Print Screen` _Trigger > Capture > Screenrecord_ ஐத் திறக்கும், அது ஒலிப்பதிவில் என்ன வேண்டும் என்று கேட்கும்: ஒலி இல்லை, டெஸ்க்டாப் ஒலி, டெஸ்க்டாப் மற்றும் மைக்ரோஃபோன், அல்லது டெஸ்க்டாப் மற்றும் மைக்ரோஃபோன் மற்றும் வெப்கேம். அந்தக் கடைசி விருப்பம் உங்களிடம் உண்மையில் ஒரு கேமரா இணைக்கப்பட்டிருந்தால் மட்டுமே தோன்றும். ஒன்றைத் தேர்ந்தெடுங்கள், Omarchy இன் பதிவுத் தேர்வி ஒரு பகுதியை இழுக்கவோ ஒரு சாளரத்தையோ மானிட்டரையோ கிளிக் செய்யவோ உங்களை அனுமதிக்கும்.

பதிவு gpu-screen-recorder இல் இயங்குகிறது, இது GPU இல் 60fps இல் குறியாக்கம் செய்கிறது, அவசியமானால் CPU க்குத் திரும்புகிறது. இதன் விளைவாக `~/Videos` இல் ஒரு MP4 கிடைக்கும், `screenrecording-2026-08-13_14-22-05.mp4` என்ற பெயருடன். அதை மாற்ற `OMARCHY_SCREENRECORD_DIR` ஐ அமையுங்கள் — ஆனால் திரைப்பிடிப்புக் கோப்பகத்தைப் போலன்றி, இது ஏற்கனவே இருக்க வேண்டும், இல்லையெனில் பதிவு தொடங்க மறுக்கும் என்பதைக் கவனியுங்கள்.

நீங்கள் பதிவு செய்யும்போது, பட்டியில் ஒரு சிறிய காட்டி தோன்றும். நிறுத்த அதைக் கிளிக் செய்யுங்கள். நீங்கள் மீண்டும் `Alt + Print Screen` ஆலும் நிறுத்தலாம், அல்லது _Trigger > Capture > Screenrecord_ இன் கீழ் உள்ள _Stop Screenrecording_ உள்ளீட்டாலும் நிறுத்தலாம், இது ஏதாவது உண்மையில் பதிவாகிக் கொண்டிருக்கும்போது மட்டுமே தோன்றும்.

நிறுத்துவது கோப்பை உங்களிடம் ஒப்படைப்பதற்கு முன் கொஞ்சம் ஒழுங்குபடுத்தும்: முதல் சட்டகம் வெட்டி நீக்கப்படும், ஒலி இருந்தால் அது -14 LUFS க்கு இயல்பாக்கப்பட்டு, மிகத் தொடக்கத்தில் உள்ள PipeWire பிடிப்பு வெடிப்பொலி மௌனமாக்கப்படும். பிறகு பதிவிலிருந்து ஒரு சிறுபடத்துடன் ஒரு அறிவிப்பு தோன்றும். கோப்பை mpv இல் இயக்க அதைக் கிளிக் செய்யுங்கள்.

### வெப்கேம் மேலடுக்கு

நீங்கள் வெப்கேமுடன் பதிவு செய்யும்போது, நீங்கள் பதிவு செய்வதன் கீழ்-வலது மூலையில் கேமரா பின் செய்யப்பட்ட, வெட்டப்பட்ட நிழற்படச் சாளரமாகத் தோன்றும். அது உங்களுக்குத் தேவையான ஒன்றின் மேல் அமர்ந்திருந்தால், அப்போதே அதன் அளவை மாற்றுங்கள்:

| குறுக்குவிசை | செயல்பாடு |
| ------ | -------- |
| `Super + Alt + [` | வெப்கேம் மேலடுக்கைச் சிறிதாக்கு |
| `Super + Alt + ]` | வெப்கேம் மேலடுக்கைப் பெரிதாக்கு |

மூன்று அளவுகள் உள்ளன — சிறியது, நடுத்தரம், பெரியது — குறுக்குவிசைகள் அவற்றுக்கு இடையே படிப்படியாக நகரும். நடுத்தரம் இயல்புநிலை. அவை பதிவுக்கு விகிதாசாரமானவை, எனவே நீங்கள் 1080p மானிட்டரைப் பதிவு செய்தாலும் 6K மானிட்டரைப் பதிவு செய்தாலும் கேமரா சட்டகத்தில் அதே பங்கை எடுத்துக்கொள்ளும். நீங்கள் முழுக் காட்சிக்குப் பதிலாக ஒரு பகுதியைப் பதிவு செய்திருந்தால், மேலடுக்கு மானிட்டரின் மூலைக்குப் பதிலாக அந்தப் பகுதியின் மூலையில் நங்கூரமிடும், எனவே அது படத்துக்குள்ளேயே இருக்கும்.

நீங்கள் அதை `omarchy-capture-webcam-resize small` என நேரடியாகவும் அழைக்கலாம், அல்லது நடுத்தரத்துக்குத் திரும்ப `reset` எனவும் அழைக்கலாம்.

## உரை, QR குறியீடுகள், மற்றும் வண்ணங்கள்

`Super + Ctrl + Print Screen` ஒரு பகுதியைத் தேர்ந்து அதை OCR செய்து கிளிப்போர்டுக்கு அனுப்பும். அது [உரை பிரித்தெடுத்தல் & கட்டளையிடலில்](11-text-extraction-dictation.md) முறையாக விவரிக்கப்பட்டுள்ளது.

_Trigger > Capture > QR Code_ அதே தந்திரத்தை QR குறியீடுகளுக்குச் செய்கிறது. குறியீடு உள்ள பகுதியைத் தேர்ந்தெடுங்கள், குறியீடு நீக்கப்பட்ட மதிப்பு கிளிப்போர்டுக்குச் செல்லும். அது QR குறியீடுகளை மட்டுமே தேடுகிறது — அடர்த்தியான திரை உள்ளடக்கம் இல்லையெனில் பார்கோடாகத் தவறாகக் கண்டறியப்படும் பழக்கம் கொண்டது. தெரிந்து கொள்ள வேண்டியது: குறியீடு நீக்கப்பட்ட மதிப்பு கிளிப்போர்டுக்கு மட்டுமே செல்கிறது, வேறு எங்கும் செல்லாது. அது அச்சிடப்படாது, அது அறிவிப்பில் இருக்காது, [கிளிப்போர்டு வரலாற்றில்](08-unified-clipboard-history.md) ஒட்டிக்கொண்டிருக்காதபடி அது உணர்திறன் மிக்கதாகக் குறிக்கப்படும். QR குறியீடுகள் வழக்கமாக ரகசியங்களைக் கொண்டிருக்கும் — எடுத்துக்காட்டாக, 2FA அமைப்புக் குறியீட்டின் பின்னால் உள்ள `otpauth://` URI — அது ஒரு பதிவில் இருப்பதை நீங்கள் விரும்ப மாட்டீர்கள். ஒட்டுவது இன்னும் நன்றாக வேலை செய்யும்.

`Super + Print Screen` (அல்லது _Trigger > Capture > Color_) கர்சரை ஒரு துளிப்பானாக மாற்றும். திரையில் எதையாவது கிளிக் செய்யுங்கள், அந்த வண்ணம் கிளிப்போர்டில் வந்து சேரும். தேர்க்காமல் பின்வாங்க குறுக்குவிசையை மீண்டும் அழுத்துங்கள்.

## பகிர்வதற்கு முன் வடிவமாற்றம் செய்தல்

4K திரைப்பதிவோ உங்கள் தொலைபேசியிலிருந்து வந்த பதப்படுத்தப்படாத HEIC ஓ பெரும்பாலும் அப்படியே அனுப்ப முடியாத அளவுக்குப் பெரிதாக இருக்கும். `Super + Ctrl + .` (அல்லது _Trigger > Transcode_) அதைச் சரிசெய்கிறது. அது `~/Pictures` மற்றும் `~/Videos` மீது ஒரு தெளிவற்ற கோப்புத் தேர்வியை உங்களுக்கு வழங்கி, பிறகு ஒரு வடிவத்தையும் ஒரு அளவையும் கேட்கும்.

படங்கள் உயர், நடுத்தரம், அல்லது குறைந்த தரத்தில் jpg அல்லது png க்குச் செல்லும், இவை அகலத்தை 3160, 2160, மற்றும் 1080 பிக்சல்களில் கட்டுப்படுத்தும். வீடியோக்கள் 4k, 1080p, அல்லது 720p இல் mp4 அல்லது அனிமேஷன் செய்யப்பட்ட gif க்குச் செல்லும். மாற்றப்பட்ட கோப்பு அசலுக்கு அருகிலேயே பெயரில் தெளிவுத்திறனுடன் எழுதப்படும் — `demo-1080p.mp4` — பாதை கோப்பு URI ஆக கிளிப்போர்டுக்கு நகலெடுக்கப்படும், எனவே கோப்பு இழுத்துப் போடுதலை ஏற்கும் ஒரு செயலியில் அதை நேரடியாக ஒட்டலாம்.

நீங்கள் விரும்புவது ஏற்கனவே தெரிந்திருந்தால், அது முனையத்திலிருந்தும் வேலை செய்யும்: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. `omarchy transcode ascii` உம் உள்ளது, இது ஒரு படத்தை ASCII கலையாக மாற்றும் — அது பெரும்பாலும் [பிராண்டிங்குக்கானது](41-branding.md).

## அதை எங்காவது அனுப்புதல்

உங்களிடம் கோப்பு கிடைத்தவுடன், `Super + Ctrl + S` Share மெனுவைத் திறந்து LocalSend வழியாக உங்கள் வலையமைப்பில் உள்ள மற்றொரு சாதனத்துக்கு அதை அனுப்பும். அதற்கு [GUIகளைப்](22-guis.md) பாருங்கள்.
