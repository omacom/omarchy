# பொதுவான சிறு மாற்றங்கள்

இது Omarchy அமைப்புக்கான பொதுவான தனிப்பயனாக்கங்களின் தொகுப்பு. சிஸ்டம் புதுப்பிப்புகள் சில கான்ஃபிகுகளை அவற்றின் அசல் நிலைக்கு மீட்டமைக்க வேண்டியது அவ்வப்போது தேவைப்படலாம் என்பதைத் தெரிந்து கொள்ளுங்கள். இது நடந்தால், உங்கள் மாற்றங்கள் தொலைந்து போகாது, ஆனால் அசலுக்கு அருகில் உள்ள `.bak.<timestamp>` கோப்பில் வைக்கப்படும்.

நீங்கள் ஏதாவது குழப்பிவிட்டால், Omarchy மெனுவில் _Update > Config_ வழியாக தனிப்பட்ட கான்ஃபிகுகளை அவற்றின் அசல் அமைப்புக்கு மீட்டமைக்கலாம். நீங்கள் *உண்மையிலேயே* எல்லாவற்றையும் குழப்பிவிட்டால், `omarchy reinstall configs` வழியாக அனைத்து கான்ஃபிகுகளையும் மீட்டமைக்கலாம், அல்லது `omarchy reinstall` வழியாக ஒவ்வொரு இயல்புநிலை தொகுப்பையும் கான்ஃபிகையும் மீண்டும் நிறுவலாம்.

### அனைத்து tray ஐகான்களையும் எல்லா நேரமும் வெளிப்படுத்து

இயல்பாக, Dropbox, 1password, அல்லது Steam போன்ற tray ஐகான்கள் tray விரிவாக்க அம்புக்குறிக்குப் பின்னால் மறைக்கப்பட்டிருக்கும், நீங்கள் அதன் மீது வைக்கும்போது அது அவற்றை வெளிப்படுத்தும். அவற்றை எல்லா நேரமும் வெளிப்படையாக வைத்திருக்க விரும்பினால், tray ஐகான் மேலாளரைத் திறக்க விரிவாக்க அம்புக்குறியில் வலது-கிளிக் செய்யுங்கள், பிறகு நீங்கள் காணக்கூடியதாக வைத்திருக்க விரும்பும் ஐகான்களைப் பின் செய்யுங்கள் (நீங்கள் ஒருபோதும் பார்க்க விரும்பாதவற்றையும் மறைக்கலாம்).

### வட்டமான சாளர மூலைகள்

Omarchy இன் இயல்புநிலை வடிவமைப்பு சதுர மூலைகளைக் கொண்டது, ஆனால் அதைக் கொஞ்சம் மென்மையாக்க விரும்பினால், Omarchy மெனுவில் _Appearance > Windows > Window Corners > Rounded Corners_ ஐத் தேர்ந்தெடுங்கள், அல்லது `omarchy hyprland corners rounded` ஐ இயக்குங்கள். _Theme Corners_ தீம் பயன்படுத்துவதற்கே திரும்பச் செல்லும். உங்கள் சொந்த ஆரத்தைத் தேர்ந்தெடுக்க, _Theme Corners_ இலேயே இருங்கள் (`omarchy hyprland corners theme`), ஏனெனில் Rounded மற்றும் Sharp உங்கள் கான்ஃபிகுக்குப் பிறகு ஏற்றப்பட்டு அதை மேலெழுதும், மற்றும் `~/.config/hypr/looknfeel.lua` இல் rounding இன் கருத்துரையை நீக்குங்கள்:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### சாளர இடைவெளிகளை நீக்கு

மடிக்கணினி திரைகளில், சிலர் சாளர இடைவெளிகளில் எந்த பிக்சல்களையும் வீணாக்க விரும்புவதில்லை (அல்லது மேல் பட்டியைக் கூட, அதை நீங்கள் `Super + Shift + Space` கொண்டு அணைக்கலாம்). நீங்கள் `Super + Shift + Backspace` கொண்டு அனைத்து இடைவெளிகளையும் பார்டர்களையும் அணைக்கலாம், அல்லது `~/.config/hypr/looknfeel.lua` இன் இந்தப் பிரிவில் உள்ள கருத்துரைகளை நீக்குவதன் மூலம் அவற்றை நிரந்தரமாக நீக்கலாம்:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
