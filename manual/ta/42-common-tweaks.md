# பொதுவான மாற்றங்கள்

இது Omarchy அமைப்பிற்கான பொதுவான தையல்களின் தொகுப்பு. கணினிப் புதுப்பிப்புகள் சில உள்ளமைவுகளை அவற்றின் அசல் நிலைக்கு மீண்டும் கொண்டு வருவது எப்போதாவது தேவைப்படலாம் என்பதை அறிந்து கொள்ளுங்கள். இது நடந்தால், உங்கள் மாற்றங்கள் தொலையாது, அதே கோப்பகத்தில் ஒரு `.bak` கோப்பில் வைக்கப்படும்.

ஏதாவது கோளாறு செய்தால், Omarchy மெனுவில் _புதுப்பி > உள்ளமைவு_ வழியே தனிப்பட்ட உள்ளமைவுகளை அவற்றின் அசல் அமைப்பிற்கு மீட்டமைக்கலாம். _உண்மையிலேயே_ எல்லாவற்றையும் கோளாறு செய்தால், `omarchy-reinstall` வழியே எல்லா உள்ளமைவுகளையும் மீட்டமைக்கலாம்.

### எல்லாத் தட்டுச் சின்னங்களையும் எப்போதும் வெளிப்படுத்துதல்

இயல்பாகவே, Dropbox, 1password அல்லது Steam போன்ற தட்டுச் சின்னங்கள் தட்டு விரிப்பு அம்பிற்குப் பின்னால் மறைந்திருக்கும், நீங்கள் அதன் மீது கொண்டு செல்லும்போது அது அவற்றை வெளிப்படுத்தும். அவற்றை எல்லா நேரமும் வெளிப்படுத்தி வைக்க விரும்பினால், தட்டுச் சின்ன மேலாளரைத் திறக்க விரிப்பு அம்பின் மீது வலது சொடுக்கு செய்து, கண்ணுக்குத் தெரிய வைக்க விரும்பும் சின்னங்களைப் பொருத்துங்கள் (ஒருபோதும் பார்க்க விரும்பாதவற்றையும் மறைக்கலாம்).

### வட்டமான சாளர மூலைகள்

Omarchy-இன் இயல்புநிலை வடிவமைப்பு சதுர மூலைகளுடையது, ஆனால் அதைச் சற்று மென்மையாக்க விரும்பினால், வட்டமாக்கல் இனி கருத்தாக்கப்படாதபடி `~/.config/hypr/looknfeel.lua` என்பதை மாற்றலாம்:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### சாளர இடைவெளிகளை நீக்குதல்

மடிக்கணினித் திரைகளில், சிலர் சாளர இடைவெளிகளில் (`Super + Shift + Space` என்பதைக் கொண்டு நிறுத்தக்கூடிய மேல் பட்டையில் கூட) எந்தப் பிக்சல்களையும் வீணாக்க விரும்புவதில்லை. `Super + Shift + Backspace` என்பதைக் கொண்டு எல்லா இடைவெளிகளையும் எல்லைகளையும் நிறுத்தலாம், அல்லது `~/.config/hypr/looknfeel.lua`-இன் இந்தப் பிரிவில் உள்ள கருத்துகளை நீக்குவதன் மூலம் அவற்றை நிரந்தரமாக நீக்கலாம்:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
