# ஹாட்கீகள்

`Super + K` மூலம் அனைத்து முக்கிய விசைப்பலகை பிணைப்புகளையும் (`Super + Alt + K` மூலம் Tmux பிணைப்புகள் மற்றும் `Super + Ctrl + K` மூலம் Herdr பிணைப்புகள்) காணலாம்.

## வழிசெலுத்தல்

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy மெனு (செயலிகள் மற்றும் மற்ற அனைத்தும்)    |
| `Super + Alt + Space` | செயலி கட்டம் |
| `Super + Escape` | கணினி மெனு (இடைநிறுத்து, மறுதொடக்கம், முதலியன)  |

## உலகளாவிய கிளிப்போர்டு

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Super + C`           | நகலெடு    |
| `Super + X`           | வெட்டு (டெர்மினலில் அல்ல)    |
| `Super + V`           | ஒட்டு    |
| `Super + Ctrl + V`           | கிளிப்போர்டு மேலாளர்    |

பொதுவாக Linux-இல், டெர்மினலில் நகலெடுத்து ஒட்ட `Ctrl + Shift + C/V` தேவைப்படுகிறது மற்றும் மற்ற இடங்களில் அதைச் செய்ய `Ctrl + C/V` தேவைப்படுகிறது. இந்த Omarchy ஒருங்கிணைந்த கிளிப்போர்டு ஹாட்கீகள் எல்லா இடங்களிலும் வேலை செய்கின்றன.

## பதிவு செய்

| ஹாட்கீ              | செயல்பாடு                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | பதிவு மெனு (PrintScr பொத்தான் இல்லாத விசைப்பலகைகளுக்கு) |
| `Print Screen`            | திரைப்பிடிப்பு                      |
| `Alt + Print Screen`            | திரைப்பதிவு                     |
| `Super + Print Screen` | நிறம் தேர்வாளர் |
| `Super + Ctrl + Print Screen` | கிளிப்போர்டுக்கு உரை பிரித்தெடுத்தல் |
| `Super + Alt + [` | பதிவு செய்யும் போது வெப்கேம் மேலடுக்கை சிறியதாக்கு |
| `Super + Alt + ]` | பதிவு செய்யும் போது வெப்கேம் மேலடுக்கை பெரியதாக்கு |
| `Alt + Shift + L` | வெப்ஆப் அல்லது Chromium இலிருந்து தற்போதைய URL ஐ நகலெடு |
| `Alt + Shift + D` | தற்போதைய பக்கத்தில் உள்ள வீடியோவை `~/Videos` க்குப் பதிவிறக்கு |
| `Super + Ctrl + X` | கட்டளையிடலைத் தொடங்கு/நிறுத்து (_அமைப்பு > இயல்புநிலைகள் > Dictation_ தேவை) |
| `Right Alt` / `F9` | Push-to-talk கட்டளையிடல் (Voxtype அல்லது Superwhisper தேவை) |

திரைப்பதிவுகளுடன், ஹாட்கீ முதலில் நீங்கள் விரும்பும் ஒலியைக் கேட்கிறது, பிறகு பதிவைத் தொடங்குகிறது. நிறுத்த அதை மீண்டும் அழுத்தவும். விவரங்களுக்கு [திரைப்பிடிப்புகள் மற்றும் பதிவு](12-screenshots-recording.md) பார்க்கவும்.

அனைத்து பதிவு விருப்பங்களும் Omarchy மெனுவில் (`Super + Space`) _தூண்டு > பதிவு செய்_ இன் கீழும் அணுகக் கிடைக்கின்றன.

## பாணி

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Super + Ctrl + Shift + Space` | ஒரு புதிய தீமைத் தேர்ந்தெடு  |
| `Super + Ctrl + Space` | தீம் பின்னணியைத் தேர்ந்தெடு |
| `Super + Backspace` | ஒரு சாளரத்தில் வெளிப்படைத் தன்மையை மாற்று |
| `Super + Ctrl + Backspace` | ஒற்றை-சாளர சதுர அம்சத்தை மாற்று |

கூடுதல் பின்னணி படங்கள் `~/.config/omarchy/backgrounds/<theme name>` இல் உள்ளன. Omarchy மெனுவில் _நிறுவு > பாணி > பின்னணி_ வழியாகவும் கிடைக்கிறது.

அனைத்து பாணி விருப்பங்களும் Omarchy மெனுவில் (`Super + Space`) _பாணி_ இன் கீழும் அணுகக் கிடைக்கின்றன.

## மாற்றங்கள்

| ----------------------- | --------------------- |

| `Super + Shift + Space` | மேல் பட்டையை மாற்று  |

| `Super + Ctrl + Alt + F` | முழுத் திரை டெஸ்க்டாப்பை மாற்று (மேல் பட்டை + சாளர இடைவெளி) |

## Tmux

முன்னொட்டு விசை `Ctrl + Space` (`Ctrl + B` உம் வேலை செய்கிறது). இந்த பிணைப்புகளை `~/.config/tmux/tmux.conf` இல் மாற்றலாம்.

### பேன்கள்

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Prefix + v` | பக்கத்தில் பேனைப் பிள (செங்குத்து) |
| `Prefix + h` | கீழே பேனைப் பிள (கிடைமட்டம்) |
| `Prefix + x` | பேனைக் கொல் |
| `Prefix + z` | பேன் பெரிதாக்கத்தை மாற்று (முழுத்திரை) |
| `Alt + Enter` | கீழே பேனைப் பிள (முன்னொட்டு இல்லை) |
| `Alt + Shift + Enter` | பக்கத்தில் பேனைப் பிள (முன்னொட்டு இல்லை) |
| `Alt + Escape` | பேனைக் கொல் (முன்னொட்டு இல்லை) |
| `Ctrl + Alt + Arrows` | பேன்களுக்கு இடையே நகரவும் |
| `Ctrl + Alt + Shift + Arrows` | பேன்களை மறுஅளவிடு |

### சாளரங்கள்

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Prefix + c` | புதிய சாளரம் |
| `Prefix + k` | சாளரத்தைக் கொல் |
| `Prefix + r` | சாளரத்தை மறுபெயரிடு |
| `Alt + 1-9` | குறிப்பிட்ட சாளரத்திற்குச் செல் |
| `Alt + Arrow Left/Right` | சாளரங்களுக்கு இடையே நகரவும் |
| `Alt + Shift + Arrow Left/Right` | சாளரத்தை இடது/வலது நகர்த்து |

### அமர்வுகள்

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Prefix + C` | புதிய அமர்வு |
| `Prefix + K` | அமர்வைக் கொல் |
| `Prefix + R` | அமர்வை மறுபெயரிடு |
| `Prefix + N` | அடுத்த அமர்வு |
| `Prefix + P` | முந்தைய அமர்வு |
| `Alt + Arrow Up/Down` | அமர்வுகளுக்கு இடையே நகரவும் |
| `Prefix + s` | அமர்வுகளைப் பட்டியலிடு |
| `Prefix + d` | அமர்விலிருந்து பிரி |

### நகல் பயன்முறை (vi-பாணி)

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Prefix + [` | நகல் பயன்முறைக்குள் நுழை |
| `v` | தேர்வைத் தொடங்கு (நகல் பயன்முறையில்) |
| `y` | தேர்வை நகலெடு (நகல் பயன்முறையில்) |

### பொது

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Prefix + q` | கட்டமைப்பை மறுஏற்று |
| `Prefix + ?` | Tmux விசைப்பிணைப்புகளைக் காட்டு |
| `Prefix + :` | கட்டளைத் தூண்டல் |

### Tmux தளவமைப்பு செயல்பாடுகள்

இந்த செயல்பாடுகள் ஒரு Tmux அமர்விற்குள் இயக்கப்பட வேண்டும்.

| கட்டளை | செயல்பாடு |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | எடிட்டர், AI, மற்றும் டெர்மினலுடன் dev தளவமைப்பை உருவாக்கு |
| `tdlm <ai> [<second_ai>]` | துணை கோப்பகத்திற்கு dev தளவமைப்பை உருவாக்கு |
| `tsl <count> <command>` | பல-பேன் கூட்ட தளவமைப்பை உருவாக்கு |
