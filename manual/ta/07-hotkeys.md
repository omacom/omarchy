# ஹாட்கீகள்

நீங்கள் அனைத்து முக்கிய விசைப்பலகை பிணைப்புகளையும் `Super + K` மூலம் பார்க்கலாம் (Tmux பிணைப்புகள் `Super + Alt + K` மூலமும் Herdr பிணைப்புகள் `Super + Ctrl + K` மூலமும்).

அளவு மாற்ற குறுக்குவழிகள், விசைப்பலகையில் அச்சிடப்பட்ட எழுத்துக்களைப் பொருட்படுத்தாமல், இயற்பியல் விசைகளான `code:20` மற்றும் `code:21` (XKB `<AE11>` மற்றும் `<AE12>`) ஆகியவற்றைப் பயன்படுத்துகின்றன. US விசைப்பலகைகளில் இந்த விசைகள் `-` மற்றும் `=`; ஜப்பானிய (JIS) விசைப்பலகைகளில் அவை `-` மற்றும் `^`; ஸ்பானிஷ் விசைப்பலகைகளில் அவை `'` மற்றும் `¡`. JIS இல், `Super + ^` என்பது `Super + Equal`, அதே நேரத்தில் `Super + Shift + -` (இது `=` என தட்டச்சு செய்கிறது) என்பது `Super + Shift + Minus`.

## உலகளாவிய கிளிப்போர்டு

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Super + A`           | `Ctrl + A` ஐ ஆதரிக்கும் செயலிகளில் அனைத்தையும் தேர்ந்தெடு    |
| `Super + C`           | நகலெடு    |
| `Super + X`           | வெட்டு (முனையத்தில் அல்ல)    |
| `Super + V`           | ஒட்டு    |
| `Super + Ctrl + V`           | கிளிப்போர்டு மேலாளர்    |

வழக்கமாக Linux இல், முனையத்தில் நகலெடுக்கவும் ஒட்டவும் உங்களுக்கு `Ctrl + Shift + C/V` தேவை, மற்ற எல்லா இடங்களிலும் அதைச் செய்ய `Ctrl + C/V` தேவை. இந்த Omarchy ஒருங்கிணைந்த கிளிப்போர்டு ஹாட்கீகள் எல்லா இடங்களிலும் வேலை செய்கின்றன.

திரைப்பதிவுகளில், ஹாட்கீ முதலில் நீங்கள் எந்த ஆடியோவை விரும்புகிறீர்கள் என்று கேட்கும், பின்னர் பதிவைத் தொடங்கும். நிறுத்த மீண்டும் அதை அழுத்தவும். விவரங்களுக்கு [ஸ்கிரீன்ஷாட்டுகள் மற்றும் பதிவு](12-screenshots-recording.md) ஐப் பார்க்கவும்.

அனைத்து பிடிப்பு விருப்பங்களும் Omarchy மெனுவில் (`Super + Space`) _Trigger > Capture_ இன் கீழும் அணுகக்கூடியவை.
