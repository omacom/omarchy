# விசைப்பலகை குறுக்குவழிகள்

`Super + K` மூலம் அனைத்து முக்கிய விசைப்பலகை பிணைப்புகளையும் நீங்கள் பார்க்கலாம் (Tmux பிணைப்புகள் `Super + Alt + K` மூலம் மற்றும் Herdr பிணைப்புகள் `Super + Ctrl + K` மூலம்).

## விசைப்பலகை குறுக்குவழிகள் எவ்வாறு அமைக்கப்பட்டுள்ளன

ஒவ்வொரு விசைப்பலகை குறுக்குவழியும் அதன் மாற்றி விசைகளால் அமைக்கப்பட்ட ஒரு தளத்தில் அமர்ந்திருக்கிறது, மேலும் ஒவ்வொரு தளத்திற்கும் ஒரு வேலை உள்ளது. அதுதான் விசைப்பலகை குறுக்குவழிகள் ஒன்றோடொன்று குழம்பாமல் தடுக்கிறது, அதாவது பொதுவாக எது எங்கே இருக்கிறது என்று நீங்கள் ஊகிக்க முடியும்.

| தளம் | அங்கு என்ன இருக்கிறது | எடுத்துக்காட்டுகள் |
| --- | --- | --- |
| `Super + key` | அமைப்பு: சாளரங்கள், பணியிடங்கள், தளவமைப்புகள் மற்றும் மைய மெனுக்கள் | `Super + Space` Omarchy மெனு, `Super + W` சாளரத்தை மூடு, `Super + F` முழுத் திரை |
| `Super + Shift + key` | பயன்பாடுகள் | `Super + Shift + B` உலாவி, `Super + Shift + E` மின்னஞ்சல், `Super + Shift + N` தொகுப்பான் |
| `Super + Ctrl + key` | பேனல்கள் மற்றும் அமைப்பு மெனுக்கள் | `Super + Ctrl + A` ஒலி, `Super + Ctrl + N` வலையமைப்பு, `Super + Ctrl + C` பிடிப்பு மெனு |
| `Super + Ctrl + Alt + key` | விரைவு செயல்கள் மற்றும் அறிவிப்புகள் | `Super + Ctrl + Alt + T` நேரத்தைக் காட்டு, `Super + Ctrl + Alt + B` மின்கலம், `Super + Ctrl + Alt + C` திரைப்பிடிப்பு |

ஒரு விசைப்பலகை குறுக்குவழியில் `Alt` சேர்ப்பது உங்களுக்கு அதே விஷயத்தின் ஒரு மாறுபாட்டைத் தருகிறது, தொடர்பில்லாத எதையும் ஒருபோதும் தராது:

- `Super + Shift + B` உலாவியைத் திறக்கிறது; `Super + Shift + Alt + B` ஒரு தனிப்பட்ட சாளரத்தைத் திறக்கிறது
- `Super + Shift + E` மின்னஞ்சலைத் திறக்கிறது; `Super + Shift + Alt + E` புதிய ஒன்றைத் தொடங்குகிறது
- `Super + F` முழுத் திரைக்குச் செல்கிறது; `Super + Alt + F` முழு அகலத்திற்குச் செல்கிறது
- `Super + Ctrl + C` பிடிப்பு மெனுவைத் திறக்கிறது; `Super + Ctrl + Alt + C` மெனுவைத் தவிர்த்துவிட்டு திரைப்பிடிப்பை எடுக்கிறது

ஒரு விசைப்பலகை குறுக்குவழியைச் சேர்க்கும் போது:

1. அது என்ன செய்கிறது என்பதிலிருந்து தளத்தைத் தேர்ந்தெடுங்கள், பிறகு விசையைத் தேர்ந்தெடுங்கள்.
2. இடம் உருவாக்குவதற்காக ஏற்கனவே உள்ள விசைப்பலகை குறுக்குவழியை நகர்த்தாதீர்கள். சரியான தளத்தில் காலியான விசையைக் கண்டறியுங்கள்.
3. `Alt` ஐ அது இல்லாத விசைப்பலகை குறுக்குவழியின் மாறுபாட்டிற்கு மட்டுமே பயன்படுத்துங்கள்.

சில விசைப்பலகை குறுக்குவழிகள் வசதியாக இருப்பதால் இந்த விதிகளை மீறுகின்றன. அம்புக்குறி அல்லது `Tab` உடன் `Shift` என்பது ஒரு பயன்பாட்டைத் திறப்பதற்குப் பதிலாக நகர்த்துகிறது அல்லது தலைகீழாக்குகிறது, மேலும் `Print`, ஊடக விசைகள், `Alt + Tab`, மற்றும் `Ctrl + Alt + Del` ஆகியவை மற்ற எல்லா இடங்களிலும் செயல்படுவது போலவே செயல்படுகின்றன. அவை விதிவிலக்குகள், நகலெடுக்க வேண்டிய வடிவங்கள் அல்ல.

ஒரு இயல்புநிலை உங்களுக்குப் பொருந்தவில்லை என்றால் (Windows இல் உள்ளது போல திரைப்பிடிப்புகளுக்கு `Super + Shift + S` வேண்டும் என்று வைத்துக்கொள்வோம்), அதை `~/.config/hypr/bindings.lua` இல் மீண்டும் பிணைக்கவும்.

அளவுமாற்ற குறுக்குவழிகள் விசைப்பலகையில் அச்சிடப்பட்ட எழுத்துக்களைப் பொருட்படுத்தாமல், இயற்பியல் விசைகளான `code:20` மற்றும் `code:21` (XKB `<AE11>` மற்றும் `<AE12>`) ஆகியவற்றைப் பயன்படுத்துகின்றன. அமெரிக்க விசைப்பலகைகளில் இந்த விசைகள் `-` மற்றும் `=`; ஜப்பானிய (JIS) விசைப்பலகைகளில் அவை `-` மற்றும் `^`; ஸ்பானிஷ் விசைப்பலகைகளில் அவை `'` மற்றும் `¡`. JIS இல், `Super + ^` என்பது `Super + Equal`, அதே சமயம் `Super + Shift + -` (இது `=` எனத் தட்டச்சு செய்கிறது) என்பது `Super + Shift + Minus`.
