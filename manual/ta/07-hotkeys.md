# விசை குறுக்குவழிகள்

`Super + K` மூலம் அனைத்து முக்கிய விசைப்பலகை பிணைப்புகளையும் காணலாம் (Tmux பிணைப்புகள் `Super + Alt + K` மூலமும் Herdr பிணைப்புகள் `Super + Ctrl + K` மூலமும்).

## உலகளாவிய கிளிப்போர்டு

| விசை குறுக்குவழி | செயல்பாடு |

| `Super + C` | நகலெடு |
| `Super + X` | வெட்டு (terminal-இல் இல்லை) |
| `Super + V` | ஒட்டு |
| `Super + Ctrl + V` | Clipboard manager |

வழக்கமாக Linux-இல், terminal-இல் copy'n'paste செய்ய `Ctrl + Shift + C/V` தேவை, மற்ற எல்லா இடங்களிலும் அதைச் செய்ய `Ctrl + C/V` தேவை. இந்த Omarchy ஒருங்கிணைந்த clipboard விசை குறுக்குவழிகள் எல்லா இடங்களிலும் வேலை செய்யும்.

screenrecordings-உடன், விசை குறுக்குவழி முதலில் நீங்கள் எந்த ஆடியோவை விரும்புகிறீர்கள் என்று கேட்கும், பின்னர் பதிவைத் தொடங்கும். நிறுத்த மீண்டும் அதை அழுத்தவும். விவரங்களுக்கு [ஸ்கிரீன்ஷாட்கள் மற்றும் பதிவு](12-screenshots-recording.md) பார்க்கவும்.

அனைத்து பிடிப்பு விருப்பங்களும் Omarchy மெனுவில் (`Super + Space`) _Trigger > Capture_ கீழும் அணுகக்கூடியவை.

| விசை குறுக்குவழி | செயல்பாடு |
| ----------------------- | --------------------- |
| `Super + Ctrl + T` | புதிய theme-ஐத் தேர்ந்தெடு (`Super + Ctrl + Shift + Space` கூட) |
| `Super + Ctrl + W` | theme பின்னணியைத் தேர்ந்தெடு (`Super + Ctrl + Space` கூட) |
| `Super + Backspace` | சாளரத்தில் வெளிப்படைத்தன்மையை மாற்று |
| `Super + Ctrl + Backspace` | ஒற்றை-சாளர சதுர விகிதத்தை மாற்று |

கூடுதல் பின்னணி படங்கள் `~/.config/omarchy/backgrounds/<theme name>`-இல் உள்ளன. Omarchy மெனுவில் _Install > Style > Background_ வழியாகவும் கிடைக்கும்.

அனைத்து பாணி விருப்பங்களும் Omarchy மெனுவில் (`Super + Space`) _Style_ கீழும் அணுகக்கூடியவை.

## Tmux

prefix விசை `Ctrl + Space` (`Ctrl + B` கூட வேலை செய்யும்). இந்த பிணைப்புகளை `~/.config/tmux/tmux.conf`-இல் மாற்றலாம்.

### பலகங்கள்

| விசை குறுக்குவழி | செயல்பாடு |
| ----------------------- | --------------------- |
| `Prefix + v` | பலகத்தை அருகில் பிரி (செங்குத்து) |
| `Prefix + h` | பலகத்தை கீழே பிரி (கிடைமட்டம்) |
| `Prefix + x` | பலகத்தை அழி |
| `Prefix + z` | பலக பெரிதாக்கத்தை மாற்று (முழுத்திரை) |
| `Alt + Enter` | பலகத்தை கீழே பிரி (prefix இல்லை) |
| `Alt + Shift + Enter` | பலகத்தை அருகில் பிரி (prefix இல்லை) |
| `Alt + Escape` | பலகத்தை அழி (prefix இல்லை) |
| `Ctrl + Alt + Arrows` | பலகங்களுக்கு இடையே நகர் |
| `Ctrl + Alt + Shift + Arrows` | பலகங்களின் அளவை மாற்று |

### சாளரங்கள்

| விசை குறுக்குவழி | செயல்பாடு |
| ----------------------- | --------------------- |
| `Prefix + c` | புதிய சாளரம் |
| `Prefix + k` | சாளரத்தை அழி |
| `Prefix + r` | சாளரத்திற்கு மறுபெயரிடு |
| `Alt + 1-9` | குறிப்பிட்ட சாளரத்திற்குச் செல் |
| `Alt + Arrow Left/Right` | சாளரங்களுக்கு இடையே நகர் |
| `Alt + Shift + Arrow Left/Right` | சாளரத்தை இடது/வலது நகர்த்து |

### அமர்வுகள்

| விசை குறுக்குவழி | செயல்பாடு |
| ----------------------- | --------------------- |
| `Prefix + C` | புதிய அமர்வு |
| `Prefix + K` | அமர்வை அழி |
| `Prefix + R` | அமர்விற்கு மறுபெயரிடு |
| `Prefix + N` | அடுத்த அமர்வு |
| `Prefix + P` | முந்தைய அமர்வு |
| `Alt + Arrow Up/Down` | அமர்வுகளுக்கு இடையே நகர் |
| `Prefix + s` | அமர்வுகளைப் பட்டியலிடு |
| `Prefix + d` | அமர்விலிருந்து பிரி |

### நகல் பயன்முறை (vi-style)

| விசை குறுக்குவழி | செயல்பாடு |
| ----------------------- | --------------------- |
| `Prefix + [` | நகல் பயன்முறையில் நுழை |
| `v` | தேர்வைத் தொடங்கு (நகல் பயன்முறையில்) |
| `y` | தேர்வை நகலெடு (நகல் பயன்முறையில்) |

### பொது

| விசை குறுக்குவழி | செயல்பாடு |
| ----------------------- | --------------------- |
| `Prefix + q` | config-ஐ மீண்டும் ஏற்று |
| `Prefix + ?` | Tmux விசை பிணைப்புகளைக் காட்டு |
| `Prefix + :` | Command prompt |

### Tmux தளவமைப்பு செயல்பாடுகள்

இந்த செயல்பாடுகள் ஒரு Tmux அமர்விற்குள் இயக்கப்பட வேண்டும்.

| Command | செயல்பாடு |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | editor, AI, மற்றும் terminal உடன் dev தளவமைப்பை உருவாக்கு |
| `tdlm <ai> [<second_ai>]` | துணை அடைவிற்கு ஒன்றாக dev தளவமைப்பை உருவாக்கு |
| `tsl <count> <command>` | பல-பலக swarm தளவமைப்பை உருவாக்கு |
