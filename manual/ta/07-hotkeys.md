# விசைப்பலகை குறுக்குவழிகள்

`Super + K` மூலம் அனைத்து முக்கிய விசைப்பலகை பிணைப்புகளையும் பார்க்கலாம் (Tmux பிணைப்புகள் `Super + Alt + K` மூலமும் Herdr பிணைப்புகள் `Super + Ctrl + K` மூலமும்).

## விசைப்பலகை குறுக்குவழிகள் எவ்வாறு அமைக்கப்பட்டுள்ளன

ஒவ்வொரு குறுக்குவழியும் அதன் மாற்றி விசைகளால் தீர்மானிக்கப்படும் ஒரு தளத்தில் அமர்ந்திருக்கிறது, ஒவ்வொரு தளத்திற்கும் ஒரே ஒரு வேலை. குறுக்குவழிகள் ஒன்றோடொன்று குழம்பாமல் இருப்பது இதனால்தான், மேலும் பொதுவாக ஒன்று எங்கு இருக்கும் என்பதை உங்களால் ஊகிக்க முடிவது இதனால்தான்.

| தளம் | அங்கு இருப்பவை | எடுத்துக்காட்டுகள் |
| --- | --- | --- |
| `Super + key` | அமைப்பு: சாளரங்கள், பணிவெளிகள், தளவமைப்புகள் மற்றும் மைய மெனுக்கள் | `Super + Space` Omarchy மெனு, `Super + W` சாளரத்தை மூடு, `Super + F` முழுத்திரை |
| `Super + Shift + key` | பயன்பாடுகள் | `Super + Shift + B` உலாவி, `Super + Shift + E` மின்னஞ்சல், `Super + Shift + N` தொகுப்பான் |
| `Super + Ctrl + key` | பலகைகள் மற்றும் அமைப்பு மெனுக்கள் | `Super + Ctrl + A` ஒலி, `Super + Ctrl + N` வலையமைப்பு, `Super + Ctrl + C` பிடிப்பு மெனு |
| `Super + Ctrl + Alt + key` | விரைவு செயல்கள் மற்றும் அறிவிப்புகள் | `Super + Ctrl + Alt + T` நேரத்தைக் காட்டு, `Super + Ctrl + Alt + B` மின்கலம், `Super + Ctrl + Alt + C` திரைப்பிடிப்பு |

ஒரு குறுக்குவழியில் `Alt` சேர்ப்பது அதே பொருளின் ஒரு மாற்று வடிவத்தைத் தருகிறது, ஒருபோதும் தொடர்பில்லாத ஒன்றை அல்ல:

- `Super + Shift + B` உலாவியைத் திறக்கிறது; `Super + Shift + Alt + B` தனிப்பட்ட சாளரத்தைத் திறக்கிறது
- `Super + Shift + E` மின்னஞ்சலைத் திறக்கிறது; `Super + Shift + Alt + E` புதிய ஒன்றைத் தொடங்குகிறது
- `Super + F` முழுத்திரைக்குச் செல்கிறது; `Super + Alt + F` முழு அகலத்திற்குச் செல்கிறது
- `Super + Ctrl + C` பிடிப்பு மெனுவைத் திறக்கிறது; `Super + Ctrl + Alt + C` மெனுவைத் தவிர்த்து திரைப்பிடிப்பை எடுக்கிறது

ஒரு குறுக்குவழியைச் சேர்க்கும்போது:

1. அது என்ன செய்கிறது என்பதிலிருந்து தளத்தைத் தேர்ந்தெடு, பின்னர் விசையைத் தேர்ந்தெடு.
2. இடம் உருவாக்க ஏற்கனவே உள்ள குறுக்குவழியை நகர்த்தாதே. சரியான தளத்தில் காலியான விசையைக் கண்டுபிடி.
3. `Alt` இல்லாத குறுக்குவழியின் மாற்று வடிவத்திற்கு மட்டுமே `Alt` ஐப் பயன்படுத்து.

சில குறுக்குவழிகள் வசதியாக இருப்பதால் இந்த விதிகளை மீறுகின்றன. அம்புக்குறி அல்லது `Tab` உடன் `Shift` பயன்பாட்டைத் திறப்பதற்குப் பதிலாக நகர்த்துகிறது அல்லது தலைகீழாக்குகிறது, மேலும் `Print`, ஊடக விசைகள், `Alt + Tab`, மற்றும் `Ctrl + Alt + Del` மற்ற எல்லா இடங்களிலும் செயல்படுவது போலவே செயல்படுகின்றன. அவை விதிவிலக்குகள், நகலெடுக்க வேண்டிய முறைகள் அல்ல.

இயல்புநிலை உங்களுக்குப் பொருந்தவில்லை என்றால் (எடுத்துக்காட்டாக Windows இல் உள்ளது போல திரைப்பிடிப்புகளுக்கு `Super + Shift + S` வேண்டும் என்றால்), அதை `~/.config/hypr/bindings.lua` இல் மீண்டும் பிணைக்கவும்.

தொடுதிரையில், மூன்று மற்றும் நான்கு விரல் வழுக்கல்கள் பணிவெளிகளை மாற்றுகின்றன, சாளரங்களை நகர்த்துகின்றன, மேலும் மெனுவையும் Quake கன்சோலையும் திறக்கின்றன; சைகைகளுக்கு [விசைப்பலகை, சுட்டி மற்றும் தொடுதிரை](34-keyboard-mouse-trackpad.md) ஐப் பார்க்கவும்.

மறுஅளவிடல் 0 இன் வலதுபுறம் உள்ள இரண்டு விசைகளைப் பயன்படுத்துகிறது, உங்கள் விசைப்பலகை அவற்றில் எதை அச்சிட்டிருந்தாலும்: US விசைப்பலகைகளில் `-` மற்றும் `=`, Danish மற்றும் Swedish இல் `+` மற்றும் `´`, Norwegian இல் `+` மற்றும் `\`, German இல் `ß` மற்றும் `´`, Spanish இல் `'` மற்றும் `¡`, மற்றும் Japanese (JIS) இல் `-` மற்றும் `^`. `Super + K` அவற்றை உங்கள் விசைப்பலகை அச்சிட்டுள்ளபடி பட்டியலிடுகிறது. JIS இல், `Super + ^` என்பது `Super + Equal`, அதே நேரத்தில் `Super + Shift + -` (இது `=` ஐத் தட்டச்சு செய்கிறது) என்பது `Super + Shift + Minus`. திரை அளவிடலும் கடவுச்சொல் நிர்வாகியும் `/` ஐப் பயன்படுத்துகின்றன; பெரும்பாலான European தளவமைப்புகளைப் போல, Shift உடன் மட்டுமே `/` ஐத் தட்டச்சு செய்யும் தளவமைப்புகளில், அவை அதற்குப் பதிலாக வலது Shift இன் இடதுபுறம் உள்ள விசையைப் பயன்படுத்துகின்றன (Danish மற்றும் German இல் `-`).

| `Super + Ctrl + Alt + B` | மின்கலத்தை அறிவிப்பாகக் காட்டு  |
| `Super + Ctrl + Alt + W` | வானிலையை அறிவிப்பாக மாற்று  |

## Tmux

முன்னொட்டு விசை `Ctrl + Space` (`Ctrl + B` ம் வேலை செய்கிறது). இந்த பிணைப்புகளை `~/.config/tmux/tmux.conf` இல் மாற்றலாம்.

### பலகைகள்

| குறுக்குவழி | செயல்பாடு |
| ----------------------- | --------------------- |
| `Prefix + v` | பலகையை அருகில் பிரி (செங்குத்து) |
| `Prefix + h` | பலகையை கீழே பிரி (கிடைமட்டம்) |
| `Prefix + x` | பலகையை அழி |
| `Prefix + z` | பலகை பெரிதாக்கத்தை மாற்று (முழுத்திரை) |
| `Alt + Enter` | பலகையை கீழே பிரி (முன்னொட்டு இல்லை) |
| `Alt + Shift + Enter` | பலகையை அருகில் பிரி (முன்னொட்டு இல்லை) |
| `Alt + Escape` | பலகையை அழி (முன்னொட்டு இல்லை) |
| `Ctrl + Alt + Arrows` | பலகைகளுக்கு இடையே நகரு |
| `Ctrl + Alt + Shift + Arrows` | பலகைகளை மறுஅளவிடு |

### சாளரங்கள்

| குறுக்குவழி | செயல்பாடு |
| ----------------------- | --------------------- |
| `Prefix + c` | புதிய சாளரம் |
| `Prefix + k` | சாளரத்தை அழி |
| `Prefix + r` | சாளரத்தை மறுபெயரிடு |
| `Alt + 1-9` | குறிப்பிட்ட சாளரத்திற்குச் செல் |
| `Alt + Arrow Left/Right` | சாளரங்களுக்கு இடையே நகரு |
| `Alt + Shift + Arrow Left/Right` | சாளரத்தை இடது/வலது நகர்த்து |

### அமர்வுகள்

| குறுக்குவழி | செயல்பாடு |
| ----------------------- | --------------------- |
| `Prefix + C` | புதிய அமர்வு |
| `Prefix + K` | அமர்வை அழி |
| `Prefix + R` | அமர்வை மறுபெயரிடு |
| `Prefix + N` | அடுத்த அமர்வு |
| `Prefix + P` | முந்தைய அமர்வு |
| `Alt + Arrow Up/Down` | அமர்வுகளுக்கு இடையே நகரு |
| `Prefix + s` | அமர்வுகளைப் பட்டியலிடு |
| `Prefix + d` | அமர்விலிருந்து பிரிந்து செல் |

### நகல் முறை (vi-பாணி)

| குறுக்குவழி | செயல்பாடு |
| ----------------------- | --------------------- |
| `Prefix + [` | நகல் முறையில் நுழை |
| `v` | தேர்வைத் தொடங்கு (நகல் முறையில்) |
| `y` | தேர்வை நகலெடு (நகல் முறையில்) |

### பொது

| குறுக்குவழி | செயல்பாடு |
| ----------------------- | --------------------- |
| `Prefix + q` | உள்ளமைவை மீண்டும் ஏற்று |
| `Prefix + ?` | Tmux விசைப்பிணைப்புகளைக் காட்டு |
| `Prefix + :` | கட்டளைத் தூண்டல் |

### Tmux தளவமைப்பு செயல்பாடுகள்

இந்த செயல்பாடுகள் Tmux அமர்விற்குள் இயக்கப்பட வேண்டும்.

| கட்டளை | செயல்பாடு |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | தொகுப்பான், AI, மற்றும் முனையத்துடன் மேம்பாட்டு தளவமைப்பை உருவாக்கு |
| `tdlm <ai> [<second_ai>]` | துணை அடைவுக்கு ஒன்றாக மேம்பாட்டு தளவமைப்பை உருவாக்கு |
| `tsl <count> <command>` | பலபலகை திரள் தளவமைப்பை உருவாக்கு |
