# ஹாட்கீகள்

எல்லா முக்கிய விசைப்பலகைக் கட்டுகளையும் `Super + K` உடன் பார்க்கலாம் (Tmux கட்டுகளை `Super + Alt + K` உடனும் Herdr கட்டுகளை `Super + Ctrl + K` உடனும்).

## ஹாட்கீகள் எப்படி அமைக்கப்பட்டுள்ளன

ஒவ்வொரு ஹாட்கீயும் அதன் மாற்றிகளால் அமைக்கப்படும் ஒரு தளத்தில் அமர்ந்திருக்கிறது, ஒவ்வொரு தளத்துக்கும் ஒரே ஒரு வேலைதான். அதுதான் ஹாட்கீகள் ஒன்றோடொன்று குழம்பாமல் தடுக்கிறது, ஏதாவது ஒன்று எங்கே இருக்கும் என்று நீங்கள் வழக்கமாக யூகிக்கவும் முடியும் என்பதையும் அது குறிக்கிறது.

| Plane | What lives there | Examples |
| --- | --- | --- |
| `Super + key` | அமைப்பு: சாளரங்கள், பணியிடங்கள், தளவமைப்புகள், முக்கிய மெனுக்கள் | `Super + Space` Omarchy மெனு, `Super + W` சாளரத்தை மூடு, `Super + F` முழுத் திரை |
| `Super + Shift + key` | செயலிகள் | `Super + Shift + B` உலாவி, `Super + Shift + E` மின்னஞ்சல், `Super + Shift + N` தொகுப்பாளர் |
| `Super + Ctrl + key` | பேனல்கள் மற்றும் அமைப்பு மெனுக்கள் | `Super + Ctrl + A` ஆடியோ, `Super + Ctrl + N` பிணையம், `Super + Ctrl + C` பிடிப்பு மெனு |
| `Super + Ctrl + Alt + key` | விரைவுச் செயல்கள் மற்றும் அறிவிப்புகள் | `Super + Ctrl + Alt + T` நேரத்தைக் காட்டு, `Super + Ctrl + Alt + B` பேட்டரி, `Super + Ctrl + Alt + C` திரைப்பிடிப்பு |

ஹாட்கீயில் `Alt` சேர்ப்பது உங்களுக்கு அதே பொருளின் ஒரு மாறுபாட்டைத்தான் தரும், தொடர்பே இல்லாத வேறொன்றை ஒருபோதும் அல்ல:

- `Super + Shift + B` உலாவியைத் திறக்கிறது; `Super + Shift + Alt + B` ஒரு தனிப்பட்ட சாளரத்தைத் திறக்கிறது
- `Super + Shift + E` மின்னஞ்சலைத் திறக்கிறது; `Super + Shift + Alt + E` புதிய ஒன்றைத் தொடங்குகிறது
- `Super + F` முழுத் திரைக்குச் செல்கிறது; `Super + Alt + F` முழு அகலத்துக்குச் செல்கிறது
- `Super + Ctrl + C` பிடிப்பு மெனுவைத் திறக்கிறது; `Super + Ctrl + Alt + C` மெனுவைத் தவிர்த்துத் திரைப்பிடிப்பை எடுக்கிறது

ஹாட்கீயைச் சேர்க்கும்போது:

1. அது என்ன செய்கிறது என்பதிலிருந்து தளத்தைத் தேர்ந்தெடுங்கள், பிறகு விசையைத் தேர்ந்தெடுங்கள்.
2. இடம் உருவாக்க இருக்கும் ஹாட்கீயை நகர்த்தாதீர்கள். சரியான தளத்தில் காலியாக இருக்கும் விசையைக் கண்டறியுங்கள்.
3. `Alt` ஐ அது இல்லாத ஹாட்கீயின் மாறுபாட்டுக்கு மட்டுமே பயன்படுத்துங்கள்.

சில ஹாட்கீகள் வசதியாக இருப்பதால் இந்த விதிகளை மீறுகின்றன. அம்பு அல்லது `Tab` உடன் `Shift` செயலியைத் திறப்பதற்குப் பதிலாக நகர்த்துகிறது அல்லது திருப்புகிறது, `Print`, மீடியா விசைகள், `Alt + Tab`, மற்றும் `Ctrl + Alt + Del` எல்லா இடங்களிலும் செயல்படுவதுபோலவே செயல்படுகின்றன. அவை விதிவிலக்குகள், நகலெடுக்க வேண்டிய முறைகள் அல்ல.

இயல்புநிலை உங்களுக்குப் பொருந்தவில்லை என்றால் (Windows இல் போல திரைப்பிடிப்புகளுக்கு `Super + Shift + S` வேண்டும் என்று வைத்துக்கொள்வோம்), அதை `~/.config/hypr/bindings.lua` இல் மறுகட்டுங்கள்.

| ----------------------- | --------------------- |

| `Super + J` | சாளர நிலையை மாற்று (கிடைமட்டம்/செங்குத்து) |
| `Super + O`               | சாளரத்தை ஒட்டும்'மிதக்கும் நிலைக்கு வெளியே கொண்டுவருவதை மாற்று |

| `Super + Alt + L`         | தளவமைப்புகள் வழியாகத் தலைகீழாகச் சுழற்று |
| `Super + P`               | போலிச் சாளரப் பாணியை மாற்று (இயல்பு எதிர் நீட்டிப்பு) |
| `Super + F`                 | முழுத் திரைக்குச் செல்              |
| `Super + Alt + F`                 | முழு அகலத்துக்குச் செல்              |
| `Super + Ctrl + F`                 | சாளரத்துக்குள் முழுத் திரைக்குச் செல்              |
| `Super + 1…9/0`         | கவனம் செலுத்தப்பட்ட மானிட்டரில் குறிப்பிட்ட பணியிடத்துக்குத் தாவு (0 என்பது 10) |
| `Super + Tab` | கவனம் செலுத்தப்பட்ட மானிட்டரில் அடுத்த பணியிடத்துக்குத் தாவு |
| `Super + Shift + Tab` | கவனம் செலுத்தப்பட்ட மானிட்டரில் முந்தைய பணியிடத்துக்குத் தாவு |
| `Super + Ctrl + Tab` | கவனம் செலுத்தப்பட்ட மானிட்டரில் முன்னாள் பணியிடத்துக்குத் தாவு |
| `Super + Shift + 1…9/0` | கவனம் செலுத்தப்பட்ட மானிட்டரில் சாளரத்தைப் பணியிடத்துக்கு நகர்த்து |
| `Super + Shift + Alt + 1…9/0` | பின்தொடராமல் கவனம் செலுத்தப்பட்ட மானிட்டரில் சாளரத்தைப் பணியிடத்துக்கு நகர்த்து |
| `Super + S` | முழு ஸ்கிராட்ச்பேடை மாற்று |
| `Super + Alt + S` | சாளரத்தை முழு ஸ்கிராட்ச்பேடிற்கு நகர்த்து |

| `Super + Right Mouse` | சாளரத்தின் அளவை மாற்று |

டச்பேடில், மூன்று மற்றும் நான்கு விரல் ஸ்வைப்கள் பணியிடங்களை மாற்றுகின்றன, சாளரங்களை நகர்த்துகின்றன, மெனுவையும் Quake கன்சோலையும் திறக்கின்றன; சைகைகளுக்கு [விசைப்பலகை, சுட்டி, மற்றும் டிராக்பேட்](34-keyboard-mouse-trackpad.md) ஐப் பார்க்கவும்.

அளவுமாற்றம் 0 இன் வலதுபுறம் உள்ள இரண்டு விசைகளைப் பயன்படுத்துகிறது, உங்கள் விசைப்பலகை அவற்றில் எதை அச்சிட்டிருந்தாலும்: US விசைப்பலகைகளில் `-` மற்றும் `=`, Danish மற்றும் Swedish இல் `+` மற்றும் `´`, Norwegian இல் `+` மற்றும் `\`, German இல் `ß` மற்றும் `´`, Spanish இல் `'` மற்றும் `¡`, Japanese (JIS) இல் `-` மற்றும் `^`. `Super + K` அவற்றை உங்கள் விசைப்பலகை அச்சிட்டுள்ளபடியே பட்டியலிடுகிறது. JIS இல், `Super + ^` என்பது `Super + Equal`, அதே நேரத்தில் `Super + Shift + -` (இது `=` எனத் தட்டச்சு செய்கிறது) என்பது `Super + Shift + Minus`. மானிட்டர் அளவிடலும் கடவுச்சொல் நிர்வாகியும் `/` ஐப் பயன்படுத்துகின்றன; பெரும்பாலான European தளவமைப்புகளைப் போல, `/` ஐ Shift உடன் மட்டுமே தட்டச்சு செய்யும் தளவமைப்புகளில், அவை வலது Shift இன் இடதுபுறம் உள்ள விசையைப் பயன்படுத்துகின்றன (Danish மற்றும் German இல் `-`).
