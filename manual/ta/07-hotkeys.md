# ஹாட்கீகள்

`Super + K` மூலம் அனைத்து முக்கிய விசைப்பலகை பிணைப்புகளையும் காணலாம் (Tmux பிணைப்புகளுக்கு `Super + Alt + K`, Herdr பிணைப்புகளுக்கு `Super + Ctrl + K`).

## வழிசெலுத்தல்

| ஹாட்கீ | செயல்பாடு |
| ----------------------- | --------------------- |
| `Super + Space` | Omarchy மெனு (செயலிகள் மற்றும் மற்ற அனைத்தும்) |
| `Super + Alt + Space` | செயலி கட்டம் |
| `Super + Escape` | அமைப்பு மெனு (இடைநிறுத்தம், மறுதொடக்கம் போன்றவை) |
| `Super + Ctrl + L` | கணினியைப் பூட்டு |
| `Super + W` or `Super + Q` | சாளரத்தை மூடு |
| `Ctrl + Alt + Del` | அனைத்து சாளரங்களையும் மூடு |
| `Super + T` | சாளரத்தை டைலிங்/மிதக்கும் நிலைக்கு இடையே மாற்று |
| `Super + J` | சாளர நிலையை மாற்று (கிடைமட்டம்/செங்குத்து) |
| `Super + O` | சாளரத்தை ஸ்டிக்கி'ன்'ஃப்ளோட்டிங் நிலைக்கு வெளியே எடுப்பதை மாற்று |
| `Super + L` | dwindle, scrolling மற்றும் floating தளவமைப்புகளுக்கு இடையே சுழற்று |
| `Super + Alt + L` | தளவமைப்புகளுக்கு இடையே தலைகீழாகச் சுழற்று |
| `Super + P` | போலி சாளர பாணியை மாற்று (இயல்பானது v நீட்டிக்கப்பட்டது) |
| `Super + F` | முழுத் திரைக்குச் செல் |
| `Super + Alt + F` | முழு அகலத்திற்குச் செல் |
| `Super + Ctrl + F` | சாளரத்திற்குள் முழுத் திரைக்குச் செல் |
| `Super + 1/2/3/4` | கவனத்தில் உள்ள மானிட்டரில் குறிப்பிட்ட பணியிடத்திற்குத் தாவு |
| `Super + Tab` | கவனத்தில் உள்ள மானிட்டரில் அடுத்த பணியிடத்திற்குத் தாவு |
| `Super + Shift + Tab` | கவனத்தில் உள்ள மானிட்டரில் முந்தைய பணியிடத்திற்குத் தாவு |
| `Super + Ctrl + Tab` | கவனத்தில் உள்ள மானிட்டரில் முன்பிருந்த பணியிடத்திற்குத் தாவு |
| `Super + Shift + 1/2/3/4` | சாளரத்தை கவனத்தில் உள்ள மானிட்டரில் உள்ள பணியிடத்திற்கு நகர்த்து |
| `Super + Shift + Alt + 1/2/3/4` | பின்தொடராமல் சாளரத்தை கவனத்தில் உள்ள மானிட்டரில் உள்ள பணியிடத்திற்கு நகர்த்து |
| `Super + S` | முழு ஸ்கிராட்ச்பேடை மாற்று |
| `Super + Alt + S` | சாளரத்தை முழு ஸ்கிராட்ச்பேடுக்கு நகர்த்து |
| `Super + Grave` | Quake கன்சோலை மாற்று |
| `Super + Shift + Grave` | சாளரத்தை Quake கன்சோலுக்கு நகர்த்து |
| `Super + Shift + Ctrl + Arrows` | சாளரத்தை அந்தத் திசையில் உள்ள மானிட்டருக்கு நகர்த்து |
| `Super + Shift + Alt + Arrows` | பணியிடத்தை அந்தத் திசையில் உள்ள மானிட்டருக்கு நகர்த்து |
| `Super + Arrow` | அம்பின் திசையில் உள்ள சாளரத்திற்கு கவனத்தை நகர்த்து, திரையின் விளிம்பில் அந்தப் பக்கத்தில் உள்ள மானிட்டருக்குக் கடந்து செல் |
| `Super + Shift + Arrow` | சாளரத்தை அம்பின் திசையில் உள்ள மற்றொரு சாளரத்துடன் மாற்று, அந்தப் பக்கத்தில் உள்ள மானிட்டரில் உள்ள ஒன்று உட்பட |
| `Super + Minus` | சாளரத்தை இடதுபுறம் விரிவாக்கு |
| `Super + Equal` | சாளரத்தை இடதுபுறம் சுருக்கு |
| `Super + Shift + Minus` | சாளரத்தை மேல்நோக்கிச் சுருக்கு |
| `Super + Shift + Equal` | சாளரத்தை கீழ்நோக்கி விரிவாக்கு |
| `Super + Alt + Minus/Equal` | சிறிய படிகளில் அதே அளவுமாற்றம் |
| `Super + Ctrl + Minus/Equal` | பெரிய படிகளில் அதே அளவுமாற்றம் |
| `Super + Alt + Home` | சாளர அகலத்தைச் சேமி |
| `Super + Home` | சேமிக்கப்பட்ட சாளர அகலத்தை மீட்டமை |
| `Super + Left Mouse` | சாளரத்தைச் சுற்றி இழு |
| `Super + Right Mouse` | சாளரத்தின் அளவை மாற்று |
| `Super + Scroll Wheel` | கவனத்தில் உள்ள மானிட்டரில் பணியிடங்கள் வழியாக உருட்டு |
| `Super + G` | சாளரக் குழுவாக்கத்தை மாற்று |
| `Super + Alt + G` | சாளரத்தைக் குழுவாக்கத்திலிருந்து வெளியே நகர்த்து |
| `Super + Alt + Tab` | குழுவாக்கத்தில் உள்ள சாளரங்களுக்கு இடையே சுழற்று |
| `Super + Alt + Shift + Tab` | குழுவாக்கத்தில் உள்ள சாளரங்களுக்கு இடையே பின்னோக்கிச் சுழற்று |
| `Super + Alt + Scroll Wheel` | குழுவாக்கத்தில் உள்ள சாளரங்களுக்கு இடையே சுழற்று |
| `Super + Alt + 1/2/3/4/5` | குழுவாக்கத்தில் குறிப்பிட்ட சாளரத்திற்குத் தாவு |
| `Super + Alt + Arrow` | சாளரத்தை அம்பின் திசையில் குழுவாக்கத்திற்குள் நகர்த்து, அந்தப் பக்கத்தில் உள்ள மானிட்டரில் உள்ள ஒன்று உட்பட |
| `Super + Ctrl + Left/Right` | டைலிங் குழுவிற்குள் உள்ள சாளரங்களுக்கு இடையே நகர் |
| `Super + Ctrl + Z` | திரையில் பெரிதாக்கு (மேலும் பெரிதாக்க மீண்டும் அழுத்து) |
| `Super + Ctrl + Alt + Z` | திரையிலிருந்து முழுமையாகச் சிறிதாக்கு |
| `Super + /` | மானிட்டர் அளவிடல் விருப்பங்கள் வழியாக முன்னோக்கிச் செல் |
| `Super + Alt + /` | மானிட்டர் அளவிடல் விருப்பங்கள் வழியாகப் பின்னோக்கிச் செல் |
| `Alt + Tab` | செயலில் உள்ள பணியிடத்தில் உள்ள சாளரங்கள் வழியாக முன்னோக்கிச் சுழற்று |
| `Alt + Shift + Tab` | செயலில் உள்ள பணியிடத்தில் உள்ள சாளரங்கள் வழியாகப் பின்னோக்கிச் சுழற்று |
| `Ctrl + Alt + Tab` | மானிட்டர்கள் வழியாக கவனத்தை முன்னோக்கிச் சுழற்று |
| `Ctrl + Alt + Shift + Tab` | மானிட்டர்கள் வழியாக கவனத்தைப் பின்னோக்கிச் சுழற்று |

## உலகளாவிய கிளிப்போர்டு

| ஹாட்கீ | செயல்பாடு |
| ----------------------- | --------------------- |
| `Super + C` | நகலெடு |
| `Super + X` | வெட்டு (டெர்மினலில் இல்லை) |
| `Super + V` | ஒட்டு |
| `Super + Ctrl + V` | கிளிப்போர்டு மேலாளர் |

வழக்கமாக Linux-இல், டெர்மினலில் நகலெடுக்கவும் ஒட்டவும் `Ctrl + Shift + C/V` தேவை, மற்ற எல்லா இடங்களிலும் அதைச் செய்ய `Ctrl + C/V` தேவை. இந்த Omarchy ஒருங்கிணைந்த கிளிப்போர்டு ஹாட்கீகள் எல்லா இடங்களிலும் செயல்படும்.

## பிடிப்பு

| ஹாட்கீ | செயல்பாடு |
| ------------------- | ------------------------------ |
| `Print Screen` | ஸ்கிரீன்ஷாட் |
| `Super + Ctrl + Alt + C` | ஸ்கிரீன்ஷாட் (அதே ஷாட், Print Screen விசை இல்லாத விசைப்பலகைகளுக்கு) |
| `Super + Ctrl + C` | பிடிப்பு மெனு |
| `Alt + Print Screen` | திரைப்பதிவு |
| `Super + Print Screen` | வண்ணத் தேர்வி |
| `Super + Ctrl + Print Screen` | உரையைப் பிரித்தெடுத்து கிளிப்போர்டுக்கு அனுப்பு |
| `Super + Alt + [` | பதிவு செய்யும்போது வெப்கேம் மேலடுக்கைச் சிறிதாக்கு |
| `Super + Alt + ]` | பதிவு செய்யும்போது வெப்கேம் மேலடுக்கைப் பெரிதாக்கு |
| `Alt + Shift + L` | வெப்ஆப் அல்லது Chromium-இலிருந்து தற்போதைய URL-ஐ நகலெடு |
| `Alt + Shift + D` | தற்போதைய பக்கத்தில் உள்ள வீடியோவை `~/Videos`-க்குப் பதிவிறக்கு |
| `Super + Ctrl + X` | டிக்டேஷனைத் தொடங்கு/நிறுத்து (_Setup > Defaults > Dictation_ தேவை) |
| `Right Alt` / `F9` | புஷ்-டு-டாக் டிக்டேஷன் (Voxtype அல்லது Superwhisper தேவை) |

திரைப்பதிவுகளில், ஹாட்கீ முதலில் எந்த ஆடியோ வேண்டும் என்று கேட்கும், பின்னர் பதிவைத் தொடங்கும். நிறுத்த மீண்டும் அதை அழுத்து. விவரங்களுக்கு [ஸ்கிரீன்ஷாட்களும் பதிவும்](12-screenshots-recording.md) என்பதைப் பார்க்கவும்.

அனைத்து பிடிப்பு விருப்பங்களும் Omarchy மெனுவில் (`Super + Space`) _Trigger > Capture_ என்பதன் கீழும் கிடைக்கும்.

## அறிவிப்புகள்

| ஹாட்கீ | செயல்பாடு |
| ----------------------- | --------------------- |
| `Super + ,` | சமீபத்திய அறிவிப்பின் மீது செயல்படு: அதைத் திற, அல்லது அதன் ஒரே பொத்தானை அழுத்து, அதன் தேர்வுகளில் இருந்து தேர்ந்தெடு, அல்லது எதுவும் இல்லாதபோது அதை நிராகரி |
| `Super + Shift + ,` | அனைத்து அறிவிப்புகளையும் நிராகரி |
| `Super + Ctrl + ,` | விசைப்பலகை மூலம் அறிவிப்புகளைக் கட்டுப்படுத்து |
| `Super + Alt + ,` | சமீபத்திய அறிவிப்பை நிராகரி |
| `Super + Shift + Alt + ,` | அறிவிப்பு வரலாற்றைத் திற |
| `Super + Ctrl + Alt + ,` | அறிவிப்புகளை அமைதிப்படுத்துவதை மாற்று |

## பாணி

| ஹாட்கீ | செயல்பாடு |
| ----------------------- | --------------------- |
| `Super + Ctrl + T` | புதிய தீமைத் தேர்ந்தெடு (`Super + Ctrl + Shift + Space` என்பதும்) |
| `Super + Ctrl + W` | தீம் பின்னணியைத் தேர்ந்தெடு (`Super + Ctrl + Space` என்பதும்) |
| `Super + Backspace` | ஒரு சாளரத்தில் வெளிப்படைத்தன்மையை மாற்று |

கூடுதல் பின்னணி படங்கள் `~/.config/omarchy/backgrounds/<theme name>`-இல் உள்ளன. Omarchy மெனுவில் _Install > Style > Background_ வழியாகவும் கிடைக்கும்.

அனைத்து பாணி விருப்பங்களும் Omarchy மெனுவில் (`Super + Space`) _Style_ என்பதன் கீழும் கிடைக்கும்.

## Tmux

முன்னொட்டு விசை `Ctrl + Space` (`Ctrl + B` என்பதும் செயல்படும்). இந்தப் பிணைப்புகளை `~/.config/tmux/tmux.conf`-இல் மாற்றலாம்.

### பேன்கள்

| ஹாட்கீ | செயல்பாடு |
| ----------------------- | --------------------- |
| `Prefix + v` | பேனை அருகில் பிரி (செங்குத்து) |
| `Prefix + h` | பேனை கீழே பிரி (கிடைமட்டம்) |
| `Prefix + x` | பேனை அழி |
| `Prefix + z` | பேன் பெரிதாக்கத்தை மாற்று (முழுத்திரை) |
| `Alt + Enter` | பேனை கீழே பிரி (முன்னொட்டு இல்லை) |
| `Alt + Shift + Enter` | பேனை அருகில் பிரி (முன்னொட்டு இல்லை) |
| `Alt + Escape` | பேனை அழி (முன்னொட்டு இல்லை) |
| `Ctrl + Alt + Arrows` | பேன்களுக்கு இடையே நகர் |
| `Ctrl + Alt + Shift + Arrows` | பேன்களின் அளவை மாற்று |

### சாளரங்கள்

| ஹாட்கீ | செயல்பாடு |
| ----------------------- | --------------------- |
| `Prefix + c` | புதிய சாளரம் |
| `Prefix + k` | சாளரத்தை அழி |
| `Prefix + r` | சாளரத்திற்கு மறுபெயரிடு |
| `Alt + 1-9` | குறிப்பிட்ட சாளரத்திற்குச் செல் |
| `Alt + Arrow Left/Right` | சாளரங்களுக்கு இடையே நகர் |
| `Alt + Shift + Arrow Left/Right` | சாளரத்தை இடது/வலதுபுறம் நகர்த்து |

### அமர்வுகள்

| ஹாட்கீ | செயல்பாடு |
| ----------------------- | --------------------- |
| `Prefix + C` | புதிய அமர்வு |
| `Prefix + K` | அமர்வை அழி |
| `Prefix + R` | அமர்விற்கு மறுபெயரிடு |

| `Prefix + s` | அமர்வுகளைப் பட்டியலிடு |
| `Prefix + d` | அமர்விலிருந்து பிரிந்து செல் |

### நகல் பயன்முறை (vi-பாணி)

| ஹாட்கீ | செயல்பாடு |
| ----------------------- | --------------------- |
| `Prefix + [` | நகல் பயன்முறையில் நுழை |
| `v` | தேர்வைத் தொடங்கு (நகல் பயன்முறையில்) |
| `y` | தேர்வை நகலெடு (நகல் பயன்முறையில்) |

### பொதுவானவை

| ஹாட்கீ | செயல்பாடு |
| ----------------------- | --------------------- |
| `Prefix + q` | உள்ளமைவை மீண்டும் ஏற்று |
| `Prefix + ?` | Tmux விசைப்பிணைப்புகளைக் காட்டு |
| `Prefix + :` | கட்டளை வரியில் கேள் |

### Tmux தளவமைப்பு செயல்பாடுகள்

இந்தச் செயல்பாடுகள் Tmux அமர்விற்குள் இயக்கப்பட வேண்டும்.

| கட்டளை | செயல்பாடு |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | எடிட்டர், AI மற்றும் டெர்மினலுடன் டெவ் தளவமைப்பை உருவாக்கு |
| `tdlm <ai> [<second_ai>]` | துணை அடைவுக்கு ஒன்றாக டெவ் தளவமைப்பை உருவாக்கு |
| `tsl <count> <command>` | பல-பேன் ஸ்வார்ம் தளவமைப்பை உருவாக்கு |
