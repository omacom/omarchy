# ஹாட்கீகள்

`Super + K` ஐப் பயன்படுத்தி அனைத்து முக்கிய விசைப்பலகை பிணைப்புகளையும் பார்க்கலாம் (Tmux பிணைப்புகள் `Super + Alt + K` உடன் மற்றும் Herdr பிணைப்புகள் `Super + Ctrl + K` உடன்).

## உலகளாவிய கிளிப்போர்டு

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Super + C`           | நகலெடு    |
| `Super + X`           | வெட்டு (முனையத்தில் அல்ல)    |
| `Super + V`           | ஒட்டு    |
| `Super + Ctrl + V`           | கிளிப்போர்டு மேலாளர்    |

வழக்கமாக Linux இல், முனையத்தில் நகலெடுக்க'ன்'ஒட்ட `Ctrl + Shift + C/V` தேவை, மற்ற எல்லா இடங்களிலும் அதைச் செய்ய `Ctrl + C/V` தேவை. இந்த Omarchy ஒருங்கிணைந்த கிளிப்போர்டு ஹாட்கீகள் எல்லா இடங்களிலும் வேலை செய்யும்.

திரைப்பதிவுகளில், ஹாட்கீ முதலில் நீங்கள் விரும்பும் ஒலியைக் கேட்கும், பின்னர் பதிவைத் தொடங்கும். நிறுத்த மீண்டும் அதை அழுத்தவும். விவரங்களுக்கு [ஸ்கிரீன்ஷாட்கள் மற்றும் பதிவு செய்தல்](12-screenshots-recording.md) ஐப் பார்க்கவும்.

அனைத்து பிடிப்பு விருப்பங்களும் Omarchy மெனுவில் (`Super + Space`) _தூண்டு > பிடிப்பு_ இன் கீழும் கிடைக்கும்.

## அறிவிப்புகள்

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Super + ,` | சமீபத்திய அறிவிப்பில் செயல்படு: அதைத் திற, அல்லது அதன் ஒரே பொத்தானை அழுத்து, அதன் தேர்வுகளில் இருந்து தேர்ந்தெடு, அல்லது எதுவும் இல்லாதபோது அதை நிராகரி  |
| `Super + Shift + ,` | அனைத்து அறிவிப்புகளையும் நிராகரி |
| `Super + Ctrl + ,` | விசைப்பலகையால் அறிவிப்புகளைக் கட்டுப்படுத்து  |
| `Super + Alt + ,` | சமீபத்திய அறிவிப்பை நிராகரி  |
| `Super + Shift + Alt + ,` | அறிவிப்பு வரலாற்றைத் திற  |
| `Super + Ctrl + Alt + ,` | அறிவிப்புகளை அமைதிப்படுத்துவதை மாற்று  |

## பாணி

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Super + Ctrl + T` | புதிய தீமைத் தேர்ந்தெடு (மேலும் `Super + Ctrl + Shift + Space`) |
| `Super + Ctrl + W` | தீம் பின்னணியைத் தேர்ந்தெடு (மேலும் `Super + Ctrl + Space`) |
| `Super + Backspace` | சாளரத்தில் வெளிப்படைத்தன்மையை மாற்று |
| `Super + Ctrl + Backspace` | ஒற்றை சாளர சதுர விகிதத்தை மாற்று |

கூடுதல் பின்னணி படங்கள் `~/.config/omarchy/backgrounds/<theme name>` இல் உள்ளன. Omarchy மெனுவில் _நிறுவு > பாணி > பின்னணி_ வழியாகவும் கிடைக்கும்.

அனைத்து பாணி விருப்பங்களும் Omarchy மெனுவில் (`Super + Space`) _பாணி_ இன் கீழும் கிடைக்கும்.

## Tmux

முன்னொட்டு விசை `Ctrl + Space` ஆகும் (`Ctrl + B` வும் வேலை செய்யும்). இந்த பிணைப்புகளை `~/.config/tmux/tmux.conf` இல் மாற்றலாம்.

### பலகங்கள்

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Prefix + v` | பலகத்தை அருகில் பிரி (செங்குத்து) |
| `Prefix + h` | பலகத்தை கீழே பிரி (கிடைமட்டம்) |
| `Prefix + x` | பலகத்தை அழி |
| `Prefix + z` | பலக பெரிதாக்கத்தை மாற்று (முழு திரை) |

| `Ctrl + Alt + Arrows` | பலகங்களுக்கு இடையே நகரவும் |
| `Ctrl + Alt + Shift + Arrows` | பலகங்களின் அளவை மாற்று |

### Tmux தளவமைப்பு செயல்பாடுகள்

இந்த செயல்பாடுகள் Tmux அமர்வுக்குள் இயக்கப்பட வேண்டும்.

| கட்டளை | செயல்பாடு |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | எடிட்டர், AI மற்றும் முனையத்துடன் டெவ் தளவமைப்பை உருவாக்கு |
| `tdlm <ai> [<second_ai>]` | துணை அடைவு ஒன்றுக்கு டெவ் தளவமைப்பை உருவாக்கு |
| `tsl <count> <command>` | பல பலக திரள் தளவமைப்பை உருவாக்கு |
