# ஹாட்கீகள்

அனைத்து முக்கிய விசைப்பலகை பிணைப்புகளையும் `Super + K` மூலம் காணலாம் (Tmux பிணைப்புகள் `Super + Alt + K` மூலமும் Herdr பிணைப்புகள் `Super + Ctrl + K` மூலமும்).

## ஹாட்கீகள் எவ்வாறு அமைக்கப்பட்டுள்ளன

ஒவ்வொரு ஹாட்கீயும் அதன் மாற்றி விசைகளால் நிர்ணயிக்கப்படும் ஒரு தளத்தில் அமர்ந்துள்ளது, ஒவ்வொரு தளத்திற்கும் ஒரே ஒரு வேலை உள்ளது. அதுதான் ஹாட்கீகள் ஒன்றோடொன்று குழம்பிப் போகாமல் தடுக்கிறது, மேலும் பொதுவாக எது எங்கே இருக்கிறது என்று நீங்கள் யூகிக்க முடியும் என்பதையும் அது குறிக்கிறது.

| தளம் | அங்கு என்ன உள்ளது | எடுத்துக்காட்டுகள் |
| --- | --- | --- |
| `Super + key` | அமைப்பு: சாளரங்கள், பணியிடங்கள், தளவமைப்புகள் மற்றும் முக்கிய மெனுக்கள் | `Super + Space` Omarchy மெனு, `Super + W` சாளரத்தை மூடவும், `Super + F` முழுத்திரை |
| `Super + Shift + key` | பயன்பாடுகள் | `Super + Shift + B` உலாவி, `Super + Shift + E` மின்னஞ்சல், `Super + Shift + N` எடிட்டர் |
| `Super + Ctrl + key` | பேனல்கள் மற்றும் அமைப்பு மெனுக்கள் | `Super + Ctrl + A` ஆடியோ, `Super + Ctrl + N` நெட்வொர்க், `Super + Ctrl + C` பிடிப்பு மெனு |
| `Super + Ctrl + Alt + key` | விரைவு செயல்கள் மற்றும் அறிவிப்புகள் | `Super + Ctrl + Alt + T` நேரத்தைக் காட்டவும், `Super + Ctrl + Alt + B` பேட்டரி, `Super + Ctrl + Alt + C` திரைப்பிடிப்பு |

ஒரு ஹாட்கீயில் `Alt` ஐச் சேர்ப்பது அதே விஷயத்தின் ஒரு மாறுபாட்டை உங்களுக்குத் தருகிறது, தொடர்பில்லாத எதையும் ஒருபோதும் தராது:

- `Super + Shift + B` உலாவியைத் திறக்கிறது; `Super + Shift + Alt + B` ஒரு தனிப்பட்ட சாளரத்தைத் திறக்கிறது
- `Super + Shift + E` மின்னஞ்சலைத் திறக்கிறது; `Super + Shift + Alt + E` புதிய ஒன்றைத் தொடங்குகிறது
- `Super + F` முழுத்திரைக்குச் செல்கிறது; `Super + Alt + F` முழு அகலத்திற்குச் செல்கிறது
- `Super + Ctrl + C` பிடிப்பு மெனுவைத் திறக்கிறது; `Super + Ctrl + Alt + C` மெனுவைத் தவிர்த்து திரைப்பிடிப்பை எடுக்கிறது

ஒரு ஹாட்கீயைச் சேர்க்கும் போது:

1. அது என்ன செய்கிறது என்பதிலிருந்து தளத்தைத் தேர்ந்தெடுக்கவும், பின்னர் விசையைத் தேர்ந்தெடுக்கவும்.
2. இடம் உருவாக்க ஏற்கனவே உள்ள ஹாட்கீயை நகர்த்தாதீர்கள். சரியான தளத்தில் காலியான விசையைக் கண்டறியவும்.
3. `Alt` ஐ அது இல்லாத ஹாட்கீயின் மாறுபாட்டிற்கு மட்டுமே பயன்படுத்தவும்.

சில ஹாட்கீகள் வசதியாக இருப்பதால் இந்த விதிகளை மீறுகின்றன. அம்புக்குறி அல்லது `Tab` உடன் `Shift` ஒரு பயன்பாட்டைத் திறப்பதற்குப் பதிலாக நகர்த்துகிறது அல்லது தலைகீழாக்குகிறது, மேலும் `Print`, மீடியா விசைகள், `Alt + Tab` மற்றும் `Ctrl + Alt + Del` எல்லா இடங்களிலும் உள்ளது போலவே வேலை செய்கின்றன. அவை விதிவிலக்குகள், நகலெடுக்க வேண்டிய முறைகள் அல்ல.

ஒரு இயல்புநிலை உங்களுக்குப் பொருந்தவில்லை என்றால் (Windows இல் உள்ளது போல திரைப்பிடிப்புகளுக்கு `Super + Shift + S` வேண்டும் என்று வைத்துக்கொள்வோம்), அதை `~/.config/hypr/bindings.lua` இல் மீண்டும் பிணைக்கவும்.

தொடுதட்டில், மூன்று மற்றும் நான்கு விரல் தேய்ப்புகள் பணியிடங்களை மாற்றுகின்றன, சாளரங்களை நகர்த்துகின்றன, மெனுவையும் Quake கன்சோலையும் திறக்கின்றன; சைகைகளுக்கு [விசைப்பலகை, சுட்டி மற்றும் தொடுதட்டு](34-keyboard-mouse-trackpad.md) ஐக் காணவும்.

அளவு மாற்றம் 0 க்கு வலதுபுறம் உள்ள இரண்டு விசைகளைப் பயன்படுத்துகிறது, உங்கள் விசைப்பலகை அவற்றில் எதை அச்சிட்டிருந்தாலும்: US விசைப்பலகைகளில் `-` மற்றும் `=`, டேனிஷ் மற்றும் ஸ்வீடிஷில் `+` மற்றும் `´`, நார்வேஜியனில் `+` மற்றும் `\`, ஜெர்மனில் `ß` மற்றும் `´`, ஸ்பானிஷில் `'` மற்றும் `¡`, மற்றும் ஜப்பானிய (JIS) இல் `-` மற்றும் `^`. `Super + K` அவற்றை உங்கள் விசைப்பலகை அச்சிட்டபடி பட்டியலிடுகிறது. JIS இல், `Super + ^` என்பது `Super + Equal`, அதே நேரத்தில் `Super + Shift + -` (இது `=` ஐத் தட்டச்சு செய்கிறது) என்பது `Super + Shift + Minus`. மானிட்டர் அளவிடலும் கடவுச்சொல் மேலாளரும் `/` ஐப் பயன்படுத்துகின்றன; பெரும்பாலான ஐரோப்பிய தளவமைப்புகள் போல `/` ஐ Shift உடன் மட்டுமே தட்டச்சு செய்யும் தளவமைப்புகளில், அவை அதற்குப் பதிலாக வலது Shift க்கு இடதுபுறம் உள்ள விசையைப் பயன்படுத்துகின்றன (டேனிஷ் மற்றும் ஜெர்மனில் `-`).

## Tmux

முன்னொட்டு விசை `Ctrl + Space` (`Ctrl + B` ம் வேலை செய்கிறது). இந்த பிணைப்புகளை `~/.config/tmux/tmux.conf` இல் மாற்றலாம்.

### பேன்கள்

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Prefix + v` | பேனை பக்கவாட்டில் பிரிக்கவும் (செங்குத்து) |
| `Prefix + h` | பேனை கீழே பிரிக்கவும் (கிடைமட்டம்) |
| `Prefix + x` | பேனை அழிக்கவும் |
| `Prefix + z` | பேன் பெரிதாக்கத்தை மாற்றவும் (முழுத்திரை) |
| `Alt + Enter` | பேனை கீழே பிரிக்கவும் (முன்னொட்டு இல்லாமல்) |
| `Alt + Shift + Enter` | பேனை பக்கவாட்டில் பிரிக்கவும் (முன்னொட்டு இல்லாமல்) |
| `Alt + Escape` | பேனை அழிக்கவும் (முன்னொட்டு இல்லாமல்) |
| `Ctrl + Alt + Arrows` | பேன்களுக்கு இடையே நகரவும் |
| `Ctrl + Alt + Shift + Arrows` | பேன்களின் அளவை மாற்றவும் |

### சாளரங்கள்

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Prefix + c` | புதிய சாளரம் |
| `Prefix + k` | சாளரத்தை அழிக்கவும் |
| `Prefix + r` | சாளரத்திற்கு மறுபெயரிடவும் |
| `Alt + 1-9` | குறிப்பிட்ட சாளரத்திற்குச் செல்லவும் |
| `Alt + Arrow Left/Right` | சாளரங்களுக்கு இடையே நகரவும் |
| `Alt + Shift + Arrow Left/Right` | சாளரத்தை இடது/வலது நகர்த்தவும் |

### அமர்வுகள்

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Prefix + C` | புதிய அமர்வு |
| `Prefix + K` | அமர்வை அழிக்கவும் |
| `Prefix + R` | அமர்வுக்கு மறுபெயரிடவும் |
| `Prefix + N` | அடுத்த அமர்வு |
| `Prefix + P` | முந்தைய அமர்வு |
| `Alt + Arrow Up/Down` | அமர்வுகளுக்கு இடையே நகரவும் |
| `Prefix + s` | அமர்வுகளைப் பட்டியலிடவும் |
| `Prefix + d` | அமர்விலிருந்து பிரியவும் |

### நகல் பயன்முறை (vi-பாணி)

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Prefix + [` | நகல் பயன்முறையில் நுழையவும் |
| `v` | தேர்வைத் தொடங்கவும் (நகல் பயன்முறையில்) |
| `y` | தேர்வை நகலெடுக்கவும் (நகல் பயன்முறையில்) |

### பொது

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Prefix + q` | கட்டமைப்பை மீண்டும் ஏற்றவும் |
| `Prefix + ?` | Tmux விசைப்பிணைப்புகளைக் காட்டவும் |
| `Prefix + :` | கட்டளை வரியில் |

### Tmux தளவமைப்பு செயல்பாடுகள்

இந்த செயல்பாடுகள் ஒரு Tmux அமர்வுக்குள் இயக்கப்பட வேண்டும்.

| கட்டளை | செயல்பாடு |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | எடிட்டர், AI மற்றும் முனையத்துடன் dev தளவமைப்பை உருவாக்கவும் |
| `tdlm <ai> [<second_ai>]` | ஒவ்வொரு துணை அடைவுக்கும் dev தளவமைப்பை உருவாக்கவும் |
| `tsl <count> <command>` | பல-பேன் swarm தளவமைப்பை உருவாக்கவும் |
