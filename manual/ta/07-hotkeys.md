# ஹாட்கீகள்

`Super + K` மூலம் அனைத்து முக்கிய விசைப்பலகை பிணைப்புகளையும் பார்க்கலாம் (Tmux பிணைப்புகள் `Super + Alt + K` மூலமும் Herdr பிணைப்புகள் `Super + Ctrl + K` மூலமும்).

## ஹாட்கீகள் எவ்வாறு அமைக்கப்பட்டுள்ளன

ஒவ்வொரு ஹாட்கீயும் அதன் மாற்றி விசைகளால் அமைக்கப்படும் ஒரு தளத்தில் அமர்ந்துள்ளது, ஒவ்வொரு தளத்திற்கும் ஒரு வேலை உள்ளது. ஹாட்கீகள் ஒன்றோடொன்று குழம்பிப் போகாமல் இருப்பது அதனால்தான், மேலும் பொதுவாக ஒன்று எங்கே இருக்கிறது என்று நீங்கள் யூகிக்க முடிவதும் அதனால்தான்.

| தளம் | அங்கே என்ன இருக்கிறது | எடுத்துக்காட்டுகள் |
| --- | --- | --- |
| `Super + key` | அமைப்பு: சாளரங்கள், பணிவெளிகள், தளவமைப்புகள் மற்றும் முக்கிய மெனுக்கள் | `Super + Space` Omarchy மெனு, `Super + W` சாளரத்தை மூடு, `Super + F` முழுத் திரை |
| `Super + Shift + key` | பயன்பாடுகள் | `Super + Shift + B` உலாவி, `Super + Shift + E` மின்னஞ்சல், `Super + Shift + N` எடிட்டர் |
| `Super + Ctrl + key` | பேனல்கள் மற்றும் அமைப்பு மெனுக்கள் | `Super + Ctrl + A` ஆடியோ, `Super + Ctrl + N` நெட்வொர்க், `Super + Ctrl + C` பிடிப்பு மெனு |
| `Super + Ctrl + Alt + key` | விரைவுச் செயல்கள் மற்றும் அறிவிப்புகள் | `Super + Ctrl + Alt + T` நேரத்தைக் காட்டு, `Super + Ctrl + Alt + B` பேட்டரி, `Super + Ctrl + Alt + C` ஸ்கிரீன்ஷாட் |

ஒரு ஹாட்கீயில் `Alt` சேர்ப்பது அதே விஷயத்தின் ஒரு மாறுபாட்டை உங்களுக்குத் தருகிறது, தொடர்பில்லாத வேறு எதையும் ஒருபோதும் தராது:

- `Super + Shift + B` உலாவியைத் திறக்கிறது; `Super + Shift + Alt + B` தனிப்பட்ட சாளரத்தைத் திறக்கிறது
- `Super + Shift + E` மின்னஞ்சலைத் திறக்கிறது; `Super + Shift + Alt + E` புதிய ஒன்றைத் தொடங்குகிறது
- `Super + F` முழுத் திரைக்குச் செல்கிறது; `Super + Alt + F` முழு அகலத்திற்குச் செல்கிறது
- `Super + Ctrl + C` பிடிப்பு மெனுவைத் திறக்கிறது; `Super + Ctrl + Alt + C` மெனுவைத் தவிர்த்து ஸ்கிரீன்ஷாட் எடுக்கிறது

ஹாட்கீயைச் சேர்க்கும்போது:

1. அது என்ன செய்கிறது என்பதிலிருந்து தளத்தைத் தேர்ந்தெடுங்கள், பிறகு விசையைத் தேர்ந்தெடுங்கள்.
2. இடம் ஒதுக்குவதற்காக ஏற்கனவே உள்ள ஹாட்கீயை நகர்த்தாதீர்கள். சரியான தளத்தில் காலியாக உள்ள விசையைக் கண்டறியுங்கள்.
3. `Alt` ஐ அது இல்லாத ஹாட்கீயின் மாறுபாட்டிற்கு மட்டுமே பயன்படுத்துங்கள்.

சில ஹாட்கீகள் வசதியாக இருப்பதால் இந்த விதிகளை மீறுகின்றன. அம்புக்குறி அல்லது `Tab` உடன் `Shift` சேர்ப்பது பயன்பாட்டைத் திறப்பதற்குப் பதிலாக நகர்த்துகிறது அல்லது தலைகீழாக்குகிறது, மேலும் `Print`, மீடியா விசைகள், `Alt + Tab`, மற்றும் `Ctrl + Alt + Del` ஆகியவை மற்ற எல்லா இடங்களிலும் செயல்படுவது போலவே செயல்படுகின்றன. அவை விதிவிலக்குகள், நகலெடுக்க வேண்டிய வடிவங்கள் அல்ல.

இயல்புநிலை உங்களுக்குப் பொருந்தவில்லை என்றால் (Windows இல் போல ஸ்கிரீன்ஷாட்களுக்கு `Super + Shift + S` வேண்டும் என்று வைத்துக்கொள்வோம்), அதை `~/.config/hypr/bindings.lua` இல் மீண்டும் பிணைக்கவும்.

அளவுமாற்றக் குறுக்குவழிகள், விசைப்பலகையில் அச்சிடப்பட்ட எழுத்துக்களைப் பொருட்படுத்தாமல், இயற்பியல் விசைகளான `code:20` மற்றும் `code:21` (XKB `<AE11>` மற்றும் `<AE12>`) ஆகியவற்றைப் பயன்படுத்துகின்றன. US விசைப்பலகைகளில் இந்த விசைகள் `-` மற்றும் `=`; ஜப்பானிய (JIS) விசைப்பலகைகளில் அவை `-` மற்றும் `^`; ஸ்பானிய விசைப்பலகைகளில் அவை `'` மற்றும் `¡`. JIS இல், `Super + ^` என்பது `Super + Equal` ஆகும், அதே நேரத்தில் `Super + Shift + -` (இது `=` ஐத் தட்டச்சு செய்கிறது) என்பது `Super + Shift + Minus` ஆகும்.

## Tmux

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |

## Ghostty டெர்மினல்

Ghostty டெர்மினல் Omarchy மெனு வழியாக _நிறுவு > டெர்மினல்_ ஐப் பயன்படுத்தி நிறுவப்படுகிறது.

| ஹாட்கீ                  | செயல்பாடு              |
| ----------------------- | --------------------- |
| `Ctrl + Shift + E` | கீழே புதிய பிரிவு |
| `Ctrl + Shift + O` | அருகில் புதிய பிரிவு |
| `Ctrl + Alt + Arrows` | பிரிவுகளுக்கு இடையே நகர் |
| `Super + Ctrl + Shift + Arrows` | பிரிவை 10 வரிகள் அளவு மாற்று |
| `Super + Ctrl + Shift + Alt + Arrows` | பிரிவை 100 வரிகள் அளவு மாற்று |
| `Ctrl + Shift + T` | புதிய தாவல்  |
| `Ctrl + Shift + Arrows` | தாவல்களுக்கு இடையே நகர் |
| `Alt + Numbers` | குறிப்பிட்ட தாவலுக்குச் செல் |
| `Shift + Pg Up/Down` | வரலாற்றை உருட்டு |
| `Ctrl + Left mouse` | இணைப்பை உலாவியில் திற |

## கோப்பு மேலாளர்

| ஹாட்கீ              | செயல்பாடு                       |
| ------------------- | ------------------------------ |
| `Ctrl + L`            | பாதைக்குச் செல்                     |
| `Space`               | கோப்பை முன்னோட்டமிடு (அம்புக்குறிகள் வழிசெலுத்தும்) |
| `Alt + Up`       | பெற்றோர் கோப்புறைக்கு மேலே செல்        |

## விரைவு நிறைவுகள்

| ஹாட்கீ       | நிறைவு       |
| ------------ |  ---------- |
| `Shift + CapsLock Space Space` | — (mdash)   |
| `Shift + CapsLock Space N` | உங்கள் பெயர் (அமைப்பில் உள்ளிட்டபடி)  |
| `Shift + CapsLock Space E` | உங்கள் மின்னஞ்சல் (அமைப்பில் உள்ளிட்டபடி)  |

`~/.XCompose` ஐத் திருத்துவதன் மூலம் உங்களுடைய மேலும் பலவற்றைச் சேர்க்கலாம், பிறகு மாற்றங்கள் எடுத்துக்கொள்ளப்பட டெர்மினலில் `omarchy-restart-xcompose` ஐ இயக்கவும்.
