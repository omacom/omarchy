# ஹாட்கீகள்

நீங்கள் அனைத்து முக்கிய விசைப்பலகை பிணைப்புகளையும் `Super + K` (Tmux பிணைப்புகள் `Super + Alt + K` உடனும் Herdr பிணைப்புகள் `Super + Ctrl + K` உடனும்) கொண்டு பார்க்கலாம்.

## ஹாட்கீகள் எப்படி அமைக்கப்பட்டுள்ளன

ஒவ்வொரு ஹாட்கீயும் அதன் மாற்றி விசைகளால் நிர்ணயிக்கப்படும் ஒரு தளத்தில் அமர்ந்திருக்கிறது, ஒவ்வொரு தளத்திற்கும் ஒரு வேலை உண்டு. அதுதான் ஹாட்கீகள் ஒன்றோடொன்று குழம்பாமல் இருக்க வைக்கிறது, மேலும் பொதுவாக ஒன்று எங்கே இருக்கிறது என்று நீங்கள் யூகிக்க முடியும் என்பதையும் அது குறிக்கிறது.

| தளம் | அங்கு என்ன இருக்கிறது | எடுத்துக்காட்டுகள் |
| --- | --- | --- |
| `Super + key` | அமைப்பு: சாளரங்கள், பணியிடங்கள், தளவமைப்புகள், மற்றும் முக்கிய மெனுக்கள் | `Super + Space` Omarchy மெனு, `Super + W` சாளரத்தை மூடு, `Super + F` முழுத் திரை |
| `Super + Shift + key` | பயன்பாடுகள் | `Super + Shift + B` உலாவி, `Super + Shift + E` மின்னஞ்சல், `Super + Shift + N` எடிட்டர் |
| `Super + Ctrl + key` | பேனல்கள் மற்றும் அமைப்பு மெனுக்கள் | `Super + Ctrl + A` ஆடியோ, `Super + Ctrl + N` நெட்வொர்க், `Super + Ctrl + C` பிடிப்பு மெனு |
| `Super + Ctrl + Alt + key` | விரைவுச் செயல்கள் மற்றும் அறிவிப்புகள் | `Super + Ctrl + Alt + T` நேரத்தைக் காட்டு, `Super + Ctrl + Alt + B` பேட்டரி, `Super + Ctrl + Alt + C` ஸ்கிரீன்ஷாட் |

ஒரு ஹாட்கீயில் `Alt` சேர்ப்பது உங்களுக்கு அதே விஷயத்தின் ஒரு மாறுபாட்டைத் தருகிறது, ஒருபோதும் தொடர்பில்லாத ஒன்றை அல்ல:

- `Super + Shift + B` உலாவியைத் திறக்கிறது; `Super + Shift + Alt + B` தனிப்பட்ட சாளரத்தைத் திறக்கிறது
- `Super + Shift + E` மின்னஞ்சலைத் திறக்கிறது; `Super + Shift + Alt + E` புதிய ஒன்றைத் தொடங்குகிறது
- `Super + F` முழுத் திரைக்குச் செல்கிறது; `Super + Alt + F` முழு அகலத்திற்குச் செல்கிறது
- `Super + Ctrl + C` பிடிப்பு மெனுவைத் திறக்கிறது; `Super + Ctrl + Alt + C` மெனுவைத் தவிர்த்து ஸ்கிரீன்ஷாட் எடுக்கிறது

ஒரு ஹாட்கீயைச் சேர்க்கும்போது:

1. அது செய்வதை வைத்துத் தளத்தைத் தேர்ந்தெடுங்கள், பிறகு விசையைத் தேர்ந்தெடுங்கள்.
2. இடம் ஒதுக்க ஏற்கனவே உள்ள ஹாட்கீயை நகர்த்தாதீர்கள். சரியான தளத்தில் காலியான விசையைக் கண்டறியுங்கள்.
3. அது இல்லாத ஹாட்கீயின் மாறுபாட்டிற்கு மட்டுமே `Alt` ஐப் பயன்படுத்துங்கள்.

சில ஹாட்கீகள் வசதியாக இருப்பதால் இந்த விதிகளை மீறுகின்றன. அம்புக்குறி அல்லது `Tab` உடன் `Shift` என்பது பயன்பாட்டைத் திறப்பதற்குப் பதிலாக நகர்த்துகிறது அல்லது தலைகீழாக்குகிறது, மேலும் `Print`, மீடியா விசைகள், `Alt + Tab`, மற்றும் `Ctrl + Alt + Del` ஆகியவை மற்ற எல்லா இடங்களிலும் செயல்படுவது போலவே செயல்படுகின்றன. அவை விதிவிலக்குகள், நகலெடுக்க வேண்டிய வடிவங்கள் அல்ல.

ஒரு இயல்புநிலை உங்களுக்குப் பொருந்தவில்லை என்றால் (எடுத்துக்காட்டாக Windows இல் போல ஸ்கிரீன்ஷாட்களுக்கு `Super + Shift + S` வேண்டும் என்று நீங்கள் விரும்பினால்), அதை `~/.config/hypr/bindings.lua` இல் மீண்டும் பிணைக்கவும்.

டச்பேடில், மூன்று மற்றும் நான்கு விரல் ஸ்வைப்கள் பணியிடங்களை மாற்றுகின்றன, சாளரங்களை நகர்த்துகின்றன, மேலும் மெனுவையும் Quake கன்சோலையும் திறக்கின்றன; சைகைகளுக்கு [விசைப்பலகை, சுட்டி, மற்றும் டிராக்பேட்](34-keyboard-mouse-trackpad.md) ஐப் பார்க்கவும்.

அளவுமாற்றக் குறுக்குவழிகள் விசைப்பலகையில் அச்சிடப்பட்ட எழுத்துகளைப் பொருட்படுத்தாமல், இயற்பியல் விசைகள் `code:20` மற்றும் `code:21` (XKB `<AE11>` மற்றும் `<AE12>`) ஐப் பயன்படுத்துகின்றன. US விசைப்பலகைகளில் இந்த விசைகள் `-` மற்றும் `=`; ஜப்பானிய (JIS) விசைப்பலகைகளில் அவை `-` மற்றும் `^`; ஸ்பானிஷ் விசைப்பலகைகளில் அவை `'` மற்றும் `¡`. JIS இல், `Super + ^` என்பது `Super + Equal`, அதே சமயம் `Super + Shift + -` (இது `=` ஐத் தட்டச்சு செய்கிறது) என்பது `Super + Shift + Minus`.

### Tmux தளவமைப்புச் செயல்பாடுகள்

இந்தச் செயல்பாடுகள் Tmux அமர்விற்குள் இயக்கப்பட வேண்டும்.

| கட்டளை | செயல்பாடு |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | எடிட்டர், AI, மற்றும் டெர்மினலுடன் dev தளவமைப்பை உருவாக்கு |
| `tdlm <ai> [<second_ai>]` | ஒவ்வொரு துணை அடைவுக்கும் dev தளவமைப்பை உருவாக்கு |
| `tsl <count> <command>` | பல-பேன் swarm தளவமைப்பை உருவாக்கு |
