# நினைவூட்டல்கள்

Omarchy-இல் கவுண்டவுன் டைமர் மற்றும் ஒரு செய்தியின் அடிப்படையில் எளிய நினைவூட்டல்களை அமைக்க உள்ளமைக்கப்பட்ட வழி உள்ளது. இதை `Super + Ctrl + R` வழியாகச் செய்யலாம், அமைக்கப்பட்ட அனைத்தையும் `Super + Ctrl + Alt + R` வழியாகப் பார்க்கலாம், மற்றும் அனைத்தையும் `Super + Ctrl + Shift + R` வழியாக அழிக்கலாம். எல்லாம் _தூண்டு > நினைவூட்டல்_ வழியாகவும் அணுகக் கிடைக்கிறது. `omarchy reminder 7 'Tea ready'` என CLI-ஐயும் பயன்படுத்தலாம்.
