# Mac அல்லது Windows-இலிருந்து வருதல்

நீங்கள் பல ஆண்டுகளாக macOS அல்லது Windows-இல் கழித்திருந்தால், உங்கள் மூளை தான் எப்போதாவது கற்றுக்கொண்டதையே மறந்துவிட்ட நூறு விஷயங்களை உங்கள் விரல்கள் அறியும். இந்த அத்தியாயம்தான் அந்த மொழிபெயர்ப்பு அடுக்கு: Omarchy-இல் அந்த உள்ளுணர்வுகள் எங்கே போகின்றன. அம்சங்களே வேறு இடங்களில் ஆழமாக விளக்கப்பட்டுள்ளன — இது வெறும் வரைபடம் மட்டுமே.

### Super தான் எல்லாவற்றின் மையமும்

Cmd அல்லது Windows விசையைச் சுற்றி நீங்கள் உருவாக்கிக்கொண்ட அனைத்து தசை நினைவகமும் ஒரே ஒரு விசைக்கு மாறுகிறது: Super. அதுதான் PC விசைப்பலகையில் உள்ள Windows விசை, மேலும் Omarchy-இல் கிட்டத்தட்ட ஒவ்வொரு hotkey-இற்கும் அதுவே நங்கூரம்.

உங்கள் Spotlight அல்லது Raycast அல்லது Start-menu உள்ளுணர்வு `Super + Space` ஆகிறது. அது Omarchy மெனுவைத் திறக்கிறது, அது செயலிகளைத் தொடங்குகிறது, அமைப்புகளை மாற்றுகிறது, மென்பொருளை நிறுவுகிறது, திரையைப் படம்பிடிக்கிறது — கிட்டத்தட்ட எல்லாவற்றையும் செய்கிறது. வடிகட்டத் தட்டச்சு செய்யத் தொடங்குங்கள். `Super + Alt + Space` ஒவ்வொரு செயலியையும் ஒரே கட்டத்தில் காட்டுகிறது, Launchpad செய்வது போலவே. [வழிசெலுத்தல்](04-navigation.md) ஐப் பாருங்கள்.

### டெஸ்க்டாப் ஐகான்கள் இல்லை, டாக் வழியில் நிற்காது

டெஸ்க்டாப்பில் அடுக்கி வைக்க ஐகான்கள் இல்லை, மேலும் ஒரு பணியிடத்தில் ஒரு சாளரம் வந்தவுடன் டாக் மறைந்துவிடும், நீங்கள் சுட்டியைத் திரையின் அதன் விளிம்புக்குத் தள்ளும் வரை, நீங்கள் அதை நகர்த்தாவிட்டால் கீழ் விளிம்புக்கு ( [வழிசெலுத்தல்](04-navigation.md) ஐப் பாருங்கள்). செயலிகள் ஒரு hotkey-இலிருந்து தொடங்குகின்றன (டெர்மினலுக்கு `Super + Return`, உலாவிக்கு `Super + Shift + Return`, மேலும் வரைபடமாக்கப்பட்ட எல்லாவற்றின் பட்டியலுக்கும் `Super + K`) அல்லது மெனுவிலிருந்து தொடங்குகின்றன. நிலைத்திருக்கும் ஒரே UI பகுதி [மேல் பட்டை](05-the-top-bar.md) தான், அது முன்பு menu bar, system tray, மற்றும் Notification Center உங்களுக்காகச் செய்ததை எல்லாம் செய்கிறது — மேலும் அதில் உள்ள கிட்டத்தட்ட ஒவ்வொரு widget-உம் இடது, வலது, மற்றும் நடு கிளிக்கில் ஏதாவது செய்கிறது.

### சாளரங்கள் தாமாகவே தம்மை வைத்துக்கொள்கின்றன

மிகப் பெரிய மனநிலை மாற்றம்: நீங்கள் சாளரங்களைச் சுற்றி இழுக்கவோ அல்லது திரையின் பாதிகளுக்கு ஒட்டவோ இல்லை. ஒரு சாளரத்தைத் திறந்தால் அது முழுத் திரையையும் எடுத்துக்கொள்கிறது. இரண்டாவதைத் திறந்தால் அவை அதைப் பிரித்துக்கொள்கின்றன. நீங்கள் ஒருபோதும் ஒரு சாளரத்தை மற்றொன்றின் கீழிருந்து தேடி எடுக்க வேண்டியதில்லை, ஏனென்றால் சாளரங்கள் ஒன்றின் மேல் ஒன்று மேற்பொருந்துவதில்லை.

உங்களுக்கு உண்மையிலேயே ஒரு மிதக்கும் சாளரம் தேவைப்படும்போது, `Super + T` செயலில் உள்ளதை டைலிங்கிலிருந்து வெளியே மாற்றுகிறது (மீண்டும் உள்ளேயும்). ஆனால் முதலில் டைலிங்கிற்கு ஒரு உண்மையான வாய்ப்பு கொடுங்கள் — அதுதான் இந்த முழு விஷயத்தின் இதயமும். [வழிசெலுத்தல்](04-navigation.md) அதன் வழியாக உங்களை அழைத்துச் செல்கிறது.

பணியிடங்கள் பழக்கமானவையாக உணரும்: அவை macOS Spaces அல்லது Windows virtual desktops தான், ஆனால் நீங்கள் அவற்றை உண்மையிலேயே பயன்படுத்துவீர்கள், ஏனென்றால் `Super + 1/2/3/4` நேரடியாக ஒன்றுக்குத் தாவுகிறது மற்றும் `Super + Shift + 1/2/3/4` செயலில் உள்ள சாளரத்தை அங்கே அனுப்புகிறது. அனிமேஷன் தாமதம் இல்லை, வெறும் உடனடித் தாவல்கள் மட்டுமே. இதன் பொருள், நீங்கள் முன்பு அதற்குப் பழகியிருந்தாலும் கூட, உங்களுக்குப் பல மானிட்டர்கள் கூடத் தேவைப்படாமல் போகலாம் என்பதாகும்.

### நகலெடுத்தலும் ஒட்டுதலும் வெறுமனே வேலை செய்கின்றன

Mac-இல் உங்களிடம் எல்லா இடங்களிலும் Cmd + C இருந்தது. Windows-இல் உங்களிடம் எல்லா இடங்களிலும் Ctrl + C இருந்தது — டெர்மினலைத் தவிர, அங்கே அது உங்கள் நிரலைக் கொன்றுவிடும். Omarchy உங்களுக்கு `Super + C`, `Super + X`, மற்றும் `Super + V` ஐத் தருகிறது, மேலும் அவை டெர்மினல் உட்பட எல்லா இடங்களிலும் வேலை செய்கின்றன. shell-இற்காகத் தனியாக ஒரு உள்ளுணர்வைக் கற்றுக்கொள்ள வேண்டியதில்லை.

Windows நண்பர்களே: உங்கள் Win + V கிளிப்போர்டு வரலாறு `Super + Ctrl + V` இல் உள்ளது, மேலும் அது உரையுடன் படங்களையும் வைத்திருக்கிறது. [ஒருங்கிணைந்த கிளிப்போர்டு & வரலாறு](08-unified-clipboard-history.md) ஐப் பாருங்கள்.

### சில விஷயங்கள் உண்மையிலேயே வேறுபட்டவை

பல அமைப்புகள் நீங்கள் கிளிக் செய்து செல்லும் பேனல்களில் அல்ல, நீங்கள் திருத்தும் உரைக் கோப்புகளில் உள்ளன. ஒவ்வொரு மாற்றத்தையும் பார்க்கவும், உங்கள் அடுத்த கணினிக்கு நகலெடுக்கவும், version control-இல் வைக்கவும் முடியும் என்பதை நீங்கள் உணரும் வரை அது பழமையானதாகத் தோன்றும். _Setup_ மெனு உங்களை நேரடியாகச் சரியான கோப்புக்குள் கொண்டு செல்கிறது, மேலும் நீங்கள் முடித்ததும் மறுதொடக்கம் செய்ய வேண்டியதை எல்லாம் மறுதொடக்கம் செய்கிறது.

புதுப்பிப்புகள் ஒரே ஒரு கட்டளை வழியாக வருகின்றன — _Update > Omarchy_ — அது Omarchy-ஐயும் கணினியில் உள்ள ஒவ்வொரு தொகுப்பையும் புதுப்பிக்கிறது, முதலில் ஒரு ஸ்னாப்ஷாட்டை எடுத்துக்கொண்டு. சீரற்ற நேரங்களில் உங்களைத் தொந்தரவு செய்யும் செயலிக்குச் செயலி புதுப்பிப்பாளர்கள் இல்லை. [புதுப்பிப்புகள்](30-updates.md) ஐப் பாருங்கள்.

மென்பொருள் பதிவிறக்கப்பட்ட நிறுவிகளிலிருந்து அல்ல, ஒரு தொகுப்பு மேலாளரிடமிருந்து வருகிறது.

மேலும் நீங்கள் ஒரு சாளரத்தை மூடும்போது, செயலி உண்மையிலேயே வெளியேறிவிடும். சாளரங்கள் எதுவும் இல்லாமல் நிரல் தொடர்ந்து இயங்கும் macOS தத்தளிப்பு நிலை இல்லை. `Super + W` — அல்லது, நீங்கள் வந்தடைந்த விரல் நினைவகம் அதுதான் என்றால், `Super + Q` — என்றால் போய்விட்டது என்று பொருள்.

### Mac வன்பொருளில்

Omarchy Intel Macகளில் நன்றாக இயங்குகிறது, மேலும் Omarchy for Apple Silicon உடன் M1, M2 மற்றும் M3 Macகளிலும் நன்றாக இயங்குகிறது. [Mac ஆதரவு](44-mac-support.md) ஐப் பாருங்கள். மேலும் விசைப்பலகை உங்களிடம் கனிவாக நடந்துகொள்கிறது: Omarchy எதையும் மறுவரைபடமாக்குவதில்லை, மேலும் Linux Command விசையை Super ஆகக் கருதுகிறது, எனவே Cmd எப்போதும் இருந்த இடத்திலேயே Super அமர்ந்திருக்கிறது. உங்கள் கட்டைவிரல் இந்த மாற்றத்தைக் கவனிக்கவே கவனிக்காது.

### அதற்கு இரண்டு வாரங்கள் கொடுங்கள்

உள்ளுணர்வுகள் நீங்கள் நினைப்பதை விட வேகமாக மாறுகின்றன. [hotkeys](07-hotkeys.md) அத்தியாயத்தை ஒருமுறை மேலோட்டமாகப் பாருங்கள், மேலும் ஒரு பிணைப்பில் நீங்கள் தடுமாறும்போதெல்லாம், `Super + K` ஐ அழுத்துங்கள் — அது அவற்றை எல்லாம் உங்களுக்குக் காட்டுகிறது. நீங்கள் உண்மையிலேயே மனப்பாடம் செய்ய வேண்டிய ஒரே hotkey அதுதான்.
