# Mac அல்லது Windows-லிருந்து வருபவர்களுக்கு

நீங்கள் பல ஆண்டுகள் macOS அல்லது Windows-ல் கழித்திருந்தால், உங்கள் மூளை தான் கற்றுக்கொண்டதையே மறந்துவிட்ட நூறு விஷயங்களை உங்கள் விரல்கள் அறியும். இந்த அத்தியாயம்தான் மொழிபெயர்ப்பு அடுக்கு: Omarchy-ல் அந்த உள்ளுணர்வுகள் எங்கே செல்கின்றன. அம்சங்கள் தாமே வேறு இடங்களில் ஆழமாக விவரிக்கப்பட்டுள்ளன — இது வெறும் வரைபடம் மட்டுமே.

### Super தான் எல்லாவற்றின் மையம்

Cmd அல்லது Windows விசையைச் சுற்றி நீங்கள் உருவாக்கிய விரல் பழக்கம் அனைத்தும் ஒரே ஒரு விசைக்கு மாறுகிறது: Super. அது PC விசைப்பலகையில் உள்ள Windows விசை, Omarchy-ல் கிட்டத்தட்ட ஒவ்வொரு hotkey-க்கும் அதுதான் நங்கூரம்.

உங்கள் Spotlight அல்லது Raycast அல்லது Start-menu உள்ளுணர்வு `Super + Space` ஆகிறது. அது Omarchy மெனுவைத் திறக்கிறது, அது செயலிகளைத் தொடங்குகிறது, அமைப்புகளை மாற்றுகிறது, மென்பொருளை நிறுவுகிறது, திரையைப் படம்பிடிக்கிறது — கிட்டத்தட்ட எல்லாவற்றையும் செய்கிறது. வடிகட்டத் தட்டச்சு செய்யத் தொடங்குங்கள். `Super + Alt + Space` எல்லாச் செயலிகளையும் ஒரே கட்டத்தில் காட்டுகிறது, Launchpad செய்வது போல. [வழிசெலுத்தல்](04-navigation.md) ஐப் பார்க்கவும்.

### டெஸ்க்டாப் ஐகான்கள் இல்லை, dock வழியில் வராமல் இருக்கும்

டெஸ்க்டாபில் வரிசைப்படுத்த ஐகான்கள் இல்லை, ஒரு workspace-ல் ஒரு சாளரம் இருந்தவுடன் dock மறைந்துவிடும், நீங்கள் சுட்டியைத் திரையின் அதன் விளிம்பிற்கு, நீங்கள் அதை நகர்த்தாவிட்டால் வலது விளிம்பிற்கு, தள்ளும் வரை ( [வழிசெலுத்தல்](04-navigation.md) ஐப் பார்க்கவும்). செயலிகள் hotkey-லிருந்து தொடங்குகின்றன (`Super + Return` terminal-க்கு, `Super + Shift + Return` உலாவிக்கு, மற்றும் `Super + K` வரைபடமாக்கப்பட்ட எல்லாவற்றின் பட்டியலுக்கு) அல்லது மெனுவிலிருந்து. நிலையாக இருக்கும் ஒரே UI துண்டு [மேல் பட்டை](05-the-top-bar.md), அது menu bar, system tray, மற்றும் Notification Center முன்பு உங்களுக்காகச் செய்ததை உள்ளடக்குகிறது — அதில் உள்ள கிட்டத்தட்ட ஒவ்வொரு widget-ம் இடது, வலது மற்றும் நடு கிளிக்கில் ஏதாவது செய்கிறது.

### சாளரங்கள் தாமாகவே இடம் பிடிக்கின்றன

மிகப்பெரிய மனநிலை மாற்றம்: நீங்கள் சாளரங்களைச் சுற்றி இழுக்கவோ அல்லது திரையின் பாதிகளுக்கு ஒட்டவோ செய்வதில்லை. ஒரு சாளரத்தைத் திறந்தால் அது முழுத் திரையையும் எடுத்துக்கொள்கிறது. இரண்டாவதைத் திறந்தால் அவை அதைப் பிரித்துக்கொள்கின்றன. நீங்கள் ஒருபோதும் இன்னொரு சாளரத்தின் அடியிலிருந்து ஒரு சாளரத்தைத் தேடி எடுக்க வேண்டியதில்லை, ஏனெனில் சாளரங்கள் ஒன்றன் மேல் ஒன்று வருவதில்லை.

உங்களுக்கு உண்மையிலேயே ஒரு மிதக்கும் சாளரம் தேவைப்படும்போது, `Super + T` செயலில் உள்ளதை tiling-லிருந்து வெளியே (மற்றும் மீண்டும் உள்ளே) மாற்றுகிறது. ஆனால் முதலில் tiling-க்கு ஒரு உண்மையான வாய்ப்பு கொடுங்கள் — அதுதான் முழு விஷயத்தின் இதயம். [வழிசெலுத்தல்](04-navigation.md) அதன் வழியாக உங்களை அழைத்துச் செல்கிறது.

Workspaces பழக்கமாக உணரப்படும்: அவை macOS Spaces அல்லது Windows virtual desktops, ஆனால் நீங்கள் உண்மையில் அவற்றைப் பயன்படுத்துவீர்கள், ஏனெனில் `Super + 1/2/3/4` நேரடியாக ஒன்றிற்குத் தாவுகிறது மற்றும் `Super + Shift + 1/2/3/4` செயலில் உள்ள சாளரத்தை அங்கே அனுப்புகிறது. Animation தாமதம் இல்லை, உடனடித் தாவல்கள் மட்டுமே. இதன் பொருள், நீங்கள் முன்பு அதற்குப் பழகியிருந்தாலும், உங்களுக்குப் பல மானிட்டர்கள் கூடத் தேவைப்படாமல் போகலாம்.

### நகலெடுத்து ஒட்டுவது அப்படியே வேலை செய்கிறது

Mac-ல் உங்களிடம் எல்லா இடத்திலும் Cmd + C இருந்தது. Windows-ல் உங்களிடம் எல்லா இடத்திலும் Ctrl + C இருந்தது — terminal-ஐத் தவிர, அங்கு அது உங்கள் நிரலைக் கொன்றுவிடும். Omarchy உங்களுக்கு `Super + C`, `Super + X`, மற்றும் `Super + V` ஐத் தருகிறது, அவை terminal உட்பட எல்லா இடத்திலும் வேலை செய்கின்றன. Shell-க்காகத் தனி உள்ளுணர்வைக் கற்க வேண்டியதில்லை.

Windows நண்பர்களே: உங்கள் Win + V clipboard வரலாறு `Super + Ctrl + V`-ல் உள்ளது, அது உரையுடன் படங்களையும் வைத்திருக்கிறது. [ஒருங்கிணைந்த clipboard & வரலாறு](08-unified-clipboard-history.md) ஐப் பார்க்கவும்.

### சில விஷயங்கள் உண்மையிலேயே வேறுபட்டவை

பல அமைப்புகள் நீங்கள் கிளிக் செய்து செல்லும் panelகளில் அல்ல, நீங்கள் திருத்தும் உரைக் கோப்புகளில் உள்ளன. ஒவ்வொரு மாற்றத்தையும் பார்க்கவும், உங்கள் அடுத்த கணினிக்கு நகலெடுக்கவும், version control-ல் வைக்கவும் முடியும் என்பதை நீங்கள் உணரும் வரை அது பழமையானதாகத் தோன்றுகிறது. _Setup_ மெனு உங்களை நேரடியாகச் சரியான கோப்பில் இறக்குகிறது, நீங்கள் முடித்ததும் மறுதொடக்கம் தேவைப்படுவதை மறுதொடக்கம் செய்கிறது.

புதுப்பிப்புகள் ஒரே ஒரு கட்டளை வழியாக வருகின்றன — _Update > Omarchy_ — அது Omarchy-ஐயும் கணினியில் உள்ள ஒவ்வொரு தொகுப்பையும் புதுப்பிக்கிறது, முதலில் ஒரு snapshot எடுக்கிறது. தோராயமாக உங்களைத் தொந்தரவு செய்யும் தனித்தனி செயலி updaterகள் இல்லை. [புதுப்பிப்புகள்](30-updates.md) ஐப் பார்க்கவும்.

மென்பொருள் பதிவிறக்கப்பட்ட installerகளிலிருந்து அல்ல, ஒரு package manager-லிருந்து வருகிறது.

நீங்கள் ஒரு சாளரத்தை மூடும்போது, செயலி உண்மையில் வெளியேறுகிறது. சாளரங்கள் இல்லாமல் நிரல் தொடர்ந்து இயங்கும் macOS தொங்குநிலை இல்லை. `Super + W` — அல்லது, நீங்கள் அந்த விரல் பழக்கத்துடன் வந்திருந்தால், `Super + Q` — என்றால் முற்றிலும் போய்விட்டது.

### Mac வன்பொருளில்

Omarchy Intel Macகளில் நன்றாக இயங்குகிறது, மற்றும் Omarchy for Apple Silicon உடன் M1, M2 மற்றும் M3 Macகளிலும். [Mac ஆதரவு](44-mac-support.md) ஐப் பார்க்கவும். விசைப்பலகை உங்களிடம் அன்பாக இருக்கிறது: Omarchy எதையும் remap செய்வதில்லை, Linux Command விசையை Super ஆகக் கருதுகிறது, எனவே Super Cmd எப்போதும் இருந்த இடத்திலேயே அமர்ந்திருக்கிறது. உங்கள் கட்டைவிரல் இந்த மாற்றத்தைக் கவனிக்கவே செய்யாது.

### இரண்டு வாரங்கள் கொடுங்கள்

உள்ளுணர்வுகள் நீங்கள் நினைப்பதை விட வேகமாக மாறும். [hotkeyகள்](07-hotkeys.md) அத்தியாயத்தை ஒரு முறை மேலோட்டமாகப் படியுங்கள், ஒரு binding மறந்துவிடும் போதெல்லாம் `Super + K` ஐ அழுத்துங்கள் — அது அவை அனைத்தையும் உங்களுக்குக் காட்டுகிறது. நீங்கள் உண்மையில் மனப்பாடம் செய்ய வேண்டிய ஒரே hotkey அதுதான்.
