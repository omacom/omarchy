# Mac அல்லது Windows-இலிருந்து வருதல்

நீங்கள் macOS அல்லது Windows-இல் பல ஆண்டுகள் செலவிட்டிருந்தால், உங்கள் மூளை எப்போதோ கற்றுக்கொண்டதை மறந்துவிட்ட நூறு விஷயங்களை உங்கள் விரல்கள் அறியும். இந்த அத்தியாயம் அந்த மொழிபெயர்ப்பு அடுக்கு: அந்த உள்ளுணர்வுகள் Omarchy-இல் எங்கே செல்கின்றன. அம்சங்களே வேறு இடங்களில் ஆழமாக விவரிக்கப்பட்டுள்ளன — இது வெறும் வரைபடம் மட்டுமே.

### Super தான் எல்லாவற்றின் மையம்

Cmd அல்லது Windows விசையைச் சுற்றி நீங்கள் உருவாக்கிய அனைத்து தசை நினைவகமும் ஒரு விசைக்கு மாறுகிறது: Super. அது ஒரு PC விசைப்பலகையில் உள்ள Windows விசை, மேலும் அது Omarchy-இல் உள்ள கிட்டத்தட்ட ஒவ்வொரு ஹாட்கீக்கும் நங்கூரம்.

உங்கள் Spotlight அல்லது Raycast அல்லது Start-menu உள்ளுணர்வு `Super + Space` ஆக மாறுகிறது. அது Omarchy மெனுவைத் திறக்கிறது, இது செயலிகளைத் தொடங்குகிறது, அமைப்புகளை மாற்றுகிறது, மென்பொருளை நிறுவுகிறது, திரையைப் பதிவு செய்கிறது — கிட்டத்தட்ட எல்லாம். வடிகட்டத் தட்டச்சு செய்யத் தொடங்கவும். `Super + Alt + Space` ஒவ்வொரு செயலியையும் ஒரு கட்டத்தில் காட்டுகிறது, Launchpad செய்வது போல. [வழிசெலுத்தல்](04-navigation.md) பார்க்கவும்.

### Dock இல்லை, டெஸ்க்டாப் ஐகான்களும் இல்லை

விஷயங்களைத் தொடங்க கிளிக் செய்ய எதுவும் இல்லை, டெஸ்க்டாப்பில் ஒழுங்கமைக்க ஐகான்களும் இல்லை. செயலிகள் ஒரு ஹாட்கீயிலிருந்து தொடங்குகின்றன (டெர்மினலுக்கு `Super + Return`, உலாவிக்கு `Super + Shift + Return`, மற்றும் வரைபடமாக்கப்பட்ட அனைத்தின் பட்டியலுக்கு `Super + K`) அல்லது மெனுவிலிருந்து தொடங்குகின்றன. UI-இன் ஒரே நிலையான பகுதி [மேல் பட்டை](05-the-top-bar.md), இது மெனு பட்டை, அமைப்பு தட்டு, மற்றும் அறிவிப்பு மையம் முன்பு உங்களுக்காகச் செய்ததை உள்ளடக்குகிறது — மேலும் அதில் உள்ள கிட்டத்தட்ட ஒவ்வொரு விட்ஜெட்டும் இடது, வலது, மற்றும் நடு கிளிக்கில் ஏதாவது செய்கிறது.

### சாளரங்கள் தாங்களாகவே அமைகின்றன

மிகப்பெரிய மனநிலை மாற்றம்: நீங்கள் சாளரங்களைச் சுற்றி இழுக்கவோ அல்லது திரை பாதிகளுக்குப் பொருத்தவோ இல்லை. ஒரு சாளரத்தைத் திறக்கவும், அது முழுத் திரையையும் எடுக்கும். இரண்டாவதைத் திறக்கவும், அவை அதைப் பிரிக்கும். நீங்கள் ஒருபோதும் மற்றொன்றின் கீழிருந்து ஒரு சாளரத்தை மீட்க மாட்டீர்கள், ஏனெனில் சாளரங்கள் ஒன்றுடன் ஒன்று மேற்பொருந்தாது.

உங்களுக்கு உண்மையில் ஒரு மிதக்கும் சாளரம் தேவைப்படும் போது, `Super + T` செயலில் உள்ள ஒன்றை அடுக்கிலிருந்து வெளியே மாற்றுகிறது (மற்றும் திரும்பவும்). ஆனால் முதலில் அடுக்கிற்கு ஒரு உண்மையான வாய்ப்பு கொடுங்கள் — அது முழு விஷயத்தின் இதயம். [வழிசெலுத்தல்](04-navigation.md) அதன் வழியாக உங்களை அழைத்துச் செல்கிறது.

பணியிடங்கள் பழக்கமாக உணரும்: அவை macOS Spaces அல்லது Windows மெய்நிகர் டெஸ்க்டாப்புகள், ஆனால் நீங்கள் உண்மையில் அவற்றைப் பயன்படுத்துவீர்கள், ஏனெனில் `Super + 1/2/3/4` நேரடியாக ஒன்றிற்குத் தாவுகிறது மற்றும் `Super + Shift + 1/2/3/4` செயலில் உள்ள சாளரத்தை அங்கே அனுப்புகிறது. அசைவூட்ட தாமதம் இல்லை, உடனடி தாவல்கள் மட்டுமே. இதன் பொருள் என்னவென்றால், நீங்கள் முன்பு அதற்குப் பழக்கப்பட்டிருந்தால், உங்களுக்கு பல திரைகள் கூட தேவைப்படாமல் போகலாம்.

### நகல் மற்றும் ஒட்டு வெறுமனே வேலை செய்கின்றன

Mac-இல் உங்களுக்கு எல்லா இடங்களிலும் Cmd + C இருந்தது. Windows-இல் உங்களுக்கு எல்லா இடங்களிலும் Ctrl + C இருந்தது — டெர்மினலைத் தவிர, அங்கே அது உங்கள் நிரலைக் கொல்கிறது. Omarchy உங்களுக்கு `Super + C`, `Super + X`, மற்றும் `Super + V` ஐத் தருகிறது, மேலும் அவை டெர்மினல் உட்பட எல்லா இடங்களிலும் வேலை செய்கின்றன. ஷெல்லுக்காகக் கற்றுக்கொள்ள தனி உள்ளுணர்வு இல்லை.

Windows நண்பர்களே: உங்கள் Win + V கிளிப்போர்டு வரலாறு `Super + Ctrl + V` இல் உள்ளது, மேலும் அது உரையுடன் படங்களையும் வைத்திருக்கிறது. [ஒருங்கிணைந்த கிளிப்போர்டு & வரலாறு](08-unified-clipboard-history.md) பார்க்கவும்.

### சில விஷயங்கள் உண்மையிலேயே வேறுபட்டவை

நிறைய அமைப்புகள் நீங்கள் திருத்தும் உரை கோப்புகளில் உள்ளன, நீங்கள் கிளிக் செய்து செல்லும் பேனல்களில் அல்ல. ஒவ்வொரு மாற்றத்தையும் காணலாம், உங்கள் அடுத்த இயந்திரத்திற்கு நகலெடுக்கலாம், மற்றும் பதிப்பு கட்டுப்பாட்டில் வைக்கலாம் என்பதை உணரும் வரை அது பழமையானதாகத் தெரிகிறது. _அமைப்பு_ மெனு உங்களை நேரடியாக சரியான கோப்பில் சேர்க்கிறது மற்றும் நீங்கள் முடித்ததும் மறுதொடக்கம் தேவைப்படும் எதையும் மறுதொடக்கம் செய்கிறது.

புதுப்பிப்புகள் ஒரு கட்டளை மூலம் வருகின்றன — _புதுப்பி > Omarchy_ — இது Omarchy-ஐயே மற்றும் அமைப்பில் உள்ள ஒவ்வொரு தொகுப்பையும் புதுப்பிக்கிறது, முதலில் ஸ்னாப்ஷாட் எடுக்கிறது. சீரற்ற முறையில் உங்களைத் தொந்தரவு செய்யும் செயலி-வாரியான புதுப்பிப்பாளர்கள் இல்லை. [புதுப்பிப்புகள்](30-updates.md) பார்க்கவும்.

மென்பொருள் ஒரு தொகுப்பு மேலாளரிலிருந்து வருகிறது, பதிவிறக்கப்பட்ட நிறுவிகளிலிருந்து அல்ல.

மேலும் நீங்கள் ஒரு சாளரத்தை மூடும் போது, ​​செயலி உண்மையில் வெளியேறுகிறது. சாளரங்கள் இல்லாமல் நிரல் தொடர்ந்து இயங்கும் macOS லிம்போ இல்லை. `Super + W` — அல்லது `Super + Q`, அது நீங்கள் வந்த விரல் நினைவகம் என்றால் — என்றால் போய்விட்டது.

### Mac வன்பொருளில்

Omarchy Intel Mac-களில் நன்றாக இயங்குகிறது — [Mac ஆதரவு](44-mac-support.md) பார்க்கவும். மேலும் விசைப்பலகை உங்களிடம் கனிவாக உள்ளது: Omarchy எதையும் மறுவரைபடமாக்காது, மேலும் Linux Command விசையை Super ஆகக் கருதுகிறது, எனவே Cmd எப்போதும் இருந்த இடத்தில் Super அமர்ந்திருக்கிறது. உங்கள் கட்டைவிரல் நகர்வை கவனிக்காது.

### இரண்டு வாரங்கள் கொடுங்கள்

உள்ளுணர்வுகள் நீங்கள் நினைப்பதை விட வேகமாக மாறுகின்றன. [ஹாட்கீகள்](07-hotkeys.md) அத்தியாயத்தை ஒரு முறை மேலோட்டமாகப் பாருங்கள், மேலும் ஒரு பிணைப்பில் நீங்கள் திகைக்கும் போதெல்லாம், `Super + K` ஐ அழுத்தவும் — அது உங்களுக்கு அனைத்தையும் காட்டுகிறது. நீங்கள் உண்மையில் மனப்பாடம் செய்ய வேண்டிய ஒரே ஹாட்கீ அதுதான்.
