# Mac அல்லது Windows-இலிருந்து வருபவர்களுக்கு

நீங்கள் பல ஆண்டுகளாக macOS அல்லது Windows பயன்படுத்தியிருந்தால், உங்கள் மூளை கற்றுக்கொண்டதையே மறந்துவிட்ட நூறு விஷயங்களை உங்கள் விரல்கள் அறிந்திருக்கும். இந்த அத்தியாயம் அதற்கான மொழிபெயர்ப்பு அடுக்கு: அந்த உள்ளுணர்வுகள் Omarchy-இல் எங்கே செல்கின்றன. அம்சங்கள் தாமே வேறு இடங்களில் ஆழமாக விளக்கப்பட்டுள்ளன — இது வெறும் வரைபடம் மட்டுமே.

### Super தான் எல்லாவற்றின் மையம்

Cmd அல்லது Windows விசையைச் சுற்றி நீங்கள் உருவாக்கிய அனைத்து தசை நினைவுகளும் ஒரே விசைக்கு மாறுகின்றன: Super. அது PC விசைப்பலகையில் உள்ள Windows விசை, மேலும் Omarchy-இல் கிட்டத்தட்ட ஒவ்வொரு ஹாட்கீக்கும் அதுவே ஆதாரம்.

உங்கள் Spotlight அல்லது Raycast அல்லது Start-menu உள்ளுணர்வு `Super + Space` ஆக மாறுகிறது. அது Omarchy மெனுவைத் திறக்கிறது, அது செயலிகளைத் தொடங்குகிறது, அமைப்புகளை மாற்றுகிறது, மென்பொருளை நிறுவுகிறது, திரையைப் படம்பிடிக்கிறது — கிட்டத்தட்ட எல்லாமே. வடிகட்டத் தட்டச்சு செய்யத் தொடங்குங்கள். `Super + Alt + Space` Launchpad செய்வது போல ஒவ்வொரு செயலியையும் ஒரே கட்டத்தில் காட்டுகிறது. [வழிசெலுத்தல்](04-navigation.md) பார்க்கவும்.

### டெஸ்க்டாப் ஐகான்கள் இல்லை, நீங்கள் மிதக்கும்போது மட்டுமே dock தோன்றும்

டெஸ்க்டாப்பில் அடுக்கி வைக்க ஐகான்கள் இல்லை, tiling workspace-இல் dock இல்லை — floating workspace-இல் மட்டுமே dock தோன்றும் ([வழிசெலுத்தல்](04-navigation.md) பார்க்கவும்). செயலிகள் ஹாட்கீயிலிருந்து தொடங்குகின்றன (terminal-க்கு `Super + Return`, browser-க்கு `Super + Shift + Return`, வரையறுக்கப்பட்ட அனைத்தின் பட்டியலுக்கு `Super + K`) அல்லது மெனுவிலிருந்து தொடங்குகின்றன. நிலையாக இருக்கும் ஒரே UI பகுதி [மேல் பட்டை](05-the-top-bar.md); முன்பு menu bar, system tray, Notification Center ஆகியவை உங்களுக்காகச் செய்ததை அது கவனித்துக்கொள்கிறது — அதில் உள்ள கிட்டத்தட்ட ஒவ்வொரு widget-உம் இடது, வலது, நடு கிளிக்கில் ஏதாவது செய்யும்.

### சாளரங்கள் தாமாகவே தங்கள் இடத்தைப் பிடிக்கின்றன

மிகப் பெரிய மனநிலை மாற்றம்: நீங்கள் சாளரங்களை இழுத்துச் சுற்றித் திரிவதில்லை அல்லது திரையின் பாதிகளில் ஒட்டுவதில்லை. ஒரு சாளரத்தைத் திறந்தால் அது முழுத் திரையையும் எடுத்துக்கொள்ளும். இரண்டாவதைத் திறந்தால் அவை அதைப் பிரித்துக்கொள்ளும். சாளரங்கள் ஒன்றின் மீது ஒன்று மேல்படாததால், நீங்கள் ஒருபோதும் ஒரு சாளரத்தை இன்னொன்றின் அடியிலிருந்து துழாவி எடுக்க வேண்டியதில்லை.

உங்களுக்கு உண்மையிலேயே ஒரு floating சாளரம் தேவைப்படும்போது, `Super + T` செயலில் உள்ளதை tiling-இலிருந்து வெளியே (மீண்டும் உள்ளேயும்) மாற்றும். ஆனால் முதலில் tiling-க்கு உண்மையான வாய்ப்பு கொடுங்கள் — அதுதான் இவை அனைத்தின் இதயம். [வழிசெலுத்தல்](04-navigation.md) அதன் வழியாக உங்களை அழைத்துச் செல்கிறது.

Workspaces பழக்கமானவையாகத் தோன்றும்: அவை macOS Spaces அல்லது Windows virtual desktops போன்றவை, ஆனால் நீங்கள் உண்மையில் அவற்றைப் பயன்படுத்துவீர்கள், ஏனெனில் `Super + 1/2/3/4` நேரடியாக ஒன்றுக்குத் தாவுகிறது, `Super + Shift + 1/2/3/4` செயலில் உள்ள சாளரத்தை அங்கே அனுப்புகிறது. அனிமேஷன் தாமதம் இல்லை, வெறும் உடனடித் தாவல்கள் மட்டுமே. இதன் பொருள், நீங்கள் முன்பு அதற்குப் பழகியிருந்தாலும் கூட, உங்களுக்குப் பல monitors கூடத் தேவைப்படாமல் போகலாம்.

### நகலெடுத்தலும் ஒட்டுதலும் வெறுமனே வேலை செய்கின்றன

Mac-இல் எல்லா இடங்களிலும் உங்களிடம் Cmd + C இருந்தது. Windows-இல் எல்லா இடங்களிலும் Ctrl + C இருந்தது — terminal-ஐத் தவிர, அங்கு அது உங்கள் நிரலைக் கொன்றுவிடும். Omarchy உங்களுக்கு `Super + C`, `Super + X`, மற்றும் `Super + V` தருகிறது, அவை terminal உட்பட எல்லா இடங்களிலும் வேலை செய்கின்றன. shell-க்கு எனத் தனி உள்ளுணர்வு கற்றுக்கொள்ள வேண்டியதில்லை.

Windows நண்பர்களே: உங்கள் Win + V clipboard வரலாறு `Super + Ctrl + V`-இல் வாழ்கிறது, அது உரையுடன் படங்களையும் வைத்திருக்கிறது. [ஒருங்கிணைந்த கிளிப்போர்டு & வரலாறு](08-unified-clipboard-history.md) பார்க்கவும்.

### சில விஷயங்கள் உண்மையிலேயே வேறுபட்டவை

பல அமைப்புகள் நீங்கள் கிளிக் செய்து செல்லும் panels-இல் இல்லாமல், நீங்கள் திருத்தும் உரைக் கோப்புகளில் வாழ்கின்றன. ஒவ்வொரு மாற்றத்தையும் பார்க்கவும், உங்கள் அடுத்த கணினிக்கு நகலெடுக்கவும், version control-இல் வைக்கவும் முடியும் என்பதை உணரும் வரை அது பழமையானதாகத் தோன்றும். _அமைப்பு_ மெனு உங்களை நேரடியாகச் சரியான கோப்பில் கொண்டு சேர்க்கிறது, நீங்கள் முடித்ததும் மறுதொடக்கம் தேவைப்படுவதை மறுதொடக்கம் செய்கிறது.

புதுப்பிப்புகள் ஒரே கட்டளை வழியாக வருகின்றன — _புதுப்பிப்பு > Omarchy_ — அது Omarchy-ஐயும் கணினியில் உள்ள ஒவ்வொரு தொகுப்பையும் புதுப்பித்து, முதலில் ஒரு ஸ்னாப்ஷாட் எடுக்கிறது. தற்செயலான நேரங்களில் உங்களைத் தொந்தரவு செய்யும் ஒவ்வொரு செயலிக்குமான தனித்தனி புதுப்பிப்பான்கள் இல்லை. [புதுப்பிப்புகள்](30-updates.md) பார்க்கவும்.

மென்பொருள் பதிவிறக்கிய installers-இலிருந்து அல்லாமல், ஒரு package manager-இலிருந்து வருகிறது.

மேலும் நீங்கள் ஒரு சாளரத்தை மூடும்போது, செயலி உண்மையிலேயே வெளியேறுகிறது. நிரல் சாளரங்கள் இல்லாமல் தொடர்ந்து இயங்கும் macOS தொங்குநிலை இல்லை. `Super + W` — அல்லது நீங்கள் வந்தடைந்த விரல் நினைவு அதுவாக இருந்தால் `Super + Q` — என்றால் போய்விட்டது என்று பொருள்.

### Mac வன்பொருளில்

Omarchy Intel Macs-இல் நன்றாக இயங்குகிறது, மேலும் Omarchy for Apple Silicon உடன் M1, M2 மற்றும் M3 Macs-இலும் இயங்குகிறது. [Mac ஆதரவு](44-mac-support.md) பார்க்கவும். விசைப்பலகை உங்களிடம் கனிவாக நடந்துகொள்கிறது: Omarchy எதையும் remap செய்வதில்லை, Linux Command விசையை Super ஆகக் கருதுகிறது, எனவே Cmd எப்போதும் இருந்த இடத்திலேயே Super அமர்ந்திருக்கிறது. உங்கள் கட்டைவிரல் இந்த நகர்வைக் கவனிக்கவே செய்யாது.

### இரண்டு வாரங்கள் கொடுங்கள்

உள்ளுணர்வுகள் நீங்கள் நினைப்பதை விட வேகமாக மாறுகின்றன. [ஹாட்கீகள்](07-hotkeys.md) அத்தியாயத்தை ஒரு முறை மேலோட்டமாகப் பாருங்கள், ஒரு binding நினைவுக்கு வராதபோதெல்லாம், `Super + K` அழுத்துங்கள் — அது அனைத்தையும் உங்களுக்குக் காட்டுகிறது. நீங்கள் உண்மையில் மனப்பாடம் செய்ய வேண்டிய ஒரே ஹாட்கீ அதுதான்.
