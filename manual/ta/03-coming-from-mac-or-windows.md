# Mac அல்லது Windows இலிருந்து வருபவர்களுக்கு

நீங்கள் macOS அல்லது Windows இல் பல ஆண்டுகள் செலவிட்டிருந்தால், உங்கள் மூளை தான் கற்றுக்கொண்டதையே மறந்துவிட்ட நூறு விஷயங்களை உங்கள் விரல்கள் அறிந்திருக்கும். இந்த அத்தியாயம் அதற்கான மொழிபெயர்ப்பு அடுக்கு: Omarchy இல் அந்த உள்ளுணர்வுகள் எங்கே செல்கின்றன. அந்த அம்சங்களே வேறு இடங்களில் விரிவாக விளக்கப்பட்டுள்ளன — இது வெறும் வரைபடம் மட்டுமே.

### Super தான் எல்லாவற்றின் மையம்

Cmd அல்லது Windows விசையைச் சுற்றி நீங்கள் உருவாக்கிய அனைத்து தசை நினைவுகளும் ஒரே ஒரு விசைக்கு மாறுகின்றன: Super. அது PC விசைப்பலகையில் உள்ள Windows விசை, மேலும் Omarchy இல் கிட்டத்தட்ட ஒவ்வொரு ஹாட்கீக்கும் அதுவே நங்கூரம்.

உங்கள் Spotlight அல்லது Raycast அல்லது Start மெனு உள்ளுணர்வு `Super + Space` ஆக மாறுகிறது. அது Omarchy மெனுவைத் திறக்கிறது, அது செயலிகளைத் தொடங்குகிறது, அமைப்புகளை மாற்றுகிறது, மென்பொருளை நிறுவுகிறது, திரையைப் படம்பிடிக்கிறது — கிட்டத்தட்ட எல்லாவற்றையும் செய்கிறது. வடிகட்டத் தட்டச்சு செய்யத் தொடங்குங்கள். `Super + Alt + Space` அனைத்து செயலிகளையும் ஒரே கட்டத்தில் காட்டுகிறது, Launchpad செய்வது போலவே. [வழிசெலுத்தல்](04-navigation.md) பார்க்கவும்.

### டாக்கும் இல்லை, டெஸ்க்டாப் ஐகான்களும் இல்லை

பொருட்களைத் தொடங்க கிளிக் செய்ய எதுவும் இல்லை, டெஸ்க்டாப்பில் அடுக்கி வைக்க ஐகான்களும் இல்லை. செயலிகள் ஹாட்கீயிலிருந்து தொடங்குகின்றன (டெர்மினலுக்கு `Super + Return`, உலாவிக்கு `Super + Shift + Return`, வரைபடமாக்கப்பட்ட எல்லாவற்றின் பட்டியலுக்கு `Super + K`) அல்லது மெனுவிலிருந்து தொடங்குகின்றன. ஒரே ஒரு நிலையான UI பகுதி [மேல் பட்டை](05-the-top-bar.md) தான், அது மெனு பட்டை, சிஸ்டம் ட்ரே மற்றும் Notification Center முன்பு உங்களுக்காகச் செய்ததை உள்ளடக்குகிறது — மேலும் அதில் உள்ள கிட்டத்தட்ட ஒவ்வொரு விட்ஜெட்டும் இடது, வலது மற்றும் நடு கிளிக்கில் ஏதாவது செய்கிறது.

### சாளரங்கள் தாங்களாகவே தங்களை அமைத்துக்கொள்கின்றன

மிகப் பெரிய மனநிலை மாற்றம்: நீங்கள் சாளரங்களைச் சுற்றி இழுக்கவோ அவற்றைத் திரையின் பாதிகளில் ஒட்டவோ வேண்டாம். ஒரு சாளரத்தைத் திறந்தால் அது முழுத் திரையையும் எடுத்துக்கொள்கிறது. இரண்டாவதைத் திறந்தால் அவை திரையைப் பிரித்துக்கொள்கின்றன. சாளரங்கள் ஒன்றன் மேல் ஒன்று மேலடுக்காததால், நீங்கள் ஒருபோதும் மற்றொரு சாளரத்தின் அடியிலிருந்து ஒரு சாளரத்தைத் தேடி எடுக்க வேண்டியதில்லை.

உங்களுக்கு உண்மையிலேயே மிதக்கும் சாளரம் தேவைப்படும்போது, `Super + T` தற்போதைய சாளரத்தை டைலிங்கிலிருந்து வெளியே (மீண்டும் உள்ளேயும்) மாற்றுகிறது. ஆனால் முதலில் டைலிங்கிற்கு உண்மையான வாய்ப்பு கொடுங்கள் — அதுதான் இந்த முழு விஷயத்தின் இதயம். [வழிசெலுத்தல்](04-navigation.md) அதன் வழியாக உங்களை அழைத்துச் செல்கிறது.

பணியிடங்கள் பழக்கமானவையாக உணரப்படும்: அவை macOS Spaces அல்லது Windows மெய்நிகர் டெஸ்க்டாப்புகள், ஆனால் நீங்கள் உண்மையில் அவற்றைப் பயன்படுத்துவீர்கள், ஏனெனில் `Super + 1/2/3/4` நேரடியாக ஒன்றிற்குத் தாவுகிறது, மேலும் `Super + Shift + 1/2/3/4` தற்போதைய சாளரத்தை அங்கே அனுப்புகிறது. அனிமேஷன் தாமதம் இல்லை, வெறும் உடனடித் தாவல்கள் மட்டுமே. நீங்கள் முன்பு அதற்குப் பழகியிருந்தாலும்கூட, உங்களுக்குப் பல மானிட்டர்கள் தேவைப்படாமல் போகலாம் என்று இதற்கு அர்த்தம்.

### நகலெடுத்தலும் ஒட்டுதலும் வெறுமனே வேலை செய்கின்றன

Mac இல் உங்களிடம் எல்லா இடங்களிலும் Cmd + C இருந்தது. Windows இல் உங்களிடம் எல்லா இடங்களிலும் Ctrl + C இருந்தது — டெர்மினலைத் தவிர, அங்கே அது உங்கள் நிரலை அழிக்கிறது. Omarchy உங்களுக்கு `Super + C`, `Super + X` மற்றும் `Super + V` ஐ வழங்குகிறது, அவை டெர்மினல் உட்பட எல்லா இடங்களிலும் வேலை செய்கின்றன. ஷெல்லுக்காகத் தனி உள்ளுணர்வைக் கற்க வேண்டியதில்லை.

Windows நண்பர்களே: உங்கள் Win + V கிளிப்போர்டு வரலாறு `Super + Ctrl + V` இல் வாழ்கிறது, மேலும் அது உரையுடன் படங்களையும் வைத்திருக்கிறது. [ஒருங்கிணைந்த கிளிப்போர்டு & வரலாறு](08-unified-clipboard-history.md) பார்க்கவும்.

### சில விஷயங்கள் உண்மையிலேயே வித்தியாசமானவை

நிறைய அமைப்புகள் நீங்கள் கிளிக் செய்து செல்லும் பேனல்களில் அல்ல, நீங்கள் திருத்தும் உரைக் கோப்புகளில் வாழ்கின்றன. ஒவ்வொரு மாற்றத்தையும் பார்க்கவும், உங்கள் அடுத்த கணினிக்கு நகலெடுக்கவும், பதிப்புக் கட்டுப்பாட்டில் வைக்கவும் முடியும் என்று உணரும் வரை அது பழமையானதாகத் தோன்றுகிறது. _அமைப்பு_ மெனு உங்களை நேரடியாகச் சரியான கோப்பில் கொண்டு சேர்க்கிறது, மேலும் நீங்கள் முடித்ததும் மறுதொடக்கம் செய்ய வேண்டியதை மறுதொடக்கம் செய்கிறது.

புதுப்பிப்புகள் ஒரே கட்டளை வழியாக வருகின்றன — _புதுப்பி > Omarchy_ — அது முதலில் ஸ்னாப்ஷாட் எடுத்து, Omarchy ஐயும் சிஸ்டத்தில் உள்ள ஒவ்வொரு தொகுப்பையும் புதுப்பிக்கிறது. சீரற்ற நேரங்களில் உங்களைத் தொந்தரவு செய்யும் ஒவ்வொரு செயலிக்குமான புதுப்பிப்பான்கள் இல்லை. [புதுப்பிப்புகள்](30-updates.md) பார்க்கவும்.

மென்பொருள் பதிவிறக்கப்பட்ட நிறுவிகளிலிருந்து அல்ல, ஒரு தொகுப்பு மேலாளரிலிருந்து வருகிறது.

மேலும் நீங்கள் ஒரு சாளரத்தை மூடும்போது, செயலி உண்மையிலேயே மூடப்படுகிறது. சாளரங்கள் இல்லாமல் நிரல் தொடர்ந்து இயங்கும் macOS தத்தளிப்பு நிலை இல்லை. `Super + W` — அல்லது நீங்கள் வந்தடைந்த விரல் நினைவு அதுவாக இருந்தால் `Super + Q` — என்றால் போய்விட்டது என்று அர்த்தம்.

### Mac ஹார்டுவேரில்

Omarchy Intel Macகளில் நன்றாக இயங்குகிறது — [Mac ஆதரவு](44-mac-support.md) பார்க்கவும். மேலும் விசைப்பலகை உங்களிடம் அன்பாக இருக்கிறது: Omarchy எதையும் மறுவரைபடம் செய்யாது, மேலும் Linux Command விசையை Super ஆகக் கருதுகிறது, எனவே Super, Cmd எப்போதும் இருந்த இடத்திலேயே அமர்ந்திருக்கிறது. உங்கள் கட்டைவிரல் இந்த நகர்வைக் கவனிக்கவே செய்யாது.

### இரண்டு வாரங்கள் கொடுங்கள்

உள்ளுணர்வுகள் நீங்கள் நினைப்பதை விட வேகமாக மாறுகின்றன. [ஹாட்கீகள்](07-hotkeys.md) அத்தியாயத்தை ஒருமுறை மேலோட்டமாகப் படியுங்கள், மேலும் ஒரு பிணைப்பில் நீங்கள் தடுமாறும்போதெல்லாம், `Super + K` ஐ அழுத்துங்கள் — அது அவை அனைத்தையும் உங்களுக்குக் காட்டுகிறது. நீங்கள் உண்மையில் மனப்பாடம் செய்ய வேண்டிய ஒரே ஹாட்கீ அதுதான்.
