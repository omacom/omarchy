# AI

Omarchy உங்களுக்காக இயல்புநிலையைத் தேர்ந்தெடுக்காமல், கீழே உள்ள குறியீட்டு ஏஜெண்ட்களுக்கான தொடக்கிகளை உள்ளடக்கியுள்ளது. முதல் முறை பயன்படுத்தும்போது அதன் CLI-ஐ நிறுவ ஒரு கட்டளையை இயக்கி, பின்னர் கேட்கப்படும்போது அங்கீகரிக்கவும். Hermes விதிவிலக்கு: முதல் முறை பயன்படுத்தும்போது அதற்காக எதுவும் நிறுவப்படாது, அதைத் தேர்ந்தெடுப்பது Hermes Desktop-ஐ நிறுவும், கீழே உள்ள _டெஸ்க்டாப் பயன்பாடுகள்_ விளக்குவது போல.

### ஏஜெண்ட்களை நிறுவுதல் மற்றும் புதுப்பித்தல்

Hermes-ஐத் தவிர, இந்த ஏஜெண்ட்கள் mise-இன் lazy நிறுவலைப் பயன்படுத்துகின்றன: முதல் தொடக்கம் CLI-ஐ நிறுவும், பிந்தைய தொடக்கங்கள் அதையே மீண்டும் பயன்படுத்தும். mise ஒரு நிறுவப்பட்ட ஏஜெண்டிற்கு புதிய வெளியீடு உள்ளதா என நான்கு மணி நேரத்திற்கு அதிகபட்சம் ஒரு முறை, அது தொடங்குவதற்குச் சற்று முன்பு அல்லது shell prompt-இல் பின்னணியில், சரிபார்க்கும். அந்தப் புதுப்பிப்பு தோல்வியடைந்தால் அல்லது நீங்கள் offline-இல் இருந்தால், நிறுவப்பட்ட பதிப்பு இயங்கும். `omarchy update` நிறுவப்பட்ட ஏஜெண்ட்களை Omarchy-இன் மீதமுள்ளவற்றுடன் புதுப்பிக்கும், மற்றும் `mup` mise-ஆல் நிர்வகிக்கப்படும் கருவிகளை மட்டும் புதுப்பிக்கும்.

`claude update`, `codex update` போன்ற ஒரு ஏஜெண்டின் சொந்தப் புதுப்பிப்பான், அல்லது ஒரு பயன்பாட்டில் உள்ள புதுப்பிப்பு பொத்தான், mise-ஆல் நிர்வகிக்கப்படும் நிறுவலைப் புதுப்பிக்காது. `codex update` தோல்வியடையும், மற்றும் `claude update` வெற்றி என்று தெரிவித்துக்கொண்டே mise கண்காணிக்காத தனி நகலை நிறுவலாம். நீங்கள் ஒரு ஏஜெண்டின் சொந்த நிறுவி மற்றும் புதுப்பிப்பானைப் பயன்படுத்த விரும்பினால், அதை `disable_tools`-இல் சேர்க்கவும்; [முன்பே நிறுவப்பட்ட CLI கருவிகள்](18-development-tools.md#preinstalled-cli-tools) என்பதைப் பார்க்கவும்.

உள்ளமைக்கப்பட்ட அனைத்து lazy கருவிகளையும் உங்களுக்குத் தேவைப்படுவதற்கு முன்பே நிறுவ, `mise install --include-lazy` என்பதை இயக்கவும். இதில் ஏஜெண்ட்களுடன் Omarchy-இன் மற்ற இயல்புநிலை CLI கருவிகளும் அடங்கும். ஒரு தனிக் கருவியை நிறுவுவது அல்லது உங்கள் சொந்த நிறுவலைப் பயன்படுத்துவது பற்றி [முன்பே நிறுவப்பட்ட CLI கருவிகள்](18-development-tools.md#preinstalled-cli-tools) என்பதைப் பார்க்கவும்.

`grok` என்பது `claude` மற்றும் `codex` போலவே, mise-இன் first-party `grok` தொகுப்பு வழியாக நிறுவப்படுகிறது. `grok` என்பதை இயக்கவும், அல்லது _Agent > Harness_ கீழ் அதைத் தேர்ந்தெடுக்கவும். x.ai-இல் உள்ள `curl | bash` நிறுவியைத் தவிர்க்கவும். அந்த வழி இரண்டாவது நகலை `~/.grok/bin`-இல் வைக்கும், அதை `PATH`-இல் முன்னால் சேர்க்கும், மற்றும் Omarchy-இன் wrapper-ஐ மேலெழுதும்.

`dsh` அதன் உலாவி UI-ஐ `127.0.0.1:3080`-இல் திறக்கும், தொடக்கக் கோப்பகம் அதன் இயல்புநிலைப் பணியிடமாக இருக்கும். அதன் உலாவி UI தொடக்க prompt-ஐ ஏற்காது, எனவே `omarchy agent prompt` அதை ஒட்டுவதற்காக உங்கள் clipboard-இல் prompt உடன் திறக்கும். Omarchy அதை DeepSeek-இன் ஒப்புதல் தேவையில்லாத அனுமதி preset உடன் தொடங்கும். DeepSeek Harness நீங்கள் அதன் அதிகாரப்பூர்வ மாடல் API-ஐப் பயன்படுத்தும்போது அமர்வுப் பதிவுகளை DeepSeek-க்கு பதிவேற்றும்; அதன் உலாவி UI-இல் _Settings > General > Upload Session Log_ கீழ் அதை அணைக்கவும். நீங்கள் அதற்கு அனுப்பும் கருத்தும் அமர்வுடன் சேர்த்து பதிவேற்றப்படும், நீங்கள் அதை `DSH_TELEMETRY_MODE=DISABLED` உடன் தொடங்கினால் தவிர.

### இயல்புநிலை ஏஜெண்ட்

உங்கள் இயல்புநிலை ஏஜெண்டை `omarchy default agent <name>` உடன் அல்லது Omarchy Menu-இல் (`Super + Space`) _Agent > Harness_ கீழ் தேர்ந்தெடுக்கவும். ஏஜெண்ட் இன்னும் நிறுவப்படவில்லை என்றால், அதைத் தேர்ந்தெடுப்பது முதலில் அதை நிறுவும். புதிய Omarchy ஒரு முறை மட்டும் வரும் அறிவிப்புடன் இந்தத் தேர்வைச் செய்ய உங்களை அழைக்கும்.

Claude-ஐத் தேர்ந்தெடுப்பது Chromium, Chrome, Brave, Brave Origin, மற்றும் Edge-க்கான அதன் உலாவி நீட்டிப்பை அமைக்கவும் முயற்சிக்கும். நீட்டிப்பு அமைப்பு அனைத்துப் பயனர்களுக்கும் பொருந்தும் மற்றும் உங்கள் கணினி கடவுச்சொல்லைக் கேட்கலாம்; ரத்து செய்வது அல்லது தோல்வியடைந்த நீட்டிப்பு நிறுவல் கூட Claude-ஐத் தேர்ந்தெடுத்துத் தொடங்கும். உங்கள் உலாவியை மறுதொடக்கம் செய்யவும், கேட்கப்பட்டால் நீட்டிப்பை இயக்கவும், மற்றும் அதை இணைப்பதை முடிக்க Claude-இல் உள்நுழையவும். இணைப்பைச் சரிபார்க்க Claude-இல் `/chrome` என்பதை இயக்கவும். Firefox மற்றும் Zen இந்த நீட்டிப்பை ஆதரிக்காது. இந்த அமைப்பு சேர்க்கப்படுவதற்கு முன்பே Claude உங்கள் இயல்புநிலையாக இருந்திருந்தால், நீட்டிப்பை நிறுவ அதை மீண்டும் தேர்ந்தெடுக்கவும்.

நீங்கள் தேர்ந்தெடுத்தவுடன், `Super + Shift + Ctrl + A` இயல்புநிலை ஏஜெண்டை ஒரு பிரத்யேக முனைய சாளரத்தில் தொடங்கும் (அல்லது நீங்கள் இன்னும் தேர்ந்தெடுக்கவில்லை என்றால் தேர்வியைக் கொண்டு வரும்). நீங்கள் அதை `omarchy agent prompt "Review this project"` உடன் நேரடியாக ஒரு பணியிலும் தொடங்கலாம். Freebuff மற்றும் DeepSeek Harness தொடக்க prompt-ஐ ஏற்காது, எனவே அவை அதற்குப் பதிலாக ஒட்டுவதற்காக உங்கள் clipboard-இல் prompt உடன் திறக்கும். இவ்வாறு தொடங்கப்படும் ஏஜெண்ட்கள் அவற்றின் அந்தந்த நிறுத்திக் கேட்காத முறைகளில் கவனிப்பின்றி இயங்கும், எனவே அவை உண்மையில் விஷயங்களைச் செய்யத் தயாராக இருங்கள்! MiniMax Code-க்கு அதன் ஊடாடும் அமர்வுகளுக்கு அத்தகைய முறை இல்லை, எனவே அது வழக்கம் போல் அனுமதிகளைக் கேட்கும். மற்றும் ஏஜெண்ட்கள் உங்கள் home கோப்பகத்திற்கான நம்பிக்கையை நினைவில் வைக்க மறுப்பதால், `$HOME`-இலிருந்து தொடங்குவது அதற்குப் பதிலாக `~/Work`-இல் தொடங்கும்.

முனையக் குறுக்குவழிகளும் உள்ளன: `a` தற்போதைய முனையத்தில் இயல்புநிலை ஏஜெண்டை inline-ஆக இயக்கும், அதே நேரத்தில் `c`, `cx`, மற்றும் `cy` OpenCode, Claude Code, மற்றும் Codex-ஐ நேரடியாகத் தொடங்கும் (மீண்டும் அவற்றின் தானாக ஒப்புதல் அளிக்கும் முறைகளில்). Theme மாற்றங்களும் ஏஜெண்ட்களுக்கு ஒத்திசைக்கப்படும்: நீங்கள் Omarchy theme-ஐ மாற்றும்போது Claude Code, Pi, OpenCode, மற்றும் Hermes (Omarchy அதை நிறுவியவுடன்) அனைத்தும் பின்தொடரும்.

### உங்கள் ஏஜெண்ட் வழிமுறைகள்

ஒவ்வொரு ஏஜெண்டிற்கான தனிப்பட்ட விதிகள் `~/.agents/skills`-இல் உள்ள பகிரப்பட்ட திறன்களுக்கு அடுத்து `~/.agents/AGENTS.md`-இல் செல்லும். அதை _Agent > Instructions_ கீழ் திறக்கவும், இது அதன் சொந்த global கோப்பை வைத்திருக்கும் ஒவ்வொரு harness-க்குள்ளும் அதை இணைக்கும்: `~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.pi/agent/AGENTS.md`, `~/.config/opencode/AGENTS.md`, Copilot-இன் `~/.copilot/copilot-instructions.md`, மற்றும் பல. Crush மற்றும் Amp `~/.config/AGENTS.md` இணைப்பைப் படிக்கும், அதே நேரத்தில் omp, Kimi, மற்றும் DeepSeek Harness `~/.agents/AGENTS.md`-ஐ நேரடியாகப் படிக்கும். இயல்புநிலை ஏஜெண்டைத் தேர்ந்தெடுப்பதும் அதை இணைக்கும். உங்களிடம் ஏற்கனவே இருந்த ஒரு வழிமுறைகள் கோப்பு, இன்னும் எதுவும் இல்லை என்றால் பகிரப்பட்டதாக மாறும்; இல்லையெனில் அது இணைப்புக்கு அருகில் `.bak` ஆக வைக்கப்படும். மற்றொரு ஏஜெண்டை நிறுவிய பிறகு மீண்டும் இணைக்க `omarchy agent instructions` என்பதை இயக்கவும்.

### ஏஜெண்ட்கள் பேனல்

மேல் பட்டியில் ஒரு ஏஜெண்ட்கள் ஐகான் உள்ளது. நீங்கள் ஒரு ஏஜெண்டை அமைப்பதற்கு முன்பு, அதன் பேனல் Claude, Codex, அல்லது Grok-இல் உள்நுழைவதன் வழியாக உங்களை அழைத்துச் செல்லும், மற்றும் முதலாவது உங்கள் இயல்புநிலை ஏஜெண்டாக மாறும். அதன் பிறகு, பேனல் ஒவ்வொரு சந்தாவையும் ஒரே பக்கத்தில் வைக்கும்: ஒவ்வொரு ஏஜெண்ட் மற்றும் கணக்குடன் அதன் திட்டம், அதன் 5 மணி நேர அமர்வு மற்றும் வாராந்திர வரம்புகள் ஒவ்வொன்றிற்கும் அது மீட்டமைக்கப்படும் வரையிலான நேரத்துடன் ஒரு மீட்டர் (சரியான சதவீதத்திற்கு hover செய்யவும்), அல்லது மீதமுள்ள முன்கூட்டியே செலுத்தப்பட்ட இருப்பு, இந்த வாரம் tokens மற்றும் நீங்கள் அதிகம் பயன்படுத்திய மாடல் போல, அவை அனைத்திலும் நீங்கள் பயன்படுத்தியதைச் சுழற்றும் ஒரு வரியின் கீழ். _Make something_ கீழ் இது புதிய theme, plugin, அல்லது பயன்பாட்டிற்கான தொடக்க prompt-களை வழங்குகிறது, அவை பணியை உங்கள் இயல்புநிலை ஏஜெண்டிடம் ஒப்படைக்கும். Omarchy-இன் சொந்த Hype, Monologue, மற்றும் Omacut கட்டமைக்கப்பட்ட விதத்தில், C++ மற்றும் Qt Quick-இல், omarchy-app ஏஜெண்ட் திறனைப் பின்பற்றி பயன்பாடுகள் கட்டமைக்கப்படுகின்றன, மற்றும் அவற்றுக்குத் தேவையான compiler மற்றும் Qt பகுதிகள் நிறுவப்பட்டு வரும். Claude Code, Codex, Grok, Kimi, Cursor மற்றும் அதன் Grok Bot ஒதுக்கீடு, GitHub Copilot, Muse, Antigravity, Kimchi, மற்றும் Devin அவற்றின் வரம்புகளுடன் தொடக்கத்திலிருந்தே உள்ளடக்கப்பட்டுள்ளன, மற்றும் Hermes, Mistral Vibe, மற்றும் Qwen Code நீங்கள் அவற்றைப் பயன்படுத்தியவுடன் அவற்றின் அமர்வுகள் மற்றும் tokens-ஐக் காட்டும். pi, omp, அல்லது opencode வழியாக நீங்கள் பயன்படுத்தும் வழங்குநர் திட்டங்கள் மற்றும் விசைகளும் தோன்றும்: OpenCode Zen மற்றும் Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan, மற்றும் Synthetic அவற்றின் வரம்புகளுடன்; Fireworks, OpenRouter, மற்றும் DeepSeek அவற்றின் முன்கூட்டியே செலுத்தப்பட்ட இருப்புகளுடன்; மற்றும் உள்ளூர் மாடல்கள் கீழ் உங்கள் சொந்த வன்பொருளில் நீங்கள் இயக்கும் மாடல்கள். ஒவ்வொரு ஏஜெண்டும் ஒரு முறை மட்டுமே கணக்கிடப்படும், அதற்கு யார் கட்டணம் வசூலிக்கிறார்களோ அவர்களின் கீழ், நீங்கள் எத்தனை harness-கள் வழியாக அதை இயக்கினாலும்.

பேனலுக்கு பட்டி ஐகானை இடது-கிளிக் செய்யவும், உங்கள் இயல்புநிலை ஏஜெண்டைத் தொடங்க வலது-கிளிக் செய்யவும். அதன் பின்னால் உள்ள பயன்பாட்டுப் பதிவுகள் ஒவ்வொரு 15 நிமிடங்களுக்கும் `omarchy agent usage-update` மூலம் மீண்டும் உருவாக்கப்படும், மற்றும் பேனல் ஒத்திசைக்கப்பட்ட கோப்புறை வழியாக உங்கள் மற்ற இயந்திரங்களிலிருந்து பயன்பாட்டை இணைக்கவும் முடியும். முழு அமைப்புகளுக்கு `$OMARCHY_PATH/shell/plugins/agents/` கீழ் உள்ள README-ஐப் பார்க்கவும்.

### பல சந்தாக்கள்

நீங்கள் ஒன்றுக்கும் மேற்பட்ட Claude, Codex, அல்லது Grok திட்டத்திற்கு பணம் செலுத்தினால் — உதாரணமாக ஒரு தனிப்பட்ட Max மற்றும் ஒரு பணி ஒன்று — Omarchy அவை அனைத்தையும் உள்நுழைந்த நிலையில் வைத்து அவற்றுக்கிடையே நகர முடியும். ஏஜெண்ட்கள் பேனலில் உள்ள + உடன் ஒரு சந்தாவைச் சேர்க்கவும், அது அங்கேயே உங்களை அதன் வழியாக அழைத்துச் செல்லும், அல்லது `omarchy agent account add claude Work` உடன் (அல்லது `codex`, அல்லது `grok`). அது இல்லை என்றால் CLI-ஐ நிறுவும். ஒரு வழங்குநருக்கான முதல் கணக்கு உங்கள் சாதாரண உலாவி வழியாக, CLI எப்போதும் பார்க்கும் இடத்திலேயே உள்நுழையும். அதற்குப் பிறகு ஒவ்வொன்றும் ஒரு தனிப்பட்ட சாளரம் வழியாக உள்நுழையும், எனவே உங்கள் உலாவி ஏற்கனவே உள்நுழைந்துள்ள கணக்கு தவறுதலாக எடுக்கப்படாது; நீங்கள் சேர்க்கும் கணக்காக அங்கே உள்நுழையவும், மற்றும் நீங்கள் ஏற்கனவே திறந்து வைத்திருந்த எந்த தனிப்பட்ட சாளரத்தையும் முதலில் மூடவும். இதைச் செய்ய CLI-இலிருந்து ஒருபோதும் வெளியேற வேண்டாம்: வெளியேறுவது சேமிக்கப்பட்ட உள்நுழைவை ரத்து செய்யும், மற்றும் அந்தக் கணக்கு மீண்டும் சேர்க்கப்பட வேண்டும்.

உங்கள் சந்தா உள்நுழைவுகளை SSH வழியாக மற்றொரு Omarchy இயந்திரத்திற்கு நகலெடுக்க, `omarchy agent account copy user@laptop` என்பதை இயக்கவும். இலக்கில் ஒன்று நிறுவப்படவில்லை என்றால் அனுப்புநர் ஒரு தற்காலிகப் பெறுநரை வழங்கும், எனவே பழைய Omarchy இயந்திரங்கள் புதுப்பிப்பு இல்லாமல் கணக்குகளைப் பெற முடியும். நிறுவப்பட்ட பெறுநர்களுக்கு முன்னுரிமை கிடைக்கும். இது அனைத்து Claude, Codex, மற்றும் Grok சந்தாக்களையும் நகலெடுக்கும்; `omarchy agent account copy laptop claude` என்பதில் உள்ளது போல, அவற்றைத் தேர்ந்தெடுக்க வழங்குநர் பெயர்களைச் சேர்க்கவும். கணக்குப் பெயர்கள் மற்றும் கட்டளை ID-கள் மூலத்துடன் பொருந்தும், இலக்கில் ஏற்கனவே உள்ள கணக்குகள் உட்பட. தொடர்பில்லாத இலக்குக் கணக்குகளின் பெயர்கள் முரண்பட்டால் அவை எண் பின்னொட்டைப் பெறும், மற்றும் அமைப்புகள், திறன்கள், plugins, மற்றும் உரையாடல் வரலாறு ஒவ்வொரு இயந்திரத்திற்கும் உள்ளூராகவே இருக்கும்.

ஏற்கனவே உள்ள இலக்கு நற்சான்றிதழ்கள் வைக்கப்படும். அங்கே ஏற்கனவே உள்நுழைந்துள்ள ஒரு மூலக் கணக்கின் பெயர் அதன் நற்சான்றிதழ்களை மாற்றாமல் ஒத்திசைக்கப்படும்; மற்ற கணக்குகள் அதற்கு அருகில் சேர்க்கப்படும். பொருந்தும் கணக்குகளுக்குச் சேமிக்கப்பட்ட நற்சான்றிதழ்களை மாற்ற, இலக்கில் அந்தக் கணக்கின் அமர்வுகளை விட்டு வெளியேறிய பிறகு `omarchy agent account copy --replace laptop claude` என்பதைப் பயன்படுத்தவும். புதிய இலக்கு மூலத்தின் செயலில் உள்ள கணக்கு மற்றும் மாற்றும் விருப்பங்களையும் பெறும்; நிறுவப்பட்ட இலக்கு அதன் சொந்தத்தை வைத்திருக்கும்.

நற்சான்றிதழ்கள் SSH வழியாகப் பயணித்து இலக்கில் தனிப்பட்ட கோப்புகளில் சேமிக்கப்படும், எனவே நீங்கள் நம்பும் இயந்திரங்களுக்கு மட்டும் நகலெடுக்கவும். இது ஒரு முறை நகல், தொடர்ச்சியான ஒத்திசைவு அல்ல. Codex refresh tokens மற்றொரு இயந்திரத்தால் சுழற்றப்படலாம், நகலெடுக்கப்பட்ட உள்நுழைவுக்குப் புதுப்பிப்பு தேவைப்படும் நிலையை விட்டுச் செல்லும்; பல இயந்திரங்களில் ஒரே நேரத்தில் பயன்படுத்த தனித்தனி உள்நுழைவுகளே மிகவும் நம்பகமான தேர்வாக இருக்கும். [Codex-இன் கணக்கு அங்கீகார வழிகாட்டுதல்](https://developers.openai.com/codex/auth/ci-cd-auth) என்பதைப் பார்க்கவும்.

ஒரு வழங்குநருக்கு ஒரு கணக்கு செயலில் இருக்கும், மற்றும் ஒவ்வொரு புதிய அமர்வும் அதுவாகவே தொடங்கும்: `cx`, `cy`, ஒரு சாதாரண `claude`, `codex`, அல்லது `grok`, `omarchy agent` வழியாகத் தொடங்கப்படும் எதுவும், மற்றும் `PATH`-இல் CLI-ஐக் கண்டறியும் scripts அல்லது editors. `omarchy agent account use work` உடன் மாற்றவும் (மற்றும் `omarchy agent account use main` உடன் திரும்பவும்), அல்லது பேனலில் ஒரு கணக்கின் எண்ணை அழுத்தி பின்னர் `Enter` அழுத்துவதன் மூலம் (அல்லது அதன் Use பொத்தானைக் கிளிக் செய்வதன் மூலம்). ஏற்கனவே இயங்கும் அமர்வுகள் அவை தொடங்கிய கணக்கிலேயே இருக்கும். உரையாடல் வரலாறு, அமைப்புகள், திறன்கள், மற்றும் plugins கணக்குகள் முழுவதும் பகிரப்படும், எனவே அதே கோப்புறையில் `claude --continue` நீங்கள் புதிய கணக்கில் விட்ட இடத்திலிருந்து தொடரும்.

ஒன்றுக்கும் மேற்பட்ட கணக்குகளுடன், பேனல் ஒவ்வொரு கணக்கின் வரம்புகளையும் அருகருகே காட்டும், செயலில் உள்ளது குறிக்கப்பட்டிருக்கும். இயல்பாக Omarchy செயலில் உள்ள கணக்கு ஒரு வரம்பின் 95%-ஐக் கடக்கும்போது உங்களுக்கு அறிவிக்கும், மற்றும் அறிவிப்பைக் கிளிக் செய்வது அதிக இடவசதி உள்ள கணக்கிற்கு மாற்றும். பேனலில் ஒரு கணக்கின் வரியின் மீது hover செய்து Use-க்கு அருகில் தோன்றும் Autoswitch-ஐக் கிளிக் செய்யவும் (அல்லது `m` அழுத்தவும்), அல்லது அது தானாகவே மாற `omarchy agent account mode auto` என்பதை இயக்கவும்; அது இயக்கத்தில் இருக்கும்போது, Autoswitch Use-இன் இடத்தை எடுக்கும், மற்றும் அதை மீண்டும் கிளிக் செய்வது அறிவிப்பதற்குத் திரும்பும். `omarchy agent account mode auto 90` என்பதில் உள்ளது போல, வரம்பை மாற்ற ஒரு எண்ணைச் சேர்க்கவும். ஒவ்வொரு கணக்கும் வரம்புக்கு மேல் இருந்தால், எந்தக் கணக்கு முதலில் விடுபடும் என்பதுடன், அதைப் பற்றி ஒரு முறை கேட்பீர்கள். செயலில் உள்ள கணக்கு அதன் வரம்பிலிருந்து 15 புள்ளிகளுக்குள் இருக்கும்போது (இயல்புநிலையில் 80%), அதன் வரம்புகள் ஒவ்வொரு 15-க்கும் பதிலாக ஒவ்வொரு மூன்று நிமிடங்களுக்கும் சரிபார்க்கப்படும்.

`omarchy agent account list` ஒவ்வொரு கணக்கையும் அதன் சமீபத்திய வரம்புகளையும் காட்டும், `omarchy agent account remove work` ஒன்றை மறக்கும், மற்றும் `omarchy agent account rename primary Hey` ஒன்றிற்கு மறுபெயரிடும் (அல்லது பேனலில் ஒரு கணக்கின் பெயரைக் கிளிக் செய்யவும்). இந்தக் கட்டளைகள் உங்கள் இயல்புநிலை ஏஜெண்டின் கணக்குகளில் செயல்படும்; மற்ற வழங்குநரை அடைய, `omarchy agent account use codex side` என்பதில் உள்ளது போல, முதலில் அதன் பெயரைக் குறிப்பிடவும். `~/.claude` அல்லது `~/.codex`-இல் நீங்கள் ஏற்கனவே வைத்திருந்த உள்நுழைவு _Main_ கணக்கு மற்றும் அது இருக்கும் இடத்திலேயே இருக்கும். சுமார் எட்டு மணி நேரத்திற்கும் மேலாகப் பயன்படுத்தப்படாமல் விடப்பட்ட ஒரு கணக்கு _Sign-in required_ எனக் காட்டலாம்; பேனலிலேயே அந்தக் கணக்கில் மீண்டும் உள்நுழைய அதைக் கிளிக் செய்யவும், அல்லது அதில் ஒரு அமர்வைத் தொடங்கவும், இது உள்நுழைவைத் தானாகவே புதுப்பிக்கும். ஒரு கணக்கு சேர்க்கப்பட்டபோது நீங்கள் வைத்திருந்த MCP servers அதற்கு வரும், ஆனால் பின்னர் நீங்கள் `claude mcp add` உடன் சேர்ப்பவை நீங்கள் அவற்றைச் சேர்த்த கணக்கை மட்டுமே அடையும். Claude Desktop மற்றும் ஒரு CLI binary-க்கான absolute path உடன் உள்ளமைக்கப்பட்ட கருவிகள் மாற்றத்தைப் பின்பற்றாது. வெளிப்படையான `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, அல்லது `GROK_HOME` தேர்ந்தெடுக்கப்பட்ட கணக்கை விட முன்னுரிமை பெறும்.

### செயலிழப்பு கண்டறிதல்

Omarchy செயல்முறை செயலிழப்புகளுக்காக systemd-coredump-ஐக் கண்காணிக்கும். ஏதாவது segfault ஆகும்போது, உங்களுக்கு "Process crashed" அறிவிப்பு கிடைக்கும் — அதைக் கிளிக் செய்யவும், மற்றும் செயலிழப்பு Omarchy-இன் diagnose-crash திறனுடன் உங்கள் இயல்புநிலை ஏஜெண்டிடம் ஒப்படைக்கப்படும், இது core dump-இலிருந்து உண்மைகளை நிறுவுவதன் வழியாகவும் செயலிழப்பு upstream-இல் புகாரளிக்கத் தகுந்ததா என முடிவு செய்வதன் வழியாகவும் ஏஜெண்டை அழைத்துச் செல்லும். நீங்கள் அதை `coredumpctl list`-இலிருந்து எந்த PID-க்கு எதிராகவும் `omarchy agent crash <pid>` உடன் கையாலும் இயக்கலாம்.

கண்காணிப்பு இயல்பாக இயக்கத்தில் இருக்கும். அதை _Trigger > Toggle > Crash Capture_ கீழ் (அல்லது `omarchy toggle crash-capture` உடன்) அணைக்கவும் மற்றும் அறிவிப்புகள் நிற்கும்; `omarchy agent crash <pid>` இன்னும் கையால் செயல்படும்.

செயலிழப்புகளை ஒரு நேரத்தில் ஒரு நிரல் வீதமும் அமைதிப்படுத்தலாம், இதைத்தான் கண்டறிதல் இறுதியில் உங்களுக்கு வழங்குகிறது. `omarchy crash mute hyprland` அந்த நிரலுக்கான அறிவிப்புகளை மட்டும் நிறுத்தும், `omarchy crash mute hyprland off` அவற்றைத் திரும்பக் கொண்டு வரும், மற்றும் `omarchy crash mute` தனியாக நீங்கள் அமைதிப்படுத்தியதைப் பட்டியலிடும். இது binary-இன் பாதையை அதன் பெயரைப் போலவே மகிழ்ச்சியுடன் ஏற்கும், எனவே `omarchy crash mute /usr/bin/hyprland` அதே விஷயத்தைச் செய்யும். `omarchy crash mute 'Some App'` என்பதில் உள்ளது போல, இடைவெளி உள்ள பெயரை மேற்கோள் காட்டவும். மற்ற அனைத்தும் இன்னும் அறிவிக்கும், மற்றும் அமைதிப்படுத்தப்பட்ட நிரல் இன்னும் செயலிழக்கும் — இது நினைவூட்டலை மறைக்கிறது, இது எதையும் சரிசெய்யாது.

### டெஸ்க்டாப் பயன்பாடுகள்

_Install > AI_ மெனு சில வரைகலை AI பயன்பாடுகளையும் கொண்டுள்ளது: ChatGPT டெஸ்க்டாப் பயன்பாடு, Claude டெஸ்க்டாப் பயன்பாடு (Anthropic-இன் Linux beta, Chat, Cowork, மற்றும் Claude Code தாவல்களுடன்), xAI-இன் மாடல்களுடன் அரட்டை அடிக்க Grok Bot, Herdr Desktop, Hermes Desktop, OpenClaw, Perplexity டெஸ்க்டாப் பயன்பாடு, மற்றும் T3 Code. Grok Bot என்பது டெஸ்க்டாப் அரட்டைப் பயன்பாடு. குறியீட்டு ஏஜெண்ட் என்பது `grok` கட்டளை.

Hermes Desktop தான் தெரிந்து கொள்ள வேண்டியது, ஏனெனில் ஒரு இயந்திரத்தில் ஒரு Hermes உள்ளது, மற்றும் அது பயன்பாட்டினுடையது: Hermes எப்போதும் பயன்பாடு வழியாக மட்டுமே நிறுவப்படும், மற்றும் இயல்புநிலை ஏஜெண்ட் இயக்கும் `hermes` கட்டளை பயன்பாட்டினுடையது. Hermes-ஐ இயல்புநிலை ஏஜெண்டாகத் தேர்ந்தெடுப்பது _Install > AI_ உள்ளீடு செய்வதையே நிறுவும்: தொகுப்பு, மற்றும் Hermes-இன் சொந்த நிறுவியால் அமைக்கப்பட்ட `~/.hermes` கீழ் ஒரு Hermes runtime, இது முதல் முறை சில நிமிடங்கள் எடுக்கும். அந்த runtime தான் முனைய `hermes` கட்டளை, இயல்புநிலை ஏஜெண்ட் மற்றும் பயன்பாடு அனைத்தும் பயன்படுத்தும் ஒரே Hermes, மற்றும் இது Omarchy வெளியீட்டிற்காகக் காத்திருக்காமல் `hermes update` உடன் தன்னைத்தானே புதுப்பிக்கும். அதை நிறுவுவது Hermes-க்கு Omarchy theme-ஐ `omarchy` என்ற பெயரிடப்பட்ட skin ஆகவும் வழங்குகிறது, நீங்கள் theme-களை மாற்றும்போது ஒவ்வொரு Hermes மேற்பரப்பும் அதைப் பின்பற்றும்; அது வேண்டாம் என்றால் Hermes-இன் Appearance அமைப்புகள் கீழ் அல்லது `/skin` உடன் மற்றொன்றைத் தேர்ந்தெடுக்கவும், மற்றும் Omarchy அந்தத் தேர்வை அப்படியே விட்டுவிடும். _Remove > AI_ கீழ் பயன்பாட்டை அகற்றுவது முதலில் Hermes-ஐ மூடும், gateway உட்பட, அந்த runtime-ஐ அதனுடன் எடுத்துச் செல்லும், மற்றும் நீங்கள் வேறுவிதமாகச் சொன்னால் தவிர உங்கள் அரட்டைகள், நினைவுகள், மற்றும் Hermes தனக்காக எழுதிய திறன்களை வைத்திருக்கும்: அந்தத் தரவும் உங்கள் இணைப்பு அமைப்புகளும் கூடச் செல்ல வேண்டுமா என இது கேட்கும், இயல்புநிலை இல்லை என்பதாகும்.

OpenClaw-இன் டெஸ்க்டாப் அனுபவம் அதன் Control UI ஆகும், இது அதன் சொந்த உள்ளூர் gateway ஆல் ஆதரிக்கப்படும் ஒரு வலைப் பயன்பாடாகத் திறக்கும். OpenClaw `~/.openclaw`-இல் வாழ்கிறது மற்றும் தன்னைத்தானே புதுப்பிக்கிறது: Control UI-இன் "Update Gateway" பொத்தானைப் பயன்படுத்தவும் அல்லது `openclaw update` என்பதை இயக்கவும், மற்றும் gateway புதிய பதிப்பில் மறுதொடக்கம் செய்யும். Omarchy புதிய நிறுவல் எந்த வெளியீட்டிலிருந்து தொடங்குகிறது என்பதை மட்டும் தேர்ந்தெடுக்கும். _Remove > AI_ கீழ் OpenClaw-ஐ அகற்றுவது gateway சேவையையும் பயன்பாட்டையும் அதனுடன் எடுத்துச் சென்று பின்னர் `~/.openclaw` கூடச் செல்ல வேண்டுமா எனக் கேட்கும், ஏனெனில் அது OpenClaw-உடனும் அது பதிவிறக்கும் plugin runtime-களுடனும் உங்கள் அரட்டைகள் மற்றும் நற்சான்றிதழ்களை வைத்திருக்கிறது; இயல்புநிலை அதை வைத்திருக்கும், மற்றும் OpenClaw-ஐ மீண்டும் நிறுவுவது அதை மீண்டும் எடுத்துக் கொள்ளும்.

Herdr Desktop என்பது [Herdr](https://herdr.dev) டெஸ்க்டாப் பயன்பாடு: நீங்கள் சாளரத்தை மூடும்போது அதன் core-இல் தொடர்ந்து இயங்கும் முனையங்கள் மற்றும் குறியீட்டு ஏஜெண்ட்களின் spaces, tabs, மற்றும் panes. இது ஒரு தொகுப்பிலிருந்து அல்லாமல் Herdr-இன் சொந்த நிறுவியிலிருந்து வருகிறது, எனவே இது `~/.local/share/herdr-app`-இல் வாழ்கிறது, உங்களிடம் இன்னும் ஒன்று இல்லாதபோது அதன் core-ஐ `~/.local/bin/herdr-core`-இல் கொண்டு வருகிறது, மற்றும் இரண்டையும் தானே புதுப்பிக்கிறது. இது `Super + Ctrl + Return`-இல் Omarchy வழங்கும் `herdr` கட்டளையை மாற்றாமல் அதற்கு அருகில் அமர்ந்திருக்கிறது, மற்றும் அந்தக் கட்டளையின் நேரடி விசைகளைப் பெறுகிறது: `Alt + Return` மற்றும் `Alt + Shift + Return` ஒரு pane-ஐ கீழே அல்லது வலதுபுறம் பிரிக்கும், `Alt + Escape` அதை மூடும், `Ctrl + Alt + Arrow` pane-களுக்கிடையே நகர்த்தும், `Alt + 1..9` மற்றும் `Alt + Left/Right` ஒரு tab-ஐத் தேர்ந்தெடுக்கும், மற்றும் `Alt + Up/Down` space-களுக்கிடையே நகர்த்தும். `Ctrl + 1..9` ஒரு space-ஐத் தேர்ந்தெடுக்கும் மற்றும் `Alt + Shift + Up/Down` ஏஜெண்ட்கள் வழியாகச் செல்லும். `Ctrl + Space` prefix விசைகள் முனையத்திற்கு மட்டுமே இருக்கும், ஏனெனில் பயன்பாடு ஒரு வரிசைக்காக ஒரு சாதாரண Ctrl விசையைப் பிடித்து வைக்க முடியாது. Omarchy இவற்றை `~/.config/herdr-app/keys.json`-இல் எழுதும், மற்றும் `omarchy-refresh-herdr-app` அவற்றைத் திரும்ப வைக்கும். அதை நிறுவுவது Herdr-இன் Omarchy theme-ஐத் தேர்ந்தெடுக்கும், இது அப்போதிலிருந்து உங்கள் Omarchy theme-ஐப் பின்பற்றும். Herdr light mode-க்கு ஒரு theme-ஐயும் dark-க்கு ஒன்றையும் வைத்திருக்கிறது, எனவே இருண்ட மற்றும் வெளிர் Omarchy theme-க்கிடையே மாறிய பிறகு, மற்ற mode-க்காக Herdr-இன் theme தேர்வியில் Omarchy-ஐ மீண்டும் ஒரு முறை தேர்ந்தெடுக்கவும்.

T3 Code ஒரு தொகுப்பிலிருந்து அல்லாமல் `~/.local/share/t3code`-இல் அதன் அதிகாரப்பூர்வ AppImage வெளியீட்டிலிருந்து இயங்குகிறது, எனவே இது தன்னைத்தானே புதுப்பிக்கிறது. அதை நிறுவுவது Stable அல்லது Nightly channel-இல் தொடங்க வேண்டுமா எனக் கேட்கும்; பின்னர் T3 Code-இன் அமைப்புகளில் மாற்றவும். உங்கள் threads மற்றும் அமைப்புகள் `~/.t3`-இல் வாழ்கின்றன, மற்றும் _Remove > AI_ கீழ் T3 Code-ஐ அகற்றுவது அவற்றை அதனுடன் எடுத்துச் செல்லும்.

### உள்ளூர் மாடல்கள்

உங்கள் குறியீட்டு ஏஜெண்ட்களுக்காக உங்கள் சொந்த இயந்திரத்தில் ஒரு திறந்த மாடலை இயக்கவும். உங்கள் prompt-கள் மற்றும் குறியீடு இயந்திரத்திலேயே இருக்கும்; மாடலுக்கு அனுப்பப்படும் எதுவும் அதை விட்டு வெளியேறாது. இதனுடன் தொடங்கவும்:

```bash
omarchy agent local use best
```

அல்லது, மேல் பட்டியில் உள்ள ஏஜெண்ட்கள் பேனலில், + மற்றும் பின்னர் Local AI-ஐத் தேர்ந்தெடுக்கவும், இது ஒரு மாடல் இந்த இயந்திரத்திற்குப் பொருந்தும்போது தோன்றும். முதல் முறை, இது மாடல்களை இயக்கும் Podman-ஐ நிறுவும், மற்றும் NVIDIA இயந்திரத்தில் அவற்றுக்கு GPU-ஐக் கொடுக்கும் NVIDIA-இன் container toolkit-ஐ நிறுவும். Omarchy பின்னர் இந்த இயந்திரத்திற்குப் பரிந்துரைக்கப்பட்ட மாடலைத் தேர்ந்தெடுத்து, அதைப் பதிவிறக்கி, தொடங்கும். பத்துகள் GB பதிவிறக்கத்தை எதிர்பார்க்கவும் மற்றும் மாடல் இயங்கும்போது இயந்திரத்தின் நினைவகத்தின் பெரும்பகுதி பயன்பாட்டில் இருக்கும்: Flash Next அதன் முழு 256K context உடன் சுமார் 100 GiB பயன்படுத்துகிறது. அதற்குத் தேவையான நினைவகத்தை மற்ற மாடல்கள் வைத்திருந்தால், அது நிறுத்தப்பட்ட நிலையில் அமைக்கப்படும், நீங்கள் ஒன்றை நிறுத்தியவுடன் தொடங்கத் தயாராக இருக்கும். மாடல் வெளியேறும்போது நிற்கும்; வேறு ஏதாவதற்கு நினைவகம் தேவைப்படும்போது அதை நீங்களே நிறுத்தவும்.

`omarchy agent local list` விருப்பங்களைக் காட்டும் மற்றும் சில ஏன் பொருந்தவில்லை என விளக்கும். மற்றொன்றை அமைக்க, `omarchy agent local use <recipe>` என்பதை இயக்கவும். இன்று, `qwen3.8-flash-next-gufo` மற்றும் `qwen3.8-27b-gufo` 128 GB Strix Halo இயந்திரங்களுக்குக் கிடைக்கின்றன; 27B சுமார் 40 GiB எடுக்கும், எனவே இது மற்ற வேலைகளுக்கு இடம் விடுகிறது. புதிய recipes மற்றும் பரிந்துரைகள் தொகுப்பு வழியாக `omarchy update` உடன் வரும்.

நீங்கள் அமைக்கும் ஒவ்வொரு மாடலுக்கும் ஏஜெண்ட்கள் பேனலில், உங்கள் சந்தாக்களுக்கு அடுத்து, அதன் சொந்த வரி கிடைக்கும்: அதைத் தொடங்க play, அதை நிறுத்தி அதன் நினைவகத்தை விடுவிக்க pause, மற்றும் அதில் உங்கள் ஏஜெண்டைத் திறக்க terminal பொத்தான். அவை நினைவகத்தில் ஒன்றாகப் பொருந்தும்போது பல ஒரே நேரத்தில் இயங்க முடியும்; ஒன்று பொருந்தவில்லை என்றால், இயங்கும் எந்த மாடலை நிறுத்த வேண்டும் என Omarchy சொல்லும். அவற்றை மறுவரிசைப்படுத்த வரிகளை இழுக்கவும், மற்றும் ஒரு மாடலையும் அதன் பதிவிறக்கத்தையும் அகற்ற தேர்ந்தெடுக்கப்பட்ட வரியில் Delete அழுத்தவும்.

கட்டளை வரியிலிருந்து, `omarchy agent local start <recipe>` மற்றும் `omarchy agent local stop <recipe>` அதையே செய்யும், `omarchy agent local status` ஒவ்வொரு மாடலையும் காட்டும், மற்றும் `omarchy agent --local` நீங்கள் கடைசியாகத் தொடங்கிய மாடலில் உங்கள் இயல்புநிலை ஏஜெண்டைத் திறக்கும் (உங்கள் இயல்புநிலை ஏஜெண்டால் உள்ளூர் மாடலைப் பயன்படுத்த முடியாவிட்டால் pi). எந்த OpenAI-இணக்கமான client-உம் இணைக்க முடியும்: `status` ஒவ்வொரு மாடலின் முகவரியையும் காட்டும் (முதலாவது `http://127.0.0.1:11435/v1`), recipe பெயரே மாடல், மற்றும் விசை `~/.config/omarchy/agent-local/key`-இல் உள்ளது.

`omarchy agent local remove <recipe>` ஒரு மாடலையும் வேறு எந்த மாடலும் பயன்படுத்தாத பதிவிறக்கங்களையும் நீக்கும்.

மூன்றாம் தரப்பு runtime-கள் அவற்றின் வெளியீட்டாளருடன் பெயரிடப்படும். Omarchy ஒவ்வொரு மாடலையும் பிணைய அணுகல் இல்லாமல் இயக்கும்.

### உள்ளூர் LLMகள்

Omarchy உள்ளூர் LLM மாடல்களை இயக்க இரண்டு வழிகளைப் பரிந்துரைக்கிறது: LM Studio மற்றும் Ollama. LM Studio திறந்த-எடை மாடல்களைக் கண்டறிந்து, நிறுவி, இயக்க ஒரு GUI இடைமுகத்தை வழங்குகிறது. எளிதாகத் தொடங்க இது ஒரு சிறந்த வழி. Ollama அதேபோல் செய்ய ஒரு CLI-ஐ வழங்குகிறது. ஆனால் நீங்கள் உள்ளூர் மாடல்களுக்குப் புதியவர் என்றால், நான் LM Studio உடன் தொடங்குவேன். Omarchy Menu-இல் _Install > AI_ கீழ் இரண்டில் ஒன்றை நிறுவலாம்.

### Omarchy Skill

ஏஜெண்ட் திறன்கள் AI குறிப்பிட்ட கருவிகளைக் குறிப்பிட்ட விதத்தில் பயன்படுத்த உதவுகின்றன, மற்றும் Omarchy கணினியைத் தனிப்பயனாக்க ஒரு இயல்புநிலைத் திறனுடன் வருகிறது. உங்கள் Hyprland config-ஐ மாற்றுவது, பட்டியைச் சரிசெய்வது, அல்லது புதிதாக ஒரு theme-ஐ உருவாக்குவது போல. இது Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` மற்றும் ஒவ்வொரு `~/.hermes/profiles/*/skills`), மற்றும் பொதுவான `~/.agents/skills` இடத்திற்கான திறன் கோப்பகங்களில் symlinked செய்யப்பட்டுள்ளது, எனவே பெரும்பாலான harness-கள் அதைத் தானாகவே எடுத்துக் கொள்ளும்.

ஆனால் நீங்கள் இந்தத் திறனைச் சோதனை முறையாகக் கருத வேண்டும். வெவ்வேறு மாடல்கள் அதை வெவ்வேறு விளைவுகளுக்குப் பயன்படுத்தும். முதலில் plan mode-இல் இயக்குவது சிறந்தது, எனவே ஏஜெண்ட் எதை மாற்ற விரும்புகிறது என்பது பற்றி உங்களுக்கு ஒரு யோசனை இருக்கும். மற்றும் ஏஜெண்ட் எல்லாவற்றையும் குழப்பினால், மாற்றங்களைத் திரும்பப் பெற அல்லது `omarchy reinstall configs` என்பதைக் கூட அழைக்கத் தயாராக இருங்கள்.
