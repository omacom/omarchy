Hermes மற்றும் OpenClaw ஆகியவை விதிவிலக்குகள்: அவற்றுக்கு mise வழியாக எதுவும் நிறுவப்படுவதில்லை, மேலும் இரண்டில் ஒன்றைத் தேர்ந்தெடுப்பது அதன் சொந்த தானாகப் புதுப்பிக்கும் நகலை அமைக்கிறது, கீழே உள்ள _டெஸ்க்டாப் பயன்பாடுகள்_ விளக்குவது போல.

### ஏஜென்ட்களை நிறுவுதல் மற்றும் புதுப்பித்தல்

Hermes மற்றும் OpenClaw தவிர, இந்த ஏஜென்ட்கள் mise இன் சோம்பேறி நிறுவலைப் பயன்படுத்துகின்றன: முதல் தொடக்கம் CLI ஐ நிறுவுகிறது, பின்னர் வரும் தொடக்கங்கள் அதையே மீண்டும் பயன்படுத்துகின்றன. நிறுவப்பட்ட ஏஜென்ட்டுக்கு புதிய வெளியீடு உள்ளதா என்பதையும் mise அதிகபட்சம் நான்கு மணிநேரத்திற்கு ஒருமுறை சரிபார்க்கிறது, அது தொடங்குவதற்குச் சற்று முன்பு அல்லது shell prompt இல் பின்னணியில். அந்தப் புதுப்பிப்பு தோல்வியடைந்தால் அல்லது நீங்கள் ஆஃப்லைனில் இருந்தால், நிறுவப்பட்ட பதிப்பு இயங்கும். `omarchy update` ஆனது Omarchy இன் மீதியுடன் சேர்த்து நிறுவப்பட்ட ஏஜென்ட்களையும் புதுப்பிக்கிறது, மேலும் `mup` ஆனது mise ஆல் நிர்வகிக்கப்படும் கருவிகளை மட்டும் புதுப்பிக்கிறது.

`claude update`, `codex update` போன்ற ஒரு ஏஜென்ட்டின் சொந்தப் புதுப்பிப்பான், அல்லது ஒரு பயன்பாட்டில் உள்ள புதுப்பிப்பு பொத்தான், mise ஆல் நிர்வகிக்கப்படும் நிறுவலைப் புதுப்பிக்காது. `codex update` தோல்வியடையும், மேலும் `claude update` வெற்றி என்று அறிவித்துவிட்டு mise கண்காணிக்காத தனி நகலை நிறுவக்கூடும். ஒரு ஏஜென்ட்டின் சொந்த நிறுவி மற்றும் புதுப்பிப்பானையே நீங்கள் பயன்படுத்த விரும்பினால், அதை `disable_tools` இல் சேர்க்கவும்; [முன்பே நிறுவப்பட்ட CLI கருவிகள்](18-development-tools.md#preinstalled-cli-tools) ஐப் பார்க்கவும்.

உங்களுக்குத் தேவைப்படுவதற்கு முன்பே கட்டமைக்கப்பட்ட அனைத்து சோம்பேறி கருவிகளையும் நிறுவ, `mise install --include-lazy` ஐ இயக்கவும். இதில் Omarchy இன் மற்ற இயல்புநிலை CLI கருவிகளும் ஏஜென்ட்களும் அடங்கும். ஒரு தனி கருவியை நிறுவுவது அல்லது உங்கள் சொந்த நிறுவலைப் பயன்படுத்துவது குறித்து [முன்பே நிறுவப்பட்ட CLI கருவிகள்](18-development-tools.md#preinstalled-cli-tools) ஐப் பார்க்கவும்.

`grok` ஆனது mise இன் முதல் தரப்பு `grok` தொகுப்பு வழியாக நிறுவப்படுகிறது, `claude` மற்றும் `codex` போலவே. `grok` ஐ இயக்கவும், அல்லது ஏஜென்ட்கள் பேனலில் அதை நட்சத்திரமிடவும். x.ai இல் உள்ள `curl | bash` நிறுவியைத் தவிர்க்கவும். அந்த வழி இரண்டாவது நகலை `~/.grok/bin` இல் வைக்கிறது, அதை `PATH` இல் முன்னால் சேர்க்கிறது, மேலும் Omarchy இன் wrapper ஐ மேலெழுதுகிறது.

`dsh` அதன் உலாவி UI ஐ `127.0.0.1:3080` இல் திறக்கிறது, தொடக்க அடைவையே அதன் இயல்புநிலை workspace ஆகக் கொண்டு. அதன் உலாவி UI தொடக்க prompt ஐ ஏற்காது, எனவே `omarchy agent prompt` அதை உங்கள் clipboard இல் prompt ஐ ஒட்டுவதற்காக வைத்துத் திறக்கிறது. DeepSeek இன் ஒப்புதல் இல்லாத அனுமதி preset உடன் Omarchy அதைத் தொடங்குகிறது. DeepSeek Harness, நீங்கள் அதன் அதிகாரப்பூர்வ மாதிரி API ஐப் பயன்படுத்தும்போது, அமர்வு பதிவுகளை DeepSeek க்கு பதிவேற்றுகிறது; அதன் உலாவி UI இல் _Settings > General > Upload Session Log_ இன் கீழ் அதை அணைக்கவும். நீங்கள் அதற்கு அனுப்பும் கருத்தும் அமர்வுடன் சேர்த்து பதிவேற்றப்படும், நீங்கள் அதை `DSH_TELEMETRY_MODE=DISABLED` உடன் தொடங்கினால் தவிர.

### இயல்புநிலை ஏஜென்ட்

ஏஜென்ட்கள் பேனலில் ஒரு ஏஜென்ட்டுக்கு அருகில் உள்ள நட்சத்திரத்தைக் கொண்டு உங்கள் இயல்புநிலை ஏஜென்ட்டைத் தேர்ந்தெடுக்கவும், அது இயல்புநிலையில் நிரப்பப்பட்டிருக்கும், அல்லது `omarchy default agent <name>` உடன், இது அங்கு ஒரு வரி இல்லாத எந்த harness ஐயும் ஏற்கும். ஏஜென்ட் இன்னும் நிறுவப்படவில்லை என்றால், அதைத் தேர்ந்தெடுப்பது முதலில் அதை நிறுவும், மேலும் Agent க்கு அருகில், பயன்பாட்டு தொடக்கியில் அதற்கென தனி தொடக்கியும் கிடைக்கும். புதிய Omarchy ஒன்று, ஒருமுறை மட்டும் வரும் அறிவிப்பின் மூலம் ஒன்றை அமைக்க உங்களை அழைக்கிறது, அது ஏஜென்ட்கள் பேனலைத் திறக்கும்.

Claude ஐத் தேர்ந்தெடுப்பது Chromium, Chrome, Brave, Brave Origin, மற்றும் Edge க்கான அதன் உலாவி நீட்டிப்பையும் அமைக்க முயற்சிக்கிறது. நீட்டிப்பு அமைப்பு அனைத்து பயனர்களுக்கும் பொருந்தும் மற்றும் உங்கள் கணினி கடவுச்சொல்லைக் கேட்கக்கூடும்; ரத்து செய்வது அல்லது நீட்டிப்பு நிறுவல் தோல்வியடைவது கூட Claude ஐத் தேர்ந்தெடுத்து தொடங்கும். உங்கள் உலாவியை மறுதொடக்கம் செய்யவும், கேட்கப்பட்டால் நீட்டிப்பை இயக்கவும், அதை இணைப்பதை முடிக்க Claude இல் உள்நுழையவும். இணைப்பைச் சரிபார்க்க Claude இல் `/chrome` ஐ இயக்கவும். Firefox மற்றும் Zen இந்த நீட்டிப்பை ஆதரிக்காது. இந்த அமைப்பு சேர்க்கப்படுவதற்கு முன்பே Claude ஏற்கனவே உங்கள் இயல்புநிலையாக இருந்தால், நீட்டிப்பை நிறுவ அதை மீண்டும் தேர்ந்தெடுக்கவும்.

நீங்கள் தேர்ந்தெடுத்த பிறகு, `Super + Shift + Ctrl + A` ஆனது இயல்புநிலை ஏஜென்ட்டை ஒரு பிரத்யேக டெர்மினல் சாளரத்தில் தொடங்கும் (அல்லது நீங்கள் இன்னும் தேர்ந்தெடுக்கவில்லை என்றால் தேர்வியைக் கொண்டு வரும்). `omarchy agent prompt "Review this project"` உடன் அதை நேரடியாக ஒரு பணியிலும் தொடங்கலாம். Freebuff மற்றும் DeepSeek Harness தொடக்க prompt ஐ ஏற்காது, எனவே அவை அதற்குப் பதிலாக உங்கள் clipboard இல் prompt ஐ ஒட்டுவதற்காக வைத்துத் திறக்கும். இவ்வாறு தொடங்கப்படும் ஏஜென்ட்கள் அவற்றின் அந்தந்த கேட்க நிறுத்தாத பயன்முறைகளில் கவனிப்பின்றி இயங்கும், எனவே அவை உண்மையில் செயல்களைச் செய்யத் தயாராக இருங்கள்! MiniMax Code க்கு அதன் ஊடாடும் அமர்வுகளுக்கு அத்தகைய பயன்முறை இல்லை, எனவே அது வழக்கம் போல அனுமதிகளைக் கேட்கும். மேலும் ஏஜென்ட்கள் உங்கள் home அடைவுக்கான நம்பிக்கையை நினைவில் வைக்க மறுப்பதால், `$HOME` இலிருந்து தொடங்குவது அதற்குப் பதிலாக `~/Work` இல் தொடங்கும்.

டெர்மினல் குறுக்குவழிகளும் உள்ளன: `a` ஆனது தற்போதைய டெர்மினலில் இயல்புநிலை ஏஜென்ட்டை inline ஆக இயக்குகிறது, அதே நேரத்தில் `c`, `cx`, மற்றும் `cy` ஆகியவை OpenCode, Claude Code, மற்றும் Codex ஐ நேரடியாகத் தொடங்குகின்றன (மீண்டும் அவற்றின் தானாக ஒப்புதல் அளிக்கும் பயன்முறைகளில்). தீம் மாற்றங்களும் ஏஜென்ட்களுக்கு ஒத்திசைகின்றன: Claude Code, Pi, OpenCode, மற்றும் Hermes (Omarchy அதை நிறுவிய பிறகு) ஆகிய அனைத்தும் நீங்கள் Omarchy தீமை மாற்றும்போது அதனுடன் சேர்ந்து மாறும்.

### உங்கள் ஏஜென்ட் வழிமுறைகள்

ஒவ்வொரு ஏஜென்ட்டுக்கான தனிப்பட்ட விதிகள் `~/.agents/AGENTS.md` இல் செல்கின்றன, `~/.agents/skills` இல் உள்ள பகிரப்பட்ட திறன்களுக்கு அருகில். ஏஜென்ட்கள் பேனலில் + க்கு அருகில் உள்ள ஆவண ஐகானைக் கொண்டு அதைத் திறக்கவும், அல்லது `omarchy agent instructions --edit` உடன், இது அதை தனது சொந்த global கோப்பை வைத்திருக்கும் ஒவ்வொரு harness இலும் இணைக்கிறது: `~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.pi/agent/AGENTS.md`, `~/.config/opencode/AGENTS.md`, Copilot இன் `~/.copilot/copilot-instructions.md`, மற்றும் பல. Crush மற்றும் Amp ஆகியவை `~/.config/AGENTS.md` இணைப்பைப் படிக்கின்றன, அதே நேரத்தில் omp, Kimi, மற்றும் DeepSeek Harness ஆகியவை `~/.agents/AGENTS.md` ஐ நேரடியாகப் படிக்கின்றன. இயல்புநிலை ஏஜென்ட்டைத் தேர்ந்தெடுப்பதும் அதை இணைக்கிறது. நீங்கள் ஏற்கனவே வைத்திருந்த வழிமுறைகள் கோப்பு, இன்னும் ஒன்று இல்லை என்றால் பகிரப்பட்டதாக மாறும்; இல்லையெனில் அது இணைப்புக்கு அருகில் `.bak` ஆக வைக்கப்படும். மற்றொரு ஏஜென்ட்டை நிறுவிய பிறகு மீண்டும் இணைக்க `omarchy agent instructions` ஐ இயக்கவும்.

### ஏஜென்ட்கள் பேனல்

மேல் பட்டியில் ஒரு ஏஜென்ட்கள் ஐகான் உள்ளது. நீங்கள் ஒரு ஏஜென்ட்டை அமைப்பதற்கு முன்பு, அதன் பேனல் தொடங்க மூன்று வழிகளை வழங்குகிறது: Claude, Codex, Grok, Gemini, Muse, Cursor, அல்லது Copilot சந்தாவில் உள்நுழையவும், அல்லது More இன் கீழ் OpenCode Go, MiniMax, Synthetic, அல்லது Z.ai குறியீட்டுத் திட்டம்; Fireworks, OpenCode Zen and Go, OpenRouter உடன் பயன்பாட்டுக்கு ஏற்ப பணம் செலுத்தவும், அல்லது More இன் கீழ் DeepSeek அல்லது OpenCode உள்நுழையும் வேறு எந்த வழங்குநரும், அனைத்தும் OpenCode இல் இயங்கும்; அல்லது உங்கள் கணினிக்கு ஒன்று பொருந்தும்போது அதற்கான சிறந்த மாதிரியை இயக்கவும். நீங்கள் முதலில் முடிப்பது உங்கள் இயல்புநிலை ஏஜென்ட் ஆகும், மேலும் பேனலில் உள்ள +, அல்லது Omarchy Menu வில் _Agent > Add_ ஆகியவை பின்னர் அதே மூன்றையும் வழங்கும். அதற்குப் பிறகு, பேனல் ஒவ்வொரு சந்தாவையும் ஒரே பக்கத்தில் வைக்கிறது: ஒவ்வொரு ஏஜென்ட் மற்றும் கணக்கும் அதன் திட்டத்துடன், அதன் 5 மணிநேர அமர்வு மற்றும் வாராந்திர வரம்புகள் ஒவ்வொன்றுக்கும் ஒரு மீட்டர், அது மீட்டமைக்கப்படும் வரையிலான நேரத்துடன் (சரியான சதவீதத்திற்கு hover செய்யவும்), அல்லது மீதமுள்ள prepaid இருப்பு, இந்த வார டோக்கன்கள் மற்றும் நீங்கள் அதிகம் பயன்படுத்திய மாதிரி போல, அவை அனைத்திலும் நீங்கள் பயன்படுத்தியதைச் சுழற்றும் ஒரு வரியின் கீழ். _Make something cool_ இன் கீழ் இது புதிய தீம், plugin, app, அல்லது game க்கான தொடக்க prompt களை வழங்குகிறது, அவை பணியை உங்கள் இயல்புநிலை ஏஜென்ட்டிடம் ஒப்படைக்கின்றன. பயன்பாடுகள் Omarchy இன் சொந்த Hype, Monologue, மற்றும் Omacut கட்டமைக்கப்படும் விதத்திலேயே, C++ மற்றும் Qt Quick இல், omarchy-make-app ஏஜென்ட் திறனைப் பின்பற்றி கட்டமைக்கப்படுகின்றன, மேலும் அவற்றுக்குத் தேவையான compiler மற்றும் Qt பாகங்கள் நிறுவப்பட்டு வருகின்றன. விளையாட்டுகள் `~/Games/vibes` இல் உள்ள ஒற்றை three.js பக்கம், omarchy-make-game ஏஜென்ட் திறனைப் பின்பற்றி, மேலும் அனைத்தும் தற்போதைய தீமில் ஒரு Game Vibes தொடக்கியிலிருந்து திறக்கும்; அவை three.js ஐ வலையிலிருந்து ஏற்றுகின்றன, எனவே தொடங்க அவற்றுக்கு இணைப்பு தேவை. Claude Code, Codex, Grok, Kimi, Cursor மற்றும் அதன் Grok Bot அனுமதி, GitHub Copilot, Muse, Gemini (Antigravity வழியாக), மற்றும் Devin ஆகியவை அவற்றின் வரம்புகளுடன் தொடக்கத்திலிருந்தே உள்ளடக்கப்பட்டுள்ளன, Kimchi அதன் திட்டம், prepaid வரவுகள், மற்றும் செலவு வரவுசெலவுத் திட்டங்களுடன், மேலும் Hermes, Mistral Vibe, மற்றும் Qwen Code ஆகியவை நீங்கள் அவற்றைப் பயன்படுத்திய பிறகு அவற்றின் அமர்வுகள் மற்றும் டோக்கன்களைக் காட்டுகின்றன. pi, omp, அல்லது opencode வழியாக நீங்கள் பயன்படுத்தும் வழங்குநர் திட்டங்கள் மற்றும் விசைகளும் தோன்றும்: OpenCode Zen and Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan, மற்றும் Synthetic அவற்றின் வரம்புகளுடன்; OpenRouter மற்றும் DeepSeek அவற்றின் prepaid இருப்புகளுடன்; Fireworks கடந்த 30 நாட்களில் அதன் செலவுடன். உங்கள் சொந்த hardware இல் நீங்கள் இயக்கும் மாதிரிகளிலிருந்து வரும் டோக்கன்களும் மொத்தங்களில் கணக்கிடப்படும்; மாதிரிகளுக்கே தனி பேனல் உள்ளது, [உள்ளூர் மாதிரிகள்](#local-models) இன் கீழ் விவரிக்கப்பட்டுள்ளது. ஒவ்வொரு ஏஜென்ட்டும் ஒருமுறை மட்டுமே கணக்கிடப்படுகிறது, அதற்கு பில் செய்பவரின் கீழ், நீங்கள் எத்தனை harness கள் வழியாக அதை இயக்கினாலும்.

பேனலுக்கு பட்டி ஐகானை இடது-கிளிக் செய்யவும் அல்லது `Super + Ctrl + X` ஐ அழுத்தவும், உங்கள் இயல்புநிலை ஏஜென்ட்டைத் தொடங்க வலது-கிளிக் செய்யவும், புதுப்பிக்க நடு-கிளிக் செய்யவும். அதன் பின்னால் உள்ள பயன்பாட்டு பதிவுகள் ஒவ்வொரு 15 நிமிடங்களுக்கும் `omarchy agent usage update` ஆல் மீண்டும் உருவாக்கப்படுகின்றன, மேலும் பேனல் ஒத்திசைக்கப்பட்ட கோப்புறை வழியாக உங்கள் மற்ற இயந்திரங்களிலிருந்து பயன்பாட்டைக் கூட இணைக்க முடியும். முழு அமைப்புகளுக்கு `$OMARCHY_PATH/shell/plugins/agents/` இன் கீழ் உள்ள README ஐப் பார்க்கவும்.

### பல சந்தாக்கள்

நீங்கள் ஒன்றுக்கு மேற்பட்ட Claude, Codex, அல்லது Grok திட்டங்களுக்கு பணம் செலுத்தினால் — தனிப்பட்ட Max மற்றும் வேலைக்கான ஒன்று என்று வைத்துக்கொள்வோம் — Omarchy அவை அனைத்தையும் உள்நுழைந்த நிலையில் வைத்து அவற்றுக்கிடையே நகர முடியும். ஏஜென்ட்கள் பேனலில் உள்ள + உடன் ஒரு சந்தாவைச் சேர்க்கவும், அது அங்கேயே உங்களை அதன் வழியாக அழைத்துச் செல்லும், அல்லது `omarchy agent account add claude Work` உடன் (அல்லது `codex`, அல்லது `grok`). அதே + மற்றும் கட்டளை Gemini (`gemini`) மற்றும் OpenCode (`opencode`) இல் உள்நுழைகிறது, மேலும் Fireworks (`fireworks`) அல்லது OpenRouter (`openrouter`) API விசையை OpenCode இல் சேமிக்கிறது; கட்டளை Copilot (`copilot`), Cursor (`cursor`), மற்றும் Muse (`muse`) இலும் உள்நுழைகிறது. அவை ஒவ்வொன்றும் ஒரு உள்நுழைவை மட்டும் வைத்திருக்கும். CLI விடுபட்டிருந்தால் அது அதை நிறுவும். ஒரு வழங்குநருக்கான முதல் கணக்கு உங்கள் சாதாரண உலாவி வழியாக உள்நுழைகிறது, CLI எப்போதும் பார்க்கும் இடத்திலேயே. அதற்குப் பிறகு வரும் ஒவ்வொன்றும் தனிப்பட்ட சாளரம் வழியாக உள்நுழைகிறது, எனவே உங்கள் உலாவி ஏற்கனவே உள்நுழைந்துள்ள கணக்கு தவறுதலாக எடுக்கப்படாது; நீங்கள் சேர்க்கும் கணக்காக அங்கு உள்நுழையவும், மேலும் நீங்கள் ஏற்கனவே திறந்து வைத்திருந்த எந்த தனிப்பட்ட சாளரத்தையும் முதலில் மூடவும். இதைச் செய்ய CLI இலிருந்து ஒருபோதும் வெளியேற வேண்டாம்: வெளியேறுவது சேமிக்கப்பட்ட உள்நுழைவை ரத்து செய்யும், மேலும் அந்தக் கணக்கு மீண்டும் சேர்க்கப்பட வேண்டும்.

SSH வழியாக உங்கள் சந்தா உள்நுழைவுகளை மற்றொரு Omarchy இயந்திரத்திற்கு நகலெடுக்க, `omarchy agent account copy user@laptop` ஐ இயக்கவும். இலக்கில் ஒன்று நிறுவப்படாதபோது அனுப்புநர் தற்காலிக பெறுநரை வழங்குகிறது, எனவே பழைய Omarchy இயந்திரங்கள் புதுப்பிப்பு இல்லாமல் கணக்குகளைப் பெற முடியும். நிறுவப்பட்ட பெறுநர்களுக்கு முன்னுரிமை கிடைக்கும். இது அனைத்து Claude, Codex, மற்றும் Grok சந்தாக்களையும் நகலெடுக்கிறது; அவற்றைத் தேர்ந்தெடுக்க வழங்குநர் பெயர்களைச் சேர்க்கவும், `omarchy agent account copy laptop claude` இல் உள்ளது போல. கணக்கு பெயர்கள் மற்றும் கட்டளை ID கள் மூலத்துடன் பொருந்தும், இலக்கில் ஏற்கனவே உள்ள கணக்குகள் உட்பட. தொடர்பில்லாத இலக்கு கணக்குகளின் பெயர்கள் முரண்பட்டால் அவற்றுக்கு எண் பின்னொட்டு கிடைக்கும், மேலும் அமைப்புகள், திறன்கள், plugin கள், மற்றும் உரையாடல் வரலாறு ஒவ்வொரு இயந்திரத்திற்கும் உள்ளூராகவே இருக்கும்.

இருக்கும் இலக்கு சான்றுகள் வைக்கப்படும். அங்கு ஏற்கனவே உள்நுழைந்துள்ள ஒரு மூலக் கணக்கின் பெயர் அதன் சான்றுகளை மாற்றாமல் ஒத்திசைக்கப்படும்; மற்ற கணக்குகள் அதனுடன் சேர்த்து சேர்க்கப்படும். பொருந்தும் கணக்குகளுக்கான சேமிக்கப்பட்ட சான்றுகளை மாற்ற, இலக்கில் அந்தக் கணக்கின் அமர்வுகளை விட்டு வெளியேறிய பிறகு `omarchy agent account copy --replace laptop claude` ஐப் பயன்படுத்தவும். புதிய இலக்குக்கு மூலத்தின் செயலில் உள்ள கணக்கு மற்றும் மாற்றும் விருப்பங்களும் கிடைக்கும்; நிறுவப்பட்ட இலக்கு தன்னுடையதையே வைத்திருக்கும்.

சான்றுகள் SSH வழியாக பயணித்து இலக்கில் தனிப்பட்ட கோப்புகளில் சேமிக்கப்படுகின்றன, எனவே நீங்கள் நம்பும் இயந்திரங்களுக்கு மட்டும் நகலெடுக்கவும். இது ஒருமுறை நகல், தொடர்ச்சியான ஒத்திசைவு அல்ல. Codex refresh டோக்கன்கள் மற்றொரு இயந்திரத்தால் மாற்றப்படலாம், இதனால் நகலெடுக்கப்பட்ட உள்நுழைவுக்கு புதுப்பிப்பு தேவைப்படலாம்; பல இயந்திரங்களில் ஒரே நேரத்தில் பயன்படுத்த தனி உள்நுழைவுகளே மிகவும் நம்பகமான தேர்வாக இருக்கும். [Codex இன் கணக்கு அங்கீகார வழிகாட்டி](https://developers.openai.com/codex/auth/ci-cd-auth) ஐப் பார்க்கவும்.

ஒரு வழங்குநருக்கு ஒரு கணக்கு செயலில் இருக்கும், மேலும் ஒவ்வொரு புதிய அமர்வும் அதுவாகவே தொடங்கும்: `cx`, `cy`, ஒரு எளிய `claude`, `codex`, அல்லது `grok`, `omarchy agent` வழியாக தொடங்கப்படும் எதுவும், மேலும் `PATH` இல் CLI ஐக் கண்டறியும் script கள் அல்லது editor கள். `omarchy agent account use work` உடன் மாற்றவும் (மேலும் `omarchy agent account use main` உடன் திரும்பவும்), அல்லது பேனலில் ஒரு கணக்கின் எண்ணை அழுத்தி பின்னர் `Enter` ஐ அழுத்துவதன் மூலம் (அல்லது அதன் நட்சத்திரத்தைக் கிளிக் செய்வதன் மூலம்). இயங்கும் Claude அமர்வுகளும் மாறும், அவற்றின் அடுத்த செய்தியிலிருந்து: ஒவ்வொரு Claude அமர்வும் `~/.claude` இல் இயங்குகிறது, அது எப்போதும் செயலில் உள்ள கணக்கின் உள்நுழைவை வைத்திருக்கும். பழைய Omarchy ஆல் ஒரு கணக்கின் சொந்த கோப்புறையில் தொடங்கப்பட்ட Claude அமர்வு, அது வெளியேறும் வரை அந்த உள்நுழைவை வைத்திருக்கும், எனவே மாற்றம் அந்த அமர்வுகளைப் பெயரிட்டு அவை போன பிறகு தானாகவே முடியும். இயங்கும் Codex மற்றும் Grok அமர்வுகள் அவை தொடங்கிய கணக்கிலேயே இருக்கும். உரையாடல் வரலாறு, அமைப்புகள், திறன்கள், மற்றும் plugin கள் கணக்குகள் முழுவதும் பகிரப்படுகின்றன, எனவே அதே கோப்புறையில் `claude --continue` நீங்கள் புதிய கணக்கில் விட்ட இடத்திலிருந்து தொடரும்.

ஒன்றுக்கு மேற்பட்ட கணக்குகளுடன், பேனல் ஒவ்வொரு கணக்கின் வரம்புகளையும் பக்கத்திற்குப் பக்கம் காட்டுகிறது, பயன்பாட்டில் உள்ளதில் நிரப்பப்பட்ட நட்சத்திரத்துடன். செயலில் உள்ள கணக்கு ஒரு வரம்பின் 95% ஐத் தாண்டும்போது Omarchy உங்களுக்கு அறிவிக்கிறது, மேலும் அறிவிப்பைக் கிளிக் செய்வது அதிக இடவசதி உள்ள கணக்கிற்கு மாற்றும். அது ஒருபோதும் தானாக மாறாது. `omarchy agent account threshold 90` உடன் வரம்பை மாற்றவும். ஒவ்வொரு கணக்கும் வரம்பிற்கு மேல் இருந்தால், எந்தக் கணக்கு முதலில் விடுபடும் என்பதுடன், அதைப் பற்றி ஒருமுறை கேட்பீர்கள். செயலில் உள்ள கணக்கு அதன் வரம்பிலிருந்து 15 புள்ளிகளுக்குள் இருக்கும்போது (இயல்புநிலையில் 80%), அதன் வரம்புகள் ஒவ்வொரு 15 நிமிடங்களுக்குப் பதிலாக ஒவ்வொரு மூன்று நிமிடங்களுக்கும் சரிபார்க்கப்படும்.

`omarchy agent account list` ஒவ்வொரு கணக்கையும் அதன் சமீபத்திய வரம்புகளையும் காட்டுகிறது, `omarchy agent account remove work` ஒன்றை மறக்கிறது, மேலும் `omarchy agent account rename primary Hey` ஒன்றை மறுபெயரிடுகிறது (அல்லது பேனலில் ஒரு கணக்கின் பெயரைக் கிளிக் செய்யவும்). இந்த கட்டளைகள் உங்கள் இயல்புநிலை ஏஜென்ட்டின் கணக்குகளில் வேலை செய்யும்; மற்ற வழங்குநரை அடைய, `omarchy agent account use codex side` இல் உள்ளது போல முதலில் அதைப் பெயரிடவும். `~/.claude` அல்லது `~/.codex` இல் நீங்கள் ஏற்கனவே வைத்திருந்த உள்நுழைவு _Main_ கணக்கு ஆகும். Codex இனுடையது அது இருக்கும் இடத்திலேயே இருக்கும்; மற்றொரு கணக்கு செயலில் இருக்கும்போது Claude இனுடையது தனக்கென ஒரு கோப்புறையில் காத்திருக்கும். சுமார் எட்டு மணிநேரத்திற்கு மேல் பயன்படுத்தப்படாமல் விடப்பட்ட ஒரு கணக்கு _Sign-in required_ ஐக் காட்டக்கூடும்; பேனலிலேயே அந்தக் கணக்கில் மீண்டும் உள்நுழைய அதைக் கிளிக் செய்யவும், அல்லது அதற்கு மாறி ஒரு அமர்வைத் தொடங்கவும், அது உள்நுழைவைத் தானாகவே புதுப்பிக்கும். `claude mcp add` உடன் நீங்கள் சேர்க்கும் MCP server கள் ஒவ்வொரு Claude கணக்கையும் அடையும், ஏனெனில் அவை அனைத்தும் `~/.claude` இல் இயங்கும்; Codex மற்றும் Grok க்கு, ஒரு கணக்கு சேர்க்கப்பட்டபோது உங்களிடம் இருந்த server கள் அதனுடன் வரும், ஆனால் பின்னர் வருபவை நீங்கள் அவற்றைச் சேர்த்த கணக்கை மட்டுமே அடையும். Claude Desktop தனக்கென ஒரு உள்நுழைவை வைத்திருக்கிறது, மேலும் CLI binary க்கான முழுமையான பாதையுடன் கட்டமைக்கப்பட்ட Codex அல்லது Grok கருவிகள் மாற்றத்தைப் பின்பற்றாது. வெளிப்படையான `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, அல்லது `GROK_HOME` ஆகியவை தேர்ந்தெடுக்கப்பட்ட கணக்கை விட முன்னுரிமை பெறும்.

### செயலிழப்பு கண்டறிதல்

செயல்முறை செயலிழப்புகளுக்காக Omarchy systemd-coredump ஐக் கண்காணிக்கிறது. நீங்கள் ஒரு இயல்புநிலை ஏஜென்ட்டைத் தேர்ந்தெடுத்த பிறகு, core ஐ dump செய்யும் உங்கள் எந்த நிரலும் "Process crashed" அறிவிப்பைக் கொண்டு வரும் — அதைக் கிளிக் செய்யவும், மேலும் செயலிழப்பு உங்கள் இயல்புநிலை ஏஜென்ட்டிடம் Omarchy இன் omarchy-diagnose-crash திறனுடன் ஒப்படைக்கப்படும், அது core dump இலிருந்து உண்மைகளை நிறுவுவதிலும் செயலிழப்பை upstream இல் புகாரளிக்கத் தகுந்ததா என்பதை முடிவு செய்வதிலும் ஏஜென்ட்டை வழிநடத்தும். `coredumpctl list` இலிருந்து எந்த PID க்கும் எதிராக `omarchy agent crash <pid>` உடன் அதை கையாலும் இயக்கலாம்.

கண்காணிப்பு இயல்பாகவே இயக்கத்தில் இருக்கும். _Trigger > Toggle > Crash Capture Off_ இன் கீழ் (அல்லது `omarchy toggle crash-capture` உடன்) அதை அணைக்கவும், அறிவிப்புகள் நிற்கும்; `omarchy agent crash <pid>` இன்னும் கையால் வேலை செய்யும்.

செயலிழப்புகளை ஒரு நேரத்தில் ஒரு நிரல் வீதமும் அமைதிப்படுத்தலாம், இதுவே கண்டறிதல் இறுதியில் உங்களுக்கு வழங்குவது. `omarchy crash mute hyprland` அந்த நிரலுக்கு மட்டும் அறிவிப்புகளை நிறுத்துகிறது, `omarchy crash mute hyprland off` அவற்றைத் திரும்பக் கொண்டு வருகிறது, மேலும் `omarchy crash mute` தனியாக நீங்கள் அமைதிப்படுத்தியதைப் பட்டியலிடுகிறது. இது binary இன் பாதையை அதன் பெயரைப் போலவே மகிழ்ச்சியுடன் ஏற்கிறது, எனவே `omarchy crash mute /usr/bin/hyprland` அதையே செய்கிறது. இடைவெளி உள்ள பெயரை மேற்கோள் காட்டவும், `omarchy crash mute 'Some App'` இல் உள்ளது போல. மற்ற அனைத்தும் இன்னும் அறிவிக்கும், மேலும் அமைதிப்படுத்தப்பட்ட நிரல் இன்னும் செயலிழக்கும் — இது நினைவூட்டலை மறைக்கிறது, எதையும் சரிசெய்யாது.

### டெஸ்க்டாப் பயன்பாடுகள்

_Install > AI_ மெனு சில வரைகலை AI பயன்பாடுகளையும் கொண்டுள்ளது: Amp Desktop, Antigravity Desktop, ChatGPT டெஸ்க்டாப் பயன்பாடு, Claude டெஸ்க்டாப் பயன்பாடு (Anthropic இன் Linux beta, Chat, Cowork, மற்றும் Claude Code தாவல்களுடன்), xAI இன் மாதிரிகளுடன் அரட்டையடிக்க Grok Bot, Herdr Desktop, Hermes Desktop, OpenClaw, Perplexity டெஸ்க்டாப் பயன்பாடு, மற்றும் T3 Code. Grok Bot என்பது டெஸ்க்டாப் அரட்டை பயன்பாடு. குறியீட்டு ஏஜென்ட் என்பது `grok` கட்டளை.

Hermes Desktop பற்றித் தெரிந்து கொள்ள வேண்டிய ஒன்று, ஏனெனில் ஒரு இயந்திரத்தில் ஒரு Hermes உள்ளது, அது பயன்பாட்டினுடையது: Hermes எப்போதும் பயன்பாடு வழியாக மட்டுமே நிறுவப்படுகிறது, மேலும் இயல்புநிலை ஏஜென்ட் இயக்கும் `hermes` கட்டளை பயன்பாட்டினுடையது. Hermes ஐ இயல்புநிலை ஏஜென்ட்டாகத் தேர்ந்தெடுப்பது _Install > AI_ உள்ளீடு செய்வதையே நிறுவுகிறது: தொகுப்பு, மற்றும் Hermes இன் சொந்த நிறுவியால் அமைக்கப்பட்ட `~/.hermes` இன் கீழ் ஒரு Hermes runtime, இது முதல் முறை சில நிமிடங்கள் எடுக்கும். அந்த runtime தான் டெர்மினல் `hermes` கட்டளை, இயல்புநிலை ஏஜென்ட் மற்றும் பயன்பாடு அனைத்தும் பயன்படுத்தும் ஒரே Hermes, மேலும் அது Omarchy வெளியீட்டிற்காகக் காத்திருக்காமல் `hermes update` உடன் தன்னைப் புதுப்பிக்கிறது. அதை நிறுவுவது Hermes க்கு Omarchy தீமை `omarchy` என்று பெயரிடப்பட்ட தோலாகவும் வழங்குகிறது, அதை நீங்கள் தீம்களை மாற்றும்போது ஒவ்வொரு Hermes மேற்பரப்பும் பின்பற்றுகிறது; நீங்கள் அது வேண்டாம் என்றால் Hermes இன் Appearance அமைப்புகளின் கீழ் அல்லது `/skin` உடன் வேறொன்றைத் தேர்ந்தெடுக்கவும், மேலும் Omarchy அந்தத் தேர்வை அப்படியே விட்டுவிடும். _Remove > AI_ இன் கீழ் பயன்பாட்டை அகற்றுவது முதலில் Hermes ஐ மூடுகிறது, gateway உட்பட, அந்த runtime ஐ அதனுடன் எடுத்துச் செல்கிறது, மேலும் உங்கள் அரட்டைகள், நினைவுகள், மற்றும் Hermes தனக்காக எழுதிய திறன்களை வைத்திருக்கிறது, நீங்கள் வேறுவிதமாகச் சொன்னால் தவிர: அந்தத் தரவும் உங்கள் இணைப்பு அமைப்புகளும் கூட போக வேண்டுமா என்று அது கேட்கும், இயல்புநிலை வேண்டாம் என்பது.

OpenClaw இன் டெஸ்க்டாப் அனுபவம் அதன் Control UI ஆகும், அது அதன் சொந்த உள்ளூர் gateway ஆல் ஆதரிக்கப்படும் web பயன்பாடாகத் திறக்கும். OpenClaw `~/.openclaw` இல் வாழ்கிறது மற்றும் தன்னைப் புதுப்பிக்கிறது: Control UI இன் "Update Gateway" பொத்தானைப் பயன்படுத்தவும் அல்லது `openclaw update` ஐ இயக்கவும், மேலும் gateway புதிய பதிப்பில் மறுதொடக்கம் செய்யும். புதிய நிறுவல் எந்த வெளியீட்டிலிருந்து தொடங்குகிறது என்பதை மட்டுமே Omarchy தேர்ந்தெடுக்கிறது. OpenClaw உங்கள் இயல்புநிலை ஏஜென்ட்டாகவும் இருக்க முடியும்: _Agent > Harness_ இன் கீழ் அதைத் தேர்ந்தெடுப்பது `~/.openclaw` இல் அதே நகலை அமைக்கிறது, மேலும் ஏஜென்ட் OpenClaw இன் டெர்மினல் UI ஐ அதன் gateway உடன் இணைத்துத் திறக்கிறது. _Remove > AI_ இன் கீழ் OpenClaw ஐ அகற்றுவது gateway சேவையையும் பயன்பாட்டையும் அதனுடன் எடுத்துச் சென்று பின்னர் `~/.openclaw` கூட போக வேண்டுமா என்று கேட்கிறது, ஏனெனில் அது உங்கள் அரட்டைகள் மற்றும் சான்றுகளை OpenClaw உடன் மற்றும் அது பதிவிறக்கும் plugin runtime களுடன் வைத்திருக்கிறது; இயல்புநிலை அதை வைத்திருக்கிறது, மேலும் OpenClaw ஐ மீண்டும் நிறுவுவது அதை மீண்டும் எடுத்துக் கொள்ளும்.

Herdr Desktop என்பது [Herdr](https://herdr.dev) டெஸ்க்டாப் பயன்பாடு: நீங்கள் சாளரத்தை மூடும்போது அதன் மையத்தில் தொடர்ந்து இயங்கும் டெர்மினல்கள் மற்றும் குறியீட்டு ஏஜென்ட்களின் இடங்கள், தாவல்கள், மற்றும் பலகங்கள். இது ஒரு தொகுப்பிலிருந்து அல்லாமல் Herdr இன் சொந்த நிறுவியிலிருந்து வருகிறது, எனவே அது `~/.local/share/herdr-app` இல் வாழ்கிறது, உங்களிடம் இன்னும் ஒன்று இல்லாதபோது அதன் மையத்தை `~/.local/bin/herdr-core` இல் கொண்டு வருகிறது, மேலும் இரண்டையும் தானே புதுப்பிக்கிறது. இது Omarchy `Super + Ctrl + Return` இல் வழங்கும் `herdr` கட்டளையை மாற்றுவதற்குப் பதிலாக அதற்கு அருகில் அமர்கிறது, மேலும் அந்தக் கட்டளையின் நேரடி விசைகளைப் பெறுகிறது: `Alt + Return` மற்றும் `Alt + Shift + Return` ஒரு பலகத்தை கீழே அல்லது வலதுபுறம் பிரிக்கும், `Alt + Escape` அதை மூடும், `Ctrl + Alt + Arrow` பலகங்களுக்கிடையே நகரும், `Alt + 1..9` மற்றும் `Alt + Left/Right` ஒரு தாவலைத் தேர்ந்தெடுக்கும், மற்றும் `Alt + Up/Down` இடங்களுக்கிடையே நகரும். `Ctrl + 1..9` ஒரு இடத்தைத் தேர்ந்தெடுக்கிறது மற்றும் `Alt + Shift + Up/Down` ஏஜென்ட்கள் வழியாகச் செல்கிறது. `Ctrl + Space` முன்னொட்டு விசைகள் டெர்மினலுக்கு மட்டுமே இருக்கும், ஏனெனில் பயன்பாடு ஒரு வரிசைக்காக எளிய Ctrl விசையைப் பிடித்து வைக்க முடியாது. Omarchy இவற்றை `~/.config/herdr-app/keys.json` இல் எழுதுகிறது, மேலும் `omarchy-refresh-herdr-app` அவற்றைத் திரும்ப வைக்கிறது. அதை நிறுவுவது Herdr இன் Omarchy தீமைத் தேர்ந்தெடுக்கிறது, அது அதிலிருந்து உங்கள் Omarchy தீமைப் பின்பற்றுகிறது. Herdr வெளிர் பயன்முறைக்கு ஒரு தீமையும் இருண்ட பயன்முறைக்கு ஒரு தீமையும் வைத்திருக்கிறது, எனவே இருண்ட மற்றும் வெளிர் Omarchy தீமிற்கிடையே மாறிய பிறகு, மற்ற பயன்முறைக்காக Herdr இன் தீம் தேர்வியில் Omarchy ஐ மீண்டும் ஒருமுறை தேர்ந்தெடுக்கவும்.

T3 Code ஒரு தொகுப்பிலிருந்து அல்லாமல் `~/.local/share/t3code` இல் உள்ள அதன் அதிகாரப்பூர்வ AppImage வெளியீட்டிலிருந்து இயங்குகிறது, எனவே அது தன்னைப் புதுப்பிக்கிறது. அதை நிறுவுவது Stable அல்லது Nightly சேனலில் தொடங்க வேண்டுமா என்று கேட்கிறது; பின்னர் T3 Code இன் அமைப்புகளில் மாற்றவும். உங்கள் thread கள் மற்றும் அமைப்புகள் `~/.t3` இல் வாழ்கின்றன, மேலும் _Remove > AI_ இன் கீழ் T3 Code ஐ அகற்றுவது அவற்றை அதனுடன் எடுத்துச் செல்கிறது.

### உள்ளூர் மாதிரிகள்

உங்கள் குறியீட்டு ஏஜென்ட்களுக்காக உங்கள் சொந்த இயந்திரத்தில் ஒரு திறந்த மாதிரியை இயக்கவும். உங்கள் prompt களும் குறியீடும் இயந்திரத்திலேயே இருக்கும்; மாதிரிக்கு அனுப்பப்படும் எதுவும் அதை விட்டு வெளியேறாது. இதனுடன் தொடங்கவும்:

```bash
omarchy models use best text
```

இது இந்த இயந்திரத்திற்கான சிறந்த உரை மாதிரியை அமைக்கிறது, உங்கள் ஏஜென்ட்கள் பயன்படுத்தும் வகை. படம், வீடியோ மற்றும் இசை மாதிரிகளுக்கு அவற்றுக்கென சிறந்தது உள்ளது: `omarchy models use best image`, `video` அல்லது `music`. இந்த இயந்திரத்திற்கான ஒவ்வொரு வகையின் தேர்வையும் காண `omarchy models use best` ஐ இயக்கவும்.

அல்லது மேல் பட்டியில், ஏஜென்ட்கள் ஐகானுக்கு அருகில் உள்ள அதன் sparkles ஐகானிலிருந்து உள்ளூர் மாதிரிகள் பேனலைத் திறக்கவும், அல்லது Super + Ctrl + Alt + X உடன், மற்றும் + ஐத் தேர்ந்தெடுக்கவும். ஒரு மாதிரி இந்த இயந்திரத்திற்குப் பொருந்தும்போது ஐகான் தோன்றும். மாதிரிகளை இயக்கும் Podman, Omarchy உடன் வருகிறது, NVIDIA இயந்திரத்தில் NVIDIA இன் container toolkit உம் வருகிறது, அது அவற்றுக்கு GPU ஐ வழங்குகிறது; இரண்டில் ஒன்று விடுபட்டிருந்தால், முதல் அமைப்பு அதை நிறுவும். பின்னர் Omarchy இந்த இயந்திரத்திற்கு பரிந்துரைக்கப்பட்ட மாதிரியைத் தேர்ந்தெடுத்து, அதைப் பதிவிறக்கி, தொடங்கும். பத்துக்கணக்கான GB பதிவிறக்கத்தையும், மாதிரி இயங்கும்போது இயந்திரத்தின் பெரும்பாலான நினைவகம் பயன்பாட்டில் இருப்பதையும் எதிர்பார்க்கவும்: Flash Next அதன் முழு 256K சூழலுடன் சுமார் 100 GiB ஐப் பயன்படுத்துகிறது. அதற்குத் தேவையான நினைவகத்தை மற்ற மாதிரிகள் வைத்திருந்தால், அது நிறுத்தப்பட்ட நிலையில் அமைக்கப்படும், நீங்கள் ஒன்றை நிறுத்தியதும் தொடங்கத் தயாராக இருக்கும். மாதிரி வெளியேறும்போது நிற்கும்; உங்களுக்கு வேறு ஏதாவதற்கு நினைவகம் தேவைப்படும்போது அதை நீங்களே நிறுத்தவும்.

`omarchy models list` விருப்பங்களைக் காட்டுகிறது மற்றும் சில ஏன் பொருந்தவில்லை என்பதை விளக்குகிறது. மற்றொன்றை அமைக்க, `omarchy models use <recipe>` ஐ இயக்கவும். இன்று, `qwen3.8-flash-next-gufo` மற்றும் `qwen3.8-27b-gufo` ஆகியவை 128 GB Strix Halo இயந்திரங்களுக்குக் கிடைக்கின்றன; 27B சுமார் 40 GiB எடுக்கும், எனவே அது மற்ற வேலைகளுக்கு இடம் விடுகிறது. Intel இன் Arc B390 உடன் கூடிய 64 GB laptop இல், `qwen3.6-35b-a3b-llamacpp` சுமார் 30 GiB இல் இயங்குகிறது. புதிய recipe கள் மற்றும் பரிந்துரைகள் `omarchy update` உடன், தொகுப்பு வழியாக வருகின்றன.

நீங்கள் அமைக்கும் ஒவ்வொரு மாதிரிக்கும் உள்ளூர் மாதிரிகள் பேனலில் அதற்கென தனி வரி கிடைக்கும்: அதைத் தொடங்க play, அதை நிறுத்தி அதன் நினைவகத்தை விடுவிக்க pause, மற்றும் அதில் உங்கள் ஏஜென்ட்டைத் திறக்க டெர்மினல் பொத்தான். மேல் பகுதி முழுவதும், இயந்திரத்தின் நினைவகம் Omarchy க்கே (கணினி மற்றும் உங்கள் பயன்பாடுகள்), இயங்கும் ஒவ்வொரு மாதிரி, மற்றும் இலவசமாக உள்ளது ஆகியவற்றுக்கிடையே எவ்வாறு பிரிக்கப்பட்டுள்ளது என்பதை ஒரு பட்டி காட்டுகிறது. நிறுத்தப்பட்ட மாதிரியைச் சுட்டிக்காட்டவும், பட்டி அது பொருந்துமா, அல்லது எவ்வளவு குறைவாக உள்ளது என்பதைக் காட்டும். அவை நினைவகத்தில் ஒன்றாகப் பொருந்தும்போது பல ஒரே நேரத்தில் இயங்க முடியும்; ஒன்று பொருந்தவில்லை என்றால், எந்த இயங்கும் மாதிரியை நிறுத்த வேண்டும் என்பதை Omarchy சொல்லும். வரிகளை அவற்றின் logo ஆல் இழுத்து மறுவரிசைப்படுத்தவும், மேலும் தேர்ந்தெடுக்கப்பட்ட வரியில் Delete ஐ அழுத்தி ஒரு மாதிரியையும் அதன் பதிவிறக்கத்தையும் அகற்றவும்.

நீங்கள் அமைக்கும் ஒவ்வொரு குறியீட்டு மாதிரிக்கும் பயன்பாட்டு தொடக்கியில் அதற்கென தனி உள்ளீடும் கிடைக்கும், மாதிரியின் பெயரின் கீழ் மற்றும் அதன் தயாரிப்பாளரின் logo உடன், Claude, Codex அல்லது Grok இல் உள்நுழைவது ஒன்றைச் சேர்ப்பது போல. அது அந்த மாதிரியில் உங்கள் ஏஜென்ட்டைத் திறக்கும், மேலும் அது இயங்கவில்லை என்றால் முதலில் மாதிரியைத் தொடங்கும்: டெர்மினல் அது ஏற்றப்படுவதைக் காட்டி, அது தயாரானதும் ஏஜென்ட்டிடம் ஒப்படைக்கும். ஒரு மாதிரியை அகற்றுவது அதன் உள்ளீட்டை அகற்றும்.

ஒவ்வொரு மாதிரியும் குறியீட்டுக்கானது அல்ல. படம், வீடியோ மற்றும் இசை மாதிரிகள் அதற்குப் பதிலாக Fantasi இல் திறக்கும், இந்த இயந்திரத்தில் இயங்கும் மாதிரியைக் கொண்டு படங்கள், வீடியோ மற்றும் இசையை உருவாக்குவதற்கான Omarchy இன் பயன்பாடு, அங்கு அல்லது உள்ளூர் மாதிரிகள் பேனலில் அவற்றின் வரியிலிருந்து தேர்ந்தெடுக்கப்படும்.

ஒரு மாதிரி அது அமைக்கப்பட்டபடியே சரியாக இயங்கிக் கொண்டிருக்கும், எனவே Omarchy புதுப்பிப்பு உங்கள் ஏஜென்ட்களின் கீழ் ஒன்றை ஒருபோதும் மறுதொடக்கம் செய்யாது. நீங்கள் அமைத்துள்ள மாதிரிக்கு Omarchy இடம் புதிய runtime அல்லது புதிய weights இருக்கும்போது, அதன் வரி புதுப்பிப்பு பொத்தானைக் காட்டும்: அதை அழுத்தவும், மாதிரி பின்னணியில் மீண்டும் அமைக்கப்படும், மாறியதை மட்டும் பதிவிறக்கி, புதிய பதிப்பில் மறுதொடக்கம் செய்யும். நிறுத்தப்பட்ட மாதிரி நிறுத்தப்பட்டே இருக்கும். `omarchy models update` டெர்மினலில் இருந்து ஒவ்வொரு மாதிரிக்கும் அதையே செய்கிறது.

கட்டளை வரியிலிருந்து, `omarchy models start <recipe>` மற்றும் `omarchy models stop <recipe>` அதையே செய்கின்றன, `omarchy models status` ஒவ்வொரு மாதிரியையும் காட்டுகிறது, மேலும் `omarchy agent --local` உங்கள் இயல்புநிலை ஏஜென்ட் எதுவாக இருந்தாலும், நீங்கள் கடைசியாகத் தொடங்கிய மாதிரியை pi இல் திறக்கிறது. அந்த மாதிரியை ஏஜென்ட் hotkey, Quake console, மற்றும் _Make something_ திறப்பதாக ஆக்க, `omarchy default agent local` ஐ இயக்கவும் அல்லது _Agent > Harness_ இன் கீழ் _Local model_ ஐத் தேர்ந்தெடுக்கவும். pi நீங்கள் அமைத்துள்ள ஒவ்வொரு மாதிரியையும், மேலும் நீங்கள் இணைத்த இயந்திரங்களில் உள்ளவற்றையும், அதன் சொந்த மாதிரி தேர்வியில் பட்டியலிடுகிறது, எனவே எளிய `pi` அவற்றையும் அடையும். எந்த OpenAI-இணக்கமான client உம் இணைக்க முடியும்: `status` ஒவ்வொரு மாதிரியின் முகவரியையும் காட்டுகிறது (முதலாவது `http://127.0.0.1:11435/v1`), recipe பெயரே மாதிரி, மேலும் விசை `~/.config/omarchy/agent-local/key` இல் உள்ளது.

`omarchy models remove <recipe>` ஒரு மாதிரியையும் வேறு எந்த மாதிரியும் பயன்படுத்தாத பதிவிறக்கங்களையும் நீக்குகிறது.

மூன்றாம் தரப்பு runtime கள் அவற்றின் வெளியீட்டாளருடன் பெயரிடப்பட்டுள்ளன. Omarchy ஒவ்வொரு மாதிரியையும் பிணைய அணுகல் இல்லாமல் இயக்குகிறது.

### உள்ளூர் LLMகள்

உள்ளூர் LLM மாதிரிகளை இயக்க Omarchy இரண்டு வழிகளைப் பரிந்துரைக்கிறது: LM Studio மற்றும் Ollama. LM Studio திறந்த-எடை மாதிரிகளைக் கண்டறிவதற்கும், அவற்றை நிறுவுவதற்கும், இயக்குவதற்கும் GUI இடைமுகத்தை வழங்குகிறது. எளிதாகத் தொடங்க இது ஒரு சிறந்த வழி. Ollama அதே போலச் செய்ய CLI ஐ வழங்குகிறது. ஆனால் நீங்கள் உள்ளூர் மாதிரிகளுக்குப் புதியவர் என்றால், நான் LM Studio உடன் தொடங்குவேன். Omarchy Menu வில் _Install > AI_ இன் கீழ் இரண்டில் ஒன்றை நிறுவலாம்.

### Omarchy திறன்கள்

ஏஜென்ட் திறன்கள் AI குறிப்பிட்ட கருவிகளை குறிப்பிட்ட வழியில் பயன்படுத்த உதவுகின்றன, மேலும் Omarchy அவற்றில் ஏழை வழங்குகிறது. omarchy திறன் கணினியைத் தனிப்பயனாக்குவதை உள்ளடக்குகிறது, உங்கள் Hyprland config ஐ மாற்றுவது அல்லது பட்டியை சரிசெய்வது போல. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app, மற்றும் omarchy-make-game ஆகியவை புதிய ஒன்றை உருவாக்குவதை உள்ளடக்குகின்றன, omarchy-contribute ஒரு பிழையைப் புகாரளிப்பது அல்லது upstream க்கு ஒரு திருத்தத்தை அனுப்புவதை உள்ளடக்குகிறது, மேலும் omarchy-diagnose-crash ஒரு செயலிழப்பின் core dump வழியாக வேலை செய்கிறது. அவை Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` மற்றும் ஒவ்வொரு `~/.hermes/profiles/*/skills`), மற்றும் பொதுவான `~/.agents/skills` இடம் ஆகியவற்றுக்கான திறன் அடைவுகளில் symlink செய்யப்பட்டுள்ளன, எனவே பெரும்பாலான harness கள் அவற்றைத் தானாகவே எடுத்துக் கொள்ளும். அதே பெயரில் உங்கள் சொந்த திறன் கோப்புறை முன்னுரிமை பெறும்.

ஆனால் நீங்கள் இந்தத் திறன்களை சோதனை முயற்சியாகவே கருத வேண்டும். வெவ்வேறு மாதிரிகள் அதை வெவ்வேறு விளைவுகளுக்குப் பயன்படுத்தும். முதலில் plan பயன்முறையில் இயக்குவது சிறந்தது, எனவே ஏஜென்ட் எதை மாற்ற விரும்புகிறது என்பது பற்றி உங்களுக்கு ஒரு யோசனை இருக்கும். பின்னர் மாற்றங்களைத் திரும்பப் பெறவோ அல்லது ஏஜென்ட் எல்லாவற்றையும் குழப்பிவிட்டால் `omarchy reinstall configs` ஐ அழைக்கவோ கூடத் தயாராக இருங்கள்.
