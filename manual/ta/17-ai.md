Omarchy உங்களுக்காக இயல்புநிலையைத் தேர்ந்தெடுக்காமல், கீழுள்ள கோடிங் ஏஜென்டுகளுக்கான தொடக்கிகளை உள்ளடக்குகிறது. முதல் முறை பயன்படுத்தும்போது அதன் CLI-ஐ நிறுவ ஒரு கட்டளையை இயக்கவும், பின்னர் கேட்கும்போது அங்கீகரிக்கவும். Hermes விதிவிலக்கு: முதல் முறை பயன்படுத்தும்போது அதற்காக எதுவும் நிறுவப்படாது, அதைத் தேர்ந்தெடுப்பது Hermes Desktop-ஐ நிறுவும், கீழே உள்ள _Desktop apps_ விளக்குவது போல.

### ஏஜென்டுகளை நிறுவுதல் மற்றும் புதுப்பித்தல்

Hermes தவிர, இந்த ஏஜென்டுகள் mise-இன் சோம்பேறி நிறுவலைப் பயன்படுத்துகின்றன: முதல் தொடக்கம் CLI-ஐ நிறுவும், பிந்தைய தொடக்கங்கள் அதையே மீண்டும் பயன்படுத்தும். mise ஒரு நிறுவப்பட்ட ஏஜென்டில் புதிய வெளியீடு உள்ளதா என நான்கு மணிநேரத்திற்கு ஒரு முறைக்கு மேல் சரிபார்க்காது, அது தொடங்குவதற்கு சற்று முன்பு அல்லது ஷெல் ப்ராம்ப்டில் பின்னணியில். அந்தப் புதுப்பிப்பு தோல்வியடைந்தால் அல்லது நீங்கள் ஆஃப்லைனில் இருந்தால், நிறுவப்பட்ட பதிப்பு இயங்கும். `omarchy update` நிறுவப்பட்ட ஏஜென்டுகளை Omarchy-இன் மீதியுடன் புதுப்பிக்கிறது, மற்றும் `mup` mise-ஆல் நிர்வகிக்கப்படும் கருவிகளை மட்டுமே புதுப்பிக்கிறது.

`claude update`, `codex update` போன்ற ஒரு ஏஜென்டின் சொந்தப் புதுப்பிப்பான், அல்லது ஒரு பயன்பாட்டில் உள்ள புதுப்பிப்பு பொத்தான், mise-ஆல் நிர்வகிக்கப்படும் நிறுவலைப் புதுப்பிக்காது. `codex update` தோல்வியடைகிறது, மற்றும் `claude update` வெற்றி என அறிவித்து, mise கண்காணிக்காத தனி நகலை நிறுவக்கூடும். நீங்கள் ஒரு ஏஜென்டின் சொந்த நிறுவியையும் புதுப்பிப்பானையும் பயன்படுத்த விரும்பினால், அதை `disable_tools`-இல் சேர்க்கவும்; [முன்நிறுவப்பட்ட CLI கருவிகள்](18-development-tools.md#preinstalled-cli-tools) பார்க்கவும்.

உங்களுக்குத் தேவைப்படுவதற்கு முன்பே கட்டமைக்கப்பட்ட அனைத்து சோம்பேறி கருவிகளையும் நிறுவ, `mise install --include-lazy` இயக்கவும். இதில் ஏஜென்டுகளுடன் Omarchy-இன் மற்ற இயல்புநிலை CLI கருவிகளும் அடங்கும். ஒரு தனி கருவியை நிறுவுவதற்கு அல்லது உங்கள் சொந்த நிறுவலைப் பயன்படுத்துவதற்கு [முன்நிறுவப்பட்ட CLI கருவிகள்](18-development-tools.md#preinstalled-cli-tools) பார்க்கவும்.

`grok` mise-இன் முதல்-தரப்பு `grok` தொகுப்பு மூலம் நிறுவப்படுகிறது, `claude` மற்றும் `codex` போலவே. `grok` இயக்கவும், அல்லது _Setup > Defaults > Agent_ கீழ் அதைத் தேர்ந்தெடுக்கவும். x.ai-இல் உள்ள `curl | bash` நிறுவியைத் தவிர்க்கவும். அந்த வழி `~/.grok/bin`-இல் இரண்டாவது நகலை வைக்கிறது, அதை `PATH`-இல் முன்னால் சேர்க்கிறது, மற்றும் Omarchy-இன் ரேப்பரை மேலெழுதுகிறது.

`dsh` அதன் உலாவி UI-ஐ `127.0.0.1:3080`-இல் திறக்கிறது, தொடக்க கோப்பகத்தை அதன் இயல்புநிலை பணியிடமாகக் கொண்டு. அதன் உலாவி UI தொடக்க ப்ராம்ப்ட் எதையும் எடுக்காது, எனவே `omarchy agent prompt` அதை உங்கள் கிளிப்போர்டில் ப்ராம்ப்டுடன் ஒட்டுவதற்காகத் திறக்கிறது. Omarchy அதை DeepSeek-இன் ஒப்புதல்-தேவையில்லா அனுமதி முன்னமைவுடன் தொடங்குகிறது. நீங்கள் அதன் அதிகாரப்பூர்வ மாதிரி API-ஐப் பயன்படுத்தும்போது DeepSeek Harness அமர்வு பதிவுகளை DeepSeek-க்கு பதிவேற்றுகிறது; அதன் உலாவி UI-இல் _Settings > General > Upload Session Log_ கீழ் அதை அணைக்கவும். நீங்கள் அதற்கு அனுப்பும் கருத்தும் அமர்வுடன் பதிவேற்றப்படும், நீங்கள் அதை `DSH_TELEMETRY_MODE=DISABLED` உடன் தொடங்காவிட்டால்.

### இயல்புநிலை ஏஜென்ட்

`omarchy default agent <name>` உடன் அல்லது Omarchy Menu-இல் (`Super + Space`) _Setup > Defaults > Agent_ கீழ் உங்கள் இயல்புநிலை ஏஜென்டைத் தேர்ந்தெடுக்கவும். ஏஜென்ட் இன்னும் நிறுவப்படவில்லை என்றால், அதைத் தேர்ந்தெடுப்பது முதலில் அதை நிறுவும். புதிய Omarchy இந்தத் தேர்வைச் செய்ய ஒரு முறை அறிவிப்புடன் உங்களை அழைக்கும்.

Claude-ஐத் தேர்ந்தெடுப்பது Chromium, Chrome, Brave, Brave Origin, மற்றும் Edge-க்கான அதன் உலாவி நீட்டிப்பை அமைக்கவும் முயற்சிக்கிறது. நீட்டிப்பு அமைப்பு அனைத்து பயனர்களுக்கும் பொருந்தும் மற்றும் உங்கள் கணினி கடவுச்சொல்லைக் கேட்கக்கூடும்; ரத்து செய்வது அல்லது தோல்வியுற்ற நீட்டிப்பு நிறுவல் இன்னும் Claude-ஐத் தேர்ந்தெடுத்து தொடங்கும். உங்கள் உலாவியை மறுதொடக்கம் செய்யவும், கேட்டால் நீட்டிப்பை இயக்கவும், மற்றும் அதை இணைப்பதை முடிக்க Claude-இல் உள்நுழையவும். இணைப்பைச் சரிபார்க்க Claude-இல் `/chrome` இயக்கவும். Firefox மற்றும் Zen இந்த நீட்டிப்பை ஆதரிக்காது. இந்த அமைப்பு சேர்க்கப்படுவதற்கு முன்பே Claude உங்கள் இயல்புநிலையாக இருந்திருந்தால், நீட்டிப்பை நிறுவ அதை மீண்டும் தேர்ந்தெடுக்கவும்.

நீங்கள் தேர்ந்தெடுத்தவுடன், `Super + Shift + Ctrl + A` இயல்புநிலை ஏஜென்டை ஒரு பிரத்யேக டெர்மினல் சாளரத்தில் தொடங்கும் (அல்லது நீங்கள் இன்னும் தேர்ந்தெடுக்கவில்லை என்றால் தேர்வியைக் கொண்டுவரும்). `omarchy agent prompt "Review this project"` உடன் அதை நேரடியாக ஒரு பணியில் தொடங்கவும் முடியும். Freebuff மற்றும் DeepSeek Harness தொடக்க ப்ராம்ப்ட் எதையும் எடுக்காது, எனவே அவை அதற்குப் பதிலாக உங்கள் கிளிப்போர்டில் ப்ராம்ப்டுடன் ஒட்டுவதற்காகத் திறக்கும். இந்த வழியில் தொடங்கப்படும் ஏஜென்டுகள் அவற்றின் அந்தந்த நிறுத்தி-கேட்காத முறைகளில் கவனமின்றி இயங்கும், எனவே அவை உண்மையில் செயல்களைச் செய்யத் தயாராக இருக்கவும்! MiniMax Code-இன் ஊடாடும் அமர்வுகளுக்கு அத்தகைய முறை இல்லை, எனவே அது வழக்கம் போல அனுமதிகளைக் கேட்கும். மற்றும் ஏஜென்டுகள் உங்கள் வீட்டு கோப்பகத்திற்கான நம்பிக்கையை நினைவில் வைக்க மறுப்பதால், `$HOME`-இலிருந்து தொடக்கங்கள் அதற்குப் பதிலாக `~/Work`-இல் தொடங்கும்.

டெர்மினல் குறுக்குவழிகளும் உள்ளன: `a` தற்போதைய டெர்மினலில் இயல்புநிலை ஏஜென்டை இன்லைனில் இயக்குகிறது, அதே நேரத்தில் `c`, `cx`, மற்றும் `cy` OpenCode, Claude Code, மற்றும் Codex-ஐ நேரடியாகத் தொடங்குகின்றன (மீண்டும் அவற்றின் தானியங்கு-ஒப்புதல் முறைகளில்). தீம் மாற்றங்களும் ஏஜென்டுகளுக்கு ஒத்திசைகின்றன: நீங்கள் Omarchy தீமை மாற்றும்போது Claude Code, Pi, OpenCode, மற்றும் Hermes (Omarchy அதை நிறுவியவுடன்) அனைத்தும் பின்தொடரும்.

### ஏஜென்டுகள் பேனல்

மேல் பட்டியில் ஏஜென்டுகள் ஐகான் உள்ளது. நீங்கள் ஒரு ஏஜென்டை அமைப்பதற்கு முன்பு, அதன் பேனல் Claude, Codex, அல்லது Grok-இல் உள்நுழைவதன் மூலம் உங்களை வழிநடத்துகிறது, மற்றும் முதலாவது உங்கள் இயல்புநிலை ஏஜென்டாகிறது. அதன் பிறகு, பேனல் ஒவ்வொரு சந்தாவையும் ஒரே பக்கத்தில் வைக்கிறது: ஒவ்வொரு ஏஜென்ட் மற்றும் கணக்கும் அதன் திட்டத்துடன், அதன் 5-மணிநேர அமர்வு மற்றும் வாராந்திர வரம்புகள் ஒவ்வொன்றுக்கும் ஒரு மீட்டர், அது மீட்டமைக்கப்படும் வரையிலான நேரத்துடன் (சரியான சதவீதத்திற்கு மேலே வைக்கவும்), அல்லது மீதமுள்ள முன்கூட்டியே செலுத்தப்பட்ட இருப்பு, இந்த வாரம் டோக்கன்கள் மற்றும் உங்கள் மிகவும் பயன்படுத்தப்பட்ட மாதிரி போல, அவை அனைத்திலும் நீங்கள் பயன்படுத்தியதைச் சுழற்றும் ஒரு வரிக்குக் கீழே. _Make something_ கீழ் இது புதிய தீம், செருகுநிரல், அல்லது பயன்பாட்டிற்கான தொடக்க ப்ராம்ப்டுகளை வழங்குகிறது, அவை பணியை உங்கள் இயல்புநிலை ஏஜென்டிடம் ஒப்படைக்கின்றன. பயன்பாடுகள் Omarchy-இன் சொந்த Hype, Monologue, மற்றும் Omacut கட்டமைக்கப்பட்ட வழியில், C++ மற்றும் Qt Quick-இல், omarchy-app ஏஜென்ட் திறனைப் பின்பற்றி கட்டமைக்கப்படுகின்றன, மற்றும் அவற்றுக்குத் தேவையான கம்பைலர் மற்றும் Qt துண்டுகள் நிறுவப்பட்டு வருகின்றன. Claude Code, Codex, Grok, Kimi, Cursor மற்றும் அதன் Grok Bot ஒதுக்கீடு, GitHub Copilot, Muse, Antigravity, Kimchi, மற்றும் Devin ஆகியவை அவற்றின் வரம்புகளுடன் தொடக்கத்திலிருந்தே உள்ளடக்கப்பட்டுள்ளன, மற்றும் Hermes, Mistral Vibe, மற்றும் Qwen Code நீங்கள் அவற்றைப் பயன்படுத்தியவுடன் அவற்றின் அமர்வுகளையும் டோக்கன்களையும் காட்டுகின்றன. நீங்கள் pi, omp, அல்லது opencode மூலம் பயன்படுத்தும் வழங்குநர் திட்டங்களும் விசைகளும் காட்டப்படும்: OpenCode Zen மற்றும் Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan, மற்றும் Synthetic அவற்றின் வரம்புகளுடன்; Fireworks, OpenRouter, மற்றும் DeepSeek அவற்றின் முன்கூட்டியே செலுத்தப்பட்ட இருப்புகளுடன்; மற்றும் Local models கீழ் உங்கள் சொந்த வன்பொருளில் நீங்கள் இயக்கும் மாதிரிகள். ஒவ்வொரு ஏஜென்டும் ஒரு முறை மட்டுமே கணக்கிடப்படுகிறது, அதற்கு பில் செய்பவர் கீழ், நீங்கள் அதை எத்தனை ஹார்னஸ்கள் மூலம் இயக்கினாலும்.

பேனலுக்கு பட்டி ஐகானை இடது-கிளிக் செய்யவும், உங்கள் இயல்புநிலை ஏஜென்டைத் தொடங்க வலது-கிளிக் செய்யவும். அதன் பின்னணியில் உள்ள பயன்பாட்டு பதிவுகள் ஒவ்வொரு 15 நிமிடங்களுக்கும் `omarchy agent usage-update` ஆல் மீண்டும் உருவாக்கப்படுகின்றன, மற்றும் பேனல் ஒத்திசைக்கப்பட்ட கோப்புறை வழியாக உங்கள் மற்ற இயந்திரங்களிலிருந்து பயன்பாட்டைக் கூட இணைக்க முடியும். முழு அமைப்புகளுக்கு `$OMARCHY_PATH/shell/plugins/agents/` கீழ் README பார்க்கவும்.

### பல சந்தாக்கள்

நீங்கள் ஒன்றுக்கும் மேற்பட்ட Claude, Codex, அல்லது Grok திட்டத்திற்கு பணம் செலுத்தினால் — தனிப்பட்ட Max மற்றும் வேலைக்கான ஒன்று, சொல்லப்போனால் — Omarchy அவை அனைத்தையும் உள்நுழைந்த நிலையில் வைத்து அவற்றுக்கிடையே நகர முடியும். ஏஜென்டுகள் பேனலில் + உடன் ஒரு சந்தாவைச் சேர்க்கவும், அது அங்கேயே உங்களை வழிநடத்தும், அல்லது `omarchy agent account add claude Work` உடன் (அல்லது `codex`, அல்லது `grok`). அது காணவில்லை என்றால் CLI-ஐ நிறுவும். ஒரு வழங்குநருக்கான முதல் கணக்கு உங்கள் வழக்கமான உலாவி மூலம் உள்நுழைகிறது, CLI எப்போதும் பார்க்கும் இடத்திலேயே. அதற்குப் பிறகு ஒவ்வொன்றும் ஒரு தனிப்பட்ட சாளரம் மூலம் உள்நுழைகிறது, எனவே உங்கள் உலாவி ஏற்கனவே உள்நுழைந்துள்ள கணக்கு தவறுதலாக எடுக்கப்படாது; நீங்கள் சேர்க்கும் கணக்காக அங்கே உள்நுழையவும், மற்றும் நீங்கள் ஏற்கனவே திறந்து வைத்திருந்த எந்த தனிப்பட்ட சாளரத்தையும் முதலில் மூடவும். இதைச் செய்ய CLI-இலிருந்து ஒருபோதும் வெளியேற வேண்டாம்: வெளியேறுவது சேமிக்கப்பட்ட உள்நுழைவை ரத்து செய்யும், மற்றும் அந்தக் கணக்கு மீண்டும் சேர்க்கப்பட வேண்டும்.

SSH வழியாக உங்கள் சந்தா உள்நுழைவுகளை மற்றொரு Omarchy இயந்திரத்திற்கு நகலெடுக்க, `omarchy agent account copy user@laptop` இயக்கவும். இலக்கில் ஒன்று நிறுவப்படவில்லை என்றால் அனுப்புநர் ஒரு தற்காலிக பெறுநரை வழங்குகிறார், எனவே பழைய Omarchy இயந்திரங்கள் புதுப்பிப்பு இல்லாமல் கணக்குகளைப் பெற முடியும். நிறுவப்பட்ட பெறுநர்கள் முன்னுரிமை பெறுகிறார்கள். இது அனைத்து Claude, Codex, மற்றும் Grok சந்தாக்களையும் நகலெடுக்கிறது; அவற்றைத் தேர்ந்தெடுக்க வழங்குநர் பெயர்களைச் சேர்க்கவும், `omarchy agent account copy laptop claude` இல் உள்ளது போல. கணக்கு பெயர்களும் கட்டளை ID-களும் மூலத்துடன் பொருந்தும், இலக்கில் ஏற்கனவே உள்ள கணக்குகள் உட்பட. தொடர்பில்லாத இலக்கு கணக்குகள் அவற்றின் பெயர்கள் முரண்பட்டால் எண் பின்னொட்டைப் பெறுகின்றன, மற்றும் அமைப்புகள், திறன்கள், செருகுநிரல்கள், மற்றும் உரையாடல் வரலாறு ஒவ்வொரு இயந்திரத்திற்கும் உள்ளூராகவே இருக்கும்.

ஏற்கனவே உள்ள இலக்கு சான்றுகள் வைக்கப்படுகின்றன. அங்கே ஏற்கனவே உள்நுழைந்துள்ள ஒரு மூலக் கணக்கு அதன் சான்றுகளை மாற்றாமல் அதன் பெயர் ஒத்திசைக்கப்படுகிறது; மற்ற கணக்குகள் அதனுடன் சேர்க்கப்படுகின்றன. பொருந்தும் கணக்குகளுக்கு சேமிக்கப்பட்ட சான்றுகளை மாற்ற, இலக்கில் அந்தக் கணக்கின் அமர்வுகளை விட்டு வெளியேறிய பிறகு `omarchy agent account copy --replace laptop claude` பயன்படுத்தவும். புதிய இலக்கு மூலத்தின் செயலில் உள்ள கணக்கு மற்றும் மாற்று விருப்பங்களையும் பெறுகிறது; நிறுவப்பட்ட இலக்கு அதன் சொந்தத்தை வைத்திருக்கிறது.

சான்றுகள் SSH வழியாகப் பயணிக்கின்றன மற்றும் இலக்கில் தனிப்பட்ட கோப்புகளில் சேமிக்கப்படுகின்றன, எனவே நீங்கள் நம்பும் இயந்திரங்களுக்கு மட்டுமே நகலெடுக்கவும். இது ஒரு முறை நகல், தொடர்ச்சியான ஒத்திசைவு அல்ல. Codex புதுப்பிப்பு டோக்கன்கள் மற்றொரு இயந்திரத்தால் சுழற்றப்படலாம், நகலெடுக்கப்பட்ட உள்நுழைவு புதுப்பிக்கப்பட வேண்டிய நிலையில் இருக்கும்; பல இயந்திரங்களில் ஒரே நேரத்தில் பயன்படுத்த தனி உள்நுழைவுகள் மிகவும் நம்பகமான தேர்வாக இருக்கும். [Codex-இன் கணக்கு அங்கீகார வழிகாட்டுதல்](https://developers.openai.com/codex/auth/ci-cd-auth) பார்க்கவும்.

ஒரு வழங்குநருக்கு ஒரு கணக்கு செயலில் உள்ளது, மற்றும் ஒவ்வொரு புதிய அமர்வும் அதுவாகவே தொடங்குகிறது: `cx`, `cy`, ஒரு வெற்று `claude`, `codex`, அல்லது `grok`, `omarchy agent` மூலம் தொடங்கப்படும் எதுவும், மற்றும் `PATH`-இல் CLI-ஐக் கண்டறியும் ஸ்கிரிப்டுகள் அல்லது எடிட்டர்கள். `omarchy agent account use work` உடன் மாற்றவும் (மற்றும் `omarchy agent account use main` உடன் திரும்பவும்), அல்லது பேனலில் ஒரு கணக்கின் எண்ணை அழுத்தி பின்னர் `Enter` அழுத்துவதன் மூலம் (அல்லது அதன் Use பொத்தானைக் கிளிக் செய்வதன் மூலம்). ஏற்கனவே இயங்கும் அமர்வுகள் அவை தொடங்கிய கணக்கிலேயே இருக்கும். உரையாடல் வரலாறு, அமைப்புகள், திறன்கள், மற்றும் செருகுநிரல்கள் கணக்குகள் முழுவதும் பகிரப்படுகின்றன, எனவே அதே கோப்புறையில் `claude --continue` நீங்கள் புதிய கணக்கில் விட்ட இடத்திலிருந்து தொடரும்.

ஒன்றுக்கும் மேற்பட்ட கணக்குகளுடன், பேனல் ஒவ்வொரு கணக்கின் வரம்புகளையும் அருகருகே காட்டுகிறது, செயலில் உள்ளது குறிக்கப்பட்டு. இயல்பாக செயலில் உள்ள கணக்கு ஒரு வரம்பின் 95%-ஐக் கடக்கும்போது Omarchy உங்களுக்கு அறிவிக்கிறது, மற்றும் அறிவிப்பைக் கிளிக் செய்வது மிகவும் இடவசதி உள்ள கணக்கிற்கு மாற்றுகிறது. பேனலில் ஒரு கணக்கின் வரி மீது வைத்து Use-க்கு அருகில் தோன்றும் Autoswitch-ஐக் கிளிக் செய்யவும் (அல்லது `m` அழுத்தவும்), அல்லது அது தானாகவே மாற `omarchy agent account mode auto` இயக்கவும்; அது இயக்கத்தில் இருக்கும்போது, Autoswitch Use-இன் இடத்தைப் பிடிக்கிறது, மற்றும் அதை மீண்டும் கிளிக் செய்வது அறிவிப்புக்குத் திரும்புகிறது. வரம்பை மாற்ற ஒரு எண்ணைச் சேர்க்கவும், `omarchy agent account mode auto 90` இல் உள்ளது போல. ஒவ்வொரு கணக்கும் வரம்புக்கு மேல் இருந்தால், எந்தக் கணக்கு முதலில் விடுவிக்கப்படுகிறது என்பதுடன், அதைப் பற்றி ஒரு முறை கேட்பீர்கள். ஒரு செயலில் உள்ள கணக்கு அதன் வரம்பிலிருந்து 15 புள்ளிகளுக்குள் இருக்கும்போது (இயல்புநிலையில் 80%), அதன் வரம்புகள் ஒவ்வொரு 15 நிமிடங்களுக்கும் பதிலாக ஒவ்வொரு மூன்று நிமிடங்களுக்கும் சரிபார்க்கப்படுகின்றன.

`omarchy agent account list` ஒவ்வொரு கணக்கையும் அதன் சமீபத்திய வரம்புகளையும் காட்டுகிறது, `omarchy agent account remove work` ஒன்றை மறக்கிறது, மற்றும் `omarchy agent account rename primary Hey` ஒன்றை மறுபெயரிடுகிறது (அல்லது பேனலில் ஒரு கணக்கின் பெயரைக் கிளிக் செய்யவும்). இந்தக் கட்டளைகள் உங்கள் இயல்புநிலை ஏஜென்டின் கணக்குகளில் வேலை செய்கின்றன; மற்ற வழங்குநரை அடைய, முதலில் அதைப் பெயரிடவும், `omarchy agent account use codex side` இல் உள்ளது போல. நீங்கள் ஏற்கனவே `~/.claude` அல்லது `~/.codex`-இல் வைத்திருந்த உள்நுழைவு _Main_ கணக்கு மற்றும் அது இருக்கும் இடத்திலேயே இருக்கும். சுமார் எட்டு மணிநேரத்திற்கும் மேலாகப் பயன்படுத்தப்படாமல் விடப்பட்ட ஒரு கணக்கு _Sign-in required_ காட்டக்கூடும்; பேனலிலேயே அந்தக் கணக்கில் மீண்டும் உள்நுழைய அதைக் கிளிக் செய்யவும், அல்லது அதில் ஒரு அமர்வைத் தொடங்கவும், இது தானாகவே உள்நுழைவைப் புதுப்பிக்கிறது. ஒரு கணக்கு சேர்க்கப்பட்டபோது நீங்கள் வைத்திருந்த MCP சர்வர்கள் அதற்கு வருகின்றன, ஆனால் நீங்கள் பின்னர் `claude mcp add` உடன் சேர்ப்பவை நீங்கள் அவற்றைச் சேர்த்த கணக்கை மட்டுமே அடைகின்றன. ஒரு CLI பைனரிக்கு முழுமையான பாதையுடன் கட்டமைக்கப்பட்ட Claude Desktop மற்றும் கருவிகள் மாற்றத்தைப் பின்பற்றாது. வெளிப்படையான `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, அல்லது `GROK_HOME` தேர்ந்தெடுக்கப்பட்ட கணக்கை விட முன்னுரிமை பெறுகிறது.

### செயலிழப்பு கண்டறிதல்

Omarchy செயல்முறை செயலிழப்புகளுக்கு systemd-coredump-ஐக் கண்காணிக்கிறது. ஏதாவது segfault ஆகும்போது, உங்களுக்கு "Process crashed" அறிவிப்பு கிடைக்கும் — அதைக் கிளிக் செய்யவும், மற்றும் செயலிழப்பு உங்கள் இயல்புநிலை ஏஜென்டிடம் Omarchy-இன் diagnose-crash திறனுடன் ஒப்படைக்கப்படுகிறது, இது கோர் டம்பிலிருந்து உண்மைகளை நிறுவுவதிலும் செயலிழப்பு மேல்நிலையில் புகாரளிக்கத் தகுந்ததா என்பதைத் தீர்மானிப்பதிலும் ஏஜென்டை வழிநடத்துகிறது. `coredumpctl list`-இலிருந்து எந்த PID-க்கு எதிராகவும் `omarchy agent crash <pid>` உடன் அதை கையால் இயக்கவும் முடியும்.

கண்காணிப்பு இயல்பாக இயக்கத்தில் உள்ளது. _Trigger > Toggle > Crash Capture_ கீழ் அதை அணைக்கவும் (அல்லது `omarchy toggle crash-capture` உடன்) மற்றும் அறிவிப்புகள் நிற்கும்; `omarchy agent crash <pid>` இன்னும் கையால் வேலை செய்கிறது.

செயலிழப்புகள் ஒரு நேரத்தில் ஒரு நிரலாகவும் அமைதியாக்கப்படலாம், இதைத்தான் கண்டறிதல் இறுதியில் உங்களுக்கு வழங்குகிறது. `omarchy crash mute hyprland` அந்த நிரலுக்கு மட்டுமே அறிவிப்புகளை நிறுத்துகிறது, `omarchy crash mute hyprland off` அவற்றைத் திரும்பக் கொண்டுவருகிறது, மற்றும் `omarchy crash mute` தனியாக நீங்கள் அமைதியாக்கியதைப் பட்டியலிடுகிறது. இது பைனரியின் பாதையை அதன் பெயரைப் போலவே மகிழ்ச்சியாக எடுக்கிறது, எனவே `omarchy crash mute /usr/bin/hyprland` அதே வேலையைச் செய்கிறது. அதில் இடைவெளி உள்ள பெயரை மேற்கோள் காட்டவும், `omarchy crash mute 'Some App'` இல் உள்ளது போல. மற்ற அனைத்தும் இன்னும் அறிவிக்கிறது, மற்றும் அமைதியாக்கப்பட்ட நிரல் இன்னும் செயலிழக்கிறது — இது நினைவூட்டலை மறைக்கிறது, எதையும் சரிசெய்யாது.

### டெஸ்க்டாப் பயன்பாடுகள்

_Install > AI_ மெனு சில வரைகலை AI பயன்பாடுகளையும் கொண்டுள்ளது: ChatGPT டெஸ்க்டாப் பயன்பாடு, Claude டெஸ்க்டாப் பயன்பாடு (Anthropic-இன் Linux பீட்டா, Chat, Cowork, மற்றும் Claude Code டேப்களுடன்), xAI-இன் மாதிரிகளுடன் அரட்டையடிக்க Grok Bot, Herdr Desktop, Hermes Desktop, OpenClaw, Perplexity டெஸ்க்டாப் பயன்பாடு, மற்றும் T3 Code. Grok Bot என்பது டெஸ்க்டாப் அரட்டை பயன்பாடு. கோடிங் ஏஜென்ட் என்பது `grok` கட்டளை.

Hermes Desktop தெரிந்து கொள்ள வேண்டிய ஒன்று, ஏனெனில் ஒரு இயந்திரத்தில் ஒரு Hermes உள்ளது, மற்றும் அது பயன்பாட்டினுடையது: Hermes எப்போதும் பயன்பாடு மூலம் மட்டுமே நிறுவப்படுகிறது, மற்றும் இயல்புநிலை ஏஜென்ட் இயக்கும் `hermes` கட்டளை பயன்பாட்டினுடையது. Hermes-ஐ இயல்புநிலை ஏஜென்டாகத் தேர்ந்தெடுப்பது _Install > AI_ உள்ளீடு செய்யும் அதே விஷயத்தை நிறுவுகிறது: தொகுப்பு, மற்றும் Hermes-இன் சொந்த நிறுவியால் அமைக்கப்பட்ட `~/.hermes` கீழ் ஒரு Hermes ரன்டைம், இது முதல் முறை சில நிமிடங்கள் எடுக்கும். அந்த ரன்டைம் தான் டெர்மினல் `hermes` கட்டளை, இயல்புநிலை ஏஜென்ட் மற்றும் பயன்பாடு அனைத்தும் பயன்படுத்தும் ஒரே Hermes, மற்றும் இது Omarchy வெளியீட்டிற்காகக் காத்திருப்பதற்குப் பதிலாக `hermes update` உடன் தானாகவே புதுப்பிக்கிறது. அதை நிறுவுவது Hermes-க்கு Omarchy தீமை `omarchy` என்ற பெயரிடப்பட்ட தோலாகவும் வழங்குகிறது, இதை நீங்கள் தீம்களை மாற்றும்போது ஒவ்வொரு Hermes மேற்பரப்பும் பின்பற்றுகிறது; நீங்கள் அது வேண்டாம் என்றால் Hermes-இன் Appearance அமைப்புகள் கீழ் அல்லது `/skin` உடன் மற்றொன்றைத் தேர்ந்தெடுக்கவும், மற்றும் Omarchy அந்தத் தேர்வை அப்படியே விட்டுவிடும். _Remove > AI_ கீழ் பயன்பாட்டை அகற்றுவது முதலில் Hermes-ஐ மூடுகிறது, கேட்வே உட்பட, அந்த ரன்டைமை அதனுடன் எடுத்துச் செல்கிறது, மற்றும் நீங்கள் வேறுவிதமாகச் சொல்லாவிட்டால் உங்கள் அரட்டைகள், நினைவுகள், மற்றும் Hermes தனக்காக எழுதிய திறன்களை வைத்திருக்கிறது: அந்தத் தரவும் உங்கள் இணைப்பு அமைப்புகளும் கூட போக வேண்டுமா என்று கேட்கிறது, இயல்புநிலை இல்லை என.

OpenClaw-இன் டெஸ்க்டாப் அனுபவம் அதன் Control UI ஆகும், இது அதன் சொந்த உள்ளூர் கேட்வேயால் ஆதரிக்கப்படும் வலை பயன்பாடாகத் திறக்கிறது. OpenClaw `~/.openclaw`-இல் வாழ்கிறது மற்றும் தானாகவே புதுப்பிக்கிறது: Control UI-இன் "Update Gateway" பொத்தானைப் பயன்படுத்தவும் அல்லது `openclaw update` இயக்கவும், மற்றும் கேட்வே புதிய பதிப்பில் மறுதொடக்கம் செய்யும். Omarchy புதிய நிறுவல் தொடங்கும் வெளியீட்டை மட்டுமே தேர்ந்தெடுக்கிறது. _Remove > AI_ கீழ் OpenClaw-ஐ அகற்றுவது கேட்வே சேவையையும் பயன்பாட்டையும் அதனுடன் எடுத்து, பின்னர் `~/.openclaw` கூட போக வேண்டுமா என்று கேட்கிறது, ஏனெனில் அது OpenClaw-உடன் மற்றும் அது பதிவிறக்கும் செருகுநிரல் ரன்டைம்களுடன் உங்கள் அரட்டைகளையும் சான்றுகளையும் வைத்திருக்கிறது; இயல்புநிலை அதை வைத்திருக்கிறது, மற்றும் OpenClaw-ஐ மீண்டும் நிறுவுவது அதை மீண்டும் எடுத்துக்கொள்ளும்.

Herdr Desktop என்பது [Herdr](https://herdr.dev) டெஸ்க்டாப் பயன்பாடு: நீங்கள் சாளரத்தை மூடும்போது அதன் மையத்தில் தொடர்ந்து இயங்கும் டெர்மினல்கள் மற்றும் கோடிங் ஏஜென்டுகளின் இடங்கள், டேப்கள், மற்றும் பேன்கள். இது ஒரு தொகுப்பிலிருந்து அல்லாமல் Herdr-இன் சொந்த நிறுவியிலிருந்து வருகிறது, எனவே இது `~/.local/share/herdr-app`-இல் வாழ்கிறது, உங்களிடம் ஏற்கனவே ஒன்று இல்லாதபோது `~/.local/bin/herdr-core`-இல் அதன் மையத்தைக் கொண்டுவருகிறது, மற்றும் இரண்டையும் தானாகவே புதுப்பிக்கிறது. இது Omarchy `Super + Ctrl + Return`-இல் வழங்கும் `herdr` கட்டளையை மாற்றுவதற்குப் பதிலாக அதன் அருகில் அமர்ந்திருக்கிறது. அதை நிறுவுவது Herdr-இன் Omarchy தீமைத் தேர்ந்தெடுக்கிறது, இது அதன் பிறகு உங்கள் Omarchy தீமைப் பின்பற்றுகிறது. Herdr வெளிர் முறைக்கு ஒரு தீமையும் இருண்ட முறைக்கு ஒன்றையும் வைத்திருக்கிறது, எனவே இருண்ட மற்றும் வெளிர் Omarchy தீமுக்கு இடையில் மாறிய பிறகு, மற்ற முறைக்கு Herdr-இன் தீம் தேர்வியில் Omarchy-ஐ மீண்டும் ஒரு முறை தேர்ந்தெடுக்கவும்.

T3 Code ஒரு தொகுப்பிலிருந்து அல்லாமல் `~/.local/share/t3code`-இல் அதன் அதிகாரப்பூர்வ AppImage வெளியீட்டிலிருந்து இயங்குகிறது, எனவே இது தானாகவே புதுப்பிக்கிறது. அதை நிறுவுவது Stable அல்லது Nightly சேனலில் தொடங்க வேண்டுமா என்று கேட்கிறது; பின்னர் T3 Code-இன் அமைப்புகளில் மாற்றவும். உங்கள் திரெட்களும் அமைப்புகளும் `~/.t3`-இல் வாழ்கின்றன, மற்றும் _Remove > AI_ கீழ் T3 Code-ஐ அகற்றுவது அவற்றை அதனுடன் எடுத்துச் செல்கிறது.

### உள்ளூர் மாதிரிகள்

உங்கள் கோடிங் ஏஜென்டுகளுக்கு உங்கள் சொந்த இயந்திரத்தில் ஒரு திறந்த மாதிரியை இயக்கவும். உங்கள் ப்ராம்ப்டுகளும் குறியீடும் இயந்திரத்தில் இருக்கும்; மாதிரிக்கு அனுப்பப்படும் எதுவும் அதை விட்டு வெளியேறாது. இதனுடன் தொடங்கவும்:

```bash
omarchy agent local use best
```

அல்லது, மேல் பட்டியில் உள்ள ஏஜென்டுகள் பேனலில், + மற்றும் பின்னர் Local AI-ஐத் தேர்ந்தெடுக்கவும், இது ஒரு மாதிரி இந்த இயந்திரத்திற்குப் பொருந்தும்போது காட்டப்படும். முதல் முறை, இது மாதிரிகளை இயக்கும் Podman-ஐ நிறுவுகிறது, மற்றும் NVIDIA இயந்திரத்தில் NVIDIA-இன் கொள்கலன் கருவித்தொகுப்பை நிறுவுகிறது, இது அவற்றுக்கு GPU-ஐ வழங்குகிறது. Omarchy பின்னர் இந்த இயந்திரத்திற்கு பரிந்துரைக்கப்பட்ட மாதிரியைத் தேர்ந்தெடுத்து, அதைப் பதிவிறக்கி, தொடங்குகிறது. பத்து GB பதிவிறக்கத்தையும், மாதிரி இயங்கும்போது இயந்திரத்தின் பெரும்பாலான நினைவகம் பயன்பாட்டில் இருக்கும் என்றும் எதிர்பார்க்கவும்: Flash Next அதன் முழு 256K சூழலுடன் சுமார் 100 GiB பயன்படுத்துகிறது. மற்ற மாதிரிகள் அதற்குத் தேவையான நினைவகத்தை வைத்திருந்தால், அது நிறுத்தப்பட்ட நிலையில் அமைக்கப்படுகிறது, நீங்கள் ஒன்றை நிறுத்தியவுடன் தொடங்கத் தயாராக. மாதிரி வெளியேறும்போது நிற்கிறது; வேறு ஏதாவதுக்கு நினைவகம் தேவைப்படும்போது அதை நீங்களே நிறுத்தவும்.

`omarchy agent local list` விருப்பங்களைக் காட்டுகிறது மற்றும் சில ஏன் பொருந்தாது என்பதை விளக்குகிறது. மற்றொன்றை அமைக்க, `omarchy agent local use <recipe>` இயக்கவும். இன்று, `qwen3.8-flash-next-gufo` மற்றும் `qwen3.8-27b-gufo` 128 GB Strix Halo இயந்திரங்களுக்குக் கிடைக்கின்றன; 27B சுமார் 40 GiB எடுக்கும், எனவே இது மற்ற வேலைகளுக்கு இடம் விட்டுச் செல்கிறது. புதிய சமையல் குறிப்புகளும் பரிந்துரைகளும் `omarchy update` உடன், தொகுப்பு மூலம் வருகின்றன.

நீங்கள் அமைக்கும் ஒவ்வொரு மாதிரியும் ஏஜென்டுகள் பேனலில் அதன் சொந்த வரியைப் பெறுகிறது, உங்கள் சந்தாக்களுக்கு அடுத்து: அதைத் தொடங்க இயக்கவும், அதை நிறுத்தி அதன் நினைவகத்தை விடுவிக்க இடைநிறுத்தவும், மற்றும் அதில் உங்கள் ஏஜென்டைத் திறக்க டெர்மினல் பொத்தான். அவை நினைவகத்தில் ஒன்றாகப் பொருந்தும்போது பல ஒரே நேரத்தில் இயங்க முடியும்; ஒன்று பொருந்தவில்லை என்றால், எந்த இயங்கும் மாதிரியை நிறுத்த வேண்டும் என்று Omarchy சொல்கிறது. அவற்றை மறுவரிசைப்படுத்த வரிகளை இழுக்கவும், மற்றும் ஒரு மாதிரியையும் அதன் பதிவிறக்கத்தையும் அகற்ற தேர்ந்தெடுக்கப்பட்ட வரியில் Delete அழுத்தவும்.

கட்டளை வரியிலிருந்து, `omarchy agent local start <recipe>` மற்றும் `omarchy agent local stop <recipe>` அதையே செய்கின்றன, `omarchy agent local status` ஒவ்வொரு மாதிரியையும் காட்டுகிறது, மற்றும் `omarchy agent --local` நீங்கள் கடைசியாகத் தொடங்கிய மாதிரியில் உங்கள் இயல்புநிலை ஏஜென்டைத் திறக்கிறது (உங்கள் இயல்புநிலை ஏஜென்ட் உள்ளூர் மாதிரியைப் பயன்படுத்த முடியாவிட்டால் pi). எந்த OpenAI-இணக்கமான கிளையன்டும் இணைக்க முடியும்: `status` ஒவ்வொரு மாதிரியின் முகவரியையும் காட்டுகிறது (முதலாவது `http://127.0.0.1:11435/v1`), சமையல் குறிப்பு பெயர் மாதிரி, மற்றும் விசை `~/.config/omarchy/agent-local/key`-இல் உள்ளது.

`omarchy agent local remove <recipe>` ஒரு மாதிரியையும் வேறு எந்த மாதிரியும் பயன்படுத்தாத பதிவிறக்கங்களையும் நீக்குகிறது.

மூன்றாம் தரப்பு ரன்டைம்கள் அவற்றின் வெளியீட்டாளருடன் குறிக்கப்படுகின்றன. Omarchy ஒவ்வொரு மாதிரியையும் நெட்வொர்க் அணுகல் இல்லாமல் இயக்குகிறது.

### உள்ளூர் LLM-கள்

Omarchy உள்ளூர் LLM மாதிரிகளை இயக்க இரண்டு வழிகளைப் பரிந்துரைக்கிறது: LM Studio மற்றும் Ollama. LM Studio திறந்த-எடை மாதிரிகளைக் கண்டறிவதற்கும், அவற்றை நிறுவுவதற்கும், அவற்றை இயக்குவதற்கும் GUI இடைமுகத்தை வழங்குகிறது. எளிதாகத் தொடங்க இது ஒரு சிறந்த வழி. Ollama அதேபோல் செய்வதற்கு CLI வழங்குகிறது. ஆனால் நீங்கள் உள்ளூர் மாதிரிகளுக்குப் புதியவராக இருந்தால், நான் LM Studio-உடன் தொடங்குவேன். Omarchy Menu-இல் _Install > AI_ கீழ் இரண்டில் ஒன்றையும் நிறுவலாம்.

### Omarchy Skill

ஏஜென்ட் திறன்கள் AI குறிப்பிட்ட கருவிகளை ஒரு குறிப்பிட்ட வழியில் பயன்படுத்த உதவுகின்றன, மற்றும் Omarchy கணினியைத் தனிப்பயனாக்குவதற்கான இயல்புநிலை திறனுடன் வருகிறது. உங்கள் Hyprland கட்டமைப்பை மாற்றுவது, பட்டியை சரிசெய்வது, அல்லது புதிதாக ஒரு புதிய தீமை உருவாக்குவது போல. இது Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` மற்றும் ஒவ்வொரு `~/.hermes/profiles/*/skills`), மற்றும் பொதுவான `~/.agents/skills` இருப்பிடத்திற்கான திறன் கோப்பகங்களில் சிம்லிங்க் செய்யப்பட்டுள்ளது, எனவே பெரும்பாலான ஹார்னஸ்கள் அதைத் தானாகவே எடுத்துக்கொள்கின்றன.

ஆனால் நீங்கள் இந்தத் திறனைச் சோதனை முயற்சியாகக் கருத வேண்டும். வெவ்வேறு மாதிரிகள் அதை வெவ்வேறு விளைவுகளுக்குப் பயன்படுத்தும். முதலில் திட்ட முறையில் இயக்குவது சிறந்தது, எனவே ஏஜென்ட் எதை மாற்ற விரும்புகிறது என்பது பற்றிய ஒரு யோசனை உங்களுக்கு இருக்கும். மற்றும் பின்னர் மாற்றங்களைத் திரும்பப் பெற அல்லது ஏஜென்ட் எல்லாவற்றையும் குழப்பினால் `omarchy reinstall configs`-ஐக் கூட அழைக்கத் தயாராக இருக்கவும்.
