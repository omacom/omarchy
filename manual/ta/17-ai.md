Omarchy, உங்களுக்காக ஒரு இயல்புநிலையைத் தேர்ந்தெடுக்காமல், கீழே உள்ள கோடிங் ஏஜென்ட்களுக்கான தொடக்கிகளை உள்ளடக்கியுள்ளது. ஒரு கட்டளையை இயக்கினால் முதல் பயன்பாட்டில் அதன் CLI நிறுவப்படும், பின்னர் கேட்கப்படும்போது அங்கீகரிக்கவும். ### ஏஜென்ட்களை நிறுவுதல் மற்றும் புதுப்பித்தல்

Hermes-ஐத் தவிர, இந்த ஏஜென்ட்கள் mise-இன் சோம்பேறி நிறுவலைப் பயன்படுத்துகின்றன: முதல் தொடக்கம் CLI-ஐ நிறுவும், பிந்தைய தொடக்கங்கள் அதையே மீண்டும் பயன்படுத்தும். mise, நிறுவப்பட்ட ஏஜென்ட்டிற்குப் புதிய வெளியீடு உள்ளதா என நான்கு மணிநேரத்திற்கு ஒரு முறைக்கு மேல் சரிபார்க்காது, அது தொடங்குவதற்குச் சற்று முன்பு அல்லது shell prompt-இல் பின்னணியில். அந்தப் புதுப்பிப்பு தோல்வியடைந்தால் அல்லது நீங்கள் ஆஃப்லைனில் இருந்தால், நிறுவப்பட்ட பதிப்பு இயங்கும். `omarchy update` நிறுவப்பட்ட ஏஜென்ட்களை Omarchy-இன் மற்ற பகுதிகளுடன் சேர்த்துப் புதுப்பிக்கிறது, மேலும் `mup` mise-ஆல் நிர்வகிக்கப்படும் கருவிகளை மட்டும் புதுப்பிக்கிறது.

ஏஜென்ட்டின் சொந்தப் புதுப்பிப்பான், எடுத்துக்காட்டாக `claude update`, `codex update`, அல்லது ஒரு செயலியில் உள்ள புதுப்பிப்புப் பொத்தான், mise-ஆல் நிர்வகிக்கப்படும் நிறுவலைப் புதுப்பிக்காது. `codex update` தோல்வியடையும், மேலும் `claude update` வெற்றி என அறிவித்துக்கொண்டே mise கண்காணிக்காத தனி நகலை நிறுவக்கூடும். நீங்கள் ஏஜென்ட்டின் சொந்த நிறுவி மற்றும் புதுப்பிப்பானைப் பயன்படுத்த விரும்பினால், அதை `disable_tools`-இல் சேர்க்கவும்; [முன்பே நிறுவப்பட்ட CLI கருவிகள்](18-development-tools.md#preinstalled-cli-tools) என்பதைப் பார்க்கவும்.

உள்ளமைக்கப்பட்ட அனைத்து சோம்பேறி கருவிகளையும் உங்களுக்குத் தேவைப்படுவதற்கு முன்பே நிறுவ, `mise install --include-lazy` என்பதை இயக்கவும். இதில் ஏஜென்ட்களுடன் Omarchy-இன் மற்ற இயல்புநிலை CLI கருவிகளும் அடங்கும். ஒரு கருவியை நிறுவுவது அல்லது உங்கள் சொந்த நிறுவலைப் பயன்படுத்துவது குறித்து [முன்பே நிறுவப்பட்ட CLI கருவிகள்](18-development-tools.md#preinstalled-cli-tools) என்பதைப் பார்க்கவும்.

`grok` mise-இன் முதல்-தரப்பு `grok` தொகுப்பு வழியாக நிறுவப்படுகிறது, `claude` மற்றும் `codex` போலவே. `grok` என்பதை இயக்கவும், அல்லது _அமைப்பு > இயல்புநிலைகள் > Agent_ என்பதன் கீழ் அதைத் தேர்ந்தெடுக்கவும். x.ai-இல் `curl | bash` நிறுவியைத் தவிர்க்கவும். அந்தப் பாதை இரண்டாவது நகலை `~/.grok/bin`-இல் வைக்கிறது, அதை `PATH`-இல் முன்னால் சேர்க்கிறது, மேலும் Omarchy-இன் wrapper-ஐ மேலெழுதுகிறது.

`dsh` அதன் உலாவி UI-ஐ `127.0.0.1:3080`-இல் திறக்கிறது, தொடக்க அடைவை அதன் இயல்புநிலை பணியிடமாகக் கொண்டு. அதன் உலாவி UI தொடக்கக் குறிப்பை ஏற்காது, எனவே `omarchy agent prompt` அதை ஒட்டுவதற்காக உங்கள் clipboard-இல் குறிப்புடன் திறக்கிறது. Omarchy அதை DeepSeek-இன் ஒப்புதல்-தேவையில்லா அனுமதி முன்னமைவுடன் தொடங்குகிறது. நீங்கள் அதன் அதிகாரப்பூர்வ மாடல் API-ஐப் பயன்படுத்தும்போது DeepSeek Harness அமர்வுப் பதிவுகளை DeepSeek-க்குப் பதிவேற்றுகிறது; அதன் உலாவி UI-இல் _அமைப்புகள் > பொது > Upload Session Log_ என்பதன் கீழ் அதை அணைக்கவும். நீங்கள் அதற்கு அனுப்பும் கருத்தும் அமர்வுடன் சேர்த்துப் பதிவேற்றப்படும், நீங்கள் அதை `DSH_TELEMETRY_MODE=DISABLED` உடன் தொடங்கினால் தவிர.

### இயல்புநிலை ஏஜென்ட்

உங்கள் இயல்புநிலை ஏஜென்ட்டை `omarchy default agent <name>` உடன் அல்லது Omarchy Menu (`Super + Space`)-இல் _அமைப்பு > இயல்புநிலைகள் > Agent_ என்பதன் கீழ் தேர்ந்தெடுக்கவும். ஏஜென்ட் இன்னும் நிறுவப்படவில்லை என்றால், அதைத் தேர்ந்தெடுப்பது முதலில் அதை நிறுவும். புதிய Omarchy ஒரு முறை மட்டுமே வரும் அறிவிப்புடன் இந்தத் தேர்வைச் செய்ய உங்களை அழைக்கும்.

Claude-ஐத் தேர்ந்தெடுப்பது Chromium, Chrome, Brave, Brave Origin, மற்றும் Edge-க்காக அதன் உலாவி நீட்டிப்பை அமைக்கவும் முயற்சிக்கிறது. நீட்டிப்பு அமைப்பு அனைத்துப் பயனர்களுக்கும் பொருந்தும் மற்றும் உங்கள் கணினி கடவுச்சொல்லைக் கேட்கக்கூடும்; ரத்து செய்வது அல்லது தோல்வியடைந்த நீட்டிப்பு நிறுவல் கூட Claude-ஐத் தேர்ந்தெடுத்துத் தொடங்கும். உங்கள் உலாவியை மறுதொடக்கம் செய்யவும், கேட்கப்பட்டால் நீட்டிப்பை இயக்கவும், அதை இணைப்பதை முடிக்க Claude-இல் உள்நுழையவும். இணைப்பைச் சரிபார்க்க Claude-இல் `/chrome` என்பதை இயக்கவும். Firefox மற்றும் Zen இந்த நீட்டிப்பை ஆதரிக்காது. இந்த அமைப்பு சேர்க்கப்படுவதற்கு முன்பே Claude உங்கள் இயல்புநிலையாக இருந்திருந்தால், நீட்டிப்பை நிறுவ அதை மீண்டும் தேர்ந்தெடுக்கவும்.

நீங்கள் தேர்ந்தெடுத்தவுடன், `Super + Shift + Ctrl + A` இயல்புநிலை ஏஜென்ட்டைத் தனி terminal சாளரத்தில் தொடங்கும் (அல்லது நீங்கள் இன்னும் தேர்ந்தெடுக்கவில்லை என்றால் தேர்வியைக் கொண்டு வரும்). `omarchy agent prompt "Review this project"` உடன் அதை நேராக ஒரு பணியிலும் தொடங்கலாம். Freebuff மற்றும் DeepSeek Harness தொடக்கக் குறிப்பை ஏற்காது, எனவே அவை அதற்குப் பதிலாக ஒட்டுவதற்காக உங்கள் clipboard-இல் குறிப்புடன் திறக்கும். இப்படித் தொடங்கப்படும் ஏஜென்ட்கள் அவற்றின் அந்தந்த நிறுத்தி-கேட்காத பயன்முறைகளில் கவனிக்கப்படாமல் இயங்கும், எனவே அவை உண்மையிலேயே விஷயங்களைச் செய்யத் தயாராக இருங்கள்! MiniMax Code-இன் ஊடாடும் அமர்வுகளுக்கு அத்தகைய பயன்முறை இல்லை, எனவே அது வழக்கம் போல அனுமதிகளைக் கேட்கும். மேலும் ஏஜென்ட்கள் உங்கள் home அடைவுக்கான நம்பிக்கையை நினைவில் வைக்க மறுப்பதால், `$HOME`-இலிருந்து தொடங்குவது அதற்குப் பதிலாக `~/Work`-இல் தொடங்கும்.

terminal குறுக்குவழிகளும் உள்ளன: `a` தற்போதைய terminal-இல் இயல்புநிலை ஏஜென்ட்டை இன்லைனாக இயக்குகிறது, அதே நேரத்தில் `c`, `cx`, மற்றும் `cy` OpenCode, Claude Code, மற்றும் Codex-ஐ நேரடியாகத் தொடங்குகின்றன (மீண்டும் அவற்றின் தானியங்கு-ஒப்புதல் பயன்முறைகளில்). Theme மாற்றங்களும் ஏஜென்ட்களுக்கு ஒத்திசைகின்றன: நீங்கள் Omarchy theme-ஐ மாற்றும்போது Claude Code, Pi, OpenCode, மற்றும் Hermes (Omarchy அதை நிறுவியவுடன்) அனைத்தும் பின்தொடரும்.

### ஏஜென்ட்கள் panel

மேல் பட்டியில் ஏஜென்ட்கள் ஐகான் உள்ளது. நீங்கள் ஒரு ஏஜென்ட்டை அமைப்பதற்கு முன், அதன் panel Claude, Codex, அல்லது Grok-இல் உள்நுழைவதன் வழியாக உங்களை அழைத்துச் செல்லும், முதலாவது உங்கள் இயல்புநிலை ஏஜென்ட் ஆகும். அதன் பிறகு, panel ஒவ்வொரு சந்தாவையும் ஒரே பக்கத்தில் வைக்கிறது: ஒவ்வொரு ஏஜென்ட் மற்றும் கணக்கு அதன் திட்டத்துடன், அதன் 5 மணிநேர அமர்வு மற்றும் வாராந்திர வரம்புகள் ஒவ்வொன்றுக்கும் ஒரு மீட்டர், அது மீட்டமைக்கப்படும் வரையிலான நேரத்துடன் (சரியான சதவீதத்திற்கு மேலே வைக்கவும்), அல்லது மீதமுள்ள முன்பண இருப்பு, அவை அனைத்திலும் நீங்கள் பயன்படுத்தியதைச் சுழற்றும் ஒரு வரிக்குக் கீழ், இந்த வாரம் tokens மற்றும் உங்கள் மிகவும் பயன்படுத்தப்பட்ட மாடல் போன்றவை. _ஏதாவது உருவாக்கு_ என்பதன் கீழ் இது புதிய theme, plugin, அல்லது செயலிக்கான தொடக்கக் குறிப்புகளை வழங்குகிறது, அவை பணியை உங்கள் இயல்புநிலை ஏஜென்ட்டிடம் ஒப்படைக்கும். செயலிகள் Omarchy-இன் சொந்த Hype, Monologue, மற்றும் Omacut கட்டமைக்கப்பட்ட விதத்தில், C++ மற்றும் Qt Quick-இல், omarchy-app agent skill-ஐப் பின்பற்றிக் கட்டமைக்கப்படுகின்றன, மேலும் அவற்றுக்குத் தேவையான compiler மற்றும் Qt பகுதிகள் நிறுவப்பட்டு வருகின்றன. Claude Code, Codex, Grok, Kimi, Cursor மற்றும் அதன் Grok Bot சலுகை, GitHub Copilot, Muse, Antigravity, Kimchi, மற்றும் Devin ஆகியவை அவற்றின் வரம்புகளுடன் உடனடியாக உள்ளடக்கப்பட்டுள்ளன, மேலும் Hermes, Mistral Vibe, மற்றும் Qwen Code நீங்கள் அவற்றைப் பயன்படுத்தியவுடன் அவற்றின் அமர்வுகள் மற்றும் tokens-ஐக் காட்டும். pi, omp, அல்லது opencode வழியாக நீங்கள் பயன்படுத்தும் வழங்குநர் திட்டங்கள் மற்றும் keys-ம் தோன்றும்: OpenCode Zen மற்றும் Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan, மற்றும் Synthetic அவற்றின் வரம்புகளுடன்; Fireworks, OpenRouter, மற்றும் DeepSeek அவற்றின் முன்பண இருப்புகளுடன்; மேலும் Local models-இன் கீழ் உங்கள் சொந்த வன்பொருளில் நீங்கள் இயக்கும் மாடல்கள். ஒவ்வொரு ஏஜென்ட்டும் ஒரு முறை மட்டுமே கணக்கிடப்படும், அதற்குக் கட்டணம் வசூலிப்பவரின் கீழ், நீங்கள் எத்தனை ஹார்னஸ்கள் வழியாக அதை இயக்கினாலும்.

panel-க்கு பட்டி ஐகானை இடது-கிளிக் செய்யவும், உங்கள் இயல்புநிலை ஏஜென்ட்டைத் தொடங்க வலது-கிளிக் செய்யவும். அதன் பின்னணியில் உள்ள பயன்பாட்டுப் பதிவுகள் ஒவ்வொரு 15 நிமிடங்களுக்கும் `omarchy agent usage-update` ஆல் மீண்டும் உருவாக்கப்படும், மேலும் panel ஒத்திசைக்கப்பட்ட கோப்புறை வழியாக உங்கள் மற்ற இயந்திரங்களிலிருந்து பயன்பாட்டையும் இணைக்க முடியும். முழு அமைப்புகளுக்கு `$OMARCHY_PATH/shell/plugins/agents/`-இன் கீழ் உள்ள README-ஐப் பார்க்கவும்.

### பல சந்தாக்கள்

நீங்கள் ஒன்றுக்கு மேற்பட்ட Claude, Codex, அல்லது Grok திட்டத்திற்குப் பணம் செலுத்தினால் — எடுத்துக்காட்டாக தனிப்பட்ட Max மற்றும் பணி ஒன்று — Omarchy அவை அனைத்தையும் உள்நுழைந்த நிலையில் வைத்து அவற்றுக்கிடையே நகர முடியும். ஏஜென்ட்கள் panel-இல் + உடன் சந்தாவைச் சேர்க்கவும், அது அங்கேயே உங்களை அதன் வழியாக அழைத்துச் செல்லும், அல்லது `omarchy agent account add claude Work` (அல்லது `codex`, அல்லது `grok`) உடன். அது இல்லை என்றால் CLI-ஐ நிறுவும். ஒரு வழங்குநருக்கான முதல் கணக்கு உங்கள் சாதாரண உலாவி வழியாக உள்நுழையும், CLI எப்போதும் பார்க்கும் இடத்திலேயே. அதற்குப் பிறகு ஒவ்வொன்றும் தனிப்பட்ட சாளரம் வழியாக உள்நுழையும், எனவே உங்கள் உலாவி ஏற்கனவே உள்நுழைந்துள்ள கணக்கு தவறுதலாக எடுக்கப்படாது; நீங்கள் சேர்க்கும் கணக்காக அங்கு உள்நுழையவும், ஏற்கனவே திறந்திருந்த எந்தத் தனிப்பட்ட சாளரத்தையும் முதலில் மூடவும். இதைச் செய்ய CLI-இலிருந்து ஒருபோதும் வெளியேற வேண்டாம்: வெளியேறுவது சேமிக்கப்பட்ட உள்நுழைவை ரத்து செய்யும், மேலும் அந்தக் கணக்கை மீண்டும் சேர்க்க வேண்டியிருக்கும்.

உங்கள் சந்தா உள்நுழைவுகளை SSH வழியாக மற்றொரு Omarchy இயந்திரத்திற்கு நகலெடுக்க, `omarchy agent account copy user@laptop` என்பதை இயக்கவும். இலக்கில் ஒன்று நிறுவப்படவில்லை என்றால் அனுப்புநர் தற்காலிக பெறுநரை வழங்குகிறது, எனவே பழைய Omarchy இயந்திரங்கள் புதுப்பிப்பு இல்லாமல் கணக்குகளைப் பெற முடியும். நிறுவப்பட்ட பெறுநர்களுக்கு முன்னுரிமை கிடைக்கும். இது அனைத்து Claude, Codex, மற்றும் Grok சந்தாக்களையும் நகலெடுக்கிறது; அவற்றைத் தேர்ந்தெடுக்க வழங்குநர் பெயர்களைச் சேர்க்கவும், `omarchy agent account copy laptop claude` இல் உள்ளது போல. கணக்குப் பெயர்கள் மற்றும் கட்டளை ID-கள் மூலத்துடன் பொருந்தும், இலக்கில் ஏற்கனவே உள்ள கணக்குகள் உட்பட. தொடர்பில்லாத இலக்குக் கணக்குகளின் பெயர்கள் முரண்பட்டால் எண் பின்னொட்டைப் பெறும், மேலும் அமைப்புகள், skills, plugins, மற்றும் உரையாடல் வரலாறு ஒவ்வொரு இயந்திரத்திற்கும் உள்ளூராகவே இருக்கும்.

ஏற்கனவே உள்ள இலக்கு நற்சான்றுகள் வைக்கப்படும். அங்கு ஏற்கனவே உள்நுழைந்துள்ள மூலக் கணக்கின் பெயர் அதன் நற்சான்றுகளை மாற்றாமல் ஒத்திசைக்கப்படும்; மற்ற கணக்குகள் அதனுடன் சேர்த்துச் சேர்க்கப்படும். பொருந்தும் கணக்குகளுக்குச் சேமிக்கப்பட்ட நற்சான்றுகளை மாற்ற, இலக்கில் அந்தக் கணக்கின் அமர்வுகளை விட்டு வெளியேறிய பிறகு `omarchy agent account copy --replace laptop claude` என்பதைப் பயன்படுத்தவும். புதிய இலக்கு மூலத்தின் செயலில் உள்ள கணக்கு மற்றும் மாற்று விருப்பங்களையும் பெறுகிறது; நிறுவப்பட்ட இலக்கு அதன் சொந்தத்தை வைத்திருக்கிறது.

நற்சான்றுகள் SSH வழியாகப் பயணித்து இலக்கில் தனிப்பட்ட கோப்புகளில் சேமிக்கப்படுகின்றன, எனவே நீங்கள் நம்பும் இயந்திரங்களுக்கு மட்டும் நகலெடுக்கவும். இது ஒரு முறை நகல், தொடர்ச்சியான ஒத்திசைவு அல்ல. Codex refresh tokens மற்றொரு இயந்திரத்தால் சுழற்றப்படலாம், நகலெடுக்கப்பட்ட உள்நுழைவுக்குப் புதுப்பிப்பு தேவைப்படும் நிலையை விட்டுச் செல்லும்; பல இயந்திரங்களில் ஒரே நேரத்தில் பயன்படுத்த தனித்தனி உள்நுழைவுகளே மிகவும் நம்பகமான தேர்வாக இருக்கும். [Codex-இன் கணக்கு அங்கீகார வழிகாட்டுதல்](https://developers.openai.com/codex/auth/ci-cd-auth) என்பதைப் பார்க்கவும்.

ஒரு வழங்குநருக்கு ஒரு கணக்கு செயலில் இருக்கும், மேலும் ஒவ்வொரு புதிய அமர்வும் அதுவாகவே தொடங்கும்: `cx`, `cy`, சாதாரண `claude`, `codex`, அல்லது `grok`, `omarchy agent` வழியாகத் தொடங்கப்படும் எதுவும், மற்றும் `PATH`-இல் CLI-ஐக் கண்டறியும் scripts அல்லது editors. `omarchy agent account use work` உடன் மாறவும் (மற்றும் `omarchy agent account use main` உடன் திரும்பவும்), அல்லது panel-இல் கணக்கின் எண்ணை அழுத்தி பின்னர் `Enter` (அல்லது அதன் Use பொத்தானைக் கிளிக் செய்வதன் மூலம்). ஏற்கனவே இயங்கும் அமர்வுகள் அவை தொடங்கிய கணக்கிலேயே இருக்கும். உரையாடல் வரலாறு, அமைப்புகள், skills, மற்றும் plugins கணக்குகள் முழுவதும் பகிரப்படும், எனவே அதே கோப்புறையில் `claude --continue` நீங்கள் புதிய கணக்கில் விட்ட இடத்திலிருந்து தொடரும்.

ஒன்றுக்கு மேற்பட்ட கணக்குகளுடன், panel ஒவ்வொரு கணக்கின் வரம்புகளையும் அருகருகே காட்டும், செயலில் உள்ளது குறிக்கப்பட்டிருக்கும். இயல்பாக செயலில் உள்ள கணக்கு ஒரு வரம்பின் 95%-ஐக் கடக்கும்போது Omarchy உங்களுக்கு அறிவிக்கும், மேலும் அறிவிப்பைக் கிளிக் செய்வது அதிக இடவசதி உள்ள கணக்குக்கு மாறும். panel-இல் கணக்கின் வரியின் மேல் வைத்து Use-க்கு அருகில் தோன்றும் Autoswitch-ஐக் கிளிக் செய்யவும் (அல்லது `m` அழுத்தவும்), அல்லது அது தானாகவே மாற `omarchy agent account mode auto` என்பதை இயக்கவும்; அது இயக்கத்தில் இருக்கும்போது, Autoswitch Use-இன் இடத்தைப் பிடிக்கும், மேலும் அதை மீண்டும் கிளிக் செய்வது அறிவிப்பதற்குத் திரும்பும். வரம்பை மாற்ற ஒரு எண்ணைச் சேர்க்கவும், `omarchy agent account mode auto 90` இல் உள்ளது போல. ஒவ்வொரு கணக்கும் வரம்புக்கு மேல் இருந்தால், எந்தக் கணக்கு முதலில் விடுபடுகிறது என்பதுடன் ஒரு முறை நீங்கள் கேட்பீர்கள். செயலில் உள்ள கணக்கு அதன் வரம்பிலிருந்து 15 புள்ளிகளுக்குள் இருக்கும்போது (இயல்புநிலையில் 80%), அதன் வரம்புகள் ஒவ்வொரு 15 நிமிடங்களுக்குப் பதிலாக ஒவ்வொரு மூன்று நிமிடங்களுக்கும் சரிபார்க்கப்படும்.

`omarchy agent account list` ஒவ்வொரு கணக்கையும் அதன் சமீபத்திய வரம்புகளையும் காட்டுகிறது, `omarchy agent account remove work` ஒன்றை மறக்கிறது, மேலும் `omarchy agent account rename primary Hey` ஒன்றை மறுபெயரிடுகிறது (அல்லது panel-இல் கணக்கின் பெயரைக் கிளிக் செய்யவும்). இந்தக் கட்டளைகள் உங்கள் இயல்புநிலை ஏஜென்ட்டின் கணக்குகளில் செயல்படும்; மற்ற வழங்குநரை அடைய, முதலில் அதைப் பெயரிடவும், `omarchy agent account use codex side` இல் உள்ளது போல. நீங்கள் ஏற்கனவே `~/.claude` அல்லது `~/.codex`-இல் வைத்திருந்த உள்நுழைவு _Main_ கணக்கு மற்றும் அது இருக்கும் இடத்திலேயே இருக்கும். சுமார் எட்டு மணிநேரத்திற்கு மேல் பயன்படுத்தப்படாமல் விடப்பட்ட கணக்கு _Sign-in required_ எனக் காட்டக்கூடும்; அந்தக் கணக்கில் மீண்டும் உள்நுழைய panel-இல் அதைக் கிளிக் செய்யவும், அல்லது அதில் ஒரு அமர்வைத் தொடங்கவும், அது உள்நுழைவைத் தானாகவே புதுப்பிக்கும். கணக்கு சேர்க்கப்பட்டபோது நீங்கள் வைத்திருந்த MCP servers அதனுடன் வரும், ஆனால் பின்னர் `claude mcp add` உடன் நீங்கள் சேர்ப்பவை நீங்கள் அவற்றைச் சேர்த்த கணக்கை மட்டுமே சென்றடையும். CLI binary-க்கு முழுமையான பாதையுடன் உள்ளமைக்கப்பட்ட Claude Desktop மற்றும் கருவிகள் மாற்றத்தைப் பின்தொடராது. வெளிப்படையான `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, அல்லது `GROK_HOME` தேர்ந்தெடுக்கப்பட்ட கணக்கை விட முன்னுரிமை பெறும்.

### செயலிழப்பு கண்டறிதல்

Omarchy செயல்முறை செயலிழப்புகளுக்காக systemd-coredump-ஐக் கண்காணிக்கிறது. ஏதாவது segfault ஆகும்போது, நீங்கள் "Process crashed" அறிவிப்பைப் பெறுவீர்கள் — அதைக் கிளிக் செய்யவும், மேலும் செயலிழப்பு உங்கள் இயல்புநிலை ஏஜென்ட்டிடம் Omarchy-இன் diagnose-crash skill-உடன் ஒப்படைக்கப்படும், அது core dump-இலிருந்து உண்மைகளை நிறுவுவதன் வழியாகவும் செயலிழப்பை மேல்நிலையில் புகாரளிப்பது மதிப்புள்ளதா என முடிவு செய்வதன் வழியாகவும் ஏஜென்ட்டை அழைத்துச் செல்லும். `coredumpctl list`-இலிருந்து எந்த PID-க்கு எதிராகவும் `omarchy agent crash <pid>` உடன் அதைக் கையாலும் இயக்கலாம்.

கண்காணிப்பு இயல்பாக இயக்கத்தில் இருக்கும். _Trigger > Toggle > Crash Capture_ என்பதன் கீழ் (அல்லது `omarchy toggle crash-capture` உடன்) அதை அணைக்கவும், அறிவிப்புகள் நிற்கும்; `omarchy agent crash <pid>` இன்னும் கையால் செயல்படும்.

செயலிழப்புகளை ஒரு நேரத்தில் ஒரு நிரலாகவும் அமைதிப்படுத்தலாம், இறுதியில் கண்டறிதல் உங்களுக்கு வழங்குவது அதுதான். `omarchy crash mute hyprland` அந்த நிரலுக்கு மட்டும் அறிவிப்புகளை நிறுத்துகிறது, `omarchy crash mute hyprland off` அவற்றைத் திரும்பக் கொண்டு வருகிறது, மேலும் `omarchy crash mute` தனியாக நீங்கள் மியூட் செய்தவற்றைப் பட்டியலிடுகிறது. இது binary-இன் பாதையை அதன் பெயரைப் போலவே மகிழ்ச்சியாக ஏற்கும், எனவே `omarchy crash mute /usr/bin/hyprland` அதையே செய்கிறது. இடைவெளி உள்ள பெயரை மேற்கோள் காட்டவும், `omarchy crash mute 'Some App'` இல் உள்ளது போல. மற்ற அனைத்தும் இன்னும் அறிவிக்கும், மேலும் மியூட் செய்யப்பட்ட நிரல் இன்னும் செயலிழக்கும் — இது நினைவூட்டலை மறைக்கிறது, இது எதையும் சரிசெய்யாது.

### டெஸ்க்டாப் செயலிகள்

_நிறுவு > AI_ மெனு சில வரைகலை AI செயலிகளையும் கொண்டுள்ளது: ChatGPT desktop app, Claude desktop app (Anthropic-இன் Linux beta, Chat, Cowork, மற்றும் Claude Code tabs உடன்), xAI-இன் மாடல்களுடன் அரட்டை அடிக்க Grok Bot, Hermes Desktop, OpenClaw, Perplexity desktop app, மற்றும் T3 Code. Grok Bot என்பது desktop chat app. கோடிங் ஏஜென்ட் என்பது `grok` கட்டளை.

Hermes Desktop தான் தெரிந்து கொள்ள வேண்டியது, ஏனெனில் ஒரு இயந்திரத்தில் ஒரு Hermes உள்ளது, அது செயலியினுடையது: Hermes எப்போதும் செயலி வழியாகவே நிறுவப்படுகிறது, மேலும் இயல்புநிலை ஏஜென்ட் இயக்கும் `hermes` கட்டளை செயலியினுடையது. Hermes-ஐ இயல்புநிலை ஏஜென்ட்டாகத் தேர்ந்தெடுப்பது _நிறுவு > AI_ உள்ளீடு செய்வதையே நிறுவும்: தொகுப்பு, மற்றும் Hermes-இன் சொந்த நிறுவியால் அமைக்கப்பட்ட `~/.hermes`-இன் கீழ் Hermes runtime, இது முதல் முறை சில நிமிடங்கள் எடுக்கும். அந்த runtime தான் terminal `hermes` கட்டளை, இயல்புநிலை ஏஜென்ட் மற்றும் செயலி அனைத்தும் பயன்படுத்தும் ஒரே Hermes, மேலும் அது Omarchy வெளியீட்டிற்காகக் காத்திருக்காமல் `hermes update` உடன் தன்னைப் புதுப்பிக்கிறது. அதை நிறுவுவது Hermes-க்கு Omarchy theme-ஐ `omarchy` என்ற பெயரில் skin ஆகவும் வழங்குகிறது, நீங்கள் themes மாற்றும்போது ஒவ்வொரு Hermes மேற்பரப்பும் அதைப் பின்தொடரும்; நீங்கள் அது வேண்டாம் என விரும்பினால் Hermes-இன் Appearance அமைப்புகளின் கீழ் அல்லது `/skin` உடன் மற்றொன்றைத் தேர்ந்தெடுக்கவும், மேலும் Omarchy அந்தத் தேர்வை அப்படியே விட்டுவிடும். _அகற்று > AI_ என்பதன் கீழ் செயலியை அகற்றுவது முதலில் Hermes-ஐ மூடும், gateway உட்பட, அந்த runtime-ஐ அதனுடன் எடுத்துச் செல்லும், மேலும் நீங்கள் வேறுவிதமாகச் சொன்னால் தவிர உங்கள் chats, memories, மற்றும் Hermes தனக்காக எழுதிய skills-ஐ வைத்திருக்கும்: அந்தத் தரவும் உங்கள் இணைப்பு அமைப்புகளும் கூட நீக்கப்பட வேண்டுமா என அது கேட்கும், இயல்பாக இல்லை என.

OpenClaw-இன் desktop அனுபவம் அதன் Control UI, இது அதன் சொந்த உள்ளூர் gateway-ஆல் ஆதரிக்கப்படும் web app ஆகத் திறக்கும். OpenClaw `~/.openclaw`-இல் வாழ்கிறது மற்றும் தன்னைப் புதுப்பிக்கிறது: Control UI-இன் "Update Gateway" பொத்தானைப் பயன்படுத்தவும் அல்லது `openclaw update` என்பதை இயக்கவும், மேலும் gateway புதிய பதிப்பில் மறுதொடக்கம் செய்யும். புதிய நிறுவல் எந்த வெளியீட்டில் தொடங்குகிறது என்பதை மட்டும் Omarchy தேர்ந்தெடுக்கிறது. _அகற்று > AI_ என்பதன் கீழ் OpenClaw-ஐ அகற்றுவது gateway சேவையையும் செயலியையும் அதனுடன் எடுத்துச் செல்லும், பின்னர் `~/.openclaw` கூட நீக்கப்பட வேண்டுமா எனக் கேட்கும், ஏனெனில் அது OpenClaw உடன் மற்றும் அது பதிவிறக்கும் plugin runtimes உடன் உங்கள் chats மற்றும் நற்சான்றுகளை வைத்திருக்கிறது; இயல்புநிலை அதை வைத்திருக்கும், மேலும் OpenClaw-ஐ மீண்டும் நிறுவுவது அதை மீண்டும் எடுக்கும்.

T3 Code தொகுப்பிலிருந்து அல்லாமல் `~/.local/share/t3code`-இல் அதன் அதிகாரப்பூர்வ AppImage வெளியீட்டிலிருந்து இயங்குகிறது, எனவே அது தன்னைப் புதுப்பிக்கிறது. அதை நிறுவுவது Stable அல்லது Nightly channel-இல் தொடங்க வேண்டுமா எனக் கேட்கும்; பின்னர் T3 Code-இன் அமைப்புகளில் மாறவும். உங்கள் threads மற்றும் அமைப்புகள் `~/.t3`-இல் வாழ்கின்றன, மேலும் _அகற்று > AI_ என்பதன் கீழ் T3 Code-ஐ அகற்றுவது அவற்றை அதனுடன் எடுத்துச் செல்லும்.

### உள்ளூர் மாடல்கள்

உங்கள் கோடிங் ஏஜென்ட்களுக்காக உங்கள் சொந்த இயந்திரத்தில் திறந்த மாடலை இயக்கவும். உங்கள் குறிப்புகள் மற்றும் குறியீடு இயந்திரத்தில் இருக்கும்; மாடலுக்கு அனுப்பப்படும் எதுவும் அதை விட்டு வெளியேறாது. இதனுடன் தொடங்கவும்:

```bash
omarchy agent local use best
```

அல்லது, மேல் பட்டியில் உள்ள ஏஜென்ட்கள் panel-இல், + மற்றும் பின்னர் Local AI-ஐத் தேர்ந்தெடுக்கவும், ஒரு மாடல் இந்த இயந்திரத்திற்குப் பொருந்தும்போது இது தோன்றும். முதல் முறை, இது மாடல்களை இயக்கும் Podman-ஐ நிறுவும், மேலும் NVIDIA இயந்திரத்தில் NVIDIA-இன் container toolkit-ஐ நிறுவும், இது அவற்றுக்கு GPU-ஐ வழங்குகிறது. Omarchy பின்னர் இந்த இயந்திரத்திற்குப் பரிந்துரைக்கப்பட்ட மாடலைத் தேர்ந்தெடுத்து, அதைப் பதிவிறக்கி, தொடங்குகிறது. பத்துகள் GB பதிவிறக்கத்தையும் மாடல் இயங்கும்போது இயந்திரத்தின் பெரும்பாலான நினைவகம் பயன்பாட்டில் இருப்பதையும் எதிர்பார்க்கவும்: Flash Next அதன் முழு 256K context-உடன் சுமார் 100 GiB பயன்படுத்துகிறது. மற்ற மாடல்கள் அதற்குத் தேவையான நினைவகத்தை வைத்திருந்தால், ஒன்றை நிறுத்தியவுடன் தொடங்கத் தயாராக நிறுத்தப்பட்ட நிலையில் அது அமைக்கப்படும். மாடல் logout-இல் நிற்கும்; உங்களுக்கு வேறு ஏதாவதுக்கு நினைவகம் தேவைப்படும்போது அதை நீங்களே நிறுத்தவும்.

`omarchy agent local list` விருப்பங்களைக் காட்டுகிறது மற்றும் சில ஏன் பொருந்தவில்லை என விளக்குகிறது. மற்றொன்றை அமைக்க, `omarchy agent local use <recipe>` என்பதை இயக்கவும். இன்று, `qwen3.8-flash-next-gufo` மற்றும் `qwen3.8-27b-gufo` 128 GB Strix Halo இயந்திரங்களுக்குக் கிடைக்கின்றன; 27B சுமார் 40 GiB எடுக்கும், எனவே அது மற்ற வேலைகளுக்கு இடம் விடுகிறது. புதிய recipes மற்றும் பரிந்துரைகள் `omarchy update` உடன், தொகுப்பு வழியாக வருகின்றன.

நீங்கள் அமைக்கும் ஒவ்வொரு மாடலும் உங்கள் சந்தாக்களுக்கு அருகில் ஏஜென்ட்கள் panel-இல் அதன் சொந்த வரியைப் பெறுகிறது: அதைத் தொடங்க play, அதை நிறுத்தி அதன் நினைவகத்தை விடுவிக்க pause, மேலும் அதில் உங்கள் ஏஜென்ட்டைத் திறக்க terminal பொத்தான். அவை நினைவகத்தில் ஒன்றாகப் பொருந்தும்போது பல ஒரே நேரத்தில் இயங்க முடியும்; ஒன்று பொருந்தவில்லை என்றால், எந்த இயங்கும் மாடலை நிறுத்த வேண்டும் என Omarchy சொல்லும். அவற்றை மறுவரிசைப்படுத்த வரிகளை இழுக்கவும், மேலும் மாடல் மற்றும் அதன் பதிவிறக்கத்தை அகற்ற தேர்ந்தெடுக்கப்பட்ட வரியில் Delete அழுத்தவும்.

கட்டளை வரியிலிருந்து, `omarchy agent local start <recipe>` மற்றும் `omarchy agent local stop <recipe>` அதையே செய்கின்றன, `omarchy agent local status` ஒவ்வொரு மாடலையும் காட்டுகிறது, மேலும் `omarchy agent --local` நீங்கள் கடைசியாகத் தொடங்கிய மாடலில் உங்கள் இயல்புநிலை ஏஜென்ட்டைத் திறக்கிறது (உங்கள் இயல்புநிலை ஏஜென்ட் உள்ளூர் மாடலைப் பயன்படுத்த முடியாவிட்டால் pi). எந்த OpenAI-இணக்கமான client-ம் இணைக்க முடியும்: `status` ஒவ்வொரு மாடலின் முகவரியையும் காட்டுகிறது (முதலாவது `http://127.0.0.1:11435/v1`), recipe பெயர் மாடல், மேலும் key `~/.config/omarchy/agent-local/key`-இல் உள்ளது.

`omarchy agent local remove <recipe>` ஒரு மாடலையும் வேறு எந்த மாடலும் பயன்படுத்தாத பதிவிறக்கங்களையும் நீக்குகிறது.

மூன்றாம் தரப்பு runtimes அவற்றின் வெளியீட்டாளரால் குறிக்கப்படுகின்றன. Omarchy ஒவ்வொரு மாடலையும் நெட்வொர்க் அணுகல் இல்லாமல் இயக்குகிறது.

### உள்ளூர் LLMs

Omarchy உள்ளூர் LLM மாடல்களை இயக்க இரண்டு வழிகளைப் பரிந்துரைக்கிறது: LM Studio மற்றும் Ollama. LM Studio திறந்த-எடை மாடல்களைக் கண்டறிவதற்கும், அவற்றை நிறுவுவதற்கும், இயக்குவதற்கும் GUI இடைமுகத்தை வழங்குகிறது. எளிதாகத் தொடங்க இது சிறந்த வழி. Ollama அதையே செய்ய CLI வழங்குகிறது. ஆனால் நீங்கள் உள்ளூர் மாடல்களுக்குப் புதியவராக இருந்தால், நான் LM Studio-உடன் தொடங்குவேன். Omarchy Menu-இல் _நிறுவு > AI_ என்பதன் கீழ் இரண்டில் ஒன்றை நிறுவலாம்.

### Omarchy Skill

ஏஜென்ட் skills AI குறிப்பிட்ட கருவிகளைக் குறிப்பிட்ட வழியில் பயன்படுத்த உதவுகின்றன, மேலும் Omarchy கணினியைத் தனிப்பயனாக்க இயல்புநிலை skill உடன் வருகிறது. உங்கள் Hyprland config-ஐ மாற்றுவது, பட்டியைச் சரிசெய்வது, அல்லது புதிதாக ஒரு theme உருவாக்குவது போல. இது Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` மற்றும் ஒவ்வொரு `~/.hermes/profiles/*/skills`), மற்றும் பொதுவான `~/.agents/skills` இடத்திற்கான skill அடைவுகளில் symlinked, எனவே பெரும்பாலான ஹார்னஸ்கள் அதைத் தானாகவே எடுக்கும்.

ஆனால் நீங்கள் இந்த skill-ஐ சோதனை முயற்சியாகக் கருத வேண்டும். வெவ்வேறு மாடல்கள் அதை வெவ்வேறு விளைவுகளுக்குப் பயன்படுத்தும். முதலில் plan mode-இல் இயக்குவது சிறந்தது, எனவே ஏஜென்ட் என்ன மாற்ற விரும்புகிறது என்பது குறித்து உங்களுக்கு யோசனை கிடைக்கும். பின்னர் மாற்றங்களைத் திரும்பப் பெற அல்லது ஏஜென்ட் எல்லாவற்றையும் குழப்பினால் `omarchy reinstall configs` என்பதை அழைக்கவும் தயாராக இருங்கள்.
