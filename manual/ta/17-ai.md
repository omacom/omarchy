Omarchy, உங்களுக்காக ஒரு இயல்புநிலையைத் தேர்ந்தெடுக்காமல், கீழுள்ள குறியீட்டு ஏஜெண்டுகளுக்கான துவக்கிகளை உள்ளடக்கியுள்ளது. ஒரு கட்டளையை இயக்கினால் முதல் பயன்பாட்டில் அதன் CLI நிறுவப்படும், பின்னர் கேட்கப்படும்போது அங்கீகரிக்கவும். ### ஏஜெண்டுகளை நிறுவுதல் மற்றும் புதுப்பித்தல்

Hermes-ஐத் தவிர, இந்த ஏஜெண்டுகள் mise-இன் சோம்பேறி நிறுவலைப் பயன்படுத்துகின்றன: முதல் துவக்கம் CLI-ஐ நிறுவுகிறது, பிந்தைய துவக்கங்கள் அதையே மீண்டும் பயன்படுத்துகின்றன. மேலும் mise, நிறுவப்பட்ட ஏஜெண்டிற்கு ஒரு புதிய வெளியீடு உள்ளதா என நான்கு மணி நேரத்திற்கு ஒரு முறைக்கு மேல் சரிபார்ப்பதில்லை, அது தொடங்குவதற்குச் சற்று முன்பு அல்லது ஒரு shell prompt-இல் பின்னணியில். அந்தப் புதுப்பிப்பு தோல்வியடைந்தால் அல்லது நீங்கள் offline-இல் இருந்தால், நிறுவப்பட்ட பதிப்பு இயங்கும். `omarchy update` நிறுவப்பட்ட ஏஜெண்டுகளை Omarchy-இன் மற்றவற்றுடன் சேர்த்துப் புதுப்பிக்கிறது, மேலும் `mup` mise-ஆல் நிர்வகிக்கப்படும் கருவிகளை மட்டும் புதுப்பிக்கிறது.

`claude update`, `codex update`, அல்லது ஒரு பயன்பாட்டில் உள்ள ஒரு புதுப்பிப்புப் பொத்தான் போன்ற ஒரு ஏஜெண்டின் சொந்தப் புதுப்பிப்பாளர், mise-ஆல் நிர்வகிக்கப்படும் நிறுவலைப் புதுப்பிப்பதில்லை. `codex update` தோல்வியடைகிறது, மேலும் `claude update` வெற்றி என அறிவித்துக்கொண்டே mise கண்காணிக்காத ஒரு தனி நகலை நிறுவக்கூடும். நீங்கள் ஒரு ஏஜெண்டின் சொந்த நிறுவியையும் புதுப்பிப்பாளரையும் பயன்படுத்த விரும்பினால், அதை `disable_tools`-இல் சேர்க்கவும்; [முன்பே நிறுவப்பட்ட CLI கருவிகள்](18-development-tools.md#preinstalled-cli-tools) என்பதைப் பார்க்கவும்.

உள்ளமைக்கப்பட்ட அனைத்து சோம்பேறி கருவிகளையும் உங்களுக்குத் தேவைப்படுவதற்கு முன்பே நிறுவ, `mise install --include-lazy` என்பதை இயக்கவும். இதில் ஏஜெண்டுகளுடன் Omarchy-இன் மற்ற இயல்புநிலை CLI கருவிகளும் அடங்கும். ஒரு தனிக் கருவியை நிறுவுவதற்கு அல்லது உங்கள் சொந்த நிறுவலைப் பயன்படுத்துவதற்கு [முன்பே நிறுவப்பட்ட CLI கருவிகள்](18-development-tools.md#preinstalled-cli-tools) என்பதைப் பார்க்கவும்.

`grok`, `claude` மற்றும் `codex` போலவே, mise-இன் முதல்-தரப்பு `grok` தொகுப்பு மூலம் நிறுவப்படுகிறது. `grok` என்பதை இயக்கவும், அல்லது _Agent > Harness_ என்பதன் கீழ் அதைத் தேர்ந்தெடுக்கவும். x.ai-இல் உள்ள `curl | bash` நிறுவியைத் தவிர்க்கவும். அந்தப் பாதை இரண்டாவது நகலை `~/.grok/bin`-இல் வைக்கிறது, அதை `PATH`-இல் முன்னால் சேர்க்கிறது, மேலும் Omarchy-இன் wrapper-ஐ மேலெழுதுகிறது.

`dsh` அதன் உலாவி UI-ஐ `127.0.0.1:3080`-இல் திறக்கிறது, துவக்க அடைவை அதன் இயல்புநிலை workspace ஆகக் கொண்டு. அதன் உலாவி UI தொடக்க prompt எதையும் எடுப்பதில்லை, எனவே `omarchy agent prompt` அதை ஒட்டுவதற்கு உங்கள் clipboard-இல் prompt உடன் திறக்கிறது. Omarchy அதை DeepSeek-இன் ஒப்புதல்-தேவையில்லாத அனுமதி முன்னமைவுடன் தொடங்குகிறது. நீங்கள் அதன் அதிகாரப்பூர்வ மாதிரி API-ஐப் பயன்படுத்தும்போது DeepSeek Harness அமர்வுப் பதிவுகளை DeepSeek-இற்குப் பதிவேற்றுகிறது; அதன் உலாவி UI-இல் _Settings > General > Upload Session Log_ என்பதன் கீழ் அதை முடக்கவும். நீங்கள் அதற்கு அனுப்பும் கருத்தும் அமர்வுடன் சேர்த்துப் பதிவேற்றப்படும், நீங்கள் அதை `DSH_TELEMETRY_MODE=DISABLED` உடன் தொடங்கினால் தவிர.

### இயல்புநிலை ஏஜெண்ட்

உங்கள் இயல்புநிலை ஏஜெண்டை `omarchy default agent <name>` உடன் அல்லது Omarchy Menu-இல் (`Super + Space`) _Agent > Harness_ என்பதன் கீழ் தேர்ந்தெடுக்கவும். ஏஜெண்ட் இன்னும் நிறுவப்படவில்லை என்றால், அதைத் தேர்ந்தெடுப்பது முதலில் அதை நிறுவும். ஒரு புதிய Omarchy ஒரு முறை மட்டுமான அறிவிப்புடன் இந்தத் தேர்வைச் செய்ய உங்களை அழைக்கும்.

Claude-ஐத் தேர்ந்தெடுப்பது Chromium, Chrome, Brave, Brave Origin, மற்றும் Edge-க்கான அதன் உலாவி நீட்டிப்பை அமைக்கவும் முயற்சிக்கிறது. நீட்டிப்பு அமைப்பு அனைத்து பயனர்களுக்கும் பொருந்தும் மற்றும் உங்கள் கணினி கடவுச்சொல்லைக் கேட்கக்கூடும்; ரத்து செய்வது அல்லது தோல்வியடைந்த நீட்டிப்பு நிறுவல் இருந்தாலும் Claude தேர்ந்தெடுக்கப்பட்டு துவக்கப்படும். உங்கள் உலாவியை மறுதொடக்கம் செய்யவும், கேட்கப்பட்டால் நீட்டிப்பை இயக்கவும், அதை இணைப்பதை முடிக்க Claude-இல் உள்நுழையவும். இணைப்பைச் சரிபார்க்க Claude-இல் `/chrome` என்பதை இயக்கவும். Firefox மற்றும் Zen இந்த நீட்டிப்பை ஆதரிப்பதில்லை. இந்த அமைப்பு சேர்க்கப்படுவதற்கு முன்பே Claude உங்கள் இயல்புநிலையாக இருந்திருந்தால், நீட்டிப்பை நிறுவ அதை மீண்டும் தேர்ந்தெடுக்கவும்.

நீங்கள் தேர்ந்தெடுத்த பிறகு, `Super + Shift + Ctrl + A` இயல்புநிலை ஏஜெண்டை ஒரு பிரத்யேக terminal சாளரத்தில் துவக்குகிறது (அல்லது நீங்கள் இன்னும் தேர்ந்தெடுக்கவில்லை என்றால் தேர்வியைக் கொண்டு வருகிறது). நீங்கள் அதை `omarchy agent prompt "Review this project"` உடன் நேரடியாக ஒரு பணிக்குள்ளும் துவக்கலாம். Freebuff மற்றும் DeepSeek Harness தொடக்க prompt எதையும் எடுப்பதில்லை, எனவே அவை அதற்குப் பதிலாக ஒட்டுவதற்கு உங்கள் clipboard-இல் prompt உடன் திறக்கின்றன. இப்படித் துவக்கப்படும் ஏஜெண்டுகள் அவற்றின் அந்தந்த நிறுத்தி-கேட்காத முறைகளில் கவனிக்கப்படாமல் இயங்குகின்றன, எனவே அவை உண்மையில் விஷயங்களைச் செய்யத் தயாராக இருங்கள்! MiniMax Code-இற்கு அதன் ஊடாடும் அமர்வுகளுக்கு அத்தகைய முறை இல்லை, எனவே அது வழக்கம் போல அனுமதிகளைக் கேட்கிறது. மேலும் ஏஜெண்டுகள் உங்கள் home அடைவிற்கான நம்பிக்கையை நினைவில் வைக்க மறுப்பதால், `$HOME`-இலிருந்து துவக்கங்கள் அதற்குப் பதிலாக `~/Work`-இல் தொடங்குகின்றன.

terminal குறுக்குவழிகளும் உள்ளன: `a` தற்போதைய terminal-இல் இயல்புநிலை ஏஜெண்டை inline ஆக இயக்குகிறது, அதே நேரத்தில் `c`, `cx`, மற்றும் `cy` OpenCode, Claude Code, மற்றும் Codex ஆகியவற்றை நேரடியாகத் தொடங்குகின்றன (மீண்டும் அவற்றின் தானியங்கு-ஒப்புதல் முறைகளில்). Theme மாற்றங்களும் ஏஜெண்டுகளுக்கு ஒத்திசைகின்றன: நீங்கள் Omarchy theme-ஐ மாற்றும்போது Claude Code, Pi, OpenCode, மற்றும் Hermes (Omarchy அதை நிறுவிய பிறகு) அனைத்தும் பின்தொடர்கின்றன.

### உங்கள் ஏஜெண்ட் வழிமுறைகள்

ஒவ்வொரு ஏஜெண்டிற்கான தனிப்பட்ட விதிகளும் `~/.agents/skills`-இல் உள்ள பகிரப்பட்ட skills-க்கு அடுத்ததாக `~/.agents/AGENTS.md`-இல் செல்கின்றன. அதை _Agent > Instructions_ என்பதன் கீழ் திறக்கவும், இது அதைத் தனது சொந்த உலகளாவிய கோப்பை வைத்திருக்கும் ஒவ்வொரு harness-இற்குள்ளும் இணைக்கிறது: `~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.pi/agent/AGENTS.md`, `~/.config/opencode/AGENTS.md`, Copilot-இன் `~/.copilot/copilot-instructions.md`, மற்றும் பல. Crush மற்றும் Amp `~/.config/AGENTS.md` இணைப்பைப் படிக்கின்றன, அதே நேரத்தில் omp, Kimi, மற்றும் DeepSeek Harness `~/.agents/AGENTS.md`-ஐ நேரடியாகப் படிக்கின்றன. ஒரு இயல்புநிலை ஏஜெண்டைத் தேர்ந்தெடுப்பதும் அதை இணைக்கிறது. நீங்கள் ஏற்கனவே வைத்திருந்த ஒரு வழிமுறைகள் கோப்பு, இன்னும் எதுவும் இல்லாதிருந்தால் பகிரப்பட்டதாக மாறுகிறது; இல்லையெனில் அது இணைப்புக்கு அருகில் `.bak` ஆக வைக்கப்படுகிறது. மற்றொரு ஏஜெண்டை நிறுவிய பிறகு மீண்டும் இணைக்க `omarchy agent instructions` என்பதை இயக்கவும்.

### ஏஜெண்டுகள் panel

மேல் பட்டியில் ஒரு ஏஜெண்டுகள் சின்னம் உள்ளது. நீங்கள் ஒரு ஏஜெண்டை அமைப்பதற்கு முன்பு, அதன் panel Claude, Codex, அல்லது Grok-இல் உள்நுழைவதன் மூலம் உங்களை வழிநடத்துகிறது, மேலும் முதலாவது உங்கள் இயல்புநிலை ஏஜெண்டாக மாறுகிறது. அதன் பிறகு, panel ஒவ்வொரு சந்தாவையும் ஒரே பக்கத்தில் வைக்கிறது: ஒவ்வொரு ஏஜெண்டும் கணக்கும் அதன் திட்டத்துடன், அதன் 5 மணி நேர அமர்வு மற்றும் வாராந்திர வரம்புகள் ஒவ்வொன்றிற்கும் அது மீட்டமைக்கப்படும் வரையிலான நேரத்துடன் ஒரு மீட்டர் (சரியான சதவீதத்திற்கு hover செய்யவும்), அல்லது மீதமுள்ள முன்கூட்டியே செலுத்தப்பட்ட இருப்பு, இந்த வாரம் tokens மற்றும் உங்கள் மிகவும் பயன்படுத்தப்பட்ட மாதிரி போன்ற, அவை அனைத்திலும் நீங்கள் பயன்படுத்தியதைச் சுழற்றும் ஒரு வரியின் கீழ். _Make something_ என்பதன் கீழ் இது புதிய theme, plugin, அல்லது app-க்கான தொடக்க prompts-ஐ வழங்குகிறது, அவை பணியை உங்கள் இயல்புநிலை ஏஜெண்டிடம் ஒப்படைக்கின்றன. Omarchy-இன் சொந்த Hype, Monologue, மற்றும் Omacut போலவே, C++ மற்றும் Qt Quick-இல், omarchy-app agent skill-ஐப் பின்பற்றி apps கட்டமைக்கப்படுகின்றன, மேலும் அவற்றுக்குத் தேவையான compiler மற்றும் Qt துண்டுகள் நிறுவப்பட்டு வருகின்றன. Claude Code, Codex, Grok, Kimi, Cursor மற்றும் அதன் Grok Bot கொடுப்பனவு, GitHub Copilot, Muse, Antigravity, Kimchi, மற்றும் Devin ஆகியவை அவற்றின் வரம்புகளுடன் தொடக்கத்திலிருந்தே உள்ளடக்கப்பட்டுள்ளன, மேலும் Hermes, Mistral Vibe, மற்றும் Qwen Code நீங்கள் அவற்றைப் பயன்படுத்திய பிறகு அவற்றின் அமர்வுகளையும் tokens-ஐயும் காட்டுகின்றன. pi, omp, அல்லது opencode மூலம் நீங்கள் பயன்படுத்தும் வழங்குநர் திட்டங்களும் keys-ம் தோன்றுகின்றன: OpenCode Zen மற்றும் Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan, மற்றும் Synthetic அவற்றின் வரம்புகளுடன்; Fireworks, OpenRouter, மற்றும் DeepSeek அவற்றின் முன்கூட்டியே செலுத்தப்பட்ட இருப்புகளுடன்; மற்றும் Local models என்பதன் கீழ் உங்கள் சொந்த hardware-இல் நீங்கள் இயக்கும் மாதிரிகள். நீங்கள் எத்தனை harness-கள் மூலம் அதை இயக்கினாலும், ஒவ்வொரு ஏஜெண்டும் ஒரு முறை மட்டுமே, அதற்குக் கட்டணம் வசூலிப்பவரின் கீழ் கணக்கிடப்படுகிறது.

panel-க்கு பட்டி சின்னத்தை இடது-click செய்யவும், உங்கள் இயல்புநிலை ஏஜெண்டைத் துவக்க வலது-click செய்யவும். அதன் பின்னால் உள்ள பயன்பாட்டுப் பதிவுகள் ஒவ்வொரு 15 நிமிடங்களுக்கும் `omarchy agent usage-update`-ஆல் மீண்டும் உருவாக்கப்படுகின்றன, மேலும் panel ஒரு synced கோப்புறை வழியாக உங்கள் மற்ற இயந்திரங்களிலிருந்து பயன்பாட்டைக் கூட இணைக்க முடியும். முழு அமைப்புகளுக்கும் `$OMARCHY_PATH/shell/plugins/agents/` என்பதன் கீழ் உள்ள README-ஐப் பார்க்கவும்.

### பல சந்தாக்கள்

நீங்கள் ஒன்றுக்கு மேற்பட்ட Claude, Codex, அல்லது Grok திட்டத்திற்குப் பணம் செலுத்தினால் — உதாரணமாக ஒரு தனிப்பட்ட Max மற்றும் ஒரு பணி ஒன்று — Omarchy அவை அனைத்தையும் உள்நுழைந்த நிலையில் வைத்து அவற்றுக்கிடையே நகர முடியும். ஏஜெண்டுகள் panel-இல் உள்ள + உடன் ஒரு சந்தாவைச் சேர்க்கவும், அது அங்கேயே உங்களை அதன் மூலம் வழிநடத்துகிறது, அல்லது `omarchy agent account add claude Work` உடன் (அல்லது `codex`, அல்லது `grok`). அது இல்லாவிட்டால் CLI-ஐ நிறுவுகிறது. ஒரு வழங்குநருக்கான முதல் கணக்கு உங்கள் சாதாரண உலாவி மூலம், CLI எப்போதும் பார்க்கும் இடத்திலேயே உள்நுழைகிறது. அதன் பிறகு உள்ள ஒவ்வொன்றும் ஒரு private சாளரம் மூலம் உள்நுழைகிறது, எனவே உங்கள் உலாவி ஏற்கனவே உள்நுழைந்துள்ள கணக்கு தவறுதலாக எடுக்கப்படாது; நீங்கள் சேர்க்கும் கணக்காக அங்கே உள்நுழையவும், நீங்கள் ஏற்கனவே திறந்து வைத்திருந்த எந்த private சாளரத்தையும் முதலில் மூடவும். இதைச் செய்ய CLI-இலிருந்து ஒருபோதும் வெளியேற வேண்டாம்: வெளியேறுவது சேமிக்கப்பட்ட உள்நுழைவை ரத்து செய்கிறது, மேலும் அந்தக் கணக்கு மீண்டும் சேர்க்கப்பட வேண்டியிருக்கும்.

உங்கள் சந்தா உள்நுழைவுகளை SSH வழியாக மற்றொரு Omarchy இயந்திரத்திற்கு நகலெடுக்க, `omarchy agent account copy user@laptop` என்பதை இயக்கவும். இலக்கில் ஒன்று நிறுவப்படாதபோது அனுப்புநர் ஒரு தற்காலிக receiver-ஐ வழங்குகிறார், எனவே பழைய Omarchy இயந்திரங்கள் ஒரு புதுப்பிப்பு இல்லாமல் கணக்குகளைப் பெற முடியும். நிறுவப்பட்ட receivers முன்னுரிமை பெறுகின்றன. இது அனைத்து Claude, Codex, மற்றும் Grok சந்தாக்களையும் நகலெடுக்கிறது; அவற்றைத் தேர்ந்தெடுக்க வழங்குநர் பெயர்களைச் சேர்க்கவும், `omarchy agent account copy laptop claude` இல் உள்ளது போல. இலக்கில் ஏற்கனவே உள்ள கணக்குகள் உட்பட, கணக்குப் பெயர்களும் கட்டளை IDs-ம் மூலத்துடன் பொருந்துகின்றன. தொடர்பில்லாத இலக்குக் கணக்குகள் அவற்றின் பெயர்கள் முரண்பட்டால் ஒரு எண் பின்னொட்டைப் பெறுகின்றன, மேலும் அமைப்புகள், skills, plugins, மற்றும் உரையாடல் வரலாறு ஒவ்வொரு இயந்திரத்திற்கும் உள்ளூராகவே இருக்கும்.

ஏற்கனவே உள்ள இலக்குச் சான்றுகள் வைக்கப்படுகின்றன. அங்கே ஏற்கனவே உள்நுழைந்துள்ள ஒரு மூலக் கணக்கின் பெயர் அதன் சான்றுகளை மாற்றாமல் ஒத்திசைக்கப்படுகிறது; மற்ற கணக்குகள் அதனுடன் சேர்த்துச் சேர்க்கப்படுகின்றன. பொருந்தும் கணக்குகளுக்கான சேமிக்கப்பட்ட சான்றுகளை மாற்ற, இலக்கில் அந்தக் கணக்கின் அமர்வுகளை விட்டு வெளியேறிய பிறகு `omarchy agent account copy --replace laptop claude` என்பதைப் பயன்படுத்தவும். ஒரு புதிய இலக்கு மூலத்தின் செயலில் உள்ள கணக்கையும் மாறுதல் விருப்பங்களையும் பெறுகிறது; ஒரு நிறுவப்பட்ட இலக்கு தனதையே வைத்திருக்கிறது.

சான்றுகள் SSH வழியாகப் பயணித்து இலக்கில் private கோப்புகளில் சேமிக்கப்படுகின்றன, எனவே நீங்கள் நம்பும் இயந்திரங்களுக்கு மட்டும் நகலெடுக்கவும். இது ஒரு முறை நகல், தொடர்ச்சியான ஒத்திசைவு அல்ல. Codex refresh tokens மற்றொரு இயந்திரத்தால் சுழற்றப்படலாம், நகலெடுக்கப்பட்ட உள்நுழைவுக்குப் புதுப்பிப்பு தேவைப்படும் நிலையை விட்டுச்செல்லும்; பல இயந்திரங்களில் ஒரே நேரத்தில் பயன்படுத்த தனித்தனி உள்நுழைவுகளே மிகவும் நம்பகமான தேர்வாக இருக்கின்றன. [Codex-இன் கணக்கு அங்கீகார வழிகாட்டுதல்](https://developers.openai.com/codex/auth/ci-cd-auth) என்பதைப் பார்க்கவும்.

ஒரு வழங்குநருக்கு ஒரு கணக்கு செயலில் உள்ளது, மேலும் ஒவ்வொரு புதிய அமர்வும் அதுவாகவே தொடங்குகிறது: `cx`, `cy`, ஒரு சாதாரண `claude`, `codex`, அல்லது `grok`, `omarchy agent` மூலம் துவக்கப்படும் எதுவும், மற்றும் `PATH`-இல் CLI-ஐக் கண்டறியும் scripts அல்லது editors. `omarchy agent account use work` உடன் மாற்றவும் (மேலும் `omarchy agent account use main` உடன் திரும்பவும்), அல்லது panel-இல் ஒரு கணக்கின் எண்ணை அழுத்தி பின்னர் `Enter` (அல்லது அதன் Use பொத்தானைக் click செய்வதன் மூலம்). ஏற்கனவே இயங்கும் அமர்வுகள் அவை தொடங்கிய கணக்கிலேயே இருக்கும். உரையாடல் வரலாறு, அமைப்புகள், skills, மற்றும் plugins கணக்குகள் முழுவதும் பகிரப்படுகின்றன, எனவே அதே கோப்புறையில் `claude --continue` நீங்கள் புதிய கணக்கில் விட்ட இடத்திலிருந்து தொடர்கிறது.

ஒன்றுக்கு மேற்பட்ட கணக்குகளுடன், panel ஒவ்வொரு கணக்கின் வரம்புகளையும் அருகருகே காட்டுகிறது, செயலில் உள்ளது குறிக்கப்பட்டு. இயல்பாக Omarchy செயலில் உள்ள கணக்கு ஒரு வரம்பின் 95%-ஐக் கடக்கும்போது உங்களுக்கு அறிவிக்கிறது, மேலும் அறிவிப்பைக் click செய்வது மிகவும் இடவசதி உள்ள கணக்கிற்கு மாறுகிறது. panel-இல் ஒரு கணக்கின் வரியில் hover செய்து Use-க்கு அருகில் தோன்றும் Autoswitch-ஐக் click செய்யவும் (அல்லது `m` அழுத்தவும்), அல்லது அதற்குப் பதிலாக அது தானாகவே மாற `omarchy agent account mode auto` என்பதை இயக்கவும்; அது இயக்கத்தில் இருக்கும்போது, Autoswitch Use-இன் இடத்தை எடுக்கிறது, மேலும் அதை மீண்டும் click செய்வது அறிவிப்பதற்குத் திரும்பச் செல்கிறது. வரம்பை மாற்ற ஒரு எண்ணைச் சேர்க்கவும், `omarchy agent account mode auto 90` இல் உள்ளது போல. ஒவ்வொரு கணக்கும் வரம்புக்கு மேல் இருந்தால், எந்தக் கணக்கு முதலில் விடுபடுகிறது என்பதுடன், அதைப் பற்றி ஒரு முறை கேட்பீர்கள். ஒரு செயலில் உள்ள கணக்கு அதன் வரம்பிலிருந்து 15 புள்ளிகளுக்குள் இருக்கும்போது (இயல்புநிலையில் 80%), அதன் வரம்புகள் ஒவ்வொரு 15 நிமிடங்களுக்கும் பதிலாக ஒவ்வொரு மூன்று நிமிடங்களுக்கும் சரிபார்க்கப்படுகின்றன.

`omarchy agent account list` ஒவ்வொரு கணக்கையும் அதன் சமீபத்திய வரம்புகளையும் காட்டுகிறது, `omarchy agent account remove work` ஒன்றை மறக்கிறது, மேலும் `omarchy agent account rename primary Hey` ஒன்றிற்குப் பெயர் மாற்றுகிறது (அல்லது panel-இல் ஒரு கணக்கின் பெயரைக் click செய்யவும்). இந்தக் கட்டளைகள் உங்கள் இயல்புநிலை ஏஜெண்டின் கணக்குகளில் வேலை செய்கின்றன; மற்ற வழங்குநரை அடைய, முதலில் அதைப் பெயரிடவும், `omarchy agent account use codex side` இல் உள்ளது போல. நீங்கள் ஏற்கனவே `~/.claude` அல்லது `~/.codex`-இல் வைத்திருந்த உள்நுழைவு _Main_ கணக்கு மற்றும் அது இருக்கும் இடத்திலேயே இருக்கிறது. சுமார் எட்டு மணி நேரத்திற்கும் மேலாகப் பயன்படுத்தப்படாமல் விடப்பட்ட ஒரு கணக்கு _Sign-in required_ எனக் காட்டக்கூடும்; panel-இலேயே அந்தக் கணக்கில் மீண்டும் உள்நுழைய அதைக் click செய்யவும், அல்லது அதில் ஒரு அமர்வைத் தொடங்கவும், இது உள்நுழைவைத் தானாகவே புதுப்பிக்கிறது. ஒரு கணக்கு சேர்க்கப்பட்டபோது நீங்கள் வைத்திருந்த MCP servers அதனுடன் வருகின்றன, ஆனால் நீங்கள் பின்னர் `claude mcp add` உடன் சேர்ப்பவை நீங்கள் அவற்றைச் சேர்த்த கணக்கை மட்டுமே அடைகின்றன. ஒரு CLI binary-க்கான முழுமையான பாதையுடன் உள்ளமைக்கப்பட்ட Claude Desktop மற்றும் கருவிகள் மாற்றத்தைப் பின்தொடர்வதில்லை. ஒரு வெளிப்படையான `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, அல்லது `GROK_HOME` தேர்ந்தெடுக்கப்பட்ட கணக்கை விட முன்னுரிமை பெறுகிறது.

### செயலிழப்பு கண்டறிதல்

Omarchy செயல்முறை செயலிழப்புகளுக்காக systemd-coredump-ஐக் கண்காணிக்கிறது. ஏதாவது segfault ஆகும்போது, உங்களுக்கு ஒரு "Process crashed" அறிவிப்பு கிடைக்கும் — அதைக் click செய்யவும், மேலும் செயலிழப்பு உங்கள் இயல்புநிலை ஏஜெண்டிடம் Omarchy-இன் diagnose-crash skill உடன் ஒப்படைக்கப்படுகிறது, இது core dump-இலிருந்து உண்மைகளை நிறுவுவதன் மூலமும் செயலிழப்பு upstream-இல் அறிவிக்கத் தகுதியானதா எனத் தீர்மானிப்பதன் மூலமும் ஏஜெண்டை வழிநடத்துகிறது. நீங்கள் அதை `coredumpctl list`-இலிருந்து எந்த PID-க்கு எதிராகவும் `omarchy agent crash <pid>` உடன் கையாலும் இயக்கலாம்.

கண்காணிப்பு இயல்பாகவே இயக்கத்தில் உள்ளது. அதை _Trigger > Toggle > Crash Capture_ என்பதன் கீழ் (அல்லது `omarchy toggle crash-capture` உடன்) முடக்கவும் மற்றும் அறிவிப்புகள் நின்றுவிடும்; `omarchy agent crash <pid>` இன்னும் கையால் வேலை செய்கிறது.

செயலிழப்புகளை ஒரு நேரத்தில் ஒரு நிரல் என்ற வகையிலும் அமைதிப்படுத்தலாம், இதைத்தான் கண்டறிதல் இறுதியில் உங்களுக்கு வழங்குகிறது. `omarchy crash mute hyprland` அந்த நிரலுக்கு மட்டும் அறிவிப்புகளை நிறுத்துகிறது, `omarchy crash mute hyprland off` அவற்றைத் திரும்பக் கொண்டு வருகிறது, மேலும் `omarchy crash mute` தனியாக நீங்கள் அமைதிப்படுத்தியதைப் பட்டியலிடுகிறது. இது binary-இன் பாதையை அதன் பெயரைப் போலவே மகிழ்ச்சியுடன் எடுக்கிறது, எனவே `omarchy crash mute /usr/bin/hyprland` அதையே செய்கிறது. இடைவெளி உள்ள ஒரு பெயரை மேற்கோள் காட்டவும், `omarchy crash mute 'Some App'` இல் உள்ளது போல. மற்ற அனைத்தும் இன்னும் அறிவிக்கின்றன, மேலும் அமைதிப்படுத்தப்பட்ட நிரல் இன்னும் செயலிழக்கிறது — இது நினைவூட்டலை மறைக்கிறது, இது எதையும் சரிசெய்வதில்லை.

### Desktop பயன்பாடுகள்

_Install > AI_ menu சில வரைகலை AI பயன்பாடுகளையும் கொண்டுள்ளது: ChatGPT desktop பயன்பாடு, Claude desktop பயன்பாடு (Anthropic-இன் Linux beta, Chat, Cowork, மற்றும் Claude Code tabs உடன்), xAI-இன் மாதிரிகளுடன் அரட்டை அடிக்க Grok Bot, Herdr Desktop, Hermes Desktop, OpenClaw, Perplexity desktop பயன்பாடு, மற்றும் T3 Code. Grok Bot என்பது desktop அரட்டை பயன்பாடு. குறியீட்டு ஏஜெண்ட் என்பது `grok` கட்டளை.

Hermes Desktop பற்றித்தான் தெரிந்து கொள்ள வேண்டும், ஏனெனில் ஒரு இயந்திரத்தில் ஒரு Hermes உள்ளது, மேலும் அது பயன்பாட்டினுடையது: Hermes எப்போதும் பயன்பாடு மூலமாக மட்டுமே நிறுவப்படுகிறது, மேலும் இயல்புநிலை ஏஜெண்ட் இயக்கும் `hermes` கட்டளை பயன்பாட்டினுடையது. Hermes-ஐ இயல்புநிலை ஏஜெண்டாகத் தேர்ந்தெடுப்பது _Install > AI_ நுழைவு செய்வதையே நிறுவுகிறது: தொகுப்பு, மற்றும் Hermes-இன் சொந்த நிறுவியால் அமைக்கப்பட்ட `~/.hermes` என்பதன் கீழ் ஒரு Hermes runtime, இது முதல் முறை சில நிமிடங்கள் எடுக்கும். அந்த runtime தான் terminal `hermes` கட்டளை, இயல்புநிலை ஏஜெண்ட் மற்றும் பயன்பாடு அனைத்தும் பயன்படுத்தும் ஒரே Hermes, மேலும் இது ஒரு Omarchy வெளியீட்டிற்காகக் காத்திருப்பதற்குப் பதிலாக `hermes update` உடன் தன்னைத்தானே புதுப்பிக்கிறது. அதை நிறுவுவது Hermes-இற்கு Omarchy theme-ஐ `omarchy` எனப் பெயரிடப்பட்ட ஒரு skin ஆகவும் வழங்குகிறது, நீங்கள் themes-ஐ மாற்றும்போது ஒவ்வொரு Hermes மேற்பரப்பும் அதைப் பின்தொடர்கிறது; நீங்கள் அது அப்படிச் செய்ய விரும்பவில்லை என்றால் Hermes-இன் Appearance அமைப்புகளின் கீழ் அல்லது `/skin` உடன் மற்றொன்றைத் தேர்ந்தெடுக்கவும், மேலும் Omarchy அந்தத் தேர்வை அப்படியே விட்டுவிடுகிறது. _Remove > AI_ என்பதன் கீழ் பயன்பாட்டை அகற்றுவது முதலில் Hermes-ஐ மூடுகிறது, gateway உட்பட, அந்த runtime-ஐ அதனுடன் எடுத்துச் செல்கிறது, மேலும் நீங்கள் வேறுவிதமாகக் கூறினால் தவிர உங்கள் அரட்டைகள், நினைவுகள், மற்றும் Hermes தனக்காக எழுதிய skills ஆகியவற்றை வைத்திருக்கிறது: அந்தத் தரவும் உங்கள் இணைப்பு அமைப்புகளும் கூடச் செல்ல வேண்டுமா என அது கேட்கிறது, இயல்புநிலை இல்லை என்பது.

OpenClaw-இன் desktop அனுபவம் அதன் Control UI ஆகும், இது அதன் சொந்த உள்ளூர் gateway-ஆல் ஆதரிக்கப்படும் ஒரு web பயன்பாடாகத் திறக்கிறது. OpenClaw `~/.openclaw`-இல் வாழ்கிறது மற்றும் தன்னைத்தானே புதுப்பிக்கிறது: Control UI-இன் "Update Gateway" பொத்தானைப் பயன்படுத்தவும் அல்லது `openclaw update` என்பதை இயக்கவும், மேலும் gateway புதிய பதிப்பில் மறுதொடக்கம் செய்கிறது. ஒரு புதிய நிறுவல் எந்த வெளியீட்டிலிருந்து தொடங்குகிறது என்பதை மட்டுமே Omarchy தேர்ந்தெடுக்கிறது. _Remove > AI_ என்பதன் கீழ் OpenClaw-ஐ அகற்றுவது gateway service-ஐயும் பயன்பாட்டையும் அதனுடன் எடுத்துச் சென்று பின்னர் `~/.openclaw` கூடச் செல்ல வேண்டுமா எனக் கேட்கிறது, ஏனெனில் அது OpenClaw-உடனும் அது பதிவிறக்கும் plugin runtimes உடனும் உங்கள் அரட்டைகளையும் சான்றுகளையும் வைத்திருக்கிறது; இயல்புநிலை அதை வைத்திருக்கிறது, மேலும் OpenClaw-ஐ மீண்டும் நிறுவுவது அதை மீண்டும் எடுத்துக்கொள்கிறது.

Herdr Desktop என்பது [Herdr](https://herdr.dev) desktop பயன்பாடு: நீங்கள் சாளரத்தை மூடும்போது அதன் core-இல் தொடர்ந்து இயங்கும் terminals மற்றும் குறியீட்டு ஏஜெண்டுகளின் spaces, tabs, மற்றும் panes. இது ஒரு தொகுப்பிலிருந்து அல்லாமல் Herdr-இன் சொந்த நிறுவியிலிருந்து வருகிறது, எனவே இது `~/.local/share/herdr-app`-இல் வாழ்கிறது, உங்களிடம் இன்னும் ஒன்று இல்லாதபோது அதன் core-ஐ `~/.local/bin/herdr-core`-இல் கொண்டு வருகிறது, மேலும் இரண்டையும் தன்னைத்தானே புதுப்பிக்கிறது. இது Omarchy `Super + Ctrl + Return`-இல் வழங்கும் `herdr` கட்டளையை மாற்றுவதற்குப் பதிலாக அதற்கு அருகில் அமர்ந்து, அந்தக் கட்டளையின் நேரடி விசைகளைப் பெறுகிறது: `Alt + Return` மற்றும் `Alt + Shift + Return` ஒரு pane-ஐக் கீழே அல்லது வலதே பிரிக்கின்றன, `Alt + Escape` அதை மூடுகிறது, `Ctrl + Alt + Arrow` panes-க்கிடையே நகர்கிறது, `Alt + 1..9` மற்றும் `Alt + Left/Right` ஒரு tab-ஐத் தேர்ந்தெடுக்கின்றன, மேலும் `Alt + Up/Down` spaces-க்கிடையே நகர்கின்றன. `Ctrl + 1..9` ஒரு space-ஐத் தேர்ந்தெடுக்கிறது மற்றும் `Alt + Shift + Up/Down` ஏஜெண்டுகள் வழியாகச் செல்கிறது. `Ctrl + Space` prefix விசைகள் terminal-மட்டுமாகவே இருக்கின்றன, ஏனெனில் பயன்பாடு ஒரு வரிசைக்கு ஒரு சாதாரண Ctrl விசையை வைத்திருக்க முடியாது. Omarchy இவற்றை `~/.config/herdr-app/keys.json`-இல் எழுதுகிறது, மேலும் `omarchy-refresh-herdr-app` அவற்றைத் திரும்ப வைக்கிறது. அதை நிறுவுவது Herdr-இன் Omarchy theme-ஐத் தேர்ந்தெடுக்கிறது, இது அப்போதிலிருந்து உங்கள் Omarchy theme-ஐப் பின்தொடர்கிறது. Herdr light mode-க்கு ஒரு theme-ஐயும் dark-க்கு ஒன்றையும் வைத்திருக்கிறது, எனவே ஒரு dark மற்றும் ஒரு light Omarchy theme-க்கிடையே மாறிய பிறகு, மற்ற mode-க்கு Herdr-இன் theme தேர்வியில் Omarchy-ஐ மீண்டும் ஒரு முறை தேர்ந்தெடுக்கவும்.

T3 Code ஒரு தொகுப்பிலிருந்து அல்லாமல் `~/.local/share/t3code`-இல் உள்ள அதன் அதிகாரப்பூர்வ AppImage வெளியீட்டிலிருந்து இயங்குகிறது, எனவே இது தன்னைத்தானே புதுப்பிக்கிறது. அதை நிறுவுவது Stable அல்லது Nightly channel-இல் தொடங்க வேண்டுமா எனக் கேட்கிறது; பின்னர் T3 Code-இன் அமைப்புகளில் மாற்றவும். உங்கள் threads மற்றும் அமைப்புகள் `~/.t3`-இல் வாழ்கின்றன, மேலும் _Remove > AI_ என்பதன் கீழ் T3 Code-ஐ அகற்றுவது அவற்றை அதனுடன் எடுத்துச் செல்கிறது.

### உள்ளூர் மாதிரிகள்

உங்கள் குறியீட்டு ஏஜெண்டுகளுக்காக உங்கள் சொந்த இயந்திரத்தில் ஒரு திறந்த மாதிரியை இயக்கவும். உங்கள் prompts மற்றும் குறியீடு இயந்திரத்திலேயே இருக்கும்; மாதிரிக்கு அனுப்பப்படும் எதுவும் அதை விட்டு வெளியேறாது. இதனுடன் தொடங்கவும்:

```bash
omarchy agent local use best
```

அல்லது, மேல் பட்டியில் உள்ள ஏஜெண்டுகள் panel-இல், + மற்றும் பின்னர் Local AI-ஐத் தேர்ந்தெடுக்கவும், இது ஒரு மாதிரி இந்த இயந்திரத்திற்குப் பொருந்தும்போது தோன்றும். முதல் முறை, இது மாதிரிகளை இயக்கும் Podman-ஐ நிறுவுகிறது, மேலும் ஒரு NVIDIA இயந்திரத்தில் NVIDIA-இன் container toolkit-ஐ நிறுவுகிறது, இது அவற்றுக்கு GPU-ஐ வழங்குகிறது. பின்னர் Omarchy இந்த இயந்திரத்திற்குப் பரிந்துரைக்கப்பட்ட மாதிரியைத் தேர்ந்தெடுத்து, அதைப் பதிவிறக்கி, தொடங்குகிறது. பல்லாயிரக்கணக்கான GB பதிவிறக்கத்தையும் மாதிரி இயங்கும்போது இயந்திரத்தின் நினைவகத்தின் பெரும்பகுதி பயன்பாட்டில் இருப்பதையும் எதிர்பார்க்கவும்: Flash Next அதன் முழு 256K context உடன் சுமார் 100 GiB பயன்படுத்துகிறது. மற்ற மாதிரிகள் அதற்குத் தேவையான நினைவகத்தை வைத்திருந்தால், அது நிறுத்தப்பட்ட நிலையில் அமைக்கப்படுகிறது, நீங்கள் ஒன்றை நிறுத்தியவுடன் தொடங்கத் தயாராக. மாதிரி logout-இல் நிற்கிறது; உங்களுக்கு வேறு எதற்காவது நினைவகம் தேவைப்படும்போது அதை நீங்களே நிறுத்தவும்.

`omarchy agent local list` விருப்பங்களைக் காட்டுகிறது மற்றும் சில ஏன் பொருந்தவில்லை என விளக்குகிறது. மற்றொன்றை அமைக்க, `omarchy agent local use <recipe>` என்பதை இயக்கவும். இன்று, `qwen3.8-flash-next-gufo` மற்றும் `qwen3.8-27b-gufo` 128 GB Strix Halo இயந்திரங்களுக்குக் கிடைக்கின்றன; 27B சுமார் 40 GiB எடுக்கிறது, எனவே இது மற்ற வேலைகளுக்கு இடம் விடுகிறது. புதிய recipes மற்றும் பரிந்துரைகள் தொகுப்பு மூலம் `omarchy update` உடன் வருகின்றன.

நீங்கள் அமைக்கும் ஒவ்வொரு மாதிரியும் ஏஜெண்டுகள் panel-இல், உங்கள் சந்தாக்களுக்கு அடுத்ததாக அதன் சொந்த வரியைப் பெறுகிறது: அதைத் தொடங்க play, அதை நிறுத்தி அதன் நினைவகத்தை விடுவிக்க pause, மற்றும் அதில் உங்கள் ஏஜெண்டைத் திறக்க terminal பொத்தான். அவை நினைவகத்தில் ஒன்றாகப் பொருந்தும்போது பல ஒரே நேரத்தில் இயங்க முடியும்; ஒன்று பொருந்தவில்லை என்றால், எந்த இயங்கும் மாதிரியை நிறுத்த வேண்டும் என Omarchy கூறுகிறது. அவற்றை மறுவரிசைப்படுத்த வரிகளை இழுக்கவும், மேலும் ஒரு மாதிரியையும் அதன் பதிவிறக்கத்தையும் அகற்ற தேர்ந்தெடுக்கப்பட்ட வரியில் Delete அழுத்தவும்.

கட்டளை வரியிலிருந்து, `omarchy agent local start <recipe>` மற்றும் `omarchy agent local stop <recipe>` அதையே செய்கின்றன, `omarchy agent local status` ஒவ்வொரு மாதிரியையும் காட்டுகிறது, மேலும் `omarchy agent --local` நீங்கள் கடைசியாகத் தொடங்கிய மாதிரியில் உங்கள் இயல்புநிலை ஏஜெண்டைத் திறக்கிறது. pi, OpenCode மற்றும் Qwen Code ஒன்றைப் பயன்படுத்த முடியும்; வேறு எந்த இயல்புநிலையுடனும் இது pi-இல் திறக்கிறது. pi நீங்கள் அமைத்த ஒவ்வொரு மாதிரியையும், மேலும் நீங்கள் இணைத்த இயந்திரங்களில் உள்ளவற்றையும், அதன் சொந்த மாதிரித் தேர்வியில் பட்டியலிடுகிறது, எனவே சாதாரண `pi` அவற்றையும் அடைய முடியும். எந்த OpenAI-இணக்கமான client-ம் இணைக்க முடியும்: `status` ஒவ்வொரு மாதிரியின் முகவரியையும் காட்டுகிறது (முதலாவது `http://127.0.0.1:11435/v1`), recipe பெயரே மாதிரி, மேலும் key `~/.config/omarchy/agent-local/key`-இல் உள்ளது.

`omarchy agent local remove <recipe>` ஒரு மாதிரியையும் வேறு எந்த மாதிரியும் பயன்படுத்தாத பதிவிறக்கங்களையும் நீக்குகிறது.

மூன்றாம் தரப்பு runtimes அவற்றின் வெளியீட்டாளருடன் குறிக்கப்படுகின்றன. Omarchy ஒவ்வொரு மாதிரியையும் network அணுகல் இல்லாமல் இயக்குகிறது.

### உள்ளூர் LLMs

Omarchy உள்ளூர் LLM மாதிரிகளை இயக்குவதற்கு இரண்டு வழிகளைப் பரிந்துரைக்கிறது: LM Studio மற்றும் Ollama. LM Studio திறந்த-எடை மாதிரிகளைக் கண்டறிவதற்கும், அவற்றை நிறுவுவதற்கும், அவற்றை இயக்குவதற்கும் ஒரு GUI இடைமுகத்தை வழங்குகிறது. இது எளிதாகத் தொடங்க ஒரு சிறந்த வழி. Ollama அதேபோல் செய்வதற்கு ஒரு CLI-ஐ வழங்குகிறது. ஆனால் நீங்கள் உள்ளூர் மாதிரிகளுக்குப் புதியவர் என்றால், நான் LM Studio உடன் தொடங்குவேன். நீங்கள் Omarchy Menu-இல் _Install > AI_ என்பதன் கீழ் இரண்டில் ஒன்றை நிறுவலாம்.

### Omarchy Skill

Agent skills, AI குறிப்பிட்ட கருவிகளை ஒரு குறிப்பிட்ட வழியில் பயன்படுத்த உதவுகின்றன, மேலும் Omarchy கணினியைத் தனிப்பயனாக்குவதற்கான ஒரு இயல்புநிலை skill உடன் வருகிறது. உங்கள் Hyprland config-ஐ மாற்றுவது, பட்டியைச் சரிசெய்வது, அல்லது புதிதாக ஒரு புதிய theme-ஐ உருவாக்குவது போல. இது Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` மற்றும் ஒவ்வொரு `~/.hermes/profiles/*/skills`), மற்றும் பொதுவான `~/.agents/skills` இருப்பிடத்திற்கான skill அடைவுகளில் symlink செய்யப்பட்டுள்ளது, எனவே பெரும்பாலான harness-கள் அதைத் தானாகவே எடுத்துக்கொள்கின்றன.

ஆனால் நீங்கள் இந்த skill-ஐ சோதனை முயற்சியாகக் கருத வேண்டும். வெவ்வேறு மாதிரிகள் அதை வெவ்வேறு விளைவுகளுக்குப் பயன்படுத்தும். முதலில் plan mode-இல் இயக்குவது சிறந்தது, எனவே ஏஜெண்ட் எதை மாற்ற விரும்புகிறது என்பது பற்றிய ஒரு யோசனை உங்களுக்கு இருக்கும். மேலும் ஏஜெண்ட் எல்லாவற்றையும் குழப்பிவிட்டால், மாற்றங்களைத் திரும்பப் பெற அல்லது `omarchy reinstall configs` என்பதைக் கூட அழைக்கத் தயாராக இருங்கள்.
