# உரை பிரித்தெடுத்தல் & டிக்டேஷன்

### உரை பிரித்தெடுத்தல்

உரை பிரித்தெடுப்பதற்காக திரையில் ஒரு பகுதியைத் தேர்ந்தெடுக்க `Super + Ctrl + PrtScr` ஐ அழுத்தவும். பின்னர் tesseract open source OCR மாதிரி அந்தத் தேர்வை விரைவாக உரையாக மாற்றி கிளிப்போர்டில் வைக்கும். பிறகு நீங்கள் `Super + V` ஐ அழுத்தி ஒட்டினால் போதும்.

பட அடிக்குறிப்புகளில் உள்ள முகவரிகளையோ அல்லது வலைத்தள தலைப்புகளில் பதிக்கப்பட்ட தொலைபேசி எண்களையோ எடுப்பதற்கு இது மிகவும் உதவியாக இருக்கும்.

### டிக்டேஷன்

புதிய நிறுவல்களில், [Superwhisper](https://superwhisper.com/) தான் இயல்புநிலை டிக்டேஷன் backend ஆகும், இது offline மாதிரி பதிவிறக்கங்கள் இல்லாமல் cloud செயலாக்கத்தைப் பயன்படுத்துகிறது. Omarchy மெனுவில் _Setup > Defaults > Dictation_ வழியாக Superwhisper அல்லது [Voxtype](https://voxtype.io/) ஐத் தேர்ந்தெடுக்கவும். ஒரு backend ஐத் தேர்ந்தெடுப்பது தேவைப்பட்டால் அதை நிறுவி, டிக்டேஷனுக்கான இயல்புநிலையாக அதை மாற்றும். Voxtype 150MB இடத்தை எடுக்கும் ஒரு base English மாதிரியை ஏற்றுகிறது; `voxtype setup model` மூலம் மாதிரியை மாற்றவும், மற்ற அமைப்புகளை `~/.config/voxtype/config.toml` வழியாக மாற்றவும். Superwhisper cloud அல்லது local செயலாக்கத்தைத் தேர்ந்தெடுக்க அதன் அமைப்புகளைத் திறக்கிறது, மேலும் OPR பயன்பாட்டைப் புதுப்பித்த நிலையில் வைத்திருக்கிறது.

நீங்கள் `Right Alt` ஐ அழுத்திப் பிடித்தோ அல்லது `Alt + Space` மூலம் மாற்றியோ டிக்டேட் செய்யலாம், டிக்டேட் செய்யப்பட்ட உரை கவனத்தில் உள்ள உள்ளீட்டுப் பகுதியில் தோன்றும். இந்தக் குறுக்குவழிகள் தேர்ந்தெடுக்கப்பட்ட backend ஐப் பயன்படுத்துகின்றன. Right Alt ஒரு modifier chord இல் பயன்படுத்தப்படும்போதும் டிக்டேஷனைத் தொடங்குகிறது; அந்த chord களுக்கு Left Alt ஐப் பயன்படுத்தவும். Right Alt என்பது AltGr ஆக இருக்கும் விசைப்பலகை தளவமைப்புகளில், தட்டச்சு செய்வதற்கு AltGr கிடைக்கும்படி வைக்க `Alt + Space` ஐப் பயன்படுத்தவும். Alt + Space இயல்புநிலையாக மாறுவதற்கு முந்தைய நிறுவல்கள் push-to-talk க்கு `F9` ஐயும், மாற்றுவதற்கு `Super + Ctrl + X` ஐயும் வைத்திருக்கின்றன, இவை `~/.config/hypr/bindings.lua` இல் சேர்க்கப்பட்டுள்ளன; அந்த விசைகளைப் பயன்பாடுகளுக்குத் திரும்பக் கொடுக்க அவற்றை அங்கிருந்து நீக்கவும்.

அதே குறுக்குவழிகள் இரண்டு backend களிலும் வேலை செய்யும். Setup > Defaults > Dictation வழியாக உங்கள் backend ஐத் தேர்ந்தெடுக்கவும். backend நிறுவி அதை உள்ளமைத்து தேர்வைச் சேமிக்கிறது. எது தேர்ந்தெடுக்கப்பட்டுள்ளது என்பதைப் பார்க்க `omarchy default dictation` ஐ இயக்கவும். தேர்வு `~/.config/omarchy/defaults/dictation` இல் சேமிக்கப்படுகிறது. புதிய நிறுவல்கள் Superwhisper ஐத் தானாகவே தேர்ந்தெடுக்கின்றன.

Omarchy தேர்ந்தெடுக்கப்பட்ட backend இன் desktop ஒருங்கிணைப்பைத் தானாகவே ஏற்றுகிறது. `~/.config/hypr/` இல் Superwhisper உள்ளமைவு எதுவும் தேவையில்லை.

தனிப்பயன் binding களும் script களும் `omarchy dictation start`, `omarchy dictation stop`, மற்றும் `omarchy dictation toggle` ஆகியவற்றைப் பயன்படுத்தலாம். தேர்ந்தெடுக்கப்பட்ட backend பதிவு செய்வதையும் படியெடுப்பதையும் கையாளுகிறது. Superwhisper ஐத் தேர்ந்தெடுப்பது அதன் native hold குறுக்குவழியை முடக்கி, அதன் native toggle ஐ `Ctrl + Alt + Space` என அமைக்கிறது, இதன் மூலம் அதை Omarchy இன் பதிவு விசைகளிலிருந்து தனியாக வைத்திருக்கிறது. Superwhisper க்குக் குறைந்தது ஒரு native பதிவு குறுக்குவழி தேவை, மேலும் அதன் ரத்து குறுக்குவழி தொடர்ந்து கிடைக்கும்.

கூடுதல் backend கள் Omarchy ஐ மாற்றாமலே ஒருங்கிணைய முடியும். PATH இல் `start`, `stop`, மற்றும் `toggle` ஆகியவற்றை ஏற்று உடனடியாகத் திரும்பும், தோல்வியில் nonzero நிலையைத் தரும் `omarchy-dictation-<backend>` என்ற பெயருடைய இயக்கக்கூடியதை வழங்கவும். அதன் நிறுவி provider ஐ உள்ளமைத்து, வெற்றிகரமான அமைப்பிற்குப் பிறகு `omarchy-dictation-use <backend>` ஐ அழைக்கிறது. இது முந்தைய backend ஐ நிறுத்தி தேர்வை atomically சேமிக்கிறது; provider செயலற்ற நிலையில் அல்லது கிடைக்காத நிலையில் இருக்கும்போது `stop` வெற்றி பெற வேண்டும். Backend பெயர்கள் சிறிய எழுத்துகள், இலக்கங்கள், மற்றும் hyphens ஐப் பயன்படுத்துகின்றன. அமைப்பிற்கு `omarchy-install-dictation-<backend>` ஐ வழங்கவும்; `omarchy default dictation <backend>` அதைத் தொடங்குகிறது. அந்தத் தேர்வியை அழைக்க Omarchy மெனு நீட்டிப்பு வழியாக ஒரு Defaults மெனு உள்ளீட்டைச் சேர்க்கவும். விருப்பமான desktop ஒருங்கிணைப்பு `${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua` இல் இருக்கலாம்.
