# உரை பிரித்தெடுத்தல் & பேச்சை எழுதுதல்

### உரை பிரித்தெடுத்தல்

உரையைப் பிரித்தெடுப்பதற்காகத் திரையில் ஒரு பகுதியைத் தேர்ந்தெடுக்க `Super + Ctrl + PrtScr` ஐ அழுத்தவும். பின்னர் tesseract open source OCR மாதிரி அந்தத் தேர்வை விரைவாக உரையாக மாற்றி கிளிப்போர்டில் வைக்கும். பின்னர் நீங்கள் `Super + V` ஐ அழுத்தினால் போதும், ஒட்டிவிடலாம்.

படங்களின் அடிக்குறிப்புகளில் உள்ள முகவரிகளையோ அல்லது வலைத்தளத் தலைப்புகளில் பதிக்கப்பட்ட தொலைபேசி எண்களையோ எடுப்பதற்கு இது மிகவும் உதவியாக இருக்கும்.

### பேச்சை எழுதுதல்

புதிய நிறுவல்களில், [Superwhisper](https://superwhisper.com/) தான் இயல்புநிலை பேச்சை எழுதும் பின்நிலை; ஆஃப்லைன் மாதிரி பதிவிறக்கங்கள் இல்லாமல் மேகச் செயலாக்கத்தை இது பயன்படுத்துகிறது. Omarchy மெனுவில் _அமைப்பு > இயல்புநிலைகள் > பேச்சை எழுதுதல்_ வழியாக Superwhisper, [Voxtype](https://voxtype.io/), அல்லது [Hex](https://anoma.ly/hex/) ஐத் தேர்ந்தெடுக்கவும். ஒரு பின்நிலையைத் தேர்ந்தெடுப்பது, தேவைப்பட்டால் அதை நிறுவி, பேச்சை எழுதுவதற்கான இயல்புநிலையாக அதை ஆக்குகிறது. Voxtype 150MB இடத்தை எடுக்கும் ஒரு அடிப்படை ஆங்கில மாதிரியை ஏற்றுகிறது; `voxtype setup model` மூலம் மாதிரியையும், `~/.config/voxtype/config.toml` வழியாக மற்ற அமைப்புகளையும் மாற்றவும். Superwhisper மேகச் செயலாக்கத்தையோ உள்ளூர் செயலாக்கத்தையோ தேர்ந்தெடுக்க அதன் அமைப்புகளைத் திறக்கிறது, மேலும் OPR பயன்பாட்டைப் புதுப்பித்த நிலையில் வைத்திருக்கிறது. Hex அமைப்பின்போது அதன் சாதனத்திலேயே இயங்கும் பேச்சு மாதிரியைப் பதிவிறக்கி, `hex.service` பயனர் சேவையாக இயங்குகிறது; மாதிரியையும் மற்ற அமைப்புகளையும் மாற்ற, பட்டியின் தட்டு சின்னத்திலிருந்து அதன் சாளரத்தைத் திறக்கவும் அல்லது `hex` ஐ இயக்கவும்.

`Right Alt` ஐ அழுத்திப் பிடித்தோ, அல்லது `Alt + Space` மூலம் மாற்றியோ நீங்கள் பேச்சை எழுதலாம், நீங்கள் பேசிய உரை கவனம் பெற்ற உள்ளீட்டுப் பகுதியில் தோன்றும். இந்தக் குறுக்குவழிகள் தேர்ந்தெடுக்கப்பட்ட பின்நிலையைப் பயன்படுத்துகின்றன. ஒரு துணை விசைச் சேர்க்கையில் பயன்படுத்தும்போதும் Right Alt பேச்சை எழுதுவதைத் தொடங்குகிறது; அந்தச் சேர்க்கைகளுக்கு Left Alt ஐப் பயன்படுத்தவும். Right Alt என்பது AltGr ஆக இருக்கும் விசைப்பலகை அமைப்புகளில், தட்டச்சு செய்வதற்கு AltGr கிடைக்கும்படி வைக்க `Alt + Space` ஐப் பயன்படுத்தவும். Alt + Space இயல்புநிலையாக ஆவதற்கு முந்தைய நிறுவல்கள், அழுத்திப் பேசுவதற்கு `F9` ஐயும் மாற்றுவதற்கு `Super + Ctrl + X` ஐயும் வைத்திருக்கின்றன, இவை `~/.config/hypr/bindings.lua` இல் சேர்க்கப்பட்டுள்ளன; அங்கு அந்த `Super + Ctrl + X` முகவர்கள் பலகத்தின் இடத்தை எடுத்துக்கொள்கிறது; அந்த விசைகளைப் பயன்பாடுகளுக்கும் பலகத்திற்கும் திரும்பக் கொடுக்க அவற்றை அங்கே நீக்கவும்.

அதே குறுக்குவழிகள் ஒவ்வொரு பின்நிலையுடனும் செயல்படும். அமைப்பு > இயல்புநிலைகள் > பேச்சை எழுதுதல் வழியாக உங்கள் பின்நிலையைத் தேர்ந்தெடுக்கவும். பின்நிலை நிறுவி அதை உள்ளமைத்துத் தேர்வைச் சேமிக்கிறது. எது தேர்ந்தெடுக்கப்பட்டுள்ளது என்பதைப் பார்க்க `omarchy default dictation` ஐ இயக்கவும். தேர்வு `~/.config/omarchy/defaults/dictation` இல் சேமிக்கப்படுகிறது. புதிய நிறுவல்கள் Superwhisper ஐத் தானாகவே தேர்ந்தெடுக்கின்றன.

தேர்ந்தெடுக்கப்பட்ட பின்நிலையின் டெஸ்க்டாப் ஒருங்கிணைப்பை Omarchy தானாகவே ஏற்றுகிறது. `~/.config/hypr/` இல் Superwhisper உள்ளமைவு எதுவும் தேவையில்லை.

தனிப்பயன் பிணைப்புகளும் ஸ்கிரிப்டுகளும் `omarchy dictation start`, `omarchy dictation stop`, மற்றும் `omarchy dictation toggle` ஐப் பயன்படுத்தலாம். பதிவு செய்வதையும் படியெடுப்பதையும் தேர்ந்தெடுக்கப்பட்ட பின்நிலை கையாள்கிறது. Superwhisper ஐத் தேர்ந்தெடுப்பது அதன் சொந்த அழுத்திப் பிடிக்கும் குறுக்குவழியை முடக்கி, அதன் சொந்த மாற்று விசையை `Ctrl + Alt + Space` என அமைக்கிறது, இதனால் அது Omarchy இன் பதிவு விசைகளிலிருந்து தனியாக இருக்கிறது. Superwhisper க்குக் குறைந்தது ஒரு சொந்த பதிவுக் குறுக்குவழி தேவை, மேலும் அதன் ரத்து செய்யும் குறுக்குவழி தொடர்ந்து கிடைக்கும்.

Omarchy ஐ மாற்றாமலேயே கூடுதல் பின்நிலைகள் ஒருங்கிணையலாம். PATH இல் `omarchy-dictation-<backend>` என்ற பெயரில், `start`, `stop`, மற்றும் `toggle` ஐ ஏற்று உடனடியாகத் திரும்பும், தோல்வியில் பூஜ்ஜியமற்ற நிலையைத் தரும் ஒரு இயக்கக்கூடியதை வழங்கவும். அதன் நிறுவி வழங்குநரை உள்ளமைத்து, வெற்றிகரமான அமைப்பிற்குப் பிறகு `omarchy-dictation-use <backend>` ஐ அழைக்கிறது. இது முந்தைய பின்நிலையை நிறுத்தித் தேர்வை அணு முறையில் சேமிக்கிறது; வழங்குநர் செயலற்று இருக்கும்போதோ கிடைக்காதபோதோ `stop` வெற்றிபெற வேண்டும். பின்நிலைப் பெயர்கள் சிற்றெழுத்துகள், இலக்கங்கள் மற்றும் இணைப்புக்குறிகளைப் பயன்படுத்துகின்றன. அமைப்பிற்கு `omarchy-install-dictation-<backend>` ஐ வழங்கவும்; `omarchy default dictation <backend>` அதைத் தொடங்குகிறது. அந்தத் தேர்வியை அழைக்க Omarchy மெனு நீட்டிப்பு வழியாக இயல்புநிலைகள் மெனு உள்ளீட்டைச் சேர்க்கவும். விருப்ப டெஸ்க்டாப் ஒருங்கிணைப்பு `${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua` இல் இருக்கலாம்.
