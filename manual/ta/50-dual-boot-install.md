# இரட்டை துவக்க நிறுவல்

Windows அல்லது பிற நிறுவல்களுடன் சேர்ந்து ஒரே ஒரு பார்ட்டிஷனில் Omarchy-ஐ நீங்கள் நிறுவ முடியும்.

இந்த நிறுவல் முறையிலும் இயல்பாகவே அந்த பார்ட்டிஷனுக்கு LUKS குறியாக்கம் கிடைக்கும், எனவே இது முழு டிரைவ் நிறுவலிலிருந்து உண்மையில் வேறுபட்டதல்ல; டிஸ்க்கில் காலி இடம் இருந்தால் போதும்.

## Windows-இல் இடம் உருவாக்குதல்

Windows-உடன் சேர்ந்து நிறுவ, ஸ்டார்ட் மெனுவில் `disk management` என்று தட்டச்சு செய்து, **Create and format hard disk partitions** என்ற விருப்பத்தைத் தேர்ந்தெடுக்கவும்.

 ![dual-boot-1](images/dual-boot-1.webp)

பொருத்தமான பார்ட்டிஷனைக் கண்டறிந்து, வலது கிளிக் செய்து, **Shrink Volume** என்பதைத் தேர்ந்தெடுக்கவும்.

![dual-boot-2](images/dual-boot-2.webp)

 நீங்கள் குறைக்க விரும்பும் அளவை உள்ளிடவும். இதுவே பூட் பார்ட்டிஷன் உட்பட உங்கள் எதிர்கால Omarchy நிறுவலின் அளவாக இருக்கும் என்பதைக் கவனத்தில் கொள்ளவும்.

 ![dual-boot-3](images/dual-boot-3.webp)

முடித்ததும், இதைப் போன்ற ஒன்றை நீங்கள் காண வேண்டும்; இந்த எடுத்துக்காட்டில் 50GB பகுதியில்தான் நாம் Omarchy-ஐ நிறுவப் போகிறோம்.

 ![dual-boot-4](images/dual-boot-4.webp)

## Omarchy-ஐ நிறுவுதல்

Omarchy-க்கான நிறுவல் செயல்முறை உண்மையில் வழக்கமானதைப் போன்றதே. உங்கள் டிஸ்க்கைத் தேர்ந்தெடுத்த பிறகு, **Free space install** என்ற விருப்பம் உங்களுக்கு வழங்கப்படும். முழு டிஸ்க்கையும் அழித்துவிடாமல் தடுக்க அந்த விருப்பத்தைத் தேர்ந்தெடுக்கவும்.

 ![dual-boot-5](images/dual-boot-5.webp)

எல்லாம் சரியாக இருக்கிறதா என்பதை உறுதிசெய்து, வழக்கம்போல் நிறுவல் முடியும் வரை காத்திருக்கவும். முழு டிரைவ் நிறுவலில் செய்வதைப் போலவே, குறியாக்கம் இல்லாமல் நிறுவவும் (பரிந்துரைக்கப்படவில்லை) நீங்கள் தேர்ந்தெடுக்கக்கூடிய இடமும் இதுவே.
 ![dual-boot-6](images/dual-boot-6.webp)

## பிற நிறுவல்களை Bootloader-இல் சேர்த்தல்

உங்கள் Omarchy நிறுவலை முடித்ததும், Limine bootloader இப்போது இயல்புநிலையாக இருப்பதை நீங்கள் கவனிப்பீர்கள். இதன் மூலம், Windows போன்ற உங்கள் பிற நிறுவல்களுக்கான விருப்பங்களையும் Limine-இல் சேர்க்க முடியும்.

பிற இயக்க முறைமைகளைச் சேர்க்க, `limine-scan` ஐ இயக்கி, நீங்கள் விரும்பும் பதிவுகளை உங்கள் Limine config-இல் சேர்க்க வழிமுறைகளைப் பின்பற்றவும். பூட் மெனு இயல்பாகவே மறைந்திருக்கும், ஒரு வினாடிக்குப் பிறகு Omarchy தொடங்கும். Windows அல்லது மற்றொரு பதிவைத் தேர்ந்தெடுக்க, Limine தொடங்கியவுடன் ஏதேனும் ஒரு விசையை அழுத்தவும்; மெனு தோன்றியதும், அம்புக்குறி விசைகளைப் பயன்படுத்தி ஒரு பதிவைத் தேர்ந்தெடுத்து Enter ஐ அழுத்தவும். நீங்கள் ஒரு விசையை அழுத்துவதற்கு முன்பே Omarchy தொடங்கிவிட்டால், மறுதொடக்கம் செய்து மீண்டும் முயற்சிக்கவும்.

## Bitlocker

இந்த நிறுவல் முறை Bitlocker-உடன் இணக்கமானது அல்ல என்பதைக் கவனத்தில் கொள்வது முக்கியம், ஏனெனில் அது பார்ட்டிஷனை மட்டுமல்ல, முழு டிரைவையும் குறியாக்கம் செய்யும். Bitlocker இயக்கப்பட்டுள்ளது என்று கூறும் பிழையை நீங்கள் எதிர்கொண்டால், Windows-இல் துவங்கி, **Settings -> Privacy & Security -> Device encryption** என்பதற்குச் சென்று Bitlocker-ஐ அணைக்கவும். டிரைவின் குறியாக்கத்தை நீக்க சிறிது நேரம் ஆகலாம்.
