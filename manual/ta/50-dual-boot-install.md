# இரட்டை துவக்க நிறுவல்

Windows அல்லது பிற நிறுவல்களுடன் அருகருகே ஒரே பகிர்வில் Omarchy-ஐ நிறுவ முடியும்.

இந்த நிறுவல் முறையிலும் இயல்புநிலையாக அந்தப் பகிர்வுக்கு LUKS குறியாக்கம் கிடைக்கும், எனவே இது நடைமுறையில் முழு இயக்கக நிறுவலிலிருந்து வேறுபட்டதல்ல; வட்டில் காலி இடம் இருந்தால் போதும்.

## Windows-இல் இடம் உருவாக்குதல்

Windows-உடன் அருகருகே நிறுவ, start menu-வில் `disk management` என்று தட்டச்சு செய்து **Create and format hard disk partitions** என்ற விருப்பத்தைத் தேர்ந்தெடுக்கவும்.

 ![dual-boot-1](images/dual-boot-1.webp)

பொருத்தமான பகிர்வைக் கண்டறிந்து, அதன் மீது வலது கிளிக் செய்து **Shrink Volume** என்பதைத் தேர்ந்தெடுக்கவும்.

![dual-boot-2](images/dual-boot-2.webp)

 தொகுதியை எந்த அளவுக்குச் சுருக்க விரும்புகிறீர்கள் என்பதை உள்ளிடவும். boot பகிர்வு உட்பட, இதுவே உங்கள் எதிர்கால Omarchy நிறுவலின் அளவாக இருக்கும் என்பதைக் கவனத்தில் கொள்ளவும்.

 ![dual-boot-3](images/dual-boot-3.webp)

முடித்த பிறகு, இது போன்ற ஒன்றை நீங்கள் காண வேண்டும்; இந்த எடுத்துக்காட்டில் 50GB பகுதியில்தான் நாம் Omarchy-ஐ நிறுவப் போகிறோம்.

 ![dual-boot-4](images/dual-boot-4.webp)

## Omarchy-ஐ நிறுவுதல்

Omarchy நிறுவல் செயல்முறை நடைமுறையில் வழக்கமானதைப் போன்றதே. உங்கள் வட்டைத் தேர்ந்தெடுத்த பிறகு, **Free space install** என்ற விருப்பம் உங்களுக்குக் கிடைக்கும். முழு வட்டையும் அழித்துவிடாமல் தடுக்க அந்த விருப்பத்தைத் தேர்ந்தெடுக்கவும்.

 ![dual-boot-5](images/dual-boot-5.webp)

எல்லாம் சரியாக இருக்கிறது என்பதை உறுதிப்படுத்திவிட்டு, வழக்கம் போல நிறுவல் முடியும் வரை காத்திருக்கவும். முழு இயக்கக நிறுவலைப் போலவே, குறியாக்கம் இல்லாமல் நிறுவுவதை (பரிந்துரைக்கப்படவில்லை) தேர்ந்தெடுக்க முடியும் இடமும் இதுதான்.
 ![dual-boot-6](images/dual-boot-6.webp)

## பிற நிறுவல்களை Bootloader-இல் சேர்த்தல்

உங்கள் Omarchy நிறுவலை முடித்ததும், இப்போது Limine bootloader-தான் இயல்புநிலை என்பதை நீங்கள் கவனிப்பீர்கள். இதைக் கொண்டு, Windows போன்ற உங்கள் பிற நிறுவல்களுக்கான விருப்பங்களையும் Limine-இல் சேர்க்க முடியும்.

பிற இயக்க முறைமைகளைச் சேர்க்க, `limine-scan` என்பதை இயக்கி, நீங்கள் விரும்பும் பதிவுகளை உங்கள் Limine config-இல் சேர்க்க வழிமுறைகளைப் பின்பற்றவும். boot menu இயல்புநிலையாக மறைந்தே இருக்கும், ஒரு வினாடிக்குப் பிறகு Omarchy தொடங்கும். Windows அல்லது வேறொரு பதிவைத் தேர்ந்தெடுக்க, Limine தொடங்கிய உடனே எந்த விசையையாவது அழுத்தவும்; menu தோன்றியதும், அம்புக்குறி விசைகளைப் பயன்படுத்தி ஒரு பதிவைத் தேர்ந்தெடுத்து Enter அழுத்தவும். நீங்கள் ஒரு விசையை அழுத்துவதற்கு முன்பே Omarchy தொடங்கிவிட்டால், மறுதொடக்கம் செய்து மீண்டும் முயற்சிக்கவும்.

## Bitlocker

இந்த நிறுவல் முறை Bitlocker-உடன் பொருந்தாது என்பதைக் கவனத்தில் கொள்வது முக்கியம், ஏனெனில் அது பகிர்வை மட்டுமல்ல, முழு இயக்ககத்தையும் குறியாக்கம் செய்கிறது. Bitlocker இயக்கப்பட்டுள்ளது என்று கூறும் பிழையை நீங்கள் எதிர்கொண்டால், Windows-இற்குச் சென்று, **Settings -> Privacy & Security -> Device encryption** என்பதற்குச் சென்று Bitlocker-ஐ அணைக்கவும். இயக்ககத்தின் குறியாக்கத்தை நீக்க சிறிது நேரம் ஆகலாம்.

 ![dual-boot-7](images/dual-boot-7.webp)

## Windows-ஐ மீண்டும் நிறுவுதல்

இந்தக் கணினி Windows-உடன் வந்திருந்தால், அதன் product key firmware-இல் சேமிக்கப்பட்டிருக்கும். அதை அச்சிட `omarchy windows key` என்பதை இயக்கவும், இதன் மூலம் இந்தக் கணினியில் Windows-ஐ எப்போதாவது மீண்டும் நிறுவினால் அதை மீண்டும் செயல்படுத்த முடியும்.
