# இரட்டை துவக்க நிறுவல்

Windows அல்லது பிற நிறுவல்களுடன் சேர்த்து ஒற்றைப் பகிர்வில் Omarchy-ஐ நிறுவலாம்.

இந்த நிறுவல் முறை இயல்பாகவே பகிர்வுக்கு LUKS குறியாக்கத்துடனும் வருகிறது, எனவே இது உண்மையில் முழு இயக்ககத்திலிருந்து வேறுபட்டதல்ல, வட்டில் இலவச இடம் கிடைக்க வேண்டும் என்பது மட்டுமே.

## Windows-இல் இடம் உருவாக்குதல்

Windows-உடன் சேர்த்து நிறுவ, தொடக்க மெனுவில் `disk management` என்று தட்டச்சு செய்து **Create and format hard disk partitions** என்ற விருப்பத்தைத் தேர்ந்தெடுங்கள்.

 ![dual-boot-1](images/dual-boot-1.webp)

பொருத்தமான பகிர்வைக் கண்டுபிடித்து, வலது சொடுக்கு செய்து, **Shrink Volume** என்பதைத் தேர்ந்தெடுங்கள்.

![dual-boot-2](images/dual-boot-2.webp)

 தொகுதியை எவ்வளவு சுருக்க விரும்புகிறீர்கள் என்பதை உள்ளிடுங்கள். இது துவக்கப் பகிர்வு உட்பட உங்கள் எதிர்கால Omarchy நிறுவலின் அளவாக இருக்கும் என்பதை நினைவில் கொள்ளுங்கள்.

 ![dual-boot-3](images/dual-boot-3.webp)

முடித்தவுடன், இந்த எடுத்துக்காட்டில் Omarchy-ஐ நிறுவும் 50GB பிரிவு இருக்கும் இதைப் போன்ற ஒன்றைக் காண்பீர்கள்.

 ![dual-boot-4](images/dual-boot-4.webp)

## Omarchy-ஐ நிறுவுதல்

Omarchy-க்கான நிறுவல் செயல்முறை உண்மையில் வழக்கம் போலத்தான். உங்கள் வட்டைத் தேர்ந்தெடுத்த பிறகு, **Free space install** என்ற விருப்பம் தரப்படும். முழு வட்டையும் அழிப்பதைத் தவிர்க்க அந்த விருப்பத்தைத் தேர்ந்தெடுங்கள்.

 ![dual-boot-5](images/dual-boot-5.webp)

எல்லாம் நன்றாக இருக்கிறது என்பதை உறுதிப்படுத்தி, வழக்கம் போல நிறுவல் முடியும் வரை காத்திருங்கள். முழு-இயக்கக நிறுவலில் போலவே குறியாக்கம் இல்லாமல் நிறுவவும் (பரிந்துரைக்கப்படவில்லை) இங்கே தேர்ந்தெடுக்கலாம்.
 ![dual-boot-6](images/dual-boot-6.webp)

## துவக்க ஏற்றியில் பிற நிறுவல்களைச் சேர்த்தல்

உங்கள் Omarchy நிறுவலை முடிக்கும்போது, Limine துவக்க ஏற்றி இப்போது இயல்புநிலையாக இருப்பதைக் கவனிப்பீர்கள். இதைக் கொண்டு, Windows போன்ற உங்கள் பிற நிறுவல்களுக்கும் Limine-இல் விருப்பங்களைச் சேர்க்கலாம்.

அதைச் செய்ய, `limine-scan` என்பதை இயக்கி, உங்கள் limine உள்ளமைவில் நீங்கள் விரும்பும் உருப்படிகளைச் சேர்க்கத் தூண்டல்களைப் பின்பற்றுங்கள். பிறகு நீங்கள் துவக்கும்போது, Omarchy-க்கான உங்கள் வழக்கமான விருப்பங்களுடன், Windows Boot Manager அல்லது பிறவற்றையும் காண்பீர்கள்.

## Bitlocker

இந்த நிறுவல் முறை Bitlocker-உடன் இணக்கமாக இல்லை என்பதைக் கவனத்தில் கொள்ள வேண்டும், ஏனென்றால் அது பகிர்வை மட்டுமல்லாமல் முழு இயக்ககத்தையும் குறியாக்கம் செய்கிறது. Bitlocker இயக்கப்பட்டுள்ளது என்று கூறும் பிழையை எதிர்கொண்டால், Windows-க்குத் துவக்கி, **Settings -> Privacy & Security -> Device encryption** என்பதற்குச் சென்று Bitlocker-ஐ முடக்குங்கள். இயக்ககத்தைக் குறியாக்க நீக்கச் சிறிது நேரம் ஆகலாம்.
