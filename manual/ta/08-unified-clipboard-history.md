# ஒருங்கிணைந்த கிளிப்போர்டு & வரலாறு

வழக்கமாக Linux-இல், டெர்மினலில் நகலெடுத்து ஒட்டுவதற்கு `Ctrl + Shift + C/V`-ஐயும், மற்ற எல்லா இடங்களிலும் அதைச் செய்வதற்கு `Ctrl + C/V`-ஐயும் பயன்படுத்த வேண்டும். Linux-இலேயே பிறந்து வளர்ந்தவராக இல்லாத எவருக்கும் இதைப் பழகிக்கொள்வது கடினம்! நீங்கள் Mac-இலிருந்து வருபவராக இருந்தால், Super-இலிருந்து Ctrl-க்கு மாறுவதும் அப்படித்தான்.

Omarchy (கிட்டத்தட்ட) எல்லா இடங்களிலும் வேலை செய்யும் ஒருங்கிணைந்த கிளிப்போர்டு விசைச்சேர்க்கைகளைக் கொண்டு இந்த இரண்டு சிக்கல்களையும் சமாளிக்கிறது. அவை:

| விசைச்சேர்க்கை | கட்டளை |
| ------- | ----------- |
| Super + A | அனைத்தையும் தேர்ந்தெடு |
| Super + C | நகலெடு |
| Super + X | வெட்டு |
| Super + V | ஒட்டு |
| Super + Ctrl + V | கிளிப்போர்டு வரலாறு |

_குறிப்பு: பெரும்பாலான agent harnesses படங்களை ஒட்டுவதற்கு `Ctrl + V`-ஐயும், உரையை ஒட்டுவதற்கு `Super + V`-ஐயும் பயன்படுத்தும்._

கவனத்தில் உள்ள உரைப் புலத்தில் அல்லது `Ctrl + A`-ஐ ஆதரிக்கும் மற்றொரு செயலியில் உள்ள அனைத்தையும் நகலெடுக்க, `Super + A`-ஐயும், பின்னர் `Super + C`-ஐயும் பயன்படுத்தவும். டெர்மினலில், `Ctrl + A` அதன் உரையைத் தேர்ந்தெடுப்பதற்குப் பதிலாக கட்டளை வரியின் தொடக்கத்திற்கு நகர்த்தும்.

### கிளிப்போர்டு வரலாறு

கிளிப்போர்டு வரலாறு Omarchy shell-ஆல் வழங்கப்படுகிறது, இது உரை மற்றும் படங்கள் இரண்டிற்கும் வேலை செய்கிறது. `Super + Ctrl + V` கொண்டு அதைத் தூண்டி, Return கொண்டு உங்கள் உள்ளீட்டைத் தேர்ந்தெடுக்கவும்; அது நீங்கள் இருந்த செயலியிலேயே அதை நேரடியாக ஒட்டிவிடும். அதைக் கிளிப்போர்டுக்கு மட்டும் நகலெடுக்க `Shift + Return`-ஐயும், அதைத் திறக்க `Alt + Return`-ஐயும், வரலாற்றிலிருந்து அதை நீக்க `Delete`-ஐயும், முழு வரலாற்றையும் அழிக்க `Shift + Delete`-ஐயும் பயன்படுத்தவும்.
