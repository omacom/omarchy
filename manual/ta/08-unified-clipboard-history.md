# ஒருங்கிணைந்த கிளிப்போர்டு & வரலாறு

பொதுவாக Linux-இல், டெர்மினலில் நகலெடுத்து ஒட்ட `Ctrl + Shift + C/V` தேவைப்படுகிறது, மற்ற இடங்களில் அதைச் செய்ய `Ctrl + C/V` தேவைப்படுகிறது. Linux-இல் பிறந்து வளராத எவருக்கும் அதற்குப் பழகுவது கடினம்! Mac-இலிருந்து வருகிறீர்கள் என்றால் super-இலிருந்து ctrl-க்கு மாறுவதும் அப்படித்தான்.

(கிட்டத்தட்ட) எல்லா இடங்களிலும் வேலை செய்யும் ஒருங்கிணைந்த கிளிப்போர்டு ஹாட்கீகள் மூலம் Omarchy இரண்டு பிரச்சனைகளையும் தீர்க்கிறது. அவை:

| ஹாட்கீ | கட்டளை |
| ------- | ----------- |
| Super + C | நகலெடு |
| Super + X | வெட்டு |
| Super + V | ஒட்டு |
| Super + Ctrl + V | கிளிப்போர்டு வரலாறு |

_பெரும்பாலான Agent ஹார்னஸ்கள் படங்களை ஒட்ட `Ctrl + V` ஐப் பயன்படுத்தும், ஆனால் உரையை ஒட்ட `Super + V` ஐப் பயன்படுத்தும் என்பதைக் கவனியுங்கள்._

### கிளிப்போர்டு வரலாறு

கிளிப்போர்டு வரலாறு Omarchy ஷெல்லால் வழங்கப்படுகிறது மற்றும் உரை மற்றும் படங்கள் இரண்டிற்கும் வேலை செய்கிறது. `Super + Ctrl + V` மூலம் அதைத் தூண்டவும், return மூலம் உங்கள் பதிவைத் தேர்ந்தெடுக்கவும், பிறகு அது `Super + V` இல் ஒட்டத் தயாராக கிளிப்போர்டில் வைக்கப்படும்.
