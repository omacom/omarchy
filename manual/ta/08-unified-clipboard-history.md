# ஒருங்கிணைந்த கிளிப்போர்டு & வரலாறு

பொதுவாக Linux-இல், டெர்மினலில் நகலெடுத்து ஒட்டுவதற்கு `Ctrl + Shift + C/V` தேவை, மற்ற எல்லா இடங்களிலும் அதைச் செய்ய `Ctrl + C/V` தேவை. Linux-இலேயே பிறந்து வளராத எவருக்கும் இதைப் பழகிக் கொள்வது கடினம்! நீங்கள் Mac-இலிருந்து வருகிறீர்கள் என்றால், super-இலிருந்து ctrl-க்கு மாறுவதும் அப்படித்தான்.

Omarchy இந்த இரண்டு சிக்கல்களையும் (கிட்டத்தட்ட) எல்லா இடங்களிலும் வேலை செய்யும் ஒருங்கிணைந்த கிளிப்போர்டு குறுக்குவழி விசைகளைக் கொண்டு தீர்க்கிறது. அவை:

| Hotkey | கட்டளை |
| ------- | ----------- |
| Super + A | அனைத்தையும் தேர்ந்தெடு |
| Super + C | நகலெடு |
| Super + X | வெட்டு |
| Super + V | ஒட்டு |
| Super + Ctrl + V | கிளிப்போர்டு வரலாறு |

_பெரும்பாலான agent harnesses படங்களை ஒட்டுவதற்கு `Ctrl + V` ஐப் பயன்படுத்தும், ஆனால் உரையை ஒட்டுவதற்கு `Super + V` ஐப் பயன்படுத்தும் என்பதைக் கவனத்தில் கொள்ளவும்._

கவனம் செலுத்தப்பட்ட உரைப் புலத்தில் அல்லது `Ctrl + A` ஐ ஆதரிக்கும் வேறு பயன்பாட்டில் உள்ள அனைத்தையும் நகலெடுக்க `Super + A`, பின்னர் `Super + C` ஐப் பயன்படுத்தவும். டெர்மினலில், `Ctrl + A` உரையைத் தேர்ந்தெடுப்பதற்குப் பதிலாக கட்டளை வரியின் தொடக்கத்திற்கு நகர்த்தும்.

### கிளிப்போர்டு வரலாறு

கிளிப்போர்டு வரலாறு Omarchy shell ஆல் வழங்கப்படுகிறது, மேலும் உரை மற்றும் படங்கள் இரண்டிற்கும் வேலை செய்கிறது. நீங்கள் அதை `Super + Ctrl + V` மூலம் தூண்டி, return மூலம் உங்கள் உள்ளீட்டைத் தேர்ந்தெடுக்கிறீர்கள், பின்னர் அது `Super + V` இல் ஒட்டுவதற்குத் தயாராக கிளிப்போர்டில் வைக்கப்படும்.
