# Muistutukset

Omarchyssa on sisäänrakennettu tapa asettaa yksinkertaisia muistutuksia lähtölaskenta-ajastimen ja viestin avulla. Voit tehdä sen näppäinyhdistelmällä `Super + Ctrl + R`, nähdä kaikki asetetut yhdistelmällä `Super + Ctrl + Alt + R` ja tyhjentää kaikki yhdistelmällä `Super + Ctrl + Shift + R`. Kaikki on saatavilla myös kohdasta _Käynnistä > Muistutus_. Voit käyttää myös komentoriviä komennolla `omarchy reminder 7 'Tea ready'`.
