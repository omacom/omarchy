# الخطوط

يستخدم Omarchy خط JetBrainsMono Nerd Font كخط افتراضي لكلٍّ من الطرفية والنظام على حد سواء.

 ![fonts-jetbrainsmono](images/fonts-jetbrainsmono.webp)

يمكنك تغيير ذلك عبر قائمة _المظهر > الخط_ في قائمة Omarchy (`Super + Space`). وهذا يضبط الخط أحادي المسافة في كل مكان: الطرفية، والشريط، وأي شيء آخر يطلبه.

يمكنك تثبيت خطوط برمجة شائعة أخرى عبر _تثبيت > النمط > الخط_ في قائمة Omarchy: Cascadia Mono وMeslo LG Mono وFira Code وVictor Code وBitstream Vera Mono وIosevka، وجميعها على بُعد نقرة واحدة، بإصداراتها Nerd Font حتى تستمر الرموز الرسومية في الشريط والطرفية في العمل. بعد تثبيت أحدها، اختره ضمن _المظهر > الخط_.

## الصينية واليابانية والكورية

تتشارك الصينية واليابانية والكورية العديد من الأحرف لكنها ترسم بعضها بشكل مختلف، لذا يبدو الحرف نفسه صحيحًا لقارئ وغريبًا لقارئ آخر. اختيار إحدى هذه اللغات ضمن _الإعداد > اللغة_، أو طريقة الإدخال الخاصة بها، يضبط الأشكال المطابقة. لاختيارها بنفسك، شغّل `omarchy font cjk jp` أو `kr` أو `sc` أو `tc` (تايوان) أو `hk` (هونغ كونغ) في طرفية؛ ويعود `omarchy font cjk default` إلى اختيار النظام، وهو الأشكال اليابانية. يحتفظ النص الذي تُعلّمه صفحة ويب أو مستند بلغته الخاصة، وسطح المكتب بأكمله أثناء عمله بإحدى هذه اللغات، بأشكال تلك اللغة.
