# التعديلات الشائعة

هذه مجموعة من التعديلات الشائعة على إعداد Omarchy. اعلَمْ أنه قد يكون من الضروري أحيانًا أن تعيد تحديثات النظام تكوينات معينة إلى حالتها الأصلية. إذا حدث ذلك، فلن تُفقد تغييراتك، بل ستُوضع في ملف `.bak` في الدليل نفسه.

إذا أفسدت شيئًا، يمكنك استعادة التكوينات الفردية إلى إعدادها الأصلي عبر _تحديث > التكوين_ في قائمة Omarchy. وإذا أفسدت كل شيء _حقًا_، يمكنك إعادة تعيين جميع التكوينات عبر `omarchy-reinstall`.

### كشف جميع أيقونات الدرج طوال الوقت

افتراضيًا، تُخفى أيقونات الدرج، مثل Dropbox و1password وSteam، خلف سهم موسّع الدرج، الذي يكشفها عندما تحوم فوقه. إذا كنت ترغب في إبقائها مكشوفة طوال الوقت، فانقر بزر الماوس الأيمن على سهم الموسّع لفتح مدير أيقونات الدرج، ثم ثبّت الأيقونات التي تريد إبقاءها مرئية (يمكنك أيضًا إخفاء تلك التي لا تريد رؤيتها أبدًا).

### زوايا نوافذ مستديرة

التصميم الافتراضي لـ Omarchy هو تصميم الزوايا المربعة، ولكن إذا كنت ترغب في تلطيف ذلك قليلًا، يمكنك تغيير `~/.config/hypr/looknfeel.lua` حتى لا يعود التقريب معلّقًا:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### إزالة فواصل النوافذ

على شاشات الكمبيوتر المحمول، يفضّل بعض الأشخاص عدم إهدار أي بكسلات على فواصل النوافذ (أو حتى الشريط العلوي، الذي يمكنك إيقافه باستخدام `Super + Shift + Space`). يمكنك إيقاف جميع الفواصل والحدود باستخدام `Super + Shift + Backspace`، أو إزالتها نهائيًا بإزالة التعليقات في هذا القسم من `~/.config/hypr/looknfeel.lua`:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
