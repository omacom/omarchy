# القادم من Mac أو Windows

إذا قضيت سنوات على macOS أو Windows، فإن أصابعك تعرف مئة شيء نسي عقلك أنه تعلّمه يومًا. هذا الفصل هو طبقة الترجمة: أين تذهب تلك الغرائز في Omarchy. الميزات نفسها مشروحة بعمق في مواضع أخرى — هذه مجرد الخريطة.

### Super هو مركز كل شيء

كل الذاكرة العضلية التي بنيتها حول Cmd أو مفتاح Windows تنتقل إلى مفتاح واحد: Super. هذا هو مفتاح Windows على لوحة مفاتيح PC، وهو المرتكز لمعظم مفاتيح الاختصار في Omarchy تقريبًا.

يتحول منعكسك الخاص بـ Spotlight أو Raycast أو قائمة Start إلى `Super + Space`. هذا يفتح قائمة Omarchy، التي تُشغّل التطبيقات، وتغيّر الإعدادات، وتثبّت البرامج، وتلتقط الشاشة — كل شيء تقريبًا. ابدأ الكتابة للتصفية. يعرض `Super + Alt + Space` كل تطبيق على شبكة واحدة، بالطريقة نفسها التي يعمل بها Launchpad. راجع [التنقل](04-navigation.md).

### لا أيقونات على سطح المكتب، ولا يظهر الـ dock إلا عندما تعوّم

لا أيقونات لترتيبها على سطح المكتب، ولا dock على مساحة عمل مُرصّفة — لا يظهر الـ dock إلا على مساحة عمل عائمة (راجع [التنقل](04-navigation.md)). تبدأ التطبيقات من مفتاح اختصار (`Super + Return` للطرفية، و`Super + Shift + Return` للمتصفح، و`Super + K` لقائمة بكل ما هو مُعيّن) أو من القائمة. قطعة واجهة المستخدم الوحيدة الدائمة هي [الشريط العلوي](05-the-top-bar.md)، الذي يغطي ما كان شريط القوائم، وعلبة النظام، وNotification Center يفعله لك من قبل — وكل عنصر واجهة عليه تقريبًا يفعل شيئًا عند النقر الأيسر، والأيمن، والأوسط.

### النوافذ تضع نفسها بنفسها

أكبر تحول في طريقة التفكير: لا تسحب النوافذ هنا وهناك ولا تثبّتها على أنصاف الشاشة. افتح نافذة وستأخذ الشاشة كلها. افتح ثانية وستتقاسمانها. لا تنقّب أبدًا عن نافذة من تحت أخرى، لأن النوافذ لا تتراكب.

عندما تحتاج فعلًا إلى نافذة عائمة، فإن `Super + T` يُخرج النافذة النشطة من الترصيف (ويعيدها). لكن امنح الترصيف فرصة حقيقية أولًا — إنه قلب الأمر كله. يأخذك [التنقل](04-navigation.md) عبره خطوة بخطوة.

ستبدو مساحات العمل مألوفة: إنها Spaces في macOS أو أسطح المكتب الافتراضية في Windows، إلا أنك ستستخدمها فعلًا، لأن `Super + 1/2/3/4` يقفز مباشرة إلى واحدة منها و`Super + Shift + 1/2/3/4` يرسل النافذة النشطة إليها. لا تأخير في الحركة، مجرد قفزات فورية. هذا يعني أنك قد لا تحتاج حتى إلى شاشات متعددة، إذا كنت معتادًا على ذلك من قبل.

### النسخ واللصق يعملان ببساطة

على Mac كان لديك Cmd + C في كل مكان. على Windows كان لديك Ctrl + C في كل مكان — باستثناء الطرفية، حيث يقتل برنامجك. يمنحك Omarchy ‏`Super + C` و`Super + X` و`Super + V`، وهي تعمل في كل مكان، بما في ذلك الطرفية. لا منعكس منفصل لتعلّمه من أجل الصدفة.

أهل Windows: سجل الحافظة الخاص بكم Win + V يعيش على `Super + Ctrl + V`، وهو يحتفظ بالصور كما يحتفظ بالنص. راجع [الحافظة الموحدة والسجل](08-unified-clipboard-history.md).

| ما تمتد يدك إليه | في Omarchy |
| ------------- | ---------- |
| Spotlight / Raycast / قائمة Start | `Super + Space` — قائمة Omarchy |
| AirDrop | LocalSend، عبر `Super + Ctrl + S` — راجع [الواجهات الرسومية](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` أو `Print Screen` — راجع [لقطات الشاشة والتسجيل](12-screenshots-recording.md) |
| Notification Center | سجل الإشعارات على `Super + Shift + Alt + ,` |
| Time Machine (للنظام) | [لقطات نظام](47-system-snapshots.md) تلقائية مع كل تحديث |
| App Store / تنزيل مُثبّت | _Install_ في القائمة، أو `omarchy pkg add` — راجع [حزم أخرى](29-other-packages.md) |
| System Settings / Control Panel | _Setup_ في القائمة، الذي يحرّر ملفات إعداد نصية عادية — راجع [ملفات الإعداد](31-dotfiles.md) |
| Finder / File Explorer | Files، على `Super + Shift + F` — راجع [الواجهات الرسومية](22-guis.md) |
| Safari / Edge | Google Chrome على `Super + Shift + Return`؛ اختر آخر ضمن _Setup > Defaults > Browser_ — راجع [المتصفحات](23-browsers.md) |
| Preview / Photos | Omaview للصور والفيديو والموسيقى، وDocument Viewer لملفات PDF — راجع [الواجهات الرسومية](22-guis.md) |
| TextEdit / Notepad | Plain، على `Super + Shift + N`؛ اختر آخر ضمن _Setup > Defaults > Editor_ |

### بعض الأشياء مختلفة حقًا

تعيش كثير من الإعدادات في ملفات نصية تحرّرها، لا في لوحات تنقر عبرها. يبدو ذلك بدائيًا حتى تدرك أنه يعني أن كل تعديل يمكن رؤيته، ونسخه إلى جهازك التالي، ووضعه تحت التحكم في الإصدارات. تُسقطك قائمة _Setup_ مباشرة في الملف الصحيح وتعيد تشغيل كل ما يحتاج إلى إعادة تشغيل عندما تنتهي.

تأتي التحديثات عبر أمر واحد — _Update > Omarchy_ — يحدّث Omarchy نفسه وكل حزمة على النظام، ويأخذ لقطة أولًا. لا مُحدّثات لكل تطبيق تزعجك عشوائيًا. راجع [التحديثات](30-updates.md).

تأتي البرامج من مدير حزم، لا من مُثبّتات مُنزّلة.

وعندما تغلق نافذة، يخرج التطبيق فعلًا. لا يوجد ذلك الليمبو الخاص بـ macOS حيث يستمر البرنامج في العمل بلا نوافذ. ‏`Super + W` — أو `Super + Q`، إذا كانت تلك هي ذاكرة الأصابع التي أتيت بها — يعني أنه ذهب.

### على أجهزة Mac

يعمل Omarchy جيدًا على أجهزة Intel Macs، وعلى أجهزة M1 وM2 وM3 Macs مع Omarchy for Apple Silicon. راجع [دعم Mac](44-mac-support.md). ولوحة المفاتيح لطيفة معك: لا يعيد Omarchy تعيين أي شيء، ويعامل Linux مفتاح Command على أنه Super، لذا يجلس Super تمامًا حيث كان Cmd دائمًا. لن يلاحظ إبهامك الانتقال.

### امنحه أسبوعين

تنتقل الغرائز أسرع مما تظن. تصفّح فصل [مفاتيح الاختصار](07-hotkeys.md) مرة واحدة، وكلما فرغ ذهنك من ربط ما، اضرب `Super + K` — فهو يعرضها كلها لك. هذا هو مفتاح الاختصار الوحيد الذي عليك حفظه فعلًا.
