# التذكيرات

لدى Omarchy طريقة مدمجة لتعيين تذكيرات بسيطة مبنية على عدّاد تنازلي ومع رسالة. يمكنك فعل ذلك عبر `Super + Ctrl + R`، ورؤية كل المعيّنة عبر `Super + Ctrl + Alt + R`، ومسح الكل عبر `Super + Ctrl + Shift + R`. كل شيء متاح أيضًا عبر _تشغيل > تذكير_. يمكنك أيضًا استخدام CLI بـ `omarchy reminder 7 'Tea ready'`.
