# دوال Shell

يأتي Omarchy مع مجموعة من دوال shell لتبسيط المهام الشائعة وتغليف استدعاءات المعاملات المعقدة.

## الضغط

- `compress [file/dir]`: إنشاء أرشيف tar.gz من الملف/المجلد.
- `decompress [file.tar.gz]`: فكّ ملف tar.gz.

## الأقراص

- `iso2sd [image.iso]`: إنشاء قرص قابل للإقلاع على بطاقة SD باستخدام ملف iso المشار إليه واختيار القرص تفاعليًا.
- `format-drive [device] [name]`: تهيئة قرص كامل بقسم exFAT واحد (وهو يعمل على Windows وmacOS أيضًا). شغّله دون وسائط لترى الأقراص المتاحة. كن حذرًا!

## تخطيطات التطوير

تخطيطات تطوير فورية متعددة الألواح لـ tmux:

- `tdl [ai]`: إنشاء تخطيط تطوير Tmux مع المحرر الخاص بك، ووكيل ذكاء اصطناعي، وterminal. استخدم الاختصارات الخاصة بالوكلاء، مثل `tdl c` لـ opencode أو `tdl cx` لـ Claude Code، أو مرر وكيلًا ثانيًا لتشغيل كليهما، مثل `tdl c cx`.
- `tds`: إنشاء مربع تطوير Tmux مع المحرر، ومراقبة diff (عبر `hunk diff --watch`)، وterminal، وopencode.
- `tdlm [ai]`: إنشاء نافذة `tdl` لكل مجلد فرعي في المجلد الحالي.
- `tsl [count] [command]`: إنشاء سرب من الألواح مبلّطة في شبكة، جميعها تشغّل الأمر نفسه (رائع لوكلاء الذكاء الاصطناعي).

تتوفر التخطيطات نفسها لـ Herdr على هيئة `hdl` و`hds` و`hdlm` و`hsl`.

## أشجار عمل Git

- `ga [branch]`: إنشاء شجرة عمل وفرع جديدين بجانب المستودع الحالي والقفز إليها.
- `gd`: إزالة شجرة العمل الحالية وفرعها (تطلب تأكيدًا أولاً).

## مراقبو Rsync

- `rsw [source] [destination]`: بدء مراقب في الخلفية يقوم بمزامنة المصدر إلى الوجهة عبر rsync كلما تغيّر شيء. يمكن أن تكون الوجهة مضيفًا بعيدًا، مثل `rsw ~/Work/app nyc-dev:Work/app`.
- `lsw`: سرد جميع المراقبين النشطين.
- `dsw`: إيقاف جميع المراقبين النشطين.

## إعادة توجيه منافذ SSH

مثالي للقيام بتطوير الويب بامتيازات السياق الآمن الخاص بـ localhost مقابل صندوق بعيد.

- `fip`: إعادة توجيه منفذ واحد أو أكثر من مضيف بعيد إلى localhost عبر SSH.
- `dip`: قطع اتصال منفذ واحد أو أكثر من المنافذ المُعاد توجيهها.
- `lip`: سرد جميع عمليات إعادة توجيه منافذ SSH النشطة.

لنفترض أنك بدأت خادم تطوير على المنفذ `3000` على آلة يمكن الوصول إليها باسم `nyc-dev`، ثم يمكنك تشغيل `fip nyc-dev 3000` لإعادة توجيه ذلك المنفذ، بحيث يصل `localhost:3000` فعليًا إلى `nyc-dev:3000`، ولكن دون الحاجة إلى شهادات SSL لإنشاء السياق الآمن اللازم لاختبار web sockets أو ما شابه.

## إعادة اتصال SSH

`ssh` نفسه ملفوف في دالة تنظّف terminal إذا مات اتصال بينما كانت tmux بعيدة أو Herdr أو محرر قد استولت عليه، ثم تعيد الاتصال تلقائيًا عندما تنقطع جلسة تفاعلية (يُوقف Ctrl-C حلقة إعادة المحاولة).
