# لوحة المفاتيح والفأرة ولوحة اللمس

يتيح لك Hyprland ضبط جميع أجهزتك للإدخال بتفصيل كبير. يمكنك جعل تكرار لوحة المفاتيح سريعًا بشكل خيالي أو جعل لوحة اللمس تستخدم التمرير الطبيعي. تغيّر كل ذلك في `~/.config/hypr/input.lua`، والذي يمكنك الوصول إليه أيضًا عبر _الإعداد > الإدخال_ في قائمة Omarchy ‏(`Super + Space`). أي شيء تحدده هناك يحل محل إعدادات Omarchy الافتراضية.

إليك مثالًا:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

يمكنك [الاطّلاع على جميع خيارات الإدخال](https://wiki.hypr.land/Configuring/Basics/Variables/#input) على ويكي Hyprland الخاص بالإدخال.

يعمل CapsLock كمفتاح Caps Lock عادي، ويُعدّ `Shift + CapsLock` مفتاح الإنشاء الخاص بـ[الرموز التعبيرية السريعة](07-hotkeys.md#quick-emojis) و[عمليات الإكمال الأخرى](07-hotkeys.md#quick-completions). إذا كنت تفضّل أن يكون مفتاح الإنشاء في مكان آخر، فاستبدل `omarchy:shift_caps_compose` في `kb_options`. على سبيل المثال، ينقل هذا مفتاح الإنشاء إلى Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### إيماءات لوحة اللمس

اسحب على لوحة اللمس للتنقل في سطح المكتب:

| الإيماءة | الإجراء |
| --- | --- |
| ثلاثة أصابع إلى اليسار / اليمين | مساحة العمل السابقة / التالية، بما في ذلك الفارغة منها |
| ثلاثة أصابع إلى الأعلى | تبديل وحدة تحكم الذكاء الاصطناعي |
| ثلاثة أصابع إلى الأسفل | فتح قائمة Omarchy |
| أربعة أصابع إلى اليسار / اليمين | نقل النافذة النشطة إلى مساحة العمل السابقة / التالية |
| أربعة أصابع إلى الأسفل | تبديل ملء الشاشة |

لتغيير إحداها، ألغِ تعيينها في `~/.config/hypr/input.lua` قبل إضافة [إيماءة لوحة اللمس](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/) الخاصة بك، لأن Hyprland لن يقبل إيماءتين بنفس الأصابع والاتجاه:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

لإيقاف جميع إيماءات Omarchy، عيّن `omarchy_default_gestures = false` بالقرب من أعلى `~/.config/hypr/hyprland.lua`، قبل تحميل إعدادات Omarchy الافتراضية.

على أجهزة Dell XPS المحمولة المزوّدة بلوحة لمس لمسية، يمكنك أيضًا تعيين قوة النقر إلى منخفضة أو متوسطة أو عالية ضمن _المشغّل > الأجهزة > ردود فعل لوحة اللمس اللمسية_.

### الكتابة بالصينية واليابانية ولغات أخرى

اختر اليابانية أو الكورية أو الصينية (المبسطة، Pinyin) أو تايوان (Zhuyin) أو هونغ كونغ (Cangjie) عندما يطلب منك المثبّت اختيار لوحة المفاتيح. يضبط Omarchy لوحة المفاتيح ومحرك الإدخال المطابق تلقائيًا، بما في ذلك أثناء إعداد الإقلاع الأول دون اتصال. تستخدم اليابانية Mozc، وتستخدم الكورية Hangul القياسي بصفّين، وتستخدم الصينية المبسطة Pinyin، وتستخدم تايوان ترتيب Zhuyin القياسي من Chewing، وتستخدم هونغ كونغ Cangjie بأشكال أحرف هونغ كونغ. توفر اليابانية (لوحة مفاتيح أمريكية) Mozc مع تخطيط لوحة مفاتيح أمريكي. تبقى مفاتيح Hangul وZhuyin وCangjie في مواضعها القياسية حتى عندما تكتب أحرفًا لاتينية باستخدام Dvorak أو Colemak أو AZERTY. إذا كنت قد أضفت Hangul أو Chewing قبل هذا، فقم بإلغاء تحديده ثم أعد تحديده ضمن _الإعداد > الكتابة > طرق الإدخال_ لنقل مفاتيحه إلى هناك؛ يترك Omarchy أي محرك تكتب به بالفعل وشأنه.

تبدأ الكتابة في الوضع اللاتيني. اضغط `Super + I` للتنقل بين طرق الإدخال المهيأة، و`Super + Shift + I` للتنقل بالعكس. اضغط `Shift` بمفرده للخروج من طريقة إدخال مثل Pinyin إلى الأحرف اللاتينية، واضغطه مرة أخرى للعودة، بالطريقة التي تعمل بها Sogou وMicrosoft Pinyin وmacOS؛ لا يزال `Shift` مع حرف يكتب حرفًا كبيرًا. على لوحات المفاتيح اليابانية، يبدّل 全角/半角 الإدخال، ويشغّله 変換، ويوقفه 無変換. مع الكورية، يبدّل 한/영 Hangul ويحوّل 한자 إلى Hanja، سواء كانت لوحة مفاتيحك تحتوي على مفاتيح مخصصة أو ترسل Right Alt وRight Ctrl لهما، كما تفعل العديد من أجهزة الكمبيوتر المحمولة، لذا لا يُعدّ Right Alt وRight Ctrl معدّلين عاديين هناك؛ يبدّل الإملاء باستخدام Alt + Space بدلًا من ذلك. يبقى `Ctrl + Space` متاحًا لـ Tmux وHerdr؛ ويبقى `Shift + CapsLock` مفتاح الإنشاء.

يظهر مؤشر لوحة المفاتيح على يمين الشريط عندما يكون لديك تخطيطات لوحة مفاتيح أو طرق إدخال متعددة. انقر عليه لتبديل لغات الإدخال؛ تعرض اليابانية あ لـ hiragana. لخيارات الأحرف اليابانية، بدّل إلى اليابانية، واكتب كلمة مثل `nihongo`، ثم اضغط Space مرتين. اضغط Enter لقبول اختيارك. إذا كان لديك أيضًا تخطيطات لوحة مفاتيح متعددة، فانقر بزر الفأرة الأيمن على المؤشر للتنقل بينها.

استخدم _الإعداد > الكتابة > تخطيطات لوحة المفاتيح_ لتحديد تخطيطات مثل الإنجليزية والفرنسية، من نفس الخيارات المعروضة أثناء التثبيت. استخدم _الإعداد > الكتابة > طرق الإدخال_ لتحديد محركات التركيب النشطة. يفتح كلا المنتقين داخل قائمة Omarchy مع تحديد اختياراتك الحالية. انقر أو اضغط Enter لتبديل اختيار؛ يُطبّق كل تغيير فورًا. يؤدي إلغاء تحديد طريقة إدخال إلى إزالتها من الدورة دون إلغاء تثبيتها؛ تظل لوحة المفاتيح متاحة.

شغّل `omarchy setup keyboard` أو `omarchy setup input` لفتح نفس المنتقين. لإضافة لغة واحدة من سطر الأوامر، استخدم `omarchy setup input mozc` أو `hangul` أو `pinyin` أو `chewing` أو `cangjie5`. تأتي Quick وBoshiamy وArray في نفس حزمة Cangjie وتظهر في منتقي طرق الإدخال. تُحفظ مفاتيح التبديل المخصصة الخاصة بك. لتخطيطات أو مفاتيح محرك بديلة، ثبّت `fcitx5-configtool` باستخدام `omarchy pkg add fcitx5-configtool` وشغّله من طرفية. لا يؤدي تحديد لغة إدخال إلى تغيير لغة سطح المكتب. يؤدي اختيار اليابانية أو الكورية أو الصينية ضمن _الإعداد > اللغة_ إلى إضافة طريقة الإدخال الخاصة بها عندما لا يكون لديك أي منها بعد.

استخدم `Super + I` للتنقل بين طرق الإدخال أو تخطيطات لوحة المفاتيح، و`Super + Shift + I` للعودة في الاتجاه الآخر، لذا مع تهيئة ثلاث طرق يمكنك التنقل بين جارين. يظهر مؤشر الإدخال على يمين الشريط فقط عندما تكون أكثر من طريقة إدخال أو تخطيط واحد مهيأة. يعمل ربط سطح المكتب هذا جنبًا إلى جنب مع مفاتيح تبديل Fcitx الحالية لديك؛ يمكنك تجاوزه في `~/.config/hypr/bindings.lua`. تستخدم محركات الإدخال وتسلسلات الإنشاء خدمة [Fcitx5](https://fcitx-im.org/) التي تعمل بالفعل في كل جلسة.

### استخدام ALT كـ SUPER

على بعض لوحات المفاتيح، ليس من الملائم استخدام مفتاح meta الأساسي (مفتاح Windows/cmd) كـ SUPER. يمكنك تغيير هذا إلى ALT بدلًا من ذلك باستخدام هذا التغيير:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
