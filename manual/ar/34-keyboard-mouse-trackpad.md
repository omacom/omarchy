# لوحة المفاتيح والفأرة ولوحة اللمس

يتيح لك Hyprland تكوين جميع أجهزة الإدخال لديك بتفصيل كبير. يمكنك تغيير تكرار لوحة المفاتيح ليصبح أسرع من الصوت أو جعل لوحة اللمس تستخدم التمرير الطبيعي. تغيّر كل ذلك في `~/.config/hypr/input.lua`، والذي يمكنك الوصول إليه أيضًا عبر _الإعداد > الإدخال_ في قائمة Omarchy (`Super + Space`). أي شيء تضبطه هناك يحل محل إعدادات Omarchy الافتراضية.

إليك مثالًا:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

يمكنك [اطّلاع على جميع خيارات الإدخال](https://wiki.hypr.land/Configuring/Basics/Variables/#input) في ويكي Hyprland الخاص بأجهزة الإدخال.

يعمل CapsLock كمفتاح Caps Lock عادي، و`Shift + CapsLock` هو مفتاح التأليف لـ[الرموز التعبيرية السريعة](07-hotkeys.md#quick-emojis) و[الإكمالات الأخرى](07-hotkeys.md#quick-completions). إذا كنت تفضّل أن يكون مفتاح التأليف في مكان آخر، فاستبدل `omarchy:shift_caps_compose` في `kb_options`. على سبيل المثال، ينقل هذا مفتاح التأليف إلى Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### مفاتيح الوظائف

يرسل الصف العلوي في لوحة مفاتيح الكمبيوتر المحمول مفاتيح الوسائط (مستوى الصوت والسطوع وما إلى ذلك) افتراضيًا، ويمنحك الضغط المستمر على `Fn` المفاتيح F1-F12؛ و`Fn + Esc` يقلب ذلك في الاتجاه المعاكس ويبقيه حتى تضغط عليه مرة أخرى. تتذكّر معظم لوحات المفاتيح هذا القفل بنفسها. أما أجهزة ASUS المحمولة ولوحات المفاتيح على طراز Apple فتترك الأمر لـ Linux، الذي يبدأ بها على مفاتيح الوسائط عند كل إقلاع. لكي تبدأ على F1-F12 بدلاً من ذلك، شغّل `omarchy device keyboard toprow fnkeys` (و`omarchy device keyboard toprow mediakeys` للعودة)؛ على بعض أجهزة الكمبيوتر المحمولة يسري مفعوله بعد إعادة التشغيل. تحتفظ أجهزة Apple Silicon Macs بإعدادها الخاص.

### إيماءات لوحة اللمس

مرّر على لوحة اللمس للتنقل في سطح المكتب:

| الإيماءة | الإجراء |
| --- | --- |
| ثلاثة أصابع إلى اليسار / اليمين | مساحة العمل السابقة / التالية، بما في ذلك الفارغة منها |
| ثلاثة أصابع إلى الأعلى | تبديل وحدة تحكم AI |
| ثلاثة أصابع إلى الأسفل | فتح قائمة Omarchy |
| أربعة أصابع إلى اليسار / اليمين | نقل النافذة النشطة إلى مساحة العمل السابقة / التالية |
| أربعة أصابع إلى الأسفل | تبديل وضع ملء الشاشة |

لتغيير إيماءة، ألغِ ضبطها في `~/.config/hypr/input.lua` قبل إضافة [إيماءة لوحة اللمس](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/) الخاصة بك، لأن Hyprland لن يقبل إيماءتين على نفس الأصابع والاتجاه:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

لإيقاف جميع إيماءات Omarchy، اضبط `omarchy_default_gestures = false` بالقرب من أعلى `~/.config/hypr/hyprland.lua`، قبل تحميل إعدادات Omarchy الافتراضية.

على أجهزة Dell XPS المحمولة المزوّدة بلوحة لمس لمسية، يمكنك أيضًا ضبط قوة النقر على منخفضة أو متوسطة أو عالية ضمن _المشغّل > العتاد > لمسيات لوحة اللمس_.

### الكتابة بالصينية واليابانية ولغات أخرى

اختر اليابانية أو الكورية أو الصينية (المبسّطة، Pinyin) أو تايوان (Zhuyin) أو هونغ كونغ (Cangjie) عندما يطلب منك المثبّت لوحة المفاتيح الخاصة بك. يكوّن Omarchy لوحة المفاتيح ومحرّك الإدخال المطابق تلقائيًا، بما في ذلك أثناء إعداد الإقلاع الأول دون اتصال. تستخدم اليابانية Mozc، وتستخدم الكورية Hangul القياسي ذا المجموعتين، وتستخدم الصينية المبسّطة Pinyin، وتستخدم تايوان ترتيب Zhuyin القياسي من Chewing، وتستخدم هونغ كونغ Cangjie مع أشكال أحرف هونغ كونغ. تتيح اليابانية (لوحة مفاتيح US) Mozc مع تخطيط لوحة مفاتيح US. تبقى مفاتيح Hangul وZhuyin وCangjie في مواضعها القياسية حتى عندما تكتب أحرفًا لاتينية باستخدام Dvorak أو Colemak أو AZERTY. إذا كنت قد أضفت Hangul أو Chewing قبل هذا، فقم بإلغاء اختياره وإعادة اختياره ضمن _الإعداد > لوحة المفاتيح > طرق الإدخال_ لنقل مفاتيحه إلى هناك؛ يترك Omarchy المحرّك الذي تكتب به بالفعل وشأنه.

تبدأ الكتابة في الوضع اللاتيني. اضغط `Super + I` للتنقل عبر طرق الإدخال المكوّنة، و`Super + Shift + I` للتنقل إلى الخلف. انقر `Shift` بمفرده للخروج من طريقة إدخال مثل Pinyin إلى الأحرف اللاتينية، وانقره مرة أخرى للعودة، بالطريقة التي تعمل بها Sogou وMicrosoft Pinyin وmacOS؛ ولا يزال `Shift` مع حرف يكتب حرفًا كبيرًا. على لوحات المفاتيح اليابانية، يبدّل 全角/半角 الإدخال، ويشغّله 変換، ويوقفه 無変換. مع الكورية، يبدّل 한/영 Hangul ويحوّل 한자 إلى Hanja، سواء كانت لوحة المفاتيح لديك تحتوي على مفاتيح مخصّصة أو ترسل Right Alt وRight Ctrl لها، كما تفعل العديد من أجهزة الكمبيوتر المحمولة، لذا فإن Right Alt وRight Ctrl ليسا مفتاحي تعديل عاديين هناك؛ يتبدّل الإملاء باستخدام Alt + Space بدلاً من ذلك. يبقى `Ctrl + Space` متاحًا لـ Tmux وHerdr؛ ويبقى `Shift + CapsLock` مفتاح التأليف.

يظهر مؤشر لوحة المفاتيح على يمين الشريط عندما يكون لديك تخطيطات لوحة مفاتيح أو طرق إدخال متعددة. انقر عليه لتبديل لغات الإدخال؛ تعرض اليابانية あ لـ hiragana. لخيارات الأحرف اليابانية، بدّل إلى اليابانية، واكتب كلمة مثل `nihongo`، ثم اضغط Space مرتين. اضغط Enter لقبول اختيارك. إذا كان لديك أيضًا تخطيطات لوحة مفاتيح متعددة، فانقر بزر الفأرة الأيمن فوق المؤشر للتنقل بينها.

استخدم _الإعداد > لوحة المفاتيح > مدخلات لوحة المفاتيح_ لتحديد تخطيطات مثل الإنجليزية والفرنسية، من نفس الخيارات المعروضة أثناء التثبيت. استخدم _الإعداد > لوحة المفاتيح > طرق الإدخال_ لتحديد محرّكات التأليف النشطة. يفتح كلا المُنتقيين داخل قائمة Omarchy مع وضع علامة على اختياراتك الحالية. انقر أو اضغط Enter لتبديل اختيار؛ يطبّق كل تغيير فورًا. يزيل إلغاء اختيار طريقة إدخالها من دورة التنقل دون إلغاء تثبيتها؛ تبقى لوحة المفاتيح متاحة.

شغّل `omarchy setup keyboard` أو `omarchy setup input` لفتح نفس المُنتقيين. لإضافة لغة واحدة من سطر الأوامر، استخدم `omarchy setup input mozc` أو `hangul` أو `pinyin` أو `chewing` أو `cangjie5`. تأتي Quick وBoshiamy وArray في نفس الحزمة مثل Cangjie وتظهر في مُنتقي طرق الإدخال. تُحفظ مفاتيح التبديل المخصّصة لديك. لتخطيطات أو مفاتيح محرّك بديلة، ثبّت `fcitx5-configtool` باستخدام `omarchy pkg add fcitx5-configtool` وشغّله من الطرفية. لا يغيّر تحديد لغة إدخال لغة سطح المكتب. يؤدي اختيار اليابانية أو الكورية أو الصينية ضمن _الإعداد > اللغة_ إلى إضافة طريقة الإدخال الخاصة بها عندما لا يكون لديك أي طريقة بعد.

استخدم `Super + I` للتنقل عبر طرق الإدخال أو تخطيطات لوحة المفاتيح، و`Super + Shift + I` للعودة في الاتجاه الآخر، لذا مع تكوين ثلاث طرق يمكنك التنقل بين جارين. يظهر مؤشر الإدخال على يمين الشريط فقط عندما يتم تكوين أكثر من طريقة إدخال أو تخطيط واحد. يعمل رابط سطح المكتب هذا بجانب مفاتيح تبديل Fcitx الحالية لديك؛ يمكنك تجاوزه في `~/.config/hypr/bindings.lua`. تستخدم محرّكات الإدخال وتسلسلات التأليف خدمة [Fcitx5](https://fcitx-im.org/) التي تعمل بالفعل في كل جلسة.

### استخدام ALT كـ SUPER

على بعض لوحات المفاتيح، ليس من المناسب استخدام مفتاح meta الأساسي (مفتاح Windows/cmd) كـ SUPER. يمكنك تغيير هذا ليكون ALT بدلاً من ذلك باستخدام هذا التغيير:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
