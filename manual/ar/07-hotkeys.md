# اختصارات لوحة المفاتيح

يمكنك رؤية جميع روابط لوحة المفاتيح الرئيسية باستخدام `Super + K` (روابط Tmux باستخدام `Super + Alt + K` وروابط Herdr باستخدام `Super + Ctrl + K`).

## كيفية تنظيم مفاتيح الاختصار

يقع كل مفتاح اختصار على مستوى، تحدده مفاتيح التعديل الخاصة به، ولكل مستوى وظيفة واحدة. وهذا ما يمنع اختلاط مفاتيح الاختصار ببعضها، ويعني أنك تستطيع عادةً تخمين مكان وجود أي شيء.

| مستوى | ما يوجد هناك | أمثلة |
| --- | --- | --- |
| `Super + key` | النظام: النوافذ ومساحات العمل والتخطيطات والقوائم الأساسية | `Super + Space` قائمة Omarchy، `Super + W` إغلاق النافذة، `Super + F` ملء الشاشة |
| `Super + Shift + key` | التطبيقات | `Super + Shift + B` المتصفح، `Super + Shift + E` البريد الإلكتروني، `Super + Shift + N` المحرر |
| `Super + Ctrl + key` | اللوحات وقوائم النظام | `Super + Ctrl + A` الصوت، `Super + Ctrl + N` الشبكة، `Super + Ctrl + C` قائمة الالتقاط |
| `Super + Ctrl + Alt + key` | إجراءات سريعة وتنبيهات | `Super + Ctrl + Alt + T` إظهار الوقت، `Super + Ctrl + Alt + B` البطارية، `Super + Ctrl + Alt + C` لقطة شاشة |

إضافة `Alt` إلى مفتاح اختصار تمنحك صيغة مختلفة من الشيء نفسه، وليس شيئًا غير ذي صلة أبدًا:

- `Super + Shift + B` يفتح المتصفح؛ `Super + Shift + Alt + B` يفتح نافذة خاصة
- `Super + Shift + E` يفتح البريد الإلكتروني؛ `Super + Shift + Alt + E` يبدأ بريدًا جديدًا
- `Super + F` ينتقل إلى ملء الشاشة؛ `Super + Alt + F` ينتقل إلى العرض الكامل
- `Super + Ctrl + C` يفتح قائمة الالتقاط؛ `Super + Ctrl + Alt + C` يتخطى القائمة ويلتقط لقطة شاشة

عند إضافة مفتاح اختصار:

1. اختر المستوى بناءً على ما يفعله، ثم اختر المفتاح.
2. لا تنقل مفتاح اختصار موجودًا لإفساح المجال. اعثر على مفتاح خالٍ على المستوى الصحيح.
3. لا تستخدم `Alt` إلا لصيغة مختلفة من مفتاح الاختصار بدونه.

تكسر بعض مفاتيح الاختصار هذه القواعد لأنها مريحة. `Shift` مع سهم أو `Tab` ينقل أو يعكس بدلاً من فتح تطبيق، و`Print` ومفاتيح الوسائط و`Alt + Tab` و`Ctrl + Alt + Del` تعمل بالطريقة نفسها التي تعمل بها في كل مكان آخر. إنها استثناءات، وليست أنماطًا للنسخ.

إذا لم يناسبك إعداد افتراضي (لنقل إنك تريد `Super + Shift + S` للقطات الشاشة كما في Windows)، فأعد ربطه في `~/.config/hypr/bindings.lua`.

على لوحة اللمس، تقوم إيماءات السحب بثلاثة وأربعة أصابع بتبديل مساحات العمل ونقل النوافذ وفتح القائمة ووحدة تحكم Quake؛ راجع [لوحة المفاتيح والفأرة ولوحة اللمس](34-keyboard-mouse-trackpad.md) للإيماءات.

تستخدم اختصارات تغيير الحجم المفاتيح الفعلية `code:20` و`code:21` (XKB `<AE11>` و`<AE12>`)، بغض النظر عن الأحرف المطبوعة على لوحة المفاتيح. على لوحات المفاتيح الأمريكية هذان المفتاحان هما `-` و`=`؛ وعلى لوحات المفاتيح اليابانية (JIS) هما `-` و`^`؛ وعلى لوحات المفاتيح الإسبانية هما `'` و`¡`. على JIS، يكون `Super + ^` هو `Super + Equal`، بينما يكون `Super + Shift + -` (الذي يكتب `=`) هو `Super + Shift + Minus`.
