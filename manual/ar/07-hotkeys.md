# اختصارات لوحة المفاتيح

يمكنك رؤية جميع اختصارات لوحة المفاتيح الرئيسية باستخدام `Super + K` (اختصارات Tmux باستخدام `Super + Alt + K` واختصارات Herdr باستخدام `Super + Ctrl + K`).

## كيف تُنظَّم الاختصارات

يقع كل اختصار على مستوى، تحدده مفاتيح التعديل الخاصة به، ولكل مستوى وظيفة واحدة. هذا ما يمنع الاختصارات من الاختلاط ببعضها، ويعني أنك تستطيع عادةً تخمين مكان وجود أي شيء.

| المستوى | ما يوجد فيه | أمثلة |
| --- | --- | --- |
| `Super + key` | النظام: النوافذ ومساحات العمل والتخطيطات والقوائم الأساسية | `Super + Space` قائمة Omarchy، `Super + W` إغلاق النافذة، `Super + F` ملء الشاشة |
| `Super + Shift + key` | التطبيقات | `Super + Shift + B` المتصفح، `Super + Shift + E` البريد الإلكتروني، `Super + Shift + N` المحرر |
| `Super + Ctrl + key` | اللوحات وقوائم النظام | `Super + Ctrl + A` الصوت، `Super + Ctrl + N` الشبكة، `Super + Ctrl + C` قائمة الالتقاط |
| `Super + Ctrl + Alt + key` | الإجراءات السريعة والتنبيهات | `Super + Ctrl + Alt + T` إظهار الوقت، `Super + Ctrl + Alt + B` البطارية، `Super + Ctrl + Alt + C` لقطة شاشة |

إضافة `Alt` إلى اختصار يمنحك بديلاً من الشيء نفسه، وليس شيئاً غير ذي صلة أبداً:

- `Super + Shift + B` يفتح المتصفح؛ `Super + Shift + Alt + B` يفتح نافذة خاصة
- `Super + Shift + E` يفتح البريد الإلكتروني؛ `Super + Shift + Alt + E` يبدأ بريداً جديداً
- `Super + F` ينتقل إلى ملء الشاشة؛ `Super + Alt + F` ينتقل إلى ملء العرض
- `Super + Ctrl + C` يفتح قائمة الالتقاط؛ `Super + Ctrl + Alt + C` يتخطى القائمة ويلتقط لقطة شاشة

عند إضافة اختصار:

1. اختر المستوى بناءً على ما يفعله، ثم اختر المفتاح.
2. لا تنقل اختصاراً موجوداً لإفساح المجال. ابحث عن مفتاح شاغر في المستوى الصحيح.
3. لا تستخدم `Alt` إلا لبديل من الاختصار الذي بدونه.

تخالف بعض الاختصارات هذه القواعد لأنها مريحة. `Shift` مع سهم أو `Tab` ينقل أو يعكس الاتجاه بدلاً من فتح تطبيق، و`Print` ومفاتيح الوسائط و`Alt + Tab` و`Ctrl + Alt + Del` تعمل كما تعمل في كل مكان آخر. إنها استثناءات، وليست أنماطاً تُنسخ.

إذا لم يناسبك إعداد افتراضي (لنقل إنك تريد `Super + Shift + S` للقطات الشاشة كما في Windows)، أعد ربطه في `~/.config/hypr/bindings.lua`.

| `Super + /` | التقدم عبر خيارات تحجيم الشاشة |

| `Alt + Shift + Tab` | التنقل إلى الخلف عبر النوافذ في مساحة العمل النشطة |
| `Ctrl + Alt + Tab` | تدوير التركيز إلى الأمام عبر الشاشات |
| `Ctrl + Alt + Shift + Tab` | تدوير التركيز إلى الخلف عبر الشاشات |

تستخدم اختصارات إعادة التحجيم المفاتيح الفيزيائية `code:20` و`code:21` (في XKB ‏`<AE11>` و`<AE12>`)، بغض النظر عن الأحرف المطبوعة على لوحة المفاتيح. في لوحات المفاتيح الأمريكية هذه المفاتيح هي `-` و`=`؛ وفي لوحات المفاتيح اليابانية (JIS) هي `-` و`^`؛ وفي لوحات المفاتيح الإسبانية هي `'` و`¡`. في JIS، يكون `Super + ^` هو `Super + Equal`، بينما يكون `Super + Shift + -` (الذي يكتب `=`) هو `Super + Shift + Minus`.

## طرفية Ghostty

تُثبَّت طرفية Ghostty باستخدام _Install > Terminal_ عبر قائمة Omarchy.

| الاختصار | الوظيفة |
| ----------------------- | --------------------- |
| `Ctrl + Shift + E` | تقسيم جديد أسفل |
| `Ctrl + Shift + O` | تقسيم جديد بجانب |
| `Ctrl + Alt + Arrows` | التنقل بين التقسيمات |
| `Super + Ctrl + Shift + Arrows` | تغيير حجم التقسيم بمقدار 10 أسطر |
| `Super + Ctrl + Shift + Alt + Arrows` | تغيير حجم التقسيم بمقدار 100 سطر |
| `Ctrl + Shift + T` | علامة تبويب جديدة |
| `Ctrl + Shift + Arrows` | التنقل بين علامات التبويب |
| `Alt + Numbers` | الذهاب إلى علامة تبويب محددة |
| `Shift + Pg Up/Down` | تمرير السجل |
| `Ctrl + Left mouse` | فتح الرابط في المتصفح |

## مدير الملفات

| الاختصار | الوظيفة |
| ------------------- | ------------------------------ |
| `Ctrl + L` | الذهاب إلى المسار |
| `Space` | معاينة الملف (الأسهم للتنقل) |
| `Alt + Up` | الصعود إلى المجلد الأب |

## Neovim (مع lazyvim)

### التنقل

| الاختصار | الوظيفة |
| ------------------------ | ------------------------------- |
| `Space` | إظهار خيارات الأوامر |
| `Space Space` | فتح ملف عبر البحث التقريبي |
| `Space E` | تبديل الشريط الجانبي |
| `Space G G` | إظهار عناصر التحكم في Git |
| `Space S G` | بحث في محتوى الملف |
| `Ctrl + W W` | القفز بين الشريط الجانبي والمحرر |
| `Ctrl + Left/right arrow` | تغيير حجم الشريط الجانبي |
| `Shift + H` | الذهاب إلى علامة تبويب الملف اليسرى |
| `Shift + L` | الذهاب إلى علامة تبويب الملف اليمنى |
| `Space B D` | إغلاق علامة تبويب الملف |

### أثناء وجودك في الشريط الجانبي

| الاختصار | الوظيفة |
| ------------------------ | ------------------------------- |
| `A` | إضافة ملف جديد في الدليل الأب |
| `Shift + A` | إضافة دليل فرعي جديد في الدليل الأب |
| `D` | حذف الملف/الدليل المحدد |
| `M` | نقل الملف/الدليل المحدد |
| `R` | إعادة تسمية الملف/الدليل المحدد |
| `?` | إظهار المساعدة لجميع الأوامر |

[راجع جميع اختصارات Neovim التي هيّأتها LazyVim](https://www.lazyvim.org/keymaps).

## الإكمالات السريعة

| الاختصار | الإكمال |
| ------------ |  ---------- |
| `Shift + CapsLock Space Space` | — (شرطة طويلة) |
| `Shift + CapsLock Space N` | اسمك (كما أُدخل عند الإعداد) |
| `Shift + CapsLock Space E` | بريدك الإلكتروني (كما أُدخل عند الإعداد) |

يمكنك إضافة المزيد بنفسك عن طريق تحرير `~/.XCompose`، ثم تشغيل `omarchy-restart-xcompose` في الطرفية لتطبيق التغييرات.
