# مفاتيح الاختصار

يمكنك رؤية جميع روابط لوحة المفاتيح الرئيسية باستخدام `Super + K` (روابط Tmux باستخدام `Super + Alt + K` وروابط Herdr باستخدام `Super + Ctrl + K`).

## كيفية تنظيم مفاتيح الاختصار

يقع كل مفتاح اختصار على مستوى تحدده مفاتيح التعديل الخاصة به، ولكل مستوى مهمة واحدة. وهذا ما يمنع مفاتيح الاختصار من الاختلاط ببعضها، ويعني أنك تستطيع عادةً تخمين مكان وجود أي شيء.

| المستوى | ما يوجد فيه | أمثلة |
| --- | --- | --- |
| `Super + key` | النظام: النوافذ ومساحات العمل والتخطيطات والقوائم الأساسية | `Super + Space` قائمة Omarchy، `Super + W` إغلاق النافذة، `Super + F` ملء الشاشة |
| `Super + Shift + key` | التطبيقات | `Super + Shift + B` المتصفح، `Super + Shift + E` البريد الإلكتروني، `Super + Shift + N` المحرر |
| `Super + Ctrl + key` | اللوحات وقوائم النظام | `Super + Ctrl + A` الصوت، `Super + Ctrl + N` الشبكة، `Super + Ctrl + C` قائمة الالتقاط |
| `Super + Ctrl + Alt + key` | الإجراءات السريعة والتنبيهات | `Super + Ctrl + Alt + T` إظهار الوقت، `Super + Ctrl + Alt + B` البطارية، `Super + Ctrl + Alt + C` لقطة شاشة |

إضافة `Alt` إلى مفتاح اختصار تمنحك صيغة مختلفة من الشيء نفسه، ولا تمنحك أبدًا شيئًا غير ذي صلة:

- `Super + Shift + B` يفتح المتصفح؛ `Super + Shift + Alt + B` يفتح نافذة خاصة
- `Super + Shift + E` يفتح البريد الإلكتروني؛ `Super + Shift + Alt + E` يبدأ بريدًا جديدًا
- `Super + F` ينتقل إلى ملء الشاشة؛ `Super + Alt + F` ينتقل إلى ملء العرض
- `Super + Ctrl + C` يفتح قائمة الالتقاط؛ `Super + Ctrl + Alt + C` يتخطى القائمة ويلتقط لقطة شاشة

عند إضافة مفتاح اختصار:

1. اختر المستوى بناءً على ما يفعله، ثم اختر المفتاح.
2. لا تنقل مفتاح اختصار موجودًا لإفساح المجال. اعثر على مفتاح حر على المستوى الصحيح.
3. لا تستخدم `Alt` إلا لصيغة مختلفة من مفتاح الاختصار بدونه.

تكسر بضعة مفاتيح اختصار هذه القواعد لأنها مريحة. `Shift` مع سهم أو `Tab` ينقل أو يعكس بدلاً من فتح تطبيق، و`Print` ومفاتيح الوسائط و`Alt + Tab` و`Ctrl + Alt + Del` تعمل بالطريقة نفسها التي تعمل بها في كل مكان آخر. إنها استثناءات، وليست أنماطًا للنسخ.

إذا لم يناسبك إعداد افتراضي (على سبيل المثال تريد `Super + Shift + S` للقطات الشاشة كما هو الحال على Windows)، فأعد ربطه في `~/.config/hypr/bindings.lua`.

على لوحة اللمس، تقوم إيماءات السحب بثلاثة وأربعة أصابع بتبديل مساحات العمل ونقل النوافذ وفتح القائمة ووحدة تحكم Quake؛ راجع [لوحة المفاتيح والفأرة ولوحة اللمس](34-keyboard-mouse-trackpad.md) للاطلاع على الإيماءات.

تستخدم اختصارات تغيير الحجم المفاتيح الفعلية `code:20` و`code:21` (XKB `<AE11>` و`<AE12>`)، بغض النظر عن الأحرف المطبوعة على لوحة المفاتيح. على لوحات المفاتيح الأمريكية هذه المفاتيح هي `-` و`=`؛ وعلى لوحات المفاتيح اليابانية (JIS) هي `-` و`^`؛ وعلى لوحات المفاتيح الإسبانية هي `'` و`¡`. على JIS، يكون `Super + ^` هو `Super + Equal`، بينما يكون `Super + Shift + -` (الذي يكتب `=`) هو `Super + Shift + Minus`.

## Tmux

مفتاح البادئة هو `Ctrl + Space` (يعمل `Ctrl + B` أيضًا). يمكنك تغيير هذه الروابط في `~/.config/tmux/tmux.conf`.

### الألواح

| مفتاح الاختصار | الوظيفة |
| ----------------------- | --------------------- |
| `Prefix + v` | تقسيم اللوحة بجانبها (عمودي) |
| `Prefix + h` | تقسيم اللوحة أسفلها (أفقي) |
| `Prefix + x` | إنهاء اللوحة |
| `Prefix + z` | تبديل تكبير اللوحة (ملء الشاشة) |
