# اختصارات لوحة المفاتيح

يمكنك رؤية جميع اختصارات لوحة المفاتيح الرئيسية باستخدام `Super + K` (اختصارات Tmux باستخدام `Super + Alt + K` واختصارات Herdr باستخدام `Super + Ctrl + K`).

## التنقل

| اختصار لوحة المفاتيح | الوظيفة |
| ----------------------- | --------------------- |
| `Super + Space` | قائمة Omarchy (التطبيقات وكل شيء آخر) |
| `Super + Alt + Space` | شبكة التطبيقات |
| `Super + Escape` | قائمة النظام (تعليق، إعادة تشغيل، إلخ) |
| `Super + Ctrl + L` | قفل الكمبيوتر |
| `Super + W` or `Super + Q` | إغلاق النافذة |
| `Ctrl + Alt + Del` | إغلاق جميع النوافذ |
| `Super + T` | تبديل النافذة بين التبليط/العائمة |
| `Super + J` | تبديل موضع النافذة (أفقي/عمودي) |
| `Super + O` | تبديل تحويل النافذة إلى لاصقة وعائمة |
| `Super + L` | التنقل بين تخطيطات dwindle وscrolling والعائم |
| `Super + Alt + L` | التنقل بين التخطيطات في الاتجاه المعاكس |
| `Super + P` | تبديل نمط النافذة الزائفة (طبيعي مقابل ممتد) |
| `Super + F` | ملء الشاشة |
| `Super + Alt + F` | ملء العرض |
| `Super + Ctrl + F` | ملء الشاشة داخل النافذة |
| `Super + 1/2/3/4` | الانتقال إلى مساحة عمل محددة على الشاشة المركّز عليها |
| `Super + Tab` | الانتقال إلى مساحة العمل التالية على الشاشة المركّز عليها |
| `Super + Shift + Tab` | الانتقال إلى مساحة العمل السابقة على الشاشة المركّز عليها |
| `Super + Ctrl + Tab` | الانتقال إلى مساحة العمل التي كنت عليها من قبل على الشاشة المركّز عليها |
| `Super + Shift + 1/2/3/4` | نقل النافذة إلى مساحة عمل على الشاشة المركّز عليها |
| `Super + Shift + Alt + 1/2/3/4` | نقل النافذة إلى مساحة عمل على الشاشة المركّز عليها دون اتباعها |
| `Super + S` | تبديل لوحة الخدش الكاملة |
| `Super + Alt + S` | نقل النافذة إلى لوحة الخدش الكاملة |
| `Super + Grave` | تبديل وحدة تحكم Quake |
| `Super + Shift + Grave` | نقل النافذة إلى وحدة تحكم Quake |
| `Super + Shift + Ctrl + Arrows` | نقل النافذة إلى الشاشة في ذلك الاتجاه |
| `Super + Shift + Alt + Arrows` | نقل مساحة العمل إلى الشاشة في ذلك الاتجاه |
| `Super + Arrow` | نقل التركيز إلى النافذة في اتجاه السهم، مع العبور إلى الشاشة على ذلك الجانب عند حافة الشاشة |
| `Super + Shift + Arrow` | مبادلة النافذة مع أخرى في اتجاه السهم، بما في ذلك واحدة على الشاشة على ذلك الجانب |
| `Super + Minus` | توسيع النافذة إلى اليسار |
| `Super + Equal` | تصغير النافذة إلى اليسار |
| `Super + Shift + Minus` | تصغير النافذة إلى الأعلى |
| `Super + Shift + Equal` | توسيع النافذة إلى الأسفل |
| `Super + Alt + Minus/Equal` | نفس تغيير الحجم بخطوات أصغر |
| `Super + Ctrl + Minus/Equal` | نفس تغيير الحجم بخطوات أكبر |
| `Super + Alt + Home` | حفظ عرض النافذة |
| `Super + Home` | استعادة عرض النافذة المحفوظ |
| `Super + Left Mouse` | سحب النافذة حول الشاشة |
| `Super + Right Mouse` | تغيير حجم النافذة |
| `Super + Scroll Wheel` | التمرير عبر مساحات العمل على الشاشة المركّز عليها |
| `Super + G` | تبديل تجميع النوافذ |
| `Super + Alt + G` | إخراج النافذة من التجميع |
| `Super + Alt + Tab` | التنقل بين النوافذ في التجميع |
| `Super + Alt + Shift + Tab` | التنقل للخلف بين النوافذ في التجميع |
| `Super + Alt + Scroll Wheel` | التنقل بين النوافذ في التجميع |
| `Super + Alt + 1/2/3/4/5` | الانتقال إلى نافذة محددة في التجميع |
| `Super + Alt + Arrow` | نقل النافذة إلى التجميع في اتجاه السهم، بما في ذلك واحدة على الشاشة على ذلك الجانب |
| `Super + Ctrl + Left/Right` | التنقل بين النوافذ داخل مجموعة تبليط |
| `Super + Ctrl + Z` | التكبير على الشاشة (كرر لمزيد من التكبير) |
| `Super + Ctrl + Alt + Z` | التصغير الكامل من الشاشة |
| `Super + /` | التقدم عبر خيارات تحجيم الشاشة |
| `Super + Alt + /` | التراجع عبر خيارات تحجيم الشاشة |
| `Alt + Tab` | التنقل للأمام عبر النوافذ على مساحة العمل النشطة |
| `Alt + Shift + Tab` | التنقل للخلف عبر النوافذ على مساحة العمل النشطة |
| `Ctrl + Alt + Tab` | التنقل بالتركيز للأمام عبر الشاشات |
| `Ctrl + Alt + Shift + Tab` | التنقل بالتركيز للخلف عبر الشاشات |

تستخدم اختصارات تغيير الحجم المفاتيح الفعلية `code:20` و`code:21` (XKB `<AE11>` و`<AE12>`)، بغض النظر عن الأحرف المطبوعة على لوحة المفاتيح. على لوحات المفاتيح الأمريكية هذه المفاتيح هي `-` و`=`؛ على لوحات المفاتيح اليابانية (JIS) هي `-` و`^`؛ على لوحات المفاتيح الإسبانية هي `'` و`¡`. على JIS، `Super + ^` هو `Super + Equal`، بينما `Super + Shift + -` (الذي يكتب `=`) هو `Super + Shift + Minus`.

## الحافظة العالمية

| اختصار لوحة المفاتيح | الوظيفة |
| ----------------------- | --------------------- |
| `Super + A` | تحديد الكل في التطبيقات التي تدعم `Ctrl + A` |
| `Super + C` | نسخ |
| `Super + X` | قص (ليس في الطرفية) |
| `Super + V` | لصق |
| `Super + Ctrl + V` | مدير الحافظة |

عادةً على Linux، تحتاج إلى `Ctrl + Shift + C/V` للنسخ واللصق في الطرفية و`Ctrl + C/V` للقيام بذلك في كل مكان آخر. اختصارات الحافظة الموحدة هذه في Omarchy تعمل في كل مكان.

## الالتقاط

| اختصار لوحة المفاتيح | الوظيفة |
| ------------------- | ------------------------------ |
| `Print Screen` | لقطة شاشة |
| `Super + Ctrl + Alt + C` | لقطة شاشة (نفس اللقطة، للوحات المفاتيح التي لا تحتوي على مفتاح Print Screen) |
| `Super + Ctrl + C` | قائمة الالتقاط |
| `Alt + Print Screen` | تسجيل الشاشة |
| `Super + Print Screen` | منتقي الألوان |
| `Super + Ctrl + Print Screen` | استخراج النص إلى الحافظة |
| `Super + Alt + [` | تصغير تراكب كاميرا الويب أثناء التسجيل |
| `Super + Alt + ]` | تكبير تراكب كاميرا الويب أثناء التسجيل |
| `Alt + Shift + L` | نسخ URL الحالي من تطبيق الويب أو Chromium |
| `Alt + Shift + D` | تنزيل الفيديو على الصفحة الحالية إلى `~/Videos` |
| `Alt + Space` | بدء/إيقاف الإملاء (يتطلب _Setup > Defaults > Dictation_) |
| `Right Alt` | اضغط باستمرار للإملاء (يتطلب _Setup > Defaults > Dictation_) |

مع تسجيلات الشاشة، يسأل الاختصار أولاً عن الصوت الذي تريده، ثم يبدأ التسجيل. اضغط عليه مرة أخرى للإيقاف. راجع [لقطات الشاشة والتسجيل](12-screenshots-recording.md) للحصول على التفاصيل.

جميع خيارات الالتقاط متاحة أيضًا ضمن _Trigger > Capture_ في قائمة Omarchy (`Super + Space`).

## Tmux

مفتاح البادئة هو `Ctrl + Space` (يعمل `Ctrl + B` أيضًا). يمكنك تغيير هذه الاختصارات في `~/.config/tmux/tmux.conf`.

### الألواح

| اختصار لوحة المفاتيح | الوظيفة |
| ----------------------- | --------------------- |
| `Prefix + v` | تقسيم اللوحة بجانبها (عمودي) |
| `Prefix + h` | تقسيم اللوحة أسفلها (أفقي) |
| `Prefix + x` | إنهاء اللوحة |
| `Prefix + z` | تبديل تكبير اللوحة (ملء الشاشة) |
| `Alt + Enter` | تقسيم اللوحة أسفلها (بدون بادئة) |
| `Alt + Shift + Enter` | تقسيم اللوحة بجانبها (بدون بادئة) |
| `Alt + Escape` | إنهاء اللوحة (بدون بادئة) |
| `Ctrl + Alt + Arrows` | التنقل بين الألواح |
| `Ctrl + Alt + Shift + Arrows` | تغيير حجم الألواح |

### النوافذ

| اختصار لوحة المفاتيح | الوظيفة |
| ----------------------- | --------------------- |
| `Prefix + c` | نافذة جديدة |
| `Prefix + k` | إنهاء النافذة |
| `Prefix + r` | إعادة تسمية النافذة |
| `Alt + 1-9` | الانتقال إلى نافذة محددة |
| `Alt + Arrow Left/Right` | التنقل بين النوافذ |
| `Alt + Shift + Arrow Left/Right` | نقل النافذة إلى اليسار/اليمين |

### وظائف تخطيط Tmux

يجب تشغيل هذه الوظائف داخل جلسة Tmux.

| الأمر | الوظيفة |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | إنشاء تخطيط تطوير مع محرر وAI وطرفية |

## الإكمالات السريعة

| اختصار لوحة المفاتيح | الإكمال |
| ------------ |  ---------- |
| `Shift + CapsLock Space Space` | — (شرطة طويلة) |
| `Shift + CapsLock Space N` | اسمك (كما تم إدخاله عند الإعداد) |
| `Shift + CapsLock Space E` | بريدك الإلكتروني (كما تم إدخاله عند الإعداد) |

يمكنك إضافة المزيد بنفسك عن طريق تحرير `~/.XCompose`، ثم تشغيل `omarchy-restart-xcompose` في الطرفية ليتم التقاط التغييرات.
