# اختصارات لوحة المفاتيح

يمكنك رؤية جميع ارتباطات لوحة المفاتيح الرئيسية باستخدام `Super + K` (وارتباطات Tmux باستخدام `Super + Alt + K` وارتباطات Herdr باستخدام `Super + Ctrl + K`).

## التنقّل

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + Space`           | قائمة Omarchy (التطبيقات وكل شيء آخر)    |
| `Super + Alt + Space` | شبكة التطبيقات |
| `Super + Escape` | قائمة النظام (تعليق، إعادة تشغيل، إلخ)  |
| `Super + Ctrl + L` | قفل الكمبيوتر |
| `Super + W` or `Super + Q` | إغلاق النافذة             |
| `Ctrl + Alt + Del` | إغلاق جميع النوافذ |
| `Super + T`               | تبديل النافذة بين التجانب/العوم             |
| `Super + J` | تبديل موضع النافذة (أفقي/رأسي) |
| `Super + O`               | تبديل إبراز النافذة إلى وضع لاصق وعائم |
| `Super + L`               | التنقّل بين تخطيطات dwindle و scrolling و floating |
| `Super + Alt + L`         | التنقّل بين التخطيطات بالعكس |
| `Super + P`               | تبديل نمط النافذة الزائف (طبيعي مقابل ممتد) |
| `Super + F`                 | ملء الشاشة              |
| `Super + Alt + F`                 | ملء العرض              |
| `Super + Ctrl + F`                 | ملء الشاشة داخل النافذة              |

| `Super + Tab` | الانتقال إلى مساحة العمل التالية على الشاشة المركّزة |
| `Super + Shift + Tab` | الانتقال إلى مساحة العمل السابقة على الشاشة المركّزة |

| `Super + Shift + Alt + 1/2/3/4` | نقل النافذة إلى مساحة عمل على الشاشة المركّزة دون متابعتها |

| `Super + Alt + S` | نقل النافذة إلى الـ scratchpad الكامل |
| `Super + Grave` | تبديل وحدة تحكم Quake |
| `Super + Shift + Grave` | نقل النافذة إلى وحدة تحكم Quake |
| `Super + Shift + Ctrl + Arrows` | نقل النافذة إلى الشاشة في ذلك الاتجاه |
| `Super + Shift + Alt + Arrows` | نقل مساحة العمل إلى الشاشة في ذلك الاتجاه |
| `Super + Arrow`  | نقل التركيز إلى النافذة في اتجاه السهم، والعبور إلى الشاشة على ذلك الجانب عند حافة الشاشة |
| `Super + Shift + Arrow`  | مبادلة النافذة مع أخرى في اتجاه السهم، بما في ذلك واحدة على الشاشة على ذلك الجانب |
| `Super + Minus` | توسيع النافذة لليسار |
| `Super + Equal` | تقليص النافذة لليسار |
| `Super + Shift + Minus` | تقليص النافذة لأعلى |
| `Super + Shift + Equal` | توسيع النافذة لأسفل |
| `Super + Alt + Minus/Equal` | نفس تغيير الحجم بخطوات أصغر |
| `Super + Ctrl + Minus/Equal` | نفس تغيير الحجم بخطوات أكبر |
| `Super + Alt + Home` | حفظ عرض النافذة |
| `Super + Home` | استعادة عرض النافذة المحفوظ |
| `Super + Left Mouse` | سحب النافذة من مكان لآخر |
| `Super + Right Mouse` | تغيير حجم النافذة |
| `Super + Scroll Wheel` | التمرير عبر مساحات العمل على الشاشة المركّزة |
| `Super + G`               | تبديل تجميع النوافذ      |
| `Super + Alt + G`               | إخراج النافذة من التجميع      |
| `Super + Alt + Tab`               | التنقّل بين النوافذ في التجميع      |
| `Super + Alt + Shift + Tab`               | التنقّل للخلف بين النوافذ في التجميع      |
| `Super + Alt + Scroll Wheel` | التنقّل بين النوافذ في التجميع |
| `Super + Alt + 1/2/3/4/5`               | الانتقال إلى نافذة محددة في التجميع      |
| `Super + Alt + Arrow`  | نقل النافذة إلى التجميع في اتجاه السهم، بما في ذلك واحدة على الشاشة على ذلك الجانب |
| `Super + Ctrl + Left/Right`  | التنقّل بين النوافذ داخل مجموعة تجانب |
| `Super + Ctrl + Z` | تكبير الشاشة (كرر لمزيد من التكبير) |
| `Super + Ctrl + Alt + Z` | تصغير الشاشة بالكامل |
| `Super + /` | التقدم عبر خيارات قياس الشاشة |
| `Super + Alt + /` | الرجوع للخلف عبر خيارات قياس الشاشة |
| `Alt + Tab` | التنقّل للأمام عبر النوافذ على مساحة العمل النشطة |
| `Alt + Shift + Tab` | التنقّل للخلف عبر النوافذ على مساحة العمل النشطة |
| `Ctrl + Alt + Tab`| التنقّل بالتركيز للأمام عبر الشاشات |
| `Ctrl + Alt + Shift + Tab`| التنقّل بالتركيز للخلف عبر الشاشات |

## الالتقاط

| Hotkey              | Function                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | لقطة شاشة                      |
| `Super + Ctrl + Alt + C`            | لقطة شاشة (نفس اللقطة، للوحات المفاتيح التي لا تحتوي على مفتاح Print Screen) |
| `Super + Ctrl + C` | قائمة الالتقاط |
| `Alt + Print Screen`            | تسجيل الشاشة                     |
| `Super + Print Screen` | منتقي الألوان |
| `Super + Ctrl + Print Screen` | استخراج النص إلى الحافظة |
| `Super + Alt + [` | تصغير تراكب كاميرا الويب أثناء التسجيل |
| `Super + Alt + ]` | تكبير تراكب كاميرا الويب أثناء التسجيل |
| `Alt + Shift + L` | نسخ URL الحالي من تطبيق الويب أو Chromium |
| `Alt + Shift + D` | تنزيل الفيديو الموجود على الصفحة الحالية إلى `~/Videos` |
| `Super + Ctrl + X` | بدء/إيقاف الإملاء (يتطلب _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | إملاء بالضغط والتحدث (يتطلب Voxtype أو Superwhisper) |

مع تسجيلات الشاشة، يسألك الاختصار أولاً عن الصوت الذي تريده، ثم يبدأ التسجيل. اضغطه مرة أخرى للإيقاف. راجع [لقطات الشاشة والتسجيل](12-screenshots-recording.md) للاطلاع على التفاصيل.

جميع خيارات الالتقاط متاحة أيضًا ضمن _Trigger > Capture_ في قائمة Omarchy (`Super + Space`).

## Tmux

مفتاح البادئة هو `Ctrl + Space` (يعمل `Ctrl + B` أيضًا). يمكنك تغيير هذه الارتباطات في `~/.config/tmux/tmux.conf`.

### اللوحات

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + v` | تقسيم اللوحة بجانبها (رأسي) |
| `Prefix + h` | تقسيم اللوحة أسفلها (أفقي) |
| `Prefix + x` | إنهاء اللوحة |
| `Prefix + z` | تبديل تكبير اللوحة (ملء الشاشة) |
| `Alt + Enter` | تقسيم اللوحة أسفلها (بدون بادئة) |
| `Alt + Shift + Enter` | تقسيم اللوحة بجانبها (بدون بادئة) |
| `Alt + Escape` | إنهاء اللوحة (بدون بادئة) |
| `Ctrl + Alt + Arrows` | التنقّل بين اللوحات |
| `Ctrl + Alt + Shift + Arrows` | تغيير حجم اللوحات |

### النوافذ

| ------- | -------- |
