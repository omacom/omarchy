# مفاتيح الاختصار

يمكنك رؤية جميع روابط لوحة المفاتيح الرئيسية باستخدام `Super + K` (روابط Tmux باستخدام `Super + Alt + K` وروابط Herdr باستخدام `Super + Ctrl + K`).

## كيفية تنظيم مفاتيح الاختصار

يقع كل مفتاح اختصار على مستوى، تحدده مفاتيح التعديل الخاصة به، ولكل مستوى وظيفة واحدة. هذا ما يمنع مفاتيح الاختصار من الاختلاط ببعضها البعض، ويعني أنك تستطيع عادةً تخمين مكان وجود أي شيء.

| المستوى | ما يوجد هناك | أمثلة |
| --- | --- | --- |
| `Super + key` | النظام: النوافذ ومساحات العمل والتخطيطات والقوائم الأساسية | `Super + Space` قائمة Omarchy، `Super + W` إغلاق النافذة، `Super + F` ملء الشاشة |
| `Super + Shift + key` | التطبيقات | `Super + Shift + B` المتصفح، `Super + Shift + E` البريد الإلكتروني، `Super + Shift + N` المحرر |
| `Super + Ctrl + key` | اللوحات وقوائم النظام | `Super + Ctrl + A` الصوت، `Super + Ctrl + N` الشبكة، `Super + Ctrl + C` قائمة الالتقاط |
| `Super + Ctrl + Alt + key` | الإجراءات السريعة والتنبيهات | `Super + Ctrl + Alt + T` إظهار الوقت، `Super + Ctrl + Alt + B` البطارية، `Super + Ctrl + Alt + C` لقطة الشاشة |

إضافة `Alt` إلى مفتاح اختصار تمنحك صيغة مغايرة للشيء نفسه، وليست أبدًا شيئًا غير ذي صلة:

- `Super + Shift + B` يفتح المتصفح؛ `Super + Shift + Alt + B` يفتح نافذة خاصة
- `Super + Shift + E` يفتح البريد الإلكتروني؛ `Super + Shift + Alt + E` يبدأ بريدًا إلكترونيًا جديدًا
- `Super + F` ينتقل إلى ملء الشاشة؛ `Super + Alt + F` ينتقل إلى ملء العرض
- `Super + Ctrl + C` يفتح قائمة الالتقاط؛ `Super + Ctrl + Alt + C` يتخطى القائمة ويلتقط لقطة شاشة

عند إضافة مفتاح اختصار:

1. اختر المستوى بناءً على ما يفعله، ثم اختر المفتاح.
2. لا تنقل مفتاح اختصار موجودًا لإفساح المجال. ابحث عن مفتاح خالٍ على المستوى الصحيح.
3. استخدم `Alt` فقط لصيغة مغايرة من مفتاح الاختصار بدونه.

بعض مفاتيح الاختصار تخالف هذه القواعد لأنها مريحة. `Shift` مع سهم أو `Tab` ينقل أو يعكس بدلاً من فتح تطبيق، و`Print` ومفاتيح الوسائط و`Alt + Tab` و`Ctrl + Alt + Del` تعمل بالطريقة نفسها التي تعمل بها في كل مكان آخر. إنها استثناءات، وليست أنماطًا للنسخ.

إذا لم يناسبك إعداد افتراضي (مثلاً تريد `Super + Shift + S` لالتقاط الشاشة كما في Windows)، فأعد ربطه في `~/.config/hypr/bindings.lua`.

على لوحة اللمس، تقوم إيماءات السحب بثلاثة وأربعة أصابع بتبديل مساحات العمل ونقل النوافذ وفتح القائمة ووحدة تحكم Quake؛ راجع [لوحة المفاتيح والفأرة ولوحة اللمس](34-keyboard-mouse-trackpad.md) للاطلاع على الإيماءات.

يستخدم تغيير الحجم المفتاحين الموجودين على يمين 0، مهما كان ما تطبعه لوحة مفاتيحك عليهما: `-` و`=` على لوحات مفاتيح US، و`+` و`´` على الدنماركية والسويدية، و`+` و`\` على النرويجية، و`ß` و`´` على الألمانية، و`'` و`¡` على الإسبانية، و`-` و`^` على اليابانية (JIS). يسردها `Super + K` كما تطبعهما لوحة مفاتيحك. على JIS، يكون `Super + ^` هو `Super + Equal`، بينما يكون `Super + Shift + -` (الذي يكتب `=`) هو `Super + Shift + Minus`. يستخدم تحجيم الشاشة ومدير كلمات المرور `/`؛ على التخطيطات التي تكتب `/` فقط مع Shift، كما تفعل معظم التخطيطات الأوروبية، يستخدمان المفتاح الموجود على يسار Shift الأيمن بدلاً من ذلك (`-` على الدنماركية والألمانية).

## Tmux

مفتاح البادئة هو `Ctrl + Space` (يعمل `Ctrl + B` أيضًا). يمكنك تغيير هذه الروابط في `~/.config/tmux/tmux.conf`.

### الأجزاء

| مفتاح الاختصار | الوظيفة |
| ----------------------- | --------------------- |
| `Prefix + v` | تقسيم الجزء بجانبه (عموديًا) |
| `Prefix + h` | تقسيم الجزء أسفله (أفقيًا) |
| `Prefix + x` | إنهاء الجزء |
| `Prefix + z` | تبديل تكبير الجزء (ملء الشاشة) |
| `Alt + Enter` | تقسيم الجزء أسفله (بدون بادئة) |
| `Alt + Shift + Enter` | تقسيم الجزء بجانبه (بدون بادئة) |
| `Alt + Escape` | إنهاء الجزء (بدون بادئة) |
| `Ctrl + Alt + Arrows` | التنقل بين الأجزاء |
| `Ctrl + Alt + Shift + Arrows` | تغيير حجم الأجزاء |

### النوافذ

| مفتاح الاختصار | الوظيفة |
| ----------------------- | --------------------- |
| `Prefix + c` | نافذة جديدة |
| `Prefix + k` | إنهاء النافذة |
| `Prefix + r` | إعادة تسمية النافذة |
| `Alt + 1-9` | الانتقال إلى نافذة محددة |
| `Alt + Arrow Left/Right` | التنقل بين النوافذ |
| `Alt + Shift + Arrow Left/Right` | نقل النافذة إلى اليسار/اليمين |

### الجلسات

| مفتاح الاختصار | الوظيفة |
| ----------------------- | --------------------- |
| `Prefix + C` | جلسة جديدة |
| `Prefix + K` | إنهاء الجلسة |
| `Prefix + R` | إعادة تسمية الجلسة |
| `Prefix + N` | الجلسة التالية |
| `Prefix + P` | الجلسة السابقة |
| `Alt + Arrow Up/Down` | التنقل بين الجلسات |
| `Prefix + s` | سرد الجلسات |
| `Prefix + d` | الانفصال عن الجلسة |

### وضع النسخ (بنمط vi)

| مفتاح الاختصار | الوظيفة |
| ----------------------- | --------------------- |
| `Prefix + [` | الدخول إلى وضع النسخ |
| `v` | بدء التحديد (في وضع النسخ) |
| `y` | نسخ التحديد (في وضع النسخ) |

### عام

| مفتاح الاختصار | الوظيفة |
| ----------------------- | --------------------- |
| `Prefix + q` | إعادة تحميل التهيئة |
| `Prefix + ?` | إظهار روابط مفاتيح Tmux |
| `Prefix + :` | موجه الأوامر |

### دوال تخطيط Tmux

يجب تشغيل هذه الدوال داخل جلسة Tmux.

| الأمر | الوظيفة |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | إنشاء تخطيط تطوير يحتوي على محرر وذكاء اصطناعي وطرفية |
| `tdlm <ai> [<second_ai>]` | إنشاء تخطيط تطوير لكل مجلد فرعي |
| `tsl <count> <command>` | إنشاء تخطيط سرب متعدد الأجزاء |
