# مفاتيح الاختصار

يمكنك رؤية جميع ارتباطات لوحة المفاتيح الرئيسية باستخدام `Super + K` (ارتباطات Tmux باستخدام `Super + Alt + K` وارتباطات Herdr باستخدام `Super + Ctrl + K`).

## كيف تُنظَّم مفاتيح الاختصار

يوجد كل مفتاح اختصار على مستوى، تحدّده مفاتيح التعديل الخاصة به، ولكل مستوى مهمة واحدة. وهذا ما يمنع مفاتيح الاختصار من الاختلاط ببعضها، ويعني أنك تستطيع عادةً تخمين موضع أي شيء.

| المستوى | ما يوجد هناك | أمثلة |
| --- | --- | --- |
| `Super + key` | النظام: النوافذ ومساحات العمل والتخطيطات والقوائم الأساسية | `Super + Space` قائمة Omarchy، `Super + W` إغلاق النافذة، `Super + F` ملء الشاشة |
| `Super + Shift + key` | التطبيقات | `Super + Shift + B` المتصفح، `Super + Shift + E` البريد الإلكتروني، `Super + Shift + N` المحرر |
| `Super + Ctrl + key` | اللوحات وقوائم النظام | `Super + Ctrl + A` الصوت، `Super + Ctrl + N` الشبكة، `Super + Ctrl + C` قائمة الالتقاط |
| `Super + Ctrl + Alt + key` | الإجراءات السريعة والتنبيهات | `Super + Ctrl + Alt + T` إظهار الوقت، `Super + Ctrl + Alt + B` البطارية، `Super + Ctrl + Alt + C` لقطة شاشة |

تمنحك إضافة `Alt` إلى مفتاح اختصار نسخة مختلفة من الشيء نفسه، وليس شيئًا غير مرتبط به أبدًا:

- `Super + Shift + B` يفتح المتصفح؛ `Super + Shift + Alt + B` يفتح نافذة خاصة
- `Super + Shift + E` يفتح البريد الإلكتروني؛ `Super + Shift + Alt + E` يبدأ بريدًا إلكترونيًا جديدًا
- `Super + F` ينتقل إلى ملء الشاشة؛ `Super + Alt + F` ينتقل إلى ملء العرض
- `Super + Ctrl + C` يفتح قائمة الالتقاط؛ `Super + Ctrl + Alt + C` يتخطى القائمة ويلتقط لقطة شاشة

عند إضافة مفتاح اختصار:

1. اختر المستوى بناءً على ما يفعله، ثم اختر المفتاح.
2. لا تنقل مفتاح اختصار حاليًا لإفساح المجال. ابحث عن مفتاح حر على المستوى الصحيح.
3. لا تستخدم `Alt` إلا لنسخة مختلفة من مفتاح الاختصار بدونه.

تخالف بعض مفاتيح الاختصار هذه القواعد لأنها مريحة. فاستخدام `Shift` مع سهم أو `Tab` ينقل أو يعكس بدلاً من فتح تطبيق، وتعمل `Print` ومفاتيح الوسائط و`Alt + Tab` و`Ctrl + Alt + Del` بالطريقة نفسها التي تعمل بها في كل مكان آخر. إنها استثناءات، وليست أنماطًا للنسخ.

إذا لم يناسبك إعداد افتراضي (لنقل إنك تريد `Super + Shift + S` لالتقاط لقطات الشاشة كما في Windows)، فأعد ربطه في `~/.config/hypr/bindings.lua`.

| `Super + Alt + Scroll Wheel` | التنقّل بين النوافذ في التجميع |
| `Super + Alt + 1/2/3/4/5`               | الانتقال إلى نافذة محددة في التجميع      |
| `Super + Alt + Arrow`  | نقل النافذة إلى التجميع في اتجاه السهم، بما في ذلك واحدة على الشاشة الموجودة على ذلك الجانب |

| `Super + /` | التقدم عبر خيارات تحجيم الشاشة |
| `Super + Alt + /` | التراجع عبر خيارات تحجيم الشاشة |
| `Alt + Tab` | التنقّل للأمام عبر النوافذ على مساحة العمل النشطة |
| `Alt + Shift + Tab` | التنقّل للخلف عبر النوافذ على مساحة العمل النشطة |
| `Ctrl + Alt + Tab`| التنقّل بالتركيز للأمام عبر الشاشات |
| `Ctrl + Alt + Shift + Tab`| التنقّل بالتركيز للخلف عبر الشاشات |

تستخدم اختصارات تغيير الحجم المفاتيح الفعلية `code:20` و`code:21` (XKB `<AE11>` و`<AE12>`)، بغض النظر عن الأحرف المطبوعة على لوحة المفاتيح. على لوحات المفاتيح الأمريكية هذه المفاتيح هي `-` و`=`؛ وعلى لوحات المفاتيح اليابانية (JIS) هي `-` و`^`؛ وعلى لوحات المفاتيح الإسبانية هي `'` و`¡`. على JIS، يكون `Super + ^` هو `Super + Equal`، بينما يكون `Super + Shift + -` (الذي يكتب `=`) هو `Super + Shift + Minus`.
