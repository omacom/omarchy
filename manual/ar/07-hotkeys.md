# مفاتيح الاختصار

يمكنك رؤية جميع روابط المفاتيح الرئيسية باستخدام `Super + K` (روابط Tmux باستخدام `Super + Alt + K` وروابط Herdr باستخدام `Super + Ctrl + K`).

## كيفية تنظيم مفاتيح الاختصار

كل مفتاح اختصار يقع على مستوى، تحدده مفاتيح التعديل الخاصة به، ولكل مستوى وظيفة واحدة. هذا ما يمنع مفاتيح الاختصار من الاختلاط ببعضها، ويعني أنك تستطيع عادةً تخمين أين يوجد الشيء.

| المستوى | ما يوجد هناك | أمثلة |
| --- | --- | --- |
| `Super + key` | النظام: النوافذ ومساحات العمل والتخطيطات والقوائم الأساسية | `Super + Space` قائمة Omarchy، `Super + W` إغلاق النافذة، `Super + F` ملء الشاشة |
| `Super + Shift + key` | التطبيقات | `Super + Shift + B` المتصفح، `Super + Shift + E` البريد الإلكتروني، `Super + Shift + N` المحرر |
| `Super + Ctrl + key` | اللوحات وقوائم النظام | `Super + Ctrl + A` الصوت، `Super + Ctrl + N` الشبكة، `Super + Ctrl + C` قائمة الالتقاط |
| `Super + Ctrl + Alt + key` | الإجراءات السريعة والتنبيهات | `Super + Ctrl + Alt + T` إظهار الوقت، `Super + Ctrl + Alt + B` البطارية، `Super + Ctrl + Alt + C` لقطة الشاشة |

إضافة `Alt` إلى مفتاح اختصار يمنحك نسخة مختلفة من الشيء نفسه، وليس أبداً شيئاً لا علاقة له به:

- `Super + Shift + B` يفتح المتصفح؛ `Super + Shift + Alt + B` يفتح نافذة خاصة
- `Super + Shift + E` يفتح البريد الإلكتروني؛ `Super + Shift + Alt + E` يبدأ بريداً إلكترونياً جديداً
- `Super + F` يذهب إلى ملء الشاشة؛ `Super + Alt + F` يذهب إلى العرض الكامل
- `Super + Ctrl + C` يفتح قائمة الالتقاط؛ `Super + Ctrl + Alt + C` يتخطى القائمة ويلتقط لقطة شاشة

عند إضافة مفتاح اختصار:

1. اختر المستوى بناءً على ما يفعله، ثم اختر المفتاح.
2. لا تنقل مفتاح اختصار موجوداً لإفساح المجال. اعثر على مفتاح حر على المستوى الصحيح.
3. لا تستخدم `Alt` إلا لنسخة مختلفة من مفتاح الاختصار بدونه.

بعض مفاتيح الاختصار تكسر هذه القواعد لأنها مريحة. `Shift` مع سهم أو `Tab` ينقل أو يعكس بدلاً من فتح تطبيق، و`Print` ومفاتيح الوسائط و`Alt + Tab` و`Ctrl + Alt + Del` تعمل بالطريقة نفسها في كل مكان آخر. إنها استثناءات، وليست أنماطاً للنسخ.

إذا لم يناسبك إعداد افتراضي (مثلاً تريد `Super + Shift + S` للقطات الشاشة كما في Windows)، أعد ربطه في `~/.config/hypr/bindings.lua`.

على لوحة اللمس، تُبدّل السحبات بثلاثة وأربعة أصابع مساحات العمل، وتنقل النوافذ، وتفتح القائمة ووحدة تحكم Quake؛ راجع [لوحة المفاتيح والفأرة ولوحة اللمس](34-keyboard-mouse-trackpad.md) للاطلاع على الإيماءات.

تستخدم اختصارات تغيير الحجم المفاتيح الفعلية `code:20` و`code:21` (XKB `<AE11>` و`<AE12>`)، بغض النظر عن الأحرف المطبوعة على لوحة المفاتيح. على لوحات المفاتيح الأمريكية هذه المفاتيح هي `-` و`=`؛ وعلى لوحات المفاتيح اليابانية (JIS) هي `-` و`^`؛ وعلى لوحات المفاتيح الإسبانية هي `'` و`¡`. على JIS، يكون `Super + ^` هو `Super + Equal`، بينما `Super + Shift + -` (الذي يكتب `=`) هو `Super + Shift + Minus`.

## Tmux

مفتاح البادئة هو `Ctrl + Space` (`Ctrl + B` يعمل أيضاً). يمكنك تغيير هذه الروابط في `~/.config/tmux/tmux.conf`.

| مفتاح الاختصار                  | الوظيفة              |
