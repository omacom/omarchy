# مفاتيح الاختصار

يمكنك رؤية جميع ارتباطات لوحة المفاتيح الرئيسية باستخدام `Super + K` (وارتباطات Tmux باستخدام `Super + Alt + K` وارتباطات Herdr باستخدام `Super + Ctrl + K`).

## كيف تُنظَّم مفاتيح الاختصار

كل مفتاح اختصار يقع على مستوى تحدّده مفاتيح التعديل الخاصة به، ولكل مستوى مهمة واحدة. هذا ما يمنع مفاتيح الاختصار من الاختلاط ببعضها البعض، ويعني أنك تستطيع عادةً تخمين مكان وجود شيء ما.

| المستوى | ما يوجد فيه | أمثلة |
| --- | --- | --- |
| `Super + key` | النظام: النوافذ ومساحات العمل والتخطيطات والقوائم الأساسية | `Super + Space` قائمة Omarchy، `Super + W` إغلاق النافذة، `Super + F` ملء الشاشة |
| `Super + Shift + key` | التطبيقات | `Super + Shift + B` المتصفح، `Super + Shift + E` البريد الإلكتروني، `Super + Shift + N` المحرر |
| `Super + Ctrl + key` | اللوحات وقوائم النظام | `Super + Ctrl + A` الصوت، `Super + Ctrl + N` الشبكة، `Super + Ctrl + C` قائمة الالتقاط |
| `Super + Ctrl + Alt + key` | إجراءات سريعة وتنبيهات | `Super + Ctrl + Alt + T` إظهار الوقت، `Super + Ctrl + Alt + B` البطارية، `Super + Ctrl + Alt + C` لقطة شاشة |

إضافة `Alt` إلى مفتاح اختصار يمنحك نسخة مختلفة من الشيء نفسه، وليس أبدًا شيئًا غير ذي صلة:

- `Super + Shift + B` يفتح المتصفح؛ `Super + Shift + Alt + B` يفتح نافذة خاصة
- `Super + Shift + E` يفتح البريد الإلكتروني؛ `Super + Shift + Alt + E` يبدأ بريدًا جديدًا
- `Super + F` ينتقل إلى ملء الشاشة؛ `Super + Alt + F` ينتقل إلى ملء العرض
- `Super + Ctrl + C` يفتح قائمة الالتقاط؛ `Super + Ctrl + Alt + C` يتخطى القائمة ويلتقط لقطة شاشة

عند إضافة مفتاح اختصار:

1. اختر المستوى بناءً على ما يفعله، ثم اختر المفتاح.
2. لا تنقل مفتاح اختصار موجودًا لإفساح المجال. ابحث عن مفتاح حر على المستوى الصحيح.
3. استخدم `Alt` فقط لنسخة مختلفة من مفتاح الاختصار بدونه.

بعض مفاتيح الاختصار تكسر هذه القواعد لأنها مريحة. استخدام `Shift` مع سهم أو `Tab` ينقل أو يعكس بدلاً من فتح تطبيق، و`Print` ومفاتيح الوسائط و`Alt + Tab` و`Ctrl + Alt + Del` تعمل بالطريقة نفسها في كل مكان آخر. إنها استثناءات، وليست أنماطًا للنسخ.

إذا لم يناسبك إعداد افتراضي (مثلاً تريد `Super + Shift + S` للقطات الشاشة كما في Windows)، فأعد ربطه في `~/.config/hypr/bindings.lua`.

| `Alt + Tab` | التنقل إلى الأمام عبر النوافذ في مساحة العمل النشطة |
| `Alt + Shift + Tab` | التنقل إلى الخلف عبر النوافذ في مساحة العمل النشطة |

| `Ctrl + Alt + Shift + Tab`| نقل التركيز إلى الخلف عبر الشاشات |

تستخدم اختصارات تغيير الحجم المفاتيح الفيزيائية `code:20` و`code:21` (‏XKB ‏`<AE11>` و`<AE12>`)، بغض النظر عن الأحرف المطبوعة على لوحة المفاتيح. على لوحات المفاتيح الأمريكية هذه المفاتيح هي `-` و`=`؛ وعلى لوحات المفاتيح اليابانية (JIS) هي `-` و`^`؛ وعلى لوحات المفاتيح الإسبانية هي `'` و`¡`. على JIS، `Super + ^` هو `Super + Equal`، بينما `Super + Shift + -` (الذي يكتب `=`) هو `Super + Shift + Minus`.

| مفتاح الاختصار                  | الوظيفة              |
| ----------------------- | --------------------- |
| `Super + A`           | تحديد الكل في التطبيقات التي تدعم `Ctrl + A`    |
