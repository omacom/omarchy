# اختصارات لوحة المفاتيح

يمكنك رؤية جميع روابط لوحة المفاتيح الرئيسية باستخدام `Super + K` (روابط Tmux باستخدام `Super + Alt + K` وروابط Herdr باستخدام `Super + Ctrl + K`).

## كيفية توزيع اختصارات لوحة المفاتيح

يقع كل اختصار ضمن مستوى تحدّده مفاتيح التعديل الخاصة به، ولكل مستوى وظيفة واحدة. وهذا ما يمنع اختلاط الاختصارات ببعضها، ويعني أنك تستطيع عادةً تخمين موضع أي شيء.

| المستوى | ما يوجد هناك | أمثلة |
| --- | --- | --- |
| `Super + key` | النظام: النوافذ ومساحات العمل والتخطيطات والقوائم الأساسية | `Super + Space` قائمة Omarchy، `Super + W` إغلاق النافذة، `Super + F` ملء الشاشة |
| `Super + Shift + key` | التطبيقات | `Super + Shift + B` المتصفح، `Super + Shift + E` البريد الإلكتروني، `Super + Shift + N` المحرر |
| `Super + Ctrl + key` | اللوحات وقوائم النظام | `Super + Ctrl + A` الصوت، `Super + Ctrl + N` الشبكة، `Super + Ctrl + C` قائمة الالتقاط |
| `Super + Ctrl + Alt + key` | الإجراءات السريعة والتنويهات | `Super + Ctrl + Alt + T` إظهار الوقت، `Super + Ctrl + Alt + B` البطارية، `Super + Ctrl + Alt + C` لقطة شاشة |

يمنحك إضافة `Alt` إلى اختصار نسخة مختلفة من الشيء نفسه، وليس أبدًا شيئًا غير ذي صلة:

- `Super + Shift + B` يفتح المتصفح؛ و`Super + Shift + Alt + B` يفتح نافذة خاصة
- `Super + Shift + E` يفتح البريد الإلكتروني؛ و`Super + Shift + Alt + E` يبدأ رسالة جديدة
- `Super + F` ينتقل إلى ملء الشاشة؛ و`Super + Alt + F` ينتقل إلى العرض الكامل
- `Super + Ctrl + C` يفتح قائمة الالتقاط؛ و`Super + Ctrl + Alt + C` يتخطى القائمة ويلتقط لقطة شاشة

عند إضافة اختصار:

1. اختر المستوى بناءً على ما يفعله، ثم اختر المفتاح.
2. لا تنقل اختصارًا موجودًا لتفسح له مكانًا. ابحث عن مفتاح حر في المستوى الصحيح.
3. لا تستخدم `Alt` إلا لنسخة مختلفة من الاختصار الذي بدونه.

تخالف بعض الاختصارات هذه القواعد لأنها مريحة. فمفتاح `Shift` مع سهم أو `Tab` ينقل أو يعكس بدلًا من فتح تطبيق، و`Print` ومفاتيح الوسائط و`Alt + Tab` و`Ctrl + Alt + Del` تعمل بالطريقة نفسها التي تعمل بها في كل مكان آخر. إنها استثناءات، وليست أنماطًا للنسخ.

إذا لم يناسبك اختصار افتراضي (لنقل إنك تريد `Super + Shift + S` للقطات الشاشة كما في Windows)، فأعد ربطه في `~/.config/hypr/bindings.lua`.

| `Super + Right Mouse` | تغيير حجم النافذة |
| `Super + Scroll Wheel` | التمرير عبر مساحات العمل على الشاشة المركّز عليها |
| `Super + G` | تبديل تجميع النوافذ |
| `Super + Alt + G` | إخراج النافذة من التجميع |

| `Super + Alt + Shift + Tab` | التنقّل للخلف بين النوافذ داخل التجميع |
| `Super + Alt + Scroll Wheel` | التنقّل بين النوافذ داخل التجميع |
| `Super + Alt + 1/2/3/4/5` | الانتقال إلى نافذة محددة داخل التجميع |
| `Super + Alt + Arrow` | نقل النافذة إلى التجميع في اتجاه السهم، بما في ذلك واحدة على الشاشة على ذلك الجانب |
| `Super + Ctrl + Left/Right` | التنقّل بين النوافذ داخل مجموعة متجانبة |
| `Super + Ctrl + Z` | تكبير الشاشة (كرّر للمزيد من التكبير) |
| `Super + Ctrl + Alt + Z` | إبعاد الشاشة بالكامل |
| `Super + /` | التقدم عبر خيارات تحجيم الشاشة |
| `Super + Alt + /` | الرجوع عبر خيارات تحجيم الشاشة |
| `Alt + Tab` | التنقّل للأمام عبر النوافذ في مساحة العمل النشطة |
| `Alt + Shift + Tab` | التنقّل للخلف عبر النوافذ في مساحة العمل النشطة |
| `Ctrl + Alt + Tab` | تنقّل التركيز للأمام عبر الشاشات |
| `Ctrl + Alt + Shift + Tab` | تنقّل التركيز للخلف عبر الشاشات |

تستخدم اختصارات تغيير الحجم المفاتيح الفعلية `code:20` و`code:21` (أي XKB `<AE11>` و`<AE12>`), بغض النظر عن الأحرف المطبوعة على لوحة المفاتيح. على لوحات المفاتيح الأمريكية، هذان المفتاحان هما `-` و`=`; وعلى لوحات المفاتيح اليابانية (JIS), هما `-` و`^`; وعلى لوحات المفاتيح الإسبانية، هما `'` و`¡`. على JIS، يكون `Super + ^` هو `Super + Equal`، بينما `Super + Shift + -` (الذي يكتب `=`) هو `Super + Shift + Minus`.

### دوال تخطيط Tmux

يجب تشغيل هذه الدوال داخل جلسة Tmux.

| الأمر | الوظيفة |
