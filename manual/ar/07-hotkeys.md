# اختصارات المفاتيح

يمكنك رؤية كل روابط لوحة المفاتيح الرئيسية بـ `Super + K` (روابط Tmux بـ `Super + Alt + K` وروابط Herdr بـ `Super + Ctrl + K`).

## التنقّل

| المفتاح السريع                  | الوظيفة              |
| ----------------------- | --------------------- |
| `Super + Space`           | قائمة Omarchy (التطبيقات وكل شيء آخر)    |
| `Super + Alt + Space` | شبكة التطبيقات |
| `Super + Escape` | قائمة النظام (تعليق، إعادة تشغيل، إلخ)  |
| `Super + Ctrl + L` | قفل الكمبيوتر |
| `Super + W` or `Super + Q` | إغلاق النافذة             |
| `Ctrl + Alt + Del` | إغلاق كل النوافذ |
| `Super + T`               | تبديل النافذة بين التبليط/العوم             |
| `Super + J` | تبديل موضع النافذة (أفقي/عمودي) |
| `Super + O`               | تبديل إخراج النافذة إلى لاصقة وعائمة |
| `Super + L`               | التدوير عبر تخطيطات dwindle والتمرير والعائم |
| `Super + Alt + L`         | التدوير عبر التخطيطات عكسيًا |
| `Super + P`               | تبديل نمط النافذة الزائفة (طبيعي مقابل ممتد) |
| `Super + F`                 | الذهاب إلى ملء الشاشة              |
| `Super + Alt + F`                 | الذهاب إلى ملء العرض              |
| `Super + Ctrl + F`                 | الذهاب إلى ملء الشاشة داخل النافذة              |
| `Super + 1/2/3/4`         | القفز إلى مساحة عمل محددة     |
| `Super + Tab` | القفز إلى مساحة العمل التالية |
| `Super + Shift + Tab` | القفز إلى مساحة العمل السابقة |
| `Super + Ctrl + Tab` | القفز إلى مساحة العمل السابقة زمنيًا |
| `Super + Shift + 1/2/3/4` | نقل النافذة إلى مساحة عمل |
| `Super + Shift + Alt + 1/2/3/4` | نقل النافذة إلى مساحة عمل دون اتباعها |
| `Super + S` / `Super + Grave` | تبديل المسودة |
| `Super + Alt + S` / `Super + Shift + Grave` | نقل النافذة إلى المسودة |
| `Super + Shift + Alt + Arrows` | نقل مساحات العمل إلى شاشة اتجاهية |
| `Super + Arrow`  | نقل التركيز إلى نافذة في اتجاه السهم              |
| `Super + Shift + Arrow`  | مبادلة النافذة مع أخرى في اتجاه السهم     |
| `Super + Minus` | توسيع النافذة يسارًا |
| `Super + Equal` | تقليص النافذة يسارًا |
| `Super + Shift + Minus` | تقليص النافذة لأعلى |
| `Super + Shift + Equal` | توسيع النافذة لأسفل |
| `Super + Alt + Minus/Equal` | نفس تغيير الحجم بخطوات أصغر |
| `Super + Ctrl + Minus/Equal` | نفس تغيير الحجم بخطوات أكبر |
| `Super + Alt + Home` | حفظ عرض النافذة |
| `Super + Home` | استعادة عرض النافذة المحفوظ |
| `Super + Left Mouse` | سحب النافذة حولها |
| `Super + Right Mouse` | تغيير حجم النافذة |
| `Super + Scroll Wheel` | التمرير عبر مساحات العمل |
| `Super + G`               | تبديل تجميع النوافذ      |
| `Super + Alt + G`               | نقل النافذة خارج التجميع      |
| `Super + Alt + Tab`               | التدوير بين النوافذ في التجميع      |
| `Super + Alt + Shift + Tab`               | التدوير للخلف بين النوافذ في التجميع      |
| `Super + Alt + 1/2/3/4/5`               | القفز إلى نافذة محددة في التجميع      |
| `Super + Alt + Arrow`  | نقل النافذة إلى التجميع في اتجاه السهم  |
| `Super + Ctrl + Left/Right`  | التنقّل بين النوافذ داخل مجموعة تبليط |
| `Super + Ctrl + Z` | التكبير على الشاشة (كرّر لتكبير أكثر) |
| `Super + Ctrl + Alt + Z` | التصغير بالكامل من الشاشة |
| `Super + /` | التقدّم خطوة عبر خيارات تحجيم الشاشة |
| `Super + Alt + /` | التراجع خطوة عبر خيارات تحجيم الشاشة |
| `Alt + Tab` | التدوير للأمام عبر النوافذ على مساحة العمل النشطة |
| `Alt + Shift + Tab` | التدوير للخلف عبر النوافذ على مساحة العمل النشطة |
| `Ctrl + Alt + Tab`| تدوير التركيز للأمام عبر الشاشات |
| `Ctrl + Alt + Shift + Tab`| تدوير التركيز للخلف عبر الشاشات |

## الالتقاط

| المفتاح السريع              | الوظيفة                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | قائمة الالتقاط (للوحات المفاتيح بدون زر PrintScr) |
| `Print Screen`            | لقطة شاشة                      |
| `Alt + Print Screen`            | تسجيل شاشة                     |
| `Super + Print Screen` | منتقي الألوان |
| `Super + Ctrl + Print Screen` | استخراج النص إلى الحافظة |
| `Super + Alt + [` | تصغير تراكب كاميرا الويب أثناء التسجيل |
| `Super + Alt + ]` | تكبير تراكب كاميرا الويب أثناء التسجيل |
| `Alt + Shift + L` | نسخ URL الحالي من تطبيق الويب أو Chromium |
| `Alt + Shift + D` | تنزيل الفيديو على الصفحة الحالية إلى `~/Videos` |
| `Super + Ctrl + X` | بدء/إيقاف الإملاء (يتطلّب _الإعداد > الافتراضية > الإملاء_) |
| `Right Alt` / `F9` | إملاء اضغط للتحدّث (يتطلّب Voxtype أو Superwhisper) |

مع تسجيلات الشاشة، يسأل المفتاح السريع أولًا أي صوت تريده، ثم يبدأ التسجيل. اضغطه مرة أخرى للإيقاف. راجع [لقطات الشاشة والتسجيل](12-screenshots-recording.md) للتفاصيل.

كل خيارات الالتقاط متاحة أيضًا تحت _تشغيل > التقاط_ في قائمة Omarchy (`Super + Space`).

## Tmux

مفتاح البادئة هو `Ctrl + Space` (`Ctrl + B` يعمل أيضًا). يمكنك تغيير هذه الروابط في `~/.config/tmux/tmux.conf`.

### الألواح

| المفتاح السريع                  | الوظيفة              |
| ----------------------- | --------------------- |
| `Prefix + v` | تقسيم اللوح بجانب (عمودي) |
| `Prefix + h` | تقسيم اللوح أسفل (أفقي) |
| `Prefix + x` | قتل اللوح |
| `Prefix + z` | تبديل تكبير اللوح (ملء الشاشة) |
| `Alt + Enter` | تقسيم اللوح أسفل (بدون بادئة) |
| `Alt + Shift + Enter` | تقسيم اللوح بجانب (بدون بادئة) |
| `Alt + Escape` | قتل اللوح (بدون بادئة) |
| `Ctrl + Alt + Arrows` | التنقّل بين الألواح |
| `Ctrl + Alt + Shift + Arrows` | تغيير حجم الألواح |

### النوافذ

| المفتاح السريع                  | الوظيفة              |
| ----------------------- | --------------------- |
| `Prefix + c` | نافذة جديدة |
| `Prefix + k` | قتل النافذة |
| `Prefix + r` | إعادة تسمية النافذة |
| `Alt + 1-9` | الذهاب إلى نافذة محددة |
| `Alt + Arrow Left/Right` | التنقّل بين النوافذ |
| `Alt + Shift + Arrow Left/Right` | نقل النافذة يسارًا/يمينًا |

### الجلسات

| المفتاح السريع                  | الوظيفة              |
| ----------------------- | --------------------- |
| `Prefix + C` | جلسة جديدة |
| `Prefix + K` | قتل الجلسة |
| `Prefix + R` | إعادة تسمية الجلسة |
| `Prefix + N` | الجلسة التالية |
| `Prefix + P` | الجلسة السابقة |
| `Alt + Arrow Up/Down` | التنقّل بين الجلسات |
| `Prefix + s` | سرد الجلسات |
| `Prefix + d` | الانفصال عن الجلسة |

### وضع النسخ (بنمط vi)

| المفتاح السريع                  | الوظيفة              |
| ----------------------- | --------------------- |
| `Prefix + [` | الدخول إلى وضع النسخ |
| `v` | بدء التحديد (في وضع النسخ) |

### عام

| المفتاح السريع                  | الوظيفة              |
| ----------------------- | --------------------- |
| `Prefix + q` | إعادة تحميل التكوين |
| `Prefix + ?` | إظهار روابط مفاتيح Tmux |
| `Prefix + :` | موجّه الأوامر |

### دوال تخطيط Tmux

يجب تشغيل هذه الدوال داخل جلسة Tmux.

| الأمر | الوظيفة |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | إنشاء تخطيط تطوير مع المحرّر وAI والطرفية |
| `tdlm <ai> [<second_ai>]` | إنشاء تخطيط تطوير لكل دليل فرعي |
| `tsl <count> <command>` | إنشاء تخطيط سرب متعدد الألواح |
