# اختصارات لوحة المفاتيح

يمكنك رؤية جميع ارتباطات لوحة المفاتيح الرئيسية باستخدام `Super + K` (ارتباطات Tmux باستخدام `Super + Alt + K` وارتباطات Herdr باستخدام `Super + Ctrl + K`).

## كيفية تنظيم اختصارات لوحة المفاتيح

كل اختصار يقع على مستوى، تحدده مفاتيح التعديل الخاصة به، ولكل مستوى مهمة واحدة. هذا ما يمنع اختصارات لوحة المفاتيح من الاختلاط ببعضها، ويعني أنك تستطيع عادةً تخمين مكان وجود أي شيء.

| المستوى | ما يوجد هناك | أمثلة |
| --- | --- | --- |
| `Super + key` | النظام: النوافذ ومساحات العمل والتخطيطات والقوائم الأساسية | `Super + Space` قائمة Omarchy، `Super + W` إغلاق النافذة، `Super + F` ملء الشاشة |
| `Super + Shift + key` | التطبيقات | `Super + Shift + B` المتصفح، `Super + Shift + E` البريد الإلكتروني، `Super + Shift + N` المحرر |
| `Super + Ctrl + key` | اللوحات وقوائم النظام | `Super + Ctrl + A` الصوت، `Super + Ctrl + N` الشبكة، `Super + Ctrl + C` قائمة الالتقاط |
| `Super + Ctrl + Alt + key` | الإجراءات السريعة والتنبيهات | `Super + Ctrl + Alt + T` عرض الوقت، `Super + Ctrl + Alt + B` البطارية، `Super + Ctrl + Alt + C` لقطة الشاشة |

إضافة `Alt` إلى اختصار تمنحك نسخة مختلفة من الشيء نفسه، وليس شيئًا غير ذي صلة أبدًا:

- `Super + Shift + B` يفتح المتصفح؛ `Super + Shift + Alt + B` يفتح نافذة خاصة
- `Super + Shift + E` يفتح البريد الإلكتروني؛ `Super + Shift + Alt + E` يبدأ بريدًا إلكترونيًا جديدًا
- `Super + F` ينتقل إلى ملء الشاشة؛ `Super + Alt + F` ينتقل إلى العرض الكامل
- `Super + Ctrl + C` يفتح قائمة الالتقاط؛ `Super + Ctrl + Alt + C` يتخطى القائمة ويلتقط لقطة شاشة

عند إضافة اختصار:

1. اختر المستوى بناءً على ما يفعله، ثم اختر المفتاح.
2. لا تنقل اختصارًا موجودًا لإفساح المجال. اعثر على مفتاح حر على المستوى الصحيح.
3. استخدم `Alt` فقط لنسخة مختلفة من الاختصار بدونه.

بعض الاختصارات تخالف هذه القواعد لأنها مريحة. `Shift` مع سهم أو `Tab` ينقل أو يعكس بدلاً من فتح تطبيق، و`Print` ومفاتيح الوسائط و`Alt + Tab` و`Ctrl + Alt + Del` تعمل كما تعمل في كل مكان آخر. إنها استثناءات، وليست أنماطًا للنسخ.

إذا لم يناسبك اختصار افتراضي (لنقل إنك تريد `Super + Shift + S` للقطات الشاشة كما في Windows)، أعد ربطه في `~/.config/hypr/bindings.lua`.

على لوحة اللمس، تقوم إيماءات التمرير بثلاثة وأربعة أصابع بتبديل مساحات العمل ونقل النوافذ وفتح القائمة ووحدة تحكم Quake؛ راجع [لوحة المفاتيح والفأرة ولوحة اللمس](34-keyboard-mouse-trackpad.md) للإيماءات.

تستخدم اختصارات تغيير الحجم المفاتيح الفعلية `code:20` و`code:21` (XKB `<AE11>` و`<AE12>`)، بغض النظر عن الأحرف المطبوعة على لوحة المفاتيح. على لوحات المفاتيح الأمريكية هذه المفاتيح هي `-` و`=`؛ على لوحات المفاتيح اليابانية (JIS) هي `-` و`^`؛ على لوحات المفاتيح الإسبانية هي `'` و`¡`. على JIS، يكون `Super + ^` هو `Super + Equal`، بينما `Super + Shift + -` (الذي يكتب `=`) هو `Super + Shift + Minus`.
