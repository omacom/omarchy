# Podsjetnici

Omarchy ima ugrađen način postavljanja jednostavnih podsjetnika temeljenih na odbrojavalici i poruci. To možete učiniti pomoću `Super + Ctrl + R`, pregledati sve postavljene pomoću `Super + Ctrl + Alt + R` i izbrisati sve pomoću `Super + Ctrl + Shift + R`. Sve je dostupno i putem _Pokreni > Podsjetnik_. Možete koristiti i cli s `omarchy reminder 7 'Tea ready'`.
