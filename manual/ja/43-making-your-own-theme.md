# 自分だけのテーマを作る

独自のテーマは `~/.config/omarchy/themes` に追加できます。既存のテーマのいずれかをベースとしてコピーし（`/usr/share/omarchy/themes` を見てください）、思う存分調整してください。テーマがそのフォルダの中にある限り、テーマ選択メニューに表示されます。

調整する必要がある主なファイルは `colors.toml` です。そこで定義されたカラーセットを使って、ターミナル（Foot/Alacritty/Ghostty/Kitty）、btop、Chromium、Hyprland、Neovim、Helix、VSCode、Obsidian、Qt アプリ、キーボードのバックライト、入力メソッド、画面共有ピッカー、アプリアイコン、いくつかの AI ツール（Claude、Pi、Hermes、T3 Code、Herdr）、そして Omarchy シェル全体（トップバー、メニュー、通知、OSD、ロック画面）の設定が生成されます。

同梱の Aether アプリケーションを使って、新しいテーマを作成することもできます。素敵な GUI インターフェースで色を試したり、背景を検索したりできます。`Super + Alt + Space` でアプリグリッドから起動するだけです。

### インストールしたテーマに含められるもの

`~/.config/omarchy/themes` に自分で書いたテーマには、好きなものを何でも含められます。あなたのマシンであり、あなたのファイルなのですから。Omarchy はそのすべてを適用します。

`omarchy theme install` で他人のリポジトリからインストールしたテーマでは、色に関するものはすべて保持され、あなたのマシンでコードを実行することになる一握りのファイルだけが失われます。あらゆる `.lua` ファイル、ターミナル設定（`alacritty.toml`、`foot.ini`、`ghostty.conf`、`kitty.conf`）、そして `vscode.json` です。テーマの `hyprland.lua` はログイン時にコンポジタが実行する Lua であり、ターミナル設定はターミナルが起動するプログラムを指定し、`vscode.json` はインストールする VSCode 拡張機能を指定します。他人のテーマをインストールすることで変わるべきなのは、デスクトップの見た目であって、実行されるものではありません。

それ以外のものはすべて、テーマの作者が書いたとおりに機能します。`btop.theme`、`chromium.theme`、`helix.toml`、`shell.toml`、背景とプレビューはすべて保持されます。削除されたものだけが、あなたのマシン上で `colors.toml` から再生成されます。

Omarchy は、テーマの中に独自の git リポジトリがあるかどうかで、この2つを区別します。それは `omarchy theme install` がクローンしたときに残すものです。つまり、自分で書いたテーマはあなたのもののまま、インターネットから取得したものは色だけに制限されます。

### ライトモード

ライトモードのテーマを作る場合は、`colors.toml` の先頭に `mode = "light"` と設定してください。そうすれば、すべてのアプリで自動的にライトモードと組み合わされます。（テーマのルートに `light.mode` という空のファイルを置く従来の方法も引き続き使えます。）

### ロック解除画像

`unlock.png` と `preview-unlock.png` の画像が用意されたテーマは、_外観 > ロック解除_ の下に表示されます。`unlock.png` は透明な png が望ましいです。プレビュー画像は `omarchy plymouth preview` を使って作成できます。

### Omarchy が対応していないアプリのテーマ設定

その一覧にないアプリを使っている場合は、テンプレートを使って Omarchy にそのアプリのテーマ設定方法を自分で教えることができます。生成する設定ファイルの名前に `.tpl` 拡張子を付けたファイルを `~/.config/omarchy/themed/` に置き、`{{ background }}`、`{{ foreground }}`、`{{ accent }}`、`{{ red }}`、`{{ color0 }}` から `{{ color15 }}` まで、そしてパレットの残りをプレースホルダーとして使って設定を書いてください。テーマを切り替えるたびに、そのテーマの色でファイルが再生成されます。

そのフォルダには、コピー元として使える、完全にコメント付きの `alacritty.toml.tpl.sample` があります。使用できるすべての変数が一覧になっており、色を `#` なしで、または10進数の RGB で必要とするアプリ向けの `_strip` 修飾子と `_rgb` 修飾子についても記載されています。あなたのテンプレートは Omarchy 自身のものより優先されるため、これを使って組み込みアプリのテーマ設定方法を上書きすることもできます。

### テーマを配布する

自分のテーマを配布して他の人に使ってもらいたい場合は、GitHub のような公開 git サーバーに置く必要があります。そうすれば、その URL を使って、Omarchy メニューの _インストール > スタイル > テーマ_ からインストールできるようになります。命名規則として `omarchy-[themename]-theme` に従うことをおすすめします。インストール後、テーマ選択メニューでテーマが単に `[themename]` と正しく表示されるためです。

残りの `[themename]` がテーマのディレクトリ名になるため、Omarchy が安全に扱えるものでなければなりません。先頭は英字、数字、またはアンダースコアでなければならず、残りの部分には英字、数字、`.`、`_`、`+`、`-` を含めることができます。大文字は自動的に小文字に変換されますが、それ以外のもの（空白、引用符、英語以外の文字）はディレクトリ名に変換されるのではなく、インストール時に拒否されます。したがって、`omarchy-tokyo-night-theme`、`omarchy-flexoki_light-theme`、`omarchy-c++-theme` はすべて問題なくインストールできます。

リポジトリからインストールされると、同梱されているあらゆる `.lua`、ターミナル設定、または `vscode.json` は削除されることを覚えておいてください。ですから、テーマをそれらを中心に構築しないでください。

[omarchy-site リポジトリ](https://github.com/omacom-io/omarchy-site) にプルリクエストを送ることで、自分のテーマを[追加テーマのページ](https://omarchy.org/themes/)に追加してもらえます。
