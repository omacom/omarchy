# 独自のテーマを作る

`~/.config/omarchy/themes` に独自のテーマを追加できます。既存のテーマのどれかをベースとしてコピーし（`/usr/share/omarchy/themes` を見てください）、好きなように調整するだけです。テーマがそのフォルダの中にあれば、テーマ選択メニューに表示されます。

主に調整する必要があるファイルは `colors.toml` です。これで色のセットを定義し、それをもとにターミナル（Foot/Alacritty/Ghostty/Kitty）、btop、Chromium、Hyprland、Neovim、Helix、VSCode、Obsidian、Qt アプリ、キーボードのバックライト、入力メソッド、画面共有ピッカー、アプリアイコン、いくつかの AI ツール（Claude、Pi、Hermes、T3 Code、Herdr）、そして Omarchy シェル全体（トップバー、メニュー、通知、OSD、ロック画面）の設定が生成されます。

付属の Aether アプリケーションを使って、新しいテーマを作成することもできます。素敵な GUI インターフェースで色を試したり、背景を探したりできます。`Super + Alt + Space` でアプリグリッドから起動するだけです。

### インストールしたテーマに含められるもの

`~/.config/omarchy/themes` に自分で書いたテーマには、好きなものを何でも含められます。あなたのマシンであり、あなたのファイルなのですから、Omarchy はそのすべてを適用します。

`omarchy theme install` で他人のリポジトリからインストールしたテーマでは、色に関するものはすべて保持されますが、マシン上でコードを実行することになる一握りのファイルは失われます。任意の `.lua` ファイル、ターミナル設定（`alacritty.toml`、`foot.ini`、`ghostty.conf`、`kitty.conf`）、そして `vscode.json` です。テーマの `hyprland.lua` はログイン時にコンポジタが実行する Lua であり、ターミナル設定はターミナルが起動するプログラムを指定し、`vscode.json` はインストールする VSCode 拡張機能を指定します。他人のテーマをインストールしても変わるべきなのはデスクトップの見た目だけであり、実行されるものが変わってはなりません。

それ以外のものはすべて、テーマの作者が書いたとおりにそのまま動作します。`btop.theme`、`chromium.theme`、`helix.toml`、`shell.toml`、背景、プレビューはすべて保持されます。削除されたものだけが、あなたのマシン上で `colors.toml` から再生成されます。

Omarchy は、テーマの中に独自の git リポジトリがあるかどうかでこの2つを区別します。それは `omarchy theme install` がクローンしたときに残すものです。つまり、自分で書いたテーマはあなたのもののままであり、インターネットから取得したテーマは色だけに留まります。

### ライトモード

ライトモードのテーマを作る場合は、`colors.toml` の先頭に `mode = "light"` と設定してください。そうすれば、すべてのアプリでライトモードと自動的に組み合わされます。（テーマのルートに `light.mode` という空のファイルを置くという従来の方法も引き続き使えます。）

### 起動画面とログイン画面

起動時にドライブのパスワードを尋ねる画面とログイン画面では、テーマの `background` の上に `accent` 色で Omarchy のロゴを描画し、パスワードフィールドには `foreground` を、パスワードが間違っている場合には `red` を使います。これらのために追加で同梱するものは何もありません。Omarchy はテーマの `unlock.png` や `preview-unlock.png` をもはや使いません。Apple Silicon 搭載 Mac では、ドライブのパスワード画面はテーマによらず Omarchy のデフォルトの見た目を維持します。

### Omarchy が対応していないアプリのテーマ設定

そのリストにないアプリを使っている場合は、テンプレートを使って Omarchy にそのアプリのテーマ設定方法を自分で教えることができます。`~/.config/omarchy/themed/` に、生成する設定ファイルの名前に `.tpl` 拡張子を付けたファイルを置き、`{{ background }}`、`{{ foreground }}`、`{{ accent }}`、`{{ red }}`、`{{ color0 }}` から `{{ color15 }}`、そしてパレットの残りをプレースホルダとして使って設定を書いてください。テーマを切り替えるたびに、そのテーマの色でファイルが再生成されます。

そのフォルダには、コピー元として使える、すべてにコメントが付いた `alacritty.toml.tpl.sample` があります。使用できるすべての変数に加え、`#` なしの色や10進数 RGB としての色を必要とするアプリのための `_strip` 修飾子と `_rgb` 修飾子も列挙されています。あなたのテンプレートは Omarchy 自身のテンプレートより優先されるため、これを使って組み込みアプリのテーマ設定方法を上書きすることもできます。

### テーマを配布する

他の人が使えるようにテーマを配布したい場合は、GitHub のような公開 git サーバーに置く必要があります。そうすれば、その URL を使って、Omarchy メニューの _Install > Style > Theme_ からインストールできるようになります。命名規則として `omarchy-[themename]-theme` に従うことをおすすめします。インストール後、テーマ選択メニューでテーマが単に `[themename]` と正しく表示されるようになるためです。

残った `[themename]` がテーマのディレクトリ名になるため、Omarchy が安全に扱えるものでなければなりません。先頭は文字、数字、またはアンダースコアでなければならず、それ以降には文字、数字、`.`、`_`、`+`、`-` を含めることができます。大文字は自動的に小文字に変換されますが、それ以外のもの（スペース、引用符、非英語文字など）はディレクトリ名に変換されるのではなく、インストール時に拒否されます。そのため、`omarchy-tokyo-night-theme`、`omarchy-flexoki_light-theme`、`omarchy-c++-theme` はすべて問題なくインストールできます。

リポジトリからインストールされると、同梱されている `.lua`、ターミナル設定、`vscode.json` はすべて削除されることを覚えておいてください。そのため、それらを中心にテーマを構築しないでください。

[omarchy-site リポジトリ](https://github.com/omacom-io/omarchy-site) に pull request を送ることで、あなたのテーマを[追加テーマのページ](https://omarchy.org/themes/) に追加してもらうことができます。
