# 独自のテーマを作る

`~/.config/omarchy/themes` に独自のテーマを追加できます。既存のテーマのどれかをベースとしてコピーし（`/usr/share/omarchy/themes` を見てください）、あとは好きなように調整するだけです。そのフォルダー内にテーマが入っていれば、テーマ選択メニューに表示されます。

調整する必要がある主なファイルは `colors.toml` です。これがカラーセットを定義し、そこからターミナル（Foot/Alacritty/Ghostty/Kitty）、btop、Chromium、Hyprland、Neovim、Helix、VSCode、Obsidian、そして Omarchy シェル全体（トップバー、メニュー、通知、OSD、ロック画面）の設定が生成されます。

付属の Aether アプリケーションを使って、色をいじったり背景を探したりできる素敵な GUI インターフェースで新しいテーマを作ることもできます。`Super + Alt + Space` でアプリグリッドから起動するだけです。

### インストールしたテーマに含められるもの

`~/.config/omarchy/themes` に自分で書いたテーマには、好きなものを何でも含められます。あなたのマシンで、あなたのファイルなのですから、Omarchy はそのすべてを適用します。

`omarchy theme install` で他人のリポジトリからインストールしたテーマは、色に関するものをすべて保持し、マシン上でコードを実行することになる一握りのファイルを失います。任意の `.lua` ファイル、ターミナル設定（`alacritty.toml`、`foot.ini`、`ghostty.conf`、`kitty.conf`）、そして `vscode.json` です。テーマの `hyprland.lua` はログイン時にコンポジターが実行する Lua で、ターミナル設定はターミナルが起動するプログラムを指定し、`vscode.json` はインストールする VSCode 拡張機能を指定します。他人のテーマをインストールすることで変わるべきなのはデスクトップの見た目であり、実行されるものでは決してありません。

それ以外のものはすべて、テーマの作者が書いたとおりにそのまま動作します。`btop.theme`、`chromium.theme`、`helix.toml`、`icons.theme`、`shell.toml`、背景、プレビューはすべて保持されます。削除されたものだけが、あなたのマシン上で `colors.toml` から再生成されます。

Omarchy は、テーマの中にそれ自体の git リポジトリがあるかどうかで両者を区別します。これは `omarchy theme install` がクローンしたときに残すものです。だから、自分で書いたテーマはあなたのもののままで、インターネットから取得したテーマは色だけに留まります。

### ライトモード

ライトモードのテーマを作る場合は、`colors.toml` の先頭に `mode = "light"` を設定してください。そうすれば、すべてのアプリでライトモードと自動的に組み合わされます。（テーマのルートに `light.mode` という空のファイルを置くという昔の方法も引き続き使えます。）

### アイコンの色

ファイルマネージャーのアイコンをテーマに合わせて色付けしたい場合は、使用したいアイコンセットの名前を書いた `icons.theme` というファイルを追加してください。デフォルトでは、次の選択肢があります： `Yaru Yaru-blue Yaru-dark Yaru-magenta Yaru-olive Yaru-prussiangreen Yaru-purple Yaru-red Yaru-sage Yaru-wartybrown Yaru-yellow`。

### ロック解除画像

`unlock.png` と `preview-unlock.png` の画像が用意されたテーマは、_外観 > ロック解除_ の下に一覧表示されます。`unlock.png` は透明な png が望ましいです。プレビュー画像は `omarchy plymouth preview` を使って作成できます。

### Omarchy が対応していないアプリにテーマを適用する

そのリストにないアプリを使っている場合は、テンプレートを使って Omarchy にテーマの適用方法を自分で教えることができます。生成される設定の名前に `.tpl` 拡張子を付けたファイルを `~/.config/omarchy/themed/` に置き、`{{ background }}`、`{{ foreground }}`、`{{ accent }}`、`{{ red }}`、`{{ color0 }}` から `{{ color15 }}`、そしてパレットの残りをプレースホルダーとして使って設定を書いてください。テーマを切り替えるたびに、そのテーマの色でファイルが再生成されます。

そのフォルダーには、コピー元として使える、すべてにコメントが付いた `alacritty.toml.tpl.sample` があります。使用できるすべての変数に加え、`#` なしの色や 10 進数 RGB としての色を必要とするアプリのための `_strip` および `_rgb` 修飾子も列挙されています。あなたのテンプレートは Omarchy 自身のものより優先されるため、これを使って組み込みアプリへのテーマ適用方法を上書きすることもできます。

### テーマを配布する

他の人が使えるようにテーマを配布したい場合は、GitHub のような公開 git サーバーにテーマを置く必要があります。そうすれば、その URL を使って Omarchy メニューの _インストール > スタイル > テーマ_ からインストールできるようになります。命名規則 `omarchy-[themename]-theme` に従うことをおすすめします。そうすれば、インストール後にテーマ選択メニューでテーマが単に `[themename]` として正しく表示されます。

残った `[themename]` がテーマのディレクトリ名になるため、Omarchy が安全にやり取りできるものでなければなりません。先頭は文字、数字、またはアンダースコアでなければならず、それ以降には文字、数字、`.`、`_`、`+`、`-` を含めることができます。大文字は小文字に変換されますが、それ以外のもの（スペース、引用符、英語以外の文字）は、ディレクトリ名に変換されるのではなく、インストール時に拒否されます。したがって、`omarchy-tokyo-night-theme`、`omarchy-flexoki_light-theme`、`omarchy-c++-theme` はすべて問題なくインストールできます。

リポジトリからインストールされると、同梱されている `.lua`、ターミナル設定、`vscode.json` はすべて削除されることを覚えておいてください。テーマをそれら中心に作らないでください。

[omarchy-site リポジトリ](https://github.com/omacom-io/omarchy-site) にプルリクエストを送ることで、あなたのテーマを[追加テーマのページ](https://omarchy.org/themes/)に追加してもらえます。
