# 独自のテーマを作る

`~/.config/omarchy/themes` に独自のテーマを追加できます。まず既存のテーマのどれかを土台としてコピーし（`/usr/share/omarchy/themes` を見てください）、あとは思う存分調整してください。テーマがそのフォルダー内にある限り、テーマ選択メニューに表示されます。

調整すべき中心となるファイルは `colors.toml` です。ここで定義したカラーセットを使って、ターミナル（Foot/Alacritty/Ghostty/Kitty）、btop、Chromium、Hyprland、Neovim、Helix、VSCode、Obsidian、そして Omarchy シェル全体（トップバー、メニュー、通知、OSD、ロック画面）の設定が生成されます。

付属の Aether アプリケーションを使って、新しいテーマを作ることもできます。素敵な GUI インターフェースで色を試したり、背景を探したりできます。`Super + Alt + Space` でアプリグリッドから起動するだけです。

### インストールされたテーマに含められるもの

`~/.config/omarchy/themes` に自分で書いたテーマには、好きなものを何でも含められます。あなたのマシンであり、あなたのファイルなのですから、Omarchy はそのすべてを適用します。

`omarchy theme install` で他人のリポジトリからインストールしたテーマでは、色に関するものはすべて保持されますが、マシン上でコードを実行することになる一握りのファイルは失われます。任意の `.lua` ファイル、ターミナル設定（`alacritty.toml`、`foot.ini`、`ghostty.conf`、`kitty.conf`）、そして `vscode.json` です。テーマの `hyprland.lua` は、ログイン時にコンポジタが実行する Lua であり、ターミナル設定はターミナルが起動するプログラムを指定し、`vscode.json` はインストールすべき VSCode 拡張機能を指定します。他人のテーマをインストールしても変わるべきなのはデスクトップの見た目だけであり、実行されるものが変わってはなりません。

それ以外のものはすべて、テーマの作者が書いたとおりにそのまま動作します。`btop.theme`、`chromium.theme`、`helix.toml`、`shell.toml`、背景、プレビューはすべて保持されます。削除されたものだけが、あなたのマシン上で `colors.toml` から再生成されます。

Omarchy は、テーマの内部に独自の git リポジトリがあるかどうかで、この2つを区別します。それが `omarchy theme install` がクローンした際に残すものです。つまり、自分で書いたテーマはあなたのもののままであり、インターネットから取得したテーマは色だけに留まります。

### ライトモード

ライトモードのテーマを作る場合は、`colors.toml` の先頭に `mode = "light"` を設定してください。そうすれば、すべてのアプリで自動的にライトモードと組み合わされます。（テーマのルートに `light.mode` という空のファイルを置く旧来の方法も引き続き使えます。）

### ロック解除画像

`unlock.png` と `preview-unlock.png` の画像が用意されたテーマは、_外観 > ロック解除_ の下に一覧表示されます。`unlock.png` は透明な png であることが望ましいです。また、プレビュー画像は `omarchy plymouth preview` を使って作成できます。

### Omarchy が対応していないアプリのテーマ設定

そのリストにないアプリを使っている場合は、テンプレートを使って Omarchy にそのアプリのテーマ設定を自分で教えることができます。生成される設定ファイルの名前に `.tpl` 拡張子を付けたファイルを `~/.config/omarchy/themed/` に置き、`{{ background }}`、`{{ foreground }}`、`{{ accent }}`、`{{ red }}`、`{{ color0 }}` から `{{ color15 }}`、そしてパレットのその他の色をプレースホルダーとして使って設定を書いてください。テーマを切り替えるたびに、そのテーマの色でファイルが再生成されます。

そのフォルダーには、コメントが十分に付けられた `alacritty.toml.tpl.sample` があり、コピー元として使えます。使用できるすべての変数に加え、`#` なしの色や10進数 RGB としての色を求めるアプリ向けの `_strip` 修飾子と `_rgb` 修飾子も列挙されています。あなたのテンプレートは Omarchy 自身のテンプレートより優先されるため、これを使って組み込みアプリのテーマ設定方法を上書きすることもできます。

### テーマを配布する

他の人が使えるようにテーマを配布したい場合は、GitHub のような公開 git サーバーに置く必要があります。そうすれば、その URL を使って Omarchy メニューの _インストール > スタイル > テーマ_ からインストールできるようになります。命名規則として `omarchy-[themename]-theme` に従うことを推奨します。そうすれば、インストール後にテーマ選択メニューでテーマが単に `[themename]` として正しく表示されます。

残りの `[themename]` がテーマのディレクトリ名になるため、Omarchy が安全に取り回せるものでなければなりません。先頭は文字、数字、またはアンダースコアでなければならず、それ以降には文字、数字、`.`、`_`、`+`、`-` を含めることができます。大文字は自動的に小文字化されますが、それ以外のもの（スペース、引用符、英語以外の文字）はディレクトリ名に変換されるのではなく、インストール時に拒否されます。そのため、`omarchy-tokyo-night-theme`、`omarchy-flexoki_light-theme`、`omarchy-c++-theme` はすべて問題なくインストールできます。

リポジトリからインストールされると、同梱された `.lua`、ターミナル設定、`vscode.json` はいずれも削除されることを覚えておいてください。テーマをそれらを中心に構築しないでください。

[omarchy-site リポジトリ](https://github.com/omacom-io/omarchy-site) にプルリクエストを送ることで、あなたのテーマを[追加テーマのページ](https://omarchy.org/themes/)に追加してもらうことができます。
