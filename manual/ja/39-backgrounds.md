# 背景

すべてのテーマには独自の背景セットが付属しており、`~/.config/omarchy/backgrounds/[theme]` に自分の背景を追加できる。たとえば nord テーマに背景画像を追加したいなら、ファイルを `~/.config/omarchy/backgrounds/nord` に置くだけだ。

最も簡単な方法は、Omarchy Menu で _Install > Style > Background_ に移動することだ。そのテーマの背景が保存されているフォルダが開く。`Super + Shift + F` を押して別のファイルマネージャーを起動し、背景を見つけてコピーする。これで、`Super + Ctrl + W` で切り替えられる背景の選択肢に含まれるようになる。

背景は静止画だけでなく動画でもよい。同じフォルダに `mp4`、`m4v`、`mov`、`webm`、`mkv`、`avi` ファイルを入れれば、画像と並んで表示される。動画は OWE wallpaper engine で再生される。すべてのモニターに対して動画を一度だけデコードし、音声はデフォルトのオーディオ出力で再生され、誰にも見えない状態では再生を止める。それでも、動画の壁紙は静止画よりはるかに多くの電力を消費する。

テーマには、静止画の背景用に短いイントロを含めることができる。`backgrounds/road.webp` の場合、対応する動画は `backgrounds/intros/road.mp4` にある。起動時、その背景が選択されたテーマに切り替えたとき、その背景を選んだときに自動で再生され、その後静止画に戻る。イントロ動画は背景ピッカーには表示されず、ループもしない。

_Appearance > Animations_ をオフにすると、背景イントロもオフになる。Omarchy は仮想マシンではデフォルトでこれを行う。`omarchy theme bg intro toggle` コマンドを使えば、イントロを個別に切り替えられる。テーマをリフレッシュしてもイントロは再生されない。

静止画にはループも付けられる。これは、同じ絵が静かに動き続けるバージョンで、`backgrounds/loops/road.mp4` に置く。イントロがある場合はその後に、静止画の代わりに再生され、アニメーションをオフにすると止まる。ループは背景ピッカーには表示されず、ほかの動画背景と同じく、静止画より多くの電力を消費する。

厳選されたかっこいい背景の膨大なコレクションは [dharmx/walls](https://github.com/dharmx/walls) で見つけられる。

ロック画面では、アニメーション GIF の静止フレームを表示するのと同じように、動画背景の静止フレームを表示する。
