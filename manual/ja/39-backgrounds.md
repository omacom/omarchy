# 背景

すべてのテーマには専用の背景セットが同梱されており、`~/.config/omarchy/backgrounds/[theme]` に自分の背景を追加することもできる。たとえば nord テーマに背景画像を追加したいなら、ファイルを `~/.config/omarchy/backgrounds/nord` に置くだけだ。

最も簡単なのは、Omarchy Menu で _インストール > スタイル > 背景_ に移動する方法だ。そのテーマの背景が保存されているフォルダが開く。`Super + Shift + F` を押して別のファイルマネージャーを起動し、背景を見つけてコピーする。これで、`Super + Ctrl + W` で切り替えられる背景の選択肢に含まれるようになる。

背景には静止画だけでなく動画も使える。同じフォルダに `mp4`、`m4v`、`mov`、`webm`、`mkv`、`avi` ファイルを置けば、画像と並んで表示される。動画は OWE 壁紙エンジンが再生する。すべてのモニター向けに動画を一度だけデコードし、音声はデフォルトのオーディオ出力から再生する。そして、何も見えていないときは再生を停止する。動画の壁紙は静止画よりもはるかに多くの電力を消費することに変わりはない。

テーマには、静止画の背景向けに短いイントロを含めることができる。`backgrounds/road.webp` の場合、対応する動画は `backgrounds/intros/road.mp4` にある。起動時、その背景を選択したテーマに切り替えたとき、そしてその背景を選んだときに自動で再生され、その後静止画に戻る。イントロ動画は背景ピッカーには表示されず、ループもしない。

_外観 > アニメーション_ をオフにすると、背景のイントロもオフになる。Omarchy は仮想マシンではデフォルトでこれを行う。`omarchy theme bg intro toggle` コマンドでイントロだけを別々に切り替えることもできる。テーマを更新してもイントロは再生されない。

キュレーションされた大量のかっこいい背景コレクションは [dharmx/walls](https://github.com/dharmx/walls) で見つけることができる。

ロック画面では、動画背景の静止フレームが表示される。アニメーション GIF の静止フレームが表示されるのと同じだ。
