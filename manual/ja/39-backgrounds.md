# 背景

すべてのテーマには独自の背景セットが付属しており、`~/.config/omarchy/backgrounds/[theme]` に自分で追加することもできます。たとえば nord テーマに背景画像を1つ追加したいなら、そのファイルを `~/.config/omarchy/backgrounds/nord` に置くだけです。

これを最も簡単に行う方法は、Omarchy Menu で _Install > Style > Background_ に移動することです。そのテーマの背景が保存されているフォルダが表示されます。`Super + Shift + F` を押して別のファイルマネージャーを起動し、背景を見つけてコピーしてください。これで、`Super + Ctrl + W` を使って選択できる背景の選択肢に含まれるようになります。

背景は静止画だけでなく動画も使えます。`mp4`、`m4v`、`mov`、`webm`、`mkv`、または `avi` ファイルを同じフォルダに置くと、画像と一緒に表示されます。動画は OWE wallpaper engine が再生します。動画はすべてのモニター分を一度だけデコードし、音声はデフォルトのオーディオ出力から再生し、何も表示されていないときは再生を停止します。動画の壁紙は、静止画の壁紙よりもはるかに多くの電力を消費します。

テーマには、静止画の背景用の短いイントロを含めることができます。`backgrounds/road.webp` に対応する動画は `backgrounds/intros/road.mp4` にあります。起動時、その背景が選択されたテーマに切り替えたとき、そしてその背景を選んだときに自動で再生され、その後静止画に戻ります。イントロ動画は背景ピッカーには表示されず、ループすることもありません。

_Appearance > Animations_ をオフにすると、背景のイントロもオフになります。Omarchy は仮想マシンではデフォルトでこれを行います。`omarchy theme bg intro toggle` コマンドを使えば、イントロだけを別々に切り替えられます。テーマをリフレッシュしてもイントロは再生されません。

静止画にはループも設定できます。これは、同じ画像を静かに動き続けるようにしたもので、`backgrounds/loops/road.mp4` に置きます。イントロがあればその後に、静止画の代わりに再生され、アニメーションがオフになると停止します。バッテリー駆動時は代わりに静止画が表示され、電源に接続するとループに戻ります。ループは背景ピッカーには表示されません。

厳選されたクールな背景の膨大なコレクションは [dharmx/walls](https://github.com/dharmx/walls) で見つけることができます。

ロック画面には、動画背景の静止フレームが表示されます。これはアニメーション GIF の静止フレームを表示するのと同じ方法です。
