# 背景

すべてのテーマには独自の背景セットが同梱されており、`~/.config/omarchy/backgrounds/[theme]` に自分で追加することもできます。たとえば nord テーマに背景画像を追加したい場合は、ファイルを `~/.config/omarchy/backgrounds/nord` に入れるだけです。

最も簡単にやるには、Omarchy Menu で _インストール > スタイル > 背景_ を開きます。そのテーマの背景が保存されているフォルダーが表示されます。`Super + Shift + F` を押して別のファイルマネージャーを起動し、背景を探してコピーしてください。これで、`Super + Ctrl + W` で選択できる背景の候補に含まれるようになります。

背景には静止画だけでなく動画も使えます。同じフォルダーに `mp4`、`m4v`、`mov`、`webm`、`mkv`、`avi` ファイルを入れれば、画像と並んで表示されます。動画は OWE wallpaper engine で再生されます。すべてのモニターに対して動画を一度だけデコードし、音声をデフォルトのオーディオ出力から再生し、何も表示されていないときには再生を停止します。それでも動画の壁紙は静止画の壁紙よりもはるかに多くの電力を消費します。

テーマには静止画背景用の短いイントロを含めることができます。`backgrounds/road.webp` の場合、対応する動画は `backgrounds/intros/road.mp4` にあります。起動時と、その背景を選択したテーマに切り替えたときに自動で再生され、その後静止画に戻ります。イントロ動画は背景ピッカーには表示されず、ループすることもありません。

_外観 > アニメーション_ をオフにすると、背景イントロもオフになります。Omarchy は仮想マシンではデフォルトでこれを行います。`omarchy theme bg intro toggle` コマンドを使えば、イントロだけを別に切り替えられます。テーマを更新したり、同じテーマ内で別の背景を選んだりしてもイントロは再生されません。

[dharmx/walls](https://github.com/dharmx/walls) には、厳選されたクールな背景の膨大なコレクションがあります。

ロック画面では、アニメーション GIF の静止フレームが表示されるのと同様に、動画背景の静止フレームが表示されます。
