# 背景

すべてのテーマには独自の背景セットが付属しており、`~/.config/omarchy/backgrounds/[theme]` に自分で追加することもできます。たとえば nord テーマに背景画像を追加したい場合は、そのファイルを `~/.config/omarchy/backgrounds/nord` に置くだけです。

これを最も簡単に行うには、Omarchy Menu で _Install > Style > Background_ を開きます。そのテーマの背景が保存されているフォルダーが表示されます。`Super + Shift + F` を押して別のファイルマネージャーを起動し、背景を見つけてコピーします。これで、`Super + Ctrl + W` で切り替えられる背景の選択肢に含まれるようになります。

独自の背景を持たないテーマには、その色から生成された背景が使われます。背景色の上に、テーマのアクセントカラーで描かれた Omarchy ロゴです。自分で追加すれば、それに置き換わります。

背景は静止画だけでなく動画も使えます。`mp4`、`m4v`、`mov`、`webm`、`mkv`、`avi` ファイルを同じフォルダーに置けば、画像と並んで表示されます。動画は OWE wallpaper engine で再生されます。すべてのモニターに対して動画を一度だけデコードし、音声はデフォルトのオーディオ出力から再生され、何も見えなくなると再生を停止します。それでも動画の壁紙は静止画よりはるかに多くの電力を消費します。

テーマには静止画の背景用に短いイントロを含めることができます。`backgrounds/road.webp` の場合、対応する動画は `backgrounds/intros/road.mp4` にあります。起動時、その背景が選択されたテーマに切り替えたとき、その背景を選択したときに自動で再生され、その後静止画に戻ります。イントロ動画は背景ピッカーには表示されず、ループもされません。

_Appearance > Animations Off_ を選択すると、背景イントロもオフになります。Omarchy では仮想マシン上でデフォルトでこうなります。`omarchy theme bg intro toggle` コマンドでイントロを個別に切り替えることもできます。テーマをリフレッシュしてもイントロは再生されません。

静止画にはループも付けられます。同じ絵が静かに動き続けるバージョンで、`backgrounds/loops/road.mp4` に置きます。静止画の代わりに再生され、イントロがある場合はその後に再生され、アニメーションをオフにすると停止します。バッテリー駆動時は代わりに静止画が表示され、電源に接続するとループに戻ります。ループは背景ピッカーには表示されません。

[dharmx/walls](https://github.com/dharmx/walls) には、選りすぐりのクールな背景が大量に集められています。

ロック画面では、動画の背景の静止フレームが表示されます。これはアニメーション GIF の静止フレームを表示するのと同じ方法です。
