# ネットワーク

OmarchyのネットワークはNetworkManagerが扱い、[トップバー](05-the-top-bar.md)のネットワークアイコン、または`Super + Ctrl + W`から操作します。

そのパネルでWi-Fiネットワークを検索し、信号強度を表示して接続します。Ethernetは何もする必要がありません。ケーブルを挿せば動きます。ターミナルにいたいなら`nmtui`で同じ操作ができますし、`omarchy network`コマンドグループもあります。

## Wi-Fiを共有する

長いパスワードを読み上げる代わりに、Wi-Fiに接続した状態で_設定 > ネットワーク > QRコード_を実行してください。画面にQRコードが表示され、スマートフォンのカメラでスキャンすれば接続できます。あることを知れば、思ったより頻繁に使う機能のひとつです。

パスワードそのものが必要な場合は、`omarchy network password <interface>`で表示できます。

## DNS

Omarchyは、ネットワークがDHCP経由で配布するDNSをそのまま使います。マシン全体でそれを上書きしたい場合は_設定 > ネットワーク > DNS_を開いてください。CloudflareとGoogleがワンクリックで選べます。_カスタム_を選べば、自分のサーバーを入力できます。

ターミナルからは、`omarchy dns`で現在のプロバイダーを表示し、`omarchy dns Cloudflare`で設定できます。

## Wi-Fiのバンドを固定する

ルーターが2.4GHz、5GHz、6GHzを同じネットワーク名にまとめていると、ノートPCが遅い方にしがみつくことがあります。`omarchy network band`で現在のバンドを表示し、`omarchy network band 5`で固定できます。`auto`を使えば、再び自動で選ぶようになります。

これは特定のアクセスポイントではなくバンドを固定するので、AP間のローミングは通常どおり行われます。

## どれくらい速いのか

_実行 > 速度テスト > ネットワーク速度テスト_では、2つのダイヤルで実際の上りと下りの速度を測定できます。ターミナルからは`omarchy network speedtest down`または`up`です。（そのメニューの隣にはディスク速度テストもあるので、もう一方のボトルネックをベンチマークしたい場合に使えます。）

## ファイアウォール

ファイアウォールはデフォルトで有効で、入ってくるトラフィックをすべてブロックします。ただし1つ例外があります。ポート53317です。これにより[LocalSend](22-guis.md)がそのまま使えます。

SSHは_設定 > セキュリティ > SSHD_で有効にするまでオフです。有効にするとデーモンが起動し、ブルートフォース対策のレート制限付きでポート22が開き、鍵が承認されます。Dockerもロックダウンされているので、コンテナが誤って外部に公開されることはありません。詳細は[セキュリティ](48-security.md)をご覧ください。

## Tailscale

[Tailscale](https://tailscale.com/)は、インターネット越しに自分のすべてのコンピューターやサーバーへ簡単かつ安全に到達できるメッシュVPNです。_インストール > サービス > Tailscale_でインストールできます。

これによりバーにTailscaleパネルが表示され、tailnetへの接続と切断、アカウントの切り替え、終了ノードの選択ができます。自分のマシンもMullvadのリージョンもリストに表示されます。また、自分のマシンを閲覧できます。そこにTaildropがあります。マシンを選んで`s`を押せばファイルを送信でき、`c`、`n`、`d`でIP、名前、完全なDNS名をコピーできます。ターミナルでの同等コマンドは`omarchy tailscale send <machine> [file...]`で、送られたファイルは自動的に`~/Downloads`に届きます。到着を知らせる通知は、クリックして開くか閉じるまで残ります。そのため、席を離れている間に届いたファイルも、戻ってきたときに確認できます。

インストールすると、Tailscale管理コンソール用のウェブアプリも追加されます。

## 動かなくなったとき

再起動する前に、問題のある部分だけを再起動してみてください。_更新 > ハードウェア_にはWi-Fi、Bluetooth、オーディオ、トラックパッドがあり、そのいずれかを再読み込みすれば、「5分前は動いていた」という状況のほとんどは直ります。[トラブルシューティング](45-troubleshooting.md)をご覧ください。
