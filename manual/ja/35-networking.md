# ネットワーク

Omarchy のネットワークは NetworkManager が処理します。操作は[トップバー](05-the-top-bar.md)のネットワークアイコンから、または `Super + Ctrl + N` で行います。

そのパネルは Wi-Fi ネットワークをスキャンし、信号強度を表示して、接続します。Ethernet は何もいりません。差し込むだけで動きます。ターミナルで済ませたいなら、`nmtui` で同じ操作ができますし、`omarchy network` コマンドグループもあります。

## Wi-Fi を共有する

長いパスワードを読み上げたりせず、Wi-Fi に接続中に _Setup > Network > QR Code_ を実行してください。画面に QR コードが表示され、どの電話のカメラでもスキャンして参加できます。知っておくと、思った以上によく使う機能のひとつです。

パスワード自体が実際に必要なら、`omarchy network password <interface>` で表示されます。

## DNS

Omarchy は、ネットワークが DHCP 経由で配布する DNS を使います。これはマシン全体について _Setup > Network > DNS_ で上書きでき、Cloudflare と Google はワンクリックで選べます。自分のサーバーを入力するには _Custom_ を選んでください。

ターミナルからは、`omarchy dns` で現在のプロバイダーが表示され、`omarchy dns Cloudflare` で設定できます。

## Wi-Fi のバンドを固定する

ルーターが 2.4GHz、5GHz、6GHz を同じネットワーク名にまとめていると、ノートパソコンが遅い方にしがみつくことがあります。`omarchy network band` で今いるバンドが分かり、`omarchy network band 5` で固定できます。再び自動で選ばせるには `auto` を使います。

これは特定のアクセスポイントではなくバンドを固定するので、AP 間のローミングは通常どおり続きます。

## 速度はどれくらい？

_Trigger > Speed Test > Network Speed Test_ は、2つのダイヤルで実際の上りと下りの速度を測ります。ターミナルでは `omarchy network speedtest down` または `up` です。（そのメニューの隣にはディスク速度テストもあります。もう一方のボトルネックをベンチマークしたいときにどうぞ。）

## ファイアウォール

ファイアウォールはデフォルトでオンになっており、入ってくるトラフィックをすべてブロックします。例外はひとつだけ、ポート 53317 です。おかげで [LocalSend](22-guis.md) がそのまま動きます。

SSH は _Setup > Security > SSHD_ でオンにするまでオフです。これでデーモンが起動し、ブルートフォース対策のレート制限付きでポート 22 が開き、鍵が認可されます。Docker もロックダウンされているので、コンテナがうっかり世界にさらされることもありません。全容は[セキュリティ](48-security.md)を見てください。

## Tailscale

[Tailscale](https://tailscale.com/) はメッシュ VPN で、インターネット越しに自分のすべてのコンピューターとサーバーへ届くことをシンプルかつ安全にします。_Install > Service > Tailscale_ でインストールしてください。

バーに Tailscale パネルが追加され、tailnet への接続と切断、アカウントの切り替え、exit node の選択ができます。自分のマシンも Mullvad のリージョンも一覧に並びます。マシンの閲覧もでき、そこに Taildrop があります。マシンを選んで `s` を押せばファイルを送れ、`c`、`n`、`d` でその IP、名前、完全な DNS 名をコピーできます。ターミナルの同等コマンドは `omarchy tailscale send <machine> [file...]` で、送られてきたファイルは自動で `~/Downloads` に入ります。到着を知らせる通知は、クリックして開くか閉じるまで待つので、マシンから離れている間に届いたファイルも、戻ってきたときにまだそこにあって対応できます。

インストールすると、Tailscale 管理コンソール用のウェブアプリも追加されます。

## 動かなくなったら

再起動する前に、問題の部分だけを単独で再起動してみてください。_Update > Hardware_ には Wi-Fi、Bluetooth、Audio、Trackpad があり、そのどれかをリロードすれば「5分前まで動いていたのに」という状況の大半は片付きます。[トラブルシューティング](45-troubleshooting.md)を見てください。
