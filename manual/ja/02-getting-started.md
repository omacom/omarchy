# はじめに

Omarchy は ISO を使ってインストールします。ドライブ全体を引き継ぐフルディスクインストールか、ドライブの未割り当て領域に Omarchy を入れる空き領域インストールのどちらかを選べます。後者は Windows や別の OS と並べてデュアルブートする方法です（[デュアルブートインストール](50-dual-boot-install.md) を参照してください。なお、Windows で先に BitLocker をオフにする必要があります）。どちらの場合も、インストールではデフォルトで完全な暗号化が行われ、フルディスクオプションでは選択したドライブが消去されるため、既存のドライブを使う前に必ずバックアップを取ってください！

Apple Silicon Mac では、ISO も USB メモリも使わず、代わりに macOS からインストールします。[Apple Silicon 向け Omarchy](44-mac-support.md#omarchy-for-apple-silicon) を参照してください。

まず [Omarchy ISO をダウンロード](https://omarchy.org/) して USB メモリに入れ（Windows では [Rufus](https://rufus.ie/)、Mac では [balenaEtcher](https://etcher.balena.io/)、Linux では [caligula](https://github.com/ifd3f/caligula) を使ってください）、そのメモリから起動してください。

_BIOS で Secure Boot および/または TPM をオフにしなければなりません。Omarchy をインストールするには、これらをオフにする必要があります。これらは Windows と Microsoft 系の Linux ディストリビューション向けに作られた Microsoft のセキュリティ方式です。_

次に設定の質問に答え、次のように確認してください：

 ![install-config](images/install-config.webp)

次にインストール先のドライブを選択し、あとは座ってインストールショーを眺めてください。最速の最新マシンでは 1 分未満で終わりますが、古いコンピューターでも 5 分以上かかることはないはずです。

これで Omarchy を始める準備は完了です！

### 有線または 2.4ghz キーボードを使ってください！

フルディスク暗号化では、起動時に Bluetooth キーボードからパスワードを入力できません。PC で Bluetooth キーボードを使って BIOS に入ることができないのと同じです。2.4ghz ドングルを使うキーボードか、ケーブル接続のキーボードが必要です（そのほうが遅延の面でもずっと快適です！）。私は個人的に [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard) が大好きです！

### 別の所有者のためにインストールする

家族、新しい従業員、買い手など、他の人のためにマシンをセットアップする場合は、その人に代わって個人的な質問に答えるべきではありません。インストーラーの最初の画面（キーボード選択）で `Ctrl + C` を押すと、Omarchy は代わりに別の所有者向けにマシンを準備することを提案します。システムはすぐにインストールされますが、キーボードレイアウト、ユーザー名、パスワードといった個人設定はすべて、マシンが初めて起動するまで延期されます。ドライブは引き続きデフォルトで暗号化され、新しい所有者がその初回起動時に選んだパスワードが、そのまま暗号化パスワードにもなります。（すでに使っているマシンも、再インストールなしで引き渡せます。[コンピューターのリセット](48-security.md) を参照してください。）

### 無人インストール

ISO は、第 2 のドライブに設定を渡されれば、キーボードもウィザードもなしに、完全に単独でインストールすることもできます。それが Omarchy を VM やフリートマシン向けのベースイメージとして扱う方法です。[無人インストール](51-unattended-installs.md) を参照してください。

### 暗号化なしのインストール

Omarchy はデフォルトで暗号化付きでインストールされます。紛失や盗難の可能性があるコンピューターにとって、それが安全で責任ある選択です。ハードウェアにアクセスできる誰かに自分のデータを取得されるようなことは避けたいはずです！

ただし、保護されたコンピューターへのリモートな Omarchy インストールや、機密データのない使い捨てのインストールなど、特別な事情がある場合は、暗号化なしでインストールしたいこともあるでしょう。ディスクのフォーマット確認画面で `Ctrl + C` を押すと、暗号化なしのインストールに切り替えられます。

### 言語

Omarchy は 50 言語に対応しています。omarchy.org と同じセットで、デフォルトは英語です。切り替えるには、Omarchy メニューを開いて _Setup > Region > Language_ へ進むか、ターミナルで `omarchy language <code>` を実行してください（コードの一覧は `omarchy language list` で表示されます）。メニュー、デスクトップ、Omarchy 自体の通知はすぐに言語が切り替わり、その後に開くすべてのアプリケーションもそれに従います。すでに開いているアプリは、再起動すると切り替わります。

言語はそのままに、日付、時刻、数値、お金、単位、紙のサイズの書き方だけを別の地域の方式にするには（たとえば、英語のままヨーロッパ式の日付と 24 時間時計を使うなど）、_Setup > Region > Formats_ で地域を選んでください。各選択肢にはサンプルが表示されます。または `omarchy region formats <code>` を実行してください（`omarchy region formats list` でコードの一覧が表示されます）。_Same as language_ を選ぶと、言語自体のフォーマットに戻ります。言語の切り替えと同様、その後に開くアプリに適用されます。
