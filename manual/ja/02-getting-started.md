# はじめに

Omarchy は ISO を使ってインストールします。ドライブ全体を占有するフルディスクインストールか、ドライブの未割り当て領域に Omarchy を入れる空き領域インストールのどちらかを選べます — 後者が Windows や他の OS と並べてデュアルブートする方法です（[デュアルブートインストール](50-dual-boot-install.md) を参照 — なお、まず Windows で BitLocker をオフにする必要があります）。どちらの場合も、インストールはデフォルトで完全暗号化され、フルディスクオプションでは選択したドライブが消去されるため、既存のドライブを使う前に必ずバックアップを取ってください！

まず [Omarchy ISO をダウンロード](https://omarchy.org/) し、USB メモリに入れて（Windows では [Rufus](https://rufus.ie/)、Mac では [balenaEtcher](https://etcher.balena.io/)、Linux では [caligula](https://github.com/ifd3f/caligula) を使います）、そのメモリから起動してください。

_BIOS で Secure Boot および/または TPM をオフにしなければなりません。Omarchy をインストールするには、これらをオフにする必要があります。これらは Windows と Microsoft 系の Linux ディストリビューション向けの Microsoft のセキュリティスキームです。_

次に設定の質問に答え、このように確認します：

 ![install-config](images/install-config.webp)

次にインストール先のドライブを選択し、あとはくつろいでインストールショーが進むのを見ていてください。最速の最新マシンなら 1 分未満で終わりますが、古いコンピューターでも 5 分以上かかることはないはずです。

 ![install-done](images/install-done.webp)

これで Omarchy の準備が整いました！

### 有線または 2.4ghz キーボードを使ってください！

フルディスク暗号化では、起動時に Bluetooth キーボードからパスワードを入力できません。PC で Bluetooth キーボードを使って BIOS に入れないのと同じです。2.4ghz ドングルを使うか、ケーブルを使うキーボードが必要です（そもそもレイテンシ的にはケーブルのほうがずっと気持ちいいです！）。私自身は [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard) が大好きです！

### 他の所有者のためにインストールする

家族、新入社員、買い手など、他の誰かのためにマシンをセットアップしているなら、その人の個人的な質問に代わりに答えるべきではありません。インストーラーの一番最初の画面（キーボード選択）で `Ctrl + C` を押すと、Omarchy は代わりに、他の所有者向けにマシンを準備することを提案します。システムはすぐにインストールされますが、キーボードレイアウト、ユーザー名、パスワードといった個人的なセットアップはすべて、マシンが初めて起動するまで延期されます。ドライブは引き続きデフォルトで暗号化され、新しい所有者がその初回起動時に選んだパスワードが暗号化パスワードにもなります。（すでに使っているマシンも、再インストールなしに引き渡せます — [コンピューターのリセット](48-security.md) を参照してください。）

### 無人インストール

ISO は、2 台目のドライブで設定を渡されれば、完全に単独で — キーボードなし、ウィザードなしで — インストールすることもできます。それが、Omarchy を VM やフリートマシン向けのベースイメージとして扱う方法です。[無人インストール](51-unattended-installs.md) を参照してください。

### 暗号化なしのインストール

Omarchy はデフォルトで暗号化ありでインストールされます。紛失や盗難の可能性があるコンピューターにとって、それが安全で責任ある選択です。ハードウェアにアクセスできる誰かに、あなたのデータを取得されたくはないでしょう！

しかし、保護されたコンピューターへのリモートな Omarchy インストールや、機密データのない使い捨てインストールのような特別な状況では、暗号化なしでインストールしたい場合があります。ディスクフォーマットの確認画面で `Ctrl + C` を押すと、暗号化なしのインストールに切り替えられます。

### 言語

Omarchy は 50 言語に対応しています — omarchy.org と同じセットです — デフォルトは英語です。切り替えるには、Omarchy メニューを開いて _セットアップ > 言語_ に進むか、ターミナルで `omarchy language <code>` を実行します（`omarchy language list` でコードの一覧が表示されます）。メニュー、デスクトップ、そして Omarchy 自身の通知はすぐに言語が切り替わり、その後に開くすべてのアプリケーションも同様に追随します。すでに開いているアプリは、再起動すると切り替わります。

### 困ったときの助け

困ったときは、通常、[コミュニティ Discord](https://omarchy.org/discord) の _#omarchy-help_ チャンネルで、助けてくれる人が見つかります。
