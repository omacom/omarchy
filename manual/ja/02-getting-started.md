# はじめに

Omarchy は ISO を使ってインストールします。ドライブ全体を占有するフルディスク・インストールと、ドライブの未割り当て領域に Omarchy を入れる空き領域インストールから選べます — 後者が Windows や他の OS と並べてデュアルブートする方法です（[デュアルブート・インストール](50-dual-boot-install.md) を参照 — なお、先に Windows で BitLocker をオフにする必要があります）。どちらの場合も、インストールはデフォルトで完全暗号化されます。フルディスク・オプションは選択したドライブを消去するので、既存のドライブを使う前に必ずバックアップを取ってください!

まず [Omarchy ISO をダウンロード](https://omarchy.org/) し、USB メモリに入れて（Mac/Windows では [balenaEtcher](https://etcher.balena.io/)、Linux では [caligula](https://github.com/ifd3f/caligula) を使います）、そのメモリから起動してください。

_BIOS で Secure Boot および/または TPM をオフにしなければなりません。Omarchy をインストールするには、これらをオフにする必要があります。これらは Windows および Microsoft 傘下の Linux ディストリビューション向けの Microsoft のセキュリティ方式です。_

次に設定に関する質問に答え、次のように確認します:

 ![install-config](images/install-config.webp)

次にインストール先のドライブを選択し、あとはくつろいでインストールのショーを眺めてください。最速の現代的なマシンでは 1 分未満で完了しますが、古いコンピューターでも 5 分以上かかることはないはずです。

 ![install-done](images/install-done.webp)

これで Omarchy を始める準備ができました!

### 有線または 2.4ghz キーボードを使おう!

フルディスク暗号化では、起動時に Bluetooth キーボードからパスワードを入力できません。PC で BIOS に入るのに Bluetooth キーボードを使えないのと同じです。2.4ghz ドングルを使うか、ケーブルで接続するキーボードが必要です（そもそも遅延の点でそちらの方がずっと快適です!）。個人的には [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard) が大好きです!

### 別のオーナー向けのインストール

家族、新しい従業員、買い手など、他の誰かのためにマシンをセットアップしている場合、本人の代わりに個人的な質問に答えるべきではありません。インストーラーの最初の画面（キーボード選択）で `Ctrl + C` を押すと、Omarchy が代わりに別のオーナー向けにマシンを準備するよう提案します。システムはすぐにインストールされますが、キーボードレイアウト、ユーザー名、パスワードといった個人的なセットアップはすべて、マシンが初めて起動するまで延期されます。ドライブは引き続きデフォルトで暗号化され、その初回起動時に新しいオーナーが選んだパスワードが暗号化パスワードにもなります。（すでに使っているマシンも、再インストールなしで引き渡せます — [コンピューターのリセット](48-security.md) を参照してください。）

### 無人インストール

ISO は、2 台目のドライブで設定を渡された場合、キーボードもウィザードもなしに、完全に単独でインストールすることもできます。それが Omarchy を VM やフリートマシンのベースイメージとして扱う方法です。[無人インストール](51-unattended-installs.md) を参照してください。

### 暗号化なしのインストール

Omarchy はデフォルトで暗号化付きでインストールされます。紛失や盗難の可能性があるすべてのコンピューターにとって、それが安全で責任ある選択です。ハードウェアにアクセスできる誰かに自分のデータを入手されたくはないでしょう!

しかし、保護されたコンピューターへのリモートな Omarchy インストールや、機密データのない使い捨てインストールといった特殊な状況では、暗号化なしでインストールしたい場合もあるでしょう。ディスクのフォーマット確認画面で `Ctrl + C` を押すと、暗号化なしのインストールに切り替えられます。

### 言語

Omarchy は 50 言語に対応しています — omarchy.org と同じセットで、デフォルトは英語です。切り替えるには、Omarchy メニューを開いて _Setup > Language_ に進むか、ターミナルで `omarchy language <code>` を実行してください（`omarchy language list` でコード一覧が表示されます）。メニュー、デスクトップ、Omarchy 自体の通知はすぐに言語が変わり、その後に開くすべてのアプリケーションもそれに従います。すでに開いていたアプリは、再起動すると切り替わります。

### 困ったときの助け

困ったときは、通常 [コミュニティ Discord](https://omarchy.org/discord) の _#omarchy-help_ チャンネルで、喜んで助けてくれる人が見つかります。
