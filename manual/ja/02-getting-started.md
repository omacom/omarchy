# はじめに

Omarchy は ISO を使ってインストールします。ドライブ全体を占有する全ディスクインストールか、ドライブの未割り当て領域に Omarchy を配置する空き領域インストールのどちらかを選べます。後者は Windows や別の OS と並べてデュアルブートする方法です（[デュアルブートインストール](50-dual-boot-install.md) を参照 — なお、事前に Windows で BitLocker を無効にする必要があります）。どちらの方法でも、インストールはデフォルトで完全暗号化され、全ディスクオプションでは選択したドライブが消去されるので、既存のドライブを使う前に必ずバックアップを取ってください！

まず [Omarchy ISO をダウンロード](https://omarchy.org/) して、USB メモリに入れ（Windows では [Rufus](https://rufus.ie/)、Mac では [balenaEtcher](https://etcher.balena.io/)、Linux では [caligula](https://github.com/ifd3f/caligula) を使用）、そのメモリから起動してください。

_BIOS で Secure Boot および／または TPM を無効にしなければなりません。Omarchy をインストールするには、これらを無効にする必要があります。これらは Windows および Microsoft と提携した Linux ディストリビューション向けに設計された Microsoft のセキュリティ方式です。_

次に設定の質問に答え、次のように確認します：

 ![install-config](images/install-config.webp)

次にインストール先のドライブを選択し、あとはインストールの様子を眺めていてください。最速の最新マシンでは 1 分未満で完了することもありますが、古いコンピューターでも 5 分以上かかることはないはずです。

 ![install-done](images/install-done.webp)

これで Omarchy を始める準備が整いました！

### 有線または 2.4ghz キーボードを使ってください！

全ディスク暗号化では、起動時に Bluetooth キーボードからパスワードを入力できません。PC で Bluetooth キーボードを使って BIOS に入ることができないのと同じです。2.4ghz ドングルを使うキーボードか、ケーブル接続のキーボードが必要です（その方がレイテンシの面でもずっと快適です！）。個人的には [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard) が大好きです！

### 別の所有者のためにインストールする

家族、新しい従業員、購入者など、他の人のためにマシンをセットアップする場合は、その人の代わりに個人的な質問に答えるべきではありません。インストーラーの最初の画面（キーボード選択）で `Ctrl + C` を押すと、Omarchy は代わりにそのマシンを別の所有者向けに準備することを提案します。システムはすぐにインストールされますが、キーボードレイアウト、ユーザー名、パスワードといった個人的な設定はすべて、マシンが初めて起動するまで延期されます。ドライブは引き続きデフォルトで暗号化され、新しい所有者がその初回起動時に選んだパスワードが暗号化パスワードにもなります。（すでに使っているマシンも、再インストールなしで引き渡すことができます — [コンピューターのリセット](48-security.md) を参照してください。）

### 無人インストール

ISO は、第 2 のドライブに設定を渡せば、キーボードもウィザードもなしに、完全に単独でインストールすることもできます。Omarchy を VM やフリートマシン向けのベースイメージとして扱うにはこの方法が適しています。[無人インストール](51-unattended-installs.md) を参照してください。

### 暗号化なしのインストール

Omarchy はデフォルトで暗号化されてインストールされます。紛失や盗難の可能性があるコンピューターにとって、安全で責任ある選択です。ハードウェアにアクセスできる人に、自分のデータを取得されるのは困ります！

しかし、保護されたコンピューターへのリモート Omarchy インストールや、機密データのない使い捨てインストールのような特別な状況では、暗号化なしでインストールしたい場合があるかもしれません。ディスクのフォーマット確認画面で `Ctrl + C` を押すと、暗号化なしのインストールに切り替えることができます。

### 言語

Omarchy は 50 の言語に対応しています — omarchy.org と同じセットです — デフォルトは英語です。切り替えるには、Omarchy メニューを開いて _設定 > 地域 > 言語_ に進むか、ターミナルで `omarchy language <code>` を実行します（`omarchy language list` でコードの一覧が表示されます）。メニュー、デスクトップ、Omarchy 自身の通知はすぐに言語が変わり、その後に開くすべてのアプリケーションもそれに従います。すでに開いていたアプリは、再起動すると切り替わります。

言語はそのままで、日付、時刻、数値、お金、単位、用紙サイズを別の地域の形式で表示したい場合（たとえば、英語のままヨーロッパ式の日付と 24 時間時計を使う場合）は、_設定 > 地域 > 書式_ で地域を選択してください。各選択肢にはサンプルが表示されます。または `omarchy region formats <code>` を実行してください（`omarchy region formats list` でコードの一覧が表示されます）。_言語と同じ_ を選ぶと、言語自身の書式に戻ります。言語の切り替えと同様に、その後に開くアプリに適用されます。
