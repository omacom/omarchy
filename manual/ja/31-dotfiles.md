# ドットファイル

Omarchy は主に、`~/.config` にあるいわゆるドットファイルを通じて設定します。それらは、あなたが変更するための、あなたのファイルとみなされます。`/usr/share/omarchy` にあるファイルは Omarchy 自体に属するもので、そこをいじるべきではありません。`/usr/share/omarchy` 内の何かを変更する必要がある場合は、代わりに `~/.config` でその値を上書きすべきです。

主要な設定は、Omarchy メニュー（`Super + Space`）から直接編集できます。たとえば _設定 > キーバインド_、_設定 > 入力_、_設定 > Config > [file]_ などです。この方法で編集すると、設定の編集後に再起動が必要なプロセスは、エディターを終了した後に自動的に再起動します（デフォルトは Neovim です — `:wq`、覚えていますね！ — ただし _設定 > デフォルト > エディター_ 経由で変更できます）。

`~/.config` にある主要なファイルと、それぞれが何を制御するかの一覧は次のとおりです：

| ファイル | 用途 |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | メインの Hyprland 設定です。Omarchy のデフォルトと、下記のあなたの上書きファイルを読み込みます。[Hyprland 設定について詳しく見る](https://wiki.hypr.land/Configuring/)。 |
| `~/.config/hypr/bindings.lua` | あなた自身のキーバインドと、デフォルトの上書きです。 |
| `~/.config/hypr/monitors.lua` | 回転、追加モード、モニターをオフのままにするなど、モニターパネルで扱えないモニター設定です。 |
| `~/.config/hypr/input.lua` | キーボードレイアウト、マウス、トラックパッドの設定を制御します。 |
| `~/.config/hypr/looknfeel.lua` | ギャップ、ボーダー、アニメーション、その他の見た目を制御します。 |
| `~/.config/hypr/autostart.lua` | セッションと一緒に起動する追加のプロセスを制御します。 |
| `~/.config/omarchy/shell.json` | Omarchy シェルを制御します：バーの位置、レイアウト、ウィジェットに加え、スクリーンセーバー、ロック、アイドルのタイミングです。 |
| `~/.config/foot/foot.ini` | ターミナルを制御します（デフォルトは foot です）。 |
| `~/.XCompose` | クイックアクセス用の絵文字と、名前/メールアドレスの自動補完を定義します。変更後は必ず `omarchy-restart-xcompose` を実行してください。 |

自分のセットアップを調整するためにたくさんの変更を加えるようになったら、これらのドットファイルをすべてバックアップしておくのがよい考えです。[Stow はそのための優れた方法です](https://www.youtube.com/watch?v=NoFiYOqnC4o)。

### セッションと一緒に自分のアプリを起動する

ログインするたびに何かを実行したい場合 — 同期デーモン、チャットアプリ、自分のスクリプトなど — それを `~/.config/hypr/autostart.lua` に入れます：

```lua
o.launch_on_start("my-service")
```

これにより、そのコマンドはセッションの一部として起動するため、再びログアウトすると適切にクリーンアップされます。

### システムイベントでスクリプトを実行する

Omarchy はいくつかのタイミングでフックを発火し、そこに自分のスクリプトをぶら下げることができます。それらは `~/.config/omarchy/hooks/<event>.d/` にあり、イベントごとに1つのディレクトリがあり、その中にある実行可能なファイルはすべて、そのイベントが発生したときに実行されます：

| イベント | 実行されるタイミング |
| ----- | ------------ |
| `post-boot` | デスクトップが起動した直後 |
| `post-update` | `omarchy update` の終盤、パッケージ、マイグレーション、サービスの再起動の後、mise ツールが更新される前 |
| `pre-refresh-pacman` | `omarchy refresh pacman` がパッケージ設定を再同期した後、パッケージを更新する前。チャンネルの切り替えは、その同じ更新ステップ中にこれを実行します |
| `theme-set` | テーマ変更の後（テーマ名は `$1`） |
| `font-set` | フォント変更の後（フォント名は `$1`） |
| `battery-low` | バッテリーが少なくなったとき（パーセンテージは `$1`） |

`pre-refresh-pacman` フックは、カスタムリポジトリや `IgnorePkg` 行を置くべき場所です。パッケージのトランザクションの前に実行されるからです。更新に関連する両方のフックは、Omarchy がキャッシュした sudo 認証をクリアした後に、あなたのユーザーとして実行されます。そのため、`sudo` を使うフックには独自の認証が必要で、パスワードを求められる場合があります。

これらのディレクトリにはそれぞれ、フックの形を示す `.sample` ファイルがすでに入っています — 名前から `.sample` を取り除けば、それが使えるようになります。別の場所で書いたスクリプトをインストールするには、`omarchy hook install post-boot ~/my-hook` を使用します。これにより、それがコピーされ、実行可能になります。

### 独自のメニュー項目を追加する

Omarchy メニュー（`Super + Space`）は、`~/.config/omarchy/extensions/omarchy-menu.jsonc` を編集することで、あなた自身の行を追加して拡張できます。項目はドットで区切られた id でキー指定され、その id がツリー内での配置を決めます。そのため、`personal` はルートメニューに表示され、`personal.notes` はその内側に表示されます：

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

既存の id を再利用すると、新しい行を追加するのではなく、その行を上書きします。このファイルには、利用可能なすべてのフィールドがコメントとして記載された状態で付属しています。

### 独自のシェルエクスポート、関数、エイリアスを追加する

Omarchy には、使いやすいエイリアスや便利な関数がたくさん付属していますが、自分自身のものを追加したくなることは非常によくあります。エイリアス、関数、エクスポートはすべて `~/.bashrc` に追加すべきです。このファイルはアップデートで上書きされません。Omarchy のデフォルトのいずれかを変更したい場合も、ここに安全に追加できます。

### Omarchy の内部ファイルを変更する

いいですか、これはあなたのコンピューターです。好きなようにできますが、`/usr/share/omarchy` 内のファイルを直接変更することはお勧めしません。それらは Omarchy の pacman パッケージに属しているため、あなたの変更は次回のアップデートで単に上書きされてしまいます。代わりに、`~/.config/*` フォルダーで気に入らないデフォルト値を上書きするほうがよいでしょう。

その方法で、ほぼすべてのものを変更できます。たとえばデフォルトのキーバインドなどです。`~/.config/hypr/bindings.lua` を編集して、たとえば [Obsidian](https://obsidian.md/) を [Joplin](https://joplinapp.org/) に置き換えます（インストールは `omarchy-pkg-add joplin-bin` です）：

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` は、既存のバインドを削除してから、その置き換えを追加します。起動ヘルパーやバインドオプションを含め、`o.bind` と同じ引数を取ります。バインドを追加するには `o.bind` を使用し、置き換えずに削除するには `hl.unbind` を使用します。

どうしても Omarchy の内部ファイルをハックしたい場合は、_アップデート > チャンネル > Dev_ 経由で dev チャンネルに切り替えてください。それにより Omarchy は、`~/omarchy` にあるソースコードの git チェックアウトにリンクされ、思う存分自由に変更できます。あなたに指図する人間はここにはいません！

### 変更をリセットする

設定をめちゃくちゃにしてしまった場合でも、Omarchy メニューの _アップデート > Config_ 経由で、いつでもデフォルトに戻せます。または、`omarchy reinstall configs` を実行してすべてをリセットできます。
