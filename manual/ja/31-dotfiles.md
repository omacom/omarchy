# ドットファイル

Omarchy は主に `~/.config` にある、いわゆるドットファイルで設定します。これらは、あなたが変更するための、あなたのファイルだと考えてください。`/usr/share/omarchy` にあるファイルは Omarchy 自体に属するもので、そこはいじるべきではありません。`/usr/share/omarchy` の何かを変更する必要がある場合は、代わりに `~/.config` でその値を上書きすべきです。

主要な設定は Omarchy メニュー（`Super + Space`）から直接編集できます。たとえば _Setup > Keyboard > Keybindings_、_Setup > Input_、_Setup > Config > [file]_ などです。この方法で編集すると、設定の編集後に再起動が必要なプロセスは、エディタを終了したときに自動的に再起動されます（デフォルトは Neovim です — `:wq` ですよ、忘れずに！ — ただし _Setup > Defaults > Editor_ から変更できます）。

`~/.config` にある主要なファイルと、それらが何を制御するかのリストです：

| File                  | Purpose              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | Hyprland のメイン設定です。Omarchy のデフォルトに加え、以下のあなたの上書きファイルを読み込みます。[Hyprland の設定について詳しく学ぶ](https://wiki.hypr.land/Configuring/)。  |
| `~/.config/hypr/bindings.lua` | 独自のキーバインドと、デフォルトの上書きです。 |
| `~/.config/hypr/monitors.lua` | 回転、追加モード、モニターをオフのままにするなど、モニターパネルでカバーできないモニター設定です。 |
| `~/.config/hypr/input.lua` | キーボードレイアウト、マウス、トラックパッドの設定を制御します。 |
| `~/.config/hypr/looknfeel.lua` | ギャップ、境界線、アニメーション、その他の見た目を制御します。 |
| `~/.config/hypr/autostart.lua` | セッションと一緒に起動する追加のプロセスを制御します。 |
| `~/.config/omarchy/shell.json` | バーの位置、レイアウト、ウィジェットに加え、スクリーンセーバー、ロック、アイドル時間など、Omarchy シェルを制御します。 |
| `~/.config/foot/foot.ini` | ターミナルを制御します（デフォルトは foot です）。 |
| `~/.XCompose` | クイックアクセス用の絵文字と名前/メールアドレスの自動補完を定義します。変更後は必ず `omarchy-restart-xcompose` を実行してください。 |

自分のセットアップを微調整するために多くの変更を加えることになったら、これらのドットファイルをすべてバックアップしておくのがよいでしょう。[Stow はそのための優れた方法です](https://www.youtube.com/watch?v=NoFiYOqnC4o)。

### セッションと一緒に独自のアプリを起動する

ログインするたびに何かを実行したい場合 — 同期デーモン、チャットアプリ、独自のスクリプトなど — は、`~/.config/hypr/autostart.lua` に記述してください：

```lua
o.launch_on_start("my-service")
```

これにより、そのコマンドがセッションの一部として起動されるので、ログアウトしたときにちゃんとクリーンアップされます。

### システムイベントでスクリプトを実行する

Omarchy はいくつかのタイミングでフックを発火させ、そこに独自のスクリプトをぶら下げることができます。それらは `~/.config/omarchy/hooks/<event>.d/` にあり、イベントごとに1つのディレクトリがあって、イベントが発生すると、その中にある実行可能なファイルがすべて実行されます：

| Event | When it runs |
| ----- | ------------ |
| `post-boot` | デスクトップが起動した直後 |
| `post-update` | `omarchy update` の終わり近く、パッケージ、マイグレーション、サービスの再起動の後、mise ツールが更新される前 |
| `pre-refresh-pacman` | `omarchy refresh pacman` がパッケージ設定を再同期した後、パッケージを更新する前。チャンネル切り替えでは、同じリフレッシュ手順の中で実行されます |
| `theme-set` | テーマ変更の後（テーマ名は `$1`） |
| `font-set` | フォント変更の後（フォント名は `$1`） |
| `battery-low` | バッテリー残量が少なくなったとき（パーセンテージは `$1`） |

`pre-refresh-pacman` フックは、パッケージのトランザクションの前に実行されるため、カスタムリポジトリや `IgnorePkg` の行を置くべき場所です。更新に関連する2つのフックはいずれも、Omarchy がキャッシュした sudo 認証をクリアした後に、あなたのユーザーとして実行されます。そのため、`sudo` を使うフックには独自の認証が必要で、パスワードを求められることがあります。

それらのディレクトリにはそれぞれ、フックの形を示す `.sample` ファイルがすでに置かれています — 名前から `.sample` を外せば、それが使えるようになります。他の場所で書いたスクリプトをインストールするには、`omarchy hook install post-boot ~/my-hook` を使います。これにより、スクリプトがコピーされ、実行可能になります。

### 独自のメニュー項目を追加する

Omarchy メニュー（`Super + Space`）は、`~/.config/omarchy/extensions/omarchy-menu.jsonc` を編集することで、独自の行で拡張できます。エントリはドット付きの id をキーとし、その id がツリー内の配置を決めます。つまり、`personal` はルートメニューに表示され、`personal.notes` はその中に表示されます：

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

既存の id を再利用すると、新しい行を追加する代わりに、その行を上書きします。このファイルには、利用可能なすべてのフィールドがコメントとして文書化された状態で同梱されています。

### 独自のシェルのエクスポート、関数、エイリアスを追加する

Omarchy には、使いやすいエイリアスや便利な関数がたくさん同梱されていますが、独自のものを追加したくなるのはごく一般的です。エイリアス、関数、エクスポートはすべて `~/.bashrc` に追加してください。このファイルは更新で上書きされません。Omarchy のデフォルトのいずれかを変更したい場合も、ここに安全に追加できます。

### デスクトップ用の環境変数を設定する

デスクトップセッション用のエクスポートは `~/.config/uwsm/env.d/` に置きます。これらのファイルはデスクトップが起動する前に実行されるため、シェルのエラーでログイン画面に戻されることがあります。編集する間は、動作するターミナルを開いたままにしてください。上書きを無効にするには、`env.d` の外に移動します。変更によりログインできなくなった場合は、[ログインの復旧](45-troubleshooting.md#my-password-is-accepted-but-i-return-to-the-login-screen) を参照してください。

### Omarchy の内部ファイルを変更する

いいですか、これはあなたのコンピュータです。好きなようにできますが、`/usr/share/omarchy` にあるファイルを直接変更するのはおすすめしません。それらは Omarchy の pacman パッケージに属しているため、変更は次の更新で単に上書きされてしまいます。代わりに、気に入らないデフォルト値は `~/.config/*` フォルダで上書きする方がずっとよいです。

その方法で、デフォルトのキーバインドなど、ほぼすべてのものを変更できます。たとえば、[Obsidian](https://obsidian.md/) を [Joplin](https://joplinapp.org/) に置き換えるには、`~/.config/hypr/bindings.lua` を編集するだけです（インストールは `omarchy-pkg-add joplin-bin` で）：

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` は、既存のバインドを削除してから置き換えを追加します。起動ヘルパーやバインドオプションを含め、`o.bind` と同じ引数を取ります。バインドを追加するには `o.bind` を、置き換えずに削除するには `hl.unbind` を使います。

どうしても Omarchy の内部ファイルをハックしたいのであれば、_Update > Channel > Dev_ から dev チャンネルに切り替えてください。そうすると Omarchy が `~/omarchy` にあるソースコードの git チェックアウトにリンクされ、心ゆくまで自由に変更できます。ここであなたに指図する人なんていませんよ！

### 変更をリセットする

設定をぐちゃぐちゃにしてしまった場合は、Omarchy メニューの _Update > Config_ からいつでもデフォルトに戻せます。または、`omarchy reinstall configs` を実行してすべてをリセットできます。
