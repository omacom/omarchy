# スクリーンショットと録画

画面から取り込めるものはすべて、Print Screen キーにぶら下がっている。このキー単体で写真を撮り、修飾キーを組み合わせると録画、色、領域内のテキストを取り込める。キーボードに Print Screen キーがまったくない場合は、`Super + Ctrl + Alt + C` で同じスクリーンショットを撮れて、`Super + Ctrl + C` で一式をメニューとして開ける。

| ホットキー | 機能 |
| ------ | -------- |
| `Print Screen` | スクリーンショット |
| `Super + Ctrl + Alt + C` | スクリーンショット |
| `Alt + Print Screen` | 画面録画（または実行中の録画を停止） |
| `Super + Print Screen` | カラーピッカー |
| `Super + Ctrl + Print Screen` | 領域からテキストを抽出 |
| `Super + Ctrl + C` | キャプチャメニュー |
| `Super + Ctrl + .` | 画像や動画をトランスコード |

## スクリーンショット

`Print Screen`（または `Super + Ctrl + Alt + C`）を押すと、Omasnap はオーバーレイが表示される前にフォーカス中のモニターをキャプチャするので、照準を合わせている間に下の画面がずれることはない。フリーフォームで領域をドラッグしたり、ウィンドウをクリックしてそのウィンドウをキャプチャしたり、空白部分をクリックしてモニター全体をキャプチャしたりできる。描画前に `S` を押すと、スクロール領域をキャプチャできる。気が変わったか？ 同じキーをもう一度押せば Omasnap を閉じられる。

領域を選択すると、Omasnap はキャプチャを保存し、クリップボードにコピーし、保存された画面録画と同じように、そのサムネイル付きの通知を表示する。Open を選べば保存した画像を画像ビューアーで開き、Edit を選べば注釈を付けられる。

注釈エディターでは、矢印、線、図形、ハイライト、番号付きマーカー、テキスト、セキュアな墨消しを描画したり、画像の一部を切り取ったり切り抜いたり、そのテキストを OCR したり、背景を追加したりできる。エディターでは、`Enter` を押すと完成した PNG をコピーして保存し、`Ctrl + C` を押すと保存せずにコピーし、`Ctrl + S` を押すとコピーせずに保存する。

保存されたスクリーンショットは、デフォルトでは `~/Pictures/Screenshots` に、`screenshot-2026-08-13_14-22-05-firefox.png` のような名前で保存される。別のディレクトリを使うには `OMASNAP_SCREENSHOT_DIR` を設定する。セッション環境変数をどこに書くかについては [FAQ](46-faq.md) を参照すること。Omasnap は最初の画像を保存するときにそのディレクトリを作成する。自動保存を無効にするには、`~/.config/omasnap/omasnap.conf` で `[output] autosave = false` を設定する。その場合、キャプチャはコピーされるだけになり、10 秒間プレビューが表示される。ピンボタンまたは `Ctrl + P` でそのプレビューを画面に固定しておける。

ターミナルからは、`omarchy screenshot` で同じオーバーレイを開ける。開始モードも選べる。`omarchy capture screenshot region`、`windows`、`fullscreen`、`scroll` だ。第 2 引数に `copy` または `save` を指定すると、画像はその送信先に直接送られる。出力前に編集するには、フルスクリーンエディターには `omarchy screenshot --editor=overlay` を、別ウィンドウには `omarchy screenshot --editor=window` を使う。

### キーボードでピッカーを操作する

選択画面が表示されている間は、マウスをまったく使う必要はない。

| キー | 機能 |
| --- | -------- |
| `S` | スクロール領域モードを切り替え |
| `Super + Arrow keys` | Window モードでウィンドウ間を移動 |
| `Return` | ハイライトされたウィンドウをキャプチャ |
| `Ctrl + A` | フォーカス中のモニター全体をキャプチャ |
| `R` | このセッションで最後に描いた領域を復元 |
| `Esc` | Omasnap を閉じる |

これらのバインディングは Omasnap が開いている間だけ存在するので、自分の設定の何かと衝突することはない。

## 画面録画

`Alt + Print Screen` を押すと _Trigger > Capture > Screenrecord_ が開き、サウンドトラックに何を入れるか聞かれる。音声なし、デスクトップ音声、デスクトップとマイク、またはデスクトップとマイクとウェブカメラだ。最後のものは、実際にカメラが接続されている場合にのみ表示される。1 つ選ぶと、Omarchy の録画ピッカーで領域をドラッグしたり、ウィンドウやモニターをクリックしたりできる。

録画は gpu-screen-recorder で動作し、GPU で 60fps でエンコードし、必要なら CPU にフォールバックする。結果は `~/Videos` に MP4 として保存され、`screenrecording-2026-08-13_14-22-05.mp4` のような名前が付けられる。それを変更するには `OMARCHY_SCREENRECORD_DIR` を設定する。ただし、スクリーンショットのディレクトリとは違い、こちらはあらかじめ存在していなければならない。そうでなければ録画は開始を拒否するので注意すること。

録画中は、バーに小さなインジケーターが表示される。それをクリックすると停止する。`Alt + Print Screen` をもう一度押して停止することもできるし、_Trigger > Capture > Screenrecord_ の下にある _Stop Screenrecording_ 項目でも停止できる。こちらは実際に何かを録画している間だけ表示される。

停止時には、ファイルを渡す前に少し整理が行われる。最初のフレームがトリミングされ、音声がある場合は -14 LUFS にノーマライズされ、一番最初にある PipeWire のキャプチャ時のポップ音がミュートされる。その後、録画から取ったサムネイル付きの通知が表示される。それをクリックすると、mpv でファイルが再生される。

### ウェブカメラのオーバーレイ

ウェブカメラ付きで録画すると、カメラは録画対象の右下隅に、ピン留めされ切り取られたポートレートウィンドウとして表示される。必要なものの上に重なって邪魔な場合は、その場でサイズを変更できる。

| ホットキー | 機能 |
| ------ | -------- |
| `Super + Alt + [` | ウェブカメラのオーバーレイを小さくする |
| `Super + Alt + ]` | ウェブカメラのオーバーレイを大きくする |

サイズは小、中、大の 3 種類で、ホットキーでその間を段階的に切り替える。デフォルトは中だ。これらは録画に対して比例するので、1080p のモニターを録画しても 6K のモニターを録画しても、カメラがフレームに占める割合は同じになる。また、ディスプレイ全体ではなく領域を録画した場合は、オーバーレイはモニターではなくその領域の隅に固定されるので、ショットの中に収まり続ける。

`omarchy-capture-webcam-resize small` で直接呼び出すこともできるし、`reset` で中に戻すこともできる。

## テキスト、QR コード、色

`Super + Ctrl + Print Screen` は領域を選択し、そのテキストを OCR してクリップボードに入れる。それについては [テキスト抽出とディクテーション](11-text-extraction-dictation.md) で properly 取り上げている。

_Trigger > Capture > QR Code_ は QR コードに対して同じ技を使う。コードが入った領域を選択すると、デコードされた値がクリップボードに入る。探すのは QR コードだけだ。そうしないと、密度の高い画面コンテンツはバーコードとして誤検出する癖がある。知っておくべきこととして、デコードされた値はクリップボードに入るだけで、それ以外のどこにも行かない。印刷されず、通知にも入らず、機密としてマークされるので [クリップボード履歴](08-unified-clipboard-history.md) にも残らない。QR コードは日常的に秘密を運んでいる。たとえば 2FA セットアップコードの背後にある `otpauth://` URI がそうだ。そんなものをログに入れたくはないだろう。貼り付けは問題なく機能する。

`Super + Print Screen`（または _Trigger > Capture > Color_）を押すと、カーソルがスポイトに変わる。画面上の何かをクリックすると、その色がクリップボードに入る。ホットキーをもう一度押すと、何も選択せずに抜けられる。

## 共有する前のトランスコード

4K の画面録画や、スマートフォンから取り出したそのままの HEIC は、そのまま送るには大きすぎることがよくある。`Super + Ctrl + .`（または _Trigger > Transcode_）がそれを解決する。`~/Pictures` と `~/Videos` を対象としたあいまい検索のファイルピッカーが表示され、次にフォーマットとサイズを聞かれる。

画像は jpg または png になり、高、中、低で幅の上限がそれぞれ 3160、2160、1080 ピクセルになる。動画は mp4 またはアニメーション gif になり、4k、1080p、720p から選べる。変換されたファイルは元のファイルの隣に、解像度を名前に含めて書き込まれる。`demo-1080p.mp4` のようにだ。そのパスはファイル URI としてクリップボードにコピーされるので、ファイルのドロップを受け付けるアプリに直接貼り付けられる。

やりたいことがすでに決まっている場合は、ターミナルからも使える。`omarchy transcode ~/Videos/demo.mov mp4 1080p` だ。画像を ASCII アートに変換する `omarchy transcode ascii` もある。こちらは主に [ブランディング](41-branding.md) 用だ。

## どこかへ送信する

ファイルが手に入ったら、`Super + Ctrl + S` で Share メニューを開き、LocalSend 経由でネットワーク上の別のデバイスに送信できる。それについては [GUIs](22-guis.md) を参照すること。
