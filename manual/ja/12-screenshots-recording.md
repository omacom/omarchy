# スクリーンショットと録画

画面から取得できるものはすべて Print Screen キーにぶら下がっています。1 つのキー単独で写真を撮り、修飾キーで録画、色、または領域内のテキストを取得します。キーボードに Print Screen キーがまったくない場合は、`Super + Ctrl + C` で同じセットがメニューとして開きます。

| ホットキー | 機能 |
| ------ | -------- |
| `Print Screen` | スクリーンショット |
| `Alt + Print Screen` | 画面録画（または実行中のものを停止） |
| `Super + Print Screen` | カラーピッカー |
| `Super + Ctrl + Print Screen` | 領域からテキストを抽出 |
| `Super + Ctrl + C` | キャプチャメニュー |
| `Super + Ctrl + .` | 画像または動画を変換 |

## スクリーンショット

`Print Screen` を押すと、Omasnap はオーバーレイが表示される前にフォーカスされたモニターをキャプチャするので、狙っている間に何かが下でずれることはありません。フリーフォームの領域をドラッグするか、ウィンドウをクリックしてキャプチャするか、開いたスペースをクリックしてモニター全体をキャプチャしてください。描画前に `S` を押すとスクロール領域をキャプチャできます。気が変わりましたか？ もう一度 `Print Screen` を押すと Omasnap を閉じます。

領域を選択すると、Omasnap はキャプチャを保存し、クリップボードにコピーし、10 秒間プレビューを表示します。プレビューのピンボタンまたは `Ctrl + P` で画面に留めておくか、Edit を選んで注釈を付けてください。

注釈エディタでは、矢印、線、図形、ハイライト、番号付きマーカー、テキスト、安全な墨消しを描いたり、画像の一部を切り取ったり切り抜いたり、テキストを OCR したり、背景を追加したりできます。エディタでは、`Enter` を押して完成した PNG をコピーして保存するか、`Ctrl + C` で保存せずにコピーするか、`Ctrl + S` でコピーせずに保存してください。

保存されたスクリーンショットはデフォルトで `~/Pictures/Screenshots` に入り、`screenshot-2026-08-13_14-22-05-firefox.png` のような名前が付きます。別のディレクトリを使うには `OMASNAP_SCREENSHOT_DIR` を設定してください。セッション環境変数をどこに置くかは [FAQ](46-faq.md) を参照してください。Omasnap は最初のショットを保存するときにそのディレクトリを作成します。自動保存を無効にするには、`~/.config/omasnap/omasnap.conf` で `[output] autosave = false` を設定してください。

ターミナルからは、`omarchy screenshot` で同じオーバーレイが開き、開始モードを選べます：`omarchy capture screenshot region`、`windows`、`fullscreen`、`scroll` です。第 2 引数に `copy` または `save` を指定するとプレビューをスキップし、ショットを直接その宛先へ送ります。出力前に編集するには、全画面エディタには `omarchy screenshot --editor=overlay` を、別ウィンドウには `omarchy screenshot --editor=window` を使ってください。

### キーボードでピッカーを操作する

選択が表示されている間は、マウスをまったく使う必要がありません：

| キー | 機能 |
| --- | -------- |
| `S` | スクロール領域モードを切り替える |
| `Super + Arrow keys` | Window モードでウィンドウ間を移動 |
| `Return` | ハイライトされたウィンドウをキャプチャ |
| `Ctrl + A` | フォーカスされたモニター全体をキャプチャ |
| `R` | このセッションで描いた最後の領域を復元 |
| `Esc` | Omasnap を閉じる |

これらのバインドは Omasnap が開いている間だけ存在するので、自分の設定と衝突することはありません。

## 画面録画

`Alt + Print Screen` は _実行 > キャプチャ > 画面録画_ を開き、サウンドトラックに何が欲しいか聞きます：オーディオなし、デスクトップオーディオ、デスクトップ＋マイク、デスクトップ＋マイク＋Web カメラです。最後のものは、実際にカメラが接続されている場合にのみ表示されます。1 つ選ぶと、Omarchy の録画ピッカーで領域をドラッグしたり、ウィンドウやモニターをクリックしたりできます。

録画は gpu-screen-recorder で動作し、60fps で GPU でエンコードし、必要なら CPU にフォールバックします。結果は `~/Videos` に入り、`screenrecording-2026-08-13_14-22-05.mp4` と名付けられます。それを変更するには `OMARCHY_SCREENRECORD_DIR` を設定してください。ただしスクリーンショットディレクトリと違って、こちらはすでに存在しなければならず、存在しない場合は録画が開始を拒否することに注意してください。

録画中は、バーに小さなインジケーターが表示されます。それをクリックすると停止します。もう一度 `Alt + Print Screen` を押したり、_実行 > キャプチャ > 画面録画_ の下の _画面録画を停止_ エントリ（実際に何かが録画されている間だけ表示されます）でも停止できます。

停止すると、ファイルを渡す前に少し整理をします：最初のフレームがトリミングされ、オーディオがある場合は -14 LUFS に正規化され、冒頭の PipeWire キャプチャのポップ音がミュートされます。次に、録画からのサムネイル付きの通知が表示されます。それをクリックすると mpv でファイルが再生されます。

### Web カメラオーバーレイ

Web カメラで録画すると、カメラは録画しているものの右下隅に、ピン留めされた切り取られたポートレートウィンドウとして表示されます。必要なものの上に座っている場合は、その場でリサイズしてください：

| ホットキー | 機能 |
| ------ | -------- |
| `Super + Alt + [` | Web カメラオーバーレイを小さく |
| `Super + Alt + ]` | Web カメラオーバーレイを大きく |

サイズは 3 つ（小、中、大）あり、ホットキーでその間をステップ移動します。中がデフォルトです。録画に比例するので、1080p モニターを録画していようと 6K モニターを録画していようと、カメラはフレームの同じ割合を占めます。そしてディスプレイ全体ではなく領域を録画した場合、オーバーレイはモニターの隅ではなくその領域の隅に固定されるので、ショットの中に収まります。

`omarchy-capture-webcam-resize small` で直接呼んだり、`reset` で中に戻したりすることもできます。

## テキスト、QR コード、色

`Super + Ctrl + Print Screen` は領域を選択し、それを OCR してクリップボードに載せます。それは [テキスト抽出とディクテーション](11-text-extraction-dictation.md) で詳しく扱います。

_実行 > キャプチャ > QR コード_ は QR コードにも同じ手品を使います。コードを含む領域を選択すると、デコードされた値がクリップボードに入ります。QR コードだけを探します。密度の高い画面コンテンツは、そうでないとバーコードとして誤検出する癖があります。知っておく価値のあること：デコードされた値はクリップボードにだけ入り、他にはどこにも行きません。印刷されず、通知にもなく、センシティブとしてマークされるので [クリップボード履歴](08-unified-clipboard-history.md) に残りません。QR コードは日常的に秘密を運びます。例えば 2FA セットアップコードの背後にある `otpauth://` URI などです。それをログに残したくはないでしょう。貼り付けは問題なく動きます。

`Super + Print Screen`（または _実行 > キャプチャ > 色_）はカーソルをスポイトに変えます。画面上の何かをクリックすると、その色がクリップボードに載ります。もう一度ホットキーを押すと拾わずに戻ります。

## 共有前の変換

4K 画面録画や携帯電話からの生の HEIC は、送るには大きすぎることがよくあります。`Super + Ctrl + .`（または _実行 > 変換_）でそれを修正できます。`~/Pictures` と `~/Videos` のあいまいファイルピッカーを提示し、次に形式とサイズを聞きます。

画像は高、中、低の jpg または png になり、幅は 3160、2160、1080 ピクセルが上限です。動画は 4k、1080p、720p の mp4 またはアニメーション gif になります。変換されたファイルは元のファイルの隣に、解像度を名前に含めて書き込まれ（`demo-1080p.mp4`）、パスはファイル URI としてクリップボードにコピーされるので、ファイルドロップを受け付けるアプリに直接貼り付けられます。

ターミナルからも動きます。すでに欲しいものが分かっている場合：`omarchy transcode ~/Videos/demo.mov mp4 1080p`。画像を ASCII アートに変換する `omarchy transcode ascii` もあります。これは主に [ブランディング](41-branding.md) 用です。

## どこかへ送る

ファイルができたら、`Super + Ctrl + S` で共有メニューを開き、LocalSend 経由でネットワーク上の別のデバイスへ送信します。それについては [GUI](22-guis.md) を参照してください。
