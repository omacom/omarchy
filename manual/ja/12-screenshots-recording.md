# スクリーンショットと録画

画面から取り込めるものはすべて Print Screen キーにぶら下がっている。そのキー単体で画像を取り込み、修飾キーとの組み合わせで録画、色、または領域内のテキストを取り込む。キーボードに Print Screen キーがそもそもない場合は、`Super + Ctrl + Alt + C` で同じスクリーンショットが撮れ、`Super + Ctrl + C` で一式すべてがメニューとして開く。

| ホットキー | 機能 |
| ------ | -------- |
| `Print Screen` | スクリーンショット |
| `Super + Ctrl + Alt + C` | スクリーンショット |
| `Alt + Print Screen` | 画面録画（または実行中の録画を停止） |
| `Super + Print Screen` | カラーピッカー |
| `Super + Ctrl + Print Screen` | 領域からテキストを抽出 |
| `Super + Ctrl + C` | Capture メニュー |
| `Super + Ctrl + .` | 画像または動画をトランスコード |

## スクリーンショット

`Print Screen`（または `Super + Ctrl + Alt + C`）を押すと、Omasnap はオーバーレイが表示される前にフォーカス中のモニターをキャプチャするので、狙いを定めている間に下のものがずれることはない。自由な形の領域をドラッグしたり、ウィンドウをクリックしてそれをキャプチャしたり、空いた場所をクリックしてモニター全体をキャプチャしたりできる。描画する前に `S` を押すと、スクロールする領域をキャプチャできる気が変わったか？同じキーをもう一度押せば Omasnap を閉じられる。

領域を選択すると、Omasnap はキャプチャを保存し、クリップボードにコピーし、保存された画面録画と同じように、そのサムネイル付きの通知を表示する。Open を選ぶと保存したショットを画像ビューアーで表示でき、Edit を選ぶと注釈を付けられる。

注釈エディターでは、矢印、線、図形、ハイライト、番号付きマーカー、テキスト、安全な墨消しを描画したり、画像の一部を切り抜いたり切り取ったり、テキストを OCR したり、背景を追加したりできる。エディターでは、`Enter` を押すと完成した PNG をコピーして保存し、`Ctrl + C` を押すと保存せずにコピーし、`Ctrl + S` を押すとコピーせずに保存する。

保存されたスクリーンショットはデフォルトで `~/Pictures/Screenshots` に置かれ、`screenshot-2026-08-13_14-22-05-firefox.png` のような名前が付けられる。別のディレクトリを使うには `OMASNAP_SCREENSHOT_DIR` を設定すること。セッション環境変数を置く場所については [FAQ](46-faq.md) を参照すること。Omasnap は最初のショットを保存するときにディレクトリを作成する。自動保存を無効にするには、`~/.config/omasnap/omasnap.conf` で `[output] autosave = false` を設定すること。その場合、キャプチャはコピーされるだけになり、10 秒間プレビューが表示される。このプレビューは、ピンボタンまたは `Ctrl + P` で画面に留めておける。

ターミナルからは、`omarchy screenshot` で同じオーバーレイが開き、開始モードを選択できる：`omarchy capture screenshot region`、`windows`、`fullscreen`、または `scroll` だ。2 番目の引数に `copy` または `save` を指定すると、ショットはその宛先に直接送られる。出力前に編集するには、フルスクリーンエディターなら `omarchy screenshot --editor=overlay` を、別ウィンドウなら `omarchy screenshot --editor=window` を使う。

### キーボードでピッカーを操作する

選択画面が表示されている間は、マウスをまったく使う必要はない：

| キー | 機能 |
| --- | -------- |
| `S` | スクロール領域モードを切り替える |
| `Super + Arrow keys` | Window モードでウィンドウ間を移動する |
| `Return` | ハイライトされたウィンドウをキャプチャする |
| `Ctrl + A` | フォーカス中のモニター全体をキャプチャする |
| `R` | このセッションで最後に描いた領域を復元する |
| `Esc` | Omasnap を閉じる |

これらのバインディングは Omasnap が開いている間だけ存在するので、自分の設定の何かと衝突することはない。

## 画面録画

`Alt + Print Screen` を押すと _Trigger > Capture > Screenrecord_ が開き、サウンドトラックに何を入れるかを尋ねる：音声なし、デスクトップ音声、デスクトップとマイク、またはデスクトップとマイクとウェブカメラだ。最後のものは、実際にカメラが接続されている場合にだけ表示される。1 つ選ぶと、Omarchy の録画ピッカーで領域をドラッグしたり、ウィンドウやモニターをクリックしたりできる。

録画は gpu-screen-recorder で動作し、GPU で 60fps でエンコードし、必要なら CPU にフォールバックする。結果は `~/Videos` にある MP4 で、`screenrecording-2026-08-13_14-22-05.mp4` のような名前が付けられる。それを変更するには `OMARCHY_SCREENRECORD_DIR` を設定すること。ただし、スクリーンショットのディレクトリとは違い、こちらはあらかじめ存在していなければならない。そうでないと録画は開始を拒否することに注意すること。

録画中は、バーに小さなインジケーターが表示される。クリックすると停止する。`Alt + Print Screen` をもう一度押しても停止でき、_Trigger > Capture > Screenrecord_ の下にある _Stop Screenrecording_ 項目でも停止できる。この項目は、実際に何かが録画されている間だけ表示される。

停止すると、ファイルを渡す前に少し後片付けをする：最初のフレームがトリミングされ、音声がある場合は -14 LUFS に正規化され、一番最初にある PipeWire キャプチャのポップ音がミュートされる。その後、録画から取ったサムネイル付きの通知が表示される。クリックすると Omaview でファイルが再生される。

### ウェブカメラオーバーレイ

ウェブカメラ付きで録画すると、カメラは録画しているものの右下隅に、ピン留めされ、切り抜かれたポートレートウィンドウとして表示される。必要なものの上に重なっている場合は、その場でサイズを変更できる：

| ホットキー | 機能 |
| ------ | -------- |
| `Super + Alt + [` | ウェブカメラオーバーレイを小さくする |
| `Super + Alt + ]` | ウェブカメラオーバーレイを大きくする |

サイズは小、中、大の 3 つあり、ホットキーでその間を段階的に切り替える。中がデフォルトだ。サイズは録画に比例するので、1080p のモニターを録画していても 6K のモニターを録画していても、カメラがフレームに占める割合は同じだ。また、ディスプレイ全体ではなく領域を録画した場合は、オーバーレイはモニターの隅ではなくその領域の隅に固定されるので、ショットの中に収まったままになる。

`omarchy-capture-webcam-resize small` で直接呼び出すこともでき、中に戻すには `reset` を使う。

## テキスト、QR コード、色

`Super + Ctrl + Print Screen` は領域を選択し、それを OCR してクリップボードに入れる。それについては [テキスト抽出とディクテーション](11-text-extraction-dictation.md) でちゃんと取り上げている。

_Trigger > Capture > QR Code_ も QR コードに対して同じ手口を使う。コードが入っている領域を選択すると、デコードされた値がクリップボードに入る。探すのは QR コードだけだ。そうしないと、密度の高い画面コンテンツはバーコードとして誤検出する癖がある。知っておくべきこと：デコードされた値はクリップボードにだけ入り、それ以外のどこにも行かない。印刷されず、通知にも入らず、機密としてマークされるので [クリップボード履歴](08-unified-clipboard-history.md) に残らない。QR コードは日常的に秘密を運ぶ。例えば 2FA セットアップコードの背後にある `otpauth://` URI だ。そんなものをログに入れたくはないだろう。貼り付けは問題なく動作する。

`Super + Print Screen`（または _Trigger > Capture > Color_）でカーソルがスポイトになる。画面上の何かをクリックすると、その色がクリップボードに入る。拾わずにやめるには、ホットキーをもう一度押す。

## 共有前のトランスコード

4K の画面録画や、スマートフォンから取り込んだそのままの HEIC は、たいていそのまま送るには大きすぎる。`Super + Ctrl + .`（または _Trigger > Transcode_）がそれを解決する。`~/Pictures` と `~/Videos` を対象にしたあいまい検索ファイルピッカーが表示され、その後フォーマットとサイズを尋ねる。

画像は jpg または png になり、高、中、低では幅が 3160、2160、1080 ピクセルに制限される。動画は mp4 またはアニメーション gif になり、4k、1080p、または 720p になる。変換されたファイルは元のファイルの隣に、名前に解像度を入れて書き込まれ（`demo-1080p.mp4`）、そのパスがファイル URI としてクリップボードにコピーされるので、ファイルドロップを受け付けるアプリに直接貼り付けられる。

すでに何が欲しいか分かっているなら、ターミナルからも動作する：`omarchy transcode ~/Videos/demo.mov mp4 1080p` だ。`omarchy transcode ascii` もあり、これは画像を ASCII アートに変換する。そちらは主に [ブランディング](41-branding.md) 用だ。

## どこかへ送る

ファイルが手に入ったら、`Super + Ctrl + S` で Share メニューが開き、LocalSend 経由でネットワーク上の別のデバイスに送る。それについては [GUIs](22-guis.md) を参照すること。
