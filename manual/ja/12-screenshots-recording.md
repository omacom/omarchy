# スクリーンショットと録画

画面から取得できるものはすべて Print Screen キーに集約されている。キー単体で写真を撮り、修飾キーとの組み合わせで録画、色、領域内のテキストを取得する。キーボードに Print Screen キーがまったくない場合は、`Super + Ctrl + Alt + C` で同じスクリーンショットを撮り、`Super + Ctrl + C` で一式をメニューとして開く。

| Hotkey | Function |
| ------ | -------- |
| `Print Screen` | スクリーンショット |
| `Super + Ctrl + Alt + C` | スクリーンショット |
| `Alt + Print Screen` | 画面録画（または実行中の録画を停止） |
| `Super + Print Screen` | カラーピッカー |
| `Super + Ctrl + Print Screen` | 領域からテキストを抽出 |
| `Super + Ctrl + C` | キャプチャメニュー |
| `Super + Ctrl + .` | 画像または動画をトランスコード |

## スクリーンショット

`Print Screen`（または `Super + Ctrl + Alt + C`）を押すと、Omasnap はオーバーレイが表示される前にフォーカス中のモニターをキャプチャするので、狙いを定めている間に下のものがずれることはない。自由な領域をドラッグしたり、ウィンドウをクリックしてキャプチャしたり、何もない場所をクリックしてモニター全体をキャプチャしたりできる。描画する前に `S` を押すと、スクロール領域をキャプチャする。気が変わった場合は、同じキーをもう一度押せば Omasnap を閉じられる。

領域を選択すると、Omasnap はキャプチャを保存し、クリップボードにコピーし、10 秒間プレビューを表示する。プレビューのピンボタンを使うか `Ctrl + P` を押すと画面に残しておけるし、Edit を選ぶと注釈を付けられる。

注釈エディターでは、矢印、線、図形、ハイライト、番号付きマーカー、テキスト、安全な墨消しを描画したり、画像の一部を切り取ったり切り抜いたり、テキストを OCR したり、背景を追加したりできる。エディターで `Enter` を押すと完成した PNG をコピーして保存し、`Ctrl + C` を押すと保存せずにコピーし、`Ctrl + S` を押すとコピーせずに保存する。

保存したスクリーンショットはデフォルトで `~/Pictures/Screenshots` に入り、`screenshot-2026-08-13_14-22-05-firefox.png` のような名前が付く。別のディレクトリを使うには `OMASNAP_SCREENSHOT_DIR` を設定する。セッション環境変数をどこに置くかは[FAQ](46-faq.md)を参照。Omasnap は最初の撮影を保存するときにディレクトリを作成する。自動保存を無効にするには、`~/.config/omasnap/omasnap.conf` で `[output] autosave = false` を設定する。

ターミナルから `omarchy screenshot` を実行すると同じオーバーレイが開き、開始モードも選べる：`omarchy capture screenshot region`、`windows`、`fullscreen`、`scroll`。第 2 引数に `copy` または `save` を指定するとプレビューをスキップし、撮影結果をその宛先へ直接送る。出力前に編集するには、フルスクリーンエディターの場合は `omarchy screenshot --editor=overlay` を、別ウィンドウの場合は `omarchy screenshot --editor=window` を使う。

### ピッカーをキーボードで操作する

選択画面が表示されている間は、マウスをまったく使わなくても操作できる：

| Key | Function |
| --- | -------- |
| `S` | スクロール領域モードを切り替え |
| `Super + Arrow keys` | Window モードでウィンドウ間を移動 |
| `Return` | 強調表示されたウィンドウをキャプチャ |
| `Ctrl + A` | フォーカス中のモニター全体をキャプチャ |
| `R` | このセッションで最後に描画した領域を復元 |
| `Esc` | Omasnap を閉じる |

これらのバインディングは Omasnap が開いている間だけ存在するので、自分の設定と競合することはない。

## 画面録画

`Alt + Print Screen` を押すと _Trigger > Capture > Screenrecord_ が開き、サウンドトラックに何を入れるか尋ねられる：音声なし、デスクトップ音声、デスクトップとマイク、デスクトップとマイクとウェブカメラ。最後のものは、カメラが実際に接続されている場合にだけ表示される。1 つ選ぶと、Omarchy の録画ピッカーで領域をドラッグしたり、ウィンドウやモニターをクリックしたりできる。

録画は gpu-screen-recorder で動作し、GPU で 60fps でエンコードし、必要に応じて CPU にフォールバックする。結果は `~/Videos` 内の MP4 で、名前は `screenrecording-2026-08-13_14-22-05.mp4` となる。それを変更するには `OMARCHY_SCREENRECORD_DIR` を設定する。ただし、スクリーンショットのディレクトリとは違い、こちらは事前に存在していないと録画が開始を拒否する点に注意。

録画中はバーに小さなインジケーターが表示される。クリックすると停止する。`Alt + Print Screen` をもう一度押して停止することもできるし、_Trigger > Capture > Screenrecord_ の下にある _Stop Screenrecording_ 項目でも停止できる。これは実際に何かが録画中のときだけ表示される。

停止すると、ファイルを渡す前に少し後片付けをする：最初のフレームがトリミングされ、音声がある場合は -14 LUFS に正規化され、一番最初にある PipeWire キャプチャのポップ音がミュートされる。その後、録画から取得したサムネイル付きの通知が表示される。クリックすると mpv でファイルを再生する。

### ウェブカメラオーバーレイ

ウェブカメラを使って録画すると、カメラはピン留めされトリミングされたポートレートウィンドウとして、録画対象の右下隅に表示される。必要なものの上に重なっている場合は、その場でサイズを変更できる：

| Hotkey | Function |
| ------ | -------- |
| `Super + Alt + [` | ウェブカメラオーバーレイを小さくする |
| `Super + Alt + ]` | ウェブカメラオーバーレイを大きくする |

サイズは小、中、大の 3 つがあり、ホットキーで切り替える。中がデフォルトだ。録画に比例するので、1080p モニターを録画しても 6K モニターを録画しても、カメラがフレームに占める割合は同じだ。ディスプレイ全体ではなく領域を録画した場合は、オーバーレイはモニターではなくその領域の隅に固定されるので、ショットの中に収まる。

`omarchy-capture-webcam-resize small` で直接呼び出すこともできるし、`reset` で中に戻すこともできる。

## テキスト、QR コード、色

`Super + Ctrl + Print Screen` は領域を選択し、OCR してクリップボードに入れる。それについては[テキスト抽出とディクテーション](11-text-extraction-dictation.md)で詳しく説明している。

_Trigger > Capture > QR Code_ は QR コードに対して同じことをする。コードが含まれる領域を選択すると、デコードされた値がクリップボードに入る。探すのは QR コードだけだ。そうしないと、密度の高い画面コンテンツはバーコードとして誤検出する癖があるからだ。知っておくべきこと：デコードされた値はクリップボードに入るだけで、それ以外にはどこにも行かない。出力されず、通知にも入らず、機密としてマークされるので[クリップボード履歴](08-unified-clipboard-history.md)にも残らない。QR コードには秘密が日常的に含まれている。たとえば 2FA セットアップコードの背後にある `otpauth://` URI だ。そんなものをログに入れたくはないだろう。貼り付けは問題なく動作する。

`Super + Print Screen`（または _Trigger > Capture > Color_）を押すとカーソルがスポイトになる。画面上の何かをクリックすると、その色がクリップボードに入る。ホットキーをもう一度押すと、選ばずに戻ることができる。

## 共有前のトランスコード

4K の画面録画や、スマートフォンから取得した生の HEIC は、そのまま送るには大きすぎることが多い。`Super + Ctrl + .`（または _Trigger > Transcode_）がそれを解決する。`~/Pictures` と `~/Videos` を対象にあいまいなファイルピッカーが表示され、次に形式とサイズを尋ねられる。

画像は jpg または png になり、高、中、低では幅が最大でそれぞれ 3160、2160、1080 ピクセルに制限される。動画は mp4 またはアニメーション gif になり、4k、1080p、720p を選べる。変換されたファイルは、元のファイルの隣に解像度を含めた名前で書き出される — `demo-1080p.mp4` — パスはファイル URI としてクリップボードにコピーされるので、ファイルドロップを受け付けるアプリに直接貼り付けられる。

すでにやりたいことが分かっている場合は、ターミナルからも動作する：`omarchy transcode ~/Videos/demo.mov mp4 1080p`。`omarchy transcode ascii` もあり、画像を ASCII アートに変換する。こちらは主に[ブランディング](41-branding.md)用だ。

## どこかへ送る

ファイルが用意できたら、`Super + Ctrl + S` で Share メニューが開き、LocalSend 経由でネットワーク上の別のデバイスへ送る。それについては[GUIs](22-guis.md)を参照。
