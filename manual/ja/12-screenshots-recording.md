# スクリーンショットと録画

画面に映っているものを取り込む機能は、すべて Print Screen キーに集約されています。このキー単体で写真を撮り、修飾キーを組み合わせると録画、色、領域内のテキストを取り出せます。キーボードに Print Screen キー自体がない場合は、`Super + Ctrl + Alt + C` で同じスクリーンショットが撮れ、`Super + Ctrl + C` で一式をメニューとして開けます。

| ホットキー | 機能 |
| ------ | -------- |
| `Print Screen` | スクリーンショット |
| `Super + Ctrl + Alt + C` | スクリーンショット |
| `Alt + Print Screen` | 画面録画（または実行中のものを停止） |
| `Super + Print Screen` | カラーピッカー |
| `Super + Ctrl + Print Screen` | 領域からテキストを抽出 |
| `Super + Ctrl + C` | キャプチャメニュー |
| `Super + Ctrl + .` | 画像または動画をトランスコード |

## スクリーンショット

`Print Screen`（または `Super + Ctrl + Alt + C`）を押すと、Omasnap はオーバーレイが表示される前にフォーカスのあるモニターをキャプチャするので、狙っている間に下で何かがずれることはありません。自由な形の領域をドラッグしたり、ウィンドウをクリックしてそれをキャプチャしたり、何もない場所をクリックしてモニター全体をキャプチャしたりできます。描画する前に `S` を押すと、スクロールする領域をキャプチャできます。気が変わりましたか？ 同じキーをもう一度押せば Omasnap を閉じられます。

領域を選択すると、Omasnap はキャプチャを保存し、クリップボードにコピーし、保存済みの画面録画と同じようにサムネイル付きの通知を表示します。Open を選ぶと保存した画像を画像ビューアーで表示し、Edit を選ぶと注釈を付けられます。

注釈エディターでは、矢印、線、図形、ハイライト、番号付きマーカー、テキスト、安全な墨消しを描画したり、画像の一部を切り取ったり切り抜いたり、テキストを OCR したり、背景を追加したりできます。エディターでは、`Enter` を押すと完成した PNG をコピーして保存し、`Ctrl + C` を押すと保存せずにコピーし、`Ctrl + S` を押すとコピーせずに保存します。

保存したスクリーンショットは、デフォルトで `~/Pictures/Screenshots` に置かれ、`screenshot-2026-08-13_14-22-05-firefox.png` のような名前が付きます。別のディレクトリを使うには `OMASNAP_SCREENSHOT_DIR` を設定してください。セッション環境変数をどこに置くかについては [FAQ](46-faq.md) を参照してください。Omasnap は最初の画像を保存するときにそのディレクトリを作成します。自動保存を無効にするには、`~/.config/omasnap/omasnap.conf` で `[output] autosave = false` と設定してください。その場合、キャプチャはコピーされるだけになり、7 秒間プレビューが表示されます。ピンボタンまたは `Ctrl + P` でそのプレビューを画面に留めておけます。

ターミナルから `omarchy screenshot` を実行しても同じオーバーレイが開きます。開始モードは `omarchy capture screenshot region`、`windows`、`fullscreen`、`scroll` から選べます。2 番目の引数に `copy` または `save` を指定すると、画像がその宛先へ直接送られます。出力前に編集するには、フルスクリーンエディターなら `omarchy screenshot --editor=overlay` を、別ウィンドウなら `omarchy screenshot --editor=window` を使ってください。

### キーボードでピッカーを操作する

選択画面が表示されている間は、マウスをまったく使う必要はありません。

| キー | 機能 |
| --- | -------- |
| `S` | スクロール領域モードを切り替え |
| `Super + Arrow keys` | Window モードでウィンドウ間を移動 |
| `Return` | ハイライトされたウィンドウをキャプチャ |
| `Ctrl + A` | フォーカスのあるモニター全体をキャプチャ |
| `R` | このセッションで最後に描いた領域を復元 |
| `Esc` | Omasnap を閉じる |

これらのバインディングは Omasnap が開いている間だけ存在するので、自分の設定内の何かと衝突することはありません。

## 画面録画

`Alt + Print Screen` を押すと _Trigger > Capture > Screenrecord_ が開き、サウンドトラックに何を入れるか尋ねられます。オーディオなし、デスクトップオーディオ、デスクトップとマイク、またはデスクトップとマイクとウェブカメラです。最後のものは、カメラが実際に接続されている場合にだけ表示されます。1 つ選ぶと、Omarchy の録画ピッカーで領域をドラッグしたり、ウィンドウやモニターをクリックしたりできます。

録画は gpu-screen-recorder で実行され、GPU で 60fps エンコードし、必要なら CPU にフォールバックします。Apple Silicon のような、サポートしていない GPU では、Omarchy は代わりに wf-recorder で録画します。結果は `~/Videos` 内の MP4 で、`screenrecording-2026-08-13_14-22-05.mp4` のような名前が付きます。それを変更するには `OMARCHY_SCREENRECORD_DIR` を設定してください。ただし、スクリーンショットのディレクトリとは違い、こちらはあらかじめ存在していなければならないことに注意してください。存在しないと録画は開始を拒否します。

録画中は、バーに小さなインジケーターが表示されます。クリックすると停止します。`Alt + Print Screen` をもう一度押して停止することもできますし、_Trigger > Capture > Screenrecord_ の下にある _Stop Screenrecording_ エントリでも停止できます。こちらは実際に何かが録画中のときにだけ表示されます。

停止すると、ファイルを渡す前に少し整理が行われます。最初のフレームがトリミングされ、オーディオがある場合は -14 LUFS に正規化され、冒頭の PipeWire キャプチャのポップ音がミュートされます。その後、録画のサムネイル付きの通知が表示されます。_Open_ を選ぶと Omaview でファイルを再生し、_Cut_ を選ぶと Omacut でトリミングします。

### ウェブカメラオーバーレイ

ウェブカメラ付きで録画すると、カメラは録画しているものの右下隅に、固定された切り抜き済みの縦向きウィンドウとして表示されます。必要なものの上に重なっている場合は、その場でサイズを変更できます。

| ホットキー | 機能 |
| ------ | -------- |
| `Super + Alt + [` | ウェブカメラオーバーレイを小さくする |
| `Super + Alt + ]` | ウェブカメラオーバーレイを大きくする |

サイズは small、medium、large の 3 つで、ホットキーでその間を段階的に切り替えます。Medium がデフォルトです。これらは録画に比例するので、1080p モニターを録画していても 6K モニターを録画していても、カメラがフレームに占める割合は同じです。ディスプレイ全体ではなく領域を録画した場合は、オーバーレイはモニターの隅ではなくその領域の隅に固定されるので、画像の中に収まります。

`omarchy-capture-webcam-resize small` で直接呼び出すこともできますし、`reset` で medium に戻すこともできます。

## テキスト、QR コード、色

`Super + Ctrl + Print Screen` で領域を選択すると、それを OCR してクリップボードに入れます。それについては [テキスト抽出とディクテーション](11-text-extraction-dictation.md) でちゃんと取り上げています。

_Trigger > Capture > QR Code_ は QR コードに対して同じ芸当をします。コードが入っている領域を選択すると、デコードされた値がクリップボードに入ります。QR コードだけを探します。画面の内容が密だと、そうでなければバーコードとして誤検出する癖があるからです。知っておくべきこととして、デコードされた値はクリップボードにしか入りません。表示されることも、通知に入ることもなく、機密としてマークされるので [クリップボード履歴](08-unified-clipboard-history.md) に残りません。QR コードは日常的に秘密を運んでいます。たとえば 2FA セットアップコードの背後にある `otpauth://` URI がそうで、それをログに入れたくはないでしょう。貼り付けは問題なく動きます。

`Super + Print Screen`（または _Trigger > Capture > Color_）を押すと、カーソルがスポイトに変わります。画面上の何かをクリックすると、その色がクリップボードに入ります。もう一度ホットキーを押すと、選ばずにやめられます。

## 共有する前にトランスコードする

4K の画面録画や、スマートフォンから取り出した生の HEIC は、そのまま送るには大きすぎることがよくあります。`Super + Ctrl + .`（または _Trigger > Transcode_）でそれを直せます。`~/Pictures` と `~/Videos` を対象にしたあいまいなファイルピッカーが表示され、次に形式とサイズを尋ねられます。

画像は high、medium、low で jpg または png になり、幅はそれぞれ 3160、2160、1080 ピクセルが上限になります。動画は 4k、1080p、720p で mp4 またはアニメーション gif になります。変換されたファイルは元のファイルの隣に、名前に解像度を含めて書き込まれ（`demo-1080p.mp4`）、そのパスはファイル URI としてクリップボードにコピーされるので、ファイルドロップを受け付けるアプリに直接貼り付けられます。

すでに何が欲しいか分かっているなら、ターミナルからも動きます。`omarchy transcode ~/Videos/demo.mov mp4 1080p` です。画像を ASCII アートに変える `omarchy transcode ascii` もあります。そちらは主に [ブランディング](41-branding.md) 用です。

## どこかへ送る

ファイルができたら、`Super + Ctrl + S` で Share メニューを開き、LocalSend 経由でネットワーク上の別のデバイスへ送れます。それについては [GUIs](22-guis.md) を参照してください。
