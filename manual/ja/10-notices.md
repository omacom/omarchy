# 通知

通知はフォーカスのあるディスプレイの右上隅に表示されます。ホットキー通知を使えば、日付と時刻、バッテリーの状態、現在の天気にもすばやくアクセスできます。

## 通知

同じアプリやサイトからの通知はデッキに積み重なるので、おしゃべりな Slack チャンネルがビルド失敗の通知を画面の外に押し出すことはありません。デッキにホバーすると展開します。読んでいる間は、ポインターの下に新しい通知が滑り込んでくることもありません。カードをクリックすると送信元にジャンプし、右クリック、中クリック、または ✕ を押すと消去できます。

カードには、内容に応じた操作が用意されます。認証コード向けの _コードをコピー_（[クリップボード履歴](08-unified-clipboard-history.md) には残らず、1分後に消去されます）に加え、アプリが提供するボタンも使えます。通知テキスト内のリンクはクリックすると開きます。

`Super + ,` は最新の通知を消去するか、通知に遷移先がある場合はそれを開きます。`Super + Alt + ,` は最後の1件だけを消去し、`Super + Shift + ,` はすべてを消去し、`Super + Shift + Alt + ,` は履歴を開きます。マウスなしで操作するには `Super + Ctrl + ,` を押してください。最新の通知が選択され、そのボタンに番号が振られます。数字を押すとそのボタンを使い、`Enter` で通知をクリックし、`↑` と `↓` で通知間を移動し、`Delete` で1件を消去し、`Esc` でキーボードの制御を戻します。数秒間何も操作しなければ、自動的に解除されます。

通知をサイレントにすると通知は抑えられますが、Omarchy 自身の確認、緊急アラート、そしてつい先ほどあなたが求めた認証コードは例外です。抑えられていたかどうかに関係なく、直近の数件を `Super + Shift + Alt + ,` で画面に戻せます。履歴は1日保持されます。

### 天気

`Super + Ctrl + Alt + W`

 ![notice-weather](images/notice-weather.webp)

現在地は IP アドレスから検出されます。通常はそれで十分近い場所になりますが、常に正確とは限りません。`omarchy weather location --set Malibu` で固定できます。座標を追加すれば正確に指定できます: `omarchy weather location --set Malibu 34.0259,-118.7798`。`omarchy weather location` を単独で実行すると現在認識されている場所を確認でき、`--clear` で自動検出に戻せます。
