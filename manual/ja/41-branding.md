# ブランディング

Omarchy では、スクリーンセーバーと About 画面の両方に、会社のロゴや個人の画像を設定できます。

### スクリーンセーバー

スクリーンセーバーに使われるロゴは、_外観 > ブランディング > スクリーンセーバー_ で変更できます。これは ASCII ロゴなので、テキストを直接編集できますが、png や svg 画像を渡すこともでき、そちらを ASCII に変換します。かなりかっこいいですよ。

 ![branding-screensaver](images/branding-screensaver.webp)

そのメニューには3つの項目があります:

- **テキストを編集** は、`~/.config/omarchy/branding/screensaver.txt` をエディターで開きます。好きなものを入力または貼り付けてください — ASCII アート、あなたの名前、汚い言葉でも。保存して終了すると、すぐにスクリーンセーバーが起動して確認できます。
- **画像から設定** は、png または svg 用のファイルピッカーを開き、ASCII に変換して結果を表示します。写真よりも、輪郭のはっきりしたロゴのほうがずっとうまくいきます。
- **デフォルトに戻す** は、Omarchy ロゴに戻します。

### About 画面

同じ3つのオプションが _外観 > ブランディング > About_ にあり、Omarchy メニューから開く _About_ 画面用で、まったく同じように動作します — ファイルは `~/.config/omarchy/branding/about.txt` で、変更のたびに About ウィンドウがポップアップ表示されます。About 用のアートは、ディスプレイを埋めるのではなくウィンドウ内に収める必要があるため、スクリーンセーバー用よりも小さいサイズに変換されます。

ウィンドウが開いている間、数秒ごとに明るい白い光の帯がアートの上を斜めに横切り、その後また静止します。あなた自身のアートも同様で、その中のすべての文字が1列幅である限りそうなります — _画像から設定_ で生成されるものはすべてそうです。絵文字や全角文字で作られたアートは代わりに静止したままになり、自分用の fastfetch 設定を保持している場合も画面は静止します。これらの場合にロゴが静止しているのは、アニメーションが失敗しているのではなく、邪魔をしないようにしているためです。それらの上を光のきらめきを滑らせると、行の残りの部分が間違った位置に来てしまうからです。

 ![branding-about](images/branding-about.webp)

### 画像を自分で変換する

_画像から設定_ のオプションはどちらも、単に `omarchy transcode ascii` を呼び出しているだけです。変換を自分で制御したい場合は、直接実行できます:

```
omarchy transcode ascii ~/logo.svg ~/.config/omarchy/branding/screensaver.txt --width 100
```

これは、ターミナルの列数と行数で指定する `--width` と `--height`、`braille`（デフォルトで、はるかに細かい）または `block` のいずれかの `--mode`、どのピクセルをロゴの一部として数えるかを決めるパーセンテージの `--threshold`、そしてロゴが暗い背景に明るい色である場合のための `--invert` を受け付けます。変換結果が塊のようになってしまったら、通常は threshold が回すべきつまみです。

### ロゴの代わりに言葉を

`omarchy ascii` は、Omarchy のワードマーク自体が描かれている FIGlet フォントである Delta Corps Priest 1 でテキストを描くので、スクリーンセーバーに絵を見せる代わりに何かを言わせることができます:

```
omarchy ascii "Back in five" > ~/.config/omarchy/branding/screensaver.txt
```

テキストを引数として受け取るか、引数が与えられない場合はパイプから読み取ります。このフォントには文字とスペースしか含まれていません — 数字や句読点なしで描かれました — したがって、それ以外のものは黙って飲み込まれるのではなく、破棄され、stderr に名前が出力されます。
