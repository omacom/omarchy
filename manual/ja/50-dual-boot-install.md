# デュアルブートでのインストール

Windows や他のインストールと並べて、単一のパーティションに Omarchy をインストールできる。

このインストール方法でも、デフォルトでパーティションに LUKS 暗号化が適用されるため、実質的にドライブ全体へのインストールと変わらず、ディスクに空き領域があることだけが必要だ。

## Windows で空き領域を作る

Windows と並べてインストールするには、スタートメニューで `disk management` と入力し、**ハード ディスク パーティションの作成とフォーマット** のオプションを選択する。

 ![dual-boot-1](images/dual-boot-1.webp)

適切なパーティションを見つけ、右クリックして **ボリュームの縮小** を選択する。

![dual-boot-2](images/dual-boot-2.webp)

 ボリュームを縮小する容量を入力する。これは、ブートパーティションを含めた、今後の Omarchy インストールのサイズになることに注意すること。

 ![dual-boot-3](images/dual-boot-3.webp)

完了すると、このような表示になるはずだ。この例では、50GB の部分に Omarchy をインストールする。

 ![dual-boot-4](images/dual-boot-4.webp)

## Omarchy のインストール

Omarchy のインストール手順は、実質的に通常と同じだ。ディスクを選択すると、**Free space install** のオプションが表示される。ドライブ全体を消去しないように、そのオプションを選択すること。

 ![dual-boot-5](images/dual-boot-5.webp)

すべて問題ないことを確認し、通常どおりインストールが完了するまで待つ。ここでは、ドライブ全体へのインストールと同様に、暗号化なしでインストールすることも選択できる（推奨しない）。
 ![dual-boot-6](images/dual-boot-6.webp)

## 他のインストールをブートローダーに追加する

Omarchy のインストールが完了すると、Limine ブートローダーがデフォルトになっていることに気づくだろう。これにより、Windows など他のインストール用の選択肢を Limine に追加することもできる。

他のオペレーティングシステムを追加するには、`limine-scan` を実行し、プロンプトに従って、必要なエントリーを Limine の設定に追加する。ブートメニューはデフォルトでは非表示のままで、1 秒後に Omarchy が起動する。Windows や他のエントリーを選択するには、Limine が起動したらすぐに任意のキーを押す。メニューが表示されたら、矢印キーでエントリーを選択し、Enter を押す。キーを押す前に Omarchy が起動してしまった場合は、再起動してもう一度試すこと。

## Bitlocker

このインストール方法は Bitlocker と互換性がないことに注意することが重要だ。Bitlocker はパーティションだけでなく、ドライブ全体を暗号化するためだ。Bitlocker が有効であるというエラーが表示された場合は、Windows を起動し、**設定 -> プライバシーとセキュリティ -> デバイスの暗号化** に移動して、Bitlocker をオフに切り替える。ドライブの暗号化解除には時間がかかる場合がある。

 ![dual-boot-7](images/dual-boot-7.webp)
