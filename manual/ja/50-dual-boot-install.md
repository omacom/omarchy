# デュアルブートインストール

Omarchyは、Windowsや他のインストールと並べて単一のパーティションにインストールできます。

このインストール方法では、デフォルトでパーティションにLUKS暗号化が伴います。そのため実質的にフルドライブの場合と変わらず、必要なのはディスク上の空き領域だけです。

## Windowsで空き領域を作る

Windowsと並べてインストールするには、スタートメニューで`disk management`と入力し、**ハード ディスク パーティションの作成とフォーマット**のオプションを選択してください。

 ![dual-boot-1](images/dual-boot-1.webp)

適切なパーティションを見つけ、右クリックして、**ボリュームの縮小**を選んでください。

![dual-boot-2](images/dual-boot-2.webp)

 縮小したいボリュームの量を入力します。これが、ブートパーティションを含む将来のOmarchyインストールのサイズになることに注意してください。

 ![dual-boot-3](images/dual-boot-3.webp)

終わると、この例のように50GBのセクションがOmarchyをインストールする場所となったような表示が現れるはずです。

 ![dual-boot-4](images/dual-boot-4.webp)

## Omarchyをインストールする

Omarchyのインストールプロセスは実質的に通常と同じです。ディスクを選択した後、**空き領域へのインストール**のオプションが提示されます。フルディスクの消去を防ぐため、そのオプションを選択してください。

 ![dual-boot-5](images/dual-boot-5.webp)

すべてが問題ないことを確認し、通常どおりインストールが終わるのを待ちます。ここは、フルドライブインストールと同様に、暗号化なしでインストールする（非推奨）を選べる場所でもあります。
 ![dual-boot-6](images/dual-boot-6.webp)

## 他のインストールをブートローダーに追加する

Omarchyのインストールを終えると、Limineブートローダーがデフォルトになっていることに気付くでしょう。これを使って、Windowsのような他のインストール向けのオプションをLimineに追加することもできます。

そのためには、`limine-scan`を実行し、プロンプトに従って希望の項目をlimine設定に追加してください。そうすれば、起動時にOmarchy向けの通常のオプションと、Windows Boot Managerやその他のものが表示されます。

## Bitlocker

このインストール方法はBitlockerと互換性がないことに注意してください。Bitlockerはパーティションだけでなくドライブ全体を暗号化するためです。Bitlockerが有効であることを示すエラーに遭遇した場合は、Windowsを起動し、**設定 -> プライバシーとセキュリティ -> デバイスの暗号化**に進んでBitlockerをオフにしてください。ドライブの復号化には時間がかかる場合があります。

 ![dual-boot-7](images/dual-boot-7.webp)
