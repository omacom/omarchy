# デュアルブートインストール

Windows や他のインストールと並べて、Omarchy を1つのパーティションにインストールできます。

このインストール方法でもデフォルトでパーティションに LUKS 暗号化が適用されるため、実質的にはドライブ全体へのインストールと違いはなく、ディスクに空き領域があればよいだけです。

## Windows で空き領域を作る

Windows と並べてインストールするには、スタートメニューで `disk management` と入力し、**ハードディスク パーティションの作成とフォーマット**というオプションを選択します。

 ![dual-boot-1](images/dual-boot-1.webp)

該当するパーティションを見つけ、右クリックして**ボリュームの縮小**を選択します。

![dual-boot-2](images/dual-boot-2.webp)

 縮小する量を入力します。これが、ブートパーティションを含めた、将来の Omarchy インストールのサイズになることに注意してください。

 ![dual-boot-3](images/dual-boot-3.webp)

終了すると、この例では 50GB の部分に Omarchy をインストールする、といったような表示になるはずです。

 ![dual-boot-4](images/dual-boot-4.webp)

## Omarchy のインストール

Omarchy のインストールプロセスは、実質的には通常と同じです。ディスクを選択すると、**Free space install** というオプションが表示されます。ドライブ全体が消去されるのを防ぐため、そのオプションを選択してください。

 ![dual-boot-5](images/dual-boot-5.webp)

すべて問題ないことを確認し、通常どおりインストールが終わるのを待ちます。ここでは、ドライブ全体へのインストールと同様に、暗号化せずにインストールすることも選択できます（非推奨）。
 ![dual-boot-6](images/dual-boot-6.webp)

## 他のインストールをブートローダーに追加する

Omarchy のインストールが終わると、Limine ブートローダーがデフォルトになっていることに気づくでしょう。これを使えば、Windows など他のインストール用のオプションを Limine に追加することもできます。

他のオペレーティングシステムを追加するには、`limine-scan` を実行し、プロンプトに従って希望するエントリを Limine の設定に追加します。ブートメニューはデフォルトでは非表示のままで、1秒後に Omarchy が起動します。Windows や別のエントリを選ぶには、Limine が起動したらすぐに何かキーを押してください。メニューが表示されたら、矢印キーでエントリを選択し、Enter を押します。キーを押す前に Omarchy が起動してしまった場合は、再起動してもう一度試してください。

## Bitlocker

このインストール方法は Bitlocker と互換性がないことに注意することが重要です。Bitlocker はパーティションだけでなくドライブ全体を暗号化するためです。Bitlocker が有効になっているというエラーが表示された場合は、Windows で起動し、**設定 -> プライバシーとセキュリティ -> デバイスの暗号化**に移動して Bitlocker をオフに切り替えてください。ドライブの暗号化解除には時間がかかる場合があります。

 ![dual-boot-7](images/dual-boot-7.webp)

## Windows の再インストール

このコンピューターに Windows がプリインストールされていた場合、そのプロダクトキーはファームウェアに保存されています。`omarchy windows key` を実行すると表示できるため、このマシンに Windows を再インストールした際に、再度ライセンス認証できます。
