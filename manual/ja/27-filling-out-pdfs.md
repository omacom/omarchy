# PDF への記入

Omarchy には Document Viewer と呼ばれる、素敵で基本的な PDF ビューアが同梱されています。これはあなたがダブルクリックした PDF を開くプログラムです。

しかし Document Viewer はフォームとして設定された PDF への記入にしか使えません。そうなっていない PDF へ記入する必要がある場合、または PDF に署名する必要がある場合は、[Signed](https://github.com/omacom/signed) を使ってください。アプリランチャー（`Super + Space`）経由で起動するか、ファイルを右クリックして _Open With..._ を選び、Signed を選択してください。

`T` を押すとテキストが入力され、`D` を押すと今日の日付が置かれます。どちらもマウスポインタのある場所に置かれます。何でもドラッグして移動させ、その角をドラッグして大きくしたり小さくしたりし、テキストをダブルクリックして変更してください。

署名するには、署名の写真が必要です。スキャンでも、白い紙の上の署名をよく照らして撮った写真でも構いません。_Signature_ メニュー（`Shift + S`）を開き、_Add signature..._ を選び、写真を選んで名前を付けてください。Signed は紙を取り除き、インクを保持します。それ以降、`S` でマウスポインタの下にあなたの署名が置かれます。

終わったら、_Save signed copy..._（`Ctrl + S`）で記入済みの PDF を元のファイルの隣に保存してください。元は決して変更されません。Signed の中で `?` を押すとすべてのショートカットが表示されます。
