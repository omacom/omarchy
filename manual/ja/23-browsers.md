# ブラウザ

Omarchy はデフォルトブラウザとして [Chromium](https://www.chromium.org/) を同梱しています。これはプレーンなオープンソースビルドで、システムの他の部分に合わせたテーマが適用されており、`Super + Shift + Return` が開くものであり、すべての [Web アプリ](25-web-apps.md) がその中で動作します。

Chromium が好みでなければ、それに縛られる必要はありません。Omarchy メニューの _インストール > Browser_ には Chrome、Edge、Brave、Brave Origin、Firefox、そして [Zen](https://zen-browser.app/) があります。1つ選べば、Omarchy がそれをインストールし、そのポリシーディレクトリをセットアップし、現在のテーマを適用します。

## デフォルトにする

ブラウザをインストールしても、それが昇格することはありません。マシン上にインストールしたら、_設定 > Defaults > Browser_ へ移動して選んでください — メニューには実際にインストールされているブラウザだけが並び、現在のデフォルトにチェックが付きます。

ターミナルからは次のようにします：

```bash
omarchy default browser firefox
```

引数なしで実行すると現在のデフォルトが表示されます。これは XDG ハンドラを設定するため、従うのは Omarchy のホットキーだけではありません — チャットアプリからターミナルコマンドまで、リンクを開くものはすべてあなたが選んだブラウザへ行きます。

## URL をコピーと動画のダウンロード

Chromium 系ブラウザ（Chromium 自体、Chrome、Edge、Brave）には、ブラウザの外へ出てシステムの残りに手を伸ばす2つの Omarchy 拡張機能が付属しています。

**Copy URL** は `Alt + Shift + L` で現在のタブのアドレスをクリップボードに置きます。アドレスバーをクリックしてコピーするより速く、ブラウザではなくシステムのクリップボードを通るため、確認の Omarchy 通知が得られ、その URL は [クリップボード履歴](08-unified-clipboard-history.md) と他のすべてのアプリですぐに利用できます。クリックが好みならツールバーボタンもあります。

**Download Video** は `Alt + Shift + D` で見ているページで再生中の動画を取得します。URL を [yt-dlp](https://github.com/yt-dlp/yt-dlp) に渡すため、YouTube をはるかに超えて動作し、ダウンロードは `~/Videos` に届きます。進捗は音量と輝度が使うのと同じオンスクリーン表示に現れ、通知を積み重ねる代わりにその場で更新されます。ファイルを別の場所に置きたい場合は `OMARCHY_YTDLP_DIR` を設定してください — 環境変数の置き場所については [FAQ](46-faq.md) を参照してください。

どちらの拡張機能も小規模なネイティブメッセージングホストを通じて Omarchy と通信し、それはブラウザと一緒にインストールされます。それこそが、Web ページの動画があなたのホームディレクトリに届き、URL がクリップボードマネージャーに届くことを可能にする部分であり、通常の拡張機能だけではできないことです。

これらは Chromium 系専用です。Firefox と Zen には付きません。

## Firefox と Zen

Firefox と Zen は異なるファミリであるため、扱いも異なります。Omarchy は妥当なデフォルトのためのポリシーファイルをインストールし、ネイティブ Wayland モードに切り替えます。これは分数スケーリングと滑らかなトラックパッドスクロールのために欲しいものです。

上記の Chromium 拡張機能は付かず、Omarchy によるテーマも適用されないため、それらの部分の体験はあなたが自分でセットアップすることになります。

## 再び削除する

ここでインストールしたものはすべて _削除 > Browser_ で取り除けます。Chromium はそのリストにありません — ベースシステムの一部です。
