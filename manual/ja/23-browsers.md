# ブラウザ

Omarchy には、デフォルトのブラウザとして [Google Chrome](https://www.google.com/chrome/) が同梱されています。システムの他の部分に合わせてテーマが適用され、`Super + Shift + Return` で開くのも、すべての[ウェブアプリ](25-web-apps.md)がその中で動作するのも、このブラウザです。起動するとすぐにブラウザウィンドウが開きます。ようこそ画面もサインインの催促もなく、使用状況の統計やクラッシュレポートが Google に送信されることもなく、広告プライバシーに関するプロンプトもオフになっています。同期したくなったら、プロフィールボタンからいつでも Google アカウントにサインインできます。

Chrome が好みでなくても、それに縛られることはありません。Omarchy メニューの _Install > Browser_ には、[Chromium](https://www.chromium.org/)（Chrome の元になった、素のオープンソースビルド）、Edge、Brave、Brave Origin、Firefox、そして [Zen](https://zen-browser.app/) があります。どれかを選べば、Omarchy がインストールし、そのポリシー用ディレクトリを用意し、現在のテーマを適用します。

## デフォルトに設定する

ブラウザをインストールしても、それがデフォルトに格上げされるわけではありません。マシンに入ったら、_Setup > Defaults > Browser_ に行って選んでください。メニューには実際にインストールされているブラウザだけが表示され、現在のデフォルトにはチェックが付きます。

ターミナルからはこうします：

```bash
omarchy default browser firefox
```

引数なしで実行すると、現在のデフォルトを教えてくれます。これは XDG ハンドラを設定するので、追随するのは Omarchy のホットキーだけではありません。チャットアプリからターミナルコマンドまで、リンクを開くものはすべて、あなたが選んだブラウザへ向かいます。

## Copy URL と Download Video

Chromium 系のブラウザ（Chromium 自体、Chrome、Edge、Brave）には、ブラウザの外へ手を伸ばしてシステムの他の部分と連携する、Omarchy の拡張機能が2つ付いてきます。

**Copy URL** は `Alt + Shift + L` で現在のタブのアドレスをクリップボードに入れます。アドレスバーをクリックしてコピーするより速く、ブラウザのものではなくシステムのクリップボードを経由するので、Omarchy の通知で確認でき、その URL はすぐに[クリップボード履歴](08-unified-clipboard-history.md)や他のすべてのアプリで使えるようになります。クリックする方が好みなら、ツールバーのボタンもあります。

**Download Video** は `Alt + Shift + D` で、見ているページで再生中の動画を取得します。URL を [yt-dlp](https://github.com/yt-dlp/yt-dlp) に渡すので、YouTube よりはるかに多くのサイトで動作し、ダウンロードは `~/Videos` に保存されます。進行状況は音量や明るさが使うのと同じオンスクリーンディスプレイに表示され、通知を積み重ねるのではなく、その場で更新されます。ファイルを別の場所に保存したい場合は `OMARCHY_YTDLP_DIR` を設定してください。環境変数をどこに置くかは [FAQ](46-faq.md) を参照してください。

どちらの拡張機能も、小さなネイティブメッセージングホストを介して Omarchy と通信します。これはブラウザと一緒に自動でインストールされます。ウェブページの動画がホームディレクトリにたどり着き、URL がクリップボードマネージャーにたどり着けるのはこの仕組みのおかげで、通常の拡張機能だけではできません。

これらは Chromium 系専用です。Firefox と Zen には付きません。

## Firefox と Zen

Firefox と Zen は別の系統なので、扱いも異なります。Omarchy は無難なデフォルトのためのポリシーファイルをインストールし、ネイティブの Wayland モードに切り替えます。分数スケーリングやスムーズなトラックパッドスクロールのためには、そうしておきたいはずです。

上記の Chromium 用拡張機能は付かず、Omarchy によるテーマ適用もないので、それらの部分は自分で設定してください。

## 再び削除する

これらのブラウザはどれも、Chrome を含め、_Remove > Browser_ から再び取り除けます。その後、リンクは、もう一方がまだインストールされていれば Chrome または Chromium へ向かいます。
