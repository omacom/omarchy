# ブラウザ

Omarchy にはデフォルトブラウザとして [Google Chrome](https://www.google.com/chrome/) が同梱されています。システム全体に合わせてテーマが適用されており、`Super + Shift + Return`（または `Super + Shift + B`）で開くのがこれで、`Super + Shift + Alt + B` ではプライベートウィンドウが開き、すべての [Web アプリ](25-web-apps.md) もこの中で動作します。起動するとそのままブラウザウィンドウが開きます。ウェルカム画面やサインインを求めるプロンプトはなく、使用統計やクラッシュレポートが Google に送信されることもなく、広告プライバシーに関するプロンプトもオフになっています。同期したくなったら、プロフィールボタンからいつでも Google アカウントにサインインできます。

Chrome が好みでなくても、それで固定されるわけではありません。Omarchy メニューの _Install > Browser_ では、[Chromium](https://www.chromium.org/)（Chrome の元になっている素のオープンソースビルド）、Edge、Brave、Brave Origin、Firefox、そして [Zen](https://zen-browser.app/) が見つかります（Edge は x86 マシンでのみ）。1つ選べば、Omarchy がそれをインストールし、ポリシーディレクトリを設定し、現在のテーマを適用します。

## デフォルトにする

ブラウザをインストールしても、デフォルトにはなりません。切り替えるには、_Setup > Defaults > Browser_ に移動して1つ選択します。現在のデフォルトにはチェックマークが付き、まだ持っていないブラウザを選んだ場合は先にインストールされます。

ターミナルからは次のとおりです：

```bash
omarchy default browser firefox
```

引数なしで実行すると、現在のデフォルトが表示されます。これにより XDG ハンドラーが設定されるため、従うのは Omarchy のホットキーだけではありません。チャットアプリからターミナルコマンドまで、リンクを開くあらゆるものが、選んだブラウザへ移動します。

## Copy URL と Download Video

Chromium 系ブラウザ（Chromium 自体、Chrome、Edge、Brave、Brave Origin）には、3つの Omarchy 拡張機能が付属しています。2つはブラウザの外へ、システムの残りの部分へと手を伸ばすもので、1つは WhatsApp をすっきりさせるものです。

**Copy URL** は、現在のタブのアドレスを `Alt + Shift + L` でクリップボードにコピーします。アドレスバーをクリックしてコピーするより高速で、ブラウザではなくシステムのクリップボードを経由するため、確認する Omarchy の通知が表示され、URL はすぐに [クリップボード履歴](08-unified-clipboard-history.md) や他のすべてのアプリで利用できるようになります。クリックしたい場合は、ツールバーボタンもあります。

**Download Video** は、表示しているページで再生中の動画を `Alt + Shift + D` で取得します。URL を [yt-dlp](https://github.com/yt-dlp/yt-dlp) に渡すため、YouTube よりはるかに多くのサイトで動作し、ダウンロードは `~/Videos` に保存されます。進行状況は、音量や明るさが使うのと同じオンスクリーンディスプレイに表示され、通知が積み重なるのではなく、その場で更新されます。ファイルを別の場所に保存したい場合は `OMARCHY_YTDLP_DIR` を設定してください。環境変数をどこに置くかについては [FAQ](46-faq.md) を参照してください。

どちらの拡張機能も、小さなネイティブメッセージングホストを介して Omarchy と通信します。これはブラウザと一緒にインストールされます。これがあるおかげで、Web ページの動画がホームディレクトリに保存されたり、URL がクリップボードマネージャーに送られたりできるのです。通常の拡張機能だけではできません。

**WhatsApp Slim** は WhatsApp Web をシステムテーマに従わせ、ウィンドウの幅が狭いときにチャットリストを折りたたみます。

これらは Chromium 系のみです。Firefox と Zen には含まれません。

## Firefox と Zen

Firefox と Zen は別の系統なので、扱いも異なります。Omarchy は適切なデフォルト設定のためのポリシーファイルをインストールし、ネイティブ Wayland モードに切り替えます。これは分数スケーリングやスムーズなトラックパッドスクロールのために必要です。

上記の Chromium 拡張機能は含まれず、Omarchy によるテーマ適用も行われないため、それらの部分は自分で設定する必要があります。

## 削除する

Chrome を含め、これらのブラウザはいずれも _Remove > Browser_ から削除できます。その後、リンクは Chrome または Chromium のうち、もう一方がまだインストールされていればそちらへ移動します。
