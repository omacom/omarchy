# システムのスリープ

Omarchy ではサスペンドがデフォルトで有効になっており、ハイバネーションは設定すれば使えるようになるが、自分のマシンでどちらかに問題がある場合は、それらをオフに切り替えることができる。

DGX Spark や ASUS Ascent GX10 のような NVIDIA GB10 搭載マシンでは、サスペンドとハイバネーションはオフになっている。これは、そのハードウェアでスリープが動作することがまだ確認されていないためで、NVIDIA の DGX OS でも同様だ。そこではサスペンドの切り替えもハイバネーションの設定も適用されない。スリープを再びオンにするには、`sudo rm` で `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf` を削除すること。そうすればサスペンドがメニューに戻り、他のマシンと同じようにハイバネーションも設定できるようになる。`sudo omarchy apply hardware --install-user "$USER"` を実行すると、そのファイルが元に戻る。

### 電源プロファイル

ノートパソコンでは、Omarchy は電源に接続しているときとバッテリーで動作しているときの電源プロファイルを別々に記憶し、接続したり外したりするのに合わせて両者を切り替える。初期状態では、それは AC 電源ではパフォーマンス、バッテリーではバランスドを意味する。

自分のマシンが何を提供しているかは `omarchy powerprofiles list` で確認でき、今いる状態に対して使いたいものは `omarchy powerprofiles set autodetect power-saver` で設定できる。何も抜き差しせずに、もう一方の状態を設定するには、直接名前を指定する：`omarchy powerprofiles set battery power-saver`。選んだものが、次にその状態になったときに再び使われるものになる。

### サスペンドの切り替え

サスペンドは、ターミナルから `omarchy toggle suspend` を実行することで切り替える。これは _システム_（または `Super + Esc`）の下にあるオプションを表示/非表示にするだけなので、自分のシステムで安定して動作するかを確認できる。動作しなければ、同じコマンドでもう一度非表示にできる。

### ハイバネーションの切り替え

ハイバネーションは、ターミナルから `omarchy hibernation setup` を実行することで設定する（Apple Silicon 搭載 Mac では利用できない）。ハイバネーションは、物理 RAM の割り当てと同じサイズの /swap サブボリュームをブートドライブに作成するので、十分な空き容量があることを確認しておくこと。32GB のマシンでは、このボリュームのために常に 32GB+ の空き容量が必要になる。ハイバネーションには、デフォルトの Limine ブートローダーも必要だ。

設定が済むと、_システム_（または `Super + Esc`）の下にハイバネートのオプションが表示され、自分のシステムで安定して動作するかを確認できる。動作しなければ、`omarchy hibernation remove` を実行してもう一度削除できる。
