# システムスリープ

Omarchy はデフォルトでサスペンドとハイバネーションを有効にしていますが、お使いのマシンでどちらかに問題がある場合は、オフに切り替えられます。

NVIDIA GB10 マシン、例えば DGX Spark や ASUS Ascent GX10 では、NVIDIA の DGX OS と同様にサスペンドとハイバネーションがオフになっています。そのハードウェアでスリープが動作することがまだ確認されていないためです。ASUS Zenbook A16 (UX3607OA) も同様で、サスペンドしてもまだチップが完全にスリープせず、一晩でハングすることがあります。そこではサスペンドの切り替えとハイバネーションのセットアップは適用されません。スリープを再びオンにするには、`sudo rm` で `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf` を削除してください。そうすれば Suspend がメニューに戻り、他のマシンと同様にハイバネーションをセットアップできます。`sudo omarchy apply hardware --install-user "$USER"` を実行すると、そのファイルが元に戻ります。

### 電源プロファイル

ノートパソコンでは、Omarchy は電源プロファイルを電源接続時とバッテリー駆動時で別々に記憶し、接続と取り外しに合わせて両者を切り替えます。初期状態では、AC 電源時は performance、バッテリー時は balanced になります。

お使いのマシンで利用できるものは `omarchy powerprofiles list` で確認でき、現在いる状態に対して使いたいものは `omarchy powerprofiles set autodetect power-saver` で設定できます。何も取り外さずにもう一方の状態を設定するには、直接名前を指定してください： `omarchy powerprofiles set battery power-saver`。選んだものが、次にその状態になったときにそのまま戻ってきます。

### サスペンドの切り替え

サスペンドは、ターミナルから `omarchy toggle suspend` を実行して切り替えます。これにより _System_（または `Super + Esc`）の下にあるオプションが表示／非表示になるだけなので、お使いのシステムで安定して動作するか確認できます。動作しない場合は、同じコマンドでもう一度非表示にできます。

### ハイバネーションの切り替え

ハイバネーションは、ターミナルから `omarchy hibernation setup` を実行してセットアップします。ハイバネーションは、物理 RAM 割り当てと同じサイズの /swap サブボリュームをブートドライブ上に作成するので、十分な空き容量があることを確認してください。32GB のマシンでは、このボリューム用に常に 32GB 以上の空き容量が必要です。ハイバネーションにはデフォルトの Limine ブートローダーも必要です。

セットアップすると、_System_（または `Super + Esc`）の下にハイバネートのオプションが表示されるので、お使いのシステムで安定して動作するか確認できます。動作しない場合は、`omarchy hibernation remove` を実行してもう一度削除できます。
