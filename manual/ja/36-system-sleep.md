# システムスリープ

Omarchyはデフォルトでサスペンドと休止状態（ハイバネーション）を有効にしていますが、マシンでどちらかに問題がある場合は、オフに切り替えることができます。

### 電源プロファイル

ノートPCでは、Omarchyは電源に接続しているときとバッテリーで動作しているときの電源プロファイルを別々に記憶し、抜き差しに応じて切り替えます。初期状態では、AC電源時はパフォーマンス、バッテリー時はバランスです。

マシンが提供するものは`omarchy powerprofiles list`で確認でき、現在の状態に対して使いたいものは`omarchy powerprofiles set autodetect power-saver`で設定できます。何も外さずにもう一方の状態を設定するには、直接名前を指定してください。`omarchy powerprofiles set battery power-saver`です。選んだものが、次にその状態になったときに得られるものになります。

### サスペンドの切り替え

サスペンドはターミナルから`omarchy toggle suspend`を実行して切り替えます。これにより_システム_（または`Super + Esc`）の下にオプションが表示／非表示になり、システムで安定して動作するかどうかを確認できます。動作しなければ、同じコマンドで再び非表示にできます。

### 休止状態の切り替え

休止状態はターミナルから`omarchy hibernation setup`を実行して設定します。休止状態では、ブートドライブに物理RAM割り当てと同サイズの/swapサブボリュームが作成されるため、十分な空き容量があることを確認してください。32GBのマシンでは、このボリューム用に常に32GB以上の空きが必要です。休止状態にはデフォルトのLimineブートローダーも必要です。

設定が終わると、_システム_（または`Super + Esc`）の下に休止状態のオプションが表示され、システムで安定して動作するかどうかを確認できます。動作しなければ、`omarchy hibernation remove`を実行して再び削除できます。
