# システムスリープ

Omarchy ではデフォルトでサスペンドとハイバネーションが有効になっていますが、お使いのマシンでどちらかに問題がある場合は、無効に切り替えることができます。

DGX Spark や ASUS Ascent GX10 などの NVIDIA GB10 マシンでは、NVIDIA の DGX OS と同様に、サスペンドとハイバネーションが無効になっています。そのハードウェアではスリープが動作することがまだ確認されていないためです。サスペンドの切り替えとハイバネーションのセットアップは、そこでは適用されません。スリープを再び有効にするには、`sudo rm` で `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf` を削除してください。そうすると Suspend がメニューに戻り、ハイバネーションも他のマシンと同様にセットアップできるようになります。`sudo omarchy apply hardware --install-user "$USER"` を実行すると、そのファイルが元に戻ります。

### 電源プロファイル

ノートパソコンでは、Omarchy は電源に接続しているときとバッテリーで動作しているときの電源プロファイルを別々に記憶し、接続と取り外しに応じて両者を切り替えます。初期状態では、AC 電源では performance、バッテリーでは balanced になります。

お使いのマシンで利用できるものは `omarchy powerprofiles list` で確認でき、現在いる状態に対して 원하는ものを `omarchy powerprofiles set autodetect power-saver` で設定できます。何も取り外さずにもう一方の状態を設定するには、直接指定してください： `omarchy powerprofiles set battery power-saver`。選択したものが、次にその状態になったときに再び適用されます。

### サスペンドの切り替え

サスペンドは、ターミナルから `omarchy toggle suspend` を実行して切り替えます。これにより _System_（または `Super + Esc`）の下にあるオプションの表示／非表示が切り替わるだけなので、お使いのシステムで一貫して動作するかどうかを確認できます。動作しない場合は、同じコマンドで再び非表示にできます。

### ハイバネーションの切り替え

ハイバネーションは、ターミナルから `omarchy hibernation setup` を実行してセットアップします。ハイバネーションは、ブートドライブ上に物理 RAM 割り当てと同じサイズの /swap サブボリュームを作成するので、十分な空き容量があることを確認してください。32GB のマシンでは、このボリュームのために常に 32GB 以上の空き容量が必要です。ハイバネーションにはデフォルトの Limine ブートローダーも必要です。

セットアップが完了すると、_System_（または `Super + Esc`）の下に hibernate オプションが表示されるので、お使いのシステムで一貫して動作するかどうかを確認できます。動作しない場合は、`omarchy hibernation remove` を実行して再び削除できます。
