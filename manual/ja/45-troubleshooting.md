# トラブルシューティング

### アップデートでシステムを壊してしまった！

まず、最近のアップデート前のバージョンに[システムをロールバック](47-system-snapshots.md)してみてください。それでダメなら、`omarchy-debug` を使って Discord の #omarchy-help で問題を共有してください。それでも全部ダメなら、`omarchy-reinstall` を使ってデフォルトの設定とパッケージを再インストールできます。

### なぜ一部のアプリがディスプレイでこんなに大きく表示されるのか？

Omarchy は 2x の高解像度ディスプレイを想定しているため、モニターパネルでスケールを選ぶまでは `GDK_SCALE` を 2 に設定します。1x ディスプレイを使っていて GTK や X11 アプリが大きすぎる場合は、モニターパネルで 1x を選ぶか、`~/.config/hypr/monitors.lua` に `hl.env("GDK_SCALE", "1")` を追加してください（その後、大きすぎるアプリは再起動してください）。[モニターに関するマニュアル](33-monitors.md) を参照してください。

Spotify では、`Ctrl + Minus` で UI を縮小できます（`Ctrl + Plus` で拡大できます）。

### なぜ Super キーのバインドが全部効かなくなったのか？

一部の ASUS ROG および TUF ノートパソコンでは、`Fn + Super` が見落としやすいキーコンビネーションになっていて、ファームウェアの Windows キーロックを切り替えます（ゲーム中に誤ってゲームから離れないようにするためのものです）。画面上には何も表示されません。ロックがオンの間、Super は一切何も発しません。だから Super を使う Omarchy のバインドは全部止まってしまい、Hyprland が壊れたように見えます。

`~/.config/hypr/` を掘り下げる前に、まず `Fn + Super` を1回押してください。それで Super が戻らなければ、ロックをかけたままにしないよう、もう1回押してください。これは Fn-lock とは違います。Fn-lock は F キー列の動作を変えるだけです。

### Wi-Fi、Bluetooth、オーディオ、トラックパッドが突然動かなくなった

再起動する前に、問題の起きているサブシステムだけを再起動してみてください。Omarchy メニューの _Update > Hardware_ には Wi-Fi、Bluetooth、Audio、Trackpad があり、そのどれかをリロードすれば、「5分前まで動いていたのに」という状況の大半は片付きます。再接続しない Bluetooth ヘッドセット、サスペンド後に死んだトラックパッド、モニターを抜いたら消えた音、といった具合です。

### なぜ外部スピーカーから音が出ないのか？

おそらくプライマリ出力に設定されていないからです。バーの右側にあるスピーカーアイコンをクリックすると音量ポップアップが開き、そこで出力デバイスを選べます（アプリごとの音量をミックスすることもできます）。

### ノートパソコンのスピーカーの音がおかしい

一部のノートパソコンでは、Omarchy が内蔵スピーカーの周波数特性を補正するスピーカーチューニングを自動的に適用します。`omarchy audio tuning status` で、自分のマシンで有効になっているかどうかが分かります。スピーカーの生の音で聞きたい場合は `omarchy audio tuning off` でオフにできます。

### なぜパスワードでログインや sudo ができないのか？

おそらく何回も間違えて入力して、ロックアウトされたのでしょう。ロック画面でこれが起きている場合は、`CTRL + ALT + F2` を押して新しい TTY を起動し、root でログインしてから `faillock --reset --user [your-username]` を実行してください。それでロックアウトがリセットされ、元通り使えるようになります。

### 1Password SSH Agent / CLI の 1Password 認証プロンプトが表示されないのはなぜ？

理由は2つ考えられます：

リッチな承認プロンプトを表示するには、Settings > Advanced > Use Hardware Acceleration をオンにする必要があります。_注：これが動作し始めるには再起動が必要です。_

 ![troubleshooting-1password](images/troubleshooting-1password.webp)

または、起動してから 1Password を一度も起動していない場合も、プロンプトは表示されません。
