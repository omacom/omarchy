# トラブルシューティング

### アップデートでシステムを壊してしまった！

まず、最近のアップデート前のバージョンに[システムをロールバック](47-system-snapshots.md)してみてください。それで解決しない場合は、`omarchy-debug` を使って Discord の #omarchy-help で問題を共有してください。それでもすべてダメなら、`omarchy-reinstall` を使ってデフォルトの設定とパッケージを再インストールできます。

### なぜ一部のアプリがディスプレイ上でこんなに大きく表示されるのですか？

Omarchy は 2x の高解像度ディスプレイを想定しており、`~/.config/hypr/monitors.lua` で `GDK_SCALE` を 2 に設定する必要があります。しかし 1x ディスプレイを使っている場合は、`local omarchy_gdk_scale = 2` を 1 に変更できます（その後、大きく表示されているアプリを再起動してください）。[モニターに関するマニュアル](33-monitors.md)を参照してください。

Spotify については、`Ctrl + Minus` で UI を縮小でき（`Ctrl + Plus` で拡大できます）。

### なぜ Super キーのバインドがすべて効かなくなったのですか？

一部の ASUS ROG および TUF ノートパソコンでは、`Fn + Super` は見落としやすい組み合わせで、ファームウェアの Windows キーロック（ゲーム中に誤ってゲームを離脱しないためのもの）を切り替えます。画面上には何も表示されません。ロックがオンの間、Super は一切何も送信しません。つまり Super を使う Omarchy のバインドがすべて停止し、Hyprland が壊れたように見えます。

`~/.config/hypr/` を掘り下げる前に `Fn + Super` を一度押してください。それで Super が戻らなければ、ロックをオンのままにしないよう、もう一度押してください。これは F キー行の動作を変えるだけの Fn ロックとは違います。

### Wi-Fi、Bluetooth、オーディオ、トラックパッドが突然動かなくなった

再起動する前に、問題のあるサブシステムだけを再起動してみてください。Omarchy メニューの _Update > Hardware_ には Wi-Fi、Bluetooth、Audio、Trackpad があり、そのうちの一つを再読み込みすれば、「5分前まで動いていた」という状況の大半は解決します。再接続しない Bluetooth ヘッドセット、サスペンド後に反応しなくなったトラックパッド、モニターを取り外したら消えたサウンドなどです。

### なぜ外部スピーカーから音が出ないのですか？

おそらくプライマリ出力として設定されていないからです。バーの右側にあるスピーカーアイコンをクリックすると、音量ポップアップが開き、出力デバイスを選べます（アプリごとの音量をミックスすることもできます）。

### ノートパソコンのスピーカーの音がおかしい

一部のノートパソコンでは、Omarchy は内蔵スピーカーの周波数特性を補正するスピーカーチューニングを自動的に適用します。`omarchy audio tuning status` で自分のマシンで有効かどうかが分かり、スピーカーの生の音を聞きたい場合は `omarchy audio tuning off` でオフにできます。

### なぜパスワードでログインや sudo ができないのですか？

おそらく何度も間違えて入力し、ロックアウトされたのでしょう。ロック画面でこれが起きている場合は、`CTRL + ALT + F2` を押して新しい TTY を起動し、root としてログインしてから `faillock --reset --user [your-username]` を実行できます。それでロックアウトがリセットされ、使えるようになります。

### なぜ 1Password SSH Agent / CLI の 1Password 認証プロンプトが表示されないのですか？

これには 2 つの理由が考えられます：

リッチな承認プロンプトを表示するには、Settings > Advanced > Use Hardware Acceleration をオンにする必要があります。_注: これが機能し始めるには再起動が必要です。_

 ![troubleshooting-1password](images/troubleshooting-1password.webp)

または、起動してから 1Password を一度も起動していない場合も、プロンプトは表示されません。
