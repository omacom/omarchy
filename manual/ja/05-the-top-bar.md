# トップバー

画面上部の帯が Omarchy バーです。これは後付けのステータスバーではなく、Omarchy シェルの一部であり、メニュー、通知、OSD ポップアップ、ロック画面も描画する、単一の長時間実行される Quickshell プロセスです。だからこそ他のすべてと完璧にテーマが合い、新しいアプリを起動するのではなく、パネルが瞬時に開くのです。

また、常に画面にある唯一のデスクトップ要素でもあるので、あの小さなグリフがすべて何をするのか知っておく価値があります。

## デフォルトで何が載っているか

バーには 3 つのセクションがあります。左には Omarchy ロゴ（メニューランチャー）とワークスペースインジケーターがあります。中央にはステータスインジケーター、時計、Elsewhen（世界時計）、天気、Omarchy の更新バッジがあります。右にはキーボードレイアウト（複数設定されている場合）、システムトレイ、エージェント、bluetooth、ネットワーク、オーディオ、ディスプレイ、電源があります。

そのいくつかは、伝えることがあるときだけ表示されます。キーボードレイアウトは、複数のレイアウトを設定した場合にのみ表示されます。更新バッジは、Omarchy の更新が待っているときだけ表示されます。そしてエージェントアイコンは、Omarchy がマシン上で AI コーディングの使用を初めて検出したときに表示されます（[AI](17-ai.md) を参照）。

## クリックして回る

ほぼすべてのウィジェットが左、右、中クリックで何かをし、いくつかはスクロールにも反応します。ここが人々が見落とす部分です。右ボタンと中ボタンに良いものの多くが隠れています。

| ウィジェット | 左 | 右 | 中 / スクロール |
| --- | --- | --- | --- |
| メニュー | Omarchy メニュー | 新しいターミナル | — |
| ワークスペース | そのワークスペースにフォーカス | — | スクロール：次/前のワークスペース |
| 時計 | カレンダーポップアップ | ラベル形式を切り替える | 中：タイムゾーンピッカー |
| 天気 | 予報ポップアップ | 完全な天気を通知として | 中：更新 |
| オーディオ | オーディオパネル | ミュート | 中：パネル · スクロール：音量 |
| マイク | マイクをミュート | — | 中：オーディオパネル · スクロール：入力音量 |
| ネットワーク | ネットワークパネル | — | — |
| Bluetooth | Bluetooth パネル | ラジオを切り替える | — |
| ディスプレイ | ディスプレイパネル | — | スクロール：明るさ |
| 電源 | 電源パネル | バッテリー残量表示を切り替える | — |
| メディア | 再生/一時停止 | カバーアートポップアップ | 中：次へ · スクロール：前/次へ |
| エージェント | エージェントパネル | エージェントを起動 | 中：次のサブスクリプション |
| トレイ | ホバーでドロワーを表示 | 管理するにはシェブロンを右クリック | — |
| Omarchy の更新 | 更新を実行 | — | — |

その表のものがすべて、最初からバーにあるわけではありません。メディアウィジェット（スクロールするトラックとアーティスト付きの MPRIS 再生中表示）とマイクウィジェットはどちらも組み込みですが、デフォルトではオフです。以下で説明するように、必要なら追加してください。

## パネル

バーアイコンをクリックするとパネルが開きます。これはツールチップではなく、スライダー、リスト、キーボードナビゲーションを備えた本物のポップアップです。それぞれにホットキーもあるので、16 ピクセルのグリフを狙う必要は決してありません：

| ホットキー | パネル |
| --- | --- |
| `Super + Ctrl + A` | オーディオ |
| `Super + Ctrl + W` | ネットワーク |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | ディスプレイ |
| `Super + Ctrl + P` | 電源 |
| `Super + Ctrl + Alt + D` | カレンダー |
| `Super + Ctrl + Alt + E` | 世界時計 |
| `Super + Ctrl + 1-9` | 右セクションの n 番目のパネルを切り替える |

パネルは表示専用ではありません。実際に操作を行う場所です：

- **オーディオ** にはマスターボリュームスライダー、出力デバイスピッカー、アプリごとのミキサーがあり、他のすべてに触れずにあのブラウザタブ 1 つの音量を下げられます。
- **ネットワーク** は Wi-Fi をスキャンし、信号強度を表示し、接続し、DNS プロバイダーを選べます。
- **Bluetooth** は接続/切断とバッテリーレベル付きでデバイスを一覧表示します。
- **電源** はバッテリー統計を表示し、電力プロファイルを切り替え（バッテリー用と AC 用で別々の選択を覚えます）、システム情報をいくつか表示します。
- **ディスプレイ** には明るさスライダー、テキストサイズ、モニタースケーリングのプリセットがあり、画面が複数ある場合はモニターごとのコントロールがあります。詳しくは [モニター](33-monitors.md) を参照してください。
- **時計** は ISO 週番号と月のステップ移動付きの月グリッドを開きます。

すべてのパネルはマウスだけでなくキーボードでも操作できます：矢印で移動、Return で有効化、Tab で隣のパネルへステップ、Escape で閉じます。

`Super + Ctrl + 1-9` は右セクションのパネルを左から右へ数え、独自のパネルがないトレイはスキップします。だから番号は指したいアイコンと一致します。

### Tailscale と Dropbox

もう 2 つのウィジェットは、**インストール → サービス** から対応するサービスをインストールしたときだけバーに表示され、どちらもステータスを報告する以上のことをするので知っておく価値があります。

**Tailscale** パネルは tailnet への接続と切断、アカウントの切り替え、exit node の選択を行います（自分のマシンと Mullvad リージョンの両方がそのリストに表示されます）。マシンも閲覧できます。1 つを選択した状態で `s` を押すと Taildrop でファイルを送信します。これは携帯電話や別のノートパソコンへファイルを移動する最速の方法です。`c` はマシンの IP、`n` は名前、`d` は完全な DNS 名をコピーします。各マシンの行にも送信ボタンがあるので、クリックしたい場合はそちらも使えます。ターミナルからは同じことを `omarchy tailscale send <machine> [file...]` で行います。

**Dropbox** パネルはログインを処理し、使用したストレージ量を表示し、最近同期されたファイルを一覧表示します。

どちらかのサービスを削除すると、そのウィジェットもバーから外れます。

## インジケーター

中央の小さな集まりがインジケーターウィジェットです。これらはオンにしたモードのステータスグリフです：おやすみモード、ナイトライト、キューに入った [リマインダー](09-reminders.md)、アクティブな画面録画、スリープ抑制、[ディクテーション](11-text-extraction-dictation.md) です。モードがアクティブなときに点灯し、それ以外は目立たないようにしています。時計の左側（縦バーの場合は上）にホバーすると、非アクティブなものが見えます。インジケーターをクリックするとそのモードが切り替わります。もう 1 つはステータス専用です：リモートセッションは、gliff 経由で誰かがこのマシンに接続している間、赤く点灯します。

常に表示しておきたい場合は、ウィジェットの `alwaysShow` を `true` に設定してください。そして一部だけ必要な場合は、欲しいものを `items` に列挙してください：`["Dnd", "Reminder", "NightLight"]`。インジケーターウィジェットを複数持てるので、セクションごとに異なるサブセットを表示できます。

## バーの並べ替え

バーは自分で設定できます。ものを移動するために設定ファイルを開く必要はありません。

中央付近のバーの空白部分をつかんで別の画面端へドラッグすると、バーがそこへ移動します。左、右、上、下のすべてが機能し、すべてのウィジェットが適応します（縦バーはコンパクトなアイコンのみの形式にフォールバックします）。クリックして長押ししても同じドラッグが始まります。その同じ空白部分を左ダブルクリックすると、バーの背景が透明からガラス質、不透明へと切り替わります。そして任意のウィジェットをドラッグして並べ替えたり、別のセクションへ投げ入れたりできます。

手近に置いておきたいけれど常に見えている必要はないウィジェットは、トレイのドロワーに入れられます。トレイの上へドラッグすると、受け入れるためにドロワーが開きます。そこではアプリアイコンの後ろに収まり、ドロワーが開くたびに現れ、パネルが開いている間はドロワーも開いたままになります。バーの上へドラッグし戻すと、元の場所に戻ります。

メニューから選びたい場合は、**実行 → 外観 → メニューバー** に位置があり、**バーの背景** でバーの描画方法を選びます：**不透明バー**、**ガラス質バー**（透けて見え、後ろのものがぼかされます）、**透明バー** です。

同じことにはコマンドもあり、それが [dotfiles](31-dotfiles.md) セットアップで欲しいものです：

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.clock --section center --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

ウィジェットを完全に追加または削除するには、プラグインコマンドを使います。`omarchy plugin list` はシェルが知っているすべてのウィジェットをその ID とともに表示します。その後：

```bash
omarchy plugin enable omarchy.media --section center
omarchy plugin disable omarchy.weather
```

## バーを隠す

`Super + Shift + Space` はシェルを終了させずにバーをオフ/オンに切り替えます。パネルとホットキーは機能し続け、ピクセルを取り戻すだけです。メニューの **実行 → 外観 → メニューバー → バーを隠す** の下にもあります。

## 設定ファイル

すべては `~/.config/omarchy/shell.json` の `bar` キーの下に保存されます。トリミングした版がこちらです：

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "centerAnchor": "omarchy.clock",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

すべてのウィジェットは 3 つのレイアウト配列のいずれかの 1 エントリであり、その設定はそのエントリにインラインであります。別の設定ファイルも、`config` サブオブジェクトもありません。時計の `format`、`formatAlt`（右クリックで切り替わる先）、`verticalFormat` はすべて `{ "id": "omarchy.clock" }` の上にあります。

`centerAnchor` は、画面のちょうど中央に固定され、他がその両側に配置される 1 つの中央ウィジェットを指定します。そうやって、天気や更新バッジが出たり消えたりしても時計が真ん中に留まります。空文字列に設定すると、中央リストはグループとして中央揃えになるだけです。

内面化しておく価値のあるルールが 1 つ：**自分の `shell.json` を持ったら、それが正準です**。何もカスタマイズしていない間は、シェルは Omarchy のデフォルトファイルを読みます。ウィジェットをドラッグしたり、`omarchy bar` を実行したり、自分でファイルを編集したりした瞬間、それはあなたのものになります。深いマージはないので、将来の Omarchy リリースの新しいデフォルトウィジェットは自動的にはバーに表示されません。`omarchy bar defaults` で、きれいな状態が欲しいときにいつでも出荷時のレイアウトに戻せます。

同じファイルには、`bar` キーの外側、トップレベルにアイドルタイミングも保持されています：`idle.screensaver` と `idle.lock` で、どちらもアイドルになってからの秒数です。だからデフォルトのスクリーンセーバーは 150 秒で、ロックは 300 秒で作動します。
