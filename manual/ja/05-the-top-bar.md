# トップバー

画面上端に沿った帯が Omarchy バーだ。これは後付けのステータスバーではなく、Omarchy シェルの一部であり、メニュー、通知、OSD ポップアップ、ロック画面も描画する、単一の常駐 Quickshell プロセスだ。だからこそ、他のすべてと完璧にテーマが揃い、パネルも新しいアプリを起動するのではなく瞬時に開く。

同時に、これはデスクトップで常に画面に表示されている唯一の要素でもある。だから、あの小さなグリフがそれぞれ何をするのか知っておく価値がある。

## デフォルトで表示されるもの

バーは3つのセクションで構成される。左側には Omarchy ロゴ（メニューランチャー）とワークスペースインジケーターがある。中央にはステータスインジケーター、時計、Elsewhen（世界時計）、天気、Omarchy アップデートバッジがある。右側には、システムトレイ、キーボードレイアウト（複数設定されている場合のみ）、エージェント、bluetooth、ネットワーク、オーディオ、ディスプレイ、電源がある。

このうちいくつかは、伝えることがあるときだけ表示される。キーボードレイアウトは、レイアウトを複数設定している場合にのみ表示される。アップデートバッジは、Omarchy のアップデートが待っている場合にのみ表示される。そしてエージェントアイコンは、Omarchy がこのマシンで AI コーディングの使用を初めて検出したときに表示される（[AI](17-ai.md) を参照）。

## クリック操作

ほぼすべてのウィジェットは左クリック、右クリック、中央クリックで何らかの動作をし、いくつかはスクロールにも反応する。ここが多くの人が見落とす部分だ。良い機能の多くは右ボタンと中央ボタンに隠れている。

| ウィジェット | 左クリック | 右クリック | 中央クリック / スクロール |
| --- | --- | --- | --- |
| メニュー | Omarchy メニュー | 新しいターミナル | — |
| ワークスペース | このモニターでそのワークスペースにフォーカス | — | スクロール: 次/前のワークスペース |
| 時計 | カレンダーポップアップ | ラベル形式を切り替え | 中央: タイムゾーンピッカー |
| 天気 | 予報ポップアップ | 完全な天気を通知で表示 | 中央: 更新 |
| オーディオ | オーディオパネル | ミュート | 中央: パネル · スクロール: 音量 |
| マイク | マイクをミュート | — | 中央: オーディオパネル · スクロール: 入力音量 |
| ネットワーク | ネットワークパネル | — | — |
| Bluetooth | Bluetooth パネル | 無線のオン/オフを切り替え | — |
| ディスプレイ | ディスプレイパネル | — | スクロール: 明るさ |
| 電源 | 電源パネル | バッテリー残量表示のオン/オフを切り替え | — |
| メディア | 再生/一時停止 | カバーアートポップアップ | 中央: 次へ · スクロール: 前/次 |
| エージェント | エージェントパネル | エージェントを起動 | 中央: 次のサブスクリプション |
| トレイ | ホバーでドロワーを表示 | シェブロンを右クリックして管理 | — |
| Omarchy アップデート | アップデートを実行 | — | — |

あの表にあるすべてが最初からバーにあるわけではない。メディアウィジェット（スクロールする曲名とアーティストを表示する MPRIS の再生中表示）とマイクウィジェットはどちらも組み込みだが、デフォルトではオフになっている。欲しければ、後述の方法で追加できる。

## パネル

バーアイコンをクリックするとパネルが開く。これはツールチップではなく、スライダー、リスト、キーボードナビゲーションを備えた正規のポップアップだ。各パネルにはホットキーもあるので、16ピクセルのグリフを狙う必要は決してない。

| ホットキー | パネル |
| --- | --- |
| `Super + Ctrl + A` | オーディオ |
| `Super + Ctrl + N` | ネットワーク |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | ディスプレイ |
| `Super + Ctrl + P` | 電源 |
| `Super + Ctrl + Alt + D` | カレンダー |
| `Super + Ctrl + Alt + E` | 世界時計 |
| `Super + Ctrl + 1-9` | 右セクションの n 番目のパネルを切り替え |

パネルは単なる表示ではない。実際に操作を行う場所だ。

- **Audio** にはマスター音量スライダー、出力デバイスピッカー、アプリごとのミキサーがあるので、他のすべてには触れずに、そのブラウザタブだけ音量を下げられる。
- **Network** は Wi-Fi をスキャンし、信号強度を表示し、接続し、DNS プロバイダーを選べる。
- **Bluetooth** はデバイスを一覧表示し、接続/切断とバッテリー残量を表示する。
- **Power** はバッテリー統計を表示し、電源プロファイルを切り替え（バッテリー用と AC 用で別々の選択を記憶する）、システム情報も表示する。
- **Display** には明るさスライダー、テキストサイズ、モニターのスケーリングプリセットがあり、画面が複数ある場合はモニターごとのコントロールもある。詳しくは [モニター](33-monitors.md) を参照。
- **Clock** は ISO 週番号付きの月グリッドを開き、月を前後に移動できる。
- **World clock** は都市ごとに1行を保持し、その天気とその日の進み具合を表示する。検索ではタイムゾーンだけでなく町も見つかるので、Fort Lauderdale は New York ではなく Fort Lauderdale として表示される。一番上の行に間違った都市名が表示されている場合は、それをクリックして自分の居場所を知らせる。別のタイムゾーンの場所を選ぶとシステムクロックもそこへ移動するので、旅行のときに便利だ。都市にホバーして人物ボタンをクリックすると、誰がそこに住んでいるかを伝えられる。普通の名前でも、`@` GitHub ハンドルで顔写真も一緒に表示できる。

すべてのパネルはマウスだけでなくキーボードでも操作できる。矢印キーで移動、Return で実行、Tab で隣のパネルへ移動、Escape で閉じる。

`Super + Ctrl + 1-9` は右セクションのパネルを左から右へ数える。トレイは独自のパネルを持たないのでスキップする。だから、その番号は指さすアイコンと一致する。

### Tailscale と Dropbox

**Install → Service** から対応するサービスをインストールして初めてバーに表示されるウィジェットがあと2つあり、どちらもステータスを報告する以上のことをするので知っておく価値がある。

**Tailscale** パネルは tailnet への接続と切断、アカウントの切り替え、exit node の選択を行う（自分のマシンと Mullvad の地域の両方がそのリストに表示される）。マシンを閲覧することもでき、1台を選択した状態で `s` を押すと Taildrop でファイルを送信する。これはスマートフォンや別のラップトップへファイルを移動する最速の方法だ。`c` はそのマシンの IP を、`n` はその名前を、`d` はその完全な DNS 名をコピーする。各マシンの行には送信ボタンもあるので、クリックしたい場合はそちらでもよい。ターミナルから同じことを行うのは `omarchy tailscale send <machine> [file...]` だ。

**Dropbox** パネルはログインを処理し、使用済みストレージ量を表示し、最近同期したファイルを一覧表示する。

どちらかのサービスを削除すると、そのウィジェットもバーから消える。

## インジケーター

中央の小さなクラスターがインジケーターウィジェットだ。これらはオンにしたモードのステータスグリフである。おやすみモード、夜間ライト、キューに入った [リマインダー](09-reminders.md)、アクティブな画面録画、スリープ防止、[ディクテーション](11-text-extraction-dictation.md) だ。モードがアクティブなときは点灯し、それ以外は邪魔にならない。非アクティブなものが置かれるはずの場所のすぐ横にホバーすると、それらを覗き見ることができる。インジケーターをクリックすると、そのモードが切り替わる。もう1つはステータスのみだ。誰かが gliff を通じてこのマシンに接続している間、リモートセッションは赤く点灯する。

常に表示しておきたい場合は、ウィジェットで `alwaysShow` を `true` に設定する。一部だけが気になる場合は、欲しいものを `items` に列挙する: `["Dnd", "Reminder", "NightLight"]`。インジケーターウィジェットは複数持てるので、セクションごとに異なるサブセットを表示できる。

## バーの並び替え

バーは自分で設定する。ものを移動するのに設定ファイルを開く必要はない。

中央付近のバーの空いた部分を掴んで別の画面端へドラッグすると、バーはそこへ移動する。左、右、上、下すべて機能し、すべてのウィジェットが適応する（縦型バーはコンパクトなアイコンのみ形式に戻る）。クリックして保持しても同じドラッグが始まる。同じ空いたスペースを左ダブルクリックすると、バーの背景がクリアからガラス質、不透明へと切り替わる。そして、任意のウィジェットをドラッグすれば並び替えたり、別のセクションへ投げ入れたりできる。他のウィジェットは、着地点に余地を作るために左右に滑って開く。

バーの中央はボックスだ。その中にあるものは1つのグループとして中央に置かれたままになり、その両側にあるウィジェットはその端からぶら下がる。ウィジェットをドラッグしている間、ボックスはアウトラインとして表示され、空のときはバーを横切る線として表示され、その中にも、その横にもドロップできる。ドロップがボックス内に着地する場合、ボックスはウィジェットを取り込むために広がる。

常に表示しておきたいわけではないが手元に置いておきたいウィジェットは、トレイのドロワーに入れられる。トレイへドラッグすると、ドロワーが開いてそれを取り込む。それはアプリアイコンの後にそこに置かれ、ドロワーが表示されるたびに表示され、そのパネルが開いている間はドロワーを開いたままにする。バーへドラッグして戻せば、元の場所に戻る。

メニューから選びたい場合は、**Appearance → Menu Bar** に位置があり、**Bar Background** でバーの描画方法を選ぶ: **Opaque Bar**、**Glassy Bar**（透けて見え、背後がぼかされる）、または **Clear Bar** だ。

同じことはコマンドでも行える。[dotfiles](31-dotfiles.md) セットアップではこちらが欲しくなる。

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

ウィジェットを丸ごと追加または削除するには、プラグインコマンドを使う。`omarchy plugin list` はシェルが知っているすべてのウィジェットをその id 付きで表示する。そして:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## バーを隠す

`Super + Shift + Space` でシェルを終了させずにバーをオフとオンに切り替える。パネルとホットキーは引き続き動作し、ピクセルを取り戻せるだけだ。メニューの **Appearance → Menu Bar → Hide Bar** からも行える。

## 設定ファイル

すべては `~/.config/omarchy/shell.json` の `bar` キーの下に保存される。切り詰めたバージョンがこちらだ。

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

すべてのウィジェットは5つのレイアウト配列のうち1つの中の1エントリであり、その設定はそのエントリにインラインで置かれる。別の設定ファイルも、`config` サブオブジェクトもない。時計の `format`、`formatAlt`（右クリックで切り替わる先）、`verticalFormat` はすべて `{ "id": "omarchy.clock" }` のまさにそこに存在する。

`center` はバーの中央にあるボックスだ。その中のすべては1つのグループとして画面の中央に配置される。`centerBegin` と `centerEnd` はボックスの両側からぶら下がり、これによって天気やアップデートバッジが出入りしても時計はど真ん中に居続ける。`center` にウィジェットを複数入れると一緒に中央に配置され、空にしておくと `centerBegin` と `centerEnd` はバーの中央で出会う。

身に付けておく価値のあるルールが1つある: **独自の `shell.json` を持った時点で、それが正となる**。何もカスタマイズしていない間は、シェルは Omarchy のデフォルトファイルを読む。ウィジェットをドラッグしたり、`omarchy bar` を実行したり、自分でファイルを編集したりした瞬間、それは自分のものになる。深いマージはないので、将来の Omarchy リリースの新しいデフォルトウィジェットはバーに自動的には表示されない。`omarchy bar defaults` を実行すれば、いつでも出荷時のレイアウトに戻して白紙の状態にできる。

同じファイルには、`bar` キーの外のトップレベルに、アイドル時のタイミングも保持される: `idle.screensaver` と `idle.lock` で、どちらもアイドル状態になってからの秒数だ。だからデフォルトではスクリーンセーバーは150秒で始まり、ロックは300秒でかかる。
