# トップバー

画面の上部に沿った帯がOmarchyバーだ。これは後付けのステータスバーではなく、Omarchyシェルの一部であり、メニュー、通知、OSDポップアップ、ロック画面も描画する、単一の常駐Quickshellプロセスだ。だからこそ他のすべてと完璧にテーマが揃い、パネルも新しいアプリを起動するのではなく瞬時に開く。

また、デスクトップ上で常に画面に表示されている唯一の要素でもある。だから、あの小さなグリフがそれぞれ何をするのか知っておく価値がある。

## デフォルトで表示されるもの

バーには3つのセクションがある。左側にはOmarchyロゴ（メニューランチャー）とワークスペースインジケーターがある。中央にはステータスインジケーター、時計、Elsewhen（世界時計）、天気、そしてOmarchyアップデートバッジがある。右側には、システムトレイ、キーボードレイアウト（複数が設定されている場合）、agents、bluetooth、ネットワーク、オーディオ、ディスプレイ、電源がある。

そのうちいくつかは、伝えることがあるときにだけ表示される。キーボードレイアウトは、複数のレイアウトを設定している場合にのみ表示される。アップデートバッジは、Omarchyのアップデートが待機しているときにのみ表示される。そしてagentsアイコンは、Omarchyがマシン上でAIコーディングの使用を初めて検出したときに表示される（[AI](17-ai.md)を参照）。

## クリックしてみる

ほぼすべてのウィジェットは、左、右、中クリックで何かをし、いくつかはスクロールにも反応する。ここが人々が見落とす部分だ — 右ボタンと中ボタンにこそ、良いものの多くが隠れている。

| ウィジェット | 左 | 右 | 中 / スクロール |
| --- | --- | --- | --- |
| メニュー | Omarchyメニュー | 新しいターミナル | — |
| ワークスペース | このモニターでそのワークスペースにフォーカス | — | スクロール：次/前のワークスペース |
| 時計 | カレンダーポップアップ | ラベル形式を切り替え | 中：タイムゾーンピッカー |
| 天気 | 予報ポップアップ | 通知として完全な天気を表示 | 中：更新 |
| オーディオ | オーディオパネル | ミュート | 中：パネル · スクロール：音量 |
| マイク | マイクをミュート | — | 中：オーディオパネル · スクロール：入力音量 |
| ネットワーク | ネットワークパネル | — | — |
| Bluetooth | Bluetoothパネル | 無線のオン/オフ | — |
| ディスプレイ | ディスプレイパネル | — | スクロール：明るさ |
| 電源 | 電源パネル | バッテリー残量パーセンテージのオン/オフ | — |
| メディア | 再生/一時停止 | カバーアートのポップアップ | 中：次へ · スクロール：前/次 |

| Omarchyアップデート | アップデートを実行 | — | — |

その表にあるすべてが、最初からバーにあるわけではない。メディアウィジェット（MPRISの再生中表示で、トラックとアーティストがスクロールする）とマイクウィジェットはどちらも組み込みだが、デフォルトではオフになっている — 欲しければ、以下で説明するように追加できる。

## パネル

バーのアイコンをクリックするとパネルが開く。これはツールチップではなく、スライダー、リスト、キーボードナビゲーションを備えた正式なポップアップだ。それぞれにホットキーもあるので、16ピクセルのグリフを狙う必要は決してない：

| ホットキー | パネル |
| --- | --- |
| `Super + Ctrl + A` | オーディオ |
| `Super + Ctrl + N` | ネットワーク |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | ディスプレイ |
| `Super + Ctrl + P` | 電源 |
| `Super + Ctrl + Alt + D` | カレンダー |
| `Super + Ctrl + Alt + E` | 世界時計 |
| `Super + Ctrl + 1-9` | 右セクションのn番目のパネルを切り替え |

パネルは読み取り専用の表示ではない。実際に物事を行う場所だ：

- **Audio**にはマスター音量スライダー、出力デバイスピッカー、アプリごとのミキサーがあり、他のすべてに触れることなく、その1つのブラウザタブだけ音量を下げられる。
- **Network**はWi-Fiをスキャンし、信号強度を表示し、接続し、DNSプロバイダーを選ばせる。
- **Bluetooth**はデバイスを接続/切断とバッテリーレベル付きで一覧表示する。
- **Power**はバッテリー統計を表示し、電源プロファイルを切り替え（バッテリー用とAC用で別々の選択を記憶する）、システム情報もいくつか表示する。
- **Display**には明るさスライダー、テキストサイズ、モニタースケーリングのプリセットがあり、画面が複数ある場合はモニターごとのコントロールもある。より深い話は[モニター](33-monitors.md)を参照。
- **Clock**はISO週番号と月移動を備えた月グリッドを開く。
- **World clock**は都市ごとに1行を保持し、その天気とその日の進み具合を表示する。検索ではタイムゾーンだけでなく町も見つかるので、Fort LauderdaleはNew YorkではなくFort Lauderdaleになる。上部の行が間違った都市を名指している場合は、それをクリックして自分の居場所を伝える；別のタイムゾーンの場所を選ぶとシステムクロックもそこへ移動する。これは旅行時に便利だ。都市にホバーして人物ボタンをクリックすると、そこに誰が住んでいるかを伝えられる — プレーンな名前でも、`@` GitHubハンドルでもよく、後者なら顔も一緒に連れてくる。

すべてのパネルはマウスだけでなくキーボードも受け付ける：矢印で移動し、Returnで有効化し、Tabで隣のパネルへ移動し、Escapeで閉じる。

`Super + Ctrl + 1-9`は右セクションのパネルを左から右へ数え、独自のパネルを持たないトレイはスキップする。だから数字は、指し示すアイコンと一致する。

### TailscaleとDropbox

さらに2つのウィジェットは、**Install → Service**から対応するサービスをインストールしたときにだけバーに表示され、どちらもステータスを報告する以上のことをするので知っておく価値がある。

**Tailscale**パネルはtailnetへの接続と切断、アカウント間の切り替え、出口ノードの選択を行う（自分のマシンとMullvadリージョンの両方がそのリストに表示される）。マシンの閲覧もでき、1つを選択した状態で`s`を押すとTaildrop経由でファイルを送信する。これはファイルを携帯電話や別のラップトップへ移動する最速の方法だ。`c`はマシンのIPを、`n`はその名前を、`d`はその完全なDNS名をコピーする。各マシンの行には送信ボタンもあるので、クリックしたい場合はそちらでもよい。ターミナルから同じことを行うのは`omarchy tailscale send <machine> [file...]`だ。

**Dropbox**パネルはログインを処理し、使用したストレージ容量を表示し、最近同期されたファイルを一覧表示する。

どちらかのサービスを削除すると、そのウィジェットもバーから消える。

## インジケーター

中央にある小さな集まりがインジケーターウィジェットだ。これらは、オンにしたモードのためのステータスグリフだ：おやすみモード、夜間ライト、キューに入った[リマインダー](09-reminders.md)、アクティブな画面録画、スリープ抑制、そして[音声入力](11-text-extraction-dictation.md)。モードがアクティブなときに点灯し、それ以外は邪魔にならない場所にいる — バーのどこかにホバーすると、非アクティブなものを覗き見できる。インジケーターをクリックするとそのモードが切り替わる。もう1つはステータス専用だ：誰かがgliff経由でこのマシンに接続している間、リモートセッションが赤く点灯する。

常に表示しておきたい場合は、ウィジェットで`alwaysShow`を`true`に設定する。そして一部のものだけを気にする場合は、欲しいものを`items`に列挙する：`["Dnd", "Reminder", "NightLight"]`。インジケーターウィジェットは複数持てるので、異なるセクションで異なるサブセットを表示できる。

## バーを並べ替える

バーは自分で設定する。物事を移動するために設定ファイルを開く必要はない。

中央付近のバーの空いている部分をつかんで別の画面端へドラッグすると、バーがそこへ移動する — 左、右、上、下のすべてが機能し、すべてのウィジェットが適応する（縦型バーはコンパクトなアイコンのみの形式にフォールバックする）。クリックして保持することでも同じドラッグが始まる。同じ空きスペースを左ダブルクリックすると、バーの背景がクリアからガラス質、不透明へと切り替わる。そして任意のウィジェットをドラッグして並べ替えたり、別のセクションへ投げ入れたりできる；他のウィジェットは、着地する場所にスペースを作るためにスライドして開く。

バーの中央はボックスだ：その中にあるものは1つのグループとして中央に置かれたままになり、その両側のウィジェットはその端からぶら下がる。ウィジェットをドラッグしている間、ボックスはアウトラインとして表示され、空の場合はバー全体に引かれた線として表示され、その中にも、その横にもドロップできる。ドロップがボックス内に着地する場合、ボックスはウィジェットを取り込むために広がる。

手元に置いておきたいが常に見せたくないウィジェットは、トレイのドロワーに入れられる：トレイ上にドラッグすると、ドロワーが開いてそれを受け入れる。それはアプリアイコンの後にそこに座り、ドロワーが表示されるたびに現れ、自分のパネルが開いている間はドロワーを開いたままにする。バー上にドラッグして戻せば元に戻る。

メニューから選びたい場合は、**Appearance → Menu Bar**に位置があり、**Bar Background**でバーの描画方法を選ぶ：**Opaque Bar**、**Glassy Bar**（透けて見え、背後にあるものがぼかされる）、または**Clear Bar**。

同じことにはコマンドもある。これは[dotfiles](31-dotfiles.md)セットアップで欲しくなるものだ：

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

ウィジェットを entirely 追加または削除するには、プラグインコマンドを使う。`omarchy plugin list`はシェルが知っているすべてのウィジェットをそのid付きで表示し、その後：

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## バーを隠す

`Super + Shift + Space`はシェルを終了させることなくバーをオフにしたり戻したりする — パネルとホットキーは引き続き機能し、ピクセルを取り戻せるだけだ。メニューの**Appearance → Menu Bar → Hide Bar**にもある。

## 設定ファイル

すべては`~/.config/omarchy/shell.json`に、`bar`キーの下に保存される。以下は切り詰めたバージョンだ：

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

すべてのウィジェットは5つのレイアウト配列のいずれかの中の1つのエントリであり、その設定はそのエントリにインラインで置かれる — 別個の設定ファイルはなく、`config`サブオブジェクトもない。時計の`format`、`formatAlt`（右クリックで切り替わる先）、そして`verticalFormat`はすべて`{ "id": "omarchy.clock" }`の上にそのまま存在する。

`center`はバーの中央にあるボックスだ：その中にあるすべては、1つのグループとして画面の中央に配置される。`centerBegin`と`centerEnd`はボックスの両側からぶら下がり、これにより天気やアップデートバッジが出入りしても時計はど真ん中に留まる。`center`に複数のウィジェットを入れれば一緒に中央に配置される；空にしておけば`centerBegin`と`centerEnd`はバーの中央で出会う。

内面化する価値のあるルールが1つある：**自分自身の`shell.json`を持った瞬間、それが正となる**。何もカスタマイズしていない間は、シェルはOmarchyのデフォルトファイルを読み込む。ウィジェットをドラッグしたり、`omarchy bar`を実行したり、自分でファイルを編集したりした瞬間、それはあなたのものになる — 深いマージはないので、将来のOmarchyリリースで追加される新しいデフォルトウィジェットは自動的にはバーに表示されない。`omarchy bar defaults`はいつでも出荷時のレイアウトに戻し、きれいな状態にできる。

同じファイルは、`bar`キーの外側のトップレベルに、アイドル時のタイミングも保持する：`idle.screensaver`と`idle.lock`で、どちらもアイドルになってからの秒数だ。だからデフォルトのスクリーンセーバーは150秒で開始し、ロックは300秒で開始する。
