# トップバー

画面の上端に沿った帯がOmarchyバーだ。これは後付けのステータスバーではなく、Omarchyシェルの一部であり、メニュー、通知、OSDポップアップ、ロック画面も描画する、単一の長時間動作するQuickshellプロセスだ。だからこそ他のすべてと完璧にテーマが揃い、パネルも新しいアプリを起動するのではなく瞬時に開く。

また、デスクトップで常に画面に表示されている唯一の要素でもあるので、あの小さなグリフがそれぞれ何をするのか知っておく価値がある。

## デフォルトで表示されているもの

バーには3つのセクションがある。左側にはOmarchyロゴ（メニューランチャー）とワークスペースインジケーターがある。中央にはステータスインジケーター、時計、Elsewhen（ワールドクロック）、天気、Omarchyアップデートバッジがある。右側にはシステムトレイ、キーボードレイアウト（複数のレイアウトまたは入力方式が設定されている場合）、Agents、Bluetooth、ネットワーク、オーディオ、ディスプレイ、電源がある。

そのうちのいくつかは、伝えることがあるときにだけ表示される。キーボードレイアウトは、複数のレイアウトまたは入力方式を設定した場合にのみ表示される。アップデートバッジは、Omarchyのアップデートが待機しているときにのみ表示される。

## クリック操作

ほぼすべてのウィジェットは左クリック、右クリック、中クリックで何かをし、いくつかはスクロールにも反応する。ここがみんな見逃す部分だ ― 右ボタンと中ボタンにこそ、いいものの多くが隠れている。

| ウィジェット | 左 | 右 | 中 / スクロール |
| --- | --- | --- | --- |
| メニュー | Omarchyメニュー | 新しいターミナル | — |
| ワークスペース | このモニターでそのワークスペースにフォーカス | — | スクロール: 次/前のワークスペース |
| 時計 | カレンダーポップアップ | ラベル形式を切り替え | 中: タイムゾーンピッカー |
| ワールドクロック | ワールドクロックパネル | 更新 | 中: 更新 |
| 天気 | 予報ポップアップ | 通知として天気の詳細 | 中: 更新 |
| オーディオ | オーディオパネル | ミュート | 中: パネル · スクロール: 音量 |
| マイク | マイクをミュート | — | 中: オーディオパネル · スクロール: 入力音量 |
| ネットワーク | ネットワークパネル | — | — |
| Bluetooth | Bluetoothパネル | 無線のオン/オフ | — |
| ディスプレイ | ディスプレイパネル | — | スクロール: 明るさ |
| 電源 | 電源パネル | バッテリー残量表示のオン/オフ | — |
| メディア | 再生/一時停止 | カバーアートのポップアップ | 中: 次 · スクロール: 前/次 |
| Agents | Agentsパネル | エージェントを起動 | 中: 使用量を更新 |
| トレイ | ホバーでドロワーを表示 | シェブロンを右クリックして管理 | — |
| Omarchyアップデート | アップデートを実行 | — | — |

上の表にあるものすべてが、最初からバーにあるわけではない。メディアウィジェット（スクロールするトラックとアーティスト付きのMPRIS再生中）とマイクウィジェットはどちらも組み込みだがデフォルトではオフだ ― 欲しければ、以下で説明するように追加すればいい。

## パネル

バーアイコンをクリックするとパネルが開く。これはツールチップではなく、スライダー、リスト、キーボードナビゲーションを備えたまっとうなポップアップだ。どれにもホットキーもあるので、16ピクセルのグリフを狙う必要は決してない:

| ホットキー | パネル |
| --- | --- |
| `Super + Ctrl + A` | オーディオ |
| `Super + Ctrl + N` | ネットワーク |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | ディスプレイ |
| `Super + Ctrl + P` | 電源 |
| `Super + Ctrl + Alt + D` | カレンダー |
| `Super + Ctrl + Alt + E` | ワールドクロック |
| `Super + Ctrl + X` | Agents |
| `Super + Ctrl + 1-9` | 右セクションのn番目のパネルを切り替え |

パネルはただの表示ではない。実際に何かをする場所だ:

- **オーディオ**にはマスター音量スライダー、出力デバイスピッカー、アプリごとのミキサーがあるので、他のすべてに触れずにあの1つのブラウザタブだけ音量を下げられる。
- **ネットワーク**はWi-Fiをスキャンし、信号強度を表示し、接続し、DNSプロバイダーを選ばせる。
- **Bluetooth**はデバイスを接続/切断とバッテリー残量とともに一覧表示する。
- **電源**はバッテリー統計を表示し、電源プロファイルを切り替え（バッテリー用とAC用に別々の選択を記憶する）、システム情報をいくつか表示する。
- **ディスプレイ**には明るさスライダー、テキストサイズ、モニターのスケーリングプリセットがあり、画面が複数ある場合はモニターごとのコントロールもある。詳しくは[モニター](33-monitors.md)を参照。
- **時計**はISO週番号と月移動を備えた月グリッドを開く。
- **ワールドクロック**は都市ごとに1行を保持し、その天気とその日の進み具合を表示する。検索ではタイムゾーンだけでなく町も見つかるので、Fort LauderdaleはNew YorkではなくFort Lauderdaleだ。上部の行が間違った都市名を挙げていたら、それをクリックして自分がどこにいるか伝えればいい。別のタイムゾーンの場所を選ぶとシステムクロックもそこへ移動するので、旅行のときに便利だ。都市にホバーして人物ボタンをクリックすると、誰がそこに住んでいるかを伝えられる ― プレーンネームでも、`@` GitHubハンドルで顔も一緒に連れてくることもできる。

どのパネルもマウスだけでなくキーボードも受け付ける: 矢印で移動し、Returnで有効化し、Tabで隣のパネルへ移動し、Escapeで閉じる。

`Super + Ctrl + 1-9`は右セクションのパネルを左から右へ数える。独自のパネルを持たないトレイはスキップする。だから数字は指し示すアイコンと一致する。

### TailscaleとDropbox

さらに2つのウィジェットは、**インストール → サービス**から対応するサービスをインストールして初めてバーに表示される。どちらもステータスを報告する以上のことをするので、知っておく価値がある。

**Tailscale**パネルはtailnetの接続と切断、アカウントの切り替え、出口ノードの選択を行う（自分のマシンとMullvadリージョンの両方がそのリストに表示される）。またマシンを閲覧でき、1つ選択した状態で`s`を押すとTaildropでそれにファイルを送信する。これが携帯電話や別のノートパソコンにファイルを移動する最速の方法だ。`c`はマシンのIPを、`n`はその名前を、`d`はその完全なDNS名をコピーする。各マシンの行には送信ボタンもあるので、クリックしたいならそれでいい。ターミナルから同じことをするには`omarchy tailscale send <machine> [file...]`だ。

**Dropbox**パネルはログインを処理し、使用したストレージ容量を表示し、最近同期されたファイルを一覧表示する。

どちらかのサービスを削除すると、そのウィジェットもバーから消える。

## インジケーター

中央にある小さな集まりがインジケーターウィジェットだ。これらはオンにしたモードのステータスグリフだ: 取り込み中、ナイトライト、キューに入った[リマインダー](09-reminders.md)、アクティブな画面録画、起きたまま維持、それにパスワードなしsudoがオンのときや誰かがリモートセッションに接続しているときの警告だ。モードがアクティブなときに点灯し、それ以外のときは邪魔にならない ― 非アクティブなものがあるはずの場所のすぐ横にホバーすれば、それらを覗き見ることができる。インジケーターをクリックするとそのモードが切り替わる。もう1つはステータスのみだ: リモートセッションは、誰かがgliffを通じてこのマシンに接続している間、赤く点灯する。

常に表示したいなら、ウィジェットで`alwaysShow`を`true`に設定すればいい。一部だけ気にするなら、欲しいものを`items`に列挙すればいい: `["Dnd", "Reminder", "NightLight"]`。インジケーターウィジェットは複数持てるので、セクションごとに異なるサブセットを表示できる。

## バーの並べ替え

バーは自分自身を設定する。ものを移動するために設定ファイルを開く必要はない。

中央付近のバーの空いている場所を掴んで別の画面の端へドラッグすると、バーがそこへ移動する ― 左、右、上、下すべて機能し、すべてのウィジェットが適応する（縦型バーはコンパクトなアイコンのみの形にフォールバックする）。クリックして保持することでも同じドラッグが始まる。同じ空いている場所を左ダブルクリックすると、バーの背景が透明からガラス質、不透明へと切り替わる。また、任意のウィジェットをドラッグして並べ替えたり別のセクションに投げ入れたりできる。他のウィジェットは、それが着地する場所に場所を空けるよう滑って離れる。

バーの中央はボックスだ: その中にあるものは1つのグループとして中央に置かれ続け、その両側のウィジェットはその端からぶら下がる。ウィジェットをドラッグしている間、ボックスは輪郭として表示されるか、空の場合はバーを横切る線として表示され、その中にもその横にもドロップできる。ドロップがボックス内に着地する場合、ボックスはそのウィジェットを取り込めるよう大きくなる。

常に見えていなくても構わないが手元には置きたいウィジェットは、トレイのドロワーに入れることができる: トレイにドラッグすると、ドロワーが開いてそれを取り込む。それはアプリのアイコンの後ろにそこに座り、ドロワーが表示されるたびに現れ、自分のパネルが開いている間はドロワーを開いたままにする。バーに再びドラッグして戻せば元に戻る。

メニューから選びたいなら、**外観 → メニューバー**に位置があり、**バーの背景**でバーの描画方法を選ぶ: **不透明なバー**、**ガラス質のバー**（透けて見え、背後がぼやける）、または**透明なバー**。

同じことはコマンドでもできる。これが[dotfiles](31-dotfiles.md)セットアップで欲しいものだ:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

ウィジェットを丸ごと追加または削除するには、プラグインコマンドを使う。`omarchy plugin list`は、シェルが知っているすべてのウィジェットをそのidとともに表示し、次に:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## バーを隠す

`Super + Shift + Space`はシェルを終了せずにバーをオフとオンに切り替える ― パネルとホットキーは引き続き機能し、ピクセルを取り戻せるだけだ。メニューの**外観 → メニューバー → バーを隠す**にもある。

## 設定ファイル

すべては`~/.config/omarchy/shell.json`の`bar`キーの下に保存される。トリミングしたバージョンは次のとおりだ:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

すべてのウィジェットは5つのレイアウト配列のうち1つにある1つのエントリで、その設定はそのエントリ上にインラインで置かれる ― 別個の設定ファイルはなく、`config`サブオブジェクトもない。時計の`format`、`formatAlt`（右クリックで切り替わるもの）、`verticalFormat`はすべて`{ "id": "omarchy.clock" }`のすぐそこにある。

`center`はバーの中央にあるボックスだ: その中にあるものはすべて1つのグループとして画面の中央に配置される。`centerBegin`と`centerEnd`はボックスの両側にぶら下がる。これにより、天気やアップデートバッジが出たり消えたりしても時計がど真ん中に居続ける。`center`に複数のウィジェットを置けばそれらは一緒に中央配置され、空にしておけば`centerBegin`と`centerEnd`がバーの中央で出会う。

覚えておく価値のあるルールは1つ: **自分の`shell.json`を持った瞬間、それが正となる**。何もカスタマイズしていないうちは、シェルはOmarchyのデフォルトファイルを読み込む。ウィジェットをドラッグしたり、`omarchy bar`を実行したり、自分でファイルを編集した瞬間、それはあなたのものになる ― ディープマージはないので、今後のOmarchyリリースで新しいデフォルトウィジェットが現れても、自動でバーには現れない。`omarchy bar defaults`は、きれいな状態からやり直したいときはいつでも出荷時のレイアウトに戻す。

同じファイルは、`bar`キーの外のトップレベルにアイドルタイミングも保持する: `idle.screensaver`と`idle.lock`。どちらもアイドルになってからの秒数だ。だからデフォルトのスクリーンセーバーは150秒で起動し、ロックは300秒で起動する。
