# その他のパッケージ

Arch には、公式リポジトリと Arch User Repository (AUR) の間に、ほぼあらゆる種類のソフトウェア向けの驚くべきパッケージの豊かさがあります。

使い方も簡単です。新しい Arch パッケージは Omarchy メニュー（`Super + Space`）の _インストール > Package_ へ移動し、欲しいパッケージを入力してインストールします。すべてのパッケージのリストを自動であいまいフィルタします。（ターミナルで `omarchy pkg add [package]` を使って手動でもできます）。

AUR でも同じことができます。その場合は _インストール > AUR_ を使ってください。ただし、AUR は Arch チームによって審査されていないことを覚えておいてください。RubyGems や npm のようなものです。誰でもアップロードできます。

パッケージを削除したい場合は、Omarchy メニューの _削除 > Package_ を使ってください。パッケージ、設定ファイル、依存関係が削除されます。（`omarchy pkg drop [package]` を使って手動でもできます）。
