# トグル、アイドルとスクリーンセーバー

日々変更するものの多くは、本当の意味での設定ではない。1時間だけオンにして、またオフに戻すモードだ。夜遅くまで作業するときのナイトライト、プレゼンテーション中の通知ミュート、何かを見ている間にスリープさせないための常時起動。Omarchyはこれらをトグルと呼び、すべて同じように動作する。ホットキー、メニュー項目、コマンドのどれからでも、同じスイッチを操作できる。

### トグルメニュー

`Super + Ctrl + O` で _Trigger > Toggle_ を直接開ける。Omarchyメニュー（`Super + Space`）からたどることもできる。このリストにあるものはすべて、状態がどこに保存されているかを考えなくても切り替えられるスイッチだ。デスクトップの見た目に関するスイッチは、その隣の _Appearance_ にある。

ターミナルからは、同じスイッチを `omarchy toggle <thing>` で操作できる。`omarchy toggle` を単独で実行すると、グループ全体を確認できる。

| トグル | ホットキー | コマンド |
| ------ | ------ | ------- |
| ナイトライト | — | `omarchy toggle nightlight` |
| 通知をミュート | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| 常時起動（アイドル時にロックしない） | `Super + Ctrl + I` | `omarchy toggle idle` |
| クラッシュキャプチャ | — | `omarchy toggle crash-capture` |
| スクリーンセーバー | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) のテーマ同期 | — | `omarchy toggle theme sync` |
| メニューバー | `Super + Shift + Space` | `omarchy toggle bar` |
| タッチパッド | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| タッチスクリーン | — | `omarchy toggle touchscreen` |
| サスペンド | — | `omarchy toggle suspend` |
| Hybrid GPU | — | `omarchy toggle hybrid gpu` |

タッチパッド、タッチスクリーン、Hybrid GPU のスイッチは、Toggle ではなく _Trigger > Hardware_（`Super + Ctrl + H`）にある。そのハードウェアを実際に搭載している場合にのみ表示されるからだ。タッチパッドとタッチスクリーンのスイッチは Hyprland のリロード後も維持される。無効化したデバイスの名前が小さな状態ファイルに保存され、Hyprland は起動時にそれを読み取って再び無効化する。

_Appearance_ にはメニューバーとアニメーションに加え、`omarchy toggle` コマンドではないが同じように動作するものがいくつかある。バーへのバッテリー残量パーセント表示、デフォルトのワークスペースレイアウト、そして _Windows_ にはウィンドウの間隔（`Super + Shift + Backspace`）と1ウィンドウ時の正方形アスペクト（`Super + Ctrl + Backspace`）がある。

これらのほとんどは、`~/.local/state/omarchy/toggles/` にあるただのフラグファイルだ。スクリプトで分岐させたい場合は、わざわざ探しに行かなくても `omarchy-toggle-enabled` が終了コードを返してくれる。

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

フラグはオフ状態の名前になっている。`screensaver-off`、`suspend-off`、`bar-off` などだ。つまり、ファイルが存在すればその機能は無効になっている。

### バーのインジケーター

モードがオンになると、トップバーの中央、時計の隣に小さなグリフが表示される。これがインジケーターウィジェットで、音声入力、画面録画、保留中のリマインダー、ナイトライト、通知ミュート、常時起動を担っている。

非アクティブなインジケーターは隠れている。バーのどこかにカーソルを合わせると暗くフェードインするので、ホットキーを知らなくてもクリックしてオンにできる。アクティブなものをクリックするとオフに戻る。すべてを常に表示したい場合は、`~/.config/omarchy/shell.json` の `omarchy.indicators` エントリで `alwaysShow` を `true` に設定する。バーウィジェットの設定方法については[トップバー](05-the-top-bar.md)を参照のこと。

### ナイトライト

ナイトライトは画面を 4000K に暖かくし、もう一度トグルすると 6500K に戻す。トグルメニュー（`Super + Ctrl + O`）から、または `omarchy toggle nightlight` で切り替える。hyprsunset が駆動しており、まだ実行されていない場合はトグルが起動してくれる。

デフォルトでは hyprsunset は画面にまったく何もしない。`~/.config/hypr/hyprsunset.conf` には identity プロファイルが同梱されており、暖かさを求めるまではディスプレイに一切手を加えないようになっている。時計に合わせて切り替えたい場合は、それを時間プロファイルに置き換える。

```
profile {
    time = 20:00
    temperature = 4000
}
```

そのうえで、`~/.config/hypr/autostart.lua` に `o.launch_on_start("hyprsunset")` を追加して、ログイン時に hyprsunset を起動する。トグルが使う 4000K/6500K のペアは固定されているので、別の色温度にしたい場合は設定ファイルを変更する。

### 通知ミュート

`Super + Ctrl + Alt + ,` で通知をミュートする。オンの間はトーストがポップアップせず、バーには斜線の入ったベルのインジケーターが表示され、デスクトップが静かになっている理由を思い出させてくれる。

何も失われるわけではない。ミュートされた通知は保留される。`Super + Shift + Alt + ,` で直近の数件を画面に戻せる。残りについては[通知](10-notices.md)を参照のこと。

それでも通過するメッセージが2種類ある。今しがた自分が行った操作に対する Omarchy 自身の確認トースト（「Theme changed」、「Screenshot saved」）と、コマンドラインから送信された重要なアラートだ。何でもかんでも critical とマークして無理やり前面に出ようとするチャットアプリは該当しない。

### アイドル

Omarchy シェルがアイドル時の動作を担っており、そのタイミングは `~/.config/omarchy/shell.json` のトップレベルの `idle` ブロックにある。

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

どちらの数値も、アイドル状態になった瞬間から数えた秒数であり、互いからの秒数ではない。つまりデフォルトでは、スクリーンセーバーが2分半後に表示され、スクリーンセーバーが実行されたかどうかに関係なく、5分でロック画面に引き継がれる。ファイルを保存すれば、シェルは新しいタイミングをすぐに反映する。

ロックの期限前にスクリーンセーバーを解除した場合、それはアクティビティとして数えられ、保留中のロックはキャンセルされる。マシンをちらっと見ただけでロックアウトされることはない。

アイドル時のロックを完全に止めるには、`Super + Ctrl + I`、または `omarchy toggle idle` で常時起動をオンにする。バーにコーヒーカップのインジケーターが表示される。長いプレゼンテーションの前や、見守りたいビルドの前に押すべきなのはこれだ。もう一度押せば通常に戻る。スクリプトから必要な場合は、`omarchy toggle idle status` で現在の状態を JSON として出力できる。

これはロックとスクリーンセーバーについての話であり、電源についての話ではない。サスペンドとハイバネーションは[システムスリープ](36-system-sleep.md)で別途設定する。

### スクリーンセーバー

Omarchy のスクリーンセーバーは、ランダムなテキストエフェクトを通じて流れる ASCII アートで、モニターごとに1インスタンスが動く。任意のキー入力やマウス移動で終了する。

_System > Screensaver_（`Super + Esc`）からオンデマンドで起動でき、アイドル時のスクリーンセーバーをオフにしていても強制的に表示できる。デフォルトで割り当てられたホットキーはない。

アイドル時のものをオフにして、作業状態から直接ロック状態に移りたい場合は `omarchy toggle screensaver` を使う。設定方法を把握しているターミナル、つまり Alacritty、Foot、Ghostty、Kitty のいずれかが必要で、デフォルトのターミナルがそれ以外であればその旨を教えてくれる。

描画されるロゴは _Appearance > Branding > Screensaver_ で変更できる。png または svg をアップロードすると、Omarchy が ASCII に変換する。[ブランディング](41-branding.md)を参照のこと。

### ロック画面

`Super + Ctrl + L` でマシンをロックする。これにより Omarchy シェルからロック画面が実行され、ディスプレイが消え、キーボードレイアウトが最初のものにリセットされて間違ったアルファベットでパスワードを入力することがなくなり、実行中であれば 1Password もついでにロックされる。

ロック画面はパスワードを受け付け、指紋を設定済みであれば指紋も受け付ける。その点やその他の認証方法については[ハードウェア認証](37-hardware-authentication.md)で説明している。
