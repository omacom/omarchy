# トグル、アイドル、スクリーンセーバー

日常的に変えるものの多くは、実は設定じゃない。1時間だけオンにして、またオフに戻すモードだ：遅くまで作業するときのナイトライト、発表中の通知を止める機能、何かを見ている間にスリープさせない機能。Omarchy はこれをトグルと呼び、どれも同じように動く — ホットキー、メニュー項目、コマンドがすべて同じスイッチを叩く。

### トグルメニュー

`Super + Ctrl + O` で _Trigger > Toggle_ を直接開く。Omarchy メニュー（`Super + Space`）からたどってもいい。そのリストにあるものは全部、状態がどこに保存されているか考えずに切り替えられるスイッチだ。デスクトップの見た目に関するスイッチは、その隣の _Appearance_ にある。

ターミナルからは、同じスイッチが `omarchy toggle <thing>` だ。`omarchy toggle` だけを実行すれば、グループ全体が見える。

| トグル | ホットキー | コマンド |
| ------ | ------ | ------- |
| ナイトライト | — | `omarchy toggle nightlight` |
| 通知を止める | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| スリープ防止（アイドル時ロックなし） | `Super + Ctrl + I` | `omarchy toggle idle` |
| クラッシュキャプチャ | — | `omarchy toggle crash-capture` |
| スクリーンセーバー | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) テーマ同期 | — | `omarchy toggle theme sync` |
| メニューバー | `Super + Shift + Space` | `omarchy toggle bar` |
| タッチパッド | `XF86TouchpadToggle` | `omarchy device touchpad` |
| タッチスクリーン | — | `omarchy device touchscreen` |
| サスペンド | — | `omarchy toggle suspend` |
| ハイブリッド GPU | — | `omarchy toggle hybrid gpu` |

タッチパッド、タッチスクリーン、ハイブリッド GPU のスイッチは Toggle ではなく _Trigger > Hardware_（`Super + Ctrl + H`）にある。そういうハードウェアがあるときにだけ表示されるからだ。タッチパッドとタッチスクリーンのスイッチは Hyprland のリロード後も維持される — 無効化したデバイスの名前が小さな状態ファイルに保存され、Hyprland が起動時にそれを読んで再び無効化する。

_Appearance_ にはメニューバーとアニメーションがあり、`omarchy toggle` コマンドではないが同じように動作するものもいくつかある：バーに表示するバッテリー残量のパーセンテージ、デフォルトのワークスペースレイアウト、そして _Windows_ の下にあるウィンドウの隙間（`Super + Shift + Backspace`）と1ウィンドウ時の正方形アスペクト比（`Super + Ctrl + Backspace`）だ。

Hyprland が描画に使える GPU を持たず、代わりに CPU でレンダリングする場合（llvmpipe）、GPU がまだサポートされていない Mac、ほとんどの仮想マシン、グラフィックスドライバーが読み込みに失敗した場合などでは、Omarchy はそのセッションのアニメーション、ぼかし、影をオフにし、そのことを通知で一度だけ知らせる。_Appearance > Animations On_ で元に戻せて、Omarchy はそれを以降のセッションでも覚えている。

これらのほとんどは、`~/.local/state/omarchy/toggles/` の下にあるただのフラグファイルだ。スクリプトでどれかを条件分岐に使いたいなら、自分で探しに行かなくても `omarchy-toggle-enabled` が終了コードで教えてくれる：

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

フラグの名前はオフの状態を表している — `screensaver-off`、`suspend-off`、`bar-off` — つまり、ファイルが存在すればその機能は無効だということだ。

### バーのインジケーター

モードがオンのとき、トップバーの中央、時計の隣に小さなグリフが表示される。それがインジケーターウィジェットで、ディクテーション、画面録画、保留中のリマインダー、ナイトライト、通知を止める機能、スリープ防止を表示する。

非アクティブなインジケーターは隠れている。バーのどこかにホバーすると、薄くフェードインするので、ホットキーを知らなくてもクリックしてオンにできる。アクティブなものをクリックすればオフに戻る。全部を常時表示したいなら、`~/.config/omarchy/shell.json` の `omarchy.indicators` エントリで `alwaysShow` を `true` に設定する — バーウィジェットの設定方法は[トップバー](05-the-top-bar.md)を参照。

### ナイトライト

ナイトライトは画面を 4000K まで暖かくし、もう一度トグルすると 6500K に戻す。トグルメニュー（`Super + Ctrl + O`）から、または `omarchy toggle nightlight` で切り替える。hyprsunset が駆動していて、まだ実行されていない場合はトグルが起動してくれる。

デフォルトでは、hyprsunset は画面にまったく何もしない。`~/.config/hypr/hyprsunset.conf` にはアイデンティティプロファイルが同梱されており、暖かさを求めるまでディスプレイはそのままに保たれる。時計で切り替えたいなら、時間プロファイルに置き換える：

```
profile {
    time = 20:00
    temperature = 4000
}
```

その後、`~/.config/hypr/autostart.lua` に `o.launch_on_start("hyprsunset")` を追加して、ログイン時に hyprsunset を起動する。トグルが使う 4000K/6500K のペアは固定されているので、違う温度が欲しい場合は設定ファイルが行き先だ。

### 通知を止める

`Super + Ctrl + Alt + ,` で通知を止める。オンの間はトーストがポップアップせず、バーにある斜線入りのベルのインジケーターが、デスクトップが静かになった理由を思い出させてくれる。

何も失われないけどな。止められた通知は保留される：最後の数件を `Super + Shift + Alt + ,` で画面に戻せる。残りは[通知](10-notices.md)を参照。

2種類のメッセージはそれでも通る：ちょうど行ったことに対する Omarchy 自身の確認トースト（"Theme changed"、"Screenshot saved"）と、コマンドラインから送信される重要なアラートだ。何でもかんでも critical とマークして無理やり前に出てくるチャットアプリは該当しない。

### アイドル

Omarchy シェルがアイドル時の動作を所有し、そのタイミングは `~/.config/omarchy/shell.json` のトップレベルの `idle` ブロックにある：

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

どちらの数値も、アイドル状態になってからの秒数だ — お互いからの秒数じゃない。だからデフォルトでは、スクリーンセーバーが2分半後に表示され、スクリーンセーバーが実行されたかどうかに関係なく、ロック画面が5分で引き継ぐ。ファイルを保存すれば、シェルは新しいタイミングをすぐに取り込む。

ロックの期限前にスクリーンセーバーを閉じたら、それはアクティビティとしてカウントされ、保留中のロックはキャンセルされる。マシンをちらっと見ただけでロックアウトされることはない。

アイドル時のロックを完全に止めるには、`Super + Ctrl + I` — または `omarchy toggle idle` — でスリープ防止をオンにすると、バーにコーヒーカップのインジケーターが現れる。長いプレゼンテーションの前や、見守りたいビルドの前に押すのはこれだ。もう一度押せば通常に戻る。スクリプトから必要な場合は、`omarchy toggle idle status` が現在の状態を JSON として出力する。

これは電源ではなく、ロックとスクリーンセーバーの話だ。サスペンドとハイバネーションは[システムスリープ](36-system-sleep.md)で独自に設定する。

### スクリーンセーバー

Omarchy のスクリーンセーバーは、ランダムなテキストエフェクトを次々と適用しながら流れる ASCII アートで、モニターごとに1インスタンスが動く。任意のキーやマウスの動きで終了する。

_System > Screensaver_（`Super + Esc`）からオンデマンドで起動でき、アイドル時のスクリーンセーバーをオフにしていても強制的に表示できる。デフォルトではホットキーは割り当てられていない。

アイドル時のものをオフにするのは `omarchy toggle screensaver` で、作業中から直接ロック状態に行きたい場合に使う。任意のキー、クリック、スクロール、マウスの動きで閉じる。

描画されるロゴは変更でき、_Appearance > Branding > Screensaver_ の下にある。png や svg をアップロードすると、Omarchy が ASCII に変換する。[ブランディング](41-branding.md)を参照。

### ロック画面

`Super + Ctrl + L` でマシンをロックする。Omarchy シェルからロック画面を実行し、ディスプレイを空白にし、キーボードレイアウトを最初のものにリセットするので、間違ったアルファベットでパスワードを入力することがなくなり — 実行している場合は — 終了時に 1Password もロックする。

ロック画面はパスワードを受け付け、設定済みであれば指紋も受け付ける。その話とその他の認証方法は[ハードウェア認証](37-hardware-authentication.md)でカバーしている。
