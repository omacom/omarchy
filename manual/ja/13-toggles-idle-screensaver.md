# トグル、アイドル、スクリーンセーバー

日常的に変更するものの多くは、実際には設定ではありません。1時間だけオンにして、またオフに戻すモードです。夜遅くまで作業するときのナイトライト、プレゼンテーション中の通知ミュート、何かを見ている間にスリープさせないための起きたままモードなどです。Omarchyはこれらをトグルと呼び、すべて同じように動作します。ホットキー、メニュー項目、コマンドのどれもが同じスイッチを操作します。

### トグルメニュー

`Super + Ctrl + O` で _Trigger > Toggle_ を直接開くか、Omarchyメニュー（`Super + Space`）からたどることができます。そのリストにあるものはすべて、状態がどこに保存されているかを考えなくても切り替えられるスイッチです。デスクトップの見た目に関するスイッチは、その隣の _Appearance_ にあります。

ターミナルからは、同じスイッチを `omarchy toggle <thing>` で操作できます。`omarchy toggle` を単独で実行すると、グループ全体を確認できます。

| トグル | ホットキー | コマンド |
| ------ | ------ | ------- |
| ナイトライト | — | `omarchy toggle nightlight` |
| 通知をミュート | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| 起きたままにする（アイドルロックなし） | `Super + Ctrl + I` | `omarchy toggle idle` |
| クラッシュキャプチャ | — | `omarchy toggle crash-capture` |
| スクリーンセーバー | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) テーマ同期 | — | `omarchy toggle theme sync` |
| メニューバー | `Super + Shift + Space` | `omarchy toggle bar` |
| タッチパッド | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| タッチスクリーン | — | `omarchy toggle touchscreen` |
| サスペンド | — | `omarchy toggle suspend` |
| ハイブリッド GPU | — | `omarchy toggle hybrid gpu` |

タッチパッド、タッチスクリーン、ハイブリッド GPU のスイッチは Toggle ではなく _Trigger > Hardware_（`Super + Ctrl + H`）にあります。これらは、そのハードウェアを実際に備えている場合にだけ表示されるためです。タッチパッドとタッチスクリーンのスイッチは Hyprland のリロード後も維持されます。無効化したデバイスの名前が小さな状態ファイルに保存され、Hyprland は起動時にそれを読み取って再び無効化します。

_Appearance_ にはメニューバーとアニメーションのほか、`omarchy toggle` コマンドではありませんが同じように動作するものがいくつかあります。バーに表示するバッテリー残量のパーセンテージ、デフォルトのワークスペースレイアウト、そして _Windows_ におけるウィンドウの間隔（`Super + Shift + Backspace`）と1ウィンドウ時の正方形アスペクト（`Super + Ctrl + Backspace`）です。

Hyprland が描画に使える GPU を持たず、代わりに CPU でレンダリングする場合（llvmpipe）、たとえば GPU がまだサポートされていない Mac、ほとんどの仮想マシン、グラフィックスドライバーの読み込みに失敗した場合などには、Omarchy はそのセッションのアニメーション、ぼかし、影をオフにし、通知で一度だけそのことを知らせます。_Appearance > Animations On_ で元に戻すことができ、Omarchy はその設定を以降のセッションでも記憶します。

これらのほとんどは、`~/.local/state/omarchy/toggles/` 以下にある単なるフラグファイルです。スクリプトで条件分岐したい場合は、自分で探しに行かなくても `omarchy-toggle-enabled` が終了コードを返します。

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

フラグはオフの状態を表す名前になっています。`screensaver-off`、`suspend-off`、`bar-off` などです。そのため、ファイルが存在すれば、その機能は無効化されているということです。

### バーのインジケーター

モードがオンになると、トップバーの中央、時計の隣に小さなグリフが表示されます。それがインジケーターウィジェットで、ディクテーション、画面録画、保留中のリマインダー、ナイトライト、通知ミュート、起きたままモードを表示します。

非アクティブなインジケーターは非表示です。バーのどこかにホバーすると、それらが薄くフェードインするので、ホットキーを知らなくてもクリックしてオンにできます。アクティブなものをクリックすると再びオフになります。常にすべて表示したい場合は、`~/.config/omarchy/shell.json` の `omarchy.indicators` エントリで `alwaysShow` を `true` に設定してください。バーウィジェットの設定方法については [トップバー](05-the-top-bar.md) を参照してください。

### ナイトライト

ナイトライトは画面を 4000K まで温かくし、もう一度トグルすると 6500K に戻します。トグルメニュー（`Super + Ctrl + O`）から切り替えるか、`omarchy toggle nightlight` を使います。hyprsunset が動作していない場合は、トグルが自動で起動します。

デフォルトでは、hyprsunset は画面に一切影響しません。`~/.config/hypr/hyprsunset.conf` にはアイデンティティプロファイルが同梱されており、温かみを求めるまではディスプレイに手を加えないようになっています。時計に合わせて切り替えたい場合は、それを時刻プロファイルに置き換えてください。

```
profile {
    time = 20:00
    temperature = 4000
}
```

その後、`~/.config/hypr/autostart.lua` に `o.launch_on_start("hyprsunset")` を追加して、ログイン時に hyprsunset を起動します。トグルで使われる 4000K/6500K のペアは固定されているため、別の色温度にしたい場合は設定ファイルを編集してください。

### 通知ミュート

`Super + Ctrl + Alt + ,` で通知をミュートします。オンの間はトーストがポップアップせず、取り消し線の入ったベルのインジケーターがバーに表示され、デスクトップが静かになった理由を思い出させてくれます。

ただし、何も失われません。ミュートされた通知は保留されます。直近の数件は `Super + Shift + Alt + ,` で画面に戻せます。その他の詳細は [お知らせ](10-notices.md) を参照してください。

それでも通過するメッセージが2種類あります。自分が今行った操作に対する Omarchy 自身の確認トースト（「テーマを変更しました」「スクリーンショットを保存しました」）と、コマンドラインから送信された重要なアラートです。すべてを重要として無理やり前面に出ようとするチャットアプリは、その対象にはなりません。

### アイドル

Omarchy シェルがアイドル時の動作を管理し、そのタイミングは `~/.config/omarchy/shell.json` のトップレベルにある `idle` ブロックで設定します。

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

どちらの数値も、アイドル状態になってからの秒数であり、互いからの秒数ではありません。そのため、デフォルトではスクリーンセーバーが2分半後に表示され、スクリーンセーバーが実行されたかどうかに関係なく、5分後にロック画面に切り替わります。ファイルを保存すれば、シェルは新しいタイミングをすぐに反映します。

ロックの期限前にスクリーンセーバーを解除した場合、それはアクティビティとして扱われ、保留中のロックはキャンセルされます。マシンをちらっと見ただけで締め出されることはありません。

アイドル時のロックを完全に止めるには、`Super + Ctrl + I` を押すか `omarchy toggle idle` を実行して起きたままモードをオンにすると、バーにコーヒーカップのインジケーターが表示されます。長いプレゼンテーションの前や、見守りたいビルドの前に押すべきなのはこれです。もう一度押すと通常に戻ります。スクリプトから必要な場合は、`omarchy toggle idle status` で現在の状態を JSON として出力できます。

これはロックとスクリーンセーバーに関するもので、電源に関するものではありません。サスペンドとハイバネーションには、[システムスリープ](36-system-sleep.md) で説明する独自の設定があります。

### スクリーンセーバー

Omarchy のスクリーンセーバーは、ランダムなテキストエフェクトを通じて表示される ASCII アートで、モニターごとに1インスタンスずつ実行されます。キー入力やマウスの動きで終了します。

_System > Screensaver_（`Super + Esc`）からオンデマンドで起動でき、アイドル時のスクリーンセーバーをオフにしていても強制的に表示できます。デフォルトではホットキーは割り当てられていません。

作業状態から直接ロック状態に移りたい場合にアイドル時のスクリーンセーバーをオフにするのが、`omarchy toggle screensaver` です。キー入力、クリック、スクロール、マウスの動きのいずれかで閉じます。

描画されるロゴは _Appearance > Branding > Screensaver_ で変更できます。png または svg をアップロードすると、Omarchy が ASCII に変換します。[ブランディング](41-branding.md) を参照してください。

### ロック画面

`Super + Ctrl + L` でマシンをロックします。これにより Omarchy シェルからロック画面が実行され、ディスプレイが消灯し、キーボードレイアウトが最初のものにリセットされて間違ったアルファベットでパスワードを入力することがなくなり、実行中の場合は終了時に 1Password もロックされます。

ロック画面はパスワードを受け付け、指紋を設定済みであれば指紋も受け付けます。その点やその他の認証方法については、[ハードウェア認証](37-hardware-authentication.md) で説明しています。
