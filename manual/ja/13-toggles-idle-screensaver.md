# トグル、アイドル、スクリーンセーバー

日常的に切り替えるものの多くは、本当の意味での設定ではない。1時間だけオンにして、またオフに戻すモードだ。夜遅くまで作業するときのナイトライト、プレゼン中のおやすみモード、何かを見ているときにスリープさせないモード。Omarchy ではこれらをトグルと呼び、どれも同じ仕組みで動作する。ホットキー、メニュー項目、コマンド、そのすべてが同じスイッチを操作する。

### トグルメニュー

`Super + Ctrl + O` で _Trigger > Toggle_ を直接開ける。Omarchy メニュー（`Super + Space`）からたどることもできる。そのリストにあるものはすべて、状態がどこに保存されているかなど気にせずに切り替えられるスイッチだ。デスクトップの見た目に関するスイッチは、その隣の _Appearance_ にある。

ターミナルからは、同じスイッチを `omarchy toggle <thing>` で操作できる。`omarchy toggle` だけを実行すれば、グループ全体が表示される。

| トグル | ホットキー | コマンド |
| ------ | ------ | ------- |
| ナイトライト | — | `omarchy toggle nightlight` |
| 通知を消音 | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| スリープ防止（アイドル時にロックしない） | `Super + Ctrl + I` | `omarchy toggle idle` |
| クラッシュキャプチャ | — | `omarchy toggle crash-capture` |
| スクリーンセーバー | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) テーマ同期 | — | `omarchy toggle theme sync` |
| メニューバー | `Super + Shift + Space` | `omarchy toggle bar` |
| フルスクリーンデスクトップ（バーなし、隙間なし） | `Super + Ctrl + Alt + F` | `omarchy toggle fullscreen desktop` |
| アニメーション、ぼかし、影 | — | `omarchy toggle animations` |
| タッチパッド | `XF86TouchpadToggle` | `omarchy device touchpad` |
| タッチスクリーン | — | `omarchy device touchscreen` |
| サスペンド | — | `omarchy toggle suspend` |
| ハイブリッド GPU | — | `omarchy device gpu hybrid` |

タッチパッド、タッチスクリーン、ハイブリッド GPU のスイッチは、Toggle ではなく _Trigger > Hardware_（`Super + Ctrl + H`）にある。そのハードウェアが実際に存在する場合にだけ表示されるからだ。タッチパッドとタッチスクリーンの設定は Hyprland のリロード後も維持される。無効化したデバイスの名前が小さな状態ファイルに保存され、Hyprland が起動時にそれを読み取って再び無効化する。

_Appearance_ にはメニューバーとアニメーションに加え、`omarchy toggle` コマンドではないが同じように動作するものがいくつかある。バーへのバッテリー残量パーセント表示、デフォルトのワークスペースレイアウト、そして _Windows_ の下にあるウィンドウの隙間（`Super + Shift + Backspace`）と1ウィンドウ時の正方形アスペクト（`Super + Ctrl + Backspace`）だ。

Hyprland が描画に使える GPU を持たず、代わりに CPU でレンダリングする場合（llvmpipe）、たとえば GPU がまだサポートされていない Mac、ほとんどの仮想マシン、グラフィックスドライバーの読み込みに失敗した場合などでは、Omarchy はそのセッションのアニメーション、ぼかし、影をオフにし、通知で一度だけそのことを知らせる。_Appearance > Animations On_ で元に戻せる。Omarchy はその設定を以降のセッションでも覚えている。

これらのほとんどは、`~/.local/state/omarchy/toggles/` 下にある単なるフラグファイルだ。スクリプトで条件分岐したい場合は、自分で探しに行かなくても `omarchy-toggle-enabled` が終了コードで教えてくれる：

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

フラグはオフ状態の名前になっている。`screensaver-off`、`suspend-off`、`bar-off` のように。つまり、ファイルが存在すればその機能は無効ということだ。

### バーのインジケーター

モードがオンになると、トップバー中央の時計の隣に小さなグリフが表示される。それがインジケーターウィジェットで、画面録画、保留中のリマインダー、ナイトライト、おやすみモード、スリープ防止を表示し、パスワードなし sudo がオンの間や、誰かがリモートセッションに接続している間の警告も表示する。

非アクティブなインジケーターは隠れている。バーのどこかにホバーすると薄くフェードインするので、ホットキーを知らなくてもクリックしてオンにできる。アクティブなものをクリックすればオフに戻る。すべてを常時表示したい場合は、`~/.config/omarchy/shell.json` の `omarchy.indicators` エントリで `alwaysShow` を `true` に設定する。バーウィジェットの設定方法については[トップバー](05-the-top-bar.md)を参照。

### ナイトライト

ナイトライトは画面を 4000K まで暖かくし、もう一度切り替えると 6500K に戻る。トグルメニュー（`Super + Ctrl + O`）か `omarchy toggle nightlight` で切り替える。駆動しているのは hyprsunset で、まだ実行されていなければトグルが代わりに起動してくれる。

デフォルトでは、hyprsunset は画面に一切何もしない。`~/.config/hypr/hyprsunset.conf` には identity プロファイルが同梱されており、暖かさを求めるまではディスプレイに手を加えないようになっている。時刻で切り替えたい場合は、それを時刻プロファイルに置き換える：

```
profile {
    time = 20:00
    temperature = 4000
}
```

そのうえで、`~/.config/hypr/autostart.lua` に `o.launch_on_start("hyprsunset")` を追加して、ログイン時に hyprsunset を起動する。トグルが使う 4000K/6500K のペアは固定なので、別の色温度にしたい場合は設定ファイルを編集することになる。

### おやすみモード

`Super + Ctrl + Alt + ,` で通知を消音する。オンの間はトーストが一切ポップアップせず、バーに斜線入りのベルのインジケーターが表示され、デスクトップが静かになった理由を思い出させてくれる。

ただし、何も失われるわけではない。消音された通知は保留される。`Super + Shift + Alt + ,` で直近の数件を画面に戻せる。残りについては[通知](10-notices.md)を参照。

それでも通過するメッセージが3種類ある。今しがた自分が行った操作に対する Omarchy 自身の確認トースト（"Theme changed"、"Screenshot saved"）、コマンドラインから送信された重大なアラート、そして認証コードだ。何でもかんでも重大とマークして無理やり前面に出ようとするチャットアプリは対象外だ。

### アイドル

Omarchy シェルがアイドル時の動作を管理しており、そのタイミングは `~/.config/omarchy/shell.json` のトップレベルの `idle` ブロックで設定する：

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

どちらの数値も、アイドル状態に入った瞬間から数えた秒数であり、互いを起点にしたものではない。したがってデフォルトでは、スクリーンセーバーが2分半後に表示され、スクリーンセーバーが実行されたかどうかに関係なく、5分後にロック画面に切り替わる。ファイルを保存すれば、シェルがすぐに新しいタイミングを反映する。

ロックの期限前にスクリーンセーバーを解除すれば、それが操作として数えられ、保留中のロックはキャンセルされる。ちょっとマシンをのぞいただけで締め出されることはない。

アイドル時のロックを完全に止めるには、`Super + Ctrl + I`（または `omarchy toggle idle`）でスリープ防止をオンにする。するとバーにコーヒーカップのインジケーターが表示される。長いプレゼンや、見守りたいビルドの前に押すべきなのはこれだ。もう一度押せば通常に戻る。スクリプトから必要な場合は、`omarchy toggle idle status` が現在の状態を JSON で出力する。

これはロックとスクリーンセーバーについての話で、電源についての話ではない。サスペンドとハイバネーションには[システムスリープ](36-system-sleep.md)で独自の設定がある。

### スクリーンセーバー

Omarchy のスクリーンセーバーは、ランダムなテキストエフェクトがかかった ASCII アートで、モニターごとに1インスタンスが動く。キーを押すかマウスを動かせば終了する。

_System > Screensaver_（`Super + Esc`）からオンデマンドで起動することもでき、アイドル時のスクリーンセーバーをオフにしていても強制的に表示される。デフォルトではホットキーは割り当てられていない。

作業中から直接ロック状態に移りたい場合は、`omarchy toggle screensaver` でアイドル時のスクリーンセーバーをオフにする。キー入力、クリック、スクロール、マウスの移動のいずれでも閉じる。

描画されるロゴは _Appearance > Branding > Screensaver_ で変更できる。png または svg をアップロードすれば、Omarchy が ASCII に変換する。[ブランディング](41-branding.md)を参照。

### ロック画面

`Super + Ctrl + L` でマシンをロックする。これにより Omarchy シェルのロック画面が実行され、ディスプレイが消灯し、キーボードレイアウトが最初のものにリセットされるので、間違った文字種でパスワードを入力してしまうことがなくなり、さらに実行中であれば 1Password もついでにロックされる。

ロック画面ではパスワードを受け付け、指紋を設定すれば指紋でも解除できる。その点やその他の認証方法については[ハードウェア認証](37-hardware-authentication.md)で説明している。
