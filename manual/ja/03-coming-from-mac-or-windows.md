# Mac や Windows から来た人へ

長年 macOS や Windows を使ってきたなら、指は、脳が覚えたことすら忘れてしまったようなことを何百も覚えている。この章は、その翻訳レイヤーだ：その直感が Omarchy ではどこへ行くのか。機能そのものは他で詳しく扱っている——ここでは地図だけを示す。

### Super がすべての中心

Cmd や Windows キーを巡って培ってきたすべての筋肉の記憶は、1つのキーに移る：Super だ。それは PC キーボードの Windows キーで、Omarchy のほぼすべてのホットキーの起点になる。

Spotlight や Raycast やスタートメニューを反射的に開く動きは、`Super + Space` になる。それで Omarchy メニューが開き、アプリの起動、設定の変更、ソフトウェアのインストール、画面のキャプチャ——ほぼ何でもできる。入力し始めれば絞り込める。`Super + Alt + Space` は、Launchpad のように、すべてのアプリを1つのグリッドに表示する。[ナビゲーション](04-navigation.md) を参照。

### デスクトップアイコンはなく、ドックは浮動させたときだけ現れる

デスクトップに並べるアイコンはなく、タイリングワークスペースにはドックもない——ドックは浮動ワークスペースでのみ現れる（[ナビゲーション](04-navigation.md) を参照）。アプリはホットキー（ターミナルは `Super + Return`、ブラウザは `Super + Shift + Return`、割り当て済みのすべてのものの一覧は `Super + K`）か、メニューから起動する。常駐する UI は [トップバー](05-the-top-bar.md) の1つだけで、以前のメニューバー、システムトレイ、通知センターの役割を担う——そしてその上のほぼすべてのウィジットは、左クリック、右クリック、中クリックで何かをする。

### ウィンドウは自分で配置される

最大の考え方の転換：ウィンドウをドラッグしたり、画面の半分にスナップしたりしない。ウィンドウを開けば画面全体を使う。2つ目を開けば画面を分割する。ウィンドウが重ならないので、別のウィンドウの下からウィンドウを掘り出すことも決してない。

浮動ウィンドウが本当に必要なときは、`Super + T` でアクティブなウィンドウをタイリングから切り離す（そして戻す）。だが、まずはタイリングに本気で機会を与えてほしい——それが全体の核心だ。[ナビゲーション](04-navigation.md) が案内する。

ワークスペースは馴染み深く感じるはずだ：macOS の Spaces や Windows の仮想デスクトップのようなものだが、`Super + 1/2/3/4` で直接ジャンプし、`Super + Shift + 1/2/3/4` でアクティブなウィンドウをそこへ送れるので、実際に使うようになる。アニメーションの遅延はなく、即座にジャンプする。つまり、以前は複数モニターに慣れていたとしても、もう必要ないかもしれない。

### コピー＆ペーストはそのまま使える

Mac ではどこでも Cmd + C だった。Windows ではどこでも Ctrl + C だった——ターミナルを除いて。そこではプログラムが終了してしまう。Omarchy では `Super + C`、`Super + X`、`Super + V` が使え、ターミナルを含めどこでも使える。シェル用に別の反射を覚える必要はない。

Windows ユーザーへ：Win + V のクリップボード履歴は `Super + Ctrl + V` にあり、テキストだけでなく画像も保持する。[統合クリップボードと履歴](08-unified-clipboard-history.md) を参照。

### 本当に違うものもある

多くの設定は、クリックしていくパネルではなく、編集するテキストファイルにある。地味に聞こえるが、すべての調整が見え、次のマシンにコピーでき、バージョン管理に置けるということだと気づくまではそうだろう。_Setup_ メニューは正しいファイルへ直接連れて行き、終わったら再起動が必要なものを再起動する。

更新は1つのコマンド——_Update > Omarchy_——で来て、Omarchy 自体とシステム上のすべてのパッケージを更新し、まずスナップショットを取る。ランダムに煩わせるアプリごとのアップデーターはない。[アップデート](30-updates.md) を参照。

ソフトウェアは、ダウンロードしたインストーラーからではなく、パッケージマネージャーから来る。

そしてウィンドウを閉じると、アプリは実際に終了する。ウィンドウがないのにプログラムが動き続ける macOS の中途半端な状態はない。`Super + W`——あるいは、来たときの指の記憶がそれなら `Super + Q`——は、消えることを意味する。

### Mac ハードウェアでは

Omarchy は Intel Mac でよく動作し、M1、M2、M3 Mac では Omarchy for Apple Silicon で動作する。[Mac サポート](44-mac-support.md) を参照。そしてキーボードは優しい：Omarchy は何も再マッピングせず、Linux は Command キーを Super として扱うので、Super は Cmd が常にあった場所にある。親指は引っ越しに気づかないだろう。

### 2週間ください

直感は思うより早く移る。[ホットキー](07-hotkeys.md) の章を一度さっと読めば、割り当てを忘れたときはいつでも `Super + K` を押す——すべて表示される。それが実際に覚えなければならない唯一のホットキーだ。
