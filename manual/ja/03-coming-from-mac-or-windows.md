# Mac や Windows から来た方へ

macOS や Windows で何年も過ごしてきたら、指は、脳がかつて覚えたことすら忘れてしまった何百ものことを知っています。この章はその翻訳レイヤーです。そうした直感が Omarchy ではどこへ行くのか。機能そのものは他の場所で詳しく扱います。ここは単に地図です。

### Super がすべての中心

Cmd や Windows キーを中心に培ってきた筋肉の記憶はすべて、1 つのキー、Super に移ります。PC キーボードでは Windows キーのことで、Omarchy のほぼすべてのホットキーの基点です。

Spotlight や Raycast やスタートメニューの反射は `Super + Space` になります。これで Omarchy メニューが開き、アプリの起動、設定の変更、ソフトウェアのインストール、画面のキャプチャなど、ほぼ何でもできます。入力を始めると絞り込みができます。`Super + Alt + Space` はすべてのアプリを 1 つのグリッドに表示します。Launchpad のような感じです。[移動](04-navigation.md) を参照してください。

### Dock もデスクトップアイコンもありません

クリックして起動するものも、デスクトップに並べるアイコンもありません。アプリはホットキー（ターミナルは `Super + Return`、ブラウザは `Super + Shift + Return`、マッピングされているすべてのリストは `Super + K`）かメニューから起動します。常駐する唯一の UI は [トップバー](05-the-top-bar.md) で、以前メニューバー、システムトレイ、通知センターがやってくれていたことをカバーします。そしてその上のほぼすべてのウィジェットが、左クリック、右クリック、中クリックで何かをします。

### ウィンドウは自分で配置されます

最大の考え方の転換：ウィンドウをドラッグしたり、画面の半分にスナップしたりはしません。ウィンドウを開くと画面全体を使います。2 つ目を開くと画面を分割します。ウィンドウ同士が重ならないので、別のウィンドウの下からウィンドウを掘り出すことは決してありません。

本当にフローティングウィンドウが必要なときは、`Super + T` でアクティブなウィンドウをタイリングから外したり戻したりできます。でもまずタイリングに本当のチャンスを与えてください。それが全体の心臓部です。[移動](04-navigation.md) がその手順を案内します。

ワークスペースは馴染み深く感じるでしょう。macOS の Spaces や Windows の仮想デスクトップです。ただし実際に使うようになるでしょう。なぜなら `Super + 1/2/3/4` で直接ジャンプでき、`Super + Shift + 1/2/3/4` でアクティブなウィンドウをそこへ送れるからです。アニメーションの遅延はなく、瞬時にジャンプします。つまり、以前は複数モニターに慣れていたとしても、もう必要ないかもしれません。

### コピーと貼り付けはそのまま動きます

Mac ではどこでも Cmd + C でした。Windows ではどこでも Ctrl + C でした。ただしターミナルではプログラムを終了させてしまいます。Omarchy では `Super + C`、`Super + X`、`Super + V` が用意されており、ターミナルを含めてどこでも動きます。シェル用に別の反射を覚える必要はありません。

Windows の方：Win + V のクリップボード履歴は `Super + Ctrl + V` にあり、テキストだけでなく画像も保持します。[統合クリップボードと履歴](08-unified-clipboard-history.md) を参照してください。

### 翻訳表

| 手が伸びる先 | Omarchy では |
| ------------- | ---------- |
| Spotlight / Raycast / スタートメニュー | `Super + Space` — Omarchy メニュー |
| AirDrop | LocalSend、`Super + Ctrl + S` 経由 — [GUI](22-guis.md) を参照 |
| Cmd + Shift + 4 / Win + Shift + S | `Print Screen` — [スクリーンショットと録画](12-screenshots-recording.md) を参照 |
| 通知センター | `Super + Shift + Alt + ,` の通知履歴 |
| Time Machine（システム用） | 更新ごとの自動 [システムスナップショット](47-system-snapshots.md) |
| App Store / インストーラーのダウンロード | メニューの _インストール_、または `omarchy pkg add` — [その他のパッケージ](29-other-packages.md) を参照 |
| システム設定 / コントロールパネル | メニューの _設定_。プレーンな設定ファイルを編集します — [dotfiles](31-dotfiles.md) を参照 |

### 本当に違うこともあります

多くの設定は、クリックして回るパネルではなく、編集するテキストファイルの中にあります。それは原始的に聞こえますが、すべての微調整が見え、次のマシンにコピーでき、バージョン管理に入れられるという意味だと気づくまでは、です。_設定_ メニューは正しいファイルに直接連れて行ってくれ、終わったら再起動が必要なものを再起動してくれます。

更新は 1 つのコマンド、_更新 > Omarchy_ で行われ、Omarchy 自体とシステム上のすべてのパッケージを更新し、まずスナップショットを取ります。ランダムにうるさくしてくるアプリごとのアップデーターはありません。[更新](30-updates.md) を参照してください。

ソフトウェアはダウンロードしたインストーラーからではなく、パッケージマネージャーから来ます。

そしてウィンドウを閉じると、アプリは実際に終了します。ウィンドウがないのにプログラムが動き続ける macOS の limbo はありません。`Super + W`、あるいは身につけた指の記憶がそちらなら `Super + Q` で、なくなります。

### Mac ハードウェアでは

Omarchy は Intel Mac で快適に動きます。[Mac サポート](44-mac-support.md) を参照してください。そしてキーボードは親切です。Omarchy は何もリマップせず、Linux は Command キーを Super として扱うので、Super は Cmd がいつもあった場所にあります。親指は移動に気づかないでしょう。

### 2 週間試してください

直感は思っているより早く移ります。[ホットキー](07-hotkeys.md) の章を一度ざっと読み、バインドを思い出せないときはいつでも `Super + K` を押してください。すべて表示してくれます。それが実際に覚えなければならない唯一のホットキーです。
