# MacやWindowsから来た人のために

macOSやWindowsで何年も過ごしてきたなら、指は、脳が覚えたことすら忘れてしまったようなことを百も知っている。この章はその翻訳レイヤーだ。その直感がOmarchyではどこへ行くのかを示す。機能そのものは他の場所で詳しく扱っている。ここでは地図だけを示す。

### Superがすべての中心だ

CmdやWindowsキーの周りに築き上げてきた筋肉の記憶はすべて、1つのキーに引き継がれる。Superだ。PCキーボードのWindowsキーのことであり、Omarchyのほぼすべてのホットキーの起点になる。

SpotlightやRaycastやスタートメニューを開こうとする反射は、`Super + Space`になる。これでOmarchyメニューが開く。アプリの起動、設定の変更、ソフトウェアのインストール、画面のキャプチャ、ほぼ何でもできる。入力し始めれば絞り込める。`Super + Alt + Space`は、Launchpadのように、すべてのアプリを1つのグリッドに表示する。[ナビゲーション](04-navigation.md)を参照。

### デスクトップアイコンはなく、ドックは邪魔にならない

デスクトップに並べるアイコンはなく、ドックはワークスペースにウィンドウが現れると隠れ、ポインターを画面の端、デフォルトでは下端に押し当てるまで出てこない（移動もできる。[ナビゲーション](04-navigation.md)を参照）。アプリはホットキー（ターミナルは`Super + Return`、ブラウザは`Super + Shift + Return`、割り当て済みのすべてのものの一覧は`Super + K`）か、メニューから起動する。常駐する唯一のUIは[トップバー](05-the-top-bar.md)で、以前メニューバー、システムトレイ、Notification Centerが担っていたことをカバーする。そしてその上のほぼすべてのウィジェットは、左クリック、右クリック、中クリックで何かをする。

### ウィンドウは自分で配置される

最大の発想の転換はここだ。ウィンドウをドラッグしたり、画面の半分にスナップしたりしない。ウィンドウを開けば画面いっぱいを占める。2つ目を開けば画面を分割する。別のウィンドウの下からウィンドウを掘り出すことは決してない。ウィンドウが重ならないからだ。

フローティングウィンドウが本当に必要なときは、`Super + T`でアクティブなウィンドウをタイリングから切り離す（そして戻す）。だが、まずタイリングに本当のチャンスを与えてみてほしい。それが全体の心臓部だ。[ナビゲーション](04-navigation.md)がその手順を案内する。

ワークスペースは馴染み深く感じるだろう。macOSのSpacesやWindowsの仮想デスクトップだ。ただし、実際に使うことになる点が違う。`Super + 1/2/3/4`で直にジャンプし、`Super + Shift + 1/2/3/4`でアクティブなウィンドウをそこへ送れるからだ。アニメーションの遅延はない。ただ即座にジャンプする。つまり、以前は複数モニターに慣れていた人でも、もう必要ないかもしれない。

### コピーとペーストはそのまま使える

MacではどこでもCmd + Cだった。WindowsではどこでもCtrl + Cだった。ターミナルを除いて。そこではプログラムが終了してしまう。Omarchyは`Super + C`、`Super + X`、`Super + V`を提供し、ターミナルを含め、どこでも使える。シェル用に別の反射を覚える必要はない。

Windows派の人へ。Win + Vのクリップボード履歴は`Super + Ctrl + V`にあり、テキストだけでなく画像も保持する。[統合クリップボードと履歴](08-unified-clipboard-history.md)を参照。

### 本当に違うものもある

多くの設定は、クリックして回るパネルではなく、編集するテキストファイルの中にある。原始的に聞こえるが、すべての調整を見て、次のマシンにコピーして、バージョン管理に入れられると気づくまでは、だ。_セットアップ_メニューは、まさに適切なファイルへ直行させ、終わったら再起動が必要なものを再起動する。

アップデートは1つのコマンド、_アップデート > Omarchy_を通して届く。これがOmarchy自体とシステム上のすべてのパッケージをアップデートし、まずスナップショットを取る。ランダムに煩わせるアプリごとのアップデーターはない。[アップデート](30-updates.md)を参照。

ソフトウェアは、ダウンロードしたインストーラーからではなく、パッケージマネージャーから来る。

そしてウィンドウを閉じると、アプリは実際に終了する。プログラムがウィンドウなしで動き続けるmacOSの宙ぶらりんな状態はない。`Super + W`、あるいは、到着したときの指の記憶がそうなら`Super + Q`は、消えたという意味だ。

### Macハードウェアでは

OmarchyはIntel Macで快適に動き、Omarchy for Apple SiliconではM1、M2、M3 Macでも動く。[Macサポート](44-mac-support.md)を参照。そしてキーボードは優しい。Omarchyは何もリマップせず、LinuxはCommandキーをSuperとして扱う。だからSuperはCmdが常あった場所にちょうど座っている。親指は引っ越しに気づかないだろう。

### 2週間与えてみてほしい

直感は思ったより速く移る。[ホットキー](07-hotkeys.md)の章を一度ざっと読み、割り当てで頭が真っ白になったらいつでも`Super + K`を押せばよい。すべてを表示してくれる。本当に覚えなければならないホットキーはそれだけだ。
