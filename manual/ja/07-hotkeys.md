# ホットキー

主なキーボードバインディングはすべて `Super + K` で確認できる（Tmux のバインディングは `Super + Alt + K`、Herdr のバインディングは `Super + Ctrl + K`）。

## ナビゲーション

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy メニュー（アプリとその他すべて）    |
| `Super + Alt + Space` | アプリグリッド |
| `Super + Escape` | システムメニュー（サスペンド、再起動など）  |
| `Super + Ctrl + L` | コンピュータをロック |
| `Super + W` or `Super + Q` | ウィンドウを閉じる             |
| `Ctrl + Alt + Del` | すべてのウィンドウを閉じる |
| `Super + T`               | ウィンドウのタイリング／フローティングを切り替える             |
| `Super + J` | ウィンドウ位置を切り替える（横／縦） |
| `Super + O`               | ウィンドウを sticky'n'floating へポップする切り替え |
| `Super + L`               | dwindle、scrolling、floating レイアウトを順に切り替える |
| `Super + Alt + L`         | レイアウトを逆順に切り替える |
| `Super + P`               | pseudo ウィンドウスタイルを切り替える（natural v stretch） |

| `Super + Tab` | フォーカス中のモニターの次のワークスペースへ移動 |

| `Super + Shift + Equal` | ウィンドウを下へ広げる |

| `Super + Ctrl + Minus/Equal` | 同じリサイズをより大きいステップで |
| `Super + Alt + Home` | ウィンドウ幅を保存 |
| `Super + Home` | 保存したウィンドウ幅を復元 |
| `Super + Left Mouse` | ウィンドウをドラッグして移動 |
| `Super + Right Mouse` | ウィンドウをリサイズ |

| `Super + Alt + G`               | ウィンドウをグループから出す      |
| `Super + Alt + Tab`               | グループ内のウィンドウを順に切り替える      |
| `Super + Alt + Shift + Tab`               | グループ内のウィンドウを逆順に切り替える      |
| `Super + Alt + Scroll Wheel` | グループ内のウィンドウを順に切り替える |

| `Alt + Tab` | アクティブなワークスペース上のウィンドウを順に切り替える |
| `Alt + Shift + Tab` | アクティブなワークスペース上のウィンドウを逆順に切り替える |
| `Ctrl + Alt + Tab`| モニター間でフォーカスを順に切り替える |
| `Ctrl + Alt + Shift + Tab`| モニター間でフォーカスを逆順に切り替える |

## ユニバーサルクリップボード

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + C`           | コピー    |
| `Super + X`           | 切り取り（ターミナルでは不可）    |
| `Super + V`           | 貼り付け    |
| `Super + Ctrl + V`           | クリップボードマネージャー    |

通常、Linux ではターミナルでコピー＆ペーストするには `Ctrl + Shift + C/V` が必要で、それ以外では `Ctrl + C/V` が必要だ。これらの Omarchy の統一クリップボードホットキーはどこでも使える。

## キャプチャ

| Hotkey              | Function                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | スクリーンショット                      |
| `Super + Ctrl + Alt + C`            | スクリーンショット（同じショット。Print Screen キーのないキーボード向け） |
| `Super + Ctrl + C` | キャプチャメニュー |
| `Alt + Print Screen`            | 画面録画                     |
| `Super + Print Screen` | カラーピッカー |
| `Super + Ctrl + Print Screen` | テキストを抽出してクリップボードへ |
| `Super + Alt + [` | 録画中にウェブカメラオーバーレイを小さくする |
| `Super + Alt + ]` | 録画中にウェブカメラオーバーレイを大きくする |
| `Alt + Shift + L` | webapp または Chromium から現在の URL をコピー |
| `Alt + Shift + D` | 現在のページの動画を `~/Videos` にダウンロード |
| `Super + Ctrl + X` | 音声入力を開始／停止（_Setup > Defaults > Dictation_ が必要） |
| `Right Alt` / `F9` | プッシュトゥトーク音声入力（Voxtype または Superwhisper が必要） |

画面録画では、このホットキーを押すとまずどの音声を使うか聞かれ、それから録画が始まる。もう一度押すと停止する。詳細は[スクリーンショットと録画](12-screenshots-recording.md)を見ること。

すべてのキャプチャオプションは、Omarchy メニュー（`Super + Space`）の _Trigger > Capture_ からも使える。

## Tmux

プレフィックスキーは `Ctrl + Space` だ（`Ctrl + B` も使える）。これらのバインディングは `~/.config/tmux/tmux.conf` で変更できる。

### ペイン

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + v` | 隣にペインを分割（縦） |
| `Prefix + h` | 下にペインを分割（横） |
| `Prefix + x` | ペインを終了 |
| `Prefix + z` | ペインのズームを切り替える（全画面） |
| `Alt + Enter` | 下にペインを分割（プレフィックスなし） |
| `Alt + Shift + Enter` | 隣にペインを分割（プレフィックスなし） |
| `Alt + Escape` | ペインを終了（プレフィックスなし） |
| `Ctrl + Alt + Arrows` | ペイン間を移動 |
| `Ctrl + Alt + Shift + Arrows` | ペインをリサイズ |

### ウィンドウ

| Hotkey                  | Function              |
| ----------------------- | --------------------- |

| `Prefix + k` | ウィンドウを終了 |

| `Alt + Arrow Left/Right` | ウィンドウ間を移動 |
| `Alt + Shift + Arrow Left/Right` | ウィンドウを左／右へ移動 |

### セッション

### Tmux レイアウト関数

これらの関数は Tmux セッション内で実行しなければならない。
