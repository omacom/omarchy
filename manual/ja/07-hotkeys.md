# ホットキー

主要なキーボードバインディングはすべて `Super + K` で確認できます（Tmux のバインディングは `Super + Alt + K`、Herdr のバインディングは `Super + Ctrl + K`）。

## ナビゲーション

| ホットキー | 機能 |
| ----------------------- | --------------------- |
| `Super + Space` | Omarchy メニュー（アプリとその他すべて） |
| `Super + Alt + Space` | アプリグリッド |
| `Super + Escape` | システムメニュー（サスペンド、再起動など） |
| `Super + Ctrl + L` | コンピュータをロック |
| `Super + W` または `Super + Q` | ウィンドウを閉じる |
| `Ctrl + Alt + Del` | すべてのウィンドウを閉じる |
| `Super + T` | ウィンドウをタイリング/フローティングで切り替え |
| `Super + J` | ウィンドウの位置を切り替え（水平/垂直） |
| `Super + O` | ウィンドウをスティッキー＆フローティングとして切り出す切り替え |
| `Super + L` | dwindle、scrolling、floating レイアウトを順に切り替え |
| `Super + Alt + L` | レイアウトを逆順に切り替え |
| `Super + P` | 疑似ウィンドウスタイルを切り替え（natural と stretch） |
| `Super + F` | フルスクリーンにする |
| `Super + Alt + F` | 全幅にする |
| `Super + Ctrl + F` | ウィンドウ内でフルスクリーンにする |
| `Super + 1/2/3/4` | フォーカス中のモニターの特定のワークスペースへ移動 |
| `Super + Tab` | フォーカス中のモニターの次のワークスペースへ移動 |
| `Super + Shift + Tab` | フォーカス中のモニターの前のワークスペースへ移動 |
| `Super + Ctrl + Tab` | フォーカス中のモニターの以前のワークスペースへ移動 |
| `Super + Shift + 1/2/3/4` | ウィンドウをフォーカス中のモニターのワークスペースへ移動 |
| `Super + Shift + Alt + 1/2/3/4` | ウィンドウをフォーカス中のモニターのワークスペースへ移動（追随しない） |
| `Super + S` | フルスクラッチパッドを切り替え |
| `Super + Alt + S` | ウィンドウをフルスクラッチパッドへ移動 |
| `Super + Grave` | Quake コンソールを切り替え |
| `Super + Shift + Grave` | ウィンドウを Quake コンソールへ移動 |
| `Super + Shift + Ctrl + Arrows` | ウィンドウをその方向のモニターへ移動 |
| `Super + Shift + Alt + Arrows` | ワークスペースをその方向のモニターへ移動 |
| `Super + Arrow` | 矢印の方向のウィンドウへフォーカスを移動し、画面端ではその側のモニターへ横断する |
| `Super + Shift + Arrow` | 矢印の方向の別のウィンドウと入れ替え、その側のモニター上のウィンドウも含む |
| `Super + Minus` | ウィンドウを左へ拡大 |
| `Super + Equal` | ウィンドウを左へ縮小 |
| `Super + Shift + Minus` | ウィンドウを上へ縮小 |
| `Super + Shift + Equal` | ウィンドウを下へ拡大 |
| `Super + Alt + Minus/Equal` | より小さいステップで同じリサイズ |
| `Super + Ctrl + Minus/Equal` | より大きいステップで同じリサイズ |
| `Super + Alt + Home` | ウィンドウの幅を保存 |
| `Super + Home` | 保存したウィンドウの幅を復元 |
| `Super + Left Mouse` | ウィンドウをドラッグして移動 |
| `Super + Right Mouse` | ウィンドウをリサイズ |
| `Super + Scroll Wheel` | フォーカス中のモニターのワークスペースをスクロール |
| `Super + G` | ウィンドウのグループ化を切り替え |
| `Super + Alt + G` | ウィンドウをグループ化から外す |
| `Super + Alt + Tab` | グループ内のウィンドウを順に切り替え |
| `Super + Alt + Shift + Tab` | グループ内のウィンドウを逆順に切り替え |
| `Super + Alt + Scroll Wheel` | グループ内のウィンドウを順に切り替え |
| `Super + Alt + 1/2/3/4/5` | グループ内の特定のウィンドウへ移動 |
| `Super + Alt + Arrow` | ウィンドウを矢印の方向のグループへ移動し、その側のモニター上のウィンドウも含む |
| `Super + Ctrl + Left/Right` | タイリンググループ内のウィンドウ間を移動 |
| `Super + Ctrl + Z` | 画面をズームイン（繰り返すとさらにズーム） |
| `Super + Ctrl + Alt + Z` | 画面を完全にズームアウト |
| `Super + /` | モニターのスケーリングオプションを順に進む |
| `Super + Alt + /` | モニターのスケーリングオプションを逆に進む |
| `Alt + Tab` | アクティブなワークスペースのウィンドウを順に切り替え |
| `Alt + Shift + Tab` | アクティブなワークスペースのウィンドウを逆順に切り替え |
| `Ctrl + Alt + Tab` | モニター間でフォーカスを順に切り替え |
| `Ctrl + Alt + Shift + Tab` | モニター間でフォーカスを逆順に切り替え |

## ユニバーサルクリップボード

| ホットキー | 機能 |
| ----------------------- | --------------------- |
| `Super + C` | コピー |
| `Super + X` | 切り取り（ターミナルでは不可） |
| `Super + V` | 貼り付け |
| `Super + Ctrl + V` | クリップボードマネージャー |

通常 Linux では、ターミナルでコピー＆ペーストするには `Ctrl + Shift + C/V` が必要で、それ以外では `Ctrl + C/V` を使います。これらの Omarchy の統合クリップボード用ホットキーは、どこでも使えます。

## キャプチャ

| ホットキー | 機能 |
| ------------------- | ------------------------------ |
| `Print Screen` | スクリーンショット |
| `Super + Ctrl + Alt + C` | スクリーンショット（Print Screen キーがないキーボード向けの同じ撮影） |
| `Super + Ctrl + C` | キャプチャメニュー |
| `Alt + Print Screen` | 画面録画 |
| `Super + Print Screen` | カラーピッカー |
| `Super + Ctrl + Print Screen` | テキストを抽出してクリップボードへ |
| `Super + Alt + [` | 録画中にウェブカムオーバーレイを小さくする |
| `Super + Alt + ]` | 録画中にウェブカムオーバーレイを大きくする |
| `Alt + Shift + L` | ウェブアプリまたは Chromium から現在の URL をコピー |
| `Alt + Shift + D` | 現在のページの動画を `~/Videos` へダウンロード |
| `Super + Ctrl + X` | ディクテーションを開始/停止（_セットアップ > デフォルト > ディクテーション_ が必要） |
| `Right Alt` / `F9` | プッシュトゥトークのディクテーション（Voxtype または Superwhisper が必要） |

画面録画では、ホットキーを押すとまず使用する音声を尋ねられ、次に録画が始まります。もう一度押すと停止します。詳細は [スクリーンショットと録画](12-screenshots-recording.md) を参照してください。

すべてのキャプチャオプションは、Omarchy メニュー（`Super + Space`）の _トリガー > キャプチャ_ からもアクセスできます。

## 通知

| ホットキー | 機能 |
| ----------------------- | --------------------- |
| `Super + ,` | 最新の通知に対してアクションする：開く、その唯一のボタンを押す、選択肢から選ぶ、または選択肢がない場合は閉じる |
| `Super + Shift + ,` | すべての通知を閉じる |
| `Super + Ctrl + ,` | キーボードで通知を操作する |
| `Super + Alt + ,` | 最新の通知を閉じる |
| `Super + Shift + Alt + ,` | 通知履歴を開く |
| `Super + Ctrl + Alt + ,` | 通知の消音を切り替え |

## Tmux

プレフィックスキーは `Ctrl + Space` です（`Ctrl + B` も使えます）。これらのバインディングは `~/.config/tmux/tmux.conf` で変更できます。

### ペイン

| ホットキー | 機能 |
| ----------------------- | --------------------- |
| `Prefix + v` | 隣にペインを分割（垂直） |
| `Prefix + h` | 下にペインを分割（水平） |
| `Prefix + x` | ペインを終了 |
| `Prefix + z` | ペインのズームを切り替え（フルスクリーン） |
| `Alt + Enter` | 下にペインを分割（プレフィックスなし） |
| `Alt + Shift + Enter` | 隣にペインを分割（プレフィックスなし） |
| `Alt + Escape` | ペインを終了（プレフィックスなし） |
| `Ctrl + Alt + Arrows` | ペイン間を移動 |
| `Ctrl + Alt + Shift + Arrows` | ペインをリサイズ |

### ウィンドウ

| ホットキー | 機能 |
| ----------------------- | --------------------- |
| `Prefix + c` | 新しいウィンドウ |
| `Prefix + k` | ウィンドウを終了 |
| `Prefix + r` | ウィンドウの名前を変更 |
| `Alt + 1-9` | 特定のウィンドウへ移動 |
| `Alt + Arrow Left/Right` | ウィンドウ間を移動 |
| `Alt + Shift + Arrow Left/Right` | ウィンドウを左/右へ移動 |

### セッション

| ホットキー | 機能 |
| ----------------------- | --------------------- |
| `Prefix + C` | 新しいセッション |
| `Prefix + K` | セッションを終了 |
| `Prefix + R` | セッションの名前を変更 |
| `Prefix + N` | 次のセッション |
| `Prefix + P` | 前のセッション |
| `Alt + Arrow Up/Down` | セッション間を移動 |
| `Prefix + s` | セッションを一覧表示 |
| `Prefix + d` | セッションからデタッチ |

### コピーモード（vi スタイル）

| ホットキー | 機能 |
| ----------------------- | --------------------- |
| `Prefix + [` | コピーモードに入る |
| `v` | 選択を開始（コピーモード内） |
| `y` | 選択をコピー（コピーモード内） |

### 一般

| ホットキー | 機能 |
| ----------------------- | --------------------- |
| `Prefix + q` | 設定を再読み込み |
| `Prefix + ?` | Tmux のキーバインディングを表示 |
| `Prefix + :` | コマンドプロンプト |

### Tmux レイアウト関数

これらの関数は Tmux セッション内で実行する必要があります。

| コマンド | 機能 |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | エディター、AI、ターミナルで開発レイアウトを作成 |
| `tdlm <ai> [<second_ai>]` | サブディレクトリごとに開発レイアウトを作成 |
| `tsl <count> <command>` | マルチペインの swarm レイアウトを作成 |
