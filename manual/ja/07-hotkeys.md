# ホットキー

主なキーバインドはすべて `Super + K` で確認できます（Tmux のバインドは `Super + Alt + K`、Herdr のバインドは `Super + Ctrl + K`）。

## 移動

| ホットキー                  | 機能              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy メニュー（アプリとその他すべて）    |
| `Super + Alt + Space` | アプリグリッド |
| `Super + Escape` | システムメニュー（サスペンド、再起動など）  |
| `Super + Ctrl + L` | コンピューターをロック |
| `Super + W` または `Super + Q` | ウィンドウを閉じる             |
| `Ctrl + Alt + Del` | すべてのウィンドウを閉じる |
| `Super + T`               | ウィンドウをタイリング/フローティング間で切り替える             |
| `Super + J` | ウィンドウ位置を切り替える（横/縦） |
| `Super + O`               | ウィンドウをスティッキー＆フローティングにポップする切り替え |
| `Super + L`               | dwindle、scrolling、floating レイアウトを順に切り替える |
| `Super + Alt + L`         | レイアウトを逆順に切り替える |
| `Super + P`               | 疑似ウィンドウスタイルを切り替える（自然な比率とストレッチ） |
| `Super + F`                 | 全画面              |
| `Super + Alt + F`                 | 全幅              |
| `Super + Ctrl + F`                 | ウィンドウ内で全画面              |
| `Super + 1/2/3/4`         | 特定のワークスペースへジャンプ     |
| `Super + Tab` | 次のワークスペースへジャンプ |
| `Super + Shift + Tab` | 前のワークスペースへジャンプ |
| `Super + Ctrl + Tab` | 以前のワークスペースへジャンプ |
| `Super + Shift + 1/2/3/4` | ウィンドウをワークスペースへ移動 |
| `Super + Shift + Alt + 1/2/3/4` | 追従せずにウィンドウをワークスペースへ移動 |
| `Super + S` / `Super + Grave` | スクラッチパッドを切り替える |
| `Super + Alt + S` / `Super + Shift + Grave` | ウィンドウをスクラッチパッドへ移動 |
| `Super + Shift + Alt + Arrows` | ワークスペースを方向モニターへ移動 |
| `Super + Arrow`  | 矢印方向のウィンドウへフォーカスを移動              |
| `Super + Shift + Arrow`  | 矢印方向の別のウィンドウと入れ替える     |
| `Super + Minus` | ウィンドウを左へ拡大 |
| `Super + Equal` | ウィンドウを左へ縮小 |
| `Super + Shift + Minus` | ウィンドウを上へ縮小 |
| `Super + Shift + Equal` | ウィンドウを下へ拡大 |
| `Super + Alt + Minus/Equal` | 同じリサイズを小さいステップで |
| `Super + Ctrl + Minus/Equal` | 同じリサイズを大きいステップで |
| `Super + Alt + Home` | ウィンドウ幅を保存 |
| `Super + Home` | 保存したウィンドウ幅を復元 |
| `Super + Left Mouse` | ウィンドウをドラッグ |
| `Super + Right Mouse` | ウィンドウをリサイズ |
| `Super + Scroll Wheel` | ワークスペース間をスクロール |
| `Super + G`               | ウィンドウのグループ化を切り替える      |
| `Super + Alt + G`               | ウィンドウをグループから出す      |
| `Super + Alt + Tab`               | グループ内のウィンドウを順に切り替える      |
| `Super + Alt + Shift + Tab`               | グループ内のウィンドウを逆順に切り替える      |
| `Super + Alt + 1/2/3/4/5`               | グループ内の特定のウィンドウへジャンプ      |
| `Super + Alt + Arrow`  | 矢印方向にウィンドウをグループへ移動  |
| `Super + Ctrl + Left/Right`  | タイルグループ内のウィンドウ間を移動 |
| `Super + Ctrl + Z` | 画面をズームイン（繰り返すとさらにズーム） |
| `Super + Ctrl + Alt + Z` | 画面から完全にズームアウト |
| `Super + /` | モニタースケーリングの選択肢を前に進める |
| `Super + Alt + /` | モニタースケーリングの選択肢を後ろに戻す |
| `Alt + Tab` | アクティブなワークスペースのウィンドウを前に順に切り替える |
| `Alt + Shift + Tab` | アクティブなワークスペースのウィンドウを後ろに順に切り替える |
| `Ctrl + Alt + Tab`| モニター間を前に順にフォーカスを切り替える |
| `Ctrl + Alt + Shift + Tab`| モニター間を後ろに順にフォーカスを切り替える |

## 統合クリップボード

| ホットキー                  | 機能              |
| ----------------------- | --------------------- |
| `Super + C`           | コピー    |
| `Super + X`           | 切り取り（ターミナルでは不可）    |
| `Super + V`           | 貼り付け    |
| `Super + Ctrl + V`           | クリップボードマネージャー    |

Linux では通常、ターミナルでコピー＆ペーストするには `Ctrl + Shift + C/V` が、その他の場所では `Ctrl + C/V` が必要です。これらの Omarchy 統合クリップボードホットキーはどこでも動きます。

## キャプチャ

| ホットキー              | 機能                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | キャプチャメニュー（PrintScr ボタンなしのキーボード用） |
| `Print Screen`            | スクリーンショット                      |
| `Alt + Print Screen`            | 画面録画                     |
| `Super + Print Screen` | カラーピッカー |
| `Super + Ctrl + Print Screen` | クリップボードへテキスト抽出 |
| `Super + Alt + [` | 録画中に Web カメラオーバーレイを小さく |
| `Super + Alt + ]` | 録画中に Web カメラオーバーレイを大きく |
| `Alt + Shift + L` | Web アプリまたは Chromium から現在の URL をコピー |
| `Alt + Shift + D` | 現在のページの動画を `~/Videos` にダウンロード |
| `Super + Ctrl + X` | ディクテーションを開始/停止（_設定 > デフォルト > ディクテーション_ が必要） |
| `Right Alt` / `F9` | プッシュ・トゥ・トーク ディクテーション（Voxtype または Superwhisper が必要） |

画面録画では、ホットキーがまずどのオーディオが欲しいか聞いてから、録画を開始します。もう一度押すと停止します。詳しくは [スクリーンショットと録画](12-screenshots-recording.md) を参照してください。

すべてのキャプチャオプションは Omarchy メニュー（`Super + Space`）の _実行 > キャプチャ_ からもアクセスできます。

## スタイル

| ホットキー                  | 機能              |
| ----------------------- | --------------------- |
| `Super + Ctrl + Shift + Space` | 新しいテーマを選ぶ  |
| `Super + Ctrl + Space` | テーマの背景を選ぶ |

すべてのスタイルオプションは Omarchy メニュー（`Super + Space`）の _スタイル_ からもアクセスできます。

## Tmux

プレフィックスキーは `Ctrl + Space` です（`Ctrl + B` も動作します）。これらのバインドは `~/.config/tmux/tmux.conf` で変更できます。

### ペイン

| ホットキー                  | 機能              |
| ----------------------- | --------------------- |
| `Prefix + v` | 横にペインを分割（垂直） |
| `Prefix + h` | 下にペインを分割（水平） |
| `Prefix + x` | ペインを終了 |
| `Prefix + z` | ペインズームを切り替える（全画面） |
| `Alt + Enter` | 下にペインを分割（プレフィックスなし） |
| `Alt + Shift + Enter` | 横にペインを分割（プレフィックスなし） |
| `Alt + Escape` | ペインを終了（プレフィックスなし） |
| `Ctrl + Alt + Arrows` | ペイン間を移動 |
| `Ctrl + Alt + Shift + Arrows` | ペインをリサイズ |

### ウィンドウ

| ホットキー                  | 機能              |
| ----------------------- | --------------------- |
| `Prefix + c` | 新しいウィンドウ |
| `Prefix + k` | ウィンドウを終了 |
| `Prefix + r` | ウィンドウ名を変更 |
| `Alt + 1-9` | 特定のウィンドウへ移動 |
| `Alt + Arrow Left/Right` | ウィンドウ間を移動 |
| `Alt + Shift + Arrow Left/Right` | ウィンドウを左/右へ移動 |

### セッション

| ホットキー                  | 機能              |
| ----------------------- | --------------------- |
| `Prefix + C` | 新しいセッション |
| `Prefix + K` | セッションを終了 |
| `Prefix + R` | セッション名を変更 |
| `Prefix + N` | 次のセッション |
| `Prefix + P` | 前のセッション |
| `Alt + Arrow Up/Down` | セッション間を移動 |
| `Prefix + s` | セッション一覧 |
| `Prefix + d` | セッションからデタッチ |

### コピーモード（vi スタイル）

| ホットキー                  | 機能              |
| ----------------------- | --------------------- |
| `Prefix + [` | コピーモードに入る |
| `v` | 選択を開始（コピーモード内） |
| `y` | 選択をコピー（コピーモード内） |

### 一般

| ホットキー                  | 機能              |
| ----------------------- | --------------------- |
| `Prefix + q` | 設定をリロード |
| `Prefix + ?` | Tmux キーバインドを表示 |
| `Prefix + :` | コマンドプロンプト |

### Tmux レイアウト関数

これらの関数は Tmux セッション内で実行しなければなりません。

| コマンド | 機能 |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | エディタ、AI、ターミナルで開発レイアウトを作成 |
| `tdlm <ai> [<second_ai>]` | サブディレクトリごとに開発レイアウトを作成 |
| `tsl <count> <command>` | 複数ペインの swarm レイアウトを作成 |
