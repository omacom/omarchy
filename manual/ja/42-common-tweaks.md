# よくある調整

これはOmarchyの設定によく行われる調整のコレクションです。システム更新の際に、特定の設定を元の状態に戻す必要がある場合があることに注意してください。その場合でも変更は失われませんが、同じディレクトリの`.bak`ファイルに入れられます。

何かを台無しにしてしまった場合は、Omarchyメニューの_更新 > 設定_から個別の設定を元の設定に戻せます。本当にすべてを台無しにしてしまった場合は、`omarchy-reinstall`ですべての設定をリセットできます。

### すべてのトレイアイコンを常時表示する

デフォルトでは、Dropboxや1password、Steamなどのトレイアイコンはトレイ展開矢印の後ろに隠れており、ホバーすると表示されます。常時露出させたい場合は、展開矢印を右クリックしてトレイアイコンマネージャーを開き、表示し続けたいアイコンを固定してください（決して見たくないものを非表示にすることもできます）。

### ウィンドウの角を丸くする

Omarchyのデフォルトデザインは角が四角いものですが、少し柔らかくしたい場合は、`~/.config/hypr/looknfeel.lua`を変更してroundingのコメントアウトを外してください。

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### ウィンドウの間隔を取り除く

ノートPCのディスプレイでは、ウィンドウの間隔にピクセルを使いたくない人もいます（トップバーも同様で、`Super + Shift + Space`でオフにできます）。すべての間隔と境界線は`Super + Shift + Backspace`でオフに切り替えられます。恒久的に取り除くには、`~/.config/hypr/looknfeel.lua`のこのセクションのコメントを外してください。

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
