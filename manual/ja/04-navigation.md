# ナビゲーション

Omarchyではすべてがキーボードで完結する——_すべてだ！_ システムが初めて起動したとき、文字通りマウスだけでは何もできない。しかし`Super + Space`を押せばOmarchyメニューが表示され、ここからほぼ何でもできる。

だがOmarchyメニューは、そもそも普段の主な操作方法として意図されたものではない。もっと速くできる！ 最も重要なアプリケーションはすべて、それぞれ個別のホットキーに直接割り当てられている。ターミナルは`Super + Return`で、ブラウザは`Super + Shift + Return`で起動する。一方を起動した直後にもう一方も起動してみれば、Hyprlandのタイリングの魔法が目の前で繰り広げられるのがわかるはずだ：

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

次に`Super + J`を押すと、横並びではなく上下に積み重なる：

 ![navigation-stacked](images/navigation-stacked.webp)

もう一度`Super + J`を押すと、横並びの位置に戻る。続いて、ブラウザにフォーカスした状態で`Super + Shift + Arrow Right`を押してウィンドウを入れ替えてみよう。

次に`Super + Shift + T`を押してActivityモニターを起動してみよう。これはフローティングウィンドウとして表示される。`Super + T`でタイリング表示にでき、もう一度押すと再びフローティングに戻せる。今度は`Super + Shift + F`を押してファイルマネージャーを開こう。きれいな4分割レイアウトが完成する：

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

アクティブにしたいウィンドウへの移動は`Super + Arrow`で行う。これでフォーカスが切り替わり、カーソルが新しいアプリケーションの中央に移動する。画面の端まで来たら、その方向にあるモニターへそのまま移動する。

`Super + Shift + 2`を押すと、現在フォーカスされているアプリケーションが2番目のワークスペースに移動する。`Super + Shift + 1`で元に戻る。（そして`Super + Shift + Alt + 2`では、現在フォーカスされているアプリケーションを2番目のワークスペースに移動させるが、そちらには切り替わらない）。

モニターが複数ある場合、各モニターが独自の1から10までのワークスペースを持つ。`Super + 2`で現在のモニターの2番目のワークスペースに移動し、各モニターのトップバーにはそのモニター自身のワークスペースと、現在表示中のものが表示される。`Super + Tab`で現在のモニター上のワークスペースを順に切り替える。`Super + Shift + Ctrl + Arrows`で、フォーカス中のウィンドウをその方向のモニターへ、そのモニターが表示中のワークスペース上に移動させ、`Super + Shift + Alt + Arrows`で、フォーカス中のワークスペース自体をその方向のモニターへ移動させ、移動先で空いていれば同じ番号を引き継ぐ。モニターを取り外しても、そのワークスペースは保持される：別の画面のワークスペースに合流し、既存のものの後ろに番号が付けられ、モニターが戻ってきたら元の番号に戻る。

`Super`を押しながらマウスでウィンドウをクリックすると、その配置場所を変更できる。`Super`を押しながらマウスの右ボタンを使うと、ウィンドウを自由にリサイズできる。

ウィンドウは`Super + W`または`Super + Q`で閉じ（すべてのウィンドウは`Ctrl + Alt + Delete`で閉じる）。

`Super + F`で全画面表示にもでき、`Super + Alt + F`でトップバーを残したまま全幅表示にしたり、`Super + Ctrl + F`でウィンドウ内全画面表示にもできる（YouTubeに最適だ！）。

### Dwindleレイアウトとスクロールレイアウト

Omarchyのデフォルトレイアウトはdwindleと呼ばれる。これは、1つのワークスペース上で開いたすべてのウィンドウを、たとえ縮小してでも、常に表示し続ける。

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

一方で、ワークスペースをスクロールレイアウトに変更することもできる。このレイアウトではウィンドウが横に並び、ディスプレイの見える範囲を超えて続いていく。1つのワークスペースをこのレイアウトにするには`Super + L`を使う。

もう一度`Super + L`を押すと、そのワークスペースはフローティングになり、ウィンドウが自由に重なり合い、自分で配置できるようになる。3回目に押すとdwindleに戻る。`Super + Alt + L`では逆の順序で切り替わる。もともとフローティングしているウィンドウ——`Super + T`で切り離したものや、常にフローティングで開くアプリ——は、ワークスペースがタイリングに戻ってもフローティングのままになる。トップバーには現在のワークスペースにそのレイアウトがマークで示される：dwindleは四角、スクロールは円、フローティングは三角だ。そのマークをクリックしてもレイアウトを切り替えられる。

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

この選択はワークスペースごとに決まり、保持される。だからワークスペース1はブラウジング用にdwindleのままにし、ワークスペース2はコード用にスクロールにしておけば、再起動後もその状態で戻ってくる。

スクロールレイアウトをデフォルトとして使いたい場合は、`~/.config/hypr/looknfeel.lua`で設定できる：

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### フローティングワークスペース

フローティングワークスペースは従来のデスクトップのように動作する：ウィンドウが重なり合い、自分で移動やサイズ変更を行う。各ウィンドウにはテーマの色でタイトルバーが付き、最小化、最大化、閉じるボタンが表示される。`Super + M`でもフォーカス中のウィンドウを最小化できる。最小化されたウィンドウはドックで待機する；そのアプリをクリックすれば戻ってくる。ウィンドウをクリックすれば前面に出る。どの端や角からでもリサイズできる。タイトルバーをダブルクリックすると、トップバーを表示したままウィンドウを最大化でき、もう一度ダブルクリックすると元のサイズに戻る。

フローティングワークスペースにはドックも表示される。そこにはピン留めしたアプリ、実行中のすべて、そしてアプリボタンの奥にあるすべてのアプリのグリッドがあり、これは`Super + Alt + Space`やOmarchyメニューの_Apps_からも開ける。グリッド上のアプリを右クリックするか、`Delete`を押すとアンインストールできる。アプリをクリックすると開くか、そのウィンドウが前面に出る；もう一度クリックするとそのウィンドウを順に切り替える。中クリックで新しいウィンドウを開く。アイコンをドックに沿ってドラッグすると移動できる；実行中のアプリを他のアプリの間にドラッグすると、そこに留まるようになる。右クリックでアプリをドックに保持したり、ドックから外したり、終了したりできる。ドックは全画面ウィンドウの邪魔にならないよう退く。アプリボタンを右クリックすると、ドックを別の端に移動させたり、ポインターがその端に到達するまで隠したりできる。その位置は_Appearance > Dock > Dock Position_からも設定でき、`omarchy dock position left`と`omarchy dock autohide on`でターミナルから両方を設定できる。ドックに保持したアプリは、実行中でない間は色あせて表示される。

新しいワークスペースと、`Super + L`で独自のレイアウトを与えていないワークスペースは、デフォルトレイアウトを使用する。デフォルトを変更すると、ウィンドウのないすべてのワークスペースがそれにリセットされる一方、ウィンドウのあるワークスペースは現在のレイアウトを維持する。ドックに最小化されたウィンドウも、それが離れたワークスペース上のウィンドウとして数えられる。_Appearance > Workspace Layout_でTiling、Scrolling、Floatingから選択する。`omarchy-hyprland-workspace-layout-default scrolling`でターミナルから設定できる。

### ウィンドウのグループ化

ウィンドウは`Super + G`でグループ化できる。グループに入ったら、その状態がアクティブな間に起動したすべてのウィンドウがそのグループに属するようになる。これらのグループ化されたウィンドウ間は、`Super + Ctrl + Arrow Left/Right`で移動でき、`Super + Alt + 1/2/3/4`で順序どおりにグループ化されたウィンドウへ直接移動できる。

ウィンドウをグループから外すには`Super + Alt + G`を使い、グループ全体を解体するにはもう一度`Super + G`を押す。最後に、グループ外のウィンドウを`Super + Alt + Arrows`でグループ内に移動させることもできる。

### ウィンドウのポップアウト

ウィンドウは`Super + O`でワークスペースの割り当てから切り離せる。そうするとフローティングウィンドウとしてピン留めされ、どのワークスペースに移動してもついてくる。動画プレイヤーなどに最適だ。

 ![navigation-popped-window](images/navigation-popped-window.webp)

### スクラッチパッドワークスペース

現在いるワークスペースの上に重なる、フルサイズの特別なスクラッチパッドワークスペースがある。その上にあるものには`Super + S`でアクセスし、ウィンドウをそこに置くには`Super + Alt + S`を使う。

現在のワークスペースを離れることなく、コントロール類やターミナルと素早くやり取りしたいときにうまく機能する。

### Quakeコンソール

最後に、現在いるワークスペースの上にドロップダウンする、半分の高さのQuakeコンソールがある。`Super + Grave`で切り替え、ウィンドウをそこに置くには`Super + Shift + Grave`を使う。

デフォルトのエージェントがすぐに使える状態で開く。コンソールにウィンドウが1つだけの間は、画面いっぱいに広がるのではなく、中央に配置されたパネルとしてドロップダウンする。そこに2つ目のアプリを置くと全幅に戻り、2つが横並びに収まる余地ができる。

スクラッチパッドやコンソールからウィンドウを外へ移動させるには、`Super + Shift + 1`のような操作で別のワークスペースへ直接送る。

### 慣れるまで少し時間がかかる！

こうしてデスクトップを移動するやり方に慣れるには少し時間がかかるが、一度慣れてしまえば、従来のマウス主導のデスクトップ体験に戻るのは難しくなるだろう！
