# ナビゲーション

Omarchy ではすべてがキーボードで起こる ― _全部だ！_ システムが初めて起動したときは、マウスだけでは文字通り何もできない。だが `Super + Space` を押せば Omarchy メニューが表示され、ここからほぼ何でもできる。

だが Omarchy メニューは、ほとんどの時間システムを操作する主な方法として意図されたものではない。もっと速くできる！最も重要なアプリケーションはすべて、個別のホットキーに直接割り当てられている。ターミナルは `Super + Return` で、ブラウザは `Super + Shift + Return` で起動する。続けて一つずつ試してみれば、Hyprland のタイリングの魔法が実際に動く様子がわかるだろう：

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

その後 `Super + J` を押すと、横並びではなく上下に重ねられる：

 ![navigation-stacked](images/navigation-stacked.webp)

`Super + J` をもう一度押すと、横並びの位置に戻る。次にブラウザにいる状態で `Super + Shift + Arrow Right` を試して、ウィンドウを入れ替えてみよう。

次に `Super + Shift + T` で Activity モニターを起動してみよう。フローティングウィンドウとして表示される。`Super + T` でタイリングできる（もう一度押すと再びフローティングになる）。次に `Super + Shift + F` を押してファイルマネージャーを開く。きれいな4分割のセットアップになる：

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

`Super + Arrow` でアクティブにしたいウィンドウ間を移動する。これでフォーカスが切り替わり、カーソルが新しいアプリケーションの中央へ移動する。画面の端では、その側にあるモニターへ続いていく。

`Super + Shift + 2` を押すと、現在フォーカスされているアプリケーションが2番目のワークスペースへ移動する。`Super + Shift + 1` で戻る。（そして `Super + Shift + Alt + 2` では、現在フォーカスされているアプリケーションを、そのワークスペースへ切り替えずに2番目のワークスペースへ移動できる）。

モニターが複数ある場合、各モニターは独自の1から10までのワークスペースを持つ。`Super + 2` は今いるモニターの2番目のワークスペースへ移動し、各モニターのトップバーにはそのモニター自身のワークスペースと、表示中のワークスペースが表示される。`Super + Tab` は今いるモニター上のワークスペースを順に切り替える。`Super + Shift + Ctrl + Arrows` は今いるウィンドウをその方向にあるモニターへ、そのモニターが表示しているワークスペース上に移動し、`Super + Shift + Alt + Arrows` は今いるワークスペースをその方向にあるモニターへ移動し、空いていれば同じ番号を引き継ぐ。モニターを取り外しても、そのモニターはワークスペースを保持する：それらは別の画面のワークスペースに加わり、既存のものの後ろに番号が付けられ、モニターが戻ると元の番号に戻る。

`Super` を押したままマウスでウィンドウをクリックすると、配置場所を並べ替えられる。`Super` を押したままマウスの右ボタンを使うと、ウィンドウを自由にリサイズできる。

ウィンドウは `Super + W` または `Super + Q` で閉じる（すべてのウィンドウは `Ctrl + Alt + Delete` で閉じる）。

`Super + F` で全画面にもでき、`Super + Alt + F` で（トップバーを残したまま）全幅にもでき、`Super + Ctrl + F` でウィンドウ内全画面にもできる（YouTube に最適だ！）。

### Dwindle とスクローリングレイアウト

Omarchy のデフォルトレイアウトは dwindle と呼ばれる。1つのワークスペース上に開いたすべてのウィンドウを、縮小しなければならない場合でも、常時表示し続ける。

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

だがワークスペースをスクローリングレイアウトに変更することも選べる。このレイアウトではウィンドウが横並びに並び、ディスプレイの見える端を超えて続く。単一のワークスペースは `Super + L` でこのレイアウトにできる。

`Super + L` をもう一度押すとワークスペースがフローティングになり、ウィンドウが自由に重なり、自分で配置できるようになり、3回目で dwindle に戻る。`Super + Alt + L` では逆の順序で切り替わる。もともとフローティングしているウィンドウ ― `Super + T` でポップアウトしたものや、常時フローティングで開くアプリ ― は、ワークスペースがタイリングに戻ってもフローティングのままになる。トップバーは、今いるワークスペースにそのレイアウトを示すマークを表示する：dwindle は四角形、スクローリングは円、フローティングは三角形だ。そのマークをクリックしてもレイアウトが切り替わり、ディスプレイキーがあるラップトップではそのキーでも切り替わる。

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

選択はワークスペースごとで、保持される。だからワークスペース1は閲覧用に dwindle にし、ワークスペース2はコード用にスクローリングにして、再起動後もその状態に戻せる。

スクローリングレイアウトをデフォルトとして使いたい場合は、`~/.config/hypr/looknfeel.lua` で設定できる：

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### フローティングワークスペース

フローティングワークスペースは従来のデスクトップのように動作する：ウィンドウが重なり、自分で移動してサイズを変更する。各ウィンドウにはテーマの色のタイトルバーが付き、最小化、最大化、閉じるボタンがある。`Super + M` でもフォーカスされたウィンドウを最小化できる。最小化されたウィンドウはドックで待機する；そのアプリをクリックすれば戻せる。ウィンドウをクリックすれば前面に出る。どの端や角からでもリサイズできる。タイトルバーをダブルクリックすると、トップバーを表示したままウィンドウを最大化でき、もう一度ダブルクリックすると元のサイズに戻る。Chrome やその他の Chromium ベースのブラウザ、Disks、Document Viewer はタイトルバーをスキップし、代わりに独自のヘッダーを使う；これらは `Super + Alt + F` で最大化でき、`Super + M` で最小化できる。

フローティングワークスペースではドックも表示され、ピン留めしたアプリ、実行中のすべて、そしてアプリボタンの後ろにあるすべてのアプリのグリッドがある。`Super + Alt + Space` でも、Omarchy メニューの _アプリ_ でもそのグリッドを開ける。グリッド上のアプリを右クリックするか、`Delete` を押すとアンインストールできる。アプリをクリックすればそれを開くか、そのウィンドウを前面に出せる；もう一度クリックすればそのウィンドウ間を順に切り替えられる。Files は今いるワークスペースからのウィンドウだけを戻し、それ以外では新しいウィンドウを開き、Terminal と Agent は常にもう一つ起動するが、最小化されたウィンドウがあればそちらが先に戻る。中クリックすると新しいウィンドウが開く。アイコンをドックに沿ってドラッグすると移動できる；実行中のアプリを他のアプリの間にドラッグすれば、そこに保持される。右クリックすればアプリをドックに保持するか、ドックから外すか、終了できる。ドックは全画面ウィンドウの邪魔にならない場所へ退く。アプリボタンを右クリックすれば、ドックを別の端へ移動したり、ポインターがその端に到達するまで隠したりできる。位置は _外観 > Dock > Dock の位置_ でも設定でき、`omarchy dock position left` と `omarchy dock autohide on` を使えばどちらもターミナルから設定できる。ドックに保持したアプリは、実行されていない間は淡く表示される。

新しいワークスペースと、`Super + L` で独自のレイアウトを与えていないワークスペースは、デフォルトレイアウトを使う。デフォルトを変更すると、ウィンドウのないすべてのワークスペースはそれにリセットされる一方、ウィンドウがあるワークスペースは現在のレイアウトを保持する。ドックに最小化されたウィンドウは、離れたワークスペース上のウィンドウとして引き続き数えられる。これは _外観 > ワークスペースレイアウト_ で選ぶ：タイリング、スクローリング、またはフローティング。`omarchy hyprland workspace layout default scrolling` を使えばターミナルから設定できる。

### ウィンドウのグループ化

ウィンドウは `Super + G` でグループ化できる。グループに入ると、それがアクティブな間に起動したすべてのウィンドウはそのグループに属する。これらのグループ化されたウィンドウ間は `Super + Ctrl + Arrow Left/Right` で移動できるし、`Super + Alt + 1/2/3/4` で順序どおりにグループ化されたウィンドウへ直接移動できる。

`Super + Alt + G` でウィンドウをグループから外したり、`Super + G` をもう一度押してグループ全体を解散したりできる。最後に、`Super + Alt + Arrows` でグループ外のウィンドウをグループ内へ移動できる。

### ウィンドウのポップ

ウィンドウは `Super + O` でワークスペースの割り当てからポップアウトできる。そうするとフローティングウィンドウとしてピン留めされ、どのワークスペースへ移動しても付いてくる。動画プレイヤーなどに最適だ。

 ![navigation-popped-window](images/navigation-popped-window.webp)

### スクラッチパッドワークスペース

現在いるワークスペースに重なる、特別なフルサイズのスクラッチパッドワークスペースがある。そこにあるものには `Super + S` でアクセスし、ウィンドウは `Super + Alt + S` でそこに配置する。

現在のワークスペースを離れることなく素早く操作したいコントロールやターミナルに適している。

### Quake コンソール

最後に、現在いるワークスペース上に降りてくる、半分の高さの Quake コンソールがある。切り替えは `Super + the key above Tab`（US レイアウトでは grave）で、ウィンドウの配置は `Super + Shift + the key above Tab` で行う。

初めて開いたときは、デフォルトのエージェントが起動し、まだ選んでいない場合はどれか選ぶよう求められる。コンソールにウィンドウが1つだけの間は、画面いっぱいに広がらず、中央に配置されたパネルとして降りてくる。2つ目のアプリを配置すると全幅に戻り、2つが横並びに座る余地ができる。

スクラッチパッドやコンソールからウィンドウを外すには、`Super + Shift + 1` のような操作で別のワークスペースへ直接送る。

### 慣れるまで少し時間がかかる！

このようにデスクトップを移動することに慣れるまで少し時間がかかるが、一度慣れてしまえば、従来のマウス主導のデスクトップ体験に戻るのは難しくなるだろう！
