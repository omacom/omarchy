# ナビゲーション

Omarchy での操作はすべてキーボードで行います — _すべてです！_ システムが初めて起動したときは、マウスだけでは文字通り何もできません。ですが `Super + Space` を押せば Omarchy Menu が表示され、そこからほぼ何でもできます。

しかし、Omarchy メニューは、ほとんどの場面でシステムを操作する主な方法として意図されたものでさえありません。それよりもっと速くできます！ 最も重要なアプリケーションはすべて、個別のホットキーに直接割り当てられています。ターミナルは `Super + Return` で起動し、ブラウザは `Super + Shift + Return` で起動します。一方を起動した直後にもう一方を試してみれば、Hyprland のタイリングの魔法が実際に動く様子がわかるでしょう：

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

次に `Super + J` を押すと、横並びではなく上下に積み重ねることができます：

 ![navigation-stacked](images/navigation-stacked.webp)

もう一度 `Super + J` を押すと、横並びの位置に戻ります。次に、ブラウザにいる状態で `Super + Shift + Arrow Right` を押して、ウィンドウを入れ替えてみてください。

次に `Super + Shift + T` を押して Activity モニターを起動してみてください。これはフローティングウィンドウとして表示され、ドラッグできるタイトルバーと、最小化、最大化、閉じるボタンが付いています。フローティングウィンドウには、どこにあっても必ず付きます。`Super + T` でタイリングできます（もう一度押すと再びフローティングになります）。次に `Super + Shift + F` を押してファイルマネージャーを開いてください。きれいな 4 分割の配置になります：

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

アクティブにしたいウィンドウ間の移動は `Super + Arrow` で行います。これでフォーカスが切り替わり、カーソルが新しいアプリケーションの中央に移動します。画面の端では、その方向にあるモニターへそのまま移ります。

`Super + Shift + 2` を押すと、現在フォーカスしているアプリケーションが 2 番目のワークスペースに移動します。`Super + Shift + 1` で戻ります。（また、`Super + Shift + Alt + 2` を押すと、現在フォーカスしているアプリケーションが 2 番目のワークスペースに移動しますが、そこへは切り替わりません）。

モニターが複数ある場合、各モニターにそれぞれ 1 から 10 までのワークスペースがあります。`Super + 2` は現在のモニターの 2 番目のワークスペースへ移動し、各モニターのトップバーにはそれぞれのワークスペースと現在表示しているものが表示されます。`Super + Tab` は現在のモニター上のワークスペースを順に切り替えます。`Super + Shift + Ctrl + Arrows` は現在のウィンドウをその方向にあるモニターへ、そのモニターが表示しているワークスペース上に移動し、`Super + Shift + Alt + Arrows` は現在のワークスペースをその方向にあるモニターへ移動させ、空いていれば同じ番号を引き継ぎます。モニターを取り外しても、そのワークスペースは保持されます。別の画面のワークスペースに加わり、既存のものの後に番号が付けられ、モニターが戻ると元の番号に戻ります。

`Super` を押しながらマウスでウィンドウをクリックすると、その配置を並べ替えることができます。`Super` を押しながらマウスの右ボタンを使うと、ウィンドウを自由にリサイズできます。

ウィンドウは `Super + W` または `Super + Q` で閉じます（すべてのウィンドウを閉じるには `Ctrl + Alt + Delete` です）。

`Super + F` で全画面表示にしたり、`Super + Alt + F` でトップバーを残したまま横幅いっぱいにしたり、`Super + Ctrl + F` でウィンドウ内全画面にしたりもできます（YouTube に最適です！）。

### Dwindle とスクロールレイアウト

Omarchy のデフォルトレイアウトは dwindle と呼ばれます。1 つのワークスペース上に開いたすべてのウィンドウを、縮小してでも常に見える状態に保ちます。

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

しかし、ワークスペースをスクロールレイアウトに切り替えることもできます。このレイアウトではウィンドウが横並びに配置され、ディスプレイの見える範囲を超えて続きます。1 つのワークスペースをこのレイアウトにするには `Super + L` を使います。

もう一度 `Super + L` を押すとワークスペースがフローティングになり、ウィンドウが自由に重なって自分で配置できるようになり、3 回目に押すと dwindle に戻ります。`Super + Alt + L` は逆の順序で切り替えます。もともとフローティングしているウィンドウ — `Super + T` で切り離したものや、常にフローティングで開くアプリ — は、ワークスペースがタイリングに戻ってもフローティングのままです。トップバーには現在のワークスペースにそのレイアウトがマークで表示されます。dwindle は四角、スクロールは丸、フローティングは三角です。そのマークをクリックしてもレイアウトが切り替わります。そのための表示キーがあるノートパソコンでは、そのキーでも切り替わります。

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

この選択はワークスペースごとに適用され、保持されます。つまり、ワークスペース 1 は閲覧用に dwindle、ワークスペース 2 はコード用にスクロールにしておけば、再起動後もその状態で戻ってきます。

スクロールレイアウトをデフォルトとして使いたい場合は、`~/.config/hypr/looknfeel.lua` で設定できます：

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### フローティングワークスペース

フローティングワークスペースは従来のデスクトップのように動作します。ウィンドウが重なり合い、自分で移動やサイズ変更を行います。各ウィンドウにはテーマの色のタイトルバーが付き、最小化、最大化、閉じるボタンがあります。`Super + M` でもフォーカスしたウィンドウを最小化できます。最小化したウィンドウはドックで待機します。そのアプリをクリックすれば戻ります。ウィンドウをクリックすると前面に出ます。どの端や角からでもリサイズできます。タイトルバーをダブルクリックするとトップバーを表示したままウィンドウが最大化され、もう一度ダブルクリックすると元のサイズに戻ります。Chrome やその他の Chromium ベースのブラウザ、Disks、Document Viewer はタイトルバーを省略し、代わりに独自のヘッダーを使います。`Super + Alt + F` で最大化し、`Super + M` で最小化します。

すべてのワークスペースにはドックがあり、ピン留めしたアプリ、実行中のすべてのもの、そしてアプリボタンの後ろにあるすべてのアプリのグリッドがあります。`Super + Alt + Space` と Omarchy メニューの _Apps_ でも開けます。グリッド上のアプリを右クリックするか、`Delete` を押すと、アンインストールできます。アプリをクリックすると開くか、そのウィンドウが前面に出ます。もう一度クリックするとそのウィンドウを順に切り替えます。Files は現在のワークスペースからのウィンドウだけを戻し、それ以外では新しいものを開きます。Terminal と Agent は常にもう 1 つ起動しますが、最小化したウィンドウがあればそちらが先に戻ります。中クリックで新しいウィンドウが開きます。アイコンをドックに沿ってドラッグすると移動できます。実行中のアプリを他のアプリの間にドラッグすると、そこに残ります。右クリックすると、アプリをドックに残したり、ドックから外したり、終了したりできます。ドックはワークスペースが空の間は表示されたままになり、ワークスペースにウィンドウができると、ポインターがその端に到達するまで隠れます。全画面ウィンドウがある場合は完全に隠れます。アプリボタンを画面の別の端へ向けてドラッグすると、ドックをそこへ移動できます。それを右クリックして _Position_ で端を選び、_Layout_ で _Appearance > Workspace Layout_ と同じようにデフォルトレイアウトを設定します。位置は _Appearance > Dock > Dock Position_ でも設定でき、`omarchy dock position left` でターミナルから設定できます。ドックに残したアプリは、実行中でない間は淡く表示されます。ドックをフローティングワークスペースだけに表示するには、_Appearance > Dock > Dock Only on Floating_ を使うか、`omarchy dock tiling off` を実行してください。

新しいワークスペースと、`Super + L` で独自のレイアウトを指定していないワークスペースは、デフォルトレイアウトを使います。デフォルトを変更すると、ウィンドウのないすべてのワークスペースがそれにリセットされますが、ウィンドウのあるワークスペースは現在のレイアウトを維持します。ドックに最小化されたウィンドウも、元のワークスペースにあるウィンドウとして数えられます。_Appearance > Workspace Layout_ で Tiling、Scrolling、Floating から選んでください。`omarchy hyprland workspace layout default scrolling` でターミナルから設定できます。

### ウィンドウのグループ化

ウィンドウは `Super + G` を使ってグループ化できます。一度グループに入ると、その状態がアクティブな間に起動したすべてのウィンドウがそのグループに属します。これらのグループ化されたウィンドウ間は、`Super + Ctrl + Arrow Left/Right` で移動したり、`Super + Alt + 1/2/3/4` で順番にグループ化されたウィンドウへ直接移動したりできます。

ウィンドウをグループから外すには `Super + Alt + G` を使い、グループ全体を解体するにはもう一度 `Super + G` を押します。最後に、`Super + Alt + Arrows` でグループ外のウィンドウをグループ内へ移動させることができます。

### ウィンドウのポップアウト

`Super + O` でウィンドウをワークスペースの割り当てから切り離すことができます。そうすると、どのワークスペースへ移動しても付いてくるフローティングウィンドウとしてピン留めされます。動画プレイヤーなどに最適です。

 ![navigation-popped-window](images/navigation-popped-window.webp)

### スクラッチパッドワークスペース

現在いるワークスペースの上に重なる、特別な全画面サイズのスクラッチパッドワークスペースがあります。その上にあるものには `Super + S` でアクセスし、ウィンドウをそこに配置するには `Super + Alt + S` を使います。

現在のワークスペースを離れることなく素早く操作したいコントロールやターミナルに適しています。

### Quake コンソール

最後に、現在いるワークスペースの上にドロップダウンする、半分の高さの Quake コンソールがあります。`Super + the key above Tab`（US 配列では grave）で切り替え、ウィンドウをそこに配置するには `Super + Shift + the key above Tab` を使います。

初めて開くときは、デフォルトのエージェントが起動します。まだ選んでいない場合は、選ぶよう求められます。コンソールにウィンドウが 1 つだけある間は、画面いっぱいに広がるのではなく、中央に配置されたパネルとしてドロップダウンします。2 つ目のアプリをそこに置くと全幅に戻り、2 つが横並びに収まるスペースが確保されます。

ウィンドウをスクラッチパッドやコンソールから移動させるには、`Super + Shift + 1` のようにして別のワークスペースへ直接送ってください。

### 慣れるまで少し時間がかかります！

このようにデスクトップを移動する方法に慣れるまで少し時間がかかりますが、一度慣れてしまえば、従来のマウス主体のデスクトップ体験に戻るのは難しくなるでしょう！
