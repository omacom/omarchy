# ナビゲーション

Omarchy ではすべてがキーボードで行われます — _すべてです！_ システムが起動した直後は、マウスだけでは文字通り何もできません。でも `Super + Space` を押せば Omarchy Menu が表示され、そこからほぼ何でもできます。

ただし、Omarchy メニューは、ほとんどの時間システムを操作する主な方法として意図されたものでさえありません。もっと速くできます！最も重要なアプリケーションはすべて、個別のホットキーに直接割り当てられています。ターミナルは `Super + Return` で、ブラウザは `Super + Shift + Return` で起動します。続けて両方を試してみてください。Hyprland のタイル表示の魔法が実際に動くのを見られます：

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

次に `Super + J` を押すと、横並びではなく上下に積み重ねられます：

 ![navigation-stacked](images/navigation-stacked.webp)

`Super + J` をもう一度押すと、横並びの位置に戻ります。次に、ブラウザで `Super + Shift + Arrow Right` を試してウィンドウを入れ替えてみてください。

次に `Super + Shift + T` を試して Activity モニターを起動してください。それはフローティングウィンドウとして表示されます。`Super + T` でタイル表示にでき（もう一度押すと再びフローティングに戻ります）。次に `Super + Shift + F` を押してファイルマネージャーを開きます。すっきりした 4 分割のセットアップが完成します：

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

アクティブにしたいウィンドウ間は `Super + Arrow` で移動します。これによりフォーカスが切り替わり、カーソルが新しいアプリケーションの中央へ移動します。画面の端では、その側にあるモニターへそのまま移動します。

`Super + Shift + 2` を押すと、現在フォーカスしているアプリケーションが 2 番目のワークスペースへ移動します。`Super + Shift + 1` で戻ります。（そして `Super + Shift + Alt + 2` を押すと、現在フォーカスしているアプリケーションが、そのワークスペースへ切り替えることなく 2 番目のワークスペースへ移動します。）

モニターが複数ある場合、各モニターにそれぞれ 1 から 10 までのワークスペースがあります。`Super + 2` で現在のモニターの 2 番目のワークスペースへ移動し、各モニターのトップバーには、そのモニター自体のワークスペースと、現在表示しているワークスペースが表示されます。`Super + Tab` で現在のモニターのワークスペースを順に切り替えます。`Super + Shift + Ctrl + Arrows` で現在のウィンドウをその方向にあるモニターへ、そのモニターが表示しているワークスペース上に移動し、`Super + Shift + Alt + Arrows` で現在のワークスペースをその方向にあるモニターへ移動します。移動先では、空いていれば同じ番号になります。モニターを取り外しても、そのワークスペースは保持されます。別の画面のワークスペースに加わり、その画面にすでに存在するものの後ろに番号が付けられ、モニターが戻ると元の番号に戻ります。

`Super` を押しながらマウスでウィンドウをクリックすると、その配置を変更できます。`Super` を押しながらマウスの右ボタンを使うと、ウィンドウを自由にリサイズできます。

ウィンドウは `Super + W` または `Super + Q` で閉じます（すべてのウィンドウは `Ctrl + Alt + Delete` で閉じます）。

`Super + F` でフルスクリーンにしたり、`Super + Alt + F` でトップバーを残したまま全幅にしたり、`Super + Ctrl + F` でウィンドウ内フルスクリーンにしたりもできます（YouTube に最適です！）。

### Dwindle と scrolling レイアウト

Omarchy のデフォルトのレイアウトは dwindle と呼ばれます。1 つのワークスペースで開いたすべてのウィンドウを、縮小してでも常時表示し続けます。

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

しかし、ワークスペースを scrolling レイアウトに変更することも選べます。このレイアウトではウィンドウが横並びに配置され、ディスプレイの見える端の先まで続きます。単一のワークスペースをこのレイアウトにするには `Super + L` を使います。

`Super + L` をもう一度押すとワークスペースがフローティングになり、ウィンドウが自由に重なり、自分で配置できるようになり、3 回目で dwindle に戻ります。`Super + Alt + L` では逆の順序で切り替わります。もともとフローティングしているウィンドウ — `Super + T` で切り離したものや、常にフローティングで開くアプリ — は、ワークスペースがタイル表示に戻ってもフローティングのままです。トップバーでは、現在のワークスペースにそのレイアウトを示すマークが表示されます。dwindle は四角形、scrolling は円、フローティングは三角形です。そのマークをクリックしてもレイアウトを順に切り替えられます。

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

この選択はワークスペースごとで、保持されます。そのため、ワークスペース 1 はブラウジング用に dwindle、ワークスペース 2 はコード用に scrolling にしておけば、再起動後もその状態で戻ってきます。

scrolling レイアウトをデフォルトとして使いたい場合は、`~/.config/hypr/looknfeel.lua` で設定できます：

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### フローティングワークスペース

フローティングワークスペースは従来のデスクトップのように動作します。ウィンドウが重なり合い、移動もサイズ変更も自分で行います。各ウィンドウにはテーマの色のタイトルバーが付き、最小化、最大化、閉じるボタンがあります。`Super + M` でもフォーカス中のウィンドウを最小化できます。最小化されたウィンドウはドックで待機します。そのアプリをクリックすれば戻ってきます。ウィンドウをクリックすれば前面に表示されます。任意の辺や角からサイズを変更できます。タイトルバーをダブルクリックすると、トップバーを表示したままウィンドウを最大化し、もう一度ダブルクリックすると元のサイズに戻ります。Chrome やその他の Chromium ベースのブラウザ、Disks、Document Viewer はタイトルバーをスキップし、代わりに独自のヘッダーを使います。`Super + Alt + F` で最大化し、`Super + M` で最小化します。

フローティングワークスペースではドックも表示されます。そこにはピン留めしたアプリ、実行中のすべてのアプリが並び、apps ボタンの後ろにはすべてのアプリのグリッドがあります。このグリッドは `Super + Alt + Space` や Omarchy メニューの _Apps_ でも開けます。グリッド上でアプリを右クリックするか、`Delete` を押すと、そのアプリをアンインストールできます。アプリをクリックすると開くか、そのウィンドウを前面に表示します。もう一度クリックすると、そのアプリのウィンドウを順に切り替えます。中クリックすると新しいウィンドウを開きます。アイコンをドックに沿ってドラッグすると移動できます。実行中のアプリを他のアプリの間にドラッグすると、そこに保持されます。右クリックすると、アプリをドックに保持したり、ドックから外したり、終了したりできます。ドックはフルスクリーンウィンドウの邪魔にならないよう退きます。apps ボタンを右クリックすると、ドックを別の辺に移動したり、ポインターがその辺に到達するまで隠したりできます。位置は _Appearance > Dock > Dock Position_ でも設定でき、`omarchy dock position left` と `omarchy dock autohide on` でターミナルから両方を設定できます。ドックに保持しているアプリは、実行中でない間は薄く表示されます。

新しいワークスペースと、`Super + L` で独自のレイアウトを指定していないワークスペースは、デフォルトのレイアウトを使います。デフォルトを変更すると、ウィンドウのないすべてのワークスペースがそのレイアウトにリセットされますが、ウィンドウのあるワークスペースは現在のレイアウトを保持します。ドックに最小化されたウィンドウも、離れたワークスペース上のウィンドウとして数えられます。_Appearance > Workspace Layout_ で Tiling、Scrolling、Floating のいずれかを選んでください。`omarchy-hyprland-workspace-layout-default scrolling` でターミナルから設定できます。

### ウィンドウのグループ化

ウィンドウは `Super + G` でグループ化できます。グループに入ると、それがアクティブな間に起動したすべてのウィンドウがそのグループに属します。これらのグループ化されたウィンドウ間は、`Super + Ctrl + Arrow Left/Right` で移動したり、`Super + Alt + 1/2/3/4` で順番に直接移動したりできます。

`Super + Alt + G` でウィンドウをグループから外したり、`Super + G` をもう一度押してグループ全体を解体したりできます。最後に、`Super + Alt + Arrows` でグループ外のウィンドウをグループ内に移動できます。

### ウィンドウのポップアウト

ウィンドウは `Super + O` でワークスペースへの割り当てから切り離せます。すると、どのワークスペースへ行ってもついてくるフローティングウィンドウとしてピン留めされます。動画プレーヤーなどに最適です。

 ![navigation-popped-window](images/navigation-popped-window.webp)

### スクラッチパッドワークスペース

現在のワークスペースに重ねて表示される、フルサイズの特別なスクラッチパッドワークスペースがあります。そこにあるものには `Super + S` でアクセスし、ウィンドウは `Super + Alt + S` でそこに配置します。

現在のワークスペースを離れることなく、コントロールやターミナルを素早く操作したい場合に便利です。

### Quake コンソール

最後に、現在のワークスペース上にドロップダウンする、高さ半分の Quake コンソールがあります。`Super + Grave` で切り替え、`Super + Shift + Grave` でウィンドウをそこに配置します。

開くと、デフォルトの agent がすぐに使える状態になっています。コンソールにウィンドウが 1 つだけある間は、画面いっぱいに広がらず、中央に配置されたパネルとしてドロップダウンします。2 つ目のアプリを配置すると全幅に戻り、2 つが横並びに収まるスペースが確保されます。

スクラッチパッドやコンソールからウィンドウを外すには、`Super + Shift + 1` のようにして、別のワークスペースへ直接送ります。

### 慣れるまで少し時間がかかります！

このようにデスクトップを移動する操作に慣れるには少し時間がかかりますが、一度慣れてしまえば、従来のマウス中心のデスクトップ体験には戻れなくなるでしょう！
