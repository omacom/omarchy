# ナビゲーション

Omarchy ではすべてキーボードで操作します ― _すべてです！_ システムが初めて起動したときは、マウスだけでは文字通り何もできません。しかし `Super + Space` を押せば Omarchy Menu が表示され、ここからほぼ何でもできます。

とはいえ、Omarchy Menu はそもそも、普段システムを操作する主な方法として使うことすら想定されていません。もっと速くできます！最も重要なアプリケーションはすべて、それぞれ個別のホットキーに直接割り当てられています。ターミナルは `Super + Return` で、ブラウザは `Super + Shift + Return` で起動します。続けて一つずつ試してみれば、Hyprland のタイル配置の魔法が実際に動くところが見られます：

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

次に `Super + J` を押すと、横に並べる代わりに上下に重ねて配置できます：

 ![navigation-stacked](images/navigation-stacked.webp)

もう一度 `Super + J` を押すと、横並びの位置に戻ります。次にブラウザにいる状態で `Super + Shift + Arrow Right` を試して、ウィンドウを入れ替えてみてください。

今度は `Super + Shift + T` を押して Activity monitor を起動してみてください。フローティングウィンドウとして表示されます。`Super + T` を使えばタイル配置にできます（もう一度押せば再びフローティングに戻ります）。次に `Super + Shift + F` を押してファイルマネージャーを開いてください。きれいな4分割のセットアップができあがります：

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

アクティブにしたいウィンドウの間は `Super + Arrow` で移動します。これでフォーカスが切り替わり、カーソルが新しいアプリケーションの中央に移動します。画面の端では、その方向にあるモニターへそのまま移動します。

`Super + Shift + 2` を押すと、現在フォーカスしているアプリケーションが2番目のワークスペースに移動します。`Super + Shift + 1` で戻ります。（そして `Super + Shift + Alt + 2` を使うと、現在フォーカスしているアプリケーションを、そのワークスペースに切り替えずに2番目のワークスペースへ移動できます）。

モニターが複数ある場合、各モニターにはそれぞれ独自の1から10までのワークスペースがあります。`Super + 2` は今いるモニターの2番目のワークスペースへ移動し、各モニターのトップバーにはそのモニター自身のワークスペースと、現在表示しているものが表示されます。`Super + Tab` は今いるモニター上のワークスペースを順に切り替えます。`Super + Shift + Ctrl + Arrows` は今いるウィンドウをその方向のモニターへ、そのモニターが表示しているワークスペース上に移動し、`Super + Shift + Alt + Arrows` は今いるワークスペースをその方向のモニターへ移動します。移動先では、空いていれば同じ番号になります。モニターを取り外しても、そのモニターはワークスペースを保持します：それらは別の画面のワークスペースに加わり、既存のものの後ろに番号が付けられ、モニターが戻ってくると元の番号に戻ります。

`Super` を押しながらマウスでウィンドウをクリックすると、その配置場所を並べ替えることができます。`Super` を押しながらマウスの右ボタンを使うと、ウィンドウを自由にリサイズできます。

ウィンドウは `Super + W` または `Super + Q` で閉じます（すべてのウィンドウは `Ctrl + Alt + Delete` で閉じます）。

`Super + F` で全画面表示にすることもできますし、`Super + Alt + F` で（トップバーを残したまま）単に全幅表示にしたり、`Super + Ctrl + F` でウィンドウ内での全画面表示にしたりもできます（YouTube に最適です！）。

### Dwindle vs scrolling layout

Omarchy のデフォルトレイアウトは dwindle と呼ばれます。単一のワークスペース上で開いたすべてのウィンドウを、縮小しなければならない場合でも、常にすべて表示したままにします。

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

しかし、ワークスペースを scrolling layout に変えることも選べます。このレイアウトではウィンドウが横に並び、ディスプレイの見える端の先まで続きます。単一のワークスペースは `Super + L` でこのレイアウトにできます。

もう一度 `Super + L` を押すとワークスペースが floating になり、ウィンドウが自由に重なり、自分で配置できるようになり、3回目を押すと dwindle に戻ります。`Super + Alt + L` は逆の順序で切り替えます。もともとフローティングしているウィンドウ ― `Super + T` で取り出したものや、常にフローティングで開くアプリ ― は、ワークスペースがタイル配置に戻ってもフローティングのままです。トップバーには、今いるワークスペースにそのレイアウトを示すマークが表示されます：dwindle は四角、scrolling は円、floating は三角です。そのマークをクリックしてもレイアウトは順に切り替わり、そういうキーがあるラップトップではディスプレイキーでも切り替わります。

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

この選択はワークスペースごとで、保持されます。つまり、ワークスペース1はブラウジング用に dwindle のままにし、ワークスペース2はコード用に scrolling にしておけば、再起動後もその状態で戻ってきます。

scrolling layout をデフォルトとして使いたい場合は、`~/.config/hypr/looknfeel.lua` で設定できます：

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### Floating workspaces

floating workspace は従来のデスクトップのように動作します：ウィンドウが重なり、移動とサイズ変更は自分で行います。各ウィンドウにはテーマの色のタイトルバーが付き、最小化、最大化、閉じるボタンがあります。`Super + M` でもフォーカスしているウィンドウを最小化できます。最小化したウィンドウは dock で待機します；そのアプリをクリックすれば戻ってきます。ウィンドウをクリックすれば手前に来ます。どの端や角からでもリサイズできます。タイトルバーをダブルクリックすると、トップバーを表示したままウィンドウが最大化され、もう一度ダブルクリックすると元のサイズに戻ります。Chrome やその他の Chromium ベースのブラウザ、Disks、Document Viewer はタイトルバーを省き、代わりに独自のヘッダーを使います；`Super + Alt + F` で最大化し、`Super + M` で最小化します。

floating workspace には dock も表示され、ピン留めしたアプリ、実行中のすべてのもの、そして apps ボタンの後ろにあるすべてのアプリのグリッドがあります。このグリッドは `Super + Alt + Space` でも、Omarchy menu の _Apps_ でも開けます。グリッド上のアプリを右クリックするか、`Delete` を押すとアンインストールできます。アプリをクリックすると開くか、そのウィンドウが手前に来ます；もう一度クリックするとそのウィンドウを順に切り替えます。Files は今いるワークスペースからウィンドウを持ち戻すだけで、それ以外では新しいウィンドウを開きます。Terminal と Agent は常にもう一つ起動しますが、最小化したウィンドウがあればそちらが先に戻ります。中クリックすると新しいウィンドウが開きます。アイコンを dock に沿ってドラッグすると移動できます；実行中のアプリを他のアプリの間にドラッグするとそこに保持されます。右クリックするとアプリを dock に保持したり、dock から外したり、終了したりできます。dock は全画面ウィンドウの邪魔にならないよう退きます。apps ボタンを右クリックすると、dock を別の端に移動したり、ポインターがその端に届くまで隠したりできます。位置は _Appearance > Dock > Dock Position_ でも設定でき、`omarchy dock position left` と `omarchy dock autohide on` でターミナルから両方を設定できます。dock に保持したアプリは、実行中でない間は薄く表示されます。

新しいワークスペースと、`Super + L` で独自のレイアウトを与えていないワークスペースは、デフォルトレイアウトを使います。デフォルトを変更すると、ウィンドウのないすべてのワークスペースがそれにリセットされますが、ウィンドウがあるワークスペースは今のレイアウトを保持します。dock に最小化したウィンドウも、それが離れたワークスペース上のウィンドウとして数えられます。_Appearance > Workspace Layout_ で選びます：Tiling、Scrolling、または Floating です。`omarchy hyprland workspace layout default scrolling` でターミナルから設定できます。

### Grouping windows

ウィンドウは `Super + G` を使ってグループ化できます。グループに入ると、その状態がアクティブな間に起動したすべてのウィンドウがそのグループに属します。これらのグループ化されたウィンドウの間は、`Super + Ctrl + Arrow Left/Right` を使って移動したり、`Super + Alt + 1/2/3/4` を使って順番にグループ化されたウィンドウへ直接移動したりできます。

ウィンドウをグループから出すには `Super + Alt + G` を使い、グループ全体を解体するにはもう一度 `Super + G` を押します。最後に、グループの外にあるウィンドウを `Super + Alt + Arrows` でグループ内へ移動することもできます。

### Popping windows

ウィンドウは `Super + O` でワークスペースの割り当てから取り出すことができます。そうすると、どのワークスペースに行っても付いてくるフローティングウィンドウとしてピン留めされます。動画プレイヤーなどに最適です。

 ![navigation-popped-window](images/navigation-popped-window.webp)

### Scratchpad workspace

現在いるワークスペースに重ねて表示される、専用のフルサイズの scratchpad workspace があります。その上にあるものには `Super + S` でアクセスし、ウィンドウは `Super + Alt + S` でそこに配置します。

現在のワークスペースを離れることなく素早く操作したいコントロールやターミナルに適しています。

### Quake console

最後に、現在いるワークスペースの上に降りてくる、高さが半分の Quake console があります。`Super + Grave` で切り替え、ウィンドウは `Super + Shift + Grave` でそこに配置します。

初めて開くときは、デフォルトの agent が起動するか、まだ選んでいない場合は選ぶよう求められます。console にウィンドウが一つだけ入っている間は、画面いっぱいに広がるのではなく、中央に配置されたパネルとして降りてきます。2つ目のアプリを置くと全幅に戻り、2つが横に並ぶ余地ができます。

scratchpad や console からウィンドウを移動するには、`Super + Shift + 1` のような組み合わせで別のワークスペースへ直接送ります。

### It takes some getting used to!

このようにデスクトップを移動することに慣れるまでには少し時間がかかりますが、一度慣れてしまえば、従来のマウス主導のデスクトップ体験に戻るのは難しくなるでしょう！
