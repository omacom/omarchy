# ナビゲーション

Omarchy ではすべてをキーボードで行う — _すべてだ！_ システムが初めて起動したとき、文字通りマウスだけでは何もできない。しかし `Super + Space` を押せば Omarchy メニューが表示され、ここからほぼ何でもできる。

しかし Omarchy メニューは、ほとんどの時間システムを操作する主な方法として意図されたものではない。それよりもっと速くできる！最も重要なアプリケーションはすべて、個別のホットキーに直接割り当てられている。ターミナルは `Super + Return` で、ブラウザは `Super + Shift + Return` で起動する。続けて一つずつ試してみれば、Hyprland のタイリングの魔法が動く様子がわかるだろう：

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

次に `Super + J` を押すと、横並びではなく上下に重ねて配置できる：

 ![navigation-stacked](images/navigation-stacked.webp)

`Super + J` をもう一度押すと、横並びの位置に戻る。次に、ブラウザにいる状態で `Super + Shift + Arrow Right` を試して、ウィンドウを入れ替えてみよう。

次に `Super + Shift + T` を試して、Activity モニターを起動してみよう。それはフローティングウィンドウとして表示され、ドラッグするためのタイトルバーと、最小化、最大化、閉じるボタンが付いている。すべてのフローティングウィンドウには、どこにあってもそれが付く。`Super + T` を使ってタイリングできる（もう一度押すと再びフローティングになる）。次に `Super + Shift + F` を押してファイルマネージャーを開く。きれいな4分割のセットアップになる：

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

アクティブにしたいウィンドウ間の移動は `Super + Arrow` で行う。これでフォーカスが切り替わり、カーソルが新しいアプリケーションの中央に移動する。画面の端では、その側にあるモニターへと続いていく。

`Super + Shift + 2` を押すと、現在フォーカスされているアプリケーションが2番目のワークスペースに移動する。`Super + Shift + 1` で戻る。（そして `Super + Shift + Alt + 2` は、現在フォーカスされているアプリケーションを、そちらに切り替えることなく2番目のワークスペースに移動する）。

モニターが複数ある場合、各モニターはそれぞれ独自の1から10までのワークスペースを持つ。`Super + 2` は、現在いるモニターの2番目のワークスペースに移動し、各モニターのトップバーにはそのモニター自身のワークスペースと、表示中のものが表示される。`Super + Tab` は、現在いるモニター上のワークスペースを順に切り替える。`Super + Shift + Ctrl + Arrows` は、現在のウィンドウをその方向にあるモニターへ、そのモニターが表示しているワークスペース上に移動し、`Super + Shift + Alt + Arrows` は、現在のワークスペースをその方向にあるモニターへ移動し、そこでは空いていれば同じ番号になる。モニターを取り外しても、そのワークスペースは保持される：それらは別の画面のワークスペースに加わり、既存のものの後に番号が付けられ、モニターが戻ると元の番号に戻る。

`Super` を押しながらマウスでウィンドウをクリックすると、その配置を並べ替えることができる。`Super` を押しながらマウスの右ボタンを使うと、ウィンドウを自由にリサイズできる。

ウィンドウは `Super + W` または `Super + Q` で閉じる（すべてのウィンドウは `Ctrl + Alt + Delete` で閉じる）。

また、`Super + F` でフルスクリーンにしたり、`Super + Alt + F` で（トップバーを残して）幅いっぱいにしたり、`Super + Ctrl + F` でウィンドウ内フルスクリーンにしたりもできる（YouTube に最適だ！）。

### Dwindle とスクローリングレイアウト

Omarchy のデフォルトレイアウトは dwindle と呼ばれる。1つのワークスペースで開いたすべてのウィンドウを、縮小しなければならない場合でも、常に表示し続ける。

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

しかし、ワークスペースをスクローリングレイアウトに変更することもできる。そこではウィンドウが横並びに並び、ディスプレイの見える端を超えて続く。1つのワークスペースをこのレイアウトに変更するには `Super + L` を使う。

`Super + L` をもう一度押すとワークスペースがフローティングになり、ウィンドウが自由に重なり、自分で配置できるようになり、3回目を押すと dwindle に戻る。`Super + Alt + L` は逆の順序で切り替える。もともとフローティングしているウィンドウ — `Super + T` で切り離したものや、常にフローティングで開くアプリ — は、ワークスペースがタイリングに戻ってもフローティングのままである。トップバーには、現在のワークスペースにそのレイアウトがマークされる：dwindle は四角形、スクローリングは円形、フローティングは三角形だ。そのマークをクリックしてもレイアウトが切り替わり、そのキーがあるラップトップではディスプレイキーでも切り替わる。

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

選択はワークスペースごとであり、保持される。したがって、ワークスペース1は閲覧用に dwindle、ワークスペース2はコード用にスクローリングにしておくことができ、再起動後もその状態で戻ってくる。

スクローリングレイアウトをデフォルトとして使用したい場合は、`~/.config/hypr/looknfeel.lua` で設定できる：

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### フローティングワークスペース

フローティングワークスペースは従来のデスクトップのように機能する：ウィンドウが重なり合い、自分で移動とサイズ変更を行う。各ウィンドウにはテーマの色のタイトルバーが付き、最小化、最大化、閉じるボタンがある。`Super + M` でもフォーカスされたウィンドウを最小化できる。最小化されたウィンドウはドックで待機する；そのアプリをクリックすると戻ってくる。ウィンドウをクリックすると前面に来る。任意の端や角からリサイズできる。タイトルバーをダブルクリックすると、トップバーを表示したままウィンドウが最大化され、もう一度ダブルクリックすると元のサイズに戻る。Chrome やその他の Chromium ベースのブラウザ、Disks、Document Viewer はタイトルバーを省略し、代わりに独自のヘッダーを使用する；`Super + Alt + F` で最大化し、`Super + M` で最小化する。

すべてのワークスペースにはドックがあり、ピン留めしたアプリ、実行中のすべて、そしてアプリボタンの背後にあるすべてのアプリのグリッドがある。アプリボタンは `Super + Alt + Space` や Omarchy メニューの _Apps_ でも開くことができる。グリッド上のアプリを右クリックするか、`Delete` を押すとアンインストールできる。アプリをクリックすると、それが開くか、そのウィンドウが前面に来る；もう一度クリックすると、そのウィンドウを順に切り替える。Files は現在のワークスペースからのウィンドウだけを戻し、それ以外では新しいウィンドウを開き、Terminal と Agent は常にもう1つ起動するが、最小化されたウィンドウがまず戻ってくる。中クリックで新しいウィンドウが開く。アイコンをドックに沿ってドラッグすると移動できる；実行中のアプリを他のアプリの間にドラッグすると、そこに保持される。右クリックすると、アプリをドックに保持するか、取り除くか、終了できる。ドックはワークスペースが空の間は表示されており、ワークスペースにウィンドウができると、ポインタがその端に到達するまで隠れる。フルスクリーンウィンドウは完全に隠す。アプリボタンを画面の別の端に向かってドラッグすると、ドックをそこへ移動できる。それを右クリックすると、端を選ぶ _Position_、_Appearance > Workspace Layout_ が行うようにデフォルトレイアウトを設定する _Layout_、ドックを常に表示するか、最初のアプリで隠すか、常に隠しておくかを選ぶ _Visibility_ が使える。`omarchy dock visibility always` でターミナルから設定できる。位置は _Appearance > Dock > Dock Position_ にもあり、`omarchy dock position left` でターミナルから設定できる。ドックに保持しているアプリは、実行されていない間は色あせて表示される。ドックをフローティングワークスペースだけに限定するには、_Appearance > Dock > Dock Only on Floating_ を使用するか、`omarchy dock tiling off` を使う。

新しいワークスペース、および `Super + L` で独自のレイアウトを与えていないワークスペースは、デフォルトレイアウトを使用する。デフォルトを変更すると、ウィンドウのないすべてのワークスペースがそれにリセットされる一方で、ウィンドウのあるワークスペースは現在のレイアウトを保持する。ドックに最小化されたウィンドウは、それが離れたワークスペース上のウィンドウとして依然として数えられる。_Appearance > Workspace Layout_ の下で選ぶ：Tiling、Scrolling、または Floating。`omarchy hyprland workspace layout default scrolling` でターミナルから設定できる。

### ウィンドウのグループ化

ウィンドウは `Super + G` を使ってグループ化できる。いったんグループに入ると、それがアクティブな間に起動したすべてのウィンドウはそのグループに属する。これらのグループ化されたウィンドウ間は、`Super + Ctrl + Arrow Left/Right` を使って移動したり、`Super + Alt + 1/2/3/4` を使って順序どおりグループ化されたウィンドウに直接移動したりできる。

ウィンドウをグループから外すには `Super + Alt + G` を使い、グループ全体を解体するには `Super + G` をもう一度押す。最後に、`Super + Alt + Arrows` でグループ外のウィンドウをグループ内へ移動できる。

### ウィンドウのポップアウト

`Super + O` でウィンドウをそのワークスペース割り当てから切り離すことができる。それにより、どのワークスペースに行っても付いてくるフローティングウィンドウとしてピン留めされる。ビデオプレーヤーなどに最適だ。

 ![navigation-popped-window](images/navigation-popped-window.webp)

### スクラッチパッドワークスペース

現在いるワークスペースの上に重なる、特別なフルサイズのスクラッチパッドワークスペースがある。そこにあるものには `Super + S` でアクセスし、ウィンドウをそこに配置するには `Super + Alt + S` を使う。

現在のワークスペースを離れることなく素早く操作したいコントロールやターミナルに適している。

### Quake コンソール

最後に、現在いるワークスペースの上にドロップダウンする、高さ半分の Quake コンソールがある。`Super + the key above Tab`（US レイアウトでは grave）で切り替え、`Super + Shift + the key above Tab` を使ってそこにウィンドウを配置する。

初めて開くときは、デフォルトの agent が起動するか、まだ選んでいない場合は選ぶよう求められる。コンソールが1つのウィンドウだけを保持している間は、画面いっぱいに広がるのではなく、中央に配置されたパネルとしてドロップダウンする。2つ目のアプリをそこに置くと全幅に戻り、2つが横並びに座る余地ができる。

スクラッチパッドやコンソールからウィンドウを移動するには、`Super + Shift + 1` のようなもので別のワークスペースに直接送る。

### 慣れるまで少し時間がかかる！

このようにデスクトップをナビゲートすることに慣れるまで少し時間がかかるが、一度慣れると、従来のマウス中心のデスクトップ体験に戻るのは難しくなるだろう！
