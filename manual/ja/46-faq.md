# FAQ

### キーボードレイアウトを切り替えるには？

`~/.config/hypr/input.lua` ファイルを編集し、`Left Alt + Right Alt` でレイアウトを切り替えられるように次を追加してください：

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

複数のレイアウトを設定すると、バーに現在のキーボードレイアウトが自動的に表示されます（クリックして切り替えることもできます）。

### 時計の形式を12時間表示に変更するには？

バーにある時計を右クリックすると、12時間形式を含む一般的な形式を順に切り替えられます。形式を直接設定することもできます：

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

これにより、日曜日 10:55 AM と表示されます。

### タイムゾーンを変更するには？

Omarchyメニューで _設定 > 地域 > タイムゾーン_ を実行し、一覧から選んでください。タイムゾーンは正しいのに時計自体がずれている場合は、_アップデート > 時刻_ が時刻同期を再起動してくれます。

### DNSを変更したり、Wi-Fiを共有したり、接続速度を確認したりするには？

それらはすべて [ネットワーク](35-networking.md) にあります。

### ディスクの速度を確認するには？

_トリガー > スピードテスト > ディスクスピードテスト_ でドライブの読み取り速度と書き込み速度をリアルタイムに測定できます。ターミナルから `omarchy disk speedtest` を実行しても測定できます。

### プリンターを追加するには？

印刷機能は最初から設定済みで動作しています。各プリンターはアプリランチャー（`Super + Alt + Space`）の _印刷設定_ から自分で追加します。

_追加_ を選んで、少し待ってください。USBで接続されたプリンターと、ほとんどのネットワークプリンターは自動で見つかります。お使いのプリンターが一覧にない場合は _ネットワークプリンター > Internet Printing Protocol (ipp)_ を選び、そのアドレスを入力してください。アドレスはプリンター本体のディスプレイか、そのWebページで確認できます。通常は `192.168.1.50` のようなアドレスで、キューは `ipp/print` です。次に _進む_ を押すとドライバーが提示されます。最近のプリンターはドライバーレスな _IPP Everywhere_ プロファイルが最適で、古いプリンターはそのモデル専用のドライバーが適しています。

プリンターを右クリックし、アプリが最初に使うプリンターを選ぶ場合は _デフォルトに設定_、用紙サイズ、両面印刷、品質を設定する場合は _プロパティ_ を選んでください。

ネットワーク上のプリンターを追加しなくても表示される自動検出は、改修中のため一時的にオフになっています。だからこそ、最初の手順は自動ではなくあなたの手で行うものになっています。プリンターがまったくなくても、PDFファイルへの印刷はできます。

### スクリーンショットや画面録画の保存先を変更するには？

保存したスクリーンショットはデフォルトで `~/Pictures/Screenshots` に入ります。別のディレクトリを使うには、`~/.config/uwsm/env.d/` 以下のファイル（`~/.config/uwsm/env.d/capture` など）に次を追加してください：

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

画面録画についても `OMARCHY_SCREENRECORD_DIR` を使って同じことができます。

Omasnapはスクリーンショット用のディレクトリを自動的に作成します。画面録画用のディレクトリは自分で作成してください。その後、どちらの環境変更も有効にするためにOmarchyを再起動してください。

### Apple Studio Displayでスピーカーとウェブカメラを動作させるには？

USB Cを差すだけで全部そのまま動くはずだ、と思うでしょう。でも残念ながらそうはいきません。確実に動かすために私が見つけた解決策は、[WJESOG DisplayPort + USB-A => USB-Cケーブル](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) を使うことです。そうすればスピーカーとウェブカメラが嘘のように快調に動きます。

OmarchyにはApple Displays（StudioとXDRの両方）向けの明るさ調整が組み込まれていて、通常のキーボードの明るさボタンで使えることも覚えておいてください。

### 余分なソフトウェアをすべて取り除くには？

ObsidianやLibreOffice、その他のプリインストール済みプログラムが不要なら、とても簡単に削除できます。

_削除 > パッケージ_ を実行すると、インストールされているすべてのパッケージが表示されます。Tabで削除したいパッケージを選び、Returnで選んだものの削除を開始できます。

Omarchyメニューの _削除 > Webアプリ_ を使えば、不要なプリインストール済みWebアプリも削除できます。

あるいは _削除 > プリインストール_ を実行すれば、Webアプリ、TUI、オプションのアプリケーションといったプリインストール済みの追加ソフトウェアを一気に一掃できます。それらを起動していたホットキーも一緒に消えるので、`~/.config/hypr/bindings.lua` に自分の設定で埋めるための、すっきりしたバインディングだけが残ります。
