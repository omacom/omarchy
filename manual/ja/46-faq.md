# FAQ

### キーボードレイアウトを切り替えるにはどうすればいいですか？

`~/.config/hypr/input.lua`ファイルを編集し、`Left Alt + Right Alt`でレイアウトを切り替えられるよう次を追加してください。

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

複数のレイアウトを設定すると、バーに現在のキーボードレイアウトが自動的に表示されます（クリックして切り替えることもできます）。

### 時計の形式を12時間制に変更するにはどうすればいいですか？

バーの時計を右クリックすると、12時間制を含む一般的な形式が順に切り替わります。形式を直接設定することもできます。

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

これにより Sunday 10:55 AM と表示されます。

### タイムゾーンを変更するにはどうすればいいですか？

Omarchyメニューで_更新 > タイムゾーン_を実行し、リストから選んでください。タイムゾーンは正しいが時計自体がずれている場合は、_更新 > 時刻_で時刻同期を再起動できます。

### DNSの変更、Wi-Fiの共有、接続速度の確認はどうすればいいですか？

それらすべては[ネットワーク](35-networking.md)にあります。

### ディスクの速度を確認するにはどうすればいいですか？

_実行 > 速度テスト > ディスク速度テスト_でドライブの実際の読み取りと書き込み速度を測定でき、ターミナルからは`omarchy disk speedtest`です。

### ChromiumでGoogleアカウントにサインインできないのはなぜですか？

プレーンなオープンソースChromiumビルドには、Googleがアカウントサインインに必要とするOAuth認証情報が同梱されていません。Omarchyメニューで_インストール > サービス > Chromiumアカウント_を実行して追加し、ブラウザーを再起動すると、サインインが通るようになります。

### プリンターを追加するにはどうすればいいですか？

印刷は初期状態で設定済みで動作しており、各プリンターはアプリランチャー（`Super + Space`）の_印刷設定_から自分で追加します。

_追加_を選び、しばらく検索させてください。USBで接続されたプリンターと、ほとんどのネットワークプリンターは自動で見つかります。自分のものがリストにない場合は、_ネットワークプリンター > Internet Printing Protocol (ipp)_を選んでアドレスを入力してください。プリンター自体のディスプレイやウェブページに表示されているはずで、通常は`192.168.1.50`のようなもので、キューは`ipp/print`です。_進む_を押すとドライバーが提示されます。現代のプリンターはドライバーレスの_IPP Everywhere_プロファイルで最もよく動作し、古いものはモデル固有のドライバーを必要とします。

プリンターを右クリックして_デフォルトとして設定_を選ぶと、アプリが最初に使うものを選べ、_プロパティ_では用紙サイズ、両面印刷、品質を設定できます。

ネットワーク上のプリンターを追加せずに表示させる自動検出は、再設計のため一時的にオフになっています。そのため、上の最初の手順は自動ではなくあなたの作業になります。PDFファイルへの印刷はプリンターがまったくなくても動作します。

### スクリーンショットや画面録画の保存先を変更するにはどうすればいいですか？

保存されたスクリーンショットはデフォルトで`~/Pictures/Screenshots`に入ります。別のディレクトリを使うには、`~/.config/uwsm/env.d/`の下のファイル（例：`~/.config/uwsm/env.d/capture`）に次を追加してください。

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

画面録画についても、`OMARCHY_SCREENRECORD_DIR`を使って同じことができます。

Omasnapはスクリーンショットディレクトリを自動的に作成します。画面録画ディレクトリは自分で作成し、その後どちらの環境変更を有効にするためにもOmarchyを再起動してください。

### Apple Studio Displayのスピーカーとウェブカメラを動作させるにはどうすればいいですか？

USB Cを接続すればすべて動くと思うでしょうが、残念ながらそうではありません。確実に動作させるために私が見つけた解決策は、[WJESOG DisplayPort + USB-A => USB-Cケーブル](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/)を使うことです。そうすればスピーカーもウェブカメラも見事に動作します。

Omarchyには、通常のキーボード輝度ボタンを使うApple純正ディスプレイ（StudioとXDRの両方）向けの輝度制御が内蔵されていることも覚えておいてください。

### 余分なソフトウェアをすべて取り除くにはどうすればいいですか？

ObsidianやLibreOffice、その他のプリインストールされているものが不要なら、非常に簡単に削除できます。

_削除 > パッケージ_を実行すると、インストールされているすべてのパッケージが見えます。次に、削除したいパッケージをtabで選択し、returnで選択したすべてのものの削除を開始できます。

また、Omarchyメニューの_削除 > Webアプリ_では、不要なプリインストール済みウェブアプリを削除できます。

あるいは、_削除 > プリインストール_を実行すると、ウェブアプリ、TUI、オプションのアプリケーションなど、プリインストールされた追加要素を一度にすべて取り除けます。それらを起動していたホットキーも一緒に消えるので、`~/.config/hypr/bindings.lua`に自分のものを入れるためのクリーンなバインドが残ります。
