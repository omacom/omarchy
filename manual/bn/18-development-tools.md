# ডেভেলপমেন্ট টুল

## বিকল্প এডিটর

Omarchy ডিফল্টভাবে [Neovim](https://neovim.io/) সহ আসে, তবে আপনি যদি আরও প্রচলিত ও পরিচিত কিছু চান, তাহলে Omarchy মেনু (`Super + Space`) চালিয়ে _ইনস্টল > Editor_-এর অধীনে বিকল্পগুলো দেখতে পারেন। সেখানে VSCode, Cursor, Zed, Sublime Text, Helix, Vim এবং Emacs তালিকাভুক্ত আছে। আপনি যা খুঁজছেন তা না পেলে, _ইনস্টল > Package_ দেখুন এবং দেখুন সেটি কোনো Arch প্যাকেজে আছে কিনা (আর না থাকলে, AUR দেখতে _ইনস্টল > AUR_ চেষ্টা করুন)।

আসল `vi` এডিটরটিও শুরু থেকেই পাওয়া যায়। টার্মিনালে কোনো ফাইল সম্পাদনা করতে `vi filename` চালান।

`VSCode`, `Cursor`, `VSCodium` এবং `Helix`-এর জন্য থিমের মিল দেওয়া হয়।

আপনি `Setup > Defaults > Editor`-এর অধীনে সিস্টেমব্যাপী ডিফল্ট এডিটর সেট করতে পারেন।

## এনভায়রনমেন্ট

Omarchy, Omarchy মেনুর (`Super + Space`) _ইনস্টল > Development_ বিভাগের মাধ্যমে নানান ধরনের ডেভেলপমেন্ট এনভায়রনমেন্ট সেট আপ করা সমর্থন করে। আপনি অবশ্যই _Ruby on Rails_ পাবেন, তবে JavaScript-এর তিনটি প্রধান রানটাইমও (Node.js, Bun, Deno) পাবেন, সেই সঙ্গে Laravel এবং Symfony-এর মতো জনপ্রিয় PHP ফ্রেমওয়ার্কও। ওহ, আর Go, Rust, Python, Java, Elixir (Phoenix সহ), .NET, OCaml, Zig, Clojure এবং Scala-ও আছে। এটি খুবই বিস্তৃত একটি নির্বাচন!

এই এনভায়রনমেন্টগুলোর বেশিরভাগই [Mise](https://mise.jdx.dev/) দিয়ে পরিচালিত হয়। এটি এমন একটি টুল যা আপনাকে একই মেশিনে কোনো প্রোগ্রামিং ভাষার একাধিক সংস্করণ ইনস্টল ও চালাতে দেয়। এটি Ruby-এর জন্য rbenv বা rvm অথবা Python-এর জন্য virtualenv-এর মতো, তবে এটি নানান ধরনের এনভায়রনমেন্টের জন্য কাজ করে।

উদাহরণস্বরূপ, Ruby ইনস্টল করতে আপনি `mise use -g ruby` চালাবেন, যা Ruby ইনস্টল করবে এবং সেটিকে গ্লোবাল ডিফল্ট হিসেবেও সেট করবে। অথবা, আপনার প্রোজেক্টে যদি একটি .ruby-version ফাইল থাকে, তাহলে সেই প্রোজেক্টের রুটে শুধু `mise i` চালালেই চলবে।

## Docker

[Docker](https://www.docker.com/)-এর তেমন কোনো পরিচিতির প্রয়োজন নেই। এটি আপনাকে বিচ্ছিন্ন কন্টেইনার চালাতে দেয়, এবং Omarchy সেটি ভালোভাবে চালানোর জন্য প্রয়োজনীয় সবকিছু ইনস্টল করে, যার মধ্যে Docker নিজে এবং [Docker Compose](https://docs.docker.com/compose/)-ও অন্তর্ভুক্ত।

ডিফল্টভাবে আপনার ব্যবহারকারী `docker` গ্রুপে *নেই*। সেই গ্রুপটি কার্যকরভাবে পাসওয়ার্ডবিহীন root — এর মধ্যে থাকা যেকোনো কিছু `docker run -v /:/host` চালিয়ে মেশিনটি দখল করে নিতে পারে — তাই আপনার হিসেবে চলা একটি দুষ্ট স্ক্রিপ্ট বা ডিপেন্ডেন্সি অন্যথায় root থেকে মাত্র একটি কমান্ড দূরে থাকত। তাই কমান্ড লাইনে আপনি `sudo` দিয়ে Docker চালান (`sudo docker ps`, `sudo docker compose up`), এবং ডিমনের সঙ্গে কথা বলা গ্রাফিক্যাল টুলগুলো — Windows VM — প্রয়োজনে অনুমোদন চায়। আপনি যদি গ্রুপবিহীন ব্যবস্থার সুবিধাটি ফিরে পেতে চান এবং বিনিময়টি বোঝেন, তাহলে **Setup > Security > Sudoless Docker** থেকে এটি সক্রিয় করুন (অথবা `omarchy-setup-security-sudoless-docker` চালান), যা একটি সতর্কবার্তার পর আপনাকে `docker` গ্রুপে যোগ করে; তারপর সাধারণ `docker` এবং `d` অ্যালিয়াস আবার `sudo` ছাড়াই কাজ করবে।

আপনি Omarchy মেনুতে _ইনস্টল > Development > Docker DB_ ব্যবহার করে Docker-এ স্থানীয় ডেভেলপমেন্টের জন্য সাধারণ ডাটাবেসগুলো সেট আপ করতে পারেন।

## GitHub CLI

[The GitHub CLI](https://cli.github.com/) আপনাকে আপনার GitHub অ্যাকাউন্ট দিয়ে প্রমাণীকরণ করতে এবং সেটি ব্যবহার করে প্রাইভেট রিপোজিটরি ক্লোন করতে দেয়। এটি অলসভাবে লোড হওয়া mise স্টাবগুলোর একটি হিসেবে যুক্ত আছে, তাই প্রথমবার আপনি `gh` চালালে, এটি নিজেই ইনস্টল হয়ে যায়। প্রমাণীকরণ করতে, `gh auth login` চালান। তারপর আপনি `gh repo clone org/repo` ব্যবহার করে প্রাইভেট রিপোজিটরি চেকআউট করতে পারেন।

এই কমান্ডটি ব্যবহার করে আপনি আরও অনেক GitHub কাজও করতে পারেন। কী কী সম্ভব তা দেখতে শুধু `gh` চালান।

TUI-তে আপনার পুল রিকোয়েস্টগুলো পরিচালনার জন্য `ghui`-এর একটি অলসভাবে ইনস্টল হওয়া স্টাবও আছে। আর [lazygit](https://github.com/jesseduffield/lazygit) আগে থেকেই ইনস্টল করা আছে, যদি আপনি git-কেও TUI থেকে চালাতে চান।
