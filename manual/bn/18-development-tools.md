# ডেভেলপমেন্ট টুলস

## বিকল্প এডিটর

নতুন ইনস্টলে Omarchy-তে ডিফল্ট এডিটর হিসেবে Plain থাকে এবং [Neovim](https://neovim.io/) আগে থেকে ইনস্টল করা থাকে, তবে আপনি যদি আরও বেশি মূলধারার ও পরিচিত কিছু চান, তাহলে Omarchy Menu (`Super + Space`) চালিয়ে _Install > Editor_-এর অধীনে থাকা বিকল্পগুলো দেখতে পারেন। সেখানে আমাদের তালিকায় VSCode, Cursor, Zed, Sublime Text, Helix, Vim এবং Emacs রয়েছে। আপনি যা খুঁজছেন তা না পেলে _Install > Package_ দেখুন, এবং কোনো Arch প্যাকেজে তা আছে কিনা দেখুন (আর না থাকলে AUR যাচাই করতে _Install > AUR_ চেষ্টা করুন)।

মূল `vi` এডিটরটিও একদম শুরু থেকেই পাওয়া যায়। টার্মিনালে কোনো ফাইল সম্পাদনা করতে `vi filename` চালান।

`VSCode`, `Cursor`, `VSCodium` এবং `Helix`-এর জন্য থিম মেলানোর সুবিধা দেওয়া হয়।

`Setup > Defaults > Editor`-এর অধীনে আপনি পুরো সিস্টেমের ডিফল্ট এডিটর সেট করতে পারেন।

## এনভায়রনমেন্ট

Omarchy Menu (`Super + Space`)-এর _Install > Development_ অংশের মাধ্যমে Omarchy নানা ধরনের ডেভেলপমেন্ট এনভায়রনমেন্ট সেট আপ করার সুবিধা দেয়। সেখানে অবশ্যই _Ruby on Rails_ পাবেন, তবে JavaScript-এর তিনটি প্রধান রানটাইমও (Node.js, Bun, Deno) পাবেন, সেই সঙ্গে Laravel ও Symfony-এর মতো জনপ্রিয় PHP ফ্রেমওয়ার্কও। ওহ, আর Go, Rust, Python, Java, Elixir (Phoenix সহ), .NET, OCaml, Zig, Clojure এবং Scala-ও আছে। নির্বাচনটা সত্যিই অনেক বিস্তৃত!

এই এনভায়রনমেন্টগুলোর বেশিরভাগই [Mise](https://mise.jdx.dev/) দিয়ে পরিচালিত হয়। এটি এমন একটি টুল যা দিয়ে আপনি একই মেশিনে একটি প্রোগ্রামিং ভাষার একাধিক সংস্করণ ইনস্টল ও চালাতে পারেন। এটি Ruby-র জন্য rbenv বা rvm কিংবা Python-এর জন্য virtualenv-এর মতো, তবে এটি নানা ধরনের এনভায়রনমেন্টের জন্য কাজ করে।

ধরুন Ruby ইনস্টল করতে, আপনি `mise use -g ruby` চালাবেন, যা Ruby ইনস্টলও করবে এবং এটিকে গ্লোবাল ডিফল্ট হিসেবেও সেট করবে। অথবা, আপনার প্রকল্পে যদি একটি .ruby-version ফাইল থাকে, তাহলে সেই প্রকল্পের মূলে শুধু `mise i` চালালেই হবে।

## আগে থেকে ইনস্টল করা CLI টুল

`uv`, Node.js এবং `playwright-cli` (এজেন্টদের ইনস্টল করা Chrome ব্যবহার করে একটি ব্রাউজার চালানোর জন্য) প্যাকেজ হিসেবে ইনস্টল করা থাকে, এবং `omarchy update` বাকি সিস্টেমের সঙ্গে এগুলোকে হালনাগাদ রাখে। `ghui`, [Hunk](https://github.com/modem-dev/hunk) এবং Basecamp, Cloudflare ও HEY CLI _Install > CLI_-এর অধীনে একটি বেছে নেওয়ার দূরত্বে রয়েছে, আর [কোডিং এজেন্ট](17-ai.md) রয়েছে _Install > AI > CLI_-এর অধীনে।

mise শুধু সেই রানটাইমগুলোই পরিচালনা করে যেগুলো আপনি _Install > Development_ থেকে সেট আপ করেন; Omarchy নিজে থেকে এর মাধ্যমে কিছুই ইনস্টল করে না। বাকি Omarchy-র সঙ্গে এগুলো হালনাগাদ করতে `omarchy update` চালান; `mup` অ্যালিয়াস শুধু mise দিয়ে পরিচালিত টুলগুলোই হালনাগাদ করে। আপনার নিজের কনফিগারেশনে আরেকটি টুল যোগ করতে `mise use -g <tool>` ব্যবহার করুন।

## Docker

[Docker](https://www.docker.com/)-এর আলাদা করে পরিচয় দেওয়ার দরকার প্রায় নেই বললেই চলে। এটি দিয়ে আপনি বিচ্ছিন্ন কন্টেইনার চালাতে পারেন, এবং Omarchy এটি ভালোভাবে চালানোর জন্য প্রয়োজনীয় সবকিছুই ইনস্টল করে, যার মধ্যে Docker নিজে এবং [Docker Compose](https://docs.docker.com/compose/)-ও রয়েছে।

ডিফল্টভাবে আপনার ব্যবহারকারী `docker` গ্রুপে *না* থাকে। ওই গ্রুপটি কার্যত পাসওয়ার্ডহীন root — এর মধ্যে থাকা যেকোনো কিছু `docker run -v /:/host` চালিয়ে মেশিন দখল করে নিতে পারে — তাই আপনার পরিচয়ে চলা একটিমাত্র দুর্বৃত্ত স্ক্রিপ্ট বা ডিপেনডেন্সি অন্যথায় root পাওয়া থেকে মাত্র একটি কমান্ড দূরে থাকত। তাই কমান্ড লাইনে আপনি Docker `sudo` দিয়ে চালান (`sudo docker ps`, `sudo docker compose up`), আর ডেমনের সঙ্গে কথা বলা গ্রাফিক্যাল টুলগুলো — Windows VM — প্রয়োজনের সময় আপনার কাছে অনুমোদন চায়। আপনি যদি গ্রুপহীন সেটআপের সুবিধা ফিরে পেতে চান এবং বিনিময়ের বিষয়টি বুঝে থাকেন, তাহলে **Setup > Security > Sudoless Docker** থেকে (অথবা `omarchy-setup-security-sudoless-docker` চালিয়ে) এটি সক্রিয় করুন, যা একটি সতর্কবার্তার পর আপনাকে `docker` গ্রুপে যোগ করে; তারপর সাধারণ `docker` এবং `d` অ্যালিয়াস আবার `sudo` ছাড়াই কাজ করবে।

Omarchy মেনুতে _Install > Development > Docker DB_ ব্যবহার করে আপনি Docker-এ স্থানীয় ডেভেলপমেন্টের জন্য সাধারণ ডাটাবেসগুলো সেট আপ করতে পারেন।

## GitHub CLI

[GitHub CLI](https://cli.github.com/) হলো `gh`, টার্মিনাল থেকে রিপোজিটরি, ইস্যু ও পুল রিকোয়েস্ট নিয়ে কাজ করার জন্য। _Setup > Git_ এটি ইনস্টল করে যখন আপনি সেখানে GitHub-এ সাইন ইন করা বেছে নেন, তারপর `gh repo clone org/repo` একটি রিপোজিটরি ক্লোন করে। এর কমান্ডগুলো জানতে `gh --help` চালান।

_Install > CLI > GitHub_ GitHub CLI, `gh` ইনস্টল করে, সেই সঙ্গে `ghui`-ও, যা পুল রিকোয়েস্টের জন্য একটি টার্মিনাল ইন্টারফেস। Git নিয়ে কাজ করার জন্য [Lazygit](https://github.com/jesseduffield/lazygit) আগে থেকে ইনস্টল করা থাকে।
