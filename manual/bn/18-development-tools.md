# ডেভেলপমেন্ট টুলস

## বিকল্প এডিটর

নতুন ইনস্টলে Omarchy-র ডিফল্ট এডিটর হিসেবে Plain থাকে এবং [Neovim](https://neovim.io/) আগে থেকে ইনস্টল করা থাকে, তবে আপনি যদি আরও মূলধারার ও পরিচিত কিছু চান, তাহলে Omarchy Menu (`Super + Space`) চালিয়ে _ইনস্টল > এডিটর_-এর অধীনে থাকা বিকল্পগুলো দেখতে পারেন। সেখানে VSCode, Cursor, Zed, Sublime Text, Helix, Vim এবং Emacs তালিকাভুক্ত আছে। আপনি যা খুঁজছেন তা যদি না পান, তাহলে _ইনস্টল > প্যাকেজ_ দেখুন এবং সেটি কোনো Arch প্যাকেজে আছে কিনা দেখুন (আর যদি না থাকে, তাহলে AUR যাচাই করতে _ইনস্টল > AUR_ চেষ্টা করুন)।

আসল `vi` এডিটরটিও একদম শুরু থেকেই পাওয়া যায়। টার্মিনালে কোনো ফাইল সম্পাদনা করতে `vi filename` চালান।

`VSCode`, `Cursor`, `VSCodium` এবং `Helix`-এর জন্য থিম মেলানোর সুবিধা দেওয়া হয়।

আপনি `Setup > Defaults > Editor`-এর অধীনে সিস্টেমজুড়ে ডিফল্ট এডিটর সেট করতে পারেন।

## এনভায়রনমেন্ট

Omarchy Menu (`Super + Space`)-এর _ইনস্টল > ডেভেলপমেন্ট_ অংশের মাধ্যমে Omarchy নানা ধরনের ডেভেলপমেন্ট এনভায়রনমেন্ট সেট আপ করা সমর্থন করে। সেখানে আপনি অবশ্যই _Ruby on Rails_ পাবেন, তবে JavaScript-এর তিনটি প্রধান রানটাইমও (Node.js, Bun, Deno) পাবেন, সেই সঙ্গে Laravel ও Symfony-এর মতো জনপ্রিয় PHP ফ্রেমওয়ার্কও। ওহ, আর Go, Rust, Python, Java, Elixir (Phoenix সহ), .NET, OCaml, Zig, Clojure এবং Scala-ও আছে। এটি সত্যিই অনেক বিস্তৃত একটি সংগ্রহ!

এই এনভায়রনমেন্টগুলোর বেশিরভাগই [Mise](https://mise.jdx.dev/) দিয়ে পরিচালিত হয়। এটি এমন একটি টুল যা দিয়ে আপনি একই মেশিনে একটি প্রোগ্রামিং ভাষার একাধিক সংস্করণ ইনস্টল ও চালাতে পারেন। এটি Ruby-র জন্য rbenv বা rvm-এর মতো, কিংবা Python-এর জন্য virtualenv-এর মতো, তবে এটি নানা ধরনের এনভায়রনমেন্টের জন্য কাজ করে।

উদাহরণস্বরূপ, Ruby ইনস্টল করতে আপনি `mise use -g ruby` চালাবেন, যা Ruby ইনস্টলও করবে এবং এটিকে গ্লোবাল ডিফল্ট হিসেবেও সেট করবে। অথবা, আপনার প্রকল্পে .ruby-version ফাইল থাকলে, সেই প্রকল্পের রুটে শুধু `mise i` চালালেই হবে।

## আগে থেকে ইনস্টল করা CLI টুলস

`uv`, Node.js এবং `playwright-cli` (এজেন্টদের দিয়ে ব্রাউজার চালানোর জন্য, ইনস্টল করা Chrome ব্যবহার করে) প্যাকেজ হিসেবে ইনস্টল করা থাকে, আর `omarchy update` সিস্টেমের বাকি অংশের সঙ্গে সেগুলোকে হালনাগাদ রাখে। [Hunk](https://github.com/modem-dev/hunk) এবং GitHub, Basecamp, Cloudflare ও HEY CLI _ইনস্টল > CLI_-এর অধীনে একবার বেছে নিলেই পাওয়া যায়, আর [কোডিং এজেন্ট](17-ai.md) পাওয়া যায় _ইনস্টল > AI > CLI_-এর অধীনে।

mise কেবল সেই রানটাইমগুলোই পরিচালনা করে যেগুলো আপনি _ইনস্টল > ডেভেলপমেন্ট_ থেকে সেট আপ করেন; Omarchy নিজে থেকে এর মাধ্যমে কিছুই ইনস্টল করে না। Omarchy-র বাকি অংশের সঙ্গে সেগুলো হালনাগাদ করতে `omarchy update` চালান; `mup` অ্যালিয়াসটি শুধু mise দিয়ে পরিচালিত টুলগুলো হালনাগাদ করে। আপনার নিজের কনফিগারেশনে আরেকটি টুল যোগ করতে `mise use -g <tool>` ব্যবহার করুন।

## Docker

[Docker](https://www.docker.com/)-এর পরিচিতি দেওয়ার তেমন প্রয়োজন নেই বললেই চলে। এটি দিয়ে আপনি বিচ্ছিন্ন কন্টেইনার চালাতে পারেন, আর Omarchy এটি ভালোভাবে চালানোর জন্য প্রয়োজনীয় সবকিছু ইনস্টল করে দেয়, যার মধ্যে Docker নিজে এবং [Docker Compose](https://docs.docker.com/compose/) অন্তর্ভুক্ত।

ডিফল্টভাবে আপনার ব্যবহারকারী `docker` গ্রুপে *নেই*। এই গ্রুপটি কার্যত পাসওয়ার্ডবিহীন root — এর মধ্যে থাকা যেকোনো কিছু `docker run -v /:/host` চালিয়ে পুরো মেশিনের দখল নিতে পারে — তাই আপনার পরিচয়ে চলা একটিমাত্র দুষ্ট স্ক্রিপ্ট বা ডিপেনডেন্সি অন্যথায় root পাওয়া থেকে মাত্র একটি কমান্ড দূরে থাকত। তাই কমান্ড লাইনে আপনি `sudo` দিয়ে Docker চালান (`sudo docker ps`, `sudo docker compose up`), আর যেসব গ্রাফিক্যাল টুল ডিমনের সঙ্গে কথা বলে — Windows VM — প্রয়োজন হলে সেগুলো অনুমোদন চায়। আপনি যদি গ্রুপবিহীন সেটআপের সুবিধাটি ফিরে চান এবং এর বিনিময়টা বোঝেন, তাহলে **সেটআপ > নিরাপত্তা > Sudoless Docker** থেকে এটি চালু করুন (অথবা `omarchy-setup-security-sudoless-docker` চালান), যা একটি সতর্কবার্তার পর আপনাকে `docker` গ্রুপে যোগ করে; তারপর সাধারণ `docker` এবং `d` অ্যালিয়াস আবার `sudo` ছাড়াই কাজ করবে।

Omarchy মেনুতে _ইনস্টল > ডেভেলপমেন্ট > Docker DB_ ব্যবহার করে আপনি স্থানীয় ডেভেলপমেন্টের জন্য প্রচলিত ডাটাবেসগুলো সেট আপ করতে পারেন।

## GitHub CLI

[GitHub CLI](https://cli.github.com/) হলো `gh`, টার্মিনাল থেকে রিপোজিটরি, ইস্যু এবং পুল রিকোয়েস্ট নিয়ে কাজ করার জন্য। আপনি সেখানে GitHub-এ সাইন ইন করা বেছে নিলে _সেটআপ > Git_ এটি ইনস্টল করে, অথবা _ইনস্টল > CLI > GitHub_ থেকে আলাদাভাবে এটি ইনস্টল করুন। তারপর `gh repo clone org/repo` একটি রিপোজিটরি ক্লোন করে; এর কমান্ডগুলো জানতে `gh --help` চালান।

[Lazygit](https://github.com/jesseduffield/lazygit) Git নিয়ে কাজ করার জন্য আগে থেকে ইনস্টল করা থাকে।
