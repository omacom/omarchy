# স্ক্রিনশট ও রেকর্ডিং

স্ক্রিন থেকে যা কিছু ধরা যায়, সবই Print Screen কী-কে ঘিরে। একা ওই কী-ই ছবি তোলে, আর মডিফায়ারগুলো নেয় রেকর্ডিং, কোনো রঙ, বা কোনো অঞ্চলের ভেতরের টেক্সট। আপনার কীবোর্ডে যদি Print Screen কী-ই না থাকে, `Super + Ctrl + Alt + C` একই স্ক্রিনশট নেয়, আর `Super + Ctrl + C` পুরো সেটটি মেনু হিসেবে খোলে।

| Hotkey | Function |
| ------ | -------- |
| `Print Screen` | স্ক্রিনশট |
| `Super + Ctrl + Alt + C` | স্ক্রিনশট |
| `Alt + Print Screen` | Screenrecord (অথবা চলমানটি বন্ধ করা) |
| `Super + Print Screen` | রঙ বাছাইকারী |
| `Super + Ctrl + Print Screen` | কোনো অঞ্চল থেকে টেক্সট বের করা |
| `Super + Ctrl + C` | ক্যাপচার মেনু |
| `Super + Ctrl + .` | কোনো ছবি বা ভিডিও ট্রান্সকোড করা |

## স্ক্রিনশট

`Print Screen` (অথবা `Super + Ctrl + Alt + C`) চাপুন, Omasnap তার ওভারলে আসার আগেই ফোকাস করা মনিটরটি ক্যাপচার করে, যাতে লক্ষ্য ঠিক করার সময় আপনার নিচে কিছু নড়ে না যায়।自由 একটি অঞ্চল টেনে আঁকুন, কোনো উইন্ডোতে ক্লিক করে সেটি ক্যাপচার করুন, বা খোলা জায়গায় ক্লিক করে পুরো মনিটরটি ক্যাপচার করুন। আঁকার আগে `S` চাপুন স্ক্রলিং অঞ্চল ক্যাপচার করতে। মন বদলে গেছে? Omasnap বন্ধ করতে আবার একই কী চাপুন।

কোনো এলাকা বাছার পর, Omasnap ক্যাপচারটি সংরক্ষণ করে, ক্লিপবোর্ডে কপি করে, এবং তার থাম্বনেইলসহ একটি বিজ্ঞপ্তি দেখায়, যেমনটা সংরক্ষিত স্ক্রিন রেকর্ডিং করে। সংরক্ষিত ছবিটি আপনার ইমেজ ভিউয়ারে দেখতে Open বাছুন, অথবা সেটিতে টীকা দিতে Edit বাছুন।

টীকা সম্পাদক তীর, রেখা, আকৃতি, হাইলাইট, সংখ্যাযুক্ত মার্কার, টেক্সট এবং সুরক্ষিত রিড্যাকশন আঁকতে পারে; ছবির অংশ ক্রপ বা কেটে বাদ দিতে পারে; তার টেক্সট OCR করতে পারে; এবং একটি ব্যাকড্রপ যোগ করতে পারে। সম্পাদকে, সমাপ্ত PNG কপি ও সংরক্ষণ করতে `Enter` চাপুন, সংরক্ষণ না করে কপি করতে `Ctrl + C` চাপুন, অথবা কপি না করে সংরক্ষণ করতে `Ctrl + S` চাপুন।

সংরক্ষিত স্ক্রিনশট ডিফল্টভাবে `~/Pictures/Screenshots`-এ যায়, `screenshot-2026-08-13_14-22-05-firefox.png`-এর মতো নাম নিয়ে। অন্য ডিরেক্টরি ব্যবহার করতে `OMASNAP_SCREENSHOT_DIR` সেট করুন — সেশন পরিবেশ ভেরিয়েবল কোথায় রাখবেন তা জানতে [FAQ](46-faq.md) দেখুন। প্রথম ছবি সংরক্ষণের সময় Omasnap ডিরেক্টরিটি তৈরি করে। স্বয়ংক্রিয় সংরক্ষণ বন্ধ করতে `~/.config/omasnap/omasnap.conf`-এ `[output] autosave = false` সেট করুন; তখন ক্যাপচার শুধু কপি হয়, এবং 10 সেকেন্ডের একটি প্রিভিউতে দেখানো হয় যা আপনি তার পিন বোতাম বা `Ctrl + P` দিয়ে স্ক্রিনে ধরে রাখতে পারেন।

টার্মিনাল থেকে, `omarchy screenshot` একই ওভারলে খোলে, এবং আপনি এর শুরুর মোড বাছতে পারেন: `omarchy capture screenshot region`, `windows`, `fullscreen`, অথবা `scroll`। `copy` বা `save`-এর দ্বিতীয় আর্গুমেন্ট ছবিটি সরাসরি সেই গন্তব্যে পাঠায়। আউটপুটের আগে সম্পাদনা করতে, পূর্ণস্ক্রিন সম্পাদকের জন্য `omarchy screenshot --editor=overlay` বা আলাদা উইন্ডোর জন্য `omarchy screenshot --editor=window` ব্যবহার করুন।

### কীবোর্ড থেকে পিকার চালানো

নির্বাচন চালু থাকা অবস্থায়, আপনাকে মোটেই মাউস ব্যবহার করতে হবে না:

| Key | Function |
| --- | -------- |
| `S` | স্ক্রলিং-অঞ্চল মোড টগল করা |
| `Super + Arrow keys` | Window মোডে উইন্ডোগুলোর মধ্যে যাওয়া |
| `Return` | হাইলাইট করা উইন্ডোটি ক্যাপচার করা |
| `Ctrl + A` | পূর্ণ ফোকাস করা মনিটরটি ক্যাপচার করা |
| `R` | এই সেশনে আঁকা শেষ অঞ্চলটি পুনরুদ্ধার করা |
| `Esc` | Omasnap বন্ধ করা |

এই বাইন্ডিংগুলো শুধু Omasnap খোলা থাকলেই থাকে, তাই আপনার নিজের কনফিগে কোনো কিছুর সঙ্গে এগুলোর সংঘর্ষ হতে পারে না।

## স্ক্রিন রেকর্ডিং

`Alt + Print Screen` _Trigger > Capture > Screenrecord_ খোলে, যা জিজ্ঞেস করে সাউন্ডট্র্যাকে আপনি কী চান: কোনো অডিও নেই, ডেস্কটপ অডিও, ডেস্কটপ প্লাস মাইক্রোফোন, বা ডেস্কটপ প্লাস মাইক্রোফোন প্লাস ওয়েবক্যাম। শেষেরটি শুধু তখনই দেখায় যদি আপনার সত্যিই একটি ক্যামেরা লাগানো থাকে। একটি বাছুন, আর Omarchy-র রেকর্ডিং পিকার আপনাকে একটি অঞ্চল টানতে বা কোনো উইন্ডো বা মনিটরে ক্লিক করতে দেয়।

রেকর্ডিং gpu-screen-recorder-এ চলে, যা GPU-তে 60fps-এ এনকোড করে এবং প্রয়োজনে CPU-তে ফিরে যায়। ফলাফলটি `~/Videos`-এ একটি MP4, যার নাম `screenrecording-2026-08-13_14-22-05.mp4`। তা বদলাতে `OMARCHY_SCREENRECORD_DIR` সেট করুন — তবে মনে রাখবেন স্ক্রিনশট ডিরেক্টরির মতো নয়, এটি আগে থেকেই থাকতে হবে, নাহলে রেকর্ডিং শুরু হতে অস্বীকার করে।

আপনি যখন রেকর্ড করছেন, বারে একটি ছোট নির্দেশক দেখা যায়। বন্ধ করতে সেটিতে ক্লিক করুন। আপনি আবার `Alt + Print Screen` দিয়েও বন্ধ করতে পারেন, অথবা _Trigger > Capture > Screenrecord_-এর অধীনে _Stop Screenrecording_ এন্ট্রি দিয়ে, যা শুধু তখনই দেখায় যখন সত্যিই কিছু রেকর্ড হচ্ছে।

বন্ধ করা ফাইলটি আপনার হাতে দেওয়ার আগে একটু গোছগাছ করে: প্রথম ফ্রেমটি ছেঁটে ফেলা হয়, এবং অডিও থাকলে তা -14 LUFS-এ নরমালাইজ করা হয়, একেবারে শুরুতে PipeWire ক্যাপচারের পপ শব্দটি মিউট করে দেওয়া হয়। তারপর রেকর্ডিং থেকে একটি থাম্বনেইলসহ একটি বিজ্ঞপ্তি আসে। mpv-তে ফাইলটি চালাতে সেটিতে ক্লিক করুন।

### ওয়েবক্যাম ওভারলে

আপনি যখন ওয়েবক্যাম দিয়ে রেকর্ড করেন, ক্যামেরাটি আপনি যা রেকর্ড করছেন তার নিচের-ডান কোণায় একটি পিন করা, ক্রপ করা পোর্ট্রেট উইন্ডো হিসেবে দেখা যায়। এটি যদি আপনার প্রয়োজনীয় কিছুর ওপরে বসে থাকে, চলতে চলতেই এর আকার বদলান:

| Hotkey | Function |
| ------ | -------- |
| `Super + Alt + [` | ওয়েবক্যাম ওভারলে ছোট করা |
| `Super + Alt + ]` | ওয়েবক্যাম ওভারলে বড় করা |

তিনটি আকার আছে — ছোট, মাঝারি, এবং বড় — এবং হটকীগুলো তাদের মধ্যে ধাপে ধাপে যায়। মাঝারি হলো ডিফল্ট। এগুলো রেকর্ডিংয়ের আনুপাতিক, তাই আপনি 1080p মনিটর রেকর্ড করুন বা 6K মনিটর, ক্যামেরা ফ্রেমের একই অংশ জুড়ে থাকে। আর আপনি যদি পুরো ডিসপ্লের বদলে একটি অঞ্চল রেকর্ড করে থাকেন, ওভারলেটি মনিটরের কোণার বদলে ওই অঞ্চলের কোণায় নোঙর করে, যাতে এটি ছবির ভেতরেই থাকে।

আপনি সরাসরি `omarchy-capture-webcam-resize small` দিয়েও এটি ডাকতে পারেন, অথবা মাঝারিতে ফিরে যেতে `reset` ব্যবহার করতে পারেন।

## টেক্সট, QR কোড, এবং রঙ

`Super + Ctrl + Print Screen` একটি অঞ্চল বাছে এবং তা OCR করে ক্লিপবোর্ডে পাঠায়। এটি [টেক্সট এক্সট্রাকশন ও ডিক্টেশন](11-text-extraction-dictation.md)-এ যথাযথভাবে আলোচনা করা হয়েছে।

_Trigger > Capture > QR Code_ QR কোডের জন্য একই কৌশল করে। কোডটি আছে এমন অঞ্চলটি বাছুন, আর ডিকোড করা মান ক্লিপবোর্ডে যায়। এটি শুধু QR কোডই খোঁজে — ঘন স্ক্রিন বিষয়বস্তু অন্যথায় বারকোড হিসেবে ভুল-পজিটিভ হওয়ার অভ্যাস রাখে। জেনে রাখা ভালো: ডিকোড করা মান ক্লিপবোর্ডে যায় এবং অন্য কোথাও নয়। এটি ছাপা হয় না, এটি বিজ্ঞপ্তিতে থাকে না, এবং এটি সংবেদনশীল হিসেবে চিহ্নিত, যাতে এটি [ক্লিপবোর্ড ইতিহাস](08-unified-clipboard-history.md)-এ আটকে না থাকে। QR কোড নিয়মিত গোপন তথ্য বহন করে — যেমন 2FA সেটআপ কোডের পেছনের `otpauth://` URI — এবং আপনি তা কোনো লগে চান না। পেস্ট করা তবু ঠিকঠাক কাজ করে।

`Super + Print Screen` (অথবা _Trigger > Capture > Color_) কার্সরকে আইড্রপারে পরিণত করে। স্ক্রিনে যেকোনো কিছুতে ক্লিক করুন আর রঙটি ক্লিপবোর্ডে যায়। না বেছে বেরিয়ে আসতে আবার হটকী চাপুন।

## শেয়ার করার আগে ট্রান্সকোড করা

একটি 4K স্ক্রিন রেকর্ডিং বা আপনার ফোন থেকে আসা কাঁচা HEIC প্রায়ই শুধু পাঠিয়ে দেওয়ার জন্য খুব বড় হয়। `Super + Ctrl + .` (অথবা _Trigger > Transcode_) তা ঠিক করে। এটি আপনাকে `~/Pictures` এবং `~/Videos`-এর ওপর একটি ফাজি ফাইল পিকার দেয়, তারপর একটি ফরম্যাট ও একটি আকার জিজ্ঞেস করে।

ছবি high, medium, বা low-তে jpg বা png-তে যায়, যা প্রস্থকে 3160, 2160, এবং 1080 পিক্সেলে সীমাবদ্ধ করে। ভিডিও 4k, 1080p, বা 720p-তে mp4 বা একটি অ্যানিমেটেড gif-এ যায়। রূপান্তরিত ফাইলটি মূলটির পাশে নামে রেজোলিউশনসহ লেখা হয় — `demo-1080p.mp4` — এবং পথটি ফাইল URI হিসেবে ক্লিপবোর্ডে কপি হয়, যাতে আপনি ফাইল ড্রপ নেয় এমন অ্যাপে সরাসরি পেস্ট করতে পারেন।

আপনি ইতিমধ্যে কী চান জানলে এটি টার্মিনাল থেকেও কাজ করে: `omarchy transcode ~/Videos/demo.mov mp4 1080p`। আরও আছে `omarchy transcode ascii`, যা একটি ছবিকে ASCII আর্টে পরিণত করে — সেটি মূলত [ব্র্যান্ডিং](41-branding.md)-এর জন্য।

## কোথাও পাঠানো

ফাইলটি পেয়ে গেলে, `Super + Ctrl + S` Share মেনু খোলে এবং LocalSend দিয়ে আপনার নেটওয়ার্কের অন্য ডিভাইসে তা পাঠায়। তার জন্য [GUIs](22-guis.md) দেখুন।
