# স্ক্রিনশট ও রেকর্ডিং

স্ক্রিন থেকে যা কিছু তুলতে পারবেন, সবই Print Screen কির ওপর নির্ভর করে। কিটি একা চাপলে একটি ছবি ওঠে, আর মডিফায়ারগুলো নেয় একটি রেকর্ডিং, একটি রঙ, অথবা একটি অঞ্চলের ভেতরের টেক্সট। আপনার কিবোর্ডে যদি Print Screen কিই না থাকে, `Super + Ctrl + Alt + C` একই স্ক্রিনশট নেয়, এবং `Super + Ctrl + C` পুরো সেটটি একটি মেনু হিসেবে খোলে।

| Hotkey | Function |
| ------ | -------- |
| `Print Screen` | স্ক্রিনশট |
| `Super + Ctrl + Alt + C` | স্ক্রিনশট |
| `Alt + Print Screen` | স্ক্রিনরেকর্ড (অথবা চলমানটি বন্ধ করুন) |
| `Super + Print Screen` | রঙ বাছাইকারী |
| `Super + Ctrl + Print Screen` | একটি অঞ্চল থেকে টেক্সট বের করুন |
| `Super + Ctrl + C` | ক্যাপচার মেনু |
| `Super + Ctrl + .` | একটি ছবি বা ভিডিও ট্রান্সকোড করুন |

## স্ক্রিনশট

`Print Screen` (অথবা `Super + Ctrl + Alt + C`) চাপুন এবং Omasnap এর ওভারলে আসার আগেই ফোকাস করা মনিটরটি ক্যাপচার করে, তাই লক্ষ্য ঠিক করার সময় আপনার নিচে কিছুই নড়ে না। একটি ফ্রিফর্ম অঞ্চল টেনে নির্বাচন করুন, সেটি ক্যাপচার করতে একটি উইন্ডোতে ক্লিক করুন, অথবা পুরো মনিটর ক্যাপচার করতে খোলা জায়গায় ক্লিক করুন। একটি স্ক্রলিং অঞ্চল ক্যাপচার করতে আঁকার আগে `S` চাপুন। মত বদলেছেন? Omasnap বন্ধ করতে একই কিটি আবার চাপুন।

একটি এলাকা নির্বাচন করার পর, Omasnap ক্যাপচারটি সংরক্ষণ করে, ক্লিপবোর্ডে কপি করে, এবং একটি সংরক্ষিত স্ক্রিন রেকর্ডিং যেমন করে, তেমনই এর থাম্বনেইলসহ একটি বিজ্ঞপ্তি দেখায়। সংরক্ষিত ছবিটি আপনার ইমেজ ভিউয়ারে দেখতে Open বেছে নিন, অথবা সেটিতে টীকা যোগ করতে Edit বেছে নিন।

টীকা সম্পাদক তির, রেখা, আকৃতি, হাইলাইট, সংখ্যাযুক্ত মার্কার, টেক্সট এবং নিরাপদ রিড্যাকশন আঁকতে পারে; ছবির অংশ ক্রপ বা কেটে বাদ দিতে পারে; এর টেক্সট OCR করতে পারে; এবং একটি ব্যাকড্রপ যোগ করতে পারে। সম্পাদকে, সমাপ্ত PNG কপি ও সংরক্ষণ করতে `Enter` চাপুন, সংরক্ষণ না করে কপি করতে `Ctrl + C` চাপুন, অথবা কপি না করে সংরক্ষণ করতে `Ctrl + S` চাপুন।

সংরক্ষিত স্ক্রিনশটগুলো ডিফল্টভাবে `~/Pictures/Screenshots`-এ যায়, যার নাম হয় যেমন `screenshot-2026-08-13_14-22-05-firefox.png`। অন্য ডিরেক্টরি ব্যবহার করতে `OMASNAP_SCREENSHOT_DIR` সেট করুন — সেশন পরিবেশ চলকগুলো কোথায় রাখবেন তা জানতে [FAQ](46-faq.md) দেখুন। প্রথম ছবিটি সংরক্ষণের সময় Omasnap ডিরেক্টরিটি তৈরি করে। স্বয়ংক্রিয় সংরক্ষণ বন্ধ করতে `~/.config/omasnap/omasnap.conf`-এ `[output] autosave = false` সেট করুন; তখন ক্যাপচারগুলো শুধু কপি করা হয়, এবং 10 সেকেন্ডের জন্য একটি প্রিভিউতে দেখানো হয়, যা আপনি এর পিন বোতাম অথবা `Ctrl + P` দিয়ে স্ক্রিনে ধরে রাখতে পারেন।

টার্মিনাল থেকে, `omarchy screenshot` একই ওভারলে খোলে, এবং আপনি এর শুরুর মোড বেছে নিতে পারেন: `omarchy capture screenshot region`, `windows`, `fullscreen`, অথবা `scroll`। `copy` অথবা `save`-এর দ্বিতীয় আর্গুমেন্ট ছবিটি সরাসরি সেই গন্তব্যে পাঠায়। আউটপুটের আগে সম্পাদনা করতে, পূর্ণস্ক্রিন সম্পাদকের জন্য `omarchy screenshot --editor=overlay` অথবা একটি আলাদা উইন্ডোর জন্য `omarchy screenshot --editor=window` ব্যবহার করুন।

### কিবোর্ড থেকে পিকার চালানো

সিলেকশন চালু থাকা অবস্থায়, আপনাকে মোটেও মাউস ব্যবহার করতে হবে না:

| Key | Function |
| --- | -------- |
| `S` | স্ক্রলিং-অঞ্চল মোড টগল করুন |
| `Super + Arrow keys` | Window মোডে উইন্ডোগুলোর মধ্যে যান |
| `Return` | হাইলাইট করা উইন্ডোটি ক্যাপচার করুন |
| `Ctrl + A` | সম্পূর্ণ ফোকাস করা মনিটরটি ক্যাপচার করুন |
| `R` | এই সেশনে আঁকা শেষ অঞ্চলটি পুনরুদ্ধার করুন |
| `Esc` | Omasnap বন্ধ করুন |

এই বাইন্ডিংগুলো শুধু Omasnap খোলা থাকলেই থাকে, তাই এগুলো আপনার নিজের কনফিগের কোনো কিছুর সঙ্গে সংঘর্ষ করতে পারে না।

## স্ক্রিন রেকর্ডিং

`Alt + Print Screen` _Trigger > Capture > Screenrecord_ খোলে, যা জিজ্ঞেস করে আপনি সাউন্ডট্র্যাকে কী চান: কোনো অডিও নয়, ডেস্কটপ অডিও, ডেস্কটপ প্লাস মাইক্রোফোন, অথবা ডেস্কটপ প্লাস মাইক্রোফোন প্লাস ওয়েবক্যাম। শেষটি শুধু তখনই দেখা যায় যদি সত্যিই একটি ক্যামেরা প্লাগ ইন করা থাকে। একটি বেছে নিন এবং Omarchy-এর রেকর্ডিং পিকার আপনাকে একটি অঞ্চল টেনে নির্বাচন করতে বা একটি উইন্ডো বা মনিটরে ক্লিক করতে দেয়।

রেকর্ডিং gpu-screen-recorder-এ চলে, যা GPU-তে 60fps-এ এনকোড করে এবং দরকার হলে CPU-তে ফিরে যায়। ফলাফলটি `~/Videos`-এ একটি MP4, যার নাম `screenrecording-2026-08-13_14-22-05.mp4`। তা বদলাতে `OMARCHY_SCREENRECORD_DIR` সেট করুন — তবে মনে রাখবেন, স্ক্রিনশট ডিরেক্টরির মতো নয়, এটি আগে থেকেই থাকতে হবে, নাহলে রেকর্ডিং শুরু হতে অস্বীকৃতি জানাবে।

রেকর্ডিং করার সময়, বারে একটি ছোট নির্দেশক দেখা যায়। বন্ধ করতে সেটিতে ক্লিক করুন। আপনি আবার `Alt + Print Screen` দিয়েও বন্ধ করতে পারেন, অথবা _Trigger > Capture > Screenrecord_-এর অধীনে _Stop Screenrecording_ এন্ট্রি দিয়ে, যা শুধু তখনই দেখা যায় যখন সত্যিই কিছু রেকর্ড হচ্ছে।

বন্ধ করা ফাইলটি আপনার হাতে দেওয়ার আগে একটু গুছিয়ে নেয়: প্রথম ফ্রেমটি ছেঁটে ফেলা হয়, এবং অডিও থাকলে তা -14 LUFS-এ নরমালাইজ করা হয়, একেবারে শুরুতে PipeWire ক্যাপচারের পপ শব্দটি মিউট করে দেওয়া হয়। তারপর রেকর্ডিং থেকে একটি থাম্বনেইলসহ একটি বিজ্ঞপ্তি আসে। Omaview-তে ফাইলটি চালাতে সেটিতে ক্লিক করুন।

### ওয়েবক্যাম ওভারলে

যখন আপনি একটি ওয়েবক্যাম দিয়ে রেকর্ড করেন, ক্যামেরাটি আপনি যা রেকর্ড করছেন তার নিচের-ডান কোণে একটি পিন করা, ক্রপ করা পোর্ট্রেট উইন্ডো হিসেবে দেখা যায়। এটি যদি আপনার দরকারি কোনো কিছুর ওপরে বসে থাকে,即时ভাবে এর আকার বদলান:

| Hotkey | Function |
| ------ | -------- |
| `Super + Alt + [` | ওয়েবক্যাম ওভারলে ছোট করুন |
| `Super + Alt + ]` | ওয়েবক্যাম ওভারলে বড় করুন |

তিনটি আকার আছে — ছোট, মাঝারি, এবং বড় — এবং হটকিগুলো সেগুলোর মধ্যে ধাপে ধাপে যায়। মাঝারিটি ডিফল্ট। এগুলো রেকর্ডিংয়ের অনুপাতে থাকে, তাই আপনি একটি 1080p মনিটর রেকর্ড করুন বা একটি 6K মনিটর, ক্যামেরা ফ্রেমের একই অংশ নেয়। আর আপনি যদি পুরো ডিসপ্লের বদলে একটি অঞ্চল রেকর্ড করে থাকেন, ওভারলেটি মনিটরের কোণের বদলে সেই অঞ্চলের কোণে নোঙর করে, তাই এটি ছবির ভেতরেই থাকে।

আপনি সরাসরি `omarchy-capture-webcam-resize small` দিয়েও এটি ডাকতে পারেন, অথবা মাঝারিতে ফিরে যেতে `reset` ব্যবহার করতে পারেন।

## টেক্সট, QR কোড, এবং রঙ

`Super + Ctrl + Print Screen` একটি অঞ্চল নির্বাচন করে এবং তা OCR করে ক্লিপবোর্ডে পাঠায়। তা [টেক্সট এক্সট্রাকশন ও ডিকটেশন](11-text-extraction-dictation.md)-এ ঠিকমতো আলোচনা করা হয়েছে।

_Trigger > Capture > QR Code_ QR কোডের জন্যও একই কৌশল করে। কোডটি আছে এমন অঞ্চলটি নির্বাচন করুন, এবং ডিকোড করা মানটি ক্লিপবোর্ডে যায়। এটি শুধু QR কোডই খোঁজে — নাহলে ঘন স্ক্রিন কনটেন্টের বারকোড হিসেবে ভুলভাবে চিহ্নিত হওয়ার অভ্যাস আছে। জেনে রাখা ভালো: ডিকোড করা মানটি ক্লিপবোর্ডে যায়, আর কোথাও নয়। এটি ছাপা হয় না, এটি বিজ্ঞপ্তিতে থাকে না, এবং এটি সংবেদনশীল হিসেবে চিহ্নিত থাকে যাতে এটি [ক্লিপবোর্ডের ইতিহাসে](08-unified-clipboard-history.md) থেকে না যায়। QR কোড নিয়মিত গোপন তথ্য বহন করে — যেমন একটি 2FA সেটআপ কোডের পেছনের `otpauth://` URI — এবং আপনি তা কোনো লগে চান না। পেস্ট করা তবু ঠিকঠাক কাজ করে।

`Super + Print Screen` (অথবা _Trigger > Capture > Color_) কার্সরকে একটি আইড্রপারে পরিণত করে। স্ক্রিনের যেকোনো কিছুতে ক্লিক করুন এবং রঙটি ক্লিপবোর্ডে যাবে। না বেছে বেরিয়ে আসতে হটকিটি আবার চাপুন।

## শেয়ার করার আগে ট্রান্সকোডিং

একটি 4K স্ক্রিন রেকর্ডিং অথবা আপনার ফোন থেকে আসা একটি কাঁচা HEIC প্রায়ই শুধু পাঠিয়ে দেওয়ার জন্য খুব বড় হয়। `Super + Ctrl + .` (অথবা _Trigger > Transcode_) তা ঠিক করে। এটি আপনাকে `~/Pictures` এবং `~/Videos` জুড়ে একটি ফাজি ফাইল পিকার দেয়, তারপর একটি ফরম্যাট এবং একটি আকার জিজ্ঞেস করে।

ছবিগুলো jpg বা png-তে high, medium, অথবা low-তে যায়, যা প্রস্থকে 3160, 2160, এবং 1080 পিক্সেলে সীমাবদ্ধ করে। ভিডিওগুলো mp4 বা একটি অ্যানিমেটেড gif-এ 4k, 1080p, অথবা 720p-তে যায়। রূপান্তরিত ফাইলটি মূলটির পাশেই রেজোলিউশন নামে লিখে রাখা হয় — `demo-1080p.mp4` — এবং পাথটি একটি ফাইল URI হিসেবে ক্লিপবোর্ডে কপি করা হয়, তাই আপনি সরাসরি ফাইল ড্রপ নেয় এমন একটি অ্যাপে তা পেস্ট করতে পারেন।

আপনি ইতিমধ্যে কী চান তা জানলে এটি টার্মিনাল থেকেও কাজ করে: `omarchy transcode ~/Videos/demo.mov mp4 1080p`। আরও আছে `omarchy transcode ascii`, যা একটি ছবিকে ASCII আর্টে পরিণত করে — সেটি মূলত [ব্র্যান্ডিংয়ের](41-branding.md) জন্য।

## কোথাও পাঠানো

ফাইলটি পেয়ে গেলে, `Super + Ctrl + S` Share মেনু খোলে এবং LocalSend দিয়ে আপনার নেটওয়ার্কের অন্য একটি ডিভাইসে তা পাঠায়। তার জন্য [GUIs](22-guis.md) দেখুন।
