# হটকি

আপনি `Super + K` দিয়ে সব প্রধান কীবোর্ড বাইন্ডিং দেখতে পারবেন (Tmux বাইন্ডিং `Super + Alt + K` দিয়ে এবং Herdr বাইন্ডিং `Super + Ctrl + K` দিয়ে)।

## হটকিগুলো কীভাবে সাজানো

প্রতিটি হটকি একটি প্লেনে থাকে, যা তার মডিফায়ার দিয়ে নির্ধারিত হয়, এবং প্রতিটি প্লেনের একটি কাজ থাকে। এভাবেই হটকিগুলো একে অপরের সঙ্গে গুলিয়ে যায় না, এবং এর মানে হলো আপনি সাধারণত অনুমান করতে পারবেন কোনটা কোথায় আছে।

| প্লেন | সেখানে যা থাকে | উদাহরণ |
| --- | --- | --- |
| `Super + key` | সিস্টেম: উইন্ডো, ওয়ার্কস্পেস, লেআউট এবং মূল মেনুগুলো | `Super + Space` Omarchy মেনু, `Super + W` উইন্ডো বন্ধ করুন, `Super + F` পূর্ণ স্ক্রিন |
| `Super + Shift + key` | অ্যাপ | `Super + Shift + B` ব্রাউজার, `Super + Shift + E` ইমেল, `Super + Shift + N` এডিটর |
| `Super + Ctrl + key` | প্যানেল ও সিস্টেম মেনু | `Super + Ctrl + A` অডিও, `Super + Ctrl + N` নেটওয়ার্ক, `Super + Ctrl + C` ক্যাপচার মেনু |
| `Super + Ctrl + Alt + key` | দ্রুত অ্যাকশন ও নোটিস | `Super + Ctrl + Alt + T` সময় দেখান, `Super + Ctrl + Alt + B` ব্যাটারি, `Super + Ctrl + Alt + C` স্ক্রিনশট |

কোনো হটকিতে `Alt` যোগ করলে আপনি একই জিনিসের একটি ভ্যারিয়েন্ট পাবেন, কখনোই সম্পর্কহীন কিছু নয়:

- `Super + Shift + B` ব্রাউজার খোলে; `Super + Shift + Alt + B` একটি প্রাইভেট উইন্ডো খোলে
- `Super + Shift + E` ইমেল খোলে; `Super + Shift + Alt + E` একটি নতুন ইমেল শুরু করে
- `Super + F` পূর্ণ স্ক্রিনে যায়; `Super + Alt + F` পূর্ণ প্রস্থে যায়
- `Super + Ctrl + C` ক্যাপচার মেনু খোলে; `Super + Ctrl + Alt + C` মেনু এড়িয়ে স্ক্রিনশট নেয়

হটকি যোগ করার সময়:

1. এটি কী করে তা থেকে প্লেন বাছুন, তারপর কি বাছুন।
2. জায়গা করার জন্য বিদ্যমান হটকি সরাবেন না। সঠিক প্লেনে একটি খালি কি খুঁজুন।
3. `Alt` শুধুমাত্র এটি ছাড়া হটকির ভ্যারিয়েন্টের জন্যই ব্যবহার করুন।

সুবিধাজনক বলে কয়েকটি হটকি এই নিয়ম ভাঙে। তীর বা `Tab`-এর সঙ্গে `Shift` অ্যাপ খোলার বদলে সরায় বা উল্টো দিকে যায়, এবং `Print`, মিডিয়া কিগুলো, `Alt + Tab`, এবং `Ctrl + Alt + Del` অন্য সব জায়গার মতোই কাজ করে। এগুলো ব্যতিক্রম, অনুকরণ করার প্যাটার্ন নয়।

কোনো ডিফল্ট আপনার পছন্দ না হলে (ধরুন Windows-এর মতো স্ক্রিনশটের জন্য আপনি `Super + Shift + S` চান), `~/.config/hypr/bindings.lua`-তে এটি রিবাইন্ড করুন।

টাচপ্যাডে, তিন ও চার আঙুলের সোয়াইপ ওয়ার্কস্পেস বদলায়, উইন্ডো সরায়, এবং মেনু ও Quake কনসোল খোলে; অঙ্গভঙ্গির জন্য [কীবোর্ড, মাউস ও ট্র্যাকপ্যাড](34-keyboard-mouse-trackpad.md) দেখুন।

রিসাইজ শর্টকাটগুলো ফিজিক্যাল কি `code:20` এবং `code:21` (XKB `<AE11>` এবং `<AE12>`) ব্যবহার করে, কীবোর্ডে ছাপানো অক্ষর যাই হোক না কেন। US কীবোর্ডে এই কিগুলো `-` এবং `=`; জাপানি (JIS) কীবোর্ডে এগুলো `-` এবং `^`; স্প্যানিশ কীবোর্ডে এগুলো `'` এবং `¡`। JIS-এ, `Super + ^` হলো `Super + Equal`, আবার `Super + Shift + -` (যা `=` টাইপ করে) হলো `Super + Shift + Minus`।

সম্পূর্ণ ইমোজি পিকার দেখাতে আপনি `Super + Ctrl + E` ব্যবহার করতে পারেন, যা নির্বাচনটি ক্লিপবোর্ডে রাখবে, অথবা আপনি এই দ্রুত অ্যাক্সেস বিকল্পগুলো ব্যবহার করতে পারেন।

## দ্রুত কমপ্লিশন

| হটকি       | কমপ্লিশন       |
| ------------ |  ---------- |
| `Shift + CapsLock Space Space` | — (mdash)   |
| `Shift + CapsLock Space N` | আপনার নাম (সেটাপের সময় যেমন দেওয়া হয়েছিল)  |
| `Shift + CapsLock Space E` | আপনার ইমেল (সেটাপের সময় যেমন দেওয়া হয়েছিল)  |

`~/.XCompose` সম্পাদনা করে আপনি নিজের আরও যোগ করতে পারেন, তারপর পরিবর্তনগুলো কার্যকর করতে টার্মিনালে `omarchy restart xcompose` চালান।
