# হটকি

আপনি `Super + K` দিয়ে প্রধান সব কিবোর্ড বাইন্ডিং দেখতে পারেন (Tmux বাইন্ডিং `Super + Alt + K` দিয়ে এবং Herdr বাইন্ডিং `Super + Ctrl + K` দিয়ে)।

## নেভিগেশন

| হটকি                  | কার্যকারিতা              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy মেনু (অ্যাপ ও অন্য সবকিছু)    |
| `Super + Alt + Space` | অ্যাপ গ্রিড |
| `Super + Escape` | সিস্টেম মেনু (সাসপেন্ড, পুনরায় চালু, ইত্যাদি)  |
| `Super + Ctrl + L` | কম্পিউটার লক করা |
| `Super + W` অথবা `Super + Q` | উইন্ডো বন্ধ করা             |
| `Ctrl + Alt + Del` | সব উইন্ডো বন্ধ করা |
| `Super + T`               | উইন্ডোকে টাইলিং/ভাসমানে টগল করা             |
| `Super + J` | উইন্ডোর অবস্থান টগল করা (অনুভূমিক/উল্লম্ব) |
| `Super + O`               | উইন্ডোকে স্টিকি ও ভাসমানে পপ করা টগল করা |
| `Super + L`               | dwindle, স্ক্রলিং ও ভাসমান লেআউটের মধ্য দিয়ে পালাক্রমে যাওয়া |
| `Super + Alt + L`         | উল্টো ক্রমে লেআউটের মধ্য দিয়ে যাওয়া |
| `Super + P`               | সিউডো উইন্ডো স্টাইল টগল করা (স্বাভাবিক বনাম প্রসারিত) |
| `Super + F`                 | পূর্ণস্ক্রিনে যাওয়া              |
| `Super + Alt + F`                 | পূর্ণ প্রস্থে যাওয়া              |
| `Super + Ctrl + F`                 | উইন্ডোর ভিতরে পূর্ণস্ক্রিনে যাওয়া              |
| `Super + 1/2/3/4`         | নির্দিষ্ট ওয়ার্কস্পেসে যাওয়া     |
| `Super + Tab` | পরের ওয়ার্কস্পেসে যাওয়া |
| `Super + Shift + Tab` | আগের ওয়ার্কস্পেসে যাওয়া |
| `Super + Ctrl + Tab` | পূর্ববর্তী ওয়ার্কস্পেসে যাওয়া |
| `Super + Shift + 1/2/3/4` | উইন্ডোকে ওয়ার্কস্পেসে সরানো |
| `Super + Shift + Alt + 1/2/3/4` | অনুসরণ না করে উইন্ডোকে ওয়ার্কস্পেসে সরানো |
| `Super + S` / `Super + Grave` | স্ক্র্যাচপ্যাড টগল করা |
| `Super + Alt + S` / `Super + Shift + Grave` | উইন্ডোকে স্ক্র্যাচপ্যাডে সরানো |
| `Super + Shift + Alt + Arrows` | ওয়ার্কস্পেসকে নির্দেশিত মনিটরে সরানো |
| `Super + Arrow`  | তীরচিহ্নের দিকে থাকা উইন্ডোতে ফোকাস সরানো              |
| `Super + Shift + Arrow`  | তীরচিহ্নের দিকে থাকা অন্য উইন্ডোর সঙ্গে অদলবদল করা     |

| `Super + Alt + Home` | উইন্ডোর প্রস্থ সংরক্ষণ করা |
| `Super + Home` | সংরক্ষিত উইন্ডোর প্রস্থ ফিরিয়ে আনা |
| `Super + Left Mouse` | উইন্ডো টেনে ঘোরানো |
| `Super + Right Mouse` | উইন্ডোর আকার বদলানো |
| `Super + Scroll Wheel` | ওয়ার্কস্পেসের মধ্য দিয়ে স্ক্রল করা |
| `Super + G`               | উইন্ডোর গোষ্ঠীবদ্ধকরণ টগল করা      |

| `Super + Alt + 1/2/3/4/5`               | গোষ্ঠীর নির্দিষ্ট উইন্ডোতে যাওয়া      |
| `Super + Alt + Arrow`  | তীরচিহ্নের দিকে উইন্ডোকে গোষ্ঠীতে সরানো  |
| `Super + Ctrl + Left/Right`  | টাইলিং গোষ্ঠীর ভিতরে উইন্ডোগুলোর মধ্যে যাওয়া |
| `Super + Ctrl + Z` | স্ক্রিনে জুম ইন করা (আরও জুমের জন্য আবার চাপুন) |
| `Super + Ctrl + Alt + Z` | স্ক্রিন থেকে পুরোপুরি জুম আউট করা |
| `Super + /` | মনিটর স্কেলিং বিকল্পের মধ্য দিয়ে এগিয়ে যাওয়া |
| `Super + Alt + /` | মনিটর স্কেলিং বিকল্পের মধ্য দিয়ে পিছিয়ে যাওয়া |
| `Alt + Tab` | সক্রিয় ওয়ার্কস্পেসের উইন্ডোগুলোর মধ্য দিয়ে এগিয়ে ঘোরা |
| `Alt + Shift + Tab` | সক্রিয় ওয়ার্কস্পেসের উইন্ডোগুলোর মধ্য দিয়ে পিছিয়ে ঘোরা |
| `Ctrl + Alt + Tab`| মনিটরগুলোর মধ্য দিয়ে ফোকাস এগিয়ে ঘোরানো |
| `Ctrl + Alt + Shift + Tab`| মনিটরগুলোর মধ্য দিয়ে ফোকাস পিছিয়ে ঘোরানো |

## সর্বজনীন ক্লিপবোর্ড

| হটকি                  | কার্যকারিতা              |
| ----------------------- | --------------------- |
| `Super + C`           | কপি    |
| `Super + X`           | কাট করা (টার্মিনালে নয়)    |
| `Super + V`           | পেস্ট    |
| `Super + Ctrl + V`           | ক্লিপবোর্ড ম্যানেজার    |

সাধারণত Linux-এ টার্মিনালে কপি-পেস্ট করতে `Ctrl + Shift + C/V` এবং অন্য সব জায়গায় তা করতে `Ctrl + C/V` লাগে। Omarchy-র এই একীভূত ক্লিপবোর্ড হটকিগুলো সব জায়গায় কাজ করে।

## ক্যাপচার

| হটকি              | কার্যকারিতা                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | ক্যাপচার মেনু (PrintScr বোতাম ছাড়া কিবোর্ডের জন্য) |
| `Print Screen`            | স্ক্রিনশট                      |
| `Alt + Print Screen`            | স্ক্রিনরেকর্ড                     |
| `Super + Print Screen` | রঙ বাছাইকার |
| `Super + Ctrl + Print Screen` | ক্লিপবোর্ডে টেক্সট নিষ্কাশন |
| `Super + Alt + [` | রেকর্ডিংয়ের সময় ওয়েবক্যাম ওভারলে ছোট করা |
| `Super + Alt + ]` | রেকর্ডিংয়ের সময় ওয়েবক্যাম ওভারলে বড় করা |
| `Alt + Shift + L` | ওয়েবঅ্যাপ বা Chromium থেকে বর্তমান URL কপি করা |
| `Alt + Shift + D` | বর্তমান পৃষ্ঠার ভিডিও `~/Videos`-এ ডাউনলোড করা |
| `Super + Ctrl + X` | ডিক্টেশন শুরু/থামানো (লাগবে _সেটআপ > Defaults > Dictation_) |
| `Right Alt` / `F9` | Push-to-talk ডিক্টেশন (Voxtype বা Superwhisper লাগবে) |

স্ক্রিনরেকর্ডিংয়ের ক্ষেত্রে হটকিটি প্রথমে জিজ্ঞেস করে আপনি কোন অডিও চান, তারপর রেকর্ডিং শুরু করে। থামাতে আবার চাপুন। বিস্তারিতের জন্য দেখুন [স্ক্রিনশট ও রেকর্ডিং](12-screenshots-recording.md)।

সমস্ত ক্যাপচার বিকল্প Omarchy মেনুতে (`Super + Space`) _ট্রিগার > ক্যাপচার_-এর অধীনেও পাওয়া যায়।

## স্টাইল

| হটকি                  | কার্যকারিতা              |
| ----------------------- | --------------------- |
| `Super + Ctrl + Shift + Space` | নতুন থিম বেছে নেওয়া  |
| `Super + Ctrl + Space` | থিমের পটভূমি বেছে নেওয়া |
| `Super + Backspace` | উইন্ডোর স্বচ্ছতা টগল করা |

অতিরিক্ত পটভূমি ছবি থাকে `~/.config/omarchy/backgrounds/<theme name>`-এ। Omarchy মেনুতে _Install > Style > Background_ দিয়েও পাওয়া যায়।

সমস্ত স্টাইল বিকল্প Omarchy মেনুতে (`Super + Space`) _স্টাইল_-এর অধীনেও পাওয়া যায়।

## Tmux

প্রিফিক্স কী হলো `Ctrl + Space` (`Ctrl + B`-ও কাজ করে)। আপনি `~/.config/tmux/tmux.conf`-এ এই বাইন্ডিংগুলো বদলাতে পারেন।

### প্যান

| হটকি                  | কার্যকারিতা              |
| ----------------------- | --------------------- |
| `Prefix + v` | পাশে প্যান ভাগ করা (উল্লম্ব) |
| `Prefix + h` | নিচে প্যান ভাগ করা (অনুভূমিক) |
| `Prefix + x` | প্যান বন্ধ করা |
| `Prefix + z` | প্যান জুম টগল করা (পূর্ণস্ক্রিন) |
| `Alt + Enter` | নিচে প্যান ভাগ করা (প্রিফিক্স ছাড়া) |
| `Alt + Shift + Enter` | পাশে প্যান ভাগ করা (প্রিফিক্স ছাড়া) |
| `Alt + Escape` | প্যান বন্ধ করা (প্রিফিক্স ছাড়া) |
| `Ctrl + Alt + Arrows` | প্যানগুলোর মধ্যে যাওয়া |
| `Ctrl + Alt + Shift + Arrows` | প্যানের আকার বদলানো |

### উইন্ডো

| হটকি                  | কার্যকারিতা              |
| ----------------------- | --------------------- |
| `Prefix + c` | নতুন উইন্ডো |
| `Prefix + k` | উইন্ডো বন্ধ করা |
| `Prefix + r` | উইন্ডোর নাম বদলানো |
| `Alt + 1-9` | নির্দিষ্ট উইন্ডোতে যাওয়া |
| `Alt + Arrow Left/Right` | উইন্ডোগুলোর মধ্যে যাওয়া |
| `Alt + Shift + Arrow Left/Right` | উইন্ডো বামে/ডানে সরানো |

### সেশন

| হটকি                  | কার্যকারিতা              |
| ----------------------- | --------------------- |
| `Prefix + C` | নতুন সেশন |
| `Prefix + K` | সেশন বন্ধ করা |
| `Prefix + R` | সেশনের নাম বদলানো |
| `Prefix + N` | পরের সেশন |
| `Prefix + P` | আগের সেশন |
| `Alt + Arrow Up/Down` | সেশনগুলোর মধ্যে যাওয়া |
| `Prefix + s` | সেশনের তালিকা দেখা |
| `Prefix + d` | সেশন থেকে বিচ্ছিন্ন হওয়া |

### কপি মোড (vi-স্টাইল)

| হটকি                  | কার্যকারিতা              |
| ----------------------- | --------------------- |
| `Prefix + [` | কপি মোডে ঢোকা |
| `v` | নির্বাচন শুরু করা (কপি মোডে) |
| `y` | নির্বাচন কপি করা (কপি মোডে) |

### সাধারণ

| হটকি                  | কার্যকারিতা              |
| ----------------------- | --------------------- |
| `Prefix + q` | কনফিগ পুনরায় লোড করা |
| `Prefix + ?` | Tmux কিবাইন্ডিং দেখানো |
| `Prefix + :` | কমান্ড প্রম্পট |

### Tmux লেআউট ফাংশন

এই ফাংশনগুলো Tmux সেশনের ভিতরে চালাতে হবে।

| কমান্ড | কার্যকারিতা |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | সম্পাদক, AI ও টার্মিনালসহ ডেভ লেআউট তৈরি করা |
| `tdlm <ai> [<second_ai>]` | প্রতি সাবডিরেক্টরির জন্য ডেভ লেআউট তৈরি করা |
| `tsl <count> <command>` | বহু-প্যান সোয়ার্ম লেআউট তৈরি করা |
