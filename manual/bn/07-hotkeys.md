# হটকি

আপনি `Super + K` দিয়ে সব প্রধান কিবোর্ড বাইন্ডিং দেখতে পারবেন (Tmux বাইন্ডিং `Super + Alt + K` দিয়ে এবং Herdr বাইন্ডিং `Super + Ctrl + K` দিয়ে)।

| `Super + Ctrl + Left/Right`  | টাইলিং গ্রুপের ভিতরে উইন্ডোগুলোর মধ্যে যান |
| `Super + Ctrl + Z` | স্ক্রিনে জুম ইন করুন (আরও জুমের জন্য আবার চাপুন) |

| `Super + Alt + /` | মনিটর স্কেলিং বিকল্পগুলোর মধ্যে পেছনে এগিয়ে যান |
| `Alt + Tab` | সক্রিয় workspace-এ উইন্ডোগুলোর মধ্যে সামনের দিকে চক্রাকারে যান |
| `Alt + Shift + Tab` | সক্রিয় workspace-এ উইন্ডোগুলোর মধ্যে পেছনের দিকে চক্রাকারে যান |
| `Ctrl + Alt + Tab`| মনিটরগুলোর মধ্যে ফোকাস সামনের দিকে চক্রাকারে যান |
| `Ctrl + Alt + Shift + Tab`| মনিটরগুলোর মধ্যে ফোকাস পেছনের দিকে চক্রাকারে যান |

আকার পরিবর্তনের শর্টকাটগুলো ফিজিক্যাল কী `code:20` এবং `code:21` (XKB `<AE11>` এবং `<AE12>`) ব্যবহার করে, কিবোর্ডে ছাপানো অক্ষর যাই হোক না কেন। US কিবোর্ডে এই কীগুলো `-` এবং `=`; জাপানি (JIS) কিবোর্ডে এগুলো `-` এবং `^`; স্প্যানিশ কিবোর্ডে এগুলো `'` এবং `¡`। JIS-এ, `Super + ^` হলো `Super + Equal`, আর `Super + Shift + -` (যা `=` টাইপ করে) হলো `Super + Shift + Minus`।

## সার্বজনীন ক্লিপবোর্ড

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Super + A`           | `Ctrl + A` সমর্থন করে এমন অ্যাপে সব নির্বাচন করুন    |
| `Super + C`           | কপি করুন    |
| `Super + X`           | কাট করুন (টার্মিনালে নয়)    |
| `Super + V`           | পেস্ট করুন    |
| `Super + Ctrl + V`           | ক্লিপবোর্ড ম্যানেজার    |

সাধারণত Linux-এ, টার্মিনালে কপি'এন'পেস্ট করতে আপনার `Ctrl + Shift + C/V` লাগে এবং অন্য সব জায়গায় করতে `Ctrl + C/V` লাগে। এই Omarchy-র একীভূত ক্লিপবোর্ড হটকিগুলো সব জায়গায় কাজ করে।

স্ক্রিনরেকর্ডিংয়ের ক্ষেত্রে, হটকি প্রথমে জিজ্ঞেস করে আপনি কোন অডিও চান, তারপর রেকর্ডিং শুরু করে। বন্ধ করতে আবার চাপুন। বিস্তারিত জানতে [স্ক্রিনশট এবং রেকর্ডিং](12-screenshots-recording.md) দেখুন।

সমস্ত ক্যাপচার বিকল্প Omarchy মেনুতে (`Super + Space`) _Trigger > Capture_-এর অধীনেও পাওয়া যায়।

| `Super + Ctrl + T` | নতুন থিম বেছে নিন (এছাড়াও `Super + Ctrl + Shift + Space`) |
| `Super + Ctrl + W` | থিমের ব্যাকগ্রাউন্ড বেছে নিন (এছাড়াও `Super + Ctrl + Space`) |
| `Super + Backspace` | একটি উইন্ডোতে স্বচ্ছতা টগল করুন |
| `Super + Ctrl + Backspace` | একক-উইন্ডোর বর্গাকার আকৃতি টগল করুন |

অতিরিক্ত ব্যাকগ্রাউন্ড ছবি `~/.config/omarchy/backgrounds/<theme name>`-এ থাকে। Omarchy মেনুতে _Install > Style > Background_ দিয়েও পাওয়া যায়।

সমস্ত স্টাইল বিকল্প Omarchy মেনুতে (`Super + Space`) _Style_-এর অধীনেও পাওয়া যায়।

## Tmux

প্রিফিক্স কী হলো `Ctrl + Space` (`Ctrl + B`-ও কাজ করে)। আপনি এই বাইন্ডিংগুলো `~/.config/tmux/tmux.conf`-এ পরিবর্তন করতে পারবেন।

### প্যান

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Prefix + v` | পাশে প্যান বিভক্ত করুন (উল্লম্ব) |
| `Prefix + h` | নিচে প্যান বিভক্ত করুন (অনুভূমিক) |
| `Prefix + x` | প্যান কিল করুন |
| `Prefix + z` | প্যান জুম টগল করুন (পূর্ণস্ক্রিন) |
| `Alt + Enter` | নিচে প্যান বিভক্ত করুন (প্রিফিক্স ছাড়া) |
| `Alt + Shift + Enter` | পাশে প্যান বিভক্ত করুন (প্রিফিক্স ছাড়া) |
| `Alt + Escape` | প্যান কিল করুন (প্রিফিক্স ছাড়া) |
| `Ctrl + Alt + Arrows` | প্যানগুলোর মধ্যে যান |
| `Ctrl + Alt + Shift + Arrows` | প্যানগুলোর আকার পরিবর্তন করুন |

### উইন্ডো

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Prefix + c` | নতুন উইন্ডো |
| `Prefix + k` | উইন্ডো কিল করুন |
| `Prefix + r` | উইন্ডোর নাম পরিবর্তন করুন |
| `Alt + 1-9` | নির্দিষ্ট উইন্ডোতে যান |
| `Alt + Arrow Left/Right` | উইন্ডোগুলোর মধ্যে যান |
| `Alt + Shift + Arrow Left/Right` | উইন্ডো বামে/ডানে সরান |

### সেশন

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Prefix + C` | নতুন সেশন |
| `Prefix + K` | সেশন কিল করুন |
| `Prefix + R` | সেশনের নাম পরিবর্তন করুন |
| `Prefix + N` | পরবর্তী সেশন |
| `Prefix + P` | পূর্ববর্তী সেশন |
| `Alt + Arrow Up/Down` | সেশনগুলোর মধ্যে যান |
| `Prefix + s` | সেশনগুলো তালিকাভুক্ত করুন |
| `Prefix + d` | সেশন থেকে বিচ্ছিন্ন হোন |

### কপি মোড (vi-style)

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Prefix + [` | কপি মোডে প্রবেশ করুন |
| `v` | নির্বাচন শুরু করুন (কপি মোডে) |
| `y` | নির্বাচন কপি করুন (কপি মোডে) |

### সাধারণ

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Prefix + q` | কনফিগ রিলোড করুন |
| `Prefix + ?` | Tmux কিবাইন্ডিং দেখান |
| `Prefix + :` | কমান্ড প্রম্পট |

### Tmux লেআউট ফাংশন

এই ফাংশনগুলো অবশ্যই একটি Tmux সেশনের ভিতরে চালাতে হবে।

| কমান্ড | কাজ |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | এডিটর, AI, এবং টার্মিনালসহ dev লেআউট তৈরি করুন |
| `tdlm <ai> [<second_ai>]` | প্রতি সাবডিরেক্টরির জন্য dev লেআউট তৈরি করুন |
| `tsl <count> <command>` | মাল্টি-প্যান swarm লেআউট তৈরি করুন |
