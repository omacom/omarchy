# হটকি

`Super + K` দিয়ে আপনি সব প্রধান কীবোর্ড বাইন্ডিং দেখতে পারেন (Tmux বাইন্ডিং `Super + Alt + K` দিয়ে এবং Herdr বাইন্ডিং `Super + Ctrl + K` দিয়ে)।

## নেভিগেশন

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy মেনু (অ্যাপ ও অন্য সবকিছু)    |
| `Super + Alt + Space` | অ্যাপ গ্রিড |
| `Super + Escape` | সিস্টেম মেনু (সাসপেন্ড, রিস্টার্ট, ইত্যাদি)  |
| `Super + Ctrl + L` | কম্পিউটার লক করুন |
| `Super + W` or `Super + Q` | উইন্ডো বন্ধ করুন             |
| `Ctrl + Alt + Del` | সব উইন্ডো বন্ধ করুন |
| `Super + T`               | টাইলিং/ফ্লোটিংয়ের মধ্যে উইন্ডো টগল করুন             |
| `Super + J` | উইন্ডোর অবস্থান টগল করুন (অনুভূমিক/উল্লম্ব) |
| `Super + O`               | উইন্ডোকে sticky'n'floating অবস্থায় পপ করা টগল করুন |
| `Super + L`               | dwindle, scrolling ও floating লেআউটগুলোর মধ্যে চক্রাকারে ঘুরুন |
| `Super + Alt + L`         | লেআউটগুলোর মধ্যে বিপরীত দিকে চক্রাকারে ঘুরুন |
| `Super + P`               | pseudo উইন্ডো স্টাইল টগল করুন (স্বাভাবিক বনাম stretch) |
| `Super + F`                 | পূর্ণ স্ক্রিনে যান              |
| `Super + Alt + F`                 | পূর্ণ প্রস্থে যান              |
| `Super + Ctrl + F`                 | উইন্ডোর ভিতরে পূর্ণ স্ক্রিনে যান              |
| `Super + 1/2/3/4`         | ফোকাস করা মনিটরে নির্দিষ্ট ওয়ার্কস্পেসে যান |
| `Super + Tab` | ফোকাস করা মনিটরে পরের ওয়ার্কস্পেসে যান |
| `Super + Shift + Tab` | ফোকাস করা মনিটরে আগের ওয়ার্কস্পেসে যান |
| `Super + Ctrl + Tab` | ফোকাস করা মনিটরে পূর্ববর্তী ওয়ার্কস্পেসে যান |
| `Super + Shift + 1/2/3/4` | ফোকাস করা মনিটরে উইন্ডোটি ওয়ার্কস্পেসে সরান |
| `Super + Shift + Alt + 1/2/3/4` | অনুসরণ না করে ফোকাস করা মনিটরে উইন্ডোটি ওয়ার্কস্পেসে সরান |
| `Super + S` | পূর্ণ scratchpad টগল করুন |
| `Super + Alt + S` | উইন্ডোটি পূর্ণ scratchpad-এ সরান |
| `Super + Grave` | Quake কনসোল টগল করুন |
| `Super + Shift + Grave` | উইন্ডোটি Quake কনসোলে সরান |
| `Super + Shift + Ctrl + Arrows` | উইন্ডোটি ওই দিকের মনিটরে সরান |
| `Super + Shift + Alt + Arrows` | ওয়ার্কস্পেসটি ওই দিকের মনিটরে সরান |
| `Super + Arrow`  | তীরের দিকে উইন্ডোতে ফোকাস সরান, স্ক্রিনের প্রান্তে ওই পাশের মনিটরে চলে যান |
| `Super + Shift + Arrow`  | তীরের দিকে অন্য উইন্ডোর সঙ্গে উইন্ডো অদলবদল করুন, ওই পাশের মনিটরে থাকা উইন্ডোসহ |
| `Super + Minus` | উইন্ডো বাম দিকে প্রসারিত করুন |
| `Super + Equal` | উইন্ডো বাম দিকে সংকুচিত করুন |
| `Super + Shift + Minus` | উইন্ডো ওপর দিকে সংকুচিত করুন |
| `Super + Shift + Equal` | উইন্ডো নিচ দিকে প্রসারিত করুন |
| `Super + Alt + Minus/Equal` | ছোট ধাপে একই আকার পরিবর্তন |
| `Super + Ctrl + Minus/Equal` | বড় ধাপে একই আকার পরিবর্তন |
| `Super + Alt + Home` | উইন্ডোর প্রস্থ সংরক্ষণ করুন |
| `Super + Home` | সংরক্ষিত উইন্ডোর প্রস্থ পুনরুদ্ধার করুন |
| `Super + Left Mouse` | উইন্ডো টেনে সরান |
| `Super + Right Mouse` | উইন্ডোর আকার পরিবর্তন করুন |
| `Super + Scroll Wheel` | ফোকাস করা মনিটরে ওয়ার্কস্পেসগুলোর মধ্যে স্ক্রল করুন |
| `Super + G`               | উইন্ডো গ্রুপিং টগল করুন      |
| `Super + Alt + G`               | উইন্ডোটি গ্রুপিং থেকে বের করুন      |
| `Super + Alt + Tab`               | গ্রুপিংয়ের উইন্ডোগুলোর মধ্যে চক্রাকারে ঘুরুন      |
| `Super + Alt + Shift + Tab`               | গ্রুপিংয়ের উইন্ডোগুলোর মধ্যে পেছনের দিকে চক্রাকারে ঘুরুন      |
| `Super + Alt + Scroll Wheel` | গ্রুপিংয়ের উইন্ডোগুলোর মধ্যে চক্রাকারে ঘুরুন |
| `Super + Alt + 1/2/3/4/5`               | গ্রুপিংয়ে নির্দিষ্ট উইন্ডোতে যান      |
| `Super + Alt + Arrow`  | তীরের দিকে উইন্ডোটিকে গ্রুপিংয়ে সরান, ওই পাশের মনিটরে থাকা উইন্ডোসহ |
| `Super + Ctrl + Left/Right`  | টাইলিং গ্রুপের ভিতরে উইন্ডোগুলোর মধ্যে সরুন |
| `Super + Ctrl + Z` | স্ক্রিনে জুম ইন করুন (আরও জুমের জন্য আবার চাপুন) |
| `Super + Ctrl + Alt + Z` | স্ক্রিন থেকে সম্পূর্ণ জুম আউট করুন |
| `Super + /` | মনিটর স্কেলিং বিকল্পগুলোর মধ্যে ধাপে ধাপে এগিয়ে যান |
| `Super + Alt + /` | মনিটর স্কেলিং বিকল্পগুলোর মধ্যে ধাপে ধাপে পেছিয়ে যান |
| `Alt + Tab` | সক্রিয় ওয়ার্কস্পেসে উইন্ডোগুলোর মধ্যে সামনের দিকে চক্রাকারে ঘুরুন |
| `Alt + Shift + Tab` | সক্রিয় ওয়ার্কস্পেসে উইন্ডোগুলোর মধ্যে পেছনের দিকে চক্রাকারে ঘুরুন |
| `Ctrl + Alt + Tab`| মনিটরগুলোর মধ্যে ফোকাস সামনের দিকে চক্রাকারে ঘোরান |
| `Ctrl + Alt + Shift + Tab`| মনিটরগুলোর মধ্যে ফোকাস পেছনের দিকে চক্রাকারে ঘোরান |

## ইউনিভার্সাল ক্লিপবোর্ড

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Super + C`           | কপি    |
| `Super + X`           | কাট (টার্মিনালে নয়)    |
| `Super + V`           | পেস্ট    |
| `Super + Ctrl + V`           | ক্লিপবোর্ড ম্যানেজার    |

সাধারণত Linux-এ, টার্মিনালে copy'n'paste করতে আপনার `Ctrl + Shift + C/V` লাগে এবং অন্য সব জায়গায় করতে `Ctrl + C/V` লাগে। এই Omarchy ইউনিফাইড ক্লিপবোর্ড হটকিগুলো সব জায়গায় কাজ করে।

## ক্যাপচার

| হটকি              | কাজ                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | স্ক্রিনশট                      |
| `Super + Ctrl + Alt + C`            | স্ক্রিনশট (একই শট, Print Screen কী নেই এমন কীবোর্ডের জন্য) |
| `Super + Ctrl + C` | ক্যাপচার মেনু |
| `Alt + Print Screen`            | স্ক্রিনরেকর্ড                     |
| `Super + Print Screen` | রঙ পিকার |
| `Super + Ctrl + Print Screen` | ক্লিপবোর্ডে টেক্সট নিষ্কাশন |
| `Super + Alt + [` | রেকর্ডিংয়ের সময় ওয়েবক্যাম ওভারলে ছোট করুন |
| `Super + Alt + ]` | রেকর্ডিংয়ের সময় ওয়েবক্যাম ওভারলে বড় করুন |
| `Alt + Shift + L` | ওয়েবঅ্যাপ বা Chromium থেকে বর্তমান URL কপি করুন |
| `Alt + Shift + D` | বর্তমান পৃষ্ঠার ভিডিও `~/Videos`-এ ডাউনলোড করুন |
| `Super + Ctrl + X` | ডিকটেশন শুরু/বন্ধ করুন (_Setup > Defaults > Dictation_ প্রয়োজন) |
| `Right Alt` / `F9` | Push-to-talk ডিকটেশন (Voxtype বা Superwhisper প্রয়োজন) |

স্ক্রিনরেকর্ডিংয়ের ক্ষেত্রে, হটকি প্রথমে জিজ্ঞেস করে আপনি কোন অডিও চান, তারপর রেকর্ডিং শুরু করে। বন্ধ করতে আবার চাপুন। বিস্তারিত জানতে [স্ক্রিনশট ও রেকর্ডিং](12-screenshots-recording.md) দেখুন।

সব ক্যাপচার বিকল্প Omarchy মেনুতে (`Super + Space`) _Trigger > Capture_-এর অধীনেও পাওয়া যায়।

| `Super + Ctrl + Backspace` | একক-উইন্ডো বর্গাকার অনুপাত টগল করুন |

অতিরিক্ত ব্যাকগ্রাউন্ড ছবি `~/.config/omarchy/backgrounds/<theme name>`-এ থাকে। Omarchy মেনুতে _Install > Style > Background_ দিয়েও পাওয়া যায়।

সব স্টাইল বিকল্প Omarchy মেনুতে (`Super + Space`) _Style_-এর অধীনেও পাওয়া যায়।

## Tmux

প্রিফিক্স কী হলো `Ctrl + Space` (`Ctrl + B`-ও কাজ করে)। আপনি `~/.config/tmux/tmux.conf`-এ এই বাইন্ডিংগুলো পরিবর্তন করতে পারেন।

### প্যান

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Prefix + v` | পাশে প্যান ভাগ করুন (উল্লম্ব) |
| `Prefix + h` | নিচে প্যান ভাগ করুন (অনুভূমিক) |
| `Prefix + x` | প্যান বন্ধ করুন |
| `Prefix + z` | প্যান জুম টগল করুন (পূর্ণস্ক্রিন) |
| `Alt + Enter` | নিচে প্যান ভাগ করুন (প্রিফিক্স ছাড়া) |
| `Alt + Shift + Enter` | পাশে প্যান ভাগ করুন (প্রিফিক্স ছাড়া) |
| `Alt + Escape` | প্যান বন্ধ করুন (প্রিফিক্স ছাড়া) |
| `Ctrl + Alt + Arrows` | প্যানগুলোর মধ্যে সরুন |
| `Ctrl + Alt + Shift + Arrows` | প্যানগুলোর আকার পরিবর্তন করুন |

### উইন্ডো

| হটকি                  | কাজ              |

| `Prefix + r` | উইন্ডোর নাম পরিবর্তন করুন |
| `Alt + 1-9` | নির্দিষ্ট উইন্ডোতে যান |

| `Alt + Shift + Arrow Left/Right` | উইন্ডো বামে/ডানে সরান |

| হটকি                  | কাজ              |

### Tmux লেআউট ফাংশন

এই ফাংশনগুলো অবশ্যই একটি Tmux সেশনের ভিতরে চালাতে হবে।

| কমান্ড | কাজ |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | এডিটর, AI ও টার্মিনালসহ ডেভ লেআউট তৈরি করুন |
| `tdlm <ai> [<second_ai>]` | প্রতি সাবডিরেক্টরির জন্য ডেভ লেআউট তৈরি করুন |
| `tsl <count> <command>` | বহু-প্যান swarm লেআউট তৈরি করুন |
