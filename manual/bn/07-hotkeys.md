# হটকি

আপনি `Super + K` দিয়ে সব প্রধান কীবোর্ড বাইন্ডিং দেখতে পারেন (Tmux বাইন্ডিং `Super + Alt + K` দিয়ে এবং Herdr বাইন্ডিং `Super + Ctrl + K` দিয়ে)।

## সার্বজনীন ক্লিপবোর্ড

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + C`           | কপি    |
| `Super + X`           | কাট (টার্মিনালে নয়)    |
| `Super + V`           | পেস্ট    |
| `Super + Ctrl + V`           | ক্লিপবোর্ড ম্যানেজার    |

সাধারণত Linux-এ, টার্মিনালে কপি-পেস্ট করতে আপনার `Ctrl + Shift + C/V` লাগে এবং অন্য সব জায়গায় করতে `Ctrl + C/V` লাগে। এই Omarchy একীভূত ক্লিপবোর্ড হটকিগুলো সব জায়গায় কাজ করে।

সব ক্যাপচার বিকল্প Omarchy মেনুতে (`Super + Space`) _Trigger > Capture_-এর অধীনেও অ্যাক্সেস করা যায়।

## স্টাইল

| Hotkey                  | Function              |
| ----------------------- | --------------------- |

| `Super + Ctrl + W` | থিমের ব্যাকগ্রাউন্ড বেছে নিন (এছাড়াও `Super + Ctrl + Space`) |

অতিরিক্ত ব্যাকগ্রাউন্ড ছবি `~/.config/omarchy/backgrounds/<theme name>`-এ থাকে। Omarchy মেনুতে _Install > Style > Background_-এর মাধ্যমেও পাওয়া যায়।

সব স্টাইল বিকল্প Omarchy মেনুতে (`Super + Space`) _Style_-এর অধীনেও অ্যাক্সেস করা যায়।

## টগল

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + Ctrl + I` | নিষ্ক্রিয় থাকলে লক করা টগল করুন |
| `Super + Ctrl + Delete` | ল্যাপটপ ডিসপ্লে চালু/বন্ধ টগল করুন |
| `Super + Ctrl + Alt + Delete` | ল্যাপটপ ডিসপ্লে মিররিং টগল করুন |
| `Super + Shift + Space` | উপরের বার টগল করুন  |
| `Shift + Mute` | পরের অডিও আউটপুটে যান |
| `Shift + Play` | পরের মিডিয়া উৎসে যান |
| `Super + Shift + Backspace` | উইন্ডোর ফাঁক টগল করুন |
| `Super + Ctrl + Alt + F` | ফুল স্ক্রিন ডেস্কটপ টগল করুন (উপরের বার + উইন্ডোর ফাঁক) |

## অনুস্মারক

## নোটিশ

| ----------------------- | --------------------- |

## Tmux

প্রিফিক্স কী হলো `Ctrl + Space` (`Ctrl + B`-ও কাজ করে)। আপনি `~/.config/tmux/tmux.conf`-এ এই বাইন্ডিংগুলো পরিবর্তন করতে পারেন।

### প্যান

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + v` | পাশে প্যান ভাগ করুন (উল্লম্ব) |
| `Prefix + h` | নিচে প্যান ভাগ করুন (অনুভূমিক) |
| `Prefix + x` | প্যান বন্ধ করুন |
| `Prefix + z` | প্যান জুম টগল করুন (ফুলস্ক্রিন) |
| `Alt + Enter` | নিচে প্যান ভাগ করুন (প্রিফিক্স ছাড়া) |
| `Alt + Shift + Enter` | পাশে প্যান ভাগ করুন (প্রিফিক্স ছাড়া) |
| `Alt + Escape` | প্যান বন্ধ করুন (প্রিফিক্স ছাড়া) |
| `Ctrl + Alt + Arrows` | প্যানগুলোর মধ্যে সরুন |
| `Ctrl + Alt + Shift + Arrows` | প্যানগুলোর আকার পরিবর্তন করুন |

### উইন্ডো

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + c` | নতুন উইন্ডো |
| `Prefix + k` | উইন্ডো বন্ধ করুন |
| `Prefix + r` | উইন্ডোর নাম পরিবর্তন করুন |
| `Alt + 1-9` | নির্দিষ্ট উইন্ডোতে যান |
| `Alt + Arrow Left/Right` | উইন্ডোগুলোর মধ্যে সরুন |
| `Alt + Shift + Arrow Left/Right` | উইন্ডো বামে/ডানে সরান |

### সেশন

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + C` | নতুন সেশন |
| `Prefix + K` | সেশন বন্ধ করুন |
| `Prefix + R` | সেশনের নাম পরিবর্তন করুন |
| `Prefix + N` | পরের সেশন |
| `Prefix + P` | আগের সেশন |
| `Alt + Arrow Up/Down` | সেশনগুলোর মধ্যে সরুন |
| `Prefix + s` | সেশনগুলোর তালিকা দেখুন |
| `Prefix + d` | সেশন থেকে বিচ্ছিন্ন হোন |

### কপি মোড (vi-স্টাইল)

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + [` | কপি মোডে প্রবেশ করুন |
| `v` | নির্বাচন শুরু করুন (কপি মোডে) |
| `y` | নির্বাচন কপি করুন (কপি মোডে) |

### সাধারণ

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + q` | কনফিগ পুনরায় লোড করুন |
| `Prefix + ?` | Tmux কীবাইন্ডিং দেখান |
| `Prefix + :` | কমান্ড প্রম্পট |

### Tmux লেআউট ফাংশন

এই ফাংশনগুলো Tmux সেশনের ভিতরে চালাতে হবে।

| Command | Function |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | এডিটর, AI এবং টার্মিনালসহ dev লেআউট তৈরি করুন |
| `tdlm <ai> [<second_ai>]` | প্রতি সাবডিরেক্টরির জন্য dev লেআউট তৈরি করুন |
| `tsl <count> <command>` | মাল্টি-প্যান swarm লেআউট তৈরি করুন |

## Ghostty Terminal

Ghostty terminal Omarchy মেনুর মাধ্যমে _Install > Terminal_ ব্যবহার করে ইনস্টল করা হয়।

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Ctrl + Shift + E` | নিচে নতুন স্প্লিট |
| `Ctrl + Shift + O` | পাশে নতুন স্প্লিট |
| `Ctrl + Alt + Arrows` | স্প্লিটগুলোর মধ্যে সরুন |
| `Super + Ctrl + Shift + Arrows` | 10 লাইন করে স্প্লিটের আকার পরিবর্তন করুন |
| `Super + Ctrl + Shift + Alt + Arrows` | 100 লাইন করে স্প্লিটের আকার পরিবর্তন করুন |
| `Ctrl + Shift + T` | নতুন ট্যাব  |
| `Ctrl + Shift + Arrows` | ট্যাবগুলোর মধ্যে সরুন |
| `Alt + Numbers` | নির্দিষ্ট ট্যাবে যান |
| `Shift + Pg Up/Down` | ইতিহাস স্ক্রল করুন |
| `Ctrl + Left mouse` | ব্রাউজারে লিংক খুলুন |
