# হটকি

আপনি `Super + K` দিয়ে সব প্রধান কীবোর্ড বাইন্ডিং দেখতে পারেন (`Super + Alt + K` দিয়ে Tmux বাইন্ডিং এবং `Super + Ctrl + K` দিয়ে Herdr বাইন্ডিং)।

## হটকিগুলো কীভাবে সাজানো হয়

প্রতিটি হটকি একটি প্লেনে থাকে, যা এর মডিফায়ারগুলো দিয়ে নির্ধারিত হয়, এবং প্রতিটি প্লেনের একটি কাজ থাকে। এটাই হটকিগুলোকে একসঙ্গে গুলিয়ে যাওয়া থেকে রক্ষা করে, এবং এর মানে হলো আপনি সাধারণত অনুমান করতে পারবেন কোনো কিছু কোথায় থাকে।

| প্লেন | সেখানে যা থাকে | উদাহরণ |
| --- | --- | --- |
| `Super + key` | সিস্টেম: উইন্ডো, ওয়ার্কস্পেস, লেআউট এবং মূল মেনু | `Super + Space` Omarchy মেনু, `Super + W` উইন্ডো বন্ধ করুন, `Super + F` পূর্ণ স্ক্রিন |
| `Super + Shift + key` | অ্যাপ | `Super + Shift + B` ব্রাউজার, `Super + Shift + E` ইমেল, `Super + Shift + N` এডিটর |
| `Super + Ctrl + key` | প্যানেল ও সিস্টেম মেনু | `Super + Ctrl + A` অডিও, `Super + Ctrl + N` নেটওয়ার্ক, `Super + Ctrl + C` ক্যাপচার মেনু |
| `Super + Ctrl + Alt + key` | দ্রুত কাজ ও নোটিশ | `Super + Ctrl + Alt + T` সময় দেখান, `Super + Ctrl + Alt + B` ব্যাটারি, `Super + Ctrl + Alt + C` স্ক্রিনশট |

কোনো হটকিতে `Alt` যোগ করলে আপনি একই জিনিসের একটি ভ্যারিয়েন্ট পান, কখনোই সম্পর্কহীন কিছু নয়:

- `Super + Shift + B` ব্রাউজার খোলে; `Super + Shift + Alt + B` একটি প্রাইভেট উইন্ডো খোলে
- `Super + Shift + E` ইমেল খোলে; `Super + Shift + Alt + E` একটি নতুন ইমেল শুরু করে
- `Super + F` পূর্ণ স্ক্রিনে যায়; `Super + Alt + F` পূর্ণ প্রস্থে যায়
- `Super + Ctrl + C` ক্যাপচার মেনু খোলে; `Super + Ctrl + Alt + C` মেনু এড়িয়ে স্ক্রিনশট নেয়

হটকি যোগ করার সময়:

1. এটি কী করে তা থেকে প্লেনটি বেছে নিন, তারপর কীটি বেছে নিন।
2. জায়গা করতে বিদ্যমান হটকি সরাবেন না। সঠিক প্লেনে একটি খালি কী খুঁজুন।
3. শুধুমাত্র এটি ছাড়া হটকিটির একটি ভ্যারিয়েন্টের জন্য `Alt` ব্যবহার করুন।

কিছু হটকি সুবিধাজনক বলে এই নিয়মগুলো ভাঙে। তির বা `Tab`-এর সঙ্গে `Shift` কোনো অ্যাপ খোলার পরিবর্তে সরায় বা উল্টো করে, এবং `Print`, মিডিয়া কীগুলো, `Alt + Tab` ও `Ctrl + Alt + Del` অন্য সব জায়গায় যেভাবে কাজ করে সেভাবেই কাজ করে। এগুলো ব্যতিক্রম, অনুকরণ করার প্যাটার্ন নয়।

যদি কোনো ডিফল্ট আপনার পছন্দ না হয় (ধরুন আপনি Windows-এর মতো স্ক্রিনশটের জন্য `Super + Shift + S` চান), সেটি `~/.config/hypr/bindings.lua`-তে রিবাইন্ড করুন।

| `Super + Alt + /` | মনিটর স্কেলিং বিকল্পগুলোর মধ্যে পেছনে যান |

| `Alt + Shift + Tab` | সক্রিয় ওয়ার্কস্পেসের উইন্ডোগুলোর মধ্যে পেছনে চক্রাকারে যান |
| `Ctrl + Alt + Tab` | মনিটরগুলোর মধ্যে ফোকাস সামনে চক্রাকারে যান |
| `Ctrl + Alt + Shift + Tab` | মনিটরগুলোর মধ্যে ফোকাস পেছনের দিকে চক্রাকারে যান |

রিসাইজ শর্টকাটগুলো ফিজিক্যাল কী `code:20` ও `code:21` (XKB `<AE11>` ও `<AE12>`) ব্যবহার করে, কীবোর্ডে ছাপা অক্ষর যা-ই হোক না কেন। US কীবোর্ডে এই কীগুলো `-` ও `=`; জাপানি (JIS) কীবোর্ডে এগুলো `-` ও `^`; স্প্যানিশ কীবোর্ডে এগুলো `'` ও `¡`। JIS-এ, `Super + ^` হলো `Super + Equal`, আর `Super + Shift + -` (যা `=` টাইপ করে) হলো `Super + Shift + Minus`।

## সর্বজনীন ক্লিপবোর্ড

| হটকি | কাজ |
| ----------------------- | --------------------- |
| `Super + A` | `Ctrl + A` সমর্থন করে এমন অ্যাপে সব নির্বাচন করুন |
| `Super + C` | কপি করুন |

সাধারণত Linux-এ, টার্মিনালে কপি'n'পেস্ট করতে আপনার `Ctrl + Shift + C/V` দরকার হয় এবং অন্য সব জায়গায় তা করতে `Ctrl + C/V` দরকার হয়। এই Omarchy একীভূত ক্লিপবোর্ড হটকিগুলো সব জায়গায় কাজ করে।

## Tmux

### পেন
