# হটকি

আপনি `Super + K` দিয়ে সব প্রধান কীবোর্ড বাইন্ডিং দেখতে পারবেন (Tmux বাইন্ডিং `Super + Alt + K` দিয়ে এবং Herdr বাইন্ডিং `Super + Ctrl + K` দিয়ে)।

## হটকিগুলো কীভাবে সাজানো হয়েছে

প্রতিটি হটকি একটি স্তরে থাকে, যা তার মডিফায়ার দিয়ে নির্ধারিত হয়, এবং প্রতিটি স্তরের একটি কাজ থাকে। এভাবেই হটকিগুলো একে অন্যের সঙ্গে গুলিয়ে যায় না, এবং এর মানে হলো আপনি সাধারণত অনুমান করতে পারবেন কোনটা কোথায় আছে।

| স্তর | সেখানে যা থাকে | উদাহরণ |
| --- | --- | --- |
| `Super + key` | সিস্টেম: উইন্ডো, ওয়ার্কস্পেস, লেআউট এবং মূল মেনু | `Super + Space` Omarchy মেনু, `Super + W` উইন্ডো বন্ধ করুন, `Super + F` পূর্ণ স্ক্রিন |
| `Super + Shift + key` | অ্যাপ | `Super + Shift + B` ব্রাউজার, `Super + Shift + E` ইমেল, `Super + Shift + N` এডিটর |
| `Super + Ctrl + key` | প্যানেল এবং সিস্টেম মেনু | `Super + Ctrl + A` অডিও, `Super + Ctrl + N` নেটওয়ার্ক, `Super + Ctrl + C` ক্যাপচার মেনু |
| `Super + Ctrl + Alt + key` | দ্রুত অ্যাকশন এবং নোটিস | `Super + Ctrl + Alt + T` সময় দেখান, `Super + Ctrl + Alt + B` ব্যাটারি, `Super + Ctrl + Alt + C` স্ক্রিনশট |

কোনো হটকিতে `Alt` যোগ করলে একই জিনিসের একটি ভ্যারিয়েন্ট পাওয়া যায়, কখনোই সম্পর্কহীন কিছু নয়:

- `Super + Shift + B` ব্রাউজার খোলে; `Super + Shift + Alt + B` একটি প্রাইভেট উইন্ডো খোলে
- `Super + Shift + E` ইমেল খোলে; `Super + Shift + Alt + E` একটি নতুন ইমেল শুরু করে
- `Super + F` পূর্ণ স্ক্রিনে যায়; `Super + Alt + F` পূর্ণ প্রস্থে যায়
- `Super + Ctrl + C` ক্যাপচার মেনু খোলে; `Super + Ctrl + Alt + C` মেনু এড়িয়ে স্ক্রিনশট নেয়

নতুন হটকি যোগ করার সময়:

1. এটি কী করে তা থেকে স্তর বেছে নিন, তারপর কী বেছে নিন।
2. জায়গা করার জন্য বিদ্যমান কোনো হটকি সরাবেন না। সঠিক স্তরে একটি ফাঁকা কী খুঁজুন।
3. `Alt` শুধুমাত্র এটি ছাড়া হটকির ভ্যারিয়েন্টের জন্যই ব্যবহার করুন।

কিছু হটকি এই নিয়ম ভাঙে কারণ সেগুলো সুবিধাজনক। তীর চিহ্ন বা `Tab`-এর সঙ্গে `Shift` কোনো অ্যাপ খোলার পরিবর্তে সরায় বা উল্টো দিকে যায়, এবং `Print`, মিডিয়া কী, `Alt + Tab`, এবং `Ctrl + Alt + Del` অন্য সব জায়গায় যেভাবে কাজ করে সেভাবেই কাজ করে। এগুলো ব্যতিক্রম, অনুকরণ করার মতো প্যাটার্ন নয়।

যদি কোনো ডিফল্ট আপনার পছন্দ না হয় (ধরুন আপনি Windows-এর মতো স্ক্রিনশটের জন্য `Super + Shift + S` চান), তাহলে `~/.config/hypr/bindings.lua`-তে সেটি রিবাইন্ড করুন।

টাচপ্যাডে, তিন- এবং চার-আঙুলের সোয়াইপে ওয়ার্কস্পেস বদলায়, উইন্ডো সরায়, এবং মেনু ও Quake কনসোল খোলে; জেশ্চারগুলোর জন্য [কীবোর্ড, মাউস এবং ট্র্যাকপ্যাড](34-keyboard-mouse-trackpad.md) দেখুন।

রিসাইজ শর্টকাটগুলো ফিজিক্যাল কী `code:20` এবং `code:21` (XKB `<AE11>` এবং `<AE12>`) ব্যবহার করে, কীবোর্ডে ছাপানো অক্ষর যাই হোক না কেন। US কীবোর্ডে এই কীগুলো হলো `-` এবং `=`; জাপানি (JIS) কীবোর্ডে এগুলো `-` এবং `^`; স্প্যানিশ কীবোর্ডে এগুলো `'` এবং `¡`। JIS-এ, `Super + ^` হলো `Super + Equal`, আবার `Super + Shift + -` (যা `=` টাইপ করে) হলো `Super + Shift + Minus`।

| `?`                        | সব কমান্ডের জন্য সাহায্য দেখান      |

[LazyVim দিয়ে কনফিগার করা সব Neovim হটকি দেখুন](https://www.lazyvim.org/keymaps)।
