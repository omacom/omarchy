# হটকি

আপনি `Super + K` দিয়ে সব প্রধান কীবোর্ড বাইন্ডিং দেখতে পারবেন (Tmux বাইন্ডিং `Super + Alt + K` দিয়ে এবং Herdr বাইন্ডিং `Super + Ctrl + K` দিয়ে)।

## নেভিগেট করা

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy মেনু (অ্যাপ এবং আরও সবকিছু)    |
| `Super + Alt + Space` | অ্যাপ গ্রিড |
| `Super + Escape` | সিস্টেম মেনু (সাসপেন্ড, রিস্টার্ট, ইত্যাদি)  |
| `Super + Ctrl + L` | কম্পিউটার লক করুন |
| `Super + W` or `Super + Q` | উইন্ডো বন্ধ করুন             |
| `Ctrl + Alt + Del` | সব উইন্ডো বন্ধ করুন |
| `Super + T`               | উইন্ডোকে টাইলিং/ফ্লোটিংয়ের মধ্যে টগল করুন             |
| `Super + J` | উইন্ডোর অবস্থান টগল করুন (অনুভূমিক/উল্লম্ব) |
| `Super + O`               | উইন্ডোকে sticky'n'floating-এ পপ করা টগল করুন |
| `Super + L`               | dwindle, scrolling এবং floating লেআউটগুলোর মধ্যে চক্রাকারে যান |
| `Super + Alt + L`         | লেআউটগুলোর মধ্যে উল্টো দিকে চক্রাকারে যান |
| `Super + P`               | pseudo উইন্ডো স্টাইল টগল করুন (natural বনাম stretch) |
| `Super + F`                 | পূর্ণ স্ক্রিনে যান              |
| `Super + Alt + F`                 | পূর্ণ প্রস্থে যান              |
| `Super + Ctrl + F`                 | উইন্ডোর ভেতরে পূর্ণ স্ক্রিনে যান              |
| `Super + 1/2/3/4`         | ফোকাস করা মনিটরে নির্দিষ্ট ওয়ার্কস্পেসে যান |
| `Super + Tab` | ফোকাস করা মনিটরে পরের ওয়ার্কস্পেসে যান |
| `Super + Shift + Tab` | ফোকাস করা মনিটরে আগের ওয়ার্কস্পেসে যান |
| `Super + Ctrl + Tab` | ফোকাস করা মনিটরে পূর্ববর্তী ওয়ার্কস্পেসে যান |
| `Super + Shift + 1/2/3/4` | ফোকাস করা মনিটরে ওয়ার্কস্পেসে উইন্ডো সরান |
| `Super + Shift + Alt + 1/2/3/4` | অনুসরণ না করে ফোকাস করা মনিটরে ওয়ার্কস্পেসে উইন্ডো সরান |
| `Super + S` | পূর্ণ scratchpad টগল করুন |
| `Super + Alt + S` | উইন্ডোকে পূর্ণ scratchpad-এ সরান |
| `Super + Grave` | Quake কনসোল টগল করুন |
| `Super + Shift + Grave` | উইন্ডোকে Quake কনসোলে সরান |
| `Super + Shift + Ctrl + Arrows` | উইন্ডোকে সেই দিকের মনিটরে সরান |
| `Super + Shift + Alt + Arrows` | ওয়ার্কস্পেসকে সেই দিকের মনিটরে সরান |
| `Super + Arrow`  | তীরের দিকে উইন্ডোতে ফোকাস সরান, স্ক্রিনের কিনারায় সেই দিকের মনিটরে চলে যান |
| `Super + Shift + Arrow`  | তীরের দিকে অন্য উইন্ডোর সঙ্গে উইন্ডো অদলবদল করুন, সেই দিকের মনিটরে থাকা উইন্ডোসহ |
| `Super + Minus` | উইন্ডো বামদিকে প্রসারিত করুন |
| `Super + Equal` | উইন্ডো বামদিকে সংকুচিত করুন |
| `Super + Shift + Minus` | উইন্ডো ওপরদিকে সংকুচিত করুন |
| `Super + Shift + Equal` | উইন্ডো নিচের দিকে প্রসারিত করুন |
| `Super + Alt + Minus/Equal` | ছোট ছোট ধাপে একই রিসাইজ |
| `Super + Ctrl + Minus/Equal` | বড় বড় ধাপে একই রিসাইজ |
| `Super + Alt + Home` | উইন্ডোর প্রস্থ সংরক্ষণ করুন |
| `Super + Home` | সংরক্ষিত উইন্ডোর প্রস্থ পুনরুদ্ধার করুন |
| `Super + Left Mouse` | উইন্ডো টেনে সরান |
| `Super + Right Mouse` | উইন্ডো রিসাইজ করুন |
| `Super + Scroll Wheel` | ফোকাস করা মনিটরে ওয়ার্কস্পেসগুলোর মধ্যে স্ক্রল করুন |
| `Super + G`               | উইন্ডো গ্রুপিং টগল করুন      |
| `Super + Alt + G`               | উইন্ডোকে গ্রুপিং থেকে বের করুন      |
| `Super + Alt + Tab`               | গ্রুপিংয়ের উইন্ডোগুলোর মধ্যে চক্রাকারে যান      |
| `Super + Alt + Shift + Tab`               | গ্রুপিংয়ের উইন্ডোগুলোর মধ্যে পেছনের দিকে চক্রাকারে যান      |
| `Super + Alt + Scroll Wheel` | গ্রুপিংয়ের উইন্ডোগুলোর মধ্যে চক্রাকারে যান |
| `Super + Alt + 1/2/3/4/5`               | গ্রুপিংয়ে নির্দিষ্ট উইন্ডোতে যান      |
| `Super + Alt + Arrow`  | তীরের দিকে উইন্ডোকে গ্রুপিংয়ে সরান, সেই দিকের মনিটরে থাকা উইন্ডোসহ |
| `Super + Ctrl + Left/Right`  | একটি টাইলিং গ্রুপের ভেতরের উইন্ডোগুলোর মধ্যে যান |
| `Super + Ctrl + Z` | স্ক্রিনে জুম ইন করুন (আরও জুমের জন্য আবার চাপুন) |
| `Super + Ctrl + Alt + Z` | স্ক্রিন থেকে পুরোপুরি জুম আউট করুন |
| `Super + /` | মনিটর স্কেলিং বিকল্পগুলোর মধ্যে সামনে এগিয়ে যান |
| `Super + Alt + /` | মনিটর স্কেলিং বিকল্পগুলোর মধ্যে পেছনে যান |
| `Alt + Tab` | সক্রিয় ওয়ার্কস্পেসে উইন্ডোগুলোর মধ্যে সামনের দিকে চক্রাকারে যান |
| `Alt + Shift + Tab` | সক্রিয় ওয়ার্কস্পেসে উইন্ডোগুলোর মধ্যে পেছনের দিকে চক্রাকারে যান |
| `Ctrl + Alt + Tab`| মনিটরগুলোর মধ্যে ফোকাস সামনের দিকে চক্রাকারে যান |
| `Ctrl + Alt + Shift + Tab`| মনিটরগুলোর মধ্যে ফোকাস পেছনের দিকে চক্রাকারে যান |

## সার্বজনীন ক্লিপবোর্ড

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Super + C`           | কপি    |
| `Super + X`           | কাট (টার্মিনালে নয়)    |
| `Super + V`           | পেস্ট    |
| `Super + Ctrl + V`           | ক্লিপবোর্ড ম্যানেজার    |

সাধারণত Linux-এ, টার্মিনালে কপি'n'পেস্ট করতে `Ctrl + Shift + C/V` এবং অন্য সব জায়গায় করতে `Ctrl + C/V` লাগে। এই Omarchy একীভূত ক্লিপবোর্ড হটকিগুলো সব জায়গায় কাজ করে।

## ক্যাপচার

| হটকি              | কাজ                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | স্ক্রিনশট                      |
| `Super + Ctrl + Alt + C`            | স্ক্রিনশট (একই শট, Print Screen কি নেই এমন কীবোর্ডের জন্য) |
| `Super + Ctrl + C` | ক্যাপচার মেনু |
| `Alt + Print Screen`            | স্ক্রিনরেকর্ড                     |
| `Super + Print Screen` | কালার পিকার |
| `Super + Ctrl + Print Screen` | ক্লিপবোর্ডে টেক্সট এক্সট্র্যাকশন |
| `Super + Alt + [` | রেকর্ড করার সময় ওয়েবক্যাম ওভারলে ছোট করুন |
| `Super + Alt + ]` | রেকর্ড করার সময় ওয়েবক্যাম ওভারলে বড় করুন |
| `Alt + Shift + L` | ওয়েবঅ্যাপ বা Chromium থেকে বর্তমান URL কপি করুন |
| `Alt + Shift + D` | বর্তমান পেজের ভিডিও `~/Videos`-এ ডাউনলোড করুন |
| `Super + Ctrl + X` | ডিকটেশন শুরু/বন্ধ করুন (প্রয়োজন _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | পুশ-টু-টক ডিকটেশন (Voxtype বা Superwhisper প্রয়োজন) |

স্ক্রিনরেকর্ডিংয়ের ক্ষেত্রে, হটকিটি প্রথমে জিজ্ঞেস করে আপনি কোন অডিও চান, তারপর রেকর্ডিং শুরু করে। আবার চাপলে বন্ধ হবে। বিস্তারিত জানতে [স্ক্রিনশট ও রেকর্ডিং](12-screenshots-recording.md) দেখুন।

সব ক্যাপচার বিকল্প Omarchy মেনুতে (`Super + Space`) _Trigger > Capture_-এর অধীনেও পাওয়া যায়।

## স্টাইল

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Super + Ctrl + T` | একটি নতুন থিম বেছে নিন (`Super + Ctrl + Shift + Space`-ও) |
| `Super + Ctrl + W` | থিমের ব্যাকগ্রাউন্ড বেছে নিন (`Super + Ctrl + Space`-ও) |
| `Super + Backspace` | একটি উইন্ডোতে স্বচ্ছতা টগল করুন |
| `Super + Ctrl + Backspace` | একক-উইন্ডোর বর্গাকার অনুপাত টগল করুন |

অতিরিক্ত ব্যাকগ্রাউন্ড ছবি `~/.config/omarchy/backgrounds/<theme name>`-এ থাকে। Omarchy মেনুতে _Install > Style > Background_-এর মাধ্যমেও পাওয়া যায়।

সব স্টাইল বিকল্প Omarchy মেনুতে (`Super + Space`) _Style_-এর অধীনেও পাওয়া যায়।

## Tmux

প্রিফিক্স কি হলো `Ctrl + Space` (`Ctrl + B`-ও কাজ করে)। আপনি `~/.config/tmux/tmux.conf`-এ এই বাইন্ডিংগুলো পরিবর্তন করতে পারবেন।

### পেন

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Prefix + v` | পাশে পেন ভাগ করুন (উল্লম্ব) |
| `Prefix + h` | নিচে পেন ভাগ করুন (অনুভূমিক) |
| `Prefix + x` | পেন বন্ধ করুন |
| `Prefix + z` | পেন জুম টগল করুন (পূর্ণস্ক্রিন) |
| `Alt + Enter` | নিচে পেন ভাগ করুন (প্রিফিক্স ছাড়া) |
| `Alt + Shift + Enter` | পাশে পেন ভাগ করুন (প্রিফিক্স ছাড়া) |
| `Alt + Escape` | পেন বন্ধ করুন (প্রিফিক্স ছাড়া) |
| `Ctrl + Alt + Arrows` | পেনগুলোর মধ্যে যান |
| `Ctrl + Alt + Shift + Arrows` | পেন রিসাইজ করুন |

### উইন্ডো

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Prefix + c` | নতুন উইন্ডো |

| `Prefix + r` | উইন্ডোর নাম বদলান |
| `Alt + 1-9` | নির্দিষ্ট উইন্ডোতে যান |
| `Alt + Arrow Left/Right` | উইন্ডোগুলোর মধ্যে যান |
| `Alt + Shift + Arrow Left/Right` | উইন্ডো বামে/ডানে সরান |

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |

| `Prefix + K` | সেশন বন্ধ করুন |
| `Prefix + R` | সেশনের নাম বদলান |
| `Prefix + N` | পরের সেশন |
| `Prefix + P` | আগের সেশন |
| `Alt + Arrow Up/Down` | সেশনগুলোর মধ্যে যান |
| `Prefix + s` | সেশনের তালিকা দেখুন |
| `Prefix + d` | সেশন থেকে বিচ্ছিন্ন হোন |

| `Prefix + :` | কমান্ড প্রম্পট |

### Tmux লেআউট ফাংশন

এই ফাংশনগুলো অবশ্যই একটি Tmux সেশনের ভেতরে চালাতে হবে।

| কমান্ড | কাজ |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | এডিটর, AI এবং টার্মিনালসহ ডেভ লেআউট তৈরি করুন |
| `tdlm <ai> [<second_ai>]` | প্রতি সাবডিরেক্টরিতে ডেভ লেআউট তৈরি করুন |
| `tsl <count> <command>` | মাল্টি-পেন সোয়ার্ম লেআউট তৈরি করুন |
