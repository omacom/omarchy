# হটকি

আপনি `Super + K` দিয়ে সব প্রধান কীবোর্ড বাইন্ডিং দেখতে পারবেন (Tmux বাইন্ডিং `Super + Alt + K` দিয়ে এবং Herdr বাইন্ডিং `Super + Ctrl + K` দিয়ে)।

## হটকি কীভাবে সাজানো হয়েছে

প্রতিটি হটকি একটি প্লেনে বসে, যা তার মডিফায়ার দিয়ে নির্ধারিত হয়, এবং প্রতিটি প্লেনের একটি কাজ থাকে। এটাই হটকিগুলোকে এলোমেলো হয়ে যাওয়া থেকে রক্ষা করে, এবং এর মানে হলো আপনি সাধারণত অনুমান করতে পারবেন কোন জিনিস কোথায় থাকে।

| প্লেন | সেখানে যা থাকে | উদাহরণ |
| --- | --- | --- |
| `Super + key` | সিস্টেম: উইন্ডো, ওয়ার্কস্পেস, লেআউট এবং মূল মেনু | `Super + Space` Omarchy মেনু, `Super + W` উইন্ডো বন্ধ করুন, `Super + F` ফুল স্ক্রিন |
| `Super + Shift + key` | অ্যাপ | `Super + Shift + B` ব্রাউজার, `Super + Shift + E` ইমেল, `Super + Shift + N` এডিটর |
| `Super + Ctrl + key` | প্যানেল এবং সিস্টেম মেনু | `Super + Ctrl + A` অডিও, `Super + Ctrl + N` নেটওয়ার্ক, `Super + Ctrl + C` ক্যাপচার মেনু |
| `Super + Ctrl + Alt + key` | দ্রুত কাজ এবং নোটিশ | `Super + Ctrl + Alt + T` সময় দেখান, `Super + Ctrl + Alt + B` ব্যাটারি, `Super + Ctrl + Alt + C` স্ক্রিনশট |

একটি হটকিতে `Alt` যোগ করলে একই জিনিসের একটি ভ্যারিয়েন্ট পাবেন, কখনোই সম্পর্কহীন কিছু নয়:

- `Super + Shift + B` ব্রাউজার খোলে; `Super + Shift + Alt + B` একটি প্রাইভেট উইন্ডো খোলে
- `Super + Shift + E` ইমেল খোলে; `Super + Shift + Alt + E` একটি নতুন ইমেল শুরু করে
- `Super + F` ফুল স্ক্রিনে যায়; `Super + Alt + F` ফুল উইডথে যায়
- `Super + Ctrl + C` ক্যাপচার মেনু খোলে; `Super + Ctrl + Alt + C` মেনু এড়িয়ে স্ক্রিনশট নেয়

হটকি যোগ করার সময়:

1. এটি কী করে তা থেকে প্লেন বেছে নিন, তারপর কী বেছে নিন।
2. জায়গা করার জন্য কোনো বিদ্যমান হটকি সরাবেন না। সঠিক প্লেনে একটি ফাঁকা কী খুঁজুন।
3. `Alt` শুধু তা ছাড়া হটকির একটি ভ্যারিয়েন্টের জন্য ব্যবহার করুন।

কয়েকটি হটকি এই নিয়মগুলো ভাঙে কারণ সেগুলো সুবিধাজনক। একটি তীর বা `Tab`-এর সঙ্গে `Shift` কোনো অ্যাপ খোলার বদলে সরায় বা উল্টো দিকে যায়, এবং `Print`, মিডিয়া কী, `Alt + Tab` এবং `Ctrl + Alt + Del` অন্য সব জায়গায় যেভাবে কাজ করে সেভাবেই কাজ করে। এগুলো ব্যতিক্রম, অনুকরণ করার মতো প্যাটার্ন নয়।

যদি কোনো ডিফল্ট আপনার জন্য উপযুক্ত না হয় (ধরুন আপনি Windows-এর মতো স্ক্রিনশটের জন্য `Super + Shift + S` চান), সেটি `~/.config/hypr/bindings.lua`-তে রিবাইন্ড করুন।

| `Super + Shift + I` | ইনপুট ভাষা আগেরটিতে বদলান |

টাচপ্যাডে, তিন- এবং চার-আঙুলের সোয়াইপ ওয়ার্কস্পেস বদলায়, উইন্ডো সরায় এবং মেনু ও Quake কনসোল খোলে; অঙ্গভঙ্গিগুলোর জন্য [কীবোর্ড, মাউস এবং ট্র্যাকপ্যাড](34-keyboard-mouse-trackpad.md) দেখুন।

রিসাইজিংয়ে 0-এর ডানদিকের দুটি কী ব্যবহার হয়, আপনার কীবোর্ডে সেগুলোতে যা-ই ছাপা থাকুক না কেন: US কীবোর্ডে `-` এবং `=`, Danish এবং Swedish-এ `+` এবং `´`, Norwegian-এ `+` এবং `\`, German-এ `ß` এবং `´`, Spanish-এ `'` এবং `¡`, এবং Japanese (JIS)-এ `-` এবং `^`। `Super + K` সেগুলোকে আপনার কীবোর্ডে যেভাবে ছাপা আছে সেভাবেই তালিকাভুক্ত করে। JIS-এ, `Super + ^` হলো `Super + Equal`, আর `Super + Shift + -` (যা `=` টাইপ করে) হলো `Super + Shift + Minus`। মনিটর স্কেলিং এবং পাসওয়ার্ড ম্যানেজার `/` ব্যবহার করে; যেসব লেআউটে `/` শুধু Shift দিয়ে টাইপ হয়, যেমন বেশিরভাগ European লেআউটে, সেগুলোতে তার বদলে ডান Shift-এর বামদিকের কী ব্যবহার হয় (Danish এবং German-এ `-`)।

| `A` | প্যারেন্ট ডিরেক্টরিতে নতুন ফাইল যোগ করুন |
| `Shift + A` | প্যারেন্ট ডিরেক্টরিতে নতুন সাবডিরেক্টরি যোগ করুন |

| `?` | সব কমান্ডের জন্য সাহায্য দেখান |
