# হটকি

আপনি `Super + K` দিয়ে সব প্রধান কীবোর্ড বাইন্ডিং দেখতে পারেন (Tmux বাইন্ডিং `Super + Alt + K` দিয়ে এবং Herdr বাইন্ডিং `Super + Ctrl + K` দিয়ে)।

## নেভিগেশন

| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy মেনু (অ্যাপ এবং আরও সবকিছু)    |

| `Super + Escape` | সিস্টেম মেনু (সাসপেন্ড, রিস্টার্ট, ইত্যাদি)  |
| `Super + Ctrl + L` | কম্পিউটার লক করুন |

| `Super + Shift + Tab` | ফোকাস করা মনিটরে আগের ওয়ার্কস্পেসে যান |

| `Super + Minus` | উইন্ডো বামে প্রসারিত করুন |

| `Super + Shift + Minus` | উইন্ডো উপরে সংকুচিত করুন |

| `Super + Alt + Shift + Tab`               | গ্রুপিংয়ের ভিতরে উইন্ডোগুলোর মধ্যে পেছনের দিকে চক্রাকারে যান      |
| `Super + Alt + Scroll Wheel` | গ্রুপিংয়ের ভিতরে উইন্ডোগুলোর মধ্যে চক্রাকারে যান |
| `Super + Alt + 1/2/3/4/5`               | গ্রুপিংয়ের ভিতরে নির্দিষ্ট উইন্ডোতে যান      |
| `Super + Alt + Arrow`  | তীরের দিকে উইন্ডোকে গ্রুপিংয়ে সরান, সেই পাশের মনিটরে থাকা একটিসহ |
| `Super + Ctrl + Left/Right`  | টাইলিং গ্রুপের ভিতরে উইন্ডোগুলোর মধ্যে যান |
| `Super + Ctrl + Z` | স্ক্রিনে জুম ইন করুন (আরও জুমের জন্য আবার চাপুন) |
| `Super + Ctrl + Alt + Z` | স্ক্রিন থেকে পুরোপুরি জুম আউট করুন |
| `Super + /` | মনিটর স্কেলিং অপশনগুলোতে সামনে এগিয়ে যান |
| `Super + Alt + /` | মনিটর স্কেলিং অপশনগুলোতে পেছনে এগিয়ে যান |
| `Alt + Tab` | সক্রিয় ওয়ার্কস্পেসে উইন্ডোগুলোর মধ্যে সামনে চক্রাকারে যান |
| `Alt + Shift + Tab` | সক্রিয় ওয়ার্কস্পেসে উইন্ডোগুলোর মধ্যে পেছনে চক্রাকারে যান |
| `Ctrl + Alt + Tab`| মনিটরগুলোর মধ্যে ফোকাস সামনে চক্রাকারে নিন |
| `Ctrl + Alt + Shift + Tab`| মনিটরগুলোর মধ্যে ফোকাস পেছনে চক্রাকারে নিন |

আকার পরিবর্তনের শর্টকাটগুলো ফিজিক্যাল কী `code:20` এবং `code:21` (XKB `<AE11>` এবং `<AE12>`) ব্যবহার করে, কীবোর্ডে ছাপা অক্ষর যাই হোক না কেন। US কীবোর্ডে এই কীগুলো `-` এবং `=`; জাপানি (JIS) কীবোর্ডে এগুলো `-` এবং `^`; স্প্যানিশ কীবোর্ডে এগুলো `'` এবং `¡`। JIS-এ, `Super + ^` হলো `Super + Equal`, আর `Super + Shift + -` (যাতে `=` টাইপ হয়) হলো `Super + Shift + Minus`।

## সার্বজনীন ক্লিপবোর্ড

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Super + A`           | যেসব অ্যাপ `Ctrl + A` সমর্থন করে সেগুলোতে সব নির্বাচন করুন    |
| `Super + C`           | কপি করুন    |
| `Super + X`           | কাট করুন (টার্মিনালে নয়)    |
| `Super + V`           | পেস্ট করুন    |
| `Super + Ctrl + V`           | ক্লিপবোর্ড ম্যানেজার    |

সাধারণত Linux-এ, টার্মিনালে কপি'ন'পেস্ট করতে আপনার `Ctrl + Shift + C/V` লাগে এবং অন্য সব জায়গায় করতে লাগে `Ctrl + C/V`। এই Omarchy-র একীভূত ক্লিপবোর্ড হটকিগুলো সব জায়গায় কাজ করে।

## ক্যাপচার

| হটকি              | কাজ                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | স্ক্রিনশট                      |
| `Super + Ctrl + Alt + C`            | স্ক্রিনশট (একই শট, যেসব কীবোর্ডে Print Screen কী নেই সেগুলোর জন্য) |
| `Super + Ctrl + C` | ক্যাপচার মেনু |
| `Alt + Print Screen`            | স্ক্রিনরেকর্ড                     |
| `Super + Print Screen` | রঙ বাছাইকারী |
| `Super + Ctrl + Print Screen` | ক্লিপবোর্ডে টেক্সট এক্সট্র্যাকশন |
| `Super + Alt + [` | রেকর্ডিংয়ের সময় ওয়েবক্যাম ওভারলে ছোট করুন |
| `Super + Alt + ]` | রেকর্ডিংয়ের সময় ওয়েবক্যাম ওভারলে বড় করুন |
| `Alt + Shift + L` | ওয়েবঅ্যাপ বা Chromium থেকে বর্তমান URL কপি করুন |
| `Alt + Shift + D` | বর্তমান পেজের ভিডিও `~/Videos`-এ ডাউনলোড করুন |
| `Super + Ctrl + X` | ডিক্টেশন শুরু/বন্ধ করুন (প্রয়োজন _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | পুশ-টু-টক ডিক্টেশন (প্রয়োজন Voxtype বা Superwhisper) |

স্ক্রিনরেকর্ডিংয়ের ক্ষেত্রে, হটকিটি প্রথমে জিজ্ঞেস করে আপনি কোন অডিও চান, তারপর রেকর্ডিং শুরু করে। বন্ধ করতে আবার চাপুন। বিস্তারিত জানতে [স্ক্রিনশট এবং রেকর্ডিং](12-screenshots-recording.md) দেখুন।

সব ক্যাপচার অপশন Omarchy মেনুতে (`Super + Space`) _Trigger > Capture_-এর অধীনেও পাওয়া যায়।

অতিরিক্ত ব্যাকগ্রাউন্ড ছবি `~/.config/omarchy/backgrounds/<theme name>`-এ থাকে। Omarchy মেনুতে _Install > Style > Background_ দিয়েও পাওয়া যায়।

সব স্টাইল অপশন Omarchy মেনুতে (`Super + Space`) _Style_-এর অধীনেও পাওয়া যায়।

## Tmux

প্রিফিক্স কী হলো `Ctrl + Space` (`Ctrl + B`-ও কাজ করে)। আপনি এই বাইন্ডিংগুলো `~/.config/tmux/tmux.conf`-এ পরিবর্তন করতে পারেন।

### প্যান

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Prefix + v` | পাশে প্যান ভাগ করুন (উল্লম্ব) |
| `Prefix + h` | নিচে প্যান ভাগ করুন (অনুভূমিক) |
| `Prefix + x` | প্যান বন্ধ করুন |
| `Prefix + z` | প্যান জুম টগল করুন (পূর্ণ স্ক্রিন) |
| `Alt + Enter` | নিচে প্যান ভাগ করুন (প্রিফিক্স ছাড়া) |
| `Alt + Shift + Enter` | পাশে প্যান ভাগ করুন (প্রিফিক্স ছাড়া) |
| `Alt + Escape` | প্যান বন্ধ করুন (প্রিফিক্স ছাড়া) |
| `Ctrl + Alt + Arrows` | প্যানগুলোর মধ্যে যান |
| `Ctrl + Alt + Shift + Arrows` | প্যানগুলোর আকার পরিবর্তন করুন |

### উইন্ডো

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Prefix + c` | নতুন উইন্ডো |
| `Prefix + k` | উইন্ডো বন্ধ করুন |
| `Prefix + r` | উইন্ডোর নাম পরিবর্তন করুন |
| `Alt + 1-9` | নির্দিষ্ট উইন্ডোতে যান |
| `Alt + Arrow Left/Right` | উইন্ডোগুলোর মধ্যে যান |
| `Alt + Shift + Arrow Left/Right` | উইন্ডো বামে/ডানে সরান |

### সেশন

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Prefix + C` | নতুন সেশন |
| `Prefix + K` | সেশন বন্ধ করুন |
| `Prefix + R` | সেশনের নাম পরিবর্তন করুন |
| `Prefix + N` | পরের সেশন |
| `Prefix + P` | আগের সেশন |
| `Alt + Arrow Up/Down` | সেশনগুলোর মধ্যে যান |
| `Prefix + s` | সেশনগুলোর তালিকা দেখুন |
| `Prefix + d` | সেশন থেকে বিচ্ছিন্ন হোন |

### কপি মোড (vi-স্টাইল)

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Prefix + [` | কপি মোডে প্রবেশ করুন |
| `v` | নির্বাচন শুরু করুন (কপি মোডে) |
| `y` | নির্বাচন কপি করুন (কপি মোডে) |

### সাধারণ

| হটকি                  | কাজ              |
| ----------------------- | --------------------- |
| `Prefix + q` | কনফিগ রিলোড করুন |
| `Prefix + ?` | Tmux কীবাইন্ডিং দেখান |
| `Prefix + :` | কমান্ড প্রম্পট |

### Tmux লেআউট ফাংশন

এই ফাংশনগুলো একটি Tmux সেশনের ভিতরে চালাতে হবে।

| কমান্ড | কাজ |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | এডিটর, AI, এবং টার্মিনালসহ ডেভ লেআউট তৈরি করুন |
| `tdlm <ai> [<second_ai>]` | প্রতিটি সাবডিরেক্টরি অনুযায়ী ডেভ লেআউট তৈরি করুন |
| `tsl <count> <command>` | মাল্টি-প্যান swarm লেআউট তৈরি করুন |
