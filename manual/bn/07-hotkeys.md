# হটকি

আপনি `Super + K` দিয়ে সব প্রধান কীবোর্ড বাইন্ডিং দেখতে পারেন (Tmux বাইন্ডিং `Super + Alt + K` দিয়ে এবং Herdr বাইন্ডিং `Super + Ctrl + K` দিয়ে)।

## হটকিগুলো কীভাবে সাজানো

প্রতিটি হটকি একটি প্লেনে থাকে, যা তার মডিফায়ার দিয়ে নির্ধারিত, এবং প্রতিটি প্লেনের একটি কাজ আছে। এটাই হটকিগুলোকে একে অপরের সঙ্গে গুলিয়ে যাওয়া থেকে বাঁচায়, এবং এর মানে হলো আপনি সাধারণত অনুমান করতে পারবেন কোনটা কোথায় থাকে।

| প্লেন | সেখানে যা থাকে | উদাহরণ |
| --- | --- | --- |
| `Super + key` | সিস্টেম: উইন্ডো, ওয়ার্কস্পেস, লেআউট এবং মূল মেনু | `Super + Space` Omarchy মেনু, `Super + W` উইন্ডো বন্ধ করুন, `Super + F` ফুল স্ক্রিন |
| `Super + Shift + key` | অ্যাপ | `Super + Shift + B` ব্রাউজার, `Super + Shift + E` ইমেল, `Super + Shift + N` এডিটর |
| `Super + Ctrl + key` | প্যানেল এবং সিস্টেম মেনু | `Super + Ctrl + A` অডিও, `Super + Ctrl + N` নেটওয়ার্ক, `Super + Ctrl + C` ক্যাপচার মেনু |
| `Super + Ctrl + Alt + key` | দ্রুত অ্যাকশন এবং নোটিশ | `Super + Ctrl + Alt + T` সময় দেখান, `Super + Ctrl + Alt + B` ব্যাটারি, `Super + Ctrl + Alt + C` স্ক্রিনশট |

একটি হটকিতে `Alt` যোগ করলে আপনি একই জিনিসের একটি ভ্যারিয়েন্ট পান, কখনোই সম্পর্কহীন কিছু নয়:

- `Super + Shift + B` ব্রাউজার খোলে; `Super + Shift + Alt + B` একটি প্রাইভেট উইন্ডো খোলে
- `Super + Shift + E` ইমেল খোলে; `Super + Shift + Alt + E` একটি নতুন ইমেল শুরু করে
- `Super + F` ফুল স্ক্রিনে যায়; `Super + Alt + F` ফুল উইডথে যায়
- `Super + Ctrl + C` ক্যাপচার মেনু খোলে; `Super + Ctrl + Alt + C` মেনু এড়িয়ে স্ক্রিনশট নেয়

একটি হটকি যোগ করার সময়:

1. এটি কী করে তা থেকে প্লেন বেছে নিন, তারপর কী বেছে নিন।
2. জায়গা করার জন্য বিদ্যমান কোনো হটকি সরাবেন না। সঠিক প্লেনে একটি ফাঁকা কী খুঁজুন।
3. `Alt` শুধু তা ছাড়া হটকির একটি ভ্যারিয়েন্টের জন্য ব্যবহার করুন।

কিছু হটকি এই নিয়ম ভাঙে কারণ সেগুলো সুবিধাজনক। একটি তীর বা `Tab`-এর সঙ্গে `Shift` অ্যাপ খোলার বদলে সরায় বা বিপরীত দিকে যায়, এবং `Print`, মিডিয়া কীগুলো, `Alt + Tab` এবং `Ctrl + Alt + Del` অন্য সব জায়গায় যেভাবে কাজ করে সেভাবেই কাজ করে। এগুলো ব্যতিক্রম, অনুকরণ করার প্যাটার্ন নয়।

যদি কোনো ডিফল্ট আপনার পছন্দ না হয় (ধরুন আপনি Windows-এর মতো স্ক্রিনশটের জন্য `Super + Shift + S` চান), তাহলে `~/.config/hypr/bindings.lua`-তে এটি রিবাইন্ড করুন।

| `Super + Alt + /` | মনিটর স্কেলিং অপশনগুলোতে পিছনে এগিয়ে যান |

| `Ctrl + Alt + Tab` | মনিটরগুলোর মধ্যে ফোকাস সামনে চক্রাকারে নিন |
| `Ctrl + Alt + Shift + Tab` | মনিটরগুলোর মধ্যে ফোকাস পিছনে চক্রাকারে নিন |

রিসাইজ শর্টকাটগুলো ফিজিক্যাল কী `code:20` এবং `code:21` (XKB `<AE11>` এবং `<AE12>`) ব্যবহার করে, কীবোর্ডে ছাপানো অক্ষর যাই হোক না কেন। US কীবোর্ডে এই কীগুলো `-` এবং `=`; জাপানি (JIS) কীবোর্ডে এগুলো `-` এবং `^`; স্প্যানিশ কীবোর্ডে এগুলো `'` এবং `¡`। JIS-এ, `Super + ^` হলো `Super + Equal`, আর `Super + Shift + -` (যা `=` টাইপ করে) হলো `Super + Shift + Minus`।

## ইউনিভার্সাল ক্লিপবোর্ড

| হটকি | কাজ |
| ----------------------- | --------------------- |
| `Super + A` | যেসব অ্যাপ `Ctrl + A` সমর্থন করে সেগুলোতে সব নির্বাচন করুন |
| `Super + C` | কপি করুন |
| `Super + X` | কাট করুন (টার্মিনালে নয়) |
| `Super + V` | পেস্ট করুন |
| `Super + Ctrl + V` | ক্লিপবোর্ড ম্যানেজার |

সাধারণত Linux-এ, টার্মিনালে কপি-পেস্ট করতে আপনার `Ctrl + Shift + C/V` লাগে এবং অন্য সব জায়গায় করতে `Ctrl + C/V` লাগে। এই Omarchy-এর একীভূত ক্লিপবোর্ড হটকিগুলো সব জায়গায় কাজ করে।

## Tmux

Prefix কী হলো `Ctrl + Space` (`Ctrl + B`-ও কাজ করে)। আপনি এই বাইন্ডিংগুলো `~/.config/tmux/tmux.conf`-এ বদলাতে পারেন।

### পেন

| হটকি | কাজ |
| ----------------------- | --------------------- |
| `Prefix + v` | পাশে পেন বিভক্ত করুন (উল্লম্ব) |
| `Prefix + h` | নিচে পেন বিভক্ত করুন (অনুভূমিক) |

| `Alt + Escape` | পেন কিল করুন (প্রিফিক্স ছাড়া) |
