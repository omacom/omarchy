# অন্যান্য প্যাকেজ

Arch-এর কাছে সরকারি রিপোজিটরি এবং Arch User Repository (AUR)-এর মধ্যে প্রায় যেকোনো ধরনের সফটওয়্যারের জন্য আশ্চর্য রকমের প্রচুর প্যাকেজ পাওয়া যায়।

যেকোনো একটি ব্যবহার করাও এর চেয়ে সহজ হতে পারত না। আপনি Omarchy মেনুতে (`Super + Space`) _ইনস্টল > Package_-এ গিয়ে এবং আপনি যে প্যাকেজটি চান তা টাইপ করে একটি নতুন Arch প্যাকেজ ইনস্টল করেন। এটি স্বয়ংক্রিয়ভাবে সব প্যাকেজের তালিকাটি ফাজি পদ্ধতিতে ছেঁকে নেবে। (আপনি টার্মিনালে `omarchy pkg add [package]` ব্যবহার করে হাতেও এটি করতে পারেন)।

আপনি AUR দিয়েও একই কাজ করতে পারেন, শুধু _ইনস্টল > AUR_ ব্যবহার করুন। শুধু মনে রাখুন যে AUR Arch দলের দ্বারা যাচাই করা নয়। এটি RubyGems বা npm-এর মতো। যে কেউ আপলোড করতে পারে।

আপনি কোনো প্যাকেজ সরাতে চাইলে, Omarchy মেনু থেকে _সরান > Package_ ব্যবহার করতে পারেন। এটি প্যাকেজ, কনফিগ ফাইল এবং ডিপেন্ডেন্সিগুলো সরাবে। (আপনি `omarchy pkg drop [package]` ব্যবহার করে হাতেও এটি করতে পারেন)।
