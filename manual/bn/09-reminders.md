# রিমাইন্ডার

Omarchy-তে কাউন্টডাউন টাইমার ও একটি বার্তার ভিত্তিতে সহজ রিমাইন্ডার সেট করার অন্তর্নির্মিত উপায় রয়েছে। আপনি `Super + Ctrl + R` দিয়ে এটি করতে পারেন, `Super + Ctrl + Alt + R` দিয়ে সেট করা সবগুলো দেখতে পারেন এবং `Super + Ctrl + Shift + R` দিয়ে সব মুছতে পারেন। সবকিছু _ট্রিগার > রিমাইন্ডার_ দিয়েও পাওয়া যায়। আপনি `omarchy reminder 7 'Tea ready'` দিয়ে CLI-ও ব্যবহার করতে পারেন।
