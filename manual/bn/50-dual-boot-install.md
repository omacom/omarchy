# ডুয়াল বুট ইনস্টল

আপনি Windows বা অন্যান্য ইনস্টলেশনের পাশাপাশি একটি একক পার্টিশনে Omarchy ইনস্টল করতে পারবেন।

এই ইনস্টলেশন পদ্ধতিতে ডিফল্টভাবে পার্টিশনের জন্য LUKS এনক্রিপশন থাকেই, তাই এটি কার্যত সম্পূর্ণ ড্রাইভে ইনস্টল করার থেকে আলাদা কিছু নয় এবং ডিস্কে কেবল ফাঁকা জায়গা থাকলেই চলবে।

## Windows-এ জায়গা তৈরি করা

Windows-এর পাশাপাশি ইনস্টল করতে স্টার্ট মেনুতে `disk management` লিখুন এবং **Create and format hard disk partitions** বিকল্পটি নির্বাচন করুন।

 ![dual-boot-1](images/dual-boot-1.webp)

উপযুক্ত পার্টিশনটি খুঁজুন, ডান-ক্লিক করুন এবং **Shrink Volume** বেছে নিন।

![dual-boot-2](images/dual-boot-2.webp)

 আপনি ভলিউমটি যতটা ছোট করতে চান তার পরিমাণ লিখুন। মনে রাখবেন, এটাই হবে বুট পার্টিশনসহ আপনার ভবিষ্যৎ Omarchy ইনস্টলের আকার।

 ![dual-boot-3](images/dual-boot-3.webp)

শেষ হলে আপনার এরকম কিছু দেখা উচিত, যেখানে এই উদাহরণে 50GB অংশটিতে আমরা Omarchy ইনস্টল করব।

 ![dual-boot-4](images/dual-boot-4.webp)

## Omarchy ইনস্টল করা

Omarchy-র ইনস্টল প্রক্রিয়াটি কার্যত স্বাভাবিক প্রক্রিয়ার মতোই। আপনি আপনার ডিস্ক নির্বাচন করার পর আপনাকে **Free space install** বিকল্পটি দেওয়া হবে। সম্পূর্ণ ডিস্ক মুছে ফেলা এড়াতে সেই বিকল্পটি নির্বাচন করুন।

 ![dual-boot-5](images/dual-boot-5.webp)

সবকিছু ঠিকঠাক আছে কিনা নিশ্চিত করুন এবং স্বাভাবিকভাবেই ইনস্টল শেষ হওয়ার জন্য অপেক্ষা করুন। এখানেই আপনি সম্পূর্ণ ড্রাইভে ইনস্টলের মতোই এনক্রিপশন ছাড়া ইনস্টল করাও বেছে নিতে পারেন (প্রস্তাবিত নয়)।
 ![dual-boot-6](images/dual-boot-6.webp)

## Bootloader-এ অন্যান্য ইনস্টল যোগ করা

আপনার Omarchy ইনস্টল শেষ হলে আপনি লক্ষ্য করবেন যে এখন Limine bootloader-ই ডিফল্ট। এটি দিয়ে আপনি Windows-এর মতো আপনার অন্যান্য ইনস্টলের জন্যও Limine-তে বিকল্প যোগ করতে পারবেন।

অন্যান্য অপারেটিং সিস্টেম যোগ করতে `limine-scan` চালান এবং আপনার Limine কনফিগে পছন্দের এন্ট্রিগুলো যোগ করতে নির্দেশনাগুলো অনুসরণ করুন। বুট মেনুটি ডিফল্টভাবে লুকানো থাকে এবং এক সেকেন্ড পরে Omarchy চালু হয়ে যায়। Windows বা অন্য কোনো এন্ট্রি বেছে নিতে Limine চালু হওয়ার সঙ্গে সঙ্গে যেকোনো কী চাপুন; মেনুটি এলে তীর কীগুলো ব্যবহার করে একটি এন্ট্রি নির্বাচন করুন এবং Enter চাপুন। আপনি কী চাপার আগেই Omarchy চালু হয়ে গেলে পুনরায় চালু করে আবার চেষ্টা করুন।

## Bitlocker

লক্ষ্য করা জরুরি যে এই ইনস্টলেশন পদ্ধতিটি Bitlocker-এর সঙ্গে সামঞ্জস্যপূর্ণ নয়, কারণ এটি শুধু পার্টিশন নয়, সম্পূর্ণ ড্রাইভ এনক্রিপ্ট করে। Bitlocker চালু আছে বলে কোনো ত্রুটি দেখলে Windows-এ বুট করুন, **Settings -> Privacy & Security -> Device encryption**-এ যান এবং Bitlocker বন্ধ করে দিন। ড্রাইভ ডিক্রিপ্ট হতে কিছুটা সময় লাগতে পারে।

 ![dual-boot-7](images/dual-boot-7.webp)

## Windows পুনরায় ইনস্টল করা

এই কম্পিউটারটি Windows-সহ এসে থাকলে এর প্রোডাক্ট কী ফার্মওয়্যারে সংরক্ষিত থাকে। সেটি প্রিন্ট করতে `omarchy windows key` চালান, যাতে আপনি কখনো এই মেশিনে Windows পুনরায় ইনস্টল করলে আবার তা সক্রিয় করতে পারেন।
