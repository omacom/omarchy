# কীবোর্ড, মাউস, ট্র্যাকপ্যাড

Hyprland আপনাকে আপনার সব ইনপুট অত্যন্ত বিস্তারিতভাবে কনফিগার করতে দেয়। আপনি কীবোর্ড রিপিটকে অতিসোনিক দ্রুত করতে পারেন কিংবা ট্র্যাকপ্যাডে ন্যাচারাল স্ক্রলিং ব্যবহার করতে পারেন। এসবই আপনি পরিবর্তন করেন `~/.config/hypr/input.lua`-তে, যেখানে Omarchy মেনু (`Super + Space`) দিয়ে _সেটআপ > ইনপুট_ থেকেও পৌঁছাতে পারেন। সেখানে আপনি যা সেট করবেন, তা Omarchy-র ডিফল্টগুলোকে প্রতিস্থাপন করবে।

এখানে একটি উদাহরণ দেওয়া হলো:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

আপনি Hyprland উইকিতে ইনপুটের জন্য [সব ইনপুট অপশন দেখতে পারেন](https://wiki.hypr.land/Configuring/Basics/Variables/#input)।

CapsLock সাধারণ Caps Lock হিসেবে কাজ করে, এবং `Shift + CapsLock` হলো [দ্রুত ইমোজি](07-hotkeys.md#quick-emojis) ও [অন্যান্য কমপ্লিশন](07-hotkeys.md#quick-completions)-এর জন্য কম্পোজ কী। আপনি যদি বরং কম্পোজ কী অন্য কোথাও রাখতে চান, তাহলে `kb_options`-এ `omarchy:shift_caps_compose` প্রতিস্থাপন করুন। উদাহরণস্বরূপ, এটি কম্পোজ কীকে Right Alt-এ সরিয়ে দেয়:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### ট্র্যাকপ্যাড জেসচার

ডেস্কটপে ঘোরাফেরা করতে ট্র্যাকপ্যাডে সোয়াইপ করুন:

| জেসচার | অ্যাকশন |
| --- | --- |
| তিন আঙুল বামে / ডানে | আগের / পরের ওয়ার্কস্পেস, খালিগুলোসহ |
| তিন আঙুল উপরে | AI কনসোল টগল করা |
| তিন আঙুল নিচে | Omarchy মেনু খোলা |
| চার আঙুল বামে / ডানে | সক্রিয় উইন্ডোটিকে আগের / পরের ওয়ার্কস্পেসে সরানো |
| চার আঙুল নিচে | ফুলস্ক্রিন টগল করা |

কোনো একটি পরিবর্তন করতে, আপনার নিজের [টাচপ্যাড জেসচার](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/) যোগ করার আগে `~/.config/hypr/input.lua`-তে সেটি আনসেট করুন, কারণ Hyprland একই আঙুল ও একই দিকে দুটি জেসচার নেবে না:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Omarchy-র সব জেসচার বন্ধ করতে, Omarchy-র ডিফল্টগুলো লোড হওয়ার আগে, `~/.config/hypr/hyprland.lua`-এর উপরের দিকের কাছাকাছি `omarchy_default_gestures = false` সেট করুন।

হ্যাপটিক টাচপ্যাডযুক্ত Dell XPS ল্যাপটপে, আপনি _ট্রিগার > হার্ডওয়্যার > টাচপ্যাড হ্যাপটিক্স_-এর অধীনে ক্লিকের শক্তি লো, মিড বা হাই হিসেবেও সেট করতে পারেন।

### চীনা, জাপানি এবং অন্যান্য ভাষায় টাইপ করা

ইনস্টলার যখন আপনার কীবোর্ড সম্পর্কে জিজ্ঞাসা করবে, তখন জাপানি, কোরিয়ান, চীনা (সরলীকৃত, Pinyin), তাইওয়ান (Zhuyin) বা হংকং (Cangjie) নির্বাচন করুন। Omarchy স্বয়ংক্রিয়ভাবে কীবোর্ড এবং মিলে যাওয়া ইনপুট ইঞ্জিন কনফিগার করে, অফলাইন ফার্স্ট-বুট সেটআপের সময়সহ। জাপানি Mozc ব্যবহার করে, কোরিয়ান স্ট্যান্ডার্ড দুই-সেট Hangul ব্যবহার করে, সরলীকৃত চীনা Pinyin ব্যবহার করে, তাইওয়ান Chewing-এর স্ট্যান্ডার্ড Zhuyin বিন্যাস ব্যবহার করে, এবং হংকং হংকং অক্ষর রূপসহ Cangjie ব্যবহার করে। জাপানি (US কীবোর্ড) একটি US কীবোর্ড লেআউটসহ Mozc প্রদান করে। Hangul, Zhuyin এবং Cangjie কীগুলো তাদের স্ট্যান্ডার্ড অবস্থানেই থাকে, এমনকি আপনি Dvorak, Colemak বা AZERTY দিয়ে লাতিন অক্ষর টাইপ করলেও। আপনি যদি এর আগে Hangul বা Chewing যোগ করে থাকেন, তাহলে এর কীগুলো সেখানে সরাতে _সেটআপ > টাইপিং > ইনপুট পদ্ধতি_-এর অধীনে সেটি অনির্বাচন করে আবার নির্বাচন করুন; আপনি ইতিমধ্যে যে ইঞ্জিন দিয়ে টাইপ করেন, Omarchy সেটিকে একা ছেড়ে দেয়।

টাইপিং লাতিন মোডে শুরু হয়। কনফিগার করা ইনপুট পদ্ধতিগুলোর মধ্যে চক্রাকারে ঘুরতে `Super + I` চাপুন, এবং পেছনের দিকে চক্রাকারে ঘুরতে `Super + Shift + I` চাপুন। Pinyin-এর মতো একটি ইনপুট পদ্ধতি থেকে বেরিয়ে লাতিন অক্ষরে যেতে নিজে থেকে `Shift` ট্যাপ করুন, এবং ফিরে যেতে আবার ট্যাপ করুন, ঠিক যেভাবে Sogou, Microsoft Pinyin এবং macOS কাজ করে; `Shift` এবং একটি অক্ষর একসঙ্গে চাপলে এখনও বড় হাতের অক্ষর টাইপ হয়। জাপানি কীবোর্ডে, 全角/半角 ইনপুট টগল করে, 変換 এটি চালু করে, এবং 無変換 এটি বন্ধ করে। কোরিয়ানের ক্ষেত্রে, 한/영 Hangul সুইচ করে এবং 한자 Hanja-তে রূপান্তর করে, আপনার কীবোর্ডে ডেডিকেটেড কী থাকুক কিংবা অনেক ল্যাপটপের মতো সেগুলোর জন্য Right Alt এবং Right Ctrl পাঠাক, তাই সেখানে Right Alt এবং Right Ctrl সাধারণ মডিফায়ার নয়; এর পরিবর্তে ডিক্টেশন Alt + Space দিয়ে টগল হয়। `Ctrl + Space` Tmux এবং Herdr-এর জন্য উপলব্ধ থাকে; `Shift + CapsLock` কম্পোজ কী হিসেবেই থাকে।

আপনার একাধিক কীবোর্ড লেআউট বা ইনপুট পদ্ধতি থাকলে বারের ডানদিকে কীবোর্ড নির্দেশকটি দেখা যায়। ইনপুট ভাষা সুইচ করতে এতে ক্লিক করুন; জাপানির ক্ষেত্রে হিরাগানার জন্য あ প্রদর্শিত হয়। জাপানি অক্ষরের পছন্দগুলোর জন্য, জাপানিতে সুইচ করুন, `nihongo`-এর মতো একটি শব্দ টাইপ করুন, তারপর Space দুইবার চাপুন। আপনার পছন্দ গ্রহণ করতে Enter চাপুন। আপনার যদি একাধিক কীবোর্ড লেআউটও থাকে, তাহলে সেগুলোর মধ্যে চক্রাকারে ঘুরতে নির্দেশকটিতে রাইট-ক্লিক করুন।

ইংরেজি এবং ফরাসির মতো লেআউট নির্বাচন করতে _সেটআপ > টাইপিং > কীবোর্ড লেআউট_ ব্যবহার করুন, ইনস্টলেশনের সময় দেওয়া একই পছন্দগুলো থেকে। কোন কম্পোজিশন ইঞ্জিনগুলো সক্রিয় থাকবে তা নির্বাচন করতে _সেটআপ > টাইপিং > ইনপুট পদ্ধতি_ ব্যবহার করুন। দুটি পিকারই Omarchy মেনুর ভিতরে খোলে, যেখানে আপনার বর্তমান নির্বাচনগুলো চেক করা থাকে। কোনো পছন্দ টগল করতে ক্লিক করুন বা Enter চাপুন; প্রতিটি পরিবর্তন সঙ্গে সঙ্গে প্রয়োগ হয়। কোনো ইনপুট পদ্ধতি অনির্বাচন করলে সেটিকে আনইনস্টল না করেই চক্র থেকে সরিয়ে দেওয়া হয়; কীবোর্ডটি উপলব্ধ থাকে।

একই পিকারগুলো খুলতে `omarchy setup keyboard` বা `omarchy setup input` চালান। কমান্ড লাইন থেকে একটি ভাষা যুক্ত করতে, `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` বা `cangjie5` ব্যবহার করুন। Quick, Boshiamy এবং Array, Cangjie-এর একই প্যাকেজে আসে এবং ইনপুট পদ্ধতি পিকারে দেখা যায়। আপনার কাস্টম সুইচিং কীগুলো সংরক্ষিত থাকে। বিকল্প ইঞ্জিন লেআউট বা কীগুলোর জন্য, `omarchy pkg add fcitx5-configtool` দিয়ে `fcitx5-configtool` ইনস্টল করুন এবং একটি টার্মিনাল থেকে এটি চালু করুন। একটি ইনপুট ভাষা নির্বাচন করলে ডেস্কটপের ভাষা পরিবর্তন হয় না। আপনার এখনও কোনো ইনপুট পদ্ধতি না থাকলে, _সেটআপ > ভাষা_-এর অধীনে জাপানি, কোরিয়ান বা চীনা বেছে নিলে তার ইনপুট পদ্ধতি যোগ হয়ে যায়।

ইনপুট পদ্ধতি বা কীবোর্ড লেআউটগুলোর মধ্যে চক্রাকারে ঘুরতে `Super + I` ব্যবহার করুন, এবং অন্য দিকে ফিরে যেতে `Super + Shift + I` ব্যবহার করুন, তাই তিনটি কনফিগার করা থাকলে আপনি দুটি প্রতিবেশীর মধ্যে চলাচল করতে পারবেন। ইনপুট নির্দেশকটি বারের ডানদিকে কেবল তখনই দেখা যায় যখন একাধিক ইনপুট পদ্ধতি বা লেআউট কনফিগার করা থাকে। এই ডেস্কটপ বাইন্ডিংটি আপনার বিদ্যমান Fcitx সুইচিং কীগুলোর পাশাপাশি কাজ করে; আপনি `~/.config/hypr/bindings.lua`-তে এটি ওভাররাইড করতে পারেন। ইনপুট ইঞ্জিন এবং কম্পোজ সিকোয়েন্সগুলো প্রতিটি সেশনে ইতিমধ্যে চলমান [Fcitx5](https://fcitx-im.org/) পরিষেবাটি ব্যবহার করে।

### SUPER হিসেবে ALT ব্যবহার করা

কিছু কীবোর্ডে, প্রাথমিক মেটা কী (Windows/cmd কী) SUPER হিসেবে ব্যবহার করা সুবিধাজনক নয়। এই পরিবর্তনটি ব্যবহার করে আপনি এর পরিবর্তে ALT ব্যবহার করার জন্য এটি পরিবর্তন করতে পারেন:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
