# TUI

## Lazygit

[Lazygit](https://github.com/jesseduffield/lazygit) হলো GitHub Desktop অ্যাপ্লিকেশনের মতো কিছুর একটি মনোরম বিকল্প, এবং এটি টার্মিনালের ভেতরে চলে।

আপনি git দিয়ে পরিচালিত যেকোনো ডিরেক্টরিতে গিয়ে `lazygit` চালিয়ে এটি সরাসরি চালাতে পারেন। অথবা আপনি এটি Neovim-এর ভেতরে চালাতে পারেন যেখানে এটি `Space G G` দিয়ে শুরু করা যায়।

আপনি `Tab` ব্যবহার করে বিভিন্ন পেনের মধ্যে লাফ দেন। Files পেনে, আপনি `Space` ব্যবহার করে স্টেজিংয়ের জন্য ফাইল বেছে নেন, এবং তারপর আপনি `c` ব্যবহার করে একটি নতুন কমিট তৈরি করতে পারেন। আপনি `?` ব্যবহার করে পাওয়া যাওয়া সব কমান্ড দেখতে পারেন।

## Btop

[Btop](https://github.com/aristocratos/btop) হলো একটি সুন্দর রিসোর্স ম্যানেজার যা মেমরি, CPU, ডিস্ক এবং নেটওয়ার্কের ব্যবহার দেখায়। এটি সব সক্রিয় প্রসেসের তালিকাও দেয়, এবং আপনাকে সেগুলো পরিচালনা করতে দেয়।

Omarchy এটিকে Activity বলে ডাকে, এবং আপনি `Super + Ctrl + T` চেপে এটি শুরু করেন। এটি একটি ভাসমান উইন্ডো হিসেবে খোলে, যেটিকে আপনি `Super + T` দিয়ে টাইল করতে পারেন।

## Herdr

[Herdr](https://github.com/omacom-io/herdr) হলো একটি টার্মিনাল ওয়ার্কস্পেস ম্যানেজার যা আপনাকে ওয়ার্কস্পেস, ট্যাব এবং পেন দেয়, এবং সেগুলো সব একটি স্থায়ী সেশনে চালু রাখে যা থেকে আপনি বিচ্ছিন্ন হয়ে পরে আবার ফিরে আসতে পারেন।

আপনি `Super + Ctrl + Return` দিয়ে এটি শুরু করেন (অথবা আপনার বিদ্যমান সেশনে পুনরায় সংযুক্ত হন)। Omarchy একটি Herdr কনফিগারেশন পাঠায় যা তার Tmux কনফিগের প্রতিচ্ছবি, তাই এখানেও প্রিফিক্স কী হলো `Ctrl + Space`। আপনি `Super + Ctrl + K` দিয়ে সব কিবাইন্ডিং দেখতে পারেন।

## Fastfetch

[Fastfetch](https://github.com/fastfetch-cli/fastfetch) সিস্টেমের তথ্য দেখায়, যেমন কার্নেলের সংস্করণ, আপটাইম, থিম, CPU, মেমরি এবং আরও অনেক কিছু। এটি জনপ্রিয় neofetch টুলের উত্তরসূরি।

Omarchy এটিকে Omarchy মেনুতে (`Super + Space`) _সম্পর্কে_ হিসেবে প্যাকেজ করেছে।

## Cliamp

[Cliamp](https://www.cliamp.stream/) হলো Winamp 2.x অনুপ্রাণিত একটি রেট্রো টার্মিনাল মিউজিক প্লেয়ার, যাতে lo-fi বিটের জন্য অন্তর্নির্মিত রেডিও স্টেশনও আছে। এটি `Super + Shift + Alt + M` দিয়ে, অথবা Omarchy মেনুতে _অ্যাপ_-এর অধীন থেকে চালান। পুরো কিবাইন্ডিং তালিকার জন্য `?` চাপুন।

## Wi-Fi এবং Bluetooth-এর কী হবে?

আপনি Wi-Fi এবং Bluetooth-এর জন্য TUI পাবেন না — সেই কাজগুলো Omarchy শেলের। নেটওয়ার্ক দেখতে ও সংযোগ করতে উপরের বারের Wi-Fi আইকনে ক্লিক করুন (অথবা `Super + Ctrl + W` চাপুন), এবং ডিভাইস পেয়ার ও সংযোগ করতে Bluetooth আইকনে ক্লিক করুন (অথবা `Super + Ctrl + B` চাপুন)। পুরো কাহিনির জন্য [networking](35-networking.md) দেখুন।

## নিজেরটা যোগ করা

যেকোনো টার্মিনাল প্রোগ্রাম পূর্ণ অ্যাপের মর্যাদা পেতে পারে। Omarchy মেনুতে (`Super + Space`) _ইনস্টল > TUI_-তে যান, এটিকে একটি নাম, একটি চালুর কমান্ড, একটি উইন্ডো স্টাইল এবং একটি আইকন দিন, আর এটি অন্য যেকোনো অ্যাপ্লিকেশনের মতো অ্যাপ লঞ্চারে দেখা যাবে। আপনি _সরান > TUI_-এর অধীনে এটিকে আবার সরিয়ে ফেলতে পারেন।
