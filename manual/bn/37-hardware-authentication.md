# হার্ডওয়্যার প্রমাণীকরণ

### ফিঙ্গারপ্রিন্ট প্রমাণীকরণ

অনেক ল্যাপটপেই প্রমাণীকরণের জন্য ফিঙ্গারপ্রিন্ট সেন্সর থাকে। Omarchy মেনুতে (`Super + Space`) _Setup > Security > Fingerprint_ চালিয়ে আপনি Omarchy-র সঙ্গে এটি ব্যবহার করতে পারবেন।

এটি ফিঙ্গারপ্রিন্ট প্যাকেজটি ইনস্টল করবে, আপনার ছাপ সংগ্রহ করবে, তা যাচাই করবে, আর তারপর আপনি লক স্ক্রিন থেকে আনলক করতে (যা আপনি `Super + Ctrl + L` দিয়ে চালু করতে পারেন), sudo মোডে ঢুকতে এবং সিস্টেম প্রম্পট অনুমোদন করতে আপনার ফিঙ্গারপ্রিন্ট ব্যবহারের জন্য তৈরি হয়ে যাবেন।

লক স্ক্রিন ডিসপ্লে বন্ধ করে দিলে বিদ্যুৎ বাঁচাতে সেন্সরটি বিশ্রামে চলে যায়, তাই এটিকে স্পর্শ করার আগে যেকোনো কী বা টাচপ্যাড দিয়ে স্ক্রিনটি জাগিয়ে নিন।

আপনার ল্যাপটপের ঢাকনা বন্ধ থাকলে ফিঙ্গারপ্রিন্ট প্রম্পটটি স্বয়ংক্রিয়ভাবে এড়িয়ে যাওয়া হয়, ফলে হাতের নাগালে নেই এমন একটি সেন্সরের জন্য অপেক্ষা করার বদলে আপনি সরাসরি পাসওয়ার্ড প্রম্পটে চলে যান। অন্যথায় সেন্সর নেই এমন একটি এক্সটার্নাল কীবোর্ডে কাজ করতে হলে, `sudo`-র সময় আপনার ফিঙ্গারপ্রিন্ট চাওয়া হলে শুধু `CTRL + C` চাপুন।

Omarchy মেনুতে _Remove > Security > Fingerprint_-এর অধীনে আপনি ফিঙ্গারপ্রিন্ট প্রমাণীকরণ সরিয়ে ফেলতে পারবেন।

### Fido2 প্রমাণীকরণ

আপনি যদি একটি Fido2 ডিভাইস ব্যবহার করেন, তাহলে Omarchy মেনুতে (`Super + Space`) _Setup > Security > Fido2_ ব্যবহার করে `sudo` প্রমাণীকরণের জন্য এটি সেট আপ করতে পারবেন। তবে এটি `sudo` এবং সিস্টেম অনুমোদন প্রম্পট কভার করে, আপনার কম্পিউটার আনলক করা নয়।

Omarchy মেনুতে _Remove > Security > Fido2_-এর অধীনে আপনি fido2 প্রমাণীকরণ সরিয়ে ফেলতে পারবেন।
