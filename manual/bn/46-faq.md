# প্রায়শই জিজ্ঞাসিত প্রশ্নাবলী

### আমি কীভাবে কীবোর্ড লেআউটগুলোর মধ্যে সুইচ করব?

আপনার `~/.config/hypr/input.lua` ফাইলটি সম্পাদনা করুন এবং `Left Alt + Right Alt` দিয়ে লেআউটগুলোর মধ্যে সুইচ করার জন্য এটি যোগ করুন:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

একবার একাধিক লেআউট কনফিগার করা হয়ে গেলে বারটি স্বয়ংক্রিয়ভাবে আপনার বর্তমান কীবোর্ড লেআউট দেখাবে (এবং সুইচ করতে আপনি এটিতে ক্লিকও করতে পারেন)।

### আমি কীভাবে ঘড়ির ফরম্যাট 12-ঘণ্টায় বদলাব?

সাধারণ ফরম্যাটগুলোর মধ্যে দিয়ে চক্রাকারে যেতে বারে ঘড়িটিতে ডান-ক্লিক করুন, যার মধ্যে 12-ঘণ্টার ফরম্যাটগুলোও আছে। আপনি সরাসরি ফরম্যাটটিও সেট করতে পারেন:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

এটি রবিবার 10:55 AM দেখাবে।

### আমি কীভাবে আমার টাইমজোন বদলাব?

Omarchy মেনুতে _Update > Timezone_ চালান এবং তালিকা থেকে বেছে নিন। টাইমজোন ঠিক থাকলেও ঘড়িটি নিজে যদি সরে গিয়ে থাকে, তাহলে _Update > Time_ আপনার জন্য টাইম সিঙ্ক্রোনাইজেশন পুনরায় চালু করে দেয়।

### আমি কীভাবে আমার DNS বদলাব, আমার Wi-Fi শেয়ার করব, অথবা আমার সংযোগের গতি পরীক্ষা করব?

সেগুলো সবই [নেটওয়ার্কিং](35-networking.md)-এ আছে।

### আমি কীভাবে পরীক্ষা করব আমার ডিস্ক কতটা দ্রুত?

_Trigger > Speed Test > Disk Speed Test_ আপনার ড্রাইভে লাইভ রিড ও রাইট গতি মাপে, অথবা টার্মিনাল থেকে `omarchy disk speedtest`।

### আমি কীভাবে একটি প্রিন্টার যোগ করব?

প্রিন্টিং বাক্স থেকে বের করলেই সেট আপ করা ও চলমান থাকে, এবং প্রতিটি প্রিন্টার আপনি নিজে অ্যাপ লঞ্চারের (`Super + Space`) _Print Settings_ থেকে যোগ করেন।

_Add_ বেছে নিন, এবং খুঁজে দেখার জন্য এটিকে কিছুটা সময় দিন: USB দিয়ে প্লাগ ইন করা একটি প্রিন্টার, এবং বেশিরভাগ নেটওয়ার্ক প্রিন্টার, আপনার জন্য খুঁজে পাওয়া যায়। আপনারটি যদি তালিকায় না থাকে, তাহলে _Network Printer > Internet Printing Protocol (ipp)_ বেছে নিন এবং এর ঠিকানা লিখুন — প্রিন্টারের নিজের ডিসপ্লে অথবা এর ওয়েব পেজ আপনাকে সেটি বলে দেবে, সাধারণত `192.168.1.50`-এর মতো কিছু, যার কিউ `ipp/print`। এরপর _Forward_ একটি ড্রাইভার অফার করে, যেখানে একটি আধুনিক প্রিন্টার ড্রাইভারবিহীন _IPP Everywhere_ প্রোফাইলে সবচেয়ে ভালো কাজ করে এবং একটি পুরোনো প্রিন্টার মডেলের নিজের ড্রাইভার চায়।

একটি প্রিন্টারে ডান-ক্লিক করে _Set as Default_ বেছে নিন কোনটি আপনার অ্যাপগুলো প্রথমে ব্যবহার করবে তা ঠিক করতে, এবং কাগজের আকার, ডুপ্লেক্স ও মান সেট করতে _Properties_ বেছে নিন।

স্বয়ংক্রিয় আবিষ্কার, যেখানে নেটওয়ার্কের প্রিন্টারগুলো যোগ করা ছাড়াই দেখা যায়, এটি নতুন করে তৈরি করার সময় সাময়িকভাবে বন্ধ রাখা হয়েছে, যে কারণে উপরের প্রথম ধাপটি স্বয়ংক্রিয় না হয়ে আপনারই করতে হয়। কোনো প্রিন্টার ছাড়াই একটি PDF ফাইলে প্রিন্ট করা যায়।

### আমি কীভাবে বদলাব স্ক্রিনশট বা স্ক্রিনরেকর্ডিং কোথায় সংরক্ষণ করা হবে?

সংরক্ষিত স্ক্রিনশটগুলো ডিফল্টভাবে `~/Pictures/Screenshots`-এ যায়। অন্য কোনো ডিরেক্টরি ব্যবহার করতে, `~/.config/uwsm/env.d/`-এর অধীনে একটি ফাইলে (যেমন `~/.config/uwsm/env.d/capture`) এটি যোগ করুন:

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

স্ক্রিনরেকর্ডিংয়ের জন্যও আপনি `OMARCHY_SCREENRECORD_DIR` ব্যবহার করে একই কাজ করতে পারেন।

Omasnap এর স্ক্রিনশট ডিরেক্টরি স্বয়ংক্রিয়ভাবে তৈরি করে। স্ক্রিনরেকর্ডিং ডিরেক্টরিটি নিজে তৈরি করুন, তারপর যেকোনো একটি এনভায়রনমেন্ট পরিবর্তন কার্যকর হওয়ার জন্য Omarchy পুনরায় চালু করুন।

### আমি কীভাবে আমার Apple Studio Display-তে স্পিকার + ওয়েবক্যাম কাজ করাব?

আপনি ভাববেন যে শুধু USB C প্লাগ ইন করলেই সব কাজ করা উচিত, কিন্তু দুর্ভাগ্যবশত তা হয় না। নির্ভরযোগ্যভাবে এটি কাজ করানোর জন্য আমি যে সমাধানটি পেয়েছি তা হলো [the WJESOG DisplayPort + USB-A => USB-C cable](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) ব্যবহার করা। তখন স্পিকার ও ওয়েবক্যাম চমৎকারভাবে কাজ করে।

মনে রাখবেন যে Apple Displays (Studio এবং XDR উভয়ই)-এর জন্য Omarchy-তে আপনার বিল্ট-ইন উজ্জ্বলতা নিয়ন্ত্রণ আছে, সাধারণ কীবোর্ড উজ্জ্বলতা বোতামগুলো ব্যবহার করেই।

### আমি কীভাবে সব অতিরিক্ত সফটওয়্যার থেকে মুক্তি পাব?

আপনি যদি Obsidian বা LibreOffice বা অন্য কোনো আগে থেকে ইনস্টল করা জিনিসের মতো প্রোগ্রাম না চান, তাহলে আপনি খুব সহজেই সেগুলো সরিয়ে ফেলতে পারেন।

ইনস্টল করা প্রতিটি প্যাকেজ দেখতে _Remove > Package_ চালান। তারপর tab দিয়ে আপনি যে কোনো প্যাকেজ সরাতে চান তা নির্বাচন করতে পারেন, এবং return দিয়ে আপনার নির্বাচিত সবকিছু সরানো শুরু করতে পারেন।

আর আপনি যে আগে থেকে ইনস্টল করা ওয়েব অ্যাপগুলো চান না সেগুলো সরাতে Omarchy মেনু থেকে _Remove > Web App_ ব্যবহার করতে পারেন।

অথবা একবারে সব আগে থেকে ইনস্টল করা অতিরিক্ত জিনিস — ওয়েব অ্যাপ, TUI, এবং ঐচ্ছিক অ্যাপ্লিকেশন — ঝেড়ে ফেলতে _Remove > Preinstalls_ চালান। যেসব হটকি সেগুলো চালু করত সেগুলোও সেগুলোর সঙ্গে চলে যায়, তাই আপনার কাছে বাইন্ডিংয়ের একটি পরিষ্কার স্লেট থাকে যা আপনি `~/.config/hypr/bindings.lua`-তে নিজের পছন্দমতো ভরতে পারেন।
