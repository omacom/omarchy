# Dotfiles

Omarchy প্রাথমিকভাবে তথাকথিত dotfiles দিয়েই কনফিগার করা হয়, যেগুলি `~/.config`-এ থাকে। সেগুলি আপনার পরিবর্তনের জন্য আপনারই ফাইল হিসেবে বিবেচিত। `/usr/share/omarchy`-তে থাকা ফাইলগুলি Omarchy-র নিজের, এবং সেগুলি নিয়ে আপনার ঘাঁটাঘাঁটি করা উচিত নয়। `/usr/share/omarchy`-তে যদি আপনার কিছু পরিবর্তন করতেই হয়, তাহলে তার বদলে আপনার উচিত `~/.config`-এ মানটি ওভাররাইট করা।

মূল কনফিগগুলি Omarchy মেনু (`Super + Space`) থেকেই সরাসরি সম্পাদনা করা যায়, যেমন _Setup > Keyboard > Keybindings_, _Setup > Input_, এবং _Setup > Config > [file]_। আপনি যখন এভাবে এটি করেন, তখন কনফিগ সম্পাদনার পরে যে প্রসেসগুলি পুনরায় চালু করা প্রয়োজন, সেগুলি সম্পাদক থেকে বের হয়ে আসার পর স্বয়ংক্রিয়ভাবে পুনরায় চালু হবে (ডিফল্ট হিসেবে Neovim — `:wq`, মনে রাখবেন! — তবে আপনি _Setup > Defaults > Editor_ এর মাধ্যমে তা পরিবর্তন করতে পারেন)।

এখানে `~/.config`-এর মূল ফাইলগুলির একটি তালিকা এবং সেগুলি কী নিয়ন্ত্রণ করে তা দেওয়া হলো:

| File                  | Purpose              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | প্রধান Hyprland কনফিগ। এটি Omarchy ডিফল্টের পাশাপাশি নিচে দেওয়া আপনার ওভাররাইড ফাইলগুলি লোড করে। [Hyprland কনফিগ সম্পর্কে আরও জানুন](https://wiki.hypr.land/Configuring/).  |
| `~/.config/hypr/bindings.lua` | আপনার নিজের কী-বাইন্ডিং এবং ডিফল্টগুলির ওভাররাইড। |
| `~/.config/hypr/monitors.lua` | মনিটর প্যানেলে যা নেই এমন মনিটর সেটিং, যেমন ঘূর্ণন, অতিরিক্ত মোড, অথবা একটি মনিটর বন্ধ রাখা। |
| `~/.config/hypr/input.lua` | আপনার কীবোর্ড লেআউট, মাউস এবং ট্র্যাকপ্যাড সেটিং নিয়ন্ত্রণ করে। |
| `~/.config/hypr/looknfeel.lua` | ফাঁক, বর্ডার, অ্যানিমেশন এবং বাকি চেহারা নিয়ন্ত্রণ করে। |
| `~/.config/hypr/autostart.lua` | সেশনের সঙ্গে শুরু হওয়া অতিরিক্ত প্রসেস নিয়ন্ত্রণ করে। |
| `~/.config/omarchy/shell.json` | Omarchy শেল নিয়ন্ত্রণ করে: বারের অবস্থান, লেআউট এবং উইজেট, পাশাপাশি স্ক্রিনসেভার, লক এবং নিষ্ক্রিয়তার সময়। |
| `~/.config/foot/foot.ini` | আপনার টার্মিনাল নিয়ন্ত্রণ করে (foot হলো ডিফল্ট)। |
| `~/.XCompose` | আপনার দ্রুত-অ্যাক্সেস ইমোজি এবং নাম/ইমেল অটোকমপ্লিট নির্ধারণ করে। পরিবর্তন করার পর `omarchy-restart-xcompose` চালাতে ভুলবেন না। |

আপনি যদি নিজের সেটআপকে নিজের মতো করে সাজাতে গিয়ে অনেক পরিবর্তন করে ফেলেন, তাহলে এই সব dotfiles-এর ব্যাকআপ রাখা ভালো ধারণা। [Stow এটি করার একটি দারুণ উপায়](https://www.youtube.com/watch?v=NoFiYOqnC4o)।

### সেশনের সঙ্গে আপনার নিজের অ্যাপ শুরু করা

আপনি যদি চান যে প্রতিবার লগ ইন করার সময় কিছু চলুক — একটি সিঙ্ক ডেমন, একটি চ্যাট অ্যাপ, আপনার নিজের স্ক্রিপ্ট — তাহলে সেটি `~/.config/hypr/autostart.lua`-তে রাখুন:

```lua
o.launch_on_start("my-service")
```

এটি সেশনের অংশ হিসেবে কমান্ডটি শুরু করে, তাই আপনি আবার লগ আউট করলে এটি ঠিকমতো পরিষ্কার হয়ে যায়।

### সিস্টেম ইভেন্টে স্ক্রিপ্ট চালানো

Omarchy বেশ কয়েকটি মুহূর্তে হুক ফায়ার করে, এবং আপনি সেগুলির সঙ্গে আপনার নিজের স্ক্রিপ্ট ঝুলিয়ে দিতে পারেন। এগুলি `~/.config/omarchy/hooks/<event>.d/`-তে থাকে, প্রতিটি ইভেন্টের জন্য একটি করে ডিরেক্টরি, এবং সেখানে থাকা প্রতিটি ফাইল যা `.sample` দিয়ে শেষ হয় না, ইভেন্ট ঘটলে bash দিয়ে চলে:

| Event | When it runs |
| ----- | ------------ |
| `post-boot` | ডেস্কটপ শুরু হওয়ার ঠিক পরে |
| `post-update` | `omarchy update`-এর শেষের দিকে, প্যাকেজ, মাইগ্রেশন এবং সার্ভিস পুনরায় চালু হওয়ার পরে, mise টুলগুলি আপডেট হওয়ার আগে |
| `pre-refresh-pacman` | `omarchy refresh pacman` প্যাকেজ কনফিগ পুনরায় সিঙ্ক করার পরে, প্যাকেজ আপডেট করার আগে; একটি চ্যানেল পরিবর্তন সেই একই রিফ্রেশ ধাপের সময় এটি চালায় |
| `theme-set` | থিম পরিবর্তনের পরে (`$1`-এ থিমের নাম) |
| `font-set` | ফন্ট পরিবর্তনের পরে (`$1`-এ ফন্টের নাম) |
| `battery-low` | যখন ব্যাটারি কমে যায় (`$1`-এ শতাংশ) |

`pre-refresh-pacman` হুকটিতেই কাস্টম রিপোজিটরি বা `IgnorePkg` লাইনগুলি থাকা উচিত, কারণ এটি প্যাকেজ লেনদেনের আগে চলে। দুটিই আপনার ব্যবহারকারী হিসেবে চলে। `post-update` চলে যখন `omarchy update`-এর sudo অনুমোদন এখনও তাজা থাকে, তাই যে হুক `sudo` ব্যবহার করে তা আবার আপনার পাসওয়ার্ড চাইবে না; `pre-refresh-pacman` চলে ঠিক `omarchy refresh pacman` নিজে sudo ব্যবহার করার পরেই।

ওই ডিরেক্টরিগুলির প্রতিটিতেই ইতিমধ্যে একটি `.sample` ফাইল রয়েছে যা একটি হুকের আকার দেখায় — এটিকে কাজে লাগাতে নাম থেকে `.sample` বাদ দিন। আপনি অন্য কোথাও লেখা একটি স্ক্রিপ্ট ইনস্টল করতে `omarchy hook install post-boot ~/my-hook` ব্যবহার করুন, যা এটিকে ভেতরে কপি করে এবং এটিকে এক্সিকিউটেবল করে তোলে।

### আপনার নিজের মেনু এন্ট্রি যোগ করা

Omarchy মেনু (`Super + Space`) আপনার নিজের সারি দিয়ে বাড়ানো যায় `~/.config/omarchy/extensions/omarchy-menu.jsonc` সম্পাদনা করে। এন্ট্রিগুলি একটি ডটেড id দিয়ে চিহ্নিত, এবং এই id-ই এগুলিকে গাছে বসায়, তাই `personal` রুট মেনুতে দেখা যায় এবং `personal.notes` তার ভেতরে দেখা যায়:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

একটি বিদ্যমান id আবার ব্যবহার করলে আপনি নতুন একটি যোগ করার বদলে ওই সারিটিকে ওভাররাইড করেন। ফাইলটি উপলব্ধ সব ফিল্ড মন্তব্য হিসেবে নথিভুক্ত অবস্থায় আসে।

### আপনার নিজের শেল এক্সপোর্ট, ফাংশন এবং অ্যালিয়াস যোগ করা

Omarchy অনেকগুলি সুবিধাজনক অ্যালিয়াস এবং সহায়ক ফাংশন নিয়ে আসে, তবে নিজের কিছু যোগ করতে চাওয়া খুবই সাধারণ। আপনার অ্যালিয়াস, ফাংশন এবং এক্সপোর্ট — সবই `~/.bashrc`-তে যোগ করা উচিত। এই ফাইলটি আপডেটে ওভাররাইট হবে না। আপনি যদি Omarchy ডিফল্টগুলির কোনোটি পরিবর্তন করতে চান, তাহলেও আপনি নিরাপদে সেগুলি এখানে যোগ করতে পারেন।

### ডেস্কটপের জন্য এনভায়রনমেন্ট ভেরিয়েবল সেট করা

ডেস্কটপ সেশনের এক্সপোর্টগুলি `~/.config/uwsm/env.d/`-তে থাকে। এই ফাইলগুলি আপনার ডেস্কটপ শুরু হওয়ার আগে চলে, তাই একটি শেল ত্রুটি আপনাকে লগইন স্ক্রিনে ফেরত পাঠাতে পারে। এগুলি সম্পাদনা করার সময় একটি কাজ করা টার্মিনাল খোলা রাখুন। একটি ওভাররাইড নিষ্ক্রিয় করতে, সেটিকে `env.d` থেকে সরিয়ে নিন। কোনো পরিবর্তন লগইন প্রতিরোধ করলে [লগইন পুনরুদ্ধার](45-troubleshooting.md#my-password-is-accepted-but-i-return-to-the-login-screen) দেখুন।

### অভ্যন্তরীণ Omarchy ফাইল পরিবর্তন করা

দেখুন, এটি আপনার কম্পিউটার। আপনি এটি নিয়ে যা খুশি তাই করতে পারেন, তবে আমি `/usr/share/omarchy`-তে থাকা ফাইলগুলিতে সরাসরি পরিবর্তন করার বিরুদ্ধে পরামর্শ দেব। এগুলি Omarchy pacman প্যাকেজের অন্তর্গত, তাই আপনার পরিবর্তনগুলি পরের আপডেটেই শুধু ওভাররাইট হয়ে যাবে। তার বদলে আপনি `~/.config/*` ফোল্ডারে আপনার পছন্দ নয় এমন যেকোনো ডিফল্ট মান ওভাররাইট করলেই ভালো করবেন।

আপনি এভাবে প্রায় সবকিছুই পরিবর্তন করতে পারেন, যেমন ডিফল্ট কী-বাইন্ডিংগুলি। শুধু `~/.config/hypr/bindings.lua` সম্পাদনা করে, ধরুন, [Obsidian](https://obsidian.md/)-কে [Joplin](https://joplinapp.org/) দিয়ে বদলে দিন (`omarchy-pkg-add joplin-bin` দিয়ে ইনস্টল করুন):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` তার প্রতিস্থাপন যোগ করার আগে বিদ্যমান বাইন্ডিংটি সরিয়ে দেয়। এটি `o.bind`-এর মতোই একই আর্গুমেন্ট নেয়, যার মধ্যে লঞ্চ হেল্পার এবং বাইন্ডিং অপশন রয়েছে। একটি বাইন্ডিং যোগ করতে `o.bind` ব্যবহার করুন, অথবা প্রতিস্থাপন না করে একটি সরাতে `hl.unbind` ব্যবহার করুন।

আপনি যদি অভ্যন্তরীণ Omarchy ফাইলগুলিতে হ্যাক করতেই চান, তাহলে _Update > Channel > Dev_ এর মাধ্যমে dev চ্যানেলে চলে যান। এটি Omarchy-কে `~/omarchy`-তে থাকা সোর্স কোডের একটি git চেকআউটের সঙ্গে লিঙ্ক করে, যা আপনি প্রাণ ভরে পরিবর্তন করতে পারেন। এখানে আপনাকে বলার কেউ নেই আপনি কী করবেন!

### যেকোনো পরিবর্তন রিসেট করা

আপনি যদি কনফিগারেশনগুলি গুবলেট করে ফেলেন, তাহলে আপনি সবসময় Omarchy মেনুতে _Update > Config_ এর মাধ্যমে সেগুলিকে ডিফল্টে ফিরিয়ে নিতে পারেন। অথবা সবকিছু রিসেট করতে `omarchy reinstall configs` চালিয়ে।
