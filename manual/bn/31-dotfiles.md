# ডটফাইলস

Omarchy মূলত তথাকথিত ডটফাইলের মাধ্যমে কনফিগার করা হয়, যেগুলো থাকে `~/.config`-এ। সেগুলোকে আপনার পরিবর্তনের জন্য আপনার ফাইল হিসেবেই ধরা হয়। যেসব ফাইল `/usr/share/omarchy`-তে থাকে, সেগুলো Omarchy-এর নিজের, আর সেগুলো নিয়ে আপনার ঘাঁটাঘাঁটি করা উচিত নয়। `/usr/share/omarchy`-তে কোনো কিছু বদলানোর দরকার হলে, তার বদলে `~/.config`-এ মানটি ওভাররাইট করা উচিত।

মূল কনফিগগুলো Omarchy মেনু (`Super + Space`) থেকে সরাসরি সম্পাদনা করা যায়, যেমন _Setup > Keyboard > Keybindings_, _Setup > Input_, এবং _Setup > Config > [file]_। এইভাবে করলে, কনফিগ সম্পাদনার পর যেসব প্রসেস আবার চালু করা দরকার, এডিটর থেকে বের হয়ে এলেই সেগুলো স্বয়ংক্রিয়ভাবে আবার চালু হয়ে যাবে (ডিফল্ট হিসেবে Neovim — `:wq`, মনে আছে তো! — তবে _Setup > Defaults > Editor_ দিয়ে আপনি তা বদলাতে পারবেন)।

এখানে `~/.config`-এর মূল ফাইলগুলোর একটি তালিকা দেওয়া হলো, আর সেগুলো কী নিয়ন্ত্রণ করে:

| ফাইল | উদ্দেশ্য |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | মূল Hyprland কনফিগ। Omarchy-এর ডিফল্টগুলোর সঙ্গে নিচের আপনার ওভাররাইড ফাইলগুলো লোড করে। [Hyprland কনফিগ সম্পর্কে আরও জানুন](https://wiki.hypr.land/Configuring/) |
| `~/.config/hypr/bindings.lua` | আপনার নিজের কিবাইন্ডিং এবং ডিফল্টগুলোর ওভাররাইড। |
| `~/.config/hypr/monitors.lua` | মনিটর প্যানেলে যা নেই এমন মনিটর সেটিং, যেমন ঘূর্ণন, অতিরিক্ত মোড, বা কোনো মনিটর বন্ধ রাখা। |
| `~/.config/hypr/input.lua` | আপনার কিবোর্ড লেআউট, মাউস এবং ট্র্যাকপ্যাড সেটিং নিয়ন্ত্রণ করে। |
| `~/.config/hypr/looknfeel.lua` | ফাঁক, বর্ডার, অ্যানিমেশন এবং বাকি চেহারার সবকিছু নিয়ন্ত্রণ করে। |
| `~/.config/hypr/autostart.lua` | সেশনের সঙ্গে চালু হওয়া অতিরিক্ত প্রসেস নিয়ন্ত্রণ করে। |
| `~/.config/omarchy/shell.json` | Omarchy শেল নিয়ন্ত্রণ করে: বারের অবস্থান, লেআউট এবং উইজেট, সেই সঙ্গে স্ক্রিনসেভার, লক এবং নিষ্ক্রিয় থাকার সময়। |
| `~/.config/foot/foot.ini` | আপনার টার্মিনাল নিয়ন্ত্রণ করে (foot হলো ডিফল্ট)। |
| `~/.XCompose` | আপনার দ্রুত-অ্যাক্সেস ইমোজি এবং নাম/ইমেল অটোকমপ্লিট নির্ধারণ করে। পরিবর্তন করার পর অবশ্যই `omarchy-restart-xcompose` চালাবেন। |

নিজের সেটআপ সাজাতে গিয়ে যদি আপনি অনেক পরিবর্তন করে ফেলেন, তাহলে এই সব ডটফাইলের ব্যাকআপ নেওয়া ভালো ধারণা। [Stow তা করার একটি চমৎকার উপায়](https://www.youtube.com/watch?v=NoFiYOqnC4o)।

### সেশনের সঙ্গে আপনার নিজের অ্যাপ চালু করা

আপনি যদি চান প্রতিবার লগ ইন করার সময় কিছু চলুক — একটি সিঙ্ক ডেমন, একটি চ্যাট অ্যাপ, আপনার নিজের স্ক্রিপ্ট — তাহলে তা `~/.config/hypr/autostart.lua`-তে রাখুন:

```lua
o.launch_on_start("my-service")
```

এতে কমান্ডটি সেশনের অংশ হিসেবে চালু হয়, তাই আবার লগ আউট করলে তা ঠিকঠাক পরিষ্কার হয়ে যায়।

### সিস্টেম ইভেন্টে স্ক্রিপ্ট চালানো

Omarchy কয়েকটি মুহূর্তে হুক চালু করে, আর আপনি সেগুলোর সঙ্গে আপনার নিজের স্ক্রিপ্ট জুড়ে দিতে পারেন। সেগুলো থাকে `~/.config/omarchy/hooks/<event>.d/`-তে, প্রতিটি ইভেন্টের জন্য একটি ডিরেক্টরি, আর ইভেন্ট ঘটলে সেখানে থাকা প্রতিটি এক্সিকিউটেবল ফাইল চলে:

| ইভেন্ট | কখন এটি চলে |
| ----- | ------------ |
| `post-boot` | ডেস্কটপ চালু হওয়ার ঠিক পরপরই |
| `post-update` | `omarchy update`-এর প্রায় শেষের দিকে, প্যাকেজ, মাইগ্রেশন এবং সার্ভিস রিস্টার্টের পর, mise টুল আপডেট হওয়ার আগে |
| `pre-refresh-pacman` | `omarchy refresh pacman` প্যাকেজ কনফিগ আবার সিঙ্ক করার পর, প্যাকেজ আপডেট করার আগে; চ্যানেল বদলালে সেই একই রিফ্রেশ ধাপে এটি চলে |
| `theme-set` | থিম পরিবর্তনের পর (`$1`-এ থিমের নাম) |
| `font-set` | ফন্ট পরিবর্তনের পর (`$1`-এ ফন্টের নাম) |
| `battery-low` | ব্যাটারি কমে গেলে (`$1`-এ শতাংশ) |

`pre-refresh-pacman` হুকেই কাস্টম রিপোজিটরি বা `IgnorePkg` লাইন থাকা উচিত, কারণ এটি প্যাকেজ ট্রানজ্যাকশনের আগে চলে। আপডেট-সংক্রান্ত দুটি হুকই আপনার ব্যবহারকারী হিসেবে চলে, Omarchy তার ক্যাশ করা sudo অনুমোদন মুছে ফেলার পর, তাই `sudo` ব্যবহার করে এমন হুকের নিজের অনুমোদন লাগবে এবং তা আপনার পাসওয়ার্ড চাইতে পারে।

ওই ডিরেক্টরিগুলোর প্রতিটিতেই ইতিমধ্যে একটি `.sample` ফাইল আছে, যা একটি হুকের আকার দেখায় — তা কাজে লাগাতে নাম থেকে `.sample` ফেলে দিন। অন্য কোথাও লেখা কোনো স্ক্রিপ্ট ইনস্টল করতে `omarchy hook install post-boot ~/my-hook` ব্যবহার করুন, যা তা কপি করে এনে এক্সিকিউটেবল করে দেয়।

### আপনার নিজের মেনু এন্ট্রি যোগ করা

`~/.config/omarchy/extensions/omarchy-menu.jsonc` সম্পাদনা করে Omarchy মেনু (`Super + Space`) আপনার নিজের সারি দিয়ে বাড়ানো যায়। এন্ট্রিগুলো একটি বিন্দুযুক্ত id দিয়ে চিহ্নিত করা হয়, আর সেই id-ই গাছে সেগুলোর জায়গা ঠিক করে, তাই `personal` মূল মেনুতে দেখায় এবং `personal.notes` তার ভেতরে দেখায়:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

বিদ্যমান কোনো id আবার ব্যবহার করলে নতুন সারি যোগ করার বদলে আপনি ওই সারিটিই ওভাররাইড করবেন। ফাইলটিতে সব উপলব্ধ ফিল্ড মন্তব্য হিসেবে নথিভুক্ত করা অবস্থায় থাকে।

### আপনার নিজের শেল এক্সপোর্ট, ফাংশন এবং অ্যালিয়াস যোগ করা

Omarchy-এর সঙ্গে অনেক সুবিধাজনক অ্যালিয়াস এবং সহায়ক ফাংশন আসে, তবে নিজের কিছু যোগ করতে চাওয়া খুবই সাধারণ। অ্যালিয়াস, ফাংশন এবং এক্সপোর্ট — সবই আপনার `~/.bashrc`-তে যোগ করা উচিত। আপডেটে এই ফাইল ওভাররাইট হবে না। Omarchy-এর কোনো ডিফল্ট বদলাতে চাইলেও আপনি নিরাপদে এখানে তা যোগ করতে পারেন।

### ডেস্কটপের জন্য এনভায়রনমেন্ট ভেরিয়েবল সেট করা

ডেস্কটপ সেশন এক্সপোর্ট থাকে `~/.config/uwsm/env.d/`-তে। এই ফাইলগুলো আপনার ডেস্কটপ চালু হওয়ার আগে চলে, তাই শেলের একটি ত্রুটি আপনাকে লগইন স্ক্রিনে ফেরত পাঠিয়ে দিতে পারে। এগুলো সম্পাদনা করার সময় একটি চালু টার্মিনাল খোলা রাখুন। কোনো ওভাররাইড নিষ্ক্রিয় করতে তা `env.d` থেকে সরিয়ে ফেলুন। কোনো পরিবর্তন লগইন আটকে দিলে [লগইন পুনরুদ্ধার](45-troubleshooting.md#my-password-is-accepted-but-i-return-to-the-login-screen) দেখুন।

### অভ্যন্তরীণ Omarchy ফাইল বদলানো

দেখুন, এটা আপনার কম্পিউটার। আপনি যা খুশি তা করতে পারেন, তবে `/usr/share/omarchy`-এর ফাইলগুলোতে সরাসরি পরিবর্তন না করার পরামর্শই আমি দেব। সেগুলো Omarchy pacman প্যাকেজের অংশ, তাই পরের আপডেটেই আপনার পরিবর্তনগুলো স্রেফ ওভাররাইট হয়ে যাবে। তার বদলে আপনার পছন্দ নয় এমন যেকোনো ডিফল্ট মান `~/.config/*` ফোল্ডারে ওভাররাইট করলেই আপনি ভালো করবেন।

এভাবে আপনি প্রায় সবকিছুই বদলাতে পারেন, যেমন ডিফল্ট কিবাইন্ডিং। উদাহরণস্বরূপ, [Obsidian](https://obsidian.md/)-এর বদলে [Joplin](https://joplinapp.org/) বসাতে শুধু `~/.config/hypr/bindings.lua` সম্পাদনা করুন (`omarchy-pkg-add joplin-bin` দিয়ে ইনস্টল করুন):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` প্রতিস্থাপন যোগ করার আগে বিদ্যমান বাইন্ডিং সরিয়ে ফেলে। এটি `o.bind`-এর মতোই আর্গুমেন্ট নেয়, লঞ্চ হেল্পার এবং বাইন্ডিং অপশনসহ। বাইন্ডিং যোগ করতে `o.bind` ব্যবহার করুন, বা প্রতিস্থাপন না করে কোনো বাইন্ডিং সরাতে `hl.unbind` ব্যবহার করুন।

অভ্যন্তরীণ Omarchy ফাইল নিয়ে ঘাঁটাঘাঁটি করতেই যদি আপনি জেদ ধরেন, তাহলে _Update > Channel > Dev_ দিয়ে dev চ্যানেলে চলে যান। এতে Omarchy `~/omarchy`-তে সোর্স কোডের একটি git চেকআউটের সঙ্গে যুক্ত হয়, যা আপনি মন ভরে বদলাতে পারবেন। এখানে আপনাকে বলার কেউ নেই, আপনি কী করবেন!

### যেকোনো পরিবর্তন রিসেট করা

কনফিগারেশন নিয়ে যদি আপনি গোলমাল পাকিয়ে ফেলেন, তাহলে Omarchy মেনুতে _Update > Config_ দিয়ে আপনি সবসময় সেগুলো ডিফল্টে ফিরিয়ে আনতে পারবেন। অথবা সবকিছু রিসেট করতে `omarchy reinstall configs` চালিয়েও তা করা যায়।
