# শুরু করা

Omarchy একটি ISO ব্যবহার করে ইনস্টল করা হয়। আপনি একটি full-disk install বেছে নিতে পারেন, যা পুরো drive দখল করে নেয়, অথবা একটি free-space install, যা একটি drive-এর বরাদ্দহীন জায়গায় Omarchy বসায় — এভাবেই আপনি Windows বা অন্য কোনো OS-এর পাশাপাশি dual boot করেন (দেখুন [ডুয়াল-বুট ইনস্টল](50-dual-boot-install.md) — মনে রাখবেন যে আপনাকে প্রথমে Windows-এ BitLocker বন্ধ করতে হবে)। যেভাবেই হোক, ইনস্টলেশনে ডিফল্ট হিসেবে full encryption থাকে, এবং full-disk বিকল্পটি নির্বাচিত drive মুছে ফেলবে, তাই বিদ্যমান কোনো drive ব্যবহার করার আগে অবশ্যই backup নিন!

একটি Apple Silicon Mac-এ, আপনি বরং macOS থেকে ইনস্টল করেন, কোনো ISO বা USB stick ছাড়াই। দেখুন [Apple Silicon-এর জন্য Omarchy](44-mac-support.md#omarchy-for-apple-silicon)।

প্রথমে [Omarchy ISO ডাউনলোড করুন](https://omarchy.org/), এটি একটি USB stick-এ রাখুন (Windows-এ [Rufus](https://rufus.ie/), Mac-এ [balenaEtcher](https://etcher.balena.io/), অথবা Linux-এ [caligula](https://github.com/ifd3f/caligula) ব্যবহার করুন), এবং stick থেকে boot করুন।

_BIOS-এ আপনাকে Secure Boot এবং/অথবা TPM বন্ধ করতেই হবে। Omarchy ইনস্টল করতে সক্ষম হতে হলে আপনাকে এগুলো বন্ধ করতে হবে। এগুলো Windows এবং Microsoft-অধিভুক্ত Linux distribution-গুলোর জন্য তৈরি Microsoft নিরাপত্তা ব্যবস্থা।_

তারপর কনফিগারেশনের প্রশ্নগুলোর উত্তর দিন, এবং সেগুলো এভাবে নিশ্চিত করুন:

 ![install-config](images/install-config.webp)

তারপর আপনার ইনস্টলেশনের জন্য একটি drive নির্বাচন করুন, এবং আরাম করে বসে ইনস্টলেশনের শো চলতে দেখুন। সবচেয়ে দ্রুতগতির আধুনিক মেশিনগুলোতে এটি এক মিনিটেরও কম সময়ে হয়ে যেতে পারে, তবে পুরোনো কম্পিউটারেও এটি 5 মিনিটের বেশি সময় নেওয়া উচিত নয়।

 ![install-done](images/install-done.webp)

এখন আপনি Omarchy-র জন্য প্রস্তুত!

### তারযুক্ত বা 2.4ghz keyboard ব্যবহার করুন!

full-disk encryption স্টার্টআপে Bluetooth keyboard থেকে আপনাকে পাসওয়ার্ড দিতে দেবে না। ঠিক যেমন আপনি PC-তে BIOS-এ প্রবেশ করতে Bluetooth keyboard ব্যবহার করতে পারেন না। আপনার এমন একটি keyboard লাগবে যা হয় একটি 2.4ghz dongle ব্যবহার করে, নয়তো একটি কেবল ব্যবহার করে (যা যাইহোক latency-র জন্য অনেক ভালো!)। আমি ব্যক্তিগতভাবে [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard) খুব পছন্দ করি!

### অন্য মালিকের জন্য ইনস্টল করা

আপনি যদি অন্য কারোর জন্য একটি মেশিন সেট আপ করেন — পরিবারের সদস্য, নতুন কর্মী, কোনো ক্রেতা — তাহলে তাদের হয়ে ব্যক্তিগত প্রশ্নগুলোর উত্তর দেওয়া আপনার উচিত নয়। ইনস্টলারের একেবারে প্রথম স্ক্রিনে (keyboard নির্বাচন) `Ctrl + C` চাপুন, এবং Omarchy বরং অন্য মালিকের জন্য মেশিনটি প্রস্তুত করার প্রস্তাব দেবে। সিস্টেম সঙ্গে সঙ্গে ইনস্টল হয়ে যায়, কিন্তু সমস্ত ব্যক্তিগত সেটআপ — keyboard layout, ব্যবহারকারীর নাম, পাসওয়ার্ড — মেশিন প্রথমবার boot না হওয়া পর্যন্ত স্থগিত থাকে। drive এখনও ডিফল্ট হিসেবে এনক্রিপ্ট করা থাকে, এবং প্রথম সেই boot-এ নতুন মালিক যে পাসওয়ার্ড বেছে নেন, সেটাই এনক্রিপশনের পাসওয়ার্ডও হয়ে যায়। (আপনি ইতিমধ্যে ব্যবহার করে আসছেন এমন একটি মেশিনও পুনরায় ইনস্টল না করেই হস্তান্তর করা যায় — দেখুন [কম্পিউটার রিসেট করা](48-security.md)।)

### উপস্থিতি ছাড়াই ইনস্টল

ISO সম্পূর্ণ নিজে নিজেও ইনস্টল করতে পারে — কোনো keyboard নেই, কোনো wizard নেই — যখন একটি দ্বিতীয় drive-এ এর কনফিগারেশন তাকে ধরিয়ে দেওয়া হয়। VM এবং fleet মেশিনগুলোর জন্য Omarchy-কে একটি base image হিসেবে ব্যবহার করার এটাই উপায়। দেখুন [উপস্থিতি ছাড়াই ইনস্টল](51-unattended-installs.md)।

### এনক্রিপশন ছাড়া ইনস্টল

Omarchy ডিফল্ট হিসেবে এনক্রিপশনসহ ইনস্টল করা হয়। হারিয়ে যেতে বা চুরি হয়ে যেতে পারে এমন যেকোনো কম্পিউটারের জন্য এটাই নিরাপদ, দায়িত্বশীল পছন্দ। আপনার hardware-এর নাগাল পাওয়া যে কেউ আপনার ডেটা পেয়ে যাক, তা আপনি চান না!

তবে বিশেষ পরিস্থিতিতে, যেমন সুরক্ষিত কম্পিউটারে দূর থেকে Omarchy ইনস্টল করা, অথবা সংবেদনশীল ডেটা ছাড়া ফেলে দেওয়ার মতো ইনস্টলেশনের জন্য, আপনি এনক্রিপশন ছাড়া ইনস্টল করতে চাইতে পারেন। এনক্রিপশনহীন ইনস্টলেশনে যেতে আপনি disk ফরম্যাট করার নিশ্চিতকরণে `Ctrl + C` চাপতে পারেন।

### ভাষা

Omarchy 50টি ভাষায় কথা বলে — omarchy.org-এর একই সেট — এবং ইংরেজি হলো ডিফল্ট। বদলাতে, Omarchy মেনু খুলুন এবং _Setup > Region > Language_-এ যান, অথবা terminal-এ `omarchy language <code>` চালান (`omarchy language list` কোডগুলো দেখায়)। মেনু, ডেস্কটপ এবং Omarchy-র নিজস্ব বিজ্ঞপ্তিগুলো সঙ্গে সঙ্গে ভাষা বদলে ফেলে, এবং এরপর আপনি যে প্রতিটি application খোলেন, তারাও তা অনুসরণ করে। ইতিমধ্যে খোলা থাকা Apps আপনি সেগুলো পুনরায় চালু করলেই বদলে যায়।

ভাষাটি অপরিবর্তিত রেখে তারিখ, সময়, সংখ্যা, অর্থ, একক এবং কাগজের আকার অন্য কোনো অঞ্চলের মতো করে লিখতে (যেমন ইউরোপীয় তারিখ এবং 24-ঘণ্টার ঘড়িসহ ইংরেজি), _Setup > Region > Formats_-এর অধীনে একটি অঞ্চল বেছে নিন, যেখানে প্রতিটি পছন্দ একটি নমুনা দেখায়, অথবা `omarchy region formats <code>` চালান (`omarchy region formats list` কোডগুলো দেখায়)। _ভাষার মতোই_ ভাষার নিজস্ব ফরম্যাটগুলোতে ফিরে যায়। ভাষা বদলের মতোই, এটি এরপর আপনি যে Apps খোলেন, সেগুলোতে পৌঁছায়।
