# AI

Omarchy AI কোডিং এজেন্টদের প্রথম শ্রেণির নাগরিক হিসেবে দেখে, কিন্তু এটি আপনার পক্ষে পছন্দের একটি বেছে দেয় না। বরং প্রতিটি বড় কোডিং-এজেন্ট CLI lazy-loaded লঞ্চার হিসেবে আগে থেকেই সংযুক্ত থাকে। লঞ্চারগুলো `~/.local/bin/`-এ থাকা ছোট ছোট [mise](https://mise.jdx.dev/)-পরিচালিত স্টাব, তাই আপনি প্রথমবার আসলে কোনোটি চালানোর আগে কিছুই ডাউনলোড হয় না। Hermes হলো ব্যতিক্রম: এর জন্য কিছুই স্টাব করা হয় না, এবং এটিকে বেছে নিলে Hermes Desktop ইনস্টল হয়, যেমনটা নিচে _Desktop apps_ ব্যাখ্যা করে। এগুলোর যেকোনোটি চালান এবং অনুরোধ করা হলে প্রমাণীকরণ করুন:

| Command    | Agent                                                            |
|------------|------------------------------------------------------------------|
| `claude`   | [Claude Code](https://code.claude.com/docs/en/overview)          |
| `codex`    | [OpenAI Codex](https://github.com/openai/codex)                  |
| `opencode` | [OpenCode](https://opencode.ai/)                                 |
| `agy`      | [Google Antigravity CLI](https://github.com/google-antigravity/antigravity-cli) |
| `copilot`  | [GitHub Copilot CLI](https://github.com/github/copilot-cli)      |
| `crush`    | [Crush](https://github.com/charmbracelet/crush)                  |
| `grok`     | xAI-এর [Grok Build](https://x.ai/build)                        |
| `kimi`     | [Kimi Code](https://www.kimi.com/code/docs/en/)                  |
| `pi`       | [Mario Zechner-এর Pi](https://github.com/badlogic/pi-mono)        |
| `omp`      | [Oh My Pi](https://github.com/can1357/oh-my-pi)                  |
| `ori`      | [Ori](https://openrouter.ai/docs/guides/ori/harness), OpenRouter-এর হারনেস |
| `hermes`   | [Hermes](https://hermes-agent.nousresearch.com/), Nous Research-এর এজেন্ট  |
| `muse`     | [Muse Code](https://dev.meta.ai), Meta-র কোডিং এজেন্ট           |
| `cursor-agent` | [Cursor CLI](https://cursor.com/cli)                         |

`ori` হলো ব্যতিক্রমীটি: এটি অন্য হারনেসগুলোকে OpenRouter-এর পুরো মডেল ক্যাটালগের বিরুদ্ধে চালায়, তাই `ori claude`, `ori codex` বা `ori opencode` সেই এজেন্টগুলোকে আপনি যে মডেলের দিকে নির্দেশ করবেন সেই মডেলে শুরু করে, এবং `ori code` হলো Ori-র নিজস্ব এজেন্ট।

একইভাবে অতিরিক্ত কোনো CLI যুক্ত করতে চালান `omarchy-mise-install <package> [command-name]`। আপনি যখন `omarchy update` (বা `mup` অ্যালিয়াস) চালান, তখন mise যা কিছু পরিচালনা করে তার সবকিছুর সঙ্গেই স্টাবগুলো হালনাগাদ রাখা হয়।

`grok` mise-র ফার্স্ট-পার্টি `grok` প্যাকেজের মাধ্যমে ইনস্টল করা হয়, ঠিক `claude` এবং `codex`-এর মতোই। `grok` চালান, বা _Setup > Defaults > Agent_-এর অধীনে এটিকে বেছে নিন। x.ai-তে থাকা `curl | bash` ইনস্টলারটি এড়িয়ে চলুন। সেই পথটি `~/.grok/bin`-এ দ্বিতীয় একটি কপি রাখে, এটিকে `PATH`-এর শুরুতে যুক্ত করে, এবং Omarchy-র র‍্যাপারটি ওভাররাইট করে।

### ডিফল্ট এজেন্ট

`omarchy default agent <name>` দিয়ে অথবা Omarchy Menu (`Super + Space`)-তে _Setup > Defaults > Agent_-এর অধীনে আপনার ডিফল্ট এজেন্ট বেছে নিন। এজেন্টটি এখনো ইনস্টল করা না থাকলে, এটিকে বেছে নিলে প্রথমে এটি ইনস্টল হয়। একটি নতুন Omarchy একবারের নোটিফিকেশনের মাধ্যমে আপনাকে এই পছন্দটি করার আমন্ত্রণ জানাবে।

Claude বেছে নিলে Chromium, Chrome, Brave, Brave Origin এবং Edge-এর জন্য এর ব্রাউজার এক্সটেনশন সেট আপ করারও চেষ্টা করা হয়। এক্সটেনশন সেটআপটি সব ব্যবহারকারীর ক্ষেত্রে প্রযোজ্য হয় এবং আপনার সিস্টেম পাসওয়ার্ড চাইতে পারে; বাতিল করলে বা এক্সটেনশন ইনস্টল ব্যর্থ হলেও Claude নির্বাচন ও চালু হয়। আপনার ব্রাউজার পুনরায় চালু করুন, অনুরোধ করা হলে এক্সটেনশনটি সক্রিয় করুন, এবং সংযোগ সম্পূর্ণ করতে Claude-এ সাইন ইন করুন। সংযোগ পরীক্ষা করতে Claude-এ `/chrome` চালান। Firefox এবং Zen এই এক্সটেনশন সমর্থন করে না। এই সেটআপটি যোগ হওয়ার আগে Claude যদি ইতিমধ্যে আপনার ডিফল্ট থেকে থাকে, তাহলে এক্সটেনশনটি ইনস্টল করতে এটিকে আবার নির্বাচন করুন।

[Muse Code](https://dev.meta.ai) — Meta-র `muse` — অন্য এজেন্টগুলোর মতোই আগে থেকে ইনস্টল করা একটি mise স্টাব ব্যবহার করে। এটিকে ডিফল্ট হিসেবে বেছে নিলে mise-র HTTP ব্যাকএন্ডের মাধ্যমে Meta-র অফিসিয়াল লঞ্চার ইনস্টল হয়। লঞ্চারটি আপনার মেশিনের জন্য নেটিভ বাইনারি যাচাই ও হালনাগাদ করে।

একবার বেছে নিলে, `Super + Shift + Ctrl + A` একটি নিবেদিত টার্মিনাল উইন্ডোতে ডিফল্ট এজেন্ট চালু করে (অথবা আপনি এখনো না বেছে থাকলে পিকারটি সামনে আনে)। আপনি `omarchy agent prompt "Review this project"` দিয়ে এটিকে সরাসরি কোনো কাজেও চালু করতে পারেন। এভাবে চালু করা এজেন্টগুলো তাদের নিজ নিজ don't-stop-to-ask মোডে অযত্নে চলে, তাই তারা আসলেই কিছু করবে বলে প্রস্তুত থাকুন! এবং যেহেতু এজেন্টগুলো আপনার হোম ডিরেক্টরির জন্য আস্থা মনে রাখতে অস্বীকার করে, তাই `$HOME` থেকে চালু করলে সেগুলো এর পরিবর্তে `~/Work`-এ শুরু হয়।

টার্মিনাল শর্টকাটও আছে: `a` বর্তমান টার্মিনালে ইনলাইনে ডিফল্ট এজেন্ট চালায়, আর `c`, `cx` এবং `cy` সরাসরি OpenCode, Claude Code এবং Codex শুরু করে (আবারও তাদের অটো-অ্যাপ্রুভিং মোডে)। থিম পরিবর্তন এজেন্টগুলোর সঙ্গেও সিঙ্ক হয়: আপনি যখন Omarchy থিম বদলান, তখন Claude Code, Pi, OpenCode এবং Hermes (একবার Omarchy এটিকে ইনস্টল করলে) সবাই তার সঙ্গে তাল মিলিয়ে চলে।

### এজেন্ট প্যানেল

উপরের বারে একটি এজেন্ট আইকন আছে। আপনি কোনো এজেন্ট সেট আপ করার আগে, এর প্যানেল আপনাকে Claude, Codex বা Grok-এ সাইন ইন করার ধাপগুলো দেখিয়ে দেয়, এবং প্রথমটিই আপনার ডিফল্ট এজেন্ট হয়ে যায়। এরপর, প্যানেলটি প্রতিটি সাবস্ক্রিপশনকে এক পৃষ্ঠায় রাখে: প্রতিটি এজেন্ট ও অ্যাকাউন্ট তার প্ল্যানসহ, এর 5-ঘণ্টার সেশন এবং সাপ্তাহিক সীমার প্রতিটির জন্য একটি মিটারসহ রিসেট হতে বাকি সময় (ঠিক শতাংশের জন্য হোভার করুন), অথবা অবশিষ্ট প্রিপেইড ব্যালেন্স, একটি লাইনের নিচে যা সেগুলোর সবকটিতে আপনি যা ব্যবহার করেছেন তা ঘুরিয়ে ঘুরিয়ে দেখায়, যেমন এই সপ্তাহের টোকেন এবং আপনার সবচেয়ে বেশি ব্যবহৃত মডেল। _Make something_-এর অধীনে এটি একটি নতুন থিম, প্লাগইন বা অ্যাপের জন্য স্টার্টার প্রম্পট দেয় যা কাজটি আপনার ডিফল্ট এজেন্টের হাতে তুলে দেয়। অ্যাপগুলো তৈরি করা হয় যেভাবে Omarchy-র নিজস্ব Hype, Monologue এবং Omacut তৈরি, C++ এবং Qt Quick-এ, omarchy-app এজেন্ট স্কিল অনুসরণ করে, এবং তাদের প্রয়োজনীয় কম্পাইলার ও Qt অংশগুলো ইনস্টল করা অবস্থায় আসে। Claude Code, Codex, Grok, Fireworks এবং Kimi শুরু থেকেই অন্তর্ভুক্ত। Kimi বর্তমানে লোকাল টোকেন বা প্রম্পট পরিসংখ্যান ছাড়াই অ্যাকাউন্ট কোটার সীমা জানায়।

প্যানেলের জন্য বার আইকনে বাম-ক্লিক করুন, আপনার ডিফল্ট এজেন্ট চালু করতে ডান-ক্লিক করুন। এর পেছনের ব্যবহারের রেকর্ডগুলো প্রতি 15 মিনিটে `omarchy agent usage-update` দিয়ে পুনরায় তৈরি হয়, এবং প্যানেলটি সিঙ্ক করা ফোল্ডারের মাধ্যমে আপনার অন্য মেশিনগুলো থেকেও ব্যবহার একত্র করতে পারে। সম্পূর্ণ সেটিংসের জন্য `$OMARCHY_PATH/shell/plugins/agents/`-এর অধীনে README দেখুন।

### একাধিক সাবস্ক্রিপশন

আপনি যদি একাধিক Claude, Codex বা Grok প্ল্যানের জন্য অর্থ দেন — ধরা যাক একটি ব্যক্তিগত Max এবং একটি কাজের — Omarchy সেগুলো সবকটিকে সাইন ইন রাখতে এবং তাদের মধ্যে বদলাতে পারে। এজেন্ট প্যানেলে + দিয়ে একটি সাবস্ক্রিপশন যোগ করুন, যা ঠিক সেখানেই আপনাকে ধাপগুলো দেখিয়ে দেয়, অথবা `omarchy agent account add claude Work` দিয়ে (অথবা `codex`, বা `grok`)। CLI অনুপস্থিত থাকলে এটি তা ইনস্টল করে। কোনো প্রদানকারীর জন্য প্রথম অ্যাকাউন্টটি আপনার স্বাভাবিক ব্রাউজারের মাধ্যমে সাইন ইন করে, ঠিক যেখানে CLI সবসময় খোঁজে। এরপরের প্রতিটি একটি প্রাইভেট উইন্ডোর মাধ্যমে সাইন ইন করে, যাতে আপনার ব্রাউজার ইতিমধ্যে যে অ্যাকাউন্টে সাইন ইন আছে তা ভুল করে ধরা না পড়ে; সেখানে আপনি যে অ্যাকাউন্টটি যোগ করছেন সেটি হিসেবে সাইন ইন করুন, এবং আগে থেকে খোলা যেকোনো প্রাইভেট উইন্ডো প্রথমে বন্ধ করুন। এটি করতে কখনো CLI থেকে লগ আউট করবেন না: লগ আউট করলে সংরক্ষিত সাইন-ইন বাতিল হয়ে যায়, এবং সেই অ্যাকাউন্টটি আবার যোগ করতে হবে।

SSH-র মাধ্যমে আপনার সাবস্ক্রিপশন লগইনগুলো অন্য Omarchy মেশিনে কপি করতে চালান `omarchy agent account copy user@laptop`। গন্তব্যে কোনো রিসিভার ইনস্টল করা না থাকলে প্রেরক একটি অস্থায়ী রিসিভার সরবরাহ করে, তাই পুরনো Omarchy মেশিনগুলো আপডেট ছাড়াই অ্যাকাউন্ট গ্রহণ করতে পারে। ইনস্টল করা রিসিভারগুলো অগ্রাধিকার পায়। এটি সব Claude, Codex এবং Grok সাবস্ক্রিপশন কপি করে; সেগুলো নির্বাচন করতে প্রদানকারীর নাম যোগ করুন, যেমন `omarchy agent account copy laptop claude`। অ্যাকাউন্টের নাম এবং কমান্ড ID উৎসের সঙ্গে মেলে, গন্তব্যে ইতিমধ্যে থাকা অ্যাকাউন্টগুলো সহ। অসম্পর্কিত গন্তব্য অ্যাকাউন্টগুলোর নাম সংঘাতে পড়লে তারা একটি সংখ্যাসূচক প্রত্যয় পায়, এবং সেটিংস, স্কিল, প্লাগইন ও কথোপকথনের ইতিহাস প্রতিটি মেশিনে লোকালই থাকে।

বিদ্যমান গন্তব্যের ক্রেডেনশিয়ালগুলো রাখা হয়। সেখানে ইতিমধ্যে সাইন ইন থাকা কোনো উৎস অ্যাকাউন্টের নাম তার ক্রেডেনশিয়াল প্রতিস্থাপন না করেই সিঙ্ক্রোনাইজ হয়; অন্য অ্যাকাউন্টগুলো এর পাশাপাশি যোগ হয়। মিলে যাওয়া অ্যাকাউন্টগুলোর জন্য সংরক্ষিত ক্রেডেনশিয়াল প্রতিস্থাপন করতে, গন্তব্যে সেই অ্যাকাউন্টের সেশনগুলো ছেড়ে দেওয়ার পর `omarchy agent account copy --replace laptop claude` ব্যবহার করুন। একটি নতুন গন্তব্য উৎসের সক্রিয় অ্যাকাউন্ট এবং স্যুইচিং পছন্দগুলোও পায়; একটি প্রতিষ্ঠিত গন্তব্য নিজেরগুলোই রাখে।

ক্রেডেনশিয়ালগুলো SSH-র মাধ্যমে যায় এবং গন্তব্যে প্রাইভেট ফাইলে সংরক্ষিত হয়, তাই কেবল আপনার বিশ্বাসের মেশিনগুলোতেই কপি করুন। এটি একবারের কপি, চলমান সিঙ্ক্রোনাইজেশন নয়। Codex রিফ্রেশ টোকেন অন্য মেশিন দ্বারা ঘোরানো যেতে পারে, ফলে কপি করা লগইনের নবায়ন প্রয়োজন হতে পারে; একাধিক মেশিনে একসঙ্গে ব্যবহারের জন্য আলাদা সাইন-ইনই সবচেয়ে নির্ভরযোগ্য পছন্দ থাকে। [Codex-এর অ্যাকাউন্ট প্রমাণীকরণ নির্দেশনা](https://developers.openai.com/codex/auth/ci-cd-auth) দেখুন।

প্রদানকারী প্রতি একটি অ্যাকাউন্ট সক্রিয় থাকে, এবং প্রতিটি নতুন সেশন তাই হিসেবে শুরু হয়: `cx`, `cy`, একটি সাধারণ `claude`, `codex` বা `grok`, `omarchy agent`-এর মাধ্যমে চালু করা যেকোনো কিছু, এবং স্ক্রিপ্ট বা এডিটর যা `PATH`-এ CLI খুঁজে পায়। `omarchy agent account use work` দিয়ে বদলান (এবং `omarchy agent account use main` দিয়ে ফিরে আসুন), অথবা প্যানেলে কোনো অ্যাকাউন্টের নম্বর চেপে তারপর `Enter` চেপে (অথবা এর Use বোতামে ক্লিক করে)। ইতিমধ্যে চলমান সেশনগুলো যে অ্যাকাউন্ট দিয়ে শুরু হয়েছিল তাতেই থাকে। কথোপকথনের ইতিহাস, সেটিংস, স্কিল এবং প্লাগইন অ্যাকাউন্টগুলোর মধ্যে ভাগ করা থাকে, তাই একই ফোল্ডারে `claude --continue` নতুন অ্যাকাউন্টে যেখানে ছেড়েছিলেন সেখান থেকেই তুলে নেয়।

একাধিক অ্যাকাউন্ট থাকলে, প্যানেলটি প্রতিটি অ্যাকাউন্টের সীমা পাশাপাশি দেখায়, সক্রিয়টি চিহ্নিত করে। ডিফল্টভাবে সক্রিয় অ্যাকাউন্ট কোনো সীমার 95% পার হলে Omarchy আপনাকে জানায়, এবং নোটিফিকেশনে ক্লিক করলে সবচেয়ে বেশি হেডরুম থাকা অ্যাকাউন্টে বদলে যায়। প্যানেলে কোনো অ্যাকাউন্টের লাইনের ওপর হোভার করে Use-এর পাশে আসা Autoswitch-এ ক্লিক করুন (বা `m` চাপুন), অথবা `omarchy agent account mode auto` চালান, যাতে এটি নিজে নিজেই বদলায়; এটি চালু থাকাকালীন, Autoswitch Use-এর জায়গা নেয়, এবং আবার এটিতে ক্লিক করলে জানানোর পদ্ধতিতে ফিরে যায়। থ্রেশহোল্ড বদলাতে একটি সংখ্যা যোগ করুন, যেমন `omarchy agent account mode auto 90`। প্রতিটি অ্যাকাউন্ট থ্রেশহোল্ডের ওপরে থাকলে, আপনি একবার তা শুনবেন, কোন অ্যাকাউন্টটি প্রথমে মুক্ত হবে তা সহ। কোনো সক্রিয় অ্যাকাউন্ট তার থ্রেশহোল্ডের 15 পয়েন্টের মধ্যে থাকাকালীন (ডিফল্টে 80%), এর সীমাগুলো প্রতি 15 মিনিটের বদলে প্রতি তিন মিনিটে পরীক্ষা করা হয়।

`omarchy agent account list` প্রতিটি অ্যাকাউন্ট এবং এর সর্বশেষ সীমা দেখায়, `omarchy agent account remove work` একটিকে ভুলে যায়, এবং `omarchy agent account rename primary Hey` একটির নাম বদলায় (বা প্যানেলে কোনো অ্যাকাউন্টের নামে ক্লিক করুন)। এই কমান্ডগুলো আপনার ডিফল্ট এজেন্টের অ্যাকাউন্টগুলোতে কাজ করে; অন্য প্রদানকারীর কাছে পৌঁছাতে, প্রথমে তার নাম দিন, যেমন `omarchy agent account use codex side`। `~/.claude` বা `~/.codex`-এ আপনার ইতিমধ্যে থাকা লগইনটি হলো _Main_ অ্যাকাউন্ট এবং যেখানে আছে সেখানেই থাকে। প্রায় আট ঘণ্টার বেশি অব্যবহৃত থাকা কোনো অ্যাকাউন্ট _Sign-in required_ দেখাতে পারে; প্যানেলেই সেই অ্যাকাউন্টে আবার সাইন ইন করতে এটিতে ক্লিক করুন, অথবা এতে একটি সেশন শুরু করুন, যা নিজে নিজেই সাইন-ইন রিফ্রেশ করে। কোনো অ্যাকাউন্ট যোগ করার সময় আপনার থাকা MCP সার্ভারগুলো এতে চলে আসে, কিন্তু পরে `claude mcp add` দিয়ে যোগ করা সার্ভারগুলো কেবল যে অ্যাকাউন্টে যোগ করেছেন সেখানেই পৌঁছায়। Claude Desktop এবং কোনো CLI বাইনারির পরম পাথ দিয়ে কনফিগার করা টুলগুলো স্যুইচ অনুসরণ করে না। একটি সুস্পষ্ট `CLAUDE_CONFIG_DIR`, `CODEX_HOME` বা `GROK_HOME` নির্বাচিত অ্যাকাউন্টের ওপর অগ্রাধিকার পায়।

### ক্র্যাশ নির্ণয়

Omarchy প্রসেস ক্র্যাশের জন্য systemd-coredump পর্যবেক্ষণ করে। কিছু segfault করলে, আপনি একটি "Process crashed" নোটিফিকেশন পাবেন — এটিতে ক্লিক করুন, এবং ক্র্যাশটি Omarchy-র diagnose-crash স্কিলসহ আপনার ডিফল্ট এজেন্টের হাতে তুলে দেওয়া হয়, যা এজেন্টকে core dump থেকে তথ্য প্রতিষ্ঠা করা এবং ক্র্যাশটি আপস্ট্রিমে রিপোর্ট করার যোগ্য কিনা তা সিদ্ধান্ত নেওয়ার ধাপগুলো দেখিয়ে দেয়। আপনি `omarchy agent crash <pid>` দিয়ে `coredumpctl list` থেকে যেকোনো PID-র বিরুদ্ধে হাতেও এটি চালাতে পারেন।

পর্যবেক্ষণ ডিফল্টভাবে চালু থাকে। _Trigger > Toggle > Crash Capture_-এর অধীনে (বা `omarchy toggle crash-capture` দিয়ে) এটি বন্ধ করুন এবং নোটিফিকেশনগুলো বন্ধ হয়ে যায়; `omarchy agent crash <pid>` তবুও হাতে কাজ করে।

ক্র্যাশগুলো একবারে একটি প্রোগ্রাম করেও নীরব করা যায়, যা নির্ণয় শেষে আপনাকে প্রস্তাব করে। `omarchy crash mute hyprland` কেবল সেই প্রোগ্রামের জন্য নোটিফিকেশন বন্ধ করে, `omarchy crash mute hyprland off` সেগুলো ফিরিয়ে আনে, এবং নিজে নিজে `omarchy crash mute` আপনি যা মিউট করেছেন তা তালিকাভুক্ত করে। এটি বাইনারির নামের মতোই আনন্দের সঙ্গে তার পাথও নেয়, তাই `omarchy crash mute /usr/bin/hyprland` একই কাজ করে। স্পেস থাকা নাম উদ্ধৃত করুন, যেমন `omarchy crash mute 'Some App'`। অন্য সবকিছু তবুও জানায়, এবং মিউট করা প্রোগ্রামটি তবুও ক্র্যাশ করে — এটি স্মরণিকাটি লুকায়, কিছু ঠিক করে না।

### ডেস্কটপ অ্যাপ

_Install > AI_ মেনুতে কয়েকটি গ্রাফিক্যাল AI অ্যাপও আছে: ChatGPT ডেস্কটপ অ্যাপ, Claude ডেস্কটপ অ্যাপ (Anthropic-র Linux বিটা, Chat, Cowork এবং Claude Code ট্যাবসহ), xAI-র মডেলগুলোর সঙ্গে চ্যাট করার জন্য Grok Bot, Hermes Desktop, OpenClaw, এবং Perplexity ডেস্কটপ অ্যাপ। Grok Bot হলো ডেস্কটপ চ্যাট অ্যাপ। কোডিং এজেন্টটি হলো `grok` কমান্ড।

Hermes Desktop-ই জানার মতোটি, কারণ একটি মেশিনে একটি Hermes থাকে, এবং সেটি অ্যাপেরই: Hermes কেবল অ্যাপের মাধ্যমেই ইনস্টল হয়, এবং ডিফল্ট এজেন্ট যে `hermes` কমান্ড চালায় তা অ্যাপেরই। Hermes-কে ডিফল্ট এজেন্ট হিসেবে বেছে নিলে ঠিক তাই ইনস্টল হয় যা _Install > AI_ এন্ট্রি করে: প্যাকেজটি, এবং Hermes-এর নিজস্ব ইনস্টলার দ্বারা সেট আপ করা `~/.hermes`-এর অধীনে একটি Hermes রানটাইম, যা প্রথমবার কয়েক মিনিট সময় নেয়। সেই রানটাইমটিই একমাত্র Hermes যা টার্মিনাল `hermes` কমান্ড, ডিফল্ট এজেন্ট এবং অ্যাপ সবাই ব্যবহার করে, এবং এটি Omarchy রিলিজের অপেক্ষা না করে `hermes update` দিয়ে নিজে নিজেকে হালনাগাদ করে। এটি ইনস্টল করলে Hermes-কে `omarchy` নামের স্কিন হিসেবে Omarchy থিমও দেওয়া হয়, যা আপনি থিম বদলানোর সঙ্গে সঙ্গে প্রতিটি Hermes সারফেস অনুসরণ করে; আপনি যদি তা না চান তাহলে Hermes-র Appearance সেটিংসের অধীনে বা `/skin` দিয়ে আরেকটি বেছে নিন, এবং Omarchy সেই পছন্দে হাত দেয় না। _Remove > AI_-এর অধীনে অ্যাপটি সরালে প্রথমে Hermes বন্ধ হয়, গেটওয়ে সহ, সেই রানটাইমটিও তার সঙ্গে নিয়ে যায়, এবং আপনি অন্যথা না বললে আপনার চ্যাট, স্মৃতি, এবং Hermes নিজের জন্য লেখা স্কিলগুলো রেখে দেয়: এটি জিজ্ঞাসা করে, ডিফল্ট না, সেই ডেটা এবং আপনার সংযোগ সেটিংসও যাবে কিনা।

OpenClaw-র ডেস্কটপ অভিজ্ঞতা হলো এর Control UI, যা এর নিজস্ব লোকাল গেটওয়ের সমর্থনে ওয়েব অ্যাপ হিসেবে খোলে। OpenClaw `~/.openclaw`-এ থাকে এবং নিজে নিজেকে হালনাগাদ করে: Control UI-র "Update Gateway" বোতাম ব্যবহার করুন বা `openclaw update` চালান, এবং গেটওয়ে নতুন সংস্করণে পুনরায় চালু হয়। Omarchy কেবল একটি নতুন ইনস্টল কোন রিলিজ থেকে শুরু হবে তা বেছে দেয়। _Remove > AI_-এর অধীনে OpenClaw সরালে গেটওয়ে সার্ভিস এবং অ্যাপটি তার সঙ্গে নিয়ে যায় এবং তারপর জিজ্ঞাসা করে `~/.openclaw`-ও যাবে কিনা, কারণ সেখানে OpenClaw নিজে এবং এটির ডাউনলোড করা প্লাগইন রানটাইমগুলোর পাশাপাশি আপনার চ্যাট ও ক্রেডেনশিয়াল থাকে; ডিফল্ট এটি রেখে দেয়, এবং আবার OpenClaw ইনস্টল করলে তা আবার তুলে নেয়।

### লোকাল LLM

Omarchy লোকাল LLM মডেল চালানোর দুটি উপায় সুপারিশ করে: LM Studio এবং Ollama। LM Studio ওপেন-ওয়েট মডেল খুঁজে বের করা, সেগুলো ইনস্টল করা এবং চালানোর জন্য একটি GUI ইন্টারফেস দেয়। সহজে শুরু করার এটি দারুণ উপায়। Ollama একইভাবে করার জন্য একটি CLI দেয়। কিন্তু আপনি লোকাল মডেলে নতুন হলে, আমি LM Studio দিয়ে শুরু করতাম। আপনি Omarchy Menu-তে _Install > AI_-এর অধীনে যেকোনোটি ইনস্টল করতে পারেন।

### Omarchy স্কিল

এজেন্ট স্কিল AI-কে নির্দিষ্ট উপায়ে নির্দিষ্ট টুল ব্যবহার করতে সাহায্য করে, এবং Omarchy সিস্টেমটি নিজের মতো করে সাজানোর জন্য একটি ডিফল্ট স্কিলসহ আসে। যেমন আপনার Hyprland কনফিগ টুইক করা, বার সামঞ্জস্য করা, বা এমনকি একেবারে শুরু থেকে একটি নতুন থিম তৈরি করা। এটি Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` এবং প্রতিটি `~/.hermes/profiles/*/skills`), এবং জেনেরিক `~/.agents/skills` অবস্থানের জন্য স্কিল ডিরেক্টরিগুলোতে সিমলিঙ্ক করা থাকে, তাই বেশিরভাগ হারনেস এটি স্বয়ংক্রিয়ভাবে তুলে নেয়।

কিন্তু আপনার এই স্কিলটিকে পরীক্ষামূলক হিসেবে দেখা উচিত। বিভিন্ন মডেল এটিকে বিভিন্ন কার্যকারিতায় ব্যবহার করবে। প্রথমে প্ল্যান মোডে চালানোই সবচেয়ে ভালো, যাতে এজেন্ট কী বদলাতে চায় সে সম্পর্কে আপনার ধারণা থাকে। এবং তারপর পরিবর্তনগুলো রোলব্যাক করতে বা এমনকি `omarchy reinstall configs` চালাতেও প্রস্তুত থাকুন, যদি এজেন্ট সবকিছু এলোমেলো করে ফেলে।
