# মনিটর

Omarchy ডিফল্টভাবে ধরে নেয় আপনি 2x-সক্ষম retina-শ্রেণির ডিসপ্লেতে চালাচ্ছেন। সুন্দর, ঝকঝকে প্রোগ্রামার ফন্ট পেতে আপনার এটাই দরকার। উচ্চ-রেজোলিউশন স্ক্রিনসহ প্রায় সব নতুন প্রিমিয়াম ল্যাপটপ এর জন্যই অপ্টিমাইজ করা। 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) অথবা 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/)-তে আপনি এটাই চালাতে চাইবেন।

কিন্তু আপনি যদি 218 বা তার বেশি PPI-এর ডিসপ্লে না চালান, তাহলে মনিটরের সেটিংস বদলাতে চাইবেন। উদাহরণস্বরূপ, আপনার যদি 27" বা 32" 4K থাকে, তাহলে উপরের বারের মনিটর প্যানেল থেকে এর জন্য একটি ভগ্নাংশ স্কেল বেছে নিতে পারেন, অথবা `~/.config/hypr/monitors.lua` খুলে সেই কম্বোর জন্য সুপারিশে স্যুইচ করে প্রতিটি মনিটরের জন্য ডিফল্ট সেট করতে পারেন:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

আপনি যদি একটি 1080p বা 1440p ডিসপ্লে ব্যবহার করেন, তাহলে সম্ভবত শুধু 1x স্কেলিং ব্যবহার করতে চাইবেন, এবং GTK ও X11 অ্যাপের ক্ষেত্রেও একই, তাই আপনি ব্যবহার করতে পারেন:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

`GDK_SCALE`-এর পরিবর্তন পরিবর্তনের পরে চালু করা অ্যাপ্লিকেশনগুলোতে প্রযোজ্য হয় (এবং GTK শুধু পূর্ণ সংখ্যা মানে, তাই এটি আপনার মনিটর স্কেলের নিকটতম পূর্ণসংখ্যায় রাখুন)। তাই পরিবর্তনের পরে আকারে বড় হয়ে যাওয়া যে উইন্ডোগুলো আপনার আছে সেগুলো অবশ্যই বন্ধ করুন (অথবা `Ctrl + Alt + Del` দিয়ে সব উইন্ডো বন্ধ করুন!)।

আপনি `Super + /` ব্যবহার করে উপরে এবং `Super + Alt + /` ব্যবহার করে নিচে গিয়ে প্রধান মনিটর স্কেলিং অনুপাতগুলোর (1x, 1.25x, 1.6x, 2x, 3x, 4x) মধ্য দিয়েও দ্রুত এগোতে পারেন, অথবা উপরের বারের মনিটর প্যানেল থেকে একটি বেছে নিতে পারেন। এগুলো শুধু আপনি যে মনিটরে ফোকাস করেছেন সেটি বদলায়, তাই একটি ল্যাপটপ স্ক্রিন এবং একটি বাহ্যিক ডিসপ্লের প্রত্যেকের নিজস্ব স্কেল থাকতে পারে। প্যানেলটি প্রতিটি মনিটরের রেজোলিউশন, রিফ্রেশ রেট এবং রোটেশনও সেট করে। আপনার পছন্দগুলো সেই ফিজিক্যাল মনিটরের জন্য `~/.local/state/omarchy/monitors/settings`-এ সংরক্ষিত হয়, তাই সেগুলো রিবুটের পরেও থাকে এবং পরের বার মনিটরটি যে পোর্ট বা ডকেই প্লাগ করা হোক না কেন তার সঙ্গে যায়। সেগুলো `~/.config/hypr/monitors.lua`-তে একই মনিটরের জন্য যেকোনো নিয়মের চেয়ে অগ্রাধিকার পায়, যা Omarchy কখনো সম্পাদনা করে না। আপনি যদি বরং আপনার মনিটরগুলো সম্পূর্ণভাবে সেই ফাইলে সেট করতে চান, তাহলে এতে `omarchy_monitor_panel_settings = false` যোগ করুন, এবং প্যানেলের পরিবর্তনগুলো শুধু Hyprland রিলোড না হওয়া পর্যন্ত থাকবে। যেহেতু `GDK_SCALE` সব স্ক্রিনের জন্য একটি মান, তাই একটি নির্বাচিত স্কেল সবচেয়ে কম স্কেলের মনিটর থেকে এটি সেট করে, তাই X11 অ্যাপগুলো অন্য স্ক্রিনে আকারে বড় হওয়ার পরিবর্তে ঘন স্ক্রিনে একটু ছোট দেখায়।

### টেক্সট বড় বা ছোট করা

মনিটর স্কেলিং সবকিছুর আকার বদলায়। আপনি যদি শুধু বড় বা ছোট _টেক্সট_ চান, তার জন্য একটি মাত্র নব আছে:

```
omarchy display text size 14
```

এটি 9 থেকে 20-র মধ্যে একটি পিক্সেল আকার নেয়, এবং Omarchy শেল, GTK অ্যাপ্লিকেশন এবং আপনার টার্মিনালকে একসঙ্গে সরায়, তাই পুরো ডেস্কটপ অনুপাতে থাকে। আপনি কোথায় আছেন তা দেখতে আর্গুমেন্ট ছাড়া এটি চালান, এবং ডিফল্টে ফিরে যেতে `omarchy display text size reset` চালান। Foot একমাত্র পিছিয়ে পড়া: এর কনফিগ রিলোড করার কোনো উপায় নেই, তাই চলমান টার্মিনালগুলো আপনি একটি নতুন টার্মিনাল না খোলা পর্যন্ত তাদের পুরনো আকার ধরে রাখে।

### ল্যাপটপ ডিসপ্লে প্রসারিত করা এবং মিরর করা

যখন আপনি আপনার ল্যাপটপে একটি বাহ্যিক স্ক্রিন সংযুক্ত করেন, ডিসপ্লেটি স্বয়ংক্রিয়ভাবে প্রসারিত হয়। কিন্তু Omarchy মেনুতে _Trigger > Hardware_ অথবা `Super + Ctrl + Alt + Delete` ব্যবহার করে আপনি সেটি পরিবর্তে মিররিংয়ে বদলাতে পারেন। সেই বাহ্যিক স্ক্রিনটি একটি প্রজেক্টর হলে এবং কাজ করার সময় আপনি কিছু দেখাতে চাইলে এটি বিশেষভাবে সহায়ক।

আপনি যখন প্রসারিত করছেন, ল্যাপটপের ঢাকনা বন্ধ করলে অভ্যন্তরীণ স্ক্রিনটি স্বয়ংক্রিয়ভাবে বন্ধ হয়ে যাবে। ঢাকনা খুললে এটি আবার চালু হবে। Omarchy মেনুতে _Trigger > Hardware_ অথবা `Super + Ctrl + Delete` ব্যবহার করে আপনি এটি ম্যানুয়ালিও নিয়ন্ত্রণ করতে পারেন।

### একাধিক স্ক্রিন সাজানো

Hyprland একাধিক স্ক্রিনের সঙ্গে দারুণ কাজ করে। উপরের বারের মনিটর প্যানেল সেগুলো যেখানে আছে সেখানে আঁকে: একটিকে অন্যটির পাশে টেনে সেখানে সরান, এবং সাজানোটি প্রতিটি মনিটরের অন্যান্য সেটিংসের সঙ্গে সংরক্ষিত হয়। প্যানেল যা কভার করে না এমন যেকোনো কিছুর জন্য, সেগুলো কীভাবে সাজাতে হয় সে সম্পর্কে [Hyprland মনিটর ডকুমেন্টেশনে](https://wiki.hypr.land/Configuring/Basics/Monitors/) আরও পড়ুন। Omarchy-তে, এগুলো `~/.config/hypr/monitors.lua`-তে `hl.monitor` এন্ট্রি হিসেবে যায় — ফাইলটি একটি মনিটর বন্ধ রাখা, প্যানেল যে মোডগুলো দেয় না সেগুলো, 10-bit রঙ, এবং পরিবর্তনশীল রিফ্রেশ রেটের জন্য মন্তব্য করা উদাহরণসহ আসে।

প্রতিটি মনিটরের নিজস্ব 1 থেকে 10 পর্যন্ত ওয়ার্কস্পেস আছে, তাই `Super + 1` সবসময় আপনি যে মনিটরে আছেন তার প্রথম ওয়ার্কস্পেস বোঝায়। পর্দার আড়ালে, Hyprland এখনও সব মনিটরজুড়ে ওয়ার্কস্পেসগুলোকে নম্বর দেয়: আপনার ল্যাপটপ স্ক্রিন (বা প্রথম মনিটর) পায় 1–10, পরের মনিটর 11–20, এবং এভাবে চলতে থাকে, এবং প্রতিটি মনিটর প্রতিবার আপনি এটি প্লাগ করার সময় তার ব্লক ধরে রাখে। আপনি যদি একটি নির্দিষ্ট মনিটরের জন্য [ওয়ার্কস্পেসের নিয়ম](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) বা উইন্ডোর নিয়ম লেখেন তাহলে সেই নম্বরগুলো ব্যবহার করুন, তাই ওয়ার্কস্পেস 12 হলো আপনার দ্বিতীয় মনিটরের দ্বিতীয় ওয়ার্কস্পেস। `~/.local/state/omarchy/monitors/workspaces` তালিকাভুক্ত করে কোন মনিটরের কোন ব্লক আছে।

অ্যারো কীগুলো আপনার লেআউটে একটি প্রান্ত ভাগ করা মনিটরগুলো জুড়ে কাজ করে। যে স্ক্রিনগুলো শুধু একটি কোণায় স্পর্শ করে, বা যাদের মধ্যে ফাঁক আছে, সেগুলো প্রতিবেশী নয়, তাই তাদের মধ্যে যেতে `Ctrl + Alt + Tab` ব্যবহার করুন।

| হটকি | একাধিক মনিটরে |
| --- | --- |
| `Super + Arrow` | সেই দিকে আর কোনো উইন্ডো না থাকলে সেই পাশের মনিটরে ফোকাস সরায় |
| `Super + Shift + Arrow` | সেই পাশের মনিটরের একটি উইন্ডোর সঙ্গে অদলবদল করে |
| `Super + Alt + Arrow` | উইন্ডোটিকে সেই পাশের মনিটরের একটি গ্রুপে সরায় |
| `Super + Shift + Ctrl + Arrow` | উইন্ডোটিকে সেই পাশের মনিটরে, এটি যে ওয়ার্কস্পেস দেখাচ্ছে তাতে সরায় |
| `Super + Shift + Alt + Arrow` | ওয়ার্কস্পেসটিকে সেই পাশের মনিটরে সরায়, খালি থাকলে এর নম্বর ধরে রাখে |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | লেআউট যাই হোক, পরের বা আগের মনিটরে ফোকাস সরায় |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | আপনি যে মনিটরে আছেন সেখানেই থাকে |

আপনি [Hyprmon](https://github.com/erans/hyprmon/)-ও দেখতে পারেন, যদি একাধিক স্ক্রিনের অবস্থান নির্ধারণে সাহায্যের জন্য একটি TUI চান।

### উজ্জ্বলতা নিয়ন্ত্রণ করা

মনিটরের উজ্জ্বলতা উজ্জ্বলতা বাড়ানো/কমানোর জন্য নির্ধারিত ফাংশন কী দিয়ে নিয়ন্ত্রিত হয়। এগুলো চাপার সময় shift ধরে রাখলে, আপনি সর্বোচ্চ বা সর্বনিম্ন উজ্জ্বলতায় যাবেন। কীগুলো আপনি যে ডিসপ্লেতে ফোকাস করেছেন তা নিয়ন্ত্রণ করে, তাই DDC/CI বলতে পারা বাহ্যিক মনিটরগুলো ল্যাপটপ স্ক্রিনের মতোই একইভাবে সামঞ্জস্য করা হয়।

### Apple ডিসপ্লে

আপনি যদি একটি Apple ডিসপ্লে ব্যবহার করেন, তাহলে নিয়মিত কীবোর্ড উজ্জ্বলতা কীগুলোও স্বয়ংক্রিয়ভাবে কাজ করবে, যদি আপনি Apple ডিসপ্লেতে ফোকাস করে থাকেন। এটি `asdcontrol` কমান্ডের মাধ্যমে করা হয়।

লক্ষ্য করুন আপনি যদি একটি Apple 6K XDR ডিসপ্লে ব্যবহার করেন, তাহলে আপনার `hyprctl monitors` তালিকায় একটি ভূতুড়ে স্ক্রিন দেখতে পারেন। `~/.config/hypr/monitors.lua`-তে `hl.monitor({ output = "DP-2", disabled = true })`-এর মতো কিছু দিয়ে আপনি এটি বন্ধ করতে পারেন।

Intel মেশিনে, আপনার একটি নিয়মিত Thunderbolt কেবল ব্যবহার করে Apple ডিসপ্লেতে সংযোগ করা উচিত। Thunderbolt ছাড়া অন্য মেশিনে, এটি কাজ করাতে সাধারণত আপনাকে একটি [DP + USB-A -> USB-C কেবল](https://www.amazon.com/dp/B0BNX7MS6N) ব্যবহার করতে হবে।
