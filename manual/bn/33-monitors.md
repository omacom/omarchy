# মনিটর

Omarchy ধরে নেয় যে আপনি ডিফল্টভাবে একটি 2x-সক্ষম retina-শ্রেণির ডিসপ্লেতে এটি চালাচ্ছেন। ওই সুন্দর, ঝকঝকে প্রোগ্রামার ফন্ট পেতে আপনার এটাই দরকার। উচ্চ-রেজোলিউশনের স্ক্রিনসহ প্রায় সব নতুন প্রিমিয়াম ল্যাপটপ যার জন্য অপ্টিমাইজ করা, সেটাই এটা। 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) অথবা 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/)-তে আপনি এটাই চালাতে চাইবেন।

কিন্তু আপনি যদি 218 বা তার বেশি PPI-এর ডিসপ্লে না চালান, তাহলে আপনি মনিটরের সেটিংস বদলাতে চাইবেন। উদাহরণস্বরূপ, আপনার যদি একটি 27" বা 32" 4K থাকে, তাহলে আপনি উপরের বারে মনিটর প্যানেল থেকে সেটির জন্য একটি ভগ্নাংশ স্কেল বেছে নিতে পারেন, অথবা `~/.config/hypr/monitors.lua` খুলে ওই কম্বোর জন্য সুপারিশে বদলে প্রতিটি মনিটরের জন্য ডিফল্ট সেট করতে পারেন:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

আপনি যদি একটি 1080p বা 1440p ডিসপ্লে ব্যবহার করেন, তাহলে সম্ভবত আপনি শুধু 1x স্কেলিং ব্যবহার করতে চাইবেন, এবং GTK ও X11 অ্যাপের জন্যও একই, তাই আপনি এটি ব্যবহার করতে পারেন:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

`GDK_SCALE`-এ পরিবর্তন পরিবর্তনের পরে চালু করা অ্যাপ্লিকেশনগুলোর ক্ষেত্রে প্রযোজ্য হয় (এবং GTK শুধু পূর্ণ সংখ্যা মানে, তাই এটিকে আপনার মনিটর স্কেলের সবচেয়ে কাছের পূর্ণসংখ্যায় রাখুন)। তাই নিশ্চিত করুন যে পরিবর্তনের পরে আপনার যেসব উইন্ডো অতিরিক্ত বড় হয়ে গেছে সেগুলো আপনি বন্ধ করেছেন (অথবা `Ctrl + Alt + Del` দিয়ে সব উইন্ডো বন্ধ করুন!)।

আপনি উপরে যেতে `Super + /` এবং নিচে যেতে `Super + Alt + /` ব্যবহার করে, অথবা উপরের বারে মনিটর প্যানেল থেকে একটি বেছে নিয়ে প্রধান মনিটর স্কেলিং অনুপাতগুলোর (1x, 1.25x, 1.6x, 2x, 3x, 4x) মধ্যে দ্রুত ধাপে ধাপে এগোতে পারেন। এগুলো শুধু আপনি যে মনিটরে ফোকাস করেছেন সেটিকে বদলায়, তাই একটি ল্যাপটপ স্ক্রিন ও একটি বাহ্যিক ডিসপ্লে প্রত্যেকের নিজস্ব স্কেল থাকতে পারে। প্যানেলটি প্রতিটি মনিটরের রেজোলিউশনও সেট করে। আপনার পছন্দগুলো ওই ফিজিক্যাল মনিটরের জন্য `~/.local/state/omarchy/monitors/settings`-এ সংরক্ষিত হয়, তাই সেগুলো রিবুটের পরেও থাকে এবং মনিটরটি পরের বার যেই পোর্ট বা ডকে লাগানো হোক না কেন তার সঙ্গে যায়। সেগুলো `~/.config/hypr/monitors.lua`-তে একই মনিটরের জন্য যেকোনো নিয়মের চেয়ে অগ্রাধিকার পায়, যা Omarchy কখনো সম্পাদনা করে না। যেহেতু `GDK_SCALE` সব স্ক্রিনের জন্য একটি মান, তাই একটি নির্বাচিত স্কেল সবচেয়ে কম স্কেলের মনিটর থেকে এটি সেট করে, ফলে X11 অ্যাপগুলো অন্য স্ক্রিনে অতিরিক্ত বড় হওয়ার বদলে ঘন স্ক্রিনে একটু ছোট হয়ে আসে।

### টেক্সট বড় বা ছোট করা

মনিটর স্কেলিং সবকিছুর আকার বদলায়। আপনি যদি শুধু বড় বা ছোট _টেক্সট_ চান, তাহলে সেটির জন্য একটি মাত্র নব আছে:

```
omarchy display text size 14
```

এটি 9 থেকে 20-এর মধ্যে একটি পিক্সেল আকার নেয়, এবং Omarchy শেল, GTK অ্যাপ্লিকেশন ও আপনার টার্মিনালকে একসঙ্গে সরায়, যাতে পুরো ডেস্কটপ অনুপাতে থাকে। আপনি কোথায় আছেন তা দেখতে আর্গুমেন্ট ছাড়া এটি চালান, এবং ডিফল্টে ফিরে যেতে `omarchy display text size reset` চালান। Foot হলো একমাত্র পিছিয়ে থাকা: এর কনফিগ পুনরায় লোড করার কোনো উপায় নেই, তাই চলমান টার্মিনালগুলো আপনি নতুন একটি না খোলা পর্যন্ত তাদের পুরনো আকার ধরে রাখে।

### ল্যাপটপ ডিসপ্লে প্রসারিত করা ও মিরর করা

আপনি যখন আপনার ল্যাপটপে একটি বাহ্যিক স্ক্রিন সংযোগ করেন, তখন ডিসপ্লেটি স্বয়ংক্রিয়ভাবে প্রসারিত হয়। কিন্তু আপনি Omarchy মেনুতে _Trigger > Hardware_ অথবা `Super + Ctrl + Alt + Delete` ব্যবহার করে এর বদলে সেটিকে মিররিংয়ে বদলাতে পারেন। এটি বিশেষভাবে সহায়ক যদি ওই বাহ্যিক স্ক্রিনটি একটি প্রজেক্টর হয়, এবং আপনি কাজ করার সময় কিছু দেখাতে চান।

আপনি যখন প্রসারিত করছেন, তখন ল্যাপটপের ঢাকনা বন্ধ করলে অভ্যন্তরীণ স্ক্রিনটি স্বয়ংক্রিয়ভাবে বন্ধ হয়ে যাবে। ঢাকনা খুললে এটি আবার চালু হবে। আপনি Omarchy মেনুতে _Trigger > Hardware_ অথবা `Super + Ctrl + Delete` ব্যবহার করে এটিকে ম্যানুয়ালিও নিয়ন্ত্রণ করতে পারেন।

### একাধিক স্ক্রিন সাজানো

Hyprland একাধিক স্ক্রিনের সঙ্গে দারুণ কাজ করে। উপরের বারে মনিটর প্যানেল সেগুলো যেখানে বসে আছে সেখানে আঁকে: একটিকে অন্যটির পাশে টেনে সেখানে সরান, এবং বিন্যাসটি প্রতিটি মনিটরের অন্যান্য সেটিংসের সঙ্গে সংরক্ষিত হয়। প্যানেল যা কভার করে না তার যেকোনো কিছুর জন্য, [Hyprland মনিটর ডকুমেন্টেশন](https://wiki.hypr.land/Configuring/Basics/Monitors/)-এ সেগুলো কীভাবে সাজাতে হয় সে সম্পর্কে আরও পড়ুন। Omarchy-তে, এগুলো `~/.config/hypr/monitors.lua`-তে `hl.monitor` এন্ট্রি হিসেবে যায় — ফাইলটি একটি নির্দিষ্ট মনিটরকে একটি রেজোলিউশন, অবস্থান ও ঘূর্ণনে পিন করার জন্য মন্তব্য করা উদাহরণসহ আসে।

প্রতিটি মনিটরের নিজস্ব 1 থেকে 10 পর্যন্ত ওয়ার্কস্পেস আছে, তাই `Super + 1` সবসময় মানে আপনি যে মনিটরে আছেন তার প্রথম ওয়ার্কস্পেস। পর্দার আড়ালে, Hyprland এখনও সব মনিটরজুড়ে ওয়ার্কস্পেসগুলোকে নম্বর দেয়: আপনার ল্যাপটপ স্ক্রিন (অথবা প্রথম মনিটর) পায় 1–10, পরের মনিটর 11–20, এবং এভাবেই চলতে থাকে, এবং প্রতিটি মনিটর প্রতিবার আপনি এটি লাগানোর সময় তার ব্লক ধরে রাখে। আপনি যদি একটি নির্দিষ্ট মনিটরের জন্য [ওয়ার্কস্পেসের নিয়ম](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) বা উইন্ডোর নিয়ম লেখেন তাহলে ওই সংখ্যাগুলো ব্যবহার করুন, যাতে ওয়ার্কস্পেস 12 হয় আপনার দ্বিতীয় মনিটরের দ্বিতীয় ওয়ার্কস্পেস। `~/.local/state/omarchy/monitors/workspaces` তালিকাভুক্ত করে কোন মনিটরের কোন ব্লক আছে।

আপনার বিন্যাসে একটি প্রান্ত ভাগ করে এমন মনিটরগুলোজুড়ে অ্যারো কি-গুলো কাজ করে। যেসব স্ক্রিন শুধু একটি কোণায় স্পর্শ করে, অথবা যাদের মধ্যে ফাঁক আছে, তারা প্রতিবেশী নয়, তাই তাদের মধ্যে যেতে `Ctrl + Alt + Tab` ব্যবহার করুন।

| হটকি | মনিটরজুড়ে |
| --- | --- |
| `Super + Arrow` | ওই দিকে আর কোনো উইন্ডো না থাকলে ওই পাশের মনিটরে ফোকাস সরায় |
| `Super + Shift + Arrow` | ওই পাশের মনিটরে একটি উইন্ডোর সঙ্গে অদলবদল করে |
| `Super + Alt + Arrow` | উইন্ডোটিকে ওই পাশের মনিটরে একটি গ্রুপে সরায় |
| `Super + Shift + Ctrl + Arrow` | উইন্ডোটিকে ওই পাশের মনিটরে, এটি যে ওয়ার্কস্পেস দেখাচ্ছে তার উপরে সরায় |
| `Super + Shift + Alt + Arrow` | ওয়ার্কস্পেসটিকে ওই পাশের মনিটরে সরায়, এটি খালি থাকলে তার নম্বর ধরে রেখে |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | বিন্যাস যাই হোক না কেন, পরের বা আগের মনিটরে ফোকাস সরায় |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | আপনি যে মনিটরে আছেন সেখানেই থাকে |

আপনি [Hyprmon](https://github.com/erans/hyprmon/)-ও দেখতে পারেন, যদি আপনি একাধিক স্ক্রিনের অবস্থান নির্ধারণে সাহায্য করার জন্য একটি TUI চান।

### উজ্জ্বলতা নিয়ন্ত্রণ করা

মনিটরের উজ্জ্বলতা উজ্জ্বলতা বাড়ানো/কমানোর জন্য নিবেদিত ফাংশন কি দিয়ে নিয়ন্ত্রিত হয়। আপনি যদি এগুলো চাপার সময় shift চেপে ধরে রাখেন, তাহলে আপনি সর্বোচ্চ বা সর্বনিম্ন উজ্জ্বলতায় যাবেন। কি-গুলো আপনি যে ডিসপ্লেতে ফোকাস করেছেন সেটিকে নিয়ন্ত্রণ করে, তাই DDC/CI বলতে পারে এমন বাহ্যিক মনিটরগুলো ল্যাপটপ স্ক্রিনের মতো একইভাবে সামঞ্জস্য করা হয়।

### Apple ডিসপ্লে

আপনি যদি একটি Apple ডিসপ্লে ব্যবহার করেন, তাহলে নিয়মিত কীবোর্ড উজ্জ্বলতার কি-গুলোও স্বয়ংক্রিয়ভাবে কাজ করবে, যদি আপনি Apple ডিসপ্লেতে ফোকাস করে থাকেন। এটি `asdcontrol` কমান্ডের মাধ্যমে করা হয়।

মনে রাখবেন আপনি যদি একটি Apple 6K XDR ডিসপ্লে ব্যবহার করেন, তাহলে আপনি আপনার `hyprctl monitors` তালিকায় একটি ভূতুড়ে স্ক্রিন দেখতে পারেন। আপনি `~/.config/hypr/monitors.lua`-তে `hl.monitor({ output = "DP-2", disabled = true })`-এর মতো কিছু দিয়ে এটি বন্ধ করতে পারেন।

Intel মেশিনে, আপনার একটি নিয়মিত Thunderbolt কেবল ব্যবহার করে Apple ডিসপ্লেতে সংযোগ করা উচিত। Thunderbolt ছাড়া অন্য মেশিনে, এটি কাজ করাতে আপনাকে সাধারণত একটি [DP + USB-A -> USB-C কেবল](https://www.amazon.com/dp/B0BNX7MS6N) ব্যবহার করতে হবে।
