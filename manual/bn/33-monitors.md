# মনিটর

Omarchy ডিফল্টভাবে ধরে নেয় আপনি একটি 2x-সক্ষম retina-শ্রেণির ডিসপ্লে ব্যবহার করছেন। সেই সুন্দর, ঝকঝকে programmer ফন্ট পেতে আপনার এটাই দরকার। high-resolution স্ক্রিনসহ প্রায় সব নতুন premium ল্যাপটপ এর জন্যই optimized। 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) বা 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/)-তে আপনি এটাই চালাতে চাইবেন।

কিন্তু আপনি যদি 218 বা তার বেশি PPI-এর ডিসপ্লে ব্যবহার না করেন, তাহলে আপনি মনিটরের সেটিংস বদলাতে চাইবেন। উদাহরণস্বরূপ, আপনার যদি একটি 27" বা 32" 4K থাকে, তাহলে উপরের বারের monitor প্যানেল থেকে এর জন্য একটি fractional scale বেছে নিতে পারেন, অথবা `~/.config/hypr/monitors.lua` খুলে সেই combo-র জন্য সুপারিশে স্যুইচ করে প্রতিটি মনিটরের জন্য ডিফল্ট সেট করতে পারেন:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

আপনি যদি একটি 1080p বা 1440p ডিসপ্লে ব্যবহার করেন, তাহলে সম্ভবত আপনি শুধু 1x scaling ব্যবহার করতে চাইবেন, এবং GTK ও X11 অ্যাপের জন্যও একই, তাই আপনি ব্যবহার করতে পারেন:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

`GDK_SCALE`-এ পরিবর্তন পরিবর্তনের পরে চালু করা অ্যাপ্লিকেশনগুলোর ক্ষেত্রে প্রযোজ্য হয় (এবং GTK শুধু পূর্ণ সংখ্যা মানে, তাই এটিকে আপনার মনিটর স্কেলের নিকটতম পূর্ণসংখ্যায় রাখুন)। তাই পরিবর্তনের পরে আপনার যেসব উইন্ডো অতিরিক্ত বড় হয়ে আছে সেগুলো অবশ্যই বন্ধ করুন (অথবা `Ctrl + Alt + Del` দিয়ে সব উইন্ডো বন্ধ করুন!)।

এছাড়াও আপনি `Super + /` ব্যবহার করে উপরে যেতে এবং `Super + Alt + /` ব্যবহার করে নিচে যেতে প্রধান মনিটর scaling অনুপাতগুলোর (1x, 1.25x, 1.6x, 2x, 3x, 4x) মধ্য দিয়ে দ্রুত ধাপে ধাপে যেতে পারেন, অথবা উপরের বারের monitor প্যানেল থেকে একটি বেছে নিতে পারেন। এগুলো শুধু আপনি যে মনিটরে ফোকাস করেছেন সেটিই বদলায়, তাই একটি ল্যাপটপ স্ক্রিন এবং একটি external ডিসপ্লে প্রতিটির নিজস্ব scale থাকতে পারে। প্যানেলটি প্রতিটি মনিটরের resolution, refresh rate এবং rotation-ও সেট করে। আপনার পছন্দগুলো সেই physical মনিটরের জন্য `~/.local/state/omarchy/monitors/settings`-এ সংরক্ষিত হয়, তাই সেগুলো reboot-এর পরেও থাকে এবং পরের বার মনিটরটি যে port বা dock-এই লাগানো হোক না কেন তার সঙ্গে যায়। সেগুলো `~/.config/hypr/monitors.lua`-তে একই মনিটরের জন্য থাকা যেকোনো নিয়মের চেয়ে অগ্রাধিকার পায়, যা Omarchy কখনো সম্পাদনা করে না। আপনি যদি বরং আপনার মনিটরগুলো সম্পূর্ণরূপে সেই ফাইলেই সেট করতে চান, তাহলে এতে `omarchy_monitor_panel_settings = false` যোগ করুন, এবং প্যানেলের পরিবর্তনগুলো শুধু Hyprland reload না হওয়া পর্যন্ত থাকবে। যেহেতু `GDK_SCALE` সব স্ক্রিনের জন্য একটি মান, তাই একটি নির্বাচিত scale সবচেয়ে কম scale-এর মনিটর থেকে এটি সেট করে, যাতে X11 অ্যাপগুলো অন্য স্ক্রিনে অতিরিক্ত বড় হওয়ার পরিবর্তে ঘন স্ক্রিনে একটু ছোট হয়ে আসে।

### টেক্সট বড় বা ছোট করা

মনিটর scaling সবকিছুর আকার বদলে দেয়। আপনি যদি শুধু বড় বা ছোট _text_ চান, তার জন্য একটিই knob আছে:

```
omarchy display text size 14
```

এটি 9 থেকে 20-এর মধ্যে একটি pixel আকার নেয়, এবং Omarchy shell, GTK অ্যাপ্লিকেশন এবং আপনার টার্মিনালকে একসঙ্গে সরায়, যাতে পুরো ডেস্কটপ অনুপাতে থাকে। আপনি কোথায় আছেন তা দেখতে আর্গুমেন্ট ছাড়া এটি চালান, এবং ডিফল্টে ফিরে যেতে `omarchy display text size reset` চালান। Foot একমাত্র পিছিয়ে থাকা: এর config reload করার কোনো উপায় নেই, তাই আপনি নতুন একটি না খোলা পর্যন্ত চলমান টার্মিনালগুলো তাদের পুরনো আকারই ধরে রাখে।

### ল্যাপটপ ডিসপ্লে প্রসারিত করা এবং মিরর করা

আপনি যখন আপনার ল্যাপটপে একটি external স্ক্রিন সংযুক্ত করেন, তখন ডিসপ্লেটি স্বয়ংক্রিয়ভাবে প্রসারিত হয়। কিন্তু আপনি উপরের বারের monitor প্যানেলে _Extend_ | _Mirror_, Omarchy মেনুতে _Trigger > Hardware_, অথবা `Super + Ctrl + Alt + Delete` দিয়ে তার পরিবর্তে এটিকে mirroring-এ বদলাতে পারেন। এটি বিশেষভাবে সহায়ক যদি সেই external স্ক্রিনটি একটি projector হয়, এবং আপনি কাজ করার সময় কিছু দেখাতে চান।

আপনি যখন প্রসারিত করছেন, তখন ল্যাপটপের ঢাকনা বন্ধ করলে অভ্যন্তরীণ স্ক্রিনটি স্বয়ংক্রিয়ভাবে বন্ধ হয়ে যাবে। ঢাকনা খুললে এটি আবার চালু হবে। এছাড়াও আপনি Omarchy মেনুতে _Trigger > Hardware_ অথবা `Super + Ctrl + Delete` ব্যবহার করে ম্যানুয়ালি এটি নিয়ন্ত্রণ করতে পারেন।

ল্যাপটপ plugged in থাকা অবস্থায়, ঢাকনা বন্ধ করলে এটি কখনো sleep-এ যায় না, তাই external স্ক্রিন সাময়িকভাবে disconnect হলেও একটি dock করা ল্যাপটপ জেগে থাকে। কোনো external স্ক্রিন সংযুক্ত না থাকলে, power-এ থাকা অবস্থায় ঢাকনা বন্ধ করলে এটি শুধু lock হয়। ব্যাটারিতে থাকলে, ঢাকনা বন্ধ করলে যথারীতি suspend হয়।

### একাধিক স্ক্রিন সাজানো

Hyprland একাধিক স্ক্রিনের সঙ্গে দারুণ কাজ করে। উপরের বারের monitor প্যানেল সেগুলো যেখানে বসে আছে সেখানে আঁকে: একটিকে অন্যটির পাশে টেনে সেখানে সরান, এবং প্রতিটি মনিটরের অন্যান্য সেটিংসের সঙ্গে বিন্যাসটি সংরক্ষিত হয়। প্যানেলে যা নেই তার জন্য, [Hyprland মনিটর ডকুমেন্টেশনে](https://wiki.hypr.land/Configuring/Basics/Monitors/) সেগুলো কীভাবে সাজাতে হয় সে সম্পর্কে আরও পড়ুন। Omarchy-তে, এগুলো `hl.monitor` এন্ট্রি হিসেবে `~/.config/hypr/monitors.lua`-তে যায় — ফাইলটির সঙ্গে একটি মনিটর বন্ধ রাখা, প্যানেলে দেওয়া হয় না এমন mode, 10-bit রঙ, এবং variable refresh rate-এর জন্য commented উদাহরণ দেওয়া থাকে।

প্রতিটি মনিটরের নিজস্ব 1 থেকে 10 পর্যন্ত workspace আছে, তাই `Super + 1` সবসময় মানে আপনি যে মনিটরে আছেন তার প্রথম workspace। পর্দার আড়ালে, Hyprland এখনও সব মনিটর জুড়ে workspace নম্বর দেয়: আপনার ল্যাপটপ স্ক্রিন (বা প্রথম মনিটর) 1–10 পায়, পরের মনিটর 11–20 পায়, এবং এভাবেই চলতে থাকে, এবং আপনি যতবার এটি লাগান প্রতিটি মনিটর তার block ধরে রাখে। আপনি যদি একটি নির্দিষ্ট মনিটরের জন্য [workspace নিয়মাবলি](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) বা window নিয়ম লেখেন তাহলে সেই নম্বরগুলো ব্যবহার করুন, যাতে workspace 12 হয় আপনার দ্বিতীয় মনিটরের দ্বিতীয় workspace। `~/.local/state/omarchy/monitors/workspaces` তালিকাভুক্ত করে প্রতিটি মনিটরের কোন block আছে।

আপনার লেআউটে একটি প্রান্ত ভাগ করে এমন মনিটরগুলোর মধ্যে arrow কীগুলো কাজ করে। যেসব স্ক্রিন শুধু একটি কোণায় ছোঁয়, বা যাদের মধ্যে ফাঁক আছে, তারা প্রতিবেশী নয়, তাই তাদের মধ্যে যেতে `Ctrl + Alt + Tab` ব্যবহার করুন।

| হটকি | মনিটর জুড়ে |
| --- | --- |
| `Super + Arrow` | সেই দিকে আর কোনো উইন্ডো না থাকলে ফোকাস সেই পাশের মনিটরে সরায় |
| `Super + Shift + Arrow` | সেই পাশের মনিটরের একটি উইন্ডোর সঙ্গে অদলবদল করে |
| `Super + Alt + Arrow` | উইন্ডোটিকে সেই পাশের মনিটরের একটি গ্রুপে সরায় |
| `Super + Shift + Ctrl + Arrow` | উইন্ডোটিকে সেই পাশের মনিটরে, সেটি যে workspace দেখাচ্ছে তার উপর সরায় |
| `Super + Shift + Alt + Arrow` | workspace-টিকে সেই পাশের মনিটরে সরায়, ফাঁকা থাকলে এর নম্বর ধরে রাখে |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | লেআউট যাই হোক না কেন, ফোকাস পরবর্তী বা আগের মনিটরে সরায় |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | আপনি যে মনিটরে আছেন সেখানেই থাকে |

একাধিক স্ক্রিনের অবস্থান ঠিক করতে সাহায্য করার জন্য আপনি যদি একটি TUI চান, তাহলে আপনি [Hyprmon](https://github.com/erans/hyprmon/)-ও দেখতে পারেন।

### উজ্জ্বলতা নিয়ন্ত্রণ

মনিটরের উজ্জ্বলতা brightness up/down-এর জন্য নিবেদিত function কীগুলো দিয়ে নিয়ন্ত্রিত হয়। আপনি যদি এগুলো চাপার সময় shift চেপে ধরে রাখেন, তাহলে আপনি সর্বোচ্চ বা সর্বনিম্ন উজ্জ্বলতায় যাবেন। কীগুলো আপনি যে ডিসপ্লেতে ফোকাস করেছেন তা নিয়ন্ত্রণ করে, তাই DDC/CI বলতে পারে এমন external মনিটরগুলো ল্যাপটপ স্ক্রিনের মতো একইভাবে সামঞ্জস্য করা হয়।

### Apple ডিসপ্লে

আপনি যদি একটি Apple ডিসপ্লে ব্যবহার করেন, তাহলে আপনি Apple ডিসপ্লেতে ফোকাস করে থাকলে নিয়মিত keyboard brightness কীগুলোও স্বয়ংক্রিয়ভাবে কাজ করবে। এটি `asdcontrol` কমান্ডের মাধ্যমে করা হয়।

মনে রাখবেন আপনি যদি একটি Apple 6K XDR ডিসপ্লে ব্যবহার করেন, তাহলে আপনার `hyprctl monitors` তালিকায় একটি phantom স্ক্রিন দেখতে পারেন। আপনি `~/.config/hypr/monitors.lua`-তে `hl.monitor({ output = "DP-2", disabled = true })`-এর মতো কিছু দিয়ে এটি বন্ধ করতে পারেন।

Intel মেশিনে, আপনার একটি নিয়মিত Thunderbolt কেবল ব্যবহার করে Apple ডিসপ্লেতে সংযোগ করা উচিত। Thunderbolt ছাড়া অন্য মেশিনে, এটি কাজ করাতে আপনাকে সাধারণত একটি [DP + USB-A -> USB-C কেবল](https://www.amazon.com/dp/B0BNX7MS6N) ব্যবহার করতে হবে।
