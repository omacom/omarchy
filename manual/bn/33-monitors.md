# মনিটর

Omarchy ধরে নেয় যে আপনি ডিফল্টভাবে একটি 2x-সক্ষম retina-শ্রেণির ডিসপ্লেতে চলছেন। সেই সুন্দর, ঝকঝকে প্রোগ্রামার ফন্টগুলো পেতে এটাই দরকার। প্রায় সব নতুন প্রিমিয়াম ল্যাপটপ, যেগুলো উচ্চ-রেজোলিউশনের স্ক্রিনের জন্য অপ্টিমাইজ করা, সেগুলো এভাবেই চলে। 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) অথবা 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) — এসব ডিসপ্লেতে আপনি যেভাবে চালাতে চাইবেন, ঠিক সেভাবে।

কিন্তু আপনি যদি 218 বা তার বেশি PPI-এর ডিসপ্লে না চালান, তাহলে মনিটরের সেটিংস বদলাতে চাইবেন। উদাহরণস্বরূপ, আপনার যদি 27" বা 32" 4K থাকে, তাহলে `~/.config/hypr/monitors.lua` খুলে (Omarchy মেনুতে _সেটআপ > মনিটর_ হয়ে) এবং সেই কম্বোর জন্য সুপারিশে বদলে ফ্র্যাকশনাল স্কেলিং ব্যবহার করতে পারেন:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

আপনি যদি 1080p বা 1440p ডিসপ্লে ব্যবহার করেন, তাহলে সম্ভবত শুধু 1x স্কেলিং-ই চাইবেন, তাই আপনি এটি ব্যবহার করতে পারেন:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

`GDK_SCALE`-এ করা পরিবর্তন পরিবর্তনের পরে চালু হওয়া অ্যাপ্লিকেশনগুলোর ক্ষেত্রে প্রযোজ্য হয় (এবং GTK শুধু পূর্ণ সংখ্যা মানে, তাই এটিকে আপনার মনিটর স্কেলের নিকটতম পূর্ণসংখ্যায় রাখুন)। তাই পরিবর্তনের পরে যেসব উইন্ডো অতিরিক্ত বড় হয়ে আছে, সেগুলো বন্ধ করে দেওয়ার বিষয়টি নিশ্চিত করুন (অথবা `Ctrl + Alt + Del` দিয়ে সব উইন্ডো বন্ধ করুন!)।

আপনি `Super + /` দিয়ে উপরে এবং `Super + Alt + /` দিয়ে নিচে গিয়ে প্রধান মনিটর স্কেলিং অনুপাতগুলোর (1x, 1.25x, 1.6x, 2x, 3x, 4x) মধ্যে দ্রুত ধাপে ধাপে এগোতেও পারেন। আপনার কাছে ডিফল্ট কনফিগারেশন থাকলে, এই পরিবর্তনগুলো রিবুটের পরেও থেকে যাবে।

### টেক্সট বড় বা ছোট করা

মনিটর স্কেলিং সবকিছুর আকার বদলে দেয়। আপনি যদি শুধু বড় বা ছোট _টেক্সট_ চান, তাহলে তার জন্য একটাই নব আছে:

```
omarchy display text size 14
```

এটি 9 থেকে 20-এর মধ্যে একটি পিক্সেল আকার নেয়, এবং Omarchy শেল, GTK অ্যাপ্লিকেশন এবং আপনার টার্মিনালকে একসঙ্গে বদলায়, যাতে পুরো ডেস্কটপ অনুপাতে থাকে। আপনি কোথায় আছেন তা দেখতে কোনো আর্গুমেন্ট ছাড়া এটি চালান, এবং ডিফল্টে ফিরে যেতে `omarchy display text size reset` চালান। Foot হলো একমাত্র পিছিয়ে পড়া অ্যাপ: এর কনফিগ পুনরায় লোড করার কোনো উপায় নেই, তাই চলমান টার্মিনালগুলো নতুন একটি না খোলা পর্যন্ত তাদের পুরোনো আকারই ধরে রাখে।

### ল্যাপটপ ডিসপ্লে প্রসারিত করা এবং মিরর করা

আপনি যখন আপনার ল্যাপটপে একটি বাহ্যিক স্ক্রিন সংযোগ করেন, তখন ডিসপ্লেটি স্বয়ংক্রিয়ভাবে প্রসারিত হয়। কিন্তু Omarchy মেনুতে _ট্রিগার > হার্ডওয়্যার_ ব্যবহার করে অথবা `Super + Ctrl + Alt + Delete` দিয়ে আপনি সেটিকে বদলে মিররিং করে দিতে পারেন। সেই বাহ্যিক স্ক্রিনটি যদি একটি প্রজেক্টর হয় এবং আপনি কাজ করার সময় কিছু দেখাতে চান, তাহলে এটি বিশেষভাবে সহায়ক।

আপনি যখন প্রসারিত করছেন, তখন ল্যাপটপের ঢাকনা বন্ধ করলে অভ্যন্তরীণ স্ক্রিনটি স্বয়ংক্রিয়ভাবে বন্ধ হয়ে যাবে। ঢাকনা খুললে সেটি আবার চালু হবে। আপনি Omarchy মেনুতে _ট্রিগার > হার্ডওয়্যার_ ব্যবহার করে অথবা `Super + Ctrl + Delete` দিয়েও এটি ম্যানুয়ালি নিয়ন্ত্রণ করতে পারেন।

### একাধিক স্ক্রিন সাজানো

Hyprland একাধিক স্ক্রিন নিয়ে দারুণ কাজ করে। সেগুলোকে কীভাবে সাজাতে হয় সে সম্পর্কে [Hyprland মনিটর ডকুমেন্টেশনে](https://wiki.hypr.land/Configuring/Basics/Monitors/) আরও পড়ুন। Omarchy-তে, এগুলো `hl.monitor` এন্ট্রি হিসেবে `~/.config/hypr/monitors.lua`-তে থাকে — একটি নির্দিষ্ট মনিটরকে একটি রেজোলিউশন, অবস্থান এবং ঘূর্ণনে পিন করার জন্য ফাইলটি মন্তব্য করা উদাহরণসহ আসে।

প্রতিটি মনিটরের নিজস্ব 1 থেকে 10 পর্যন্ত ওয়ার্কস্পেস আছে, তাই `Super + 1` বলতে সবসময় আপনি যে মনিটরে আছেন তার প্রথম ওয়ার্কস্পেসকে বোঝায়। পর্দার আড়ালে, Hyprland এখনও সব মনিটর জুড়ে ওয়ার্কস্পেসগুলোকে নম্বর দেয়: আপনার ল্যাপটপের স্ক্রিন (বা প্রথম মনিটর) পায় 1–10, পরের মনিটর 11–20, এবং এভাবেই চলতে থাকে, এবং প্রতিটি মনিটর প্রতিবার প্লাগ ইন করার সময় তার ব্লকটি ধরে রাখে। আপনি যদি কোনো নির্দিষ্ট মনিটরের জন্য [ওয়ার্কস্পেস নিয়ম](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) বা উইন্ডো নিয়ম লেখেন তাহলে এই নম্বরগুলো ব্যবহার করুন, যাতে ওয়ার্কস্পেস 12 হয় আপনার দ্বিতীয় মনিটরের দ্বিতীয় ওয়ার্কস্পেস। `~/.local/state/omarchy/monitor-workspaces` তালিকাভুক্ত করে কোন মনিটরের কোন ব্লক আছে।

তীর কীগুলো এমন মনিটরগুলো জুড়ে কাজ করে যেগুলো আপনার লেআউটে একটি ধার ভাগ করে। যেসব স্ক্রিন শুধু একটি কোণায় ছোঁয়, অথবা যাদের মধ্যে ফাঁক আছে, তারা প্রতিবেশী নয়, তাই তাদের মধ্যে যেতে `Ctrl + Alt + Tab` ব্যবহার করুন।

| হটকি | মনিটর জুড়ে |
| --- | --- |
| `Super + Arrow` | সেই দিকে আর কোনো উইন্ডো অবশিষ্ট না থাকলে ফোকাস সেই দিকের মনিটরে সরায় |
| `Super + Shift + Arrow` | সেই দিকের মনিটরের একটি উইন্ডোর সঙ্গে অদলবদল করে |
| `Super + Alt + Arrow` | উইন্ডোটিকে সেই দিকের মনিটরের একটি গ্রুপে সরায় |
| `Super + Shift + Ctrl + Arrow` | উইন্ডোটিকে সেই দিকের মনিটরে, সেটি যে ওয়ার্কস্পেস দেখাচ্ছে তার উপরে সরায় |
| `Super + Shift + Alt + Arrow` | ওয়ার্কস্পেসটিকে সেই দিকের মনিটরে সরায়, খালি থাকলে তার নম্বর ধরে রেখে |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | লেআউট যাই হোক না কেন, ফোকাস পরের বা আগের মনিটরে সরায় |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | আপনি যে মনিটরে আছেন সেখানেই থাকে |

আপনি [Hyprmon](https://github.com/erans/hyprmon/)-ও দেখে নিতে পারেন, যদি একাধিক স্ক্রিনের অবস্থান নির্ধারণে সাহায্য করার জন্য একটি TUI চান।

### উজ্জ্বলতা নিয়ন্ত্রণ করা

মনিটরের উজ্জ্বলতা উজ্জ্বলতা বাড়ানো/কমানোর জন্য নির্ধারিত ফাংশন কী দিয়ে নিয়ন্ত্রিত হয়। আপনি যদি এগুলো চাপার সময় shift চেপে ধরে রাখেন, তাহলে সর্বোচ্চ বা সর্বনিম্ন উজ্জ্বলতায় চলে যাবেন। কীগুলো আপনি যে ডিসপ্লেতে ফোকাস করেছেন সেটিকে নিয়ন্ত্রণ করে, তাই DDC/CI বলতে পারে এমন বাহ্যিক মনিটরগুলো ল্যাপটপের স্ক্রিনের মতো একইভাবে সামঞ্জস্য করা হয়।

### Apple ডিসপ্লে

আপনি যদি একটি Apple ডিসপ্লে ব্যবহার করেন, তাহলে নিয়মিত কীবোর্ড উজ্জ্বলতা কীগুলোও স্বয়ংক্রিয়ভাবে কাজ করবে, যদি আপনি Apple ডিসপ্লেতে ফোকাস করে থাকেন। এটি `asdcontrol` কমান্ডের মাধ্যমে করা হয়।

মনে রাখবেন, আপনি যদি একটি Apple 6K XDR ডিসপ্লে ব্যবহার করেন, তাহলে আপনার `hyprctl monitors` তালিকায় একটি ভূতুড়ে স্ক্রিন দেখতে পারেন। আপনি _সেটআপ > মনিটর_ হয়ে `hl.monitor({ output = "DP-2", disabled = true })`-এর মতো কিছু দিয়ে এটি বন্ধ করতে পারেন।

Intel মেশিনে, আপনার একটি নিয়মিত Thunderbolt কেবল ব্যবহার করে Apple ডিসপ্লেতে সংযোগ করা উচিত। Thunderbolt ছাড়া অন্য মেশিনে, এটি কাজ করাতে আপনাকে সাধারণত একটি [DP + USB-A -> USB-C কেবল](https://www.amazon.com/dp/B0BNX7MS6N) ব্যবহার করতে হবে।
