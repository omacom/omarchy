# Mac বা Windows থেকে আসছেন

আপনি যদি macOS বা Windows-এ বছরের পর বছর কাটিয়ে থাকেন, তাহলে আপনার আঙুলগুলো এমন শত শত জিনিস জানে যা আপনার মস্তিষ্ক কখনো শিখেছিল বলেই ভুলে গেছে। এই অধ্যায়টি হলো সেই অনুবাদের স্তর: Omarchy-তে সেই সহজাত অভ্যাসগুলো কোথায় যাবে। বৈশিষ্ট্যগুলো নিজে অন্য জায়গায় গভীরভাবে আলোচনা করা হয়েছে — এটি কেবল মানচিত্র।

### Super হলো সবকিছুর কেন্দ্র

Cmd বা Windows কীকে ঘিরে আপনি যত পেশি-স্মৃতি গড়ে তুলেছেন, তার সবই একটিমাত্র কী-তে সরে আসে: Super। এটি একটি PC কীবোর্ডের Windows কী, আর এটি Omarchy-র প্রায় প্রতিটি হটকির নোঙর।

আপনার Spotlight বা Raycast বা Start মেনুর সেই সহজাত অভ্যাসটি হয়ে যায় `Super + Space`। এটি Omarchy মেনু খোলে, যা অ্যাপ চালু করে, সেটিংস বদলায়, সফটওয়্যার ইনস্টল করে, স্ক্রিন ক্যাপচার করে — মোটামুটি সবকিছুই। ফিল্টার করতে টাইপ করা শুরু করুন। `Super + Alt + Space` সব অ্যাপ একটিমাত্র গ্রিডে দেখায়, যেভাবে Launchpad করে। দেখুন [নেভিগেশন](04-navigation.md)।

### কোনো ডক নেই, ডেস্কটপ আইকনও নেই

কোনো কিছু চালু করার জন্য ক্লিক করার মতো কিছু নেই, ডেস্কটপে সাজানোর মতো কোনো আইকনও নেই। অ্যাপ চালু হয় একটি হটকি থেকে (`Super + Return` টার্মিনালের জন্য, `Super + Shift + Return` ব্রাউজারের জন্য, আর `Super + K` ম্যাপ করা সবকিছুর তালিকার জন্য) অথবা মেনু থেকে। UI-এর একমাত্র স্থায়ী অংশ হলো [উপরের বার](05-the-top-bar.md), যা আগে মেনু বার, সিস্টেম ট্রে আর Notification Center আপনার জন্য যা করত, তার সবই সামলায় — আর এতে থাকা প্রায় প্রতিটি উইজেটই বাম, ডান ও মাঝের ক্লিকে কিছু না কিছু করে।

### উইন্ডোগুলো নিজে নিজেই বসে যায়

সবচেয়ে বড় মানসিক বদল: আপনি উইন্ডো টেনে এখানে-সেখানে সরান না, কিংবা সেগুলোকে স্ক্রিনের অর্ধেকে স্ন্যাপ করেন না। একটি উইন্ডো খুলুন আর এটি পুরো স্ক্রিন দখল করে নেয়। দ্বিতীয়টি খুলুন আর সেগুলো স্ক্রিন ভাগ করে নেয়। আপনাকে কখনো অন্য একটির নিচ থেকে একটি উইন্ডো টেনে বের করতে হয় না, কারণ উইন্ডোগুলো একে অপরের উপর চাপে না।

যখন আপনার সত্যিই একটি ভাসমান উইন্ডো দরকার হয়, তখন `Super + T` সক্রিয় উইন্ডোটিকে টাইলিং থেকে বের করে আনে (এবং আবার ফিরিয়ে নেয়)। তবে আগে টাইলিংকে সত্যিকার সুযোগ দিন — এটাই পুরো বিষয়টার প্রাণ। [নেভিগেশন](04-navigation.md) আপনাকে এটি ধাপে ধাপে বুঝিয়ে দেবে।

ওয়ার্কস্পেসগুলো পরিচিত মনে হবে: এগুলো macOS Spaces বা Windows ভার্চুয়াল ডেস্কটপের মতো, তবে ব্যতিক্রম হলো আপনি সত্যিই এগুলো ব্যবহার করবেন, কারণ `Super + 1/2/3/4` সরাসরি একটিতে ঝাঁপ দেয় আর `Super + Shift + 1/2/3/4` সক্রিয় উইন্ডোটিকে সেখানে পাঠিয়ে দেয়। কোনো অ্যানিমেশন বিলম্ব নেই, শুধু তাৎক্ষণিক ঝাঁপ। এর মানে হলো, আগে যদি আপনার একাধিক মনিটরে অভ্যাস থেকে থাকে, তাহলে হয়তো আপনার আর সেগুলোর দরকারই হবে না।

### কপি আর পেস্ট ঠিকঠাক কাজ করে

Mac-এ আপনার সব জায়গায় ছিল Cmd + C। Windows-এ আপনার সব জায়গায় ছিল Ctrl + C — টার্মিনাল ছাড়া, যেখানে এটি আপনার প্রোগ্রাম বন্ধ করে দেয়। Omarchy আপনাকে দেয় `Super + C`, `Super + X` আর `Super + V`, আর এগুলো সব জায়গায় কাজ করে, টার্মিনালসহ। শেলের জন্য আলাদা কোনো সহজাত অভ্যাস শেখার দরকার নেই।

Windows-এর লোকজন: আপনার Win + V ক্লিপবোর্ড ইতিহাস থাকে `Super + Ctrl + V`-তে, আর এটি টেক্সটের পাশাপাশি ছবিও ধারণ করে। দেখুন [একীভূত ক্লিপবোর্ড ও ইতিহাস](08-unified-clipboard-history.md)।

| আপনি যা খোঁজেন | Omarchy-তে |

| Spotlight / Raycast / Start মেনু | `Super + Space` — Omarchy মেনু |

| Time Machine (সিস্টেমের জন্য) | প্রতিটি আপডেটে স্বয়ংক্রিয় [সিস্টেম স্ন্যাপশট](47-system-snapshots.md) |

| System Settings / Control Panel | মেনুতে _Setup_, যা সাধারণ কনফিগ ফাইল সম্পাদনা করে — দেখুন [ডটফাইল](31-dotfiles.md) |

### কিছু জিনিস সত্যিই আলাদা

অনেক সেটিংস থাকে টেক্সট ফাইলে, যেগুলো আপনি সম্পাদনা করেন, ক্লিক করে ঘুরে বেড়ানোর প্যানেলে নয়। এটি আদিম শোনায়, যতক্ষণ না আপনি বুঝতে পারেন এর মানে হলো প্রতিটি ছোটখাটো বদল দেখা যায়, আপনার পরের মেশিনে কপি করা যায়, আর সংস্করণ নিয়ন্ত্রণে রাখা যায়। _Setup_ মেনু আপনাকে সরাসরি সঠিক ফাইলে ফেলে দেয় আর আপনার কাজ শেষ হলে যা যা পুনরায় চালু করা দরকার, তা পুনরায় চালু করে দেয়।

আপডেট আসে একটি মাত্র কমান্ড দিয়ে — _Update > Omarchy_ — যা Omarchy নিজেকে আর সিস্টেমের প্রতিটি প্যাকেজ আপডেট করে, আগে একটি স্ন্যাপশট নিয়ে। এলোমেলো সময়ে আপনাকে বিরক্ত করার মতো প্রতি-অ্যাপ আপডেটার নেই। দেখুন [আপডেট](30-updates.md)।

সফটওয়্যার আসে একটি প্যাকেজ ম্যানেজার থেকে, ডাউনলোড করা ইনস্টলার থেকে নয়।

আর যখন আপনি একটি উইন্ডো বন্ধ করেন, অ্যাপটি সত্যিই বন্ধ হয়ে যায়। macOS-এর সেই অনিশ্চিত অবস্থা নেই, যেখানে কোনো উইন্ডো ছাড়াই প্রোগ্রাম চলতে থাকে। `Super + W` — অথবা `Super + Q`, যদি সেটাই আপনার সঙ্গে আসা আঙুলের স্মৃতি হয়ে থাকে — মানেই চলে গেছে।

### Mac হার্ডওয়্যারে

Omarchy Intel Mac-এ ভালোভাবে চলে — দেখুন [Mac সহায়তা](44-mac-support.md)। আর কীবোর্ড আপনার প্রতি সদয়: Omarchy কোনো কিছুই রিম্যাপ করে না, আর Linux Command কীকে Super হিসেবে বিবেচনা করে, তাই Super ঠিক সেখানেই বসে যেখানে Cmd সবসময় ছিল। আপনার বুড়ো আঙুল এই বদল টেরই পাবে না।

### একে দুই সপ্তাহ সময় দিন

সহজাত অভ্যাসগুলো আপনার ধারণার চেয়ে দ্রুত সরে আসে। [হটকি](07-hotkeys.md) অধ্যায়টি একবার চোখ বুলিয়ে নিন, আর যখনই কোনো বাইন্ডিং মনে করতে পারবেন না, `Super + K` চাপুন — এটি আপনাকে সবগুলো দেখিয়ে দেয়। এটাই একমাত্র হটকি যা আপনাকে সত্যিই মুখস্থ করতে হবে।
