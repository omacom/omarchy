# টগল, Idle ও স্ক্রিনসেভার

প্রতিদিন আপনি যা বদলান তার অনেকটাই আসলে কোনো সেটিং নয়। এটা এমন একটা মোড যা আপনি এক ঘণ্টার জন্য চালু করেন, আবার বন্ধ করে দেন: রাতে দেরি করে কাজ করার সময় নাইট লাইট, প্রেজেন্টেশন দেওয়ার সময় বিরক্ত করবেন না, কিছু দেখার সময় জেগে থাকা। Omarchy এগুলোকে টগল বলে, এবং সবগুলো একইভাবে কাজ করে — একটি হটকি, একটি মেনু এন্ট্রি এবং একটি কমান্ড, সবই একই সুইচে আঘাত করে।

### টগল মেনু

`Super + Ctrl + O` সরাসরি _Trigger > Toggle_ খোলে, অথবা আপনি Omarchy মেনু (`Super + Space`) থেকে সেখানে যেতে পারেন। ওই তালিকার সবকিছুই এমন একটা সুইচ যা আপনি state কোথায় থাকে তা না ভেবেই উল্টে দিতে পারেন। ডেস্কটপ দেখতে কেমন হবে তার সুইচগুলো এর পাশেই, _Appearance_-এর অধীনে আছে।

টার্মিনাল থেকে, একই সুইচগুলো হলো `omarchy toggle <thing>`। পুরো গ্রুপটি দেখতে শুধু `omarchy toggle` চালান।

| টগল | হটকি | কমান্ড |
| ------ | ------ | ------- |
| নাইট লাইট | — | `omarchy toggle nightlight` |
| নোটিফিকেশন নীরব করা | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| জেগে থাকা (কোনো idle lock নয়) | `Super + Ctrl + I` | `omarchy toggle idle` |
| ক্র্যাশ ক্যাপচার | — | `omarchy toggle crash-capture` |
| স্ক্রিনসেভার | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) থিম সিঙ্ক | — | `omarchy toggle theme sync` |
| মেনু বার | `Super + Shift + Space` | `omarchy toggle bar` |
| টাচপ্যাড | `XF86TouchpadToggle` | `omarchy device touchpad` |
| টাচস্ক্রিন | — | `omarchy device touchscreen` |
| সাসপেন্ড | — | `omarchy toggle suspend` |
| Hybrid GPU | — | `omarchy toggle hybrid gpu` |

টাচপ্যাড, টাচস্ক্রিন এবং Hybrid GPU সুইচগুলো Toggle-এর অধীনে না থেকে _Trigger > Hardware_ (`Super + Ctrl + H`)-এর অধীনে থাকে, কারণ সেগুলো শুধু তখনই দেখা যায় যখন আপনার কাছে সত্যিই ওই হার্ডওয়্যার থাকে। টাচপ্যাড ও টাচস্ক্রিনেরগুলো Hyprland রিলোডের পরেও টিকে থাকে — নিষ্ক্রিয় করা ডিভাইসের নাম একটি ছোট state ফাইলে সংরক্ষিত হয়, যা Hyprland স্টার্টআপে পড়ে সেটিকে আবার নিষ্ক্রিয় করে দেয়।

_Appearance_-এ আছে মেনু বার ও অ্যানিমেশন, আর সেইসঙ্গে এমন কয়েকটি জিনিস যা `omarchy toggle` কমান্ড নয় কিন্তু একইভাবে আচরণ করে: বারে ব্যাটারির শতাংশ, ডিফল্ট ওয়ার্কস্পেস লেআউট, এবং _Windows_-এর অধীনে, উইন্ডোর ফাঁক (`Super + Shift + Backspace`) এবং 1-উইন্ডো বর্গাকার অনুপাত (`Super + Ctrl + Backspace`)।

যখন Hyprland-এর আঁকার জন্য কোনো GPU থাকে না এবং তার বদলে CPU-তে রেন্ডার করে (llvmpipe), যেমন যেসব Mac-এর GPU এখনও সমর্থিত নয়, বেশিরভাগ ভার্চুয়াল মেশিনে, অথবা যখন কোনো গ্রাফিক্স ড্রাইভার লোড হতে ব্যর্থ হয়, তখন Omarchy ওই সেশনের জন্য অ্যানিমেশন, ব্লার ও ছায়া বন্ধ করে দেয় এবং একটি নোটিফিকেশন দিয়ে একবার আপনাকে তা জানিয়ে দেয়। _Appearance > Animations On_ সেগুলো ফিরিয়ে আনে, এবং Omarchy পরের সেশনগুলোর জন্যও তা মনে রাখে।

এগুলোর বেশিরভাগই শুধু `~/.local/state/omarchy/toggles/`-এর অধীনে থাকা একটি ফ্ল্যাগ ফাইল। আপনি যদি কোনো স্ক্রিপ্টে এর উপর ভিত্তি করে শাখা করতে চান, তাহলে `omarchy-toggle-enabled` আপনাকে খুঁজতে যাওয়ার বদলে একটি exit code দেয়:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

ফ্ল্যাগগুলোর নামকরণ করা হয়েছে বন্ধ অবস্থার জন্য — `screensaver-off`, `suspend-off`, `bar-off` — তাই তাদের উপস্থিতি মানে বৈশিষ্ট্যটি নিষ্ক্রিয় আছে।

### বারে ইন্ডিকেটর

যখন কোনো মোড চালু থাকে, তখন আপনি ঘড়ির পাশে শীর্ষ বারের মাঝখানে একটি ছোট গ্লিফ পান। সেটি হলো ইন্ডিকেটর উইজেট, এবং এতে থাকে ডিক্টেশন, স্ক্রিন রেকর্ডিং, অপেক্ষমাণ রিমাইন্ডার, নাইট লাইট, বিরক্ত করবেন না এবং জেগে থাকা।

নিষ্ক্রিয় ইন্ডিকেটরগুলো লুকানো থাকে। বারের যেকোনো জায়গায় হোভার করুন এবং সেগুলো ম্লান হয়ে ভেসে উঠবে, যাতে আপনি তার হটকি না জেনেই একটিতে ক্লিক করে তা চালু করতে পারেন। সক্রিয় একটিতে ক্লিক করলে তা আবার বন্ধ হয়ে যায়। আপনি যদি বরং সবসময় সেগুলোর সবকটিই দেখতে চান, তাহলে `~/.config/omarchy/shell.json`-এ `omarchy.indicators` এন্ট্রিতে `alwaysShow`-কে `true` সেট করুন — বার উইজেটগুলো কীভাবে কনফিগার করা হয় তা জানতে [শীর্ষ বার](05-the-top-bar.md) দেখুন।

### নাইট লাইট

নাইট লাইট স্ক্রিনকে 4000K-তে উষ্ণ করে, এবং আবার টগল করলে তা 6500K-তে ফিরিয়ে আনে। টগল মেনু (`Super + Ctrl + O`) থেকে অথবা `omarchy toggle nightlight` দিয়ে এটি উল্টে দিন। এটি hyprsunset দ্বারা চালিত হয়, যা ইতিমধ্যে চলমান না থাকলে টগল আপনার জন্য চালু করে দেয়।

ডিফল্টভাবে hyprsunset আপনার স্ক্রিনে একেবারেই কিছু করে না। `~/.config/hypr/hyprsunset.conf` একটি identity প্রোফাইলসহ আসে ঠিক এই কারণে যাতে আপনি উষ্ণতা না চাওয়া পর্যন্ত ডিসপ্লে অক্ষত থাকে। আপনি যদি বরং চান এটি ঘড়ি অনুযায়ী বদলাক, তাহলে তা একটি সময় প্রোফাইল দিয়ে প্রতিস্থাপন করুন:

```
profile {
    time = 20:00
    temperature = 4000
}
```

তারপর `~/.config/hypr/autostart.lua`-তে `o.launch_on_start("hyprsunset")` যোগ করে লগইনে hyprsunset চালু করুন। টগল দ্বারা ব্যবহৃত 4000K/6500K জোড়াটি স্থির, তাই আপনি ভিন্ন তাপমাত্রা চাইলে কনফিগ ফাইলই হলো যাওয়ার জায়গা।

### বিরক্ত করবেন না

`Super + Ctrl + Alt + ,` নোটিফিকেশন নীরব করে। এটি চালু থাকাকালীন কোনো টোস্ট পপ আপ হয় না, এবং ডেস্কটপ কেন নীরব হয়ে গেছে তা মনে করিয়ে দিতে বারে কাটা-দাগ দেওয়া ঘণ্টার ইন্ডিকেটর বসে থাকে।

তবে কিছুই হারিয়ে যায় না। নীরব করা নোটিফিকেশনগুলো আটকে রাখা হয়: `Super + Shift + Alt + ,` দিয়ে শেষ কয়েকটি আবার স্ক্রিনে ফিরিয়ে আনুন। বাকিটির জন্য [নোটিস](10-notices.md) দেখুন।

দুই ধরনের বার্তা এখনও পৌঁছে যায়: আপনি এইমাত্র যা করেছেন তার জন্য Omarchy-র নিজস্ব নিশ্চিতকরণ টোস্ট (“থিম পরিবর্তন হয়েছে”, “স্ক্রিনশট সংরক্ষিত হয়েছে”), এবং কমান্ড লাইন থেকে পাঠানো গুরুতর সতর্কতা। যেসব চ্যাট অ্যাপ সবকিছুকে গুরুতর হিসেবে চিহ্নিত করে আপনার সামনে জোর করে আসার চেষ্টা করে, সেগুলো যোগ্য নয়।

### Idle

Omarchy শেল idle আচরণের মালিক, এবং সময়গুলো হলো `~/.config/omarchy/shell.json`-এ থাকা একটি শীর্ষ-স্তরের `idle` ব্লক:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

দুটি সংখ্যাই হলো আপনি idle হয়ে যাওয়ার মুহূর্ত থেকে গণনা করা সেকেন্ড — একে অপরের থেকে নয়। তাই ডিফল্টগুলো দিয়ে, স্ক্রিনসেভার আড়াই মিনিট পর আসে এবং স্ক্রিনসেভার চলুক বা না চলুক, পাঁচ মিনিটে লক স্ক্রিন দায়িত্ব নেয়। ফাইলটি সংরক্ষণ করুন এবং শেল সঙ্গে সঙ্গে নতুন সময়গুলো গ্রহণ করে।

আপনি যদি লকের সময়সীমার আগে স্ক্রিনসেভার খারিজ করেন, তা কার্যকলাপ হিসেবে গণ্য হয় এবং অপেক্ষমাণ লক বাতিল হয়ে যায়। আপনার মেশিনের দিকে এক ঝলক তাকানোর জন্য আপনি লক আউট হন না।

idle অবস্থায় লক করা সম্পূর্ণ বন্ধ করতে, `Super + Ctrl + I` — অথবা `omarchy toggle idle` — জেগে থাকা চালু করে, এবং বারে কফি কাপের ইন্ডিকেটর দেখা যায়। দীর্ঘ প্রেজেন্টেশন অথবা আপনি দেখতে চান এমন কোনো বিল্ডের আগে এটিই চাপ দেওয়ার মতো। স্বাভাবিক অবস্থায় ফিরতে আবার চাপ দিন। আপনার যদি কোনো স্ক্রিপ্ট থেকে এটি দরকার হয়, তাহলে `omarchy toggle idle status` বর্তমান state JSON হিসেবে প্রিন্ট করে।

এটি লক করা ও স্ক্রিনসেভার সম্পর্কে, বিদ্যুৎ সম্পর্কে নয়। সাসপেন্ড ও হাইবারনেশনের নিজস্ব সেটআপ আছে [সিস্টেম স্লিপ](36-system-sleep.md)-এ।

### স্ক্রিনসেভার

Omarchy-র স্ক্রিনসেভার হলো এলোমেলো টেক্সট ইফেক্টের মধ্য দিয়ে চলা ASCII আর্ট, প্রতি মনিটরে একটি করে ইনস্ট্যান্স। যেকোনো কী বা মাউসের নড়াচড়া এটি থেকে বের করে দেয়।

আপনি _System > Screensaver_ (`Super + Esc`) থেকে চাহিদা অনুযায়ী এটি চালু করতে পারেন, যা আপনি idle স্ক্রিনসেভার বন্ধ করে রাখলেও জোর করে তা তুলে আনে। ডিফল্টভাবে এর সঙ্গে কোনো হটকি বাঁধা নেই।

আপনি যদি বরং কাজ করা থেকে সরাসরি লক অবস্থায় যেতে চান, তাহলে `omarchy toggle screensaver` হলো যা idle-এরটিকে বন্ধ করে। যেকোনো কী, ক্লিক, স্ক্রল অথবা মাউসের নড়াচড়া এটি বন্ধ করে দেয়।

এটি যে লোগো আঁকে তা বদলানো আপনার হাতে, _Appearance > Branding > Screensaver_-এর অধীনে। একটি png বা svg আপলোড করুন এবং Omarchy সেটিকে ASCII-তে রূপান্তর করে। [ব্র্যান্ডিং](41-branding.md) দেখুন।

### লক স্ক্রিন

`Super + Ctrl + L` মেশিন লক করে। তা Omarchy শেল থেকে লক স্ক্রিন চালায়, ডিসপ্লে ফাঁকা করে, আপনার কীবোর্ড লেআউট প্রথমটিতে রিসেট করে যাতে আপনি ভুল বর্ণমালায় আপনার পাসওয়ার্ড টাইপ না করেন, এবং — আপনি যদি তা চালিয়ে থাকেন — বের হওয়ার পথে 1Password লক করে দেয়।

লক স্ক্রিন একটি পাসওয়ার্ড নেয়, এবং আপনি একবার সেট আপ করলে এটি একটি আঙুলের ছাপও নেবে। তা, এবং প্রমাণীকরণের অন্যান্য উপায়, [হার্ডওয়্যার প্রমাণীকরণ](37-hardware-authentication.md)-এ আলোচনা করা হয়েছে।
