# একীভূত ক্লিপবোর্ড ও ইতিহাস

সাধারণত Linux-এ, টার্মিনালে কপি-পেস্ট করতে আপনাকে `Ctrl + Shift + C/V` ব্যবহার করতে হয় এবং অন্য সব জায়গায় করতে হয় `Ctrl + C/V`। যারা Linux-এ জন্মে আর বেড়ে ওঠেননি, তাদের কারও জন্য এতে অভ্যস্ত হওয়া কঠিন! Mac থেকে এলে super থেকে ctrl-এ বদলে যাওয়াটাও তেমনই কঠিন।

Omarchy দুটি সমস্যারই মোকাবিলা করে একীভূত ক্লিপবোর্ড হটকি দিয়ে, যা (প্রায়) সব জায়গায় কাজ করে। সেগুলো হলো:

| হটকি | কমান্ড |
| ------- | ----------- |
| Super + A | সব নির্বাচন করুন |
| Super + C | কপি |
| Super + X | কাট |
| Super + V | পেস্ট |
| Super + Ctrl + V | ক্লিপবোর্ড ইতিহাস |

_খেয়াল করুন, বেশিরভাগ এজেন্ট হার্নেস ছবি পেস্ট করার জন্য `Ctrl + V` ব্যবহার করবে, কিন্তু লেখা পেস্ট করার জন্য ব্যবহার করবে `Super + V`।_

ফোকাস করা কোনো টেক্সট ফিল্ডে বা `Ctrl + A` সমর্থন করে এমন অন্য কোনো অ্যাপে সবকিছু কপি করতে `Super + A`, তারপর `Super + C` ব্যবহার করুন। টার্মিনালে, `Ctrl + A` লেখা নির্বাচন করার বদলে কমান্ড লাইনের শুরুতে চলে যায়।

### ক্লিপবোর্ড ইতিহাস

ক্লিপবোর্ড ইতিহাস Omarchy শেল সরবরাহ করে এবং এটি লেখা ও ছবি দুটোর জন্যই কাজ করে। আপনি `Super + Ctrl + V` দিয়ে এটি চালু করেন এবং return দিয়ে আপনার এন্ট্রি নির্বাচন করেন, যা সেটিকে সরাসরি আপনি যে অ্যাপে ছিলেন সেখানে পেস্ট করে দেয়। শুধু ক্লিপবোর্ডে কপি করতে `Shift + Return`, সেটি খুলতে `Alt + Return`, ইতিহাস থেকে তা সরাতে `Delete` এবং পুরো ইতিহাস মুছে ফেলতে `Shift + Delete` ব্যবহার করুন।
