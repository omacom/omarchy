# একীভূত ক্লিপবোর্ড ও ইতিহাস

সাধারণত Linux-এ টার্মিনালে কপি-পেস্ট করতে `Ctrl + Shift + C/V` এবং অন্য সব জায়গায় তা করতে `Ctrl + C/V` লাগে। Linux-এ জন্মে বড় হননি এমন কারো জন্য এতে অভ্যস্ত হওয়া কঠিন! Mac থেকে এলে super থেকে ctrl-এ যাওয়ার পরিবর্তনটাও তা-ই।

Omarchy একীভূত ক্লিপবোর্ড হটকি দিয়ে দুটো সমস্যারই সমাধান করে, যা (প্রায়) সব জায়গায় কাজ করে। সেগুলো হলো:

| হটকি | কমান্ড |
| ------- | ----------- |
| Super + C | কপি |
| Super + X | কাট |
| Super + V | পেস্ট |
| Super + Ctrl + V | ক্লিপবোর্ড ইতিহাস |

_খেয়াল রাখবেন, বেশিরভাগ এজেন্ট হারনেস ছবি পেস্ট করতে `Ctrl + V` ব্যবহার করবে, কিন্তু টেক্সট পেস্ট করতে `Super + V` ব্যবহার করবে।_

### ক্লিপবোর্ড ইতিহাস

ক্লিপবোর্ড ইতিহাস Omarchy শেল প্রদান করে এবং এটি টেক্সট ও ছবি দুটোর জন্যই কাজ করে। আপনি `Super + Ctrl + V` দিয়ে এটি চালু করেন, return দিয়ে আপনার এন্ট্রি বেছে নেন, এবং তারপর সেটি ক্লিপবোর্ডে রাখা হবে, `Super + V` দিয়ে পেস্ট করার জন্য প্রস্তুত।
