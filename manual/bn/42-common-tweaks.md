# সাধারণ টুইক

এটি Omarchy সেটআপে করা সাধারণ নিজের মতো সাজিয়ে নেওয়ার একটি সংগ্রহ। জেনে রাখুন, সিস্টেম আপডেটের জন্য মাঝে মাঝে নির্দিষ্ট কিছু কনফিগকে তাদের আসল অবস্থায় ফিরিয়ে আনার প্রয়োজন হতে পারে। এমনটা হলে আপনার পরিবর্তনগুলো হারিয়ে যাবে না, বরং আসল ফাইলের পাশে একটি `.bak.<timestamp>` ফাইলে রাখা হবে।

আপনি যদি কিছু গড়বড় করে ফেলেন, তাহলে Omarchy মেনুতে _Update > Config_ দিয়ে পৃথক পৃথক কনফিগকে তাদের আসল সেটআপে ফিরিয়ে নিতে পারবেন। আপনি যদি _সত্যিই_ সবকিছু গড়বড় করে ফেলেন, তাহলে `omarchy reinstall configs` দিয়ে সব কনফিগ রিসেট করতে পারবেন, অথবা `omarchy reinstall` দিয়ে প্রতিটি ডিফল্ট প্যাকেজ ও কনফিগ আবার ইনস্টল করতে পারবেন।

### সব সময় সব ট্রে আইকন দেখান

ডিফল্টভাবে, Dropbox, 1password বা Steam-এর মতো ট্রে আইকনগুলো ট্রে এক্সপ্যান্ডার তীরের পেছনে লুকানো থাকে, যা তার উপর হোভার করলে সেগুলো দেখায়। আপনি যদি সেগুলোকে সব সময় প্রকাশিত রাখতে চান, তাহলে ট্রে আইকন ম্যানেজার খুলতে এক্সপ্যান্ডার তীরে রাইট-ক্লিক করুন, তারপর যেসব আইকন দৃশ্যমান রাখতে চান সেগুলো পিন করুন (যেগুলো আপনি কখনোই দেখতে চান না, সেগুলো লুকিয়েও রাখতে পারবেন)।

### গোলাকার উইন্ডো কোণ

Omarchy-র ডিফল্ট ডিজাইন হলো চৌকো কোণ, কিন্তু আপনি যদি সেটিকে একটু নরম করতে চান, তাহলে Omarchy মেনুতে _Appearance > Windows > Window Corners > Rounded Corners_ বেছে নিন, অথবা `omarchy hyprland corners rounded` চালান। _Theme Corners_ থিম যা ব্যবহার করে সেখানেই ফিরে যায়। নিজের পছন্দমতো ব্যাসার্ধ বেছে নিতে, _Theme Corners_-এই থাকুন (`omarchy hyprland corners theme`), কারণ Rounded এবং Sharp আপনার কনফিগের পরে লোড হয় এবং সেটিকে ওভাররাইড করে, এবং `~/.config/hypr/looknfeel.lua`-তে rounding-এর কমেন্ট তুলে দিন:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### উইন্ডোর ফাঁক সরান

ল্যাপটপ ডিসপ্লেতে, কেউ কেউ উইন্ডোর ফাঁকে একটি পিক্সেলও নষ্ট করতে পছন্দ করেন না (এমনকি টপ বারেও না, যা আপনি `Super + Shift + Space` দিয়ে বন্ধ করতে পারবেন)। আপনি `Super + Shift + Backspace` দিয়ে সব ফাঁক ও বর্ডার বন্ধ করতে পারবেন, অথবা `~/.config/hypr/looknfeel.lua`-র এই অংশের কমেন্টগুলো সরিয়ে দিয়ে সেগুলো স্থায়ীভাবে সরিয়ে দিতে পারবেন:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
