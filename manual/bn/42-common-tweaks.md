# সাধারণ টুইক

এটি Omarchy সেটআপের সাধারণ কাস্টমাইজেশনের একটি সংগ্রহ। জেনে রাখুন সিস্টেম আপডেটের জন্য মাঝে মাঝে নির্দিষ্ট কনফিগগুলো তাদের আসল অবস্থায় ফিরিয়ে আনা দরকার হতে পারে। এমন হলে, আপনার পরিবর্তন হারাবে না, কিন্তু একই ডিরেক্টরিতে একটি `.bak` ফাইলে রাখা হবে।

কিছু গড়বড় করে ফেললে, Omarchy মেনুতে _আপডেট > Config_ দিয়ে পৃথক কনফিগ তাদের আসল সেটআপে ফিরিয়ে আনতে পারেন। _সত্যিই_ সবকিছু গড়বড় করে ফেললে, `omarchy-reinstall` দিয়ে সব কনফিগ রিসেট করতে পারেন।

### সব সময় সব ট্রে আইকন প্রকাশ করা

ডিফল্টভাবে, Dropbox, 1password বা Steam-এর মতো ট্রে আইকন ট্রে এক্সপ্যান্ডার তীরের পেছনে লুকানো থাকে, যা হোভার করলে সেগুলো প্রকাশ করে। সেগুলো সব সময় প্রকাশিত রাখতে চাইলে, ট্রে আইকন ম্যানেজার খুলতে এক্সপ্যান্ডার তীরে ডান-ক্লিক করুন, তারপর যে আইকনগুলো দৃশ্যমান রাখতে চান সেগুলো পিন করুন (যেগুলো কখনো দেখতে চান না সেগুলোও লুকাতে পারেন)।

### গোলাকার উইন্ডো কোণ

Omarchy-র ডিফল্ট ডিজাইন বর্গাকার কোণের, কিন্তু তা কিছুটা নরম করতে চাইলে, `~/.config/hypr/looknfeel.lua` বদলাতে পারেন যাতে rounding আর কমেন্ট করা না থাকে:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### উইন্ডোর ফাঁক সরানো

ল্যাপটপ ডিসপ্লেতে, কিছু লোক উইন্ডোর ফাঁকে কোনো পিক্সেল নষ্ট না করতে পছন্দ করেন (অথবা এমনকি উপরের বারও নয়, যা `Super + Shift + Space` দিয়ে টগল বন্ধ করতে পারেন)। `Super + Shift + Backspace` দিয়ে সব ফাঁক ও বর্ডার টগল বন্ধ করতে পারেন, অথবা `~/.config/hypr/looknfeel.lua`-র এই অংশে কমেন্ট সরিয়ে স্থায়ীভাবে সরাতে পারেন:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
