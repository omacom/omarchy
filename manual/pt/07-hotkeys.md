# Atalhos

Podes ver todos os principais atalhos de teclado com `Super + K` (os atalhos do Tmux com `Super + Alt + K` e os do Herdr com `Super + Ctrl + K`).

## Navegação

| Atalho                  | Função              |
| ----------------------- | --------------------- |
| `Super + Space`           | Menu do Omarchy (aplicações e tudo o resto)    |
| `Super + Alt + Space` | Grelha de aplicações |
| `Super + Escape` | Menu do sistema (suspender, reiniciar, etc.)  |
| `Super + Ctrl + L` | Bloquear computador |
| `Super + W` ou `Super + Q` | Fechar janela             |
| `Ctrl + Alt + Del` | Fechar todas as janelas |
| `Super + T`               | Alternar janela entre mosaico/flutuante             |
| `Super + J` | Alternar posição da janela (horizontal/vertical) |
| `Super + O`               | Alternar janela solta em fixa e flutuante |
| `Super + L`               | Percorrer as disposições dwindle, deslizante e flutuante |
| `Super + Alt + L`         | Percorrer as disposições no sentido inverso |
| `Super + P`               | Alternar estilo de janela pseudo (natural vs. esticada) |
| `Super + F`                 | Ir para ecrã inteiro              |
| `Super + Alt + F`                 | Ir para largura total              |
| `Super + Ctrl + F`                 | Ir para ecrã inteiro dentro da janela              |
| `Super + 1/2/3/4`         | Saltar para um espaço de trabalho específico     |
| `Super + Tab` | Saltar para o espaço de trabalho seguinte |
| `Super + Shift + Tab` | Saltar para o espaço de trabalho anterior |
| `Super + Ctrl + Tab` | Saltar para o espaço de trabalho anterior a este |
| `Super + Shift + 1/2/3/4` | Mover janela para o espaço de trabalho |
| `Super + Shift + Alt + 1/2/3/4` | Mover janela para o espaço de trabalho sem a seguir |
| `Super + S` / `Super + Grave` | Alternar scratchpad |
| `Super + Alt + S` / `Super + Shift + Grave` | Mover janela para o scratchpad |
| `Super + Shift + Alt + Arrows` | Mover espaços de trabalho para o monitor direcional |
| `Super + Arrow`  | Mover o foco para a janela na direção da seta              |
| `Super + Shift + Arrow`  | Trocar janela com outra na direção da seta     |
| `Super + Minus` | Expandir janela para a esquerda |
| `Super + Equal` | Encolher janela para a esquerda |
| `Super + Shift + Minus` | Encolher janela para cima |
| `Super + Shift + Equal` | Expandir janela para baixo |
| `Super + Alt + Minus/Equal` | O mesmo redimensionamento em passos mais pequenos |
| `Super + Ctrl + Minus/Equal` | O mesmo redimensionamento em passos maiores |
| `Super + Alt + Home` | Guardar largura da janela |
| `Super + Home` | Restaurar largura de janela guardada |
| `Super + Left Mouse` | Arrastar janela |
| `Super + Right Mouse` | Redimensionar janela |
| `Super + Scroll Wheel` | Deslizar pelos espaços de trabalho |
| `Super + G`               | Alternar agrupamento de janelas      |
| `Super + Alt + G`               | Mover janela para fora do agrupamento      |
| `Super + Alt + Tab`               | Percorrer janelas dentro do agrupamento      |
| `Super + Alt + Shift + Tab`               | Percorrer para trás janelas dentro do agrupamento      |
| `Super + Alt + 1/2/3/4/5`               | Saltar para janela específica no agrupamento      |
| `Super + Alt + Arrow`  | Mover janela para dentro do agrupamento na direção da seta  |
| `Super + Ctrl + Left/Right`  | Mover entre janelas dentro de um grupo em mosaico |
| `Super + Ctrl + Z` | Ampliar no ecrã (repetir para ampliar mais) |
| `Super + Ctrl + Alt + Z` | Afastar totalmente do ecrã |
| `Super + /` | Avançar pelas opções de escala do monitor |
| `Super + Alt + /` | Recuar pelas opções de escala do monitor |
| `Alt + Tab` | Percorrer para a frente as janelas no espaço de trabalho ativo |
| `Alt + Shift + Tab` | Percorrer para trás as janelas no espaço de trabalho ativo |
| `Ctrl + Alt + Tab`| Percorrer para a frente o foco pelos monitores |
| `Ctrl + Alt + Shift + Tab`| Percorrer para trás o foco pelos monitores |

## Área de transferência universal

| Atalho                  | Função              |
| ----------------------- | --------------------- |
| `Super + C`           | Copiar    |
| `Super + X`           | Cortar (não no terminal)    |
| `Super + V`           | Colar    |
| `Super + Ctrl + V`           | Gestor da área de transferência    |

Normalmente, no Linux, precisas de `Ctrl + Shift + C/V` para copiar e colar no terminal e de `Ctrl + C/V` para fazeres isso em todo o resto. Estes atalhos de área de transferência unificados do Omarchy funcionam em todo o lado.

## Capturar

| Atalho              | Função                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Menu de captura (para teclados sem botão PrintScr) |
| `Print Screen`            | Captura de ecrã                      |
| `Alt + Print Screen`            | Gravação de ecrã                     |
| `Super + Print Screen` | Seletor de cores |
| `Super + Ctrl + Print Screen` | Extração de texto para a área de transferência |
| `Super + Alt + [` | Tornar a sobreposição da webcam mais pequena enquanto gravas |
| `Super + Alt + ]` | Tornar a sobreposição da webcam maior enquanto gravas |
| `Alt + Shift + L` | Copiar o URL atual de uma aplicação web ou do Chromium |
| `Alt + Shift + D` | Transferir o vídeo da página atual para `~/Videos` |
| `Super + Ctrl + X` | Iniciar/parar ditado (exige _Configurar > Predefinições > Ditado_) |
| `Right Alt` / `F9` | Ditado push-to-talk (exige Voxtype ou Superwhisper) |

Nas gravações de ecrã, o atalho pergunta primeiro que áudio queres e depois inicia a gravação. Prime-o outra vez para parar. Vê [capturas de ecrã e gravação](12-screenshots-recording.md) para os detalhes.

Todas as opções de captura também estão acessíveis em _Acionar > Capturar_ no menu do Omarchy (`Super + Space`).

## Tmux

A tecla de prefixo é `Ctrl + Space` (`Ctrl + B` também funciona). Podes alterar estas associações em `~/.config/tmux/tmux.conf`.

### Painéis

| Atalho                  | Função              |
| ----------------------- | --------------------- |
| `Prefix + v` | Dividir painel ao lado (vertical) |
| `Prefix + h` | Dividir painel em baixo (horizontal) |
| `Prefix + x` | Matar painel |
| `Prefix + z` | Alternar zoom do painel (ecrã inteiro) |
| `Alt + Enter` | Dividir painel em baixo (sem prefixo) |
| `Alt + Shift + Enter` | Dividir painel ao lado (sem prefixo) |
| `Alt + Escape` | Matar painel (sem prefixo) |
| `Ctrl + Alt + Arrows` | Mover entre painéis |
| `Ctrl + Alt + Shift + Arrows` | Redimensionar painéis |

### Janelas

| Atalho                  | Função              |
| ----------------------- | --------------------- |
| `Prefix + c` | Nova janela |
| `Prefix + k` | Matar janela |
| `Prefix + r` | Mudar o nome da janela |
| `Alt + 1-9` | Ir para uma janela específica |
| `Alt + Arrow Left/Right` | Mover entre janelas |
| `Alt + Shift + Arrow Left/Right` | Mover janela para a esquerda/direita |

### Sessões

| Atalho                  | Função              |
| ----------------------- | --------------------- |
| `Prefix + C` | Nova sessão |
| `Prefix + K` | Matar sessão |
| `Prefix + R` | Mudar o nome da sessão |
| `Prefix + N` | Sessão seguinte |
| `Prefix + P` | Sessão anterior |
| `Alt + Arrow Up/Down` | Mover entre sessões |
| `Prefix + s` | Listar sessões |
| `Prefix + d` | Desanexar da sessão |

### Modo de cópia (ao estilo vi)

| Atalho                  | Função              |
| ----------------------- | --------------------- |
| `Prefix + [` | Entrar no modo de cópia |
| `v` | Iniciar seleção (no modo de cópia) |
| `y` | Copiar seleção (no modo de cópia) |

### Geral

| Atalho                  | Função              |
| ----------------------- | --------------------- |
| `Prefix + q` | Recarregar configuração |
| `Prefix + ?` | Mostrar atalhos do Tmux |
| `Prefix + :` | Linha de comandos |

### Funções de disposição do Tmux

Estas funções têm de ser executadas dentro de uma sessão do Tmux.

| Comando | Função |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Criar disposição de desenvolvimento com editor, IA e terminal |
| `tdlm <ai> [<second_ai>]` | Criar disposição de desenvolvimento por subdiretório |
| `tsl <count> <command>` | Criar disposição enxame com vários painéis |
