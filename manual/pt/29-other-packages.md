# Outros pacotes

O Arch tem uma riqueza espantosa de pacotes disponíveis para quase todo o tipo de software, entre o repositório oficial e o Arch User Repository (AUR).

Além disso, não podia ser mais fácil de usar. Instalas um novo pacote Arch indo a _Instalar > Pacote_ no menu Omarchy (`Super + Space`) e escrevendo o pacote que queres. Ele filtra automaticamente, de forma difusa, a lista de todos os pacotes. (Também o podes fazer manualmente usando `omarchy pkg add [package]` no terminal).

Podes fazer o mesmo com o AUR, basta usares _Instalar > AUR_. Lembra-te apenas de que o AUR não é avaliado pela equipa do Arch. É como o RubyGems ou o npm. Qualquer pessoa pode fazer carregamentos.

Se quiseres remover um pacote, podes usar _Remover > Pacote_ no menu Omarchy. Ele remove o pacote, os ficheiros de configuração e as dependências. (Também o podes fazer manualmente usando `omarchy pkg drop [package]`).
