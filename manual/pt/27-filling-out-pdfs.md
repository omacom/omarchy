# Preencher PDF

O Omarchy vem com um visualizador de PDF simples e agradável chamado Document Viewer. É este o programa que abre todos os PDF em que simplesmente fazes duplo clique.

Mas só podes usar o Document Viewer para preencher PDF que tenham sido configurados como formulários. Se precisares de preencher PDF que não o tenham sido, ou se precisares de assinar um PDF, usa o [Signed](https://github.com/omacom/signed). Inicia-o através do lançador de aplicações (`Super + Space`), ou clica com o botão direito no ficheiro, seleciona _Abrir Com..._ e escolhe o Signed.

Carrega em `T` para escreveres texto e em `D` para colocares a data de hoje. Ambos vão parar onde está o ponteiro do rato. Arrasta qualquer coisa para a moveres, arrasta o seu canto para a tornares maior ou menor e faz duplo clique no texto para o alterares.

Para assinares, vais precisar de uma imagem da tua assinatura: uma digitalização, ou uma fotografia bem iluminada dela em papel branco. Abre o menu _Assinatura_ (`Shift + S`), escolhe _Adicionar assinatura..._, escolhe a imagem e dá-lhe um nome. O Signed remove o papel e mantém a tinta. A partir daí, `S` coloca a tua assinatura sob o ponteiro do rato.

Quando terminares, usa _Guardar cópia assinada..._ (`Ctrl + S`) para guardares o PDF preenchido ao lado do original, que nunca é alterado. Carrega em `?` dentro do Signed para veres todos os atalhos.
