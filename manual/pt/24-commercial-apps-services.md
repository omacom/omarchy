# Aplicações/serviços comerciais

O Omarchy está sobretudo focado em fornecer software gratuito e open source, mas não é religioso quanto a isso. Às vezes, a melhor solução é uma oferta comercial, e isso não tem mal nenhum. Eis algumas das opções para as quais fornecemos uma instalação fácil.

## 1Password

Guardar as tuas palavras-passe num gestor de palavras-passe é uma boa prática. Em especial se estiveres a trabalhar com uma equipa. E o [1Password](https://1password.com/) é uma ótima solução, que também traz uma ferramenta de linha de comandos para integrar pesquisas de chaves em scripts.

Inicias o 1Password com `Super + Shift + /`. Se ainda não estiver instalado, esse atalho inicia primeiro a instalação (também podes usar _Instalar > Serviço > 1Password_ no menu Omarchy). O instalador também configura a extensão do 1Password para o Chromium.

## Bitwarden

O [Bitwarden](https://bitwarden.com/) é a alternativa open source no espaço dos gestores de palavras-passe, com um nível gratuito que cobre a maior parte da utilização pessoal. Instala-o com _Instalar > Serviço > Bitwarden_ no menu Omarchy, o que traz também a ferramenta de linha de comandos do Bitwarden.

## Spotify

O [Spotify](https://spotify.com/) é o serviço de streaming de música mais popular do mundo. E a aplicação para Linux oferece tudo o que esperarias, incluindo reprodução offline.

Inicias o Spotify com `Super + Shift + M`. Tal como o 1Password, o atalho inicia primeiro a instalação se o Spotify ainda não estiver instalado (ou usa _Instalar > Serviço > Spotify_ no menu Omarchy).

## Slack

O [Slack](https://slack.com/) é onde muitas equipas conversam, tanto dentro da empresa como com colaboradores externos. Instala-o com _Instalar > Serviço > Slack_ no menu Omarchy, e ele abre assim que estiver pronto.

## Dropbox

O [Dropbox](https://www.dropbox.com/) é uma ótima forma de sincronizar ficheiros entre máquinas, mantendo uma cópia de segurança na nuvem. Para o configurares, seleciona _Instalar > Serviço > Dropbox_ no menu Omarchy. Depois de estar a correr, passa o rato sobre a bandeja no canto superior direito da barra e clica com o botão direito no ícone do Dropbox para concluíres a configuração.

## Tailscale

O [Tailscale](https://tailscale.com/) é uma VPN em malha que torna extremamente simples acederes, em segurança, a todos os teus computadores e servidores através da Internet. Para o configurares, seleciona _Instalar > Serviço > Tailscale_ no menu Omarchy.

Recebe um painel na barra, uma aplicação web para a consola de administração e o Taildrop para enviar ficheiros entre as tuas máquinas — vê [rede](35-networking.md).

## ONCE

O [ONCE](https://once.com/) é a linha de software da 37signals que compras uma vez e executas no teu próprio servidor, como o sistema de chat Campfire. Seleciona _Instalar > Serviço > ONCE_ no menu Omarchy para o instalares, o que ativa o seu serviço em segundo plano e te coloca na interface de terminal do ONCE para continuares a partir daí.

## NordVPN

O [NordVPN](https://nordvpn.com/) é um serviço VPN normal que te permite fazer sair o teu tráfego da maioria das regiões do mundo. Para o configurares, seleciona _Instalar > Serviço > NordVPN_ no menu Omarchy. Depois do reinício que ele pede, executa `nordvpn login` para te autenticares.
