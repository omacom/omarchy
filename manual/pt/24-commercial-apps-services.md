# Aplicações/serviços comerciais

O Omarchy está sobretudo focado em fornecer software livre e de código aberto, mas não é religioso quanto a isso. Às vezes, a melhor solução é uma oferta comercial, e está tudo bem. Aqui estão algumas das opções para as quais fornecemos uma instalação fácil.

## 1Password

Guardar as tuas palavras-passe num gestor de palavras-passe é uma boa prática. Ainda mais se estiveres a trabalhar com uma equipa. E o [1password](https://1password.com/) é uma excelente solução, que também inclui uma ferramenta de linha de comandos para integrar consultas de chaves em scripts.

Inicias o 1Password com `Super + Shift + /`. Se ainda não estiver instalado, esse atalho inicia primeiro a instalação (também podes usar _Install > Service > 1Password_ a partir do menu do Omarchy). O instalador configura também a extensão do 1Password para o Chromium.

## Bitwarden

O [Bitwarden](https://bitwarden.com/) é a alternativa de código aberto no espaço dos gestores de palavras-passe, com um nível gratuito que cobre a maior parte da utilização pessoal. Instala-o com _Install > Service > Bitwarden_ a partir do menu do Omarchy, o que também traz a ferramenta de linha de comandos do Bitwarden.

## Spotify

O [Spotify](https://spotify.com/) é o serviço de streaming de música mais popular do mundo. O Omarchy fornece-o como uma aplicação web, que te dá o leitor completo, as teclas multimédia e o Spotify Connect, mas não transferências offline. Inicia-o com `Super + Shift + M`.

## Slack

O [Slack](https://slack.com/) é onde muitas equipas conversam, tanto dentro da empresa como com colaboradores externos. Instala-o com _Install > Service > Slack_ a partir do menu do Omarchy, e ele abre assim que estiver pronto.

## Dropbox

O [Dropbox](https://www.dropbox.com/) é uma excelente forma de sincronizar ficheiros entre máquinas, mantendo ao mesmo tempo uma cópia de segurança na nuvem. Para o configurares, seleciona _Install > Service > Dropbox_ a partir do menu do Omarchy. Assim que estiver a correr, passa o cursor sobre a bandeja no canto superior direito da barra e clica com o botão direito no ícone do Dropbox para concluíres a configuração.

## Tailscale

O [Tailscale](https://tailscale.com/) é uma VPN em mesh que torna super simples acederes de forma segura a todos os teus computadores e servidores através da internet. Para o configurares, seleciona _Install > Service > Tailscale_ a partir do menu do Omarchy.

Recebe um painel na barra, uma aplicação web para a consola de administração e o Taildrop para enviar ficheiros entre as tuas máquinas — vê [rede](35-networking.md).

## ONCE

O [ONCE](https://once.com/) é a linha de software da 37signals que compras uma vez e executas no teu próprio servidor, como o sistema de chat Campfire. Seleciona _Install > Service > ONCE_ a partir do menu do Omarchy para o instalares, o que ativa o respetivo serviço em segundo plano e te coloca na interface de terminal do ONCE para continuares a partir daí.

## NordVPN

O [NordVPN](https://nordvpn.com/) é um serviço VPN standard que te permite fazer sair o teu tráfego a partir da maioria das regiões do mundo. Para o configurares, seleciona _Install > Service > NordVPN_ a partir do menu do Omarchy. Após o reinício que ele pede, executa `nordvpn login` para te autenticares.
