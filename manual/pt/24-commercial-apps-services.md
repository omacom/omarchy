# Aplicações/serviços comerciais

O Omarchy está sobretudo focado em fornecer software gratuito e de código aberto, mas não é religioso quanto a isso. Por vezes, a melhor solução é uma oferta comercial, e não há mal nenhum nisso. Eis algumas das opções para as quais disponibilizamos uma instalação fácil.

## 1Password

Guardar as suas palavras-passe num gestor de palavras-passe é uma boa prática. A dobrar se estiver a trabalhar com uma equipa. E o [1password](https://1password.com/) é uma ótima solução, que também inclui uma ferramenta de linha de comandos para integrar consultas de chaves em scripts.

Arranca o 1Password com `Super + Shift + /`. Se ainda não estiver instalado, esse atalho inicia primeiro a instalação (também pode usar _Install > Service > 1Password_ a partir do menu do Omarchy). O instalador também traz a ferramenta de linha de comandos do 1Password e configura a extensão do 1Password para o Chrome e o Chromium; reinicie o navegador para a carregar.

## Bitwarden

O [Bitwarden](https://bitwarden.com/) é a alternativa de código aberto no mundo dos gestores de palavras-passe, com um nível gratuito que cobre a maior parte da utilização pessoal. Instale-o com _Install > Service > Bitwarden_ a partir do menu do Omarchy, o que também traz a ferramenta de linha de comandos do Bitwarden.

## Spotify

O [Spotify](https://spotify.com/) é o serviço de streaming de música mais popular do mundo. O Omarchy disponibiliza-o como uma aplicação web, que lhe dá o leitor completo, as teclas multimédia e o Spotify Connect, mas não descarregamentos offline. Arranque-o com `Super + Shift + M`.

## Slack

O [Slack](https://slack.com/) é onde muitas equipas conversam, tanto dentro da empresa como com colaboradores externos. Instale-o com _Install > Service > Slack_ a partir do menu do Omarchy, e ele abrirá assim que estiver pronto.

## Notion

O [Notion](https://www.notion.com/) é um espaço de trabalho para notas, documentos e projetos. Instale a sua aplicação de ambiente de trabalho com _Install > Service > Notion_ a partir do menu do Omarchy.

## Dropbox

O [Dropbox](https://www.dropbox.com/) é uma ótima forma de sincronizar ficheiros entre máquinas, mantendo ao mesmo tempo uma cópia de segurança na nuvem. Para o configurar, selecione _Install > Service > Dropbox_ a partir do menu do Omarchy. Adiciona um ícone do Dropbox à barra: clique nele para iniciar sessão e depois use o mesmo painel para verificar o seu armazenamento e abrir ficheiros sincronizados recentemente.

## Tailscale

O [Tailscale](https://tailscale.com/) é uma VPN em malha que torna extremamente simples aceder de forma segura a todos os seus computadores e servidores através da internet. Para o configurar, selecione _Install > Service > Tailscale_ a partir do menu do Omarchy.

Ganha um painel na barra, uma aplicação web para a consola de administração e o Taildrop para enviar ficheiros entre as suas máquinas — consulte [redes](35-networking.md).

## ONCE

O [ONCE](https://once.com/) é a linha de software da 37signals que compra uma vez e executa no seu próprio servidor, como o sistema de chat Campfire. Selecione _Install > Service > ONCE_ a partir do menu do Omarchy para o instalar, o que ativa o seu serviço em segundo plano e o coloca na interface de terminal do ONCE para continuar a partir daí.

## NordVPN

O [NordVPN](https://nordvpn.com/) é um serviço VPN normal que lhe permite fazer sair o seu tráfego a partir da maioria das regiões do mundo. Para o configurar, selecione _Install > Service > NordVPN_ a partir do menu do Omarchy. Após o reinício que ele pede, execute `nordvpn login` para se autenticar.
