# Lembretes

O Omarchy tem uma forma integrada de definir lembretes simples baseados num temporizador descendente e com uma mensagem. Podes fazê-lo com `Super + Ctrl + R`, ver todos os que estão definidos com `Super + Ctrl + Alt + R`, e limpar todos com `Super + Ctrl + Shift + R`. Tudo também acessível através de _Acionar > Lembrete_. Também podes usar a CLI com `omarchy reminder 7 'Tea ready'`.
