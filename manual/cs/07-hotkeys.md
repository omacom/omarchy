# Klávesové zkratky

Všechny hlavní klávesové zkratky uvidíte pomocí `Super + K` (zkratky Tmuxu pomocí `Super + Alt + K` a zkratky Herdr pomocí `Super + Ctrl + K`).

## Navigace

| Klávesová zkratka                  | Funkce              |
| ----------------------- | --------------------- |
| `Super + Space`           | Nabídka Omarchy (aplikace a všechno ostatní)    |
| `Super + Alt + Space` | Mřížka aplikací |
| `Super + Escape` | Systémová nabídka (uspat, restartovat atd.)  |
| `Super + Ctrl + L` | Zamknout počítač |
| `Super + W` or `Super + Q` | Zavřít okno             |
| `Ctrl + Alt + Del` | Zavřít všechna okna |
| `Super + T`               | Přepnout okno mezi dlaždicemi/plovoucím             |
| `Super + J` | Přepnout polohu okna (vodorovně/svisle) |
| `Super + O`               | Přepnout vysunutí okna do připnutého a plovoucího |
| `Super + L`               | Procházet rozloženími dwindle, posouvání a plovoucím |
| `Super + Alt + L`         | Procházet rozloženími v opačném pořadí |
| `Super + P`               | Přepnout styl pseudo okna (přirozený vs. roztažený) |
| `Super + F`                 | Přejít na celou obrazovku              |
| `Super + Alt + F`                 | Přejít na plnou šířku              |
| `Super + Ctrl + F`                 | Přejít na celou obrazovku uvnitř okna              |
| `Super + 1/2/3/4`         | Skočit na konkrétní pracovní plochu     |
| `Super + Tab` | Skočit na další pracovní plochu |
| `Super + Shift + Tab` | Skočit na předchozí pracovní plochu |
| `Super + Ctrl + Tab` | Skočit na dřívější pracovní plochu |
| `Super + Shift + 1/2/3/4` | Přesunout okno na pracovní plochu |
| `Super + Shift + Alt + 1/2/3/4` | Přesunout okno na pracovní plochu bez následování |
| `Super + S` / `Super + Grave` | Přepnout scratchpad |
| `Super + Alt + S` / `Super + Shift + Grave` | Přesunout okno na scratchpad |
| `Super + Shift + Alt + Arrows` | Přesunout pracovní plochy na monitor daným směrem |
| `Super + Arrow`  | Přesunout fokus na okno ve směru šipky              |
| `Super + Shift + Arrow`  | Prohodit okno s jiným ve směru šipky     |
| `Super + Minus` | Rozšířit okno doleva |
| `Super + Equal` | Zúžit okno doleva |
| `Super + Shift + Minus` | Zmenšit okno nahoru |
| `Super + Shift + Equal` | Rozšířit okno dolů |
| `Super + Alt + Minus/Equal` | Stejná změna velikosti v menších krocích |
| `Super + Ctrl + Minus/Equal` | Stejná změna velikosti ve větších krocích |
| `Super + Alt + Home` | Uložit šířku okna |
| `Super + Home` | Obnovit uloženou šířku okna |
| `Super + Left Mouse` | Tahat okno sem a tam |
| `Super + Right Mouse` | Změnit velikost okna |
| `Super + Scroll Wheel` | Posouvat se pracovními plochami |
| `Super + G`               | Přepnout seskupování oken      |
| `Super + Alt + G`               | Přesunout okno ven ze seskupení      |
| `Super + Alt + Tab`               | Procházet okny v seskupení      |
| `Super + Alt + Shift + Tab`               | Procházet okny v seskupení pozpátku      |
| `Super + Alt + 1/2/3/4/5`               | Skočit na konkrétní okno v seskupení      |
| `Super + Alt + Arrow`  | Přesunout okno do seskupení ve směru šipky  |
| `Super + Ctrl + Left/Right`  | Pohybovat se mezi okny uvnitř dlaždicové skupiny |
| `Super + Ctrl + Z` | Přiblížit obrazovku (opakujte pro větší přiblížení) |
| `Super + Ctrl + Alt + Z` | Úplně oddálit obrazovku |
| `Super + /` | Krokovat vpřed možnostmi škálování monitoru |
| `Super + Alt + /` | Krokovat vzad možnostmi škálování monitoru |
| `Alt + Tab` | Procházet vpřed okny na aktivní pracovní ploše |
| `Alt + Shift + Tab` | Procházet vzad okny na aktivní pracovní ploše |
| `Ctrl + Alt + Tab`| Procházet fokusem vpřed monitory |
| `Ctrl + Alt + Shift + Tab`| Procházet fokusem vzad monitory |

## Univerzální schránka

| Klávesová zkratka                  | Funkce              |
| ----------------------- | --------------------- |
| `Super + C`           | Kopírovat    |
| `Super + X`           | Vyjmout (ne v terminálu)    |
| `Super + V`           | Vložit    |
| `Super + Ctrl + V`           | Správce schránky    |

Obvykle na Linuxu potřebujete `Ctrl + Shift + C/V` pro kopírování a vkládání v terminálu a `Ctrl + C/V` všude jinde. Tyto jednotné klávesové zkratky schránky v Omarchy fungují všude.

## Zachytit

| Klávesová zkratka              | Funkce                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Nabídka Zachytit (pro klávesnice bez tlačítka PrintScr) |
| `Print Screen`            | Snímek obrazovky                      |
| `Alt + Print Screen`            | Nahrávání obrazovky                     |
| `Super + Print Screen` | Výběr barvy |
| `Super + Ctrl + Print Screen` | Extrakce textu do schránky |
| `Super + Alt + [` | Zmenšit překryv webové kamery během nahrávání |
| `Super + Alt + ]` | Zvětšit překryv webové kamery během nahrávání |
| `Alt + Shift + L` | Kopírovat current URL from webapp or Chromium |
| `Alt + Shift + D` | Stáhnout video na aktuální stránce do `~/Videos` |
| `Super + Ctrl + X` | Spustit/zastavit diktování (vyžaduje _Nastavení > Výchozí > Diktování_) |
| `Right Alt` / `F9` | Diktování push-to-talk (vyžaduje Voxtype nebo Superwhisper) |

U nahrávání obrazovky se klávesová zkratka nejdřív zeptá, jaký zvuk chcete, a poté spustí nahrávání. Stiskněte ji znovu pro zastavení. Podrobnosti viz [snímky obrazovky a nahrávání](12-screenshots-recording.md).

Všechny možnosti zachycení jsou přístupné také v _Akce > Zachytit_ v nabídce Omarchy (`Super + Space`).

## Tmux

Prefixová klávesa je `Ctrl + Space` (funguje také `Ctrl + B`). Tyto zkratky můžete změnit v `~/.config/tmux/tmux.conf`.

### Panely

| Klávesová zkratka                  | Funkce              |
| ----------------------- | --------------------- |
| `Prefix + v` | Rozdělit panel vedle (svisle) |
| `Prefix + h` | Rozdělit panel dole (vodorovně) |
| `Prefix + x` | Zabít panel |
| `Prefix + z` | Přepnout přiblížení panelu (celá obrazovka) |
| `Alt + Enter` | Rozdělit panel dole (bez prefixu) |
| `Alt + Shift + Enter` | Rozdělit panel vedle (bez prefixu) |
| `Alt + Escape` | Zabít panel (no prefix) |
| `Ctrl + Alt + Arrows` | Pohybovat se mezi panely |
| `Ctrl + Alt + Shift + Arrows` | Změnit velikost panelů |

### Okna

| Klávesová zkratka                  | Funkce              |
| ----------------------- | --------------------- |
| `Prefix + c` | Nové okno |
| `Prefix + k` | Zabít okno |
| `Prefix + r` | Přejmenovat okno |
| `Alt + 1-9` | Přejít na konkrétní okno |
| `Alt + Arrow Left/Right` | Pohybovat se mezi okny |
| `Alt + Shift + Arrow Left/Right` | Přesunout okno doleva/doprava |

### Relace

| Klávesová zkratka                  | Funkce              |
| ----------------------- | --------------------- |
| `Prefix + C` | Nová relace |
| `Prefix + K` | Zabít relaci |
| `Prefix + R` | Přejmenovat relaci |
| `Prefix + N` | Další relace |
| `Prefix + P` | Předchozí relace |
| `Alt + Arrow Up/Down` | Pohybovat se mezi relacemi |
| `Prefix + s` | Seznam relací |
| `Prefix + d` | Odpojit se od relace |

### Režim kopírování (ve stylu vi)

| Klávesová zkratka                  | Funkce              |
| ----------------------- | --------------------- |
| `Prefix + [` | Vstoupit do režimu kopírování |
| `v` | Zahájit výběr (v režimu kopírování) |
| `y` | Kopírovat selection (in copy mode) |

### Obecné

| Klávesová zkratka                  | Funkce              |
| ----------------------- | --------------------- |
| `Prefix + q` | Znovu načíst konfiguraci |
| `Prefix + ?` | Zobrazit klávesové zkratky Tmuxu |
| `Prefix + :` | Příkazový řádek |

### Funkce rozložení Tmuxu

Tyto funkce musí být spuštěny uvnitř relace Tmux.

| Příkaz | Funkce |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Vytvořit vývojové rozložení s editorem, AI a terminálem |
| `tdlm <ai> [<second_ai>]` | Vytvořit vývojové rozložení pro každý podadresář |
| `tsl <count> <command>` | Vytvořit vícesložkové rojové rozložení |
