# Klávesové zkratky

Všechna hlavní přiřazení kláves si můžete zobrazit pomocí `Super + K` (přiřazení pro Tmux pomocí `Super + Alt + K` a přiřazení pro Herdr pomocí `Super + Ctrl + K`).

## Navigace

| ----------------------- | --------------------- |
| `Super + Space`           | Nabídka Omarchy (aplikace a všechno ostatní)    |
| `Super + Alt + Space` | Mřížka aplikací |
| `Super + Escape` | Systémová nabídka (uspání, restart atd.)  |

| `Super + Alt + Shift + Tab`               | Procházet okna ve seskupení zpět      |

## Zachytávání

| Hotkey              | Function                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Snímek obrazovky                      |
| `Super + Ctrl + Alt + C`            | Snímek obrazovky (tentýž snímek, pro klávesnice bez klávesy Print Screen) |
| `Super + Ctrl + C` | Nabídka zachytávání |
| `Alt + Print Screen`            | Nahrávání obrazovky                     |
| `Super + Print Screen` | Výběr barvy |
| `Super + Ctrl + Print Screen` | Extrakce textu do schránky |
| `Super + Alt + [` | Zmenšit překryv webkamery během nahrávání |
| `Super + Alt + ]` | Zvětšit překryv webkamery během nahrávání |
| `Alt + Shift + L` | Zkopírovat aktuální URL z webové aplikace nebo Chromium |
| `Alt + Shift + D` | Stáhnout video na aktuální stránce do `~/Videos` |
| `Super + Ctrl + X` | Spustit/zastavit diktování (vyžaduje _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | Diktování push-to-talk (vyžaduje Voxtype nebo Superwhisper) |

U nahrávání obrazovky se klávesová zkratka nejprve zeptá, který zvuk chcete, a poté spustí nahrávání. Stiskněte ji znovu pro zastavení. Podrobnosti najdete v [snímky obrazovky a nahrávání](12-screenshots-recording.md).

Všechny možnosti zachytávání jsou dostupné také pod _Trigger > Capture_ v nabídce Omarchy (`Super + Space`).

## Tmux

Předponová klávesa je `Ctrl + Space` (funguje také `Ctrl + B`). Tato přiřazení můžete změnit v `~/.config/tmux/tmux.conf`.

### Panely

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + v` | Rozdělit panel vedle (svisle) |
| `Prefix + h` | Rozdělit panel pod (vodorovně) |
| `Prefix + x` | Zavřít panel |
| `Prefix + z` | Přepnout přiblížení panelu (celá obrazovka) |
| `Alt + Enter` | Rozdělit panel pod (bez předpony) |
| `Alt + Shift + Enter` | Rozdělit panel vedle (bez předpony) |
| `Alt + Escape` | Zavřít panel (bez předpony) |
| `Ctrl + Alt + Arrows` | Pohyb mezi panely |
| `Ctrl + Alt + Shift + Arrows` | Měnit velikost panelů |

### Okna

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + c` | Nové okno |
| `Prefix + k` | Zavřít okno |
| `Prefix + r` | Přejmenovat okno |
| `Alt + 1-9` | Přejít na konkrétní okno |
| `Alt + Arrow Left/Right` | Pohyb mezi okny |
| `Alt + Shift + Arrow Left/Right` | Přesunout okno doleva/doprava |

### Relace

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + C` | Nová relace |
| `Prefix + K` | Ukončit relaci |
| `Prefix + R` | Přejmenovat relaci |
| `Prefix + N` | Další relace |
| `Prefix + P` | Předchozí relace |
| `Alt + Arrow Up/Down` | Pohyb mezi relacemi |
| `Prefix + s` | Seznam relací |
| `Prefix + d` | Odpojit se od relace |

### Režim kopírování (ve stylu vi)

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + [` | Vstoupit do režimu kopírování |
| `v` | Začít výběr (v režimu kopírování) |
| `y` | Zkopírovat výběr (v režimu kopírování) |

### Obecné

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + q` | Znovu načíst konfiguraci |
| `Prefix + ?` | Zobrazit klávesové zkratky Tmux |
| `Prefix + :` | Příkazový řádek |

### Funkce rozvržení Tmux

Tyto funkce musí být spuštěny uvnitř relace Tmux.

| Command | Function |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Vytvořit vývojové rozvržení s editorem, AI a terminálem |
| `tdlm <ai> [<second_ai>]` | Vytvořit vývojové rozvržení pro každý podadresář |
| `tsl <count> <command>` | Vytvořit rozvržení roje s více panely |
