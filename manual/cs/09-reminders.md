# Připomínka

Omarchy má vestavěný způsob, jak nastavit jednoduché připomínky na základě odpočítávacího časovače se zprávou. Můžete to udělat přes `Super + Ctrl + R`, všechny nastavené zobrazit přes `Super + Ctrl + Alt + R` a všechny vymazat přes `Super + Ctrl + Shift + R`. Všechno je přístupné také přes _Akce > Připomínka_. Můžete také použít cli pomocí `omarchy reminder 7 'Tea ready'`.
