# 내비게이션

Omarchy에서는 모든 것이 키보드로 이루어집니다 — _모든 것이요!_ 시스템이 처음 시작되면 마우스만으로는 말 그대로 아무것도 할 수 없습니다. 하지만 `Super + Space`를 누르면 Omarchy Menu가 나타나고, 여기서 거의 모든 것을 할 수 있습니다.

하지만 Omarchy 메뉴는 대부분의 시간에 시스템을 조작하는 주된 방법이 되도록 의도된 것도 아닙니다. 우리는 그보다 더 빨라질 수 있습니다! 가장 중요한 애플리케이션은 모두 개별 단축키에 직접 바인딩되어 있습니다. 터미널은 `Super + Return`으로, 브라우저는 `Super + Shift + Return`으로 시작합니다. 하나를 실행한 뒤 다른 하나를 실행해 보세요. Hyprland 타일링의 마법을 직접 보게 될 것입니다:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

그런 다음 `Super + J`를 누르면 나란히 배치하는 대신 위아래로 쌓을 수 있습니다:

 ![navigation-stacked](images/navigation-stacked.webp)

`Super + J`를 다시 누르면 나란히 있는 위치로 돌아갑니다. 그런 다음 브라우저에 있는 상태에서 `Super + Shift + Arrow Right`를 눌러 창을 서로 바꿔 보세요.

이제 `Super + Shift + T`를 눌러 Activity 모니터를 시작해 보세요. 플로팅 창으로 나타날 것입니다. `Super + T`를 사용해 타일링할 수 있습니다(다시 누르면 다시 플로팅이 됩니다). 이제 `Super + Shift + F`를 눌러 파일 관리자를 여세요. 깔끔한 4분할 구성이 완성될 것입니다:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

`Super + Arrow`를 사용해 활성화하려는 창 사이를 이동합니다. 그러면 포커스가 전환되고 커서가 새 애플리케이션의 중앙으로 이동합니다. 화면 가장자리에서는 그쪽에 있는 모니터로 이어집니다.

`Super + Shift + 2`를 누르면 현재 포커스된 애플리케이션이 두 번째 워크스페이스로 이동합니다. `Super + Shift + 1`을 누르면 다시 돌아옵니다. (그리고 `Super + Shift + Alt + 2`를 누르면 현재 포커스된 애플리케이션이 두 번째 워크스페이스로 이동하지만, 그 워크스페이스로 전환되지는 않습니다).

모니터가 여러 개이면 각 모니터마다 고유한 1부터 10까지의 워크스페이스가 있습니다. `Super + 2`는 현재 있는 모니터의 두 번째 워크스페이스로 이동하고, 각 모니터의 상단 바에는 해당 모니터의 워크스페이스와 현재 표시 중인 워크스페이스가 표시됩니다. `Super + Tab`은 현재 있는 모니터의 워크스페이스를 순환합니다. `Super + Shift + Ctrl + Arrows`는 현재 있는 창을 해당 방향의 모니터로, 그 모니터가 표시 중인 워크스페이스로 이동시키고, `Super + Shift + Alt + Arrows`는 현재 있는 워크스페이스를 해당 방향의 모니터로 이동시키며, 비어 있으면 같은 번호를 차지합니다. 모니터를 분리해도 그 모니터는 워크스페이스를 유지합니다: 워크스페이스는 다른 화면의 워크스페이스에 합쳐져 이미 있는 워크스페이스 뒤에 번호가 매겨지고, 모니터가 돌아오면 이전 번호로 돌아갑니다.

`Super`를 누른 채 마우스로 창을 클릭하면 창이 있는 위치를 재배열할 수 있습니다. `Super`를 누른 채 마우스 오른쪽 버튼을 사용하면 창 크기를 자유롭게 조절할 수 있습니다.

창은 `Super + W` 또는 `Super + Q`로 닫습니다(모든 창은 `Ctrl + Alt + Delete`로 닫습니다).

`Super + F`로 전체 화면으로 전환할 수도 있고, `Super + Alt + F`로 상단 바를 유지하면서 전체 너비로만 전환할 수도 있으며, `Super + Ctrl + F`로 창 안에서 전체 화면으로 전환할 수도 있습니다(YouTube에 좋습니다!).

### Dwindle vs 스크롤링 레이아웃

Omarchy의 기본 레이아웃은 dwindle이라고 합니다. 이는 창을 축소해야 하더라도 단일 워크스페이스에 여는 모든 창을 항상 볼 수 있게 유지합니다.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

하지만 창이 나란히 줄지어 디스플레이의 보이는 가장자리를 넘어 배치되는 스크롤링 레이아웃으로 워크스페이스를 전환할 수도 있습니다. `Super + L`을 통해 단일 워크스페이스를 이 레이아웃으로 전환합니다.

`Super + L`을 다시 누르면 워크스페이스가 플로팅으로 전환되어 창이 자유롭게 겹치고 직접 배치하게 되며, 세 번째로 누르면 dwindle로 돌아갑니다. `Super + Alt + L`은 반대 방향으로 순환합니다. 어쨌든 플로팅 상태인 창 — `Super + T`로 분리한 창이나 항상 플로팅으로 열리는 앱 — 은 워크스페이스가 타일링으로 돌아가도 계속 플로팅 상태를 유지합니다. 상단 바는 현재 있는 워크스페이스에 레이아웃을 표시합니다: dwindle은 정사각형, 스크롤링은 원, 플로팅은 삼각형입니다. 그 표시를 클릭해도 레이아웃이 순환합니다.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

선택은 워크스페이스별로 이루어지며 유지됩니다. 따라서 워크스페이스 1은 브라우징용으로 dwindle에, 워크스페이스 2는 코드용으로 스크롤링에 유지할 수 있으며, 재시작 후에도 그대로 돌아옵니다.

스크롤링 레이아웃을 기본값으로 사용하려면 `~/.config/hypr/looknfeel.lua`에서 설정할 수 있습니다:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### 플로팅 워크스페이스

플로팅 워크스페이스는 전통적인 데스크톱처럼 작동합니다: 창이 겹치고, 직접 이동하고 크기를 조절합니다. 각 창에는 테마 색상의 타이틀바가 생기며, 최소화, 최대화, 닫기 버튼이 있습니다. `Super + M`도 포커스된 창을 최소화합니다. 최소화된 창은 dock에서 기다립니다; 해당 앱을 클릭하면 다시 불러옵니다. 창을 클릭하면 앞으로 가져옵니다. 어느 가장자리나 모서리에서든 크기를 조절할 수 있습니다. 타이틀바를 더블클릭하면 상단 바를 계속 보이게 하면서 창을 최대화하고, 다시 더블클릭하면 이전 크기로 돌아갑니다.

플로팅 워크스페이스는 dock도 표시합니다. 고정된 앱, 실행 중인 모든 것, 그리고 apps 버튼 뒤에 있는 모든 앱의 그리드가 있으며, `Super + Alt + Space`와 Omarchy 메뉴의 _Apps_로도 열립니다. 그리드에서 앱을 마우스 오른쪽 버튼으로 클릭하거나 `Delete`를 눌러 제거할 수 있습니다. 앱을 클릭하면 열거나 해당 창을 앞으로 가져옵니다; 다시 클릭하면 해당 앱의 창을 순환합니다. 가운데 버튼 클릭은 새 창을 엽니다. 아이콘을 dock을 따라 드래그하면 이동합니다; 실행 중인 앱을 다른 앱들 사이에 드래그하면 그곳에 유지됩니다. 마우스 오른쪽 버튼으로 클릭해 앱을 dock에 유지하거나, 빼거나, 종료할 수 있습니다. dock은 전체 화면 창의 방해가 되지 않도록 물러납니다. apps 버튼을 마우스 오른쪽 버튼으로 클릭하면 dock을 다른 가장자리로 이동하거나 포인터가 가장자리에 닿을 때까지 숨길 수 있습니다. 위치는 _Appearance > Dock > Dock Position_ 아래에도 있으며, `omarchy dock position left`와 `omarchy dock autohide on`은 터미널에서 두 가지를 모두 설정합니다. dock에 유지하는 앱은 실행 중이 아닐 때 흐리게 표시됩니다.

새 워크스페이스와 `Super + L`로 고유한 레이아웃을 지정하지 않은 모든 워크스페이스는 기본 레이아웃을 사용합니다. 기본값을 변경하면 창이 없는 모든 워크스페이스가 기본값으로 재설정되지만, 창이 있는 워크스페이스는 현재 레이아웃을 유지합니다. dock으로 최소화된 창은 여전히 떠난 워크스페이스의 창으로 셉니다. _Appearance > Workspace Layout_에서 선택하세요: Tiling, Scrolling 또는 Floating. `omarchy-hyprland-workspace-layout-default scrolling`은 터미널에서 설정합니다.

### 창 그룹화

창은 `Super + G`를 사용해 그룹화할 수 있습니다. 그룹에 들어가면, 활성화된 상태에서 시작하는 모든 창은 그 그룹에 속하게 됩니다. `Super + Ctrl + Arrow Left/Right`를 사용해 그룹화된 창 사이를 이동하거나, `Super + Alt + 1/2/3/4`를 사용해 순서대로 그룹화된 창으로 직접 이동할 수 있습니다.

`Super + Alt + G`를 사용해 창을 그룹에서 빼거나, `Super + G`를 다시 눌러 전체 그룹을 해체할 수 있습니다. 마지막으로, `Super + Alt + Arrows`를 사용해 그룹 밖에 있는 창을 그룹 안으로 이동할 수 있습니다.

### 창 분리하기

`Super + O`를 사용해 창을 워크스페이스 할당에서 분리할 수 있습니다. 그러면 어느 워크스페이스로 이동하든 따라다니는 플로팅 창으로 고정됩니다. 동영상 플레이어 같은 것에 좋습니다.

 ![navigation-popped-window](images/navigation-popped-window.webp)

### 스크래치패드 워크스페이스

현재 있는 워크스페이스 위에 겹쳐지는 특별한 전체 크기 스크래치패드 워크스페이스가 있습니다. 그 위에 있는 것에는 `Super + S`를 사용해 접근하고, 창을 그곳에 배치할 때는 `Super + Alt + S`를 사용합니다.

현재 워크스페이스를 떠나지 않고 빠르게 상호작용하려는 컨트롤이나 터미널에 잘 작동합니다.

### Quake 콘솔

마지막으로, 현재 있는 워크스페이스 위에 내려오는 절반 높이의 Quake 콘솔이 있습니다. `Super + Grave`로 토글하고, `Super + Shift + Grave`를 사용해 창을 그곳에 배치합니다.

기본 agent가 준비된 상태로 열립니다. 콘솔에 창이 하나만 있을 때는 화면 전체에 걸쳐 나타나지 않고 가운데에 있는 패널로 내려옵니다. 두 번째 앱을 그곳에 두면 전체 너비로 돌아가 두 앱이 나란히 앉을 공간이 생깁니다.

스크래치패드나 콘솔에서 창을 옮기려면, `Super + Shift + 1` 같은 것으로 다른 워크스페이스로 직접 보내세요.

### 익숙해지는 데 시간이 좀 걸립니다!

이렇게 데스크톱을 탐색하는 데 익숙해지는 데는 시간이 조금 걸리지만, 익숙해지면 전통적인 마우스 중심 데스크톱 경험으로 돌아가기 어려울 것입니다!
