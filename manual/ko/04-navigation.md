# 탐색

Omarchy에서는 모든 것이 키보드로 이루어집니다 — _전부 다요!_ 시스템이 처음 시작되면 마우스만으로는 말 그대로 아무것도 할 수 없습니다. 하지만 `Super + Space`를 누르면 Omarchy 메뉴가 나타나고, 여기에서 거의 모든 것을 할 수 있습니다.

하지만 Omarchy 메뉴는 대부분의 시간에 시스템을 조작하는 주된 방법이 되도록 의도된 것조차 아닙니다. 그보다 더 빨라질 수 있습니다! 가장 중요한 애플리케이션은 모두 개별 단축키에 직접 바인딩되어 있습니다. `Super + Return`으로 터미널을 시작하고 `Super + Shift + Return`으로 브라우저를 시작합니다. 하나를 실행한 뒤 바로 다른 하나를 실행해 보세요. Hyprland 타일링의 마법이 실제로 작동하는 모습을 보게 될 것입니다:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

그런 다음 `Super + J`를 누르면 나란히 있는 대신 서로 위아래로 쌓을 수 있습니다:

 ![navigation-stacked](images/navigation-stacked.webp)

`Super + J`를 다시 누르면 나란히 있는 위치로 돌아갑니다. 그런 다음 브라우저에 있는 동안 `Super + Shift + Arrow Right`를 눌러 창들을 서로 바꿔 보세요.

이제 `Super + Shift + T`를 눌러 Activity 모니터를 시작해 보세요. 플로팅 창으로 나타날 것입니다. `Super + T`를 사용해 타일링할 수 있고 (다시 누르면 다시 플로팅으로 만들 수 있습니다). 이제 `Super + Shift + F`를 눌러 파일 관리자를 여세요. 깔끔한 4분할 구성이 완성될 것입니다:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

`Super + Arrow`로 활성화하려는 창 사이를 이동합니다. 이렇게 하면 초점이 전환되고 커서가 새 애플리케이션의 중앙으로 이동합니다. 화면 가장자리에서는 그쪽에 있는 모니터로 이어집니다.

`Super + Shift + 2`를 누르면 현재 초점이 있는 애플리케이션이 두 번째 워크스페이스로 이동합니다. `Super + Shift + 1`을 누르면 다시 돌아옵니다. (그리고 `Super + Shift + Alt + 2`를 누르면 현재 초점이 있는 애플리케이션을 두 번째 워크스페이스로 이동시키지만 그곳으로 전환하지는 않습니다).

모니터가 여러 대이면 각 모니터마다 1부터 10까지의 자체 워크스페이스가 있습니다. `Super + 2`는 현재 있는 모니터의 두 번째 워크스페이스로 이동하고, 각 모니터의 상단 바에는 자체 워크스페이스와 현재 표시 중인 워크스페이스가 표시됩니다. `Super + Tab`은 현재 있는 모니터의 워크스페이스들을 순환합니다. `Super + Shift + Ctrl + Arrows`는 현재 있는 창을 그 방향에 있는 모니터로, 그 모니터가 표시 중인 워크스페이스 위로 이동시키고, `Super + Shift + Alt + Arrows`는 현재 있는 워크스페이스를 그 방향에 있는 모니터로 이동시키며, 그곳에서는 비어 있으면 같은 번호를 차지합니다. 모니터를 분리하면 그 모니터는 워크스페이스를 유지합니다. 워크스페이스들은 다른 화면의 워크스페이스에 합쳐져 이미 있는 워크스페이스 뒤에 번호가 매겨지고, 모니터가 돌아오면 이전 번호로 돌아갑니다.

`Super`를 누른 채 마우스로 창을 클릭하면 창이 있는 위치를 재배열할 수 있습니다. `Super`를 누른 채 마우스 오른쪽 버튼을 사용하면 창 크기를 자유롭게 조정할 수 있습니다.

`Super + W` 또는 `Super + Q`로 창을 닫습니다 (그리고 `Ctrl + Alt + Delete`로 모든 창을 닫습니다).

`Super + F`로 전체 화면으로 전환할 수도 있고, `Super + Alt + F`로 상단 바를 유지한 채 너비 전체로만 전환하거나, `Super + Ctrl + F`로 창 안에서 전체 화면으로 전환할 수도 있습니다 (YouTube에 좋습니다!).

### dwindle 대 스크롤링 레이아웃

Omarchy의 기본 레이아웃은 dwindle이라고 합니다. 단일 워크스페이스에 여는 모든 창을, 창을 축소해야 하더라도 항상 모두 보이게 유지합니다.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

하지만 워크스페이스를 창들이 디스플레이의 보이는 가장자리를 넘어 나란히 줄지어 있는 스크롤링 레이아웃으로 전환하도록 선택할 수도 있습니다. `Super + L`을 통해 단일 워크스페이스를 이 레이아웃으로 전환합니다.

`Super + L`을 다시 누르면 워크스페이스가 플로팅으로 전환되어 창들이 자유롭게 겹치고 직접 배치하게 되며, 세 번째로 누르면 dwindle로 돌아갑니다. `Super + Alt + L`은 반대 방향으로 순환합니다. 어차피 떠 있는 창 — `Super + T`로 꺼낸 창이나 항상 플로팅으로 열리는 앱 — 은 워크스페이스가 타일링으로 돌아가도 계속 떠 있습니다. 상단 바는 현재 있는 워크스페이스에 그 레이아웃을 표시합니다. dwindle은 사각형, 스크롤링은 원, 플로팅은 삼각형입니다. 그 표시를 클릭해도 레이아웃이 순환하고, 그런 키가 있는 노트북에서는 디스플레이 키를 눌러도 마찬가지입니다.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

이 선택은 워크스페이스별로 적용되며 유지됩니다. 따라서 워크스페이스 1은 브라우징용으로 dwindle에 두고 워크스페이스 2는 코드용으로 스크롤링에 둘 수 있으며, 재시작 후에도 그런 상태로 돌아올 것입니다.

스크롤링 레이아웃을 기본값으로 사용하려면 `~/.config/hypr/looknfeel.lua`에서 설정할 수 있습니다:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### 플로팅 워크스페이스

플로팅 워크스페이스는 전통적인 데스크톱처럼 작동합니다. 창이 겹치고, 직접 이동하고 크기를 조정합니다. 각 창에는 테마 색상의 타이틀바가 생기며 최소화, 최대화, 닫기 버튼이 있습니다. `Super + M`도 초점이 있는 창을 최소화합니다. 최소화된 창은 dock에서 기다립니다. 해당 앱을 클릭하면 다시 돌아옵니다. 창을 클릭하면 앞으로 가져옵니다. 어느 가장자리나 모서리에서든 크기를 조정할 수 있습니다. 타이틀바를 더블 클릭하면 상단 바를 보이게 유지하면서 창을 최대화하고, 다시 더블 클릭하면 이전 크기로 돌아옵니다. Chrome 및 기타 Chromium 기반 브라우저, Disks, Document Viewer는 타이틀바를 건너뛰고 대신 자체 헤더를 사용합니다. `Super + Alt + F`로 최대화하고 `Super + M`으로 최소화합니다.

플로팅 워크스페이스에는 dock도 표시되며, 고정된 앱, 실행 중인 모든 것, 그리고 앱 버튼 뒤에 있는 모든 앱의 그리드가 있습니다. 이는 `Super + Alt + Space`와 Omarchy 메뉴의 _Apps_로도 열 수 있습니다. 그리드에서 앱을 마우스 오른쪽 버튼으로 클릭하거나 `Delete`를 눌러 제거하세요. 앱을 클릭해 열거나 그 창을 앞으로 가져옵니다. 다시 클릭하면 그 창들을 순환합니다. Files는 현재 있는 워크스페이스의 창만 다시 가져오고 그렇지 않으면 새 창을 열며, Terminal과 Agent는 항상 또 다른 창을 시작하지만, 최소화된 창이 먼저 돌아옵니다. 가운데 버튼 클릭은 새 창을 엽니다. 아이콘을 dock을 따라 드래그해 이동합니다. 실행 중인 앱을 다른 앱들 사이에 드래그하면 그곳에 유지됩니다. 마우스 오른쪽 버튼으로 클릭해 앱을 dock에 유지하거나, dock에서 제거하거나, 종료하세요. dock은 전체 화면 창이 있으면 방해되지 않도록 물러납니다. 앱 버튼을 마우스 오른쪽 버튼으로 클릭해 dock을 다른 가장자리로 이동하거나 포인터가 그 가장자리에 도달할 때까지 숨기도록 하세요. 위치는 _Appearance > Dock > Dock Position_ 아래에도 있으며, `omarchy dock position left`와 `omarchy dock autohide on`으로 터미널에서 둘 다 설정합니다. dock에 유지하는 앱은 실행 중이 아닐 때 희미하게 표시됩니다.

새 워크스페이스와 `Super + L`로 자체 레이아웃을 지정하지 않은 워크스페이스는 기본 레이아웃을 사용합니다. 기본값을 변경하면 창이 없는 모든 워크스페이스가 그 레이아웃으로 재설정되지만, 창이 있는 워크스페이스는 가진 레이아웃을 유지합니다. dock으로 최소화된 창은 여전히 떠난 워크스페이스에 있는 창으로 간주됩니다. _Appearance > Workspace Layout_에서 선택하세요: Tiling, Scrolling 또는 Floating. `omarchy hyprland workspace layout default scrolling`으로 터미널에서 설정합니다.

### 창 그룹화

`Super + G`를 사용해 창을 그룹화할 수 있습니다. 그룹에 들어가면, 그룹이 활성화된 동안 시작하는 모든 창은 그 그룹에 속하게 됩니다. `Super + Ctrl + Arrow Left/Right`를 사용해 이 그룹화된 창 사이를 이동하거나 `Super + Alt + 1/2/3/4`를 사용해 순서대로 그룹화된 창으로 직접 이동할 수 있습니다.

`Super + Alt + G`로 창을 그룹에서 이동시킬 수 있고, `Super + G`를 다시 눌러 전체 그룹을 해체할 수 있습니다. 마지막으로, `Super + Alt + Arrows`를 사용해 그룹 밖에 있는 창을 그룹 안으로 이동시킬 수 있습니다.

### 창 꺼내기

`Super + O`로 창을 워크스페이스 할당에서 꺼낼 수 있습니다. 그러면 창이 어느 워크스페이스로 이동하든 따라다니는 플로팅 창으로 고정됩니다. 동영상 플레이어 같은 것에 좋습니다.

 ![navigation-popped-window](images/navigation-popped-window.webp)

### 스크래치패드 워크스페이스

현재 있는 워크스페이스 위에 겹쳐지는 특수한 전체 크기 스크래치패드 워크스페이스가 있습니다. `Super + S`를 사용해 그 안에 있는 것에 접근하고, `Super + Alt + S`를 사용해 창을 그곳에 배치합니다.

현재 워크스페이스를 떠나지 않고 빠르게 상호작용하려는 컨트롤이나 터미널에 잘 작동합니다.

### Quake 콘솔

마지막으로, 현재 있는 워크스페이스 위로 아래로 내려오는 절반 높이의 Quake 콘솔이 있습니다. `Super + Grave`로 토글하고, `Super + Shift + Grave`를 사용해 창을 그곳에 배치하세요.

처음 열리면 기본 에이전트가 시작되거나, 아직 선택하지 않았다면 선택하라고 묻습니다. 콘솔에 창이 하나만 있을 때는 화면 전체에 걸쳐 나타나지 않고 가운데 패널로 아래로 내려옵니다. 두 번째 앱을 그곳에 두면 전체 너비로 돌아가 두 앱이 나란히 앉을 공간이 생깁니다.

스크래치패드나 콘솔에서 창을 이동시키려면 `Super + Shift + 1` 같은 단축키를 사용해 다른 워크스페이스로 직접 보내세요.
