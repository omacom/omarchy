# 상단 바

화면 상단을 따라 있는 띠가 Omarchy 바다. 볼트로 붙인 상태 표시줄이 아니라 Omarchy 셸의 일부이며, 메뉴, 알림, OSD 팝업, 잠금 화면도 그리는 단일 장기 실행 Quickshell 프로세스다. 그래서 다른 모든 것과 완벽하게 테마가 맞고, 패널이 새 앱을 실행하는 대신 즉시 열린다.

또한 항상 화면에 있는 유일한 데스크톱 요소이므로, 그 작은 글리프들이 모두 무엇을 하는지 알아둘 가치가 있다.

## 기본으로 표시되는 것

바는 세 개의 섹션으로 이루어져 있다. 왼쪽에는 Omarchy 로고(메뉴 실행기)와 워크스페이스 인디케이터가 있다. 가운데에는 상태 인디케이터, 시계, Elsewhen(세계 시계), 날씨, Omarchy 업데이트 배지가 있다. 오른쪽에는 시스템 트레이, 키보드 레이아웃(하나보다 많이 설정한 경우), 에이전트, Bluetooth, 네트워크, 오디오, 디스플레이, 전원이 있다.

그중 몇몇은 할 말이 있을 때만 나타난다. 키보드 레이아웃은 레이아웃을 하나보다 많이 설정했을 때만 나타난다. 업데이트 배지는 Omarchy 업데이트가 대기 중일 때만 나타난다. 그리고 에이전트 아이콘은 Omarchy가 컴퓨터에서 AI 코딩 사용량을 처음 발견했을 때 나타난다([AI](17-ai.md) 참조).

## 클릭해 보기

거의 모든 위젯은 왼쪽, 오른쪽, 가운데 클릭에 무언가를 하며, 여럿은 스크롤에도 반응한다. 사람들이 놓치는 부분이 바로 이것이다 — 오른쪽과 가운데 버튼 뒤에 좋은 기능이 많이 숨어 있다.

| 위젯 | 왼쪽 | 오른쪽 | 가운데 / 스크롤 |
| --- | --- | --- | --- |
| 메뉴 | Omarchy 메뉴 | 새 터미널 | — |
| 워크스페이스 | 이 모니터에서 해당 워크스페이스에 포커스 | — | 스크롤: 다음/이전 워크스페이스 |
| 시계 | 캘린더 팝업 | 레이블 형식 순환 | 가운데: 시간대 선택기 |
| 날씨 | 예보 팝업 | 전체 날씨를 알림으로 표시 | 가운데: 새로고침 |
| 오디오 | 오디오 패널 | 음소거 | 가운데: 패널 · 스크롤: 볼륨 |
| 마이크 | 마이크 음소거 | — | 가운데: 오디오 패널 · 스크롤: 입력 볼륨 |
| 네트워크 | 네트워크 패널 | — | — |
| Bluetooth | Bluetooth 패널 | 라디오 켜기/끄기 | — |
| 디스플레이 | 디스플레이 패널 | — | 스크롤: 밝기 |
| 전원 | 전원 패널 | 배터리 백분율 켜기/끄기 | — |
| 미디어 | 재생/일시정지 | 커버 아트 팝업 | 가운데: 다음 · 스크롤: 이전/다음 |
| 에이전트 | 에이전트 패널 | 에이전트 실행 | 가운데: 다음 구독 |
| 트레이 | 마우스를 올리면 서랍 표시 | 셰브런을 오른쪽 클릭해 관리 | — |
| Omarchy 업데이트 | 업데이트 실행 | — | — |

위 표에 있는 모든 것이 기본으로 바에 있는 것은 아니다. 미디어 위젯(MPRIS 현재 재생 중, 스크롤되는 트랙과 아티스트 표시)과 마이크 위젯은 둘 다 내장되어 있지만 기본으로는 꺼져 있다 — 원하면 아래 설명대로 추가하면 된다.

## 패널

바 아이콘을 클릭하면 패널이 열리며, 이는 툴팁이 아니라 슬라이더, 목록, 키보드 탐색을 갖춘 제대로 된 팝업이다. 각 패널마다 단축키도 있어 16픽셀짜리 글리프를 조준할 필요가 전혀 없다:

| 단축키 | 패널 |
| --- | --- |
| `Super + Ctrl + A` | 오디오 |
| `Super + Ctrl + N` | 네트워크 |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | 디스플레이 |
| `Super + Ctrl + P` | 전원 |
| `Super + Ctrl + Alt + D` | 캘린더 |
| `Super + Ctrl + Alt + E` | 세계 시계 |
| `Super + Ctrl + 1-9` | 오른쪽 섹션에서 n번째 패널 켜기/끄기 |

패널은 단순한 표시창이 아니다. 실제로 일을 처리하는 곳이다:

- **오디오**에는 마스터 볼륨 슬라이더, 출력 장치 선택기, 앱별 믹서가 있어, 다른 모든 것에는 손대지 않고 그 브라우저 탭 하나의 소리만 줄일 수 있다.
- **네트워크**는 Wi-Fi를 검색하고, 신호 강도를 보여주고, 연결하며, DNS 공급자를 선택할 수 있게 한다.
- **Bluetooth**는 장치를 목록으로 보여주고 연결/연결 해제와 배터리 수준을 표시한다.
- **전원**은 배터리 통계를 보여주고, 전원 프로필을 전환하며(배터리와 AC에 대해 각각 다른 선택을 기억한다), 일부 시스템 정보를 출력한다.
- **디스플레이**에는 밝기 슬라이더, 텍스트 크기, 모니터 스케일링 프리셋이 있고 — 화면이 하나보다 많으면 — 모니터별 컨트롤도 있다. 더 깊은 이야기는 [모니터](33-monitors.md)를 참조하라.
- **시계**는 ISO 주차 번호와 월 이동이 있는 월간 그리드를 연다.
- **세계 시계**는 도시마다 한 행을 유지하며, 그곳의 날씨와 하루가 어떻게 흘러가고 있는지 보여준다. 검색은 시간대뿐 아니라 마을도 찾으므로 Fort Lauderdale는 New York이 아니라 Fort Lauderdale다. 상단 줄이 잘못된 도시를 이름으로 표시하면, 그것을 클릭해 현재 위치를 알려줘라; 다른 시간대에 있는 곳을 선택하면 시스템 시계도 그곳으로 이동하는데, 여행할 때 편리하다. 도시 위에 마우스를 올리고 사람 버튼을 클릭해 누가 그곳에 사는지 알려줘라 — 일반 이름이나, 얼굴까지 함께 가져오는 `@` GitHub 핸들을 사용할 수 있다.

모든 패널은 마우스뿐 아니라 키보드도 받는다: 화살표로 이동하고, Return으로 활성화하고, Tab으로 이웃 패널로 이동하고, Escape로 닫는다.

`Super + Ctrl + 1-9`는 오른쪽 섹션에서 패널을 왼쪽에서 오른쪽으로 세며, 자체 패널이 없는 트레이는 건너뛴다. 그래서 숫자가 가리킬 아이콘과 일치한다.

### Tailscale과 Dropbox

두 개의 위젯이 더 있는데, **설치 → 서비스**에서 해당 서비스를 설치한 뒤에만 바에 나타나며, 둘 다 상태 보고 이상의 일을 하므로 알아둘 가치가 있다.

**Tailscale** 패널은 tailnet을 연결하고 연결을 끊고, 계정 간에 전환하고, 종료 노드를 선택한다(자신의 컴퓨터와 Mullvad 지역이 모두 그 목록에 나타난다). 또한 컴퓨터들을 탐색할 수 있으며 — 하나를 선택한 상태에서 `s`를 누르면 Taildrop으로 그곳에 파일을 보내는데, 이는 파일을 휴대폰이나 다른 노트북으로 옮기는 가장 빠른 방법이다. `c`는 컴퓨터의 IP를, `n`은 이름을, `d`는 전체 DNS 이름을 복사한다. 클릭하는 편이 좋다면 각 컴퓨터 행에도 보내기 버튼이 있다. 터미널에서 같은 작업을 하는 명령은 `omarchy tailscale send <machine> [file...]`이다.

**Dropbox** 패널은 로그인을 처리하고, 사용한 저장 공간의 양을 보여주고, 최근에 동기화된 파일을 목록으로 표시한다.

두 서비스 중 하나를 제거하면 그 위젯도 바에서 사라진다.

## 인디케이터

가운데의 작은 무리가 인디케이터 위젯이다. 켜둔 모드에 대한 상태 글리프다: 방해 금지, 야간 조명, 대기 중인 [리마인더](09-reminders.md), 활성 화면 녹화, 깨어 있기 유지, [받아쓰기](11-text-extraction-dictation.md). 모드가 활성화되면 켜지고 그렇지 않으면 방해되지 않게 물러나 있다 — 비활성 인디케이터가 있을 자리 바로 옆에 마우스를 올리면 그것들을 살짝 볼 수 있다. 인디케이터를 클릭하면 해당 모드가 켜지거나 꺼진다. 하나는 상태 전용이다: gliff를 통해 누군가 이 컴퓨터에 연결되어 있는 동안 원격 세션이 빨간색으로 켜진다.

항상 표시되기를 원하면 위젯에서 `alwaysShow`를 `true`로 설정하라. 그리고 그중 일부만 신경 쓴다면 원하는 것들을 `items`에 나열하라: `["Dnd", "Reminder", "NightLight"]`. 인디케이터 위젯을 하나보다 많이 가질 수 있으므로, 서로 다른 섹션이 서로 다른 부분집합을 표시할 수 있다.

## 바 재배열하기

바는 스스로를 설정한다. 무언가를 옮기기 위해 설정 파일을 열 필요가 없다.

가운데 주변 바의 빈 부분을 잡아 다른 화면 가장자리 쪽으로 드래그하면 바가 그곳으로 이동한다 — 왼쪽, 오른쪽, 위쪽, 아래쪽 모두 동작하며, 모든 위젯이 적응한다(세로 바는 컴팩트한 아이콘 전용 형태로 대체된다). 클릭한 채로 유지해도 같은 드래그가 시작된다. 같은 빈 공간을 왼쪽 버튼으로 더블클릭하면 바 배경이 투명에서 유리 질감으로, 불투명으로 순환한다. 그리고 어떤 위젯이든 드래그해 순서를 바꾸거나 다른 섹션으로 던져 넣으면, 다른 위젯들이 착지할 자리에 공간을 만들기 위해 양쪽으로 미끄러져 벌어진다.

바의 가운데는 상자다: 그 안에 있는 것은 무엇이든 하나의 그룹으로 가운데에 유지되고, 그 양쪽의 위젯들은 그 가장자리에 매달린다. 위젯을 드래그하는 동안 상자는 윤곽선으로 표시되거나, 비어 있을 때는 바를 가로지르는 선으로 표시되며, 그 안이나 옆에 드롭할 수 있다. 드롭이 상자에 착지하게 될 경우, 상자가 커져 위젯을 받아들인다.

항상 곁에 두고 싶지만 항상 보이게 하고 싶지는 않은 위젯은 트레이의 서랍에 넣을 수 있다: 트레이 위로 드래그하면 서랍이 열려 그것을 받아들인다. 그것은 앱 아이콘 뒤에 그곳에 앉아 있고, 서랍이 나타날 때마다 나타나며, 패널이 열려 있는 동안 서랍을 열린 채로 유지한다. 다시 바 위로 드래그해 꺼내면 원래 자리로 돌아간다.

메뉴에서 선택하는 편이 좋다면, **모양 → 메뉴 바**에 위치가 있고, **바 배경**은 바가 그려지는 방식을 선택한다: **불투명 바**, **유리 질감 바**(뒤에 있는 것이 흐릿하게 보이는 투명한 바), 또는 **투명 바**.

같은 것들에 대한 명령도 있는데, 이는 [dotfiles](31-dotfiles.md) 설정을 원할 때 필요한 것이다:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

위젯을 완전히 추가하거나 제거하려면 플러그인 명령을 사용하라. `omarchy plugin list`는 셸이 알고 있는 모든 위젯을 id와 함께 출력하며, 그 뒤에는 다음과 같이 한다:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## 바 숨기기

`Super + Shift + Space`는 셸을 종료하지 않고 바를 껐다가 다시 켠다 — 패널과 단축키는 계속 동작하고, 픽셀만 되찾는다. 메뉴의 **모양 → 메뉴 바 → 바 숨기기**에도 있다.

## 설정 파일

이 모든 것은 `~/.config/omarchy/shell.json`의 `bar` 키 아래에 저장된다. 다음은 다듬은 버전이다:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

모든 위젯은 다섯 개의 레이아웃 배열 중 하나에 있는 항목 하나이며, 그 설정은 그 항목에 인라인으로 들어 있다 — 별도의 설정 파일도 없고 `config` 하위 객체도 없다. 시계의 `format`, `formatAlt`(오른쪽 클릭으로 순환되는 것), `verticalFormat`은 모두 바로 그곳 `{ "id": "omarchy.clock" }`에 있다.

`center`는 바 가운데의 상자다: 그 안의 모든 것은 하나의 그룹으로 화면 중앙에 정렬된다. `centerBegin`과 `centerEnd`는 상자의 양쪽에 매달리며, 날씨와 업데이트 배지가 오가더라도 시계가 정확히 중앙에 유지되는 방식이 바로 이것이다. `center`에 위젯을 하나보다 많이 넣으면 함께 중앙에 정렬되고; 비워 두면 `centerBegin`과 `centerEnd`가 바의 가운데에서 만난다.

내면화할 가치가 있는 규칙 하나: **자신만의 `shell.json`을 갖게 되면, 그것이 정본이다**. 어떤 것도 사용자 지정하지 않은 동안에는 셸이 Omarchy의 기본 파일을 읽는다. 위젯을 드래그하거나, `omarchy bar`를 실행하거나, 파일을 직접 편집하는 순간, 그것은 당신의 것이 된다 — 깊은 병합은 없으므로, 향후 Omarchy 릴리스의 새 기본 위젯이 바에 자동으로 나타나지 않는다. `omarchy bar defaults`는 깨끗한 상태로 시작하고 싶을 때마다 출고 시 레이아웃을 되돌려 놓는다.

같은 파일은 또한 `bar` 키 밖에, 최상위 수준에서 유휴 타이밍도 보관한다: `idle.screensaver`와 `idle.lock`, 둘 다 유휴 상태가 된 뒤의 초 단위다. 그래서 기본 화면 보호기는 150초에 시작되고 잠금은 300초에 시작된다.
