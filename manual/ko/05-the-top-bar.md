# 상단 바

화면 상단을 따라 길게 놓인 띠가 Omarchy 바이다. 이는 볼트로 고정해 붙인 상태 표시줄이 아니라, 메뉴, 알림, OSD 팝업, 잠금 화면까지 함께 그리는 단 하나의 오래 실행되는 Quickshell 프로세스인 Omarchy 셸의 일부이다. 그래서 다른 모든 것과 완벽하게 어울리는 테마를 유지하고, 패널도 새 앱을 실행할 필요 없이 즉시 열린다.

또한 데스크톱에서 항상 화면에 떠 있는 유일한 요소이기도 하므로, 그 작은 글리프들이 각각 무슨 일을 하는지 알아둘 가치가 있다.

## 기본적으로 무엇이 올라가 있나

바는 세 개의 섹션으로 이루어져 있다. 왼쪽에는 Omarchy 로고(메뉴 실행기)와 워크스페이스 표시기가 있다. 가운데에는 상태 표시기, 시계, Elsewhen(세계 시계), 날씨, 그리고 Omarchy 업데이트 배지가 있다. 오른쪽에는 시스템 트레이, 키보드 레이아웃(레이아웃이나 입력 방식을 둘 이상 구성했을 때), 에이전트, bluetooth, 네트워크, 오디오, 디스플레이, 전원이 있다.

이 중 몇 가지는 말할 것이 있을 때만 나타난다. 키보드 레이아웃은 레이아웃이나 입력 방식을 둘 이상 구성했을 때만 나타나고, 업데이트 배지는 기다리고 있는 Omarchy 업데이트가 있을 때만 나타난다.

## 여기저기 클릭하기

거의 모든 위젯이 왼쪽, 오른쪽, 가운데 클릭에 각각 반응하고, 몇몇은 스크롤에도 반응한다. 사람들이 놓치는 부분이 바로 이것이다 — 좋은 것 상당수가 오른쪽 버튼과 가운데 버튼 뒤에 숨어 있다.

| 위젯 | 왼쪽 | 오른쪽 | 가운데 / 스크롤 |
| --- | --- | --- | --- |
| 메뉴 | Omarchy 메뉴 | 새 터미널 | — |
| 워크스페이스 | 이 모니터에서 해당 워크스페이스로 포커스 | — | 스크롤: 다음/이전 워크스페이스 |
| 시계 | 캘린더 팝업 | 레이블 형식 순환 | 가운데: 시간대 선택기 |
| 세계 시계 | 세계 시계 패널 | 새로고침 | 가운데: 새로고침 |
| 날씨 | 예보 팝업 | 전체 날씨를 알림으로 표시 | 가운데: 새로고침 |
| 오디오 | 오디오 패널 | 음소거 | 가운데: 패널 · 스크롤: 볼륨 |
| 마이크 | 마이크 음소거 | — | 가운데: 오디오 패널 · 스크롤: 입력 볼륨 |
| 네트워크 | 네트워크 패널 | — | — |
| Bluetooth | Bluetooth 패널 | 라디오 켜기/끄기 | — |
| 디스플레이 | 디스플레이 패널 | — | 스크롤: 밝기 |
| 전원 | 전원 패널 | 배터리 백분율 표시 켜기/끄기 | — |
| 미디어 | 재생/일시 정지 | 커버 아트 팝업 | 가운데: 다음 · 스크롤: 이전/다음 |
| 에이전트 | 에이전트 패널 | 에이전트 실행 | 가운데: 사용량 새로고침 |
| 트레이 | 마우스를 올리면 서랍 표시 | 셰브론에서 오른쪽 클릭해 관리 | — |
| Omarchy 업데이트 | 업데이트 실행 | — | — |

그 표에 있는 모든 것이 처음부터 바에 올라가 있는 것은 아니다. 미디어 위젯(MPRIS 현재 재생 중, 스크롤되는 곡과 아티스트 표시)과 마이크 위젯은 둘 다 내장되어 있지만 기본적으로 꺼져 있다 — 원한다면 아래 설명대로 추가하면 된다.

## 패널

바 아이콘을 클릭하면 패널이 열리는데, 이는 툴팁이 아니라 슬라이더, 목록, 키보드 탐색을 갖춘 제대로 된 팝업이다. 각 패널마다 단축키도 있어 16픽셀짜리 글리프를 조준할 필요가 전혀 없다:

| 단축키 | 패널 |
| --- | --- |
| `Super + Ctrl + A` | 오디오 |
| `Super + Ctrl + N` | 네트워크 |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | 디스플레이 |
| `Super + Ctrl + P` | 전원 |
| `Super + Ctrl + Alt + D` | 캘린더 |
| `Super + Ctrl + Alt + E` | 세계 시계 |
| `Super + Ctrl + X` | 에이전트 |
| `Super + Ctrl + 1-9` | 오른쪽 섹션에서 n번째 패널 켜기/끄기 |

패널은 단순히 보여주기만 하는 표시창이 아니다. 실제로 일을 처리하는 곳이 바로 패널이다:

- **오디오**에는 마스터 볼륨 슬라이더, 출력 장치 선택기, 앱별 믹서가 있어, 다른 모든 것에는 손대지 않고 그 브라우저 탭 하나만 줄일 수 있다.
- **네트워크**는 Wi-Fi를 검색하고, 신호 강도를 보여주고, 연결하며, DNS 제공업체를 선택할 수 있게 한다.
- **Bluetooth**는 장치를 연결/연결 해제 및 배터리 잔량과 함께 나열한다.
- **전원**은 배터리 통계를 보여주고, 전원 프로필을 전환하며(배터리와 AC에 대해 서로 다른 선택을 따로 기억한다), 시스템 정보 일부를 표시한다.
- **디스플레이**에는 밝기 슬라이더, 텍스트 크기, 모니터 배율 프리셋이 있으며 — 화면이 둘 이상일 때는 — 모니터별 컨트롤도 있다. 더 깊은 이야기는 [모니터](33-monitors.md)를 보라.
- **시계**는 ISO 주 번호와 월 이동이 있는 월간 그리드를 연다.
- **세계 시계**는 도시마다 한 줄씩 유지하면서 그곳의 날씨와 그곳의 하루가 어떻게 흘러가고 있는지를 보여준다. 검색은 시간대뿐 아니라 마을과 도시도 찾으므로, Fort Lauderdale는 New York가 아닌 Fort Lauderdale 그대로이다. 상단 줄이 잘못된 도시를 가리키고 있다면 클릭해서 지금 어디에 있는지 알려주라; 다른 시간대에 있는 곳을 고르면 시스템 시계도 그곳으로 이동하는데, 여행할 때 편리하다. 도시에 마우스를 올리고 사람 버튼을 클릭하면 누가 거기에 사는지 말해줄 수 있다 — 평범한 이름도 좋고, `@` GitHub 핸들을 쓰면 얼굴까지 함께 가져온다.

모든 패널은 마우스뿐 아니라 키보드도 받는다: 화살표로 이동하고, Return으로 활성화하고, Tab으로 이웃 패널로 이동하고, Escape로 닫는다.

`Super + Ctrl + 1-9`는 자체 패널이 없는 트레이를 건너뛰고 오른쪽 섹션의 패널을 왼쪽에서 오른쪽으로 센다. 그래서 그 숫자가 가리킬 아이콘과 일치한다.

### Tailscale과 Dropbox

**Install → Service**에서 해당 서비스를 설치한 뒤에야 바에 나타나는 위젯이 두 개 더 있는데, 둘 다 상태 보고 이상의 일을 하므로 알아둘 가치가 있다.

**Tailscale** 패널은 tailnet을 연결하고 연결을 끊고, 계정을 전환하고, 종료 노드를 고른다(내 컴퓨터와 Mullvad 지역이 모두 그 목록에 나타난다). 또한 내 컴퓨터들을 탐색할 수도 있다 — 그중 하나를 선택한 상태에서 `s`를 누르면 Taildrop으로 파일을 보내는데, 이는 파일을 휴대폰이나 다른 노트북으로 옮기는 가장 빠른 방법이다. `c`는 그 컴퓨터의 IP를 복사하고, `n`은 이름, `d`는 전체 DNS 이름을 복사한다. 각 컴퓨터 줄마다 보내기 버튼도 있으니 클릭하는 쪽이 더 좋다면 그렇게 하면 된다. 터미널에서 같은 일을 하는 것은 `omarchy tailscale send <machine> [file...]`이다.

**Dropbox** 패널은 로그인을 처리하고, 저장 공간을 얼마나 사용했는지 보여주고, 최근에 동기화된 파일을 나열한다.

두 서비스 중 어느 하나라도 제거하면 그 위젯도 바에서 사라진다.

## 표시기

가운데에 있는 작은 무리가 표시기 위젯이다. 이는 켜둔 모드들을 위한 상태 글리프이다: 방해 금지, 야간 모드, 대기 중인 [리마인더](09-reminders.md), 활성화된 화면 녹화, 깨어 있기, 그리고 비밀번호 없는 sudo가 켜져 있거나 누군가 원격 세션에 연결되어 있을 때의 경고가 그것이다. 모드가 활성화되면 켜지고, 그렇지 않으면 방해가 되지 않게 물러나 있다 — 비활성 표시기가 있을 자리 바로 옆에 마우스를 올리면 그것들을 엿볼 수 있다. 표시기를 클릭하면 그 모드가 켜졌다 꺼졌다 한다. 상태 전용인 것이 하나 더 있다: 누군가 gliff를 통해 이 컴퓨터에 연결되어 있는 동안 원격 세션이 빨간색으로 켜진다.

항상 보이게 하고 싶다면, 위젯에서 `alwaysShow`를 `true`로 설정하라. 그리고 그중 일부만 신경 쓴다면, 원하는 것들을 `items`에 나열하라: `["Dnd", "Reminder", "NightLight"]`. 표시기 위젯은 둘 이상 가질 수 있으므로, 서로 다른 섹션에서 서로 다른 부분집합을 보여줄 수 있다.

## 바 재배열하기

바는 스스로를 구성한다. 무언가를 옮기기 위해 구성 파일을 열 필요가 없다.

가운데 주변의 빈 바 조각을 잡고 다른 화면 가장자리를 향해 끌면 바가 그곳으로 이동한다 — 왼쪽, 오른쪽, 위쪽, 아래쪽 모두 되며, 모든 위젯이 적응한다(세로 바는 간결한 아이콘 전용 형태로 대체된다). 클릭한 채로 유지하면 같은 끌기가 시작된다. 같은 빈 공간을 왼쪽 버튼으로 두 번 클릭하면 바 배경이 투명에서 유리 같은 질감으로, 불투명으로 순환한다. 그리고 어떤 위젯이든 끌어서 순서를 바꾸거나 다른 섹션으로 던져 넣으면, 다른 위젯들이 놓일 자리를 만들기 위해 양쪽으로 미끄러지며 벌어진다.

바의 가운데는 상자이다: 그 안에 있는 것은 한 그룹으로 가운데에 유지되고, 그 양쪽에 있는 위젯들은 그 가장자리에 매달린다. 위젯을 끌고 있는 동안 상자는 윤곽선으로 나타나거나, 비어 있을 때는 바를 가로지르는 선으로 나타나며, 그 안이나 그 옆에 떨어뜨릴 수 있다. 떨어뜨릴 위치가 상자 안에 있게 되면, 상자가 커져서 그 위젯을 받아들인다.

곁에 두고 싶지만 항상 보이게 하고 싶지는 않은 위젯은 트레이의 서랍에 넣을 수 있다: 위젯을 트레이 위로 끌면 서랍이 열려 그 위젯을 받아들인다. 그 위젯은 앱 아이콘 뒤에 그 자리에 앉아 서랍이 나타날 때마다 함께 나타나고, 자신의 패널이 떠 있는 동안에는 서랍을 열어둔다. 다시 바 위로 끌어내면 원래 자리로 돌아간다.

메뉴에서 고르는 편이 더 좋다면, **Appearance → Menu Bar**에 위치가 있고, **Bar Background**는 바가 그려지는 방식을 고른다: **Opaque Bar**, **Glassy Bar**(투명하며 뒤에 있는 것이 흐려진다), 또는 **Clear Bar**이다.

같은 것들에 명령도 있는데, 이는 [dotfiles](31-dotfiles.md) 설정을 원할 때 필요한 것이다:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

위젯을 완전히 추가하거나 제거하려면, 플러그인 명령을 사용하라. `omarchy plugin list`는 셀이 알고 있는 모든 위젯을 그 id와 함께 출력하고, 그 다음은:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## 바 숨기기

`Super + Shift + Space`는 셸을 죽이지 않고 바를 껐다가 다시 켠다 — 패널과 단축키는 계속 작동하고, 픽셀만 되찾을 뿐이다. 메뉴의 **Appearance → Menu Bar → Hide Bar**에도 있다.

## 구성 파일

모든 것은 `~/.config/omarchy/shell.json`에, `bar` 키 아래에 저장된다. 다음은 다듬어진 버전이다:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

모든 위젯은 다섯 개의 레이아웃 배열 중 하나에 있는 하나의 항목이며, 그 설정은 그 항목에 인라인으로 들어간다 — 별도의 설정 파일도 없고 `config` 하위 객체도 없다. 시계의 `format`, `formatAlt`(오른쪽 클릭으로 순환되는 대상), `verticalFormat`이 모두 바로 그 `{ "id": "omarchy.clock" }`에 산다.

`center`는 바 가운데에 있는 상자이다: 그 안에 있는 모든 것이 화면에 한 그룹으로 가운데 정렬된다. `centerBegin`과 `centerEnd`는 상자의 양쪽에 매달리는데, 날씨와 업데이트 배지가 오고 가도 시계가 정확히 가운데에 유지되는 방식이 바로 이것이다. `center`에 위젯을 둘 이상 넣으면 그것들이 함께 가운데 정렬되고; 비워두면 `centerBegin`과 `centerEnd`가 바 가운데에서 만난다.

내면화해둘 가치가 있는 규칙 하나: **자신만의 `shell.json`을 갖게 된 순간부터, 그것이 정본이다**. 어떤 것도 맞춤 설정하기 전까지는 셸이 Omarchy의 기본 파일을 읽는다. 위젯을 끌거나, `omarchy bar`를 실행하거나, 파일을 직접 편집하는 순간부터는 그 파일이 당신의 것이 된다 — 깊은 병합은 없으므로, 미래의 Omarchy 릴리스에 들어갈 새 기본 위젯이 바에 자동으로 나타나지는 않는다. 깨끗한 상태로 시작하고 싶을 때는 언제든 `omarchy bar defaults`가 출고 시 레이아웃을 되돌려준다.

같은 파일은 `bar` 키 바깥의 최상위 수준에 유휴 타이밍도 담고 있다: `idle.screensaver`와 `idle.lock`이며, 둘 다 유휴 상태가 된 뒤의 초 단위 시간이다. 그래서 기본 화면 보호기는 150초에, 잠금은 300초에 작동한다.
