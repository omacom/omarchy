# 상단 바

화면 상단을 따라 있는 띠가 Omarchy 바입니다. 덧붙인 상태 바가 아니라 Omarchy 셸의 일부입니다. 메뉴, 알림, OSD 팝업, 잠금 화면도 그리는 단일 장기 실행 Quickshell 프로세스입니다. 그래서 다른 모든 것과 완벽하게 테마가 맞고, 새 앱을 실행하는 대신 패널이 즉시 열립니다.

또한 항상 화면에 있는 유일한 데스크톱 요소이므로, 그 작은 글리프들이 모두 무엇을 하는지 알아 둘 가치가 있습니다.

## 기본적으로 무엇이 들어 있나

바에는 세 개의 섹션이 있습니다. 왼쪽에는 Omarchy 로고(메뉴 실행기)와 워크스페이스 표시기가 있습니다. 가운데에는 상태 표시기, 시계, Elsewhen(세계 시계), 날씨, Omarchy 업데이트 배지가 있습니다. 오른쪽에는 키보드 레이아웃(하나 이상 구성했을 때), 시스템 트레이, 에이전트, bluetooth, 네트워크, 오디오, 디스플레이, 전원이 있습니다.

그중 몇 가지는 말할 것이 있을 때만 나타납니다. 키보드 레이아웃은 레이아웃을 하나 이상 구성했을 때만 나타납니다. 업데이트 배지는 Omarchy 업데이트가 대기 중일 때만 나타납니다. 그리고 에이전트 아이콘은 Omarchy가 머신에서 AI 코딩 사용량을 처음 발견했을 때 나타납니다([AI](17-ai.md) 참조).

## 클릭 살펴보기

거의 모든 위젯이 왼쪽, 오른쪽, 가운데 클릭에 각각 반응하고, 여러 위젯이 스크롤에도 반응합니다. 사람들이 놓치는 부분입니다 — 좋은 것들 중 상당수가 오른쪽과 가운데 버튼에 숨어 있습니다.

| 위젯 | 왼쪽 | 오른쪽 | 가운데 / 스크롤 |
| --- | --- | --- | --- |
| 메뉴 | Omarchy 메뉴 | 새 터미널 | — |
| 워크스페이스 | 해당 워크스페이스로 포커스 | — | 스크롤: 다음/이전 워크스페이스 |
| 시계 | 달력 팝업 | 레이블 형식 순환 | 가운데: 시간대 선택기 |
| 날씨 | 예보 팝업 | 알림으로 전체 날씨 | 가운데: 새로고침 |
| 오디오 | 오디오 패널 | 음소거 | 가운데: 패널 · 스크롤: 볼륨 |
| 마이크 | 마이크 음소거 | — | 가운데: 오디오 패널 · 스크롤: 입력 볼륨 |
| 네트워크 | 네트워크 패널 | — | — |
| Bluetooth | Bluetooth 패널 | 라디오 토글 | — |
| 디스플레이 | 디스플레이 패널 | — | 스크롤: 밝기 |
| 전원 | 전원 패널 | 배터리 백분율 토글 | — |
| 미디어 | 재생/일시정지 | 커버 아트 팝업 | 가운데: 다음 · 스크롤: 이전/다음 |
| 에이전트 | 에이전트 패널 | 에이전트 실행 | 가운데: 다음 구독 |
| 트레이 | 마우스를 올리면 서랍 표시 | 셰브론을 오른쪽 클릭해 관리 | — |
| Omarchy 업데이트 | 업데이트 실행 | — | — |

표에 있는 모든 것이 기본 상태로 바에 있는 것은 아닙니다. 미디어 위젯(스크롤되는 트랙과 아티스트가 있는 MPRIS 재생 중)과 마이크 위젯은 둘 다 내장되어 있지만 기본적으로 꺼져 있습니다 — 원한다면 아래 설명대로 추가하세요.

## 패널

바 아이콘을 클릭하면 패널이 열립니다. 툴팁이 아니라 슬라이더, 목록, 키보드 탐색을 갖춘 제대로 된 팝업입니다. 각각 단축키도 있어 16픽셀짜리 글리프를 조준할 필요가 없습니다:

| 단축키 | 패널 |
| --- | --- |
| `Super + Ctrl + A` | 오디오 |
| `Super + Ctrl + W` | 네트워크 |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | 디스플레이 |
| `Super + Ctrl + P` | 전원 |
| `Super + Ctrl + Alt + D` | 달력 |
| `Super + Ctrl + Alt + E` | 세계 시계 |
| `Super + Ctrl + 1-9` | 오른쪽 섹션의 n번째 패널 토글 |

패널은 읽기 전용 표시가 아닙니다. 실제로 일을 하는 곳입니다:

- **오디오**에는 마스터 볼륨 슬라이더, 출력 장치 선택기, 앱별 믹서가 있어 다른 것은 건드리지 않고 브라우저 탭 하나의 소리를 줄일 수 있습니다.
- **네트워크**는 Wi-Fi를 스캔하고, 신호 강도를 보여 주며, 연결하고, DNS 공급자를 고르게 합니다.
- **Bluetooth**는 연결/연결 해제와 배터리 수준과 함께 장치를 나열합니다.
- **전원**은 배터리 통계를 보여 주고, 전원 프로필을 전환하며(배터리와 AC에 대해 별도의 선택을 기억합니다), 시스템 정보를 일부 출력합니다.
- **디스플레이**에는 밝기 슬라이더, 텍스트 크기, 모니터 배율 프리셋, 그리고 화면이 두 개 이상일 때 모니터별 컨트롤이 있습니다. 더 깊은 이야기는 [모니터](33-monitors.md)를 참조하세요.
- **시계**는 ISO 주차 번호와 월 이동이 있는 월별 그리드를 엽니다.

모든 패널은 마우스뿐 아니라 키보드도 지원합니다. 화살표로 이동하고, Return으로 활성화하며, Tab으로 인접한 패널로 이동하고, Escape로 닫습니다.

`Super + Ctrl + 1-9`는 오른쪽 섹션의 패널을 왼쪽에서 오른쪽 순서로 세며, 자체 패널이 없는 트레이는 건너뜁니다. 따라서 숫자가 가리키는 아이콘과 일치합니다.

### Tailscale와 Dropbox

두 가지 위젯이 더 바에 나타납니다. **설치 → 서비스**에서 해당 서비스를 설치한 뒤에만 나타나며, 둘 다 상태 보고 그 이상을 하므로 알아 둘 가치가 있습니다.

**Tailscale** 패널은 tailnet에 연결하고 연결을 해제하며, 계정 간에 전환하고, 종료 노드를 선택합니다(자신의 머신과 Mullvad 지역이 모두 그 목록에 표시됩니다). 머신 목록도 탐색합니다 — 하나를 선택한 상태에서 `s`를 누르면 Taildrop을 통해 파일을 전송하는데, 이는 휴대폰이나 다른 노트북으로 파일을 옮기는 가장 빠른 방법입니다. `c`는 머신의 IP를, `n`은 이름을, `d`는 전체 DNS 이름을 복사합니다. 클릭하고 싶다면 각 머신 행에도 전송 버튼이 있습니다. 터미널에서 같은 동작은 `omarchy tailscale send <machine> [file...]`입니다.

**Dropbox** 패널은 로그인을 처리하고, 사용한 스토리지 양을 보여 주며, 최근 동기화된 파일을 나열합니다.

어느 서비스를 제거하든 그 위젯은 바에서 사라집니다.

## 표시기

가운데의 작은 무리가 표시기 위젯입니다. 켜 둔 모드에 대한 상태 글리프입니다. 방해 금지, 야간 조명, 대기 중인 [리마인더](09-reminders.md), 활성 화면 녹화, 절전 금지, [받아쓰기](11-text-extraction-dictation.md)가 여기에 있습니다. 모드가 활성화되면 켜지고, 그렇지 않으면 눈에 띄지 않습니다 — 시계 왼쪽(수직 바에서는 위쪽)에 마우스를 올리면 비활성 항목들을 엿볼 수 있습니다. 표시기를 클릭하면 그 모드가 토글됩니다. 상태 전용인 것이 하나 더 있습니다. 원격 세션은 gliff를 통해 누군가 이 머신에 연결되어 있는 동안 빨간색으로 켜집니다.

항상 보이게 하고 싶다면 위젯에서 `alwaysShow`를 `true`로 설정하세요. 그리고 일부만 신경 쓴다면 원하는 항목을 `items`에 나열하세요: `["Dnd", "Reminder", "NightLight"]`. 표시기 위젯을 두 개 이상 둘 수 있으므로, 서로 다른 섹션이 서로 다른 부분집합을 보여 줄 수 있습니다.

## 바 재배열

바는 스스로를 구성합니다. 구성 파일을 열지 않고도 항목을 이동할 수 있습니다.

가운데 주변의 빈 바 부분을 잡아 다른 화면 가장자리 쪽으로 드래그하면 바가 그쪽으로 이동합니다 — 왼쪽, 오른쪽, 위쪽, 아래쪽 모두 작동하며, 모든 위젯이 적응합니다(수직 바는 간결한 아이콘 전용 형태로 대체됩니다). 클릭한 채로 길게 누르면 같은 드래그가 시작됩니다. 같은 빈 공간을 왼쪽 버튼으로 두 번 클릭하면 바 배경이 투명 → 유리질 → 불투명 순으로 순환합니다. 그리고 어느 위젯이든 드래그해 순서를 바꾸거나 다른 섹션으로 던질 수 있습니다.

가까이 두고 싶지만 항상 눈에 보일 필요는 없는 위젯은 트레이의 서랍에 넣을 수 있습니다. 트레이 위로 드래그하면 서랍이 열려 위젯을 받아 줍니다. 위젯은 앱 아이콘 뒤에 자리하며, 서랍이 나타날 때마다 함께 표시되고, 자신의 패널이 떠 있는 동안에는 서랍을 열린 채로 유지합니다. 바 위로 다시 드래그해서 꺼내면 되돌릴 수 있습니다.

메뉴에서 고르고 싶다면, **실행 → 모양 → 메뉴 막대**에 위치가 있고, **바 배경**에서 바가 그려지는 방식을 고릅니다: **불투명 바(Opaque Bar)**, **유리질 바(Glassy Bar)**(뒤에 있는 것이 흐려진 반투명), 또는 **투명 바(Clear Bar)**.

같은 항목들에게 명령도 있으며, 이는 [dotfiles](31-dotfiles.md) 설정을 원할 때 필요한 것입니다:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.clock --section center --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

위젯을 완전히 추가하거나 제거하려면 플러그인 명령을 사용하세요. `omarchy plugin list`는 셸이 아는 모든 위젯을 id와 함께 출력합니다. 그런 다음:

```bash
omarchy plugin enable omarchy.media --section center
omarchy plugin disable omarchy.weather
```

## 바 숨기기

`Super + Shift + Space`는 셸을 죽이지 않고 바를 끄고 다시 켭니다 — 패널과 단축키는 계속 작동하고, 픽셀만 돌려받는 셈입니다. 메뉴의 **실행 → 모양 → 메뉴 막대 → 막대 숨기기**에도 있습니다.

## 구성 파일

이 모든 것은 `~/.config/omarchy/shell.json`에 `bar` 키 아래에 저장됩니다. 간략화된 버전은 다음과 같습니다:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "centerAnchor": "omarchy.clock",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

모든 위젯은 세 개의 레이아웃 배열 중 하나의 항목이며, 그 설정은 그 항목 안에 인라인으로 들어가 있습니다 — 별도의 설정 파일도 없고 `config` 하위 객체도 없습니다. 시계의 `format`, `formatAlt`(오른쪽 클릭으로 순환), `verticalFormat`은 모두 `{ "id": "omarchy.clock" }` 바로 거기에 있습니다.

`centerAnchor`는 화면의 정확한 가운데에 고정되는 가운데 위젯 하나를 지정하고, 나머지는 그 양옆에 있습니다. 그래서 날씨와 업데이트 배지가 오가도 시계가 정중앙에 남습니다. 빈 문자열로 설정하면 가운데 목록이 그룹으로 가운데 정렬됩니다.

내면화해 둘 가치가 있는 규칙 하나: **자신의 `shell.json`을 갖는 순간, 그 파일이 정본입니다.** 아무것도 사용자 지정하지 않는 한 셸은 Omarchy의 기본 파일을 읽습니다. 위젯을 드래그하거나, `omarchy bar`를 실행하거나, 파일을 직접 편집하는 순간, 그 파일은 여러분의 것입니다 — 깊은 병합은 없으므로, 향후 Omarchy 릴리스의 새 기본 위젯은 바에 자동으로 나타나지 않습니다. 깨끗한 상태로 돌아가고 싶을 때면 언제든 `omarchy bar defaults`로 출고 시 레이아웃을 복원할 수 있습니다.

같은 파일은 최상위 수준에서 `bar` 키 밖으로 유휴(idle) 타이밍도 보관합니다. `idle.screensaver`와 `idle.lock`은 모두 유휴 상태가 된 이후의 초 단위 값입니다. 따라서 기본 화면 보호기는 150초에, 잠금은 300초에 시작됩니다.
