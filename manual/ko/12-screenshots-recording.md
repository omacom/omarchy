# 스크린샷 및 녹화

화면에서 가져올 수 있는 모든 것은 Print Screen 키에 달려 있습니다. 키 하나만으로는 사진을 찍고, 수정자 키들과 함께면 녹화, 색상, 또는 영역 안의 텍스트를 가져옵니다. 키보드에 Print Screen 키가 아예 없다면, `Super + Ctrl + C`가 같은 집합을 메뉴로 엽니다.

| 단축키 | 기능 |
| ------ | -------- |
| `Print Screen` | 스크린샷 |
| `Alt + Print Screen` | 화면 녹화(또는 실행 중인 녹화 중지) |
| `Super + Print Screen` | 색상 선택기 |
| `Super + Ctrl + Print Screen` | 영역에서 텍스트 추출 |
| `Super + Ctrl + C` | 캡처 메뉴 |
| `Super + Ctrl + .` | 사진 또는 동영상 트랜스코딩 |

## 스크린샷

`Print Screen`을 누르면 Omasnap이 오버레이가 나타나기 전에 포커스된 모니터를 캡처하므로, 조준하는 동안 밑에서 아무것도 움직이지 않습니다. 자유형 영역을 드래그하거나, 창을 클릭해 캡처하거나, 빈 공간을 클릭해 전체 모니터를 캡처하세요. 그리기 전에 `S`를 누르면 스크롤되는 영역을 캡처합니다. 마음이 바뀌었나요? `Print Screen`을 다시 누르면 Omasnap이 닫힙니다.

영역을 선택한 뒤 Omasnap은 캡처를 저장하고, 클립보드에 복사하며, 10초간 미리보기를 보여 줍니다. 미리보기의 핀 버튼이나 `Ctrl + P`를 사용해 화면에 유지하거나, 편집(Edit)을 선택해 주석을 달 수 있습니다.

주석 편집기는 화살표, 선, 도형, 하이라이트, 번호 마커, 텍스트, 안전한 편집(redaction)을 그릴 수 있고, 이미지 일부를 자르거나 잘라낼 수 있으며, 텍스트를 OCR하고, 배경을 추가할 수 있습니다. 편집기에서 `Enter`를 누르면 완성된 PNG를 복사하고 저장하며, `Ctrl + C`를 누르면 저장하지 않고 복사하고, `Ctrl + S`를 누르면 복사하지 않고 저장합니다.

저장된 스크린샷은 기본적으로 `~/Pictures/Screenshots`에 `screenshot-2026-08-13_14-22-05-firefox.png` 같은 이름으로 저장됩니다. 다른 디렉터리를 사용하려면 `OMASNAP_SCREENSHOT_DIR`을 설정하세요 — 세션 환경 변수를 어디에 두는지는 [FAQ](46-faq.md)를 참조하세요. Omasnap은 첫 번째 스크린샷을 저장할 때 디렉터리를 만듭니다. 자동 저장을 끄려면 `~/.config/omasnap/omasnap.conf`에서 `[output] autosave = false`로 설정하세요.

터미널에서 `omarchy screenshot`은 같은 오버레이를 열고, 시작 모드를 선택할 수 있습니다: `omarchy capture screenshot region`, `windows`, `fullscreen`, 또는 `scroll`. 두 번째 인수 `copy`나 `save`를 주면 미리보기를 건너뛰고 스크린샷을 해당 대상으로 바로 보냅니다. 출력 전에 편집하려면 전체 화면 편집기에 대해 `omarchy screenshot --editor=overlay`를, 별도 창에 대해 `omarchy screenshot --editor=window`를 사용하세요.

### 키보드에서 선택기 조작하기

선택 영역 표시가 떠 있는 동안 마우스를 전혀 쓰지 않아도 됩니다:

| 키 | 기능 |
| --- | -------- |
| `S` | 스크롤 영역 모드 토글 |
| `Super + Arrow keys` | Window 모드에서 창 사이 이동 |
| `Return` | 강조된 창 캡처 |
| `Ctrl + A` | 포커스된 전체 모니터 캡처 |
| `R` | 이 세션에서 그린 마지막 영역 복원 |
| `Esc` | Omasnap 닫기 |

이 바인딩들은 Omasnap이 열려 있을 때만 존재하므로, 사용자 구성의 어떤 것과도 충돌할 수 없습니다.

## 화면 녹화

`Alt + Print Screen`은 _실행 > 캡처 > 화면 녹화_를 열며, 사운드트랙에 무엇을 원하는지 묻습니다. 오디오 없음, 데스크톱 오디오, 데스크톱 + 마이크, 또는 데스크톱 + 마이크 + 웹캠이 있습니다. 마지막 항목은 카메라가 실제로 연결되어 있을 때만 나타납니다. 하나를 고르면 Omarchy의 녹화 선택기로 영역을 드래그하거나 창이나 모니터를 클릭할 수 있습니다.

녹화는 gpu-screen-recorder를 이용해 실행되며, 60fps로 GPU에서 인코딩하고 필요하면 CPU로 대체합니다. 결과는 `~/Videos`에 `screenrecording-2026-08-13_14-22-05.mp4`라는 이름의 MP4입니다. `OMARCHY_SCREENRECORD_DIR`을 설정해 변경하세요 — 단, 스크린샷 디렉터리와 달리 이 디렉터리는 이미 존재해야 하며, 그렇지 않으면 녹화를 시작하지 않는다는 점에 유의하세요.

녹화 중에는 작은 표시기가 바에 나타납니다. 클릭하면 중지됩니다. `Alt + Print Screen`을 다시 눌러 중지하거나, _실행 > 캡처 > 화면 녹화_ 아래에 실제로 녹화 중일 때만 나타나는 _화면 녹화 중지(Stop Screenrecording)_ 항목으로 중지할 수도 있습니다.

중지를 누르면 파일이 전달되기 전에 약간의 정리를 합니다. 첫 프레임이 다듬어지고, 오디오가 있으면 -14 LUFS로 정규화되며 맨 처음에 있는 PipeWire 캡처 팝 소리는 음소거됩니다. 그런 다음 녹화에서 가져온 썸네일과 함께 알림이 나타납니다. 클릭하면 mpv에서 파일이 재생됩니다.

### 웹캠 오버레이

웹캠으로 녹화하면 카메라가 녹화 중인 화면의 오른쪽 아래 모서리에 고정되고 잘린 인물 창으로 나타납니다. 필요한 것 위에 얹혀 있다면 즉시 크기를 조정할 수 있습니다:

| 단축키 | 기능 |
| ------ | -------- |
| `Super + Alt + [` | 웹캠 오버레이를 작게 만들기 |
| `Super + Alt + ]` | 웹캠 오버레이를 크게 만들기 |

크기는 작게, 중간, 크게 세 가지이며 단축키는 그 사이를 이동합니다. 중간이 기본값입니다. 녹화에 비례하므로 1080p 모니터를 녹화하든 6K 모니터를 녹화하든 카메라가 프레임에서 차지하는 비중은 같습니다. 그리고 전체 디스플레이가 아니라 영역을 녹화했다면 오버레이는 모니터 모서리가 아니라 그 영역의 모서리에 고정되므로 화면 안에 남습니다.

`omarchy-capture-webcam-resize small`로 직접 호출하거나, `reset`으로 중간 크기로 돌아갈 수도 있습니다.

## 텍스트, QR 코드, 색상

`Super + Ctrl + Print Screen`은 영역을 선택해 클립보드에 OCR합니다. 그 내용은 [텍스트 추출 및 받아쓰기](11-text-extraction-dictation.md)에서 제대로 다룹니다.

_실행 > 캡처 > QR 코드_는 QR 코드에 대해 같은 기술을 사용합니다. 코드가 있는 영역을 선택하면 디코딩된 값이 클립보드로 갑니다. QR 코드만 찾습니다 — 빽빽한 화면 내용은 그렇지 않으면 바코드로 오인되는 경향이 있습니다. 알아 둘 점: 디코딩된 값은 클립보드로만 가고 다른 곳에는 가지 않습니다. 출력되지도 않고, 알림에도 없으며, 민감한 것으로 표시되어 [클립보드 히스토리](08-unified-clipboard-history.md)에 남지 않습니다. QR 코드는 일상적으로 비밀을 담고 있습니다 — 예를 들어 2FA 설정 코드 뒤의 `otpauth://` URI — 로그에 남는 것은 원치 않을 것입니다. 붙여넣기는 여전히 잘 작동합니다.

`Super + Print Screen`(또는 _실행 > 캡처 > 색상_)은 커서를 스포이트로 바꿉니다. 화면의 무엇이든 클릭하면 색상이 클립보드에 올라갑니다. 단축키를 다시 누르면 선택하지 않고 빠져나갑니다.

## 공유하기 전에 트랜스코딩하기

4K 화면 녹화나 휴대폰의 원본 HEIC는 그냥 보내기에는 너무 큰 경우가 많습니다. `Super + Ctrl + .`(또는 _실행 > 트랜스코딩_)이 그 문제를 해결합니다. `~/Pictures`와 `~/Videos`에 대한 퍼지 파일 선택기를 제공한 다음 형식과 크기를 묻습니다.

사진은 높음, 중간, 낮음으로 jpg나 png가 되며, 너비는 3160, 2160, 1080픽셀에서 최대화됩니다. 동영상은 4k, 1080p, 720p로 mp4나 애니메이션 gif가 됩니다. 변환된 파일은 이름에 해상도가 들어간 채 원본 옆에 쓰이며 — `demo-1080p.mp4` — 경로는 파일 URI로 클립보드에 복사되므로 파일 드롭을 받는 앱에 직접 붙여넣을 수 있습니다.

이미 원하는 것을 안다면 터미널에서도 작동합니다: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. 이미지를 ASCII 아트로 바꾸는 `omarchy transcode ascii`도 있습니다 — 이건 주로 [브랜딩](41-branding.md)을 위한 것입니다.
