# 스크린샷 및 녹화

화면에서 가져올 수 있는 모든 것은 Print Screen 키에 달려 있다. 이 키 하나만 누르면 사진을 찍고, 수정자 키와 함께 누르면 녹화, 색상, 또는 영역 안의 텍스트를 가져온다. 키보드에 Print Screen 키가 아예 없다면 `Super + Ctrl + Alt + C`로 같은 스크린샷을 찍고, `Super + Ctrl + C`로 전체 세트를 메뉴로 연다.

| 단축키 | 기능 |
| ------ | -------- |
| `Print Screen` | 스크린샷 |
| `Super + Ctrl + Alt + C` | 스크린샷 |
| `Alt + Print Screen` | 화면 녹화 (또는 실행 중인 녹화 중지) |
| `Super + Print Screen` | 색상 피커 |
| `Super + Ctrl + Print Screen` | 영역에서 텍스트 추출 |
| `Super + Ctrl + C` | 캡처 메뉴 |
| `Super + Ctrl + .` | 사진 또는 동영상 트랜스코딩 |

## 스크린샷

`Print Screen`(또는 `Super + Ctrl + Alt + C`)을 누르면 Omasnap이 오버레이가 나타나기 전에 포커스된 모니터를 캡처하므로, 조준하는 동안 아래쪽이 밀리지 않는다. 자유형 영역을 드래그하거나, 창을 클릭해 해당 창을 캡처하거나, 빈 공간을 클릭해 모니터 전체를 캡처한다. 그리기 전에 `S`를 누르면 스크롤 영역을 캡처한다. 마음이 바뀌었는가? 같은 키를 다시 누르면 Omasnap이 닫힌다.

영역을 선택하면 Omasnap이 캡처를 저장하고 클립보드에 복사한 뒤, 저장된 화면 녹화가 그러하듯이 썸네일이 담긴 알림을 보여준다. Open을 선택하면 이미지 뷰어에서 저장된 사진을 보고, Edit을 선택하면 주석을 단다.

주석 편집기에서는 화살표, 선, 도형, 강조 표시, 번호 매긴 마커, 텍스트, 안전한 가림 처리를 그릴 수 있고, 이미지의 일부를 자르거나 잘라낼 수 있으며, 텍스트를 OCR하고, 배경을 추가할 수 있다. 편집기에서 `Enter`를 누르면 완성된 PNG를 복사하고 저장하고, `Ctrl + C`를 누르면 저장하지 않고 복사하며, `Ctrl + S`를 누르면 복사하지 않고 저장한다.

저장된 스크린샷은 기본적으로 `~/Pictures/Screenshots`에 들어가며, 이름은 `screenshot-2026-08-13_14-22-05-firefox.png`와 같은 식이다. 다른 디렉터리를 쓰려면 `OMASNAP_SCREENSHOT_DIR`를 설정한다 — 세션 환경 변수를 어디에 넣어야 하는지는 [FAQ](46-faq.md)를 참조한다. Omasnap은 첫 사진을 저장할 때 디렉터리를 만든다. 자동 저장을 끄려면 `~/.config/omasnap/omasnap.conf`에 `[output] autosave = false`를 설정한다. 그러면 캡처는 복사만 되고, 핀 버튼이나 `Ctrl + P`로 화면에 고정해 둘 수 있는 미리보기로 7초 동안 표시된다.

터미널에서 `omarchy screenshot`을 실행하면 같은 오버레이가 열리고, 시작 모드를 선택할 수 있다: `omarchy capture screenshot region`, `windows`, `fullscreen`, 또는 `scroll`. 두 번째 인자로 `copy` 또는 `save`를 주면 사진이 곧바로 해당 대상으로 보내진다. 출력 전에 편집하려면 전체 화면 편집기에는 `omarchy screenshot --editor=overlay`를, 별도 창에는 `omarchy screenshot --editor=window`를 사용한다.

### 키보드로 피커 조작하기

선택 화면이 떠 있는 동안 마우스를 전혀 쓸 필요가 없다:

| 키 | 기능 |
| --- | -------- |
| `S` | 스크롤 영역 모드 전환 |
| `Super + Arrow keys` | Window 모드에서 창 사이 이동 |
| `Return` | 강조 표시된 창 캡처 |
| `Ctrl + A` | 포커스된 모니터 전체 캡처 |
| `R` | 이 세션에서 마지막으로 그린 영역 복원 |
| `Esc` | Omasnap 닫기 |

이 바인딩은 Omasnap이 열려 있을 때만 존재하므로, 자신의 설정과 충돌할 일이 없다.

## 화면 녹화

`Alt + Print Screen`을 누르면 _Trigger > Capture > Screenrecord_가 열리고, 사운드트랙에 무엇을 넣을지 묻는다: 오디오 없음, 데스크톱 오디오, 데스크톱 + 마이크, 또는 데스크톱 + 마이크 + 웹캠. 마지막 항목은 실제로 카메라가 연결되어 있을 때만 나타난다. 하나를 선택하면 Omarchy의 녹화 피커에서 영역을 드래그하거나 창이나 모니터를 클릭할 수 있다.

녹화는 gpu-screen-recorder로 실행되며, GPU에서 60fps로 인코딩하고 필요하면 CPU로 대체된다. Apple Silicon처럼 지원하지 않는 GPU에서는 대신 wf-recorder로 녹화한다. 결과물은 `~/Videos`에 들어가는 MP4이며, 이름은 `screenrecording-2026-08-13_14-22-05.mp4`와 같다. 바꾸려면 `OMARCHY_SCREENRECORD_DIR`를 설정한다 — 단, 스크린샷 디렉터리와 달리 이 디렉터리는 미리 존재해야 하며, 그렇지 않으면 녹화가 시작을 거부한다는 점에 유의한다.

녹화 중에는 바에 작은 표시기가 나타난다. 클릭하면 중지된다. `Alt + Print Screen`을 다시 눌러 중지할 수도 있고, _Trigger > Capture > Screenrecord_ 아래의 _Stop Screenrecording_ 항목으로 중지할 수도 있는데, 이 항목은 실제로 녹화 중일 때만 나타난다.

중지를 하면 파일을 건네기 전에 약간의 정리를 한다: 첫 프레임이 잘리고, 오디오가 있으면 -14 LUFS로 정규화되며, 맨 처음에 있는 PipeWire 캡처 팝 소리는 음소거된다. 그런 다음 녹화에서 가져온 썸네일과 함께 알림이 나타난다. _Open_을 선택하면 Omaview에서 파일을 재생하고, _Cut_을 선택하면 Omacut에서 다듬는다.

### 웹캠 오버레이

웹캠으로 녹화하면 카메라는 녹화 중인 화면의 오른쪽 아래 모서리에 고정된, 잘린 세로 창 형태로 나타난다. 필요한 것 위에 겹쳐 있다면 즉시 크기를 바꿀 수 있다:

| 단축키 | 기능 |
| ------ | -------- |
| `Super + Alt + [` | 웹캠 오버레이 작게 만들기 |
| `Super + Alt + ]` | 웹캠 오버레이 크게 만들기 |

크기는 작음, 중간, 큼 세 가지가 있고, 단축키로 그 사이를 오간다. 중간이 기본값이다. 크기는 녹화에 비례하므로, 1080p 모니터를 녹화하든 6K 모니터를 녹화하든 카메라가 프레임에서 차지하는 비율은 같다. 그리고 전체 디스플레이가 아니라 영역을 녹화했다면 오버레이는 모니터가 아니라 해당 영역의 모서리에 고정되므로, 사진 안에 그대로 들어간다.

`omarchy-capture-webcam-resize small`로 직접 호출할 수도 있고, `reset`으로 중간으로 돌아갈 수도 있다.

## 텍스트, QR 코드, 색상

`Super + Ctrl + Print Screen`은 영역을 선택하고 OCR한 결과를 클립보드에 넣는다. 이는 [텍스트 추출 및 받아쓰기](11-text-extraction-dictation.md)에서 제대로 다룬다.

_Trigger > Capture > QR Code_는 QR 코드로 같은 요령을 부린다. 코드가 들어 있는 영역을 선택하면 디코딩된 값이 클립보드에 들어간다. QR 코드만 찾는다 — 그렇지 않으면 빽빽한 화면 내용이 바코드로 오인되는 일이 잦기 때문이다. 알아둘 만한 점: 디코딩된 값은 클립보드로만 가고 다른 곳으로는 가지 않는다. 출력되지도 않고, 알림에도 들어가지 않으며, 민감한 정보로 표시되어 [클립보드 기록](08-unified-clipboard-history.md)에 남아 있지 않는다. QR 코드는 일상적으로 비밀을 담고 있다 — 예를 들어 2FA 설정 코드 뒤에 있는 `otpauth://` URI가 그렇다 — 그런 것이 로그에 남는 것은 원치 않을 것이다. 붙여넣기는 여전히 문제없이 된다.

`Super + Print Screen`(또는 _Trigger > Capture > Color_)을 누르면 커서가 스포이트로 바뀐다. 화면의 아무것이나 클릭하면 색상이 클립보드에 들어간다. 단축키를 다시 누르면 선택하지 않고 빠져나온다.

## 공유하기 전에 트랜스코딩하기

4K 화면 녹화나 휴대폰에서 가져온 원본 HEIC는 그냥 보내기에는 너무 큰 경우가 많다. `Super + Ctrl + .`(또는 _Trigger > Transcode_)가 이를 해결한다. `~/Pictures`와 `~/Videos`에 대한 퍼지 파일 피커를 보여준 뒤, 형식과 크기를 묻는다.

사진은 jpg 또는 png로 높음, 중간, 낮음 중 하나로 변환되며, 너비는 각각 최대 3160, 2160, 1080픽셀로 제한된다. 동영상은 mp4 또는 애니메이션 gif로 4k, 1080p, 720p 중 하나로 변환된다. 변환된 파일은 원본 옆에 해상도가 이름에 들어간 채로 기록된다 — `demo-1080p.mp4` — 그리고 경로는 파일 URI로 클립보드에 복사되므로, 파일 드롭을 받는 앱에 바로 붙여넣을 수 있다.

터미널에서도 되며, 원하는 것을 이미 알고 있다면 `omarchy transcode ~/Videos/demo.mov mp4 1080p`와 같이 실행한다. `omarchy transcode ascii`도 있는데, 이미지를 ASCII 아트로 바꾼다 — 이쪽은 주로 [브랜딩](41-branding.md)을 위한 것이다.

## 어딘가로 보내기

파일을 얻었다면 `Super + Ctrl + S`로 Share 메뉴를 열어 LocalSend를 통해 네트워크상의 다른 기기로 보낸다. 자세한 내용은 [GUI](22-guis.md)를 참조한다.
