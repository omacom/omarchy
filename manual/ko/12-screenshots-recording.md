# 스크린샷 및 녹화

화면에서 캡처할 수 있는 모든 기능은 Print Screen 키에 달려 있다. 이 키 하나만 누르면 사진을 찍고, 조합 키를 함께 누르면 녹화, 색상, 또는 영역 안의 텍스트를 가져온다. 키보드에 Print Screen 키가 아예 없다면 `Super + Ctrl + Alt + C`로 같은 스크린샷을 찍을 수 있고, `Super + Ctrl + C`로 전체 세트를 메뉴로 열 수 있다.

| 단축키 | 기능 |
| ------ | -------- |
| `Print Screen` | 스크린샷 |
| `Super + Ctrl + Alt + C` | 스크린샷 |
| `Alt + Print Screen` | 화면 녹화 (또는 실행 중인 녹화 중지) |
| `Super + Print Screen` | 색상 선택기 |
| `Super + Ctrl + Print Screen` | 영역에서 텍스트 추출 |
| `Super + Ctrl + C` | 캡처 메뉴 |
| `Super + Ctrl + .` | 사진 또는 동영상 트랜스코딩 |

## 스크린샷

`Print Screen`(또는 `Super + Ctrl + Alt + C`)을 누르면 Omasnap이 오버레이가 나타나기 전에 포커스된 모니터를 캡처하므로, 조준하는 동안 화면이 아래에서 밀릴 일이 없다. 자유형 영역을 드래그하거나, 창을 클릭해 해당 창을 캡처하거나, 빈 공간을 클릭해 모니터 전체를 캡처한다. 그리기 전에 `S`를 누르면 스크롤 영역을 캡처한다. 마음이 바뀌었는가? 같은 키를 다시 누르면 Omasnap이 닫힌다.

영역을 선택하면 Omasnap이 캡처를 저장하고 클립보드에 복사한 뒤, 저장된 화면 녹화처럼 썸네일이 있는 알림을 보여준다. Open을 선택하면 이미지 뷰어에서 저장된 사진을 보고, Edit를 선택하면 주석을 단다.

주석 편집기에서는 화살표, 선, 도형, 강조 표시, 번호 매긴 마커, 텍스트, 보안 삭제 표시를 그릴 수 있고, 이미지의 일부를 자르거나 잘라낼 수 있으며, 텍스트를 OCR하고, 배경을 추가할 수 있다. 편집기에서 `Enter`를 누르면 완성된 PNG를 복사하고 저장하고, `Ctrl + C`를 누르면 저장하지 않고 복사하며, `Ctrl + S`를 누르면 복사하지 않고 저장한다.

저장된 스크린샷은 기본적으로 `~/Pictures/Screenshots`에 저장되며, 이름은 `screenshot-2026-08-13_14-22-05-firefox.png`와 같다. 다른 디렉터리를 사용하려면 `OMASNAP_SCREENSHOT_DIR`를 설정한다 — 세션 환경 변수를 어디에 넣어야 하는지는 [FAQ](46-faq.md)를 참조한다. Omasnap은 첫 번째 사진을 저장할 때 디렉터리를 만든다. 자동 저장을 끄려면 `~/.config/omasnap/omasnap.conf`에서 `[output] autosave = false`를 설정한다. 그러면 캡처는 복사만 되고, 핀 버튼이나 `Ctrl + P`로 화면에 고정할 수 있는 10초짜리 미리보기로 표시된다.

터미널에서 `omarchy screenshot`을 실행하면 같은 오버레이가 열리고 시작 모드를 선택할 수 있다: `omarchy capture screenshot region`, `windows`, `fullscreen`, 또는 `scroll`. 두 번째 인자로 `copy` 또는 `save`를 주면 사진이 해당 대상으로 바로 전송된다. 출력 전에 편집하려면 전체 화면 편집기에는 `omarchy screenshot --editor=overlay`를, 별도 창에는 `omarchy screenshot --editor=window`를 사용한다.

### 키보드로 선택기 조작하기

선택 화면이 떠 있는 동안에는 마우스를 전혀 쓸 필요가 없다:

| 키 | 기능 |
| --- | -------- |
| `S` | 스크롤 영역 모드 전환 |
| `Super + Arrow keys` | Window 모드에서 창 사이 이동 |
| `Return` | 강조 표시된 창 캡처 |
| `Ctrl + A` | 포커스된 모니터 전체 캡처 |
| `R` | 이번 세션에서 마지막으로 그린 영역 복원 |
| `Esc` | Omasnap 닫기 |

이러한 바인딩은 Omasnap이 열려 있는 동안에만 존재하므로, 사용자 설정과 충돌할 일이 없다.

## 화면 녹화

`Alt + Print Screen`을 누르면 _Trigger > Capture > Screenrecord_가 열리고 사운드트랙에 무엇을 넣을지 묻는다: 오디오 없음, 데스크톱 오디오, 데스크톱과 마이크, 또는 데스크톱과 마이크와 웹캠. 마지막 항목은 카메라가 실제로 연결되어 있을 때만 나타난다. 하나를 선택하면 Omarchy의 녹화 선택기로 영역을 드래그하거나 창이나 모니터를 클릭할 수 있다.

녹화는 gpu-screen-recorder로 실행되며, GPU에서 60fps로 인코딩하고 필요하면 CPU로 대체한다. 결과물은 `~/Videos`에 있는 MP4로, 이름은 `screenrecording-2026-08-13_14-22-05.mp4`이다. 변경하려면 `OMARCHY_SCREENRECORD_DIR`를 설정한다 — 단, 스크린샷 디렉터리와 달리 이 디렉터리는 미리 존재해야 하며, 그렇지 않으면 녹화가 시작을 거부한다는 점에 유의한다.

녹화 중에는 바에 작은 표시기가 나타난다. 클릭하면 중지된다. `Alt + Print Screen`을 다시 눌러 중지할 수도 있고, 실제로 녹화 중일 때만 나타나는 _Trigger > Capture > Screenrecord_ 아래의 _Stop Screenrecording_ 항목으로 중지할 수도 있다.

중지하면 파일을 건네기 전에 약간의 정리를 한다: 첫 번째 프레임이 잘리고, 오디오가 있으면 -14 LUFS로 정규화되며 맨 처음의 PipeWire 캡처 팝음이 음소거된다. 그런 다음 녹화에서 가져온 썸네일이 있는 알림이 나타난다. 클릭하면 Omaview에서 파일이 재생된다.

### 웹캠 오버레이

웹캠으로 녹화하면 카메라는 녹화 중인 화면의 오른쪽 아래 모서리에 고정되고 잘린 세로 창 형태로 나타난다. 필요한 콘텐츠를 가리고 있다면 즉시 크기를 조정한다:

| 단축키 | 기능 |
| ------ | -------- |
| `Super + Alt + [` | 웹캠 오버레이 작게 만들기 |
| `Super + Alt + ]` | 웹캠 오버레이 크게 만들기 |

크기는 작게, 중간, 크게의 세 가지가 있으며 단축키로 단계를 오간다. 중간이 기본값이다. 크기는 녹화에 비례하므로, 1080p 모니터를 녹화하든 6K 모니터를 녹화하든 카메라는 프레임에서 같은 비율을 차지한다. 그리고 전체 디스플레이가 아닌 영역을 녹화한 경우 오버레이는 모니터가 아닌 해당 영역의 모서리에 고정되므로 사진 안에 그대로 들어간다.

`omarchy-capture-webcam-resize small`로 직접 호출할 수도 있고, `reset`으로 중간으로 돌아갈 수도 있다.

## 텍스트, QR 코드 및 색상

`Super + Ctrl + Print Screen`은 영역을 선택하고 OCR 결과를 클립보드에 넣는다. 이는 [텍스트 추출 및 받아쓰기](11-text-extraction-dictation.md)에서 제대로 다룬다.

_Trigger > Capture > QR Code_는 QR 코드에 대해 같은 작업을 한다. 코드가 있는 영역을 선택하면 디코딩된 값이 클립보드로 간다. QR 코드만 찾는다 — 빽빽한 화면 콘텐츠는 그렇지 않으면 바코드로 오인되는 경우가 많기 때문이다. 알아둘 만한 점: 디코딩된 값은 클립보드로만 가고 다른 곳으로는 가지 않는다. 출력되지 않고, 알림에도 없으며, 민감한 것으로 표시되어 [클립보드 기록](08-unified-clipboard-history.md)에 남아 있지 않는다. QR 코드에는 일상적으로 비밀이 들어 있다 — 예를 들어 2FA 설정 코드 뒤의 `otpauth://` URI가 그렇다 — 그런 것이 로그에 남는 것은 원치 않을 것이다. 붙여넣기는 여전히 잘 된다.

`Super + Print Screen`(또는 _Trigger > Capture > Color_)을 누르면 커서가 스포이트로 바뀐다. 화면에서 아무것이나 클릭하면 색상이 클립보드에 들어간다. 단축키를 다시 누르면 선택하지 않고 빠져나온다.

## 공유하기 전에 트랜스코딩하기

4K 화면 녹화나 휴대폰에서 가져온 원본 HEIC는 그냥 보내기에는 너무 큰 경우가 많다. `Super + Ctrl + .`(또는 _Trigger > Transcode_)가 이를 해결한다. `~/Pictures`와 `~/Videos`에 대한 퍼지 파일 선택기를 제공한 다음 형식과 크기를 묻는다.

사진은 높음, 중간, 낮음으로 jpg 또는 png가 되며, 너비는 각각 3160, 2160, 1080 픽셀로 제한된다. 동영상은 4k, 1080p, 720p로 mp4 또는 애니메이션 gif가 된다. 변환된 파일은 원본 옆에 해상도가 이름에 포함되어 작성된다 — `demo-1080p.mp4` — 그리고 경로는 파일 URI로 클립보드에 복사되므로 파일을 드롭할 수 있는 앱에 직접 붙여넣을 수 있다.

무엇을 원하는지 이미 알고 있다면 터미널에서도 된다: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. 이미지를 ASCII 아트로 바꾸는 `omarchy transcode ascii`도 있다 — 이는 주로 [브랜딩](41-branding.md)용이다.

## 어딘가로 보내기
