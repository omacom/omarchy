# 시스템 절전

Omarchy는 기본적으로 일시 중단과 최대 절전 모드를 활성화하지만, 사용 중인 기기에서 둘 중 하나라도 문제가 발생하면 꺼둘 수 있습니다.

DGX Spark와 ASUS Ascent GX10 같은 NVIDIA GB10 기기에서는 NVIDIA의 DGX OS에서와 마찬가지로 일시 중단과 최대 절전 모드가 꺼져 있습니다. 해당 하드웨어에서는 아직 절전 모드가 제대로 작동하는 것이 확인되지 않았기 때문입니다. ASUS Zenbook A16 (UX3607OA)도 마찬가지인데, 이 기기에서는 일시 중단 시 칩이 완전히 절전 상태로 전환되지 않아 밤새 멈춰 버릴 수 있습니다. 일시 중단 토글과 최대 절전 모드 설정은 이 기기들에는 적용되지 않습니다. 절전 모드를 다시 켜려면 `sudo rm`으로 `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf`를 삭제하세요. 그러면 일시 중단이 메뉴에 다시 나타나고, 다른 기기와 마찬가지로 최대 절전 모드를 설정할 수 있습니다. `sudo omarchy apply hardware --install-user "$USER"`를 실행하면 해당 파일이 다시 생성됩니다.

### 전원 프로필

노트북에서는 Omarchy가 전원에 연결된 상태와 배터리로 실행 중인 상태의 전원 프로필을 각각 따로 기억하고, 전원을 연결하거나 분리할 때마다 두 상태 사이를 전환합니다. 기본 설정에서는 AC 전원에서는 performance, 배터리에서는 balanced가 적용됩니다.

`omarchy powerprofiles list`로 사용 중인 기기에서 제공하는 프로필을 확인할 수 있고, `omarchy powerprofiles set autodetect power-saver`로 현재 상태에 대해 원하는 프로필을 설정할 수 있습니다. 아무것도 분리하지 않고 다른 상태의 프로필을 설정하려면 상태를 직접 지정하세요: `omarchy powerprofiles set battery power-saver`. 선택한 프로필은 다음에 해당 상태가 되었을 때 그대로 다시 적용됩니다.

### 일시 중단 토글

터미널에서 `omarchy toggle suspend`를 실행해 일시 중단을 토글합니다. 이 명령은 _시스템_ (또는 `Super + Esc`) 아래의 옵션을 표시/숨기기만 하며, 이를 통해 시스템에서 일관되게 작동하는지 확인할 수 있습니다. 제대로 작동하지 않으면 같은 명령으로 다시 숨길 수 있습니다.

### 최대 절전 모드 토글

터미널에서 `omarchy hibernation setup`를 실행해 최대 절전 모드를 설정합니다. 최대 절전 모드는 부팅 드라이브에 실제 RAM 할당량과 같은 크기의 /swap 서브볼륨을 생성하므로, 여유 공간이 충분한지 반드시 확인하세요. 32GB 기기에서는 이 볼륨을 위해 항상 32GB 이상의 여유 공간이 필요합니다. 최대 절전 모드를 사용하려면 기본 Limine 부트로더도 필요합니다.

설정이 완료되면 _시스템_ (또는 `Super + Esc`) 아래에 최대 절전 모드 옵션이 표시되며, 이를 통해 시스템에서 일관되게 작동하는지 확인할 수 있습니다. 제대로 작동하지 않으면 `omarchy hibernation remove`를 실행해 다시 제거할 수 있습니다.
