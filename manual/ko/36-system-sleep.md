# 시스템 절전

Omarchy는 기본으로 일시 중단(suspend)과 최대 절전을 활성화하지만, 사용하는 컴퓨터에서 둘 중 하나에 문제가 있다면 끌 수 있습니다.

### 전원 프로필

노트북에서 Omarchy는 전원에 연결했을 때와 배터리로 실행 중일 때의 전원 프로필을 따로 기억하고, 꽂고 뽑을 때 두 상태 사이를 전환합니다. 기본 설정에서는 AC 전원에서는 성능 모드, 배터리에서는 균형 모드를 뜻합니다.

`omarchy powerprofiles list`로 컴퓨터가 제공하는 프로필을 확인할 수 있고, `omarchy powerprofiles set autodetect power-saver`로 현재 상태에서 원하는 프로필을 설정할 수 있습니다. 아무것도 뽑지 않고 다른 상태를 설정하려면 직접 이름을 지정하세요: `omarchy powerprofiles set battery power-saver`. 무엇을 고르든 다음에 그 상태가 되었을 때 다시 적용됩니다.

### 일시 중단 켜고 끄기

터미널에서 `omarchy toggle suspend`를 실행해 일시 중단을 켜고 끕니다. 이는 _시스템_(또는 `Super + Esc`) 아래의 옵션을 보여 주거나 숨길 뿐이며, 이후 시스템에서 일관되게 작동하는지 확인할 수 있습니다. 그렇지 않다면 같은 명령으로 다시 숨길 수 있습니다.

### 최대 절전 켜고 끄기

터미널에서 `omarchy hibernation setup`을 실행해 최대 절전을 설정합니다. 최대 절전은 물리적 RAM 할당량과 같은 크기의 /swap 하위 볼륨을 부팅 드라이브에 만들므로 여유 공간이 충분한지 확인하세요. 32GB 컴퓨터에서는 이 볼륨을 위해 항상 32GB 이상의 여유 공간이 필요합니다. 최대 절전에는 기본 Limine 부트로더도 필요합니다.

설정이 끝나면 _시스템_(또는 `Super + Esc`) 아래에 최대 절전 옵션이 나타나고, 이후 시스템에서 일관되게 작동하는지 확인할 수 있습니다. 그렇지 않다면 `omarchy hibernation remove`를 실행해 다시 제거할 수 있습니다.
