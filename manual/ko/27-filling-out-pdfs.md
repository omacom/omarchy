# PDF 작성하기

Omarchy에는 Document Viewer라는 멋지고 기본적인 PDF 뷰어가 함께 제공됩니다. 더블클릭한 모든 PDF를 여는 프로그램입니다.

하지만 Document Viewer로는 양식으로 설정된 PDF만 작성할 수 있습니다. 양식으로 설정되지 않은 PDF를 작성해야 하거나 PDF에 서명해야 한다면 [Signed](https://github.com/omacom/signed)를 사용하세요. 애플리케이션 실행 프로그램(`Super + Space`)에서 시작하거나, 파일을 마우스 오른쪽 버튼으로 클릭하고 _Open With..._를 선택한 뒤 Signed를 고르세요.

`T`를 누르면 텍스트를 입력하고 `D`를 누르면 오늘 날짜를 넣습니다. 둘 다 마우스 포인터가 있는 위치에 놓입니다. 무엇이든 드래그해 이동하고, 모서리를 드래그해 크기를 조절하고, 텍스트를 더블클릭해 변경하세요.

서명하려면 서명 사진이 필요합니다. 스캔 파일이나 흰 종이 위에 서명한 서명을 밝은 조명 아래에서 찍은 사진이면 됩니다. _Signature_ 메뉴(`Shift + S`)를 열고 _Add signature..._를 선택한 뒤 사진을 고르고 이름을 지정하세요. Signed는 종이를 제거하고 잉크만 남깁니다. 그때부터 `S`를 누르면 마우스 포인터 아래에 서명이 놓입니다.

작업이 끝나면 _Save signed copy..._(`Ctrl + S`)를 사용해 작성한 PDF를 원본 옆에 저장하세요. 원본은 절대 변경되지 않습니다. Signed 안에서 `?`를 누르면 모든 단축키를 볼 수 있습니다.
