# 하드웨어 인증

### 지문 인증

많은 노트북에는 인증용 지문 센서가 내장되어 있습니다. Omarchy 메뉴(`Super + Space`)에서 _설정 > 보안 > 지문_을 실행하면 이를 Omarchy에서 사용할 수 있습니다.

그러면 지문 패키지가 설치되고, 지문이 등록되고, 확인 과정을 거친 뒤, 잠금 화면(`Super + Ctrl + L`로 실행할 수 있습니다)에서 잠금을 해제하고, sudo 모드에 들어가고, 시스템 프롬프트를 승인할 때 지문을 사용할 준비가 완료됩니다.

잠금 화면에서 디스플레이가 꺼지면 센서는 전력을 절약하기 위해 휴면 상태에 들어가므로, 센서를 터치하기 전에 아무 키나 터치패드로 화면을 깨워 주세요.

노트북 덮개가 닫혀 있으면 지문 입력 요청이 자동으로 건너뛰어지므로, 닿을 수 없는 센서를 기다리지 않고 바로 비밀번호 입력 화면으로 이동합니다. 그 밖에 센서가 없는 외부 키보드로 작업해야 한다면, `sudo` 실행 중 지문 입력을 요구받을 때 `CTRL + C`를 누르기만 하면 됩니다.

지문 인증은 Omarchy 메뉴의 _제거 > 보안 > 지문_에서 제거할 수 있습니다.

### Fido2 인증

Fido2 장치를 사용하고 있다면 Omarchy 메뉴(`Super + Space`)의 _설정 > 보안 > Fido2_를 이용해 `sudo` 인증용으로 설정할 수 있습니다. 다만 이는 `sudo`와 시스템 승인 프롬프트에 적용되며, 컴퓨터 잠금 해제에는 적용되지 않습니다.

fido2 인증은 Omarchy 메뉴의 _제거 > 보안 > Fido2_에서 제거할 수 있습니다.
