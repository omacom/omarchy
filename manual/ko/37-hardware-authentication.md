# 하드웨어 인증

### 지문 인증

많은 노트북에는 인증용 지문 센서가 탑재되어 있습니다. Omarchy에서는 Omarchy 메뉴(`Super + Space`)에서 _Setup > Security > Fingerprint_를 실행해 이를 사용할 수 있습니다.

그러면 센서를 터치할 때마다 채워지는 전체 화면 지문이 열립니다. 그 뒤에서 Omarchy는 지문 패키지를 설치하고, 지문을 수집하고, 확인하며, 그러면 지문으로 잠금 화면(`Super + Ctrl + L`로 실행할 수 있음)을 해제하고, sudo 모드에 들어가고, 시스템 프롬프트를 승인할 준비가 됩니다.

잠금 화면이 디스플레이를 끄면 센서는 전력을 절약하기 위해 휴식 상태에 들어가므로, 센서를 터치하기 전에 아무 키나 터치패드로 화면을 먼저 깨우세요.

노트북 덮개가 닫혀 있으면 지문 프롬프트가 자동으로 건너뛰어지므로, 닿을 수 없는 센서를 기다리는 대신 곧바로 비밀번호 프롬프트로 이동합니다. 그 외에 센서가 없는 외장 키보드로 작업해야 할 경우에는 `sudo` 중에 지문 입력이 요청될 때 `CTRL + C`를 누르기만 하면 됩니다.

지문 인증은 Omarchy 메뉴의 _Remove > Security > Fingerprint_에서 제거할 수 있습니다.

### Fido2 인증

Fido2 기기를 사용 중이라면 Omarchy 메뉴(`Super + Space`)의 _Setup > Security > Fido2_를 이용해 `sudo` 인증용으로 설정할 수 있습니다. 다만 컴퓨터 잠금 해제가 아니라 `sudo`와 시스템 승인 프롬프트에만 적용됩니다.

fido2 인증은 Omarchy 메뉴의 _Remove > Security > Fido2_에서 제거할 수 있습니다.
