# FAQ

### 키보드 레이아웃 간에 전환하려면 어떻게 하나요?

`~/.config/hypr/input.lua` 파일을 편집하고 `Left Alt + Right Alt`로 레이아웃 간에 전환할 수 있도록 다음을 추가하세요:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

여러 레이아웃을 구성하면 바에 현재 키보드 레이아웃이 자동으로 표시됩니다(클릭해서 전환할 수도 있습니다).

### 시계 형식을 12시간제로 바꾸려면 어떻게 하나요?

바에서 시계를 오른쪽 클릭하면 12시간제를 포함한 일반적인 형식들을 순환하며 바꿀 수 있습니다. 형식을 직접 설정할 수도 있습니다:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

이렇게 하면 일요일 10:55 AM으로 표시됩니다.

### 시간대를 변경하려면 어떻게 하나요?

Omarchy 메뉴에서 _설정 > 지역 > 시간대_를 실행하고 목록에서 선택하세요. 시간대는 맞는데 시계 자체가 어긋났다면 _업데이트 > 시간_이 시간 동기화를 대신 다시 시작해 줍니다.

### DNS를 변경하거나, Wi-Fi를 공유하거나, 연결 속도를 확인하려면 어떻게 하나요?

그것들은 모두 [네트워킹](35-networking.md)에 있습니다.

### 디스크 속도를 확인하려면 어떻게 하나요?

_실행 > 속도 테스트 > 디스크 속도 테스트_는 드라이브의 실시간 읽기 및 쓰기 속도를 측정합니다. 터미널에서는 `omarchy disk speedtest`를 사용하세요.

### 프린터를 추가하려면 어떻게 하나요?

인쇄는 기본으로 설정되어 실행 중이며, 각 프린터는 앱 런처(`Super + Space`)의 _인쇄 설정_에서 직접 추가합니다.

_추가_를 선택하고 잠시 기다리며 찾아보세요: USB로 연결된 프린터와 대부분의 네트워크 프린터는 자동으로 찾아줍니다. 목록에 없으면 _네트워크 프린터 > Internet Printing Protocol (ipp)_를 선택하고 주소를 입력하세요 — 프린터 자체 디스플레이나 웹 페이지에서 그 주소를 확인할 수 있으며, 보통 `192.168.1.50` 같은 주소에 `ipp/print` 큐를 사용합니다. 그런 다음 _다음_에서 드라이버를 제공하는데, 최신 프린터는 드라이버 없는 _IPP Everywhere_ 프로필에서 가장 잘 작동하고, 구형 프린터는 해당 모델 전용 드라이버가 필요합니다.

프린터를 오른쪽 클릭하고 _기본값으로 설정_을 선택하면 앱에서 먼저 사용할 프린터를 정할 수 있고, _속성_에서 용지 크기, 양면 인쇄 및 품질을 설정할 수 있습니다.

네트워크의 프린터가 추가하지 않아도 나타나는 자동 검색은 개편 작업 중이라 일시적으로 꺼져 있습니다. 그래서 위의 첫 단계는 자동이 아니라 직접 해야 합니다. 프린터가 전혀 없어도 PDF 파일로 인쇄할 수는 있습니다.

### 스크린샷이나 화면 녹화가 저장되는 위치를 변경하려면 어떻게 하나요?

저장된 스크린샷은 기본적으로 `~/Pictures/Screenshots`에 저장됩니다. 다른 디렉터리를 사용하려면 `~/.config/uwsm/env.d/` 아래 파일(예: `~/.config/uwsm/env.d/capture`)에 다음을 추가하세요:

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

`OMARCHY_SCREENRECORD_DIR`를 사용해 화면 녹화에도 같은 설정을 할 수 있습니다.

Omasnap은 스크린샷 디렉터리를 자동으로 만듭니다. 화면 녹화 디렉터리는 직접 만든 다음, 환경 변경 사항이 적용되도록 Omarchy를 다시 시작하세요.

### Apple Studio Display에서 스피커와 웹캠이 작동하게 하려면 어떻게 하나요?

USB C를 꽂기만 하면 다 작동할 것 같지만, 안타깝게도 그렇지 않습니다. 제가 찾은 안정적인 해결 방법은 [WJESOG DisplayPort + USB-A => USB-C 케이블](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/)을 사용하는 것입니다. 그러면 스피커와 웹캠이 아주 잘 작동합니다.

Omarchy에는 일반 키보드 밝기 버튼을 사용하는 Apple 디스플레이(Studio와 XDR 모두)용 내장 밝기 조절 기능이 있다는 점도 기억하세요.

### 불필요한 추가 소프트웨어를 모두 제거하려면 어떻게 하나요?

Obsidian이나 LibreOffice 같은 프로그램이나 기타 사전 설치된 프로그램을 원하지 않는다면 아주 쉽게 제거할 수 있습니다.

_제거 > 패키지_를 실행하면 설치된 모든 패키지를 볼 수 있습니다. 그런 다음 Tab으로 제거하려는 패키지를 선택하고, Return으로 선택한 모든 항목 제거를 시작할 수 있습니다.

Omarchy 메뉴의 _제거 > 웹 앱_을 사용하면 원하지 않는 사전 설치 웹 앱을 제거할 수 있습니다.

또는 _제거 > 사전 설치 항목_을 실행하면 사전 설치된 추가 항목 — 웹 앱, TUI, 선택적 애플리케이션 — 을 한 번에 모두 제거할 수 있습니다. 이들을 실행하던 단축키도 함께 사라지므로, `~/.config/hypr/bindings.lua`에 자신만의 바인딩으로 채울 수 있는 깨끗한 상태가 됩니다.
