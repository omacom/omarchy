# 통합 클립보드 및 히스토리

보통 Linux에서는 터미널에서 복사/붙여넣기를 하려면 `Ctrl + Shift + C/V`가 필요하고, 다른 모든 곳에서는 `Ctrl + C/V`를 사용합니다. Linux에서 태어나고 자란 사람이 아니라면 익숙해지기 어렵습니다! Mac에서 온 경우 super에서 ctrl로 전환하는 것도 마찬가지입니다.

Omarchy는 (거의) 모든 곳에서 작동하는 통합 클립보드 단축키로 두 문제를 모두 해결합니다. 단축키는 다음과 같습니다:

| 단축키 | 명령 |
| ------- | ----------- |
| Super + C | 복사 |
| Super + X | 잘라내기 |
| Super + V | 붙여넣기 |
| Super + Ctrl + V | 클립보드 히스토리 |

_대부분의 에이전트 하네스는 이미지 붙여넣기에 `Ctrl + V`를 사용하지만, 텍스트 붙여넣기에는 `Super + V`를 사용합니다._

### 클립보드 히스토리

클립보드 히스토리는 Omarchy 셸에서 제공하며 텍스트와 이미지 모두에서 작동합니다. `Super + Ctrl + V`로 실행하고, Return 키로 항목을 선택하면 클립보드에 올라가 `Super + V`로 붙여넣을 준비가 됩니다.
