# 단축키

`Super + K`로 모든 주요 키보드 바인딩을 볼 수 있습니다(Tmux 바인딩은 `Super + Alt + K`, Herdr 바인딩은 `Super + Ctrl + K`입니다).

## 탐색

| 단축키                  | 기능              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy 메뉴(앱 및 기타 모든 것)    |
| `Super + Alt + Space` | 앱 그리드 |
| `Super + Escape` | 시스템 메뉴(일시 중단, 재시작 등)  |
| `Super + Ctrl + L` | 컴퓨터 잠금 |
| `Super + W` 또는 `Super + Q` | 창 닫기             |
| `Ctrl + Alt + Del` | 모든 창 닫기 |
| `Super + T`               | 창을 타일링/플로팅 간에 토글             |
| `Super + J` | 창 위치 토글(가로/세로) |
| `Super + O`               | 창을 고정/플로팅으로 튀기기 토글 |
| `Super + L`               | dwindle, 스크롤링, 플로팅 레이아웃 순환 |
| `Super + Alt + L`         | 레이아웃을 역순으로 순환 |
| `Super + P`               | 가짜 창 스타일 토글(자연스럽게 대 늘리기) |
| `Super + F`                 | 전체 화면으로 가기              |
| `Super + Alt + F`                 | 전체 너비로 가기              |
| `Super + Ctrl + F`                 | 창 안에서 전체 화면으로 가기              |
| `Super + 1/2/3/4`         | 특정 워크스페이스로 이동     |
| `Super + Tab` | 다음 워크스페이스로 이동 |
| `Super + Shift + Tab` | 이전 워크스페이스로 이동 |
| `Super + Ctrl + Tab` | 이전 워크스페이스로 이동 |
| `Super + Shift + 1/2/3/4` | 창을 워크스페이스로 이동 |
| `Super + Shift + Alt + 1/2/3/4` | 따라가지 않고 창을 워크스페이스로 이동 |
| `Super + S` / `Super + Grave` | 스크래치패드 토글 |
| `Super + Alt + S` / `Super + Shift + Grave` | 창을 스크래치패드로 이동 |
| `Super + Shift + Alt + Arrows` | 워크스페이스를 방향 모니터로 이동 |
| `Super + Arrow`  | 화살표 방향의 창으로 포커스 이동              |
| `Super + Shift + Arrow`  | 창을 화살표 방향의 다른 창과 맞바꾸기     |
| `Super + Minus` | 창을 왼쪽으로 확장 |
| `Super + Equal` | 창을 왼쪽으로 축소 |
| `Super + Shift + Minus` | 창을 위쪽으로 축소 |
| `Super + Shift + Equal` | 창을 아래쪽으로 확장 |
| `Super + Alt + Minus/Equal` | 더 작은 단계로 같은 크기 조절 |
| `Super + Ctrl + Minus/Equal` | 더 큰 단계로 같은 크기 조절 |
| `Super + Alt + Home` | 창 너비 저장 |
| `Super + Home` | 저장된 창 너비 복원 |
| `Super + Left Mouse` | 창을 드래그해 이동 |
| `Super + Right Mouse` | 창 크기 조절 |
| `Super + Scroll Wheel` | 워크스페이스 스크롤 |
| `Super + G`               | 창 그룹화 토글      |
| `Super + Alt + G`               | 창을 그룹에서 빼내기      |
| `Super + Alt + Tab`               | 그룹 안 창 사이 순환      |
| `Super + Alt + Shift + Tab`               | 그룹 안 창 사이 역방향 순환      |
| `Super + Alt + 1/2/3/4/5`               | 그룹의 특정 창으로 이동      |
| `Super + Alt + Arrow`  | 창을 화살표 방향으로 그룹 안으로 이동  |
| `Super + Ctrl + Left/Right`  | 타일링 그룹 안 창 사이 이동 |
| `Super + Ctrl + Z` | 화면 확대(반복하면 더 확대) |
| `Super + Ctrl + Alt + Z` | 화면 완전히 축소 |
| `Super + /` | 모니터 배율 옵션 앞으로 단계 이동 |
| `Super + Alt + /` | 모니터 배율 옵션 뒤로 단계 이동 |
| `Alt + Tab` | 활성 워크스페이스 창 앞으로 순환 |
| `Alt + Shift + Tab` | 활성 워크스페이스 창 뒤로 순환 |
| `Ctrl + Alt + Tab`| 모니터 간 포커스 앞으로 순환 |
| `Ctrl + Alt + Shift + Tab`| 모니터 간 포커스 뒤로 순환 |

## 범용 클립보드

| 단축키                  | 기능              |
| ----------------------- | --------------------- |
| `Super + C`           | 복사    |
| `Super + X`           | 잘라내기(터미널에서는 제외)    |
| `Super + V`           | 붙여넣기    |
| `Super + Ctrl + V`           | 클립보드 관리자    |

보통 Linux에서는 터미널에서 복사/붙여넣기를 하려면 `Ctrl + Shift + C/V`가 필요하고, 다른 모든 곳에서는 `Ctrl + C/V`를 사용합니다. Omarchy의 이 통합 클립보드 단축키는 어디서나 작동합니다.

## 캡처

| 단축키              | 기능                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | 캡처 메뉴(PrintScr 버튼이 없는 키보드용) |
| `Print Screen`            | 스크린샷                      |
| `Alt + Print Screen`            | 화면 녹화                     |
| `Super + Print Screen` | 색상 선택기 |
| `Super + Ctrl + Print Screen` | 클립보드로 텍스트 추출 |
| `Super + Alt + [` | 녹화 중 웹캠 오버레이를 작게 만들기 |
| `Super + Alt + ]` | 녹화 중 웹캠 오버레이를 크게 만들기 |
| `Alt + Shift + L` | 웹앱이나 Chromium에서 현재 URL 복사 |
| `Alt + Shift + D` | 현재 페이지의 동영상을 `~/Videos`로 다운로드 |
| `Super + Ctrl + X` | 받아쓰기 시작/중지(_설정 > 기본값 > 받아쓰기_ 필요) |
| `Right Alt` / `F9` | 푸시-투-토크 받아쓰기(Voxtype 또는 Superwhisper 필요) |

화면 녹화에서는 단축키가 먼저 어떤 오디오를 원하는지 묻고, 그 뒤에 녹화를 시작합니다. 다시 누르면 중지됩니다. 자세한 내용은 [스크린샷 및 녹화](12-screenshots-recording.md)를 참조하세요.

모든 캡처 옵션은 Omarchy 메뉴(`Super + Space`)의 _실행 > 캡처_에서도 사용할 수 있습니다.

## Tmux

프리픽스 키는 `Ctrl + Space`입니다(`Ctrl + B`도 작동합니다). 이 바인딩들은 `~/.config/tmux/tmux.conf`에서 바꿀 수 있습니다.

### 창(Panes)

| 단축키                  | 기능              |
| ----------------------- | --------------------- |
| `Prefix + v` | 창을 옆으로 분할(세로) |
| `Prefix + h` | 창을 아래로 분할(가로) |
| `Prefix + x` | 창 죽이기 |
| `Prefix + z` | 창 확대 토글(전체 화면) |
| `Alt + Enter` | 창을 아래로 분할(프리픽스 없음) |
| `Alt + Shift + Enter` | 창을 옆으로 분할(프리픽스 없음) |
| `Alt + Escape` | 창 죽이기(프리픽스 없음) |
| `Ctrl + Alt + Arrows` | 창 사이 이동 |
| `Ctrl + Alt + Shift + Arrows` | 창 크기 조절 |

### 윈도우(Windows)

| 단축키                  | 기능              |
| ----------------------- | --------------------- |
| `Prefix + c` | 새 윈도우 |
| `Prefix + k` | 윈도우 죽이기 |
| `Prefix + r` | 윈도우 이름 바꾸기 |
| `Alt + 1-9` | 특정 윈도우로 가기 |
| `Alt + Arrow Left/Right` | 윈도우 사이 이동 |
| `Alt + Shift + Arrow Left/Right` | 윈도우를 왼쪽/오른쪽으로 이동 |

### 세션

| 단축키                  | 기능              |
| ----------------------- | --------------------- |
| `Prefix + C` | 새 세션 |
| `Prefix + K` | 세션 죽이기 |
| `Prefix + R` | 세션 이름 바꾸기 |
| `Prefix + N` | 다음 세션 |
| `Prefix + P` | 이전 세션 |
| `Alt + Arrow Up/Down` | 세션 사이 이동 |
| `Prefix + s` | 세션 목록 |
| `Prefix + d` | 세션에서 분리(Detach) |

### 복사 모드(vi 스타일)

| 단축키                  | 기능              |
| ----------------------- | --------------------- |
| `Prefix + [` | 복사 모드 진입 |
| `v` | 선택 시작(복사 모드에서) |
| `y` | 선택 복사(복사 모드에서) |

### 일반

| 단축키                  | 기능              |
| ----------------------- | --------------------- |
| `Prefix + q` | 구성 다시 로드 |
| `Prefix + ?` | Tmux 키바인딩 표시 |
| `Prefix + :` | 명령 프롬프트 |

### Tmux 레이아웃 함수

이 함수들은 Tmux 세션 안에서 실행해야 합니다.

| 명령 | 기능 |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | 편집기, AI, 터미널로 개발 레이아웃 만들기 |
| `tdlm <ai> [<second_ai>]` | 하위 디렉터리마다 개발 레이아웃 만들기 |
| `tsl <count> <command>` | 다중 창 스웜 레이아웃 만들기 |

| `?`                        | 모든 명령에 대한 도움말 표시      |
