# 단축키

`Super + K`로 모든 주요 키보드 바인딩을 볼 수 있습니다. (Tmux 바인딩은 `Super + Alt + K`, Herdr 바인딩은 `Super + Ctrl + K`)

## 탐색

| 단축키                  | 기능              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy 메뉴 (앱 및 기타 모든 항목)    |
| `Super + Alt + Space` | 앱 그리드 |
| `Super + Escape` | 시스템 메뉴 (절전, 재시작 등)  |
| `Super + Ctrl + L` | 컴퓨터 잠그기 |
| `Super + W` or `Super + Q` | 창 닫기             |
| `Ctrl + Alt + Del` | 모든 창 닫기 |
| `Super + T`               | 창을 타일링/플로팅 간 전환             |
| `Super + J` | 창 위치 전환 (가로/세로) |
| `Super + O`               | 창을 sticky'n'floating으로 팝업 전환 |
| `Super + L`               | dwindle, scrolling, floating 레이아웃 순환 |
| `Super + Alt + L`         | 레이아웃을 역순으로 순환 |
| `Super + P`               | pseudo 창 스타일 전환 (natural 대 stretch) |
| `Super + F`                 | 전체 화면으로 전환              |
| `Super + Alt + F`                 | 전체 너비로 전환              |
| `Super + Ctrl + F`                 | 창 내부에서 전체 화면으로 전환              |
| `Super + 1/2/3/4`         | 포커스가 있는 모니터의 특정 워크스페이스로 이동 |
| `Super + Tab` | 포커스가 있는 모니터의 다음 워크스페이스로 이동 |
| `Super + Shift + Tab` | 포커스가 있는 모니터의 이전 워크스페이스로 이동 |
| `Super + Ctrl + Tab` | 포커스가 있는 모니터의 이전 워크스페이스로 이동 |
| `Super + Shift + 1/2/3/4` | 창을 포커스가 있는 모니터의 워크스페이스로 이동 |
| `Super + Shift + Alt + 1/2/3/4` | 따라가지 않고 창을 포커스가 있는 모니터의 워크스페이스로 이동 |
| `Super + S` | 전체 scratchpad 전환 |
| `Super + Alt + S` | 창을 전체 scratchpad로 이동 |
| `Super + Grave` | Quake 콘솔 전환 |
| `Super + Shift + Grave` | 창을 Quake 콘솔로 이동 |
| `Super + Shift + Ctrl + Arrows` | 창을 해당 방향의 모니터로 이동 |
| `Super + Shift + Alt + Arrows` | 워크스페이스를 해당 방향의 모니터로 이동 |
| `Super + Arrow`  | 화살표 방향의 창으로 포커스 이동, 화면 가장자리에서는 해당 쪽 모니터로 넘어감 |
| `Super + Shift + Arrow`  | 화살표 방향의 다른 창과 창 교체, 해당 쪽 모니터에 있는 창 포함 |
| `Super + Minus` | 창을 왼쪽으로 확장 |
| `Super + Equal` | 창을 왼쪽으로 축소 |
| `Super + Shift + Minus` | 창을 위쪽으로 축소 |
| `Super + Shift + Equal` | 창을 아래쪽으로 확장 |
| `Super + Alt + Minus/Equal` | 더 작은 단계로 동일한 크기 조정 |
| `Super + Ctrl + Minus/Equal` | 더 큰 단계로 동일한 크기 조정 |
| `Super + Alt + Home` | 창 너비 저장 |
| `Super + Home` | 저장된 창 너비 복원 |
| `Super + Left Mouse` | 창 드래그 |
| `Super + Right Mouse` | 창 크기 조정 |
| `Super + Scroll Wheel` | 포커스가 있는 모니터의 워크스페이스 스크롤 |
| `Super + G`               | 창 그룹화 전환      |
| `Super + Alt + G`               | 창을 그룹에서 빼기      |
| `Super + Alt + Tab`               | 그룹 내 창 순환      |
| `Super + Alt + Shift + Tab`               | 그룹 내 창을 역방향으로 순환      |
| `Super + Alt + Scroll Wheel` | 그룹 내 창 순환 |
| `Super + Alt + 1/2/3/4/5`               | 그룹 내 특정 창으로 이동      |
| `Super + Alt + Arrow`  | 화살표 방향으로 창을 그룹에 넣기, 해당 쪽 모니터에 있는 창 포함 |
| `Super + Ctrl + Left/Right`  | 타일링 그룹 내부의 창 사이 이동 |
| `Super + Ctrl + Z` | 화면 확대 (반복할수록 더 확대) |
| `Super + Ctrl + Alt + Z` | 화면 완전히 축소 |
| `Super + /` | 모니터 배율 옵션을 앞으로 단계 이동 |
| `Super + Alt + /` | 모니터 배율 옵션을 뒤로 단계 이동 |
| `Alt + Tab` | 활성 워크스페이스의 창을 앞으로 순환 |
| `Alt + Shift + Tab` | 활성 워크스페이스의 창을 뒤로 순환 |
| `Ctrl + Alt + Tab`| 모니터 간 포커스를 앞으로 순환 |
| `Ctrl + Alt + Shift + Tab`| 모니터 간 포커스를 뒤로 순환 |

## 범용 클립보드

| 단축키                  | 기능              |
| ----------------------- | --------------------- |
| `Super + C`           | 복사    |
| `Super + X`           | 잘라내기 (터미널에서는 안 됨)    |
| `Super + V`           | 붙여넣기    |
| `Super + Ctrl + V`           | 클립보드 관리자    |

보통 Linux에서는 터미널에서 복사/붙여넣기를 하려면 `Ctrl + Shift + C/V`가 필요하고, 그 밖의 모든 곳에서는 `Ctrl + C/V`가 필요합니다. 이 Omarchy 통합 클립보드 단축키는 어디에서나 작동합니다.

## 캡처

| 단축키              | 기능                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | 스크린샷                      |
| `Super + Ctrl + Alt + C`            | 스크린샷 (동일한 촬영, Print Screen 키가 없는 키보드용) |
| `Super + Ctrl + C` | 캡처 메뉴 |
| `Alt + Print Screen`            | 화면 녹화                     |
| `Super + Print Screen` | 색상 피커 |
| `Super + Ctrl + Print Screen` | 텍스트를 추출해 클립보드로 |
| `Super + Alt + [` | 녹화 중 웹캠 오버레이 작게 만들기 |
| `Super + Alt + ]` | 녹화 중 웹캠 오버레이 크게 만들기 |
| `Alt + Shift + L` | 웹앱 또는 Chromium에서 현재 URL 복사 |
| `Alt + Shift + D` | 현재 페이지의 동영상을 `~/Videos`로 다운로드 |
| `Super + Ctrl + X` | 받아쓰기 시작/중지 (_Setup > Defaults > Dictation_ 필요) |
| `Right Alt` / `F9` | 눌러서 말하는 받아쓰기 (Voxtype 또는 Superwhisper 필요) |

화면 녹화에서는 단축키를 누르면 먼저 어떤 오디오를 원하는지 묻고, 그다음 녹화를 시작합니다. 다시 누르면 중지됩니다. 자세한 내용은 [스크린샷 및 녹화](12-screenshots-recording.md)를 참조하세요.

모든 캡처 옵션은 Omarchy 메뉴(`Super + Space`)의 _Trigger > Capture_에서도 이용할 수 있습니다.

## Tmux

접두사 키는 `Ctrl + Space`입니다 (`Ctrl + B`도 작동합니다). `~/.config/tmux/tmux.conf`에서 이 바인딩을 변경할 수 있습니다.

### 창 분할 (Panes)

| 단축키                  | 기능              |
| ----------------------- | --------------------- |
| `Prefix + v` | 옆으로 창 분할 (세로) |
| `Prefix + h` | 아래로 창 분할 (가로) |
| `Prefix + x` | 창 종료 |
| `Prefix + z` | 창 확대/축소 전환 (전체 화면) |
| `Alt + Enter` | 아래로 창 분할 (접두사 없음) |
| `Alt + Shift + Enter` | 옆으로 창 분할 (접두사 없음) |
| `Alt + Escape` | 창 종료 (접두사 없음) |
| `Ctrl + Alt + Arrows` | 창 사이 이동 |
| `Ctrl + Alt + Shift + Arrows` | 창 크기 조정 |

### 창 (Windows)

| 단축키                  | 기능              |
| ----------------------- | --------------------- |
| `Prefix + c` | 새 창 |
| `Prefix + k` | 창 종료 |
| `Prefix + r` | 창 이름 변경 |
| `Alt + 1-9` | 특정 창으로 이동 |
| `Alt + Arrow Left/Right` | 창 사이 이동 |
| `Alt + Shift + Arrow Left/Right` | 창을 왼쪽/오른쪽으로 이동 |

### 세션

| 단축키                  | 기능              |
| ----------------------- | --------------------- |
| `Prefix + C` | 새 세션 |
| `Prefix + K` | 세션 종료 |
| `Prefix + R` | 세션 이름 변경 |
| `Prefix + N` | 다음 세션 |
| `Prefix + P` | 이전 세션 |
| `Alt + Arrow Up/Down` | 세션 사이 이동 |
| `Prefix + s` | 세션 목록 |
| `Prefix + d` | 세션에서 분리 |

### 복사 모드 (vi 스타일)

| 단축키                  | 기능              |
| ----------------------- | --------------------- |
| `Prefix + [` | 복사 모드 진입 |
| `v` | 선택 시작 (복사 모드에서) |
| `y` | 선택 복사 (복사 모드에서) |

### 일반

| 단축키                  | 기능              |
| ----------------------- | --------------------- |
| `Prefix + q` | 설정 다시 불러오기 |
| `Prefix + ?` | Tmux 키 바인딩 표시 |
| `Prefix + :` | 명령 프롬프트 |

### Tmux 레이아웃 함수

이 함수는 Tmux 세션 내부에서 실행해야 합니다.

| 명령 | 기능 |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | 편집기, AI, 터미널이 있는 개발 레이아웃 만들기 |
| `tdlm <ai> [<second_ai>]` | 하위 디렉터리별 개발 레이아웃 만들기 |
| `tsl <count> <command>` | 여러 창이 있는 swarm 레이아웃 만들기 |
