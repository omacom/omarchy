# 리마인더

Omarchy에는 카운트다운 타이머와 메시지를 기반으로 간단한 리마인더를 설정하는 기능이 내장되어 있습니다. `Super + Ctrl + R`로 설정하고, `Super + Ctrl + Alt + R`로 설정된 모든 리마인더를 보며, `Super + Ctrl + Shift + R`로 모두 지울 수 있습니다. 모든 기능은 _실행 > 리마인더_에서도 사용할 수 있습니다. `omarchy reminder 7 'Tea ready'`처럼 CLI를 사용할 수도 있습니다.
