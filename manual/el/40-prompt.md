# Προτροπή

Το Omarchy έρχεται με μια ελάχιστη προτροπή [Starship](https://starship.rs/) από προεπιλογή. Έτσι μου αρέσει να κρατώ την προτροπή μου. Δεν χρειάζεται να ξέρω τον χρήστη, επειδή είμαι πάντα εγώ, και δεν χρειάζεται να ξέρω την ώρα, επειδή είναι πάντα στην κορυφή.

 ![prompt](images/prompt.webp)

Αν θέλεις περισσότερες πληροφορίες ή στυλ, μπορείς να αλλάξεις τη διαμόρφωση [Starship.rs](https://starship.rs/) στο `~/.config/starship.toml`. Υπάρχουν πολλά που μπορείς να κάνεις. Απλώς μην το παρακάνεις (ή παρακάντο, κάνε ό,τι θέλεις, είναι ο υπολογιστής σου!)
