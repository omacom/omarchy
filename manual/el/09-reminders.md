# Υπενθυμίσεις

Το Omarchy έχει έναν ενσωματωμένο τρόπο να ορίζεις απλές υπενθυμίσεις βασισμένες σε χρονόμετρο αντίστροφης μέτρησης και με ένα μήνυμα. Μπορείς να το κάνεις αυτό μέσω `Super + Ctrl + R`, βλέποντας όλες όσες έχουν οριστεί μέσω `Super + Ctrl + Alt + R`, και εκκαθαρίζοντας όλες μέσω `Super + Ctrl + Shift + R`. Όλα προσβάσιμα επίσης μέσω _Ενεργοποίηση > Υπενθύμιση_. Μπορείς επίσης να χρησιμοποιήσεις το cli με `omarchy reminder 7 'Tea ready'`.
