# Πλήκτρα συντόμευσης

Μπορείτε να δείτε όλες τις κύριες συντομεύσεις πληκτρολογίου με `Super + K` (συντομεύσεις Tmux με `Super + Alt + K` και συντομεύσεις Herdr με `Super + Ctrl + K`).

## Πλοήγηση

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Super + Space` | Μενού Omarchy (εφαρμογές και όλα τα υπόλοιπα) |
| `Super + Alt + Space` | Πλέγμα εφαρμογών |
| `Super + Escape` | Μενού συστήματος (αναστολή, επανεκκίνηση κ.λπ.) |
| `Super + Ctrl + L` | Κλείδωμα υπολογιστή |
| `Super + W` ή `Super + Q` | Κλείσιμο παραθύρου |
| `Ctrl + Alt + Del` | Κλείσιμο όλων των παραθύρων |
| `Super + T` | Εναλλαγή παραθύρου ανάμεσα σε πλακίδια/αιωρούμενο |
| `Super + J` | Εναλλαγή θέσης παραθύρου (οριζόντια/κατακόρυφη) |
| `Super + O` | Εναλλαγή παραθύρου σε αναδυόμενο sticky'n'floating |
| `Super + L` | Κυκλική εναλλαγή ανάμεσα στις διατάξεις dwindle, scrolling και floating |
| `Super + Alt + L` | Κυκλική εναλλαγή ανάμεσα στις διατάξεις αντίστροφα |
| `Super + P` | Εναλλαγή στυλ pseudo παραθύρου (φυσικό ή τεντωμένο) |
| `Super + F` | Μετάβαση σε πλήρη οθόνη |
| `Super + Alt + F` | Μετάβαση σε πλήρες πλάτος |
| `Super + Ctrl + F` | Μετάβαση σε πλήρη οθόνη μέσα στο παράθυρο |
| `Super + 1/2/3/4` | Μετάβαση σε συγκεκριμένο χώρο εργασίας στην εστιασμένη οθόνη |
| `Super + Tab` | Μετάβαση στον επόμενο χώρο εργασίας στην εστιασμένη οθόνη |
| `Super + Shift + Tab` | Μετάβαση στον προηγούμενο χώρο εργασίας στην εστιασμένη οθόνη |
| `Super + Ctrl + Tab` | Μετάβαση στον προηγούμενο χώρο εργασίας στην εστιασμένη οθόνη |
| `Super + Shift + 1/2/3/4` | Μετακίνηση παραθύρου σε χώρο εργασίας στην εστιασμένη οθόνη |
| `Super + Shift + Alt + 1/2/3/4` | Μετακίνηση παραθύρου σε χώρο εργασίας στην εστιασμένη οθόνη χωρίς να το ακολουθήσετε |
| `Super + S` | Εναλλαγή πλήρους scratchpad |
| `Super + Alt + S` | Μετακίνηση παραθύρου στο πλήρες scratchpad |
| `Super + Grave` | Εναλλαγή κονσόλας Quake |
| `Super + Shift + Grave` | Μετακίνηση παραθύρου στην κονσόλα Quake |
| `Super + Shift + Ctrl + Arrows` | Μετακίνηση παραθύρου στην οθόνη προς αυτή την κατεύθυνση |
| `Super + Shift + Alt + Arrows` | Μετακίνηση χώρου εργασίας στην οθόνη προς αυτή την κατεύθυνση |
| `Super + Arrow` | Μετακίνηση της εστίασης στο παράθυρο προς την κατεύθυνση του βέλους, περνώντας στην οθόνη εκείνης της πλευράς στο άκρο της οθόνης |
| `Super + Shift + Arrow` | Ανταλλαγή παραθύρου με άλλο προς την κατεύθυνση του βέλους, συμπεριλαμβανομένου ενός στην οθόνη εκείνης της πλευράς |
| `Super + Minus` | Επέκταση παραθύρου προς τα αριστερά |
| `Super + Equal` | Συρρίκνωση παραθύρου προς τα αριστερά |
| `Super + Shift + Minus` | Συρρίκνωση παραθύρου προς τα πάνω |
| `Super + Shift + Equal` | Επέκταση παραθύρου προς τα κάτω |
| `Super + Alt + Minus/Equal` | Ίδια αλλαγή μεγέθους σε μικρότερα βήματα |
| `Super + Ctrl + Minus/Equal` | Ίδια αλλαγή μεγέθους σε μεγαλύτερα βήματα |
| `Super + Alt + Home` | Αποθήκευση πλάτους παραθύρου |
| `Super + Home` | Επαναφορά αποθηκευμένου πλάτους παραθύρου |
| `Super + Left Mouse` | Σύρσιμο παραθύρου |
| `Super + Right Mouse` | Αλλαγή μεγέθους παραθύρου |
| `Super + Scroll Wheel` | Κύλιση στους χώρους εργασίας στην εστιασμένη οθόνη |
| `Super + G` | Εναλλαγή ομαδοποίησης παραθύρου |
| `Super + Alt + G` | Μετακίνηση παραθύρου έξω από την ομάδα |
| `Super + Alt + Tab` | Κυκλική εναλλαγή ανάμεσα στα παράθυρα της ομάδας |
| `Super + Alt + Shift + Tab` | Κυκλική εναλλαγή προς τα πίσω ανάμεσα στα παράθυρα της ομάδας |
| `Super + Alt + Scroll Wheel` | Κυκλική εναλλαγή ανάμεσα στα παράθυρα της ομάδας |
| `Super + Alt + 1/2/3/4/5` | Μετάβαση σε συγκεκριμένο παράθυρο της ομάδας |
| `Super + Alt + Arrow` | Μετακίνηση παραθύρου μέσα στην ομάδα προς την κατεύθυνση του βέλους, συμπεριλαμβανομένου ενός στην οθόνη εκείνης της πλευράς |
| `Super + Ctrl + Left/Right` | Μετακίνηση ανάμεσα στα παράθυρα μέσα σε μια ομάδα πλακιδίων |
| `Super + Ctrl + Z` | Μεγέθυνση στην οθόνη (επαναλάβετε για μεγαλύτερη μεγέθυνση) |
| `Super + Ctrl + Alt + Z` | Πλήρης σμίκρυνση από την οθόνη |
| `Super + /` | Προχώρημα βήμα-βήμα στις επιλογές κλιμάκωσης οθόνης |
| `Super + Alt + /` | Πίσω βήμα-βήμα στις επιλογές κλιμάκωσης οθόνης |
| `Alt + Tab` | Κυκλική εναλλαγή προς τα εμπρός ανάμεσα στα παράθυρα στον ενεργό χώρο εργασίας |
| `Alt + Shift + Tab` | Κυκλική εναλλαγή προς τα πίσω ανάμεσα στα παράθυρα στον ενεργό χώρο εργασίας |
| `Ctrl + Alt + Tab` | Κυκλική εναλλαγή της εστίασης προς τα εμπρός ανάμεσα στις οθόνες |
| `Ctrl + Alt + Shift + Tab` | Κυκλική εναλλαγή της εστίασης προς τα πίσω ανάμεσα στις οθόνες |

## Καθολικό πρόχειρο

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Super + C` | Αντιγραφή |
| `Super + X` | Αποκοπή (όχι στο τερματικό) |
| `Super + V` | Επικόλληση |
| `Super + Ctrl + V` | Διαχειριστής προχείρου |

Συνήθως στο Linux, χρειάζεστε `Ctrl + Shift + C/V` για να αντιγράφετε και να επικολλάτε στο τερματικό και `Ctrl + C/V` για να το κάνετε παντού αλλού. Αυτές οι ενοποιημένες συντομεύσεις προχείρου του Omarchy λειτουργούν παντού.

## Καταγραφή

| Πλήκτρο συντόμευσης | Λειτουργία |
| ------------------- | ------------------------------ |
| `Print Screen` | Στιγμιότυπο οθόνης |
| `Super + Ctrl + Alt + C` | Στιγμιότυπο οθόνης (η ίδια λήψη, για πληκτρολόγια χωρίς πλήκτρο Print Screen) |
| `Super + Ctrl + C` | Μενού καταγραφής |

| `Super + Print Screen` | Επιλογέας χρώματος |
| `Super + Ctrl + Print Screen` | Εξαγωγή κειμένου στο πρόχειρο |
| `Super + Alt + [` | Μίκρυνση της επικάλυψης της κάμερας web κατά την εγγραφή |
| `Super + Alt + ]` | Μεγάλωμα της επικάλυψης της κάμερας web κατά την εγγραφή |
| `Alt + Shift + L` | Αντιγραφή του τρέχοντος URL από webapp ή Chromium |
| `Alt + Shift + D` | Λήψη του βίντεο της τρέχουσας σελίδας στο `~/Videos` |
| `Super + Ctrl + X` | Έναρξη/διακοπή υπαγόρευσης (απαιτεί _Ρύθμιση > Προεπιλογές > Υπαγόρευση_) |

Με τις εγγραφές οθόνης, η συντόμευση ρωτά πρώτα ποιον ήχο θέλετε και μετά ξεκινά την εγγραφή. Πατήστε την ξανά για να σταματήσετε. Δείτε [στιγμιότυπα οθόνης και εγγραφή](12-screenshots-recording.md) για λεπτομέρειες.

Όλες οι επιλογές καταγραφής είναι επίσης διαθέσιμες στο _Ενεργοποίηση > Καταγραφή_ στο μενού Omarchy (`Super + Space`).

## Tmux

Το πλήκτρο prefix είναι το `Ctrl + Space` (λειτουργεί επίσης το `Ctrl + B`). Μπορείτε να αλλάξετε αυτές τις συντομεύσεις στο `~/.config/tmux/tmux.conf`.

### Πλαίσια

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + v` | Διαίρεση πλαισίου δίπλα (κατακόρυφα) |
| `Prefix + h` | Διαίρεση πλαισίου κάτω (οριζόντια) |
| `Prefix + x` | Τερματισμός πλαισίου |
| `Prefix + z` | Εναλλαγή μεγέθυνσης πλαισίου (πλήρης οθόνη) |
| `Alt + Enter` | Διαίρεση πλαισίου κάτω (χωρίς prefix) |
| `Alt + Shift + Enter` | Διαίρεση πλαισίου δίπλα (χωρίς prefix) |
| `Alt + Escape` | Τερματισμός πλαισίου (χωρίς prefix) |
| `Ctrl + Alt + Arrows` | Μετακίνηση ανάμεσα στα πλαίσια |
| `Ctrl + Alt + Shift + Arrows` | Αλλαγή μεγέθους πλαισίων |

### Παράθυρα

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + c` | Νέο παράθυρο |
| `Prefix + k` | Τερματισμός παραθύρου |
| `Prefix + r` | Μετονομασία παραθύρου |
| `Alt + 1-9` | Μετάβαση σε συγκεκριμένο παράθυρο |
| `Alt + Arrow Left/Right` | Μετακίνηση ανάμεσα στα παράθυρα |
| `Alt + Shift + Arrow Left/Right` | Μετακίνηση παραθύρου αριστερά/δεξιά |

### Συνεδρίες

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + C` | Νέα συνεδρία |
| `Prefix + K` | Τερματισμός συνεδρίας |
| `Prefix + R` | Μετονομασία συνεδρίας |
| `Prefix + N` | Επόμενη συνεδρία |
| `Prefix + P` | Προηγούμενη συνεδρία |
| `Alt + Arrow Up/Down` | Μετακίνηση ανάμεσα στις συνεδρίες |
| `Prefix + s` | Λίστα συνεδριών |
| `Prefix + d` | Αποσύνδεση από τη συνεδρία |

### Λειτουργία αντιγραφής (vi-style)

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + [` | Είσοδος στη λειτουργία αντιγραφής |
| `v` | Έναρξη επιλογής (στη λειτουργία αντιγραφής) |
| `y` | Αντιγραφή επιλογής (στη λειτουργία αντιγραφής) |

### Γενικά

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + q` | Επαναφόρτωση διαμόρφωσης |
| `Prefix + ?` | Εμφάνιση συντομεύσεων Tmux |
| `Prefix + :` | Γραμμή εντολών |

### Συναρτήσεις διάταξης Tmux

Αυτές οι συναρτήσεις πρέπει να εκτελούνται μέσα σε μια συνεδρία Tmux.

| Εντολή | Λειτουργία |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Δημιουργία διάταξης ανάπτυξης με επεξεργαστή, AI και τερματικό |
| `tdlm <ai> [<second_ai>]` | Δημιουργία διάταξης ανάπτυξης ανά υποκατάλογο |
| `tsl <count> <command>` | Δημιουργία διάταξης swarm με πολλά πλαίσια |
