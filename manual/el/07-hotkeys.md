# Πλήκτρα συντόμευσης

Μπορείτε να δείτε όλες τις κύριες συντομεύσεις πληκτρολογίου με το `Super + K` (τις συντομεύσεις του Tmux με το `Super + Alt + K` και τις συντομεύσεις του Herdr με το `Super + Ctrl + K`).

## Πώς είναι οργανωμένες οι συντομεύσεις

Κάθε συντόμευση βρίσκεται σε ένα επίπεδο, που ορίζεται από τους τροποποιητές της, και κάθε επίπεδο έχει μία δουλειά. Αυτό κρατά τις συντομεύσεις από το να μπερδεύονται μεταξύ τους, και σημαίνει ότι συνήθως μπορείτε να μαντέψετε πού βρίσκεται κάτι.

| Επίπεδο | Τι βρίσκεται εκεί | Παραδείγματα |
| --- | --- | --- |
| `Super + key` | Το σύστημα: παράθυρα, χώροι εργασίας, διατάξεις και βασικά μενού | `Super + Space` μενού Omarchy, `Super + W` κλείσιμο παραθύρου, `Super + F` πλήρης οθόνη |
| `Super + Shift + key` | Εφαρμογές | `Super + Shift + B` πρόγραμμα περιήγησης, `Super + Shift + E` email, `Super + Shift + N` επεξεργαστής |
| `Super + Ctrl + key` | Πίνακες και μενού συστήματος | `Super + Ctrl + A` ήχος, `Super + Ctrl + N` δίκτυο, `Super + Ctrl + C` μενού καταγραφής |
| `Super + Ctrl + Alt + key` | Γρήγορες ενέργειες και ειδοποιήσεις | `Super + Ctrl + Alt + T` εμφάνιση ώρας, `Super + Ctrl + Alt + B` μπαταρία, `Super + Ctrl + Alt + C` στιγμιότυπο οθόνης |

Προσθέτοντας το `Alt` σε μια συντόμευση παίρνετε μια παραλλαγή του ίδιου πράγματος, ποτέ κάτι άσχετο:

- Το `Super + Shift + B` ανοίγει το πρόγραμμα περιήγησης· το `Super + Shift + Alt + B` ανοίγει ένα ιδιωτικό παράθυρο
- Το `Super + Shift + E` ανοίγει το email· το `Super + Shift + Alt + E` ξεκινά ένα νέο
- Το `Super + F` μεταβαίνει σε πλήρη οθόνη· το `Super + Alt + F` μεταβαίνει σε πλήρες πλάτος
- Το `Super + Ctrl + C` ανοίγει το μενού καταγραφής· το `Super + Ctrl + Alt + C` παρακάμπτει το μενού και τραβά ένα στιγμιότυπο οθόνης

Όταν προσθέτετε μια συντόμευση:

1. Επιλέξτε το επίπεδο από αυτό που κάνει, και μετά επιλέξτε το πλήκτρο.
2. Μην μετακινείτε μια υπάρχουσα συντόμευση για να κάνετε χώρο. Βρείτε ένα ελεύθερο πλήκτρο στο σωστό επίπεδο.
3. Χρησιμοποιείτε το `Alt` μόνο για μια παραλλαγή της συντόμευσης χωρίς αυτό.

Λίγες συντομεύσεις παραβιάζουν αυτούς τους κανόνες επειδή είναι βολικές. Το `Shift` με ένα βέλος ή το `Tab` μετακινεί ή αντιστρέφει αντί να ανοίγει μια εφαρμογή, και το `Print`, τα πλήκτρα πολυμέσων, το `Alt + Tab` και το `Ctrl + Alt + Del` λειτουργούν όπως παντού αλλού. Είναι εξαιρέσεις, όχι μοτίβα για αντιγραφή.

Αν μια προεπιλογή δεν σας ταιριάζει (πείτε ότι θέλετε το `Super + Shift + S` για στιγμιότυπα οθόνης όπως στα Windows), αλλάξτε την στο `~/.config/hypr/bindings.lua`.

| `Ctrl + Alt + Shift + Tab` | Κυκλική μετακίνηση εστίασης προς τα πίσω μεταξύ οθονών |

Οι συντομεύσεις αλλαγής μεγέθους χρησιμοποιούν τα φυσικά πλήκτρα `code:20` και `code:21` (XKB `<AE11>` και `<AE12>`), ανεξάρτητα από τους χαρακτήρες που είναι τυπωμένοι στο πληκτρολόγιο. Στα πληκτρολόγια ΗΠΑ αυτά τα πλήκτρα είναι τα `-` και `=`· στα ιαπωνικά (JIS) πληκτρολόγια είναι τα `-` και `^`· στα ισπανικά πληκτρολόγια είναι τα `'` και `¡`. Στα JIS, το `Super + ^` είναι το `Super + Equal`, ενώ το `Super + Shift + -` (που πληκτρολογεί `=`) είναι το `Super + Shift + Minus`.

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Super + A` | Επιλογή όλων σε εφαρμογές που υποστηρίζουν το `Ctrl + A` |
| `Super + C` | Αντιγραφή |
| `Super + X` | Αποκοπή (όχι στο τερματικό) |
| `Super + V` | Επικόλληση |

Συνήθως στο Linux, χρειάζεστε το `Ctrl + Shift + C/V` για αντιγραφή'n'επικόλληση στο τερματικό και το `Ctrl + C/V` για να το κάνετε παντού αλλού. Αυτές οι ενοποιημένες συντομεύσεις πρόχειρου του Omarchy λειτουργούν παντού.

## Tmux

Το πλήκτρο προθέματος είναι το `Ctrl + Space` (λειτουργεί επίσης το `Ctrl + B`). Μπορείτε να αλλάξετε αυτές τις συντομεύσεις στο `~/.config/tmux/tmux.conf`.

### Πλαίσια

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + v` | Διαίρεση πλαισίου δίπλα (κάθετα) |
| `Prefix + h` | Διαίρεση πλαισίου κάτω (οριζόντια) |
| `Prefix + x` | Τερματισμός πλαισίου |
| `Prefix + z` | Εναλλαγή ζουμ πλαισίου (πλήρης οθόνη) |
| `Alt + Enter` | Διαίρεση πλαισίου κάτω (χωρίς πρόθεμα) |
| `Alt + Shift + Enter` | Διαίρεση πλαισίου δίπλα (χωρίς πρόθεμα) |
| `Alt + Escape` | Τερματισμός πλαισίου (χωρίς πρόθεμα) |
| `Ctrl + Alt + Arrows` | Μετακίνηση μεταξύ πλαισίων |
| `Ctrl + Alt + Shift + Arrows` | Αλλαγή μεγέθους πλαισίων |
