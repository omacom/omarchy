# Συντομεύσεις πληκτρολογίου

Μπορείτε να δείτε όλες τις κύριες συντομεύσεις πληκτρολογίου με το `Super + K` (συντομεύσεις Tmux με το `Super + Alt + K` και συντομεύσεις Herdr με το `Super + Ctrl + K`).

## Πώς είναι οργανωμένες οι συντομεύσεις

Κάθε συντόμευση βρίσκεται σε ένα επίπεδο, που ορίζεται από τους τροποποιητές της, και κάθε επίπεδο έχει μία δουλειά. Γι' αυτό οι συντομεύσεις δεν μπλέκονται μεταξύ τους, και συνήθως μπορείτε να μαντέψετε πού βρίσκεται κάτι.

| Επίπεδο | Τι βρίσκεται εκεί | Παραδείγματα |
| --- | --- | --- |
| `Super + key` | Το σύστημα: παράθυρα, χώροι εργασίας, διατάξεις και βασικά μενού | `Super + Space` μενού Omarchy, `Super + W` κλείσιμο παραθύρου, `Super + F` πλήρης οθόνη |
| `Super + Shift + key` | Εφαρμογές | `Super + Shift + B` πρόγραμμα περιήγησης, `Super + Shift + E` email, `Super + Shift + N` επεξεργαστής |
| `Super + Ctrl + key` | Πίνακες και μενού συστήματος | `Super + Ctrl + A` ήχος, `Super + Ctrl + N` δίκτυο, `Super + Ctrl + C` μενού λήψης |
| `Super + Ctrl + Alt + key` | Γρήγορες ενέργειες και ειδοποιήσεις | `Super + Ctrl + Alt + T` εμφάνιση ώρας, `Super + Ctrl + Alt + B` μπαταρία, `Super + Ctrl + Alt + C` στιγμιότυπο οθόνης |

Η προσθήκη του `Alt` σε μια συντόμευση σάς δίνει μια παραλλαγή του ίδιου πράγματος, ποτέ κάτι άσχετο:

- Το `Super + Shift + B` ανοίγει το πρόγραμμα περιήγησης· το `Super + Shift + Alt + B` ανοίγει ένα ιδιωτικό παράθυρο
- Το `Super + Shift + E` ανοίγει το email· το `Super + Shift + Alt + E` ξεκινά ένα νέο
- Το `Super + F` μεταβαίνει σε πλήρη οθόνη· το `Super + Alt + F` μεταβαίνει σε πλήρες πλάτος
- Το `Super + Ctrl + C` ανοίγει το μενού λήψης· το `Super + Ctrl + Alt + C` παρακάμπτει το μενού και τραβά ένα στιγμιότυπο οθόνης

Όταν προσθέτετε μια συντόμευση:

1. Διαλέξτε το επίπεδο από το τι κάνει, μετά διαλέξτε το πλήκτρο.
2. Μην μετακινείτε μια υπάρχουσα συντόμευση για να κάνετε χώρο. Βρείτε ένα ελεύθερο πλήκτρο στο σωστό επίπεδο.
3. Χρησιμοποιείτε το `Alt` μόνο για μια παραλλαγή της συντόμευσης χωρίς αυτό.

Μερικές συντομεύσεις παραβιάζουν αυτούς τους κανόνες επειδή είναι βολικές. Το `Shift` με ένα βέλος ή το `Tab` μετακινεί ή αντιστρέφει αντί να ανοίγει μια εφαρμογή, και το `Print`, τα πλήκτρα πολυμέσων, το `Alt + Tab` και το `Ctrl + Alt + Del` λειτουργούν όπως λειτουργούν παντού αλλού. Είναι εξαιρέσεις, όχι πρότυπα για αντιγραφή.

Αν μια προεπιλογή δεν σας ταιριάζει (ας πούμε ότι θέλετε το `Super + Shift + S` για στιγμιότυπα οθόνης όπως στα Windows), αλλάξτε την στο `~/.config/hypr/bindings.lua`.

Σε μια επιφάνεια αφής, οι σαρώσεις με τρία και τέσσερα δάχτυλα αλλάζουν χώρους εργασίας, μετακινούν παράθυρα και ανοίγουν το μενού και την κονσόλα Quake· δείτε το [πληκτρολόγιο, ποντίκι και επιφάνεια αφής](34-keyboard-mouse-trackpad.md) για τις χειρονομίες.

Οι συντομεύσεις αλλαγής μεγέθους χρησιμοποιούν τα φυσικά πλήκτρα `code:20` και `code:21` (XKB `<AE11>` και `<AE12>`), ανεξάρτητα από τους χαρακτήρες που είναι τυπωμένοι στο πληκτρολόγιο. Στα πληκτρολόγια US αυτά τα πλήκτρα είναι `-` και `=`· στα ιαπωνικά (JIS) πληκτρολόγια είναι `-` και `^`· στα ισπανικά πληκτρολόγια είναι `'` και `¡`. Στο JIS, το `Super + ^` είναι `Super + Equal`, ενώ το `Super + Shift + -` (που πληκτρολογεί `=`) είναι `Super + Shift + Minus`.

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Super + A`           | Επιλογή όλων σε εφαρμογές που υποστηρίζουν το `Ctrl + A`    |
| `Super + C`           | Αντιγραφή    |
| `Super + X`           | Αποκοπή (όχι στο τερματικό)    |
| `Super + V`           | Επικόλληση    |

## Tmux

Το πλήκτρο προθέματος είναι το `Ctrl + Space` (το `Ctrl + B` λειτουργεί επίσης). Μπορείτε να αλλάξετε αυτές τις συντομεύσεις στο `~/.config/tmux/tmux.conf`.

### Υποπαράθυρα

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + v` | Διαίρεση υποπαραθύρου δίπλα (κάθετα) |
| `Prefix + h` | Διαίρεση υποπαραθύρου κάτω (οριζόντια) |
| `Prefix + x` | Τερματισμός υποπαραθύρου |
| `Prefix + z` | Εναλλαγή ζουμ υποπαραθύρου (πλήρης οθόνη) |
| `Alt + Enter` | Διαίρεση υποπαραθύρου κάτω (χωρίς πρόθεμα) |
| `Alt + Shift + Enter` | Διαίρεση υποπαραθύρου δίπλα (χωρίς πρόθεμα) |
| `Alt + Escape` | Τερματισμός υποπαραθύρου (χωρίς πρόθεμα) |
| `Ctrl + Alt + Arrows` | Μετακίνηση ανάμεσα σε υποπαράθυρα |
| `Ctrl + Alt + Shift + Arrows` | Αλλαγή μεγέθους υποπαραθύρων |

### Παράθυρα

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + c` | Νέο παράθυρο |
| `Prefix + k` | Τερματισμός παραθύρου |
| `Prefix + r` | Μετονομασία παραθύρου |
| `Alt + 1-9` | Μετάβαση σε συγκεκριμένο παράθυρο |
| `Alt + Arrow Left/Right` | Μετακίνηση ανάμεσα σε παράθυρα |
| `Alt + Shift + Arrow Left/Right` | Μετακίνηση παραθύρου αριστερά/δεξιά |

### Συνεδρίες

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + C` | Νέα συνεδρία |
| `Prefix + K` | Τερματισμός συνεδρίας |
| `Prefix + R` | Μετονομασία συνεδρίας |
| `Prefix + N` | Επόμενη συνεδρία |
| `Prefix + P` | Προηγούμενη συνεδρία |
| `Alt + Arrow Up/Down` | Μετακίνηση ανάμεσα σε συνεδρίες |
| `Prefix + s` | Λίστα συνεδριών |
| `Prefix + d` | Αποσύνδεση από συνεδρία |

### Λειτουργία αντιγραφής (στυλ vi)

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + [` | Είσοδος σε λειτουργία αντιγραφής |
| `v` | Έναρξη επιλογής (σε λειτουργία αντιγραφής) |
| `y` | Αντιγραφή επιλογής (σε λειτουργία αντιγραφής) |

### Γενικά

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + q` | Επαναφόρτωση διαμόρφωσης |
| `Prefix + ?` | Εμφάνιση συντομεύσεων Tmux |
| `Prefix + :` | Γραμμή εντολών |

### Συναρτήσεις διάταξης Tmux

Αυτές οι συναρτήσεις πρέπει να εκτελούνται μέσα σε μια συνεδρία Tmux.

| Εντολή | Λειτουργία |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Δημιουργία διάταξης ανάπτυξης με επεξεργαστή, AI και τερματικό |
| `tdlm <ai> [<second_ai>]` | Δημιουργία διάταξης ανάπτυξης ανά υποκατάλογο |
| `tsl <count> <command>` | Δημιουργία διάταξης σμήνους πολλαπλών υποπαραθύρων |
