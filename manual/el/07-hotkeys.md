# Συντομεύσεις

Μπορείς να δεις όλες τις κύριες αντιστοιχίσεις πληκτρολογίου με `Super + K` (τις αντιστοιχίσεις Tmux με `Super + Alt + K` και τις αντιστοιχίσεις Herdr με `Super + Ctrl + K`).

## Πλοήγηση

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Super + Space`           | Μενού Omarchy (εφαρμογές και όλα τα υπόλοιπα)    |
| `Super + Alt + Space` | Πλέγμα εφαρμογών |
| `Super + Escape` | Μενού συστήματος (αναστολή, επανεκκίνηση, κλπ.)  |
| `Super + Ctrl + L` | Κλείδωμα υπολογιστή |
| `Super + W` or `Super + Q` | Κλείσιμο παραθύρου             |
| `Ctrl + Alt + Del` | Κλείσιμο όλων των παραθύρων |
| `Super + T`               | Εναλλαγή παραθύρου μεταξύ tiling/αιωρούμενο             |
| `Super + J` | Εναλλαγή θέσης παραθύρου (οριζόντια/κατακόρυφη) |
| `Super + O`               | Εναλλαγή αναδυόμενου παραθύρου σε κολλώδες και αιωρούμενο |
| `Super + L`               | Κύκλωση στις διατάξεις dwindle, κύλισης και αιωρούμενη |
| `Super + Alt + L`         | Κύκλωση στις διατάξεις αντίστροφα |
| `Super + P`               | Εναλλαγή ψευδο-στυλ παραθύρου (φυσικό έναντι τεντωμένο) |
| `Super + F`                 | Μετάβαση σε πλήρη οθόνη              |
| `Super + Alt + F`                 | Μετάβαση σε πλήρες πλάτος              |
| `Super + Ctrl + F`                 | Μετάβαση σε πλήρη οθόνη μέσα σε παράθυρο              |
| `Super + 1/2/3/4`         | Άλμα σε συγκεκριμένο χώρο εργασίας     |
| `Super + Tab` | Άλμα στον επόμενο χώρο εργασίας |
| `Super + Shift + Tab` | Άλμα στον προηγούμενο χώρο εργασίας |
| `Super + Ctrl + Tab` | Άλμα στον προγενέστερο χώρο εργασίας |
| `Super + Shift + 1/2/3/4` | Μετακίνηση παραθύρου σε χώρο εργασίας |
| `Super + Shift + Alt + 1/2/3/4` | Μετακίνηση παραθύρου σε χώρο εργασίας χωρίς ακολούθηση |
| `Super + S` / `Super + Grave` | Εναλλαγή προχείρου |
| `Super + Alt + S` / `Super + Shift + Grave` | Μετακίνηση παραθύρου στο πρόχειρο |
| `Super + Shift + Alt + Arrows` | Μετακίνηση χώρων εργασίας σε κατευθυντική οθόνη |
| `Super + Arrow`  | Μετακίνηση εστίασης στο παράθυρο προς την κατεύθυνση του βέλους              |
| `Super + Shift + Arrow`  | Εναλλαγή παραθύρου με άλλο προς την κατεύθυνση του βέλους     |
| `Super + Minus` | Επέκταση παραθύρου προς τα αριστερά |
| `Super + Equal` | Συρρίκνωση παραθύρου προς τα αριστερά |
| `Super + Shift + Minus` | Συρρίκνωση παραθύρου προς τα πάνω |
| `Super + Shift + Equal` | Επέκταση παραθύρου προς τα κάτω |
| `Super + Alt + Minus/Equal` | Ίδια αλλαγή μεγέθους σε μικρότερα βήματα |
| `Super + Ctrl + Minus/Equal` | Ίδια αλλαγή μεγέθους σε μεγαλύτερα βήματα |
| `Super + Alt + Home` | Αποθήκευση πλάτους παραθύρου |
| `Super + Home` | Επαναφορά αποθηκευμένου πλάτους παραθύρου |
| `Super + Left Mouse` | Σύρσιμο παραθύρου |
| `Super + Right Mouse` | Αλλαγή μεγέθους παραθύρου |
| `Super + Scroll Wheel` | Κύλιση στους χώρους εργασίας |
| `Super + G`               | Εναλλαγή ομαδοποίησης παραθύρων      |
| `Super + Alt + G`               | Μετακίνηση παραθύρου έξω από την ομαδοποίηση      |
| `Super + Alt + Tab`               | Κύκλωση ανάμεσα σε παράθυρα στην ομαδοποίηση      |
| `Super + Alt + Shift + Tab`               | Κύκλωση προς τα πίσω ανάμεσα σε παράθυρα στην ομαδοποίηση      |
| `Super + Alt + 1/2/3/4/5`               | Άλμα σε συγκεκριμένο παράθυρο στην ομαδοποίηση      |
| `Super + Alt + Arrow`  | Μετακίνηση παραθύρου μέσα στην ομαδοποίηση προς την κατεύθυνση του βέλους  |
| `Super + Ctrl + Left/Right`  | Μετακίνηση ανάμεσα σε παράθυρα μέσα σε ομάδα tiling |
| `Super + Ctrl + Z` | Ζουμ στην οθόνη (επανάλαβε για περισσότερο ζουμ) |
| `Super + Ctrl + Alt + Z` | Πλήρες ξεζούμισμα από την οθόνη |
| `Super + /` | Βήμα μπροστά στις επιλογές κλιμάκωσης οθόνης |
| `Super + Alt + /` | Βήμα πίσω στις επιλογές κλιμάκωσης οθόνης |
| `Alt + Tab` | Κύκλωση μπροστά στα παράθυρα του ενεργού χώρου εργασίας |
| `Alt + Shift + Tab` | Κύκλωση πίσω στα παράθυρα του ενεργού χώρου εργασίας |
| `Ctrl + Alt + Tab`| Κύκλωση εστίασης μπροστά στις οθόνες |
| `Ctrl + Alt + Shift + Tab`| Κύκλωση εστίασης πίσω στις οθόνες |

## Καθολικό πρόχειρο

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Super + C`           | Αντιγραφή    |
| `Super + X`           | Αποκοπή (όχι στο τερματικό)    |
| `Super + V`           | Επικόλληση    |
| `Super + Ctrl + V`           | Διαχειριστής προχείρου    |

Συνήθως στο Linux, χρειάζεσαι `Ctrl + Shift + C/V` για αντιγραφή και επικόλληση στο τερματικό και `Ctrl + C/V` για να το κάνεις παντού αλλού. Αυτές οι ενοποιημένες συντομεύσεις προχείρου του Omarchy δουλεύουν παντού.

## Καταγραφή

| Συντόμευση              | Λειτουργία                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Μενού καταγραφής (για πληκτρολόγια χωρίς κουμπί PrintScr) |
| `Print Screen`            | Στιγμιότυπο                      |
| `Alt + Print Screen`            | Εγγραφή οθόνης                     |
| `Super + Print Screen` | Επιλογέας χρώματος |
| `Super + Ctrl + Print Screen` | Εξαγωγή κειμένου στο πρόχειρο |
| `Super + Alt + [` | Μικρότερη επικάλυψη webcam κατά την εγγραφή |
| `Super + Alt + ]` | Μεγαλύτερη επικάλυψη webcam κατά την εγγραφή |
| `Alt + Shift + L` | Αντιγραφή τρέχοντος URL από webapp ή Chromium |
| `Alt + Shift + D` | Κατέβασμα του βίντεο της τρέχουσας σελίδας στο `~/Videos` |
| `Super + Ctrl + X` | Έναρξη/διακοπή υπαγόρευσης (απαιτεί _Ρύθμιση > Προεπιλογές > Dictation_) |
| `Right Alt` / `F9` | Υπαγόρευση push-to-talk (απαιτεί Voxtype ή Superwhisper) |

Με τις εγγραφές οθόνης, η συντόμευση ρωτάει πρώτα ποιον ήχο θέλεις, μετά ξεκινά την εγγραφή. Πάτησέ τη ξανά για διακοπή. Δες [στιγμιότυπα και εγγραφή](12-screenshots-recording.md) για τις λεπτομέρειες.

Όλες οι επιλογές καταγραφής είναι επίσης προσβάσιμες στο _Ενεργοποίηση > Καταγραφή_ στο μενού Omarchy (`Super + Space`).

## Tmux

Το πλήκτρο prefix είναι `Ctrl + Space` (δουλεύει επίσης το `Ctrl + B`). Μπορείς να αλλάξεις αυτές τις αντιστοιχίσεις στο `~/.config/tmux/tmux.conf`.

### Πλαίσια

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + v` | Διαίρεση πλαισίου δίπλα (κατακόρυφα) |
| `Prefix + h` | Διαίρεση πλαισίου κάτω (οριζόντια) |
| `Prefix + x` | Τερματισμός πλαισίου |
| `Prefix + z` | Εναλλαγή ζουμ πλαισίου (πλήρης οθόνη) |
| `Alt + Enter` | Διαίρεση πλαισίου κάτω (χωρίς prefix) |
| `Alt + Shift + Enter` | Διαίρεση πλαισίου δίπλα (χωρίς prefix) |
| `Alt + Escape` | Τερματισμός πλαισίου (χωρίς prefix) |
| `Ctrl + Alt + Arrows` | Μετακίνηση ανάμεσα σε πλαίσια |
| `Ctrl + Alt + Shift + Arrows` | Αλλαγή μεγέθους πλαισίων |

### Παράθυρα

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + c` | Νέο παράθυρο |
| `Prefix + k` | Τερματισμός παραθύρου |
| `Prefix + r` | Μετονομασία παραθύρου |
| `Alt + 1-9` | Μετάβαση σε συγκεκριμένο παράθυρο |
| `Alt + Arrow Left/Right` | Μετακίνηση ανάμεσα σε παράθυρα |
| `Alt + Shift + Arrow Left/Right` | Μετακίνηση παραθύρου αριστερά/δεξιά |

### Συνεδρίες

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + C` | Νέα συνεδρία |
| `Prefix + K` | Τερματισμός συνεδρίας |
| `Prefix + R` | Μετονομασία συνεδρίας |
| `Prefix + N` | Επόμενη συνεδρία |
| `Prefix + P` | Προηγούμενη συνεδρία |
| `Alt + Arrow Up/Down` | Μετακίνηση ανάμεσα σε συνεδρίες |
| `Prefix + s` | Λίστα συνεδριών |
| `Prefix + d` | Αποσύνδεση από συνεδρία |

### Λειτουργία αντιγραφής (στυλ vi)

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + [` | Είσοδος στη λειτουργία αντιγραφής |
| `v` | Έναρξη επιλογής (στη λειτουργία αντιγραφής) |
| `y` | Αντιγραφή επιλογής (στη λειτουργία αντιγραφής) |

### Γενικά

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + q` | Επαναφόρτωση config |
| `Prefix + ?` | Εμφάνιση αντιστοιχίσεων Tmux |
| `Prefix + :` | Γραμμή εντολών |

### Συναρτήσεις διάταξης Tmux

Αυτές οι συναρτήσεις πρέπει να τρέξουν μέσα σε μια συνεδρία Tmux.

| Εντολή | Λειτουργία |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Δημιουργία dev διάταξης με επεξεργαστή, AI και τερματικό |
| `tdlm <ai> [<second_ai>]` | Δημιουργία dev διάταξης ανά υποκατάλογο |
| `tsl <count> <command>` | Δημιουργία διάταξης σμήνους πολλαπλών πλαισίων |

## Γρήγορα Emoji

Μπορείς να χρησιμοποιήσεις το `Super + Ctrl + E` για να εμφανίσεις έναν πλήρη επιλογέα emoji που θα βάλει την επιλογή στο πρόχειρο ή μπορείς να χρησιμοποιήσεις αυτές τις επιλογές γρήγορης πρόσβασης.

| Συντόμευση       | EM | Ένδειξη       |
| ------------ | -- | ---------- |
| `Shift + CapsLock M S` | 😄 | χαμόγελο      |
| `Shift + CapsLock M C` | 😂 | κλάμα        |
| `Shift + CapsLock M L` | 😍 | αγάπη       |
| `Shift + CapsLock M V` | ✌️ | νίκη    |
| `Shift + CapsLock M H` | ❤️ | καρδιά      |
| `Shift + CapsLock M Y` | 👍 | ναι        |
| `Shift + CapsLock M N` | 👎 | όχι         |
| `Shift + CapsLock M F` | 🖕 | φάκελος       |
| `Shift + CapsLock M W` | 🤞 | ευχή       |
| `Shift + CapsLock M R` | 🤘 | ροκ       |
| `Shift + CapsLock M K` | 😘 | φιλί       |
| `Shift + CapsLock M E` | 🙄 | στραβομάτι    |
| `Shift + CapsLock M I` | 😉 | κλείσιμο ματιού       |
| `Shift + CapsLock M P` | 🙏 | προσευχή |

## Γρήγορες συμπληρώσεις

| Συντόμευση       | Συμπλήρωση       |
| ------------ |  ---------- |
| `Shift + CapsLock Space Space` | — (mdash)   |
| `Shift + CapsLock Space N` | Το όνομά σου (όπως εισήχθη στη ρύθμιση)  |
| `Shift + CapsLock Space E` | Το email σου (όπως εισήχθη στη ρύθμιση)  |

Μπορείς να προσθέσεις περισσότερες δικές σου επεξεργάζοντας το `~/.XCompose`, μετά τρέχοντας το `omarchy-restart-xcompose` στο τερματικό για να ληφθούν οι αλλαγές.
