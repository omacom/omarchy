# Συντομεύσεις πληκτρολογίου

Μπορείς να δεις όλες τις κύριες συνδέσεις πλήκτρων με το `Super + K` (συνδέσεις Tmux με το `Super + Alt + K` και συνδέσεις Herdr με το `Super + Ctrl + K`).

## Πώς είναι οργανωμένες οι συντομεύσεις

Κάθε συντόμευση βρίσκεται σε ένα επίπεδο, που ορίζεται από τα πλήκτρα τροποποίησής της, και κάθε επίπεδο έχει μία δουλειά. Έτσι οι συντομεύσεις δεν μπερδεύονται μεταξύ τους, και συνήθως μπορείς να μαντέψεις πού βρίσκεται κάτι.

| Επίπεδο | Τι βρίσκεται εκεί | Παραδείγματα |
| --- | --- | --- |
| `Super + key` | Το σύστημα: παράθυρα, χώροι εργασίας, διατάξεις και βασικά μενού | `Super + Space` μενού Omarchy, `Super + W` κλείσιμο παραθύρου, `Super + F` πλήρης οθόνη |
| `Super + Shift + key` | Εφαρμογές | `Super + Shift + B` πρόγραμμα περιήγησης, `Super + Shift + E` email, `Super + Shift + N` επεξεργαστής |
| `Super + Ctrl + key` | Πάνελ και μενού συστήματος | `Super + Ctrl + A` ήχος, `Super + Ctrl + N` δίκτυο, `Super + Ctrl + C` μενού λήψης |
| `Super + Ctrl + Alt + key` | Γρήγορες ενέργειες και ειδοποιήσεις | `Super + Ctrl + Alt + T` εμφάνιση ώρας, `Super + Ctrl + Alt + B` μπαταρία, `Super + Ctrl + Alt + C` στιγμιότυπο οθόνης |

Η προσθήκη του `Alt` σε μια συντόμευση σού δίνει μια παραλλαγή του ίδιου πράγματος, ποτέ κάτι άσχετο:

- `Super + Shift + B` ανοίγει το πρόγραμμα περιήγησης· `Super + Shift + Alt + B` ανοίγει ένα ιδιωτικό παράθυρο
- `Super + Shift + E` ανοίγει το email· `Super + Shift + Alt + E` ξεκινά ένα νέο
- `Super + F` μεταβαίνει σε πλήρη οθόνη· `Super + Alt + F` μεταβαίνει σε πλήρες πλάτος
- `Super + Ctrl + C` ανοίγει το μενού λήψης· `Super + Ctrl + Alt + C` παρακάμπτει το μενού και τραβά ένα στιγμιότυπο οθόνης

Όταν προσθέτεις μια συντόμευση:

1. Διάλεξε το επίπεδο ανάλογα με το τι κάνει, μετά διάλεξε το πλήκτρο.
2. Μην μετακινείς μια υπάρχουσα συντόμευση για να κάνεις χώρο. Βρες ένα ελεύθερο πλήκτρο στο σωστό επίπεδο.
3. Χρησιμοποίησε το `Alt` μόνο για μια παραλλαγή της συντόμευσης χωρίς αυτό.

Μερικές συντομεύσεις παραβιάζουν αυτούς τους κανόνες επειδή είναι βολικές. Το `Shift` με ένα βέλος ή `Tab` μετακινεί ή αντιστρέφει αντί να ανοίγει μια εφαρμογή, και το `Print`, τα πλήκτρα πολυμέσων, το `Alt + Tab` και το `Ctrl + Alt + Del` λειτουργούν όπως παντού αλλού. Είναι εξαιρέσεις, όχι πρότυπα για αντιγραφή.

Αν μια προεπιλογή δεν σε βολεύει (ας πούμε θέλεις το `Super + Shift + S` για στιγμιότυπα οθόνης όπως στα Windows), άλλαξέ τη στο `~/.config/hypr/bindings.lua`.

Σε ένα touchpad, οι ολισθήσεις με τρία και τέσσερα δάχτυλα αλλάζουν χώρους εργασίας, μετακινούν παράθυρα και ανοίγουν το μενού και την κονσόλα Quake· δες το [πληκτρολόγιο, ποντίκι και trackpad](34-keyboard-mouse-trackpad.md) για τις χειρονομίες.

Οι συντομεύσεις αλλαγής μεγέθους χρησιμοποιούν τα φυσικά πλήκτρα `code:20` και `code:21` (XKB `<AE11>` και `<AE12>`), ανεξάρτητα από τους χαρακτήρες που είναι τυπωμένοι στο πληκτρολόγιο. Στα πληκτρολόγια US αυτά τα πλήκτρα είναι τα `-` και `=`· στα ιαπωνικά πληκτρολόγια (JIS) είναι τα `-` και `^`· στα ισπανικά πληκτρολόγια είναι τα `'` και `¡`. Στο JIS, το `Super + ^` είναι `Super + Equal`, ενώ το `Super + Shift + -` (που πληκτρολογεί `=`) είναι `Super + Shift + Minus`.

| Συντόμευση | Λειτουργία |
| ----------------------- | --------------------- |
| `Super + A` | Επιλογή όλων σε εφαρμογές που υποστηρίζουν το `Ctrl + A` |
| `Super + C` | Αντιγραφή |
| `Super + X` | Αποκοπή (όχι στο τερματικό) |
| `Super + V` | Επικόλληση |

## Tmux

Το πλήκτρο prefix είναι το `Ctrl + Space` (λειτουργεί επίσης το `Ctrl + B`). Μπορείς να αλλάξεις αυτές τις συνδέσεις στο `~/.config/tmux/tmux.conf`.

### Πλαίσια

| Συντόμευση | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + v` | Διαχωρισμός πλαισίου δίπλα (κάθετα) |
| `Prefix + h` | Διαχωρισμός πλαισίου από κάτω (οριζόντια) |
| `Prefix + x` | Τερματισμός πλαισίου |
| `Prefix + z` | Εναλλαγή μεγέθυνσης πλαισίου (πλήρης οθόνη) |
| `Alt + Enter` | Διαχωρισμός πλαισίου από κάτω (χωρίς prefix) |
| `Alt + Shift + Enter` | Διαχωρισμός πλαισίου δίπλα (χωρίς prefix) |
| `Alt + Escape` | Τερματισμός πλαισίου (χωρίς prefix) |
| `Ctrl + Alt + Arrows` | Μετακίνηση μεταξύ πλαισίων |
| `Ctrl + Alt + Shift + Arrows` | Αλλαγή μεγέθους πλαισίων |

### Παράθυρα

| Συντόμευση | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + c` | Νέο παράθυρο |
| `Prefix + k` | Τερματισμός παραθύρου |
| `Prefix + r` | Μετονομασία παραθύρου |
| `Alt + 1-9` | Μετάβαση σε συγκεκριμένο παράθυρο |
| `Alt + Arrow Left/Right` | Μετακίνηση μεταξύ παραθύρων |
| `Alt + Shift + Arrow Left/Right` | Μετακίνηση παραθύρου αριστερά/δεξιά |

### Συνεδρίες

| Συντόμευση | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + C` | Νέα συνεδρία |
| `Prefix + K` | Τερματισμός συνεδρίας |
| `Prefix + R` | Μετονομασία συνεδρίας |
| `Prefix + N` | Επόμενη συνεδρία |
| `Prefix + P` | Προηγούμενη συνεδρία |
| `Alt + Arrow Up/Down` | Μετακίνηση μεταξύ συνεδριών |
| `Prefix + s` | Λίστα συνεδριών |
| `Prefix + d` | Αποσύνδεση από τη συνεδρία |

### Λειτουργία αντιγραφής (στυλ vi)

| Συντόμευση | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + [` | Είσοδος σε λειτουργία αντιγραφής |
| `v` | Έναρξη επιλογής (σε λειτουργία αντιγραφής) |
| `y` | Αντιγραφή επιλογής (σε λειτουργία αντιγραφής) |

### Γενικά

| Συντόμευση | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + q` | Επαναφόρτωση διαμόρφωσης |
| `Prefix + ?` | Εμφάνιση συνδέσεων πλήκτρων Tmux |
| `Prefix + :` | Γραμμή εντολών |

### Συναρτήσεις διάταξης Tmux

Αυτές οι συναρτήσεις πρέπει να εκτελούνται μέσα σε μια συνεδρία Tmux.

| Εντολή | Λειτουργία |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Δημιουργία διάταξης ανάπτυξης με επεξεργαστή, AI και τερματικό |
| `tdlm <ai> [<second_ai>]` | Δημιουργία διάταξης ανάπτυξης ανά υποκατάλογο |
| `tsl <count> <command>` | Δημιουργία διάταξης σμήνους πολλαπλών πλαισίων |
