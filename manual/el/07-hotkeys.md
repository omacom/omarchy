# Συντομεύσεις πληκτρολογίου

Μπορείτε να δείτε όλες τις κύριες συνδέσεις πληκτρολογίου με `Super + K` (συνδέσεις Tmux με `Super + Alt + K` και συνδέσεις Herdr με `Super + Ctrl + K`).

## Πώς είναι οργανωμένες οι συντομεύσεις

Κάθε συντόμευση βρίσκεται σε ένα επίπεδο, που ορίζεται από τους τροποποιητές της, και κάθε επίπεδο έχει μία δουλειά. Αυτό κρατά τις συντομεύσεις από το να μπερδεύονται μεταξύ τους, και σημαίνει ότι συνήθως μπορείτε να μαντέψετε πού ζει κάτι.

| Επίπεδο | Τι ζει εκεί | Παραδείγματα |
| --- | --- | --- |
| `Super + key` | Το σύστημα: παράθυρα, χώροι εργασίας, διατάξεις και βασικά μενού | `Super + Space` μενού Omarchy, `Super + W` κλείσιμο παραθύρου, `Super + F` πλήρης οθόνη |
| `Super + Shift + key` | Εφαρμογές | `Super + Shift + B` πρόγραμμα περιήγησης, `Super + Shift + E` email, `Super + Shift + N` επεξεργαστής |
| `Super + Ctrl + key` | Πίνακες και μενού συστήματος | `Super + Ctrl + A` ήχος, `Super + Ctrl + N` δίκτυο, `Super + Ctrl + C` μενού καταγραφής |
| `Super + Ctrl + Alt + key` | Γρήγορες ενέργειες και γνωστοποιήσεις | `Super + Ctrl + Alt + T` εμφάνιση ώρας, `Super + Ctrl + Alt + B` μπαταρία, `Super + Ctrl + Alt + C` στιγμιότυπο οθόνης |

Η προσθήκη `Alt` σε μια συντόμευση σάς δίνει μια παραλλαγή του ίδιου πράγματος, ποτέ κάτι άσχετο:

- Το `Super + Shift + B` ανοίγει το πρόγραμμα περιήγησης· το `Super + Shift + Alt + B` ανοίγει ένα ιδιωτικό παράθυρο
- Το `Super + Shift + E` ανοίγει το email· το `Super + Shift + Alt + E` ξεκινά ένα νέο
- Το `Super + F` μεταβαίνει σε πλήρη οθόνη· το `Super + Alt + F` μεταβαίνει σε πλήρες πλάτος
- Το `Super + Ctrl + C` ανοίγει το μενού καταγραφής· το `Super + Ctrl + Alt + C` παρακάμπτει το μενού και τραβά ένα στιγμιότυπο οθόνης

Όταν προσθέτετε μια συντόμευση:

1. Επιλέξτε το επίπεδο από το τι κάνει, έπειτα επιλέξτε το πλήκτρο.
2. Μην μετακινείτε μια υπάρχουσα συντόμευση για να κάνετε χώρο. Βρείτε ένα ελεύθερο πλήκτρο στο σωστό επίπεδο.
3. Χρησιμοποιείτε το `Alt` μόνο για μια παραλλαγή της συντόμευσης χωρίς αυτό.

Μερικές συντομεύσεις παραβιάζουν αυτούς τους κανόνες επειδή είναι βολικές. Το `Shift` με ένα βέλος ή `Tab` μετακινεί ή αντιστρέφει αντί να ανοίγει μια εφαρμογή, και το `Print`, τα πλήκτρα πολυμέσων, το `Alt + Tab` και το `Ctrl + Alt + Del` λειτουργούν όπως λειτουργούν παντού αλλού. Είναι εξαιρέσεις, όχι πρότυπα για αντιγραφή.

Αν μια προεπιλογή δεν σας ταιριάζει (ας πούμε ότι θέλετε το `Super + Shift + S` για στιγμιότυπα οθόνης όπως στα Windows), αλλάξτε τη σύνδεσή της στο `~/.config/hypr/bindings.lua`.

| `Super + /` | Προχώρημα προς τα εμπρός στις επιλογές κλιμάκωσης οθόνης |
| `Super + Alt + /` | Προχώρημα προς τα πίσω στις επιλογές κλιμάκωσης οθόνης |

| `Ctrl + Alt + Shift + Tab` | Κυκλική εναλλαγή εστίασης προς τα πίσω στις οθόνες |
| `Super + I` | Εναλλαγή γλώσσας εισόδου (με περισσότερες από μία διατάξεις ή μεθόδους εισόδου) |
| `Super + Shift + I` | Επαναφορά γλώσσας εισόδου |

Σε ένα touchpad, σαρώσεις με τρία και τέσσερα δάχτυλα αλλάζουν χώρους εργασίας, μετακινούν παράθυρα και ανοίγουν το μενού και την κονσόλα Quake· δείτε το [πληκτρολόγιο, ποντίκι και trackpad](34-keyboard-mouse-trackpad.md) για τις χειρονομίες.

Η αλλαγή μεγέθους χρησιμοποιεί τα δύο πλήκτρα δεξιά του 0, ό,τι κι αν εκτυπώνει το πληκτρολόγιό σας πάνω τους: `-` και `=` σε πληκτρολόγια US, `+` και `´` σε δανέζικα και σουηδικά, `+` και `\` σε νορβηγικά, `ß` και `´` σε γερμανικά, `'` και `¡` σε ισπανικά, και `-` και `^` σε ιαπωνικά (JIS). Το `Super + K` τα παραθέτει όπως τα εκτυπώνει το πληκτρολόγιό σας. Σε JIS, το `Super + ^` είναι `Super + Equal`, ενώ το `Super + Shift + -` (που πληκτρολογεί `=`) είναι `Super + Shift + Minus`. Η κλιμάκωση οθόνης και ο διαχειριστής κωδικών πρόσβασης χρησιμοποιούν το `/`· σε διατάξεις που πληκτρολογούν `/` μόνο με Shift, όπως οι περισσότερες ευρωπαϊκές, χρησιμοποιούν αντ' αυτού το πλήκτρο αριστερά του δεξιού Shift (`-` σε δανέζικα και γερμανικά).

| Συντόμευση | Λειτουργία |
| ----------------------- | --------------------- |
| `Super + A` | Επιλογή όλων σε εφαρμογές που υποστηρίζουν `Ctrl + A` |
| `Super + C` | Αντιγραφή |
| `Super + X` | Αποκοπή (όχι στο τερματικό) |
| `Super + V` | Επικόλληση |

## Tmux

Το πλήκτρο prefix είναι `Ctrl + Space` (`Ctrl + B` λειτουργεί επίσης). Μπορείτε να αλλάξετε αυτές τις συνδέσεις στο `~/.config/tmux/tmux.conf`.

### Πλαίσια

| Συντόμευση | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + v` | Διαίρεση πλαισίου δίπλα (κάθετα) |
| `Prefix + h` | Διαίρεση πλαισίου από κάτω (οριζόντια) |
| `Prefix + x` | Τερματισμός πλαισίου |
| `Prefix + z` | Εναλλαγή ζουμ πλαισίου (πλήρης οθόνη) |
| `Alt + Enter` | Διαίρεση πλαισίου από κάτω (χωρίς prefix) |
| `Alt + Shift + Enter` | Διαίρεση πλαισίου δίπλα (χωρίς prefix) |
| `Alt + Escape` | Τερματισμός πλαισίου (χωρίς prefix) |
| `Ctrl + Alt + Arrows` | Μετακίνηση μεταξύ πλαισίων |
| `Ctrl + Alt + Shift + Arrows` | Αλλαγή μεγέθους πλαισίων |

### Παράθυρα

| Συντόμευση | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + c` | Νέο παράθυρο |
| `Prefix + k` | Τερματισμός παραθύρου |
| `Prefix + r` | Μετονομασία παραθύρου |
| `Alt + 1-9` | Μετάβαση σε συγκεκριμένο παράθυρο |
| `Alt + Arrow Left/Right` | Μετακίνηση μεταξύ παραθύρων |
| `Alt + Shift + Arrow Left/Right` | Μετακίνηση παραθύρου αριστερά/δεξιά |

### Συνεδρίες

| Συντόμευση | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + C` | Νέα συνεδρία |
| `Prefix + K` | Τερματισμός συνεδρίας |
| `Prefix + R` | Μετονομασία συνεδρίας |
| `Prefix + N` | Επόμενη συνεδρία |
| `Prefix + P` | Προηγούμενη συνεδρία |
| `Alt + Arrow Up/Down` | Μετακίνηση μεταξύ συνεδριών |
| `Prefix + s` | Λίστα συνεδριών |
| `Prefix + d` | Αποσύνδεση από συνεδρία |

### Λειτουργία αντιγραφής (στυλ vi)

| ----------------------- | --------------------- |

### Γενικά

| Συντόμευση | Λειτουργία |

### Συναρτήσεις διάταξης Tmux

Αυτές οι συναρτήσεις πρέπει να εκτελούνται μέσα σε μια συνεδρία Tmux.

| Εντολή | Λειτουργία |
