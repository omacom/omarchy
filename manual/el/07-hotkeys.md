# Πλήκτρα συντόμευσης

Μπορείτε να δείτε όλες τις κύριες συντομεύσεις πληκτρολογίου με `Super + K` (τις συντομεύσεις Tmux με `Super + Alt + K` και τις συντομεύσεις Herdr με `Super + Ctrl + K`).

## Πώς είναι οργανωμένες οι συντομεύσεις

Κάθε συντόμευση κάθεται σε ένα επίπεδο, που ορίζεται από τους τροποποιητές της, και κάθε επίπεδο έχει μία δουλειά. Αυτό κρατά τις συντομεύσεις από το να μπλέκονται μεταξύ τους, και σημαίνει ότι συνήθως μπορείτε να μαντέψετε πού βρίσκεται κάτι.

| Επίπεδο | Τι ζει εκεί | Παραδείγματα |
| --- | --- | --- |
| `Super + key` | Το σύστημα: παράθυρα, χώροι εργασίας, διατάξεις και βασικά μενού | `Super + Space` μενού Omarchy, `Super + W` κλείσιμο παραθύρου, `Super + F` πλήρης οθόνη |
| `Super + Shift + key` | Εφαρμογές | `Super + Shift + B` πρόγραμμα περιήγησης, `Super + Shift + E` email, `Super + Shift + N` επεξεργαστής |
| `Super + Ctrl + key` | Πίνακες και μενού συστήματος | `Super + Ctrl + A` ήχος, `Super + Ctrl + N` δίκτυο, `Super + Ctrl + C` μενού λήψης |
| `Super + Ctrl + Alt + key` | Γρήγορες ενέργειες και γνωστοποιήσεις | `Super + Ctrl + Alt + T` εμφάνιση ώρας, `Super + Ctrl + Alt + B` μπαταρία, `Super + Ctrl + Alt + C` στιγμιότυπο οθόνης |

Η προσθήκη `Alt` σε μια συντόμευση σάς δίνει μια παραλλαγή του ίδιου πράγματος, ποτέ κάτι άσχετο:

- `Super + Shift + B` ανοίγει το πρόγραμμα περιήγησης· `Super + Shift + Alt + B` ανοίγει ένα ιδιωτικό παράθυρο
- `Super + Shift + E` ανοίγει το email· `Super + Shift + Alt + E` ξεκινά ένα νέο
- `Super + F` μεταβαίνει σε πλήρη οθόνη· `Super + Alt + F` μεταβαίνει σε πλήρες πλάτος
- `Super + Ctrl + C` ανοίγει το μενού λήψης· `Super + Ctrl + Alt + C` παρακάμπτει το μενού και τραβά ένα στιγμιότυπο οθόνης

Όταν προσθέτετε μια συντόμευση:

1. Διαλέξτε το επίπεδο από αυτό που κάνει, μετά διαλέξτε το πλήκτρο.
2. Μην μετακινείτε μια υπάρχουσα συντόμευση για να κάνετε χώρο. Βρείτε ένα ελεύθερο πλήκτρο στο σωστό επίπεδο.
3. Χρησιμοποιείτε `Alt` μόνο για μια παραλλαγή της συντόμευσης χωρίς αυτό.

Μερικές συντομεύσεις παραβιάζουν αυτούς τους κανόνες επειδή είναι βολικές. Το `Shift` με ένα βέλος ή `Tab` μετακινεί ή αντιστρέφει αντί να ανοίγει μια εφαρμογή, και τα `Print`, τα πλήκτρα πολυμέσων, `Alt + Tab` και `Ctrl + Alt + Del` λειτουργούν όπως λειτουργούν παντού αλλού. Είναι εξαιρέσεις, όχι πρότυπα για αντιγραφή.

Αν μια προεπιλογή δεν σας ταιριάζει (πείτε ότι θέλετε `Super + Shift + S` για στιγμιότυπα οθόνης όπως στα Windows), αλλάξτε τη σύνδεσή της στο `~/.config/hypr/bindings.lua`.

| `Super + Ctrl + Alt + Z` | Πλήρης σμίκρυνση από την οθόνη |

| `Super + Alt + /` | Βήμα πίσω στις επιλογές κλιμάκωσης οθόνης |

| `Ctrl + Alt + Shift + Tab`| Περιήγηση εστίασης πίσω στις οθόνες |

| `Super + Shift + I` | Αλλαγή γλώσσας εισόδου προς τα πίσω |

Σε μια επιφάνεια αφής, τα swipes με τρία και τέσσερα δάχτυλα αλλάζουν χώρους εργασίας, μετακινούν παράθυρα και ανοίγουν το μενού και την κονσόλα Quake· δείτε το [πληκτρολόγιο, ποντίκι και trackpad](34-keyboard-mouse-trackpad.md) για τις χειρονομίες.

Οι συντομεύσεις αλλαγής μεγέθους χρησιμοποιούν τα φυσικά πλήκτρα `code:20` και `code:21` (XKB `<AE11>` και `<AE12>`), ανεξάρτητα από τους χαρακτήρες που είναι τυπωμένοι στο πληκτρολόγιο. Στα πληκτρολόγια US αυτά τα πλήκτρα είναι `-` και `=`· στα ιαπωνικά (JIS) πληκτρολόγια είναι `-` και `^`· στα ισπανικά πληκτρολόγια είναι `'` και `¡`. Στο JIS, το `Super + ^` είναι `Super + Equal`, ενώ το `Super + Shift + -` (που πληκτρολογεί `=`) είναι `Super + Shift + Minus`.

## Tmux

Το πλήκτρο προθέματος είναι `Ctrl + Space` (`Ctrl + B` λειτουργεί επίσης). Μπορείτε να αλλάξετε αυτές τις συνδέσεις στο `~/.config/tmux/tmux.conf`.

### Πλαίσια

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + v` | Διαίρεση πλαισίου δίπλα (κάθετα) |
| `Prefix + h` | Διαίρεση πλαισίου από κάτω (οριζόντια) |
| `Prefix + x` | Τερματισμός πλαισίου |
| `Prefix + z` | Εναλλαγή ζουμ πλαισίου (πλήρης οθόνη) |
| `Alt + Enter` | Διαίρεση πλαισίου από κάτω (χωρίς πρόθεμα) |
| `Alt + Shift + Enter` | Διαίρεση πλαισίου δίπλα (χωρίς πρόθεμα) |
| `Alt + Escape` | Τερματισμός πλαισίου (χωρίς πρόθεμα) |
| `Ctrl + Alt + Arrows` | Μετακίνηση μεταξύ πλαισίων |
| `Ctrl + Alt + Shift + Arrows` | Αλλαγή μεγέθους πλαισίων |

### Παράθυρα

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + c` | Νέο παράθυρο |
| `Prefix + k` | Τερματισμός παραθύρου |
| `Prefix + r` | Μετονομασία παραθύρου |
| `Alt + 1-9` | Μετάβαση σε συγκεκριμένο παράθυρο |
| `Alt + Arrow Left/Right` | Μετακίνηση μεταξύ παραθύρων |
| `Alt + Shift + Arrow Left/Right` | Μετακίνηση παραθύρου αριστερά/δεξιά |

### Συνεδρίες

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + C` | Νέα συνεδρία |

| `Prefix + N` | Επόμενη συνεδρία |
| `Prefix + P` | Προηγούμενη συνεδρία |

### Συναρτήσεις διάταξης Tmux
