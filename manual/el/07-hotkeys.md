# Συντομεύσεις πληκτρολογίου

Μπορείτε να δείτε όλες τις κύριες αντιστοιχίσεις πλήκτρων με `Super + K` (τις αντιστοιχίσεις του Tmux με `Super + Alt + K` και του Herdr με `Super + Ctrl + K`).

## Πώς είναι οργανωμένες οι συντομεύσεις

Κάθε συντόμευση βρίσκεται σε ένα επίπεδο, που ορίζεται από τα πλήκτρα τροποποίησής της, και κάθε επίπεδο έχει μία δουλειά. Αυτό κρατά τις συντομεύσεις ξεχωριστές μεταξύ τους και σημαίνει ότι συνήθως μπορείτε να μαντέψετε πού βρίσκεται κάτι.

| Επίπεδο | Τι βρίσκεται εκεί | Παραδείγματα |
| --- | --- | --- |
| `Super + key` | Το σύστημα: παράθυρα, χώροι εργασίας, διατάξεις και βασικά μενού | `Super + Space` μενού Omarchy, `Super + W` κλείσιμο παραθύρου, `Super + F` πλήρης οθόνη |
| `Super + Shift + key` | Εφαρμογές | `Super + Shift + B` πρόγραμμα περιήγησης, `Super + Shift + E` email, `Super + Shift + N` επεξεργαστής |
| `Super + Ctrl + key` | Πάνελ και μενού συστήματος | `Super + Ctrl + A` ήχος, `Super + Ctrl + N` δίκτυο, `Super + Ctrl + C` μενού λήψης |
| `Super + Ctrl + Alt + key` | Γρήγορες ενέργειες και ειδοποιήσεις | `Super + Ctrl + Alt + T` εμφάνιση ώρας, `Super + Ctrl + Alt + B` μπαταρία, `Super + Ctrl + Alt + C` στιγμιότυπο οθόνης |

Η προσθήκη του `Alt` σε μια συντόμευση σάς δίνει μια παραλλαγή του ίδιου πράγματος, ποτέ κάτι άσχετο:

- `Super + Shift + B` ανοίγει το πρόγραμμα περιήγησης· `Super + Shift + Alt + B` ανοίγει ένα ιδιωτικό παράθυρο
- `Super + Shift + E` ανοίγει το email· `Super + Shift + Alt + E` ξεκινά ένα νέο
- `Super + F` μεταβαίνει σε πλήρη οθόνη· `Super + Alt + F` μεταβαίνει σε πλήρες πλάτος
- `Super + Ctrl + C` ανοίγει το μενού λήψης· `Super + Ctrl + Alt + C` παρακάμπτει το μενού και τραβά στιγμιότυπο οθόνης

Όταν προσθέτετε μια συντόμευση:

1. Επιλέξτε το επίπεδο από το τι κάνει και μετά επιλέξτε το πλήκτρο.
2. Μην μετακινείτε μια υπάρχουσα συντόμευση για να κάνετε χώρο. Βρείτε ένα ελεύθερο πλήκτρο στο σωστό επίπεδο.
3. Χρησιμοποιείτε το `Alt` μόνο για παραλλαγή της συντόμευσης χωρίς αυτό.

Μερικές συντομεύσεις παραβιάζουν αυτούς τους κανόνες επειδή είναι βολικές. Το `Shift` με βέλος ή `Tab` μετακινεί ή αντιστρέφει αντί να ανοίγει εφαρμογή, και τα `Print`, τα πλήκτρα πολυμέσων, `Alt + Tab` και `Ctrl + Alt + Del` λειτουργούν όπως παντού αλλού. Είναι εξαιρέσεις, όχι πρότυπα για αντιγραφή.

Αν μια προεπιλογή δεν σας βολεύει (π.χ. θέλετε το `Super + Shift + S` για στιγμιότυπα οθόνης όπως στα Windows), αλλάξτε την αντιστοίχιση στο `~/.config/hypr/bindings.lua`.

Οι συντομεύσεις αλλαγής μεγέθους χρησιμοποιούν τα φυσικά πλήκτρα `code:20` και `code:21` (XKB `<AE11>` και `<AE12>`), ανεξάρτητα από τους χαρακτήρες που είναι τυπωμένοι στο πληκτρολόγιο. Στα πληκτρολόγια US αυτά τα πλήκτρα είναι `-` και `=`· στα ιαπωνικά πληκτρολόγια (JIS) είναι `-` και `^`· στα ισπανικά πληκτρολόγια είναι `'` και `¡`. Στα JIS, το `Super + ^` είναι `Super + Equal`, ενώ το `Super + Shift + -` (που πληκτρολογεί `=`) είναι `Super + Shift + Minus`.

## Tmux

Το πλήκτρο prefix είναι `Ctrl + Space` (λειτουργεί επίσης το `Ctrl + B`). Μπορείτε να αλλάξετε αυτές τις αντιστοιχίσεις στο `~/.config/tmux/tmux.conf`.

### Πλαίσια

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + v` | Διαχωρισμός πλαισίου δίπλα (κάθετα) |
| `Prefix + h` | Διαχωρισμός πλαισίου από κάτω (οριζόντια) |
| `Prefix + x` | Τερματισμός πλαισίου |
| `Prefix + z` | Εναλλαγή zoom πλαισίου (πλήρης οθόνη) |
| `Alt + Enter` | Διαχωρισμός πλαισίου από κάτω (χωρίς prefix) |
| `Alt + Shift + Enter` | Διαχωρισμός πλαισίου δίπλα (χωρίς prefix) |
| `Alt + Escape` | Τερματισμός πλαισίου (χωρίς prefix) |
