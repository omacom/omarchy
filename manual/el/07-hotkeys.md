# Συντομεύσεις πληκτρολογίου

Μπορείτε να δείτε όλες τις κύριες συνδέσεις πλήκτρων με `Super + K` (συνδέσεις Tmux με `Super + Alt + K` και συνδέσεις Herdr με `Super + Ctrl + K`).

## Πλοήγηση

| ----------------------- | --------------------- |
| `Super + Space`           | Μενού Omarchy (εφαρμογές και όλα τα υπόλοιπα)    |
| `Super + Alt + Space` | Πλέγμα εφαρμογών |
| `Super + Escape` | Μενού συστήματος (αναστολή, επανεκκίνηση κ.λπ.)  |

| `Super + Shift + Equal` | Επέκταση παραθύρου προς τα κάτω |
| `Super + Alt + Minus/Equal` | Ίδια αλλαγή μεγέθους σε μικρότερα βήματα |
| `Super + Ctrl + Minus/Equal` | Ίδια αλλαγή μεγέθους σε μεγαλύτερα βήματα |

| `Super + Home` | Επαναφορά αποθηκευμένου πλάτους παραθύρου |

| `Super + G`               | Εναλλαγή ομαδοποίησης παραθύρου      |
| `Super + Alt + G`               | Μετακίνηση παραθύρου εκτός ομαδοποίησης      |
| `Super + Alt + Tab`               | Εναλλαγή μεταξύ παραθύρων στην ομαδοποίηση      |

| `Super + Alt + Scroll Wheel` | Εναλλαγή μεταξύ παραθύρων στην ομαδοποίηση |
| `Super + Alt + 1/2/3/4/5`               | Μετάβαση σε συγκεκριμένο παράθυρο στην ομαδοποίηση      |
| `Super + Alt + Arrow`  | Μετακίνηση παραθύρου στην ομαδοποίηση προς την κατεύθυνση του βέλους, συμπεριλαμβανομένου ενός στην οθόνη εκείνης της πλευράς |
| `Super + Ctrl + Left/Right`  | Μετακίνηση μεταξύ παραθύρων μέσα σε ομάδα πλακιδίων |
| `Super + Ctrl + Z` | Μεγέθυνση στην οθόνη (επαναλάβετε για περισσότερη μεγέθυνση) |
| `Super + Ctrl + Alt + Z` | Πλήρης σμίκρυνση από την οθόνη |
| `Super + /` | Βήμα προς τα εμπρός στις επιλογές κλιμάκωσης οθόνης |
| `Super + Alt + /` | Βήμα προς τα πίσω στις επιλογές κλιμάκωσης οθόνης |
| `Alt + Tab` | Εναλλαγή προς τα εμπρός μεταξύ παραθύρων στον ενεργό χώρο εργασίας |
| `Alt + Shift + Tab` | Εναλλαγή προς τα πίσω μεταξύ παραθύρων στον ενεργό χώρο εργασίας |
| `Ctrl + Alt + Tab`| Εναλλαγή εστίασης προς τα εμπρός μεταξύ οθονών |
| `Ctrl + Alt + Shift + Tab`| Εναλλαγή εστίασης προς τα πίσω μεταξύ οθονών |

Οι συντομεύσεις αλλαγής μεγέθους χρησιμοποιούν τα φυσικά πλήκτρα `code:20` και `code:21` (XKB `<AE11>` και `<AE12>`), ανεξάρτητα από τους χαρακτήρες που είναι τυπωμένοι στο πληκτρολόγιο. Στα πληκτρολόγια US αυτά τα πλήκτρα είναι `-` και `=`· στα ιαπωνικά πληκτρολόγια (JIS) είναι `-` και `^`· στα ισπανικά πληκτρολόγια είναι `'` και `¡`. Στο JIS, το `Super + ^` είναι `Super + Equal`, ενώ το `Super + Shift + -` (που πληκτρολογεί `=`) είναι `Super + Shift + Minus`.
