# Συντομεύσεις πληκτρολογίου

Μπορείτε να δείτε όλες τις κύριες αντιστοιχίσεις πληκτρολογίου με το `Super + K` (αντιστοιχίσεις Tmux με το `Super + Alt + K` και αντιστοιχίσεις Herdr με το `Super + Ctrl + K`).

## Πώς είναι οργανωμένες οι συντομεύσεις πληκτρολογίου

Κάθε συντόμευση βρίσκεται σε ένα επίπεδο, που ορίζεται από τους τροποποιητές της, και κάθε επίπεδο έχει μία δουλειά. Αυτό κρατά τις συντομεύσεις από το να μπερδεύονται μεταξύ τους, και σημαίνει ότι συνήθως μπορείτε να μαντέψετε πού ζει κάτι.

| Επίπεδο | Τι ζει εκεί | Παραδείγματα |
| --- | --- | --- |
| `Super + key` | Το σύστημα: παράθυρα, χώροι εργασίας, διατάξεις και βασικά μενού | `Super + Space` μενού Omarchy, `Super + W` κλείσιμο παραθύρου, `Super + F` πλήρης οθόνη |
| `Super + Shift + key` | Εφαρμογές | `Super + Shift + B` πρόγραμμα περιήγησης, `Super + Shift + E` email, `Super + Shift + N` επεξεργαστής |
| `Super + Ctrl + key` | Πίνακες και μενού συστήματος | `Super + Ctrl + A` ήχος, `Super + Ctrl + N` δίκτυο, `Super + Ctrl + C` μενού καταγραφής |
| `Super + Ctrl + Alt + key` | Γρήγορες ενέργειες και σημειώματα | `Super + Ctrl + Alt + T` εμφάνιση ώρας, `Super + Ctrl + Alt + B` μπαταρία, `Super + Ctrl + Alt + C` στιγμιότυπο οθόνης |

Η προσθήκη του `Alt` σε μια συντόμευση σας δίνει μια παραλλαγή του ίδιου πράγματος, ποτέ κάτι άσχετο:

- `Super + Shift + B` ανοίγει το πρόγραμμα περιήγησης· `Super + Shift + Alt + B` ανοίγει ένα ιδιωτικό παράθυρο
- `Super + Shift + E` ανοίγει το email· `Super + Shift + Alt + E` ξεκινά ένα νέο
- `Super + F` μεταβαίνει σε πλήρη οθόνη· `Super + Alt + F` μεταβαίνει σε πλήρες πλάτος
- `Super + Ctrl + C` ανοίγει το μενού καταγραφής· `Super + Ctrl + Alt + C` παρακάμπτει το μενού και τραβά στιγμιότυπο οθόνης

Όταν προσθέτετε μια συντόμευση:

1. Επιλέξτε το επίπεδο από το τι κάνει, μετά επιλέξτε το πλήκτρο.
2. Μην μετακινείτε μια υπάρχουσα συντόμευση για να κάνετε χώρο. Βρείτε ένα ελεύθερο πλήκτρο στο σωστό επίπεδο.
3. Χρησιμοποιείτε το `Alt` μόνο για παραλλαγή της συντόμευσης χωρίς αυτό.

Μερικές συντομεύσεις παραβιάζουν αυτούς τους κανόνες επειδή είναι βολικές. Το `Shift` με βέλος ή `Tab` μετακινεί ή αντιστρέφει αντί να ανοίγει εφαρμογή, και τα `Print`, τα πλήκτρα πολυμέσων, `Alt + Tab` και `Ctrl + Alt + Del` λειτουργούν όπως παντού αλλού. Είναι εξαιρέσεις, όχι μοτίβα για αντιγραφή.

Αν μια προεπιλογή δεν σας ταιριάζει (ας πούμε ότι θέλετε το `Super + Shift + S` για στιγμιότυπα οθόνης όπως στα Windows), αντιστοιχίστε την ξανά στο `~/.config/hypr/bindings.lua`.

| `Super + G` | Εναλλαγή ομαδοποίησης παραθύρων |

| `Super + Alt + Arrow` | Μετακίνηση παραθύρου μέσα στην ομαδοποίηση προς την κατεύθυνση του βέλους, συμπεριλαμβανομένου ενός στην οθόνη εκείνης της πλευράς |
| `Super + Ctrl + Left/Right` | Μετακίνηση μεταξύ παραθύρων μέσα σε μια ομάδα παράθεσης |
| `Super + Ctrl + Z` | Μεγέθυνση στην οθόνη (επαναλάβετε για περισσότερη μεγέθυνση) |
| `Super + Ctrl + Alt + Z` | Πλήρης σμίκρυνση από την οθόνη |
| `Super + /` | Προχωρήστε προς τα εμπρός στις επιλογές κλιμάκωσης οθόνης |
| `Super + Alt + /` | Προχωρήστε προς τα πίσω στις επιλογές κλιμάκωσης οθόνης |
| `Alt + Tab` | Κυκλική εναλλαγή προς τα εμπρός στα παράθυρα του ενεργού χώρου εργασίας |
| `Alt + Shift + Tab` | Κυκλική εναλλαγή προς τα πίσω στα παράθυρα του ενεργού χώρου εργασίας |
| `Ctrl + Alt + Tab` | Κυκλική εναλλαγή εστίασης προς τα εμπρός στις οθόνες |
| `Ctrl + Alt + Shift + Tab` | Κυκλική εναλλαγή εστίασης προς τα πίσω στις οθόνες |
| `Super + I` | Εναλλαγή γλώσσας εισαγωγής (με περισσότερες από μία διατάξεις ή μεθόδους εισαγωγής) |
| `Super + Shift + I` | Εναλλαγή γλώσσας εισαγωγής πίσω |

Σε επιφάνεια αφής, τα σαρώματα με τρία και τέσσερα δάχτυλα αλλάζουν χώρους εργασίας, μετακινούν παράθυρα και ανοίγουν το μενού και την κονσόλα Quake· δείτε το [πληκτρολόγιο, ποντίκι και επιφάνεια αφής](34-keyboard-mouse-trackpad.md) για τις χειρονομίες.

Η αλλαγή μεγέθους χρησιμοποιεί τα δύο πλήκτρα δεξιά του 0, ό,τι κι αν τυπώνει πάνω τους το πληκτρολόγιό σας: `-` και `=` σε πληκτρολόγια US, `+` και `´` σε δανικά και σουηδικά, `+` και `\` σε νορβηγικά, `ß` και `´` σε γερμανικά, `'` και `¡` σε ισπανικά, και `-` και `^` σε ιαπωνικά (JIS). Το `Super + K` τα παραθέτει όπως τα τυπώνει το πληκτρολόγιό σας. Στο JIS, το `Super + ^` είναι το `Super + Equal`, ενώ το `Super + Shift + -` (που πληκτρολογεί `=`) είναι το `Super + Shift + Minus`. Η κλιμάκωση οθόνης και ο διαχειριστής κωδικών πρόσβασης χρησιμοποιούν το `/`· σε διατάξεις που πληκτρολογούν `/` μόνο με Shift, όπως οι περισσότερες ευρωπαϊκές, χρησιμοποιούν αντ' αυτού το πλήκτρο αριστερά του δεξιού Shift (`-` σε δανικά και γερμανικά).

## Καθολικό πρόχειρο

| Συντόμευση | Λειτουργία |
| ----------------------- | --------------------- |
| `Super + A` | Επιλογή όλων σε εφαρμογές που υποστηρίζουν το `Ctrl + A` |
| `Super + C` | Αντιγραφή |
| `Super + X` | Αποκοπή (όχι στο τερματικό) |
| `Super + V` | Επικόλληση |
| `Super + Ctrl + V` | Διαχειριστής προχείρου |

Συνήθως στο Linux, χρειάζεστε το `Ctrl + Shift + C/V` για αντιγραφή'n'επικόλληση στο τερματικό και το `Ctrl + C/V` για να το κάνετε παντού αλλού. Αυτές οι ενοποιημένες συντομεύσεις προχείρου του Omarchy λειτουργούν παντού.

## Tmux

Το πλήκτρο προθέματος είναι το `Ctrl + Space` (`Ctrl + B` λειτουργεί επίσης). Μπορείτε να αλλάξετε αυτές τις αντιστοιχίσεις στο `~/.config/tmux/tmux.conf`.

### Πλαίσια

| Συντόμευση | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + v` | Διαίρεση πλαισίου δίπλα (κάθετα) |
| `Prefix + h` | Διαίρεση πλαισίου κάτω (οριζόντια) |
| `Prefix + x` | Τερματισμός πλαισίου |
| `Prefix + z` | Εναλλαγή ζουμ πλαισίου (πλήρης οθόνη) |
| `Alt + Enter` | Διαίρεση πλαισίου κάτω (χωρίς πρόθεμα) |
| `Alt + Shift + Enter` | Διαίρεση πλαισίου δίπλα (χωρίς πρόθεμα) |
| `Alt + Escape` | Τερματισμός πλαισίου (χωρίς πρόθεμα) |
| `Ctrl + Alt + Arrows` | Μετακίνηση μεταξύ πλαισίων |
| `Ctrl + Alt + Shift + Arrows` | Αλλαγή μεγέθους πλαισίων |

### Παράθυρα

| Συντόμευση | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + c` | Νέο παράθυρο |
| `Prefix + k` | Τερματισμός παραθύρου |
| `Prefix + r` | Μετονομασία παραθύρου |
| `Alt + 1-9` | Μετάβαση σε συγκεκριμένο παράθυρο |
| `Alt + Arrow Left/Right` | Μετακίνηση μεταξύ παραθύρων |
| `Alt + Shift + Arrow Left/Right` | Μετακίνηση παραθύρου αριστερά/δεξιά |

### Συνεδρίες

| Συντόμευση | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + C` | Νέα συνεδρία |
| `Prefix + K` | Τερματισμός συνεδρίας |
| `Prefix + R` | Μετονομασία συνεδρίας |
| `Prefix + N` | Επόμενη συνεδρία |
| `Prefix + P` | Προηγούμενη συνεδρία |
| `Alt + Arrow Up/Down` | Μετακίνηση μεταξύ συνεδριών |
| `Prefix + s` | Λίστα συνεδριών |
| `Prefix + d` | Αποσύνδεση από συνεδρία |

### Λειτουργία αντιγραφής (στυλ vi)

| Συντόμευση | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + [` | Είσοδος στη λειτουργία αντιγραφής |
| `v` | Έναρξη επιλογής (στη λειτουργία αντιγραφής) |
| `y` | Αντιγραφή επιλογής (στη λειτουργία αντιγραφής) |

### Γενικά

| Συντόμευση | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + q` | Επαναφόρτωση διαμόρφωσης |
| `Prefix + ?` | Εμφάνιση αντιστοιχίσεων πλήκτρων Tmux |
| `Prefix + :` | Γραμμή εντολών |

### Συναρτήσεις διάταξης Tmux

Αυτές οι συναρτήσεις πρέπει να εκτελούνται μέσα σε μια συνεδρία Tmux.

| Εντολή | Λειτουργία |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Δημιουργία διάταξης ανάπτυξης με επεξεργαστή, AI και τερματικό |
| `tdlm <ai> [<second_ai>]` | Δημιουργία διάταξης ανάπτυξης ανά υποκατάλογο |
| `tsl <count> <command>` | Δημιουργία διάταξης swarm πολλών πλαισίων |
