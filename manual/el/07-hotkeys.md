# Πλήκτρα συντόμευσης

Μπορείτε να δείτε όλους τους κύριους συνδυασμούς πλήκτρων με `Super + K` (τους συνδυασμούς Tmux με `Super + Alt + K` και τους συνδυασμούς Herdr με `Super + Ctrl + K`).

## Πλοήγηση

| Πλήκτρο συντόμευσης                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Super + Space`           | Μενού Omarchy (εφαρμογές και όλα τα υπόλοιπα)    |
| `Super + Alt + Space` | Πλέγμα εφαρμογών |
| `Super + Escape` | Μενού συστήματος (αναστολή, επανεκκίνηση, κ.λπ.)  |
| `Super + Ctrl + L` | Κλείδωμα υπολογιστή |
| `Super + W` or `Super + Q` | Κλείσιμο παραθύρου             |
| `Ctrl + Alt + Del` | Κλείσιμο όλων των παραθύρων |
| `Super + T`               | Εναλλαγή παραθύρου μεταξύ πλακόστρωσης/αιώρησης             |
| `Super + J` | Εναλλαγή θέσης παραθύρου (οριζόντια/κάθετη) |
| `Super + O`               | Εναλλαγή παραθύρου σε sticky'n'floating |
| `Super + L`               | Κύλιση ανάμεσα στις διατάξεις dwindle, scrolling και floating |
| `Super + Alt + L`         | Κύλιση ανάμεσα στις διατάξεις αντίστροφα |
| `Super + P`               | Εναλλαγή στυλ pseudo παραθύρου (φυσικό έναντι τεντωμένου) |
| `Super + F`                 | Μετάβαση σε πλήρη οθόνη              |
| `Super + Alt + F`                 | Μετάβαση σε πλήρες πλάτος              |
| `Super + Ctrl + F`                 | Μετάβαση σε πλήρη οθόνη μέσα στο παράθυρο              |
| `Super + 1/2/3/4`         | Μετάβαση σε συγκεκριμένο χώρο εργασίας στην εστιασμένη οθόνη |
| `Super + Tab` | Μετάβαση στον επόμενο χώρο εργασίας στην εστιασμένη οθόνη |
| `Super + Shift + Tab` | Μετάβαση στον προηγούμενο χώρο εργασίας στην εστιασμένη οθόνη |
| `Super + Ctrl + Tab` | Μετάβαση στον πρώην χώρο εργασίας στην εστιασμένη οθόνη |
| `Super + Shift + 1/2/3/4` | Μετακίνηση παραθύρου σε χώρο εργασίας στην εστιασμένη οθόνη |
| `Super + Shift + Alt + 1/2/3/4` | Μετακίνηση παραθύρου σε χώρο εργασίας στην εστιασμένη οθόνη χωρίς να το ακολουθήσετε |
| `Super + S` | Εναλλαγή πλήρους scratchpad |
| `Super + Alt + S` | Μετακίνηση παραθύρου στο πλήρες scratchpad |
| `Super + Grave` | Εναλλαγή κονσόλας Quake |
| `Super + Shift + Grave` | Μετακίνηση παραθύρου στην κονσόλα Quake |
| `Super + Shift + Ctrl + Arrows` | Μετακίνηση παραθύρου στην οθόνη προς εκείνη την κατεύθυνση |
| `Super + Shift + Alt + Arrows` | Μετακίνηση χώρου εργασίας στην οθόνη προς εκείνη την κατεύθυνση |
| `Super + Arrow`  | Μετακίνηση εστίασης στο παράθυρο προς την κατεύθυνση του βέλους, περνώντας στην οθόνη εκείνης της πλευράς στην άκρη της οθόνης |
| `Super + Shift + Arrow`  | Ανταλλαγή παραθύρου με άλλο προς την κατεύθυνση του βέλους, συμπεριλαμβανομένου ενός στην οθόνη εκείνης της πλευράς |
| `Super + Minus` | Επέκταση παραθύρου προς τα αριστερά |
| `Super + Equal` | Σμίκρυνση παραθύρου προς τα αριστερά |
| `Super + Shift + Minus` | Σμίκρυνση παραθύρου προς τα πάνω |
| `Super + Shift + Equal` | Επέκταση παραθύρου προς τα κάτω |
| `Super + Alt + Minus/Equal` | Ίδια αλλαγή μεγέθους σε μικρότερα βήματα |
| `Super + Ctrl + Minus/Equal` | Ίδια αλλαγή μεγέθους σε μεγαλύτερα βήματα |
| `Super + Alt + Home` | Αποθήκευση πλάτους παραθύρου |
| `Super + Home` | Επαναφορά αποθηκευμένου πλάτους παραθύρου |
| `Super + Left Mouse` | Σύρσιμο παραθύρου |
| `Super + Right Mouse` | Αλλαγή μεγέθους παραθύρου |
| `Super + Scroll Wheel` | Κύλιση ανάμεσα στους χώρους εργασίας στην εστιασμένη οθόνη |
| `Super + G`               | Εναλλαγή ομαδοποίησης παραθύρων      |
| `Super + Alt + G`               | Μετακίνηση παραθύρου εκτός ομαδοποίησης      |
| `Super + Alt + Tab`               | Κύλιση ανάμεσα στα παράθυρα της ομαδοποίησης      |
| `Super + Alt + Shift + Tab`               | Κύλιση προς τα πίσω ανάμεσα στα παράθυρα της ομαδοποίησης      |
| `Super + Alt + Scroll Wheel` | Κύλιση ανάμεσα στα παράθυρα της ομαδοποίησης |
| `Super + Alt + 1/2/3/4/5`               | Μετάβαση σε συγκεκριμένο παράθυρο της ομαδοποίησης      |
| `Super + Alt + Arrow`  | Μετακίνηση παραθύρου στην ομαδοποίηση προς την κατεύθυνση του βέλους, συμπεριλαμβανομένου ενός στην οθόνη εκείνης της πλευράς |
| `Super + Ctrl + Left/Right`  | Μετακίνηση ανάμεσα στα παράθυρα μέσα σε μια ομάδα πλακόστρωσης |
| `Super + Ctrl + Z` | Μεγέθυνση στην οθόνη (επαναλάβετε για περισσότερη μεγέθυνση) |
| `Super + Ctrl + Alt + Z` | Πλήρης σμίκρυνση από την οθόνη |
| `Super + /` | Μετάβαση προς τα εμπρός στις επιλογές κλιμάκωσης οθόνης |
| `Super + Alt + /` | Μετάβαση προς τα πίσω στις επιλογές κλιμάκωσης οθόνης |
| `Alt + Tab` | Κύλιση προς τα εμπρός ανάμεσα στα παράθυρα στον ενεργό χώρο εργασίας |
| `Alt + Shift + Tab` | Κύλιση προς τα πίσω ανάμεσα στα παράθυρα στον ενεργό χώρο εργασίας |
| `Ctrl + Alt + Tab`| Κύλιση εστίασης προς τα εμπρός ανάμεσα στις οθόνες |
| `Ctrl + Alt + Shift + Tab`| Κύλιση εστίασης προς τα πίσω ανάμεσα στις οθόνες |

## Καθολικό πρόχειρο

| Πλήκτρο συντόμευσης                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Super + C`           | Αντιγραφή    |
| `Super + X`           | Αποκοπή (όχι στο τερματικό)    |
| `Super + V`           | Επικόλληση    |
| `Super + Ctrl + V`           | Διαχειριστής προχείρου    |

Συνήθως στο Linux, χρειάζεστε `Ctrl + Shift + C/V` για αντιγραφή και επικόλληση στο τερματικό και `Ctrl + C/V` για να το κάνετε παντού αλλού. Αυτά τα ενοποιημένα πλήκτρα συντόμευσης προχείρου του Omarchy λειτουργούν παντού.

## Καταγραφή

| Πλήκτρο συντόμευσης              | Λειτουργία                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Στιγμιότυπο οθόνης                      |
| `Super + Ctrl + Alt + C`            | Στιγμιότυπο οθόνης (το ίδιο στιγμιότυπο, για πληκτρολόγια χωρίς πλήκτρο Print Screen) |
| `Super + Ctrl + C` | Μενού καταγραφής |
| `Alt + Print Screen`            | Εγγραφή οθόνης                     |
| `Super + Print Screen` | Επιλογέας χρώματος |
| `Super + Ctrl + Print Screen` | Εξαγωγή κειμένου στο πρόχειρο |
| `Super + Alt + [` | Μικρότερη επικάλυψη κάμερας web κατά την εγγραφή |
| `Super + Alt + ]` | Μεγαλύτερη επικάλυψη κάμερας web κατά την εγγραφή |
| `Alt + Shift + L` | Αντιγραφή τρέχοντος URL από webapp ή Chromium |
| `Alt + Shift + D` | Λήψη του βίντεο στην τρέχουσα σελίδα στο `~/Videos` |
| `Super + Ctrl + X` | Έναρξη/διακοπή υπαγόρευσης (απαιτεί _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | Υπαγόρευση push-to-talk (απαιτεί Voxtype ή Superwhisper) |

Με τις εγγραφές οθόνης, το πλήκτρο συντόμευσης ρωτά πρώτα ποιον ήχο θέλετε και μετά ξεκινά την εγγραφή. Πατήστε το ξανά για διακοπή. Δείτε τα [στιγμιότυπα οθόνης και την εγγραφή](12-screenshots-recording.md) για τις λεπτομέρειες.

Όλες οι επιλογές καταγραφής είναι επίσης προσβάσιμες στο _Trigger > Capture_ στο μενού Omarchy (`Super + Space`).

## Tmux

Το πλήκτρο προθέματος είναι το `Ctrl + Space` (λειτουργεί επίσης το `Ctrl + B`). Μπορείτε να αλλάξετε αυτούς τους συνδυασμούς στο `~/.config/tmux/tmux.conf`.

### Πλαίσια

| Πλήκτρο συντόμευσης                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + v` | Διαίρεση πλαισίου δίπλα (κάθετα) |
| `Prefix + h` | Διαίρεση πλαισίου κάτω (οριζόντια) |
| `Prefix + x` | Τερματισμός πλαισίου |
| `Prefix + z` | Εναλλαγή ζουμ πλαισίου (πλήρης οθόνη) |
| `Alt + Enter` | Διαίρεση πλαισίου κάτω (χωρίς πρόθεμα) |
| `Alt + Shift + Enter` | Διαίρεση πλαισίου δίπλα (χωρίς πρόθεμα) |
| `Alt + Escape` | Τερματισμός πλαισίου (χωρίς πρόθεμα) |
| `Ctrl + Alt + Arrows` | Μετακίνηση ανάμεσα στα πλαίσια |
| `Ctrl + Alt + Shift + Arrows` | Αλλαγή μεγέθους πλαισίων |

### Παράθυρα

| Πλήκτρο συντόμευσης                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + c` | Νέο παράθυρο |
| `Prefix + k` | Τερματισμός παραθύρου |
| `Prefix + r` | Μετονομασία παραθύρου |
| `Alt + 1-9` | Μετάβαση σε συγκεκριμένο παράθυρο |
| `Alt + Arrow Left/Right` | Μετακίνηση ανάμεσα στα παράθυρα |
| `Alt + Shift + Arrow Left/Right` | Μετακίνηση παραθύρου αριστερά/δεξιά |

### Συνεδρίες

| Πλήκτρο συντόμευσης                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + C` | Νέα συνεδρία |
| `Prefix + K` | Τερματισμός συνεδρίας |
| `Prefix + R` | Μετονομασία συνεδρίας |
| `Prefix + N` | Επόμενη συνεδρία |
| `Prefix + P` | Προηγούμενη συνεδρία |
| `Alt + Arrow Up/Down` | Μετακίνηση ανάμεσα στις συνεδρίες |
| `Prefix + s` | Λίστα συνεδριών |
| `Prefix + d` | Αποσύνδεση από τη συνεδρία |

### Λειτουργία αντιγραφής (στυλ vi)

| Πλήκτρο συντόμευσης                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + [` | Είσοδος στη λειτουργία αντιγραφής |
| `v` | Έναρξη επιλογής (στη λειτουργία αντιγραφής) |
| `y` | Αντιγραφή επιλογής (στη λειτουργία αντιγραφής) |

### Γενικά

| Πλήκτρο συντόμευσης                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + q` | Επαναφόρτωση ρυθμίσεων |
| `Prefix + ?` | Εμφάνιση συνδυασμών πλήκτρων Tmux |
| `Prefix + :` | Γραμμή εντολών |

### Συναρτήσεις διάταξης Tmux

Αυτές οι συναρτήσεις πρέπει να εκτελούνται μέσα σε μια συνεδρία Tmux.

| Εντολή | Λειτουργία |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Δημιουργία διάταξης ανάπτυξης με επεξεργαστή, AI και τερματικό |
| `tdlm <ai> [<second_ai>]` | Δημιουργία διάταξης ανάπτυξης ανά υποκατάλογο |
| `tsl <count> <command>` | Δημιουργία διάταξης swarm πολλών πλαισίων |
