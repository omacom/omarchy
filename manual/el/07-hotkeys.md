# Πλήκτρα συντόμευσης

Μπορείτε να δείτε όλες τις κύριες αντιστοιχίσεις πληκτρολογίου με το `Super + K` (τις αντιστοιχίσεις Tmux με το `Super + Alt + K` και τις αντιστοιχίσεις Herdr με το `Super + Ctrl + K`).

## Πώς είναι οργανωμένα τα πλήκτρα συντόμευσης

Κάθε πλήκτρο συντόμευσης βρίσκεται σε ένα επίπεδο, που ορίζεται από τους τροποποιητές του, και κάθε επίπεδο έχει μία δουλειά. Αυτό κρατά τα πλήκτρα συντόμευσης ξεχωριστά μεταξύ τους και σημαίνει ότι συνήθως μπορείτε να μαντέψετε πού βρίσκεται κάτι.

| Επίπεδο | Τι βρίσκεται εκεί | Παραδείγματα |
| --- | --- | --- |
| `Super + key` | Το σύστημα: παράθυρα, χώροι εργασίας, διατάξεις και βασικά μενού | `Super + Space` μενού Omarchy, `Super + W` κλείσιμο παραθύρου, `Super + F` πλήρης οθόνη |
| `Super + Shift + key` | Εφαρμογές | `Super + Shift + B` πρόγραμμα περιήγησης, `Super + Shift + E` email, `Super + Shift + N` πρόγραμμα επεξεργασίας |
| `Super + Ctrl + key` | Πίνακες και μενού συστήματος | `Super + Ctrl + A` ήχος, `Super + Ctrl + N` δίκτυο, `Super + Ctrl + C` μενού λήψης |
| `Super + Ctrl + Alt + key` | Γρήγορες ενέργειες και γνωστοποιήσεις | `Super + Ctrl + Alt + T` εμφάνιση ώρας, `Super + Ctrl + Alt + B` μπαταρία, `Super + Ctrl + Alt + C` στιγμιότυπο οθόνης |

Η προσθήκη του `Alt` σε ένα πλήκτρο συντόμευσης σάς δίνει μια παραλλαγή του ίδιου πράγματος, ποτέ κάτι άσχετο:

- Το `Super + Shift + B` ανοίγει το πρόγραμμα περιήγησης· το `Super + Shift + Alt + B` ανοίγει ένα ιδιωτικό παράθυρο
- Το `Super + Shift + E` ανοίγει το email· το `Super + Shift + Alt + E` ξεκινά ένα νέο
- Το `Super + F` μεταβαίνει σε πλήρη οθόνη· το `Super + Alt + F` μεταβαίνει σε πλήρες πλάτος
- Το `Super + Ctrl + C` ανοίγει το μενού λήψης· το `Super + Ctrl + Alt + C` παρακάμπτει το μενού και τραβά ένα στιγμιότυπο οθόνης

Όταν προσθέτετε ένα πλήκτρο συντόμευσης:

1. Επιλέξτε το επίπεδο από αυτό που κάνει και μετά επιλέξτε το πλήκτρο.
2. Μην μετακινείτε ένα υπάρχον πλήκτρο συντόμευσης για να κάνετε χώρο. Βρείτε ένα ελεύθερο πλήκτρο στο σωστό επίπεδο.
3. Χρησιμοποιείτε το `Alt` μόνο για μια παραλλαγή του πλήκτρου συντόμευσης χωρίς αυτό.

Μερικά πλήκτρα συντόμευσης παραβιάζουν αυτούς τους κανόνες επειδή είναι βολικά. Το `Shift` με ένα βέλος ή το `Tab` μετακινεί ή αντιστρέφει αντί να ανοίγει μια εφαρμογή, και το `Print`, τα πλήκτρα πολυμέσων, το `Alt + Tab` και το `Ctrl + Alt + Del` λειτουργούν όπως λειτουργούν παντού αλλού. Είναι εξαιρέσεις, όχι μοτίβα για αντιγραφή.

Αν μια προεπιλογή δεν σας ταιριάζει (πείτε ότι θέλετε το `Super + Shift + S` για στιγμιότυπα οθόνης όπως στα Windows), αλλάξτε την αντιστοίχισή του στο `~/.config/hypr/bindings.lua`.

| `Super + Ctrl + Z` | Μεγέθυνση στην οθόνη (επαναλάβετε για περισσότερο ζουμ) |
| `Super + Ctrl + Alt + Z` | Πλήρης σμίκρυνση από την οθόνη |
| `Super + /` | Προχώρημα προς τα εμπρός στις επιλογές κλιμάκωσης οθόνης |
| `Super + Alt + /` | Προχώρημα προς τα πίσω στις επιλογές κλιμάκωσης οθόνης |
| `Alt + Tab` | Κυκλική εναλλαγή προς τα εμπρός στα παράθυρα στον ενεργό χώρο εργασίας |
| `Alt + Shift + Tab` | Κυκλική εναλλαγή προς τα πίσω στα παράθυρα στον ενεργό χώρο εργασίας |
| `Ctrl + Alt + Tab` | Κυκλική μετακίνηση εστίασης προς τα εμπρός στις οθόνες |
| `Ctrl + Alt + Shift + Tab` | Κυκλική μετακίνηση εστίασης προς τα πίσω στις οθόνες |
| `Super + I` | Αλλαγή γλώσσας εισαγωγής (με περισσότερες από μία διατάξεις ή μεθόδους εισαγωγής) |
| `Super + Shift + I` | Επιστροφή αλλαγής γλώσσας εισαγωγής |

Σε μια επιφάνεια αφής, τα σαρώματα με τρία και τέσσερα δάχτυλα αλλάζουν χώρους εργασίας, μετακινούν παράθυρα και ανοίγουν το μενού και την κονσόλα Quake· δείτε το [πληκτρολόγιο, ποντίκι και επιφάνεια αφής](34-keyboard-mouse-trackpad.md) για τις χειρονομίες.

Η αλλαγή μεγέθους χρησιμοποιεί τα δύο πλήκτρα δεξιά του 0, ό,τι κι αν τυπώνει πάνω τους το πληκτρολόγιό σας: `-` και `=` στα πληκτρολόγια US, `+` και `´` στα δανέζικα και σουηδικά, `+` και `\` στα νορβηγικά, `ß` και `´` στα γερμανικά, `'` και `¡` στα ισπανικά και `-` και `^` στα ιαπωνικά (JIS). Το `Super + K` τα παραθέτει όπως τα τυπώνει το πληκτρολόγιό σας. Στο JIS, το `Super + ^` είναι το `Super + Equal`, ενώ το `Super + Shift + -` (που τυπώνει `=`) είναι το `Super + Shift + Minus`. Η κλιμάκωση οθόνης και ο διαχειριστής κωδικών πρόσβασης χρησιμοποιούν το `/`· στις διατάξεις που τυπώνουν το `/` μόνο με Shift, όπως οι περισσότερες ευρωπαϊκές, χρησιμοποιούν αντ' αυτού το πλήκτρο αριστερά του δεξιού Shift (`-` στα δανέζικα και γερμανικά).

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Super + A` | Επιλογή όλων σε εφαρμογές που υποστηρίζουν το `Ctrl + A` |

| `Super + X` | Αποκοπή (όχι στο τερματικό) |
| `Super + V` | Επικόλληση |

Όλες οι επιλογές στυλ είναι επίσης προσβάσιμες στην ενότητα _Εμφάνιση_ στο μενού Omarchy (`Super + Space`).

## Εναλλαγές

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Super + Ctrl + I` | Εναλλαγή κλειδώματος κατά την αδράνεια |
| `Super + Ctrl + Delete` | Εναλλαγή ενεργοποίησης/απενεργοποίησης οθόνης φορητού υπολογιστή |
| `Super + Ctrl + Alt + Delete` | Εναλλαγή αντικατοπτρισμού οθόνης φορητού υπολογιστή |
| `Super + Shift + Space` | Εναλλαγή της επάνω γραμμής |
| `Shift + Mute` | Μετάβαση στην επόμενη έξοδο ήχου |
| `Shift + Play` | Μετάβαση στην επόμενη πηγή πολυμέσων |
| `Super + Shift + Backspace` | Εναλλαγή κενών παραθύρων |
| `Super + Ctrl + Alt + F` | Εναλλαγή επιφάνειας εργασίας πλήρους οθόνης (επάνω γραμμή + κενά παραθύρων) |

## Υπενθυμίσεις

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Super + Ctrl + R` | Ορισμός υπενθύμισης |
| `Super + Ctrl + Alt + R` | Προβολή όλων των υπενθυμίσεων |
| `Super + Ctrl + Shift + R` | Εκκαθάριση όλων των υπενθυμίσεων |

## Γνωστοποιήσεις

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |

## Tmux

Το πλήκτρο prefix είναι το `Ctrl + Space` (λειτουργεί επίσης το `Ctrl + B`). Μπορείτε να αλλάξετε αυτές τις αντιστοιχίσεις στο `~/.config/tmux/tmux.conf`.

### Πλαίσια

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + v` | Διαίρεση πλαισίου δίπλα (κατακόρυφα) |
| `Prefix + h` | Διαίρεση πλαισίου από κάτω (οριζόντια) |
| `Prefix + x` | Τερματισμός πλαισίου |
| `Prefix + z` | Εναλλαγή ζουμ πλαισίου (πλήρης οθόνη) |
| `Alt + Enter` | Διαίρεση πλαισίου από κάτω (χωρίς prefix) |
| `Alt + Shift + Enter` | Διαίρεση πλαισίου δίπλα (χωρίς prefix) |
| `Alt + Escape` | Τερματισμός πλαισίου (χωρίς prefix) |
| `Ctrl + Alt + Arrows` | Μετακίνηση μεταξύ πλαισίων |
| `Ctrl + Alt + Shift + Arrows` | Αλλαγή μεγέθους πλαισίων |

### Παράθυρα

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + c` | Νέο παράθυρο |
| `Prefix + k` | Τερματισμός παραθύρου |
| `Prefix + r` | Μετονομασία παραθύρου |
| `Alt + 1-9` | Μετάβαση σε συγκεκριμένο παράθυρο |
| `Alt + Arrow Left/Right` | Μετακίνηση μεταξύ παραθύρων |
| `Alt + Shift + Arrow Left/Right` | Μετακίνηση παραθύρου αριστερά/δεξιά |

### Συνεδρίες

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + C` | Νέα συνεδρία |
| `Prefix + K` | Τερματισμός συνεδρίας |
| `Prefix + R` | Μετονομασία συνεδρίας |
| `Prefix + N` | Επόμενη συνεδρία |
| `Prefix + P` | Προηγούμενη συνεδρία |
| `Alt + Arrow Up/Down` | Μετακίνηση μεταξύ συνεδριών |
| `Prefix + s` | Λίστα συνεδριών |
| `Prefix + d` | Αποσύνδεση από συνεδρία |

### Λειτουργία αντιγραφής (σε στυλ vi)

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + [` | Είσοδος σε λειτουργία αντιγραφής |
| `v` | Έναρξη επιλογής (σε λειτουργία αντιγραφής) |
| `y` | Αντιγραφή επιλογής (σε λειτουργία αντιγραφής) |

### Γενικά

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Prefix + q` | Επαναφόρτωση διαμόρφωσης |
| `Prefix + ?` | Εμφάνιση αντιστοιχίσεων πλήκτρων Tmux |
| `Prefix + :` | Γραμμή εντολών |

### Συναρτήσεις διάταξης Tmux

Αυτές οι συναρτήσεις πρέπει να εκτελούνται μέσα σε μια συνεδρία Tmux.

| Εντολή | Λειτουργία |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Δημιουργία διάταξης ανάπτυξης με πρόγραμμα επεξεργασίας, AI και τερματικό |
| `tdlm <ai> [<second_ai>]` | Δημιουργία διάταξης ανάπτυξης ανά υποκατάλογο |
| `tsl <count> <command>` | Δημιουργία διάταξης swarm πολλών πλαισίων |

## Τερματικό Ghostty

Το τερματικό Ghostty εγκαθίσταται με _Εγκατάσταση > Τερματικό_ μέσω του μενού Omarchy.

| Πλήκτρο συντόμευσης | Λειτουργία |
| ----------------------- | --------------------- |
| `Ctrl + Shift + E` | Νέος διαχωρισμός από κάτω |
| `Ctrl + Shift + O` | Νέος διαχωρισμός δίπλα |
| `Ctrl + Alt + Arrows` | Μετακίνηση μεταξύ διαχωρισμών |
| `Super + Ctrl + Shift + Arrows` | Αλλαγή μεγέθους διαχωρισμού κατά 10 γραμμές |
| `Super + Ctrl + Shift + Alt + Arrows` | Αλλαγή μεγέθους διαχωρισμού κατά 100 γραμμές |
| `Ctrl + Shift + T` | Νέα καρτέλα |
| `Ctrl + Shift + Arrows` | Μετακίνηση μεταξύ καρτελών |
| `Alt + Numbers` | Μετάβαση σε συγκεκριμένη καρτέλα |
| `Shift + Pg Up/Down` | Κύλιση στο ιστορικό |
| `Ctrl + Left mouse` | Άνοιγμα συνδέσμου στο πρόγραμμα περιήγησης |
