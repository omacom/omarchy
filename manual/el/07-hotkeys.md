# Συντομεύσεις πληκτρολογίου

Μπορείτε να δείτε όλους τους κύριους συνδυασμούς πληκτρολογίου με `Super + K` (συνδυασμοί Tmux με `Super + Alt + K` και συνδυασμοί Herdr με `Super + Ctrl + K`).

## Πώς είναι οργανωμένες οι συντομεύσεις

Κάθε συντόμευση βρίσκεται σε ένα επίπεδο, που ορίζεται από τους τροποποιητές της, και κάθε επίπεδο έχει μία δουλειά. Αυτό κρατάει τις συντομεύσεις από το να μπερδεύονται μεταξύ τους, και σημαίνει ότι συνήθως μπορείτε να μαντέψετε πού βρίσκεται κάτι.

| Επίπεδο | Τι βρίσκεται εκεί | Παραδείγματα |
| --- | --- | --- |
| `Super + key` | Το σύστημα: παράθυρα, χώροι εργασίας, διατάξεις και βασικά μενού | `Super + Space` μενού Omarchy, `Super + W` κλείσιμο παραθύρου, `Super + F` πλήρης οθόνη |
| `Super + Shift + key` | Εφαρμογές | `Super + Shift + B` πρόγραμμα περιήγησης, `Super + Shift + E` email, `Super + Shift + N` επεξεργαστής |
| `Super + Ctrl + key` | Πάνελ και μενού συστήματος | `Super + Ctrl + A` ήχος, `Super + Ctrl + N` δίκτυο, `Super + Ctrl + C` μενού λήψης |
| `Super + Ctrl + Alt + key` | Γρήγορες ενέργειες και ειδοποιήσεις | `Super + Ctrl + Alt + T` εμφάνιση ώρας, `Super + Ctrl + Alt + B` μπαταρία, `Super + Ctrl + Alt + C` στιγμιότυπο οθόνης |

Η προσθήκη του `Alt` σε μια συντόμευση σάς δίνει μια παραλλαγή του ίδιου πράγματος, ποτέ κάτι άσχετο:

- `Super + Shift + B` ανοίγει το πρόγραμμα περιήγησης· `Super + Shift + Alt + B` ανοίγει ένα ιδιωτικό παράθυρο
- `Super + Shift + E` ανοίγει το email· `Super + Shift + Alt + E` ξεκινάει ένα νέο
- `Super + F` μεταβαίνει σε πλήρη οθόνη· `Super + Alt + F` μεταβαίνει σε πλήρες πλάτος
- `Super + Ctrl + C` ανοίγει το μενού λήψης· `Super + Ctrl + Alt + C` παρακάμπτει το μενού και τραβάει ένα στιγμιότυπο οθόνης

Όταν προσθέτετε μια συντόμευση:

1. Επιλέξτε το επίπεδο από αυτό που κάνει, μετά επιλέξτε το πλήκτρο.
2. Μην μετακινείτε μια υπάρχουσα συντόμευση για να κάνετε χώρο. Βρείτε ένα ελεύθερο πλήκτρο στο σωστό επίπεδο.
3. Χρησιμοποιείτε το `Alt` μόνο για μια παραλλαγή της συντόμευσης χωρίς αυτό.

Μερικές συντομεύσεις παραβιάζουν αυτούς τους κανόνες επειδή είναι βολικές. Το `Shift` με ένα βέλος ή `Tab` μετακινεί ή αντιστρέφει αντί να ανοίγει μια εφαρμογή, και τα `Print`, τα πλήκτρα πολυμέσων, τα `Alt + Tab` και `Ctrl + Alt + Del` λειτουργούν όπως λειτουργούν παντού αλλού. Είναι εξαιρέσεις, όχι πρότυπα για αντιγραφή.

Αν μια προεπιλογή δεν σας ταιριάζει (π.χ. θέλετε το `Super + Shift + S` για στιγμιότυπα οθόνης όπως στα Windows), αλλάξτε την στο `~/.config/hypr/bindings.lua`.

Στα πληκτρολόγια US αυτά τα πλήκτρα είναι `-` και `=`· στα ιαπωνικά (JIS) πληκτρολόγια είναι `-` και `^`· στα ισπανικά πληκτρολόγια είναι `'` και `¡`. Στα JIS, το `Super + ^` είναι `Super + Equal`, ενώ το `Super + Shift + -` (που πληκτρολογεί `=`) είναι `Super + Shift + Minus`.

## Tmux

Το πλήκτρο prefix είναι το `Ctrl + Space` (το `Ctrl + B` λειτουργεί επίσης). Μπορείτε να αλλάξετε αυτούς τους συνδυασμούς στο `~/.config/tmux/tmux.conf`.

### Πλαίσια

| Συντόμευση                  | Λειτουργία              |
| ----------------------- | --------------------- |
| `Prefix + v` | Διαίρεση πλαισίου δίπλα (κάθετα) |
| `Prefix + h` | Διαίρεση πλαισίου κάτω (οριζόντια) |
| `Prefix + x` | Τερματισμός πλαισίου |
| `Prefix + z` | Εναλλαγή μεγέθυνσης πλαισίου (πλήρης οθόνη) |
| `Alt + Enter` | Διαίρεση πλαισίου κάτω (χωρίς prefix) |
| `Alt + Shift + Enter` | Διαίρεση πλαισίου δίπλα (χωρίς prefix) |
| `Alt + Escape` | Τερματισμός πλαισίου (χωρίς prefix) |
| `Ctrl + Alt + Arrows` | Μετακίνηση μεταξύ πλαισίων |
| `Ctrl + Alt + Shift + Arrows` | Αλλαγή μεγέθους πλαισίων |
