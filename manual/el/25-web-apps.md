# Web εφαρμογές

Μπορείτε να προσθέσετε τις δικές σας web εφαρμογές χρησιμοποιώντας το _Εγκατάσταση > Web App_ στο μενού του Omarchy (`Super + Space`). Θα σας ζητήσει το όνομα της εφαρμογής, τη διεύθυνση URL της εφαρμογής, και τη διεύθυνση URL του εικονιδίου, αν δεν μπορεί να την ανακτήσει μέσω του favicon. Μπορείτε να βρείτε υπέροχα εικονίδια PNG για πολλές δημοφιλείς web εφαρμογές στο [Dashboard Icons](https://dashboardicons.com).

Στη συνέχεια θα είναι προσβάσιμες μέσω του εκκινητή εφαρμογών (`Super + Space`), και θα χρησιμοποιούν το όμορφο παράθυρο web εφαρμογής χωρίς πλαίσιο.

Αν θέλετε να αφαιρέσετε μια web εφαρμογή, απλώς πηγαίνετε στο _Αφαίρεση > Web App_ στο μενού του Omarchy.

Είναι καλύτερο να συνδεθείτε σε όλους τους λογαριασμούς σας χρησιμοποιώντας έναν κανονικό περιηγητή πριν χρησιμοποιήσετε τις συντομεύσεις των web εφαρμογών. Το λεπτό πλαίσιο περιτυλίγματος δεν λειτουργεί καλά με το 1password, οπότε είναι απλώς ευκολότερο να είστε ήδη συνδεδεμένοι απευθείας.

Όλες οι συντομεύσεις πληκτρολογίου για αυτές τις web εφαρμογές μπορούν να αλλάξουν στο `~/.config/hypr/bindings.lua`.

Όταν βρίσκεστε σε μια web εφαρμογή, μπορείτε να αντιγράψετε την τρέχουσα διεύθυνση URL στο πρόχειρο χρησιμοποιώντας το `Shift + Alt + L`.

Από προεπιλογή, το Omarchy συνοδεύεται ήδη από μια συλλογή προεπιλεγμένων εφαρμογών:

## HEY

Το [HEY](https://www.hey.com/) είναι μια υπηρεσία email και ημερολογίου που αποτελεί μια εξαιρετική εναλλακτική για όσους έχουν κουραστεί από το Gmail, το Outlook ή το Apple Mail. Κατασκευάζεται από την [37signals](https://37signals.com/) όπου γεννήθηκε το Omarchy.

Μπορείτε να εκκινήσετε το HEY Email χρησιμοποιώντας το `Super + Shift + E`, να μεταπηδήσετε κατευθείαν στη σύνθεση ενός νέου email χρησιμοποιώντας το `Super + Shift + Alt + E`, και να εκκινήσετε το HEY Calendar χρησιμοποιώντας το `Super + Shift + C`.

## Basecamp

Το [Basecamp](https://basecamp.com/) είναι μια υπηρεσία διαχείρισης έργων που βοηθά μικρές ομάδες να κινούνται πιο γρήγορα και να σημειώνουν περισσότερη πρόοδο. Αντί να συνδέετε ένα ασυνάρτητο παζλ από Trello, Slack, Asana, Notion ή οτιδήποτε άλλο, μπορείτε να τα έχετε όλα σε ένα μέρος με το Basecamp. Κατασκευάζεται από την [37signals](https://37signals.com/) όπου γεννήθηκε το Omarchy.

Μπορείτε να εκκινήσετε το Basecamp χρησιμοποιώντας τον εκκινητή εφαρμογών (`Super + Space`)

## ChatGPT

Το [ChatGPT](https://chatgpt.com) είναι το πιο δημοφιλές chat bot AI στον κόσμο.

Μπορείτε να εκκινήσετε το ChatGPT χρησιμοποιώντας το `Super + Shift + A`.

## Grok

Το [Grok](https://grok.com) είναι το chat bot της xAI.

Μπορείτε να εκκινήσετε το Grok χρησιμοποιώντας το `Super + Shift + Alt + A`.

## WhatsApp

Το [WhatsApp](https://www.whatsapp.com/) είναι μία από τις πιο δημοφιλείς υπηρεσίες ανταλλαγής μηνυμάτων στον κόσμο, και η έκδοση web είναι μια εξαιρετική επιλογή για Linux.

Μπορείτε να εκκινήσετε το WhatsApp χρησιμοποιώντας το `Super + Shift + Alt + G`.

## Εφαρμογές Google

Τα Google Messages, Google Photos, Google Maps και Google Contacts περιλαμβάνονται όλα και ως web εφαρμογές.

Μπορείτε να εκκινήσετε το Google Messages χρησιμοποιώντας το `Super + Shift + Ctrl + G`, το Google Photos χρησιμοποιώντας το `Super + Shift + P`, και το Google Maps χρησιμοποιώντας το `Super + Shift + S`. Το Google Contacts διατίθεται μέσω του εκκινητή εφαρμογών (`Super + Space`).

## X

Το X είναι εκεί όπου σπάνε οι ειδήσεις.

Μπορείτε να εκκινήσετε το X χρησιμοποιώντας το `Super + Shift + X` και να πάτε κατευθείαν στη σύνταξη μιας νέας ανάρτησης με το `Super + Shift + Alt + X`.

## YouTube

Το [YouTube](https://youtube.com/) είναι η πιο δημοφιλής πλατφόρμα βίντεο στον κόσμο.

Μπορείτε να εκκινήσετε το YouTube χρησιμοποιώντας το `Super + Shift + Y`.

## Zoom

Το [Zoom](https://zoom.us/) είναι το πιο δημοφιλές σύστημα βιντεοσυνομιλίας που χρησιμοποιείται στις ΗΠΑ. Εξαιρετικές συνδέσεις σε όλο τον κόσμο. Και συναντήσεις 40 λεπτών μπορούν να πραγματοποιηθούν χωρίς λογαριασμό επί πληρωμή. Το Omarchy τυλίγει τον web πελάτη του Zoom, και οι σύνδεσμοι συναντήσεων του zoom θα ανοίγουν κατευθείαν μέσα σε αυτόν.

Εκκινείτε το Zoom χρησιμοποιώντας τον εκκινητή εφαρμογών (`Super + Space`).

## Discord

Το [Discord](https://discord.com/) είναι εκεί όπου συχνάζουν οι περισσότερες κοινότητες gaming και ανοιχτού κώδικα, συμπεριλαμβανομένης της [δικής μας του Omarchy](https://discord.gg/tXFUdasqhY).

Εκκινείτε το Discord χρησιμοποιώντας τον εκκινητή εφαρμογών (`Super + Space`).

## Εφαρμογές Microsoft

Επιλέξτε το _Εγκατάσταση > Service > Microsoft_ για να προσθέσετε τα Outlook, Word, Excel, PowerPoint, Teams και OneDrive ως web εφαρμογές. Κάθε εφαρμογή έχει τον δικό της εκκινητή και ανοίγει απευθείας, χρησιμοποιώντας τις εμπορικές διευθύνσεις URL του Microsoft 365 και το υπάρχον προφίλ του περιηγητή σας. Ανοίγουν στα ίδια παράθυρα εφαρμογών περιηγητή όπως οι άλλες web εφαρμογές του Omarchy· δεν εγκαθιστούν τον ξεχωριστό πελάτη Teams for Linux.

Αφαιρέστε την δέσμη με το _Αφαίρεση > Service > Microsoft_, ή αφαιρέστε μεμονωμένες εφαρμογές με το _Αφαίρεση > Web App_. Μπορείτε επίσης να εγκαταστήσετε μόνο τις εφαρμογές που θέλετε μέσω του _Εγκατάσταση > Web App_.

Για ένα κρατικό ή κυρίαρχο cloud, επεξεργαστείτε τη διεύθυνση URL στη γραμμή `Exec=` στον σχετικό εκκινητή κάτω από το `~/.local/share/applications/`, όπως το `Microsoft Teams.desktop`, χρησιμοποιώντας τη διεύθυνση URL που παρείχε ο οργανισμός σας. Γράψτε κάθε κυριολεκτικό `%` σε εκείνη τη γραμμή ως `%%`. Οι αλλαγές ισχύουν στην επόμενη εκκίνηση. Η εκτέλεση ξανά του εγκαταστάτη της δέσμης αντικαθιστά τους εκκινητές του με τις προεπιλεγμένες διευθύνσεις URL.

Για να κρατήσετε χωριστές τις συνδέσεις εργασίας, προσθέστε έναν κατάλογο δεδομένων περιηγητή στη γραμμή `Exec=` κάθε εκκινητή:

```ini
Exec=omarchy-launch-webapp "https://teams.cloud.microsoft/" --user-data-dir=/absolute/path/to/work-browser-profile
```

Αντικαταστήστε τον κατάλογο του παραδείγματος με μια απόλυτη διαδρομή της επιλογής σας και χρησιμοποιήστε την ίδια διαδρομή και για τους έξι εκκινητές για να μοιράζονται μεταξύ τους τις συνδέσεις εργασίας. Οι web εφαρμογές χρησιμοποιούν τον επιλεγμένο υποστηριζόμενο περιηγητή του Omarchy, επιστρέφοντας στο Chromium όταν ο προεπιλεγμένος περιηγητής δεν υποστηρίζεται.
