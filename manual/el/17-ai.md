# AI

Το Omarchy περιλαμβάνει εκκινητές για τους παρακάτω πράκτορες προγραμματισμού, χωρίς να επιλέγει προεπιλογή για εσάς. Εκτελέστε μια εντολή για να εγκαταστήσετε το CLI της κατά την πρώτη χρήση και στη συνέχεια πραγματοποιήστε έλεγχο ταυτότητας όταν σας ζητηθεί. Ο Hermes αποτελεί την εξαίρεση: δεν εγκαθίσταται τίποτα γι' αυτόν κατά την πρώτη χρήση και η επιλογή του εγκαθιστά το Hermes Desktop, όπως εξηγεί παρακάτω η ενότητα _Εφαρμογές για υπολογιστή_.

### Εγκατάσταση και ενημέρωση πρακτόρων

Με εξαίρεση τον Hermes, αυτοί οι πράκτορες χρησιμοποιούν την οκνηρή εγκατάσταση του mise: η πρώτη εκκίνηση εγκαθιστά το CLI και οι επόμενες εκκινήσεις το επαναχρησιμοποιούν. Το mise ελέγχει επίσης έναν εγκατεστημένο πράκτορα για νέα έκδοση το πολύ μία φορά κάθε τέσσερις ώρες, λίγο πριν ξεκινήσει ή στο παρασκήνιο σε μια προτροπή κελύφους. Εάν αυτή η ενημέρωση αποτύχει ή είστε εκτός σύνδεσης, εκτελείται η εγκατεστημένη έκδοση. Η `omarchy update` ενημερώνει τους εγκατεστημένους πράκτορες μαζί με το υπόλοιπο Omarchy και η `mup` ενημερώνει μόνο τα εργαλεία που διαχειρίζεται το mise.

Ο μηχανισμός ενημέρωσης ενός πράκτορα, όπως `claude update`, `codex update` ή ένα κουμπί ενημέρωσης σε μια εφαρμογή, δεν ενημερώνει την εγκατάσταση που διαχειρίζεται το mise. Η `codex update` αποτυγχάνει και η `claude update` μπορεί να αναφέρει επιτυχία ενώ εγκαθιστά ένα ξεχωριστό αντίγραφο που το mise δεν παρακολουθεί. Εάν προτιμάτε να χρησιμοποιείτε τον εγγενή εγκαταστάτη και μηχανισμό ενημέρωσης ενός πράκτορα, προσθέστε τον στο `disable_tools`· δείτε [Προεγκατεστημένα εργαλεία CLI](18-development-tools.md#preinstalled-cli-tools).

Για να εγκαταστήσετε όλα τα διαμορφωμένα οκνηρά εργαλεία πριν τα χρειαστείτε, εκτελέστε `mise install --include-lazy`. Αυτό περιλαμβάνει τα άλλα προεπιλεγμένα εργαλεία CLI του Omarchy καθώς και τους πράκτορες. Δείτε [Προεγκατεστημένα εργαλεία CLI](18-development-tools.md#preinstalled-cli-tools) για την εγκατάσταση ενός μεμονωμένου εργαλείου ή τη χρήση της δικής σας εγκατάστασης.

Το `grok` εγκαθίσταται μέσω του πακέτου `grok` πρώτου μέρους του mise, με τον ίδιο τρόπο όπως τα `claude` και `codex`. Εκτελέστε `grok` ή επιλέξτε το στην ενότητα _Setup > Defaults > Agent_. Παραλείψτε τον εγκαταστάτη `curl | bash` στο x.ai. Αυτή η διαδρομή τοποθετεί ένα δεύτερο αντίγραφο στο `~/.grok/bin`, το προτάσσει στο `PATH` και αντικαθιστά το wrapper του Omarchy.

Το `dsh` ανοίγει το περιβάλλον χρήστη του προγράμματος περιήγησής του στο `127.0.0.1:3080`, με τον κατάλογο εκκίνησης ως προεπιλεγμένο χώρο εργασίας του. Το περιβάλλον χρήστη του προγράμματος περιήγησης δεν δέχεται αρχική προτροπή, επομένως η `omarchy agent prompt` το ανοίγει με την προτροπή στο πρόχειρό σας για επικόλληση. Το Omarchy το ξεκινά με την προεπιλογή δικαιωμάτων χωρίς έγκριση της DeepSeek. Το DeepSeek Harness ανεβάζει αρχεία καταγραφής συνεδριών στην DeepSeek όταν χρησιμοποιείτε το επίσημο API μοντέλου της· απενεργοποιήστε το στην ενότητα _Settings > General > Upload Session Log_ στο περιβάλλον χρήστη του προγράμματος περιήγησης. Τα σχόλια που του στέλνετε ανεβαίνουν επίσης μαζί με τη συνεδρία, εκτός εάν το ξεκινήσετε με `DSH_TELEMETRY_MODE=DISABLED`.

### Ο προεπιλεγμένος πράκτορας

Επιλέξτε τον προεπιλεγμένο πράκτορά σας με `omarchy default agent <name>` ή στην ενότητα _Setup > Defaults > Agent_ στο Μενού Omarchy (`Super + Space`). Εάν ο πράκτορας δεν έχει εγκατασταθεί ακόμη, η επιλογή του τον εγκαθιστά πρώτα. Ένα φρέσκο Omarchy θα σας καλέσει να κάνετε αυτή την επιλογή με μια εφάπαξ ειδοποίηση.

Η επιλογή του Claude επιχειρεί επίσης να ρυθμίσει την επέκταση του προγράμματος περιήγησής του για Chromium, Chrome, Brave, Brave Origin και Edge. Η ρύθμιση της επέκτασης ισχύει για όλους τους χρήστες και ενδέχεται να ζητήσει τον κωδικό πρόσβασης του συστήματός σας· η ακύρωση ή μια αποτυχημένη εγκατάσταση επέκτασης εξακολουθεί να επιλέγει και να εκκινεί το Claude. Επανεκκινήστε το πρόγραμμα περιήγησής σας, ενεργοποιήστε την επέκταση εάν σας ζητηθεί και συνδεθείτε στο Claude για να ολοκληρώσετε τη σύνδεσή του. Εκτελέστε `/chrome` στο Claude για να ελέγξετε τη σύνδεση. Τα Firefox και Zen δεν υποστηρίζουν αυτή την επέκταση. Εάν το Claude ήταν ήδη η προεπιλογή σας πριν προστεθεί αυτή η ρύθμιση, επιλέξτε το ξανά για να εγκαταστήσετε την επέκταση.

Αφού επιλέξετε, το `Super + Shift + Ctrl + A` εκκινεί τον προεπιλεγμένο πράκτορα σε ένα ειδικό παράθυρο τερματικού (ή εμφανίζει τον επιλογέα εάν δεν έχετε επιλέξει ακόμη). Μπορείτε επίσης να το εκκινήσετε απευθείας σε μια εργασία με `omarchy agent prompt "Review this project"`. Τα Freebuff και DeepSeek Harness δεν δέχονται αρχική προτροπή, επομένως ανοίγουν με την προτροπή στο πρόχειρό σας για επικόλληση αντ' αυτού. Οι πράκτορες που εκκινούνται με αυτόν τον τρόπο εκτελούνται χωρίς επίβλεψη στους αντίστοιχους τρόπους λειτουργίας τους που δεν σταματούν για να ρωτήσουν, οπότε να είστε έτοιμοι να κάνουν πράγματα στην πράξη! Το MiniMax Code δεν διαθέτει τέτοια λειτουργία για τις διαδραστικές συνεδρίες του, επομένως ζητά δικαιώματα ως συνήθως. Και επειδή οι πράκτορες αρνούνται να θυμούνται την εμπιστοσύνη για τον αρχικό κατάλογό σας, οι εκκινήσεις από το `$HOME` ξεκινούν στο `~/Work` αντ' αυτού.

Υπάρχουν επίσης συντομεύσεις τερματικού: το `a` εκτελεί τον προεπιλεγμένο πράκτορα ενσωματωμένο στο τρέχον τερματικό, ενώ τα `c`, `cx` και `cy` ξεκινούν απευθείας τα OpenCode, Claude Code και Codex (ξανά στους τρόπους αυτόματης έγκρισής τους). Οι αλλαγές θέματος συγχρονίζονται επίσης στους πράκτορες: τα Claude Code, Pi, OpenCode και Hermes (αφού το Omarchy το έχει εγκαταστήσει) ακολουθούν όλα όταν αλλάζετε το θέμα του Omarchy.

### Το πάνελ πρακτόρων

Η επάνω γραμμή διαθέτει ένα εικονίδιο πρακτόρων. Πριν ρυθμίσετε έναν πράκτορα, το πάνελ του σας καθοδηγεί στη σύνδεση στο Claude, το Codex ή το Grok και το πρώτο γίνεται ο προεπιλεγμένος πράκτοράς σας. Μετά από αυτό, το πάνελ συγκεντρώνει κάθε συνδρομή σε μία σελίδα: κάθε πράκτορα και λογαριασμό με το πλάνο του, έναν μετρητή για κάθε όριο συνεδρίας 5 ωρών και εβδομαδιαίο όριό του με τον χρόνο μέχρι να μηδενιστεί (τοποθετήστε τον δείκτη για το ακριβές ποσοστό) ή το υπόλοιπο προπληρωμένο υπόλοιπο, κάτω από μια γραμμή που εναλλάσσεται κυκλικά σε ό,τι έχετε χρησιμοποιήσει σε όλα αυτά, όπως tokens αυτή την εβδομάδα και το μοντέλο που χρησιμοποιείτε περισσότερο. Στην ενότητα _Make something_ προσφέρει αρχικές προτροπές για ένα νέο θέμα, πρόσθετο ή εφαρμογή που παραδίδουν την εργασία στον προεπιλεγμένο πράκτορά σας. Οι εφαρμογές κατασκευάζονται με τον τρόπο που κατασκευάζονται τα ίδια τα Hype, Monologue και Omacut του Omarchy, σε C++ και Qt Quick, ακολουθώντας τη δεξιότητα πράκτορα omarchy-app, και ο μεταγλωττιστής και τα κομμάτια Qt που χρειάζονται παρέχονται εγκατεστημένα. Τα Claude Code, Codex, Grok, Kimi, Cursor και η παροχή Grok Bot του, GitHub Copilot, Muse, Antigravity, Kimchi και Devin καλύπτονται εξ αρχής με τα όριά τους και τα Hermes, Mistral Vibe και Qwen Code εμφανίζουν τις συνεδρίες και τα tokens τους αφού τα χρησιμοποιήσετε. Τα πλάνα παρόχων και τα κλειδιά που χρησιμοποιείτε μέσω pi, omp ή opencode εμφανίζονται επίσης: OpenCode Zen και Go, το Z.ai GLM Coding Plan, Ollama Cloud, το MiniMax Token Plan και Synthetic με τα όριά τους· Fireworks, OpenRouter και DeepSeek με τα προπληρωμένα υπόλοιπά τους· και τα μοντέλα που εκτελείτε στο δικό σας υλικό στην ενότητα Local models. Κάθε πράκτορας μετράται μία φορά, κάτω από όποιον τον χρεώνει, ανεξάρτητα από το μέσω πόσων harness τον χειρίζεστε.

Κάντε αριστερό κλικ στο εικονίδιο της γραμμής για το πάνελ, δεξί κλικ για να εκκινήσετε τον προεπιλεγμένο πράκτορά σας. Τα αρχεία χρήσης πίσω από αυτό αναγεννώνται κάθε 15 λεπτά από την `omarchy agent usage-update` και το πάνελ μπορεί ακόμη και να συγχωνεύσει χρήση από τα άλλα μηχανήματά σας μέσω ενός συγχρονισμένου φακέλου. Δείτε το README στο `$OMARCHY_PATH/shell/plugins/agents/` για τις πλήρεις ρυθμίσεις.

### Πολλές συνδρομές

Εάν πληρώνετε για περισσότερα από ένα πλάνα Claude, Codex ή Grok — ένα προσωπικό Max και ένα επαγγελματικό, ας πούμε — το Omarchy μπορεί να τα κρατήσει όλα συνδεδεμένα και να μετακινείται μεταξύ τους. Προσθέστε μια συνδρομή με το + στο πάνελ πρακτόρων, το οποίο σας καθοδηγεί εκεί ακριβώς, ή με `omarchy agent account add claude Work` (ή `codex` ή `grok`). Εγκαθιστά το CLI εάν λείπει. Ο πρώτος λογαριασμός για έναν πάροχο συνδέεται μέσω του κανονικού προγράμματος περιήγησής σας, ακριβώς εκεί που πάντα ψάχνει το CLI. Κάθε επόμενος συνδέεται μέσω ενός ιδιωτικού παραθύρου, ώστε ο λογαριασμός στον οποίο το πρόγραμμα περιήγησής σας είναι ήδη συνδεδεμένο να μην επιλεγεί κατά λάθος· συνδεθείτε εκεί ως ο λογαριασμός που προσθέτετε και κλείστε πρώτα οποιοδήποτε ιδιωτικό παράθυρο είχατε ήδη ανοιχτό. Ποτέ μην αποσυνδέεστε από το CLI για να το κάνετε αυτό: η αποσύνδεση ανακαλεί την αποθηκευμένη σύνδεση και αυτός ο λογαριασμός θα έπρεπε να προστεθεί ξανά.

Για να αντιγράψετε τις συνδέσεις συνδρομών σας σε ένα άλλο μηχάνημα Omarchy μέσω SSH, εκτελέστε `omarchy agent account copy user@laptop`. Ο αποστολέας παρέχει έναν προσωρινό παραλήπτη όταν ο προορισμός δεν έχει εγκατεστημένο έναν, ώστε παλαιότερα μηχανήματα Omarchy να μπορούν να λάβουν λογαριασμούς χωρίς ενημέρωση. Οι εγκατεστημένοι παραλήπτες έχουν προτεραιότητα. Αυτό αντιγράφει όλες τις συνδρομές Claude, Codex και Grok· προσθέστε ονόματα παρόχων για να τις επιλέξετε, όπως στο `omarchy agent account copy laptop claude`. Τα ονόματα λογαριασμών και τα αναγνωριστικά εντολών ταιριάζουν με την πηγή, συμπεριλαμβανομένων των λογαριασμών που υπάρχουν ήδη στον προορισμό. Άσχετοι λογαριασμοί προορισμού λαμβάνουν ένα αριθμητικό επίθημα εάν τα ονόματά τους συγκρούονται και οι ρυθμίσεις, οι δεξιότητες, τα πρόσθετα και το ιστορικό συνομιλιών παραμένουν τοπικά σε κάθε μηχάνημα.

Τα υπάρχοντα διαπιστευτήρια προορισμού διατηρούνται. Ένας λογαριασμός πηγής που είναι ήδη συνδεδεμένος εκεί έχει το όνομά του συγχρονισμένο χωρίς να αντικατασταθούν τα διαπιστευτήριά του· άλλοι λογαριασμοί προστίθενται δίπλα του. Για να αντικαταστήσετε τα αποθηκευμένα διαπιστευτήρια για λογαριασμούς που ταιριάζουν, χρησιμοποιήστε `omarchy agent account copy --replace laptop claude` αφού τερματίσετε τις συνεδρίες αυτού του λογαριασμού στον προορισμό. Ένας νέος προορισμός λαμβάνει επίσης τον ενεργό λογαριασμό και τις προτιμήσεις εναλλαγής της πηγής· ένας καθιερωμένος προορισμός διατηρεί τις δικές του.

Τα διαπιστευτήρια ταξιδεύουν μέσω SSH και αποθηκεύονται σε ιδιωτικά αρχεία στον προορισμό, επομένως αντιγράψτε μόνο σε μηχανήματα που εμπιστεύεστε. Πρόκειται για εφάπαξ αντιγραφή, όχι για συνεχή συγχρονισμό. Τα tokens ανανέωσης του Codex μπορούν να εναλλάσσονται κυκλικά από άλλο μηχάνημα, αφήνοντας μια αντιγραμμένη σύνδεση να χρειάζεται ανανέωση· ξεχωριστές συνδέσεις παραμένουν η πιο αξιόπιστη επιλογή για ταυτόχρονη χρήση σε πολλά μηχανήματα. Δείτε [τις οδηγίες ελέγχου ταυτότητας λογαριασμού του Codex](https://developers.openai.com/codex/auth/ci-cd-auth).

Ένας λογαριασμός ανά πάροχο είναι ενεργός και κάθε νέα συνεδρία ξεκινά ως αυτός: `cx`, `cy`, μια απλή `claude`, `codex` ή `grok`, οτιδήποτε εκκινείται μέσω `omarchy agent` και σενάρια ή επεξεργαστές που βρίσκουν το CLI στο `PATH`. Κάντε εναλλαγή με `omarchy agent account use work` (και πίσω με `omarchy agent account use main`) ή στο πάνελ πατώντας τον αριθμό ενός λογαριασμού και στη συνέχεια `Enter` (ή κάνοντας κλικ στο κουμπί Use του). Οι συνεδρίες που εκτελούνται ήδη παραμένουν στον λογαριασμό με τον οποίο ξεκίνησαν. Το ιστορικό συνομιλιών, οι ρυθμίσεις, οι δεξιότητες και τα πρόσθετα μοιράζονται μεταξύ λογαριασμών, επομένως η `claude --continue` στον ίδιο φάκελο συνεχίζει από εκεί που σταματήσατε στον νέο λογαριασμό.

Με περισσότερους από έναν λογαριασμούς, το πάνελ εμφανίζει τα όρια κάθε λογαριασμού δίπλα-δίπλα, με τον ενεργό επισημασμένο. Από προεπιλογή, το Omarchy σας ειδοποιεί όταν ο ενεργός λογαριασμός ξεπεράσει το 95% ενός ορίου και κάνοντας κλικ στην ειδοποίηση γίνεται εναλλαγή στον λογαριασμό με το μεγαλύτερο περιθώριο. Τοποθετήστε τον δείκτη πάνω από τη γραμμή ενός λογαριασμού στο πάνελ και κάντε κλικ στο Autoswitch που εμφανίζεται δίπλα στο Use (ή πατήστε `m`) ή εκτελέστε `omarchy agent account mode auto`, για να γίνεται η εναλλαγή από μόνη της αντ' αυτού· ενώ είναι ενεργό, το Autoswitch παίρνει τη θέση του Use και κάνοντας ξανά κλικ σε αυτό επιστρέφει στην ειδοποίηση. Προσθέστε έναν αριθμό για να αλλάξετε το όριο, όπως στο `omarchy agent account mode auto 90`. Εάν κάθε λογαριασμός υπερβαίνει το όριο, θα ενημερωθείτε μία φορά, μαζί με το ποιος λογαριασμός ελευθερώνεται πρώτος. Ενώ ένας ενεργός λογαριασμός βρίσκεται εντός 15 μονάδων από το όριό του (80% στην προεπιλογή), τα όριά του ελέγχονται κάθε τρία λεπτά αντί για κάθε 15.

Η `omarchy agent account list` εμφανίζει κάθε λογαριασμό και τα τελευταία όριά του, η `omarchy agent account remove work` ξεχνά έναν και η `omarchy agent account rename primary Hey` μετονομάζει έναν (ή κάντε κλικ στο όνομα ενός λογαριασμού στο πάνελ). Αυτές οι εντολές λειτουργούν στους λογαριασμούς του προεπιλεγμένου πράκτορά σας· για να φτάσετε στον άλλο πάροχο, ονομάστε τον πρώτα, όπως στο `omarchy agent account use codex side`. Η σύνδεση που είχατε ήδη στο `~/.claude` ή στο `~/.codex` είναι ο λογαριασμός _Main_ και παραμένει εκεί που είναι. Ένας λογαριασμός που μένει αχρησιμοποίητος για περισσότερες από περίπου οκτώ ώρες μπορεί να εμφανίζει _Sign-in required_· κάντε κλικ σε αυτόν για να συνδεθείτε ξανά σε αυτόν τον λογαριασμό ακριβώς στο πάνελ ή ξεκινήστε μια συνεδρία σε αυτόν, η οποία ανανεώνει τη σύνδεση από μόνη της. Οι διακομιστές MCP που είχατε όταν προστέθηκε ένας λογαριασμός τον ακολουθούν, αλλά αυτοί που προσθέτετε αργότερα με `claude mcp add` φτάνουν μόνο στον λογαριασμό στον οποίο τους προσθέσατε. Το Claude Desktop και εργαλεία που έχουν διαμορφωθεί με απόλυτη διαδρομή προς ένα δυαδικό αρχείο CLI δεν ακολουθούν την εναλλαγή. Ένα ρητό `CLAUDE_CONFIG_DIR`, `CODEX_HOME` ή `GROK_HOME` έχει προτεραιότητα έναντι του επιλεγμένου λογαριασμού.

### Διάγνωση σφαλμάτων κατάρρευσης

Το Omarchy παρακολουθεί το systemd-coredump για καταρρεύσεις διεργασιών. Όταν κάτι υποστεί segfault, θα λάβετε μια ειδοποίηση "Process crashed" — κάντε κλικ σε αυτήν και η κατάρρευση παραδίδεται στον προεπιλεγμένο πράκτορά σας μαζί με τη δεξιότητα diagnose-crash του Omarchy, η οποία καθοδηγεί τον πράκτορα στην εξακρίβωση των γεγονότων από το core dump και στην απόφαση για το εάν η κατάρρευση αξίζει να αναφερθεί upstream. Μπορείτε επίσης να την εκτελέσετε χειροκίνητα έναντι οποιουδήποτε PID από τη `coredumpctl list` με `omarchy agent crash <pid>`.

Η παρακολούθηση είναι ενεργή από προεπιλογή. Απενεργοποιήστε την στην ενότητα _Trigger > Toggle > Crash Capture_ (ή με `omarchy toggle crash-capture`) και οι ειδοποιήσεις σταματούν· η `omarchy agent crash <pid>` εξακολουθεί να λειτουργεί χειροκίνητα.

Οι καταρρεύσεις μπορούν επίσης να σιγαστούν ένα πρόγραμμα κάθε φορά, πράγμα που σας προσφέρει η διάγνωση στο τέλος. Η `omarchy crash mute hyprland` σταματά τις ειδοποιήσεις μόνο για αυτό το πρόγραμμα, η `omarchy crash mute hyprland off` τις επαναφέρει και η `omarchy crash mute` από μόνη της απαριθμεί ό,τι έχετε σιγάσει. Δέχεται τη διαδρομή του δυαδικού αρχείου εξίσου ευχάριστα με το όνομά του, επομένως η `omarchy crash mute /usr/bin/hyprland` κάνει το ίδιο πράγμα. Βάλτε σε εισαγωγικά ένα όνομα με κενό σε αυτό, όπως στο `omarchy crash mute 'Some App'`. Όλα τα άλλα εξακολουθούν να ειδοποιούν και το σιγασμένο πρόγραμμα εξακολουθεί να καταρρέει — αυτό κρύβει την υπενθύμιση, δεν διορθώνει τίποτα.

### Εφαρμογές για υπολογιστή

Το μενού _Install > AI_ περιλαμβάνει επίσης μερικές γραφικές εφαρμογές AI: την εφαρμογή για υπολογιστή ChatGPT, την εφαρμογή για υπολογιστή Claude (τη beta για Linux της Anthropic, με καρτέλες Chat, Cowork και Claude Code), το Grok Bot για συνομιλία με τα μοντέλα της xAI, το Herdr Desktop, το Hermes Desktop, το OpenClaw, την εφαρμογή για υπολογιστή Perplexity και το T3 Code. Το Grok Bot είναι η εφαρμογή συνομιλίας για υπολογιστή. Ο πράκτορας προγραμματισμού είναι η εντολή `grok`.

Το Hermes Desktop είναι αυτό που πρέπει να γνωρίζετε, επειδή ένα μηχάνημα διαθέτει ένα Hermes και είναι της εφαρμογής: το Hermes εγκαθίσταται μόνο ποτέ μέσω της εφαρμογής και η εντολή `hermes` που εκτελεί ο προεπιλεγμένος πράκτορας είναι της εφαρμογής. Η επιλογή του Hermes ως προεπιλεγμένου πράκτορα εγκαθιστά το ίδιο πράγμα που κάνει η καταχώριση _Install > AI_: το πακέτο και ένα περιβάλλον εκτέλεσης Hermes στο `~/.hermes` που ρυθμίζεται από τον ίδιο τον εγκαταστάτη του Hermes, πράγμα που διαρκεί μερικά λεπτά την πρώτη φορά. Αυτό το περιβάλλον εκτέλεσης είναι το ένα Hermes που χρησιμοποιούν η εντολή τερματικού `hermes`, ο προεπιλεγμένος πράκτορας και η εφαρμογή, και ενημερώνεται μόνο του με `hermes update` αντί να περιμένει μια έκδοση του Omarchy. Η εγκατάστασή του παραδίδει επίσης στο Hermes το θέμα του Omarchy ως skin με όνομα `omarchy`, το οποίο ακολουθεί κάθε επιφάνεια του Hermes καθώς αλλάζετε θέματα· επιλέξτε ένα άλλο στις ρυθμίσεις Appearance του Hermes ή με `/skin` εάν προτιμάτε να μην το κάνει και το Omarchy αφήνει αυτή την επιλογή ήσυχη. Η αφαίρεση της εφαρμογής στην ενότητα _Remove > AI_ κλείνει πρώτα το Hermes, συμπεριλαμβανομένης της πύλης, παίρνει μαζί της αυτό το περιβάλλον εκτέλεσης και διατηρεί τις συνομιλίες, τις μνήμες σας και τις δεξιότητες που έγραψε το Hermes για τον εαυτό του, εκτός εάν του πείτε διαφορετικά: ρωτά, με προεπιλογή όχι, εάν αυτά τα δεδομένα και οι ρυθμίσεις σύνδεσής σας πρέπει να φύγουν επίσης.

Η εμπειρία για υπολογιστή του OpenClaw είναι το Control UI του, το οποίο ανοίγει ως εφαρμογή web υποστηριζόμενη από τη δική του τοπική πύλη. Το OpenClaw βρίσκεται στο `~/.openclaw` και ενημερώνεται μόνο του: χρησιμοποιήστε το κουμπί "Update Gateway" του Control UI ή εκτελέστε `openclaw update` και η πύλη επανεκκινείται στη νέα έκδοση. Το Omarchy επιλέγει μόνο την έκδοση από την οποία ξεκινά μια φρέσκια εγκατάσταση. Η αφαίρεση του OpenClaw στην ενότητα _Remove > AI_ παίρνει μαζί της την υπηρεσία πύλης και την εφαρμογή και στη συνέχεια ρωτά εάν το `~/.openclaw` πρέπει να φύγει επίσης, καθώς αυτό περιέχει τις συνομιλίες και τα διαπιστευτήριά σας δίπλα στο ίδιο το OpenClaw και τα περιβάλλοντα εκτέλεσης πρόσθετων που κατεβάζει· η προεπιλογή το διατηρεί και η εγκατάσταση του OpenClaw ξανά το ξαναπαίρνει.

Το Herdr Desktop είναι η εφαρμογή για υπολογιστή [Herdr](https://herdr.dev): χώροι, καρτέλες και πλαίσια τερματικών και πρακτόρων προγραμματισμού που συνεχίζουν να εκτελούνται στον πυρήνα του όταν κλείνετε το παράθυρο. Προέρχεται από τον ίδιο τον εγκαταστάτη του Herdr αντί για ένα πακέτο, επομένως βρίσκεται στο `~/.local/share/herdr-app`, φέρνει τον πυρήνα του στο `~/.local/bin/herdr-core` όταν δεν έχετε ακόμη έναν και ενημερώνει και τα δύο μόνο του. Βρίσκεται δίπλα στην εντολή `herdr` που παρέχει το Omarchy στο `Super + Ctrl + Return` αντί να την αντικαθιστά και λαμβάνει τα άμεσα πλήκτρα αυτής της εντολής: τα `Alt + Return` και `Alt + Shift + Return` διαιρούν ένα πλαίσιο προς τα κάτω ή προς τα δεξιά, το `Alt + Escape` το κλείνει, το `Ctrl + Alt + Arrow` μετακινείται μεταξύ πλαισίων, τα `Alt + 1..9` και `Alt + Left/Right` επιλέγουν μια καρτέλα και το `Alt + Up/Down` μετακινείται μεταξύ χώρων. Το `Ctrl + 1..9` επιλέγει έναν χώρο και το `Alt + Shift + Up/Down` περιηγείται στους πράκτορες. Τα πλήκτρα με πρόθεμα `Ctrl + Space` παραμένουν μόνο για τερματικό, καθώς η εφαρμογή δεν μπορεί να κρατήσει ένα απλό πλήκτρο Ctrl για μια ακολουθία. Το Omarchy τα γράφει στο `~/.config/herdr-app/keys.json` και η `omarchy-refresh-herdr-app` τα επαναφέρει. Η εγκατάστασή του επιλέγει το θέμα Omarchy του Herdr, το οποίο ακολουθεί το θέμα Omarchy σας από τότε και στο εξής. Το Herdr διατηρεί ένα θέμα για τη φωτεινή λειτουργία και ένα για τη σκοτεινή, επομένως αφού εναλλαγείτε μεταξύ ενός σκοτεινού και ενός φωτεινού θέματος Omarchy, επιλέξτε το Omarchy στον επιλογέα θέματος του Herdr μία ακόμη φορά για την άλλη λειτουργία.

Το T3 Code εκτελείται από την επίσημη έκδοση AppImage του στο `~/.local/share/t3code` αντί από ένα πακέτο, επομένως ενημερώνεται μόνο του. Η εγκατάστασή του ρωτά εάν θα ξεκινήσετε στο κανάλι Stable ή Nightly· αλλάξτε αργότερα στις ρυθμίσεις του T3 Code. Τα νήματά σας και οι ρυθμίσεις σας βρίσκονται στο `~/.t3` και η αφαίρεση του T3 Code στην ενότητα _Remove > AI_ τα παίρνει μαζί της.

### Τοπικά μοντέλα

Εκτελέστε ένα ανοιχτό μοντέλο στο δικό σας μηχάνημα για τους πράκτορες προγραμματισμού σας. Οι προτροπές και ο κώδικάς σας παραμένουν στο μηχάνημα· τίποτα που στέλνεται στο μοντέλο δεν το αφήνει. Ξεκινήστε με:

```bash
omarchy agent local use best
```

Ή, στο πάνελ πρακτόρων στην επάνω γραμμή, επιλέξτε + και στη συνέχεια Local AI, το οποίο εμφανίζεται όταν ένα μοντέλο ταιριάζει σε αυτό το μηχάνημα. Την πρώτη φορά, αυτό εγκαθιστά το Podman, το οποίο εκτελεί τα μοντέλα, και σε ένα μηχάνημα NVIDIA την εργαλειοθήκη κοντέινερ της NVIDIA, η οποία τους δίνει τη GPU. Το Omarchy στη συνέχεια επιλέγει το συνιστώμενο μοντέλο για αυτό το μηχάνημα, το κατεβάζει και το ξεκινά. Αναμένετε λήψη δεκάδων GB και το μεγαλύτερο μέρος της μνήμης του μηχανήματος να χρησιμοποιείται ενώ εκτελείται το μοντέλο: το Flash Next χρησιμοποιεί περίπου 100 GiB με το πλήρες περιβάλλον 256K του. Εάν άλλα μοντέλα κρατούν τη μνήμη που χρειάζεται, ρυθμίζεται σταματημένο, έτοιμο να ξεκινήσει μόλις σταματήσετε ένα. Το μοντέλο σταματά κατά την αποσύνδεση· σταματήστε το μόνοι σας όταν χρειάζεστε τη μνήμη για κάτι άλλο.

Η `omarchy agent local list` εμφανίζει τις επιλογές και εξηγεί γιατί ορισμένες δεν ταιριάζουν. Για να ρυθμίσετε ένα άλλο, εκτελέστε `omarchy agent local use <recipe>`. Σήμερα, τα `qwen3.8-flash-next-gufo` και `qwen3.8-27b-gufo` είναι διαθέσιμα για μηχανήματα Strix Halo 128 GB· το 27B καταλαμβάνει περίπου 40 GiB, επομένως αφήνει χώρο για άλλη εργασία. Νέες συνταγές και συστάσεις φτάνουν με την `omarchy update`, μέσω του πακέτου.

Κάθε μοντέλο που ρυθμίζετε λαμβάνει τη δική του γραμμή στο πάνελ πρακτόρων, δίπλα στις συνδρομές σας: play για να το ξεκινήσετε, pause για να το σταματήσετε και να ελευθερώσετε τη μνήμη του και το κουμπί τερματικού για να ανοίξετε τον πράκτορά σας σε αυτό. Πολλά μπορούν να εκτελούνται ταυτόχρονα όταν χωρούν μαζί στη μνήμη· εάν ένα δεν χωρά, το Omarchy λέει ποιο μοντέλο που εκτελείται να σταματήσετε. Σύρετε γραμμές για να τις αναδιατάξετε και πατήστε Delete σε μια επιλεγμένη γραμμή για να αφαιρέσετε ένα μοντέλο και τη λήψη του.

Από τη γραμμή εντολών, οι `omarchy agent local start <recipe>` και `omarchy agent local stop <recipe>` κάνουν το ίδιο, η `omarchy agent local status` εμφανίζει κάθε μοντέλο και η `omarchy agent --local` ανοίγει τον προεπιλεγμένο πράκτορά σας στο τελευταίο μοντέλο που ξεκινήσατε (pi εάν ο προεπιλεγμένος πράκτοράς σας δεν μπορεί να χρησιμοποιήσει τοπικό μοντέλο). Οποιοσδήποτε πελάτης συμβατός με OpenAI μπορεί επίσης να συνδεθεί: η `status` εμφανίζει τη διεύθυνση κάθε μοντέλου (η πρώτη είναι `http://127.0.0.1:11435/v1`), το όνομα της συνταγής είναι το μοντέλο και το κλειδί βρίσκεται στο `~/.config/omarchy/agent-local/key`.

Η `omarchy agent local remove <recipe>` διαγράφει ένα μοντέλο και τις λήψεις που δεν χρησιμοποιεί κανένα άλλο μοντέλο.

Τα περιβάλλοντα εκτέλεσης τρίτων επισημαίνονται με τον εκδότη τους. Το Omarchy εκτελεί κάθε μοντέλο χωρίς πρόσβαση στο δίκτυο.

### Τοπικά LLM

Το Omarchy συνιστά δύο τρόπους εκτέλεσης τοπικών μοντέλων LLM: LM Studio και Ollama. Το LM Studio παρέχει μια διεπαφή GUI για την εύρεση μοντέλων ανοιχτών βαρών, την εγκατάστασή τους και την εκτέλεσή τους. Είναι ένας εξαιρετικός τρόπος για να ξεκινήσετε εύκολα. Το Ollama προσφέρει ένα CLI για να κάνετε το ίδιο παρόμοια. Αλλά εάν είστε νέοι στα τοπικά μοντέλα, θα ξεκινούσα με το LM Studio. Μπορείτε να εγκαταστήσετε οποιοδήποτε από τα δύο στην ενότητα _Install > AI_ στο Μενού Omarchy.

### Η δεξιότητα Omarchy

Οι δεξιότητες πρακτόρων βοηθούν την AI να χρησιμοποιεί συγκεκριμένα εργαλεία με συγκεκριμένο τρόπο και το Omarchy παρέχεται με μια προεπιλεγμένη δεξιότητα για την προσαρμογή του συστήματος. Όπως η ρύθμιση του Hyprland config σας, η προσαρμογή της γραμμής ή ακόμη και η δημιουργία ενός νέου θέματος από την αρχή. Είναι συμβολικά συνδεδεμένη στους καταλόγους δεξιοτήτων για Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` και κάθε `~/.hermes/profiles/*/skills`) και τη γενική τοποθεσία `~/.agents/skills`, επομένως τα περισσότερα harness την εντοπίζουν αυτόματα.

Αλλά θα πρέπει να αντιμετωπίζετε αυτή τη δεξιότητα ως πειραματική. Διαφορετικά μοντέλα θα τη χρησιμοποιήσουν με διαφορετικό αποτέλεσμα. Είναι καλύτερο να εκτελείται πρώτα σε λειτουργία σχεδιασμού, ώστε να έχετε μια ιδέα για το τι θα ήθελε να αλλάξει ο πράκτορας. Και στη συνέχεια να είστε έτοιμοι να επαναφέρετε αλλαγές ή ακόμη και να επικαλεστείτε την `omarchy reinstall configs`, εάν ο πράκτορας κάνει τα πάντα άνω κάτω.
