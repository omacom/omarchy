# Τεχνητή Νοημοσύνη

Το Omarchy περιλαμβάνει εκκινητές για τους παρακάτω agents προγραμματισμού, χωρίς να επιλέγει κάποιον προεπιλεγμένο για εσάς. Εκτελέστε μια εντολή για να εγκατασταθεί το CLI της κατά την πρώτη χρήση και, στη συνέχεια, κάντε έλεγχο ταυτότητας όταν σας ζητηθεί. Το Hermes αποτελεί την εξαίρεση: δεν εγκαθίσταται τίποτα για αυτό κατά την πρώτη χρήση και, αν το επιλέξετε, εγκαθίσταται το Hermes Desktop, όπως εξηγεί παρακάτω η ενότητα _Desktop apps_.

### Εγκατάσταση και ενημέρωση των agents

Με εξαίρεση το Hermes, αυτοί οι agents χρησιμοποιούν την lazy εγκατάσταση του mise: η πρώτη εκκίνηση εγκαθιστά το CLI και οι επόμενες εκκινήσεις το επαναχρησιμοποιούν. Το mise ελέγχει επίσης έναν εγκατεστημένο agent για νέα έκδοση το πολύ μία φορά κάθε τέσσερις ώρες, αμέσως πριν ξεκινήσει ή στο παρασκήνιο σε ένα prompt του shell. Αν αυτή η ενημέρωση αποτύχει ή είστε εκτός σύνδεσης, εκτελείται η εγκατεστημένη έκδοση. Η εντολή `omarchy update` ενημερώνει τους εγκατεστημένους agents μαζί με το υπόλοιπο Omarchy, ενώ η εντολή `mup` ενημερώνει μόνο τα εργαλεία που διαχειρίζεται το mise.

Το πρόγραμμα ενημέρωσης ενός agent, όπως το `claude update`, το `codex update` ή ένα κουμπί ενημέρωσης σε μια εφαρμογή, δεν ενημερώνει την εγκατάσταση που διαχειρίζεται το mise. Η εντολή `codex update` αποτυγχάνει και η εντολή `claude update` μπορεί να αναφέρει επιτυχία ενώ εγκαθιστά ένα ξεχωριστό αντίγραφο που το mise δεν παρακολουθεί. Αν προτιμάτε να χρησιμοποιείτε το εγγενές πρόγραμμα εγκατάστασης και ενημέρωσης ενός agent, προσθέστε το στο `disable_tools`. Δείτε τα [Προεγκατεστημένα εργαλεία CLI](18-development-tools.md#preinstalled-cli-tools).

Για να εγκαταστήσετε όλα τα ρυθμισμένα lazy εργαλεία πριν τα χρειαστείτε, εκτελέστε την εντολή `mise install --include-lazy`. Αυτό περιλαμβάνει τα άλλα προεπιλεγμένα εργαλεία CLI του Omarchy, καθώς και τους agents. Δείτε τα [Προεγκατεστημένα εργαλεία CLI](18-development-tools.md#preinstalled-cli-tools) για την εγκατάσταση ενός μεμονωμένου εργαλείου ή τη χρήση της δικής σας εγκατάστασης.

Το `grok` εγκαθίσταται μέσω του first-party πακέτου `grok` του mise, με τον ίδιο τρόπο όπως τα `claude` και `codex`. Εκτελέστε την εντολή `grok` ή επιλέξτε το στην ενότητα _Setup > Defaults > Agent_. Παραλείψτε το πρόγραμμα εγκατάστασης `curl | bash` στο x.ai. Αυτή η διαδρομή τοποθετεί ένα δεύτερο αντίγραφο στο `~/.grok/bin`, το προσθέτει στην αρχή του `PATH` και αντικαθιστά το wrapper του Omarchy.

Το `dsh` ανοίγει το UI του προγράμματος περιήγησής του στη διεύθυνση `127.0.0.1:3080`, με τον κατάλογο εκκίνησης ως τον προεπιλεγμένο χώρο εργασίας του. Το UI του προγράμματος περιήγησής του δεν δέχεται αρχικό prompt, οπότε η εντολή `omarchy agent prompt` το ανοίγει με το prompt στο πρόχειρό σας για επικόλληση. Το Omarchy το ξεκινά με το preset δικαιωμάτων no-approval της DeepSeek. Το DeepSeek Harness ανεβάζει αρχεία καταγραφής συνεδριών στην DeepSeek όταν χρησιμοποιείτε το επίσημο API μοντέλων της. Απενεργοποιήστε το στην ενότητα _Settings > General > Upload Session Log_ στο UI του προγράμματος περιήγησής του. Τα σχόλια που του στέλνετε ανεβαίνουν επίσης μαζί με τη συνεδρία, εκτός αν το ξεκινήσετε με `DSH_TELEMETRY_MODE=DISABLED`.

### Ο προεπιλεγμένος agent

Επιλέξτε τον προεπιλεγμένο agent σας με την εντολή `omarchy default agent <name>` ή στην ενότητα _Setup > Defaults > Agent_ στο Omarchy Menu (`Super + Space`). Αν ο agent δεν έχει εγκατασταθεί ακόμα, η επιλογή του τον εγκαθιστά πρώτα. Ένα φρέσκο Omarchy θα σας καλέσει να κάνετε αυτή την επιλογή με μια εφάπαξ ειδοποίηση.

Η επιλογή του Claude επιχειρεί επίσης να ρυθμίσει την επέκταση του προγράμματος περιήγησής του για τα Chromium, Chrome, Brave, Brave Origin και Edge. Η ρύθμιση της επέκτασης ισχύει για όλους τους χρήστες και ενδέχεται να ζητήσει τον κωδικό πρόσβασης του συστήματός σας. Η ακύρωση ή μια αποτυχημένη εγκατάσταση επέκτασης εξακολουθεί να επιλέγει και να εκκινεί το Claude. Επανεκκινήστε το πρόγραμμα περιήγησής σας, ενεργοποιήστε την επέκταση αν σας ζητηθεί και συνδεθείτε στο Claude για να ολοκληρώσετε τη σύνδεσή της. Εκτελέστε την εντολή `/chrome` στο Claude για να ελέγξετε τη σύνδεση. Τα Firefox και Zen δεν υποστηρίζουν αυτή την επέκταση. Αν το Claude ήταν ήδη ο προεπιλεγμένος agent σας πριν προστεθεί αυτή η ρύθμιση, επιλέξτε το ξανά για να εγκαταστήσετε την επέκταση.

Αφού κάνετε την επιλογή σας, ο συνδυασμός `Super + Shift + Ctrl + A` εκκινεί τον προεπιλεγμένο agent σε ένα αποκλειστικό παράθυρο τερματικού (ή εμφανίζει τον επιλογέα αν δεν έχετε επιλέξει ακόμα). Μπορείτε επίσης να τον εκκινήσετε απευθείας σε μια εργασία με την εντολή `omarchy agent prompt "Review this project"`. Τα Freebuff και DeepSeek Harness δεν δέχονται αρχικό prompt, οπότε ανοίγουν με το prompt στο πρόχειρό σας για επικόλληση. Οι agents που εκκινούνται με αυτόν τον τρόπο εκτελούνται χωρίς επίβλεψη στις αντίστοιχες λειτουργίες don't-stop-to-ask, οπότε να είστε έτοιμοι να κάνουν πραγματικά πράγματα! Το MiniMax Code δεν διαθέτει τέτοια λειτουργία για τις διαδραστικές συνεδρίες του, οπότε ζητά δικαιώματα ως συνήθως. Και επειδή οι agents αρνούνται να θυμούνται την εμπιστοσύνη για τον αρχικό κατάλογό σας, οι εκκινήσεις από το `$HOME` ξεκινούν αντί αυτού στο `~/Work`.

Υπάρχουν και συντομεύσεις τερματικού: η εντολή `a` εκτελεί τον προεπιλεγμένο agent ενσωματωμένο στο τρέχον τερματικό, ενώ οι εντολές `c`, `cx` και `cy` ξεκινούν απευθείας τα OpenCode, Claude Code και Codex (και πάλι στις λειτουργίες αυτόματης έγκρισής τους). Οι αλλαγές θέματος συγχρονίζονται επίσης με τους agents: τα Claude Code, Pi, OpenCode και Hermes (αφού το Omarchy το έχει εγκαταστήσει) ακολουθούν όλα όταν αλλάζετε το θέμα του Omarchy.

### Το πάνελ των agents

Η επάνω μπάρα έχει ένα εικονίδιο agents. Πριν ρυθμίσετε έναν agent, το πάνελ του σας καθοδηγεί στη σύνδεση στο Claude, το Codex ή το Grok και το πρώτο γίνεται ο προεπιλεγμένος agent σας. Μετά από αυτό, το πάνελ συγκεντρώνει κάθε συνδρομή σε μία σελίδα: κάθε agent και λογαριασμό με το πλάνο του, έναν μετρητή για καθένα από τα όρια συνεδρίας 5 ωρών και τα εβδομαδιαία όριά του με τον χρόνο μέχρι την επαναφορά του (τοποθετήστε τον δείκτη πάνω του για το ακριβές ποσοστό) ή το υπόλοιπο προπληρωμένο υπόλοιπο, κάτω από μια γραμμή που εναλλάσσεται ανάμεσα σε όσα έχετε χρησιμοποιήσει σε όλα αυτά, όπως τα tokens αυτής της εβδομάδας και το μοντέλο που χρησιμοποιείτε περισσότερο. Στην ενότητα _Make something_ προσφέρει αρχικά prompts για ένα νέο θέμα, plugin ή εφαρμογή, τα οποία αναθέτουν την εργασία στον προεπιλεγμένο agent σας. Οι εφαρμογές δημιουργούνται με τον τρόπο που δημιουργούνται τα ίδια τα Hype, Monologue και Omacut του Omarchy, σε C++ και Qt Quick, ακολουθώντας το agent skill omarchy-app, ενώ ο compiler και τα στοιχεία Qt που χρειάζονται παρέχονται εγκατεστημένα. Τα Claude Code, Codex, Grok, Kimi, Cursor και το Grok Bot allowance του, GitHub Copilot, Muse, Antigravity, Kimchi και Devin καλύπτονται εξαρχής με τα όριά τους, ενώ τα Hermes, Mistral Vibe και Qwen Code εμφανίζουν τις συνεδρίες και τα tokens τους αφού τα χρησιμοποιήσετε. Τα πλάνα παρόχων και τα κλειδιά που χρησιμοποιείτε μέσω των pi, omp ή opencode εμφανίζονται επίσης: τα OpenCode Zen και Go, το Z.ai GLM Coding Plan, το Ollama Cloud, το MiniMax Token Plan και το Synthetic με τα όριά τους. Τα Fireworks, OpenRouter και DeepSeek με τα προπληρωμένα υπόλοιπά τους. Και τα μοντέλα που εκτελείτε στο δικό σας hardware στην ενότητα Local models. Κάθε agent καταμετράται μία φορά, σε όποιον τον χρεώνει, ανεξάρτητα από το πόσα harnesses χρησιμοποιείτε για να τον χειριστείτε.

Κάντε αριστερό κλικ στο εικονίδιο της μπάρας για το πάνελ και δεξί κλικ για να εκκινήσετε τον προεπιλεγμένο agent σας. Τα αρχεία χρήσης που βρίσκονται πίσω από αυτό αναδημιουργούνται κάθε 15 λεπτά από την εντολή `omarchy agent usage-update` και το πάνελ μπορεί ακόμη και να συγχωνεύσει τη χρήση από τα άλλα μηχανήματά σας μέσω ενός συγχρονισμένου φακέλου. Δείτε το README στην ενότητα `$OMARCHY_PATH/shell/plugins/agents/` για τις πλήρεις ρυθμίσεις.

### Πολλαπλές συνδρομές

Αν πληρώνετε για περισσότερα από ένα πλάνα Claude, Codex ή Grok — ένα προσωπικό Max και ένα επαγγελματικό, ας πούμε — το Omarchy μπορεί να τα κρατήσει όλα συνδεδεμένα και να μετακινείται ανάμεσά τους. Προσθέστε μια συνδρομή με το + στο πάνελ των agents, το οποίο σας καθοδηγεί εκεί επί τόπου, ή με την εντολή `omarchy agent account add claude Work` (ή `codex` ή `grok`). Εγκαθιστά το CLI αν λείπει. Ο πρώτος λογαριασμός για έναν πάροχο συνδέεται μέσω του κανονικού προγράμματος περιήγησής σας, ακριβώς εκεί όπου το CLI αναζητά πάντα. Κάθε επόμενος συνδέεται μέσω ενός ιδιωτικού παραθύρου, ώστε ο λογαριασμός στον οποίο το πρόγραμμα περιήγησής σας είναι ήδη συνδεδεμένο να μην επιλεγεί κατά λάθος. Συνδεθείτε εκεί ως ο λογαριασμός που προσθέτετε και κλείστε πρώτα κάθε ιδιωτικό παράθυρο που είχατε ήδη ανοιχτό. Μην αποσυνδέεστε ποτέ από το CLI για να το κάνετε αυτό: η αποσύνδεση ανακαλεί την αποθηκευμένη σύνδεση και αυτός ο λογαριασμός θα πρέπει να προστεθεί ξανά.

Για να αντιγράψετε τις συνδέσεις της συνδρομής σας σε ένα άλλο μηχάνημα Omarchy μέσω SSH, εκτελέστε την εντολή `omarchy agent account copy user@laptop`. Ο αποστολέας παρέχει έναν προσωρινό δέκτη όταν ο προορισμός δεν έχει εγκατεστημένο κάποιον, οπότε παλαιότερα μηχανήματα Omarchy μπορούν να λάβουν λογαριασμούς χωρίς ενημέρωση. Οι εγκατεστημένοι δέκτες έχουν προτεραιότητα. Αυτό αντιγράφει όλες τις συνδρομές Claude, Codex και Grok. Προσθέστε ονόματα παρόχων για να τις επιλέξετε, όπως στην εντολή `omarchy agent account copy laptop claude`. Τα ονόματα λογαριασμών και τα αναγνωριστικά εντολών ταιριάζουν με την πηγή, συμπεριλαμβανομένων των λογαριασμών που υπάρχουν ήδη στον προορισμό. Οι άσχετοι λογαριασμοί προορισμού λαμβάνουν ένα αριθμητικό επίθημα αν τα ονόματά τους συγκρούονται, ενώ οι ρυθμίσεις, τα skills, τα plugins και το ιστορικό συνομιλιών παραμένουν τοπικά σε κάθε μηχάνημα.

Τα υπάρχοντα διαπιστευτήρια προορισμού διατηρούνται. Ένας λογαριασμός πηγής που είναι ήδη συνδεδεμένος εκεί συγχρονίζει το όνομά του χωρίς να αντικαθιστά τα διαπιστευτήριά του. Οι άλλοι λογαριασμοί προστίθενται δίπλα του. Για να αντικαταστήσετε τα αποθηκευμένα διαπιστευτήρια για λογαριασμούς που ταιριάζουν, χρησιμοποιήστε την εντολή `omarchy agent account copy --replace laptop claude` αφού κλείσετε τις συνεδρίες αυτού του λογαριασμού στον προορισμό. Ένας φρέσκος προορισμός λαμβάνει επίσης τον ενεργό λογαριασμό και τις προτιμήσεις εναλλαγής της πηγής. Ένας εδραιωμένος προορισμός διατηρεί τις δικές του.

Τα διαπιστευτήρια ταξιδεύουν μέσω SSH και αποθηκεύονται σε ιδιωτικά αρχεία στον προορισμό, οπότε αντιγράψτε τα μόνο σε μηχανήματα που εμπιστεύεστε. Πρόκειται για μια εφάπαξ αντιγραφή, όχι για συνεχή συγχρονισμό. Τα refresh tokens του Codex μπορούν να ανανεωθούν από άλλο μηχάνημα, αφήνοντας μια αντιγραμμένη σύνδεση να χρειάζεται ανανέωση. Οι ξεχωριστές συνδέσεις παραμένουν η πιο αξιόπιστη επιλογή για ταυτόχρονη χρήση σε πολλά μηχανήματα. Δείτε τις [οδηγίες ελέγχου ταυτότητας λογαριασμού του Codex](https://developers.openai.com/codex/auth/ci-cd-auth).

Ένας λογαριασμός ανά πάροχο είναι ενεργός και κάθε νέα συνεδρία ξεκινά ως αυτός: οι εντολές `cx`, `cy`, ένα απλό `claude`, `codex` ή `grok`, οτιδήποτε εκκινείται μέσω του `omarchy agent`, καθώς και scripts ή επεξεργαστές που βρίσκουν το CLI στο `PATH`. Αλλάξτε με την εντολή `omarchy agent account use work` (και επιστρέψτε με την εντολή `omarchy agent account use main`) ή στο πάνελ πατώντας τον αριθμό ενός λογαριασμού και στη συνέχεια το `Enter` (ή κάνοντας κλικ στο κουμπί Use του). Οι συνεδρίες που εκτελούνται ήδη παραμένουν στον λογαριασμό με τον οποίο ξεκίνησαν. Το ιστορικό συνομιλιών, οι ρυθμίσεις, τα skills και τα plugins μοιράζονται μεταξύ λογαριασμών, οπότε η εντολή `claude --continue` στον ίδιο φάκελο συνεχίζει από εκεί που σταματήσατε στον νέο λογαριασμό.

Με περισσότερους από έναν λογαριασμούς, το πάνελ εμφανίζει τα όρια κάθε λογαριασμού δίπλα-δίπλα, με τον ενεργό επισημασμένο. Από προεπιλογή, το Omarchy σας ειδοποιεί όταν ο ενεργός λογαριασμός ξεπερνά το 95% ενός ορίου και, κάνοντας κλικ στην ειδοποίηση, μεταβαίνετε στον λογαριασμό με το μεγαλύτερο περιθώριο. Τοποθετήστε τον δείκτη πάνω στη γραμμή ενός λογαριασμού στο πάνελ και κάντε κλικ στο Autoswitch που εμφανίζεται δίπλα στο Use (ή πατήστε `m`) ή εκτελέστε την εντολή `omarchy agent account mode auto`, για να γίνεται η εναλλαγή αυτόματα. Όσο είναι ενεργό, το Autoswitch παίρνει τη θέση του Use και, κάνοντας ξανά κλικ σε αυτό, επιστρέφετε στις ειδοποιήσεις. Προσθέστε έναν αριθμό για να αλλάξετε το όριο, όπως στην εντολή `omarchy agent account mode auto 90`. Αν κάθε λογαριασμός βρίσκεται πάνω από το όριο, θα ενημερωθείτε μία φορά, μαζί με το ποιος λογαριασμός απελευθερώνεται πρώτος. Όσο ένας ενεργός λογαριασμός βρίσκεται εντός 15 μονάδων από το όριό του (80% στην προεπιλογή), τα όριά του ελέγχονται κάθε τρία λεπτά αντί για κάθε 15.

Η εντολή `omarchy agent account list` εμφανίζει κάθε λογαριασμό και τα πιο πρόσφατα όριά του, η εντολή `omarchy agent account remove work` ξεχνά έναν και η εντολή `omarchy agent account rename primary Hey` μετονομάζει έναν (ή κάντε κλικ στο όνομα ενός λογαριασμού στο πάνελ). Αυτές οι εντολές λειτουργούν στους λογαριασμούς του προεπιλεγμένου agent σας. Για να φτάσετε στον άλλο πάροχο, ονομάστε τον πρώτα, όπως στην εντολή `omarchy agent account use codex side`. Η σύνδεση που είχατε ήδη στο `~/.claude` ή στο `~/.codex` είναι ο λογαριασμός _Main_ και παραμένει εκεί που βρίσκεται. Ένας λογαριασμός που παραμένει αχρησιμοποίητος για περισσότερες από περίπου οκτώ ώρες μπορεί να εμφανίσει _Sign-in required_. Κάντε κλικ σε αυτόν για να συνδεθείτε ξανά σε αυτόν τον λογαριασμό απευθείας στο πάνελ ή ξεκινήστε μια συνεδρία σε αυτόν, η οποία ανανεώνει τη σύνδεση από μόνη της. Οι διακομιστές MCP που είχατε όταν προστέθηκε ένας λογαριασμός μεταφέρονται σε αυτόν, αλλά όσοι προσθέτετε αργότερα με την εντολή `claude mcp add` φτάνουν μόνο στον λογαριασμό στον οποίο τους προσθέσατε. Το Claude Desktop και τα εργαλεία που έχουν ρυθμιστεί με μια απόλυτη διαδρομή προς ένα δυαδικό αρχείο CLI δεν ακολουθούν την εναλλαγή. Ένα ρητό `CLAUDE_CONFIG_DIR`, `CODEX_HOME` ή `GROK_HOME` υπερισχύει του επιλεγμένου λογαριασμού.

### Διάγνωση κατάρρευσης

Το Omarchy παρακολουθεί το systemd-coredump για καταρρεύσεις διεργασιών. Όταν κάτι παρουσιάσει segfault, θα λάβετε μια ειδοποίηση "Process crashed" — κάντε κλικ σε αυτήν και η κατάρρευση παραδίδεται στον προεπιλεγμένο agent σας μαζί με το skill diagnose-crash του Omarchy, το οποίο καθοδηγεί τον agent στη διαπίστωση των γεγονότων από το core dump και στην απόφαση για το αν η κατάρρευση αξίζει να αναφερθεί upstream. Μπορείτε επίσης να το εκτελέσετε χειροκίνητα για οποιοδήποτε PID από τη λίστα `coredumpctl list` με την εντολή `omarchy agent crash <pid>`.

Η παρακολούθηση είναι ενεργοποιημένη από προεπιλογή. Απενεργοποιήστε την στην ενότητα _Trigger > Toggle > Crash Capture_ (ή με την εντολή `omarchy toggle crash-capture`) και οι ειδοποιήσεις σταματούν. Η εντολή `omarchy agent crash <pid>` εξακολουθεί να λειτουργεί χειροκίνητα.

Οι καταρρεύσεις μπορούν επίσης να σιγήσουν ένα πρόγραμμα κάθε φορά, κάτι που σας προσφέρει η διάγνωση στο τέλος. Η εντολή `omarchy crash mute hyprland` σταματά τις ειδοποιήσεις μόνο για αυτό το πρόγραμμα, η εντολή `omarchy crash mute hyprland off` τις επαναφέρει και η εντολή `omarchy crash mute` από μόνη της παραθέτει όσα έχετε θέσει σε σίγαση. Δέχεται τη διαδρομή του δυαδικού αρχείου εξίσου ευχαρίστως με το όνομά του, οπότε η εντολή `omarchy crash mute /usr/bin/hyprland` κάνει το ίδιο πράγμα. Βάλτε σε εισαγωγικά ένα όνομα με κενό, όπως στην εντολή `omarchy crash mute 'Some App'`. Όλα τα υπόλοιπα εξακολουθούν να ειδοποιούν και το πρόγραμμα σε σίγαση εξακολουθεί να καταρρέει — αυτό κρύβει την υπενθύμιση, δεν διορθώνει τίποτα.

### Εφαρμογές desktop

Το μενού _Install > AI_ περιλαμβάνει επίσης μερικές γραφικές εφαρμογές τεχνητής νοημοσύνης: την εφαρμογή desktop ChatGPT, την εφαρμογή desktop Claude (τη Linux beta της Anthropic, με καρτέλες Chat, Cowork και Claude Code), το Grok Bot για συνομιλία με τα μοντέλα της xAI, το Herdr Desktop, το Hermes Desktop, το OpenClaw, την εφαρμογή desktop Perplexity και το T3 Code. Το Grok Bot είναι η εφαρμογή συνομιλίας desktop. Ο agent προγραμματισμού είναι η εντολή `grok`.

Το Hermes Desktop είναι αυτό που πρέπει να γνωρίζετε, επειδή ένα μηχάνημα έχει ένα Hermes και είναι της εφαρμογής: το Hermes εγκαθίσταται πάντα μόνο μέσω της εφαρμογής και η εντολή `hermes` που εκτελεί ο προεπιλεγμένος agent είναι της εφαρμογής. Η επιλογή του Hermes ως προεπιλεγμένου agent εγκαθιστά το ίδιο πράγμα που εγκαθιστά η καταχώριση _Install > AI_: το πακέτο και ένα runtime του Hermes στο `~/.hermes`, ρυθμισμένο από το ίδιο το πρόγραμμα εγκατάστασης του Hermes, κάτι που διαρκεί μερικά λεπτά την πρώτη φορά. Αυτό το runtime είναι το μοναδικό Hermes που χρησιμοποιούν η εντολή τερματικού `hermes`, ο προεπιλεγμένος agent και η εφαρμογή, και ενημερώνεται μόνο του με την εντολή `hermes update` αντί να περιμένει μια έκδοση του Omarchy. Η εγκατάστασή του παραδίδει επίσης στο Hermes το θέμα του Omarchy ως ένα skin με όνομα `omarchy`, το οποίο ακολουθεί κάθε επιφάνεια του Hermes καθώς αλλάζετε θέματα. Επιλέξτε ένα άλλο στις ρυθμίσεις Appearance του Hermes ή με την εντολή `/skin` αν προτιμάτε να μην το κάνει και το Omarchy αφήνει αυτή την επιλογή ανεπηρέαστη. Η αφαίρεση της εφαρμογής στην ενότητα _Remove > AI_ κλείνει πρώτα το Hermes, συμπεριλαμβανομένου του gateway, παίρνει μαζί της αυτό το runtime και διατηρεί τις συνομιλίες, τις αναμνήσεις και τα skills που το Hermes έγραψε για τον εαυτό του, εκτός αν του πείτε διαφορετικά: σας ρωτά, με προεπιλογή το όχι, αν αυτά τα δεδομένα και οι ρυθμίσεις σύνδεσής σας πρέπει να φύγουν επίσης.

Η εμπειρία desktop του OpenClaw είναι το Control UI του, το οποίο ανοίγει ως μια web εφαρμογή που υποστηρίζεται από το δικό του τοπικό gateway. Το OpenClaw βρίσκεται στο `~/.openclaw` και ενημερώνεται μόνο του: χρησιμοποιήστε το κουμπί "Update Gateway" του Control UI ή εκτελέστε την εντολή `openclaw update` και το gateway επανεκκινείται στη νέα έκδοση. Το Omarchy επιλέγει μόνο την έκδοση από την οποία ξεκινά μια φρέσκια εγκατάσταση. Η αφαίρεση του OpenClaw στην ενότητα _Remove > AI_ παίρνει μαζί της την υπηρεσία gateway και την εφαρμογή και στη συνέχεια ρωτά αν πρέπει να φύγει και το `~/.openclaw`, αφού εκεί φυλάσσονται οι συνομιλίες και τα διαπιστευτήριά σας μαζί με το ίδιο το OpenClaw και τα runtimes των plugins που κατεβάζει. Η προεπιλογή το διατηρεί και η επανεγκατάσταση του OpenClaw το αναλαμβάνει ξανά.

Το Herdr Desktop είναι η εφαρμογή desktop [Herdr](https://herdr.dev): χώροι, καρτέλες και panes τερματικών και agents προγραμματισμού που συνεχίζουν να εκτελούνται στον πυρήνα του όταν κλείνετε το παράθυρο. Προέρχεται από το ίδιο το πρόγραμμα εγκατάστασης του Herdr και όχι από ένα πακέτο, οπότε βρίσκεται στο `~/.local/share/herdr-app`, φέρνει τον πυρήνα του στο `~/.local/bin/herdr-core` όταν δεν έχετε ήδη έναν και ενημερώνει και τα δύο μόνο του. Βρίσκεται δίπλα στην εντολή `herdr` που παρέχει το Omarchy στον συνδυασμό `Super + Ctrl + Return` αντί να την αντικαθιστά. Η εγκατάστασή του επιλέγει το θέμα Omarchy του Herdr, το οποίο ακολουθεί από τότε το θέμα του Omarchy σας. Το Herdr διατηρεί ένα θέμα για τη φωτεινή λειτουργία και ένα για τη σκοτεινή, οπότε, αφού μεταβείτε από ένα σκοτεινό σε ένα φωτεινό θέμα Omarchy, επιλέξτε το Omarchy στον επιλογέα θέματος του Herdr άλλη μία φορά για την άλλη λειτουργία.

Το T3 Code εκτελείται από την επίσημη έκδοση AppImage του στο `~/.local/share/t3code` και όχι από ένα πακέτο, οπότε ενημερώνεται μόνο του. Η εγκατάστασή του σας ρωτά αν θα ξεκινήσετε στο κανάλι Stable ή Nightly. Αλλάξτε το αργότερα στις ρυθμίσεις του T3 Code. Τα νήματα και οι ρυθμίσεις σας βρίσκονται στο `~/.t3` και η αφαίρεση του T3 Code στην ενότητα _Remove > AI_ τα παίρνει μαζί της.

### Τοπικά μοντέλα

Εκτελέστε ένα ανοιχτό μοντέλο στο δικό σας μηχάνημα για τους agents προγραμματισμού σας. Τα prompts και ο κώδικάς σας παραμένουν στο μηχάνημα. Τίποτα από όσα στέλνονται στο μοντέλο δεν φεύγει από αυτό. Ξεκινήστε με:

```bash
omarchy agent local use best
```

Ή, στο πάνελ των agents στην επάνω μπάρα, επιλέξτε + και στη συνέχεια Local AI, το οποίο εμφανίζεται όταν ένα μοντέλο ταιριάζει σε αυτό το μηχάνημα. Την πρώτη φορά, αυτό εγκαθιστά το Podman, το οποίο εκτελεί τα μοντέλα, και σε ένα μηχάνημα NVIDIA το container toolkit της NVIDIA, το οποίο τους δίνει πρόσβαση στη GPU. Στη συνέχεια, το Omarchy επιλέγει το προτεινόμενο μοντέλο για αυτό το μηχάνημα, το κατεβάζει και το ξεκινά. Να περιμένετε μια λήψη δεκάδων GB και το μεγαλύτερο μέρος της μνήμης του μηχανήματος να χρησιμοποιείται όσο εκτελείται το μοντέλο: το Flash Next χρησιμοποιεί περίπου 100 GiB με το πλήρες context των 256K. Αν άλλα μοντέλα κατέχουν τη μνήμη που χρειάζεται, ρυθμίζεται σταματημένο, έτοιμο να ξεκινήσει μόλις σταματήσετε ένα. Το μοντέλο σταματά κατά την αποσύνδεση. Σταματήστε το μόνοι σας όταν χρειάζεστε τη μνήμη για κάτι άλλο.

Η εντολή `omarchy agent local list` εμφανίζει τις επιλογές και εξηγεί γιατί ορισμένες δεν ταιριάζουν. Για να ρυθμίσετε ένα άλλο, εκτελέστε την εντολή `omarchy agent local use <recipe>`. Σήμερα, τα `qwen3.8-flash-next-gufo` και `qwen3.8-27b-gufo` είναι διαθέσιμα για μηχανήματα Strix Halo των 128 GB. Το 27B καταλαμβάνει περίπου 40 GiB, οπότε αφήνει χώρο για άλλη εργασία. Νέες συνταγές και προτάσεις φτάνουν με την εντολή `omarchy update`, μέσω του πακέτου.

Κάθε μοντέλο που ρυθμίζετε αποκτά τη δική του γραμμή στο πάνελ των agents, δίπλα στις συνδρομές σας: play για να το ξεκινήσετε, pause για να το σταματήσετε και να ελευθερώσετε τη μνήμη του και το κουμπί τερματικού για να ανοίξετε τον agent σας σε αυτό. Πολλά μπορούν να εκτελούνται ταυτόχρονα όταν χωρούν μαζί στη μνήμη. Αν ένα δεν χωρά, το Omarchy λέει ποιο μοντέλο που εκτελείται να σταματήσετε. Σύρετε τις γραμμές για να τις αναδιατάξετε και πατήστε Delete σε μια επιλεγμένη γραμμή για να αφαιρέσετε ένα μοντέλο και τη λήψη του.

Από τη γραμμή εντολών, οι εντολές `omarchy agent local start <recipe>` και `omarchy agent local stop <recipe>` κάνουν το ίδιο, η εντολή `omarchy agent local status` εμφανίζει κάθε μοντέλο και η εντολή `omarchy agent --local` ανοίγει τον προεπιλεγμένο agent σας στο τελευταίο μοντέλο που ξεκινήσατε (το pi αν ο προεπιλεγμένος agent σας δεν μπορεί να χρησιμοποιήσει ένα τοπικό μοντέλο). Οποιοσδήποτε client συμβατός με OpenAI μπορεί επίσης να συνδεθεί: η εντολή `status` εμφανίζει τη διεύθυνση κάθε μοντέλου (η πρώτη είναι `http://127.0.0.1:11435/v1`), το όνομα της συνταγής είναι το μοντέλο και το κλειδί βρίσκεται στο `~/.config/omarchy/agent-local/key`.

Η εντολή `omarchy agent local remove <recipe>` διαγράφει ένα μοντέλο και τις λήψεις που δεν χρησιμοποιεί κανένα άλλο μοντέλο.

Τα runtimes τρίτων επισημαίνονται με τον εκδότη τους. Το Omarchy εκτελεί κάθε μοντέλο χωρίς πρόσβαση στο δίκτυο.

### Τοπικά LLM

Το Omarchy προτείνει δύο τρόπους εκτέλεσης τοπικών μοντέλων LLM: το LM Studio και το Ollama. Το LM Studio παρέχει ένα GUI περιβάλλον για την εύρεση μοντέλων ανοιχτών βαρών, την εγκατάστασή τους και την εκτέλεσή τους. Είναι ένας εξαιρετικός τρόπος για να ξεκινήσετε εύκολα. Το Ollama προσφέρει ένα CLI για να κάνετε κάτι παρόμοιο. Αλλά αν είστε νέοι στα τοπικά μοντέλα, θα ξεκινούσα με το LM Studio. Μπορείτε να εγκαταστήσετε οποιοδήποτε από τα δύο στην ενότητα _Install > AI_ στο Omarchy Menu.

### Το Omarchy Skill

Τα agent skills βοηθούν την τεχνητή νοημοσύνη να χρησιμοποιεί συγκεκριμένα εργαλεία με συγκεκριμένο τρόπο και το Omarchy παρέχεται με ένα προεπιλεγμένο skill για την προσαρμογή του συστήματος. Όπως η τροποποίηση του config του Hyprland σας, η προσαρμογή της μπάρας ή ακόμη και η δημιουργία ενός νέου θέματος από το μηδέν. Είναι συνδεδεμένο μέσω symlink στους καταλόγους skills για τα Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` και κάθε `~/.hermes/profiles/*/skills`) και τη γενική τοποθεσία `~/.agents/skills`, οπότε τα περισσότερα harnesses το εντοπίζουν αυτόματα.

Αλλά πρέπει να αντιμετωπίζετε αυτό το skill ως πειραματικό. Διαφορετικά μοντέλα θα το χρησιμοποιήσουν με διαφορετικό αποτέλεσμα. Είναι καλύτερο να το εκτελείτε πρώτα σε plan mode, ώστε να έχετε μια ιδέα για το τι θα ήθελε να αλλάξει ο agent. Και στη συνέχεια να είστε έτοιμοι να επαναφέρετε τις αλλαγές ή ακόμη και να καλέσετε την εντολή `omarchy reinstall configs`, αν ο agent τα κάνει όλα χάλια.
