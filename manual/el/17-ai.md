# AI

Το Omarchy αντιμετωπίζει τους AI coding agents ως πολίτες πρώτης κατηγορίας, αλλά δεν διαλέγει έναν αγαπημένο για εσένα. Αντίθετα, κάθε σημαντικό CLI coding-agent έρχεται προεγκατεστημένο ως εκκινητής με lazy φόρτωση. Οι εκκινητές είναι μικρά stubs που διαχειρίζεται το [mise](https://mise.jdx.dev/) στο `~/.local/bin/`, οπότε τίποτα δεν κατεβαίνει μέχρι την πρώτη φορά που θα εκτελέσεις πραγματικά κάποιον. Ο Hermes είναι η εξαίρεση: δεν υπάρχει κανένα stub γι' αυτόν, και αν τον επιλέξεις εγκαθίσταται το Hermes Desktop, όπως εξηγούν οι _Εφαρμογές desktop_ παρακάτω. Κάλσεσε οποιονδήποτε από αυτούς και κάνε ταυτοποίηση όταν σου ζητηθεί:

| Εντολή    | Agent                                                            |
|------------|------------------------------------------------------------------|
| `claude`   | [Claude Code](https://code.claude.com/docs/en/overview)          |
| `codex`    | [OpenAI Codex](https://github.com/openai/codex)                  |
| `opencode` | [OpenCode](https://opencode.ai/)                                 |
| `agy`      | [Google Antigravity CLI](https://github.com/google-antigravity/antigravity-cli) |
| `copilot`  | [GitHub Copilot CLI](https://github.com/github/copilot-cli)      |
| `crush`    | [Crush](https://github.com/charmbracelet/crush)                  |
| `grok`     | [Grok Build](https://x.ai/build) από την xAI                        |
| `kimi`     | [Kimi Code](https://www.kimi.com/code/docs/en/)                  |
| `pi`       | [Mario Zechner's Pi](https://github.com/badlogic/pi-mono)        |
| `omp`      | [Oh My Pi](https://github.com/can1357/oh-my-pi)                  |
| `ori`      | [Ori](https://openrouter.ai/docs/guides/ori/harness), το harness του OpenRouter |
| `hermes`   | [Hermes](https://hermes-agent.nousresearch.com/), ο agent της Nous Research  |
| `muse`     | [Muse Code](https://dev.meta.ai), ο coding agent της Meta           |
| `cursor-agent` | [Cursor CLI](https://cursor.com/cli)                         |

Το `ori` είναι το παράξενο της παρέας: εκτελεί τα άλλα harnesses ενάντια σε ολόκληρο τον κατάλογο μοντέλων του OpenRouter, οπότε τα `ori claude`, `ori codex` ή `ori opencode` ξεκινούν αυτούς τους agents σε όποιο μοντέλο τους υποδείξεις, και το `ori code` είναι ο δικός του agent του Ori.

Για να τυλίξεις ένα επιπλέον CLI με τον ίδιο τρόπο, εκτέλεσε `omarchy-mise-install <package> [command-name]`. Τα stubs διατηρούνται ενημερωμένα μαζί με όλα τα άλλα που διαχειρίζεται το mise όταν εκτελείς `omarchy update` (ή το alias `mup`).

Το `grok` εγκαθίσταται μέσω του πρώτου-μέρους πακέτου `grok` του mise, με τον ίδιο τρόπο όπως τα `claude` και `codex`. Εκτέλεσε `grok`, ή επίλεξέ το στο _Ρύθμιση > Προεπιλογές > Agent_. Παράλειψε τον εγκαταστάτη `curl | bash` στο x.ai. Αυτή η διαδρομή βάζει ένα δεύτερο αντίγραφο στο `~/.grok/bin`, το προσαρτά στην αρχή του `PATH`, και αντικαθιστά το wrapper του Omarchy.

### Ο προεπιλεγμένος agent

Επίλεξε τον προεπιλεγμένο agent σου με `omarchy default agent <name>` ή στο _Ρύθμιση > Προεπιλογές > Agent_ στο Μενού Omarchy (`Super + Space`). Αν ο agent δεν είναι εγκατεστημένος ακόμα, η επιλογή του τον εγκαθιστά πρώτα. Ένα φρέσκο Omarchy θα σε προσκαλέσει να κάνεις αυτή την επιλογή με μια εφάπαξ ειδοποίηση.

Η επιλογή του Claude προσπαθεί επίσης να ρυθμίσει την επέκταση προγράμματος περιήγησής του για Chromium, Chrome, Brave, Brave Origin και Edge. Η ρύθμιση της επέκτασης ισχύει για όλους τους χρήστες και μπορεί να ζητήσει τον κωδικό πρόσβασης του συστήματός σου· η ακύρωση ή μια αποτυχημένη εγκατάσταση επέκτασης εξακολουθεί να επιλέγει και να εκκινεί τον Claude. Επανεκκίνησε το πρόγραμμα περιήγησής σου, ενεργοποίησε την επέκταση αν σου ζητηθεί, και συνδέσου στον Claude για να ολοκληρώσεις τη σύνδεσή του. Εκτέλεσε `/chrome` στον Claude για να ελέγξεις τη σύνδεση. Τα Firefox και Zen δεν υποστηρίζουν αυτή την επέκταση. Αν ο Claude ήταν ήδη ο προεπιλεγμένος σου πριν προστεθεί αυτή η ρύθμιση, επίλεξέ τον ξανά για να εγκαταστήσεις την επέκταση.

Το [Muse Code](https://dev.meta.ai) — το `muse` της Meta — χρησιμοποιεί ένα προεγκατεστημένο mise stub όπως οι άλλοι agents. Η επιλογή του ως προεπιλεγμένου εγκαθιστά τον επίσημο εκκινητή της Meta μέσω του HTTP backend του mise. Ο εκκινητής επαληθεύει και ενημερώνει το εγγενές δυαδικό για το μηχάνημά σου.

Μόλις επιλέξεις, το `Super + Shift + Ctrl + A` εκκινεί τον προεπιλεγμένο agent σε ένα αποκλειστικό παράθυρο τερματικού (ή εμφανίζει τον επιλογέα αν δεν έχεις επιλέξει ακόμα). Μπορείς επίσης να τον εκκινήσεις κατευθείαν σε μια εργασία με `omarchy agent prompt "Review this project"`. Οι agents που εκκινούνται με αυτόν τον τρόπο εκτελούνται χωρίς επίβλεψη στις αντίστοιχες λειτουργίες «μην σταματάς να ρωτάς» τους, οπότε να είσαι έτοιμος να κάνουν πραγματικά πράγματα! Και επειδή οι agents αρνούνται να θυμούνται την εμπιστοσύνη για τον αρχικό κατάλογό σου, οι εκκινήσεις από το `$HOME` ξεκινούν στο `~/Work` αντίθετα.

Υπάρχουν και συντομεύσεις τερματικού: το `a` εκτελεί τον προεπιλεγμένο agent ενσωματωμένο στο τρέχον τερματικό, ενώ τα `c`, `cx` και `cy` ξεκινούν τα OpenCode, Claude Code και Codex απευθείας (ξανά στις λειτουργίες αυτόματης έγκρισής τους). Οι αλλαγές θέματος συγχρονίζονται και στους agents: τα Claude Code, Pi, OpenCode και Hermes (μόλις το Omarchy τον έχει εγκαταστήσει) ακολουθούν όλα όταν αλλάζεις το θέμα του Omarchy.

### Το πάνελ των agents

Η επάνω γραμμή έχει ένα εικονίδιο agents. Πριν ρυθμίσεις έναν agent, το πάνελ του σε καθοδηγεί να συνδεθείς σε Claude, Codex ή Grok, και ο πρώτος γίνεται ο προεπιλεγμένος agent σου. Μετά από αυτό, το πάνελ βάζει κάθε συνδρομή σε μία σελίδα: κάθε agent και λογαριασμό με το πλάνο του, έναν μετρητή για καθένα από τα όρια 5ωρης συνεδρίας και εβδομαδιαία όριά του με τον χρόνο μέχρι να επαναφερθεί (κράτα το ποντίκι από πάνω για το ακριβές ποσοστό), ή το υπόλοιπο προπληρωμένο υπόλοιπο, κάτω από μια γραμμή που εναλλάσσεται μέσα από όσα έχεις χρησιμοποιήσει σε όλους τους, όπως tokens αυτή την εβδομάδα και το πιο χρησιμοποιημένο μοντέλο σου. Στο _Φτιάξε κάτι_ προσφέρει αρχικά prompts για ένα νέο θέμα, plugin ή εφαρμογή που παραδίδουν την εργασία στον προεπιλεγμένο agent σου. Οι εφαρμογές κατασκευάζονται με τον τρόπο που κατασκευάζονται τα δικά του Omarchy Hype, Monologue και Omacut, σε C++ και Qt Quick, ακολουθώντας το omarchy-app agent skill, και ο compiler και τα κομμάτια Qt που χρειάζονται έρχονται εγκατεστημένα. Τα Claude Code, Codex, Grok, Fireworks και Kimi καλύπτονται από την αρχή. Το Kimi προς το παρόν αναφέρει όρια ποσοστώσεων λογαριασμού χωρίς τοπικά στατιστικά tokens ή prompts.

Κάνε αριστερό κλικ στο εικονίδιο της γραμμής για το πάνελ, δεξί κλικ για να εκκινήσεις τον προεπιλεγμένο agent σου. Τα αρχεία χρήσης πίσω από αυτό αναδημιουργούνται κάθε 15 λεπτά από το `omarchy agent usage-update`, και το πάνελ μπορεί ακόμη και να συγχωνεύσει χρήση από τα άλλα μηχανήματά σου μέσω ενός συγχρονισμένου φακέλου. Δες το README στο `$OMARCHY_PATH/shell/plugins/agents/` για όλες τις ρυθμίσεις.

### Πολλές συνδρομές

Αν πληρώνεις για περισσότερα από ένα πλάνα Claude, Codex ή Grok — ένα προσωπικό Max και ένα της δουλειάς, ας πούμε — το Omarchy μπορεί να τα κρατήσει όλα συνδεδεμένα και να μετακινείται ανάμεσά τους. Πρόσθεσε μια συνδρομή με το + στο πάνελ των agents, που σε καθοδηγεί ακριβώς εκεί, ή με `omarchy agent account add claude Work` (ή `codex`, ή `grok`). Εγκαθιστά το CLI αν λείπει. Ο πρώτος λογαριασμός για έναν πάροχο συνδέεται μέσω του κανονικού προγράμματος περιήγησής σου, ακριβώς εκεί που κοιτάζει πάντα το CLI. Κάθε επόμενος συνδέεται μέσω ενός ιδιωτικού παραθύρου, ώστε ο λογαριασμός στον οποίο το πρόγραμμα περιήγησής σου είναι ήδη συνδεδεμένο να μην επιλεγεί κατά λάθος· συνδέσου εκεί ως ο λογαριασμός που προσθέτεις, και κλείσε πρώτα όποιο ιδιωτικό παράθυρο είχες ήδη ανοιχτό. Μην αποσυνδέεσαι ποτέ από το CLI για να το κάνεις αυτό: η αποσύνδεση ανακαλεί την αποθηκευμένη σύνδεση, και αυτός ο λογαριασμός θα έπρεπε να προστεθεί ξανά.

Για να αντιγράψεις τις συνδέσεις των συνδρομών σου σε ένα άλλο μηχάνημα Omarchy μέσω SSH, εκτέλεσε `omarchy agent account copy user@laptop`. Ο αποστολέας παρέχει έναν προσωρινό παραλήπτη όταν ο προορισμός δεν έχει εγκατεστημένο κάποιον, οπότε παλαιότερα μηχανήματα Omarchy μπορούν να λαμβάνουν λογαριασμούς χωρίς ενημέρωση. Οι εγκατεστημένοι παραλήπτες έχουν προτεραιότητα. Αυτό αντιγράφει όλες τις συνδρομές Claude, Codex και Grok· πρόσθεσε ονόματα παρόχων για να τις επιλέξεις, όπως στο `omarchy agent account copy laptop claude`. Τα ονόματα λογαριασμών και τα αναγνωριστικά εντολών ταιριάζουν με την πηγή, συμπεριλαμβανομένων λογαριασμών που υπάρχουν ήδη στον προορισμό. Άσχετοι λογαριασμοί προορισμού λαμβάνουν ένα αριθμητικό επίθημα αν τα ονόματά τους συγκρούονται, και οι ρυθμίσεις, τα skills, τα plugins και το ιστορικό συνομιλιών παραμένουν τοπικά σε κάθε μηχάνημα.

Τα υπάρχοντα διαπιστευτήρια προορισμού διατηρούνται. Ένας λογαριασμός πηγής που είναι ήδη συνδεδεμένος εκεί έχει το όνομά του συγχρονισμένο χωρίς να αντικαθίστανται τα διαπιστευτήριά του· άλλοι λογαριασμοί προστίθενται δίπλα του. Για να αντικαταστήσεις αποθηκευμένα διαπιστευτήρια για λογαριασμούς που ταιριάζουν, χρησιμοποίησε `omarchy agent account copy --replace laptop claude` αφού κλείσεις τις συνεδρίες αυτού του λογαριασμού στον προορισμό. Ένας φρέσκος προορισμός παίρνει επίσης τον ενεργό λογαριασμό και τις προτιμήσεις εναλλαγής της πηγής· ένας εδραιωμένος προορισμός κρατά τις δικές του.

Τα διαπιστευτήρια ταξιδεύουν μέσω SSH και αποθηκεύονται σε ιδιωτικά αρχεία στον προορισμό, οπότε αντιγράφεις μόνο σε μηχανήματα που εμπιστεύεσαι. Αυτή είναι μια εφάπαξ αντιγραφή, όχι συνεχής συγχρονισμός. Τα Codex refresh tokens μπορούν να ανανεωθούν από άλλο μηχάνημα, αφήνοντας μια αντιγραμμένη σύνδεση να χρειάζεται ανανέωση· ξεχωριστές συνδέσεις παραμένουν η πιο αξιόπιστη επιλογή για ταυτόχρονη χρήση σε πολλά μηχανήματα. Δες τις [οδηγίες ταυτοποίησης λογαριασμού του Codex](https://developers.openai.com/codex/auth/ci-cd-auth).

Ένας λογαριασμός ανά πάροχο είναι ενεργός, και κάθε νέα συνεδρία ξεκινά ως αυτός: `cx`, `cy`, ένα απλό `claude`, `codex` ή `grok`, οτιδήποτε εκκινείται μέσω `omarchy agent`, και scripts ή επεξεργαστές που βρίσκουν το CLI στο `PATH`. Άλλαξε με `omarchy agent account use work` (και πίσω με `omarchy agent account use main`), ή στο πάνελ πατώντας τον αριθμό ενός λογαριασμού και μετά `Enter` (ή κάνοντας κλικ στο κουμπί Use του). Οι συνεδρίες που εκτελούνται ήδη παραμένουν στον λογαριασμό με τον οποίο ξεκίνησαν. Το ιστορικό συνομιλιών, οι ρυθμίσεις, τα skills και τα plugins μοιράζονται μεταξύ λογαριασμών, οπότε το `claude --continue` στον ίδιο φάκελο συνεχίζει από εκεί που σταμάτησες στον νέο λογαριασμό.

Με περισσότερους από έναν λογαριασμούς, το πάνελ δείχνει τα όρια κάθε λογαριασμού δίπλα-δίπλα, με τον ενεργό σημαδεμένο. Από προεπιλογή το Omarchy σε ειδοποιεί όταν ο ενεργός λογαριασμός ξεπερνά το 95% ενός ορίου, και το κλικ στην ειδοποίηση αλλάζει στον λογαριασμό με το μεγαλύτερο περιθώριο. Κράτα το ποντίκι πάνω από τη γραμμή ενός λογαριασμού στο πάνελ και κάνε κλικ στο Autoswitch που εμφανίζεται δίπλα στο Use (ή πάτα `m`), ή εκτέλεσε `omarchy agent account mode auto`, για να αλλάζει μόνο του αντίθετα· ενώ είναι ενεργό, το Autoswitch παίρνει τη θέση του Use, και κάνοντάς του κλικ ξανά επιστρέφει στην ειδοποίηση. Πρόσθεσε έναν αριθμό για να αλλάξεις το όριο, όπως στο `omarchy agent account mode auto 90`. Αν κάθε λογαριασμός είναι πάνω από το όριο, θα το μάθεις μία φορά, μαζί με το ποιος λογαριασμός ελευθερώνεται πρώτος. Όσο ένας ενεργός λογαριασμός βρίσκεται εντός 15 μονάδων από το όριό του (80% στην προεπιλογή), τα όριά του ελέγχονται κάθε τρία λεπτά αντί για κάθε 15.

Το `omarchy agent account list` δείχνει κάθε λογαριασμό και τα τελευταία όριά του, το `omarchy agent account remove work` ξεχνά έναν, και το `omarchy agent account rename primary Hey` μετονομάζει έναν (ή κάνε κλικ στο όνομα ενός λογαριασμού στο πάνελ). Αυτές οι εντολές λειτουργούν στους λογαριασμούς του προεπιλεγμένου agent σου· για να φτάσεις τον άλλο πάροχο, ονόμασέ τον πρώτα, όπως στο `omarchy agent account use codex side`. Η σύνδεση που είχες ήδη στο `~/.claude` ή `~/.codex` είναι ο λογαριασμός _Main_ και παραμένει εκεί που είναι. Ένας λογαριασμός που μένει αχρησιμοποίητος για περισσότερες από περίπου οκτώ ώρες μπορεί να δείξει _Απαιτείται σύνδεση_· κάνε του κλικ για να συνδεθείς ξανά σε αυτόν τον λογαριασμό ακριβώς στο πάνελ, ή ξεκίνα μια συνεδρία σε αυτόν, που ανανεώνει τη σύνδεση από μόνη της. Οι MCP servers που είχες όταν προστέθηκε ένας λογαριασμός έρχονται μαζί του, αλλά αυτοί που προσθέτεις αργότερα με `claude mcp add` φτάνουν μόνο στον λογαριασμό στον οποίο τους πρόσθεσες. Το Claude Desktop και εργαλεία ρυθμισμένα με απόλυτη διαδρομή προς ένα CLI δυαδικό δεν ακολουθούν την αλλαγή. Ένα ρητό `CLAUDE_CONFIG_DIR`, `CODEX_HOME` ή `GROK_HOME` έχει προτεραιότητα έναντι του επιλεγμένου λογαριασμού.

### Διάγνωση κρασαρισμάτων

Το Omarchy παρακολουθεί το systemd-coredump για κρασαρίσματα διεργασιών. Όταν κάτι κάνει segfault, θα λάβεις μια ειδοποίηση «Process crashed» — κάνε της κλικ, και το κρασάρισμα παραδίδεται στον προεπιλεγμένο agent σου μαζί με το diagnose-crash skill του Omarchy, που καθοδηγεί τον agent να διαπιστώσει τα γεγονότα από το core dump και να αποφασίσει αν το κρασάρισμα αξίζει να αναφερθεί upstream. Μπορείς επίσης να το εκτελέσεις με το χέρι ενάντια σε οποιοδήποτε PID από το `coredumpctl list` με `omarchy agent crash <pid>`.

Η παρακολούθηση είναι ενεργοποιημένη από προεπιλογή. Απενεργοποίησέ την στο _Trigger > Εναλλαγή > Καταγραφή κρασαρισμάτων_ (ή με `omarchy toggle crash-capture`) και οι ειδοποιήσεις σταματούν· το `omarchy agent crash <pid>` εξακολουθεί να λειτουργεί με το χέρι.

Τα κρασαρίσματα μπορούν επίσης να σιγαστούν ένα πρόγραμμα τη φορά, που είναι αυτό που σου προσφέρει η διάγνωση στο τέλος. Το `omarchy crash mute hyprland` σταματά τις ειδοποιήσεις μόνο για εκείνο το πρόγραμμα, το `omarchy crash mute hyprland off` τις επαναφέρει, και το `omarchy crash mute` από μόνο του παραθέτει όσα έχεις σιγάσει. Δέχεται τη διαδρομή του δυαδικού τόσο ευχάριστα όσο το όνομά του, οπότε το `omarchy crash mute /usr/bin/hyprland` κάνει το ίδιο πράγμα. Βάλε σε εισαγωγικά ένα όνομα με κενό, όπως στο `omarchy crash mute 'Some App'`. Όλα τα άλλα εξακολουθούν να ειδοποιούν, και το σιγασμένο πρόγραμμα εξακολουθεί να κρασάρει — αυτό κρύβει την υπενθύμιση, δεν διορθώνει τίποτα.

### Εφαρμογές desktop

Το μενού _Εγκατάσταση > AI_ φέρει επίσης μερικές γραφικές εφαρμογές AI: την εφαρμογή desktop του ChatGPT, την εφαρμογή desktop του Claude (η Linux beta της Anthropic, με καρτέλες Chat, Cowork και Claude Code), το Grok Bot για συνομιλία με τα μοντέλα της xAI, το Hermes Desktop, το OpenClaw και την εφαρμογή desktop του Perplexity. Το Grok Bot είναι η εφαρμογή συνομιλίας desktop. Ο coding agent είναι η εντολή `grok`.

Το Hermes Desktop είναι αυτό που πρέπει να ξέρεις, επειδή ένα μηχάνημα έχει έναν Hermes, και είναι της εφαρμογής: ο Hermes εγκαθίσταται πάντα και μόνο μέσω της εφαρμογής, και η εντολή `hermes` που εκτελεί ο προεπιλεγμένος agent είναι της εφαρμογής. Η επιλογή του Hermes ως προεπιλεγμένου agent εγκαθιστά το ίδιο πράγμα που κάνει η καταχώριση _Εγκατάσταση > AI_: το πακέτο, και ένα Hermes runtime στο `~/.hermes` που ρυθμίζεται από τον δικό του εγκαταστάτη του Hermes, που παίρνει λίγα λεπτά την πρώτη φορά. Αυτό το runtime είναι ο ένας Hermes που χρησιμοποιούν η εντολή τερματικού `hermes`, ο προεπιλεγμένος agent και η εφαρμογή, και ενημερώνεται μόνο του με `hermes update` αντί να περιμένει μια κυκλοφορία του Omarchy. Η εγκατάστασή του δίνει επίσης στον Hermes το θέμα του Omarchy ως ένα skin με όνομα `omarchy`, που ακολουθεί κάθε επιφάνεια του Hermes καθώς αλλάζεις θέματα· επίλεξε άλλο στις ρυθμίσεις Appearance του Hermes ή με `/skin` αν θα προτιμούσες να μην το κάνει, και το Omarchy αφήνει αυτή την επιλογή ήσυχη. Η αφαίρεση της εφαρμογής στο _Κατάργηση > AI_ κλείνει πρώτα τον Hermes, μαζί με το gateway, παίρνει εκείνο το runtime μαζί της, και κρατά τις συνομιλίες σου, τις μνήμες σου και τα skills που έγραψε ο Hermes για τον εαυτό του εκτός αν του πεις διαφορετικά: ρωτά, με προεπιλογή το όχι, αν αυτά τα δεδομένα και οι ρυθμίσεις σύνδεσής σου πρέπει να φύγουν επίσης.

Η εμπειρία desktop του OpenClaw είναι το Control UI του, που ανοίγει ως web app υποστηριζόμενο από το δικό του τοπικό gateway. Το OpenClaw ζει στο `~/.openclaw` και ενημερώνεται μόνο του: χρησιμοποίησε το κουμπί "Update Gateway" του Control UI ή εκτέλεσε `openclaw update`, και το gateway επανεκκινεί στη νέα έκδοση. Το Omarchy επιλέγει μόνο την κυκλοφορία από την οποία ξεκινά μια φρέσκια εγκατάσταση. Η αφαίρεση του OpenClaw στο _Κατάργηση > AI_ παίρνει την υπηρεσία gateway και την εφαρμογή μαζί της και μετά ρωτά αν το `~/.openclaw` πρέπει να φύγει επίσης, αφού αυτό κρατά τις συνομιλίες και τα διαπιστευτήριά σου δίπλα στο ίδιο το OpenClaw και τα plugin runtimes που κατεβάζει· η προεπιλογή το κρατά, και η εκ νέου εγκατάσταση του OpenClaw το ξανασηκώνει.

### Τοπικά LLMs

Το Omarchy συνιστά δύο τρόπους εκτέλεσης τοπικών μοντέλων LLM: LM Studio και Ollama. Το LM Studio παρέχει ένα GUI interface για εύρεση μοντέλων ανοιχτών βαρών, εγκατάστασή τους και εκτέλεσή τους. Είναι ένας εξαιρετικός τρόπος να ξεκινήσεις εύκολα. Το Ollama προσφέρει ένα CLI για να κάνεις το ίδιο παρόμοια. Αλλά αν είσαι νέος στα τοπικά μοντέλα, θα ξεκινούσα με το LM Studio. Μπορείς να εγκαταστήσεις οποιοδήποτε από τα δύο στο _Εγκατάσταση > AI_ στο Μενού Omarchy.

### Το Omarchy Skill

Τα agent skills βοηθούν το AI να χρησιμοποιεί συγκεκριμένα εργαλεία με συγκεκριμένο τρόπο, και το Omarchy έρχεται με ένα προεπιλεγμένο skill για προσαρμογή του συστήματος. Όπως να πειράζεις τη διαμόρφωση Hyprland σου, να προσαρμόζεις τη γραμμή, ή ακόμη και να δημιουργείς ένα νέο θέμα από την αρχή. Είναι symlinked στους καταλόγους skills για Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` και κάθε `~/.hermes/profiles/*/skills`), και τη γενική τοποθεσία `~/.agents/skills`, οπότε τα περισσότερα harnesses το μαζεύουν αυτόματα.

Αλλά θα πρέπει να αντιμετωπίζεις αυτό το skill ως πειραματικό. Διαφορετικά μοντέλα θα το χρησιμοποιήσουν με διαφορετικό αποτέλεσμα. Είναι καλύτερο να εκτελείς πρώτα σε λειτουργία σχεδίου, ώστε να έχεις μια ιδέα του τι θα ήθελε να αλλάξει ο agent. Και μετά να είσαι έτοιμος να επαναφέρεις αλλαγές ή ακόμη και να επικαλεστείς `omarchy reinstall configs`, αν ο agent τα κάνει όλα χάλια.
