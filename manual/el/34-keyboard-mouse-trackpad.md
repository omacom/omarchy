# Πληκτρολόγιο, Ποντίκι, Επιφάνεια Αφής

Το Hyprland σάς επιτρέπει να ρυθμίζετε όλες τις συσκευές εισόδου σας με μεγάλη λεπτομέρεια. Μπορείτε να κάνετε την επανάληψη του πληκτρολογίου υπερηχητικά γρήγορη ή να κάνετε την επιφάνεια αφής να χρησιμοποιεί φυσική κύλιση. Τα αλλάζετε όλα στο `~/.config/hypr/input.lua`, στο οποίο μπορείτε επίσης να φτάσετε μέσω του _Setup > Input_ στο μενού του Omarchy (`Super + Space`). Οτιδήποτε ορίσετε εκεί αντικαθιστά τις προεπιλογές του Omarchy.

Ορίστε ένα παράδειγμα:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Μπορείτε να [δείτε όλες τις επιλογές εισόδου](https://wiki.hypr.land/Configuring/Basics/Variables/#input) στο wiki του Hyprland για τις συσκευές εισόδου.

Το CapsLock λειτουργεί ως κανονικό Caps Lock, και το `Shift + CapsLock` είναι το πλήκτρο σύνθεσης για [γρήγορα emoji](07-hotkeys.md#quick-emojis) και [άλλες συμπληρώσεις](07-hotkeys.md#quick-completions). Αν προτιμάτε το πλήκτρο σύνθεσης να βρίσκεται αλλού, αντικαταστήστε το `omarchy:shift_caps_compose` στο `kb_options`. Για παράδειγμα, αυτό μετακινεί το πλήκτρο σύνθεσης στο Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Πλήκτρα λειτουργιών

Η επάνω σειρά ενός πληκτρολογίου φορητού υπολογιστή στέλνει από προεπιλογή τα πλήκτρα πολυμέσων (ένταση ήχου, φωτεινότητα και ούτω καθεξής), και κρατώντας πατημένο το `Fn` έχετε τα F1-F12· το `Fn + Esc` το κλειδώνει στην αντίθετη κατάσταση μέχρι να το πατήσετε ξανά. Τα περισσότερα πληκτρολόγια θυμούνται μόνα τους αυτό το κλείδωμα. Οι φορητοί υπολογιστές ASUS και τα πληκτρολόγια τύπου Apple το αφήνουν στο Linux, το οποίο τα ξεκινά με τα πλήκτρα πολυμέσων σε κάθε εκκίνηση. Για να ξεκινούν αντίθετα με τα F1-F12, εκτελέστε το `omarchy device keyboard toprow fnkeys` (και το `omarchy device keyboard toprow mediakeys` για να επιστρέψετε)· σε ορισμένους φορητούς υπολογιστές τίθεται σε ισχύ μετά από επανεκκίνηση. Τα Mac με Apple Silicon διατηρούν τη δική τους ρύθμιση.

### Χειρονομίες επιφάνειας αφής

Σύρετε στην επιφάνεια αφής για να μετακινείστε στην επιφάνεια εργασίας:

| Χειρονομία | Ενέργεια |
| --- | --- |
| Τρία δάχτυλα αριστερά / δεξιά | Προηγούμενος / επόμενος χώρος εργασίας, συμπεριλαμβανομένων των κενών |
| Τρία δάχτυλα επάνω | Εναλλαγή της κονσόλας AI |
| Τρία δάχτυλα κάτω | Άνοιγμα του μενού του Omarchy |
| Τέσσερα δάχτυλα αριστερά / δεξιά | Μετακίνηση του ενεργού παραθύρου στον προηγούμενο / επόμενο χώρο εργασίας |
| Τέσσερα δάχτυλα κάτω | Εναλλαγή πλήρους οθόνης |

Για να αλλάξετε μία, καταργήστε την στο `~/.config/hypr/input.lua` πριν προσθέσετε τη δική σας [χειρονομία επιφάνειας αφής](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), καθώς το Hyprland δεν θα δεχτεί δύο χειρονομίες με τα ίδια δάχτυλα και την ίδια κατεύθυνση:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Για να απενεργοποιήσετε όλες τις χειρονομίες του Omarchy, ορίστε `omarchy_default_gestures = false` κοντά στην κορυφή του `~/.config/hypr/hyprland.lua`, πριν φορτωθούν οι προεπιλογές του Omarchy.

Σε φορητούς υπολογιστές Dell XPS με απτική επιφάνεια αφής, μπορείτε επίσης να ορίσετε την ισχύ του κλικ σε χαμηλή, μεσαία ή υψηλή στο _Trigger > Hardware > Touchpad Haptics_.

### Πληκτρολόγηση στα Κινεζικά, τα Ιαπωνικά και άλλες γλώσσες

Επιλέξτε Ιαπωνικά, Κορεατικά, Κινεζικά (Απλοποιημένα, Pinyin), Ταϊβάν (Zhuyin) ή Χονγκ Κονγκ (Cangjie) όταν το πρόγραμμα εγκατάστασης σάς ρωτήσει για το πληκτρολόγιό σας. Το Omarchy ρυθμίζει αυτόματα το πληκτρολόγιο και την αντίστοιχη μηχανή εισόδου, συμπεριλαμβανομένης της ρύθμισης πρώτης εκκίνησης χωρίς σύνδεση. Τα Ιαπωνικά χρησιμοποιούν το Mozc, τα Κορεατικά χρησιμοποιούν την τυπική διάταξη Hangul δύο συνόλων, τα Απλοποιημένα Κινεζικά χρησιμοποιούν το Pinyin, η Ταϊβάν χρησιμοποιεί την τυπική διάταξη Zhuyin του Chewing και το Χονγκ Κονγκ χρησιμοποιεί το Cangjie με μορφές χαρακτήρων του Χονγκ Κονγκ. Τα Ιαπωνικά (πληκτρολόγιο US) παρέχουν το Mozc με διάταξη πληκτρολογίου US. Τα πλήκτρα Hangul, Zhuyin και Cangjie παραμένουν στις τυπικές θέσεις τους ακόμη και όταν πληκτρολογείτε λατινικούς χαρακτήρες με Dvorak, Colemak ή AZERTY. Αν είχατε προσθέσει το Hangul ή το Chewing πριν από αυτό, αποεπιλέξτε το και επιλέξτε το ξανά στο _Setup > Keyboard > Input Methods_ για να μετακινήσετε τα πλήκτρα του εκεί· το Omarchy αφήνει ήσυχη μια μηχανή με την οποία ήδη πληκτρολογείτε.

Η πληκτρολόγηση ξεκινά σε λειτουργία Λατινικών. Πατήστε `Super + I` για να περιηγηθείτε κυκλικά στις ρυθμισμένες μεθόδους εισόδου, και `Super + Shift + I` για να περιηγηθείτε κυκλικά προς τα πίσω. Πατήστε το `Shift` μόνο του για να βγείτε από μια μέθοδο εισόδου όπως το Pinyin και να περάσετε σε λατινικούς χαρακτήρες, και πατήστε το ξανά για να επιστρέψετε, όπως λειτουργούν τα Sogou, Microsoft Pinyin και macOS· το `Shift` μαζί με ένα γράμμα εξακολουθεί να πληκτρολογεί κεφαλαίο. Στα ιαπωνικά πληκτρολόγια, το 全角/半角 εναλλάσσει την είσοδο, το 変換 την ενεργοποιεί και το 無変換 την απενεργοποιεί. Με τα Κορεατικά, το 한/영 εναλλάσσει το Hangul και το 한자 μετατρέπει σε Hanja, είτε το πληκτρολόγιό σας έχει αποκλειστικά πλήκτρα είτε στέλνει Right Alt και Right Ctrl για αυτά, όπως κάνουν πολλοί φορητοί υπολογιστές, οπότε τα Right Alt και Right Ctrl δεν είναι απλοί τροποποιητές εκεί· η υπαγόρευση εναλλάσσεται με Alt + Space αντί για αυτό. Το `Ctrl + Space` παραμένει διαθέσιμο για τα Tmux και Herdr· το `Shift + CapsLock` παραμένει το πλήκτρο σύνθεσης.

Η ένδειξη πληκτρολογίου εμφανίζεται στα δεξιά της γραμμής όταν έχετε πολλαπλές διατάξεις πληκτρολογίου ή μεθόδους εισόδου. Κάντε κλικ σε αυτήν για να αλλάξετε γλώσσες εισόδου· τα Ιαπωνικά εμφανίζουν το あ για τα hiragana. Για επιλογές ιαπωνικών χαρακτήρων, μεταβείτε στα Ιαπωνικά, πληκτρολογήστε μια λέξη όπως `nihongo` και μετά πατήστε Space δύο φορές. Πατήστε Enter για να αποδεχτείτε την επιλογή σας. Αν έχετε επίσης πολλαπλές διατάξεις πληκτρολογίου, κάντε δεξί κλικ στην ένδειξη για να περιηγηθείτε κυκλικά σε αυτές.

Χρησιμοποιήστε το _Setup > Keyboard > Keyboard Inputs_ για να επιλέξετε διατάξεις όπως Αγγλικά και Γαλλικά, από τις ίδιες επιλογές που προσφέρονται κατά την εγκατάσταση. Χρησιμοποιήστε το _Setup > Keyboard > Input Methods_ για να επιλέξετε ποιες μηχανές σύνθεσης είναι ενεργές. Και οι δύο επιλογείς ανοίγουν μέσα στο μενού του Omarchy με τις τρέχουσες επιλογές σας επιλεγμένες. Κάντε κλικ ή πατήστε Enter για να εναλλάξετε μια επιλογή· κάθε αλλαγή εφαρμόζεται αμέσως. Η αποεπιλογή μιας μεθόδου εισόδου την αφαιρεί από τον κύκλο χωρίς να την απεγκαθιστά· το πληκτρολόγιο παραμένει διαθέσιμο.

Εκτελέστε το `omarchy setup keyboard` ή το `omarchy setup input` για να ανοίξετε τους ίδιους επιλογείς. Για να προσθέσετε μία γλώσσα από τη γραμμή εντολών, χρησιμοποιήστε τα `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` ή `cangjie5`. Τα Quick, Boshiamy και Array έρχονται στο ίδιο πακέτο με το Cangjie και εμφανίζονται στον επιλογέα Input Methods. Τα προσαρμοσμένα πλήκτρα εναλλαγής σας διατηρούνται. Για εναλλακτικές διατάξεις ή πλήκτρα μηχανών, εγκαταστήστε το `fcitx5-configtool` με το `omarchy pkg add fcitx5-configtool` και εκκινήστε το από ένα τερματικό. Η επιλογή μιας γλώσσας εισόδου δεν αλλάζει τη γλώσσα της επιφάνειας εργασίας. Η επιλογή Ιαπωνικών, Κορεατικών ή Κινεζικών στο _Setup > Region > Language_ προσθέτει τη μέθοδο εισόδου τους όταν δεν έχετε ακόμη καμία.

Χρησιμοποιήστε το `Super + I` για να περιηγηθείτε κυκλικά στις μεθόδους εισόδου ή τις διατάξεις πληκτρολογίου, και το `Super + Shift + I` για να πάτε πίσω προς την άλλη κατεύθυνση, ώστε με τρεις ρυθμισμένες να μπορείτε να μετακινείστε ανάμεσα σε δύο γειτονικές. Η ένδειξη εισόδου εμφανίζεται στα δεξιά της γραμμής μόνο όταν έχει ρυθμιστεί περισσότερη από μία μέθοδος εισόδου ή διάταξη. Αυτή η δέσμευση επιφάνειας εργασίας λειτουργεί μαζί με τα υπάρχοντα πλήκτρα εναλλαγής Fcitx σας· μπορείτε να την παρακάμψετε στο `~/.config/hypr/bindings.lua`. Οι μηχανές εισόδου και οι ακολουθίες σύνθεσης χρησιμοποιούν την υπηρεσία [Fcitx5](https://fcitx-im.org/) που ήδη εκτελείται σε κάθε συνεδρία.

### Χρήση του ALT ως SUPER

Σε ορισμένα πληκτρολόγια, δεν είναι βολικό να χρησιμοποιείτε το κύριο πλήκτρο meta (πλήκτρο Windows/cmd) ως SUPER. Μπορείτε να το αλλάξετε ώστε να είναι το ALT αντί αυτού χρησιμοποιώντας αυτήν την αλλαγή:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
