# Πληκτρολόγιο, ποντίκι, επιφάνεια αφής

Το Hyprland σας επιτρέπει να διαμορφώσετε όλες τις εισόδους σας με μεγάλη λεπτομέρεια. Μπορείτε να αλλάξετε την επανάληψη του πληκτρολογίου ώστε να είναι υπερηχητικά γρήγορη ή να κάνετε την επιφάνεια αφής να χρησιμοποιεί φυσική κύλιση. Τα αλλάζετε όλα στο `~/.config/hypr/input.lua`, στο οποίο μπορείτε επίσης να φτάσετε μέσω του _Ρύθμιση > Input_ στο μενού του Omarchy (`Super + Space`). Ό,τι ορίσετε εκεί αντικαθιστά τις προεπιλογές του Omarchy.

Εδώ είναι ένα παράδειγμα:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Μπορείτε να [δείτε όλες τις επιλογές εισόδου](https://wiki.hypr.land/Configuring/Basics/Variables/#input) στο wiki του Hyprland για τις εισόδους.

Το CapsLock λειτουργεί ως κανονικό Caps Lock, και το `Shift + CapsLock` είναι το πλήκτρο σύνθεσης για [γρήγορα emoji](07-hotkeys.md#quick-emojis) και [άλλες συμπληρώσεις](07-hotkeys.md#quick-completions). Αν θα προτιμούσατε το πλήκτρο σύνθεσης αλλού, αντικαταστήστε το `omarchy:shift_caps_compose` στο `kb_options`. Για παράδειγμα, αυτό μετακινεί το πλήκτρο σύνθεσης στο Δεξί Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Κινήσεις επιφάνειας αφής

Μπορείτε επίσης να ενεργοποιήσετε [χειρονομίες επιφάνειας αφής](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), όπως το σύρσιμο με τρία δάχτυλα για αλλαγή χώρων εργασίας:

```lua
hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })
```

Σε φορητούς υπολογιστές Dell XPS με απτική επιφάνεια αφής, μπορείτε επίσης να ορίσετε την ένταση του κλικ σε χαμηλή, μεσαία ή υψηλή κάτω από το _Ενεργοποίηση > Hardware > Touchpad Haptics_.

### Πληκτρολόγηση σε κινέζικα, ιαπωνικά και άλλες γλώσσες

Επιλέξτε ιαπωνικά, κορεατικά, κινέζικα (απλοποιημένα, Pinyin) ή κινέζικα (παραδοσιακά, Zhuyin) όταν ο εγκαταστάτης σας ρωτήσει για το πληκτρολόγιό σας. Το Omarchy διαμορφώνει αυτόματα το πληκτρολόγιο και τη σύνθεση εισόδου που ταιριάζει, συμπεριλαμβανομένης της ρύθμισης πρώτης εκκίνησης εκτός σύνδεσης. Τα ιαπωνικά χρησιμοποιούν το Mozc, τα κορεατικά χρησιμοποιούν το τυπικό Hangul δύο συνόλων, τα απλοποιημένα κινέζικα χρησιμοποιούν το Pinyin και τα παραδοσιακά κινέζικα χρησιμοποιούν την τυπική διάταξη Zhuyin του Chewing. Τα ιαπωνικά (πληκτρολόγιο ΗΠΑ) παρέχουν το Mozc με διάταξη πληκτρολογίου ΗΠΑ.

Η πληκτρολόγηση ξεκινά σε λειτουργία Latin. Πατήστε `Super + I` για να περιηγηθείτε μέσα στις διαμορφωμένες μεθόδους εισαγωγής και `Super + Shift + I` για να περιηγηθείτε πίσω. Αγγίξτε το `Shift` μόνο του για να βγείτε από μια μέθοδο εισαγωγής όπως το Pinyin στα λατινικά γράμματα, και αγγίξτε το ξανά για να επιστρέψετε, με τον τρόπο που λειτουργούν τα Sogou, Microsoft Pinyin και macOS· το `Shift` και ένα γράμμα εξακολουθεί να πληκτρολογεί ένα κεφαλαίο. Στα ιαπωνικά πληκτρολόγια, το 全角/半角 εναλλάσσει την είσοδο, το 変換 την ενεργοποιεί και το 無変換 την απενεργοποιεί. Σε μια διάταξη κορεατικού πληκτρολογίου, τα αποκλειστικά πλήκτρα 한/영 και 한자 εναλλάσσουν το Hangul και μετατρέπουν σε Hanja. Το `Ctrl + Space` παραμένει διαθέσιμο για Tmux και Herdr· το `Shift + CapsLock` παραμένει το πλήκτρο σύνθεσης.

Ο δείκτης πληκτρολογίου εμφανίζεται δεξιά στη γραμμή όταν έχετε πολλαπλές διατάξεις πληκτρολογίου ή μεθόδους εισαγωγής. Κάντε κλικ σε αυτόν για να εναλλάξετε γλώσσες εισαγωγής· τα ιαπωνικά εμφανίζουν あ για τα hiragana. Για επιλογές ιαπωνικών χαρακτήρων, μεταβείτε στα ιαπωνικά, πληκτρολογήστε μια λέξη όπως `nihongo`, και στη συνέχεια πατήστε το Space δύο φορές. Πατήστε το Enter για να δεχτείτε την επιλογή σας. Αν έχετε επίσης πολλαπλές διατάξεις πληκτρολογίου, κάντε δεξί κλικ στον δείκτη για να περιηγηθείτε σε αυτές.

Χρησιμοποιήστε το _Ρύθμιση > Typing > Keyboard Layouts_ για να επιλέξετε διατάξεις όπως τα αγγλικά και τα γαλλικά, από τις ίδιες επιλογές που προσφέρονται κατά την εγκατάσταση. Χρησιμοποιήστε το _Ρύθμιση > Typing > Input Methods_ για να επιλέξετε ποιοι μηχανισμοί σύνθεσης είναι ενεργοί. Και οι δύο επιλογείς ανοίγουν μέσα στο μενού του Omarchy με τις τρέχουσες επιλογές σας σημειωμένες. Κάντε κλικ ή πατήστε το Enter για να εναλλάξετε μια επιλογή· κάθε αλλαγή ισχύει αμέσως. Η αποεπιλογή μιας μεθόδου εισαγωγής την αφαιρεί από τον κύκλο χωρίς να την απεγκαθιστά· το πληκτρολόγιο παραμένει διαθέσιμο.

Εκτελέστε `omarchy setup keyboard` ή `omarchy setup input` για να ανοίξετε τους ίδιους επιλογείς. Για να προσθέσετε μία γλώσσα από τη γραμμή εντολών, χρησιμοποιήστε τα `omarchy setup input mozc`, `hangul`, `pinyin` ή `chewing`. Τα προσαρμοσμένα πλήκτρα εναλλαγής σας διατηρούνται. Για εναλλακτικές διατάξεις ή πλήκτρα μηχανισμών, εγκαταστήστε το `fcitx5-configtool` με το `omarchy pkg add fcitx5-configtool` και εκκινήστε το από ένα τερματικό. Η επιλογή μιας γλώσσας εισαγωγής δεν αλλάζει τη γλώσσα της επιφάνειας εργασίας.

Χρησιμοποιήστε το `Super + I` για να περιηγηθείτε μέσα σε μεθόδους εισαγωγής ή διατάξεις πληκτρολογίου, και το `Super + Shift + I` για να πάτε προς την άλλη κατεύθυνση, οπότε με τρεις διαμορφωμένες μπορείτε να κινηθείτε μεταξύ δύο γειτόνων. Ο δείκτης εισαγωγής εμφανίζεται δεξιά στη γραμμή μόνο όταν είναι διαμορφωμένες περισσότερες από μία μέθοδος εισαγωγής ή διάταξη. Αυτή η δέσμευση επιφάνειας εργασίας λειτουργεί παράλληλα με τα υπάρχοντα πλήκτρα εναλλαγής του Fcitx σας· μπορείτε να την παρακάμψετε στο `~/.config/hypr/bindings.lua`. Οι μηχανισμοί εισαγωγής και οι ακολουθίες σύνθεσης χρησιμοποιούν την υπηρεσία [Fcitx5](https://fcitx-im.org/) που ήδη τρέχει σε κάθε συνεδρία.

### Χρήση του ALT ως SUPER

Σε κάποια πληκτρολόγια, δεν είναι βολικό να χρησιμοποιείτε το κύριο πλήκτρο meta (πλήκτρο Windows/cmd) ως το SUPER. Μπορείτε να αλλάξετε αυτό ώστε να είναι αντί αυτού το ALT χρησιμοποιώντας αυτή την αλλαγή:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
