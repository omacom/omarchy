# Πληκτρολόγιο, Ποντίκι, Trackpad

Το Hyprland σου επιτρέπει να ρυθμίσεις όλες τις εισόδους σου με μεγάλη λεπτομέρεια. Μπορείς να κάνεις την επανάληψη πληκτρολογίου υπερηχητικά γρήγορη ή να βάλεις το trackpad να χρησιμοποιεί φυσική κύλιση. Όλα αυτά τα αλλάζεις στο `~/.config/hypr/input.lua`, στο οποίο μπορείς επίσης να φτάσεις μέσω του _Ρύθμιση > Είσοδος_ στο μενού του Omarchy (`Super + Space`). Οτιδήποτε ορίσεις εκεί αντικαθιστά τις προεπιλογές του Omarchy.

Να ένα παράδειγμα:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Μπορείς να [δεις όλες τις επιλογές εισόδου](https://wiki.hypr.land/Configuring/Basics/Variables/#input) στο wiki του Hyprland για τις εισόδους.

Το CapsLock λειτουργεί ως κανονικό Caps Lock και το `Shift + CapsLock` είναι το πλήκτρο σύνθεσης για [γρήγορα emoji](07-hotkeys.md#quick-emojis) και [άλλες συμπληρώσεις](07-hotkeys.md#quick-completions). Αν προτιμάς το πλήκτρο σύνθεσης αλλού, αντικατάστησε το `omarchy:shift_caps_compose` στο `kb_options`. Για παράδειγμα, αυτό μετακινεί το πλήκτρο σύνθεσης στο Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Πλήκτρα λειτουργιών

Η επάνω σειρά ενός πληκτρολογίου φορητού υπολογιστή στέλνει από προεπιλογή τα πλήκτρα πολυμέσων (ένταση, φωτεινότητα κ.λπ.) και κρατώντας πατημένο το `Fn` παίρνεις τα F1-F12· το `Fn + Esc` το κλειδώνει αντίστροφα μέχρι να το πατήσεις ξανά. Τα περισσότερα πληκτρολόγια θυμούνται μόνα τους αυτό το κλείδωμα. Οι φορητοί υπολογιστές ASUS και τα πληκτρολόγια τύπου Apple το αφήνουν στο Linux, το οποίο τα ξεκινά με τα πλήκτρα πολυμέσων σε κάθε εκκίνηση. Για να ξεκινούν αντίθετα με τα F1-F12, εκτέλεσε `omarchy device keyboard toprow fnkeys` (και `omarchy device keyboard toprow mediakeys` για να επιστρέψεις)· σε ορισμένους φορητούς υπολογιστές τίθεται σε ισχύ μετά από επανεκκίνηση. Τα Mac με Apple Silicon διατηρούν τη δική τους ρύθμιση.

### Χειρονομίες στο trackpad

Σύρε στο trackpad για να περιηγηθείς στην επιφάνεια εργασίας:

| Χειρονομία | Ενέργεια |
| --- | --- |
| Τρία δάχτυλα αριστερά / δεξιά | Προηγούμενος / επόμενος χώρος εργασίας, συμπεριλαμβανομένων των κενών |
| Τρία δάχτυλα πάνω | Εναλλαγή της κονσόλας AI |
| Τρία δάχτυλα κάτω | Άνοιγμα του μενού Omarchy |
| Τέσσερα δάχτυλα αριστερά / δεξιά | Μετακίνηση του ενεργού παραθύρου στον προηγούμενο / επόμενο χώρο εργασίας |
| Τέσσερα δάχτυλα κάτω | Εναλλαγή πλήρους οθόνης |

Για να αλλάξεις μία, κατάργησέ την στο `~/.config/hypr/input.lua` πριν προσθέσεις τη δική σου [χειρονομία touchpad](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), επειδή το Hyprland δεν δέχεται δύο χειρονομίες με τα ίδια δάχτυλα και την ίδια κατεύθυνση:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Για να απενεργοποιήσεις όλες τις χειρονομίες του Omarchy, όρισε `omarchy_default_gestures = false` κοντά στην κορυφή του `~/.config/hypr/hyprland.lua`, πριν φορτωθούν οι προεπιλογές του Omarchy.

Σε φορητούς υπολογιστές Dell XPS με απτικό touchpad, μπορείς επίσης να ρυθμίσεις την ισχύ του κλικ σε χαμηλή, μεσαία ή υψηλή στο _Έναυσμα > Υλικό > Απτικά Touchpad_.

### Πληκτρολόγηση στα Κινεζικά, Ιαπωνικά και άλλες γλώσσες

Επίλεξε Ιαπωνικά, Κορεατικά, Κινεζικά (Απλοποιημένα, Pinyin), Ταϊβάν (Zhuyin) ή Χονγκ Κονγκ (Cangjie) όταν το πρόγραμμα εγκατάστασης σου ζητήσει το πληκτρολόγιό σου. Το Omarchy ρυθμίζει αυτόματα το πληκτρολόγιο και την αντίστοιχη μηχανή εισαγωγής, συμπεριλαμβανομένης της ρύθμισης πρώτης εκκίνησης εκτός σύνδεσης. Τα Ιαπωνικά χρησιμοποιούν το Mozc, τα Κορεατικά χρησιμοποιούν το τυπικό Hangul δύο συνόλων, τα Απλοποιημένα Κινεζικά χρησιμοποιούν το Pinyin, η Ταϊβάν χρησιμοποιεί την τυπική διάταξη Zhuyin του Chewing και το Χονγκ Κονγκ χρησιμοποιεί το Cangjie με μορφές χαρακτήρων του Χονγκ Κονγκ. Η επιλογή Ιαπωνικά (πληκτρολόγιο US) παρέχει το Mozc με διάταξη πληκτρολογίου US. Τα πλήκτρα Hangul, Zhuyin και Cangjie παραμένουν στις τυπικές τους θέσεις ακόμη και όταν πληκτρολογείς λατινικά γράμματα με Dvorak, Colemak ή AZERTY. Αν είχες προσθέσει το Hangul ή το Chewing πριν από αυτό, αποεπίλεξέ το και επίλεξέ το ξανά στο _Ρύθμιση > Πληκτρολόγιο > Μέθοδοι Εισαγωγής_ για να μετακινηθούν τα πλήκτρα του εκεί· το Omarchy αφήνει ήσυχη μια μηχανή με την οποία ήδη πληκτρολογείς.

Η πληκτρολόγηση ξεκινά σε λατινική λειτουργία. Πάτα `Super + I` για να περιηγηθείς κυκλικά στις ρυθμισμένες μεθόδους εισαγωγής και `Super + Shift + I` για να περιηγηθείς κυκλικά προς τα πίσω. Πάτα το `Shift` μόνο του για να βγεις από μια μέθοδο εισαγωγής όπως το Pinyin στα λατινικά γράμματα και πάτα το ξανά για να επιστρέψεις, όπως λειτουργούν τα Sogou, Microsoft Pinyin και macOS· το `Shift` μαζί με ένα γράμμα εξακολουθεί να πληκτρολογεί κεφαλαίο. Στα ιαπωνικά πληκτρολόγια, το 全角/半角 εναλλάσσει την εισαγωγή, το 変換 την ενεργοποιεί και το 無変換 την απενεργοποιεί. Με τα Κορεατικά, το 한/영 εναλλάσσει το Hangul και το 한자 μετατρέπει σε Hanja, είτε το πληκτρολόγιό σου έχει αποκλειστικά πλήκτρα είτε στέλνει Right Alt και Right Ctrl για αυτά, όπως κάνουν πολλοί φορητοί υπολογιστές, οπότε τα Right Alt και Right Ctrl δεν είναι απλοί τροποποιητές εκεί· η υπαγόρευση εναλλάσσεται με Alt + Space αντί για αυτό. Το `Ctrl + Space` παραμένει διαθέσιμο για τα Tmux και Herdr· το `Shift + CapsLock` παραμένει το πλήκτρο σύνθεσης.

Η ένδειξη πληκτρολογίου εμφανίζεται στα δεξιά της γραμμής όταν έχεις πολλαπλές διατάξεις πληκτρολογίου ή μεθόδους εισαγωγής. Κάνε κλικ σε αυτήν για να αλλάξεις γλώσσες εισαγωγής· τα Ιαπωνικά εμφανίζουν あ για τα hiragana. Για επιλογές ιαπωνικών χαρακτήρων, μετάβα στα Ιαπωνικά, πληκτρολόγησε μια λέξη όπως `nihongo` και μετά πάτα το Space δύο φορές. Πάτα Enter για να αποδεχτείς την επιλογή σου. Αν έχεις επίσης πολλαπλές διατάξεις πληκτρολογίου, κάνε δεξί κλικ στην ένδειξη για να περιηγηθείς κυκλικά σε αυτές.

Χρησιμοποίησε το _Ρύθμιση > Πληκτρολόγιο > Είσοδοι Πληκτρολογίου_ για να επιλέξεις διατάξεις όπως Αγγλικά και Γαλλικά, από τις ίδιες επιλογές που προσφέρονται κατά την εγκατάσταση. Χρησιμοποίησε το _Ρύθμιση > Πληκτρολόγιο > Μέθοδοι Εισαγωγής_ για να επιλέξεις ποιες μηχανές σύνθεσης είναι ενεργές. Και τα δύο εργαλεία επιλογής ανοίγουν μέσα στο μενού του Omarchy με τις τρέχουσες επιλογές σου επισημασμένες. Κάνε κλικ ή πάτα Enter για να εναλλάξεις μια επιλογή· κάθε αλλαγή εφαρμόζεται αμέσως. Η αποεπιλογή μιας μεθόδου εισαγωγής την αφαιρεί από τον κύκλο χωρίς να την απεγκαθιστά· το πληκτρολόγιο παραμένει διαθέσιμο.

Εκτέλεσε `omarchy setup keyboard` ή `omarchy setup input` για να ανοίξεις τα ίδια εργαλεία επιλογής. Για να προσθέσεις μία γλώσσα από τη γραμμή εντολών, χρησιμοποίησε `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` ή `cangjie5`. Τα Quick, Boshiamy και Array έρχονται στο ίδιο πακέτο με το Cangjie και εμφανίζονται στο εργαλείο επιλογής μεθόδων εισαγωγής. Τα προσαρμοσμένα πλήκτρα εναλλαγής σου διατηρούνται. Για εναλλακτικές διατάξεις ή πλήκτρα μηχανής, εγκατάστησε το `fcitx5-configtool` με `omarchy pkg add fcitx5-configtool` και εκκίνησέ το από ένα τερματικό. Η επιλογή μιας γλώσσας εισαγωγής δεν αλλάζει τη γλώσσα της επιφάνειας εργασίας. Η επιλογή Ιαπωνικών, Κορεατικών ή Κινεζικών στο _Ρύθμιση > Γλώσσα_ προσθέτει τη μέθοδο εισαγωγής τους όταν δεν έχεις ακόμη καμία.

Χρησιμοποίησε το `Super + I` για να περιηγηθείς κυκλικά στις μεθόδους εισαγωγής ή τις διατάξεις πληκτρολογίου και το `Super + Shift + I` για να πας προς την αντίθετη κατεύθυνση, ώστε με τρεις ρυθμισμένες να μπορείς να μετακινείσαι ανάμεσα σε δύο γειτονικές. Η ένδειξη εισαγωγής εμφανίζεται στα δεξιά της γραμμής μόνο όταν έχει ρυθμιστεί περισσότερη από μία μέθοδος εισαγωγής ή διάταξη. Αυτή η δέσμευση επιφάνειας εργασίας λειτουργεί μαζί με τα υπάρχοντα πλήκτρα εναλλαγής Fcitx· μπορείς να την παρακάμψεις στο `~/.config/hypr/bindings.lua`. Οι μηχανές εισαγωγής και οι ακολουθίες σύνθεσης χρησιμοποιούν την υπηρεσία [Fcitx5](https://fcitx-im.org/) που ήδη εκτελείται σε κάθε συνεδρία.

### Χρήση του ALT ως SUPER

Σε ορισμένα πληκτρολόγια, δεν είναι βολικό να χρησιμοποιείς το κύριο πλήκτρο meta (πλήκτρο Windows/cmd) ως SUPER. Μπορείς να το αλλάξεις ώστε να είναι το ALT αντί αυτού χρησιμοποιώντας αυτή την αλλαγή:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
