# Πληκτρολόγιο, Ποντίκι, Επιφάνεια Αφής

Το Hyprland σάς επιτρέπει να διαμορφώνετε όλες τις εισόδους σας με μεγάλη λεπτομέρεια. Μπορείτε να κάνετε την επανάληψη του πληκτρολογίου υπερηχητικά γρήγορη ή να κάνετε την επιφάνεια αφής να χρησιμοποιεί φυσική κύλιση. Τα αλλάζετε όλα στο `~/.config/hypr/input.lua`, στο οποίο μπορείτε επίσης να φτάσετε μέσω του _Setup > Input_ στο μενού του Omarchy (`Super + Space`). Οτιδήποτε ορίσετε εκεί αντικαθιστά τις προεπιλογές του Omarchy.

Ιδού ένα παράδειγμα:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Μπορείτε να [δείτε όλες τις επιλογές εισόδου](https://wiki.hypr.land/Configuring/Basics/Variables/#input) στο wiki του Hyprland για τις εισόδους.

Το CapsLock λειτουργεί ως κανονικό Caps Lock και το `Shift + CapsLock` είναι το πλήκτρο σύνθεσης για [γρήγορα emoji](07-hotkeys.md#quick-emojis) και [άλλες συμπληρώσεις](07-hotkeys.md#quick-completions). Αν προτιμάτε το πλήκτρο σύνθεσης αλλού, αντικαταστήστε το `omarchy:shift_caps_compose` στο `kb_options`. Για παράδειγμα, αυτό μετακινεί το πλήκτρο σύνθεσης στο Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Χειρονομίες επιφάνειας αφής

Σύρετε στην επιφάνεια αφής για να μετακινηθείτε στην επιφάνεια εργασίας:

| Gesture | Action |
| --- | --- |
| Three fingers left / right | Previous / next workspace, including empty ones |
| Three fingers up | Toggle the AI console |
| Three fingers down | Open the Omarchy menu |
| Four fingers left / right | Move the active window to the previous / next workspace |
| Four fingers down | Toggle fullscreen |

Για να αλλάξετε μία, καταργήστε την στο `~/.config/hypr/input.lua` πριν προσθέσετε τη δική σας [χειρονομία επιφάνειας αφής](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), αφού το Hyprland δεν δέχεται δύο χειρονομίες με τα ίδια δάχτυλα και την ίδια κατεύθυνση:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Για να απενεργοποιήσετε όλες τις χειρονομίες του Omarchy, ορίστε `omarchy_default_gestures = false` κοντά στην κορυφή του `~/.config/hypr/hyprland.lua`, πριν φορτωθούν οι προεπιλογές του Omarchy.

Σε φορητούς υπολογιστές Dell XPS με απτική επιφάνεια αφής, μπορείτε επίσης να ορίσετε την ισχύ κλικ σε χαμηλή, μεσαία ή υψηλή στο _Trigger > Hardware > Touchpad Haptics_.

### Πληκτρολόγηση στα Κινεζικά, Ιαπωνικά και άλλες γλώσσες

Επιλέξτε Ιαπωνικά, Κορεατικά, Κινεζικά (Απλοποιημένα, Pinyin), Ταϊβάν (Zhuyin) ή Χονγκ Κονγκ (Cangjie) όταν το πρόγραμμα εγκατάστασης σάς ρωτήσει για το πληκτρολόγιό σας. Το Omarchy διαμορφώνει αυτόματα το πληκτρολόγιο και την αντίστοιχη μηχανή εισόδου, μεταξύ άλλων και κατά την αρχική ρύθμιση πρώτης εκκίνησης εκτός σύνδεσης. Τα Ιαπωνικά χρησιμοποιούν Mozc, τα Κορεατικά χρησιμοποιούν το τυπικό Hangul δύο συνόλων, τα Απλοποιημένα Κινεζικά χρησιμοποιούν Pinyin, η Ταϊβάν χρησιμοποιεί την τυπική διάταξη Zhuyin του Chewing και το Χονγκ Κονγκ χρησιμοποιεί Cangjie με μορφές χαρακτήρων του Χονγκ Κονγκ. Τα Ιαπωνικά (πληκτρολόγιο US) παρέχουν Mozc με διάταξη πληκτρολογίου US. Τα πλήκτρα Hangul, Zhuyin και Cangjie παραμένουν στις τυπικές θέσεις τους ακόμη και όταν πληκτρολογείτε λατινικά γράμματα με Dvorak, Colemak ή AZERTY. Αν προσθέσατε Hangul ή Chewing πριν από αυτό, αποεπιλέξτε το και επιλέξτε το ξανά στο _Setup > Typing > Input Methods_ για να μετακινηθούν τα πλήκτρα του εκεί· το Omarchy αφήνει ήσυχη μια μηχανή με την οποία ήδη πληκτρολογείτε.

Η πληκτρολόγηση ξεκινά σε λατινική λειτουργία. Πατήστε `Super + I` για να περιηγηθείτε κυκλικά στις διαμορφωμένες μεθόδους εισόδου και `Super + Shift + I` για να περιηγηθείτε προς τα πίσω. Πατήστε `Shift` μόνο του για να βγείτε από μια μέθοδο εισόδου όπως το Pinyin στα λατινικά γράμματα και πατήστε το ξανά για να επιστρέψετε, όπως λειτουργούν τα Sogou, Microsoft Pinyin και macOS· το `Shift` συν ένα γράμμα εξακολουθεί να πληκτρολογεί κεφαλαίο. Στα ιαπωνικά πληκτρολόγια, το 全角/半角 εναλλάσσει την είσοδο, το 変換 την ενεργοποιεί και το 無変換 την απενεργοποιεί. Με τα Κορεατικά, το 한/영 εναλλάσσει το Hangul και το 한자 μετατρέπει σε Hanja, είτε το πληκτρολόγιό σας έχει αποκλειστικά πλήκτρα είτε στέλνει Right Alt και Right Ctrl για αυτά, όπως κάνουν πολλοί φορητοί υπολογιστές, οπότε το Right Alt και το Right Ctrl δεν είναι απλοί τροποποιητές εκεί· η υπαγόρευση εναλλάσσεται με Alt + Space. Το `Ctrl + Space` παραμένει διαθέσιμο για Tmux και Herdr· το `Shift + CapsLock` παραμένει το πλήκτρο σύνθεσης.

Η ένδειξη πληκτρολογίου εμφανίζεται στα δεξιά της γραμμής όταν έχετε πολλαπλές διατάξεις πληκτρολογίου ή μεθόδους εισόδου. Κάντε κλικ σε αυτήν για να αλλάξετε γλώσσες εισόδου· τα Ιαπωνικά εμφανίζουν あ για τα hiragana. Για επιλογές ιαπωνικών χαρακτήρων, μεταβείτε στα Ιαπωνικά, πληκτρολογήστε μια λέξη όπως `nihongo` και μετά πατήστε Space δύο φορές. Πατήστε Enter για να αποδεχτείτε την επιλογή σας. Αν έχετε επίσης πολλαπλές διατάξεις πληκτρολογίου, κάντε δεξί κλικ στην ένδειξη για να περιηγηθείτε κυκλικά σε αυτές.

Χρησιμοποιήστε το _Setup > Typing > Keyboard Layouts_ για να επιλέξετε διατάξεις όπως Αγγλικά και Γαλλικά, από τις ίδιες επιλογές που προσφέρονται κατά την εγκατάσταση. Χρησιμοποιήστε το _Setup > Typing > Input Methods_ για να επιλέξετε ποιες μηχανές σύνθεσης είναι ενεργές. Και τα δύο εργαλεία επιλογής ανοίγουν μέσα στο μενού του Omarchy με τις τρέχουσες επιλογές σας επιλεγμένες. Κάντε κλικ ή πατήστε Enter για να εναλλάξετε μια επιλογή· κάθε αλλαγή εφαρμόζεται αμέσως. Η αποεπιλογή μιας μεθόδου εισόδου την αφαιρεί από τον κύκλο χωρίς να την απεγκαθιστά· το πληκτρολόγιο παραμένει διαθέσιμο.

Εκτελέστε `omarchy setup keyboard` ή `omarchy setup input` για να ανοίξετε τα ίδια εργαλεία επιλογής. Για να προσθέσετε μία γλώσσα από τη γραμμή εντολών, χρησιμοποιήστε `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` ή `cangjie5`. Τα Quick, Boshiamy και Array περιλαμβάνονται στο ίδιο πακέτο με το Cangjie και εμφανίζονται στο εργαλείο επιλογής Input Methods. Τα προσαρμοσμένα πλήκτρα εναλλαγής σας διατηρούνται. Για εναλλακτικές διατάξεις μηχανών ή πλήκτρα, εγκαταστήστε το `fcitx5-configtool` με `omarchy pkg add fcitx5-configtool` και εκκινήστε το από ένα τερματικό. Η επιλογή μιας γλώσσας εισόδου δεν αλλάζει τη γλώσσα της επιφάνειας εργασίας. Η επιλογή Ιαπωνικών, Κορεατικών ή Κινεζικών στο _Setup > Language_ προσθέτει τη μέθοδο εισόδου τους όταν δεν έχετε ακόμη καμία.

Χρησιμοποιήστε το `Super + I` για να περιηγηθείτε κυκλικά στις μεθόδους εισόδου ή τις διατάξεις πληκτρολογίου και το `Super + Shift + I` για να πάτε προς την άλλη κατεύθυνση, οπότε με τρεις διαμορφωμένες μπορείτε να μετακινηθείτε ανάμεσα σε δύο γείτονες. Η ένδειξη εισόδου εμφανίζεται στα δεξιά της γραμμής μόνο όταν έχουν διαμορφωθεί περισσότερες από μία μέθοδοι εισόδου ή διατάξεις. Αυτή η σύνδεση επιφάνειας εργασίας λειτουργεί παράλληλα με τα υπάρχοντα πλήκτρα εναλλαγής Fcitx· μπορείτε να την παρακάμψετε στο `~/.config/hypr/bindings.lua`. Οι μηχανές εισόδου και οι ακολουθίες σύνθεσης χρησιμοποιούν την υπηρεσία [Fcitx5](https://fcitx-im.org/) που ήδη εκτελείται σε κάθε συνεδρία.

### Χρήση του ALT ως SUPER

Σε ορισμένα πληκτρολόγια, δεν είναι βολικό να χρησιμοποιείτε το κύριο πλήκτρο meta (πλήκτρο Windows/cmd) ως SUPER. Μπορείτε να το αλλάξετε αυτό σε ALT χρησιμοποιώντας αυτήν την αλλαγή:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
