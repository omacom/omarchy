# Πληκτρολόγιο, Ποντίκι, Trackpad

Το Hyprland σάς επιτρέπει να διαμορφώνετε όλες τις εισόδους σας με μεγάλη λεπτομέρεια. Μπορείτε να κάνετε την επανάληψη του πληκτρολογίου υπερηχητικά γρήγορη ή να κάνετε το trackpad να χρησιμοποιεί φυσική κύλιση. Τα αλλάζετε όλα στο `~/.config/hypr/input.lua`, στο οποίο μπορείτε επίσης να φτάσετε μέσω του _Setup > Input_ στο μενού του Omarchy (`Super + Space`). Οτιδήποτε ορίσετε εκεί αντικαθιστά τις προεπιλογές του Omarchy.

Ακολουθεί ένα παράδειγμα:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Μπορείτε να [δείτε όλες τις επιλογές εισόδου](https://wiki.hypr.land/Configuring/Basics/Variables/#input) στο wiki του Hyprland για τις εισόδους.

Το CapsLock λειτουργεί ως κανονικό Caps Lock, και το `Shift + CapsLock` είναι το πλήκτρο compose για [γρήγορα emoji](07-hotkeys.md#quick-emojis) και [άλλες συμπληρώσεις](07-hotkeys.md#quick-completions). Αν προτιμάτε το πλήκτρο compose αλλού, αντικαταστήστε το `omarchy:shift_caps_compose` στο `kb_options`. Για παράδειγμα, αυτό μετακινεί το πλήκτρο compose στο Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Χειρονομίες trackpad

Σύρετε στο trackpad για να μετακινηθείτε στην επιφάνεια εργασίας:

| Χειρονομία | Ενέργεια |
| --- | --- |
| Τρία δάχτυλα αριστερά / δεξιά | Προηγούμενος / επόμενος χώρος εργασίας, συμπεριλαμβανομένων των κενών |
| Τρία δάχτυλα επάνω | Εναλλαγή της κονσόλας AI |
| Τρία δάχτυλα κάτω | Άνοιγμα του μενού του Omarchy |
| Τέσσερα δάχτυλα αριστερά / δεξιά | Μετακίνηση του ενεργού παραθύρου στον προηγούμενο / επόμενο χώρο εργασίας |
| Τέσσερα δάχτυλα κάτω | Εναλλαγή πλήρους οθόνης |

Για να αλλάξετε μία, καταργήστε τον ορισμό της στο `~/.config/hypr/input.lua` πριν προσθέσετε τη δική σας [χειρονομία trackpad](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), καθώς το Hyprland δεν θα δεχτεί δύο χειρονομίες με τα ίδια δάχτυλα και την ίδια κατεύθυνση:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Για να απενεργοποιήσετε όλες τις χειρονομίες του Omarchy, ορίστε το `omarchy_default_gestures = false` κοντά στην κορυφή του `~/.config/hypr/hyprland.lua`, πριν φορτωθούν οι προεπιλογές του Omarchy.

Σε φορητούς υπολογιστές Dell XPS με απτικό touchpad, μπορείτε επίσης να ορίσετε την ισχύ του κλικ σε χαμηλή, μεσαία ή υψηλή κάτω από το _Trigger > Hardware > Touchpad Haptics_.

### Πληκτρολόγηση στα Κινεζικά, στα Ιαπωνικά και σε άλλες γλώσσες

Επιλέξτε Ιαπωνικά, Κορεατικά, Κινεζικά (Απλοποιημένα, Pinyin), Ταϊβάν (Zhuyin) ή Χονγκ Κονγκ (Cangjie) όταν το πρόγραμμα εγκατάστασης σάς ζητήσει το πληκτρολόγιό σας. Το Omarchy διαμορφώνει αυτόματα το πληκτρολόγιο και την αντίστοιχη μηχανή εισαγωγής, συμπεριλαμβανομένης της ρύθμισης πρώτης εκκίνησης χωρίς σύνδεση. Τα Ιαπωνικά χρησιμοποιούν το Mozc, τα Κορεατικά χρησιμοποιούν το τυπικό Hangul δύο συνόλων, τα Απλοποιημένα Κινεζικά χρησιμοποιούν Pinyin, η Ταϊβάν χρησιμοποιεί την τυπική διάταξη Zhuyin του Chewing, και το Χονγκ Κονγκ χρησιμοποιεί Cangjie με μορφές χαρακτήρων του Χονγκ Κονγκ. Τα Ιαπωνικά (πληκτρολόγιο US) παρέχουν το Mozc με διάταξη πληκτρολογίου US. Τα πλήκτρα Hangul, Zhuyin και Cangjie παραμένουν στις τυπικές τους θέσεις ακόμα κι όταν πληκτρολογείτε λατινικούς χαρακτήρες με Dvorak, Colemak ή AZERTY. Αν είχατε προσθέσει το Hangul ή το Chewing πριν από αυτό, αποεπιλέξτε το και επιλέξτε το ξανά κάτω από το _Setup > Typing > Input Methods_ για να μετακινήσετε τα πλήκτρα του εκεί· το Omarchy αφήνει ήσυχη μια μηχανή με την οποία ήδη πληκτρολογείτε.

Η πληκτρολόγηση ξεκινά σε λειτουργία Λατινικών. Πατήστε `Super + I` για να περιηγηθείτε κυκλικά στις διαμορφωμένες μεθόδους εισαγωγής, και `Super + Shift + I` για να περιηγηθείτε αντίστροφα. Πατήστε το `Shift` μόνο του για να βγείτε από μια μέθοδο εισαγωγής όπως το Pinyin στους λατινικούς χαρακτήρες, και πατήστε το ξανά για να επιστρέψετε, με τον τρόπο που λειτουργούν τα Sogou, Microsoft Pinyin και macOS· το `Shift` μαζί με ένα γράμμα εξακολουθεί να πληκτρολογεί κεφαλαίο. Στα ιαπωνικά πληκτρολόγια, το 全角/半角 εναλλάσσει την είσοδο, το 変換 την ενεργοποιεί και το 無変換 την απενεργοποιεί. Με τα Κορεατικά, το 한/영 εναλλάσσει το Hangul και το 한자 μετατρέπει σε Hanja, είτε το πληκτρολόγιό σας έχει αποκλειστικά πλήκτρα είτε στέλνει Right Alt και Right Ctrl για αυτά, όπως κάνουν πολλοί φορητοί υπολογιστές, οπότε τα Right Alt και Right Ctrl δεν είναι απλοί τροποποιητές εκεί· η υπαγόρευση με push-to-talk παραμένει στο F9. Το `Ctrl + Space` παραμένει διαθέσιμο για τα Tmux και Herdr· το `Shift + CapsLock` παραμένει το πλήκτρο compose.

Ο δείκτης πληκτρολογίου εμφανίζεται στα δεξιά της γραμμής όταν έχετε πολλαπλές διατάξεις πληκτρολογίου ή μεθόδους εισαγωγής. Κάντε κλικ σε αυτόν για να αλλάξετε γλώσσες εισαγωγής· τα Ιαπωνικά εμφανίζουν το あ για τα hiragana. Για επιλογές ιαπωνικών χαρακτήρων, μεταβείτε στα Ιαπωνικά, πληκτρολογήστε μια λέξη όπως `nihongo`, και μετά πατήστε Space δύο φορές. Πατήστε Enter για να αποδεχτείτε την επιλογή σας. Αν έχετε επίσης πολλαπλές διατάξεις πληκτρολογίου, κάντε δεξί κλικ στον δείκτη για να περιηγηθείτε κυκλικά σε αυτές.

Χρησιμοποιήστε το _Setup > Typing > Keyboard Layouts_ για να επιλέξετε διατάξεις όπως Αγγλικά και Γαλλικά, από τις ίδιες επιλογές που προσφέρονται κατά την εγκατάσταση. Χρησιμοποιήστε το _Setup > Typing > Input Methods_ για να επιλέξετε ποιες μηχανές σύνθεσης είναι ενεργές. Και τα δύο εργαλεία επιλογής ανοίγουν μέσα στο μενού του Omarchy με τις τρέχουσες επιλογές σας επιλεγμένες. Κάντε κλικ ή πατήστε Enter για να εναλλάξετε μια επιλογή· κάθε αλλαγή εφαρμόζεται αμέσως. Η αποεπιλογή μιας μεθόδου εισαγωγής την αφαιρεί από τον κύκλο χωρίς να την απεγκαθιστά· το πληκτρολόγιο παραμένει διαθέσιμο.

Εκτελέστε το `omarchy setup keyboard` ή το `omarchy setup input` για να ανοίξετε τα ίδια εργαλεία επιλογής. Για να προσθέσετε μία γλώσσα από τη γραμμή εντολών, χρησιμοποιήστε το `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` ή `cangjie5`. Τα Quick, Boshiamy και Array έρχονται στο ίδιο πακέτο με το Cangjie και εμφανίζονται στο εργαλείο επιλογής Input Methods. Τα προσαρμοσμένα πλήκτρα εναλλαγής σας διατηρούνται. Για εναλλακτικές διατάξεις ή πλήκτρα μηχανών, εγκαταστήστε το `fcitx5-configtool` με το `omarchy pkg add fcitx5-configtool` και εκκινήστε το από ένα τερματικό. Η επιλογή μιας γλώσσας εισαγωγής δεν αλλάζει τη γλώσσα της επιφάνειας εργασίας. Η επιλογή Ιαπωνικών, Κορεατικών ή Κινεζικών κάτω από το _Setup > Language_ προσθέτει τη μέθοδο εισαγωγής τους όταν δεν έχετε ακόμα καμία.

Χρησιμοποιήστε το `Super + I` για να περιηγηθείτε κυκλικά στις μεθόδους εισαγωγής ή στις διατάξεις πληκτρολογίου, και το `Super + Shift + I` για να πάτε αντίστροφα, οπότε με τρεις διαμορφωμένες μπορείτε να μετακινηθείτε μεταξύ δύο γειτονικών. Ο δείκτης εισαγωγής εμφανίζεται στα δεξιά της γραμμής μόνο όταν έχουν διαμορφωθεί περισσότερες από μία μέθοδοι εισαγωγής ή διατάξεις. Αυτή η συντόμευση επιφάνειας εργασίας λειτουργεί παράλληλα με τα υπάρχοντα πλήκτρα εναλλαγής του Fcitx· μπορείτε να την παρακάμψετε στο `~/.config/hypr/bindings.lua`. Οι μηχανές εισαγωγής και οι ακολουθίες compose χρησιμοποιούν την υπηρεσία [Fcitx5](https://fcitx-im.org/) που ήδη εκτελείται σε κάθε συνεδρία.

### Χρήση του ALT ως SUPER

Σε ορισμένα πληκτρολόγια, δεν είναι βολικό να χρησιμοποιείτε το κύριο πλήκτρο meta (πλήκτρο Windows/cmd) ως SUPER. Μπορείτε να το αλλάξετε αυτό σε ALT αντ' αυτού χρησιμοποιώντας αυτή την αλλαγή:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
