# Συχνές ερωτήσεις

### Πώς εναλλάσσομαι μεταξύ διατάξεων πληκτρολογίου;

Επεξεργαστείτε το αρχείο `~/.config/hypr/input.lua` και προσθέστε αυτό για να εναλλάσσεστε μεταξύ διατάξεων με `Left Alt + Right Alt`:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

Η μπάρα θα εμφανίζει αυτόματα την τρέχουσα διάταξη πληκτρολογίου σας μόλις έχετε ρυθμίσει πολλές διατάξεις (και μπορείτε επίσης να κάνετε κλικ σε αυτήν για να εναλλαγείτε).

### Πώς αλλάζω τη μορφή του ρολογιού σε 12ωρη;

Κάντε δεξί κλικ στο ρολόι στη μπάρα για να περιηγηθείτε στις συνηθισμένες μορφές, συμπεριλαμβανομένων των 12ωρων. Μπορείτε επίσης να ορίσετε τη μορφή απευθείας:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

Αυτό θα εμφανίζει Κυριακή 10:55 AM.

### Πώς αλλάζω τη ζώνη ώρας μου;

Εκτελέστε _Ρύθμιση > Περιοχή > Ζώνη ώρας_ στο μενού του Omarchy και επιλέξτε από τη λίστα. Αν η ζώνη ώρας είναι σωστή αλλά το ίδιο το ρολόι έχει ξεφύγει, το _Ενημέρωση > Ώρα_ επανεκκινεί τον συγχρονισμό ώρας για εσάς.

### Πώς αλλάζω το DNS μου, μοιράζομαι το Wi-Fi μου ή ελέγχω την ταχύτητα της σύνδεσής μου;

Όλα αυτά βρίσκονται στη [δικτύωση](35-networking.md).

### Πώς ελέγχω πόσο γρήγορος είναι ο δίσκος μου;

Το _Ενεργοποίηση > Δοκιμή ταχύτητας > Δοκιμή ταχύτητας δίσκου_ μετρά σε πραγματικό χρόνο την ταχύτητα ανάγνωσης και εγγραφής στον δίσκο σας, ή `omarchy disk speedtest` από το τερματικό.

### Πώς προσθέτω έναν εκτυπωτή;

Η εκτύπωση είναι ρυθμισμένη και λειτουργεί από την πρώτη στιγμή, και προσθέτετε κάθε εκτυπωτή μόνοι σας από τις _Ρυθμίσεις εκτύπωσης_ στον εκκινητή εφαρμογών (`Super + Alt + Space`).

Επιλέξτε _Προσθήκη_ και δώστε του λίγο χρόνο να ψάξει: ένας εκτυπωτής συνδεδεμένος μέσω USB, και οι περισσότεροι εκτυπωτές δικτύου, εντοπίζονται για εσάς. Αν ο δικός σας δεν είναι στη λίστα, επιλέξτε _Εκτυπωτής δικτύου > Internet Printing Protocol (ipp)_ και εισαγάγετε τη διεύθυνσή του — η οθόνη του ίδιου του εκτυπωτή ή η ιστοσελίδα του θα σας πει ποια είναι, συνήθως κάτι σαν `192.168.1.50` με ουρά `ipp/print`. Το _Επόμενο_ στη συνέχεια προσφέρει ένα πρόγραμμα οδήγησης, όπου ένας σύγχρονος εκτυπωτής λειτουργεί καλύτερα με το προφίλ _IPP Everywhere_ χωρίς πρόγραμμα οδήγησης και ένας παλαιότερος θέλει το πρόγραμμα οδήγησης του ίδιου του μοντέλου.

Κάντε δεξί κλικ σε έναν εκτυπωτή και επιλέξτε _Ορισμός ως προεπιλογής_ για να διαλέξετε ποιον θα προσεγγίζουν πρώτα οι εφαρμογές σας, και _Ιδιότητες_ για να ορίσετε μέγεθος χαρτιού, εκτύπωση διπλής όψης και ποιότητα.

Ο αυτόματος εντοπισμός, όπου οι εκτυπωτές στο δίκτυο εμφανίζονται χωρίς να προστεθούν, είναι προσωρινά απενεργοποιημένος ενώ επανεξετάζεται, γι' αυτό το πρώτο βήμα παραπάνω είναι δικό σας και όχι αυτόματο. Η εκτύπωση σε αρχείο PDF λειτουργεί χωρίς κανέναν απολύτως εκτυπωτή.

### Πώς αλλάζω πού αποθηκεύονται τα στιγμιότυπα οθόνης ή οι εγγραφές οθόνης;

Τα αποθηκευμένα στιγμιότυπα οθόνης πηγαίνουν στο `~/Pictures/Screenshots` από προεπιλογή. Για να χρησιμοποιήσετε άλλον κατάλογο, προσθέστε αυτό σε ένα αρχείο κάτω από το `~/.config/uwsm/env.d/` (όπως το `~/.config/uwsm/env.d/capture`):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

Μπορείτε να κάνετε το ίδιο για τις εγγραφές οθόνης χρησιμοποιώντας το `OMARCHY_SCREENRECORD_DIR`.

Το Omasnap δημιουργεί τον κατάλογο στιγμιότυπων οθόνης του αυτόματα. Δημιουργήστε τον κατάλογο εγγραφών οθόνης μόνοι σας, στη συνέχεια επανεκκινήστε το Omarchy για να τεθεί σε ισχύ οποιαδήποτε από τις δύο αλλαγές περιβάλλοντος.

### Πώς κάνω τα ηχεία + την κάμερα web να λειτουργήσουν στην Apple Studio Display μου;

Θα νόμιζες πως όλα θα έπρεπε να δουλεύουν απλώς συνδέοντας το USB C, αλλά δυστυχώς δεν είναι έτσι. Η λύση που βρήκα για να λειτουργεί αξιόπιστα είναι να χρησιμοποιώ [το καλώδιο WJESOG DisplayPort + USB-A => USB-C](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/). Τότε τα ηχεία και η κάμερα web δουλεύουν άψογα.

Να θυμάστε ότι έχετε ενσωματωμένο έλεγχο φωτεινότητας στο Omarchy για τις οθόνες Apple (τόσο τη Studio όσο και την XDR) χρησιμοποιώντας τα κανονικά κουμπιά φωτεινότητας του πληκτρολογίου.

### Πώς απαλλάσσομαι από όλο το επιπλέον λογισμικό;

Αν δεν θέλετε προγράμματα όπως το Obsidian ή το LibreOffice ή οποιοδήποτε άλλο προεγκατεστημένο υλικό, μπορείτε πολύ εύκολα να το αφαιρέσετε.

Εκτελέστε _Κατάργηση > Πακέτο_ για να δείτε κάθε πακέτο που είναι εγκατεστημένο. Στη συνέχεια μπορείτε να επιλέξετε όποιο πακέτο θα θέλατε να καταργήσετε με το tab, και να ξεκινήσετε να καταργείτε όλα όσα έχετε επιλέξει με το return.

Και μπορείτε να χρησιμοποιήσετε το _Κατάργηση > Εφαρμογή web_ από το μενού του Omarchy για να καταργήσετε οποιαδήποτε από τις προεγκατεστημένες εφαρμογές web δεν θέλετε.

Ή εκτελέστε _Κατάργηση > Προεγκατεστημένα_ για να σαρώσετε όλα τα προεγκατεστημένα επιπλέον — εφαρμογές web, TUI και προαιρετικές εφαρμογές — με μία κίνηση. Οι συντομεύσεις πληκτρολογίου που τις εκκινούσαν εξαφανίζονται μαζί τους, οπότε μένετε με μια καθαρή αφετηρία στους συνδυασμούς πλήκτρων για να τους γεμίσετε με τους δικούς σας στο `~/.config/hypr/bindings.lua`.
