# Συχνές ερωτήσεις

### Πώς εναλλάσσω μεταξύ διατάξεων πληκτρολογίου;

Επεξεργάσου το αρχείο σου `~/.config/hypr/input.lua` και πρόσθεσε αυτό για εναλλαγή μεταξύ διατάξεων στο `Left Alt + Right Alt`:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

Η γραμμή θα δείχνει αυτόματα την τρέχουσα διάταξη πληκτρολογίου σου μόλις έχεις πολλαπλές διατάξεις διαμορφωμένες (και μπορείς να την πατήσεις για να αλλάξεις επίσης).

### Πώς αλλάζω τη μορφή ρολογιού σε 12ωρη;

Κάνε δεξί κλικ στο ρολόι στη γραμμή για να περιηγηθείς στις συνηθισμένες μορφές, συμπεριλαμβανομένων των 12ωρων. Μπορείς επίσης να ορίσεις τη μορφή απευθείας:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

Αυτό θα εμφανίσει Κυριακή 10:55 AM.

### Πώς αλλάζω τη ζώνη ώρας μου;

Τρέξε _Ενημέρωση > Ζώνη ώρας_ στο μενού Omarchy και διάλεξε από τη λίστα. Αν η ζώνη ώρας είναι σωστή αλλά το ίδιο το ρολόι έχει παρασυρθεί, το _Ενημέρωση > Ώρα_ επανεκκινεί τον συγχρονισμό ώρας για εσένα.

### Πώς αλλάζω το DNS μου, μοιράζομαι το Wi-Fi μου ή ελέγχω την ταχύτητα σύνδεσής μου;

Αυτά ζουν όλα στη [δικτύωση](35-networking.md).

### Πώς ελέγχω πόσο γρήγορος είναι ο δίσκος μου;

Το _Ενεργοποίηση > Δοκιμή ταχύτητας > Δοκιμή ταχύτητας δίσκου_ μετρά ζωντανή ταχύτητα ανάγνωσης και εγγραφής στη μονάδα σου, ή `omarchy disk speedtest` από το τερματικό.

### Γιατί δεν μπορώ να συνδεθώ στον λογαριασμό μου Google στο Chromium;

Η απλή έκδοση ανοιχτού κώδικα του Chromium δεν έρχεται με τα διαπιστευτήρια OAuth που απαιτεί η Google για σύνδεση λογαριασμού. Τρέξε _Εγκατάσταση > Υπηρεσία > Chromium Account_ στο μενού Omarchy για να τα προσθέσεις, επανεκκίνησε το πρόγραμμα περιήγησης, και η σύνδεση θα περάσει.

### Πώς προσθέτω έναν εκτυπωτή;

Η εκτύπωση είναι ρυθμισμένη και τρέχει από το κουτί, και προσθέτεις κάθε εκτυπωτή ο ίδιος από _Print Settings_ στον εκκινητή εφαρμογών (`Super + Space`).

Διάλεξε _Add_, και δώσ' του μια στιγμή να ψάξει: ένας εκτυπωτής συνδεδεμένος μέσω USB, και οι περισσότεροι εκτυπωτές δικτύου, βρίσκονται για εσένα. Αν ο δικός σου δεν είναι στη λίστα, διάλεξε _Network Printer > Internet Printing Protocol (ipp)_ και εισήγαγε τη διεύθυνσή του — η ίδια η οθόνη του εκτυπωτή ή η ιστοσελίδα του θα σου πει ποια είναι, συνήθως κάτι σαν `192.168.1.50` με ουρά `ipp/print`. Το _Forward_ προσφέρει μετά έναν οδηγό, όπου ένας σύγχρονος εκτυπωτής δουλεύει καλύτερα στο προφίλ χωρίς οδηγό _IPP Everywhere_ και ένας παλαιότερος θέλει τον δικό του οδηγό μοντέλου.

Κάνε δεξί κλικ σε έναν εκτυπωτή και διάλεξε _Set as Default_ για να διαλέξεις ποιον θα προτιμούν πρώτα οι εφαρμογές σου, και _Properties_ για να ορίσεις μέγεθος χαρτιού, διπλή όψη και ποιότητα.

Η αυτόματη ανακάλυψη, όπου εκτυπωτές στο δίκτυο εμφανίζονται χωρίς να προστεθούν, είναι προσωρινά απενεργοποιημένη ενώ αναδιαμορφώνεται, γι' αυτό το πρώτο βήμα παραπάνω είναι δικό σου αντί για αυτόματο. Η εκτύπωση σε αρχείο PDF δουλεύει χωρίς κανέναν εκτυπωτή.

### Πώς αλλάζω πού αποθηκεύονται τα στιγμιότυπα ή οι εγγραφές οθόνης;

Τα αποθηκευμένα στιγμιότυπα πηγαίνουν στο `~/Pictures/Screenshots` από προεπιλογή. Για να χρησιμοποιήσεις έναν άλλο κατάλογο, πρόσθεσε αυτό σε ένα αρχείο κάτω από `~/.config/uwsm/env.d/` (όπως `~/.config/uwsm/env.d/capture`):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

Μπορείς να κάνεις το ίδιο για εγγραφές οθόνης χρησιμοποιώντας `OMARCHY_SCREENRECORD_DIR`.

Το Omasnap δημιουργεί τον κατάλογο στιγμιότυπών του αυτόματα. Δημιούργησε τον κατάλογο εγγραφής οθόνης ο ίδιος, μετά επανεκκίνησε το Omarchy για να τεθεί σε ισχύ οποιαδήποτε αλλαγή περιβάλλοντος.

### Πώς κάνω τα ηχεία + την κάμερα web να δουλεύουν στην Apple Studio Display μου;

Θα νόμιζες ότι όλα πρέπει να δουλεύουν απλώς συνδέοντας USB C, αλλά δυστυχώς αυτό δεν ισχύει. Η λύση που βρήκα να δουλεύει αξιόπιστα είναι η χρήση [του καλωδίου WJESOG DisplayPort + USB-A => USB-C](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/). Τότε τα ηχεία και η κάμερα web δουλεύουν θαυμάσια.

Θυμήσου ότι έχεις ενσωματωμένο έλεγχο φωτεινότητας στο Omarchy για τις Οθόνες Apple (τόσο Studio όσο και XDR) χρησιμοποιώντας τα κανονικά κουμπιά φωτεινότητας πληκτρολογίου.

### Πώς ξεφορτώνομαι όλο το επιπλέον λογισμικό;

Αν δεν θέλεις προγράμματα όπως Obsidian ή LibreOffice ή οποιοδήποτε από τα άλλα προεγκατεστημένα πράγματα, μπορείς πολύ εύκολα να τα αφαιρέσεις.

Τρέξε _Αφαίρεση > Πακέτο_ για να δεις κάθε εγκατεστημένο πακέτο. Μετά μπορείς να επιλέξεις οποιοδήποτε πακέτο θα ήθελες να αφαιρέσεις με tab, και να αρχίσεις να αφαιρείς όλα όσα επέλεξες με return.

Και μπορείς να χρησιμοποιήσεις _Αφαίρεση > Web App_ από το μενού Omarchy για να αφαιρέσεις οποιαδήποτε από τις προεγκατεστημένες εφαρμογές web που δεν θέλεις.

Ή τρέξε _Αφαίρεση > Preinstalls_ για να σαρώσεις έξω όλα τα προεγκατεστημένα επιπλέον — εφαρμογές web, TUI και προαιρετικές εφαρμογές — με μία κίνηση. Οι συντομεύσεις που τα εκκινούσαν φεύγουν μαζί τους, οπότε σου μένει μια καθαρή πλάκα δεσμεύσεων για να γεμίσεις με τις δικές σου στο `~/.config/hypr/bindings.lua`.
