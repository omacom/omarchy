# Συχνές ερωτήσεις

### Πώς μπορώ να εναλλάσσομαι μεταξύ διατάξεων πληκτρολογίου;

Επεξεργαστείτε το αρχείο `~/.config/hypr/input.lua` και προσθέστε αυτό για εναλλαγή μεταξύ διατάξεων με `Left Alt + Right Alt`:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

Η μπάρα θα εμφανίζει αυτόματα την τρέχουσα διάταξη πληκτρολογίου μόλις ρυθμίσετε πολλαπλές διατάξεις (και μπορείτε επίσης να κάνετε κλικ σε αυτήν για εναλλαγή).

### Πώς μπορώ να αλλάξω τη μορφή του ρολογιού σε 12ωρη;

Κάντε δεξί κλικ στο ρολόι στη μπάρα για να περιηγηθείτε στις συνηθισμένες μορφές, συμπεριλαμβανομένων των 12ωρων. Μπορείτε επίσης να ορίσετε τη μορφή απευθείας:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

Έτσι θα εμφανίζεται Κυριακή 10:55 AM.

### Πώς μπορώ να αλλάξω τη ζώνη ώρας μου;

Εκτελέστε _Ρύθμιση > Περιοχή > Ζώνη ώρας_ στο μενού του Omarchy και επιλέξτε από τη λίστα. Αν η ζώνη ώρας είναι σωστή αλλά το ίδιο το ρολόι έχει ξεφύγει, το _Ενημέρωση > Ώρα_ επανεκκινεί τον συγχρονισμό ώρας για εσάς.

### Πώς μπορώ να αλλάξω το DNS μου, να μοιραστώ το Wi-Fi μου ή να ελέγξω την ταχύτητα της σύνδεσής μου;

Όλα αυτά βρίσκονται στη [δικτύωση](35-networking.md).

### Πώς μπορώ να ελέγξω πόσο γρήγορος είναι ο δίσκος μου;

Το _Ενεργοποίηση > Δοκιμή ταχύτητας > Δοκιμή ταχύτητας δίσκου_ μετρά την τρέχουσα ταχύτητα ανάγνωσης και εγγραφής στη μονάδα σας, ή `omarchy disk speedtest` από το τερματικό.

### Πώς μπορώ να προσθέσω έναν εκτυπωτή;

Η εκτύπωση είναι ρυθμισμένη και λειτουργεί εξαρχής, και προσθέτετε κάθε εκτυπωτή μόνοι σας από τις _Ρυθμίσεις εκτύπωσης_ στον εκκινητή εφαρμογών (`Super + Space`).

Επιλέξτε _Προσθήκη_, και δώστε του λίγο χρόνο για αναζήτηση: ένας εκτυπωτής συνδεδεμένος μέσω USB, και οι περισσότεροι εκτυπωτές δικτύου, εντοπίζονται για εσάς. Αν ο δικός σας δεν είναι στη λίστα, επιλέξτε _Εκτυπωτής δικτύου > Internet Printing Protocol (ipp)_ και εισαγάγετε τη διεύθυνσή του — η οθόνη του ίδιου του εκτυπωτή ή η ιστοσελίδα του θα σας πει ποια είναι αυτή, συνήθως κάτι σαν `192.168.1.50` με ουρά `ipp/print`. Το _Επόμενο_ στη συνέχεια προσφέρει έναν οδηγό, όπου ένας σύγχρονος εκτυπωτής λειτουργεί καλύτερα με το προφίλ _IPP Everywhere_ χωρίς οδηγό και ένας παλαιότερος θέλει τον οδηγό του ίδιου του μοντέλου.

Κάντε δεξί κλικ σε έναν εκτυπωτή και επιλέξτε _Ορισμός ως προεπιλογή_ για να επιλέξετε ποιον θα προσεγγίζουν πρώτα οι εφαρμογές σας, και _Ιδιότητες_ για να ορίσετε μέγεθος χαρτιού, διπλή όψη και ποιότητα.

Η αυτόματη ανακάλυψη, όπου οι εκτυπωτές στο δίκτυο εμφανίζονται χωρίς να προστεθούν, είναι προσωρινά απενεργοποιημένη ενώ επανασχεδιάζεται, γι' αυτό το πρώτο βήμα παραπάνω είναι δικό σας και όχι αυτόματο. Η εκτύπωση σε αρχείο PDF λειτουργεί χωρίς κανέναν εκτυπωτή.

### Πώς μπορώ να αλλάξω πού αποθηκεύονται τα στιγμιότυπα οθόνης ή οι εγγραφές οθόνης;

Τα αποθηκευμένα στιγμιότυπα οθόνης πηγαίνουν στο `~/Pictures/Screenshots` από προεπιλογή. Για να χρησιμοποιήσετε άλλο κατάλογο, προσθέστε αυτό σε ένα αρχείο κάτω από το `~/.config/uwsm/env.d/` (όπως το `~/.config/uwsm/env.d/capture`):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

Μπορείτε να κάνετε το ίδιο για τις εγγραφές οθόνης χρησιμοποιώντας το `OMARCHY_SCREENRECORD_DIR`.

Το Omasnap δημιουργεί αυτόματα τον κατάλογο στιγμιότυπων οθόνης του. Δημιουργήστε μόνοι σας τον κατάλογο εγγραφών οθόνης, και στη συνέχεια επανεκκινήστε το Omarchy για να τεθεί σε ισχύ οποιαδήποτε από τις δύο αλλαγές περιβάλλοντος.

### Πώς μπορώ να κάνω τα ηχεία + την κάμερα web να λειτουργούν στην Apple Studio Display μου;

Θα περίμενε κανείς ότι όλα θα λειτουργούσαν απλώς συνδέοντας το USB C, αλλά δυστυχώς αυτό δεν ισχύει. Η λύση που βρήκα για να λειτουργεί αξιόπιστα είναι η χρήση [του καλωδίου WJESOG DisplayPort + USB-A => USB-C](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/). Τότε τα ηχεία και η κάμερα web λειτουργούν άψογα.

Να θυμάστε ότι έχετε ενσωματωμένο έλεγχο φωτεινότητας στο Omarchy για τις οθόνες Apple (τόσο Studio όσο και XDR) χρησιμοποιώντας τα κανονικά κουμπιά φωτεινότητας του πληκτρολογίου.

### Πώς μπορώ να απαλλαγώ από όλο το επιπλέον λογισμικό;

Αν δεν θέλετε προγράμματα όπως το Obsidian ή το LibreOffice ή οποιοδήποτε άλλο προεγκατεστημένο υλικό, μπορείτε πολύ εύκολα να το αφαιρέσετε.

Εκτελέστε _Αφαίρεση > Πακέτο_ για να δείτε κάθε πακέτο που είναι εγκατεστημένο. Στη συνέχεια μπορείτε να επιλέξετε οποιοδήποτε πακέτο θέλετε να αφαιρέσετε με tab, και να ξεκινήσετε την αφαίρεση όλων όσων επιλέξατε με return.

Και μπορείτε να χρησιμοποιήσετε _Αφαίρεση > Εφαρμογή Web_ από το μενού του Omarchy για να αφαιρέσετε οποιαδήποτε από τις προεγκατεστημένες εφαρμογές web που δεν θέλετε.

Ή εκτελέστε _Αφαίρεση > Προεγκατεστημένα_ για να σαρώσετε όλα τα προεγκατεστημένα επιπλέον — εφαρμογές web, TUI και προαιρετικές εφαρμογές — με μία κίνηση. Οι συντομεύσεις πληκτρολογίου που τις εκκινούσαν εξαφανίζονται μαζί τους, οπότε σας μένει μια καθαρή κατάσταση συνδυασμών για να γεμίσετε με τους δικούς σας στο `~/.config/hypr/bindings.lua`.
