# Συχνές ερωτήσεις

### Πώς εναλλάσσομαι μεταξύ διατάξεων πληκτρολογίου;

Επεξεργαστείτε το αρχείο `~/.config/hypr/input.lua` και προσθέστε αυτό για εναλλαγή μεταξύ διατάξεων με `Left Alt + Right Alt`:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

Η μπάρα θα εμφανίσει αυτόματα την τρέχουσα διάταξη πληκτρολογίου μόλις ρυθμίσετε πολλαπλές διατάξεις (και μπορείτε επίσης να κάνετε κλικ πάνω της για εναλλαγή).

### Πώς αλλάζω τη μορφή του ρολογιού σε 12ωρη;

Κάντε δεξί κλικ στο ρολόι στη μπάρα για να περιηγηθείτε κυκλικά στις συνηθισμένες μορφές, συμπεριλαμβανομένων των 12ωρων. Μπορείτε επίσης να ορίσετε τη μορφή απευθείας:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

Αυτό θα εμφανίσει Κυριακή 10:55 AM.

### Πώς αλλάζω τη ζώνη ώρας μου;

Εκτελέστε _Ενημέρωση > Ζώνη ώρας_ στο μενού του Omarchy και επιλέξτε από τη λίστα. Αν η ζώνη ώρας είναι σωστή αλλά το ίδιο το ρολόι έχει ξεφύγει, το _Ενημέρωση > Ώρα_ επανεκκινεί τον συγχρονισμό ώρας για εσάς.

### Πώς αλλάζω το DNS μου, πώς μοιράζομαι το Wi-Fi μου ή πώς ελέγχω την ταχύτητα της σύνδεσής μου;

Όλα αυτά βρίσκονται στη [δικτύωση](35-networking.md).

### Πώς ελέγχω πόσο γρήγορος είναι ο δίσκος μου;

Το _Ενεργοποίηση > Δοκιμή ταχύτητας > Δοκιμή ταχύτητας δίσκου_ μετρά σε πραγματικό χρόνο την ταχύτητα ανάγνωσης και εγγραφής στη μονάδα σας, ή το `omarchy disk speedtest` από το τερματικό.

### Πώς προσθέτω έναν εκτυπωτή;

Η εκτύπωση είναι ρυθμισμένη και λειτουργεί εξαρχής, και προσθέτετε κάθε εκτυπωτή μόνοι σας από τις _Ρυθμίσεις εκτύπωσης_ στον εκκινητή εφαρμογών (`Super + Space`).

Επιλέξτε _Προσθήκη_, και δώστε του λίγο χρόνο να ψάξει: ένας εκτυπωτής συνδεδεμένος μέσω USB, και οι περισσότεροι εκτυπωτές δικτύου, εντοπίζονται για εσάς. Αν ο δικός σας δεν είναι στη λίστα, επιλέξτε _Εκτυπωτής δικτύου > Internet Printing Protocol (ipp)_ και εισαγάγετε τη διεύθυνσή του — η οθόνη του ίδιου του εκτυπωτή ή η ιστοσελίδα του θα σας πει ποια είναι αυτή, συνήθως κάτι σαν `192.168.1.50` με ουρά `ipp/print`. Το _Εμπρός_ στη συνέχεια προσφέρει έναν οδηγό, όπου ένας σύγχρονος εκτυπωτής λειτουργεί καλύτερα με το προφίλ _IPP Everywhere_ χωρίς οδηγό και ένας παλαιότερος θέλει τον οδηγό του ίδιου του μοντέλου.

Κάντε δεξί κλικ σε έναν εκτυπωτή και επιλέξτε _Ορισμός ως προεπιλογής_ για να διαλέξετε ποιον θα χρησιμοποιούν πρώτα οι εφαρμογές σας, και _Ιδιότητες_ για να ορίσετε μέγεθος χαρτιού, εκτύπωση διπλής όψης και ποιότητα.

Η αυτόματη ανακάλυψη, όπου οι εκτυπωτές στο δίκτυο εμφανίζονται χωρίς να προστεθούν, είναι προσωρινά απενεργοποιημένη όσο επανασχεδιάζεται, γι' αυτό το πρώτο βήμα παραπάνω είναι δικό σας και όχι αυτόματο. Η εκτύπωση σε αρχείο PDF λειτουργεί χωρίς κανέναν απολύτως εκτυπωτή.

### Πώς αλλάζω πού αποθηκεύονται τα στιγμιότυπα οθόνης ή οι εγγραφές οθόνης;

Τα αποθηκευμένα στιγμιότυπα οθόνης πηγαίνουν στο `~/Pictures/Screenshots` από προεπιλογή. Για να χρησιμοποιήσετε άλλον κατάλογο, προσθέστε αυτό σε ένα αρχείο κάτω από το `~/.config/uwsm/env.d/` (όπως το `~/.config/uwsm/env.d/capture`):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

Μπορείτε να κάνετε το ίδιο για τις εγγραφές οθόνης χρησιμοποιώντας το `OMARCHY_SCREENRECORD_DIR`.

Το Omasnap δημιουργεί αυτόματα τον κατάλογο στιγμιότυπων οθόνης του. Δημιουργήστε μόνοι σας τον κατάλογο εγγραφών οθόνης, και μετά επανεκκινήστε το Omarchy για να τεθεί σε ισχύ οποιαδήποτε από τις δύο αλλαγές περιβάλλοντος.

### Πώς κάνω να λειτουργήσουν τα ηχεία + η κάμερα web στην Apple Studio Display μου;

Θα περίμενε κανείς να λειτουργούν όλα απλώς συνδέοντας το USB C, αλλά δυστυχώς δεν συμβαίνει αυτό. Η λύση που βρήκα για να λειτουργεί αξιόπιστα είναι η χρήση [του καλωδίου WJESOG DisplayPort + USB-A => USB-C](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/). Τότε τα ηχεία και η κάμερα web λειτουργούν άψογα.

Θυμηθείτε ότι έχετε ενσωματωμένο έλεγχο φωτεινότητας στο Omarchy για τις οθόνες της Apple (τόσο τη Studio όσο και την XDR) χρησιμοποιώντας τα κανονικά κουμπιά φωτεινότητας του πληκτρολογίου.

### Πώς ξεφορτώνομαι όλο το επιπλέον λογισμικό;

Αν δεν θέλετε προγράμματα όπως το Obsidian ή το LibreOffice ή οποιοδήποτε άλλο προεγκατεστημένο πράγμα, μπορείτε πολύ εύκολα να το αφαιρέσετε.

Εκτελέστε _Αφαίρεση > Πακέτο_ για να δείτε κάθε πακέτο που είναι εγκατεστημένο. Μετά μπορείτε να επιλέξετε οποιοδήποτε πακέτο θέλετε να αφαιρέσετε με tab, και να αρχίσετε να αφαιρείτε όλα όσα επιλέξατε με return.

Και μπορείτε να χρησιμοποιήσετε το _Αφαίρεση > Εφαρμογή web_ από το μενού του Omarchy για να αφαιρέσετε οποιαδήποτε από τις προεγκατεστημένες εφαρμογές web δεν θέλετε.

Ή εκτελέστε το _Αφαίρεση > Προεγκατεστημένα_ για να σαρώσετε όλα τα προεγκατεστημένα πρόσθετα — εφαρμογές web, TUI και προαιρετικές εφαρμογές — με μία κίνηση. Τα πλήκτρα συντόμευσης που τις εκκινούσαν εξαφανίζονται μαζί τους, οπότε σας μένει ένα καθαρό σύνολο συντομεύσεων για να το γεμίσετε με τις δικές σας στο `~/.config/hypr/bindings.lua`.
