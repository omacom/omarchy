# Ανακοινώσεις

Μπορείς να αποκτήσεις γρήγορα πρόσβαση στην ημερομηνία και την ώρα, την κατάσταση μπαταρίας και τον τρέχοντα καιρό χρησιμοποιώντας τις ανακοινώσεις μέσω συντομεύσεων.

### Ημερομηνία & Ώρα

`Super + Ctrl + Alt + T`

 ![notice-datetime](images/notice-datetime.webp)

### Καιρός

`Super + Ctrl + Alt + W`

 ![notice-weather](images/notice-weather.webp)

Η τοποθεσία εντοπίζεται από τη διεύθυνση IP σου, που συνήθως είναι αρκετά κοντινή, αλλά όχι πάντα. Μπορείς να την προσδιορίσεις με `omarchy weather location --set Malibu`, ή να είσαι ακριβής προσθέτοντας συντεταγμένες: `omarchy weather location --set Malibu 34.0259,-118.7798`. Τρέξε `omarchy weather location` μόνο του για να δεις πού νομίζει ότι βρίσκεσαι, και `--clear` για να επιστρέψεις στον αυτόματο εντοπισμό.
