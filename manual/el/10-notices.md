# Ειδοποιήσεις

Οι ειδοποιήσεις εμφανίζονται στην επάνω δεξιά γωνία της εστιασμένης οθόνης. Μπορείτε επίσης να αποκτήσετε γρήγορα πρόσβαση στην ημερομηνία και την ώρα, την κατάσταση της μπαταρίας και τον τρέχοντα καιρό χρησιμοποιώντας τις ειδοποιήσεις πλήκτρων συντόμευσης.

## Ειδοποιήσεις

Οι ειδοποιήσεις από την ίδια εφαρμογή ή ιστότοπο στοιβάζονται σε μια ομάδα, ώστε ένα φλύαρο κανάλι Slack να μην διώχνει την αποτυχία της κατασκευής σας από την οθόνη. Περάστε το δείκτη πάνω από μια ομάδα για να ξεδιπλωθεί· τίποτα νέο δεν γλιστρά κάτω από το δείκτη σας όσο διαβάζετε. Κάντε κλικ σε μια κάρτα για να μεταβείτε από εκεί που προήλθε, κάντε δεξί κλικ, μεσαίο κλικ ή πατήστε το ✕ για να την απορρίψετε.

Οι κάρτες προσφέρουν ό,τι φέρουν: _Αντιγραφή κωδικού_ για κωδικούς επαλήθευσης (που δεν καταχωρούνται στο [ιστορικό προχείρου](08-unified-clipboard-history.md) και διαγράφονται μετά από ένα λεπτό), καθώς και όποια κουμπιά παρέχει η εφαρμογή. Οι σύνδεσμοι στο κείμενο μιας ειδοποίησης ανοίγουν όταν κάνετε κλικ σε αυτούς.

Για να τις χρησιμοποιήσετε χωρίς το ποντίκι, πατήστε `Super + Ctrl + ,`. Επιλέγεται η νεότερη ειδοποίηση και τα κουμπιά της αριθμούνται: πατήστε έναν αριθμό για να χρησιμοποιήσετε ένα, `Enter` για να κάνετε κλικ στην ειδοποίηση, `↑` και `↓` για να μετακινηθείτε μεταξύ ειδοποιήσεων, `Delete` για να απορρίψετε μία και `Esc` για να επιστρέψετε το πληκτρολόγιο. Επίσης απελευθερώνεται από μόνο του μετά από μερικά δευτερόλεπτα αδράνειας.

Η σίγαση των ειδοποιήσεων τις συγκρατεί, εκτός από τις επιβεβαιώσεις του ίδιου του Omarchy, τις ειδοποιήσεις έκτακτης ανάγκης και τους κωδικούς επαλήθευσης, τους οποίους ζητήσατε πριν από λίγο. Επαναφέρετε τις τελευταίες λίγες στην οθόνη, είτε είχαν συγκρατηθεί είτε όχι, με `Super + Shift + Alt + ,`. Το ιστορικό διατηρείται για μία ημέρα.

## Ειδοποιήσεις πλήκτρων συντόμευσης

### Ημερομηνία & Ώρα

`Super + Ctrl + Alt + T`

 ![notice-datetime](images/notice-datetime.webp)

### Καιρός

`Super + Ctrl + Alt + W`

 ![notice-weather](images/notice-weather.webp)

Η τοποθεσία εντοπίζεται από τη διεύθυνση IP σας, κάτι που συνήθως είναι αρκετά ακριβές, αλλά όχι πάντα. Μπορείτε να την ορίσετε με ακρίβεια με `omarchy weather location --set Malibu`, ή να είστε ακριβείς προσθέτοντας συντεταγμένες: `omarchy weather location --set Malibu 34.0259,-118.7798`. Εκτελέστε `omarchy weather location` από μόνο του για να δείτε πού νομίζει ότι βρίσκεστε, και `--clear` για να επιστρέψετε στον αυτόματο εντοπισμό.
