# Ενοποιημένο Πρόχειρο & Ιστορικό

Συνήθως στο Linux, χρειάζεστε `Ctrl + Shift + C/V` για αντιγραφή κι επικόλληση στο τερματικό και `Ctrl + C/V` για να το κάνετε παντού αλλού. Αυτό είναι δύσκολο να το συνηθίσει οποιοσδήποτε δεν έχει γεννηθεί και μεγαλώσει με το Linux! Το ίδιο ισχύει και για τη μετάβαση από το super στο ctrl, αν έρχεστε από το Mac.

Το Omarchy αντιμετωπίζει και τα δύο προβλήματα με ενοποιημένα πλήκτρα συντόμευσης προχείρου που λειτουργούν (σχεδόν) παντού. Είναι τα εξής:

| Πλήκτρο συντόμευσης | Εντολή |
| ------- | ----------- |
| Super + A | Επιλογή όλων |
| Super + C | Αντιγραφή |
| Super + X | Αποκοπή |
| Super + V | Επικόλληση |
| Super + Ctrl + V | Ιστορικό προχείρου |

_Σημειώστε ότι τα περισσότερα agent harnesses θα χρησιμοποιήσουν `Ctrl + V` για την επικόλληση εικόνων, αλλά `Super + V` για την επικόλληση κειμένου._

Χρησιμοποιήστε `Super + A` και στη συνέχεια `Super + C` για να αντιγράψετε τα πάντα σε ένα εστιασμένο πεδίο κειμένου ή σε άλλη εφαρμογή που υποστηρίζει `Ctrl + A`. Σε ένα τερματικό, το `Ctrl + A` μετακινεί στην αρχή της γραμμής εντολών αντί να επιλέγει το κείμενό της.

### Ιστορικό προχείρου

Το ιστορικό προχείρου παρέχεται από το κέλυφος του Omarchy και λειτουργεί τόσο για κείμενο όσο και για εικόνες. Το ενεργοποιείτε με `Super + Ctrl + V`, επιλέγετε την καταχώρισή σας με return, και στη συνέχεια αυτή θα τοποθετηθεί στο πρόχειρο έτοιμη για επικόλληση με `Super + V`.
