# Ενιαίο Πρόχειρο & Ιστορικό

Συνήθως στο Linux, χρειάζεστε το `Ctrl + Shift + C/V` για αντιγραφή και επικόλληση στο τερματικό και το `Ctrl + C/V` για να το κάνετε παντού αλλού. Αυτό είναι δύσκολο να το συνηθίσει όποιος δεν έχει γεννηθεί και μεγαλώσει με Linux! Το ίδιο ισχύει και για τη μετάβαση από το super στο ctrl, αν έρχεστε από Mac.

Το Omarchy αντιμετωπίζει και τα δύο προβλήματα με ενοποιημένες συντομεύσεις πληκτρολογίου για το πρόχειρο που λειτουργούν (σχεδόν) παντού. Είναι οι εξής:

| Hotkey | Command |
| ------- | ----------- |
| Super + A | Επιλογή όλων |
| Super + C | Αντιγραφή |
| Super + X | Αποκοπή |
| Super + V | Επικόλληση |
| Super + Ctrl + V | Ιστορικό προχείρου |

_Σημειώστε ότι τα περισσότερα agent harnesses θα χρησιμοποιούν το `Ctrl + V` για την επικόλληση εικόνων, αλλά το `Super + V` για την επικόλληση κειμένου._

Χρησιμοποιήστε το `Super + A` και στη συνέχεια το `Super + C` για να αντιγράψετε τα πάντα σε ένα εστιασμένο πεδίο κειμένου ή σε άλλη εφαρμογή που υποστηρίζει το `Ctrl + A`. Σε ένα τερματικό, το `Ctrl + A` μετακινεί στην αρχή της γραμμής εντολών αντί να επιλέγει το κείμενό της.

### Ιστορικό προχείρου

Το ιστορικό προχείρου παρέχεται από το Omarchy shell και λειτουργεί τόσο για κείμενο όσο και για εικόνες. Το ενεργοποιείτε με το `Super + Ctrl + V` και επιλέγετε την καταχώρισή σας με return, το οποίο την επικολλά απευθείας στην εφαρμογή στην οποία βρισκόσασταν. Χρησιμοποιήστε το `Shift + Return` για να την αντιγράψετε μόνο στο πρόχειρο, το `Alt + Return` για να την ανοίξετε, το `Delete` για να την αφαιρέσετε από το ιστορικό και το `Shift + Delete` για να διαγράψετε ολόκληρο το ιστορικό.
