# Ενοποιημένο πρόχειρο & Ιστορικό

Συνήθως στο Linux, χρειάζεσαι `Ctrl + Shift + C/V` για αντιγραφή και επικόλληση στο τερματικό και `Ctrl + C/V` για να το κάνεις παντού αλλού. Αυτό είναι δύσκολο να το συνηθίσει όποιος δεν γεννήθηκε και δεν μεγάλωσε στο Linux! Το ίδιο ισχύει για την αλλαγή από super σε ctrl, αν έρχεσαι από το Mac.

Το Omarchy αντιμετωπίζει και τα δύο προβλήματα με ενοποιημένες συντομεύσεις προχείρου που δουλεύουν (σχεδόν) παντού. Είναι:

| Συντόμευση | Εντολή |
| ------- | ----------- |
| Super + C | Αντιγραφή |
| Super + X | Αποκοπή |
| Super + V | Επικόλληση |
| Super + Ctrl + V | Ιστορικό προχείρου |

_Σημείωσε ότι τα περισσότερα περιβάλλοντα πρακτόρων θα χρησιμοποιούν `Ctrl + V` για επικόλληση εικόνων, αλλά `Super + V` για επικόλληση κειμένου._

### Ιστορικό προχείρου

Το ιστορικό προχείρου παρέχεται από το shell του Omarchy και δουλεύει τόσο για κείμενο όσο και για εικόνες. Το ενεργοποιείς με `Super + Ctrl + V`, επιλέγεις την καταχώρησή σου με return, και μετά αυτή θα τοποθετηθεί στο πρόχειρο έτοιμη για επικόλληση με `Super + V`.
