# Windows VM

Το Omarchy προσφέρει έναν εύκολο τρόπο να τρέχεις τα Windows μέσω ενός Docker VM σε μηχανήματα x86_64. Μπορείς να το εγκαταστήσεις από το _Install > Windows_ στο μενού του Omarchy (`Super + Space`).

Το μηχάνημά σου χρειάζεται εικονικοποίηση KVM για αυτό, και τα περισσότερα την έχουν — αλλά μερικές φορές είναι απενεργοποιημένη στο BIOS, και ο εγκαταστάτης θα σου το πει αν συμβαίνει αυτό. Θα χρειαστείς επίσης χώρο στον δίσκο: όσο δώσεις στα Windows, συν περίπου 10GB για την ίδια την εικόνα.

Ο εγκαταστάτης ρωτά πόση RAM, πόσους πυρήνες CPU και πόσο χώρο στον δίσκο θέλεις να παραχωρήσεις (τα 64GB ή περισσότερα είναι το λογικό ελάχιστο), και μετά ένα όνομα χρήστη και έναν κωδικό πρόσβασης για τα Windows. Άφησέ τα κενά και παίρνεις `docker` / `admin`. Η λήψη παίρνει ώρα — τα 10-15 λεπτά είναι φυσιολογικά — και μπορείς να παρακολουθείς την πρόοδο στον browser στη διεύθυνση `http://127.0.0.1:8006`. Ο browser ζητά το ίδιο όνομα χρήστη και τον ίδιο κωδικό πρόσβασης πριν ανοίξει την κονσόλα.

## Χρήση

Μόλις εγκατασταθεί, εκκίνησε το _Windows_ από τον εκκινητή εφαρμογών. Αυτό ξεκινά το VM αν δεν τρέχει ήδη και σε συνδέει μέσω RDP, σε πλήρη οθόνη. Δώσε του 15-30 δευτερόλεπτα σε ψυχρή εκκίνηση.

Η συνεδρία RDP μεταφέρει ήχο, το μικρόφωνό σου και ένα κοινόχρηστο πρόχειρο, οπότε η αντιγραφή κειμένου ανάμεσα σε Linux και Windows απλώς δουλεύει. Η ανάλυση ακολουθεί το παράθυρό σου, και το Omarchy περνά την κλιμάκωση της οθόνης σου, οπότε δεν είναι ένα θολό χάλι σε οθόνη HiDPI.

Όταν κλείνεις το παράθυρο RDP, το VM τερματίζεται αυτόματα. Αν προτιμάς να το αφήσεις να τρέχει — πες ότι έχεις κάτι που δουλεύει εκεί μέσα — εκκίνησέ το με `omarchy windows vm launch --keep-alive` αντί γι' αυτό.

Οι υπόλοιποι έλεγχοι βρίσκονται στην ίδια εντολή:

```bash
omarchy windows vm status    # is it running?
omarchy windows vm stop      # shut it down
omarchy windows vm launch    # start and connect
```

## Κοινή χρήση αρχείων

Ο κατάλογος `~/Windows` στον αρχικό σου κατάλογο μοιράζεται αυτόματα με το VM. Βάλε αρχεία εκεί αν θέλεις να είναι προσβάσιμα στα Windows. Το VM δεν έχει πρόσβαση σε κανένα άλλο μέρος του συστήματος αρχείων σου, οπότε είσαι ασφαλής από οτιδήποτε κακόβουλο στην πλευρά των Windows. Ο δικός του εικονικός δίσκος είναι διαθέσιμος στο `~/.windows`.

Αυτές οι γνώριμες διαδρομές του αρχικού καταλόγου παραμένουν στα δικά τους συστήματα αρχείων. Μπορούν επίσης να είναι symlinks προς καταλόγους που σου ανήκουν, κάτι χρήσιμο όταν ο εικονικός δίσκος βρίσκεται σε μεγαλύτερη μονάδα. Ο εγκαταστάτης μετρά τον ελεύθερο χώρο στο σύστημα αρχείων που περιέχει πραγματικά το `~/.windows`, όχι απαραίτητα στο σύστημα αρχείων που περιέχει τον αρχικό σου κατάλογο.

Κράτα τις διαδρομές του δίσκου και των κοινόχρηστων αρχείων ως ξεχωριστούς, μη επικαλυπτόμενους καταλόγους. Η αφαίρεση αδειάζει σκόπιμα τον κατάλογο του δίσκου αλλά διατηρεί τον κοινόχρηστο κατάλογο. Αμέσως πριν τη διαγραφή, το Omarchy εκτελεί έναν έλεγχο περιορισμού με χρονικό όριο και αρνείται να αφαιρέσει οτιδήποτε αν αυτός ο έλεγχος λήξει ή δεν μπορεί να αποδείξει ότι τα δύο δέντρα είναι ξεχωριστά.

Πριν ξεκινήσει το VM, το Omarchy ανοίγει και καρφιτσώνει αυτούς τους δύο καταλόγους, και στη συνέχεια προσαρτά μέσω bind mount τα ακριβή inode των καταλόγων σε ιδιωτικές αγκυρώσεις ανά χρήστη κάτω από το `/var/lib/omarchy/windows/mounts`. Το Docker βλέπει μόνο αυτές τις αγκυρώσεις που προστατεύονται από τον root. Έτσι διατηρούνται οι προσαρμοσμένες θέσεις δίσκου, ενώ εμποδίζεται μια άλλη διεργασία που τρέχει ως εσύ να ανταλλάξει μια ελεγμένη διαδρομή πριν την καταναλώσει το προνομιούχο container. Οι υπάρχοντες κατάλογοι δίσκου και κοινόχρηστων αρχείων σφίγγονται σε mode `0700` κατά τη μετεγκατάσταση, ώστε άλλοι τοπικοί λογαριασμοί να μην μπορούν να περιηγηθούν στα περιεχόμενά τους.

Οι θύρες του VM δεσμεύονται μόνο στο localhost, οπότε τίποτα στο δίκτυό σου δεν μπορεί να φτάσει το μηχάνημα Windows. Η κονσόλα web απαιτεί επίσης το ρυθμισμένο όνομα χρήστη και τον κωδικό πρόσβασης των Windows, εμποδίζοντας έναν άλλον τοπικό λογαριασμό να οδηγήσει το VM μέσω της θύρας 8006.

## Περιορισμοί και αδειοδότηση

Δεν υπάρχει GPU passthrough με αυτή τη ρύθμιση, οπότε δεν είναι κατάλληλο για gaming ή επεξεργασία βίντεο. Είναι ένας εξαιρετικός τρόπος να τρέχεις το Microsoft Office ή οτιδήποτε άλλο πρέπει οπωσδήποτε να έχεις.

Η έκδοση που εγκαθίσταται είναι τα Windows 11 Pro, μη ενεργοποιημένη. Θα χρειαστείς το δικό σου κλειδί άδειας για να χρησιμοποιήσεις τις λειτουργίες που απαιτούν ενεργοποίηση.

Αν αυτός ο υπολογιστής παραδόθηκε με Windows, το κλειδί OEM βρίσκεται ακόμα στο firmware ακόμη και μετά την εγκατάσταση του Omarchy. Εκτύπωσέ το με `omarchy windows key`. Αυτό το κλειδί είναι δεσμευμένο σε αυτό το μηχάνημα — θα ενεργοποιήσει τα Windows που επανεγκαθίστανται σε αυτό το hardware, αλλά συνήθως δεν θα ενεργοποιήσει το VM.

Μπορείς να αλλάξεις την κατανομή πόρων αργότερα εκτελώντας `omarchy windows vm install` σε ένα τερματικό, το οποίο ξαναγράφει τη διαμόρφωση του VM από τις απαντήσεις σου. Το ίδιο το αρχείο compose ζει πλέον στο `/var/lib/omarchy/windows/docker-compose.yml` και ανήκει στον root — αυτό είναι σκόπιμο, ώστε μια διεργασία που τρέχει ως εσύ να μην μπορεί να το ξαναγράψει και να κάνει το προνομιούχο bring-up να προσαρτήσει ολόκληρο τον δίσκο σου μέσα στο container. Αν χρειαστεί να το επεξεργαστείς χειροκίνητα (για παράδειγμα για να προσαρτήσεις μια συσκευή USB), επεξεργάσου το με `sudo` και δες όλες τις επιλογές στο [project Dockur Windows](https://github.com/dockur/windows).

Για να ξεφορτωθείς όλο το πράγμα, χρησιμοποίησε το _Remove > Windows_ από το μενού του Omarchy. Αυτό διαγράφει τον δίσκο του VM στο `~/.windows` και όλα όσα είναι εγκατεστημένα μέσα στα Windows, οπότε αντίγραψε πρώτα έξω από το VM οτιδήποτε χρειάζεσαι. Ο κοινόχρηστος φάκελός σου `~/Windows` μένει ανέπαφος.
