# Αντιμετώπιση προβλημάτων

### Χάλασα το σύστημά μου με μια ενημέρωση!

Πρώτα δοκίμασε να [επαναφέρεις το σύστημά σου](47-system-snapshots.md) στην έκδοση πριν από την πρόσφατη ενημέρωσή σου. Αν αυτό δεν δουλέψει, χρησιμοποίησε `omarchy-debug` για να μοιραστείς το πρόβλημά σου στο #omarchy-help στο Discord. Και αν όλα αυτά αποτύχουν, μπορείς να επανεγκαταστήσεις τις προεπιλεγμένες διαμορφώσεις και πακέτα χρησιμοποιώντας `omarchy-reinstall`.

### Γιατί μερικές εφαρμογές είναι τόσο μεγάλες στην οθόνη μου;

Το Omarchy υποθέτει μια οθόνη υψηλής ανάλυσης 2x, που απαιτεί τον ορισμό `GDK_SCALE` σε 2 στο `~/.config/hypr/monitors.lua`. Αλλά αν είσαι σε οθόνη 1x, μπορείς να αλλάξεις το `local omarchy_gdk_scale = 2` σε 1 (και μετά να επανεκκινήσεις οποιαδήποτε υπερμεγέθη εφαρμογή). Δες [το εγχειρίδιο για τις οθόνες](33-monitors.md).

Για το Spotify, μπορείς να χρησιμοποιήσεις `Ctrl + Minus` για να συρρικνώσεις το UI (και `Ctrl + Plus` για να το μεγαλώσεις).

### Το Wi-Fi, Bluetooth, ο ήχος ή η επιφάνεια αφής μου σταμάτησε απλώς να δουλεύει

Πριν κάνεις επανεκκίνηση, δοκίμασε να επανεκκινήσεις το προβληματικό υποσύστημα μόνο του. Το _Ενημέρωση > Υλικό_ στο μενού Omarchy έχει Wi-Fi, Bluetooth, Ήχο και Επιφάνεια αφής, και η επαναφόρτωση ενός από αυτά ξεκαθαρίζει την πλειονότητα των καταστάσεων «δούλευε πριν από πέντε λεπτά» — ένα ακουστικό Bluetooth που δεν επανασυνδέεται, μια επιφάνεια αφής που νεκρώθηκε μετά από αναστολή, ήχος που εξαφανίστηκε όταν αποσύνδεσες μια οθόνη.

### Γιατί τα εξωτερικά ηχεία μου δεν παίζουν;

Πιθανώς επειδή δεν είναι ορισμένα ως η κύρια έξοδος. Κάνε κλικ στο εικονίδιο ηχείου στη δεξιά πλευρά της γραμμής, και θα ανοίξει το αναδυόμενο παράθυρο έντασης όπου μπορείς να διαλέξεις τη συσκευή εξόδου (και να αναμίξεις εντάσεις ανά εφαρμογή επίσης).

### Τα ηχεία του φορητού μου ακούγονται περίεργα

Σε μερικούς φορητούς, το Omarchy εφαρμόζει αυτόματα μια ρύθμιση ηχείων που διορθώνει την απόκριση συχνότητας των ενσωματωμένων ηχείων. Η `omarchy audio tuning status` σου λέει αν υπάρχει ενεργή μία στο μηχάνημά σου, και η `omarchy audio tuning off` την απενεργοποιεί αν προτιμάς να ακούς τα ηχεία ακατέργαστα.

### Γιατί δεν μπορώ να συνδεθώ ή να κάνω sudo με τον κωδικό μου;

Πιθανώς τον πληκτρολόγησες λάθος πάρα πολλές φορές και κλειδώθηκες έξω. Αν αυτό συμβαίνει στην οθόνη κλειδώματος, μπορείς να πατήσεις `CTRL + ALT + F2` για να ξεκινήσεις ένα νέο TTY όπου μπορείς να συνδεθείς ως root, μετά να τρέξεις `faillock --reset --user [your-username]`. Αυτό θα επαναφέρει το κλείδωμα, και είσαι έτοιμος.

### Γιατί δεν εμφανίζονται οι προτροπές εξουσιοδότησης 1Password για τον 1Password SSH Agent / CLI;

Αυτό μπορεί να συμβεί για 2 λόγους:

Για να εμφανιστεί η πλούσια προτροπή έγκρισης, το Settings > Advanced > Use Hardware Acceleration πρέπει να είναι ενεργοποιημένο. _Σημείωση: Αυτό απαιτεί επανεκκίνηση για να αρχίσει να δουλεύει._

 ![troubleshooting-1password](images/troubleshooting-1password.webp)

Ή αν δεν έχεις εκκινήσει το 1Password από την εκκίνηση, η προτροπή δεν θα εμφανιστεί.
