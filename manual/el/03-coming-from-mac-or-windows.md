# Ερχόμενοι από Mac ή Windows

Αν έχετε περάσει χρόνια σε macOS ή Windows, τα δάχτυλά σας ξέρουν εκατό πράγματα που ο εγκέφαλός σας έχει ξεχάσει ότι έμαθε ποτέ. Αυτό το κεφάλαιο είναι το στρώμα μετάφρασης: πού πηγαίνουν αυτά τα ένστικτα στο Omarchy. Οι ίδιες οι λειτουργίες καλύπτονται σε βάθος αλλού — αυτός είναι απλώς ο χάρτης.

### Το Super είναι το κέντρο των πάντων

Όλη η μυϊκή μνήμη που έχετε χτίσει γύρω από το Cmd ή το πλήκτρο των Windows μεταφέρεται σε ένα πλήκτρο: το Super. Αυτό είναι το πλήκτρο των Windows σε ένα πληκτρολόγιο PC, και είναι η άγκυρα για σχεδόν κάθε hotkey στο Omarchy.

Το αντανακλαστικό σας για Spotlight ή Raycast ή μενού Start γίνεται `Super + Space`. Αυτό ανοίγει το μενού Omarchy, το οποίο εκκινεί εφαρμογές, αλλάζει ρυθμίσεις, εγκαθιστά λογισμικό, καταγράφει την οθόνη — σχεδόν τα πάντα. Αρχίστε να πληκτρολογείτε για να φιλτράρετε. Το `Super + Alt + Space` δείχνει κάθε εφαρμογή σε ένα πλέγμα, όπως κάνει το Launchpad. Δείτε [πλοήγηση](04-navigation.md).

### Δεν υπάρχει dock ούτε εικονίδια επιφάνειας εργασίας

Τίποτα για κλικ για να εκκινήσετε πράγματα, κανένα εικονίδιο για τακτοποίηση στην επιφάνεια εργασίας. Οι εφαρμογές ξεκινούν από ένα hotkey (`Super + Return` για το τερματικό, `Super + Shift + Return` για τον browser, και `Super + K` για μια λίστα με όλα όσα έχουν αντιστοιχιστεί) ή από το μενού. Το μόνο μόνιμο στοιχείο UI είναι [η επάνω μπάρα](05-the-top-bar.md), η οποία καλύπτει ό,τι έκανε για εσάς πριν η μπάρα μενού, το system tray και το Notification Center — και σχεδόν κάθε widget πάνω της κάνει κάτι με αριστερό, δεξί και μεσαίο κλικ.

### Τα παράθυρα τοποθετούνται μόνα τους

Η μεγαλύτερη αλλαγή νοοτροπίας: δεν σέρνετε παράθυρα εδώ κι εκεί ούτε τα κουμπώνετε σε μισές οθόνες. Ανοίξτε ένα παράθυρο και καταλαμβάνει όλη την οθόνη. Ανοίξτε ένα δεύτερο και μοιράζονται την οθόνη. Δεν ψαρεύετε ποτέ ένα παράθυρο κάτω από ένα άλλο, επειδή τα παράθυρα δεν επικαλύπτονται.

Όταν χρειάζεστε πραγματικά ένα αιωρούμενο παράθυρο, το `Super + T` βγάζει το ενεργό από το tiling (και το επαναφέρει). Αλλά δώστε πρώτα στο tiling μια πραγματική ευκαιρία — είναι η καρδιά όλου του πράγματος. Η [Πλοήγηση](04-navigation.md) σας ξεναγεί σε αυτό.

Οι χώροι εργασίας θα σας φανούν οικείοι: είναι τα macOS Spaces ή οι εικονικές επιφάνειες εργασίας των Windows, με τη διαφορά ότι θα τους χρησιμοποιείτε πραγματικά, επειδή το `Super + 1/2/3/4` πηγαίνει κατευθείαν σε έναν και το `Super + Shift + 1/2/3/4` στέλνει εκεί το ενεργό παράθυρο. Χωρίς καθυστέρηση animation, μόνο στιγμιαία άλματα. Αυτό σημαίνει ότι μπορεί να μη χρειάζεστε καν πολλαπλές οθόνες, αν το είχατε συνηθίσει αυτό πριν.

### Η αντιγραφή και η επικόλληση απλώς λειτουργούν

Στο Mac είχατε Cmd + C παντού. Στα Windows είχατε Ctrl + C παντού — εκτός από το τερματικό, όπου τερματίζει το πρόγραμμά σας. Το Omarchy σας δίνει `Super + C`, `Super + X` και `Super + V`, και λειτουργούν παντού, συμπεριλαμβανομένου του τερματικού. Δεν υπάρχει ξεχωριστό αντανακλαστικό να μάθετε για το shell.

Εσείς των Windows: το ιστορικό προχείρου σας με Win + V ζει στο `Super + Ctrl + V`, και κρατάει εικόνες καθώς και κείμενο. Δείτε [ενοποιημένο πρόχειρο & ιστορικό](08-unified-clipboard-history.md).

### Ο πίνακας μετάφρασης

| Αναζητάτε | Στο Omarchy |
| ------------- | ---------- |
| Spotlight / Raycast / μενού Start | `Super + Space` — το μενού Omarchy |
| AirDrop | LocalSend, μέσω `Super + Ctrl + S` — δείτε [τα GUI](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` ή `Print Screen` — δείτε [στιγμιότυπα οθόνης & εγγραφή](12-screenshots-recording.md) |
| Notification Center | Ιστορικό ειδοποιήσεων στο `Super + Shift + Alt + ,` |
| Time Machine (για το σύστημα) | Αυτόματα [στιγμιότυπα συστήματος](47-system-snapshots.md) σε κάθε ενημέρωση |
| App Store / λήψη ενός installer | _Install_ στο μενού, ή `omarchy pkg add` — δείτε [άλλα πακέτα](29-other-packages.md) |
| System Settings / Control Panel | _Setup_ στο μενού, το οποίο επεξεργάζεται απλά αρχεία ρυθμίσεων — δείτε [dotfiles](31-dotfiles.md) |

### Μερικά πράγματα είναι όντως διαφορετικά

Πολλές ρυθμίσεις ζουν σε αρχεία κειμένου που επεξεργάζεστε, όχι σε πάνελ στα οποία κάνετε κλικ. Αυτό ακούγεται πρωτόγονο μέχρι να συνειδητοποιήσετε ότι σημαίνει πως κάθε ρύθμιση μπορεί να ιδωθεί, να αντιγραφεί στο επόμενο μηχάνημά σας και να μπει σε version control. Το μενού _Setup_ σας ρίχνει κατευθείαν στο σωστό αρχείο και επανεκκινεί ό,τι χρειάζεται επανεκκίνηση όταν τελειώσετε.

Οι ενημερώσεις έρχονται μέσω μίας εντολής — _Update > Omarchy_ — που ενημερώνει το ίδιο το Omarchy και κάθε πακέτο στο σύστημα, παίρνοντας πρώτα ένα στιγμιότυπο. Κανένα updater ανά εφαρμογή να σας ενοχλεί σε τυχαίες στιγμές. Δείτε [ενημερώσεις](30-updates.md).

Το λογισμικό προέρχεται από έναν package manager, όχι από installers που κατεβάζετε.

Και όταν κλείνετε ένα παράθυρο, η εφαρμογή τερματίζεται πραγματικά. Δεν υπάρχει το μετέωρο στάδιο του macOS όπου το πρόγραμμα συνεχίζει να τρέχει χωρίς παράθυρα. Το `Super + W` — ή το `Super + Q`, αν αυτή είναι η μνήμη των δαχτύλων με την οποία φτάσατε — σημαίνει εξαφανίστηκε.

### Σε hardware Mac

Το Omarchy τρέχει καλά σε Intel Macs — δείτε [υποστήριξη Mac](44-mac-support.md). Και το πληκτρολόγιο είναι ευγενικό μαζί σας: το Omarchy δεν επαναντιστοιχίζει τίποτα, και το Linux αντιμετωπίζει το πλήκτρο Command ως Super, οπότε το Super βρίσκεται ακριβώς εκεί που ήταν πάντα το Cmd. Ο αντίχειράς σας δεν θα προσέξει τη μετακίνηση.

### Δώστε του δύο εβδομάδες

Τα ένστικτα μεταφέρονται πιο γρήγορα απ' όσο θα νομίζατε. Ξεφυλλίστε το κεφάλαιο [hotkeys](07-hotkeys.md) μία φορά, και όποτε κολλάτε σε μια αντιστοίχιση, πατήστε `Super + K` — σας δείχνει όλες. Αυτό είναι το μόνο hotkey που πρέπει πραγματικά να απομνημονεύσετε.
