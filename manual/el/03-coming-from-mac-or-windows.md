# Έρχεσαι από Mac ή Windows

Αν έχεις περάσει χρόνια στο macOS ή στα Windows, τα δάχτυλά σου ξέρουν εκατό πράγματα που το μυαλό σου έχει ξεχάσει ότι έμαθε ποτέ. Αυτό το κεφάλαιο είναι το επίπεδο μετάφρασης: πού πάνε αυτά τα ένστικτα στο Omarchy. Οι ίδιες οι λειτουργίες καλύπτονται σε βάθος αλλού — αυτό είναι απλώς ο χάρτης.

### Το Super είναι το κέντρο των πάντων

Όλη η μυϊκή μνήμη που έχτισες γύρω από το Cmd ή το πλήκτρο Windows μεταφέρεται σε ένα πλήκτρο: το Super. Αυτό είναι το πλήκτρο Windows σε ένα πληκτρολόγιο PC, και είναι η άγκυρα για σχεδόν κάθε συντόμευση στο Omarchy.

Το αντανακλαστικό σου για Spotlight ή Raycast ή μενού Start γίνεται `Super + Space`. Αυτό ανοίγει το μενού Omarchy, που εκκινεί εφαρμογές, αλλάζει ρυθμίσεις, εγκαθιστά λογισμικό, καταγράφει την οθόνη — σχεδόν τα πάντα. Άρχισε να πληκτρολογείς για φιλτράρισμα. Το `Super + Alt + Space` δείχνει κάθε εφαρμογή σε ένα πλέγμα, όπως κάνει το Launchpad. Δες [πλοήγηση](04-navigation.md).

### Δεν υπάρχει dock ούτε εικονίδια επιφάνειας εργασίας

Τίποτα για κλικ ώστε να εκκινείς πράγματα, κανένα εικονίδιο για τακτοποίηση στην επιφάνεια εργασίας. Οι εφαρμογές ξεκινούν από μια συντόμευση (`Super + Return` για το τερματικό, `Super + Shift + Return` για τον φυλλομετρητή, και `Super + K` για μια λίστα με όλα όσα είναι χαρτογραφημένα) ή από το μενού. Το ένα μόνιμο κομμάτι του UI είναι [την πάνω γραμμή](05-the-top-bar.md), που καλύπτει ό,τι έκαναν για σένα πριν η γραμμή μενού, ο δίσκος συστήματος και το Notification Center — και σχεδόν κάθε widget σε αυτή κάνει κάτι με αριστερό, δεξί και μεσαίο κλικ.

### Τα παράθυρα τοποθετούνται μόνα τους

Η μεγαλύτερη αλλαγή νοοτροπίας: δεν σύρεις παράθυρα ούτε τα κουμπώνεις σε μισές οθόνες. Ανοίγεις ένα παράθυρο και καταλαμβάνει ολόκληρη την οθόνη. Ανοίγεις ένα δεύτερο και την μοιράζονται. Ποτέ δεν ψαρεύεις ένα παράθυρο κάτω από ένα άλλο, γιατί τα παράθυρα δεν επικαλύπτονται.

Όταν πραγματικά χρειάζεσαι ένα αιωρούμενο παράθυρο, το `Super + T` εναλλάσσει το ενεργό έξω από το tiling (και πάλι πίσω). Αλλά δώσε πρώτα μια πραγματική ευκαιρία στο tiling — είναι η καρδιά όλου αυτού. Η [Πλοήγηση](04-navigation.md) σε καθοδηγεί μέσα σε αυτό.

Οι χώροι εργασίας θα σου φανούν οικείοι: είναι τα Spaces του macOS ή τα εικονικά desktop των Windows, μόνο που πράγματι θα τα χρησιμοποιείς, γιατί το `Super + 1/2/3/4` πηδά κατευθείαν σε έναν και το `Super + Shift + 1/2/3/4` στέλνει το ενεργό παράθυρο εκεί. Καμία καθυστέρηση κίνησης, μόνο άμεσα άλματα. Αυτό σημαίνει ότι ίσως να μην χρειάζεσαι καν πολλαπλές οθόνες, αν το είχες συνηθίσει πριν.

### Η αντιγραφή και η επικόλληση απλώς δουλεύουν

Στο Mac είχες Cmd + C παντού. Στα Windows είχες Ctrl + C παντού — εκτός από το τερματικό, όπου σκοτώνει το πρόγραμμά σου. Το Omarchy σου δίνει `Super + C`, `Super + X`, και `Super + V`, και δουλεύουν παντού, συμπεριλαμβανομένου του τερματικού. Κανένα ξεχωριστό αντανακλαστικό να μάθεις για το shell.

Εσείς των Windows: το ιστορικό προχείρου του Win + V ζει στο `Super + Ctrl + V`, και κρατάει εικόνες αλλά και κείμενο. Δες [ενοποιημένο πρόχειρο & ιστορικό](08-unified-clipboard-history.md).

### Ο πίνακας μετάφρασης

| Αναζητάς | Στο Omarchy |
| ------------- | ---------- |
| Spotlight / Raycast / μενού Start | `Super + Space` — το μενού Omarchy |
| AirDrop | LocalSend, μέσω `Super + Ctrl + S` — δες [GUIs](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Print Screen` — δες [στιγμιότυπα & εγγραφή](12-screenshots-recording.md) |
| Notification Center | Ιστορικό ειδοποιήσεων στο `Super + Shift + Alt + ,` |
| Time Machine (για το σύστημα) | Αυτόματα [στιγμιότυπα συστήματος](47-system-snapshots.md) σε κάθε ενημέρωση |
| App Store / κατέβασμα εγκαταστάτη | _Εγκατάσταση_ στο μενού, ή `omarchy pkg add` — δες [άλλα πακέτα](29-other-packages.md) |
| System Settings / Control Panel | _Ρύθμιση_ στο μενού, που επεξεργάζεται απλά αρχεία config — δες [dotfiles](31-dotfiles.md) |

### Μερικά πράγματα είναι όντως διαφορετικά

Πολλές ρυθμίσεις ζουν σε αρχεία κειμένου που επεξεργάζεσαι, όχι σε πάνελ που διασχίζεις με κλικ. Αυτό ακούγεται πρωτόγονο μέχρι να συνειδητοποιήσεις ότι σημαίνει πως κάθε τσίμπημα μπορεί να φανεί, να αντιγραφεί στο επόμενο μηχάνημά σου και να μπει σε σύστημα ελέγχου εκδόσεων. Το μενού _Ρύθμιση_ σε ρίχνει κατευθείαν στο σωστό αρχείο και επανεκκινεί ό,τι χρειάζεται επανεκκίνηση όταν τελειώσεις.

Οι ενημερώσεις έρχονται μέσω μιας εντολής — _Ενημέρωση > Omarchy_ — που ενημερώνει το ίδιο το Omarchy και κάθε πακέτο στο σύστημα, παίρνοντας πρώτα ένα στιγμιότυπο. Κανένας ενημερωτής ανά εφαρμογή να σε ενοχλεί τυχαία. Δες [ενημερώσεις](30-updates.md).

Το λογισμικό έρχεται από έναν διαχειριστή πακέτων, όχι από κατεβασμένους εγκαταστάτες.

Και όταν κλείνεις ένα παράθυρο, η εφαρμογή πραγματικά τερματίζεται. Δεν υπάρχει το limbo του macOS όπου το πρόγραμμα συνεχίζει να τρέχει χωρίς παράθυρα. Το `Super + W` — ή το `Super + Q`, αν αυτή είναι η μνήμη δαχτύλου με την οποία ήρθες — σημαίνει έφυγε.

### Σε υλικό Mac

Το Omarchy τρέχει καλά σε Mac με Intel — δες [υποστήριξη Mac](44-mac-support.md). Και το πληκτρολόγιο είναι ευγενικό μαζί σου: το Omarchy δεν επαναχαρτογραφεί τίποτα, και το Linux αντιμετωπίζει το πλήκτρο Command ως Super, οπότε το Super κάθεται ακριβώς εκεί που ήταν πάντα το Cmd. Ο αντίχειράς σου δεν θα παρατηρήσει τη μετακίνηση.

### Δώσ' του δύο εβδομάδες

Τα ένστικτα μεταφέρονται πιο γρήγορα απ' ό,τι νομίζεις. Ρίξε μια ματιά στο κεφάλαιο για τις [συντομεύσεις](07-hotkeys.md) μία φορά, και κάθε φορά που κολλάς σε μια αντιστοίχιση, πάτησε `Super + K` — σου τις δείχνει όλες. Αυτή είναι η μόνη συντόμευση που πραγματικά πρέπει να απομνημονεύσεις.
