# Προερχόμενοι από Mac ή Windows

Αν έχεις περάσει χρόνια σε macOS ή Windows, τα δάχτυλά σου ξέρουν εκατό πράγματα που ο εγκέφαλός σου έχει ξεχάσει ότι έμαθε ποτέ. Αυτό το κεφάλαιο είναι το επίπεδο μετάφρασης: πού πάνε αυτά τα ένστικτα στο Omarchy. Οι ίδιες οι λειτουργίες καλύπτονται σε βάθος αλλού — αυτός είναι απλώς ο χάρτης.

### Το Super είναι το κέντρο των πάντων

Όλη η μυϊκή μνήμη που έχεις χτίσει γύρω από το Cmd ή το πλήκτρο των Windows μεταφέρεται σε ένα πλήκτρο: το Super. Αυτό είναι το πλήκτρο των Windows σε ένα πληκτρολόγιο PC, και είναι η άγκυρα για σχεδόν κάθε συντόμευση στο Omarchy.

Το αντανακλαστικό σου για Spotlight ή Raycast ή το μενού Έναρξης γίνεται `Super + Space`. Αυτό ανοίγει το μενού του Omarchy, το οποίο εκκινεί εφαρμογές, αλλάζει ρυθμίσεις, εγκαθιστά λογισμικό, καταγράφει την οθόνη — σχεδόν τα πάντα. Ξεκίνα να πληκτρολογείς για να φιλτράρεις. Το `Super + Alt + Space` δείχνει κάθε εφαρμογή σε ένα πλέγμα, όπως κάνει το Launchpad. Δες την [πλοήγηση](04-navigation.md).

### Χωρίς εικονίδια στην επιφάνεια εργασίας, και το dock εμφανίζεται μόνο όταν αιωρείσαι

Κανένα εικονίδιο για τακτοποίηση στην επιφάνεια εργασίας, και κανένα dock σε έναν χώρο εργασίας με πλακίδια — το dock εμφανίζεται μόνο σε έναν αιωρούμενο χώρο εργασίας (δες την [πλοήγηση](04-navigation.md)). Οι εφαρμογές ξεκινούν από μια συντόμευση (`Super + Return` για το τερματικό, `Super + Shift + Return` για τον περιηγητή, και `Super + K` για μια λίστα με όλα όσα έχουν αντιστοιχιστεί) ή από το μενού. Το ένα μόνιμο κομμάτι του UI είναι [η επάνω γραμμή](05-the-top-bar.md), η οποία καλύπτει ό,τι έκαναν για εσένα πριν η γραμμή μενού, η περιοχή ειδοποιήσεων του συστήματος και το Notification Center — και σχεδόν κάθε widget πάνω της κάνει κάτι με αριστερό, δεξί και μεσαίο κλικ.

### Τα παράθυρα τοποθετούνται μόνα τους

Η μεγαλύτερη αλλαγή νοοτροπίας: δεν σέρνεις παράθυρα εδώ κι εκεί ούτε τα κουμπώνεις σε μισά της οθόνης. Άνοιξε ένα παράθυρο και καταλαμβάνει όλη την οθόνη. Άνοιξε ένα δεύτερο και μοιράζονται την οθόνη. Ποτέ δεν ψαρεύεις ένα παράθυρο κάτω από ένα άλλο, επειδή τα παράθυρα δεν επικαλύπτονται.

Όταν πραγματικά χρειάζεσαι ένα αιωρούμενο παράθυρο, το `Super + T` βγάζει το ενεργό από τη διάταξη πλακιδίων (και το επαναφέρει). Αλλά δώσε πρώτα μια πραγματική ευκαιρία στη διάταξη πλακιδίων — είναι η καρδιά όλου του πράγματος. Η [Πλοήγηση](04-navigation.md) σε καθοδηγεί σε αυτό.

Οι χώροι εργασίας θα σου φανούν οικείοι: είναι τα macOS Spaces ή οι εικονικές επιφάνειες εργασίας των Windows, μόνο που εδώ θα τους χρησιμοποιείς πραγματικά, επειδή το `Super + 1/2/3/4` σε πάει κατευθείαν σε έναν και το `Super + Shift + 1/2/3/4` στέλνει εκεί το ενεργό παράθυρο. Χωρίς καθυστέρηση κίνησης, απλώς άμεσα άλματα. Αυτό σημαίνει ότι μπορεί να μη χρειάζεσαι καν πολλές οθόνες, αν το είχες συνηθίσει αυτό πριν.

### Η αντιγραφή και η επικόλληση απλώς δουλεύουν

Στο Mac είχες Cmd + C παντού. Στα Windows είχες Ctrl + C παντού — εκτός από το τερματικό, όπου τερματίζει το πρόγραμμά σου. Το Omarchy σού δίνει `Super + C`, `Super + X` και `Super + V`, και δουλεύουν παντού, συμπεριλαμβανομένου του τερματικού. Κανένα ξεχωριστό αντανακλαστικό να μάθεις για το κέλυφος.

Εσείς που έρχεστε από τα Windows: το ιστορικό προχείρου σας με Win + V βρίσκεται στο `Super + Ctrl + V`, και κρατάει εικόνες καθώς και κείμενο. Δες το [ενοποιημένο πρόχειρο & ιστορικό](08-unified-clipboard-history.md).

### Ο πίνακας μετάφρασης

| Αυτό που ψάχνεις | Στο Omarchy |
| ------------- | ---------- |
| Spotlight / Raycast / Start menu | `Super + Space` — το μενού του Omarchy |
| AirDrop | LocalSend, μέσω `Super + Ctrl + S` — δες τα [GUIs](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` ή `Print Screen` — δες τα [στιγμιότυπα οθόνης & εγγραφή](12-screenshots-recording.md) |
| Notification Center | Ιστορικό ειδοποιήσεων στο `Super + Shift + Alt + ,` |
| Time Machine (για το σύστημα) | Αυτόματα [στιγμιότυπα συστήματος](47-system-snapshots.md) σε κάθε ενημέρωση |
| App Store / λήψη ενός προγράμματος εγκατάστασης | _Install_ στο μενού, ή `omarchy pkg add` — δες τα [άλλα πακέτα](29-other-packages.md) |
| System Settings / Control Panel | _Setup_ στο μενού, το οποίο επεξεργάζεται απλά αρχεία ρυθμίσεων — δες τα [dotfiles](31-dotfiles.md) |
| Finder / File Explorer | Files, στο `Super + Shift + F` — δες τα [GUIs](22-guis.md) |
| Safari / Edge | Google Chrome στο `Super + Shift + Return`; διάλεξε άλλο στο _Setup > Defaults > Browser_ — δες τους [περιηγητές](23-browsers.md) |
| Preview / Photos | Omaview για εικόνες, βίντεο και μουσική, Document Viewer για PDF — δες τα [GUIs](22-guis.md) |
| TextEdit / Notepad | Plain, στο `Super + Shift + N`; διάλεξε άλλο στο _Setup > Defaults > Editor_ |

### Μερικά πράγματα είναι όντως διαφορετικά

Πολλές ρυθμίσεις βρίσκονται σε αρχεία κειμένου που επεξεργάζεσαι, όχι σε πάνελ που διατρέχεις με κλικ. Αυτό ακούγεται πρωτόγονο μέχρι να συνειδητοποιήσεις ότι σημαίνει πως κάθε ρύθμιση μπορεί να ιδωθεί, να αντιγραφεί στο επόμενο μηχάνημά σου και να μπει σε σύστημα ελέγχου εκδόσεων. Το μενού _Setup_ σε ρίχνει κατευθείαν στο σωστό αρχείο και επανεκκινεί ό,τι χρειάζεται επανεκκίνηση όταν τελειώσεις.

Οι ενημερώσεις έρχονται μέσω μιας εντολής — _Update > Omarchy_ — που ενημερώνει το ίδιο το Omarchy και κάθε πακέτο στο σύστημα, παίρνοντας πρώτα ένα στιγμιότυπο. Κανένας ξεχωριστός ενημερωτής ανά εφαρμογή να σε ενοχλεί τυχαία. Δες τις [ενημερώσεις](30-updates.md).

Το λογισμικό έρχεται από έναν διαχειριστή πακέτων, όχι από ληφθέντα προγράμματα εγκατάστασης.

Και όταν κλείνεις ένα παράθυρο, η εφαρμογή τερματίζεται πραγματικά. Δεν υπάρχει το κενό του macOS όπου το πρόγραμμα συνεχίζει να τρέχει χωρίς παράθυρα. Το `Super + W` — ή το `Super + Q`, αν αυτή είναι η μνήμη των δαχτύλων με την οποία έφτασες — σημαίνει εξαφανίστηκε.

### Σε υλικό Mac

Το Omarchy τρέχει καλά σε Intel Macs, και σε Mac με M1, M2 και M3 με το Omarchy for Apple Silicon. Δες την [υποστήριξη Mac](44-mac-support.md). Και το πληκτρολόγιο είναι ευγενικό μαζί σου: το Omarchy δεν επαναντιστοιχίζει τίποτα, και το Linux αντιμετωπίζει το πλήκτρο Command ως Super, οπότε το Super βρίσκεται ακριβώς εκεί όπου ήταν πάντα το Cmd. Ο αντίχειράς σου δεν θα καταλάβει τη μετακόμιση.

### Δώσε του δύο εβδομάδες

Τα ένστικτα μεταφέρονται πιο γρήγορα απ' ό,τι νομίζεις. Ρίξε μια ματιά στο κεφάλαιο για τις [συντομεύσεις](07-hotkeys.md) μία φορά, και όποτε κολλάς σε μια αντιστοίχιση, πάτα `Super + K` — σου τις δείχνει όλες. Αυτή είναι η μόνη συντόμευση που πραγματικά πρέπει να απομνημονεύσεις.
