# Αν έρχεστε από Mac ή Windows

Αν έχετε περάσει χρόνια στο macOS ή στα Windows, τα δάχτυλά σας ξέρουν εκατό πράγματα που ο εγκέφαλός σας έχει ξεχάσει ότι τα έμαθε ποτέ. Αυτό το κεφάλαιο είναι το στρώμα μετάφρασης: πού καταλήγουν αυτά τα ένστικτα στο Omarchy. Τα ίδια τα χαρακτηριστικά καλύπτονται σε βάθος αλλού — αυτός είναι απλώς ο χάρτης.

### Το Super είναι το κέντρο των πάντων

Όλη η μυϊκή μνήμη που έχετε χτίσει γύρω από το Cmd ή το πλήκτρο των Windows μεταφέρεται σε ένα πλήκτρο: το Super. Αυτό είναι το πλήκτρο των Windows σε ένα πληκτρολόγιο PC, και είναι η άγκυρα για σχεδόν κάθε συντόμευση πληκτρολογίου στο Omarchy.

Το αντανακλαστικό σας για το Spotlight ή το Raycast ή το μενού Έναρξη γίνεται `Super + Space`. Αυτό ανοίγει το μενού του Omarchy, το οποίο εκκινεί εφαρμογές, αλλάζει ρυθμίσεις, εγκαθιστά λογισμικό, καταγράφει την οθόνη — σχεδόν τα πάντα. Αρχίστε να πληκτρολογείτε για να φιλτράρετε. Το `Super + Alt + Space` εμφανίζει κάθε εφαρμογή σε ένα πλέγμα, όπως κάνει το Launchpad. Δείτε την [πλοήγηση](04-navigation.md).

### Χωρίς εικονίδια στην επιφάνεια εργασίας, και το dock εμφανίζεται μόνο όταν αιωρείστε

Κανένα εικονίδιο για να τακτοποιήσετε στην επιφάνεια εργασίας, και κανένα dock σε έναν χώρο εργασίας με παράθεση — το dock εμφανίζεται μόνο σε έναν αιωρούμενο χώρο εργασίας (δείτε την [πλοήγηση](04-navigation.md)). Οι εφαρμογές ξεκινούν από μια συντόμευση πληκτρολογίου (`Super + Return` για το τερματικό, `Super + Shift + Return` για τον περιηγητή, και `Super + K` για μια λίστα με όλα όσα έχουν αντιστοιχιστεί) ή από το μενού. Το ένα μόνιμο στοιχείο του UI είναι [η επάνω γραμμή](05-the-top-bar.md), η οποία καλύπτει ό,τι έκαναν για εσάς πριν η γραμμή μενού, η περιοχή ειδοποιήσεων του συστήματος και το Notification Center — και σχεδόν κάθε widget πάνω της κάνει κάτι με αριστερό, δεξί και μεσαίο κλικ.

### Τα παράθυρα τοποθετούνται μόνα τους

Η μεγαλύτερη αλλαγή νοοτροπίας: δεν σέρνετε παράθυρα από εδώ κι από εκεί ούτε τα κουμπώνετε σε μισές οθόνες. Ανοίξτε ένα παράθυρο και καταλαμβάνει όλη την οθόνη. Ανοίξτε ένα δεύτερο και μοιράζονται την οθόνη. Ποτέ δεν ψαρεύετε ένα παράθυρο κάτω από ένα άλλο, επειδή τα παράθυρα δεν επικαλύπτονται.

Όταν πραγματικά χρειάζεστε ένα αιωρούμενο παράθυρο, το `Super + T` βγάζει το ενεργό από την παράθεση (και το επαναφέρει). Αλλά δώστε πρώτα στην παράθεση μια πραγματική ευκαιρία — είναι η καρδιά όλου του πράγματος. Η [Πλοήγηση](04-navigation.md) σας καθοδηγεί βήμα βήμα.

Οι χώροι εργασίας θα σας φανούν οικείοι: είναι τα Spaces του macOS ή οι εικονικές επιφάνειες εργασίας των Windows, με τη διαφορά ότι θα τους χρησιμοποιείτε πραγματικά, επειδή το `Super + 1/2/3/4` μεταπηδά κατευθείαν σε έναν και το `Super + Shift + 1/2/3/4` στέλνει εκεί το ενεργό παράθυρο. Καμία καθυστέρηση από κίνηση, μόνο στιγμιαία άλματα. Αυτό σημαίνει ότι μπορεί να μη χρειάζεστε καν πολλαπλές οθόνες, αν το είχατε συνηθίσει αυτό παλιότερα.

### Η αντιγραφή και η επικόλληση απλώς λειτουργούν

Στο Mac είχατε Cmd + C παντού. Στα Windows είχατε Ctrl + C παντού — εκτός από το τερματικό, όπου τερματίζει το πρόγραμμά σας. Το Omarchy σας δίνει `Super + C`, `Super + X` και `Super + V`, και λειτουργούν παντού, συμπεριλαμβανομένου του τερματικού. Κανένα ξεχωριστό αντανακλαστικό για να μάθετε για το κέλυφος.

Εσείς των Windows: το ιστορικό προχείρου σας με το Win + V βρίσκεται στο `Super + Ctrl + V`, και κρατά εικόνες καθώς και κείμενο. Δείτε το [ενοποιημένο πρόχειρο & ιστορικό](08-unified-clipboard-history.md).

### Ο πίνακας μετάφρασης

| Αυτό που αναζητάτε | Στο Omarchy |
| ------------- | ---------- |
| Spotlight / Raycast / μενού Έναρξη | `Super + Space` — το μενού του Omarchy |
| AirDrop | LocalSend, μέσω `Super + Ctrl + S` — δείτε τα [GUIs](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` ή `Print Screen` — δείτε τα [στιγμιότυπα οθόνης & εγγραφή](12-screenshots-recording.md) |
| Notification Center | Ιστορικό ειδοποιήσεων στο `Super + Shift + Alt + ,` |
| Time Machine (για το σύστημα) | Αυτόματα [στιγμιότυπα συστήματος](47-system-snapshots.md) σε κάθε ενημέρωση |
| App Store / λήψη ενός προγράμματος εγκατάστασης | _Install_ στο μενού, ή `omarchy pkg add` — δείτε τα [άλλα πακέτα](29-other-packages.md) |
| Ρυθμίσεις Συστήματος / Πίνακας Ελέγχου | _Setup_ στο μενού, το οποίο επεξεργάζεται απλά αρχεία διαμόρφωσης — δείτε τα [dotfiles](31-dotfiles.md) |
| Finder / Εξερεύνηση Αρχείων | Files, στο `Super + Shift + F` — δείτε τα [GUIs](22-guis.md) |
| Safari / Edge | Google Chrome στο `Super + Shift + Return`; επιλέξτε άλλον στο _Setup > Defaults > Browser_ — δείτε τους [περιηγητές](23-browsers.md) |
| Preview / Photos | Omaview για εικόνες, βίντεο και μουσική, Document Viewer για PDF — δείτε τα [GUIs](22-guis.md) |
| TextEdit / Notepad | Plain, στο `Super + Shift + N`; επιλέξτε άλλον στο _Setup > Defaults > Editor_ |

### Μερικά πράγματα είναι πραγματικά διαφορετικά

Πολλές ρυθμίσεις βρίσκονται σε αρχεία κειμένου που επεξεργάζεστε, όχι σε πάνελ στα οποία κάνετε κλικ. Αυτό ακούγεται πρωτόγονο, μέχρι να συνειδητοποιήσετε ότι σημαίνει πως κάθε ρύθμιση μπορεί να προβληθεί, να αντιγραφεί στο επόμενο μηχάνημά σας και να μπει σε σύστημα ελέγχου εκδόσεων. Το μενού _Setup_ σας αφήνει κατευθείαν στο σωστό αρχείο και επανεκκινεί ό,τι χρειάζεται επανεκκίνηση όταν τελειώσετε.

Οι ενημερώσεις έρχονται μέσω μιας εντολής — _Update > Omarchy_ — η οποία ενημερώνει το ίδιο το Omarchy και κάθε πακέτο στο σύστημα, παίρνοντας πρώτα ένα στιγμιότυπο. Κανένα πρόγραμμα ενημέρωσης ανά εφαρμογή να σας ενοχλεί σε τυχαίες στιγμές. Δείτε τις [ενημερώσεις](30-updates.md).

Το λογισμικό έρχεται από έναν διαχειριστή πακέτων, όχι από προγράμματα εγκατάστασης που κατεβάσατε.

Και όταν κλείνετε ένα παράθυρο, η εφαρμογή πραγματικά τερματίζεται. Δεν υπάρχει το limbo του macOS, όπου το πρόγραμμα συνεχίζει να τρέχει χωρίς κανένα παράθυρο. Το `Super + W` — ή το `Super + Q`, αν αυτή είναι η μνήμη των δαχτύλων με την οποία ήρθατε — σημαίνει ότι εξαφανίστηκε.

### Σε υλικό Mac

Το Omarchy τρέχει καλά σε Intel Macs — δείτε την [υποστήριξη Mac](44-mac-support.md). Και το πληκτρολόγιο σας φέρεται ευγενικά: το Omarchy δεν επαναντιστοιχίζει τίποτα, και το Linux αντιμετωπίζει το πλήκτρο Command ως Super, οπότε το Super βρίσκεται ακριβώς εκεί όπου βρισκόταν πάντα το Cmd. Ο αντίχειράς σας δεν θα προσέξει τη μετακίνηση.

### Δώστε του δύο εβδομάδες

Τα ένστικτα μεταφέρονται πιο γρήγορα από ό,τι νομίζετε. Ρίξτε μια ματιά στο κεφάλαιο για τις [συντομεύσεις πληκτρολογίου](07-hotkeys.md) μία φορά, και κάθε φορά που ξεχνάτε μια αντιστοίχιση, πατήστε `Super + K` — σας τις δείχνει όλες. Αυτή είναι η μόνη συντόμευση πληκτρολογίου που πραγματικά πρέπει να απομνημονεύσετε.
