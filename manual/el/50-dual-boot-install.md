# Εγκατάσταση Διπλής Εκκίνησης

Μπορείς να εγκαταστήσεις το Omarchy σε ένα μόνο διαμέρισμα δίπλα σε Windows ή άλλες εγκαταστάσεις.

Αυτή η μέθοδος εγκατάστασης έρχεται ακόμα με κρυπτογράφηση LUKS για το διαμέρισμα από προεπιλογή, οπότε είναι ουσιαστικά ίδια με την πλήρη μονάδα και απλώς απαιτεί ελεύθερο χώρο διαθέσιμο στον δίσκο.

## Δημιουργία Χώρου στα Windows

Για να εγκαταστήσεις δίπλα στα Windows, πληκτρολόγησε `disk management` στο μενού εκκίνησης και επίλεξε την επιλογή για **Δημιουργία και μορφοποίηση διαμερισμάτων σκληρού δίσκου**.

 ![dual-boot-1](images/dual-boot-1.webp)

Βρες το κατάλληλο διαμέρισμα, κάνε δεξί κλικ και διάλεξε **Συρρίκνωση Τόμου**.

![dual-boot-2](images/dual-boot-2.webp)

 Εισήγαγε το ποσό κατά το οποίο θα ήθελες να συρρικνώσεις τον τόμο. Σημείωσε ότι αυτό θα είναι το μέγεθος της μελλοντικής σου εγκατάστασης Omarchy συμπεριλαμβανομένου του διαμερίσματος εκκίνησης.

 ![dual-boot-3](images/dual-boot-3.webp)

Όταν τελειώσεις, πρέπει να δεις κάτι σαν αυτό όπου η ενότητα 50GB είναι όπου θα εγκαταστήσουμε το Omarchy σε αυτό το παράδειγμα.

 ![dual-boot-4](images/dual-boot-4.webp)

## Εγκατάσταση Omarchy

Η διαδικασία εγκατάστασης για το Omarchy είναι ουσιαστικά η ίδια με την κανονική. Αφού επιλέξεις τον δίσκο σου, θα σου δοθεί η επιλογή **Εγκατάσταση σε ελεύθερο χώρο**. Επίλεξε εκείνη την επιλογή για να αποτρέψεις το σβήσιμο ολόκληρου του δίσκου.

 ![dual-boot-5](images/dual-boot-5.webp)

Επιβεβαίωσε ότι όλα φαίνονται καλά και περίμενε να τελειώσει η εγκατάσταση όπως συνήθως. Εδώ επίσης θα μπορούσες να επιλέξεις να εγκαταστήσεις ακρυπτογράφητο (δεν συνιστάται) όπως ακριβώς σε μια εγκατάσταση πλήρους μονάδας.
 ![dual-boot-6](images/dual-boot-6.webp)

## Προσθήκη Άλλων Εγκαταστάσεων στον Φορτωτή Εκκίνησης

Όταν τελειώσεις την εγκατάσταση Omarchy, θα παρατηρήσεις ότι ο φορτωτής εκκίνησης Limine είναι η προεπιλογή τώρα. Με αυτό, μπορείς επίσης να προσθέσεις επιλογές στο Limine για τις άλλες εγκαταστάσεις σου όπως Windows.

Για να το κάνεις αυτό, τρέξε `limine-scan` και ακολούθησε τις προτροπές για να προσθέσεις όποια στοιχεία θα ήθελες στη διαμόρφωσή σου limine. Μετά όταν εκκινείς, θα βλέπεις τις κανονικές επιλογές σου για Omarchy, καθώς και Windows Boot Manager ή άλλα.

## Bitlocker

Είναι σημαντικό να σημειώσεις ότι αυτή η μέθοδος εγκατάστασης δεν είναι συμβατή με το Bitlocker καθώς κρυπτογραφεί ολόκληρη τη μονάδα, όχι μόνο το διαμέρισμα. Αν συναντήσεις ένα σφάλμα που δηλώνει ότι το Bitlocker είναι ενεργοποιημένο, εκκίνησε στα Windows, πήγαινε στο **Settings -> Privacy & Security -> Device encryption** και απενεργοποίησε το Bitlocker. Μπορεί να χρειαστεί κάποιος χρόνος για την αποκρυπτογράφηση της μονάδας.
