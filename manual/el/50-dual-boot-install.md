# Εγκατάσταση Dual Boot

Μπορείτε να εγκαταστήσετε το Omarchy σε ένα μόνο διαμέρισμα μαζί με τα Windows ή άλλες εγκαταστάσεις.

Αυτή η μέθοδος εγκατάστασης περιλαμβάνει από προεπιλογή κρυπτογράφηση LUKS για το διαμέρισμα, οπότε ουσιαστικά δεν διαφέρει από την εγκατάσταση σε ολόκληρο τον δίσκο και απλώς απαιτεί να υπάρχει διαθέσιμος ελεύθερος χώρος στον δίσκο.

## Δημιουργία χώρου στα Windows

Για να εγκαταστήσετε το Omarchy μαζί με τα Windows, πληκτρολογήστε `disk management` στο μενού έναρξης και επιλέξτε την επιλογή **Δημιουργία και μορφοποίηση διαμερισμάτων σκληρού δίσκου**.

 ![dual-boot-1](images/dual-boot-1.webp)

Βρείτε το κατάλληλο διαμέρισμα, κάντε δεξί κλικ και επιλέξτε **Συρρίκνωση τόμου**.

![dual-boot-2](images/dual-boot-2.webp)

 Εισαγάγετε το μέγεθος κατά το οποίο θέλετε να συρρικνώσετε τον τόμο. Σημειώστε ότι αυτό θα είναι το μέγεθος της μελλοντικής σας εγκατάστασης Omarchy, συμπεριλαμβανομένου του διαμερίσματος εκκίνησης.

 ![dual-boot-3](images/dual-boot-3.webp)

Όταν τελειώσετε, θα πρέπει να δείτε κάτι σαν αυτό, όπου το τμήμα των 50GB είναι το σημείο όπου θα εγκαταστήσουμε το Omarchy σε αυτό το παράδειγμα.

 ![dual-boot-4](images/dual-boot-4.webp)

## Εγκατάσταση του Omarchy

Η διαδικασία εγκατάστασης του Omarchy είναι ουσιαστικά ίδια με την κανονική. Αφού επιλέξετε τον δίσκο σας, θα σας δοθεί η επιλογή **Free space install**. Επιλέξτε αυτή την επιλογή για να αποτρέψετε τη διαγραφή ολόκληρου του δίσκου.

 ![dual-boot-5](images/dual-boot-5.webp)

Επιβεβαιώστε ότι όλα φαίνονται σωστά και περιμένετε να ολοκληρωθεί η εγκατάσταση κανονικά. Εδώ μπορείτε επίσης να επιλέξετε να κάνετε εγκατάσταση χωρίς κρυπτογράφηση (δεν συνιστάται), όπως ακριβώς και σε μια εγκατάσταση σε ολόκληρο τον δίσκο.
 ![dual-boot-6](images/dual-boot-6.webp)

## Προσθήκη άλλων εγκαταστάσεων στον Bootloader

Όταν ολοκληρώσετε την εγκατάσταση του Omarchy, θα παρατηρήσετε ότι ο bootloader Limine είναι πλέον ο προεπιλεγμένος. Με αυτόν, μπορείτε επίσης να προσθέσετε στο Limine επιλογές για τις άλλες εγκαταστάσεις σας, όπως τα Windows.

Για να προσθέσετε άλλα λειτουργικά συστήματα, εκτελέστε `limine-scan` και ακολουθήστε τις οδηγίες για να προσθέσετε τις καταχωρίσεις που θέλετε στη διαμόρφωση του Limine. Το μενού εκκίνησης παραμένει κρυφό από προεπιλογή και ξεκινά το Omarchy μετά από ένα δευτερόλεπτο. Για να επιλέξετε τα Windows ή μια άλλη καταχώριση, πατήστε οποιοδήποτε πλήκτρο μόλις ξεκινήσει το Limine· όταν εμφανιστεί το μενού, χρησιμοποιήστε τα πλήκτρα βέλους για να επιλέξετε μια καταχώριση και πατήστε Enter. Αν το Omarchy ξεκινήσει πριν πατήσετε κάποιο πλήκτρο, κάντε επανεκκίνηση και δοκιμάστε ξανά.

## Bitlocker

Είναι σημαντικό να σημειωθεί ότι αυτή η μέθοδος εγκατάστασης δεν είναι συμβατή με το Bitlocker, καθώς αυτό κρυπτογραφεί ολόκληρο τον δίσκο, όχι μόνο το διαμέρισμα. Αν εμφανιστεί σφάλμα που δηλώνει ότι το Bitlocker είναι ενεργοποιημένο, εκκινήστε στα Windows, μεταβείτε στις **Ρυθμίσεις -> Απόρρητο και ασφάλεια -> Κρυπτογράφηση συσκευής** και απενεργοποιήστε το Bitlocker. Η αποκρυπτογράφηση του δίσκου μπορεί να πάρει κάποιο χρόνο.
