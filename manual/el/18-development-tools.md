# Εργαλεία ανάπτυξης

## Εναλλακτικοί επεξεργαστές

Το Omarchy έρχεται με το [Neovim](https://neovim.io/) από προεπιλογή, αλλά αν θα θέλατε κάτι λίγο πιο mainstream και οικείο, μπορείτε να ανοίξετε το Omarchy Menu (`Super + Space`) και να δείτε τις επιλογές στο _Εγκατάσταση > Editor_. Έχουμε εκεί τα VSCode, Cursor, Zed, Sublime Text, Helix, Vim και Emacs. Αν δεν βρείτε αυτό που ψάχνετε, ρίξτε μια ματιά στο _Εγκατάσταση > Package_ και δείτε μήπως υπάρχει σε πακέτο του Arch (και αν όχι, δοκιμάστε το _Εγκατάσταση > AUR_ για να ελέγξετε το AUR).

Ο αρχικός επεξεργαστής `vi` είναι επίσης διαθέσιμος από το κουτί. Εκτελέστε `vi filename` για να επεξεργαστείτε ένα αρχείο στο τερματικό.

Ταίριασμα θέματος προσφέρεται για τα `VSCode`, `Cursor`, `VSCodium` και `Helix`.

Μπορείτε να ορίσετε τον προεπιλεγμένο επεξεργαστή για όλο το σύστημα στο `Setup > Defaults > Editor`.

## Περιβάλλον

Το Omarchy υποστηρίζει τη ρύθμιση πολλών περιβαλλόντων ανάπτυξης μέσα από την ενότητα _Εγκατάσταση > Development_ του Omarchy Menu (`Super + Space`). Θα βρείτε φυσικά το _Ruby on Rails_, αλλά και τα τρία μεγάλα runtimes για JavaScript (Node.js, Bun, Deno), καθώς και δημοφιλή PHP frameworks όπως τα Laravel και Symfony. Α, και υπάρχουν επίσης Go, Rust, Python, Java, Elixir (με Phoenix), .NET, OCaml, Zig, Clojure και Scala. Είναι μια πολύ ευρεία επιλογή!

Η πλειονότητα αυτών των περιβαλλόντων διαχειρίζεται από το [Mise](https://mise.jdx.dev/). Είναι ένα εργαλείο που σας επιτρέπει να εγκαθιστάτε και να εκτελείτε πολλαπλές εκδόσεις μιας γλώσσας προγραμματισμού στο ίδιο μηχάνημα. Είναι σαν το rbenv ή το rvm για Ruby ή το virtualenv για Python, αλλά λειτουργεί για πολλά διαφορετικά περιβάλλοντα.

Για να εγκαταστήσετε, ας πούμε, τη Ruby, θα εκτελέσετε `mise use -g ruby`, το οποίο θα εγκαταστήσει τη Ruby και θα την ορίσει ως καθολική προεπιλογή. Ή, αν το έργο σας έχει ένα αρχείο .ruby-version, μπορείτε απλώς να εκτελέσετε `mise i` στη ρίζα αυτού του έργου.

## Docker

Το [Docker](https://www.docker.com/) σχεδόν δεν χρειάζεται συστάσεις. Σάς επιτρέπει να εκτελείτε απομονωμένα containers, και το Omarchy εγκαθιστά όλα όσα χρειάζονται για να λειτουργεί καλά, συμπεριλαμβανομένων του ίδιου του Docker και του [Docker Compose](https://docs.docker.com/compose/).

Από προεπιλογή ο χρήστης σας *δεν* βρίσκεται στην ομάδα `docker`. Αυτή η ομάδα είναι ουσιαστικά root χωρίς κωδικό — οτιδήποτε βρίσκεται σε αυτή μπορεί να εκτελέσει `docker run -v /:/host` και να καταλάβει το μηχάνημα — οπότε ένα μόνο κακόβουλο script ή εξάρτηση που εκτελείται ως εσείς θα βρισκόταν διαφορετικά ένα βήμα πριν από το root. Έτσι, στη γραμμή εντολών εκτελείτε το Docker με `sudo` (`sudo docker ps`, `sudo docker compose up`), και τα γραφικά εργαλεία που επικοινωνούν με τον δαίμονα — το Windows VM — ζητούν εξουσιοδότηση όταν τη χρειάζονται. Αν θέλετε πίσω την ευκολία μιας ρύθμισης χωρίς ομάδα και κατανοείτε τον συμβιβασμό, ενεργοποιήστε την από το **Ρύθμιση > Security > Sudoless Docker** (ή εκτελέστε `omarchy-setup-security-sudoless-docker`), το οποίο σας προσθέτει στην ομάδα `docker` μετά από μια προειδοποίηση· τότε το απλό `docker` και το alias `d` λειτουργούν ξανά χωρίς `sudo`.

Μπορείτε να ρυθμίσετε τις συνηθισμένες βάσεις δεδομένων για τοπική ανάπτυξη στο Docker χρησιμοποιώντας το _Εγκατάσταση > Development > Docker DB_ στο μενού του Omarchy.

## GitHub CLI

[Το GitHub CLI](https://cli.github.com/) σας επιτρέπει να κάνετε ταυτοποίηση με τον λογαριασμό σας στο GitHub και να κλωνοποιείτε ιδιωτικά αποθετήρια χρησιμοποιώντας το. Είναι ενσωματωμένο ως ένα από τα stubs του mise με αργή φόρτωση, οπότε την πρώτη φορά που θα εκτελέσετε `gh`, εγκαθίσταται μόνο του. Για ταυτοποίηση, εκτελέστε `gh auth login`. Έπειτα μπορείτε να κάνετε checkout σε ιδιωτικά αποθετήρια χρησιμοποιώντας `gh repo clone org/repo`.

Μπορείτε επίσης να εκτελέσετε πολλές άλλες λειτουργίες του GitHub χρησιμοποιώντας αυτή την εντολή. Απλώς εκτελέστε `gh` για να δείτε όλα όσα είναι δυνατά.

Υπάρχει επίσης ένα stub για το `ghui` με αργή εγκατάσταση, για τη διαχείριση των pull requests σας σε TUI. Και το [lazygit](https://github.com/jesseduffield/lazygit) είναι προεγκατεστημένο, αν θέλετε να χειρίζεστε και το ίδιο το git μέσα από TUI.
