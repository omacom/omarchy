# Οθόνες

Το Omarchy θεωρεί από προεπιλογή ότι χρησιμοποιείτε οθόνη κατηγορίας retina με δυνατότητα 2x. Αυτό χρειάζεστε για να έχετε αυτές τις ωραίες, ευκρινείς γραμματοσειρές προγραμματιστή. Αυτό είναι που είναι βελτιστοποιημένα σχεδόν όλα τα νέα premium laptop με οθόνες υψηλής ανάλυσης. Αυτό θα θέλατε να χρησιμοποιείτε σε μια 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) ή 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/).

Αλλά αν δεν χρησιμοποιείτε οθόνη με PPI 218 ή παραπάνω, θα θέλετε να αλλάξετε τις ρυθμίσεις οθόνης. Για παράδειγμα, αν έχετε 4K 27" ή 32", μπορείτε να χρησιμοποιήσετε κλασματική κλιμάκωση ανοίγοντας το `~/.config/hypr/monitors.lua` (μέσω του _Ρυθμίσεις > Οθόνες_ στο μενού του Omarchy) και αλλάζοντας στη σύσταση για αυτόν τον συνδυασμό:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

Αν χρησιμοποιείτε οθόνη 1080p ή 1440p, μάλλον θα θέλετε απλώς να χρησιμοποιήσετε κλιμάκωση 1x, οπότε μπορείτε να χρησιμοποιήσετε:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

Οι αλλαγές στο `GDK_SCALE` ισχύουν για εφαρμογές που ξεκινούν μετά την αλλαγή (και το GTK δέχεται μόνο ακέραιους αριθμούς, οπότε κρατήστε το στον πλησιέστερο ακέραιο της κλίμακας της οθόνης σας). Φροντίστε λοιπόν να κλείσετε τα παράθυρα που έχετε και είναι υπερμεγέθη μετά την αλλαγή (ή κλείστε όλα τα παράθυρα με `Ctrl + Alt + Del`!).

Μπορείτε επίσης να περνάτε γρήγορα μέσα από τις κύριες αναλογίες κλιμάκωσης οθόνης (1x, 1.25x, 1.6x, 2x, 3x, 4x) χρησιμοποιώντας το `Super + /` για να πάτε ψηλότερα και το `Super + Alt + /` για να πάτε χαμηλότερα, ή να διαλέξετε μία από το πάνελ οθόνης στην επάνω μπάρα. Αυτές αλλάζουν μόνο την οθόνη στην οποία είστε εστιασμένοι, οπότε μια οθόνη laptop και μια εξωτερική οθόνη μπορούν να έχουν η καθεμία τη δική της κλίμακα. Η επιλογή αποθηκεύεται στο `~/.config/hypr/monitors.lua` ως κανόνας `hl.monitor` για εκείνη την οθόνη, οπότε διατηρείται μετά την επανεκκίνηση και υπερισχύει του `omarchy_monitor_scale`, το οποίο παραμένει η κλίμακα για κάθε οθόνη χωρίς δικό της κανόνα. Καθώς το `GDK_SCALE` είναι μία τιμή για όλες τις οθόνες, αυτές οι αλλαγές το ορίζουν από την οθόνη με τη χαμηλότερη κλίμακα, οπότε οι εφαρμογές X11 βγαίνουν λίγο μικρές στην πυκνότερη οθόνη αντί για υπερμεγέθεις στην άλλη.

### Μεγέθυνση ή σμίκρυνση κειμένου

Η κλιμάκωση οθόνης αλλάζει το μέγεθος των πάντων. Αν το μόνο που θέλετε είναι μεγαλύτερο ή μικρότερο _κείμενο_, υπάρχει ένα μόνο κουμπί για αυτό:

```
omarchy display text size 14
```

Αυτό παίρνει ένα μέγεθος pixel μεταξύ 9 και 20, και μετακινεί το κέλυφος του Omarchy, τις εφαρμογές GTK και το τερματικό σας μαζί, οπότε ολόκληρη η επιφάνεια εργασίας παραμένει σε αναλογία. Εκτελέστε το χωρίς όρισμα για να δείτε πού βρίσκεστε, και το `omarchy display text size reset` για να επιστρέψετε στην προεπιλογή. Το Foot είναι ο μόνος αργοπορημένος: δεν έχει τρόπο να επαναφορτώσει τη διαμόρφωσή του, οπότε τα τερματικά που τρέχουν κρατούν το παλιό τους μέγεθος μέχρι να ανοίξετε ένα νέο.

### Επέκταση και κατοπτρισμός οθονών φορητού υπολογιστή

Όταν συνδέετε μια εξωτερική οθόνη στο laptop σας, η οθόνη επεκτείνεται αυτόματα. Αλλά μπορείτε να το αλλάξετε αυτό σε κατοπτρισμό αντί για επέκταση χρησιμοποιώντας το _Ενεργοποίηση > Υλικό_ στο μενού του Omarchy ή το `Super + Ctrl + Alt + Delete`. Αυτό είναι ιδιαίτερα χρήσιμο αν εκείνη η εξωτερική οθόνη είναι προβολέας, και θέλετε να δείξετε κάτι ενώ εργάζεστε.

Όταν κάνετε επέκταση, το κλείσιμο του καπακιού στο laptop θα απενεργοποιήσει αυτόματα την εσωτερική οθόνη. Το άνοιγμα του καπακιού θα την ενεργοποιήσει ξανά. Μπορείτε επίσης να το ελέγχετε αυτό χειροκίνητα χρησιμοποιώντας το _Ενεργοποίηση > Υλικό_ στο μενού του Omarchy ή το `Super + Ctrl + Delete`.

### Διαρρύθμιση πολλαπλών οθονών

Το Hyprland δουλεύει υπέροχα με πολλαπλές οθόνες. Διαβάστε περισσότερα για το πώς να τις διατάξετε στην [τεκμηρίωση οθονών του Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/). Στο Omarchy, αυτά μπαίνουν στο `~/.config/hypr/monitors.lua` ως εγγραφές `hl.monitor` — το αρχείο παρέχεται με παραδείγματα σε σχόλια για να καρφιτσώσετε μια συγκεκριμένη οθόνη σε μια ανάλυση, θέση και περιστροφή.

Κάθε οθόνη έχει δικούς της χώρους εργασίας 1 έως 10, οπότε το `Super + 1` σημαίνει πάντα τον πρώτο χώρο εργασίας της οθόνης στην οποία βρίσκεστε. Στα παρασκήνια, το Hyprland εξακολουθεί να αριθμεί τους χώρους εργασίας σε όλες τις οθόνες: η οθόνη του laptop σας (ή η πρώτη οθόνη) παίρνει το 1–10, η επόμενη οθόνη το 11–20, και ούτω καθεξής, και κάθε οθόνη κρατά το μπλοκ της κάθε φορά που τη συνδέετε. Χρησιμοποιήστε αυτούς τους αριθμούς αν γράψετε [κανόνες χώρων εργασίας](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) ή κανόνες παραθύρων για μια συγκεκριμένη οθόνη, οπότε ο χώρος εργασίας 12 είναι ο δεύτερος χώρος εργασίας της δεύτερης οθόνης σας. Το `~/.local/state/omarchy/monitor-workspaces` απαριθμεί ποιο μπλοκ έχει κάθε οθόνη.

Τα πλήκτρα βέλους δουλεύουν μεταξύ οθονών που μοιράζονται μια ακμή στη διάταξή σας. Οθόνες που αγγίζονται μόνο σε μια γωνία, ή που έχουν κενό μεταξύ τους, δεν είναι γείτονες, οπότε χρησιμοποιήστε το `Ctrl + Alt + Tab` για να μετακινηθείτε ανάμεσά τους.

| Hotkey | Μεταξύ οθονών |
| --- | --- |
| `Super + Arrow` | Μετακινεί την εστίαση στην οθόνη εκείνης της πλευράς μόλις δεν υπάρχει άλλο παράθυρο προς εκείνη την κατεύθυνση |
| `Super + Shift + Arrow` | Ανταλλάσσει με ένα παράθυρο στην οθόνη εκείνης της πλευράς |
| `Super + Alt + Arrow` | Μετακινεί το παράθυρο σε μια ομάδα στην οθόνη εκείνης της πλευράς |
| `Super + Shift + Ctrl + Arrow` | Μετακινεί το παράθυρο στην οθόνη εκείνης της πλευράς, στον χώρο εργασίας που αυτή προβάλλει |
| `Super + Shift + Alt + Arrow` | Μετακινεί τον χώρο εργασίας στην οθόνη εκείνης της πλευράς, κρατώντας τον αριθμό του αν είναι ελεύθερος |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | Μετακινεί την εστίαση στην επόμενη ή την προηγούμενη οθόνη, ανεξάρτητα από τη διάταξη |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | Παραμένουν στην οθόνη στην οποία βρίσκεστε |

Μπορείτε επίσης να δείτε το [Hyprmon](https://github.com/erans/hyprmon/), αν θα θέλατε ένα TUI για να σας βοηθήσει με την τοποθέτηση πολλαπλών οθονών.

### Έλεγχος φωτεινότητας

Η φωτεινότητα οθόνης ελέγχεται από τα ειδικά πλήκτρα λειτουργιών για αύξηση/μείωση φωτεινότητας. Αν κρατήσετε πατημένο το shift ενώ πατάτε αυτά, θα πάτε στη μέγιστη ή την ελάχιστη φωτεινότητα. Τα πλήκτρα ελέγχουν την οθόνη στην οποία είστε εστιασμένοι, οπότε εξωτερικές οθόνες που μιλούν DDC/CI ρυθμίζονται με τον ίδιο τρόπο όπως η οθόνη του laptop.

### Οθόνες Apple

Αν χρησιμοποιείτε οθόνη Apple, τα κανονικά πλήκτρα φωτεινότητας του πληκτρολογίου θα δουλεύουν επίσης αυτόματα, αν είστε εστιασμένοι στην οθόνη Apple. Αυτό γίνεται μέσω της εντολής `asdcontrol`.

Σημειώστε ότι αν χρησιμοποιείτε οθόνη Apple 6K XDR, μπορεί να δείτε μια οθόνη-φάντασμα στην καταχώρισή σας `hyprctl monitors`. Μπορείτε να το απενεργοποιήσετε αυτό με κάτι σαν `hl.monitor({ output = "DP-2", disabled = true })` μέσω του _Ρυθμίσεις > Οθόνες_.

Σε μηχανήματα Intel, θα πρέπει να συνδέεστε σε οθόνες Apple χρησιμοποιώντας ένα κανονικό καλώδιο Thunderbolt. Σε άλλα μηχανήματα χωρίς Thunderbolt, θα πρέπει συνήθως να χρησιμοποιήσετε ένα [καλώδιο DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) για να το κάνετε να δουλέψει.
