# Οθόνες

Το Omarchy θεωρεί δεδομένο ότι χρησιμοποιείς από προεπιλογή μια οθόνη κατηγορίας retina με δυνατότητα 2x. Αυτό χρειάζεσαι για να έχεις αυτές τις ωραίες, ευκρινείς γραμματοσειρές προγραμματιστή. Γι' αυτό είναι βελτιστοποιημένες σχεδόν όλες οι νέες premium φορητές συσκευές με οθόνες υψηλής ανάλυσης. Είναι αυτό που θα ήθελες να χρησιμοποιείς σε μια 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) ή 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/).

Αν όμως δεν χρησιμοποιείς οθόνη με PPI 218 ή παραπάνω, θα θέλεις να αλλάξεις τις ρυθμίσεις οθόνης. Για παράδειγμα, αν έχεις μια 4K 27" ή 32", μπορείς να χρησιμοποιήσεις κλασματική κλιμάκωση ανοίγοντας το `~/.config/hypr/monitors.lua` (μέσω του _Ρύθμιση > Οθόνες_ στο μενού του Omarchy) και αλλάζοντας στη σύσταση για αυτόν τον συνδυασμό:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

Αν χρησιμοποιείς οθόνη 1080p ή 1440p, μάλλον θα θέλεις απλώς να χρησιμοποιήσεις κλιμάκωση 1x, οπότε μπορείς να χρησιμοποιήσεις:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

Οι αλλαγές στο `GDK_SCALE` ισχύουν για εφαρμογές που ξεκινούν μετά την αλλαγή (και το GTK σέβεται μόνο ακέραιους αριθμούς, οπότε κράτησέ το στον πλησιέστερο ακέραιο της κλίμακας της οθόνης σου). Φρόντισε λοιπόν να κλείσεις τα παράθυρα που έχεις και είναι υπερμεγέθη μετά την αλλαγή (ή κλείσε όλα τα παράθυρα με `Ctrl + Alt + Del`!).

Μπορείς επίσης να περνάς γρήγορα από τις βασικές αναλογίες κλιμάκωσης οθόνης (1x, 1.25x, 1.6x, 2x, 3x, 4x) χρησιμοποιώντας το `Super + /` για να πας ψηλότερα και το `Super + Alt + /` για να πας χαμηλότερα, ή να διαλέξεις μία από τον πίνακα οθόνης στην επάνω γραμμή. Αυτές αλλάζουν μόνο την οθόνη στην οποία είσαι εστιασμένος, οπότε η οθόνη ενός φορητού υπολογιστή και μια εξωτερική οθόνη μπορούν να έχουν η καθεμία τη δική της κλίμακα. Η επιλογή αποθηκεύεται στο `~/.config/hypr/monitors.lua` ως κανόνας `hl.monitor` για εκείνη την οθόνη, οπότε παραμένει μετά την επανεκκίνηση και υπερισχύει του `omarchy_monitor_scale`, που παραμένει η κλίμακα για κάθε οθόνη χωρίς δικό της κανόνα.

### Μεγέθυνση ή σμίκρυνση κειμένου

Η κλιμάκωση οθόνης αλλάζει το μέγεθος των πάντων. Αν το μόνο που θέλεις είναι μεγαλύτερο ή μικρότερο _κείμενο_, υπάρχει μία μόνο ρύθμιση γι' αυτό:

```
omarchy display text size 14
```

Αυτό παίρνει ένα μέγεθος σε pixel μεταξύ 9 και 20, και μετακινεί μαζί το κέλυφος του Omarchy, τις εφαρμογές GTK και το τερματικό σου, οπότε ολόκληρη η επιφάνεια εργασίας παραμένει σε αναλογία. Εκτέλεσέ το χωρίς όρισμα για να δεις πού βρίσκεσαι, και `omarchy display text size reset` για να επιστρέψεις στην προεπιλογή. Το Foot είναι το μόνο που μένει πίσω: δεν έχει τρόπο να επαναφορτώσει τη διαμόρφωσή του, οπότε τα τερματικά που εκτελούνται διατηρούν το παλιό τους μέγεθος μέχρι να ανοίξεις ένα νέο.

### Επέκταση και κατοπτρισμός οθονών φορητού υπολογιστή

Όταν συνδέεις μια εξωτερική οθόνη στον φορητό υπολογιστή σου, η οθόνη επεκτείνεται αυτόματα. Μπορείς όμως να το αλλάξεις αυτό σε κατοπτρισμό χρησιμοποιώντας το _Ενεργοποίηση > Υλικό_ στο μενού του Omarchy ή το `Super + Ctrl + Alt + Delete`. Αυτό είναι ιδιαίτερα χρήσιμο αν αυτή η εξωτερική οθόνη είναι προβολέας, και θέλεις να δείξεις κάτι ενώ εργάζεσαι.

Όταν κάνεις επέκταση, το κλείσιμο του καπακιού στον φορητό υπολογιστή θα απενεργοποιήσει αυτόματα την εσωτερική οθόνη. Το άνοιγμα του καπακιού θα την ενεργοποιήσει ξανά. Μπορείς επίσης να το ελέγχεις αυτό χειροκίνητα χρησιμοποιώντας το _Ενεργοποίηση > Υλικό_ στο μενού του Omarchy ή το `Super + Ctrl + Delete`.

### Τακτοποίηση πολλών οθονών

Το Hyprland δουλεύει εξαιρετικά με πολλές οθόνες. Διάβασε περισσότερα για το πώς να τις διατάξεις στην [τεκμηρίωση οθονών του Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/). Στο Omarchy, αυτές μπαίνουν στο `~/.config/hypr/monitors.lua` ως καταχωρίσεις `hl.monitor` — το αρχείο παρέχεται με σχολιασμένα παραδείγματα για τον ορισμό μιας συγκεκριμένης οθόνης σε μια ανάλυση, θέση και περιστροφή.

Κάθε οθόνη έχει τους δικούς της χώρους εργασίας 1 έως 10, οπότε το `Super + 1` σημαίνει πάντα τον πρώτο χώρο εργασίας της οθόνης στην οποία βρίσκεσαι. Πίσω από τις σκηνές, το Hyprland εξακολουθεί να αριθμεί τους χώρους εργασίας σε όλες τις οθόνες: η οθόνη του φορητού υπολογιστή σου (ή η πρώτη οθόνη) παίρνει το 1–10, η επόμενη οθόνη το 11–20, και ούτω καθεξής, και κάθε οθόνη διατηρεί το μπλοκ της κάθε φορά που τη συνδέεις. Χρησιμοποίησε αυτούς τους αριθμούς αν γράφεις [κανόνες χώρων εργασίας](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) ή κανόνες παραθύρων για μια συγκεκριμένη οθόνη, οπότε ο χώρος εργασίας 12 είναι ο δεύτερος χώρος εργασίας της δεύτερης οθόνης σου. Το `~/.local/state/omarchy/monitor-workspaces` παραθέτει ποιο μπλοκ έχει κάθε οθόνη.

Τα πλήκτρα βέλους δουλεύουν μεταξύ οθονών που μοιράζονται μια ακμή στη διάταξή σου. Οθόνες που αγγίζονται μόνο σε μια γωνία, ή που έχουν κενό μεταξύ τους, δεν είναι γείτονες, οπότε χρησιμοποίησε το `Ctrl + Alt + Tab` για να μετακινηθείς μεταξύ τους.

| Πλήκτρο συντόμευσης | Μεταξύ οθονών |
| --- | --- |
| `Super + Arrow` | Μετακινεί την εστίαση στην οθόνη εκείνης της πλευράς μόλις δεν υπάρχει άλλο παράθυρο προς εκείνη την κατεύθυνση |
| `Super + Shift + Arrow` | Ανταλλάσσει με ένα παράθυρο στην οθόνη εκείνης της πλευράς |
| `Super + Alt + Arrow` | Μετακινεί το παράθυρο σε μια ομάδα στην οθόνη εκείνης της πλευράς |
| `Super + Shift + Ctrl + Arrow` | Μετακινεί το παράθυρο στην οθόνη εκείνης της πλευράς, στον χώρο εργασίας που δείχνει |
| `Super + Shift + Alt + Arrow` | Μετακινεί τον χώρο εργασίας στην οθόνη εκείνης της πλευράς, διατηρώντας τον αριθμό του αν είναι ελεύθερος |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | Μετακινεί την εστίαση στην επόμενη ή προηγούμενη οθόνη, όποια κι αν είναι η διάταξη |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | Παραμένουν στην οθόνη στην οποία βρίσκεσαι |

Μπορείς επίσης να ρίξεις μια ματιά στο [Hyprmon](https://github.com/erans/hyprmon/), αν θέλεις ένα TUI να σε βοηθήσει με την τοποθέτηση πολλών οθονών.

### Έλεγχος φωτεινότητας

Η φωτεινότητα της οθόνης ελέγχεται από τα ειδικά πλήκτρα λειτουργιών για αύξηση/μείωση φωτεινότητας. Αν κρατήσεις πατημένο το shift ενώ πατάς αυτά, θα πας στη μέγιστη ή την ελάχιστη φωτεινότητα. Τα πλήκτρα ελέγχουν την οθόνη στην οποία είσαι εστιασμένος, οπότε οι εξωτερικές οθόνες που μιλούν DDC/CI ρυθμίζονται με τον ίδιο τρόπο όπως η οθόνη του φορητού υπολογιστή.

### Οθόνες Apple

Αν χρησιμοποιείς οθόνη Apple, τα κανονικά πλήκτρα φωτεινότητας του πληκτρολογίου θα δουλεύουν επίσης αυτόματα, αν είσαι εστιασμένος στην οθόνη Apple. Αυτό γίνεται μέσω της εντολής `asdcontrol`.

Σημείωσε ότι αν χρησιμοποιείς οθόνη Apple 6K XDR, μπορεί να δεις μια οθόνη-φάντασμα στην καταχώρισή σου `hyprctl monitors`. Μπορείς να την απενεργοποιήσεις με κάτι σαν `hl.monitor({ output = "DP-2", disabled = true })` μέσω του _Ρύθμιση > Οθόνες_.

Σε μηχανήματα Intel, πρέπει να συνδέεσαι σε οθόνες Apple χρησιμοποιώντας ένα κανονικό καλώδιο Thunderbolt. Σε άλλα μηχανήματα χωρίς Thunderbolt, συνήθως θα πρέπει να χρησιμοποιήσεις ένα [καλώδιο DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) για να το κάνεις να δουλέψει.
