# Οθόνες

Το Omarchy θεωρεί από προεπιλογή ότι χρησιμοποιείτε οθόνη κατηγορίας retina με δυνατότητα 2x. Αυτό χρειάζεστε για να έχετε εκείνες τις όμορφες, καθαρές γραμματοσειρές προγραμματιστή. Γι' αυτό είναι βελτιστοποιημένα σχεδόν όλα τα νέα premium laptop με οθόνες υψηλής ανάλυσης. Αυτό θα θέλατε να χρησιμοποιείτε σε μια 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) ή 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/).

Αν όμως δεν χρησιμοποιείτε οθόνη με PPI 218 ή παραπάνω, θα θελήσετε να αλλάξετε τις ρυθμίσεις οθόνης. Για παράδειγμα, αν έχετε μια 4K 27" ή 32", μπορείτε να επιλέξετε μια κλασματική κλίμακα για αυτήν από τον πίνακα οθονών στην επάνω γραμμή, ή να ορίσετε την προεπιλογή για κάθε οθόνη ανοίγοντας το `~/.config/hypr/monitors.lua` και αλλάζοντας στη σύσταση για αυτόν τον συνδυασμό:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

Αν χρησιμοποιείτε οθόνη 1080p ή 1440p, πιθανότατα θα θέλετε απλώς να χρησιμοποιήσετε κλιμάκωση 1x, και το ίδιο για τις εφαρμογές GTK και X11, οπότε μπορείτε να χρησιμοποιήσετε:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

Οι αλλαγές στο `GDK_SCALE` ισχύουν για εφαρμογές που ξεκινούν μετά την αλλαγή (και το GTK δέχεται μόνο ακέραιους αριθμούς, οπότε κρατήστε το στον πλησιέστερο ακέραιο της κλίμακας της οθόνης σας). Φροντίστε λοιπόν να κλείσετε τα παράθυρα που έχετε και είναι υπερμεγέθη μετά την αλλαγή (ή κλείστε όλα τα παράθυρα με `Ctrl + Alt + Del`!).

Μπορείτε επίσης να περάσετε γρήγορα από τις βασικές αναλογίες κλιμάκωσης οθόνης (1x, 1.25x, 1.6x, 2x, 3x, 4x) χρησιμοποιώντας `Super + /` για να πάτε ψηλότερα και `Super + Alt + /` για να πάτε χαμηλότερα, ή να επιλέξετε μία από τον πίνακα οθονών στην επάνω γραμμή. Αυτές αλλάζουν μόνο την οθόνη στην οποία είστε εστιασμένοι, οπότε η οθόνη ενός laptop και μια εξωτερική οθόνη μπορούν να έχουν η καθεμία τη δική της κλίμακα. Ο πίνακας ορίζει επίσης για κάθε οθόνη την ανάλυση, τον ρυθμό ανανέωσης και την περιστροφή της. Οι επιλογές σας αποθηκεύονται για τη συγκεκριμένη φυσική οθόνη στο `~/.local/state/omarchy/monitors/settings`, οπότε διατηρούνται μετά την επανεκκίνηση και ακολουθούν την οθόνη σε όποια θύρα ή dock συνδεθεί την επόμενη φορά. Έχουν προτεραιότητα έναντι οποιουδήποτε κανόνα για την ίδια οθόνη στο `~/.config/hypr/monitors.lua`, το οποίο το Omarchy δεν επεξεργάζεται ποτέ. Αν προτιμάτε να ορίζετε τις οθόνες σας εξ ολοκλήρου σε αυτό το αρχείο, προσθέστε σε αυτό το `omarchy_monitor_panel_settings = false`, και οι αλλαγές του πίνακα θα διαρκούν μόνο μέχρι να επαναφορτωθεί το Hyprland. Επειδή το `GDK_SCALE` είναι μία τιμή για όλες τις οθόνες, μια επιλεγμένη κλίμακα το ορίζει από την οθόνη με τη χαμηλότερη κλίμακα, οπότε οι εφαρμογές X11 βγαίνουν λίγο μικρές στην πυκνότερη οθόνη αντί για υπερμεγέθεις στην άλλη.

### Μεγέθυνση ή σμίκρυνση του κειμένου

Η κλιμάκωση οθόνης αλλάζει το μέγεθος των πάντων. Αν το μόνο που θέλετε είναι μεγαλύτερο ή μικρότερο _κείμενο_, υπάρχει ένας μόνο διακόπτης για αυτό:

```
omarchy display text size 14
```

Αυτό δέχεται ένα μέγεθος σε pixel μεταξύ 9 και 20, και μετακινεί μαζί το κέλυφος του Omarchy, τις εφαρμογές GTK και το τερματικό σας, οπότε ολόκληρη η επιφάνεια εργασίας παραμένει σε αναλογία. Εκτελέστε το χωρίς όρισμα για να δείτε πού βρίσκεστε, και `omarchy display text size reset` για να επιστρέψετε στην προεπιλογή. Το Foot είναι ο μόνος που μένει πίσω: δεν έχει τρόπο να επαναφορτώσει τη διαμόρφωσή του, οπότε τα τερματικά που ήδη τρέχουν κρατούν το παλιό τους μέγεθος μέχρι να ανοίξετε ένα νέο.

### Επέκταση και κατοπτρισμός οθονών laptop

Όταν συνδέετε μια εξωτερική οθόνη στο laptop σας, η οθόνη επεκτείνεται αυτόματα. Μπορείτε όμως να το αλλάξετε αυτό σε κατοπτρισμό αντί για επέκταση με τα _Extend_ | _Mirror_ στον πίνακα οθονών στην επάνω γραμμή, το _Trigger > Hardware_ στο μενού του Omarchy, ή το `Super + Ctrl + Alt + Delete`. Αυτό είναι ιδιαίτερα χρήσιμο αν αυτή η εξωτερική οθόνη είναι προτζέκτορας, και θέλετε να δείξετε κάτι ενώ εργάζεστε.

Όταν κάνετε επέκταση, το κλείσιμο του καπακιού στο laptop θα απενεργοποιήσει αυτόματα την εσωτερική οθόνη. Το άνοιγμα του καπακιού θα την ενεργοποιήσει ξανά. Μπορείτε επίσης να το ελέγξετε χειροκίνητα χρησιμοποιώντας το _Trigger > Hardware_ στο μενού του Omarchy ή το `Super + Ctrl + Delete`.

Ενώ το laptop είναι συνδεδεμένο στο ρεύμα, το κλείσιμο του καπακιού δεν το βάζει ποτέ σε αναστολή, οπότε ένα laptop σε dock παραμένει ξύπνιο ακόμη κι αν η εξωτερική οθόνη αποσυνδεθεί για λίγο. Χωρίς συνδεδεμένη εξωτερική οθόνη, το κλείσιμο του καπακιού στο ρεύμα απλώς το κλειδώνει. Στην μπαταρία, το κλείσιμο του καπακιού κάνει αναστολή ως συνήθως.

### Διάταξη πολλών οθονών

Το Hyprland δουλεύει εξαιρετικά με πολλές οθόνες. Ο πίνακας οθονών στην επάνω γραμμή τις σχεδιάζει εκεί όπου βρίσκονται: σύρετε μία πάνω στην πλευρά μιας άλλης για να τη μετακινήσετε εκεί, και η διάταξη αποθηκεύεται μαζί με τις άλλες ρυθμίσεις κάθε οθόνης. Για οτιδήποτε δεν καλύπτει ο πίνακας, διαβάστε περισσότερα για το πώς να τις διατάξετε στην [τεκμηρίωση οθονών του Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/). Στο Omarchy, αυτές μπαίνουν στο `~/.config/hypr/monitors.lua` ως καταχωρήσεις `hl.monitor` — το αρχείο παρέχεται με σχολιασμένα παραδείγματα για να κρατάτε μια οθόνη απενεργοποιημένη, για λειτουργίες που δεν προσφέρει ο πίνακας, για χρώμα 10-bit και για μεταβλητό ρυθμό ανανέωσης.

Κάθε οθόνη έχει δικούς της χώρους εργασίας 1 έως 10, οπότε το `Super + 1` σημαίνει πάντα τον πρώτο χώρο εργασίας της οθόνης στην οποία βρίσκεστε. Πίσω από τις σκηνές, το Hyprland εξακολουθεί να αριθμεί τους χώρους εργασίας σε όλες τις οθόνες: η οθόνη του laptop σας (ή η πρώτη οθόνη) παίρνει το 1–10, η επόμενη οθόνη το 11–20, και ούτω καθεξής, και κάθε οθόνη κρατά το μπλοκ της κάθε φορά που τη συνδέετε. Χρησιμοποιήστε αυτούς τους αριθμούς αν γράφετε [κανόνες χώρων εργασίας](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) ή κανόνες παραθύρων για μια συγκεκριμένη οθόνη, οπότε ο χώρος εργασίας 12 είναι ο δεύτερος χώρος εργασίας της δεύτερης οθόνης σας. Το `~/.local/state/omarchy/monitors/workspaces` αναφέρει ποιο μπλοκ έχει κάθε οθόνη.

Τα πλήκτρα βελών δουλεύουν μεταξύ οθονών που μοιράζονται μια πλευρά στη διάταξή σας. Οθόνες που ακουμπούν μόνο σε μια γωνία, ή που έχουν κενό μεταξύ τους, δεν είναι γειτονικές, οπότε χρησιμοποιήστε `Ctrl + Alt + Tab` για να μετακινηθείτε μεταξύ τους.

| Πλήκτρο συντόμευσης | Μεταξύ οθονών |
| --- | --- |
| `Super + Arrow` | Μετακινεί την εστίαση στην οθόνη εκείνης της πλευράς μόλις δεν έχει μείνει κανένα παράθυρο προς εκείνη την κατεύθυνση |
| `Super + Shift + Arrow` | Ανταλλάσσει με ένα παράθυρο στην οθόνη εκείνης της πλευράς |
| `Super + Alt + Arrow` | Μετακινεί το παράθυρο σε μια ομάδα στην οθόνη εκείνης της πλευράς |
| `Super + Shift + Ctrl + Arrow` | Μετακινεί το παράθυρο στην οθόνη εκείνης της πλευράς, στον χώρο εργασίας που δείχνει |
| `Super + Shift + Alt + Arrow` | Μετακινεί τον χώρο εργασίας στην οθόνη εκείνης της πλευράς, κρατώντας τον αριθμό του αν είναι ελεύθερος |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | Μετακινεί την εστίαση στην επόμενη ή την προηγούμενη οθόνη, όποια κι αν είναι η διάταξη |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | Παραμένουν στην οθόνη στην οποία βρίσκεστε |

Μπορείτε επίσης να ρίξετε μια ματιά στο [Hyprmon](https://github.com/erans/hyprmon/), αν θα θέλατε ένα TUI να σας βοηθήσει με την τοποθέτηση πολλών οθονών.

### Έλεγχος φωτεινότητας

Η φωτεινότητα της οθόνης ελέγχεται από τα ειδικά πλήκτρα λειτουργιών για αύξηση/μείωση φωτεινότητας. Αν κρατήσετε πατημένο το shift ενώ πατάτε αυτά, θα πάτε στη μέγιστη ή την ελάχιστη φωτεινότητα. Τα πλήκτρα ελέγχουν την οθόνη στην οποία είστε εστιασμένοι, οπότε οι εξωτερικές οθόνες που μιλούν DDC/CI ρυθμίζονται με τον ίδιο τρόπο όπως η οθόνη του laptop.

### Οθόνες Apple

Αν χρησιμοποιείτε οθόνη Apple, τα κανονικά πλήκτρα φωτεινότητας του πληκτρολογίου θα δουλεύουν επίσης αυτόματα, αν είστε εστιασμένοι στην οθόνη Apple. Αυτό γίνεται μέσω της εντολής `asdcontrol`.

Σημειώστε ότι αν χρησιμοποιείτε οθόνη Apple 6K XDR, μπορεί να δείτε μια οθόνη-φάντασμα στην καταχώρισή σας `hyprctl monitors`. Μπορείτε να το απενεργοποιήσετε με κάτι σαν `hl.monitor({ output = "DP-2", disabled = true })` στο `~/.config/hypr/monitors.lua`.

Σε μηχανήματα Intel, θα πρέπει να συνδέεστε σε οθόνες Apple χρησιμοποιώντας ένα κανονικό καλώδιο Thunderbolt. Σε άλλα μηχανήματα χωρίς Thunderbolt, συνήθως θα πρέπει να χρησιμοποιήσετε ένα [καλώδιο DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) για να το κάνετε να δουλέψει.
