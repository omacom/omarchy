# Οθόνες

Το Omarchy θεωρεί δεδομένο εξ ορισμού ότι χρησιμοποιείς οθόνη κατηγορίας retina με δυνατότητα 2x. Αυτό χρειάζεσαι για να έχεις εκείνες τις ωραίες, καθαρές γραμματοσειρές προγραμματισμού. Είναι αυτό για το οποίο είναι βελτιστοποιημένοι σχεδόν όλοι οι νέοι premium φορητοί υπολογιστές με οθόνες υψηλής ανάλυσης. Είναι αυτό που θα ήθελες να χρησιμοποιείς σε μια 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) ή 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/).

Αν όμως δεν χρησιμοποιείς οθόνη με PPI 218 ή παραπάνω, θα θέλεις να αλλάξεις τις ρυθμίσεις οθόνης. Για παράδειγμα, αν έχεις 4K 27" ή 32", μπορείς να χρησιμοποιήσεις κλασματική κλιμάκωση ανοίγοντας το `~/.config/hypr/monitors.lua` (μέσω του _Setup > Monitors_ στο μενού του Omarchy) και αλλάζοντας στη σύσταση για αυτόν τον συνδυασμό:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

Αν χρησιμοποιείς οθόνη 1080p ή 1440p, πιθανότατα θα θέλεις απλώς να χρησιμοποιήσεις κλιμάκωση 1x, οπότε μπορείς να χρησιμοποιήσεις:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

Οι αλλαγές στο `GDK_SCALE` ισχύουν για εφαρμογές που ξεκινούν μετά την αλλαγή (και το GTK δέχεται μόνο ακέραιους αριθμούς, οπότε κράτα το στον πλησιέστερο ακέραιο της κλιμάκωσης της οθόνης σου). Φρόντισε λοιπόν να κλείσεις τα παράθυρα που έχεις και είναι υπερμεγέθη μετά την αλλαγή (ή κλείσε όλα τα παράθυρα με `Ctrl + Alt + Del`!).

Μπορείς επίσης να περνάς γρήγορα από τις βασικές αναλογίες κλιμάκωσης οθόνης (1x, 1.25x, 1.6x, 2x, 3x, 4x) χρησιμοποιώντας το `Super + /` για να πας ψηλότερα και το `Super + Alt + /` για να πας χαμηλότερα. Αν έχεις την προεπιλεγμένη διαμόρφωση, αυτές οι αλλαγές θα διατηρηθούν και μετά την επανεκκίνηση.

### Μεγέθυνση ή σμίκρυνση του κειμένου

Η κλιμάκωση οθόνης αλλάζει το μέγεθος των πάντων. Αν το μόνο που θέλεις είναι μεγαλύτερο ή μικρότερο _κείμενο_, υπάρχει ένας μόνο διακόπτης για αυτό:

```
omarchy display text size 14
```

Αυτό δέχεται ένα μέγεθος σε pixel μεταξύ 9 και 20, και μετακινεί μαζί το κέλυφος του Omarchy, τις εφαρμογές GTK και το τερματικό σου, ώστε ολόκληρη η επιφάνεια εργασίας να παραμένει σε αναλογία. Εκτέλεσέ το χωρίς όρισμα για να δεις πού βρίσκεσαι, και `omarchy display text size reset` για να επιστρέψεις στην προεπιλογή. Το Foot είναι η μοναδική εξαίρεση που μένει πίσω: δεν έχει τρόπο να επαναφορτώσει τη διαμόρφωσή του, οπότε τα τερματικά που ήδη τρέχουν κρατούν το παλιό τους μέγεθος μέχρι να ανοίξεις ένα νέο.

### Επέκταση και κατοπτρισμός οθονών φορητού υπολογιστή

Όταν συνδέεις μια εξωτερική οθόνη στον φορητό υπολογιστή σου, η οθόνη επεκτείνεται αυτόματα. Μπορείς όμως να το αλλάξεις αυτό σε κατοπτρισμό χρησιμοποιώντας το _Trigger > Hardware_ στο μενού του Omarchy ή το `Super + Ctrl + Alt + Delete`. Αυτό είναι ιδιαίτερα χρήσιμο αν εκείνη η εξωτερική οθόνη είναι προβολέας, και θέλεις να δείξεις κάτι ενώ δουλεύεις.

Όταν κάνεις επέκταση, το κλείσιμο του καπακιού του φορητού υπολογιστή θα απενεργοποιήσει αυτόματα την εσωτερική οθόνη. Το άνοιγμα του καπακιού θα την ενεργοποιήσει ξανά. Μπορείς επίσης να το ελέγχεις χειροκίνητα χρησιμοποιώντας το _Trigger > Hardware_ στο μενού του Omarchy ή το `Super + Ctrl + Delete`.

### Διάταξη πολλών οθονών

Το Hyprland δουλεύει εξαιρετικά με πολλές οθόνες. Διάβασε περισσότερα για το πώς να τις διατάξεις στην [τεκμηρίωση του Hyprland για τις οθόνες](https://wiki.hypr.land/Configuring/Basics/Monitors/). Στο Omarchy, αυτές μπαίνουν στο `~/.config/hypr/monitors.lua` ως καταχωρήσεις `hl.monitor` — το αρχείο συνοδεύεται από παραδείγματα σε σχόλια για τον ορισμό μιας συγκεκριμένης οθόνης σε μια ανάλυση, θέση και περιστροφή.

Κάθε οθόνη έχει τους δικούς της χώρους εργασίας 1 έως 10, οπότε το `Super + 1` σημαίνει πάντα τον πρώτο χώρο εργασίας της οθόνης στην οποία βρίσκεσαι. Πίσω από τις σκηνές, το Hyprland εξακολουθεί να αριθμεί τους χώρους εργασίας σε όλες τις οθόνες: η οθόνη του φορητού υπολογιστή σου (ή η πρώτη οθόνη) παίρνει το 1–10, η επόμενη οθόνη το 11–20, και ούτω καθεξής, και κάθε οθόνη κρατά το μπλοκ της κάθε φορά που τη συνδέεις. Χρησιμοποίησε αυτούς τους αριθμούς αν γράψεις [κανόνες χώρων εργασίας](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) ή κανόνες παραθύρων για μια συγκεκριμένη οθόνη, ώστε ο χώρος εργασίας 12 να είναι ο δεύτερος χώρος εργασίας της δεύτερης οθόνης σου. Το `~/.local/state/omarchy/monitor-workspaces` αναφέρει ποιο μπλοκ έχει κάθε οθόνη.

Τα πλήκτρα βελών δουλεύουν μεταξύ οθονών που μοιράζονται μια πλευρά στη διάταξή σου. Οθόνες που αγγίζονται μόνο σε μια γωνία, ή που έχουν κενό μεταξύ τους, δεν είναι γείτονες, οπότε χρησιμοποίησε το `Ctrl + Alt + Tab` για να μετακινηθείς μεταξύ τους.

| Πλήκτρο συντόμευσης | Μεταξύ οθονών |
| --- | --- |
| `Super + Arrow` | Μετακινεί την εστίαση στην οθόνη εκείνης της πλευράς μόλις δεν υπάρχει άλλο παράθυρο προς εκείνη την κατεύθυνση |
| `Super + Shift + Arrow` | Ανταλλάσσει με ένα παράθυρο στην οθόνη εκείνης της πλευράς |
| `Super + Alt + Arrow` | Μετακινεί το παράθυρο σε μια ομάδα στην οθόνη εκείνης της πλευράς |
| `Super + Shift + Ctrl + Arrow` | Μετακινεί το παράθυρο στην οθόνη εκείνης της πλευράς, στον χώρο εργασίας που δείχνει |
| `Super + Shift + Alt + Arrow` | Μετακινεί τον χώρο εργασίας στην οθόνη εκείνης της πλευράς, κρατώντας τον αριθμό του αν είναι ελεύθερος |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | Μετακινεί την εστίαση στην επόμενη ή την προηγούμενη οθόνη, όποια κι αν είναι η διάταξη |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | Παραμένουν στην οθόνη στην οποία βρίσκεσαι |

Μπορείς επίσης να ρίξεις μια ματιά στο [Hyprmon](https://github.com/erans/hyprmon/), αν θα ήθελες ένα TUI για να σε βοηθήσει με την τοποθέτηση πολλών οθονών.

### Έλεγχος φωτεινότητας

Η φωτεινότητα της οθόνης ελέγχεται από τα ειδικά πλήκτρα λειτουργιών για αύξηση/μείωση φωτεινότητας. Αν κρατάς πατημένο το Shift ενώ πατάς αυτά, θα πας στη μέγιστη ή την ελάχιστη φωτεινότητα. Τα πλήκτρα ελέγχουν την οθόνη στην οποία είσαι εστιασμένος, οπότε οι εξωτερικές οθόνες που μιλούν DDC/CI ρυθμίζονται με τον ίδιο τρόπο όπως η οθόνη του φορητού υπολογιστή.

### Οθόνες Apple

Αν χρησιμοποιείς οθόνη Apple, τα κανονικά πλήκτρα φωτεινότητας του πληκτρολογίου θα δουλεύουν επίσης αυτόματα, αν είσαι εστιασμένος στην οθόνη Apple. Αυτό γίνεται μέσω της εντολής `asdcontrol`.

Σημείωσε ότι αν χρησιμοποιείς οθόνη Apple 6K XDR, μπορεί να δεις μια φανταστική οθόνη στην καταχώρισή σου `hyprctl monitors`. Μπορείς να την απενεργοποιήσεις με κάτι σαν `hl.monitor({ output = "DP-2", disabled = true })` μέσω του _Setup > Monitors_.

Στα μηχανήματα Intel, πρέπει να συνδέεσαι σε οθόνες Apple χρησιμοποιώντας ένα κανονικό καλώδιο Thunderbolt. Σε άλλα μηχανήματα χωρίς Thunderbolt, συνήθως θα πρέπει να χρησιμοποιήσεις ένα [DP + USB-A -> USB-C cable](https://www.amazon.com/dp/B0BNX7MS6N) για να το κάνεις να δουλέψει.
