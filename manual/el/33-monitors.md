# Οθόνες

Το Omarchy θεωρεί από προεπιλογή ότι χρησιμοποιείς οθόνη κατηγορίας retina με δυνατότητα 2x. Αυτό είναι που χρειάζεσαι για να έχεις αυτές τις ωραίες, ευκρινείς γραμματοσειρές προγραμματισμού. Για αυτό είναι βελτιστοποιημένοι σχεδόν όλοι οι νέοι premium φορητοί υπολογιστές με οθόνες υψηλής ανάλυσης. Αυτό θα ήθελες να χρησιμοποιείς σε μια 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) ή 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/).

Αλλά αν δεν χρησιμοποιείς οθόνη με PPI 218 ή παραπάνω, θα θέλεις να αλλάξεις τις ρυθμίσεις οθόνης. Για παράδειγμα, αν έχεις μια 4K 27" ή 32", μπορείς να επιλέξεις μια κλασματική κλιμάκωση για αυτήν από τον πίνακα οθόνης στην επάνω γραμμή ή να ορίσεις την προεπιλογή για κάθε οθόνη ανοίγοντας το `~/.config/hypr/monitors.lua` και αλλάζοντας στη σύσταση για αυτόν τον συνδυασμό:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

Αν χρησιμοποιείς οθόνη 1080p ή 1440p, πιθανότατα θα θέλεις απλώς να χρησιμοποιήσεις κλιμάκωση 1x, και το ίδιο για τις εφαρμογές GTK και X11, οπότε μπορείς να χρησιμοποιήσεις:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

Οι αλλαγές στο `GDK_SCALE` ισχύουν για τις εφαρμογές που ξεκινούν μετά την αλλαγή (και το GTK δέχεται μόνο ακέραιους αριθμούς, οπότε κράτα το στον πλησιέστερο ακέραιο της κλιμάκωσης της οθόνης σου). Οπότε βεβαιώσου ότι κλείνεις τα παράθυρα που έχεις και είναι υπερμεγέθη μετά την αλλαγή (ή κλείσε όλα τα παράθυρα με `Ctrl + Alt + Del`!).

Μπορείς επίσης να περάσεις γρήγορα από τις βασικές αναλογίες κλιμάκωσης οθόνης (1x, 1.25x, 1.6x, 2x, 3x, 4x) χρησιμοποιώντας `Super + /` για να πας ψηλότερα και `Super + Alt + /` για να πας χαμηλότερα, ή να επιλέξεις μία από τον πίνακα οθόνης στην επάνω γραμμή. Αυτές αλλάζουν μόνο την οθόνη στην οποία είσαι εστιασμένος, οπότε μια οθόνη φορητού υπολογιστή και μια εξωτερική οθόνη μπορούν να έχουν η καθεμία τη δική της κλιμάκωση. Ο πίνακας ορίζει επίσης την ανάλυση κάθε οθόνης. Οι επιλογές σου αποθηκεύονται για αυτή τη φυσική οθόνη στο `~/.local/state/omarchy/monitors/settings`, οπότε διατηρούνται μετά την επανεκκίνηση και ακολουθούν την οθόνη σε όποια θύρα ή βάση σύνδεσης συνδεθεί την επόμενη φορά. Έχουν προτεραιότητα έναντι οποιουδήποτε κανόνα για την ίδια οθόνη στο `~/.config/hypr/monitors.lua`, το οποίο το Omarchy δεν επεξεργάζεται ποτέ. Επειδή το `GDK_SCALE` είναι μία τιμή για όλες τις οθόνες, μια επιλεγμένη κλιμάκωση το ορίζει από την οθόνη με τη χαμηλότερη κλιμάκωση, οπότε οι εφαρμογές X11 βγαίνουν λίγο μικρές στην πυκνότερη οθόνη αντί για υπερμεγέθεις στην άλλη.

### Μεγέθυνση ή σμίκρυνση κειμένου

Η κλιμάκωση οθόνης αλλάζει το μέγεθος των πάντων. Αν το μόνο που θέλεις είναι μεγαλύτερο ή μικρότερο _κείμενο_, υπάρχει μία μόνο ρύθμιση για αυτό:

```
omarchy display text size 14
```

Αυτό παίρνει ένα μέγεθος σε pixel μεταξύ 9 και 20 και μετακινεί μαζί το κέλυφος του Omarchy, τις εφαρμογές GTK και το τερματικό σου, ώστε ολόκληρη η επιφάνεια εργασίας να παραμένει σε αναλογία. Εκτέλεσέ το χωρίς όρισμα για να δεις πού βρίσκεσαι και `omarchy display text size reset` για να επιστρέψεις στην προεπιλογή. Το Foot είναι ο μόνος καθυστερημένος: δεν έχει τρόπο να επαναφορτώσει τη διαμόρφωσή του, οπότε τα τερματικά που ήδη εκτελούνται διατηρούν το παλιό τους μέγεθος μέχρι να ανοίξεις ένα νέο.

### Επέκταση και κατοπτρισμός οθονών φορητού υπολογιστή

Όταν συνδέεις μια εξωτερική οθόνη στον φορητό υπολογιστή σου, η οθόνη επεκτείνεται αυτόματα. Αλλά μπορείς να το αλλάξεις αυτό σε κατοπτρισμό χρησιμοποιώντας το _Trigger > Hardware_ στο μενού του Omarchy ή το `Super + Ctrl + Alt + Delete`. Αυτό είναι ιδιαίτερα χρήσιμο αν αυτή η εξωτερική οθόνη είναι προβολέας και θέλεις να δείξεις κάτι ενώ εργάζεσαι.

Όταν κάνεις επέκταση, το κλείσιμο του καπακιού στον φορητό υπολογιστή θα απενεργοποιήσει αυτόματα την εσωτερική οθόνη. Το άνοιγμα του καπακιού θα την ενεργοποιήσει ξανά. Μπορείς επίσης να το ελέγξεις χειροκίνητα χρησιμοποιώντας το _Trigger > Hardware_ στο μενού του Omarchy ή το `Super + Ctrl + Delete`.

### Τακτοποίηση πολλών οθονών

Το Hyprland λειτουργεί εξαιρετικά με πολλές οθόνες. Ο πίνακας οθόνης στην επάνω γραμμή τις σχεδιάζει εκεί όπου βρίσκονται: σύρε μία πάνω στην πλευρά μιας άλλης για να τη μετακινήσεις εκεί και η διάταξη αποθηκεύεται μαζί με τις άλλες ρυθμίσεις κάθε οθόνης. Για οτιδήποτε δεν καλύπτει ο πίνακας, διάβασε περισσότερα για το πώς να τις διατάξεις στην [τεκμηρίωση οθονών του Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/). Στο Omarchy, αυτά μπαίνουν στο `~/.config/hypr/monitors.lua` ως καταχωρίσεις `hl.monitor` — το αρχείο συνοδεύεται από σχολιασμένα παραδείγματα για το καρφίτσωμα μιας συγκεκριμένης οθόνης σε μια ανάλυση, θέση και περιστροφή.

Κάθε οθόνη έχει τους δικούς της χώρους εργασίας 1 έως 10, οπότε το `Super + 1` σημαίνει πάντα τον πρώτο χώρο εργασίας της οθόνης στην οποία βρίσκεσαι. Πίσω από τις σκηνές, το Hyprland εξακολουθεί να αριθμεί τους χώρους εργασίας σε όλες τις οθόνες: η οθόνη του φορητού υπολογιστή σου (ή η πρώτη οθόνη) παίρνει το 1–10, η επόμενη οθόνη το 11–20 και ούτω καθεξής, και κάθε οθόνη διατηρεί το μπλοκ της κάθε φορά που τη συνδέεις. Χρησιμοποίησε αυτούς τους αριθμούς αν γράψεις [κανόνες χώρων εργασίας](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) ή κανόνες παραθύρων για μια συγκεκριμένη οθόνη, οπότε ο χώρος εργασίας 12 είναι ο δεύτερος χώρος εργασίας της δεύτερης οθόνης σου. Το `~/.local/state/omarchy/monitors/workspaces` αναφέρει ποιο μπλοκ έχει κάθε οθόνη.

Τα πλήκτρα βέλους λειτουργούν ανάμεσα σε οθόνες που μοιράζονται μια πλευρά στη διάταξή σου. Οι οθόνες που αγγίζονται μόνο σε μια γωνία ή που έχουν κενό μεταξύ τους δεν είναι γειτονικές, οπότε χρησιμοποίησε το `Ctrl + Alt + Tab` για να μετακινηθείς μεταξύ τους.

| Πλήκτρο συντόμευσης | Ανάμεσα σε οθόνες |
| --- | --- |
| `Super + Arrow` | Μετακινεί την εστίαση στην οθόνη σε εκείνη την πλευρά μόλις δεν υπάρχει άλλο παράθυρο προς εκείνη την κατεύθυνση |
| `Super + Shift + Arrow` | Ανταλλάσσει με ένα παράθυρο στην οθόνη σε εκείνη την πλευρά |
| `Super + Alt + Arrow` | Μετακινεί το παράθυρο σε μια ομάδα στην οθόνη σε εκείνη την πλευρά |
| `Super + Shift + Ctrl + Arrow` | Μετακινεί το παράθυρο στην οθόνη σε εκείνη την πλευρά, στον χώρο εργασίας που δείχνει |
| `Super + Shift + Alt + Arrow` | Μετακινεί τον χώρο εργασίας στην οθόνη σε εκείνη την πλευρά, διατηρώντας τον αριθμό του αν είναι ελεύθερος |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | Μετακινεί την εστίαση στην επόμενη ή την προηγούμενη οθόνη, όποια κι αν είναι η διάταξη |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | Παραμένουν στην οθόνη στην οποία βρίσκεσαι |

Μπορείς επίσης να ρίξεις μια ματιά στο [Hyprmon](https://github.com/erans/hyprmon/), αν θα ήθελες ένα TUI για να σε βοηθήσει με την τοποθέτηση πολλών οθονών.

### Έλεγχος φωτεινότητας

Η φωτεινότητα της οθόνης ελέγχεται από τα ειδικά πλήκτρα λειτουργιών για αύξηση/μείωση φωτεινότητας. Αν κρατήσεις πατημένο το shift ενώ πατάς αυτά, θα πας στη μέγιστη ή την ελάχιστη φωτεινότητα. Τα πλήκτρα ελέγχουν την οθόνη στην οποία είσαι εστιασμένος, οπότε οι εξωτερικές οθόνες που μιλούν DDC/CI ρυθμίζονται με τον ίδιο τρόπο όπως η οθόνη του φορητού υπολογιστή.

### Οθόνες Apple

Αν χρησιμοποιείς οθόνη Apple, τα κανονικά πλήκτρα φωτεινότητας του πληκτρολογίου θα λειτουργούν επίσης αυτόματα, αν είσαι εστιασμένος στην οθόνη Apple. Αυτό γίνεται μέσω της εντολής `asdcontrol`.

Σημείωσε ότι αν χρησιμοποιείς οθόνη Apple 6K XDR, μπορεί να δεις μια οθόνη-φάντασμα στην καταχώρισή σου `hyprctl monitors`. Μπορείς να το απενεργοποιήσεις με κάτι σαν `hl.monitor({ output = "DP-2", disabled = true })` στο `~/.config/hypr/monitors.lua`.

Στα μηχανήματα Intel, θα πρέπει να συνδέεσαι σε οθόνες Apple χρησιμοποιώντας ένα κανονικό καλώδιο Thunderbolt. Σε άλλα μηχανήματα χωρίς Thunderbolt, συνήθως θα πρέπει να χρησιμοποιήσεις ένα [DP + USB-A -> USB-C cable](https://www.amazon.com/dp/B0BNX7MS6N) για να το κάνεις να λειτουργήσει.
