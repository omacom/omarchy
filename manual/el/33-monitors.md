# Οθόνες

Το Omarchy θεωρεί από προεπιλογή δεδομένο ότι χρησιμοποιείτε οθόνη κατηγορίας retina με δυνατότητα 2x. Αυτό είναι που χρειάζεστε για να έχετε αυτές τις ωραίες, πεντακάθαρες γραμματοσειρές προγραμματισμού. Είναι αυτό για το οποίο είναι βελτιστοποιημένοι σχεδόν όλοι οι νέοι premium φορητοί υπολογιστές με οθόνες υψηλής ανάλυσης. Είναι αυτό που θα θέλατε να χρησιμοποιείτε σε μια 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) ή 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/).

Αν όμως δεν χρησιμοποιείτε οθόνη με PPI 218 ή παραπάνω, θα θέλετε να αλλάξετε τις ρυθμίσεις οθόνης. Για παράδειγμα, αν έχετε μια 4K 27" ή 32", μπορείτε να επιλέξετε μια κλασματική κλίμακα για αυτήν από τον πίνακα οθόνης στην επάνω γραμμή, ή να ορίσετε την προεπιλογή για κάθε οθόνη ανοίγοντας το `~/.config/hypr/monitors.lua` και αλλάζοντας στη σύσταση για αυτόν τον συνδυασμό:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

Αν χρησιμοποιείτε οθόνη 1080p ή 1440p, πιθανότατα θα θέλετε απλώς να χρησιμοποιήσετε κλιμάκωση 1x, και το ίδιο για τις εφαρμογές GTK και X11, οπότε μπορείτε να χρησιμοποιήσετε:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

Οι αλλαγές στο `GDK_SCALE` ισχύουν για εφαρμογές που ξεκινούν μετά την αλλαγή (και το GTK δέχεται μόνο ακέραιους αριθμούς, οπότε κρατήστε το στον πλησιέστερο ακέραιο της κλίμακας της οθόνης σας). Φροντίστε λοιπόν να κλείσετε τα παράθυρα που έχετε και είναι υπερμεγέθη μετά την αλλαγή (ή κλείστε όλα τα παράθυρα με `Ctrl + Alt + Del`!).

Μπορείτε επίσης να περάσετε γρήγορα από τις βασικές αναλογίες κλιμάκωσης οθόνης (1x, 1.25x, 1.6x, 2x, 3x, 4x) χρησιμοποιώντας το `Super + /` για να ανεβείτε και το `Super + Alt + /` για να κατεβείτε, ή να επιλέξετε μία από τον πίνακα οθόνης στην επάνω γραμμή. Αυτές αλλάζουν μόνο την οθόνη στην οποία είστε εστιασμένοι, οπότε η οθόνη ενός φορητού υπολογιστή και μια εξωτερική οθόνη μπορούν να έχουν η καθεμία τη δική της κλίμακα. Ο πίνακας ορίζει επίσης για κάθε οθόνη την ανάλυση, τον ρυθμό ανανέωσης και την περιστροφή της. Οι επιλογές σας αποθηκεύονται για τη συγκεκριμένη φυσική οθόνη στο `~/.local/state/omarchy/monitors/settings`, οπότε διατηρούνται μετά την επανεκκίνηση και ακολουθούν την οθόνη σε όποια θύρα ή βάση σύνδεσης την συνδέσετε την επόμενη φορά. Έχουν προτεραιότητα έναντι οποιουδήποτε κανόνα για την ίδια οθόνη στο `~/.config/hypr/monitors.lua`, το οποίο το Omarchy δεν επεξεργάζεται ποτέ. Αν προτιμάτε να ρυθμίζετε τις οθόνες σας εξ ολοκλήρου σε αυτό το αρχείο, προσθέστε σε αυτό το `omarchy_monitor_panel_settings = false`, και οι αλλαγές του πίνακα θα διαρκούν μόνο μέχρι να επαναφορτωθεί το Hyprland. Επειδή το `GDK_SCALE` είναι μία τιμή για όλες τις οθόνες, μια επιλεγμένη κλίμακα το ορίζει από την οθόνη με τη χαμηλότερη κλίμακα, οπότε οι εφαρμογές X11 βγαίνουν λίγο μικρές στην πυκνότερη οθόνη αντί για υπερμεγέθεις στην άλλη.

### Κάνοντας το κείμενο μεγαλύτερο ή μικρότερο

Η κλιμάκωση οθόνης αλλάζει το μέγεθος των πάντων. Αν το μόνο που θέλετε είναι μεγαλύτερο ή μικρότερο _κείμενο_, υπάρχει μία μόνο ρύθμιση για αυτό:

```
omarchy display text size 14
```

Αυτό δέχεται ένα μέγεθος σε pixel μεταξύ 9 και 20, και μετακινεί μαζί το κέλυφος του Omarchy, τις εφαρμογές GTK και το τερματικό σας, οπότε ολόκληρη η επιφάνεια εργασίας παραμένει σε αναλογία. Εκτελέστε το χωρίς όρισμα για να δείτε πού βρίσκεστε, και `omarchy display text size reset` για να επιστρέψετε στην προεπιλογή. Το Foot είναι ο μόνος που μένει πίσω: δεν έχει τρόπο να επαναφορτώσει τη διαμόρφωσή του, οπότε τα τερματικά που ήδη τρέχουν κρατούν το παλιό τους μέγεθος μέχρι να ανοίξετε ένα νέο.

### Επέκταση και κατοπτρισμός οθονών φορητού υπολογιστή

Όταν συνδέετε μια εξωτερική οθόνη στον φορητό υπολογιστή σας, η οθόνη επεκτείνεται αυτόματα. Μπορείτε όμως να το αλλάξετε αυτό σε κατοπτρισμό αντί για επέκταση με _Επέκταση_ | _Κατοπτρισμός_ στον πίνακα οθόνης στην επάνω γραμμή, _Trigger > Hardware_ στο μενού του Omarchy, ή `Super + Ctrl + Alt + Delete`. Αυτό είναι ιδιαίτερα χρήσιμο αν αυτή η εξωτερική οθόνη είναι προβολέας, και θέλετε να δείξετε κάτι ενώ εργάζεστε.

Όταν κάνετε επέκταση, το κλείσιμο του καπακιού στον φορητό υπολογιστή θα απενεργοποιήσει αυτόματα την εσωτερική οθόνη. Το άνοιγμα του καπακιού θα την ενεργοποιήσει ξανά. Μπορείτε επίσης να το ελέγχετε αυτό χειροκίνητα χρησιμοποιώντας το _Trigger > Hardware_ στο μενού του Omarchy ή το `Super + Ctrl + Delete`.

### Τακτοποίηση πολλών οθονών

Το Hyprland λειτουργεί εξαιρετικά με πολλές οθόνες. Ο πίνακας οθόνης στην επάνω γραμμή τις σχεδιάζει εκεί όπου βρίσκονται: σύρετε τη μία πάνω στην πλευρά μιας άλλης για να τη μετακινήσετε εκεί, και η διάταξη αποθηκεύεται μαζί με τις υπόλοιπες ρυθμίσεις κάθε οθόνης. Για οτιδήποτε δεν καλύπτει ο πίνακας, διαβάστε περισσότερα για το πώς να τις διατάξετε στην [τεκμηρίωση του Hyprland για τις οθόνες](https://wiki.hypr.land/Configuring/Basics/Monitors/). Στο Omarchy, αυτά μπαίνουν στο `~/.config/hypr/monitors.lua` ως καταχωρήσεις `hl.monitor` — το αρχείο συνοδεύεται από σχολιασμένα παραδείγματα για να κρατάτε μια οθόνη απενεργοποιημένη, για λειτουργίες που δεν προσφέρει ο πίνακας, για χρώμα 10-bit και για μεταβλητό ρυθμό ανανέωσης.

Κάθε οθόνη έχει τους δικούς της χώρους εργασίας 1 έως 10, οπότε το `Super + 1` σημαίνει πάντα τον πρώτο χώρο εργασίας της οθόνης στην οποία βρίσκεστε. Στο παρασκήνιο, το Hyprland εξακολουθεί να αριθμεί τους χώρους εργασίας σε όλες τις οθόνες: η οθόνη του φορητού υπολογιστή σας (ή η πρώτη οθόνη) παίρνει το 1–10, η επόμενη οθόνη το 11–20, και ούτω καθεξής, και κάθε οθόνη κρατά το μπλοκ της κάθε φορά που τη συνδέετε. Χρησιμοποιήστε αυτούς τους αριθμούς αν γράφετε [κανόνες χώρων εργασίας](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) ή κανόνες παραθύρων για μια συγκεκριμένη οθόνη, οπότε ο χώρος εργασίας 12 είναι ο δεύτερος χώρος εργασίας της δεύτερης οθόνης σας. Το `~/.local/state/omarchy/monitors/workspaces` αναφέρει ποιο μπλοκ έχει κάθε οθόνη.

Τα πλήκτρα βέλους λειτουργούν μεταξύ οθονών που μοιράζονται μια πλευρά στη διάταξή σας. Οθόνες που αγγίζονται μόνο σε μια γωνία, ή που έχουν κενό μεταξύ τους, δεν είναι γειτονικές, οπότε χρησιμοποιήστε το `Ctrl + Alt + Tab` για να μετακινηθείτε μεταξύ τους.

| Πλήκτρο συντόμευσης | Μεταξύ οθονών |
| --- | --- |
| `Super + Arrow` | Μετακινεί την εστίαση στην οθόνη εκείνης της πλευράς μόλις δεν υπάρχει άλλο παράθυρο προς αυτή την κατεύθυνση |
| `Super + Shift + Arrow` | Ανταλλάσσει με ένα παράθυρο στην οθόνη εκείνης της πλευράς |
| `Super + Alt + Arrow` | Μετακινεί το παράθυρο σε μια ομάδα στην οθόνη εκείνης της πλευράς |
| `Super + Shift + Ctrl + Arrow` | Μετακινεί το παράθυρο στην οθόνη εκείνης της πλευράς, στον χώρο εργασίας που αυτή προβάλλει |
| `Super + Shift + Alt + Arrow` | Μετακινεί τον χώρο εργασίας στην οθόνη εκείνης της πλευράς, διατηρώντας τον αριθμό του αν είναι ελεύθερος |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | Μετακινεί την εστίαση στην επόμενη ή την προηγούμενη οθόνη, ανεξάρτητα από τη διάταξη |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | Παραμένουν στην οθόνη στην οποία βρίσκεστε |

Μπορείτε επίσης να ρίξετε μια ματιά στο [Hyprmon](https://github.com/erans/hyprmon/), αν θα θέλατε ένα TUI να σας βοηθήσει με την τοποθέτηση πολλών οθονών.

### Έλεγχος φωτεινότητας

Η φωτεινότητα της οθόνης ελέγχεται από τα ειδικά πλήκτρα λειτουργιών για αύξηση/μείωση φωτεινότητας. Αν κρατήσετε πατημένο το shift ενώ πατάτε αυτά, θα πάτε στη μέγιστη ή την ελάχιστη φωτεινότητα. Τα πλήκτρα ελέγχουν την οθόνη στην οποία είστε εστιασμένοι, οπότε οι εξωτερικές οθόνες που μιλούν DDC/CI ρυθμίζονται με τον ίδιο τρόπο όπως η οθόνη του φορητού υπολογιστή.

### Οθόνες Apple

Αν χρησιμοποιείτε οθόνη Apple, τα κανονικά πλήκτρα φωτεινότητας του πληκτρολογίου θα λειτουργούν επίσης αυτόματα, αν είστε εστιασμένοι στην οθόνη Apple. Αυτό γίνεται μέσω της εντολής `asdcontrol`.

Σημειώστε ότι αν χρησιμοποιείτε οθόνη Apple 6K XDR, μπορεί να δείτε μια οθόνη-φάντασμα στη λίστα του `hyprctl monitors`. Μπορείτε να το απενεργοποιήσετε αυτό με κάτι σαν `hl.monitor({ output = "DP-2", disabled = true })` στο `~/.config/hypr/monitors.lua`.

Σε μηχανήματα Intel, θα πρέπει να συνδέεστε σε οθόνες Apple χρησιμοποιώντας ένα κανονικό καλώδιο Thunderbolt. Σε άλλα μηχανήματα χωρίς Thunderbolt, συνήθως θα πρέπει να χρησιμοποιήσετε ένα [καλώδιο DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) για να το κάνετε να λειτουργήσει.
