# Οθόνες

Το Omarchy υποθέτει ότι εργάζεστε σε μια οθόνη κλάσης retina ικανή για 2x από προεπιλογή. Αυτό είναι που χρειάζεστε για να πάρετε εκείνες τις ωραίες, ευκρινείς γραμματοσειρές προγραμματιστή. Είναι αυτό για το οποίο βελτιστοποιούνται σχεδόν όλοι οι νέοι φορητοί υψηλής τεχνολογίας με οθόνες υψηλής ανάλυσης. Είναι αυτό που θα θέλατε να τρέχετε σε μια 27" 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) ή 32" 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/).

Αλλά αν δεν χρησιμοποιείτε μια οθόνη με PPI 218 ή μεγαλύτερο, θα θέλετε να αλλάξετε τις ρυθμίσεις της οθόνης. Για παράδειγμα, αν έχετε μια 27" ή 32" 4K, μπορείτε να χρησιμοποιήσετε κλασματική κλιμάκωση ανοίγοντας το `~/.config/hypr/monitors.lua` (μέσω του _Ρύθμιση > Monitors_ στο μενού του Omarchy) και μεταβαίνοντας στη σύσταση για εκείνο τον συνδυασμό:

```lua
local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6
```

Αν χρησιμοποιείτε μια οθόνη 1080p ή 1440p, πιθανότατα θα θέλετε απλώς να χρησιμοποιήσετε κλιμάκωση 1x, οπότε μπορείτε να χρησιμοποιήσετε:

```lua
local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1
```

Οι αλλαγές στο `GDK_SCALE` ισχύουν για εφαρμογές που ξεκινούν μετά την αλλαγή (και το GTK σέβεται μόνο ολόκληρους αριθμούς, οπότε κρατήστε το στον πλησιέστερο ακέραιο της κλίμακας της οθόνης σας). Γι' αυτό βεβαιωθείτε ότι κλείνετε τα παράθυρα που είναι υπερμεγέθη μετά την αλλαγή (ή κλείστε όλα τα παράθυρα με το `Ctrl + Alt + Del`!).

Μπορείτε επίσης να κάνετε γρήγορα βήματα μέσα στους κύριους λόγους κλιμάκωσης οθόνης (1x, 1.25x, 1.6x, 2x, 3x, 4x) χρησιμοποιώντας το `Super + /` για να ανέβετε και το `Super + Alt + /` για να κατέβετε. Αν έχετε την προεπιλεγμένη διαμόρφωση, αυτές οι αλλαγές θα διατηρηθούν και πέρα από επανεκκινήσεις.

### Κάνοντας το κείμενο μεγαλύτερο ή μικρότερο

Η κλιμάκωση της οθόνης αλλάζει το μέγεθος των πάντων. Αν το μόνο που θέλετε είναι μεγαλύτερο ή μικρότερο _κείμενο_, υπάρχει ένα μόνο κουμπί για αυτό:

```
omarchy display text size 14
```

Αυτό δέχεται ένα μέγεθος σε pixel μεταξύ 9 και 20, και μετακινεί μαζί το κέλυφος του Omarchy, τις εφαρμογές GTK και το τερματικό σας, ώστε ολόκληρη η επιφάνεια εργασίας να μένει σε αναλογία. Εκτελέστε το χωρίς όρισμα για να δείτε πού βρίσκεστε, και το `omarchy display text size reset` για να επιστρέψετε στην προεπιλογή. Το Foot είναι ο μοναδικός αργόπορος: δεν έχει τρόπο να επαναφορτώσει τη διαμόρφωσή του, οπότε τα τερματικά που τρέχουν κρατούν το παλιό τους μέγεθος μέχρι να ανοίξετε ένα νέο.

### Επέκταση και κατοπτρισμός οθονών φορητών υπολογιστών

Όταν συνδέετε μια εξωτερική οθόνη στον φορητό υπολογιστή σας, η οθόνη επεκτείνεται αυτόματα. Αλλά μπορείτε να αλλάξετε αυτό σε κατοπτρισμό χρησιμοποιώντας το _Ενεργοποίηση > Hardware_ στο μενού του Omarchy ή το `Super + Ctrl + Alt + Delete`. Αυτό είναι ιδιαίτερα χρήσιμο αν αυτή η εξωτερική οθόνη είναι ένας προβολέας, και θέλετε να δείξετε κάτι ενόσω εργάζεστε.

Όταν επεκτείνετε, το κλείσιμο του καπακιού του φορητού υπολογιστή θα απενεργοποιήσει αυτόματα την εσωτερική οθόνη. Το άνοιγμα του καπακιού θα την ενεργοποιήσει ξανά. Μπορείτε επίσης να το ελέγχετε χειροκίνητα χρησιμοποιώντας το _Ενεργοποίηση > Hardware_ στο μενού του Omarchy ή το `Super + Ctrl + Delete`.

### Τακτοποίηση πολλαπλών οθονών

Το Hyprland λειτουργεί υπέροχα με πολλαπλές οθόνες. Διαβάστε περισσότερα για το πώς να τις διατάξετε στη [την τεκμηρίωση οθονών του Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/). Μπορείτε επίσης να [δεσμεύσετε συγκεκριμένους χώρους εργασίας σε συγκεκριμένες οθόνες](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/). Στο Omarchy, αυτοί οι κανόνες μπαίνουν στο `~/.config/hypr/monitors.lua` ως καταχωρίσεις `hl.monitor` — το αρχείο συνοδεύεται από σχολιασμένα παραδείγματα για το καρφίτσωμα μιας συγκεκριμένης οθόνης σε ανάλυση, θέση και περιστροφή.

Μπορείτε επίσης να ρίξετε μια ματιά στο [Hyprmon](https://github.com/erans/hyprmon/), αν θα θέλατε ένα TUI για να σας βοηθήσει με την τοποθέτηση πολλαπλών οθονών.

### Έλεγχος της φωτεινότητας

Η φωτεινότητα της οθόνης ελέγχεται από τα αποκλειστικά πλήκτρα λειτουργιών για την αύξηση/μείωση της φωτεινότητας. Αν κρατήσετε πατημένο το shift ενόσω τα πατάτε, θα πάτε στη μέγιστη ή την ελάχιστη φωτεινότητα. Τα πλήκτρα ελέγχουν την οθόνη στην οποία είστε εστιασμένοι, οπότε οι εξωτερικές οθόνες που μιλούν DDC/CI ρυθμίζονται με τον ίδιο τρόπο όπως η οθόνη του φορητού υπολογιστή.

### Οθόνες Apple

Αν χρησιμοποιείτε μια οθόνη Apple, τα συνηθισμένα πλήκτρα φωτεινότητας του πληκτρολογίου θα λειτουργούν επίσης αυτόματα, αν είστε εστιασμένοι στην οθόνη Apple. Αυτό γίνεται μέσα από την εντολή `asdcontrol`.

Σημειώστε ότι αν χρησιμοποιείτε μια οθόνη Apple 6K XDR, μπορεί να δείτε μια φάντασμα οθόνη στην καταχώριση `hyprctl monitors` σας. Μπορείτε να την απενεργοποιήσετε με κάτι όπως η `hl.monitor({ output = "DP-2", disabled = true })` μέσω του _Ρύθμιση > Monitors_.

Σε μηχανήματα Intel, θα πρέπει να συνδέεστε σε οθόνες Apple χρησιμοποιώντας ένα συνηθισμένο καλώδιο Thunderbolt. Σε άλλα μηχανήματα χωρίς Thunderbolt, συνήθως θα χρειαστεί να χρησιμοποιήσετε ένα [καλώδιο DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) για να το καταφέρετε.
