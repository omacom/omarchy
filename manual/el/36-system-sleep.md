# Ύπνος συστήματος

Το Omarchy ενεργοποιεί την αναστολή και την αδρανοποίηση από προεπιλογή, αλλά αν έχεις προβλήματα με οποιαδήποτε από τις δύο στο μηχάνημά σου, μπορείς να τις απενεργοποιήσεις.

### Προφίλ ισχύος

Σε φορητό, το Omarchy θυμάται το προφίλ ισχύος σου ξεχωριστά για συνδεδεμένο στην πρίζα και σε μπαταρία, και εναλλάσσεται μεταξύ των δύο καθώς συνδέεις και αποσυνδέεις. Από το κουτί αυτό σημαίνει απόδοση σε AC και ισορροπημένο σε μπαταρία.

Μπορείς να δεις τι προσφέρει το μηχάνημά σου με `omarchy powerprofiles list`, και να ορίσεις αυτό που θέλεις για την κατάσταση στην οποία βρίσκεσαι αυτή τη στιγμή με `omarchy powerprofiles set autodetect power-saver`. Για να ορίσεις την άλλη κατάσταση χωρίς να αποσυνδέσεις τίποτα, ονόμασέ την απευθείας: `omarchy powerprofiles set battery power-saver`. Ό,τι διαλέξεις είναι αυτό που θα έχεις ξανά την επόμενη φορά που θα βρίσκεσαι σε εκείνη την κατάσταση.

### Εναλλαγή αναστολής

Εναλλάσσεις την αναστολή τρέχοντας `omarchy toggle suspend` από το τερματικό. Αυτό απλώς εμφανίζει/κρύβει την επιλογή κάτω από _Σύστημα_ (ή `Super + Esc`), και μετά μπορείς να δεις αν δουλεύει σταθερά στο σύστημά σου. Αν όχι, μπορείς να την κρύψεις ξανά με την ίδια εντολή.

### Εναλλαγή αδρανοποίησης

Ρυθμίζεις την αδρανοποίηση τρέχοντας `omarchy hibernation setup` από το τερματικό. Η αδρανοποίηση δημιουργεί έναν υποτόμο /swap στη μονάδα εκκίνησής σου στο μέγεθος της φυσικής σου RAM, οπότε βεβαιώσου ότι έχεις άφθονο ελεύθερο χώρο. Σε μηχάνημα 32GB, θα χρειάζεσαι πάντα 32GB+ ελεύθερα για αυτόν τον τόμο. Η αδρανοποίηση απαιτεί επίσης τον προεπιλεγμένο φορτωτή εκκίνησης Limine.

Όταν ρυθμιστεί, θα δεις την επιλογή αδρανοποίησης κάτω από _Σύστημα_ (ή `Super + Esc`), και μετά μπορείς να δεις αν δουλεύει σταθερά στο σύστημά σου. Αν όχι, μπορείς να την αφαιρέσεις ξανά τρέχοντας `omarchy hibernation remove`.
