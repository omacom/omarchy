# Αναστολή λειτουργίας συστήματος

Το Omarchy ενεργοποιεί την αναστολή λειτουργίας και την αδρανοποίηση από προεπιλογή, αλλά αν αντιμετωπίζετε προβλήματα με οποιαδήποτε από τις δύο στο μηχάνημά σας, μπορείτε να τις απενεργοποιήσετε.

Σε μηχανήματα NVIDIA GB10, όπως το DGX Spark και το ASUS Ascent GX10, η αναστολή λειτουργίας και η αδρανοποίηση είναι απενεργοποιημένες, όπως και στο DGX OS της NVIDIA, επειδή δεν έχει αποδειχθεί ακόμα ότι ο ύπνος λειτουργεί σε αυτό το υλικό. Το ίδιο ισχύει και για το ASUS Zenbook A16 (UX3607OA), όπου η αναστολή λειτουργίας δεν θέτει ακόμα το τσιπ σε πλήρη ύπνο και μπορεί να κολλήσει κατά τη διάρκεια της νύχτας. Η εναλλαγή αναστολής λειτουργίας και η ρύθμιση αδρανοποίησης δεν ισχύουν εκεί. Για να ενεργοποιήσετε ξανά τον ύπνο, αφαιρέστε το `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf` με `sudo rm`· η Αναστολή λειτουργίας επιστρέφει τότε στο μενού, και η αδρανοποίηση μπορεί να ρυθμιστεί όπως σε άλλα μηχανήματα. Η εκτέλεση του `sudo omarchy apply hardware --install-user "$USER"` επαναφέρει το αρχείο.

### Προφίλ ενέργειας

Σε φορητό υπολογιστή, το Omarchy θυμάται το προφίλ ενέργειάς σας ξεχωριστά για όταν είναι συνδεδεμένο στο ρεύμα και για όταν λειτουργεί με μπαταρία, και εναλλάσσεται μεταξύ των δύο καθώς συνδέετε και αποσυνδέετε το καλώδιο. Από προεπιλογή αυτό σημαίνει απόδοση στο AC και ισορροπημένη λειτουργία στη μπαταρία.

Μπορείτε να δείτε τι προσφέρει το μηχάνημά σας με `omarchy powerprofiles list`, και να ορίσετε αυτό που θέλετε για την κατάσταση στην οποία βρίσκεστε αυτή τη στιγμή με `omarchy powerprofiles set autodetect power-saver`. Για να ορίσετε την άλλη κατάσταση χωρίς να αποσυνδέσετε τίποτα, ονομάστε την απευθείας: `omarchy powerprofiles set battery power-saver`. Ό,τι επιλέξετε είναι αυτό που θα έχετε ξανά την επόμενη φορά που θα βρίσκεστε σε αυτή την κατάσταση.

### Εναλλαγή αναστολής λειτουργίας

Εναλλάσσετε την αναστολή λειτουργίας εκτελώντας `omarchy toggle suspend` από το τερματικό. Αυτό απλώς εμφανίζει/κρύβει την επιλογή στο _Σύστημα_ (ή `Super + Esc`), και μετά μπορείτε να δείτε αν λειτουργεί σταθερά στο σύστημά σας. Αν όχι, μπορείτε να την κρύψετε ξανά με την ίδια εντολή.

### Εναλλαγή αδρανοποίησης

Ρυθμίζετε την αδρανοποίηση εκτελώντας `omarchy hibernation setup` από το τερματικό. Η αδρανοποίηση δημιουργεί έναν υποτόμο /swap στη μονάδα εκκίνησής σας στο μέγεθος της φυσικής σας μνήμης RAM, οπότε βεβαιωθείτε ότι έχετε αρκετό ελεύθερο χώρο. Σε ένα μηχάνημα 32GB, θα χρειάζεστε πάντα 32GB+ ελεύθερα για αυτόν τον τόμο. Η αδρανοποίηση απαιτεί επίσης τον προεπιλεγμένο bootloader Limine.

Όταν ρυθμιστεί, θα δείτε την επιλογή αδρανοποίησης στο _Σύστημα_ (ή `Super + Esc`), και μετά μπορείτε να δείτε αν λειτουργεί σταθερά στο σύστημά σας. Αν όχι, μπορείτε να την αφαιρέσετε ξανά εκτελώντας `omarchy hibernation remove`.
