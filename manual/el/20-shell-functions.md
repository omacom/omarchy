# Συναρτήσεις κελύφους

Το Omarchy έρχεται με ένα σύνολο συναρτήσεων κελύφους για να απλοποιεί συνηθισμένες εργασίες και να ενθυλακώνει πολύπλοκες κλήσεις παραμέτρων.

## Συμπίεση

- `compress [file/dir]`: Δημιουργεί ένα αρχείο tar.gz από το αρχείο/τον κατάλογο.
- `decompress [file.tar.gz]`: Επεκτείνει ένα αρχείο tar.gz.

## Δίσκοι

- `iso2sd [image.iso]`: Δημιουργεί έναν εκκινήσιμο δίσκο σε μια κάρτα SD χρησιμοποιώντας το αναφερόμενο αρχείο iso και επιλέγοντας τον δίσκο διαδραστικά.
- `format-drive [device] [name]`: Μορφοποιεί έναν ολόκληρο δίσκο με ένα μόνο διαμέρισμα exFAT (το οποίο λειτουργεί και σε Windows και macOS). Εκτελέστε το χωρίς ορίσματα για να δείτε τους διαθέσιμους δίσκους. Προσοχή!

## Διατάξεις ανάπτυξης

Άμεσες διατάξεις ανάπτυξης πολλαπλών πάνελ για το tmux:

- `tdl [ai]`: Δημιουργεί μια Tmux Dev Layout με τον επεξεργαστή σας, έναν πράκτορα AI και ένα τερματικό. Χρησιμοποιήστε τα alias των πρακτόρων, όπως `tdl c` για το opencode ή `tdl cx` για το Claude Code, ή περάστε έναν δεύτερο πράκτορα για να εκτελούνται και οι δύο, όπως `tdl c cx`.
- `tds`: Δημιουργεί ένα Tmux Dev Square με επεξεργαστή, παρακολούθηση διαφορών (μέσω `hunk diff --watch`), τερματικό και opencode.
- `tdlm [ai]`: Δημιουργεί ένα παράθυρο `tdl` για κάθε υποκατάλογο στον τρέχοντα κατάλογο.
- `tsl [count] [command]`: Δημιουργεί μια συστάδα πάνελ σε πλακιδωτό πλέγμα, όλα να εκτελούν την ίδια εντολή (ιδανικό για πράκτορες AI).

Οι ίδιες διατάξεις είναι διαθέσιμες για το Herdr ως `hdl`, `hds`, `hdlm` και `hsl`.

## Git worktrees

- `ga [branch]`: Δημιουργεί ένα νέο worktree και branch δίπλα στο τρέχον αποθετήριο και μεταπηδά σε αυτό.
- `gd`: Αφαιρεί το τρέχον worktree και το branch του (ζητά πρώτα επιβεβαίωση).

## Παρατηρητές Rsync

- `rsw [source] [destination]`: Ξεκινά έναν παρατηρητή στο παρασκήνιο που συγχρονίζει με rsync την πηγή στον προορισμό όποτε αλλάζει κάτι. Ο προορισμός μπορεί να είναι ένας απομακρυσμένος κεντρικός υπολογιστής, όπως `rsw ~/Work/app nyc-dev:Work/app`.
- `lsw`: Παραθέτει όλους τους ενεργούς παρατηρητές.
- `dsw`: Διακόπτει όλους τους ενεργούς παρατηρητές.

## Προώθηση θυρών SSH

Ιδανικό για ανάπτυξη web με προνόμια ασφαλούς πλαισίου localhost απέναντι σε ένα απομακρυσμένο μηχάνημα.

- `fip`: Προωθεί μία ή περισσότερες θύρες από έναν απομακρυσμένο κεντρικό υπολογιστή στο localhost μέσω SSH.
- `dip`: Αποσυνδέει μία ή περισσότερες προωθημένες θύρες.
- `lip`: Παραθέτει όλες τις ενεργές προωθήσεις θυρών SSH.

Πείτε ότι ξεκινάτε έναν διακομιστή ανάπτυξης στη θύρα `3000` σε ένα μηχάνημα προσβάσιμο ως `nyc-dev`· τότε μπορείτε να εκτελέσετε `fip nyc-dev 3000` για να προωθήσετε εκείνη τη θύρα, ώστε το `localhost:3000` να φτάνει πράγματι στο `nyc-dev:3000`, αλλά χωρίς την ανάγκη πιστοποιητικών SSL για τη δημιουργία του ασφαλούς πλαισίου που χρειάζεται για τη δοκιμή web sockets ή παρόμοιων.

## Επανασύνδεση SSH

Το ίδιο το `ssh` είναι τυλιγμένο σε μια συνάρτηση που καθαρίζει το τερματικό αν μια σύνδεση χαθεί ενώ ένα απομακρυσμένο tmux, Herdr ή ένας επεξεργαστής το έχει καταλάβει, και στη συνέχεια επανασυνδέεται αυτόματα όταν αποτυγχάνει μια διαδραστική συνεδρία (το Ctrl-C σταματά τον βρόχο επανάληψης).
