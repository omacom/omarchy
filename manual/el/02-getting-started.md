# Ξεκινώντας

Το Omarchy εγκαθίσταται χρησιμοποιώντας ένα ISO. Μπορείτε να επιλέξετε ανάμεσα σε μια εγκατάσταση σε ολόκληρο τον δίσκο, η οποία καταλαμβάνει ολόκληρη τη μονάδα δίσκου, ή μια εγκατάσταση σε ελεύθερο χώρο, η οποία τοποθετεί το Omarchy στον μη εκχωρημένο χώρο μιας μονάδας δίσκου — έτσι κάνετε διπλή εκκίνηση μαζί με Windows ή άλλο λειτουργικό σύστημα (δείτε [εγκατάσταση διπλής εκκίνησης](50-dual-boot-install.md) — σημειώστε ότι θα χρειαστεί πρώτα να απενεργοποιήσετε το BitLocker στα Windows). Σε κάθε περίπτωση, η εγκατάσταση χρησιμοποιεί από προεπιλογή πλήρη κρυπτογράφηση, και η επιλογή ολόκληρου του δίσκου θα διαγράψει την επιλεγμένη μονάδα δίσκου, οπότε φροντίστε να πάρετε ένα αντίγραφο ασφαλείας πριν χρησιμοποιήσετε μια υπάρχουσα!

Σε Mac με Apple Silicon, η εγκατάσταση γίνεται από το macOS αντί γι' αυτό, χωρίς ISO ή στικάκι USB. Δείτε [Omarchy για Apple Silicon](44-mac-support.md#omarchy-for-apple-silicon).

[Κατεβάστε το ISO του Omarchy](https://omarchy.org/) πρώτα, βάλτε το σε ένα στικάκι USB (χρησιμοποιήστε [Rufus](https://rufus.ie/) στα Windows, [balenaEtcher](https://etcher.balena.io/) σε Mac, ή [caligula](https://github.com/ifd3f/caligula) σε Linux), και εκκινήστε από το στικάκι.

_Πρέπει να απενεργοποιήσετε το Secure Boot και/ή το TPM στο BIOS. Πρέπει να τα απενεργοποιήσετε για να μπορέσετε να εγκαταστήσετε το Omarchy. Είναι μηχανισμοί ασφαλείας της Microsoft που προορίζονται για τα Windows και για διανομές Linux συνδεδεμένες με τη Microsoft._

Στη συνέχεια απαντήστε στις ερωτήσεις διαμόρφωσης, και επιβεβαιώστε τις κάπως έτσι:

 ![install-config](images/install-config.webp)

Έπειτα επιλέξτε μια μονάδα δίσκου για την εγκατάστασή σας, και καθίστε αναπαυτικά και παρακολουθήστε το σόου της εγκατάστασης. Μπορεί να ολοκληρωθεί σε λιγότερο από ένα λεπτό στα ταχύτερα σύγχρονα μηχανήματα, αλλά δεν θα πρέπει να πάρει περισσότερο από 5 λεπτά ακόμη και σε έναν παλαιότερο υπολογιστή.

 ![install-done](images/install-done.webp)

Τώρα είστε έτοιμοι για Omarchy!

### Χρησιμοποιήστε ενσύρματο πληκτρολόγιο ή πληκτρολόγιο 2.4ghz!

Η κρυπτογράφηση ολόκληρου του δίσκου δεν θα σας επιτρέψει να εισαγάγετε τον κωδικό πρόσβασης από πληκτρολόγιο Bluetooth κατά την εκκίνηση. Ακριβώς όπως δεν μπορείτε να χρησιμοποιήσετε πληκτρολόγιο Bluetooth για να μπείτε στο BIOS σε ένα PC. Θα χρειαστείτε ένα πληκτρολόγιο που είτε χρησιμοποιεί dongle 2.4ghz είτε καλώδιο (που έτσι κι αλλιώς είναι πολύ καλύτερο όσον αφορά την καθυστέρηση!). Προσωπικά λατρεύω το [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard)!

### Εγκατάσταση για άλλον κάτοχο

Αν στήνετε ένα μηχάνημα για κάποιον άλλον — ένα μέλος της οικογένειας, έναν νέο υπάλληλο, έναν αγοραστή — δεν θα πρέπει να απαντάτε στις προσωπικές ερωτήσεις εκ μέρους του. Πατήστε `Ctrl + C` στην πρώτη κιόλας οθόνη του προγράμματος εγκατάστασης (την επιλογή πληκτρολογίου), και το Omarchy θα προσφερθεί να προετοιμάσει το μηχάνημα για άλλον κάτοχο αντί γι' αυτό. Το σύστημα εγκαθίσταται αμέσως, αλλά όλη η προσωπική ρύθμιση — διάταξη πληκτρολογίου, όνομα χρήστη, κωδικός πρόσβασης — αναβάλλεται μέχρι το μηχάνημα να εκκινήσει για πρώτη φορά. Η μονάδα δίσκου εξακολουθεί να είναι κρυπτογραφημένη από προεπιλογή, και ο κωδικός πρόσβασης που θα επιλέξει ο νέος κάτοχος σε εκείνη την πρώτη εκκίνηση γίνεται και ο κωδικός κρυπτογράφησης. (Ένα μηχάνημα που ήδη χρησιμοποιείτε μπορεί επίσης να παραδοθεί χωρίς επανεγκατάσταση — δείτε [επαναφορά του υπολογιστή](48-security.md).)

### Εγκαταστάσεις χωρίς επίβλεψη

Το ISO μπορεί επίσης να εγκατασταθεί εντελώς μόνο του — χωρίς πληκτρολόγιο, χωρίς οδηγό — όταν του δοθεί η διαμόρφωσή του σε μια δεύτερη μονάδα δίσκου. Αυτός είναι ο τρόπος για να αντιμετωπίζετε το Omarchy ως βασική εικόνα για VM και μηχανήματα στόλου. Δείτε [εγκαταστάσεις χωρίς επίβλεψη](51-unattended-installs.md).

### Εγκαταστάσεις χωρίς κρυπτογράφηση

Το Omarchy εγκαθίσταται με κρυπτογράφηση από προεπιλογή. Είναι η ασφαλής, υπεύθυνη επιλογή για κάθε υπολογιστή που μπορεί ενδεχομένως να χαθεί ή να κλαπεί. Δεν θέλετε όποιος έχει πρόσβαση στο υλικό σας να μπορεί να πάρει τα δεδομένα σας!

Αλλά σε ειδικές περιπτώσεις, όπως απομακρυσμένες εγκαταστάσεις Omarchy σε προστατευμένους υπολογιστές ή για προσωρινές εγκαταστάσεις χωρίς ευαίσθητα δεδομένα, ίσως θελήσετε να κάνετε εγκατάσταση χωρίς κρυπτογράφηση. Μπορείτε να πατήσετε `Ctrl + C` στην επιβεβαίωση μορφοποίησης δίσκου για να μεταβείτε σε εγκατάσταση χωρίς κρυπτογράφηση.

### Γλώσσα

Το Omarchy μιλάει 50 γλώσσες — το ίδιο σύνολο με το omarchy.org — και τα Αγγλικά είναι η προεπιλογή. Για να αλλάξετε, ανοίξτε το μενού του Omarchy και μεταβείτε στο _Ρύθμιση > Περιοχή > Γλώσσα_, ή εκτελέστε `omarchy language <code>` σε ένα τερματικό (`omarchy language list` δείχνει τους κωδικούς). Το μενού, η επιφάνεια εργασίας και οι ίδιες οι ειδοποιήσεις του Omarchy αλλάζουν γλώσσα αμέσως, και κάθε εφαρμογή που ανοίγετε στη συνέχεια ακολουθεί επίσης. Οι εφαρμογές που ήταν ήδη ανοιχτές αλλάζουν μόλις τις επανεκκινήσετε.

Για να κρατήσετε τη γλώσσα αλλά να γράφετε ημερομηνίες, ώρες, αριθμούς, χρήματα, μονάδες και μεγέθη χαρτιού όπως τα γράφει μια άλλη περιοχή (Αγγλικά με ευρωπαϊκές ημερομηνίες και 24ωρο ρολόι, ας πούμε), επιλέξτε μια περιοχή στο _Ρύθμιση > Περιοχή > Μορφές_, όπου κάθε επιλογή δείχνει ένα δείγμα, ή εκτελέστε `omarchy region formats <code>` (`omarchy region formats list` δείχνει τους κωδικούς). Το _Ίδιες με τη γλώσσα_ επιστρέφει στις μορφές της ίδιας της γλώσσας. Όπως και μια αλλαγή γλώσσας, φτάνει στις εφαρμογές που ανοίγετε στη συνέχεια.
