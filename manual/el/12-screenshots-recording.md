# Στιγμιότυπα & Εγγραφή

Όλα όσα μπορείς να αρπάξεις από την οθόνη κρέμονται από το πλήκτρο Print Screen. Ένα πλήκτρο μόνο του βγάζει μια φωτογραφία, και οι τροποποιητές παίρνουν μια εγγραφή, ένα χρώμα, ή το κείμενο μέσα σε μια περιοχή. Αν το πληκτρολόγιό σου δεν έχει καθόλου πλήκτρο Print Screen, το `Super + Ctrl + C` ανοίγει το ίδιο σύνολο ως μενού.

| Συντόμευση | Λειτουργία |
| ------ | -------- |
| `Print Screen` | Στιγμιότυπο |
| `Alt + Print Screen` | Εγγραφή οθόνης (ή διακοπή αυτής που τρέχει) |
| `Super + Print Screen` | Επιλογέας χρώματος |
| `Super + Ctrl + Print Screen` | Εξαγωγή κειμένου από μια περιοχή |
| `Super + Ctrl + C` | Μενού καταγραφής |
| `Super + Ctrl + .` | Μετακωδικοποίηση εικόνας ή βίντεο |

## Στιγμιότυπα

Πάτησε `Print Screen` και το Omasnap καταγράφει την εστιασμένη οθόνη πριν εμφανιστεί η επικάλυψή της, ώστε τίποτα να μην μετακινηθεί κάτω από σένα ενώ στοχεύεις. Σύρε μια ελεύθερη περιοχή, κάνε κλικ σε ένα παράθυρο για να το καταγράψεις, ή κάνε κλικ σε κενό χώρο για καταγραφή ολόκληρης της οθόνης. Πάτησε `S` πριν σχεδιάσεις για καταγραφή περιοχής κύλισης. Άλλαξες γνώμη; Πάτησε `Print Screen` ξανά για να απορρίψεις το Omasnap.

Αφού επιλέξεις μια περιοχή, το Omasnap αποθηκεύει την καταγραφή, την αντιγράφει στο πρόχειρο, και δείχνει μια προεπισκόπηση για 10 δευτερόλεπτα. Χρησιμοποίησε το κουμπί καρφίτσας της προεπισκόπησης ή το `Ctrl + P` για να την κρατήσεις στην οθόνη, ή διάλεξε Edit για να τη σημειώσεις.

Ο επεξεργαστής σχολιασμού μπορεί να ζωγραφίσει βέλη, γραμμές, σχήματα, επισημάνσεις, αριθμημένους δείκτες, κείμενο, και ασφαλείς αποκρύψεις· να περικόψει ή να κόψει έξω μέρος της εικόνας· να κάνει OCR στο κείμενό της· και να προσθέσει ένα παρασκήνιο. Στον επεξεργαστή, πάτησε `Enter` για αντιγραφή και αποθήκευση του τελικού PNG, `Ctrl + C` για αντιγραφή χωρίς αποθήκευση, ή `Ctrl + S` για αποθήκευση χωρίς αντιγραφή.

Τα αποθηκευμένα στιγμιότυπα προσγειώνονται στο `~/Pictures/Screenshots` από προεπιλογή, με ένα όνομα όπως `screenshot-2026-08-13_14-22-05-firefox.png`. Όρισε `OMASNAP_SCREENSHOT_DIR` για χρήση άλλου καταλόγου — δες [το FAQ](46-faq.md) για το πού μπαίνουν οι μεταβλητές περιβάλλοντος συνεδρίας. Το Omasnap δημιουργεί τον κατάλογο όταν αποθηκεύει την πρώτη λήψη. Όρισε `[output] autosave = false` στο `~/.config/omasnap/omasnap.conf` για απενεργοποίηση της αυτόματης αποθήκευσης.

Από το τερματικό, το `omarchy screenshot` ανοίγει την ίδια επικάλυψη, και μπορείς να επιλέξεις τη λειτουργία εκκίνησής του: `omarchy capture screenshot region`, `windows`, `fullscreen`, ή `scroll`. Ένα δεύτερο όρισμα `copy` ή `save` παραλείπει την προεπισκόπηση και στέλνει τη λήψη κατευθείαν σε εκείνο τον προορισμό. Για επεξεργασία πριν την έξοδο, χρησιμοποίησε `omarchy screenshot --editor=overlay` για έναν επεξεργαστή πλήρους οθόνης ή `omarchy screenshot --editor=window` για ένα ξεχωριστό παράθυρο.

### Οδήγηση του επιλογέα από το πληκτρολόγιο

Όσο η επιλογή είναι επάνω, δεν χρειάζεται να χρησιμοποιείς καθόλου το ποντίκι:

| Πλήκτρο | Λειτουργία |
| --- | -------- |
| `S` | Εναλλαγή λειτουργίας περιοχής κύλισης |
| `Super + Arrow keys` | Μετακίνηση ανάμεσα σε παράθυρα στη λειτουργία Window |
| `Return` | Καταγραφή του επισημασμένου παραθύρου |
| `Ctrl + A` | Καταγραφή της πλήρους εστιασμένης οθόνης |
| `R` | Επαναφορά της τελευταίας περιοχής που σχεδιάστηκε σε αυτή τη συνεδρία |
| `Esc` | Απόρριψη Omasnap |

Αυτές οι αντιστοιχίσεις υπάρχουν μόνο όσο το Omasnap είναι ανοιχτό, οπότε δεν μπορούν να συγκρουστούν με τίποτα στο δικό σου config.

## Εγγραφή οθόνης

Το `Alt + Print Screen` ανοίγει το _Ενεργοποίηση > Καταγραφή > Εγγραφή οθόνης_, που ρωτά τι θέλεις στη μουσική επένδυση: χωρίς ήχο, ήχο desktop, desktop συν μικρόφωνο, ή desktop συν μικρόφωνο συν webcam. Το τελευταίο εμφανίζεται μόνο αν πράγματι έχεις κάμερα συνδεδεμένη. Διάλεξε ένα και ο επιλογέας εγγραφής του Omarchy σου επιτρέπει να σύρεις μια περιοχή ή να κάνεις κλικ σε ένα παράθυρο ή οθόνη.

Η εγγραφή τρέχει στο gpu-screen-recorder, που κωδικοποιεί στη GPU στα 60fps και υποχωρεί στη CPU αν χρειαστεί. Το αποτέλεσμα είναι ένα MP4 στο `~/Videos`, με όνομα `screenrecording-2026-08-13_14-22-05.mp4`. Όρισε `OMARCHY_SCREENRECORD_DIR` για να το αλλάξεις — αλλά σημείωσε ότι σε αντίθεση με τον κατάλογο στιγμιότυπων, αυτός πρέπει να υπάρχει ήδη, διαφορετικά η εγγραφή αρνείται να ξεκινήσει.

Όσο εγγράφεις, ένας μικρός ενδείκτης εμφανίζεται στη γραμμή. Κάνε κλικ σε αυτόν για διακοπή. Μπορείς επίσης να σταματήσεις με `Alt + Print Screen` ξανά, ή με την καταχώρηση _Διακοπή εγγραφής_ στο _Ενεργοποίηση > Καταγραφή > Εγγραφή οθόνης_, που εμφανίζεται μόνο όσο κάτι πράγματι εγγράφεται.

Η διακοπή κάνει μια μικρή τακτοποίηση πριν σου παραδώσει το αρχείο: το πρώτο καρέ κόβεται, και αν υπάρχει ήχος κανονικοποιείται στα -14 LUFS με το ποπ καταγραφής PipeWire στην αρχή σιγαμένο. Μετά μια ειδοποίηση εμφανίζεται με μια μικρογραφία από την εγγραφή. Κάνε κλικ σε αυτή για αναπαραγωγή του αρχείου στο mpv.

### Η επικάλυψη webcam

Όταν εγγράφεις με webcam, η κάμερα εμφανίζεται ως ένα καρφιτσωμένο, περικομμένο πορτρέτο παράθυρο στην κάτω-δεξιά γωνία οτιδήποτε εγγράφεις. Αν κάθεται πάνω σε κάτι που χρειάζεσαι, αλλάξ' του μέγεθος εν κινήσει:

| Συντόμευση | Λειτουργία |
| ------ | -------- |
| `Super + Alt + [` | Μικρότερη επικάλυψη webcam |
| `Super + Alt + ]` | Μεγαλύτερη επικάλυψη webcam |

Υπάρχουν τρία μεγέθη — μικρό, μεσαίο και μεγάλο — και οι συντομεύσεις πηγαίνουν ανάμεσα τους. Το μεσαίο είναι το προεπιλεγμένο. Είναι αναλογικά προς την εγγραφή, οπότε η κάμερα καταλαμβάνει το ίδιο μερίδιο του καρέ είτε εγγράφεις μια οθόνη 1080p είτε μια 6K. Και αν έγγραψες μια περιοχή αντί για μια ολόκληρη οθόνη, η επικάλυψη αγκυρώνεται στη γωνία εκείνης της περιοχής αντί της οθόνης, οπότε μένει μέσα στη λήψη.

Μπορείς επίσης να την καλέσεις απευθείας με `omarchy-capture-webcam-resize small`, ή `reset` για επιστροφή στο μεσαίο.

## Κείμενο, κωδικοί QR και χρώματα

Το `Super + Ctrl + Print Screen` επιλέγει μια περιοχή και κάνει OCR σε αυτή στο πρόχειρο. Αυτό καλύπτεται σωστά στο [Εξαγωγή Κειμένου & Υπαγόρευση](11-text-extraction-dictation.md).

Το _Ενεργοποίηση > Καταγραφή > Κωδικός QR_ κάνει το ίδιο κόλπο για κωδικούς QR. Επίλεξε την περιοχή με τον κωδικό μέσα της, και η αποκωδικοποιημένη τιμή πηγαίνει στο πρόχειρο. Ψάχνει μόνο για κωδικούς QR — το πυκνό περιεχόμενο οθόνης έχει τη συνήθεια να δίνει ψευδοθετικά ως barcode διαφορετικά. Αξίζει να ξέρεις: η αποκωδικοποιημένη τιμή πηγαίνει στο πρόχειρο και πουθενά αλλού. Δεν τυπώνεται, δεν βρίσκεται στην ειδοποίηση, και σημειώνεται ως ευαίσθητη ώστε να μην παραμένει στο [ιστορικό προχείρου](08-unified-clipboard-history.md). Οι κωδικοί QR φέρουν τακτικά μυστικά — το URI `otpauth://` πίσω από έναν κωδικό ρύθμισης 2FA, για παράδειγμα — και δεν θέλεις αυτό σε ένα log. Η επικόλληση δουλεύει ακόμα μια χαρά.

Το `Super + Print Screen` (ή _Ενεργοποίηση > Καταγραφή > Χρώμα_) μετατρέπει τον δρομέα σε σταγονόμετρο. Κάνε κλικ σε οτιδήποτε στην οθόνη και το χρώμα προσγειώνεται στο πρόχειρο. Πάτησε τη συντόμευση ξανά για έξοδο χωρίς επιλογή.

## Μετακωδικοποίηση πριν τη μοιραστείς

Μια εγγραφή οθόνης 4K ή ένα ακατέργαστο HEIC από το κινητό σου είναι συχνά πολύ μεγάλο για απλή αποστολή. Το `Super + Ctrl + .` (ή _Ενεργοποίηση > Μετακωδικοποίηση_) το διορθώνει. Σου προσφέρει έναν επιλογέα αρχείου ασαφούς αναζήτησης πάνω από τα `~/Pictures` και `~/Videos`, μετά ρωτά για μια μορφή και ένα μέγεθος.

Οι εικόνες πηγαίνουν σε jpg ή png σε high, medium, ή low, που περιορίζουν το πλάτος στα 3160, 2160, και 1080 pixel. Τα βίντεο πηγαίνουν σε mp4 ή ένα κινούμενο gif σε 4k, 1080p, ή 720p. Το μετατραπέν αρχείο γράφεται δίπλα στο πρωτότυπο με την ανάλυση στο όνομα — `demo-1080p.mp4` — και η διαδρομή αντιγράφεται στο πρόχειρο ως URI αρχείου, ώστε να μπορείς να την επικολλήσεις απευθείας σε μια εφαρμογή που δέχεται αποθέσεις αρχείων.

Δουλεύει και από το τερματικό, αν ξέρεις ήδη τι θέλεις: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. Υπάρχει επίσης το `omarchy transcode ascii`, που μετατρέπει μια εικόνα σε τέχνη ASCII — αυτό είναι κυρίως για [branding](41-branding.md).

## Αποστολή κάπου

Μόλις έχεις το αρχείο, το `Super + Ctrl + S` ανοίγει το μενού Κοινής χρήσης και το στέλνει σε άλλη συσκευή στο δίκτυό σου μέσω LocalSend. Δες [GUIs](22-guis.md) γι' αυτό.
