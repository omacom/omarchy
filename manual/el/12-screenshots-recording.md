# Στιγμιότυπα οθόνης & Εγγραφή

Ό,τι μπορείς να αρπάξεις από την οθόνη κρέμεται από το πλήκτρο Print Screen. Ένα πλήκτρο μόνο του τραβάει μια φωτογραφία, και οι τροποποιητές τραβούν μια εγγραφή, ένα χρώμα, ή το κείμενο μέσα σε μια περιοχή. Αν το πληκτρολόγιό σου δεν έχει καθόλου πλήκτρο Print Screen, το `Super + Ctrl + Alt + C` τραβάει το ίδιο στιγμιότυπο οθόνης, και το `Super + Ctrl + C` ανοίγει ολόκληρο το σύνολο ως μενού.

| Πλήκτρο συντόμευσης | Λειτουργία |
| ------ | -------- |
| `Print Screen` | Στιγμιότυπο οθόνης |
| `Super + Ctrl + Alt + C` | Στιγμιότυπο οθόνης |
| `Alt + Print Screen` | Εγγραφή οθόνης (ή διακοπή αυτής που εκτελείται) |
| `Super + Print Screen` | Επιλογέας χρώματος |
| `Super + Ctrl + Print Screen` | Εξαγωγή κειμένου από μια περιοχή |
| `Super + Ctrl + C` | Μενού λήψης |
| `Super + Ctrl + .` | Μετατροπή κωδικοποίησης μιας εικόνας ή ενός βίντεο |

## Στιγμιότυπα οθόνης

Πάτα `Print Screen` (ή `Super + Ctrl + Alt + C`) και το Omasnap καταγράφει την εστιασμένη οθόνη πριν εμφανιστεί η επικάλυψή του, οπότε τίποτα δεν μετακινείται από κάτω σου όσο στοχεύεις. Σύρε μια περιοχή ελεύθερης μορφής, κάνε κλικ σε ένα παράθυρο για να το καταγράψεις, ή κάνε κλικ σε κενό χώρο για να καταγράψεις ολόκληρη την οθόνη. Πάτα `S` πριν σχεδιάσεις για να καταγράψεις μια περιοχή με κύλιση. Άλλαξες γνώμη; Πάτα ξανά το ίδιο πλήκτρο για να απορρίψεις το Omasnap.

Αφού επιλέξεις μια περιοχή, το Omasnap αποθηκεύει τη λήψη, την αντιγράφει στο πρόχειρο, και εμφανίζει μια ειδοποίηση με τη μικρογραφία της, όπως κάνει μια αποθηκευμένη εγγραφή οθόνης. Επίλεξε Open για να δεις το αποθηκευμένο στιγμιότυπο στο πρόγραμμα προβολής εικόνων σου, ή Edit για να το σχολιάσεις.

Ο επεξεργαστής σχολιασμού μπορεί να σχεδιάσει βέλη, γραμμές, σχήματα, επισημάνσεις, αριθμημένους δείκτες, κείμενο, και ασφαλείς αποκρύψεις· να περικόψει ή να κόψει μέρος της εικόνας· να κάνει OCR στο κείμενό της· και να προσθέσει ένα φόντο. Στον επεξεργαστή, πάτα `Enter` για να αντιγράψεις και να αποθηκεύσεις το τελικό PNG, `Ctrl + C` για να το αντιγράψεις χωρίς αποθήκευση, ή `Ctrl + S` για να το αποθηκεύσεις χωρίς αντιγραφή.

Τα αποθηκευμένα στιγμιότυπα οθόνης καταλήγουν στο `~/Pictures/Screenshots` από προεπιλογή, με ένα όνομα όπως `screenshot-2026-08-13_14-22-05-firefox.png`. Όρισε το `OMASNAP_SCREENSHOT_DIR` για να χρησιμοποιήσεις άλλον κατάλογο — δες [τις Συχνές Ερωτήσεις](46-faq.md) για το πού να βάλεις τις μεταβλητές περιβάλλοντος περιόδου λειτουργίας. Το Omasnap δημιουργεί τον κατάλογο όταν αποθηκεύει την πρώτη λήψη. Όρισε `[output] autosave = false` στο `~/.config/omasnap/omasnap.conf` για να απενεργοποιήσεις την αυτόματη αποθήκευση· οι λήψεις τότε μόνο αντιγράφονται, και εμφανίζονται σε μια προεπισκόπηση για 10 δευτερόλεπτα που μπορείς να κρατήσεις στην οθόνη με το κουμπί καρφιτσώματός της ή με `Ctrl + P`.

Από το τερματικό, το `omarchy screenshot` ανοίγει την ίδια επικάλυψη, και μπορείς να επιλέξεις την αρχική του λειτουργία: `omarchy capture screenshot region`, `windows`, `fullscreen`, ή `scroll`. Ένα δεύτερο όρισμα `copy` ή `save` στέλνει τη λήψη κατευθείαν σε αυτόν τον προορισμό. Για επεξεργασία πριν από την έξοδο, χρησιμοποίησε `omarchy screenshot --editor=overlay` για έναν επεξεργαστή πλήρους οθόνης ή `omarchy screenshot --editor=window` για ένα ξεχωριστό παράθυρο.

### Χειρισμός του επιλογέα από το πληκτρολόγιο

Όσο η επιλογή είναι ανοιχτή, δεν χρειάζεται να χρησιμοποιήσεις καθόλου το ποντίκι:

| Πλήκτρο | Λειτουργία |
| --- | -------- |
| `S` | Εναλλαγή λειτουργίας περιοχής με κύλιση |
| `Super + Arrow keys` | Μετακίνηση ανάμεσα σε παράθυρα στη λειτουργία Παραθύρου |
| `Return` | Καταγραφή του επισημασμένου παραθύρου |
| `Ctrl + A` | Καταγραφή της πλήρους εστιασμένης οθόνης |
| `R` | Επαναφορά της τελευταίας περιοχής που σχεδιάστηκε σε αυτή την περίοδο λειτουργίας |
| `Esc` | Απόρριψη του Omasnap |

Αυτές οι αντιστοιχίσεις υπάρχουν μόνο όσο το Omasnap είναι ανοιχτό, οπότε δεν μπορούν να συγκρουστούν με τίποτα στη δική σου διαμόρφωση.

## Εγγραφή οθόνης

Το `Alt + Print Screen` ανοίγει το _Trigger > Capture > Screenrecord_, το οποίο ρωτάει τι θέλεις στην ηχητική μπάντα: καθόλου ήχο, ήχο επιφάνειας εργασίας, επιφάνεια εργασίας συν μικρόφωνο, ή επιφάνεια εργασίας συν μικρόφωνο συν κάμερα web. Η τελευταία επιλογή εμφανίζεται μόνο αν έχεις πράγματι μια κάμερα συνδεδεμένη. Διάλεξε μία και ο επιλογέας εγγραφής του Omarchy σε αφήνει να σύρεις μια περιοχή ή να κάνεις κλικ σε ένα παράθυρο ή μια οθόνη.

Η εγγραφή εκτελείται στο gpu-screen-recorder, το οποίο κωδικοποιεί στη GPU στα 60fps και καταφεύγει στη CPU αν χρειαστεί. Το αποτέλεσμα είναι ένα MP4 στο `~/Videos`, με όνομα `screenrecording-2026-08-13_14-22-05.mp4`. Όρισε το `OMARCHY_SCREENRECORD_DIR` για να το αλλάξεις — αλλά σημείωσε ότι, σε αντίθεση με τον κατάλογο στιγμιότυπων οθόνης, αυτός πρέπει να υπάρχει ήδη, αλλιώς η εγγραφή αρνείται να ξεκινήσει.

Όσο εγγράφεις, εμφανίζεται μια μικρή ένδειξη στη γραμμή. Κάνε κλικ πάνω της για να σταματήσεις. Μπορείς επίσης να σταματήσεις ξανά με το `Alt + Print Screen`, ή με την καταχώριση _Stop Screenrecording_ κάτω από το _Trigger > Capture > Screenrecord_, η οποία εμφανίζεται μόνο όσο κάτι εγγράφεται πράγματι.

Η διακοπή κάνει λίγο συμμάζεμα πριν σου παραδώσει το αρχείο: το πρώτο καρέ περικόπτεται, και αν υπάρχει ήχος κανονικοποιείται στα -14 LUFS με το pop λήψης του PipeWire στην πολύ αρχή σιγασμένο. Μετά εμφανίζεται μια ειδοποίηση με μια μικρογραφία από την εγγραφή. Κάνε κλικ πάνω της για να αναπαραγάγεις το αρχείο στο Omaview.

### Η επικάλυψη της κάμερας web

Όταν εγγράφεις με κάμερα web, η κάμερα εμφανίζεται ως ένα καρφιτσωμένο, περικομμένο παράθυρο πορτρέτου στην κάτω δεξιά γωνία οτιδήποτε εγγράφεις. Αν κάθεται πάνω σε κάτι που χρειάζεσαι, άλλαξε το μέγεθός της εν κινήσει:

| Πλήκτρο συντόμευσης | Λειτουργία |
| ------ | -------- |
| `Super + Alt + [` | Κάνε την επικάλυψη της κάμερας web μικρότερη |
| `Super + Alt + ]` | Κάνε την επικάλυψη της κάμερας web μεγαλύτερη |

Υπάρχουν τρία μεγέθη — μικρό, μεσαίο, και μεγάλο — και τα πλήκτρα συντόμευσης μετακινούνται ανάμεσά τους. Το μεσαίο είναι η προεπιλογή. Είναι ανάλογα της εγγραφής, οπότε η κάμερα καταλαμβάνει το ίδιο μερίδιο του καρέ είτε εγγράφεις μια οθόνη 1080p είτε μία 6K. Και αν έγραψες μια περιοχή αντί για ολόκληρη οθόνη, η επικάλυψη αγκυρώνεται στη γωνία αυτής της περιοχής αντί για της οθόνης, οπότε μένει μέσα στο πλάνο.

Μπορείς επίσης να το καλέσεις απευθείας με `omarchy-capture-webcam-resize small`, ή `reset` για να επιστρέψεις στο μεσαίο.

## Κείμενο, κωδικοί QR, και χρώματα

Το `Super + Ctrl + Print Screen` επιλέγει μια περιοχή και κάνει OCR σε αυτήν στο πρόχειρο. Αυτό καλύπτεται σωστά στο [Εξαγωγή κειμένου & Υπαγόρευση](11-text-extraction-dictation.md).

Το _Trigger > Capture > QR Code_ κάνει το ίδιο κόλπο για κωδικούς QR. Επίλεξε την περιοχή με τον κωδικό μέσα της, και η αποκωδικοποιημένη τιμή πηγαίνει στο πρόχειρο. Ψάχνει μόνο για κωδικούς QR — το πυκνό περιεχόμενο οθόνης έχει τη συνήθεια να περνιέται ψευδώς για barcode διαφορετικά. Αξίζει να το ξέρεις: η αποκωδικοποιημένη τιμή πηγαίνει στο πρόχειρο και πουθενά αλλού. Δεν εκτυπώνεται, δεν βρίσκεται στην ειδοποίηση, και επισημαίνεται ως ευαίσθητη ώστε να μην παραμένει στο [ιστορικό προχείρου](08-unified-clipboard-history.md). Οι κωδικοί QR μεταφέρουν τακτικά μυστικά — το URI `otpauth://` πίσω από έναν κωδικό ρύθμισης 2FA, για παράδειγμα — και δεν το θέλεις αυτό σε ένα αρχείο καταγραφής. Η επικόλληση εξακολουθεί να δουλεύει μια χαρά.

Το `Super + Print Screen` (ή το _Trigger > Capture > Color_) μετατρέπει τον κέρσορα σε σταγονόμετρο. Κάνε κλικ σε οτιδήποτε στην οθόνη και το χρώμα καταλήγει στο πρόχειρο. Πάτα ξανά το πλήκτρο συντόμευσης για να βγεις χωρίς να επιλέξεις.

## Μετατροπή κωδικοποίησης πριν μοιραστείς

Μια εγγραφή οθόνης 4K ή ένα ακατέργαστο HEIC από το τηλέφωνό σου είναι συχνά πολύ μεγάλο για να το στείλεις απλώς. Το `Super + Ctrl + .` (ή το _Trigger > Transcode_) το διορθώνει αυτό. Σου προσφέρει έναν επιλογέα αρχείων με ασαφή αναζήτηση στα `~/Pictures` και `~/Videos`, και μετά ρωτάει για μορφή και μέγεθος.

Οι εικόνες πηγαίνουν σε jpg ή png σε υψηλό, μεσαίο, ή χαμηλό, που περιορίζουν το πλάτος στα 3160, 2160, και 1080 pixels. Τα βίντεο πηγαίνουν σε mp4 ή σε κινούμενο gif σε 4k, 1080p, ή 720p. Το μετατρεμμένο αρχείο γράφεται δίπλα στο πρωτότυπο με την ανάλυση στο όνομα — `demo-1080p.mp4` — και η διαδρομή αντιγράφεται στο πρόχειρο ως URI αρχείου, οπότε μπορείς να το επικολλήσεις απευθείας σε μια εφαρμογή που δέχεται αποθέσεις αρχείων.

Δουλεύει και από το τερματικό, αν ξέρεις ήδη τι θέλεις: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. Υπάρχει επίσης το `omarchy transcode ascii`, που μετατρέπει μια εικόνα σε τέχνη ASCII — αυτό είναι κυρίως για [επωνυμία](41-branding.md).

## Αποστολή κάπου

Μόλις έχεις το αρχείο, το `Super + Ctrl + S` ανοίγει το μενού Share και το στέλνει σε άλλη συσκευή στο δίκτυό σου μέσω LocalSend. Δες τα [GUIs](22-guis.md) για αυτό.
