# שינת מערכת

Omarchy מפעילה השהיה ותרדמת כברירת מחדל, אבל אם יש לכם בעיות עם אחת מהן במכונה שלכם, תוכלו לכבות אותן.

במכונות NVIDIA GB10, כגון DGX Spark ו-ASUS Ascent GX10, השהיה ותרדמת כבויות, כפי שהן ב-DGX OS של NVIDIA, כי טרם הוכח ששינה עובדת על החומרה הזו. הדבר נכון גם לגבי ASUS Zenbook A16 (UX3607OA), שבו ההשהיה עדיין אינה מכניסה את השבב לשינה מלאה ויכולה להיתקע במהלך הלילה. מתג ההשהיה והגדרת התרדמת אינם חלים שם. כדי להפעיל מחדש את השינה, הסירו את `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf` עם `sudo rm`; לאחר מכן ההשהיה תחזור לתפריט, וניתן יהיה להגדיר תרדמת כבשאר המכונות. הרצת `sudo omarchy apply hardware --install-user "$USER"` מחזירה את הקובץ.

### פרופילי צריכת חשמל

במחשב נייד, Omarchy זוכרת את פרופיל צריכת החשמל שלכם בנפרד למצב מחובר לחשמל ולמצב פועל על סוללה, ומחליפה בין השניים כשאתם מחברים ומנתקים. מהקופסה, המשמעות היא ביצועים ב-AC ומאוזן בסוללה.

תוכלו לראות מה המכונה שלכם מציעה עם `omarchy powerprofiles list`, ולהגדיר את הפרופיל הרצוי למצב שבו אתם נמצאים כעת עם `omarchy powerprofiles set autodetect power-saver`. כדי להגדיר את המצב האחר מבלי לנתק דבר, ציינו אותו ישירות: `omarchy powerprofiles set battery power-saver`. מה שתבחרו הוא מה שתקבלו בחזרה בפעם הבאה שתהיו במצב הזה.

### החלפת מצב השהיה

מחליפים את מצב ההשהיה על ידי הרצת `omarchy toggle suspend` מהטרמינל. זה רק מגלה/מסתיר את האפשרות תחת _מערכת_ (או `Super + Esc`), ואז תוכלו לראות אם זה עובד באופן עקבי במערכת שלכם. אם לא, תוכלו להסתיר אותה שוב עם אותה פקודה.

### החלפת מצב תרדמת

מגדירים תרדמת על ידי הרצת `omarchy hibernation setup` מהטרמינל. התרדמת יוצרת תת-נפח /swap בכונן האתחול שלכם בגודל הקצאת ה-RAM הפיזי שלכם, אז ודאו שיש לכם הרבה מקום פנוי. במכונה של 32GB, תמיד תצטרכו 32GB+ פנויים עבור נפח זה. התרדמת דורשת גם את מנהל האתחול ברירת המחדל Limine.

לאחר ההגדרה, תראו את אפשרות התרדמת תחת _מערכת_ (או `Super + Esc`), ואז תוכלו לראות אם היא עובדת באופן עקבי במערכת שלכם. אם לא, תוכלו להסיר אותה שוב על ידי הרצת `omarchy hibernation remove`.
