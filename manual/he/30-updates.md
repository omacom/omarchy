# עדכונים

Omarchy והחבילות שלכם נשמרות מעודכנות דרך _עדכון > Omarchy_ בתפריט Omarchy (`Super + Space`).

Omarchy עצמה מותקנת כחבילות pacman רגילות מ[מאגר החבילות של Omarchy](https://github.com/omacom-io/omarchy-pkgs), כך שעדכון מתקין את [גרסת Omarchy העדכנית ביותר](https://github.com/omacom/omarchy/releases), מריץ כל הגירה ממתינה כדי לסנכרן את המערכת שלכם עם העדכנית ביותר, ומעדכן את כל חבילות המערכת מ[מראת Arch של Omarchy](https://github.com/omacom-io/omarchy-mirror) ומ[AUR](https://aur.archlinux.org/) (אם התקנתם חבילות AUR כלשהן).

כאשר יוצאות גרסאות חדשות, אייקון חץ עגול יופיע מימין לשעון שלכם. לחצו עליו ותהליך העדכון יתחיל.

![update-available](images/update-available.webp)

### ארבעה ערוצים

Omarchy מתעדכנת לאורך ארבעה ערוצים: יציב, RC, edge ו-dev. התקנות חדשות מתחילות בערוץ היציב, העוקב אחר [הגרסאות הרשמיות](https://github.com/omacom/omarchy/releases/), וכן אחר [מראת Arch היציבה של Omarchy](https://github.com/omacom-io/omarchy-mirror) המריצה חודש אחד מאחורי העדכנית ביותר, כך שנוכל לתפוס כל אי-תאימות חדשה הדורשת שינויי תצורה לפני שהם גורמים לבעיות לאנשים.

אבל אם תרצו לעזור לאתר את הבעיות הפוטנציאליות האלה, תוכלו לרוץ בערוץ edge. זה ישמור את חבילות Omarchy שלכם עוקבות אחר גרסאות הפיתוח העדכניות ביותר, ויאפשר לכם להתעדכן לחבילות Arch העדכניות ביותר ברגע שהן זמינות. עליכם לעשות זאת רק אם אתם מנוסים ב-Linux, ויודעים כיצד לשחזר מערכת שיש לה בעיות.

לפני כל גרסה עיקרית חדשה, נבצע אימות סופי באמצעות ערוץ RC. אם אתם מעוניינים לעזור בליטוש הסופי, בואו להסתובב ב-#omarchy-release-candidates ב-Discord.

לבסוף, יש ערוץ dev, המקשר את Omarchy ישירות לשכפול git של קוד המקור ב-`~/omarchy`, בשילוב עם חבילות edge. עליכם להשתמש בערוץ זה רק אם אתם משתמשי Linux מנוסים, העובדים ישירות על Omarchy, ומוכנים לסבול שברים.

תוכלו לעבור בין ערוצים באמצעות _עדכון > ערוץ_ מתפריט Omarchy (או `omarchy-channel-set` במסוף).

### עדכוני קושחה

החבילות שלכם אינן הדבר היחיד שמתיישן. מחשבים ניידים והתקנים היקפיים רבים שולחים קושחת BIOS, SSD ועגינה דרך שירות קושחת ספקי Linux, ו_עדכון > קושחה_ בתפריט Omarchy יביא ויתקין כל מה שהחומרה שלכם ממתינה לו. הוא מתקין את `fwupd` בפעם הראשונה שתפעילו אותו. הרבה קושחה ניתנת לכתיבה רק במהלך הפעלה מחדש, אז אל תופתעו אם תתבקשו לאחת.

### אזהרה לגבי עדכוני pacman/yay ישירים

אם אתם כבר מכירים את Arch, אולי תתפתו פשוט להריץ `pacman -Syu` או `yay -Syu` בעצמכם, אבל אם תעשו זאת, תפספסו את תמונת המצב, ההגירות ועדכוני התצורה ש-Omarchy מריצה יחד עם חבילות חדשות. לכן Omarchy תעצור בפועל שדרוג מערכת ישיר ותפנה אתכם ל-`omarchy update` במקום זאת. (אם אתם באמת יודעים מה אתם עושים, השומר יאמר לכם כיצד לעקוף אותו עבור עסקה אחת.)

### החזרת עדכונים גרועים

אם אי פעם תהיה לכם בעיה לאחר ביצוע עדכון, תוכלו להחזיר את המערכת שלכם לתמונת המצב שצולמה לפני העדכון. פשוט הפעילו מחדש ובחרו את תמונת המצב בתפריט טעינת האתחול מזמן שלפני שהתחלתם את העדכון.

![bootloader](images/bootloader.webp)

אם איכשהו קבצי התצורה שלכם נפגמו, תוכלו גם לבצע התקנה מחדש של Omarchy באמצעות `omarchy reinstall` במסוף. זה יתקין מחדש את כל חבילות ברירת המחדל של Omarchy, ישים אתכם על יציב וישנמך כל חבילה שהיא חדשה מדי, ויאפס את כל קבצי התצורה. שימו לב שכל שינויי תצורת המשתמש שלכם לברירות המחדל של Omarchy יידרסו בעשותכם זאת!
