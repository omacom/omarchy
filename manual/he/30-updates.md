# עדכונים

Omarchy והחבילות שלך נשמרים מעודכנים דרך _Update > Omarchy_ בתפריט Omarchy (`Super + Space`).

Omarchy עצמה מותקנת כחבילות pacman רגילות מ-[מאגר החבילות של Omarchy](https://github.com/omacom-io/omarchy-pkgs), כך שעדכון מתקין את [המהדורה האחרונה של Omarchy](https://github.com/omacom/omarchy/releases), מריץ כל מיגרציה ממתינה כדי לסנכרן את המערכת שלך עם הגרסה האחרונה, ומעדכן את כל חבילות המערכת מ-[מראת ה-Arch של Omarchy](https://github.com/omacom-io/omarchy-mirror) ומ-[AUR](https://aur.archlinux.org/) (אם התקנת חבילות AUR כלשהן).

כשמתפרסמות מהדורות חדשות, יופיע סמל של חץ במעגל מימין לשעון שלך. לחץ עליו ותהליך העדכון יתחיל.

![update-available](images/update-available.webp)

### ארבעה ערוצים

Omarchy מתעדכנת בארבעה ערוצים: stable, RC, edge ו-dev. התקנות חדשות מתחילות בערוץ stable, שעוקב אחר [המהדורות הרשמיות](https://github.com/omacom/omarchy/releases/), וגם אחר [מראת ה-Arch היציבה של Omarchy](https://github.com/omacom-io/omarchy-mirror) שרצה חודש אחד מאחורי הגרסה האחרונה, כדי שנוכל לתפוס אי-התאמות חדשות שדורשות שינויי תצורה לפני שהן גורמות בעיות לאנשים.

אבל אם תרצה לעזור לאתר את הבעיות הפוטנציאליות האלה, תוכל לרוץ על ערוץ edge. זה ישאיר את חבילות Omarchy שלך עוקבות אחר גרסאות הבנייה האחרונות לפיתוח, ויאפשר לך להתעדכן לחבילות Arch האחרונות ברגע שהן זמינות. כדאי לעשות זאת רק אם אתה מנוסה ב-Linux, ויודע איך לשחזר מערכת שיש לה בעיות.

לפני כל מהדורה ראשית חדשה, נבצע אימות סופי באמצעות ערוץ RC. אם אתה מעוניין לעזור בליטוש הסופי, בוא לבלות ב-#omarchy-release-candidates ב-Discord.

לבסוף, יש את ערוץ dev, שמקשר את Omarchy ישירות ל-checkout של git של קוד המקור ב-`~/omarchy`, בשילוב עם חבילות edge. כדאי להשתמש בערוץ הזה רק אם אתה משתמש Linux מנוסה, עובד ישירות על Omarchy, ומוכן לסבול תקלות.

תוכל לעבור בין ערוצים באמצעות _Update > Channel_ מתפריט Omarchy (או `omarchy channel set <stable|rc|edge|dev>` בטרמינל, עם `omarchy channel current` כדי לראות איפה אתה).

### החלפת ליבות

Omarchy מאתחלת את ליבת `linux-omarchy` שלה עצמה, אבל תוכל להשאיר ליבות אחרות מותקנות לצידה, כמו ליבת `linux` הרגילה של Arch או גרסת בנייה ניסיונית שאתה בודק. כשיש יותר מאחת, _Update > Kernel_ בתפריט Omarchy מפרט אותן עם סימן ביקורת ליד זו שמאתחלת כברירת מחדל. בחר אחרת, הזן את הסיסמה שלך פעם אחת, והיא תאתחל אחרי ההפעלה מחדש הבאה. הליבות האחרות נשארות בתפריט האתחול, כך שעדיין תוכל לבחור אחת ידנית אם ברירת המחדל החדשה עושה לך בעיות. בטרמינל, זה `omarchy kernel` כדי לראות את ברירת המחדל הנוכחית, `omarchy kernel list` למה שמותקן, ו-`omarchy kernel set <kernel>` כדי לעבור.

### עדכוני קושחה

החבילות שלך הן לא הדבר היחיד שמתיישן. מחשבים ניידים וציוד היקפי רבים מספקים קושחת BIOS, SSD ועגינה דרך Linux Vendor Firmware Service, ו-_Update > Firmware_ בתפריט Omarchy יביא ויתקין כל מה שהחומרה שלך ממתינה לו. הוא מתקין את `fwupd` בפעם הראשונה שאתה מריץ אותו. הרבה קושחה אפשר לכתוב רק במהלך הפעלה מחדש, אז אל תתפלא אם תתבקש לעשות אחת.

כשאתה צריך לשנות הגדרה ב-BIOS עצמו, החזק את `Alt` בתפריט המערכת (`Super + Escape`) ו-_Reboot_ הופך ל-_Reboot to BIOS_, שמפעיל מחדש ישירות לתוך הגדרת הקושחה בלי שתצטרך לתפוס את המקש הנכון באתחול. מהטרמינל, זה `omarchy system firmware`.

### אזהרה לגבי עדכוני pacman/yay ישירים

אם אתה כבר מכיר את Arch, אולי תתפתה פשוט להריץ `pacman -Syu` או `yay -Syu` בעצמך, אבל אם תעשה זאת, תפספס את תמונת המצב, המיגרציות ועדכוני התצורה ש-Omarchy מריצה יחד עם חבילות חדשות. לכן Omarchy למעשה תעצור שדרוג מערכת ישיר ותפנה אותך ל-`omarchy update` במקום זאת. (אם אתה באמת יודע מה אתה עושה, המגן יגיד לך איך לעקוף אותו עבור טרנזקציה אחת.)

### חזרה לאחור מעדכונים בעייתיים

אם אי פעם תהיה לך בעיה אחרי שביצעת עדכון, תוכל להחזיר את המערכת שלך לאחור לתמונת המצב שצולמה לפני העדכון. פשוט הפעל מחדש ובחר בתפריט טעינת האתחול את תמונת המצב מלפני שהתחלת את העדכון.

![bootloader](images/bootloader.webp)

אם איכשהו קבצי התצורה שלך הושחתו, תוכל גם לבצע התקנה מחדש של Omarchy באמצעות `omarchy reinstall` בטרמינל. זה יתקין מחדש את כל חבילות ברירת המחדל של Omarchy, ישים אותך על stable (edge ב-Apple Silicon) וישנמך כל חבילה שחדשה מדי, ויאפס את כל קבצי התצורה. שים לב שכל שינויי תצורת המשתמש שלך לברירות המחדל של Omarchy יידרסו אם תעשה זאת!
