# עדכונים

Omarchy והחבילות שלכם נשמרים מעודכנים דרך _Update > Omarchy_ בתפריט Omarchy (`Super + Space`).

Omarchy עצמה מותקנת כחבילות pacman רגילות מתוך [Omarchy Package Repository](https://github.com/omacom-io/omarchy-pkgs), ולכן עדכון יתקין את [הגרסה האחרונה של Omarchy](https://github.com/omacom/omarchy/releases), יריץ כל מיגרציה ממתינה כדי לסנכרן את המערכת שלכם עם הגרסה האחרונה, ויעדכן את כל חבילות המערכת מתוך [Omarchy Arch Mirror](https://github.com/omacom-io/omarchy-mirror) ו-[AUR](https://aur.archlinux.org/) (אם התקנתם חבילות AUR כלשהן).

כאשר יוצאות גרסאות חדשות, יופיע סמל חץ מעגלי מימין לשעון שלכם. לחצו עליו ותהליך העדכון יתחיל.

![update-available](images/update-available.webp)

### ארבעה ערוצים

Omarchy מתעדכנת לאורך ארבעה ערוצים: stable, RC, edge ו-dev. התקנות חדשות מתחילות בערוץ stable, שעוקב אחר [הגרסאות הרשמיות](https://github.com/omacom/omarchy/releases/), וכן אחר [stable Omarchy Arch mirror](https://github.com/omacom-io/omarchy-mirror) שנמצא חודש אחד מאחורי הגרסה האחרונה, כדי שנוכל לתפוס אי-התאמות חדשות שדורשות שינויי תצורה לפני שהן גורמות בעיות לאנשים.

אבל אם אתם רוצים לעזור לזהות את הבעיות הפוטנציאליות האלה, תוכלו לעבוד בערוץ edge. זה ישמור את חבילות Omarchy שלכם מעודכנות לפי גרסאות הפיתוח האחרונות, ויאפשר לכם לעדכן לחבילות Arch האחרונות ברגע שהן זמינות. כדאי לעשות זאת רק אם אתם מנוסים ב-Linux, ויודעים איך לשחזר מערכת שיש בה בעיות.

לפני כל גרסה מרכזית חדשה, נבצע אימות סופי באמצעות ערוץ RC. אם אתם מעוניינים לעזור בליטוש הסופי, בואו להסתובב ב-#omarchy-release-candidates ב-Discord.

לבסוף, יש את ערוץ dev, שמקשר את Omarchy ישירות ל-git checkout של קוד המקור ב-`~/omarchy`, בשילוב עם חבילות edge. כדאי להשתמש בערוץ הזה רק אם אתם משתמשי Linux מנוסים, עובדים ישירות על Omarchy, ומוכנים לסבול שברונות.

תוכלו לעבור בין ערוצים באמצעות _Update > Channel_ מתפריט Omarchy (או `omarchy-channel-set` בטרמינל).

### החלפת קרנלים

Omarchy מאתחלת את קרנל `linux-omarchy` שלה עצמה, אבל תוכלו להשאיר קרנלים אחרים מותקנים לצידו, כמו קרנל Arch הסטנדרטי `linux` או גרסת ניסוי שאתם בודקים. כאשר יש יותר מאחד, האפשרות _Update > Kernel_ בתפריט Omarchy מפרטת אותם עם סימן וי ליד זה שמאתחל כברירת מחדל. בחרו אחר, הזינו את הסיסמה שלכם פעם אחת, והוא יאתחל לאחר ההפעלה מחדש הבאה. הקרנלים האחרים נשארים בתפריט האתחול, כך שתוכלו עדיין לבחור אחד ידנית אם ברירת המחדל החדשה עושה לכם צרות. בטרמינל, זה `omarchy-kernel` כדי לראות את ברירת המחדל הנוכחית, `omarchy-kernel list` כדי לראות מה מותקן, ו-`omarchy-kernel set <kernel>` כדי לעבור.

### עדכוני קושחה

החבילות שלכם הן לא הדבר היחיד שמתיישן. מחשבים ניידים וציוד היקפי רבים מספקים קושחת BIOS, SSD ועגינה דרך Linux Vendor Firmware Service, והאפשרות _Update > Firmware_ בתפריט Omarchy תביא ותתקין כל מה שהחומרה שלכם ממתינה לו. היא מתקינה את `fwupd` בפעם הראשונה שאתם מריצים אותה. הרבה קושחה יכולה להיכתב רק במהלך אתחול מחדש, אז אל תופתעו אם תתבקשו לעשות אחד.

כאשר אתם צריכים לשנות הגדרה ב-BIOS עצמו, החזיקו את `Alt` בתפריט המערכת (`Super + Escape`) והאפשרות _Reboot_ הופכת ל-_Reboot to BIOS_, שמאתחלת ישירות לתוך הגדרת הקושחה בלי צורך לתפוס את המקש הנכון בעת האתחול. מהטרמינל, זה `omarchy system firmware`.

### אזהרה לגבי עדכוני pacman/yay ישירים

אם אתם כבר מכירים את Arch, אולי תתפתו פשוט להריץ `pacman -Syu` או `yay -Syu` בעצמכם, אבל אם תעשו זאת, תפספסו את צילום המצב, המיגרציות ועדכוני התצורה ש-Omarchy מריצה יחד עם חבילות חדשות. זו הסיבה ש-Omarchy למעשה תעצור שדרוג מערכת ישיר ותפנה אתכם אל `omarchy update` במקום זאת. (אם אתם באמת יודעים מה אתם עושים, השומר יגיד לכם איך לעקוף אותו עבור טרנזקציה בודדת.)

### גלגול לאחור של עדכונים גרועים

אם אי פעם תהיה לכם בעיה לאחר ביצוע עדכון, תוכלו לשחזר את המערכת שלכם לצילום המצב שנלקח לפני העדכון. פשוט הפעילו מחדש ובחרו בתפריט טעינת האתחול את צילום המצב שלפני תחילת העדכון.

![bootloader](images/bootloader.webp)

אם איכשהו קבצי התצורה שלכם הושחתו, תוכלו גם לבצע התקנה מחדש של Omarchy באמצעות `omarchy reinstall` בטרמינל. פעולה זו תתקין מחדש את כל חבילות ברירת המחדל של Omarchy, תעביר אתכם ל-stable ותשנמך כל חבילה חדשה מדי, ותאפס את כל קבצי התצורה. שימו לב שכל שינויי תצורת המשתמש שלכם לברירות המחדל של Omarchy יידרסו בעת ביצוע פעולה זו!
