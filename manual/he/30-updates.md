# עדכונים

Omarchy והחבילות שלך נשמרים מעודכנים דרך _Update > Omarchy_ בתפריט Omarchy (`Super + Space`).

Omarchy עצמה מותקנת כחבילות pacman רגילות מתוך [מאגר החבילות של Omarchy](https://github.com/omacom-io/omarchy-pkgs), כך שעדכון מתקין את [הגרסה האחרונה של Omarchy](https://github.com/omacom/omarchy/releases), מריץ את כל המיגרציות הממתינות כדי לסנכרן את המערכת שלך עם הגרסה האחרונה, ומעדכן את כל חבילות המערכת מתוך [מראת Arch של Omarchy](https://github.com/omacom-io/omarchy-mirror) ו-[AUR](https://aur.archlinux.org/) (אם התקנת חבילות AUR כלשהן).

כשמתפרסמות גרסאות חדשות, יופיע סמל של חץ מעגלי מימין לשעון שלך. לחץ עליו ותהליך העדכון יתחיל.

![update-available](images/update-available.webp)

### ארבעה ערוצים

Omarchy מתעדכנת לאורך ארבעה ערוצים: stable, RC, edge ו-dev. התקנות חדשות מתחילות בערוץ stable, שעוקב אחר [הגרסאות הרשמיות](https://github.com/omacom/omarchy/releases/), וגם אחר [מראת Arch היציבה של Omarchy](https://github.com/omacom-io/omarchy-mirror) שרצה חודש אחד מאחורי הגרסה האחרונה, כדי שנוכל לתפוס כל חוסר תאימות חדש שדורש שינויי תצורה לפני שהוא גורם בעיות לאנשים.

אבל אם תרצה לעזור לזהות את הבעיות הפוטנציאליות האלה, תוכל לרוץ על ערוץ edge. זה ישמור את חבילות Omarchy שלך מעודכנות לפי בניית הפיתוח האחרונות, ויאפשר לך להתעדכן לחבילות Arch האחרונות ברגע שהן זמינות. כדאי לעשות זאת רק אם אתה מנוסה ב-Linux, ויודע איך לשחזר מערכת שיש בה בעיות.

לפני כל גרסה ראשית חדשה, נבצע אימות סופי באמצעות ערוץ RC. אם אתה מעוניין לעזור בליטוש הסופי, בוא לבלות ב-#omarchy-release-candidates ב-Discord.

לבסוף, יש את ערוץ dev, שמקשר את Omarchy ישירות ל-checkout של git של קוד המקור בתוך `~/omarchy`, בשילוב עם חבילות edge. כדאי להשתמש בערוץ הזה רק אם אתה משתמש Linux מנוסה, עובד ישירות על Omarchy, ומוכן לסבול שבר.

תוכל לעבור בין ערוצים באמצעות _Update > Channel_ מתפריט Omarchy (או `omarchy-channel-set` במסוף).

### החלפת קרנלים

Omarchy מאתחלת עם קרנל `linux-omarchy` משלה, אבל תוכל לשמור אחרים מותקנים לצידה, כמו קרנל `linux` הסטנדרטי של Arch או בנייה ניסיונית שאתה בודק. כשיש יותר מאחד, _Update > Kernel_ בתפריט Omarchy מפרט אותם עם סימן וי ליד זה שמאתחל כברירת מחדל. בחר אחר, הזן את הסיסמה שלך פעם אחת, והוא יאתחל לאחר ההפעלה מחדש הבאה. הקרנלים האחרים נשארים בתפריט האתחול, כך שעדיין תוכל לבחור אחד ידנית אם ברירת המחדל החדשה עושה לך בעיות. במסוף, זה `omarchy-kernel` כדי לראות את ברירת המחדל הנוכחית, `omarchy-kernel list` למה שמותקן, ו-`omarchy-kernel set <kernel>` כדי להחליף.

### עדכוני קושחה

החבילות שלך הן לא הדבר היחיד שמתיישן. מחשבים ניידים וציוד היקפי רבים מספקים קושחת BIOS, SSD ועגינה דרך Linux Vendor Firmware Service, ו-_Update > Firmware_ בתפריט Omarchy יביא ויתקין את כל מה שממתין לחומרה שלך. הוא מתקין את `fwupd` בפעם הראשונה שאתה מריץ אותו. הרבה קושחה ניתן לכתוב רק במהלך הפעלה מחדש, אז אל תופתע אם תתבקש לעשות אחת.

### אזהרה לגבי עדכוני pacman/yay ישירים

אם אתה כבר מכיר את Arch, אתה עלול להתפתות פשוט להריץ `pacman -Syu` או `yay -Syu` בעצמך, אבל אם תעשה זאת, תפספס את ה-snapshot, המיגרציות ועדכוני התצורה ש-Omarchy מריצה יחד עם חבילות חדשות. לכן Omarchy למעשה תעצור שדרוג מערכת ישיר ותפנה אותך ל-`omarchy update` במקום זאת. (אם אתה באמת יודע מה אתה עושה, המגן יגיד לך איך לעקוף אותו עבור טרנזקציה בודדת.)

### חזרה לאחור מעדכונים גרועים

אם אי פעם תהיה לך בעיה לאחר ביצוע עדכון, תוכל להחזיר את המערכת שלך ל-snapshot שצולם לפני העדכון. פשוט הפעל מחדש ובחר בתפריט טעינת האתחול את ה-snapshot מלפני שהתחלת את העדכון.

![bootloader](images/bootloader.webp)

אם איכשהו קבצי התצורה שלך הושחתו, תוכל גם לבצע התקנה מחדש של Omarchy באמצעות `omarchy reinstall` במסוף. זה יתקין מחדש את כל חבילות ברירת המחדל של Omarchy, יעביר אותך ל-stable ויוריד גרסה של כל חבילה שחדשה מדי, ויאפס את כל קבצי התצורה. שים לב שכל שינויי תצורת המשתמש שלך לברירות המחדל של Omarchy יידרסו בעת ביצוע פעולה זו!
