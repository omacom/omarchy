# אימות חומרה

### אימות באמצעות טביעת אצבע

מחשבים ניידים רבים מגיעים עם חיישן טביעת אצבע לצורך אימות. אפשר להשתמש בו עם Omarchy על ידי הפעלת _Setup > Security > Fingerprint_ בתפריט Omarchy (`Super + Space`).

זה יתקין את חבילת טביעת האצבע, יקלוט את הטביעה שלכם, יאמת אותה, ותהיו מוכנים להשתמש בטביעת האצבע שלכם כדי לבטל את النעילה ממסך הנعילה (שאותו אפשר להפעיל עם `Super + Ctrl + L`), להיכנס למצב sudo, ולאשר בקשות הרشאה של המערכה.

לאחר שמסך النעילה כיבה את התצוגה, החיישן נח כדי לחסוך בחشמל, אז העירו את המסך עם כל מקש או עם مشطח המגע לפני שתגעו בו.

כשמכסה המחשב النייד סגור, בקשת טביעת האצבע נדלגת אוטומטית, כך שעוברים ישר לבקשת הסיסמה במקום לחכות לחיישן שאי אפשר להגיע אליו. אם מסיבה אחרת עליכם לעבוד עם מקלדת חיצונית שאין בה חיישן, פשוט לחצו על `CTRL + C` כשמוצגת לכם בקשה לטביעת אצבע במהלך `sudo`.

אפשר להסיר את האימות באמצעות טביעת אצבע תחת _Remove > Security > Fingerprint_ בתפריט Omarchy.

### אימות Fido2

אם אתם משתמשים בהתקן Fido2, אפשר להגדיר אותו לאימות `sudo` באמצעות _Setup > Security > Fido2_ בתפריט Omarchy (`Super + Space`). זה מכסה את `sudo` ובקשות הרשאה של המערכת, אבל לא את ביטול הנعילה של המחשב.

אפשר להסיר את האימות באמצעות fido2 תחת _Remove > Security > Fido2_ בתפריט Omarchy.
