# אימות חומרה

### אימות בטביעת אצבע

לפטופים רבים מגיעים עם חיישן טביעת אצבע לביצוע אימות. תוכלו להשתמש בזה עם Omarchy על ידי הרצת _Setup > Security > Fingerprint_ בתפריט Omarchy (`Super + Space`).

זה פותח טביעת אצבע במסך מלא שמתמלאת כשאתם נוגעים בחיישן. מאחורי הקלעים, Omarchy יתקין את חבילת טביעת האצבע, יאסוף את הטביעה שלכם, יאמת אותה, ותהיו מוכנים להשתמש בטביעת האצבע שלכם כדי לבטל נעילה ממסך הנעילה (שתוכלו להפעיל עם `Super + Ctrl + L`), להיכנס למצב sudo, ולאשר בקשות מערכת.

לאחר שמסך הנעילה כיבה את הצג, החיישן נח כדי לחסוך בחשמל, אז העירו את המסך עם מקש כלשהו או עם משטח המגע לפני שתיגעו בו.

כאשר מכסה הלפטופ שלכם סגור, בקשת טביעת האצבע מדולגת אוטומטית, כך שתעברו ישר לבקשת הסיסמה במקום לחכות לחיישן שאינכם יכולים להגיע אליו. אם אתם צריכים לעבוד אחרת על מקלדת חיצונית שאין לה חיישן, פשוט לחצו על `CTRL + C`, כאשר תתבקשו לספק את טביעת האצבע שלכם במהלך `sudo`.

תוכלו להסיר את אימות טביעת האצבע תחת _Remove > Security > Fingerprint_ בתפריט Omarchy.

### אימות Fido2

אם אתם משתמשים בהתקן Fido2, תוכלו להגדיר אותו לאימות `sudo` באמצעות _Setup > Security > Fido2_ בתפריט Omarchy (`Super + Space`). הוא מכסה את `sudo` ואת בקשות הרשאת המערכת, אך לא את ביטול נעילת המחשב שלכם.

תוכלו להסיר את אימות ה-Fido2 תחת _Remove > Security > Fido2_ בתפריט Omarchy.
