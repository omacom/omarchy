# רשת

הרשת ב-Omarchy מנוהלת על ידי NetworkManager, ואתם שולטים בה מסמל הרשת ב[פס העליון](05-the-top-bar.md) או עם `Super + Ctrl + N`.

הפאנל הזה סורק רשתות Wi-Fi, מראה את עוצמת האות ומתחבר. Ethernet לא צריך שום דבר בכלל — חברו אותו וזה עובד. אם אתם מעדיפים להישאר בטרמינל, `nmtui` נותן לכם את אותן האפשרויות, ויש גם קבוצת פקודות של `omarchy network`.

## שיתוף ה-Wi-Fi שלכם

במקום להקריא סיסמה ארוכה בקול, הפעילו את _Setup > Network > QR Code_ בזמן שאתם מחוברים ל-Wi-Fi. זה מציג על המסך קוד QR שכל מצלמת טלפון יכולה לסרוק כדי להצטרף. זה אחד מאותם דברים שתשתמשו בהם יותר ממה שהייתם מצפים ברגע שתדעו שהוא שם.

אם אתם באמת צריכים את הסיסמה עצמה, `omarchy network password <interface>` מדפיס אותה.

## DNS

Omarchy משתמשת בכל DNS שהרשת שלכם מוסרת דרך DHCP. אתם יכולים לעקוף את זה עבור המחשב כולו תחת _Setup > Network > DNS_, שם Cloudflare ו-Google נמצאים במרחק לחיצה אחת. בחרו ב-_Custom_ כדי להקליד את השרתים שלכם.

מהטרמינל, `omarchy dns` מדפיס את הספק הנוכחי ו-`omarchy dns Cloudflare` מגדיר אחד.

## קיבוע פס ה-Wi-Fi

אם הנתב שלכם שם את 2.4GHz, 5GHz ו-6GHz על אותו שם רשת, המחשב הנייד שלכם לפעמים ייצמד דווקא לאיטי שבהם. `omarchy network band` מראה על איזה פס אתם נמצאים, ו-`omarchy network band 5` מקבע אותו. השתמשו ב-`auto` כדי לתת לו לבחור שוב.

זה מקבע את הפס ולא נקודת גישה ספציפית, כך שאתם ממשיכים לעבור בין APs כרגיל.

## כמה זה מהיר?

_Trigger > Speed Test > Network Speed Test_ מודד את מהירות ההעלאה וההורדה האמיתית שלכם באמצעות צמד חוגות. מהטרמינל זה `omarchy network speedtest down` או `up`. זה מודד מול השירות של Omarchy עצמה וסופר רק את העברות הבדיקה שלה. הורדות אחרות יכולות להתחרות על רוחב הפס, אבל הן לא מתווספות לתוצאת בדיקת המהירות. (יש בדיקת מהירות דיסק שיושבת לידה באותו תפריט, אם אתם מודדים את צוואר הבקבוק האחר.)

## חומת האש

חומת האש דולקת כברירת מחדל וחוסמת את כל התעבורה הנכנסת, עם יוצא מן הכלל אחד: פורט 53317, כדי ש-[LocalSend](22-guis.md) יעבוד מיד מהקופסה.

SSH כבוי עד שאתם מפעילים אותו עם _Setup > Security > SSHD_, שמפעיל את ה-daemon, פותח את פורט 22 עם הגבלת קצב נגד brute force, ומאשר מפתח. גם Docker נעול היטב, כך שקונטיינרים לא יכולים לחשוף את עצמם בטעות לעולם. ראו את [האבטחה](48-security.md) לסיפור המלא.

## Tailscale

[Tailscale](https://tailscale.com/) הוא VPN מסוג mesh שהופך את ההגעה לכל המחשבים והשרתים שלכם דרך האינטרנט לפשוטה ובטוחה. התקינו אותו עם _Install > Service > Tailscale_.

זה נותן לכם פאנל Tailscale בפס, שמחבר ומנתק את ה-tailnet, מחליף חשבונות ובוחר exit node — גם המכונות שלכם וגם אזורי Mullvad מופיעים ברשימה. הוא גם מעיין במכונות שלכם, ושם גר Taildrop: בחרו מכונה ולחצו על `s` כדי לשלוח אליה קבצים, או על `c`, `n` ו-`d` כדי להעתיק את ה-IP, השם או שם ה-DNS המלא שלה. המקבילה בטרמינל היא `omarchy tailscale send <machine> [file...]`, וקבצים שנשלחים אליכם נוחתים ב-`~/Downloads` באופן אוטומטי. ההתראה שמכריזה על הגעה מחכה עד שתלחצו כדי לפתוח אותה או לסגור אותה, כך שקובץ שמגיע בזמן שאתם רחוקים מהמכונה עדיין יהיה שם כדי להגיב אליו כשתחזרו.

ההתקנה גם מוסיפה אפליקציית ווב למסוף הניהול של Tailscale.

## כשזה מפסיק לעבוד

לפני שאתם מאתחלים, נסו להפעיל מחדש רק את החלק הבעייתי בפני עצמו. ב-_Update > Hardware_ יש Wi-Fi, Bluetooth, Audio ו-Trackpad, וטעינה מחדש של אחד מהם פותרת את רוב מצבי "זה עבד לפני חמש דקות". ראו את [פתרון הבעיות](45-troubleshooting.md).
