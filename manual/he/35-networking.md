# רשת

החיבור לרשת ב-Omarchy מנוהל על ידי NetworkManager, ואתה שולט בו מסמל הרשת ב-[הסרגל העליון](05-the-top-bar.md) או באמצעות `Super + Ctrl + N`.

החלונית הזו סורקת רשתות Wi-Fi, מציגה את עוצמת האות ומתחברת אליהן. Ethernet לא דורש שום דבר — פשוט חבר כבל וזה עובד. אם אתה מעדיף להישאר בטרמינל, `nmtui` נותן לך את אותם הכלים, ויש גם קבוצת פקודות של `omarchy network`.

## שיתוף ה-Wi-Fi שלך

במקום להקריא סיסמה ארוכה בקול רם, הפעל את _Setup > Network > QR Code_ בזמן שאתה מחובר ל-Wi-Fi. זה יציג על המסך קוד QR שכל מצלמת טלפון יכולה לסרוק כדי להצטרף. זה אחד מאותם דברים שתמצא את עצמך משתמש בהם יותר ממה שציפית, ברגע שתדע שהם קיימים.

אם אתה באמת צריך את הסיסמה עצמה, הפקודה `omarchy network password <interface>` תדפיס אותה.

## DNS

Omarchy משתמש בכל DNS שהרשת שלך מספקת דרך DHCP. אתה יכול לעקוף את זה עבור כל המכונה תחת _Setup > Network > DNS_, שם Cloudflare ו-Google זמינים במרחק קליק אחד. בחר _Custom_ כדי להקליד את השרתים שלך בעצמך.

מהטרמינל, `omarchy dns` מדפיס את הספק הנוכחי, ו-`omarchy dns Cloudflare` מגדיר אחד כזה.

## קיבוע תחום ה-Wi-Fi

אם הנתב שלך מאחד את 2.4GHz, 5GHz ו-6GHz תחת אותו שם רשת, המחשב הנייד שלך לפעמים ייצמד דווקא לאיטי שבהם. הפקודה `omarchy network band` מראה באיזה תחום אתה נמצא, ו-`omarchy network band 5` מקבעת אותך אליו. השתמש ב-`auto` כדי לתת לו לבחור שוב בעצמו.

זה מקבע את התחום ולא נקודת גישה ספציפית, כך שאתה ממשיך לנדוד בין APs כרגיל.

## כמה מהיר זה?

הכלי _Trigger > Speed Test > Network Speed Test_ מודד את מהירות ההורדה וההעלאה בפועל שלך בעזרת צמד מחוגים. מהטרמינל זה `omarchy network speedtest down` או `up`. (יש גם מבחן מהירות לדיסק שיושב ממש לידו בתפריט הזה, אם אתה בדיוק בוחן את צוואר הבקבוק השני.)

## חומת האש

חומת האש מופעלת כברירת מחדל וחוסמת את כל התעבורה הנכנסת, עם חריג אחד: פורט 53317, כדי ש-[LocalSend](22-guis.md) יעבוד ישר מהקופסה.

SSH כבוי עד שאתה מדליק אותו דרך _Setup > Security > SSHD_, שמפעיל את הדמון, פותח את פורט 22 עם הגבלת קצב נגד ניסיונות brute force, ומאשר מפתח. גם Docker נעול היטב, כך שקונטיינרים לא יכולים לחשוף את עצמם בטעות לעולם. ראה את [האבטחה](48-security.md) בשביל הסיפור המלא.

## Tailscale

[Tailscale](https://tailscale.com/) הוא VPN ברשת mesh שמאפשר להגיע לכל המחשבים והשרתים שלך דרך האינטרנט בצורה פשוטה ומאובטחת. התקן אותו דרך _Install > Service > Tailscale_.

זה מוסיף לך חלונית Tailscale בסרגל, שמחברת ומנתקת את ה-tailnet, מחליפה חשבונות ובוחרת צומת יציאה — גם המחשבים שלך וגם האזורים של Mullvad מופיעים ברשימה. היא גם מאפשרת לעיין במחשבים שלך, ושם בדיוק נמצא Taildrop: בחר מחשב ולחץ `s` כדי לשלוח אליו קבצים, או `c`, `n` ו-`d` כדי להעתיק את ה-IP שלו, את שמו או את שם ה-DNS המלא שלו. המקבילה בטרמינל היא `omarchy tailscale send <machine> [file...]`, וקבצים שנשלחים אליך נוחתים אוטומטית ב-`~/Downloads`. ההתראה שמכריזה על הגעת קובץ מחכה עד שתלחץ עליה כדי לפתוח או לסגור אותה, כך שקובץ שמגיע כשאתה לא ליד המחשב עדיין יהיה שם ותוכל להגיב אליו כשתחזור.

ההתקנה גם מוסיפה אפליקציית רשת למסוף הניהול של Tailscale.

## כשזה מפסיק לעבוד

לפני שאתה מאתחל, נסה להפעיל מחדש רק את הרכיב שמתקלקל. תחת _Update > Hardware_ תמצא את Wi-Fi, Bluetooth, Audio ו-Trackpad, וטעינה מחדש של אחד מהם פותרת את רוב מצבי ה"זה עבד לפני חמש דקות". ראה את [פתרון הבעיות](45-troubleshooting.md).
