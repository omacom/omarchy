# רשת

הרשת ב-Omarchy מנוהלת על ידי NetworkManager, ואתם מפעילים אותה מסמל הרשת ב[שורת התפריט](05-the-top-bar.md) או עם `Super + Ctrl + W`.

החלונית הזו סורקת רשתות Wi-Fi, מראה את עוצמת האות ומתחברת. Ethernet לא צריך כלום — חברו אותו וזה עובד. אם אתם מעדיפים להישאר בטרמינל, `nmtui` נותן לכם את אותן בקרות, ויש גם קבוצת פקודות `omarchy network`.

## שיתוף ה-Wi-Fi שלכם

במקום להקריא סיסמה ארוכה בקול, הריצו _הגדרה > רשת > קוד QR_ כשאתם מחוברים ל-Wi-Fi. זה מציב קוד QR על המסך שכל מצלמת טלפון יכולה לסרוק כדי להצטרף. זה אחד הדברים האלה שתשתמשו בהם יותר ממה שציפיתם ברגע שתדעו שהוא שם.

אם אתם באמת צריכים את הסיסמה עצמה, `omarchy network password <interface>` מדפיס אותה.

## DNS

Omarchy משתמש בכל DNS שהרשת שלכם מחלקת דרך DHCP. תוכלו לעקוף זאת עבור כל המכונה תחת _הגדרה > רשת > DNS_, שם Cloudflare ו-Google נמצאים במרחק קליק אחד. בחרו _מותאם אישית_ כדי להקליד את השרתים שלכם.

מהטרמינל, `omarchy dns` מדפיס את הספק הנוכחי ו-`omarchy dns Cloudflare` מגדיר אחד.

## קיבוע תחום ה-Wi-Fi

אם הנתב שלכם שם 2.4GHz, 5GHz ו-6GHz על אותו שם רשת, המחשב הנייד שלכם יידבק לפעמים לאיטי. `omarchy network band` מראה באיזה תחום אתם נמצאים, ו-`omarchy network band 5` מקבע אותו. השתמשו ב-`auto` כדי לתת לו לבחור שוב.

זה מקבע את התחום ולא נקודת גישה מסוימת, כך שאתם ממשיכים לנדוד בין נקודות גישה כרגיל.

## כמה מהיר זה?

_הפעלה > בדיקת מהירות > בדיקת מהירות רשת_ מודד את מהירות ההעלאה וההורדה האמיתית שלכם עם זוג מחוונים. מהטרמינל זה `omarchy network speedtest down` או `up`. (יש בדיקת מהירות דיסק שיושבת לידו באותו תפריט, אם אתם בודקים את צוואר הבקבוק האחר.)

## חומת האש

חומת האש מופעלת כברירת מחדל וחוסמת את כל התעבורה הנכנסת, עם חריג אחד: יציאה 53317, כדי ש-[LocalSend](22-guis.md) יעבוד מהקופסה.

SSH כבוי עד שתפעילו אותו עם _הגדרה > Security > SSHD_, שמפעיל את הדימון, פותח את יציאה 22 עם הגבלת קצב נגד כוח גס, ומאשר מפתח. Docker נעול גם הוא, כך שקונטיינרים לא יכולים לחשוף את עצמם בטעות לעולם. ראו [אבטחה](48-security.md) לסיפור המלא.

## Tailscale

[Tailscale](https://tailscale.com/) הוא VPN רשת שהופך את הגישה לכל המחשבים והשרתים שלכם דרך האינטרנט לפשוטה ובטוחה. התקינו אותו עם _התקנה > Service > Tailscale_.

זה נותן לכם חלונית Tailscale בשורה, שמחברת ומנתקת את ה-tailnet, מחליפה חשבונות ובוחרת צומת יציאה — המכונות שלכם ואזורי Mullvad שניהם מופיעים ברשימה. היא גם גולשת במכונות שלכם, ושם Taildrop חי: בחרו מכונה ולחצו `s` כדי לשלוח לה קבצים, או `c`, `n` ו-`d` כדי להעתיק את ה-IP, השם או שם ה-DNS המלא שלה. המקבילה בטרמינל היא `omarchy tailscale send <machine> [file...]`, וקבצים שנשלחים אליכם נוחתים ב-`~/Downloads` אוטומטית. ההתראה שמודיעה על הגעה מחכה עד שתלחצו כדי לפתוח או לבטל אותה, כך שקובץ שמופיע בזמן שאתם רחוקים מהמכונה עדיין שם לענות עליו כשאתם חוזרים.

התקנתו מוסיפה גם אפליקציית רשת עבור מסוף הניהול של Tailscale.

## כשזה מפסיק לעבוד

לפני הפעלה מחדש, נסו להפעיל מחדש רק את החלק הבעייתי לבדו. ל-_עדכון > Hardware_ יש Wi-Fi, Bluetooth, Audio ו-Trackpad, וטעינה מחדש של אחד מאלה פותרת את רוב מצבי ה"זה עבד לפני חמש דקות". ראו [פתרון בעיות](45-troubleshooting.md).
