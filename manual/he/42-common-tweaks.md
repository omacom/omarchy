# התאמות נפוצות

זהו אוסף של התאמות נפוצות להתקנת Omarchy. דעו שלעתים ייתכן שעדכוני מערכת יידרשו לשחזר תצורות מסוימות למצבן המקורי. אם זה קורה, השינויים שלכם לא ילכו לאיבוד, אלא יישמרו בקובץ `.bak.<timestamp>` לצד הקובץ המקורי.

אם פישלתם במשהו, תוכלו לשחזר תצורות בודדות להגדרות המקוריות שלהן דרך _Update > Config_ בתפריט Omarchy. אם _באמת_ פישלתם בהכול, תוכלו לאפס את כל התצורות באמצעות `omarchy reinstall configs`, או להתקין מחדש כל חבילה ותצורת ברירת מחדל באמצעות `omarchy reinstall`.

### הצגת כל סמלי מגש המערכת כל הזמן

כברירת מחדל, סמלי מגש המערכת, כמו Dropbox, 1password או Steam, מוסתרים מאחורי חץ הרחבת המגש, שחושף אותם כשמרחפים מעליו. אם תרצו שהם יהיו חשופים כל הזמן, לחצו לחיצה ימנית על חץ ההרחבה כדי לפתוח את מנהל סמלי המגש, ואז הצמידו את הסמלים שתרצו להשאיר גלויים (תוכלו גם להסתיר את אלה שלעולם לא תרצו לראות).

### פינות חלון מעוגלות

העיצוב של Omarchy כברירת מחדל הוא של פינות מרובעות, אבל אם אתם אוהבים לרכך את זה קצת, בחרו _Appearance > Windows > Window Corners > Rounded Corners_ בתפריט Omarchy, או הריצו `omarchy hyprland corners rounded`. האפשרות _Theme Corners_ חוזרת למה שערכת הנושא משתמשת בו. כדי לבחור רדיוס משלכם, הישארו על _Theme Corners_ (`omarchy hyprland corners theme`), מכיוון ש-Rounded ו-Sharp נטענים אחרי התצורה שלכם ועוקפים אותה, והסירו את ההערה מעיגול הפינות ב-`~/.config/hypr/looknfeel.lua`:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### הסרת מרווחי חלונות

במסכי מחשב נייד, יש אנשים שמעדיפים לא לבזבז אף פיקסל על מרווחי חלונות (או אפילו על סרגל עליון, שאפשר לכבות באמצעות `Super + Shift + Space`). תוכלו לכבות את כל המרווחים והגבולות באמצעות `Super + Shift + Backspace`, או להסיר אותם לצמיתות על ידי הסרת ההערות במקטע הזה של `~/.config/hypr/looknfeel.lua`:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
