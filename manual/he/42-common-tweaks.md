# התאמות נפוצות

זהו אוסף של התאמות נפוצות להגדרת Omarchy. דעו שייתכן שמדי פעם יהיה צורך בעדכוני מערכת לשחזר תצורות מסוימות למצבן המקורי. אם זה יקרה, השינויים שלכם לא יאבדו, אלא יוכנסו לקובץ `.bak` באותה תיקייה.

אם הרסתם משהו, תוכלו לשחזר תצורות בודדות להגדרתן המקורית דרך _עדכון > Config_ בתפריט Omarchy. אם _באמת_ הרסתם הכול, תוכלו לאפס את כל התצורות דרך `omarchy-reinstall`.

### חשיפת כל סמלי המגש כל הזמן

כברירת מחדל, סמלי מגש, כמו Dropbox, 1password או Steam, מוסתרים מאחורי חץ מרחיב המגש, שחושף אותם כשאתם מרחפים מעליו. אם תרצו שהם יהיו חשופים כל הזמן, לחצו לחיצה ימנית על חץ המרחיב כדי לפתוח את מנהל סמלי המגש, ואז הצמידו את הסמלים שברצונכם לשמור גלויים (תוכלו גם להסתיר את אלה שלעולם אינכם רוצים לראות).

### פינות חלון מעוגלות

העיצוב כברירת מחדל של Omarchy הוא של פינות מרובעות, אך אם אתם אוהבים לרכך זאת מעט, תוכלו לשנות את `~/.config/hypr/looknfeel.lua` כך שהעיגול לא יהיה עוד בהערה:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### הסרת מרווחי חלון

בתצוגות מחשב נייד, יש אנשים שמעדיפים לא לבזבז פיקסלים על מרווחי חלון (או אפילו שורת תפריט, שתוכלו לכבות עם `Super + Shift + Space`). תוכלו לכבות את כל המרווחים והגבולות עם `Super + Shift + Backspace`, או להסיר אותם לצמיתות על ידי הסרת ההערות בקטע זה של `~/.config/hypr/looknfeel.lua`:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
