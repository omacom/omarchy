# מתגים, מצב סרק ושומר המסך

הרבה ממה שמשנים ביום־יום הוא לא באמת הגדרה. זה מצב שמדליקים לשעה ומכבים שוב: תאורת לילה כשעובדים עד מאוחר, נא לא להפריע כשמציגים, הישארות ערה כשצופים במשהו. Omarchy קוראת לאלה מתגים, וכולם עובדים באותה צורה — מקש קיצור, פריט בתפריט ופקודה, כולם פוגעים באותו מתג.

### תפריט המתגים

`Super + Ctrl + O` פותח ישירות את _הפעלה > מתגים_, או שאפשר להגיע לשם מתפריט Omarchy (`Super + Space`). כל מה שברשימה הזו הוא מתג שאפשר להפעיל בלי לחשוב איפה המצב שמור. מתגים למראה של שולחן העבודה נמצאים לידו, תחת _מראה_.

מהמסוף, אותם מתגים הם `omarchy toggle <thing>`. הריצו `omarchy toggle` לבדו כדי לראות את כל הקבוצה.

| מתג | מקש קיצור | פקודה |
| ------ | ------ | ------- |
| תאורת לילה | — | `omarchy toggle nightlight` |
| השתקת התראות | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| הישארות ערה (ללא נעילה במצב סרק) | `Super + Ctrl + I` | `omarchy toggle idle` |
| לכידת קריסות | — | `omarchy toggle crash-capture` |
| שומר מסך | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) סנכרון ערכת נושא | — | `omarchy toggle theme sync` |
| שורת תפריט | `Super + Shift + Space` | `omarchy toggle bar` |
| משטח מגע | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| מסך מגע | — | `omarchy toggle touchscreen` |
| השהיה | — | `omarchy toggle suspend` |
| GPU היברידי | — | `omarchy toggle hybrid gpu` |

מתגי משטח המגע, מסך המגע וה־GPU ההיברידי נמצאים תחת _הפעלה > חומרה_ (`Super + Ctrl + H`) ולא תחת מתגים, כי הם מופיעים רק כשיש לכם בפועל את החומרה הזו. מתגי משטח המגע ומסך המגע שורדים טעינה מחדש של Hyprland — שמו של ההתקן המושבת נשמר בקובץ מצב קטן ש־Hyprland קורא בעת ההפעלה כדי להשבית אותו שוב.

_מראה_ מכיל את שורת התפריט והאנימציות, ועוד כמה דברים שאינם פקודות `omarchy toggle` אבל מתנהגים אותו דבר: אחוזי סוללה בשורה, פריסת ברירת המחדל של סביבת העבודה, ותחת _חלונות_, רווחי חלונות (`Super + Shift + Backspace`) ויחס הגובה־רוחב הריבועי של חלון אחד (`Super + Ctrl + Backspace`).

רוב אלה הם פשוט קובץ דגל תחת `~/.local/state/omarchy/toggles/`. אם תרצו להסתעף לפי אחד מהם בתסריט, `omarchy-toggle-enabled` נותן לכם קוד יציאה במקום לשלוח אתכם לחפש:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

הדגלים נקראים לפי מצב הכיבוי — `screensaver-off`, `suspend-off`, `bar-off` — כך שהנוכחות שלהם פירושה שהתכונה מושבתת.

### מחוונים בשורה

כשמצב פעיל, מופיע גליף קטן באמצע השורה העליונה ליד השעון. זהו וידג'ט המחוונים, והוא נושא הכתבה, הקלטת מסך, תזכורות ממתינות, תאורת לילה, נא לא להפריע והישארות ערה.

מחוונים לא פעילים מוסתרים. העבירו את הסמן מעל מקום כלשהו בשורה והם מופיעים בהדרגה כשהם מעומעמים, כך שאפשר ללחוץ על אחד כדי להפעיל אותו בלי לדעת את מקש הקיצור שלו. לחיצה על מחוון פעיל מכבה אותו שוב. אם אתם מעדיפים לראות את כולם כל הזמן, הגדירו את `alwaysShow` ל־`true` בערך `omarchy.indicators` שב־`~/.config/omarchy/shell.json` — ראו [השורה העליונה](05-the-top-bar.md) להסבר על אופן ההגדרה של וידג'טים בשורה.

### תאורת לילה

תאורת לילה מחממת את המסך ל־4000K, והפעלה נוספת שלה מחזירה אותו ל־6500K. הפעילו אותה מתפריט המתגים (`Super + Ctrl + O`) או באמצעות `omarchy toggle nightlight`. היא מונעת על ידי hyprsunset, שהמתג מפעיל עבורכם אם הוא אינו פועל כבר.

כברירת מחדל hyprsunset אינו עושה למסך שלכם שום דבר בכלל. `~/.config/hypr/hyprsunset.conf` מגיע עם פרופיל זהות בדיוק כדי שהתצוגה תישאר ללא שינוי עד שתבקשו חמימות. אם אתם מעדיפים שהיא תתחלף לפי השעון, החליפו אותו בפרופיל זמן:

```
profile {
    time = 20:00
    temperature = 4000
}
```

לאחר מכן הפעילו את hyprsunset בעת ההתחברות על ידי הוספת `o.launch_on_start("hyprsunset")` ל־`~/.config/hypr/autostart.lua`. צמד ה־4000K/6500K שבו משתמש המתג קבוע, כך שקובץ התצורה הוא המקום לפנות אליו אם תרצו טמפרטורה אחרת.

### נא לא להפריע

`Super + Ctrl + Alt + ,` משתיק התראות. שום הודעות קופצות לא מופיעות כשהוא פעיל, ומחוון הפעמון המחוק יושב בשורה כדי להזכיר לכם למה שולחן העבודה השתתק.

שום דבר לא הולך לאיבוד, עם זאת. התראות מושתקות מוחזקות: החזירו את האחרונות שבהן למסך באמצעות `Super + Shift + Alt + ,`. ראו [התראות](10-notices.md) לשאר.

שני סוגי הודעות עדיין עוברים: הודעות האישור של Omarchy עצמה על משהו שעשיתם הרגע ("ערכת הנושא שונתה", "צילום המסך נשמר"), והתראות קריטיות שנשלחות משורת הפקודה. אפליקציות צ'אט שמסמנות הכול כקריטי כדי לכפות את דרכן לפניכם אינן עומדות בדרישות.

### מצב סרק

מעטפת Omarchy היא הבעלים של התנהגות מצב הסרק, והתזמונים הם בלוק `idle` ברמה העליונה ב־`~/.config/omarchy/shell.json`:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

שני המספרים הם שניות שנספרות מהרגע שבו עברתם למצב סרק — לא זה מזה. כך שעם ערכי ברירת המחדל, שומר המסך עולה אחרי שתי דקות וחצי ומסך הנעילה משתלט בחמש דקות, בין אם שומר המסך פעל ובין אם לא. שמרו את הקובץ והמעטפת קולטת את התזמונים החדשים מיד.

אם תבטלו את שומר המסך לפני מועד הנעילה, זה נחשב פעילות והנעילה הממתינה מבוטלת. לא תינעלו החוצה בגלל שהצצתם במחשב שלכם.

כדי להפסיק לגמרי נעילה במצב סרק, `Super + Ctrl + I` — או `omarchy toggle idle` — מפעיל את מצב ההישארות ערה, ומחוון ספל הקפה מופיע בשורה. זה המתג ללחוץ עליו לפני מצגת ארוכה או בנייה שתרצו לצפות בה. לחצו עליו שוב כדי לחזור למצב רגיל. `omarchy toggle idle status` מדפיס את המצב הנוכחי כ־JSON אם תזדקקו לו מתסריט.

מדובר בנעילה ובשומר המסך, לא בחשמל. להשעיה ולתרדמת יש הגדרה משלהן ב[שינת מערכת](36-system-sleep.md).

### שומר המסך

שומר המסך של Omarchy הוא אמנות ASCII שעוברת אפקטי טקסט אקראיים, מופע אחד לכל צג. כל מקש או תנועת עכבר יוצאים ממנו.

אפשר להפעיל אותו לפי דרישה מ_מערכת > שומר מסך_ (`Super + Esc`), מה שמעלה אותו בכוח גם אם כיביתם את שומר המסך במצב סרק. אין מקש קיצור שמוגדר עבורו כברירת מחדל.

`omarchy toggle screensaver` הוא מה שמכבה את זה של מצב הסרק, אם אתם מעדיפים לעבור היישר מעבודה לנעילה. כל מקש, לחיצה, גלילה או תנועת עכבר סוגרים אותו.

הלוגו שהוא מצייר הוא שלכם לשנות, תחת _מראה > מיתוג > שומר מסך_. העלו png או svg ו־Omarchy תמיר אותו ל־ASCII. ראו [מיתוג](41-branding.md).

### מסך הנעילה

`Super + Ctrl + L` נועל את המחשב. זה מפעיל את מסך הנעילה ממעטפת Omarchy, מחשיך את התצוגה, מאפס את פריסת המקלדת שלכם לראשונה כדי שלא תקלידו את הסיסמה שלכם באלפבית הלא נכון, ו — אם הוא פועל אצלכם — נועל את 1Password בדרך החוצה.

מסך הנעילה מקבל סיסמה, והוא יקבל גם טביעת אצבע ברגע שתגדירו אחת. את זה, ואת הדרכים האחרות לאימות, אפשר למצוא ב[אימות חומרה](37-hardware-authentication.md).
