# מתגים, חוסר פעילות ושומר המסך

הרבה ממה שאתה משנה ביום־יום הוא לא באמת הגדרה. זה מצב שאתה מפעיל לשעה ומכבה שוב: תאורת לילה כשאתה עובד עד מאוחר, נא לא להפריע כשאתה מציג, הישארות ערה כשאתה צופה במשהו. Omarchy קוראת לאלה מתגים, וכולם עובדים באותה צורה — מקש קיצור, ערך בתפריט ופקודה, כולם פוגעים באותו מתג.

### תפריט המתגים

`Super + Ctrl + O` פותח ישירות את _הפעלה > מתג_, או שאפשר להגיע לשם מהתפריט של Omarchy (`Super + Space`). כל מה שברשימה הזו הוא מתג שאפשר להפעיל ולכבות בלי לחשוב איפה המצב נשמר. המתגים לאופן שבו שולחן העבודה נראה נמצאים לידו, תחת _מראה_.

מהטרמינל, אותם מתגים הם `omarchy toggle <thing>`. הרץ את `omarchy toggle` בפני עצמו כדי לראות את כל הקבוצה.

| מתג | מקש קיצור | פקודה |
| ------ | ------ | ------- |
| תאורת לילה | — | `omarchy toggle nightlight` |
| השתקת התראות | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| הישארות ערה (ללא נעילה בחוסר פעילות) | `Super + Ctrl + I` | `omarchy toggle idle` |
| לכידת קריסות | — | `omarchy toggle crash-capture` |
| שומר מסך | — | `omarchy toggle screensaver` |
| סנכרון ערכת הנושא של [Herdr](https://herdr.dev) | — | `omarchy toggle theme sync` |
| סרגל התפריטים | `Super + Shift + Space` | `omarchy toggle bar` |
| שולחן עבודה במסך מלא (ללא סרגל, ללא רווחים) | `Super + Ctrl + Alt + F` | `omarchy toggle fullscreen desktop` |
| אנימציות, טשטוש וצללים | — | `omarchy toggle animations` |
| משטח מגע | `XF86TouchpadToggle` | `omarchy device touchpad` |
| מסך מגע | — | `omarchy device touchscreen` |
| השהיה | — | `omarchy toggle suspend` |
| GPU היברידי | — | `omarchy device gpu hybrid` |

מתגי משטח המגע, מסך המגע וה־GPU ההיברידי נמצאים תחת _הפעלה > חומרה_ (`Super + Ctrl + H`) ולא תחת מתג, כי הם מופיעים רק כשבאמת יש לך את החומרה הזו. מתגי משטח המגע ומסך המגע שורדים טעינה מחדש של Hyprland — שמו של ההתקן המושבת נשמר בקובץ מצב קטן ש־Hyprland קורא בעת ההפעלה כדי להשבית אותו שוב.

_מראה_ מכיל את סרגל התפריטים ואת האנימציות, ועוד כמה דברים שאינם פקודות `omarchy toggle` אבל מתנהגים אותו דבר: אחוזי הסוללה בסרגל, פריסת סביבת העבודה המוגדרת כברירת מחדל, ותחת _חלונות_, רווחי חלונות (`Super + Shift + Backspace`) ויחס הגובה־רוחב הריבועי של חלון אחד (`Super + Ctrl + Backspace`).

כאשר ל־Hyprland אין GPU לצייר איתו והוא מרנדר על ה־CPU במקום זאת (llvmpipe), כמו במחשבי Mac שה־GPU שלהם עדיין לא נתמך, ברוב המכונות הווירטואליות, או כאשר מנהל התקן גרפי נכשל בטעינה, Omarchy מכבה אנימציות, טשטוש וצללים לאותה הפעלה ומודיעה לך על כך פעם אחת בהתראה. _מראה > אנימציות מופעלות_ מחזיר אותם, ו־Omarchy זוכרת זאת גם להפעלות הבאות.

רוב אלה הם פשוט קובץ דגל תחת `~/.local/state/omarchy/toggles/`. אם אתה רוצה להסתעף לפי אחד מהם בסקריפט, `omarchy-toggle-enabled` נותן לך קוד יציאה במקום לאלץ אותך ללכת לחפש:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

הדגלים נקראים על שם מצב הכיבוי — `screensaver-off`, `suspend-off`, `bar-off` — כך שנוכחותם פירושה שהתכונה מושבתת.

### מחוונים בסרגל

כשמצב פעיל, אתה מקבל גליף קטן באמצע הסרגל העליון ליד השעון. זהו ווידג'ט המחוונים, והוא נושא את הקלטת המסך, תזכורות ממתינות, תאורת לילה, נא לא להפריע והישארות ערה, ועוד אזהרות בזמן ש־sudo ללא סיסמה פעיל או מישהו מחובר להפעלה מרוחקת.

מחוונים לא פעילים מוסתרים. רחף בכל מקום על הסרגל והם מופיעים בהדרגה כשהם מעומעמים, כך שתוכל ללחוץ על אחד כדי להפעיל אותו בלי להכיר את מקש הקיצור שלו. לחיצה על אחד פעיל מכבה אותו שוב. אם אתה מעדיף לראות את כולם כל הזמן, הגדר את `alwaysShow` ל־`true` בערך `omarchy.indicators` שב־`~/.config/omarchy/shell.json` — ראה [הסרגל העליון](05-the-top-bar.md) למידע על אופן התצורה של ווידג'טי הסרגל.

### תאורת לילה

תאורת לילה מחממת את המסך ל־4000K, והפעלה חוזרת שלה מחזירה אותו ל־6500K. הפעל אותה מתפריט המתגים (`Super + Ctrl + O`) או באמצעות `omarchy toggle nightlight`. היא מונעת על ידי hyprsunset, שהמתג מפעיל עבורך אם הוא עדיין לא פועל.

כברירת מחדל hyprsunset לא עושה שום דבר למסך שלך. `~/.config/hypr/hyprsunset.conf` מגיע עם פרופיל זהות בדיוק כדי שהתצוגה תישאר ללא שינוי עד שתבקש חמימות. אם אתה מעדיף שהיא תתחלף לפי השעון, החלף זאת בפרופיל זמן:

```
profile {
    time = 20:00
    temperature = 4000
}
```

לאחר מכן הפעל את hyprsunset בעת הכניסה על ידי הוספת `o.launch_on_start("hyprsunset")` ל־`~/.config/hypr/autostart.lua`. צמד ה־4000K/6500K שמשמש את המתג קבוע, כך שקובץ התצורה הוא המקום אליו הולכים אם רוצים טמפרטורה אחרת.

### נא לא להפריע

`Super + Ctrl + Alt + ,` משתיק התראות. שום הודעות קופצות לא מופיעות כשהוא פעיל, ומחוון הפעמון המחוק יושב בסרגל כדי להזכיר לך למה שולחן העבודה נעשה שקט.

שום דבר לא הולך לאיבוד, עם זאת. התראות מושתקות מוחזקות: החזר את האחרונות שבהן למסך באמצעות `Super + Shift + Alt + ,`. ראה [הודעות](10-notices.md) לשאר.

שלושה סוגי הודעות עדיין עוברים: הודעות האישור של Omarchy עצמה על משהו שזה עתה עשית ("Theme changed", "Screenshot saved"), התראות קריטיות שנשלחות משורת הפקודה, וקודי אימות. אפליקציות צ'אט שמסמנות הכול כקריטי כדי לכפות את דרכן לפניך לא נחשבות.

### חוסר פעילות

המעטפת של Omarchy היא הבעלים של התנהגות חוסר הפעילות, והתזמונים הם גוש `idle` ברמה העליונה ב־`~/.config/omarchy/shell.json`:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

שני המספרים הם שניות שנספרות מהרגע שבו הפכת ללא פעיל — לא זה מזה. כך שעם ערכי ברירת המחדל, שומר המסך מופיע אחרי שתיים וחצי דקות ומסך הנעילה משתלט בחמש דקות, בין אם שומר המסך פעל ובין אם לא. שמור את הקובץ והמעטפת קולטת את התזמונים החדשים מיד.

אם תסלק את שומר המסך לפני מועד הנעילה, זה נחשב לפעילות והנעילה הממתינה מבוטלת. אתה לא ננעל החוצה רק כי הצצת במחשב שלך.

כדי להפסיק לגמרי נעילה בחוסר פעילות, `Super + Ctrl + I` — או `omarchy toggle idle` — מפעיל את מצב ההישארות הערה, ומחוון ספל הקפה מופיע בסרגל. זה המתג ללחוץ עליו לפני מצגת ארוכה או בנייה שאתה רוצה לצפות בה. לחץ עליו שוב כדי לחזור לשגרה. `omarchy toggle idle status` מדפיס את המצב הנוכחי כ־JSON אם אתה צריך אותו מסקריפט.

מדובר בנעילה ובשומר המסך, לא בחשמל. להשעיה ולתרדמת יש הגדרה משלהן ב־[שנת מערכת](36-system-sleep.md).

### שומר המסך

שומר המסך של Omarchy הוא אמנות ASCII שעוברת דרך אפקטי טקסט אקראיים, מופע אחד לכל צג. כל מקש או תנועת עכבר יוצאים ממנו.

אפשר להפעיל אותו לפי דרישה מתוך _מערכת > שומר מסך_ (`Super + Esc`), מה שמאלץ אותו לעלות גם אם כיבית את שומר המסך בחוסר פעילות. אין מקש קיצור המשויך אליו כברירת מחדל.

`omarchy toggle screensaver` הוא מה שמכבה את זה של חוסר הפעילות, אם אתה מעדיף לעבור ישר מעבודה לנעילה. כל מקש, לחיצה, גלילה או תנועת עכבר סוגרים אותו.

הלוגו שהוא מצייר הוא שלך לשנות, תחת _מראה > מיתוג > שומר מסך_. העלה png או svg ו־Omarchy תמיר אותו ל־ASCII. ראה [מיתוג](41-branding.md).

### מסך הנעילה

`Super + Ctrl + L` נועל את המחשב. זה מריץ את מסך הנעילה ממעטפת Omarchy, מחשיך את התצוגה, מאפס את פריסת המקלדת שלך לראשונה כך שלא תקליד את הסיסמה שלך באלפבית הלא נכון, ו־— אם הוא פועל אצלך — נועל את 1Password בדרך החוצה.

מסך הנעילה מקבל סיסמה, והוא יקבל גם טביעת אצבע ברגע שתגדיר אחת. זאת, ואת הדרכים האחרות לאימות, מכסה [אימות חומרה](37-hardware-authentication.md).
