# מתגים, חוסר פעילות ושומר המסך

הרבה ממה שמשנים ביום־יום הוא לא באמת הגדרה. זה מצב שמפעילים לשעה ואז מכבים שוב: תאורת לילה כשעובדים עד מאוחר, נא לא להפריע כשמציגים, הישארות ער כשצופים במשהו. Omarchy קוראת לאלה מתגים, וכולם עובדים באותה הדרך — מקש חם, פריט בתפריט ופקודה, כולם פוגעים באותו מתג.

### תפריט המתגים

`Super + Ctrl + O` פותח את _Trigger > Toggle_ ישירות, או שאפשר להגיע לשם מתפריט Omarchy (`Super + Space`). כל מה שברשימה הזאת הוא מתג שאפשר להפעיל ולכבות בלי לחשוב איפה המצב נשמר. המתגים לאופן שבו שולחן העבודה נראה נמצאים לידו, תחת _Appearance_.

מהטרמינל, אותם מתגים הם `omarchy toggle <thing>`. הריצו `omarchy toggle` לבדו כדי לראות את כל הקבוצה.

| מתג | מקש חם | פקודה |
| ------ | ------ | ------- |
| תאורת לילה | — | `omarchy toggle nightlight` |
| השתקת התראות | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| הישארות ער (ללא נעילה בחוסר פעילות) | `Super + Ctrl + I` | `omarchy toggle idle` |
| לכידת קריסות | — | `omarchy toggle crash-capture` |
| שומר מסך | — | `omarchy toggle screensaver` |
| סנכרון ערכת נושא של [Herdr](https://herdr.dev) | — | `omarchy toggle theme sync` |
| הסרגל | `Super + Shift + Space` | `omarchy toggle bar` |
| משטח מגע | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| מסך מגע | — | `omarchy toggle touchscreen` |
| השהיה | — | `omarchy toggle suspend` |
| GPU היברידי | — | `omarchy toggle hybrid gpu` |

המתגים של משטח המגע, מסך המגע וה־GPU ההיברידי נמצאים תחת _Trigger > Hardware_ (`Super + Ctrl + H`) ולא תחת Toggle, מכיוון שהם מופיעים רק כשיש לכם באמת את החומרה הזאת. המתגים של משטח המגע ומסך המגע שורדים טעינה מחדש של Hyprland — השם של ההתקן המושבת נשמר בקובץ מצב קטן ש־Hyprland קורא בעת ההפעלה כדי להשבית אותו שוב.

_Appearance_ מחזיק את הסרגל ואת האנימציות, ועוד כמה דברים שאינם פקודות `omarchy toggle` אבל מתנהגים אותו הדבר: אחוזי הסוללה בסרגל, פריסת סביבת העבודה המוגדרת כברירת מחדל, ותחת _Windows_, מרווחי החלונות (`Super + Shift + Backspace`) והיחס הריבועי של חלון אחד (`Super + Ctrl + Backspace`).

רוב אלה הם פשוט קובץ דגל תחת `~/.local/state/omarchy/toggles/`. אם רוצים להסתעף על אחד מהם בסקריפט, `omarchy-toggle-enabled` נותן לכם קוד יציאה במקום לשלוח אתכם לחפש:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

שמות הדגלים הם למצב הכבוי — `screensaver-off`, `suspend-off`, `bar-off` — כך שהנוכחות שלהם פירושה שהתכונה מושבתת.

### מחוונים בסרגל

כשמצב פעיל, תקבלו גליף קטן באמצע הסרגל העליון ליד השעון. זהו וידג'ט המחוונים, והוא נושא הכתבה, הקלטת מסך, תזכורות ממתינות, תאורת לילה, נא לא להפריע והישארות ער.

מחוונים לא פעילים מוסתרים. רחפו עם העכבר בכל מקום על הסרגל והם יופיעו בהדרגה מעומעמים, כך שתוכלו ללחוץ על אחד כדי להפעיל אותו בלי לדעת את המקש החם שלו. לחיצה על מחוון פעיל מכבה אותו בחזרה. אם אתם מעדיפים לראות את כולם כל הזמן, הגדירו `alwaysShow` ל־`true` בערך `omarchy.indicators` שב־`~/.config/omarchy/shell.json` — ראו [הסרגל העליון](05-the-top-bar.md) להסבר על אופן ההגדרה של וידג'טים בסרגל.

### תאורת לילה

תאורת לילה מחממת את המסך ל־4000K, והפעלה נוספת של המתג מחזירה אותו ל־6500K. הפעילו אותו מתפריט המתגים (`Super + Ctrl + O`) או עם `omarchy toggle nightlight`. הוא מונע על ידי hyprsunset, שהמתג מפעיל עבורכם אם הוא אינו פועל כבר.

כברירת מחדל hyprsunset לא עושה למסך שלכם כלום. `~/.config/hypr/hyprsunset.conf` מגיע עם פרופיל זהות בדיוק כדי שהתצוגה תישאר ללא שינוי עד שתבקשו חום. אם אתם מעדיפים שהוא יתחלף לפי השעון, החליפו אותו בפרופיל זמן:

```
profile {
    time = 20:00
    temperature = 4000
}
```

לאחר מכן הפעילו את hyprsunset בעת ההתחברות על ידי הוספת `o.launch_on_start("hyprsunset")` ל־`~/.config/hypr/autostart.lua`. צמד ה־4000K/6500K שבו המתג משתמש הוא קבוע, כך שקובץ ההגדרות הוא המקום ללכת אליו אם רוצים טמפרטורה אחרת.

### נא לא להפריע

`Super + Ctrl + Alt + ,` משתיק התראות. שום הודעות קופצות לא מופיעות כשהוא פעיל, ומחוון הפעמון המחוק יושב בסרגל כדי להזכיר לכם למה שולחן העבודה השתתק.

שום דבר לא הולך לאיבוד, עם זאת. התראות מושתקות מוחזקות: החזירו את האחרונות שבהן למסך עם `Super + Shift + Alt + ,`. ראו [הודעות](10-notices.md) לשאר.

שני סוגי הודעות עדיין עוברים: הודעות האישור של Omarchy עצמה על משהו שזה עתה עשיתם ("Theme changed", "Screenshot saved"), והתראות קריטיות שנשלחות משורת הפקודה. אפליקציות צ'אט שמסמנות הכול כקריטי כדי לדחוף את עצמן בכוח לפניכם לא עומדות בדרישות.

### חוסר פעילות

מעטפת Omarchy היא הבעלים של התנהגות חוסר הפעילות, והתזמונים הם בלוק `idle` ברמה העליונה ב־`~/.config/omarchy/shell.json`:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

שני המספרים הם שניות שנספרות מהרגע שבו הפכתם ללא פעילים — לא זה מזה. כך, עם ברירות המחדל, שומר המסך עולה אחרי שתי דקות וחצי ומסך הנעילה משתלט בחמש דקות, בין אם שומר המסך פעל ובין אם לא. שמרו את הקובץ והמעטפת תקלוט את התזמונים החדשים מיד.

אם תבטלו את שומר המסך לפני מועד הנעילה, זה נחשב פעילות והנעילה הממתינה מבוטלת. לא תינעלו בחוץ בגלל שהצצתם במכונה שלכם.

כדי להפסיק לגמרי את הנעילה בחוסר פעילות, `Super + Ctrl + I` — או `omarchy toggle idle` — מפעיל את מצב הישארות ער, ומחוון ספל הקפה מופיע בסרגל. זה המתג ללחוץ עליו לפני מצגת ארוכה או בנייה שאתם רוצים לצפות בה. לחצו עליו שוב כדי לחזור למצב רגיל. `omarchy toggle idle status` מדפיס את המצב הנוכחי כ־JSON אם אתם צריכים אותו מסקריפט.

זה נוגע לנעילה ולשומר המסך, לא לחשמל. להשהיה ולתרדמת יש הגדרה משלהן ב[שנת המערכת](36-system-sleep.md).

### שומר המסך

שומר המסך של Omarchy הוא אמנות ASCII שרצה דרך אפקטי טקסט אקראיים, מופע אחד לכל צג. כל מקש או תנועת עכבר יוצאים ממנו.

אפשר להפעיל אותו לפי דרישה מ־_System > Screensaver_ (`Super + Esc`), מה שמאלץ אותו לעלות גם אם כיביתם את שומר המסך של חוסר הפעילות. אין לו מקש חם כבול כברירת מחדל.

`omarchy toggle screensaver` הוא מה שמכבה את זה של חוסר הפעילות, אם אתם מעדיפים לעבור היישר מעבודה לנעילה. הוא צריך טרמינל שהוא יודע להגדיר — Alacritty, Foot, Ghostty או Kitty — ויגיד לכם זאת אם הטרמינל המוגדר כברירת מחדל שלכם הוא משהו אחר.

הלוגו שהוא מצייר הוא שלכם לשנות, תחת _Appearance > Branding > Screensaver_. העלו png או svg ו־Omarchy תמיר אותו ל־ASCII. ראו [מיתוג](41-branding.md).

### מסך הנעילה

`Super + Ctrl + L` נועל את המכונה. זה מריץ את מסך הנעילה ממעטפת Omarchy, מחשיך את התצוגה, מאפס את פריסת המקלדת שלכם לראשונה כדי שלא תקלידו את הסיסמה שלכם באלפבית הלא נכון, ו—אם הוא פועל אצלכם—נועל את 1Password בדרך החוצה.

מסך הנעילה מקבל סיסמה, והוא יקבל גם טביעת אצבע ברגע שתגדירו אחת. את זה, ואת הדרכים האחרות לאמת, מכסים ב[אימות חומרה](37-hardware-authentication.md).
