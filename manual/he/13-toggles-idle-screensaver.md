# מתגים, חוסר פעילות ושומר המסך

הרבה ממה שמשנים ביום־יום הוא לא באמת הגדרה. זה מצב שמפעילים לשעה ואז מכבים שוב: תאורת לילה כשעובדים עד מאוחר, נא לא להפריע כשמציגים, הישארות ערה כשצופים במשהו. Omarchy קוראת לאלה מתגים, וכולם פועלים באותה דרך — מקש קיצור, ערך בתפריט ופקודה, כולם פוגעים באותו מתג.

### תפריט המתגים

`Super + Ctrl + O` פותח ישירות את _Trigger > Toggle_, או שאפשר להגיע לשם מתפריט Omarchy‏ (`Super + Space`). כל מה שברשימה הזו הוא מתג שאפשר להפעיל בלי לחשוב איפה המצב נשמר. מתגים למראה שולחן העבודה נמצאים לידו, תחת _Appearance_.

מהטרמינל, אותם מתגים הם `omarchy toggle <thing>`. הריצו `omarchy toggle` בפני עצמו כדי לראות את הקבוצה כולה.

| מתג | מקש קיצור | פקודה |
| ------ | ------ | ------- |
| תאורת לילה | — | `omarchy toggle nightlight` |
| השתקת התראות | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| הישארות ערה (ללא נעילת חוסר פעילות) | `Super + Ctrl + I` | `omarchy toggle idle` |
| לכידת קריסות | — | `omarchy toggle crash-capture` |
| שומר מסך | — | `omarchy toggle screensaver` |
| סנכרון ערכת נושא של [Herdr](https://herdr.dev) | — | `omarchy toggle theme sync` |
| סרגל תפריט | `Super + Shift + Space` | `omarchy toggle bar` |
| משטח מגע | `XF86TouchpadToggle` | `omarchy device touchpad` |
| מסך מגע | — | `omarchy device touchscreen` |
| השהיה | — | `omarchy toggle suspend` |
| GPU היברידי | — | `omarchy toggle hybrid gpu` |

מתגי משטח המגע, מסך המגע וה־GPU ההיברידי נמצאים תחת _Trigger > Hardware_‏ (`Super + Ctrl + H`) ולא תחת Toggle, מכיוון שהם מופיעים רק כשיש לכם באמת את החומרה הזו. מתגי משטח המגע ומסך המגע שורדים טעינה מחדש של Hyprland — שמו של ההתקן המושבת נשמר בקובץ מצב קטן ש־Hyprland קורא בעת ההפעלה כדי להשבית אותו שוב.

_Appearance_ מכיל את סרגל התפריט והאנימציות, ועוד כמה דברים שאינם פקודות `omarchy toggle` אבל מתנהגים אותו דבר: אחוז סוללה בסרגל, פריסת סביבת העבודה המוגדרת כברירת מחדל, ותחת _Windows_, מרווחי חלונות (`Super + Shift + Backspace`) והיחס הריבועי של חלון אחד (`Super + Ctrl + Backspace`).

כשאין ל־Hyprland ‏GPU לצייר איתו והוא מרנדר על המעבד במקום זאת (llvmpipe), כמו ב־Mac שה־GPU שלהם אינו נתמך עדיין, ברוב המכונות הווירטואליות, או כשמנהל התקן גרפי נכשל בטעינה, Omarchy מכבה אנימציות, טשטוש וצללים לאותה הפעלה ומודיעה לכם על כך פעם אחת בהתראה. ‏_Appearance > Animations On_ מחזיר אותם, ו־Omarchy זוכרת זאת גם להפעלות הבאות.

רוב אלה הם רק קובץ דגל תחת `~/.local/state/omarchy/toggles/`. אם תרצו להתפצל על פיו בסקריפט, `omarchy-toggle-enabled` נותן לכם קוד יציאה במקום לשלוח אתכם לחפש:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

הדגלים נקראים על שם מצב הכיבוי — `screensaver-off`, `suspend-off`, `bar-off` — כך שנוכחותם פירושה שהתכונה מושבתת.

### מחוונים בסרגל

כשמצב פעיל, מופיע גליף קטן באמצע הסרגל העליון לצד השעון. זהו וידג'ט המחוונים, והוא נושא את הכתבה, הקלטת מסך, תזכורות ממתינות, תאורת לילה, נא לא להפריע והישארות ערה.

מחוונים לא פעילים מוסתרים. רחפו עם העכבר בכל מקום על הסרגל והם יופיעו בדהוי, כך שתוכלו ללחוץ על אחד כדי להפעיל אותו בלי לדעת את מקש הקיצור שלו. לחיצה על מחוון פעיל מכבה אותו שוב. אם אתם מעדיפים לראות את כולם כל הזמן, הגדירו `alwaysShow` ל־`true` בערך `omarchy.indicators` שב־`~/.config/omarchy/shell.json` — ראו [הסרגל העליון](05-the-top-bar.md) להסבר על אופן הגדרת וידג'טים בסרגל.

### תאורת לילה

תאורת לילה מחממת את המסך ל־4000K, והפעלה חוזרת שלה מחזירה אותו ל־6500K. הפעילו אותה מתפריט המתגים (`Super + Ctrl + O`) או עם `omarchy toggle nightlight`. היא מונעת על ידי hyprsunset, שהמתג מפעיל עבורכם אם הוא אינו פועל כבר.

כברירת מחדל hyprsunset אינו עושה למסך שלכם שום דבר בכלל. ‏`~/.config/hypr/hyprsunset.conf` מגיע עם פרופיל זהות בדיוק כדי שהתצוגה תישאר ללא שינוי עד שתבקשו חום. אם אתם מעדיפים שהיא תתחלף לפי השעון, החליפו זאת בפרופיל זמן:

```
profile {
    time = 20:00
    temperature = 4000
}
```

לאחר מכן הפעילו את hyprsunset בעת ההתחברות על ידי הוספת `o.launch_on_start("hyprsunset")` ל־`~/.config/hypr/autostart.lua`. צמד ה־4000K/6500K שבו משתמש המתג קבוע, כך שקובץ התצורה הוא המקום לפנות אליו אם תרצו טמפרטורה אחרת.

### נא לא להפריע

`Super + Ctrl + Alt + ,` משתיק התראות. שום חלונית קופצת לא מופיעה כשהוא פעיל, ומחוון הפעמון המחוק יושב בסרגל כדי להזכיר לכם למה שולחן העבודה השתתק.

שום דבר לא הולך לאיבוד, עם זאת. התראות מושתקות מוחזקות: החזירו את האחרונות שבהן למסך עם `Super + Shift + Alt + ,`. ראו [הודעות](10-notices.md) לשאר.

שני סוגי הודעות עדיין עוברים: חלוניות האישור של Omarchy עצמה על משהו שזה עתה עשיתם ("Theme changed", "Screenshot saved"), והתראות קריטיות שנשלחות משורת הפקודה. אפליקציות צ'אט שמסמנות הכול כקריטי כדי לכפות את דרכן אליכם אינן זכאיות לכך.

### חוסר פעילות

מעטפת Omarchy היא הבעלים של התנהגות חוסר הפעילות, והתזמונים הם בלוק `idle` ברמה העליונה ב־`~/.config/omarchy/shell.json`:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

שני המספרים הם שניות שנספרות מהרגע שבו הפכתם ללא פעילים — לא זה מזה. כך, עם ברירות המחדל, שומר המסך עולה אחרי שתיים וחצי דקות ומסך הנעילה משתלט בחמש דקות, בין אם שומר המסך רץ ובין אם לא. שמרו את הקובץ והמעטפת תקלוט את התזמונים החדשים מיד.

אם תסגרו את שומר המסך לפני מועד הנעילה, זה נחשב פעילות והנעילה הממתינה מתבטלת. לא תינעלו בחוץ רק כי הצצתם במכונה שלכם.

כדי להפסיק לגמרי נעילה בחוסר פעילות, `Super + Ctrl + I` — או `omarchy toggle idle` — מפעיל הישארות ערה, ומחוון ספל הקפה מופיע בסרגל. זהו המתג ללחוץ עליו לפני מצגת ארוכה או בנייה שתרצו לצפות בה. לחצו עליו שוב כדי לחזור לנורמלי. ‏`omarchy toggle idle status` מדפיס את המצב הנוכחי כ־JSON אם תזדקקו לו מסקריפט.

מדובר כאן בנעילה ובשומר המסך, לא בחשמל. להשׁהיה ולתרדמת יש הגדרה משלהן ב־[שנת מערכת](36-system-sleep.md).

### שומר המסך

שומר המסך של Omarchy הוא אמנות ASCII שרצה דרך אפקטי טקסט אקראיים, מופע אחד לכל צג. כל מקש או תנועת עכבר יוצאים ממנו.

אפשר להפעיל אותו לפי דרישה מתוך _System > Screensaver_‏ (`Super + Esc`), מה שמכריח אותו לעלות גם אם כיביתם את שומר המסך של חוסר הפעילות. אין לו מקש קיצור קשור כברירת מחדל.

`omarchy toggle screensaver` הוא מה שמכבה את זה של חוסר הפעילות, אם אתם מעדיפים לעבור ישירות מעבודה לנעילה. כל מקש, לחיצה, גלילה או תנועת עכבר סוגרים אותו.

הלוגו שהוא מצייר ניתן לשינוי על ידיכם, תחת _Appearance > Branding > Screensaver_. העלו png או svg ו־Omarchy תמיר אותו ל־ASCII. ראו [מיתוג](41-branding.md).

### מסך הנעילה

`Super + Ctrl + L` נועל את המכונה. זה מריץ את מסך הנעילה ממעטפת Omarchy, מחשיך את התצוגה, מאפס את פריסת המקלדת שלכם לראשונה כך שלא תקלידו את הסיסמה שלכם באלפבית הלא נכון, ו — אם הוא פועל אצלכם — נועל את 1Password בדרך החוצה.

מסך הנעילה מקבל סיסמה, והוא יקבל גם טביעת אצבע לאחר שתגדירו אחת. זאת, ואת הדרכים האחרות לאימות, מכסים ב־[אימות חומרה](37-hardware-authentication.md).
