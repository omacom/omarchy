# מתגים, סרק ושומר המסך

הרבה ממה שאתה משנה ביום־יום הוא לא באמת הגדרה. זה מצב שאתה מדליק לשעה ואז מכבה שוב: תאורת לילה כשאתה עובד עד מאוחר, נא לא להפריע כשאתה מציג, להישאר ער כשאתה צופה במשהו. Omarchy קוראת לאלה מתגים, וכולם עובדים באותה צורה — מקש חם, ערך בתפריט ופקודה, כולם מכוונים לאותו מתג.

### תפריט המתגים

`Super + Ctrl + O` פותח ישירות את _הפעלה > מתג_, או שאפשר להגיע לשם דרך תפריט Omarchy‏ (`Super + Space`). כל מה שברשימה הזו הוא מתג שאפשר להפעיל ולכבות בלי לחשוב איפה המצב נשמר. מתגים למראה של שולחן העבודה נמצאים לידו, תחת _מראה_.

מהמסוף, אותם מתגים הם `omarchy toggle <thing>`. הרץ את `omarchy toggle` בפני עצמו כדי לראות את הקבוצה כולה.

| מתג | מקש חם | פקודה |
| ------ | ------ | ------- |
| תאורת לילה | — | `omarchy toggle nightlight` |
| השתקת התראות | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| להישאר ער (ללא נעילת סרק) | `Super + Ctrl + I` | `omarchy toggle idle` |
| לכידת קריסות | — | `omarchy toggle crash-capture` |
| שומר מסך | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) סנכרון ערכת נושא | — | `omarchy toggle theme sync` |
| שורת התפריט | `Super + Shift + Space` | `omarchy toggle bar` |
| משטח מגע | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| מסך מגע | — | `omarchy toggle touchscreen` |
| השהיה | — | `omarchy toggle suspend` |
| GPU היברידי | — | `omarchy toggle hybrid gpu` |

המתגים של משטח המגע, מסך המגע וה־GPU ההיברידי נמצאים תחת _הפעלה > חומרה_ (`Super + Ctrl + H`) ולא תחת מתג, כי הם מופיעים רק כשיש לך בפועל את החומרה הזו. המתגים של משטח המגע ומסך המגע שורדים טעינה מחדש של Hyprland — שמו של ההתקן המושבת נשמר בקובץ מצב קטן ש־Hyprland קורא בהפעלה כדי להשבית אותו שוב.

_מראה_ מכיל את שורת התפריט ואת ההנפשות, ועוד כמה דברים שאינם פקודות `omarchy toggle` אבל מתנהגים באותה צורה: אחוז הסוללה בשורה, פריסת ברירת המחדל של סביבת העבודה, ותחת _חלונות_, מרווחי החלונות (`Super + Shift + Backspace`) ויחס הממדים הריבועי לחלון יחיד (`Super + Ctrl + Backspace`).

כשאין ל־Hyprland‏ GPU לצייר איתו והוא מרנדר על המעבד במקום זאת (llvmpipe), כמו במחשבי Mac שה־GPU שלהם עדיין לא נתמך, ברוב המכונות הווירטואליות, או כשמנהל התקן גרפי נכשל בטעינה, Omarchy מכבה את ההנפשות, הטשטוש והצללים לאותה הפעלה ומודיעה לך על כך פעם אחת בהתראה. _מראה > הפעלת הנפשות_ מחזיר אותם, ו־Omarchy זוכרת את זה גם להפעלות הבאות.

רוב אלה הם רק קובץ דגל תחת `~/.local/state/omarchy/toggles/`. אם אתה רוצה להסתעף לפי אחד מהם בסקריפט, `omarchy-toggle-enabled` נותן לך קוד יציאה במקום להכריח אותך לחפש:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

הדגלים נקראים על שם המצב הכבוי — `screensaver-off`, `suspend-off`, `bar-off` — כך שהנוכחות שלהם פירושה שהתכונה מושבתת.

### מחוונים בשורה

כשמצב כלשהו פעיל, אתה מקבל גליף קטן באמצע השורה העליונה ליד השעון. זהו רכיב המחוונים, והוא נושא הכתבה, הקלטת מסך, תזכורות ממתינות, תאורת לילה, נא לא להפריע והישארות ערה.

מחוונים לא פעילים מוסתרים. עבור עם הסמן מעל כל מקום בשורה והם יופיעו כשהם מעומעמים, כך שתוכל ללחוץ על אחד כדי להפעיל אותו בלי לדעת את מקש החם שלו. לחיצה על מחוון פעיל מכבה אותו שוב. אם אתה מעדיף לראות את כולם כל הזמן, הגדר את `alwaysShow` ל־`true` בערך `omarchy.indicators` שב־`~/.config/omarchy/shell.json` — ראה את [השורה העליונה](05-the-top-bar.md) להסבר על אופן התצורה של רכיבי השורה.

### תאורת לילה

תאורת לילה מחממת את המסך ל־4000K, והפעלה מחדש של המתג מחזירה אותו ל־6500K. הפעל אותה מתפריט המתגים (`Super + Ctrl + O`) או באמצעות `omarchy toggle nightlight`. היא מונעת על ידי hyprsunset, שהמתג מפעיל עבורך אם הוא עדיין לא פועל.

כברירת מחדל hyprsunset לא עושה למסך שלך כלום. `~/.config/hypr/hyprsunset.conf` מגיע עם פרופיל זהות בדיוק כדי שהתצוגה תישאר ללא שינוי עד שתבקש חמימות. אם אתה מעדיף שהוא יתחלף לפי השעון, החלף אותו בפרופיל זמן:

```
profile {
    time = 20:00
    temperature = 4000
}
```

לאחר מכן הפעל את hyprsunset בכניסה על ידי הוספת `o.launch_on_start("hyprsunset")` ל־`~/.config/hypr/autostart.lua`. צמד ה־4000K/6500K שבו משתמש המתג קבוע, כך שקובץ התצורה הוא המקום שאליו הולכים אם רוצים טמפרטורה אחרת.

### נא לא להפריע

`Super + Ctrl + Alt + ,` משתיק התראות. שום הודעות קופצות לא מופיעות כשהוא פעיל, ומחוון הפעמון המחוק יושב בשורה כדי להזכיר לך למה שולחן העבודה השתתק.

שום דבר לא הולך לאיבוד, עם זאת. התראות מושתקות מוחזקות בצד: החזר את האחרונות שבהן למסך באמצעות `Super + Shift + Alt + ,`. ראה את [ההודעות](10-notices.md) לשאר הפרטים.

שני סוגי הודעות עדיין עוברים: הודעות האישור הקופצות של Omarchy עצמה על משהו שזה עתה עשית ("ערכת הנושא השתנתה", "צילום המסך נשמר"), והתראות קריטיות שנשלחות משורת הפקודה. אפליקציות צ'אט שמסמנות הכול כקריטי כדי לכפות את דרכן לפניך לא נחשבות.

### מצב סרק

המעטפת של Omarchy אחראית על התנהגות הסרק, והתזמונים הם בלוק `idle` ברמה העליונה ב־`~/.config/omarchy/shell.json`:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

שני המספרים הם שניות שנספרות מהרגע שנכנסת למצב סרק — לא זה מזה. כך, עם ברירות המחדל, שומר המסך עולה אחרי שתי דקות וחצי ומסך הנעילה משתלט בחמש דקות, בין אם שומר המסך פעל ובין אם לא. שמור את הקובץ והמעטפת תקלוט את התזמונים החדשים מיד.

אם תסגור את שומר המסך לפני מועד הנעילה, זה נחשב לפעילות והנעילה הממתינה מבוטלת. לא תינעל בחוץ רק כי הצצת במכונה שלך.

כדי להפסיק לגמרי את הנעילה במצב סרק, `Super + Ctrl + I` — או `omarchy toggle idle` — מפעיל את מצב ההישארות הערה, ומחוון ספל הקפה מופיע בשורה. זה המתג שלוחצים עליו לפני מצגת ארוכה או בנייה שאתה רוצה לצפות בה. לחץ עליו שוב כדי לחזור למצב הרגיל. `omarchy toggle idle status` מדפיס את המצב הנוכחי כ־JSON אם אתה צריך אותו מסקריפט.

מדובר כאן בנעילה ובשומר המסך, לא בצריכת חשמל. להשעיה ולתרדמת יש הגדרה משלהן ב־[שינת המערכת](36-system-sleep.md).

### שומר המסך

שומר המסך של Omarchy הוא אמנות ASCII שרצה דרך אפקטים אקראיים של טקסט, מופע אחד לכל צג. כל מקש או תנועת עכבר יוצאים ממנו.

אפשר להפעיל אותו לפי דרישה מתוך _מערכת > שומר מסך_ (`Super + Esc`), מה שכופה עליו לעלות גם אם כיבית את שומר המסך במצב סרק. כברירת מחדל לא קשור אליו שום מקש חם.

`omarchy toggle screensaver` הוא מה שמכבה את זה של מצב הסרק, אם אתה מעדיף לעבור ישר מעבודה לנעילה. כל מקש, לחיצה, גלילה או תנועת עכבר סוגרים אותו.

הלוגו שהוא מצייר נתון לשינוי שלך, תחת _מראה > מיתוג > שומר מסך_. העלה png או svg ו־Omarchy תמיר אותו ל־ASCII. ראה את [המיתוג](41-branding.md).

### מסך הנעילה

`Super + Ctrl + L` נועל את המכונה. זה מפעיל את מסך הנעילה מהמעטפת של Omarchy, מחשיך את התצוגה, מאפס את פריסת המקלדת לראשונה כדי שלא תקליד את הסיסמה באלפבית הלא נכון, ו — אם הוא פועל אצלך — נועל את 1Password בדרך החוצה.

מסך הנעילה מקבל סיסמה, והוא יקבל גם טביעת אצבע ברגע שתגדיר אחת. את זה, ואת דרכי האימות האחרות, מכסה [אימות החומרה](37-hardware-authentication.md).
