# החלפות, סרק ושומר המסך

הרבה ממה שמשנים מיום ליום לא באמת הגדרה. זה מצב שמפעילים לשעה ומכבים שוב: אור לילה בזמן שעובדים מאוחר, נא לא להפריע בזמן שמציגים, הישאר ער בזמן שצופים במשהו. Omarchy קוראת לאלה החלפות, וכולם עובדים באותה דרך — קיצור מקלדת, ערך תפריט ופקודה, כולם פוגעים באותו מתג.

### תפריט ההחלפה

`Super + Ctrl + O` פותח את _הפעלה > החלפה_ ישירות, או שאפשר ללכת לשם מתפריט Omarchy (`Super + Space`). כל דבר ברשימה הזו הוא מתג שאפשר להחליף בלי לחשוב היכן חי המצב. מתגים לאיך שולחן העבודה נראה יושבים לידו, תחת _הפעלה > מראה_.

מהטרמינל, אותם מתגים הם `omarchy toggle <thing>`. הריצו את `omarchy toggle` לבדו כדי לראות את הקבוצה כולה.

| החלפה | קיצור מקלדת | פקודה |
| ------ | ------ | ------- |
| אור לילה | `Super + Ctrl + N` | `omarchy toggle nightlight` |
| השתקת התראות | `Super + Ctrl + ,` | `omarchy toggle notification silencing` |
| הישאר ער (בלי נעילת סרק) | `Super + Ctrl + I` | `omarchy toggle idle` |
| לכידת קריסות | — | `omarchy toggle crash-capture` |
| שומר מסך | — | `omarchy toggle screensaver` |
| סנכרון ערכת נושא של [Herdr](https://herdr.dev) | — | `omarchy toggle theme sync` |
| שורת תפריט | `Super + Shift + Space` | `omarchy toggle bar` |
| משטח מגע | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| מסך מגע | — | `omarchy toggle touchscreen` |
| השהיה | — | `omarchy toggle suspend` |
| Hybrid GPU | — | `omarchy toggle hybrid gpu` |

מתגי משטח המגע, מסך המגע וה-Hybrid GPU חיים תחת _הפעלה > חומרה_ (`Super + Ctrl + H`) ולא תחת החלפה, מאחר שהם מופיעים רק כאשר באמת יש לכם את החומרה הזו. אלה של משטח המגע ומסך המגע שורדים טעינה מחדש של Hyprland — שם ההתקן המושבת נשמר לקובץ מצב קטן ש-Hyprland קורא בעת ההפעלה כדי להשבית אותו שוב.

האפשרות _הפעלה > מראה_ מחזיקה את שורת התפריט ואת ההנפשות, ועוד כמה דברים שאינם פקודות `omarchy toggle` אבל מתנהגים באותה דרך: אחוז סוללה בשורה, פריסת סביבת העבודה המוגדרת כברירת מחדל, מרווחי חלונות (`Super + Shift + Backspace`), והיבט הריבוע של חלון אחד (`Super + Ctrl + Backspace`).

רוב אלה הם פשוט קובץ דגל תחת `~/.local/state/omarchy/toggles/`. אם תרצו להסתעף על אחד בסקריפט, `omarchy-toggle-enabled` נותן לכם קוד יציאה במקום לאלץ אתכם לחפש:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

הדגלים נקראים לפי מצב הכיבוי — `screensaver-off`, `suspend-off`, `bar-off` — כך שנוכחותם פירושה שהתכונה מושבתת.

### מחוונים בשורה

כאשר מצב דלוק, מקבלים גליף קטן באמצע שורת התפריט ליד השעון. זהו רכיב המחוונים, והוא נושא הכתבה, הקלטת מסך, תזכורות ממתינות, אור לילה, נא לא להפריע והישאר ער.

מחוונים לא פעילים מוסתרים. עברו עם העכבר על האזור סביבם והם דועכים מעומעמים, כך שאפשר ללחוץ על אחד כדי להדליק אותו בלי לדעת את קיצור המקלדת שלו. לחיצה על פעיל מכבה אותו בחזרה. אם תעדיפו לראות את כולם כל הזמן, הגדירו את `alwaysShow` ל-`true` על הערך `omarchy.indicators` ב-`~/.config/omarchy/shell.json` — ראו [שורת התפריט](05-the-top-bar.md) לאיך רכיבי שורה מוגדרים.

### אור לילה

`Super + Ctrl + N` מחמם את המסך ל-4000K, ולחיצה נוספת מחזירה אותו ל-6500K. הוא מונע על ידי hyprsunset, שההחלפה מתחילה עבורכם אם הוא כבר לא רץ.

כברירת מחדל hyprsunset לא עושה שום דבר למסך שלכם בכלל. `~/.config/hypr/hyprsunset.conf` מגיע עם פרופיל זהות בדיוק כדי שהתצוגה תישאר ללא מגע עד שמבקשים חמימות. אם תעדיפו שהוא יתחלף לפי השעון, החליפו אותו בפרופיל זמן:

```
profile {
    time = 20:00
    temperature = 4000
}
```

אחר כך התחילו את hyprsunset בעת ההתחברות על ידי הוספת `o.launch_on_start("hyprsunset")` ל-`~/.config/hypr/autostart.lua`. הצמד 4000K/6500K שנמצא בשימוש על ידי ההחלפה קבוע, כך שקובץ ההגדרות הוא המקום שאליו הולכים אם רוצים טמפרטורה שונה.

### נא לא להפריע

`Super + Ctrl + ,` משתיק התראות. שום הודעת טוסט לא קופצת בזמן שהוא דלוק, ומחוון הפעמון החצוי יושב בשורה כדי להזכיר לכם למה שולחן העבודה השתתק.

אבל שום דבר לא הולך לאיבוד. התראה מושתקת נכתבת ישירות להיסטוריית ההתראות שלכם, שהיא בדיוק התיעוד שתרצו כאשר תחזרו ותהו מה פספסתם. פתחו אותה עם `Super + Shift + Alt + ,`. ראו [הודעות](10-notices.md) ליתר סיפור ההתראות.

שני סוגי הודעות עדיין עוברים: הודעות אישור של Omarchy עצמה על משהו שעשיתם זה עתה ("ערכת הנושא שונתה", "צילום המסך נשמר"), והתראות קריטיות שנשלחות משורת הפקודה. אפליקציות צ'אט שמסמנות הכול כקריטי כדי לכפות את דרכן לפניכם לא זכאיות לכך.

### סרק

מעטפת Omarchy היא בעלת התנהגות הסרק, והתזמונים הם בלוק `idle` ברמה העליונה ב-`~/.config/omarchy/shell.json`:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

שני המספרים הם שניות שנספרות מהרגע שהפכתם לסרק — לא זה מזה. כך שעם ברירות המחדל, שומר המסך עולה לאחר שתיים וחצי דקות ומסך הנעילה משתלט בחמש דקות, בין אם שומר המסך רץ ובין אם לא. שמרו את הקובץ והמעטפת קולטת את התזמונים החדשים מיד.

אם מבטלים את שומר המסך לפני מועד הנעילה, זה נחשב כפעילות והנעילה הממתינה מבוטלת. לא תינעלו החוצה בגלל שהצצתם במכונה שלכם.

כדי להפסיק להינעל על סרק לגמרי, `Super + Ctrl + I` — או `omarchy toggle idle` — מדליק את הישאר ער, ומחוון כוס הקפה מופיע בשורה. זה זה שלוחצים עליו לפני מצגת ארוכה או בנייה שתרצו לצפות בה. לחצו שוב כדי לחזור לשגרה. `omarchy toggle idle status` מדפיס את המצב הנוכחי כ-JSON אם צריך אותו מסקריפט.

זה עוסק בנעילה ובשומר המסך, לא בכוח. להשיה ולתרדמת יש הגדרה משלהן ב-[שינת מערכת](36-system-sleep.md).

### שומר המסך

שומר המסך של Omarchy הוא אמנות ASCII שרצה דרך אפקטי טקסט אקראיים, מופע אחד לכל מסך. כל מקש או תנועת עכבר יוצאים ממנו.

אפשר להתחיל אותו על פי דרישה מ-_מערכת > שומר מסך_ (`Super + Esc`), שמאלץ אותו לעלות גם אם כיביתם את שומר מסך הסרק. אין קיצור מקלדת שמשויך אליו כברירת מחדל.

`omarchy toggle screensaver` הוא זה שמכבה את שומר מסך הסרק, אם תעדיפו לעבור ישר מעבודה לנעילה. הוא צריך טרמינל שהוא יודע להגדיר — Alacritty, Foot, Ghostty או Kitty — ויודיע לכם אם הטרמינל המוגדר כברירת מחדל שלכם הוא משהו אחר.

הלוגו שהוא מצייר שלכם לשינוי, תחת _סגנון > שומר מסך_. העלו png או svg ו-Omarchy ממירה אותו ל-ASCII. ראו [מיתוג](41-branding.md).

### מסך הנעילה

`Super + Ctrl + L` נועל את המכונה. זה מריץ את מסך הנעילה ממעטפת Omarchy, מחשיך את התצוגה, מאפס את פריסת המקלדת שלכם לראשונה כדי שלא תקלידו את הסיסמה שלכם באלפבית הלא נכון, ו — אם יש לכם אותו רץ — נועל את 1Password בדרך החוצה.

מסך הנעילה מקבל סיסמה, והוא יקבל גם טביעת אצבע ברגע שתגדירו אחת. זה, והדרכים האחרות לאמת, מכוסים ב-[אימות חומרה](37-hardware-authentication.md).
