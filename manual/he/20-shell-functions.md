# פונקציות מעטפת

Omarchy מגיעה עם קבוצה של פונקציות מעטפת לפישוט משימות נפוצות ולכימוס קריאות פרמטרים מסובכות.

## דחיסה

- `compress [file/dir]`: יצירת ארכיון tar.gz מהקובץ/ספרייה.
- `decompress [file.tar.gz]`: פתיחת קובץ tar.gz.

## כוננים

- `iso2sd [image.iso]`: יצירת כונן ניתן לאתחול על כרטיס SD באמצעות קובץ ה-iso המופנה ובחירת הכונן באופן אינטראקטיבי.
- `format-drive [device] [name]`: עיצוב דיסק שלם עם מחיצת exFAT אחת (שעובדת גם ב-Windows וב-macOS). הריצו אותו ללא ארגומנטים כדי לראות את הכוננים הזמינים. היזהרו!

## פריסות פיתוח

פריסות פיתוח מיידיות מרובות חלוניות עבור tmux:

- `tdl [ai]`: יצירת Tmux Dev Layout עם העורך שלכם, סוכן AI ומסוף. השתמשו בכינויי הסוכנים, כמו `tdl c` עבור opencode או `tdl cx` עבור Claude Code, או העבירו סוכן שני כדי להפעיל את שניהם, כמו `tdl c cx`.
- `tds`: יצירת Tmux Dev Square עם עורך, צפייה ב-diff (דרך `hunk diff --watch`), מסוף ו-opencode.
- `tdlm [ai]`: יצירת חלון `tdl` עבור כל תת-ספרייה בספרייה הנוכחית.
- `tsl [count] [command]`: יצירת נחיל של חלוניות מרוצפות ברשת, כולן מריצות את אותה פקודה (נהדר לסוכני AI).

אותן פריסות זמינות עבור Herdr כ-`hdl`, `hds`, `hdlm` ו-`hsl`.

## עצי עבודה של Git

- `ga [branch]`: יצירת עץ עבודה וענף חדשים ליד המאגר הנוכחי וקפיצה לתוכו.
- `gd`: הסרת עץ העבודה הנוכחי וענפו (מבקש אישור תחילה).

## צופי Rsync

- `rsw [source] [destination]`: התחלת צופה רקע שמסנכרן ב-rsync את המקור ליעד בכל פעם שמשהו משתנה. היעד יכול להיות מארח מרוחק, כמו `rsw ~/Work/app nyc-dev:Work/app`.
- `lsw`: רשימת כל הצופים הפעילים.
- `dsw`: עצירת כל הצופים הפעילים.

## העברת פורטים ב-SSH

אידיאלי לביצוע פיתוח רשת עם הרשאות הקשר-מאובטח של localhost כנגד קופסה מרוחקת.

- `fip`: העברת פורט אחד או יותר ממארח מרוחק ל-localhost דרך SSH.
- `dip`: ניתוק פורט מועבר אחד או יותר.
- `lip`: רשימת כל העברות הפורטים הפעילות ב-SSH.

נניח שמפעילים שרת פיתוח בפורט `3000` על מכונה נגישה כ-`nyc-dev`, אז תוכלו להריץ `fip nyc-dev 3000` כדי להעביר את הפורט ההוא, כך ש-`localhost:3000` מגיע בפועל ל-`nyc-dev:3000`, אך ללא צורך בתעודות SSL כדי ליצור את ההקשר המאובטח הדרוש לבדיקת שקעי רשת וכדומה.

## חיבור מחדש של SSH

`ssh` עצמו עטוף בפונקציה שמנקה את המסוף אם חיבור מת בזמן ש-tmux, Herdr או עורך מרוחקים תפסו אותו, ולאחר מכן מתחברת מחדש באופן אוטומטי כשמושב אינטראקטיבי נופל (Ctrl-C עוצר את לולאת הניסיון מחדש).
