# AI

Omarchy כוללת משגרים לסוכני הקידוד שלהלן מבלי לבחור עבורך ברירת מחדל. הרץ פקודה כדי להתקין את ה-CLI שלה בשימוש הראשון, ולאחר מכן בצע אימות כשתתבקש. Hermes הוא היוצא מן הכלל: שום דבר לא מותקן עבורו בשימוש הראשון, ובחירתו מתקינה את Hermes Desktop, כפי ש-_Desktop apps_ להלן מסביר.

### התקנה ועדכון של סוכנים

למעט Hermes, הסוכנים האלה משתמשים בהתקנה העצלה של mise: ההפעלה הראשונה מתקינה את ה-CLI, והפעלות מאוחרות יותר משתמשות בו שוב. mise גם בודק אם קיימת גרסה חדשה לסוכן מותקן לכל היותר אחת לארבע שעות, ממש לפני שהוא מתחיל או ברקע בפרומפט של ה-shell. אם העדכון הזה נכשל או שאתה לא מחובר, הגרסה המותקנת תרוץ. `omarchy update` מעדכן סוכנים מותקנים יחד עם שאר Omarchy, ו-`mup` מעדכן רק כלים המנוהלים על ידי mise.

המעדכן של סוכן עצמו, כמו `claude update`, `codex update`, או כפתור עדכון באפליקציה, לא מעדכן את ההתקנה המנוהלת על ידי mise. `codex update` נכשל, ו-`claude update` יכול לדווח על הצלחה תוך התקנת עותק נפרד ש-mise לא עוקב אחריו. אם אתה מעדיף להשתמש במתקין ובמעדכן המקוריים של סוכן, הוסף אותו ל-`disable_tools`; ראה [כלי CLI מותקנים מראש](18-development-tools.md#preinstalled-cli-tools).

כדי להתקין מראש את כל הכלים העצלים המוגדרים לפני שתצטרך אותם, הרץ `mise install --include-lazy`. זה כולל גם את כלי ה-CLI האחרים של Omarchy כברירת מחדל וגם את הסוכנים. ראה [כלי CLI מותקנים מראש](18-development-tools.md#preinstalled-cli-tools) להתקנת כלי יחיד או לשימוש בהתקנה משלך.

`grok` מותקן דרך חבילת `grok` הרשמית של mise, באותו אופן כמו `claude` ו-`codex`. הרץ `grok`, או בחר בו תחת _Setup > Defaults > Agent_. דלג על המתקין של `curl | bash` ב-x.ai. הנתיב הזה מניח עותק שני ב-`~/.grok/bin`, מקדים אותו ב-`PATH`, ודורס את ה-wrapper של Omarchy.

`dsh` פותח את ממשק הדפדפן שלו ב-`127.0.0.1:3080`, כאשר ספריית ההפעלה היא סביבת העבודה המוגדרת כברירת מחדל שלו. ממשק הדפדפן שלו לא מקבל פרומפט התחלתי, ולכן `omarchy agent prompt` פותח אותו עם הפרומפט שבלוח ההעתקה שלך כדי להדביק. Omarchy מפעיל אותו עם הגדרת ההרשאות no-approval של DeepSeek. DeepSeek Harness מעלה יומני session ל-DeepSeek כשאתה משתמש ב-API המודלים הרשמי שלו; כבה זאת תחת _Settings > General > Upload Session Log_ בממשק הדפדפן שלו. גם משוב שאתה שולח אליו מועלה עם ה-session, אלא אם אתה מפעיל אותו עם `DSH_TELEMETRY_MODE=DISABLED`.

### הסוכן המוגדר כברירת מחדל

בחר את הסוכן שיוגדר כברירת מחדל עם `omarchy default agent <name>` או תחת _Setup > Defaults > Agent_ בתפריט Omarchy (`Super + Space`). אם הסוכן עדיין לא מותקן, בחירתו תתקין אותו תחילה. Omarchy טרי יזמין אותך לעשות בחירה זו עם התראה חד-פעמית.

בחירה ב-Claude מנסה גם להגדיר את הרחבת הדפדפן שלו עבור Chromium, Chrome, Brave, Brave Origin ו-Edge. הגדרת ההרחבה חלה על כל המשתמשים ועלולה לבקש את סיסמת המערכת שלך; ביטול או התקנת הרחבה שנכשלה עדיין בוחרים ומפעילים את Claude. הפעל מחדש את הדפדפן, הפעל את ההרחבה אם תתבקש, והיכנס ל-Claude כדי לסיים את החיבור שלו. הרץ `/chrome` ב-Claude כדי לבדוק את החיבור. Firefox ו-Zen לא תומכים בהרחבה זו. אם Claude כבר היה ברירת המחדל שלך לפני שההגדרה הזו נוספה, בחר בו שוב כדי להתקין את ההרחבה.

לאחר שבחרת, `Super + Shift + Ctrl + A` מפעיל את הסוכן המוגדר כברירת מחדל בחלון טרמינל ייעודי (או מציג את הבורר אם עדיין לא בחרת). אפשר גם להפעיל אותו ישירות למשימה עם `omarchy agent prompt "Review this project"`. Freebuff ו-DeepSeek Harness לא מקבלים פרומפט התחלתי, ולכן הם נפתחים עם הפרומפט שבלוח ההעתקה שלך להדבקה במקום זאת. סוכנים המופעלים בדרך זו רצים ללא השגחה במצבי ה-don't-stop-to-ask שלהם, אז תהיה מוכן לכך שהם באמת יעשו דברים! ל-MiniMax Code אין מצב כזה עבור ה-sessions האינטראקטיביים שלו, ולכן הוא מבקש הרשאות כרגיל. ומכיוון שסוכנים מסרבים לזכור אמון עבור ספריית הבית שלך, הפעלות מ-`$HOME` מתחילות ב-`~/Work` במקום זאת.

יש גם קיצורי דרך לטרמינל: `a` מריץ את הסוכן המוגדר כברירת מחדל ישירות בטרמינל הנוכחי, בעוד `c`, `cx` ו-`cy` מפעילים את OpenCode, Claude Code ו-Codex ישירות (שוב במצבי האישור האוטומטי שלהם). שינויי ערכת נושא מסתנכרנים גם לסוכנים: Claude Code, Pi, OpenCode ו-Hermes (לאחר ש-Omarchy התקין אותו) כולם עוקבים כשאתה מחליף את ערכת הנושא של Omarchy.

### פאנל הסוכנים

בסרגל העליון יש אייקון סוכנים. לפני שהגדרת סוכן, הפאנל שלו מדריך אותך בהתחברות ל-Claude, Codex או Grok, והראשון שבהם הופך לסוכן ברירת המחדל שלך. לאחר מכן, הפאנל מציג כל מנוי בעמוד אחד: כל סוכן וחשבון עם התוכנית שלו, מד עבור כל אחת ממגבלות ה-session של 5 שעות והמגבלות השבועיות שלו עם הזמן עד לאיפוס (רחף כדי לראות את האחוז המדויק), או יתרת התשלום מראש שנותרה, תחת שורה המתחלפת בין מה שהשתמשת בו בכל כולם, כמו טוקנים השבוע והמודל שבו השתמשת הכי הרבה. תחת _Make something_ הוא מציע פרומפטים לפתיחה לערכת נושא, תוסף או אפליקציה חדשים שמעבירים את המשימה לסוכן ברירת המחדל שלך. אפליקציות נבנות באותו אופן שבו נבנו Hype, Monologue ו-Omacut של Omarchy עצמה, ב-C++ וב-Qt Quick, בהתאם למיומנות הסוכן omarchy-app, והמהדר וחלקי ה-Qt שהם צריכים מגיעים מותקנים. Claude Code, Codex, Grok, Kimi, Cursor והקצבת Grok Bot שלו, GitHub Copilot, Muse, Antigravity, Kimchi ו-Devin מכוסים מיד עם המגבלות שלהם, ו-Hermes, Mistral Vibe ו-Qwen Code מציגים את ה-sessions והטוקנים שלהם לאחר שהשתמשת בהם. תוכניות ומפתחות של ספקים שאתה משתמש בהם דרך pi, omp או opencode מופיעים גם כן: OpenCode Zen ו-Go, תוכנית Z.ai GLM Coding Plan, Ollama Cloud, תוכנית MiniMax Token Plan ו-Synthetic עם המגבלות שלהם; Fireworks, OpenRouter ו-DeepSeek עם יתרות התשלום מראש שלהם; והמודלים שאתה מריץ על החומרה שלך תחת Local models. כל סוכן נספר פעם אחת, אצל מי שמחייב עליו, לא משנה כמה harnesses אתה מפעיל אותו דרכם.

לחץ עם הלחצן השמאלי על אייקון הסרגל כדי לפתוח את הפאנל, לחץ עם הלחצן הימני כדי להפעיל את סוכן ברירת המחדל שלך. רשומות השימוש שמאחוריו נוצרות מחדש כל 15 דקות על ידי `omarchy agent usage-update`, והפאנל יכול אפילו למזג שימוש מהמכונות האחרות שלך דרך תיקייה מסונכרנת. ראה את ה-README תחת `$OMARCHY_PATH/shell/plugins/agents/` להגדרות המלאות.

### מספר מנויים

אם אתה משלם עבור יותר מתוכנית אחת של Claude, Codex או Grok — Max אישי ואחד לעבודה, נניח — Omarchy יכול לשמור את כולם מחוברים ולעבור ביניהם. הוסף מנוי עם ה-+ בפאנל הסוכנים, שמדריך אותך לעשות זאת ממש שם, או עם `omarchy agent account add claude Work` (או `codex`, או `grok`). הוא מתקין את ה-CLI אם הוא חסר. החשבון הראשון עבור ספק נכנס דרך הדפדפן הרגיל שלך, בדיוק במקום שבו ה-CLI תמיד מחפש. כל אחד אחרי זה נכנס דרך חלון פרטי, כדי שהחשבון שהדפדפן שלך כבר מחובר אליו לא ייבחר בטעות; היכנס שם כחשבון שאתה מוסיף, וסגור תחילה כל חלון פרטי שכבר היה פתוח. אל תצא מה-CLI לעולם כדי לעשות זאת: יציאה מבטלת את הכניסה השמורה, והחשבון הזה יצטרך להיות מוסף שוב.

כדי להעתיק את כניסות המנויים שלך למכונת Omarchy אחרת דרך SSH, הרץ `omarchy agent account copy user@laptop`. השולח מספק מקלט זמני כאשר ליעד אין אחד מותקן, כך שמכונות Omarchy ישנות יותר יכולות לקבל חשבונות ללא עדכון. מקלטים מותקנים מקבלים עדיפות. זה מעתיק את כל המנויים של Claude, Codex ו-Grok; הוסף שמות ספקים כדי לבחור בהם, כמו ב-`omarchy agent account copy laptop claude`. שמות החשבונות ומזהי הפקודות תואמים למקור, כולל חשבונות שכבר קיימים ביעד. חשבונות יעד לא קשורים מקבלים סיומת מספרית אם השמות שלהם מתנגשים, והגדרות, מיומנויות, תוספים והיסטוריית שיחות נשארים מקומיים לכל מכונה.

אישורי יעד קיימים נשמרים. חשבון מקור שכבר מחובר שם מסונכרן בשמו מבלי להחליף את האישורים שלו; חשבונות אחרים נוספים לצידו. כדי להחליף אישורים שמורים עבור חשבונות תואמים, השתמש ב-`omarchy agent account copy --replace laptop claude` לאחר שסיימת את ה-sessions של החשבון הזה ביעד. יעד טרי מקבל גם את החשבון הפעיל של המקור ואת העדפות המעבר שלו; יעד מבוסס שומר על שלו.

אישורים עוברים דרך SSH ומאוחסנים בקבצים פרטיים ביעד, אז העתק רק למכונות שאתה סומך עליהן. זו העתקה חד-פעמית, לא סנכרון מתמשך. אסימוני רענון של Codex יכולים להיות מוחלפים על ידי מכונה אחרת, מה שמשאיר כניסה מועתקת הזקוקה לחידוש; כניסות נפרדות נשארות הבחירה האמינה ביותר לשימוש בו-זמני על מספר מכונות. ראה את [הנחיות אימות החשבון של Codex](https://developers.openai.com/codex/auth/ci-cd-auth).

חשבון אחד לכל ספק פעיל, וכל session חדש מתחיל כמוהו: `cx`, `cy`, `claude`, `codex` או `grok` פשוטים, כל דבר המופעל דרך `omarchy agent`, וסקריפטים או עורכים שמוצאים את ה-CLI ב-`PATH`. החלף עם `omarchy agent account use work` (ובחזרה עם `omarchy agent account use main`), או בפאנל על ידי לחיצה על מספר של חשבון ולאחר מכן `Enter` (או לחיצה על כפתור Use שלו). Sessions שכבר רצים נשארים על החשבון שהם התחילו איתו. היסטוריית שיחות, הגדרות, מיומנויות ותוספים משותפים בין חשבונות, כך ש-`claude --continue` באותה תיקייה ממשיך מהנקודה שבה הפסקת בחשבון החדש.

עם יותר מחשבון אחד, הפאנל מציג את המגבלות של כל חשבון זה לצד זה, עם הפעיל מסומן. כברירת מחדל Omarchy מודיע לך כאשר החשבון הפעיל עובר 95% ממגבלה, ולחיצה על ההתראה עוברת לחשבון עם הכי הרבה מרווח. רחף מעל שורת חשבון בפאנל ולחץ על Autoswitch שמופיע ליד Use (או לחץ `m`), או הרץ `omarchy agent account mode auto`, כדי שזה יעבור מעצמו במקום זאת; בזמן שזה מופעל, Autoswitch תופס את מקומו של Use, ולחיצה עליו שוב חוזרת למצב התראה. הוסף מספר כדי לשנות את הסף, כמו ב-`omarchy agent account mode auto 90`. אם כל חשבון מעל הסף, תשמע על כך פעם אחת, יחד עם איזה חשבון מתפנה ראשון. בזמן שחשבון פעיל נמצא בטווח של 15 נקודות מהסף שלו (80% בברירת המחדל), המגבלות שלו נבדקות כל שלוש דקות ולא כל 15.

`omarchy agent account list` מציג כל חשבון ואת המגבלות האחרונות שלו, `omarchy agent account remove work` שוכח אחד, ו-`omarchy agent account rename primary Hey` משנה שם של אחד (או לחץ על שם חשבון בפאנל). פקודות אלה פועלות על חשבונות סוכן ברירת המחדל שלך; כדי להגיע לספק האחר, ציין אותו תחילה, כמו ב-`omarchy agent account use codex side`. הכניסה שכבר הייתה לך ב-`~/.claude` או ב-`~/.codex` היא חשבון ה-_Main_ ונשארת היכן שהיא. חשבון שנשאר לא בשימוש יותר מכשמונה שעות יכול להציג _Sign-in required_; לחץ עליו כדי להיכנס לחשבון הזה שוב ממש בפאנל, או התחל session בו, שמרענן את הכניסה מעצמו. שרתי MCP שהיו לך כאשר חשבון נוסף מגיעים איתו, אבל אלה שאתה מוסיף אחר כך עם `claude mcp add` מגיעים רק לחשבון שבו הוספת אותם. Claude Desktop וכלים המוגדרים עם נתיב מוחלט לקובץ הבינארי של ה-CLI לא עוקבים אחר המעבר. `CLAUDE_CONFIG_DIR`, `CODEX_HOME` או `GROK_HOME` מפורשים מקבלים עדיפות על החשבון שנבחר.

### אבחון קריסות

Omarchy עוקב אחר systemd-coredump אחר קריסות תהליכים. כאשר משהו עושה segfault, תקבל התראת "Process crashed" — לחץ עליה, והקריסה מועברת לסוכן ברירת המחדל שלך יחד עם מיומנות diagnose-crash של Omarchy, שמדריכה את הסוכן בביסוס העובדות מה-core dump ובהחלטה אם הקריסה שווה דיווח ל-upstream. אפשר גם להריץ אותה ידנית מול כל PID מתוך `coredumpctl list` עם `omarchy agent crash <pid>`.

המעקב מופעל כברירת מחדל. כבה אותו תחת _Trigger > Toggle > Crash Capture_ (או עם `omarchy toggle crash-capture`) וההתראות מפסיקות; `omarchy agent crash <pid>` עדיין עובד ידנית.

אפשר גם להשתיק קריסות תוכנית אחת בכל פעם, שזה מה שהאבחון מציע לך בסוף. `omarchy crash mute hyprland` מפסיק את ההתראות עבור התוכנית הזאת בלבד, `omarchy crash mute hyprland off` מחזיר אותן, ו-`omarchy crash mute` בפני עצמו מפרט מה השתקת. הוא מקבל את הנתיב של הקובץ הבינארי בשמחה כמו את שמו, כך ש-`omarchy crash mute /usr/bin/hyprland` עושה אותו דבר. צטט שם עם רווח בתוכו, כמו ב-`omarchy crash mute 'Some App'`. כל השאר עדיין מודיע, והתוכנית המושתקת עדיין קורסת — זה מסתיר את התזכורת, זה לא מתקן כלום.

### אפליקציות שולחן עבודה

תפריט _Install > AI_ נושא גם כמה אפליקציות AI גרפיות: אפליקציית שולחן העבודה של ChatGPT, אפליקציית שולחן העבודה של Claude (הבטא ל-Linux של Anthropic, עם לשוניות Chat, Cowork ו-Claude Code), Grok Bot לשיחה עם המודלים של xAI, Hermes Desktop, OpenClaw, אפליקציית שולחן העבודה של Perplexity ו-T3 Code. Grok Bot היא אפליקציית הצ'אט לשולחן העבודה. סוכן הקידוד הוא פקודת `grok`.

Hermes Desktop היא זו שכדאי לדעת עליה, כי למכונה יש Hermes אחד, והוא של האפליקציה: Hermes מותקן רק אי-פעם דרך האפליקציה, ופקודת `hermes` שסוכן ברירת המחדל מריץ היא של האפליקציה. בחירה ב-Hermes כסוכן ברירת מחדל מתקינה אותו דבר שערך _Install > AI_ מתקין: החבילה, ו-runtime של Hermes תחת `~/.hermes` המוגדר על ידי המתקין של Hermes עצמו, שלוקח כמה דקות בפעם הראשונה. ה-runtime הזה הוא ה-Hermes האחד שפקודת `hermes` בטרמינל, סוכן ברירת המחדל והאפליקציה כולם משתמשים בו, והוא מעדכן את עצמו עם `hermes update` ולא מחכה לגרסת Omarchy. התקנתו גם מעניקה ל-Hermes את ערכת הנושא של Omarchy כסקין בשם `omarchy`, שכל משטח של Hermes עוקב אחריה כשאתה מחליף ערכות נושא; בחר אחרת תחת הגדרות Appearance של Hermes או עם `/skin` אם אתה מעדיף שלא, ו-Omarchy משאיר את הבחירה הזו לבד. הסרת האפליקציה תחת _Remove > AI_ סוגרת תחילה את Hermes, כולל ה-gateway, לוקחת איתה את ה-runtime הזה, ושומרת את הצ'אטים, הזיכרונות והמיומנויות ש-Hermes כתב לעצמו אלא אם אתה אומר אחרת: היא שואלת, כברירת מחדל לא, האם גם הנתונים והגדרות החיבור שלך צריכים להימחק.

חוויית שולחן העבודה של OpenClaw היא ה-Control UI שלו, שנפתח כאפליקציית web המגובה על ידי ה-gateway המקומי שלו. OpenClaw חי ב-`~/.openclaw` ומעדכן את עצמו: השתמש בכפתור "Update Gateway" של ה-Control UI או הרץ `openclaw update`, וה-gateway יופעל מחדש על הגרסה החדשה. Omarchy בוחר רק את הגרסה שממנה התקנה טרייה מתחילה. הסרת OpenClaw תחת _Remove > AI_ לוקחת איתה את שירות ה-gateway ואת האפליקציה ולאחר מכן שואלת האם גם `~/.openclaw` צריך להימחק, מכיוון שזה מחזיק את הצ'אטים והאישורים שלך לצד OpenClaw עצמו ו-runtime-י התוספים שהוא מוריד; ברירת המחדל שומרת אותו, והתקנת OpenClaw שוב תקלוט אותו בחזרה.

T3 Code פועל מהגרסה הרשמית שלו ב-AppImage ב-`~/.local/share/t3code` ולא מחבילה, כך שהוא מעדכן את עצמו. התקנתו שואלת האם להתחיל בערוץ Stable או Nightly; החלף מאוחר יותר בהגדרות של T3 Code. האשכולות וההגדרות שלך חיים ב-`~/.t3`, והסרת T3 Code תחת _Remove > AI_ לוקחת אותם איתה.

### מודלים מקומיים

הרץ מודל פתוח על המכונה שלך עבור סוכני הקידוד שלך. הפרומפטים והקוד שלך נשארים על המכונה; שום דבר שנשלח למודל לא עוזב אותה. התחל עם:

```bash
omarchy agent local use best
```

או, בפאנל הסוכנים בסרגל העליון, בחר + ולאחר מכן Local AI, שמופיע כאשר מודל מתאים למכונה זו. בפעם הראשונה, זה מתקין את Podman, שמריץ את המודלים, ועל מכונת NVIDIA את ערכת כלי ה-container של NVIDIA, שמעניקה להם את ה-GPU. לאחר מכן Omarchy בוחר את המודל המומלץ למכונה זו, מוריד אותו ומפעיל אותו. צפה להורדה של עשרות GB ולכך שרוב זיכרון המכונה יהיה בשימוש בזמן שהמודל רץ: Flash Next משתמש בכ-100 GiB עם הקשר מלא של 256K. אם מודלים אחרים מחזיקים את הזיכרון שהוא צריך, הוא מוגדר כמופסק, מוכן להתחיל ברגע שתעצור אחד. המודל עוצר ביציאה; עצור אותו בעצמך כשאתה צריך את הזיכרון למשהו אחר.

`omarchy agent local list` מציג את האפשרויות ומסביר מדוע חלקן לא מתאימות. כדי להגדיר אחר, הרץ `omarchy agent local use <recipe>`. כיום, `qwen3.8-flash-next-gufo` ו-`qwen3.8-27b-gufo` זמינים למכונות Strix Halo של 128 GB; ה-27B לוקח כ-40 GiB, כך שהוא משאיר מקום לעבודה אחרת. מתכונים והמלצות חדשים מגיעים עם `omarchy update`, דרך החבילה.

לכל מודל שאתה מגדיר יש שורה משלו בפאנל הסוכנים, לצד המנויים שלך: הפעל כדי להתחיל אותו, השהה כדי לעצור אותו ולפנות את הזיכרון שלו, וכפתור הטרמינל כדי לפתוח את הסוכן שלך עליו. כמה יכולים לרוץ בבת אחת כאשר הם נכנסים לזיכרון יחד; אם אחד לא נכנס, Omarchy אומר איזה מודל רץ לעצור. גרור שורות כדי לסדר אותן מחדש, ולחץ Delete על שורה נבחרת כדי להסיר מודל ואת ההורדה שלו.

משורת הפקודה, `omarchy agent local start <recipe>` ו-`omarchy agent local stop <recipe>` עושים את אותו הדבר, `omarchy agent local status` מציג כל מודל, ו-`omarchy agent --local` פותח את סוכן ברירת המחדל שלך על המודל האחרון שהפעלת (pi אם סוכן ברירת המחדל שלך לא יכול להשתמש במודל מקומי). כל לקוח תואם-OpenAI יכול להתחבר גם כן: `status` מציג את כתובת כל מודל (הראשון הוא `http://127.0.0.1:11435/v1`), שם המתכון הוא המודל, והמפתח נמצא ב-`~/.config/omarchy/agent-local/key`.

`omarchy agent local remove <recipe>` מוחק מודל ואת ההורדות שאף מודל אחר לא משתמש בהן.

runtime-ים של צד שלישי מסומנים עם המוציא לאור שלהם. Omarchy מריץ כל מודל ללא גישה לרשת.

### מודלי LLM מקומיים

Omarchy ממליץ על שתי דרכים להרצת מודלי LLM מקומיים: LM Studio ו-Ollama. LM Studio מספק ממשק GUI למציאת מודלים פתוחי-משקל, התקנתם והרצתם. זו דרך מעולה להתחיל בקלות. Ollama מציע CLI לעשות זאת באופן דומה. אבל אם אתה חדש במודלים מקומיים, הייתי מתחיל עם LM Studio. אפשר להתקין כל אחד מהם תחת _Install > AI_ בתפריט Omarchy.

### מיומנות Omarchy

מיומנויות סוכן עוזרות ל-AI להשתמש בכלים ספציפיים בדרך ספציפית, ו-Omarchy מגיע עם מיומנות ברירת מחדל להתאמת המערכת. כמו לכוונן את הגדרות Hyprland שלך, להתאים את הסרגל, או אפילו ליצור ערכת נושא חדשה מאפס. היא מקושרת באמצעות קישור סמלי לתוך ספריות המיומנויות של Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` וכל `~/.hermes/profiles/*/skills`), והמיקום הגנרי `~/.agents/skills`, כך שרוב ה-harnesses קולטים אותה אוטומטית.

אבל כדאי להתייחס למיומנות הזו כניסיונית. מודלים שונים ישתמשו בה במידת השפעה שונה. הכי טוב להריץ תחילה במצב plan, כדי שיהיה לך מושג מה הסוכן רוצה לשנות. ואז תהיה מוכן לשחזר שינויים או אפילו להפעיל `omarchy reinstall configs`, אם הסוכן עושה בלגן מהכול.
