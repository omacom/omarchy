# שאלות נפוצות

### איך עוברים בין פריסות מקלדת?

ערכו את קובץ `~/.config/hypr/input.lua` שלכם והוסיפו את זה כדי לעבור בין פריסות באמצעות `Left Alt + Right Alt`:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

הסרגל יציג אוטומטית את פריסת המקלדת הנוכחית שלכם ברגע שהגדרתם כמה פריסות (ותוכלו גם ללחוץ עליו כדי לעבור).

### איך משנים את תבנית השעון ל-12 שעות?

לחצו לחיצה ימנית על השעון בסרגל כדי לעבור בין התבניות הנפוצות, כולל אלה של 12 השעות. תוכלו גם להגדיר את התבנית ישירות:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

זה יציג יום ראשון 10:55 AM.

### איך משנים את אזור הזמן שלי?

הריצו את _עדכון > אזור זמן_ בתפריט Omarchy ובחרו מהרשימה. אם אזור הזמן נכון אבל השעון עצמו נסחף, _עדכון > שעה_ מפעיל מחדש את סנכרון השעה בשבילכם.

### איך משנים את ה-DNS שלי, משתפים את ה-Wi-Fi שלי, או בודקים את מהירות החיבור שלי?

כל אלה נמצאים ב[רשת](35-networking.md).

### איך בודקים כמה הדיסק שלי מהיר?

_הפעלה > בדיקת מהירות > בדיקת מהירות דיסק_ מודד מהירות קריאה וכתיבה חיה בכונן שלכם, או `omarchy disk speedtest` מהמסוף.

### איך מוסיפים מדפסת?

ההדפסה מוגדרת ופועלת היישר מהקופסה, ואתם מוסיפים כל מדפסת בעצמכם מתוך _הגדרות הדפסה_ במפעיל היישומים (`Super + Space`).

בחרו _הוספה_, ותנו לו רגע לחפש: מדפסת המחוברת באמצעות USB, ורוב מדפסות הרשת, יימצאו בשבילכם. אם שלכם אינה ברשימה, בחרו _מדפסת רשת > Internet Printing Protocol (ipp)_ והזינו את הכתובת שלה — התצוגה של המדפסת עצמה או דף הרשת שלה יגידו לכם מהי, בדרך כלל משהו כמו `192.168.1.50` עם תור של `ipp/print`. _הבא_ מציע אז מנהל התקן, כאשר מדפסת מודרנית עובדת הכי טוב על פרופיל _IPP Everywhere_ ללא מנהל התקן ומדפסת ישנה יותר רוצה את מנהל ההתקן של הדגם עצמו.

לחצו לחיצה ימנית על מדפסת ובחרו _הגדר כברירת מחדל_ כדי לבחור לאיזו מהן היישומים שלכם פונים קודם, ו_מאפיינים_ כדי להגדיר גודל נייר, דופלקס ואיכות.

גילוי אוטומטי, שבו מדפסות ברשת מופיעות מבלי שיוסיפו אותן, כבוי זמנית בזמן שהוא נבנה מחדש, ולכן הצעד הראשון למעלה הוא שלכם ולא אוטומטי. הדפסה לקובץ PDF עובדת ללא מדפסת כלל.

### איך משנים היכן נשמרים צילומי מסך או הקלטות מסך?

צילומי מסך שנשמרו הולכים ל-`~/Pictures/Screenshots` כברירת מחדל. כדי להשתמש בתיקייה אחרת, הוסיפו את זה לקובץ תחת `~/.config/uwsm/env.d/` (כמו `~/.config/uwsm/env.d/capture`):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

תוכלו לעשות אותו דבר עבור הקלטות מסך באמצעות `OMARCHY_SCREENRECORD_DIR`.

Omasnap יוצר את תיקיית צילומי המסך שלו אוטומטית. צרו את תיקיית הקלטות המסך בעצמכם, ואז הפעילו מחדש את Omarchy כדי שכל אחד משינויי הסביבה ייכנס לתוקף.

### איך גורמים לרמקולים + מצלמת הרשת לעבוד על Apple Studio Display שלי?

הייתם חושבים שהכול אמור לעבוד פשוט על ידי חיבור USB C, אבל למרבה הצער זה לא המצב. הפתרון שמצאתי כדי שזה יעבוד באופן אמין הוא שימוש ב[כבל WJESOG DisplayPort + USB-A => USB-C](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/). אז הרמקולים ומצלמת הרשת עובדים כמו קסם.

זכרו שיש לכם בקרת בהירות מובנית ב-Omarchy עבור צגי Apple (גם Studio וגם XDR) באמצעות לחצני בהירות המקלדת הרגילים.

### איך נפטרים מכל התוכנות הנוספות?

אם אינכם רוצים תוכניות כמו Obsidian או LibreOffice או כל שאר הדברים המותקנים מראש, תוכלו להסיר אותם בקלות רבה מאוד.

הריצו את _הסרה > חבילה_ כדי לראות כל חבילה שמותקנת. אז תוכלו לבחור כל חבילה שתרצו להסיר עם tab, ולהתחיל להסיר כל מה שבחרתם עם return.

ותוכלו להשתמש ב_הסרה > יישום רשת_ מתפריט Omarchy כדי להסיר כל אחד מיישומי הרשת המותקנים מראש שאינכם רוצים.

או הריצו את _הסרה > התקנות מראש_ כדי לסחוף החוצה את כל התוספות המותקנות מראש — יישומי רשת, TUIs ויישומים אופציונליים — במכה אחת. מקשי הקיצור שהפעילו אותם נעלמים איתם, כך שנשארתם עם לוח נקי של קישורים למלא בשלכם ב-`~/.config/hypr/bindings.lua`.
