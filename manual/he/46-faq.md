# שאלות נפוצות

### איך מחליפים בין פריסות מקלדת?

ערכו את הקובץ `~/.config/hypr/input.lua` שלכם והוסיפו את זה כדי להחליף בין פריסות עם `Left Alt + Right Alt`:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

הסרגל יציג אוטומטית את פריסת המקלדת הנוכחית שלכם ברגע שתגדירו כמה פריסות (ותוכלו גם ללחוץ עליו כדי להחליף).

### איך משנים את תבנית השעון ל-12 שעות?

לחצו בלחצן הימני על השעון בסרגל כדי לעבור בין התבניות הנפוצות, כולל תבניות 12 השעות. תוכלו גם להגדיר את התבנית ישירות:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

זה יציג יום ראשון 10:55 AM.

### איך משנים את אזור הזמן שלי?

הפעילו את _הגדרה > אזור > אזור זמן_ בתפריט Omarchy ובחרו מהרשימה. אם אזור הזמן נכון אבל השעון עצמו נסחף, _עדכון > זמן_ מפעיל מחדש עבורכם את סנכרון הזמן.

### איך משנים את ה-DNS שלי, משתפים את ה-Wi-Fi שלי, או בודקים את מהירות החיבור שלי?

כל אלה נמצאים ב[רישות](35-networking.md).

### איך בודקים כמה מהיר הדיסק שלי?

_הפעלה > מבחן מהירות > מבחן מהירות דיסק_ מודד מהירות קריאה וכתיבה חיה בכונן שלכם, או `omarchy disk speedtest` מהמסוף.

### איך מוסיפים מדפסת?

ההדפסה מוגדרת ופועלת מהקופסה, ואתם מוסיפים כל מדפסת בעצמכם מתוך _הגדרות הדפסה_ במפעיל היישומים (`Super + Space`).

בחרו _הוספה_, ותנו לזה רגע לחפש: מדפסת המחוברת ב-USB, ורוב מדפסות הרשת, יימצאו עבורכם. אם שלכם אינה ברשימה, בחרו _מדפסת רשת > Internet Printing Protocol (ipp)_ והזינו את כתובתה — הצג של המדפסת עצמה או דף האינטרנט שלה יגידו לכם מהי, בדרך כלל משהו כמו `192.168.1.50` עם תור של `ipp/print`. _הבא_ מציע אז מנהל התקן, כאשר מדפסת מודרנית עובדת הכי טוב עם פרופיל ה_ IPP Everywhere_ ללא מנהל התקן ומדפסת ישנה יותר רוצה את מנהל ההתקן של הדגם עצמו.

לחצו בלחצן הימני על מדפסת ובחרו _הגדרה כברירת מחדל_ כדי לבחור באיזו מהן היישומים שלכם יגיעו ראשונה, ו_מאפיינים_ כדי להגדיר גודל נייר, הדפסה דו-צדדית ואיכות.

גילוי אוטומטי, שבו מדפסות ברשת מופיעות בלי שמוסיפים אותן, כובה זמנית בזמן שהוא נבנה מחדש, ולכן הצעד הראשון למעלה הוא שלכם ולא אוטומטי. הדפסה לקובץ PDF עובדת בלי שום מדפסת בכלל.

### איך משנים היכן נשמרים צילומי מסך או הקלטות מסך?

צילומי מסך שנשמרים עוברים ל-`~/Pictures/Screenshots` כברירת מחדל. כדי להשתמש בספרייה אחרת, הוסיפו את זה לקובץ תחת `~/.config/uwsm/env.d/` (כמו `~/.config/uwsm/env.d/capture`):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

תוכלו לעשות אותו דבר עבור הקלטות מסך באמצעות `OMARCHY_SCREENRECORD_DIR`.

Omasnap יוצרת את ספריית צילומי המסך שלה אוטומטית. צרו את ספריית הקלטות המסך בעצמכם, ואז הפעילו מחדש את Omarchy כדי שכל אחד משינויי הסביבה ייכנס לתוקף.

### איך גורמים לרמקולים + למצלמת הרשת לעבוד ב-Apple Studio Display שלי?

הייתם חושבים שהכול אמור לעבוד רק מחיבור USB C, אבל למרבה הצער זה לא המצב. הפתרון שמצאתי כדי לגרום לזה לעבוד באופן אמין הוא שימוש ב[כבל WJESOG DisplayPort + USB-A => USB-C](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/). אז הרמקולים ומצלמת הרשת עובדים כמו קסם.

זכרו שיש לכם בקרת בהירות מובנית ב-Omarchy עבור צגי Apple (גם Studio וגם XDR) באמצעות לחצני בהירות המקלדת הרגילים.

### איך נפטרים מכל התוכנות המיותרות?

אם אינכם רוצים תוכניות כמו Obsidian או LibreOffice או כל שאר הדברים המותקנים מראש, תוכלו להסיר אותן בקלות רבה.

הפעילו את _הסרה > חבילה_ כדי לראות כל חבילה שמותקנת. אז תוכלו לבחור כל חבילה שתרצו להסיר עם tab, ולהתחיל להסיר את כל מה שבחרתם עם return.

ותוכלו להשתמש ב_הסרה > יישום אינטרנט_ מתפריט Omarchy כדי להסיר כל אחד מיישומי האינטרנט המותקנים מראש שאינכם רוצים.

או הפעילו את _הסרה > התקנות מראש_ כדי לסלק את כל התוספות המותקנות מראש — יישומי אינטרנט, TUIs ויישומים אופציונליים — בפעם אחת. מקשי הקיצור ששיגרו אותם נעלמים איתם, כך שנשארתם עם לוח נקי של קיצורי דרך למלא בשלכם ב-`~/.config/hypr/bindings.lua`.
