# שאלות נפוצות

### איך עוברים בין פריסות מקלדת?

ערכו את הקובץ `~/.config/hypr/input.lua` שלכם והוסיפו את זה כדי לעבור בין פריסות באמצעות `Left Alt + Right Alt`:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

הסרגל יציג אוטומטית את פריסת המקלדת הנוכחית שלכם ברגע שהגדרתם כמה פריסות (ואפשר גם ללחוץ עליו כדי לעבור).

### איך משנים את תבנית השעון ל-12 שעות?

לחצו לחיצה ימנית על השעון בסרגל כדי לעבור בין התבניות הנפוצות, כולל תבניות 12 השעות. אפשר גם להגדיר את התבנית ישירות:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

זה יציג יום ראשון 10:55 AM.

### איך משנים את אזור הזמן שלי?

הפעילו את _הגדרות > אזור > אזור זמן_ בתפריט Omarchy ובחרו מתוך הרשימה. אם אזור הזמן נכון אבל השעון עצמו נסחף, _עדכון > שעה_ מפעיל מחדש עבורכם את סנכרון השעה.

### איך משנים את ה-DNS שלי, משתפים את ה-Wi-Fi שלי, או בודקים את מהירות החיבור שלי?

כל אלה נמצאים ב[רשתות](35-networking.md).

### איך בודקים כמה מהיר הדיסק שלי?

האפשרות _הפעלה > בדיקת מהירות > בדיקת מהירות דיסק_ מודדת את מהירות הקריאה והכתיבה החיה בכונן שלכם, או `omarchy disk speedtest` מהמסוף.

### איך מוסיפים מדפסת?

ההדפסה מוגדרת ופועלת מהקופסה, ואתם מוסיפים כל מדפסת בעצמכם מתוך _הגדרות הדפסה_ במפעיל האפליקציות (`Super + Alt + Space`).

בחרו _הוספה_, ותנו לזה רגע לחפש: מדפסת המחוברת באמצעות USB, ורוב מדפסות הרשת, יימצאו עבורכם. אם המדפסת שלכם אינה ברשימה, בחרו _מדפסת רשת > Internet Printing Protocol (ipp)_ והזינו את הכתובת שלה — התצוגה של המדפסת עצמה או דף האינטרנט שלה יגידו לכם מהי, בדרך כלל משהו כמו `192.168.1.50` עם תור של `ipp/print`. לאחר מכן _הבא_ מציע מנהל התקן, כאשר מדפסת מודרנית עובדת בצורה הטובה ביותר עם פרופיל ה-_IPP Everywhere_ ללא מנהל התקן, ומדפסת ישנה יותר רוצה את מנהל ההתקן של הדגם עצמו.

לחצו לחיצה ימנית על מדפסת ובחרו _הגדרה כברירת מחדל_ כדי לבחור לאיזו מהן האפליקציות שלכם יפנו קודם, ו_מאפיינים_ כדי להגדיר גודל נייר, הדפסה דו-צדדית ואיכות.

הגילוי האוטומטי, שבו מדפסות ברשת מופיעות מבלי שיוסיפו אותן, כבוי זמנית בזמן שהוא נבנה מחדש, ולכן הצעד הראשון לעיל הוא שלכם ולא אוטומטי. הדפסה לקובץ PDF עובדת ללא מדפסת כלל.

### איך משנים היכן נשמרים צילומי מסך או הקלטות מסך?

צילומי מסך שנשמרו עוברים ל-`~/Pictures/Screenshots` כברירת מחדל. כדי להשתמש בתיקייה אחרת, הוסיפו את זה לקובץ תחת `~/.config/uwsm/env.d/` (כמו `~/.config/uwsm/env.d/capture`):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

אפשר לעשות את אותו הדבר עבור הקלטות מסך באמצעות `OMARCHY_SCREENRECORD_DIR`.

Omasnap יוצרת את תיקיית צילומי המסך שלה באופן אוטומטי. צרו את תיקיית הקלטות המסך בעצמכם, ולאחר מכן הפעילו מחדש את Omarchy כדי שכל שינוי סביבה ייכנס לתוקף.

### איך גורמים לרמקולים + מצלמת הרשת לעבוד על ה-Apple Studio Display שלי?

הייתם חושבים שכל זה אמור לעבוד פשוט על ידי חיבור USB C, אבל לצערנו זה לא המקרה. הפתרון שמצאתי שעובד בצורה אמינה הוא שימוש ב[כבל ה-WJESOG DisplayPort + USB-A => USB-C](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/). אז הרמקולים ומצלמת הרשת עובדים כמו קסם.

זכרו שיש לכם בקרת בהירות מובנית ב-Omarchy עבור צגי Apple (גם Studio וגם XDR) באמצעות כפתורי בהירות המקלדת הרגילים.

### איך נפטרים מכל התוכנות הנוספות?

אם אינכם רוצים תוכניות כמו Obsidian או LibreOffice או כל שאר הדברים המותקנים מראש, תוכלו להסיר אותן בקלות רבה.

הפעילו את _הסרה > חבילה_ כדי לראות כל חבילה המותקנת. לאחר מכן תוכלו לבחור כל חבילה שתרצו להסיר באמצעות tab, ולהתחיל להסיר את כל מה שבחרתם באמצעות return.

ואפשר להשתמש ב_הסרה > אפליקציית רשת_ מתפריט Omarchy כדי להסיר כל אחת מאפליקציות הרשת המותקנות מראש שאינכם רוצים.

או הפעילו את _הסרה > התקנות מראש_ כדי לסלק את כל התוספות המותקנות מראש — אפליקציות רשת, TUIs, ואפליקציות אופציונליות — בבת אחת. מקשי הקיצור שהפעילו אותן נעלמים איתן, כך שנשאר לכם לוח נקי של שיוכים למלא בשלכם ב-`~/.config/hypr/bindings.lua`.
