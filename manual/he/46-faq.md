# שאלות נפוצות

### איך אני עובר בין פריסות מקלדת?

ערכו את קובץ `~/.config/hypr/input.lua` שלכם והוסיפו זאת כדי לעבור בין פריסות ב-`Left Alt + Right Alt`:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

השורה תציג אוטומטית את פריסת המקלדת הנוכחית שלכם ברגע שיש לכם מספר פריסות מוגדרות (ותוכלו גם ללחוץ עליה כדי לעבור).

### איך אני משנה את פורמט השעון ל-12 שעות?

לחצו לחיצה ימנית על השעון בשורה כדי לעבור בין הפורמטים הנפוצים, כולל אלה של 12 שעות. תוכלו גם לקבוע את הפורמט ישירות:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

זה יציג Sunday 10:55 AM.

### איך אני משנה את אזור הזמן שלי?

הריצו _עדכון > Timezone_ בתפריט Omarchy ובחרו מהרשימה. אם אזור הזמן נכון אך השעון עצמו נסחף, _עדכון > Time_ מפעיל מחדש את סנכרון הזמן עבורכם.

### איך אני משנה את ה-DNS שלי, משתף את ה-Wi-Fi שלי או בודק את מהירות החיבור שלי?

כל אלה נמצאים ב[רשת](35-networking.md).

### איך אני בודק כמה מהיר הדיסק שלי?

_הפעלה > בדיקת מהירות > בדיקת מהירות דיסק_ מודד מהירות קריאה וכתיבה חיה בכונן שלכם, או `omarchy disk speedtest` מהטרמינל.

### למה איני יכול להיכנס לחשבון Google שלי ב-Chromium?

בניית Chromium בקוד פתוח רגילה אינה מגיעה עם אישורי OAuth ש-Google דורש לכניסה לחשבון. הריצו _התקנה > Service > Chromium Account_ בתפריט Omarchy כדי להוסיף אותם, הפעילו מחדש את הדפדפן, והכניסה תעבור.

### איך אני מוסיף מדפסת?

הדפסה מוגדרת ופועלת מהקופסה, ואתם מוסיפים כל מדפסת בעצמכם מ-_Print Settings_ במפעיל האפליקציות (`Super + Space`).

בחרו _Add_, ותנו לו רגע לחפש: מדפסת מחוברת דרך USB, ורוב מדפסות הרשת, נמצאות עבורכם. אם שלכם אינה ברשימה, בחרו _Network Printer > Internet Printing Protocol (ipp)_ והזינו את כתובתה — התצוגה של המדפסת עצמה או דף הרשת שלה יגידו לכם מה זה, בדרך כלל משהו כמו `192.168.1.50` עם תור של `ipp/print`. _Forward_ אז מציע מנהל התקן, שם מדפסת מודרנית עובדת בצורה הטובה ביותר בפרופיל חסר מנהל התקן _IPP Everywhere_ וישנה יותר רוצה את מנהל ההתקן של הדגם עצמו.

לחצו לחיצה ימנית על מדפסת ובחרו _Set as Default_ כדי לבחור לאיזו האפליקציות שלכם מגיעות ראשונה, ו-_Properties_ כדי לקבוע גודל נייר, דופלקס ואיכות.

גילוי אוטומטי, שבו מדפסות ברשת מופיעות מבלי שיוסיפו אותן, כבוי זמנית בזמן שהוא עובד מחדש, ולכן הצעד הראשון למעלה הוא שלכם ולא אוטומטי. הדפסה לקובץ PDF עובדת בלי שום מדפסת כלל.

### איך אני משנה היכן נשמרים צילומי מסך או הקלטות מסך?

צילומי מסך שמורים עוברים ל-`~/Pictures/Screenshots` כברירת מחדל. כדי להשתמש בתיקייה אחרת, הוסיפו זאת לקובץ תחת `~/.config/uwsm/env.d/` (כמו `~/.config/uwsm/env.d/capture`):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

תוכלו לעשות אותו דבר עבור הקלטות מסך באמצעות `OMARCHY_SCREENRECORD_DIR`.

Omasnap יוצר את תיקיית צילומי המסך שלו אוטומטית. צרו את תיקיית הקלטות המסך בעצמכם, ואז הפעילו מחדש את Omarchy כדי שכל שינוי סביבה ייכנס לתוקף.

### איך אני מפעיל את הרמקולים + מצלמת הרשת ב-Apple Studio Display שלי?

הייתם חושבים שהכול צריך לעבוד רק בחיבור USB C, אך למרבה הצער זה לא המקרה. הפתרון שמצאתי כדי שזה יעבוד באופן אמין הוא שימוש ב[כבל WJESOG DisplayPort + USB-A => USB-C](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/). אז רמקולים ומצלמת רשת עובדים כמו קסם.

זכרו שיש לכם בקרת בהירות מובנית ב-Omarchy עבור צגי Apple (הן Studio והן XDR) באמצעות כפתורי הבהירות הרגילים במקלדת.

### איך אני נפטר מכל התוכנות הנוספות?

אם אינכם רוצים תוכניות כמו Obsidian או LibreOffice או כל השאר המותקן מראש, תוכלו להסיר אותן בקלות רבה.

הריצו _הסרה > Package_ כדי לראות כל חבילה שמותקנת. אז תוכלו לבחור כל חבילה שתרצו להסיר עם tab, ולהתחיל להסיר כל מה שבחרתם עם return.

ותוכלו להשתמש ב-_הסרה > Web App_ מתפריט Omarchy כדי להסיר כל אחת מהאפליקציות המותקנות מראש שאינכם רוצים.

או הריצו _הסרה > Preinstalls_ כדי לטאטא החוצה את כל התוספות המותקנות מראש — אפליקציות רשת, TUIs ואפליקציות אופציונליות — בבת אחת. מקשי הקיצור שהפעילו אותן הולכים איתן, כך שאתם נשארים עם לוח נקי של קישורים למלא בשלכם ב-`~/.config/hypr/bindings.lua`.
