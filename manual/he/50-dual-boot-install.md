# התקנה באתחול כפול

אפשר להתקין את Omarchy על מחיצה אחת לצד Windows או התקנות אחרות.

שיטת התקנה זו עדיין מגיעה עם הצפנת LUKS למחיצה כברירת מחדל, כך שבפועל היא אינה שונה מהתקנה על כונן מלא ופשוט דורשת שיהיה מקום פנוי זמין בדיסק.

## פינוי מקום ב-Windows

כדי להתקין לצד Windows, הקלידו `disk management` בתפריט ההתחלה ובחרו באפשרות **יצירה ועיצוב של מחיצות דיסק קשיח**.

 ![dual-boot-1](images/dual-boot-1.webp)

מצאו את המחיצה המתאימה, לחצו עליה בלחצן הימני ובחרו **כווץ אמצעי אחסון**.

![dual-boot-2](images/dual-boot-2.webp)

 הזינו את הכמות שברצונכם לכווץ בה את אמצעי האחסון. שימו לב שזה יהיה הגודל של התקנת Omarchy העתידית שלכם, כולל מחיצת האתחול.

 ![dual-boot-3](images/dual-boot-3.webp)

כשתסיימו, אתם אמורים לראות משהו כזה, שבו החלק של 50GB הוא המקום שבו נתקין את Omarchy בדוגמה זו.

 ![dual-boot-4](images/dual-boot-4.webp)

## התקנת Omarchy

תהליך ההתקנה של Omarchy זהה בפועל לתהליך הרגיל. לאחר שתבחרו את הדיסק, תקבלו את האפשרות **התקנה במקום פנוי**. בחרו באפשרות זו כדי למנוע מחיקה של הדיסק המלא.

 ![dual-boot-5](images/dual-boot-5.webp)

ודאו שהכול נראה תקין והמתינו לסיום ההתקנה כרגיל. כאן גם תוכלו לבחור להתקין ללא הצפנה (לא מומלץ), בדיוק כמו בהתקנה על כונן מלא.
 ![dual-boot-6](images/dual-boot-6.webp)

## הוספת התקנות אחרות למנהל האתחול

כשתסיימו את התקנת Omarchy, תשימו לב שמנהל האתחול Limine הוא כעת ברירת המחדל. באמצעותו תוכלו גם להוסיף ל-Limine אפשרויות עבור ההתקנות האחרות שלכם, כגון Windows.

כדי להוסיף מערכות הפעלה אחרות, הריצו את `limine-scan` ועקבו אחר ההנחיות כדי להוסיף את הערכים הרצויים לתצורת Limine שלכם. תפריט האתחול נשאר מוסתר כברירת מחדל ומפעיל את Omarchy לאחר שנייה אחת. כדי לבחור ב-Windows או בערך אחר, לחצו על מקש כלשהו ברגע ש-Limine מתחיל; כשהתפריט מופיע, השתמשו במקשי החצים כדי לבחור ערך ולחצו על Enter. אם Omarchy מתחיל לפני שתלחצו על מקש, הפעילו מחדש ונסו שוב.

## Bitlocker

חשוב לציין ששיטת התקנה זו אינה תואמת ל-Bitlocker, מאחר שהוא מצפין את הכונן כולו, לא רק את המחיצה. אם תיתקלו בשגיאה המציינת ש-Bitlocker מופעל, אתחלו ל-Windows, עברו אל **הגדרות -> פרטיות ואבטחה -> הצפנת מכשיר** וכבו את Bitlocker. פענוח הכונן עשוי לקחת זמן מה.

 ![dual-boot-7](images/dual-boot-7.webp)

## התקנה מחדש של Windows

אם המחשב הזה הגיע עם Windows, מפתח המוצר שלו מאוחסן בקושחה. הריצו את `omarchy windows key` כדי להדפיס אותו, כך שתוכלו להפעיל שוב את Windows אם אי פעם תתקינו אותו מחדש במכונה זו.
