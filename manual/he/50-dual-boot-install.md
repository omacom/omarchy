# התקנת אתחול כפול

תוכלו להתקין את Omarchy למחיצה יחידה לצד Windows או התקנות אחרות.

שיטת התקנה זו עדיין מגיעה עם הצפנת LUKS למחיצה כברירת מחדל, כך שהיא למעשה אינה שונה מכונן מלא ופשוט דורשת שטח פנוי זמין בדיסק.

## פינוי מקום ב-Windows

כדי להתקין לצד Windows, הקלידו `disk management` בתפריט ההתחלה ובחרו באפשרות עבור **Create and format hard disk partitions**.

 ![dual-boot-1](images/dual-boot-1.webp)

מצאו את המחיצה המתאימה, לחצו לחיצה ימנית ובחרו **Shrink Volume**.

![dual-boot-2](images/dual-boot-2.webp)

 הזינו את הכמות שתרצו לכווץ את אמצעי האחסון. שימו לב שזה יהיה הגודל של התקנת Omarchy העתידית שלכם כולל מחיצת האתחול.

 ![dual-boot-3](images/dual-boot-3.webp)

כשתסיימו, עליכם לראות משהו כמו זה שבו קטע 50GB הוא המקום שבו נתקין את Omarchy בדוגמה זו.

 ![dual-boot-4](images/dual-boot-4.webp)

## התקנת Omarchy

תהליך ההתקנה עבור Omarchy הוא למעשה זהה לרגיל. לאחר שתבחרו את הדיסק שלכם, תינתן לכם האפשרות של **Free space install**. בחרו באפשרות זו כדי למנוע מחיקת הדיסק המלא.

 ![dual-boot-5](images/dual-boot-5.webp)

אשרו שהכול נראה טוב והמתינו לסיום ההתקנה כרגיל. כאן גם תוכלו לבחור להתקין לא מוצפן (לא מומלץ) בדיוק כמו בהתקנת כונן מלא.

 ![dual-boot-6](images/dual-boot-6.webp)

## הוספת התקנות אחרות למטען האתחול

כשתסיימו את התקנת Omarchy שלכם, תבחינו שמטען האתחול Limine הוא ברירת המחדל כעת. עם זה, תוכלו גם להוסיף אפשרויות ל-Limine עבור ההתקנות האחרות שלכם כמו Windows.

כדי לעשות זאת, הריצו `limine-scan` ופעלו לפי ההנחיות להוספת כל הפריטים שתרצו לתצורת limine שלכם. אז כשתאתחלו, תראו את האפשרויות הרגילות שלכם עבור Omarchy, וגם Windows Boot Manager או אחרים.

## Bitlocker

חשוב לציין ששיטת התקנה זו אינה תואמת Bitlocker שכן היא מצפינה את הכונן כולו, לא רק את המחיצה. אם תיתקלו בשגיאה המציינת ש-Bitlocker מופעל, אתחלו ל-Windows, לכו ל-**Settings -> Privacy & Security -> Device encryption** וכבו את Bitlocker. ייתכן שייקח זמן לפענח את הכונן.
