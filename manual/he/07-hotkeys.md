# מקשי קיצור

תוכלו לראות את כל קיצורי המקלדת הראשיים עם `Super + K` (קיצורי Tmux עם `Super + Alt + K` וקיצורי Herdr עם `Super + Ctrl + K`).

## כיצד מקשי הקיצור מסודרים

כל מקש קיצור נמצא על מישור, שנקבע לפי המקשים המשלימים שלו, ולכל מישור יש תפקיד אחד. זה מה שמונע ממקשי הקיצור להתערבב זה בזה, וזה אומר שבדרך כלל תוכלו לנחש היכן משהו נמצא.

| מישור | מה נמצא שם | דוגמאות |
| --- | --- | --- |
| `Super + key` | המערכת: חלונות, סביבות עבודה, פריסות ותפריטי ליבה | `Super + Space` תפריט Omarchy, `Super + W` סגירת חלון, `Super + F` מסך מלא |
| `Super + Shift + key` | אפליקציות | `Super + Shift + B` דפדפן, `Super + Shift + E` דוא"ל, `Super + Shift + N` עורך |
| `Super + Ctrl + key` | פאנלים ותפריטי מערכת | `Super + Ctrl + A` שמע, `Super + Ctrl + N` רשת, `Super + Ctrl + C` תפריט לכידה |
| `Super + Ctrl + Alt + key` | פעולות מהירות והודעות | `Super + Ctrl + Alt + T` הצגת השעה, `Super + Ctrl + Alt + B` סוללה, `Super + Ctrl + Alt + C` צילום מסך |

הוספת `Alt` למקש קיצור נותנת לכם גרסה של אותו הדבר, לעולם לא משהו לא קשור:

- `Super + Shift + B` פותח את הדפדפן; `Super + Shift + Alt + B` פותח חלון פרטי
- `Super + Shift + E` פותח דוא"ל; `Super + Shift + Alt + E` מתחיל דוא"ל חדש
- `Super + F` עובר למסך מלא; `Super + Alt + F` עובר לרוחב מלא
- `Super + Ctrl + C` פותח את תפריט הלכידה; `Super + Ctrl + Alt + C` מדלג על התפריט ומצלם צילום מסך

בעת הוספת מקש קיצור:

1. בחרו את המישור לפי מה שהוא עושה, ואז בחרו את המקש.
2. אל תזיזו מקש קיצור קיים כדי לפנות מקום. מצאו מקש פנוי במישור הנכון.
3. השתמשו ב-`Alt` רק עבור גרסה של מקש הקיצור בלעדיו.

כמה מקשי קיצור שוברים את הכללים האלה כי זה נוח. `Shift` עם חץ או `Tab` מזיז או הופך כיוון במקום לפתוח אפליקציה, ו-`Print`, מקשי המדיה, `Alt + Tab` ו-`Ctrl + Alt + Del` עובדים כפי שהם עובדים בכל מקום אחר. אלה חריגים, לא דפוסים להעתקה.

אם ברירת מחדל לא מתאימה לכם (נגיד שאתם רוצים `Super + Shift + S` לצילומי מסך כמו ב-Windows), קשרו אותה מחדש ב-`~/.config/hypr/bindings.lua`.

במשטח מגע, החלקות בשלוש וארבע אצבעות מחליפות סביבות עבודה, מזיזות חלונות ופותחות את התפריט ואת קונסולת Quake; ראו [מקלדת, עכבר ומשטח מגע](34-keyboard-mouse-trackpad.md) למחוות.

קיצורי שינוי הגודל משתמשים במקשים פיזיים `code:20` ו-`code:21` (XKB `<AE11>` ו-`<AE12>`), ללא קשר לתווים המודפסים על המקלדת. במקלדות US מקשים אלה הם `-` ו-`=`; במקלדות יפניות (JIS) הם `-` ו-`^`; במקלדות ספרדיות הם `'` ו-`¡`. ב-JIS, `Super + ^` הוא `Super + Equal`, בעוד `Super + Shift + -` (שמקליד `=`) הוא `Super + Shift + Minus`.

## לוח העתקה אוניברסלי

| מקש קיצור                  | תפקיד              |
| ----------------------- | --------------------- |
| `Super + A`           | בחירת הכול באפליקציות שתומכות ב-`Ctrl + A`    |
| `Super + C`           | העתקה    |
| `Super + X`           | גזירה (לא במסוף)    |
| `Super + V`           | הדבקה    |
| `Super + Ctrl + V`           | מנהל לוח העתקה    |

בדרך כלל ב-Linux, צריך `Ctrl + Shift + C/V` כדי להעתיק ולהדביק במסוף ו-`Ctrl + C/V` כדי לעשות זאת בכל מקום אחר. מקשי הקיצור המאוחדים האלה של לוח ההעתקה של Omarchy עובדים בכל מקום.

## Tmux

מקש הקידומת הוא `Ctrl + Space` (גם `Ctrl + B` עובד). תוכלו לשנות קישורים אלה ב-`~/.config/tmux/tmux.conf`.

### חלוניות

| מקש קיצור                  | תפקיד              |
| ----------------------- | --------------------- |
| `Prefix + v` | פיצול חלונית לצד (אנכי) |
| `Prefix + h` | פיצול חלונית למטה (אופקי) |
| `Prefix + x` | סגירת חלונית |
| `Prefix + z` | החלפת מצב הגדלת חלונית (מסך מלא) |
| `Alt + Enter` | פיצול חלונית למטה (ללא קידומת) |
| `Alt + Shift + Enter` | פיצול חלונית לצד (ללא קידומת) |
| `Alt + Escape` | סגירת חלונית (ללא קידומת) |
| `Ctrl + Alt + Arrows` | מעבר בין חלוניות |
| `Ctrl + Alt + Shift + Arrows` | שינוי גודל חלוניות |

### חלונות
