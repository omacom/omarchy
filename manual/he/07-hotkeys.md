# קיצורי מקלדת

אפשר לראות את כל קיצורי המקלדת העיקריים עם `Super + K` (קיצורי Tmux עם `Super + Alt + K` וקיצורי Herdr עם `Super + Ctrl + K`).

## איך קיצורי המקלדת מסודרים

כל קיצור מקלדת יושב על מישור, שנקבע לפי המקשים המלווים שלו, ולכל מישור יש תפקיד אחד. זה מה שמונע מהקיצורים להתערבב זה בזה, וזה אומר שבדרך כלל אפשר לנחש איפה משהו נמצא.

| מישור | מה נמצא שם | דוגמאות |
| --- | --- | --- |
| `Super + key` | המערכת: חלונות, סביבות עבודה, פריסות ותפריטי ליבה | `Super + Space` תפריט Omarchy, `Super + W` סגירת חלון, `Super + F` מסך מלא |
| `Super + Shift + key` | אפליקציות | `Super + Shift + B` דפדפן, `Super + Shift + E` דוא"ל, `Super + Shift + N` עורך |
| `Super + Ctrl + key` | פאנלים ותפריטי מערכת | `Super + Ctrl + A` שמע, `Super + Ctrl + N` רשת, `Super + Ctrl + C` תפריט לכידה |
| `Super + Ctrl + Alt + key` | פעולות מהירות והודעות | `Super + Ctrl + Alt + T` הצגת השעה, `Super + Ctrl + Alt + B` סוללה, `Super + Ctrl + Alt + C` צילום מסך |

הוספת `Alt` לקיצור מקלדת נותנת לך גרסה של אותו הדבר, אף פעם לא משהו לא קשור:

- `Super + Shift + B` פותח את הדפדפן; `Super + Shift + Alt + B` פותח חלון פרטי
- `Super + Shift + E` פותח דוא"ל; `Super + Shift + Alt + E` מתחיל דוא"ל חדש
- `Super + F` עובר למסך מלא; `Super + Alt + F` עובר לרוחב מלא
- `Super + Ctrl + C` פותח את תפריט הלכידה; `Super + Ctrl + Alt + C` מדלג על התפריט ומצלם צילום מסך

כשמוסיפים קיצור מקלדת:

1. בחרו את המישור לפי מה שהוא עושה, ואז בחרו את המקש.
2. אל תזיזו קיצור קיים כדי לפנות מקום. מצאו מקש פנוי במישור הנכון.
3. השתמשו ב-`Alt` רק לגרסה של הקיצור בלעדיו.

כמה קיצורים שוברים את הכללים האלה כי הם נוחים. `Shift` עם חץ או `Tab` מזיז או הופך כיוון במקום לפתוח אפליקציה, ו-`Print`, מקשי המדיה, `Alt + Tab` ו-`Ctrl + Alt + Del` עובדים כמו בכל מקום אחר. הם חריגים, לא דפוסים שצריך להעתיק.

אם ברירת מחדל לא מתאימה לך (נניח שאתה רוצה `Super + Shift + S` לצילומי מסך כמו ב-Windows), קשר אותה מחדש ב-`~/.config/hypr/bindings.lua`.

קיצורי שינוי הגודל משתמשים במקשים הפיזיים `code:20` ו-`code:21` (‏XKB‏ `<AE11>` ו-`<AE12>`), ללא קשר לתווים המודפסים על המקלדת. במקלדות US מקשים אלה הם `-` ו-`=`; במקלדות יפניות (JIS) הם `-` ו-`^`; במקלדות ספרדיות הם `'` ו-`¡`. ב-JIS,‏ `Super + ^` הוא `Super + Equal`, בעוד `Super + Shift + -` (שמקליד `=`) הוא `Super + Shift + Minus`.

## לוח העתקה אוניברסלי

| קיצור | פעולה |
| ----------------------- | --------------------- |
| `Super + A` | בחירת הכול באפליקציות שתומכות ב-`Ctrl + A` |
| `Super + C` | העתקה |
| `Super + X` | גזירה (לא במסוף) |
| `Super + V` | הדבקה |
| `Super + Ctrl + V` | מנהל לוח העתקה |

בדרך כלל ב-Linux, צריך `Ctrl + Shift + C/V` כדי להעתיק ולהדביק במסוף ו-`Ctrl + C/V` כדי לעשות זאת בכל מקום אחר. מקשי לוח ההעתקה המאוחדים האלה של Omarchy עובדים בכל מקום.
