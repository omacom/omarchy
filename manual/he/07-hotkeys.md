# מקשי קיצור

ניתן לראות את כל קיצורי המקלדת הראשיים עם `Super + K` (קיצורי Tmux עם `Super + Alt + K` וקיצורי Herdr עם `Super + Ctrl + K`).

## ניווט

| מקש קיצור                  | פונקציה              |
| ----------------------- | --------------------- |
| `Super + Space`           | תפריט Omarchy (אפליקציות וכל השאר)    |
| `Super + Alt + Space` | רשת האפליקציות |
| `Super + Escape` | תפריט מערכת (השהיה, הפעלה מחדש וכו')  |

| `Super + L`               | מעבר בין פריסות dwindle, גלילה וציפה |

| `Super + Ctrl + Alt + Z` | הקטנת תצוגת המסך לגמרי |

| `Super + Alt + /` | מעבר אחורה בין אפשרויות קנה המידה של המסך |
| `Alt + Tab` | מעבר קדימה בין חלונות בסביבת העבודה הפעילה |

| `Ctrl + Alt + Shift + Tab`| מעבר מיקוד אחורה בין מסכים |

קיצורי שינוי הגודל משתמשים במקשים הפיזיים `code:20` ו-`code:21` (‏XKB‏ `<AE11>` ו-`<AE12>`), בלי קשר לתווים המודפסים על המקלדת. במקלדות US מקשים אלה הם `-` ו-`=`; במקלדות יפניות (JIS) הם `-` ו-`^`; במקלדות ספרדיות הם `'` ו-`¡`. במקלדות JIS, `Super + ^` הוא `Super + Equal`, בעוד `Super + Shift + -` (שמקליד `=`) הוא `Super + Shift + Minus`.

## לוח העתקה אוניברסלי

| מקש קיצור                  | פונקציה              |
| ----------------------- | --------------------- |
| `Super + A`           | בחירת הכול באפליקציות שתומכות ב-`Ctrl + A`    |
| `Super + C`           | העתקה    |
| `Super + X`           | גזירה (לא במסוף)    |
| `Super + V`           | הדבקה    |
| `Super + Ctrl + V`           | מנהל לוח העתקה    |

בדרך כלל ב-Linux צריך `Ctrl + Shift + C/V` כדי להעתיק ולהדביק במסוף ו-`Ctrl + C/V` כדי לעשות זאת בכל מקום אחר. מקשי לוח ההעתקה המאוחדים האלה של Omarchy עובדים בכל מקום.

## Tmux

| ----------------------- | --------------------- |
| `Prefix + v` | פיצול חלונית לצד (אנכי) |

## Neovim (עם lazyvim)

### ניווט

| מקש קיצור                   | פונקציה                        |
| ------------------------ | ------------------------------- |
| `Space`                    | הצגת אפשרויות פקודה            |
| `Space Space`              | פתיחת קובץ באמצעות חיפוש מטושטש      |
| `Space E`                  | החלפת סרגל הצד                  |
| `Space G G`                | הצגת בקרות git               |
| `Space S G`                | חיפוש בתוכן הקובץ             |
| `Ctrl + W W`               | קפיצה בין סרגל הצד לעורך |
| `Ctrl + Left/right arrow`  | שינוי גודל סרגל הצד          |
| `Shift + H`                      | מעבר ללשונית הקובץ השמאלית             |
| `Shift + L`                      | מעבר ללשונית הקובץ הימנית            |
| `Space B D`                | סגירת לשונית קובץ                  |

### כשנמצאים בסרגל הצד

| מקש קיצור                   | פונקציה                        |
| ------------------------ | ------------------------------- |
| `A`                        | הוספת קובץ חדש בתיקיית האב      |
| `Shift + A`                | הוספת תת-תיקייה חדשה בתיקיית האב    |
| `D`                        | מחיקת הקובץ/התיקייה המודגשים     |
| `M`                        | העברת הקובץ/התיקייה המודגשים       |
| `R`                        | שינוי שם הקובץ/התיקייה המודגשים     |
| `?`                        | הצגת עזרה לכל הפקודות      |

[ראו את כל מקשי הקיצור של Neovim שמוגדרים על ידי LazyVim](https://www.lazyvim.org/keymaps).

## השלמות מהירות

| מקש קיצור       | השלמה       |
| ------------ |  ---------- |
| `Shift + CapsLock Space Space` | — (mdash)   |
| `Shift + CapsLock Space N` | השם שלכם (כפי שהוזן בהגדרה)  |
| `Shift + CapsLock Space E` | הדוא"ל שלכם (כפי שהוזן בהגדרה)  |

ניתן להוסיף עוד משלכם על ידי עריכת `~/.XCompose`, ואז הרצת `omarchy-restart-xcompose` במסוף כדי שהשינויים ייקלטו.
