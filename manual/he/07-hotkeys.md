# מקשי קיצור

אפשר לראות את כל קיצורי המקלדת הראשיים עם `Super + K` (קיצורי Tmux עם `Super + Alt + K` וקיצורי Herdr עם `Super + Ctrl + K`).

## איך מקשי הקיצור מסודרים

כל מקש קיצור נמצא על מישור, שנקבע לפי המקשים המלווים שלו, ולכל מישור יש תפקיד אחד. זה מה שמונע ממקשי הקיצור להתערבב זה בזה, וזה אומר שבדרך כלל אפשר לנחש איפה משהו נמצא.

| מישור | מה נמצא שם | דוגמאות |
| --- | --- | --- |
| `Super + key` | המערכת: חלונות, סביבות עבודה, פריסות ותפריטים מרכזיים | `Super + Space` תפריט Omarchy, `Super + W` סגירת חלון, `Super + F` מסך מלא |
| `Super + Shift + key` | אפליקציות | `Super + Shift + B` דפדפן, `Super + Shift + E` דוא"ל, `Super + Shift + N` עורך |
| `Super + Ctrl + key` | לוחות ותפריטי מערכת | `Super + Ctrl + A` שמע, `Super + Ctrl + N` רשת, `Super + Ctrl + C` תפריט לכידה |
| `Super + Ctrl + Alt + key` | פעולות מהירות והודעות | `Super + Ctrl + Alt + T` הצגת השעה, `Super + Ctrl + Alt + B` סוללה, `Super + Ctrl + Alt + C` צילום מסך |

הוספת `Alt` למקש קיצור נותנת גרסה אחרת של אותו דבר, אף פעם לא משהו לא קשור:

- `Super + Shift + B` פותח את הדפדפן; `Super + Shift + Alt + B` פותח חלון פרטי
- `Super + Shift + E` פותח דוא"ל; `Super + Shift + Alt + E` מתחיל דוא"ל חדש
- `Super + F` עובר למסך מלא; `Super + Alt + F` עובר לרוחב מלא
- `Super + Ctrl + C` פותח את תפריט הלכידה; `Super + Ctrl + Alt + C` מדלג על התפריט ומצלם צילום מסך

כשמוסיפים מקש קיצור:

1. בחרו את המישור לפי מה שהוא עושה, ואז בחרו את המקש.
2. אל תזיזו מקש קיצור קיים כדי לפנות מקום. מצאו מקש פנוי במישור הנכון.
3. השתמשו ב-`Alt` רק לגרסה אחרת של מקש הקיצור בלעדיו.

כמה מקשי קיצור שוברים את הכללים האלה כי זה נוח. `Shift` עם חץ או `Tab` מזיז או הופך כיוון במקום לפתוח אפליקציה, ו-`Print`, מקשי המדיה, `Alt + Tab` ו-`Ctrl + Alt + Del` עובדים כמו בכל מקום אחר. הם יוצאים מן הכלל, לא דפוסים שצריך להעתיק.

אם ברירת מחדל לא מתאימה לכם (למשל אתם רוצים `Super + Shift + S` לצילומי מסך כמו ב-Windows), שנו את הקיצור ב-`~/.config/hypr/bindings.lua`.

במשטח מגע, החלקות בשלוש ובארבע אצבעות מחליפות סביבות עבודה, מזיזות חלונות ופותחות את התפריט ואת קונסולת Quake; ראו [מקלדת, עכבר ומשטח מגע](34-keyboard-mouse-trackpad.md) למחוות.

שינוי הגודל משתמש בשני המקשים שמימין ל-0, מה שהמקלדת שלכם מדפיסה עליהם: `-` ו-`=` במקלדות אמריקאיות, `+` ו-`´` בדנית ובשוודית, `+` ו-`\` בנורווגית, `ß` ו-`´` בגרמנית, `'` ו-`¡` בספרדית, ו-`-` ו-`^` ביפנית (JIS). `Super + K` מציג אותם כפי שהם מודפסים על המקלדת שלכם. ב-JIS, `Super + ^` הוא `Super + Equal`, בעוד `Super + Shift + -` (שמקליד `=`) הוא `Super + Shift + Minus`. קנה המידה של הצג ומנהל הסיסמאות משתמשים ב-`/`; בפריסות שבהן מקלידים `/` רק עם Shift, כמו רוב הפריסות האירופיות, הם משתמשים במקום זאת במקש שמשמאל ל-Shift הימני (`-` בדנית ובגרמנית).

| מקש קיצור | פעולה |

## Tmux

מקש הקידומת הוא `Ctrl + Space` (גם `Ctrl + B` עובד). אפשר לשנות קיצורים אלה ב-`~/.config/tmux/tmux.conf`.

### חלוניות

| מקש קיצור | פעולה |
| ----------------------- | --------------------- |
| `Prefix + v` | פיצול חלונית לצד (אנכי) |
| `Prefix + h` | פיצול חלונית מתחת (אופקי) |
| `Prefix + x` | סגירת חלונית |
| `Prefix + z` | החלפת הגדלת חלונית (מסך מלא) |
| `Alt + Enter` | פיצול חלונית מתחת (בלי קידומת) |
| `Alt + Shift + Enter` | פיצול חלונית לצד (בלי קידומת) |
| `Alt + Escape` | סגירת חלונית (בלי קידומת) |
| `Ctrl + Alt + Arrows` | מעבר בין חלוניות |
| `Ctrl + Alt + Shift + Arrows` | שינוי גודל חלוניות |

### חלונות

| מקש קיצור | פעולה |
| ----------------------- | --------------------- |
