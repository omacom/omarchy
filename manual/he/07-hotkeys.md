# מקשי קיצור

ניתן לראות את כל צירופי המקשים העיקריים עם `Super + K` (צירופי Tmux עם `Super + Alt + K` וצירופי Herdr עם `Super + Ctrl + K`).

## כיצד מקשי הקיצור מסודרים

כל מקש קיצור נמצא על מישור, שנקבע לפי מקשי השינוי שלו, ולכל מישור יש תפקיד אחד. זה מה שמונע ממקשי הקיצור להתערבב זה בזה, וזה אומר שבדרך כלל אפשר לנחש היכן משהו נמצא.

| מישור | מה נמצא שם | דוגמאות |
| --- | --- | --- |
| `Super + key` | המערכת: חלונות, מרחבי עבודה, פריסות ותפריטי ליבה | `Super + Space` תפריט Omarchy, `Super + W` סגירת חלון, `Super + F` מסך מלא |
| `Super + Shift + key` | יישומים | `Super + Shift + B` דפדפן, `Super + Shift + E` דוא"ל, `Super + Shift + N` עורך |
| `Super + Ctrl + key` | פאנלים ותפריטי מערכת | `Super + Ctrl + A` שמע, `Super + Ctrl + N` רשת, `Super + Ctrl + C` תפריט לכידה |
| `Super + Ctrl + Alt + key` | פעולות מהירות והודעות | `Super + Ctrl + Alt + T` הצגת השעה, `Super + Ctrl + Alt + B` סוללה, `Super + Ctrl + Alt + C` צילום מסך |

הוספת `Alt` למקש קיצור נותנת גרסה של אותו הדבר בדיוק, אף פעם לא משהו לא קשור:

- `Super + Shift + B` פותח את הדפדפן; `Super + Shift + Alt + B` פותח חלון פרטי
- `Super + Shift + E` פותח דוא"ל; `Super + Shift + Alt + E` מתחיל דוא"ל חדש
- `Super + F` עובר למסך מלא; `Super + Alt + F` עובר לרוחב מלא
- `Super + Ctrl + C` פותח את תפריט הלכידה; `Super + Ctrl + Alt + C` מדלג על התפריט ומצלם צילום מסך

כשמוסיפים מקש קיצור:

1. בחרו את המישור לפי מה שהוא עושה, ואז בחרו את המקש.
2. אל תזיזו מקש קיצור קיים כדי לפנות מקום. מצאו מקש פנוי במישור הנכון.
3. השתמשו ב-`Alt` רק עבור גרסה של מקש הקיצור שבלעדיו.

כמה מקשי קיצור מפרים את הכללים האלה כי זה נוח. `Shift` עם חץ או `Tab` מזיז או הופך כיוון במקום לפתוח יישום, ו-`Print`, מקשי המדיה, `Alt + Tab` ו-`Ctrl + Alt + Del` עובדים כמו שהם עובדים בכל מקום אחר. הם חריגים, לא דפוסים שצריך להעתיק.

אם ברירת מחדל לא מתאימה לכם (למשל אתם רוצים את `Super + Shift + S` לצילומי מסך כמו ב-Windows), שנו את הצירוף ב-`~/.config/hypr/bindings.lua`.

קיצורי שינוי הגודל משתמשים במקשים הפיזיים `code:20` ו-`code:21` (‏XKB `<AE11>` ו-`<AE12>`), ללא קשר לתווים המודפסים על המקלדת. במקלדות אמריקאיות המקשים האלה הם `-` ו-`=`; במקלדות יפניות (JIS) הם `-` ו-`^`; במקלדות ספרדיות הם `'` ו-`¡`. ב-JIS,‏ `Super + ^` הוא `Super + Equal`, בעוד ש-`Super + Shift + -` (שמקליד `=`) הוא `Super + Shift + Minus`.

## לוח העתקה אוניברסלי

| מקש קיצור                  | פעולה              |
| ----------------------- | --------------------- |
| `Super + A`           | בחירת הכל ביישומים שתומכים ב-`Ctrl + A`    |
| `Super + C`           | העתקה    |
| `Super + X`           | גזירה (לא במסוף)    |
| `Super + V`           | הדבקה    |
| `Super + Ctrl + V`           | מנהל לוח העתקה    |

בדרך כלל ב-Linux, צריך `Ctrl + Shift + C/V` כדי להעתיק ולהדביק במסוף ו-`Ctrl + C/V` כדי לעשות זאת בכל מקום אחר. מקשי הקיצור המאוחדים האלה של Omarchy ללוח ההעתקה עובדים בכל מקום.
