# מקשי קיצור

ניתן לראות את כל קיצורי המקלדת העיקריים עם `Super + K` (קיצורי Tmux עם `Super + Alt + K` וקיצורי Herdr עם `Super + Ctrl + K`).

## איך מקשי הקיצור מסודרים

כל מקש קיצור נמצא על מישור, שנקבע לפי המקשים הנלווים שלו, ולכל מישור יש תפקיד אחד. זה מה שמונע ממקשי הקיצור להתערבב זה בזה, וזה אומר שבדרך כלל אפשר לנחש איפה משהו נמצא.

| מישור | מה נמצא שם | דוגמאות |
| --- | --- | --- |
| `Super + key` | המערכת: חלונות, סביבות עבודה, פריסות ותפריטי ליבה | `Super + Space` תפריט Omarchy, `Super + W` סגירת חלון, `Super + F` מסך מלא |
| `Super + Shift + key` | אפליקציות | `Super + Shift + B` דפדפן, `Super + Shift + E` דוא"ל, `Super + Shift + N` עורך |
| `Super + Ctrl + key` | פאנלים ותפריטי מערכת | `Super + Ctrl + A` שמע, `Super + Ctrl + N` רשת, `Super + Ctrl + C` תפריט צילום |
| `Super + Ctrl + Alt + key` | פעולות מהירות והודעות | `Super + Ctrl + Alt + T` הצגת שעה, `Super + Ctrl + Alt + B` סוללה, `Super + Ctrl + Alt + C` צילום מסך |

הוספת `Alt` למקש קיצור נותנת לך וריאנט של אותו הדבר, אף פעם לא משהו לא קשור:

- `Super + Shift + B` פותח את הדפדפן; `Super + Shift + Alt + B` פותח חלון פרטי
- `Super + Shift + E` פותח דוא"ל; `Super + Shift + Alt + E` מתחיל דוא"ל חדש
- `Super + F` עובר למסך מלא; `Super + Alt + F` עובר לרוחב מלא
- `Super + Ctrl + C` פותח את תפריט הצילום; `Super + Ctrl + Alt + C` מדלג על התפריט ומצלם צילום מסך

כשמוסיפים מקש קיצור:

1. בחר את המישור לפי מה שהוא עושה, ואז בחר את המקש.
2. אל תזיז מקש קיצור קיים כדי לפנות מקום. מצא מקש פנוי במישור הנכון.
3. השתמש ב-`Alt` רק עבור וריאנט של מקש הקיצור בלעדיו.

כמה מקשי קיצור שוברים את הכללים האלה כי זה נוח. `Shift` עם חץ או `Tab` מזיז או הופך כיוון במקום לפתוח אפליקציה, ו-`Print`, מקשי המדיה, `Alt + Tab` ו-`Ctrl + Alt + Del` עובדים כמו בכל מקום אחר. הם חריגים, לא דפוסים להעתקה.

אם ברירת מחדל לא מתאימה לך (נניח שאתה רוצה `Super + Shift + S` לצילומי מסך כמו ב-Windows), קשור אותו מחדש ב-`~/.config/hypr/bindings.lua`.

במשטח מגע, החלקות בשלוש ובארבע אצבעות מחליפות סביבות עבודה, מזיזות חלונות ופותחות את התפריט ואת קונסולת Quake; ראה [מקלדת, עכבר ומשטח מגע](34-keyboard-mouse-trackpad.md) למחוות.

קיצורי שינוי גודל משתמשים במקשים פיזיים `code:20` ו-`code:21` (XKB `<AE11>` ו-`<AE12>`), ללא קשר לתווים המודפסים על המקלדת. במקלדות US מקשים אלה הם `-` ו-`=`; במקלדות יפניות (JIS) הם `-` ו-`^`; במקלדות ספרדיות הם `'` ו-`¡`. ב-JIS, `Super + ^` הוא `Super + Equal`, בעוד `Super + Shift + -` (שמקליד `=`) הוא `Super + Shift + Minus`.

## Tmux

מקש הקידומת הוא `Ctrl + Space` (`Ctrl + B` גם עובד). ניתן לשנות קישורים אלה ב-`~/.config/tmux/tmux.conf`.

### חלוניות

| מקש קיצור | פונקציה |
| ----------------------- | --------------------- |
| `Prefix + v` | פיצול חלונית לצד (אנכי) |
| `Prefix + h` | פיצול חלונית מתחת (אופקי) |
| `Prefix + x` | סגירת חלונית |
| `Prefix + z` | מעבר של הגדלת חלונית (מסך מלא) |
| `Alt + Enter` | פיצול חלונית מתחת (בלי קידומת) |
| `Alt + Shift + Enter` | פיצול חלונית לצד (בלי קידומת) |
| `Alt + Escape` | סגירת חלונית (בלי קידומת) |
| `Ctrl + Alt + Arrows` | מעבר בין חלוניות |
| `Ctrl + Alt + Shift + Arrows` | שינוי גודל חלוניות |

### חלונות

| מקש קיצור | פונקציה |
| ----------------------- | --------------------- |
| `Prefix + c` | חלון חדש |
| `Prefix + k` | סגירת חלון |
| `Prefix + r` | שינוי שם חלון |
| `Alt + 1-9` | מעבר לחלון ספציפי |
| `Alt + Arrow Left/Right` | מעבר בין חלונות |
| `Alt + Shift + Arrow Left/Right` | הזזת חלון שמאלה/ימינה |

### הפעלות

| מקש קיצור | פונקציה |
| ----------------------- | --------------------- |
| `Prefix + C` | הפעלה חדשה |
| `Prefix + K` | סגירת הפעלה |
| `Prefix + R` | שינוי שם הפעלה |
| `Prefix + N` | ההפעלה הבאה |
| `Prefix + P` | ההפעלה הקודמת |
| `Alt + Arrow Up/Down` | מעבר בין הפעלות |
| `Prefix + s` | רשימת הפעלות |
| `Prefix + d` | ניתוק מהפעלה |

### מצב העתקה (בסגנון vi)

| מקש קיצור | פונקציה |
| ----------------------- | --------------------- |
| `Prefix + [` | כניסה למצב העתקה |
| `v` | התחלת בחירה (במצב העתקה) |
| `y` | העתקת בחירה (במצב העתקה) |

### כללי

| מקש קיצור | פונקציה |
| ----------------------- | --------------------- |
| `Prefix + q` | טעינה מחדש של התצורה |
| `Prefix + ?` | הצגת קיצורי המקלדת של Tmux |
| `Prefix + :` | שורת פקודה |

### פונקציות פריסת Tmux

פונקציות אלה חייבות לרוץ בתוך הפעלת Tmux.

| פקודה | פונקציה |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | יצירת פריסת פיתוח עם עורך, AI ומסוף |
| `tdlm <ai> [<second_ai>]` | יצירת פריסת פיתוח לכל תת-תיקייה |
| `tsl <count> <command>` | יצירת פריסת נחיל מרובת חלוניות |

| `Super + Ctrl + Shift + Arrows` | שינוי גודל פיצול ב-10 שורות |

| `Ctrl + Shift + Arrows` | מעבר בין לשוניות |
