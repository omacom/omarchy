# מקשי קיצור

תוכלו לראות את כל כריכות המקלדת הראשיות עם `Super + K` (כריכות Tmux עם `Super + Alt + K` וכריכות Herdr עם `Super + Ctrl + K`).

## איך מקשי הקיצור מסודרים

כל מקש קיצור יושב על מישור, שנקבע לפי המקשים הנלווים שלו, ולכל מישור יש תפקיד אחד. זה מה שמונע ממקשי הקיצור להתערבב זה בזה, וזה אומר שבדרך כלל תוכלו לנחש איפה משהו נמצא.

| מישור | מה נמצא שם | דוגמאות |
| --- | --- | --- |
| `Super + key` | המערכת: חלונות, סביבות עבודה, פריסות ותפריטי ליבה | `Super + Space` תפריט Omarchy, `Super + W` סגירת חלון, `Super + F` מסך מלא |
| `Super + Shift + key` | אפליקציות | `Super + Shift + B` דפדפן, `Super + Shift + E` דוא"ל, `Super + Shift + N` עורך |
| `Super + Ctrl + key` | פאנלים ותפריטי מערכת | `Super + Ctrl + A` שמע, `Super + Ctrl + N` רשת, `Super + Ctrl + C` תפריט לכידה |
| `Super + Ctrl + Alt + key` | פעולות מהירות והודעות | `Super + Ctrl + Alt + T` הצגת השעה, `Super + Ctrl + Alt + B` סוללה, `Super + Ctrl + Alt + C` צילום מסך |

הוספת `Alt` למקש קיצור נותנת לכם גרסה של אותו הדבר, אף פעם לא משהו לא קשור:

- `Super + Shift + B` פותח את הדפדפן; `Super + Shift + Alt + B` פותח חלון פרטי
- `Super + Shift + E` פותח דוא"ל; `Super + Shift + Alt + E` מתחיל דוא"ל חדש
- `Super + F` עובר למסך מלא; `Super + Alt + F` עובר לרוחב מלא
- `Super + Ctrl + C` פותח את תפריט הלכידה; `Super + Ctrl + Alt + C` מדלג על התפריט ומצלם צילום מסך

כשמוסיפים מקש קיצור:

1. בחרו את המישור לפי מה שהוא עושה, ואז בחרו את המקש.
2. אל תזיזו מקש קיצור קיים כדי לפנות מקום. מצאו מקש פנוי במישור הנכון.
3. השתמשו ב-`Alt` רק לגרסה של מקש הקיצור בלעדיו.

כמה מקשי קיצור שוברים את הכללים האלה כי זה נוח. `Shift` עם חץ או `Tab` מזיז או הופך כיוון במקום לפתוח אפליקציה, ו-`Print`, מקשי המדיה, `Alt + Tab` ו-`Ctrl + Alt + Del` עובדים כמו בכל מקום אחר. אלה חריגים, לא דפוסים להעתקה.

אם ברירת מחדל לא מתאימה לכם (למשל אם אתם רוצים `Super + Shift + S` לצילומי מסך כמו ב-Windows), כירכו אותו מחדש ב-`~/.config/hypr/bindings.lua`.

במשטח מגע, החלקות בשלוש ובארבע אצבעות מחליפות סביבות עבודה, מזיזות חלונות ופותחות את התפריט ואת קונסולת Quake; ראו [מקלדת, עכבר ומשטח מגע](34-keyboard-mouse-trackpad.md) למחוות.

קיצורי שינוי הגודל משתמשים במקשים הפיזיים `code:20` ו-`code:21` (‏XKB `<AE11>` ו-`<AE12>`), בלי קשר לתווים המודפסים על המקלדת. במקלדות US המקשים האלה הם `-` ו-`=`; במקלדות יפניות (JIS) הם `-` ו-`^`; במקלדות ספרדיות הם `'` ו-`¡`. ב-JIS, `Super + ^` הוא `Super + Equal`, בעוד `Super + Shift + -` (שמקליד `=`) הוא `Super + Shift + Minus`.

## Tmux

מקש הקידומת הוא `Ctrl + Space` (גם `Ctrl + B` עובד). תוכלו לשנות את הכריכות האלה ב-`~/.config/tmux/tmux.conf`.

### חלוניות

| מקש קיצור                  | פעולה              |
| ----------------------- | --------------------- |
| `Prefix + v` | פיצול חלונית לצד (אנכי) |
| `Prefix + h` | פיצול חלונית מתחת (אופקי) |
| `Prefix + x` | סגירת חלונית |
| `Prefix + z` | החלפת הגדלת חלונית (מסך מלא) |
| `Alt + Enter` | פיצול חלונית מתחת (בלי קידומת) |
| `Alt + Shift + Enter` | פיצול חלונית לצד (בלי קידומת) |
| `Alt + Escape` | סגירת חלונית (בלי קידומת) |
| `Ctrl + Alt + Arrows` | מעבר בין חלוניות |
| `Ctrl + Alt + Shift + Arrows` | שינוי גודל חלוניות |

### חלונות

| מקש קיצור                  | פעולה              |
| ----------------------- | --------------------- |
| `Prefix + c` | חלון חדש |
| `Prefix + k` | סגירת חלון |
| `Prefix + r` | שינוי שם חלון |
| `Alt + 1-9` | מעבר לחלון מסוים |
| `Alt + Arrow Left/Right` | מעבר בין חלונות |
| `Alt + Shift + Arrow Left/Right` | הזזת חלון שמאלה/ימינה |

### הפעלות

| מקש קיצור                  | פעולה              |
| ----------------------- | --------------------- |

| `Prefix + K` | סגירת הפעלה |
| `Prefix + R` | שינוי שם הפעלה |
| `Prefix + N` | ההפעלה הבאה |
| `Prefix + P` | ההפעלה הקודמת |

| `Prefix + s` | רשימת הפעלות |

### מצב העתקה (בסגנון vi)

| מקש קיצור                  | פעולה              |
| ----------------------- | --------------------- |

### כללי

| מקש קיצור                  | פעולה              |
| ----------------------- | --------------------- |
| `Prefix + q` | טעינה מחדש של התצורה |
| `Prefix + ?` | הצגת כריכות המקשים של Tmux |
| `Prefix + :` | שורת פקודה |

### פונקציות פריסה של Tmux

יש להפעיל את הפונקציות האלה בתוך הפעלת Tmux.

| פקודה | פעולה |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | יצירת פריסת פיתוח עם עורך, AI ומסוף |
| `tdlm <ai> [<second_ai>]` | יצירת פריסת פיתוח לכל תת-ספרייה |
| `tsl <count> <command>` | יצירת פריסת swarm מרובת חלוניות |
