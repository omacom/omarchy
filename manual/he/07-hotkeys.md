# מקשי קיצור

אפשר לראות את כל צירופי המקשים העיקריים עם `Super + K` (צירופי Tmux עם `Super + Alt + K` וצירופי Herdr עם `Super + Ctrl + K`).

## ניווט

| מקש קיצור                  | פעולה              |
| ----------------------- | --------------------- |
| `Super + Space`           | תפריט Omarchy (אפליקציות וכל השאר)    |
| `Super + Alt + Space` | רשת האפליקציות |
| `Super + Escape` | תפריט מערכת (השהיה, הפעלה מחדש וכו')  |
| `Super + Ctrl + L` | נעילת המחשב |
| `Super + W` or `Super + Q` | סגירת חלון             |
| `Ctrl + Alt + Del` | סגירת כל החלונות |
| `Super + T`               | מעבר של חלון בין ריצוף/ציפה             |
| `Super + J` | מעבר בין מיקום חלון (אופקי/אנכי) |
| `Super + O`               | הפעלה/כיבוי של הצמדת חלון במצב sticky'n'floating |
| `Super + L`               | מעבר בין פריסות dwindle, scrolling ו-floating |
| `Super + Alt + L`         | מעבר בין הפריסות בסדר הפוך |
| `Super + P`               | הפעלה/כיבוי של סגנון חלון pseudo (טבעי מול מתוח) |
| `Super + F`                 | מעבר למסך מלא              |
| `Super + Alt + F`                 | מעבר לרוחב מלא              |
| `Super + Ctrl + F`                 | מעבר למסך מלא בתוך החלון              |
| `Super + 1/2/3/4`         | קפיצה לסביבת עבודה מסוימת בצג שבמוקד |
| `Super + Tab` | קפיצה לסביבת העבודה הבאה בצג שבמוקד |
| `Super + Shift + Tab` | קפיצה לסביבת העבודה הקודמת בצג שבמוקד |
| `Super + Ctrl + Tab` | קפיצה לסביבת העבודה הקודמת שהייתם בה בצג שבמוקד |
| `Super + Shift + 1/2/3/4` | העברת חלון לסביבת עבודה בצג שבמוקד |
| `Super + Shift + Alt + 1/2/3/4` | העברת חלון לסביבת עבודה בצג שבמוקד בלי לעקוב אחריו |
| `Super + S` | הפעלה/כיבוי של scratchpad מלא |
| `Super + Alt + S` | העברת חלון ל-scratchpad מלא |
| `Super + Grave` | הפעלה/כיבוי של קונסולת Quake |
| `Super + Shift + Grave` | העברת חלון לקונסולת Quake |
| `Super + Shift + Ctrl + Arrows` | העברת חלון לצג שבאותו כיוון |
| `Super + Shift + Alt + Arrows` | העברת סביבת עבודה לצג שבאותו כיוון |
| `Super + Arrow`  | העברת המוקד לחלון בכיוון החץ, עם מעבר לצג שבאותו צד בקצה המסך |
| `Super + Shift + Arrow`  | החלפת חלון עם חלון אחר בכיוון החץ, כולל חלון בצג שבאותו צד |
| `Super + Minus` | הרחבת חלון שמאלה |
| `Super + Equal` | כיווץ חלון שמאלה |
| `Super + Shift + Minus` | כיווץ חלון למעלה |
| `Super + Shift + Equal` | הרחבת חלון למטה |
| `Super + Alt + Minus/Equal` | אותו שינוי גודל בצעדים קטנים יותר |
| `Super + Ctrl + Minus/Equal` | אותו שינוי גודל בצעדים גדולים יותר |
| `Super + Alt + Home` | שמירת רוחב החלון |
| `Super + Home` | שחזור רוחב החלון השמור |
| `Super + Left Mouse` | גרירת חלון ממקום למקום |
| `Super + Right Mouse` | שינוי גודל חלון |
| `Super + Scroll Wheel` | גלילה בין סביבות עבודה בצג שבמוקד |
| `Super + G`               | הפעלה/כיבוי של קיבוץ חלונות      |
| `Super + Alt + G`               | הוצאת חלון מהקיבוץ      |
| `Super + Alt + Tab`               | מעבר בין חלונות בקיבוץ      |
| `Super + Alt + Shift + Tab`               | מעבר אחורה בין חלונות בקיבוץ      |
| `Super + Alt + Scroll Wheel` | מעבר בין חלונות בקיבוץ |
| `Super + Alt + 1/2/3/4/5`               | קפיצה לחלון מסוים בקיבוץ      |
| `Super + Alt + Arrow`  | העברת חלון לתוך קיבוץ בכיוון החץ, כולל חלון בצג שבאותו צד |
| `Super + Ctrl + Left/Right`  | מעבר בין חלונות בתוך קבוצת ריצוף |
| `Super + Ctrl + Z` | התקרבות למסך (חזרה על הפעולה מגדילה את הזום) |
| `Super + Ctrl + Alt + Z` | התרחקות מלאה מהמסך |
| `Super + /` | מעבר קדימה בין אפשרויות קנה המידה של הצג |
| `Super + Alt + /` | מעבר אחורה בין אפשרויות קנה המידה של הצג |
| `Alt + Tab` | מעבר קדימה בין חלונות בסביבת העבודה הפעילה |
| `Alt + Shift + Tab` | מעבר אחורה בין חלונות בסביבת העבודה הפעילה |
| `Ctrl + Alt + Tab`| מעבר המוקד קדימה בין צגים |
| `Ctrl + Alt + Shift + Tab`| מעבר המוקד אחורה בין צגים |

## לוח העתקה אוניברסלי

| מקש קיצור                  | פעולה              |
| ----------------------- | --------------------- |
| `Super + C`           | העתקה    |
| `Super + X`           | גזירה (לא בטרמינל)    |
| `Super + V`           | הדבקה    |
| `Super + Ctrl + V`           | מנהל לוח ההעתקה    |

בדרך כלל ב-Linux צריך `Ctrl + Shift + C/V` כדי להעתיק ולהדביק בטרמינל ו-`Ctrl + C/V` כדי לעשות זאת בכל מקום אחר. מקשי לוח ההעתקה המאוחדים האלה של Omarchy עובדים בכל מקום.

## לכידה

| מקש קיצור              | פעולה                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | צילום מסך                      |
| `Super + Ctrl + Alt + C`            | צילום מסך (אותו צילום, למקלדות בלי מקש Print Screen) |
| `Super + Ctrl + C` | תפריט לכידה |
| `Alt + Print Screen`            | הקלטת מסך                     |
| `Super + Print Screen` | בורר צבעים |
| `Super + Ctrl + Print Screen` | חילוץ טקסט ללוח ההעתקה |
| `Super + Alt + [` | הקטנת שכבת מצלמת הרשת בזמן הקלטה |
| `Super + Alt + ]` | הגדלת שכבת מצלמת הרשת בזמן הקלטה |
| `Alt + Shift + L` | העתקת ה-URL הנוכחי מאפליקציית רשת או מ-Chromium |
| `Alt + Shift + D` | הורדת הסרטון שבדף הנוכחי אל `~/Videos` |
| `Super + Ctrl + X` | התחלה/עצירה של הכתבה (דורש _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | הכתבה בלחיצה-ודיבור (דורש Voxtype או Superwhisper) |

בהקלטות מסך, מקש הקיצור שואל קודם איזה שמע תרצו, ואז מתחיל להקליט. לחצו עליו שוב כדי לעצור. ראו [צילומי מסך והקלטה](12-screenshots-recording.md) לפרטים.

כל אפשרויות הלכידה זמינות גם תחת _Trigger > Capture_ בתפריט Omarchy (`Super + Space`).

## Tmux

מקש הקידומת הוא `Ctrl + Space` (`Ctrl + B` עובד גם הוא). אפשר לשנות את הצירופים האלה ב-`~/.config/tmux/tmux.conf`.

### חלוניות

| מקש קיצור                  | פעולה              |
| ----------------------- | --------------------- |
| `Prefix + v` | פיצול חלונית לצד (אנכי) |
| `Prefix + h` | פיצול חלונית מתחת (אופקי) |
| `Prefix + x` | סגירת חלונית |
| `Prefix + z` | הפעלה/כיבוי של זום חלונית (מסך מלא) |
| `Alt + Enter` | פיצול חלונית מתחת (בלי קידומת) |
| `Alt + Shift + Enter` | פיצול חלונית לצד (בלי קידומת) |
| `Alt + Escape` | סגירת חלונית (בלי קידומת) |
| `Ctrl + Alt + Arrows` | מעבר בין חלוניות |
| `Ctrl + Alt + Shift + Arrows` | שינוי גודל חלוניות |

### חלונות

| מקש קיצור                  | פעולה              |
| ----------------------- | --------------------- |
| `Prefix + c` | חלון חדש |
| `Prefix + k` | סגירת חלון |
| `Prefix + r` | שינוי שם חלון |
| `Alt + 1-9` | מעבר לחלון מסוים |
| `Alt + Arrow Left/Right` | מעבר בין חלונות |
| `Alt + Shift + Arrow Left/Right` | הזזת חלון שמאלה/ימינה |

### הפעלות

### פונקציות פריסה של Tmux

יש להריץ את הפונקציות האלה בתוך הפעלת Tmux.

| פקודה | פעולה |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | יצירת פריסת פיתוח עם עורך, AI וטרמינל |
