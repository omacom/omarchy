# קיצורי מקלדת

תוכלו לראות את כל קיצורי המקלדת העיקריים עם `Super + K` (קיצורי Tmux עם `Super + Alt + K` וקיצורי Herdr עם `Super + Ctrl + K`).

## איך קיצורי המקלדת מסודרים

כל קיצור מקלדת יושב על מישור, שנקבע לפי מקשי השינוי שלו, ולכל מישור יש תפקיד אחד. זה מה שמונע מקיצורי המקלדת להתערבב זה בזה, וזה אומר שבדרך כלל תוכלו לנחש איפה משהו נמצא.

| מישור | מה נמצא שם | דוגמאות |
| --- | --- | --- |
| `Super + key` | המערכת: חלונות, סביבות עבודה, פריסות ותפריטי ליבה | `Super + Space` תפריט Omarchy, `Super + W` סגירת חלון, `Super + F` מסך מלא |
| `Super + Shift + key` | אפליקציות | `Super + Shift + B` דפדפן, `Super + Shift + E` דוא"ל, `Super + Shift + N` עורך |
| `Super + Ctrl + key` | פאנלים ותפריטי מערכת | `Super + Ctrl + A` שמע, `Super + Ctrl + N` רשת, `Super + Ctrl + C` תפריט לכידה |
| `Super + Ctrl + Alt + key` | פעולות מהירות והודעות | `Super + Ctrl + Alt + T` הצגת השעה, `Super + Ctrl + Alt + B` סוללה, `Super + Ctrl + Alt + C` צילום מסך |

הוספת `Alt` לקיצור מקלדת נותנת לכם גרסה של אותו הדבר, לעולם לא משהו לא קשור:

- `Super + Shift + B` פותח את הדפדפן; `Super + Shift + Alt + B` פותח חלון פרטי
- `Super + Shift + E` פותח דוא"ל; `Super + Shift + Alt + E` מתחיל דוא"ל חדש
- `Super + F` עובר למסך מלא; `Super + Alt + F` עובר לרוחב מלא
- `Super + Ctrl + C` פותח את תפריט הלכידה; `Super + Ctrl + Alt + C` מדלג על התפריט ומצלם צילום מסך

כשמוסיפים קיצור מקלדת:

1. בחרו את המישור לפי מה שהוא עושה, ואז בחרו את המקש.
2. אל תזיזו קיצור מקלדת קיים כדי לפנות מקום. מצאו מקש פנוי במישור הנכון.
3. השתמשו ב-`Alt` רק עבור גרסה של הקיצור בלעדיו.

קיצורי מקלדת בודדים מפרים את הכללים האלה כי זה נוח. `Shift` עם חץ או `Tab` מזיז או הופך כיוון במקום לפתוח אפליקציה, ו-`Print`, מקשי המדיה, `Alt + Tab` ו-`Ctrl + Alt + Del` עובדים כמו בכל מקום אחר. הם חריגים, לא דפוסים להעתקה.

אם ברירת מחדל לא מתאימה לכם (נניח שאתם רוצים את `Super + Shift + S` לצילומי מסך כמו ב-Windows), שנו את השיוך שלו ב-`~/.config/hypr/bindings.lua`.

במשטח מגע, החלקות בשלוש ובארבע אצבעות מחליפות סביבות עבודה, מזיזות חלונות ופותחות את התפריט ואת מסוף Quake; ראו [מקלדת, עכבר ומשטח מגע](34-keyboard-mouse-trackpad.md) עבור המחוות.

קיצורי שינוי הגודל משתמשים במקשים הפיזיים `code:20` ו-`code:21` (‏XKB `<AE11>` ו-`<AE12>`), בלי קשר לתווים המודפסים על המקלדת. במקלדות US מקשים אלה הם `-` ו-`=`; במקלדות יפניות (JIS) הם `-` ו-`^`; במקלדות ספרדיות הם `'` ו-`¡`. ב-JIS, ‏`Super + ^` הוא `Super + Equal`, ואילו `Super + Shift + -` (שמקליד `=`) הוא `Super + Shift + Minus`.

## Tmux

מקש הקידומת הוא `Ctrl + Space` (גם `Ctrl + B` עובד). תוכלו לשנות שיוכים אלה ב-`~/.config/tmux/tmux.conf`.

### חלוניות

| קיצור מקלדת                  | פונקציה              |
| ----------------------- | --------------------- |
| `Prefix + v` | פיצול חלונית לצד (אנכי) |
| `Prefix + h` | פיצול חלונית מתחת (אופקי) |
| `Prefix + x` | סגירת חלונית |
| `Prefix + z` | החלפת הגדלת חלונית (מסך מלא) |
| `Alt + Enter` | פיצול חלונית מתחת (בלי קידומת) |
| `Alt + Shift + Enter` | פיצול חלונית לצד (בלי קידומת) |
| `Alt + Escape` | סגירת חלונית (בלי קידומת) |
| `Ctrl + Alt + Arrows` | מעבר בין חלוניות |
| `Ctrl + Alt + Shift + Arrows` | שינוי גודל חלוניות |

### חלונות
