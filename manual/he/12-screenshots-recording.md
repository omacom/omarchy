# צילומי מסך והקלטה

כל מה שאפשר לתפוס מהמסך תלוי במקש Print Screen. מקש אחד לבדו מצלם תמונה, ומקשי השינוי נותנים הקלטה, צבע, או את הטקסט שבתוך אזור. אם למקלדת שלכם אין מקש Print Screen בכלל, `Super + Ctrl + Alt + C` מצלם את אותו צילום מסך, ו־`Super + Ctrl + C` פותח את כל הסט כתפריט.

| מקש קיצור | פעולה |
| ------ | -------- |
| `Print Screen` | צילום מסך |
| `Super + Ctrl + Alt + C` | צילום מסך |
| `Alt + Print Screen` | הקלטת מסך (או עצירת ההקלטה שרצה) |
| `Super + Print Screen` | בוחר צבעים |
| `Super + Ctrl + Print Screen` | חילוץ טקסט מאזור |
| `Super + Ctrl + C` | תפריט לכידה |
| `Super + Ctrl + .` | המרת קידוד של תמונה או וידאו |

## צילומי מסך

לחצו על `Print Screen` (או על `Super + Ctrl + Alt + C`) ו־Omasnap ילכוד את המסך הממוקד לפני ששכבת העל שלו מופיעה, כך ששום דבר לא זז מתחתיכם בזמן שאתם מכוונים. גררו אזור חופשי, לחצו על חלון כדי ללכוד אותו, או לחצו על שטח פתוח כדי ללכוד את כל המסך. לחצו על `S` לפני הציור כדי ללכוד אזור גלילה. שיניתם את דעתכם? לחצו שוב על אותו מקש כדי לסגור את Omasnap.

אחרי שאתם בוחרים אזור, Omasnap שומר את הלכידה, מעתיק אותה ללוח ההעתקה, ומציג התראה עם התמונה הממוזערת שלה, כמו שהקלטת מסך שמורה עושה. בחרו Open כדי לצפות בצילום השמור במציג התמונות שלכם, או Edit כדי להוסיף עליו הערות.

עורך ההערות יכול לצייר חצים, קווים, צורות, הדגשות, סמנים ממוספרים, טקסט והשחרות מאובטחות; לחתוך או לגזור חלק מהתמונה; לבצע OCR לטקסט שלה; ולהוסיף רקע. בעורך, לחצו על `Enter` כדי להעתיק ולשמור את ה־PNG המוגמר, על `Ctrl + C` כדי להעתיק אותו בלי לשמור, או על `Ctrl + S` כדי לשמור אותו בלי להעתיק.

צילומי מסך שמורים מגיעים כברירת מחדל ל־`~/Pictures/Screenshots`, עם שם כמו `screenshot-2026-08-13_14-22-05-firefox.png`. הגדירו את `OMASNAP_SCREENSHOT_DIR` כדי להשתמש בתיקייה אחרת — ראו [השאלות הנפוצות](46-faq.md) כדי לדעת איפה לשים משתני סביבה של ההפעלה. Omasnap יוצר את התיקייה כשהוא שומר את הצילום הראשון. הגדירו `[output] autosave = false` ב־`~/.config/omasnap/omasnap.conf` כדי להשבית שמירה אוטומטית; הלכידות אז רק מועתקות, ומוצגות בתצוגה מקדימה למשך 10 שניות שתוכלו להשאיר על המסך עם כפתור ההצמדה שלה או עם `Ctrl + P`.

מהמסוף, `omarchy screenshot` פותח את אותה שכבת על, ותוכלו לבחור את מצב ההתחלה שלה: `omarchy capture screenshot region`, `windows`, `fullscreen`, או `scroll`. ארגומנט שני של `copy` או `save` שולח את הצילום ישירות ליעד הזה. כדי לערוך לפני הפלט, השתמשו ב־`omarchy screenshot --editor=overlay` לעורך במסך מלא או ב־`omarchy screenshot --editor=window` לחלון נפרד.

### הפעלת הבוחר מהמקלדת

בזמן שהבחירה פתוחה, לא חייבים להשתמש בעכבר בכלל:

| מקש | פעולה |
| --- | -------- |
| `S` | מעבר למצב אזור גלילה |
| `Super + Arrow keys` | מעבר בין חלונות במצב חלון |
| `Return` | לכידת החלון המודגש |
| `Ctrl + A` | לכידת המסך הממוקד המלא |
| `R` | שחזור האזור האחרון ששורטט בהפעלה זו |
| `Esc` | סגירת Omasnap |

הקישורים האלה קיימים רק בזמן ש־Omasnap פתוח, כך שהם לא יכולים להתנגש עם שום דבר בתצורה שלכם.

## הקלטת מסך

`Alt + Print Screen` פותח את _Trigger > Capture > Screenrecord_, ששואל מה אתם רוצים בפסקול: בלי שמע, שמע של שולחן העבודה, שולחן עבודה פלוס מיקרופון, או שולחן עבודה פלוס מיקרופון פלוס מצלמת רשת. האחרון מופיע רק אם באמת יש לכם מצלמה מחוברת. בחרו אחד ובוחר ההקלטה של Omarchy יאפשר לכם לגרור אזור או ללחוץ על חלון או מסך.

ההקלטה רצה על gpu-screen-recorder, שמקודד על ה־GPU ב־60fps וחוזר ל־CPU אם הוא חייב. התוצאה היא MP4 ב־`~/Videos`, עם שם כמו `screenrecording-2026-08-13_14-22-05.mp4`. הגדירו את `OMARCHY_SCREENRECORD_DIR` כדי לשנות את זה — אבל שימו לב שבניגוד לתיקיית צילומי המסך, זו חייבת כבר להתקיים, אחרת ההקלטה תסרב להתחיל.

בזמן שאתם מקליטים, מחוון קטן מופיע בשורת המצב. לחצו עליו כדי לעצור. תוכלו גם לעצור עם `Alt + Print Screen` שוב, או עם הערך _Stop Screenrecording_ תחת _Trigger > Capture > Screenrecord_, שמופיע רק בזמן שמשהו באמת מוקלט.

העצירה עושה קצת סדר לפני שהיא מוסרת לכם את הקובץ: הפריים הראשון נחתך, ואם יש שמע הוא מנורמל ל־-14 LUFS כשרעש ההתחלה של לכידת PipeWire בתחילת הדרך מושתק החוצה. אחר כך מופיעה התראה עם תמונה ממוזערת מההקלטה. לחצו עליה כדי לנגן את הקובץ ב־mpv.

### שכבת מצלמת הרשת

כשאתם מקליטים עם מצלמת רשת, המצלמה מופיעה כחלון דיוקן מוצמד וחתוך בפינה הימנית התחתונה של מה שאתם מקליטים. אם היא יושבת על משהו שאתם צריכים, שנו את הגודל שלה תוך כדי:

| מקש קיצור | פעולה |
| ------ | -------- |
| `Super + Alt + [` | הקטנת שכבת מצלמת הרשת |
| `Super + Alt + ]` | הגדלת שכבת מצלמת הרשת |

יש שלושה גדלים — קטן, בינוני וגדול — ומקשי הקיצור מדלגים ביניהם. בינוני הוא ברירת המחדל. הם פרופורציונליים להקלטה, כך שהמצלמה תופסת את אותו נתח מהפריים בין אם אתם מקליטים מסך 1080p או מסך 6K. ואם הקלטתם אזור ולא תצוגה שלמה, השכבה מתעגנת לפינה של האזור הזה ולא של המסך, כך שהיא נשארת בתוך הצילום.

תוכלו גם לקרוא לזה ישירות עם `omarchy-capture-webcam-resize small`, או `reset` כדי לחזור לבינוני.

## טקסט, קודי QR וצבעים

`Super + Ctrl + Print Screen` בוחר אזור ומבצע לו OCR ללוח ההעתקה. זה מכוסה כמו שצריך ב־[חילוץ טקסט והכתבה](11-text-extraction-dictation.md).

_Trigger > Capture > QR Code_ עושה את אותו טריק לקודי QR. בחרו את האזור עם הקוד בתוכו, והערך המפוענח עובר ללוח ההעתקה. הוא מחפש רק קודי QR — לתוכן מסך צפוף יש נטייה להתגלות בטעות כברקוד אחרת. כדאי לדעת: הערך המפוענח עובר ללוח ההעתקה ולא לשום מקום אחר. הוא לא מודפס, הוא לא בהתראה, והוא מסומן כרגיש כך שהוא לא נתקע ב־[היסטוריית לוח ההעתקה](08-unified-clipboard-history.md). קודי QR נושאים באופן שגרתי סודות — ה־URI של `otpauth://` שמאחורי קוד הגדרת 2FA, למשל — ואתם לא רוצים את זה ביומן. ההדבקה עדיין עובדת מצוין.

`Super + Print Screen` (או _Trigger > Capture > Color_) הופך את הסמן לטפטפת. לחצו על כל דבר על המסך והצבע ינחת בלוח ההעתקה. לחצו שוב על מקש הקיצור כדי לצאת מבלי לבחור.

## המרת קידוד לפני שיתוף

הקלטת מסך ב־4K או HEIC גולמי מהטלפון שלכם הם לעתים קרובות גדולים מדי בשביל פשוט לשלוח. `Super + Ctrl + .` (או _Trigger > Transcode_) מתקן את זה. הוא מציע לכם בוחר קבצים מטושטש מעל `~/Pictures` ו־`~/Videos`, ואז שואל על פורמט וגודל.

תמונות עוברות ל־jpg או png בגבוה, בינוני או נמוך, שמגבילים את הרוחב ל־3160, 2160 ו־1080 פיקסלים. סרטונים עוברים ל־mp4 או ל־gif מונפש ב־4k, 1080p או 720p. הקובץ המומר נכתב ליד המקור עם הרזולוציה בשם — `demo-1080p.mp4` — והנתיב מועתק ללוח ההעתקה כ־URI של קובץ, כך שתוכלו להדביק אותו ישירות לתוך אפליקציה שמקבלת שחרור קבצים.

זה עובד גם מהמסוף, אם אתם כבר יודעים מה אתם רוצים: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. יש גם `omarchy transcode ascii`, שהופך תמונה לאמנות ASCII — זה בעיקר ל־[מיתוג](41-branding.md).

## שליחה למקום כלשהו

ברגע שיש לכם את הקובץ, `Super + Ctrl + S` פותח את תפריט השיתוף ושולח אותו למכשיר אחר ברשת שלכם דרך LocalSend. ראו [ממשקים גרפיים](22-guis.md) בשביל זה.
