# צילומי מסך והקלטה

כל מה שאפשר לתפוס מהמסך תלוי במקש Print Screen. מקש אחד לבדו מצלם תמונה, והמקשים הנלווים מקליטים, דוגמים צבע, או לוקחים את הטקסט מתוך אזור. אם למקלדת שלכם אין מקש Print Screen בכלל, `Super + Ctrl + Alt + C` מצלם את אותו צילום מסך, ו-`Super + Ctrl + C` פותח את כל הסט כתפריט.

| מקש קיצור | פעולה |
| ------ | -------- |
| `Print Screen` | צילום מסך |
| `Super + Ctrl + Alt + C` | צילום מסך |
| `Alt + Print Screen` | הקלטת מסך (או עצירת ההקלטה הפועלת) |
| `Super + Print Screen` | דוגם צבעים |
| `Super + Ctrl + Print Screen` | חילוץ טקסט מאזור |
| `Super + Ctrl + C` | תפריט לכידה |
| `Super + Ctrl + .` | המרת קידוד של תמונה או סרטון |

## צילומי מסך

לחצו על `Print Screen` (או על `Super + Ctrl + Alt + C`) ו-Omasnap לוכדת את הצג הממוקד לפני ששכבת-העל שלה מופיעה, כך ששום דבר לא זז מתחתיכם בזמן שאתם מכוונים. גררו אזור חופשי, לחצו על חלון כדי ללכוד אותו, או לחצו על שטח פתוח כדי ללכוד את כל הצג. לחצו על `S` לפני הציור כדי ללכוד אזור גולל. שיניתם את דעתכם? לחצו שוב על אותו מקש כדי לסגור את Omasnap.

אחרי שתבחרו אזור, Omasnap שומרת את הלכידה, מעתיקה אותה ללוח, ומציגה תצוגה מקדימה למשך 10 שניות. השתמשו בכפתור הנעיצה שבתצוגה המקדימה או ב-`Ctrl + P` כדי להשאיר אותה על המסך, או בחרו Edit כדי להוסיף לה הערות.

עורך ההערות יכול לצייר חצים, קווים, צורות, הדגשות, סמנים ממוספרים, טקסט, וטשטושים מאובטחים; לחתוך או לגזור חלק מהתמונה; לבצע OCR לטקסט שלה; ולהוסיף רקע. בעורך, לחצו על `Enter` כדי להעתיק ולשמור את ה-PNG המוגמר, על `Ctrl + C` כדי להעתיק אותו בלי לשמור, או על `Ctrl + S` כדי לשמור אותו בלי להעתיק.

צילומי מסך שמורים מגיעים כברירת מחדל אל `~/Pictures/Screenshots`, עם שם כגון `screenshot-2026-08-13_14-22-05-firefox.png`. הגדירו את `OMASNAP_SCREENSHOT_DIR` כדי להשתמש בתיקייה אחרת — ראו [השאלות הנפוצות](46-faq.md) כדי לדעת היכן לשים משתני סביבה של ההפעלה. Omasnap יוצרת את התיקייה כשהיא שומרת את הצילום הראשון. הגדירו `[output] autosave = false` בתוך `~/.config/omasnap/omasnap.conf` כדי להשבית שמירה אוטומטית.

מהטרמינל, `omarchy screenshot` פותח את אותה שכבת-על, ואפשר לבחור את מצב ההתחלה שלה: `omarchy capture screenshot region`, ‏`windows`, ‏`fullscreen`, או `scroll`. ארגומנט שני של `copy` או `save` מדלג על התצוגה המקדימה ושולח את הצילום ישירות ליעד הזה. כדי לערוך לפני הפלט, השתמשו ב-`omarchy screenshot --editor=overlay` לעורך במסך מלא או ב-`omarchy screenshot --editor=window` לחלון נפרד.

### הנעת הבורר מהמקלדת

בזמן שהבחירה פתוחה, לא חייבים להשתמש בעכבר בכלל:

| מקש | פעולה |
| --- | -------- |
| `S` | הפעלה/כיבוי של מצב אזור גולל |
| `Super + Arrow keys` | מעבר בין חלונות במצב חלון |
| `Return` | לכידת החלון המודגש |
| `Ctrl + A` | לכידת הצג הממוקד כולו |
| `R` | שחזור האזור האחרון שצויר בהפעלה זו |
| `Esc` | סגירת Omasnap |

הקישורים האלה קיימים רק בזמן ש-Omasnap פתוחה, כך שהם לא יכולים להתנגש עם שום דבר בתצורה שלכם.

## הקלטת מסך

`Alt + Print Screen` פותח את _Trigger > Capture > Screenrecord_, ששואל מה אתם רוצים בפסקול: בלי שמע, שמע של שולחן העבודה, שולחן העבודה פלוס מיקרופון, או שולחן העבודה פלוס מיקרופון פלוס מצלמת רשת. האפשרות האחרונה מופיעה רק אם באמת מחוברת אצלכם מצלמה. בחרו אחת ובורר ההקלטה של Omarchy יאפשר לכם לגרור אזור או ללחוץ על חלון או צג.

gpu-screen-recorder מריץ את ההקלטה, מקודד על ה-GPU ב-60fps ונופל בחזרה אל ה-CPU אם הוא חייב. התוצאה היא MP4 בתוך `~/Videos`, בשם `screenrecording-2026-08-13_14-22-05.mp4`. הגדירו את `OMARCHY_SCREENRECORD_DIR` כדי לשנות זאת — אבל שימו לב שבניגוד לתיקיית צילומי המסך, התיקייה הזו חייבת כבר להתקיים, אחרת ההקלטה תסרב להתחיל.

בזמן שאתם מקליטים, מחוון קטן מופיע בשורת המצב. לחצו עליו כדי לעצור. אפשר גם לעצור שוב עם `Alt + Print Screen`, או עם הערך _Stop Screenrecording_ תחת _Trigger > Capture > Screenrecord_, שמופיע רק בזמן שמשהו באמת מקליט.

העצירה עושה קצת סדר לפני שהיא מוסרת לכם את הקובץ: הפריים הראשון נחתך, ואם יש שמע הוא מנורמל ל--14 LUFS כשקפיצת לכידת ה-PipeWire ממש בהתחלה מושתקת החוצה. אחר כך מופיעה התראה עם תמונה ממוזערת מההקלטה. לחצו עליה כדי לנגן את הקובץ ב-mpv.

### שכבת-העל של מצלמת הרשת

כשאתם מקליטים עם מצלמת רשת, המצלמה מופיעה כחלון דיוקן נעוץ וחתוך בפינה הימנית התחתונה של כל מה שאתם מקליטים. אם היא יושבת על משהו שאתם צריכים, שנו את גודלה תוך כדי תנועה:

| מקש קיצור | פעולה |
| ------ | -------- |
| `Super + Alt + [` | הקטנת שכבת-העל של מצלמת הרשת |
| `Super + Alt + ]` | הגדלת שכבת-העל של מצלמת הרשת |

יש שלושה גדלים — קטן, בינוני, וגדול — ומקשי הקיצור מדלגים ביניהם. בינוני הוא ברירת המחדל. הם פרופורציונליים להקלטה, כך שהמצלמה תופסת את אותו נתח מהפריים בין אם אתם מקליטים צג 1080p או צג 6K. ואם הקלטתם אזור ולא תצוגה שלמה, שכבת-העל מתעגנת לפינת האזור הזה ולא לפינת הצג, כך שהיא נשארת בתוך הצילום.

אפשר גם לקרוא לה ישירות עם `omarchy-capture-webcam-resize small`, או עם `reset` כדי לחזור לבינוני.

## טקסט, קודי QR, וצבעים

`Super + Ctrl + Print Screen` בוחר אזור ומבצע לו OCR אל הלוח. זה מכוסה כמו שצריך ב-[חילוץ טקסט ותכתיב](11-text-extraction-dictation.md).

_Trigger > Capture > QR Code_ עושה את אותו תעלול לקודי QR. בחרו את האזור שבו נמצא הקוד, והערך המפוענח עובר ללוח. הוא מחפש רק קודי QR — לתוכן מסך צפוף יש הרגל להזדהות בטעות כברקוד אחרת. כדאי לדעת: הערך המפוענח עובר ללוח ולשום מקום אחר. הוא לא מודפס, הוא לא נמצא בהתראה, והוא מסומן כרגיש כך שהוא לא נשאר ב-[היסטוריית הלוח](08-unified-clipboard-history.md). קודי QR נושאים routinely סודות — ה-URI של `otpauth://` שמאחורי קוד הגדרה של 2FA, לדוגמה — ואתם לא רוצים את זה ביומן. ההדבקה עדיין עובדת מצוין.

`Super + Print Screen` (או _Trigger > Capture > Color_) הופך את הסמן לטפטפת. לחצו על כל דבר על המסך והצבע נוחת על הלוח. לחצו שוב על מקש הקיצור כדי לצאת בלי לבחור.

## המרת קידוד לפני שמשתפים

הקלטת מסך ב-4K או HEIC גולמי מהטלפון שלכם הם לעיתים קרובות גדולים מדי מכדי פשוט לשלוח. `Super + Ctrl + .` (או _Trigger > Transcode_) מתקן זאת. הוא מציע לכם בורר קבצים מטושטש מעל `~/Pictures` ו-`~/Videos`, ואז שואל על פורמט ועל גודל.

תמונות עוברות ל-jpg או ל-png בגבוה, בינוני, או נמוך, שמגבילים את הרוחב ל-3160, 2160, ו-1080 פיקסלים. סרטונים עוברים ל-mp4 או ל-gif מונפש ב-4k, ‏1080p, או 720p. הקובץ המומר נכתב ליד המקור עם הרזולוציה בשם — `demo-1080p.mp4` — והנתיב מועתק ללוח כ-URI של קובץ, כך שתוכלו להדביק אותו ישירות לתוך אפליקציה שמקבלת שחרור קבצים.

זה עובד גם מהטרמינל, אם אתם כבר יודעים מה אתם רוצים: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. יש גם `omarchy transcode ascii`, שהופך תמונה לאמנות ASCII — זה מיועד בעיקר ל-[מיתוג](41-branding.md).

## שליחה לאנשהו

ברגע שיש לכם את הקובץ, `Super + Ctrl + S` פותח את תפריט השיתוף ושולח אותו למכשיר אחר ברשת שלכם דרך LocalSend. ראו [ממשקי GUI](22-guis.md) לזה.
