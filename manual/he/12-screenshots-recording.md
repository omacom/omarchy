# צילומי מסך והקלטה

כל מה שאפשר לתפוס מהמסך תלוי במקש Print Screen. מקש אחד לבדו מצלם תמונה, והצירופים מבצעים הקלטה, בוחרים צבע, או מחלצים את הטקסט שבתוך אזור. אם במקלדת שלכם אין מקש Print Screen בכלל, `Super + Ctrl + Alt + C` מצלם את אותו צילום מסך, ו-`Super + Ctrl + C` פותח את כל הסט כתפריט.

| מקש קיצור | פעולה |
| ------ | -------- |
| `Print Screen` | צילום מסך |
| `Super + Ctrl + Alt + C` | צילום מסך |
| `Alt + Print Screen` | הקלטת מסך (או עצירת ההקלטה הפעילה) |
| `Super + Print Screen` | בוחר צבעים |
| `Super + Ctrl + Print Screen` | חילוץ טקסט מאזור |
| `Super + Ctrl + C` | תפריט לכידה |
| `Super + Ctrl + .` | המרת קידוד של תמונה או וידאו |

## צילומי מסך

לחצו על `Print Screen` (או `Super + Ctrl + Alt + C`) ו-Omasnap לוכדת את הצג הממוקד עוד לפני שהשכבה שלה מופיעה, כך ששום דבר לא זז מתחתיכם בזמן שאתם מכוונים. גררו אזור חופשי, לחצו על חלון כדי ללכוד אותו, או לחצו על שטח פתוח כדי ללכוד את הצג כולו. לחצו על `S` לפני הציור כדי ללכוד אזור גלילה. שיניתם את דעתכם? לחצו שוב על אותו מקש כדי לסגור את Omasnap.

לאחר בחירת אזור, Omasnap שומרת את הלכידה, מעתיקה אותה ללוח, ומציגה התראה עם התמונה הממוזערת שלה, כמו שעושה הקלטת מסך שמורה. בחרו בפתיחה כדי לצפות בצילום השמור במציג התמונות שלכם, או בעריכה כדי להוסיף לו הערות.

עורך ההערות יכול לצייר חצים, קווים, צורות, הדגשות, סמנים ממוספרים, טקסט והשחרות מאובטחות; לחתוך או לגזור חלק מהתמונה; לבצע OCR לטקסט שלה; ולהוסיף רקע. בעורך, לחצו על `Enter` כדי להעתיק ולשמור את ה-PNG המוגמר, על `Ctrl + C` כדי להעתיק אותו בלי לשמור, או על `Ctrl + S` כדי לשמור אותו בלי להעתיק.

צילומי מסך שמורים מגיעים כברירת מחדל אל `~/Pictures/Screenshots`, עם שם כגון `screenshot-2026-08-13_14-22-05-firefox.png`. הגדירו את `OMASNAP_SCREENSHOT_DIR` כדי להשתמש בתיקייה אחרת — ראו [השאלות הנפוצות](46-faq.md) כדי לדעת היכן לשים משתני סביבה של ההפעלה. Omasnap יוצרת את התיקייה כשהיא שומרת את הצילום הראשון. הגדירו `[output] autosave = false` בקובץ `~/.config/omasnap/omasnap.conf` כדי להשבית שמירה אוטומטית; הלכידות אז רק מועתקות, ומוצגות בתצוגה מקדימה למשך 10 שניות שתוכלו להשאיר על המסך עם כפתור ההצמדה שלה או עם `Ctrl + P`.

מהמסוף, `omarchy screenshot` פותח את אותה שכבה, ואפשר לבחור את מצב ההתחלה שלה: `omarchy capture screenshot region`, `windows`, `fullscreen`, או `scroll`. ארגומנט שני של `copy` או `save` שולח את הצילום ישירות ליעד הזה. כדי לערוך לפני הפלט, השתמשו ב-`omarchy screenshot --editor=overlay` לעורך במסך מלא או ב-`omarchy screenshot --editor=window` לחלון נפרד.

### הפעלת הבוחר מהמקלדת

כשהבחירה פתוחה, אין צורך להשתמש בעכבר בכלל:

| מקש | פעולה |
| --- | -------- |
| `S` | החלפת מצב אזור גלילה |
| `Super + Arrow keys` | מעבר בין חלונות במצב חלון |
| `Return` | לכידת החלון המודגש |
| `Ctrl + A` | לכידת הצג הממוקד במלואו |
| `R` | שחזור האזור האחרון שצויר בהפעלה זו |
| `Esc` | סגירת Omasnap |

המקשים האלה קיימים רק כש-Omasnap פתוחה, כך שהם לא יכולים להתנגש עם שום דבר בתצורה שלכם.

## הקלטת מסך

`Alt + Print Screen` פותח את _הפעלה > לכידה > הקלטת מסך_, ששואל מה תרצו בפסקול: ללא שמע, שמע שולחן עבודה, שולחן עבודה ומיקרופון, או שולחן עבודה ומיקרופון ומצלמת רשת. האפשרות האחרונה מופיעה רק אם אכן מחוברת אצלכם מצלמה. בחרו אחת, ובוחר ההקלטה של Omarchy יאפשר לכם לגרור אזור או ללחוץ על חלון או צג.

ההקלטה רצה על gpu-screen-recorder, שמקודד על ה-GPU ב-60fps ונופל בחזרה ל-CPU אם הוא חייב. התוצאה היא MP4 בתיקיית `~/Videos`, בשם `screenrecording-2026-08-13_14-22-05.mp4`. הגדירו את `OMARCHY_SCREENRECORD_DIR` כדי לשנות זאת — אבל שימו לב שבניגוד לתיקיית צילומי המסך, תיקייה זו חייבת כבר להתקיים, אחרת ההקלטה תסרב להתחיל.

בזמן ההקלטה, מחוון קטן מופיע בסרגל. לחצו עליו כדי לעצור. אפשר גם לעצור שוב עם `Alt + Print Screen`, או עם הערך _עצירת הקלטת מסך_ תחת _הפעלה > לכידה > הקלטת מסך_, שמופיע רק כשמשהו אכן מוקלט.

העצירה מבצעת מעט סדר לפני שהיא מוסרת לכם את הקובץ: הפריים הראשון נחתך, ואם יש שמע הוא מנורמל ל--14 LUFS כשקפיצת לכידת PipeWire ממש בהתחלה מושתקת החוצה. לאחר מכן מופיעה התראה עם תמונה ממוזערת מההקלטה. לחצו עליה כדי לנגן את הקובץ ב-Omaview.

### שכבת מצלמת הרשת

כשמקליטים עם מצלמת רשת, המצלמה מופיעה כחלון דיוקן מוצמד וחתוך בפינה הימנית התחתונה של כל מה שאתם מקליטים. אם היא יושבת על משהו שאתם צריכים, שנו את גודלה תוך כדי:

| מקש קיצור | פעולה |
| ------ | -------- |
| `Super + Alt + [` | הקטנת שכבת מצלמת הרשת |
| `Super + Alt + ]` | הגדלת שכבת מצלמת הרשת |

יש שלושה גדלים — קטן, בינוני וגדול — ומקשי הקיצור עוברים ביניהם. בינוני הוא ברירת המחדל. הם יחסיים להקלטה, כך שהמצלמה תופסת את אותו חלק מהפריים בין אם אתם מקליטים צג 1080p או צג 6K. ואם הקלטתם אזור ולא תצוגה שלמה, השכבה מתעגנת לפינת האזור ולא לפינת הצג, כך שהיא נשארת בתוך הצילום.

אפשר גם לקרוא לה ישירות עם `omarchy-capture-webcam-resize small`, או `reset` כדי לחזור לבינוני.

## טקסט, קודי QR וצבעים

`Super + Ctrl + Print Screen` בוחר אזור ומבצע לו OCR ללוח. זה מכוסה כראוי ב[חילוץ טקסט ותכתיב](11-text-extraction-dictation.md).

_הפעלה > לכידה > קוד QR_ עושה את אותו טריק לקודי QR. בחרו את האזור שבו נמצא הקוד, והערך המפוענח עובר ללוח. הוא מחפש רק קודי QR — אחרת תוכן מסך צפוף נוטה להתגלות בטעות כברקוד. כדאי לדעת: הערך המפוענח עובר ללוח ולשום מקום אחר. הוא אינו מודפס, אינו מופיע בהתראה, ומסומן כרגיש כך שהוא לא נשאר ב[היסטוריית הלוח](08-unified-clipboard-history.md). קודי QR נושאים באופן שגרתי סודות — ה-URI מסוג `otpauth://` שמאחורי קוד הגדרת 2FA, למשל — ואתם לא רוצים את זה ביומן. ההדבקה עדיין עובדת מצוין.

`Super + Print Screen` (או _הפעלה > לכידה > צבע_) הופך את הסמן לטפטפת. לחצו על כל דבר על המסך והצבע יגיע ללוח. לחצו שוב על מקש הקיצור כדי לצאת בלי לבחור.

## המרת קידוד לפני שיתוף

הקלטת מסך ב-4K או HEIC גולמי מהטלפון שלכם לרוב גדולים מדי לשליחה פשוטה. `Super + Ctrl + .` (או _הפעלה > המרת קידוד_) מתקן זאת. הוא מציע לכם בוחר קבצים עם חיפוש מטושטש מעל `~/Pictures` ו-`~/Videos`, ואז שואל על תבנית וגודל.

תמונות עוברות ל-jpg או ל-png באיכות גבוהה, בינונית או נמוכה, שמגבילות את הרוחב ל-3160, 2160 ו-1080 פיקסלים. סרטונים עוברים ל-mp4 או ל-gif מונפש ב-4k, ב-1080p או ב-720p. הקובץ המומר נכתב ליד המקור עם הרזולוציה בשם — `demo-1080p.mp4` — והנתיב מועתק ללוח כ-URI של קובץ, כך שתוכלו להדביק אותו ישירות לאפליקציה שמקבלת שחרור קבצים.

זה עובד גם מהמסוף, אם אתם כבר יודעים מה אתם רוצים: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. יש גם `omarchy transcode ascii`, שהופך תמונה לאמנות ASCII — זה בעיקר עבור [מיתוג](41-branding.md).

## שליחתו למקום אחר

לאחר שיש לכם את הקובץ, `Super + Ctrl + S` פותח את תפריט השיתוף ושולח אותו למכשיר אחר ברשת שלכם באמצעות LocalSend. ראו [ממשקים גרפיים](22-guis.md) למידע על כך.
