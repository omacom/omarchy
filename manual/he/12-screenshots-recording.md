# צילומי מסך והקלטה

כל מה שאפשר לקחת מהמסך תלוי על מקש Print Screen. מקש אחד לבדו מצלם תמונה, והמשנים לוקחים הקלטה, צבע או את הטקסט בתוך אזור. אם למקלדת שלכם אין בכלל מקש Print Screen, `Super + Ctrl + C` פותח את אותו סט כתפריט.

| קיצור מקלדת | פונקציה |
| ------ | -------- |
| `Print Screen` | צילום מסך |
| `Alt + Print Screen` | הקלטת מסך (או עצירת זו שרצה) |
| `Super + Print Screen` | בורר צבע |
| `Super + Ctrl + Print Screen` | חילוץ טקסט מאזור |
| `Super + Ctrl + C` | תפריט לכידה |
| `Super + Ctrl + .` | המרת תמונה או וידאו |

## צילומי מסך

לחצו על `Print Screen` ו-Omasnap לוכד את המסך הממוקד לפני ששכבת-העל שלו מופיעה, כך ששום דבר לא זז תחתיכם בזמן היעד. גררו אזור חופשי, לחצו על חלון כדי ללכוד אותו, או לחצו על שטח פתוח כדי ללכוד את כל המסך. לחצו על `S` לפני הציור כדי ללכוד אזור גולל. שיניתם את דעתכם? לחצו שוב על `Print Screen` כדי לבטל את Omasnap.

לאחר שבוחרים אזור, Omasnap שומר את הלכידה, מעתיק אותה ללוח ומציג תצוגה מקדימה למשך 10 שניות. השתמשו בכפתור ההצמדה של התצוגה המקדימה או ב-`Ctrl + P` כדי להשאיר אותה על המסך, או בחרו בעריכה כדי להוסיף לה הערות.

עורך ההערות יכול לצייר חצים, קווים, צורות, הדגשות, סמנים ממוספרים, טקסט ועריכות מאובטחות; לחתוך או לגזור חלק מהתמונה; לבצע OCR לטקסט שלה; ולהוסיף רקע. בעורך, לחצו על `Enter` כדי להעתיק ולשמור את ה-PNG המוגמר, על `Ctrl + C` כדי להעתיק אותו בלי לשמור, או על `Ctrl + S` כדי לשמור אותו בלי להעתיק.

צילומי מסך שמורים נוחתים ב-`~/Pictures/Screenshots` כברירת מחדל, עם שם כגון `screenshot-2026-08-13_14-22-05-firefox.png`. הגדירו את `OMASNAP_SCREENSHOT_DIR` כדי להשתמש בספרייה אחרת — ראו [השאלות הנפוצות](46-faq.md) להיכן לשים משתני סביבת מושב. Omasnap יוצר את הספרייה כאשר הוא שומר את הצילום הראשון. הגדירו את `[output] autosave = false` ב-`~/.config/omasnap/omasnap.conf` כדי להשבית שמירה אוטומטית.

מהטרמינל, `omarchy screenshot` פותח את אותה שכבת-על, ואפשר לבחור את מצב ההתחלה שלה: `omarchy capture screenshot region`, `windows`, `fullscreen` או `scroll`. ארגומנט שני של `copy` או `save` מדלג על התצוגה המקדימה ושולח את הצילום ישירות ליעד הזה. כדי לערוך לפני הפלט, השתמשו ב-`omarchy screenshot --editor=overlay` לעורך במסך מלא או ב-`omarchy screenshot --editor=window` לחלון נפרד.

### ניהוג הבורר מהמקלדת

בזמן שהבחירה למעלה, לא חייבים להשתמש בעכבר בכלל:

| מקש | פונקציה |
| --- | -------- |
| `S` | החלפת מצב אזור גולל |
| `Super + Arrow keys` | מעבר בין חלונות במצב חלון |
| `Return` | לכידת החלון המודגש |
| `Ctrl + A` | לכידת המסך הממוקד כולו |
| `R` | שחזור האזור האחרון שצויר במושב זה |
| `Esc` | ביטול Omasnap |

שיוכים אלה קיימים רק בזמן ש-Omasnap פתוח, כך שהם לא יכולים להתנגש עם שום דבר בהגדרה שלכם.

## הקלטת מסך

`Alt + Print Screen` פותח את _הפעלה > לכידה > הקלטת מסך_, ששואל מה תרצו על הפסקול: בלי שמע, שמע שולחן עבודה, שולחן עבודה ועוד מיקרופון, או שולחן עבודה ועוד מיקרופון ועוד מצלמת רשת. האחרון מופיע רק אם באמת יש לכם מצלמה מחוברת. בחרו אחד ובורר ההקלטה של Omarchy מאפשר לגרור אזור או ללחוץ על חלון או מסך.

ההקלטה רצה על gpu-screen-recorder, שמקודד על ה-GPU ב-60fps ונופל חזרה למעבד אם הוא מוכרח. התוצאה היא MP4 ב-`~/Videos`, בשם `screenrecording-2026-08-13_14-22-05.mp4`. הגדירו את `OMARCHY_SCREENRECORD_DIR` כדי לשנות זאת — אבל שימו לב שבניגוד לספריית צילומי המסך, זו חייבת כבר להתקיים, אחרת ההקלטה מסרבת להתחיל.

בזמן שמקליטים, מחוון קטן מופיע בשורה. לחצו עליו כדי לעצור. אפשר גם לעצור עם `Alt + Print Screen` שוב, או עם הערך _עצירת הקלטת מסך_ תחת _הפעלה > לכידה > הקלטת מסך_, שמופיע רק בזמן שמשהו באמת מקליט.

העצירה עושה קצת סדר לפני שהיא מוסרת לכם את הקובץ: הפריים הראשון נחתך, ואם יש שמע הוא מנורמל ל--14 LUFS עם השתקת פיצוץ הלכידה של PipeWire ממש בהתחלה. אחר כך מופיעה התראה עם תמונה ממוזערת מההקלטה. לחצו עליה כדי לנגן את הקובץ ב-mpv.

### שכבת-העל של מצלמת הרשת

כאשר מקליטים עם מצלמת רשת, המצלמה מופיעה כחלון דיוקן חתוך ומוצמד בפינה הימנית התחתונה של כל מה שמקליטים. אם היא יושבת על משהו שצריך, שנו את גודלה תוך כדי תנועה:

| קיצור מקלדת | פונקציה |
| ------ | -------- |
| `Super + Alt + [` | הקטנת שכבת-העל של מצלמת הרשת |
| `Super + Alt + ]` | הגדלת שכבת-העל של מצלמת הרשת |

יש שלושה גדלים — קטן, בינוני וגדול — וקיצורי המקלדת צועדים ביניהם. בינוני הוא ברירת המחדל. הם פרופורציונליים להקלטה, כך שהמצלמה תופסת את אותו חלק מהפריים בין אם מקליטים מסך 1080p או מסך 6K. ואם הקלטתם אזור ולא תצוגה שלמה, שכבת-העל נצמדת לפינת האזור הזה ולא לפינת המסך, כך שהיא נשארת בתוך הצילום.

אפשר גם לקרוא לה ישירות עם `omarchy-capture-webcam-resize small`, או `reset` כדי לחזור לבינוני.

## טקסט, קודי QR וצבעים

`Super + Ctrl + Print Screen` בוחר אזור ועושה לו OCR ללוח. זה מכוסה כראוי ב-[חילוץ טקסט והכתבה](11-text-extraction-dictation.md).

האפשרות _הפעלה > לכידה > קוד QR_ עושה את אותו טריק לקודי QR. בחרו את האזור עם הקוד בתוכו, והערך המפוענח עובר ללוח. הוא מחפש רק קודי QR — תוכן מסך צפוף נוטה להזדהות שגוי כברקוד אחרת. כדאי לדעת: הערך המפוענח עובר ללוח ולשום מקום אחר. הוא לא מודפס, הוא לא בהתראה, והוא מסומן כרגיש כך שהוא לא נשאר ב[היסטוריית הלוח](08-unified-clipboard-history.md). קודי QR נושאים באופן שגרתי סודות — ה-URI של `otpauth://` מאחורי קוד הגדרת 2FA, למשל — ואתם לא רוצים את זה ביומן. ההדבקה עדיין עובדת בסדר גמור.

`Super + Print Screen` (או _הפעלה > לכידה > צבע_) הופך את הסמן לטפטפת. לחצו על כל דבר על המסך והצבע נוחת על הלוח. לחצו שוב על קיצור המקלדת כדי לצאת בלי לבחור.

## המרה לפני שמשתפים

הקלטת מסך 4K או HEIC גולמי מהטלפון שלכם לעיתים קרובות גדולים מדי כדי פשוט לשלוח. `Super + Ctrl + .` (או _הפעלה > המרה_) מתקן זאת. הוא מציע לכם בורר קבצים מטושטש מעל `~/Pictures` ו-`~/Videos`, ואחר כך שואל לפורמט ולגודל.

תמונות עוברות ל-jpg או ל-png בגבוה, בינוני או נמוך, המגבילים את הרוחב ל-3160, 2160 ו-1080 פיקסלים. סרטונים עוברים ל-mp4 או ל-gif מונפש ב-4k, 1080p או 720p. הקובץ המומר נכתב לצד המקורי כשהרזולוציה בשם — `demo-1080p.mp4` — והנתיב מועתק ללוח כ-URI של קובץ, כך שאפשר להדביק אותו ישירות לאפליקציה שמקבלת גרירת קבצים.

זה עובד גם מהטרמינל, אם כבר יודעים מה רוצים: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. יש גם את `omarchy transcode ascii`, שהופך תמונה לאמנות ASCII — זה בעיקר ל[מיתוג](41-branding.md).

## שליחתו לאיפשהו

ברגע שיש לכם את הקובץ, `Super + Ctrl + S` פותח את תפריט השיתוף ושולח אותו להתקן אחר ברשת שלכם באמצעות LocalSend. ראו [ממשקי GUI](22-guis.md) לכך.
