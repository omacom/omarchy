# צילומי מסך והקלטה

כל מה שאפשר לתפוס מהמסך תלוי במקש Print Screen. מקש אחד לבדו מצלם תמונה, והצירופים מבצעים הקלטה, בוחרים צבע, או מחלצים את הטקסט שבתוך אזור. אם במקלדת שלכם אין מקש Print Screen בכלל, `Super + Ctrl + Alt + C` מצלם את אותו צילום מסך, ו־`Super + Ctrl + C` פותח את כל הסט כתפריט.

| מקש קיצור | פעולה |
| ------ | -------- |
| `Print Screen` | צילום מסך |
| `Super + Ctrl + Alt + C` | צילום מסך |
| `Alt + Print Screen` | הקלטת מסך (או עצירת ההקלטה הפועלת) |
| `Super + Print Screen` | בורר צבעים |
| `Super + Ctrl + Print Screen` | חילוץ טקסט מאזור |
| `Super + Ctrl + C` | תפריט לכידה |
| `Super + Ctrl + .` | המרת קידוד של תמונה או סרטון |

## צילומי מסך

לחצו על `Print Screen` (או על `Super + Ctrl + Alt + C`) ו־Omasnap ילכוד את הצג הממוקד לפני שהשכבה שלו מופיעה, כך ששום דבר לא זז מתחתיכם בזמן שאתם מכוונים. גררו אזור חופשי, לחצו על חלון כדי ללכוד אותו, או לחצו על שטח פתוח כדי ללכוד את כל הצג. לחצו על `S` לפני הציור כדי ללכוד אזור נגלל. שיניתם את דעתכם? לחצו שוב על אותו מקש כדי לסגור את Omasnap.

אחרי שתבחרו אזור, Omasnap שומר את הלכידה, מעתיק אותה ללוח הגזירים, ומציג התראה עם התמונה הממוזערת שלה, כמו שהקלטת מסך שמורה עושה. בחרו Open כדי לצפות בצילום השמור במציג התמונות שלכם, או Edit כדי להוסיף לו הערות.

עורך ההערות יכול לצייר חצים, קווים, צורות, הדגשות, סמנים ממוספרים, טקסט והשחרות מאובטחות; לחתוך או לגזור חלק מהתמונה; לבצע OCR לטקסט שלה; ולהוסיף רקע. בעורך, לחצו על `Enter` כדי להעתיק ולשמור את ה־PNG המוגמר, על `Ctrl + C` כדי להעתיק אותו בלי לשמור, או על `Ctrl + S` כדי לשמור אותו בלי להעתיק.

צילומי מסך שמורים נוחתים ב־`~/Pictures/Screenshots` כברירת מחדל, עם שם כמו `screenshot-2026-08-13_14-22-05-firefox.png`. הגדירו את `OMASNAP_SCREENSHOT_DIR` כדי להשתמש בתיקייה אחרת — ראו את [השאלות הנפוצות](46-faq.md) כדי לדעת היכן לשים משתני סביבה של ההפעלה. Omasnap יוצר את התיקייה כשהוא שומר את הצילום הראשון. הגדירו `[output] autosave = false` ב־`~/.config/omasnap/omasnap.conf` כדי להשבית שמירה אוטומטית; הלכידות אז רק מועתקות, ומוצגות בתצוגה מקדימה למשך 7 שניות שתוכלו להשאיר על המסך עם כפתור הנעיצה שלה או עם `Ctrl + P`.

מהמסוף, `omarchy screenshot` פותח את אותה שכבה, ואפשר לבחור את מצב ההתחלה שלה: `omarchy capture screenshot region`, `windows`, `fullscreen` או `scroll`. ארגומנט שני של `copy` או `save` שולח את הצילום ישר ליעד הזה. כדי לערוך לפני הפלט, השתמשו ב־`omarchy screenshot --editor=overlay` לעורך במסך מלא או ב־`omarchy screenshot --editor=window` לחלון נפרד.

### הפעלת הבורר מהמקלדת

בזמן שהבחירה פתוחה, לא חייבים להשתמש בעכבר בכלל:

| מקש | פעולה |
| --- | -------- |
| `S` | החלפת מצב אזור נגלל |
| `Super + Arrow keys` | מעבר בין חלונות במצב חלון |
| `Return` | לכידת החלון המודגש |
| `Ctrl + A` | לכידת כל הצג הממוקד |
| `R` | שחזור האזור האחרון שצויר בהפעלה זו |
| `Esc` | סגירת Omasnap |

הקישורים האלה קיימים רק בזמן ש־Omasnap פתוח, כך שהם לא יכולים להתנגש עם שום דבר בתצורה שלכם.

## הקלטת מסך

`Alt + Print Screen` פותח את _Trigger > Capture > Screenrecord_, ששואל מה אתם רוצים בפסקול: בלי שמע, שמע שולחן עבודה, שולחן עבודה ומיקרופון, או שולחן עבודה ומיקרופון ומצלמת רשת. האחרון מופיע רק אם באמת יש לכם מצלמה מחוברת. בחרו אחד ובורר ההקלטה של Omarchy יאפשר לכם לגרור אזור או ללחוץ על חלון או על צג.

ההקלטה פועלת על gpu-screen-recorder, שמקודד על ה־GPU ב־60fps וחוזר ל־CPU אם הוא חייב; ב־GPU שהוא לא תומך בהם, כמו של Apple Silicon, Omarchy מקליט עם wf-recorder במקום זאת. התוצאה היא MP4 ב־`~/Videos`, בשם `screenrecording-2026-08-13_14-22-05.mp4`. הגדירו את `OMARCHY_SCREENRECORD_DIR` כדי לשנות זאת — אבל שימו לב שבניגוד לתיקיית צילומי המסך, זו חייבת להתקיים כבר, אחרת ההקלטה מסרבת להתחיל.

בזמן שאתם מקליטים, מחוון קטן מופיע בסרגל. לחצו עליו כדי לעצור. אפשר גם לעצור שוב עם `Alt + Print Screen`, או עם הערך _Stop Screenrecording_ תחת _Trigger > Capture > Screenrecord_, שמופיע רק בזמן שמשהו באמת מקליט.

העצירה עושה קצת סדר לפני שהיא מוסרת לכם את הקובץ: הפריים הראשון נחתך, ואם יש שמע הוא מנורמל ל־-14 LUFS כשקפיצת לכידת PipeWire ממש בהתחלה מושתקת. אחר כך מופיעה התראה עם תמונה ממוזערת מההקלטה. בחרו _Open_ כדי לנגן את הקובץ ב־Omaview, או _Cut_ כדי לחתוך אותו ב־Omacut.

### שכבת מצלמת הרשת

כאשר אתם מקליטים עם מצלמת רשת, המצלמה מופיעה כחלון דיוקן חתוך ומוצמד בפינה הימנית התחתונה של כל מה שאתם מקליטים. אם היא יושבת על משהו שאתם צריכים, שנו את גודלה תוך כדי:

| מקש קיצור | פעולה |
| ------ | -------- |
| `Super + Alt + [` | הקטנת שכבת מצלמת הרשת |
| `Super + Alt + ]` | הגדלת שכבת מצלמת הרשת |

יש שלושה גדלים — קטן, בינוני וגדול — ומקשי הקיצור מדלגים ביניהם. בינוני הוא ברירת המחדל. הם פרופורציונליים להקלטה, כך שהמצלמה תופסת את אותו חלק מהפריים בין שאתם מקליטים צג 1080p ובין שאתם מקליטים צג 6K. ואם הקלטתם אזור ולא תצוגה שלמה, השכבה מתעגנת לפינת האזור הזה ולא לפינת הצג, כך שהיא נשארת בתוך הצילום.

אפשר גם לקרוא לה ישירות עם `omarchy-capture-webcam-resize small`, או עם `reset` כדי לחזור לבינוני.

## טקסט, קודי QR וצבעים

`Super + Ctrl + Print Screen` בוחר אזור ומבצע לו OCR ללוח הגזירים. זה מכוסה כראוי ב־[חילוץ טקסט ותכתיב](11-text-extraction-dictation.md).

_Trigger > Capture > QR Code_ עושה את אותו טריק לקודי QR. בחרו את האזור שבו נמצא הקוד, והערך המפוענח עובר ללוח הגזירים. הוא מחפש רק קודי QR — לתוכן מסך צפוף יש הרגל להזדהות בטעות כברקוד אחרת. שווה לדעת: הערך המפוענח עובר ללוח הגזירים ולשום מקום אחר. הוא לא מודפס, הוא לא נמצא בהתראה, והוא מסומן כרגיש כך שהוא לא נשאר ב־[היסטוריית לוח הגזירים](08-unified-clipboard-history.md). קודי QR נושאים באופן שגרתי סודות — ה־URI של `otpauth://` שמאחורי קוד הגדרת 2FA, למשל — ואתם לא רוצים את זה בלוג. ההדבקה עדיין עובדת מצוין.

`Super + Print Screen` (או _Trigger > Capture > Color_) הופך את הסמן לטפטפת. לחצו על כל דבר על המסך והצבע נוחת על לוח הגזירים. לחצו שוב על מקש הקיצור כדי לצאת בלי לבחור.

## המרת קידוד לפני השיתוף

הקלטת מסך ב־4K או HEIC גולמי מהטלפון שלכם לרוב גדולים מדי מכדי פשוט לשלוח. `Super + Ctrl + .` (או _Trigger > Transcode_) פותר את זה. הוא מציע לכם בורר קבצים מטושטש מעל `~/Pictures` ו־`~/Videos`, ואז שואל על פורמט ועל גודל.

תמונות עוברות ל־jpg או ל־png בגבוה, בינוני או נמוך, שמגבילים את הרוחב ל־3160, 2160 ו־1080 פיקסלים. סרטונים עוברים ל־mp4 או ל־gif מונפש ב־4k, 1080p או 720p. הקובץ המומר נכתב ליד המקור עם הרזולוציה בשם — `demo-1080p.mp4` — והנתיב מועתק ללוח הגזירים כ־URI של קובץ, כך שתוכלו להדביק אותו ישירות לתוך אפליקציה שמקבלת שחרור קבצים.

זה עובד גם מהמסוף, אם אתם כבר יודעים מה אתם רוצים: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. יש גם `omarchy transcode ascii`, שהופך תמונה לאמנות ASCII — זה בעיקר ל־[מיתוג](41-branding.md).

## שליחתו לאנשהו

ברגע שיש לכם את הקובץ, `Super + Ctrl + S` פותח את תפריט השיתוף ושולח אותו למכשיר אחר ברשת שלכם דרך LocalSend. ראו את [ממשקים גרפיים](22-guis.md) לזה.
