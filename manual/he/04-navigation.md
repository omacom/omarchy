# ניווט

כל דבר ב-Omarchy קורה דרך המקלדת — _הכול!_ כשהמערכת עולה בפעם הראשונה, ממש אי אפשר לעשות שום דבר עם העכבר בלבד. אבל אפשר ללחוץ על `Super + Space` כדי להציג את תפריט Omarchy, ומכאן אפשר לעשות כמעט הכול.

אבל תפריט Omarchy אפילו לא נועד להיות הדרך העיקרית להפעיל את המערכת רוב הזמן. אפשר להיות מהירים יותר מזה! כל היישומים החשובים ביותר קשורים ישירות למקשי קיצור נפרדים. מפעילים את המסוף עם `Super + Return` ודפדפן עם `Super + Shift + Return`. נסו לעשות אחד אחרי השני, ותראו את הקסם של הריצוף של Hyprland בפעולה:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

אפשר אז ללחוץ על `Super + J` כדי לערום אותם אחד על גבי השני במקום זה לצד זה:

 ![navigation-stacked](images/navigation-stacked.webp)

לחצו שוב על `Super + J` כדי להחזיר אותם למיקומים שלהם זה לצד זה. אחר כך נסו את `Super + Shift + Arrow Right` בזמן שאתם בדפדפן כדי להחליף בין החלונות.

עכשיו נסו את `Super + Shift + T` כדי להפעיל את מנטר הפעילות. הוא יופיע כחלון צף. אפשר לרצף אותו באמצעות `Super + T` (וללחוץ על זה שוב כדי להפוך אותו שוב לצף). עכשיו לחצו על `Super + Shift + F` כדי לפתוח את מנהל הקבצים. תהיה לכם סידור מסודר של ארבעה:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

מנווטים בין החלון שרוצים שיהיה פעיל באמצעות `Super + Arrow`. זה יעביר את המיקוד ויזיז את הסמן למרכז היישום החדש. בקצה של מסך, זה ממשיך אל הצג שבאותו צד.

אם תלחצו על `Super + Shift + 2`, תעבירו את היישום הממוקד הנוכחי אל סביבת העבודה השנייה. `Super + Shift + 1` מחזיר אותו. (וגם `Super + Shift + Alt + 2` יעביר את היישום הממוקד הנוכחי אל סביבת העבודה השנייה בלי לעבור אליה).

עם יותר מצג אחד, לכל צג יש סביבות עבודה 1 עד 10 משלו. `Super + 2` עובר אל סביבת העבודה השנייה של הצג שבו אתם נמצאים, והשורת העליונה של כל צג מציגה את סביבות העבודה שלו ואת זו שהוא מציג. `Super + Tab` עובר במחזור בין סביבות העבודה בצג שבו אתם נמצאים. `Super + Shift + Ctrl + Arrows` מעביר את החלון שבו אתם נמצאים אל הצג שבאותו כיוון, אל סביבת העבודה שהוא מציג, ו-`Super + Shift + Alt + Arrows` מעביר את סביבת העבודה שבה אתם נמצאים אל הצג שבאותו כיוון, שם היא מקבלת את אותו מספר אם הוא פנוי. צג שומר את סביבות העבודה שלו כשמנתקים אותו: הן מצטרפות לאלו של מסך אחר, ממוספרות אחרי אלו שכבר יש לו, וחוזרות למספרים הישנים שלהן כשהצג חוזר.

אם תחזיקו את `Super` לחוץ ותשתמשו בעכבר כדי ללחוץ על חלון, תוכלו לסדר מחדש איפה הוא יושב. אם תחזיקו את `Super` לחוץ ותשתמשו בכפתור הימני בעכבר, תוכלו לשנות את גודל החלון בחופשיות.

סוגרים חלון באמצעות `Super + W` או `Super + Q` (וסוגרים את כל החלונות באמצעות `Ctrl + Alt + Delete`).

אפשר גם לעבור למסך מלא באמצעות `Super + F` או אפילו רק לרוחב מלא (תוך שמירה על השורה העליונה) באמצעות `Super + Alt + F` או למסך מלא בתוך חלון באמצעות `Super + Ctrl + F` (טוב בשביל YouTube!).

### פריסת dwindle לעומת פריסת גלילה

פריסת ברירת המחדל של Omarchy נקראת dwindle. היא שומרת את כל החלונות שפותחים בסביבת עבודה אחת גלויים בכל עת, גם אם היא צריכה לכווץ אותם.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

אבל אפשר גם לבחור להפוך סביבת עבודה לפריסת הגלילה שבה חלונות מסודרים זה לצד זה, מעבר לקצה הנראה של התצוגה. הופכים סביבת עבודה אחת לפריסה הזאת באמצעות `Super + L`.

לחיצה נוספת על `Super + L` הופכת את סביבת העבודה לצפה, שבה חלונות חופפים בחופשיות ואתם ממקמים אותם בעצמכם, ולחיצה שלישית מחזירה אותה ל-dwindle. `Super + Alt + L` עובר ביניהן בכיוון ההפוך. חלון שצף בכל מקרה — כזה שהוצאתם באמצעות `Super + T`, או יישום שתמיד נפתח כצף — ממשיך לצוף כשסביבת העבודה חוזרת לריצוף. השורה העליונה מסמנת את סביבת העבודה שבה אתם נמצאים עם הפריסה שלה: ריבוע בשביל dwindle, עיגול בשביל גלילה, ומשולש בשביל צפה. לחיצה על הסימן הזה גם היא עוברת במחזור בין הפריסות, וכך גם מקש התצוגה במחשבים ניידים שיש להם אחד.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

הבחירה היא לכל סביבת עבודה, והיא נשארת. כך אפשר להשאיר את סביבת עבודה 1 על dwindle בשביל גלישה ואת סביבת עבודה 2 על גלילה בשביל קוד, והן יחזרו כך אחרי הפעלה מחדש.

אם תרצו להשתמש בפריסת הגלילה כברירת מחדל, אפשר להגדיר זאת ב-`~/.config/hypr/looknfeel.lua`:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### סביבות עבודה צפות

סביבת עבודה צפה עובדת כמו שולחן עבודה מסורתי: חלונות חופפים, ואתם מזיזים וקובעים את הגודל שלהם בעצמכם. כל חלון מקבל שורת כותרת בצבעי ערכת הנושא שלכם, עם כפתורים למזער, להגדיל ולסגור. גם `Super + M` ממזער את החלון הממוקד. חלון ממוזער מחכה ב-dock; לחצו על היישום שלו כדי להחזיר אותו. לחצו על חלון כדי להביא אותו קדימה. שנו את הגודל שלו מכל קצה או פינה. לחצו לחיצה כפולה על שורת כותרת כדי להגדיל את החלון תוך שמירה על השורה העליונה גלויה, ושוב כדי לקבל בחזרה את הגודל הישן שלו. Chrome ודפדפנים אחרים מבוססי Chromium, Disks ו-Document Viewer מדלגים על שורת הכותרת ומשתמשים בכותרת משלהם במקום זאת; `Super + Alt + F` מגדיל אותם, ו-`Super + M` ממזער אותם.

סביבת עבודה צפה מציגה גם dock, עם היישומים המוצמדים שלכם, כל מה שרץ, ורשת של כל יישום מאחורי כפתור היישומים, שאותה גם `Super + Alt + Space` ו-_Apps_ בתפריט Omarchy פותחים. לחצו לחיצה ימנית על יישום ברשת, או לחצו על `Delete`, כדי להסיר את ההתקנה שלו. לחצו על יישום כדי לפתוח אותו, או כדי להביא את החלון שלו קדימה; לחצו שוב כדי לעבור במחזור בין החלונות שלו. Files רק מחזיר חלון מסביבת העבודה שבה אתם נמצאים ואחרת פותח אחד חדש, ו-Terminal ו-Agent תמיד מפעילים עוד אחד, אם כי חלון ממוזער חוזר קודם. לחיצה אמצעית פותחת חלון חדש. גררו סמל לאורך ה-dock כדי להזיז אותו; גרירת יישום רץ פנימה בין האחרים משאירה אותו שם. לחצו לחיצה ימנית כדי להשאיר יישום ב-dock, להוציא אותו, או לצאת ממנו. ה-dock מפנה את הדרך לחלון במסך מלא. לחצו לחיצה ימנית על כפתור היישומים כדי להעביר את ה-dock לקצה אחר או לגרום לו להסתתר עד שהמצביע מגיע לקצה שלו. המיקום נמצא גם תחת _Appearance > Dock > Dock Position_, ו-`omarchy dock position left` ו-`omarchy dock autohide on` מגדירים את שניהם ממסוף. יישומים שאתם משאירים ב-dock דהויים בזמן שהם לא רצים.

סביבות עבודה חדשות, וכל אחת שלא נתתם לה פריסה משלה באמצעות `Super + L`, משתמשות בפריסת ברירת המחדל. שינוי ברירת המחדל מאפס אליה כל סביבת עבודה בלי חלונות, בעוד שאחת שיש עליה חלונות שומרת את הפריסה שיש לה. חלון שממוזער ל-dock עדיין נחשב חלון בסביבת העבודה שהוא עזב. בחרו אותה תחת _Appearance > Workspace Layout_: Tiling, Scrolling, או Floating. `omarchy hyprland workspace layout default scrolling` מגדיר אותה ממסוף.

### קיבוץ חלונות

אפשר לקבץ חלונות באמצעות `Super + G`. ברגע שאתם בקבוצה, כל חלון שתפעילו בזמן שהיא פעילה ישתייך לקבוצה. אפשר לעבור בין החלונות המקובצים האלה באמצעות `Super + Ctrl + Arrow Left/Right` או `Super + Alt + 1/2/3/4` כדי לעבור ישירות לחלונות מקובצים לפי הסדר.

אפשר להוציא חלון מהקיבוץ באמצעות `Super + Alt + G` או לפרק את כל הקבוצה בלחיצה נוספת על `Super + G`. לבסוף, אפשר להעביר חלונות שמחוץ לקבוצה לתוכה באמצעות `Super + Alt + Arrows`.

### הוצאת חלונות

אפשר להוציא חלון מהקצאת סביבת העבודה שלו באמצעות `Super + O`. זה יצמיד אותו כחלון צף שעוקב אחריכם לכל סביבת עבודה שתעברו אליה. נהדר לנגני וידאו וכדומה.

 ![navigation-popped-window](images/navigation-popped-window.webp)

### סביבת עבודת scratchpad

יש סביבת עבודת scratchpad מיוחדת בגודל מלא שמכסה את סביבת העבודה שבה אתם נמצאים כרגע. ניגשים למה שעליה באמצעות `Super + S`, וממקמים שם חלונות באמצעות `Super + Alt + S`.

זה עובד טוב בשביל פקדים או מסוף שרוצים לקיים איתם אינטראקציה במהירות בלי לעזוב את סביבת העבודה הנוכחית.

### קונסולת Quake

לבסוף, יש קונסולת Quake בחצי גובה שיורדת מעל סביבת העבודה שבה אתם נמצאים כרגע. מחליפים את מצבה באמצעות `Super + the key above Tab` (grave בפריסות US), וממקמים שם חלון באמצעות `Super + Shift + the key above Tab`.

בפעם הראשונה שהיא נפתחת, היא מפעילה את הסוכן המוגדר כברירת מחדל שלכם, או מבקשת מכם לבחור אחד אם עדיין לא בחרתם אחד. בזמן שהקונסולה מחזיקה חלון אחד, היא יורדת כחלונית ממורכזת במקום להתפרס על כל המסך. שימו עליה יישום שני והיא תחזור לרוחב המלא, כך שלשניים יהיה מקום לשבת זה לצד זה.

כדי להעביר חלון החוצה מ-scratchpad או מהקונסולה, שלחו אותו ישירות לסביבת עבודה אחרת באמצעות משהו כמו `Super + Shift + 1`.

### לוקח זמן להתרגל לזה!

לוקח קצת זמן להתרגל לנווט בשולחן העבודה שלכם ככה, אבל ברגע שתעשו זאת, יהיה קשה לחזור לחוויית שולחן עבודה מסורתית מונעת עכבר!
