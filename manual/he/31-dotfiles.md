# קבצי Dotfiles

Omarchy מוגדרת בעיקר באמצעות מה שנקרא קבצי dotfiles שנמצאים ב-`~/.config`. אלה נחשבים לקבצים שלך, עבור השינויים שלך. הקבצים שנמצאים ב-`/usr/share/omarchy` שייכים ל-Omarchy עצמה, ולא כדאי לך להתעסק איתם. אם אתה צריך לשנות משהו ב-`/usr/share/omarchy`, עליך לדרוס את הערך ב-`~/.config` במקום זאת.

ניתן לערוך את התצורות המרכזיות ישירות מתפריט Omarchy (`Super + Space`), כמו _Setup > Keybindings_, _Setup > Input_ ו-_Setup > Config > [file]_. כשאתה עושה זאת בדרך הזו, כל תהליך שצריך להיות מופעל מחדש לאחר עריכות תצורה יופעל מחדש אוטומטית לאחר שתצא מהעורך (Neovim כברירת מחדל — `:wq`, זכור! — אבל ניתן לשנות זאת דרך _Setup > Defaults > Editor_).

הנה רשימה של קבצי המפתח ב-`~/.config` ומה הם שולטים בו:

| File                  | Purpose              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | תצורת Hyprland הראשית. טוענת את ברירות המחדל של Omarchy בתוספת קבצי הדריסה שלך שלהלן. [מידע נוסף על תצורות Hyprland](https://wiki.hypr.land/Configuring/).  |
| `~/.config/hypr/bindings.lua` | קיצורי המקשים שלך ודריסות של ברירות המחדל. |
| `~/.config/hypr/monitors.lua` | הגדרות צג שהפאנל של הצג אינו מכסה, כמו סיבוב, מצבים נוספים, או השארת צג כבוי. |
| `~/.config/hypr/input.lua` | שולט בפריסת המקלדת, בעכבר ובהגדרות משטח המגע שלך. |
| `~/.config/hypr/looknfeel.lua` | שולט במרווחים, במסגרות, באנימציות ובשאר המראה. |
| `~/.config/hypr/autostart.lua` | שולט בתהליכים נוספים שמופעלים עם ההפעלה. |
| `~/.config/omarchy/shell.json` | שולט במעטפת של Omarchy: מיקום הסרגל, הפריסה והווידג'טים, בתוספת זמני שומר המסך, הנעילה והסרק. |
| `~/.config/foot/foot.ini` | שולט במסוף שלך (foot היא ברירת המחדל). |
| `~/.XCompose` | מגדיר את האימוג'ים שלך לגישה מהירה ואת ההשלמה האוטומטית של שם/דוא"ל. הקפד להריץ את `omarchy-restart-xcompose` לאחר ביצוע שינויים. |

אם בסופו של דבר תבצע הרבה שינויים כדי לכוונן את ההגדרה שלך, מומלץ לגבות את כל קבצי ה-dotfiles האלה. [Stow היא דרך מצוינת לעשות זאת](https://www.youtube.com/watch?v=NoFiYOqnC4o).

### הפעלת אפליקציות משלך עם ההפעלה

אם אתה רוצה שמשהו ירוץ בכל פעם שאתה מתחבר — daemon לסנכרון, אפליקציית צ'אט, סקריפט משלך — שים אותו ב-`~/.config/hypr/autostart.lua`:

```lua
o.launch_on_start("my-service")
```

זה מפעיל את הפקודה כחלק מההפעלה, כך שהיא מנוקה כראוי כשאתה מתנתק שוב.

### הרצת סקריפטים באירועי מערכת

Omarchy מפעילה hooks במספר רגעים, וניתן לתלות עליהם סקריפטים משלך. הם נמצאים ב-`~/.config/omarchy/hooks/<event>.d/`, ספרייה אחת לכל אירוע, וכל קובץ בר-הרצה שנמצא שם רץ כשהאירוע מתרחש:

| Event | When it runs |
| ----- | ------------ |
| `post-boot` | מיד לאחר ששולחן העבודה הופעל |
| `post-update` | לקראת סוף `omarchy update`, לאחר חבילות, הגירות והפעלות מחדש של שירותים, לפני שכלים של mise מתעדכנים |
| `pre-refresh-pacman` | לאחר ש-`omarchy refresh pacman` מסנכרן מחדש את תצורת החבילות, לפני שהוא מעדכן חבילות; החלפת ערוץ מריצה אותו במהלך אותו שלב רענון |
| `theme-set` | לאחר שינוי ערכת נושא (שם ערכת הנושא ב-`$1`) |
| `font-set` | לאחר שינוי גופן (שם הגופן ב-`$1`) |
| `battery-low` | כשהסוללה חלשה (האחוז ב-`$1`) |

ה-hook `pre-refresh-pacman` הוא המקום שבו שייכים מאגרים מותאמים אישית או שורות `IgnorePkg`, מכיוון שהוא רץ לפני טרנזקציית החבילות. שני ה-hooks הקשורים לעדכון רצים כמשתמש שלך לאחר ש-Omarchy מנקה את הרשאת ה-sudo השמורה במטמון שלה, כך ש-hook שמשתמש ב-`sudo` זקוק להרשאה משלו ועשוי לבקש ממך את הסיסמה.

כל אחת מהספריות האלה כבר מכילה קובץ `.sample` שמראה את צורת ה-hook — הסר את ה-`.sample` מהשם כדי להפעיל אותו. כדי להתקין סקריפט שכתבת במקום אחר, השתמש ב-`omarchy hook install post-boot ~/my-hook`, שמעתיק אותו פנימה והופך אותו לבר-הרצה.

### הוספת רשומות תפריט משלך

ניתן להרחיב את תפריט Omarchy (`Super + Space`) עם שורות משלך על ידי עריכת `~/.config/omarchy/extensions/omarchy-menu.jsonc`. הרשומות ממופתחות לפי id מנוקד, וה-id הוא מה שממקם אותן בעץ, כך ש-`personal` מופיע בתפריט השורש ו-`personal.notes` מופיע בתוכו:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

שימוש חוזר ב-id קיים ידרוס את אותה שורה במקום להוסיף שורה חדשה. הקובץ מגיע עם כל השדות הזמינים מתועדים כהערות.

### הוספת ייצואי shell, פונקציות וכינויים משלך

Omarchy מגיעה עם חבורה של כינויים ארגונומיים ופונקציות מועילות, אבל נפוץ מאוד לרצות להוסיף משלך. עליך להוסיף כינויים, פונקציות וייצואים גם יחד ב-`~/.bashrc`. קובץ זה לא יידרס בעדכונים. אם אתה רוצה לשנות כל אחת מברירות המחדל של Omarchy, תוכל גם להוסיף אותן כאן בבטחה.

### שינוי קבצים פנימיים של Omarchy

תשמע, זה המחשב שלך. אתה יכול לעשות איתו מה שאתה רוצה, אבל הייתי ממליץ שלא לבצע שינויים בקבצים שב-`/usr/share/omarchy` ישירות. הם שייכים לחבילת ה-pacman של Omarchy, כך שהשינויים שלך פשוט יידרסו בעדכון הבא. עדיף לך פשוט לדרוס כל ערך ברירת מחדל שאינו מוצא חן בעיניך בתיקיית `~/.config/*` במקום זאת.

תוכל לשנות כמעט הכול בדרך הזו, כמו קיצורי המקשים של ברירת המחדל. פשוט ערוך את `~/.config/hypr/bindings.lua` כדי, נניח, להחליף את [Obsidian](https://obsidian.md/) ב-[Joplin](https://joplinapp.org/) (התקן באמצעות `omarchy-pkg-add joplin-bin`):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` מסירה את הקישור הקיים לפני הוספת התחליף שלו. היא מקבלת את אותם ארגומנטים כמו `o.bind`, כולל עזרי הפעלה ואפשרויות קישור. השתמש ב-`o.bind` כדי להוסיף קישור, או ב-`hl.unbind` כדי להסיר אחד מבלי להחליפו.

אם אתה מתעקש לפרוץ לקבצים הפנימיים של Omarchy, עבור לערוץ ה-dev דרך _Update > Channel > Dev_. זה מקשר את Omarchy ל-checkout של git של קוד המקור ב-`~/omarchy`, שאתה חופשי לשנות כאוות נפשך. אין פה אף אחד שיגיד לך מה לעשות!

### איפוס כל שינוי

אם בסופו של דבר תעשה בלגן בתצורות, תוכל תמיד להחזיר אותן לברירות המחדל דרך _Update > Config_ בתפריט Omarchy. או על ידי הרצת `omarchy reinstall configs` כדי לאפס הכול.
