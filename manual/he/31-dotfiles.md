# קבצי Dotfiles

Omarchy מוגדרת בעיקר באמצעות מה שנקרא קבצי dotfiles שנמצאים ב-`~/.config`. אלה נחשבים לקבצים שלך, בשביל השינויים שלך. הקבצים שנמצאים ב-`/usr/share/omarchy` שייכים ל-Omarchy עצמה, ולא כדאי שתתעסק איתם. אם אתה צריך לשנות משהו ב-`/usr/share/omarchy`, במקום זאת עליך לדרוס את הערך ב-`~/.config`.

ניתן לערוך את התצורות המרכזיות ישירות מתפריט Omarchy (`Super + Space`), כמו _הגדרות > מקלדת > שיוכי מקשים_, _הגדרות > קלט_ ו-_הגדרות > תצורה > [file]_. כשאתה עושה זאת כך, כל תהליך שצריך הפעלה מחדש לאחר עריכת התצורה יופעל מחדש באופן אוטומטי לאחר שתצא מהעורך (Neovim כברירת מחדל — `:wq`, זכור! — אבל תוכל לשנות זאת דרך _הגדרות > ברירות מחדל > עורך_).

הנה רשימה של הקבצים המרכזיים ב-`~/.config` ומה הם שולטים בו:

| File                  | Purpose              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | תצורת Hyprland הראשית. טוענת את ברירות המחדל של Omarchy וגם את קבצי הדריסה שלך שבהמשך. [למידע נוסף על תצורות Hyprland](https://wiki.hypr.land/Configuring/).  |
| `~/.config/hypr/bindings.lua` | שיוכי המקשים שלך ודריסות של ברירות המחדל. |
| `~/.config/hypr/monitors.lua` | הגדרות צג שפאנל הצגים אינו מכסה, כמו סיבוב, מצבים נוספים או השארת צג כבוי. |
| `~/.config/hypr/input.lua` | שולט בפריסת המקלדת, בעכבר ובהגדרות משטח המגע שלך. |
| `~/.config/hypr/looknfeel.lua` | שולט במרווחים, בגבולות, באנימציות ובשאר המראה. |
| `~/.config/hypr/autostart.lua` | שולט בתהליכים נוספים שמופעלים עם הסשן. |
| `~/.config/omarchy/shell.json` | שולט ב-shell של Omarchy: מיקום הסרגל, הפריסה והווידג'טים, וכן תזמוני שומר המסך, הנעילה וחוסר הפעילות. |
| `~/.config/foot/foot.ini` | שולט במסוף שלך (foot הוא ברירת המחדל). |
| `~/.XCompose` | מגדיר את האימוג'ים לגישה מהירה שלך ואת ההשלמה האוטומטית של שם/אימייל. הקפד להריץ `omarchy-restart-xcompose` לאחר ביצוע שינויים. |

אם בסופו של דבר תעשה הרבה שינויים כדי להתאים את ההגדרה שלך, מומלץ לגבות את כל קבצי ה-dotfiles האלה. [Stow היא דרך מצוינת לעשות זאת](https://www.youtube.com/watch?v=NoFiYOqnC4o).

### הפעלת אפליקציות משלך עם הסשן

אם אתה רוצה שמשהו ירוץ בכל פעם שאתה מתחבר — דמון סנכרון, אפליקציית צ'אט, סקריפט משלך — שים אותו ב-`~/.config/hypr/autostart.lua`:

```lua
o.launch_on_start("my-service")
```

זה מפעיל את הפקודה כחלק מהסשן, כך שהיא מנוקה כראוי כאשר אתה מתנתק שוב.

### הרצת סקריפטים באירועי מערכת

Omarchy מפעילה hooks בכמה רגעים בודדים, ותוכל לתלות עליהם סקריפטים משלך. הם נמצאים ב-`~/.config/omarchy/hooks/<event>.d/`, ספרייה אחת לכל אירוע, וכל קובץ שם שאינו מסתיים ב-`.sample` רץ עם bash כאשר האירוע מתרחש:

| Event | When it runs |
| ----- | ------------ |
| `post-boot` | מיד לאחר ששולחן העבודה הופעל |
| `post-update` | לקראת סוף `omarchy update`, לאחר חבילות, הגירות והפעלות מחדש של שירותים, לפני שכלים של mise מתעדכנים |
| `pre-refresh-pacman` | לאחר ש-`omarchy refresh pacman` מסנכרן מחדש את תצורת החבילות, לפני שהוא מעדכן חבילות; החלפת ערוץ מריצה אותו במהלך אותו שלב רענון |
| `theme-set` | לאחר שינוי ערכת נושא (שם ערכת הנושא ב-`$1`) |
| `font-set` | לאחר שינוי גופן (שם הגופן ב-`$1`) |
| `battery-low` | כאשר הסוללה נחלשת (האחוז ב-`$1`) |

ה-hook `pre-refresh-pacman` הוא המקום שבו שייכים מאגרים מותאמים אישית או שורות `IgnorePkg`, שכן הוא רץ לפני טרנזקציית החבילות. שניהם רצים כמשתמש שלך. `post-update` רץ בזמן שהרשאת ה-sudo של `omarchy update` עדיין טרייה, כך ש-hook שמשתמש ב-`sudo` לא יבקש שוב את הסיסמה שלך; `pre-refresh-pacman` רץ מיד לאחר ש-`omarchy refresh pacman` השתמש בעצמו ב-sudo.

כל אחת מהספריות האלה כבר מכילה קובץ `.sample` שמציג את הצורה של hook — הסר את ה-`.sample` מהשם כדי להפעיל אותו. כדי להתקין סקריפט שכתבת במקום אחר, השתמש ב-`omarchy hook install post-boot ~/my-hook`, שמעתיק אותו פנימה והופך אותו לבר-הרצה.

### הוספת רשומות משלך לתפריט

ניתן להרחיב את תפריט Omarchy (`Super + Space`) עם שורות משלך על ידי עריכת `~/.config/omarchy/extensions/omarchy-menu.jsonc`. הרשומות ממופתחות לפי id מנוקד, וה-id הוא מה שממקם אותן בעץ, כך ש-`personal` מופיע בתפריט השורש ו-`personal.notes` מופיע בתוכו:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

שימוש חוזר ב-id קיים ידרוס את אותה שורה במקום להוסיף שורה חדשה. הקובץ מגיע עם כל השדות הזמינים מתועדים כהערות.

### הוספת ייצואי shell, פונקציות וכינויים משלך

Omarchy מגיעה עם חבורה של כינויים ארגונומיים ופונקציות מועילות, אבל זה מאוד נפוץ לרצות להוסיף משלך. עליך להוסיף כינויים, פונקציות וייצואים ב-`~/.bashrc`. קובץ זה לא יידרס בעדכונים. אם אתה רוצה לשנות אחת מברירות המחדל של Omarchy, תוכל גם להוסיף אותן כאן בבטחה.

### הגדרת משתני סביבה לשולחן העבודה

ייצואים של סשן שולחן העבודה שייכים ל-`~/.config/uwsm/env.d/`. קבצים אלה רצים לפני ששולחן העבודה שלך מופעל, כך ששגיאת shell עלולה לשלוח אותך בחזרה למסך ההתחברות. השאר מסוף עובד פתוח בזמן שאתה עורך אותם. כדי להשבית דריסה, העבר אותה אל מחוץ ל-`env.d`. ראה [שחזור התחברות](45-troubleshooting.md#my-password-is-accepted-but-i-return-to-the-login-screen) אם שינוי מונע התחברות.

### שינוי קבצים פנימיים של Omarchy

תראה, זה המחשב שלך. אתה יכול לעשות איתו מה שאתה רוצה, אבל הייתי ממליץ לא לבצע שינויים בקבצים שב-`/usr/share/omarchy` ישירות. הם שייכים לחבילת ה-pacman של Omarchy, כך שהשינויים שלך פשוט יידרסו בעדכון הבא. עדיף לך פשוט לדרוס בתיקיית `~/.config/*` כל ערך ברירת מחדל שאינך אוהב.

תוכל לשנות כמעט הכל כך, כמו שיוכי המקשים המוגדרים כברירת מחדל. פשוט ערוך את `~/.config/hypr/bindings.lua` כדי, נניח, להחליף את [Obsidian](https://obsidian.md/) ב-[Joplin](https://joplinapp.org/) (התקן עם `omarchy-pkg-add joplin-bin`):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` מסיר את השיוך הקיים לפני שהוא מוסיף את התחליף שלו. הוא מקבל את אותם ארגומנטים כמו `o.bind`, כולל עזרי הפעלה ואפשרויות שיוך. השתמש ב-`o.bind` כדי להוסיף שיוך, או ב-`hl.unbind` כדי להסיר שיוך מבלי להחליף אותו.

אם אתה מתעקש להתעסק בקבצים הפנימיים של Omarchy, עבור לערוץ ה-dev דרך _עדכון > ערוץ > Dev_. זה מקשר את Omarchy ל-checkout של git של קוד המקור ב-`~/omarchy`, שאתה חופשי לשנות ככל העולה על רוחך. אין כאן אף אחד שיגיד לך מה לעשות!

### איפוס כל השינויים

אם בסופו של דבר תעשה בלגן מהתצורות, תוכל תמיד להחזיר אותן לברירות המחדל דרך _עדכון > תצורה_ בתפריט Omarchy. או על ידי הרצת `omarchy reinstall configs` כדי לאפס הכל.
