# Dotfiles

התצורה של Omarchy נקבעת בעיקר באמצעות מה שנקרא dotfiles, שנמצאים ב-`~/.config`. אלה נחשבים לקבצים שלך, בשביל השינויים שלך. הקבצים שנמצאים ב-`/usr/share/omarchy` שייכים ל-Omarchy עצמה, ואל תתעסק איתם. אם אתה צריך לשנות משהו ב-`/usr/share/omarchy`, במקום זאת עליך לדרוס את הערך ב-`~/.config`.

ניתן לערוך את קבצי התצורה המרכזיים ישירות מתפריט Omarchy (`Super + Space`), כמו _הגדרות > מקלדת > שיוכי מקשים_, _הגדרות > קלט_ ו-_הגדרות > תצורה > [file]_. כשאתה עושה זאת בדרך הזו, כל תהליך שצריך הפעלה מחדש אחרי עריכת התצורה יופעל מחדש אוטומטית אחרי שתצא מהעורך (Neovim כברירת מחדל — `:wq`, זכור! — אבל תוכל לשנות זאת דרך _הגדרות > ברירות מחדל > עורך_).

הנה רשימה של קבצי המפתח ב-`~/.config` ומה הם שולטים בו:

| קובץ                  | מטרה              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | קובץ התצורה הראשי של Hyprland. טוען את ברירות המחדל של Omarchy וגם את קבצי הדריסה שלך שלהלן. [מידע נוסף על תצורת Hyprland](https://wiki.hypr.land/Configuring/).  |
| `~/.config/hypr/bindings.lua` | שיוכי המקשים שלך ודריסות של ברירות המחדל. |
| `~/.config/hypr/monitors.lua` | הגדרות צג שהפאנל של הצגים לא מכסה, כמו סיבוב, מצבים נוספים או השארת צג כבוי. |
| `~/.config/hypr/input.lua` | שולט בפריסת המקלדת, בעכבר ובהגדרות משטח המגע שלך. |
| `~/.config/hypr/looknfeel.lua` | שולט במרווחים, בגבולות, באנימציות ובשאר המראה. |
| `~/.config/hypr/autostart.lua` | שולט בתהליכים נוספים שמופעלים עם ההפעלה. |
| `~/.config/omarchy/shell.json` | שולט במעטפת של Omarchy: מיקום הסרגל, הפריסה והווידג'טים, וגם תזמוני שומר המסך, הנעילה ומצב הסרק. |
| `~/.config/foot/foot.ini` | שולט במסוף שלך (foot היא ברירת המחדל). |
| `~/.XCompose` | מגדיר את האימוג'י לגישה מהירה ואת ההשלמה האוטומטית של שם/דוא"ל. הקפד להריץ `omarchy-restart-xcompose` אחרי ביצוע שינויים. |

אם בסופו של דבר תבצע הרבה שינויים כדי להתאים את ההגדרות שלך, מומלץ לגבות את כל קבצי ה-dotfiles האלה. [Stow היא דרך מצוינת לעשות זאת](https://www.youtube.com/watch?v=NoFiYOqnC4o).

### הפעלת האפליקציות שלך יחד עם ההפעלה

אם אתה רוצה שמשהו יפעל בכל פעם שאתה מתחבר — דמון סנכרון, אפליקציית צ'אט, סקריפט שלך — שים אותו ב-`~/.config/hypr/autostart.lua`:

```lua
o.launch_on_start("my-service")
```

זה מפעיל את הפקודה כחלק מההפעלה, כך שהיא מנוקה כראוי כשאתה מתנתק שוב.

### הרצת סקריפטים באירועי מערכת

Omarchy מפעילה hooks בכמה רגעים, ואתה יכול לתלות עליהם את הסקריפטים שלך. הם נמצאים ב-`~/.config/omarchy/hooks/<event>.d/`, ספרייה אחת לכל אירוע, וכל קובץ בר-הפעלה שם מורץ כשהאירוע מתרחש:

| אירוע | מתי הוא רץ |
| ----- | ------------ |
| `post-boot` | מיד לאחר ששולחן העבודה עלה |
| `post-update` | לקראת סוף `omarchy update`, אחרי חבילות, מיגרציות והפעלות מחדש של שירותים, לפני שכלים של mise מתעדכנים |
| `pre-refresh-pacman` | אחרי ש-`omarchy refresh pacman` מסנכרן מחדש את תצורת החבילות, לפני שהוא מעדכן חבילות; החלפת ערוץ מריצה אותו במהלך אותו שלב רענון |
| `theme-set` | אחרי שינוי ערכת נושא (שם ערכת הנושא ב-`$1`) |
| `font-set` | אחרי שינוי גופן (שם הגופן ב-`$1`) |
| `battery-low` | כשהסוללה נחלשת (האחוז ב-`$1`) |

ה-hook של `pre-refresh-pacman` הוא המקום שבו שייכים מאגרים מותאמים אישית או שורות `IgnorePkg`, כי הוא רץ לפני טרנזקציית החבילות. שני ה-hooks הקשורים לעדכון רצים כמשתמש שלך אחרי ש-Omarchy מנקה את הרשאת ה-sudo השמורה במטמון שלה, כך ש-hook שמשתמש ב-`sudo` צריך הרשאה משלו ועלול לבקש את הסיסמה שלך.

בכל אחת מהספריות האלה כבר יש קובץ `.sample` שמראה את הצורה של hook — הסר את `.sample` מהשם כדי להפעיל אותו. כדי להתקין סקריפט שכתבת במקום אחר, השתמש ב-`omarchy hook install post-boot ~/my-hook`, שמעתיק אותו פנימה והופך אותו לבר-הפעלה.

### הוספת פריטי תפריט משלך

ניתן להרחיב את תפריט Omarchy (`Super + Space`) עם שורות משלך על ידי עריכת `~/.config/omarchy/extensions/omarchy-menu.jsonc`. הערכים מקושרים לפי מזהה עם נקודות, והמזהה הוא מה שממקם אותם בעץ, כך ש-`personal` מופיע בתפריט הראשי ו-`personal.notes` מופיע בתוכו:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

שימוש חוזר במזהה קיים ידרוס את אותה שורה במקום להוסיף שורה חדשה. הקובץ מגיע עם כל השדות הזמינים מתועדים כהערות.

### הוספת exports, פונקציות וכינויים משלך למעטפת

Omarchy מגיעה עם חבורה של כינויים ארגונומיים ופונקציות שימושיות, אבל נפוץ מאוד לרצות להוסיף משלך. עליך להוסיף כינויים, פונקציות ו-exports ב-`~/.bashrc`. קובץ זה לא יידרס בעדכונים. אם אתה רוצה לשנות אחת מברירות המחדל של Omarchy, תוכל גם להוסיף אותן בבטחה כאן.

### הגדרת משתני סביבה עבור שולחן העבודה

ה-exports של הפעלת שולחן העבודה שייכים ל-`~/.config/uwsm/env.d/`. קבצים אלה רצים לפני ששולחן העבודה שלך עולה, כך ששגיאת מעטפת עלולה לשלוח אותך בחזרה למסך ההתחברות. השאר מסוף תקין פתוח בזמן שאתה עורך אותם. כדי להשבית דריסה, הוצא אותה מ-`env.d`. ראה [שחזור התחברות](45-troubleshooting.md#my-password-is-accepted-but-i-return-to-the-login-screen) אם שינוי מונע התחברות.

### שינוי קבצים פנימיים של Omarchy

תראה, זה המחשב שלך. אתה יכול לעשות איתו מה שאתה רוצה, אבל אני ממליץ לא לבצע שינויים בקבצים ב-`/usr/share/omarchy` ישירות. הם שייכים לחבילת ה-pacman של Omarchy, כך שהשינויים שלך פשוט יידרסו בעדכון הבא. עדיף פשוט לדרוס כל ערך ברירת מחדל שאתה לא אוהב בתיקיית `~/.config/*` במקום זאת.

אתה יכול לשנות כמעט הכל בדרך הזו, כמו שיוכי המקשים המוגדרים כברירת מחדל. פשוט ערוך את `~/.config/hypr/bindings.lua` כדי, נגיד, להחליף את [Obsidian](https://obsidian.md/) ב-[Joplin](https://joplinapp.org/) (התקן עם `omarchy-pkg-add joplin-bin`):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` מסיר את השיוך הקיים לפני הוספת התחליף שלו. הוא מקבל את אותם הארגומנטים כמו `o.bind`, כולל עזרי הפעלה ואפשרויות שיוך. השתמש ב-`o.bind` כדי להוסיף שיוך, או ב-`hl.unbind` כדי להסיר אחד בלי להחליף אותו.

אם אתה מתעקש לפרוץ את קבצי Omarchy הפנימיים, עבור לערוץ ה-dev דרך _עדכון > ערוץ > Dev_. זה מקשר את Omarchy לעותק git של קוד המקור ב-`~/omarchy`, שאתה חופשי לשנות כאוות נפשך. אין כאן אף אחד שיגיד לך מה לעשות!

### איפוס כל השינויים

אם בסופו של דבר תבלגן את התצורות, תמיד תוכל להחזיר אותן לברירות המחדל דרך _עדכון > תצורה_ בתפריט Omarchy. או על ידי הרצת `omarchy reinstall configs` כדי לאפס הכל.
