# Dotfiles

Omarchy מוגדרת בעיקר דרך מה שמכונה dotfiles, שחיים ב־`~/.config`. אלה נחשבים לקבצים שלך, לשינויים שלך. הקבצים שחיים ב־`/usr/share/omarchy` שייכים ל־Omarchy עצמה, ואין לך מה להתעסק איתם. אם אתה צריך לשנות משהו ב־`/usr/share/omarchy`, עליך במקום זאת לדרוס את הערך ב־`~/.config`.

את תצורות המפתח אפשר לערוך ישירות מתפריט Omarchy (`Super + Space`), כמו _Setup > Keybindings_, ‏_Setup > Input_ ו־_Setup > Config > [file]_. כשאתה עושה זאת כך, כל תהליך שצריך הפעלה מחדש לאחר עריכת התצורה יופעל מחדש אוטומטית לאחר שתצא מהעורך (Neovim כברירת מחדל — `:wq`, זכור! — אבל אפשר לשנות זאת דרך _Setup > Defaults > Editor_).

הנה רשימה של קבצי המפתח ב־`~/.config` ומה הם שולטים בו:

| File                  | Purpose              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | תצורת Hyprland הראשית. טוענת את ברירות המחדל של Omarchy ואת קבצי הדריסה שלך שלהלן. [מידע נוסף על תצורות Hyprland](https://wiki.hypr.land/Configuring/).  |
| `~/.config/hypr/bindings.lua` | קיצורי המקשים שלך ודריסות של ברירות המחדל. |
| `~/.config/hypr/monitors.lua` | הגדרות צג שפאנל הצגים אינו מכסה, כמו סיבוב, מצבים נוספים או השארת צג כבוי. |
| `~/.config/hypr/input.lua` | שולט בפריסת המקלדת, בעכבר ובהגדרות משטח המגע שלך. |
| `~/.config/hypr/looknfeel.lua` | שולט במרווחים, בגבולות, באנימציות ובשאר המראה. |
| `~/.config/hypr/autostart.lua` | שולט בתהליכים נוספים שמופעלים עם הסשן. |
| `~/.config/omarchy/shell.json` | שולט במעטפת Omarchy: מיקום הסרגל, הפריסה והווידג'טים, וכן תזמוני שומר המסך, הנעילה והשהייה. |
| `~/.config/foot/foot.ini` | שולט במסוף שלך (foot היא ברירת המחדל). |
| `~/.XCompose` | מגדיר את האמוג'י שלך לגישה מהירה ואת ההשלמה האוטומטית של שם/אימייל. הקפד להריץ `omarchy-restart-xcompose` לאחר ביצוע שינויים. |

אם בסוף אתה עושה הרבה שינויים כדי להתאים את ההגדרה שלך, כדאי לגבות את כל ה־dotfiles האלה. [Stow היא דרך מצוינת לעשות את זה](https://www.youtube.com/watch?v=NoFiYOqnC4o).

### הפעלת האפליקציות שלך יחד עם הסשן

אם אתה רוצה שמשהו ירוץ בכל פעם שאתה מתחבר — דמון סנכרון, אפליקציית צ'אט, סקריפט משלך — שים אותו ב־`~/.config/hypr/autostart.lua`:

```lua
o.launch_on_start("my-service")
```

זה מפעיל את הפקודה כחלק מהסשן, כך שהיא מנוקה כראוי כשאתה מתנתק שוב.

### הרצת סקריפטים באירועי מערכת

Omarchy מפעילה hooks בכמה רגעים, ואפשר לתלות עליהם את הסקריפטים שלך. הם חיים ב־`~/.config/omarchy/hooks/<event>.d/`, תיקייה אחת לכל אירוע, וכל קובץ ניתן להפעלה שנמצא שם רץ כשהאירוע מתרחש:

| Event | When it runs |
| ----- | ------------ |
| `post-boot` | מיד לאחר ששולחן העבודה הופעל |
| `post-update` | לקראת סוף `omarchy update`, לאחר חבילות, מיגרציות והפעלות מחדש של שירותים, לפני שכלֵי mise מתעדכנים |
| `pre-refresh-pacman` | לאחר ש־`omarchy refresh pacman` מסנכרן מחדש את תצורת החבילות, לפני שהוא מעדכן חבילות; החלפת ערוץ מריצה אותו באותו שלב רענון עצמו |
| `theme-set` | לאחר שינוי ערכת נושא (שם ערכת הנושא ב־`$1`) |
| `font-set` | לאחר שינוי גופן (שם הגופן ב־`$1`) |
| `battery-low` | כשמפלס הסוללה נמוך (האחוז ב־`$1`) |

ה־hook של `pre-refresh-pacman` הוא המקום שאליו שייכים מאגרים מותאמים אישית או שורות `IgnorePkg`, שכן הוא רץ לפני טרנזקציית החבילות. שני ה־hooks הקשורים לעדכון רצים כמשתמש שלך לאחר ש־Omarchy מנקה את הרשאת ה־sudo השמורה במטמון שלה, כך ש־hook שמשתמש ב־`sudo` זקוק להרשאה משלו ועשוי לבקש את הסיסמה שלך.

כל אחת מהתיקיות האלה כבר מחזיקה קובץ `.sample` שמציג את צורתו של hook — הסר את ה־`.sample` מהשם כדי להפעיל אותו. כדי להתקין סקריפט שכתבת במקום אחר, השתמש ב־`omarchy hook install post-boot ~/my-hook`, שמעתיק אותו פנימה והופך אותו לניתן להפעלה.

### הוספת רשומות תפריט משלך

אפשר להרחיב את תפריט Omarchy (`Super + Space`) בשורות משלך על ידי עריכת `~/.config/omarchy/extensions/omarchy-menu.jsonc`. הרשומות ממופתחות לפי מזהה מנוקד, והמזהה הוא מה שממקם אותן בעץ, כך ש־`personal` מופיע בתפריט השורש ו־`personal.notes` מופיע בתוכו:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

שימוש חוזר במזהה קיים ידרוס את אותה שורה במקום להוסיף שורה חדשה. הקובץ מגיע עם כל השדות הזמינים מתועדים כהערות.

### הוספת exports, פונקציות ו־aliases משלך למעטפת

Omarchy מגיעה עם חבורה של aliases ארגונומיים ופונקציות מועילות, אבל נפוץ מאוד לרצות להוסיף משלך. עליך להוסיף גם aliases, גם פונקציות וגם exports ב־`~/.bashrc`. הקובץ הזה לא יידרס בעדכונים. אם אתה רוצה לשנות אי־אילו מברירות המחדל של Omarchy, תוכל גם להוסיף אותן כאן בבטחה.

### הגדרת משתני סביבה לשולחן העבודה

exports של סשן שולחן העבודה שייכים ל־`~/.config/uwsm/env.d/`. הקבצים האלה רצים לפני ששולחן העבודה שלך מופעל, כך ששגיאת מעטפת עלולה לשלוח אותך בחזרה למסך ההתחברות. השאר מסוף תקין פתוח בזמן שאתה עורך אותם. כדי להשבית דריסה, הוצא אותה מ־`env.d`. ראה [שחזור התחברות](45-troubleshooting.md#my-password-is-accepted-but-i-return-to-the-login-screen) אם שינוי מונע התחברות.

### שינוי קבצים פנימיים של Omarchy

תראה, זה המחשב שלך. אתה יכול לעשות איתו מה שאתה רוצה, אבל הייתי ממליץ לא לבצע שינויים ישירות בקבצים שב־`/usr/share/omarchy`. הם שייכים לחבילת ה־pacman של Omarchy, כך שהשינויים שלך פשוט יידרסו בעדכון הבא. עדיף לך פשוט לדרוס בתיקיית `~/.config/*` כל ערך ברירת מחדל שאתה לא אוהב.

אפשר לשנות כך כמעט הכול, כמו קיצורי המקשים של ברירת המחדל. פשוט ערוך את `~/.config/hypr/bindings.lua` כדי, נאמר, להחליף את [Obsidian](https://obsidian.md/) ב־[Joplin](https://joplinapp.org/) (התקן עם `omarchy-pkg-add joplin-bin`):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` מסיר את הקיצור הקיים לפני שהוא מוסיף את המחליף שלו. הוא מקבל את אותם ארגומנטים כמו `o.bind`, כולל עזרי הפעלה ואפשרויות קיצור. השתמש ב־`o.bind` כדי להוסיף קיצור, או ב־`hl.unbind` כדי להסיר אחד בלי להחליף אותו.

אם אתה מתעקש לחטט בקבצים הפנימיים של Omarchy, עבור לערוץ ה־dev דרך _Update > Channel > Dev_. זה מקשר את Omarchy ל־git checkout של קוד המקור ב־`~/omarchy`, שאתה חופשי לשנות ככל העולה על רוחך. אף אחד כאן לא יגיד לך מה לעשות!

### איפוס כל השינויים

אם בסוף אתה עושה בלאגן מהתצורות, תוכל תמיד להחזיר אותן לברירות המחדל דרך _Update > Config_ בתפריט Omarchy. או על ידי הרצת `omarchy reinstall configs` כדי לאפס הכול.
