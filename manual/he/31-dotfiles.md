# קבצי Dotfiles

Omarchy מוגדרת בעיקר דרך מה שנקרא קבצי dotfiles החיים ב-`~/.config`. אלה נחשבים לקבצים שלכם עבור השינויים שלכם. הקבצים החיים ב-`/usr/share/omarchy` שייכים ל-Omarchy עצמה, ואתם לא צריכים להתעסק איתם. אם עליכם לשנות משהו ב-`/usr/share/omarchy`, עליכם לדרוס את הערך ב-`~/.config` במקום זאת.

ניתן לערוך את התצורות העיקריות ישירות מתפריט Omarchy (`Super + Space`), כמו _הגדרה > מסכים_, _הגדרה > קיצורי מקלדת_, _הגדרה > קלט_ ו-_הגדרה > תצורה > [file]_. כשאתם עושים זאת בדרך זו, כל תהליך שצריך הפעלה מחדש לאחר עריכת תצורה באופן אוטומטי יתבצע לאחר שתצאו מהעורך (Neovim כברירת מחדל — `:wq`, זכרו! — אך תוכלו לשנות זאת דרך _הגדרה > ברירות מחדל > עורך_).

הנה רשימה של קבצי המפתח ב-`~/.config` ומה הם שולטים בו:

| קובץ                  | מטרה              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | תצורת Hyprland הראשית. טוענת את ברירות המחדל של Omarchy בנוסף לקבצי הדריסה שלכם להלן. [למדו עוד על תצורות Hyprland](https://wiki.hypr.land/Configuring/).  |
| `~/.config/hypr/bindings.lua` | קיצורי המקלדת משלכם ודריסות של ברירות המחדל. |
| `~/.config/hypr/monitors.lua` | שולט במסכים שלכם, ברזולוציה ובמיקום. |
| `~/.config/hypr/input.lua` | שולט בפריסת המקלדת שלכם, בעכבר ובהגדרות משטח המגע. |
| `~/.config/hypr/looknfeel.lua` | שולט במרווחים, בגבולות, בהנפשות ובשאר המראה. |
| `~/.config/hypr/autostart.lua` | שולט בתהליכים נוספים שהתחילו עם המושב. |
| `~/.config/omarchy/shell.json` | שולט במעטפת Omarchy: מיקום שורה, פריסה ווידג'טים, בנוסף לשומר מסך, נעילה ותזמוני סרק. |
| `~/.config/foot/foot.ini` | שולט במסוף שלכם (foot היא ברירת המחדל). |
| `~/.XCompose` | מגדיר את האימוג'י והשלמת שם/דוא"ל בגישה מהירה שלכם. הקפידו להריץ `omarchy-restart-xcompose` לאחר ביצוע שינויים. |

אם תבצעו הרבה שינויים כדי להתאים את ההגדרה משלכם, זה רעיון טוב לגבות את כל קבצי ה-dotfiles האלה. [Stow היא דרך מצוינת לעשות זאת](https://www.youtube.com/watch?v=NoFiYOqnC4o).

### הפעלת אפליקציות משלכם עם המושב

אם ברצונכם שמשהו יפעל בכל פעם שתיכנסו — daemon סנכרון, אפליקציית צ'אט, סקריפט משלכם — שימו אותו ב-`~/.config/hypr/autostart.lua`:

```lua
o.launch_on_start("my-service")
```

זה מפעיל את הפקודה כחלק מהמושב, כך שהיא מנוקה כראוי כשאתם מתנתקים שוב.

### הרצת סקריפטים באירועי מערכת

Omarchy מפעילה ווים בכמה רגעים, ותוכלו לתלות עליהם סקריפטים משלכם. הם חיים ב-`~/.config/omarchy/hooks/<event>.d/`, ספרייה אחת לכל אירוע, וכל קובץ הניתן להרצה שם פועל כאשר האירוע קורה:

| אירוע | מתי הוא פועל |
| ----- | ------------ |
| `post-boot` | מיד לאחר ששולחן העבודה התחיל |
| `post-update` | קרוב לסוף של `omarchy update`, לאחר חבילות, הגירות והפעלות מחדש של שירותים, לפני שכלי mise מתעדכנים |
| `pre-refresh-pacman` | לאחר ש-`omarchy refresh pacman` מסנכרנת מחדש את תצורת החבילה, לפני שהיא מעדכנת חבילות; מעבר ערוץ מריץ אותה במהלך אותו שלב רענון |
| `theme-set` | לאחר שינוי ערכת נושא (שם ערכת נושא ב-`$1`) |
| `font-set` | לאחר שינוי גופן (שם גופן ב-`$1`) |
| `battery-low` | כשהסוללה מתרוקנת (אחוז ב-`$1`) |

הוו `pre-refresh-pacman` הוא המקום שבו מאגרים מותאמים אישית או שורות `IgnorePkg` שייכים, מכיוון שהוא פועל לפני עסקת החבילה. שני הווים הקשורים לעדכון פועלים כמשתמש שלכם לאחר ש-Omarchy מנקה את אישור ה-sudo השמור שלה, כך שוו שמשתמש ב-`sudo` זקוק לאישור משלו ועלול לבקש את הסיסמה שלכם.

כל אחת מהספריות האלה כבר מחזיקה קובץ `.sample` המראה את צורת הוו — השמיטו את ה-`.sample` מהשם כדי להפעיל אותו. כדי להתקין סקריפט שכתבתם במקום אחר, השתמשו ב-`omarchy hook install post-boot ~/my-hook`, המעתיק אותו פנימה והופך אותו לניתן להרצה.

### הוספת ערכי תפריט משלכם

ניתן להרחיב את תפריט Omarchy (`Super + Space`) עם שורות משלכם על ידי עריכת `~/.config/omarchy/extensions/omarchy-menu.jsonc`. ערכים מקוודים לפי מזהה מנוקד, והמזהה הוא מה שמציב אותם בעץ, כך ש-`personal` מופיע בתפריט השורש ו-`personal.notes` מופיע בתוכו:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

שימוש חוזר במזהה קיים דורס את השורה ההיא במקום להוסיף חדשה. הקובץ נשלח עם כל השדות הזמינים מתועדים כהערות.

### הוספת יצואי מעטפת, פונקציות וכינויים משלכם

Omarchy מגיעה עם שפע של כינויים ארגונומיים ופונקציות מועילות, אבל זה נורמלי מאוד לרצות להוסיף משלכם. עליכם להוסיף הן כינויים, הן פונקציות והן יצואים ב-`~/.bashrc`. קובץ זה לא יידרס בעדכונים. אם ברצונכם לשנות כל אחת מברירות המחדל של Omarchy, תוכלו גם להוסיף אותן בבטחה כאן.

### שינוי קבצי Omarchy פנימיים

שמעו, זה המחשב שלכם. תוכלו לעשות איתו כל מה שתרצו, אבל הייתי ממליץ לא לבצע שינויים בקבצים ב-`/usr/share/omarchy` ישירות. הם שייכים לחבילת ה-pacman של Omarchy, כך שהשינויים שלכם פשוט יידרסו בעדכון הבא. מוטב לכם פשוט לדרוס כל ערך ברירת מחדל שאינכם אוהבים בתיקיית `~/.config/*` במקום זאת.

תוכלו לשנות כמעט כל דבר בדרך זו, כמו קיצורי המקלדת של ברירת המחדל. פשוט ערכו את `~/.config/hypr/bindings.lua` כדי, נניח, להחליף את [Obsidian](https://obsidian.md/) ב-[Joplin](https://joplinapp.org/) (התקינו עם `omarchy-pkg-add joplin-bin`):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` מסיר את הקישור הקיים לפני הוספת התחליף שלו. הוא מקבל את אותם ארגומנטים כמו `o.bind`, כולל עוזרי הפעלה ואפשרויות קישור. השתמשו ב-`o.bind` כדי להוסיף קישור, או ב-`hl.unbind` כדי להסיר אחד מבלי להחליפו.

אם אתם מתעקשים לפרוץ לקבצי Omarchy הפנימיים, עברו לערוץ dev דרך _עדכון > ערוץ > Dev_. זה מקשר את Omarchy לשכפול git של קוד המקור ב-`~/omarchy`, שאתם חופשיים לשנות ככל העולה על רוחכם. אין כאן אף אחד שיאמר לכם מה לעשות!

### איפוס כל שינוי

אם תעשו בלגן מהתצורות, תמיד תוכלו להחזיר אותן לברירות המחדל דרך _עדכון > תצורה_ בתפריט Omarchy. או על ידי הרצת `omarchy reinstall configs` כדי לאפס הכול.
