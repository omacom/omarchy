# דפדפנים

Omarchy מגיעה עם [Chromium](https://www.chromium.org/) כדפדפן ברירת המחדל. זו גרסת הקוד הפתוח הפשוטה, עם ערכת נושא התואמת לשאר המערכת שלכם, והוא מה ש-`Super + Shift + Return` פותח ומה שכל [אפליקציית רשת](25-web-apps.md) רצה בתוכו.

אם Chromium אינו לטעמכם, אינכם תקועים איתו. תחת _התקנה > דפדפן_ בתפריט Omarchy תמצאו את Chrome, Edge, Brave, Brave Origin, Firefox ו-[Zen](https://zen-browser.app/). בחרו אחד ו-Omarchy תתקין אותו, תגדיר את ספריית המדיניות שלו, ותחיל עליו את ערכת הנושא הנוכחית שלכם.

## קביעת אחד כברירת מחדל

התקנת דפדפן אינה מקדמת אותו. לאחר שהוא על המכונה, לכו ל_הגדרה > ברירות מחדל > דפדפן_ ובחרו אותו — התפריט מפרט רק דפדפנים שבאמת התקנתם, ומסמן את ברירת המחדל הנוכחית בסימן וי.

מהמסוף זה:

```bash
omarchy default browser firefox
```

הריצו אותו ללא ארגומנט והוא יאמר לכם את ברירת המחדל הנוכחית. זה קובע את מטפל ה-XDG, כך שלא רק קיצורי המקשים של Omarchy הולכים בעקבותיו — כל דבר שפותח קישור, מאפליקציית צ'אט ועד פקודת מסוף, הולך לדפדפן שבחרתם.

## העתקת URL והורדת וידאו

הדפדפנים ממשפחת Chromium (Chromium עצמו, Chrome, Edge ו-Brave) מגיעים עם שתי הרחבות של Omarchy המגיעות אל מחוץ לדפדפן ואל שאר המערכת שלכם.

**העתקת URL** שמה את כתובת הלשונית הנוכחית על הלוח שלכם עם `Alt + Shift + L`. זה מהיר יותר מלחיצה לתוך שורת הכתובת והעתקה, ומכיוון שזה עובר דרך לוח המערכת ולא של הדפדפן, אתם מקבלים התראת Omarchy המאשרת זאת וה-URL זמין מיד ב[היסטוריית הלוח](08-unified-clipboard-history.md) ובכל אפליקציה אחרת. יש גם לחצן בסרגל הכלים, אם אתם מעדיפים להקליק.

**הורדת וידאו** תופסת את הווידאו המתנגן בעמוד שאתם מסתכלים עליו עם `Alt + Shift + D`. היא מוסרת את ה-URL ל-[yt-dlp](https://github.com/yt-dlp/yt-dlp), כך שהיא עובדת על הרבה יותר מ-YouTube, וההורדה נוחתת ב-`~/Videos`. ההתקדמות מופיעה באותו תצוגת מסך שעוצמת הקול והבהירות משתמשות בה, מתעדכנת במקום במקום להיערם בהתראות. הגדירו `OMARCHY_YTDLP_DIR` אם תעדיפו שהקבצים ילכו למקום אחר — ראו את ה[שאלות נפוצות](46-faq.md) היכן לשים משתני סביבה.

שתי ההרחבות מדברות עם Omarchy דרך מארח הודעות מקומי קטן, שמותקן עבורכם יחד עם הדפדפן. זה החלק שמאפשר לווידאו של דף רשת להגיע לספריית הבית שלכם ול-URL להגיע למנהל הלוח שלכם, מה שהרחבה רגילה אינה יכולה לעשות בכוחות עצמה.

אלה מיועדים למשפחת Chromium בלבד. Firefox ו-Zen אינם מקבלים אותם.

## Firefox ו-Zen

Firefox ו-Zen הן משפחה שונה, כך שהן מקבלות יחס שונה: Omarchy מתקינה קובץ מדיניות לברירות מחדל הגיוניות ומעבירה אותן למצב Wayland מקורי, שתרצו עבור קנה מידה שברירי וגלילת משטח מגע חלקה.

הן אינן מקבלות את הרחבות Chromium לעיל, והן אינן מקבלות ערכת נושא מ-Omarchy, כך שחלקים אלה של החוויה הם שלכם להגדיר.

## הסרת אחד שוב

כל מה שהתקנתם כאן ניתן להסיר שוב תחת _הסרה > דפדפן_. Chromium אינו ברשימה זו — הוא חלק ממערכת הבסיס.
