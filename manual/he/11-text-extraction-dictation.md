# חילוץ טקסט והכתבה

### חילוץ טקסט

לחצו על `Super + Ctrl + PrtScr` כדי לבחור אזור במסך לחילוץ טקסט. מודל ה-OCR בקוד פתוח tesseract ימיר אז במהירות את הבחירה הזו לטקסט ויניח אותה בלוח ההעתקה. לאחר מכן פשוט לחצו על `Super + V` כדי להדביק.

זה שימושי מאוד לחילוץ כתובות מכותרות תחתונות של תמונות או מספרי טלפון שמוטמעים בכותרות של אתרי אינטרנט.

### הכתבה

בהתקנות חדשות, [Superwhisper](https://superwhisper.com/) הוא מנוע ההכתבה המוגדר כברירת מחדל, והוא משתמש בעיבוד בענן ללא הורדת מודלים לשימוש לא מקוון. בחרו ב-Superwhisper, ב-[Voxtype](https://voxtype.io/) או ב-[Hex](https://anoma.ly/hex/) דרך _Setup > Defaults > Dictation_ בתפריט של Omarchy. בחירת מנוע מתקינה אותו במידת הצורך והופכת אותו לברירת המחדל להכתבה. Voxtype טוען מודל בסיסי לאנגלית שתופס 150MB; שנו את המודל באמצעות `voxtype setup model` והגדרות אחרות דרך `~/.config/voxtype/config.toml`. Superwhisper פותח את ההגדרות שלו כדי לבחור עיבוד בענן או מקומי, ו-OPR שומר על האפליקציה מעודכנת. Hex מוריד את מודל הדיבור שלו שפועל על המכשיר במהלך ההגדרה ופועל כשירות המשתמש `hex.service`; פתחו את החלון שלו מסמל המגש שבסרגל או על ידי הרצת `hex` כדי לשנות את המודל והגדרות אחרות.

אתם מכתיבים על ידי החזקת `Right Alt`, או על ידי החלפת מצב עם `Alt + Space`, והטקסט המוכתב יופיע באזור הקלט שנמצא במוקד. קיצורי הדרך האלה משתמשים במנוע שנבחר. Right Alt מתחיל הכתבה גם כאשר משתמשים בו בצירוף של מקשי שינוי; השתמשו ב-Left Alt לצירופים האלה. בפריסות מקלדת שבהן Right Alt הוא AltGr, השתמשו ב-`Alt + Space` כדי ש-AltGr יישאר זמין להקלדה. התקנות מהתקופה שלפני ש-Alt + Space הפך לברירת המחדל שומרות את `F9` ללחיצה לדיבור ואת `Super + Ctrl + X` להחלפת מצב, שנוספו אל `~/.config/hypr/bindings.lua`; הסירו אותם משם כדי להחזיר את המקשים האלה לאפליקציות.

אותם קיצורי דרך פועלים עם כל מנוע. בחרו את המנוע שלכם דרך Setup > Defaults > Dictation. המתקין של המנוע מגדיר אותו ושומר את הבחירה. הריצו את `omarchy default dictation` כדי לראות איזה מנוע נבחר. הבחירה נשמרת ב-`~/.config/omarchy/defaults/dictation`. התקנות חדשות בוחרות ב-Superwhisper באופן אוטומטי.

Omarchy טוען באופן אוטומטי את אינטגרציית שולחן העבודה של המנוע שנבחר. לא נדרשת שום הגדרת תצורה של Superwhisper ב-`~/.config/hypr/`.

קישורי מקשים מותאמים אישית וסקריפטים יכולים להשתמש ב-`omarchy dictation start`, ב-`omarchy dictation stop` וב-`omarchy dictation toggle`. המנוע שנבחר מטפל בהקלטה ובתמלול. בחירה ב-Superwhisper משביתה את קיצור ההחזקה המקורי שלו ומגדירה את החלפת המצב המקורית שלו ל-`Ctrl + Alt + Space`, תוך שמירה על הפרדה ממקשי ההקלטה של Omarchy. Superwhisper דורש לפחות קיצור הקלטה מקורי אחד, וקיצור הביטול שלו נשאר זמין.

מנועים נוספים יכולים להשתלב מבלי לשנות את Omarchy. ספקו קובץ הפעלה בשם `omarchy-dictation-<backend>` ב-PATH שמקבל `start`, `stop` ו-`toggle` וחוזר מיד, עם סטטוס שאינו אפס במקרה של כשל. המתקין שלו מגדיר את הספק וקורא ל-`omarchy-dictation-use <backend>` לאחר הגדרה מוצלחת. פעולה זו עוצרת את המנוע הקודם ושומרת את הבחירה באופן אטומי; `stop` חייב להצליח כאשר הספק לא פעיל או לא זמין. שמות מנועים משתמשים באותיות לטיניות קטנות, בספרות ובמקפים. ספקו את `omarchy-install-dictation-<backend>` לצורך הגדרה; `omarchy default dictation <backend>` מפעיל אותו. הוסיפו ערך בתפריט Defaults דרך הרחבת תפריט של Omarchy כדי לקרוא לבורר הזה. אינטגרציית שולחן עבודה אופציונלית יכולה להיות ב-`${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua`.
