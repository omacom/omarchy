# חילוץ טקסט והכתבה

### חילוץ טקסט

לחצו על `Super + Ctrl + PrtScr` כדי לבחור אזור על המסך לחילוץ טקסט. מודל ה-OCR בקוד פתוח tesseract ימיר אז במהירות את הבחירה הזו לטקסט ויניח אותו בלוח ההעתקה. לאחר מכן פשוט לחצו על `Super + V` כדי להדביק.

זה שימושי מאוד לשליפת כתובות מכותרות תחתונות של תמונות או מספרי טלפון המשובצים בכותרות של אתרי אינטרנט.

### הכתבה

בהתקנות חדשות, [Superwhisper](https://superwhisper.com/) הוא מנוע ההכתבה המוגדר כברירת מחדל, והוא משתמש בעיבוד בענן ללא הורדות של מודלים לא מקוונים. בחרו ב-Superwhisper, ב-[Voxtype](https://voxtype.io/) או ב-[Hex](https://anoma.ly/hex/) דרך _Setup > Defaults > Dictation_ בתפריט Omarchy. בחירת מנוע מתקינה אותו במידת הצורך והופכת אותו לברירת המחדל להכתבה. Voxtype טוען מודל בסיסי באנגלית שתופס 150MB; שנו את המודל עם `voxtype setup model` והגדרות אחרות דרך `~/.config/voxtype/config.toml`. Superwhisper פותח את ההגדרות שלו כדי לבחור בין עיבוד בענן לעיבוד מקומי, ו-OPR שומר על האפליקציה מעודכנת. Hex מוריד את מודל הדיבור שלו הפועל על המכשיר במהלך ההתקנה ורץ כשירות המשתמש `hex.service`; פתחו את החלון שלו מסמל המגש שבסרגל או על ידי הרצת `hex` כדי לשנות את המודל והגדרות אחרות.

אתם מכתיבים על ידי החזקת `Right Alt`, או על ידי מעבר עם `Alt + Space`, והטקסט המוכתב יופיע באזור הקלט הממוקד. קיצורי הדרך האלה משתמשים במנוע שנבחר. Right Alt גם מפעיל הכתבה כאשר משתמשים בו בצירוף מקשי שינוי; השתמשו ב-Left Alt לאותם צירופים. בפריסות מקלדת שבהן Right Alt הוא AltGr, השתמשו ב-`Alt + Space` כדי לשמור את AltGr זמין להקלדה. התקנות מלפני ש-Alt + Space הפך לברירת המחדל שומרות את `F9` לדבר-בלחיצה-והחזקה ואת `Super + Ctrl + X` למעבר, שנוספו ל-`~/.config/hypr/bindings.lua`, שם אותו `Super + Ctrl + X` תופס את מקומו של פאנל הסוכנים; הסירו אותם שם כדי להחזיר את המקשים האלה לאפליקציות ולפאנל.

אותם קיצורי דרך עובדים עם כל מנוע. בחרו את המנוע שלכם דרך Setup > Defaults > Dictation. מתקין המנוע מגדיר אותו ושומר את הבחירה. הריצו את `omarchy default dictation` כדי לראות איזה מהם נבחר. הבחירה נשמרת ב-`~/.config/omarchy/defaults/dictation`. התקנות חדשות בוחרות ב-Superwhisper באופן אוטומטי.

Omarchy טוען את האינטגרציה לשולחן העבודה של המנוע שנבחר באופן אוטומטי. לא נדרשת שום הגדרת Superwhisper ב-`~/.config/hypr/`.

מיפויי מקשים וסקריפטים מותאמים אישית יכולים להשתמש ב-`omarchy dictation start`, ב-`omarchy dictation stop` וב-`omarchy dictation toggle`. המנוע שנבחר מטפל בהקלטה ובתמלול. בחירה ב-Superwhisper מבטלת את קיצור הדרך המקורי שלו להחזקה ומגדירה את המעבר המקורי שלו ל-`Ctrl + Alt + Space`, תוך שמירה על הפרדה ממקשי ההקלטה של Omarchy. Superwhisper דורש לפחות קיצור דרך מקורי אחד להקלטה, וקיצור הדרך שלו לביטול נשאר זמין.

מנועים נוספים יכולים להשתלב מבלי לשנות את Omarchy. ספקו קובץ הפעלה בשם `omarchy-dictation-<backend>` ב-PATH שמקבל `start`, `stop` ו-`toggle` וחוזר מיד, עם סטטוס שאינו אפס במקרה של כשל. המתקין שלו מגדיר את הספק וקורא ל-`omarchy-dictation-use <backend>` לאחר התקנה מוצלחת. פעולה זו עוצרת את המנוע הקודם ושומרת את הבחירה באופן אטומי; `stop` חייב להצליח כאשר הספק במצב חוסר פעילות או אינו זמין. שמות מנועים משתמשים באותיות קטנות, ספרות ומקפים. ספקו את `omarchy-install-dictation-<backend>` להתקנה; `omarchy default dictation <backend>` מפעיל אותו. הוסיפו ערך בתפריט Defaults דרך הרחבת תפריט Omarchy כדי לקרוא לבורר הזה. אינטגרציה אופציונלית לשולחן העבודה יכולה לחיות ב-`${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua`.
