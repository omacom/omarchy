# חילוץ טקסט והכתבה

### חילוץ טקסט

לחצו על `Super + Ctrl + PrtScr` כדי לבחור אזור במסך לחילוץ טקסט. מודל ה-OCR בקוד פתוח tesseract ימיר אז במהירות את הבחירה הזו לטקסט ויניח אותו בלוח ההעתקה. אז פשוט לחצו על `Super + V` כדי להדביק.

זה מועיל מאוד לתפיסת כתובות מכותרות תחתונות של תמונות או מספרי טלפון שמוטבעים בכותרות של אתרים.

 ![text-extraction](images/text-extraction.webp)

### הכתבה

בהתקנות חדשות, [Superwhisper](https://superwhisper.com/) הוא מנגנון ההכתבה המוגדר כברירת מחדל, והוא משתמש בעיבוד בענן בלי הורדות של מודלים לא מקוונים. בחרו ב-Superwhisper, ב-[Voxtype](https://voxtype.io/) או ב-[Hex](https://anoma.ly/hex/) דרך _Setup > Defaults > Dictation_ בתפריט Omarchy. בחירת מנגנון מתקינה אותו במידת הצורך והופכת אותו לברירת המחדל להכתבה. Voxtype טוען מודל אנגלית בסיסי שתופס 150MB; שנו את המודל עם `voxtype setup model` והגדרות אחרות דרך `~/.config/voxtype/config.toml`. Superwhisper פותח את ההגדרות שלו כדי לבחור עיבוד בענן או עיבוד מקומי, ו-OPR שומר על היישום מעודכן. Hex מוריד את מודל הדיבור שלו על המכשיר במהלך ההגדרה ופועל כשירות המשתמש `hex.service`; פתחו את החלון שלו מסמל המגש שבסרגל או על ידי הרצת `hex` כדי לשנות את המודל והגדרות אחרות.

אתם מכתיבים על ידי החזקת `Right Alt`, או על ידי החלפת מצב עם `Alt + Space`, והטקסט המוכתב יופיע באזור הקלט שבמוקד. קיצורי הדרך האלה משתמשים במנגנון שנבחר. Right Alt מפעיל הכתבה גם כשהוא משמש בצירוף של מקשי שינוי; השתמשו ב-Left Alt לצירופים כאלה. בפריסות מקלדת שבהן Right Alt הוא AltGr, כולל כשפריסה כזו היא אחת שאתם עוברים אליה, החזיקו אותו לבדו לרגע כדי להכתיב; AltGr שנלחץ יחד עם מקש אחר עדיין מקליד את התו שלו. התקנות מלפני ש-Alt + Space נעשה ברירת המחדל שומרות על `F9` לדחוף-כדי-לדבר ועל `Super + Ctrl + X` להחלפת מצב, שנוספו ל-`~/.config/hypr/bindings.lua`, שם אותו `Super + Ctrl + X` תופס את מקומו של פאנל הסוכנים; הסירו אותם משם כדי להחזיר את המקשים האלה ליישומים ולפאנל.

אותם קיצורי דרך עובדים עם כל מנגנון. בחרו את המנגנון שלכם דרך Setup > Defaults > Dictation. מתקין המנגנון מגדיר אותו ושומר את הבחירה. הריצו `omarchy default dictation` כדי לראות איזה מהם נבחר. הבחירה נשמרת ב-`~/.config/omarchy/defaults/dictation`. התקנות חדשות בוחרות ב-Superwhisper באופן אוטומטי.

Omarchy טוען באופן אוטומטי את אינטגרציית שולחן העבודה של המנגנון שנבחר. אין צורך בשום הגדרת Superwhisper ב-`~/.config/hypr/`.

קישורים וסקריפטים מותאמים אישית יכולים להשתמש ב-`omarchy dictation start`, ב-`omarchy dictation stop` וב-`omarchy dictation toggle`. המנגנון שנבחר מטפל בהקלטה ובתמלול. בחירה ב-Superwhisper משביתה את קיצור ההחזקה המובנה שלו ומגדירה את החלפת המצב המובנית שלו ל-`Ctrl + Alt + Space`, ושומרת אותה נפרדת ממקשי ההקלטה של Omarchy. Superwhisper דורש לפחות קיצור הקלטה מובנה אחד, וקיצור הביטול שלו נשאר זמין.

מנגנונים נוספים יכולים להשתלב בלי לשנות את Omarchy. ספקו קובץ להפעלה בשם `omarchy-dictation-<backend>` ב-PATH שמקבל את `start`, את `stop` ואת `toggle` וחוזר מיד, עם סטטוס שונה מאפס במקרה של כשל. המתקין שלו מגדיר את הספק וקורא ל-`omarchy-dictation-use <backend>` לאחר הגדרה מוצלחת. פעולה זו עוצרת את המנגנון הקודם ושומרת את הבחירה באופן אטומי; `stop` חייב להצליח כשהספק במצב מנוחה או אינו זמין. שמות מנגנונים משתמשים באותיות קטנות, ספרות ומקפים. ספקו את `omarchy-install-dictation-<backend>` לצורך הגדרה; `omarchy default dictation <backend>` מפעיל אותו. הוסיפו רשומה בתפריט Defaults דרך הרחבת תפריט של Omarchy כדי לקרוא לבורר הזה. אינטגרציית שולחן עבודה אופציונלית יכולה לשכון ב-`${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua`.
