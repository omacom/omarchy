# חילוץ טקסט והכתבה

### חילוץ טקסט

לחצו על `Super + Ctrl + PrtScr` כדי לבחור אזור על המסך לחילוץ טקסט. מודל ה-OCR בקוד פתוח tesseract ימיר אז במהירות את הבחירה הזו לטקסט ויניח אותו על הלוח. אחר כך פשוט לחצו על `Super + V` כדי להדביק.

זה מאוד שימושי לשליפת כתובות מכותרות תחתונות של תמונות או מספרי טלפון שמוטבעים בכותרות של אתרים.

 ![text-extraction](images/text-extraction.webp)

### הכתבה

בהתקנות חדשות, [Superwhisper](https://superwhisper.com/) הוא מנוע ההכתבה המוגדר כברירת מחדל, תוך שימוש בעיבוד ענן ללא הורדות מודלים לא מקוונות. בחרו ב-Superwhisper או ב-[Voxtype](https://voxtype.io/) באמצעות _הגדרה > ברירות מחדל > הכתבה_ בתפריט Omarchy. בחירת מנוע מתקינה אותו במידת הצורך והופכת אותו לברירת המחדל להכתבה. Voxtype טוען מודל אנגלית בסיסי שתופס 150MB; שנו את המודל עם `voxtype setup model` והגדרות אחרות באמצעות `~/.config/voxtype/config.toml`. Superwhisper פותח את הגדרותיו לבחירת עיבוד ענן או מקומי, ו-OPR שומר את האפליקציה מעודכנת.

מכתיבים על ידי החזקת `Right Alt` או `F9`, או על ידי החלפה עם `Super + Ctrl + X`, והטקסט המוכתב יופיע באזור הקלט הממוקד. קיצורי דרך אלה משתמשים במנוע שנבחר. Right Alt גם מתחיל הכתבה כאשר הוא בשימוש בצירוף מקשים משנה; השתמשו ב-Left Alt לצירופים אלה. בפריסות מקלדת שבהן Right Alt הוא AltGr, השתמשו ב-`F9` כדי להשאיר את AltGr זמין להקלדה.

אותם קיצורי דרך עובדים עם כל אחד מהמנועים. בחרו את המנוע שלכם באמצעות הגדרה > ברירות מחדל > הכתבה. מתקין המנוע מגדיר אותו ושומר את הבחירה. הריצו את `omarchy default dictation` כדי לראות איזה נבחר. הבחירה נשמרת ב-`~/.config/omarchy/defaults/dictation`. התקנות חדשות בוחרות ב-Superwhisper אוטומטית.

Omarchy טוענת את שילוב שולחן העבודה של המנוע שנבחר אוטומטית. לא נדרשת שום הגדרת Superwhisper ב-`~/.config/hypr/`.

שיוכים מותאמים אישית וסקריפטים יכולים להשתמש ב-`omarchy dictation start`, ב-`omarchy dictation stop` וב-`omarchy dictation toggle`. המנוע שנבחר מטפל בהקלטה ובתמלול. בחירת Superwhisper משביתה את קיצור ההחזקה המקורי שלו ומגדירה את ההחלפה המקורית שלו ל-`Alt + Space`, תוך שמירה על הפרדה ממקשי ההקלטה של Omarchy. Superwhisper דורש לפחות קיצור הקלטה מקורי אחד, וקיצור הביטול שלו נשאר זמין.

מנועים נוספים יכולים להשתלב בלי לשנות את Omarchy. ספקו קובץ הפעלה בשם `omarchy-dictation-<backend>` על PATH שמקבל את `start`, `stop` ו-`toggle` וחוזר מיד, עם סטטוס שאינו אפס במקרה של כישלון. המתקין שלו מגדיר את הספק וקורא ל-`omarchy-dictation-use <backend>` לאחר הגדרה מוצלחת. זה עוצר את המנוע הקודם ושומר את הבחירה באופן אטומי; `stop` חייב להצליח כאשר הספק במצב סרק או לא זמין. שמות מנועים משתמשים באותיות קטנות, ספרות ומקפים. ספקו את `omarchy-install-dictation-<backend>` להגדרה; `omarchy default dictation <backend>` מפעיל אותו. הוסיפו ערך בתפריט ברירות מחדל באמצעות הרחבת תפריט Omarchy כדי לקרוא לבורר הזה. שילוב שולחן עבודה אופציונלי יכול לחיות ב-`${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua`.
