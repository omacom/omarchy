# חילוץ טקסט והכתבה

### חילוץ טקסט

לחצו על `Super + Ctrl + PrtScr` כדי לבחור אזור על המסך לחילוץ טקסט. מודל ה-OCR בקוד פתוח tesseract ימיר במהירות את הבחירה הזו לטקסט וישים אותו בלוח ההעתקה. לאחר מכן פשוט לחצו על `Super + V` כדי להדביק.

זה שימושי מאוד לקחת כתובות מתוך כותרות תחתונות של תמונות או מספרי טלפון המוטמעים בכותרות של אתרים.

 ![text-extraction](images/text-extraction.webp)

### הכתבה

בהתקנות חדשות, [Superwhisper](https://superwhisper.com/) הוא מנוע ההכתבה המוגדר כברירת מחדל, המשתמש בעיבוד בענן ללא הורדות של מודלים לא מקוונים. בחרו ב-Superwhisper או ב-[Voxtype](https://voxtype.io/) דרך _Setup > Defaults > Dictation_ בתפריט Omarchy. בחירת מנוע מתקינה אותו אם יש צורך וקובעת אותו כברירת מחדל להכתבה. Voxtype טוען מודל בסיסי באנגלית שתופס 150MB; שנו את המודל באמצעות `voxtype setup model` והגדרות אחרות דרך `~/.config/voxtype/config.toml`. Superwhisper פותח את ההגדרות שלו לבחירה בין עיבוד בענן לעיבוד מקומי, ו-OPR שומר שהיישום יישאר מעודכן.

אתם מכתיבים על ידי החזקת `Right Alt` לחוץ, או על ידי מעבר באמצעות `Alt + Space`, והטקסט המוכתב יופיע באזור הקלט הממוקד. קיצורי דרך אלה משתמשים במנוע שנבחר. Right Alt גם מפעיל הכתבה כאשר משתמשים בו בשילוב מקשי שינוי; השתמשו ב-Left Alt לשילובים אלה. בפריסות מקלדת שבהן Right Alt הוא AltGr, השתמשו ב-`Alt + Space` כדי לשמור את AltGr זמין להקלדה. התקנות מלפני ש-Alt + Space הפך לברירת המחדל שומרות על `F9` לדבר-בלחיצה-מתמשכת ועל `Super + Ctrl + X` למעבר, שנוספו ל-`~/.config/hypr/bindings.lua`; הסירו אותם שם כדי להחזיר את המקשים האלה ליישומים.

אותם קיצורי דרך עובדים עם כל אחד מהמנועים. בחרו את המנוע שלכם דרך Setup > Defaults > Dictation. מתקין המנוע מגדיר אותו ושומר את הבחירה. הריצו את `omarchy default dictation` כדי לראות איזה מהם נבחר. הבחירה נשמרת ב-`~/.config/omarchy/defaults/dictation`. התקנות חדשות בוחרות ב-Superwhisper באופן אוטומטי.

Omarchy טוען באופן אוטומטי את אינטגרציית שולחן העבודה של המנוע שנבחר. אין צורך בתצורה של Superwhisper בתוך `~/.config/hypr/`.

קישורים מותאמים אישית וסקריפטים יכולים להשתמש ב-`omarchy dictation start`, ב-`omarchy dictation stop` וב-`omarchy dictation toggle`. המנוע שנבחר מטפל בהקלטה ובתמלול. בחירה ב-Superwhisper משביתה את קיצור הלחיצה המתמשכת המקורי שלו ומגדירה את המעבר המקורי שלו ל-`Ctrl + Alt + Space`, מה ששומר על הפרדה ממקשי ההקלטה של Omarchy. Superwhisper מחייב לפחות קיצור הקלטה מקורי אחד, וקיצור הביטול שלו נשאר זמין.

מנועים נוספים יכולים להשתלב מבלי לשנות את Omarchy. ספקו קובץ הפעלה בשם `omarchy-dictation-<backend>` ב-PATH שמקבל את `start`, `stop` ו-`toggle` וחוזר מיד, עם סטטוס שאינו אפס במקרה של כשל. המתקין שלו מגדיר את הספק וקורא ל-`omarchy-dictation-use <backend>` לאחר התקנה מוצלחת. פעולה זו עוצרת את המנוע הקודם ושומרת את הבחירה באופן אטומי; `stop` חייב להצליח כאשר הספק אינו פעיל או אינו זמין. שמות מנועים משתמשים באותיות קטנות, ספרות ומקפים. ספקו את `omarchy-install-dictation-<backend>` להתקנה; `omarchy default dictation <backend>` מפעיל אותו. הוסיפו ערך בתפריט Defaults דרך הרחבת תפריט של Omarchy כדי לקרוא לבוחר הזה. אינטגרציה אופציונלית לשולחן העבודה יכולה לשכון ב-`${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua`.
