# הגעה מ-Mac או מ-Windows

אם ביליתם שנים ב-macOS או ב-Windows, האצבעות שלכם יודעות מאה דברים שהמוח שלכם כבר שכח שהוא למד אי פעם. הפרק הזה הוא שכבת התרגום: לאן האינסטינקטים האלה הולכים ב-Omarchy. התכונות עצמן מכוסות לעומק במקומות אחרים — זו רק המפה.

### Super הוא מרכז הכול

כל זיכרון השרירים שבניתם סביב Cmd או מקש Windows עובר למקש אחד: Super. זהו מקש Windows במקלדת PC, והוא העוגן כמעט לכל קיצור מקלדת ב-Omarchy.

הרפלקס של Spotlight או Raycast או תפריט התחל הופך ל-`Super + Space`. זה פותח את תפריט Omarchy, שמשיק אפליקציות, משנה הגדרות, מתקין תוכנות, לוכד את המסך — פשוט כמעט הכול. התחילו להקליד כדי לסנן. `Super + Alt + Space` מציג כל אפליקציה על רשת אחת, כפי ש-Launchpad עושה. ראו [ניווט](04-navigation.md).

### אין Dock ואין אייקונים על שולחן העבודה

אין על מה ללחוץ כדי להשיק דברים, אין אייקונים לסדר על שולחן העבודה. אפליקציות מתחילות מקיצור מקלדת (`Super + Return` לטרמינל, `Super + Shift + Return` לדפדפן, ו-`Super + K` לרשימה של כל מה שממופה) או מהתפריט. פיסת ממשק המשתמש הקבועה היחידה היא [שורת התפריט](05-the-top-bar.md), שמכסה את מה ששורת התפריטים, מגש המערכת ומרכז ההתראות עשו עבורכם קודם — וכמעט כל רכיב עליה עושה משהו בלחיצה שמאלית, ימנית ואמצעית.

### החלונות מציבים את עצמם

השינוי המחשבתי הגדול ביותר: אתם לא גוררים חלונות ולא מצמידים אותם לחצאי מסך. פתחו חלון והוא תופס את כל המסך. פתחו שני והם מפצלים אותו. אף פעם לא תדוגו חלון מתחת לחלון אחר, כי חלונות לא חופפים.

כאשר באמת צריך חלון צף, `Super + T` מוציא את החלון הפעיל מהריצוף (ומחזיר אותו). אבל תנו לריצוף הזדמנות אמיתית קודם — זה לב העניין כולו. [ניווט](04-navigation.md) מדריך אתכם בכך.

סביבות עבודה ירגישו מוכרות: הן Spaces של macOS או שולחנות עבודה וירטואליים של Windows, אלא שבאמת תשתמשו בהן, כי `Super + 1/2/3/4` קופץ ישירות לאחת ו-`Super + Shift + 1/2/3/4` שולח את החלון הפעיל לשם. בלי השהיית הנפשה, רק קפיצות מיידיות. המשמעות היא שייתכן שאפילו לא תצטרכו כמה מסכים, אם התרגלתם לכך קודם.

### העתקה והדבקה פשוט עובדות

ב-Mac היה לכם Cmd + C בכל מקום. ב-Windows היה לכם Ctrl + C בכל מקום — חוץ מבטרמינל, שם הוא הורג את התוכנית שלכם. Omarchy נותנת לכם את `Super + C`, `Super + X` ו-`Super + V`, והם עובדים בכל מקום, כולל בטרמינל. אין רפלקס נפרד ללמוד עבור המעטפת.

אנשי Windows: היסטוריית הלוח של Win + V חיה על `Super + Ctrl + V`, והיא מחזיקה גם תמונות וגם טקסט. ראו [לוח מאוחד והיסטוריה](08-unified-clipboard-history.md).

### טבלת התרגום

| אתם מושיטים יד אל | ב-Omarchy |
| ------------- | ---------- |
| Spotlight / Raycast / תפריט התחל | `Super + Space` — תפריט Omarchy |
| AirDrop | LocalSend, באמצעות `Super + Ctrl + S` — ראו [ממשקי GUI](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Print Screen` — ראו [צילומי מסך והקלטה](12-screenshots-recording.md) |
| מרכז התראות | היסטוריית התראות על `Super + Shift + Alt + ,` |
| Time Machine (למערכת) | [תמונות מערכת](47-system-snapshots.md) אוטומטיות בכל עדכון |
| App Store / הורדת מתקין | _התקנה_ בתפריט, או `omarchy pkg add` — ראו [חבילות אחרות](29-other-packages.md) |
| הגדרות מערכת / לוח הבקרה | _הגדרה_ בתפריט, שעורך קובצי הגדרות פשוטים — ראו [dotfiles](31-dotfiles.md) |

### יש דברים שבאמת שונים

הרבה הגדרות חיות בקובצי טקסט שאתם עורכים, לא בלוחות שלוחצים דרכם. זה נשמע פרימיטיבי עד שמבינים שזה אומר שכל שינוי יכול להיראות, להיות מועתק למכונה הבאה שלכם, ולהיות תחת בקרת גרסאות. תפריט _הגדרה_ מפיל אתכם ישירות לקובץ הנכון ומפעיל מחדש את מה שצריך להפעיל מחדש כשסיימתם.

עדכונים מגיעים דרך פקודה אחת — _עדכון > Omarchy_ — שמעדכנת את Omarchy עצמה וכל חבילה במערכת, תוך נטילת תמונת מצב קודם. בלי מעדכנים לכל אפליקציה שמציקים לכם באקראי. ראו [עדכונים](30-updates.md).

תוכנות מגיעות ממנהל חבילות, לא ממתקינים שהורדו.

וכאשר סוגרים חלון, האפליקציה באמת נסגרת. אין את הלימבו של macOS שבו התוכנית ממשיכה לרוץ בלי חלונות. `Super + W` — או `Super + Q`, אם זה זיכרון האצבעות שאיתו הגעתם — פירושו נעלם.

### על חומרת Mac

Omarchy רצה היטב על מחשבי Mac עם Intel — ראו [תמיכה ב-Mac](44-mac-support.md). והמקלדת נדיבה אליכם: Omarchy לא ממפה שום דבר מחדש, ו-Linux מתייחסת למקש Command כאל Super, כך ש-Super יושב בדיוק במקום שבו Cmd תמיד היה. האגודל שלכם לא יבחין במעבר.

### תנו לזה שבועיים

האינסטינקטים עוברים מהר יותר ממה שחשבתם. עברו על פרק [קיצורי המקלדת](07-hotkeys.md) פעם אחת, ובכל פעם שנתקעים על שיוך, לחצו על `Super + K` — הוא מציג לכם את כולם. זה קיצור המקלדת היחיד שבאמת צריך לשנן.
