# המעבר מ-Mac או מ-Windows

אם ביליתם שנים ב-macOS או ב-Windows, האצבעות שלכם יודעות מאה דברים שהמוח שלכם כבר שכח שהוא אי פעם למד. הפרק הזה הוא שכבת התרגום: לאן האינסטינקטים האלה הולכים ב-Omarchy. התכונות עצמן מכוסות לעומק במקומות אחרים — זו רק המפה.

### Super הוא המרכז של הכול

כל זיכרון השרירים שבניתם סביב Cmd או מקש Windows עובר למקש אחד: Super. זהו מקש Windows במקלדת PC, והוא העוגן של כמעט כל קיצור מקשים ב-Omarchy.

הרפלקס שלכם ל-Spotlight או ל-Raycast או לתפריט התחל הופך ל-`Super + Space`. זה פותח את תפריט Omarchy, שמפעיל אפליקציות, משנה הגדרות, מתקין תוכנה, מצלם את המסך — פשוט הכול. התחילו להקליד כדי לסנן. `Super + Alt + Space` מציג כל אפליקציה ברשת אחת, כפי ש-Launchpad עושה. ראו [ניווט](04-navigation.md).

### אין Dock ואין סמלים על שולחן העבודה

אין על מה ללחוץ כדי להפעיל דברים, אין סמלים לסדר על שולחן העבודה. אפליקציות מופעלות מקיצור מקשים (`Super + Return` למסוף, `Super + Shift + Return` לדפדפן, ו-`Super + K` לרשימה של כל מה שממופה) או מהתפריט. פיסת הממשק הקבועה היחידה היא [הסרגל העליון](05-the-top-bar.md), שמכסה את מה ששורת התפריטים, מגש המערכת ומרכז ההתראות עשו עבורכם קודם — וכמעט כל וידג'ט עליו עושה משהו בלחיצה שמאלית, ימנית ואמצעית.

### חלונות ממקמים את עצמם

השינוי התפיסתי הגדול ביותר: לא גוררים חלונות ממקום למקום ולא מצמידים אותם לחצאי מסך. פותחים חלון והוא תופס את כל המסך. פותחים שני והם מחלקים אותו. אף פעם לא צריך לדוג חלון מתחת לאחר, כי חלונות לא חופפים.

כשאתם באמת צריכים חלון צף, `Super + T` מוציא את החלון הפעיל מהריצוף (ומחזיר אותו). אבל תנו לריצוף הזדמנות אמיתית קודם — הוא הלב של כל העניין. [ניווט](04-navigation.md) מדריך אתכם דרכו.

סביבות עבודה ירגישו מוכרות: הן Spaces של macOS או שולחנות עבודה וירטואליים של Windows, אלא שבאמת תשתמשו בהן, כי `Super + 1/2/3/4` קופץ ישירות לאחת ו-`Super + Shift + 1/2/3/4` שולח אליה את החלון הפעיל. אין השהיית אנימציה, רק קפיצות מיידיות. זה אומר שייתכן שלא תצטרכו אפילו כמה צגים, אם הייתם רגילים לזה קודם.

### העתקה והדבקה פשוט עובדות

ב-Mac היה לכם Cmd + C בכל מקום. ב-Windows היה לכם Ctrl + C בכל מקום — חוץ מבמסוף, שם זה הורג את התוכנית שלכם. Omarchy נותנת לכם `Super + C`, `Super + X` ו-`Super + V`, והם עובדים בכל מקום, כולל במסוף. אין רפלקס נפרד ללמוד עבור ה-shell.

אנשי Windows: היסטוריית הלוח שלכם מ-Win + V נמצאת ב-`Super + Ctrl + V`, והיא מחזיקה תמונות וגם טקסט. ראו [לוח והיסטוריה מאוחדים](08-unified-clipboard-history.md).

### טבלת התרגום

| מה שאתם מחפשים | ב-Omarchy |
| ------------- | ---------- |
| Spotlight / Raycast / תפריט התחל | `Super + Space` — תפריט Omarchy |
| AirDrop | LocalSend, באמצעות `Super + Ctrl + S` — ראו [GUIs](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` או `Print Screen` — ראו [צילומי מסך והקלטה](12-screenshots-recording.md) |
| מרכז ההתראות | היסטוריית התראות ב-`Super + Shift + Alt + ,` |
| Time Machine (למערכת) | [תמונות מצב של המערכת](47-system-snapshots.md) אוטומטיות בכל עדכון |
| App Store / הורדת מתקין | _התקנה_ בתפריט, או `omarchy pkg add` — ראו [חבילות אחרות](29-other-packages.md) |
| System Settings / Control Panel | _הגדרה_ בתפריט, שעורכת קובצי תצורה פשוטים — ראו [dotfiles](31-dotfiles.md) |

### יש דברים שבאמת שונים

הרבה הגדרות חיות בקובצי טקסט שאתם עורכים, לא בלוחות שלוחצים דרכם. זה נשמע פרימיטיבי עד שמבינים שזה אומר שכל כוונון קטן אפשר לראות, להעתיק למחשב הבא שלכם, ולשים בבקרת גרסאות. תפריט _ההגדרה_ זורק אתכם ישירות לקובץ הנכון ומפעיל מחדש את מה שצריך להפעיל מחדש כשסיימתם.

עדכונים מגיעים דרך פקודה אחת — _עדכון > Omarchy_ — שמעדכנת את Omarchy עצמה ואת כל חבילה במערכת, ולוקחת קודם תמונת מצב. אין מעדכנים נפרדים לכל אפליקציה שמציקים לכם בזמנים אקראיים. ראו [עדכונים](30-updates.md).

תוכנה מגיעה ממנהל חבילות, לא ממתקינים שהורדו.

וכשאתם סוגרים חלון, האפליקציה באמת נסגרת. אין לימבו של macOS שבו התוכנית ממשיכה לרוץ בלי חלונות. `Super + W` — או `Super + Q`, אם זה זיכרון האצבעות שהגעתם איתו — פירושו נעלמה.

### על חומרת Mac

Omarchy רצה היטב על מחשבי Mac עם Intel — ראו [תמיכה ב-Mac](44-mac-support.md). והמקלדת נחמדה אליכם: Omarchy לא ממפה מחדש שום דבר, ו-Linux מתייחסת למקש Command כאל Super, כך ש-Super יושב בדיוק איפה ש-Cmd תמיד היה. האגודל שלכם לא יבחין במעבר.

### תנו לזה שבועיים

האינסטינקטים עוברים מהר יותר ממה שהייתם חושבים. רפרפו פעם אחת על פרק [קיצורי המקשים](07-hotkeys.md), ובכל פעם שנתקע לכם מיפוי בראש, לחצו על `Super + K` — הוא מראה לכם את כולם. זה קיצור המקשים היחיד שאתם באמת צריכים לזכור בעל פה.
