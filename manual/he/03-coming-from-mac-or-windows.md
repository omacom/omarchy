# מגיעים מ-Mac או מ-Windows

אם ביליתם שנים ב-macOS או ב-Windows, האצבעות שלכם יודעות מאה דברים שהמוח שלכם כבר שכח שלמד אי פעם. הפרק הזה הוא שכבת התרגום: לאן האינסטינקטים האלה הולכים ב-Omarchy. התכונות עצמן מכוסות לעומק במקומות אחרים — זו רק המפה.

### Super הוא מרכז הכול

כל זיכרון השרירים שבניתם סביב Cmd או מקש Windows עובר למקש אחד: Super. זהו מקש Windows במקלדת PC, והוא העוגן של כמעט כל קיצור מקשים ב-Omarchy.

הרפלקס שלכם של Spotlight או Raycast או תפריט ההתחלה הופך ל-`Super + Space`. זה פותח את תפריט Omarchy, שמפעיל אפליקציות, משנה הגדרות, מתקין תוכנה, מצלם את המסך — בעצם הכול. התחילו להקליד כדי לסנן. `Super + Alt + Space` מציג כל אפליקציה ברשת אחת, כמו ש-Launchpad עושה. ראו [ניווט](04-navigation.md).

### אין אייקונים על שולחן העבודה, וה-dock לא מפריע

אין אייקונים לסדר על שולחן העבודה, וה-dock מתחבא ברגע שבמרחב עבודה יש חלון, עד שדוחפים את הסמן לקצה המסך שלו, הימני אלא אם מעבירים אותו (ראו [ניווט](04-navigation.md)). אפליקציות מתחילות מקיצור מקשים (`Super + Return` לטרמינל, `Super + Shift + Return` לדפדפן, ו-`Super + K` לרשימה של כל מה שממופה) או מהתפריט. פיסת ממשק המשתמש הקבועה היחידה היא [הסרגל העליון](05-the-top-bar.md), שמכסה את מה ששורת התפריטים, מגש המערכת ומרכז ההתראות עשו עבורכם קודם — וכמעט כל וידג'ט עליו עושה משהו בלחיצה שמאלית, ימנית ואמצעית.

### חלונות ממקמים את עצמם

שינוי התפיסה הגדול ביותר: אתם לא גוררים חלונות ולא מצמידים אותם לחצאי מסך. פותחים חלון והוא תופס את כל המסך. פותחים שני והם מפצלים אותו. לעולם לא תדוגו חלון מתחת לאחר, כי חלונות לא חופפים.

כשאתם באמת צריכים חלון צף, `Super + T` מוציא את החלון הפעיל מהריצוף (ומחזיר אותו). אבל תנו לריצוף הזדמנות אמיתית קודם — זה הלב של כל העניין. [ניווט](04-navigation.md) ילווה אתכם בזה.

מרחבי עבודה ירגישו מוכרים: הם Spaces של macOS או שולחנות עבודה וירטואליים של Windows, אלא שבאמת תשתמשו בהם, כי `Super + 1/2/3/4` קופץ ישירות לאחד ו-`Super + Shift + 1/2/3/4` שולח את החלון הפעיל לשם. אין השהיית אנימציה, רק קפיצות מיידיות. זה אומר שאולי אפילו לא תצטרכו כמה מסכים, אם הייתם רגילים לזה קודם.

### העתקה והדבקה פשוט עובדות

ב-Mac היה לכם Cmd + C בכל מקום. ב-Windows היה לכם Ctrl + C בכל מקום — חוץ מבטרמינל, שם זה הורג את התוכנית שלכם. Omarchy נותנת לכם `Super + C`, `Super + X` ו-`Super + V`, והם עובדים בכל מקום, כולל הטרמינל. אין רפלקס נפרד ללמוד עבור ה-shell.

אנשי Windows: היסטוריית הלוח שלכם של Win + V נמצאת ב-`Super + Ctrl + V`, והיא מחזיקה תמונות וגם טקסט. ראו [לוח והיסטוריה מאוחדים](08-unified-clipboard-history.md).

### טבלת התרגום

| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` או `Print Screen` — ראו [צילומי מסך והקלטה](12-screenshots-recording.md) |
| Notification Center | היסטוריית התראות ב-`Super + Shift + Alt + ,` |
| Time Machine (למערכת) | [תמונות מצב של המערכת](47-system-snapshots.md) אוטומטיות בכל עדכון |
| App Store / הורדת מתקין | _Install_ בתפריט, או `omarchy pkg add` — ראו [חבילות נוספות](29-other-packages.md) |
| System Settings / Control Panel | _Setup_ בתפריט, שעורך קבצי קונפיגורציה פשוטים — ראו [dotfiles](31-dotfiles.md) |
| Finder / File Explorer | Files, ב-`Super + Shift + F` — ראו [ממשקים גרפיים](22-guis.md) |
| Safari / Edge | Google Chrome ב-`Super + Shift + Return`; בחרו אחר תחת _Setup > Defaults > Browser_ — ראו [דפדפנים](23-browsers.md) |
| Preview / Photos | Omaview לתמונות, וידאו ומוזיקה, Document Viewer לקבצי PDF — ראו [ממשקים גרפיים](22-guis.md) |
| TextEdit / Notepad | Plain, ב-`Super + Shift + N`; בחרו אחר תחת _Setup > Defaults > Editor_ |

### יש דברים שבאמת שונים

הרבה הגדרות נמצאות בקבצי טקסט שאתם עורכים, לא בלוחות שלוחצים דרכם. זה נשמע פרימיטיבי עד שמבינים שזה אומר שכל כוונון אפשר לראות, להעתיק למחשב הבא שלכם, ולשים בבקרת גרסאות. תפריט _Setup_ זורק אתכם ישירות לקובץ הנכון ומפעיל מחדש את מה שצריך להפעיל מחדש כשסיימתם.

עדכונים מגיעים דרך פקודה אחת — _Update > Omarchy_ — שמעדכנת את Omarchy עצמה ואת כל חבילה במערכת, ולוקחת תמונת מצב קודם. אין מעדכנים נפרדים לכל אפליקציה שמציקים לכם באקראי. ראו [עדכונים](30-updates.md).

תוכנה מגיעה ממנהל חבילות, לא ממתקינים שהורדו.

וכשסוגרים חלון, האפליקציה באמת נסגרת. אין לימבו של macOS שבו התוכנית ממשיכה לרוץ בלי חלונות. `Super + W` — או `Super + Q`, אם זה זיכרון האצבעות שהגעתם איתו — אומר נעלם.

### על חומרת Mac

Omarchy רצה היטב על מחשבי Mac עם Intel, ועל מחשבי Mac עם M1, M2 ו-M3 עם Omarchy for Apple Silicon. ראו [תמיכה ב-Mac](44-mac-support.md). והמקלדת נחמדה אליכם: Omarchy לא ממפה מחדש שום דבר, ו-Linux מתייחסת למקש Command כ-Super, אז Super יושב בדיוק איפה ש-Cmd תמיד היה. האגודל שלכם לא ישים לב למעבר.

### תנו לזה שבועיים

האינסטינקטים עוברים מהר יותר ממה שחושבים. רפרפו פעם אחת על פרק [קיצורי המקשים](07-hotkeys.md), ובכל פעם שנתקעים על מיפוי, לחצו על `Super + K` — הוא מראה לכם את כולם. זה קיצור המקשים היחיד שאתם באמת צריכים לשנן.
