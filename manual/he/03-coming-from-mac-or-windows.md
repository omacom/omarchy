# מגיעים מ-Mac או מ-Windows

אם ביליתם שנים ב-macOS או ב-Windows, האצבעות שלכם יודעות מאה דברים שהמוח שלכם כבר שכח שהוא אי פעם למד. הפרק הזה הוא שכבת התרגום: לאן האינסטינקטים האלה עוברים ב-Omarchy. התכונות עצמן מכוסות לעומק במקומות אחרים — זו רק המפה.

### Super הוא מרכז הכול

כל זיכרון השרירים שבניתם סביב Cmd או מקש Windows עובר למקש אחד: Super. זהו מקש Windows במקלדת PC, והוא העוגן של כמעט כל מקש קיצור ב-Omarchy.

הרפלקס של Spotlight או Raycast או תפריט ההתחלה שלכם הופך ל-`Super + Space`. זה פותח את תפריט Omarchy, שמפעיל אפליקציות, משנה הגדרות, מתקין תוכנות, מצלם את המסך — פשוט כמעט הכול. התחילו להקליד כדי לסנן. `Super + Alt + Space` מציג כל אפליקציה ברשת אחת, כמו ש-Launchpad עושה. ראו [ניווט](04-navigation.md).

### אין סמלים על שולחן העבודה, וה-dock מופיע רק כשצפים

אין סמלים לסדר על שולחן העבודה, ואין dock במרחב עבודה מרוצף — ה-dock מופיע רק במרחב עבודה צף (ראו [ניווט](04-navigation.md)). אפליקציות מופעלות ממקש קיצור (`Super + Return` למסוף, `Super + Shift + Return` לדפדפן, ו-`Super + K` לרשימה של כל מה שממופה) או מהתפריט. חלק הממשק הקבוע היחיד הוא [הסרגל העליון](05-the-top-bar.md), שמכסה את מה ששורת התפריטים, מגש המערכת ומרכז ההתראות עשו עבורכם קודם — וכמעט כל וידג'ט עליו עושה משהו בלחיצה שמאלית, ימנית ואמצעית.

### חלונות ממקמים את עצמם

השינוי התפיסתי הגדול ביותר: לא גוררים חלונות ולא מצמידים אותם לחצאי מסך. פותחים חלון והוא תופס את כל המסך. פותחים שני והם מפצלים אותו. אף פעם לא דגים חלון מתחת לאחר, כי חלונות לא חופפים.

כשאתם באמת צריכים חלון צף, `Super + T` מחליף את החלון הפעיל אל מחוץ לריצוף (ובחזרה). אבל תנו לריצוף הזדמנות אמיתית קודם — זה הלב של כל העניין. [ניווט](04-navigation.md) מלווה אתכם בזה.

מרחבי עבודה ירגישו מוכרים: הם Spaces של macOS או שולחנות עבודה וירטואליים של Windows, חוץ מזה שבאמת תשתמשו בהם, כי `Super + 1/2/3/4` קופץ ישירות לאחד ו-`Super + Shift + 1/2/3/4` שולח לשם את החלון הפעיל. בלי עיכוב אנימציה, רק קפיצות מיידיות. זה אומר שאולי אפילו לא תצטרכו כמה מסכים, אם הייתם רגילים לזה קודם.

### העתקה והדבקה פשוט עובדות

ב-Mac היה לכם Cmd + C בכל מקום. ב-Windows היה לכם Ctrl + C בכל מקום — חוץ מבמסוף, שם זה הורג את התוכנית שלכם. Omarchy נותן לכם `Super + C`, `Super + X` ו-`Super + V`, והם עובדים בכל מקום, כולל במסוף. אין רפלקס נפרד ללמוד בשביל ה-shell.

אנשי Windows: היסטוריית לוח הגזירים שלכם מ-Win + V חיה על `Super + Ctrl + V`, והיא מחזיקה גם תמונות וגם טקסט. ראו [לוח גזירים והיסטוריה מאוחדים](08-unified-clipboard-history.md).

| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` או `Print Screen` — ראו [צילומי מסך והקלטה](12-screenshots-recording.md) |
| מרכז ההתראות | היסטוריית התראות על `Super + Shift + Alt + ,` |
| Time Machine (למערכת) | [תמונות מצב אוטומטיות של המערכת](47-system-snapshots.md) בכל עדכון |
| App Store / הורדת מתקין | _Install_ בתפריט, או `omarchy pkg add` — ראו [חבילות אחרות](29-other-packages.md) |
| הגדרות מערכת / לוח בקרה | _Setup_ בתפריט, שעורך קובצי תצורה פשוטים — ראו [dotfiles](31-dotfiles.md) |
| Finder / File Explorer | Files, על `Super + Shift + F` — ראו [GUIs](22-guis.md) |

### יש דברים שבאמת שונים

הרבה הגדרות חיות בקובצי טקסט שאתם עורכים, לא בפאנלים שאתם מקליקים דרכם. זה נשמע פרימיטיבי עד שמבינים שזה אומר שכל שינוי קטן אפשר לראות, להעתיק למכונה הבאה שלכם, ולשים בבקרת גרסאות. תפריט _Setup_ זורק אתכם ישירות לקובץ הנכון ומפעיל מחדש את מה שצריך להפעיל מחדש כשסיימתם.

עדכונים מגיעים דרך פקודה אחת — _Update > Omarchy_ — שמעדכנת את Omarchy עצמה ואת כל חבילה במערכת, ולוקחת תמונת מצב קודם. אין מעדכני אפליקציות נפרדים שמציקים לכם באקראי. ראו [עדכונים](30-updates.md).

תוכנות מגיעות ממנהל חבילות, לא ממתקינים שהורדו.

וכשאתם סוגרים חלון, האפליקציה באמת נסגרת. אין לימבו של macOS שבו התוכנית ממשיכה לרוץ בלי חלונות. `Super + W` — או `Super + Q`, אם זה זיכרון האצבעות שהגעתם איתו — אומר נעלם.

### על חומרת Mac

Omarchy רץ היטב על מחשבי Mac עם Intel — ראו [תמיכה ב-Mac](44-mac-support.md). והמקלדת נדיבה אליכם: Omarchy לא ממפה מחדש שום דבר, ו-Linux מתייחס למקש Command כ-Super, אז Super יושב בדיוק איפה ש-Cmd תמיד היה. האגודל שלכם לא ישים לב למעבר.

### תנו לזה שבועיים

האינסטינקטים עוברים מהר יותר ממה שהייתם חושבים. רפרפו פעם אחת על פרק [מקשי הקיצור](07-hotkeys.md), ובכל פעם שנתקעתם על מיפוי, לחצו `Super + K` — הוא מראה לכם את כולם. זה מקש הקיצור היחיד שאתם באמת צריכים לזכור.
