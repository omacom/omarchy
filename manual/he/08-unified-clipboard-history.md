# לוח גזירים מאוחד והיסטוריה

בדרך כלל בלינוקס, צריך `Ctrl + Shift + C/V` כדי להעתיק ולהדביק במסוף ו-`Ctrl + C/V` כדי לעשות זאת בכל מקום אחר. קשה להתרגל לזה לכל מי שלא נולד וגדל על לינוקס! כך גם המעבר מ-Super ל-Ctrl, אם אתם מגיעים מה-Mac.

Omarchy מטפלת בשתי הבעיות עם מקשי קיצור מאוחדים ללוח הגזירים שעובדים (כמעט) בכל מקום. הם:

| מקש קיצור | פעולה |
| ------- | ----------- |
| Super + A | בחירת הכל |
| Super + C | העתקה |
| Super + X | גזירה |
| Super + V | הדבקה |
| Super + Ctrl + V | היסטוריית לוח הגזירים |

_שימו לב שרוב מעטפות הסוכנים ישתמשו ב-`Ctrl + V` להדבקת תמונות, אבל ב-`Super + V` להדבקת טקסט._

השתמשו ב-`Super + A`, ואז ב-`Super + C` כדי להעתיק הכל בשדה טקסט ממוקד או באפליקציה אחרת שתומכת ב-`Ctrl + A`. במסוף, `Ctrl + A` מעביר לתחילת שורת הפקודה במקום לבחור את הטקסט שלה.

### היסטוריית לוח הגזירים

היסטוריית לוח הגזירים מסופקת על ידי מעטפת Omarchy ועובדת גם עבור טקסט וגם עבור תמונות. מפעילים אותה באמצעות `Super + Ctrl + V` ובוחרים את הערך שלכם עם Return, מה שמדביק אותו ישירות לאפליקציה שהייתם בה. השתמשו ב-`Shift + Return` כדי רק להעתיק אותו ללוח הגזירים, ב-`Alt + Return` כדי לפתוח אותו, ב-`Delete` כדי להסיר אותו מההיסטוריה, וב-`Shift + Delete` כדי לנקות את כל ההיסטוריה.
