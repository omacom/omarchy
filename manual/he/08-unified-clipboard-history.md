# לוח מאוחד והיסטוריה

בדרך כלל ב-Linux, צריך את `Ctrl + Shift + C/V` כדי להעתיק ולהדביק בטרמינל ואת `Ctrl + C/V` כדי לעשות זאת בכל מקום אחר. קשה להתרגל לזה למי שלא נולד וגדל על Linux! כך גם המעבר מ-super ל-ctrl, אם אתם מגיעים מ-Mac.

Omarchy מתמודדת עם שתי הבעיות עם קיצורי לוח מאוחדים שעובדים (כמעט) בכל מקום. הם:

| קיצור מקלדת | פקודה |
| ------- | ----------- |
| Super + C | העתקה |
| Super + X | גזירה |
| Super + V | הדבקה |
| Super + Ctrl + V | היסטוריית לוח |

_שימו לב שרוב מסגרות הסוכנים ישתמשו ב-`Ctrl + V` להדבקת תמונות, אבל ב-`Super + V` להדבקת טקסט._

### היסטוריית לוח

היסטוריית הלוח מסופקת על ידי מעטפת Omarchy ועובדת הן לטקסט והן לתמונות. מפעילים אותה עם `Super + Ctrl + V`, בוחרים את הערך עם return, ואחר כך הוא יונח על הלוח מוכן להדבקה עם `Super + V`.
