# שורת התפריט

הפס לאורך החלק העליון של המסך הוא שורת Omarchy. זו אינה שורת מצב שהוברגה על המערכת אלא חלק ממעטפת Omarchy, תהליך ה-Quickshell ארוך-הריצה היחיד שמצייר גם את התפריט, את ההתראות, את חלוניות ה-OSD ואת מסך הנעילה. לכן היא מקבלת ערכת נושא מושלמת עם כל השאר, ולכן פנל נפתח מיד במקום להשיק אפליקציה חדשה.

זו גם פיסת שולחן העבודה היחידה שתמיד על המסך, אז כדאי לדעת מה כל הגליפים הקטנים האלה עושים.

## מה יש עליה כברירת מחדל

לשורה יש שלושה מקטעים. משמאל יושבים לוגו Omarchy (מפעיל התפריט) ומחווני סביבות העבודה. במרכז מקבלים את מחווני המצב, את השעון, את Elsewhen (שעון עולם), את מזג האוויר ואת תג עדכון Omarchy. מימין: פריסת המקלדת (כאשר מוגדרת יותר מאחת), מגש המערכת, סוכנים, bluetooth, רשת, שמע, תצוגה וכוח.

כמה מהם מופיעים רק כאשר יש להם מה לומר. פריסת המקלדת מופיעה רק אם הגדרתם יותר מפריסה אחת. תג העדכון מופיע רק כאשר ממתין עדכון Omarchy. ואייקון הסוכנים מופיע בפעם הראשונה ש-Omarchy מוצאת שימוש בסוכני קידוד AI במכונה (ראו [AI](17-ai.md)).

## לחיצות מסביב

כמעט כל רכיב עושה משהו בלחיצה שמאלית, ימנית ואמצעית, ומספר מהם מגיבים לגלילה. זה החלק שאנשים מפספסים — הכפתורים הימני והאמצעי הם המקום שבו הרבה מהדברים הטובים מתחבאים.

| רכיב | שמאל | ימין | אמצע / גלילה |
| --- | --- | --- | --- |
| תפריט | תפריט Omarchy | טרמינל חדש | — |
| סביבות עבודה | מיקוד בסביבת עבודה זו | — | גלילה: סביבת עבודה הבאה/הקודמת |
| שעון | חלונית לוח שנה | החלפת פורמט התווית במחזוריות | אמצע: בורר אזור זמן |
| מזג אוויר | חלונית תחזית | מזג אוויר מלא כהתראה | אמצע: רענון |
| שמע | פנל שמע | השתקה | אמצע: פנל · גלילה: עוצמה |
| מיקרופון | השתקת המיקרופון | — | אמצע: פנל שמע · גלילה: עוצמת קלט |
| רשת | פנל רשת | — | — |
| Bluetooth | פנל Bluetooth | החלפת הרדיו | — |
| תצוגה | פנל תצוגה | — | גלילה: בהירות |
| כוח | פנל כוח | החלפת אחוז הסוללה | — |
| מדיה | ניגון/השהיה | חלונית תמונת שער | אמצע: הבא · גלילה: הקודם/הבא |
| סוכנים | פנל סוכנים | הפעלת הסוכן שלכם | אמצע: המנוי הבא |
| מגש | מעבר עכבר לחשיפת המגירה | ימין על הסימן לניהול | — |
| עדכון Omarchy | הרצת העדכון | — | — |

לא כל מה בטבלה נמצא על השורה שלכם מהקופסה. רכיב המדיה (MPRIS שמנגן עכשיו, עם רצועה ואמן גוללים) ורכיב המיקרופון שניהם מובנים אבל כבויים כברירת מחדל — הוסיפו אותם אם תרצו, כמתואר להלן.

## הפנלים

לחיצה על אייקון בשורה פותחת פנל, שהוא חלונית ראויה עם מחוונים, רשימות וניווט מקלדת ולא רמז כלים. לכל אחד יש גם קיצור מקלדת, כך שלעולם לא תצטרכו לכוון לגליף של 16 פיקסלים:

| קיצור מקלדת | פנל |
| --- | --- |
| `Super + Ctrl + A` | שמע |
| `Super + Ctrl + W` | רשת |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | תצוגה |
| `Super + Ctrl + P` | כוח |
| `Super + Ctrl + Alt + D` | לוח שנה |
| `Super + Ctrl + Alt + E` | שעון עולם |
| `Super + Ctrl + 1-9` | החלפת הפנל ה-n במקטע הימני |

הפנלים אינם קריאות מצב. הם המקום שבו באמת עושים את הדבר:

- **שמע** כולל מחוון עוצמה ראשי, בורר התקן פלט ומערבל לכל אפליקציה, כך שאפשר להנמיך את אותה לשונית דפדפן אחת בלי לגעת בכל השאר.
- **רשת** סורק Wi-Fi, מציג עוצמת אות, מתחבר ומאפשר לבחור ספק DNS.
- **Bluetooth** מפרט את ההתקנים שלכם עם חיבור/ניתוק ורמות סוללה.
- **כוח** מציג נתוני סוללה, מחליף פרופילי כוח (הוא זוכר בחירה נפרדת לסוללה ול-AC) ומדפיס קצת מידע מערכת.
- **תצוגה** נושא מחוון בהירות, גודל טקסט, הגדרות קנה מידה למסך, ו — כאשר יש יותר ממסך אחד — פקדים לכל מסך. ראו [מסכים](33-monitors.md) לסיפור העמוק יותר.
- **שעון** פותח רשת חודש עם מספרי שבוע ISO ומעבר בין חודשים.

כל פנל מקבל את המקלדת וגם את העכבר: חצים זוים, Return מפעיל, Tab צועד לפנל השכן, ו-Escape סוגר.

`Super + Ctrl + 1-9` סופר פנלים משמאל לימין במקטע הימני, תוך דילוג על המגש מאחר שאין לו פנל משלו. כך המספר תואם לאייקון שהייתם מצביעים עליו.

### Tailscale ו-Dropbox

עוד שני רכיבים מופיעים על השורה רק לאחר שמתקינים את השירות המתאים מהאפשרות **התקנה → שירות**, ושניהם שווים היכרות כי הם עושים יותר מדיווח מצב.

פנל **Tailscale** מחבר ומנתק את ה-tailnet, מחליף בין חשבונות ובוחר צומת יציאה (המכונות שלכם ואזורי Mullvad שניהם מופיעים ברשימה). הוא גם גולש בין המכונות שלכם — ועם אחת שנבחרה, `s` שולח אליה קבצים over Taildrop, שזו הדרך המהירה ביותר להעביר קובץ לטלפון או למחשב נייד אחר. `c` מעתיק את ה-IP של המכונה, `n` את שמה, ו-`d` את שם ה-DNS המלא שלה. יש גם כפתור שליחה על כל שורת מכונה, אם תעדיפו ללחוץ. אותו דבר מהטרמינל הוא `omarchy tailscale send <machine> [file...]`.

פנל **Dropbox** מטפל בהתחברות, מציג כמה אחסון ניצלתם ומפרט קבצים שסונכרנו לאחרונה.

הסרת כל אחד מהשירותים מחזירה את הרכיב שלו מהשורה.

## מחוונים

הצביר הקטן במרכז הוא רכיב המחוונים. אלה גליפי מצב למצבים שהפעלתם: נא לא להפריע, אור לילה, [תזכורת](09-reminders.md) בתור, הקלטת מסך פעילה, הישאר ער ו[הכתבה](11-text-extraction-dictation.md). הם נדלקים כאשר המצב פעיל ואחרת נשארים בצד — עברו עם העכבר משמאל לשעון (מעליו בשורה אנכית) כדי להציץ באלה הלא פעילים. לחיצה על מחוון מחליפה את המצב הזה. עוד אחד הוא למצב בלבד: מושב מרוחק נדלק באדום בזמן שמישהו מחובר למכונה זו דרך gliff.

אם תעדיפו שהם תמיד יהיו גלויים, הגדירו את `alwaysShow` ל-`true` על הרכיב. ואם אכפת לכם רק מחלקם, פרטו את אלה שתרצו ב-`items`: `["Dnd", "Reminder", "NightLight"]`. אפשר שיהיה יותר מרכיב מחוונים אחד, כך שמקטעים שונים יכולים להציג קבוצות משנה שונות.

## סידור מחדש של השורה

השורה מגדירה את עצמה. לא חייבים לפתוח קובץ הגדרות כדי להזיז דברים.

תפסו פיסת ריק של השורה סביב המרכז וגררו אותה לעבר קצה מסך אחר, והשורה עוברת לשם — שמאל, ימין, עליון או תחתון כולם עובדים, וכל רכיב מסתגל (שורות אנכיות חוזרות לצורות קומפקטיות של אייקון בלבד). לחיצה והחזקה מתחילה את אותה גרירה. לחצו פעמיים שמאל על אותו שטח ריק כדי לעבור במחזוריות את רקע השורה משקוף לזכוכיתי לאטום. וגררו כל רכיב כדי לסדר אותו מחדש או לזרוק אותו למקטע אחר.

רכיב שאתם רוצים בהישג יד אבל לא תמיד מול העיניים יכול להיכנס למגירה של המגש: גררו אותו על המגש, והמגירה נפתחת כדי לקבל אותו. הוא יושב שם אחרי אייקוני האפליקציות, מופיע בכל פעם שהמגירה מופיעה, ושומר את המגירה פתוחה כל עוד הפנל שלו פתוח. גררו אותו בחזרה החוצה אל השורה כדי להחזיר אותו למקומו.

אם תעדיפו לבחור מתפריט, **הפעלה → מראה → שורת תפריט** כוללת את המיקום, ו**רקע שורה** בוחרת איך השורה מצוירת: **שורה אטומה**, **שורה זכוכיתית** (שקופה, עם טשטוש של מה שמאחוריה) או **שורה שקופה**.

לאותם דברים יש פקודות, וזה מה שרוצים להגדרת [dotfiles](31-dotfiles.md):

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.clock --section center --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

כדי להוסיף או להסיר רכיב לגמרי, השתמשו בפקודות התוסף. `omarchy plugin list` מדפיס כל רכיב שהמעטפת מכירה עם המזהה שלו, ואחר כך:

```bash
omarchy plugin enable omarchy.media --section center
omarchy plugin disable omarchy.weather
```

## הסתרת השורה

`Super + Shift + Space` מכבה את השורה ומחזיר אותה בלי להרוג את המעטפת — פנלים וקיצורי מקלדת ממשיכים לעבוד, פשוט מקבלים את הפיקסלים בחזרה. זה גם בתפריט תחת **הפעלה → מראה → שורת תפריט → הסתרת שורה**.

## קובץ ההגדרות

כל זה מאוחסן ב-`~/.config/omarchy/shell.json`, תחת המפתח `bar`. הנה גרסה מקוצצת:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "centerAnchor": "omarchy.clock",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

כל רכיב הוא ערך אחד באחד משלושת מערכי הפריסה, וההגדרות שלו יושבות בתוך אותו ערך — אין קובץ הגדרות נפרד ואין תת-אובייקט `config`. ה-`format`, ה-`formatAlt` (שאליו לחיצה ימנית מחליפה במחזוריות) וה-`verticalFormat` של השעון חיים כולם ממש שם על `{ "id": "omarchy.clock" }`.

ה-`centerAnchor` מציין את רכיב המרכז האחד שמקבל הצמדה למרכז המדויק של המסך, כשאחרים מאגפים אותו. כך השעון נשאר במרכז המת גם כאשר מזג האוויר ותג העדכון באים והולכים. הגדירו אותו למחרוזת ריקה ורשימת המרכז פשוט תמורכז כקבוצה במקום זאת.

כלל אחד שכדאי להפנים: **ברגע שיש לכם `shell.json` משלכם, הוא קנוני**. עד שתתאימו משהו, המעטפת קוראת את קובץ ברירת המחדל של Omarchy. ברגע שאתם גוררים רכיב, מריצים את `omarchy bar` או עורכים את הקובץ בעצמכם, אתם הבעלים שלו — אין מיזוג עמוק, כך שרכיבי ברירת מחדל חדשים בגרסאות Omarchy עתידיות לא יופיעו על השורה שלכם אוטומטית. `omarchy bar defaults` מחזיר את הפריסה שסופקה בכל עת שתרצו דף נקי.

אותו קובץ מחזיק גם את תזמוני ה-idle שלכם ברמה העליונה, מחוץ למפתח `bar`: `idle.screensaver` ו-`idle.lock`, שניהם בשניות מאז שהפכתם ל-idle. כך שומר המסך המוגדר כברירת מחדל נכנס לפעולה ב-150 שניות והנעילה ב-300.
