# הבר העליון

הרצועה לאורך החלק העליון של המסך היא הבר של Omarchy. זה לא סרגל סטטוס שהוברג מבחוץ אלא חלק מהמעטפת של Omarchy, תהליך Quickshell יחיד וממושך שמצייר גם את התפריט, את ההתראות, את חלוניות ה-OSD ואת מסך הנעילה. לכן הוא מקבל את ערכת הנושא באופן מושלם עם כל השאר, ולכן פאנל נפתח מיד במקום להפעיל אפליקציה חדשה.

זה גם החלק היחיד של שולחן העבודה שתמיד על המסך, אז שווה לדעת מה כל הסמלים הקטנים האלה עושים.

## מה יש עליו כברירת מחדל

לבר יש שלושה מקטעים. בצד שמאל נמצאים הלוגו של Omarchy (מפעיל התפריט) ומחווני סביבות העבודה. במרכז מקבלים את מחווני הסטטוס, את השעון, את Elsewhen (שעון עולם), את מזג האוויר ואת תג עדכון Omarchy. בצד ימין: מגש המערכת, פריסת המקלדת (כשמוגדרת יותר מפריסה אחת או שיטת קלט אחת), סוכנים, bluetooth, רשת, שמע, תצוגה וחשמל.

חלק מאלה מופיעים רק כשיש להם מה לומר. פריסת המקלדת מופיעה רק אם הגדרתם יותר מפריסה אחת או שיטת קלט אחת. תג העדכון מופיע רק כשממתין עדכון ל-Omarchy.

כמעט כל ווידג'ט עושה משהו בלחיצה שמאלית, ימנית ואמצעית, וכמה מהם מגיבים לגלילה. זה החלק שאנשים מפספסים — הלחצנים הימני והאמצעי הם המקום שבו מסתתרים הרבה מהדברים הטובים.

## הפאנלים

לחיצה על סמל בבר פותחת פאנל, שהוא חלונית קופצת אמיתית עם מחוונים, רשימות וניווט מקלדת במקום טולטיפ. לכל אחד יש גם קיצור מקלדת, כך שלעולם לא צריך לכוון לסמל של 16 פיקסלים:

| קיצור מקלדת | פאנל |
| --- | --- |
| `Super + Ctrl + A` | שמע |
| `Super + Ctrl + N` | רשת |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | תצוגה |
| `Super + Ctrl + P` | חשמל |
| `Super + Ctrl + Alt + D` | לוח שנה |
| `Super + Ctrl + Alt + E` | שעון עולם |
| `Super + Ctrl + X` | סוכנים |
| `Super + Ctrl + 1-9` | הפעלה/כיבוי של הפאנל ה-n במקטע הימני |

הפאנלים אינם רק תצוגות. שם אתם באמת עושים את הדבר:

- **שמע** כולל מחוון עוצמת קול ראשי, בורר התקן פלט ומיקסר לפי אפליקציה, כך שתוכלו להנמיך כרטיסיית דפדפן אחת מבלי לגעת בכל השאר.
- **רשת** סורק רשתות Wi-Fi, מציג את עוצמת האות, מתחבר ומאפשר לכם לבחור ספק DNS.
- **Bluetooth** מפרט את המכשירים שלכם עם חיבור/ניתוק ורמות סוללה.
- **חשמל** מציג נתוני סוללה, מחליף פרופילי חשמל (הוא זוכר בחירה נפרדת לסוללה ול-AC), ומדפיס קצת מידע על המערכת.
- **תצוגה** כולל מחוון בהירות, גודל טקסט, קביעות מראש של קנה מידה למסך, ו—כשיש יותר ממסך אחד—פקדים לכל מסך. ראו [מסכים](33-monitors.md) לסיפור המעמיק יותר.
- **שעון** פותח רשת חודש עם מספרי שבועות ISO ומעבר בין חודשים.
- **שעון עולם** שומר שורה לכל עיר, עם מזג האוויר שלה ואיך היום שלה מתקדם. חיפוש מוצא עיירות כמו גם אזורי זמן, כך ש-Fort Lauderdale היא Fort Lauderdale ולא New York. אם השורה למעלה מציינת את העיר הלא נכונה, לחצו עליה ואמרו איפה אתם; בחרו מקום באזור זמן אחר ושעון המערכת יעבור לשם גם הוא, מה שנוח כשאתם נוסעים. עברו עם העכבר מעל עיר ולחצו על כפתור האדם כדי לומר מי גר שם — שמות פשוטים, או מזהי GitHub עם `@` כדי להביא גם את הפנים שלהם.

כל פאנל מקבל את המקלדת וגם את העכבר: החצים מזיזים, Return מפעיל, Tab עובר לפאנל הסמוך, ו-Escape סוגר.

`Super + Ctrl + 1-9` סופר את הפאנלים משמאל לימין במקטע הימני, ומדלג על המגש מאחר שאין לו פאנל משלו. כך המספר מתאים לסמל שהייתם מצביעים עליו.

### Tailscale ו-Dropbox

שני ווידג'טים נוספים מופיעים על הבר רק לאחר שתתקינו את השירות המתאים מתוך **התקנה → שירות**, ושניהם שווים הכרה כי הם עושים יותר מלדווח על סטטוס.

פאנל **Tailscale** מחבר ומנתק את ה-tailnet, מחליף בין חשבונות ובוחר צומת יציאה (המכונות שלכם ואזורי Mullvad מופיעים שניהם ברשימה הזו). הוא גם מעיין במכונות שלכם — וכשאחת נבחרה, `s` שולח אליה קבצים דרך Taildrop, שזו הדרך המהירה ביותר להעביר קובץ לטלפון שלכם או למחשב נייד אחר. `c` מעתיק את ה-IP של המכונה, `n` את שמה, ו-`d` את שם ה-DNS המלא שלה. יש גם כפתור שליחה בכל שורת מכונה, אם אתם מעדיפים ללחוץ. אותו דבר מהטרמינל הוא `omarchy tailscale send <machine> [file...]`.

פאנל **Dropbox** מטפל בכניסה, מציג כמה אחסון ניצלתם ומפרט קבצים שסונכרנו לאחרונה.

הסרת אחד מהשירותים מסירה גם את הווידג'ט שלו מהבר.

## מחוונים

הצביר הקטן במרכז הוא ווידג'ט המחוונים. אלה סמלי סטטוס למצבים שהפעלתם: אל תפריע, תאורת לילה, [תזכורת](09-reminders.md) בתור, הקלטת מסך פעילה ולהישאר ער, ובנוסף אזהרות בזמן ש-passwordless sudo מופעל או שמישהו מחובר להפעלה מרוחקת. הם נדלקים כשהמצב פעיל ואחרת נשארים בצד — עברו עם העכבר ממש לצידם, במקום שבו היו יושבים אלה שאינם פעילים, כדי להציץ בהם. לחיצה על מחוון מפעילה/מכבה את המצב הזה. אחד נוסף הוא לסטטוס בלבד: הפעלה מרוחקת נדלקת באדום בזמן שמישהו מחובר למכונה זו דרך gliff.

אם אתם מעדיפים שהם תמיד יהיו גלויים, הגדירו `alwaysShow` ל-`true` בווידג'ט. ואם אתם מתעניינים רק בחלק מהם, פרטו את אלה שאתם רוצים ב-`items`: `["Dnd", "Reminder", "NightLight"]`. יכול להיות לכם יותר מווידג'ט מחוונים אחד, כך שמקטעים שונים יכולים להציג קבוצות משנה שונות.

## סידור מחדש של הבר

הבר מגדיר את עצמו. לא צריך לפתוח קובץ הגדרות כדי להזיז דברים.

תפסו פיסת בר ריקה סביב המרכז וגררו אותה לעבר קצה אחר של המסך, והבר עובר לשם — שמאל, ימין, למעלה או למטה כולם עובדים, וכל ווידג'ט מתאים את עצמו (ברים אנכיים חוזרים לצורות קומפקטיות של סמלים בלבד). לחיצה והחזקה מתחילה את אותה גרירה. לחצו לחיצה כפולה שמאלית על אותו שטח ריק כדי לעבור ברקע הבר משקוף לזכוכיתי לאטום. וגררו כל ווידג'ט כדי לסדר אותו מחדש או לזרוק אותו למקטע אחר; שאר הווידג'טים זזים הצידה כדי לפנות מקום במקום שבו הוא ינחת.

האמצע של הבר הוא תיבה: כל מה שבתוכה נשאר במרכז כקבוצה אחת, והווידג'טים משני צדיה תלויים בקצותיה. בזמן שאתם גוררים ווידג'ט התיבה מופיעה כמתאר, או כקו לרוחב הבר כשהיא ריקה, ותוכלו לשחרר לתוכה או לצידה. כששחרור ינחת בתיבה, התיבה גדלה כדי לקבל את הווידג'ט פנימה.

ווידג'ט שאתם רוצים בסביבה אבל לא תמיד בגלוי יכול להיכנס למגירת המגש: גררו אותו אל המגש, והמגירה נפתחת כדי לקבל אותו. הוא יושב שם אחרי סמלי האפליקציות, מופיע בכל פעם שהמגירה מופיעה, ושומר את המגירה שלו פתוחה בזמן שהפאנל שלו למעלה. גררו אותו חזרה החוצה אל הבר כדי להחזיר אותו.

אם אתם מעדיפים לבחור מתפריט, ב-**מראה → סרגל התפריט** נמצא המיקום, ו-**רקע הבר** בוחר איך הבר מצויר: **בר אטום**, **בר זכוכיתי** (שקוף, עם מה שמאחוריו מטושטש), או **בר שקוף**.

לאותם דברים יש פקודות, שזה מה שתרצו להגדרת [dotfiles](31-dotfiles.md):

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

כדי להוסיף או להסיר ווידג'ט לגמרי, השתמשו בפקודות התוספים. `omarchy plugin list` מדפיס כל ווידג'ט שהמעטפת מכירה עם ה-id שלו, ואז:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## הסתרת הבר

`Super + Shift + Space` מפעיל/מכבה את הבר מבלי להרוג את המעטפת — פאנלים וקיצורי מקלדת ממשיכים לעבוד, אתם פשוט מקבלים את הפיקסלים בחזרה. זה נמצא גם בתפריט תחת **מראה → סרגל התפריט → הסתר בר**.

## קובץ ההגדרות

כל זה נשמר ב-`~/.config/omarchy/shell.json`, תחת המפתח `bar`. הנה גרסה מצומצמת:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

כל ווידג'ט הוא ערך אחד באחד מחמשת מערכי הפריסה, וההגדרות שלו יושבות בתוך אותו ערך — אין קובץ הגדרות נפרד ואין תת-אובייקט `config`. ה-`format`, ה-`formatAlt` (מה שלחיצה ימנית עוברת אליו), וה-`verticalFormat` של השעון חיים כולם ממש שם על `{ "id": "omarchy.clock" }`.

`center` הוא התיבה באמצע הבר: כל מה שבתוכה ממורכז על המסך כקבוצה אחת. `centerBegin` ו-`centerEnd` תלויים משני צדי התיבה, וכך השעון נשאר בול במרכז גם כשמזג האוויר ותג העדכון באים והולכים. שימו יותר מווידג'ט אחד ב-`center` והם ימומקזו יחד; השאירו אותו ריק ו-`centerBegin` ו-`centerEnd` ייפגשו באמצע הבר.

כלל אחד ששווה להפנים: **ברגע שיש לכם `shell.json` משלכם, הוא הקנוני**. עד שתתאימו אישית משהו, המעטפת קוראת את קובץ ברירת המחדל של Omarchy. ברגע שאתם גוררים ווידג'ט, מריצים `omarchy bar`, או עורכים את הקובץ בעצמכם, הוא שלכם — אין מיזוג עמוק, כך שווידג'טים חדשים של ברירת מחדל במהדורות Omarchy עתידיות לא יופיעו על הבר שלכם אוטומטית. `omarchy bar defaults` מחזיר את הפריסה שסופקה בכל פעם שתרצו דף נקי.

אותו קובץ מחזיק גם את תזמוני הבטלה שלכם ברמה העליונה, מחוץ למפתח `bar`: `idle.screensaver` ו-`idle.lock`, שניהם בשניות מאז שהלכתם למצב בטלה. כך שומר המסך המוגדר כברירת מחדל נכנס לפעולה ב-150 שניות והנעילה ב-300.
