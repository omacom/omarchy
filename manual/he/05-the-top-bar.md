# הסרגל העליון

הרצועה לאורך החלק העליון של המסך היא סרגל Omarchy. זה לא סרגל מצב שהוצמד מבחוץ, אלא חלק ממעטפת Omarchy, תהליך Quickshell יחיד וממושך שמצייר גם את התפריט, את ההתראות, את חלוניות ה-OSD ואת מסך הנעילה. לכן הוא מקבל את ערכת הנושא בצורה מושלמת עם כל השאר, ולכן חלונית נפתחת מיד במקום להפעיל אפליקציה חדשה.

זה גם החלק היחיד של שולחן העבודה שתמיד נמצא על המסך, אז שווה לדעת מה כל הגליפים הקטנים האלה עושים.

## מה נמצא בו כברירת מחדל

לסרגל יש שלושה חלקים. בצד שמאל נמצאים הלוגו של Omarchy (משגר התפריט) ומחווני סביבות העבודה. במרכז מקבלים את מחווני המצב, את השעון, את Elsewhen (שעון עולמי), את מזג האוויר ואת תג העדכון של Omarchy. בצד ימין: מגש המערכת, פריסת המקלדת (כאשר מוגדרת יותר מפריסה אחת), סוכנים, Bluetooth, רשת, שמע, תצוגה וחשמל.

חלק מהם מופיעים רק כשיש להם משהו לומר. פריסת המקלדת מופיעה רק אם הגדרת יותר מפריסה אחת. תג העדכון מופיע רק כאשר מחכה עדכון ל-Omarchy. וסמל הסוכנים מופיע בפעם הראשונה שבה Omarchy מוצא שימוש בקידוד ב-AI במחשב (ראו [AI](17-ai.md)).

כמעט כל וידג'ט עושה משהו בלחיצה שמאלית, ימנית ואמצעית, וכמה מהם מגיבים גם לגלילה. זה החלק שאנשים מפספסים — הלחצנים הימני והאמצעי הם המקום שבו מסתתר הרבה מהטוב.

## החלוניות

לחיצה על סמל בסרגל פותחת חלונית, שהיא חלונית קופצת אמיתית עם מחוונים, רשימות וניווט במקלדת, ולא טולטיפ. לכל אחת יש גם מקש קיצור, אז אף פעם לא צריך לכוון לגליף של 16 פיקסלים:

| מקש קיצור | חלונית |
| --- | --- |
| `Super + Ctrl + A` | שמע |
| `Super + Ctrl + N` | רשת |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | תצוגה |
| `Super + Ctrl + P` | חשמל |
| `Super + Ctrl + Alt + D` | לוח שנה |
| `Super + Ctrl + Alt + E` | שעון עולמי |
| `Super + Ctrl + 1-9` | הפעלה/כיבוי של החלונית ה-n בחלק הימני |

החלוניות אינן רק תצוגות. שם באמת עושים את הדבר:

- **שמע** כולל מחוון עוצמת קול ראשי, בורר התקן פלט ומיקסר לכל אפליקציה, כך שאפשר להנמיך את לשונית הדפדפן האחת ההיא בלי לגעת בכל השאר.
- **רשת** סורקת רשתות Wi-Fi, מציגה עוצמת אות, מתחברת, ומאפשרת לבחור ספק DNS.
- **Bluetooth** מציגה את המכשירים שלך עם חיבור/ניתוק ורמות סוללה.
- **חשמל** מציגה נתוני סוללה, מחליפה פרופילי חשמל (היא זוכרת בחירה נפרדת לסוללה ול-AC), ומציגה קצת מידע על המערכת.
- **תצוגה** כוללת מחוון בהירות, גודל טקסט, הגדרות קבועות מראש לשינוי קנה מידה של המסך, ו — כאשר יש יותר ממסך אחד — פקדים לכל מסך. ראו [מסכים](33-monitors.md) לסיפור המעמיק יותר.
- **שעון** פותח רשת חודשית עם מספרי שבועות לפי ISO ומעבר בין חודשים.
- **שעון עולמי** מחזיק שורה לכל עיר, עם מזג האוויר שלה ואיך מתקדם היום שלה. החיפוש מוצא עיירות כמו גם אזורי זמן, כך ש-Fort Lauderdale היא Fort Lauderdale ולא New York. אם השורה למעלה מציינת את העיר הלא נכונה, לחץ עליה ואמור היכן אתה נמצא; בחר מקום באזור זמן אחר וגם שעון המערכת יעבור לשם, מה ששימושי כשנוסעים. רחף מעל עיר ולחץ על כפתור האדם כדי לומר מי גר שם — שמות רגילים, או מזהי GitHub עם `@` כדי להביא גם את הפנים שלהם.

כל חלונית מקבלת גם את המקלדת ולא רק את העכבר: החצים מזיזים, Return מפעיל, Tab עובר לחלונית השכנה, ו-Escape סוגר.

`Super + Ctrl + 1-9` סופר חלוניות משמאל לימין בחלק הימני, ומדלג על המגש כי אין לו חלונית משלו. כך המספר מתאים לסמל שהיית מצביע עליו.

### Tailscale ו-Dropbox

שני וידג'טים נוספים מופיעים בסרגל רק לאחר התקנת השירות המתאים מתוך **התקנה → שירות**, ושניהם שווים היכרות כי הם עושים יותר מלדווח על מצב.

חלונית **Tailscale** מחברת ומנתקת את ה-tailnet, מחליפה בין חשבונות, ובוחרת צומת יציאה (המכשירים שלך וגם אזורי Mullvad מופיעים ברשימה הזו). היא גם מאפשרת לעיין במכשירים שלך — וכאשר אחד מהם נבחר, `s` שולח אליו קבצים דרך Taildrop, שזו הדרך המהירה ביותר להעביר קובץ לטלפון או למחשב נייד אחר. `c` מעתיק את ה-IP של המכשיר, `n` את שמו, ו-`d` את שם ה-DNS המלא שלו. יש גם כפתור שליחה בכל שורת מכשיר, אם אתה מעדיף ללחוץ. אותו הדבר מהטרמינל הוא `omarchy tailscale send <machine> [file...]`.

חלונית **Dropbox** מטפלת בהתחברות, מציגה כמה שטח אחסון נוצל, ומציגה קבצים שסונכרנו לאחרונה.

הסרת אחד מהשירותים מסירה גם את הווידג'ט שלו מהסרגל.

## מחוונים

האשכול הקטן במרכז הוא וידג'ט המחוונים. אלה גליפי מצב למצבים שהפעלת: נא לא להפריע, תאורת לילה, [תזכורת](09-reminders.md) בתור, הקלטת מסך פעילה, הישארות ערה, ו[הכתבה](11-text-extraction-dictation.md). הם נדלקים כשהמצב פעיל ואחרת נשארים בצד — רחף ממש לידם, במקום שבו היו יושבים אלה שאינם פעילים, כדי להציץ בהם. לחיצה על מחוון מפעילה או מכבה את המצב הזה. עוד אחד הוא למצב בלבד: הפעלה מרוחקת נדלקת באדום בזמן שמישהו מחובר למחשב הזה דרך gliff.

אם אתה מעדיף שהם יהיו תמיד גלויים, הגדר את `alwaysShow` ל-`true` בווידג'ט. ואם אכפת לך רק מחלק מהם, רשום את אלה שאתה רוצה ב-`items`: `["Dnd", "Reminder", "NightLight"]`. יכול להיות יותר מווידג'ט מחוונים אחד, כך שחלקים שונים יכולים להציג תתי-קבוצות שונות.

## סידור מחדש של הסרגל

הסרגל מגדיר את עצמו. לא צריך לפתוח קובץ תצורה כדי להזיז דברים.

תפוס פיסת סרגל ריקה סביב המרכז וגרור אותה לעבר קצה אחר של המסך, והסרגל יעבור לשם — שמאל, ימין, למעלה או למטה, הכל עובד, וכל וידג'ט מתאים את עצמו (סרגלים אנכיים חוזרים לצורות קומפקטיות של סמלים בלבד). לחיצה והחזקה מתחילה את אותה גרירה. לחץ לחיצה שמאלית כפולה על אותו שטח ריק כדי לעבור בין רקעי הסרגל, משקוף לזכוכיתי לאטום. וגרור כל וידג'ט כדי לסדר אותו מחדש או לזרוק אותו לחלק אחר; שאר הווידג'טים זזים הצידה כדי לפנות מקום במקום שבו הוא ינחת.

אמצע הסרגל הוא תיבה: כל מה שבתוכה נשאר ממורכז כקבוצה אחת, והווידג'טים משני צדיה תלויים בקצותיה. בזמן גרירת וידג'ט התיבה מוצגת כקו מתאר, או כקו לרוחב הסרגל כשהיא ריקה, ואפשר להפיל לתוכה או לצדה. כאשר הפלה אמורה לנחות בתיבה, התיבה גדלה כדי לקלוט את הווידג'ט.

וידג'ט שאתה רוצה בסביבה אבל לא תמיד גלוי יכול להיכנס למגירת המגש: גרור אותו אל המגש, והמגירה תיפתח כדי לקלוט אותו. הוא יושב שם אחרי סמלי האפליקציות, מופיע בכל פעם שהמגירה מופיעה, ושומר על המגירה פתוחה בזמן שהחלונית שלו פתוחה. גרור אותו בחזרה החוצה אל הסרגל כדי להחזיר אותו.

אם אתה מעדיף לבחור מתפריט, ב-**מראה → סרגל התפריט** נמצא המיקום, ו-**רקע הסרגל** בוחר איך הסרגל מצויר: **סרגל אטום**, **סרגל זכוכיתי** (שקוף למחצה, עם טשטוש של מה שמאחוריו), או **סרגל שקוף**.

לאותם דברים יש פקודות, שזה מה שתרצה עבור מערך [dotfiles](31-dotfiles.md):

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

כדי להוסיף או להסיר וידג'ט לחלוטין, השתמש בפקודות התוספים. `omarchy plugin list` מדפיסה כל וידג'ט שהמעטפת מכירה עם המזהה שלו, ולאחר מכן:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## הסתרת הסרגל

`Super + Shift + Space` מכבה ומדליקה מחדש את הסרגל בלי להרוג את המעטפת — חלוניות ומקשי קיצור ממשיכים לעבוד, אתה פשוט מקבל בחזרה את הפיקסלים. זה נמצא גם בתפריט תחת **מראה → סרגל התפריט → הסתרת הסרגל**.

## קובץ התצורה

כל זה מאוחסן ב-`~/.config/omarchy/shell.json`, תחת מפתח ה-`bar`. הנה גרסה מקוצרת:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

כל וידג'ט הוא רשומה אחת באחד מחמשת מערכי הפריסה, וההגדרות שלו יושבות בתוך אותה רשומה — אין קובץ הגדרות נפרד ואין תת-אובייקט `config`. ה-`format`, ה-`formatAlt` (מה שלחיצה ימנית עוברת אליו) וה-`verticalFormat` של השעון חיים כולם ממש שם על `{ "id": "omarchy.clock" }`.

`center` היא התיבה באמצע הסרגל: כל מה שבתוכה ממורכז על המסך כקבוצה אחת. `centerBegin` ו-`centerEnd` תלויים משני צדי התיבה, וכך השעון נשאר בדיוק במרכז גם כשמזג האוויר ותג העדכון באים והולכים. שים יותר מווידג'ט אחד ב-`center` והם ימורכזו יחד; השאר אותה ריקה ו-`centerBegin` ו-`centerEnd` ייפגשו באמצע הסרגל.

כלל אחד שכדאי להפנים: **ברגע שיש לך `shell.json` משלך, הוא הקובע**. עד שתתאים משהו אישית, המעטפת קוראת את קובץ ברירת המחדל של Omarchy. ברגע שתגרור וידג'ט, תריץ `omarchy bar`, או תערוך את הקובץ בעצמך, הוא שלך — אין מיזוג עמוק, כך שווידג'טים חדשים של ברירת מחדל במהדורות Omarchy עתידיות לא יופיעו בסרגל שלך אוטומטית. `omarchy bar defaults` מחזירה את הפריסה שסופקה בכל פעם שתרצה לוח נקי.

אותו קובץ מחזיק גם את תזמוני חוסר הפעילות שלך ברמה העליונה, מחוץ למפתח ה-`bar`: `idle.screensaver` ו-`idle.lock`, שניהם בשניות מאז שהפסקת להיות פעיל. כך שומר המסך המוגדר כברירת מחדל נכנס לפעולה לאחר 150 שניות והנעילה לאחר 300.
