# תזכורות

ל-Omarchy יש דרך מובנית לקבוע תזכורות פשוטות על בסיס טיימר ספירה לאחור ועם הודעה. אפשר לעשות זאת באמצעות `Super + Ctrl + R`, לראות את כל אלה שנקבעו באמצעות `Super + Ctrl + Alt + R`, ולנקות את כולן באמצעות `Super + Ctrl + Shift + R`. הכול נגיש גם באמצעות _הפעלה > תזכורת_. אפשר גם להשתמש ב-CLI עם `omarchy reminder 7 'Tea ready'`.
