# צגים

Omarchy מניחה כברירת מחדל שאתה עובד עם צג ברמת retina שתומך ב-2x. זה מה שצריך כדי לקבל את גופני התכנות הנאים והחדים האלה. לזה מותאמים כמעט כל המחשבים הניידים החדשים והיוקרתיים עם מסכים ברזולוציה גבוהה. זה מה שתרצה להריץ על [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) בגודל 27" 5K או [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) בגודל 32" 6K.

אבל אם אתה לא עובד עם צג עם PPI של 218 ומעלה, תרצה לשנות את הגדרות הצג. לדוגמה, אם יש לך 4K בגודל 27" או 32", תוכל לבחור עבורו קנה מידה חלקי מפאנל הצג בשורת העליונה, או להגדיר את ברירת המחדל לכל הצגים על ידי פתיחת `~/.config/hypr/monitors.lua` ומעבר להמלצה לשילוב הזה:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

אם אתה משתמש בצג 1080p או 1440p, כנראה שתרצה פשוט להשתמש בקנה מידה של 1x, וכך גם עבור אפליקציות GTK ו-X11, כך שתוכל להשתמש בזה:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

שינויים ב-`GDK_SCALE` חלים על אפליקציות שמתחילות אחרי השינוי (ו-GTK מכבדת רק מספרים שלמים, אז שמור אותו בערך השלם הקרוב ביותר לקנה המידה של הצג שלך). אז דאג לצאת מהחלונות שיש לך שהם מוגדלים מדי אחרי השינוי (או סגור את כל החלונות עם `Ctrl + Alt + Del`!).

תוכל גם לעבור במהירות בין יחסי קנה המידה העיקריים של הצג (1x, 1.25x, 1.6x, 2x, 3x, 4x) באמצעות `Super + /` כדי לעלות ו-`Super + Alt + /` כדי לרדת, או לבחור אחד מפאנל הצג בשורה העליונה. אלה משנים רק את הצג שבו אתה ממוקד, כך שלמסך של מחשב נייד ולצג חיצוני יכול להיות קנה מידה משלהם. הפאנל גם מגדיר את הרזולוציה, קצב הרענון והסיבוב של כל צג. הבחירות שלך נשמרות עבור הצג הפיזי הזה ב-`~/.local/state/omarchy/monitors/settings`, כך שהן נשמרות לאחר אתחול ועוקבות אחר הצג לכל יציאה או תחנת עגינה שאליהם הוא מחובר בפעם הבאה. הן קודמות לכל כלל עבור אותו צג ב-`~/.config/hypr/monitors.lua`, ש-Omarchy לעולם לא עורכת. אם אתה מעדיף להגדיר את הצגים שלך לגמרי בקובץ הזה, הוסף לו את `omarchy_monitor_panel_settings = false`, והשינויים של הפאנל יימשכו רק עד שה-Hyprland ייטען מחדש. מכיוון ש-`GDK_SCALE` הוא ערך אחד עבור כל המסכים, קנה מידה שנבחר מגדיר אותו לפי הצג עם קנה המידה הנמוך ביותר, כך שאפליקציות X11 יוצאות קצת קטנות על המסך הצפוף יותר ולא מוגדלות מדי על האחר.

### הגדלה או הקטנה של טקסט

קנה מידה של צג משנה את הגודל של הכל. אם כל מה שאתה רוצה הוא _טקסט_ גדול יותר או קטן יותר, יש לזה כפתור אחד:

```
omarchy display text size 14
```

זה מקבל גודל בפיקסלים בין 9 ל-20, ומזיז את מעטפת Omarchy, אפליקציות GTK והמסוף שלך יחד, כך שכל שולחן העבודה נשאר בפרופורציה. הרץ אותו ללא ארגומנט כדי לראות איפה אתה נמצא, ו-`omarchy display text size reset` כדי לחזור לברירת המחדל. Foot הוא המשתרך היחיד: אין לו דרך לטעון מחדש את התצורה שלו, כך שמסופים פעילים שומרים על הגודל הישן עד שתפתח אחד חדש.

### הרחבה ושיקוף של צגי מחשב נייד

כאשר אתה מחבר מסך חיצוני למחשב הנייד שלך, התצוגה מורחבת באופן אוטומטי. אבל תוכל לשנות את זה לשיקוף במקום זאת באמצעות _Trigger > Hardware_ בתפריט Omarchy או `Super + Ctrl + Alt + Delete`. זה מועיל במיוחד אם המסך החיצוני הזה הוא מקרן, ואתה רוצה להציג משהו בזמן שאתה עובד.

כאשר אתה מרחיב, סגירת המכסה של המחשב הנייד תכבה אוטומטית את המסך הפנימי. פתיחת המכסה תדליק אותו שוב. תוכל גם לשלוט בזה באופן ידני באמצעות _Trigger > Hardware_ בתפריט Omarchy או `Super + Ctrl + Delete`.

### סידור מסכים מרובים

Hyprland עובדת נהדר עם מסכים מרובים. פאנל הצג בשורה העליונה מצייר אותם במקום שבו הם נמצאים: גרור אחד נגד הצד של אחר כדי להזיז אותו לשם, והסידור נשמר יחד עם ההגדרות האחרות של כל צג. לכל דבר שהפאנל לא מכסה, קרא עוד על איך לפרוס אותם ב[תיעוד הצגים של Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/). ב-Omarchy, אלה נכנסים ל-`~/.config/hypr/monitors.lua` כרשומות `hl.monitor` — הקובץ מגיע עם דוגמאות בהערות לשמירה על צג כבוי, מצבים שהפאנל לא מציע, צבע 10-bit וקצב רענון משתנה.

לכל צג יש סביבות עבודה משלו 1 עד 10, כך ש-`Super + 1` תמיד אומר סביבת העבודה הראשונה של הצג שאתה עליו. מאחורי הקלעים, Hyprland עדיין ממספרת את סביבות העבודה בכל הצגים: מסך המחשב הנייד שלך (או הצג הראשון) מקבל 1–10, הצג הבא 11–20, וכן הלאה, וכל צג שומר על הבלוק שלו בכל פעם שאתה מחבר אותו. השתמש במספרים האלה אם אתה כותב [כללי סביבות עבודה](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) או כללי חלונות לצג ספציפי, כך שסביבת עבודה 12 היא סביבת העבודה השנייה של הצג השני שלך. `~/.local/state/omarchy/monitors/workspaces` מפרט איזה בלוק יש לכל צג.

מקשי החצים עובדים בין צגים שחולקים קצה בפריסה שלך. מסכים שנוגעים רק בפינה, או שיש ביניהם רווח, אינם שכנים, אז השתמש ב-`Ctrl + Alt + Tab` כדי לעבור ביניהם.

| מקש קיצור | בין צגים |
| --- | --- |
| `Super + Arrow` | מעביר את המיקוד לצג שבאותו צד ברגע שאין חלון נוסף באותו כיוון |
| `Super + Shift + Arrow` | מחליף עם חלון בצג שבאותו צד |
| `Super + Alt + Arrow` | מעביר את החלון לקבוצה בצג שבאותו צד |
| `Super + Shift + Ctrl + Arrow` | מעביר את החלון לצג שבאותו צד, לסביבת העבודה שהוא מציג |
| `Super + Shift + Alt + Arrow` | מעביר את סביבת העבודה לצג שבאותו צד, ושומר על מספרה אם הוא פנוי |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | מעביר את המיקוד לצג הבא או לקודם, ללא קשר לפריסה |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | נשארים על הצג שאתה עליו |

תוכל גם לבדוק את [Hyprmon](https://github.com/erans/hyprmon/), אם תרצה TUI שיעזור לך במיקום של מסכים מרובים.

### שליטה בבהירות

בהירות הצג נשלטת על ידי מקשי הפונקציה היעודיים להגברה/הורדה של בהירות. אם תחזיק את shift לחוץ בזמן הלחיצה על אלה, תגיע לבהירות מקסימלית או מינימלית. המקשים שולטים בתצוגה שבה אתה ממוקד, כך שצגים חיצוניים שמדברים DDC/CI מכוונים באותה דרך כמו מסך המחשב הנייד.

### צגי Apple

אם אתה משתמש בצג Apple, מקשי הבהירות הרגילים של המקלדת יעבדו גם הם באופן אוטומטי, אם אתה ממוקד בצג Apple. זה נעשה דרך הפקודה `asdcontrol`.

שים לב שאם אתה משתמש בצג Apple 6K XDR, ייתכן שתראה מסך פנטום ברישום `hyprctl monitors` שלך. תוכל לכבות את זה עם משהו כמו `hl.monitor({ output = "DP-2", disabled = true })` ב-`~/.config/hypr/monitors.lua`.

במכונות Intel, עליך לחבר לצגי Apple באמצעות כבל Thunderbolt רגיל. במכונות אחרות ללא Thunderbolt, בדרך כלל תצטרך להשתמש ב[כבל DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) כדי שזה יעבוד.
