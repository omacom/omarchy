# צגים

Omarchy מניחה כברירת מחדל שאתם מריצים צג ברמת retina עם יכולת 2x. זה מה שצריך כדי לקבל את גופני התכנות הנאים והחדים האלה. זה מה שכמעט כל הלפטופים החדשים והיוקרתיים עם מסכים ברזולוציה גבוהה מותאמים אליו. זה מה שתרצו להריץ על [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) בגודל 27" ברזולוציית 5K או על [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) בגודל 32" ברזולוציית 6K.

אבל אם אתם לא מריצים צג עם PPI של 218 ומעלה, תרצו לשנות את הגדרות הצג. למשל, אם יש לכם 4K בגודל 27" או 32", תוכלו לבחור עבורו קנה מידה חלקי מפאנל הצג בסרגל העליון, או לקבוע את ברירת המחדל לכל צג על ידי פתיחת `~/.config/hypr/monitors.lua` ומעבר להמלצה לשילוב הזה:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

אם אתם משתמשים בצג 1080p או 1440p, כנראה פשוט תרצו להשתמש בקנה מידה של 1x, וכך גם עבור אפליקציות GTK ו-X11, אז תוכלו להשתמש ב:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

שינויים ב-`GDK_SCALE` חלים על אפליקציות שהופעלו אחרי השינוי (ו-GTK מכבד רק מספרים שלמים, אז השאירו אותו על המספר השלם הקרוב ביותר לקנה המידה של הצג שלכם). אז הקפידו לצאת מהחלונות שיש לכם שגדולים מדי אחרי השינוי (או סגרו את כל החלונות עם `Ctrl + Alt + Del`!).

תוכלו גם לעבור במהירות בין יחסי קנה המידה העיקריים של הצג (1x, 1.25x, 1.6x, 2x, 3x, 4x) באמצעות `Super + /` כדי לעלות ו-`Super + Alt + /` כדי לרדת, או לבחור אחד מפאנל הצג בסרגל העליון. אלה משנים רק את הצג שאתם ממוקדים בו, כך שלמסך לפטופ ולצג חיצוני יכול להיות לכל אחד קנה מידה משלו. הפאנל גם קובע את הרזולוציה של כל צג. הבחירות שלכם נשמרות עבור אותו צג פיזי ב-`~/.local/state/omarchy/monitors/settings`, כך שהן נשמרות גם אחרי אתחול ועוקבות אחרי הצג לכל יציאה או תחנת עגינה שהוא יחובר אליה בהמשך. הן גוברות על כל כלל לאותו צג ב-`~/.config/hypr/monitors.lua`, ש-Omarchy אף פעם לא עורכת. מכיוון ש-`GDK_SCALE` הוא ערך אחד לכל המסכים, קנה מידה שנבחר קובע אותו מהצג עם קנה המידה הנמוך ביותר, כך שאפליקציות X11 יוצאות קצת קטנות במסך הצפוף יותר ולא גדולות מדי באחר.

### הגדלה או הקטנה של הטקסט

קנה המידה של הצג משנה את הגודל של הכול. אם כל מה שאתם רוצים זה _טקסט_ גדול יותר או קטן יותר, יש כפתור אחד בדיוק בשביל זה:

```
omarchy display text size 14
```

זה מקבל גודל בפיקסלים בין 9 ל-20, ומזיז יחד את מעטפת Omarchy, אפליקציות GTK והטרמינל שלכם, כך שכל שולחן העבודה נשאר בפרופורציה. הריצו אותו בלי ארגומנט כדי לראות איפה אתם נמצאים, ו-`omarchy display text size reset` כדי לחזור לברירת המחדל. Foot היא היחידה שמשתרכת מאחור: אין לה דרך לטעון מחדש את התצורה שלה, אז טרמינלים פעילים שומרים על הגודל הישן שלהם עד שתפתחו אחד חדש.

### הרחבה ושיקוף של צגי לפטופ

כשמחברים מסך חיצוני ללפטופ, התצוגה מורחבת אוטומטית. אבל תוכלו לשנות זאת לשיקוף במקום זאת באמצעות _Trigger > Hardware_ בתפריט Omarchy או `Super + Ctrl + Alt + Delete`. זה מועיל במיוחד אם המסך החיצוני הזה הוא מקרן, ואתם רוצים להציג משהו בזמן העבודה.

כשאתם מרחיבים, סגירת המכסה של הלפטופ תכבה אוטומטית את המסך הפנימי. פתיחת המכסה תדליק אותו שוב. תוכלו גם לשלוט בזה ידנית באמצעות _Trigger > Hardware_ בתפריט Omarchy או `Super + Ctrl + Delete`.

### סידור מסכים מרובים

Hyprland עובדת נהדר עם מסכים מרובים. פאנל הצג בסרגל העליון מצייר אותם היכן שהם יושבים: גררו אחד אל הצד של אחר כדי להזיז אותו לשם, והסידור נשמר יחד עם שאר ההגדרות של כל צג. לכל מה שהפאנל לא מכסה, קראו עוד על איך לפרוס אותם ב[תיעוד הצגים של Hyprland](https://wiki.hypr.land/Configuring/Basics/Monitors/). ב-Omarchy, אלה נכנסים ל-`~/.config/hypr/monitors.lua` כערכי `hl.monitor` — הקובץ מגיע עם דוגמאות בהערות לקיבוע צג ספציפי לרזולוציה, מיקום וסיבוב.

לכל צג יש סביבות עבודה 1 עד 10 משלו, כך ש-`Super + 1` תמיד אומר סביבת העבודה הראשונה של הצג שאתם עליו. מאחורי הקלעים, Hyprland עדיין ממספרת סביבות עבודה על פני כל הצגים: מסך הלפטופ שלכם (או הצג הראשון) מקבל 1–10, הצג הבא 11–20, וכן הלאה, וכל צג שומר על הבלוק שלו בכל פעם שמחברים אותו. השתמשו במספרים האלה אם אתם כותבים [כללי סביבות עבודה](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) או כללי חלונות לצג ספציפי, כך שסביבת עבודה 12 היא סביבת העבודה השנייה של הצג השני שלכם. `~/.local/state/omarchy/monitors/workspaces` מפרט איזה בלוק יש לכל צג.

מקשי החצים עובדים בין צגים שחולקים קצה בפריסה שלכם. מסכים שנוגעים רק בפינה, או שיש ביניהם רווח, אינם שכנים, אז השתמשו ב-`Ctrl + Alt + Tab` כדי לעבור ביניהם.

| מקש קיצור | בין צגים |
| --- | --- |
| `Super + Arrow` | מעביר את המיקוד לצג שבצד הזה ברגע שלא נשאר חלון בכיוון הזה |
| `Super + Shift + Arrow` | מחליף עם חלון בצג שבצד הזה |
| `Super + Alt + Arrow` | מעביר את החלון לקבוצה בצג שבצד הזה |
| `Super + Shift + Ctrl + Arrow` | מעביר את החלון לצג שבצד הזה, אל סביבת העבודה שהוא מציג |
| `Super + Shift + Alt + Arrow` | מעביר את סביבת העבודה לצג שבצד הזה, ושומר על המספר שלה אם הוא פנוי |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | מעביר את המיקוד לצג הבא או הקודם, ללא קשר לפריסה |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | נשארים בצג שאתם עליו |

תוכלו גם לבדוק את [Hyprmon](https://github.com/erans/hyprmon/), אם תרצו TUI שיעזור לכם עם המיקום של מסכים מרובים.

### שליטה בבהירות

בהירות הצג נשלטת על ידי מקשי הפונקציה הייעודיים לבהירות למעלה/למטה. אם תחזיקו את shift לחוץ בזמן הלחיצה עליהם, תגיעו לבהירות מקסימלית או מינימלית. המקשים שולטים בתצוגה שאתם ממוקדים בה, כך שצגים חיצוניים שמדברים DDC/CI מותאמים בדיוק כמו מסך הלפטופ.

### צגי Apple

אם אתם משתמשים בצג Apple, מקשי בהירות המקלדת הרגילים יעבדו גם הם אוטומטית, אם אתם ממוקדים בצג Apple. זה נעשה באמצעות הפקודה `asdcontrol`.

שימו לב שאם אתם משתמשים בצג Apple 6K XDR, אתם עלולים לראות מסך פנטום ברשימת `hyprctl monitors` שלכם. תוכלו לכבות זאת עם משהו כמו `hl.monitor({ output = "DP-2", disabled = true })` ב-`~/.config/hypr/monitors.lua`.

במכונות Intel, עליכם להתחבר לצגי Apple באמצעות כבל Thunderbolt רגיל. במכונות אחרות ללא Thunderbolt, בדרך כלל תצטרכו להשתמש ב[כבל DP + USB-A -> USB-C](https://www.amazon.com/dp/B0BNX7MS6N) כדי שזה יעבוד.
