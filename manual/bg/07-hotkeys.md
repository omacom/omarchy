# Клавишни комбинации

Можеш да видиш всички основни клавишни комбинации със `Super + K` (комбинациите за Tmux със `Super + Alt + K`, а за Herdr — със `Super + Ctrl + K`).

## Навигация

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Super + Space`           | Меню на Omarchy (приложения и всичко останало)    |
| `Super + Alt + Space` | Решетка с приложения |
| `Super + Escape` | Системно меню (приспиване, рестартиране и т.н.)  |
| `Super + Ctrl + L` | Заключи компютъра |
| `Super + W` or `Super + Q` | Затвори прозорец             |
| `Ctrl + Alt + Del` | Затвори всички прозорци |
| `Super + T`               | Превключи прозорец между плочки/плаващ             |
| `Super + J` | Превключи позицията на прозореца (хоризонтална/вертикална) |
| `Super + O`               | Превключи изскачащия прозорец в лепкав и плаващ |
| `Super + L`               | Превъртай през оформленията dwindle, превъртане и плаващо |
| `Super + Alt + L`         | Превъртай през оформленията в обратен ред |
| `Super + P`               | Превключи псевдо стила на прозореца (естествен срещу разтегнат) |
| `Super + F`                 | Отиди на цял екран              |
| `Super + Alt + F`                 | Отиди на пълна ширина              |
| `Super + Ctrl + F`                 | Отиди на цял екран вътре в прозореца              |
| `Super + 1/2/3/4`         | Скочи на конкретно работно пространство     |
| `Super + Tab` | Скочи на следващото работно пространство |
| `Super + Shift + Tab` | Скочи на предишното работно пространство |
| `Super + Ctrl + Tab` | Скочи на бившето работно пространство |
| `Super + Shift + 1/2/3/4` | Премести прозорец на работно пространство |
| `Super + Shift + Alt + 1/2/3/4` | Премести прозорец на работно пространство без следване |
| `Super + S` / `Super + Grave` | Превключи черновата |
| `Super + Alt + S` / `Super + Shift + Grave` | Премести прозорец на черновата |
| `Super + Shift + Alt + Arrows` | Премести работни пространства на насочен монитор |
| `Super + Arrow`  | Премести фокуса на прозорец по посока на стрелката              |
| `Super + Shift + Arrow`  | Размени прозорец с друг по посока на стрелката     |
| `Super + Minus` | Разшири прозореца наляво |
| `Super + Equal` | Сви прозореца наляво |
| `Super + Shift + Minus` | Сви прозореца нагоре |
| `Super + Shift + Equal` | Разшири прозореца надолу |
| `Super + Alt + Minus/Equal` | Същото оразмеряване с по-малки стъпки |
| `Super + Ctrl + Minus/Equal` | Същото оразмеряване с по-големи стъпки |
| `Super + Alt + Home` | Запази ширината на прозореца |
| `Super + Home` | Възстанови запазената ширина на прозореца |
| `Super + Left Mouse` | Влачи прозорец наоколо |
| `Super + Right Mouse` | Оразмери прозорец |
| `Super + Scroll Wheel` | Превъртай през работни пространства |
| `Super + G`               | Превключи групирането на прозорци      |
| `Super + Alt + G`               | Извади прозорец от групирането      |
| `Super + Alt + Tab`               | Превъртай между прозорци в групиране      |
| `Super + Alt + Shift + Tab`               | Превъртай назад между прозорци в групиране      |
| `Super + Alt + 1/2/3/4/5`               | Скочи на конкретен прозорец в групиране      |
| `Super + Alt + Arrow`  | Премести прозорец в групирането по посока на стрелката  |
| `Super + Ctrl + Left/Right`  | Движи се между прозорци вътре в група с плочки |
| `Super + Ctrl + Z` | Увеличи на екрана (повтори за повече увеличение) |
| `Super + Ctrl + Alt + Z` | Намали изцяло от екрана |
| `Super + /` | Стъпи напред през опциите за мащабиране на монитора |
| `Super + Alt + /` | Стъпи назад през опциите за мащабиране на монитора |
| `Alt + Tab` | Превъртай напред през прозорци на активното работно пространство |
| `Alt + Shift + Tab` | Превъртай назад през прозорци на активното работно пространство |
| `Ctrl + Alt + Tab`| Превъртай фокуса напред през монитори |
| `Ctrl + Alt + Shift + Tab`| Превъртай фокуса назад през монитори |

## Универсален клипборд

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Super + C`           | Копирай    |
| `Super + X`           | Изрежи (не в терминал)    |
| `Super + V`           | Постави    |
| `Super + Ctrl + V`           | Мениджър на клипборда    |

Обикновено на Linux ти трябват `Ctrl + Shift + C/V`, за да копираш и поставяш в терминала, и `Ctrl + C/V`, за да го правиш навсякъде другаде. Тези единни клавишни комбинации за клипборда на Omarchy работят навсякъде.

## Заснемане

| Клавишна комбинация              | Функция                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Меню за заснемане (за клавиатури без бутон PrintScr) |
| `Print Screen`            | Снимка на екрана                      |
| `Alt + Print Screen`            | Запис на екрана                     |
| `Super + Print Screen` | Избор на цвят |
| `Super + Ctrl + Print Screen` | Извличане на текст в клипборда |
| `Super + Alt + [` | Намали наслагването на уебкамерата по време на запис |
| `Super + Alt + ]` | Увеличи наслагването на уебкамерата по време на запис |
| `Alt + Shift + L` | Копирай текущия URL от уеб приложение или Chromium |
| `Alt + Shift + D` | Изтегли видеото на текущата страница в `~/Videos` |
| `Super + Ctrl + X` | Стартирай/спри диктовка (изисква _Настройка > По подразбиране > Диктовка_) |
| `Right Alt` / `F9` | Диктовка с натискане за говорене (изисква Voxtype или Superwhisper) |

При записи на екрана клавишната комбинация първо пита кой звук искаш, след това започва записа. Натисни я отново, за да спреш. Виж [снимки на екрана и запис](12-screenshots-recording.md) за подробностите.

Всички опции за заснемане са достъпни и под _Задействай > Заснемане_ в менюто на Omarchy (`Super + Space`).

## Стил

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Super + Ctrl + Shift + Space` | Избери нова тема  |
| `Super + Ctrl + Space` | Избери фон на тема |

| `Super + Ctrl + Backspace` | Превключи квадратното съотношение за единичен прозорец |

Допълнителни фонови изображения живеят в `~/.config/omarchy/backgrounds/<theme name>`. Достъпно също чрез _Инсталирай > Стил > Фон_ в менюто на Omarchy.

Всички опции за стил са достъпни и под _Стил_ в менюто на Omarchy (`Super + Space`).

## Tmux

Префиксният клавиш е `Ctrl + Space` (`Ctrl + B` също работи). Можеш да промениш тези връзки в `~/.config/tmux/tmux.conf`.

### Панели

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + v` | Раздели панела встрани (вертикално) |
| `Prefix + h` | Раздели панела отдолу (хоризонтално) |
| `Prefix + x` | Убий панела |
| `Prefix + z` | Превключи увеличението на панела (на цял екран) |
| `Alt + Enter` | Раздели панела отдолу (без префикс) |
| `Alt + Shift + Enter` | Раздели панела встрани (без префикс) |
| `Alt + Escape` | Убий панела (без префикс) |
| `Ctrl + Alt + Arrows` | Движи се между панели |
| `Ctrl + Alt + Shift + Arrows` | Оразмерявай панели |

### Прозорци

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + c` | Нов прозорец |
| `Prefix + k` | Убий прозореца |
| `Prefix + r` | Преименувай прозореца |
| `Alt + 1-9` | Отиди на конкретен прозорец |
| `Alt + Arrow Left/Right` | Движи се между прозорци |
| `Alt + Shift + Arrow Left/Right` | Мести прозореца наляво/надясно |

### Сесии

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + C` | Нова сесия |
| `Prefix + K` | Убий сесията |
| `Prefix + R` | Преименувай сесията |
| `Prefix + N` | Следваща сесия |
| `Prefix + P` | Предишна сесия |
| `Alt + Arrow Up/Down` | Движи се между сесии |
| `Prefix + s` | Изброй сесиите |
| `Prefix + d` | Откачи се от сесията |

### Режим за копиране (в стил vi)

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + [` | Влез в режим за копиране |
| `v` | Започни избор (в режим за копиране) |
| `y` | Копирай избора (в режим за копиране) |

### Общи

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + q` | Презареди конфигурацията |
| `Prefix + ?` | Покажи клавишните комбинации на Tmux |
| `Prefix + :` | Команден ред |

### Функции за оформление в Tmux

Тези функции трябва да се изпълняват вътре в Tmux сесия.

| Команда | Функция |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Създай оформление за разработка с редактор, AI и терминал |
| `tdlm <ai> [<second_ai>]` | Създай оформление за разработка за поддиректория |
| `tsl <count> <command>` | Създай роячно оформление с много панели |
