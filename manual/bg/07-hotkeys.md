# Клавишни комбинации

Можете да видите всички основни клавишни комбинации с `Super + K` (комбинациите за Tmux с `Super + Alt + K`, а за Herdr с `Super + Ctrl + K`).

## Навигация

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Super + Space`           | Меню на Omarchy (приложения и всичко останало)    |
| `Super + Alt + Space` | Мрежа с приложения |
| `Super + Escape` | Системно меню (спиране, рестартиране и др.)  |
| `Super + Ctrl + L` | Заключване на компютъра |
| `Super + W` or `Super + Q` | Затваряне на прозорец             |
| `Ctrl + Alt + Del` | Затваряне на всички прозорци |
| `Super + T`               | Превключване на прозореца между плочков/плаващ режим             |
| `Super + J` | Превключване на позицията на прозореца (хоризонтална/вертикална) |
| `Super + O`               | Превключване на изскачащ прозорец в лепкав и плаващ |
| `Super + L`               | Циклично превключване между подредбите dwindle, scrolling и floating |
| `Super + Alt + L`         | Циклично превключване между подредбите в обратен ред |
| `Super + P`               | Превключване на стила на псевдопрозорец (естествен срещу разтегнат) |
| `Super + F`                 | Цял екран              |
| `Super + Alt + F`                 | Цяла ширина              |
| `Super + Ctrl + F`                 | Цял екран вътре в прозореца              |
| `Super + 1/2/3/4`         | Преминаване към конкретно работно пространство на фокусирания монитор |
| `Super + Tab` | Преминаване към следващото работно пространство на фокусирания монитор |
| `Super + Shift + Tab` | Преминаване към предишното работно пространство на фокусирания монитор |
| `Super + Ctrl + Tab` | Преминаване към последно използваното работно пространство на фокусирания монитор |
| `Super + Shift + 1/2/3/4` | Преместване на прозорец към работно пространство на фокусирания монитор |
| `Super + Shift + Alt + 1/2/3/4` | Преместване на прозорец към работно пространство на фокусирания монитор, без да го следвате |
| `Super + S` | Превключване на цял scratchpad |
| `Super + Alt + S` | Преместване на прозорец към цял scratchpad |
| `Super + Grave` | Превключване на конзолата Quake |
| `Super + Shift + Grave` | Преместване на прозорец към конзолата Quake |
| `Super + Shift + Ctrl + Arrows` | Преместване на прозорец към монитора в тази посока |
| `Super + Shift + Alt + Arrows` | Преместване на работно пространство към монитора в тази посока |
| `Super + Arrow`  | Преместване на фокуса към прозорец в посоката на стрелката, с преминаване към монитора от тази страна при ръба на екрана |
| `Super + Shift + Arrow`  | Размяна на прозорец с друг в посоката на стрелката, включително такъв на монитора от тази страна |
| `Super + Minus` | Разширяване на прозореца наляво |
| `Super + Equal` | Свиване на прозореца наляво |
| `Super + Shift + Minus` | Свиване на прозореца нагоре |
| `Super + Shift + Equal` | Разширяване на прозореца надолу |
| `Super + Alt + Minus/Equal` | Същото преоразмеряване на по-малки стъпки |
| `Super + Ctrl + Minus/Equal` | Същото преоразмеряване на по-големи стъпки |
| `Super + Alt + Home` | Запазване на ширината на прозореца |
| `Super + Home` | Възстановяване на запазената ширина на прозореца |
| `Super + Left Mouse` | Влачене на прозореца |
| `Super + Right Mouse` | Преоразмеряване на прозорец |
| `Super + Scroll Wheel` | Превъртане през работните пространства на фокусирания монитор |
| `Super + G`               | Превключване на групирането на прозорци      |
| `Super + Alt + G`               | Изваждане на прозорец от група      |
| `Super + Alt + Tab`               | Циклично превключване между прозорците в групата      |
| `Super + Alt + Shift + Tab`               | Циклично превключване назад между прозорците в групата      |
| `Super + Alt + Scroll Wheel` | Циклично превключване между прозорците в групата |
| `Super + Alt + 1/2/3/4/5`               | Преминаване към конкретен прозорец в групата      |
| `Super + Alt + Arrow`  | Преместване на прозорец в група в посоката на стрелката, включително такъв на монитора от тази страна |
| `Super + Ctrl + Left/Right`  | Преместване между прозорци в плочкова група |
| `Super + Ctrl + Z` | Увеличаване на мащаба на екрана (повторете за повече увеличение) |
| `Super + Ctrl + Alt + Z` | Пълно намаляване на мащаба на екрана |
| `Super + /` | Стъпка напред през опциите за мащабиране на монитора |
| `Super + Alt + /` | Стъпка назад през опциите за мащабиране на монитора |
| `Alt + Tab` | Циклично превключване напред през прозорците на активното работно пространство |
| `Alt + Shift + Tab` | Циклично превключване назад през прозорците на активното работно пространство |
| `Ctrl + Alt + Tab`| Циклично преместване на фокуса напред през мониторите |
| `Ctrl + Alt + Shift + Tab`| Циклично преместване на фокуса назад през мониторите |

Клавишите за преоразмеряване използват физическите клавиши `code:20` и `code:21` (XKB `<AE11>` и `<AE12>`), независимо от символите, отпечатани на клавиатурата. На американски клавиатури тези клавиши са `-` и `=`; на японски (JIS) клавиатури са `-` и `^`; на испански клавиатури са `'` и `¡`. На JIS `Super + ^` е `Super + Equal`, докато `Super + Shift + -` (което въвежда `=`) е `Super + Shift + Minus`.

## Универсален клипборд

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Super + A`           | Избиране на всичко в приложения, които поддържат `Ctrl + A`    |
| `Super + C`           | Копиране    |
| `Super + X`           | Изрязване (не в терминала)    |
| `Super + V`           | Поставяне    |
| `Super + Ctrl + V`           | Мениджър на клипборда    |

Обикновено в Linux трябва `Ctrl + Shift + C/V` за копиране и поставяне в терминала и `Ctrl + C/V` навсякъде другаде. Тези унифицирани клавишни комбинации за клипборда на Omarchy работят навсякъде.

| Клавишна комбинация              | Функция                       |

| `Print Screen`            | Екранна снимка                      |

| `Super + Ctrl + Print Screen` | Извличане на текст в клипборда |

При записите на екрана клавишната комбинация първо пита кой звук искате, след което започва записа. Натиснете я отново, за да спрете. Вижте [екранни снимки и запис](12-screenshots-recording.md) за подробностите.

Всички опции за заснемане са достъпни и от _Trigger > Capture_ в менюто на Omarchy (`Super + Space`).

## Tmux

Префиксният клавиш е `Ctrl + Space` (`Ctrl + B` също работи). Можете да промените тези комбинации в `~/.config/tmux/tmux.conf`.

### Панели

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + v` | Разделяне на панел отстрани (вертикално) |
| `Prefix + h` | Разделяне на панел отдолу (хоризонтално) |
| `Prefix + x` | Затваряне на панел |
| `Prefix + z` | Превключване на мащаба на панела (цял екран) |
| `Alt + Enter` | Разделяне на панел отдолу (без префикс) |
| `Alt + Shift + Enter` | Разделяне на панел отстрани (без префикс) |
| `Alt + Escape` | Затваряне на панел (без префикс) |
| `Ctrl + Alt + Arrows` | Преместване между панели |
| `Ctrl + Alt + Shift + Arrows` | Преоразмеряване на панели |

### Прозорци

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + c` | Нов прозорец |
| `Prefix + k` | Затваряне на прозорец |
| `Prefix + r` | Преименуване на прозорец |
| `Alt + 1-9` | Преминаване към конкретен прозорец |
| `Alt + Arrow Left/Right` | Преместване между прозорци |
| `Alt + Shift + Arrow Left/Right` | Преместване на прозорец наляво/надясно |

### Сесии

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + C` | Нова сесия |
| `Prefix + K` | Затваряне на сесия |
| `Prefix + R` | Преименуване на сесия |
| `Prefix + N` | Следваща сесия |
| `Prefix + P` | Предишна сесия |
| `Alt + Arrow Up/Down` | Преместване между сесии |
| `Prefix + s` | Списък със сесии |
| `Prefix + d` | Откачане от сесия |

### Режим на копиране (vi-style)

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + [` | Влизане в режим на копиране |
| `v` | Започване на избор (в режим на копиране) |
| `y` | Копиране на избора (в режим на копиране) |

### Общи

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + q` | Презареждане на конфигурацията |
| `Prefix + ?` | Показване на клавишните комбинации на Tmux |
| `Prefix + :` | Команден ред |

### Функции за подредба в Tmux

Тези функции трябва да се изпълняват в сесия на Tmux.

| Команда | Функция |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Създаване на подредба за разработка с редактор, AI и терминал |
| `tdlm <ai> [<second_ai>]` | Създаване на подредба за разработка за всяка поддиректория |
| `tsl <count> <command>` | Създаване на подредба тип рояк с множество панели |

Можете да използвате `Super + Ctrl + E`, за да покажете пълен избор на емоджита, който ще постави избора в клипборда, или можете да използвате тези опции за бърз достъп.

| Клавишна комбинация       | EM | Подсказка       |
| ------------ | -- | ---------- |
| `Shift + CapsLock M S` | 😄 | усмивка      |

## Бързи допълвания

| Клавишна комбинация       | Допълване       |
| ------------ |  ---------- |
| `Shift + CapsLock Space Space` | — (дълго тире)   |
| `Shift + CapsLock Space N` | Вашето име (както е въведено при настройката)  |
| `Shift + CapsLock Space E` | Вашият имейл (както е въведен при настройката)  |

Можете да добавите още свои, като редактирате `~/.XCompose`, след което изпълните `omarchy-restart-xcompose` в терминала, за да се приложат промените.
