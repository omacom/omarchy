# Клавишни комбинации

Можете да видите всички основни клавишни комбинации с `Super + K` (комбинациите за Tmux с `Super + Alt + K` и комбинациите за Herdr с `Super + Ctrl + K`).

## Навигация

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Super + Space`           | Меню на Omarchy (приложения и всичко останало)    |
| `Super + Alt + Space` | Решетка с приложения |
| `Super + Escape` | Системно меню (спиране, рестартиране и т.н.)  |
| `Super + Ctrl + L` | Заключване на компютъра |
| `Super + W` или `Super + Q` | Затваряне на прозорец             |
| `Ctrl + Alt + Del` | Затваряне на всички прозорци |
| `Super + T`               | Превключване на прозореца между подреждане/плаващ             |
| `Super + J` | Превключване на позицията на прозореца (хоризонтална/вертикална) |
| `Super + O`               | Превключване на изскачането на прозореца в sticky'n'floating |
| `Super + L`               | Циклично превключване между оформленията dwindle, scrolling и floating |
| `Super + Alt + L`         | Циклично превключване между оформленията в обратен ред |
| `Super + P`               | Превключване на стила на псевдо прозорец (natural срещу stretch) |
| `Super + F`                 | Цял екран              |
| `Super + Alt + F`                 | Цяла ширина              |
| `Super + Ctrl + F`                 | Цял екран вътре в прозореца              |
| `Super + 1/2/3/4`         | Преминаване към конкретно работно пространство на фокусирания монитор |
| `Super + Tab` | Преминаване към следващото работно пространство на фокусирания монитор |
| `Super + Shift + Tab` | Преминаване към предишното работно пространство на фокусирания монитор |
| `Super + Ctrl + Tab` | Преминаване към предишно използваното работно пространство на фокусирания монитор |
| `Super + Shift + 1/2/3/4` | Преместване на прозореца в работно пространство на фокусирания монитор |
| `Super + Shift + Alt + 1/2/3/4` | Преместване на прозореца в работно пространство на фокусирания монитор без следване |
| `Super + S` | Превключване на пълния scratchpad |
| `Super + Alt + S` | Преместване на прозореца в пълния scratchpad |
| `Super + Grave` | Превключване на конзолата Quake |
| `Super + Shift + Grave` | Преместване на прозореца в конзолата Quake |
| `Super + Shift + Ctrl + Arrows` | Преместване на прозореца на монитора в тази посока |
| `Super + Shift + Alt + Arrows` | Преместване на работното пространство на монитора в тази посока |
| `Super + Arrow`  | Преместване на фокуса към прозореца в посоката на стрелката, с преминаване към монитора от тази страна при ръба на екрана |
| `Super + Shift + Arrow`  | Размяна на прозореца с друг в посоката на стрелката, включително такъв на монитора от тази страна |
| `Super + Minus` | Разширяване на прозореца наляво |
| `Super + Equal` | Свиване на прозореца наляво |
| `Super + Shift + Minus` | Свиване на прозореца нагоре |
| `Super + Shift + Equal` | Разширяване на прозореца надолу |
| `Super + Alt + Minus/Equal` | Същото преоразмеряване на по-малки стъпки |
| `Super + Ctrl + Minus/Equal` | Същото преоразмеряване на по-големи стъпки |
| `Super + Alt + Home` | Запазване на ширината на прозореца |
| `Super + Home` | Възстановяване на запазената ширина на прозореца |
| `Super + Left Mouse` | Влачене на прозореца наоколо |
| `Super + Right Mouse` | Преоразмеряване на прозореца |
| `Super + Scroll Wheel` | Превъртане през работните пространства на фокусирания монитор |
| `Super + G`               | Превключване на групирането на прозорци      |
| `Super + Alt + G`               | Изваждане на прозореца от групиране      |
| `Super + Alt + Tab`               | Циклично превключване между прозорците в групиране      |
| `Super + Alt + Shift + Tab`               | Циклично превключване назад между прозорците в групиране      |
| `Super + Alt + Scroll Wheel` | Циклично превключване между прозорците в групиране |
| `Super + Alt + 1/2/3/4/5`               | Преминаване към конкретен прозорец в групиране      |
| `Super + Alt + Arrow`  | Преместване на прозореца в групиране в посоката на стрелката, включително такъв на монитора от тази страна |
| `Super + Ctrl + Left/Right`  | Преминаване между прозорците вътре в група за подреждане |
| `Super + Ctrl + Z` | Увеличаване на екрана (повторете за още по-голямо увеличение) |
| `Super + Ctrl + Alt + Z` | Пълно намаляване от екрана |
| `Super + /` | Преминаване напред през опциите за мащабиране на монитора |
| `Super + Alt + /` | Преминаване назад през опциите за мащабиране на монитора |
| `Alt + Tab` | Циклично превключване напред през прозорците в активното работно пространство |
| `Alt + Shift + Tab` | Циклично превключване назад през прозорците в активното работно пространство |
| `Ctrl + Alt + Tab`| Циклично преместване на фокуса напред през мониторите |
| `Ctrl + Alt + Shift + Tab`| Циклично преместване на фокуса назад през мониторите |

## Универсален клипборд

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Super + C`           | Копиране    |
| `Super + X`           | Изрязване (не в терминал)    |
| `Super + V`           | Поставяне    |
| `Super + Ctrl + V`           | Мениджър на клипборда    |

Обикновено в Linux ви трябва `Ctrl + Shift + C/V`, за да копирате и поставяте в терминала, и `Ctrl + C/V`, за да го правите навсякъде другаде. Тези унифицирани клавишни комбинации за клипборда в Omarchy работят навсякъде.

## Заснемане

| Клавишна комбинация              | Функция                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Екранна снимка                      |
| `Super + Ctrl + Alt + C`            | Екранна снимка (същата снимка, за клавиатури без клавиш Print Screen) |
| `Super + Ctrl + C` | Меню за заснемане |
| `Alt + Print Screen`            | Запис на екрана                     |
| `Super + Print Screen` | Избор на цвят |
| `Super + Ctrl + Print Screen` | Извличане на текст в клипборда |
| `Super + Alt + [` | Намаляване на наслагването на уебкамерата по време на запис |
| `Super + Alt + ]` | Увеличаване на наслагването на уебкамерата по време на запис |
| `Alt + Shift + L` | Копиране на текущия URL от уеб приложение или Chromium |
| `Alt + Shift + D` | Изтегляне на видеото на текущата страница в `~/Videos` |
| `Super + Ctrl + X` | Старт/стоп на диктовка (изисква _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | Диктовка с натискане за говорене (изисква Voxtype или Superwhisper) |

При записите на екрана клавишната комбинация първо пита кое аудио искате, след което започва записа. Натиснете я отново, за да спрете. Вижте [екранни снимки и запис](12-screenshots-recording.md) за подробностите.

Всички опции за заснемане са достъпни и под _Trigger > Capture_ в менюто на Omarchy (`Super + Space`).

## Стил

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Super + Ctrl + T` | Избор на нова тема (също `Super + Ctrl + Shift + Space`) |

Всички опции за стил са достъпни и под _Style_ в менюто на Omarchy (`Super + Space`).

## Tmux

Префиксният клавиш е `Ctrl + Space` (`Ctrl + B` също работи). Можете да промените тези комбинации в `~/.config/tmux/tmux.conf`.

### Панели

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + v` | Разделяне на панела отстрани (вертикално) |
| `Prefix + h` | Разделяне на панела отдолу (хоризонтално) |
| `Prefix + x` | Убиване на панела |
| `Prefix + z` | Превключване на увеличението на панела (на цял екран) |
| `Alt + Enter` | Разделяне на панела отдолу (без префикс) |
| `Alt + Shift + Enter` | Разделяне на панела отстрани (без префикс) |
| `Alt + Escape` | Убиване на панела (без префикс) |
| `Ctrl + Alt + Arrows` | Преминаване между панелите |
| `Ctrl + Alt + Shift + Arrows` | Преоразмеряване на панелите |

### Прозорци

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + c` | Нов прозорец |
| `Prefix + k` | Убиване на прозореца |
| `Prefix + r` | Преименуване на прозореца |
| `Alt + 1-9` | Отиване към конкретен прозорец |
| `Alt + Arrow Left/Right` | Преминаване между прозорците |
| `Alt + Shift + Arrow Left/Right` | Преместване на прозореца наляво/надясно |

### Сесии

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + C` | Нова сесия |
| `Prefix + K` | Убиване на сесията |
| `Prefix + R` | Преименуване на сесията |
| `Prefix + N` | Следваща сесия |
| `Prefix + P` | Предишна сесия |
| `Alt + Arrow Up/Down` | Преминаване между сесиите |
| `Prefix + s` | Списък със сесии |
| `Prefix + d` | Откачане от сесията |

### Режим на копиране (в стил vi)

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + [` | Влизане в режим на копиране |
| `v` | Започване на избор (в режим на копиране) |
| `y` | Копиране на избора (в режим на копиране) |

### Общи

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + q` | Презареждане на конфигурацията |
| `Prefix + ?` | Показване на клавишните комбинации на Tmux |
| `Prefix + :` | Команден ред |

### Функции за оформление в Tmux

Тези функции трябва да се изпълняват вътре в сесия на Tmux.

| Команда | Функция |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Създаване на оформление за разработка с редактор, AI и терминал |
| `tdlm <ai> [<second_ai>]` | Създаване на оформление за разработка за всяка поддиректория |
| `tsl <count> <command>` | Създаване на оформление swarm с множество панели |
