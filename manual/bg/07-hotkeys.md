# Клавишни комбинации

Можете да видите всички основни клавишни комбинации с `Super + K` (комбинациите за Tmux с `Super + Alt + K` и комбинациите за Herdr с `Super + Ctrl + K`).

## Навигация

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Super + Space`           | Меню на Omarchy (приложения и всичко останало)    |
| `Super + Alt + Space` | Мрежа с приложения |
| `Super + Escape` | Системно меню (спиране, рестартиране и др.)  |
| `Super + Ctrl + L` | Заключване на компютъра |
| `Super + W` or `Super + Q` | Затваряне на прозорец             |
| `Ctrl + Alt + Del` | Затваряне на всички прозорци |
| `Super + T`               | Превключване на прозореца между плочков/плаващ режим             |
| `Super + J` | Превключване на позицията на прозореца (хоризонтална/вертикална) |
| `Super + O`               | Превключване на изскачащия прозорец в sticky'n'floating |
| `Super + L`               | Циклично преминаване през оформленията dwindle, scrolling и floating |
| `Super + Alt + L`         | Циклично преминаване през оформленията в обратен ред |
| `Super + P`               | Превключване на стила на псевдопрозореца (natural срещу stretch) |
| `Super + F`                 | Цял екран              |
| `Super + Alt + F`                 | Цяла ширина              |
| `Super + Ctrl + F`                 | Цял екран вътре в прозореца              |
| `Super + 1/2/3/4`         | Преминаване към конкретно работно пространство на фокусирания монитор |
| `Super + Tab` | Преминаване към следващото работно пространство на фокусирания монитор |
| `Super + Shift + Tab` | Преминаване към предишното работно пространство на фокусирания монитор |
| `Super + Ctrl + Tab` | Преминаване към предишно използваното работно пространство на фокусирания монитор |
| `Super + Shift + 1/2/3/4` | Преместване на прозореца към работно пространство на фокусирания монитор |
| `Super + Shift + Alt + 1/2/3/4` | Преместване на прозореца към работно пространство на фокусирания монитор без следване |
| `Super + S` | Превключване на пълния scratchpad |
| `Super + Alt + S` | Преместване на прозореца към пълния scratchpad |
| `Super + Grave` | Превключване на Quake конзолата |
| `Super + Shift + Grave` | Преместване на прозореца към Quake конзолата |
| `Super + Shift + Ctrl + Arrows` | Преместване на прозореца към монитора в тази посока |
| `Super + Shift + Alt + Arrows` | Преместване на работното пространство към монитора в тази посока |
| `Super + Arrow`  | Преместване на фокуса към прозореца в посоката на стрелката, с преминаване към монитора от тази страна при ръба на екрана |
| `Super + Shift + Arrow`  | Размяна на прозореца с друг в посоката на стрелката, включително такъв на монитора от тази страна |
| `Super + Minus` | Разширяване на прозореца наляво |
| `Super + Equal` | Свиване на прозореца наляво |
| `Super + Shift + Minus` | Свиване на прозореца нагоре |
| `Super + Shift + Equal` | Разширяване на прозореца надолу |
| `Super + Alt + Minus/Equal` | Същото преоразмеряване с по-малки стъпки |
| `Super + Ctrl + Minus/Equal` | Същото преоразмеряване с по-големи стъпки |
| `Super + Alt + Home` | Запазване на ширината на прозореца |
| `Super + Home` | Възстановяване на запазената ширина на прозореца |
| `Super + Left Mouse` | Плъзгане на прозореца наоколо |
| `Super + Right Mouse` | Преоразмеряване на прозореца |
| `Super + Scroll Wheel` | Превъртане през работните пространства на фокусирания монитор |
| `Super + G`               | Превключване на групирането на прозорци      |
| `Super + Alt + G`               | Изваждане на прозореца от групата      |
| `Super + Alt + Tab`               | Циклично преминаване между прозорците в групата      |
| `Super + Alt + Shift + Tab`               | Циклично преминаване назад между прозорците в групата      |
| `Super + Alt + Scroll Wheel` | Циклично преминаване между прозорците в групата |
| `Super + Alt + 1/2/3/4/5`               | Преминаване към конкретен прозорец в групата      |
| `Super + Alt + Arrow`  | Преместване на прозореца в група в посоката на стрелката, включително такъв на монитора от тази страна |
| `Super + Ctrl + Left/Right`  | Преминаване между прозорците вътре в плочкова група |
| `Super + Ctrl + Z` | Увеличаване на мащаба на екрана (повторете за още по-голямо увеличение) |
| `Super + Ctrl + Alt + Z` | Пълно намаляване на мащаба на екрана |
| `Super + /` | Придвижване напред през опциите за мащабиране на монитора |
| `Super + Alt + /` | Придвижване назад през опциите за мащабиране на монитора |
| `Alt + Tab` | Циклично преминаване напред през прозорците на активното работно пространство |
| `Alt + Shift + Tab` | Циклично преминаване назад през прозорците на активното работно пространство |
| `Ctrl + Alt + Tab`| Циклично преминаване на фокуса напред през мониторите |
| `Ctrl + Alt + Shift + Tab`| Циклично преминаване на фокуса назад през мониторите |

Клавишните комбинации за преоразмеряване използват физическите клавиши `code:20` и `code:21` (XKB `<AE11>` и `<AE12>`), независимо от символите, отпечатани на клавиатурата. На американските клавиатури тези клавиши са `-` и `=`; на японските (JIS) клавиатури са `-` и `^`; на испанските клавиатури са `'` и `¡`. На JIS `Super + ^` е `Super + Equal`, докато `Super + Shift + -` (което въвежда `=`) е `Super + Shift + Minus`.

## Универсален клипборд

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Super + A`           | Избиране на всичко в приложения, които поддържат `Ctrl + A`    |
| `Super + C`           | Копиране    |
| `Super + X`           | Изрязване (не в терминала)    |
| `Super + V`           | Поставяне    |
| `Super + Ctrl + V`           | Мениджър на клипборда    |

Обикновено в Linux трябва `Ctrl + Shift + C/V` за копиране и поставяне в терминала и `Ctrl + C/V`, за да го правите навсякъде другаде. Тези унифицирани клавишни комбинации за клипборда на Omarchy работят навсякъде.

## Tmux

Префиксният клавиш е `Ctrl + Space` (`Ctrl + B` също работи). Можете да промените тези комбинации в `~/.config/tmux/tmux.conf`.

### Панели

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + v` | Разделяне на панела отстрани (вертикално) |
| `Prefix + h` | Разделяне на панела отдолу (хоризонтално) |
| `Prefix + x` | Убиване на панела |
| `Prefix + z` | Превключване на мащаба на панела (цял екран) |
| `Alt + Enter` | Разделяне на панела отдолу (без префикс) |
| `Alt + Shift + Enter` | Разделяне на панела отстрани (без префикс) |
| `Alt + Escape` | Убиване на панела (без префикс) |
| `Ctrl + Alt + Arrows` | Преминаване между панелите |
| `Ctrl + Alt + Shift + Arrows` | Преоразмеряване на панелите |

### Прозорци

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + c` | Нов прозорец |
| `Prefix + k` | Убиване на прозореца |
| `Prefix + r` | Преименуване на прозореца |
| `Alt + 1-9` | Отиване до конкретен прозорец |
| `Alt + Arrow Left/Right` | Преминаване между прозорците |
| `Alt + Shift + Arrow Left/Right` | Преместване на прозореца наляво/надясно |

### Общи

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + q` | Презареждане на конфигурацията |
| `Prefix + ?` | Показване на клавишните комбинации на Tmux |

### Функции за оформление на Tmux

Тези функции трябва да се изпълняват вътре в Tmux сесия.

| Команда | Функция |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Създаване на оформление за разработка с редактор, AI и терминал |
| `tdlm <ai> [<second_ai>]` | Създаване на оформление за разработка за всяка поддиректория |
| `tsl <count> <command>` | Създаване на оформление тип рояк с множество панели |

Можете да използвате `Super + Ctrl + E`, за да покажете пълен избор на емоджита, който ще постави избора в клипборда, или можете да използвате тези опции за бърз достъп.

| Клавишна комбинация       | EM | Подсказка       |
| ------------ | -- | ---------- |

## Бързи довършвания

| Клавишна комбинация       | Довършване       |
| ------------ |  ---------- |
| `Shift + CapsLock Space Space` | — (дълго тире)   |
| `Shift + CapsLock Space N` | Вашето име (както е въведено при настройката)  |
| `Shift + CapsLock Space E` | Вашият имейл (както е въведен при настройката)  |

Можете да добавите още свои, като редактирате `~/.XCompose`, след което изпълните `omarchy-restart-xcompose` в терминала, за да бъдат приети промените.
