# Клавишни комбинации

Можете да видите всички основни клавишни комбинации със `Super + K` (комбинациите за Tmux със `Super + Alt + K`, а комбинациите за Herdr със `Super + Ctrl + K`).

## Навигиране

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Super + Space`           | Меню на Omarchy (приложения и всичко останало)    |
| `Super + Alt + Space` | Решетка с приложения |
| `Super + Escape` | Системно меню (спиране, рестартиране и др.)  |
| `Super + Ctrl + L` | Заключване на компютъра |
| `Super + W` or `Super + Q` | Затваряне на прозорец             |
| `Ctrl + Alt + Del` | Затваряне на всички прозорци |
| `Super + T`               | Превключване на прозореца между подреждане/плаващ режим             |
| `Super + J` | Превключване на позицията на прозореца (хоризонтална/вертикална) |
| `Super + O`               | Превключване на прозореца в залепващ плаващ режим |
| `Super + L`               | Превъртане през оформленията dwindle, scrolling и floating |
| `Super + Alt + L`         | Превъртане през оформленията в обратен ред |
| `Super + P`               | Превключване на псевдо стила на прозореца (естествен срещу разтегнат) |
| `Super + F`                 | Цял екран              |
| `Super + Alt + F`                 | Цяла ширина              |
| `Super + Ctrl + F`                 | Цял екран вътре в прозореца              |
| `Super + 1/2/3/4`         | Отиване до конкретно работно пространство на фокусирания монитор |
| `Super + Tab` | Отиване до следващото работно пространство на фокусирания монитор |
| `Super + Shift + Tab` | Отиване до предишното работно пространство на фокусирания монитор |
| `Super + Ctrl + Tab` | Отиване до предходното работно пространство на фокусирания монитор |
| `Super + Shift + 1/2/3/4` | Преместване на прозореца в работно пространство на фокусирания монитор |
| `Super + Shift + Alt + 1/2/3/4` | Преместване на прозореца в работно пространство на фокусирания монитор, без да го следвате |
| `Super + S` | Превключване на пълния scratchpad |
| `Super + Alt + S` | Преместване на прозореца в пълния scratchpad |
| `Super + Grave` | Превключване на конзолата Quake |
| `Super + Shift + Grave` | Преместване на прозореца в конзолата Quake |
| `Super + Shift + Ctrl + Arrows` | Преместване на прозореца към монитора в тази посока |
| `Super + Shift + Alt + Arrows` | Преместване на работното пространство към монитора в тази посока |
| `Super + Arrow`  | Преместване на фокуса към прозореца в посоката на стрелката, с преминаване към монитора от тази страна при ръба на екрана |
| `Super + Shift + Arrow`  | Размяна на прозореца с друг в посоката на стрелката, включително такъв на монитора от тази страна |
| `Super + Minus` | Разширяване на прозореца наляво |
| `Super + Equal` | Свиване на прозореца отляво |
| `Super + Shift + Minus` | Свиване на прозореца нагоре |
| `Super + Shift + Equal` | Разширяване на прозореца надолу |
| `Super + Alt + Minus/Equal` | Същото преоразмеряване на по-малки стъпки |
| `Super + Ctrl + Minus/Equal` | Същото преоразмеряване на по-големи стъпки |
| `Super + Alt + Home` | Запазване на ширината на прозореца |
| `Super + Home` | Възстановяване на запазената ширина на прозореца |
| `Super + Left Mouse` | Влачене на прозореца наоколо |
| `Super + Right Mouse` | Преоразмеряване на прозореца |
| `Super + Scroll Wheel` | Превъртане през работните пространства на фокусирания монитор |
| `Super + G`               | Превключване на групирането на прозорци      |
| `Super + Alt + G`               | Изваждане на прозореца от групата      |
| `Super + Alt + Tab`               | Превъртане между прозорците в групата      |
| `Super + Alt + Shift + Tab`               | Превъртане назад между прозорците в групата      |
| `Super + Alt + Scroll Wheel` | Превъртане между прозорците в групата |
| `Super + Alt + 1/2/3/4/5`               | Отиване до конкретен прозорец в групата      |
| `Super + Alt + Arrow`  | Преместване на прозореца в група в посоката на стрелката, включително такава на монитора от тази страна |
| `Super + Ctrl + Left/Right`  | Придвижване между прозорците в група за подреждане |
| `Super + Ctrl + Z` | Увеличаване на мащаба на екрана (повторете за още по-голямо увеличение) |
| `Super + Ctrl + Alt + Z` | Пълно намаляване на мащаба на екрана |
| `Super + /` | Придвижване напред през опциите за мащабиране на монитора |
| `Super + Alt + /` | Придвижване назад през опциите за мащабиране на монитора |
| `Alt + Tab` | Превъртане напред през прозорците на активното работно пространство |
| `Alt + Shift + Tab` | Превъртане назад през прозорците на активното работно пространство |
| `Ctrl + Alt + Tab`| Превъртане на фокуса напред през мониторите |
| `Ctrl + Alt + Shift + Tab`| Превъртане на фокуса назад през мониторите |

## Универсален клипборд

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Super + C`           | Копиране    |
| `Super + X`           | Изрязване (не в терминала)    |
| `Super + V`           | Поставяне    |
| `Super + Ctrl + V`           | Мениджър на клипборда    |

Обикновено в Linux ви трябват `Ctrl + Shift + C/V` за копиране и поставяне в терминала и `Ctrl + C/V` за същото навсякъде другаде. Тези унифицирани клавишни комбинации за клипборда на Omarchy работят навсякъде.

## Заснемане

| Клавишна комбинация              | Функция                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Снимка на екрана                      |
| `Super + Ctrl + Alt + C`            | Снимка на екрана (същата снимка, за клавиатури без клавиш Print Screen) |
| `Super + Ctrl + C` | Меню за заснемане |
| `Alt + Print Screen`            | Запис на екрана                     |
| `Super + Print Screen` | Избор на цвят |
| `Super + Ctrl + Print Screen` | Извличане на текст в клипборда |
| `Super + Alt + [` | Намаляване на наслагването на уебкамерата по време на запис |
| `Super + Alt + ]` | Увеличаване на наслагването на уебкамерата по време на запис |
| `Alt + Shift + L` | Копиране на текущия URL от уеб приложение или Chromium |
| `Alt + Shift + D` | Изтегляне на видеото от текущата страница в `~/Videos` |
| `Super + Ctrl + X` | Стартиране/спиране на диктовка (изисква _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | Диктовка с push-to-talk (изисква Voxtype или Superwhisper) |

При записите на екрана клавишната комбинация първо пита кой звук искате, след което започва записа. Натиснете я отново, за да спрете. Вижте [снимки на екрана и запис](12-screenshots-recording.md) за подробностите.

Всички опции за заснемане са достъпни и под _Trigger > Capture_ в менюто на Omarchy (`Super + Space`).

| `Super + Ctrl + T` | Избор на нова тема (също и `Super + Ctrl + Shift + Space`) |

## Tmux

Клавишът за префикс е `Ctrl + Space` (работи и `Ctrl + B`). Можете да променяте тези комбинации в `~/.config/tmux/tmux.conf`.

### Панели

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + v` | Разделяне на панела отстрани (вертикално) |
| `Prefix + h` | Разделяне на панела отдолу (хоризонтално) |
| `Prefix + x` | Затваряне на панела |
| `Prefix + z` | Превключване на мащаба на панела (цял екран) |
| `Alt + Enter` | Разделяне на панела отдолу (без префикс) |
| `Alt + Shift + Enter` | Разделяне на панела отстрани (без префикс) |
| `Alt + Escape` | Затваряне на панела (без префикс) |
| `Ctrl + Alt + Arrows` | Придвижване между панелите |
| `Ctrl + Alt + Shift + Arrows` | Преоразмеряване на панелите |

### Прозорци

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + c` | Нов прозорец |
| `Prefix + k` | Затваряне на прозореца |
| `Prefix + r` | Преименуване на прозореца |
| `Alt + 1-9` | Отиване до конкретен прозорец |
| `Alt + Arrow Left/Right` | Придвижване между прозорците |
| `Alt + Shift + Arrow Left/Right` | Преместване на прозореца наляво/надясно |

### Сесии

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + C` | Нова сесия |
| `Prefix + K` | Затваряне на сесията |
| `Prefix + R` | Преименуване на сесията |
| `Prefix + N` | Следваща сесия |
| `Prefix + P` | Предишна сесия |
| `Alt + Arrow Up/Down` | Придвижване между сесиите |
| `Prefix + s` | Списък със сесиите |
| `Prefix + d` | Откачане от сесията |

### Режим на копиране (в стил vi)

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + [` | Влизане в режим на копиране |
| `v` | Започване на избор (в режим на копиране) |
| `y` | Копиране на избраното (в режим на копиране) |

### Общи

| Клавишна комбинация                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + q` | Презареждане на конфигурацията |
| `Prefix + ?` | Показване на клавишните комбинации на Tmux |
| `Prefix + :` | Команден ред |

### Функции за оформление в Tmux

Тези функции трябва да се изпълняват вътре в сесия на Tmux.

| Команда | Функция |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Създаване на оформление за разработка с редактор, AI и терминал |
| `tdlm <ai> [<second_ai>]` | Създаване на оформление за разработка за всяка поддиректория |
| `tsl <count> <command>` | Създаване на оформление тип рояк с множество панели |
