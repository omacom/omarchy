# Клавишни комбинации

Можете да видите всички основни клавишни комбинации със `Super + K` (комбинациите за Tmux със `Super + Alt + K`, а тези за Herdr със `Super + Ctrl + K`).

## Как са подредени клавишните комбинации

Всяка клавишна комбинация лежи на една равнина, определена от нейните модификатори, и всяка равнина има една задача. Това предпазва комбинациите от сливане една с друга и означава, че обикновено можете да отгатнете къде се намира нещо.

| Равнина | Какво живее там | Примери |
| --- | --- | --- |
| `Super + key` | Системата: прозорци, работни пространства, подредби и основни менюта | `Super + Space` меню Omarchy, `Super + W` затвори прозорец, `Super + F` цял екран |
| `Super + Shift + key` | Приложения | `Super + Shift + B` браузър, `Super + Shift + E` имейл, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панели и системни менюта | `Super + Ctrl + A` аудио, `Super + Ctrl + N` мрежа, `Super + Ctrl + C` меню за заснемане |
| `Super + Ctrl + Alt + key` | Бързи действия и известия | `Super + Ctrl + Alt + T` покажи часа, `Super + Ctrl + Alt + B` батерия, `Super + Ctrl + Alt + C` екранна снимка |

Добавянето на `Alt` към клавишна комбинация ви дава вариант на същото нещо, никога нещо несвързано:

- `Super + Shift + B` отваря браузъра; `Super + Shift + Alt + B` отваря частен прозорец
- `Super + Shift + E` отваря имейла; `Super + Shift + Alt + E` започва нов имейл
- `Super + F` преминава на цял екран; `Super + Alt + F` преминава на пълна ширина
- `Super + Ctrl + C` отваря менюто за заснемане; `Super + Ctrl + Alt + C` пропуска менюто и прави екранна снимка

Когато добавяте клавишна комбинация:

1. Изберете равнината според това какво прави, след това изберете клавиша.
2. Не местете съществуваща клавишна комбинация, за да освободите място. Намерете свободен клавиш на правилната равнина.
3. Използвайте `Alt` само за вариант на комбинацията без него.

Няколко клавишни комбинации нарушават тези правила, защото са удобни. `Shift` със стрелка или `Tab` мести или обръща вместо да отваря приложение, а `Print`, медийните клавиши, `Alt + Tab` и `Ctrl + Alt + Del` работят както навсякъде другаде. Те са изключения, не модели за копиране.

Ако дадена подразбираща се комбинация не ви устройва (например искате `Super + Shift + S` за екранни снимки като в Windows), преназначете я в `~/.config/hypr/bindings.lua`.

## Навигация

| Клавишна комбинация | Функция |
| ----------------------- | --------------------- |
| `Super + Space` | Меню Omarchy (приложения и всичко останало) |
| `Super + Alt + Space` | Мрежа с приложения |
| `Super + Escape` | Системно меню (приспиване, рестартиране и т.н.) |
| `Super + Ctrl + L` | Заключи компютъра |
| `Super + W` or `Super + Q` | Затвори прозорец |

| `Super + J` | Превключи позицията на прозореца (хоризонтална/вертикална) |
| `Super + O` | Превключи преминаването на прозореца в режим лепкав и плаващ |
| `Super + L` | Преминавай циклично през подредбите dwindle, scrolling и floating |
| `Super + Alt + L` | Преминавай циклично през подредбите в обратен ред |
| `Super + P` | Превключи стила на псевдопрозореца (естествен срещу разтегнат) |

| `Super + Ctrl + F` | Премини на цял екран вътре в прозореца |
| `Super + 1/2/3/4` | Отиди на конкретно работно пространство на фокусирания монитор |
| `Super + Tab` | Отиди на следващото работно пространство на фокусирания монитор |
| `Super + Shift + Tab` | Отиди на предишното работно пространство на фокусирания монитор |
| `Super + Ctrl + Tab` | Отиди на предходното работно пространство на фокусирания монитор |
| `Super + Shift + 1/2/3/4` | Премести прозореца на работно пространство на фокусирания монитор |
| `Super + Shift + Alt + 1/2/3/4` | Премести прозореца на работно пространство на фокусирания монитор, без да го следваш |
| `Super + S` | Превключи пълния scratchpad |
| `Super + Alt + S` | Премести прозореца на пълния scratchpad |
| `Super + Grave` | Превключи конзолата Quake |
| `Super + Shift + Grave` | Премести прозореца на конзолата Quake |
| `Super + Shift + Ctrl + Arrows` | Премести прозореца на монитора в тази посока |
| `Super + Shift + Alt + Arrows` | Премести работното пространство на монитора в тази посока |
| `Super + Arrow` | Премести фокуса на прозореца в посоката на стрелката, като преминеш към монитора от тази страна в края на екрана |
| `Super + Shift + Arrow` | Размени прозореца с друг в посоката на стрелката, включително такъв на монитора от тази страна |
| `Super + Minus` | Разшири прозореца наляво |
| `Super + Equal` | Свий прозореца наляво |
| `Super + Shift + Minus` | Свий прозореца нагоре |
| `Super + Shift + Equal` | Разшири прозореца надолу |
| `Super + Alt + Minus/Equal` | Същото преоразмеряване с по-малки стъпки |
| `Super + Ctrl + Minus/Equal` | Същото преоразмеряване с по-големи стъпки |
| `Super + Alt + Home` | Запази ширината на прозореца |
| `Super + Home` | Възстанови запазената ширина на прозореца |
| `Super + Left Mouse` | Влачи прозореца |
| `Super + Right Mouse` | Преоразмерявай прозореца |
| `Super + Scroll Wheel` | Превъртай през работните пространства на фокусирания монитор |
| `Super + G` | Превключи групирането на прозорци |
| `Super + Alt + G` | Извади прозореца от групата |
| `Super + Alt + Tab` | Преминавай циклично през прозорците в групата |
| `Super + Alt + Shift + Tab` | Преминавай циклично назад през прозорците в групата |
| `Super + Alt + Scroll Wheel` | Преминавай циклично през прозорците в групата |
| `Super + Alt + 1/2/3/4/5` | Отиди на конкретен прозорец в групата |
| `Super + Alt + Arrow` | Премести прозореца в група в посоката на стрелката, включително такъв на монитора от тази страна |
| `Super + Ctrl + Left/Right` | Придвижвай се между прозорците в група с плочкова подредба |
| `Super + Ctrl + Z` | Увеличи мащаба на екрана (повтори за още увеличение) |
| `Super + Ctrl + Alt + Z` | Намали напълно мащаба на екрана |
| `Super + /` | Преминавай напред през опциите за мащабиране на монитора |
| `Super + Alt + /` | Преминавай назад през опциите за мащабиране на монитора |
| `Alt + Tab` | Преминавай циклично напред през прозорците на активното работно пространство |
| `Alt + Shift + Tab` | Преминавай циклично назад през прозорците на активното работно пространство |
| `Ctrl + Alt + Tab` | Преминавай циклично фокуса напред през мониторите |
| `Ctrl + Alt + Shift + Tab` | Преминавай циклично фокуса назад през мониторите |

Клавишните комбинации за преоразмеряване използват физическите клавиши `code:20` и `code:21` (XKB `<AE11>` и `<AE12>`), независимо от символите, отпечатани на клавиатурата. На американски клавиатури тези клавиши са `-` и `=`; на японски (JIS) клавиатури са `-` и `^`; на испански клавиатури са `'` и `¡`. На JIS `Super + ^` е `Super + Equal`, докато `Super + Shift + -` (който въвежда `=`) е `Super + Shift + Minus`.

## Универсален клипборд

| Клавишна комбинация | Функция |
| ----------------------- | --------------------- |
| `Super + A` | Избери всичко в приложения, които поддържат `Ctrl + A` |
| `Super + C` | Копирай |
| `Super + X` | Изрежи (не в терминала) |
| `Super + V` | Постави |
| `Super + Ctrl + V` | Мениджър на клипборда |

Обикновено в Linux ви трябва `Ctrl + Shift + C/V`, за да копирате и поставяте в терминала, и `Ctrl + C/V`, за да го правите навсякъде другаде. Тези унифицирани клавишни комбинации за клипборда на Omarchy работят навсякъде.
