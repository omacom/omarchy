# Клавишни комбинации

Можете да видите всички основни клавишни комбинации с `Super + K` (комбинациите за Tmux с `Super + Alt + K`, а комбинациите за Herdr с `Super + Ctrl + K`).

## Как са подредени клавишните комбинации

Всяка клавишна комбинация се намира на една равнина, определена от модификаторите ѝ, и всяка равнина има една задача. Това не позволява комбинациите да се размиват и означава, че обикновено можете да отгатнете къде се намира нещо.

| Равнина | Какво живее там | Примери |
| --- | --- | --- |
| `Super + key` | Системата: прозорци, работни пространства, оформления и основни менюта | `Super + Space` меню Omarchy, `Super + W` затваряне на прозорец, `Super + F` цял екран |
| `Super + Shift + key` | Приложения | `Super + Shift + B` браузър, `Super + Shift + E` имейл, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панели и системни менюта | `Super + Ctrl + A` звук, `Super + Ctrl + N` мрежа, `Super + Ctrl + C` меню за заснемане |
| `Super + Ctrl + Alt + key` | Бързи действия и справки | `Super + Ctrl + Alt + T` показване на часа, `Super + Ctrl + Alt + B` батерия, `Super + Ctrl + Alt + C` екранна снимка |

Добавянето на `Alt` към клавишна комбинация ви дава вариант на същото нещо, никога нещо несвързано:

- `Super + Shift + B` отваря браузъра; `Super + Shift + Alt + B` отваря частен прозорец
- `Super + Shift + E` отваря имейла; `Super + Shift + Alt + E` започва нов
- `Super + F` преминава на цял екран; `Super + Alt + F` преминава на цяла ширина
- `Super + Ctrl + C` отваря менюто за заснемане; `Super + Ctrl + Alt + C` пропуска менюто и прави екранна снимка

Когато добавяте клавишна комбинация:

1. Изберете равнината според това какво прави, след което изберете клавиша.
2. Не местете съществуваща клавишна комбинация, за да освободите място. Намерете свободен клавиш на правилната равнина.
3. Използвайте `Alt` само за вариант на комбинацията без него.

Няколко клавишни комбинации нарушават тези правила, защото са удобни. `Shift` със стрелка или `Tab` премества или обръща посоката, вместо да отваря приложение, а `Print`, медийните клавиши, `Alt + Tab` и `Ctrl + Alt + Del` работят така, както работят навсякъде другаде. Те са изключения, а не модели за копиране.

Ако дадена комбинация по подразбиране не ви устройва (да кажем, искате `Super + Shift + S` за екранни снимки като в Windows), я преназначете в `~/.config/hypr/bindings.lua`.

| `Super + Alt + Shift + Tab` | Преминаване назад между прозорците в групата |
| `Super + Alt + Scroll Wheel` | Преминаване между прозорците в групата |
| `Super + Alt + 1/2/3/4/5` | Скачане до конкретен прозорец в групата |
| `Super + Alt + Arrow` | Преместване на прозореца в група в посоката на стрелката, включително такъв на монитора от тази страна |
| `Super + Ctrl + Left/Right` | Преместване между прозорците в група за подреждане |

| `Super + Ctrl + Alt + Z` | Пълно намаляване от екрана |
| `Super + /` | Стъпка напред през опциите за мащабиране на монитора |
| `Super + Alt + /` | Стъпка назад през опциите за мащабиране на монитора |
| `Alt + Tab` | Преминаване напред през прозорците на активното работно пространство |
| `Alt + Shift + Tab` | Преминаване назад през прозорците на активното работно пространство |
| `Ctrl + Alt + Tab` | Преминаване на фокуса напред през мониторите |
| `Ctrl + Alt + Shift + Tab` | Преминаване на фокуса назад през мониторите |
| `Super + I` | Превключване на езика за въвеждане (при повече от едно оформление или метод за въвеждане) |
| `Super + Shift + I` | Превключване на езика за въвеждане назад |

На тъчпад плъзганията с три и четири пръста превключват работните пространства, местят прозорци и отварят менюто и конзолата Quake; вижте [клавиатура, мишка и тъчпад](34-keyboard-mouse-trackpad.md) за жестовете.

Клавишите за преоразмеряване използват физическите клавиши `code:20` и `code:21` (XKB `<AE11>` и `<AE12>`), независимо от символите, отпечатани на клавиатурата. На американските клавиатури тези клавиши са `-` и `=`; на японските (JIS) клавиатури са `-` и `^`; на испанските клавиатури са `'` и `¡`. При JIS `Super + ^` е `Super + Equal`, докато `Super + Shift + -` (което въвежда `=`) е `Super + Shift + Minus`.

## Универсален клипборд

| Клавишна комбинация | Функция |
| ----------------------- | --------------------- |
| `Super + A` | Избиране на всичко в приложения, които поддържат `Ctrl + A` |
| `Super + C` | Копиране |
| `Super + X` | Изрязване (не в терминала) |
| `Super + V` | Поставяне |
| `Super + Ctrl + V` | Мениджър на клипборда |

Обикновено в Linux ви трябва `Ctrl + Shift + C/V` за копиране и поставяне в терминала и `Ctrl + C/V`, за да го правите навсякъде другаде. Тези унифицирани клавишни комбинации за клипборда в Omarchy работят навсякъде.
