# Бързи клавиши

Можете да видите всички основни клавишни комбинации с `Super + K` (комбинациите за Tmux със `Super + Alt + K`, а за Herdr със `Super + Ctrl + K`).

## Как са подредени бързите клавиши

Всеки бърз клавиш се намира на една равнина, зададена от модификаторите му, и всяка равнина има една задача. Това не позволява бързите клавиши да се смесват и означава, че обикновено можете да отгатнете къде се намира нещо.

| Равнина | Какво се намира там | Примери |
| --- | --- | --- |
| `Super + key` | Системата: прозорци, работни пространства, подредби и основни менюта | `Super + Space` меню Omarchy, `Super + W` затваряне на прозорец, `Super + F` цял екран |
| `Super + Shift + key` | Приложения | `Super + Shift + B` браузър, `Super + Shift + E` имейл, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панели и системни менюта | `Super + Ctrl + A` аудио, `Super + Ctrl + N` мрежа, `Super + Ctrl + C` меню за заснемане |
| `Super + Ctrl + Alt + key` | Бързи действия и известия | `Super + Ctrl + Alt + T` показване на часа, `Super + Ctrl + Alt + B` батерия, `Super + Ctrl + Alt + C` екранна снимка |

Добавянето на `Alt` към бърз клавиш ви дава вариант на същото нещо, никога нещо несвързано:

- `Super + Shift + B` отваря браузъра; `Super + Shift + Alt + B` отваря частен прозорец
- `Super + Shift + E` отваря имейла; `Super + Shift + Alt + E` започва нов
- `Super + F` преминава на цял екран; `Super + Alt + F` преминава на цяла ширина
- `Super + Ctrl + C` отваря менюто за заснемане; `Super + Ctrl + Alt + C` пропуска менюто и прави екранна снимка

Когато добавяте бърз клавиш:

1. Изберете равнината според това какво прави, след това изберете клавиша.
2. Не местете съществуващ бърз клавиш, за да освободите място. Намерете свободен клавиш на правилната равнина.
3. Използвайте `Alt` само за вариант на бързия клавиш без него.

Няколко бързи клавиша нарушават тези правила, защото са удобни. `Shift` със стрелка или `Tab` мести или обръща посоката, вместо да отваря приложение, а `Print`, медийните клавиши, `Alt + Tab` и `Ctrl + Alt + Del` работят така, както навсякъде другаде. Те са изключения, не модели за копиране.

Ако дадена комбинация по подразбиране не ви устройва (да кажем, искате `Super + Shift + S` за екранни снимки като в Windows), преназначете я в `~/.config/hypr/bindings.lua`.

| Бърз клавиш | Функция |
| ----------------------- | --------------------- |
| `Super + Space` | Меню Omarchy (приложения и всичко останало) |
| `Super + Alt + Space` | Решетка с приложения |
| `Super + Escape` | Системно меню (спиране, рестартиране и т.н.) |
| `Super + Ctrl + L` | Заключване на компютъра |
| `Super + W` или `Super + Q` | Затваряне на прозорец |
| `Ctrl + Alt + Del` | Затваряне на всички прозорци |

| `Super + L` | Превъртане през подредбите dwindle, scrolling и floating |
| `Super + Alt + L` | Превъртане през подредбите в обратен ред |
| `Super + P` | Превключване на стила на псевдопрозореца (natural срещу stretch) |

| `Super + Shift + Tab` | Преминаване към предишното работно пространство на фокусирания монитор |
| `Super + Ctrl + Tab` | Преминаване към бившето работно пространство на фокусирания монитор |
| `Super + Shift + 1/2/3/4` | Преместване на прозореца към работно пространство на фокусирания монитор |
| `Super + Shift + Alt + 1/2/3/4` | Преместване на прозореца към работно пространство на фокусирания монитор, без да го следвате |
| `Super + S` | Превключване на пълния scratchpad |
| `Super + Alt + S` | Преместване на прозореца в пълния scratchpad |
| `Super + Grave` | Превключване на конзолата Quake |
| `Super + Shift + Grave` | Преместване на прозореца в конзолата Quake |

| `Super + Shift + Alt + Arrows` | Преместване на работното пространство към монитора в тази посока |
| `Super + Arrow` | Преместване на фокуса към прозореца в посоката на стрелката, с преминаване към монитора от тази страна в края на екрана |
| `Super + Shift + Arrow` | Размяна на прозореца с друг в посоката на стрелката, включително такъв на монитора от тази страна |
| `Super + Minus` | Разширяване на прозореца наляво |
| `Super + Equal` | Свиване на прозореца наляво |
| `Super + Shift + Minus` | Свиване на прозореца нагоре |
| `Super + Shift + Equal` | Разширяване на прозореца надолу |
| `Super + Alt + Minus/Equal` | Същото преоразмеряване на по-малки стъпки |
| `Super + Ctrl + Minus/Equal` | Същото преоразмеряване на по-големи стъпки |
| `Super + Alt + Home` | Запазване на ширината на прозореца |
| `Super + Home` | Възстановяване на запазената ширина на прозореца |
| `Super + Left Mouse` | Влачене на прозореца |
| `Super + Right Mouse` | Преоразмеряване на прозореца |
| `Super + Scroll Wheel` | Превъртане през работните пространства на фокусирания монитор |
| `Super + G` | Превключване на групирането на прозорци |
| `Super + Alt + G` | Изваждане на прозореца от групата |
| `Super + Alt + Tab` | Превъртане между прозорците в група |
| `Super + Alt + Shift + Tab` | Превъртане назад между прозорците в група |
| `Super + Alt + Scroll Wheel` | Превъртане между прозорците в група |
| `Super + Alt + 1/2/3/4/5` | Преминаване към конкретен прозорец в група |
| `Super + Alt + Arrow` | Преместване на прозореца в група в посоката на стрелката, включително такъв на монитора от тази страна |
| `Super + Ctrl + Left/Right` | Преместване между прозорците в група с плочки |
| `Super + Ctrl + Z` | Увеличаване на мащаба на екрана (повторете за още увеличение) |
| `Super + Ctrl + Alt + Z` | Пълно намаляване на мащаба на екрана |
| `Super + /` | Придвижване напред през опциите за мащабиране на монитора |
| `Super + Alt + /` | Придвижване назад през опциите за мащабиране на монитора |
| `Alt + Tab` | Превъртане напред през прозорците на активното работно пространство |
| `Alt + Shift + Tab` | Превъртане назад през прозорците на активното работно пространство |
| `Ctrl + Alt + Tab` | Превъртане на фокуса напред през мониторите |
| `Ctrl + Alt + Shift + Tab` | Превъртане на фокуса назад през мониторите |

Преките пътища за преоразмеряване използват физически клавиши `code:20` и `code:21` (XKB `<AE11>` и `<AE12>`), независимо от знаците, отпечатани на клавиатурата. На американски клавиатури тези клавиши са `-` и `=`; на японски (JIS) клавиатури са `-` и `^`; на испански клавиатури са `'` и `¡`. На JIS, `Super + ^` е `Super + Equal`, докато `Super + Shift + -` (което въвежда `=`) е `Super + Shift + Minus`.
