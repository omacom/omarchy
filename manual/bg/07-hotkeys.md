# Клавишни комбинации

Можете да видите всички основни клавишни комбинации с `Super + K` (комбинациите за Tmux с `Super + Alt + K` и комбинациите за Herdr с `Super + Ctrl + K`).

## Как са подредени клавишните комбинации

Всяка клавишна комбинация се намира на една равнина, зададена от модификаторите ѝ, и всяка равнина има една задача. Това не позволява клавишните комбинации да се сливат една с друга и означава, че обикновено можете да отгатнете къде се намира нещо.

| Равнина | Какво се намира там | Примери |
| --- | --- | --- |
| `Super + key` | Системата: прозорци, работни пространства, оформления и основни менюта | `Super + Space` меню на Omarchy, `Super + W` затваряне на прозорец, `Super + F` цял екран |
| `Super + Shift + key` | Приложения | `Super + Shift + B` браузър, `Super + Shift + E` имейл, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панели и системни менюта | `Super + Ctrl + A` аудио, `Super + Ctrl + N` мрежа, `Super + Ctrl + C` меню за заснемане |
| `Super + Ctrl + Alt + key` | Бързи действия и известия | `Super + Ctrl + Alt + T` показване на часа, `Super + Ctrl + Alt + B` батерия, `Super + Ctrl + Alt + C` екранна снимка |

Добавянето на `Alt` към клавишна комбинация ви дава вариант на същото нещо, никога нещо несвързано:

- `Super + Shift + B` отваря браузъра; `Super + Shift + Alt + B` отваря частен прозорец
- `Super + Shift + E` отваря имейла; `Super + Shift + Alt + E` започва нов
- `Super + F` преминава на цял екран; `Super + Alt + F` преминава на цяла ширина
- `Super + Ctrl + C` отваря менюто за заснемане; `Super + Ctrl + Alt + C` пропуска менюто и прави екранна снимка

Когато добавяте клавишна комбинация:

1. Изберете равнината според това какво прави, след това изберете клавиша.
2. Не местете съществуваща клавишна комбинация, за да освободите място. Намерете свободен клавиш на правилната равнина.
3. Използвайте `Alt` само за вариант на клавишната комбинация без него.

Няколко клавишни комбинации нарушават тези правила, защото са удобни. `Shift` със стрелка или `Tab` мести или обръща посоката, вместо да отваря приложение, а `Print`, медийните клавиши, `Alt + Tab` и `Ctrl + Alt + Del` работят така, както навсякъде другаде. Те са изключения, а не образци за копиране.

Ако някоя по подразбиране не ви устройва (да кажем, че искате `Super + Shift + S` за екранни снимки като в Windows), преназначете я в `~/.config/hypr/bindings.lua`.

| Клавишна комбинация | Функция |
| ----------------------- | --------------------- |
| `Super + Space` | Меню на Omarchy (приложения и всичко останало) |
| `Super + Alt + Space` | Решетка с приложения |
| `Super + Escape` | Системно меню (приспиване, рестартиране и др.) |
| `Super + Ctrl + L` | Заключване на компютъра |
| `Super + W` or `Super + Q` | Затваряне на прозорец |
| `Ctrl + Alt + Del` | Затваряне на всички прозорци |
| `Super + T` | Превключване на прозореца между подреждане/плаващ |
| `Super + J` | Превключване на позицията на прозореца (хоризонтална/вертикална) |
| `Super + O` | Превключване на прозореца в sticky'n'floating |
| `Super + L` | Циклично преминаване през оформленията dwindle, scrolling и floating |
| `Super + Alt + L` | Циклично преминаване през оформленията в обратна посока |
| `Super + P` | Превключване на стила на псевдо прозорец (естествен срещу разтегнат) |
| `Super + F` | Цял екран |
| `Super + Alt + F` | Цяла ширина |
| `Super + Ctrl + F` | Цял екран вътре в прозореца |
| `Super + 1/2/3/4` | Отиване до конкретно работно пространство на фокусирания монитор |
| `Super + Tab` | Отиване до следващото работно пространство на фокусирания монитор |
| `Super + Shift + Tab` | Отиване до предишното работно пространство на фокусирания монитор |
| `Super + Ctrl + Tab` | Отиване до по-ранното работно пространство на фокусирания монитор |
| `Super + Shift + 1/2/3/4` | Преместване на прозорец до работно пространство на фокусирания монитор |
| `Super + Shift + Alt + 1/2/3/4` | Преместване на прозорец до работно пространство на фокусирания монитор без да го следвате |
| `Super + S` | Превключване на пълния scratchpad |
| `Super + Alt + S` | Преместване на прозорец в пълния scratchpad |
| `Super + Grave` | Превключване на конзолата Quake |
| `Super + Shift + Grave` | Преместване на прозорец в конзолата Quake |
| `Super + Shift + Ctrl + Arrows` | Преместване на прозорец към монитора в тази посока |
| `Super + Shift + Alt + Arrows` | Преместване на работно пространство към монитора в тази посока |
| `Super + Arrow` | Преместване на фокуса към прозорец в посоката на стрелката, с преминаване към монитора от тази страна при ръба на екрана |
| `Super + Shift + Arrow` | Размяна на прозорец с друг в посоката на стрелката, включително такъв на монитора от тази страна |
| `Super + Minus` | Разширяване на прозореца наляво |
| `Super + Equal` | Свиване на прозореца наляво |
| `Super + Shift + Minus` | Свиване на прозореца нагоре |
| `Super + Shift + Equal` | Разширяване на прозореца надолу |
| `Super + Alt + Minus/Equal` | Същото преоразмеряване на по-малки стъпки |
| `Super + Ctrl + Minus/Equal` | Същото преоразмеряване на по-големи стъпки |
| `Super + Alt + Home` | Запазване на ширината на прозореца |
| `Super + Home` | Възстановяване на запазената ширина на прозореца |
| `Super + Left Mouse` | Влачене на прозорец |
| `Super + Right Mouse` | Преоразмеряване на прозорец |
| `Super + Scroll Wheel` | Превъртане през работните пространства на фокусирания монитор |
| `Super + G` | Превключване на групирането на прозорци |
| `Super + Alt + G` | Изваждане на прозорец от групирането |
| `Super + Alt + Tab` | Циклично преминаване между прозорците в групирането |
| `Super + Alt + Shift + Tab` | Циклично преминаване назад между прозорците в групирането |
| `Super + Alt + Scroll Wheel` | Циклично преминаване между прозорците в групирането |
| `Super + Alt + 1/2/3/4/5` | Отиване до конкретен прозорец в групирането |
| `Super + Alt + Arrow` | Преместване на прозорец в групирането в посоката на стрелката, включително такъв на монитора от тази страна |
| `Super + Ctrl + Left/Right` | Придвижване между прозорците в група за подреждане |
| `Super + Ctrl + Z` | Увеличаване на мащаба на екрана (повторете за още увеличение) |
| `Super + Ctrl + Alt + Z` | Пълно намаляване на мащаба на екрана |
| `Super + /` | Преминаване напред през опциите за мащабиране на монитора |
| `Super + Alt + /` | Преминаване назад през опциите за мащабиране на монитора |
| `Alt + Tab` | Циклично преминаване напред през прозорците на активното работно пространство |
| `Alt + Shift + Tab` | Циклично преминаване назад през прозорците на активното работно пространство |
| `Ctrl + Alt + Tab` | Циклично преместване на фокуса напред през мониторите |
| `Ctrl + Alt + Shift + Tab` | Циклично преместване на фокуса назад през мониторите |

Клавишните комбинации за преоразмеряване използват физическите клавиши `code:20` и `code:21` (XKB `<AE11>` и `<AE12>`), независимо от символите, отпечатани на клавиатурата. На американски клавиатури тези клавиши са `-` и `=`; на японски (JIS) клавиатури са `-` и `^`; на испански клавиатури са `'` и `¡`. На JIS `Super + ^` е `Super + Equal`, докато `Super + Shift + -` (което въвежда `=`) е `Super + Shift + Minus`.

## Универсален клипборд

| Клавишна комбинация | Функция |
| ----------------------- | --------------------- |
| `Super + A` | Избиране на всичко в приложения, които поддържат `Ctrl + A` |

| `Super + V` | Поставяне |
| `Super + Ctrl + V` | Мениджър на клипборда |

Обикновено в Linux ви трябва `Ctrl + Shift + C/V` за копиране и поставяне в терминала и `Ctrl + C/V`, за да го правите навсякъде другаде. Тези унифицирани клавишни комбинации за клипборда на Omarchy работят навсякъде.
