# Клавишни комбинации

Можете да видите всички основни клавишни комбинации с `Super + K` (комбинациите за Tmux с `Super + Alt + K` и комбинациите за Herdr с `Super + Ctrl + K`).

## Как са подредени клавишните комбинации

Всяка клавишна комбинация се намира на една равнина, определена от модификаторите ѝ, и всяка равнина има една задача. Това не позволява комбинациите да се смесват и означава, че обикновено можете да отгатнете къде се намира нещо.

| Равнина | Какво живее там | Примери |
| --- | --- | --- |
| `Super + key` | Системата: прозорци, работни пространства, оформления и основни менюта | `Super + Space` меню на Omarchy, `Super + W` затваряне на прозорец, `Super + F` цял екран |
| `Super + Shift + key` | Приложения | `Super + Shift + B` браузър, `Super + Shift + E` имейл, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панели и системни менюта | `Super + Ctrl + A` аудио, `Super + Ctrl + N` мрежа, `Super + Ctrl + C` меню за заснемане |
| `Super + Ctrl + Alt + key` | Бързи действия и съобщения | `Super + Ctrl + Alt + T` показване на часа, `Super + Ctrl + Alt + B` батерия, `Super + Ctrl + Alt + C` екранна снимка |

Добавянето на `Alt` към клавишна комбинация ви дава вариант на същото нещо, никога нещо несвързано:

- `Super + Shift + B` отваря браузъра; `Super + Shift + Alt + B` отваря частен прозорец
- `Super + Shift + E` отваря имейла; `Super + Shift + Alt + E` започва нов имейл
- `Super + F` преминава на цял екран; `Super + Alt + F` преминава на цяла ширина
- `Super + Ctrl + C` отваря менюто за заснемане; `Super + Ctrl + Alt + C` пропуска менюто и прави екранна снимка

Когато добавяте клавишна комбинация:

1. Изберете равнината според това какво прави, след това изберете клавиша.
2. Не местете съществуваща клавишна комбинация, за да освободите място. Намерете свободен клавиш на правилната равнина.
3. Използвайте `Alt` само за вариант на комбинацията без него.

Няколко клавишни комбинации нарушават тези правила, защото са удобни. `Shift` със стрелка или `Tab` мести или обръща посоката, вместо да отваря приложение, а `Print`, клавишите за медия, `Alt + Tab` и `Ctrl + Alt + Del` работят така, както навсякъде другаде. Те са изключения, не модели за копиране.

Ако някоя комбинация по подразбиране не ви устройва (например искате `Super + Shift + S` за екранни снимки като в Windows), я преназначете в `~/.config/hypr/bindings.lua`.

| `Super + Alt + Arrow` | Преместване на прозореца в група в посоката на стрелката, включително такава на монитора от тази страна |
| `Super + Ctrl + Left/Right` | Преместване между прозорците в група за подреждане |

| `Super + Alt + /` | Преминаване назад през опциите за мащабиране на монитора |

| `Alt + Shift + Tab` | Циклично преминаване назад през прозорците на активното работно пространство |
| `Ctrl + Alt + Tab` | Циклично преместване на фокуса напред през мониторите |
| `Ctrl + Alt + Shift + Tab` | Циклично преместване на фокуса назад през мониторите |

| `Super + Shift + I` | Връщане към предишния език на въвеждане |

На тъчпад плъзгането с три и четири пръста превключва работни пространства, мести прозорци и отваря менюто и конзолата Quake; вижте [клавиатура, мишка и тъчпад](34-keyboard-mouse-trackpad.md) за жестовете.

Клавишните комбинации за преоразмеряване използват физическите клавиши `code:20` и `code:21` (XKB `<AE11>` и `<AE12>`), независимо от символите, отпечатани на клавиатурата. На американски клавиатури тези клавиши са `-` и `=`; на японски (JIS) клавиатури са `-` и `^`; на испански клавиатури са `'` и `¡`. На JIS `Super + ^` е `Super + Equal`, докато `Super + Shift + -` (който въвежда `=`) е `Super + Shift + Minus`.

## Универсален клипборд

| Клавишна комбинация | Функция |
| ----------------------- | --------------------- |
| `Super + A` | Избиране на всичко в приложения, които поддържат `Ctrl + A` |

| `Super + V` | Поставяне |

Обикновено в Linux ви трябва `Ctrl + Shift + C/V` за копиране и поставяне в терминала и `Ctrl + C/V`, за да го правите навсякъде другаде. Тези унифицирани клавишни комбинации за клипборда на Omarchy работят навсякъде.
