# Чести настройки

Това е колекция от чести приспособления на настройката на Omarchy. Знай, че понякога може да се наложи системните актуализации да възстановят определени конфигурации до първоначалното им състояние. Ако това се случи, промените ти няма да бъдат изгубени, а ще бъдат сложени във файл `.bak` в същата директория.

Ако объркаш нещо, можеш да възстановиш отделни конфигурации до първоначалната им настройка от _Обнови > Конфигурация_ в менюто на Omarchy. Ако _наистина_ объркаш всичко, можеш да нулираш всички конфигурации с `omarchy-reinstall`.

### Показвай всички икони в системната област през цялото време

По подразбиране иконите в системната област, като Dropbox, 1password или Steam, са скрити зад стрелката за разгъване на областта, която ги разкрива, когато задържиш курсора върху нея. Ако искаш да са изложени през цялото време, кликни с десния бутон върху стрелката за разгъване, за да отвориш мениджъра на иконите в системната област, след което закачи иконите, които искаш да останат видими (можеш също да скриеш онези, които никога не искаш да виждаш).

### Заоблени ъгли на прозорците

Дизайнът по подразбиране на Omarchy е с квадратни ъгли, но ако искаш малко да го омекотиш, можеш да промениш `~/.config/hypr/looknfeel.lua`, така че заоблянето вече да не е коментирано:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### Премахване на разстоянията между прозорците

На дисплеи на лаптопи някои хора предпочитат да не хабят никакви пиксели за разстояния между прозорците (или дори за горна лента, която можеш да изключиш с `Super + Shift + Space`). Можеш да изключиш всички разстояния и рамки с `Super + Shift + Backspace` или да ги премахнеш за постоянно, като премахнеш коментарите в този раздел на `~/.config/hypr/looknfeel.lua`:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
