# 导航

Omarchy 里的一切都通过键盘完成——_一切！_ 系统刚启动时，光靠鼠标你真的什么都干不了。但你可以按 `Super + Space` 呼出 Omarchy 菜单，从这里出发，你几乎可以做任何事情。

但 Omarchy 菜单甚至不是设计来在大多数时候作为操作这个系统的主要方式的。我们可以比那更快！所有最重要的应用程序都直接绑定到了单个快捷键上。你用 `Super + Return` 启动终端，用 `Super + Shift + Return` 启动浏览器。试着一个接一个地做，你就会看到 Hyprland 平铺的魔力在发挥作用：

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

然后你可以按 `Super + J` 把它们堆叠在一起，而不是并排排列：

 ![navigation-stacked](images/navigation-stacked.webp)

再按一次 `Super + J`，让它们回到并排的位置。然后在浏览器中试着按 `Super + Shift + Arrow Right` 来交换窗口。

现在试着按 `Super + Shift + T` 启动活动监视器。它会以浮动窗口的形式出现。你可以用 `Super + T` 让它平铺（再按一次则让它重新浮动）。现在按 `Super + Shift + F` 打开文件管理器。你会得到一个整洁的四分布局：

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

你用 `Super + Arrow` 在你想要激活的窗口之间导航。这会切换焦点，并把光标移动到新应用程序的中心。在屏幕边缘时，它会继续移动到那一侧的显示器上。

如果你按 `Super + Shift + 2`，你会把当前聚焦的应用程序移动到第二个工作区。`Super + Shift + 1` 会把它移回来。（而 `Super + Shift + Alt + 2` 会把当前聚焦的应用程序移动到第二个工作区，但不会切换到那个工作区）。

使用多个显示器时，每个显示器都有自己的 1 到 10 号工作区。`Super + 2` 会前往你所在显示器的第二个工作区，每个显示器的顶栏都会显示自己的工作区以及它正在显示的那个工作区。`Super + Tab` 会在你所在显示器的工作区之间循环。`Super + Shift + Ctrl + Arrows` 会把你所在的窗口移动到那个方向的显示器上、移动到它正在显示的工作区上，而 `Super + Shift + Alt + Arrows` 会把你所在的工作区移动到那个方向的显示器上，在那里，如果该编号空闲，它会占据相同的编号。显示器被拔掉时，它会保留自己的工作区：它们会加入另一个屏幕的工作区，编号排在那块屏幕已有的工作区之后，并在显示器回来时恢复到它们原来的编号之下。

如果你按住 `Super` 并用鼠标点击一个窗口，你就能重新安排它的位置。如果你按住 `Super` 并使用鼠标右键，你可以自由地调整窗口大小。

你可以用 `Super + W` 或 `Super + Q` 关闭一个窗口（用 `Ctrl + Alt + Delete` 关闭所有窗口）。

你还可以用 `Super + F` 全屏，甚至可以用 `Super + Alt + F` 仅全宽（保留顶栏），或者用 `Super + Ctrl + F` 在窗口内全屏（非常适合 YouTube！）。

### Dwindle 与滚动布局

Omarchy 的默认布局叫作 dwindle。它让你在一个工作区上打开的所有窗口始终全部可见，即使不得不把它们缩小。

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

但你也可以选择把一个工作区变为滚动布局，在这种布局中，窗口并排排列，延伸到显示器的可见边缘之外。你通过 `Super + L` 把单个工作区变为这种布局。

再次按 `Super + L` 会把工作区变为浮动布局，在浮动布局中窗口自由重叠，由你自己放置它们；第三次按下则让它回到 dwindle。`Super + Alt + L` 会以相反的方向循环它们。一个本来就浮动的窗口——你用 `Super + T` 弹出的窗口，或者一个总是以浮动方式打开的应用——在工作区回到平铺时仍会保持浮动。顶栏会用它的布局标记你所在的工作区：正方形表示 dwindle，圆形表示滚动，三角形表示浮动。点击该标记也会循环切换布局。

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

这个选择是按工作区生效的，而且会保留下来。所以你可以让工作区 1 保持 dwindle 用于浏览，让工作区 2 保持滚动用于写代码，重启之后它们还会以那样的方式回来。

如果你希望把滚动布局用作默认布局，你可以在 `~/.config/hypr/looknfeel.lua` 中这样设置：

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### 浮动工作区

浮动工作区的工作方式就像传统桌面：窗口相互重叠，你自己移动和调整它们的大小。每个窗口都会获得一个采用你主题颜色的标题栏，带有最小化、最大化和关闭按钮。`Super + M` 也会最小化聚焦的窗口。最小化的窗口会在程序坞中等待；点击它的应用即可把它带回来。点击一个窗口即可把它带到前面。从任意边缘或角落调整它的大小。双击标题栏可最大化窗口，同时保持顶栏可见；再双击一次则恢复它原来的大小。Chrome 和其他基于 Chromium 的浏览器、Disks 和 Document Viewer 会跳过标题栏，转而使用它们自己的标题区；`Super + Alt + F` 会最大化它们，`Super + M` 会最小化它们。

浮动工作区还会显示一个程序坞，其中有你固定的应用、所有正在运行的应用，以及 apps 按钮后面的一个包含每个应用的网格，`Super + Alt + Space` 和 Omarchy 菜单中的 _Apps_ 也会打开它。在网格上右键点击一个应用，或按 `Delete`，即可卸载它。点击一个应用即可打开它，或把它的窗口带到前面；再次点击则在其窗口之间循环。中键点击会打开一个新窗口。沿着程序坞拖动一个图标即可移动它；把一个正在运行的应用拖到其他应用中间会让它保留在那里。右键点击即可把一个应用保留在程序坞中、把它从中取出，或退出它。程序坞会为全屏窗口让路。右键点击 apps 按钮，即可把程序坞移动到另一个边缘，或让它隐藏直到指针到达其边缘。该位置也位于 _Appearance > Dock > Dock Position_ 下，`omarchy dock position left` 和 `omarchy dock autohide on` 可以从终端设置这两项。你保留在程序坞中的应用在未运行时会呈淡化显示。

新工作区，以及任何你没有用 `Super + L` 赋予其专属布局的工作区，都会使用默认布局。更改默认布局会把每个没有窗口的工作区重置为该布局，而有窗口的工作区则保留它现有的布局。最小化到程序坞的窗口仍算作它离开的那个工作区上的一个窗口。在 _Appearance > Workspace Layout_ 下挑选它：Tiling、Scrolling 或 Floating。`omarchy-hyprland-workspace-layout-default scrolling` 可以从终端进行设置。

### 窗口分组

窗口可以使用 `Super + G` 进行分组。一旦你进入一个分组，在该分组处于活动状态时，你启动的每个窗口都将属于该分组。你可以使用 `Super + Ctrl + Arrow Left/Right` 在这些分组窗口之间移动，或用 `Super + Alt + 1/2/3/4` 按顺序直接前往分组窗口。

你可以用 `Super + Alt + G` 把一个窗口移出分组，或再次按 `Super + G` 解散整个分组。最后，你可以用 `Super + Alt + Arrows` 把分组之外的窗口移入其中。

### 弹出窗口

你可以用 `Super + O` 把一个窗口弹出其工作区分配。那会把它固定为一个浮动窗口，无论你前往哪个工作区，它都会跟着你。非常适合视频播放器之类的应用。

 ![navigation-popped-window](images/navigation-popped-window.webp)

### 暂存工作区

有一个特殊的大尺寸暂存工作区，它会覆盖在你当前所在的工作区之上。你用 `Super + S` 访问上面的内容，用 `Super + Alt + S` 把窗口放上去。

它非常适合放控件或一个你想快速交互、又不想离开当前工作区的终端。

### Quake 控制台

最后，有一个半高 Quake 控制台，它会从上方垂落，覆盖在你当前所在的工作区之上。用 `Super + Grave` 切换它，用 `Super + Shift + Grave` 把一个窗口放上去。

它打开时，你的默认 agent 已准备就绪，随时可用。当控制台只容纳一个窗口时，它会以居中面板的形式垂落，而不是横贯整个屏幕。在上面放上第二个应用，它就会恢复到全宽度，这样两个应用就有空间并排而坐。

要把一个窗口从暂存工作区或控制台移走，用类似 `Super + Shift + 1` 的方式把它直接发送到另一个工作区。

### 需要花点时间适应！

习惯以这种方式导航你的桌面需要花一点时间，但一旦你习惯了，就很难再回到传统的鼠标驱动的桌面体验了！
