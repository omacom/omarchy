# Omarchy 运行于……

### Apple M1/M2 芯片

[Asahi Alarm](https://asahi-alarm.org/) 是建立在 [Asahi Linux](https://asahilinux.org/) 之上、面向 Apple M1/M2 电脑的 Arch 版本。你可以费点劲让 Omarchy 在其上运行。参见[用户驱动的指南](https://github.com/omarchy-mac/omarchy-mac)。

### Apple 虚拟机

你也可以在 Parallels VM 中安装 Omarchy。过程相当繁琐，但也有一个[用户驱动的指南](https://github.com/omacom/omarchy/discussions/452)。

### VirtualBox

VirtualBox 是一个流行的虚拟机运行器。[你也可以在里面运行 Omarchy](https://github.com/omacom/omarchy/discussions/176)。但性能可能不会太出色。

### Windows 11 上的 VMware Workstation

另一个面向 Windows 的流行虚拟机运行器。[Omarchy 也在里面被设置成功了](https://github.com/omacom/omarchy/discussions/572)。

### Steam Deck

Steam Deck 运行在 Arch 之上，这意味着你可以在你的 Steam Deck 上运行 Omarchy。Altynbek Orumbayev 有[一个完整的设置脚本及说明](https://github.com/aorumbayev/deckarchy)。这有多酷！

### NixOS

Omarchy 本质上是 Arch + Hyprland，但 Henry Sipp 已经[将该设置的本质移植到了 NixOS](https://github.com/henrysipp/omarchy-nix)。所以如果你被 Nix 毒害了，这里是一个很好的起点。它可能跟不上 Omarchy 的最新变化，但不管怎样都很酷！

### 其他东西！

如果你试图将 Omarchy 运行在非默认配置上，你应该加入[我们社区 Discord](https://discord.gg/tXFUdasqhY) 中的 #omarchy-on-other 频道。
