# 硬件身份验证

### 指纹身份验证

许多笔记本电脑都配有指纹传感器，用于进行身份验证。您可以通过在 Omarchy 菜单（`Super + Space`）中运行 _Setup > Security > Fingerprint_，在 Omarchy 中使用这一功能。

这会打开一个全屏指纹图案，当您触摸传感器时，它会逐渐填满。在后台，Omarchy 会安装指纹软件包，采集您的指纹并进行验证，随后您就可以使用指纹从锁屏界面解锁（您可以使用 `Super + Ctrl + L` 触发锁屏）、进入 sudo 模式，以及授权系统提示。

一旦锁屏界面关闭了显示屏，传感器就会休眠以节省电量，因此在触摸它之前，请先使用任意按键或触摸板唤醒屏幕。

当笔记本电脑的盖子合上时，指纹提示会自动跳过，因此您会直接进入密码提示，而不必等待一个您够不到的传感器。如果您需要在没有传感器的外接键盘上工作，只需在 `sudo` 期间提示您进行指纹验证时按下 `CTRL + C`。

您可以在 Omarchy 菜单中的 _Remove > Security > Fingerprint_ 下移除指纹身份验证。

### Fido2 身份验证

如果您使用的是 Fido2 设备，您可以使用 Omarchy 菜单（`Super + Space`）中的 _Setup > Security > Fido2_，将其设置为 `sudo` 身份验证。不过，它涵盖 `sudo` 和系统授权提示，不包括解锁您的计算机。

您可以在 Omarchy 菜单中的 _Remove > Security > Fido2_ 下移除 fido2 身份验证。
