# 顶部栏

屏幕顶部那条横条就是 Omarchy 栏。它不是外挂上去的状态栏，而是 Omarchy shell 的一部分；这个长期运行的单一 Quickshell 进程还负责绘制菜单、通知、OSD 弹出窗口和锁屏。正因如此，它能与所有其他部分完美统一主题，面板也能立即打开，而不是再启动一个新应用。

它也是桌面上唯一始终显示在屏幕上的部分，所以值得弄清楚那些小图标都管什么。

## 默认显示内容

该栏分为三个区域。左侧是 Omarchy 标志（菜单启动器）和工作区指示器。中间是状态指示器、时钟、Elsewhen（世界时钟）、天气和 Omarchy 更新徽章。右侧是：系统托盘、键盘布局（配置了多个布局或输入法时）、智能体、蓝牙、网络、音频、显示和电源。

其中有几项只在有话要说时才出现。键盘布局仅当你配置了多个布局或输入法时才显示。更新徽章仅当有 Omarchy 更新在等待时才显示。

## 到处点一点

几乎每个小部件都对左键、右键和中键点击有所响应，还有几个响应滚动。这正是人们容易错过的部分——很多好东西都藏在右键和中键里。

| 小部件 | 左键 | 右键 | 中键 / 滚动 |

| 菜单 | Omarchy 菜单 | 新建终端 | — |
| 工作区 | 在此显示器上聚焦该工作区 | — | 滚动：下一个/上一个工作区 |
| 时钟 | 日历弹出窗口 | 循环切换标签格式 | 中键：时区选择器 |
| 世界时钟 | 世界时钟面板 | 刷新 | 中键：刷新 |
| 天气 | 天气预报弹出窗口 | 以通知形式显示完整天气 | 中键：刷新 |
| 音频 | 音频面板 | 静音 | 中键：面板 · 滚动：音量 |
| 麦克风 | 静音麦克风 | — | 中键：音频面板 · 滚动：输入音量 |

那张表里的内容并非全都开箱即用地在你的栏上。媒体小部件（MPRIS 正在播放，带滚动显示的曲目和艺人）和麦克风小部件都是内置的，但默认关闭——想要的话就按下面的说明把它们加上。

## 面板

点击栏上的图标会打开一个面板，这是一个正经的弹出窗口，带滑块、列表和键盘导航，而不是一个工具提示。每个面板也都有快捷键，所以你永远不用去瞄准一个 16 像素的小图标：

| 快捷键 | 面板 |
| --- | --- |
| `Super + Ctrl + A` | 音频 |
| `Super + Ctrl + N` | 网络 |
| `Super + Ctrl + B` | 蓝牙 |
| `Super + Ctrl + D` | 显示 |
| `Super + Ctrl + P` | 电源 |
| `Super + Ctrl + Alt + D` | 日历 |
| `Super + Ctrl + Alt + E` | 世界时钟 |
| `Super + Ctrl + X` | 智能体 |
| `Super + Ctrl + 1-9` | 切换右侧区域的第 n 个面板 |

这些面板不是只读的显示。它们是真正让你动手做事的地方：

- **音频**带主音量滑块、输出设备选择器和按应用划分的混音器，所以你可以只调低那一个浏览器标签页的音量，而不影响其他所有声音。
- **网络**会扫描 Wi-Fi、显示信号强度、进行连接，还让你选择 DNS 提供商。
- **蓝牙**会列出你的设备，带连接/断开操作和电池电量。
- **电源**会显示电池统计、切换电源模式（它会为电池和 AC 分别记住不同的选择），并打印一些系统信息。
- **显示**带亮度滑块、文字大小、显示器缩放预设，而且——当你有多个屏幕时——还有按显示器划分的控制。更深入的内容见[显示器](33-monitors.md)。
- **时钟**会打开带 ISO 周数和月份切换的月度网格。
- **世界时钟**为每个城市保留一行，带其天气和当天进展情况。搜索既能找到城镇，也能找到时区，所以 Fort Lauderdale 就是 Fort Lauderdale，而不是 New York。如果顶部的那一行写错了城市，点击它并告诉它你在哪儿；选一个其他时区的地方，系统时钟也会随之移到那里，旅行时很方便。把鼠标悬停在一个城市上，点击人物按钮，告诉它谁住在那里——可以用普通名字，也可以用 `@` GitHub 账号，这样还能把他们的头像一并带过来。

每个面板都既支持键盘，也支持鼠标：方向键移动，Return 激活，Tab 移到相邻面板，Escape 关闭。

`Super + Ctrl + 1-9` 按从左到右的顺序计算右侧区域的面板，会跳过托盘，因为它没有自己的面板。所以数字与你会指向的图标是一致的。

### Tailscale 和 Dropbox

还有两个小部件只有当你从**安装 → 服务**安装了对应的服务后才会出现在栏上，而且两者都值得了解一下，因为它们不只是报告状态。

**Tailscale** 面板可以连接和断开 tailnet、在账号之间切换，并选择一个出口节点（你自己的机器和 Mullvad 地区都会出现在那个列表里）。它还能浏览你的机器——选中一台后，按 `s` 就能通过 Taildrop 把文件发送给它，这是把文件传到你的手机或另一台笔记本电脑最快的方法。`c` 复制该机器的 IP，`n` 复制其名称，`d` 复制其完整 DNS 名称。每台机器的那一行上也有一个发送按钮，如果你更喜欢点击的话。从终端做同样的事是 `omarchy tailscale send <machine> [file...]`。

**Dropbox** 面板处理登录、显示你已用掉多少存储空间，并列出最近同步的文件。

移除任一服务都会把其小部件从栏上撤下来。

## 指示器

中间那一小簇就是指示器小部件。这些是为你已开启的模式显示的状态图标：勿扰、夜灯、已排队的[提醒](09-reminders.md)、正在进行的屏幕录制和保持唤醒，此外在无密码 sudo 开启时或有人连接到远程会话时还会显示警告。模式激活时它们会亮起，其余时候则乖乖让开——把鼠标悬停在它们旁边、也就是未激活的那些本该待着的地方，就能偷看一下那些未激活的。点击一个指示器会切换那个模式。还有一个仅用于显示状态：有人通过 gliff 连接到这台机器时，远程会话会亮起红色。

如果你宁愿它们始终可见，就把该小部件上的 `alwaysShow` 设为 `true`。如果你只关心其中几个，就在 `items` 里列出你想要的：`["Dnd", "Reminder", "NightLight"]`。你可以有不止一个指示器小部件，所以不同的区域可以显示不同的子集。

## 重新排列栏

这个栏会自己配置自己。你不用为了移动东西而打开配置文件。

抓住栏中间附近的一块空地，把它拖向另一个屏幕边缘，栏就会移过去——左、右、上、下都行，每个小部件都会适应（竖直栏会回退为紧凑的仅图标形式）。点击并按住也会开始同样的拖动。双击同一块空地，会让栏背景在透明、玻璃质感和不透明之间循环切换。再把任意小部件拖动，就能重新排列它，或者把它扔进另一个区域；其他小部件会滑开，在它将要落下的地方腾出空间。

栏的中间是一个盒子：里面的一切都作为一个整体保持居中，而它两侧的小部件则挂在它的边缘上。当你拖动一个小部件时，这个盒子会显示为轮廓，或者当它为空时显示为横贯栏的一条线，你可以把它放进盒子里，也可以放在它旁边。当一次放置会落进盒子时，盒子会变大，把小部件收进来。

某个你想让它留在手边、但不想让它始终可见的小部件，可以放进托盘的抽屉里：把它拖到托盘上，抽屉就会打开把它收进去。它会排在应用图标之后待在那里，每当抽屉出现时它也会出现，而且在它的面板打开期间会让抽屉保持打开。把它拖回栏上就能放回去。

如果你更愿意从菜单里选，**外观 → 菜单栏**里有位置设置，**栏背景**则决定栏如何绘制：**不透明栏**、**玻璃质感栏**（半透明，背后的内容会被模糊），或**透明栏**。

同样的事情也有命令，这正是做 [dotfiles](31-dotfiles.md) 配置时你想要的方式：

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

要彻底添加或移除一个小部件，就用插件命令。`omarchy plugin list` 会打印 shell 所知道的每一个小部件及其 id，然后：

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## 隐藏栏

`Super + Shift + Space` 可以把栏关掉再打开，而不用杀掉 shell——面板和快捷键仍能工作，你只是把像素拿了回来。菜单里的**外观 → 菜单栏 → 隐藏栏**下也有这个选项。

## 配置文件

这一切都存储在 `~/.config/omarchy/shell.json` 的 `bar` 键下。这是一个精简版：

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

每个小部件都是五个布局数组之一中的一个条目，其设置就内联在那个条目上——没有单独的设置文件，也没有 `config` 子对象。时钟的 `format`、`formatAlt`（右键点击会循环切换到的格式）和 `verticalFormat` 全都直接放在 `{ "id": "omarchy.clock" }` 上。

`center` 是栏中间的那个盒子：里面的一切都作为一个整体在屏幕上居中。`centerBegin` 和 `centerEnd` 挂在盒子的两侧，这正是时钟能保持正中、而天气和更新徽章来来去去也不会影响它的原因。把不止一个小部件放进 `center`，它们会一起居中；让它空着，`centerBegin` 和 `centerEnd` 就会在栏的中间相遇。

有一条规则值得记牢：**一旦你有了自己的 `shell.json`，它就是权威的**。在你自定义任何东西之前，shell 读取的是 Omarchy 的默认文件。从你拖动一个小部件、运行 `omarchy bar`，或者亲自编辑文件的那一刻起，它就归你了——不存在深度合并，所以未来 Omarchy 版本中的新默认小部件不会自动出现在你的栏上。`omarchy bar defaults` 可以在你想要一张白纸时把出厂布局放回来。

同一个文件还在顶层、`bar` 键之外保存了你的空闲计时：`idle.screensaver` 和 `idle.lock`，两者都是自你进入空闲以来的秒数。所以默认的屏幕保护程序在 150 秒时启动，锁屏在 300 秒时启动。
