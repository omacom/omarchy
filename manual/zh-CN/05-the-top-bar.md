# 顶部栏

屏幕顶部那条横条就是 Omarchy 栏。它不是外挂上去的状态栏，而是 Omarchy shell 的一部分；这个长期运行的单一 Quickshell 进程还同时绘制菜单、通知、OSD 弹窗和锁屏。这就是为什么它能与所有其他部分完美统一主题，也是为什么面板能瞬间打开，而不是启动一个新应用。

它也是桌面上唯一始终显示在屏幕上的部分，所以值得了解一下那些小图标都做什么。

## 默认有哪些内容

该栏分为三个区域。左侧是 Omarchy 标志（菜单启动器）和工作区指示器。中间是状态指示器、时钟、Elsewhen（世界时钟）、天气和 Omarchy 更新徽章。右侧是：系统托盘、键盘布局（配置了多个布局时）、agents、蓝牙、网络、音频、显示和电源。

其中有几个只在有内容要显示时才会出现。键盘布局仅在你配置了多个布局时出现。更新徽章仅在有 Omarchy 更新等待时出现。agents 图标则在 Omarchy 首次在机器上发现 AI 编程用量时出现（见 [AI](17-ai.md)）。

## 点击操作

几乎每个控件都支持左键、右键和中键点击，还有几个支持滚动。这正是人们容易错过的部分——很多好东西都藏在右键和中键里。

| 控件 | 左键 | 右键 | 中键 / 滚动 |
| --- | --- | --- | --- |
| 菜单 | Omarchy 菜单 | 新终端 | — |
| 工作区 | 在此显示器上聚焦该工作区 | — | 滚动：下一个/上一个工作区 |
| 时钟 | 日历弹窗 | 循环切换标签格式 | 中键：时区选择器 |
| 天气 | 天气预报弹窗 | 以通知形式显示完整天气 | 中键：刷新 |
| 音频 | 音频面板 | 静音 | 中键：面板 · 滚动：音量 |
| 麦克风 | 麦克风静音 | — | 中键：音频面板 · 滚动：输入音量 |
| 网络 | 网络面板 | — | — |
| Bluetooth | Bluetooth 面板 | 开关无线电 | — |
| 显示 | 显示面板 | — | 滚动：亮度 |
| 电源 | 电源面板 | 开关电池百分比 | — |
| 媒体 | 播放/暂停 | 封面弹窗 | 中键：下一曲 · 滚动：上一曲/下一曲 |
| Agents | Agents 面板 | 启动你的 agent | 中键：下一个订阅 |
| 托盘 | 悬停以显示抽屉 | 在 chevron 上右键以管理 | — |
| Omarchy 更新 | 运行更新 | — | — |

表中并非所有东西都开箱即用地出现在你的栏上。媒体控件（MPRIS 正在播放，带滚动的曲目和艺术家）和麦克风控件都是内置的，但默认关闭——想要的话按下面所述添加它们。

## 面板

点击栏图标会打开一个面板，它是一个真正的弹窗，带滑块、列表和键盘导航，而不是一个提示框。每个面板也都有快捷键，所以你永远不用去瞄准一个 16 像素的小图标：

| 快捷键 | 面板 |
| --- | --- |
| `Super + Ctrl + A` | 音频 |
| `Super + Ctrl + N` | 网络 |
| `Super + Ctrl + B` | 蓝牙 |
| `Super + Ctrl + D` | 显示 |
| `Super + Ctrl + P` | 电源 |
| `Super + Ctrl + Alt + D` | 日历 |
| `Super + Ctrl + Alt + E` | 世界时钟 |
| `Super + Ctrl + 1-9` | 切换右侧区域的第 n 个面板 |

面板不是只读的显示。它们是你真正做事情的地方：

- **音频**有主音量滑块、输出设备选择器和按应用划分的混音器，所以你可以调低那一个浏览器标签页的声音，而不影响其他所有内容。
- **网络**会扫描 Wi-Fi、显示信号强度、连接，并让你选择 DNS 提供商。
- **蓝牙**会列出你的设备，显示连接/断开状态和电量。
- **电源**显示电池统计信息、切换电源模式（它会分别记住电池和 AC 下的选择），并打印一些系统信息。
- **显示**带有亮度滑块、文字大小、显示器缩放预设，并且——当你有多个屏幕时——每个显示器的控制项。更深入的内容见[显示器](33-monitors.md)。
- **时钟**会打开一个月网格，带 ISO 周数和月份步进。
- **世界时钟**为每个城市保留一行，显示其天气和当天进展。搜索不仅能找到时区，也能找到城镇，所以 Fort Lauderdale 就是 Fort Lauderdale，而不是 New York。如果顶部的那一行显示了错误的城市，点击它并说明你在哪里；选择另一个时区的地方，系统时钟也会随之移动，旅行时很方便。将鼠标悬停在某个城市上，点击人物按钮来说明谁住在那里——可以使用普通姓名，或者使用 `@` GitHub 账号，这样他们的头像也会一起带来。

每个面板都同时支持键盘和鼠标：方向键移动，Return 激活，Tab 切换到相邻面板，Escape 关闭。

`Super + Ctrl + 1-9` 按从左到右的顺序计算右侧区域的面板，托盘除外，因为它没有自己的面板。所以数字会与你指的图标对应。

### Tailscale 和 Dropbox

还有两个控件只有在你从 **Install → Service** 安装对应服务后才会出现在栏上，而且两者都值得了解，因为它们不只是报告状态。

**Tailscale** 面板可以连接和断开 tailnet、切换账号，并选择出口节点（你自己的机器和 Mullvad 区域都会出现在该列表中）。它还可以浏览你的机器——选中一台后，按 `s` 可以通过 Taildrop 向它发送文件，这是把文件移动到手机或另一台笔记本电脑最快的方式。`c` 复制机器的 IP，`n` 复制其名称，`d` 复制其完整 DNS 名称。每行机器上也有一个发送按钮，如果你更喜欢点击的话。从终端执行同样的操作是 `omarchy tailscale send <machine> [file...]`。

**Dropbox** 面板处理登录、显示你已使用的存储空间，并列出最近同步的文件。

移除任一服务都会把它的控件从栏上拿掉。

## 指示器

中间那一小簇就是指示器控件。这些是表示你已打开的模式的状态图标：勿扰、夜灯、排队的[提醒](09-reminders.md)、正在进行的屏幕录制、保持唤醒和[听写](11-text-extraction-dictation.md)。它们在模式激活时亮起，其他时候则不挡路——将鼠标悬停在它们旁边，也就是未激活指示器本来会待的位置，就能偷看一下那些指示器。点击指示器会切换该模式。还有一个仅显示状态：当有人通过 gliff 连接到这台机器时，远程会话会亮起红色。

如果你希望它们始终可见，将控件上的 `alwaysShow` 设置为 `true`。如果你只关心其中某几个，把你想要的列在 `items` 中：`["Dnd", "Reminder", "NightLight"]`。你可以拥有多个指示器控件，所以不同区域可以显示不同的子集。

## 重新排列顶部栏

该栏会自我配置。你不必打开配置文件就能移动东西。

抓住中间附近栏上的一块空白区域，将它拖向另一个屏幕边缘，栏就会移动到那里——左、右、上、下都可以，每个控件都会自适应（垂直栏会回退为紧凑的仅图标形式）。点击并按住也会启动同样的拖动。在同一块空白区域双击左键，可以循环切换栏背景：从透明到玻璃质感到不透明。拖动任何控件即可重新排序，或者把它扔进另一个区域；其他控件会滑动分开，为它将落下的位置腾出空间。

栏的中间是一个盒子：里面的任何东西都作为一个组保持居中，它两侧的控件则悬挂在它的边缘。当你拖动控件时，盒子会显示为轮廓，或者当它为空时显示为一条横贯栏的线，你可以放入其中或放在它旁边。当拖放会落到盒子里时，盒子会变大以接纳该控件。

某个你想保留但不想总是看到的控件可以放进托盘的抽屉里：将它拖到托盘上，抽屉会打开接纳它。它会位于应用图标之后，每当抽屉出现时它也会出现，并且在其面板打开时保持抽屉打开。将它拖回栏上即可放回去。

如果你更喜欢从菜单中选择，**Appearance → Menu Bar** 中有位置选项，而 **Bar Background** 决定栏的绘制方式：**Opaque Bar**、**Glassy Bar**（半透明，后面的内容会模糊）或 **Clear Bar**。

同样的事情也有命令，这正是你为 [dotfiles](31-dotfiles.md) 设置所需要的：

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

要完全添加或移除一个控件，使用插件命令。`omarchy plugin list` 会打印 shell 知道的每个控件及其 id，然后：

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## 隐藏顶部栏

`Super + Shift + Space` 可以在不杀死 shell 的情况下关闭并重新打开该栏——面板和快捷键继续工作，你只是拿回了那些像素。它也在菜单的 **Appearance → Menu Bar → Hide Bar** 中。

## 配置文件

所有这些都存储在 `~/.config/omarchy/shell.json` 的 `bar` 键下。这是一个精简版：

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

每个控件都是五个布局数组之一中的一项，其设置就内联在该项上——没有单独的设置文件，也没有 `config` 子对象。时钟的 `format`、`formatAlt`（右键循环切换到的格式）和 `verticalFormat` 都直接位于 `{ "id": "omarchy.clock" }` 上。

`center` 是栏中间的盒子：其中所有内容作为一个组在屏幕上居中。`centerBegin` 和 `centerEnd` 悬挂在盒子的两侧，这就是为什么即使天气和更新徽章来来去去，时钟仍保持正中。在 `center` 中放多个控件，它们会一起居中；将其留空，`centerBegin` 和 `centerEnd` 会在栏的中间相遇。

有一条规则值得牢记：**一旦你有了自己的 `shell.json`，它就是权威的**。在你定制任何东西之前，shell 会读取 Omarchy 的默认文件。一旦你拖动控件、运行 `omarchy bar`，或者自己编辑文件，它就归你所有了——没有深度合并，所以未来 Omarchy 版本中的新默认控件不会自动出现在你的栏上。`omarchy bar defaults` 可以在你想要全新开始时随时把出厂布局放回来。

同一个文件还在顶层、`bar` 键之保存了你的空闲时间设置：`idle.screensaver` 和 `idle.lock`，两者都是自你进入空闲以来经过的秒数。所以默认屏幕保护程序会在 150 秒时启动，锁屏会在 300 秒时启动。
