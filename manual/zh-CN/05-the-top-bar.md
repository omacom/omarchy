# 顶栏

屏幕顶部那条就是 Omarchy 栏。它不是外挂上去的状态栏，而是 Omarchy shell 的一部分；这个长期运行的单个 Quickshell 进程还负责绘制菜单、通知、OSD 弹窗和锁屏。这就是它能与所有其他部分完美统一主题、面板也能瞬间打开而无需启动新应用的原因。

它也是桌面上唯一始终显示在屏幕上的部分，所以值得了解一下那些小图标都做些什么。

## 默认有哪些

栏分为三个区域。左侧是 Omarchy 标志（菜单启动器）和工作区指示器。中间是状态指示器、时钟、Elsewhen（世界时钟）、天气和 Omarchy 更新徽章。右侧依次是：系统托盘、键盘布局（配置了多个布局时）、agents、蓝牙、网络、音频、显示和电源。

其中几个只在有事要说时才出现。键盘布局仅在你配置了多个布局时出现。更新徽章仅在有 Omarchy 更新等待安装时出现。agents 图标则在 Omarchy 首次在机器上发现 AI 编程用量时出现（见 [AI](17-ai.md)）。

## 到处点一点

几乎每个小部件都支持左键、右键和中键点击，还有几个响应滚动。这正是很多人会错过的部分——好东西大多藏在右键和中键里。

| 小部件 | 左键 | 右键 | 中键 / 滚动 |
| --- | --- | --- | --- |
| 菜单 | Omarchy 菜单 | 新终端 | — |
| 工作区 | 在此显示器上聚焦该工作区 | — | 滚动：上一个/下一个工作区 |
| 时钟 | 日历弹窗 | 循环切换标签格式 | 中键：时区选择器 |
| 天气 | 天气预报弹窗 | 以通知形式显示完整天气 | 中键：刷新 |
| 音频 | 音频面板 | 静音 | 中键：面板 · 滚动：音量 |
| 麦克风 | 将麦克风静音 | — | 中键：音频面板 · 滚动：输入音量 |
| 网络 | 网络面板 | — | — |
| 蓝牙 | 蓝牙面板 | 开关无线电 | — |
| 显示 | 显示面板 | — | 滚动：亮度 |
| 电源 | 电源面板 | 切换电池百分比显示 | — |
| 媒体 | 播放/暂停 | 封面弹窗 | 中键：下一曲 · 滚动：上一曲/下一曲 |
| Agents | Agents 面板 | 启动你的 agent | 中键：下一个订阅 |
| 托盘 | 悬停以展开抽屉 | 在箭头图标上点右键进行管理 | — |
| Omarchy 更新 | 运行更新 | — | — |

那张表里的内容并非全都开箱即用地出现在你的栏上。媒体小部件（MPRIS 正在播放，带滚动显示的曲目和艺人）和麦克风小部件都已内置，但默认关闭——想要的话按下面的说明添加即可。

## 面板

点击栏上的图标会打开一个面板，它是带滑块、列表和键盘导航的正式弹窗，而不是工具提示。每个面板也都有快捷键，所以你永远不用去瞄准一个 16 像素的小图标：

| 快捷键 | 面板 |
| --- | --- |
| `Super + Ctrl + A` | 音频 |
| `Super + Ctrl + N` | 网络 |
| `Super + Ctrl + B` | 蓝牙 |
| `Super + Ctrl + D` | 显示 |
| `Super + Ctrl + P` | 电源 |
| `Super + Ctrl + Alt + D` | 日历 |
| `Super + Ctrl + Alt + E` | 世界时钟 |
| `Super + Ctrl + 1-9` | 切换右侧区域的第 n 个面板 |

面板不是只读的展示。它们是真正让你做事的地方：

- **音频**带主音量滑块、输出设备选择器和按应用划分的混音器，所以你可以只调低某一个浏览器标签页的声音，而不影响其他一切。
- **网络**会扫描 Wi-Fi、显示信号强度、进行连接，还让你选择 DNS 提供商。
- **蓝牙**列出你的设备，并显示连接/断开状态和电池电量。
- **电源**显示电池统计信息，切换电源模式（它会为电池和交流电分别记住你的选择），并打印一些系统信息。
- **显示**带亮度滑块、文字大小、显示器缩放预设，而且——当你有多个屏幕时——还有按显示器划分的控制项。更深入的内容见[显示器](33-monitors.md)。
- **时钟**打开一个带 ISO 周数和月份步进的月度网格。
- **世界时钟**为每个城市保留一行，显示其天气和当天进展如何。搜索既能找到城镇，也能找到时区，所以 Fort Lauderdale 就是 Fort Lauderdale，而不是 New York。如果顶部那一行写错了城市，点击它并说明你在哪里；选择另一个时区的地方，系统时钟也会随之移过去，旅行时非常方便。将鼠标悬停在某个城市上，点击人物按钮，说明谁住在那里——可以用普通姓名，也可以用 `@` GitHub 用户名，把他们的头像一并带过来。

每个面板都既支持键盘也支持鼠标：方向键移动，Return 激活，Tab 跳到相邻面板，Escape 关闭。

`Super + Ctrl + 1-9` 按从左到右的顺序计算右侧区域的面板，并跳过托盘，因为托盘没有自己的面板。所以数字与你会指向的图标正好对应。

### Tailscale 和 Dropbox

还有两个小部件只有在你从 **Install → Service** 安装对应服务后才会出现在栏上，而且两者都值得了解，因为它们不只是报告状态。

**Tailscale** 面板可以连接和断开 tailnet、在账户之间切换，并选择一个出口节点（你自己的机器和 Mullvad 地区都会出现在那个列表里）。它还能浏览你的机器——选中一台后，按 `s` 就能通过 Taildrop 向它发送文件，这是把文件传到手机或另一台笔记本电脑最快的方法。`c` 复制该机器的 IP，`n` 复制其名称，`d` 复制其完整 DNS 名称。每行机器上也有一个发送按钮，如果你更喜欢点击的话。从终端做同样的事是 `omarchy tailscale send <machine> [file...]`。

**Dropbox** 面板处理登录、显示你已用了多少存储空间，并列出最近同步的文件。

移除任一服务，其小部件都会从栏上消失。

## 指示器

中间那一小簇就是指示器小部件。这些是表示你已开启的各种模式的状态图标：勿扰、夜间模式、排队的[提醒](09-reminders.md)、正在进行的屏幕录制、保持唤醒，以及[听写](11-text-extraction-dictation.md)。模式激活时它们会亮起，否则就乖乖待在一边——将鼠标悬停在栏的任意位置，就能瞥见那些未激活的。点击某个指示器会切换该模式。还有一个仅用于显示状态：当有人通过 gliff 远程连接到这台机器时，远程会话会亮起红色。

如果你希望它们始终可见，把该小部件上的 `alwaysShow` 设为 `true`。如果你只关心其中几个，把想要的列在 `items` 里：`["Dnd", "Reminder", "NightLight"]`。你可以放不止一个指示器小部件，所以不同区域可以显示不同的子集。

## 重新排列栏

栏会自己配置自己。你不必打开配置文件就能移动东西。

抓住栏中央附近的一块空白区域，把它拖向另一条屏幕边缘，栏就会移到那里——左、右、上、下都可以，每个小部件都会随之适应（竖直栏会退回紧凑的仅图标形式）。点击并按住也会开始同样的拖动。在同一块空白区域双击左键，可以让栏背景在透明、玻璃质感和不透明之间循环切换。还可以拖动任何小部件来重新排序，或把它扔进另一个区域；其他小部件会滑开，为它腾出将要落下的位置。

栏的中间是一个盒子：里面的内容作为一个整体保持居中，它两侧的小部件则挂在它的边缘。拖动小部件时，盒子会显示为轮廓，空的时候则是一条横贯栏的线，你可以把小部件放进盒子里，也可以放在它旁边。当一次放置会落入盒子时，盒子会变大以接纳该小部件。

某个你想保留但不想总是看到的小部件可以放进托盘的抽屉：把它拖到托盘上，抽屉会打开接纳它。它会排在应用图标之后待在那里，每当抽屉出现时它也会出现，而且在它的面板打开期间会保持抽屉开启。把它拖回栏上即可放回去。

如果你更喜欢从菜单里选，**外观 → 菜单栏**里有位置选项，**栏背景**决定栏的绘制方式：**不透明栏**、**玻璃质感栏**（半透明，背后的内容会被模糊）或**透明栏**。

同样的事情也有命令，这正是 [dotfiles](31-dotfiles.md) 配置想要的方式：

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

要彻底添加或移除一个小部件，用插件命令。`omarchy plugin list` 会打印 shell 所知道的每个小部件及其 id，然后：

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## 隐藏栏

`Super + Shift + Space` 可以在不杀死 shell 的情况下把栏关掉再打开——面板和快捷键仍然可用，你只是把那些像素拿了回来。它也在菜单的 **外观 → 菜单栏 → 隐藏栏** 下。

## 配置文件

所有这些都存储在 `~/.config/omarchy/shell.json` 中，位于 `bar` 键下。这是一个精简后的版本：

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

每个小部件都是五个布局数组之一中的一个条目，它的设置就内联在该条目上——没有单独的设置文件，也没有 `config` 子对象。时钟的 `format`、`formatAlt`（右键循环切换到的格式）和 `verticalFormat` 全都直接位于 `{ "id": "omarchy.clock" }` 上。

`center` 就是栏中间的那个盒子：里面的所有内容作为一个整体在屏幕上居中。`centerBegin` 和 `centerEnd` 挂在盒子的两侧，这就是为什么天气和更新徽章来来去去时，时钟仍能保持正中央。把多个小部件放进 `center`，它们会一起居中；把它留空，`centerBegin` 和 `centerEnd` 就会在栏的中间相遇。

有一条规则值得牢记：**一旦你有了自己的 `shell.json`，它就是权威的**。在你自定义任何东西之前，shell 读取的是 Omarchy 的默认文件。从你拖动小部件、运行 `omarchy bar` 或自己编辑文件的那一刻起，它就归你所有了——不会有深度合并，所以未来 Omarchy 版本中的新默认小部件不会自动出现在你的栏上。每当你想要一块干净的白板时，`omarchy bar defaults` 都会把出厂布局恢复回来。

同一个文件还在顶层、`bar` 键之外保存了你的空闲计时：`idle.screensaver` 和 `idle.lock`，两者都是自你进入空闲状态起的秒数。所以默认的屏幕保护程序在 150 秒时启动，锁定在 300 秒时启动。
