# 截图与录屏

你能从屏幕上抓取的一切都离不开 Print Screen 键。单独按这个键可以拍照，配合修饰键可以录屏、取色，或提取区域内的文本。如果你的键盘根本没有 Print Screen 键，`Super + Ctrl + C` 会以菜单形式打开同一组功能。

| 快捷键 | 功能 |
| ------ | -------- |
| `Print Screen` | 截图 |
| `Alt + Print Screen` | 录屏（或停止正在进行的录屏） |
| `Super + Print Screen` | 取色器 |
| `Super + Ctrl + Print Screen` | 从区域中提取文本 |
| `Super + Ctrl + C` | 捕获菜单 |
| `Super + Ctrl + .` | 转码图片或视频 |

## 截图

按 `Print Screen`，Omasnap 会在其叠加层出现之前捕获聚焦的显示器，这样在你瞄准时，任何东西都不会在你下面移动。拖动自由区域，单击窗口以捕获它，或单击空白处以捕获整个显示器。在绘制之前按 `S` 可捕获滚动区域。改变主意了？再次按 `Print Screen` 可关闭 Omasnap。

选择区域后，Omasnap 会保存捕获，将其复制到剪贴板，并显示预览 10 秒。使用预览的图钉按钮或 `Ctrl + P` 可将其保留在屏幕上，或者选择“编辑”对其进行注释。

注释编辑器可以绘制箭头、线条、形状、高亮、编号标记、文本和安全涂抹；裁剪或剪切图片的一部分；对其文本进行 OCR；并添加背景。在编辑器中，按 `Enter` 可复制并保存完成的 PNG，按 `Ctrl + C` 可复制而不保存，或按 `Ctrl + S` 可保存而不复制。

保存的截图默认位于 `~/Pictures/Screenshots`，名称类似 `screenshot-2026-08-13_14-22-05-firefox.png`。设置 `OMASNAP_SCREENSHOT_DIR` 可使用另一个目录——有关放置会话环境变量的位置，请参见[常见问题](46-faq.md)。Omasnap 在保存第一张截图时会创建该目录。在 `~/.config/omasnap/omasnap.conf` 中设置 `[output] autosave = false` 可禁用自动保存。

在终端中，`omarchy screenshot` 会打开同一个叠加层，你可以选择其起始模式：`omarchy capture screenshot region`、`windows`、`fullscreen` 或 `scroll`。第二个参数 `copy` 或 `save` 会跳过预览，并将截图直接发送到该目标。要在输出前进行编辑，请使用 `omarchy screenshot --editor=overlay` 获取全屏编辑器，或使用 `omarchy screenshot --editor=window` 获取单独的窗口。

### 用键盘驱动选择器

在选区打开期间，你完全不必使用鼠标：

| 键 | 功能 |
| --- | -------- |
| `S` | 切换滚动区域模式 |
| `Super + Arrow keys` | 在窗口模式中在窗口之间移动 |
| `Return` | 捕获高亮显示的窗口 |
| `Ctrl + A` | 捕获完整的聚焦显示器 |
| `R` | 恢复本次会话中绘制的上一个区域 |
| `Esc` | 关闭 Omasnap |

这些绑定仅在 Omasnap 打开时存在，因此它们不会与你自己的配置中的任何内容冲突。

## 录屏

`Alt + Print Screen` 会打开_触发 > 捕获 > 录屏_，它会询问你想要什么样的音轨：无音频、桌面音频、桌面加麦克风，或桌面加麦克风加摄像头。最后一个仅当你确实插入了摄像头时才会出现。选择一个，Omarchy 的录制选择器会让你拖动区域或单击窗口或显示器。

录制运行在 gpu-screen-recorder 上，它在 GPU 上以 60fps 编码，必要时回退到 CPU。结果是 `~/Videos` 中的一个 MP4，命名为 `screenrecording-2026-08-13_14-22-05.mp4`。设置 `OMARCHY_SCREENRECORD_DIR` 可更改该位置——但请注意，与截图目录不同，这个目录必须已经存在，否则录制将拒绝开始。

录制期间，栏中会出现一个小指示器。单击它可停止。你也可以再次用 `Alt + Print Screen` 停止，或使用_触发 > 捕获 > 录屏_下的_停止录屏_条目，该条目仅在实际正在录制时出现。

停止会在将文件交给你之前做一点整理：第一帧会被修剪，如果有音频，它会被标准化到 -14 LUFS，最开始的 PipeWire 捕获爆音会被静音。然后会出现一个带有录制缩略图的通知。单击它可在 mpv 中播放该文件。

### 摄像头叠加层

当你使用摄像头录制时，相机将以固定、裁剪的人像窗口形式出现在你所录制内容的右下角。如果它挡住了你需要的东西，可即时调整其大小：

| 快捷键 | 功能 |
| ------ | -------- |
| `Super + Alt + [` | 使摄像头叠加层更小 |
| `Super + Alt + ]` | 使摄像头叠加层更大 |

有三种尺寸——小、中、大——快捷键在它们之间步进。中是默认值。它们与录制成比例，因此无论你录制的是 1080p 显示器还是 6K 显示器，相机都占据画面相同的份额。如果你录制的是区域而不是整个显示器，叠加层会锚定到该区域的角落，而不是显示器的角落，这样它就留在画面内。

你也可以用 `omarchy-capture-webcam-resize small` 直接调用它，或用 `reset` 回到中。

## 文本、QR 码和颜色

`Super + Ctrl + Print Screen` 选择一个区域并将其 OCR 到剪贴板。这在[文本提取与听写](11-text-extraction-dictation.md)中有详细介绍。

_触发 > 捕获 > QR 码_对 QR 码做同样的把戏。选择包含代码的区域，解码后的值将转到剪贴板。它只查找 QR 码——否则密集的屏幕内容有误判为条形码的习惯。值得知道：解码后的值只会转到剪贴板，不会转到任何其他地方。它不会被打印，不会出现在通知中，而且会被标记为敏感，这样它就不会留在[剪贴板历史](08-unified-clipboard-history.md)中。QR 码常携带秘密——比如 2FA 设置代码背后的 `otpauth://` URI——你可不想让它出现在日志中。粘贴仍然正常工作。

`Super + Print Screen`（或_触发 > 捕获 > 颜色_）会将光标变成吸管工具。单击屏幕上的任何内容，颜色就会落到剪贴板上。再次按快捷键可在不取色的情况下退出。

## 分享前转码

4K 录屏或手机上的原始 HEIC 通常太大，无法直接发送。`Super + Ctrl + .`（或_触发 > 转码_）可解决这个问题。它为你提供一个覆盖 `~/Pictures` 和 `~/Videos` 的模糊文件选择器，然后询问格式和大小。

图片会转换为 jpg 或 png，质量为高、中或低，宽度上限分别为 3160、2160 和 1080 像素。视频会转换为 mp4 或动画 gif，分辨率为 4k、1080p 或 720p。转换后的文件写在原文件旁边，名称中包含分辨率——`demo-1080p.mp4`——路径以文件 URI 的形式复制到剪贴板上，这样你就可以将其直接粘贴到接受文件拖放的应用中。

如果你已经知道自己想要什么，它也可以在终端中工作：`omarchy transcode ~/Videos/demo.mov mp4 1080p`。还有 `omarchy transcode ascii`，它将图片转换为 ASCII 艺术——这个主要用于[品牌](41-branding.md)。

## 将其发送到某处

拿到文件后，`Super + Ctrl + S` 会打开分享菜单，并通过 LocalSend 将其发送到你网络上的另一台设备。有关该内容，请参见 [GUI](22-guis.md)。
