# 背景

每个主题都自带一组背景，你也可以在 `~/.config/omarchy/backgrounds/[theme]` 中添加你自己的额外背景。如果你想为比如 nord 主题添加一张额外的背景图片，只需将文件放入 `~/.config/omarchy/backgrounds/nord`。

最简单的方法是在 Omarchy Menu 中前往 _Install > Style > Background_。这将打开该主题的背景所存储的文件夹。按 `Super + Shift + F` 启动另一个文件管理器，找到你的背景，将其复制过去。现在，它将包含在你可以使用 `Super + Ctrl + W` 在其中进行选择的背景选项中。

没有任何自有背景的主题会得到一个由其颜色绘制而成的背景：以主题的强调色在其背景色上绘制 Omarchy 标志。添加你自己的背景来替换它。

背景也可以是视频，而不只是静态图片。将 `mp4`、`m4v`、`mov`、`webm`、`mkv` 或 `avi` 文件放入同一个文件夹，它就会与图片一起出现。视频由 OWE 壁纸引擎播放。它为所有显示器仅解码一次视频，并通过默认音频输出播放其声音，而且当没有任何东西能看到它时，它会停止播放。视频壁纸的功耗仍然远远高于静态壁纸。

主题可以为静态背景包含一个简短的开场。对于 `backgrounds/road.webp`，与之匹配的视频位于 `backgrounds/intros/road.mp4`。它会在启动时、切换到选中了该背景的主题时以及选择该背景时自动播放，然后返回到静态图片。开场视频不会出现在背景选择器中，也永远不会循环播放。

选择 _Appearance > Animations Off_ 也会关闭背景开场。Omarchy 在虚拟机中默认这样做。`omarchy theme bg intro toggle` 命令可以单独切换开场。刷新主题不会播放开场。

静态图片也可以有一个循环，即同一个画面的安静版本，会持续移动，位于 `backgrounds/loops/road.mp4`。它会代替静态图片播放，如果有开场，则在开场之后播放，并在动画关闭时停止。使用电池时，会改为显示静态图片，一旦插上电源，循环就会回来。循环不会出现在背景选择器中。

你可以在 [dharmx/walls](https://github.com/dharmx/walls) 中找到大量精选的炫酷背景。

锁屏会显示视频背景的一帧静止画面，与它显示动态 GIF 的一帧静止画面的方式相同。
