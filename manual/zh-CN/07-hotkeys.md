# 快捷键

你可以用 `Super + K` 查看所有主要键盘绑定（用 `Super + Alt + K` 查看 Tmux 绑定，用 `Super + Ctrl + K` 查看 Herdr 绑定）。

## 导航

| 快捷键                  | 功能              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy 菜单（应用及其他一切）    |
| `Super + Alt + Space` | 应用网格 |
| `Super + Escape` | 系统菜单（挂起、重启等）  |
| `Super + Ctrl + L` | 锁定计算机 |
| `Super + W` or `Super + Q` | 关闭窗口             |
| `Ctrl + Alt + Del` | 关闭所有窗口 |
| `Super + T`               | 在平铺/浮动之间切换窗口             |
| `Super + J` | 切换窗口位置（水平/垂直） |
| `Super + O`               | 切换将窗口弹出为粘滞浮动 |
| `Super + L`               | 循环切换 dwindle、滚动和浮动布局 |
| `Super + Alt + L`         | 反向循环切换布局 |
| `Super + P`               | 切换伪窗口样式（自然与拉伸） |
| `Super + F`                 | 进入全屏              |
| `Super + Alt + F`                 | 进入全宽              |
| `Super + Ctrl + F`                 | 进入全屏 inside window              |
| `Super + 1/2/3/4`         | 跳转到指定工作区     |
| `Super + Tab` | 跳转到下一个工作区 |
| `Super + Shift + Tab` | 跳转到上一个工作区 |
| `Super + Ctrl + Tab` | 跳转到之前的工作区 |
| `Super + Shift + 1/2/3/4` | 将窗口移动到工作区 |
| `Super + Shift + Alt + 1/2/3/4` | 将窗口移动到工作区但不跟随 |
| `Super + S` / `Super + Grave` | 切换 scratchpad |
| `Super + Alt + S` / `Super + Shift + Grave` | 将窗口移动到 scratchpad |
| `Super + Shift + Alt + Arrows` | 将工作区移动到方向显示器 |
| `Super + Arrow`  | 将焦点移动到箭头方向的窗口              |
| `Super + Shift + Arrow`  | 与箭头方向的另一个窗口交换     |
| `Super + Minus` | 向左扩展窗口 |
| `Super + Equal` | 从左侧缩小窗口 |
| `Super + Shift + Minus` | 从顶部缩小窗口 |
| `Super + Shift + Equal` | 向下扩展窗口 |
| `Super + Alt + Minus/Equal` | 以更小的步幅调整大小 |
| `Super + Ctrl + Minus/Equal` | 以更大的步幅调整大小 |
| `Super + Alt + Home` | 保存窗口宽度 |
| `Super + Home` | 恢复已保存的窗口宽度 |
| `Super + Left Mouse` | 拖动窗口 |
| `Super + Right Mouse` | 调整窗口大小 |
| `Super + Scroll Wheel` | 滚动浏览工作区 |
| `Super + G`               | 切换窗口分组      |
| `Super + Alt + G`               | 将窗口移出分组      |
| `Super + Alt + Tab`               | 在分组中的窗口之间循环      |
| `Super + Alt + Shift + Tab`               | 在分组中的窗口之间反向循环      |
| `Super + Alt + 1/2/3/4/5`               | 跳转到分组中的指定窗口      |
| `Super + Alt + Arrow`  | 将窗口沿箭头方向移入分组  |
| `Super + Ctrl + Left/Right`  | 在平铺组内的窗口之间移动 |
| `Super + Ctrl + Z` | 放大屏幕（重复可进一步放大） |
| `Super + Ctrl + Alt + Z` | 完全缩小屏幕 |
| `Super + /` | 向前步进显示器缩放选项 |
| `Super + Alt + /` | 向后步进显示器缩放选项 |
| `Alt + Tab` | 在活动工作区的窗口中向前循环 |
| `Alt + Shift + Tab` | 在活动工作区的窗口中向后循环 |
| `Ctrl + Alt + Tab`| 在显示器之间向前循环焦点 |
| `Ctrl + Alt + Shift + Tab`| 在显示器之间向后循环焦点 |

## 通用剪贴板

| 快捷键                  | 功能              |
| ----------------------- | --------------------- |
| `Super + C`           | 复制    |
| `Super + X`           | 剪切（终端中除外）    |
| `Super + V`           | 粘贴    |
| `Super + Ctrl + V`           | 剪贴板管理器    |

通常在 Linux 上，你需要在终端中使用 `Ctrl + Shift + C/V` 进行复制粘贴，在其他地方使用 `Ctrl + C/V`。这些 Omarchy 统一剪贴板快捷键随处可用。

## 捕获

| 快捷键              | 功能                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | 捕获菜单（适用于没有 PrintScr 按钮的键盘） |
| `Print Screen`            | 截图                      |
| `Alt + Print Screen`            | 录屏                     |
| `Super + Print Screen` | 取色器 |
| `Super + Ctrl + Print Screen` | 将文本提取到剪贴板 |
| `Super + Alt + [` | 录制时使摄像头叠加层更小 |
| `Super + Alt + ]` | 录制时使摄像头叠加层更大 |
| `Alt + Shift + L` | 从 Web 应用或 Chromium 复制当前 URL |
| `Alt + Shift + D` | 将当前页面上的视频下载到 `~/Videos` |
| `Super + Ctrl + X` | 开始/停止听写（需要_设置 > 默认项 > 听写_） |
| `Right Alt` / `F9` | 按住说话听写（需要 Voxtype 或 Superwhisper） |

对于录屏，该快捷键会先询问你想要哪种音频，然后开始录制。再次按它可停止。有关详细信息，请参见[截图与录屏](12-screenshots-recording.md)。

所有捕获选项也可以在 Omarchy 菜单（`Super + Space`）中的_触发 > 捕获_下访问。

## Tmux

前缀键是 `Ctrl + Space`（`Ctrl + B` 也可用）。你可以在 `~/.config/tmux/tmux.conf` 中更改这些绑定。

### 窗格

| 快捷键                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + v` | 在旁边分割窗格（垂直） |
| `Prefix + h` | 在下方分割窗格（水平） |
| `Prefix + x` | 终止窗格 |
| `Prefix + z` | 切换窗格缩放（全屏） |
| `Alt + Enter` | 在下方分割窗格（无前缀） |
| `Alt + Shift + Enter` | 在旁边分割窗格（无前缀） |
| `Alt + Escape` | 终止窗格（无前缀） |
| `Ctrl + Alt + Arrows` | 在窗格之间移动 |
| `Ctrl + Alt + Shift + Arrows` | 调整窗格大小 |

### 窗口

| 快捷键                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + c` | 新窗口 |
| `Prefix + k` | 终止窗口 |
| `Prefix + r` | 重命名窗口 |
| `Alt + 1-9` | 转到指定窗口 |
| `Alt + Arrow Left/Right` | 在窗口之间移动 |
| `Alt + Shift + Arrow Left/Right` | 将窗口左移/右移 |

### 会话

| 快捷键                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + C` | 新会话 |
| `Prefix + K` | 终止会话 |
| `Prefix + R` | 重命名会话 |
| `Prefix + N` | 下一个会话 |
| `Prefix + P` | 上一个会话 |
| `Alt + Arrow Up/Down` | 在会话之间移动 |
| `Prefix + s` | 列出会话 |
| `Prefix + d` | 从会话分离 |

### 复制模式（vi 风格）

| 快捷键                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + [` | 进入复制模式 |
| `v` | 开始选择（在复制模式中） |
| `y` | 复制所选内容（在复制模式中） |

### 通用

| 快捷键                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + q` | 重新加载配置 |
| `Prefix + ?` | 显示 Tmux 快捷键 |
| `Prefix + :` | 命令提示符 |

### Tmux 布局函数

这些函数必须在 Tmux 会话内运行。

| 命令 | 功能 |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | 创建包含编辑器、AI 和终端的开发布局 |
| `tdlm <ai> [<second_ai>]` | 为每个子目录创建开发布局 |
| `tsl <count> <command>` | 创建多窗格蜂群布局 |
