# 快捷键

你可以使用 `Super + K` 查看所有主要键盘绑定（Tmux 绑定使用 `Super + Alt + K`，Herdr 绑定使用 `Super + Ctrl + K`）。

## 导航

| 快捷键                  | 功能              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy 菜单（应用及其他所有内容）    |

| `Super + Escape` | 系统菜单（挂起、重启等）  |

| `Super + Alt + Minus/Equal` | 以更小的步幅进行相同的调整大小操作 |
| `Super + Ctrl + Minus/Equal` | 以更大的步幅进行相同的调整大小操作 |
| `Super + Alt + Home` | 保存窗口宽度 |
| `Super + Home` | 恢复已保存的窗口宽度 |
| `Super + Left Mouse` | 拖动窗口 |
| `Super + Right Mouse` | 调整窗口大小 |
| `Super + Scroll Wheel` | 在聚焦显示器上滚动切换工作区 |
| `Super + G`               | 切换窗口分组      |
| `Super + Alt + G`               | 将窗口移出分组      |
| `Super + Alt + Tab`               | 在分组内的窗口之间循环切换      |

| `Super + Alt + Scroll Wheel` | 在分组内的窗口之间循环切换 |
| `Super + Alt + 1/2/3/4/5`               | 跳转到分组中的指定窗口      |

| `Super + Ctrl + Z` | 放大屏幕（重复操作可进一步放大） |
| `Super + Ctrl + Alt + Z` | 从屏幕完全缩小 |

| `Super + Alt + /` | 逐步向后切换显示器缩放选项 |

| `Alt + Shift + Tab` | 在活动工作区上向后循环切换窗口 |
| `Ctrl + Alt + Tab`| 在显示器之间向前循环切换焦点 |
| `Ctrl + Alt + Shift + Tab`| 在显示器之间向后循环切换焦点 |

调整大小快捷键使用物理按键 `code:20` 和 `code:21`（XKB `<AE11>` 和 `<AE12>`），无论键盘上印刷的是什么字符。在美式键盘上，这些按键是 `-` 和 `=`；在日式 (JIS) 键盘上，它们是 `-` 和 `^`；在西班牙语键盘上，它们是 `'` 和 `¡`。在 JIS 上，`Super + ^` 就是 `Super + Equal`，而 `Super + Shift + -`（输入 `=`）就是 `Super + Shift + Minus`。

## 通用剪贴板

| 快捷键                  | 功能              |
| ----------------------- | --------------------- |
| `Super + A`           | 在支持 `Ctrl + A` 的应用中全选    |

## Tmux

前缀键是 `Ctrl + Space`（`Ctrl + B` 也可以）。你可以在 `~/.config/tmux/tmux.conf` 中更改这些绑定。

### 窗格

| 快捷键                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + v` | 在旁边拆分窗格（垂直） |
| `Prefix + h` | 在下方拆分窗格（水平） |
| `Prefix + x` | 关闭窗格 |
| `Prefix + z` | 切换窗格缩放（全屏） |
| `Alt + Enter` | 在下方拆分窗格（无需前缀） |
| `Alt + Shift + Enter` | 在旁边拆分窗格（无需前缀） |
| `Alt + Escape` | 关闭窗格（无需前缀） |
| `Ctrl + Alt + Arrows` | 在窗格之间移动 |
| `Ctrl + Alt + Shift + Arrows` | 调整窗格大小 |
