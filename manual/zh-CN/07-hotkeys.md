# 快捷键

你可以用 `Super + K` 查看所有主要键盘绑定（Tmux 绑定用 `Super + Alt + K`，Herdr 绑定用 `Super + Ctrl + K`）。

| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy 菜单（应用和其他所有内容）    |
| `Super + Alt + Space` | 应用网格 |
| `Super + Escape` | 系统菜单（挂起、重启等）  |
| `Super + Ctrl + L` | 锁定计算机 |
| `Super + W` or `Super + Q` | 关闭窗口             |

| `Super + F`                 | 全屏              |
| `Super + Alt + F`                 | 全宽              |

| `Super + Shift + Alt + Arrows` | 将工作区移到该方向的显示器 |
| `Super + Arrow`  | 将焦点移到箭头方向的窗口，在屏幕边缘时跨到那一侧的显示器 |
| `Super + Shift + Arrow`  | 与箭头方向的另一个窗口交换位置，包括那一侧显示器上的窗口 |

| `Super + Equal` | 向左缩小窗口 |
| `Super + Shift + Minus` | 向上缩小窗口 |
| `Super + Shift + Equal` | 向下扩大窗口 |
| `Super + Alt + Minus/Equal` | 以更小的步幅进行同样的调整大小 |
| `Super + Ctrl + Minus/Equal` | 以更大的步幅进行同样的调整大小 |
| `Super + Alt + Home` | 保存窗口宽度 |
| `Super + Home` | 恢复已保存的窗口宽度 |
| `Super + Left Mouse` | 拖动窗口 |
| `Super + Right Mouse` | 调整窗口大小 |
| `Super + Scroll Wheel` | 在当前显示器的工作区之间滚动切换 |
| `Super + G`               | 切换窗口分组      |
| `Super + Alt + G`               | 将窗口移出分组      |
| `Super + Alt + Tab`               | 在分组内的窗口之间循环切换      |
| `Super + Alt + Shift + Tab`               | 在分组内的窗口之间反向循环切换      |
| `Super + Alt + Scroll Wheel` | 在分组内的窗口之间循环切换 |
| `Super + Alt + 1/2/3/4/5`               | 跳转到分组中的指定窗口      |
| `Super + Alt + Arrow`  | 将窗口移入箭头方向的分组，包括那一侧显示器上的窗口 |
| `Super + Ctrl + Left/Right`  | 在平铺分组内的窗口之间移动 |
| `Super + Ctrl + Z` | 放大屏幕（重复按下可进一步放大） |
| `Super + Ctrl + Alt + Z` | 从屏幕完全缩小 |
| `Super + /` | 向前逐步切换显示器缩放选项 |
| `Super + Alt + /` | 向后逐步切换显示器缩放选项 |
| `Alt + Tab` | 在活动工作区上向前循环切换窗口 |
| `Alt + Shift + Tab` | 在活动工作区上向后循环切换窗口 |
| `Ctrl + Alt + Tab`| 在显示器之间向前循环切换焦点 |
| `Ctrl + Alt + Shift + Tab`| 在显示器之间向后循环切换焦点 |

调整大小快捷键使用物理按键 `code:20` 和 `code:21`（XKB `<AE11>` 和 `<AE12>`），与键盘上印制的字符无关。在美式键盘上，这些键是 `-` 和 `=`；在日式 (JIS) 键盘上，它们是 `-` 和 `^`；在西班牙语键盘上，它们是 `'` 和 `¡`。在 JIS 上，`Super + ^` 是 `Super + Equal`，而 `Super + Shift + -`（输入 `=`）是 `Super + Shift + Minus`。

## 通用剪贴板

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + A`           | 在支持 `Ctrl + A` 的应用中全选    |
