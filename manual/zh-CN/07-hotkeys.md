# 快捷键

你可以用 `Super + K` 查看所有主要键盘绑定（Tmux 绑定用 `Super + Alt + K`，Herdr 绑定用 `Super + Ctrl + K`）。

## 导航

| 快捷键 | 功能 |
| ----------------------- | --------------------- |
| `Super + Space` | Omarchy 菜单（应用及其他所有内容） |
| `Super + Alt + Space` | 应用网格 |
| `Super + Escape` | 系统菜单（挂起、重启等） |
| `Super + Ctrl + L` | 锁定电脑 |
| `Super + W` 或 `Super + Q` | 关闭窗口 |
| `Ctrl + Alt + Del` | 关闭所有窗口 |
| `Super + T` | 在平铺/浮动之间切换窗口 |
| `Super + J` | 切换窗口位置（水平/垂直） |
| `Super + O` | 将窗口切换为粘性浮动的弹出状态 |
| `Super + L` | 在 dwindle、scrolling 和 floating 布局之间循环切换 |
| `Super + Alt + L` | 反向在各布局之间循环切换 |
| `Super + P` | 切换伪窗口样式（自然 v 拉伸） |
| `Super + F` | 进入全屏 |
| `Super + Alt + F` | 进入全宽 |
| `Super + Ctrl + F` | 在窗口内全屏 |
| `Super + 1/2/3/4` | 跳转到聚焦显示器上的指定工作区 |
| `Super + Tab` | 跳转到聚焦显示器上的下一个工作区 |
| `Super + Shift + Tab` | 跳转到聚焦显示器上的上一个工作区 |
| `Super + Ctrl + Tab` | 跳转到聚焦显示器上之前的工作区 |
| `Super + Shift + 1/2/3/4` | 将窗口移动到聚焦显示器上的工作区 |
| `Super + Shift + Alt + 1/2/3/4` | 将窗口移动到聚焦显示器上的工作区，但不跟随过去 |
| `Super + S` | 切换完整暂存区 |
| `Super + Alt + S` | 将窗口移动到完整暂存区 |
| `Super + Grave` | 切换 Quake 控制台 |
| `Super + Shift + Grave` | 将窗口移动到 Quake 控制台 |
| `Super + Shift + Ctrl + Arrows` | 将窗口移动到该方向的显示器 |
| `Super + Shift + Alt + Arrows` | 将工作区移动到该方向的显示器 |
| `Super + Arrow` | 将焦点移动到箭头方向的窗口，在屏幕边缘时跨到该侧的显示器 |
| `Super + Shift + Arrow` | 与箭头方向的另一个窗口交换位置，包括该侧显示器上的窗口 |
| `Super + Minus` | 向左扩大窗口 |
| `Super + Equal` | 向左缩小窗口 |
| `Super + Shift + Minus` | 向上缩小窗口 |
| `Super + Shift + Equal` | 向下扩大窗口 |
| `Super + Alt + Minus/Equal` | 以更小的步幅进行同样的大小调整 |
| `Super + Ctrl + Minus/Equal` | 以更大的步幅进行同样的大小调整 |
| `Super + Alt + Home` | 保存窗口宽度 |
| `Super + Home` | 恢复已保存的窗口宽度 |
| `Super + Left Mouse` | 拖动窗口 |
| `Super + Right Mouse` | 调整窗口大小 |
| `Super + Scroll Wheel` | 在聚焦显示器上的工作区之间滚动切换 |
| `Super + G` | 切换窗口分组 |
| `Super + Alt + G` | 将窗口移出分组 |
| `Super + Alt + Tab` | 在分组内的窗口之间循环切换 |
| `Super + Alt + Shift + Tab` | 在分组内的窗口之间反向循环切换 |
| `Super + Alt + Scroll Wheel` | 在分组内的窗口之间循环切换 |
| `Super + Alt + 1/2/3/4/5` | 跳转到分组内的指定窗口 |
| `Super + Alt + Arrow` | 将窗口沿箭头方向移入分组，包括该侧显示器上的窗口 |
| `Super + Ctrl + Left/Right` | 在平铺组内的窗口之间移动 |
| `Super + Ctrl + Z` | 放大屏幕（重复操作可进一步放大） |
| `Super + Ctrl + Alt + Z` | 从屏幕完全缩小 |
| `Super + /` | 逐步向前切换显示器缩放选项 |
| `Super + Alt + /` | 逐步向后切换显示器缩放选项 |
| `Alt + Tab` | 在当前工作区向前循环切换窗口 |
| `Alt + Shift + Tab` | 在当前工作区向后循环切换窗口 |
| `Ctrl + Alt + Tab` | 在显示器之间向前循环切换焦点 |
| `Ctrl + Alt + Shift + Tab` | 在显示器之间向后循环切换焦点 |

## 通用剪贴板

| 快捷键 | 功能 |
| ----------------------- | --------------------- |
| `Super + C` | 复制 |
| `Super + X` | 剪切（终端中除外） |
| `Super + V` | 粘贴 |
| `Super + Ctrl + V` | 剪贴板管理器 |

在 Linux 上，你通常需要在终端中使用 `Ctrl + Shift + C/V` 来复制粘贴，在其他所有地方则使用 `Ctrl + C/V`。这些 Omarchy 统一剪贴板快捷键在任何地方都能用。

## 捕获

| 快捷键 | 功能 |
| ------------------- | ------------------------------ |
| `Print Screen` | 截图 |
| `Super + Ctrl + Alt + C` | 截图（同一截图，适用于没有 Print Screen 键的键盘） |
| `Super + Ctrl + C` | 捕获菜单 |
| `Alt + Print Screen` | 录制屏幕 |
| `Super + Print Screen` | 颜色选取器 |
| `Super + Ctrl + Print Screen` | 将文本提取到剪贴板 |

| `Alt + Shift + L` | 从 webapp 或 Chromium 复制当前 URL |
| `Alt + Shift + D` | 将当前页面上的视频下载到 `~/Videos` |

录制屏幕时，快捷键会先询问你想要哪种音频，然后开始录制。再按一次即可停止。详情请查看[截图和录制](12-screenshots-recording.md)。

所有捕获选项也可以在 Omarchy 菜单（`Super + Space`）的 _触发 > 捕获_ 下访问。

## Tmux

前缀键是 `Ctrl + Space`（`Ctrl + B` 也可用）。你可以在 `~/.config/tmux/tmux.conf` 中更改这些绑定。

### 窗格

| 快捷键 | 功能 |
| ----------------------- | --------------------- |
| `Prefix + v` | 在旁边分割窗格（垂直） |
| `Prefix + h` | 在下方分割窗格（水平） |
| `Prefix + x` | 终止窗格 |
| `Prefix + z` | 切换窗格缩放（全屏） |
| `Alt + Enter` | 在下方分割窗格（无需前缀） |
| `Alt + Shift + Enter` | 在旁边分割窗格（无需前缀） |
| `Alt + Escape` | 终止窗格（无需前缀） |
| `Ctrl + Alt + Arrows` | 在窗格之间移动 |
| `Ctrl + Alt + Shift + Arrows` | 调整窗格大小 |

### 窗口

| 快捷键 | 功能 |
| ----------------------- | --------------------- |
| `Prefix + c` | 新建窗口 |
| `Prefix + k` | 终止窗口 |
| `Prefix + r` | 重命名窗口 |
| `Alt + 1-9` | 转到指定窗口 |
| `Alt + Arrow Left/Right` | 在窗口之间移动 |
| `Alt + Shift + Arrow Left/Right` | 将窗口左移/右移 |

### 会话

| 快捷键 | 功能 |
| ----------------------- | --------------------- |
| `Prefix + C` | 新建会话 |
| `Prefix + K` | 终止会话 |
| `Prefix + R` | 重命名会话 |
| `Prefix + N` | 下一个会话 |
| `Prefix + P` | 上一个会话 |
| `Alt + Arrow Up/Down` | 在会话之间移动 |
| `Prefix + s` | 列出会话 |
| `Prefix + d` | 从会话中分离 |

### 复制模式（vi 风格）

| 快捷键 | 功能 |
| ----------------------- | --------------------- |
| `Prefix + [` | 进入复制模式 |
| `v` | 开始选择（在复制模式中） |
| `y` | 复制所选内容（在复制模式中） |

### 通用

| 快捷键 | 功能 |
| ----------------------- | --------------------- |
| `Prefix + q` | 重新加载配置 |
| `Prefix + ?` | 显示 Tmux 快捷键绑定 |
| `Prefix + :` | 命令提示符 |

### Tmux 布局函数

这些函数必须在 Tmux 会话内运行。

| 命令 | 功能 |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | 创建包含编辑器、AI 和终端的开发布局 |
| `tdlm <ai> [<second_ai>]` | 按子目录创建开发布局 |
| `tsl <count> <command>` | 创建多窗格 swarm 布局 |
