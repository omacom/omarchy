# 安全

Omarchy 非常认真地对待安全。它意欲成为一个可以在 _真实世界_ 中进行 _真正工作_ 的操作系统。在那里丢失笔记本电脑不会导致安全紧急情况。所以以下是我们所做的：

1. *全盘加密是强制性的*：这是确保你数据物理保护的最重要一步。如果你的电脑丢失或被盗，数据将使用标准 LUKS（Linux Unified Key Setup）完全加密。
2. *防火墙默认启用*：默认阻止所有入站流量，端口 53317（用于 [LocalSend](https://localsend.org/)）除外。甚至 ssh 也要等到你通过 _设置 > 安全 > SSHD_ 开启后才开启，该设置打开了端口 22（对暴力破解限速）。我们甚至使用 [ufw-docker](https://github.com/chaifeng/ufw-docker) 设置锁定 Docker 访问，以防止你的容器意外暴露给外界。
3. *Arch 始终拥有最新更新*：Arch 是 Omarchy 所构建于的底层发行版，是一个滚动发行版。这意味着任何被发现并修补的软件包安全漏洞都会很快通过 `omarchy-update` 提供安装。这样一来，你运行的始终是最新、最安全的版本。
4. *Omarchy 维护自己的软件包和镜像*：Omarchy 默认仅依赖于 Arch 的 core/extra/multilib 仓库中的软件包以及它自己的 Omarchy 软件包仓库。你可以直接从 AUR 安装软件，但基础安装不会——只有一些可选安装（如第三方浏览器）会从 AUR 拉取。
5. *Cloudflare 保护我们抵御 DDoS*：所有的 Omarchy 分发基础设施——ISO、Omarchy 软件包、Arch 镜像——都受到 Cloudflare 强大的 DDoS 护盾保护，并托管在他们的 CDN 上。这提供了卓越的可用性。

## 更改你的密码

在加密安装中你有两个密码：一个用于在开机时解锁硬盘，另一个用于登录和 `sudo`。设置使它们相同。两者都可以在 Omarchy 菜单中的 _更新 > 密码_ 下更改——_磁盘加密_ 是第一个，_用户_ 是第二个。更改硬盘密码会先要求输入当前密码，所以请提前准备好。如果一次更改被中断，再次运行 _磁盘加密_：它会要求当前可以解锁硬盘的密码，并完成更改。

## 转让你已使用的机器

如果你要将你的机器交给别人，你不必重新安装它。在 Omarchy 菜单里运行 _设置 > 重置电脑_，输入 `reset` 进行确认，然后重启。这会擦除每一个用户账户以及 `/home` 中的所有内容，丢弃你自安装以来制作的所有软件包和系统更改，并清除机器的身份——网络连接、主机密钥等全部。重启后出现的将是第一次开机时的设置向导，为其新主人准备好输入自己的姓名、密码和加密密码。

它通过恢复安装程序采取的基线快照来工作，所以它仅在从 Omarchy ISO 安装的机器上可用。在没有加密的硬盘上，重置是删除而不是安全擦除，所以如果数据敏感，则进行全新安装。

## 免密 sudo

有时你希望 `sudo` 停止询问，最常见的是当一个 AI 智能体正在为你进行长时间的系统工作时。_设置 > 安全 > 免密 sudo_ 询问允许访问的时长：**15 分钟**、**1 Hour**、**1 Day** 或 **Permanently**。在访问激活期间，其他菜单栏指示器旁会出现一个红色警告图标。点击它或者再次运行该命令即可关闭访问。你也可以使用 `omarchy-sudo-passwordless 30` 传递你自己的分钟数（从 1 到 1440），或使用 `omarchy-sudo-passwordless permanent`。

定时访问会自动过期，包括在跨过截止时间的挂起恢复后立即过期。重启电脑会提前终止它。永久访问在重启后仍然存在，并一直保持启用状态，直到你禁用它。

更新或移除 Omarchy 的设置软件包会在其到期支持改变之前终止任何临时授予。如果命令报告授权或清理错误，请在尝试启用另一个授予之前解决它；出现错误并不意味着免密访问不处于非激活状态。

关于这个功能请清醒认识：当它打开时，任何以你的用户身份运行的程序都能在未经询问的情况下以 root 身份执行任何操作。这正是它的目的，也正是它的风险。

## 签名密钥

所有 ISO 签名和 Omarchy 仓库软件包的公钥是 `40DFB630FF42BCFFB047046CF0134EE680CAC571`（[在 openpgp.org 验证](https://keys.openpgp.org/search?q=pkgs%40omarchy.org)）。`omarchy/omarchy-keyring` 包也包含此密钥，并将用于无缝推出任何潜在的更新。

你可以通过在 URL 后添加 .sig 来找到任何 ISO 发行版的签名。例如 https://iso.omarchy.org/omarchy-x.x.x.iso.sig.
