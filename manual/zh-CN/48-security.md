# 安全性

Omarchy 对安全极其重视。这是一个让你能在_现实世界_里做_真正的工作_的操作系统。在这样的世界里，丢失一台笔记本电脑不能演变成一场安全紧急事件。以下是我们的做法：

1. *全盘加密是强制性的*：这是保护你的数据物理安全最重要的一步。如果你的电脑丢失或被盗，数据会使用标准 LUKS (Linux Unified Key Setup) 完全加密。
2. *防火墙默认启用*：所有传入流量默认都会被阻止，[LocalSend](https://localsend.org/) 使用的 53317 端口除外。甚至 ssh 也处于关闭状态，直到你通过 _Setup > Security > SSHD_ 将其开启；开启过程会打开 22 端口（并针对暴力破解进行速率限制）。我们甚至使用 [ufw-docker](https://github.com/chaifeng/ufw-docker) 方案来锁定 Docker 访问，防止你的容器意外暴露给全世界。
3. *Arch 始终拥有最新更新*：Arch 是 Omarchy 所基于的底层发行版，是一个滚动发行版。这意味着任何软件包中发现并修补的任何安全漏洞，都可以很快通过 `omarchy-update` 安装。就这样，你始终运行着一切的最新、最安全版本。
4. *Omarchy 维护自己的软件包和镜像*：Omarchy 默认仅依赖 Arch 自身的 core/extra/multilib 仓库以及其自己的 Omarchy Package Repository 中的软件包。你可以直接从 AUR 安装软件，但基础安装不会这样做——只有少数可选安装，如第三方浏览器，才会从 AUR 拉取。
5. *Cloudflare 保护我们免受 DDoS 攻击*：Omarchy 的分发基础设施——ISO、Omarchy 软件包、Arch 镜像——都受到 Cloudflare 强大的 DDoS 防护盾的保护，并托管在他们的 CDN 上。这提供了卓越的可用性。

## 更改你的密码

在加密安装中，你有两个密码：一个在启动时解锁驱动器，另一个用于登录和 `sudo`。Setup 会将它们设为相同。两者都可以在 Omarchy 菜单的 _Update > Password_ 下更改——第一个选择 _Drive Encryption_，第二个选择 _User_。更改驱动器密码时会先要求输入当前密码，所以请提前准备好。如果更改被中断，请再次运行 _Drive Encryption_：它会要求输入现在能解锁驱动器的密码，并完成更改。

## 将你已经用过的机器转交他人

如果你要将机器交给其他人，你不必重新安装它。在 Omarchy 菜单中运行 _Setup > Reset Computer_，输入 `reset` 确认，然后重启。这会清除每一个用户账户和 `/home` 中的所有内容，丢弃自安装以来你所做的所有软件包和系统更改，并清除机器的身份信息——网络连接、主机密钥，全部清除。重新启动后出现的是首次启动时的设置向导，准备好让新所有者输入他们自己的姓名、密码和加密密码。

它通过恢复安装程序所拍摄的基线快照来工作，因此仅适用于从 Omarchy ISO 安装的机器。而且在没有加密的驱动器上，重置是删除而不是安全擦除，所以如果数据很敏感，请改为进行全新安装。

## 免密码 sudo

有时你希望 `sudo` 不再询问密码，最常见的情况是 AI agent 正在为你做一长串系统工作时。_Setup > Security > Passwordless Sudo_ 会询问允许访问的时长：**15 分钟**、**1 小时**、**1 天**或**永久**。访问处于激活状态时，菜单栏其他指示器旁会出现一个红色警告图标。点击它或再次运行该命令即可关闭访问。你也可以用 `omarchy-sudo-passwordless 30` 传入你自己的分钟数（从 1 到 1440），或使用 `omarchy-sudo-passwordless permanent`。

定时访问会自动过期，包括从一次跨过截止时间的挂起中恢复后立即过期。重启计算机会提前结束它。永久访问在重启后仍然保留，并会保持启用，直到你将其禁用。

更新或移除 Omarchy 的设置软件包会在其过期支持变更之前结束任何临时授权。如果该命令报告授权或清理错误，请先解决它再尝试启用另一个授权；出现错误并不意味着免密码访问未处于激活状态。

对这一点要清醒：开启期间，任何以你的用户身份运行的东西都可以以 root 身份做任何事，无需询问。这正是它的全部意义，也是它的全部风险。

## 签名密钥

所有 ISO 签名和 Omarchy 仓库软件包的公钥是 `40DFB630FF42BCFFB047046CF0134EE680CAC571`（[在 openpgp.org 上验证](https://keys.openpgp.org/search?q=pkgs%40omarchy.org)）。`omarchy/omarchy-keyring` 软件包也包含这一密钥，并将被用于无缝推出任何潜在更新。

你可以通过在任何 ISO 版本的 URL 后添加 `.sig` 来找到其签名，例如 `https://iso.omarchy.org/omarchy-x.x.x.iso.sig`。
