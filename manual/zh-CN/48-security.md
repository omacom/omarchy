# 安全

Omarchy 对安全极为重视。这理应是一个你可以在_现实世界_中用来做_正经工作_的操作系统。在这里，丢了笔记本电脑也不能演变成一场安全紧急事件。所以我们是这样做的：

1. *全盘加密是强制要求*：这是保护你的数据物理安全最重要的一步。如果你的电脑丢失或被盗，数据会使用标准的 LUKS (Linux Unified Key Setup) 进行全盘加密。
2. *防火墙默认启用*：默认阻止所有传入流量，[LocalSend](https://localsend.org/) 使用的 53317 端口除外。甚至 ssh 也是关闭的，直到你通过_设置 > 安全 > SSHD_将其开启；作为设置的一部分，这会打开 22 端口（并针对暴力破解进行速率限制）。我们甚至使用 [ufw-docker](https://github.com/chaifeng/ufw-docker) 配置来锁定 Docker 访问，以防你的容器意外暴露给全世界。
3. *Arch 始终拥有最新更新*：Arch 是 Omarchy 所基于的底层发行版，它是一个滚动发行版。这意味着，任何软件包中被发现并修补的任何安全漏洞，都会很快可通过 `omarchy-update` 进行安装。这样一来，你始终运行着一切软件的最新、最安全的版本。
4. *Omarchy 维护自己的软件包和镜像*：默认情况下，Omarchy 只依赖来自 Arch 自己的 core/extra/multilib 仓库以及其自己的 Omarchy Package Repository 的软件包。你可以直接从 AUR 安装软件，但基础安装不会这样做——只有少数可选安装，比如第三方浏览器，才会从 AUR 拉取。
5. *Cloudflare 保护我们免受 DDoS 攻击*：Omarchy 的分发基础设施——ISO、Omarchy 软件包、Arch 镜像——都受到 Cloudflare 强大的 DDoS 防护盾保护，并托管在其 CDN 上。这提供了出色的可用性。

## 更改你的密码

在加密安装中你有两个密码：一个是在启动时解锁驱动器的密码，另一个是你登录和执行 `sudo` 时使用的密码。设置时会让它们保持一致。两者都可以在 Omarchy 菜单的_更新 > 密码_下更改——第一个选_驱动器加密_，第二个选_用户_。更改驱动器密码时会先要求输入当前密码，所以请提前准备好。如果更改被中断，请再次运行_驱动器加密_：它会询问现在能解锁驱动器的密码，并完成更改。

## 转交一台你已经用过的机器

如果你要把你的机器交给别人，你不必重新安装它。在 Omarchy 菜单中运行_设置 > 重置电脑_，输入 `reset` 进行确认，然后重启。这会清除每一个用户账户和 `/home` 中的一切，丢弃自安装以来你所做的所有软件包和系统更改，并清除机器的身份——网络连接、主机密钥，全部清除。重新启动后出现的是首次启动时的设置向导，准备让它的新主人输入他们自己的姓名、密码和加密密码。

它通过恢复安装程序拍摄的基线快照来工作，因此它仅适用于从 Omarchy ISO 安装的机器。而且在未加密的驱动器上，重置是删除而非安全擦除，所以如果数据敏感，请改为进行全新安装。

## 免密码 sudo

有时你希望 `sudo` 不再询问，最常见的情况是 AI agent 正在为你做一段长时间的系统工作。_设置 > 安全 > 免密码 Sudo_会询问允许访问多长时间：**15 分钟**、**1 小时**、**1 天**或**永久**。访问处于活动状态时，菜单栏其他指示器旁会出现一个红色警告图标。点击它或再次运行该命令即可关闭访问。你也可以使用 `omarchy-sudo-passwordless 30` 传入你自己的分钟数（从 1 到 1440），或使用 `omarchy-sudo-passwordless permanent`。

定时访问会自动过期，包括从跨越截止时间的挂起中恢复后立即过期。重启电脑会提前结束它。永久访问会在重启后保留，并一直保持启用状态，直到你将其禁用。

更新或移除 Omarchy 的设置软件包会在其过期支持变更之前结束任何临时授权。如果该命令报告授权或清理错误，请在尝试启用另一个授权之前先解决它；出现错误并不意味着免密码访问未处于活动状态。

对此要清醒认识：当它开启时，任何以你的用户身份运行的东西都可以以 root 身份做任何事而无需询问。这正是它的全部意义所在，也是它的全部风险所在。

## 签名密钥

所有 ISO 签名和 Omarchy 仓库软件包的公钥是 `40DFB630FF42BCFFB047046CF0134EE680CAC571`（[在 openpgp.org 上验证](https://keys.openpgp.org/search?q=pkgs%40omarchy.org)）。`omarchy/omarchy-keyring` 软件包也包含此密钥，并将被用于无缝推出任何潜在更新。

你可以通过在 URL 后添加 .sig 来找到任何 ISO 版本的签名。例如 https://iso.omarchy.org/omarchy-x.x.x.iso.sig.
