# 网络

Omarchy 中的网络由 NetworkManager 处理，你可以从[顶栏](05-the-top-bar.md)中的网络图标或使用 `Super + Ctrl + N` 来操作它。

该面板会扫描 Wi-Fi 网络、显示信号强度并进行连接。以太网则什么都不需要——插上就能用。如果你更喜欢待在终端里，`nmtui` 提供了相同的控制功能，而且还有一个 `omarchy network` 命令组。

## 分享你的 Wi-Fi

与其大声念出一长串密码，不如在连接 Wi-Fi 时运行 _设置 > 网络 > QR Code_。这会在屏幕上显示一个 QR 码，任何手机摄像头都可以扫描它来加入网络。一旦你知道它在那里，你就会发现它的使用频率比你预想的更高。

如果你确实需要密码本身，`omarchy network password <interface>` 会将其打印出来。

## DNS

Omarchy 使用你的网络通过 DHCP 下发的任何 DNS。你可以在 _设置 > 网络 > DNS_ 下为整台机器覆盖这一设置，在那里只需单击一下即可选择 Cloudflare 和 Google。选择 _自定义_ 可以输入你自己的服务器。

在终端中，`omarchy dns` 会打印当前的提供商，而 `omarchy dns Cloudflare` 则会设置一个提供商。

## 固定 Wi-Fi 频段

如果你的路由器将 2.4GHz、5GHz 和 6GHz 放在同一个网络名称下，你的笔记本电脑有时会死守着那个速度慢的频段。`omarchy network band` 会显示你当前所在的频段，而 `omarchy network band 5` 则会将其固定。使用 `auto` 可以让它重新自动选择。

这固定的是频段，而不是某个特定的接入点，因此你仍然可以在各个 AP 之间正常漫游。

## 速度有多快？

_触发器 > 测速 > 网络测速_ 会用一对表盘测量你实际的上传和下载速度。在终端中，则是 `omarchy network speedtest down` 或 `up`。（在该菜单中，它旁边还有一个磁盘测速，如果你正在为另一个瓶颈做基准测试的话。）

## 防火墙

防火墙默认开启，并阻止所有传入流量，只有一个例外：53317 端口，这样 [LocalSend](22-guis.md) 开箱即用。

SSH 默认关闭，直到你通过 _设置 > 安全 > SSHD_ 将其开启；这会启动守护进程，打开 22 端口并对其进行速率限制以防范暴力破解，同时授权一个密钥。Docker 也被锁定，因此容器不会意外地将自身暴露在外。完整情况请参阅[安全](48-security.md)。

## Tailscale

[Tailscale](https://tailscale.com/) 是一款网状 VPN，它让通过互联网访问你的所有计算机和服务器变得简单又安全。通过 _安装 > 服务 > Tailscale_ 安装它。

这会在顶栏中为你提供一个 Tailscale 面板，它可以连接和断开 tailnet、切换账户，并选择一个出口节点——你自己的机器和 Mullvad 地区都会显示在列表中。它还可以浏览你的机器，而 Taildrop 就在这里：选择一台机器并按 `s` 向其发送文件，或按 `c`、`n` 和 `d` 复制其 IP、名称或完整 DNS 名称。终端中等效的命令是 `omarchy tailscale send <machine> [file...]`，而发送给你的文件会自动落到 `~/Downloads` 中。宣布文件到达的通知会一直等待，直到你点击将其打开或将其关闭，因此当你在离开机器期间有文件到达时，等你回来时它仍然在那里等你处理。

安装它还会添加一个用于 Tailscale 管理控制台的 Web 应用。

## 当它停止工作时

在重启之前，先试着单独重启出问题的那一部分。_更新 > 硬件_ 中有 Wi-Fi、蓝牙、音频和触控板，重新加载其中一项就能解决大多数“五分钟前还好好的”情况。请参阅[故障排除](45-troubleshooting.md)。
