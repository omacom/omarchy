# 网络

Omarchy 中的网络由 NetworkManager 处理，你可以从[顶栏](05-the-top-bar.md)中的网络图标来操作它，也可以使用 `Super + Ctrl + N`。

该面板会扫描 Wi-Fi 网络，显示信号强度，并进行连接。以太网什么都不用管——插上就能用。如果你更愿意待在终端里，`nmtui` 提供了相同的控制功能，另外还有一个 `omarchy network` 命令组。

## 分享你的 Wi-Fi

与其大声念出一长串密码，不如在连接着 Wi-Fi 时运行 _设置 > 网络 > QR Code_。这样屏幕上就会显示一个二维码，任何手机的相机扫一下就能加入。一旦知道有这个功能，你会发现自己用它的次数比预想的要多。

如果你确实需要密码本身，`omarchy network password <interface>` 会把它打印出来。

## DNS

Omarchy 使用你的网络通过 DHCP 分发的任何 DNS。你可以在 _设置 > 网络 > DNS_ 下为整台机器覆盖这一设置，在那里 Cloudflare 和 Google 都只需要点一下。选择 _Custom_ 即可输入你自己的服务器。

在终端里，`omarchy dns` 会打印当前的提供商，而 `omarchy dns Cloudflare` 则会设置一个提供商。

## 锁定 Wi-Fi 频段

如果你的路由器把 2.4GHz、5GHz 和 6GHz 放在同一个网络名称下，你的笔记本电脑有时会死守着慢的那个频段不放。`omarchy network band` 会显示你当前所在的频段，而 `omarchy network band 5` 会把它锁定。使用 `auto` 可以让它重新自行选择。

这里锁定的是频段，而不是某个特定的接入点，所以你仍然可以像平常一样在各个 AP 之间漫游。

## 速度有多快？

_触发 > 测速 > 网络测速_ 会用一对表盘测量你实际的上传和下载速度。在终端里，则是 `omarchy network speedtest down` 或 `up`。它通过 Omarchy 自己的服务进行测量，并且只计入它自己的测试传输。其他下载可能会争抢带宽，但不会被计入测速结果。（如果你想给另一个瓶颈做基准测试，那个菜单里紧挨着它的还有一个磁盘测速。）

## 防火墙

防火墙默认开启，并阻止所有传入流量，只有一个例外：53317 端口，这样 [LocalSend](22-guis.md) 开箱即用。

SSH 处于关闭状态，直到你通过 _设置 > 安全 > SSHD_ 将其开启；这会启动该守护进程，打开 22 端口并对其进行速率限制以防暴力破解，还会授权一个密钥。Docker 也同样受到严格限制，所以容器不会意外地把自己暴露给全世界。完整情况请参阅[安全](48-security.md)。

## Tailscale

[Tailscale](https://tailscale.com/) 是一种网状 VPN，能让你通过互联网简单又安全地访问你的所有电脑和服务器。通过 _安装 > 服务 > Tailscale_ 来安装它。

安装后，栏里会多出一个 Tailscale 面板，用它可以连接和断开 tailnet、切换账号，以及选择一个出口节点——你自己的机器和 Mullvad 的各个地区都会出现在列表里。它还能浏览你的机器，而 Taildrop 就在这里：选中一台机器，按 `s` 向它发送文件，或者按 `c`、`n` 和 `d` 复制它的 IP、名称或完整 DNS 名称。终端里的等效命令是 `omarchy tailscale send <machine> [file...]`，而别人发给你的文件会自动落到 `~/Downloads` 里。宣布文件到达的通知会一直等到你点开它或将其关闭为止，所以当你不在机器旁时到达的文件，等你回来时它仍然在那里等你处理。

安装它还会为 Tailscale 管理控制台添加一个 Web 应用。

## 当它停止工作时

在重启之前，先试着单独重启出问题的那一部分。_更新 > 硬件_ 里有 Wi-Fi、Bluetooth、音频和触控板，重新加载其中任何一个都能解决大多数“五分钟前还好好的”情况。请参阅[故障排除](45-troubleshooting.md)。
