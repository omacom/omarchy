# Herinneringen

Omarchy heeft een ingebouwde manier om eenvoudige herinneringen in te stellen op basis van een afteltimer en met een bericht. Je kunt dit doen via `Super + Ctrl + R`, alle ingestelde herinneringen zien via `Super + Ctrl + Alt + R`, en alles wissen via `Super + Ctrl + Shift + R`. Alles is ook toegankelijk via _Activeren > Herinnering_. Je kunt ook de cli gebruiken met `omarchy reminder 7 'Tea ready'`.
