# Andere pakketten

Arch heeft een verbazingwekkende rijkdom aan pakketten beschikbaar voor bijna elk type software tussen de officiële repository en de Arch User Repository (AUR).

Het kan ook niet gemakkelijker zijn om te gebruiken. Je installeert een nieuw Arch-pakket door naar _Installeren > Pakket_ in het Omarchy-menu (`Super + Space`) te gaan en het pakket te typen dat je wilt. Het filtert automatisch fuzzy de lijst van alle pakketten. (Je kunt het ook handmatig doen met `omarchy pkg add [package]` in de terminal).

Je kunt hetzelfde doen met AUR, gebruik gewoon _Installeren > AUR_. Onthoud alleen dat de AUR niet wordt gecontroleerd door het Arch-team. Het is als RubyGems of npm. Iedereen kan uploaden.

Als je een pakket wilt verwijderen, kun je _Verwijderen > Pakket_ in het Omarchy-menu gebruiken. Het verwijdert het pakket, configuratiebestanden en afhankelijkheden. (Je kunt het ook handmatig doen met `omarchy pkg drop [package]`).
