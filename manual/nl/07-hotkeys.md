# Sneltoetsen

Je kunt alle belangrijkste toetsbindingen zien met `Super + K` (Tmux-bindingen met `Super + Alt + K` en Herdr-bindingen met `Super + Ctrl + K`).

| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy-menu (apps en al het andere)    |
| `Super + Alt + Space` | App-raster |
| `Super + Escape` | Systeemmenu (slaapstand, herstarten, enz.)  |
| `Super + Ctrl + L` | Computer vergrendelen |

| `Super + Alt + S` | Venster verplaatsen naar volledige scratchpad |

| `Super + Shift + Grave` | Venster verplaatsen naar Quake-console |
| `Super + Shift + Ctrl + Arrows` | Venster verplaatsen naar de monitor in die richting |
| `Super + Shift + Alt + Arrows` | Werkruimte verplaatsen naar de monitor in die richting |

| `Super + Minus` | Venster naar links uitbreiden |
| `Super + Equal` | Venster naar links verkleinen |
| `Super + Shift + Minus` | Venster naar boven verkleinen |
| `Super + Shift + Equal` | Venster naar beneden uitbreiden |
| `Super + Alt + Minus/Equal` | Zelfde formaatwijziging in kleinere stappen |
| `Super + Ctrl + Minus/Equal` | Zelfde formaatwijziging in grotere stappen |
| `Super + Alt + Home` | Vensterbreedte opslaan |
| `Super + Home` | Opgeslagen vensterbreedte herstellen |
| `Super + Left Mouse` | Venster rondslepen |
| `Super + Right Mouse` | Vensterformaat wijzigen |
| `Super + Scroll Wheel` | Scroll door werkruimtes op de gefocuste monitor |
| `Super + G`               | Venstergroepering wisselen      |
| `Super + Alt + G`               | Venster uit groepering halen      |
| `Super + Alt + Tab`               | Doorloop vensters in groepering      |
| `Super + Alt + Shift + Tab`               | Doorloop vensters in groepering achteruit      |
| `Super + Alt + Scroll Wheel` | Doorloop vensters in groepering |
| `Super + Alt + 1/2/3/4/5`               | Spring naar specifiek venster in groepering      |
| `Super + Alt + Arrow`  | Venster in groepering plaatsen in de richting van de pijl, inclusief een op de monitor aan die kant |
| `Super + Ctrl + Left/Right`  | Bewegen tussen vensters binnen een tiling-groep |
| `Super + Ctrl + Z` | Inzoomen op scherm (herhaal voor meer zoom) |
| `Super + Ctrl + Alt + Z` | Volledig uitzoomen van scherm |
| `Super + /` | Stap vooruit door monitor-schalingsopties |
| `Super + Alt + /` | Stap achteruit door monitor-schalingsopties |
| `Alt + Tab` | Doorloop vensters op de actieve werkruimte vooruit |
| `Alt + Shift + Tab` | Doorloop vensters op de actieve werkruimte achteruit |
| `Ctrl + Alt + Tab`| Focus vooruit doorlopen door monitors |
| `Ctrl + Alt + Shift + Tab`| Focus achteruit doorlopen door monitors |

Sneltoetsen voor formaatwijziging gebruiken de fysieke toetsen `code:20` en `code:21` (XKB `<AE11>` en `<AE12>`), ongeacht de tekens die op het toetsenbord zijn gedrukt. Op Amerikaanse toetsenborden zijn deze toetsen `-` en `=`; op Japanse (JIS) toetsenborden zijn ze `-` en `^`; op Spaanse toetsenborden zijn ze `'` en `¡`. Op JIS is `Super + ^` `Super + Equal`, terwijl `Super + Shift + -` (waarmee `=` wordt getypt) `Super + Shift + Minus` is.

## Universeel klembord

| Sneltoets                  | Functie              |
| ----------------------- | --------------------- |
| `Super + A`           | Alles selecteren in apps die `Ctrl + A` ondersteunen    |
| `Super + C`           | Kopiëren    |
| `Super + X`           | Knippen (niet in terminal)    |
| `Super + V`           | Plakken    |
| `Super + Ctrl + V`           | Klembordbeheerder    |

Normaal heb je op Linux `Ctrl + Shift + C/V` nodig om te copy'n'pasten in de terminal en `Ctrl + C/V` om het overal anders te doen. Deze uniforme klembord-sneltoetsen van Omarchy werken overal.

## Tmux

De prefix-toets is `Ctrl + Space` (`Ctrl + B` werkt ook). Je kunt deze bindingen wijzigen in `~/.config/tmux/tmux.conf`.

### Panelen

| Sneltoets                  | Functie              |
| ----------------------- | --------------------- |
| `Prefix + v` | Paneel ernaast splitsen (verticaal) |
| `Prefix + h` | Paneel eronder splitsen (horizontaal) |
| `Prefix + x` | Paneel beëindigen |
| `Prefix + z` | Paneelzoom wisselen (volledig scherm) |
| `Alt + Enter` | Paneel eronder splitsen (geen prefix) |
| `Alt + Shift + Enter` | Paneel ernaast splitsen (geen prefix) |
| `Alt + Escape` | Paneel beëindigen (geen prefix) |
