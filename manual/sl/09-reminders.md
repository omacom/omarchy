# Opomniki

Omarchy ima vgrajen način za nastavitev preprostih opomnikov na podlagi odštevalnika in s sporočilom. To lahko naredite prek `Super + Ctrl + R`, vse nastavljene si ogledate prek `Super + Ctrl + Alt + R`, vse počistite prek `Super + Ctrl + Shift + R`. Vse je dostopno tudi prek _Trigger > Reminder_. Uporabite lahko tudi cli z `omarchy reminder 7 'Tea ready'`.
