# Polices

Omarchy utilise JetBrainsMono Nerd Font comme police du terminal et du système par défaut.

 ![fonts-jetbrainsmono](images/fonts-jetbrainsmono.webp)

Vous pouvez changer cela via le menu _Style > Police_ dans le menu Omarchy (`Super + Space`). Cela définit la police à chasse fixe partout : le terminal, la barre et tout ce qui la demande.

Vous pouvez installer d'autres polices de programmation populaires via _Installer > Style > Police_ dans le menu Omarchy : Cascadia Mono, Meslo LG Mono, Fira Code, Victor Code, Bitstream Vera Mono et Iosevka sont tous à un clic, dans leurs versions Nerd Font pour que les glyphes de la barre et du terminal continuent de fonctionner. Après en avoir installé une, choisissez-la sous _Style > Police_.
