# Raccourcis clavier

Vous pouvez voir tous les principaux raccourcis clavier avec `Super + K` (raccourcis Tmux avec `Super + Alt + K` et raccourcis Herdr avec `Super + Ctrl + K`).

## Navigation

| Raccourci | Fonction |
| ----------------------- | --------------------- |
| `Super + Space`           | Menu Omarchy (applis et tout le reste) |
| `Super + Alt + Space` | Grille d'applis |
| `Super + Escape` | Menu Système (suspendre, redémarrer, etc) |
| `Super + Ctrl + L` | Verrouiller l'ordinateur |
| `Super + W` ou `Super + Q` | Fermer la fenêtre |
| `Ctrl + Alt + Del` | Fermer toutes les fenêtres |
| `Super + T`               | Basculer la fenêtre entre mosaïque/flottant |
| `Super + J` | Basculer la position de la fenêtre (horizontal/vertical) |
| `Super + O`               | Basculer la fenêtre détachée en collante et flottante |
| `Super + L`               | Parcourir les dispositions dwindle, défilement et flottante |
| `Super + Alt + L`         | Parcourir les dispositions dans l'ordre inverse |
| `Super + P`               | Basculer le style pseudo-fenêtre (naturel contre étiré) |
| `Super + F`                 | Passer en plein écran |
| `Super + Alt + F`                 | Passer en pleine largeur |
| `Super + Ctrl + F`                 | Passer en plein écran à l'intérieur de la fenêtre |
| `Super + 1/2/3/4`         | Sauter à un espace de travail précis |
| `Super + Tab` | Sauter à l'espace suivant |
| `Super + Shift + Tab` | Sauter à l'espace précédent |
| `Super + Ctrl + Tab` | Sauter à l'ancien espace |
| `Super + Shift + 1/2/3/4` | Déplacer la fenêtre vers un espace |
| `Super + Shift + Alt + 1/2/3/4` | Déplacer la fenêtre vers un espace sans la suivre |
| `Super + S` / `Super + Grave` | Basculer le scratchpad |
| `Super + Alt + S` / `Super + Shift + Grave` | Déplacer la fenêtre vers le scratchpad |
| `Super + Shift + Alt + Arrows` | Déplacer les espaces vers l'écran dans la direction |
| `Super + Arrow`  | Déplacer le focus vers la fenêtre dans la direction de la flèche |
| `Super + Shift + Arrow`  | Échanger la fenêtre avec une autre dans la direction de la flèche |
| `Super + Minus` | Élargir la fenêtre vers la gauche |
| `Super + Equal` | Rétrécir la fenêtre vers la gauche |
| `Super + Shift + Minus` | Rétrécir la fenêtre vers le haut |
| `Super + Shift + Equal` | Élargir la fenêtre vers le bas |
| `Super + Alt + Minus/Equal` | Même redimensionnement en plus petits pas |
| `Super + Ctrl + Minus/Equal` | Même redimensionnement en plus grands pas |
| `Super + Alt + Home` | Enregistrer la largeur de la fenêtre |
| `Super + Home` | Restaurer la largeur enregistrée |
| `Super + Left Mouse` | Faire glisser la fenêtre |
| `Super + Right Mouse` | Redimensionner la fenêtre |
| `Super + Scroll Wheel` | Faire défiler les espaces de travail |
| `Super + G`               | Basculer le regroupement de fenêtres |
| `Super + Alt + G`               | Sortir la fenêtre du groupe |
| `Super + Alt + Tab`               | Parcourir les fenêtres du groupe |
| `Super + Alt + Shift + Tab`               | Parcourir les fenêtres du groupe vers l'arrière |
| `Super + Alt + 1/2/3/4/5`               | Sauter à une fenêtre précise du groupe |
| `Super + Alt + Arrow`  | Déplacer la fenêtre dans le groupe dans la direction de la flèche |
| `Super + Ctrl + Left/Right`  | Se déplacer entre les fenêtres d'un groupe en mosaïque |
| `Super + Ctrl + Z` | Zoomer sur l'écran (répéter pour plus de zoom) |
| `Super + Ctrl + Alt + Z` | Dézoomer complètement de l'écran |
| `Super + /` | Avancer parmi les options d'échelle d'écran |
| `Super + Alt + /` | Reculer parmi les options d'échelle d'écran |
| `Alt + Tab` | Parcourir vers l'avant les fenêtres de l'espace actif |
| `Alt + Shift + Tab` | Parcourir vers l'arrière les fenêtres de l'espace actif |
| `Ctrl + Alt + Tab`| Parcourir le focus vers l'avant parmi les écrans |
| `Ctrl + Alt + Shift + Tab`| Parcourir le focus vers l'arrière parmi les écrans |

## Presse-papiers universel

| Raccourci | Fonction |
| ----------------------- | --------------------- |
| `Super + C`           | Copier |
| `Super + X`           | Couper (pas dans le terminal) |
| `Super + V`           | Coller |
| `Super + Ctrl + V`           | Gestionnaire de presse-papiers |

Habituellement sous Linux, vous avez besoin de `Ctrl + Shift + C/V` pour copier-coller dans le terminal et de `Ctrl + C/V` pour le faire partout ailleurs. Ces raccourcis de presse-papiers unifiés d'Omarchy fonctionnent partout.

## Capture

| Raccourci | Fonction |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Menu de capture (pour claviers sans bouton PrintScr) |
| `Print Screen`            | Capture d'écran |
| `Alt + Print Screen`            | Enregistrement d'écran |
| `Super + Print Screen` | Sélecteur de couleur |
| `Super + Ctrl + Print Screen` | Extraction de texte vers le presse-papiers |
| `Super + Alt + [` | Réduire l'overlay webcam pendant l'enregistrement |
| `Super + Alt + ]` | Agrandir l'overlay webcam pendant l'enregistrement |
| `Alt + Shift + L` | Copier l'URL actuelle depuis une web app ou Chromium |
| `Alt + Shift + D` | Télécharger la vidéo de la page actuelle dans `~/Videos` |
| `Super + Ctrl + X` | Démarrer/arrêter la dictée (nécessite _Configuration > Par défaut > Dictée_) |
| `Right Alt` / `F9` | Dictée push-to-talk (nécessite Voxtype ou Superwhisper) |

Avec les enregistrements d'écran, le raccourci demande d'abord quel audio vous voulez, puis démarre l'enregistrement. Refaites-le pour arrêter. Voir [captures d'écran et enregistrement](12-screenshots-recording.md) pour les détails.

Toutes les options de capture sont aussi accessibles sous _Déclencher > Capture_ dans le menu Omarchy (`Super + Space`).

## Tmux

La touche préfixe est `Ctrl + Space` (`Ctrl + B` fonctionne aussi). Vous pouvez changer ces raccourcis dans `~/.config/tmux/tmux.conf`.

### Panneaux

| Raccourci | Fonction |
| ----------------------- | --------------------- |
| `Prefix + v` | Diviser le panneau à côté (vertical) |
| `Prefix + h` | Diviser le panneau en dessous (horizontal) |
| `Prefix + x` | Tuer le panneau |
| `Prefix + z` | Basculer le zoom du panneau (plein écran) |
| `Alt + Enter` | Diviser le panneau en dessous (sans préfixe) |
| `Alt + Shift + Enter` | Diviser le panneau à côté (sans préfixe) |
| `Alt + Escape` | Tuer le panneau (sans préfixe) |
| `Ctrl + Alt + Arrows` | Se déplacer entre les panneaux |
| `Ctrl + Alt + Shift + Arrows` | Redimensionner les panneaux |

### Fenêtres

| Raccourci | Fonction |
| ----------------------- | --------------------- |
| `Prefix + c` | Nouvelle fenêtre |
| `Prefix + k` | Tuer la fenêtre |
| `Prefix + r` | Renommer la fenêtre |
| `Alt + 1-9` | Aller à une fenêtre précise |
| `Alt + Arrow Left/Right` | Se déplacer entre les fenêtres |
| `Alt + Shift + Arrow Left/Right` | Déplacer la fenêtre à gauche/droite |

### Sessions

| Raccourci | Fonction |
| ----------------------- | --------------------- |
| `Prefix + C` | Nouvelle session |
| `Prefix + K` | Tuer la session |
| `Prefix + R` | Renommer la session |
| `Prefix + N` | Session suivante |
| `Prefix + P` | Session précédente |
| `Alt + Arrow Up/Down` | Se déplacer entre les sessions |
| `Prefix + s` | Lister les sessions |
| `Prefix + d` | Se détacher de la session |

### Mode copie (style vi)

| Raccourci | Fonction |
| ----------------------- | --------------------- |
| `Prefix + [` | Entrer en mode copie |
| `v` | Commencer la sélection (en mode copie) |
| `y` | Copier la sélection (en mode copie) |

### Général

| Raccourci | Fonction |
| ----------------------- | --------------------- |
| `Prefix + q` | Recharger la configuration |
| `Prefix + ?` | Afficher les raccourcis Tmux |
| `Prefix + :` | Invite de commande |

### Fonctions de disposition Tmux

Ces fonctions doivent être exécutées à l'intérieur d'une session Tmux.

| Commande | Fonction |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Créer une disposition dev avec éditeur, IA et terminal |
| `tdlm <ai> [<second_ai>]` | Créer une disposition dev par sous-répertoire |
| `tsl <count> <command>` | Créer une disposition essaim multi-panneaux |
