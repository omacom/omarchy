# Remplir des PDF

Omarchy est livré avec un visualiseur PDF basique et agréable appelé Document Viewer. C'est le programme qui ouvrira tous les PDF sur lesquels vous double-cliquez simplement.

Mais vous ne pouvez utiliser Document Viewer que pour remplir des PDF qui ont été configurés comme formulaires. Si vous devez remplir des PDF qui ne le sont pas, ou si vous devez signer un PDF, utilisez [Signed](https://github.com/omacom/signed). Démarrez-le via le lanceur d'applications (`Super + Space`), ou faites un clic droit sur le fichier, sélectionnez _Open With..._, et choisissez Signed.

Appuyez sur `T` pour taper du texte et sur `D` pour placer la date du jour. Les deux atterrissent là où se trouve le pointeur de votre souris. Faites glisser n'importe quel élément pour le déplacer, faites glisser son coin pour le rendre plus grand ou plus petit, et double-cliquez sur le texte pour le modifier.

Pour signer, vous aurez besoin d'une image de votre signature : un scan, ou une photo bien éclairée de celle-ci sur du papier blanc. Ouvrez le menu _Signature_ (`Shift + S`), choisissez _Add signature..._, sélectionnez l'image, et donnez-lui un nom. Signed retire le papier et garde l'encre. À partir de là, `S` place votre signature sous le pointeur de la souris.

Quand vous avez terminé, utilisez _Save signed copy..._ (`Ctrl + S`) pour enregistrer le PDF rempli à côté de l'original, qui n'est jamais modifié. Appuyez sur `?` dans Signed pour voir tous les raccourcis.
