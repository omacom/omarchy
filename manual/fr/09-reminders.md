# Rappels

Omarchy dispose d'un moyen intégré pour définir de simples rappels basés sur un compte à rebours et accompagnés d'un message. Vous pouvez le faire via `Super + Ctrl + R`, voir tous ceux qui sont définis via `Super + Ctrl + Alt + R`, et tout effacer via `Super + Ctrl + Shift + R`. Tout est également accessible via _Déclencher > Rappel_. Vous pouvez aussi utiliser la CLI avec `omarchy reminder 7 'Tea ready'`.
