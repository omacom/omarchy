# Autres paquets

Arch dispose d'une richesse incroyable de paquets disponibles pour presque tous les types de logiciels, entre le dépôt officiel et l'Arch User Repository (AUR).

Ça ne pourrait pas être plus facile à utiliser non plus. Vous installez un nouveau paquet Arch en allant dans _Installer > Paquet_ dans le menu Omarchy (`Super + Space`) et en tapant le paquet que vous voulez. Il filtrera automatiquement par recherche floue la liste de tous les paquets. (Vous pouvez aussi le faire manuellement avec `omarchy pkg add [package]` dans le terminal).

Vous pouvez faire la même chose avec l'AUR, utilisez simplement _Installer > AUR_. Rappelez-vous juste que l'AUR n'est pas validé par l'équipe Arch. C'est comme RubyGems ou npm. N'importe qui peut téléverser.

Si vous voulez supprimer un paquet, vous pouvez utiliser _Supprimer > Paquet_ depuis le menu Omarchy. Il supprimera le paquet, les fichiers de configuration et les dépendances. (Vous pouvez aussi le faire manuellement avec `omarchy pkg drop [package]`).
