# Fylla i PDF:er

Omarchy levereras med en trevlig, grundläggande PDF-visare som heter Document Viewer. Det är programmet som öppnar alla PDF:er du bara dubbelklickar på.

Men du kan bara använda Document Viewer för att fylla i PDF:er som har satts upp som formulär. Om du behöver fylla i PDF:er som inte har det, eller om du behöver signera en PDF, använd [Signed](https://github.com/omacom/signed). Starta den via app-launchern (`Super + Space`), eller högerklicka på filen, välj _Open With..._ och välj Signed.

Tryck `T` för att skriva text och `D` för att sätta ner dagens datum. Båda landar där din muspekare är. Dra vad som helst för att flytta det, dra i dess hörn för att göra det större eller mindre, och dubbelklicka på text för att ändra den.

För att signera behöver du en bild på din signatur: en skanning, eller ett välbelyst foto av den på vitt papper. Öppna menyn _Signature_ (`Shift + S`), välj _Add signature..._, välj bilden och ge den ett namn. Signed tar bort papperet och behåller bläcket. Från och med då lägger `S` din signatur under muspekaren.

När du är klar, använd _Save signed copy..._ (`Ctrl + S`) för att spara den ifyllda PDF:en bredvid originalet, som aldrig ändras. Tryck `?` inne i Signed för att se varje genväg.
