# Påminnelser

Omarchy har ett inbyggt sätt att ställa in enkla påminnelser baserade på en nedräkningstimer och med ett meddelande. Du kan göra detta via `Super + Ctrl + R`, se alla inställda via `Super + Ctrl + Alt + R` och rensa alla via `Super + Ctrl + Shift + R`. Allt är också tillgängligt via _Trigger > Reminder_. Du kan också använda cli med `omarchy reminder 7 'Tea ready'`.
