# Snabbtangenter

Du kan se alla huvudsakliga tangentbindningar med `Super + K` (Tmux-bindningar med `Super + Alt + K` och Herdr-bindningar med `Super + Ctrl + K`).

## Navigering

| Snabbtangent                  | Funktion              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy-menyn (appar och allt annat)    |
| `Super + Alt + Space` | Apprutnät |
| `Super + Escape` | Systemmeny (viloläge, omstart osv.)  |
| `Super + Ctrl + L` | Lås datorn |
| `Super + W` eller `Super + Q` | Stäng fönster             |
| `Ctrl + Alt + Del` | Stäng alla fönster |
| `Super + T`               | Växla fönstret mellan kaklat och flytande läge             |
| `Super + J` | Växla fönsterposition (horisontell/vertikal) |
| `Super + O`               | Växla om fönstret ska poppa upp som sticky'n'floating |
| `Super + L`               | Bläddra igenom layouterna dwindle, scrolling och floating |
| `Super + Alt + L`         | Bläddra igenom layouterna i omvänd ordning |
| `Super + P`               | Växla pseudo-fönsterstil (natural mot stretch) |
| `Super + F`                 | Gå till helskärm              |
| `Super + Alt + F`                 | Gå till full bredd              |
| `Super + Ctrl + F`                 | Gå till helskärm inuti fönstret              |
| `Super + 1/2/3/4`         | Hoppa till specifik arbetsyta på den fokuserade skärmen |
| `Super + Tab` | Hoppa till nästa arbetsyta på den fokuserade skärmen |
| `Super + Shift + Tab` | Hoppa till föregående arbetsyta på den fokuserade skärmen |
| `Super + Ctrl + Tab` | Hoppa till tidigare arbetsyta på den fokuserade skärmen |
| `Super + Shift + 1/2/3/4` | Flytta fönstret till en arbetsyta på den fokuserade skärmen |
| `Super + Shift + Alt + 1/2/3/4` | Flytta fönstret till en arbetsyta på den fokuserade skärmen utan att följa efter |
| `Super + S` | Växla full scratchpad |
| `Super + Alt + S` | Flytta fönstret till full scratchpad |
| `Super + Grave` | Växla Quake-konsolen |
| `Super + Shift + Grave` | Flytta fönstret till Quake-konsolen |
| `Super + Shift + Ctrl + Arrows` | Flytta fönstret till skärmen i den riktningen |
| `Super + Shift + Alt + Arrows` | Flytta arbetsytan till skärmen i den riktningen |
| `Super + Arrow`  | Flytta fokus till fönstret i pilens riktning, och gå över till skärmen på den sidan vid skärmkanten |
| `Super + Shift + Arrow`  | Byt plats på fönstret med ett annat i pilens riktning, inklusive ett på skärmen på den sidan |
| `Super + Minus` | Expandera fönstret åt vänster |
| `Super + Equal` | Krymp fönstret åt vänster |
| `Super + Shift + Minus` | Krymp fönstret uppåt |
| `Super + Shift + Equal` | Expandera fönstret nedåt |
| `Super + Alt + Minus/Equal` | Samma storleksändring i mindre steg |
| `Super + Ctrl + Minus/Equal` | Samma storleksändring i större steg |
| `Super + Alt + Home` | Spara fönsterbredd |
| `Super + Home` | Återställ sparad fönsterbredd |
| `Super + Left Mouse` | Dra runt fönstret |
| `Super + Right Mouse` | Ändra storlek på fönstret |
| `Super + Scroll Wheel` | Scrolla igenom arbetsytor på den fokuserade skärmen |
| `Super + G`               | Växla fönstergruppering      |
| `Super + Alt + G`               | Flytta ut fönstret ur grupperingen      |
| `Super + Alt + Tab`               | Bläddra mellan fönster i grupperingen      |
| `Super + Alt + Shift + Tab`               | Bläddra bakåt mellan fönster i grupperingen      |
| `Super + Alt + Scroll Wheel` | Bläddra mellan fönster i grupperingen |
| `Super + Alt + 1/2/3/4/5`               | Hoppa till specifikt fönster i grupperingen      |
| `Super + Alt + Arrow`  | Flytta in fönstret i grupperingen i pilens riktning, inklusive ett på skärmen på den sidan |
| `Super + Ctrl + Left/Right`  | Flytta mellan fönster inuti en tiling-grupp |
| `Super + Ctrl + Z` | Zooma in på skärmen (upprepa för mer zoom) |
| `Super + Ctrl + Alt + Z` | Zooma ut helt från skärmen |
| `Super + /` | Stega framåt genom skärmskalningsalternativen |
| `Super + Alt + /` | Stega bakåt genom skärmskalningsalternativen |
| `Alt + Tab` | Bläddra framåt genom fönster på den aktiva arbetsytan |
| `Alt + Shift + Tab` | Bläddra bakåt genom fönster på den aktiva arbetsytan |
| `Ctrl + Alt + Tab`| Bläddra fokus framåt genom skärmar |
| `Ctrl + Alt + Shift + Tab`| Bläddra fokus bakåt genom skärmar |

## Universellt urklipp

| Snabbtangent                  | Funktion              |
| ----------------------- | --------------------- |
| `Super + C`           | Kopiera    |
| `Super + X`           | Klipp ut (inte i terminalen)    |
| `Super + V`           | Klistra in    |
| `Super + Ctrl + V`           | Urklippshanterare    |

Normalt på Linux behöver du `Ctrl + Shift + C/V` för att kopiera'n'klistra in i terminalen och `Ctrl + C/V` för att göra det överallt annars. Dessa enhetliga snabbtangenter för urklipp i Omarchy fungerar överallt.

## Fångst

| Snabbtangent              | Funktion                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Skärmbild                      |
| `Super + Ctrl + Alt + C`            | Skärmbild (samma bild, för tangentbord utan Print Screen-tangent) |
| `Super + Ctrl + C` | Fångstmeny |
| `Alt + Print Screen`            | Skärminspelning                     |
| `Super + Print Screen` | Färgväljare |
| `Super + Ctrl + Print Screen` | Textextrahering till urklipp |
| `Super + Alt + [` | Gör webbkameraöverlägget mindre under inspelning |
| `Super + Alt + ]` | Gör webbkameraöverlägget större under inspelning |
| `Alt + Shift + L` | Kopiera aktuell URL från webbapp eller Chromium |
| `Alt + Shift + D` | Ladda ner videon på den aktuella sidan till `~/Videos` |
| `Super + Ctrl + X` | Starta/stoppa diktering (kräver _Inställningar > Standard > Diktering_) |
| `Right Alt` / `F9` | Push-to-talk-diktering (kräver Voxtype eller Superwhisper) |

Med skärminspelningar frågar snabbtangenten först vilket ljud du vill ha, sedan startar inspelningen. Tryck på den igen för att stoppa. Se [skärmbilder och inspelning](12-screenshots-recording.md) för detaljerna.

Alla fångstalternativ finns också under _Utlösare > Fångst_ i Omarchy-menyn (`Super + Space`).

## Stil

Alla stilalternativ finns också under _Stil_ i Omarchy-menyn (`Super + Space`).

## Tmux

Prefix-tangenten är `Ctrl + Space` (`Ctrl + B` fungerar också). Du kan ändra dessa bindningar i `~/.config/tmux/tmux.conf`.

### Paneler

| Snabbtangent                  | Funktion              |
| ----------------------- | --------------------- |
| `Prefix + v` | Dela panelen bredvid (vertikal) |
| `Prefix + h` | Dela panelen nedanför (horisontell) |
| `Prefix + x` | Stäng panelen |
| `Prefix + z` | Växla panelzoom (helskärm) |
| `Alt + Enter` | Dela panelen nedanför (utan prefix) |
| `Alt + Shift + Enter` | Dela panelen bredvid (utan prefix) |
| `Alt + Escape` | Stäng panelen (utan prefix) |
| `Ctrl + Alt + Arrows` | Flytta mellan paneler |
| `Ctrl + Alt + Shift + Arrows` | Ändra storlek på paneler |

### Fönster

| Snabbtangent                  | Funktion              |
| ----------------------- | --------------------- |
| `Prefix + c` | Nytt fönster |
| `Prefix + k` | Stäng fönster |
| `Prefix + r` | Byt namn på fönster |
| `Alt + 1-9` | Gå till specifikt fönster |
| `Alt + Arrow Left/Right` | Flytta mellan fönster |
| `Alt + Shift + Arrow Left/Right` | Flytta fönstret åt vänster/höger |

### Sessioner

| Snabbtangent                  | Funktion              |
| ----------------------- | --------------------- |
| `Prefix + C` | Ny session |
| `Prefix + K` | Stäng sessionen |
| `Prefix + R` | Byt namn på sessionen |
| `Prefix + N` | Nästa session |
| `Prefix + P` | Föregående session |
| `Alt + Arrow Up/Down` | Flytta mellan sessioner |
| `Prefix + s` | Lista sessioner |
| `Prefix + d` | Koppla från sessionen |

### Kopieringsläge (vi-stil)

| Snabbtangent                  | Funktion              |
| ----------------------- | --------------------- |
| `Prefix + [` | Gå in i kopieringsläge |
| `v` | Börja markera (i kopieringsläge) |
| `y` | Kopiera markeringen (i kopieringsläge) |

### Allmänt

| Snabbtangent                  | Funktion              |
| ----------------------- | --------------------- |
| `Prefix + q` | Ladda om konfigurationen |
| `Prefix + ?` | Visa Tmux-tangentbindningar |
| `Prefix + :` | Kommandoprompt |

### Tmux-layoutfunktioner

Dessa funktioner måste köras inuti en Tmux-session.

| Kommando | Funktion |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Skapa dev-layout med redigerare, AI och terminal |
| `tdlm <ai> [<second_ai>]` | Skapa dev-layout per underkatalog |
| `tsl <count> <command>` | Skapa swarm-layout med flera paneler |
