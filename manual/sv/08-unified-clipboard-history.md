# Enhetligt urklipp & historik

Vanligtvis på Linux behöver du `Ctrl + Shift + C/V` för att kopiera och klistra in i terminalen och `Ctrl + C/V` för att göra det överallt annars. Det är svårt att vänja sig vid för alla som inte är födda och uppvuxna med Linux! Det är också bytet från super till ctrl, om du kommer från Mac.

Omarchy tacklar båda problemen med enhetliga urklipps-snabbtangenter som fungerar (nästan) överallt. De är:

| Snabbtangent | Kommando |
| ------- | ----------- |
| Super + C | Kopiera |
| Super + X | Klipp ut |
| Super + V | Klistra in |
| Super + Ctrl + V | Urklippshistorik |

_Observera att de flesta agentharnesser använder `Ctrl + V` för att klistra in bilder, men `Super + V` för att klistra in text._

### Urklippshistorik

Urklippshistoriken tillhandahålls av Omarchy-skalet och fungerar för både text och bilder. Du utlöser den med `Super + Ctrl + V`, väljer din post med retur, och sedan placeras den på urklippet redo att klistras in med `Super + V`.
