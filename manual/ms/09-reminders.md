# Peringatan

Omarchy mempunyai cara terbina dalam untuk menetapkan Peringatan ringkas berdasarkan pemasa kira detik dan dengan mesej. Anda boleh melakukannya melalui `Super + Ctrl + R`, melihat semua yang ditetapkan melalui `Super + Ctrl + Alt + R`, dan memadam semua melalui `Super + Ctrl + Shift + R`. Segala-galanya juga boleh diakses melalui _Pencetus > Peringatan_. Anda juga boleh menggunakan cli dengan `omarchy reminder 7 'Tea ready'`.
