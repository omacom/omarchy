# Kekunci Panas

Anda boleh melihat semua ikatan papan kekunci utama dengan `Super + K` (ikatan Tmux dengan `Super + Alt + K` dan ikatan Herdr dengan `Super + Ctrl + K`).

## Menavigasi

| Kekunci Panas                  | Fungsi              |
| ----------------------- | --------------------- |
| `Super + Space`           | Menu Omarchy (aplikasi dan segala-galanya yang lain)    |
| `Super + Alt + Space` | Grid aplikasi |
| `Super + Escape` | Menu sistem (tidur, mulakan semula, dll)  |
| `Super + Ctrl + L` | Kunci komputer |
| `Super + W` or `Super + Q` | Tutup tetingkap             |
| `Ctrl + Alt + Del` | Tutup semua tetingkap |
| `Super + T`               | Togol tetingkap antara jubinan/terapung             |
| `Super + J` | Togol kedudukan tetingkap (mendatar/menegak) |
| `Super + O`               | Togol mengeluarkan tetingkap menjadi melekat dan terapung |
| `Super + L`               | Kitar melalui susun atur dwindle, penatalan, dan terapung |
| `Super + Alt + L`         | Kitar melalui susun atur dalam arah songsang |
| `Super + P`               | Togol gaya tetingkap pseudo (semula jadi lwn regang) |
| `Super + F`                 | Pergi ke skrin penuh              |
| `Super + Alt + F`                 | Pergi ke lebar penuh              |
| `Super + Ctrl + F`                 | Pergi ke skrin penuh di dalam tetingkap              |
| `Super + 1/2/3/4`         | Lompat ke ruang kerja tertentu     |
| `Super + Tab` | Lompat ke ruang kerja seterusnya |
| `Super + Shift + Tab` | Lompat ke ruang kerja sebelumnya |
| `Super + Ctrl + Tab` | Lompat ke ruang kerja dahulu |
| `Super + Shift + 1/2/3/4` | Pindah tetingkap ke ruang kerja |
| `Super + Shift + Alt + 1/2/3/4` | Pindah tetingkap ke ruang kerja tanpa mengikuti |
| `Super + S` / `Super + Grave` | Togol pad conteng |
| `Super + Alt + S` / `Super + Shift + Grave` | Pindah tetingkap ke pad conteng |
| `Super + Shift + Alt + Arrows` | Pindah ruang kerja ke monitor berarah |
| `Super + Arrow`  | Pindah fokus ke tetingkap dalam arah anak panah              |
| `Super + Shift + Arrow`  | Tukar tetingkap dengan yang lain dalam arah anak panah     |
| `Super + Minus` | Kembangkan tetingkap ke kiri |
| `Super + Equal` | Kecilkan tetingkap ke kiri |
| `Super + Shift + Minus` | Kecilkan tetingkap ke atas |
| `Super + Shift + Equal` | Kembangkan tetingkap ke bawah |
| `Super + Alt + Minus/Equal` | Pengubahan saiz yang sama dalam langkah lebih kecil |
| `Super + Ctrl + Minus/Equal` | Pengubahan saiz yang sama dalam langkah lebih besar |
| `Super + Alt + Home` | Simpan lebar tetingkap |
| `Super + Home` | Pulihkan lebar tetingkap yang disimpan |
| `Super + Left Mouse` | Seret tetingkap ke sekeliling |
| `Super + Right Mouse` | Ubah saiz tetingkap |
| `Super + Scroll Wheel` | Tatal melalui ruang kerja |
| `Super + G`               | Togol pengumpulan tetingkap      |
| `Super + Alt + G`               | Pindah tetingkap keluar daripada kumpulan      |
| `Super + Alt + Tab`               | Kitar antara tetingkap dalam kumpulan      |
| `Super + Alt + Shift + Tab`               | Kitar ke belakang antara tetingkap dalam kumpulan      |
| `Super + Alt + 1/2/3/4/5`               | Lompat ke tetingkap tertentu dalam kumpulan      |
| `Super + Alt + Arrow`  | Pindah tetingkap ke dalam kumpulan dalam arah anak panah  |
| `Super + Ctrl + Left/Right`  | Bergerak antara tetingkap di dalam kumpulan jubinan |
| `Super + Ctrl + Z` | Zum masuk pada skrin (ulang untuk lebih banyak zum) |
| `Super + Ctrl + Alt + Z` | Zum sepenuhnya keluar dari skrin |
| `Super + /` | Melangkah ke hadapan melalui pilihan penskalaan monitor |
| `Super + Alt + /` | Melangkah ke belakang melalui pilihan penskalaan monitor |
| `Alt + Tab` | Kitar ke hadapan melalui tetingkap pada ruang kerja aktif |
| `Alt + Shift + Tab` | Kitar ke belakang melalui tetingkap pada ruang kerja aktif |
| `Ctrl + Alt + Tab`| Kitar fokus ke hadapan melalui monitor |
| `Ctrl + Alt + Shift + Tab`| Kitar fokus ke belakang melalui monitor |

## Papan keratan universal

| Kekunci Panas                  | Fungsi              |
| ----------------------- | --------------------- |
| `Super + C`           | Salin    |
| `Super + X`           | Potong (bukan dalam terminal)    |
| `Super + V`           | Tampal    |
| `Super + Ctrl + V`           | Pengurus papan keratan    |

Biasanya pada Linux, anda memerlukan `Ctrl + Shift + C/V` untuk salin dan tampal dalam terminal dan `Ctrl + C/V` untuk melakukannya di mana-mana sahaja. Kekunci panas papan keratan bersepadu Omarchy ini berfungsi di mana-mana.

## Tangkap

| Kekunci Panas              | Fungsi                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Menu tangkap (untuk papan kekunci tanpa butang PrintScr) |
| `Print Screen`            | Tangkap Skrin                      |
| `Alt + Print Screen`            | Rakam Skrin                     |
| `Super + Print Screen` | Pemilih warna |
| `Super + Ctrl + Print Screen` | Pengekstrakan teks ke papan keratan |
| `Super + Alt + [` | Kecilkan tindanan webcam semasa merakam |
| `Super + Alt + ]` | Besarkan tindanan webcam semasa merakam |
| `Alt + Shift + L` | Salin URL semasa dari webapp atau Chromium |
| `Alt + Shift + D` | Muat turun video pada halaman semasa ke `~/Videos` |
| `Super + Ctrl + X` | Mula/henti pendiktean (memerlukan _Persediaan > Lalai > Pendiktean_) |
| `Right Alt` / `F9` | Pendiktean tekan-untuk-bercakap (memerlukan Voxtype atau Superwhisper) |

Dengan rakaman skrin, kekunci panas mula-mula bertanya audio mana yang anda mahukan, kemudian mula merakam. Tekannya sekali lagi untuk berhenti. Lihat [tangkap skrin dan rakaman](12-screenshots-recording.md) untuk butirannya.

Semua pilihan tangkap juga boleh diakses di bawah _Pencetus > Tangkap_ dalam menu Omarchy (`Super + Space`).

## Tmux

Kekunci awalan ialah `Ctrl + Space` (`Ctrl + B` juga berfungsi). Anda boleh menukar ikatan ini dalam `~/.config/tmux/tmux.conf`.

### Anak tetingkap

| Kekunci Panas                  | Fungsi              |
| ----------------------- | --------------------- |
| `Prefix + v` | Pisah anak tetingkap di sebelah (menegak) |
| `Prefix + h` | Pisah anak tetingkap di bawah (mendatar) |
| `Prefix + x` | Bunuh anak tetingkap |
| `Prefix + z` | Togol zum anak tetingkap (skrin penuh) |
| `Alt + Enter` | Pisah anak tetingkap di bawah (tanpa awalan) |
| `Alt + Shift + Enter` | Pisah anak tetingkap di sebelah (tanpa awalan) |
| `Alt + Escape` | Bunuh anak tetingkap (tanpa awalan) |
| `Ctrl + Alt + Arrows` | Bergerak antara anak tetingkap |
| `Ctrl + Alt + Shift + Arrows` | Ubah saiz anak tetingkap |

### Tetingkap

| Kekunci Panas                  | Fungsi              |
| ----------------------- | --------------------- |
| `Prefix + c` | Tetingkap baharu |
| `Prefix + k` | Bunuh tetingkap |
| `Prefix + r` | Namakan semula tetingkap |
| `Alt + 1-9` | Pergi ke tetingkap tertentu |
| `Alt + Arrow Left/Right` | Bergerak antara tetingkap |
| `Alt + Shift + Arrow Left/Right` | Pindah tetingkap ke kiri/kanan |

### Sesi

| Kekunci Panas                  | Fungsi              |
| ----------------------- | --------------------- |
| `Prefix + C` | Sesi baharu |
| `Prefix + K` | Bunuh sesi |
| `Prefix + R` | Namakan semula sesi |
| `Prefix + N` | Sesi seterusnya |
| `Prefix + P` | Sesi sebelumnya |
| `Alt + Arrow Up/Down` | Bergerak antara sesi |
| `Prefix + s` | Senaraikan sesi |
| `Prefix + d` | Tanggalkan dari sesi |

### Mod salin (gaya vi)

| Kekunci Panas                  | Fungsi              |
| ----------------------- | --------------------- |
| `Prefix + [` | Masuki mod salin |
| `v` | Mulakan pemilihan (dalam mod salin) |
| `y` | Salin pemilihan (dalam mod salin) |

### Umum

| Kekunci Panas                  | Fungsi              |
| ----------------------- | --------------------- |
| `Prefix + q` | Muat semula konfigurasi |
| `Prefix + ?` | Papar ikatan kekunci Tmux |
| `Prefix + :` | Gesaan arahan |

### Fungsi susun atur Tmux

Fungsi ini mesti dijalankan di dalam sesi Tmux.

| Arahan | Fungsi |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Cipta susun atur pembangunan dengan penyunting, AI, dan terminal |
| `tdlm <ai> [<second_ai>]` | Cipta susun atur pembangunan bagi setiap subdirektori |
| `tsl <count> <command>` | Cipta susun atur kawanan berbilang anak tetingkap |
