### Memasang dan mengemas kini ejen

Kecuali Hermes, ejen ini menggunakan pemasangan malas mise: pelancaran pertama memasang CLI, dan pelancaran kemudian menggunakannya semula. mise juga menyemak ejen yang dipasang untuk keluaran baharu paling kerap sekali setiap empat jam, sejurus sebelum ia bermula atau di latar belakang pada gesaan shell. Jika kemas kini itu gagal atau anda di luar talian, versi yang dipasang akan berjalan. `omarchy update` mengemas kini ejen yang dipasang bersama-sama Omarchy yang lain, dan `mup` mengemas kini alat yang diurus mise sahaja.

Pengemas kini ejen sendiri, seperti `claude update`, `codex update`, atau butang kemas kini dalam aplikasi, tidak mengemas kini pemasangan yang diurus mise. `codex update` gagal, dan `claude update` boleh melaporkan kejayaan sambil memasang salinan berasingan yang tidak dijejak oleh mise. Jika anda lebih suka menggunakan pemasang dan pengemas kini natif ejen, tambahkannya pada `disable_tools`; lihat [Preinstalled CLI tools](18-development-tools.md#preinstalled-cli-tools).

Untuk memasang semua alat malas yang dikonfigurasikan sebelum anda memerlukannya, jalankan `mise install --include-lazy`. Ini termasuk alat CLI lalai Omarchy yang lain serta ejen. Lihat [Preinstalled CLI tools](18-development-tools.md#preinstalled-cli-tools) untuk memasang satu alat atau menggunakan pemasangan anda sendiri.

`grok` dipasang melalui pakej pihak pertama mise `grok`, dengan cara yang sama seperti `claude` dan `codex`. Jalankan `grok`, atau pilihnya di bawah _Setup > Defaults > Agent_. Langkau pemasang `curl | bash` di x.ai. Laluan itu meletakkan salinan kedua dalam `~/.grok/bin`, mendahulukannya pada `PATH`, dan menulis ganti pembalut Omarchy.

`dsh` membuka UI pelayarnya pada `127.0.0.1:3080`, dengan direktori pelancaran sebagai ruang kerja lalainya. UI pelayarnya tidak mengambil gesaan permulaan, jadi `omarchy agent prompt` membukanya dengan gesaan pada papan keratan anda untuk ditampal. Omarchy memulakannya dengan pratetap kebenaran tanpa kelulusan DeepSeek. DeepSeek Harness memuat naik log sesi ke DeepSeek apabila anda menggunakan API model rasminya; matikan itu di bawah _Settings > General > Upload Session Log_ dalam UI pelayarnya. Maklum balas yang anda hantar kepadanya turut dimuat naik bersama sesi, melainkan anda memulakannya dengan `DSH_TELEMETRY_MODE=DISABLED`.

### Ejen lalai

Pilih ejen lalai anda dengan `omarchy default agent <name>` atau di bawah _Setup > Defaults > Agent_ dalam Menu Omarchy (`Super + Space`). Jika ejen belum dipasang, memilihnya akan memasangnya dahulu. Omarchy baharu akan menjemput anda membuat pilihan ini dengan pemberitahuan sekali sahaja.

Memilih Claude juga cuba menyediakan sambungan pelayarnya untuk Chromium, Chrome, Brave, Brave Origin, dan Edge. Penyediaan sambungan digunakan untuk semua pengguna dan mungkin meminta kata laluan sistem anda; membatalkan atau pemasangan sambungan yang gagal tetap memilih dan melancarkan Claude. Mulakan semula pelayar anda, dayakan sambungan jika digesa, dan log masuk ke Claude untuk selesai menyambungkannya. Jalankan `/chrome` dalam Claude untuk menyemak sambungan. Firefox dan Zen tidak menyokong sambungan ini. Jika Claude sudah menjadi lalai anda sebelum penyediaan ini ditambah, pilihnya semula untuk memasang sambungan.

Sebaik sahaja anda memilih, `Super + Shift + Ctrl + A` melancarkan ejen lalai dalam tetingkap terminal khusus (atau memaparkan pemilih jika anda belum memilih). Anda juga boleh melancarkannya terus ke dalam tugas dengan `omarchy agent prompt "Review this project"`. Freebuff dan DeepSeek Harness tidak mengambil gesaan permulaan, jadi ia dibuka dengan gesaan pada papan keratan anda untuk ditampal sebaliknya. Ejen yang dilancarkan dengan cara ini berjalan tanpa pengawasan dalam mod jangan-berhenti-untuk-bertanya masing-masing, jadi bersedialah kerana ia benar-benar akan melakukan sesuatu! MiniMax Code tidak mempunyai mod sedemikian untuk sesi interaktifnya, jadi ia meminta kebenaran seperti biasa. Dan memandangkan ejen enggan mengingati kepercayaan untuk direktori rumah anda, pelancaran dari `$HOME` bermula dalam `~/Work` sebaliknya.

Terdapat pintasan terminal juga: `a` menjalankan ejen lalai sebaris dalam terminal semasa, manakala `c`, `cx`, dan `cy` memulakan OpenCode, Claude Code, dan Codex secara langsung (sekali lagi dalam mod kelulusan automatiknya). Perubahan tema turut disegerakkan kepada ejen: Claude Code, Pi, OpenCode, dan Hermes (sebaik sahaja Omarchy memasangnya) semuanya mengikut apabila anda menukar tema Omarchy.

### Panel ejen

Bar atas mempunyai ikon ejen. Sebelum anda menyediakan ejen, panelnya membimbing anda log masuk ke Claude, Codex, atau Grok, dan yang pertama menjadi ejen lalai anda. Selepas itu, panel meletakkan setiap langganan pada satu halaman: setiap ejen dan akaun dengan pelannya, meter untuk setiap had sesi 5 jam dan had mingguannya dengan masa sehingga ia ditetapkan semula (tuding untuk peratusan tepat), atau baki prabayar yang tinggal, di bawah baris yang berputar melalui apa yang telah anda gunakan merentas semuanya, seperti token minggu ini dan model anda yang paling banyak digunakan. Di bawah _Make something_ ia menawarkan gesaan permulaan untuk tema, plugin, atau aplikasi baharu yang menyerahkan tugas kepada ejen lalai anda. Aplikasi dibina dengan cara Hype, Monologue, dan Omacut milik Omarchy sendiri dibina, dalam C++ dan Qt Quick, mengikut skill ejen omarchy-app, dan pengkompil serta bahagian Qt yang diperlukannya dipasang sekali. Claude Code, Codex, Grok, Kimi, Cursor dan elaun Grok Botnya, GitHub Copilot, Muse, Antigravity, Kimchi, dan Devin diliputi terus dari kotak dengan hadnya, dan Hermes, Mistral Vibe, dan Qwen Code menunjukkan sesi dan tokennya sebaik sahaja anda menggunakannya. Pelan dan kunci pembekal yang anda gunakan melalui pi, omp, atau opencode turut muncul: OpenCode Zen dan Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan, dan Synthetic dengan hadnya; Fireworks, OpenRouter, dan DeepSeek dengan baki prabayarnya; dan model yang anda jalankan pada perkakasan anda sendiri di bawah Local models. Setiap ejen dikira sekali, di bawah pihak yang mengebilnya, tidak kira berapa banyak harness yang anda gunakan untuk menjalankannya.

Klik kiri ikon bar untuk panel, klik kanan untuk melancarkan ejen lalai anda. Rekod penggunaan di belakangnya dijana semula setiap 15 minit oleh `omarchy agent usage-update`, dan panel malah boleh menggabungkan penggunaan daripada mesin anda yang lain melalui folder yang disegerakkan. Lihat README di bawah `$OMARCHY_PATH/shell/plugins/agents/` untuk tetapan penuh.

### Beberapa langganan

Jika anda membayar lebih daripada satu pelan Claude, Codex, atau Grok — Max peribadi dan satu untuk kerja, katakan — Omarchy boleh memastikan semuanya log masuk dan beralih antara mereka. Tambah langganan dengan + dalam panel ejen, yang membimbing anda melaluinya di situ, atau dengan `omarchy agent account add claude Work` (atau `codex`, atau `grok`). Ia memasang CLI jika tiada. Akaun pertama untuk pembekal log masuk melalui pelayar biasa anda, betul-betul di tempat CLI sentiasa mencari. Setiap akaun selepas itu log masuk melalui tetingkap peribadi, supaya akaun yang pelayar anda sudah log masuk tidak terambil secara tidak sengaja; log masuk di sana sebagai akaun yang anda tambah, dan tutup mana-mana tetingkap peribadi yang sudah anda buka dahulu. Jangan sekali-kali log keluar daripada CLI untuk melakukan ini: log keluar membatalkan log masuk yang disimpan, dan akaun itu perlu ditambah semula.

Untuk menyalin log masuk langganan anda ke mesin Omarchy lain melalui SSH, jalankan `omarchy agent account copy user@laptop`. Pengirim menyediakan penerima sementara apabila destinasi tidak mempunyai satu yang dipasang, jadi mesin Omarchy lama boleh menerima akaun tanpa kemas kini. Penerima yang dipasang diutamakan. Ini menyalin semua langganan Claude, Codex, dan Grok; tambah nama pembekal untuk memilihnya, seperti dalam `omarchy agent account copy laptop claude`. Nama akaun dan ID arahan sepadan dengan sumber, termasuk akaun yang sudah ada di destinasi. Akaun destinasi yang tidak berkaitan menerima akhiran angka jika namanya bercanggah, dan tetapan, skill, plugin, dan sejarah perbualan kekal setempat pada setiap mesin.

Kelayakan destinasi sedia ada dikekalkan. Akaun sumber yang sudah log masuk di sana namanya disegerakkan tanpa menggantikan kelayakannya; akaun lain ditambah di sisinya. Untuk menggantikan kelayakan yang disimpan bagi akaun yang sepadan, gunakan `omarchy agent account copy --replace laptop claude` selepas menutup sesi akaun itu di destinasi. Destinasi baharu turut mendapat akaun aktif dan keutamaan penukaran sumber; destinasi yang sudah mantap mengekalkan miliknya sendiri.

Kelayakan bergerak melalui SSH dan disimpan dalam fail peribadi di destinasi, jadi salin hanya ke mesin yang anda percayai. Ini ialah salinan sekali sahaja, bukan penyegerakan berterusan. Token muat semula Codex boleh digilirkan oleh mesin lain, menyebabkan log masuk yang disalin memerlukan pembaharuan; log masuk berasingan kekal pilihan paling boleh dipercayai untuk penggunaan serentak pada beberapa mesin. Lihat [panduan pengesahan akaun Codex](https://developers.openai.com/codex/auth/ci-cd-auth).

Satu akaun bagi setiap pembekal aktif, dan setiap sesi baharu bermula dengannya: `cx`, `cy`, `claude`, `codex`, atau `grok` biasa, apa-apa yang dilancarkan melalui `omarchy agent`, dan skrip atau editor yang mencari CLI pada `PATH`. Beralih dengan `omarchy agent account use work` (dan kembali dengan `omarchy agent account use main`), atau dalam panel dengan menekan nombor akaun dan kemudian `Enter` (atau mengklik butang Use). Sesi yang sudah berjalan kekal pada akaun ia bermula. Sejarah perbualan, tetapan, skill, dan plugin dikongsi merentas akaun, jadi `claude --continue` dalam folder yang sama menyambung dari tempat anda berhenti pada akaun baharu.

Dengan lebih daripada satu akaun, panel menunjukkan had setiap akaun bersebelahan, dengan yang aktif ditanda. Secara lalai Omarchy memberitahu anda apabila akaun aktif melepasi 95% daripada had, dan mengklik pemberitahuan beralih ke akaun dengan ruang paling banyak. Tuding baris akaun dalam panel dan klik Autoswitch yang muncul di sebelah Use (atau tekan `m`), atau jalankan `omarchy agent account mode auto`, untuk membolehkannya beralih sendiri sebaliknya; semasa ia aktif, Autoswitch mengambil tempat Use, dan mengkliknya semula kembali kepada pemberitahuan. Tambah nombor untuk menukar ambang, seperti dalam `omarchy agent account mode auto 90`. Jika setiap akaun melebihi ambang, anda akan dimaklumkan sekali, bersama akaun mana yang bebas dahulu. Semasa akaun aktif berada dalam 15 mata daripada ambangnya (80% pada lalai), hadnya disemak setiap tiga minit berbanding setiap 15.

`omarchy agent account list` menunjukkan setiap akaun dan had terkininya, `omarchy agent account remove work` melupakan satu, dan `omarchy agent account rename primary Hey` menamakan semula satu (atau klik nama akaun dalam panel). Arahan ini berfungsi pada akaun ejen lalai anda; untuk mencapai pembekal lain, namakannya dahulu, seperti dalam `omarchy agent account use codex side`. Log masuk yang sudah anda miliki dalam `~/.claude` atau `~/.codex` ialah akaun _Main_ dan kekal di tempatnya. Akaun yang tidak digunakan lebih daripada kira-kira lapan jam boleh menunjukkan _Sign-in required_; kliknya untuk log masuk akaun itu semula terus dalam panel, atau mulakan sesi di dalamnya, yang menyegarkan log masuk dengan sendirinya. Pelayan MCP yang anda miliki semasa akaun ditambah ikut bersamanya, tetapi yang anda tambah kemudian dengan `claude mcp add` hanya sampai ke akaun anda menambahnya. Claude Desktop dan alat yang dikonfigurasikan dengan laluan mutlak ke binari CLI tidak mengikut penukaran. `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, atau `GROK_HOME` yang eksplisit diutamakan berbanding akaun yang dipilih.

### Diagnosis ranap

Omarchy memerhati systemd-coredump untuk ranap proses. Apabila sesuatu segfault, anda akan mendapat pemberitahuan "Process crashed" — kliknya, dan ranap diserahkan kepada ejen lalai anda bersama skill diagnose-crash Omarchy, yang membimbing ejen melalui penentuan fakta daripada core dump dan memutuskan sama ada ranap itu berbaloi dilaporkan ke huluan. Anda juga boleh menjalankannya secara manual terhadap mana-mana PID daripada `coredumpctl list` dengan `omarchy agent crash <pid>`.

Pemerhatian aktif secara lalai. Matikannya di bawah _Trigger > Toggle > Crash Capture_ (atau dengan `omarchy toggle crash-capture`) dan pemberitahuan berhenti; `omarchy agent crash <pid>` masih berfungsi secara manual.

Ranap juga boleh disenyapkan satu program pada satu masa, iaitu apa yang ditawarkan diagnosis kepada anda pada akhirnya. `omarchy crash mute hyprland` menghentikan pemberitahuan untuk program itu sahaja, `omarchy crash mute hyprland off` membawanya kembali, dan `omarchy crash mute` sendiri menyenaraikan apa yang telah anda senyapkan. Ia menerima laluan binari sama gembiranya seperti namanya, jadi `omarchy crash mute /usr/bin/hyprland` melakukan perkara yang sama. Petik nama dengan ruang di dalamnya, seperti dalam `omarchy crash mute 'Some App'`. Semua yang lain masih memberitahu, dan program yang disenyapkan masih ranap — ini menyembunyikan peringatan, ia tidak membaiki apa-apa.

### Aplikasi desktop

Menu _Install > AI_ turut membawa beberapa aplikasi AI grafik: aplikasi desktop ChatGPT, aplikasi desktop Claude (beta Linux Anthropic, dengan tab Chat, Cowork, dan Claude Code), Grok Bot untuk berbual dengan model xAI, Hermes Desktop, OpenClaw, aplikasi desktop Perplexity, dan T3 Code. Grok Bot ialah aplikasi sembang desktop. Ejen pengekodan ialah arahan `grok`.

Hermes Desktop ialah yang perlu diketahui, kerana mesin mempunyai satu Hermes, dan ia milik aplikasi: Hermes hanya pernah dipasang melalui aplikasi, dan arahan `hermes` yang dijalankan ejen lalai ialah milik aplikasi. Memilih Hermes sebagai ejen lalai memasang perkara yang sama seperti entri _Install > AI_: pakej, dan runtime Hermes di bawah `~/.hermes` yang disediakan oleh pemasang Hermes sendiri, yang mengambil masa beberapa minit pada kali pertama. Runtime itu ialah satu-satunya Hermes yang digunakan arahan terminal `hermes`, ejen lalai dan aplikasi, dan ia mengemas kini dirinya dengan `hermes update` berbanding menunggu keluaran Omarchy. Memasangnya turut menyerahkan tema Omarchy kepada Hermes sebagai skin bernama `omarchy`, yang diikuti setiap permukaan Hermes semasa anda menukar tema; pilih yang lain di bawah tetapan Appearance Hermes atau dengan `/skin` jika anda lebih suka ia tidak berbuat demikian, dan Omarchy membiarkan pilihan itu. Mengalih keluar aplikasi di bawah _Remove > AI_ menutup Hermes dahulu, termasuk gateway, membawa runtime itu bersamanya, dan mengekalkan sembang, memori, dan skill yang ditulis Hermes untuk dirinya melainkan anda menyuruhnya sebaliknya: ia bertanya, dengan lalai tidak, sama ada data itu dan tetapan sambungan anda patut pergi juga.

Pengalaman desktop OpenClaw ialah Control UI-nya, yang dibuka sebagai aplikasi web yang disokong oleh gateway setempatnya sendiri. OpenClaw berada dalam `~/.openclaw` dan mengemas kini dirinya: gunakan butang "Update Gateway" Control UI atau jalankan `openclaw update`, dan gateway dimulakan semula pada versi baharu. Omarchy hanya memilih keluaran yang dimulakan pemasangan baharu. Mengalih keluar OpenClaw di bawah _Remove > AI_ membawa perkhidmatan gateway dan aplikasi bersamanya dan kemudian bertanya sama ada `~/.openclaw` patut pergi juga, kerana itu menyimpan sembang dan kelayakan anda bersama OpenClaw sendiri dan runtime plugin yang dimuat turunnya; lalai mengekalkannya, dan memasang OpenClaw semula akan mengambilnya kembali.

T3 Code berjalan daripada keluaran AppImage rasminya dalam `~/.local/share/t3code` berbanding daripada pakej, jadi ia mengemas kini dirinya. Memasangnya bertanya sama ada untuk bermula pada saluran Stable atau Nightly; tukar kemudian dalam tetapan T3 Code. Thread dan tetapan anda berada dalam `~/.t3`, dan mengalih keluar T3 Code di bawah _Remove > AI_ membawanya bersama.

### Model tempatan

Jalankan model terbuka pada mesin anda sendiri untuk ejen pengekodan anda. Gesaan dan kod anda kekal pada mesin; tiada apa yang dihantar ke model meninggalkannya. Mulakan dengan:

```bash
omarchy agent local use best
```

Atau, dalam panel ejen dalam bar atas, pilih + dan kemudian Local AI, yang muncul apabila model muat pada mesin ini. Kali pertama, ini memasang Podman, yang menjalankan model. Omarchy kemudian memilih model yang disyorkan untuk mesin ini, memuat turunnya, dan memulakannya. Jangkakan muat turun berpuluh GB dan sebahagian besar memori mesin digunakan semasa model berjalan: Flash Next menggunakan kira-kira 100 GiB dengan konteks penuh 256K. Jika model lain memegang memori yang diperlukannya, ia disediakan berhenti, bersedia untuk bermula sebaik sahaja anda menghentikan satu. Model berhenti semasa log keluar; hentikannya sendiri apabila anda memerlukan memori untuk perkara lain.

`omarchy agent local list` menunjukkan pilihan dan menerangkan mengapa sesetengah tidak muat. Untuk menyediakan yang lain, jalankan `omarchy agent local use <recipe>`. Hari ini, `qwen3.8-flash-next-halogen` dan `qwen3.8-27b-gufo` tersedia untuk mesin Strix Halo 128 GB. Resipi dan syor baharu tiba dengan `omarchy update`, melalui pakej.

Setiap model yang anda sediakan mendapat barisnya sendiri dalam panel ejen, di sebelah langganan anda: main untuk memulakannya, jeda untuk menghentikannya dan membebaskan memorinya, dan butang terminal untuk membuka ejen anda padanya. Beberapa boleh berjalan serentak apabila ia muat dalam memori bersama; jika satu tidak muat, Omarchy menyatakan model berjalan mana untuk dihentikan. Seret baris untuk menyusunnya semula, dan tekan Delete pada baris yang dipilih untuk mengalih keluar model dan muat turunnya.

Dari baris arahan, `omarchy agent local start <recipe>` dan `omarchy agent local stop <recipe>` melakukan perkara yang sama, `omarchy agent local status` menunjukkan setiap model, dan `omarchy agent --local` membuka ejen lalai anda pada model terakhir anda mulakan (pi jika ejen lalai anda tidak boleh menggunakan model tempatan). Mana-mana klien serasi OpenAI boleh menyambung juga: `status` menunjukkan alamat setiap model (yang pertama ialah `http://127.0.0.1:11435/v1`), nama resipi ialah model, dan kunci berada dalam `~/.config/omarchy/agent-local/key`.

`omarchy agent local remove <recipe>` memadam model dan muat turun yang tidak digunakan model lain.

Runtime pihak ketiga dilabel dengan penerbitnya. Omarchy menjalankan setiap model tanpa akses rangkaian.

### LLM tempatan

Omarchy mengesyorkan dua cara menjalankan model LLM tempatan: LM Studio dan Ollama. LM Studio menyediakan antara muka GUI untuk mencari model open-weight, memasangnya, dan menjalankannya. Ia cara yang bagus untuk bermula dengan mudah. Ollama menawarkan CLI untuk melakukan perkara yang sama. Tetapi jika anda baharu kepada model tempatan, saya akan bermula dengan LM Studio. Anda boleh memasang mana-mana di bawah _Install > AI_ dalam Menu Omarchy.

### Skill Omarchy

Skill ejen membantu AI menggunakan alat tertentu dengan cara tertentu, dan Omarchy disertakan dengan skill lalai untuk menyesuaikan sistem. Seperti mengubah suai konfigurasi Hyprland anda, melaraskan bar, atau mencipta tema baharu dari awal. Ia disymlink ke dalam direktori skill untuk Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` dan setiap `~/.hermes/profiles/*/skills`), dan lokasi generik `~/.agents/skills`, jadi kebanyakan harness mengambilnya secara automatik.

Tetapi anda patut menganggap skill ini sebagai eksperimen. Model berbeza akan menggunakannya dengan kesan berbeza. Sebaiknya jalankan dalam mod pelan dahulu, supaya anda mempunyai idea tentang apa yang ingin diubah ejen. Dan kemudian bersedia untuk mengembalikan perubahan atau malah menggunakan `omarchy reinstall configs`, jika ejen mengacaukan semuanya.
