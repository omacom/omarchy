# AI

Omarchy menyertakan pelancar untuk ejen pengekodan di bawah tanpa memilih lalai untuk anda. Jalankan satu perintah untuk memasang CLI-nya pada penggunaan pertama, kemudian sahkan identiti apabila diminta. Hermes ialah pengecualian: tiada apa-apa dipasang untuknya pada penggunaan pertama, dan memilihnya akan memasang Hermes Desktop, seperti yang diterangkan dalam _Aplikasi desktop_ di bawah.

### Memasang dan mengemas kini ejen

Selain Hermes, ejen-ejen ini menggunakan pemasangan lazy mise: pelancaran pertama memasang CLI, dan pelancaran berikutnya menggunakannya semula. mise juga menyemak keluaran baharu untuk ejen yang telah dipasang paling kerap sekali setiap empat jam, sejurus sebelum ia bermula atau di latar belakang pada prompt shell. Jika kemas kini itu gagal atau anda berada di luar talian, versi yang telah dipasang akan dijalankan. `omarchy update` mengemas kini ejen yang telah dipasang bersama-sama seluruh Omarchy, dan `mup` hanya mengemas kini alat yang diuruskan oleh mise.

Pengemas kini milik ejen itu sendiri, seperti `claude update`, `codex update`, atau butang kemas kini dalam aplikasi, tidak mengemas kini pemasangan yang diuruskan oleh mise. `codex update` gagal, dan `claude update` boleh melaporkan kejayaan sambil memasang salinan berasingan yang tidak dijejak oleh mise. Jika anda lebih suka menggunakan pemasang dan pengemas kini asli ejen, tambahkannya pada `disable_tools`; lihat [Alat CLI prapasang](18-development-tools.md#preinstalled-cli-tools).

Untuk memasang semua alat lazy yang dikonfigurasikan sebelum anda memerlukannya, jalankan `mise install --include-lazy`. Ini termasuk alat CLI lalai Omarchy yang lain selain ejen-ejen tersebut. Lihat [Alat CLI prapasang](18-development-tools.md#preinstalled-cli-tools) untuk memasang satu alat atau menggunakan pemasangan anda sendiri.

`grok` dipasang melalui pakej `grok` pihak pertama mise, dengan cara yang sama seperti `claude` dan `codex`. Jalankan `grok`, atau pilihnya di bawah _Agent > Harness_. Langkau pemasang `curl | bash` di x.ai. Laluan itu meletakkan salinan kedua dalam `~/.grok/bin`, menambahkannya di hadapan pada `PATH`, dan menulis ganti wrapper Omarchy.

`dsh` membuka UI pelayarnya pada `127.0.0.1:3080`, dengan direktori pelancaran sebagai ruang kerja lalainya. UI pelayarnya tidak menerima prompt permulaan, jadi `omarchy agent prompt` membukanya dengan prompt pada papan keratan anda untuk ditampal. Omarchy memulakannya dengan pratetap kebenaran tanpa kelulusan DeepSeek. DeepSeek Harness memuat naik log sesi ke DeepSeek apabila anda menggunakan API model rasminya; matikan itu di bawah _Settings > General > Upload Session Log_ dalam UI pelayarnya. Maklum balas yang anda hantar kepadanya turut dimuat naik bersama sesi, melainkan anda memulakannya dengan `DSH_TELEMETRY_MODE=DISABLED`.

### Ejen lalai

Pilih ejen lalai anda dengan `omarchy default agent <name>` atau di bawah _Agent > Harness_ dalam Omarchy Menu (`Super + Space`). Jika ejen itu belum dipasang, memilihnya akan memasangnya terlebih dahulu. Omarchy yang baru dipasang akan menjemput anda membuat pilihan ini dengan pemberitahuan sekali sahaja.

Memilih Claude juga cuba menyediakan sambungan pelayarnya untuk Chromium, Chrome, Brave, Brave Origin, dan Edge. Persediaan sambungan ini terpakai untuk semua pengguna dan mungkin meminta kata laluan sistem anda; membatalkan atau kegagalan pemasangan sambungan tetap akan memilih dan melancarkan Claude. Mulakan semula pelayar anda, dayakan sambungan jika diminta, dan log masuk ke Claude untuk selesai menyambungkannya. Jalankan `/chrome` dalam Claude untuk menyemak sambungan. Firefox dan Zen tidak menyokong sambungan ini. Jika Claude sudah menjadi lalai anda sebelum persediaan ini ditambah, pilihnya semula untuk memasang sambungan tersebut.

Sebaik sahaja anda telah memilih, `Super + Shift + Ctrl + A` melancarkan ejen lalai dalam tetingkap terminal khusus (atau memaparkan pemilih jika anda belum memilih). Anda juga boleh melancarkannya terus kepada satu tugasan dengan `omarchy agent prompt "Review this project"`. Freebuff dan DeepSeek Harness tidak menerima prompt permulaan, jadi ia dibuka dengan prompt pada papan keratan anda untuk ditampal sebagai gantinya. Ejen yang dilancarkan dengan cara ini berjalan tanpa pengawasan dalam mod jangan berhenti untuk bertanya masing-masing, jadi bersedialah kerana ia benar-benar akan melakukan sesuatu! MiniMax Code tidak mempunyai mod sedemikian untuk sesi interaktifnya, jadi ia meminta kebenaran seperti biasa. Dan memandangkan ejen enggan mengingati kepercayaan untuk direktori rumah anda, pelancaran dari `$HOME` bermula dalam `~/Work` sebagai gantinya.

Ada juga pintasan terminal: `a` menjalankan ejen lalai sebaris dalam terminal semasa, manakala `c`, `cx`, dan `cy` memulakan OpenCode, Claude Code, dan Codex secara terus (sekali lagi dalam mod kelulusan automatik masing-masing). Perubahan tema turut disegerakkan kepada ejen: Claude Code, Pi, OpenCode, dan Hermes (sebaik sahaja Omarchy memasangnya) semuanya mengikut apabila anda menukar tema Omarchy.

### Arahan ejen anda

Peraturan peribadi untuk setiap ejen diletakkan dalam `~/.agents/AGENTS.md`, bersebelahan kemahiran bersama dalam `~/.agents/skills`. Bukanya di bawah _Agent > Instructions_, yang turut memautkannya ke dalam setiap harness yang menyimpan fail globalnya sendiri: `~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.pi/agent/AGENTS.md`, `~/.config/opencode/AGENTS.md`, `~/.copilot/copilot-instructions.md` milik Copilot, dan sebagainya. Crush dan Amp membaca pautan `~/.config/AGENTS.md`, manakala omp, Kimi, dan DeepSeek Harness membaca `~/.agents/AGENTS.md` secara terus. Memilih ejen lalai turut memautkannya. Fail arahan yang anda sudah ada menjadi fail bersama jika belum ada lagi; jika tidak, ia disimpan bersebelahan pautan sebagai `.bak`. Jalankan `omarchy agent instructions` untuk memaut semula selepas memasang ejen lain.

### Panel ejen

Bar atas mempunyai ikon ejen. Sebelum anda menyediakan ejen, panelnya membimbing anda log masuk ke Claude, Codex, atau Grok, dan yang pertama menjadi ejen lalai anda. Selepas itu, panel meletakkan setiap langganan pada satu halaman: setiap ejen dan akaun dengan pelannya, meter untuk setiap had sesi 5 jam dan had mingguannya beserta masa sehingga ia ditetapkan semula (letakkan kursor di atasnya untuk peratusan tepat), atau baki prabayar yang tinggal, di bawah satu baris yang bergilir-gilir memaparkan apa yang telah anda gunakan merentas semuanya, seperti token minggu ini dan model yang paling kerap anda gunakan. Di bawah _Make something_ ia menawarkan prompt permulaan untuk tema, plugin, atau aplikasi baharu yang menyerahkan tugasan kepada ejen lalai anda. Aplikasi dibina dengan cara yang sama seperti Hype, Monologue, dan Omacut milik Omarchy sendiri, dalam C++ dan Qt Quick, mengikut kemahiran ejen omarchy-app, dan pengkompil serta komponen Qt yang diperlukannya sudah dipasang. Claude Code, Codex, Grok, Kimi, Cursor dan elaun Grok Bot-nya, GitHub Copilot, Muse, Antigravity, Kimchi, dan Devin diliputi sejak awal dengan had masing-masing, dan Hermes, Mistral Vibe, dan Qwen Code menunjukkan sesi dan token mereka sebaik sahaja anda menggunakannya. Pelan dan kunci pembekal yang anda gunakan melalui pi, omp, atau opencode turut muncul: OpenCode Zen dan Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan, dan Synthetic dengan had masing-masing; Fireworks, OpenRouter, dan DeepSeek dengan baki prabayar masing-masing; dan model yang anda jalankan pada perkakasan anda sendiri di bawah Model tempatan. Setiap ejen dikira sekali sahaja, di bawah pihak yang mengebilnya, tidak kira berapa banyak harness anda menggunakannya melalui.

Klik kiri ikon bar untuk panel, klik kanan untuk melancarkan ejen lalai anda. Rekod penggunaan di sebaliknya dijana semula setiap 15 minit oleh `omarchy agent usage-update`, dan panel itu bahkan boleh menggabungkan penggunaan daripada mesin anda yang lain melalui folder yang disegerakkan. Lihat README di bawah `$OMARCHY_PATH/shell/plugins/agents/` untuk tetapan penuh.

### Beberapa langganan

Jika anda membayar lebih daripada satu pelan Claude, Codex, atau Grok — contohnya Max peribadi dan satu untuk kerja — Omarchy boleh memastikan semuanya kekal log masuk dan bergerak antara mereka. Tambah langganan dengan + dalam panel ejen, yang membimbing anda melaluinya di situ juga, atau dengan `omarchy agent account add claude Work` (atau `codex`, atau `grok`). Ia memasang CLI jika tiada. Akaun pertama untuk sesuatu pembekal log masuk melalui pelayar biasa anda, tepat di tempat CLI sentiasa mencari. Setiap akaun selepas itu log masuk melalui tetingkap peribadi, supaya akaun yang pelayar anda sudah log masuk tidak terpilih secara tidak sengaja; log masuk di situ sebagai akaun yang anda tambah, dan tutup mana-mana tetingkap peribadi yang sudah terbuka terlebih dahulu. Jangan sekali-kali log keluar daripada CLI untuk melakukan ini: log keluar membatalkan log masuk yang disimpan, dan akaun itu perlu ditambah semula.

Untuk menyalin log masuk langganan anda ke mesin Omarchy lain melalui SSH, jalankan `omarchy agent account copy user@laptop`. Pengirim menyediakan penerima sementara apabila destinasi tidak mempunyai satu yang dipasang, jadi mesin Omarchy lama boleh menerima akaun tanpa kemas kini. Penerima yang telah dipasang diutamakan. Ini menyalin semua langganan Claude, Codex, dan Grok; tambah nama pembekal untuk memilihnya, seperti dalam `omarchy agent account copy laptop claude`. Nama akaun dan ID perintah sepadan dengan sumber, termasuk akaun yang sudah ada di destinasi. Akaun destinasi yang tidak berkaitan menerima akhiran angka jika namanya bercanggah, dan tetapan, kemahiran, plugin, serta sejarah perbualan kekal setempat pada setiap mesin.

Kelayakan destinasi yang sedia ada dikekalkan. Akaun sumber yang sudah log masuk di situ namanya disegerakkan tanpa menggantikan kelayakannya; akaun lain ditambah bersebelahannya. Untuk menggantikan kelayakan yang disimpan bagi akaun yang sepadan, gunakan `omarchy agent account copy --replace laptop claude` selepas menamatkan sesi akaun tersebut di destinasi. Destinasi yang baru turut mendapat akaun aktif dan keutamaan pertukaran sumber; destinasi yang sudah mantap mengekalkan miliknya sendiri.

Kelayakan bergerak melalui SSH dan disimpan dalam fail peribadi di destinasi, jadi salin hanya ke mesin yang anda percayai. Ini ialah salinan sekali sahaja, bukan penyegerakan berterusan. Token muat semula Codex boleh digilirkan oleh mesin lain, menyebabkan log masuk yang disalin memerlukan pembaharuan; log masuk berasingan kekal pilihan paling boleh dipercayai untuk penggunaan serentak pada beberapa mesin. Lihat [panduan pengesahan akaun Codex](https://developers.openai.com/codex/auth/ci-cd-auth).

Satu akaun bagi setiap pembekal aktif, dan setiap sesi baharu bermula dengannya: `cx`, `cy`, `claude`, `codex`, atau `grok` biasa, apa-apa yang dilancarkan melalui `omarchy agent`, dan skrip atau editor yang menemui CLI pada `PATH`. Tukar dengan `omarchy agent account use work` (dan kembali dengan `omarchy agent account use main`), atau dalam panel dengan menekan nombor akaun kemudian `Enter` (atau mengklik butang Use-nya). Sesi yang sudah berjalan kekal pada akaun ia bermula. Sejarah perbualan, tetapan, kemahiran, dan plugin dikongsi merentas akaun, jadi `claude --continue` dalam folder yang sama menyambung dari tempat anda berhenti pada akaun baharu.

Dengan lebih daripada satu akaun, panel menunjukkan had setiap akaun bersebelahan, dengan yang aktif ditandakan. Secara lalai Omarchy memberitahu anda apabila akaun aktif melepasi 95% daripada sesuatu had, dan mengklik pemberitahuan menukar kepada akaun dengan ruang paling banyak. Letakkan kursor di atas baris akaun dalam panel dan klik Autoswitch yang muncul di sebelah Use (atau tekan `m`), atau jalankan `omarchy agent account mode auto`, supaya ia bertukar sendiri sebagai gantinya; semasa ia aktif, Autoswitch mengambil tempat Use, dan mengkliknya semula kembali kepada pemberitahuan. Tambah nombor untuk menukar ambang, seperti dalam `omarchy agent account mode auto 90`. Jika setiap akaun melepasi ambang, anda akan diberitahu sekali, bersama akaun mana yang bebas dahulu. Semasa akaun aktif berada dalam jarak 15 mata daripada ambangnya (80% pada lalai), hadnya disemak setiap tiga minit dan bukan setiap 15.

`omarchy agent account list` menunjukkan setiap akaun dan had terkininya, `omarchy agent account remove work` melupakan satu akaun, dan `omarchy agent account rename primary Hey` menamakan semula satu akaun (atau klik nama akaun dalam panel). Perintah ini berfungsi pada akaun ejen lalai anda; untuk mencapai pembekal lain, namakannya dahulu, seperti dalam `omarchy agent account use codex side`. Log masuk yang anda sudah ada dalam `~/.claude` atau `~/.codex` ialah akaun _Main_ dan kekal di tempatnya. Akaun yang tidak digunakan lebih daripada kira-kira lapan jam boleh menunjukkan _Sign-in required_; kliknya untuk log masuk semula akaun itu terus dalam panel, atau mulakan sesi di dalamnya, yang menyegarkan log masuk dengan sendiri. Pelayan MCP yang anda ada semasa akaun ditambah turut ikut ke akaun tersebut, tetapi yang anda tambah kemudian dengan `claude mcp add` hanya sampai ke akaun anda menambahnya. Claude Desktop dan alat yang dikonfigurasikan dengan laluan mutlak ke binari CLI tidak mengikut pertukaran. `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, atau `GROK_HOME` yang eksplisit diutamakan berbanding akaun yang dipilih.

### Diagnosis ranap

Omarchy memantau systemd-coredump untuk ranap proses. Apabila sesuatu mengalami segfault, anda akan mendapat pemberitahuan "Process crashed" — kliknya, dan ranap itu diserahkan kepada ejen lalai anda bersama kemahiran diagnose-crash Omarchy, yang membimbing ejen menentukan fakta daripada core dump dan memutuskan sama ada ranap itu berbaloi dilaporkan ke upstream. Anda juga boleh menjalankannya secara manual terhadap mana-mana PID daripada `coredumpctl list` dengan `omarchy agent crash <pid>`.

Pemantauan ini aktif secara lalai. Matikannya di bawah _Trigger > Toggle > Crash Capture_ (atau dengan `omarchy toggle crash-capture`) dan pemberitahuan berhenti; `omarchy agent crash <pid>` masih berfungsi secara manual.

Ranap juga boleh disenyapkan satu program pada satu masa, iaitu apa yang diagnosis tawarkan kepada anda pada penghujungnya. `omarchy crash mute hyprland` menghentikan pemberitahuan untuk program itu sahaja, `omarchy crash mute hyprland off` mengembalikannya, dan `omarchy crash mute` dengan sendiri menyenaraikan apa yang telah anda senyapkan. Ia menerima laluan binari sama senangnya seperti namanya, jadi `omarchy crash mute /usr/bin/hyprland` melakukan perkara yang sama. Petik nama yang mempunyai ruang di dalamnya, seperti dalam `omarchy crash mute 'Some App'`. Semua yang lain masih memberitahu, dan program yang disenyapkan masih ranap — ini menyembunyikan peringatan, ia tidak membaiki apa-apa.

### Aplikasi desktop

Menu _Install > AI_ turut membawa beberapa aplikasi AI grafik: aplikasi desktop ChatGPT, aplikasi desktop Claude (beta Linux Anthropic, dengan tab Chat, Cowork, dan Claude Code), Grok Bot untuk berbual dengan model xAI, Herdr Desktop, Hermes Desktop, OpenClaw, aplikasi desktop Perplexity, dan T3 Code. Grok Bot ialah aplikasi sembang desktop. Ejen pengekodan ialah perintah `grok`.

Hermes Desktop ialah yang perlu anda tahu, kerana satu mesin mempunyai satu Hermes, dan ia milik aplikasi itu: Hermes hanya pernah dipasang melalui aplikasi, dan perintah `hermes` yang ejen lalai jalankan ialah milik aplikasi itu. Memilih Hermes sebagai ejen lalai memasang perkara yang sama seperti entri _Install > AI_: pakej, dan runtime Hermes di bawah `~/.hermes` yang disediakan oleh pemasang Hermes sendiri, yang mengambil masa beberapa minit pada kali pertama. Runtime itu ialah satu-satunya Hermes yang perintah terminal `hermes`, ejen lalai dan aplikasi semuanya gunakan, dan ia mengemas kini dirinya sendiri dengan `hermes update` dan bukannya menunggu keluaran Omarchy. Memasangnya juga memberikan tema Omarchy kepada Hermes sebagai skin bernama `omarchy`, yang diikuti oleh setiap permukaan Hermes apabila anda menukar tema; pilih yang lain di bawah tetapan Appearance Hermes atau dengan `/skin` jika anda lebih suka ia tidak berbuat demikian, dan Omarchy membiarkan pilihan itu. Membuang aplikasi di bawah _Remove > AI_ menutup Hermes dahulu, termasuk gateway, mengambil runtime itu bersamanya, dan mengekalkan sembang, ingatan, dan kemahiran yang Hermes tulis untuk dirinya sendiri melainkan anda menyatakan sebaliknya: ia bertanya, dengan lalai tidak, sama ada data tersebut dan tetapan sambungan anda patut turut dibuang.

Pengalaman desktop OpenClaw ialah Control UI-nya, yang dibuka sebagai aplikasi web yang disokong oleh gateway tempatannya sendiri. OpenClaw tinggal dalam `~/.openclaw` dan mengemas kini dirinya sendiri: gunakan butang "Update Gateway" Control UI atau jalankan `openclaw update`, dan gateway dimulakan semula pada versi baharu. Omarchy hanya memilih keluaran yang pemasangan baru bermula daripadanya. Membuang OpenClaw di bawah _Remove > AI_ mengambil perkhidmatan gateway dan aplikasi bersamanya kemudian bertanya sama ada `~/.openclaw` patut turut dibuang, kerana itu menyimpan sembang dan kelayakan anda bersebelahan OpenClaw itu sendiri dan runtime plugin yang dimuat turunnya; lalai mengekalkannya, dan memasang OpenClaw semula akan mengambilnya kembali.

Herdr Desktop ialah aplikasi desktop [Herdr](https://herdr.dev): ruang, tab, dan pane terminal serta ejen pengekodan yang terus berjalan dalam core-nya apabila anda menutup tetingkap. Ia datang daripada pemasang Herdr sendiri dan bukannya pakej, jadi ia tinggal dalam `~/.local/share/herdr-app`, membawa core-nya dalam `~/.local/bin/herdr-core` apabila anda belum mempunyainya, dan mengemas kini kedua-duanya sendiri. Ia berada di sebelah perintah `herdr` yang Omarchy sediakan pada `Super + Ctrl + Return` dan bukannya menggantikannya, dan mendapat kekunci terus perintah tersebut: `Alt + Return` dan `Alt + Shift + Return` membahagi pane ke bawah atau ke kanan, `Alt + Escape` menutupnya, `Ctrl + Alt + Arrow` bergerak antara pane, `Alt + 1..9` dan `Alt + Left/Right` memilih tab, dan `Alt + Up/Down` bergerak antara ruang. `Ctrl + 1..9` memilih ruang dan `Alt + Shift + Up/Down` melangkah melalui ejen. Kekunci awalan `Ctrl + Space` kekal untuk terminal sahaja, kerana aplikasi tidak boleh menahan kekunci Ctrl biasa untuk satu urutan. Omarchy menulis ini ke `~/.config/herdr-app/keys.json`, dan `omarchy-refresh-herdr-app` mengembalikannya. Memasangnya memilih tema Omarchy Herdr, yang mengikut tema Omarchy anda mulai saat itu. Herdr menyimpan satu tema untuk mod cerah dan satu untuk gelap, jadi selepas bertukar antara tema Omarchy gelap dan cerah, pilih Omarchy dalam pemilih tema Herdr sekali lagi untuk mod yang satu lagi.

T3 Code berjalan daripada keluaran AppImage rasminya dalam `~/.local/share/t3code` dan bukannya daripada pakej, jadi ia mengemas kini dirinya sendiri. Memasangnya bertanya sama ada untuk bermula pada saluran Stable atau Nightly; tukar kemudian dalam tetapan T3 Code. Thread dan tetapan anda tinggal dalam `~/.t3`, dan membuang T3 Code di bawah _Remove > AI_ mengambilnya bersamanya.

### Model tempatan

Jalankan model terbuka pada mesin anda sendiri untuk ejen pengekodan anda. Prompt dan kod anda kekal pada mesin; tiada apa yang dihantar ke model meninggalkan mesin. Mulakan dengan:

```bash
omarchy agent local use best
```

Atau, dalam panel ejen di bar atas, pilih + dan kemudian Local AI, yang muncul apabila model sesuai dengan mesin ini. Pada kali pertama, ini memasang Podman, yang menjalankan model, dan pada mesin NVIDIA toolkit kontena NVIDIA, yang memberikan GPU kepadanya. Omarchy kemudian memilih model yang disyorkan untuk mesin ini, memuat turunnya, dan memulakannya. Jangkakan muat turun berpuluh GB dan sebahagian besar ingatan mesin digunakan semasa model berjalan: Flash Next menggunakan kira-kira 100 GiB dengan konteks penuh 256K-nya. Jika model lain memegang ingatan yang diperlukannya, ia disediakan dalam keadaan berhenti, bersedia untuk bermula sebaik sahaja anda menghentikan satu. Model berhenti semasa log keluar; hentikannya sendiri apabila anda memerlukan ingatan untuk sesuatu yang lain.

`omarchy agent local list` menunjukkan pilihan dan menerangkan sebab sesetengahnya tidak muat. Untuk menyediakan satu lagi, jalankan `omarchy agent local use <recipe>`. Hari ini, `qwen3.8-flash-next-gufo` dan `qwen3.8-27b-gufo` tersedia untuk mesin Strix Halo 128 GB; 27B mengambil kira-kira 40 GiB, jadi ia meninggalkan ruang untuk kerja lain. Resipi dan syor baharu tiba dengan `omarchy update`, melalui pakej.

Setiap model yang anda sediakan mendapat barisnya sendiri dalam panel ejen, bersebelahan langganan anda: play untuk memulakannya, pause untuk menghentikannya dan membebaskan ingatannya, dan butang terminal untuk membuka ejen anda padanya. Beberapa boleh berjalan serentak apabila ia muat dalam ingatan bersama; jika satu tidak muat, Omarchy memberitahu model berjalan mana yang perlu dihentikan. Seret baris untuk menyusun semula, dan tekan Delete pada baris yang dipilih untuk membuang model dan muat turunnya.

Dari baris perintah, `omarchy agent local start <recipe>` dan `omarchy agent local stop <recipe>` melakukan perkara yang sama, `omarchy agent local status` menunjukkan setiap model, dan `omarchy agent --local` membuka ejen lalai anda pada model terakhir yang anda mulakan. pi, OpenCode dan Qwen Code boleh menggunakan satu; dengan mana-mana lalai lain ia dibuka dalam pi. pi turut menyenaraikan setiap model yang anda sediakan, dan yang ada pada mesin yang anda pasangkan, dalam pemilih modelnya sendiri, jadi `pi` biasa turut mencapainya. Mana-mana klien serasi OpenAI juga boleh menyambung: `status` menunjukkan alamat setiap model (yang pertama ialah `http://127.0.0.1:11435/v1`), nama resipi ialah modelnya, dan kunci berada dalam `~/.config/omarchy/agent-local/key`.

`omarchy agent local remove <recipe>` memadam model dan muat turun yang tidak digunakan oleh model lain.

Runtime pihak ketiga dilabelkan dengan penerbitnya. Omarchy menjalankan setiap model tanpa akses rangkaian.

### LLM tempatan

Omarchy mengesyorkan dua cara menjalankan model LLM tempatan: LM Studio dan Ollama. LM Studio menyediakan antara muka GUI untuk mencari model open-weight, memasangnya, dan menjalankannya. Ia cara yang hebat untuk bermula dengan mudah. Ollama menawarkan CLI untuk melakukan perkara yang sama secara serupa. Tetapi jika anda baru dengan model tempatan, saya akan mulakan dengan LM Studio. Anda boleh memasang mana-mana satu di bawah _Install > AI_ dalam Omarchy Menu.

### Kemahiran Omarchy

Kemahiran ejen membantu AI menggunakan alat tertentu dengan cara tertentu, dan Omarchy disertakan dengan kemahiran lalai untuk menyesuaikan sistem. Seperti mengubah suai config Hyprland anda, melaraskan bar, atau bahkan mencipta tema baharu dari awal. Ia di-symlink ke dalam direktori kemahiran untuk Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` dan setiap `~/.hermes/profiles/*/skills`), dan lokasi generik `~/.agents/skills`, jadi kebanyakan harness mengambilnya secara automatik.

Tetapi anda patut menganggap kemahiran ini sebagai eksperimen. Model yang berbeza akan menggunakannya dengan kesan yang berbeza. Sebaiknya jalankan dalam mod pelan dahulu, supaya anda mempunyai gambaran tentang apa yang ejen ingin ubah. Dan kemudian bersedialah untuk mengembalikan perubahan atau bahkan menjalankan `omarchy reinstall configs`, jika ejen mengacaukan semuanya.
