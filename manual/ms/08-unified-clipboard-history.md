# Papan Keratan Bersepadu & Sejarah

Biasanya pada Linux, anda memerlukan `Ctrl + Shift + C/V` untuk salin dan tampal dalam terminal dan `Ctrl + C/V` untuk melakukannya di mana-mana sahaja. Itu sukar untuk dibiasakan oleh sesiapa yang tidak dilahirkan dan dibesarkan dengan Linux! Begitu juga peralihan dari super kepada ctrl, jika anda datang dari Mac.

Omarchy menangani kedua-dua masalah dengan kekunci panas papan keratan bersepadu yang berfungsi (hampir) di mana-mana. Iaitu:

| Kekunci Panas | Arahan |
| ------- | ----------- |
| Super + C | Salin |
| Super + X | Potong |
| Super + V | Tampal |
| Super + Ctrl + V | Sejarah Papan Keratan |

_Ambil perhatian bahawa kebanyakan abah-abah ejen akan menggunakan `Ctrl + V` untuk menampal imej, tetapi `Super + V` untuk menampal teks._

### Sejarah Papan Keratan

Sejarah Papan Keratan disediakan oleh shell Omarchy dan berfungsi untuk teks dan imej. Anda mencetuskannya dengan `Super + Ctrl + V`, memilih entri anda dengan return, dan kemudian itu akan diletakkan pada papan keratan bersedia untuk ditampal pada `Super + V`.
