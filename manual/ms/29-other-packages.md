# Pakej Lain

Arch mempunyai kekayaan pakej yang menakjubkan tersedia untuk hampir semua jenis perisian antara repositori rasmi dan Arch User Repository (AUR).

Tidak boleh menjadi lebih mudah untuk menggunakannya. Anda memasang pakej Arch baharu dengan pergi ke _Pasang > Pakej_ dalam menu Omarchy (`Super + Space`) dan menaip pakej yang anda mahu. Ia akan menapis senarai semua pakej secara kabur secara automatik. (Anda juga boleh melakukannya secara manual menggunakan `omarchy pkg add [package]` di terminal).

Anda boleh melakukan perkara yang sama dengan AUR, hanya gunakan _Pasang > AUR_. Ingat sahaja bahawa AUR tidak disemak oleh pasukan Arch. Ia seperti RubyGems atau npm. Sesiapa pun boleh memuat naik.

Jika anda ingin membuang pakej, anda boleh menggunakan _Buang > Pakej_ daripada menu Omarchy. Ia akan membuang pakej, fail konfigurasi, dan kebergantungan. (Anda juga boleh melakukannya secara manual menggunakan `omarchy pkg drop [package]`).
