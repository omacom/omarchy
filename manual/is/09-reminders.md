# Áminningar

Omarchy hefur innbyggða leið til að setja einfaldar áminningar byggðar á niðurtalningarteljara og með skilaboðum. Þú getur gert þetta með `Super + Ctrl + R`, séð allar þær sem eru stilltar með `Super + Ctrl + Alt + R` og hreinsað allar með `Super + Ctrl + Shift + R`. Allt er einnig aðgengilegt með _Kveikja > Áminning_. Þú getur líka notað CLI með `omarchy reminder 7 'Tea ready'`.
