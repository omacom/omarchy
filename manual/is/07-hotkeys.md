# Flýtilyklar

Þú getur séð öll helstu lyklabindingar með `Super + K` (Tmux bindingar með `Super + Alt + K` og Herdr bindingar með `Super + Ctrl + K`).

## Að flakka

| Flýtilykill | Virkni |
| ----------------------- | --------------------- |
| `Super + Space` | Omarchy valmynd (forrit og allt annað) |

| `Super + Home` | Endurheimta vistaða breidd glugga |
| `Super + Left Mouse` | Draga glugga um |

| `Super + Alt + Tab` | Fara á milli glugga í hópun |
| `Super + Alt + Shift + Tab` | Fara aftur á bak á milli glugga í hópun |

## Alhliða klippiborð

| Flýtilykill | Virkni |
| ----------------------- | --------------------- |
| `Super + C` | Afrita |
| `Super + X` | Klippa (ekki í skjáhermi) |
| `Super + V` | Líma |
| `Super + Ctrl + V` | Klippiborðsstjóri |

Venjulega á Linux þarftu `Ctrl + Shift + C/V` til að afrita og líma í skjáherminum og `Ctrl + C/V` til að gera það alls staðar annars staðar. Þessir sameinuðu klippiborðsflýtilyklar Omarchy virka alls staðar.

## Taka

| Flýtilykill | Virkni |
| ------------------- | ------------------------------ |
| `Print Screen` | Skjámynd |
| `Super + Ctrl + Alt + C` | Skjámynd (sama mynd, fyrir lyklaborð án Print Screen lykils) |
| `Super + Ctrl + C` | Tökuvalmynd |
| `Alt + Print Screen` | Skjáupptaka |
| `Super + Print Screen` | Litaval |
| `Super + Ctrl + Print Screen` | Textaútdráttur á klippiborð |
| `Super + Alt + [` | Gera yfirlögn vefmyndavélar minni meðan á upptöku stendur |
| `Super + Alt + ]` | Gera yfirlögn vefmyndavélar stærri meðan á upptöku stendur |
| `Alt + Shift + L` | Afrita núverandi URL úr vefforriti eða Chromium |
| `Alt + Shift + D` | Sækja myndbandið á núverandi síðu í `~/Videos` |
| `Super + Ctrl + X` | Byrja/stöðva talinnslátt (krefst _Uppsetning > Sjálfgefið > Talinnsláttur_) |
| `Right Alt` / `F9` | Ýta-til-að-tala talinnsláttur (krefst Voxtype eða Superwhisper) |

Með skjáupptökum spyr flýtilykillinn fyrst hvaða hljóð þú vilt, byrjar svo upptöku. Ýttu á hann aftur til að stöðva. Sjá [skjámyndir og upptöku](12-screenshots-recording.md) fyrir nánari upplýsingar.

Allir tökuvalkostir eru líka aðgengilegir undir _Kveikja > Taka_ í Omarchy valmyndinni (`Super + Space`).

## Tmux

Forskeytislykillinn er `Ctrl + Space` (`Ctrl + B` virkar líka). Þú getur breytt þessum bindingum í `~/.config/tmux/tmux.conf`.

### Rúður

| Flýtilykill | Virkni |
| ----------------------- | --------------------- |
| `Prefix + v` | Skipta rúðu við hliðina (lóðrétt) |
| `Prefix + h` | Skipta rúðu fyrir neðan (lárétt) |
| `Prefix + x` | Drepa rúðu |
| `Prefix + z` | Víxla þysjun rúðu (fullur skjár) |
| `Alt + Enter` | Skipta rúðu fyrir neðan (án forskeytis) |
| `Alt + Shift + Enter` | Skipta rúðu við hliðina (án forskeytis) |
| `Alt + Escape` | Drepa rúðu (án forskeytis) |
| `Ctrl + Alt + Arrows` | Fara á milli rúða |
| `Ctrl + Alt + Shift + Arrows` | Breyta stærð rúða |

### Gluggar

### Setur

### Almennt

### Tmux uppsetningarföll

Þessi föll verður að keyra inni í Tmux setu.

| Skipun | Virkni |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Búa til þróunaruppsetningu með ritli, AI og skjáhermi |
| `tdlm <ai> [<second_ai>]` | Búa til þróunaruppsetningu fyrir hverja undirmöppu |
| `tsl <count> <command>` | Búa til uppsetningu með mörgum rúðum í þyrpingu |
