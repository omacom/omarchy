# Flýtilyklar

Þú getur séð allar helstu lyklabindingar með `Super + K` (Tmux-bindingar með `Super + Alt + K` og Herdr-bindingar með `Super + Ctrl + K`).

## Leiðsögn

| Flýtilykill                  | Virkni              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy-valmynd (forrit og allt annað)    |
| `Super + Alt + Space` | Forritayfirlit |
| `Super + Escape` | Kerfisvalmynd (svæfa, endurræsa o.s.frv.)  |
| `Super + Ctrl + L` | Læsa tölvu |
| `Super + W` or `Super + Q` | Loka glugga             |
| `Ctrl + Alt + Del` | Loka öllum gluggum |
| `Super + T`               | Skipta glugga á milli flísalagningar/fljótandi             |
| `Super + J` | Skipta um stöðu glugga (lárétt/lóðrétt) |
| `Super + O`               | Kveikja/slökkva á að gluggi skjótist upp sem klístraður og fljótandi |
| `Super + L`               | Fara í gegnum dwindle-, rúllunar- og fljótandi uppröðun |
| `Super + Alt + L`         | Fara í gegnum uppröðunina í öfugri röð |
| `Super + P`               | Skipta um gerviglugga-stíl (náttúrulegur á móti teygður) |
| `Super + F`                 | Fara í fullan skjá              |
| `Super + Alt + F`                 | Fara í fulla breidd              |
| `Super + Ctrl + F`                 | Fara í fullan skjá inni í glugga              |
| `Super + 1/2/3/4`         | Hoppa á ákveðið vinnusvæði á skjánum í fókus |
| `Super + Tab` | Hoppa á næsta vinnusvæði á skjánum í fókus |
| `Super + Shift + Tab` | Hoppa á fyrra vinnusvæði á skjánum í fókus |
| `Super + Ctrl + Tab` | Hoppa á fyrra vinnusvæðið á skjánum í fókus |
| `Super + Shift + 1/2/3/4` | Færa glugga á vinnusvæði á skjánum í fókus |
| `Super + Shift + Alt + 1/2/3/4` | Færa glugga á vinnusvæði á skjánum í fókus án þess að fylgja eftir |
| `Super + S` | Kveikja/slökkva á fullri kladdablokk |
| `Super + Alt + S` | Færa glugga á fulla kladdablokk |
| `Super + Grave` | Kveikja/slökkva á Quake-stjórnborði |
| `Super + Shift + Grave` | Færa glugga á Quake-stjórnborð |
| `Super + Shift + Ctrl + Arrows` | Færa glugga á skjáinn í þá átt |
| `Super + Shift + Alt + Arrows` | Færa vinnusvæði á skjáinn í þá átt |
| `Super + Arrow`  | Færa fókus á glugga í átt örvarinnar, fara yfir á skjáinn þeim megin við jaðar skjásins |
| `Super + Shift + Arrow`  | Skipta glugga við annan í átt örvarinnar, þar á meðal einn á skjánum þeim megin |
| `Super + Minus` | Stækka glugga til vinstri |
| `Super + Equal` | Minnka glugga til vinstri |
| `Super + Shift + Minus` | Minnka glugga upp |
| `Super + Shift + Equal` | Stækka glugga niður |
| `Super + Alt + Minus/Equal` | Sama stærðarbreyting í minni skrefum |
| `Super + Ctrl + Minus/Equal` | Sama stærðarbreyting í stærri skrefum |
| `Super + Alt + Home` | Vista breidd glugga |
| `Super + Home` | Endurheimta vistaða breidd glugga |
| `Super + Left Mouse` | Draga glugga um |
| `Super + Right Mouse` | Breyta stærð glugga |
| `Super + Scroll Wheel` | Skruna í gegnum vinnusvæði á skjánum í fókus |
| `Super + G`               | Kveikja/slökkva á flokkun glugga      |
| `Super + Alt + G`               | Færa glugga úr flokkun      |
| `Super + Alt + Tab`               | Fara á milli glugga í flokkun      |
| `Super + Alt + Shift + Tab`               | Fara aftur á bak á milli glugga í flokkun      |
| `Super + Alt + Scroll Wheel` | Fara á milli glugga í flokkun |
| `Super + Alt + 1/2/3/4/5`               | Hoppa á ákveðinn glugga í flokkun      |
| `Super + Alt + Arrow`  | Færa glugga inn í flokkun í átt örvarinnar, þar á meðal einn á skjánum þeim megin |
| `Super + Ctrl + Left/Right`  | Fara á milli glugga inni í flísalögðum hópi |
| `Super + Ctrl + Z` | Þysja inn á skjáinn (endurtaka fyrir meiri þysjun) |
| `Super + Ctrl + Alt + Z` | Þysja alveg út af skjánum |
| `Super + /` | Fara áfram í gegnum valkosti fyrir kvörðun skjás |
| `Super + Alt + /` | Fara aftur á bak í gegnum valkosti fyrir kvörðun skjás |
| `Alt + Tab` | Fara áfram í gegnum glugga á virka vinnusvæðinu |
| `Alt + Shift + Tab` | Fara aftur á bak í gegnum glugga á virka vinnusvæðinu |
| `Ctrl + Alt + Tab`| Fara með fókus áfram í gegnum skjái |
| `Ctrl + Alt + Shift + Tab`| Fara með fókus aftur á bak í gegnum skjái |

## Alhliða klippiborð

| Flýtilykill                  | Virkni              |
| ----------------------- | --------------------- |
| `Super + C`           | Afrita    |
| `Super + X`           | Klippa (ekki í skjáhermi)    |
| `Super + V`           | Líma    |
| `Super + Ctrl + V`           | Klippiborðsstjóri    |

Venjulega á Linux þarftu `Ctrl + Shift + C/V` til að afrita og líma í skjáherminum og `Ctrl + C/V` til að gera það alls staðar annars staðar. Þessir sameinuðu flýtilyklar Omarchy fyrir klippiborð virka alls staðar.

## Upptaka

| Flýtilykill              | Virkni                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Skjámynd                      |
| `Super + Ctrl + Alt + C`            | Skjámynd (sama mynd, fyrir lyklaborð án Print Screen takka) |
| `Super + Ctrl + C` | Upptökuvalmynd |
| `Alt + Print Screen`            | Skjáupptaka                     |
| `Super + Print Screen` | Litavaltól |
| `Super + Ctrl + Print Screen` | Textaútdráttur á klippiborð |
| `Super + Alt + [` | Gera yfirlögn vefmyndavélar minni meðan á upptöku stendur |
| `Super + Alt + ]` | Gera yfirlögn vefmyndavélar stærri meðan á upptöku stendur |
| `Alt + Shift + L` | Afrita núverandi URL úr vefforriti eða Chromium |
| `Alt + Shift + D` | Sækja myndbandið á núverandi síðu í `~/Videos` |
| `Super + Ctrl + X` | Hefja/stöðva talinnslátt (krefst _Uppsetning > Sjálfgefið > Talinnsláttur_) |
| `Right Alt` / `F9` | Ýta-til-að-tala talinnsláttur (krefst Voxtype eða Superwhisper) |

Með skjáupptökum spyr flýtilykillinn fyrst hvaða hljóð þú vilt, byrjar síðan upptöku. Ýttu á hann aftur til að stöðva. Sjá [skjámyndir og upptaka](12-screenshots-recording.md) fyrir nánari upplýsingar.

Allir upptökuvalkostir eru einnig aðgengilegir undir _Trigger > Capture_ í Omarchy-valmyndinni (`Super + Space`).

| ----------------------- | --------------------- |

## Stíll

| Flýtilykill                  | Virkni              |
| ----------------------- | --------------------- |
| `Super + Ctrl + T` | Velja nýtt þema (einnig `Super + Ctrl + Shift + Space`) |
| `Super + Ctrl + W` | Velja bakgrunn þema (einnig `Super + Ctrl + Space`) |
| `Super + Backspace` | Kveikja/slökkva á gegnsæi glugga |

Auka bakgrunnsmyndir eru í `~/.config/omarchy/backgrounds/<theme name>`. Einnig fáanlegt í gegnum _Install > Style > Background_ í Omarchy-valmyndinni.

Allir stílvalkostir eru einnig aðgengilegir undir _Style_ í Omarchy-valmyndinni (`Super + Space`).

## Tmux

Forskeytistakkinn er `Ctrl + Space` (`Ctrl + B` virkar líka). Þú getur breytt þessum bindingum í `~/.config/tmux/tmux.conf`.

### Rúður

| Flýtilykill                  | Virkni              |
| ----------------------- | --------------------- |
| `Prefix + v` | Skipta rúðu við hliðina (lóðrétt) |
| `Prefix + h` | Skipta rúðu fyrir neðan (lárétt) |
| `Prefix + x` | Drepa rúðu |
| `Prefix + z` | Kveikja/slökkva á þysjun rúðu (fullur skjár) |
| `Alt + Enter` | Skipta rúðu fyrir neðan (án forskeytis) |
| `Alt + Shift + Enter` | Skipta rúðu við hliðina (án forskeytis) |
| `Alt + Escape` | Drepa rúðu (án forskeytis) |
| `Ctrl + Alt + Arrows` | Fara á milli rúða |
| `Ctrl + Alt + Shift + Arrows` | Breyta stærð rúða |

### Gluggar

### Tmux uppröðunaraðgerðir

Þessar aðgerðir verður að keyra inni í Tmux setu.

| Skipun | Virkni |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Búa til þróunaruppröðun með ritli, AI og skjáhermi |
| `tdlm <ai> [<second_ai>]` | Búa til þróunaruppröðun fyrir hverja undirmöppu |
| `tsl <count> <command>` | Búa til fjölrúðu sveimuppröðun |
