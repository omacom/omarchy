# Знімки екрана й запис

Усе, що ви можете схопити з екрана, висить на клавіші Print Screen. Одна клавіша сама по собі робить знімок, а модифікатори роблять запис, колір або текст усередині ділянки. Якщо на вашій клавіатурі взагалі немає клавіші Print Screen, `Super + Ctrl + C` відкриває той самий набір як меню.

| Гаряча клавіша | Функція |
| ------ | -------- |
| `Print Screen` | Знімок екрана |
| `Alt + Print Screen` | Запис екрана (або зупинити той, що працює) |
| `Super + Print Screen` | Вибір кольору |
| `Super + Ctrl + Print Screen` | Вилучити текст із ділянки |
| `Super + Ctrl + C` | Меню захоплення |
| `Super + Ctrl + .` | Перекодувати знімок або відео |

## Знімки екрана

Натисніть `Print Screen`, і Omasnap захопить монітор у фокусі ще до появи його накладання, тож нічого не зсунеться під вами, поки ви цілитеся. Перетягніть довільну ділянку, клацніть вікно, щоб захопити його, або клацніть порожній простір, щоб захопити весь монітор. Натисніть `S` перед малюванням, щоб захопити ділянку з прокручуванням. Передумали? Натисніть `Print Screen` ще раз, щоб закрити Omasnap.

Після того як ви виберете ділянку, Omasnap збереже захоплення, скопіює його в буфер обміну й покаже попередній перегляд на 10 секунд. Скористайтеся кнопкою закріплення в попередньому перегляді або `Ctrl + P`, щоб залишити його на екрані, або оберіть «Редагувати», щоб додати примітки.

Редактор приміток може малювати стрілки, лінії, фігури, підсвічування, нумеровані позначки, текст і захищене редагування; обрізати або вирізати частину зображення; розпізнавати його текст через OCR; і додавати фон. У редакторі натисніть `Enter`, щоб скопіювати й зберегти готовий PNG, `Ctrl + C`, щоб скопіювати його без збереження, або `Ctrl + S`, щоб зберегти його без копіювання.

Збережені знімки екрана типово опиняються в `~/Pictures/Screenshots` з іменем на зразок `screenshot-2026-08-13_14-22-05-firefox.png`. Установіть `OMASNAP_SCREENSHOT_DIR`, щоб використовувати інший каталог — див. [FAQ](46-faq.md) про те, куди помістити змінні середовища сеансу. Omasnap створює каталог, коли зберігає перший знімок. Установіть `[output] autosave = false` в `~/.config/omasnap/omasnap.conf`, щоб вимкнути автоматичне збереження.

Із термінала `omarchy screenshot` відкриває те саме накладання, і ви можете обрати його початковий режим: `omarchy capture screenshot region`, `windows`, `fullscreen` або `scroll`. Другий аргумент `copy` або `save` пропускає попередній перегляд і надсилає знімок прямо до цього призначення. Щоб редагувати перед виведенням, використовуйте `omarchy screenshot --editor=overlay` для повноекранного редактора або `omarchy screenshot --editor=window` для окремого вікна.

### Керування вибором із клавіатури

Поки виділення активне, вам зовсім не треба використовувати мишу:

| Клавіша | Функція |
| --- | -------- |
| `S` | Перемикання режиму ділянки з прокручуванням |
| `Super + Arrow keys` | Рух між вікнами в режимі вікон |
| `Return` | Захопити підсвічене вікно |
| `Ctrl + A` | Захопити весь монітор у фокусі |
| `R` | Відновити останню ділянку, намальовану в цьому сеансі |
| `Esc` | Закрити Omasnap |

Ці призначення існують лише поки Omasnap відкритий, тож вони не можуть конфліктувати ні з чим у вашій власній конфігурації.

## Запис екрана

`Alt + Print Screen` відкриває _Дії > Захоплення > Запис екрана_, який запитує, що ви хочете на звуковій доріжці: без звуку, звук робочого столу, звук робочого столу плюс мікрофон або звук робочого столу плюс мікрофон плюс вебкамера. Цей останній варіант з’являється лише тоді, якщо у вас справді підключена камера. Оберіть один — і вибір запису Omarchy дасть вам перетягнути ділянку або клацнути вікно чи монітор.

Запис працює на gpu-screen-recorder, який кодує на GPU зі швидкістю 60 кадрів/с і повертається до CPU, якщо доводиться. Результат — MP4 у `~/Videos` з іменем `screenrecording-2026-08-13_14-22-05.mp4`. Установіть `OMARCHY_SCREENRECORD_DIR`, щоб змінити це, — але зауважте, що на відміну від каталогу знімків екрана, цей має вже існувати, інакше запис відмовиться починатися.

Поки ви записуєте, на панелі з’являється маленький індикатор. Клацніть його, щоб зупинити. Ви також можете зупинити через `Alt + Print Screen` ще раз або через запис _Зупинити запис екрана_ в _Дії > Захоплення > Запис екрана_, який з’являється лише поки щось насправді записується.

Зупинка трохи прибирає, перш ніж передати вам файл: перший кадр обрізається, а якщо є звук, він нормалізується до -14 LUFS, а тріск захоплення PipeWire на самому початку заглушається. Потім з’являється сповіщення з мініатюрою із запису. Клацніть його, щоб відтворити файл у mpv.

### Накладання вебкамери

Коли ви записуєте з вебкамерою, камера з’являється як закріплене, обрізане портретне вікно в нижньому правому куті всього, що ви записуєте. Якщо вона сидить поверх чогось потрібного вам, змінюйте її розмір на льоту:

| Гаряча клавіша | Функція |
| ------ | -------- |
| `Super + Alt + [` | Зменшити накладання вебкамери |
| `Super + Alt + ]` | Збільшити накладання вебкамери |

Є три розміри — малий, середній і великий, — і гарячі клавіші крокують між ними. Середній — типовий. Вони пропорційні до запису, тож камера займає ту саму частку кадру, чи записуєте ви монітор 1080p, чи 6K. А якщо ви записали ділянку, а не весь дисплей, накладання прив’язується до кута цієї ділянки, а не монітора, тож воно залишається всередині кадру.

Ви також можете викликати це безпосередньо через `omarchy-capture-webcam-resize small` або `reset`, щоб повернутися до середнього.

## Текст, QR-коди й кольори

`Super + Ctrl + Print Screen` обирає ділянку й розпізнає її через OCR у буфер обміну. Це належно описано в [Вилучення тексту й диктування](11-text-extraction-dictation.md).

_Дії > Захоплення > QR-код_ робить той самий трюк для QR-кодів. Виберіть ділянку з кодом у ній, і декодоване значення потрапить до буфера обміну. Він шукає лише QR-коди — щільний вміст екрана інакше має звичку хибно розпізнаватися як штрих-код. Варто знати: декодоване значення потрапляє до буфера обміну і нікуди більше. Воно не друкується, його немає в сповіщенні, і його позначено як конфіденційне, тож воно не зависає в [історії буфера обміну](08-unified-clipboard-history.md). QR-коди зазвичай несуть секрети — наприклад URI `otpauth://` за кодом налаштування 2FA, — і ви не хочете цього в журналі. Вставляння, як і раніше, працює добре.

`Super + Print Screen` (або _Дії > Захоплення > Колір_) перетворює курсор на піпетку. Клацніть будь-що на екрані — і колір опиниться в буфері обміну. Натисніть гарячу клавішу ще раз, щоб вийти без вибору.

## Перекодування перед тим, як поділитися

Запис екрана в 4K або сирий HEIC із вашого телефона часто завеликий, щоб просто надіслати. `Super + Ctrl + .` (або _Дії > Перекодувати_) це виправляє. Він пропонує вам нечіткий вибір файлів по `~/Pictures` і `~/Videos`, а потім запитує формат і розмір.

Знімки йдуть у jpg або png на високому, середньому чи низькому рівні, які обмежують ширину 3160, 2160 і 1080 пікселями. Відео йдуть у mp4 або анімований gif на 4k, 1080p чи 720p. Перекодований файл записується поряд з оригіналом із роздільністю в імені — `demo-1080p.mp4`, — а шлях копіюється до буфера обміну як URI файлу, тож ви можете вставити його безпосередньо в програму, яка приймає перетягування файлів.

Це також працює з термінала, якщо ви вже знаєте, що хочете: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. Є також `omarchy transcode ascii`, який перетворює зображення на ASCII-арт — це здебільшого для [брендингу](41-branding.md).

## Надсилання кудись

Щойно у вас є файл, `Super + Ctrl + S` відкриває меню «Поділитися» й надсилає його на інший пристрій у вашій мережі через LocalSend. Див. [графічні інтерфейси](22-guis.md) про це.
