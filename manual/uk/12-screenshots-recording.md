# Скріншоти та запис екрана

Усе, що можна захопити з екрана, зав’язано на клавішу Print Screen. Сама клавіша робить знімок, а модифікатори — запис, колір або текст усередині області. Якщо на вашій клавіатурі взагалі немає клавіші Print Screen, `Super + Ctrl + Alt + C` робить той самий скріншот, а `Super + Ctrl + C` відкриває весь набір як меню.

| Клавіша | Функція |
| ------ | -------- |
| `Print Screen` | Скріншот |
| `Super + Ctrl + Alt + C` | Скріншот |
| `Alt + Print Screen` | Запис екрана (або зупинити той, що вже йде) |
| `Super + Print Screen` | Піпетка кольору |
| `Super + Ctrl + Print Screen` | Видобути текст з області |
| `Super + Ctrl + C` | Меню захоплення |
| `Super + Ctrl + .` | Перекодувати зображення або відео |

## Скріншоти

Натисніть `Print Screen` (або `Super + Ctrl + Alt + C`), і Omasnap захопить сфокусований монітор до появи його оверлею, тож нічого не зсунеться під вами, поки ви цілитесь. Потягніть довільну область, клацніть вікно, щоб захопити його, або клацніть порожнє місце, щоб захопити весь монітор. Натисніть `S` перед малюванням, щоб захопити область із прокручуванням. Передумали? Натисніть ту саму клавішу ще раз, щоб закрити Omasnap.

Після вибору області Omasnap зберігає захоплення, копіює його до буфера обміну та показує попередній перегляд на 10 секунд. Скористайтеся кнопкою закріплення в попередньому перегляді або `Ctrl + P`, щоб залишити його на екрані, або виберіть Edit, щоб анотувати його.

Редактор анотацій уміє малювати стрілки, лінії, фігури, виділення, нумеровані маркери, текст і безпечні редакції; обрізати або вирізати частину зображення; розпізнавати його текст за допомогою OCR; і додавати підкладку. У редакторі натисніть `Enter`, щоб скопіювати та зберегти готовий PNG, `Ctrl + C`, щоб скопіювати його без збереження, або `Ctrl + S`, щоб зберегти його без копіювання.

Збережені скріншоти за замовчуванням потрапляють до `~/Pictures/Screenshots` із назвою на кшталт `screenshot-2026-08-13_14-22-05-firefox.png`. Встановіть `OMASNAP_SCREENSHOT_DIR`, щоб використовувати інший каталог — див. [FAQ](46-faq.md) щодо того, куди поміщати змінні середовища сеансу. Omasnap створює каталог, коли зберігає перший знімок. Встановіть `[output] autosave = false` у `~/.config/omasnap/omasnap.conf`, щоб вимкнути автоматичне збереження.

Із термінала `omarchy screenshot` відкриває той самий оверлей, і ви можете вибрати його початковий режим: `omarchy capture screenshot region`, `windows`, `fullscreen` або `scroll`. Другий аргумент `copy` або `save` пропускає попередній перегляд і надсилає знімок одразу до цього призначення. Щоб редагувати перед виведенням, скористайтеся `omarchy screenshot --editor=overlay` для повноекранного редактора або `omarchy screenshot --editor=window` для окремого вікна.

### Керування засобом вибору з клавіатури

Поки вибір відкрито, мишею взагалі користуватися не треба:

| Клавіша | Функція |
| --- | -------- |
| `S` | Увімкнути або вимкнути режим області з прокручуванням |
| `Super + Arrow keys` | Переміщатися між вікнами в режимі Window |
| `Return` | Захопити виділене вікно |
| `Ctrl + A` | Захопити весь сфокусований монітор |
| `R` | Відновити останню область, намальовану в цьому сеансі |
| `Esc` | Закрити Omasnap |

Ці прив’язки існують лише поки Omasnap відкрито, тож вони не можуть конфліктувати ні з чим у вашій власній конфігурації.

## Запис екрана

`Alt + Print Screen` відкриває _Trigger > Capture > Screenrecord_, де запитується, що ви хочете на звуковій доріжці: без звуку, звук робочого столу, робочий стіл плюс мікрофон або робочий стіл плюс мікрофон плюс вебкамеру. Останній варіант з’являється лише якщо у вас справді під’єднано камеру. Виберіть один, і засіб вибору запису Omarchy дасть вам потягнути область або клацнути вікно чи монітор.

Запис працює на gpu-screen-recorder, який кодує на GPU при 60fps і за потреби відкочується на CPU. Результат — MP4 у `~/Videos` із назвою `screenrecording-2026-08-13_14-22-05.mp4`. Встановіть `OMARCHY_SCREENRECORD_DIR`, щоб змінити це — але зверніть увагу: на відміну від каталогу скріншотів, цей має вже існувати, інакше запис відмовиться запускатися.

Під час запису в панелі з’являється маленький індикатор. Клацніть його, щоб зупинити запис. Також можна зупинити його повторним натисканням `Alt + Print Screen` або пунктом _Stop Screenrecording_ у _Trigger > Capture > Screenrecord_, який з’являється лише тоді, коли щось справді записується.

Зупинка трохи прибирає, перш ніж віддати вам файл: перший кадр обрізається, а якщо є звук, його нормалізують до -14 LUFS, а клацання захоплення PipeWire на самому початку заглушують. Потім з’являється сповіщення з мініатюрою із запису. Клацніть його, щоб відтворити файл у mpv.

### Оверлей вебкамери

Коли ви записуєте з вебкамерою, камера з’являється як закріплене, обрізане портретне вікно в нижньому правому куті того, що ви записуєте. Якщо вона сидить поверх чогось потрібного вам, змінюйте її розмір на льоту:

| Клавіша | Функція |
| ------ | -------- |
| `Super + Alt + [` | Зробити оверлей вебкамери меншим |
| `Super + Alt + ]` | Зробити оверлей вебкамери більшим |

Є три розміри — малий, середній і великий — і гарячі клавіші перемикають між ними. Середній використовується за замовчуванням. Вони пропорційні запису, тож камера займає ту саму частку кадру, незалежно від того, записуєте ви монітор 1080p чи 6K. А якщо ви записали область, а не весь дисплей, оверлей прив’язується до кута цієї області, а не монітора, тож залишається всередині кадру.

Ви також можете викликати це безпосередньо за допомогою `omarchy-capture-webcam-resize small` або `reset`, щоб повернутися до середнього.

## Текст, QR-коди та кольори

`Super + Ctrl + Print Screen` вибирає область і розпізнає її текст за допомогою OCR до буфера обміну. Це належним чином описано в [Видобування тексту та диктування](11-text-extraction-dictation.md).

_Trigger > Capture > QR Code_ робить той самий трюк для QR-кодів. Виберіть область із кодом у ній, і розшифроване значення потрапить до буфера обміну. Він шукає лише QR-коди — щільний вміст екрана інакше має звичку хибно спрацьовувати як штрихкод. Варто знати: розшифроване значення потрапляє до буфера обміну й більше нікуди. Воно не друкується, його немає в сповіщенні, і його позначено як конфіденційне, тож воно не затримується в [історії буфера обміну](08-unified-clipboard-history.md). QR-коди регулярно несуть секрети — наприклад, URI `otpauth://`, що стоїть за кодом налаштування 2FA, — і ви не хочете, щоб це потрапило до журналу. Вставлення все одно працює нормально.

`Super + Print Screen` (або _Trigger > Capture > Color_) перетворює курсор на піпетку. Клацніть будь-що на екрані, і колір потрапить до буфера обміну. Натисніть гарячу клавішу ще раз, щоб вийти без вибору.

## Перекодування перед поширенням

Запис екрана у 4K або необроблений HEIC із вашого телефона часто занадто великий, щоб просто його надіслати. `Super + Ctrl + .` (або _Trigger > Transcode_) це виправляє. Він пропонує вам нечіткий засіб вибору файлів по `~/Pictures` і `~/Videos`, а потім запитує формат і розмір.

Зображення перетворюються на jpg або png у високій, середній або низькій якості, які обмежують ширину до 3160, 2160 і 1080 пікселів. Відео перетворюються на mp4 або анімований gif у 4k, 1080p або 720p. Перетворений файл записується поруч із оригіналом із роздільністю в назві — `demo-1080p.mp4` — а шлях копіюється до буфера обміну як URI файлу, тож ви можете вставити його безпосередньо в застосунок, який приймає перетягування файлів.

Це працює й із термінала, якщо ви вже знаєте, чого хочете: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. Також є `omarchy transcode ascii`, яка перетворює зображення на ASCII-арт — це здебільшого для [брендингу](41-branding.md).

## Надсилання кудись

Щойно ви отримали файл, `Super + Ctrl + S` відкриває меню Share і надсилає його на інший пристрій у вашій мережі через LocalSend. Див. [Графічні інтерфейси](22-guis.md) щодо цього.
