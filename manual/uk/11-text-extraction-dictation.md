# Видобування тексту та диктування

### Видобування тексту

Натисніть `Super + Ctrl + PrtScr`, щоб вибрати область на екрані для видобування тексту. Відкрита модель OCR tesseract потім швидко перетворить цю виділену область на текст і помістить його до буфера обміну. Потім просто натисніть `Super + V`, щоб вставити.

Це дуже зручно для копіювання адрес із підвалів зображень або номерів телефонів, вбудованих у заголовки вебсайтів.

### Диктування

На свіжих встановленнях [Superwhisper](https://superwhisper.com/) є стандартним рушієм диктування, який використовує хмарну обробку без завантаження офлайн-моделей. Оберіть Superwhisper, [Voxtype](https://voxtype.io/) або [Hex](https://anoma.ly/hex/) через _Setup > Defaults > Dictation_ у меню Omarchy. Вибір рушія встановить його за потреби та зробить його стандартним для диктування. Voxtype завантажує базову англійську модель, яка займає 150MB; змініть модель за допомогою `voxtype setup model`, а інші налаштування — через `~/.config/voxtype/config.toml`. Superwhisper відкриває свої налаштування для вибору хмарної або локальної обробки, а OPR підтримує застосунок оновленим. Hex завантажує свою модель розпізнавання мовлення на пристрої під час налаштування та працює як користувацька служба `hex.service`; відкрийте його вікно з іконки в треї панелі або запустивши `hex`, щоб змінити модель та інші налаштування.

Ви диктуєте, утримуючи `Right Alt`, або перемикаючи за допомогою `Alt + Space`, і надиктований текст з’явиться в активній області введення. Ці комбінації використовують вибраний рушій. Right Alt також запускає диктування, коли використовується в комбінації з модифікатором; використовуйте Left Alt для таких комбінацій. На розкладках клавіатури, де Right Alt є AltGr, використовуйте `Alt + Space`, щоб зберегти AltGr доступним для набору тексту. Встановлення, зроблені до того, як Alt + Space стало стандартним, зберігають `F9` для режиму «натисни й говори» та `Super + Ctrl + X` для перемикання, додані до `~/.config/hypr/bindings.lua`; видаліть їх там, щоб повернути ці клавіші застосункам.

Ті самі комбінації працюють із кожним рушієм. Оберіть свій рушій через Setup > Defaults > Dictation. Інсталятор рушія налаштовує його та зберігає вибір. Запустіть `omarchy default dictation`, щоб побачити, який із них вибрано. Вибір зберігається у `~/.config/omarchy/defaults/dictation`. На свіжих встановленнях Superwhisper обирається автоматично.

Omarchy автоматично завантажує інтеграцію вибраного рушія з робочим столом. Жодної конфігурації Superwhisper у `~/.config/hypr/` не потрібно.

Власні прив’язки та скрипти можуть використовувати `omarchy dictation start`, `omarchy dictation stop` та `omarchy dictation toggle`. Вибраний рушій обробляє запис і транскрипцію. Вибір Superwhisper вимикає його рідну комбінацію утримання та встановлює його рідне перемикання на `Ctrl + Alt + Space`, тримаючи його окремо від клавіш запису Omarchy. Superwhisper вимагає щонайменше однієї рідної комбінації запису, а його комбінація скасування залишається доступною.

Додаткові рушії можуть інтегруватися без зміни Omarchy. Надайте виконуваний файл із назвою `omarchy-dictation-<backend>` у PATH, який приймає `start`, `stop` і `toggle` та швидко повертає керування, з ненульовим статусом у разі помилки. Його інсталятор налаштовує провайдера та викликає `omarchy-dictation-use <backend>` після успішного налаштування. Це зупиняє попередній рушій і атомарно зберігає вибір; `stop` має успішно завершуватися, коли провайдер перебуває в режимі очікування або недоступний. Назви рушіїв використовують малі літери, цифри та дефіси. Надайте `omarchy-install-dictation-<backend>` для налаштування; `omarchy default dictation <backend>` запускає його. Додайте запис у меню Defaults через розширення меню Omarchy, щоб викликати цей селектор. Необов’язкова інтеграція з робочим столом може міститися в `${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua`.
