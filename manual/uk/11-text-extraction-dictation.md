# Видобування тексту та диктування

### Видобування тексту

Натисніть `Super + Ctrl + PrtScr`, щоб вибрати область на екрані для видобування тексту. Потім OCR-модель tesseract з відкритим кодом швидко перетворить вибране на текст і помістить його в буфер обміну. Після цього просто натисніть `Super + V`, щоб вставити.

Це дуже корисно, щоб вихоплювати адреси з підвалів зображень або номери телефонів, вбудовані в заголовки вебсайтів.

### Диктування

На свіжих встановленнях [Superwhisper](https://superwhisper.com/) є типовим бекендом диктування та використовує хмарну обробку без завантаження моделей для офлайн-роботи. Виберіть Superwhisper або [Voxtype](https://voxtype.io/) через _Налаштування > За замовчуванням > Диктування_ в меню Omarchy. Вибір бекенда встановлює його за потреби та робить його типовим для диктування. Voxtype завантажує базову англійську модель, яка займає 150MB; змініть модель за допомогою `voxtype setup model`, а інші параметри — через `~/.config/voxtype/config.toml`. Superwhisper відкриває свої налаштування, щоб вибрати хмарну або локальну обробку, а OPR підтримує застосунок в актуальному стані.

Ви диктуєте, утримуючи `Right Alt`, або перемикаючись за допомогою `Alt + Space`, і надиктований текст з’явиться в області введення, що перебуває у фокусі. Ці сполучення клавіш використовують вибраний бекенд. Right Alt також запускає диктування, коли використовується в акорді модифікаторів; для таких акордів використовуйте Left Alt. На розкладках клавіатури, де Right Alt є AltGr, використовуйте `Alt + Space`, щоб AltGr залишався доступним для введення тексту. Встановлення з часів до того, як Alt + Space стало типовим, зберігають `F9` для push-to-talk і `Super + Ctrl + X` для перемикання, додані до `~/.config/hypr/bindings.lua`; видаліть їх звідти, щоб повернути ці клавіші застосункам.

Ті самі сполучення клавіш працюють з будь-яким бекендом. Виберіть свій бекенд через Налаштування > За замовчуванням > Диктування. Встановлювач бекенда налаштовує його та зберігає вибір. Запустіть `omarchy default dictation`, щоб побачити, який саме вибрано. Вибір зберігається у `~/.config/omarchy/defaults/dictation`. На свіжих встановленнях Superwhisper вибирається автоматично.

Omarchy автоматично завантажує інтеграцію вибраного бекенда з робочим столом. Жодної конфігурації Superwhisper у `~/.config/hypr/` не потрібно.

Користувацькі прив’язки та скрипти можуть використовувати `omarchy dictation start`, `omarchy dictation stop` і `omarchy dictation toggle`. Вибраний бекенд обробляє запис і транскрипцію. Вибір Superwhisper вимикає його власне сполучення клавіш для утримання та встановлює його власне перемикання на `Ctrl + Alt + Space`, тримаючи його окремо від клавіш запису Omarchy. Superwhisper вимагає принаймні одного власного сполучення клавіш для запису, а його сполучення клавіш для скасування залишається доступним.

Додаткові бекенди можуть інтегруватися без змін в Omarchy. Надайте виконуваний файл із назвою `omarchy-dictation-<backend>` у PATH, який приймає `start`, `stop` і `toggle` та швидко завершує роботу, повертаючи ненульовий статус у разі помилки. Його встановлювач налаштовує провайдера та викликає `omarchy-dictation-use <backend>` після успішного налаштування. Це зупиняє попередній бекенд і атомарно зберігає вибір; `stop` має успішно завершуватися, коли провайдер перебуває в режимі очікування або недоступний. Назви бекендів використовують малі літери, цифри та дефіси. Надайте `omarchy-install-dictation-<backend>` для налаштування; `omarchy default dictation <backend>` запускає його. Додайте запис у меню Defaults через розширення меню Omarchy, щоб викликати цей засіб вибору. Необов’язкова інтеграція з робочим столом може розміщуватися у `${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua`.
