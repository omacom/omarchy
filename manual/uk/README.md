## Як допомогти

- Перед перекладом звірте сторінку з актуальним файлом у каталозі `manual/` офіційного репозиторію.
- Не перекладайте команди, клавіатурні скорочення, шляхи, URL, назви продуктів та реальні назви пунктів інтерфейсу.
- Використовуйте однакові терміни з [глосарія](GLOSSARY.md).
- Зберігайте назву файлу, посилання, зображення та структуру заголовків оригіналу.

Це переклад спільноти, яка прагне стати офіційною українською локалізацією Omarchy.
