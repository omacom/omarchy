# Навігація

Усе в Omarchy відбувається за допомогою клавіатури — _АБСОЛЮТНО ВСЕ!_ Після першого запуску системи ви буквально нічого не зможете зробити лише мишею. Але натисніть `Super + Space`, щоб відкрити меню Omarchy, — звідси можна виконати майже будь-яку дію.

Проте меню Omarchy навіть не задумувалося як основний спосіб повсякденної роботи із системою. Можна швидше! Усі найважливіші програми мають власні клавіатурні скорочення. Термінал запускається через `Super + Return`, а браузер — через `Super + Shift + Return`. Спробуйте натиснути їх по черзі, і побачите магію мозаїчного компонування Hyprland:

![Браузер і термінал](../images/navigation-browser-terminal.webp)

Потім натисніть `Super + J`, щоб розташувати їх одне над одним замість розміщення поруч:

![Вікна одне над одним](../images/navigation-stacked.webp)

Ще раз натисніть `Super + J`, щоб повернути вікна до розміщення поруч. Тепер, коли активний браузер, спробуйте `Super + Shift + Arrow Right`, щоб поміняти вікна місцями.

Запустіть Activity Monitor за допомогою `Super + Ctrl + T`. Він зʼявиться як плаваюче вікно. Додати його до мозаїчного компонування можна через `Super + T` (повторне натискання знову зробить його плаваючим). Тепер натисніть `Super + Shift + F`, щоб відкрити файловий менеджер. Вийде охайне компонування з чотирьох частин:

![Мозаїка з чотирьох вікон](../images/navigation-fourway-tiling.webp)

Переходьте між вікнами за допомогою `Super + Arrow`. Фокус перемкнеться, а вказівник переміститься до центру нової активної програми.

Натисніть `Super + Shift + 2`, щоб перемістити активну програму до другого робочого простору. `Super + Shift + 1` поверне її назад. А `Super + Shift + Alt + 2` перенесе активну програму до другого робочого простору без переходу до нього.

Якщо утримувати `Super` і перетягувати вікно мишею, можна змінити його розташування. Якщо утримувати `Super` і тягнути правою кнопкою миші, розмір вікна можна змінювати довільно.

Вікно закривається через `Super + W` або `Super + Q`, а всі вікна — через `Ctrl + Alt + Delete`.

Перейти до повноекранного режиму можна через `Super + F`, розгорнути вікно на всю ширину зі збереженням верхньої панелі — через `Super + Alt + F`, а ввімкнути повноекранний режим усередині вікна — через `Super + Ctrl + F` (зручно для YouTube!).

### Компонування dwindle і scrolling

Типове компонування Omarchy називається dwindle. Воно постійно тримає на екрані всі вікна відкритого робочого простору, навіть якщо для цього їх доводиться зменшувати.

![Компонування dwindle](../images/navigation-dwindle-layout.webp)

Окремий робочий простір можна перевести в компонування scrolling, де вікна шикуються поруч і продовжуються за видимою межею екрана. Для перемикання поточного робочого простору в цей режим натисніть `Super + L`.

![Компонування scrolling](../images/navigation-scrolling-layout.webp)

Вибір зберігається окремо для кожного робочого простору. Наприклад, простір 1 може використовувати dwindle для перегляду вебсторінок, а простір 2 — scrolling для роботи з кодом; після перезапуску вони відновляться в тих самих режимах. Цей перемикач також доступний у меню Omarchy за шляхом _Trigger > Toggle > Workspace Layout_.

Якщо ви хочете використовувати scrolling типово, задайте це в `~/.config/hypr/looknfeel.lua`:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### Групування вікон

Вікна можна згрупувати через `Super + G`. Поки група активна, кожне запущене вікно приєднуватиметься до неї. Переходьте між згрупованими вікнами за допомогою `Super + Ctrl + Arrow Left/Right` або одразу відкривайте потрібне за порядком через `Super + Alt + 1/2/3/4`.

Вивести вікно з групи можна через `Super + Alt + G`, а розібрати всю групу — повторним натисканням `Super + G`. Щоб додати до групи вікно ззовні, використовуйте `Super + Alt + Arrows`.

### Закріплення вікон поверх робочих просторів

Через `Super + O` вікно можна вивести з компонування його робочого простору. Воно стане плаваючим, закріпленим і супроводжуватиме вас під час переходів між робочими просторами. Це чудово підходить для відеопрогравачів тощо.

![Закріплене плаваюче вікно](../images/navigation-popped-window.webp)

### Робочий простір scratchpad

Є також спеціальний робочий простір scratchpad, який випадає поверх поточного подібно до консолі Quake. Перемикайте його через `Super + Grave` або `Super + S`, а переміщуйте до нього вікно через `Super + Shift + Grave` або `Super + Alt + S`.

Він особливо зручний для термінала із запущеним агентом або елементів керування, до яких потрібен швидкий доступ без виходу з поточного робочого простору. Щоб забрати вікно зі scratchpad, надішліть його безпосередньо до іншого простору, наприклад через `Super + Shift + 1`.

Коли у scratchpad лише одне вікно, він випадає як панель по центру, а не займає всю ширину. Додайте другу програму — і він знову розгорнеться на всю ширину, щоб обидва вікна могли розміститися поруч.

### До цього треба трохи звикнути!

Щоб звикнути до такої навігації стільницею, потрібен певний час. Але після цього повертатися до традиційної стільниці з керуванням мишею вже не захочеться!
