# Уніфікований буфер обміну та історія

Зазвичай у Linux вам потрібні `Ctrl + Shift + C/V`, щоб копіювати та вставляти в терміналі, і `Ctrl + C/V`, щоб робити це скрізь деінде. До цього важко звикнути кожному, хто не народився й не виріс на Linux! Так само важко перейти з Super на Ctrl, якщо ви приходите з Mac.

Omarchy вирішує обидві проблеми уніфікованими гарячими клавішами буфера обміну, які працюють (майже) скрізь. Ось вони:

| Hotkey | Command |
| ------- | ----------- |
| Super + A | Вибрати все |
| Super + C | Копіювати |
| Super + X | Вирізати |
| Super + V | Вставити |
| Super + Ctrl + V | Історія буфера обміну |

_Зауважте, що більшість агентних оболонок використовуватиме `Ctrl + V` для вставлення зображень, але `Super + V` — для вставлення тексту._

Використовуйте `Super + A`, потім `Super + C`, щоб скопіювати все у сфокусованому текстовому полі або іншому застосунку, який підтримує `Ctrl + A`. У терміналі `Ctrl + A` переміщує на початок командного рядка замість вибору його тексту.

### Історія буфера обміну

Історію буфера обміну надає оболонка Omarchy, і вона працює як для тексту, так і для зображень. Ви викликаєте її за допомогою `Super + Ctrl + V` і вибираєте потрібний запис клавішею Return, яка вставляє його безпосередньо в застосунок, у якому ви були. Використовуйте `Shift + Return`, щоб лише скопіювати його до буфера обміну, `Alt + Return`, щоб відкрити його, `Delete`, щоб видалити його з історії, і `Shift + Delete`, щоб очистити всю історію.
