# Єдиний буфер обміну й історія

Зазвичай у Linux вам потрібні `Ctrl + Shift + C/V` для копіювання й вставляння в терміналі та `Ctrl + C/V` — скрізь в інших місцях. До цього важко звикнути будь-кому, хто не народився й не виріс на Linux! Так само, як і до переходу з Super на Ctrl, якщо ви приходите з Mac.

Omarchy розв’язує обидві проблеми єдиними гарячими клавішами буфера обміну, які працюють (майже) скрізь. Ось вони:

| Гаряча клавіша | Команда |
| ------- | ----------- |
| Super + C | Копіювати |
| Super + X | Вирізати |
| Super + V | Вставити |
| Super + Ctrl + V | Історія буфера обміну |

_Зауважте, що більшість оболонок агентів використовуватимуть `Ctrl + V` для вставляння зображень, але `Super + V` — для вставляння тексту._

### Історія буфера обміну

Історію буфера обміну надає оболонка Omarchy, і вона працює як для тексту, так і для зображень. Ви викликаєте її через `Super + Ctrl + V`, обираєте запис клавішею Return, і тоді він опиняється в буфері обміну, готовий до вставляння через `Super + V`.
