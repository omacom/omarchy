# Єдиний буфер обміну та його історія

Зазвичай у Linux для копіювання й вставлення в терміналі потрібно натискати `Ctrl + Shift + C/V`, а в решті програм — `Ctrl + C/V`. До цього непросто звикнути тому, хто не користувався Linux усе життя! Користувачам Mac також незвично перейти із Super на Ctrl.

Omarchy розвʼязує обидві проблеми за допомогою єдиних клавіатурних скорочень буфера обміну, які працюють (майже) всюди:

| Клавіатурне скорочення | Команда |
| --- | --- |
| `Super + C` | Копіювати |
| `Super + X` | Вирізати |
| `Super + V` | Вставити |
| `Super + Ctrl + V` | Історія буфера обміну |

_Зверніть увагу: більшість середовищ для роботи з агентами використовують `Ctrl + V` для вставлення зображень, а `Super + V` — для вставлення тексту._

### Історія буфера обміну

Історію буфера обміну забезпечує оболонка Omarchy; вона працює як із текстом, так і з зображеннями. Відкрийте її через `Super + Ctrl + V`, виберіть потрібний запис клавішею Return — і він потрапить до буфера обміну, готовий до вставлення через `Super + V`.
