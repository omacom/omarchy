# Уніфікований буфер обміну та історія

Зазвичай у Linux потрібно натискати `Ctrl + Shift + C/V`, щоб копіювати й вставляти в терміналі, і `Ctrl + C/V`, щоб робити це всюди в інших місцях. До цього важко звикнути будь-кому, хто не народився й не виріс на Linux! Так само важко дається й перехід із super на ctrl, якщо ви переходите з Mac.

Omarchy вирішує обидві проблеми за допомогою уніфікованих гарячих клавіш буфера обміну, які працюють (майже) всюди. Ось вони:

| Гаряча клавіша | Команда |
| ------- | ----------- |
| Super + A | Вибрати все |
| Super + C | Копіювати |
| Super + X | Вирізати |
| Super + V | Вставити |
| Super + Ctrl + V | Історія буфера обміну |

_Зверніть увагу, що більшість агентних оболонок використовуватимуть `Ctrl + V` для вставки зображень, але `Super + V` для вставки тексту._

Використовуйте `Super + A`, а потім `Super + C`, щоб скопіювати все в активному текстовому полі чи іншій програмі, яка підтримує `Ctrl + A`. У терміналі `Ctrl + A` переміщує на початок командного рядка, а не вибирає його текст.

### Історія буфера обміну

Історію буфера обміну надає оболонка Omarchy, і вона працює як для тексту, так і для зображень. Ви викликаєте її за допомогою `Super + Ctrl + V`, вибираєте потрібний запис клавішею return, і потім він буде поміщений у буфер обміну, готовий до вставки за допомогою `Super + V`.
