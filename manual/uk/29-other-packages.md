# Інші пакунки

Arch має разюче багатство пакунків, доступних майже для будь-якого типу програмного забезпечення, — між офіційним репозиторієм і Arch User Repository (AUR).

Легше вже бути не може. Новий пакунок Arch ви встановлюєте, перейшовши до _Встановити > Пакунок_ у меню Omarchy (`Super + Space`) і набравши пакунок, який хочете. Він автоматично нечітко відфільтрує список усіх пакунків. (Ви також можете зробити це вручну командою `omarchy pkg add [package]` у терміналі).

Те саме можна робити з AUR — просто скористайтеся _Встановити > AUR_. Тільки памʼятайте, що AUR не проходить перевірку командою Arch. Це як RubyGems чи npm. Вивантажувати може хто завгодно.

Якщо хочете прибрати пакунок, можете скористатися _Видалити > Пакунок_ у меню Omarchy. Воно прибере пакунок, конфігураційні файли й залежності. (Ви також можете зробити це вручну командою `omarchy pkg drop [package]`).
