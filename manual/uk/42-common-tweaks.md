# Поширені налаштування

Це колекція поширених припасувань до налаштування Omarchy. Майте на увазі, що іноді оновленням системи може знадобитися повернути певні конфігурації до їхнього початкового стану. Якщо це станеться, ваші зміни не загубляться, а будуть покладені у файл `.bak` у тому самому каталозі.

Якщо ви щось зіпсуєте, ви можете відновити окремі конфігурації до їхнього початкового налаштування через _Оновити > Config_ у меню Omarchy. Якщо ви _справді_ зіпсуєте все, ви можете скинути всі конфігурації за допомогою `omarchy-reinstall`.

### Показувати всі значки області сповіщень увесь час

За замовчуванням значки області сповіщень, як-от Dropbox, 1password або Steam, приховані за стрілкою розгортання області сповіщень, яка показує їх, коли ви наводите на неї вказівник. Якщо ви хочете, щоб вони були відкриті увесь час, клацніть правою кнопкою миші стрілку розгортання, щоб відкрити менеджер значків області сповіщень, а потім закріпіть значки, які хочете тримати видимими (ви також можете приховати ті, які ніколи не хочете бачити).

### Заокруглені кути вікон

Типовий дизайн Omarchy — квадратні кути, але якщо ви хочете трохи пом'якшити це, ви можете змінити `~/.config/hypr/looknfeel.lua`, щоб заокруглення більше не було закоментованим:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### Прибрати відступи вікон

На дисплеях ноутбуків деякі люди воліють не марнувати жодного пікселя на відступи вікон (або навіть на верхню панель, яку можна вимкнути за допомогою `Super + Shift + Space`). Ви можете вимкнути всі відступи та рамки за допомогою `Super + Shift + Backspace` або прибрати їх назавжди, прибравши коментарі в цьому розділі `~/.config/hypr/looknfeel.lua`:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
