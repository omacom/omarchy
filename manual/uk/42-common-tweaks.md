# Поширені твіки

Це добірка поширених припасувань під себе конфігурації Omarchy. Майте на увазі: для оновлень системи іноді може знадобитися повернути певні конфіги до їхнього початкового стану. Якщо це станеться, ваші зміни не загубляться, а будуть поміщені у файл `.bak.<timestamp>` поруч з оригіналом.

Якщо ви щось напортачите, окремі конфіги можна повернути до початкової конфігурації через _Update > Config_ у меню Omarchy. Якщо ви _справді_ напортачите з усім, усі конфіги можна скинути за допомогою `omarchy reinstall configs` або перевстановити всі стандартні пакунки й конфіги за допомогою `omarchy reinstall`.

### Показувати всі іконки трею постійно

За замовчуванням іконки трею, як-от Dropbox, 1password або Steam, сховані за стрілкою розгортання трею, яка показує їх, коли ви наводите на неї курсор. Якщо хочете, щоб вони були видимі постійно, клацніть правою кнопкою миші стрілку розгортання, щоб відкрити менеджер іконок трею, а потім закріпіть іконки, які хочете тримати видимими (також можна сховати ті, які ніколи не хочете бачити).

### Заокруглені кути вікон

Стандартний дизайн Omarchy — із квадратними кутами, але якщо хочете трохи його пом’якшити, виберіть _Appearance > Windows > Window Corners > Rounded Corners_ у меню Omarchy або виконайте `omarchy hyprland corners rounded`. _Theme Corners_ повертає те, що використовує тема. Щоб задати власний радіус, залишайтеся на _Theme Corners_ (`omarchy hyprland corners theme`), оскільки Rounded і Sharp завантажуються після вашого конфіга й перевизначають його, та розкоментуйте заокруглення в `~/.config/hypr/looknfeel.lua`:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### Прибрати проміжки між вікнами

На екранах ноутбуків дехто воліє не витрачати жодного пікселя на проміжки між вікнами (або навіть на верхню панель, яку можна перемкнути за допомогою `Super + Shift + Space`). Усі проміжки й рамки можна перемкнути за допомогою `Super + Shift + Backspace` або прибрати їх назавжди, знявши коментарі в цьому розділі файлу `~/.config/hypr/looknfeel.lua`:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
