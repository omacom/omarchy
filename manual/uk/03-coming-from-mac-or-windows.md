# Перехід із Mac або Windows

Якщо ви роками користувалися macOS або Windows, ваші пальці памʼятають сотню речей, про які мозок уже й забув. Цей розділ допоможе перенести звичні дії в Omarchy. Самі можливості докладно описано в інших розділах — тут лише карта відповідностей.

### Super — центр усього

Уся мʼязова памʼять, повʼязана з Cmd або клавішею Windows, переноситься на одну клавішу — Super. На клавіатурі ПК це клавіша Windows, і саме вона є основою майже всіх клавіатурних скорочень Omarchy.

Звичну дію зі Spotlight, Raycast або меню Start тепер виконує `Super + Space`. Вона відкриває меню Omarchy, з якого можна запускати програми, змінювати налаштування, встановлювати програмне забезпечення, робити знімки екрана — майже все. Почніть вводити текст, щоб відфільтрувати список. Окреме меню лише з програмами відкривається через `Super + Alt + Space`. Див. [навігацію](04-navigation.md).

### Тут немає панелі Dock і значків на стільниці

Немає нічого, на що треба натискати для запуску програм, і немає значків, які треба впорядковувати на стільниці. Програми запускаються клавіатурними скороченнями (`Super + Return` для термінала, `Super + Shift + Return` для браузера, а `Super + K` показує всі призначені дії) або з меню. Єдиний постійний елемент інтерфейсу — [верхня панель](05-the-top-bar.md), яка замінює меню, системний трей і Центр сповіщень, до яких ви звикли. Майже кожен її віджет реагує на натискання лівою, правою та середньою кнопками миші.

### Вікна розміщуються самі

Найбільша зміна у звичках: вікна не потрібно перетягувати або привʼязувати до половин екрана. Відкрийте одне вікно — воно займе весь екран. Відкрийте друге — вони розділять простір. Вам ніколи не доведеться діставати одне вікно з-під іншого, бо вікна не перекриваються.

Коли справді потрібне плаваюче вікно, `Super + T` виводить активне вікно з мозаїчного компонування й повертає його назад. Але спочатку дайте мозаїчному режиму справжній шанс — це серце всієї системи. Докладніше див. у розділі [«Навігація»](04-navigation.md).

Робочі простори здадуться знайомими: це аналоги Spaces у macOS або віртуальних стільниць Windows, але ви дійсно ними користуватиметеся, адже `Super + 1/2/3/4` миттєво переходить до потрібного простору, а `Super + Shift + 1/2/3/4` переносить туди активне вікно. Жодної затримки на анімацію — лише миттєві переходи. Тож, можливо, вам навіть не знадобиться кілька моніторів, якщо раніше ви до них звикли.

### Копіювання і вставлення просто працюють

На Mac скрізь використовувалося Cmd + C. У Windows — Ctrl + C, крім термінала, де ця комбінація завершує програму. В Omarchy є `Super + C`, `Super + X` і `Super + V`, і вони працюють усюди, зокрема в терміналі. Для оболонки не доведеться виробляти окрему звичку.

Для користувачів Windows: аналог історії буфера обміну Win + V відкривається через `Super + Ctrl + V` і зберігає не лише текст, а й зображення. Див. [уніфікований буфер обміну та історію](../08-unified-clipboard-history.md).

### Таблиця відповідностей

| Звична дія | В Omarchy |
| ------------- | ---------- |
| Spotlight / Raycast / меню Start | `Super + Space` — меню Omarchy |
| AirDrop | LocalSend через `Super + Ctrl + S` — див. [графічні програми](../22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Print Screen` — див. [знімки та запис екрана](../12-screenshots-recording.md) |
| Центр сповіщень | Історія сповіщень через `Super + Shift + Alt + ,` |
| Time Machine (для системи) | Автоматичні [знімки системи](../47-system-snapshots.md) під час кожного оновлення |
| App Store / завантаження інсталятора | _Install_ у меню або `omarchy pkg add` — див. [інші пакунки](../29-other-packages.md) |
| System Settings / Control Panel | _Setup_ у меню, яке редагує звичайні конфігураційні файли, — див. [dotfiles](../31-dotfiles.md) |

### Деякі речі справді відрізняються

Багато налаштувань зберігаються в текстових файлах, які ви редагуєте, а не в панелях, на які натискаєте. Це здається примітивним, доки не усвідомите, що кожну зміну можна переглянути, скопіювати на наступний компʼютер і зберігати в системі контролю версій. Меню _Setup_ одразу відкриває потрібний файл, а після завершення роботи перезапускає все необхідне.

Оновлення виконуються однією командою — _Update > Omarchy_. Вона оновлює саму Omarchy та всі пакунки системи, попередньо створивши знімок. Жодних окремих засобів оновлення програм, які набридають у випадковий час. Див. [оновлення](../30-updates.md).

Програмне забезпечення надходить із менеджера пакунків, а не із завантажених інсталяторів.

Коли ви закриваєте вікно, програма справді завершує роботу. Тут немає властивого macOS проміжного стану, коли програма продовжує працювати без відкритих вікон. `Super + W` — або `Super + Q`, якщо до цієї комбінації звикли ваші пальці, — означає повне завершення.

### На обладнанні Mac

Omarchy добре працює на Mac із процесорами Intel — див. [підтримку Mac](../44-mac-support.md). З клавіатурою теж усе зручно: Omarchy нічого не перепризначає, а Linux сприймає клавішу Command як Super, тож вона залишається саме там, де завжди була Cmd. Ваш великий палець навіть не помітить переходу.

### Дайте собі два тижні

Звички переносяться швидше, ніж здається. Один раз перегляньте розділ про [клавіатурні скорочення](../07-hotkeys.md), а коли забудете потрібну комбінацію, натисніть `Super + K` — зʼявиться повний список. Це єдине скорочення, яке справді треба запамʼятати.
