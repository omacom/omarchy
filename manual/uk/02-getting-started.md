# Початок роботи

Omarchy встановлюється з ISO-образу. Можна вибрати встановлення на весь диск, яке займе весь накопичувач, або встановлення у вільний простір — Omarchy буде розміщено в нерозподіленій області диска. Саме так налаштовують подвійне завантаження разом із Windows чи іншою ОС (див. [встановлення з подвійним завантаженням](../50-dual-boot-install.md), поки що англійською; зверніть увагу, що спочатку у Windows потрібно вимкнути BitLocker). В обох випадках типово використовується повне шифрування, а встановлення на весь диск зітре вибраний накопичувач. Тому обовʼязково створіть резервну копію, перш ніж використовувати диск із наявними даними!

Спочатку [завантажте ISO-образ Omarchy](https://omarchy.org/), запишіть його на USB-накопичувач (за допомогою [balenaEtcher](https://etcher.balena.io/) у Mac/Windows або [caligula](https://github.com/ifd3f/caligula) у Linux), а потім завантажте компʼютер із цього накопичувача.

_У BIOS потрібно вимкнути Secure Boot та/або TPM. Без цього встановити Omarchy не вдасться. Це засоби безпеки Microsoft, призначені для Windows і повʼязаних із Microsoft дистрибутивів Linux._

Дайте відповіді на запитання щодо конфігурації та підтвердьте їх:

![Конфігурація встановлення](../images/install-config.webp)

Потім виберіть диск для встановлення й спостерігайте за процесом. На найшвидших сучасних компʼютерах він може тривати менше хвилини, але навіть на старішому обладнанні не повинен зайняти понад пʼять хвилин.

![Встановлення завершено](../images/install-done.webp)

Тепер усе готово до Omarchy!

### Використовуйте дротову клавіатуру або клавіатуру з адаптером 2,4 ГГц

Через повне шифрування диска на етапі запуску не можна ввести пароль із Bluetooth-клавіатури — так само, як не можна керувати BIOS компʼютера через Bluetooth. Знадобиться клавіатура з адаптером 2,4 ГГц або кабелем (кабель, до того ж, забезпечує значно меншу затримку). Особисто мені дуже подобається [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard)!

### Встановлення для іншого власника

Якщо ви налаштовуєте компʼютер для когось іншого — члена родини, нового працівника чи покупця, — не варто відповідати на особисті запитання замість нього. Натисніть `Ctrl + C` на першому ж екрані інсталятора (вибір клавіатури), і Omarchy запропонує підготувати компʼютер для іншого власника. Система встановиться одразу, але всі особисті налаштування — розкладку клавіатури, імʼя користувача та пароль — буде відкладено до першого запуску. Диск усе одно типово шифрується, а пароль, який новий власник вибере під час першого запуску, стане також паролем шифрування. Компʼютер, яким ви вже користувалися, теж можна передати без повторного встановлення — див. [скидання компʼютера](../48-security.md) (поки що англійською).

### Автоматичне встановлення

ISO-образ може виконати встановлення цілком самостійно — без клавіатури та майстра, — якщо отримує конфігурацію з другого накопичувача. Так Omarchy можна використовувати як базовий образ для віртуальних машин і парку компʼютерів. Див. [автоматичне встановлення](../51-unattended-installs.md) (поки що англійською).

### Встановлення без шифрування

Типово Omarchy встановлюється із шифруванням. Це безпечний і відповідальний вибір для будь-якого компʼютера, який можуть загубити або вкрасти. Ви ж не хочете, щоб людина з фізичним доступом до вашого обладнання отримала ваші дані!

Однак за особливих обставин — наприклад, для віддаленого встановлення Omarchy на захищений компʼютер або одноразової системи без конфіденційних даних — може знадобитися встановлення без шифрування. Натисніть `Ctrl + C` на екрані підтвердження форматування диска, щоб перейти до такого режиму.

### Допомога, якщо щось не виходить

Якщо ви застрягли, зазвичай можна знайти охочих допомогти в каналі _#omarchy-help_ на [Discord-сервері спільноти](https://omarchy.org/discord).
