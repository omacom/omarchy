# Гарячі клавіші

Ви можете переглянути всі основні прив'язки клавіш за допомогою `Super + K` (прив'язки Tmux — за допомогою `Super + Alt + K`, а прив'язки Herdr — за допомогою `Super + Ctrl + K`).

## Як влаштовані гарячі клавіші

Кожна гаряча клавіша перебуває на площині, визначеній її модифікаторами, і кожна площина має одне завдання. Саме це не дає гарячим клавішам змішуватися, і зазвичай ви можете здогадатися, де що розташовано.

| Площина | Що там розташовано | Приклади |
| --- | --- | --- |
| `Super + key` | Система: вікна, робочі простори, макети та основні меню | `Super + Space` меню Omarchy, `Super + W` закрити вікно, `Super + F` на весь екран |
| `Super + Shift + key` | Застосунки | `Super + Shift + B` браузер, `Super + Shift + E` електронна пошта, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панелі та системні меню | `Super + Ctrl + A` аудіо, `Super + Ctrl + N` мережа, `Super + Ctrl + C` меню захоплення |
| `Super + Ctrl + Alt + key` | Швидкі дії та сповіщення | `Super + Ctrl + Alt + T` показати час, `Super + Ctrl + Alt + B` батарея, `Super + Ctrl + Alt + C` знімок екрана |

Додавання `Alt` до гарячої клавіші дає вам варіант того самого, ніколи щось непов'язане:

- `Super + Shift + B` відкриває браузер; `Super + Shift + Alt + B` відкриває приватне вікно
- `Super + Shift + E` відкриває електронну пошту; `Super + Shift + Alt + E` створює новий лист
- `Super + F` переходить на весь екран; `Super + Alt + F` переходить на всю ширину
- `Super + Ctrl + C` відкриває меню захоплення; `Super + Ctrl + Alt + C` пропускає меню й робить знімок екрана

Додаючи гарячу клавішу:

1. Оберіть площину за тим, що вона робить, а потім оберіть клавішу.
2. Не переміщуйте наявну гарячу клавішу, щоб звільнити місце. Знайдіть вільну клавішу на правильній площині.
3. Використовуйте `Alt` лише для варіанта гарячої клавіші без неї.

Кілька гарячих клавіш порушують ці правила, бо так зручно. `Shift` зі стрілкою або `Tab` переміщує або повертає у зворотному напрямку, а не відкриває застосунок, а `Print`, медіаклавіші, `Alt + Tab` і `Ctrl + Alt + Del` працюють так само, як і скрізь. Це винятки, а не зразки для наслідування.

Якщо типова прив'язка вам не підходить (скажімо, ви хочете `Super + Shift + S` для знімків екрана, як у Windows), перевизначте її в `~/.config/hypr/bindings.lua`.

Гарячі клавіші змінення розміру використовують фізичні клавіші `code:20` і `code:21` (XKB `<AE11>` і `<AE12>`), незалежно від символів, надрукованих на клавіатурі. На клавіатурах US це клавіші `-` і `=`; на японських (JIS) клавіатурах це `-` і `^`; на іспанських клавіатурах це `'` і `¡`. На JIS `Super + ^` — це `Super + Equal`, а `Super + Shift + -` (що вводить `=`) — це `Super + Shift + Minus`.

## Універсальний буфер обміну

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Super + A`           | Вибрати все в застосунках, що підтримують `Ctrl + A`    |
| `Super + C`           | Копіювати    |
| `Super + X`           | Вирізати (не в терміналі)    |

### Функції макетів Tmux

Ці функції слід запускати всередині сесії Tmux.

| Команда | Функція |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Створити макет розробника з редактором, AI і терміналом |
| `tdlm <ai> [<second_ai>]` | Створити макет розробника для кожного підкаталогу |
| `tsl <count> <command>` | Створити багатопанельний макет swarm |
