# Гарячі клавіші

Ви можете переглянути всі основні поєднання клавіш за допомогою `Super + K` (поєднання Tmux — за допомогою `Super + Alt + K`, а поєднання Herdr — за допомогою `Super + Ctrl + K`).

## Навігація

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Super + Space`           | Меню Omarchy (застосунки та все інше)    |
| `Super + Alt + Space` | Сітка застосунків |
| `Super + Escape` | Системне меню (призупинення, перезапуск тощо)  |
| `Super + Ctrl + L` | Заблокувати комп’ютер |
| `Super + W` or `Super + Q` | Закрити вікно             |
| `Ctrl + Alt + Del` | Закрити всі вікна |
| `Super + T`               | Перемкнути вікно між плитковим/плаваючим режимами             |
| `Super + J` | Перемкнути положення вікна (горизонтальне/вертикальне) |
| `Super + O`               | Перемкнути вікно, що вискакує, у липке й плаваюче |
| `Super + L`               | Циклічно перемикати розкладки dwindle, scrolling і floating |
| `Super + Alt + L`         | Циклічно перемикати розкладки у зворотному порядку |
| `Super + P`               | Перемкнути стиль псевдовікна (природний проти розтягнутого) |
| `Super + F`                 | Перейти в повноекранний режим              |
| `Super + Alt + F`                 | Розгорнути на всю ширину              |
| `Super + Ctrl + F`                 | Перейти в повноекранний режим усередині вікна              |
| `Super + 1/2/3/4`         | Перейти до певного робочого простору на моніторі у фокусі |
| `Super + Tab` | Перейти до наступного робочого простору на моніторі у фокусі |
| `Super + Shift + Tab` | Перейти до попереднього робочого простору на моніторі у фокусі |
| `Super + Ctrl + Tab` | Перейти до колишнього робочого простору на моніторі у фокусі |
| `Super + Shift + 1/2/3/4` | Перемістити вікно до робочого простору на моніторі у фокусі |
| `Super + Shift + Alt + 1/2/3/4` | Перемістити вікно до робочого простору на моніторі у фокусі, не переходячи за ним |
| `Super + S` | Перемкнути повний scratchpad |
| `Super + Alt + S` | Перемістити вікно до повного scratchpad |
| `Super + Grave` | Перемкнути консоль Quake |
| `Super + Shift + Grave` | Перемістити вікно до консолі Quake |
| `Super + Shift + Ctrl + Arrows` | Перемістити вікно на монітор у тому напрямку |
| `Super + Shift + Alt + Arrows` | Перемістити робочий простір на монітор у тому напрямку |
| `Super + Arrow`  | Перемістити фокус до вікна в напрямку стрілки, переходячи на монітор з того боку біля краю екрана |
| `Super + Shift + Arrow`  | Поміняти вікно місцями з іншим у напрямку стрілки, включно з вікном на моніторі з того боку |
| `Super + Minus` | Розширити вікно вліво |
| `Super + Equal` | Звузити вікно вліво |
| `Super + Shift + Minus` | Зменшити вікно вгору |
| `Super + Shift + Equal` | Розширити вікно вниз |
| `Super + Alt + Minus/Equal` | Те саме змінення розміру меншими кроками |
| `Super + Ctrl + Minus/Equal` | Те саме змінення розміру більшими кроками |
| `Super + Alt + Home` | Зберегти ширину вікна |
| `Super + Home` | Відновити збережену ширину вікна |
| `Super + Left Mouse` | Перетягувати вікно |
| `Super + Right Mouse` | Змінювати розмір вікна |
| `Super + Scroll Wheel` | Прокручувати робочі простори на моніторі у фокусі |
| `Super + G`               | Перемкнути групування вікон      |
| `Super + Alt + G`               | Вивести вікно з групування      |
| `Super + Alt + Tab`               | Циклічно перемикати вікна в групі      |
| `Super + Alt + Shift + Tab`               | Циклічно перемикати вікна в групі у зворотному порядку      |
| `Super + Alt + Scroll Wheel` | Циклічно перемикати вікна в групі |
| `Super + Alt + 1/2/3/4/5`               | Перейти до певного вікна в групі      |
| `Super + Alt + Arrow`  | Перемістити вікно в групу в напрямку стрілки, включно з вікном на моніторі з того боку |
| `Super + Ctrl + Left/Right`  | Переміщатися між вікнами всередині плиткової групи |
| `Super + Ctrl + Z` | Збільшити масштаб екрана (повторити для більшого збільшення) |
| `Super + Ctrl + Alt + Z` | Повністю зменшити масштаб екрана |
| `Super + /` | Крок уперед серед варіантів масштабування монітора |
| `Super + Alt + /` | Крок назад серед варіантів масштабування монітора |
| `Alt + Tab` | Циклічно перемикати вікна вперед на активному робочому просторі |
| `Alt + Shift + Tab` | Циклічно перемикати вікна назад на активному робочому просторі |
| `Ctrl + Alt + Tab`| Циклічно переміщати фокус уперед між моніторами |
| `Ctrl + Alt + Shift + Tab`| Циклічно переміщати фокус назад між моніторами |

## Універсальний буфер обміну

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Super + C`           | Копіювати    |
| `Super + X`           | Вирізати (не в терміналі)    |
| `Super + V`           | Вставити    |
| `Super + Ctrl + V`           | Менеджер буфера обміну    |

Зазвичай у Linux вам потрібне `Ctrl + Shift + C/V`, щоб копіювати й вставляти в терміналі, і `Ctrl + C/V`, щоб робити це скрізь в інших місцях. Ці уніфіковані гарячі клавіші буфера обміну Omarchy працюють скрізь.

## Захоплення

| Гаряча клавіша              | Функція                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Знімок екрана                      |
| `Super + Ctrl + Alt + C`            | Знімок екрана (той самий знімок, для клавіатур без клавіші Print Screen) |
| `Super + Ctrl + C` | Меню захоплення |
| `Alt + Print Screen`            | Запис екрана                     |
| `Super + Print Screen` | Вибір кольору |
| `Super + Ctrl + Print Screen` | Витягування тексту в буфер обміну |
| `Super + Alt + [` | Зменшити накладку вебкамери під час запису |
| `Super + Alt + ]` | Збільшити накладку вебкамери під час запису |

Із записами екрана гаряча клавіша спочатку запитує, який звук ви хочете, а потім починає запис. Натисніть її ще раз, щоб зупинити. Подробиці див. у [знімки екрана та запис](12-screenshots-recording.md).

Усі параметри захоплення також доступні в розділі _Trigger > Capture_ у меню Omarchy (`Super + Space`).

## Tmux

Клавіша префікса — `Ctrl + Space` (`Ctrl + B` також працює). Ви можете змінити ці поєднання в `~/.config/tmux/tmux.conf`.

### Панелі

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + v` | Розділити панель поруч (вертикально) |
| `Prefix + h` | Розділити панель нижче (горизонтально) |
| `Prefix + x` | Закрити панель |
| `Prefix + z` | Перемкнути масштаб панелі (на весь екран) |
| `Alt + Enter` | Розділити панель нижче (без префікса) |
| `Alt + Shift + Enter` | Розділити панель поруч (без префікса) |
| `Alt + Escape` | Закрити панель (без префікса) |
| `Ctrl + Alt + Arrows` | Переміщатися між панелями |
| `Ctrl + Alt + Shift + Arrows` | Змінювати розмір панелей |

### Вікна

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + c` | Нове вікно |
| `Prefix + k` | Закрити вікно |
| `Prefix + r` | Перейменувати вікно |
| `Alt + 1-9` | Перейти до певного вікна |
| `Alt + Arrow Left/Right` | Переміщатися між вікнами |
| `Alt + Shift + Arrow Left/Right` | Перемістити вікно вліво/вправо |

### Сеанси

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + C` | Новий сеанс |
| `Prefix + K` | Завершити сеанс |
| `Prefix + R` | Перейменувати сеанс |
| `Prefix + N` | Наступний сеанс |
| `Prefix + P` | Попередній сеанс |
| `Alt + Arrow Up/Down` | Переміщатися між сеансами |
| `Prefix + s` | Список сеансів |
| `Prefix + d` | Від’єднатися від сеансу |

### Режим копіювання (у стилі vi)

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + [` | Увійти в режим копіювання |
| `v` | Почати виділення (у режимі копіювання) |
| `y` | Скопіювати виділення (у режимі копіювання) |

### Загальне

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + q` | Перезавантажити конфігурацію |
| `Prefix + ?` | Показати поєднання клавіш Tmux |
| `Prefix + :` | Командний рядок |

### Функції розкладки Tmux

Ці функції потрібно запускати всередині сеансу Tmux.

| Команда | Функція |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Створити розкладку для розробки з редактором, AI і терміналом |
| `tdlm <ai> [<second_ai>]` | Створити розкладку для розробки для кожного підкаталогу |
| `tsl <count> <command>` | Створити багатопанельну розкладку swarm |

## Швидкі емодзі

Ви можете використовувати `Super + Ctrl + E`, щоб показати повний засіб вибору емодзі, який помістить вибране в буфер обміну, або можете скористатися цими варіантами швидкого доступу.

| Гаряча клавіша       | EM | Підказка       |
| ------------ | -- | ---------- |
| `Shift + CapsLock M S` | 😄 | усмішка      |
| `Shift + CapsLock M C` | 😂 | плач        |
| `Shift + CapsLock M L` | 😍 | кохання       |
| `Shift + CapsLock M V` | ✌️ | перемога    |
| `Shift + CapsLock M H` | ❤️ | серце      |
| `Shift + CapsLock M Y` | 👍 | так        |
| `Shift + CapsLock M N` | 👎 | ні         |
| `Shift + CapsLock M F` | 🖕 | fuck       |
| `Shift + CapsLock M W` | 🤞 | бажання       |
| `Shift + CapsLock M R` | 🤘 | рок       |
| `Shift + CapsLock M K` | 😘 | поцілунок       |
| `Shift + CapsLock M E` | 🙄 | закочування очей    |
| `Shift + CapsLock M I` | 😉 | підморгування       |

## Швидкі доповнення

| Гаряча клавіша       | Доповнення       |
| ------------ |  ---------- |
| `Shift + CapsLock Space Space` | — (довге тире)   |
| `Shift + CapsLock Space N` | Ваше ім’я (як вказано під час налаштування)  |
| `Shift + CapsLock Space E` | Ваша електронна пошта (як вказано під час налаштування)  |

Ви можете додати більше власних, відредагувавши `~/.XCompose`, а потім запустивши `omarchy-restart-xcompose` у терміналі, щоб зміни було застосовано.
