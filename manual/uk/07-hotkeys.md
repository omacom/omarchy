# Гарячі клавіші

Усі основні прив'язки клавіш можна переглянути за допомогою `Super + K` (прив'язки Tmux — за допомогою `Super + Alt + K`, а прив'язки Herdr — за допомогою `Super + Ctrl + K`).

## Як влаштовані гарячі клавіші

Кожна гаряча клавіша перебуває на площині, яку визначають її модифікатори, і кожна площина має одне завдання. Саме це не дає гарячим клавішам змішуватися, і завдяки цьому ви зазвичай можете вгадати, де що живе.

| Площина | Що там живе | Приклади |
| --- | --- | --- |
| `Super + key` | Система: вікна, робочі простори, розкладки та основні меню | `Super + Space` меню Omarchy, `Super + W` закрити вікно, `Super + F` на весь екран |
| `Super + Shift + key` | Застосунки | `Super + Shift + B` браузер, `Super + Shift + E` електронна пошта, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панелі та системні меню | `Super + Ctrl + A` аудіо, `Super + Ctrl + N` мережа, `Super + Ctrl + C` меню захоплення |
| `Super + Ctrl + Alt + key` | Швидкі дії та повідомлення | `Super + Ctrl + Alt + T` показати час, `Super + Ctrl + Alt + B` батарея, `Super + Ctrl + Alt + C` знімок екрана |

Додавання `Alt` до гарячої клавіші дає вам варіант того самого, а ніколи щось непов'язане:

- `Super + Shift + B` відкриває браузер; `Super + Shift + Alt + B` відкриває приватне вікно
- `Super + Shift + E` відкриває електронну пошту; `Super + Shift + Alt + E` починає нову
- `Super + F` переходить на весь екран; `Super + Alt + F` переходить на всю ширину
- `Super + Ctrl + C` відкриває меню захоплення; `Super + Ctrl + Alt + C` пропускає меню і робить знімок екрана

Коли додаєте гарячу клавішу:

1. Оберіть площину за тим, що вона робить, а потім оберіть клавішу.
2. Не пересувайте наявну гарячу клавішу, щоб звільнити місце. Знайдіть вільну клавішу на правильній площині.
3. Використовуйте `Alt` лише для варіанта гарячої клавіші без неї.

Декілька гарячих клавіш порушують ці правила, бо так зручно. `Shift` зі стрілкою або `Tab` переміщує або повертає назад, а не відкриває застосунок, а `Print`, медіаклавіші, `Alt + Tab` і `Ctrl + Alt + Del` працюють так, як і всюди. Це винятки, а не зразки для наслідування.

Якщо стандартна прив'язка вам не підходить (наприклад, ви хочете `Super + Shift + S` для знімків екрана, як у Windows), перепризначте її в `~/.config/hypr/bindings.lua`.

На сенсорній панелі змахи трьома та чотирма пальцями перемикають робочі простори, переміщують вікна та відкривають меню і консоль Quake; див. [клавіатура, миша та трекпад](34-keyboard-mouse-trackpad.md) щодо жестів.

Змінення розміру використовує дві клавіші праворуч від 0, хоч би що було надруковано на вашій клавіатурі: `-` і `=` на клавіатурах США, `+` і `´` на данських і шведських, `+` і `\` на норвезьких, `ß` і `´` на німецьких, `'` і `¡` на іспанських і `-` і `^` на японських (JIS). `Super + K` показує їх так, як надруковано на вашій клавіатурі. На JIS `Super + ^` — це `Super + Equal`, а `Super + Shift + -` (що вводить `=`) — це `Super + Shift + Minus`. Масштабування монітора та менеджер паролів використовують `/`; на розкладках, які вводять `/` лише з Shift, як більшість європейських, вони натомість використовують клавішу ліворуч від правого Shift (`-` на данській і німецькій).

## Tmux

Клавіша-префікс — `Ctrl + Space` (також працює `Ctrl + B`). Ці прив'язки можна змінити в `~/.config/tmux/tmux.conf`.

### Панелі

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + v` | Розділити панель поруч (вертикально) |
| `Prefix + h` | Розділити панель знизу (горизонтально) |
| `Prefix + x` | Знищити панель |
| `Prefix + z` | Перемкнути масштаб панелі (на весь екран) |
| `Alt + Enter` | Розділити панель знизу (без префікса) |
| `Alt + Shift + Enter` | Розділити панель поруч (без префікса) |
| `Alt + Escape` | Знищити панель (без префікса) |
| `Ctrl + Alt + Arrows` | Переміщатися між панелями |
| `Ctrl + Alt + Shift + Arrows` | Змінювати розмір панелей |

### Вікна

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |

| `Prefix + k` | Знищити вікно |
| `Prefix + r` | Перейменувати вікно |
| `Alt + 1-9` | Перейти до конкретного вікна |
| `Alt + Arrow Left/Right` | Переміщатися між вікнами |
| `Alt + Shift + Arrow Left/Right` | Перемістити вікно вліво/вправо |

### Сесії

### Загальне

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + q` | Перезавантажити конфігурацію |
| `Prefix + ?` | Показати прив'язки клавіш Tmux |
| `Prefix + :` | Командний рядок |

### Функції розкладки Tmux

Ці функції треба запускати всередині сесії Tmux.

| Команда | Функція |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Створити розкладку для розробки з редактором, AI і терміналом |
| `tdlm <ai> [<second_ai>]` | Створити розкладку для розробки для кожного підкаталогу |
| `tsl <count> <command>` | Створити багатопанельну розкладку рою |
