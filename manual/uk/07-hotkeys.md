# Гарячі клавіші

Усі основні прив'язки клавіш можна переглянути за допомогою `Super + K` (прив'язки Tmux — за допомогою `Super + Alt + K`, а прив'язки Herdr — за допомогою `Super + Ctrl + K`).

## Як влаштовано гарячі клавіші

Кожна гаряча клавіша сидить на площині, яку задають її модифікатори, і кожна площина має одне завдання. Саме це не дає гарячим клавішам зливатися в одне, і саме тому ви зазвичай можете вгадати, де щось живе.

| Plane | What lives there | Examples |
| --- | --- | --- |
| `Super + key` | Система: вікна, робочі простори, макети та основні меню | `Super + Space` меню Omarchy, `Super + W` закрити вікно, `Super + F` повний екран |
| `Super + Shift + key` | Застосунки | `Super + Shift + B` браузер, `Super + Shift + E` пошта, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панелі та системні меню | `Super + Ctrl + A` аудіо, `Super + Ctrl + N` мережа, `Super + Ctrl + C` меню захоплення |
| `Super + Ctrl + Alt + key` | Швидкі дії та оповіщення | `Super + Ctrl + Alt + T` показати час, `Super + Ctrl + Alt + B` батарея, `Super + Ctrl + Alt + C` знімок екрана |

Додавання `Alt` до гарячої клавіші дає вам варіант того самого, ніколи щось непов'язане:

- `Super + Shift + B` відкриває браузер; `Super + Shift + Alt + B` відкриває приватне вікно
- `Super + Shift + E` відкриває пошту; `Super + Shift + Alt + E` починає новий лист
- `Super + F` переходить у повний екран; `Super + Alt + F` переходить у повну ширину
- `Super + Ctrl + C` відкриває меню захоплення; `Super + Ctrl + Alt + C` пропускає меню і робить знімок екрана

Коли додаєте гарячу клавішу:

1. Виберіть площину за тим, що вона робить, потім виберіть клавішу.
2. Не рухайте наявну гарячу клавішу, щоб звільнити місце. Знайдіть вільну клавішу на правильній площині.
3. Використовуйте `Alt` лише для варіанта гарячої клавіші без неї.

Кілька гарячих клавіш порушують ці правила, бо так зручно. `Shift` зі стрілкою або `Tab` рухає або реверсує замість відкривати застосунок, а `Print`, медіаклавіші, `Alt + Tab` і `Ctrl + Alt + Del` працюють так, як вони працюють скрізь. Це винятки, а не зразки для копіювання.

Якщо типовий варіант вам не підходить (скажімо, ви хочете `Super + Shift + S` для знімків екрана, як у Windows), перепризначте його у `~/.config/hypr/bindings.lua`.

Комбінації для змінення розміру використовують фізичні клавіші `code:20` і `code:21` (XKB `<AE11>` і `<AE12>`), незалежно від символів, надрукованих на клавіатурі. На клавіатурах США це клавіші `-` і `=`; на японських (JIS) клавіатурах це `-` і `^`; на іспанських клавіатурах це `'` і `¡`. На JIS `Super + ^` — це `Super + Equal`, тоді як `Super + Shift + -` (яка вводить `=`) — це `Super + Shift + Minus`.
