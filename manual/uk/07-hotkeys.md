# Гарячі клавіші

Усі основні прив'язки клавіш можна побачити за допомогою `Super + K` (прив'язки Tmux — за допомогою `Super + Alt + K`, а прив'язки Herdr — за допомогою `Super + Ctrl + K`).

## Навігація

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Super + Space`           | Меню Omarchy (застосунки та все інше)    |
| `Super + Alt + Space` | Сітка застосунків |
| `Super + Escape` | Системне меню (призупинення, перезапуск тощо)  |
| `Super + Ctrl + L` | Заблокувати комп'ютер |
| `Super + W` or `Super + Q` | Закрити вікно             |
| `Ctrl + Alt + Del` | Закрити всі вікна |
| `Super + T`               | Перемкнути вікно між плитковим/плаваючим режимами             |
| `Super + J` | Перемкнути положення вікна (горизонтальне/вертикальне) |
| `Super + O`               | Перемкнути винесення вікна в липке й плаваюче |
| `Super + L`               | Циклічно перемикати компонування dwindle, scrolling і floating |
| `Super + Alt + L`         | Циклічно перемикати компонування у зворотному порядку |
| `Super + P`               | Перемкнути стиль псевдовікна (природний проти розтягнутого) |
| `Super + F`                 | Перейти на весь екран              |
| `Super + Alt + F`                 | Перейти на всю ширину              |
| `Super + Ctrl + F`                 | Перейти на весь екран усередині вікна              |
| `Super + 1/2/3/4`         | Перейти до конкретного робочого простору на активному моніторі |
| `Super + Tab` | Перейти до наступного робочого простору на активному моніторі |
| `Super + Shift + Tab` | Перейти до попереднього робочого простору на активному моніторі |
| `Super + Ctrl + Tab` | Перейти до колишнього робочого простору на активному моніторі |
| `Super + Shift + 1/2/3/4` | Перемістити вікно до робочого простору на активному моніторі |
| `Super + Shift + Alt + 1/2/3/4` | Перемістити вікно до робочого простору на активному моніторі без переходу за ним |
| `Super + S` | Перемкнути повний scratchpad |
| `Super + Alt + S` | Перемістити вікно до повного scratchpad |
| `Super + Grave` | Перемкнути консоль Quake |
| `Super + Shift + Grave` | Перемістити вікно до консолі Quake |
| `Super + Shift + Ctrl + Arrows` | Перемістити вікно на монітор у тому напрямку |
| `Super + Shift + Alt + Arrows` | Перемістити робочий простір на монітор у тому напрямку |
| `Super + Arrow`  | Перемістити фокус до вікна в напрямку стрілки, переходячи до монітора з того боку біля краю екрана |
| `Super + Shift + Arrow`  | Поміняти вікно місцями з іншим у напрямку стрілки, включно з вікном на моніторі з того боку |
| `Super + Minus` | Розширити вікно вліво |
| `Super + Equal` | Звузити вікно вліво |
| `Super + Shift + Minus` | Звузити вікно вгору |
| `Super + Shift + Equal` | Розширити вікно вниз |
| `Super + Alt + Minus/Equal` | Те саме змінення розміру меншими кроками |
| `Super + Ctrl + Minus/Equal` | Те саме змінення розміру більшими кроками |
| `Super + Alt + Home` | Зберегти ширину вікна |
| `Super + Home` | Відновити збережену ширину вікна |
| `Super + Left Mouse` | Перетягувати вікно |
| `Super + Right Mouse` | Змінювати розмір вікна |
| `Super + Scroll Wheel` | Прокручувати робочі простори на активному моніторі |
| `Super + G`               | Перемкнути групування вікон      |
| `Super + Alt + G`               | Вивести вікно з групування      |
| `Super + Alt + Tab`               | Циклічно перемикати вікна в групуванні      |
| `Super + Alt + Shift + Tab`               | Циклічно перемикати вікна в групуванні у зворотному порядку      |
| `Super + Alt + Scroll Wheel` | Циклічно перемикати вікна в групуванні |
| `Super + Alt + 1/2/3/4/5`               | Перейти до конкретного вікна в групуванні      |
| `Super + Alt + Arrow`  | Перемістити вікно до групування в напрямку стрілки, включно з вікном на моніторі з того боку |
| `Super + Ctrl + Left/Right`  | Переміщуватися між вікнами всередині плиткової групи |
| `Super + Ctrl + Z` | Збільшити масштаб екрана (повторити для більшого збільшення) |
| `Super + Ctrl + Alt + Z` | Повністю зменшити масштаб екрана |
| `Super + /` | Крокувати вперед по варіантах масштабування монітора |
| `Super + Alt + /` | Крокувати назад по варіантах масштабування монітора |
| `Alt + Tab` | Циклічно перемикати вперед вікна на активному робочому просторі |
| `Alt + Shift + Tab` | Циклічно перемикати назад вікна на активному робочому просторі |
| `Ctrl + Alt + Tab`| Циклічно переміщувати фокус вперед по моніторах |
| `Ctrl + Alt + Shift + Tab`| Циклічно переміщувати фокус назад по моніторах |

## Універсальний буфер обміну

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Super + C`           | Копіювати    |
| `Super + X`           | Вирізати (не в терміналі)    |
| `Super + V`           | Вставити    |
| `Super + Ctrl + V`           | Менеджер буфера обміну    |

Зазвичай у Linux для копіювання й вставлення в терміналі потрібне `Ctrl + Shift + C/V`, а скрізь деінде — `Ctrl + C/V`. Ці уніфіковані гарячі клавіші буфера обміну Omarchy працюють скрізь.

## Захоплення

| Гаряча клавіша              | Функція                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Знімок екрана                      |
| `Super + Ctrl + Alt + C`            | Знімок екрана (той самий знімок, для клавіатур без клавіші Print Screen) |
| `Super + Ctrl + C` | Меню захоплення |
| `Alt + Print Screen`            | Запис екрана                     |
| `Super + Print Screen` | Вибір кольору |
| `Super + Ctrl + Print Screen` | Видобування тексту до буфера обміну |
| `Super + Alt + [` | Зменшити накладку вебкамери під час запису |
| `Super + Alt + ]` | Збільшити накладку вебкамери під час запису |

У разі записів екрана гаряча клавіша спершу запитує, яке аудіо ви хочете, а потім починає запис. Натисніть її ще раз, щоб зупинити. Деталі див. у [знімки екрана та запис](12-screenshots-recording.md).

Усі варіанти захоплення також доступні в меню Omarchy (`Super + Space`) у розділі _Trigger > Capture_.

## Tmux

Префіксна клавіша — `Ctrl + Space` (також працює `Ctrl + B`). Ці прив'язки можна змінити в `~/.config/tmux/tmux.conf`.

### Панелі

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + v` | Розділити панель поруч (вертикально) |
| `Prefix + h` | Розділити панель нижче (горизонтально) |
| `Prefix + x` | Закрити панель |
| `Prefix + z` | Перемкнути масштаб панелі (на весь екран) |
| `Alt + Enter` | Розділити панель нижче (без префікса) |
| `Alt + Shift + Enter` | Розділити панель поруч (без префікса) |
| `Alt + Escape` | Закрити панель (без префікса) |
| `Ctrl + Alt + Arrows` | Переміщуватися між панелями |
| `Ctrl + Alt + Shift + Arrows` | Змінювати розмір панелей |

### Вікна

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + c` | Нове вікно |
| `Prefix + k` | Закрити вікно |
| `Prefix + r` | Перейменувати вікно |
| `Alt + 1-9` | Перейти до конкретного вікна |
| `Alt + Arrow Left/Right` | Переміщуватися між вікнами |
| `Alt + Shift + Arrow Left/Right` | Перемістити вікно вліво/вправо |

### Сесії

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + C` | Нова сесія |
| `Prefix + K` | Закрити сесію |
| `Prefix + R` | Перейменувати сесію |
| `Prefix + N` | Наступна сесія |
| `Prefix + P` | Попередня сесія |
| `Alt + Arrow Up/Down` | Переміщуватися між сесіями |
| `Prefix + s` | Список сесій |
| `Prefix + d` | Від'єднатися від сесії |

### Режим копіювання (у стилі vi)

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + [` | Увійти в режим копіювання |
| `v` | Почати виділення (у режимі копіювання) |
| `y` | Скопіювати виділення (у режимі копіювання) |

### Загальне

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + q` | Перезавантажити конфігурацію |
| `Prefix + ?` | Показати прив'язки клавіш Tmux |
| `Prefix + :` | Командний рядок |

### Функції компонування Tmux

Ці функції треба запускати всередині сесії Tmux.

| Команда | Функція |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Створити компонування для розробки з редактором, AI і терміналом |
| `tdlm <ai> [<second_ai>]` | Створити компонування для розробки для кожного підкаталогу |
| `tsl <count> <command>` | Створити компонування swarm із багатьма панелями |

## Швидкі доповнення

| Гаряча клавіша       | Доповнення       |
| ------------ |  ---------- |
| `Shift + CapsLock Space Space` | — (mdash)   |
| `Shift + CapsLock Space N` | Ваше ім'я (як введено під час налаштування)  |
| `Shift + CapsLock Space E` | Ваша електронна пошта (як введено під час налаштування)  |

Ви можете додати більше власних, відредагувавши `~/.XCompose`, а потім запустивши `omarchy-restart-xcompose` у терміналі, щоб зміни було підхоплено.
