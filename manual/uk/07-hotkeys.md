# Гарячі клавіші

Ви можете побачити всі основні прив’язки клавіш за допомогою `Super + K` (прив’язки Tmux — за допомогою `Super + Alt + K`, а прив’язки Herdr — за допомогою `Super + Ctrl + K`).

## Як влаштовано гарячі клавіші

Кожна гаряча клавіша сидить на площині, заданій її модифікаторами, і кожна площина має одну роботу. Саме це не дає гарячим клавішам змішуватися, і це означає, що зазвичай ви можете вгадати, де що живе.

| Площина | Що там живе | Приклади |
| --- | --- | --- |
| `Super + key` | Система: вікна, робочі простори, компонування та основні меню | `Super + Space` меню Omarchy, `Super + W` закрити вікно, `Super + F` на весь екран |
| `Super + Shift + key` | Програми | `Super + Shift + B` браузер, `Super + Shift + E` електронна пошта, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панелі та системні меню | `Super + Ctrl + A` звук, `Super + Ctrl + N` мережа, `Super + Ctrl + C` меню захоплення |
| `Super + Ctrl + Alt + key` | Швидкі дії та повідомлення | `Super + Ctrl + Alt + T` показати час, `Super + Ctrl + Alt + B` батарея, `Super + Ctrl + Alt + C` знімок екрана |

Додавання `Alt` до гарячої клавіші дає вам варіант того самого, ніколи щось непов’язане:

- `Super + Shift + B` відкриває браузер; `Super + Shift + Alt + B` відкриває приватне вікно
- `Super + Shift + E` відкриває електронну пошту; `Super + Shift + Alt + E` починає новий лист
- `Super + F` переходить на весь екран; `Super + Alt + F` переходить на всю ширину
- `Super + Ctrl + C` відкриває меню захоплення; `Super + Ctrl + Alt + C` пропускає меню і робить знімок екрана

Коли додаєте гарячу клавішу:

1. Виберіть площину з того, що вона робить, потім виберіть клавішу.
2. Не рухайте наявну гарячу клавішу, щоб звільнити місце. Знайдіть вільну клавішу на правильній площині.
3. Використовуйте `Alt` лише для варіанта гарячої клавіші без нього.

Кілька гарячих клавіш порушують ці правила, бо так зручно. `Shift` зі стрілкою або `Tab` рухає або реверсує замість відкривати програму, а `Print`, медіаклавіші, `Alt + Tab` і `Ctrl + Alt + Del` працюють так, як вони працюють скрізь. Це винятки, а не шаблони для копіювання.

Якщо типове налаштування вам не підходить (скажімо, ви хочете `Super + Shift + S` для знімків екрана, як у Windows), перепризначте його в `~/.config/hypr/bindings.lua`.

| `Super + Alt + G` | Вивести вікно з групування |

| `Super + Alt + Scroll Wheel` | Циклічно перемикати вікна в групуванні |
| `Super + Alt + 1/2/3/4/5` | Перейти до певного вікна в групуванні |
| `Super + Alt + Arrow` | Перемістити вікно в групування в напрямку стрілки, включно з вікном на моніторі з того боку |
| `Super + Ctrl + Left/Right` | Переміщатися між вікнами всередині плиткової групи |
| `Super + Ctrl + Z` | Наблизити екран (повторити для більшого наближення) |
| `Super + Ctrl + Alt + Z` | Повністю віддалити екран |
| `Super + /` | Крок уперед варіантами масштабування монітора |
| `Super + Alt + /` | Крок назад варіантами масштабування монітора |
| `Alt + Tab` | Циклічно переходити вперед вікнами на активному робочому просторі |
| `Alt + Shift + Tab` | Циклічно переходити назад вікнами на активному робочому просторі |
| `Ctrl + Alt + Tab` | Циклічно переміщати фокус уперед моніторами |
| `Ctrl + Alt + Shift + Tab` | Циклічно переміщати фокус назад моніторами |

Поєднання для змінення розміру використовують фізичні клавіші `code:20` і `code:21` (XKB `<AE11>` і `<AE12>`), незалежно від символів, надрукованих на клавіатурі. На клавіатурах US це клавіші `-` і `=`; на японських (JIS) клавіатурах це `-` і `^`; на іспанських клавіатурах це `'` і `¡`. На JIS `Super + ^` є `Super + Equal`, тоді як `Super + Shift + -` (яке вводить `=`) є `Super + Shift + Minus`.

## Універсальний буфер обміну

| Гаряча клавіша | Функція |
| ----------------------- | --------------------- |
| `Super + A` | Вибрати все в програмах, які підтримують `Ctrl + A` |
| `Super + C` | Копіювати |
| `Super + X` | Вирізати (не в терміналі) |
| `Super + V` | Вставити |
| `Super + Ctrl + V` | Менеджер буфера обміну |

Зазвичай у Linux вам треба `Ctrl + Shift + C/V`, щоб копіювати й вставляти в терміналі, і `Ctrl + C/V`, щоб робити це скрізь деінде. Ці уніфіковані гарячі клавіші буфера обміну Omarchy працюють скрізь.
