# Гарячі клавіші

Усі основні сполучення клавіш можна переглянути за допомогою `Super + K` (сполучення Tmux — за допомогою `Super + Alt + K`, а сполучення Herdr — за допомогою `Super + Ctrl + K`).

## Як влаштовані гарячі клавіші

Кожна гаряча клавіша розташована на площині, яку задають її модифікатори, і кожна площина має одне завдання. Саме це не дає гарячим клавішам змішуватися, і завдяки цьому ви зазвичай можете вгадати, де що живе.

| Площина | Що там живе | Приклади |
| --- | --- | --- |
| `Super + key` | Система: вікна, робочі простори, розкладки та основні меню | `Super + Space` меню Omarchy, `Super + W` закрити вікно, `Super + F` на весь екран |
| `Super + Shift + key` | Додатки | `Super + Shift + B` браузер, `Super + Shift + E` електронна пошта, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панелі та системні меню | `Super + Ctrl + A` аудіо, `Super + Ctrl + N` мережа, `Super + Ctrl + C` меню захоплення |
| `Super + Ctrl + Alt + key` | Швидкі дії та сповіщення | `Super + Ctrl + Alt + T` показати час, `Super + Ctrl + Alt + B` батарея, `Super + Ctrl + Alt + C` знімок екрана |

Додавання `Alt` до гарячої клавіші дає вам варіант тієї самої дії, а ніколи щось непов’язане:

- `Super + Shift + B` відкриває браузер; `Super + Shift + Alt + B` відкриває приватне вікно
- `Super + Shift + E` відкриває електронну пошту; `Super + Shift + Alt + E` починає новий лист
- `Super + F` переходить на весь екран; `Super + Alt + F` переходить на всю ширину
- `Super + Ctrl + C` відкриває меню захоплення; `Super + Ctrl + Alt + C` пропускає меню й робить знімок екрана

Коли додаєте гарячу клавішу:

1. Оберіть площину за тим, що вона робить, а потім оберіть клавішу.
2. Не пересувайте наявну гарячу клавішу, щоб звільнити місце. Знайдіть вільну клавішу на правильній площині.
3. Використовуйте `Alt` лише для варіанта гарячої клавіші без неї.

Кілька гарячих клавіш порушують ці правила, бо так зручно. `Shift` зі стрілкою або `Tab` пересуває чи повертає у зворотному напрямку замість того, щоб відкривати додаток, а `Print`, медіаклавіші, `Alt + Tab` і `Ctrl + Alt + Del` працюють так само, як і скрізь. Це винятки, а не шаблони для наслідування.

Якщо стандартне призначення вам не підходить (скажімо, ви хочете `Super + Shift + S` для знімків екрана, як у Windows), перепризначте його у `~/.config/hypr/bindings.lua`.

На тачпаді свайпи трьома та чотирма пальцями перемикають робочі простори, пересувають вікна та відкривають меню й консоль Quake; жести дивіться у [клавіатура, миша та трекпад](34-keyboard-mouse-trackpad.md).

Сполучення для змінення розміру використовують фізичні клавіші `code:20` та `code:21` (XKB `<AE11>` та `<AE12>`), незалежно від символів, надрукованих на клавіатурі. На клавіатурах США це клавіші `-` та `=`; на японських (JIS) клавіатурах це `-` та `^`; на іспанських клавіатурах це `'` та `¡`. На JIS `Super + ^` — це `Super + Equal`, а `Super + Shift + -` (яке вводить `=`) — це `Super + Shift + Minus`.

| Гаряча клавіша | Функція |
| ----------------------- | --------------------- |
| `Super + A` | Вибрати все у додатках, які підтримують `Ctrl + A` |
| `Super + C` | Копіювати |
| `Super + X` | Вирізати (не в терміналі) |
| `Super + V` | Вставити |
| `Super + Ctrl + V` | Менеджер буфера обміну |

Зазвичай у Linux потрібно `Ctrl + Shift + C/V`, щоб копіювати й вставляти в терміналі, і `Ctrl + C/V`, щоб робити це скрізь. Ці уніфіковані гарячі клавіші буфера обміну Omarchy працюють скрізь.

Клавіша-префікс — це `Ctrl + Space` (також працює `Ctrl + B`). Ці прив’язки можна змінити у `~/.config/tmux/tmux.conf`.
