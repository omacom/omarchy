# Гарячі клавіші

Усі основні прив’язки клавіатури можна побачити за допомогою `Super + K` (прив’язки Tmux — за допомогою `Super + Alt + K`, а прив’язки Herdr — за допомогою `Super + Ctrl + K`).

## Як влаштовані гарячі клавіші

Кожна гаряча клавіша розташована на площині, яку визначають її модифікатори, і кожна площина має одне завдання. Саме це не дає гарячим клавішам змішуватися, і зазвичай ви можете здогадатися, де що живе.

| Площина | Що там живе | Приклади |
| --- | --- | --- |
| `Super + key` | Система: вікна, робочі простори, макети та основні меню | `Super + Space` меню Omarchy, `Super + W` закрити вікно, `Super + F` повний екран |
| `Super + Shift + key` | Застосунки | `Super + Shift + B` браузер, `Super + Shift + E` електронна пошта, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панелі та системні меню | `Super + Ctrl + A` аудіо, `Super + Ctrl + N` мережа, `Super + Ctrl + C` меню захоплення |
| `Super + Ctrl + Alt + key` | Швидкі дії та сповіщення | `Super + Ctrl + Alt + T` показати час, `Super + Ctrl + Alt + B` батарея, `Super + Ctrl + Alt + C` знімок екрана |

Додавання `Alt` до гарячої клавіші дає варіант тієї самої дії, ніколи щось непов’язане:

- `Super + Shift + B` відкриває браузер; `Super + Shift + Alt + B` відкриває приватне вікно
- `Super + Shift + E` відкриває електронну пошту; `Super + Shift + Alt + E` починає новий лист
- `Super + F` переходить у повноекранний режим; `Super + Alt + F` переходить на всю ширину
- `Super + Ctrl + C` відкриває меню захоплення; `Super + Ctrl + Alt + C` пропускає меню й робить знімок екрана

Під час додавання гарячої клавіші:

1. Спочатку оберіть площину за тим, що вона робить, потім оберіть клавішу.
2. Не переміщуйте наявну гарячу клавішу, щоб звільнити місце. Знайдіть вільну клавішу на правильній площині.
3. Використовуйте `Alt` лише для варіанта гарячої клавіші без неї.

Кілька гарячих клавіш порушують ці правила, бо так зручно. `Shift` зі стрілкою або `Tab` переміщує або змінює напрямок замість відкриття застосунку, а `Print`, мультимедійні клавіші, `Alt + Tab` і `Ctrl + Alt + Del` працюють так, як і скрізь. Це винятки, а не шаблони для копіювання.

Якщо стандартна прив’язка вам не підходить (скажімо, ви хочете `Super + Shift + S` для знімків екрана, як у Windows), перепризначте її в `~/.config/hypr/bindings.lua`.

На сенсорній панелі змахи трьома й чотирма пальцями перемикають робочі простори, переміщують вікна та відкривають меню й консоль Quake; жести див. у [клавіатура, миша та трекпад](34-keyboard-mouse-trackpad.md).

Комбінації для змінення розміру використовують фізичні клавіші `code:20` і `code:21` (XKB `<AE11>` і `<AE12>`), незалежно від символів, надрукованих на клавіатурі. На клавіатурах США це клавіші `-` і `=`; на японських (JIS) клавіатурах це `-` і `^`; на іспанських клавіатурах це `'` і `¡`. На JIS `Super + ^` — це `Super + Equal`, тоді як `Super + Shift + -` (що вводить `=`) — це `Super + Shift + Minus`.

## Універсальний буфер обміну

| Гаряча клавіша | Функція |
| ----------------------- | --------------------- |
| `Super + A` | Вибрати все в застосунках, що підтримують `Ctrl + A` |
| `Super + C` | Копіювати |
| `Super + X` | Вирізати (не в терміналі) |
| `Super + V` | Вставити |
| `Super + Ctrl + V` | Менеджер буфера обміну |

Зазвичай у Linux вам потрібні `Ctrl + Shift + C/V` для копіювання й вставляння в терміналі та `Ctrl + C/V`, щоб робити це скрізь. Ці уніфіковані гарячі клавіші буфера обміну Omarchy працюють скрізь.
