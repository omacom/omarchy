# Гарячі клавіші

Усі основні прив’язки клавіатури можна переглянути за допомогою `Super + K` (прив’язки Tmux — за допомогою `Super + Alt + K`, а прив’язки Herdr — за допомогою `Super + Ctrl + K`).

## Як влаштовані гарячі клавіші

Кожна гаряча клавіша розташована на площині, яку задають її модифікатори, і кожна площина має одне завдання. Саме це не дає гарячим клавішам змішуватися, і зазвичай ви можете здогадатися, де що розташоване.

| Площина | Що там розташоване | Приклади |
| --- | --- | --- |
| `Super + key` | Система: вікна, робочі простори, розкладки та основні меню | `Super + Space` меню Omarchy, `Super + W` закрити вікно, `Super + F` на весь екран |
| `Super + Shift + key` | Програми | `Super + Shift + B` браузер, `Super + Shift + E` електронна пошта, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панелі та системні меню | `Super + Ctrl + A` аудіо, `Super + Ctrl + N` мережа, `Super + Ctrl + C` меню захоплення |
| `Super + Ctrl + Alt + key` | Швидкі дії та повідомлення | `Super + Ctrl + Alt + T` показати час, `Super + Ctrl + Alt + B` батарея, `Super + Ctrl + Alt + C` знімок екрана |

Додавання `Alt` до гарячої клавіші дає варіант того самого, ніколи щось непов’язане:

- `Super + Shift + B` відкриває браузер; `Super + Shift + Alt + B` відкриває приватне вікно
- `Super + Shift + E` відкриває електронну пошту; `Super + Shift + Alt + E` починає новий лист
- `Super + F` переходить на весь екран; `Super + Alt + F` переходить на всю ширину
- `Super + Ctrl + C` відкриває меню захоплення; `Super + Ctrl + Alt + C` пропускає меню й робить знімок екрана

Коли додаєте гарячу клавішу:

1. Оберіть площину за тим, що вона робить, а потім оберіть клавішу.
2. Не переміщуйте наявну гарячу клавішу, щоб звільнити місце. Знайдіть вільну клавішу на потрібній площині.
3. Використовуйте `Alt` лише для варіанта гарячої клавіші без неї.

Кілька гарячих клавіш порушують ці правила, бо так зручно. `Shift` зі стрілкою або `Tab` переміщує або повертає назад замість того, щоб відкривати програму, а `Print`, мультимедійні клавіші, `Alt + Tab` і `Ctrl + Alt + Del` працюють так, як і скрізь. Це винятки, а не зразки для наслідування.

Якщо стандартний варіант вам не підходить (скажімо, ви хочете `Super + Shift + S` для знімків екрана, як у Windows), перепризначте його в `~/.config/hypr/bindings.lua`.

На тачпаді свайпи трьома та чотирма пальцями перемикають робочі простори, переміщують вікна й відкривають меню та консоль Quake; див. [клавіатура, миша та трекпад](34-keyboard-mouse-trackpad.md) щодо жестів.

Гарячі клавіші змінення розміру використовують фізичні клавіші `code:20` та `code:21` (XKB `<AE11>` та `<AE12>`), незалежно від символів, надрукованих на клавіатурі. На клавіатурах US це клавіші `-` та `=`; на японських (JIS) клавіатурах це `-` та `^`; на іспанських клавіатурах це `'` та `¡`. На JIS `Super + ^` — це `Super + Equal`, тоді як `Super + Shift + -` (що вводить `=`) — це `Super + Shift + Minus`.

## Tmux

Префіксна клавіша — `Ctrl + Space` (`Ctrl + B` також працює). Ці прив’язки можна змінити в `~/.config/tmux/tmux.conf`.

### Панелі

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + v` | Розділити панель поруч (вертикально) |
| `Prefix + h` | Розділити панель нижче (горизонтально) |
| `Prefix + x` | Закрити панель |
| `Prefix + z` | Перемкнути масштаб панелі (на весь екран) |
