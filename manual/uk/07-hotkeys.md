# Гарячі клавіші

Ви можете переглянути всі основні прив'язки клавіш за допомогою `Super + K` (прив'язки Tmux — за допомогою `Super + Alt + K`, а прив'язки Herdr — за допомогою `Super + Ctrl + K`).

## Навігація

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Super + Space`           | Меню Omarchy (застосунки й усе інше)    |
| `Super + Alt + Space` | Сітка застосунків |
| `Super + Escape` | Системне меню (призупинення, перезапуск тощо)  |
| `Super + Ctrl + L` | Заблокувати комп'ютер |
| `Super + W` or `Super + Q` | Закрити вікно             |
| `Ctrl + Alt + Del` | Закрити всі вікна |
| `Super + T`               | Перемкнути вікно між режимами tiling/floating             |
| `Super + J` | Перемкнути положення вікна (горизонтальне/вертикальне) |
| `Super + O`               | Перемкнути винесення вікна в sticky'n'floating |
| `Super + L`               | Перебирати компонування dwindle, scrolling і floating |
| `Super + Alt + L`         | Перебирати компонування у зворотному порядку |
| `Super + P`               | Перемкнути стиль псевдовікна (natural v stretch) |
| `Super + F`                 | Перейти на весь екран              |
| `Super + Alt + F`                 | Перейти на всю ширину              |
| `Super + Ctrl + F`                 | Перейти на весь екран усередині вікна              |
| `Super + 1/2/3/4`         | Перейти до певного робочого простору на моніторі у фокусі |
| `Super + Tab` | Перейти до наступного робочого простору на моніторі у фокусі |
| `Super + Shift + Tab` | Перейти до попереднього робочого простору на моніторі у фокусі |
| `Super + Ctrl + Tab` | Перейти до колишнього робочого простору на моніторі у фокусі |
| `Super + Shift + 1/2/3/4` | Перемістити вікно до робочого простору на моніторі у фокусі |
| `Super + Shift + Alt + 1/2/3/4` | Перемістити вікно до робочого простору на моніторі у фокусі, не переходячи за ним |
| `Super + S` | Перемкнути повний scratchpad |
| `Super + Alt + S` | Перемістити вікно до повного scratchpad |
| `Super + Grave` | Перемкнути консоль Quake |
| `Super + Shift + Grave` | Перемістити вікно до консолі Quake |
| `Super + Shift + Ctrl + Arrows` | Перемістити вікно на монітор у цьому напрямку |
| `Super + Shift + Alt + Arrows` | Перемістити робочий простір на монітор у цьому напрямку |
| `Super + Arrow`  | Перемістити фокус до вікна в напрямку стрілки, переходячи на монітор із того боку на краю екрана |
| `Super + Shift + Arrow`  | Поміняти вікно місцями з іншим у напрямку стрілки, включно з вікном на моніторі з того боку |
| `Super + Minus` | Розширити вікно ліворуч |
| `Super + Equal` | Звузити вікно ліворуч |
| `Super + Shift + Minus` | Звузити вікно вгору |
| `Super + Shift + Equal` | Розширити вікно вниз |
| `Super + Alt + Minus/Equal` | Те саме змінення розміру меншими кроками |
| `Super + Ctrl + Minus/Equal` | Те саме змінення розміру більшими кроками |
| `Super + Alt + Home` | Зберегти ширину вікна |
| `Super + Home` | Відновити збережену ширину вікна |
| `Super + Left Mouse` | Перетягувати вікно |
| `Super + Right Mouse` | Змінювати розмір вікна |
| `Super + Scroll Wheel` | Прокручувати робочі простори на моніторі у фокусі |
| `Super + G`               | Перемкнути групування вікон      |
| `Super + Alt + G`               | Вивести вікно з групування      |
| `Super + Alt + Tab`               | Перебирати вікна в групуванні      |
| `Super + Alt + Shift + Tab`               | Перебирати вікна в групуванні у зворотному порядку      |
| `Super + Alt + Scroll Wheel` | Перебирати вікна в групуванні |
| `Super + Alt + 1/2/3/4/5`               | Перейти до певного вікна в групуванні      |
| `Super + Alt + Arrow`  | Перемістити вікно до групування в напрямку стрілки, включно з вікном на моніторі з того боку |
| `Super + Ctrl + Left/Right`  | Переміщатися між вікнами всередині групи tiling |
| `Super + Ctrl + Z` | Наблизити екран (повторіть для більшого наближення) |
| `Super + Ctrl + Alt + Z` | Повністю віддалити екран |
| `Super + /` | Крокувати вперед варіантами масштабування монітора |
| `Super + Alt + /` | Крокувати назад варіантами масштабування монітора |
| `Alt + Tab` | Перебирати вікна на активному робочому просторі вперед |
| `Alt + Shift + Tab` | Перебирати вікна на активному робочому просторі назад |
| `Ctrl + Alt + Tab`| Перебирати фокус моніторів вперед |
| `Ctrl + Alt + Shift + Tab`| Перебирати фокус моніторів назад |

## Універсальний буфер обміну

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Super + C`           | Копіювати    |
| `Super + X`           | Вирізати (не в терміналі)    |
| `Super + V`           | Вставити    |
| `Super + Ctrl + V`           | Менеджер буфера обміну    |

Зазвичай у Linux вам потрібні `Ctrl + Shift + C/V` для копіювання й вставлення в терміналі та `Ctrl + C/V`, щоб робити це всюди інде. Ці уніфіковані гарячі клавіші буфера обміну Omarchy працюють всюди.

## Захоплення

| Гаряча клавіша              | Функція                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Знімок екрана                      |
| `Super + Ctrl + Alt + C`            | Знімок екрана (той самий знімок, для клавіатур без клавіші Print Screen) |
| `Super + Ctrl + C` | Меню захоплення |
| `Alt + Print Screen`            | Запис екрана                     |
| `Super + Print Screen` | Вибір кольору |
| `Super + Ctrl + Print Screen` | Витягнути текст до буфера обміну |
| `Super + Alt + [` | Зробити накладку вебкамери меншою під час запису |
| `Super + Alt + ]` | Зробити накладку вебкамери більшою під час запису |
| `Alt + Shift + L` | Копіювати поточний URL із вебзастосунку або Chromium |
| `Alt + Shift + D` | Завантажити відео на поточній сторінці до `~/Videos` |
| `Super + Ctrl + X` | Почати/зупинити диктування (потребує _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | Диктування push-to-talk (потребує Voxtype або Superwhisper) |

Під час запису екрана гаряча клавіша спочатку запитує, який звук ви хочете, а потім починає запис. Натисніть її ще раз, щоб зупинити. Подробиці див. у [знімки екрана та запис](12-screenshots-recording.md).

Усі варіанти захоплення також доступні в розділі _Trigger > Capture_ у меню Omarchy (`Super + Space`).

## Tmux

Префіксна клавіша — `Ctrl + Space` (`Ctrl + B` також працює). Ви можете змінити ці прив'язки у `~/.config/tmux/tmux.conf`.

### Панелі

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + v` | Розділити панель поруч (вертикально) |
| `Prefix + h` | Розділити панель нижче (горизонтально) |
| `Prefix + x` | Закрити панель |
| `Prefix + z` | Перемкнути масштаб панелі (на весь екран) |
| `Alt + Enter` | Розділити панель нижче (без префікса) |
| `Alt + Shift + Enter` | Розділити панель поруч (без префікса) |
| `Alt + Escape` | Закрити панель (без префікса) |
| `Ctrl + Alt + Arrows` | Переміщатися між панелями |
| `Ctrl + Alt + Shift + Arrows` | Змінювати розмір панелей |

### Вікна

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + c` | Нове вікно |
| `Prefix + k` | Закрити вікно |
| `Prefix + r` | Перейменувати вікно |
| `Alt + 1-9` | Перейти до певного вікна |
| `Alt + Arrow Left/Right` | Переміщатися між вікнами |
| `Alt + Shift + Arrow Left/Right` | Перемістити вікно ліворуч/праворуч |

### Сесії

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |

| `Prefix + s` | Список сесій |
| `Prefix + d` | Від'єднатися від сесії |

### Режим копіювання (у стилі vi)

| Гаряча клавіша                  | Функція              |

### Загальне

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + q` | Перезавантажити конфігурацію |

### Функції компонування Tmux

Ці функції треба запускати всередині сесії Tmux.

| Команда | Функція |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Створити компонування для розробки з редактором, AI і терміналом |
| `tdlm <ai> [<second_ai>]` | Створити компонування для розробки для кожного підкаталогу |
| `tsl <count> <command>` | Створити багатопанельне компонування swarm |

## Швидкі емодзі

Ви можете використати `Super + Ctrl + E`, щоб показати повний вибір емодзі, який помістить вибране в буфер обміну, або можете скористатися цими варіантами швидкого доступу.

| Гаряча клавіша       | EM | Підказка       |
| ------------ | -- | ---------- |
