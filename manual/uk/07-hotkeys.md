# Гарячі клавіші

Ви можете переглянути всі основні прив’язки клавіш за допомогою `Super + K` (прив’язки Tmux — за допомогою `Super + Alt + K`, а прив’язки Herdr — за допомогою `Super + Ctrl + K`).

## Як влаштовано гарячі клавіші

Кожна гаряча клавіша розташована на площині, яку задають її модифікатори, і кожна площина має одне завдання. Саме це не дає гарячим клавішам змішуватися, і завдяки цьому ви зазвичай можете вгадати, де щось живе.

| Площина | Що там живе | Приклади |
| --- | --- | --- |
| `Super + key` | Система: вікна, робочі простори, макети та основні меню | `Super + Space` меню Omarchy, `Super + W` закрити вікно, `Super + F` на весь екран |
| `Super + Shift + key` | Застосунки | `Super + Shift + B` браузер, `Super + Shift + E` електронна пошта, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панелі та системні меню | `Super + Ctrl + A` аудіо, `Super + Ctrl + N` мережа, `Super + Ctrl + C` меню захоплення |
| `Super + Ctrl + Alt + key` | Швидкі дії та сповістки | `Super + Ctrl + Alt + T` показати час, `Super + Ctrl + Alt + B` батарея, `Super + Ctrl + Alt + C` знімок екрана |

Додавання `Alt` до гарячої клавіші дає вам варіант того самого, ніколи щось непов’язане:

- `Super + Shift + B` відкриває браузер; `Super + Shift + Alt + B` відкриває приватне вікно
- `Super + Shift + E` відкриває електронну пошту; `Super + Shift + Alt + E` починає новий лист
- `Super + F` переходить на весь екран; `Super + Alt + F` переходить на всю ширину
- `Super + Ctrl + C` відкриває меню захоплення; `Super + Ctrl + Alt + C` пропускає меню й робить знімок екрана

Під час додавання гарячої клавіші:

1. Спочатку оберіть площину за тим, що вона робить, потім оберіть клавішу.
2. Не переміщуйте наявну гарячу клавішу, щоб звільнити місце. Знайдіть вільну клавішу на правильній площині.
3. Використовуйте `Alt` лише для варіанта гарячої клавіші без неї.

Кілька гарячих клавіш порушують ці правила, бо так зручно. `Shift` зі стрілкою або `Tab` переміщує або повертає у зворотному напрямку замість відкриття застосунку, а `Print`, медіаклавіші, `Alt + Tab` і `Ctrl + Alt + Del` працюють так, як і скрізь. Це винятки, а не зразки для копіювання.

Якщо стандартне призначення вам не підходить (скажімо, ви хочете `Super + Shift + S` для знімків екрана, як у Windows), переназначте його в `~/.config/hypr/bindings.lua`.

| `Super + Alt + /` | Крок назад серед варіантів масштабування монітора |

На тачпаді свайпи трьома та чотирма пальцями перемикають робочі простори, переміщують вікна й відкривають меню та консоль Quake; див. [клавіатура, миша та трекпад](34-keyboard-mouse-trackpad.md) щодо жестів.

Для змінення розміру використовуються дві клавіші праворуч від 0, хоч би що на них було надруковано на вашій клавіатурі: `-` і `=` на клавіатурах US, `+` і `´` на данських і шведських, `+` і `\` на норвезьких, `ß` і `´` на німецьких, `'` і `¡` на іспанських та `-` і `^` на японських (JIS). `Super + K` показує їх так, як їх надруковано на вашій клавіатурі. На JIS `Super + ^` — це `Super + Equal`, а `Super + Shift + -` (що вводить `=`) — це `Super + Shift + Minus`. Масштабування монітора та менеджер паролів використовують `/`; на розкладках, які вводять `/` лише з Shift, як більшість європейських, вони натомість використовують клавішу ліворуч від правого Shift (`-` на данській і німецькій).

## Універсальний буфер обміну

| Гаряча клавіша | Функція |
| ----------------------- | --------------------- |
| `Super + A` | Вибрати все в застосунках, які підтримують `Ctrl + A` |
| `Super + C` | Копіювати |
| `Super + X` | Вирізати (не в терміналі) |
| `Super + V` | Вставити |
| `Super + Ctrl + V` | Менеджер буфера обміну |

Зазвичай у Linux вам потрібні `Ctrl + Shift + C/V`, щоб копіювати й вставляти в терміналі, і `Ctrl + C/V`, щоб робити це скрізь решта. Ці уніфіковані гарячі клавіші буфера обміну Omarchy працюють скрізь.

## Tmux

Клавіша префікса — `Ctrl + Space` (також працює `Ctrl + B`). Ви можете змінити ці прив’язки в `~/.config/tmux/tmux.conf`.

### Панелі

| Гаряча клавіша | Функція |
| ----------------------- | --------------------- |
| `Prefix + v` | Розділити панель поруч (вертикально) |
| `Prefix + h` | Розділити панель знизу (горизонтально) |
| `Prefix + x` | Закрити панель |
