# Гарячі клавіші

Ви можете переглянути всі основні прив'язки клавіш за допомогою `Super + K` (прив'язки Tmux — за допомогою `Super + Alt + K`, а прив'язки Herdr — за допомогою `Super + Ctrl + K`).

## Як влаштовані гарячі клавіші

Кожна гаряча клавіша розташована на площині, яку задають її модифікатори, і кожна площина має одне завдання. Саме це не дає гарячим клавішам змішуватися, і зазвичай ви можете здогадатися, де що живе.

| Площина | Що там живе | Приклади |
| --- | --- | --- |
| `Super + key` | Система: вікна, робочі простори, розкладки та основні меню | `Super + Space` меню Omarchy, `Super + W` закрити вікно, `Super + F` повний екран |
| `Super + Shift + key` | Програми | `Super + Shift + B` браузер, `Super + Shift + E` пошта, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панелі та системні меню | `Super + Ctrl + A` аудіо, `Super + Ctrl + N` мережа, `Super + Ctrl + C` меню захоплення |
| `Super + Ctrl + Alt + key` | Швидкі дії та повідомлення | `Super + Ctrl + Alt + T` показати час, `Super + Ctrl + Alt + B` батарея, `Super + Ctrl + Alt + C` знімок екрана |

Додавання `Alt` до гарячої клавіші дає вам варіант того самого, ніколи щось непов'язане:

- `Super + Shift + B` відкриває браузер; `Super + Shift + Alt + B` відкриває приватне вікно
- `Super + Shift + E` відкриває пошту; `Super + Shift + Alt + E` починає новий лист
- `Super + F` вмикає повний екран; `Super + Alt + F` вмикає повну ширину
- `Super + Ctrl + C` відкриває меню захоплення; `Super + Ctrl + Alt + C` пропускає меню й робить знімок екрана

Додаючи гарячу клавішу:

1. Виберіть площину за тим, що вона робить, потім виберіть клавішу.
2. Не рухайте наявну гарячу клавішу, щоб звільнити місце. Знайдіть вільну клавішу на правильній площині.
3. Використовуйте `Alt` лише для варіанта гарячої клавіші без нього.

Кілька гарячих клавіш порушують ці правила, бо так зручно. `Shift` зі стрілкою або `Tab` рухає або розвертає замість того, щоб відкривати програму, а `Print`, мультимедійні клавіші, `Alt + Tab` і `Ctrl + Alt + Del` працюють так, як і скрізь. Це винятки, а не взірці для наслідування.

Якщо стандартний варіант вам не підходить (скажімо, ви хочете `Super + Shift + S` для знімків екрана, як у Windows), перев'яжіть його у `~/.config/hypr/bindings.lua`.

| `Ctrl + Alt + Shift + Tab`| Циклічно переміщати фокус назад між моніторами |

Клавіші для зміни розміру використовують фізичні клавіші `code:20` і `code:21` (XKB `<AE11>` і `<AE12>`), незалежно від символів, надрукованих на клавіатурі. На американських клавіатурах це клавіші `-` і `=`; на японських (JIS) клавіатурах це `-` і `^`; на іспанських клавіатурах це `'` і `¡`. На JIS `Super + ^` — це `Super + Equal`, а `Super + Shift + -` (яка вводить `=`) — це `Super + Shift + Minus`.
