# Гарячі клавіші

Усі основні сполучення клавіш можна переглянути за допомогою `Super + K` (сполучення Tmux — за допомогою `Super + Alt + K`, а сполучення Herdr — за допомогою `Super + Ctrl + K`).

## Навігація

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Super + Space`           | Меню Omarchy (застосунки та все інше)    |
| `Super + Alt + Space` | Сітка застосунків |
| `Super + Escape` | Системне меню (режим сну, перезавантаження тощо)  |
| `Super + Ctrl + L` | Заблокувати комп'ютер |
| `Super + W` or `Super + Q` | Закрити вікно             |
| `Ctrl + Alt + Del` | Закрити всі вікна |
| `Super + T`               | Перемкнути вікно між плитковим/плаваючим режимами             |
| `Super + J` | Перемкнути положення вікна (горизонтальне/вертикальне) |
| `Super + O`               | Перемкнути вікно в закріплений плаваючий режим |
| `Super + L`               | Циклічно перемикати компонування dwindle, scrolling і floating |
| `Super + Alt + L`         | Циклічно перемикати компонування у зворотному порядку |
| `Super + P`               | Перемкнути стиль псевдовікна (natural v stretch) |
| `Super + F`                 | Перейти в повноекранний режим              |
| `Super + Alt + F`                 | Розгорнути на всю ширину              |
| `Super + Ctrl + F`                 | Перейти в повноекранний режим усередині вікна              |
| `Super + 1/2/3/4`         | Перейти до певного робочого простору на активному моніторі |
| `Super + Tab` | Перейти до наступного робочого простору на активному моніторі |
| `Super + Shift + Tab` | Перейти до попереднього робочого простору на активному моніторі |
| `Super + Ctrl + Tab` | Перейти до колишнього робочого простору на активному моніторі |
| `Super + Shift + 1/2/3/4` | Перемістити вікно до робочого простору на активному моніторі |
| `Super + Shift + Alt + 1/2/3/4` | Перемістити вікно до робочого простору на активному моніторі без переходу за ним |
| `Super + S` | Перемкнути повний scratchpad |
| `Super + Alt + S` | Перемістити вікно до повного scratchpad |
| `Super + Grave` | Перемкнути консоль Quake |
| `Super + Shift + Grave` | Перемістити вікно до консолі Quake |
| `Super + Shift + Ctrl + Arrows` | Перемістити вікно на монітор у тому напрямку |
| `Super + Shift + Alt + Arrows` | Перемістити робочий простір на монітор у тому напрямку |
| `Super + Arrow`  | Перемістити фокус на вікно в напрямку стрілки, переходячи до монітора з того боку на краю екрана |
| `Super + Shift + Arrow`  | Обміняти вікно місцями з іншим у напрямку стрілки, включно з вікном на моніторі з того боку |
| `Super + Minus` | Розширити вікно ліворуч |
| `Super + Equal` | Звузити вікно ліворуч |
| `Super + Shift + Minus` | Зменшити вікно догори |
| `Super + Shift + Equal` | Розширити вікно донизу |
| `Super + Alt + Minus/Equal` | Те саме змінення розміру меншими кроками |
| `Super + Ctrl + Minus/Equal` | Те саме змінення розміру більшими кроками |
| `Super + Alt + Home` | Зберегти ширину вікна |
| `Super + Home` | Відновити збережену ширину вікна |
| `Super + Left Mouse` | Перетягувати вікно |
| `Super + Right Mouse` | Змінювати розмір вікна |
| `Super + Scroll Wheel` | Прокручувати робочі простори на активному моніторі |
| `Super + G`               | Перемкнути групування вікон      |
| `Super + Alt + G`               | Винести вікно з групи      |
| `Super + Alt + Tab`               | Циклічно перемикати вікна в групі      |
| `Super + Alt + Shift + Tab`               | Циклічно перемикати вікна в групі у зворотному порядку      |
| `Super + Alt + Scroll Wheel` | Циклічно перемикати вікна в групі |
| `Super + Alt + 1/2/3/4/5`               | Перейти до певного вікна в групі      |
| `Super + Alt + Arrow`  | Перемістити вікно в групу в напрямку стрілки, включно з вікном на моніторі з того боку |
| `Super + Ctrl + Left/Right`  | Переміщатися між вікнами всередині плиткової групи |
| `Super + Ctrl + Z` | Наблизити екран (повторити для більшого наближення) |
| `Super + Ctrl + Alt + Z` | Повністю віддалити екран |
| `Super + /` | Крок уперед між варіантами масштабування монітора |
| `Super + Alt + /` | Крок назад між варіантами масштабування монітора |
| `Alt + Tab` | Циклічно перемикати вікна на активному робочому просторі вперед |
| `Alt + Shift + Tab` | Циклічно перемикати вікна на активному робочому просторі назад |
| `Ctrl + Alt + Tab`| Циклічно переміщувати фокус між моніторами вперед |
| `Ctrl + Alt + Shift + Tab`| Циклічно переміщувати фокус між моніторами назад |

## Універсальний буфер обміну

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Super + C`           | Копіювати    |
| `Super + X`           | Вирізати (не в терміналі)    |
| `Super + V`           | Вставити    |
| `Super + Ctrl + V`           | Менеджер буфера обміну    |

Зазвичай у Linux для копіювання й вставлення в терміналі потрібне `Ctrl + Shift + C/V`, а скрізь деінде — `Ctrl + C/V`. Ці уніфіковані гарячі клавіші буфера обміну Omarchy працюють скрізь.

## Захоплення

| Гаряча клавіша              | Функція                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Знімок екрана                      |
| `Super + Ctrl + Alt + C`            | Знімок екрана (той самий знімок, для клавіатур без клавіші Print Screen) |
| `Super + Ctrl + C` | Меню захоплення |
| `Alt + Print Screen`            | Запис екрана                     |
| `Super + Print Screen` | Вибір кольору |
| `Super + Ctrl + Print Screen` | Витягування тексту в буфер обміну |
| `Super + Alt + [` | Зменшити накладення вебкамери під час запису |
| `Super + Alt + ]` | Збільшити накладення вебкамери під час запису |

Під час запису екрана гаряча клавіша спочатку запитує, який звук потрібен, а потім починає запис. Натисніть її ще раз, щоб зупинити. Деталі див. у розділі [знімки екрана та запис](12-screenshots-recording.md).

Усі параметри захоплення також доступні в розділі _Тригер > Захоплення_ меню Omarchy (`Super + Space`).

## Tmux

Префіксна клавіша — `Ctrl + Space` (`Ctrl + B` також працює). Ці сполучення можна змінити у файлі `~/.config/tmux/tmux.conf`.

### Панелі

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + v` | Розділити панель поруч (вертикально) |
| `Prefix + h` | Розділити панель нижче (горизонтально) |
| `Prefix + x` | Закрити панель |
| `Prefix + z` | Перемкнути масштаб панелі (на весь екран) |
| `Alt + Enter` | Розділити панель нижче (без префікса) |
| `Alt + Shift + Enter` | Розділити панель поруч (без префікса) |
| `Alt + Escape` | Закрити панель (без префікса) |
| `Ctrl + Alt + Arrows` | Переміщатися між панелями |
| `Ctrl + Alt + Shift + Arrows` | Змінювати розмір панелей |

### Вікна

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + c` | Нове вікно |
| `Prefix + k` | Закрити вікно |
| `Prefix + r` | Перейменувати вікно |
| `Alt + 1-9` | Перейти до певного вікна |
| `Alt + Arrow Left/Right` | Переміщатися між вікнами |
| `Alt + Shift + Arrow Left/Right` | Перемістити вікно ліворуч/праворуч |

### Сесії

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + C` | Нова сесія |
| `Prefix + K` | Завершити сесію |
| `Prefix + R` | Перейменувати сесію |
| `Prefix + N` | Наступна сесія |
| `Prefix + P` | Попередня сесія |
| `Alt + Arrow Up/Down` | Переміщатися між сесіями |
| `Prefix + s` | Список сесій |
| `Prefix + d` | Від'єднатися від сесії |

### Режим копіювання (у стилі vi)

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |

| `v` | Почати виділення (у режимі копіювання) |
| `y` | Копіювати виділене (у режимі копіювання) |

### Загальне

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + q` | Перезавантажити конфігурацію |
| `Prefix + ?` | Показати сполучення клавіш Tmux |
| `Prefix + :` | Командний рядок |

### Функції компонування Tmux

Ці функції слід запускати всередині сесії Tmux.

| Команда | Функція |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Створити компонування для розробки з редактором, AI і терміналом |
| `tdlm <ai> [<second_ai>]` | Створити компонування для розробки для кожного підкаталогу |
| `tsl <count> <command>` | Створити багатопанельне компонування swarm |

## Швидкі емодзі

За допомогою `Super + Ctrl + E` можна показати повний вибір емодзі, який помістить вибране в буфер обміну, або скористатися цими варіантами швидкого доступу.

| Гаряча клавіша       | EM | Підказка       |
| ------------ | -- | ---------- |
| `Shift + CapsLock M S` | 😄 | усмішка      |
| `Shift + CapsLock M C` | 😂 | плач        |
| `Shift + CapsLock M L` | 😍 | любов       |
| `Shift + CapsLock M V` | ✌️ | перемога    |
| `Shift + CapsLock M H` | ❤️ | серце      |

| `Shift + CapsLock M R` | 🤘 | рок       |
| `Shift + CapsLock M K` | 😘 | поцілунок       |
| `Shift + CapsLock M E` | 🙄 | закочування очей    |

## Швидкі доповнення

| Гаряча клавіша       | Доповнення       |
| ------------ |  ---------- |
| `Shift + CapsLock Space Space` | — (довге тире)   |
| `Shift + CapsLock Space N` | Ваше ім'я (як вказано під час налаштування)  |
| `Shift + CapsLock Space E` | Ваша електронна пошта (як вказано під час налаштування)  |

Більше власних можна додати, відредагувавши `~/.XCompose`, а потім виконавши `omarchy-restart-xcompose` у терміналі, щоб зміни було застосовано.
