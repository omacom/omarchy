# Гарячі клавіші

Ви можете переглянути всі основні прив’язки клавіш за допомогою `Super + K` (прив’язки Tmux — за допомогою `Super + Alt + K`, а прив’язки Herdr — за допомогою `Super + Ctrl + K`).

## Навігація

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Super + Space`           | Меню Omarchy (застосунки та все інше)    |
| `Super + Alt + Space` | Сітка застосунків |
| `Super + Escape` | Системне меню (призупинення, перезавантаження тощо)  |
| `Super + Ctrl + L` | Заблокувати комп’ютер |
| `Super + W` or `Super + Q` | Закрити вікно             |
| `Ctrl + Alt + Del` | Закрити всі вікна |
| `Super + T`               | Перемкнути вікно між плитковим/плаваючим режимами             |
| `Super + J` | Перемкнути положення вікна (горизонтальне/вертикальне) |
| `Super + O`               | Перемкнути вікно в режим sticky'n'floating |
| `Super + L`               | Перемикатися між розкладками dwindle, scrolling і floating |
| `Super + Alt + L`         | Перемикатися між розкладками у зворотному порядку |
| `Super + P`               | Перемкнути стиль псевдовікна (natural чи stretch) |
| `Super + F`                 | Перейти в повноекранний режим              |
| `Super + Alt + F`                 | Розгорнути на всю ширину              |
| `Super + Ctrl + F`                 | Повноекранний режим усередині вікна              |
| `Super + 1/2/3/4`         | Перейти до певного робочого простору на активному моніторі |
| `Super + Tab` | Перейти до наступного робочого простору на активному моніторі |
| `Super + Shift + Tab` | Перейти до попереднього робочого простору на активному моніторі |
| `Super + Ctrl + Tab` | Перейти до колишнього робочого простору на активному моніторі |
| `Super + Shift + 1/2/3/4` | Перемістити вікно до робочого простору на активному моніторі |
| `Super + Shift + Alt + 1/2/3/4` | Перемістити вікно до робочого простору на активному моніторі без переходу за ним |
| `Super + S` | Перемкнути повний scratchpad |
| `Super + Alt + S` | Перемістити вікно до повного scratchpad |
| `Super + Grave` | Перемкнути консоль Quake |
| `Super + Shift + Grave` | Перемістити вікно до консолі Quake |
| `Super + Shift + Ctrl + Arrows` | Перемістити вікно на монітор у тому напрямку |
| `Super + Shift + Alt + Arrows` | Перемістити робочий простір на монітор у тому напрямку |
| `Super + Arrow`  | Перемістити фокус на вікно в напрямку стрілки, переходячи на монітор з того боку біля краю екрана |
| `Super + Shift + Arrow`  | Поміняти вікно місцями з іншим у напрямку стрілки, включно з вікном на моніторі з того боку |
| `Super + Minus` | Розширити вікно ліворуч |
| `Super + Equal` | Звузити вікно ліворуч |
| `Super + Shift + Minus` | Зменшити вікно вгору |
| `Super + Shift + Equal` | Розширити вікно вниз |
| `Super + Alt + Minus/Equal` | Те саме змінення розміру меншими кроками |
| `Super + Ctrl + Minus/Equal` | Те саме змінення розміру більшими кроками |
| `Super + Alt + Home` | Зберегти ширину вікна |
| `Super + Home` | Відновити збережену ширину вікна |
| `Super + Left Mouse` | Перетягувати вікно |
| `Super + Right Mouse` | Змінювати розмір вікна |
| `Super + Scroll Wheel` | Прокручувати робочі простори на активному моніторі |
| `Super + G`               | Перемкнути групування вікон      |
| `Super + Alt + G`               | Вивести вікно з групи      |
| `Super + Alt + Tab`               | Перемикатися між вікнами в групі      |
| `Super + Alt + Shift + Tab`               | Перемикатися між вікнами в групі у зворотному порядку      |
| `Super + Alt + Scroll Wheel` | Перемикатися між вікнами в групі |
| `Super + Alt + 1/2/3/4/5`               | Перейти до певного вікна в групі      |
| `Super + Alt + Arrow`  | Перемістити вікно в групу в напрямку стрілки, включно з вікном на моніторі з того боку |
| `Super + Ctrl + Left/Right`  | Переміщатися між вікнами всередині плиткової групи |
| `Super + Ctrl + Z` | Збільшити масштаб екрана (повторити для більшого збільшення) |
| `Super + Ctrl + Alt + Z` | Повністю зменшити масштаб екрана |
| `Super + /` | Крок вперед між варіантами масштабування монітора |
| `Super + Alt + /` | Крок назад між варіантами масштабування монітора |
| `Alt + Tab` | Перемикатися вперед між вікнами на активному робочому просторі |
| `Alt + Shift + Tab` | Перемикатися назад між вікнами на активному робочому просторі |
| `Ctrl + Alt + Tab`| Перемикати фокус вперед між моніторами |
| `Ctrl + Alt + Shift + Tab`| Перемикати фокус назад між моніторами |

Комбінації для змінення розміру використовують фізичні клавіші `code:20` і `code:21` (XKB `<AE11>` і `<AE12>`), незалежно від символів, надрукованих на клавіатурі. На американських клавіатурах це клавіші `-` і `=`; на японських (JIS) клавіатурах це `-` і `^`; на іспанських клавіатурах це `'` і `¡`. На JIS `Super + ^` — це `Super + Equal`, а `Super + Shift + -` (яка вводить `=`) — це `Super + Shift + Minus`.

## Універсальний буфер обміну

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Super + A`           | Вибрати все в застосунках, що підтримують `Ctrl + A`    |
| `Super + C`           | Копіювати    |
| `Super + X`           | Вирізати (не в терміналі)    |
| `Super + V`           | Вставити    |
| `Super + Ctrl + V`           | Менеджер буфера обміну    |

Зазвичай у Linux вам потрібні `Ctrl + Shift + C/V`, щоб копіювати та вставляти в терміналі, і `Ctrl + C/V`, щоб робити це скрізь. Ці уніфіковані гарячі клавіші буфера обміну Omarchy працюють скрізь.

## Tmux

Клавіша-префікс — це `Ctrl + Space` (`Ctrl + B` також працює). Ви можете змінити ці прив’язки у `~/.config/tmux/tmux.conf`.

### Панелі

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + v` | Розділити панель поруч (вертикально) |
| `Prefix + h` | Розділити панель нижче (горизонтально) |
| `Prefix + x` | Закрити панель |
| `Prefix + z` | Перемкнути масштаб панелі (на весь екран) |
| `Alt + Enter` | Розділити панель нижче (без префікса) |
| `Alt + Shift + Enter` | Розділити панель поруч (без префікса) |
| `Alt + Escape` | Закрити панель (без префікса) |
| `Ctrl + Alt + Arrows` | Переміщатися між панелями |
| `Ctrl + Alt + Shift + Arrows` | Змінювати розмір панелей |

### Вікна

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + c` | Нове вікно |
| `Prefix + k` | Закрити вікно |
| `Prefix + r` | Перейменувати вікно |

| `Alt + Arrow Left/Right` | Переміщатися між вікнами |
| `Alt + Shift + Arrow Left/Right` | Перемістити вікно ліворуч/праворуч |

### Загальне

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |

### Функції розкладок Tmux

Ці функції потрібно запускати всередині сеансу Tmux.

| Команда | Функція |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Створити розкладку для розробки з редактором, ШІ та терміналом |
| `tdlm <ai> [<second_ai>]` | Створити розкладку для розробки для кожного підкаталогу |
| `tsl <count> <command>` | Створити багатопанельну розкладку swarm |
