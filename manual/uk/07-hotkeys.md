# Клавіатурні скорочення

Усі основні клавіатурні скорочення можна переглянути через `Super + K` (скорочення Tmux — через `Super + Alt + K`, а Herdr — через `Super + Ctrl + K`).

## Навігація

| Клавіатурне скорочення | Дія |
| --- | --- |
| `Super + Space` | Меню Omarchy (програми й усе інше) |
| `Super + Alt + Space` | Меню програм |
| `Super + Escape` | Системне меню (призупинення, перезапуск тощо) |
| `Super + Ctrl + L` | Заблокувати компʼютер |
| `Super + W` або `Super + Q` | Закрити вікно |
| `Ctrl + Alt + Del` | Закрити всі вікна |
| `Super + T` | Перемкнути вікно між мозаїчним і плаваючим режимами |
| `Super + J` | Змінити розташування вікон із горизонтального на вертикальне й навпаки |
| `Super + O` | Зробити вікно закріпленим і плаваючим або повернути його назад |
| `Super + L` | Перемкнути компонування між dwindle і scrolling |
| `Super + P` | Перемкнути стиль псевдовікна (природне чи розтягнуте по вертикалі) |
| `Super + F` | Перейти до повноекранного режиму |
| `Super + Alt + F` | Розгорнути на всю ширину |
| `Super + Ctrl + F` | Перейти до повноекранного режиму всередині вікна |
| `Super + 1/2/3/4` | Перейти до певного робочого простору |
| `Super + Tab` | Перейти до наступного робочого простору |
| `Super + Shift + Tab` | Перейти до попереднього робочого простору |
| `Super + Ctrl + Tab` | Повернутися до колишнього робочого простору |
| `Super + Shift + 1/2/3/4` | Перемістити вікно до робочого простору |
| `Super + Shift + Alt + 1/2/3/4` | Перемістити вікно до робочого простору без переходу до нього |
| `Super + S` / `Super + Grave` | Показати або приховати scratchpad |
| `Super + Alt + S` / `Super + Shift + Grave` | Перемістити вікно до scratchpad |
| `Super + Shift + Alt + Arrows` | Перемістити робочі простори на монітор у напрямку стрілки |
| `Super + Arrow` | Перемістити фокус до вікна в напрямку стрілки |
| `Super + Shift + Arrow` | Поміняти вікно місцями з іншим у напрямку стрілки |
| `Super + Minus` | Розширити вікно ліворуч |
| `Super + Equal` | Звузити вікно ліворуч |
| `Super + Shift + Minus` | Зменшити вікно згори |
| `Super + Shift + Equal` | Розширити вікно вниз |
| `Super + Alt + Minus/Equal` | Так само змінити розмір меншими кроками |
| `Super + Ctrl + Minus/Equal` | Так само змінити розмір більшими кроками |
| `Super + Alt + Home` | Зберегти ширину вікна |
| `Super + Home` | Відновити збережену ширину вікна |
| `Super + Left Mouse` | Перетягнути вікно |
| `Super + Right Mouse` | Змінити розмір вікна |
| `Super + Scroll Wheel` | Прокручувати робочі простори |
| `Super + G` | Увімкнути або вимкнути групування вікон |
| `Super + Alt + G` | Вивести вікно з групи |
| `Super + Alt + Tab` | Переходити між вікнами в групі |
| `Super + Alt + Shift + Tab` | Переходити між вікнами в групі у зворотному напрямку |
| `Super + Alt + 1/2/3/4/5` | Перейти до певного вікна в групі |
| `Super + Alt + Arrow` | Додати до групи вікно в напрямку стрілки |
| `Super + Ctrl + Left/Right` | Переходити між вікнами в мозаїчній групі |
| `Super + Ctrl + Z` | Збільшити масштаб екрана (повторіть для подальшого збільшення) |
| `Super + Ctrl + Alt + Z` | Повністю зменшити масштаб екрана |
| `Super + /` | Перейти до наступного варіанта масштабування монітора |
| `Super + Alt + /` | Перейти до попереднього варіанта масштабування монітора |
| `Alt + Tab` | Переходити вперед між вікнами в активному робочому просторі |
| `Alt + Shift + Tab` | Переходити назад між вікнами в активному робочому просторі |
| `Ctrl + Alt + Tab` | Переміщувати фокус уперед між моніторами |
| `Ctrl + Alt + Shift + Tab` | Переміщувати фокус назад між моніторами |

## Єдиний буфер обміну

| Клавіатурне скорочення | Дія |
| --- | --- |
| `Super + C` | Копіювати |
| `Super + X` | Вирізати (не в терміналі) |
| `Super + V` | Вставити |
| `Super + Ctrl + V` | Менеджер буфера обміну |

Зазвичай у Linux для копіювання й вставлення в терміналі потрібно натискати `Ctrl + Shift + C/V`, а в решті програм — `Ctrl + C/V`. Єдині клавіатурні скорочення буфера обміну Omarchy працюють усюди.

## Захоплення

| Клавіатурне скорочення | Дія |
| --- | --- |
| `Super + Ctrl + C` | Меню захоплення (для клавіатур без клавіші PrintScr) |
| `Print Screen` | Знімок екрана |
| `Alt + Print Screen` | Запис екрана |
| `Super + Print Screen` | Вибір кольору |
| `Super + Ctrl + Print Screen` | Розпізнати текст і скопіювати до буфера обміну |
| `Super + Alt + [` | Зменшити накладене зображення з вебкамери під час запису |
| `Super + Alt + ]` | Збільшити накладене зображення з вебкамери під час запису |
| `Alt + Shift + L` | Скопіювати поточну URL-адресу з вебпрограми або Chromium |
| `Alt + Shift + D` | Завантажити відео з поточної сторінки до `~/Videos` |
| `Super + Ctrl + X` | Почати або зупинити диктування (потрібно _Install > AI > Dictation_) |
| `F9` | Диктування в режимі «натисни й говори» (потрібно _Install > AI > Dictation_) |

Під час запису екрана клавіатурне скорочення спочатку пропонує вибрати джерело звуку, а потім починає запис. Натисніть його ще раз, щоб зупинити запис. Докладніше див. [знімки й запис екрана](../12-screenshots-recording.md).

Усі засоби захоплення також доступні в меню Omarchy (`Super + Space`) за шляхом _Trigger > Capture_.

| --- | --- |

## Tmux

Префіксна клавіша — `Ctrl + Space` (також працює `Ctrl + B`). Ці привʼязки можна змінити у файлі `~/.config/tmux/tmux.conf`.

### Панелі

| Клавіатурне скорочення | Дія |
| --- | --- |
| `Prefix + v` | Розділити панель збоку (вертикально) |
| `Prefix + h` | Розділити панель знизу (горизонтально) |
| `Prefix + x` | Закрити панель |
| `Prefix + z` | Увімкнути або вимкнути масштабування панелі (повноекранний режим) |
| `Alt + Enter` | Розділити панель знизу (без префікса) |
| `Alt + Shift + Enter` | Розділити панель збоку (без префікса) |
| `Alt + Escape` | Закрити панель (без префікса) |
| `Ctrl + Alt + Arrows` | Переходити між панелями |
| `Ctrl + Alt + Shift + Arrows` | Змінювати розмір панелей |

### Вікна

| Клавіатурне скорочення | Дія |
| --- | --- |
| `Prefix + c` | Нове вікно |
| `Prefix + k` | Закрити вікно |
| `Prefix + r` | Перейменувати вікно |
| `Alt + 1-9` | Перейти до певного вікна |
| `Alt + Arrow Left/Right` | Переходити між вікнами |
| `Alt + Shift + Arrow Left/Right` | Перемістити вікно ліворуч або праворуч |

### Сеанси

| Клавіатурне скорочення | Дія |
| --- | --- |
| `Prefix + C` | Новий сеанс |
| `Prefix + K` | Завершити сеанс |
| `Prefix + R` | Перейменувати сеанс |
| `Prefix + N` | Наступний сеанс |
| `Prefix + P` | Попередній сеанс |
| `Alt + Arrow Up/Down` | Переходити між сеансами |
| `Prefix + s` | Переглянути список сеансів |
| `Prefix + d` | Відʼєднатися від сеансу |

### Режим копіювання (у стилі vi)

| Клавіатурне скорочення | Дія |
| --- | --- |
| `Prefix + [` | Перейти в режим копіювання |
| `v` | Почати виділення (у режимі копіювання) |
| `y` | Скопіювати виділене (у режимі копіювання) |

### Загальні

| Клавіатурне скорочення | Дія |
| --- | --- |
| `Prefix + q` | Перезавантажити конфігурацію |
| `Prefix + ?` | Показати клавіатурні скорочення Tmux |
| `Prefix + :` | Командний рядок |

### Функції компонування Tmux

Ці функції потрібно запускати в сеансі Tmux.

| Команда | Дія |
| --- | --- |
| `tdl <ai> [<second_ai>]` | Створити компонування для розробки з редактором, ШІ й терміналом |
| `tdlm <ai> [<second_ai>]` | Створити компонування для розробки в кожному підкаталозі |
| `tsl <count> <command>` | Створити багатопанельне компонування рою |
