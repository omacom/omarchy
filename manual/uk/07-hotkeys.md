# Гарячі клавіші

Ви можете побачити всі головні сполучення клавіш через `Super + K` (призначення Tmux через `Super + Alt + K`, а призначення Herdr через `Super + Ctrl + K`).

## Навігація

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Super + Space`           | Меню Omarchy (програми й усе інше)    |
| `Super + Alt + Space` | Сітка програм |
| `Super + Escape` | Системне меню (сон, перезапуск тощо)  |
| `Super + Ctrl + L` | Заблокувати комп’ютер |
| `Super + W` або `Super + Q` | Закрити вікно             |
| `Ctrl + Alt + Del` | Закрити всі вікна |
| `Super + T`               | Перемкнути вікно між мозаїчним/плаваючим             |
| `Super + J` | Перемкнути положення вікна (горизонтальне/вертикальне) |
| `Super + O`               | Перемкнути вискакувальне вікно в липке й плаваюче |
| `Super + L`               | Циклічно змінювати схеми dwindle, прокручування й плаваючу |
| `Super + Alt + L`         | Циклічно змінювати схеми у зворотному порядку |
| `Super + P`               | Перемкнути псевдостиль вікна (природний проти розтягнутого) |
| `Super + F`                 | Перейти на весь екран              |
| `Super + Alt + F`                 | Перейти на всю ширину              |
| `Super + Ctrl + F`                 | Перейти на весь екран усередині вікна              |
| `Super + 1/2/3/4`         | Перейти до конкретного робочого простору     |
| `Super + Tab` | Перейти до наступного робочого простору |
| `Super + Shift + Tab` | Перейти до попереднього робочого простору |
| `Super + Ctrl + Tab` | Перейти до колишнього робочого простору |
| `Super + Shift + 1/2/3/4` | Перемістити вікно на робочий простір |
| `Super + Shift + Alt + 1/2/3/4` | Перемістити вікно на робочий простір, не йдучи за ним |
| `Super + S` / `Super + Grave` | Перемкнути чернетку |
| `Super + Alt + S` / `Super + Shift + Grave` | Перемістити вікно до чернетки |
| `Super + Shift + Alt + Arrows` | Перемістити робочі простори на монітор у напрямку |
| `Super + Arrow`  | Перемістити фокус до вікна в напрямку стрілки              |
| `Super + Shift + Arrow`  | Поміняти вікно з іншим у напрямку стрілки     |
| `Super + Minus` | Розширити вікно ліворуч |
| `Super + Equal` | Зменшити вікно ліворуч |
| `Super + Shift + Minus` | Зменшити вікно вгору |
| `Super + Shift + Equal` | Розширити вікно вниз |
| `Super + Alt + Minus/Equal` | Те саме змінювання розміру меншими кроками |
| `Super + Ctrl + Minus/Equal` | Те саме змінювання розміру більшими кроками |
| `Super + Alt + Home` | Зберегти ширину вікна |
| `Super + Home` | Відновити збережену ширину вікна |
| `Super + Left Mouse` | Перетягувати вікно |
| `Super + Right Mouse` | Змінювати розмір вікна |
| `Super + Scroll Wheel` | Прокручувати робочі простори |
| `Super + G`               | Перемкнути групування вікон      |
| `Super + Alt + G`               | Перемістити вікно з групування      |
| `Super + Alt + Tab`               | Циклічно рухатися між вікнами в групуванні      |
| `Super + Alt + Shift + Tab`               | Циклічно рухатися назад між вікнами в групуванні      |
| `Super + Alt + 1/2/3/4/5`               | Перейти до конкретного вікна в групуванні      |
| `Super + Alt + Arrow`  | Перемістити вікно в групування в напрямку стрілки  |
| `Super + Ctrl + Left/Right`  | Рухатися між вікнами всередині мозаїчної групи |
| `Super + Ctrl + Z` | Збільшити масштаб екрана (повторити для більшого масштабу) |
| `Super + Ctrl + Alt + Z` | Повністю зменшити масштаб екрана |
| `Super + /` | Крок уперед через опції масштабування монітора |
| `Super + Alt + /` | Крок назад через опції масштабування монітора |
| `Alt + Tab` | Циклічно рухатися вперед через вікна на активному робочому просторі |
| `Alt + Shift + Tab` | Циклічно рухатися назад через вікна на активному робочому просторі |
| `Ctrl + Alt + Tab`| Циклічно рухати фокус уперед через монітори |
| `Ctrl + Alt + Shift + Tab`| Циклічно рухати фокус назад через монітори |

## Універсальний буфер обміну

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Super + C`           | Копіювати    |
| `Super + X`           | Вирізати (не в терміналі)    |
| `Super + V`           | Вставити    |
| `Super + Ctrl + V`           | Менеджер буфера обміну    |

Зазвичай у Linux вам потрібні `Ctrl + Shift + C/V` для копіювання й вставляння в терміналі та `Ctrl + C/V` — скрізь в інших місцях. Ці єдині гарячі клавіші буфера обміну Omarchy працюють скрізь.

## Захоплення

| Гаряча клавіша              | Функція                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Меню захоплення (для клавіатур без кнопки PrintScr) |
| `Print Screen`            | Знімок екрана                      |
| `Alt + Print Screen`            | Запис екрана                     |
| `Super + Print Screen` | Вибір кольору |
| `Super + Ctrl + Print Screen` | Вилучення тексту в буфер обміну |
| `Super + Alt + [` | Зменшити накладання вебкамери під час запису |
| `Super + Alt + ]` | Збільшити накладання вебкамери під час запису |
| `Alt + Shift + L` | Скопіювати поточний URL із вебпрограми або Chromium |
| `Alt + Shift + D` | Завантажити відео з поточної сторінки до `~/Videos` |
| `Super + Ctrl + X` | Запустити/зупинити диктування (потребує _Налаштування > Типові > Диктування_) |
| `Right Alt` / `F9` | Диктування «натисни й говори» (потребує Voxtype або Superwhisper) |

Під час запису екрана гаряча клавіша спершу запитує, який звук ви хочете, а потім починає запис. Натисніть її ще раз, щоб зупинити. Див. деталі в [знімки екрана й запис](12-screenshots-recording.md).

Усі опції захоплення також доступні в _Дії > Захоплення_ в меню Omarchy (`Super + Space`).

## Tmux

Префіксна клавіша — це `Ctrl + Space` (`Ctrl + B` теж працює). Ви можете змінити ці призначення в `~/.config/tmux/tmux.conf`.

### Панелі

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + v` | Розділити панель поруч (вертикально) |
| `Prefix + h` | Розділити панель нижче (горизонтально) |
| `Prefix + x` | Вбити панель |
| `Prefix + z` | Перемкнути масштаб панелі (на весь екран) |
| `Alt + Enter` | Розділити панель нижче (без префікса) |
| `Alt + Shift + Enter` | Розділити панель поруч (без префікса) |
| `Alt + Escape` | Вбити панель (без префікса) |
| `Ctrl + Alt + Arrows` | Рухатися між панелями |
| `Ctrl + Alt + Shift + Arrows` | Змінювати розмір панелей |

### Вікна

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + c` | Нове вікно |
| `Prefix + k` | Вбити вікно |
| `Prefix + r` | Перейменувати вікно |
| `Alt + 1-9` | Перейти до конкретного вікна |
| `Alt + Arrow Left/Right` | Рухатися між вікнами |
| `Alt + Shift + Arrow Left/Right` | Перемістити вікно ліворуч/праворуч |

### Сеанси

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + C` | Новий сеанс |
| `Prefix + K` | Вбити сеанс |
| `Prefix + R` | Перейменувати сеанс |
| `Prefix + N` | Наступний сеанс |
| `Prefix + P` | Попередній сеанс |
| `Alt + Arrow Up/Down` | Рухатися між сеансами |
| `Prefix + s` | Перелічити сеанси |
| `Prefix + d` | Відключитися від сеансу |

### Режим копіювання (стиль vi)

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + [` | Увійти в режим копіювання |
| `v` | Почати виділення (у режимі копіювання) |
| `y` | Скопіювати виділення (у режимі копіювання) |

### Загальне

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Prefix + q` | Перезавантажити конфігурацію |
| `Prefix + ?` | Показати сполучення клавіш Tmux |
| `Prefix + :` | Командний рядок |

### Функції схеми Tmux

Ці функції мають запускатися всередині сеансу Tmux.

| Command | Функція |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Створити схему розробника з редактором, AI і терміналом |
| `tdlm <ai> [<second_ai>]` | Створити схему розробника для кожного підкаталогу |
| `tsl <count> <command>` | Створити схему рою з кількох панелей |
