# Гарячі клавіші

Усі основні прив'язки клавіш можна побачити за допомогою `Super + K` (прив'язки Tmux — за допомогою `Super + Alt + K`, а прив'язки Herdr — за допомогою `Super + Ctrl + K`).

## Як влаштовано гарячі клавіші

Кожна гаряча клавіша розташована на площині, яку задають її модифікатори, і кожна площина має одне завдання. Саме це не дає гарячим клавішам змішуватися, і зазвичай ви можете здогадатися, де що живе.

| Площина | Що там живе | Приклади |
| --- | --- | --- |
| `Super + key` | Система: вікна, робочі простори, розкладки та основні меню | `Super + Space` меню Omarchy, `Super + W` закрити вікно, `Super + F` повний екран |
| `Super + Shift + key` | Застосунки | `Super + Shift + B` браузер, `Super + Shift + E` пошта, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панелі та системні меню | `Super + Ctrl + A` аудіо, `Super + Ctrl + N` мережа, `Super + Ctrl + C` меню захоплення |
| `Super + Ctrl + Alt + key` | Швидкі дії та оповіщення | `Super + Ctrl + Alt + T` показати час, `Super + Ctrl + Alt + B` батарея, `Super + Ctrl + Alt + C` скриншот |

Додавання `Alt` до гарячої клавіші дає варіант того самого, ніколи щось непов'язане:

- `Super + Shift + B` відкриває браузер; `Super + Shift + Alt + B` відкриває приватне вікно
- `Super + Shift + E` відкриває пошту; `Super + Shift + Alt + E` починає новий лист
- `Super + F` переходить на повний екран; `Super + Alt + F` розгортає на всю ширину
- `Super + Ctrl + C` відкриває меню захоплення; `Super + Ctrl + Alt + C` пропускає меню і робить скриншот

Коли додаєте гарячу клавішу:

1. Спочатку оберіть площину за тим, що вона робить, потім оберіть клавішу.
2. Не переміщуйте наявну гарячу клавішу, щоб звільнити місце. Знайдіть вільну клавішу на правильній площині.
3. Використовуйте `Alt` лише для варіанта гарячої клавіші без неї.

Кілька гарячих клавіш порушують ці правила, бо так зручно. `Shift` зі стрілкою або `Tab` переміщує або розвертає, а не відкриває застосунок, а `Print`, мультимедійні клавіші, `Alt + Tab` і `Ctrl + Alt + Del` працюють так, як скрізь. Це винятки, а не шаблони для копіювання.

Якщо типовий варіант вам не підходить (скажімо, ви хочете `Super + Shift + S` для скриншотів, як у Windows), переприв'яжіть його в `~/.config/hypr/bindings.lua`.

Комбінації для змінення розміру використовують фізичні клавіші `code:20` і `code:21` (XKB `<AE11>` і `<AE12>`), незалежно від символів, надрукованих на клавіатурі. На клавіатурах US ці клавіші — `-` і `=`; на японських (JIS) клавіатурах це `-` і `^`; на іспанських клавіатурах це `'` і `¡`. На JIS `Super + ^` — це `Super + Equal`, а `Super + Shift + -` (що вводить `=`) — це `Super + Shift + Minus`.
