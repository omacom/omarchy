# Гарячі клавіші

Ви можете переглянути всі основні прив’язки клавіш за допомогою `Super + K` (прив’язки Tmux — за допомогою `Super + Alt + K`, а прив’язки Herdr — за допомогою `Super + Ctrl + K`).

## Як влаштовані гарячі клавіші

Кожна гаряча клавіша розташована на площині, яку задають її модифікатори, і кожна площина має одне завдання. Саме це не дає гарячим клавішам змішуватися, і це означає, що ви зазвичай можете здогадатися, де що живе.

| Площина | Що там живе | Приклади |
| --- | --- | --- |
| `Super + key` | Система: вікна, робочі простори, розкладки та основні меню | `Super + Space` меню Omarchy, `Super + W` закрити вікно, `Super + F` на весь екран |
| `Super + Shift + key` | Застосунки | `Super + Shift + B` браузер, `Super + Shift + E` електронна пошта, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панелі та системні меню | `Super + Ctrl + A` аудіо, `Super + Ctrl + N` мережа, `Super + Ctrl + C` меню захоплення |
| `Super + Ctrl + Alt + key` | Швидкі дії та повідомлення | `Super + Ctrl + Alt + T` показати час, `Super + Ctrl + Alt + B` батарея, `Super + Ctrl + Alt + C` скриншот |

Додавання `Alt` до гарячої клавіші дає вам варіант тієї самої дії, ніколи щось непов’язане:

- `Super + Shift + B` відкриває браузер; `Super + Shift + Alt + B` відкриває приватне вікно
- `Super + Shift + E` відкриває електронну пошту; `Super + Shift + Alt + E` починає новий лист
- `Super + F` переходить на весь екран; `Super + Alt + F` переходить на всю ширину
- `Super + Ctrl + C` відкриває меню захоплення; `Super + Ctrl + Alt + C` пропускає меню і робить скриншот

Під час додавання гарячої клавіші:

1. Оберіть площину за тим, що вона робить, потім оберіть клавішу.
2. Не переміщуйте наявну гарячу клавішу, щоб звільнити місце. Знайдіть вільну клавішу на правильній площині.
3. Використовуйте `Alt` лише для варіанта гарячої клавіші без неї.

Кілька гарячих клавіш порушують ці правила, бо так зручно. `Shift` зі стрілкою або `Tab` переміщує або повертає назад, а не відкриває застосунок, а `Print`, медіаклавіші, `Alt + Tab` і `Ctrl + Alt + Del` працюють так само, як і скрізь. Це винятки, а не шаблони для наслідування.

Якщо значення за замовчуванням вам не підходить (скажімо, ви хочете `Super + Shift + S` для скриншотів, як у Windows), перепризначте його в `~/.config/hypr/bindings.lua`.

На тачпаді свайпи трьома та чотирма пальцями перемикають робочі простори, переміщують вікна та відкривають меню й консоль Quake; див. [клавіатура, миша та трекпад](34-keyboard-mouse-trackpad.md) щодо жестів.

Для змінення розміру використовуються дві клавіші праворуч від 0, хай що надруковано на вашій клавіатурі: `-` і `=` на клавіатурах US, `+` і `´` на данських і шведських, `+` і `\` на норвезьких, `ß` і `´` на німецьких, `'` і `¡` на іспанських та `-` і `^` на японських (JIS). `Super + K` показує їх так, як надруковано на вашій клавіатурі. На JIS `Super + ^` — це `Super + Equal`, а `Super + Shift + -` (яка вводить `=`) — це `Super + Shift + Minus`. Масштабування монітора та менеджер паролів використовують `/`; на розкладках, де `/` вводиться лише з Shift, як у більшості європейських, вони натомість використовують клавішу ліворуч від правого Shift (`-` на данських і німецьких).

## Універсальний буфер обміну

| Гаряча клавіша                  | Функція              |
| ----------------------- | --------------------- |
| `Super + A`           | Вибрати все в застосунках, що підтримують `Ctrl + A`    |
| `Super + C`           | Копіювати    |
| `Super + X`           | Вирізати (не в терміналі)    |
| `Super + V`           | Вставити    |

## Tmux

Клавіша префікса — `Ctrl + Space` (`Ctrl + B` також працює). Ви можете змінити ці прив’язки в `~/.config/tmux/tmux.conf`.

| Гаряча клавіша                  | Функція              |
