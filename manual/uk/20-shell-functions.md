# Функції оболонки

Omarchy постачається з набором функцій оболонки, щоб спрощувати типові завдання та інкапсулювати заплутані виклики з параметрами.

## Стиснення

- `compress [file/dir]`: Створити архів tar.gz із файла/каталогу.
- `decompress [file.tar.gz]`: Розпакувати файл tar.gz.

## Носії

- `iso2sd [image.iso]`: Створити завантажувальний носій на SD-карті з указаного файла iso, вибравши носій інтерактивно.
- `format-drive [device] [name]`: Відформатувати весь диск одним розділом exFAT (який працює також на Windows і macOS). Виконайте без аргументів, щоб побачити доступні диски. Будьте обережні!

## Розкладки для розробки

Миттєві багатопанельні розкладки для розробки в tmux:

- `tdl [ai]`: Створити розкладку Tmux Dev Layout із вашим редактором, ШІ-агентом і терміналом. Використовуйте аліаси агентів, наприклад `tdl c` для opencode або `tdl cx` для Claude Code, або передайте другого агента, щоб запускати обох, наприклад `tdl c cx`.
- `tds`: Створити Tmux Dev Square із редактором, переглядом змін (через `hunk diff --watch`), терміналом та opencode.
- `tdlm [ai]`: Створити вікно `tdl` для кожного підкаталогу в поточному каталозі.
- `tsl [count] [command]`: Створити рій панелей, укладених мозаїкою в сітку, де всі виконують одну й ту саму команду (чудово для ШІ-агентів).

Ті самі розкладки доступні для Herdr як `hdl`, `hds`, `hdlm` та `hsl`.

## Git worktrees

- `ga [branch]`: Створити новий worktree і гілку поряд із поточним репозиторієм та стрибнути до нього.
- `gd`: Прибрати поточний worktree та його гілку (спочатку запитує підтвердження).

## Спостерігачі rsync

- `rsw [source] [destination]`: Запустити фонового спостерігача, який виконує rsync із джерела до місця призначення щоразу, коли щось змінюється. Місцем призначення може бути віддалений хост, наприклад `rsw ~/Work/app nyc-dev:Work/app`.
- `lsw`: Показати список усіх активних спостерігачів.
- `dsw`: Зупинити всіх активних спостерігачів.

## Перекидання портів SSH

Ідеально для веброзробки з привілеями безпечного контексту localhost проти віддаленої машини.

- `fip`: Перекинути один або кілька портів із віддаленого хоста на localhost через SSH.
- `dip`: Відʼєднати один або кілька перекинутих портів.
- `lip`: Показати список усіх активних перекидань портів SSH.

Припустімо, ви запускаєте сервер розробки на порті `3000` на машині, доступній як `nyc-dev`; тоді ви можете виконати `fip nyc-dev 3000`, щоб перекинути цей порт, і `localhost:3000` насправді діставатиметься до `nyc-dev:3000`, але без потреби в SSL-сертифікатах для встановлення безпечного контексту, потрібного, скажімо, для тестування вебсокетів.

## Повторне підʼєднання SSH

Сам `ssh` обгорнуто у функцію, яка прибирає за терміналом, якщо зʼєднання обривається, поки його захопив віддалений tmux, Herdr або редактор, а потім автоматично підʼєднується знову, коли інтерактивний сеанс падає (Ctrl-C зупиняє цикл повторів).
