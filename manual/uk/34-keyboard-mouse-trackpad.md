# Клавіатура, миша, трекпад

Hyprland дозволяє дуже детально налаштувати всі ваші пристрої введення. Ви можете зробити повторення клавіатури надзвуково швидким або налаштувати трекпад на природне прокручування. Усе це змінюється у `~/.config/hypr/input.lua`, куди також можна потрапити через _Setup > Input_ у меню Omarchy (`Super + Space`). Усе, що ви там задасте, замінює стандартні налаштування Omarchy.

Ось приклад:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Ви можете [переглянути всі параметри введення](https://wiki.hypr.land/Configuring/Basics/Variables/#input) на вікі Hyprland щодо введення.

CapsLock працює як звичайний Caps Lock, а `Shift + CapsLock` — це клавіша Compose для [швидких емодзі](07-hotkeys.md#quick-emojis) та [інших доповнень](07-hotkeys.md#quick-completions). Якщо ви хочете, щоб клавіша Compose була деінде, замініть `omarchy:shift_caps_compose` у `kb_options`. Наприклад, це переміщує клавішу Compose на Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Жести трекпада

Проведіть пальцями по трекпаду, щоб переміщатися робочим столом:

| Жест | Дія |
| --- | --- |
| Три пальці вліво / вправо | Попередній / наступний робочий простір, включно з порожніми |
| Три пальці вгору | Перемкнути консоль ШІ |
| Три пальці вниз | Відкрити меню Omarchy |
| Чотири пальці вліво / вправо | Перемістити активне вікно на попередній / наступний робочий простір |
| Чотири пальці вниз | Перемкнути повноекранний режим |

Щоб змінити один із них, скасуйте його у `~/.config/hypr/input.lua`, перш ніж додавати власний [жест трекпада](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), оскільки Hyprland не прийме два жести для однакової кількості пальців і напрямку:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Щоб вимкнути всі жести Omarchy, встановіть `omarchy_default_gestures = false` біля початку `~/.config/hypr/hyprland.lua`, перш ніж завантажаться стандартні налаштування Omarchy.

На ноутбуках Dell XPS із тактильним трекпадом ви також можете встановити силу натискання на низьку, середню або високу у _Trigger > Hardware > Touchpad Haptics_.

### Введення китайською, японською та іншими мовами

Виберіть японську, корейську, китайську (Simplified, Pinyin), тайванську (Zhuyin) або гонконгську (Cangjie), коли інсталятор запитає про вашу клавіатуру. Omarchy налаштовує клавіатуру та відповідний рушій введення автоматично, зокрема під час офлайн-налаштування при першому завантаженні. Для японської використовується Mozc, для корейської — стандартний дворядний Hangul, для спрощеної китайської — Pinyin, для тайванської — стандартне розташування Zhuyin від Chewing, а для гонконгської — Cangjie з гонконгськими формами ієрогліфів. Japanese (US keyboard) надає Mozc із розкладкою клавіатури US. Клавіші Hangul, Zhuyin і Cangjie залишаються на своїх стандартних позиціях, навіть коли ви друкуєте латинські літери за допомогою Dvorak, Colemak або AZERTY. Якщо ви додали Hangul або Chewing раніше, зніміть і знову виберіть його у _Setup > Typing > Input Methods_, щоб перемістити його клавіші на ці позиції; Omarchy не чіпає рушій, яким ви вже друкуєте.

Введення починається в латинському режимі. Натисніть `Super + I`, щоб циклічно перемикатися між налаштованими методами введення, а `Super + Shift + I` — щоб перемикатися у зворотному напрямку. Натисніть сам `Shift`, щоб вийти з методу введення, як-от Pinyin, до латинських літер, і натисніть його ще раз, щоб повернутися, так само як працюють Sogou, Microsoft Pinyin і macOS; `Shift` плюс літера, як і раніше, друкує велику літеру. На японських клавіатурах 全角/半角 перемикає введення, 変換 вмикає його, а 無変換 вимикає. У корейській 한/영 перемикає Hangul, а 한자 перетворює на Hanja, незалежно від того, чи має ваша клавіатура окремі клавіші для цього, чи надсилає для них Right Alt і Right Ctrl, як це роблять багато ноутбуків, тож Right Alt і Right Ctrl там не є звичайними модифікаторами; натомість диктування перемикається комбінацією Alt + Space. `Ctrl + Space` залишається доступною для Tmux і Herdr; `Shift + CapsLock` залишається клавішею Compose.

Індикатор клавіатури з’являється праворуч на панелі, коли у вас є кілька розкладок клавіатури або методів введення. Клацніть його, щоб перемкнути мови введення; для японської відображається あ для хіраґани. Щоб вибрати японські ієрогліфи, перемкніться на японську, введіть слово, наприклад `nihongo`, а потім двічі натисніть Space. Натисніть Enter, щоб підтвердити вибір. Якщо у вас також є кілька розкладок клавіатури, клацніть індикатор правою кнопкою миші, щоб циклічно їх перемикати.

Скористайтеся _Setup > Typing > Keyboard Layouts_, щоб вибрати розкладки, як-от English і French, з тих самих варіантів, що пропонуються під час встановлення. Скористайтеся _Setup > Typing > Input Methods_, щоб вибрати, які рушії композиції активні. Обидва засоби вибору відкриваються всередині меню Omarchy, де ваші поточні вибори позначені. Клацніть або натисніть Enter, щоб перемкнути вибір; кожна зміна застосовується негайно. Скасування вибору методу введення видаляє його з циклу, не видаляючи його; клавіатура залишається доступною.

Виконайте `omarchy setup keyboard` або `omarchy setup input`, щоб відкрити ті самі засоби вибору. Щоб додати одну мову з командного рядка, скористайтеся `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` або `cangjie5`. Quick, Boshiamy і Array постачаються в одному пакеті з Cangjie і з’являються в засобі вибору Input Methods. Ваші власні клавіші перемикання зберігаються. Щоб отримати альтернативні розкладки або клавіші рушіїв, установіть `fcitx5-configtool` за допомогою `omarchy pkg add fcitx5-configtool` і запустіть його з термінала. Вибір мови введення не змінює мову робочого столу. Вибір японської, корейської або китайської у _Setup > Language_ додає відповідний метод введення, коли у вас ще немає жодного.

Використовуйте `Super + I`, щоб циклічно перемикатися між методами введення або розкладками клавіатури, а `Super + Shift + I` — щоб рухатися в зворотному напрямку, тож із трьома налаштованими варіантами ви можете переміщатися між двома сусідніми. Індикатор введення з’являється праворуч на панелі лише тоді, коли налаштовано більше одного методу введення або розкладки. Це прив’язування на робочому столі працює поряд із вашими наявними клавішами перемикання Fcitx; ви можете перевизначити його у `~/.config/hypr/bindings.lua`. Рушії введення та послідовності Compose використовують службу [Fcitx5](https://fcitx-im.org/), яка вже працює в кожному сеансі.

### Використання ALT замість SUPER

На деяких клавіатурах незручно використовувати основну метаклавішу (клавішу Windows/cmd) як SUPER. Натомість ви можете змінити її на ALT за допомогою такої зміни:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
