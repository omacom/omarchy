# Клавіатура, миша, трекпад

Hyprland дає змогу дуже детально налаштувати всі ваші пристрої введення. Ви можете зробити повторення клавіш надзвуково швидким або налаштувати для трекпада природне прокручування. Усе це змінюється у `~/.config/hypr/input.lua`, куди також можна потрапити через _Налаштування > Введення_ у меню Omarchy (`Super + Space`). Усе, що ви там задасте, замінює типові значення Omarchy.

Ось приклад:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Ви можете [переглянути всі параметри введення](https://wiki.hypr.land/Configuring/Basics/Variables/#input) у вікі Hyprland про введення.

CapsLock працює як звичайна Caps Lock, а `Shift + CapsLock` є клавішею Compose для [швидких емодзі](07-hotkeys.md#quick-emojis) та [інших доповнень](07-hotkeys.md#quick-completions). Якщо ви хочете розмістити клавішу Compose деінде, замініть `omarchy:shift_caps_compose` у `kb_options`. Наприклад, ось це переміщує клавішу Compose на Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Функціональні клавіші

Верхній ряд клавіатури ноутбука за замовчуванням надсилає медійні клавіші (гучність, яскравість тощо), а утримування `Fn` дає F1-F12; `Fn + Esc` фіксує це навпаки, доки ви не натиснете це знову. Більшість клавіатур самі запам’ятовують цю фіксацію. Ноутбуки ASUS і клавіатури в стилі Apple залишають це на Linux, який під час кожного завантаження запускає їх на медійних клавішах. Щоб замість цього вони запускалися на F1-F12, виконайте `omarchy keyboard toprow fnkeys` (а щоб повернутися назад — `omarchy keyboard toprow mediakeys`); на деяких ноутбуках це набуває чинності після перезавантаження. Комп’ютери Apple Silicon Mac зберігають власне налаштування.

### Жести на трекпаді

Свайпайте по трекпаду, щоб переміщатися робочим столом:

| Жест | Дія |
| --- | --- |
| Три пальці вліво / вправо | Попередній / наступний робочий простір, включно з порожніми |
| Три пальці вгору | Увімкнути або вимкнути консоль ШІ |
| Три пальці вниз | Відкрити меню Omarchy |
| Чотири пальці вліво / вправо | Перемістити активне вікно до попереднього / наступного робочого простору |
| Чотири пальці вниз | Увімкнути або вимкнути повноекранний режим |

Щоб змінити один із них, скасуйте його у `~/.config/hypr/input.lua`, перш ніж додавати власний [жест на тачпаді](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), оскільки Hyprland не прийме два жести на тих самих пальцях і в тому ж напрямку:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Щоб вимкнути всі жести Omarchy, встановіть `omarchy_default_gestures = false` ближче до початку `~/.config/hypr/hyprland.lua`, перш ніж завантажаться типові значення Omarchy.

На ноутбуках Dell XPS із тактильним тачпадом ви також можете встановити силу натискання на низьку, середню або високу в розділі _Спрацьовування > Обладнання > Тактильний відгук тачпада_.

### Введення китайською, японською та іншими мовами

Коли програма встановлення запитає про вашу клавіатуру, виберіть Japanese, Korean, Chinese (Simplified, Pinyin), Taiwan (Zhuyin) або Hong Kong (Cangjie). Omarchy автоматично налаштовує клавіатуру та відповідний рушій введення, зокрема під час офлайн-настроювання під час першого завантаження. Японська мова використовує Mozc, корейська — стандартний дволітерний Hangul, спрощена китайська — Pinyin, тайванська — стандартну розкладку Zhuyin від Chewing, а гонконгська — Cangjie з гонконгськими формами ієрогліфів. Japanese (US keyboard) надає Mozc із розкладкою клавіатури US. Клавіші Hangul, Zhuyin і Cangjie залишаються на своїх стандартних позиціях, навіть коли ви вводите латинські літери за допомогою Dvorak, Colemak або AZERTY. Якщо ви додали Hangul або Chewing раніше, зніміть і знову виберіть його в розділі _Налаштування > Клавіатура > Методи введення_, щоб перемістити його клавіші туди; рушій, яким ви вже користуєтеся, Omarchy залишить у спокої.

Введення починається в латинському режимі. Натисніть `Super + I`, щоб перемикатися між налаштованими методами введення, а `Super + Shift + I` — щоб перемикатися назад. Натисніть саму лише `Shift`, щоб вийти з методу введення, наприклад Pinyin, до латинських літер, і натисніть її ще раз, щоб повернутися, як це працює у Sogou, Microsoft Pinyin і macOS; `Shift` разом із літерою все одно вводить велику літеру. На японських клавіатурах 全角/半角 перемикає введення, 変換 вмикає його, а 無変換 вимикає його. У корейській мові 한/영 перемикає Hangul, а 한자 перетворює на Hanja, незалежно від того, чи має ваша клавіатура спеціальні клавіші, чи надсилає для них Right Alt і Right Ctrl, як це роблять багато ноутбуків, тож Right Alt і Right Ctrl там не є звичайними модифікаторами; диктування замість цього перемикається за допомогою Alt + Space. `Ctrl + Space` залишається доступною для Tmux і Herdr; `Shift + CapsLock` залишається клавішею Compose.

Індикатор клавіатури з’являється праворуч на панелі, коли у вас налаштовано кілька розкладок клавіатури або методів введення. Клацніть його, щоб перемкнути мови введення; для японської мови відображається あ для хіраґани. Для вибору японських ієрогліфів перемкніться на японську мову, введіть слово, наприклад `nihongo`, а потім двічі натисніть Space. Натисніть Enter, щоб прийняти свій вибір. Якщо у вас також є кілька розкладок клавіатури, клацніть індикатор правою кнопкою миші, щоб перемикатися між ними.

Використовуйте _Налаштування > Клавіатура > Розкладки клавіатури_, щоб вибрати розкладки, наприклад англійську та французьку, із тих самих варіантів, що пропонуються під час установлення. Використовуйте _Налаштування > Клавіатура > Методи введення_, щоб вибрати, які рушії композиції активні. Обидва засоби вибору відкриваються всередині меню Omarchy з позначеними вашими поточними виборами. Клацніть або натисніть Enter, щоб увімкнути або вимкнути вибір; кожна зміна застосовується негайно. Зняття вибору методу введення видаляє його з циклу, не видаляючи його; клавіатура залишається доступною.

Виконайте `omarchy setup keyboard` або `omarchy setup input`, щоб відкрити ті самі засоби вибору. Щоб додати одну мову з командного рядка, використовуйте `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` або `cangjie5`. Quick, Boshiamy і Array постачаються в тому ж пакеті, що й Cangjie, і з’являються у засобі вибору методів введення. Ваші користувацькі клавіші перемикання зберігаються. Для альтернативних розкладок або клавіш рушіїв установіть `fcitx5-configtool` за допомогою `omarchy pkg add fcitx5-configtool` і запустіть його з термінала. Вибір мови введення не змінює мову робочого столу. Вибір японської, корейської або китайської мови в розділі _Налаштування > Мова_ додає її метод введення, коли у вас його ще немає.

Використовуйте `Super + I`, щоб перемикатися між методами введення або розкладками клавіатури, а `Super + Shift + I` — щоб рухатися назад в інший бік, тож із трьома налаштованими ви можете переміщатися між двома сусідами. Індикатор введення з’являється праворуч на панелі лише тоді, коли налаштовано більше одного методу введення або розкладки. Це прив’язування на робочому столі працює разом із наявними клавішами перемикання Fcitx; ви можете перевизначити його у `~/.config/hypr/bindings.lua`. Рушії введення та послідовності Compose використовують службу [Fcitx5](https://fcitx-im.org/), яка вже працює в кожному сеансі.

### Використання ALT замість SUPER

На деяких клавіатурах незручно використовувати основну метаклавішу (клавішу Windows/cmd) як SUPER. Ви можете замість цього змінити її на ALT за допомогою такої зміни:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
