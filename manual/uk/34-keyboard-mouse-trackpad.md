# Клавіатура, миша, трекпад

Hyprland дозволяє дуже детально налаштувати всі ваші пристрої введення. Ви можете зробити повторення клавіатури надзвичайно швидким або налаштувати для трекпада природне прокручування. Усе це змінюється у `~/.config/hypr/input.lua`, куди також можна потрапити через _Налаштування > Введення_ в меню Omarchy (`Super + Space`). Усе, що ви там задасте, замінює стандартні налаштування Omarchy.

Ось приклад:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Ви можете [переглянути всі параметри введення](https://wiki.hypr.land/Configuring/Basics/Variables/#input) у вікі Hyprland щодо введення.

CapsLock працює як звичайний Caps Lock, а `Shift + CapsLock` — це клавіша compose для [швидких емодзі](07-hotkeys.md#quick-emojis) та [інших доповнень](07-hotkeys.md#quick-completions). Якщо ви хочете розмістити клавішу compose в іншому місці, замініть `omarchy:shift_caps_compose` у `kb_options`. Наприклад, це переносить клавішу compose на Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Функціональні клавіші

Верхній ряд клавіатури ноутбука за замовчуванням надсилає медійні клавіші (гучність, яскравість тощо), а утримання `Fn` дає F1-F12; `Fn + Esc` фіксує це навпаки, доки ви не натиснете її знову. Більшість клавіатур самі запам’ятовують цю фіксацію. Ноутбуки ASUS і клавіатури в стилі Apple залишають це Linux, яка запускає їх із медійними клавішами під час кожного завантаження. Щоб замість цього вони запускалися з F1-F12, виконайте `omarchy device keyboard toprow fnkeys` (і `omarchy device keyboard toprow mediakeys`, щоб повернутися назад); на деяких ноутбуках це набуває чинності після перезавантаження. Комп’ютери Apple Silicon Mac зберігають власне налаштування.

### Жести трекпада

Проведіть по трекпаду, щоб переміщатися робочим столом:

| Жест | Дія |
| --- | --- |
| Три пальці вліво / вправо | Попередній / наступний робочий простір, включно з порожніми |
| Три пальці вгору | Перемкнути консоль AI |
| Три пальці вниз | Відкрити меню Omarchy |
| Чотири пальці вліво / вправо | Перемістити активне вікно на попередній / наступний робочий простір |
| Чотири пальці вниз | Перемкнути повноекранний режим |

Щоб змінити один із них, скасуйте його в `~/.config/hypr/input.lua`, перш ніж додавати власний [жест трекпада](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), оскільки Hyprland не прийме два жести для тих самих пальців і напрямку:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Щоб вимкнути всі жести Omarchy, встановіть `omarchy_default_gestures = false` біля верхньої частини `~/.config/hypr/hyprland.lua`, перш ніж завантажаться стандартні налаштування Omarchy.

На ноутбуках Dell XPS із тактильним трекпадом ви також можете встановити силу натискання на низьку, середню або високу в розділі _Тригер > Обладнання > Тактильний відгук трекпада_.

### Введення китайською, японською та іншими мовами

Виберіть японську, корейську, китайську (спрощену, Pinyin), Тайвань (Zhuyin) або Гонконг (Cangjie), коли інсталятор запитає про вашу клавіатуру. Omarchy автоматично налаштовує клавіатуру та відповідний механізм введення, зокрема під час офлайн-настроювання при першому завантаженні. Японська мова використовує Mozc, корейська — стандартний дворядний Hangul, спрощена китайська — Pinyin, Тайвань — стандартне розташування Zhuyin від Chewing, а Гонконг — Cangjie з гонконгськими формами ієрогліфів. Японська (клавіатура US) надає Mozc із розкладкою клавіатури US. Клавіші Hangul, Zhuyin і Cangjie залишаються на своїх стандартних позиціях, навіть коли ви вводите латинські літери за допомогою Dvorak, Colemak або AZERTY. Якщо ви додали Hangul або Chewing до цього, зніміть із них вибір і виберіть їх знову в розділі _Налаштування > Клавіатура > Методи введення_, щоб перемістити їхні клавіші туди; Omarchy залишає в спокої механізм, яким ви вже користуєтеся для введення.

Введення починається в латинському режимі. Натисніть `Super + I`, щоб циклічно переходити між налаштованими методами введення, і `Super + Shift + I`, щоб циклічно повертатися назад. Торкніться `Shift` окремо, щоб вийти з методу введення, як-от Pinyin, до латинських літер, і торкніться її знову, щоб повернутися, так само як працюють Sogou, Microsoft Pinyin і macOS; `Shift` плюс літера все одно вводить велику літеру. На японських клавіатурах 全角/半角 перемикає введення, 変換 вмикає його, а 無変換 вимикає його. Для корейської мови 한/영 перемикає Hangul, а 한자 перетворює на Hanja, незалежно від того, чи має ваша клавіатура виділені клавіші, чи надсилає для них Right Alt і Right Ctrl, як це роблять багато ноутбуків, тому Right Alt і Right Ctrl там не є простими модифікаторами; натомість диктування перемикається за допомогою Alt + Space. `Ctrl + Space` залишається доступним для Tmux і Herdr; `Shift + CapsLock` залишається клавішею compose.

Індикатор клавіатури з’являється праворуч на панелі, коли у вас є кілька розкладок клавіатури або методів введення. Клацніть його, щоб перемкнути мови введення; японська мова відображає あ для хірагани. Щоб вибрати японські ієрогліфи, перемкніться на японську мову, введіть слово, наприклад `nihongo`, потім двічі натисніть Space. Натисніть Enter, щоб прийняти свій вибір. Якщо у вас також є кілька розкладок клавіатури, клацніть індикатор правою кнопкою миші, щоб циклічно переходити між ними.

Використовуйте _Налаштування > Клавіатура > Введення з клавіатури_, щоб вибрати розкладки, як-от англійську та французьку, з тих самих варіантів, що пропонуються під час встановлення. Використовуйте _Налаштування > Клавіатура > Методи введення_, щоб вибрати, які механізми композиції активні. Обидва засоби вибору відкриваються всередині меню Omarchy з позначеними вашими поточними виборами. Клацніть або натисніть Enter, щоб перемкнути вибір; кожна зміна застосовується негайно. Зняття вибору з методу введення видаляє його з циклу, не видаляючи його; клавіатура залишається доступною.

Виконайте `omarchy setup keyboard` або `omarchy setup input`, щоб відкрити ті самі засоби вибору. Щоб додати одну мову з командного рядка, використовуйте `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` або `cangjie5`. Quick, Boshiamy і Array постачаються в тому самому пакеті, що й Cangjie, і з’являються в засобі вибору методів введення. Ваші власні клавіші перемикання зберігаються. Для альтернативних розкладок або клавіш механізму встановіть `fcitx5-configtool` за допомогою `omarchy pkg add fcitx5-configtool` і запустіть його з термінала. Вибір мови введення не змінює мову робочого столу. Вибір японської, корейської або китайської мови в розділі _Налаштування > Регіон > Мова_ додає її метод введення, коли у вас ще немає жодного.

Використовуйте `Super + I`, щоб циклічно переходити між методами введення або розкладками клавіатури, і `Super + Shift + I`, щоб повернутися в інший бік, тож із трьома налаштованими ви можете переміщатися між двома сусідами. Індикатор введення з’являється праворуч на панелі лише тоді, коли налаштовано більше одного методу введення або розкладки. Це поєднання клавіш робочого столу працює поряд із вашими наявними клавішами перемикання Fcitx; ви можете перевизначити його в `~/.config/hypr/bindings.lua`. Механізми введення та послідовності compose використовують службу [Fcitx5](https://fcitx-im.org/), яка вже працює в кожному сеансі.

### Використання ALT як SUPER

На деяких клавіатурах незручно використовувати основну метаклавішу (клавішу Windows/cmd) як SUPER. Замість цього ви можете змінити її на ALT за допомогою цієї зміни:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
