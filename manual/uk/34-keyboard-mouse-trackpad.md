# Клавіатура, миша і трекпад

Hyprland дозволяє детально налаштувати всі ваші пристрої вводу. Ви можете зробити повторення клавіш надзвуково швидким або налаштувати природну прокрутку для трекпада. Все це змінюється у `~/.config/hypr/input.lua`, куди ви також можете потрапити через _Налаштування > Введення_ у меню Omarchy (`Super + Space`). Усе, що ви там задасте, замінить стандартні налаштування Omarchy.

Ось приклад:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Ви можете [переглянути всі параметри вводу](https://wiki.hypr.land/Configuring/Basics/Variables/#input) на вікі Hyprland щодо вводу.

CapsLock працює як звичайний Caps Lock, а `Shift + CapsLock` є клавішею Compose для [швидких емодзі](07-hotkeys.md#quick-emojis) та [інших доповнень](07-hotkeys.md#quick-completions). Якщо ви хочете розмістити клавішу Compose деінде, замініть `omarchy:shift_caps_compose` у `kb_options`. Наприклад, це перемістить клавішу Compose на Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Жести трекпада

Ви також можете увімкнути [жести сенсорної панелі](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), наприклад проведення трьома пальцями для зміни робочих просторів:

```lua
hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })
```

На ноутбуках Dell XPS із гаптичним трекпадом ви також можете задати силу натискання на низьку, середню або високу в розділі _Тригер > Обладнання > Гаптика сенсорної панелі_.

### Введення китайською, японською та іншими мовами

Коли інсталятор запитає про вашу клавіатуру, виберіть Japanese, Korean, Chinese (Simplified, Pinyin), Taiwan (Zhuyin) або Hong Kong (Cangjie). Omarchy автоматично налаштовує клавіатуру і відповідний рушій введення, зокрема під час офлайн-налаштування при першому завантаженні. Для японської використовується Mozc, для корейської — стандартний дволітерний Hangul, для спрощеної китайської — Pinyin, для Тайваню — стандартне розташування Zhuyin від Chewing, а для Гонконгу — Cangjie з гонконгськими формами ієрогліфів. Japanese (US keyboard) надає Mozc із розкладкою клавіатури US. Клавіші Hangul, Zhuyin і Cangjie залишаються на своїх стандартних позиціях, навіть коли ви друкуєте латинські літери за допомогою Dvorak, Colemak або AZERTY. Якщо ви додали Hangul або Chewing до цього, зніміть і знову виберіть його в розділі _Налаштування > Введення тексту > Методи введення_, щоб перемістити його клавіші на ці позиції; Omarchy не чіпає рушій, яким ви вже друкуєте.

Введення починається в латинському режимі. Натисніть `Super + I`, щоб циклічно перемикатися між налаштованими методами введення, і `Super + Shift + I`, щоб рухатися назад. Торкніться `Shift` окремо, щоб вийти з методу введення, як-от Pinyin, до латинських літер, і торкніться її ще раз, щоб повернутися, як це працює в Sogou, Microsoft Pinyin і macOS; `Shift` разом із літерою, як і раніше, друкує велику літеру. На японських клавіатурах 全角/半角 перемикає введення, 変換 вмикає його, а 無変換 вимикає. Для корейської 한/영 перемикає Hangul, а 한자 перетворює на Hanja, незалежно від того, чи має ваша клавіатура окремі клавіші, чи надсилає для них Right Alt і Right Ctrl, як це роблять багато ноутбуків, тож Right Alt і Right Ctrl не є там звичайними модифікаторами; диктування за принципом push-to-talk залишається на F9. `Ctrl + Space` залишається доступною для Tmux і Herdr; `Shift + CapsLock` залишається клавішею Compose.

Індикатор клавіатури з’являється праворуч на панелі, коли у вас є кілька розкладок клавіатури або методів введення. Натисніть його, щоб перемкнути мови введення; для японської відображається あ для хірагани. Щоб вибрати японські ієрогліфи, перемкніться на японську, введіть слово, наприклад `nihongo`, потім двічі натисніть Space. Натисніть Enter, щоб прийняти вибір. Якщо у вас також є кілька розкладок клавіатури, клацніть індикатор правою кнопкою миші, щоб циклічно перемикати їх.

Використовуйте _Налаштування > Введення тексту > Розкладки клавіатури_, щоб вибрати розкладки, наприклад English і French, із тих самих варіантів, що пропонуються під час встановлення. Використовуйте _Налаштування > Введення тексту > Методи введення_, щоб вибрати, які рушії композиції активні. Обидва засоби вибору відкриваються всередині меню Omarchy з вашими поточними виборами, позначеними галочками. Натисніть або натисніть Enter, щоб перемкнути вибір; кожна зміна застосовується негайно. Зняття вибору методу введення видаляє його з циклу, не видаляючи його з системи; клавіатура залишається доступною.

Виконайте `omarchy setup keyboard` або `omarchy setup input`, щоб відкрити ті самі засоби вибору. Щоб додати одну мову з командного рядка, використайте `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` або `cangjie5`. Quick, Boshiamy і Array постачаються в тому самому пакунку, що й Cangjie, і з’являються в засобі вибору методів введення. Ваші власні клавіші перемикання зберігаються. Для альтернативних розкладок або клавіш рушіїв встановіть `fcitx5-configtool` за допомогою `omarchy pkg add fcitx5-configtool` і запустіть його з термінала. Вибір мови введення не змінює мову робочого столу. Вибір Japanese, Korean або Chinese у розділі _Налаштування > Мова_ додає відповідний метод введення, коли у вас ще немає жодного.

Використовуйте `Super + I`, щоб циклічно перемикатися між методами введення або розкладками клавіатури, і `Super + Shift + I`, щоб рухатися в зворотному напрямку, тож із трьома налаштованими варіантами ви можете переміщатися між двома сусідами. Індикатор введення з’являється праворуч на панелі лише тоді, коли налаштовано більше одного методу введення або розкладки. Ця прив’язка для робочого столу працює поряд із вашими наявними клавішами перемикання Fcitx; ви можете перевизначити її у `~/.config/hypr/bindings.lua`. Рушії введення та послідовності Compose використовують службу [Fcitx5](https://fcitx-im.org/), яка вже працює в кожному сеансі.

### Використання ALT замість SUPER

На деяких клавіатурах незручно використовувати головну мета-клавішу (клавішу Windows/cmd) як SUPER. За допомогою цієї зміни ви можете натомість використовувати для цього ALT:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
