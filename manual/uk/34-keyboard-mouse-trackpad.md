# Клавіатура, миша, трекпад

Hyprland дає змогу дуже детально налаштувати всі ваші пристрої вводу. Ви можете зробити повторення клавіатури надзвуково швидким або налаштувати для трекпада природне прокручування. Усе це змінюється у `~/.config/hypr/input.lua`, до якого також можна перейти через _Setup > Input_ у меню Omarchy (`Super + Space`). Усе, що ви там встановите, замінює стандартні налаштування Omarchy.

Ось приклад:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Ви можете [переглянути всі параметри вводу](https://wiki.hypr.land/Configuring/Basics/Variables/#input) у вікі Hyprland щодо вводу.

CapsLock працює як звичайний Caps Lock, а `Shift + CapsLock` — це клавіша compose для [швидких емодзі](07-hotkeys.md#quick-emojis) та [інших доповнень](07-hotkeys.md#quick-completions). Якщо ви хочете, щоб клавіша compose була деінде, замініть `omarchy:shift_caps_compose` у `kb_options`. Наприклад, це переміщує клавішу compose на Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Функціональні клавіші

Верхній ряд клавіатури ноутбука за замовчуванням надсилає медіаклавіші (гучність, яскравість тощо), а утримання `Fn` дає F1-F12; `Fn + Esc` фіксує це навпаки, доки ви не натиснете її знову. Більшість клавіатур самі запам’ятовують цю фіксацію. Ноутбуки ASUS і клавіатури в стилі Apple залишають це Linux, яка запускає їх із медіаклавішами під час кожного завантаження. Щоб натомість вони запускалися з F1-F12, запустіть `omarchy device keyboard toprow fnkeys` (а `omarchy device keyboard toprow mediakeys`, щоб повернутися назад); на деяких ноутбуках це набуває чинності після перезавантаження. Комп’ютери Mac з Apple Silicon зберігають власне налаштування.

### Жести трекпада

Проведіть по трекпаду, щоб переміщатися робочим столом:

| Жест | Дія |
| --- | --- |
| Трьома пальцями вліво / вправо | Попередній / наступний робочий простір, включно з порожніми |
| Трьома пальцями вгору | Перемкнути AI-консоль |
| Трьома пальцями вниз | Відкрити меню Omarchy |
| Чотирма пальцями вліво / вправо | Перемістити активне вікно до попереднього / наступного робочого простору |
| Чотирма пальцями вниз | Перемкнути повноекранний режим |

Щоб змінити один із них, скасуйте його у `~/.config/hypr/input.lua`, перш ніж додавати власний [жест трекпада](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), оскільки Hyprland не прийме два жести для однакової кількості пальців та однакового напрямку:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Щоб вимкнути всі жести Omarchy, встановіть `omarchy_default_gestures = false` біля верхньої частини `~/.config/hypr/hyprland.lua`, перш ніж завантажаться стандартні налаштування Omarchy.

На ноутбуках Dell XPS із тактильним трекпадом ви також можете встановити силу натискання на низьку, середню або високу в _Trigger > Hardware > Touchpad Haptics_.

### Набір тексту китайською, японською та іншими мовами

Виберіть японську, корейську, китайську (спрощену, Pinyin), тайванську (Zhuyin) або гонконгську (Cangjie), коли програма встановлення запитає про вашу клавіатуру. Omarchy автоматично налаштовує клавіатуру та відповідний механізм вводу, зокрема під час офлайн-настроювання при першому завантаженні. Японська використовує Mozc, корейська використовує стандартну дворядну розкладку Hangul, спрощена китайська використовує Pinyin, Тайвань використовує стандартну розкладку Zhuyin від Chewing, а Гонконг використовує Cangjie з гонконгськими формами ієрогліфів. Японська (клавіатура US) надає Mozc із розкладкою клавіатури US. Клавіші Hangul, Zhuyin і Cangjie залишаються на своїх стандартних позиціях, навіть коли ви набираєте латинські літери за допомогою Dvorak, Colemak або AZERTY. Якщо ви додали Hangul або Chewing ще до цього, зніміть і знову виберіть його в _Setup > Keyboard > Input Methods_, щоб перемістити його клавіші туди; Omarchy не чіпає механізм, за допомогою якого ви вже набираєте текст.

Набір тексту починається в латинському режимі. Натисніть `Super + I`, щоб перемикатися між налаштованими методами вводу, і `Super + Shift + I`, щоб перемикатися назад. Торкніться `Shift` окремо, щоб вийти з методу вводу на кшталт Pinyin до латинських літер, і торкніться його ще раз, щоб повернутися, так, як це працює в Sogou, Microsoft Pinyin і macOS; `Shift` разом із літерою, як і раніше, вводить велику літеру. На японських клавіатурах 全角/半角 перемикає ввід, 変換 вмикає його, а 無変換 вимикає його. З корейською 한/영 перемикає Hangul, а 한자 перетворює на Hanja, незалежно від того, чи має ваша клавіатура окремі клавіші, чи надсилає для них Right Alt і Right Ctrl, як це роблять багато ноутбуків, тож Right Alt і Right Ctrl там не є звичайними модифікаторами; натомість диктування перемикається комбінацією Alt + Space. `Ctrl + Space` залишається доступною для Tmux і Herdr; `Shift + CapsLock` залишається клавішею compose.

Індикатор клавіатури з’являється праворуч на панелі, коли у вас є кілька розкладок клавіатури або методів вводу. Клацніть його, щоб перемкнути мови вводу; японська відображає あ для хірагани. Щоб вибрати японські ієрогліфи, перемкніться на японську, наберіть слово, наприклад `nihongo`, потім двічі натисніть Space. Натисніть Enter, щоб прийняти свій вибір. Якщо у вас також є кілька розкладок клавіатури, клацніть індикатор правою кнопкою, щоб перемикатися між ними.

Використовуйте _Setup > Keyboard > Keyboard Inputs_, щоб вибрати розкладки, як-от англійську та французьку, серед тих самих варіантів, що пропонуються під час встановлення. Використовуйте _Setup > Keyboard > Input Methods_, щоб вибрати, які механізми композиції активні. Обидва засоби вибору відкриваються в меню Omarchy з позначеними вашими поточними виборами. Клацніть або натисніть Enter, щоб увімкнути чи вимкнути варіант; кожна зміна застосовується негайно. Скасування вибору методу вводу видаляє його з циклу без його видалення; клавіатура залишається доступною.

Запустіть `omarchy setup keyboard` або `omarchy setup input`, щоб відкрити ті самі засоби вибору. Щоб додати одну мову з командного рядка, використовуйте `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` або `cangjie5`. Quick, Boshiamy та Array постачаються в тому самому пакунку, що й Cangjie, і з’являються в засобі вибору Input Methods. Ваші власні клавіші перемикання зберігаються. Для альтернативних розкладок або клавіш механізму встановіть `fcitx5-configtool` за допомогою `omarchy pkg add fcitx5-configtool` і запустіть його з термінала. Вибір мови вводу не змінює мову робочого столу. Вибір японської, корейської або китайської в _Setup > Language_ додає її метод вводу, якщо у вас ще жодного немає.

Використовуйте `Super + I`, щоб перемикатися між методами вводу або розкладками клавіатури, і `Super + Shift + I`, щоб рухатися у зворотному напрямку, тож із трьома налаштованими варіантами ви можете переходити між двома сусідніми. Індикатор вводу з’являється праворуч на панелі, лише коли налаштовано більше одного методу вводу або розкладки. Це прив’язування робочого столу працює разом із вашими наявними клавішами перемикання Fcitx; ви можете перевизначити його у `~/.config/hypr/bindings.lua`. Механізми вводу та послідовності compose використовують службу [Fcitx5](https://fcitx-im.org/), яка вже працює в кожному сеансі.

### Використання ALT як SUPER

На деяких клавіатурах незручно використовувати основну мета-клавішу (клавішу Windows/cmd) як SUPER. Ви можете змінити це на ALT натомість за допомогою такої зміни:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
