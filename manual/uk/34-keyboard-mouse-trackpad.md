# Клавіатура, миша, трекпад

Hyprland дає змогу дуже детально налаштувати всі пристрої введення. Ви можете зробити повторення клавіатури надзвуково швидким або налаштувати природне прокручування на трекпаді. Усе це змінюється у `~/.config/hypr/input.lua`, куди також можна потрапити через _Setup > Input_ у меню Omarchy (`Super + Space`). Усе, що ви там задасте, замінить стандартні налаштування Omarchy.

Ось приклад:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Ви можете [переглянути всі параметри введення](https://wiki.hypr.land/Configuring/Basics/Variables/#input) у вікі Hyprland, присвяченій введенню.

CapsLock працює як звичайний Caps Lock, а `Shift + CapsLock` є клавішею Compose для [швидких емодзі](07-hotkeys.md#quick-emojis) та [інших доповнень](07-hotkeys.md#quick-completions). Якщо ви хочете розмістити клавішу Compose в іншому місці, замініть `omarchy:shift_caps_compose` у `kb_options`. Наприклад, це перемістить клавішу Compose на Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Жести трекпада

Проводьте пальцями по трекпаду, щоб переміщатися робочим столом:

| Жест | Дія |
| --- | --- |
| Трьома пальцями вліво / вправо | Попередній / наступний робочий простір, включно з порожніми |
| Трьома пальцями вгору | Перемкнути AI-консоль |
| Трьома пальцями вниз | Відкрити меню Omarchy |
| Чотирма пальцями вліво / вправо | Перемістити активне вікно на попередній / наступний робочий простір |
| Чотирма пальцями вниз | Перемкнути повноекранний режим |

Щоб змінити один із них, скасуйте його у `~/.config/hypr/input.lua` перед додаванням власного [жесту трекпада](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), оскільки Hyprland не прийме два жести на однакову кількість пальців і в однаковому напрямку:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Щоб вимкнути всі жести Omarchy, встановіть `omarchy_default_gestures = false` біля початку `~/.config/hypr/hyprland.lua`, до завантаження стандартних налаштувань Omarchy.

На ноутбуках Dell XPS із тактильним тачпадом ви також можете встановити силу натискання на низьку, середню або високу в розділі _Trigger > Hardware > Touchpad Haptics_.

### Введення китайською, японською та іншими мовами

Виберіть японську, корейську, китайську (спрощену, Pinyin), тайванську (Zhuyin) або гонконгську (Cangjie), коли інсталятор запитає про вашу клавіатуру. Omarchy автоматично налаштовує клавіатуру та відповідний рушій введення, зокрема під час офлайн-налаштування при першому завантаженні. Японська використовує Mozc, корейська — стандартний двоклавішний Hangul, спрощена китайська — Pinyin, тайванська — стандартну схему Zhuyin від Chewing, а гонконгська — Cangjie з гонконгськими формами ієрогліфів. Японська (клавіатура US) надає Mozc із розкладкою клавіатури US. Клавіші Hangul, Zhuyin і Cangjie залишаються на своїх стандартних позиціях, навіть коли ви друкуєте латинські літери за допомогою Dvorak, Colemak або AZERTY. Якщо ви додавали Hangul або Chewing раніше, зніміть вибір і виберіть його повторно в розділі _Setup > Typing > Input Methods_, щоб перемістити його клавіші туди; Omarchy не чіпає рушій, яким ви вже друкуєте.

Введення починається в латинському режимі. Натисніть `Super + I`, щоб циклічно перемикатися між налаштованими методами введення, а `Super + Shift + I`, щоб перемикатися у зворотному напрямку. Натисніть `Shift` окремо, щоб вийти з методу введення, наприклад Pinyin, до латинських літер, і натисніть її ще раз, щоб повернутися, так, як це працює в Sogou, Microsoft Pinyin і macOS; `Shift` плюс літера, як і раніше, вводить велику літеру. На японських клавіатурах 全角/半角 перемикає введення, 変換 вмикає його, а 無変換 вимикає його. У корейській мові 한/영 перемикає Hangul, а 한자 перетворює на Hanja, незалежно від того, чи має ваша клавіатура виділені клавіші, чи надсилає для них Right Alt і Right Ctrl, як це роблять багато ноутбуків, тому Right Alt і Right Ctrl там не є звичайними модифікаторами; диктування push-to-talk залишається на F9. `Ctrl + Space` залишається доступною для Tmux і Herdr; `Shift + CapsLock` залишається клавішею Compose.

Індикатор клавіатури з’являється праворуч на панелі, коли у вас кілька розкладок клавіатури або методів введення. Клацніть його, щоб перемкнути мови введення; японська відображає あ для хіраґани. Щоб вибрати японські ієрогліфи, перемкніться на японську, введіть слово, наприклад `nihongo`, потім двічі натисніть Space. Натисніть Enter, щоб підтвердити вибір. Якщо у вас також кілька розкладок клавіатури, клацніть індикатор правою кнопкою миші, щоб циклічно перемикатися між ними.

Використовуйте _Setup > Typing > Keyboard Layouts_, щоб вибрати розкладки, наприклад англійську та французьку, з тих самих варіантів, що пропонуються під час встановлення. Використовуйте _Setup > Typing > Input Methods_, щоб вибрати, які рушії композиції активні. Обидва засоби вибору відкриваються всередині меню Omarchy з позначеними поточними виборами. Клацніть або натисніть Enter, щоб перемкнути вибір; кожна зміна застосовується негайно. Зняття вибору методу введення видаляє його з циклу, не видаляючи його; клавіатура залишається доступною.

Запустіть `omarchy setup keyboard` або `omarchy setup input`, щоб відкрити ті самі засоби вибору. Щоб додати одну мову з командного рядка, використовуйте `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` або `cangjie5`. Quick, Boshiamy і Array постачаються в одному пакеті з Cangjie і відображаються в засобі вибору Input Methods. Ваші власні клавіші перемикання зберігаються. Для альтернативних розкладок або клавіш рушія встановіть `fcitx5-configtool` за допомогою `omarchy pkg add fcitx5-configtool` і запустіть його з термінала. Вибір мови введення не змінює мову робочого стола. Вибір японської, корейської або китайської в розділі _Setup > Language_ додає відповідний метод введення, якщо у вас ще немає жодного.

Використовуйте `Super + I`, щоб циклічно перемикатися між методами введення або розкладками клавіатури, а `Super + Shift + I`, щоб рухатися у зворотному напрямку, тож із трьома налаштованими ви можете переміщатися між двома сусідами. Індикатор введення з’являється праворуч на панелі лише тоді, коли налаштовано більше одного методу введення або розкладки. Це прив’язування робочого стола працює разом із вашими наявними клавішами перемикання Fcitx; ви можете перевизначити його у `~/.config/hypr/bindings.lua`. Рушії введення та послідовності Compose використовують службу [Fcitx5](https://fcitx-im.org/), яка вже працює в кожному сеансі.

### Використання ALT як SUPER

На деяких клавіатурах незручно використовувати основну мета-клавішу (клавішу Windows/cmd) як SUPER. Ви можете змінити її на ALT за допомогою цієї зміни:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
