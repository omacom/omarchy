# Kiirklahvid

Kõik peamised klaviatuuri sidumised näed klahvidega `Super + K` (Tmuxi sidumised `Super + Alt + K` ja Herdr sidumised `Super + Ctrl + K`).

## Navigeerimine

| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy menüü (rakendused ja kõik muu)    |

| `Super + Home` | Taasta salvestatud akna laius |

## Universaalne lõikelaud

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Super + C`           | Kopeeri    |
| `Super + X`           | Lõika (mitte terminalis)    |
| `Super + V`           | Kleebi    |
| `Super + Ctrl + V`           | Lõikelaua haldur    |

Tavaliselt Linuxis pead terminalis kopeerimiseks ja kleepimiseks kasutama klahve `Ctrl + Shift + C/V` ja kõikjal mujal klahve `Ctrl + C/V`. Need Omarchy ühtsed lõikelaua kiirklahvid töötavad kõikjal.

## Jäädvustamine

| Kiirklahv              | Funktsioon                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Ekraanipilt                      |
| `Super + Ctrl + Alt + C`            | Ekraanipilt (sama võte klaviatuuridele, millel pole Print Screen klahvi) |
| `Super + Ctrl + C` | Jäädvustamise menüü |
| `Alt + Print Screen`            | Ekraanisalvestus                     |
| `Super + Print Screen` | Värvivalija |
| `Super + Ctrl + Print Screen` | Teksti eraldamine lõikelauale |
| `Super + Alt + [` | Tee veebikaamera ülekate salvestamise ajal väiksemaks |
| `Super + Alt + ]` | Tee veebikaamera ülekate salvestamise ajal suuremaks |
| `Alt + Shift + L` | Kopeeri praegune URL veebirakendusest või Chromiumist |
| `Alt + Shift + D` | Laadi praegusel lehel olev video alla kausta `~/Videos` |
| `Super + Ctrl + X` | Käivita/peata dikteerimine (nõuab jaotist _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | Push-to-talk dikteerimine (nõuab Voxtype'i või Superwhisperit) |

Ekraanisalvestuste puhul küsib kiirklahv esmalt, millist heli soovid, seejärel alustab salvestamist. Salvestamise peatamiseks vajuta seda uuesti. Üksikasjad leiad jaotisest [ekraanipildid ja salvestamine](12-screenshots-recording.md).

Kõik jäädvustamise valikud on saadaval ka Omarchy menüü jaotises _Trigger > Capture_ (`Super + Space`).

## Tmux

Prefiksiklahv on `Ctrl + Space` (`Ctrl + B` töötab samuti). Neid sidumisi saad muuta failis `~/.config/tmux/tmux.conf`.

### Paneelid

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Prefix + v` | Jaga paneel kõrvale (vertikaalne) |
| `Prefix + h` | Jaga paneel alla (horisontaalne) |
| `Prefix + x` | Sulge paneel |
| `Prefix + z` | Lülita paneeli suumi (täisekraan) |
| `Alt + Enter` | Jaga paneel alla (ilma prefiksita) |
| `Alt + Shift + Enter` | Jaga paneel kõrvale (ilma prefiksita) |
| `Alt + Escape` | Sulge paneel (ilma prefiksita) |
| `Ctrl + Alt + Arrows` | Liigu paneelide vahel |
| `Ctrl + Alt + Shift + Arrows` | Muuda paneelide suurust |

### Aknad

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Prefix + c` | Uus aken |
| `Prefix + k` | Sulge aken |
| `Prefix + r` | Nimeta aken ümber |
| `Alt + 1-9` | Mine kindlale aknale |
| `Alt + Arrow Left/Right` | Liigu akende vahel |
| `Alt + Shift + Arrow Left/Right` | Teisalda akent vasakule/paremale |

### Seansid

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Prefix + C` | Uus seanss |
| `Prefix + K` | Sulge seanss |
| `Prefix + R` | Nimeta seanss ümber |
| `Prefix + N` | Järgmine seanss |
| `Prefix + P` | Eelmine seanss |
| `Alt + Arrow Up/Down` | Liigu seansside vahel |
| `Prefix + s` | Loetle seansid |
| `Prefix + d` | Eemaldu seansist |

### Kopeerimisrežiim (vi-stiilis)

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Prefix + [` | Sisene kopeerimisrežiimi |
| `v` | Alusta valikut (kopeerimisrežiimis) |
| `y` | Kopeeri valik (kopeerimisrežiimis) |

### Üldine

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Prefix + q` | Laadi konfiguratsioon uuesti |
| `Prefix + ?` | Näita Tmuxi klahvisidumisi |
| `Prefix + :` | Käsuviip |

### Tmuxi paigutusfunktsioonid

Neid funktsioone tuleb käivitada Tmuxi seansi sees.

| Käsk | Funktsioon |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Loo arenduspaigutus redaktori, AI ja terminaliga |
| `tdlm <ai> [<second_ai>]` | Loo arenduspaigutus iga alamkataloogi kohta |
| `tsl <count> <command>` | Loo mitme paneeliga parvpaigutus |
