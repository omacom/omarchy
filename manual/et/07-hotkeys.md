# Kiirklahvid

Kõiki peamisi klaviatuuri sidumisi näed klahvidega `Super + K` (Tmuxi sidumisi klahvidega `Super + Alt + K` ja Herdr sidumisi klahvidega `Super + Ctrl + K`).

## Navigeerimine

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy menüü (rakendused ja kõik muu)    |
| `Super + Alt + Space` | Rakenduste ruudustik |
| `Super + Escape` | Süsteemimenüü (peatamine, taaskäivitamine jne)  |
| `Super + Ctrl + L` | Lukusta arvuti |
| `Super + W` või `Super + Q` | Sulge aken             |
| `Ctrl + Alt + Del` | Sulge kõik aknad |
| `Super + T`               | Lülita aken paanitud ja ujuva režiimi vahel             |
| `Super + J` | Lülita akna asendit (horisontaalne/vertikaalne) |
| `Super + O`               | Lülita aken kleepuvaks ujuvaks hüpikaknaks |
| `Super + L`               | Vaheta järjest dwindle, scrolling ja ujuva paigutuse vahel |
| `Super + Alt + L`         | Vaheta paigutusi vastupidises järjekorras |
| `Super + P`               | Lülita pseudoakna stiili (loomulik vs venitatud) |
| `Super + F`                 | Mine täisekraanile              |
| `Super + Alt + F`                 | Mine täislaiusele              |
| `Super + Ctrl + F`                 | Mine aknasiseselt täisekraanile              |
| `Super + 1/2/3/4`         | Hüppa fokuseeritud monitoril kindlale tööalale |
| `Super + Tab` | Hüppa fokuseeritud monitoril järgmisele tööalale |
| `Super + Shift + Tab` | Hüppa fokuseeritud monitoril eelmisele tööalale |
| `Super + Ctrl + Tab` | Hüppa fokuseeritud monitoril varasemale tööalale |
| `Super + Shift + 1/2/3/4` | Liiguta aken fokuseeritud monitori tööalale |
| `Super + Shift + Alt + 1/2/3/4` | Liiguta aken fokuseeritud monitori tööalale ilma järgnemata |
| `Super + S` | Lülita täielikku scratchpad'i |
| `Super + Alt + S` | Liiguta aken täielikku scratchpad'i |
| `Super + Grave` | Lülita Quake konsooli |
| `Super + Shift + Grave` | Liiguta aken Quake konsooli |
| `Super + Shift + Ctrl + Arrows` | Liiguta aken selles suunas olevale monitorile |
| `Super + Shift + Alt + Arrows` | Liiguta tööala selles suunas olevale monitorile |
| `Super + Arrow`  | Liiguta fookus noole suunas olevale aknale, liikudes ekraani serval sellel küljel olevale monitorile |
| `Super + Shift + Arrow`  | Vaheta aken noole suunas oleva teisega, sealhulgas sellel küljel oleval monitoril olevaga |
| `Super + Minus` | Laienda akent vasakule |
| `Super + Equal` | Kahanda akent vasakult |
| `Super + Shift + Minus` | Kahanda akent üles |
| `Super + Shift + Equal` | Laienda akent alla |
| `Super + Alt + Minus/Equal` | Sama suuruse muutmine väiksemate sammudega |
| `Super + Ctrl + Minus/Equal` | Sama suuruse muutmine suuremate sammudega |
| `Super + Alt + Home` | Salvesta akna laius |
| `Super + Home` | Taasta salvestatud akna laius |
| `Super + Left Mouse` | Lohista akent ringi |
| `Super + Right Mouse` | Muuda akna suurust |
| `Super + Scroll Wheel` | Keri fokuseeritud monitori tööalasid |
| `Super + G`               | Lülita akende rühmitamist      |
| `Super + Alt + G`               | Liiguta aken rühmitusest välja      |
| `Super + Alt + Tab`               | Vaheta rühmituses olevaid aknaid      |
| `Super + Alt + Shift + Tab`               | Vaheta rühmituses olevaid aknaid tagurpidi      |
| `Super + Alt + Scroll Wheel` | Vaheta rühmituses olevaid aknaid |
| `Super + Alt + 1/2/3/4/5`               | Hüppa rühmituses kindlale aknale      |
| `Super + Alt + Arrow`  | Liiguta aken noole suunas rühmitusse, sealhulgas sellel küljel oleval monitoril olevasse |
| `Super + Ctrl + Left/Right`  | Liigu paanitud rühma akende vahel |
| `Super + Ctrl + Z` | Suumi ekraanil sisse (suurema suumi jaoks korda) |
| `Super + Ctrl + Alt + Z` | Suumi ekraanilt täielikult välja |
| `Super + /` | Liigu monitori skaleerimisvalikutes edasi |
| `Super + Alt + /` | Liigu monitori skaleerimisvalikutes tagasi |
| `Alt + Tab` | Vaheta aktiivse tööala aknaid edaspidi |
| `Alt + Shift + Tab` | Vaheta aktiivse tööala aknaid tagurpidi |
| `Ctrl + Alt + Tab`| Vaheta fookust monitoride vahel edaspidi |
| `Ctrl + Alt + Shift + Tab`| Vaheta fookust monitoride vahel tagurpidi |

## Universaalne lõikelaud

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Super + C`           | Kopeeri    |
| `Super + X`           | Lõika (mitte terminalis)    |
| `Super + V`           | Kleebi    |
| `Super + Ctrl + V`           | Lõikelaua haldur    |

Tavaliselt vajad Linuxis terminalis kopeerimiseks ja kleepimiseks `Ctrl + Shift + C/V` ning mujal samaks `Ctrl + C/V`. Need Omarchy ühtsed lõikelaua kiirklahvid töötavad kõikjal.

## Jäädvustamine

| Kiirklahv              | Funktsioon                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Ekraanipilt                      |
| `Super + Ctrl + Alt + C`            | Ekraanipilt (sama võte klaviatuuridele, millel puudub Print Screen klahv) |
| `Super + Ctrl + C` | Jäädvustamise menüü |
| `Alt + Print Screen`            | Ekraanisalvestus                     |
| `Super + Print Screen` | Värvivalija |
| `Super + Ctrl + Print Screen` | Teksti eraldamine lõikelauale |
| `Super + Alt + [` | Tee veebikaamera ülekatet salvestamise ajal väiksemaks |
| `Super + Alt + ]` | Tee veebikaamera ülekatet salvestamise ajal suuremaks |
| `Alt + Shift + L` | Kopeeri praegune URL veebirakendusest või Chromiumist |
| `Alt + Shift + D` | Laadi praegusel lehel olev video alla kausta `~/Videos` |
| `Super + Ctrl + X` | Käivita/peatage dikteerimine (nõuab _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | Vajuta-ja-räägi dikteerimine (nõuab Voxtype'i või Superwhisperit) |

Ekraanisalvestuste puhul küsib kiirklahv esmalt, millist heli soovid, ja alustab seejärel salvestamist. Salvestamise lõpetamiseks vajuta seda uuesti. Üksikasju vaata jaotisest [ekraanipildid ja salvestamine](12-screenshots-recording.md).

Kõik jäädvustamisvalikud on saadaval ka Omarchy menüüs (`Super + Space`) jaotises _Trigger > Capture_.

## Stiil

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Super + Ctrl + T` | Vali uus teema (ka `Super + Ctrl + Shift + Space`) |
| `Super + Ctrl + W` | Vali teema taust (ka `Super + Ctrl + Space`) |
| `Super + Backspace` | Lülita akna läbipaistvust |
| `Super + Ctrl + Backspace` | Lülita ühe akna ruudukujulist kuvasuhet |

Lisa taustapildid asuvad kaustas `~/.config/omarchy/backgrounds/<theme name>`. Saadaval ka Omarchy menüüs valiku _Install > Style > Background_ kaudu.

Kõik stiilivalikud on saadaval ka Omarchy menüüs (`Super + Space`) jaotises _Style_.

## Tmux

Eesliiteklahv on `Ctrl + Space` (`Ctrl + B` töötab ka). Neid sidumisi saad muuta failis `~/.config/tmux/tmux.conf`.

### Paanid

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Prefix + v` | Jaga paan kõrvuti (vertikaalselt) |
| `Prefix + h` | Jaga paan alla (horisontaalselt) |
| `Prefix + x` | Sulge paan |
| `Prefix + z` | Lülita paani suumi (täisekraan) |
| `Alt + Enter` | Jaga paan alla (ilma eesliiteta) |
| `Alt + Shift + Enter` | Jaga paan kõrvuti (ilma eesliiteta) |
| `Alt + Escape` | Sulge paan (ilma eesliiteta) |
| `Ctrl + Alt + Arrows` | Liigu paanide vahel |
| `Ctrl + Alt + Shift + Arrows` | Muuda paanide suurust |

### Aknad

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Prefix + c` | Uus aken |
| `Prefix + k` | Sulge aken |
| `Prefix + r` | Nimeta aken ümber |
| `Alt + 1-9` | Mine kindlale aknale |
| `Alt + Arrow Left/Right` | Liigu akende vahel |
| `Alt + Shift + Arrow Left/Right` | Liiguta akent vasakule/paremale |

### Seansid

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Prefix + C` | Uus seanss |
| `Prefix + K` | Sulge seanss |
| `Prefix + R` | Nimeta seanss ümber |
| `Prefix + N` | Järgmine seanss |
| `Prefix + P` | Eelmine seanss |
| `Alt + Arrow Up/Down` | Liigu seansside vahel |
| `Prefix + s` | Loetle seansid |
| `Prefix + d` | Eemaldu seansist |

### Kopeerimisrežiim (vi-stiilis)

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Prefix + [` | Sisene kopeerimisrežiimi |
| `v` | Alusta valikut (kopeerimisrežiimis) |
| `y` | Kopeeri valik (kopeerimisrežiimis) |

### Üldine

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Prefix + q` | Laadi konfiguratsioon uuesti |
| `Prefix + ?` | Näita Tmuxi klahvisidumisi |
| `Prefix + :` | Käsuviip |

### Tmuxi paigutusfunktsioonid

Neid funktsioone tuleb käivitada Tmuxi seansi sees.

| Käsk | Funktsioon |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Loo arenduspaigutus redaktori, AI ja terminaliga |
| `tdlm <ai> [<second_ai>]` | Loo arenduspaigutus iga alamkataloogi kohta |
| `tsl <count> <command>` | Loo mitme paaniga sülempaigutus |
