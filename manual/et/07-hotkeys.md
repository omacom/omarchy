# Kiirklahvid

Saad näha kõiki peamisi klaviatuuriseoseid `Super + K` abil (Tmuxi seoseid `Super + Alt + K` abil ja Herdr seoseid `Super + Ctrl + K` abil).

## Navigeerimine

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy menüü (rakendused ja kõik muu)    |
| `Super + Alt + Space` | Rakenduste ruudustik |
| `Super + Escape` | Süsteemi menüü (uinak, taaskäivita jne)  |
| `Super + Ctrl + L` | Lukusta arvuti |
| `Super + W` or `Super + Q` | Sulge aken             |
| `Ctrl + Alt + Del` | Sulge kõik aknad |
| `Super + T`               | Lülita aken plaatide/ujuva vahel             |
| `Super + J` | Lülita akna asend (horisontaalne/vertikaalne) |
| `Super + O`               | Lülita akna hüppamine kleepuvasse ujuvasse |
| `Super + L`               | Käi läbi dwindle'i, kerimise ja ujuva paigutused |
| `Super + Alt + L`         | Käi paigutused läbi vastupidises järjekorras |
| `Super + P`               | Lülita pseudo-akna stiili (loomulik vs venitatud) |
| `Super + F`                 | Mine täisekraanile              |
| `Super + Alt + F`                 | Mine täislaiusesse              |
| `Super + Ctrl + F`                 | Mine täisekraanile akna sees              |
| `Super + 1/2/3/4`         | Hüppa kindla tööala juurde     |
| `Super + Tab` | Hüppa järgmise tööala juurde |
| `Super + Shift + Tab` | Hüppa eelmise tööala juurde |
| `Super + Ctrl + Tab` | Hüppa endise tööala juurde |
| `Super + Shift + 1/2/3/4` | Liiguta aken tööalale |
| `Super + Shift + Alt + 1/2/3/4` | Liiguta aken tööalale järgnemata |
| `Super + S` / `Super + Grave` | Lülita scratchpad |
| `Super + Alt + S` / `Super + Shift + Grave` | Liiguta aken scratchpadile |
| `Super + Shift + Alt + Arrows` | Liiguta tööalad suunaga määratud kuvarile |
| `Super + Arrow`  | Liiguta fookus noole suunas akna juurde              |
| `Super + Shift + Arrow`  | Vaheta aken noole suunas teisega     |
| `Super + Minus` | Laienda akent vasakule |
| `Super + Equal` | Kahanda akent vasakule |

| `Super + Home` | Taasta salvestatud akna laius |
| `Super + Left Mouse` | Lohista aken ringi |
| `Super + Right Mouse` | Muuda akna suurust |
| `Super + Scroll Wheel` | Keri läbi tööalade |
| `Super + G`               | Lülita akna rühmitamine      |
| `Super + Alt + G`               | Liiguta aken rühmitusest välja      |
| `Super + Alt + Tab`               | Ringel akende vahel rühmituses      |
| `Super + Alt + Shift + Tab`               | Ringel tagurpidi akende vahel rühmituses      |
| `Super + Alt + 1/2/3/4/5`               | Hüppa kindla akna juurde rühmituses      |
| `Super + Alt + Arrow`  | Liiguta aken rühmitusse noole suunas  |
| `Super + Ctrl + Left/Right`  | Liigu akende vahel plaatide rühmas |
| `Super + Ctrl + Z` | Suumi ekraanile sisse (korda rohkemaks suumiks) |
| `Super + Ctrl + Alt + Z` | Suumi ekraanilt täielikult välja |
| `Super + /` | Astu edasi läbi kuvari skaleerimisvalikute |
| `Super + Alt + /` | Astu tagasi läbi kuvari skaleerimisvalikute |
| `Alt + Tab` | Ringel edasi läbi aktiivse tööala akende |
| `Alt + Shift + Tab` | Ringel tagasi läbi aktiivse tööala akende |
| `Ctrl + Alt + Tab`| Ringel fookusega edasi läbi kuvarite |
| `Ctrl + Alt + Shift + Tab`| Ringel fookusega tagasi läbi kuvarite |

## Üldine lõikelaud

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Super + C`           | Kopeeri    |
| `Super + X`           | Lõika (mitte terminalis)    |
| `Super + V`           | Kleebi    |
| `Super + Ctrl + V`           | Lõikelaua haldur    |

Tavaliselt on Linuxil vaja `Ctrl + Shift + C/V`, et terminalis kopeerida ja kleepida, ja `Ctrl + C/V`, et teha seda kõikjal mujal. Need Omarchy ühtsed lõikelaua kiirklahvid toimivad kõikjal.

## Jäädvusta

| Kiirklahv              | Funktsioon                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Jäädvusta menüü (klaviatuuridele ilma PrintScr nuputa) |
| `Print Screen`            | Ekraanitõmmis                      |
| `Alt + Print Screen`            | Ekraanisalvestus                     |
| `Super + Print Screen` | Värvivalija |
| `Super + Ctrl + Print Screen` | Teksti eraldamine lõikelauale |
| `Super + Alt + [` | Tee veebikaamera pealiskiht salvestamise ajal väiksemaks |
| `Super + Alt + ]` | Tee veebikaamera pealiskiht salvestamise ajal suuremaks |
| `Alt + Shift + L` | Kopeeri praegune URL veebirakendusest või Chromiumist |
| `Alt + Shift + D` | Laadi praegusel lehel olev video alla kausta `~/Videos` |
| `Super + Ctrl + X` | Alusta/peatta dikteerimine (nõuab _Seaded > Vaikimisi > Dikteerimine_) |
| `Right Alt` / `F9` | Push-to-talk dikteerimine (nõuab Voxtype'i või Superwhisperi) |

Ekraanisalvestuste puhul küsib kiirklahv esmalt, millist heli soovid, ja alustab seejärel salvestamist. Vajuta seda uuesti, et peatada. Üksikasjade jaoks vt [ekraanitõmmised ja salvestamine](12-screenshots-recording.md).

Kõik jäädvustamisvalikud on ligipääsetavad ka Omarchy menüüs _Käivita > Jäädvusta_ all (`Super + Space`).

## Tmux

Eesliite klahv on `Ctrl + Space` (`Ctrl + B` töötab ka). Saad neid seoseid muuta failis `~/.config/tmux/tmux.conf`.

### Paanid

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Prefix + v` | Jaga paan kõrvale (vertikaalne) |
| `Prefix + h` | Jaga paan alla (horisontaalne) |
| `Prefix + x` | Tapa paan |
| `Prefix + z` | Lülita paani suum (täisekraan) |
| `Alt + Enter` | Jaga paan alla (ilma eesliiteta) |
| `Alt + Shift + Enter` | Jaga paan kõrvale (ilma eesliiteta) |
| `Alt + Escape` | Tapa paan (ilma eesliiteta) |
| `Ctrl + Alt + Arrows` | Liigu paanide vahel |
| `Ctrl + Alt + Shift + Arrows` | Muuda paanide suurust |

### Aknad

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Prefix + c` | Uus aken |
| `Prefix + k` | Tapa aken |
| `Prefix + r` | Nimeta aken ümber |
| `Alt + 1-9` | Mine kindla akna juurde |
| `Alt + Arrow Left/Right` | Liigu akende vahel |
| `Alt + Shift + Arrow Left/Right` | Liiguta aken vasakule/paremale |

### Seansid

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Prefix + C` | Uus seanss |
| `Prefix + K` | Tapa seanss |

| `Prefix + N` | Järgmine seanss |
| `Prefix + P` | Eelmine seanss |
| `Alt + Arrow Up/Down` | Liigu seansside vahel |
| `Prefix + s` | Loetle seansid |

### Kopeerimisrežiim (vi-stiilis)

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |
| `Prefix + [` | Sisene kopeerimisrežiimi |

### Üldine

| Kiirklahv                  | Funktsioon              |
| ----------------------- | --------------------- |

### Tmuxi paigutusfunktsioonid

Need funktsioonid tuleb käivitada Tmuxi seansi sees.

| Käsk | Funktsioon |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Loo arenduspaigutus koos redaktori, AI ja terminaliga |
| `tdlm <ai> [<second_ai>]` | Loo arenduspaigutus alamkataloogi kohta |
| `tsl <count> <command>` | Loo mitme paaniga parve paigutus |
