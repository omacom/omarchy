# Andere Pakete

Arch hat eine erstaunliche Fülle von Paketen für fast jede Art von Software, zwischen dem offiziellen Repository und dem Arch User Repository (AUR).

Einfacher könnte es auch nicht sein. Du installierst ein neues Arch-Paket, indem du im Omarchy-Menü (`Super + Space`) zu _Installieren > Package_ gehst und das gewünschte Paket eintippst. Es filtert die Liste aller Pakete automatisch unscharf. (Du kannst es auch manuell mit `omarchy pkg add [package]` im Terminal erledigen).

Dasselbe kannst du mit dem AUR tun, verwende einfach _Installieren > AUR_. Denke nur daran, dass das AUR nicht vom Arch-Team geprüft wird. Es ist wie RubyGems oder npm. Jeder kann hochladen.

Wenn du ein Paket entfernen möchtest, kannst du im Omarchy-Menü _Entfernen > Package_ verwenden. Das entfernt Paket, Konfigurationsdateien und Abhängigkeiten. (Du kannst es auch manuell mit `omarchy pkg drop [package]` erledigen).
