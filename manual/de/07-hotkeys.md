# Tastaturkürzel

Du siehst alle wichtigen Tastaturbelegungen mit `Super + K` (Tmux-Belegungen mit `Super + Alt + K` und Herdr-Belegungen mit `Super + Ctrl + K`).

| `Super + Home` | Gespeicherte Fensterbreite wiederherstellen |

| `Super + Right Mouse` | Fenstergröße ändern |
| `Super + Scroll Wheel` | Durch Arbeitsbereiche auf dem fokussierten Monitor scrollen |
| `Super + G`               | Fenstergruppierung umschalten      |
| `Super + Alt + G`               | Fenster aus der Gruppierung entfernen      |
| `Super + Alt + Tab`               | Zwischen Fenstern in der Gruppierung durchschalten      |

| `Super + Alt + Scroll Wheel` | Zwischen Fenstern in der Gruppierung durchschalten |

| `Super + Alt + Arrow`  | Fenster in Pfeilrichtung in eine Gruppierung verschieben, auch eines auf dem Monitor auf dieser Seite |
| `Super + Ctrl + Left/Right`  | Zwischen Fenstern innerhalb einer Tiling-Gruppe wechseln |
| `Super + Ctrl + Z` | In den Bildschirm hineinzoomen (wiederholen für mehr Zoom) |
| `Super + Ctrl + Alt + Z` | Vollständig aus dem Bildschirm herauszoomen |
| `Super + /` | Schrittweise vorwärts durch die Optionen für die Monitorskalierung |
| `Super + Alt + /` | Schrittweise rückwärts durch die Optionen für die Monitorskalierung |
| `Alt + Tab` | Vorwärts durch Fenster auf dem aktiven Arbeitsbereich schalten |
| `Alt + Shift + Tab` | Rückwärts durch Fenster auf dem aktiven Arbeitsbereich schalten |
| `Ctrl + Alt + Tab`| Fokus vorwärts durch Monitore schalten |
| `Ctrl + Alt + Shift + Tab`| Fokus rückwärts durch Monitore schalten |

Die Kürzel zum Ändern der Größe nutzen die physischen Tasten `code:20` und `code:21` (XKB `<AE11>` und `<AE12>`), unabhängig von den auf der Tastatur aufgedruckten Zeichen. Auf US-Tastaturen sind diese Tasten `-` und `=`; auf japanischen (JIS) Tastaturen sind es `-` und `^`; auf spanischen Tastaturen sind es `'` und `¡`. Auf JIS ist `Super + ^` gleich `Super + Equal`, während `Super + Shift + -` (was `=` tippt) gleich `Super + Shift + Minus` ist.

## Universelle Zwischenablage

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + A`           | In Apps, die `Ctrl + A` unterstützen, alles auswählen    |
| `Super + C`           | Kopieren    |
| `Super + X`           | Ausschneiden (nicht im Terminal)    |
| `Super + V`           | Einfügen    |
| `Super + Ctrl + V`           | Zwischenablage-Manager    |

Normalerweise brauchst du unter Linux `Ctrl + Shift + C/V`, um im Terminal zu kopieren'n'einfügen, und `Ctrl + C/V`, um es überall sonst zu tun. Diese vereinheitlichten Zwischenablage-Hotkeys von Omarchy funktionieren überall.
