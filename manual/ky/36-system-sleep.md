# Тутумдун уйку режими

Omarchy демейки боюнча уйку режимин, ал эми жөндөлгөндөн кийин терең уйкуну да күйгүзөт, бирок машинаңызда алардын кайсы бири менен болсо да көйгөй чыкса, аларды өчүрүп койсоңуз болот.

DGX Spark жана ASUS Ascent GX10 сыяктуу NVIDIA GB10 машиналарында уйку режими жана терең уйку NVIDIA'нын DGX OS тутумундагыдай эле өчүрүлгөн, анткени уйку режими ал жабдууда иштей тургандыгы азырынча далилденген эмес. ASUS Zenbook A16 (UX3607OA) үчүн да ошондой, анда уйку режими чипти азырынча толук уктата албайт жана түн ичинде катып калышы мүмкүн. Уйку режимин күйгүзүп-өчүрүү жана терең уйкуну жөндөө ал жерде колдонулбайт. Уйку режимин кайра күйгүзүү үчүн `/etc/systemd/sleep.conf.d/omarchy-sleep-disabled.conf` файлын `sudo rm` менен өчүрүңүз; ошондо Уйку режими менюга кайтып келет, ал эми терең уйкуну башка машиналардагыдай эле жөндөсө болот. `sudo omarchy apply hardware --install-user "$USER"` иштетсеңиз, файл кайра ордуна коюлат.

### Кубат режимдери

Ноутбукта Omarchy кубат режимиңизди тармакка туташып турганда жана батарея менен иштегенде өзүнчө эстеп калат жана сиз заряддагычты сайып-сууруганда экөөнүн ортосунда которулуп турат. Кутудан чыгары менен бул AC'де өндүрүмдүү, ал эми батареяда тең салмактуу режимди билдирет.

Машинаңыз эмнелерди сунуштаарын `omarchy powerprofiles list` менен көрүп, учурда турган абалыңыз үчүн каалаган режимди `omarchy powerprofiles set autodetect power-saver` менен коё аласыз. Эч нерсени суурубай туруп экинчи абалды коюу үчүн аны түз атаңыз: `omarchy powerprofiles set battery power-saver`. Эмнени тандасаңыз, кийинки жолу ошол абалга түшкөнүңүздө ошол кайтып келет.

### Уйку режимин күйгүзүү/өчүрүү

Уйку режимин терминалдан `omarchy toggle suspend` иштетүү менен күйгүзүп-өчүрөсүз. Бул жөн гана _Тутум_ (же `Super + Esc`) ичиндеги вариантты көрсөтөт/жашырат, андан кийин ал тутумуңузда туруктуу иштейби же жокпу, көрө аласыз. Эгер иштебесе, ошол эле буйрук менен аны кайра жашырып койсоңуз болот.

### Терең уйкуну күйгүзүү/өчүрүү

Терең уйкуну терминалдан `omarchy hibernation setup` иштетүү менен жөндөйсүз (ал Apple Silicon Mac'тарда жеткиликтүү эмес). Терең уйку жүктөө дискиңизде физикалык RAM көлөмүңүздөй чоңдуктагы /swap субтомун түзөт, ошондуктан бош орун жетиштүү экенине ынаныңыз. 32GB машинада бул том үчүн дайыма 32GB+ бош орун керек болот. Терең уйку ошондой эле демейки Limine жүктөгүчүн талап кылат.

Жөндөлгөндөн кийин _Тутум_ (же `Super + Esc`) ичинде терең уйку вариантын көрөсүз, андан кийин ал тутумуңузда туруктуу иштейби же жокпу, көрө аласыз. Эгер иштебесе, `omarchy hibernation remove` иштетип, аны кайра алып салсаңыз болот.
