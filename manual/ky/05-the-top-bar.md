# Жогорку панель

Экраныңыздын жогору жагындагы тилке — бул Omarchy панели. Ал кийин бурап коюлган абал панели эмес, Omarchy кабыгынын бир бөлүгү, башкача айтканда менюну, билдирмелерди, OSD калкып чыкма терезелерин жана кулпу экранын да тарткан, узак иштеген жалгыз Quickshell процесси. Ошондуктан ал калган нерселердин баары менен теманы кемчиликсиз бөлүшөт жана панель жаңы тиркеме ишке киргизбей, заматта ачылат.

Ошондой эле бул иш столунун экранда ар дайым турган жалгыз бөлүгү, ошондуктан тиги кичинекей белгилердин ар бири эмне кыларын билип алган жакшы.

## Демейки боюнча эмнелер бар

Панелде үч бөлүк бар. Сол жакта Omarchy логотиби (менюну ачуучу) жана иш мейкиндиктеринин көрсөткүчтөрү турат. Ортодо абал көрсөткүчтөрү, саат, Elsewhen (дүйнөлүк саат), аба ырайы жана Omarchy жаңыртуу белгиси бар. Оң жакта: тутум трейи, баскычтоп жайгашымы (бирден ашык жайгашым же киргизүү ыкмасы жөндөлгөндө), агенттер, bluetooth, тармак, үн, экран жана кубат.

Алардын айрымдары айта турган бир нерсеси болгондо гана көрүнөт. Баскычтоп жайгашымы бирден ашык жайгашым же киргизүү ыкмасын жөндөгөн учурда гана чыгат. Жаңыртуу белгиси Omarchy жаңыртуусу күтүп турганда гана чыгат.

## Баскылап көрүү

Дээрлик ар бир виджет сол, оң жана ортоңку баскыч менен басканда бир нерсе кылат, айрымдары жылдырууга да жооп берет. Адамдар көбүнчө ушул жерин байкабай калышат — жакшы нерселердин көбү оң жана ортоңку баскычтарда жашырылган.

## Панелдер

Панелдеги белгини басканда панель ачылат, ал жөн гана калкып чыкма кеңеш эмес, сыдырмалары, тизмелери жана баскычтоп менен башкаруусу бар чыныгы калкып чыкма терезе. Ар биринин баскыч айкалышы да бар, ошондуктан 16 пикселдик белгини мелжеп отуруунун эч кереги жок:

| Баскыч айкалышы | Панель |
| --- | --- |
| `Super + Ctrl + A` | Үн |
| `Super + Ctrl + N` | Тармак |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | Экран |
| `Super + Ctrl + P` | Кубат |
| `Super + Ctrl + Alt + D` | Жылнаама |
| `Super + Ctrl + Alt + E` | Дүйнөлүк саат |
| `Super + Ctrl + X` | Агенттер |
| `Super + Ctrl + 1-9` | Оң бөлүктөгү n-панелди ачуу/жабуу |

Панелдер жөн эле маалымат көрсөткүч эмес. Ишти чындап ошол жерден аткарасыз:

- **Үн** панелинде жалпы үн катуулугунун сыдырмасы, чыгаруу түзмөгүн тандагыч жана ар бир тиркеме үчүн аралаштыргыч бар, ошондуктан калганына тийбей туруп, тиги бир браузер өтмөгүнүн үнүн гана басаңдатсаңыз болот.
- **Тармак** Wi-Fi издейт, сигналдын күчүн көрсөтөт, туташат жана DNS кызматын тандоого мүмкүндүк берет.
- **Bluetooth** түзмөктөрүңүздү туташтыруу/ажыратуу жана батарея деңгээли менен тизмелейт.
- **Кубат** батарея статистикасын көрсөтөт, кубат режимдерин алмаштырат (батарея жана тармактан кубаттануу үчүн өзүнчө тандоону эстеп калат) жана тутум тууралуу айрым маалыматты чыгарат.
- **Экран** панелинде жарыктык сыдырмасы, текст өлчөмү, мониторду масштабдоо даярдамалары жана — бирден ашык экраныңыз болгондо — ар бир мониторду өзүнчө башкаруу бар. Кененирээк маалымат үчүн [мониторлорду](33-monitors.md) караңыз.
- **Саат** ISO апта номерлери жана айларды алмаштыруу мүмкүнчүлүгү бар айлык торду ачат.
- **Дүйнөлүк саат** ар бир шаар үчүн анын аба ырайы жана күнү кандай өтүп жатканы менен бир сапты кармап турат. Издөө убакыт алкактарын гана эмес, шаарчаларды да табат, ошондуктан Fort Lauderdale Нью-Йорк эмес, Fort Lauderdale болуп калат. Эгер жогору жактагы сап туура эмес шаарды атаса, аны басып, кайда экениңизди айтыңыз; башка убакыт алкагындагы жерди тандасаңыз, тутумдун сааты да ошого жылат, бул саякаттаганда ыңгайлуу. Шаардын үстүнө алып барып, ал жерде ким жашаарын айтуу үчүн адам баскычын басыңыз — жөнөкөй аттар, же алардын жүздөрүн да кошо алып келүү үчүн `@` GitHub аттары.

Ар бир панель чычкандан тышкары баскычтопту да кабыл алат: жебелер жылдырат, Return иштетет, Tab кошуна панелге өтөт, ал эми Escape жабат.

`Super + Ctrl + 1-9` оң бөлүктөгү панелдерди солдон оңго карай санайт, өзүнүн панели жок болгондуктан трейди өткөрүп жиберет. Ошентип номер сиз көрсөтө турган белгиге дал келет.

### Tailscale жана Dropbox

Дагы эки виджет тиешелүү кызматты **Орнотуу → Кызмат** бөлүмүнөн орнотконуңуздан кийин гана панелде пайда болот, жана экөө тең абалды билдирүүдөн тышкары көбүрөөк нерсе кылгандыктан, алар тууралуу билип алган жакшы.

**Tailscale** панели tailnet'ке туташат жана андан ажырайт, аккаунттардын ортосунда алмаштырат жана чыгуу түйүнүн тандайт (ал тизмеде өзүңүздүн машиналарыңыз да, Mullvad аймактары да чыгат). Ал машиналарыңызды да карап чыгат — бирөөсү тандалганда, `s` ага Taildrop аркылуу файлдарды жөнөтөт, бул файлды телефонуңузга же башка ноутбукка өткөрүүнүн эң тез жолу. `c` машинанын IP дарегин, `n` анын атын, `d` анын толук DNS атын көчүрөт. Баскычты басканды жактырсаңыз, ар бир машинанын сабында жөнөтүү баскычы да бар. Терминалдан ушул эле нерсе `omarchy tailscale send <machine> [file...]` болот.

**Dropbox** панели аккаунтка кирүүнү башкарат, сактагычтын канчасын колдонгонуңузду көрсөтөт жана жакында шайкештирилген файлдарды тизмелейт.

Кайсы бир кызматты алып салсаңыз, анын виджети да панелден кайра алынып салынат.

## Көрсөткүчтөр

Ортодогу кичинекей топ — бул көрсөткүчтөр виджети. Булар сиз күйгүзгөн режимдердин абал белгилери: билдирмелерди тынчытуу, түнкү жарык, кезекте турган [эстеткич](09-reminders.md), жүрүп жаткан экран жаздыруу жана уйкуга өтпөө, ошондой эле сырсөзсүз sudo күйүк турганда же кимдир бирөө алыскы сеанска туташканда эскертүүлөр. Алар режим күйүк болгондо жанат, антпесе тоскоол болбой туруп калышат — активдүү эместерин көрүү үчүн чычканды алардын дал жанына, алар туруучу жерге алып барыңыз. Көрсөткүчтү басканда ошол режим күйгүзүлөт же өчүрүлөт. Дагы бирөө абалды гана көрсөтөт: кимдир бирөө бул машинага gliff аркылуу туташып турганда, алыскы сеанс кызыл болуп жанат.

Эгер алардын ар дайым көрүнүп турганын кааласаңыз, виджетте `alwaysShow` маанисин `true` кылып коюңуз. Ал эми алардын айрымдары гана кызыктырса, керектүүлөрүн `items` ичинде тизмелеңиз: `["Dnd", "Reminder", "NightLight"]`. Бирден ашык көрсөткүчтөр виджетин кармасаңыз болот, ошентип ар кайсы бөлүктөр ар кайсы топтомдорду көрсөтө алат.

## Панелди кайра жайгаштыруу

Панель өзүн өзү жөндөйт. Нерселерди жылдыруу үчүн конфигурация файлын ачуунун кереги жок.

Панелдин ортосуна жакын бош жерин кармап, экрандын башка четин көздөй сүйрөсөңүз, панель ошол жакка көчөт — сол, оң, үст же ылдый, баары иштейт, жана ар бир виджет ыңгайлашат (тик панелдерде белгилер гана калган жыйнак түргө өтөт). Басып кармап туруу да ушундай эле сүйрөөнү баштайт. Ошол эле бош жерди сол баскыч менен эки жолу басып, панелдин фонун тунуктан айнектейге, андан тунук эмеске алмаштырасыз. Ал эми каалаган виджетти тартибин өзгөртүү үчүн сүйрөңүз же башка бөлүккө ыргытыңыз; калган виджеттер ал түшө турган жерде орун бошотуп, эки жакка жылышат.

Панелдин ортосу — бул куту: анын ичиндеги нерсенин баары бир топ катары ортодо турат, ал эми анын эки жагындагы виджеттер анын четтеринен илинип турат. Виджетти сүйрөп жатканда куту контур катары көрүнөт, же бош болсо панелди кесип өткөн сызык катары көрүнөт, жана аны ичине да, жанына да таштасаңыз болот. Виджет кутуга түшө турган болсо, куту аны батыруу үчүн чоңоёт.

Жаныңызда болушун каалаган, бирок ар дайым көз алдыңызда туруусу шарт эмес виджетти трейдин тартмасына салса болот: аны трейдин үстүнө сүйрөңүз, тартма аны кабыл алуу үчүн ачылат. Ал ошол жерде тиркеме белгилеринен кийин турат, тартма ачылган сайын көрүнөт жана панели ачык турганда тартмасын ачык кармап турат. Кайра ордуна коюу үчүн аны панелге сүйрөп чыгарыңыз.

Эгер менюдан тандаганды жактырсаңыз, **Көрүнүш → Меню панели** бөлүмүндө жайгашуусу бар, ал эми **Панелдин фону** панелдин кантип тартыларын тандайт: **Тунук эмес панель**, **Айнектей панель** (тунук, артындагысы бүдөмүктөлгөн) же **Тунук панель**.

Ушул эле нерселердин буйруктары да бар, бул [dotfiles](31-dotfiles.md) жөндөөсү үчүн дал керектүү нерсе:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

Виджетти толугу менен кошуу же алып салуу үчүн плагин буйруктарын колдонуңуз. `omarchy plugin list` кабыкка белгилүү болгон ар бир виджетти анын id'си менен чыгарат, андан кийин:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## Панелди жашыруу

`Super + Shift + Space` кабыкты өлтүрбөй туруп, панелди өчүрүп, кайра күйгүзөт — панелдер жана баскыч айкалыштары иштей берет, сиз болгону пикселдерди кайтарып аласыз. Бул менюда **Көрүнүш → Меню панели → Панелди жашыруу** астында да бар.

## Конфигурация файлы

Мунун баары `~/.config/omarchy/shell.json` ичинде, `bar` ачкычынын астында сакталат. Мына кыскартылган нускасы:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

Ар бир виджет беш жайгашуу массивинин биринде бир жазуу болуп саналат, жана анын жөндөөлөрү ошол жазуунун өзүндө турат — өзүнчө жөндөөлөр файлы да, `config` деген ички объект да жок. Сааттын `format`, `formatAlt` (оң баскыч алмаштыра турган формат) жана `verticalFormat` маанилеринин баары дал ошол `{ "id": "omarchy.clock" }` ичинде жашайт.

`center` — панелдин ортосундагы куту: анын ичиндегинин баары экрандын ортосунда бир топ катары турат. `centerBegin` жана `centerEnd` кутунун эки жагынан илинип турат, ошондуктан аба ырайы жана жаңыртуу белгиси пайда болуп, жоголуп турса да, саат так ортодо калат. `center` ичине бирден ашык виджет койсоңуз, алар чогуу ортого коюлат; аны бош калтырсаңыз, `centerBegin` жана `centerEnd` панелдин ортосунда жолугушат.

Жакшылап өздөштүрүп алууга арзыган бир эреже: **өзүңүздүн `shell.json` файлыңыз пайда болгондон кийин, ал негизги булак болуп калат**. Бир нерсени ыңгайлаштырмайынча, кабык Omarchy'нин демейки файлын окуйт. Виджетти сүйрөгөн, `omarchy bar` иштеткен же файлды өзүңүз түзөткөн замат, ал сиздики болуп калат — терең бириктирүү жок, ошондуктан Omarchy'нин келечектеги чыгарылыштарындагы жаңы демейки виджеттер панелиңизде өзүнөн өзү пайда болбойт. Таза баракчадан баштагыңыз келгенде, `omarchy bar defaults` демейки жайгашууну кайра ордуна коёт.

Ушул эле файл жогорку деңгээлде, `bar` ачкычынан сырткары, күтүү убакыттарыңызды да сактайт: `idle.screensaver` жана `idle.lock`, экөө тең колдонбой калгандан бери өткөн секунда менен. Ошентип демейки экран сактагыч 150 секундда, ал эми кулпу 300 секундда иштейт.
