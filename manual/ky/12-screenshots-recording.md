# Экран сүрөтү жана жаздыруу

Экрандан эмнени гана тартып алгыңыз келсе, баары Print Screen баскычына байланган. Бул баскыч өзү эле сүрөткө тартат, ал эми модификаторлор менен экранды жаздырат, түстү же аймактагы текстти алат. Эгер баскычтопуңузда Print Screen баскычы такыр жок болсо, `Super + Ctrl + Alt + C` ошол эле экран сүрөтүн тартат, ал эми `Super + Ctrl + C` бардык мүмкүнчүлүктөрдү меню катары ачат.

| Баскыч айкалышы | Аракет |
| ------ | -------- |
| `Print Screen` | Экран сүрөтү |
| `Super + Ctrl + Alt + C` | Экран сүрөтү |
| `Alt + Print Screen` | Экран жаздыруу (же жүрүп жаткан жаздырууну токтотуу) |
| `Super + Print Screen` | Түс тандагыч |
| `Super + Ctrl + Print Screen` | Аймактан текстти алуу |
| `Super + Ctrl + C` | Экран тартуу менюсу |
| `Super + Ctrl + .` | Сүрөттү же видеону башка форматка айландыруу |

## Экран сүрөттөрү

`Print Screen` (же `Super + Ctrl + Alt + C`) баскычын бассаңыз, Omasnap өз катмары чыкканга чейин эле фокустагы мониторду тартып алат, ошондуктан сиз мээлеп жатканда эч нерсе ордунан жылбайт. Каалаган формадагы аймакты сүйрөп белгилеңиз, терезени тартуу үчүн аны чыкылдатыңыз же бүт мониторду тартуу үчүн бош жерди чыкылдатыңыз. Жылдырылуучу аймакты тартуу үчүн белгилөөдөн мурун `S` басыңыз. Оюңуздан кайттыңызбы? Omasnap жабуу үчүн ошол эле баскычты дагы бир жолу басыңыз.

Аймакты тандагандан кийин Omasnap сүрөттү сактап, аны алмашуу буферине көчүрөт жана сакталган экран жаздыруудагыдай эле анын миниатюрасы менен билдирме көрсөтөт. Сакталган сүрөттү сүрөт көрүүчүдө көрүү үчүн Ачуу, ага белгилерди кошуу үчүн Түзөтүү тандаңыз.

Белгилөө редактору жебелерди, сызыктарды, фигураларды, бөлүп көрсөтүүлөрдү, номерленген белгилерди, текстти жана ишенимдүү жашырууларды тарта алат; сүрөттү кыркып же анын бир бөлүгүн кесип таштай алат; андагы текстти OCR менен тааный алат; жана фон кошо алат. Редактордо даяр PNG файлын көчүрүп, сактоо үчүн `Enter`, сактабай көчүрүү үчүн `Ctrl + C`, же көчүрбөй сактоо үчүн `Ctrl + S` басыңыз.

Сакталган экран сүрөттөрү демейки боюнча `~/Pictures/Screenshots` папкасына `screenshot-2026-08-13_14-22-05-firefox.png` сыяктуу аталыш менен түшөт. Башка папканы колдонуу үчүн `OMASNAP_SCREENSHOT_DIR` маанисин коюңуз — сеанстын чөйрө өзгөрмөлөрүн кайда жазуу керектигин [FAQ](46-faq.md) бөлүмүнөн караңыз. Omasnap биринчи сүрөттү сактаганда папканы өзү түзөт. Автоматтык сактоону өчүрүү үчүн `~/.config/omasnap/omasnap.conf` файлында `[output] autosave = false` коюңуз; ошондо сүрөттөр алмашуу буферине гана көчүрүлүп, 7 секунд алдын ала көрүү терезесинде көрсөтүлөт, аны кадоо баскычы же `Ctrl + P` менен экранда калтырсаңыз болот.

Терминалдан `omarchy screenshot` ошол эле катмарды ачат, ал эми анын баштапкы режимин тандай аласыз: `omarchy capture screenshot region`, `windows`, `fullscreen` же `scroll`. Экинчи аргумент катары `copy` же `save` берсеңиз, сүрөт түз ошол жерге жөнөтүлөт. Чыгаруудан мурун түзөтүү үчүн толук экрандагы редактор керек болсо `omarchy screenshot --editor=overlay`, өзүнчө терезе керек болсо `omarchy screenshot --editor=window` колдонуңуз.

### Тандагычты баскычтоп менен башкаруу

Тандоо экранда турганда чычканды такыр колдонбосоңуз да болот:

| Баскыч | Аракет |
| --- | -------- |
| `S` | Жылдырылуучу аймак режимин күйгүзүү/өчүрүү |
| `Super + жебе баскычтары` | Терезе режиминде терезелердин арасында жылуу |
| `Return` | Белгиленген терезени тартуу |
| `Ctrl + A` | Фокустагы мониторду толугу менен тартуу |
| `R` | Ушул сеанста акыркы жолу белгиленген аймакты кайтаруу |
| `Esc` | Omasnap жабуу |

Бул баскыч айкалыштары Omasnap ачык турганда гана иштейт, ошондуктан өзүңүздүн конфигурацияңыздагы эч нерсе менен кагылышпайт.

## Экранды жаздыруу

`Alt + Print Screen` _Аракеттер > Экран тартуу > Экран жаздыруу_ менюсун ачат, ал үн жолунда эмне болушу керектигин сурайт: үнсүз, иш тактасынын үнү, иш тактасы плюс микрофон, же иш тактасы плюс микрофон плюс веб-камера. Акыркысы камераңыз чындап туташып турганда гана чыгат. Бирөөнү тандасаңыз, Omarchy жаздыруу тандагычы аймакты сүйрөп белгилөөгө же терезени, мониторду чыкылдатып тандоого мүмкүндүк берет.

Жаздыруу gpu-screen-recorder аркылуу иштейт, ал GPU аркылуу 60fps менен коддойт, керек болсо CPU колдонууга өтөт; ал колдобогон GPU түрлөрүндө, мисалы Apple Silicon чиптеринде, Omarchy анын ордуна wf-recorder менен жаздырат. Натыйжада `~/Videos` папкасында `screenrecording-2026-08-13_14-22-05.mp4` деп аталган MP4 файлы пайда болот. Муну өзгөртүү үчүн `OMARCHY_SCREENRECORD_DIR` маанисин коюңуз — бирок экран сүрөттөрүнүн папкасынан айырмаланып, бул папка алдын ала бар болушу керек, антпесе жаздыруу башталбайт.

Жаздырып жатканда панелде кичинекей көрсөткүч пайда болот. Токтотуу үчүн аны чыкылдатыңыз. Ошондой эле кайра `Alt + Print Screen` менен же _Аракеттер > Экран тартуу > Экран жаздыруу_ ичиндеги _Экран жаздырууну токтотуу_ пункту менен токтото аласыз, ал пункт бир нерсе чындап жаздырылып жатканда гана көрүнөт.

Токтоткондо файлды сизге берүүдөн мурун аны бир аз иретке келтирет: биринчи кадр кесилет, ал эми үн болсо, ал -14 LUFS деңгээлине нормалдаштырылып, эң башындагы PipeWire жаздыруусунун чыкылдаган үнү өчүрүлөт. Андан кийин жаздыруунун миниатюрасы менен билдирме чыгат. Файлды Omaview тиркемесинде ойнотуу үчүн _Ачуу_, Omacut тиркемесинде кесүү үчүн _Кесүү_ тандаңыз.

### Веб-камера терезеси

Веб-камера менен жаздырганда камера сиз жаздырып жаткан нерсенин төмөнкү оң бурчунда кадалган, кесилген тик терезе катары чыгат. Эгер ал сизге керектүү бир нерсенин үстүндө турса, анын өлчөмүн ошол замат өзгөртүңүз:

| Баскыч айкалышы | Аракет |
| ------ | -------- |
| `Super + Alt + [` | Веб-камера терезесин кичирейтүү |
| `Super + Alt + ]` | Веб-камера терезесин чоңойтуу |

Үч өлчөм бар — кичине, орто жана чоң — жана баскыч айкалыштары алардын арасында бир кадамдан которот. Демейки өлчөм — орто. Алар жаздырууга пропорциялуу, ошондуктан 1080p мониторду жаздырасызбы же 6K мониторду жаздырасызбы, камера кадрдын бирдей үлүшүн ээлейт. Ал эми бүт дисплейди эмес, бир аймакты жаздырсаңыз, терезе мониторго эмес, ошол аймактын бурчуна бекийт, ошондуктан ал кадрдын ичинде калат.

Аны `omarchy-capture-webcam-resize small` менен түз чакырсаңыз да болот, ал эми ортого кайтуу үчүн `reset` колдонуңуз.

## Текст, QR коддор жана түстөр

`Super + Ctrl + Print Screen` аймакты тандап, андагы текстти OCR менен таанып, алмашуу буферине салат. Бул [Текстти алуу жана айтып жаздыруу](11-text-extraction-dictation.md) бөлүмүндө кеңири жазылган.

_Аракеттер > Экран тартуу > QR код_ QR коддор үчүн ушундай эле амалды аткарат. Код турган аймакты тандасаңыз, чечмеленген маани алмашуу буферине түшөт. Ал QR коддорду гана издейт — антпесе экрандагы тыгыз мазмун штрих-код катары жаңылыш таанылып калышы көп кездешет. Билип коюңуз: чечмеленген маани алмашуу буферине гана түшөт, башка эч жакка эмес. Ал басып чыгарылбайт, билдирмеде да жок, жана [алмашуу буферинин тарыхында](08-unified-clipboard-history.md) сакталып калбашы үчүн купуя деп белгиленет. QR коддор көбүнчө сырларды камтыйт — мисалы, 2FA жөндөө кодунун артындагы `otpauth://` URI — жана муну журналда калтыргыңыз келбейт. Чаптоо баары бир кадимкидей иштейт.

`Super + Print Screen` (же _Аракеттер > Экран тартуу > Түс_) курсорду пипеткага айлантат. Экрандагы каалаган нерсени чыкылдатсаңыз, түс алмашуу буферине түшөт. Эч нерсе тандабай чыгуу үчүн баскыч айкалышын дагы бир жолу басыңыз.

## Бөлүшүүдөн мурун форматка айландыруу

4K экран жаздыруусу же телефонуңуздан алынган чийки HEIC файлы жөн эле жөнөтүү үчүн көп учурда өтө чоң болот. `Super + Ctrl + .` (же _Аракеттер > Форматка айландыруу_) муну чечет. Ал `~/Pictures` жана `~/Videos` папкалары боюнча так эмес издөөчү файл тандагычты сунуштап, анан формат менен өлчөмдү сурайт.

Сүрөттөр jpg же png форматына high, medium же low сапатта айландырылат, алар туурасын тиешелүүлүгүнө жараша 3160, 2160 жана 1080 пиксель менен чектейт. Видеолор mp4 же анимацияланган gif форматына 4k, 1080p же 720p өлчөмүндө айландырылат. Айландырылган файл түп нускасынын жанына аталышында чечилиши менен жазылат — `demo-1080p.mp4` — ал эми жолу алмашуу буферине файл URI катары көчүрүлөт, ошондуктан аны файл сүйрөп таштоону кабыл алган тиркемеге түз чаптай аласыз.

Эмне керек экенин мурунтан билсеңиз, бул терминалдан да иштейт: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. Ошондой эле сүрөттү ASCII артка айландырган `omarchy transcode ascii` да бар — ал негизинен [өзгөчө белгилер](41-branding.md) үчүн.

## Аны бир жакка жөнөтүү

Файл колуңузга тийгенден кийин `Super + Ctrl + S` Бөлүшүү менюсун ачат жана аны LocalSend аркылуу тармагыңыздагы башка түзмөккө жөнөтөт. Бул тууралуу [Графикалык тиркемелер](22-guis.md) бөлүмүн караңыз.
