# Mac колдоосу

## Apple Silicon үчүн Omarchy

Apple Silicon үчүн Omarchy — Omacom компаниясынын расмий чечими, ал алгач Omarchy 4.5 менен чыккан. Ал macOS тутумунун жанына орнотулат, ал эми Mac күйгөн сайын экөөнүн бирин тандайсыз.

Omarchy Mac тууралуу эскертме алдыңызбы? [Omarchy Mac колдонуп жүргөндөр үчүн](#coming-from-omarchy-mac) бөлүмүнө өтүңүз.

Ал төмөнкү Mac компьютерлеринде иштейт:

| Mac | Чиптер |
| --- | --- |
| MacBook Air | M1, M2, M3 |
| MacBook Pro | M1, M1 Pro, M1 Max, M2, M2 Pro, M2 Max, M3, M3 Pro, M3 Max |
| MacBook Neo | A18 Pro |
| Mac mini | M1, M2, M2 Pro |
| Mac Studio | M1 Max, M1 Ultra, M2 Max, M2 Ultra |
| iMac | M1, M3 |
| Mac Pro | M2 Ultra |

M4 жана андан жаңы Mac компьютерлери азырынча колдоого алынбайт. M4 колдоосу edge каналында сыналып жатат, кезекте ошол турат. Орноткуч эч нерсени өзгөртүүдөн мурун Mac компьютериңизди текшерип чыгат.

Apple Silicon чиптүү каалаган Mac компьютеринде, анын ичинде M4 жана андан жаңыларында, Omarchy тутумун виртуалдык машинада [Try Omarchy](https://github.com/omacom/try-omarchy) аркылуу иштете аласыз.

### Эмне керек

- macOS 15 Sequoia же андан кийинки версия, жана администратордун аккаунту
- Omarchy үчүн дискте бош орун. Орноткуч өлчөмүн сунуштайт жана аны өзгөртүүгө мүмкүндүк берет.
- Mac компьютериңиздин камдык көчүрмөсү, электр булагы жана интернет байланышы. Орнотуу учурунда бир нече гигабайт жүктөлөт.

### Орнотуу

Орнотуу macOS ичинен жүргүзүлөт. Omarchy Installer программасын [Homebrew](https://brew.sh) менен орнотуңуз:

```sh
brew install omacom/mac/omarchy
```

Же Omarchy Installer программасынын эң жаңы версиясын анын [релиздер барагынан](https://github.com/omacom/omarchy-mac-installer/releases) жүктөп алып, ачыңыз.

Орноткуч Mac компьютериңизди текшерет, планды көрсөтөт жана macOS бөлүмүн кичирейтип, Omarchy үчүн орун бошотот. macOS дискте калат, USB түзмөгүнүн кереги жок. Биринчи этап бүткөндөн кийин ал сизге жөндөөнү macOS Recovery режиминде аягына чыгарууну кадам-кадамы менен көрсөтөт: компьютерди өчүрүңүз, "Loading startup options" жазуусу чыкканча кубат баскычын басып кармап туруңуз, Omarchy тандап, кадамдарды аткарыңыз.

Биринчи жолу жүктөлгөндө Omarchy өз дискин шифрлей турган сырсөздү сурайт. Калыбына келтирүү ачкычы жок: сырсөздү унутуп калсаңыз, Omarchy файлдарыңызды калыбына келтирүү мүмкүн эмес.

Кийин Omarchy менен macOS ортосунда которулуу үчүн компьютерди өчүрүп, жүктөө параметрлери чыкканча кубат баскычын басып кармап туруңуз да, бирин тандаңыз.

### Omarchy Mac колдонуп жүргөндөр үчүн

Omarchy Mac эми Apple Silicon үчүн Omarchy долбоорунун бир бөлүгү, жана аны иштеткен ар бир Mac колдоого алынат. Учурдагы орнотууңуз иштей берет, анын тутумдук пакеттери да жаңыланып турат, бирок мындан ары Omarchy жаңыртууларын албайт. Эч кандай мөөнөт жок, ордунда жаңыртуу мүмкүнчүлүгү да жок: камдык көчүрмө аласыз, эски орнотууну алып саласыз, таза орнотуп, анан файлдарыңызды калыбына келтиресиз. 2-кадамдан 5-кадамга чейин баары macOS ичинде аткарылат, ошондуктан кайра жүктөөдөн мурун бул баракты телефонуңуздан ачып алыңыз.

1. **Omarchy ичинен камдык көчүрмө алып, аны Mac компьютеринен тышкары сактаңыз.** Эски орнотууну алып салганда ал өчүп кетет, ал эми macOS Omarchy дискин окуй албайт. Үй папкаңызды тышкы дискке же башка компьютерге көчүрүңүз, анын ичинде SSH жана GPG ачкычтарын, браузер профилдерин жана push кылына элек иштериңизди. Пакеттериңиздин тизмесин `pacman -Qqe > ~/packages.txt` менен сактап алыңыз. macOS тутумунун да камдык көчүрмөсүн алыңыз, анткени алып салуу да, орнотуу да анын дискинин өлчөмүн өзгөртөт.
2. **Mac компьютериңизди macOS менен иштетиңиз.** Компьютерди өчүрүп, жүктөө параметрлери чыкканча кубат баскычын басып кармап туруңуз да, macOS тандаңыз.
3. **Omarchy Installer программасын орнотуңуз**, [Орнотуу](#installing) бөлүмүндө көрсөтүлгөндөй.
4. **Эски орнотууну алып салыңыз.** Omarchy Installer программасын ачып, Installation > Remove Omarchy тандаңыз. Ал эмнени өчүрө турганын көрсөтөт жана бошогон орунду macOS тутумуна кайтарат. Эгер орнотууңузду тааныбаса, дискке тийбестен токтойт. Бөлүмдөрдү кол менен өчүрбөй, [Discord](https://discord.gg/tXFUdasqhY) аркылуу жардам сураңыз, антпесе macOS да өчүп кетиши мүмкүн.
5. **Apple Silicon үчүн Omarchy тутумун** орноткуч менен орнотуңуз.
6. **Файлдарыңызды калыбына келтириңиз.** Бүт `~/.config` папкасын жаңы демейки жөндөөлөрдүн үстүнө көчүрбөй, жөндөөлөрүңүздү бирден-бирден кайтарыңыз, анткени эски жөндөөлөр аларды басып калышы мүмкүн.

### Билип коюңуз

- M1 жана M2 MacBook компьютерлерин уйку режиминен капкагын ачып же кубат баскычын басып ойготосуз.
- Суроолор же көйгөйлөр болсо, биздин [Discord](https://discord.gg/tXFUdasqhY) серверинен сураңыз.

[Орноткучтун README файлында](https://github.com/omacom/omarchy-mac-installer#readme) релиз каналдары, орноткучту жаңыртуу жана Omarchy тутумун алып салуу жазылган.

## Intel Mac компьютерлери

Жөнөкөй сыноодо 2019-жылкы MacBook Pro компьютерине жөн гана Omarchy орнотуп эле, иштөө ылдамдыгын 36% жогорулата алдык.

 ![macbook-omarchy](images/macbook-omarchy.webp)

### Mac компьютерине Omarchy орнотуу

Азырынча Omarchy орнотулган **жалгыз** OS болгондо гана колдоого алынат. Орнотуу учурунда диск толугу менен тазаланат жана MacOS мындан ары жүктөлбөй калат.

Кааласаңыз, аны кийин Internet Recovery аркылуу калыбына келтире аласыз.

Бул бөлүмдө сиз [Баштоо](02-getting-started.md) бөлүмүн окуп чыгып, USB түзмөгүңүздү даярдап койдуңуз деп эсептейбиз. Эгер даярдай элек болсоңуз, азыр эле даярдап алыңыз.

#### Secure Boot функциясын өчүрүү

Жүктөлүүчү USB түзмөгүнөн, ошондой эле OS өзүнөн жүктөлүү үчүн Apple компаниясынын Secure Boot функциясын өчүрүү зарыл. Аны өчүрүү үчүн төмөнкүлөрдү аткарыңыз:

1. Mac компьютериңизди өчүрүңүз
2. Аны күйгүзүп, жүктөлүү экраны чыкканча _дароо_ Command-R баскычтарын басып кармап туруңуз
3. Колдонуучуңузду тандап, суралса, сырсөзүңүздү киргизиңиз
4. Калыбына келтирүү экранына киргенден кийин меню тилкесинен **Utilities > Startup Security Utility** тандаңыз
5. Аутентификация үчүн суралганда сырсөзүңүздү киргизиңиз
6. Secure Boot параметрлеринен "No Security" тандаңыз
7. External Boot параметрлеринен "Allow booting from external or removable media" тандаңыз

#### Орнотууну баштоо

1. USB түзмөгүн сайыңыз
2. Mac компьютериңизди кайра жүктөп, жүктөө түзмөктөрүнүн экраны чыкканча _дароо_ Option баскычын басып кармап туруңуз
3. Кызгылт сары түстөгү EFI Boot түзмөгүн тандаңыз
4. [Кадимкидей орнотууну](02-getting-started.md) улантыңыз

Орноткуч Mac жабдууларын таанып, керектүү оңдоолорду автоматтык түрдө колдонот: Broadcom Wi-Fi драйверлери жана микропрограммасы, Broadcom 1570 орнотулган машиналарда FaceTime HD камерасынын драйвери (орноткуч интернетсиз иштегендиктен, анын микропрограммасы Mac интернетке туташкандан кийин Apple сайтынан жүктөлөт), ага муктаж MacBook моделдеринде SPI баскычтоп драйвери жана ошол эле моделдер үчүн NVMe уйку режиминин оңдоосу.

### Белгилүү чектөөлөр

Коомчулуктун мүчөлөрү бул көйгөйлөрдүн чечимдери үстүндө тынымсыз иштеп жатышат, ошондуктан алар сизге тоскоол болсо, биздин [Discord](https://discord.gg/tXFUdasqhY) серверибиздеги #omarchy-on-other каналына кошулуп, аларды чечүүнүн жаңы ыкмалары бар-жогун билип алыңыз.

#### FaceTime HD камерасы

Mac гибернацияга өткөндө камеранын драйвери жүктөлүп турса, машина катып калат, ошондуктан драйвер алдын ала түшүрүлөт. Кайсы бир тиркеме камераны ачып турганда аны түшүрүүгө болбойт, ошондуктан гибернация жокко чыгарылып, ошол тиркеменин атын атаган билдирме чыгат: тиркемени жаап, кайра гибернацияга өткөрүңүз. Бул батарея өтө азайганда автоматтык түрдө гибернацияга өтүүгө да, suspend-then-hibernate режимине да тиешелүү — ал уйку режимине өтүүдөн мурун эле четке кагылат. Кадимки уйку режимин болсо камера ачык турганда драйвердин өзү билдирмесиз эле четке кагат.

Камеранын микропрограммасы Apple сайтынан жүктөлөт, ошондуктан камера Mac интернетке бир жолу туташкандан кийин гана иштейт. Жүктөө тутум жүктөлгөндө башталат жана көйгөй тармакта болсо, ар 15 мүнөт сайын кайталанат; эгер Apple файлы өзгөрүп кетсе, жүктөө токтоп, Omarchy жаңыртуусун күтөт. Камера көрүнбөсө, `journalctl -u facetimehd-firmware-fetcher` себебин айтып берет, `sudo systemctl restart facetimehd-firmware-fetcher` кайра аракет кылат, ал эми жүктөө бүтүп, бирок камера дагы эле жок болсо, кайра жүктөгөндө драйвер жүктөлөт.

#### T2 чиби бар түзмөктөр

Apple T2 Security Chip 2017-жылы чыккан. 2020-жылы Apple silicon (M сериясындагы чиптер) башталганда T2 чибин чыгаруу токтотулган.

- iMac Pro (2017) – Модель: A1862
- MacBook Pro 13 дюйм (2018, төрт Thunderbolt 3 порту) – Модель: A1989
- MacBook Pro 15 дюйм (2018) – Модель: A1990
- MacBook Air (Retina, 13 дюйм, 2018) – Модель: A1932
- Mac mini (2018) – Модель: A1998
- MacBook Pro 13 дюйм (2019, эки Thunderbolt 3 порту) – Модель: A2159
- MacBook Pro 13 дюйм (2019, төрт Thunderbolt 3 порту) – Модель: A2178
- MacBook Pro 15 дюйм (2019) – Модель: A1990
- iMac (Retina 5K, 27 дюйм, 2020) – Модель: A2115 (iMac20,1 жана iMac20,2)
- MacBook Pro 13 дюйм (2020, эки Thunderbolt 3 порту) – Модель: A2265
- MacBook Pro 15 дюйм (2020) – Модель: A1990

Бул моделдерде орноткуч патч салынган `linux-t2` ядросун, T2 аудио конфигурациясын, Apple чыгарган Broadcom Wi-Fi/Bluetooth микропрограммасын жана `t2fanrd` аркылуу желдеткичти башкарууну автоматтык түрдө орнотот. Touch Bar ядронун Boot Camp сыяктуу кыналган колдоосу менен иштейт.
