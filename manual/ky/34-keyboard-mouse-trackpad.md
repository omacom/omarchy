# Баскычтоп, чычкан, сенсордук такта

Hyprland бардык киргизүү түзмөктөрүн абдан кылдат жөндөөгө мүмкүндүк берет. Баскычтын кайталанышын үндөн да ылдам кылып же сенсордук тактага табигый жылдырууну коё аласыз. Мунун баарын `~/.config/hypr/input.lua` файлында өзгөртөсүз, ага Omarchy менюсундагы (`Super + Space`) _Жөндөө > Киргизүү_ аркылуу да жетсеңиз болот. Ал жерде койгон нерселериңиз Omarchy'нин демейки маанилерин алмаштырат.

Мына бир мисал:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Hyprland вики барагынан [киргизүүнүн бардык параметрлерин көрө аласыз](https://wiki.hypr.land/Configuring/Basics/Variables/#input).

CapsLock кадимки Caps Lock катары иштейт, ал эми `Shift + CapsLock` [ыкчам эмодзилер](07-hotkeys.md#quick-emojis) жана [башка толуктоолор](07-hotkeys.md#quick-completions) үчүн compose баскычы болуп саналат. Compose баскычын башка жерге койгуңуз келсе, `kb_options` ичиндеги `omarchy:shift_caps_compose` маанисин алмаштырыңыз. Мисалы, бул compose баскычын оң Alt'ка көчүрөт:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Функциялык баскычтар

Ноутбук баскычтобунун жогорку катары демейки боюнча медиа баскычтарын (үн, жарык жана башкалар) жөнөтөт, ал эми `Fn` кармап турсаңыз F1-F12 чыгат; `Fn + Esc` аны тескерисинче кулпулайт, кайра басмайынча ошондой калат. Көпчүлүк баскычтоптор бул кулпуну өздөрү эстеп калат. ASUS ноутбуктары жана Apple стилиндеги баскычтоптор муну Linux'ка калтырат, ал болсо аларды ар бир жүктөлгөндө медиа баскычтарынан баштайт. Алардын ордуна F1-F12ден башталышын кааласаңыз, `omarchy device keyboard toprow fnkeys` иштетиңиз (кайра кайтуу үчүн `omarchy device keyboard toprow mediakeys`); кээ бир ноутбуктарда бул кайра жүктөгөндөн кийин күчүнө кирет. Apple Silicon Mac'тары өз жөндөөсүн сактайт.

### Сенсордук тактанын жаңсоолору

Иш столунда жылуу үчүн сенсордук тактада манжаларыңызды сүрүңүз:

| Жаңсоо | Аракет |
| --- | --- |
| Үч манжа солго / оңго | Мурунку / кийинки иш мейкиндиги, бош иш мейкиндиктерин кошо алганда |
| Үч манжа жогору | AI консолун ачуу/жабуу |
| Үч манжа төмөн | Omarchy менюсун ачуу |
| Төрт манжа солго / оңго | Активдүү терезени мурунку / кийинки иш мейкиндигине жылдыруу |
| Төрт манжа төмөн | Толук экранды күйгүзүү/өчүрүү |

Бирөөнү өзгөртүү үчүн, өзүңүздүн [сенсордук такта жаңсооңузду](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/) кошуудан мурун аны `~/.config/hypr/input.lua` ичинде алып салыңыз, анткени Hyprland бир эле манжалар саны жана багыт үчүн эки жаңсоону кабыл албайт:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Omarchy'нин бардык жаңсоолорун өчүрүү үчүн `~/.config/hypr/hyprland.lua` файлынын башына жакын, Omarchy'нин демейки маанилери жүктөлгөнгө чейин `omarchy_default_gestures = false` коюңуз.

Хаптикалык сенсордук тактасы бар Dell XPS ноутбуктарында _Аракеттер > Жабдуулар > Сенсордук тактанын термелүүсү_ бөлүмүнөн басуунун күчүн төмөн, орто же жогору кылып да коё аласыз.

### Кытай, жапон жана башка тилдерде терүү

Орнотуучу баскычтопту сураганда Japanese, Korean, Chinese (Simplified, Pinyin), Taiwan (Zhuyin) же Hong Kong (Cangjie) тандаңыз. Omarchy баскычтопту жана ага ылайыктуу киргизүү кыймылдаткычын автоматтык түрдө жөндөйт, анын ичинде офлайн биринчи жүктөлүүдөгү жөндөөдө да. Жапон тили үчүн Mozc, корей тили үчүн стандарттуу эки топтомдуу Hangul, жөнөкөйлөтүлгөн кытай тили үчүн Pinyin, Тайвань үчүн Chewing'дин стандарттуу Zhuyin жайгашуусу, ал эми Гонконг үчүн Гонконг белгилеринин формалары менен Cangjie колдонулат. Japanese (US keyboard) Mozc'ту АКШ баскычтоп жайгашуусу менен берет. Латын тамгаларын Dvorak, Colemak же AZERTY менен терсеңиз да, Hangul, Zhuyin жана Cangjie баскычтары өздөрүнүн стандарттуу ордунда калат. Эгер буга чейин Hangul же Chewing кошкон болсоңуз, анын баскычтарын ошол жерге көчүрүү үчүн аны _Жөндөө > Баскычтоп > Киргизүү ыкмалары_ бөлүмүндө тандоодон чыгарып, кайра тандаңыз; Omarchy сиз мурунтан эле колдонуп жаткан кыймылдаткычка тийбейт.

Терүү латын режиминде башталат. Жөндөлгөн киргизүү ыкмаларынын арасында алмашуу үчүн `Super + I`, артка алмашуу үчүн `Super + Shift + I` басыңыз. Pinyin сыяктуу киргизүү ыкмасынан латын тамгаларына чыгуу үчүн `Shift` баскычын жалгыз бир басыңыз, кайра кайтуу үчүн дагы бир басыңыз, Sogou, Microsoft Pinyin жана macOS'то кандай иштесе, ошондой; `Shift` менен кошо тамга бассаңыз, мурдагыдай эле баш тамга терилет. Жапон баскычтопторунда 全角/半角 киргизүүнү күйгүзүп/өчүрөт, 変換 аны күйгүзөт, ал эми 無変換 өчүрөт. Корей тилинде 한/영 Hangul'га которот жана 한자 Hanja'га айландырат, баскычтопуңузда атайын баскычтар болобу же көп ноутбуктардагыдай алардын ордуна оң Alt жана оң Ctrl жөнөтүлөбү, баары бир, ошондуктан ал жерде оң Alt жана оң Ctrl кадимки модификатор баскычтары эмес; анын ордуна үн менен жазуу Alt + Space менен күйгүзүлүп/өчүрүлөт. `Ctrl + Space` Tmux жана Herdr үчүн бош калат; `Shift + CapsLock` compose баскычы бойдон калат.

Бир нече баскычтоп жайгашуусу же киргизүү ыкмасы болгондо, панелдин оң жагында баскычтоп индикатору пайда болот. Киргизүү тилин алмаштыруу үчүн аны басыңыз; жапон тили үчүн хирагана あ болуп көрсөтүлөт. Жапон белгилерин тандоо үчүн жапон тилине өтүп, `nihongo` сыяктуу сөз териңиз, анан Space'ти эки жолу басыңыз. Тандооңузду кабыл алуу үчүн Enter басыңыз. Эгер бир нече баскычтоп жайгашууңуз да болсо, алардын арасында алмашуу үчүн индикаторду оң баскыч менен басыңыз.

Англис жана француз сыяктуу жайгашууларды орнотуу учурунда сунушталган тандоолордун ичинен тандоо үчүн _Жөндөө > Баскычтоп > Баскычтоп киргизүүлөрү_ колдонуңуз. Кайсы терүү кыймылдаткычтары активдүү болорун тандоо үчүн _Жөндөө > Баскычтоп > Киргизүү ыкмалары_ колдонуңуз. Эки тандагыч тең Omarchy менюсунун ичинде ачылат, учурдагы тандоолоруңуз белгиленип турат. Тандоону күйгүзүү же өчүрүү үчүн аны басыңыз же Enter басыңыз; ар бир өзгөртүү ошол замат колдонулат. Киргизүү ыкмасын тандоодон чыгарсаңыз, ал алмашуу тизмесинен чыгарылат, бирок өчүрүлбөйт; баскычтоп жеткиликтүү бойдон калат.

Ошол эле тандагычтарды ачуу үчүн `omarchy setup keyboard` же `omarchy setup input` иштетиңиз. Буйрук сабынан бир тилди кошуу үчүн `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` же `cangjie5` колдонуңуз. Quick, Boshiamy жана Array Cangjie менен бир пакетте келет жана Киргизүү ыкмалары тандагычында көрүнөт. Өзүңүз койгон алмаштыруу баскычтары сакталат. Кыймылдаткычтын башка жайгашуулары же баскычтары үчүн `fcitx5-configtool` пакетин `omarchy pkg add fcitx5-configtool` менен орнотуп, аны терминалдан ишке киргизиңиз. Киргизүү тилин тандоо иш столунун тилин өзгөртпөйт. _Жөндөө > Аймак > Тил_ бөлүмүндө жапон, корей же кытай тилин тандасаңыз, эгер сизде азырынча киргизүү ыкмасы жок болсо, анын киргизүү ыкмасы кошулат.

Киргизүү ыкмаларынын же баскычтоп жайгашууларынын арасында алмашуу үчүн `Super + I`, ал эми тескери багытта кайтуу үчүн `Super + Shift + I` колдонуңуз, ошондо үчөө жөндөлгөн болсо да, эки коңшу тандоонун ортосунда ары-бери жыла аласыз. Киргизүү индикатору бирден ашык киргизүү ыкмасы же жайгашуу жөндөлгөндө гана панелдин оң жагында пайда болот. Бул иш столунун баскыч айкалышы сиздин учурдагы Fcitx алмаштыруу баскычтарыңыз менен катар иштейт; аны `~/.config/hypr/bindings.lua` ичинде өзгөртсөңүз болот. Киргизүү кыймылдаткычтары жана compose ырааттуулуктары ар бир сеанста мурунтан эле иштеп турган [Fcitx5](https://fcitx-im.org/) кызматын колдонот.

### ALT баскычын SUPER катары колдонуу

Кээ бир баскычтопторда негизги мета баскычты (Windows/cmd баскычы) SUPER катары колдонуу ыңгайсыз. Муну төмөнкү өзгөртүү менен ALT кылып алмаштырсаңыз болот:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
