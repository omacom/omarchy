# Кеңири таралган ыңгайлаштыруулар

Бул Omarchy жөндөөсүн өзүңүзгө ылайыкташтыруунун кеңири таралган ыкмаларынын жыйнагы. Тутумдук жаңыртуулар кээде айрым конфигурацияларды баштапкы абалына кайтарышы керек болушу мүмкүн экенин билип коюңуз. Мындай болсо, өзгөртүүлөрүңүз жоголбойт, бирок баштапкы файлдын жанындагы `.bak.<timestamp>` файлына салынат.

Эгер бир нерсени бузуп алсаңыз, Omarchy менюсундагы _Жаңыртуу > Жөндөөлөр_ аркылуу айрым конфигурацияларды баштапкы абалына кайтарсаңыз болот. Эгер _чындап эле_ баарын бузуп алсаңыз, `omarchy reinstall configs` аркылуу бардык конфигурацияларды баштапкы абалга кайтарсаңыз, же `omarchy reinstall` менен ар бир демейки пакетти жана конфигурацияны кайра орнотсоңуз болот.

### Трейдин бардык белгилерин дайыма көрсөтүү

Демейки боюнча Dropbox, 1password же Steam сыяктуу трей белгилери трейди ачуучу жебенин артында жашырылып турат, ал үстүнө курсорду алып барганда аларды көрсөтөт. Эгер алар дайыма көрүнүп турушун кааласаңыз, трей белгилерин башкаргычты ачуу үчүн ачуучу жебени оң баскыч менен басып, көрүнүп турушун каалаган белгилерди кадап коюңуз (эч качан көргүңүз келбегендерин жашырып да койсоңуз болот).

### Тегерек терезе бурчтары

Omarchy'нин демейки дизайны — тик бурчтар, бирок аны бир аз жумшарткыңыз келсе, Omarchy менюсунда _Көрүнүш > Терезелер > Терезе бурчтары > Тегерек бурчтар_ тандаңыз же `omarchy hyprland corners rounded` иштетиңиз. _Темадагы бурчтар_ тема колдонгон абалга кайтарат. Өз радиусуңузду коюу үчүн _Темадагы бурчтар_ (`omarchy hyprland corners theme`) тандоосунда калыңыз, анткени Тегерек жана Тик бурчтар сиздин конфигурацияңыздан кийин жүктөлүп, аны кайра жазып салат, анан `~/.config/hypr/looknfeel.lua` ичиндеги rounding сабын комментарийден чыгарыңыз:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### Терезелердин ортосундагы боштуктарды алып салуу

Ноутбук дисплейлеринде кээ бирөөлөр терезелердин ортосундагы боштуктарга бир да пикселди коротпоону жакшы көрөт (ал тургай жогорку панелге да, аны `Super + Shift + Space` менен жашырып койсоңуз болот). Бардык боштуктарды жана чектерди `Super + Shift + Backspace` менен өчүрсөңүз болот, же `~/.config/hypr/looknfeel.lua` ичиндеги бул бөлүмдөгү комментарийлерди алып салып, аларды биротоло алып салсаңыз болот:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
