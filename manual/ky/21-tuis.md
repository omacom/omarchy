# TUI'лер

## Lazygit

[Lazygit](https://github.com/jesseduffield/lazygit) — GitHub Desktop сыяктуу тиркемелерге жагымдуу альтернатива, ал терминалдын ичинде иштейт.

Аны түз иштетсеңиз болот: git башкарган каалаган папкага барып, `lazygit` иштетиңиз. Же Neovim ичинде `Space G G` менен иштетсеңиз болот.

Ар кандай панелдердин арасында `Tab` менен өтөсүз. Files панелинде `Space` менен файлдарды staging үчүн тандайсыз, андан кийин `c` менен жаңы коммит түзсөңүз болот. Жеткиликтүү бардык буйруктарды `?` менен көрө аласыз.

## Btop

[Btop](https://github.com/aristocratos/btop) — эстутумдун, CPU'нун, дисктин жана тармактын колдонулушун көрсөткөн кооз ресурс башкаргыч. Ал ошондой эле бардык активдүү процесстерди тизмелеп, аларды башкарууга мүмкүндүк берет.

Omarchy аны Activity Monitor деп атайт, аны тиркеме иштеткичтен же `Super + Shift + T` басып ачасыз. Ал калкыма терезе болуп ачылат, аны `Super + T` менен тизилген терезеге айландырсаңыз болот.

## Herdr

[Herdr](https://herdr.dev) — терминалдык иш мейкиндиктерин башкаргыч, ал сизге иш мейкиндиктерин, өтмөктөрдү жана панелдерди берип, алардын баарын туруктуу сеанста иштетип турат, ал сеанстан ажырап, кийин кайра келсеңиз болот.

Аны (же учурдагы сеансыңызга кайра туташууну) тиркеме иштеткичтен же `Super + Ctrl + Return` менен баштайсыз. Omarchy Tmux жөндөөлөрүн кайталаган Herdr жөндөөлөрү менен келет, ошондуктан префикс баскычы бул жерде да `Ctrl + Space`. Бардык баскыч айкалыштарын `Super + Ctrl + K` менен карап чыга аласыз.

## Fastfetch

[Fastfetch](https://github.com/fastfetch-cli/fastfetch) ядронун версиясы, иштеп турган убакыт, тема, CPU, эстутум жана башкалар сыяктуу тутум маалыматын көрсөтөт. Ал популярдуу neofetch куралынын мураскери.

Omarchy муну Omarchy менюсунда (`Super + Space`) _Тутум > Тутум жөнүндө_ катары таңгактаган.

## Cliamp

[Cliamp](https://www.cliamp.stream/) — Winamp 2.x'тен шыктанган ретро стилдеги терминалдык музыка ойноткуч, анда lo-fi ыргактары үчүн орнотулган радиостанциялар да бар. Аны `Super + Shift + Alt + M` менен же Omarchy менюсунун _Тиркемелер_ бөлүмүнөн ачыңыз. Баскыч айкалыштарынын толук тизмеси үчүн `?` басыңыз.

## Wi-Fi жана Bluetooth эмне болот?

Wi-Fi жана Bluetooth үчүн TUI'лерди таппайсыз — ал иштер Omarchy кабыгына таандык. Тармактарды көрүп, туташуу үчүн жогорку панелдеги Wi-Fi белгисин басыңыз (же `Super + Ctrl + N` басыңыз), ал эми түзмөктөрдү жупташтырып, туташтыруу үчүн Bluetooth белгисин басыңыз (же `Super + Ctrl + B` басыңыз). Толук маалымат үчүн [тармак](35-networking.md) бөлүмүн караңыз.

## Өзүңүздүкүн кошуу

Каалаган терминалдык программа толук тиркеме катары иштей алат. Omarchy менюсундагы (`Super + Space`) _Орнотуу > TUI_ бөлүмүнө барып, ага ат, иштетүү буйругун, терезе стилин жана белги бериңиз, ошондо ал тиркеме иштеткичте башка тиркемелер сыяктуу эле пайда болот. Аны кайра _Алып салуу > TUI_ бөлүмүнөн алып салсаңыз болот.
