# Dotfiles

Omarchy негизинен `~/.config` ичинде жайгашкан dotfiles деп аталган файлдар аркылуу жөндөлөт. Алар сиздин өзгөртүүлөрүңүз үчүн сиздин файлдарыңыз деп эсептелет. `/usr/share/omarchy` ичиндеги файлдар Omarchy'нин өзүнө таандык, аларга тийбешиңиз керек. `/usr/share/omarchy` ичинде бир нерсени өзгөртүү керек болсо, анын ордуна ал маанини `~/.config` ичинде кайра жазып коюңуз.

Негизги конфигурацияларды түз эле Omarchy менюсунан (`Super + Space`) оңдосо болот, мисалы, _Жөндөө > Баскычтоп > Баскыч айкалыштары_, _Жөндөө > Киргизүү_ жана _Жөндөө > Жөндөөлөр > [файл]_. Ушул жол менен оңдосоңуз, конфигурация өзгөргөндөн кийин кайра иштетилиши керек болгон ар бир процесс редактордон чыкканыңыздан кийин автоматтык түрдө кайра иштетилет (демейки боюнча Neovim — `:wq` экенин унутпаңыз! — бирок аны _Жөндөө > Демейкилер > Редактор_ аркылуу өзгөртсөңүз болот).

Мына `~/.config` ичиндеги негизги файлдардын тизмеси жана алар эмнени башкарары:

| Файл                  | Максаты              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | Hyprland'дын негизги конфигурациясы. Omarchy'нин демейки маанилерин жана төмөндөгү өзүңүздүн кайра жазуу файлдарыңызды жүктөйт. [Hyprland конфигурациялары тууралуу көбүрөөк билиңиз](https://wiki.hypr.land/Configuring/).  |
| `~/.config/hypr/bindings.lua` | Өзүңүздүн баскыч айкалыштарыңыз жана демейкилерди кайра жазуулар. |
| `~/.config/hypr/monitors.lua` | Монитор панели камтыбаган монитор жөндөөлөрү, мисалы, бурулуш, кошумча режимдер же мониторду өчүк калтыруу. |
| `~/.config/hypr/input.lua` | Баскычтоп жайгашууңузду, чычкандын жана сенсордук тактанын жөндөөлөрүн башкарат. |
| `~/.config/hypr/looknfeel.lua` | Боштуктарды, чектерди, анимацияларды жана көрүнүштүн калган бөлүгүн башкарат. |
| `~/.config/hypr/autostart.lua` | Сеанс менен кошо ишке кирген кошумча процесстерди башкарат. |
| `~/.config/omarchy/shell.json` | Omarchy шелин башкарат: панелдин ордун, жайгашуусун жана виджеттерин, ошондой эле экран сактагычтын, кулпунун жана күтүү режиминин убакыттарын. |
| `~/.config/foot/foot.ini` | Терминалыңызды башкарат (демейки боюнча foot). |
| `~/.XCompose` | Ыкчам эмодзилериңизди жана аты/email автотолуктоосун аныктайт. Өзгөртүүлөрдөн кийин сөзсүз `omarchy-restart-xcompose` иштетиңиз. |

Эгер өз жөндөөңүздү ыңгайлаштыруу үчүн көп өзгөртүү киргизсеңиз, бул dotfiles файлдарынын баарынын камдык көчүрмөсүн сактап коюу жакшы идея. [Stow муну жасоонун сонун жолу](https://www.youtube.com/watch?v=NoFiYOqnC4o).

### Өз тиркемелериңизди сеанс менен кошо ишке киргизүү

Эгер бир нерсе ар бир кирген сайын иштеп турушун кааласаңыз — синхрондоо демону, чат тиркемеси, өзүңүздүн скриптиңиз — аны `~/.config/hypr/autostart.lua` ичине жазыңыз:

```lua
o.launch_on_start("my-service")
```

Ал буйрукту сеанстын бир бөлүгү катары ишке киргизет, ошондуктан сиз кайра чыкканда ал туура тазаланат.

### Тутумдук окуяларда скрипттерди иштетүү

Omarchy бир нече учурда хуктарды иштетет, ал эми сиз аларга өз скрипттериңизди илип койсоңуз болот. Алар `~/.config/omarchy/hooks/<event>.d/` ичинде жайгашат, ар бир окуяга бир каталогдон, ал жердеги `.sample` менен бүтпөгөн ар бир файл окуя болгондо bash менен иштетилет:

| Окуя | Качан иштейт |
| ----- | ------------ |
| `post-boot` | Иш столу ишке киргенден кийин дароо |
| `post-update` | `omarchy update` аягына жакын, пакеттерден, миграциялардан жана кызматтарды кайра иштетүүдөн кийин, mise куралдары жаңыртылганга чейин |
| `pre-refresh-pacman` | `omarchy refresh pacman` пакет конфигурациясын кайра синхрондогондон кийин, пакеттерди жаңыртканга чейин; канал алмаштырылганда ал ошол эле жаңылоо кадамында иштейт |
| `theme-set` | Тема өзгөргөндөн кийин (теманын аты `$1` ичинде) |
| `font-set` | Шрифт өзгөргөндөн кийин (шрифттин аты `$1` ичинде) |
| `battery-low` | Батарея азайып калганда (пайызы `$1` ичинде) |

Өз репозиторийлериңиз же `IgnorePkg` саптары `pre-refresh-pacman` хугуна жазылышы керек, анткени ал пакет транзакциясынан мурун иштейт. Экөө тең сиздин колдонуучуңуздун атынан иштейт. `post-update` `omarchy update` алган sudo уруксаты али жаңы турганда иштейт, ошондуктан `sudo` колдонгон хук сырсөзүңүздү кайра сурабайт; `pre-refresh-pacman` болсо `omarchy refresh pacman` sudo'ну өзү колдонгондон кийин дароо иштейт.

Ошол каталогдордун ар биринде хуктун түзүлүшүн көрсөткөн `.sample` файлы мурунтан эле бар — аны иштетүү үчүн атынан `.sample` бөлүгүн алып салыңыз. Башка жерде жазган скриптиңизди орнотуу үчүн `omarchy hook install post-boot ~/my-hook` колдонуңуз, ал скриптти көчүрүп, аны аткарылуучу кылат.

### Менюга өз жазууларыңызды кошуу

Omarchy менюсун (`Super + Space`) `~/.config/omarchy/extensions/omarchy-menu.jsonc` файлын оңдоп, өз саптарыңыз менен кеңейтсеңиз болот. Жазуулар чекиттүү id менен белгиленет, ал эми id аларды дарактын кайсы жерине коерун аныктайт, ошондуктан `personal` негизги менюда көрүнөт, ал эми `personal.notes` анын ичинде көрүнөт:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

Бар болгон id'ни колдонсоңуз, жаңы сап кошулбай, ошол сап кайра жазылат. Файлда бардык жеткиликтүү талаалар комментарий катары сүрөттөлүп берилген.

### Өз шел экспортторуңузду, функцияларыңызды жана алиастарыңызды кошуу

Omarchy бир топ ыңгайлуу алиастар жана пайдалуу функциялар менен келет, бирок өзүңүздүкүн кошкуңуз келиши абдан кадимки нерсе. Алиастарды да, функцияларды да, экспортторду да `~/.bashrc` ичине кошушуңуз керек. Бул файл жаңыртууларда кайра жазылбайт. Omarchy'нин демейки маанилеринин кайсы бирин өзгөрткүңүз келсе, аларды да бул жерге коопсуз кошо аласыз.

### Иш столу үчүн чөйрө өзгөрмөлөрүн коюу

Иш столу сеансынын экспорттору `~/.config/uwsm/env.d/` ичинде турушу керек. Бул файлдар иш столуңуз ишке кирерден мурун иштейт, ошондуктан шелдеги ката сизди кайра кирүү экранына кайтарып жибериши мүмкүн. Аларды оңдоп жатканда иштеп турган терминалды ачык калтырыңыз. Кайра жазууну өчүрүү үчүн аны `env.d` ичинен башка жерге жылдырыңыз. Эгер өзгөртүү кирүүгө тоскоол болсо, [кирүүнү калыбына келтирүү](45-troubleshooting.md#my-password-is-accepted-but-i-return-to-the-login-screen) бөлүмүн караңыз.

### Omarchy'нин ички файлдарын өзгөртүү

Ооба, бул сиздин компьютериңиз. Аны менен каалаганыңызды кыла аласыз, бирок `/usr/share/omarchy` ичиндеги файлдарды түз өзгөртпөөнү сунуштайт элем. Алар Omarchy pacman пакетине таандык, ошондуктан өзгөртүүлөрүңүз кийинки жаңыртууда жөн эле кайра жазылып кетет. Анын ордуна жактырбаган демейки маанилериңизди `~/.config/*` папкасында кайра жазып койгонуңуз жакшы.

Ушул жол менен дээрлик баарын өзгөртсөңүз болот, мисалы, демейки баскыч айкалыштарын. Жөн гана `~/.config/hypr/bindings.lua` файлын оңдоп, мисалы, [Obsidian](https://obsidian.md/) ордуна [Joplin](https://joplinapp.org/) коюңуз (`omarchy-pkg-add joplin-bin` менен орнотуңуз):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` алмаштыруучу айкалышты кошуудан мурун бар болгон айкалышты алып салат. Ал `o.bind` менен бирдей аргументтерди кабыл алат, анын ичинде ишке киргизүү жардамчыларын жана айкалыш параметрлерин. Айкалыш кошуу үчүн `o.bind`, ал эми аны алмаштырбастан жөн гана алып салуу үчүн `hl.unbind` колдонуңуз.

Эгер Omarchy'нин ички файлдарын сөзсүз оңдойм десеңиз, _Жаңыртуу > Канал > Dev_ аркылуу dev каналына өтүңүз. Ал Omarchy'ни `~/omarchy` ичиндеги баштапкы коддун git көчүрмөсүнө байланыштырат, аны көңүлүңүз каалагандай өзгөртө бересиз. Бул жерде сизге эмне кылууну эч ким айтпайт!

### Бардык өзгөртүүлөрдү баштапкы абалга кайтаруу

Эгер конфигурацияларды чаташтырып алсаңыз, аларды ар дайым Omarchy менюсундагы _Жаңыртуу > Жөндөөлөр_ аркылуу демейки абалга кайтарсаңыз болот. Же баарын баштапкы абалга кайтаруу үчүн `omarchy reinstall configs` иштетиңиз.
