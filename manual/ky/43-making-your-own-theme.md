# Өз темаңызды түзүү

Өзүңүздүн темаларыңызды `~/.config/omarchy/themes` ичине кошо аласыз. Негиз катары учурдагы темалардын бирин көчүрүп алыңыз (`/usr/share/omarchy/themes` ичинен караңыз), андан кийин көңүлүңүз толгонго чейин оңдоп-түзөңүз. Темаңыз ошол папканын ичинде болсо эле, ал тема тандоо менюсуна кошулат.

Оңдошуңуз керек болгон негизги файл — `colors.toml`. Ал түстөр топтомун аныктайт, ал эми ошол топтомдон терминал (Foot/Alacritty/Ghostty/Kitty), btop, Chromium, Hyprland, Neovim, Helix, VSCode, Obsidian, Qt тиркемелери, баскычтоптун жарыгы, киргизүү ыкмасы, экранды бөлүшүү тандагычы, тиркемелердин сүрөтчөлөрү, бир нече AI куралдары (Claude, Pi, Hermes, T3 Code, Herdr) жана бүт Omarchy shell (жогорку панель, меню, билдирмелер, OSD жана кулпу экраны) үчүн конфигурациялар түзүлөт.

Ошондой эле камтылган Aether тиркемесин колдонуп, түстөр менен ойноп, фон издөөгө ыңгайлуу сонун графикалык интерфейс аркылуу жаңы тема түзө аласыз. Аны `Super + Alt + Space` ичиндеги тиркемелер торунан ачыңыз.

### Орнотулган тема эмнелерди камтый алат

`~/.config/omarchy/themes` ичинде өзүңүз жазган тема каалаганыңызды камтый алат — бул сиздин машинаңыз жана сиздин файлыңыз, Omarchy анын баарын колдонот.

Башка бирөөнүн репозиторийинен `omarchy theme install` менен орноткон тема түскө тиешелүү нерселердин баарын сактайт, бирок машинаңызда код иштетиши мүмкүн болгон бир нече файлдан ажырайт: ар кандай `.lua` файлы, терминалдын конфигурациялары (`alacritty.toml`, `foot.ini`, `ghostty.conf`, `kitty.conf`) жана `vscode.json`. Теманын `hyprland.lua` файлы — композиторуңуз кирүүдө иштеткен Lua коду, терминалдын конфигурациясы терминалыңыз иштете турган программаны атайт, ал эми `vscode.json` орнотула турган VSCode кеңейтүүсүн атайт. Бирөөнүн темасын орнотуу иш тактаңыздын сырткы көрүнүшүн өзгөртүшү керек, бирок анда эмне иштей турганын эч качан өзгөртпөшү керек.

Калгандарынын баары теманын автору жазгандай так иштей берет — `btop.theme`, `chromium.theme`, `helix.toml`, `shell.toml`, фондор жана алдын ала көрүнүштөр толугу менен сакталат. Алынып салынгандар гана машинаңызда `colors.toml` негизинде кайра түзүлөт.

Omarchy экөөн теманын ичинде өзүнүн git репозиторийи бар-жогуна карап айырмалайт, ал эми `omarchy theme install` клондогондо так ошону калтырат. Ошентип, өзүңүз жазган тема сиздики бойдон калат, ал эми интернеттен алган тема түстөр бойдон калат.

### Жарык режим

Эгер жарык режимдеги тема жасап жатсаңыз, `colors.toml` файлыңыздын башына `mode = "light"` деп жазыңыз. Ошондо ал бардык тиркемелер үчүн автоматтык түрдө жарык режим менен жупталат. (Теманын тамырына `light.mode` деп аталган бош файл таштоонун эски ыкмасы да дагы эле иштейт.)

### Кулпуну ачуу сүрөтү

`unlock.png` жана `preview-unlock.png` сүрөттөрү менен келген темалар _Көрүнүш > Кулпуну ачуу_ ичинде тизмеленет. `unlock.png` сүрөтүңүз тунук фондогу png болгону жакшы. Ал эми алдын ала көрүнүш сүрөтүн `omarchy plymouth preview` менен түзө аласыз.

### Omarchy камтыбаган тиркемелерди темалоо

Эгер ал тизмеде жок тиркемени колдонсоңуз, Omarchy'ге аны калып аркылуу темалоону өзүңүз үйрөтө аласыз. `~/.config/omarchy/themed/` ичине ал түзө турган конфигурациянын аты менен аталган жана `.tpl` кеңейтүүсү кошулган файл таштаңыз, андан кийин конфигурацияны `{{ background }}`, `{{ foreground }}`, `{{ accent }}`, `{{ red }}`, `{{ color0 }}` баштап `{{ color15 }}` чейинки жана палитранын калган түстөрүн орун ээлегич катары колдонуп жазыңыз. Теманы алмаштырган сайын файл ошол теманын түстөрү менен кайра түзүлөт.

Ошол папкада көчүрүп алуу үчүн толугу менен түшүндүрмөлөнгөн `alacritty.toml.tpl.sample` бар — анда колдоно турган ар бир өзгөрмө, ошондой эле түстөрдү `#` белгисиз же ондук RGB түрүндө күткөн тиркемелер үчүн `_strip` жана `_rgb` өзгөрткүчтөрү тизмеленген. Сиздин калыптарыңыз Omarchy'нин өз калыптарынан артык турат, ошондуктан муну камтылган тиркеменин кантип темаланышын өзгөртүү үчүн да колдоно аласыз.

### Темаңызды таратуу

Темаңызды башкалар колдоно алышы үчүн таратгыңыз келсе, аны GitHub сыяктуу ачык git серверине жайгаштырышыңыз керек. Андан кийин адамдар аны ошол URL менен Omarchy менюсундагы _Орнотуу > Көрүнүш > Тема_ аркылуу орното алышат. `omarchy-[themename]-theme` аталыш эрежесин карманганыңыз сунушталат, анткени ошондо тема орнотулгандан кийин тема тандоо менюсунда жөн гана `[themename]` болуп туура көрүнөт.

Ошол калган `[themename]` теманын каталогунун аты болуп калат, ошондуктан ал Omarchy коопсуз колдоно ала турган ат болушу керек: ал тамга, сан же астын сызуу менен башталышы керек, ал эми калганы тамгаларды, сандарды, `.`, `_`, `+` жана `-` белгилерин камтый алат. Баш тамгалар сиз үчүн кичине тамгага айландырылат, бирок башка нерселердин баары — боштук, тырмакча, англис эмес тамга — каталогдун атына айландырылбай, орнотуу учурунда четке кагылат. Демек, `omarchy-tokyo-night-theme`, `omarchy-flexoki_light-theme` жана `omarchy-c++-theme` баары эле көйгөйсүз орнотулат.

Эсиңизде болсун: тема репозиторийден орнотулгандан кийин, ал камтыган ар кандай `.lua`, терминал конфигурациясы же `vscode.json` алынып салынат, ошондуктан теманы ошолорго таянып курбаңыз.

Темаңызды [кошумча темалар барагына](https://omarchy.org/themes/) кошууну [omarchy-site репозиторийине](https://github.com/omacom-io/omarchy-site) pull request жөнөтүү менен сурасаңыз болот.
