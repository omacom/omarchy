# Shell плагиндери

Omarchy иш тактасы `omarchy-shell` деп аталган узак иштеген бир Quickshell процесси катары иштейт, ал эми экранда көргөнүңүздүн дээрлик баары анын ичиндеги плагин. Панель — плагин. Андан ылдый түшкөн панелдер, эмодзи тандагыч жана алмашуу буферинин менеджери сыяктуу толук экрандагы катмарлар, Omarchy менюсунун өзү, кулпу экраны, polkit диалогу жана батареяңызды көзөмөлдөп, түнкүсүн экраныңызды жылуулаткан интерфейси жок кызматтар да плагиндер.

Бул жөн гана ички ишке ашыруунун майда-чүйдөсү эмес. Бул иш тактасынын бөлүктөрүн өчүрүп, алмаштырып же Omarchy булак кодунун бир сабына да тийбей өзүңүз жаза аласыз дегенди билдирет.

Биринчи тараптын плагиндери Omarchy менен бирге келет жана `$OMARCHY_PATH/shell/plugins/` ичинде жайгашкан. Өзүңүз кошкон нерселердин баары — өз эксперименттериңиз же GitHub сайтынан тапкан бир нерсе — `~/.config/omarchy/plugins/` ичинде жайгашат. Экөө тең ишке киргенде бирдей эле жол менен табылат, бирок кыналган плагиндер ишенимдүү shell интерфейстерин алат, ал эми үчүнчү тараптын плагиндери өз кызматы жана жашоо цикли менен гана чектелген интерфейсти алат. Кыналган плагиндердин клондору баштапкы жүрүм-турум үчүн керектүү булакка тиешелүү конфигурацияны жана UI чакырыктарын гана сактап калат.

## Сизде эмнелер бар экенин көрүү

```
omarchy plugin list
```

Бул табылган ар бир плагинди анын id белгиси, күйгүзүлгөн-күйгүзүлбөгөнү, биринчи тараптыкыбы же үчүнчү тараптыкыбы, түрлөрү жана көрсөтүлүүчү аты менен чыгарат. Эгер аны башка бир нерсеге берип жатсаңыз, `--json` кошуңуз.

Плагиндердин id белгилери аттар мейкиндигине бөлүнгөн. Кыналгандардын баары `omarchy.` менен башталат — `omarchy.clock`, `omarchy.network`, `omarchy.notifications` — жана бул аттар мейкиндиги резервделген, ошондуктан үчүнчү тараптын плагини аны эч качан ээлей албайт.

## Аларды күйгүзүү жана өчүрүү

```
omarchy plugin enable omarchy.tailscale
omarchy plugin disable omarchy.weather
```

Же менюну колдонуңуз: _Жөндөө > Плагиндер_ бөлүмүндө Күйгүзүү, Өчүрүү, Кошуу, Клондоо жана Алып салуу бар, ар биринде ошол аракет үчүн маанилүү плагиндерди гана сунуштаган тандагыч бар.

Күйгүзүлгөн абал `~/.config/omarchy/shell.json` ичинде сакталат, жана эреже плагиндин эки түрү үчүн бир аз айырмаланат. Үчүнчү тараптын плагини анын id белгиси ошол файлдын кайсы бир жеринде — панелдин макетиндеги жазуу катары, `plugins[]` ичиндеги жазуу катары же `bar.id` катары — кездешкенде гана күйгүзүлгөн болот. Панелдин виджети болбогон биринчи тараптын плагиндери тескерисинче иштейт: алар демейки боюнча күйгүзүлгөн жана `disabledPlugins[]` ичинде тизмеленгенде гана өчөт.

Толук панель плагининде өчүк абалы такыр жок. Ар дайым так бир панель болот, ошондуктан аны башкасын күйгүзүү менен алмаштырасыз. Панелдин виджеттерин жайгаштыруу [жогорку панель](05-the-top-bar.md) бөлүмүндө жазылган.

## git аркылуу плагин кошуу

Үчүнчү тараптын плагини — бул жөн гана тамырында `manifest.json` файлы бар git репозиторийи.

```
omarchy plugin add https://github.com/acme/omarchy-weather.git --enable
```

Эч нерсе кылуудан мурун ал плагиндер узак иштеген shell процессиңиздин ичинде каалагандай, кумсалгычсыз код катары иштей турганын ачык айтып, URL дарегин көрсөтөт жана ырастооңузду сурайт. Буга олуттуу мамиле кылыңыз. Үчүнчү тараптын плагин интерфейси аутентификация кызматтарын түз ачып бербейт, ал эми алмаштыруучу панель аутентификацияга тиешеси жок, конфигурацияланган UI үчүн гана чектелген мүмкүнчүлүктөрдү алат. Визуалдык плагиндер баары бир shell процессинин QML сахнасын бөлүшөт жана кадимки ата-эне объекттерин аралап чыга алат, ал эми бардык плагин коду колдонуучу аккаунтуңуз жете алган нерселердин баарына жетет. Аутентификация абалы ал кызматтарды хосттун жеткиликтүү объект графынан тышкары кармоо аркылуу өзүнчө корголот. Иштетүүгө даяр болгон репозиторийлерди гана кошуңуз жана аларды күйгүзүүдөн мурун окуп чыгыңыз.

Алмаштыруучу панель орнотулган виджеттерди көрсөтө алат, бирок кызматка таянган үчүнчү тараптын виджеттеринин мүмкүнчүлүктөрү ал жерде чектелиши мүмкүн, анткени панелге башка плагиндин жандуу кызмат объектин суроого уруксат жок. Эгер мындай виджетке өзүнүн шерик кызматы керек болсо, кыналган `omarchy.bar` панелине кайтыңыз.

Андан кийин ал репозиторийди убактылуу папкага клондоп, манифестти текшерет, эгер ошол id белгисин башка плагин мурунтан ээлеп алган болсо, орнотуудан баш тартат жана аны `~/.config/omarchy/plugins/<id>/` ичине жылдырат. `--enable` жок болсо, аны азыр күйгүзгүңүз келеби деп сурайт, жана сиз "жок" деп, адегенде кодду окуганы кетсеңиз болот. Ал плагиндеги эч нерсени эч качан иштетпейт, орнотуу хугун эч качан аткарбайт жана эч качан sudo сурабайт — ал файлдарды клондоп, манифестти текшерип, IPC аркылуу бир битти которот, болгону ошол.

Жаңыртуу — ошол эле көчүрмөнү fast-forward pull кылуу:

```
omarchy plugin update acme.weather
omarchy plugin update
```

id көрсөтүлбөсө, ал сиздеги git менен башкарылган бардык плагиндерди жаңыртат. Ал колдонуудан мурун айырмаларды (diff) көрсөтөт, fast-forward кылып өтө албаган жергиликтүү өзгөртүүлөрүңүз болсо, жаңыртуудан баш тартат, ал эми жаңы ревизия текшерүүдөн өтпөсө, мурунку абалга кайтарат.

```
omarchy plugin remove acme.weather
```

Алып салуу адегенде плагинди өчүрөт, андан кийин эгер ал git көчүрмөсү болсо, аны өчүрөт (репозиторий upstream жакта дагы эле бар), же эгер ал симлинк болсо, байланышын үзөт. git репозиторийи жок, кол менен жасалган плагин папкасы түз эле өчүрүлбөй, плагиндер папкасынын ичиндеги убакыт белгиси бар камдык көчүрмөгө жылдырылат.

## Өзгөртүү үчүн кыналган плагинди клондоо

Бул менин эң жакшы көргөн бөлүгүм. Кыналган виджеттин жүрүм-турумун өзгөрткүңүз келсе, `$OMARCHY_PATH` ичиндеги файлдарды түзөтпөңүз — алар пакетке таандык жана кийинки жаңыртуу аларды кайра жазып салат. Анын ордуна аны клондоңуз:

```
omarchy plugin clone omarchy.clock
```

Бул бүт плагинди `~/.config/omarchy/plugins/dhh.clock` ичине (менин эмес, сиздин колдонуучу атыңыз менен) көчүрүп, атын "My Clock" деп өзгөртөт, аны күйгүзөт жана shell процессин кыналган плагинден сиздин көчүрмөңүзгө которот — бар панель виджетинин ордун жана жөндөөлөрүн сактап. Жаңы папканы дароо `$EDITOR` ичинде ачуу үчүн `--edit` кошуңуз, менюдагы _Жөндөө > Плагиндер > Плагинди клондоо_ сиз үчүн дал ушуну жасайт.

Колдонуучу атынын префикси клонуңуздун id белгисин сизге гана таандык кылат, ошондуктан аны бөлүшсөңүз, башка эч кимдикине кагылышпайт. Баштапкы кыналган id белгисине жасалган чакырыктар сиздин клонуңузга багытталат, ошондуктан `omarchy.clock` белгисине шилтеме кылган эч нерсени жаңыртуунун кереги жок. Эгер баарын бузуп алсаңыз, `omarchy plugin remove dhh.clock` кыналган плагинди кайра ордуна коёт.

`~/.config/omarchy/plugins/` ичиндеги каалаган файлды сактаганда плагин коду автоматтык түрдө кайра жүктөлөт, ошондуктан редакторду ачык калтырып, өзгөртүүлөрүңүздүн кантип иштеп жатканын карап отура аласыз.

## Өзүңүздүкүн жазуу

Плагин — бул `manifest.json` жана бир аз QML камтыган папка. Манифест `schemaVersion: 1`, `id`, `name`, `version`, бир же бир нече `kinds` жана ар бир түр үчүн QML файлын көрсөткөн `entryPoints` объектин жарыялайт:

| Түрү | Бул эмне |
|------|------------|
| `bar-widget` | Активдүү панель бир бөлүгүнө жайгаштыра ала турган компонент |
| `panel` | Туруктуу же чакырылуучу калкыма терезе |
| `overlay` | Толук экрандагы катмар |
| `menu` | Чакырылуучу меню бети |
| `service` | Интерфейси жок, жалгыз нускадагы кызмат |
| `bar` | Кыналган панелдин ордун баскан толук панель |

Плагин бир эле учурда бир нече түрдү жарыялай алат — медиа плагини `service` да, `bar-widget` да. Панелдин виджеттери көрсөтүлүүчү аты, категориясы, кошумча `defaultSection` жана `allowMultiple` камтыган кошумча `barWidget` блогун алат, `allowMultiple` панелде андан бирден ашык болушунун мааниси бар-жогун айтат. Көпчүлүк виджеттер аны `false` кылып коюшат; аралык калтыргычтар жана көрсөткүчтөр `true` кылышат.

Бир нерсени жарыялоодон мурун аны текшериңиз:

```
omarchy plugin validate ./my-plugin
```

Бул shell процесси жүктөө учурунда жасаган текшерүүлөрдү эле жүргүзөт: схеманын версиясы, милдеттүү талаалар, резервделбеген id, коопсуз салыштырмалуу жол болгон жана чындап бар кирүү чекиттери, жарыялаган ар бир түр үчүн кирүү чекити, жана папканын ичинде эч кандай симлинк жок экени.

Плагин иштеп чыгуу боюнча [shell маалымдамасын](https://github.com/omacom/omarchy/blob/quattro/docs/omarchy-shell.md) жана [биринчи тараптын плагиндеринин каталогун](https://github.com/omacom/omarchy/blob/quattro/shell/plugins/README.md) караңыз.

## Өзүңүздүкүн дүйнө менен бөлүшүү

Жаккан бир нерсе жасап алгандан кийин, аны ачык git репозиторийине жайгаштырыңыз. Таратуу механизми ушул эле — андан кийин каалаган адам сиздин URL дарегиңизге карата `omarchy plugin add` иштетип, аны бир нече секундда иштетип ала алат.

Адамдар аны чындап таба алышы үчүн, аны [plugins.omarchy.org](https://plugins.omarchy.org) сайтына кошуңуз. Бул Omarchy shell плагиндеринин базары, жана жазайын деп жаткан виджетиңизди кимдир бирөө мурунтан эле жасап койгон-койбогонун билгиңиз келгенде биринчи карай турган жер ушул. Баштоодон мурун аны карап чыгыңыз!
