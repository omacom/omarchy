# Жаңыртуулар

Omarchy жана пакеттериңиз Omarchy менюсундагы (`Super + Space`) _Жаңыртуу > Omarchy_ аркылуу жаңыланып турат.

Omarchy өзү [Omarchy пакеттер репозиторийинен](https://github.com/omacom-io/omarchy-pkgs) кадимки pacman пакеттери катары орнотулат, ошондуктан жаңыртуу [Omarchy'нин акыркы чыгарылышын](https://github.com/omacom/omarchy/releases) орнотот, тутумуңузду акыркы абалга шайкеш келтирүү үчүн күтүп турган миграцияларды иштетет жана бардык тутум пакеттерин [Omarchy Arch күзгүсүнөн](https://github.com/omacom-io/omarchy-mirror) жана [AUR](https://aur.archlinux.org/) булагынан (эгер AUR пакеттерин орноткон болсоңуз) жаңыртат.

Жаңы чыгарылыштар чыкканда, саатыңыздын оң жагында тегерек жебе сүрөтчөсү пайда болот. Аны бассаңыз, жаңыртуу процесси башталат.

![update-available](images/update-available.webp)

### Төрт канал

Omarchy төрт канал боюнча жаңыртылат: stable, RC, edge жана dev. Жаңы орнотуулар stable каналынан башталат, ал [расмий чыгарылыштарды](https://github.com/omacom/omarchy/releases/), ошондой эле акыркы абалдан бир ай артта турган [туруктуу Omarchy Arch күзгүсүн](https://github.com/omacom-io/omarchy-mirror) ээрчийт, ошентип конфигурацияны өзгөртүүнү талап кылган жаңы шайкешсиздиктерди адамдарга көйгөй жаратканга чейин кармап калабыз.

Бирок ошол мүмкүн болгон көйгөйлөрдү табууга жардам бергиңиз келсе, edge каналында иштесеңиз болот. Ал Omarchy пакеттериңизди эң акыркы иштеп чыгуу куруламаларына ылайык кармап, Arch'тын эң акыркы пакеттери чыгары менен жаңыртууга мүмкүнчүлүк берет. Муну Linux боюнча тажрыйбаңыз болсо жана көйгөй чыккан тутумду калыбына келтирүүнү билсеңиз гана жасаңыз.

Ар бир жаңы ири чыгарылыштын алдында биз акыркы текшерүүнү RC каналы аркылуу жүргүзөбүз. Акыркы жылмалоого жардам бергиңиз келсе, Discord'догу #omarchy-release-candidates каналына келиңиз.

Акырында, dev каналы бар, ал Omarchy'ни түз эле `~/omarchy` ичиндеги баштапкы коддун git көчүрмөсүнө edge пакеттери менен бирге байлайт. Бул каналды Linux'ту жакшы билген, Omarchy'нин өзүнүн үстүндө түз иштеген жана бузулууларга чыдаганга даяр болсоңуз гана колдонуңуз.

Каналдардын ортосунда Omarchy менюсундагы _Жаңыртуу > Канал_ аркылуу (же терминалда `omarchy channel set <stable|rc|edge|dev>` менен, ал эми кайсы каналда экениңизди көрүү үчүн `omarchy channel current` менен) которула аласыз.

### Өзөктөрдү алмаштыруу

Omarchy өзүнүн `linux-omarchy` өзөгү менен жүктөлөт, бирок анын жанына башкаларды да орнотуп кое аласыз, мисалы Arch'тын стандарттуу `linux` өзөгүн же сынап жаткан эксперименталдык куруламаңызды. Бирден көп болгондо, Omarchy менюсундагы _Жаңыртуу > Өзөк_ аларды тизмелеп, демейки боюнча жүктөлө тургандын жанына белги коёт. Башкасын тандап, сырсөзүңүздү бир жолу киргизсеңиз, ал кийинки кайра жүктөөдөн кийин жүктөлөт. Башка өзөктөр жүктөө менюсунда калат, ошондуктан жаңы демейки өзөк көйгөй жаратса, бирөөнү колго тандай берсеңиз болот. Терминалда учурдагы демейкини көрүү үчүн `omarchy kernel`, орнотулгандарды көрүү үчүн `omarchy kernel list`, ал эми алмаштыруу үчүн `omarchy kernel set <kernel>` колдонулат.

### Микропрограмманы жаңыртуу

Эскирип калган нерсе пакеттериңиз гана эмес. Көптөгөн ноутбуктар жана перифериялык түзмөктөр BIOS, SSD жана док-станциянын микропрограммаларын Linux Vendor Firmware Service аркылуу жеткирет, ал эми Omarchy менюсундагы _Жаңыртуу > Микропрограмма_ жабдууңузду күтүп турган жаңыртуулардын баарын жүктөп алып, орнотот. Биринчи жолу иштеткенде ал `fwupd` орнотот. Көп микропрограммаларды кайра жүктөө учурунда гана жазууга болот, ошондуктан кайра жүктөөнү суранса таң калбаңыз.

BIOS'тун өзүндө кандайдыр бир жөндөөнү өзгөртүү керек болгондо, тутум менюсунда (`Super + Escape`) `Alt` баскычын басып турсаңыз, _Кайра жүктөө_ пункту _BIOS ичине кайра жүктөө_ болуп өзгөрөт, ал жүктөлүүдө туура баскычты кармап калуунун кереги жок эле түз микропрограмманын жөндөөлөрүнө кайра жүктөйт. Терминалдан бул `omarchy system firmware`.

### pacman/yay менен түз жаңыртуу тууралуу эскертүү

Эгер Arch менен мурунтан тааныш болсоңуз, `pacman -Syu` же `yay -Syu` буйругун өзүңүз эле иштетип койгуңуз келиши мүмкүн, бирок андай кылсаңыз, Omarchy жаңы пакеттер менен бирге иштеткен снапшотту, миграцияларды жана конфигурация жаңыртууларын өткөрүп жибересиз. Ошол себептен Omarchy тутумду түз жаңыртууну чындыгында токтотуп, анын ордуна сизди `omarchy update` колдонууга багыттайт. (Эгер эмне кылып жатканыңызды чындап билсеңиз, коргоочу аны бир транзакция үчүн кантип айланып өтүүнү айтып берет.)

### Начар жаңыртууларды артка кайтаруу

Жаңыртуудан кийин кандайдыр бир көйгөй чыкса, тутумуңузду жаңыртуунун алдында алынган снапшотко кайтара аласыз. Жөн гана кайра жүктөп, жүктөгүч менюсунан жаңыртууну баштаганга чейинки снапшотту тандаңыз.

![bootloader](images/bootloader.webp)

Эгер кандайдыр бир жол менен конфигурация файлдарыңыз бузулуп калса, терминалда `omarchy reinstall` менен Omarchy'ни кайра орнотсоңуз да болот. Бул бардык демейки Omarchy пакеттерин кайра орнотот, сизди stable каналына (Apple Silicon'до edge) которот, өтө жаңы пакеттерди мурунку версияга түшүрөт жана бардык конфигурация файлдарын баштапкы абалга келтирет. Эске алыңыз: мындай кылганда Omarchy демейкилерине киргизген бардык колдонуучу конфигурация өзгөртүүлөрүңүздүн үстүнөн кайра жазылат!
