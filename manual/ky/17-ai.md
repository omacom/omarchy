# AI

Omarchy төмөндөгү код жазуучу агенттер үчүн иштеткичтерди камтыйт, бирок сиз үчүн демейкисин тандап бербейт. Бирөөсүн _Орнотуу > AI > CLI_ бөлүмүнөн орнотуп, сурап калганда аккаунтка кириңиз. Hermes менен OpenClaw — өзгөчө учурлар: алардын бирин тандасаңыз, өзүн өзү жаңыртып туруучу өз көчүрмөсү орнотулат, бул төмөндө _Иш столу тиркемелери_ бөлүмүндө түшүндүрүлөт.

### Агенттерди орнотуу жана жаңыртуу

Hermes менен OpenClaw'дон башка ар бир агент — Omarchy'нин өз репозиторийиндеги пакет. Бирөөсүн _Орнотуу > AI > CLI_ бөлүмүнөн же `omarchy install ai cli <command>` менен орнотуп, кайра _Алып салуу > AI > CLI_ аркылуу алып салыңыз, мында анын кирүү маалыматтары жана тарыхы ордунда калат. Азырынча орнотула элек агентти тандоо аны да орнотот: агенттер панелинде ага жылдызча коюу, аны `omarchy default agent <name>` менен тандоо же анын жазылуусуна кирүү. Omarchy агенттин ар бир жаңы чыгарылышын бир сааттын ичинде бардык каналдарга жарыялайт, жана `omarchy update` аны тутумдун калган бөлүгү менен кошо орнотот.

Аларды pacman жаңыртып тургандыктан, агенттердин өз жаңырткычтары өчүрүлгөн: `claude update` же тиркемедеги жаңыртуу баскычы эч нерсе кылбайт. Агентти анын өз орноткучунан иштеткениңиз жакшы болсо, ошону колдонуп, Omarchy'нин пакетин орнотпой коюңуз; `PATH` ичинде мурунтан эле бар көчүрмө орнотулган деп эсептелет. `PATH` ичинде Omarchy'дикинен алдыга экинчи көчүрмө коё турган `curl | bash` орноткучтарын, мисалы x.ai'нын `grok` үчүн орноткучун, колдонбоңуз.

`dsh` өзүнүн браузер интерфейсин `127.0.0.1:3080` дарегинде ачат, ишке киргизилген папка анын демейки иш мейкиндиги болот. Анын браузер интерфейси баштапкы промпт кабыл албайт, ошондуктан `omarchy agent prompt` аны промптту алмашуу буферине салып, чаптоого даяр абалда ачат. Omarchy аны DeepSeek'тин ырастоо сурабаган уруксат даярдамасы менен ишке киргизет. DeepSeek Harness анын расмий модель API'син колдонгондо сеанс журналдарын DeepSeek'ке жүктөйт; муну анын браузер интерфейсиндеги _Settings > General > Upload Session Log_ астында өчүрүңүз. Ага жөнөткөн пикириңиз да сеанс менен кошо жүктөлөт, эгер аны `DSH_TELEMETRY_MODE=DISABLED` менен ишке киргизбесеңиз.

### Демейки агент

Демейки агентиңизди агенттер панелиндеги агенттин жанындагы жылдызча менен тандаңыз, демейки агентте ал толтурулган болот, же `omarchy default agent <name>` менен тандаңыз, ал панелде сабы жок каалаган харнести да кабыл алат. Агент азырынча орнотула элек болсо, аны тандоо адегенде аны орнотот, жана ал тиркеме иштеткичте Agent'тин жанында өзүнүн өз иштеткичине да ээ болот. Жаңы Omarchy бир жолку билдирме менен бирөөсүн жөндөөгө чакырат, ал агенттер панелин ачат.

Claude'ду тандоо Chromium, Chrome, Brave, Brave Origin жана Edge үчүн анын браузер кеңейтүүсүн жөндөөгө да аракет кылат. Кеңейтүүнү жөндөө бардык колдонуучуларга тиешелүү жана тутумдук сырсөзүңүздү сурашы мүмкүн; жокко чыгарсаңыз же кеңейтүү орнотулбай калса да, Claude баары бир тандалып, ишке киргизилет. Аны туташтырууну бүтүрүү үчүн браузериңизди кайра иштетип, сураса кеңейтүүнү күйгүзүп, Claude'га кириңиз. Туташууну текшерүү үчүн Claude ичинде `/chrome` иштетиңиз. Firefox жана Zen бул кеңейтүүнү колдобойт. Эгер бул жөндөө кошулганга чейин эле Claude демейки агентиңиз болсо, кеңейтүүнү орнотуу үчүн аны кайра тандаңыз.

Тандагандан кийин, `Super + Shift + Ctrl + A` демейки агентти өзүнчө терминал терезесинде ишке киргизет (же азырынча тандай элек болсоңуз, тандагычты ачат). Аны түз эле тапшырма менен да ишке киргизсеңиз болот: `omarchy agent prompt "Review this project"`. Freebuff жана DeepSeek Harness баштапкы промпт кабыл албайт, ошондуктан алар анын ордуна промптту алмашуу буферине салып, чаптоого даяр абалда ачылат. Ушундай ишке киргизилген агенттер ар бири өзүнүн «уруксат сурабай токтобой иштей бер» режиминде көзөмөлсүз иштешет, ошондуктан алар чындап эле бир нерселерди жасап коёруна даяр болуңуз! MiniMax Code'дун интерактивдүү сеанстары үчүн мындай режими жок, ошондуктан ал адаттагыдай эле уруксат сурайт. Ал эми агенттер үй папкаңызга ишенимди эстеп калуудан баш тарткандыктан, `$HOME` ичинен ишке киргизилгендер анын ордуна `~/Work` ичинде башталат.

Терминал кыска жолдору да бар: `a` демейки агентти учурдагы терминалдын ичинде иштетет, ал эми `c`, `cx`, `cy` жана `ca` OpenCode, Claude Code, Codex жана Antigravity'ни түз ишке киргизет (бул жолу да алардын автоматтык ырастоо режимдеринде). Тема өзгөрүүлөрү агенттерге да шайкештирилет: Omarchy темасын алмаштырганыңызда Claude Code, Pi, OpenCode жана Hermes (Omarchy аны орноткондон кийин) баары ага ээрчишет.

### Агенттериңиздин нускамалары

Бардык агенттер үчүн жеке эрежелер `~/.agents/AGENTS.md` ичине, `~/.agents/skills` ичиндеги жалпы көндүмдөрдүн жанына жазылат. Аны агенттер панелиндеги + жанындагы документ белгиси менен же `omarchy agent instructions --edit` менен ачыңыз, ал аны өзүнүн глобалдык файлын кармаган ар бир харнеске да шилтеме кылып байлайт: `~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.pi/agent/AGENTS.md`, `~/.config/opencode/AGENTS.md`, Copilot'тун `~/.copilot/copilot-instructions.md` жана башкалар. Crush менен Amp `~/.config/AGENTS.md` шилтемесин окушат, ал эми omp, Kimi жана DeepSeek Harness `~/.agents/AGENTS.md` файлын түз окушат. Демейки агентти тандоо да аны байлайт. Мурунтан бар болгон нускамалар файлыңыз, эгер жалпы файл азырынча жок болсо, жалпы файл болуп калат; антпесе ал шилтеменин жанында `.bak` катары сакталат. Башка агентти орноткондон кийин кайра байлоо үчүн `omarchy agent instructions` иштетиңиз.

### Агенттер панели

Жогорку панелде агенттер белгиси бар. Агентти жөндөй электе, анын панели баштоонун үч жолун сунуштайт: Claude, Codex, Grok, Gemini, Muse, Cursor же Copilot жазылуусуна кирүү, же _Дагы_ астында OpenCode Go, MiniMax, Synthetic же Z.ai код жазуу планына кирүү; Fireworks, OpenCode Zen жана Go, OpenRouter менен, же _Дагы_ астында DeepSeek же OpenCode кире алган каалаган башка провайдер менен колдонгон сайын төлөө, булардын баары OpenCode ичинде иштейт; же компьютериңизге ылайыктуу модель бар болсо, ага эң жакшы моделди иштетүү. Биринчи бүтүргөнүңүз демейки агентиңиз болуп калат, ал эми панелдеги + кийин ушул эле үч жолду сунуштайт. Андан кийин панель бардык жазылууларды бир баракка чогултат: ар бир агент жана аккаунт өзүнүн планы менен, анын 5 сааттык сеанс жана апталык чектөөлөрүнүн ар бири үчүн өлчөгүч жана кайра жаңыланганга чейин калган убакыт менен (так пайызды көрүү үчүн үстүнө алып барыңыз), же калган алдын ала төлөнгөн каражат менен, баарында эмне колдонгонуңузду кезек-кезек көрсөткөн саптын астында, мисалы ушул аптадагы токендер жана эң көп колдонгон моделиңиз. _Сонун нерсе жаса_ астында ал жаңы тема, плагин, тиркеме же оюн үчүн тапшырманы демейки агентиңизге өткөрүп берген баштапкы промпттарды сунуштайт. Тиркемелер Omarchy'нин өз Hype, Monologue жана Omacut тиркемелери курулгандай, C++ жана Qt Quick менен, omarchy-make-app агент көндүмүнө ылайык курулат, жана аларга керектүү компилятор менен Qt бөлүктөрү орнотулган бойдон келет. Оюндар — `~/Games/vibes` ичиндеги бир three.js барагы, omarchy-make-game агент көндүмүнө ылайык жасалат, жана баары учурдагы темадагы бир Game Vibes иштеткичинен ачылат; алар three.js'ти интернеттен жүктөшөт, ошондуктан башталыш үчүн байланыш керек. Claude Code, Codex, Grok, Kimi, Cursor жана анын Grok Bot лимити, GitHub Copilot, Muse, Gemini (Antigravity аркылуу) жана Devin алгач эле чектөөлөрү менен камтылган, Kimchi өзүнүн планы, алдын ала төлөнгөн кредиттери жана чыгым бюджеттери менен камтылган, ал эми Hermes, Mistral Vibe жана Qwen Code аларды колдонгонуңуздан кийин сеанстарын жана токендерин көрсөтүшөт. pi, omp же opencode аркылуу колдонгон провайдер пландары жана ачкычтары да чыгат: OpenCode Zen жана Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan жана Synthetic чектөөлөрү менен; OpenRouter жана DeepSeek алдын ала төлөнгөн каражаттары менен; Fireworks акыркы 30 күндөгү чыгымы менен. Өзүңүздүн жабдууңузда иштеткен код жазуучу моделдер өз саптарына ээ болот, жана алардын токендери да жалпы эсепке кошулат, бул [Жергиликтүү моделдер](#local-models) бөлүмүндө сүрөттөлгөн. Ар бир агент, аны канча харнес аркылуу башкарсаңыз да, ага ким эсеп чыгарса ошонун астында бир гана жолу эсептелет.

Панелди ачуу үчүн панелдеги белгини сол баскыч менен басыңыз же `Super + Ctrl + X` басыңыз, демейки агентиңизди ишке киргизүү үчүн оң баскыч менен, жаңылоо үчүн ортоңку баскыч менен басыңыз. Анын артындагы колдонуу жазуулары ар 15 мүнөт сайын `omarchy agent usage update` тарабынан кайра түзүлөт, жана панель шайкештирилген папка аркылуу башка машиналарыңыздагы колдонууну да бириктире алат. Толук жөндөөлөр үчүн `$OMARCHY_PATH/shell/plugins/agents/` ичиндеги README'ни караңыз.

### Бир нече жазылуу

Эгер бирден ашык Claude, Codex же Grok планы үчүн төлөсөңүз — мисалы, жеке Max жана жумуштагысы — Omarchy алардын баарын кирген абалда кармап, ортосунда алмаштыра алат. Жазылууну агенттер панелиндеги + менен кошуңуз, ал сизди ошол жерде эле кадам-кадамы менен жетелейт, же `omarchy agent account add claude Work` менен кошуңуз (же `codex`, же `grok`). Ушул эле + жана буйрук Gemini (`gemini`) жана OpenCode'ко (`opencode`) кирет, ошондой эле Fireworks (`fireworks`) же OpenRouter (`openrouter`) API ачкычын OpenCode ичинде сактайт; буйрук Copilot (`copilot`), Cursor (`cursor`) жана Muse'ка (`muse`) да кирет. Алардын ар биринде бирден гана кирүү сакталат. CLI жок болсо, ал аны орнотот. Провайдер үчүн биринчи аккаунт кадимки браузериңиз аркылуу, CLI ар дайым караган жерде эле кирет. Андан кийинкилердин баары купуя терезе аркылуу кирет, ошондуктан браузериңизде мурунтан кирилген аккаунт жаңылыштык менен алынып калбайт; ал жерге кошуп жаткан аккаунтуңуз менен кириңиз, жана мурунтан ачык турган купуя терезеңиз болсо, адегенде аны жабыңыз. Муну жасоо үчүн CLI'дан эч качан чыкпаңыз: чыгуу сакталган кирүүнү жокко чыгарат, жана ал аккаунтту кайра кошууга туура келет.

Жазылуу кирүүлөрүңүздү SSH аркылуу башка Omarchy машинасына көчүрүү үчүн `omarchy agent account copy user@laptop` иштетиңиз. Эгер бара турган машинада кабыл алгыч орнотулбаса, жөнөтүүчү убактылуу кабыл алгычты өзү берет, ошондуктан эски Omarchy машиналары жаңыртуусуз эле аккаунттарды кабыл ала алат. Орнотулган кабыл алгычтар артыкчылыкка ээ. Бул бардык Claude, Codex жана Grok жазылууларын көчүрөт; тандоо үчүн провайдер аттарын кошуңуз, мисалы `omarchy agent account copy laptop claude`. Аккаунт аттары жана буйрук ID'лери булактагыдай болот, бара турган машинада мурунтан бар аккаунттарды кошо алганда. Бара турган машинадагы тиешеси жок аккаунттардын аттары кагылышса, аларга сандык кошумча берилет, ал эми жөндөөлөр, көндүмдөр, плагиндер жана маектердин тарыхы ар бир машинанын өзүндө калат.

Бара турган машинадагы бар кирүү маалыматтары сакталат. Ал жерде мурунтан кирилген булак аккаунтунун аты анын кирүү маалыматтары алмаштырылбастан шайкештирилет; башка аккаунттар анын жанына кошулат. Дал келген аккаунттардын сакталган кирүү маалыматтарын алмаштыруу үчүн, бара турган машинадагы ошол аккаунттун сеанстарынан чыккандан кийин `omarchy agent account copy --replace laptop claude` колдонуңуз. Жаңы бара турган машина булактын активдүү аккаунтун жана алмаштыруу жөндөөлөрүн да алат; мурунтан колдонулуп жүргөн машина өзүнүкүн сактап калат.

Кирүү маалыматтары SSH аркылуу өтүп, бара турган машинада купуя файлдарда сакталат, ошондуктан ишенген машиналарыңызга гана көчүрүңүз. Бул бир жолку көчүрүү, үзгүлтүксүз шайкештирүү эмес. Codex'тин жаңылоо токендерин башка машина алмаштырып коюшу мүмкүн, анда көчүрүлгөн кирүүнү жаңылоого туура келет; бир нече машинада бир убакта колдонуу үчүн өзүнчө кирүүлөр эң ишенимдүү тандоо бойдон калат. [Codex'тин аккаунт аутентификациясы боюнча колдонмосун](https://developers.openai.com/codex/auth/ci-cd-auth) караңыз.

Ар бир провайдер үчүн бир аккаунт активдүү болот, жана ар бир жаңы сеанс ошол аккаунт менен башталат: `cx`, `cy`, жөнөкөй `claude`, `codex` же `grok`, `omarchy agent` аркылуу ишке киргизилген каалаган нерсе, жана CLI'ды `PATH` ичинен тапкан скрипттер же редакторлор. `omarchy agent account use work` менен алмаштырыңыз (жана `omarchy agent account use main` менен кайра кайтыңыз), же панелде аккаунттун номерин басып, андан кийин `Enter` басыңыз (же анын жылдызчасын басыңыз). Иштеп жаткан Claude сеанстары да кийинки билдирүүсүнөн баштап алмашат: ар бир Claude сеансы `~/.claude` ичинде иштейт, ал ар дайым активдүү аккаунттун кирүүсүн кармайт. Эски Omarchy аккаунттун өз папкасында баштаган Claude сеансы ал жабылганга чейин ошол кирүүнү кармап турат, ошондуктан алмаштыруу ошол сеанстарды атап, алар жабылгандан кийин өзү эле аягына чыгат. Иштеп жаткан Codex жана Grok сеанстары кайсы аккаунт менен башталса, ошол бойдон калат. Маектердин тарыхы, жөндөөлөр, көндүмдөр жана плагиндер аккаунттардын ортосунда жалпы, ошондуктан ошол эле папкада `claude --continue` жаңы аккаунтта токтогон жериңизден улантат.

Бирден ашык аккаунт болгондо, панель ар бир аккаунттун чектөөлөрүн катар көрсөтөт, колдонулуп жаткан аккаунтта жылдызча толтурулган болот. Активдүү аккаунт чектөөнүн 95% ашканда Omarchy сизге билдирет, жана билдирмени басканда эң көп запасы бар аккаунтка алмашат. Ал эч качан өзүнөн өзү алмаштырбайт. Босогону `omarchy agent account threshold 90` менен өзгөртүңүз. Эгер бардык аккаунттар босогодон ашып кетсе, бул тууралуу бир жолу, кайсы аккаунт биринчи бошой турганы менен кошо кабар аласыз. Активдүү аккаунт босогосуна 15 пункттан азыраак калганда (демейки боюнча 80%), анын чектөөлөрү ар 15 мүнөттүн ордуна ар үч мүнөт сайын текшерилет.

`omarchy agent account list` ар бир аккаунтту жана анын акыркы чектөөлөрүн көрсөтөт, `omarchy agent account remove work` бирөөсүн унутат, ал эми `omarchy agent account rename primary Hey` бирөөсүнүн атын өзгөртөт (же панелде аккаунттун атын басыңыз). Бул буйруктар демейки агентиңиздин аккаунттары менен иштейт; башка провайдерге жетүү үчүн адегенде аны атаңыз, мисалы `omarchy agent account use codex side`. `~/.claude` же `~/.codex` ичинде мурунтан бар болгон кирүүңүз — бул _Main_ аккаунт. Codex'тики болгон жеринде калат; Claude'дуку башка аккаунт активдүү турганда өзүнчө папкада күтүп турат. Болжол менен сегиз сааттан ашык колдонулбай калган аккаунтта _Аккаунтка кирүү керек_ деп чыгышы мүмкүн; ошол аккаунтка панелдин өзүндө кайра кирүү үчүн аны басыңыз, же ага алмашып, сеанс баштаңыз, бул кирүүнү өзү эле жаңылайт. `claude mcp add` менен кошкон MCP серверлериңиз ар бир Claude аккаунтуна жетет, анткени алардын баары `~/.claude` ичинде иштейт; Codex жана Grok үчүн аккаунт кошулган учурда бар болгон серверлер ага кошо келет, бирок кийинкилери сиз аларды кошкон аккаунтка гана жетет. Claude Desktop өзүнүн өз кирүүсүн кармайт, ал эми CLI бинардык файлына абсолюттук жол менен жөндөлгөн Codex же Grok куралдары алмаштырууга ээрчибейт. Ачык коюлган `CLAUDE_CONFIG_DIR`, `CODEX_HOME` же `GROK_HOME` тандалган аккаунттан артыкчылыкка ээ.

### Кыйроолорду аныктоо

Omarchy процесстердин кыйрашын systemd-coredump аркылуу көзөмөлдөйт. Демейки агентти тандагандан кийин, сиздин кайсы бир программаңыз core dump калтырса, «Process crashed» билдирмеси келет — аны басыңыз, жана кыйроо Omarchy'нин omarchy-diagnose-crash көндүмү менен кошо демейки агентиңизге өткөрүлөт, ал көндүм агентти core dump'тан фактыларды аныктоо жана кыйроо тууралуу жогору жакка кабарлоого арзый турган-турбаганын чечүү аркылуу жетелейт. Муну `coredumpctl list` ичиндеги каалаган PID үчүн `omarchy agent crash <pid>` менен кол менен да иштетсеңиз болот.

Көзөмөлдөө демейки боюнча күйүк. Аны _Аракеттер > Которуу > Кыйроону каттоону өчүрүү_ астында (же `omarchy toggle crash-capture` менен) өчүрүңүз, ошондо билдирмелер токтойт; `omarchy agent crash <pid>` кол менен иштей берет.

Кыйроолорду программа боюнча бир-бирден да тынчытса болот, аныктоо аягында дал ушуну сунуштайт. `omarchy crash mute hyprland` ошол программа үчүн гана билдирмелерди токтотот, `omarchy crash mute hyprland off` аларды кайра кайтарат, ал эми жалгыз `omarchy crash mute` тынчыткандарыңызды тизмелейт. Ал бинардык файлдын жолун да анын аты сыяктуу эле кабыл алат, ошондуктан `omarchy crash mute /usr/bin/hyprland` ушул эле нерсени кылат. Аралыгы бар атты тырмакчага алыңыз, мисалы `omarchy crash mute 'Some App'`. Калгандарынын баары билдирмелерди жөнөтө берет, ал эми тынчытылган программа баары бир кыйрай берет — бул эскертмени гана жашырат, эч нерсени оңдобойт.

### Иш столу тиркемелери

_Орнотуу > AI > Desktop_ графикалык AI тиркемелерин камтыйт: Amp Desktop, Antigravity Desktop, ChatGPT иш столу тиркемеси, Claude иш столу тиркемеси (Anthropic'тин Linux үчүн бета нускасы, Chat, Cowork жана Claude Code өтмөктөрү менен), xAI'нын моделдери менен маектешүү үчүн Grok Bot, Herdr Desktop, Hermes Desktop, OpenClaw, Perplexity иш столу тиркемеси жана T3 Code. Grok Bot — бул иш столундагы маек тиркемеси. Код жазуучу агент болсо — `grok` буйругу.

Hermes Desktop тууралуу сөзсүз билип алыңыз, анткени машинада бир гана Hermes болот, жана ал тиркемеге таандык: Hermes тиркеме аркылуу гана орнотулат, жана демейки агент иштеткен `hermes` буйругу да тиркемеге таандык. Hermes'ти демейки агент катары тандоо _Орнотуу > AI > Desktop_ ичиндеги жазуу орноткон нерсенин дал өзүн орнотот: пакетти жана Hermes'тин өз орноткучу `~/.hermes` ичинде жөндөгөн Hermes чөйрөсүн, биринчи жолу бул бир нече мүнөткө созулат. Ал чөйрө — терминалдагы `hermes` буйругу, демейки агент жана тиркеме колдонгон жалгыз Hermes, жана ал Omarchy чыгарылышын күтпөй, `hermes update` менен өзүн өзү жаңыртат. Аны орнотуу Hermes'ке Omarchy темасын `omarchy` деген аталыштагы скин катары да берет, тема алмаштырганыңызда Hermes'тин ар бир бети ага ээрчийт; андай болушун каалабасаңыз, Hermes'тин Appearance жөндөөлөрүнөн же `/skin` менен башкасын тандаңыз, Omarchy ал тандооңузга тийбейт. Тиркемени _Алып салуу > AI > Desktop_ астында алып салуу адегенде Hermes'ти, шлюзу менен кошо жабат, ошол чөйрөнү кошо алып кетет, жана башкача айтмайынча маектериңизди, эскерүүлөрүңүздү жана Hermes өзү үчүн жазган көндүмдөрдү сактап калат: ал ошол маалыматтар жана туташуу жөндөөлөрүңүз да өчүрүлсүнбү деп сурайт, демейки жооп — жок.

OpenClaw'дун иш столундагы тажрыйбасы — бул анын Control UI'ы, ал өзүнүн жергиликтүү шлюзуна таянган веб-тиркеме катары ачылат. OpenClaw `~/.openclaw` ичинде жашайт жана өзүн өзү жаңыртат: Control UI'дагы «Update Gateway» баскычын колдонуңуз же `openclaw update` иштетиңиз, ошондо шлюз жаңы нускада кайра иштейт. Omarchy жаңы орнотуу кайсы чыгарылыштан башталарын гана тандайт. OpenClaw демейки агентиңиз да боло алат: аны `omarchy default agent openclaw` менен тандоо `~/.openclaw` ичинде ошол эле көчүрмөнү жөндөйт, жана агент OpenClaw'дун шлюзуна туташкан терминал интерфейсин ачат. OpenClaw'ду _Алып салуу > AI > Desktop_ астында алып салуу шлюз кызматын жана тиркемени кошо алып кетет, андан кийин `~/.openclaw` да өчүрүлсүнбү деп сурайт, анткени анда OpenClaw'дун өзү жана ал жүктөгөн плагин чөйрөлөрү менен катар маектериңиз жана кирүү маалыматтарыңыз сакталат; демейки боюнча ал сакталат, жана OpenClaw'ду кайра орнотсоңуз, аны кайра колго алат.

Herdr Desktop — бул [Herdr](https://herdr.dev) иш столу тиркемеси: терезени жапсаңыз да анын өзөгүндө иштей берген терминалдардын жана код жазуучу агенттердин мейкиндиктери, өтмөктөрү жана панелдери. Ал пакеттен эмес, Herdr'дин өз орноткучунан келет, ошондуктан ал `~/.local/share/herdr-app` ичинде жашайт, эгер сизде өзөк жок болсо, аны `~/.local/bin/herdr-core` ичине кошо алып келет, жана экөөнү тең өзү жаңыртат. Ал Omarchy `Super + Ctrl + Return` баскычына берген `herdr` буйругунун ордун баспай, анын жанында турат жана ошол буйруктун түз баскычтарын алат: `Alt + Return` жана `Alt + Shift + Return` панелди ылдый же оңго бөлөт, `Alt + Escape` аны жабат, `Ctrl + Alt + Arrow` панелдердин ортосунда жылдырат, `Alt + 1..9` жана `Alt + Left/Right` өтмөктү тандайт, ал эми `Alt + Up/Down` мейкиндиктердин ортосунда жылдырат. `Ctrl + 1..9` мейкиндикти тандайт, ал эми `Alt + Shift + Up/Down` агенттерди бирден аралап өтөт. `Ctrl + Space` префикс баскычтары терминалда гана калат, анткени тиркеме ырааттуулук үчүн жөнөкөй Ctrl баскычын кармап тура албайт. Omarchy буларды `~/.config/herdr-app/keys.json` ичине жазат, ал эми `omarchy-refresh-herdr-app` аларды кайра ордуна коёт. Аны орнотуу Herdr'дин Omarchy темасын тандайт, ал андан ары Omarchy темаңызга ээрчийт. Herdr жарык режим үчүн бир теманы, караңгы режим үчүн бир теманы кармайт, ошондуктан караңгы жана жарык Omarchy темасынын ортосунда алмашкандан кийин, экинчи режим үчүн Herdr'дин тема тандагычынан Omarchy'ни дагы бир жолу тандаңыз.

T3 Code пакеттен эмес, `~/.local/share/t3code` ичиндеги расмий AppImage чыгарылышынан иштейт, ошондуктан өзүн өзү жаңыртат. Аны орнотуп жатканда Stable же Nightly каналынан баштоону сурайт; кийин T3 Code'дун жөндөөлөрүнөн алмаштырсаңыз болот. Тредлериңиз жана жөндөөлөрүңүз `~/.t3` ичинде жашайт, жана T3 Code'ду _Алып салуу > AI > Desktop_ астында алып салуу аларды кошо алып кетет.

### Жергиликтүү моделдер

Код жазуучу агенттериңиз үчүн ачык моделди өзүңүздүн машинаңызда иштетиңиз. Промпттарыңыз жана кодуңуз машинада калат; моделге жөнөтүлгөн эч нерсе андан чыкпайт. Баштоо үчүн:

```bash
omarchy models use best text
```

Бул ушул машина үчүн эң жакшы текст моделин жөндөйт, агенттериңиз дал ушундай моделди колдонушат. Сүрөт, видео жана музыка моделдеринин да өз эң жакшылары бар: `omarchy models use best image`, `video` же `music`. Ушул машина үчүн ар бир түрдүн тандоосун көрүү үчүн `omarchy models use best` иштетиңиз.

Же агенттер панелинде + тандаңыз: _Жергиликтүү моделди колдонуу_ астында ал ушул машинага туура келген ар бир код жазуучу моделди тизмелейт, сунушталганы биринчи турат. Моделдерди иштеткен Podman Omarchy менен кошо келет, NVIDIA машинасында аларга GPU берген NVIDIA'нын контейнер куралдары да ошондой; алардын бири жок болсо, биринчи жөндөө аны орнотот. Андан кийин Omarchy ушул машина үчүн сунушталган моделди тандап, аны жүктөп алып, ишке киргизет. Ондогон GB жүктөө жана модель иштеп турганда машинанын эсинин көбү ээленерин күтүңүз: Flash Next толук 256K контексти менен болжол менен 100 GiB колдонот. Эгер ага керектүү эсти башка моделдер ээлеп турса, ал токтотулган абалда жөндөлөт, бирөөсүн токтотконуңузда иштөөгө даяр болот. Модель сеанстан чыкканда токтойт; эсти башка нерсеге керек болгондо аны өзүңүз токтотуңуз.

`omarchy models list` варианттарды көрсөтөт жана айрымдары эмне үчүн туура келбей турганын түшүндүрөт. Башкасын жөндөө үчүн `omarchy models use <recipe>` иштетиңиз. Бүгүнкү күндө 128 GB Strix Halo машиналары үчүн `qwen3.8-flash-next-gufo` жана `qwen3.8-27b-gufo` жеткиликтүү; 27B болжол менен 40 GiB алат, ошондуктан башка иштерге орун калтырат. Intel'дин Arc B390 менен 64 GB ноутбукта `qwen3.6-35b-a3b-llamacpp` болжол менен 30 GiB менен иштейт. Жаңы рецепттер жана сунуштар `omarchy update` менен, пакет аркылуу келет.

Сиз кошкон код жазуучу модель агенттер панелинде жазылууларыңыздын жанында өз сабына ээ болот: аны иштетүү үчүн ойнотуу, токтотуп, эсин бошотуу үчүн тыным, иштеп турганда аны tailnet'иңиздеги башка машиналар менен бөлүшүү үчүн Tailscale белгиси, жана агентиңизди анда ачуу үчүн терминал баскычы. Анын сабы жүктөө, ишке киргизүү же токтотуу жүрүп жатканын көрсөтөт, ишке киргизүү үчүн бош эс жетишпесе ошону айтат, же ката менен токтоп калса анын журналдарына шилтеме берет. Эске чогуу батса, бир нечеси бир убакта иштей алат. Моделди жүктөлгөн файлдары менен кошо бул машинадан алып салуу үчүн тандалган сапта Delete басыңыз; + аны кайра жөндөй алат. Терминалдан жөндөлгөн код жазуучу модель сиз аны кошконго чейин + астында күтүп турат, сиз жупташкан машина (`omarchy models pair <host>`) иштеткен моделдер да ошондой.

Сиз жөндөгөн ар бир код жазуучу модель тиркеме иштеткичте да моделдин аты жана аны жасагандын логотиби менен өз жазуусуна ээ болот, Claude, Codex же Grok'ко киргенде бирөө кошулгандай эле. Ал агентиңизди ошол моделде ачат, эгер модель иштебей турса, адегенде аны ишке киргизет: терминал анын жүктөлүп жатканын көрсөтүп, ал иштеп баштаганда башкарууну агентке берет. Моделди алып салсаңыз, анын жазуусу да алынып салынат.

Бардык моделдер эле код жазуу үчүн эмес. Сүрөт, видео жана музыка моделдери анын ордуна Fantasi'де ачылат, бул ушул машинада иштеген модель менен сүрөт, видео жана музыка жасоо үчүн Omarchy'нин тиркемеси, жана алар ошол жерде же `omarchy models` менен башкарылат.

Модель кандай жөндөлсө, так ошондой иштей берет, ошондуктан Omarchy жаңыртуусу агенттериңиздин астындагы моделди эч качан кайра иштетпейт. Omarchy'де сиз жөндөгөн модель үчүн жаңыраак чөйрө же жаңыраак салмактар пайда болгондо, анын сабында жаңыртуу баскычы чыгат: аны бассаңыз, модель фондо кайра жөндөлөт, өзгөргөнүн гана жүктөп алат жана жаңы нускада кайра иштейт. Токтотулган модель токтотулган бойдон калат. `omarchy models update` терминалдан ар бир модель үчүн ушул эле нерсени кылат.

Буйрук сабынан `omarchy models start <recipe>` жана `omarchy models stop <recipe>` ушул эле нерсени кылат, `omarchy models status` ар бир моделди көрсөтөт, ал эми `omarchy agent --local-model <recipe>` демейки агентиңиз кандай болбосун, ошол моделди pi ичинде ачат. Агент баскыч айкалышы, Quake консолу жана _Сонун нерсе жаса_ жергиликтүү моделиңизди ачышы үчүн `omarchy default agent local` иштетиңиз же агенттер панелинде иштеп турган моделге жылдызча коюңуз. pi да өзүнүн модель тандагычында сиз жөндөгөн ар бир моделди жана сиз жупташкан машиналардагы моделдерди тизмелейт, ошондуктан жөнөкөй `pi` да аларга жетет. OpenAI менен шайкеш каалаган кардар да туташа алат: `status` ар бир моделдин дарегин көрсөтөт (биринчиси `http://127.0.0.1:11435/v1`), рецепттин аты — модель, ал эми ачкыч `~/.config/omarchy/agent-local/key` ичинде.

`omarchy models remove <recipe>` моделди жана башка эч бир модель колдонбогон жүктөлгөн файлдарды өчүрөт.

Үчүнчү тараптын чөйрөлөрү чыгаруучусунун аты менен белгиленет. Omarchy ар бир моделди тармакка эч кандай жетүүсүз иштетет.

### Жергиликтүү LLM'дер

Omarchy жергиликтүү LLM моделдерин иштетүүнүн эки жолун сунуштайт: LM Studio жана Ollama. LM Studio ачык салмактуу моделдерди табуу, орнотуу жана иштетүү үчүн GUI интерфейсин берет. Бул оңой баштоонун сонун жолу. Ollama ушуну эле кылуу үчүн CLI сунуштайт. Бирок жергиликтүү моделдерге жаңы болсоңуз, мен LM Studio'дон баштамакмын. Omarchy менюсунда LM Studio'ну _Орнотуу > AI > Desktop_ бөлүмүнөн, Ollama'ны _Орнотуу > AI > CLI_ бөлүмүнөн орнотуңуз.

### Omarchy көндүмдөрү

Агент көндүмдөрү AI'га белгилүү куралдарды белгилүү бир жол менен колдонууга жардам берет, жана Omarchy алардын жетөөсү менен келет. omarchy көндүмү тутумду ыңгайлаштырууну камтыйт, мисалы Hyprland конфигурацияңызды оңдоо же панелди тууралоо. omarchy-make-theme, omarchy-make-plugin, omarchy-make-app жана omarchy-make-game жаңы бир нерсе жасоону камтыйт, omarchy-contribute катаны кабарлоону же оңдоону жогору жакка жөнөтүүнү камтыйт, ал эми omarchy-diagnose-crash кыйроонун core dump'ын иликтейт. Алар Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` жана ар бир `~/.hermes/profiles/*/skills`) үчүн көндүм папкаларына жана жалпы `~/.agents/skills` жайгашкан жерине символдук шилтеме менен байланган, ошондуктан көпчүлүк харнестер аларды автоматтык түрдө табышат. Ушундай эле аталыштагы өзүңүздүн көндүм папкаңыз артыкчылыкка ээ.

Бирок бул көндүмдөргө эксперименттик нерсе катары мамиле кылышыңыз керек. Ар кандай моделдер аларды ар кандай натыйжа менен колдонушат. Агент эмнени өзгөрткүсү келерин түшүнүп алышыңыз үчүн, адегенде пландоо режиминде иштеткен жакшы. Андан кийин, агент баарын чаташтырып жиберсе, өзгөрүүлөрдү артка кайтарууга, ал тургай `omarchy reinstall configs` чакырууга даяр болуңуз.
