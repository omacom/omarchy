# Mac же Windows'тон келгендер үчүн

Эгер macOS же Windows'ко көп жылдарыңызды берген болсоңуз, манжаларыңыз мээңиз качандыр бир кезде үйрөнгөнүн да унутуп калган жүздөгөн нерселерди билет. Бул бөлүм — котормочу катмар: ошол адаттар Omarchy'де кайда өтөт. Мүмкүнчүлүктөрдүн өзү башка бөлүмдөрдө кеңири жазылган — бул жөн гана карта.

### Super — баарынын борбору

Cmd же Windows баскычынын тегерегинде калыптанган булчуң эс тутумуңуздун баары бир баскычка өтөт: Super. Бул PC баскычтобундагы Windows баскычы, ал Omarchy'деги дээрлик ар бир ыкчам баскычтын таянычы.

Spotlight, Raycast же Start менюсуна жетүү адатыңыз `Super + Space` болуп калат. Ал Omarchy менюсун ачат, ал тиркемелерди ишке киргизет, жөндөөлөрдү өзгөртөт, программаларды орнотот, экранды тартат — дээрлик баарын кылат. Чыпкалоо үчүн тере баштаңыз. `Super + Alt + Space` Launchpad сыяктуу эле бардык тиркемелерди бир торчодо көрсөтөт. [Навигация](04-navigation.md) бөлүмүн караңыз.

### Иш столунда белгилер жок, ал эми док эркин режимде гана чыгат

Иш столунда тизип коё турган белгилер жок, тизилген иш мейкиндигинде док да жок — док эркин иш мейкиндигинде гана пайда болот ([навигация](04-navigation.md) бөлүмүн караңыз). Тиркемелер ыкчам баскыч менен (терминал үчүн `Super + Return`, браузер үчүн `Super + Shift + Return`, ал эми байланыштырылган нерселердин баарынын тизмеси үчүн `Super + K`) же менюдан ишке кирет. Дайыма көрүнүп турган жалгыз интерфейс бөлүгү — [жогорку панель](05-the-top-bar.md), ал мурда меню тилкеси, тутумдук трей жана Notification Center сиз үчүн аткарган ишти аткарат — анын дээрлик ар бир виджети сол, оң жана ортоңку баскыч менен басканда бир нерсе кылат.

### Терезелер өздөрү орношот

Ой жүгүртүүдөгү эң чоң өзгөрүү: терезелерди сүйрөп жүрбөйсүз жана экрандын жарымына жабыштырбайсыз. Терезени ачсаңыз, ал бүт экранды ээлейт. Экинчисин ачсаңыз, экөө экранды бөлүшөт. Бир терезени экинчисинин астынан издеп отурбайсыз, анткени терезелер бири-бирин жаппайт.

Чындап эркин терезе керек болгондо, `Super + T` активдүү терезени тизүүдөн чыгарат (жана кайра киргизет). Бирок адегенде тизүүгө чыныгы мүмкүнчүлүк бериңиз — бул бүт системанын жүрөгү. [Навигация](04-navigation.md) сизди аны менен тааныштырат.

Иш мейкиндиктери тааныш сезилет: алар macOS'тогу Spaces же Windows'тогу виртуалдык иш столдору, бир гана айырмасы — аларды чындап колдоносуз, анткени `Super + 1/2/3/4` түз эле бирине өткөрөт, ал эми `Super + Shift + 1/2/3/4` активдүү терезени ошол жакка жөнөтөт. Анимациянын кечигүүсү жок, жөн эле ошол замат өтөсүз. Демек, мурда бир нече мониторго көнгөн болсоңуз, балким алар сизге керек да болбой калат.

### Көчүрүү жана коюу жөн эле иштейт

Mac'та Cmd + C бардык жерде иштечү. Windows'то Ctrl + C бардык жерде иштечү — терминалдан башка, ал жерде ал программаңызды өлтүрөт. Omarchy сизге `Super + C`, `Super + X` жана `Super + V` берет, алар бардык жерде, анын ичинде терминалда да иштейт. Шел үчүн өзүнчө адат үйрөнүүнүн кереги жок.

Windows колдонуучулары: Win + V алмашуу буферинин тарыхыңыз `Super + Ctrl + V` баскычында турат, ал текст менен кошо сүрөттөрдү да сактайт. [Бирдиктүү алмашуу буфери жана тарыхы](08-unified-clipboard-history.md) бөлүмүн караңыз.

### Кээ бир нерселер чындап эле башкача

Көп жөндөөлөр басып өтө турган панелдерде эмес, сиз оңдой турган текст файлдарында жашайт. Бул эскирген ыкмадай угулат, бирок ар бир өзгөртүүнү көрүүгө, кийинки машинаңызга көчүрүүгө жана версияларды башкаруу тутумуна салууга болорун түшүнгөнгө чейин гана. _Жөндөө_ менюсу сизди түз эле керектүү файлга алып барат жана иш бүткөндө кайра иштетилиши керек болгондун баарын кайра иштетет.

Жаңыртуулар бир буйрук аркылуу келет — _Жаңыртуу > Omarchy_ — ал Omarchy'нин өзүн жана тутумдагы ар бир пакетти жаңыртат, адегенде снапшот алып коюп. Капысынан тажатып турган ар бир тиркеменин өз жаңырткычы жок. [Жаңыртуулар](30-updates.md) бөлүмүн караңыз.

Программалар жүктөлүп алынган орнотуучулардан эмес, пакет менеджеринен келет.

Ошондой эле терезени жапканда тиркеме чындап эле жабылат. Программа бир да терезеси жок эле иштей берген macOS'тогудай белгисиз абал жок. `Super + W` — же манжаларыңыз ошого көнгөн болсо, `Super + Q` — жок болду дегенди билдирет.

### Mac жабдууларында

Omarchy Intel Mac'тарында, ошондой эле Omarchy for Apple Silicon менен M1, M2 жана M3 Mac'тарында жакшы иштейт. [Mac колдоосу](44-mac-support.md) бөлүмүн караңыз. Баскычтоп да сизге жайлуу: Omarchy эч нерсени кайра дайындабайт, ал эми Linux Command баскычын Super катары кабыл алат, ошондуктан Super дал мурда Cmd турган жерде турат. Бармагыңыз бул өзгөрүүнү байкабайт да.

### Ага эки жума убакыт бериңиз

Адаттар ойлогонуңуздан тезирээк өтөт. [Ыкчам баскычтар](07-hotkeys.md) бөлүмүн бир жолу карап чыгыңыз, ал эми кайсы бир айкалыш эсиңизден чыгып калганда, `Super + K` басыңыз — ал баарын көрсөтөт. Чындап жаттап алышыңыз керек болгон жалгыз ыкчам баскыч ушул.
