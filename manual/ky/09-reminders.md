# Эстеткичтер

Omarchy'де билдирүүсү бар, тескери саноочу таймерге негизделген жөнөкөй эстеткичтерди коюунун орнотулган жолу бар. Муну `Super + Ctrl + R` аркылуу жасасаңыз болот, коюлгандардын баарын `Super + Ctrl + Alt + R` менен көрүп, баарын `Super + Ctrl + Shift + R` менен тазалайсыз. Мунун баары _Аракеттер > Эстеткич_ аркылуу да жеткиликтүү. Терминалдан да колдонсоңуз болот: `omarchy reminder 7 'Tea ready'`.
