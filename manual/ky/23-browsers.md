# Браузерлер

Omarchy демейки браузер катары [Google Chrome](https://www.google.com/chrome/) менен келет. Ал тутумуңуздун калган бөлүгүнө ылайык жасалгаланган, `Super + Shift + Return` (же `Super + Shift + B`) ачкан да ушул, купуя терезе үчүн `Super + Shift + Alt + B`, ар бир [веб-тиркеме](25-web-apps.md) да анын ичинде иштейт. Ал түз эле браузер терезеси болуп ачылат: эч кандай саламдашуу экраны же кирүү сунушу жок, колдонуу статистикасы жана кыйроо отчеттору Google'га жөнөтүлбөйт, жарнамалык купуялык суроолору өчүрүлгөн. Синхрондоо керек болгондо каалаган убакта профиль баскычынан Google аккаунтуңузга кире аласыз.

Эгер Chrome жакпаса, аны менен гана чектелбейсиз. Omarchy менюсундагы _Орнотуу > Браузер_ бөлүмүнөн [Chromium](https://www.chromium.org/) (Chrome жасалган жөнөкөй ачык булактуу курама), Edge, Brave, Brave Origin, Firefox жана [Zen](https://zen-browser.app/) табасыз (Edge x86 машиналарында гана). Бирөөнү тандасаңыз, Omarchy аны орнотуп, анын саясат папкасын жөндөйт жана ага учурдагы темаңызды колдонот.

## Бирөөнү демейки кылуу

Браузерди орнотуу аны демейки кылбайт. Алмаштыруу үчүн _Жөндөө > Демейкилер > Браузер_ бөлүмүнө барып, бирөөнү тандаңыз. Учурдагы демейки браузер белги менен белгиленген, ал эми азырынча жок браузерди тандасаңыз, адегенде ал орнотулат.

Терминалдан мындай:

```bash
omarchy default browser firefox
```

Аны аргументсиз иштетсеңиз, учурдагы демейкини айтат. Бул XDG иштеткичин коёт, ошондуктан аны Omarchy'нин баскыч айкалыштары гана эмес, шилтеме ачкан бардык нерсе — чат тиркемесинен баштап терминал буйругуна чейин — ээрчийт: баары сиз тандаган браузерге барат.

## URL көчүрүү жана видео жүктөө

Chromium үй-бүлөсүндөгү браузерлер (Chromium өзү, Chrome, Edge, Brave жана Brave Origin) Omarchy'нин үч кеңейтмеси менен келет: экөө браузерден чыгып, тутумуңуздун калган бөлүгүнө жетет, ал эми бирөө WhatsApp'ты иретке келтирет.

**Copy URL** `Alt + Shift + L` менен учурдагы өтмөктүн дарегин алмашуу буфериңизге салат. Бул дарек тилкесин басып, көчүрүүдөн тезирээк, ал эми браузердин эмес, тутумдун алмашуу буфери аркылуу өткөндүктөн, муну ырастаган Omarchy билдирмесин аласыз жана URL ошол замат [алмашуу буферинин тарыхында](08-unified-clipboard-history.md) жана башка бардык тиркемелерде жеткиликтүү болот. Басканды жактырсаңыз, куралдар тилкесинде баскычы да бар.

**Download Video** `Alt + Shift + D` менен сиз карап жаткан барактагы ойноп жаткан видеону жүктөп алат. Ал URL'ди [yt-dlp](https://github.com/yt-dlp/yt-dlp) куралына берет, ошондуктан YouTube'дан башка дагы көп сайттарда иштейт, ал эми жүктөлгөн файл `~/Videos` ичине түшөт. Жүрүшү үн жана жарыктык колдонгон ошол эле экрандагы көрсөткүчтө чыгат, билдирмелер үйүлүп калбай, ошол эле жерде жаңыланып турат. Файлдар башка жакка түшсүн десеңиз, `OMARCHY_YTDLP_DIR` коюңуз — чөйрө өзгөрмөлөрүн кайда жазуу керектигин [FAQ](46-faq.md) бөлүмүнөн караңыз.

Эки кеңейтме тең Omarchy менен кичинекей native messaging хосту аркылуу байланышат, ал браузер менен кошо сиз үчүн орнотулат. Веб барактагы видеонун үй папкаңызга, URL'дин алмашуу буферин башкаргычка түшүшүнө ушул бөлүк мүмкүндүк берет, кадимки кеңейтме муну өз алдынча жасай албайт.

**WhatsApp Slim** WhatsApp Web'ти тутумуңуздун темасына ылайыкташтырат жана терезе тар болгондо анын чаттар тизмесин жыйнап коёт.

Булар Chromium үй-бүлөсү үчүн гана. Firefox менен Zen аларды албайт.

## Firefox жана Zen

Firefox менен Zen башка үй-бүлөгө кирет, ошондуктан аларга башкача мамиле жасалат: Omarchy акылга сыярлык демейки жөндөөлөр үчүн саясат файлын орнотуп, аларды Wayland'дын өз режимине которот, бөлчөктүү масштабдоо жана сенсордук тактада жылмакай жылдыруу үчүн дал ушул керек.

Аларга жогорудагы Chromium кеңейтмелери берилбейт, Omarchy аларды жасалгалабайт да, ошондуктан тажрыйбанын ал бөлүктөрүн өзүңүз жөндөйсүз.

## Кайра алып салуу

Бул браузерлердин каалаганын, Chrome'ду да кошо, _Алып салуу > Браузер_ бөлүмүнөн алып салсаңыз болот. Андан кийин шилтемелер Chrome же Chromium'дун кайсынысы орнотулуп калса, ошого барат.
