# Shell функциялары

Omarchy кеңири кездешкен иштерди жеңилдетип, татаал параметрлүү чакырууларды жашырган shell функцияларынын топтому менен келет.

## Кысуу

- `compress [file/dir]`: Файлдан же папкадан tar.gz архивин түзөт.
- `decompress [file.tar.gz]`: tar.gz файлын ачат.

## Дисктер

- `iso2sd [image.iso]`: Көрсөтүлгөн iso файлды колдонуп, SD картада жүктөлүүчү диск түзөт, дискти интерактивдүү тандатат.
- `format-drive [device] [name]`: Бүт дискти бир exFAT бөлүмү менен форматтайт (ал Windows'та жана macOS'то да иштейт). Жеткиликтүү дисктерди көрүү үчүн аны аргументсиз иштетиңиз. Абайлаңыз!

## Иштеп чыгуу калыптары

tmux үчүн бир нече панелдүү иштеп чыгуу калыптары, заматта:

- `tdl [ai]`: Редакторуңуз, AI агенти жана терминал менен Tmux Dev Layout түзөт. Агенттердин кыска аттарын колдонуңуз, мисалы opencode үчүн `tdl c`, Claude Code үчүн `tdl cx`, же экөөнү тең иштетүү үчүн экинчи агентти кошуңуз, мисалы `tdl c cx`.
- `tds`: Редактор, өзгөрүүлөрдү көзөмөлдөө (`hunk diff --watch` аркылуу), терминал жана opencode менен Tmux Dev Square түзөт.
- `tdlm [ai]`: Учурдагы папкадагы ар бир ички папка үчүн `tdl` терезесин түзөт.
- `tsl [count] [command]`: Торчо болуп тизилген, баары бир эле буйрукту иштеткен панелдердин тобун түзөт (AI агенттери үчүн сонун).

Ошол эле калыптар Herdr үчүн `hdl`, `hds`, `hdlm` жана `hsl` катары бар.

## Git worktree'лер

- `ga [branch]`: Учурдагы репозиторийдин жанынан жаңы worktree жана бутак түзүп, ага өтөт.
- `gd`: Учурдагы worktree'ни жана анын бутагын өчүрөт (адегенде ырастоону сурайт).

## Rsync көзөмөлчүлөрү

- `rsw [source] [destination]`: Бир нерсе өзгөргөн сайын булакты көздөгөн жерге rsync менен көчүргөн фондук көзөмөлчүнү баштайт. Көздөгөн жер алыскы хост да болушу мүмкүн, мисалы `rsw ~/Work/app nyc-dev:Work/app`.
- `lsw`: Бардык активдүү көзөмөлчүлөрдүн тизмесин көрсөтөт.
- `dsw`: Бардык активдүү көзөмөлчүлөрдү токтотот.

## SSH порт багыттоо

Алыскы машинага каршы localhost'тун коопсуз контекст артыкчылыктары менен веб иштеп чыгуу үчүн идеалдуу.

- `fip`: Алыскы хосттон бир же бир нече портту SSH аркылуу localhost'ко багыттайт.
- `dip`: Багытталган бир же бир нече портту ажыратат.
- `lip`: Бардык активдүү SSH порт багыттоолорун көрсөтөт.

Мисалы, `nyc-dev` деп кирүүгө боло турган машинада `3000` портунда иштеп чыгуу серверин баштадыңыз дейли, анда ошол портту багыттоо үчүн `fip nyc-dev 3000` иштетсеңиз болот, ошентип `localhost:3000` чындыгында `nyc-dev:3000` дарегине жетет, бирок веб сокеттерди же ушул сыяктууларды сыноо үчүн керектүү коопсуз контекстти түзүүгө SSL сертификаттарынын кереги жок.

## SSH кайра туташуу

`ssh` өзү функцияга оролгон: эгер алыскы tmux, Herdr же редактор терминалды ээлеп турганда байланыш үзүлүп калса, ал терминалды тазалайт, андан кийин интерактивдүү сеанс үзүлгөндө автоматтык түрдө кайра туташат (Ctrl-C кайра аракет кылуу циклин токтотот).
