# Навигация

Omarchy'де баары баскычтоп аркылуу жасалат — _БААРЫ!_ Тутум биринчи жолу күйгөндө, бир гана чычкан менен чындап эле эч нерсе кыла албайсыз. Бирок `Super + Space` басып Omarchy менюсун ачсаңыз болот, ал жерден дээрлик баарын кыла аласыз.

Бирок Omarchy менюсу көбүнчө тутумду башкаруунун негизги жолу болуп да эсептелбейт. Мындан да ылдамыраак иштесе болот! Эң маанилүү тиркемелердин баары өз-өзүнчө ыкчам баскычтарга байланган. Терминалды `Super + Return` менен, браузерди `Super + Shift + Return` менен ачасыз. Аларды бирин артынан бирин ачып көрүңүз, Hyprland'дин терезелерди тизүүсүнүн сыйкырын өз көзүңүз менен көрөсүз:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

Андан кийин `Super + J` басып, аларды катар эмес, бирин-биринин үстүнө тизсеңиз болот:

 ![navigation-stacked](images/navigation-stacked.webp)

Аларды кайра катар коюу үчүн `Super + J` дагы бир жолу басыңыз. Андан соң браузерде турганда `Super + Shift + Arrow Right` басып, терезелердин ордун алмаштырып көрүңүз.

Эми `Super + Shift + T` басып, Иш-аракеттер мониторун ачып көрүңүз. Ал эркин терезе болуп ачылат. Аны `Super + T` менен тизүүгө кошсоңуз болот (кайра эркин терезе кылуу үчүн дагы бир жолу басыңыз). Эми `Super + Shift + F` басып, файл башкаргычты ачыңыз. Экраныңыз төрт бөлүккө сонун бөлүнөт:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

Кайсы терезе активдүү болсун десеңиз, `Super + Arrow` менен ага өтөсүз. Бул фокусту которуп, курсорду жаңы тиркеменин ортосуна жылдырат. Экрандын четине жеткенде, ошол тараптагы мониторго өтүп кетет.

`Super + Shift + 2` бассаңыз, фокустагы тиркеме экинчи иш мейкиндигине жылат. `Super + Shift + 1` аны кайра ордуна кайтарат. (Ал эми `Super + Shift + Alt + 2` фокустагы тиркемени экинчи иш мейкиндигине ага өтпөстөн жылдырат).

Бир нече монитор болсо, ар бир мониторго 1ден 10го чейинки өз иш мейкиндиктери бар. `Super + 2` сиз турган монитордун экинчи иш мейкиндигине өткөрөт, ар бир монитордун жогорку панели өз иш мейкиндиктерин жана азыр кайсынысы көрсөтүлүп жатканын көрсөтөт. `Super + Tab` сиз турган монитордун иш мейкиндиктерин кезек менен которот. `Super + Shift + Ctrl + Arrows` сиз турган терезени ошол тараптагы мониторго, анда көрсөтүлүп жаткан иш мейкиндигине жылдырат, ал эми `Super + Shift + Alt + Arrows` сиз турган иш мейкиндигин ошол тараптагы мониторго көчүрөт, эгер ошол номер бош болсо, ал ошол эле номерди алат. Мониторду ажыратканда анын иш мейкиндиктери жоголбойт: алар башка экрандын иш мейкиндиктерине кошулуп, андагы бар иш мейкиндиктерден кийинки номерлерди алышат, ал эми монитор кайра туташканда мурунку номерлерине кайтышат.

`Super` баскычын басып туруп чычкан менен терезени чыкылдатсаңыз, анын ордун өзгөртө аласыз. `Super` баскычын басып туруп чычкандын оң баскычын колдонсоңуз, терезенин өлчөмүн каалагандай өзгөртө аласыз.

Терезени `Super + W` же `Super + Q` менен жабасыз (бардык терезелерди `Ctrl + Alt + Delete` менен жабасыз).

Ошондой эле `Super + F` менен толук экранга, `Super + Alt + F` менен жөн гана толук тууралыкка (жогорку панель көрүнүп турат) же `Super + Ctrl + F` менен терезенин ичинде толук экранга өтсөңүз болот (YouTube үчүн ыңгайлуу!).

### Dwindle жана жылдыруу жайгашуусу

Omarchy'нин демейки жайгашуусу dwindle деп аталат. Ал бир иш мейкиндигинде ачкан бардык терезелериңизди, аларды кичирейтүүгө туура келсе да, дайыма көрүнүп турушун камсыз кылат.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

Бирок иш мейкиндигин жылдыруу жайгашуусуна которсоңуз да болот, анда терезелер экрандын көрүнгөн четинен ары карай катар тизилет. Бир иш мейкиндигин бул жайгашууга `Super + L` менен которосуз.

`Super + L` дагы бир жолу басылганда, иш мейкиндиги эркин режимге өтөт: терезелер бири-биринин үстүнө эркин түшөт, аларды өзүңүз жайгаштырасыз, ал эми үчүнчү басуу аны кайра dwindle'ге кайтарат. `Super + Alt + L` аларды тескери тартипте которот. Баары бир эркин турган терезе — `Super + T` менен бөлүп чыгарганыңыз же дайыма эркин ачылган тиркеме — иш мейкиндиги кайра тизүүгө өткөндө да эркин бойдон калат. Жогорку панель сиз турган иш мейкиндигин анын жайгашуусунун белгиси менен көрсөтөт: dwindle үчүн чарчы, жылдыруу үчүн тегерек, эркин режим үчүн үч бурчтук. Ошол белгини чыкылдатуу да жайгашууну которот, экран баскычы бар ноутбуктарда ал баскыч да ошентет.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

Тандоо ар бир иш мейкиндиги үчүн өзүнчө жана ал сакталып калат. Ошентип 1-иш мейкиндигин интернет кыдыруу үчүн dwindle'де, 2-иш мейкиндигин код жазуу үчүн жылдыруу жайгашуусунда калтырсаңыз болот, кайра күйгүзгөндөн кийин да алар ошол бойдон кайтып келет.

Эгер жылдыруу жайгашуусун демейки кылгыңыз келсе, аны `~/.config/hypr/looknfeel.lua` файлында коюуга болот:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### Эркин иш мейкиндиктери

Эркин иш мейкиндиги салттуу иш тактасындай иштейт: терезелер бири-биринин үстүнө түшөт, аларды өзүңүз жылдырып, өлчөмүн өзүңүз өзгөртөсүз. Ар бир терезенин темаңыздын түстөрүндөгү аталыш тилкеси болот, анда кичирейтүү, чоңойтуу жана жабуу баскычтары бар. `Super + M` да фокустагы терезени кичирейтет. Кичирейтилген терезе докто күтүп турат; аны кайтаруу үчүн тиркемесин чыкылдатыңыз. Терезени алдыга чыгаруу үчүн аны чыкылдатыңыз. Анын өлчөмүн каалаган четинен же бурчунан өзгөртөсүз. Аталыш тилкесин эки жолу чыкылдатсаңыз, терезе жогорку панелди көрүнүп калтырып чоңоёт, дагы эки жолу чыкылдатсаңыз мурунку өлчөмүнө кайтат. Chrome жана Chromium негизиндеги башка браузерлер, Disks жана Document Viewer аталыш тилкесин колдонбой, өздөрүнүн башын колдонушат; аларды `Super + Alt + F` чоңойтот, `Super + M` кичирейтет.

Эркин иш мейкиндигинде док да көрүнөт, анда бекитилген тиркемелериңиз, иштеп жаткан нерселердин баары жана тиркемелер баскычынын артында бардык тиркемелердин торчосу бар, аны `Super + Alt + Space` жана Omarchy менюсундагы _Тиркемелер_ да ачат. Тиркемени орнотуудан чыгаруу үчүн торчодо аны оң баскыч менен чыкылдатыңыз же `Delete` басыңыз. Тиркемени ачуу же анын терезесин алдыга чыгаруу үчүн аны чыкылдатыңыз; анын терезелерин кезек менен которуу үчүн дагы чыкылдатыңыз. Files сиз турган иш мейкиндигиндеги терезени гана кайтарат, болбосо жаңысын ачат, ал эми Terminal менен Agent дайыма дагы бирөөнү ачат, бирок кичирейтилген терезе биринчи кайтат. Ортоңку баскыч менен чыкылдатуу жаңы терезе ачат. Белгини доктун боюнда сүйрөп жылдырсаңыз болот; иштеп жаткан тиркемени башкалардын арасына сүйрөп койсоңуз, ал ошол жерде калат. Тиркемени докто калтыруу, доктон алып салуу же жабуу үчүн оң баскыч менен чыкылдатыңыз. Док толук экрандагы терезеге тоскоол болбойт. Докту башка четке жылдыруу же курсор анын четине жеткенге чейин жашырып коюу үчүн тиркемелер баскычын оң баскыч менен чыкылдатыңыз. Жайгашуусу _Көрүнүш > Док > Доктун жайгашуусу_ бөлүмүндө да бар, ал эми `omarchy dock position left` жана `omarchy dock autohide on` экөөнү тең терминалдан коёт. Докто калтырган тиркемелериңиз иштебей турганда күңүртүрөөк көрүнөт.

Жаңы иш мейкиндиктери жана `Super + L` менен өз жайгашуусу берилбеген иш мейкиндиктери демейки жайгашууну колдонот. Демейкини өзгөртсөңүз, терезеси жок бардык иш мейкиндиктери ага которулат, ал эми терезеси бар иш мейкиндиги учурдагы жайгашуусун сактайт. Докко кичирейтилген терезе өзү чыккан иш мейкиндигиндеги терезе катары эсептелет. Аны _Көрүнүш > Иш мейкиндигинин жайгашуусу_ бөлүмүнөн тандаңыз: Тизүү, Жылдыруу же Эркин. `omarchy hyprland workspace layout default scrolling` аны терминалдан коёт.

### Терезелерди топтоо

Терезелерди `Super + G` менен топтоого болот. Топко киргенден кийин, ал активдүү турганда ачкан ар бир терезеңиз ошол топко кирет. Топтогу терезелердин ортосунда `Super + Ctrl + Arrow Left/Right` менен жылсаңыз болот, же `Super + Alt + 1/2/3/4` менен топтогу терезелерге тартиби боюнча түз өтсөңүз болот.

Терезени топтон `Super + Alt + G` менен чыгарсаңыз болот, же `Super + G` дагы бир жолу басып, бүт топту тарката аласыз. Акырында, топтун сыртындагы терезелерди `Super + Alt + Arrows` менен топко кошсоңуз болот.

### Терезелерди бөлүп чыгаруу

Терезени иш мейкиндигинен `Super + O` менен бөлүп чыгарсаңыз болот. Ал аны эркин терезе катары бекитет, кайсы иш мейкиндигине барбаңыз, ал сизди ээрчип жүрөт. Видео ойноткучтар жана ушул сыяктуулар үчүн абдан ыңгайлуу.

 ![navigation-popped-window](images/navigation-popped-window.webp)

### Убактылуу иш мейкиндиги

Сиз учурда турган иш мейкиндигинин үстүнө чыга турган, толук өлчөмдүү атайын убактылуу иш мейкиндиги бар. Андагы нерселерди `Super + S` менен ачасыз, ал эми терезелерди ага `Super + Alt + S` менен жайгаштырасыз.

Ал учурдагы иш мейкиндигинен чыкпай туруп тез колдонгуңуз келген башкаруу элементтери же терминал үчүн жакшы ылайыктуу.

### Quake консолу

Акырында, сиз учурда турган иш мейкиндигинин үстүнө түшө турган, экрандын жарымындай бийиктиктеги Quake консолу бар. Аны `Super + Tab үстүндөгү баскыч` (US жайгашуусунда grave) менен ачып-жабасыз, ал эми терезени ага `Super + Shift + Tab үстүндөгү баскыч` менен жайгаштырасыз.

Биринчи жолу ачылганда, ал демейки агентиңизди иштетет, же эгер азырынча тандай элек болсоңуз, бирөөнү тандоону сурайт. Консолдо бир гана терезе турганда, ал экранды бүт ээлебей, ортодо турган панель болуп түшөт. Ага экинчи тиркемени койсоңуз, ал кайра толук тууралыкка кайтат, ошентип экөө катар турууга орун табылат.

Терезени убактылуу иш мейкиндигинен же консолдон алып салуу үчүн, аны `Super + Shift + 1` сыяктуу баскычтар менен түз эле башка иш мейкиндигине жөнөтүңүз.

### Көнүү үчүн бир аз убакыт керек!

Иш тактаңызды ушундай башкарууга көнүү үчүн бир аз убакыт керек, бирок көнүп алгандан кийин салттуу, чычкан менен башкарылган иш тактасына кайтуу кыйын болот!
