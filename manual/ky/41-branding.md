# Өзгөчө белгилер

Omarchy жүктөлүүдөгү кулпуну ачуу экранына, экран сактагычка жана «Тутум жөнүндө» экранына компанияңыздын логотибин же жеке сүрөтүңүздү коюуга мүмкүндүк берет.

### Жүктөлүүдөгү кулпуну ачуу

Өз логотибиңиз жана түстөрүңүз кандай көрүнөөрүн көрүү үчүн `omarchy plymouth preview` колдонсоңуз болот. Ал фон түсүн, текст түсүн, png логотипти жана алдын ала көрүнүш сүрөтү үчүн жолду кабыл алат:

```
omarchy plymouth preview '#1d2021' '#ebdbb2' logo.png preview.png
```

Андан кийин жөндөөнү `omarchy plymouth set '#1d2021' '#ebdbb2' logo.png` менен колдонуңуз, бул SDDM кирүү экранына да ошол эле түстөрдү жана логотипти берет. Мурдагы абалга кайтаруу үчүн `omarchy plymouth reset` колдонсоңуз болот.

 ![branding-plymouth-shopify](images/branding-plymouth-shopify.webp)

### Экран сактагыч

Экран сактагычта колдонулган логотипти _Көрүнүш > Өзгөчө белгилер > Экран сактагыч_ бөлүмүнөн өзгөртсөңүз болот. Бул ASCII логотип, ошондуктан текстти түз түзөтсөңүз болот, бирок ага png же svg сүрөт да берсеңиз болот, биз аны ASCII'ге айландырабыз. Абдан сонун көрүнөт.

 ![branding-screensaver](images/branding-screensaver.webp)

Ал менюда үч пункт бар:

- **Текстти түзөтүү** `~/.config/omarchy/branding/screensaver.txt` файлын редакторуңузда ачат. Каалаганыңызды териңиз же чаптаңыз — ASCII арт, атыңыз, орой сөз. Сактап, чыгып кетсеңиз, экран сактагыч ошол замат иштеп, аны көрө аласыз.
- **Сүрөттөн коюу** png же svg үчүн файл тандагычты ачып, аны ASCII'ге айландырат жана натыйжасын көрсөтөт. Так силуэти бар логотиптер сүрөттөргө караганда алда канча жакшы чыгат.
- **Демейкисин кайтаруу** Omarchy логотибин кайра коёт.

### «Тутум жөнүндө» экраны

Omarchy менюсунан ачылган _Тутум жөнүндө_ экраны үчүн ошол эле үч вариант _Көрүнүш > Өзгөчө белгилер > Тутум жөнүндө_ бөлүмүндө турат жана так ошондой иштейт — файл `~/.config/omarchy/branding/about.txt`, ал эми ар бир өзгөртүүдөн кийин «Тутум жөнүндө» терезеси ачылат. «Тутум жөнүндө» арты экран сактагычтыкынан кичирээк өлчөмгө айландырылат, анткени ал экраныңызды толтурбай, терезеге батышы керек.

Терезе ачык турганда, ар бир нече секунд сайын арттын үстүнөн ачык ак жарык тилкеси кыйшайып өтүп, кайра аны тынч калтырат. Сиздин өз артыңыз да аны алат, эгер андагы ар бир белги бир мамыча кеңдикте болсо — _Сүрөттөн коюу_ чыгарган нерселердин баары ошондой. Эмодзиден же эки эселенген кеңдиктеги белгилерден курулган арт кыймылсыз калат, ошондой эле өзүңүздүн fastfetch жөндөөңүздү колдонсоңуз, экран да кыймылсыз калат: мындай учурларда кыймылсыз логотип анимациянын бузулганы эмес, жолтоо болбой четке чыгып турганы, анткени аларга жылтылды жылдырып өтсө, саптын калган бөлүгү туура эмес жерге түшүп калмак.

### Сүрөттөрдү өзүңүз айландыруу

_Сүрөттөн коюу_ варианттарынын экөө тең жөн гана `omarchy transcode ascii` чакырат, айландырууну көзөмөлдөгүңүз келсе, аны түз иштетсеңиз болот:

```
omarchy transcode ascii ~/logo.svg ~/.config/omarchy/branding/screensaver.txt --width 100
```

Ал терминалдык мамычалар жана саптар менен `--width` жана `--height`, `braille` (демейки, бир кыйла тагыраак) же `block` болгон `--mode`, кайсы пикселдер логотиптин бөлүгү экенин чечүү үчүн пайыз менен `--threshold`, жана логотибиңиз караңгы фондо ачык түстө болгондо `--invert` кабыл алат. Эгер айландыруудан кийин логотип бүдөмүк так болуп калса, адатта бурай турган тетик — ушул threshold.

### Логотиптин ордуна сөздөр

`omarchy ascii` текстти Delta Corps Priest 1 менен тартат, бул Omarchy'нин өз сөз белгиси тартылган FIGlet шрифти, ошентип экран сактагыч сүрөт көрсөтпөй, бир нерсе айта алат:

```
omarchy ascii "Back in five" > ~/.config/omarchy/branding/screensaver.txt
```

Ал текстти аргументтер катары алат, же аргумент берилбесе, түтүктөн окуйт. Шрифтте тамгалар жана боштуктар гана бар — ал сандарсыз жана тыныш белгилерисиз тартылган — ошондуктан калганы таштаталат жана жымжырт жутулуп кетпей, stderr'де аталат.
