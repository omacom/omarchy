# Иштеп чыгуу куралдары

## Альтернативдүү редакторлор

Omarchy жаңы орнотууларда демейки редактор катары Plain менен келет жана [Neovim](https://neovim.io/) алдын ала орнотулган, бирок бир аз кеңири тараган жана тааныш бир нерсе кааласаңыз, Omarchy менюсун (`Super + Space`) ачып, _Орнотуу > Редактор_ ичиндеги варианттарды карап көрүңүз. Ал жерде VSCode, Cursor, Zed, Sublime Text, Helix, Vim жана Emacs бар. Издегениңизди таппасаңыз, _Орнотуу > Пакет_ ичинен Arch пакети катары жок бекенин текшериңиз (ал жерде да жок болсо, AUR'ду текшерүү үчүн _Орнотуу > AUR_ колдонуп көрүңүз).

Түпнуска `vi` редактору да кутудан чыгары менен жеткиликтүү. Терминалда файлды түзөтүү үчүн `vi filename` иштетиңиз.

Тема шайкештиги `VSCode`, `Cursor`, `VSCodium` жана `Helix` үчүн сунушталат.

Тутум боюнча демейки редакторду `Setup > Defaults > Editor` ичинен коё аласыз.

## Чөйрө

Omarchy менюсунун (`Super + Space`) _Орнотуу > Программалоо_ бөлүмү аркылуу Omarchy иштеп чыгуу чөйрөлөрүнүн бүтүндөй бир тобун жөндөөнү колдойт. Албетте, ал жерден _Ruby on Rails_ табасыз, бирок ошондой эле JavaScript үчүн үч негизги иштетүү чөйрөсүнүн баарын (Node.js, Bun, Deno), жана Laravel, Symfony сыяктуу популярдуу PHP фреймворкторун да табасыз. Айтмакчы, Go, Rust, Python, Java, Elixir (Phoenix менен), .NET, OCaml, Zig, Clojure жана Scala да бар. Тандоо абдан кенен!

Бул чөйрөлөрдүн көпчүлүгүн [Mise](https://mise.jdx.dev/) башкарат. Бул бир эле машинада программалоо тилинин бир нече версиясын орнотуп, иштетүүгө мүмкүндүк берген курал. Ruby үчүн rbenv же rvm, же Python үчүн virtualenv сыяктуу, бирок ал ар кандай чөйрөлөрдүн бир тобу үчүн иштейт.

Мисалы, Ruby'ни орнотуу үчүн `mise use -g ruby` иштетесиз, ал Ruby'ни орнотуп, аны глобалдык демейки катары да коёт. Же долбооруңузда .ruby-version файлы болсо, ошол долбоордун тамырында жөн гана `mise i` иштетсеңиз болот.

## Алдын ала орнотулган CLI куралдары

`uv`, Node.js жана `playwright-cli` (агенттер орнотулган Chrome аркылуу браузерди башкарышы үчүн) пакет катары орнотулуп келет, ал эми `omarchy update` аларды тутумдун калган бөлүгү менен бирге жаңыртып турат. [Hunk](https://github.com/modem-dev/hunk) жана GitHub, Basecamp, Cloudflare жана HEY CLI'лери _Орнотуу > CLI_ ичинде бир тандоо аралыкта, ал эми [коддоо агенттери](17-ai.md) _Орнотуу > AI > CLI_ ичинде.

mise сиз _Орнотуу > Программалоо_ ичинен жөндөгөн иштетүү чөйрөлөрүн гана башкарат; Omarchy ал аркылуу өз алдынча эч нерсе орнотпойт. Аларды Omarchy'нин калган бөлүгү менен бирге жаңыртуу үчүн `omarchy update` иштетиңиз; `mup` алиасы mise башкарган куралдарды гана жаңыртат. Өз конфигурацияңызга дагы бир курал кошуу үчүн `mise use -g <tool>` колдонуңуз.

## Docker

[Docker](https://www.docker.com/) дээрлик тааныштырууну талап кылбайт. Ал обочолонгон контейнерлерди иштетүүгө мүмкүндүк берет, ал эми Omarchy аны жакшы иштетүү үчүн керектүүнүн баарын, анын ичинде Docker'дин өзүн жана [Docker Compose](https://docs.docker.com/compose/) орнотот.

Демейки боюнча колдонуучуңуз `docker` тобунда *жок*. Ал топ иш жүзүндө сырсөзсүз root — анда турган ар кандай нерсе `docker run -v /:/host` аткарып, машинаны ээлеп ала алат — ошондуктан сиздин атыңыздан иштеген бир эле жаман скрипт же көз карандылык root'ко бир гана буйрук аралыкта калмак. Ошол себептен командалык сапта Docker'ди `sudo` менен иштетесиз (`sudo docker ps`, `sudo docker compose up`), ал эми демонго кайрылган графикалык куралдар — Windows VM — керек болгондо уруксат сурашат. Эгер топсуз жөндөөнүн ыңгайлуулугун кайтаргыңыз келсе жана анын баасын түшүнсөңүз, аны **Жөндөө > Коопсуздук > sudo талап кылбаган Docker** ичинен күйгүзүңүз (же `omarchy-setup-security-sudoless-docker` иштетиңиз), ал эскертүүдөн кийин сизди `docker` тобуна кошот; андан кийин жөнөкөй `docker` жана `d` алиасы кайрадан `sudo` жок иштейт.

Жергиликтүү иштеп чыгуу үчүн кеңири колдонулган маалымат базаларын Docker'де Omarchy менюсундагы _Орнотуу > Программалоо > Docker DB_ аркылуу жөндөй аласыз.

## GitHub CLI

[GitHub CLI](https://cli.github.com/) — бул `gh`, терминалдан репозиторийлер, issue'лар жана pull request'тер менен иштөө үчүн. _Жөндөө > Git_ ал жерден GitHub'ка кирүүнү тандаганыңызда аны орнотот, же аны өзүнчө _Орнотуу > CLI > GitHub_ ичинен орнотуңуз. Андан кийин `gh repo clone org/repo` репозиторийди клондойт; анын буйруктарын изилдөө үчүн `gh --help` иштетиңиз.

[Lazygit](https://github.com/jesseduffield/lazygit) Git'тин өзү менен иштөө үчүн алдын ала орнотулган.
