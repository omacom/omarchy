# Мониторлор

Omarchy демейки боюнча сиз 2x масштабды көтөрө алган retina деңгээлиндеги дисплейде иштейсиз деп эсептейт. Ошол жагымдуу, так программист шрифттерин алуу үчүн дал ушул керек. Бийик чечилиштеги экраны бар дээрлик бардык жаңы премиум ноутбуктар дал ушуга ылайыкташтырылган. 27 дюймдук 5K [Apple Studio Display](https://www.apple.com/studio-display/)/[ProArt PA27JCV](https://www.asus.com/us/displays-desktops/monitors/proart/proart-display-5k-pa27jcv/)/[Samsung S9](https://www.samsung.com/us/computing/monitors/5k/27-viewfinity-s9-5k-monitor-with-thunderbolt-4-matte-display-and-smart-features-ls27c900panxza/)/[Kuycon G27P](https://kuycon.us/monitors/G27P/) же 32 дюймдук 6K [Apple XDR](https://www.apple.com/pro-display-xdr/)/[ProArt PA32QCV](https://www.asus.com/displays-desktops/monitors/proart/proart-display-6k-pa32qcv/)/[Kuycon G32P](https://kuycon.us/monitors/G32P/) мониторунда да дал ушундай иштегиңиз келет.

Бирок дисплейиңиздин PPI көрсөткүчү 218ден төмөн болсо, монитордун жөндөөлөрүн өзгөртүшүңүз керек. Мисалы, 27 же 32 дюймдук 4K мониторуңуз болсо, жогорку панелдеги монитор панелинен ага бөлчөк масштаб тандай аласыз, же `~/.config/hypr/monitors.lua` файлын ачып, ошол айкалыш үчүн сунушталган маанини коюп, бардык мониторлор үчүн демейки маанини орното аласыз:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.6 })
```

1080p же 1440p дисплей колдонсоңуз, балким 1x масштаб эле жетиштүү болот, GTK жана X11 тиркемелери үчүн да ошондой, ошондуктан муну колдонсоңуз болот:

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1 })
hl.env("GDK_SCALE", "1")
```

`GDK_SCALE` өзгөртүүлөрү өзгөртүүдөн кийин ишке киргизилген тиркемелерге гана таасир этет (жана GTK бүтүн сандарды гана кабыл алат, ошондуктан аны монитордун масштабына эң жакын бүтүн санда калтырыңыз). Ошондуктан өзгөртүүдөн кийин ашыкча чоң болуп калган терезелерди сөзсүз жаап коюңуз (же `Ctrl + Alt + Del` менен бардык терезелерди жабыңыз!).

Ошондой эле негизги масштаб коэффициенттеринин (1x, 1.25x, 1.6x, 2x, 3x, 4x) арасында тез которулуп турсаңыз болот: жогорулатуу үчүн `Super + /`, төмөндөтүү үчүн `Super + Alt + /` басыңыз, же жогорку панелдеги монитор панелинен тандаңыз. Булар учурда фокуста турган мониторду гана өзгөртөт, ошондуктан ноутбуктун экраны менен тышкы дисплейдин ар биринин өз масштабы боло алат. Панел ар бир монитордун чечилишин, жаңылануу жыштыгын жана бурулушун да коёт. Тандоолоруңуз ошол физикалык монитор үчүн `~/.local/state/omarchy/monitors/settings` ичинде сакталат, ошондуктан алар кайра жүктөөдөн кийин да жоголбойт жана монитор кийинки жолу кайсы портко же док-станцияга сайылса да, аны менен кошо жүрөт. Алар ошол эле монитор үчүн `~/.config/hypr/monitors.lua` ичиндеги ар кандай эрежеден үстөм турат, ал файлды болсо Omarchy эч качан оңдобойт. Мониторлоруңузду толугу менен ошол файлда жөндөгүңүз келсе, ага `omarchy_monitor_panel_settings = false` кошуңуз, ошондо панелдин өзгөртүүлөрү Hyprland кайра жүктөлгөнгө чейин гана сакталат. `GDK_SCALE` бардык экрандар үчүн бир гана маани болгондуктан, тандалган масштаб аны эң кичине масштабдагы монитордун негизинде коёт, ошондуктан X11 тиркемелери экинчи экранда ашыкча чоң болуп калгандын ордуна, тыгызыраак экранда бир аз кичинерээк чыгат.

### Текстти чоңойтуу же кичирейтүү

Монитордун масштабы баарынын өлчөмүн өзгөртөт. Эгер сизге болгону _текстти_ чоңураак же кичинерээк кылуу керек болсо, ал үчүн бир эле тетик бар:

```
omarchy display text size 14
```

Ал 9 менен 20 ортосундагы пиксел өлчөмүн кабыл алат жана Omarchy шелин, GTK тиркемелерин жана терминалыңызды чогуу өзгөртөт, ошондуктан бүт иш столу пропорциясын сактайт. Учурдагы абалды көрүү үчүн аны аргументсиз иштетиңиз, ал эми демейки мааниге кайтуу үчүн `omarchy display text size reset` колдонуңуз. Артта калган жалгыз Foot: анын конфигурациясын кайра жүктөөгө эч мүмкүнчүлүгү жок, ошондуктан иштеп жаткан терминалдар жаңысын ачмайынча эски өлчөмүндө калат.

### Ноутбуктун дисплейлерин кеңейтүү жана кайталоо

Ноутбугуңузга тышкы экран туташтырганда, дисплей автоматтык түрдө кеңейтилет. Бирок муну жогорку панелдеги монитор панелиндеги _Кеңейтүү_ | _Кайталоо_ аркылуу, Omarchy менюсундагы _Аракеттер > Жабдуулар_ аркылуу же `Super + Ctrl + Alt + Delete` менен кайталоого алмаштырсаңыз болот. Бул өзгөчө тышкы экран проектор болуп, иштеп жатып бир нерсе көрсөткүңүз келгенде пайдалуу.

Кеңейтүү режиминде ноутбуктун капкагын жапканда ички экран автоматтык түрдө өчөт. Капкакты ачканда ал кайра күйөт. Муну Omarchy менюсундагы _Аракеттер > Жабдуулар_ же `Super + Ctrl + Delete` аркылуу кол менен да башкара аласыз.

### Бир нече экранды жайгаштыруу

Hyprland бир нече экран менен абдан жакшы иштейт. Жогорку панелдеги монитор панели аларды кандай турса, ошондой тартып көрсөтөт: бирин экинчисинин капталына сүйрөп барсаңыз, ал ошол жакка жылат, ал эми жайгашуу ар бир монитордун башка жөндөөлөрү менен кошо сакталат. Панел камтыбаган нерселер үчүн аларды кантип жайгаштыруу керектиги тууралуу [Hyprland монитор документациясынан](https://wiki.hypr.land/Configuring/Basics/Monitors/) окуңуз. Omarchy'де булар `~/.config/hypr/monitors.lua` ичине `hl.monitor` жазуулары катары жазылат — файлда мониторду өчүк калтыруу, панелде жок режимдер, 10-биттик түс жана өзгөрмө жаңылануу жыштыгы үчүн комментарийге алынган мисалдар бар.

Ар бир монитордун өзүнүн 1ден 10го чейинки иш мейкиндиктери бар, ошондуктан `Super + 1` ар дайым сиз турган монитордун биринчи иш мейкиндигин билдирет. Көшөгө артында Hyprland иш мейкиндиктерин дагы эле бардык мониторлор боюнча номерлейт: ноутбуктун экраны (же биринчи монитор) 1–10ду алат, кийинки монитор 11–20ны, жана ушул тартипте уланат, ар бир монитор ар бир жолу сайылганда өз блогун сактап калат. Белгилүү бир монитор үчүн [иш мейкиндик эрежелерин](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) же терезе эрежелерин жазсаңыз, ошол номерлерди колдонуңуз, демек 12-иш мейкиндиги экинчи мониторуңуздун экинчи иш мейкиндиги болот. Ар бир монитордо кайсы блок бар экенин `~/.local/state/omarchy/monitors/workspaces` тизмелейт.

Жебе баскычтары жайгашууңузда жалпы чети бар мониторлор арасында иштейт. Бурчу менен гана тийишкен же арасында боштук бар экрандар коңшу эсептелбейт, ошондуктан алардын ортосунда өтүү үчүн `Ctrl + Alt + Tab` колдонуңуз.

| Ыкчам баскыч | Мониторлор арасында |
| --- | --- |
| `Super + Arrow` | Ошол багытта терезе калбаганда, фокусту ошол тараптагы мониторго жылдырат |
| `Super + Shift + Arrow` | Ошол тараптагы монитордогу терезе менен ордун алмаштырат |
| `Super + Alt + Arrow` | Терезени ошол тараптагы монитордогу топко жылдырат |
| `Super + Shift + Ctrl + Arrow` | Терезени ошол тараптагы мониторго, анда көрүнүп турган иш мейкиндигине жылдырат |
| `Super + Shift + Alt + Arrow` | Иш мейкиндигин ошол тараптагы мониторго жылдырат, номери бош болсо аны сактап калат |
| `Ctrl + Alt + Tab` / `Ctrl + Alt + Shift + Tab` | Жайгашуу кандай болбосун, фокусту кийинки же мурунку мониторго жылдырат |
| `Super + 1-0`, `Super + Tab`, `Super + Scroll Wheel` | Сиз турган монитордун чегинде калат |

Бир нече экранды жайгаштырууга жардам бере турган TUI керек болсо, [Hyprmon](https://github.com/erans/hyprmon/) куралын да карап көрсөңүз болот.

### Жарыкты башкаруу

Монитордун жарыгы жарыкты көбөйтүү/азайтуу үчүн атайын функциялык баскычтар менен башкарылат. Аларды басып жатканда Shift баскычын кармап турсаңыз, жарык эң жогорку же эң төмөнкү деңгээлге өтөт. Баскычтар сиз фокуста турган дисплейди башкарат, ошондуктан DDC/CI колдогон тышкы мониторлор ноутбуктун экраны сыяктуу эле жөнгө салынат.

### Apple дисплейлери

Apple дисплейин колдонуп, фокусуңуз ошол Apple дисплейинде болсо, баскычтоптун кадимки жарык баскычтары да автоматтык түрдө иштейт. Бул `asdcontrol` буйругу аркылуу ишке ашат.

Apple 6K XDR дисплейин колдонсоңуз, `hyprctl monitors` тизмесинде елес экран пайда болушу мүмкүн экенин эске алыңыз. Аны `~/.config/hypr/monitors.lua` ичинде `hl.monitor({ output = "DP-2", disabled = true })` сыяктуу жазуу менен өчүрсөңүз болот.

Intel машиналарында Apple дисплейлерине кадимки Thunderbolt кабели менен туташышыңыз керек. Thunderbolt'у жок башка машиналарда иштетүү үчүн адатта [DP + USB-A -> USB-C кабели](https://www.amazon.com/dp/B0BNX7MS6N) керек болот.
