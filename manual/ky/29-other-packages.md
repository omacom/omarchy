# Башка пакеттер

Arch'та расмий репозиторий менен Arch User Repository (AUR) экөөнүн ортосунда дээрлик ар кандай программага ылайык укмуштуудай көп пакет бар.

Экөөнү тең колдонуу абдан жеңил. Жаңы Arch пакетин орнотуу үчүн Omarchy менюсунда (`Super + Space`) _Орнотуу > Пакет_ бөлүмүнө барып, керектүү пакеттин атын терип коёсуз. Бардык пакеттердин тизмеси автоматтык түрдө бүдөмүк издөө менен чыпкаланат. (Муну терминалда `omarchy pkg add [package]` аркылуу кол менен да жасасаңыз болот).

AUR менен да ушундай эле кыласыз, болгону _Орнотуу > AUR_ колдонуңуз. Бир гана нерсени эстен чыгарбаңыз: AUR'ду Arch командасы текшербейт. Ал RubyGems же npm сыяктуу. Ага каалаган адам жүктөй алат.

Эгер пакетти алып салгыңыз келсе, Omarchy менюсунан _Алып салуу > Пакет_ колдонсоңуз болот. Ал пакетти, анын конфигурация файлдарын жана көз карандылыктарын алып салат. (Муну `omarchy pkg drop [package]` аркылуу кол менен да жасасаңыз болот).
