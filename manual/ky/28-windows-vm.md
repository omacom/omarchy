# Windows VM

Omarchy x86_64 машиналарында Windows'ту Docker VM аркылуу оңой иштетүүнүн жолун сунуштайт. Аны Omarchy менюсундагы (`Super + Space`) _Орнотуу > Windows_ аркылуу орното аласыз.

Бул үчүн машинаңызда KVM виртуалдаштыруусу болушу керек, көпчүлүгүндө ал бар — бирок кээде BIOS'то өчүрүлүп калат, андай болсо орноткуч өзү айтып берет. Дискте орун да керек болот: Windows'ка канча берсеңиз, ошончо, плюс образдын өзү үчүн болжол менен 10GB.

Орноткуч канча RAM, канча CPU өзөгүн жана канча диск бергиңиз келерин (64GB же андан көп — акылга сыярлык минимум), андан кийин Windows колдонуучу атын жана сырсөзүн сурайт. Аларды бош калтырсаңыз, `docker` / `admin` болот. Жүктөп алуу бир топ убакыт алат — 10-15 мүнөт кадимки нерсе — жана жүрүшүн браузерде `http://127.0.0.1:8006` дарегинен көзөмөлдөй аласыз. Браузер консолду ачуудан мурун ошол эле колдонуучу атын жана сырсөздү сурайт.

## Колдонуу

Орнотулгандан кийин тиркеме ишке киргизгичтен _Windows_ ачыңыз. Ал VM иштебей турган болсо, аны иштетип, сизди RDP аркылуу толук экранда туташтырат. Муздак иштетүүдө 15-30 секунд күтүңүз.

RDP сеансы үндү, микрофонуңузду жана жалпы алмашуу буферин өткөрөт, ошондуктан текстти Linux менен Windows'тун ортосунда көчүрүү жөн эле иштейт. Чечилиш терезеңизге ылайыкташат, ал эми Omarchy экраныңыздын масштабын да өткөрүп берет, ошондуктан HiDPI экранда бүдөмүк башаламандык болбойт.

RDP терезесин жапканыңызда VM автоматтык түрдө өчөт. Эгер аны иштеп турган бойдон калтыргыңыз келсе — мисалы, ал жерде бир нерсе иштеп жатса — анын ордуна `omarchy windows vm launch --keep-alive` менен ачыңыз.

Калган башкаруулар ошол эле буйрукта:

```bash
omarchy windows vm status    # is it running?
omarchy windows vm stop      # shut it down
omarchy windows vm launch    # start and connect
```

## Файлдарды бөлүшүү

Үй каталогуңуздагы `~/Windows` каталогу VM менен автоматтык түрдө бөлүшүлөт. Windows'ка жеткиликтүү болсун деген файлдарды ошол жерге салыңыз. VM'дин файл тутумуңуздун башка эч бир бөлүгүнө кирүү мүмкүнчүлүгү жок, ошондуктан Windows тараптагы ар кандай жаман нерселерден коопсузсуз. Анын өзүнүн виртуалдык диски `~/.windows` ичинде жайгашкан.

Бул тааныш үй жолдору өз файл тутумдарында калат. Алар ошондой эле сизге таандык каталогдорго символдук шилтеме боло алат, бул виртуалдык диск чоңураак дискте жайгашканда пайдалуу. Орноткуч бош орунду сөзсүз түрдө үй каталогуңуз турган файл тутумунан эмес, чындыгында `~/.windows` камтылган файл тутумунан өлчөйт.

Дисктин жана бөлүшүлгөн жолдордун каталогдорун өзүнчө, бири-бирин камтыбаган кылып кармаңыз. Алып салуу дисктин каталогун атайылап тазалайт, бирок бөлүшүлгөн каталогду сактап калат. Өчүрүүнүн алдында Omarchy убакыт менен чектелген камтуу текшерүүсүн жүргүзөт жана ал текшерүүнүн убактысы бүтсө же эки бактын өзүнчө экенин далилдей албаса, эч нерсени өчүрбөйт.

VM иштей электе Omarchy ошол эки каталогду ачып, бекитип алат, андан кийин так ошол каталогдордун inode'дорун `/var/lib/omarchy/windows/mounts` ичиндеги ар бир колдонуучуга тиешелүү жеке таяныч чекиттерге bind-mount кылат. Docker root тарабынан корголгон ошол таяныч чекиттерди гана көрөт. Бул дисктин өз алдынча тандалган жайгашкан жерлерин сактайт жана артыкчылыктуу контейнер колдоно электе сиздин атыңыздан иштеген башка процесстин текшерилген жолду алмаштырып коюшуна жол бербейт. Учурдагы диск жана бөлүшүлгөн каталогдор миграция учурунда `0700` режимине чейин катуулатылат, ошондуктан башка жергиликтүү аккаунттар алардын ичин карай алышпайт.

VM'дин порттору localhost'ко гана байланган, ошондуктан тармагыңыздагы эч нерсе Windows машинасына жете албайт. Веб-консоль да жөндөлгөн Windows колдонуучу атын жана сырсөздү талап кылат, бул башка жергиликтүү аккаунттун 8006 порту аркылуу VM'ди башкарып кетишине тоскоол болот.

## Чектөөлөр жана лицензия

Бул жөндөөдө GPU passthrough жок, ошондуктан ал оюн ойноо же видео монтаж үчүн ылайыктуу эмес. Бирок Microsoft Office'ти же сөзсүз керек болгон башка нерсени иштетүүнүн сонун жолу.

Орнотулган версия — активдештирилбеген Windows 11 Pro. Чектелген мүмкүнчүлүктөрдү колдонуу үчүн өзүңүздүн лицензия ачкычыңыз керек болот.

Эгер бул компьютер Windows менен келген болсо, OEM ачкыч Omarchy орнотулгандан кийин да микропрограммада сакталып турат. Аны `omarchy windows key` менен чыгарыңыз. Ал ачкыч ушул машинага байланган — ушул жабдууга кайра орнотулган Windows'ту активдештирет, бирок адатта VM'ди активдештирбейт.

Ресурстарды бөлүштүрүүнү кийин терминалда `omarchy windows vm install` иштетип өзгөртө аласыз, ал VM'дин конфигурациясын жоопторуңузга жараша кайра жазат. Compose файлынын өзү азыр `/var/lib/omarchy/windows/docker-compose.yml` ичинде жайгашкан жана root'ко таандык — бул атайылап жасалган, ошондо сиздин атыңыздан иштеген процесс аны кайра жазып, артыкчылыктуу иштетүү учурунда бүт дискиңизди контейнерге кошуп коё албайт. Эгер аны колго түзөтүү керек болсо (мисалы, USB түзмөгүн кошуу үчүн), аны `sudo` менен түзөтүп, бардык мүмкүнчүлүктөрдү [Dockur Windows долбоорунан](https://github.com/dockur/windows) караңыз.

Бардыгынан толук кутулуу үчүн Omarchy менюсундагы _Алып салуу > Windows_ колдонуңуз. Ал `~/.windows` ичиндеги VM'дин дискин жана Windows ичине орнотулгандардын баарын өчүрөт, ошондуктан керектүү нерселердин баарын алдын ала VM'ден көчүрүп алыңыз. Бөлүшүлгөн `~/Windows` папкаңызга тийишпейт.
