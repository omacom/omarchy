# Текстти алуу жана үндөн текст жазуу

### Текстти алуу

Экрандан текстин алып чыгуу үчүн аймак тандоого `Super + Ctrl + PrtScr` басыңыз. Ачык булактуу tesseract OCR модели ал тандоону ошол замат текстке айландырып, алмашуу буферине салат. Андан кийин чаптоо үчүн `Super + V` бассаңыз эле болду.

Бул сүрөттөрдүн төмөнкү бөлүгүндөгү даректерди же сайттардын баш саптарына жашырылган телефон номерлерин алууда абдан ыңгайлуу.

### Үндөн текст жазуу

Жаңы орнотууларда [Superwhisper](https://superwhisper.com/) үндөн текст жазуунун демейки куралы болуп саналат: ал булуттагы иштетүүнү колдонот, офлайн моделдерди жүктөөнүн кереги жок. Omarchy менюсундагы _Жөндөө > Демейкилер > Үндөн текст жазуу_ аркылуу Superwhisper, [Voxtype](https://voxtype.io/) же [Hex](https://anoma.ly/hex/) тандаңыз. Курал тандалганда, керек болсо ал орнотулат жана үндөн текст жазуу үчүн демейки болуп калат. Voxtype 150MB орун ээлеген англис тилиндеги базалык моделди жүктөйт; моделди `voxtype setup model` менен, башка жөндөөлөрдү `~/.config/voxtype/config.toml` аркылуу өзгөртөсүз. Superwhisper булуттагы же жергиликтүү иштетүүнү тандоо үчүн өз жөндөөлөрүн ачат, ал эми OPR тиркемени жаңыртып турат. Hex түзмөктө иштеген кеп моделин орнотуу учурунда жүктөп алат жана `hex.service` колдонуучу кызматы катары иштейт; моделди жана башка жөндөөлөрдү өзгөртүү үчүн анын терезесин панелдеги трей белгисинен же `hex` буйругу менен ачыңыз.

Сүйлөп жаздыруу үчүн `Right Alt` баскычын басып кармап турасыз же `Alt + Space` менен күйгүзүп-өчүрөсүз, ошондо айтылган текст фокустагы киргизүү талаасына түшөт. Бул баскыч айкалыштары тандалган куралды колдонот. Right Alt модификатор айкалышында колдонулганда да үндөн жазууну баштап жиберет; ал айкалыштар үчүн Left Alt колдонуңуз. Right Alt баскычы AltGr болгон баскычтоп калыптарында, анын ичинде ошондой калыпка которулганда да, жаздыруу үчүн аны жалгыз бир аз басып кармаңыз; AltGr башка баскыч менен бирге басылса, мурдагыдай эле өз белгисин терет. Alt + Space демейки боло электе жасалган орнотууларда сүйлөп жаздыруу үчүн `F9`, күйгүзүп-өчүрүү үчүн `Super + Ctrl + X` калат, алар `~/.config/hypr/bindings.lua` файлына кошулган, ал эми ошол `Super + Ctrl + X` агенттер панелинин ордун ээлейт; ал баскычтарды тиркемелерге жана панелге кайтаруу үчүн аларды ошол жерден өчүрүңүз.

Ошол эле баскыч айкалыштары бардык куралдар менен иштейт. Куралыңызды Жөндөө > Демейкилер > Үндөн текст жазуу аркылуу тандаңыз. Куралдын орноткучу аны жөндөп, тандооңузду сактайт. Кайсынысы тандалганын көрүү үчүн `omarchy default dictation` иштетиңиз. Тандоо `~/.config/omarchy/defaults/dictation` файлында сакталат. Жаңы орнотууларда Superwhisper автоматтык түрдө тандалат.

Omarchy тандалган куралдын иш столу менен интеграциясын автоматтык түрдө жүктөйт. `~/.config/hypr/` ичинде Superwhisper үчүн эч кандай жөндөөнүн кереги жок.

Өзүңүздүн баскыч айкалыштарыңыз жана скрипттериңиз `omarchy dictation start`, `omarchy dictation stop` жана `omarchy dictation toggle` колдоно алат. Жаздырууну жана текстке айландырууну тандалган курал аткарат. Superwhisper тандалганда анын өз басып кармоо баскыч айкалышы өчүрүлүп, өз күйгүзүп-өчүрүү айкалышы `Ctrl + Alt + Space` болуп коюлат, ошентип ал Omarchy'нин жаздыруу баскычтарынан өзүнчө калат. Superwhisper'ге жок дегенде бир өз жаздыруу айкалышы керек, ал эми жокко чыгаруу айкалышы мурдагыдай эле жеткиликтүү.

Кошумча куралдар Omarchy'ни өзгөртпөстөн эле интеграцияланса болот. PATH ичинде `start`, `stop` жана `toggle` кабыл алып, тез жооп кайтарган, ката болгондо нөл эмес статус берген `omarchy-dictation-<backend>` аттуу аткарылуучу файлды бериңиз. Анын орноткучу провайдерди жөндөп, ийгиликтүү орнотуудан кийин `omarchy-dictation-use <backend>` чакырат. Бул мурдагы куралды токтотуп, тандоону атомдук түрдө сактайт; провайдер бош турганда же жеткиликсиз болгондо да `stop` ийгиликтүү аякташы керек. Куралдардын аттарында кичине тамгалар, сандар жана дефистер колдонулат. Орнотуу үчүн `omarchy-install-dictation-<backend>` бериңиз; аны `omarchy default dictation <backend>` иштетет. Ошол тандагычты чакыруу үчүн Omarchy менюсунун кеңейтмеси аркылуу Демейкилер менюсуна пункт кошуңуз. Кошумча иш столу интеграциясы `${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua` ичинде жайгашса болот.
