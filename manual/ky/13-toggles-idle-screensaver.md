# Которгучтар, бош туруу жана экран сактагыч

Күндө өзгөртүп жүргөн нерселериңиздин көбү чындыгында жөндөө эмес. Бул бир саатка күйгүзүп, кайра өчүрүп койгон режим: кечке чейин иштеп отурганда түнкү жарык, презентация учурунда тынчытуу, бир нерсе көрүп жатканда уйкуга өтпөө. Omarchy аларды которгучтар деп атайт, жана алардын баары бирдей иштейт — баскыч айкалышы, менюдагы пункт жана буйрук, баары бир эле которгучту басат.

### Которгучтар менюсу

`Super + Ctrl + O` _Аракеттер > Которуу_ менюсун түз ачат, же ага Omarchy менюсу (`Super + Space`) аркылуу барсаңыз болот. Ал тизмедеги ар бир нерсе абалы кайда сакталарын ойлонбой эле которо турган которгуч. Иш тактасынын көрүнүшүнө тиешелүү которгучтар анын жанында, _Көрүнүш_ бөлүмүндө турат.

Терминалдан ошол эле которгучтар `omarchy toggle <thing>` болуп саналат. Бүт топту көрүү үчүн `omarchy toggle` буйругун өзүнчө иштетиңиз.

| Которгуч | Баскыч айкалышы | Буйрук |
| ------ | ------ | ------- |
| Түнкү жарык | — | `omarchy toggle nightlight` |
| Билдирмелерди тынчытуу | `Super + Ctrl + Alt + ,` | `omarchy toggle notification silencing` |
| Уйкуга өтпөө (бош турганда кулпуланбайт) | `Super + Ctrl + I` | `omarchy toggle idle` |
| Кыйроону каттоо | — | `omarchy toggle crash-capture` |
| Экран сактагыч | — | `omarchy toggle screensaver` |
| [Herdr](https://herdr.dev) темаларын шайкештөө | — | `omarchy toggle theme sync` |
| Меню панели | `Super + Shift + Space` | `omarchy toggle bar` |
| Толук экрандагы иш тактасы (панель жок, боштуктар жок) | `Super + Ctrl + Alt + F` | `omarchy toggle fullscreen desktop` |
| Анимациялар, бүдөмүктөтүү жана көлөкөлөр | — | `omarchy toggle animations` |
| Сенсордук такта | `XF86TouchpadToggle` | `omarchy device touchpad` |
| Сенсордук экран | — | `omarchy device touchscreen` |
| Уйку режими | — | `omarchy toggle suspend` |
| Гибриддик GPU | — | `omarchy device gpu hybrid` |

Сенсордук такта, сенсордук экран жана гибриддик GPU которгучтары Которуу бөлүмүндө эмес, _Аракеттер > Жабдуулар_ (`Super + Ctrl + H`) бөлүмүндө турат, анткени алар ошол жабдуу чындап бар болгондо гана көрүнөт. Сенсордук такта жана сенсордук экран которгучтары Hyprland кайра жүктөлгөндөн кийин да сакталат — өчүрүлгөн түзмөктүн аты кичинекей абал файлына жазылат, Hyprland аны ишке киргенде окуп, түзмөктү кайра өчүрөт.

_Көрүнүш_ бөлүмүндө меню панели менен анимациялардан тышкары `omarchy toggle` буйруктары болбосо да, ошондой эле иштеген бир нече нерсе бар: панелдеги батарея пайызы, иш мейкиндигинин демейки жайгашуусу, ал эми _Терезелер_ ичинде — терезелердин ортосундагы боштуктар (`Super + Shift + Backspace`) жана жалгыз терезенин чарчы катышы (`Super + Ctrl + Backspace`).

Hyprland тартуу үчүн GPU таппай, анын ордуна CPU менен (llvmpipe) иштегенде — мисалы, GPU азырынча колдоого алынбаган Mac компьютерлеринде, көпчүлүк виртуалдык машиналарда же графикалык драйвер жүктөлбөй калганда — Omarchy ошол сеанс үчүн анимацияларды, бүдөмүктөтүүнү жана көлөкөлөрдү өчүрүп, бул тууралуу бир жолу билдирме менен кабарлайт. _Көрүнүш > Анимацияларды күйгүзүү_ аларды кайра күйгүзөт, жана Omarchy муну кийинки сеанстар үчүн да эстеп калат.

Булардын көбү `~/.local/state/omarchy/toggles/` ичиндеги жөн гана белги файлы. Скриптте алардын бирине карап тармактангыңыз келсе, `omarchy-toggle-enabled` сизди издеп жүрбөй эле чыгуу кодун берет:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

Белгилер өчүк абалы боюнча аталган — `screensaver-off`, `suspend-off`, `bar-off` — ошондуктан алардын бар болушу функциянын өчүрүлгөнүн билдирет.

### Панелдеги көрсөткүчтөр

Кайсы бир режим күйүп турганда, жогорку панелдин ортосунда, сааттын жанында кичинекей белги пайда болот. Бул көрсөткүчтөр виджети, ал экран жаздырууну, күтүлүп жаткан эстеткичтерди, түнкү жарыкты, тынчытуу режимин жана уйкуга өтпөө режимин көрсөтөт, ошондой эле сырсөзсүз sudo күйүп турганда же кимдир бирөө алыскы сеанска туташып турганда эскертүүлөрдү көрсөтөт.

Активдүү эмес көрсөткүчтөр жашырылган. Панелдин каалаган жерине курсорду алып барсаңыз, алар күңүрт болуп көрүнөт, ошондо баскыч айкалышын билбей эле бирин чыкылдатып күйгүзө аласыз. Активдүү көрсөткүчтү чыкылдатсаңыз, ал кайра өчөт. Эгер алардын баарын ар дайым көрүп тургуңуз келсе, `~/.config/omarchy/shell.json` ичиндеги `omarchy.indicators` жазуусунда `alwaysShow` маанисин `true` кылып коюңуз — панелдин виджеттери кантип жөндөлөрүн [жогорку панель](05-the-top-bar.md) бөлүмүнөн караңыз.

### Түнкү жарык

Түнкү жарык экранды 4000K чейин жылуулатат, ал эми кайра которсоңуз, 6500K абалына кайтарат. Аны которгучтар менюсунан (`Super + Ctrl + O`) же `omarchy toggle nightlight` менен которуңуз. Аны hyprsunset башкарат, эгер ал иштебей турса, которгуч аны өзү иштетет.

Демейки боюнча hyprsunset экраныңызга эч нерсе кылбайт. `~/.config/hypr/hyprsunset.conf` атайын өзгөрүүсүз профиль менен келет, ошондуктан сиз жылуулукту сурамайынча дисплей тийилбей турат. Эгер анын саатка жараша которулушун кааласаңыз, аны убакыт профили менен алмаштырыңыз:

```
profile {
    time = 20:00
    temperature = 4000
}
```

Андан кийин `~/.config/hypr/autostart.lua` файлына `o.launch_on_start("hyprsunset")` кошуп, hyprsunset кирүүдө иштей тургандай кылыңыз. Которгуч колдонгон 4000K/6500K жубу өзгөрбөйт, ошондуктан башка температура керек болсо, конфигурация файлына кайрыласыз.

### Тынчытуу режими

`Super + Ctrl + Alt + ,` билдирмелерди тынчытат. Ал күйүп турганда эч кандай калкыма билдирме чыкпайт, ал эми иш тактасы эмне үчүн тынчып калганын эскертип, панелде сызылган коңгуроо көрсөткүчү турат.

Бирок эч нерсе жоголбойт. Тынчытылган билдирмелер кармалып турат: акыркы бир нечесин `Super + Shift + Alt + ,` менен экранга кайра чыгарыңыз. Калганын [билдирмелер](10-notices.md) бөлүмүнөн караңыз.

Үч түрдөгү билдирүү баары бир өтөт: жаңы эле жасаган ишиңизди ырастаган Omarchy калкыма билдирмелери ("Theme changed", "Screenshot saved"), буйрук сабынан жөнөтүлгөн шашылыш эскертүүлөр жана текшерүү коддору. Сиздин алдыңызга чыгуу үчүн баарын шашылыш деп белгилеген чат тиркемелери буга кирбейт.

### Бош туруу

Бош туруу учурундагы жүрүм-турумду Omarchy shell башкарат, ал эми убакыттар `~/.config/omarchy/shell.json` ичиндеги жогорку деңгээлдеги `idle` блогунда жазылат:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

Эки сан тең бош тура баштаган учуруңуздан тартып саналган секунддар — бири-биринен эмес. Демек, демейки маанилер менен экран сактагыч эки жарым мүнөттөн кийин чыгат, ал эми кулпу экраны беш мүнөттө, экран сактагыч иштеди-иштебедиге карабай, ишке кирет. Файлды сактасаңыз, shell жаңы убакыттарды дароо колдоно баштайт.

Эгер кулпулоо мөөнөтүнө чейин экран сактагычты жапсаңыз, бул аракет катары эсептелип, күтүлүп жаткан кулпулоо жокко чыгарылат. Компьютериңизге бир карап койгонуңуз үчүн кулпуланып калбайсыз.

Бош турганда кулпулоону таптакыр токтотуу үчүн `Super + Ctrl + I` — же `omarchy toggle idle` — уйкуга өтпөө режимин күйгүзөт, ошондо панелде кофе чөйчөгү көрсөткүчү пайда болот. Бул узун презентациянын же көз салып тургуңуз келген куруунун алдында басуучу баскыч. Кадимки абалга кайтуу үчүн аны дагы бир жолу басыңыз. Скрипттен керек болсо, `omarchy toggle idle status` учурдагы абалды JSON түрүндө чыгарат.

Бул кубат эмес, кулпулоо жана экран сактагыч тууралуу. Уйку режими менен гибернациянын өз жөндөөлөрү бар, алар [тутумдун уйку режими](36-system-sleep.md) бөлүмүндө.

### Экран сактагыч

Omarchy экран сактагычы — кокустук текст эффекттери аркылуу өткөн ASCII арт, ар бир мониторго бирден нускасы. Каалаган баскыч же чычкандын кыймылы андан чыгарат.

Аны каалаган убакта _Тутум > Экран сактагыч_ (`Super + Esc`) аркылуу иштетсеңиз болот, бул бош туруудагы экран сактагычты өчүрүп койгон болсоңуз да, аны мажбурлап чыгарат. Демейки боюнча ага эч кандай баскыч айкалышы байланган эмес.

Эгер иштеп отуруп эле түз кулпуланган абалга өткүңүз келсе, бош туруудагы экран сактагычты `omarchy toggle screensaver` өчүрөт. Каалаган баскыч, чыкылдатуу, жылдыруу же чычкандын кыймылы аны жабат.

Ал тарткан логотипти _Көрүнүш > Өзгөчө белгилер > Экран сактагыч_ бөлүмүнөн өзүңүз каалагандай өзгөртө аласыз. png же svg жүктөсөңүз, Omarchy аны ASCII форматына айландырат. [Өзгөчө белгилер](41-branding.md) бөлүмүн караңыз.

### Кулпу экраны

`Super + Ctrl + L` компьютерди кулпулайт. Бул Omarchy shell кулпу экранын иштетип, дисплейди өчүрөт, сырсөзүңүздү туура эмес алфавитте терип калбашыңыз үчүн баскычтоп калыбын биринчисине кайтарат жана — эгер иштеп турса — чыгып баратканда 1Password кулпулайт.

Кулпу экраны сырсөздү кабыл алат, ал эми манжа изин жөндөп алгандан кийин аны да кабыл алат. Бул, ошондой эле аутентификациянын башка жолдору [жабдуу аркылуу аутентификация](37-hardware-authentication.md) бөлүмүндө жазылган.
