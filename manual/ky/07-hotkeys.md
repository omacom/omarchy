# Ыкчам баскычтар

Бардык негизги баскыч айкалыштарын `Super + K` менен көрө аласыз (Tmux баскыч айкалыштарын `Super + Alt + K` менен, Herdr баскыч айкалыштарын `Super + Ctrl + K` менен).

## Ыкчам баскычтар кантип жайгашкан

Ар бир ыкчам баскыч өзүнүн модификаторлору аныктаган катмарда турат, ар бир катмардын бир гана милдети бар. Ыкчам баскычтар ушунун аркасында бири-бирине аралашып кетпейт, ошондой эле бир нерсе кайсы жерде экенин көбүнчө божомолдоп таба аласыз.

| Катмар | Анда эмне бар | Мисалдар |
| --- | --- | --- |
| `Super + баскыч` | Тутум: терезелер, иш мейкиндиктери, жайгашуулар жана негизги менюлар | `Super + Space` Omarchy менюсу, `Super + W` терезени жабуу, `Super + F` толук экран |
| `Super + Shift + баскыч` | Тиркемелер | `Super + Shift + B` браузер, `Super + Shift + E` электрондук почта, `Super + Shift + N` редактор |
| `Super + Ctrl + баскыч` | Панелдер жана тутум менюлары | `Super + Ctrl + A` үн, `Super + Ctrl + N` тармак, `Super + Ctrl + C` экран тартуу менюсу |
| `Super + Ctrl + Alt + баскыч` | Тез аракеттер жана кабарлар | `Super + Ctrl + Alt + T` убакытты көрсөтүү, `Super + Ctrl + Alt + B` батарея, `Super + Ctrl + Alt + C` экран сүрөтү |

Ыкчам баскычка `Alt` кошсоңуз, ошол эле нерсенин башка бир варианты чыгат, эч качан таптакыр башка нерсе эмес:

- `Super + Shift + B` браузерди ачат; `Super + Shift + Alt + B` купуя терезени ачат
- `Super + Shift + E` электрондук почтаны ачат; `Super + Shift + Alt + E` жаңы кат баштайт
- `Super + F` толук экранга өтөт; `Super + Alt + F` толук тууралыкка өтөт
- `Super + Ctrl + C` экран тартуу менюсун ачат; `Super + Ctrl + Alt + C` менюну аттап өтүп, экран сүрөтүн тартат

Ыкчам баскыч кошкондо:

1. Катмарды ал эмне кыларына карап тандаңыз, андан кийин баскычты тандаңыз.
2. Орун бошотуу үчүн бар ыкчам баскычты жылдырбаңыз. Туура катмардан бош баскыч табыңыз.
3. `Alt` баскычын ансыз болгон ыкчам баскычтын варианты үчүн гана колдонуңуз.

Бир нече ыкчам баскыч ыңгайлуу болгону үчүн бул эрежелерди бузат. `Shift` жебе же `Tab` менен бирге тиркеме ачпай, жылдырат же тескери кылат, ал эми `Print`, медиа баскычтары, `Alt + Tab` жана `Ctrl + Alt + Del` башка бардык жердегидей иштейт. Алар өзгөчө учурлар, көчүрүп ала турган үлгүлөр эмес.

Эгер демейки баскыч сизге ылайык келбесе (мисалы, Windows'тогудай экран сүрөтү үчүн `Super + Shift + S` каалайсыз), аны `~/.config/hypr/bindings.lua` файлында кайра байлаңыз.

Сенсордук тактада үч жана төрт манжа менен сүрүү иш мейкиндиктерин которот, терезелерди жылдырат, менюну жана Quake консолун ачат; жаңсоолорду [баскычтоп, чычкан жана сенсордук такта](34-keyboard-mouse-trackpad.md) бөлүмүнөн караңыз.

Өлчөм өзгөртүү 0дүн оң жагындагы эки баскычты колдонот, баскычтопуңузда аларга эмне жазылганына карабастан: US баскычтопторунда `-` жана `=`, даний жана швед баскычтопторунда `+` жана `´`, норвег баскычтопунда `+` жана `\`, немис баскычтопунда `ß` жана `´`, испан баскычтопунда `'` жана `¡`, жапон (JIS) баскычтопунда `-` жана `^`. `Super + K` аларды баскычтопуңузда кандай жазылса, ошондой көрсөтөт. JIS'те `Super + ^` — бул `Super + Equal`, ал эми `Super + Shift + -` (ал `=` терет) — бул `Super + Shift + Minus`. Монитордун масштабы жана сырсөз башкаргыч `/` баскычын колдонот; `/` белгисин Shift менен гана тере турган жайгашууларда, европалык жайгашуулардын көбүндөгүдөй, алар анын ордуна оң Shift'тин сол жагындагы баскычты колдонот (даний жана немис жайгашууларында `-`).

Экран тартуунун бардык параметрлери Omarchy менюсундагы (`Super + Space`) _Аракеттер > Экран тартуу_ бөлүмүндө да бар.

## Tmux

Префикс баскычы — `Ctrl + Space` (`Ctrl + B` да иштейт). Бул баскыч айкалыштарын `~/.config/tmux/tmux.conf` файлында өзгөртсөңүз болот.

### Панелдер

| Ыкчам баскыч            | Милдети               |
| ----------------------- | --------------------- |
| `Prefix + v` | Панелди жанына бөлүү (тигинен) |
| `Prefix + h` | Панелди астына бөлүү (туурасынан) |
| `Prefix + x` | Панелди жабуу |
| `Prefix + z` | Панелди чоңойтуу/кайтаруу (толук экран) |
| `Alt + Enter` | Панелди астына бөлүү (префикссиз) |
| `Alt + Shift + Enter` | Панелди жанына бөлүү (префикссиз) |
| `Alt + Escape` | Панелди жабуу (префикссиз) |
| `Ctrl + Alt + Arrows` | Панелдердин ортосунда жылуу |
| `Ctrl + Alt + Shift + Arrows` | Панелдердин өлчөмүн өзгөртүү |

### Терезелер

| Ыкчам баскыч            | Милдети               |
| ----------------------- | --------------------- |

| `Prefix + r` | Терезенин атын өзгөртүү |
| `Alt + 1-9` | Белгилүү терезеге өтүү |
| `Alt + Arrow Left/Right` | Терезелердин ортосунда жылуу |
| `Alt + Shift + Arrow Left/Right` | Терезени солго/оңго жылдыруу |

### Сеанстар

| Ыкчам баскыч            | Милдети               |
| ----------------------- | --------------------- |
| `Prefix + C` | Жаңы сеанс |
