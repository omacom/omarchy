# Көп берилүүчү суроолор

### Баскычтоптун жайгашууларынын ортосунда кантип которулам?

`~/.config/hypr/input.lua` файлыңызды түзөтүп, жайгашуулардын ортосунда `Left Alt + Right Alt` менен которулуу үчүн мындайды кошуңуз:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

Бир нече жайгашуу жөндөлгөндөн кийин панель учурдагы баскычтоп жайгашууңузду автоматтык түрдө көрсөтөт (жана аны басып которулсаңыз да болот).

### Сааттын форматын 12 сааттык кылып кантип өзгөртөм?

Панелдеги саатты оң баскыч менен басып, кеңири колдонулган форматтарды, анын ичинде 12 сааттык форматтарды да, кезек-кезек алмаштырыңыз. Форматты түз эле коюп койсоңуз да болот:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

Бул Sunday 10:55 AM деп көрсөтөт.

### Убакыт алкагымды кантип өзгөртөм?

Omarchy менюсунда _Жөндөө > Аймак > Убакыт алкагы_ ачып, тизмеден тандаңыз. Эгер убакыт алкагы туура болуп, бирок сааттын өзү жылып кеткен болсо, _Жаңыртуу > Убакыт_ сиз үчүн убакытты шайкештештирүүнү кайра иштетет.

### DNS'ти кантип өзгөртөм, Wi-Fi'ды кантип бөлүшөм же туташуумдун ылдамдыгын кантип текшерем?

Алардын баары [тармак](35-networking.md) бөлүмүндө.

### Дискимдин ылдамдыгын кантип текшерем?

_Аракеттер > Ылдамдыкты текшерүү > Дисктин ылдамдыгын текшерүү_ дискиңиздеги окуу жана жазуу ылдамдыгын түз убакытта өлчөйт, же терминалдан `omarchy disk speedtest` колдонуңуз.

### Принтерди кантип кошом?

Басып чыгаруу кутудан чыгары менен жөндөлүп, иштеп турат, ал эми ар бир принтерди өзүңүз тиркеме ишке киргизгичтеги (`Super + Alt + Space`) _Print Settings_ аркылуу кошосуз.

_Add_ тандап, издеп чыгышына бир аз убакыт бериңиз: USB аркылуу туташтырылган принтер жана тармактык принтерлердин көбү сиз үчүн табылат. Эгер сиздики тизмеде жок болсо, _Network Printer > Internet Printing Protocol (ipp)_ тандап, анын дарегин киргизиңиз — принтердин өз дисплейи же анын веб-барагы ал эмне экенин айтып берет, адатта `192.168.1.50` сыяктуу бир нерсе жана `ipp/print` кезеги. Андан кийин _Forward_ драйвер сунуштайт: заманбап принтер драйверсиз _IPP Everywhere_ профилинде эң жакшы иштейт, ал эми эскирээк принтерге моделдин өз драйвери керек.

Тиркемелериңиз биринчи кайсы принтерге кайрыларын тандоо үчүн принтерди оң баскыч менен басып, _Set as Default_ тандаңыз, ал эми кагаз өлчөмүн, эки тараптуу басууну жана сапатты коюу үчүн _Properties_ тандаңыз.

Тармактагы принтерлер кошулбастан эле пайда болгон автоматтык табуу кайра иштелип жаткандыктан убактылуу өчүрүлгөн, ошондуктан жогоруда айтылган биринчи кадам автоматтык эмес, сиздин мойнуңузда. PDF файлга басып чыгаруу эч кандай принтерсиз эле иштейт.

### Экран сүрөттөрү же экран жазуулары сакталган жерди кантип өзгөртөм?

Сакталган экран сүрөттөрү демейки боюнча `~/Pictures/Screenshots` ичине түшөт. Башка каталогду колдонуу үчүн `~/.config/uwsm/env.d/` ичиндеги файлга (мисалы, `~/.config/uwsm/env.d/capture`) муну кошуңуз:

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

Экран жазуулары үчүн да ушундай эле `OMARCHY_SCREENRECORD_DIR` колдонсоңуз болот.

Omasnap экран сүрөттөрүнүн каталогун автоматтык түрдө түзөт. Экран жазууларынын каталогун өзүңүз түзүңүз, андан кийин чөйрөнүн кайсы бир өзгөрүүсү күчүнө кириши үчүн Omarchy'ни кайра иштетиңиз.

### Apple Studio Display'имдеги динамиктерди жана веб-камераны кантип иштетем?

USB C'ни сайып эле баары иштеши керек деп ойлойсуз, бирок тилекке каршы андай эмес. Анын ишенимдүү иштеши үчүн мен тапкан чечим — [WJESOG DisplayPort + USB-A => USB-C кабелин](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/) колдонуу. Ошондо динамиктер жана веб-камера сонун иштейт.

Эсиңизде болсун, Omarchy'де Apple дисплейлери (Studio да, XDR да) үчүн кадимки баскычтоптун жарыктык баскычтары аркылуу жарыктыкты башкаруу камтылган.

### Кошумча программалардын баарынан кантип кутулам?

Эгер Obsidian же LibreOffice сыяктуу программаларды же башка алдын ала орнотулган нерселерди каалабасаңыз, аларды абдан оңой алып салсаңыз болот.

Орнотулган ар бир пакетти көрүү үчүн _Алып салуу > Пакет_ ачыңыз. Андан кийин алып салгыңыз келген каалаган пакетти tab менен белгилеп, белгилегендердин баарын return менен алып сала баштайсыз.

Ал эми керексиз алдын ала орнотулган веб-тиркемелерди алып салуу үчүн Omarchy менюсундагы _Алып салуу > Веб-тиркеме_ колдонсоңуз болот.

Же бардык алдын ала орнотулган кошумчаларды — веб-тиркемелерди, TUI'лерди жана кошумча тиркемелерди — бир жолу шыпырып салуу үчүн _Алып салуу > Алдын ала орнотулгандар_ ачыңыз. Аларды ачкан ыкчам баскычтар да алар менен кошо жоголот, ошондуктан `~/.config/hypr/bindings.lua` ичинде өзүңүздүкү менен толтура турган таза айкалыштар калат.
