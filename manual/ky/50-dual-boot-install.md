# Эки тутумду жанаша орнотуу

Omarchy'ни Windows же башка орнотуулардын жанына бир бөлүмгө орното аласыз.

Бул орнотуу ыкмасы да демейки боюнча бөлүм үчүн LUKS шифрлөөсү менен келет, ошондуктан ал иш жүзүндө бүт дискке орнотуудан эч айырмаланбайт, болгону дискте бош орун болушу керек.

## Windows'та орун бошотуу

Windows'тун жанына орнотуу үчүн Start менюсуна `disk management` деп терип, **Create and format hard disk partitions** вариантын тандаңыз.

 ![dual-boot-1](images/dual-boot-1.webp)

Керектүү бөлүмдү таап, оң баскыч менен басып, **Shrink Volume** тандаңыз.

![dual-boot-2](images/dual-boot-2.webp)

 Томду канчага кичирейткиңиз келгенин киргизиңиз. Бул жүктөө бөлүмүн кошкондо келечектеги Omarchy орнотууңуздун өлчөмү болорун эске алыңыз.

 ![dual-boot-3](images/dual-boot-3.webp)

Бүткөндө, ушуга окшош нерсени көрүшүңүз керек, бул мисалда 50GB бөлүгүнө Omarchy'ни орнотобуз.

 ![dual-boot-4](images/dual-boot-4.webp)

## Omarchy'ни орнотуу

Omarchy'ни орнотуу процесси иш жүзүндө кадимкидей эле. Дискиңизди тандагандан кийин, сизге **Free space install** варианты сунушталат. Бүт дискти тазалап салбоо үчүн ошол вариантты тандаңыз.

 ![dual-boot-5](images/dual-boot-5.webp)

Баары туура экенин ырастап, орнотуу кадимкидей бүткөнчө күтүңүз. Бүт дискке орнотуудагыдай эле, ушул жерден шифрлөөсүз орнотууну да тандасаңыз болот (сунушталбайт).
 ![dual-boot-6](images/dual-boot-6.webp)

## Башка орнотууларды жүктөгүчкө кошуу

Omarchy орнотуусун бүтүргөндө, эми Limine жүктөгүчү демейки болуп калганын байкайсыз. Мунун жардамы менен Limine'ге Windows сыяктуу башка орнотууларыңыз үчүн да пункттарды кошо аласыз.

Башка операциялык тутумдарды кошуу үчүн `limine-scan` иштетип, каалаган пункттарды Limine жөндөөлөрүңүзгө кошуу үчүн көрсөтмөлөрдү аткарыңыз. Жүктөө менюсу демейки боюнча жашыруун турат жана бир секунддан кийин Omarchy'ни баштайт. Windows'ту же башка пунктту тандоо үчүн Limine башталары менен каалаган баскычты басыңыз; меню пайда болгондо, жебе баскычтары менен пунктту тандап, Enter басыңыз. Эгер баскычты басканча Omarchy башталып кетсе, кайра жүктөп, дагы бир жолу аракет кылыңыз.

## Bitlocker

Бул орнотуу ыкмасы Bitlocker менен шайкеш келбей турганын белгилей кетүү маанилүү, анткени ал бөлүмдү гана эмес, бүт дискти шифрлейт. Эгер Bitlocker күйгүзүлгөн деген катага туш болсоңуз, Windows'ка жүктөлүп, **Settings -> Privacy & Security -> Device encryption** бөлүмүнө барып, Bitlocker'ди өчүрүңүз. Дискти чечмелөөгө бир аз убакыт кетиши мүмкүн.

 ![dual-boot-7](images/dual-boot-7.webp)

## Windows'ту кайра орнотуу

Эгер бул компьютер Windows менен келген болсо, анын продукт ачкычы микропрограммада сакталат. Аны чыгаруу үчүн `omarchy windows key` иштетиңиз, ошондо Windows'ту бул машинага кайра орнотсоңуз, аны кайра активдештире аласыз.
