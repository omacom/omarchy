# Бирдиктүү алмашуу буфери жана тарыхы

Адатта Linux'та терминалда көчүрүп-чаптоо үчүн `Ctrl + Shift + C/V`, калган бардык жерде `Ctrl + C/V` керек. Linux'та туулуп-өспөгөн адамга буга көнүү кыйын! Mac'тан келген болсоңуз, super'ден ctrl'ге өтүү да ошондой эле кыйын.

Omarchy эки көйгөйдү тең (дээрлик) бардык жерде иштеген бирдиктүү алмашуу буферинин ыкчам баскычтары менен чечет. Алар:

| Ыкчам баскыч | Буйрук |
| ------- | ----------- |
| Super + A | Баарын тандоо |
| Super + C | Көчүрүү |
| Super + X | Кесүү |
| Super + V | Чаптоо |
| Super + Ctrl + V | Алмашуу буферинин тарыхы |

_Көңүл буруңуз: агенттердин көпчүлүк чөйрөлөрү сүрөттөрдү чаптоо үчүн `Ctrl + V`, ал эми текстти чаптоо үчүн `Super + V` колдонот._

Фокустагы текст талаасындагы же `Ctrl + A` колдогон башка тиркемедеги бардык нерсени көчүрүү үчүн `Super + A`, андан кийин `Super + C` басыңыз. Терминалда `Ctrl + A` буйрук сабынын текстин тандабай, анын башына жылдырат.

### Алмашуу буферинин тарыхы

Алмашуу буферинин тарыхын Omarchy shell камсыз кылат жана ал текст менен да, сүрөттөр менен да иштейт. Аны `Super + Ctrl + V` менен ачып, жазууңузду Return менен тандайсыз, ал аны түз эле сиз турган тиркемеге чаптайт. Жазууну алмашуу буферине гана көчүрүү үчүн `Shift + Return`, аны ачуу үчүн `Alt + Return`, тарыхтан өчүрүү үчүн `Delete`, бүт тарыхты тазалоо үчүн `Shift + Delete` колдонуңуз.
