# Pripomienky

Omarchy má vstavaný spôsob, ako nastaviť jednoduché pripomienky založené na odpočítavaní a so správou. Môžete to urobiť pomocou `Super + Ctrl + R`, všetky nastavené pripomienky si môžete pozrieť pomocou `Super + Ctrl + Alt + R` a všetky vymazať pomocou `Super + Ctrl + Shift + R`. Všetko je dostupné aj cez _Akcie > Pripomienka_. Môžete použiť aj CLI pomocou `omarchy reminder 7 'Tea ready'`.
