Omarchy obsahuje spúšťače pre nižšie uvedených kódovacích agentov bez toho, aby za vás vyberal predvoleného. ### Inštalácia a aktualizácia agentov

Okrem Hermes používajú títo agenti lenivú inštaláciu cez mise: prvé spustenie nainštaluje CLI a neskoršie spustenia ho znova použijú. mise tiež najviac raz za štyri hodiny skontroluje, či pre nainštalovaného agenta nevyšla nová verzia, tesne pred jeho spustením alebo na pozadí pri výzve shellu. Ak táto aktualizácia zlyhá alebo ste offline, spustí sa nainštalovaná verzia. `omarchy update` aktualizuje nainštalovaných agentov spolu so zvyškom Omarchy a `mup` aktualizuje iba nástroje spravované cez mise.

Vlastný aktualizátor agenta, ako napríklad `claude update`, `codex update` alebo tlačidlo aktualizácie v aplikácii, neaktualizuje inštaláciu spravovanú cez mise. `codex update` zlyhá a `claude update` môže hlásiť úspech, pričom nainštaluje samostatnú kópiu, ktorú mise nesleduje. Ak radšej používate natívny inštalátor a aktualizátor agenta, pridajte ho do `disable_tools`; pozri [Predinštalované CLI nástroje](18-development-tools.md#preinstalled-cli-tools).

Ak chcete nainštalovať všetky nakonfigurované lenivé nástroje skôr, ako ich budete potrebovať, spustite `mise install --include-lazy`. Patria sem aj ostatné predvolené CLI nástroje Omarchy, ako aj agenti. Informácie o inštalácii jedného nástroja alebo o použití vlastnej inštalácie nájdete v časti [Predinštalované CLI nástroje](18-development-tools.md#preinstalled-cli-tools).

`grok` sa inštaluje prostredníctvom first-party balíka `grok` od mise, rovnako ako `claude` a `codex`. Spustite `grok` alebo ho vyberte v časti _Setup > Defaults > Agent_. Preskočte inštalátor `curl | bash` na x.ai. Tá cesta umiestni druhú kópiu do `~/.grok/bin`, pridá ju na začiatok `PATH` a prepíše wrapper Omarchy.

`dsh` otvára svoje prehliadačové UI na `127.0.0.1:3080`, pričom adresár spustenia je jeho predvoleným pracovným priestorom. Jeho prehliadačové UI neprijíma žiadny úvodný prompt, takže `omarchy agent prompt` ho otvorí s promptom vo vašej schránke, ktorý môžete vložiť. Omarchy ho spúšťa s predvoľbou povolení bez schvaľovania od DeepSeek. DeepSeek Harness nahráva záznamy relácií do DeepSeek, keď používate jeho oficiálne API modelov; vypnite to v jeho prehliadačovom UI v časti _Settings > General > Upload Session Log_. Spätná väzba, ktorú mu odošlete, sa nahrá spolu s reláciou tiež, pokiaľ ho nespustíte s `DSH_TELEMETRY_MODE=DISABLED`.

### Predvolený agent

Vyberte si predvoleného agenta príkazom `omarchy default agent <name>` alebo v časti _Setup > Defaults > Agent_ v Omarchy Menu (`Super + Space`). Ak agent ešte nie je nainštalovaný, jeho výber ho najprv nainštaluje. Čerstvé Omarchy vás na túto voľbu upozorní jednorazovým oznámením.

Výber Claude sa tiež pokúsi nastaviť jeho rozšírenie prehliadača pre Chromium, Chrome, Brave, Brave Origin a Edge. Nastavenie rozšírenia sa vzťahuje na všetkých používateľov a môže si vyžiadať vaše systémové heslo; zrušenie alebo neúspešná inštalácia rozšírenia stále vyberie a spustí Claude. Reštartujte prehliadač, v prípade výzvy povoľte rozšírenie a prihláste sa do Claude, aby ste dokončili jeho pripojenie. Spustite `/chrome` v Claude na kontrolu pripojenia. Firefox a Zen toto rozšírenie nepodporujú. Ak bol Claude vaším predvoleným agentom už pred pridaním tohto nastavenia, vyberte ho znova, aby sa rozšírenie nainštalovalo.

Keď ste si vybrali, `Super + Shift + Ctrl + A` spustí predvoleného agenta v samostatnom okne terminálu (alebo otvorí výber, ak ste si ešte nevybrali). Môžete ho tiež spustiť priamo do úlohy príkazom `omarchy agent prompt "Review this project"`. Freebuff a DeepSeek Harness neprijímajú úvodný prompt, takže sa namiesto toho otvoria s promptom vo vašej schránke, ktorý môžete vložiť. Takto spustení agenti bežia bez dozoru vo svojich príslušných režimoch, v ktorých sa nezastavujú, aby sa pýtali, takže buďte pripravení, že budú skutočne niečo robiť! MiniMax Code takýto režim pre svoje interaktívne relácie nemá, takže žiada o povolenia ako zvyčajne. A keďže agenti odmietajú zapamätať si dôveru pre váš domovský adresár, spustenia z `$HOME` namiesto toho začínajú v `~/Work`.

Existujú aj skratky terminálu: `a` spustí predvoleného agenta priamo v aktuálnom termináli, zatiaľ čo `c`, `cx` a `cy` spustia OpenCode, Claude Code a Codex priamo (opäť v ich režimoch automatického schvaľovania). Zmeny témy sa synchronizujú aj do agentov: Claude Code, Pi, OpenCode a Hermes (keď ho Omarchy nainštaluje) všetci nasledujú, keď prepnete tému Omarchy.

### Panel agentov

Horná lišta má ikonu agentov. Predtým, ako si nastavíte agenta, vás jej panel prevedie prihlásením do Claude, Codex alebo Grok a prvý z nich sa stane vaším predvoleným agentom. Potom panel umiestni každé predplatné na jednu stránku: každý agent a účet so svojím plánom, merač pre každý z jeho 5-hodinových limitov relácie a týždenných limitov s časom do jeho resetovania (pre presné percento prejdite kurzorom), alebo zostávajúci predplatený zostatok, pod riadkom, ktorý strieda, čo ste použili vo všetkých z nich, napríklad tokeny tento týždeň a váš najpoužívanejší model. V časti _Make something_ ponúka úvodné prompty pre novú tému, plugin alebo aplikáciu, ktoré odovzdajú úlohu vášmu predvolenému agentovi. Aplikácie sa vytvárajú tak, ako vlastné Hype, Monologue a Omacut od Omarchy, v C++ a Qt Quick, podľa agent skillu omarchy-app, a kompilátor a časti Qt, ktoré potrebujú, prichádzajú nainštalované. Claude Code, Codex, Grok, Kimi, Cursor a jeho povolený objem Grok Bot, GitHub Copilot, Muse, Antigravity, Kimchi a Devin sú pokryté hneď po inštalácii so svojimi limitmi a Hermes, Mistral Vibe a Qwen Code ukazujú svoje relácie a tokeny, keď ich použijete. Plány poskytovateľov a kľúče, ktoré používate prostredníctvom pi, omp alebo opencode, sa tiež zobrazia: OpenCode Zen a Go, Z.ai GLM Coding Plan, Ollama Cloud, MiniMax Token Plan a Synthetic so svojimi limitmi; Fireworks, OpenRouter a DeepSeek so svojimi predplatenými zostatkami; a modely, ktoré prevádzkujete na vlastnom hardvéri, pod Lokálnymi modelmi. Každý agent sa počíta raz, pod tým, kto ho účtuje, bez ohľadu na to, cez koľko harnessov ho ovládate.

Kliknite ľavým tlačidlom na ikonu na lište pre panel, kliknite pravým tlačidlom na spustenie predvoleného agenta. Záznamy o používaní, ktoré sú za tým, sa regenerujú každých 15 minút príkazom `omarchy agent usage-update` a panel môže dokonca zlúčiť používanie z vašich ostatných počítačov prostredníctvom synchronizovaného priečinka. Úplné nastavenia nájdete v README v časti `$OMARCHY_PATH/shell/plugins/agents/`.

### Viac predplatných

Ak platíte za viac ako jeden plán Claude, Codex alebo Grok — napríklad osobný Max a pracovný — Omarchy ich môže udržať všetky prihlásené a presúvať sa medzi nimi. Pridajte predplatné pomocou + v paneli agentov, ktorý vás tým prevedie priamo tam, alebo príkazom `omarchy agent account add claude Work` (alebo `codex`, alebo `grok`). Nainštaluje CLI, ak chýba. Prvý účet pre poskytovateľa sa prihlasuje cez váš bežný prehliadač, presne tam, kde to CLI vždy hľadá. Každý ďalší sa prihlasuje cez súkromné okno, takže účet, do ktorého je váš prehliadač už prihlásený, sa omylom nevyberie; prihláste sa tam ako účet, ktorý pridávate, a najprv zatvorte všetky súkromné okná, ktoré ste už mali otvorené. Nikdy sa na to neodhlasujte z CLI: odhlásenie zruší uložené prihlásenie a tento účet by bolo potrebné znova pridať.

Ak chcete skopírovať svoje prihlásenia predplatného do iného počítača Omarchy cez SSH, spustite `omarchy agent account copy user@laptop`. Odosielateľ poskytne dočasného prijímača, keď cieľ nemá nainštalovaného žiadneho, takže staršie počítače Omarchy môžu prijímať účty bez aktualizácie. Nainštalovaní prijímači majú prednosť. Toto kopíruje všetky predplatné Claude, Codex a Grok; pridajte názvy poskytovateľov na ich výber, ako napríklad v `omarchy agent account copy laptop claude`. Názvy účtov a ID príkazov zodpovedajú zdroju, vrátane účtov, ktoré už sú v cieli prítomné. Nesúvisiace cieľové účty dostanú číselnú príponu, ak sú ich názvy v konflikte, a nastavenia, skilly, pluginy a história konverzácií zostanú lokálne pre každý počítač.

Existujúce cieľové poverenia sa zachovajú. Zdrojový účet, ktorý je tam už prihlásený, má synchronizovaný názov bez nahradenia jeho poverení; ostatné účty sa pridajú vedľa neho. Ak chcete nahradiť uložené poverenia pre zodpovedajúce účty, použite `omarchy agent account copy --replace laptop claude` po ukončení relácií tohto účtu v cieli. Nový cieľ tiež získa aktívny účet zdroja a predvoľby prepínania; zavedený cieľ si zachová svoje vlastné.

Poverenia cestujú cez SSH a ukladajú sa do súkromných súborov v cieli, takže kopírujte iba na počítače, ktorým dôverujete. Toto je jednorazová kópia, nie priebežná synchronizácia. Obnovovacie tokeny Codex môže iný počítač rotovať, čím zostane skopírované prihlásenie potrebné obnoviť; samostatné prihlásenia zostávajú najspoľahlivejšou voľbou pre súčasné používanie na viacerých počítačoch. Pozri [Pokyny Codex na overenie účtu](https://developers.openai.com/codex/auth/ci-cd-auth).

Jeden účet na poskytovateľa je aktívny a každá nová relácia začína ako on: `cx`, `cy`, obyčajné `claude`, `codex` alebo `grok`, čokoľvek spustené cez `omarchy agent` a skripty alebo editory, ktoré nájdu CLI na `PATH`. Prepínajte príkazom `omarchy agent account use work` (a späť príkazom `omarchy agent account use main`) alebo v paneli stlačením čísla účtu a potom `Enter` (alebo kliknutím na jeho tlačidlo Use). Relácie, ktoré už bežia, zostanú na účte, s ktorým začali. História konverzácií, nastavenia, skilly a pluginy sú zdieľané medzi účtami, takže `claude --continue` v rovnakom priečinku pokračuje tam, kde ste prestali na novom účte.

Pri viac ako jednom účte panel zobrazuje limity každého účtu vedľa seba, s označeným aktívnym. V predvolenom nastavení vás Omarchy upozorní, keď aktívny účet prekročí 95% limitu, a kliknutie na oznámenie prepne na účet s najväčšou rezervou. Prejdite kurzorom na riadok účtu v paneli a kliknite na Autoswitch, ktorý sa zobrazí vedľa Use (alebo stlačte `m`), alebo spustite `omarchy agent account mode auto`, aby sa prepínal sám; keď je zapnutý, Autoswitch nahradí Use a opätovné kliknutie naň sa vráti k upozorňovaniu. Pridajte číslo na zmenu prahu, ako napríklad v `omarchy agent account mode auto 90`. Ak je každý účet nad prahom, dozviete sa o tom raz, spolu s tým, ktorý účet sa uvoľní ako prvý. Kým je aktívny účet do 15 bodov od svojho prahu (80% v predvolenom nastavení), jeho limity sa kontrolujú každé tri minúty namiesto každých 15.

`omarchy agent account list` zobrazuje každý účet a jeho najnovšie limity, `omarchy agent account remove work` zabudne jeden a `omarchy agent account rename primary Hey` premenuje jeden (alebo kliknite na názov účtu v paneli). Tieto príkazy fungujú na účtoch vášho predvoleného agenta; ak chcete dosiahnuť iného poskytovateľa, najprv ho pomenujte, ako napríklad v `omarchy agent account use codex side`. Prihlásenie, ktoré ste už mali v `~/.claude` alebo `~/.codex`, je účet _Main_ a zostáva tam, kde je. Účet, ktorý sa nepoužíva viac ako približne osem hodín, môže zobraziť _Sign-in required_; kliknite naň, aby ste tento účet znova prihlásili priamo v paneli, alebo v ňom spustite reláciu, ktorá prihlásenie obnoví sama. Servery MCP, ktoré ste mali, keď bol účet pridaný, s ním prichádzajú, ale tie, ktoré pridáte neskôr príkazom `claude mcp add`, dosiahnu iba účet, do ktorého ste ich pridali. Claude Desktop a nástroje nakonfigurované s absolútnou cestou k binárke CLI prepínač nesledujú. Explicitné `CLAUDE_CONFIG_DIR`, `CODEX_HOME` alebo `GROK_HOME` má prednosť pred vybratým účtom.

### Diagnostika pádov

Omarchy sleduje systemd-coredump kvôli pádom procesov. Keď niečo segfaultuje, dostanete oznámenie „Process crashed“ — kliknite naň a pád sa odovzdá vášmu predvolenému agentovi spolu so skillom diagnose-crash od Omarchy, ktorý prevedie agenta zisťovaním faktov z core dumpu a rozhodovaním, či pád stojí za nahlásenie upstream. Môžete ho tiež spustiť ručne proti akémukoľvek PID z `coredumpctl list` príkazom `omarchy agent crash <pid>`.

Sledovanie je v predvolenom nastavení zapnuté. Vypnite ho v časti _Trigger > Toggle > Crash Capture_ (alebo príkazom `omarchy toggle crash-capture`) a oznámenia prestanú; `omarchy agent crash <pid>` stále funguje ručne.

Pády môžu byť tiež stíšené po jednom programe, čo vám diagnostika ponúkne na konci. `omarchy crash mute hyprland` zastaví oznámenia iba pre tento program, `omarchy crash mute hyprland off` ich vráti späť a `omarchy crash mute` samo o sebe vypíše, čo ste stíšili. Berie cestu binárky rovnako ochotne ako jej názov, takže `omarchy crash mute /usr/bin/hyprland` robí to isté. Názov s medzerou dajte do úvodzoviek, ako napríklad v `omarchy crash mute 'Some App'`. Všetko ostatné stále upozorňuje a stíšený program stále padá — toto skrýva pripomienku, nič to neopravuje.

### Desktopové aplikácie

Menu _Install > AI_ obsahuje aj niekoľko grafických aplikácií AI: desktopovú aplikáciu ChatGPT, desktopovú aplikáciu Claude (linuxová beta od Anthropic, s kartami Chat, Cowork a Claude Code), Grok Bot na chatovanie s modelmi xAI, Hermes Desktop, OpenClaw, desktopovú aplikáciu Perplexity a T3 Code. Grok Bot je desktopová chatovacia aplikácia. Kódovací agent je príkaz `grok`.

Hermes Desktop je ten, o ktorom treba vedieť, pretože počítač má jeden Hermes a ten patrí aplikácii: Hermes sa inštaluje iba prostredníctvom aplikácie a príkaz `hermes`, ktorý predvolený agent spúšťa, je ten od aplikácie. Výber Hermes ako predvoleného agenta nainštaluje to isté, čo položka _Install > AI_: balík a runtime Hermes v `~/.hermes` nastavený vlastným inštalátorom Hermes, čo prvýkrát trvá niekoľko minút. Tento runtime je ten jeden Hermes, ktorý používa terminálový príkaz `hermes`, predvolený agent aj aplikácia, a aktualizuje sa sám príkazom `hermes update`, namiesto čakania na vydanie Omarchy. Jeho inštalácia tiež odovzdá Hermes tému Omarchy ako skin s názvom `omarchy`, ktorý každé rozhranie Hermes nasleduje, keď prepínate témy; vyberte si iný v nastaveniach Appearance v Hermes alebo pomocou `/skin`, ak by ste radšej, aby to nerobil, a Omarchy túto voľbu nechá na pokoji. Odstránenie aplikácie v časti _Remove > AI_ najprv zatvorí Hermes vrátane gateway, vezme so sebou tento runtime a ponechá vaše chaty, spomienky a skilly, ktoré Hermes sám pre seba napísal, pokiaľ mu nepoviete inak: opýta sa, pričom predvolená odpoveď je nie, či by tieto údaje a vaše nastavenia pripojenia mali odísť tiež.

Desktopový zážitok OpenClaw je jeho Control UI, ktoré sa otvára ako webová aplikácia podporovaná vlastnou lokálnou gateway. OpenClaw žije v `~/.openclaw` a aktualizuje sa sám: použite tlačidlo „Update Gateway“ v Control UI alebo spustite `openclaw update` a gateway sa reštartuje na novej verzii. Omarchy vyberá iba vydanie, od ktorého čerstvá inštalácia začína. Odstránenie OpenClaw v časti _Remove > AI_ vezme so sebou službu gateway a aplikáciu a potom sa opýta, či by mal odísť aj `~/.openclaw`, keďže ten obsahuje vaše chaty a poverenia spolu so samotným OpenClaw a runtime pluginov, ktoré sťahuje; predvolené nastavenie ho ponecháva a opätovná inštalácia OpenClaw ho znova prevezme.

T3 Code beží zo svojho oficiálneho vydania AppImage v `~/.local/share/t3code` namiesto balíka, takže sa aktualizuje sám. Jeho inštalácia sa opýta, či začať na kanáli Stable alebo Nightly; neskôr prepnite v nastaveniach T3 Code. Vaše vlákna a nastavenia žijú v `~/.t3` a odstránenie T3 Code v časti _Remove > AI_ ich vezme so sebou.

### Lokálne modely

Spustite otvorený model na vlastnom počítači pre vašich kódovacích agentov. Vaše prompty a kód zostávajú na počítači; nič odoslané modelu ho neopúšťa. Začnite s:

```bash
omarchy agent local use best
```

Alebo v paneli agentov v hornej lište vyberte + a potom Local AI, čo sa zobrazí, keď sa model zmestí na tento počítač. Prvýkrát sa tým nainštaluje Podman, ktorý modely spúšťa, a na počítači NVIDIA súprava nástrojov kontajnerov NVIDIA, ktorá im dáva GPU. Omarchy potom vyberie odporúčaný model pre tento počítač, stiahne ho a spustí. Očakávajte sťahovanie desiatok GB a využitie väčšiny pamäte počítača, keď model beží: Flash Next používa približne 100 GiB s plným kontextom 256K. Ak iné modely držia pamäť, ktorú potrebuje, nastaví sa ako zastavený, pripravený spustiť sa, keď jeden zastavíte. Model sa zastaví pri odhlásení; zastavte ho sami, keď potrebujete pamäť na niečo iné.

`omarchy agent local list` zobrazuje možnosti a vysvetľuje, prečo niektoré nesedia. Ak chcete nastaviť iný, spustite `omarchy agent local use <recipe>`. Dnes sú `qwen3.8-flash-next-halogen` a `qwen3.8-27b-gufo` dostupné pre počítače Strix Halo so 128 GB. Nové recepty a odporúčania prichádzajú s `omarchy update`, prostredníctvom balíka.

Každý model, ktorý nastavíte, dostane vlastný riadok v paneli agentov vedľa vašich predplatných: tlačidlo prehrávania na spustenie, tlačidlo pozastavenia na zastavenie a uvoľnenie jeho pamäte a tlačidlo terminálu na otvorenie vášho agenta na ňom. Niekoľko ich môže bežať naraz, keď sa spolu zmestia do pamäte; ak jeden nesedí, Omarchy povie, ktorý bežiaci model zastaviť. Pretiahnite riadky na ich zoradenie a stlačte Delete na vybratom riadku, aby ste odstránili model a jeho sťahovanie.

Z príkazového riadku robia to isté `omarchy agent local start <recipe>` a `omarchy agent local stop <recipe>`, `omarchy agent local status` zobrazuje každý model a `omarchy agent --local` otvorí vášho predvoleného agenta na poslednom modeli, ktorý ste spustili (pi, ak váš predvolený agent nemôže používať lokálny model). Akýkoľvek klient kompatibilný s OpenAI sa môže pripojiť tiež: `status` zobrazuje adresu každého modelu (prvá je `http://127.0.0.1:11435/v1`), názov receptu je model a kľúč je v `~/.config/omarchy/agent-local/key`.

`omarchy agent local remove <recipe>` odstráni model a sťahovania, ktoré žiadny iný model nepoužíva.

Runtime od tretích strán sú označené ich vydavateľom. Omarchy spúšťa každý model bez prístupu k sieti.

### Lokálne LLM

Omarchy odporúča dva spôsoby prevádzkovania lokálnych modelov LLM: LM Studio a Ollama. LM Studio poskytuje GUI rozhranie na vyhľadávanie modelov s otvorenými váhami, ich inštaláciu a spúšťanie. Je to skvelý spôsob, ako ľahko začať. Ollama ponúka CLI na podobné činnosti. Ale ak ste v lokálnych modeloch noví, začal by som s LM Studio. Ktorýkoľvek môžete nainštalovať v časti _Install > AI_ v Omarchy Menu.

### Omarchy Skill

Skilly agentov pomáhajú AI používať konkrétne nástroje konkrétnym spôsobom a Omarchy sa dodáva s predvoleným skillom na prispôsobenie systému. Napríklad ladenie vašej konfigurácie Hyprland, úprava lišty alebo dokonca vytvorenie novej témy od nuly. Je prepojený symbolickým odkazom do adresárov skillov pre Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` a každý `~/.hermes/profiles/*/skills`) a všeobecné umiestnenie `~/.agents/skills`, takže ho väčšina harnessov prevezme automaticky.

Ale tento skill by ste mali považovať za experimentálny. Rôzne modely ho použijú s rôznym účinkom. Najlepšie je najprv bežať v plánovacom režime, aby ste mali predstavu, čo by agent rád zmenil. A potom buďte pripravení vrátiť zmeny späť alebo dokonca spustiť `omarchy reinstall configs`, ak agent všetko pokazí.
