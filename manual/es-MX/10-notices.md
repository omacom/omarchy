# Avisos

Puedes consultar rápidamente la fecha y la hora, el estado de la batería y el clima actual usando los avisos con atajos de teclado.

### Fecha y hora

`Super + Ctrl + Alt + T`

 ![notice-datetime](images/notice-datetime.webp)

### Clima

`Super + Ctrl + Alt + W`

 ![notice-weather](images/notice-weather.webp)

La ubicación se detecta desde tu dirección IP, lo cual normalmente es lo suficientemente preciso, pero no siempre. Puedes fijarla con `omarchy weather location --set Malibu`, o ser exacto al respecto agregando coordenadas: `omarchy weather location --set Malibu 34.0259,-118.7798`. Ejecuta `omarchy weather location` por sí solo para ver dónde cree que estás, y `--clear` para volver a la detección automática.
