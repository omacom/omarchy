# Recordatorios

Omarchy trae una forma integrada de crear recordatorios sencillos con una cuenta regresiva y un mensaje. Puedes hacerlo con `Super + Ctrl + R`, ver todos los que hayas creado con `Super + Ctrl + Alt + R` y borrarlos todos con `Super + Ctrl + Shift + R`. Todo también está disponible en _Activar > Recordatorio_. También puedes usar la CLI con `omarchy reminder 7 'Tea ready'`.
