# Otros paquetes

Arch tiene una increíble riqueza de paquetes disponibles para casi cualquier tipo de software entre el repositorio oficial y el Arch User Repository (AUR).

Tampoco podría ser más fácil usar ninguno de los dos. Instalas un paquete nuevo de Arch yendo a _Instalar > Paquete_ en el menú de Omarchy (`Super + Space`) y escribiendo el paquete que quieres. Filtrará de forma difusa y automática la lista de todos los paquetes. (También puedes hacerlo manualmente usando `omarchy pkg add [package]` en la terminal).

Puedes hacer lo mismo con el AUR, solo usa _Instalar > AUR_. Solo recuerda que el AUR no está revisado por el equipo de Arch. Es como RubyGems o npm. Cualquiera puede subir.

Si quieres quitar un paquete, puedes usar _Quitar > Paquete_ desde el menú de Omarchy. Quitará el paquete, los archivos de configuración y las dependencias. (También puedes hacerlo manualmente usando `omarchy pkg drop [package]`).
