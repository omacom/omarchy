# Inne pakiety

Arch ma niesamowite bogactwo pakietów dostępnych dla niemal każdego rodzaju oprogramowania między oficjalnym repozytorium a Arch User Repository (AUR).

Nie mogłoby to być również łatwiejsze w użyciu. Instalujesz nowy pakiet Arch, przechodząc do _Instaluj > Package_ w menu Omarchy (`Super + Space`) i wpisując pakiet, którego chcesz. Automatycznie rozmyto odfiltruje listę wszystkich pakietów. (Możesz również zrobić to ręcznie, używając `omarchy pkg add [package]` w terminalu).

Możesz zrobić to samo z AUR, po prostu użyj _Instaluj > AUR_. Pamiętaj tylko, że AUR nie jest sprawdzane przez zespół Arch. To jak RubyGems lub npm. Każdy może przesyłać.

Jeśli chcesz usunąć pakiet, możesz użyć _Usuń > Package_ z menu Omarchy. Usunie pakiet, pliki konfiguracyjne i zależności. (Możesz również zrobić to ręcznie, używając `omarchy pkg drop [package]`).
