# Skróty klawiszowe

Wszystkie główne przypisania klawiszy zobaczysz przez `Super + K` (przypisania Tmux przez `Super + Alt + K` i przypisania Herdr przez `Super + Ctrl + K`).

## Nawigacja

| Skrót                  | Funkcja              |
| ----------------------- | --------------------- |
| `Super + Space`           | Menu Omarchy (aplikacje i wszystko inne)    |
| `Super + Alt + Space` | Siatka aplikacji |
| `Super + Escape` | Menu systemowe (uśpienie, restart itd.)  |
| `Super + Ctrl + L` | Zablokowanie komputera |
| `Super + W` lub `Super + Q` | Zamknięcie okna             |
| `Ctrl + Alt + Del` | Zamknięcie wszystkich okien |
| `Super + T`               | Przełączenie okna między kafelkowym a pływającym             |
| `Super + J` | Przełączenie pozycji okna (poziomo/pionowo) |
| `Super + O`               | Przełączenie wyskakującego okna przyklejonego i pływającego |
| `Super + L`               | Przechodzenie przez układy dwindle, przewijany i pływający |
| `Super + Alt + L`         | Przechodzenie przez układy w odwrotną stronę |
| `Super + P`               | Przełączenie stylu pseudo okna (naturalny vs rozciągany) |
| `Super + F`                 | Pełny ekran              |
| `Super + Alt + F`                 | Pełna szerokość              |
| `Super + Ctrl + F`                 | Pełny ekran wewnątrz okna              |
| `Super + 1/2/3/4`         | Skok do wskazanego obszaru roboczego     |
| `Super + Tab` | Skok do następnego obszaru roboczego |
| `Super + Shift + Tab` | Skok do poprzedniego obszaru roboczego |
| `Super + Ctrl + Tab` | Skok do dawnego obszaru roboczego |
| `Super + Shift + 1/2/3/4` | Przeniesienie okna na obszar roboczy |
| `Super + Shift + Alt + 1/2/3/4` | Przeniesienie okna na obszar roboczy bez podążania za nim |
| `Super + S` / `Super + Grave` | Przełączenie obszaru podręcznego |
| `Super + Alt + S` / `Super + Shift + Grave` | Przeniesienie okna na obszar podręczny |
| `Super + Shift + Alt + Arrows` | Przeniesienie obszarów roboczych na sąsiedni monitor |
| `Super + Arrow`  | Przeniesienie fokusu na okno w kierunku strzałki              |
| `Super + Shift + Arrow`  | Zamiana okna z innym w kierunku strzałki     |
| `Super + Minus` | Rozszerzenie okna w lewo |
| `Super + Equal` | Zwężenie okna z lewej |
| `Super + Shift + Minus` | Skrócenie okna od góry |
| `Super + Shift + Equal` | Rozszerzenie okna w dół |
| `Super + Alt + Minus/Equal` | To samo dopasowywanie w mniejszych krokach |
| `Super + Ctrl + Minus/Equal` | To samo dopasowywanie w większych krokach |
| `Super + Alt + Home` | Zapisanie szerokości okna |
| `Super + Home` | Przywrócenie zapisanej szerokości okna |
| `Super + Left Mouse` | Przeciąganie okna |
| `Super + Right Mouse` | Zmiana rozmiaru okna |
| `Super + Scroll Wheel` | Przewijanie obszarów roboczych |
| `Super + G`               | Przełączenie grupowania okien      |
| `Super + Alt + G`               | Wyniesienie okna z grupowania      |
| `Super + Alt + Tab`               | Przechodzenie między oknami w grupie      |
| `Super + Alt + Shift + Tab`               | Przechodzenie wstecz między oknami w grupie      |
| `Super + Alt + 1/2/3/4/5`               | Skok do wskazanego okna w grupie      |
| `Super + Alt + Arrow`  | Przeniesienie okna do grupy w kierunku strzałki  |
| `Super + Ctrl + Left/Right`  | Poruszanie się między oknami wewnątrz grupy kafelkowej |
| `Super + Ctrl + Z` | Powiększenie ekranu (powtarzaj dla większego powiększenia) |
| `Super + Ctrl + Alt + Z` | Pełne oddalenie z ekranu |
| `Super + /` | Krok naprzód w opcjach skalowania monitora |
| `Super + Alt + /` | Krok wstecz w opcjach skalowania monitora |
| `Alt + Tab` | Przechodzenie naprzód między oknami na aktywnym obszarze roboczym |
| `Alt + Shift + Tab` | Przechodzenie wstecz między oknami na aktywnym obszarze roboczym |
| `Ctrl + Alt + Tab`| Przechodzenie fokusu naprzód między monitorami |
| `Ctrl + Alt + Shift + Tab`| Przechodzenie fokusu wstecz między monitorami |

## Uniwersalny schowek

| Skrót                  | Funkcja              |
| ----------------------- | --------------------- |
| `Super + C`           | Kopiowanie    |
| `Super + X`           | Wycinanie (nie w terminalu)    |
| `Super + V`           | Wklejanie    |
| `Super + Ctrl + V`           | Menedżer schowka    |

Zwykle na Linuksie potrzebujesz `Ctrl + Shift + C/V` do kopiowania i wklejania w terminalu oraz `Ctrl + C/V` w pozostałych miejscach. Te ujednolicone skróty schowka Omarchy działają wszędzie.

## Przechwytywanie

| Skrót              | Funkcja                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Menu przechwytywania (dla klawiatur bez przycisku PrintScr) |
| `Print Screen`            | Zrzut ekranu                      |
| `Alt + Print Screen`            | Nagrywanie ekranu                     |
| `Super + Print Screen` | Wybór koloru |
| `Super + Ctrl + Print Screen` | Wyciąganie tekstu do schowka |
| `Super + Alt + [` | Zmniejszenie nakładki kamery internetowej podczas nagrywania |
| `Super + Alt + ]` | Powiększenie nakładki kamery internetowej podczas nagrywania |
| `Alt + Shift + L` | Skopiowanie bieżącego adresu URL z aplikacji webowej lub Chromium |
| `Alt + Shift + D` | Pobranie wideo z bieżącej strony do `~/Videos` |
| `Super + Ctrl + X` | Start/stop dyktowania (wymaga _Ustawienia > Domyślne > Dyktowanie_) |
| `Right Alt` / `F9` | Dyktowanie push-to-talk (wymaga Voxtype lub Superwhisper) |

W przypadku nagrań ekranu skrót najpierw pyta, jaki dźwięk chcesz, a potem zaczyna nagrywanie. Naciśnij go ponownie, żeby zatrzymać. Szczegóły znajdziesz w [zrzuty ekranu i nagrywanie](12-screenshots-recording.md).

Wszystkie opcje przechwytywania są też dostępne pod _Akcje > Przechwyć_ w menu Omarchy (`Super + Space`).

## Tmux

Klawisz prefiksu to `Ctrl + Space` (działa też `Ctrl + B`). Przypisania te możesz zmienić w `~/.config/tmux/tmux.conf`.

### Pane

| Skrót                  | Funkcja              |
| ----------------------- | --------------------- |
| `Prefix + v` | Podzielenie panelu obok (pionowo) |
| `Prefix + h` | Podzielenie panelu poniżej (poziomo) |
| `Prefix + x` | Zabicie panelu |
| `Prefix + z` | Przełączenie powiększenia panelu (pełny ekran) |
| `Alt + Enter` | Podzielenie panelu poniżej (bez prefiksu) |
| `Alt + Shift + Enter` | Podzielenie panelu obok (bez prefiksu) |
| `Alt + Escape` | Zabicie panelu (bez prefiksu) |
| `Ctrl + Alt + Arrows` | Poruszanie się między panelami |
| `Ctrl + Alt + Shift + Arrows` | Zmiana rozmiaru paneli |

### Okna

| Skrót                  | Funkcja              |
| ----------------------- | --------------------- |
| `Prefix + c` | Nowe okno |
| `Prefix + k` | Zabicie okna |
| `Prefix + r` | Zmiana nazwy okna |
| `Alt + 1-9` | Przejście do wskazanego okna |
| `Alt + Arrow Left/Right` | Poruszanie się między oknami |
| `Alt + Shift + Arrow Left/Right` | Przesunięcie okna w lewo/w prawo |

### Sesje

| Skrót                  | Funkcja              |
| ----------------------- | --------------------- |
| `Prefix + C` | Nowa sesja |
| `Prefix + K` | Zabicie sesji |
| `Prefix + R` | Zmiana nazwy sesji |
| `Prefix + N` | Następna sesja |
| `Prefix + P` | Poprzednia sesja |
| `Alt + Arrow Up/Down` | Poruszanie się między sesjami |
| `Prefix + s` | Lista sesji |
| `Prefix + d` | Odłączenie od sesji |

### Tryb kopiowania (w stylu vi)

| Skrót                  | Funkcja              |
| ----------------------- | --------------------- |
| `Prefix + [` | Wejście w tryb kopiowania |
| `v` | Rozpoczęcie zaznaczenia (w trybie kopiowania) |
| `y` | Skopiowanie zaznaczenia (w trybie kopiowania) |

### Ogólne

| Skrót                  | Funkcja              |
| ----------------------- | --------------------- |
| `Prefix + q` | Przeładowanie konfiguracji |
| `Prefix + ?` | Pokazanie przypisań klawiszy Tmux |
| `Prefix + :` | Wiersz poleceń |

### Funkcje układów Tmux

Te funkcje muszą być uruchamiane wewnątrz sesji Tmux.

| Polecenie | Funkcja |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Utworzenie układu deweloperskiego z edytorem, AI i terminalem |
| `tdlm <ai> [<second_ai>]` | Utworzenie układu deweloperskiego per podkatalog |
| `tsl <count> <command>` | Utworzenie wielopanelowego układu roju |
