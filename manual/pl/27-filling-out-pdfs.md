# Wypełnianie PDF-ów

Omarchy dostarcza miłą, podstawową przeglądarkę PDF o nazwie Document Viewer. To program, który otworzy wszystkie PDF-y, które po prostu dwukrotnie klikniesz.

Ale Document Viewer możesz używać tylko do wypełniania PDF-ów, które zostały skonfigurowane jako formularze. Jeśli musisz wypełnić PDF-y, które nie zostały, lub musisz podpisać PDF, użyj [Signed](https://github.com/omacom/signed). Uruchom go za pośrednictwem launchera aplikacji (`Super + Space`) lub kliknij plik prawym przyciskiem myszy, wybierz _Open With..._ i wybierz Signed.

Naciśnij `T`, aby wpisać tekst, i `D`, aby umieścić dzisiejszą datę. Oba lądują tam, gdzie znajduje się wskaźnik myszy. Przeciągaj cokolwiek, aby to przenieść, przeciągaj jego narożnik, aby powiększyć lub pomniejszy, i dwukrotnie klikaj tekst, aby go zmienić.

Aby podpisać, będziesz potrzebować zdjęcia swojego podpisu: skanu lub dobrze oświetlonego zdjęcia go na białym papierze. Otwórz menu _Signature_ (`Shift + S`), wybierz _Add signature..._, wybierz zdjęcie i nadaj mu nazwę. Signed usuwa papier i zachowuje atrament. Od tego momentu `S` umieszcza twój podpis pod wskaźnikiem myszy.

Gdy skończysz, użyj _Save signed copy..._ (`Ctrl + S`), aby zapisać wypełniony PDF obok oryginału, który nigdy nie jest zmieniany. Naciśnij `?` wewnątrz Signed, aby zobaczyć każdy skrót.
