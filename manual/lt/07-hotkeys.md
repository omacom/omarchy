# Spartieji klavišai

Visus pagrindinius klavišų derinius galite pamatyti paspaudę `Super + K` (Tmux derinius – `Super + Alt + K`, Herdr derinius – `Super + Ctrl + K`).

## Naršymas

| Spartusis klavišas                  | Funkcija              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy meniu (programos ir visa kita)    |
| `Super + Alt + Space` | Programų tinklelis |
| `Super + Escape` | Sistemos meniu (pristabdymas, paleidimas iš naujo ir kt.)  |
| `Super + Ctrl + L` | Užrakinti kompiuterį |
| `Super + W` or `Super + Q` | Uždaryti langą             |
| `Ctrl + Alt + Del` | Uždaryti visus langus |
| `Super + T`               | Perjungti langą tarp išklotinės ir slankiojančio režimo             |
| `Super + J` | Perjungti lango padėtį (horizontali / vertikali) |
| `Super + O`               | Perjungti lango iškėlimą į „sticky'n'floating“ režimą |
| `Super + L`               | Pereiti per „dwindle“, „scrolling“ ir slankiojantį išdėstymus |
| `Super + Alt + L`         | Pereiti per išdėstymus atvirkštine tvarka |
| `Super + P`               | Perjungti pseudo lango stilių (natūralus ar ištemptas) |
| `Super + F`                 | Pereiti į viso ekrano režimą              |
| `Super + Alt + F`                 | Pereiti į viso pločio režimą              |
| `Super + Ctrl + F`                 | Pereiti į viso ekrano režimą lango viduje              |
| `Super + 1/2/3/4`         | Pereiti į konkrečią darbo sritį sutelktame monitoriuje |
| `Super + Tab` | Pereiti į kitą darbo sritį sutelktame monitoriuje |
| `Super + Shift + Tab` | Pereiti į ankstesnę darbo sritį sutelktame monitoriuje |
| `Super + Ctrl + Tab` | Pereiti į buvusią darbo sritį sutelktame monitoriuje |
| `Super + Shift + 1/2/3/4` | Perkelti langą į darbo sritį sutelktame monitoriuje |
| `Super + Shift + Alt + 1/2/3/4` | Perkelti langą į darbo sritį sutelktame monitoriuje nesekant paskui jį |

| `Super + Alt + S` | Perkelti langą į visą „scratchpad“ sritį |
| `Super + Grave` | Perjungti „Quake“ konsolę |
| `Super + Shift + Grave` | Perkelti langą į „Quake“ konsolę |

| `Super + Shift + Alt + Arrows` | Perkelti darbo sritį į monitorių ta kryptimi |
| `Super + Arrow`  | Perkelti židinį į langą rodyklės kryptimi, ekrano krašte pereinant į toje pusėje esantį monitorių |
| `Super + Shift + Arrow`  | Sukeisti langą su kitu rodyklės kryptimi, įskaitant langą toje pusėje esančiame monitoriuje |
| `Super + Minus` | Išplėsti langą į kairę |
| `Super + Equal` | Susiaurinti langą į kairę |
| `Super + Shift + Minus` | Susiaurinti langą aukštyn |
| `Super + Shift + Equal` | Išplėsti langą žemyn |
| `Super + Alt + Minus/Equal` | Tas pats dydžio keitimas mažesniais žingsniais |
| `Super + Ctrl + Minus/Equal` | Tas pats dydžio keitimas didesniais žingsniais |
| `Super + Alt + Home` | Išsaugoti lango plotį |
| `Super + Home` | Atkurti išsaugotą lango plotį |
| `Super + Left Mouse` | Vilkti langą aplink |
| `Super + Right Mouse` | Keisti lango dydį |
| `Super + Scroll Wheel` | Slinkti per darbo sritis sutelktame monitoriuje |
| `Super + G`               | Perjungti langų grupavimą      |
| `Super + Alt + G`               | Perkelti langą iš grupės      |
| `Super + Alt + Tab`               | Pereiti per langus grupėje      |
| `Super + Alt + Shift + Tab`               | Pereiti atgal per langus grupėje      |
| `Super + Alt + Scroll Wheel` | Pereiti per langus grupėje |
| `Super + Alt + 1/2/3/4/5`               | Pereiti į konkretų langą grupėje      |
| `Super + Alt + Arrow`  | Perkelti langą į grupę rodyklės kryptimi, įskaitant langą toje pusėje esančiame monitoriuje |
| `Super + Ctrl + Left/Right`  | Judėti tarp langų išklotinės grupėje |
| `Super + Ctrl + Z` | Priartinti ekraną (kartokite, jei norite priartinti dar labiau) |
| `Super + Ctrl + Alt + Z` | Visiškai atitolinti ekraną |
| `Super + /` | Žingsnis pirmyn per monitoriaus mastelio parinktis |
| `Super + Alt + /` | Žingsnis atgal per monitoriaus mastelio parinktis |
| `Alt + Tab` | Pereiti pirmyn per langus aktyvioje darbo srityje |
| `Alt + Shift + Tab` | Pereiti atgal per langus aktyvioje darbo srityje |
| `Ctrl + Alt + Tab`| Perkelti židinį pirmyn per monitorius |
| `Ctrl + Alt + Shift + Tab`| Perkelti židinį atgal per monitorius |

## Universali iškarpinė

| Spartusis klavišas                  | Funkcija              |
| ----------------------- | --------------------- |
| `Super + C`           | Kopijuoti    |
| `Super + X`           | Iškirpti (ne terminale)    |
| `Super + V`           | Įklijuoti    |
| `Super + Ctrl + V`           | Iškarpinės tvarkyklė    |

Paprastai Linux sistemoje terminale kopijuoti ir įklijuoti reikia `Ctrl + Shift + C/V`, o visur kitur – `Ctrl + C/V`. Šie Omarchy suvienodinti iškarpinės spartieji klavišai veikia visur.

## Fiksavimas

| Spartusis klavišas              | Funkcija                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Ekrano kopija                      |
| `Super + Ctrl + Alt + C`            | Ekrano kopija (tas pats kadras, klaviatūroms be Print Screen klavišo) |
| `Super + Ctrl + C` | Fiksavimo meniu |
| `Alt + Print Screen`            | Ekrano įrašymas                     |
| `Super + Print Screen` | Spalvų parinkiklis |
| `Super + Ctrl + Print Screen` | Teksto išgavimas į iškarpinę |
| `Super + Alt + [` | Sumažinti internetinės kameros perdangą įrašant |
| `Super + Alt + ]` | Padidinti internetinės kameros perdangą įrašant |
| `Alt + Shift + L` | Kopijuoti dabartinį URL iš žiniatinklio programos arba Chromium |
| `Alt + Shift + D` | Atsisiųsti dabartiniame puslapyje esantį vaizdo įrašą į `~/Videos` |
| `Super + Ctrl + X` | Pradėti / sustabdyti diktavimą (reikia _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | Diktavimas laikant paspaudus (reikia Voxtype arba Superwhisper) |

Įrašant ekraną, spartusis klavišas pirmiausia paklausia, kokio garso norite, tada pradeda įrašyti. Paspauskite jį dar kartą, kad sustabdytumėte. Išsamią informaciją žr. [ekrano kopijos ir įrašymas](12-screenshots-recording.md).

Visos fiksavimo parinktys taip pat pasiekiamos Omarchy meniu (`Super + Space`) skiltyje _Trigger > Capture_.

## Tmux

Priešdėlio klavišas yra `Ctrl + Space` (taip pat veikia `Ctrl + B`). Šiuos derinius galite keisti faile `~/.config/tmux/tmux.conf`.

### Sritys

| Spartusis klavišas                  | Funkcija              |
| ----------------------- | --------------------- |
| `Prefix + v` | Padalyti sritį šalia (vertikaliai) |
| `Prefix + h` | Padalyti sritį žemiau (horizontaliai) |
| `Prefix + x` | Užmušti sritį |
| `Prefix + z` | Perjungti srities priartinimą (visas ekranas) |
| `Alt + Enter` | Padalyti sritį žemiau (be priešdėlio) |
| `Alt + Shift + Enter` | Padalyti sritį šalia (be priešdėlio) |
| `Alt + Escape` | Užmušti sritį (be priešdėlio) |
| `Ctrl + Alt + Arrows` | Judėti tarp sričių |
| `Ctrl + Alt + Shift + Arrows` | Keisti sričių dydį |

### Langai

| Spartusis klavišas                  | Funkcija              |
| ----------------------- | --------------------- |
| `Prefix + c` | Naujas langas |
| `Prefix + k` | Užmušti langą |
| `Prefix + r` | Pervadinti langą |
| `Alt + 1-9` | Pereiti į konkretų langą |
| `Alt + Arrow Left/Right` | Judėti tarp langų |
| `Alt + Shift + Arrow Left/Right` | Perkelti langą į kairę / dešinę |

### Seansai

| Spartusis klavišas                  | Funkcija              |
| ----------------------- | --------------------- |
| `Prefix + C` | Naujas seansas |
| `Prefix + K` | Užmušti seansą |
| `Prefix + R` | Pervadinti seansą |
| `Prefix + N` | Kitas seansas |
| `Prefix + P` | Ankstesnis seansas |
| `Alt + Arrow Up/Down` | Judėti tarp seansų |
| `Prefix + s` | Seansų sąrašas |
| `Prefix + d` | Atsijungti nuo seanso |

### Kopijavimo režimas (vi stiliaus)

| Spartusis klavišas                  | Funkcija              |
| ----------------------- | --------------------- |
| `Prefix + [` | Įjungti kopijavimo režimą |
| `v` | Pradėti žymėjimą (kopijavimo režime) |
| `y` | Kopijuoti žymėjimą (kopijavimo režime) |

### Bendra

| Spartusis klavišas                  | Funkcija              |
| ----------------------- | --------------------- |
| `Prefix + q` | Iš naujo įkelti konfigūraciją |
| `Prefix + ?` | Rodyti Tmux klavišų derinius |
| `Prefix + :` | Komandų eilutė |

### Tmux išdėstymo funkcijos

Šios funkcijos turi būti vykdomos Tmux seanso viduje.

| Komanda | Funkcija |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Sukurti kūrimo išdėstymą su redaktoriumi, AI ir terminalu |
| `tdlm <ai> [<second_ai>]` | Sukurti kūrimo išdėstymą kiekvienam pakatalogiui |
| `tsl <count> <command>` | Sukurti kelių sričių spiečiaus išdėstymą |
