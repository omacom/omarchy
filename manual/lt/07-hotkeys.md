# Spartieji klavišai

Visus pagrindinius klaviatūros susiejimus galite pamatyti su `Super + K` (Tmux susiejimus su `Super + Alt + K` ir Herdr susiejimus su `Super + Ctrl + K`).

## Naršymas

| Spartusis klavišas                  | Funkcija              |
| ----------------------- | --------------------- |
| `Super + Space`           | Omarchy meniu (programos ir visa kita)    |
| `Super + Alt + Space` | Programų tinklelis |
| `Super + Escape` | Sistemos meniu (pristabdyti, paleisti iš naujo ir kt.)  |
| `Super + Ctrl + L` | Užrakinti kompiuterį |
| `Super + W` or `Super + Q` | Uždaryti langą             |
| `Ctrl + Alt + Del` | Uždaryti visus langus |
| `Super + T`               | Perjungti langą tarp plytelių / plūduriuojančio             |
| `Super + J` | Perjungti lango padėtį (horizontali / vertikali) |
| `Super + O`               | Perjungti lango išstūmimą į lipnų ir plūduriuojantį |
| `Super + L`               | Cikliškai pereiti per dwindle, slenkantį ir plūduriuojantį išdėstymus |
| `Super + Alt + L`         | Cikliškai pereiti per išdėstymus atvirkštine tvarka |
| `Super + P`               | Perjungti pseudo lango stilių (natūralus ar ištemptas) |
| `Super + F`                 | Pereiti į visą ekraną              |
| `Super + Alt + F`                 | Pereiti į visą plotį              |
| `Super + Ctrl + F`                 | Pereiti į visą ekraną lango viduje              |
| `Super + 1/2/3/4`         | Šokti į konkrečią darbo sritį     |
| `Super + Tab` | Šokti į kitą darbo sritį |
| `Super + Shift + Tab` | Šokti į ankstesnę darbo sritį |
| `Super + Ctrl + Tab` | Šokti į buvusią darbo sritį |
| `Super + Shift + 1/2/3/4` | Perkelti langą į darbo sritį |
| `Super + Shift + Alt + 1/2/3/4` | Perkelti langą į darbo sritį nesekant paskui |
| `Super + S` / `Super + Grave` | Perjungti scratchpad |
| `Super + Alt + S` / `Super + Shift + Grave` | Perkelti langą į scratchpad |
| `Super + Shift + Alt + Arrows` | Perkelti darbo sritis į kryptinį monitorių |
| `Super + Arrow`  | Perkelti fokusą į langą rodyklės kryptimi              |
| `Super + Shift + Arrow`  | Sukeisti langą su kitu rodyklės kryptimi     |
| `Super + Minus` | Išplėsti langą į kairę |
| `Super + Equal` | Sutraukti langą į kairę |
| `Super + Shift + Minus` | Sutraukti langą aukštyn |
| `Super + Shift + Equal` | Išplėsti langą žemyn |
| `Super + Alt + Minus/Equal` | Tas pats dydžio keitimas mažesniais žingsniais |
| `Super + Ctrl + Minus/Equal` | Tas pats dydžio keitimas didesniais žingsniais |
| `Super + Alt + Home` | Išsaugoti lango plotį |
| `Super + Home` | Atkurti išsaugotą lango plotį |
| `Super + Left Mouse` | Vilkti langą aplink |
| `Super + Right Mouse` | Keisti lango dydį |
| `Super + Scroll Wheel` | Slinkti per darbo sritis |
| `Super + G`               | Perjungti langų grupavimą      |
| `Super + Alt + G`               | Perkelti langą iš grupavimo      |
| `Super + Alt + Tab`               | Cikliškai pereiti tarp langų grupėje      |
| `Super + Alt + Shift + Tab`               | Cikliškai pereiti atgal tarp langų grupėje      |
| `Super + Alt + 1/2/3/4/5`               | Šokti į konkretų langą grupėje      |
| `Super + Alt + Arrow`  | Perkelti langą į grupę rodyklės kryptimi  |
| `Super + Ctrl + Left/Right`  | Judėti tarp langų plytelių grupės viduje |
| `Super + Ctrl + Z` | Priartinti ekrane (kartoti didesniam priartinimui) |
| `Super + Ctrl + Alt + Z` | Visiškai atitolinti nuo ekrano |
| `Super + /` | Eiti į priekį per monitoriaus mastelio parinktis |
| `Super + Alt + /` | Eiti atgal per monitoriaus mastelio parinktis |
| `Alt + Tab` | Cikliškai pereiti į priekį per langus aktyvioje darbo srityje |
| `Alt + Shift + Tab` | Cikliškai pereiti atgal per langus aktyvioje darbo srityje |
| `Ctrl + Alt + Tab`| Cikliškai perkelti fokusą į priekį per monitorius |
| `Ctrl + Alt + Shift + Tab`| Cikliškai perkelti fokusą atgal per monitorius |

## Universali iškarpinė

| Spartusis klavišas                  | Funkcija              |
| ----------------------- | --------------------- |
| `Super + C`           | Kopijuoti    |
| `Super + X`           | Iškirpti (ne terminale)    |
| `Super + V`           | Įklijuoti    |
| `Super + Ctrl + V`           | Iškarpinės tvarkyklė    |

Paprastai Linux jums reikia `Ctrl + Shift + C/V`, kad kopijuotumėte ir įklijuotumėte terminale, ir `Ctrl + C/V`, kad tai darytumėte visur kitur. Šie Omarchy vieningos iškarpinės spartieji klavišai veikia visur.

## Fiksuoti

| Spartusis klavišas              | Funkcija                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Fiksavimo meniu (klaviatūroms be PrintScr mygtuko) |
| `Print Screen`            | Ekrano nuotrauka                      |
| `Alt + Print Screen`            | Ekrano įrašas                     |
| `Super + Print Screen` | Spalvos parinkiklis |
| `Super + Ctrl + Print Screen` | Teksto išgavimas į iškarpinę |
| `Super + Alt + [` | Įrašant padaryti kameros perdangą mažesnę |
| `Super + Alt + ]` | Įrašant padaryti kameros perdangą didesnę |
| `Alt + Shift + L` | Kopijuoti current URL from webapp or Chromium |
| `Alt + Shift + D` | Atsisiųsti vaizdo įrašą dabartiniame puslapyje į `~/Videos` |
| `Super + Ctrl + X` | Pradėti / stabdyti diktavimą (reikia _Nuostatos > Numatytosios > Diktavimas_) |
| `Right Alt` / `F9` | Diktavimas laikant nuspaudus (reikia Voxtype arba Superwhisper) |

Su ekrano įrašais spartusis klavišas pirmiausia paklausia, kokio garso norite, tada pradeda įrašyti. Paspauskite jį dar kartą, kad sustabdytumėte. Išsamią informaciją žr. [ekrano nuotraukos ir įrašymas](12-screenshots-recording.md).

Visos fiksavimo parinktys taip pat pasiekiamos po _Veiksmai > Fiksuoti_ Omarchy meniu (`Super + Space`).

## Tmux

Prefikso klavišas yra `Ctrl + Space` (`Ctrl + B` taip pat veikia). Šiuos susiejimus galite keisti `~/.config/tmux/tmux.conf`.

### Sritys

| Spartusis klavišas                  | Funkcija              |
| ----------------------- | --------------------- |
| `Prefix + v` | Padalyti sritį šalia (vertikaliai) |
| `Prefix + h` | Padalyti sritį žemiau (horizontaliai) |
| `Prefix + x` | Užmušti sritį |
| `Prefix + z` | Perjungti srities priartinimą (visas ekranas) |
| `Alt + Enter` | Padalyti sritį žemiau (be prefikso) |
| `Alt + Shift + Enter` | Padalyti sritį šalia (be prefikso) |
| `Alt + Escape` | Užmušti sritį (no prefix) |
| `Ctrl + Alt + Arrows` | Judėti tarp sričių |
| `Ctrl + Alt + Shift + Arrows` | Keisti sričių dydį |

### Langai

| Spartusis klavišas                  | Funkcija              |
| ----------------------- | --------------------- |
| `Prefix + c` | Naujas langas |
| `Prefix + k` | Užmušti langą |
| `Prefix + r` | Pervadinti langą |
| `Alt + 1-9` | Eiti į konkretų langą |
| `Alt + Arrow Left/Right` | Judėti tarp langų |
| `Alt + Shift + Arrow Left/Right` | Perkelti langą į kairę / dešinę |

### Sesijos

| Spartusis klavišas                  | Funkcija              |
| ----------------------- | --------------------- |
| `Prefix + C` | Nauja sesija |
| `Prefix + K` | Užmušti sesiją |
| `Prefix + R` | Pervadinti sesiją |
| `Prefix + N` | Kita sesija |
| `Prefix + P` | Ankstesnė sesija |
| `Alt + Arrow Up/Down` | Judėti tarp sesijų |
| `Prefix + s` | Išvardyti sesijas |
| `Prefix + d` | Atsijungti nuo sesijos |

### Kopijuoti mode (vi-style)

| Spartusis klavišas                  | Funkcija              |
| ----------------------- | --------------------- |
| `Prefix + [` | Įeiti į kopijavimo režimą |
| `v` | Pradėti pasirinkimą (kopijavimo režime) |
| `y` | Kopijuoti selection (in copy mode) |

### Bendra

| Spartusis klavišas                  | Funkcija              |
| ----------------------- | --------------------- |
| `Prefix + q` | Iš naujo įkelti konfigūraciją |
| `Prefix + ?` | Rodyti Tmux klavišų susiejimus |
| `Prefix + :` | Komandinė eilutė |

### Tmux išdėstymo funkcijos

Šias funkcijas reikia paleisti Tmux sesijos viduje.

| Komanda | Funkcija |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Sukurti dev išdėstymą su redaguokliu, AI ir terminalu |
| `tdlm <ai> [<second_ai>]` | Sukurti dev išdėstymą kiekvienam pakatalogiui |
| `tsl <count> <command>` | Sukurti kelių sričių spiečiaus išdėstymą |
