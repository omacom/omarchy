# Vieninga iškarpinė ir istorija

Paprastai Linux sistemoje terminale kopijuoti ir įklijuoti reikia `Ctrl + Shift + C/V`, o visur kitur — `Ctrl + C/V`. Prie to sunku priprasti visiems, kurie negimė ir neužaugo su Linux! Taip pat sunku persijungti nuo super prie ctrl, jei ateinate iš Mac.

Omarchy abi problemas sprendžia vieningais iškarpinės sparčiaisiais klavišais, kurie veikia (beveik) visur. Štai jie:

| Spartusis klavišas | Veiksmas |
| ------- | ----------- |
| Super + A | Pasirinkti viską |
| Super + C | Kopijuoti |
| Super + X | Iškirpti |
| Super + V | Įklijuoti |
| Super + Ctrl + V | Iškarpinės istorija |

_Atkreipkite dėmesį, kad dauguma agentų aplinkų vaizdams įklijuoti naudos `Ctrl + V`, o tekstui įklijuoti — `Super + V`._

Naudokite `Super + A`, tada `Super + C`, kad nukopijuotumėte viską aktyviame teksto lauke ar kitoje programoje, palaikančioje `Ctrl + A`. Terminale `Ctrl + A` perkelia į komandinės eilutės pradžią, o ne pasirenka jos tekstą.

### Iškarpinės istorija

Iškarpinės istoriją teikia Omarchy apvalkalas, ir ji veikia tiek tekstui, tiek vaizdams. Ją iškviečiate paspaudę `Super + Ctrl + V` ir klavišu return pasirenkate įrašą, kuris tada įklijuojamas tiesiai į programą, kurioje buvote. Naudokite `Shift + Return`, kad tik nukopijuotumėte jį į iškarpinę, `Alt + Return`, kad jį atidarytumėte, `Delete`, kad pašalintumėte jį iš istorijos, ir `Shift + Delete`, kad išvalytumėte visą istoriją.
