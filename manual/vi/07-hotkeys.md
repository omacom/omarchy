# Phím tắt

Bạn có thể xem tất cả các binding phím chính bằng `Super + K` (binding của Tmux bằng `Super + Alt + K` và binding của Herdr bằng `Super + Ctrl + K`).

## Điều hướng

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + Space`           | Menu Omarchy (ứng dụng và mọi thứ khác)    |
| `Super + Alt + Space` | Lưới ứng dụng |
| `Super + Escape` | Menu hệ thống (tạm dừng, khởi động lại, v.v.)  |
| `Super + Ctrl + L` | Khóa máy tính |
| `Super + W` or `Super + Q` | Đóng cửa sổ             |
| `Ctrl + Alt + Del` | Đóng tất cả cửa sổ |
| `Super + T`               | Bật/tắt cửa sổ giữa chế độ tiling/floating             |
| `Super + J` | Bật/tắt vị trí cửa sổ (ngang/dọc) |
| `Super + O`               | Bật/tắt đưa cửa sổ vào chế độ sticky'n'floating |
| `Super + L`               | Chuyển vòng qua các layout dwindle, scrolling và floating |
| `Super + Alt + L`         | Chuyển vòng qua các layout theo chiều ngược lại |
| `Super + P`               | Bật/tắt kiểu cửa sổ pseudo (natural v stretch) |
| `Super + F`                 | Vào chế độ toàn màn hình              |
| `Super + Alt + F`                 | Vào chế độ toàn chiều rộng              |

| `Super + Ctrl + Alt + Z` | Thu nhỏ hoàn toàn khỏi màn hình |

| `Super + Alt + /` | Lùi qua các tùy chọn tỷ lệ màn hình |

## Tmux

Phím prefix là `Ctrl + Space` (`Ctrl + B` cũng hoạt động). Bạn có thể thay đổi các binding này trong `~/.config/tmux/tmux.conf`.

### Các ô

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + v` | Chia ô sang bên cạnh (dọc) |
| `Prefix + h` | Chia ô xuống dưới (ngang) |
| `Prefix + x` | Đóng ô |
| `Prefix + z` | Bật/tắt zoom ô (toàn màn hình) |
| `Alt + Enter` | Chia ô xuống dưới (không cần prefix) |
| `Alt + Shift + Enter` | Chia ô sang bên cạnh (không cần prefix) |
| `Alt + Escape` | Đóng ô (không cần prefix) |
| `Ctrl + Alt + Arrows` | Di chuyển giữa các ô |
| `Ctrl + Alt + Shift + Arrows` | Thay đổi kích thước các ô |

### Cửa sổ

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + c` | Cửa sổ mới |
| `Prefix + k` | Đóng cửa sổ |
| `Prefix + r` | Đổi tên cửa sổ |
| `Alt + 1-9` | Đi đến cửa sổ cụ thể |
| `Alt + Arrow Left/Right` | Di chuyển giữa các cửa sổ |
| `Alt + Shift + Arrow Left/Right` | Di chuyển cửa sổ sang trái/phải |

### Phiên

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + C` | Phiên mới |
| `Prefix + K` | Đóng phiên |
| `Prefix + R` | Đổi tên phiên |
| `Prefix + N` | Phiên tiếp theo |
| `Prefix + P` | Phiên trước đó |
| `Alt + Arrow Up/Down` | Di chuyển giữa các phiên |
| `Prefix + s` | Liệt kê các phiên |
| `Prefix + d` | Tách khỏi phiên |

### Chế độ sao chép (kiểu vi)

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + [` | Vào chế độ sao chép |
| `v` | Bắt đầu chọn (trong chế độ sao chép) |
| `y` | Sao chép vùng chọn (trong chế độ sao chép) |

### Chung

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + q` | Tải lại cấu hình |
| `Prefix + ?` | Hiển thị các keybinding của Tmux |
| `Prefix + :` | Dấu nhắc lệnh |

### Các hàm layout của Tmux

Các hàm này phải được chạy bên trong một phiên Tmux.

| Command | Function |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Tạo layout phát triển với editor, AI và terminal |
| `tdlm <ai> [<second_ai>]` | Tạo layout phát triển cho từng thư mục con |
| `tsl <count> <command>` | Tạo layout swarm nhiều ô |
