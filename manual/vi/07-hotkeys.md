# Phím tắt

Bạn có thể xem tất cả các phím gán chính trên bàn phím bằng `Super + K` (phím gán Tmux bằng `Super + Alt + K` và phím gán Herdr bằng `Super + Ctrl + K`).

## Điều hướng

| Phím tắt                  | Chức năng              |
| ----------------------- | --------------------- |
| `Super + Space`           | Menu Omarchy (ứng dụng và mọi thứ khác)    |
| `Super + Alt + Space` | Lưới ứng dụng |
| `Super + Escape` | Menu hệ thống (tạm dừng, khởi động lại, v.v.)  |
| `Super + Ctrl + L` | Khóa máy tính |
| `Super + W` or `Super + Q` | Đóng cửa sổ             |
| `Ctrl + Alt + Del` | Đóng tất cả cửa sổ |
| `Super + T`               | Chuyển cửa sổ giữa xếp ô/nổi             |
| `Super + J` | Chuyển vị trí cửa sổ (ngang/dọc) |
| `Super + O`               | Chuyển việc bật cửa sổ thành dính và nổi |
| `Super + L`               | Chuyển qua các bố cục dwindle, cuộn và nổi |
| `Super + Alt + L`         | Chuyển qua các bố cục theo chiều ngược lại |
| `Super + P`               | Chuyển kiểu cửa sổ giả (tự nhiên so với kéo giãn) |
| `Super + F`                 | Chuyển sang toàn màn hình              |
| `Super + Alt + F`                 | Chuyển sang toàn chiều rộng              |
| `Super + Ctrl + F`                 | Chuyển sang toàn màn hình bên trong cửa sổ              |
| `Super + 1/2/3/4`         | Nhảy tới không gian làm việc cụ thể     |
| `Super + Tab` | Nhảy tới không gian làm việc tiếp theo |
| `Super + Shift + Tab` | Nhảy tới không gian làm việc trước đó |
| `Super + Ctrl + Tab` | Nhảy tới không gian làm việc trước đây |
| `Super + Shift + 1/2/3/4` | Di chuyển cửa sổ tới không gian làm việc |
| `Super + Shift + Alt + 1/2/3/4` | Di chuyển cửa sổ tới không gian làm việc mà không đi theo |
| `Super + S` / `Super + Grave` | Bật/tắt scratchpad |
| `Super + Alt + S` / `Super + Shift + Grave` | Di chuyển cửa sổ tới scratchpad |
| `Super + Shift + Alt + Arrows` | Di chuyển các không gian làm việc tới màn hình theo hướng |
| `Super + Arrow`  | Di chuyển tiêu điểm tới cửa sổ theo hướng mũi tên              |
| `Super + Shift + Arrow`  | Hoán đổi cửa sổ với cửa sổ khác theo hướng mũi tên     |
| `Super + Minus` | Mở rộng cửa sổ sang trái |
| `Super + Equal` | Thu nhỏ cửa sổ sang trái |
| `Super + Shift + Minus` | Thu nhỏ cửa sổ lên trên |
| `Super + Shift + Equal` | Mở rộng cửa sổ xuống dưới |
| `Super + Alt + Minus/Equal` | Thay đổi kích thước tương tự với bước nhỏ hơn |
| `Super + Ctrl + Minus/Equal` | Thay đổi kích thước tương tự với bước lớn hơn |
| `Super + Alt + Home` | Lưu chiều rộng cửa sổ |
| `Super + Home` | Khôi phục chiều rộng cửa sổ đã lưu |
| `Super + Left Mouse` | Kéo cửa sổ đi khắp nơi |
| `Super + Right Mouse` | Thay đổi kích thước cửa sổ |
| `Super + Scroll Wheel` | Cuộn qua các không gian làm việc |
| `Super + G`               | Bật/tắt nhóm cửa sổ      |
| `Super + Alt + G`               | Di chuyển cửa sổ ra khỏi nhóm      |
| `Super + Alt + Tab`               | Chuyển qua các cửa sổ trong nhóm      |
| `Super + Alt + Shift + Tab`               | Chuyển ngược lại qua các cửa sổ trong nhóm      |
| `Super + Alt + 1/2/3/4/5`               | Nhảy tới cửa sổ cụ thể trong nhóm      |
| `Super + Alt + Arrow`  | Di chuyển cửa sổ vào nhóm theo hướng mũi tên  |
| `Super + Ctrl + Left/Right`  | Di chuyển giữa các cửa sổ bên trong một nhóm xếp ô |
| `Super + Ctrl + Z` | Phóng to màn hình (lặp lại để phóng to hơn) |
| `Super + Ctrl + Alt + Z` | Thu nhỏ hoàn toàn khỏi màn hình |
| `Super + /` | Bước tới qua các tùy chọn tỷ lệ màn hình |
| `Super + Alt + /` | Bước lui qua các tùy chọn tỷ lệ màn hình |
| `Alt + Tab` | Chuyển tới qua các cửa sổ trên không gian làm việc đang hoạt động |
| `Alt + Shift + Tab` | Chuyển lui qua các cửa sổ trên không gian làm việc đang hoạt động |
| `Ctrl + Alt + Tab`| Chuyển tiêu điểm tới qua các màn hình |
| `Ctrl + Alt + Shift + Tab`| Chuyển tiêu điểm lui qua các màn hình |

## Bảng nhớ tạm phổ quát

| Phím tắt                  | Chức năng              |
| ----------------------- | --------------------- |
| `Super + C`           | Sao chép    |
| `Super + X`           | Cắt (không phải trong terminal)    |
| `Super + V`           | Dán    |
| `Super + Ctrl + V`           | Trình quản lý bảng nhớ tạm    |

Thông thường trên Linux, bạn cần `Ctrl + Shift + C/V` để sao chép và dán trong terminal và `Ctrl + C/V` để làm điều đó ở khắp mọi nơi khác. Các phím tắt bảng nhớ tạm thống nhất này của Omarchy hoạt động ở khắp mọi nơi.

## Chụp/ghi

| Phím tắt              | Chức năng                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Menu chụp/ghi (cho bàn phím không có nút PrintScr) |
| `Print Screen`            | Ảnh chụp màn hình                      |
| `Alt + Print Screen`            | Ghi màn hình                     |
| `Super + Print Screen` | Bộ chọn màu |
| `Super + Ctrl + Print Screen` | Trích xuất văn bản vào bảng nhớ tạm |
| `Super + Alt + [` | Thu nhỏ lớp phủ webcam trong khi ghi |
| `Super + Alt + ]` | Phóng to lớp phủ webcam trong khi ghi |
| `Alt + Shift + L` | Sao chép URL hiện tại từ webapp hoặc Chromium |
| `Alt + Shift + D` | Tải video trên trang hiện tại xuống `~/Videos` |
| `Super + Ctrl + X` | Bắt đầu/dừng đọc chính tả (yêu cầu _Thiết lập > Mặc định > Đọc chính tả_) |
| `Right Alt` / `F9` | Đọc chính tả nhấn để nói (yêu cầu Voxtype hoặc Superwhisper) |

Với ghi màn hình, phím tắt trước tiên hỏi bạn muốn âm thanh nào, sau đó bắt đầu ghi. Nhấn lại để dừng. Xem [ảnh chụp màn hình và ghi hình](12-screenshots-recording.md) để biết chi tiết.

Mọi tùy chọn chụp/ghi cũng có thể truy cập trong _Kích hoạt > Chụp/ghi_ trong menu Omarchy (`Super + Space`).

## Tmux

Phím tiền tố là `Ctrl + Space` (`Ctrl + B` cũng hoạt động). Bạn có thể thay đổi các phím gán này trong `~/.config/tmux/tmux.conf`.

### Ô

| Phím tắt                  | Chức năng              |
| ----------------------- | --------------------- |
| `Prefix + v` | Chia ô bên cạnh (dọc) |
| `Prefix + h` | Chia ô bên dưới (ngang) |
| `Prefix + x` | Giết ô |
| `Prefix + z` | Bật/tắt phóng to ô (toàn màn hình) |
| `Alt + Enter` | Chia ô bên dưới (không có tiền tố) |
| `Alt + Shift + Enter` | Chia ô bên cạnh (không có tiền tố) |
| `Alt + Escape` | Giết ô (không có tiền tố) |
| `Ctrl + Alt + Arrows` | Di chuyển giữa các ô |
| `Ctrl + Alt + Shift + Arrows` | Thay đổi kích thước các ô |

### Cửa sổ

| Phím tắt                  | Chức năng              |
| ----------------------- | --------------------- |
| `Prefix + c` | Cửa sổ mới |
| `Prefix + k` | Giết cửa sổ |
| `Prefix + r` | Đổi tên cửa sổ |
| `Alt + 1-9` | Đi tới cửa sổ cụ thể |
| `Alt + Arrow Left/Right` | Di chuyển giữa các cửa sổ |
| `Alt + Shift + Arrow Left/Right` | Di chuyển cửa sổ sang trái/phải |

### Phiên

| Phím tắt                  | Chức năng              |
| ----------------------- | --------------------- |
| `Prefix + C` | Phiên mới |
| `Prefix + K` | Giết phiên |
| `Prefix + R` | Đổi tên phiên |
| `Prefix + N` | Phiên tiếp theo |
| `Prefix + P` | Phiên trước đó |
| `Alt + Arrow Up/Down` | Di chuyển giữa các phiên |
| `Prefix + s` | Liệt kê các phiên |
| `Prefix + d` | Tách khỏi phiên |

### Chế độ sao chép (kiểu vi)

| Phím tắt                  | Chức năng              |
| ----------------------- | --------------------- |
| `Prefix + [` | Vào chế độ sao chép |
| `v` | Bắt đầu chọn (trong chế độ sao chép) |
| `y` | Sao chép vùng chọn (trong chế độ sao chép) |

### Chung

| Phím tắt                  | Chức năng              |
| ----------------------- | --------------------- |
| `Prefix + q` | Tải lại cấu hình |
| `Prefix + ?` | Hiển thị phím gán Tmux |
| `Prefix + :` | Dấu nhắc lệnh |

### Hàm bố cục Tmux

Các hàm này phải được chạy bên trong một phiên Tmux.

| Lệnh | Chức năng |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Tạo bố cục dev với trình soạn thảo, AI và terminal |
| `tdlm <ai> [<second_ai>]` | Tạo bố cục dev cho mỗi thư mục con |
| `tsl <count> <command>` | Tạo bố cục đàn nhiều ô |
