# Neovim

[Neovim](https://neovim.io/) — современная реализация [редактора vi](<https://en.wikipedia.org/wiki/Vi_(text_editor)>) за авторством Билла Джоя аж из 1976-го. Модальный редактор, где режим вставки и командный режим разделены, — и это прямо суперсила, стоит выучить хоть подмножество невероятно глубокого набора кей-команд. Но кривая обучения тоже будь здоров!

Если в vim-стиле редактирования вообще ноль — рекомендую серию [ThePrimeagen «Vim As Your Editor»](https://www.youtube.com/watch?v=X6AR2RMB5tE&list=PLm323Lc7iSW_wuxqmKx_xxNtJC_hJbQ7R) на YouTube. Научит азам. Только учти: в отличие от более похожих мейнстримных редакторов, базовая сноровка во vim займёт дольше. Но как поймёшь — отдача будет больше.

Теперь Neovim конфигурится практически бесконечно. Хочешь упороться по-настоящему — собери свой конфиг Neovim с нуля. Отличный курс — [Typecraft про сетап Neovim с нуля](https://www.youtube.com/watch?v=zHTeCSVAFNY). И [у ThePrimeagen такой есть](https://www.youtube.com/watch?v=w7i4amO_zaE).

Но в Omarchy из коробки полный сетап Neovim — пакет `omarchy-nvim`, — любовно натюненный показать лучшее из возможного сразу. Не написав ни строчки конфига! Собран на [LazyVim](https://www.lazyvim.org/) — дистрибутиве neovim-плагинов и конфигов. Огонь.

## Азы LazyVim

Как сказано, учить vim в этом коротком интро не буду, но пару азов LazyVim покажу — и как ходить.

Во-первых, в Neovim есть идея leader-клавиши. Это, по сути, шлюз ко всем командам. LazyVim ставит её на `Space`. Просто нажми, подожди секунду — и увидишь кучу опций, расписанных инлайн вроде такого:

Вот базовые команды, которыми пользуюсь всё время:

- `Space Space` — нечёткий поиск любого файла в текущем каталоге.
- `Space S G` — поиск по файлам через grep с превью.
- `Space E` — тогл дерева файлов вкл/выкл.
- `Ctrl + W W` — прыгать дерево-редактор и обратно.
- `Shift + H` — влево по открытым табам (vim зовёт их буферами).
- `Shift + L` — вправо по открытым табам.
- `Space B D` — закрыть таб.
- `Space B O` — закрыть все табы кроме текущего.
- `Space G G` — поднять LazyGit в плавающей панели из текущего каталога.
- `Space U W` — тогл мягкого переноса.

В дереве файлов (`Space E` показать, `Ctrl + W W` прыгнуть туда) новый файл добавляется через `a`, новый каталог — через `A`. Нажми `?` в дереве — увидишь все команды.

Хочешь взять базовый язык vim — я писал про [трёхчастный синтаксис](https://world.hey.com/dhh/wonderful-vi-a1d034d3) и как тянуть эти sick-комбо!

Все возможные команды — на [странице кеймапов LazyVim](https://www.lazyvim.org/keymaps).

## Старт Neovim

Neovim стартует с `Super + Shift + N` (хоткей запускает дефолтный редактор, из коробки это Neovim), но обычно проще гнать из терминала: идёшь в каталог, где работать, и печатаешь `n`. `n` — алиас `nvim`, который по умолчанию откроет текущий каталог. Один файл открывается через `n myfile.txt`.

## Neovim для sudo-правок

Править файлы, которые меняются только суперюзером, можно неовимом со всеми плагинами: `sudoedit /etc/sudoers.d/00-sudo-only-file`.
