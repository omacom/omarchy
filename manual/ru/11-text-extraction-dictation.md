# Извлечение текста и диктовка

### Извлечение текста

Нажмите `Super + Ctrl + PrtScr`, чтобы выделить область на экране для извлечения текста. Открытая OCR-модель tesseract затем быстро преобразует выделенное в текст и поместит его в буфер обмена. Затем просто нажмите `Super + V`, чтобы вставить.

Это очень удобно, чтобы вытаскивать адреса из подвалов изображений или номера телефонов, встроенные в заголовки сайтов.

### Диктовка

При чистой установке [Superwhisper](https://superwhisper.com/) является бэкендом диктовки по умолчанию и использует облачную обработку без загрузки офлайн-моделей. Выберите Superwhisper или [Voxtype](https://voxtype.io/) через _Setup > Defaults > Dictation_ в меню Omarchy. Выбор бэкенда устанавливает его при необходимости и делает его используемым по умолчанию для диктовки. Voxtype загружает базовую английскую модель, которая занимает 150MB; сменить модель можно командой `voxtype setup model`, а другие настройки изменить через `~/.config/voxtype/config.toml`. Superwhisper открывает свои настройки для выбора облачной или локальной обработки, а OPR поддерживает приложение в актуальном состоянии.

Диктовать можно, удерживая `Right Alt`, или переключая режим сочетанием `Alt + Space`, и надиктованный текст появится в области ввода, находящейся в фокусе. Эти сочетания используют выбранный бэкенд. Right Alt также запускает диктовку при использовании в аккорде с модификатором; для таких аккордов используйте Left Alt. На раскладках клавиатуры, где Right Alt является AltGr, используйте `Alt + Space`, чтобы AltGr оставался доступным для ввода. В установках, сделанных до того, как Alt + Space стал значением по умолчанию, сохраняются `F9` для push-to-talk и `Super + Ctrl + X` для переключения, добавленные в `~/.config/hypr/bindings.lua`; удалите их там, чтобы вернуть эти клавиши приложениям.

Те же сочетания работают с любым бэкендом. Выберите бэкенд через Setup > Defaults > Dictation. Установщик бэкенда настраивает его и сохраняет выбор. Выполните `omarchy default dictation`, чтобы увидеть, какой бэкенд выбран. Выбор сохраняется в `~/.config/omarchy/defaults/dictation`. При чистой установке Superwhisper выбирается автоматически.

Omarchy автоматически загружает интеграцию выбранного бэкенда с рабочим столом. Никакой конфигурации Superwhisper в `~/.config/hypr/` не требуется.

Пользовательские привязки и скрипты могут использовать `omarchy dictation start`, `omarchy dictation stop` и `omarchy dictation toggle`. Выбранный бэкенд обрабатывает запись и транскрипцию. Выбор Superwhisper отключает его родное сочетание для удержания и устанавливает его родное переключение на `Ctrl + Alt + Space`, отделяя его от клавиш записи Omarchy. Superwhisper требует как минимум одно родное сочетание для записи, а его сочетание отмены остаётся доступным.

Дополнительные бэкенды могут интегрироваться без изменения Omarchy. Предоставьте исполняемый файл с именем `omarchy-dictation-<backend>` в PATH, который принимает `start`, `stop` и `toggle` и завершается быстро, возвращая ненулевой статус при сбое. Его установщик настраивает провайдера и после успешной настройки вызывает `omarchy-dictation-use <backend>`. Это останавливает предыдущий бэкенд и атомарно сохраняет выбор; `stop` должен успешно завершаться, когда провайдер простаивает или недоступен. В именах бэкендов используются строчные буквы, цифры и дефисы. Предоставьте `omarchy-install-dictation-<backend>` для настройки; `omarchy default dictation <backend>` запускает его. Добавьте пункт в меню Defaults через расширение меню Omarchy, чтобы вызывать этот селектор. Необязательная интеграция с рабочим столом может находиться в `${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua`.
