# Извлечение текста и диктовка

### Извлечение текста

Нажмите `Super + Ctrl + PrtScr`, чтобы выбрать область на экране для извлечения текста. Открытая OCR-модель tesseract затем быстро превратит эту выбранную область в текст и поместит его в буфер обмена. Затем просто нажмите `Super + V`, чтобы вставить.

Это очень помогает вытаскивать адреса из подвалов в виде изображений или номера телефонов, встроенные в заголовки веб-сайтов.

### Диктовка

При свежих установках [Superwhisper](https://superwhisper.com/) является бэкендом диктовки по умолчанию и использует облачную обработку без загрузки офлайн-моделей. Выберите Superwhisper, [Voxtype](https://voxtype.io/) или [Hex](https://anoma.ly/hex/) через _Setup > Defaults > Dictation_ в меню Omarchy. Выбор бэкенда устанавливает его при необходимости и делает его бэкендом диктовки по умолчанию. Voxtype загружает базовую английскую модель, которая занимает 150MB; смените модель с помощью `voxtype setup model`, а другие настройки — через `~/.config/voxtype/config.toml`. Superwhisper открывает свои настройки, чтобы выбрать облачную или локальную обработку, а OPR поддерживает приложение в актуальном состоянии. Hex загружает свою речевую модель на устройстве во время настройки и работает как пользовательская служба `hex.service`; откройте его окно с помощью значка в трее на панели или запустив `hex`, чтобы изменить модель и другие настройки.

Вы диктуете, удерживая `Right Alt` или переключая диктовку с помощью `Alt + Space`, и надиктованный текст появится в области ввода, находящейся в фокусе. Эти сочетания клавиш используют выбранный бэкенд. Right Alt также запускает диктовку, когда используется в аккорде с модификатором; для таких аккордов используйте Left Alt. В раскладках клавиатуры, где Right Alt является AltGr, в том числе когда такая раскладка — одна из тех, на которые вы переключаетесь, удерживайте её отдельно в течение мгновения, чтобы диктовать; AltGr, нажатая вместе с другой клавишей, по-прежнему вводит свой символ. Установки, сделанные до того, как Alt + Space стал вариантом по умолчанию, сохраняют `F9` для режима push-to-talk и `Super + Ctrl + X` для переключения, добавленные в `~/.config/hypr/bindings.lua`, где этот `Super + Ctrl + X` занимает место панели агентов; удалите их там, чтобы вернуть эти клавиши приложениям и панели.

Одни и те же сочетания клавиш работают с каждым бэкендом. Выберите свой бэкенд через Setup > Defaults > Dictation. Установщик бэкенда настраивает его и сохраняет выбор. Выполните `omarchy default dictation`, чтобы увидеть, какой бэкенд выбран. Выбор сохраняется в `~/.config/omarchy/defaults/dictation`. При свежих установках Superwhisper выбирается автоматически.

Omarchy автоматически загружает интеграцию с рабочим столом выбранного бэкенда. Никакая конфигурация Superwhisper в `~/.config/hypr/` не требуется.

Пользовательские привязки и скрипты могут использовать `omarchy dictation start`, `omarchy dictation stop` и `omarchy dictation toggle`. Выбранный бэкенд обрабатывает запись и транскрипцию. Выбор Superwhisper отключает его собственное сочетание для удержания и устанавливает его собственное переключение на `Ctrl + Alt + Space`, отделяя его от клавиш записи Omarchy. Superwhisper требует как минимум одно собственное сочетание для записи, а его сочетание отмены остаётся доступным.

Дополнительные бэкенды могут интегрироваться без изменения Omarchy. Предоставьте исполняемый файл с именем `omarchy-dictation-<backend>` в PATH, который принимает `start`, `stop` и `toggle` и быстро завершает работу, возвращая ненулевой статус при сбое. Его установщик настраивает провайдера и вызывает `omarchy-dictation-use <backend>` после успешной настройки. Это останавливает предыдущий бэкенд и атомарно сохраняет выбор; `stop` должен завершаться успешно, когда провайдер простаивает или недоступен. Имена бэкендов используют строчные буквы, цифры и дефисы. Предоставьте `omarchy-install-dictation-<backend>` для настройки; `omarchy default dictation <backend>` запускает его. Добавьте пункт меню Defaults через расширение меню Omarchy, чтобы вызывать этот селектор. Необязательная интеграция с рабочим столом может находиться в `${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua`.
