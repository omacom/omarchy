# Извлечение текста и диктовка

### Извлечение текста

Нажмите `Super + Ctrl + PrtScr`, чтобы выделить область на экране для извлечения текста. Модель OCR tesseract с открытым исходным кодом затем быстро преобразует выделенное в текст и поместит его в буфер обмена. Затем просто нажмите `Super + V`, чтобы вставить.

Это очень полезно, чтобы вытащить адреса из подвалов изображений или номера телефонов, встроенные в заголовки сайтов.

### Диктовка

На свежих установках [Superwhisper](https://superwhisper.com/) — бэкенд диктовки по умолчанию, использующий облачную обработку без загрузки офлайн-моделей. Выберите Superwhisper, [Voxtype](https://voxtype.io/) или [Hex](https://anoma.ly/hex/) через _Setup > Defaults > Dictation_ в меню Omarchy. Выбор бэкенда установит его при необходимости и сделает его бэкендом по умолчанию для диктовки. Voxtype загружает базовую английскую модель, которая занимает 150MB; смените модель с помощью `voxtype setup model`, а остальные настройки — через `~/.config/voxtype/config.toml`. Superwhisper открывает свои настройки для выбора облачной или локальной обработки, а OPR поддерживает приложение обновлённым. Hex загружает свою модель речи на устройстве во время настройки и работает как пользовательская служба `hex.service`; откройте его окно из значка в трее на панели или запустив `hex`, чтобы изменить модель и другие настройки.

Вы диктуете, удерживая `Right Alt`, или переключаясь с помощью `Alt + Space`, и надиктованный текст появится в области ввода в фокусе. Эти сочетания используют выбранный бэкенд. Right Alt также запускает диктовку при использовании в комбинации с модификаторами; для таких комбинаций используйте Left Alt. На раскладках клавиатуры, где Right Alt является AltGr, используйте `Alt + Space`, чтобы AltGr оставался доступен для ввода. Установки, сделанные до того, как Alt + Space стал настройкой по умолчанию, сохраняют `F9` для push-to-talk и `Super + Ctrl + X` для переключения, добавленные в `~/.config/hypr/bindings.lua`, где этот `Super + Ctrl + X` занимает место панели агентов; удалите их там, чтобы вернуть эти клавиши приложениям и панели.

Те же сочетания работают с каждым бэкендом. Выберите свой бэкенд через Setup > Defaults > Dictation. Установщик бэкенда настраивает его и сохраняет выбор. Запустите `omarchy default dictation`, чтобы увидеть, какой из них выбран. Выбор сохраняется в `~/.config/omarchy/defaults/dictation`. Свежие установки автоматически выбирают Superwhisper.

Omarchy автоматически загружает интеграцию выбранного бэкенда с рабочим столом. Никакой конфигурации Superwhisper в `~/.config/hypr/` не требуется.

Пользовательские привязки и скрипты могут использовать `omarchy dictation start`, `omarchy dictation stop` и `omarchy dictation toggle`. Выбранный бэкенд обрабатывает запись и транскрипцию. Выбор Superwhisper отключает его собственное сочетание удерживания и устанавливает его собственное переключение на `Ctrl + Alt + Space`, сохраняя его отдельно от клавиш записи Omarchy. Superwhisper требует как минимум одно собственное сочетание записи, а его сочетание отмены остаётся доступным.

Дополнительные бэкенды могут интегрироваться без изменения Omarchy. Предоставьте исполняемый файл с именем `omarchy-dictation-<backend>` в PATH, который принимает `start`, `stop` и `toggle` и быстро завершается, с ненулевым статусом при сбое. Его установщик настраивает провайдера и вызывает `omarchy-dictation-use <backend>` после успешной настройки. Это останавливает предыдущий бэкенд и атомарно сохраняет выбор; `stop` должен успешно выполняться, когда провайдер простаивает или недоступен. Имена бэкендов используют строчные буквы, цифры и дефисы. Предоставьте `omarchy-install-dictation-<backend>` для настройки; `omarchy default dictation <backend>` запускает его. Добавьте пункт меню Defaults через расширение меню Omarchy, чтобы вызывать этот селектор. Необязательная интеграция с рабочим столом может находиться в `${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua`.
