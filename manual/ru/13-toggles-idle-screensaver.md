# Переключатели, простой и заставка

Многое из того, что вы меняете изо дня в день, на самом деле не является настройкой. Это режим, который вы включаете на час и снова выключаете: ночной свет, пока работаете поздно, не беспокоить, пока презентуете, не засыпать, пока что-то смотрите. Omarchy называет их переключателями, и все они работают одинаково — сочетание клавиш, пункт меню и команда, все воздействующие на один переключатель.

### Меню переключателей

`Super + Ctrl + O` открывает _Действия > Переключить_ напрямую, или туда можно дойти из меню Omarchy (`Super + Space`). Всё в этом списке — переключатель, который можно щёлкнуть, не думая о том, где живёт состояние. Переключатели внешнего вида рабочего стола находятся рядом, в _Действия > Внешний вид_.

Из терминала те же переключатели — `omarchy toggle <thing>`. Выполните `omarchy toggle` сам по себе, чтобы увидеть всю группу.

| Переключатель | Сочетание | Команда |
| ------ | ------ | ------- |
| Ночной свет | `Super + Ctrl + N` | `omarchy toggle nightlight` |
| Заглушить уведомления | `Super + Ctrl + ,` | `omarchy toggle notification silencing` |
| Не засыпать (нет блокировки при простое) | `Super + Ctrl + I` | `omarchy toggle idle` |
| Отлов сбоев | — | `omarchy toggle crash-capture` |
| Заставка | — | `omarchy toggle screensaver` |
| Синхронизация темы [Herdr](https://herdr.dev) | — | `omarchy toggle theme sync` |
| Панель меню | `Super + Shift + Space` | `omarchy toggle bar` |
| Тачпад | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| Сенсорный экран | — | `omarchy toggle touchscreen` |
| Сон | — | `omarchy toggle suspend` |
| Гибридный GPU | — | `omarchy toggle hybrid gpu` |

Переключатели тачпада, сенсорного экрана и гибридного GPU живут в _Действия > Оборудование_ (`Super + Ctrl + H`), а не в Переключить, поскольку появляются только при наличии такого оборудования. Тачпад и сенсорный экран переживают перезагрузку Hyprland — имя отключённого устройства сохраняется в небольшой файл состояния, который Hyprland читает при запуске, чтобы снова его отключить.

_Действия > Внешний вид_ содержит панель меню и анимации, а также несколько вещей, которые не являются командами `omarchy toggle`, но ведут себя так же: процент батареи в панели, раскладка рабочих пространств по умолчанию, зазоры окон (`Super + Shift + Backspace`) и пропорции 1 окна (`Super + Ctrl + Backspace`).

Большинство из них — просто файл флага в `~/.local/state/omarchy/toggles/`. Если нужно ветвиться по одному из них в скрипте, `omarchy-toggle-enabled` даёт код выхода вместо того, чтобы заставлять вас искать:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

Флаги названы по выключенному состоянию — `screensaver-off`, `suspend-off`, `bar-off` — поэтому их присутствие означает, что функция отключена.

### Индикаторы в панели

Когда режим включён, в середине верхней панели рядом с часами появляется небольшой глиф. Это виджет индикаторов, несущий диктовку, запись экрана, ожидающие напоминания, ночной свет, не беспокоить и не засыпать.

Неактивные индикаторы скрыты. Наведите курсор на область вокруг них, и они появятся приглушённо, чтобы можно было щёлкнуть по одному и включить его, не зная сочетания. Щелчок по активному выключает его обратно. Если вы предпочитаете видеть их все всё время, установите `alwaysShow` в `true` в записи `omarchy.indicators` в `~/.config/omarchy/shell.json` — см. [верхнюю панель](05-the-top-bar.md) о том, как настраиваются виджеты панели.

### Ночной свет

`Super + Ctrl + N` нагревает экран до 4000K, а повторное нажатие возвращает его к 6500K. Им управляет hyprsunset, который переключатель запускает за вас, если он ещё не запущен.

По умолчанию hyprsunset вообще ничего не делает с вашим экраном. `~/.config/hypr/hyprsunset.conf` поставляется с профилем тождества именно для того, чтобы дисплей оставался нетронутым, пока вы не попросите тепла. Если вы предпочитаете переключение по часам, замените это профилем времени:

```
profile {
    time = 20:00
    temperature = 4000
}
```

Затем запускайте hyprsunset при входе, добавив `o.launch_on_start("hyprsunset")` в `~/.config/hypr/autostart.lua`. Пара 4000K/6500K, используемая переключателем, фиксирована, поэтому файл конфигурации — то место, куда идти, если нужна другая температура.

### Не беспокоить

`Super + Ctrl + ,` заглушает уведомления. Никакие всплывающие уведомления не появляются, пока режим включён, а индикатор перечёркнутого колокольчика сидит в панели, напоминая, почему рабочий стол притих.

Но ничего не теряется. Заглушённое уведомление записывается прямо в историю уведомлений, что именно та запись, которая нужна, когда вы вернётесь и задумаетесь, что пропустили. Откройте её через `Super + Shift + Alt + ,`. См. [уведомления](10-notices.md) об остальной истории уведомлений.

Два вида сообщений всё ещё проходят: собственные подтверждения Omarchy о том, что вы только что сделали («Theme changed», «Screenshot saved»), и критические оповещения, отправленные из командной строки. Чат-приложения, помечающие всё как критическое, чтобы пробиться перед вами, не подходят.

### Простой

Оболочка Omarchy владеет поведением при простое, а тайминги — блок `idle` верхнего уровня в `~/.config/omarchy/shell.json`:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

Оба числа — секунды, отсчитываемые с момента перехода в простой, а не друг от друга. Так что по умолчанию заставка появляется через две с половиной минуты, а экран блокировки берёт верх через пять минут, независимо от того, работала ли заставка. Сохраните файл, и оболочка сразу примет новые тайминги.

Если вы закроете заставку до крайнего срока блокировки, это считается активностью, и ожидаемая блокировка отменяется. Вас не блокируют за взгляд на машину.

Чтобы полностью прекратить блокировку при простое, `Super + Ctrl + I` — или `omarchy toggle idle` — включает «не засыпать», и в панели появляется индикатор чашки кофе. Именно это нужно нажать перед долгой презентацией или сборкой, за которой вы хотите наблюдать. Нажмите ещё раз, чтобы вернуться к обычному режиму. `omarchy toggle idle status` печатает текущее состояние как JSON, если нужно из скрипта.

Речь о блокировке и заставке, а не о питании. Сон и гибернация имеют собственную настройку в [сон системы](36-system-sleep.md).

### Заставка

Заставка Omarchy — это ASCII-арт, проходящий через случайные текстовые эффекты, по одному экземпляру на монитор. Любая клавиша или движение мыши выходит из неё.

Запустить её по требованию можно из _Система > Заставка_ (`Super + Esc`), что принудительно выводит её, даже если вы отключили заставку при простое. Сочетания клавиш по умолчанию для неё не назначено.

`omarchy toggle screensaver` выключает заставку при простое, если вы предпочитаете переходить прямо от работы к блокировке. Ей нужен терминал, который она умеет настраивать — Alacritty, Foot, Ghostty или Kitty — и она скажет об этом, если ваш терминал по умолчанию другой.

Логотип, который она рисует, можно изменить в _Стиль > Заставка_. Загрузите png или svg, и Omarchy преобразует его в ASCII. См. [брендинг](41-branding.md).

### Экран блокировки

`Super + Ctrl + L` блокирует машину. Это запускает экран блокировки из оболочки Omarchy, гасит дисплей, сбрасывает раскладку клавиатуры на первую, чтобы вы не вводили пароль не в том алфавите, и — если у вас запущен 1Password — блокирует его по пути.

Экран блокировки принимает пароль, а также примет отпечаток пальца, как только вы его настроите. Это и другие способы аутентификации описаны в [аппаратная аутентификация](37-hardware-authentication.md).
