# Тоглы, простой и скринсейвер

Многое из того, что меняешь день ото дня, — вообще не настройка. Это режим, который включаешь на час и выключаешь обратно: ночной свет, пока работаешь допоздна, не беспокоить, пока презентуешь, stay awake, пока смотришь что-то. Omarchy зовёт их тоглами, и все работают одинаково — хоткей, пункт меню и команда бьют в один и тот же свитч.

### Меню тоглов

`Super + Ctrl + O` открывает _Действия > Переключатели_ напрямую, а можно дойти из меню Omarchy (`Super + Space`). Всё в этом списке — свитч, который дёргаешь не думая, где живёт состояние.

Из терминала те же свитчи — `omarchy toggle <thing>`. Запусти `omarchy toggle` как есть — покажет всю группу.

| Тогл | Хоткей | Команда |
| ------ | ------ | ------- |
| Ночной свет | `Super + Ctrl + N` | `omarchy toggle nightlight` |
| Тихий режим уведомлений | `Super + Ctrl + ,` | `omarchy toggle notification silencing` |
| Stay awake (без лока в простое) | `Super + Ctrl + I` | `omarchy toggle idle` |
| Crash capture | — | `omarchy toggle crash-capture` |
| Скринсейвер | — | `omarchy toggle screensaver` |
| Синк темы [Herdr](https://herdr.dev) | — | `omarchy toggle theme sync` |
| Панель меню | `Super + Shift + Space` | `omarchy toggle bar` |
| Тачпад | `XF86TouchpadToggle` | `omarchy toggle touchpad` |
| Тачскрин | — | `omarchy toggle touchscreen` |
| Сон | — | `omarchy toggle suspend` |
| Гибридное GPU | — | `omarchy toggle hybrid gpu` |

Тачпад, тачскрин и гибридное GPU живут под _Действия > Оборудование_ (`Super + Ctrl + H`), а не под Переключатели, — они там, только когда железо правда есть. Тачпадный и тачскриновый переживают рестарт Hyprland — имя выключенного девайса пишется в маленький стейт-файл, который Hyprland читает на старте и выключает его обратно.

В меню Toggle лежит и кое-что не из команд `omarchy toggle`, но ведёт себя так же: проценты батареи в панели, layout столов (`Super + L`), отступы окон (`Super + Shift + Backspace`) и квадратный аспект на 1 окно (`Super + Ctrl + Backspace`).

Большинство — просто файл-флаг под `~/.local/state/omarchy/toggles/`. Хочешь ветвиться по нему в скрипте — `omarchy-toggle-enabled` отдаст exit-код, не лазя искать:

```bash
omarchy-toggle-enabled screensaver-off && echo "screensaver is off"
```

Флаги названы по выключенному состоянию — `screensaver-off`, `suspend-off`, `bar-off` — так что их наличие значит, что фича выключена.

### Индикаторы в панели

Когда режим включён, в середине верхней панели рядом с часами висит маленький глиф. Это виджет индикаторов: в нём диктовка, запись экрана, висящие напоминания, ночной свет, не беспокоить и stay awake.

Неактивные индикаторы спрятаны. Наведи на область около них — проступят тускло, так что включить можно кликом, не зная хоткея. Клик по активному выключает обратно. Хочешь видеть все всегда — поставь `alwaysShow` в `true` на записи `omarchy.indicators` в `~/.config/omarchy/shell.json` — как конфигурятся виджеты панели, см. [верхнюю панель](05-the-top-bar.md).

### Ночной свет

`Super + Ctrl + N` греет экран до 4000K, повторный жамк возвращает на 6500K. Едет на hyprsunset, который тогл сам стартует, если ещё не бежит.

По умолчанию hyprsunset с экраном вообще ничего не делает. `~/.config/hypr/hyprsunset.conf` из коробки с identity-профилем — ровно чтобы дисплей не трогали, пока не попросишь тепла. Хочешь по часам — замени на time-профиль:

```
profile {
    time = 20:00
    temperature = 4000
}
```

Потом добавь старт hyprsunset при логине строкой `o.launch_on_start("hyprsunset")` в `~/.config/hypr/autostart.lua`. Пара 4000K/6500K у тогла зашита, так что за другой температурой — в конфиг.

### Не беспокоить

`Super + Ctrl + ,` глушит уведомления. Пока включено, тосты не лезут, а в панели сидит перечёркнутый колокольчик — напоминание, чего стол притих.

Ничего не теряется. Приглушённое уведомление пишется прямиком в историю уведомлений — ровно та запись, что надо, когда вернёшься и задумаешься, что пропустил. Открывается через `Super + Shift + Alt + ,`. Остальное про уведомления — в [нотисах](10-notices.md).

Два сорта сообщений всё равно проходят: собственные подтверждения Omarchy на то, что только что сделал («Theme changed», «Screenshot saved»), и крит-алерты из командной строки. Чаты, которые всё подряд метят критом, чтобы пролезть вперёд, — не канают.

### Простой

Простоем владеет шелл Omarchy, а тайминги — топлевел-блок `idle` в `~/.config/omarchy/shell.json`:

```json
{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}
```

Оба числа — секунды с момента, как ушёл в простой, а не друг от друга. Так что с дефолтами скринсейвер встаёт через две с половиной минуты, а лок забирает на пяти минутах — крутился там скринсейвер или нет. Сохранил файл — шелл подхватил новые тайминги сразу.

Отмахнулся от скринсейвера до дедлайна лока — это засчиталось активностью, и висящий лок отменён. За взгляд на машину не замокан.

Чтобы вырубить лок в простое совсем — `Super + Ctrl + I`, он же `omarchy toggle idle`, включает stay awake, и в панели появляется кофейная чашка. Его жми перед долгой презой или сборкой, на которую хочешь смотреть. Жми ещё раз — назад в норму. `omarchy toggle idle status` печатает текущее состояние JSONом, если надо из скрипта.

Это про лок и скринсейвер, не про питание. Сон и гибернация настраиваются отдельно в [системном сне](36-system-sleep.md).

### Скринсейвер

Скринсейвер Omarchy — ASCII-арт через случайные текстовые эффекты, по инстансу на монитор. Любая клавиша или движение мыши его гасит.

Можно стартовать по требованию из _Система > Заставка_ (`Super + Esc`) — поднимет принудительно, даже если idle-скринсейвер выключен. Хоткея по умолчанию нет.

`omarchy toggle screensaver` — это выключить idle-вариант, если хочешь прямиком из работы в лок. Ему нужен терминал, который он умеет конфигурить, — Alacritty, Foot, Ghostty или Kitty — и он так и скажет, если дефолтный терминал другой.

Логотип, который он рисует, меняется под _Оформление > Заставка_. Загрузи png или svg — Omarchy сконвертит в ASCII. См. [брендинг](41-branding.md).

### Локскрин

`Super + Ctrl + L` локает машину. Поднимает локскрин шелла Omarchy, гасит дисплей, сбрасывает раскладку на первую — чтобы пароль не печатался не в том алфавите, — и, если крутится, локает 1Password на выходе.

Локскрин ест пароль, а после настройки — и отпечаток. Про него и другие способы аутентификации — в [железной аутентификации](37-hardware-authentication.md).
