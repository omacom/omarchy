# Другие пакеты

В Arch доступно потрясающее богатство пакетов почти для любого типа ПО между официальным репозиторием и Arch User Repository (AUR).

Пользоваться этим проще некуда. Новый пакет Arch устанавливается через _Установить > Package_ в меню Omarchy (`Super + Space`) и ввод нужного пакета. Список всех пакетов будет автоматически отфильтрован нечётким поиском. (Также можно сделать это вручную командой `omarchy pkg add [package]` в терминале).

То же самое можно сделать с AUR, просто используйте _Установить > AUR_. Только помните, что AUR не проверяется командой Arch. Это как RubyGems или npm. Загрузить туда может любой.

Если вы хотите удалить пакет, можно использовать _Удалить > Package_ в меню Omarchy. Это удалит пакет, файлы конфигурации и зависимости. (Также можно сделать это вручную командой `omarchy pkg drop [package]`).
