# Прочие пакеты

У Arch потрясающее богатство пакетов почти под любой софт — между официальным репозиторием и Arch User Repository (AUR).

Пользоваться тем и другим проще некуда. Новый арч-пакет ставится через _Установить > Пакет_ в меню Omarchy (`Super + Space`) — печатаешь нужный пакет. Список всех пакетов сам нечётко фильтруется. (Можно и руками из терминала: `omarchy pkg add [package]`).

С AUR так же — просто через _Установить > AUR_. Только помни: AUR не веттится командой Arch. Это как RubyGems или npm. Залить может кто угодно.

Снести пакет — через _Удалить > Пакет_ в меню Omarchy. Снесёт пакет, конфиги и зависимости. (Можно и руками: `omarchy pkg drop [package]`).
