# Клавиатура, мышь, трекпад

Hyprland позволяет очень подробно настраивать все устройства ввода. Можно сделать повтор клавиатуры сверхзвуково быстрым или включить для трекпада естественную прокрутку. Всё это меняется в `~/.config/hypr/input.lua`, куда также можно попасть через _Настройка > Ввод_ в меню Omarchy (`Super + Space`). Всё, что вы укажете там, заменяет значения Omarchy по умолчанию.

Вот пример:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Вы можете [посмотреть все параметры ввода](https://wiki.hypr.land/Configuring/Basics/Variables/#input) на вики Hyprland, посвящённой устройствам ввода.

CapsLock работает как обычный Caps Lock, а `Shift + CapsLock` — это клавиша Compose для [быстрых эмодзи](07-hotkeys.md#quick-emojis) и [других дополнений](07-hotkeys.md#quick-completions). Если вы предпочитаете, чтобы клавиша Compose находилась в другом месте, замените `omarchy:shift_caps_compose` в `kb_options`. Например, это перемещает клавишу Compose на Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Жесты трекпада

Проведите по трекпаду, чтобы перемещаться по рабочему столу:

| Жест | Действие |
| --- | --- |
| Три пальца влево / вправо | Предыдущее / следующее рабочее пространство, включая пустые |
| Три пальца вверх | Переключить консоль AI |
| Три пальца вниз | Открыть меню Omarchy |
| Четыре пальца влево / вправо | Переместить активное окно на предыдущее / следующее рабочее пространство |
| Четыре пальца вниз | Переключить полноэкранный режим |

Чтобы изменить один из них, отключите его в `~/.config/hypr/input.lua` перед добавлением собственного [жеста трекпада](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), поскольку Hyprland не примет два жеста для одних и тех же пальцев и направления:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Чтобы отключить все жесты Omarchy, установите `omarchy_default_gestures = false` в верхней части `~/.config/hypr/hyprland.lua`, до загрузки значений Omarchy по умолчанию.

На ноутбуках Dell XPS с тактильным трекпадом можно также установить силу нажатия на low, mid или high в разделе _Триггер > Оборудование > Тактильная отдача трекпада_.

### Ввод на китайском, японском и других языках

Выберите японский, корейский, китайский (упрощённый, Pinyin), тайваньский (Zhuyin) или гонконгский (Cangjie), когда установщик спросит о вашей клавиатуре. Omarchy автоматически настраивает клавиатуру и соответствующий движок ввода, в том числе во время офлайн-настройки при первой загрузке. Для японского используется Mozc, для корейского — стандартный двухнаборный Hangul, для упрощённого китайского — Pinyin, для Тайваня — стандартная раскладка Zhuyin от Chewing, а для Гонконга — Cangjie с гонконгскими формами иероглифов. Японский (клавиатура US) предоставляет Mozc с раскладкой клавиатуры US. Клавиши Hangul, Zhuyin и Cangjie остаются на своих стандартных позициях, даже когда вы печатаете латинские буквы с Dvorak, Colemak или AZERTY. Если вы добавили Hangul или Chewing до этого, снимите выбор и снова выберите его в разделе _Настройка > Печать > Методы ввода_, чтобы переместить его клавиши туда; Omarchy не трогает движок, с которым вы уже печатаете.

Печать начинается в латинском режиме. Нажмите `Super + I`, чтобы циклически переключаться между настроенными методами ввода, и `Super + Shift + I`, чтобы переключаться в обратном направлении. Нажмите `Shift` отдельно, чтобы выйти из метода ввода, такого как Pinyin, к латинским буквам, и нажмите её снова, чтобы вернуться назад, как работают Sogou, Microsoft Pinyin и macOS; `Shift` с буквой по-прежнему печатает заглавную букву. На японских клавиатурах 全角/半角 переключает ввод, 変換 включает его, а 無変換 выключает его. С корейским 한/영 переключает Hangul, а 한자 преобразует в Hanja, независимо от того, есть ли на вашей клавиатуре отдельные клавиши или она отправляет для них Right Alt и Right Ctrl, как делают многие ноутбуки, поэтому Right Alt и Right Ctrl там не являются обычными модификаторами; диктовка в режиме push-to-talk остаётся на F9. `Ctrl + Space` остаётся доступным для Tmux и Herdr; `Shift + CapsLock` остаётся клавишей Compose.

Индикатор клавиатуры появляется справа на панели, когда у вас несколько раскладок клавиатуры или методов ввода. Нажмите на него, чтобы переключать языки ввода; для японского отображается あ для хираганы. Для выбора японских иероглифов переключитесь на японский, введите слово, например `nihongo`, затем дважды нажмите Space. Нажмите Enter, чтобы принять выбор. Если у вас также несколько раскладок клавиатуры, щёлкните индикатор правой кнопкой мыши, чтобы циклически переключаться между ними.

Используйте _Настройка > Печать > Раскладки клавиатуры_, чтобы выбрать раскладки, такие как английская и французская, из тех же вариантов, что предлагаются во время установки. Используйте _Настройка > Печать > Методы ввода_, чтобы выбрать, какие движки композиции активны. Оба средства выбора открываются внутри меню Omarchy с отмеченными текущими выборами. Щёлкните или нажмите Enter, чтобы переключить вариант; каждое изменение применяется немедленно. Снятие выбора метода ввода удаляет его из цикла, не удаляя его; клавиатура остаётся доступной.

Выполните `omarchy setup keyboard` или `omarchy setup input`, чтобы открыть те же средства выбора. Чтобы добавить один язык из командной строки, используйте `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` или `cangjie5`. Quick, Boshiamy и Array поставляются в том же пакете, что и Cangjie, и появляются в средстве выбора методов ввода. Ваши пользовательские клавиши переключения сохраняются. Для альтернативных раскладок или клавиш движков установите `fcitx5-configtool` с помощью `omarchy pkg add fcitx5-configtool` и запустите его из терминала. Выбор языка ввода не меняет язык рабочего стола. Выбор японского, корейского или китайского в разделе _Настройка > Язык_ добавляет его метод ввода, когда у вас его ещё нет.

Используйте `Super + I`, чтобы циклически переключаться между методами ввода или раскладками клавиатуры, и `Super + Shift + I`, чтобы идти обратно в другую сторону, так что с тремя настроенными вы можете перемещаться между двумя соседями. Индикатор ввода появляется справа на панели только тогда, когда настроено более одного метода ввода или раскладки. Эта привязка рабочего стола работает наряду с вашими существующими клавишами переключения Fcitx; вы можете переопределить её в `~/.config/hypr/bindings.lua`. Движки ввода и последовательности Compose используют службу [Fcitx5](https://fcitx-im.org/), уже работающую в каждой сессии.

### Использовать ALT как SUPER

На некоторых клавиатурах неудобно использовать основную мета-клавишу (клавишу Windows/cmd) в качестве SUPER. Вы можете изменить это на ALT вместо этого, используя это изменение:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
