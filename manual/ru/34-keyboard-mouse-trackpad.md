# Клавиатура, мышь, трекпад

Hyprland позволяет детально настроить все устройства ввода. Можно сделать повтор клавиатуры сверхзвуковым или включить для трекпада естественную прокрутку. Всё это меняется в `~/.config/hypr/input.lua`, куда также можно попасть через _Setup > Input_ в меню Omarchy (`Super + Space`). Всё, что вы там зададите, заменит значения по умолчанию в Omarchy.

Вот пример:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Вы можете [посмотреть все параметры ввода](https://wiki.hypr.land/Configuring/Basics/Variables/#input) на wiki Hyprland, посвящённой вводу.

CapsLock работает как обычный Caps Lock, а `Shift + CapsLock` — это клавиша Compose для [быстрых эмодзи](07-hotkeys.md#quick-emojis) и [других дополнений](07-hotkeys.md#quick-completions). Если вы хотите назначить клавишу Compose на другое место, замените `omarchy:shift_caps_compose` в `kb_options`. Например, так клавиша Compose перемещается на Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Жесты трекпада

Проведите по трекпаду, чтобы перемещаться по рабочему столу:

| Жест | Действие |
| --- | --- |
| Три пальца влево / вправо | Предыдущее / следующее рабочее пространство, включая пустые |
| Три пальца вверх | Переключить консоль AI |
| Три пальца вниз | Открыть меню Omarchy |
| Четыре пальца влево / вправо | Переместить активное окно на предыдущее / следующее рабочее пространство |
| Четыре пальца вниз | Переключить полноэкранный режим |

Чтобы изменить один из жестов, сначала отключите его в `~/.config/hypr/input.lua`, а затем добавьте свой [жест трекпада](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), поскольку Hyprland не примет два жеста с одинаковым количеством пальцев и направлением:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Чтобы отключить все жесты Omarchy, задайте `omarchy_default_gestures = false` ближе к началу файла `~/.config/hypr/hyprland.lua`, до загрузки значений по умолчанию Omarchy.

На ноутбуках Dell XPS с тактильным трекпадом вы также можете задать силу щелчка низкой, средней или высокой в разделе _Trigger > Hardware > Touchpad Haptics_.

### Ввод на китайском, японском и других языках

Выберите Japanese, Korean, Chinese (Simplified, Pinyin), Taiwan (Zhuyin) или Hong Kong (Cangjie), когда установщик спросит о вашей клавиатуре. Omarchy настраивает клавиатуру и соответствующий механизм ввода автоматически, в том числе во время автономной первоначальной настройки при первой загрузке. Для японского языка используется Mozc, для корейского — стандартная двухнаборная раскладка Hangul, для упрощённого китайского — Pinyin, для Тайваня — стандартная раскладка Zhuyin в Chewing, а для Гонконга — Cangjie с гонконгскими формами иероглифов. Japanese (US keyboard) предоставляет Mozc с раскладкой клавиатуры US. Клавиши Hangul, Zhuyin и Cangjie остаются на своих стандартных местах, даже когда вы печатаете латинские буквы с помощью Dvorak, Colemak или AZERTY. Если вы добавили Hangul или Chewing до этого, снимите и снова выберите его в разделе _Setup > Typing > Input Methods_, чтобы переместить его клавиши туда; Omarchy не трогает механизм ввода, которым вы уже пользуетесь.

Ввод начинается в латинском режиме. Нажмите `Super + I`, чтобы циклически переключаться между настроенными методами ввода, и `Super + Shift + I`, чтобы двигаться в обратном направлении. Нажмите только `Shift`, чтобы выйти из метода ввода наподобие Pinyin к латинским буквам, и нажмите её ещё раз, чтобы вернуться обратно, как это работает в Sogou, Microsoft Pinyin и macOS; `Shift` плюс буква по-прежнему вводит заглавную букву. На японских клавиатурах 全角/半角 переключает ввод, 変換 включает его, а 無変換 выключает его. Для корейского языка 한/영 переключает Hangul, а 한자 преобразует в Hanja, независимо от того, есть ли на вашей клавиатуре выделенные клавиши или она отправляет для них Right Alt и Right Ctrl, как делают многие ноутбуки, поэтому Right Alt и Right Ctrl там не являются обычными модификаторами; диктовка вместо этого переключается сочетанием Alt + Space. `Ctrl + Space` остаётся доступным для Tmux и Herdr; `Shift + CapsLock` остаётся клавишей Compose.

Индикатор клавиатуры появляется справа на панели, когда у вас несколько раскладок клавиатуры или методов ввода. Щёлкните по нему, чтобы переключить языки ввода; для японского языка отображается あ для хираганы. Чтобы выбрать японские иероглифы, переключитесь на японский язык, введите слово, например `nihongo`, затем дважды нажмите Space. Нажмите Enter, чтобы принять ваш выбор. Если у вас также несколько раскладок клавиатуры, щёлкните по индикатору правой кнопкой мыши, чтобы циклически переключаться между ними.

Используйте _Setup > Typing > Keyboard Layouts_, чтобы выбрать раскладки, такие как English и French, из тех же вариантов, что предлагаются во время установки. Используйте _Setup > Typing > Input Methods_, чтобы выбрать, какие механизмы композиции активны. Оба окна выбора открываются внутри меню Omarchy, при этом ваши текущие выборы отмечены. Щёлкните мышью или нажмите Enter, чтобы переключить выбор; каждое изменение применяется немедленно. Снятие выбора метода ввода удаляет его из цикла без удаления; клавиатура остаётся доступной.

Выполните `omarchy setup keyboard` или `omarchy setup input`, чтобы открыть те же окна выбора. Чтобы добавить один язык из командной строки, используйте `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` или `cangjie5`. Quick, Boshiamy и Array поставляются в том же пакете, что и Cangjie, и появляются в окне выбора Input Methods. Ваши пользовательские клавиши переключения сохраняются. Для альтернативных раскладок или клавиш механизма установите `fcitx5-configtool` с помощью `omarchy pkg add fcitx5-configtool` и запустите его из терминала. Выбор языка ввода не меняет язык рабочего стола. Выбор Japanese, Korean или Chinese в разделе _Setup > Language_ добавит соответствующий метод ввода, если у вас ещё ни одного нет.

Используйте `Super + I`, чтобы циклически переключаться между методами ввода или раскладками клавиатуры, и `Super + Shift + I`, чтобы двигаться в обратном направлении, так что при трёх настроенных вариантах вы можете перемещаться между двумя соседями. Индикатор ввода появляется справа на панели, только когда настроено больше одного метода ввода или раскладки. Это сочетание клавиш рабочего стола работает вместе с вашими существующими клавишами переключения Fcitx; вы можете переопределить его в `~/.config/hypr/bindings.lua`. Механизмы ввода и последовательности Compose используют службу [Fcitx5](https://fcitx-im.org/), уже работающую в каждой сессии.

### Использование ALT в качестве SUPER

На некоторых клавиатурах неудобно использовать основную мета-клавишу (клавишу Windows/cmd) в качестве SUPER. Вместо неё можно сделать ALT с помощью такого изменения:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
