# Клавиатура, мышь, трекпад

Hyprland позволяет очень детально настроить все ваши устройства ввода. Можно сделать повтор клавиатуры сверхзвуковым или включить у трекпада естественную прокрутку. Всё это меняется в `~/.config/hypr/input.lua`, куда также можно попасть через _Настройка > Ввод_ в меню Omarchy (`Super + Space`). Всё, что вы зададите там, заменяет настройки Omarchy по умолчанию.

Вот пример:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Все параметры ввода можно [посмотреть все параметры ввода](https://wiki.hypr.land/Configuring/Basics/Variables/#input) на вики Hyprland.

CapsLock работает как обычный Caps Lock, а `Shift + CapsLock` — это клавиша Compose для [быстрых эмодзи](07-hotkeys.md#quick-emojis) и [других дополнений](07-hotkeys.md#quick-completions). Если вы предпочитаете разместить клавишу Compose в другом месте, замените `omarchy:shift_caps_compose` в `kb_options`. Например, так клавиша Compose переносится на Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Функциональные клавиши

По умолчанию верхний ряд клавиатуры ноутбука отправляет медиаклавиши (громкость, яркость и так далее), а удержание `Fn` даёт F1-F12; `Fn + Esc` фиксирует обратный режим, пока вы не нажмёте её снова. Большинство клавиатур сами запоминают эту фиксацию. Ноутбуки ASUS и клавиатуры в стиле Apple оставляют это Linux, который при каждой загрузке запускает их в режиме медиаклавиш. Чтобы вместо этого они запускались в режиме F1-F12, выполните `omarchy keyboard toprow fnkeys` (а чтобы вернуться обратно — `omarchy keyboard toprow mediakeys`); на некоторых ноутбуках это вступает в силу после перезагрузки. Mac на Apple Silicon сохраняют собственную настройку.

### Жесты трекпада

Проводите пальцами по трекпаду, чтобы перемещаться по рабочему столу:

| Жест | Действие |
| --- | --- |
| Три пальца влево / вправо | Предыдущее / следующее рабочее пространство, включая пустые |
| Три пальца вверх | Включить/выключить AI-консоль |
| Три пальца вниз | Открыть меню Omarchy |
| Четыре пальца влево / вправо | Переместить активное окно на предыдущее / следующее рабочее пространство |
| Четыре пальца вниз | Включить/выключить полноэкранный режим |

Чтобы изменить один из жестов, сначала отключите его в `~/.config/hypr/input.lua`, прежде чем добавлять собственный [жест трекпада](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), поскольку Hyprland не примет два жеста для одних и тех же пальцев и направления:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Чтобы отключить все жесты Omarchy, задайте `omarchy_default_gestures = false` ближе к началу файла `~/.config/hypr/hyprland.lua`, до загрузки настроек Omarchy по умолчанию.

На ноутбуках Dell XPS с тактильным трекпадом также можно задать низкую, среднюю или высокую силу нажатия в разделе _Trigger > Hardware > Touchpad Haptics_.

### Ввод на китайском, японском и других языках

Выберите Japanese, Korean, Chinese (Simplified, Pinyin), Taiwan (Zhuyin) или Hong Kong (Cangjie), когда установщик спросит о вашей клавиатуре. Omarchy автоматически настраивает клавиатуру и соответствующий движок ввода, в том числе во время офлайн-настройки при первой загрузке. Для японского используется Mozc, для корейского — стандартный двухнаборный Hangul, для упрощённого китайского — Pinyin, для тайваньского — стандартная раскладка Zhuyin от Chewing, а для гонконгского — Cangjie с гонконгскими формами иероглифов. Вариант Japanese (US keyboard) предоставляет Mozc с американской раскладкой клавиатуры. Клавиши Hangul, Zhuyin и Cangjie остаются на своих стандартных местах, даже когда вы вводите латинские буквы с помощью Dvorak, Colemak или AZERTY. Если вы добавляли Hangul или Chewing до этого, снимите выбор и снова выберите его в разделе _Настройка > Клавиатура > Методы ввода_, чтобы переместить его клавиши туда; движок, с которым вы уже печатаете, Omarchy оставит в покое.

Ввод начинается в латинском режиме. Нажмите `Super + I`, чтобы циклически переключаться между настроенными методами ввода, и `Super + Shift + I`, чтобы переключаться в обратном направлении. Коснитесь одного лишь `Shift`, чтобы выйти из метода ввода наподобие Pinyin к латинским буквам, и коснитесь его снова, чтобы вернуться обратно — так работают Sogou, Microsoft Pinyin и macOS; сочетание `Shift` с буквой по-прежнему вводит заглавную букву. На японских клавиатурах 全角/半角 переключает ввод, 変換 включает его, а 無変換 выключает его. При корейском 한/영 переключает Hangul, а 한자 преобразует в Hanja, независимо от того, есть ли на вашей клавиатуре выделенные клавиши или она отправляет для них Right Alt и Right Ctrl, как делают многие ноутбуки, поэтому Right Alt и Right Ctrl там не являются обычными модификаторами; вместо этого диктовка переключается с помощью Alt + Space. `Ctrl + Space` остаётся доступным для Tmux и Herdr; `Shift + CapsLock` остаётся клавишей Compose.

Индикатор клавиатуры появляется справа на панели, когда у вас несколько раскладок клавиатуры или методов ввода. Щёлкните по нему, чтобы переключить языки ввода; для японского отображается あ для хираганы. Чтобы выбрать варианты японских иероглифов, переключитесь на японский, введите слово, например `nihongo`, затем дважды нажмите Space. Нажмите Enter, чтобы подтвердить выбор. Если у вас также несколько раскладок клавиатуры, щёлкните индикатор правой кнопкой мыши, чтобы циклически переключаться между ними.

С помощью _Настройка > Клавиатура > Вводы клавиатуры_ выбирайте раскладки, такие как английская и французская, из тех же вариантов, что предлагаются во время установки. С помощью _Настройка > Клавиатура > Методы ввода_ выбирайте, какие движки композиции активны. Оба средства выбора открываются внутри меню Omarchy, при этом ваши текущие варианты отмечены. Щёлкните или нажмите Enter, чтобы переключить вариант; каждое изменение применяется немедленно. Снятие выбора метода ввода удаляет его из цикла, не удаляя его из системы; клавиатура остаётся доступной.

Выполните `omarchy setup keyboard` или `omarchy setup input`, чтобы открыть те же средства выбора. Чтобы добавить один язык из командной строки, используйте `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` или `cangjie5`. Quick, Boshiamy и Array поставляются в том же пакете, что и Cangjie, и появляются в средстве выбора методов ввода. Ваши пользовательские клавиши переключения сохраняются. Для альтернативных раскладок движка или клавиш установите `fcitx5-configtool` с помощью `omarchy pkg add fcitx5-configtool` и запустите его из терминала. Выбор языка ввода не меняет язык рабочего стола. Выбор японского, корейского или китайского в разделе _Настройка > Язык_ добавляет его метод ввода, когда у вас его ещё нет.

Используйте `Super + I`, чтобы циклически переключаться между методами ввода или раскладками клавиатуры, и `Super + Shift + I`, чтобы двигаться в обратном направлении, так что при трёх настроенных вариантах вы можете перемещаться между двумя соседями. Индикатор ввода появляется справа на панели только тогда, когда настроено более одного метода ввода или раскладки. Эта привязка рабочего стола работает наряду с вашими существующими клавишами переключения Fcitx; вы можете переопределить её в `~/.config/hypr/bindings.lua`. Движки ввода и последовательности Compose используют службу [Fcitx5](https://fcitx-im.org/), уже работающую в каждой сессии.

### Использование ALT в качестве SUPER

На некоторых клавиатурах неудобно использовать основную мета-клавишу (клавишу Windows/cmd) в качестве SUPER. С помощью этого изменения вместо неё можно сделать ALT:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
