# Клавиатура, мышь и трекпад

Hyprland позволяет очень подробно настраивать все устройства ввода. Можно сделать повтор клавиш сверхзвуковым или включить для трекпада естественную прокрутку. Всё это меняется в `~/.config/hypr/input.lua`, куда также можно попасть через _Setup > Input_ в меню Omarchy (`Super + Space`). Всё, что вы зададите там, заменит настройки Omarchy по умолчанию.

Вот пример:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Все параметры ввода можно [посмотреть на вики Hyprland](https://wiki.hypr.land/Configuring/Basics/Variables/#input).

CapsLock работает как обычный Caps Lock, а `Shift + CapsLock` — это клавиша Compose для [быстрых эмодзи](07-hotkeys.md#quick-emojis) и [других дополнений](07-hotkeys.md#quick-completions). Если вы хотите назначить клавишу Compose на другое место, замените `omarchy:shift_caps_compose` в `kb_options`. Например, так клавиша Compose переносится на Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Функциональные клавиши

Верхний ряд клавиатуры ноутбука по умолчанию отправляет мультимедийные клавиши (громкость, яркость и так далее), а при удержании `Fn` даёт F1-F12; `Fn + Esc` фиксирует обратный вариант, пока вы не нажмёте эту комбинацию снова. Большинство клавиатур сами запоминают эту фиксацию. Ноутбуки ASUS и клавиатуры в стиле Apple оставляют это Linux, который при каждой загрузке запускает их с мультимедийными клавишами. Чтобы вместо этого они запускались с F1-F12, выполните `omarchy device keyboard toprow fnkeys` (а чтобы вернуть обратно — `omarchy device keyboard toprow mediakeys`); на некоторых ноутбуках изменение вступает в силу после перезагрузки. Компьютеры Mac на Apple Silicon сохраняют собственную настройку.

### Жесты трекпада

Проведите пальцами по трекпаду, чтобы перемещаться по рабочему столу:

| Жест | Действие |
| --- | --- |
| Три пальца влево / вправо | Предыдущее / следующее рабочее пространство, включая пустые |
| Три пальца вверх | Включить/выключить консоль ИИ |
| Три пальца вниз | Открыть меню Omarchy |
| Четыре пальца влево / вправо | Переместить активное окно на предыдущее / следующее рабочее пространство |
| Четыре пальца вниз | Включить/выключить полноэкранный режим |

Чтобы изменить один из них, сначала отмените его в `~/.config/hypr/input.lua`, а затем добавьте собственный [жест трекпада](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), поскольку Hyprland не примет два жеста на одинаковое количество пальцев и направление:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Чтобы отключить все жесты Omarchy, установите `omarchy_default_gestures = false` ближе к началу файла `~/.config/hypr/hyprland.lua`, до загрузки настроек Omarchy по умолчанию.

На ноутбуках Dell XPS с тактильным тачпадом можно также установить силу нажатия low, mid или high в разделе _Trigger > Hardware > Touchpad Haptics_.

### Ввод на китайском, японском и других языках

Выберите японский, корейский, китайский (упрощённый, Pinyin), Тайвань (Zhuyin) или Гонконг (Cangjie), когда установщик спросит о вашей клавиатуре. Omarchy автоматически настраивает клавиатуру и соответствующий движок ввода, в том числе во время автономной настройки при первой загрузке. Японский использует Mozc, корейский — стандартный двухнаборный Hangul, упрощённый китайский — Pinyin, Тайвань — стандартную раскладку Zhuyin от Chewing, а Гонконг — Cangjie с гонконгскими формами иероглифов. Японский (клавиатура US) предоставляет Mozc с раскладкой клавиатуры US. Клавиши Hangul, Zhuyin и Cangjie остаются на своих стандартных позициях, даже когда вы печатаете латинские буквы на Dvorak, Colemak или AZERTY. Если вы добавили Hangul или Chewing до этого, снимите и снова выберите его в _Setup > Keyboard > Input Methods_, чтобы его клавиши встали на эти стандартные позиции; движок, на котором вы уже печатаете, Omarchy не трогает.

Ввод начинается в латинском режиме. Нажимайте `Super + I`, чтобы циклически переключаться между настроенными методами ввода, и `Super + Shift + I`, чтобы переключаться в обратном направлении. Коснитесь `Shift` отдельно, чтобы выйти из метода ввода, такого как Pinyin, к латинским буквам, и коснитесь её ещё раз, чтобы вернуться обратно — так работают Sogou, Microsoft Pinyin и macOS; `Shift` вместе с буквой по-прежнему вводит заглавную букву. На японских клавиатурах 全角/半角 переключает ввод, 変換 включает его, а 無変換 выключает. В корейском 한/영 переключает Hangul, а 한자 преобразует в Hanja, независимо от того, есть ли у вашей клавиатуры отдельные клавиши или она отправляет для них Right Alt и Right Ctrl, как делают многие ноутбуки, поэтому Right Alt и Right Ctrl там не являются обычными модификаторами; диктовка вместо этого переключается сочетанием Alt + Space. `Ctrl + Space` остаётся доступным для Tmux и Herdr; `Shift + CapsLock` остаётся клавишей Compose.

Индикатор клавиатуры появляется справа на панели, когда у вас несколько раскладок клавиатуры или методов ввода. Нажмите на него, чтобы переключить язык ввода; при японском вводе для хираганы отображается あ. Чтобы выбрать японские иероглифы, переключитесь на японский, введите слово, например `nihongo`, затем дважды нажмите Space. Нажмите Enter, чтобы принять выбор. Если у вас также несколько раскладок клавиатуры, щёлкните индикатор правой кнопкой мыши, чтобы циклически переключаться между ними.

Используйте _Setup > Keyboard > Keyboard Inputs_, чтобы выбрать раскладки, такие как English и French, из тех же вариантов, что предлагаются при установке. Используйте _Setup > Keyboard > Input Methods_, чтобы выбрать, какие движки композиции активны. Оба средства выбора открываются внутри меню Omarchy, где ваши текущие выборы отмечены. Щёлкните или нажмите Enter, чтобы переключить выбор; каждое изменение применяется немедленно. Снятие выбора метода ввода удаляет его из цикла без его удаления из системы; клавиатура остаётся доступной.

Выполните `omarchy setup keyboard` или `omarchy setup input`, чтобы открыть те же средства выбора. Чтобы добавить один язык из командной строки, используйте `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` или `cangjie5`. Quick, Boshiamy и Array входят в тот же пакет, что и Cangjie, и появляются в средстве выбора Input Methods. Ваши собственные клавиши переключения сохраняются. Для альтернативных раскладок или клавиш движков установите `fcitx5-configtool` командой `omarchy pkg add fcitx5-configtool` и запустите его из терминала. Выбор языка ввода не меняет язык рабочего стола. Выбор японского, корейского или китайского в _Setup > Region > Language_ добавляет его метод ввода, если у вас его ещё нет.

Используйте `Super + I`, чтобы циклически переключаться между методами ввода или раскладками клавиатуры, и `Super + Shift + I`, чтобы идти в обратном направлении, так что при трёх настроенных вариантах вы можете перемещаться между двумя соседями. Индикатор ввода появляется справа на панели только тогда, когда настроено больше одного метода ввода или раскладки. Это сочетание клавиш рабочего стола работает наряду с вашими существующими клавишами переключения Fcitx; вы можете переопределить его в `~/.config/hypr/bindings.lua`. Движки ввода и последовательности Compose используют службу [Fcitx5](https://fcitx-im.org/), уже запущенную в каждом сеансе.

### Использование ALT вместо SUPER

На некоторых клавиатурах неудобно использовать основную мета-клавишу (клавишу Windows/cmd) в качестве SUPER. Эту роль можно вместо этого отдать ALT с помощью такого изменения:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
