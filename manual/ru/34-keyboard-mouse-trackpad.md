# Клавиатура, мышь, трекпад

Hyprland позволяет детально настроить все устройства ввода. Можно сделать повтор клавиатуры сверхзвуковым или включить для трекпада естественную прокрутку. Все это меняется в `~/.config/hypr/input.lua` — попасть туда можно также через _Setup > Input_ в меню Omarchy (`Super + Space`). Все, что вы там зададите, заменяет настройки Omarchy по умолчанию.

Вот пример:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

На вики Hyprland [можно посмотреть все параметры ввода](https://wiki.hypr.land/Configuring/Basics/Variables/#input).

CapsLock работает как обычный Caps Lock, а `Shift + CapsLock` — это клавиша Compose для [быстрых эмодзи](07-hotkeys.md#quick-emojis) и [других дополнений](07-hotkeys.md#quick-completions). Если вы хотите назначить клавишу Compose в другое место, замените `omarchy:shift_caps_compose` в `kb_options`. Например, так клавиша Compose перемещается на Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Функциональные клавиши

Верхний ряд клавиатуры ноутбука по умолчанию отправляет мультимедийные клавиши (громкость, яркость и так далее), а при удержании `Fn` дает F1-F12; `Fn + Esc` фиксирует обратный вариант, пока вы не нажмете это сочетание снова. Большинство клавиатур запоминают эту фиксацию сами. Ноутбуки ASUS и клавиатуры в стиле Apple оставляют это Linux, который при каждой загрузке запускает их с мультимедийными клавишами. Чтобы вместо этого они запускались с F1-F12, выполните `omarchy device keyboard toprow fnkeys` (а `omarchy device keyboard toprow mediakeys` — чтобы вернуться обратно); на некоторых ноутбуках это вступает в силу после перезагрузки. Компьютеры Mac на Apple Silicon сохраняют собственную настройку.

### Жесты трекпада

Проведите по трекпаду, чтобы перемещаться по рабочему столу:

| Жест | Действие |
| --- | --- |
| Три пальца влево / вправо | Предыдущее / следующее рабочее пространство, включая пустые |
| Три пальца вверх | Переключить консоль AI |
| Три пальца вниз | Открыть меню Omarchy |
| Четыре пальца влево / вправо | Переместить активное окно на предыдущее / следующее рабочее пространство |
| Четыре пальца вниз | Переключить полноэкранный режим |

Чтобы изменить один жест, отмените его в `~/.config/hypr/input.lua`, прежде чем добавлять собственный [жест тачпада](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), поскольку Hyprland не примет два жеста на одинаковое число пальцев и направление:

```lua
hl.gesture({ fingers = 3, direction = "up", action = "unset" })
hl.gesture({ fingers = 3, direction = "up", action = "fullscreen" })
```

Чтобы отключить все жесты Omarchy, установите `omarchy_default_gestures = false` ближе к началу `~/.config/hypr/hyprland.lua`, до загрузки настроек Omarchy по умолчанию.

На ноутбуках Dell XPS с тактильным тачпадом можно также установить силу нажатия low, mid или high в _Trigger > Hardware > Touchpad Haptics_.

### Ввод на китайском, японском и других языках

Выберите Japanese, Korean, Chinese (Simplified, Pinyin), Taiwan (Zhuyin) или Hong Kong (Cangjie), когда установщик спросит про вашу клавиатуру. Omarchy автоматически настраивает клавиатуру и соответствующий движок ввода, в том числе во время автономной настройки при первой загрузке. Для японского используется Mozc, для корейского — стандартный двухнаборный Hangul, для упрощенного китайского — Pinyin, для Тайваня — стандартная раскладка Zhuyin от Chewing, а для Гонконга — Cangjie с гонконгскими формами символов. Japanese (US keyboard) предоставляет Mozc с американской раскладкой клавиатуры. Клавиши Hangul, Zhuyin и Cangjie остаются на своих стандартных позициях, даже когда вы печатаете латинскими буквами на Dvorak, Colemak или AZERTY. Если вы уже добавили Hangul или Chewing до этого, снимите выбор и выберите их заново в _Setup > Keyboard > Input Methods_, чтобы переместить их клавиши туда; движок, на котором вы уже печатаете, Omarchy оставит в покое.

Ввод начинается в латинском режиме. Нажимайте `Super + I`, чтобы циклически переключаться между настроенными методами ввода, и `Super + Shift + I`, чтобы переключаться обратно. Нажмите `Shift` отдельно, чтобы выйти из метода ввода вроде Pinyin в латинские буквы, и нажмите его еще раз, чтобы вернуться, — так, как работают Sogou, Microsoft Pinyin и macOS; `Shift` плюс буква по-прежнему печатает заглавную. На японских клавиатурах 全角/半角 переключает ввод, 変換 включает его, а 無変換 выключает. В корейском 한/영 переключает Hangul, а 한자 преобразует в Hanja, независимо от того, есть ли у вашей клавиатуры выделенные клавиши или она отправляет для них Right Alt и Right Ctrl, как делают многие ноутбуки, поэтому Right Alt и Right Ctrl там не являются обычными модификаторами; диктовка вместо этого переключается сочетанием Alt + Space. `Ctrl + Space` остается доступным для Tmux и Herdr; `Shift + CapsLock` остается клавишей Compose.

Индикатор клавиатуры появляется справа на панели, когда у вас несколько раскладок клавиатуры или методов ввода. Щелкните по нему, чтобы переключить языки ввода; для японского отображается あ для хираганы. Чтобы выбрать японские символы, переключитесь на японский, введите слово, например `nihongo`, затем дважды нажмите Space. Нажмите Enter, чтобы принять свой выбор. Если у вас также несколько раскладок клавиатуры, щелкните правой кнопкой по индикатору, чтобы циклически переключаться между ними.

Используйте _Setup > Keyboard > Keyboard Inputs_, чтобы выбрать раскладки, например английскую и французскую, из тех же вариантов, что предлагаются во время установки. Используйте _Setup > Keyboard > Input Methods_, чтобы выбрать, какие движки композиции активны. Оба средства выбора открываются внутри меню Omarchy с отмеченными текущими вариантами. Щелкните или нажмите Enter, чтобы переключить вариант; каждое изменение применяется немедленно. Снятие выбора метода ввода удаляет его из цикла, не удаляя его самого; клавиатура остается доступной.

Выполните `omarchy setup keyboard` или `omarchy setup input`, чтобы открыть те же средства выбора. Чтобы добавить один язык из командной строки, используйте `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` или `cangjie5`. Quick, Boshiamy и Array идут в том же пакете, что и Cangjie, и появляются в средстве выбора Input Methods. Ваши собственные клавиши переключения сохраняются. Для альтернативных раскладок или клавиш движков установите `fcitx5-configtool` командой `omarchy pkg add fcitx5-configtool` и запустите его из терминала. Выбор языка ввода не меняет язык рабочего стола. Выбор японского, корейского или китайского в _Setup > Language_ добавляет его метод ввода, когда у вас его еще нет.

Используйте `Super + I`, чтобы циклически переключаться между методами ввода или раскладками клавиатуры, и `Super + Shift + I`, чтобы идти в обратную сторону, — так при трех настроенных вариантах вы можете перемещаться между двумя соседними. Индикатор ввода появляется справа на панели только когда настроено больше одного метода ввода или раскладки. Эта привязка рабочего стола работает вместе с вашими существующими клавишами переключения Fcitx; вы можете переопределить ее в `~/.config/hypr/bindings.lua`. Движки ввода и последовательности Compose используют службу [Fcitx5](https://fcitx-im.org/), которая уже работает в каждой сессии.

### Использовать ALT как SUPER

На некоторых клавиатурах неудобно использовать основную мета-клавишу (клавишу Windows/cmd) как SUPER. С помощью этого изменения можно поменять ее на ALT:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
