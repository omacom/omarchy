# Клавиатура, мышь, трекпад

Hyprland позволяет очень подробно настраивать все ваши устройства ввода. Можно сделать повтор клавиатуры сверхзвуково быстрым или включить для трекпада естественную прокрутку. Всё это меняется в `~/.config/hypr/input.lua`, куда также можно попасть через _Setup > Input_ в меню Omarchy (`Super + Space`). Всё, что вы там укажете, заменяет настройки Omarchy по умолчанию.

Вот пример:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Вы можете [посмотреть все параметры ввода](https://wiki.hypr.land/Configuring/Basics/Variables/#input) на вики Hyprland по устройствам ввода.

CapsLock работает как обычный Caps Lock, а `Shift + CapsLock` — это клавиша Compose для [быстрых эмодзи](07-hotkeys.md#quick-emojis) и [других дополнений](07-hotkeys.md#quick-completions). Если вы предпочитаете, чтобы клавиша Compose была в другом месте, замените `omarchy:shift_caps_compose` в `kb_options`. Например, вот так клавиша Compose переносится на Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Жесты трекпада

Вы также можете включить [жесты тачпада](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), например свайп тремя пальцами для смены рабочих столов:

```lua
hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })
```

На ноутбуках Dell XPS с тактильным трекпадом вы также можете установить силу нажатия на low, mid или high в разделе _Trigger > Hardware > Touchpad Haptics_.

### Ввод на китайском, японском и других языках

Выберите Japanese, Korean, Chinese (Simplified, Pinyin), Taiwan (Zhuyin) или Hong Kong (Cangjie), когда установщик спросит про вашу клавиатуру. Omarchy автоматически настраивает клавиатуру и соответствующий движок ввода, в том числе во время офлайн-настройки при первой загрузке. Японский использует Mozc, корейский использует стандартный двухнаборный Hangul, упрощённый китайский использует Pinyin, Тайвань использует стандартную раскладку Zhuyin из Chewing, а Гонконг использует Cangjie с гонконгскими формами иероглифов. Japanese (US keyboard) предоставляет Mozc с американской раскладкой клавиатуры. Клавиши Hangul, Zhuyin и Cangjie остаются на своих стандартных позициях, даже когда вы печатаете латинские буквы на Dvorak, Colemak или AZERTY. Если вы добавили Hangul или Chewing до этого, снимите и снова выберите его в _Setup > Typing > Input Methods_, чтобы переместить его клавиши туда; движок, которым вы уже печатаете, Omarchy оставит в покое.

Ввод начинается в латинском режиме. Нажмите `Super + I`, чтобы циклически переключаться между настроенными методами ввода, и `Super + Shift + I` — чтобы переключаться в обратную сторону. Коснитесь одной только клавиши `Shift`, чтобы выйти из метода ввода вроде Pinyin к латинским буквам, и коснитесь её снова, чтобы вернуться, как это работает в Sogou, Microsoft Pinyin и macOS; `Shift` плюс буква по-прежнему печатает заглавную букву. На японских клавиатурах 全角/半角 переключает ввод, 変換 включает его, а 無変換 выключает. С корейским 한/영 переключает Hangul, а 한자 преобразует в Hanja, независимо от того, есть ли у вашей клавиатуры выделенные клавиши или она отправляет для них Right Alt и Right Ctrl, как это делают многие ноутбуки, поэтому Right Alt и Right Ctrl там не являются обычными модификаторами; диктовка push-to-talk остаётся на F9. `Ctrl + Space` остаётся доступным для Tmux и Herdr; `Shift + CapsLock` остаётся клавишей Compose.

Индикатор клавиатуры появляется справа на панели, когда у вас несколько раскладок клавиатуры или методов ввода. Щёлкните по нему, чтобы переключать языки ввода; для японского отображается あ для хираганы. Для выбора японских иероглифов переключитесь на японский, введите слово, например `nihongo`, затем дважды нажмите Space. Нажмите Enter, чтобы принять выбор. Если у вас также несколько раскладок клавиатуры, щёлкните индикатор правой кнопкой мыши, чтобы переключаться между ними.

Используйте _Setup > Typing > Keyboard Layouts_, чтобы выбрать раскладки, например English и French, из тех же вариантов, что предлагаются при установке. Используйте _Setup > Typing > Input Methods_, чтобы выбрать, какие движки композиции активны. Оба меню выбора открываются внутри меню Omarchy, и ваши текущие выборы отмечены. Щёлкните или нажмите Enter, чтобы переключить вариант; каждое изменение применяется немедленно. Снятие выбора метода ввода убирает его из цикла, не удаляя его; клавиатура остаётся доступной.

Запустите `omarchy setup keyboard` или `omarchy setup input`, чтобы открыть те же меню выбора. Чтобы добавить один язык из командной строки, используйте `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing` или `cangjie5`. Quick, Boshiamy и Array поставляются в том же пакете, что и Cangjie, и появляются в меню выбора Input Methods. Ваши пользовательские клавиши переключения сохраняются. Для альтернативных раскладок или клавиш движков установите `fcitx5-configtool` с помощью `omarchy pkg add fcitx5-configtool` и запустите его из терминала. Выбор языка ввода не меняет язык рабочего стола. Выбор Japanese, Korean или Chinese в _Setup > Language_ добавляет его метод ввода, когда у вас его ещё нет.

Используйте `Super + I`, чтобы циклически переключаться между методами ввода или раскладками клавиатуры, и `Super + Shift + I`, чтобы идти в обратную сторону, так что при трёх настроенных вы можете перемещаться между двумя соседними. Индикатор ввода появляется справа на панели только тогда, когда настроено больше одного метода ввода или раскладки. Это сочетание для рабочего стола работает наряду с вашими существующими клавишами переключения Fcitx; вы можете переопределить его в `~/.config/hypr/bindings.lua`. Движки ввода и последовательности Compose используют службу [Fcitx5](https://fcitx-im.org/), уже работающую в каждой сессии.

### Использование ALT в качестве SUPER

На некоторых клавиатурах неудобно использовать основную мета-клавишу (клавишу Windows/cmd) в качестве SUPER. Вместо этого вы можете сделать ею ALT, применив такое изменение:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
