# Инструменты разработчика

## Другие редакторы

В Omarchy из коробки [Neovim](https://neovim.io/), но если хочется помейнстримнее и попривычнее — открой меню Omarchy (`Super + Space`) и глянь опции в _Установить > Редактор_. Там VSCode, Cursor, Zed, Sublime Text, Helix, Vim и Emacs. Не нашёл своё — глянь _Установить > Пакет_, вдруг оно в арч-пакете (а нет — попробуй _Установить > AUR_ на предмет AUR).

Оригинальный редактор `vi` тоже есть из коробки. Правишь файл в терминале через `vi filename`.

Совпадение тем предлагается под `VSCode`, `Cursor`, `VSCodium` и `Helix`.

Системный дефолтный редактор ставится в _Настройки > Приложения по умолчанию > Редактор_.

## Окружение

Omarchy умеет поднимать целую россыпь девелоперских окружений через секцию _Установить > Разработка_ в меню Omarchy (`Super + Space`). Там, конечно, _Ruby on Rails_, но и все три главных рантайма под JavaScript (Node.js, Bun, Deno), и популярные PHP-фреймворки вроде Laravel и Symfony. О, а ещё Go, Rust, Python, Java, Elixir (с Phoenix), .NET, OCaml, Zig, Clojure и Scala. Выбор — широчайший!

Большинство окружений рулится через [Mise](https://mise.jdx.dev/). Это тула, которая ставит и гоняет несколько версий языка на одной машине. Вроде rbenv или rvm под Ruby или virtualenv под Python, но работает под кучу разных окружений.

Ставится, скажем, Ruby через `mise use -g ruby` — и поставит Ruby, и выставит глобальным дефолтом. А если у проекта есть файл .ruby-version — просто `mise i` в корне проекта.

## Docker

[Docker](https://www.docker.com/) в представлении едва нуждается. Гоняет изолированные контейнеры, а в Omarchy под него всё для хорошей езды стоит, включая сам Docker и [Docker Compose](https://docs.docker.com/compose/).

По умолчанию твой юзер в группе `docker` *не* состоит. Эта группа — фактически парольный root: всё в ней может `docker run -v /:/host` и забрать машину — так что один левый скрипт или зависимость, запущенные от твоего имени, — это одна команда до рута. Поэтому в командной строке Docker гоняешь с `sudo` (`sudo docker ps`, `sudo docker compose up`), а графические тулы, говорящие с демоном — Docker TUI на `Super + Shift + D` и Windows VM, — спрашивают авторизацию когда надо. Хочешь удобство беспарольной настройки назад и понимаешь компромисс — включи в _Настройки > Безопасность > Sudoless Docker_ (или прогони `omarchy-setup-security-sudoless-docker`): добавит тебя в группу `docker` после предупреждения, и голый `docker` с алиасом `d` снова без `sudo`.

Ходовые базы под локальную разработку поднимаются в Docker через _Установить > Разработка > База данных Docker_ в меню Omarchy.

## GitHub CLI

[GitHub CLI](https://cli.github.com/) даёт залогиниться в GitHub-аккаунт и клонить приватные репо через него. Подключён как один из ленивых mise-стабов, так что первый прогон `gh` его ставит. Аутентификация: `gh auth login`. Дальше приватные репо чекаутятся через `gh repo clone org/repo`.

Через эту команду делается ещё куча гитхабных операций. Просто прогони `gh` — увидишь всё возможное.

Есть ещё ленивый стаб `ghui` под пулл-реквесты в TUI. И предустановлен [lazygit](https://github.com/jesseduffield/lazygit), если сам git хочется гнать из TUI тоже.
