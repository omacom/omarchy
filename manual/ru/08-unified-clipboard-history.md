# Единый буфер обмена и история

Обычно в Linux нужно `Ctrl + Shift + C/V` для копирования и вставки в терминале и `Ctrl + C/V` для этого везде в остальном. К этому трудно привыкнуть тем, кто не родился и не вырос на Linux! Так же как и к переходу с super на ctrl, если вы пришли с Mac.

Omarchy решает обе проблемы с помощью единых сочетаний клавиш буфера обмена, которые работают (почти) везде. Это:

| Сочетание | Команда |
| ------- | ----------- |
| Super + C | Копировать |
| Super + X | Вырезать |
| Super + V | Вставить |
| Super + Ctrl + V | История буфера обмена |

_Обратите внимание, что большинство оболочек агентов используют `Ctrl + V` для вставки изображений, но `Super + V` для вставки текста._

### История буфера обмена

История буфера обмена предоставляется оболочкой Omarchy и работает и для текста, и для изображений. Вы вызываете её через `Super + Ctrl + V`, выбираете запись клавишей Enter, и она помещается в буфер обмена, готовая к вставке через `Super + V`.
