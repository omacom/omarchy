# Ходовые твики

Коллекция ходовых подгонок сетапа Omarchy. Учти: системным обновлениям иногда надо вернуть отдельные конфиги в исходное состояние. Если случится — правки не потеряются, а лягут `.bak`-файлом в том же каталоге.

Накосячил — отдельные конфиги возвращаются в исходный сетап через _Обновить > Конфиг_ в меню Omarchy. А _прямо всё_ накосячил — все конфиги сбрасываются через `omarchy-reinstall`.

### Все иконки трея всегда

По умолчанию иконки трея вроде Dropbox, 1password или Steam прячутся за стрелкой-экспандером трея — она их кажет по ховеру. Хочешь торчат всегда — правый клик по стрелке-экспандеру открывает менеджер иконок трея, там пинишь нужные видимыми (а ненужные никогда — прячешь).

### Круглые углы окон

Дефолтный дизайн Omarchy — квадратные углы, но смягчить можно: поменяй `~/.config/hypr/looknfeel.lua`, чтобы rounding больше не комментился:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### Убрать отступы окон

На экранах ноутов некоторые не любят тратить пиксели на отступы окон (и даже на верхнюю панель — она тоглится через `Super + Shift + Space`). Все гэпы с бордюрами снимаются разом через `Super + Shift + Backspace`, а навсегда — раскомментом вот этой секции `~/.config/hypr/looknfeel.lua`:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
