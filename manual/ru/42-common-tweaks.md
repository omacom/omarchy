# Распространённые настройки

Это подборка распространённых донастроек Omarchy под себя. Имейте в виду, что системным обновлениям иногда может понадобиться вернуть некоторые конфигурации в исходное состояние. Если это произойдёт, ваши изменения не пропадут, а окажутся в файле `.bak` в том же каталоге.

Если вы что-то сломаете, отдельные конфигурации можно вернуть к исходной настройке через _Обновление > Конфигурация_ в меню Omarchy. Если вы _действительно_ всё сломаете, все конфигурации можно сбросить командой `omarchy-reinstall`.

### Всегда показывать все значки в трее

По умолчанию значки в трее, такие как Dropbox, 1password или Steam, скрыты за стрелкой раскрытия трея, которая показывает их при наведении. Если хотите, чтобы они были видны всегда, щёлкните правой кнопкой по стрелке раскрытия, чтобы открыть менеджер значков трея, а затем закрепите значки, которые хотите держать видимыми (можно также скрыть те, которые никогда не хотите видеть).

### Скруглённые углы окон

Дизайн Omarchy по умолчанию — это острые углы, но если хотите немного смягчить его, измените `~/.config/hypr/looknfeel.lua`, чтобы скругление больше не было закомментировано:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### Убрать зазоры окон

На дисплеях ноутбуков некоторые предпочитают не тратить ни пикселя на зазоры окон (или даже на верхнюю панель, которую можно отключить сочетанием `Super + Shift + Space`). Все зазоры и границы можно отключить сочетанием `Super + Shift + Backspace` или убрать навсегда, сняв комментарии в этом разделе `~/.config/hypr/looknfeel.lua`:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
