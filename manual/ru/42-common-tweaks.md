# Распространённые доработки

Это подборка распространённых настроек под себя для конфигурации Omarchy. Имейте в виду, что при обновлениях системы иногда может потребоваться вернуть некоторые конфиги в исходное состояние. Если это произойдёт, ваши изменения не пропадут, а будут сохранены в файл `.bak.<timestamp>` рядом с оригиналом.

Если вы что-то сломаете, отдельные конфиги можно вернуть к исходной конфигурации через _Update > Config_ в меню Omarchy. Если вы _действительно_ всё сломаете, можно сбросить все конфиги командой `omarchy reinstall configs` или переустановить все пакеты и конфиги по умолчанию командой `omarchy reinstall`.

### Показывать все значки в трее постоянно

По умолчанию значки в трее, такие как Dropbox, 1password или Steam, скрыты за стрелкой раскрытия трея, которая показывает их при наведении. Если хотите, чтобы они были видны постоянно, щёлкните правой кнопкой мыши по стрелке раскрытия, чтобы открыть менеджер значков трея, затем закрепите значки, которые хотите всегда видеть (там же можно скрыть те, которые не хотите видеть никогда).

### Скруглённые углы окон

Дизайн Omarchy по умолчанию — с прямыми углами, но если хотите немного смягчить его, выберите _Appearance > Windows > Window Corners > Rounded Corners_ в меню Omarchy или выполните `omarchy hyprland corners rounded`. _Theme Corners_ возвращает то, что используется в теме. Чтобы задать собственный радиус, оставайтесь на _Theme Corners_ (`omarchy hyprland corners theme`), поскольку Rounded и Sharp загружаются после вашего конфига и переопределяют его, и раскомментируйте скругление в `~/.config/hypr/looknfeel.lua`:

```
hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})
```

### Убрать зазоры между окнами

На экранах ноутбуков некоторые предпочитают не тратить ни пикселя на зазоры между окнами (или даже на верхнюю панель, которую можно отключить сочетанием `Super + Shift + Space`). Все зазоры и рамки можно отключить сочетанием `Super + Shift + Backspace` или убрать навсегда, убрав комментарии в этом разделе `~/.config/hypr/looknfeel.lua`:

```
hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
```
