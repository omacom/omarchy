# Веб-приложения

Вы можете добавлять собственные веб-приложения через _Установить > Web App_ в меню Omarchy (`Super + Space`). Оно спросит имя приложения, URL приложения и URL значка, если не сможет получить его через favicon. Отличные значки PNG для многих популярных веб-приложений можно найти на [Dashboard Icons](https://dashboardicons.com).

Затем они будут доступны через средство запуска приложений (`Super + Space`) и будут использовать красивое безрамочное окно веб-приложения.

Если вы хотите удалить веб-приложение, просто перейдите в _Удалить > Web App_ в меню Omarchy.

Лучше всего войти во все свои учётные записи в обычном браузере, прежде чем использовать ярлыки веб-приложений. Тонкая рамка-обёртка плохо работает с 1password, так что проще сначала войти напрямую.

Все горячие клавиши для этих веб-приложений можно изменить в `~/.config/hypr/bindings.lua`.

Когда вы в веб-приложении, текущий URL можно скопировать в буфер обмена сочетанием `Shift + Alt + L`.

По умолчанию Omarchy уже поставляется с набором стандартных приложений:

## HEY

[HEY](https://www.hey.com/) — это сервис электронной почты и календаря, который служит отличной альтернативой для людей, уставших от Gmail, Outlook или Apple Mail. Его сделали в [37signals](https://37signals.com/), откуда родом и Omarchy.

HEY Email запускается сочетанием `Super + Shift + E`, сразу к созданию нового письма можно перейти сочетанием `Super + Shift + Alt + E`, а HEY Calendar запускается сочетанием `Super + Shift + C`.

## Basecamp

[Basecamp](https://basecamp.com/) — это сервис управления проектами, который помогает небольшим командам двигаться быстрее и добиваться большего. Вместо того чтобы собирать лоскутное одеяло из Trello, Slack, Asana, Notion или чего-то ещё, вы можете получить всё в одном месте с Basecamp. Его сделали в [37signals](https://37signals.com/), откуда родом и Omarchy.

Basecamp запускается через средство запуска приложений (`Super + Space`)

## ChatGPT

[ChatGPT](https://chatgpt.com) — самый популярный в мире AI-чат-бот.

ChatGPT запускается сочетанием `Super + Shift + A`.

## Grok

[Grok](https://grok.com) — это чат-бот от xAI.

Grok запускается сочетанием `Super + Shift + Alt + A`.

## WhatsApp

[WhatsApp](https://www.whatsapp.com/) — один из самых популярных в мире сервисов обмена сообщениями, и веб-версия — отличный вариант для Linux.

WhatsApp запускается сочетанием `Super + Shift + Alt + G`.

## Приложения Google

Google Messages, Google Photos, Google Maps и Google Contacts также включены как веб-приложения.

Google Messages запускается сочетанием `Super + Shift + Ctrl + G`, Google Photos — сочетанием `Super + Shift + P`, а Google Maps — сочетанием `Super + Shift + S`. Google Contacts доступен через средство запуска приложений (`Super + Space`).

## X

X — это место, где рождаются новости.

X запускается сочетанием `Super + Shift + X`, а сразу к написанию нового поста можно перейти сочетанием `Super + Shift + Alt + X`.

## YouTube

[YouTube](https://youtube.com/) — самая популярная видеоплатформа в мире.

YouTube запускается сочетанием `Super + Shift + Y`.

## Zoom

[Zoom](https://zoom.us/) — самая популярная система видеочата, используемая в США. Отличные соединения по всему миру. А 40-минутные встречи можно проводить без платной учётной записи. Omarchy оборачивает веб-клиент Zoom, и ссылки на встречи zoom будут открываться прямо в нём.

Zoom запускается через средство запуска приложений (`Super + Space`).

## Discord

[Discord](https://discord.com/) — это место, где тусуется большинство игровых сообществ и сообществ открытого исходного кода, включая [сообщество самой Omarchy](https://discord.gg/tXFUdasqhY).

Discord запускается через средство запуска приложений (`Super + Space`).

## Приложения Microsoft

Выберите _Установить > Service > Microsoft_, чтобы добавить Outlook, Word, Excel, PowerPoint, Teams и OneDrive как веб-приложения. У каждого приложения есть собственный ярлык запуска, и открывается оно напрямую, используя коммерческие URL Microsoft 365 и ваш существующий профиль браузера. Они открываются в тех же окнах браузерных приложений, что и другие веб-приложения Omarchy; отдельный клиент Teams for Linux они не устанавливают.

Удалите набор через _Удалить > Service > Microsoft_ или удалите отдельные приложения через _Удалить > Web App_. Также можно установить только нужные приложения через _Установить > Web App_.

Для государственного или суверенного облака отредактируйте URL в строке `Exec=` в соответствующем ярлыке в каталоге `~/.local/share/applications/`, например `Microsoft Teams.desktop`, используя URL, предоставленный вашей организацией. Любой буквальный `%` в этой строке пишите как `%%`. Изменения применяются при следующем запуске. Повторный запуск установщика набора заменяет его ярлыки URL по умолчанию.

Чтобы рабочие входы оставались отдельными, добавьте каталог данных браузера в строку `Exec=` каждого ярлыка:

```ini
Exec=omarchy-launch-webapp "https://teams.cloud.microsoft/" --user-data-dir=/absolute/path/to/work-browser-profile
```

Замените каталог из примера абсолютным путём по своему выбору и используйте один и тот же путь для всех шести ярлыков, чтобы рабочие входы были общими между ними. Веб-приложения используют выбранный поддерживаемый браузер Omarchy, откатываясь к Chromium, когда браузер по умолчанию не поддерживается.
