# Веб-приложения

Вы можете добавлять собственные веб-приложения через _Install > Web App_ в меню Omarchy (`Super + Space`). Оно запросит у вас название приложения, URL приложения и URL значка, если не сможет получить его через favicon. Отличные PNG-значки для многих популярных веб-приложений можно найти на [Dashboard Icons](https://dashboardicons.com).

После этого они будут доступны через лаунчер приложений (`Super + Space`) и будут использовать красивое безрамочное окно веб-приложения.

Если вы хотите удалить веб-приложение, просто перейдите в _Remove > Web App_ в меню Omarchy.

Лучше всего сначала войти во все свои аккаунты в обычном браузере, прежде чем использовать ярлыки веб-приложений. Тонкая рамка-обёртка плохо работает с 1password, поэтому проще сначала войти напрямую.

Все горячие клавиши для этих веб-приложений можно изменить в `~/.config/hypr/bindings.lua`.

Когда вы находитесь в веб-приложении, вы можете скопировать текущий URL в буфер обмена с помощью `Shift + Alt + L`.

По умолчанию Omarchy уже поставляется с набором приложений по умолчанию:

## HEY

[HEY](https://www.hey.com/) — это сервис электронной почты и календаря, который служит отличной альтернативой для людей, уставших от Gmail, Outlook или Apple Mail. Его создала компания [37signals](https://37signals.com/), где зародился Omarchy.

Вы можете запустить HEY Email с помощью `Super + Shift + E`, сразу перейти к созданию нового письма с помощью `Super + Shift + Alt + E` и запустить HEY Calendar с помощью `Super + Shift + C`.

## Basecamp

[Basecamp](https://basecamp.com/) — это сервис управления проектами, который помогает небольшим командам двигаться быстрее и добиваться большего прогресса. Вместо того чтобы сшивать воедино мешанину из Trello, Slack, Asana, Notion или чего угодно ещё, вы можете получить всё в одном месте с Basecamp. Его создала компания [37signals](https://37signals.com/), где зародился Omarchy.

Вы можете запустить Basecamp с помощью лаунчера приложений (`Super + Space`)

## ChatGPT

[ChatGPT](https://chatgpt.com) — самый популярный AI-чат-бот в мире.

Вы можете запустить ChatGPT с помощью `Super + Shift + A`.

## Grok

[Grok](https://grok.com) — это чат-бот xAI.

Вы можете запустить Grok с помощью `Super + Shift + Alt + A`.

## WhatsApp

[WhatsApp](https://www.whatsapp.com/) — один из самых популярных сервисов обмена сообщениями в мире, а веб-версия — отличный вариант для Linux.

Вы можете запустить WhatsApp с помощью `Super + Shift + Alt + G`.

## Приложения Google

Google Messages, Google Photos, Google Maps и Google Contacts тоже включены в качестве веб-приложений.

Вы можете запустить Google Messages с помощью `Super + Shift + Ctrl + G`, Google Photos с помощью `Super + Shift + P`, а Google Maps с помощью `Super + Shift + S`. Google Contacts доступен через лаунчер приложений (`Super + Space`).

## X

X — это место, где появляются новости.

Вы можете запустить X с помощью `Super + Shift + X` и сразу перейти к написанию нового поста с помощью `Super + Shift + Alt + X`.

## YouTube

[YouTube](https://youtube.com/) — самая популярная видеоплатформа в мире.

Вы можете запустить YouTube с помощью `Super + Shift + Y`.

## Zoom

[Zoom](https://zoom.us/) — самая популярная система видеочатов, используемая в США. Отличные соединения по всему миру. А 40-минутные встречи можно проводить без платного аккаунта. Omarchy оборачивает веб-клиент Zoom, и ссылки на встречи zoom будут открываться прямо в нём.

Вы запускаете Zoom с помощью лаунчера приложений (`Super + Space`).

## Discord

[Discord](https://discord.com/) — это место, где тусуется большинство игровых сообществ и сообществ открытого исходного кода, включая [собственное сообщество Omarchy](https://discord.gg/tXFUdasqhY).

Вы запускаете Discord с помощью лаунчера приложений (`Super + Space`).

## Приложения Microsoft

Выберите _Install > Service > Microsoft_, чтобы добавить Outlook, Word, Excel, PowerPoint, Teams и OneDrive в качестве веб-приложений. У каждого приложения есть собственный лаунчер, и оно открывается напрямую, используя коммерческие URL Microsoft 365 и ваш существующий профиль браузера. Они открываются в тех же окнах браузерных приложений, что и другие веб-приложения Omarchy; они не устанавливают отдельный клиент Teams for Linux.

Удалите этот набор с помощью _Remove > Service > Microsoft_ или удалите отдельные приложения с помощью _Remove > Web App_. Вы также можете установить только нужные вам приложения через _Install > Web App_.

Для государственного или суверенного облака отредактируйте URL в строке `Exec=` в соответствующем лаунчере в `~/.local/share/applications/`, например `Microsoft Teams.desktop`, используя URL, предоставленный вашей организацией. Любой буквальный `%` в этой строке записывайте как `%%`. Изменения вступят в силу при следующем запуске. Повторный запуск установщика набора заменит его лаунчеры URL по умолчанию.

Чтобы держать рабочие входы отдельно, добавьте каталог данных браузера в строку `Exec=` каждого лаунчера:

```ini
Exec=omarchy-launch-webapp "https://teams.cloud.microsoft/" --user-data-dir=/absolute/path/to/work-browser-profile
```

Замените пример каталога на абсолютный путь по вашему выбору и используйте один и тот же путь для всех шести лаунчеров, чтобы совместно использовать рабочие входы между ними. Веб-приложения используют выбранный поддерживаемый браузер Omarchy, а если браузер по умолчанию не поддерживается, откатываются на Chrome.
