# Сочетания клавиш

Все основные привязки клавиатуры можно увидеть через `Super + K` (привязки Tmux через `Super + Alt + K` и привязки Herdr через `Super + Ctrl + K`).

## Навигация

| Сочетание                  | Функция              |
| ----------------------- | --------------------- |
| `Super + Space`           | Меню Omarchy (приложения и всё остальное)    |
| `Super + Alt + Space` | Сетка приложений |
| `Super + Escape` | Меню системы (сон, перезагрузка и т.д.)  |
| `Super + Ctrl + L` | Заблокировать компьютер |
| `Super + W` or `Super + Q` | Закрыть окно             |
| `Ctrl + Alt + Del` | Закрыть все окна |
| `Super + T`               | Переключить окно между тайлингом/плавающим             |
| `Super + J` | Переключить положение окна (горизонтальное/вертикальное) |
| `Super + O`               | Переключить вынесение окна в закреплённое плавающее |
| `Super + L`               | Цикл раскладок dwindle, прокрутка и плавающая |
| `Super + Alt + L`         | Цикл раскладок в обратном порядке |
| `Super + P`               | Переключить псевдо-стиль окна (естественный vs растянутый) |
| `Super + F`                 | Полный экран              |
| `Super + Alt + F`                 | На всю ширину              |
| `Super + Ctrl + F`                 | Полный экран внутри окна              |
| `Super + 1/2/3/4`         | Перейти к конкретному рабочему пространству     |
| `Super + Tab` | Перейти к следующему рабочему пространству |
| `Super + Shift + Tab` | Перейти к предыдущему рабочему пространству |
| `Super + Ctrl + Tab` | Перейти к бывшему рабочему пространству |
| `Super + Shift + 1/2/3/4` | Переместить окно на рабочее пространство |
| `Super + Shift + Alt + 1/2/3/4` | Переместить окно на рабочее пространство, не следуя за ним |
| `Super + S` / `Super + Grave` | Переключить блокнот |
| `Super + Alt + S` / `Super + Shift + Grave` | Переместить окно в блокнот |
| `Super + Shift + Alt + Arrows` | Переместить рабочие пространства на направленный монитор |
| `Super + Arrow`  | Переместить фокус на окно в направлении стрелки              |
| `Super + Shift + Arrow`  | Поменять окно с другим в направлении стрелки     |
| `Super + Minus` | Расширить окно влево |
| `Super + Equal` | Сузить окно влево |
| `Super + Shift + Minus` | Сузить окно вверх |
| `Super + Shift + Equal` | Расширить окно вниз |
| `Super + Alt + Minus/Equal` | То же изменение размера меньшими шагами |
| `Super + Ctrl + Minus/Equal` | То же изменение размера большими шагами |
| `Super + Alt + Home` | Сохранить ширину окна |
| `Super + Home` | Восстановить сохранённую ширину окна |
| `Super + Left Mouse` | Перетаскивать окно |
| `Super + Right Mouse` | Изменять размер окна |
| `Super + Scroll Wheel` | Прокручивать рабочие пространства |
| `Super + G`               | Переключить группировку окна      |
| `Super + Alt + G`               | Вывести окно из группы      |
| `Super + Alt + Tab`               | Цикл между окнами в группе      |
| `Super + Alt + Shift + Tab`               | Обратный цикл между окнами в группе      |
| `Super + Alt + 1/2/3/4/5`               | Перейти к конкретному окну в группе      |
| `Super + Alt + Arrow`  | Переместить окно в группу в направлении стрелки  |
| `Super + Ctrl + Left/Right`  | Перемещаться между окнами внутри тайловой группы |
| `Super + Ctrl + Z` | Увеличить масштаб экрана (повторить для большего увеличения) |
| `Super + Ctrl + Alt + Z` | Полностью уменьшить масштаб экрана |
| `Super + /` | Шаг вперёд по опциям масштабирования монитора |
| `Super + Alt + /` | Шаг назад по опциям масштабирования монитора |
| `Alt + Tab` | Цикл вперёд по окнам активного рабочего пространства |
| `Alt + Shift + Tab` | Цикл назад по окнам активного рабочего пространства |
| `Ctrl + Alt + Tab`| Цикл фокуса вперёд по мониторам |
| `Ctrl + Alt + Shift + Tab`| Цикл фокуса назад по мониторам |

## Универсальный буфер обмена

| Сочетание                  | Функция              |
| ----------------------- | --------------------- |
| `Super + C`           | Копировать    |
| `Super + X`           | Вырезать (не в терминале)    |
| `Super + V`           | Вставить    |
| `Super + Ctrl + V`           | Менеджер буфера обмена    |

Обычно в Linux нужно `Ctrl + Shift + C/V` для копирования и вставки в терминале и `Ctrl + C/V` для этого везде в остальном. Эти единые сочетания клавиш буфера обмена Omarchy работают везде.

## Захват

| Сочетание              | Функция                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Меню захвата (для клавиатур без кнопки PrintScr) |
| `Print Screen`            | Снимок экрана                      |
| `Alt + Print Screen`            | Запись экрана                     |
| `Super + Print Screen` | Выбор цвета |
| `Super + Ctrl + Print Screen` | Извлечение текста в буфер обмена |
| `Super + Alt + [` | Уменьшить оверлей веб-камеры во время записи |
| `Super + Alt + ]` | Увеличить оверлей веб-камеры во время записи |
| `Alt + Shift + L` | Скопировать текущий URL из веб-приложения или Chromium |
| `Alt + Shift + D` | Скачать видео на текущей странице в `~/Videos` |
| `Super + Ctrl + X` | Старт/стоп диктовки (требуется _Настройка > По умолчанию > Dictation_) |
| `Right Alt` / `F9` | Диктовка push-to-talk (требуется Voxtype или Superwhisper) |

При записи экрана сочетание сначала спрашивает, какой звук нужен, затем начинает запись. Нажмите ещё раз, чтобы остановить. См. [снимки экрана и запись](12-screenshots-recording.md) для подробностей.

Все опции захвата также доступны в _Действия > Захват_ в меню Omarchy (`Super + Space`).

## Tmux

Префиксная клавиша — `Ctrl + Space` (`Ctrl + B` также работает). Эти привязки можно изменить в `~/.config/tmux/tmux.conf`.

### Панели

| Сочетание                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + v` | Разделить панель сбоку (вертикально) |
| `Prefix + h` | Разделить панель внизу (горизонтально) |
| `Prefix + x` | Убить панель |
| `Prefix + z` | Переключить зум панели (полный экран) |
| `Alt + Enter` | Разделить панель внизу (без префикса) |
| `Alt + Shift + Enter` | Разделить панель сбоку (без префикса) |
| `Alt + Escape` | Убить панель (без префикса) |
| `Ctrl + Alt + Arrows` | Перемещаться между панелями |
| `Ctrl + Alt + Shift + Arrows` | Изменять размер панелей |

### Окна

| Сочетание                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + c` | Новое окно |
| `Prefix + k` | Убить окно |
| `Prefix + r` | Переименовать окно |
| `Alt + 1-9` | Перейти к конкретному окну |
| `Alt + Arrow Left/Right` | Перемещаться между окнами |
| `Alt + Shift + Arrow Left/Right` | Переместить окно влево/вправо |

### Сессии

| Сочетание                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + C` | Новая сессия |
| `Prefix + K` | Убить сессию |
| `Prefix + R` | Переименовать сессию |
| `Prefix + N` | Следующая сессия |
| `Prefix + P` | Предыдущая сессия |
| `Alt + Arrow Up/Down` | Перемещаться между сессиями |
| `Prefix + s` | Список сессий |
| `Prefix + d` | Отключиться от сессии |

### Режим копирования (стиль vi)

| Сочетание                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + [` | Войти в режим копирования |
| `v` | Начать выделение (в режиме копирования) |
| `y` | Скопировать выделение (в режиме копирования) |

### Общее

| Сочетание                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + q` | Перезагрузить конфигурацию |
| `Prefix + ?` | Показать привязки клавиш Tmux |
| `Prefix + :` | Командная строка |

### Функции раскладки Tmux

Эти функции должны выполняться внутри сессии Tmux.

| Команда | Функция |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Создать раскладку разработчика с редактором, ИИ и терминалом |
| `tdlm <ai> [<second_ai>]` | Создать раскладку разработчика для каждого подкаталога |
| `tsl <count> <command>` | Создать многопанельную раскладку роя |
