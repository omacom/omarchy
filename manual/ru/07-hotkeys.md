# Горячие клавиши

Вы можете посмотреть все основные сочетания клавиш с помощью `Super + K` (сочетания Tmux — с помощью `Super + Alt + K`, а сочетания Herdr — с помощью `Super + Ctrl + K`).

## Навигация

| Сочетание                  | Функция              |
| ----------------------- | --------------------- |
| `Super + Space`           | Меню Omarchy (приложения и всё остальное)    |
| `Super + Alt + Space` | Сетка приложений |
| `Super + Escape` | Системное меню (спящий режим, перезагрузка и т. д.)  |
| `Super + Ctrl + L` | Заблокировать компьютер |
| `Super + W` or `Super + Q` | Закрыть окно             |
| `Ctrl + Alt + Del` | Закрыть все окна |
| `Super + T`               | Переключить окно между тайлингом и плавающим режимом             |
| `Super + J` | Переключить положение окна (горизонтальное/вертикальное) |
| `Super + O`               | Переключить всплывающее окно в sticky'n'floating |
| `Super + L`               | Переключение между раскладками dwindle, scrolling и floating |
| `Super + Alt + L`         | Переключение между раскладками в обратном порядке |
| `Super + P`               | Переключить стиль окна pseudo (natural v stretch) |
| `Super + F`                 | Перейти в полноэкранный режим              |
| `Super + Alt + F`                 | Развернуть на всю ширину              |
| `Super + Ctrl + F`                 | Полноэкранный режим внутри окна              |

| `Super + Tab` | Перейти к следующему рабочему столу на мониторе в фокусе |
| `Super + Shift + Tab` | Перейти к предыдущему рабочему столу на мониторе в фокусе |
| `Super + Ctrl + Tab` | Перейти к прежнему рабочему столу на мониторе в фокусе |
| `Super + Shift + 1/2/3/4` | Переместить окно на рабочий стол на мониторе в фокусе |
| `Super + Shift + Alt + 1/2/3/4` | Переместить окно на рабочий стол на мониторе в фокусе без перехода за ним |
| `Super + S` | Переключить полный scratchpad |
| `Super + Alt + S` | Переместить окно в полный scratchpad |
| `Super + Grave` | Переключить консоль Quake |
| `Super + Shift + Grave` | Переместить окно в консоль Quake |
| `Super + Shift + Ctrl + Arrows` | Переместить окно на монитор в этом направлении |
| `Super + Shift + Alt + Arrows` | Переместить рабочий стол на монитор в этом направлении |
| `Super + Arrow`  | Переместить фокус на окно в направлении стрелки, с переходом на монитор с этой стороны у края экрана |
| `Super + Shift + Arrow`  | Поменять окно местами с другим в направлении стрелки, включая окно на мониторе с этой стороны |
| `Super + Minus` | Расширить окно влево |
| `Super + Equal` | Сузить окно слева |
| `Super + Shift + Minus` | Сузить окно вверх |
| `Super + Shift + Equal` | Расширить окно вниз |
| `Super + Alt + Minus/Equal` | То же изменение размера меньшими шагами |
| `Super + Ctrl + Minus/Equal` | То же изменение размера большими шагами |
| `Super + Alt + Home` | Сохранить ширину окна |
| `Super + Home` | Восстановить сохранённую ширину окна |
| `Super + Left Mouse` | Перетаскивать окно |
| `Super + Right Mouse` | Изменять размер окна |
| `Super + Scroll Wheel` | Прокручивать рабочие столы на мониторе в фокусе |
| `Super + G`               | Переключить группировку окон      |
| `Super + Alt + G`               | Вывести окно из группировки      |
| `Super + Alt + Tab`               | Переключение между окнами в группировке      |
| `Super + Alt + Shift + Tab`               | Переключение назад между окнами в группировке      |
| `Super + Alt + Scroll Wheel` | Переключение между окнами в группировке |
| `Super + Alt + 1/2/3/4/5`               | Перейти к конкретному окну в группировке      |
| `Super + Alt + Arrow`  | Переместить окно в группировку в направлении стрелки, включая окно на мониторе с этой стороны |
| `Super + Ctrl + Left/Right`  | Перемещение между окнами внутри группы тайлинга |
| `Super + Ctrl + Z` | Увеличить масштаб экрана (повторить для большего увеличения) |
| `Super + Ctrl + Alt + Z` | Полностью уменьшить масштаб экрана |
| `Super + /` | Шаг вперёд по вариантам масштабирования монитора |
| `Super + Alt + /` | Шаг назад по вариантам масштабирования монитора |
| `Alt + Tab` | Переключение вперёд по окнам на активном рабочем столе |
| `Alt + Shift + Tab` | Переключение назад по окнам на активном рабочем столе |
| `Ctrl + Alt + Tab`| Циклический переход фокуса вперёд по мониторам |
| `Ctrl + Alt + Shift + Tab`| Циклический переход фокуса назад по мониторам |

Сочетания для изменения размера используют физические клавиши `code:20` и `code:21` (XKB `<AE11>` и `<AE12>`), независимо от символов, нанесённых на клавиатуру. На клавиатурах US эти клавиши — `-` и `=`; на японских (JIS) клавиатурах это `-` и `^`; на испанских клавиатурах это `'` и `¡`. На JIS `Super + ^` — это `Super + Equal`, а `Super + Shift + -` (которая вводит `=`) — это `Super + Shift + Minus`.

## Универсальный буфер обмена

| Сочетание                  | Функция              |
| ----------------------- | --------------------- |
| `Super + A`           | Выделить всё в приложениях, поддерживающих `Ctrl + A`    |
| `Super + C`           | Копировать    |
| `Super + X`           | Вырезать (не в терминале)    |
| `Super + V`           | Вставить    |
| `Super + Ctrl + V`           | Менеджер буфера обмена    |

Обычно в Linux вам нужно `Ctrl + Shift + C/V`, чтобы копировать и вставлять в терминале, и `Ctrl + C/V`, чтобы делать это везде в остальных местах. Эти унифицированные горячие клавиши буфера обмена Omarchy работают везде.

## Tmux

Префиксная клавиша — `Ctrl + Space` (также работает `Ctrl + B`). Вы можете изменить эти привязки в `~/.config/tmux/tmux.conf`.

### Панели

| Сочетание                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + v` | Разделить панель сбоку (вертикально) |
| `Prefix + h` | Разделить панель снизу (горизонтально) |
| `Prefix + x` | Закрыть панель |
| `Prefix + z` | Переключить масштаб панели (полноэкранный режим) |
| `Alt + Enter` | Разделить панель снизу (без префикса) |
| `Alt + Shift + Enter` | Разделить панель сбоку (без префикса) |
| `Alt + Escape` | Закрыть панель (без префикса) |
| `Ctrl + Alt + Arrows` | Перемещение между панелями |
| `Ctrl + Alt + Shift + Arrows` | Изменение размера панелей |
