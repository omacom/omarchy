# Горячие клавиши

Все основные привязки клавиш можно посмотреть с помощью `Super + K` (привязки Tmux — с помощью `Super + Alt + K`, а привязки Herdr — с помощью `Super + Ctrl + K`).

## Как устроены горячие клавиши

Каждая горячая клавиша находится на плоскости, задаваемой её модификаторами, и у каждой плоскости одна задача. Именно это не даёт горячим клавишам сливаться в кашу, и обычно можно угадать, где что живёт.

| Плоскость | Что там живёт | Примеры |
| --- | --- | --- |
| `Super + key` | Система: окна, рабочие пространства, раскладки и основные меню | `Super + Space` меню Omarchy, `Super + W` закрыть окно, `Super + F` полный экран |
| `Super + Shift + key` | Приложения | `Super + Shift + B` браузер, `Super + Shift + E` электронная почта, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панели и системные меню | `Super + Ctrl + A` аудио, `Super + Ctrl + N` сеть, `Super + Ctrl + C` меню захвата |
| `Super + Ctrl + Alt + key` | Быстрые действия и уведомления | `Super + Ctrl + Alt + T` показать время, `Super + Ctrl + Alt + B` батарея, `Super + Ctrl + Alt + C` снимок экрана |

Добавление `Alt` к горячей клавише даёт вариант того же самого, а не что-то unrelated: никогда не что-то несвязанное:

- `Super + Shift + B` открывает браузер; `Super + Shift + Alt + B` открывает приватное окно
- `Super + Shift + E` открывает электронную почту; `Super + Shift + Alt + E` создаёт новое письмо
- `Super + F` переходит в полноэкранный режим; `Super + Alt + F` растягивает на всю ширину
- `Super + Ctrl + C` открывает меню захвата; `Super + Ctrl + Alt + C` пропускает меню и делает снимок экрана

При добавлении горячей клавиши:

1. Сначала выберите плоскость по тому, что она делает, затем выберите клавишу.
2. Не двигайте существующую горячую клавишу, чтобы освободить место. Найдите свободную клавишу на нужной плоскости.
3. Используйте `Alt` только для варианта той же горячей клавиши без него.

Несколько горячих клавиш нарушают эти правила, потому что так удобнее. `Shift` со стрелкой или `Tab` перемещает или обращает действие, а не открывает приложение, а `Print`, медиа-клавиши, `Alt + Tab` и `Ctrl + Alt + Del` работают так же, как везде. Это исключения, а не паттерны для копирования.

Если значение по умолчанию вам не подходит (скажем, вы хотите `Super + Shift + S` для снимков экрана, как в Windows), перепривяжите его в `~/.config/hypr/bindings.lua`.

| `Super + Alt + Scroll Wheel` | Перебирать окна в группировке |
| `Super + Alt + 1/2/3/4/5`               | Перейти к конкретному окну в группировке      |
| `Super + Alt + Arrow`  | Переместить окно в группировку в направлении стрелки, включая окно на мониторе с той стороны |
| `Super + Ctrl + Left/Right`  | Перемещаться между окнами внутри тайлинговой группы |
| `Super + Ctrl + Z` | Увеличить экран (повторить для ещё большего увеличения) |
| `Super + Ctrl + Alt + Z` | Полностью отдалить экран |
| `Super + /` | Шаг вперёд по вариантам масштабирования монитора |
| `Super + Alt + /` | Шаг назад по вариантам масштабирования монитора |
| `Alt + Tab` | Перебирать вперёд окна на активном рабочем пространстве |
| `Alt + Shift + Tab` | Перебирать назад окна на активном рабочем пространстве |
| `Ctrl + Alt + Tab`| Перебирать фокус вперёд по мониторам |
| `Ctrl + Alt + Shift + Tab`| Перебирать фокус назад по мониторам |

Сочетания для изменения размера используют физические клавиши `code:20` и `code:21` (XKB `<AE11>` и `<AE12>`), независимо от символов, напечатанных на клавиатуре. На клавиатурах US это клавиши `-` и `=`; на японских (JIS) клавиатурах это `-` и `^`; на испанских клавиатурах это `'` и `¡`. На JIS `Super + ^` — это `Super + Equal`, а `Super + Shift + -` (которая печатает `=`) — это `Super + Shift + Minus`.

| Горячая клавиша                  | Функция              |
| ----------------------- | --------------------- |
| `Super + A`           | Выделить всё в приложениях, поддерживающих `Ctrl + A`    |
