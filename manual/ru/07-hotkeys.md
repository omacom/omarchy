# Горячие клавиши

Все основные сочетания клавиш можно посмотреть с помощью `Super + K` (привязки Tmux — с помощью `Super + Alt + K`, а привязки Herdr — с помощью `Super + Ctrl + K`).

## Как устроены горячие клавиши

Каждая горячая клавиша находится на своей плоскости, заданной её модификаторами, и у каждой плоскости одна задача. Именно это не даёт горячим клавишам сливаться друг с другом, и благодаря этому обычно можно угадать, где что находится.

| Плоскость | Что там находится | Примеры |
| --- | --- | --- |
| `Super + key` | Система: окна, рабочие пространства, раскладки и основные меню | `Super + Space` меню Omarchy, `Super + W` закрыть окно, `Super + F` во весь экран |
| `Super + Shift + key` | Приложения | `Super + Shift + B` браузер, `Super + Shift + E` электронная почта, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панели и системные меню | `Super + Ctrl + A` звук, `Super + Ctrl + N` сеть, `Super + Ctrl + C` меню захвата |
| `Super + Ctrl + Alt + key` | Быстрые действия и оповещения | `Super + Ctrl + Alt + T` показать время, `Super + Ctrl + Alt + B` батарея, `Super + Ctrl + Alt + C` скриншот |

Добавление `Alt` к горячей клавише даёт вариант того же самого, а не что-то unrelated:

- `Super + Shift + B` открывает браузер; `Super + Shift + Alt + B` открывает приватное окно
- `Super + Shift + E` открывает электронную почту; `Super + Shift + Alt + E` начинает новое письмо
- `Super + F` переходит во весь экран; `Super + Alt + F` переходит на всю ширину
- `Super + Ctrl + C` открывает меню захвата; `Super + Ctrl + Alt + C` пропускает меню и делает скриншот

При добавлении горячей клавиши:

1. Сначала выберите плоскость по тому, что она делает, затем выберите клавишу.
2. Не перемещайте существующую горячую клавишу, чтобы освободить место. Найдите свободную клавишу на нужной плоскости.
3. Используйте `Alt` только для варианта горячей клавиши без неё.

Несколько горячих клавиш нарушают эти правила, потому что так удобно. `Shift` со стрелкой или `Tab` перемещает или обращает действие, а не открывает приложение, а `Print`, медиаклавиши, `Alt + Tab` и `Ctrl + Alt + Del` работают так же, как везде. Это исключения, а не образцы для копирования.

Если значение по умолчанию вам не подходит (например, вы хотите `Super + Shift + S` для скриншотов, как в Windows), переназначьте его в `~/.config/hypr/bindings.lua`.

| `Super + Shift + I` | Переключить язык ввода обратно |

На тачпаде свайпы тремя и четырьмя пальцами переключают рабочие пространства, перемещают окна и открывают меню и консоль Quake; жесты смотрите в [клавиатура, мышь и трекпад](34-keyboard-mouse-trackpad.md).

Для изменения размера используются две клавиши справа от 0, что бы ни было напечатано на вашей клавиатуре: `-` и `=` на американских клавиатурах, `+` и `´` на датских и шведских, `+` и `\` на норвежских, `ß` и `´` на немецких, `'` и `¡` на испанских и `-` и `^` на японских (JIS). `Super + K` показывает их так, как они напечатаны на вашей клавиатуре. На JIS `Super + ^` — это `Super + Equal`, а `Super + Shift + -` (которая вводит `=`) — это `Super + Shift + Minus`. Масштабирование монитора и менеджер паролей используют `/`; на раскладках, где `/` вводится только с Shift, как на большинстве европейских, вместо этого они используют клавишу слева от правого Shift (`-` на датских и немецких).

## Универсальный буфер обмена

| Сочетание | Функция |
| ----------------------- | --------------------- |
| `Super + A` | Выбрать всё в приложениях, поддерживающих `Ctrl + A` |
| `Super + C` | Копировать |
| `Super + X` | Вырезать (не в терминале) |
| `Super + V` | Вставить |
| `Super + Ctrl + V` | Менеджер буфера обмена |

Обычно в Linux нужно `Ctrl + Shift + C/V`, чтобы копировать и вставлять в терминале, и `Ctrl + C/V`, чтобы делать это везде в остальных местах. Эти единые горячие клавиши буфера обмена Omarchy работают везде.
