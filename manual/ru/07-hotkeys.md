# Горячие клавиши

Все основные сочетания клавиш можно посмотреть с помощью `Super + K` (сочетания Tmux — `Super + Alt + K`, а сочетания Herdr — `Super + Ctrl + K`).

## Как устроены горячие клавиши

Каждая горячая клавиша находится на плоскости, которую задают её модификаторы, и у каждой плоскости одна задача. Именно поэтому горячие клавиши не сливаются в кашу, и обычно можно догадаться, где что живёт.

| Плоскость | Что здесь живёт | Примеры |
| --- | --- | --- |
| `Super + key` | Система: окна, рабочие пространства, раскладки и основные меню | `Super + Space` меню Omarchy, `Super + W` закрыть окно, `Super + F` полноэкранный режим |
| `Super + Shift + key` | Приложения | `Super + Shift + B` браузер, `Super + Shift + E` почта, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панели и системные меню | `Super + Ctrl + A` звук, `Super + Ctrl + N` сеть, `Super + Ctrl + C` меню захвата |
| `Super + Ctrl + Alt + key` | Быстрые действия и уведомления | `Super + Ctrl + Alt + T` показать время, `Super + Ctrl + Alt + B` батарея, `Super + Ctrl + Alt + C` скриншот |

Добавление `Alt` к горячей клавише даёт вариант того же самого, а не что-то unrelated:

- `Super + Shift + B` открывает браузер; `Super + Shift + Alt + B` открывает приватное окно
- `Super + Shift + E` открывает почту; `Super + Shift + Alt + E` создаёт новое письмо
- `Super + F` переходит в полноэкранный режим; `Super + Alt + F` растягивает на всю ширину
- `Super + Ctrl + C` открывает меню захвата; `Super + Ctrl + Alt + C` пропускает меню и сразу делает скриншот

При добавлении горячей клавиши:

1. Сначала выберите плоскость по тому, что она делает, затем выберите клавишу.
2. Не двигайте существующую горячую клавишу, чтобы освободить место. Найдите свободную клавишу на нужной плоскости.
3. Используйте `Alt` только для варианта той же горячей клавиши без него.

Несколько горячих клавиш нарушают эти правила, потому что так удобнее. `Shift` со стрелкой или `Tab` перемещает или обращает действие, а не открывает приложение, а `Print`, мультимедийные клавиши, `Alt + Tab` и `Ctrl + Alt + Del` работают так же, как везде. Это исключения, а не образцы для подражания.

Если стандартное сочетание вам не подходит (скажем, вы хотите `Super + Shift + S` для скриншотов, как в Windows), переназначьте его в `~/.config/hypr/bindings.lua`.

На тачпаде свайпы тремя и четырьмя пальцами переключают рабочие пространства, перемещают окна и открывают меню и консоль Quake; жесты см. в [клавиатура, мышь и трекпад](34-keyboard-mouse-trackpad.md).

Сочетания изменения размера используют физические клавиши `code:20` и `code:21` (XKB `<AE11>` и `<AE12>`), независимо от символов, напечатанных на клавиатуре. На клавиатурах US эти клавиши — `-` и `=`; на японских клавиатурах (JIS) — `-` и `^`; на испанских клавиатурах — `'` и `¡`. На JIS `Super + ^` — это `Super + Equal`, а `Super + Shift + -` (которое вводит `=`) — это `Super + Shift + Minus`.

## Универсальный буфер обмена

| Горячая клавиша | Функция |
| ----------------------- | --------------------- |
| `Super + A` | Выделить всё в приложениях, поддерживающих `Ctrl + A` |
| `Super + C` | Копировать |
| `Super + X` | Вырезать (не в терминале) |
| `Super + V` | Вставить |
| `Super + Ctrl + V` | Менеджер буфера обмена |

Обычно в Linux нужно `Ctrl + Shift + C/V` для копирования и вставки в терминале и `Ctrl + C/V` для этого везде в остальных местах. Эти унифицированные горячие клавиши буфера обмена Omarchy работают везде.
