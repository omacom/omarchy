# Горячие клавиши

Все основные сочетания клавиш можно посмотреть с помощью `Super + K` (сочетания Tmux — с помощью `Super + Alt + K`, а сочетания Herdr — с помощью `Super + Ctrl + K`).

## Как устроены горячие клавиши

Каждая горячая клавиша находится на плоскости, задаваемой её модификаторами, и у каждой плоскости одна задача. Именно поэтому горячие клавиши не сливаются друг с другом, и обычно можно догадаться, где что находится.

| Плоскость | Что там находится | Примеры |
| --- | --- | --- |
| `Super + key` | Система: окна, рабочие пространства, раскладки и основные меню | `Super + Space` меню Omarchy, `Super + W` закрыть окно, `Super + F` полноэкранный режим |
| `Super + Shift + key` | Приложения | `Super + Shift + B` браузер, `Super + Shift + E` электронная почта, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панели и системные меню | `Super + Ctrl + A` аудио, `Super + Ctrl + N` сеть, `Super + Ctrl + C` меню захвата |
| `Super + Ctrl + Alt + key` | Быстрые действия и извещения | `Super + Ctrl + Alt + T` показать время, `Super + Ctrl + Alt + B` батарея, `Super + Ctrl + Alt + C` скриншот |

Добавление `Alt` к горячей клавише даёт вариант того же самого, а не что-то несвязанное:

- `Super + Shift + B` открывает браузер; `Super + Shift + Alt + B` открывает приватное окно
- `Super + Shift + E` открывает электронную почту; `Super + Shift + Alt + E` начинает новое письмо
- `Super + F` переходит в полноэкранный режим; `Super + Alt + F` разворачивает на всю ширину
- `Super + Ctrl + C` открывает меню захвата; `Super + Ctrl + Alt + C` пропускает меню и делает скриншот

При добавлении горячей клавиши:

1. Сначала выберите плоскость по тому, что она делает, затем выберите клавишу.
2. Не перемещайте существующую горячую клавишу, чтобы освободить место. Найдите свободную клавишу на нужной плоскости.
3. Используйте `Alt` только для варианта горячей клавиши без него.

Несколько горячих клавиш нарушают эти правила, потому что так удобнее. `Shift` со стрелкой или `Tab` перемещает или обращает действие вместо открытия приложения, а `Print`, мультимедийные клавиши, `Alt + Tab` и `Ctrl + Alt + Del` работают так же, как и везде. Это исключения, а не шаблоны для подражания.

Если значение по умолчанию вам не подходит (например, вы хотите `Super + Shift + S` для скриншотов, как в Windows), переназначьте его в `~/.config/hypr/bindings.lua`.

| `Super + Alt + /` | Перейти назад по вариантам масштабирования монитора |
| `Alt + Tab` | Циклически переходить вперёд по окнам в активном рабочем пространстве |

| `Ctrl + Alt + Shift + Tab` | Циклически перемещать фокус назад по мониторам |
| `Super + I` | Переключить язык ввода (при наличии более одной раскладки или метода ввода) |
| `Super + Shift + I` | Переключить язык ввода обратно |

На сенсорной панели свайпы тремя и четырьмя пальцами переключают рабочие пространства, перемещают окна и открывают меню и консоль Quake; жесты см. в [клавиатура, мышь и трекпад](34-keyboard-mouse-trackpad.md).

Для изменения размера используются две клавиши справа от 0, что бы ни было напечатано на вашей клавиатуре: `-` и `=` на клавиатурах US, `+` и `´` на датских и шведских, `+` и `\` на норвежских, `ß` и `´` на немецких, `'` и `¡` на испанских и `-` и `^` на японских (JIS). `Super + K` показывает их так, как они напечатаны на вашей клавиатуре. На JIS `Super + ^` — это `Super + Equal`, а `Super + Shift + -` (которая вводит `=`) — это `Super + Shift + Minus`. Для масштабирования монитора и менеджера паролей используется `/`; в раскладках, где `/` вводится только с Shift, как в большинстве европейских, вместо неё используется клавиша слева от правого Shift (`-` на датских и немецких).

## Универсальный буфер обмена

| Горячая клавиша | Функция |
| ----------------------- | --------------------- |
| `Super + A` | Выделить всё в приложениях, поддерживающих `Ctrl + A` |
| `Super + C` | Копировать |
| `Super + X` | Вырезать (не в терминале) |
| `Super + V` | Вставить |
| `Super + Ctrl + V` | Менеджер буфера обмена |

Обычно в Linux нужен `Ctrl + Shift + C/V`, чтобы копировать и вставлять в терминале, и `Ctrl + C/V`, чтобы делать это везде в остальных местах. Эти унифицированные горячие клавиши буфера обмена Omarchy работают везде.
