# Горячие клавиши

Вы можете посмотреть все основные сочетания клавиш с помощью `Super + K` (сочетания Tmux — с помощью `Super + Alt + K`, а сочетания Herdr — с помощью `Super + Ctrl + K`).

## Навигация

| Горячая клавиша                  | Функция              |
| ----------------------- | --------------------- |
| `Super + Space`           | Меню Omarchy (приложения и всё остальное)    |
| `Super + Alt + Space` | Сетка приложений |
| `Super + Escape` | Системное меню (спящий режим, перезагрузка и т. д.)  |
| `Super + Ctrl + L` | Заблокировать компьютер |
| `Super + W` or `Super + Q` | Закрыть окно             |
| `Ctrl + Alt + Del` | Закрыть все окна |
| `Super + T`               | Переключить окно между тайлинговым/плавающим режимами             |
| `Super + J` | Переключить положение окна (горизонтальное/вертикальное) |
| `Super + O`               | Переключить всплывающее окно в режим sticky'n'floating |
| `Super + L`               | Переключаться по кругу между раскладками dwindle, scrolling и floating |
| `Super + Alt + L`         | Переключаться между раскладками в обратном порядке |
| `Super + P`               | Переключить стиль псевдоокна (natural против stretch) |
| `Super + F`                 | Перейти в полноэкранный режим              |
| `Super + Alt + F`                 | Растянуть на всю ширину              |
| `Super + Ctrl + F`                 | Полноэкранный режим внутри окна              |
| `Super + 1/2/3/4`         | Перейти к определённому рабочему пространству на активном мониторе |
| `Super + Tab` | Перейти к следующему рабочему пространству на активном мониторе |
| `Super + Shift + Tab` | Перейти к предыдущему рабочему пространству на активном мониторе |
| `Super + Ctrl + Tab` | Перейти к прежнему рабочему пространству на активном мониторе |
| `Super + Shift + 1/2/3/4` | Переместить окно в рабочее пространство на активном мониторе |
| `Super + Shift + Alt + 1/2/3/4` | Переместить окно в рабочее пространство на активном мониторе, не переходя следом |
| `Super + S` | Включить/выключить полный scratchpad |
| `Super + Alt + S` | Переместить окно в полный scratchpad |
| `Super + Grave` | Показать/скрыть консоль Quake |
| `Super + Shift + Grave` | Переместить окно в консоль Quake |
| `Super + Shift + Ctrl + Arrows` | Переместить окно на монитор в этом направлении |
| `Super + Shift + Alt + Arrows` | Переместить рабочее пространство на монитор в этом направлении |
| `Super + Arrow`  | Переместить фокус на окно в направлении стрелки, перейдя к монитору с той стороны у края экрана |
| `Super + Shift + Arrow`  | Поменять окно местами с другим в направлении стрелки, включая окно на мониторе с той стороны |
| `Super + Minus` | Расширить окно влево |
| `Super + Equal` | Сжать окно влево |
| `Super + Shift + Minus` | Сжать окно вверх |
| `Super + Shift + Equal` | Расширить окно вниз |
| `Super + Alt + Minus/Equal` | То же изменение размера, но меньшими шагами |
| `Super + Ctrl + Minus/Equal` | То же изменение размера, но большими шагами |
| `Super + Alt + Home` | Сохранить ширину окна |
| `Super + Home` | Восстановить сохранённую ширину окна |
| `Super + Left Mouse` | Перетаскивать окно |
| `Super + Right Mouse` | Изменять размер окна |
| `Super + Scroll Wheel` | Прокручивать рабочие пространства на активном мониторе |
| `Super + G`               | Включить/выключить группировку окна      |
| `Super + Alt + G`               | Вынести окно из группировки      |
| `Super + Alt + Tab`               | Переключаться между окнами в группировке      |
| `Super + Alt + Shift + Tab`               | Переключаться в обратном порядке между окнами в группировке      |
| `Super + Alt + Scroll Wheel` | Переключаться между окнами в группировке |
| `Super + Alt + 1/2/3/4/5`               | Перейти к определённому окну в группировке      |
| `Super + Alt + Arrow`  | Переместить окно в группировку в направлении стрелки, включая окно на мониторе с той стороны |
| `Super + Ctrl + Left/Right`  | Перемещаться между окнами внутри тайлинговой группы |
| `Super + Ctrl + Z` | Увеличить масштаб экрана (повтор — ещё больше) |
| `Super + Ctrl + Alt + Z` | Полностью уменьшить масштаб экрана |
| `Super + /` | Шаг вперёд по вариантам масштабирования монитора |
| `Super + Alt + /` | Шаг назад по вариантам масштабирования монитора |
| `Alt + Tab` | Переключаться вперёд между окнами в активном рабочем пространстве |
| `Alt + Shift + Tab` | Переключаться назад между окнами в активном рабочем пространстве |
| `Ctrl + Alt + Tab`| Перемещать фокус вперёд между мониторами |
| `Ctrl + Alt + Shift + Tab`| Перемещать фокус назад между мониторами |

## Универсальный буфер обмена

| Горячая клавиша                  | Функция              |
| ----------------------- | --------------------- |
| `Super + C`           | Копировать    |
| `Super + X`           | Вырезать (не в терминале)    |
| `Super + V`           | Вставить    |
| `Super + Ctrl + V`           | Менеджер буфера обмена    |

Обычно в Linux вам нужны `Ctrl + Shift + C/V`, чтобы копировать и вставлять в терминале, и `Ctrl + C/V`, чтобы делать это везде в остальных местах. Эти унифицированные горячие клавиши буфера обмена Omarchy работают везде.

## Захват

| Горячая клавиша              | Функция                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Скриншот                      |
| `Super + Ctrl + Alt + C`            | Скриншот (тот же снимок, для клавиатур без клавиши Print Screen) |
| `Super + Ctrl + C` | Меню захвата |
| `Alt + Print Screen`            | Запись экрана                     |
| `Super + Print Screen` | Пипетка цвета |
| `Super + Ctrl + Print Screen` | Извлечение текста в буфер обмена |
| `Super + Alt + [` | Сделать оверлей веб-камеры меньше во время записи |
| `Super + Alt + ]` | Сделать оверлей веб-камеры больше во время записи |
| `Alt + Shift + L` | Скопировать текущий URL из веб-приложения или Chromium |
| `Alt + Shift + D` | Скачать видео на текущей странице в `~/Videos` |
| `Super + Ctrl + X` | Запустить/остановить диктовку (требуется _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | Диктовка в режиме push-to-talk (требуется Voxtype или Superwhisper) |

При записи экрана горячая клавиша сначала спрашивает, какой звук вы хотите, а затем начинает запись. Нажмите её ещё раз, чтобы остановить. Подробности см. в [скриншоты и запись](12-screenshots-recording.md).

Все варианты захвата также доступны в разделе _Trigger > Capture_ в меню Omarchy (`Super + Space`).

## Tmux

Клавиша-префикс — `Ctrl + Space` (`Ctrl + B` тоже работает). Вы можете изменить эти привязки в `~/.config/tmux/tmux.conf`.

### Панели

| Горячая клавиша                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + v` | Разделить панель сбоку (вертикально) |
| `Prefix + h` | Разделить панель снизу (горизонтально) |
| `Prefix + x` | Убить панель |
| `Prefix + z` | Включить/выключить масштаб панели (на весь экран) |
| `Alt + Enter` | Разделить панель снизу (без префикса) |
| `Alt + Shift + Enter` | Разделить панель сбоку (без префикса) |
| `Alt + Escape` | Убить панель (без префикса) |
| `Ctrl + Alt + Arrows` | Перемещаться между панелями |
| `Ctrl + Alt + Shift + Arrows` | Изменять размер панелей |

### Окна

| Горячая клавиша                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + c` | Новое окно |
| `Prefix + k` | Убить окно |
| `Prefix + r` | Переименовать окно |
| `Alt + 1-9` | Перейти к определённому окну |
| `Alt + Arrow Left/Right` | Перемещаться между окнами |
| `Alt + Shift + Arrow Left/Right` | Переместить окно влево/вправо |

### Сессии

| Горячая клавиша                  | Функция              |

### Функции раскладки Tmux

Эти функции должны запускаться внутри сессии Tmux.

| Команда | Функция |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Создать раскладку для разработки с редактором, ИИ и терминалом |
| `tdlm <ai> [<second_ai>]` | Создать раскладку для разработки для каждого подкаталога |
| `tsl <count> <command>` | Создать многопанельную раскладку swarm |
