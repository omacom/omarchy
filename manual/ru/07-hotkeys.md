# Хоткеи

Все главные хоткеи видны по `Super + K` (хоткеи Tmux — по `Super + Alt + K`, хоткеи Herdr — по `Super + Ctrl + K`).

## Навигация

| Хоткей                  | Функция              |
| ----------------------- | --------------------- |
| `Super + Space`           | Меню Omarchy (приложения и всё остальное)    |
| `Super + Alt + Space` | Меню приложений |
| `Super + Escape` | Системное меню (сон, рестарт и т.д.)  |
| `Super + Ctrl + L` | Заблокировать компьютер |
| `Super + W` или `Super + Q` | Закрыть окно             |
| `Ctrl + Alt + Del` | Закрыть все окна |
| `Super + T`               | Окно туда-сюда тилинг/флоатинг             |
| `Super + J` | Позиция окна (горизонталь/вертикаль) |
| `Super + O`               | Выдернуть окно в липкое-плавающее |
| `Super + L`               | Тогл dwindle и прокручиваемого layout |
| `Super + P`               | Тогл псевдо-окна (natural v stretch) |
| `Super + F`                 | Весь экран              |
| `Super + Alt + F`                 | Вся ширина              |
| `Super + Ctrl + F`                 | Весь экран внутри окна              |
| `Super + 1/2/3/4`         | Прыгнуть на стол     |
| `Super + Tab` | Следующий стол |
| `Super + Shift + Tab` | Предыдущий стол |
| `Super + Ctrl + Tab` | Бывший стол |
| `Super + Shift + 1/2/3/4` | Окно на стол |
| `Super + Shift + Alt + 1/2/3/4` | Окно на стол без фокуса |
| `Super + S` / `Super + Grave` | Скрытый стол |
| `Super + Alt + S` / `Super + Shift + Grave` | Окно в скрытый стол |
| `Super + Shift + Alt + Стрелки` | Стол на монитор по направлению |
| `Super + Стрелка`  | Фокус на окно по направлению              |
| `Super + Shift + Стрелка`  | Поменять окно с другим по направлению     |
| `Super + Minus` | Окно шире влево |
| `Super + Equal` | Окно уже влево |
| `Super + Shift + Minus` | Окно меньше вверх |
| `Super + Shift + Equal` | Окно больше вниз |
| `Super + Alt + Minus/Equal` | Та же резина мелким шагом |
| `Super + Ctrl + Minus/Equal` | Та же резина крупным шагом |
| `Super + Alt + Home` | Сохранить ширину окна |
| `Super + Home` | Вернуть ширину окна |
| `Super + Левая мышь` | Таскать окно |
| `Super + Правая мышь` | Ресайз окна |
| `Super + Колесо` | Листать столы |
| `Super + G`               | Группа окон      |
| `Super + Alt + G`               | Окно из группы      |
| `Super + Alt + Tab`               | Листать окна в группе      |
| `Super + Alt + Shift + Tab`               | Листать назад окна в группе      |
| `Super + Alt + 1/2/3/4/5`               | Прыгнуть на окно в группе      |
| `Super + Alt + Стрелка`  | Окно в группу по направлению  |
| `Super + Ctrl + Влево/Вправо`  | Ходить между окнами в тайлинг-группе |
| `Super + Ctrl + Z` | Приблизить экран (жми ещё) |
| `Super + Ctrl + Alt + Z` | Отъехать от экрана полностью |
| `Super + /` | Шаг масштаба монитора вперёд |
| `Super + Alt + /` | Шаг масштаба монитора назад |
| `Alt + Tab` | Листать вперёд окна активного стола |
| `Alt + Shift + Tab` | Листать назад окна активного стола |
| `Ctrl + Alt + Tab`| Фокус вперёд по мониторам |
| `Ctrl + Alt + Shift + Tab`| Фокус назад по мониторам |

## Единый буфер

| Хоткей                  | Функция              |
| ----------------------- | --------------------- |
| `Super + C`           | Копировать    |
| `Super + X`           | Вырезать (не в терминале)    |
| `Super + V`           | Вставить    |
| `Super + Ctrl + V`           | Менеджер буфера    |

Обычно на Linux надо `Ctrl + Shift + C/V` для копипасты в терминале и `Ctrl + C/V` везде в остальных местах. Эти единые хоткеи Omarchy работают везде.

## Захват

| Хоткей              | Функция                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | Меню захвата (для клав без PrintScr) |
| `Print Screen`            | Скриншот                      |
| `Alt + Print Screen`            | Запись экрана                     |
| `Super + Print Screen` | Пипетка цвета |
| `Super + Ctrl + Print Screen` | Текст со скриншота в буфер |
| `Super + Alt + [` | Оверлей камеры меньше при записи |
| `Super + Alt + ]` | Оверлей камеры больше при записи |
| `Alt + Shift + L` | URL текущей страницы из веб-приложения или Chromium |
| `Alt + Shift + D` | Видео с текущей страницы в `~/Videos` |
| `Super + Ctrl + X` | Старт/стоп диктовки (надо _Установить > AI > Диктовка_) |
| `F9` | Диктовка по кнопке (надо _Установить > AI > Диктовка_) |
| `F9` | Диктовка по кнопке (надо _Установить > AI > Диктовка_) |

С записью экрана хоткей сначала спросит, какой звук писать, потом стартует. Жми ещё раз — стоп. См. [скриншоты и запись](12-screenshots-recording.md).

Все опции захвата есть и в _Действия > Захват_ в меню Omarchy (`Super + Space`).

## Tmux

Префикс — `Ctrl + Space` (работает и `Ctrl + B`). Хоткеи меняются в `~/.config/tmux/tmux.conf`.

### Панели

| Хоткей                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + v` | Сплит рядом (вертикаль) |
| `Prefix + h` | Сплит снизу (горизонталь) |
| `Prefix + x` | Убить панель |
| `Prefix + z` | Тогл зума панели (весь экран) |
| `Alt + Enter` | Сплит снизу (без префикса) |
| `Alt + Shift + Enter` | Сплит рядом (без префикса) |
| `Alt + Escape` | Убить панель (без префикса) |
| `Ctrl + Alt + Стрелки` | Ходить между панелями |
| `Ctrl + Alt + Shift + Стрелки` | Ресайз панелей |

### Окна

| Хоткей                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + c` | Новое окно |
| `Prefix + k` | Убить окно |
| `Prefix + r` | Переименовать окно |
| `Alt + 1-9` | На конкретное окно |
| `Alt + Стрелка влево/вправо` | Ходить между окнами |
| `Alt + Shift + Стрелка влево/вправо` | Окно влево/вправо |

### Сессии

| Хоткей                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + C` | Новая сессия |
| `Prefix + K` | Убить сессию |
| `Prefix + R` | Переименовать сессию |
| `Prefix + N` | Следующая сессия |
| `Prefix + P` | Предыдущая сессия |
| `Alt + Стрелка вверх/вниз` | Ходить между сессиями |
| `Prefix + s` | Список сессий |
| `Prefix + d` | Отцепиться от сессии |

### Копирежим (vi-стиль)

| Хоткей                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + [` | Войти в копирежим |
| `v` | Начать выделение (в копирежиме) |
| `y` | Скопировать (в копирежиме) |

### Общее

| Хоткей                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + q` | Перечитать конфиг |
| `Prefix + ?` | Показать хоткеи Tmux |
| `Prefix + :` | Командная строка |

### Layout-функции Tmux

Работают внутри Tmux-сессии.

| Команда | Функция |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Дев-раскладка: редактор, AI и терминал |
| `tdlm <ai> [<second_ai>]` | Дев-раскладка по подкаталогам |
| `tsl <count> <command>` | Мультипанельный рой |
