# Горячие клавиши

Все основные сочетания клавиш можно посмотреть по `Super + K` (сочетания Tmux — по `Super + Alt + K`, а Herdr — по `Super + Ctrl + K`).

## Навигация

| Горячая клавиша | Функция |
| ----------------------- | --------------------- |
| `Super + Space` | Меню Omarchy (приложения и всё остальное) |
| `Super + Alt + Space` | Сетка приложений |
| `Super + Escape` | Системное меню (сон, перезагрузка и т. д.) |
| `Super + Ctrl + L` | Заблокировать компьютер |
| `Super + W` или `Super + Q` | Закрыть окно |
| `Ctrl + Alt + Del` | Закрыть все окна |
| `Super + T` | Переключить окно между тайлингом и плавающим режимом |
| `Super + J` | Переключить положение окна (горизонтальное/вертикальное) |
| `Super + O` | Переключить окно в режим sticky'n'floating |
| `Super + L` | Переключаться по кругу между раскладками dwindle, scrolling и floating |
| `Super + Alt + L` | Переключаться по кругу между раскладками в обратном порядке |
| `Super + P` | Переключить стиль псевдоокна (natural v stretch) |
| `Super + F` | На весь экран |
| `Super + Alt + F` | На всю ширину |
| `Super + Ctrl + F` | На весь экран внутри окна |
| `Super + 1/2/3/4` | Перейти к конкретному рабочему столу на активном мониторе |
| `Super + Tab` | Перейти к следующему рабочему столу на активном мониторе |
| `Super + Shift + Tab` | Перейти к предыдущему рабочему столу на активном мониторе |
| `Super + Ctrl + Tab` | Перейти к прежнему рабочему столу на активном мониторе |
| `Super + Shift + 1/2/3/4` | Переместить окно на рабочий стол на активном мониторе |
| `Super + Shift + Alt + 1/2/3/4` | Переместить окно на рабочий стол на активном мониторе, не переходя за ним |
| `Super + S` | Показать/скрыть полный scratchpad |
| `Super + Alt + S` | Переместить окно в полный scratchpad |
| `Super + Grave` | Показать/скрыть консоль Quake |
| `Super + Shift + Grave` | Переместить окно в консоль Quake |
| `Super + Shift + Ctrl + Arrows` | Переместить окно на монитор в этом направлении |
| `Super + Shift + Alt + Arrows` | Переместить рабочий стол на монитор в этом направлении |
| `Super + Arrow` | Переместить фокус на окно в направлении стрелки, с переходом на монитор с этой стороны у края экрана |
| `Super + Shift + Arrow` | Поменять окно местами с другим в направлении стрелки, включая окно на мониторе с этой стороны |
| `Super + Minus` | Расширить окно влево |
| `Super + Equal` | Сузить окно слева |
| `Super + Shift + Minus` | Сузить окно сверху |
| `Super + Shift + Equal` | Расширить окно вниз |
| `Super + Alt + Minus/Equal` | То же изменение размера, но меньшими шагами |
| `Super + Ctrl + Minus/Equal` | То же изменение размера, но большими шагами |
| `Super + Alt + Home` | Сохранить ширину окна |
| `Super + Home` | Восстановить сохранённую ширину окна |
| `Super + Left Mouse` | Перетаскивать окно |
| `Super + Right Mouse` | Изменять размер окна |
| `Super + Scroll Wheel` | Прокручивать рабочие столы на активном мониторе |
| `Super + G` | Включить/выключить группировку окон |
| `Super + Alt + G` | Вынести окно из группы |
| `Super + Alt + Tab` | Переключаться между окнами в группе |
| `Super + Alt + Shift + Tab` | Переключаться назад между окнами в группе |
| `Super + Alt + Scroll Wheel` | Переключаться между окнами в группе |
| `Super + Alt + 1/2/3/4/5` | Перейти к конкретному окну в группе |
| `Super + Alt + Arrow` | Переместить окно в группу в направлении стрелки, включая окно на мониторе с этой стороны |
| `Super + Ctrl + Left/Right` | Перемещаться между окнами внутри тайлинговой группы |
| `Super + Ctrl + Z` | Увеличить масштаб экрана (повторить для большего увеличения) |
| `Super + Ctrl + Alt + Z` | Полностью уменьшить масштаб экрана |
| `Super + /` | Шаг вперёд по вариантам масштабирования монитора |
| `Super + Alt + /` | Шаг назад по вариантам масштабирования монитора |
| `Alt + Tab` | Переключаться вперёд между окнами на активном рабочем столе |
| `Alt + Shift + Tab` | Переключаться назад между окнами на активном рабочем столе |
| `Ctrl + Alt + Tab` | Переключать фокус вперёд между мониторами |
| `Ctrl + Alt + Shift + Tab` | Переключать фокус назад между мониторами |

Сочетания для изменения размера используют физические клавиши `code:20` и `code:21` (XKB `<AE11>` и `<AE12>`), независимо от символов, напечатанных на клавиатуре. На американских клавиатурах это клавиши `-` и `=`; на японских (JIS) клавиатурах это `-` и `^`; на испанских клавиатурах это `'` и `¡`. На JIS `Super + ^` — это `Super + Equal`, а `Super + Shift + -` (которая вводит `=`) — это `Super + Shift + Minus`.

## Универсальный буфер обмена

| Горячая клавиша | Функция |
| ----------------------- | --------------------- |
| `Super + A` | Выделить всё в приложениях, поддерживающих `Ctrl + A` |
| `Super + C` | Копировать |
| `Super + X` | Вырезать (не в терминале) |
| `Super + V` | Вставить |
| `Super + Ctrl + V` | Менеджер буфера обмена |

Обычно в Linux нужно `Ctrl + Shift + C/V`, чтобы копировать и вставлять в терминале, и `Ctrl + C/V` — чтобы делать это везде в остальных местах. Эти унифицированные горячие клавиши буфера обмена Omarchy работают везде.

| Горячая клавиша | Дополнение |
| ------------ |  ---------- |
| `Shift + CapsLock Space Space` | — (длинное тире) |
