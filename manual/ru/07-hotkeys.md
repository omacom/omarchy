# Горячие клавиши

Все основные сочетания клавиш можно посмотреть с помощью `Super + K` (сочетания Tmux — с помощью `Super + Alt + K`, а сочетания Herdr — с помощью `Super + Ctrl + K`).

## Навигация

| Горячая клавиша                  | Функция              |
| ----------------------- | --------------------- |
| `Super + Space`           | Меню Omarchy (приложения и всё остальное)    |
| `Super + Alt + Space` | Сетка приложений |
| `Super + Escape` | Системное меню (спящий режим, перезагрузка и т. д.)  |
| `Super + Ctrl + L` | Заблокировать компьютер |
| `Super + W` or `Super + Q` | Закрыть окно             |
| `Ctrl + Alt + Del` | Закрыть все окна |
| `Super + T`               | Переключить окно между плиточным/плавающим режимами             |
| `Super + J` | Переключить расположение окна (горизонтальное/вертикальное) |
| `Super + O`               | Переключить окно в закреплённый плавающий режим поверх остальных |
| `Super + L`               | Циклически переключать раскладки dwindle, scrolling и floating |
| `Super + Alt + L`         | Циклически переключать раскладки в обратном порядке |
| `Super + P`               | Переключить стиль pseudo-окна (естественный / растянутый) |
| `Super + F`                 | Перейти в полноэкранный режим              |
| `Super + Alt + F`                 | Растянуть на всю ширину              |
| `Super + Ctrl + F`                 | Полноэкранный режим внутри окна              |
| `Super + 1/2/3/4`         | Перейти к определённому рабочему пространству на активном мониторе |
| `Super + Tab` | Перейти к следующему рабочему пространству на активном мониторе |
| `Super + Shift + Tab` | Перейти к предыдущему рабочему пространству на активном мониторе |
| `Super + Ctrl + Tab` | Перейти к прежнему рабочему пространству на активном мониторе |
| `Super + Shift + 1/2/3/4` | Переместить окно в рабочее пространство на активном мониторе |
| `Super + Shift + Alt + 1/2/3/4` | Переместить окно в рабочее пространство на активном мониторе, не переходя следом |
| `Super + S` | Переключить полный scratchpad |
| `Super + Alt + S` | Переместить окно в полный scratchpad |
| `Super + Grave` | Переключить консоль Quake |
| `Super + Shift + Grave` | Переместить окно в консоль Quake |
| `Super + Shift + Ctrl + Arrows` | Переместить окно на монитор в этом направлении |
| `Super + Shift + Alt + Arrows` | Переместить рабочее пространство на монитор в этом направлении |
| `Super + Arrow`  | Переместить фокус на окно в направлении стрелки, с переходом на монитор с той стороны на краю экрана |
| `Super + Shift + Arrow`  | Поменять окно местами с другим в направлении стрелки, включая окно на мониторе с той стороны |
| `Super + Minus` | Расширить окно влево |
| `Super + Equal` | Уменьшить окно слева |
| `Super + Shift + Minus` | Уменьшить окно сверху |
| `Super + Shift + Equal` | Расширить окно вниз |
| `Super + Alt + Minus/Equal` | То же изменение размера, но меньшими шагами |
| `Super + Ctrl + Minus/Equal` | То же изменение размера, но большими шагами |
| `Super + Alt + Home` | Сохранить ширину окна |
| `Super + Home` | Восстановить сохранённую ширину окна |
| `Super + Left Mouse` | Перетаскивать окно |
| `Super + Right Mouse` | Изменять размер окна |
| `Super + Scroll Wheel` | Прокручивать рабочие пространства на активном мониторе |
| `Super + G`               | Переключить группировку окон      |
| `Super + Alt + G`               | Убрать окно из группировки      |
| `Super + Alt + Tab`               | Переключаться между окнами в группе      |
| `Super + Alt + Shift + Tab`               | Переключаться в обратном порядке между окнами в группе      |
| `Super + Alt + Scroll Wheel` | Переключаться между окнами в группе |
| `Super + Alt + 1/2/3/4/5`               | Перейти к определённому окну в группе      |
| `Super + Alt + Arrow`  | Переместить окно в группу в направлении стрелки, включая окно на мониторе с той стороны |
| `Super + Ctrl + Left/Right`  | Перемещаться между окнами внутри плиточной группы |
| `Super + Ctrl + Z` | Увеличить масштаб экрана (повторять для большего увеличения) |
| `Super + Ctrl + Alt + Z` | Полностью уменьшить масштаб экрана |
| `Super + /` | Перейти вперёд по вариантам масштабирования монитора |
| `Super + Alt + /` | Перейти назад по вариантам масштабирования монитора |
| `Alt + Tab` | Переключаться вперёд между окнами в активном рабочем пространстве |
| `Alt + Shift + Tab` | Переключаться назад между окнами в активном рабочем пространстве |
| `Ctrl + Alt + Tab`| Циклически переключать фокус вперёд между мониторами |
| `Ctrl + Alt + Shift + Tab`| Циклически переключать фокус назад между мониторами |

## Универсальный буфер обмена

| Горячая клавиша                  | Функция              |
| ----------------------- | --------------------- |
| `Super + C`           | Копировать    |
| `Super + X`           | Вырезать (не в терминале)    |
| `Super + V`           | Вставить    |
| `Super + Ctrl + V`           | Менеджер буфера обмена    |

Обычно в Linux для копирования и вставки в терминале нужно `Ctrl + Shift + C/V`, а везде в остальных местах — `Ctrl + C/V`. Эти унифицированные горячие клавиши буфера обмена Omarchy работают везде.

## Захват

| Горячая клавиша              | Функция                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Скриншот                      |
| `Super + Ctrl + Alt + C`            | Скриншот (тот же снимок, для клавиатур без клавиши Print Screen) |
| `Super + Ctrl + C` | Меню захвата |
| `Alt + Print Screen`            | Запись экрана                     |
| `Super + Print Screen` | Пипетка для выбора цвета |
| `Super + Ctrl + Print Screen` | Извлечение текста в буфер обмена |
| `Super + Alt + [` | Уменьшить оверлей веб-камеры во время записи |
| `Super + Alt + ]` | Увеличить оверлей веб-камеры во время записи |
| `Alt + Shift + L` | Скопировать текущий URL из веб-приложения или Chromium |
| `Alt + Shift + D` | Скачать видео с текущей страницы в `~/Videos` |
| `Super + Ctrl + X` | Запустить/остановить диктовку (требуется _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | Диктовка в режиме «нажми и говори» (требуется Voxtype или Superwhisper) |

При записи экрана горячая клавиша сначала спрашивает, какой звук вы хотите, а затем начинает запись. Нажмите её ещё раз, чтобы остановить. Подробности см. в разделе [скриншоты и запись экрана](12-screenshots-recording.md).

Все варианты захвата также доступны в разделе _Trigger > Capture_ в меню Omarchy (`Super + Space`).

## Tmux

Префиксная клавиша — `Ctrl + Space` (также работает `Ctrl + B`). Эти привязки можно изменить в `~/.config/tmux/tmux.conf`.

### Панели

| Горячая клавиша                  | Функция              |
| ----------------------- | --------------------- |
| `Prefix + v` | Разделить панель рядом (по вертикали) |
| `Prefix + h` | Разделить панель снизу (по горизонтали) |
| `Prefix + x` | Закрыть панель |
| `Prefix + z` | Переключить масштаб панели (на весь экран) |
| `Alt + Enter` | Разделить панель снизу (без префикса) |
| `Alt + Shift + Enter` | Разделить панель рядом (без префикса) |
| `Alt + Escape` | Закрыть панель (без префикса) |
| `Ctrl + Alt + Arrows` | Перемещаться между панелями |
| `Ctrl + Alt + Shift + Arrows` | Изменять размер панелей |

### Окна
