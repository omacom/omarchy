# Горячие клавиши

Все основные привязки клавиш можно посмотреть с помощью `Super + K` (привязки Tmux — с помощью `Super + Alt + K`, а привязки Herdr — с помощью `Super + Ctrl + K`).

## Навигация

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + Space`           | Меню Omarchy (приложения и всё остальное)    |
| `Super + Alt + Space` | Сетка приложений |
| `Super + Escape` | Системное меню (сон, перезагрузка и т. д.)  |
| `Super + Ctrl + L` | Заблокировать компьютер |
| `Super + W` or `Super + Q` | Закрыть окно             |
| `Ctrl + Alt + Del` | Закрыть все окна |
| `Super + T`               | Переключить окно между тайлингом и плавающим режимом             |
| `Super + J` | Переключить положение окна (горизонтальное/вертикальное) |
| `Super + O`               | Переключить окно в режим sticky'n'floating |
| `Super + L`               | Переключаться по кругу между раскладками dwindle, scrolling и floating |
| `Super + Alt + L`         | Переключаться по кругу между раскладками в обратном порядке |
| `Super + P`               | Переключить стиль псевдоокна (natural против stretch) |
| `Super + F`                 | Во весь экран              |
| `Super + Alt + F`                 | Во всю ширину              |
| `Super + Ctrl + F`                 | Во весь экран внутри окна              |

| `Super + Tab` | Перейти к следующему рабочему пространству на сфокусированном мониторе |
| `Super + Shift + Tab` | Перейти к предыдущему рабочему пространству на сфокусированном мониторе |

| `Super + Alt + S` | Переместить окно в полный scratchpad |
| `Super + Grave` | Переключить консоль Quake |
| `Super + Shift + Grave` | Переместить окно в консоль Quake |

| `Super + Shift + Alt + Arrows` | Переместить рабочее пространство на монитор в этом направлении |

| `Super + Minus` | Расширить окно влево |
| `Super + Equal` | Сжать окно влево |
| `Super + Shift + Minus` | Сжать окно вверх |
| `Super + Shift + Equal` | Расширить окно вниз |
| `Super + Alt + Minus/Equal` | То же изменение размера меньшими шагами |
| `Super + Ctrl + Minus/Equal` | То же изменение размера большими шагами |
| `Super + Alt + Home` | Сохранить ширину окна |
| `Super + Home` | Восстановить сохранённую ширину окна |
| `Super + Left Mouse` | Перетаскивать окно |

| `Super + Scroll Wheel` | Прокручивать рабочие пространства на сфокусированном мониторе |
| `Super + G`               | Переключить группировку окон      |
| `Super + Alt + G`               | Вывести окно из группировки      |
| `Super + Alt + Tab`               | Переключаться по кругу между окнами в группировке      |
| `Super + Alt + Shift + Tab`               | Переключаться назад по кругу между окнами в группировке      |
| `Super + Alt + Scroll Wheel` | Переключаться по кругу между окнами в группировке |
| `Super + Alt + 1/2/3/4/5`               | Перейти к конкретному окну в группировке      |
| `Super + Alt + Arrow`  | Переместить окно в группировку в направлении стрелки, включая окно на мониторе с той стороны |
| `Super + Ctrl + Left/Right`  | Перемещаться между окнами внутри тайлинговой группы |
| `Super + Ctrl + Z` | Увеличить масштаб экрана (повторить для ещё большего увеличения) |
| `Super + Ctrl + Alt + Z` | Полностью уменьшить масштаб экрана |
| `Super + /` | Шаг вперёд по вариантам масштабирования монитора |
| `Super + Alt + /` | Шаг назад по вариантам масштабирования монитора |
| `Alt + Tab` | Переключаться вперёд по кругу между окнами на активном рабочем пространстве |
| `Alt + Shift + Tab` | Переключаться назад по кругу между окнами на активном рабочем пространстве |
| `Ctrl + Alt + Tab`| Переключать фокус вперёд по кругу между мониторами |
| `Ctrl + Alt + Shift + Tab`| Переключать фокус назад по кругу между мониторами |

## Универсальный буфер обмена

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + C`           | Копировать    |
| `Super + X`           | Вырезать (не в терминале)    |
| `Super + V`           | Вставить    |
| `Super + Ctrl + V`           | Менеджер буфера обмена    |

Обычно в Linux нужно использовать `Ctrl + Shift + C/V` для копирования и вставки в терминале и `Ctrl + C/V` для этого везде в остальных местах. Эти унифицированные горячие клавиши буфера обмена Omarchy работают везде.

## Захват

| Hotkey              | Function                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Скриншот                      |
| `Super + Ctrl + Alt + C`            | Скриншот (тот же снимок, для клавиатур без клавиши Print Screen) |
| `Super + Ctrl + C` | Меню захвата |
| `Alt + Print Screen`            | Запись экрана                     |
| `Super + Print Screen` | Пипетка для выбора цвета |
| `Super + Ctrl + Print Screen` | Извлечение текста в буфер обмена |
| `Super + Alt + [` | Уменьшить оверлей веб-камеры во время записи |
| `Super + Alt + ]` | Увеличить оверлей веб-камеры во время записи |
| `Alt + Shift + L` | Скопировать текущий URL из веб-приложения или Chromium |
| `Alt + Shift + D` | Скачать видео на текущей странице в `~/Videos` |
| `Super + Ctrl + X` | Запустить/остановить диктовку (требуется _Setup > Defaults > Dictation_) |

При записи экрана горячая клавиша сначала спрашивает, какой звук вы хотите, затем начинает запись. Нажмите её ещё раз, чтобы остановить. Подробности см. в [скриншоты и запись](12-screenshots-recording.md).

Все варианты захвата также доступны в разделе _Trigger > Capture_ в меню Omarchy (`Super + Space`).

## Tmux

Префиксная клавиша — `Ctrl + Space` (`Ctrl + B` тоже работает). Изменить эти привязки можно в `~/.config/tmux/tmux.conf`.

### Панели

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + v` | Разделить панель сбоку (вертикально) |
| `Prefix + h` | Разделить панель снизу (горизонтально) |
| `Prefix + x` | Закрыть панель |
| `Prefix + z` | Переключить масштаб панели (во весь экран) |
| `Alt + Enter` | Разделить панель снизу (без префикса) |
| `Alt + Shift + Enter` | Разделить панель сбоку (без префикса) |
| `Alt + Escape` | Закрыть панель (без префикса) |
| `Ctrl + Alt + Arrows` | Перемещаться между панелями |
| `Ctrl + Alt + Shift + Arrows` | Изменять размер панелей |
