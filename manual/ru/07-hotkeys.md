# Горячие клавиши

Все основные сочетания клавиш можно посмотреть с помощью `Super + K` (сочетания Tmux — с помощью `Super + Alt + K`, а сочетания Herdr — с помощью `Super + Ctrl + K`).

## Как устроены горячие клавиши

Каждая горячая клавиша находится на плоскости, которую задают её модификаторы, и у каждой плоскости одна задача. Именно поэтому горячие клавиши не сливаются друг с другом, и обычно можно догадаться, где что находится.

| Plane | What lives there | Examples |
| --- | --- | --- |
| `Super + key` | Система: окна, рабочие пространства, раскладки и основные меню | `Super + Space` меню Omarchy, `Super + W` закрыть окно, `Super + F` на весь экран |
| `Super + Shift + key` | Приложения | `Super + Shift + B` браузер, `Super + Shift + E` электронная почта, `Super + Shift + N` редактор |
| `Super + Ctrl + key` | Панели и системные меню | `Super + Ctrl + A` аудио, `Super + Ctrl + N` сеть, `Super + Ctrl + C` меню захвата |
| `Super + Ctrl + Alt + key` | Быстрые действия и уведомления | `Super + Ctrl + Alt + T` показать время, `Super + Ctrl + Alt + B` батарея, `Super + Ctrl + Alt + C` скриншот |

Добавление `Alt` к горячей клавише даёт вариант того же самого, а не что-то несвязанное:

- `Super + Shift + B` открывает браузер; `Super + Shift + Alt + B` открывает приватное окно
- `Super + Shift + E` открывает электронную почту; `Super + Shift + Alt + E` начинает новое письмо
- `Super + F` переходит на весь экран; `Super + Alt + F` переходит на всю ширину
- `Super + Ctrl + C` открывает меню захвата; `Super + Ctrl + Alt + C` пропускает меню и делает скриншот

При добавлении горячей клавиши:

1. Выберите плоскость по тому, что она делает, затем выберите клавишу.
2. Не перемещайте существующую горячую клавишу, чтобы освободить место. Найдите свободную клавишу на нужной плоскости.
3. Используйте `Alt` только для варианта горячей клавиши без него.

Несколько горячих клавиш нарушают эти правила, потому что так удобно. `Shift` со стрелкой или `Tab` перемещает или обращает направление, а не открывает приложение, а `Print`, мультимедийные клавиши, `Alt + Tab` и `Ctrl + Alt + Del` работают так же, как везде. Это исключения, а не образцы для подражания.

Если значение по умолчанию вам не подходит (скажем, вы хотите `Super + Shift + S` для скриншотов, как в Windows), переназначьте его в `~/.config/hypr/bindings.lua`.

| `Alt + Tab` | Циклически переключать вперёд окна на активном рабочем пространстве |
| `Alt + Shift + Tab` | Циклически переключать назад окна на активном рабочем пространстве |

| `Ctrl + Alt + Shift + Tab`| Циклически переключать фокус назад по мониторам |

Сочетания для изменения размера используют физические клавиши `code:20` и `code:21` (XKB `<AE11>` и `<AE12>`), независимо от символов, напечатанных на клавиатуре. На клавиатурах США эти клавиши — `-` и `=`; на японских (JIS) клавиатурах это `-` и `^`; на испанских клавиатурах это `'` и `¡`. На JIS `Super + ^` — это `Super + Equal`, а `Super + Shift + -` (которое вводит `=`) — это `Super + Shift + Minus`.
