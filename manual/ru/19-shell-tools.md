# Инструменты оболочки

В дополнение к стандартным инструментам Linux Omarchy также поставляется с набором улучшенных инструментов оболочки. Вот ключевые из них.

## fzf

[fzf](https://junegunn.github.io/fzf/) даёт вам нечёткий поиск файлов через alias `ff`. Перейдите в любой каталог, введите `ff`, и вы сможете нечётким поиском добраться до любого файла в этом дереве, видя справа предпросмотр файлов, к которым сужается поиск.

Сочетание `Ctrl + R` позволяет использовать fzf для нечёткого поиска по истории команд.

Этот инструмент также используется в Neovim, когда вы вводите `Space Space`.

Полное руководство можно найти через `man fzf`.

## Zoxide

[Zoxide](https://github.com/ajeetdsouza/zoxide) — это замена для cd. Он запоминает каталоги, в которых вы уже были, чтобы в следующий раз было легче в них перейти. Допустим, вы один раз выполнили `cd ~/.config/omarchy`. В следующий раз можно просто выполнить `cd omarchy` (или даже просто `cd oma`), и Zoxide сразу перенесёт вас туда.

Полное руководство можно найти через `man zoxide`.

## ripgrep

[ripgrep](https://github.com/BurntSushi/ripgrep) ищет по содержимому файлов с помощью `rg <pattern> <path>`, например `rg Controller app/`, чтобы найти все упоминания `Controller` в каталоге app.

Этот инструмент также используется в Neovim, когда вы вводите `Space S G`.

Полное руководство можно найти через `man rg`.

## eza

[eza](https://eza.rocks/) — это замена для ls. Он даёт списки каталогов с большей информацией, цветом и значками. По умолчанию eza назначен как alias для ls. Также можно использовать `lt`, чтобы получить список с двумя уровнями вложенности. `lsa` даёт список, включающий скрытые файлы. А `lta` — вложенный список со скрытыми файлами.

Полное руководство можно найти через `man eza`.

## fd

[fd](https://github.com/sharkdp/fd) — это более простая в использовании замена для `find`. Используйте `fd person.rb`, чтобы найти файл с именем `person.rb` в текущем дереве. `fd person.rb /` будет искать по всей файловой системе. `fd person.rb / -H` ищет по всей файловой системе, включая скрытые каталоги.

Полное руководство можно найти через `man fd`.

## bat

[bat](https://github.com/sharkdp/bat) — это `cat` с подсветкой синтаксиса, номерами строк и постраничным выводом. Выполните `bat somefile.rb`, и вы поймёте, почему трудно вернуться назад. Он также незаметно работает на вас в других местах: именно он раскрашивает ваши man-страницы и отображает предпросмотры в `ff`.

Полное руководство можно найти через `man bat`.

## tldr

[tldr](https://tldr.sh/) — это противоядие от man-страниц, которые открываются тремя экранами истории, прежде чем показать хоть один пример. `tldr tar` даёт вам горстку вызовов, которые вы на самом деле и хотели.

## yt-dlp

[yt-dlp](https://github.com/yt-dlp/yt-dlp) скачивает видео с YouTube и сотен других сайтов. `yt-dlp <url>` забирает лучшее доступное качество в текущий каталог.

Полное руководство можно найти через `man yt-dlp`.

## try

[try](https://github.com/tobi/try) упрощает управление программными экспериментами с каталогами, помеченными датой. Все эксперименты живут в `~/Work/tries`, и доступ к ним можно получить через `try`.

Omarchy не добавляет каталог `bin/` проекта в `PATH` автоматически. Запускайте доверенные локальные инструменты проекта с явным относительным путём, например `bin/rails` или `./bin/dev`.
