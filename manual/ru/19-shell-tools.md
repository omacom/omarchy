# Шелл-тулы

Вдобавок к стандартным линуксовым тулам в Omarchy пачка улучшенных шелл-тулов. Вот ключевые.

## fzf

[fzf](https://junegunn.github.io/fzf/) даёт нечёткий поиск файлов через алиас `ff`. Иди в любой каталог, печатай `ff` — и нечётко ищи путь к любому файлу в том дереве, а справа видишь превью файлов, по которым сужаешься.

Через `Ctrl + R` — нечёткий поиск по истории команд через fzf.

Тулу юзает и Neovim, когда печатаешь `Space Space`.

Полный мануал — через `man fzf`.

## Zoxide

[Zoxide](https://github.com/ajeetdsouza/zoxide) — замена cd. Помнит каталоги, где бывал, — в следующий раз прыгнешь туда легче. Скажем, разок `cd ~/.config/omarchy`. В следующий раз хватит `cd omarchy` (или вообще `cd oma`) — и Zoxide отвезёт прямо туда.

Полный мануал — через `man zoxide`.

## ripgrep

[ripgrep](https://github.com/BurntSushi/ripgrep) ищет по содержимому файлов через `rg <pattern> <path>`: вроде `rg Controller app/` под все упоминания `Controller` в каталоге app.

Тулу юзает и Neovim, когда печатаешь `Space S G`.

Полный мануал — через `man rg`.

## eza

[eza](https://eza.rocks/) — замена ls. Листинги каталогов с большей инфой, цветом и иконками. По умолчанию eza заалиасена как ls. Через `lt` — листинг на два уровня вложенности. `lsa` даст листинг со скрытыми файлами. А `lta` — вложенный листинг со скрытыми.

Полный мануал — через `man eza`.

## fd

[fd](https://github.com/sharkdp/fd) — более удобная замена `find`. `fd person.rb` найдёт файл person.rb в текущем дереве. `fd person.rb /` обыщет всю файловую систему. `fd person.rb / -H` — всю файловую систему, включая скрытые каталоги.

Полный мануал — через `man fd`.

## bat

[bat](https://github.com/sharkdp/bat) — это `cat` с подсветкой синтаксиса, номерами строк и пейджером. Прогони `bat somefile.rb` — поймёшь, почему назад тяжело. Он ещё тихо работает на тебя в других местах: красит твои man-страницы и рендерит превью в `ff`.

Полный мануал — через `man bat`.

## tldr

[tldr](https://tldr.sh/) — антидот man-страницам, которые открываются тремя экранами истории, прежде чем показать один пример. `tldr tar` даёт горсть примеров вызова, которые реально хотел.

## yt-dlp

[yt-dlp](https://github.com/yt-dlp/yt-dlp) качает видео с YouTube и сотен других сайтов. `yt-dlp <url>` забирает лучшее доступное качество в текущий каталог.

Полный мануал — через `man yt-dlp`.

## try

[try](https://github.com/tobi/try) упрощает рулёжку программистскими экспериментами по каталогам с датами. Все эксперименты живут в `~/Work/tries`, доступ через `try`.

Omarchy не добавляет проектный каталог `bin/` в `PATH` автоматом. Гоняй доверенные проектно-локальные тулы явным относительным путём — вроде `bin/rails` или `./bin/dev`.
