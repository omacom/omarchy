# Коммерческие приложения/сервисы

Omarchy в основном ориентирован на предоставление бесплатного программного обеспечения с открытым исходным кодом, но без фанатизма на этот счёт. Иногда лучшим решением оказывается коммерческое предложение, и это совершенно нормально. Вот некоторые из вариантов, для которых мы предоставляем простую установку.

## 1Password

Хранение паролей в менеджере паролей — это лучшая практика. Вдвойне — если вы работаете в команде. И [1password](https://1password.com/) — отличное решение, которое также поставляется с инструментом командной строки для интеграции поиска ключей в скрипты.

Вы запускаете 1Password с помощью `Super + Shift + /`. Если он ещё не установлен, эта горячая клавиша сначала запустит установку (также можно использовать _Установка > Сервис > 1Password_ из меню Omarchy). Установщик также устанавливает инструмент командной строки 1Password и настраивает расширение 1Password для Chrome и Chromium; перезапустите браузер, чтобы загрузить его.

## Bitwarden

[Bitwarden](https://bitwarden.com/) — это альтернатива с открытым исходным кодом в области менеджеров паролей, с бесплатным тарифом, который покрывает большинство личных сценариев использования. Установите его с помощью _Установка > Сервис > Bitwarden_ из меню Omarchy, что также установит инструмент командной строки Bitwarden.

## Spotify

[Spotify](https://spotify.com/) — самый популярный в мире сервис потоковой музыки. Omarchy поставляется с ним как с веб-приложением, которое даёт вам полноценный плеер, медиаклавиши и Spotify Connect, но без офлайн-загрузок. Запускайте его с помощью `Super + Shift + M`.

## Slack

[Slack](https://slack.com/) — это место, где многие команды общаются, как внутри компании, так и с внешними коллегами. Установите его с помощью _Установка > Сервис > Slack_ из меню Omarchy, и он откроется, как только будет готов.

## Notion

[Notion](https://www.notion.com/) — это рабочее пространство для заметок, документов и проектов. Установите его настольное приложение с помощью _Установка > Сервис > Notion_ из меню Omarchy.

## WeChat

[WeChat](https://www.wechat.com/) — это приложение для обмена сообщениями, на котором работает большая часть Китая, для чатов, звонков и поддержания связи со всеми, кто там живёт. Установите официальный Linux-клиент Tencent с помощью _Установка > Сервис > WeChat_ из меню Omarchy, и он откроется, как только будет готов. Он доступен только на компьютерах x86.

## Dropbox

[Dropbox](https://www.dropbox.com/) — отличный способ синхронизировать файлы между машинами, сохраняя при этом резервную копию в облаке. Чтобы настроить его, выберите _Установка > Сервис > Dropbox_ из меню Omarchy. Он добавляет значок Dropbox на панель: нажмите на него, чтобы войти, затем используйте ту же панель, чтобы проверить ваше хранилище и открыть недавно синхронизированные файлы.

## Tailscale

[Tailscale](https://tailscale.com/) — это mesh VPN, благодаря которому получить безопасный доступ ко всем вашим компьютерам и серверам через интернет становится супер просто. Чтобы настроить его, выберите _Установка > Сервис > Tailscale_ из меню Omarchy.

Он получает панель в баре, веб-приложение для консоли администратора и Taildrop для отправки файлов между вашими машинами — см. [работу с сетью](35-networking.md).

## ONCE

[ONCE](https://once.com/) — это линейка программного обеспечения от 37signals, которое вы покупаете один раз и запускаете на своём собственном сервере, например система чата Campfire. Выберите _Установка > Сервис > ONCE_ из меню Omarchy, чтобы установить его, что включит его фоновую службу и перенесёт вас в терминальный интерфейс ONCE, чтобы вы могли продолжить оттуда.

## NordVPN

[NordVPN](https://nordvpn.com/) — это стандартный VPN-сервис, который позволяет вам выпускать ваш трафик из большинства регионов мира. Чтобы настроить его, выберите _Установка > Сервис > NordVPN_ из меню Omarchy. После перезагрузки, которую он попросит выполнить, запустите `nordvpn login` для аутентификации.
