# Фоны

Каждая тема поставляется со своим собственным набором фонов, и вы можете добавить собственные в `~/.config/omarchy/backgrounds/[theme]`. Если вы хотите добавить дополнительное фоновое изображение, скажем, к теме nord, вы просто помещаете файл в `~/.config/omarchy/backgrounds/nord`.

Проще всего сделать это, перейдя в _Install > Style > Background_ в Omarchy Menu. Откроется папка, где хранятся фоны для этой темы. Нажмите `Super + Shift + F`, чтобы открыть ещё один файловый менеджер, найдите свой фон и скопируйте его туда. Теперь он будет включён в список фонов, между которыми можно выбирать с помощью `Super + Ctrl + W`.

Фонами могут быть не только статичные изображения, но и видео. Поместите файл `mp4`, `m4v`, `mov`, `webm`, `mkv` или `avi` в ту же папку, и он появится рядом с изображениями. Видео воспроизводит движок обоев OWE. Он декодирует видео один раз для всех мониторов и выводит его звук через аудиовыход по умолчанию, а также останавливает воспроизведение всякий раз, когда его ничто не может видеть. Видеофоны всё равно потребляют гораздо больше энергии, чем статичные.

Темы могут включать короткое вступление для статичного фона. Для `backgrounds/road.webp` соответствующее видео находится в `backgrounds/intros/road.mp4`. Оно воспроизводится автоматически при загрузке и при переключении на тему с выбранным этим фоном, а затем возвращается к статичному изображению. Вступительные видео не попадают в выбор фонов и никогда не зацикливаются.

Отключение _Appearance > Animations_ также отключает вступления фонов. Omarchy делает это по умолчанию в виртуальной машине. Команда `omarchy theme bg intro toggle` может переключать вступления отдельно. Обновление темы или выбор другого фона в пределах той же темы вступление не воспроизводит.

Огромную коллекцию классных подобранных фонов можно найти в [dharmx/walls](https://github.com/dharmx/walls).

Экран блокировки показывает статичный кадр видеофона, так же как он показывает статичный кадр анимированного GIF.
