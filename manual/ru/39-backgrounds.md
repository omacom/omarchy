# Фоны

Каждая тема поставляется со своим собственным набором фонов, а вы можете добавить дополнительные в `~/.config/omarchy/backgrounds/[theme]`. Если вы хотите добавить дополнительное фоновое изображение, скажем, к теме nord, просто поместите файл в `~/.config/omarchy/backgrounds/nord`.

Проще всего сделать это через _Install > Style > Background_ в Omarchy Menu. Откроется папка, в которой хранятся фоны этой темы. Нажмите `Super + Shift + F`, чтобы открыть ещё один файловый менеджер, найдите свой фон и скопируйте его туда. Теперь он появится среди фонов, между которыми можно переключаться с помощью `Super + Ctrl + W`.

Тема без собственных фонов получает фон, нарисованный из её цветов: логотип Omarchy в акцентном цвете темы на её цвете фона. Добавьте свой собственный, чтобы заменить его.

Фонами могут быть не только неподвижные изображения, но и видео. Поместите файл `mp4`, `m4v`, `mov`, `webm`, `mkv` или `avi` в ту же папку, и он появится рядом с изображениями. Видео воспроизводит движок обоев OWE. Он декодирует видео один раз для всех мониторов, воспроизводит его звук через аудиовыход по умолчанию и останавливает воспроизведение всякий раз, когда его ничто не может видеть. Видеофоны всё равно потребляют гораздо больше энергии, чем неподвижные.

Темы могут включать короткое вступление для неподвижного фона. Для `backgrounds/road.webp` соответствующее видео находится по адресу `backgrounds/intros/road.mp4`. Оно воспроизводится автоматически при загрузке, при переключении на тему с выбранным этим фоном и при выборе этого фона, а затем возвращается неподвижное изображение. Видео вступлений не попадают в средство выбора фона и никогда не зацикливаются.

Выбор _Appearance > Animations Off_ также отключает вступления фонов. Omarchy делает это по умолчанию в виртуальной машине. Команда `omarchy theme bg intro toggle` может переключать вступления отдельно. Обновление темы вступление не воспроизводит.

У неподвижного изображения также может быть зацикленное видео — тихая версия той же картинки, которая продолжает двигаться, — по адресу `backgrounds/loops/road.mp4`. Оно воспроизводится вместо неподвижного изображения, после его вступления, если оно есть, и останавливается при отключении анимаций. При работе от батареи вместо него показывается неподвижное изображение, а зацикленное видео возвращается, как только вы подключите питание. Зацикленные видео не попадают в средство выбора фона.

Огромную коллекцию крутых подобранных фонов можно найти в [dharmx/walls](https://github.com/dharmx/walls).

Экран блокировки показывает неподвижный кадр видеофона, точно так же, как он показывает неподвижный кадр анимированного GIF.
