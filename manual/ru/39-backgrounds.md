# Фоны

Каждая тема поставляется со своим набором фонов, и вы можете добавить собственные в `~/.config/omarchy/backgrounds/[theme]`. Если вы хотите добавить дополнительное фоновое изображение, скажем, к теме nord, просто положите файл в `~/.config/omarchy/backgrounds/nord`.

Проще всего сделать это через _Install > Style > Background_ в Omarchy Menu. Откроется папка, в которой хранятся фоны этой темы. Нажмите `Super + Shift + F`, чтобы запустить ещё один файловый менеджер, найдите свой фон и скопируйте его туда. Теперь он появится среди фонов, между которыми можно переключаться с помощью `Super + Ctrl + W`.

Фонами могут быть как видео, так и статичные изображения. Положите файл `mp4`, `m4v`, `mov`, `webm`, `mkv` или `avi` в ту же папку, и он появится рядом с изображениями. Видео воспроизводит движок обоев OWE. Он декодирует видео один раз для всех мониторов, выводит его звук через аудиовыход по умолчанию и останавливает воспроизведение всякий раз, когда его никто не может видеть. Видеофоны всё равно потребляют гораздо больше энергии, чем статичные.

Темы могут включать короткое интро для статичного фона. Для `backgrounds/road.webp` соответствующее видео находится в `backgrounds/intros/road.mp4`. Оно автоматически воспроизводится при загрузке, при переключении на тему с выбранным этим фоном и при выборе этого фона, а затем возвращается к статичному изображению. Видео интро не попадают в выбор фонов и никогда не зацикливаются.

Отключение _Appearance > Animations_ также отключает интро фонов. Omarchy делает это по умолчанию в виртуальной машине. Команда `omarchy theme bg intro toggle` может переключать интро отдельно. Обновление темы интро не воспроизводит.

Огромную коллекцию крутых, тщательно отобранных фонов вы найдёте в [dharmx/walls](https://github.com/dharmx/walls).

Экран блокировки показывает статичный кадр видеофона — точно так же, как показывает статичный кадр анимированного GIF.
