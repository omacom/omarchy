# Браузеры

Omarchy поставляется с [Google Chrome](https://www.google.com/chrome/) в качестве браузера по умолчанию. Он оформлен под остальную часть вашей системы, и именно он открывается по `Super + Shift + Return` и именно внутри него работает каждое [веб-приложение](25-web-apps.md). Он открывается сразу в окно браузера: нет ни экрана приветствия, ни запроса на вход, статистика использования и отчёты о сбоях не отправляются в Google, а запросы, связанные с конфиденциальностью рекламы, отключены. Вы по-прежнему можете войти в свой аккаунт Google через кнопку профиля, когда захотите синхронизацию.

Если Chrome не в вашем вкусе, вы не обречены на него. В меню Omarchy в разделе _Install > Browser_ вы найдёте [Chromium](https://www.chromium.org/) (обычную сборку с открытым исходным кодом, из которой сделан Chrome), Edge, Brave, Brave Origin, Firefox и [Zen](https://zen-browser.app/). Выберите один, и Omarchy установит его, настроит его каталог политик и применит к нему вашу текущую тему.

## Как сделать один из них браузером по умолчанию

Установка браузера не делает его браузером по умолчанию. Когда он уже есть на машине, перейдите в _Setup > Defaults > Browser_ и выберите его — меню показывает только те браузеры, которые у вас действительно установлены, и отмечает текущий браузер по умолчанию галочкой.

Из терминала это делается так:

```bash
omarchy default browser firefox
```

Запустите её без аргументов, и она покажет текущий браузер по умолчанию. Это задаёт обработчик XDG, так что этому следуют не только горячие клавиши Omarchy — всё, что открывает ссылку, от приложения для чатов до команды в терминале, переходит в выбранный вами браузер.

## Copy URL и Download Video

Браузеры семейства Chromium (сам Chromium, Chrome, Edge и Brave) поставляются с двумя расширениями Omarchy, которые выходят за пределы браузера в остальную часть вашей системы.

**Copy URL** помещает адрес текущей вкладки в ваш буфер обмена с помощью `Alt + Shift + L`. Это быстрее, чем щёлкать в адресную строку и копировать, и, поскольку это проходит через системный буфер обмена, а не через буфер браузера, вы получаете подтверждение уведомлением Omarchy, а URL сразу же становится доступен в [истории буфера обмена](08-unified-clipboard-history.md) и в каждом другом приложении. Есть и кнопка на панели инструментов, если вы предпочитаете щёлкать.

**Download Video** захватывает видео, которое воспроизводится на просматриваемой вами странице, с помощью `Alt + Shift + D`. Оно передаёт URL в [yt-dlp](https://github.com/yt-dlp/yt-dlp), поэтому работает далеко не только на YouTube, а загрузка попадает в `~/Videos`. Ход выполнения показывается в том же экранном индикаторе, который используют громкость и яркость, обновляясь на месте, а не накапливая уведомления. Установите `OMARCHY_YTDLP_DIR`, если хотите, чтобы файлы попадали в другое место, — см. [FAQ](46-faq.md), чтобы узнать, куда помещать переменные окружения.

Оба расширения общаются с Omarchy через небольшой нативный хост обмена сообщениями, который устанавливается для вас вместе с браузером. Именно этот компонент позволяет видео с веб-страницы оказаться в вашем домашнем каталоге, а URL — в вашем менеджере буфера обмена, чего обычное расширение само по себе сделать не может.

Они доступны только для семейства Chromium. Firefox и Zen их не получают.

## Firefox и Zen

Firefox и Zen — это другое семейство, поэтому к ним применяется другой подход: Omarchy устанавливает файл политик с разумными настройками по умолчанию и переключает их в нативный режим Wayland, который вам нужен для дробного масштабирования и плавной прокрутки на тачпаде.

Они не получают описанные выше расширения для Chromium, и Omarchy не применяет к ним тему, так что эти части опыта вам придётся настраивать самостоятельно.

## Как снова удалить один из них

Любой из этих браузеров, включая Chrome, можно снова удалить в разделе _Remove > Browser_. После этого ссылки будут переходить в Chrome или Chromium, если другой из них всё ещё установлен.
