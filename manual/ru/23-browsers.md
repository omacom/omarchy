# Браузеры

Omarchy поставляется с [Google Chrome](https://www.google.com/chrome/) в качестве браузера по умолчанию. Он оформлен под остальную систему, и именно его открывает `Super + Shift + Return` (или `Super + Shift + B`), а `Super + Shift + Alt + B` — приватное окно, и именно внутри него работает каждое [веб-приложение](25-web-apps.md). Он открывается сразу в окно браузера: никакого экрана приветствия или предложения войти, статистика использования и отчёты о сбоях не отправляются в Google, а запросы о конфиденциальности рекламы отключены. Вы по-прежнему можете войти в свой аккаунт Google через кнопку профиля, когда захотите синхронизацию.

Если Chrome вам не по вкусу, вы к нему не привязаны. В меню Omarchy в разделе _Install > Browser_ вы найдёте [Chromium](https://www.chromium.org/) (обычную сборку с открытым исходным кодом, из которой сделан Chrome), Edge, Brave, Brave Origin, Firefox и [Zen](https://zen-browser.app/) (Edge — только на машинах x86). Выберите один, и Omarchy установит его, настроит его каталог политик и применит к нему вашу текущую тему.

## Как сделать один из них браузером по умолчанию

Установка браузера не делает его браузером по умолчанию. Чтобы переключиться, перейдите в _Setup > Defaults > Browser_ и выберите нужный. Текущий браузер по умолчанию отмечен галочкой, а выбор браузера, которого у вас ещё нет, сначала установит его.

Из терминала это делается так:

```bash
omarchy default browser firefox
```

Запустите команду без аргумента, и она покажет текущий браузер по умолчанию. Это устанавливает обработчик XDG, так что следом меняются не только горячие клавиши Omarchy — всё, что открывает ссылку, от приложения чата до команды в терминале, переходит в выбранный вами браузер.

## Copy URL и Download Video

Браузеры семейства Chromium (сам Chromium, Chrome, Edge, Brave и Brave Origin) поставляются с тремя расширениями Omarchy: два из них выходят за пределы браузера в остальную систему, а одно наводит порядок в WhatsApp.

**Copy URL** помещает адрес текущей вкладки в буфер обмена с помощью `Alt + Shift + L`. Это быстрее, чем щёлкать по адресной строке и копировать, а поскольку это проходит через системный буфер обмена, а не через буфер браузера, вы получаете подтверждение уведомлением Omarchy, и URL сразу становится доступен в [истории буфера обмена](08-unified-clipboard-history.md) и в каждом другом приложении. Есть и кнопка на панели инструментов, если вы предпочитаете щёлкать мышью.

**Download Video** захватывает видео, воспроизводящееся на странице, которую вы смотрите, с помощью `Alt + Shift + D`. Оно передаёт URL в [yt-dlp](https://github.com/yt-dlp/yt-dlp), поэтому работает далеко не только с YouTube, а скачанный файл попадает в `~/Videos`. Ход выполнения отображается в том же экранном индикаторе, который используют громкость и яркость, обновляясь на месте, а не накапливая уведомления. Установите `OMARCHY_YTDLP_DIR`, если хотите, чтобы файлы попадали в другое место, — см. [FAQ](46-faq.md) о том, куда помещать переменные окружения.

Оба расширения общаются с Omarchy через небольшой хост native messaging, который устанавливается для вас вместе с браузером. Именно эта часть позволяет видео с веб-страницы оказаться в вашем домашнем каталоге, а URL — в вашем менеджере буфера обмена, что обычное расширение само по себе сделать не может.

**WhatsApp Slim** заставляет WhatsApp Web следовать вашей системной теме и сворачивает список чатов, когда окно узкое.

Они доступны только для семейства Chromium. Firefox и Zen их не получают.

## Firefox и Zen

Firefox и Zen принадлежат к другому семейству, поэтому с ними обращаются иначе: Omarchy устанавливает файл политик с разумными настройками по умолчанию и переключает их в нативный режим Wayland, который нужен вам для дробного масштабирования и плавной прокрутки на тачпаде.

Они не получают описанные выше расширения Chromium и не оформляются Omarchy, так что эти части опыта вам предстоит настроить самостоятельно.

## Как снова удалить один из них

Любой из этих браузеров, включая Chrome, можно снова убрать в разделе _Remove > Browser_. Тогда ссылки будут переходить в Chrome или Chromium, если другой из них всё ещё установлен.
