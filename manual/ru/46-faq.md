# Частые вопросы

### Как переключаться между раскладками клавиатуры?

Отредактируйте файл `~/.config/hypr/input.lua` и добавьте это, чтобы переключаться между раскладками сочетанием `Left Alt + Right Alt`:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

Панель будет автоматически показывать текущую раскладку клавиатуры, как только у вас будет настроено несколько раскладок (и по ней тоже можно щёлкать для переключения).

### Как изменить формат часов на 12-часовой?

Щёлкните правой кнопкой по часам в панели, чтобы перебирать распространённые форматы, включая 12-часовые. Формат можно задать и напрямую:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

Это покажет Sunday 10:55 AM.

### Как изменить часовой пояс?

Запустите _Обновление > Часовой пояс_ в меню Omarchy и выберите из списка. Если часовой пояс правильный, но сами часы ушли, _Обновление > Время_ перезапустит синхронизацию времени за вас.

### Как изменить DNS, поделиться Wi-Fi или проверить скорость соединения?

Всё это находится в разделе [сеть](35-networking.md).

### Как проверить, насколько быстр мой диск?

_Действия > Тест скорости > Тест скорости диска_ измеряет текущую скорость чтения и записи на вашем диске, или `omarchy disk speedtest` в терминале.

### Почему я не могу войти в свой аккаунт Google в Chromium?

Обычная сборка Chromium с открытым исходным кодом не поставляется с учётными данными OAuth, которые Google требует для входа в аккаунт. Запустите _Установить > Служба > Аккаунт Chromium_ в меню Omarchy, чтобы добавить их, перезапустите браузер, и вход пройдёт.

### Как добавить принтер?

Печать настроена и работает из коробки, а каждый принтер вы добавляете сами через _Параметры печати_ в панели запуска приложений (`Super + Space`).

Выберите _Добавить_ и дайте системе немного времени на поиск: принтер, подключённый по USB, и большинство сетевых принтеров будут найдены за вас. Если вашего принтера нет в списке, выберите _Сетевой принтер > Internet Printing Protocol (ipp)_ и введите его адрес — собственный дисплей принтера или его веб-страница подскажут, какой он, обычно что-то вроде `192.168.1.50` с очередью `ipp/print`. _Вперёд_ затем предложит драйвер, где современный принтер лучше всего работает на бездрайверном профиле _IPP Everywhere_, а более старшему нужен собственный драйвер модели.

Щёлкните правой кнопкой по принтеру и выберите _Задать по умолчанию_, чтобы выбрать, к какому принтеру ваши приложения обращаются первым, и _Свойства_, чтобы задать размер бумаги, двустороннюю печать и качество.

Автоматическое обнаружение, при котором принтеры в сети появляются без добавления, временно отключено на время переработки, поэтому первый шаг выше — ваш, а не автоматический. Печать в PDF-файл работает вообще без принтера.

### Как изменить место сохранения скриншотов или записей экрана?

Сохранённые скриншоты по умолчанию попадают в `~/Pictures/Screenshots`. Чтобы использовать другой каталог, добавьте это в файл в `~/.config/uwsm/env.d/` (например, `~/.config/uwsm/env.d/capture`):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

То же можно сделать для записей экрана с помощью `OMARCHY_SCREENRECORD_DIR`.

Omasnap создаёт свой каталог скриншотов автоматически. Каталог записей экрана создайте сами, а затем перезапустите Omarchy, чтобы любое из изменений окружения вступило в силу.

### Как заставить работать колонки и веб-камеру на моём Apple Studio Display?

Казалось бы, всё должно работать просто при подключении USB C, но, к сожалению, это не так. Решение, которое я нашёл надёжным, — использовать [кабель WJESOG DisplayPort + USB-A => USB-C](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/). Тогда колонки и веб-камера работают как по волшебству.

Помните, что в Omarchy есть встроенное управление яркостью для дисплеев Apple (и Studio, и XDR) обычными кнопками яркости на клавиатуре.

### Как избавиться от всего лишнего ПО?

Если вы не хотите программы вроде Obsidian или LibreOffice или другое предустановленное, вы можете очень легко их удалить.

Запустите _Удалить > Пакет_, чтобы увидеть каждый установленный пакет. Затем вы можете выбрать клавишей Tab любой пакет, который хотите удалить, и начать удаление всего выбранного клавишей Return.

А через _Удалить > Веб-приложение_ в меню Omarchy можно удалить любое из предустановленных веб-приложений, которые вам не нужны.

Или запустите _Удалить > Предустановленное_, чтобы одним махом вымести все предустановленные дополнения — веб-приложения, TUI и необязательные приложения. Сочетания клавиш, запускавшие их, уйдут вместе с ними, и у вас останется чистый лист привязок, который можно заполнить своими в `~/.config/hypr/bindings.lua`.
