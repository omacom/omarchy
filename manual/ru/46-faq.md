# Частые вопросы

### Как переключаться между раскладками клавиатуры?

Отредактируйте файл `~/.config/hypr/input.lua` и добавьте туда это, чтобы переключаться между раскладками по `Left Alt + Right Alt`:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

Панель автоматически покажет вашу текущую раскладку клавиатуры, как только у вас будет настроено несколько раскладок (и по ней тоже можно кликнуть, чтобы переключиться).

### Как изменить формат часов на 12-часовой?

Кликните правой кнопкой мыши по часам на панели, чтобы циклически переключаться между распространёнными форматами, включая 12-часовые. Формат также можно задать напрямую:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

Это будет отображаться как воскресенье 10:55 AM.

### Как изменить мой часовой пояс?

Запустите _Setup > Region > Timezone_ в меню Omarchy и выберите из списка. Если часовой пояс правильный, но сами часы сбились, _Update > Time_ перезапустит синхронизацию времени за вас.

### Как изменить мой DNS, поделиться моим Wi-Fi или проверить скорость моего соединения?

Всё это живёт в [разделе о сети](35-networking.md).

### Как проверить, насколько быстрый мой диск?

_Trigger > Speed Test > Disk Speed Test_ измеряет текущую скорость чтения и записи на вашем диске, или `omarchy disk speedtest` из терминала.

### Как добавить принтер?

Печать настроена и работает из коробки, а каждый принтер вы добавляете сами из _Print Settings_ в лаунчере приложений (`Super + Alt + Space`).

Выберите _Add_ и дайте ему немного времени на поиск: принтер, подключённый по USB, и большинство сетевых принтеров найдутся за вас. Если вашего нет в списке, выберите _Network Printer > Internet Printing Protocol (ipp)_ и введите его адрес — собственный дисплей принтера или его веб-страница подскажут вам, что это такое, обычно что-то вроде `192.168.1.50` с очередью `ipp/print`. Затем _Forward_ предложит драйвер, где современный принтер лучше всего работает на бездрайверном профиле _IPP Everywhere_, а старый хочет собственный драйвер модели.

Кликните правой кнопкой мыши по принтеру и выберите _Set as Default_, чтобы указать, к какому принтеру ваши приложения должны обращаться в первую очередь, и _Properties_, чтобы задать размер бумаги, двустороннюю печать и качество.

Автоматическое обнаружение, когда принтеры в сети появляются без добавления, временно отключено, пока его переделывают, поэтому первый шаг выше — ваш, а не автоматический. Печать в PDF-файл работает вообще без всякого принтера.

### Как изменить, куда сохраняются скриншоты или записи экрана?

Сохранённые скриншоты по умолчанию попадают в `~/Pictures/Screenshots`. Чтобы использовать другой каталог, добавьте это в файл внутри `~/.config/uwsm/env.d/` (например, `~/.config/uwsm/env.d/capture`):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

То же самое можно сделать для записей экрана с помощью `OMARCHY_SCREENRECORD_DIR`.

Omasnap создаёт свой каталог для скриншотов автоматически. Каталог для записей экрана создайте сами, затем перезапустите Omarchy, чтобы любое из изменений окружения вступило в силу.

### Как заставить работать динамики + веб-камеру на моём Apple Studio Display?

Казалось бы, всё должно работать просто при подключении по USB C, но, к сожалению, это не так. Решение, которое я нашёл, чтобы всё работало надёжно, — использовать [кабель WJESOG DisplayPort + USB-A => USB-C](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/). Тогда динамики и веб-камера работают как по волшебству.

Помните, что в Omarchy у вас есть встроенное управление яркостью для дисплеев Apple (и Studio, и XDR) с помощью обычных клавиатурных кнопок яркости.

### Как избавиться от всего лишнего программного обеспечения?

Если вам не нужны программы вроде Obsidian или LibreOffice или любое другое предустановленное добро, вы можете очень легко его удалить.

Запустите _Remove > Package_, чтобы увидеть каждый установленный пакет. Затем вы можете выбрать любой пакет, который хотите удалить, клавишей tab и начать удалять всё выбранное клавишей return.

И вы можете использовать _Remove > Web App_ из меню Omarchy, чтобы удалить любые предустановленные веб-приложения, которые вам не нужны.

Или запустите _Remove > Preinstalls_, чтобы вымести все предустановленные дополнения — веб-приложения, TUI и необязательные приложения — одним махом. Горячие клавиши, которые их запускали, уйдут вместе с ними, так что у вас останется чистый лист привязок, который можно заполнить своими в `~/.config/hypr/bindings.lua`.
