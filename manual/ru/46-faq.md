# Часто задаваемые вопросы

### Как переключаться между раскладками клавиатуры?

Отредактируйте файл `~/.config/hypr/input.lua` и добавьте это, чтобы переключаться между раскладками по `Left Alt + Right Alt`:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

Панель автоматически покажет текущую раскладку клавиатуры, как только у вас будет настроено несколько раскладок (и по ней тоже можно щёлкнуть, чтобы переключиться).

### Как изменить формат часов на 12-часовой?

Щёлкните правой кнопкой мыши по часам в панели, чтобы перебирать распространённые форматы, включая 12-часовые. Формат также можно задать напрямую:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

Будет отображаться воскресенье 10:55 AM.

### Как изменить часовой пояс?

Запустите _Update > Timezone_ в меню Omarchy и выберите из списка. Если часовой пояс правильный, но сами часы сбились, _Update > Time_ перезапустит синхронизацию времени за вас.

### Как изменить DNS, поделиться Wi-Fi или проверить скорость соединения?

Всё это находится в [работе с сетью](35-networking.md).

### Как проверить, насколько быстрый мой диск?

_Trigger > Speed Test > Disk Speed Test_ измеряет актуальную скорость чтения и записи на вашем диске, или `omarchy disk speedtest` из терминала.

### Как добавить принтер?

Печать настроена и работает из коробки, а каждый принтер вы добавляете сами из _Print Settings_ в средстве запуска приложений (`Super + Space`).

Выберите _Add_ и дайте ему немного времени на поиск: принтер, подключённый по USB, и большинство сетевых принтеров будут найдены за вас. Если вашего нет в списке, выберите _Network Printer > Internet Printing Protocol (ipp)_ и введите его адрес — собственный экран принтера или его веб-страница подскажет, что это такое, обычно что-то вроде `192.168.1.50` с очередью `ipp/print`. Затем _Forward_ предложит драйвер, где современный принтер лучше всего работает на бездрайверном профиле _IPP Everywhere_, а для более старого нужен собственный драйвер модели.

Щёлкните принтер правой кнопкой мыши и выберите _Set as Default_, чтобы выбрать тот, к которому ваши приложения будут обращаться в первую очередь, и _Properties_, чтобы задать размер бумаги, двустороннюю печать и качество.

Автоматическое обнаружение, при котором принтеры в сети появляются без добавления, временно отключено, пока его переделывают, поэтому первый шаг выше — за вами, а не автоматический. Печать в PDF-файл работает вообще без принтера.

### Как изменить место сохранения скриншотов или записей экрана?

Сохранённые скриншоты по умолчанию отправляются в `~/Pictures/Screenshots`. Чтобы использовать другой каталог, добавьте это в файл в `~/.config/uwsm/env.d/` (например, `~/.config/uwsm/env.d/capture`):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

То же самое можно сделать для записей экрана с помощью `OMARCHY_SCREENRECORD_DIR`.

Omasnap создаёт каталог для скриншотов автоматически. Каталог для записей экрана создайте сами, затем перезапустите Omarchy, чтобы каждое из изменений окружения вступило в силу.

### Как заставить работать динамики и веб-камеру на моём Apple Studio Display?

Казалось бы, всё должно работать просто при подключении по USB C, но, к сожалению, это не так. Решение, которое я нашёл, чтобы заставить всё работать надёжно, — использовать [кабель WJESOG DisplayPort + USB-A => USB-C](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/). Тогда динамики и веб-камера работают как по волшебству.

Помните, что в Omarchy есть встроенное управление яркостью для дисплеев Apple (и Studio, и XDR) с помощью обычных кнопок яркости на клавиатуре.

### Как избавиться от всего лишнего программного обеспечения?

Если вам не нужны такие программы, как Obsidian или LibreOffice, или что-либо ещё из предустановленного, вы можете очень легко это удалить.

Запустите _Remove > Package_, чтобы увидеть все установленные пакеты. Затем можно выбрать с помощью tab любой пакет, который вы хотите удалить, и начать удаление всего выбранного с помощью return.

А с помощью _Remove > Web App_ из меню Omarchy можно удалить любые ненужные вам предустановленные веб-приложения.

Или запустите _Remove > Preinstalls_, чтобы одним махом вычистить все предустановленные дополнения — веб-приложения, TUI и дополнительные приложения. Горячие клавиши, запускавшие их, исчезнут вместе с ними, так что у вас останется чистый лист привязок, который можно заполнить своими в `~/.config/hypr/bindings.lua`.
