# Часто задаваемые вопросы

### Как переключаться между раскладками клавиатуры?

Отредактируйте свой файл `~/.config/hypr/input.lua` и добавьте следующее, чтобы переключаться между раскладками с помощью `Left Alt + Right Alt`:

```
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",
  },
})
```

Панель автоматически покажет вашу текущую раскладку клавиатуры, как только у вас будет настроено несколько раскладок (и вы также можете щёлкнуть по ней, чтобы переключиться).

### Как изменить формат часов на 12-часовой?

Щёлкните правой кнопкой мыши по часам в панели, чтобы переключаться между распространёнными форматами, включая 12-часовые. Вы также можете задать формат напрямую:

```
omarchy bar set omarchy.clock format "dddd h:mm AP"
```

Это будет отображаться как воскресенье 10:55 AM.

### Как изменить мой часовой пояс?

Запустите _Setup > Region > Timezone_ в меню Omarchy и выберите нужный вариант из списка. Если часовой пояс правильный, но сами часы сбились, _Update > Time_ перезапустит для вас синхронизацию времени.

### Как изменить мой DNS, раздать мой Wi-Fi или проверить скорость моего соединения?

Всё это находится в [разделе о сети](35-networking.md).

### Как проверить, насколько быстрый у меня диск?

_Trigger > Speed Test > Disk Speed Test_ измеряет скорость чтения и записи на вашем диске в реальном времени, или `omarchy disk speedtest` из терминала.

### Как добавить принтер?

Печать настроена и работает из коробки, и вы добавляете каждый принтер самостоятельно из _Print Settings_ в программе запуска приложений (`Super + Space`).

Выберите _Add_ и дайте ему время на поиск: принтер, подключённый через USB, и большинство сетевых принтеров будут найдены за вас. Если вашего нет в списке, выберите _Network Printer > Internet Printing Protocol (ipp)_ и введите его адрес — собственный дисплей принтера или его веб-страница подскажут вам, что это за адрес, обычно что-то вроде `192.168.1.50` с очередью `ipp/print`. Затем _Forward_ предложит драйвер, где для современного принтера лучше всего работает бездрайверный профиль _IPP Everywhere_, а для более старого нужна собственный драйвер модели.

Щёлкните правой кнопкой мыши по принтеру и выберите _Set as Default_, чтобы указать, к какому из них ваши приложения должны обращаться в первую очередь, и _Properties_, чтобы задать размер бумаги, двустороннюю печать и качество.

Автоматическое обнаружение, при котором принтеры в сети появляются без добавления, временно отключено, пока оно дорабатывается, поэтому первый шаг выше выполняется вами, а не автоматически. Печать в файл PDF работает вообще без какого-либо принтера.

### Как изменить, куда сохраняются скриншоты или записи экрана?

Сохранённые скриншоты по умолчанию отправляются в `~/Pictures/Screenshots`. Чтобы использовать другой каталог, добавьте следующее в файл в `~/.config/uwsm/env.d/` (например, `~/.config/uwsm/env.d/capture`):

```
export OMASNAP_SCREENSHOT_DIR="$HOME/Pictures/Captures"
```

То же самое можно сделать для записей экрана с помощью `OMARCHY_SCREENRECORD_DIR`.

Omasnap создаёт свой каталог скриншотов автоматически. Создайте каталог для записей экрана самостоятельно, затем перезапустите Omarchy, чтобы любое из изменений окружения вступило в силу.

### Как заставить работать динамики + веб-камеру на моём Apple Studio Display?

Казалось бы, всё должно работать просто при подключении по USB C, но, к сожалению, это не так. Найденное мной решение, чтобы всё работало надёжно, — использовать [кабель WJESOG DisplayPort + USB-A => USB-C](https://www.amazon.com/WJESOG-DisplayPort-Adapter-Converter-Thunderbolt/dp/B0BNX7MS6N/). Тогда динамики и веб-камера работают как часы.

Помните, что в Omarchy у вас есть встроенное управление яркостью для дисплеев Apple (как Studio, так и XDR) с помощью обычных кнопок яркости на клавиатуре.

### Как избавиться от всего лишнего программного обеспечения?

Если вам не нужны такие программы, как Obsidian или LibreOffice, или любая другая предустановленная ерунда, вы можете очень легко её удалить.

Запустите _Remove > Package_, чтобы увидеть все установленные пакеты. Затем вы можете выбрать любой пакет, который хотите удалить, с помощью tab, и начать удалять всё выбранное с помощью return.

А с помощью _Remove > Web App_ из меню Omarchy вы можете удалить любые предустановленные веб-приложения, которые вам не нужны.

Или запустите _Remove > Preinstalls_, чтобы одним махом вымести все предустановленные дополнения — веб-приложения, TUI и необязательные приложения. Горячие клавиши, которые их запускали, исчезнут вместе с ними, так что у вас останется чистый лист привязок, которые можно заполнить своими собственными в `~/.config/hypr/bindings.lua`.
