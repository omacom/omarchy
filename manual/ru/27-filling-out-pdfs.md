# Заполнение PDF

В Omarchy из коробки милый базовый просмотрщик PDF — Document Viewer. Именно он откроет любой PDF по даблклику.

Но в Document Viewer заполняются только PDF, заведённые как формы. Заполнить PDF не-формы или подписать PDF — правый клик по файлу, _Open With..._ и Xournal++.

Xournal++ даст писать где угодно на PDF через тулу T. Подписать документ — понадобится картинка подписи: тула Image вставит подпись и даст ресайзнуть.

Заполнил PDF — Файл - Экспорт в PDF сохранит финал.
