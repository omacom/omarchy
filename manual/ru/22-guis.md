# GUI-приложения

## Files

Files (Nautilus) — графический файловый менеджер. `Super + Shift + F` открывает, а `Super + Shift + Alt + F` открывает в каталоге, где сидит терминал, — куча кликов экономится. `Ctrl + L` даёт напечатать путь, а `Space` на любом файле — быстрый предпросмотр без открытия.

Воткни USB-флешку или SD-карту — примонтится сама, просто покажется в сайдбаре. Для более вовлечённого — отформатировать диск, глянуть SMART-здоровье, нарезать разделы — запускай _Disks_ из лаунчера (`Super + Space`).

Двойной клик ходит по разумным дефолтам: картинки — в imv, видео — в mpv, PDF — в Document Viewer, плейн-текст — в Neovim.

## Obsidian

[Obsidian](https://obsidian.md/) — бесплатное и сильно расширяемое приложение заметок на простых Markdown-файлах.

Obsidian бесплатен под любые цели, включая личные, коммерческие и некоммерческие.

У Obsidian есть ещё [коммерческий аддон под синк](https://obsidian.md/sync) с мобильными приложениями на iOS и Android. (https://obsidian.md/pricing).

Obsidian стартует с `Super + Shift + O`. Чтобы темилась в синхроне — выбери тему `Omarchy` в настройках.

## Omawrite

[Omawrite](https://github.com/omacom-io/omawrite) — собственный простейший Markdown-писатель Omarchy. Ни волтов, ни плагинов — только ты и слова.

Omawrite стартует с `Super + Shift + W`.

## Pinta

[Pinta](https://www.pinta-project.com/) — базовый редактор картинок: хорош под кроп, ресайз и прочие базовые манипуляции. Только альтернативы Фотошопу не жди. Но Волшебная палочка и слои на месте!

Pinta стартует через лаунчер приложений (`Super + Space`).

## Aether

[Aether](https://github.com/bjarneo/aether) — приложение темизации: вытаскивает цвета из фоновой картинки и делает из них полную связную тему. Самый лёгкий путь [сделать свою тему](43-making-your-own-theme.md).

Aether стартует через лаунчер приложений (`Super + Space`).

## LocalSend

[LocalSend](https://localsend.org/) шлёт файлы на другие девайсы в той же сети с приложением — вроде эппловского AirDrop. Но кроссплатформенный — файлы ходят туда-сюда с Windows, macOS, Android, iOS и, конечно, Linux.

Меню шаринга открывается на `Super + Ctrl + S` или в _Действия > Поделиться_ в меню Omarchy. Опций четыре:

- **Clipboard** шлёт скопированное текстовым файлом. Отлично, чтобы закинуть ссылку или сниппет на телефон без мыла себе.
- **File** открывает файликер — выбрать можно сразу несколько.
- **Folder** шлёт целый каталог.
- **Receive** открывает полноценный LocalSend, чтобы другой девайс мог отправить тебе.

То же из терминала: `omarchy share clipboard`, `omarchy share file [path]` и `omarchy share folder [path]`. Путь не дал — получишь пикер.

Отправить через файловый менеджер: правый клик по выделению в Nautilus — _Send via LocalSend_.

Фаервол Omarchy по умолчанию закрыт, кроме порта LocalSend, — на свежей установке работает из коробки. См. [безопасность](48-security.md).

## LibreOffice

[LibreOffice](https://www.libreoffice.org/) — полный офисный пакет: текстовый процессор, таблицы, презентации, рисовалка и дальше. Совместим с файлами Microsoft Office — отличный способ открывать те доки Word.

LibreOffice стартует через лаунчер приложений (`Super + Space`).

## Hype

[Hype](https://github.com/omacom/hype) — собственная простейшая презентационка Omarchy. Дека — один Markdown-файл с картинками и видео рядом: пишешь каждый слайд под живым превью, таскаешь слайды по порядку, потом презентуешь в полный экран или экспортишь в PDF и PowerPoint. Тему Omarchy подхватывает даже сам.

Hype стартует через лаунчер приложений (`Super + Space`). Жми `?` внутри — увидишь все хоткеи.

## Omacalc

[Omacalc](https://github.com/omacom-io/omacalc) — собственный простейший калькулятор Omarchy, открывается плавающим окном.

Omacalc стартует с `Super + Ctrl + Q` (или с клавиши калькулятора, если она на клавиатуре есть).

## Signal

[Signal](https://signal.org/) — пионер E2E-шифрованных мессенджеров и отличный вариант связи для тех, кто не хочет идти через один из больших техноконгломератов.

Signal стартует с `Super + Shift + G`. В базовую установку не входит, так что первый жамк предложит поставить (он же в _Установить > Сервисы_ в меню Omarchy).

## mpv

[mpv](https://mpv.io/) — простой быстрый медиаплеер, сыграет почти всё почти откуда угодно. Отличная штука под смотреть видео.

mpv стартует через лаунчер приложений (`Super + Space`) или просто даблкликом по видео в файловом менеджере.

## OBS Studio

[OBS Studio](https://obsproject.com/) пишет или стримит видео с нескольких входов. Миксуешь скринкаст с вебкой с микрофонным входом. На нём записывались скринкасты Omarchy.

OBS Studio стартует через лаунчер приложений (`Super + Space`).

## Kdenlive

[Kdenlive](https://kdenlive.org/) — отличный видеоредактор. То, что надо под пилить видео, вышедшее из OBS Studio, перед шарингом.

Kdenlive стартует через лаунчер приложений (`Super + Space`).

## Omacut

[Omacut](https://github.com/omacom-io/omacut) — собственный простейший видеотриммер Omarchy. Когда надо только отрезать начало и конец клипа — вызывает полный видеоредактор.

Omacut стартует через лаунчер приложений (`Super + Space`).

## Monologue

[Monologue](https://github.com/omacom/monologue) — собственный простейший вебкам-рекордер Omarchy. Выбери один раз камеру и микрофон, потом жми `Space` — пишет, и ещё раз — пауза с продолжением того же тейка. Пишет всегда в максимальном разрешении камеры, с живым метром микрофона — уровни проверишь до старта.

Стопнешь тейк — сразу откроется во встроенном редакторе. Даблклик по клипу режет его, хэндлы тянут трим каждого куска, ненужные куски убираются. Потом сохраняешь как MP4. Оригинал записи держится, пока не выкинешь, — всегда можно вернуться и нарезать иначе.

Monologue стартует через лаунчер приложений (`Super + Space`).
