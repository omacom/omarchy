# Графические приложения

## Файлы

Files (Nautilus) — это графический файловый менеджер. `Super + Shift + F` открывает его, а `Super + Shift + Alt + F` открывает его в каталоге, в котором находится ваш терминал, что экономит массу кликов. `Ctrl + L` позволяет ввести путь, а нажатие `Space` на любом файле даёт быстрый предпросмотр, ничего не открывая.

Подключите USB-флешку или SD-карту, и она смонтируется автоматически, так что просто появится на боковой панели. Для чего-то более сложного — форматирования накопителя, проверки здоровья SMART, создания разделов — запустите _Disks_ из средства запуска приложений (`Super + Space`).

Двойной щелчок подчиняется разумным значениям по умолчанию: изображения открываются в imv, видео в mpv, PDF в Document Viewer, а обычный текст в Neovim.

## Disktree

Когда диск заполняется и вы понятия не имеете, что его пожирает, запустите [Disktree](https://github.com/tobi/disktree) из средства запуска приложений (`Super + Space`). Он показывает графическую карту-дерево вашего домашнего каталога. Большие блоки занимают больше места; перемещайтесь по каталогам с клавиатуры или мыши, отметьте, что должно уйти, и просмотрите свой выбор, прежде чем что-либо удалять. Выполните `disktree --disk`, чтобы просканировать весь диск.

## Obsidian

[Obsidian](https://obsidian.md/) — это бесплатное и сильно расширяемое приложение для заметок, которое использует простые файлы Markdown для хранения.

Obsidian бесплатен для любых целей, включая личное, коммерческое и некоммерческое использование.

Obsidian также предлагает [коммерческое дополнение для синхронизации](https://obsidian.md/sync) с мобильными приложениями на iOS и Android. (https://obsidian.md/pricing).

Obsidian запускается сочетанием `Super + Shift + O`. Чтобы использовать синхронизацию темы, нужно выбрать тему `Omarchy` в настройках.

## Omawrite

[Omawrite](https://github.com/omacom-io/omawrite) — это собственное предельно простое приложение Omarchy для письма в Markdown. Никаких хранилищ, никаких плагинов, только вы и слова.

Omawrite запускается сочетанием `Super + Shift + W`.

## Pinta

[Pinta](https://www.pinta-project.com/) — это базовый инструмент редактирования изображений, который отлично подходит для обрезки, изменения размера и других простых операций. Только не ждите альтернативы Photoshop. Но волшебная палочка и слои в нём всё же есть!

Pinta запускается через средство запуска приложений (`Super + Space`).

## Aether

[Aether](https://github.com/bjarneo/aether) — это приложение для тем, которое может извлечь цвета из фонового изображения и превратить их в полноценную, цельную тему. Это самый простой способ [создать собственную тему](43-making-your-own-theme.md).

Aether запускается через средство запуска приложений (`Super + Space`).

## LocalSend

[LocalSend](https://localsend.org/) позволяет отправлять файлы на другие устройства в той же сети, где запущено приложение, как AirDrop от Apple. Правда, он кроссплатформенный, так что вы можете отправлять файлы на Windows, macOS, Android, iOS и, конечно, Linux и получать с них.

Меню «Поделиться» можно открыть сочетанием `Super + Ctrl + S` или в меню Omarchy в разделе _Действия > Поделиться_. Оно даёт четыре варианта:

- **Clipboard** отправляет всё, что вы скопировали, как текстовый файл. Отлично, чтобы перекинуть ссылку или фрагмент на телефон, не отправляя письмо самому себе.
- **File** открывает выбор файлов, где можно выбрать несколько сразу.
- **Folder** отправляет целый каталог.
- **Receive** открывает сам LocalSend, чтобы другое устройство могло отправить что-то вам.

То же самое работает из терминала с помощью `omarchy share clipboard`, `omarchy share file [path]` и `omarchy share folder [path]`. Опустите путь — и получите выбор файлов.

Отправлять можно и прямо из файлового менеджера: щёлкните правой кнопкой по любому выделению в Nautilus и выберите _Send via LocalSend_.

Межсетевой экран Omarchy по умолчанию закрыт, за исключением порта LocalSend, поэтому на свежей установке это работает из коробки. См. [безопасность](48-security.md).

## LibreOffice

[LibreOffice](https://www.libreoffice.org/) — это полноценный офисный пакет с текстовым процессором, электронными таблицами, презентациями, приложением для рисования и многим другим. Он совместим с файлами из Microsoft Office, так что это отличный способ открывать те самые документы Word.

LibreOffice запускается через средство запуска приложений (`Super + Space`).

## Hype

[Hype](https://github.com/omacom/hype) — это собственное предельно простое приложение Omarchy для презентаций. Ваша презентация — это один файл Markdown с изображениями и видео рядом с ним: пишите каждый слайд под живым предпросмотром, перетаскивайте слайды по порядку, а затем показывайте на весь экран или экспортируйте в PDF и PowerPoint. Он даже подхватывает вашу тему Omarchy.

Hype запускается через средство запуска приложений (`Super + Space`). Нажмите `?` внутри него, чтобы увидеть каждое сочетание клавиш.

## Signed

[Signed](https://github.com/omacom/signed) — это собственный предельно простой способ Omarchy подписывать PDF и заполнять их. Разместите сохранённую подпись, текст и сегодняшнюю дату в любом месте страницы, а затем сохраните подписанную копию рядом с оригиналом. Как это сделать см. в разделе [Заполнение PDF](27-filling-out-pdfs.md).

Signed запускается через средство запуска приложений (`Super + Space`) или открывается с PDF из файлового менеджера.

## Omacalc

[Omacalc](https://github.com/omacom-io/omacalc) — это собственный предельно простой калькулятор Omarchy, который открывается в плавающем окне.

Omacalc запускается сочетанием `Super + Ctrl + Q` (или клавишей калькулятора, если она есть на вашей клавиатуре).

## Signal

[Signal](https://signal.org/) — это первопроходец сквозного шифрования сообщений и отличный вариант общения для всех, кто предпочёл бы не идти через один из крупных технологических конгломератов.

Signal запускается сочетанием `Super + Shift + G`. Он не входит в базовую установку, поэтому при первом нажатии Omarchy предложит установить его для вас (он также есть в меню Omarchy в разделе _Установить > Service_).

## mpv

[mpv](https://mpv.io/) — это простой и быстрый медиаплеер, который воспроизведёт почти что угодно из любого источника. Отлично подходит для просмотра видео.

mpv запускается через средство запуска приложений (`Super + Space`) или просто двойным щелчком по видео в файловом менеджере.

## Omacut

[Omacut](https://github.com/omacom-io/omacut) — это собственный предельно простой инструмент Omarchy для обрезки видео. Когда нужно лишь отрезать начало и конец клипа, он лучше, чем запускать полноценный видеоредактор.

Omacut запускается через средство запуска приложений (`Super + Space`).

## Monologue

[Monologue](https://github.com/omacom/monologue) — это собственная предельно простая программа Omarchy для записи с веб-камеры. Выберите камеру и микрофон один раз, затем нажмите `Space`, чтобы записать, и ещё раз, чтобы поставить на паузу и возобновить тот же дубль. Он всегда записывает в самом высоком разрешении вашей камеры, с живым индикатором микрофона, чтобы вы могли проверить уровни перед стартом.

Остановите дубль — и он сразу откроется во встроенном редакторе. Дважды щёлкните по клипу, чтобы разрезать его, перетаскивайте ручки, чтобы обрезать каждый кусок, и удаляйте ненужные части. Затем сохраните как MP4. Оригинальная запись сохраняется, пока вы её не отбросите, так что вы всегда можете вернуться и нарезать её по-другому.

Monologue запускается через средство запуска приложений (`Super + Space`).
