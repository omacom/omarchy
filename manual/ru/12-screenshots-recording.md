# Скриншоты и запись

Всё, что снимается с экрана, висит на клавише Print Screen. Одна она делает картинку, а с модификаторами — запись, цвет или текст из региона. Если клавиши Print Screen на клавиатуре вообще нет — `Super + Ctrl + C` открывает то же самое меню.

| Хоткей | Функция |
| ------ | -------- |
| `Print Screen` | Скриншот |
| `Alt + Print Screen` | Запись экрана (или стоп идущей) |
| `Super + Print Screen` | Пипетка цвета |
| `Super + Ctrl + Print Screen` | Текст из региона |
| `Super + Ctrl + C` | Меню захвата |
| `Super + Ctrl + .` | Транскод картинки или видео |

## Скриншоты

Жмёшь `Print Screen` — и Omasnap снимает сфокусированный монитор до появления оверлея, так что под прицелом ничего не уезжает. Тяни свободный регион, кликни окно — снимет его, кликни пустоту — снимет весь монитор. Нажми `S` перед рисованием — снимет прокручиваемый регион. Передумал? Жми `Print Screen` ещё раз — Omasnap отвалит.

Выделил область — Omasnap сохранил кадр, положил в буфер и показал превью на 10 секунд. Кнопкой пина в превью или через `Ctrl + P` оставишь его на экране, а через Edit — разметишь.

В редакторе аннотаций рисуются стрелки, линии, фигуры, хайлайты, нумерованные маркеры, текст и секьюрные замазки; картинку можно кропнуть или вырезать кусок; прогнать OCR; подложить фон. В редакторе жми `Enter` — скопирует и сохранит готовый PNG, `Ctrl + C` — скопирует без сохранения, `Ctrl + S` — сохранит без копирования.

Снятые скриншоты падают в `~/Pictures/Screenshots` по умолчанию, с именем вроде `screenshot-2026-08-13_14-22-05-firefox.png`. Другую папку задашь через `OMASNAP_SCREENSHOT_DIR` — где класть переменные окружения сессии, см. [FAQ](46-faq.md). Папку Omasnap создаст сам при первом сохранении. Чтобы автосохранение выключить — поставь `[output] autosave = false` в `~/.config/omasnap/omasnap.conf`.

Из терминала то же открывает `omarchy screenshot`, и стартовый режим выбирается: `omarchy capture screenshot region`, `windows`, `fullscreen` или `scroll`. Второй аргумент `copy` или `save` пропускает превью и шлёт кадр сразу по назначению. Чтобы править до вывода — `omarchy screenshot --editor=overlay` под fullscreen-редактор или `omarchy screenshot --editor=window` под отдельное окно.

### Пикер с клавиатуры

Пока выделение висит, мышь вообще не нужна:

| Клавиша | Функция |
| --- | -------- |
| `S` | Тогл режима прокручиваемого региона |
| `Super + Стрелки` | Ходить по окнам в режиме окон |
| `Return` | Снять подсвеченное окно |
| `Ctrl + A` | Снять весь сфокусированный монитор |
| `R` | Вернуть последний регион этой сессии |
| `Esc` | Убрать Omasnap |

Эти хоткеи живут, только пока открыт Omasnap, — с твоим конфигом не столкнутся.

## Запись экрана

`Alt + Print Screen` открывает _Действия > Захват > Запись экрана_ — спросит, что писать на звуковую дорожку: ничего, звук стола, стол плюс микрофон или стол плюс микрофон плюс вебку. Последняя появится, только если камера правда воткнута. Выбрал — и пикер записи Omarchy даст тянуть регион или кликать окно/монитор.

Пишет gpu-screen-recorder — жмёт на GPU в 60fps и падает на CPU если придётся. Результат — MP4 в `~/Videos` с именем `screenrecording-2026-08-13_14-22-05.mp4`. Папка меняется через `OMARCHY_SCREENRECORD_DIR` — но учти: в отличие от папки скриншотов, эта должна уже существовать, иначе запись не стартует.

Пока пишешь, в панели висит маленький индикатор. Кликни — стоп. Остановить можно и повторным `Alt + Print Screen`, и пунктом _Stop Screenrecording_ под _Действия > Захват > Запись экрана_ — он там только пока реально пишется.

На стопе немного прибирается перед выдачей файла: первый кадр подрезается, а если есть звук — он нормализуется на -14 LUFS с замьюченным хлопком PipeWire-захвата в самом начале. Потом прилетает уведомление с миниатюрой записи. Кликни — проиграет файл в mpv.

### Оверлей вебки

Когда пишешь с вебкой, камера висит закреплённым кропнутым портретом в правом нижнем углу того, что снимаешь. Легла не туда, где надо, — ресайзишь на лету:

| Хоткей | Функция |
| ------ | -------- |
| `Super + Alt + [` | Оверлей вебки меньше |
| `Super + Alt + ]` | Оверлей вебки больше |

Размеров три — маленький, средний, большой, хоткеи шагают между ними. По умолчанию средний. Они пропорциональны записи, так что камера занимает ту же долю кадра что на 1080p-мониторе, что на 6K. А если снимал регион, а не целый экран, оверлей якорится к углу региона, а не монитора, — из кадра не вылезет.

Можно и напрямую: `omarchy-capture-webcam-resize small`, а `reset` вернёт средний.

## Текст, QR-коды и цвета

`Super + Ctrl + Print Screen` выделяет регион и кладёт его OCR в буфер. Нормально расписано в [извлечении текста и диктовке](11-text-extraction-dictation.md).

_Действия > Захват > QR-код_ делает тот же трюк для QR-кодов. Выдели регион с кодом — расшифровка уедет в буфер. Ищет только QR-коды: плотный контент экрана имеет привычку ложно срабатывать как штрихкод. Стоит знать: расшифровка едет в буфер и больше никуда. Её не печатают, её нет в уведомлении, и она помечена как sensitive — в [истории буфера](08-unified-clipboard-history.md) не задержится. В QR-кодах регулярно таскаются секреты — `otpauth://` URI за сетапом 2FA, например, — а тебе такое в логах не надо. Вставка при этом работает нормально.

`Super + Print Screen` (или _Действия > Захват > Цвет_) превращает курсор в пипетку. Кликни что-нибудь на экране — цвет упадёт в буфер. Нажми хоткей ещё раз — выйдешь без выбора.

## Транскод перед отправкой

4K-запись экрана или сырой HEIC с телефона часто слишком жирные, чтобы просто отправить. `Super + Ctrl + .` (или _Действия > Изменить формат_) лечит. Предложит нечёткий файликер по `~/Pictures` и `~/Videos`, потом спросит формат и размер.

Картинки едут в jpg или png на high, medium или low — ширина режется на 3160, 2160 и 1080 пикселей. Видео едет в mp4 или анимированный gif на 4k, 1080p или 720p. Сконверченный файл пишется рядом с оригиналом с разрешением в имени — `demo-1080p.mp4` — а путь копируется в буфер как file URI, так что вставляется прямо в приложение, которое ест дропы файлов.

Из терминала тоже работает, если знаешь чего хочешь: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. Есть ещё `omarchy transcode ascii` — превращает картинку в ASCII-арт. Он в основном для [брендинга](41-branding.md).

## Куда отправить

Файл готов — `Super + Ctrl + S` открывает меню шаринга и шлёт его на другое устройство в твоей сети через LocalSend. Про это — в [GUI](22-guis.md).
