# Снимки экрана и запись

Всё, что можно захватить с экрана, завязано на клавишу Print Screen. Сама по себе клавиша делает снимок, а модификаторы делают запись, выбирают цвет или текст внутри области. Если на вашей клавиатуре вообще нет клавиши Print Screen, `Super + Ctrl + C` открывает тот же набор в виде меню.

| Сочетание | Функция |
| ------ | -------- |
| `Print Screen` | Снимок экрана |
| `Alt + Print Screen` | Запись экрана (или остановить запущенную) |
| `Super + Print Screen` | Выбор цвета |
| `Super + Ctrl + Print Screen` | Извлечь текст из области |
| `Super + Ctrl + C` | Меню захвата |
| `Super + Ctrl + .` | Перекодировать изображение или видео |

## Снимки экрана

Нажмите `Print Screen`, и Omasnap захватит сфокусированный монитор до появления его оверлея, поэтому ничего не сдвинется под вами, пока вы целитесь. Перетащите произвольную область, щёлкните по окну, чтобы захватить его, или щёлкните по открытому пространству, чтобы захватить весь монитор. Нажмите `S` перед рисованием, чтобы захватить прокручиваемую область. Передумали? Нажмите `Print Screen` ещё раз, чтобы закрыть Omasnap.

После выбора области Omasnap сохраняет захват, копирует его в буфер обмена и показывает предпросмотр в течение 10 секунд. Используйте кнопку закрепления в предпросмотре или `Ctrl + P`, чтобы оставить его на экране, или выберите Edit для аннотирования.

Редактор аннотаций может рисовать стрелки, линии, фигуры, выделения, нумерованные маркеры, текст и безопасные редактуры; обрезать или вырезать часть изображения; распознавать его текст через OCR; и добавлять фон. В редакторе нажмите `Enter`, чтобы скопировать и сохранить готовый PNG, `Ctrl + C`, чтобы скопировать без сохранения, или `Ctrl + S`, чтобы сохранить без копирования.

Сохранённые снимки экрана по умолчанию попадают в `~/Pictures/Screenshots` с именем вида `screenshot-2026-08-13_14-22-05-firefox.png`. Установите `OMASNAP_SCREENSHOT_DIR` для использования другого каталога — см. [FAQ](46-faq.md) о том, куда помещать переменные окружения сессии. Omasnap создаёт каталог при сохранении первого снимка. Установите `[output] autosave = false` в `~/.config/omasnap/omasnap.conf`, чтобы отключить автоматическое сохранение.

Из терминала `omarchy screenshot` открывает тот же оверлей, и вы можете выбрать его стартовый режим: `omarchy capture screenshot region`, `windows`, `fullscreen` или `scroll`. Второй аргумент `copy` или `save` пропускает предпросмотр и отправляет снимок прямо в это место назначения. Для редактирования перед выводом используйте `omarchy screenshot --editor=overlay` для полноэкранного редактора или `omarchy screenshot --editor=window` для отдельного окна.

### Управление выбором с клавиатуры

Пока выделение открыто, мышь вообще не требуется:

| Клавиша | Функция |
| --- | -------- |
| `S` | Переключить режим прокручиваемой области |
| `Super + Arrow keys` | Перемещаться между окнами в режиме Window |
| `Return` | Захватить выделенное окно |
| `Ctrl + A` | Захватить весь сфокусированный монитор |
| `R` | Восстановить последнюю область, нарисованную в этой сессии |
| `Esc` | Закрыть Omasnap |

Эти привязки существуют только пока Omasnap открыт, поэтому не могут конфликтовать ни с чем в вашей конфигурации.

## Запись экрана

`Alt + Print Screen` открывает _Действия > Захват > Запись экрана_, которое спрашивает, что должно быть на звуковой дорожке: без звука, звук рабочего стола, рабочий стол плюс микрофон или рабочий стол плюс микрофон плюс веб-камера. Последний вариант появляется только если у вас действительно подключена камера. Выберите один, и средство записи Omarchy позволит перетащить область или щёлкнуть по окну или монитору.

Запись работает на gpu-screen-recorder, который кодирует на GPU при 60fps и откатывается на CPU при необходимости. Результат — MP4 в `~/Videos` с именем `screenrecording-2026-08-13_14-22-05.mp4`. Установите `OMARCHY_SCREENRECORD_DIR`, чтобы изменить это — но обратите внимание, что в отличие от каталога снимков экрана, этот каталог должен уже существовать, иначе запись откажется запускаться.

Пока вы записываете, в панели появляется небольшой индикатор. Щёлкните по нему, чтобы остановить. Также можно остановить повторным `Alt + Print Screen` или пунктом _Остановить запись экрана_ в _Действия > Захват > Запись экрана_, который появляется только пока что-то действительно записывается.

Остановка выполняет небольшую уборку перед передачей файла: первый кадр обрезается, а если есть звук, он нормализуется до -14 LUFS с приглушением хлопка захвата PipeWire в самом начале. Затем появляется уведомление с миниатюрой из записи. Щёлкните по нему, чтобы воспроизвести файл в mpv.

### Оверлей веб-камеры

При записи с веб-камерой камера появляется как закреплённое, обрезанное портретное окно в правом нижнем углу того, что вы записываете. Если оно сидит поверх чего-то нужного, измените размер на лету:

| Сочетание | Функция |
| ------ | -------- |
| `Super + Alt + [` | Уменьшить оверлей веб-камеры |
| `Super + Alt + ]` | Увеличить оверлей веб-камеры |

Есть три размера — маленький, средний и большой, — и сочетания переключают между ними. Средний — по умолчанию. Они пропорциональны записи, поэтому камера занимает ту же долю кадра, записываете ли вы монитор 1080p или 6K. А если вы записали область, а не весь дисплей, оверлей привязывается к углу этой области, а не монитора, поэтому остаётся внутри кадра.

Также можно вызывать его напрямую через `omarchy-capture-webcam-resize small` или `reset`, чтобы вернуться к среднему.

## Текст, QR-коды и цвета

`Super + Ctrl + Print Screen` выбирает область и распознаёт её в буфер обмена через OCR. Это подробно описано в [Извлечение текста и диктовка](11-text-extraction-dictation.md).

_Действия > Захват > QR-код_ делает тот же трюк для QR-кодов. Выберите область с кодом, и декодированное значение попадёт в буфер обмена. Оно ищет только QR-коды — плотное содержимое экрана иначе имеет привычку ложно срабатывать как штрихкод. Стоит знать: декодированное значение попадает в буфер обмена и никуда больше. Оно не печатается, его нет в уведомлении, и оно помечено как конфиденциальное, поэтому не остаётся в [истории буфера обмена](08-unified-clipboard-history.md). QR-коды регулярно несут секреты — URI `otpauth://` за кодом настройки 2FA, например, — и вы не хотите, чтобы это оказалось в логе. Вставка при этом работает нормально.

`Super + Print Screen` (или _Действия > Захват > Цвет_) превращает курсор в пипетку. Щёлкните по чему угодно на экране, и цвет попадёт в буфер обмена. Нажмите сочетание ещё раз, чтобы выйти без выбора.

## Перекодирование перед отправкой

4K-запись экрана или необработанный HEIC с телефона часто слишком велик, чтобы просто отправить. `Super + Ctrl + .` (или _Действия > Перекодировать_) исправляет это. Оно предлагает нечёткий выбор файла по `~/Pictures` и `~/Videos`, затем спрашивает формат и размер.

Изображения идут в jpg или png в высоком, среднем или низком качестве, что ограничивает ширину 3160, 2160 и 1080 пикселями. Видео идут в mp4 или анимированный gif в 4k, 1080p или 720p. Преобразованный файл записывается рядом с оригиналом с разрешением в имени — `demo-1080p.mp4`, — а путь копируется в буфер обмена как URI файла, поэтому его можно вставить напрямую в приложение, принимающее перетаскивание файлов.

Это также работает из терминала, если вы уже знаете, что нужно: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. Есть также `omarchy transcode ascii`, который превращает изображение в ASCII-арт — это в основном для [брендинга](41-branding.md).

## Отправка куда-либо

Когда файл готов, `Super + Ctrl + S` открывает меню Поделиться и отправляет его на другое устройство в вашей сети через LocalSend. См. [GUI-приложения](22-guis.md) об этом.
