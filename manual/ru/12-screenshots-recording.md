# Снимки экрана и запись

Всё, что можно захватить с экрана, завязано на клавишу Print Screen. Одна клавиша сама по себе делает снимок, а модификаторы делают запись, выбирают цвет или извлекают текст внутри области. Если на вашей клавиатуре вообще нет клавиши Print Screen, `Super + Ctrl + Alt + C` делает тот же снимок экрана, а `Super + Ctrl + C` открывает весь набор в виде меню.

| Hotkey | Function |
| ------ | -------- |
| `Print Screen` | Снимок экрана |
| `Super + Ctrl + Alt + C` | Снимок экрана |
| `Alt + Print Screen` | Запись экрана (или остановить текущую запись) |
| `Super + Print Screen` | Пипетка для выбора цвета |
| `Super + Ctrl + Print Screen` | Извлечь текст из области |
| `Super + Ctrl + C` | Меню захвата |
| `Super + Ctrl + .` | Перекодировать изображение или видео |

## Снимки экрана

Нажмите `Print Screen` (или `Super + Ctrl + Alt + C`), и Omasnap захватит монитор в фокусе ещё до появления его наложения, так что пока вы целитесь, под вами ничего не сдвинется. Выделите область произвольной формы, щёлкните окно, чтобы захватить его, или щёлкните пустое место, чтобы захватить весь монитор. Нажмите `S` перед выделением, чтобы захватить прокручиваемую область. Передумали? Нажмите ту же клавишу ещё раз, чтобы закрыть Omasnap.

После того как вы выберете область, Omasnap сохраняет снимок, копирует его в буфер обмена и показывает уведомление с его миниатюрой — так же, как это делает сохранённая запись экрана. Выберите Open, чтобы посмотреть сохранённый снимок в вашем просмотрщике изображений, или Edit, чтобы добавить к нему пометки.

Редактор пометок умеет рисовать стрелки, линии, фигуры, выделения, пронумерованные маркеры, текст и надёжно скрывать фрагменты; обрезать или вырезать часть изображения; распознавать его текст с помощью OCR; и добавлять подложку. В редакторе нажмите `Enter`, чтобы скопировать и сохранить готовый PNG, `Ctrl + C` — чтобы скопировать его без сохранения, или `Ctrl + S` — чтобы сохранить его без копирования.

По умолчанию сохранённые снимки экрана попадают в `~/Pictures/Screenshots` с именем вроде `screenshot-2026-08-13_14-22-05-firefox.png`. Задайте `OMASNAP_SCREENSHOT_DIR`, чтобы использовать другой каталог, — о том, куда помещать переменные окружения сеанса, см. [FAQ](46-faq.md). Omasnap создаёт каталог, когда сохраняет первый снимок. Задайте `[output] autosave = false` в `~/.config/omasnap/omasnap.conf`, чтобы отключить автоматическое сохранение; тогда снимки будут только копироваться и показываться в предпросмотре на 7 секунд, который можно оставить на экране с помощью его кнопки закрепления или `Ctrl + P`.

Из терминала `omarchy screenshot` открывает то же наложение, и вы можете выбрать его начальный режим: `omarchy capture screenshot region`, `windows`, `fullscreen` или `scroll`. Второй аргумент `copy` или `save` отправит снимок сразу в это место назначения. Чтобы отредактировать перед выводом, используйте `omarchy screenshot --editor=overlay` для полноэкранного редактора или `omarchy screenshot --editor=window` для отдельного окна.

### Управление выбором с клавиатуры

Пока открыто окно выбора, мышь вам вообще не нужна:

| Key | Function |
| --- | -------- |
| `S` | Переключить режим прокручиваемой области |
| `Super + Arrow keys` | Перемещаться между окнами в режиме окон |
| `Return` | Захватить выделенное окно |
| `Ctrl + A` | Захватить весь монитор в фокусе |
| `R` | Восстановить последнюю область, нарисованную в этом сеансе |
| `Esc` | Закрыть Omasnap |

Эти привязки существуют только пока открыт Omasnap, поэтому они не могут конфликтовать ни с чем в вашей собственной конфигурации.

## Запись экрана

`Alt + Print Screen` открывает _Trigger > Capture > Screenrecord_, где вас спрашивают, что вы хотите видеть на звуковой дорожке: без звука, звук рабочего стола, рабочий стол плюс микрофон или рабочий стол плюс микрофон плюс веб-камера. Последний вариант появляется только если у вас действительно подключена камера. Выберите вариант, и инструмент выбора записи Omarchy позволит вам выделить область или щёлкнуть окно или монитор.

Запись работает на gpu-screen-recorder, который кодирует на GPU со скоростью 60fps и при необходимости откатывается на CPU; на GPU, которые он не поддерживает, например на Apple Silicon, Omarchy вместо этого записывает с помощью wf-recorder. Результат — MP4 в `~/Videos` с именем `screenrecording-2026-08-13_14-22-05.mp4`. Задайте `OMARCHY_SCREENRECORD_DIR`, чтобы изменить это, — но учтите, что, в отличие от каталога снимков экрана, этот каталог уже должен существовать, иначе запись откажется запускаться.

Пока вы записываете, в панели появляется маленький индикатор. Щёлкните его, чтобы остановить запись. Остановить её можно также ещё одним нажатием `Alt + Print Screen` или с помощью пункта _Stop Screenrecording_ в _Trigger > Capture > Screenrecord_, который появляется только пока что-то действительно записывается.

Остановка перед тем, как отдать вам файл, выполняет небольшую уборку: первый кадр обрезается, а если есть звук, он нормализуется до -14 LUFS, при этом хлопок захвата PipeWire в самом начале заглушается. Затем появляется уведомление с миниатюрой из записи. Выберите _Open_, чтобы воспроизвести файл в Omaview, или _Cut_, чтобы обрезать его в Omacut.

### Наложение веб-камеры

Когда вы записываете с веб-камерой, камера появляется как закреплённое, обрезанное портретное окно в правом нижнем углу всего, что вы записываете. Если она загораживает что-то нужное вам, измените её размер на лету:

| Hotkey | Function |
| ------ | -------- |
| `Super + Alt + [` | Сделать наложение веб-камеры меньше |
| `Super + Alt + ]` | Сделать наложение веб-камеры больше |

Есть три размера — маленький, средний и большой — и горячие клавиши переключают между ними по шагам. По умолчанию используется средний. Они пропорциональны записи, поэтому камера занимает одну и ту же долю кадра, записываете ли вы монитор 1080p или 6K. А если вы записывали область, а не весь экран, наложение привязывается к углу этой области, а не монитора, поэтому оно остаётся внутри кадра.

Вы также можете вызвать это напрямую с помощью `omarchy-capture-webcam-resize small` или `reset`, чтобы вернуться к среднему размеру.

## Текст, QR-коды и цвета

`Super + Ctrl + Print Screen` выбирает область и распознаёт её текст с помощью OCR в буфер обмена. Это как следует описано в [Извлечение текста и диктовка](11-text-extraction-dictation.md).

_Trigger > Capture > QR Code_ делает тот же трюк для QR-кодов. Выберите область с кодом, и декодированное значение отправится в буфер обмена. Функция ищет только QR-коды — плотное содержимое экрана в противном случае имеет привычку ложно срабатывать как штрих-код. Стоит знать: декодированное значение отправляется в буфер обмена и больше никуда. Оно не печатается, его нет в уведомлении, и оно помечено как чувствительное, поэтому оно не задерживается в [истории буфера обмена](08-unified-clipboard-history.md). QR-коды регулярно несут секреты — например, URI `otpauth://`, стоящий за кодом настройки 2FA, — и вы не хотите, чтобы это попало в журнал. Вставка при этом работает отлично.

`Super + Print Screen` (или _Trigger > Capture > Color_) превращает курсор в пипетку. Щёлкните что угодно на экране, и цвет попадёт в буфер обмена. Нажмите горячую клавишу ещё раз, чтобы выйти, ничего не выбирая.

## Перекодирование перед отправкой

Запись экрана в 4K или необработанный HEIC с вашего телефона часто слишком велики, чтобы просто отправить их. `Super + Ctrl + .` (или _Trigger > Transcode_) это исправляет. Функция предлагает вам средство выбора файла с нечётким поиском по `~/Pictures` и `~/Videos`, а затем спрашивает формат и размер.

Изображения преобразуются в jpg или png с высоким, средним или низким размером, которые ограничивают ширину 3160, 2160 и 1080 пикселями. Видео преобразуются в mp4 или анимированный gif в 4k, 1080p или 720p. Преобразованный файл записывается рядом с оригиналом с разрешением в имени — `demo-1080p.mp4` — а путь копируется в буфер обмена как URI файла, поэтому вы можете вставить его прямо в приложение, принимающее перетаскивание файлов.

Это работает и из терминала, если вы уже знаете, чего хотите: `omarchy transcode ~/Videos/demo.mov mp4 1080p`. Есть также `omarchy transcode ascii`, который превращает изображение в ASCII-графику, — это в основном нужно для [брендинга](41-branding.md).

## Отправка куда-либо

Когда у вас есть файл, `Super + Ctrl + S` открывает меню Share и отправляет его на другое устройство в вашей сети через LocalSend. Об этом см. [GUIs](22-guis.md).
