# Переход с Mac или Windows

Если вы годами пользовались macOS или Windows, ваши пальцы знают сотню вещей, о которых ваш мозг уже забыл, что когда-либо их учил. Эта глава — слой перевода: куда эти инстинкты ведут в Omarchy. Сами функции подробно разобраны в других местах — здесь просто карта.

### Super — центр всего

Вся мышечная память, выстроенная вокруг Cmd или клавиши Windows, переносится на одну клавишу: Super. Это клавиша Windows на клавиатуре PC, и она — якорь почти для каждой горячей клавиши в Omarchy.

Ваш рефлекс Spotlight, Raycast или меню Start превращается в `Super + Space`. Это открывает меню Omarchy, которое запускает приложения, меняет настройки, устанавливает программное обеспечение, делает снимки экрана — практически всё. Начните вводить текст, чтобы отфильтровать. `Super + Alt + Space` показывает все приложения одной сеткой, как это делает Launchpad. См. [навигация](04-navigation.md).

### Нет ни dock, ни значков на рабочем столе

Не по чему кликать для запуска, нет значков, которые нужно расставлять на рабочем столе. Приложения запускаются горячей клавишей (`Super + Return` для терминала, `Super + Shift + Return` для браузера и `Super + K` для списка всего, что назначено) или из меню. Единственный постоянный элемент интерфейса — [верхняя панель](05-the-top-bar.md), которая берёт на себя то, что раньше для вас делали строка меню, системный трей и Notification Center, — и почти каждый виджет на ней что-то делает по левому, правому и среднему клику.

### Окна располагаются сами

Самый большой сдвиг в мышлении: вы не перетаскиваете окна и не прижимаете их к половинам экрана. Открываете окно — и оно занимает весь экран. Открываете второе — и они делят его. Вы никогда не выуживаете окно из-под другого, потому что окна не перекрываются.

Когда вам действительно нужно плавающее окно, `Super + T` выводит активное из тайлинга (и обратно). Но сначала дайте тайлингу настоящий шанс — это сердце всей системы. [Навигация](04-navigation.md) проведёт вас через это.

Рабочие пространства покажутся знакомыми: это Spaces из macOS или виртуальные рабочие столы Windows, за исключением того, что вы действительно будете ими пользоваться, потому что `Super + 1/2/3/4` мгновенно переходит к нужному, а `Super + Shift + 1/2/3/4` отправляет туда активное окно. Никакой задержки на анимацию, только мгновенные переходы. Это значит, что вам могут даже не понадобиться несколько мониторов, если вы привыкли к такому раньше.

### Копирование и вставка просто работают

На Mac у вас везде был Cmd + C. На Windows у вас везде был Ctrl + C — кроме терминала, где он убивает вашу программу. Omarchy даёт вам `Super + C`, `Super + X` и `Super + V`, и они работают везде, включая терминал. Никакого отдельного рефлекса для оболочки учить не нужно.

Пользователи Windows: ваша история буфера обмена Win + V живёт на `Super + Ctrl + V`, и она хранит изображения, а также текст. См. [единый буфер обмена и история](08-unified-clipboard-history.md).

### Таблица перевода

| Вы тянетесь к | В Omarchy |
| ------------- | ---------- |
| Spotlight / Raycast / меню Start | `Super + Space` — меню Omarchy |
| AirDrop | LocalSend, через `Super + Ctrl + S` — см. [GUI](22-guis.md) |
| Cmd + Shift + 4 / Win + Shift + S | `Super + Ctrl + Alt + C` или `Print Screen` — см. [скриншоты и запись](12-screenshots-recording.md) |
| Notification Center | История уведомлений на `Super + Shift + Alt + ,` |
| Time Machine (для системы) | Автоматические [снимки системы](47-system-snapshots.md) при каждом обновлении |
| App Store / скачивание установщика | _Install_ в меню или `omarchy pkg add` — см. [другие пакеты](29-other-packages.md) |
| System Settings / Control Panel | _Setup_ в меню, которое редактирует обычные файлы конфигурации — см. [дотфайлы](31-dotfiles.md) |

### Некоторые вещи действительно устроены иначе

Многие настройки живут в текстовых файлах, которые вы редактируете, а не в панелях, по которым вы кликаете. Это звучит примитивно, пока вы не поймёте, что это значит: каждую настройку можно увидеть, скопировать на вашу следующую машину и поместить под контроль версий. Меню _Setup_ бросает вас прямо в нужный файл и перезапускает то, что нужно перезапустить, когда вы закончите.

Обновления приходят через одну команду — _Update > Omarchy_, — которая обновляет сам Omarchy и каждый пакет в системе, предварительно сделав снимок. Никаких отдельных обновляторов для каждого приложения, достающих вас в случайные моменты. См. [обновления](30-updates.md).

Программное обеспечение приходит из менеджера пакетов, а не из скачанных установщиков.

И когда вы закрываете окно, приложение действительно завершает работу. Никакого лимба macOS, где программа продолжает работать без окон. `Super + W` — или `Super + Q`, если именно с такой памятью пальцев вы сюда пришли, — значит: исчезло.

### На оборудовании Mac

Omarchy хорошо работает на Intel Macs — см. [поддержка Mac](44-mac-support.md). И клавиатура к вам добра: Omarchy ничего не переназначает, а Linux воспринимает клавишу Command как Super, так что Super находится ровно там, где всегда был Cmd. Ваш большой палец переезда не заметит.

### Дайте этому две недели

Инстинкты переносятся быстрее, чем вы думаете. Один раз пробегите глазами главу [горячие клавиши](07-hotkeys.md), а всякий раз, когда вылетает из головы какое-то сочетание, нажимайте `Super + K` — оно покажет вам все. Это единственная горячая клавиша, которую вам на самом деле нужно запомнить.
