# Верхняя панель

Полоса вдоль верха экрана — это панель Omarchy. Не прикрученный сбоку статус-бар, а часть шелла Omarchy — одного долгоживущего процесса Quickshell, который рисует ещё меню, уведомления, OSD-попапы и локскрин. Поэтому он идеально темится со всем остальным, а панель открывается мгновенно, а не спавнит приложение.

А ещё это единственный кусок стола, который всегда на экране, — так что стоит знать, что делают все эти мелкие глифы.

## Что на ней по умолчанию

У панели три секции. Слева — лого Omarchy (лаунчер меню) и индикаторы столов. В центре — статусные индикаторы, часы, раскладка, погода и бейдж обновления Omarchy. Справа: системный трей, агенты, блютуз, сеть, звук, экран и питание.

Некоторые показываются, только когда им есть что сказать. Раскладка видна, только если настроено больше одной. Бейдж обновления — только когда ждёт обновление Omarchy. А иконка агентов появляется, когда Omarchy впервые находит использование AI-кодинга на машине (см. [AI](17-ai.md)).

## Клики туда-сюда

Почти каждый виджет что-то делает по левому, правому и среднему клику, а несколько реагируют на скролл. Эту часть люди пропускают — а зря: в правой и средней кнопках прячется много хорошего.

| Виджет | Левая | Правая | Средняя / скролл |
| --- | --- | --- | --- |
| Меню | Меню Omarchy | Новый терминал | — |
| Столы | Фокус на стол | — | — |
| Часы | Попап календаря | Смена формата подписи | Средняя: выбор часового пояса |
| Погода | Попап прогноза | Вся погода уведомлением | Средняя: обновить |
| Звук | Панель звука | Мьют | Средняя: панель · скролл: громкость |
| Микрофон | Выключить мик | — | Средняя: панель звука · скролл: громкость входа |
| Сеть | Панель сети | — | — |
| Блютуз | Панель блютуза | Выкл/вкл радио | — |
| Экран | Панель экрана | — | Скролл: яркость |
| Питание | Панель питания | Вкл/выкл проценты батареи | — |
| Медиа | Играть/пауза | Попап с обложкой | Средняя: дальше · скролл: дальше/назад |
| Агенты | Панель агентов | Запустить своего агента | Средняя: следующая подписка |
| Трей | Навести — выдвинется | Правая на шевроне — управлять | — |
| Обновление Omarchy | Запустить обновление | — | — |

Не всё из таблицы торчит у тебя из панели из коробки. Виджет медиа (MPRIS сейчас играет, с бегущими треком и артистом) и виджет микрофона встроены, но выключены по умолчанию — добавь, если хочешь, как описано ниже.

## Панели

Клик по иконке панели открывает панель — нормальный попап со слайдерами, списками и навигацией с клавиатуры, а не тултип. У каждой есть и хоткей — не надо целиться в глиф на 16 пикселей:

| Хоткей | Панель |
| --- | --- |
| `Super + Ctrl + A` | Звук |
| `Super + Ctrl + W` | Сеть |
| `Super + Ctrl + B` | Блютуз |
| `Super + Ctrl + D` | Экран |
| `Super + Ctrl + P` | Питание |
| `Super + Ctrl + Alt + D` | Календарь |
| `Super + Ctrl + Alt + E` | Мировые часы |
| `Super + Ctrl + 1-9` | N-я панель справа |

Панели — не показометры. В них реально дела делают:

- **Звук**: мастер-слайдер громкости, выбор устройства вывода и микшер по приложениям — можно прикрутить одну вкладку браузера, не трогая всё остальное.
- **Сеть**: скан Wi-Fi, уровень сигнала, подключение и выбор DNS-провайдера.
- **Блютуз**: список устройств с подключить/отключить и уровнем батареи.
- **Питание**: статистика батареи, профили питания (помнит отдельный выбор для батареи и сети) и немного системной инфы.
- **Экран**: слайдер яркости, размер текста, пресеты масштаба монитора, а если экранов больше одного — контролы на каждый. Глубже — в [мониторах](33-monitors.md).
- **Часы**: сетка месяца с ISO-номерами недель и листанием месяцев.

Каждая панель ходит и с клавиатуры, и с мыши: стрелки двигают, Return жмёт, Tab шагает на соседнюю панель, Escape закрывает.

`Super + Ctrl + 1-9` считает панели слева направо в правой секции, пропуская трей (у него своей панели нет). Так что цифра совпадает с иконкой, в которую тыкал бы.

### Tailscale и Dropbox

Ещё два виджета появляются на панели, только когда поставишь matching-сервис из **Install → Service**, — и про оба стоит знать, потому что они не только статус кажут.

Панель **Tailscale** подключает и отключает тейлнет, переключает аккаунты и выбирает exit-ноду (в списке и свои машины, и регионы Mullvad). А ещё она ходит по твоим машинам — выбрав одну, клавишей `s` отправляешь на неё файлы через Taildrop (самый быстрый способ перекинуть файл на телефон или другой ноут). `c` копирует IP машины, `n` — имя, `d` — полное DNS-имя. На каждой строке машины есть и кнопка отправки, если больше нравится кликать. То же из терминала: `omarchy tailscale send <machine> [file...]`.

Панель **Dropbox** держит логин, показывает занятое место и список свежих синкнутых файлов.

Снос любого из сервисов убирает его виджет с панели обратно.

## Индикаторы

Кучка по центру — виджет индикаторов. Это статусные глифы включённых режимов: не беспокоить, ночной свет, напоминание в очереди ([reminder](09-reminders.md)), идущая запись экрана, stay awake и [диктовка](11-text-extraction-dictation.md). Загораются, когда режим активен, иначе не мешаются — наведи на центр панели, чтобы подглядеть неактивные. Клик по индикатору тоглит режим.

Хочешь, чтобы всегда висели, — поставь `alwaysShow` в `true` на виджете. А если нужны только некоторые — перечисли их в `items`: `["Dnd", "Reminder", "NightLight"]`. Виджетов индикаторов может быть несколько — разные секции показывают разные подмножества.

## Перестановка панели

Панель конфигурится сам. Конфиг открывать не надо, чтобы подвигать.

Возьми пустое место панели около центра и потащи к другому краю экрана — панель переедет: влево, вправо, вверх или вниз, всё работает, и каждый виджет адаптируется (вертикальные панели падают в компактные иконки). Клик с холдом начинает тот же драг. Двойной левый клик по тому же пустому месту тоглит прозрачность. А любой виджет можно таскать, чтобы переупорядочить или кинуть в другую секцию.

Хочешь из меню — в **Style → Menu Bar** есть и позиция, и прозрачность.

У того же есть команды — то, что надо для [дотфайлов](31-dotfiles.md):

```bash
omarchy bar position bottom
omarchy bar transparent toggle
omarchy bar move omarchy.clock --section center --index 0
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # назад на shipped-раскладку
```

Чтобы добавить или убрать виджет целиком — команды плагинов. `omarchy plugin list` печатает каждый виджет, который знает шелл, с id, а дальше:

```bash
omarchy plugin enable omarchy.media --section center
omarchy plugin disable omarchy.weather
```

## Прячем панель

`Super + Shift + Space` тоглит панель туда-сюда, не убивая шелл — панели и хоткеи работают, просто пиксели возвращаются. Оно же в меню под **Trigger → Toggle → Menu Bar**.

## Файл конфига

Всё это лежит в `~/.config/omarchy/shell.json` под ключом `bar`. Вот ужатая версия:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "transparent": false,
    "centerAnchor": "omarchy.clock",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

Каждый виджет — одна запись в одном из трёх массивов layout, и настройки сидят инлайн на записи — отдельного файла настроек нет и под-объекта `config` тоже. Формат часов `format`, `formatAlt` (на что переключает правый клик) и `verticalFormat` живут прямо там, на `{ "id": "omarchy.clock" }`.

`centerAnchor` называет один центральный виджет, который пришпиливается ровно к центру экрана, а остальные фланкируют его. Так часы стоят мёртво по центру, даже когда погода и бейдж обновления приходят и уходят. Поставь пустую строку — и центральный список просто центрируется группой.

Одно правило стоит впитать: **как завёл свой `shell.json` — он канон**. Пока ничего не кастомизировал, шелл читает дефолтный файл Omarchy. Как только подёргал виджет, запустил `omarchy bar` или поправил файл руками — он твой: глубокого мержа нет, так что новые дефолтные виджеты будущих релизов Omarchy сами на панель не приедут. `omarchy bar defaults` в любой момент возвращает shipped-раскладку.

В том же файле лежат твои тайминги простоя на верхнем уровне, вне ключа `bar`: `idle.screensaver` и `idle.lock`, оба в секундах с момента простоя. Так что дефолтный скринсейвер встаёт на 150-й секунде, а лок — на 300-й.
