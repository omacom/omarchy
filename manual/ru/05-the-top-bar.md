# Верхняя панель

Полоса вдоль верхней части экрана — это панель Omarchy. Это не прикрученная статусная панель, а часть оболочки Omarchy — единого долгоработающего процесса Quickshell, который также отрисовывает меню, уведомления, всплывающие OSD и экран блокировки. Вот почему она идеально сочетается по теме со всем остальным и почему панель открывается мгновенно, а не порождает новое приложение.

Это также единственный элемент рабочего стола, который всегда на экране, поэтому стоит знать, что делают все эти маленькие глифы.

## Что на ней по умолчанию

Панель состоит из трёх секций. Слева расположены логотип Omarchy (средство запуска меню) и индикаторы рабочих пространств. В центре — индикаторы состояния, часы, Elsewhen (мировые часы), погода и бейдж обновления Omarchy. Справа: раскладка клавиатуры (когда настроено более одной), системный трей, агенты, bluetooth, сеть, аудио, дисплей и питание.

Некоторые из них появляются только тогда, когда им есть что сказать. Раскладка клавиатуры появляется только если вы настроили более одной раскладки. Бейдж обновления появляется только когда ждёт обновление Omarchy. А значок агентов появляется при первом обнаружении Omarchy использования ИИ-кодирования на машине (см. [ИИ](17-ai.md)).

## Щелчки

Почти каждый виджет что-то делает при левом, правом и среднем щелчке, а несколько реагируют на прокрутку. Это та часть, которую люди упускают — правая и средняя кнопки скрывают много хорошего.

| Виджет | Левый | Правый | Средний / прокрутка |
| --- | --- | --- | --- |
| Меню | Меню Omarchy | Новый терминал | — |
| Рабочие пространства | Фокус на это рабочее пространство | — | Прокрутка: следующее/предыдущее рабочее пространство |
| Часы | Всплывающий календарь | Цикл форматов подписи | Средний: выбор часового пояса |
| Погода | Всплывающий прогноз | Полная погода как уведомление | Средний: обновить |
| Аудио | Панель аудио | Отключить звук | Средний: панель · прокрутка: громкость |
| Микрофон | Отключить микрофон | — | Средний: панель аудио · прокрутка: громкость входа |
| Сеть | Панель сети | — | — |
| Bluetooth | Панель Bluetooth | Переключить радио | — |
| Дисплей | Панель дисплея | — | Прокрутка: яркость |
| Питание | Панель питания | Переключить процент батареи | — |
| Медиа | Воспроизведение/пауза | Всплывающая обложка | Средний: далее · прокрутка: ранее/далее |
| Агенты | Панель агентов | Запустить вашего агента | Средний: следующая подписка |
| Трей | Наведите, чтобы показать ящик | Правый на шевроне для управления | — |
| Обновление Omarchy | Запустить обновление | — | — |

Не всё в этой таблице есть на вашей панели из коробки. Виджет медиа (MPRIS now-playing с прокручивающимся треком и исполнителем) и виджет микрофона встроены, но выключены по умолчанию — добавьте их, если хотите, как описано ниже.

## Панели

Щелчок по значку панели открывает панель — полноценное всплывающее окно со слайдерами, списками и навигацией с клавиатуры, а не подсказку. У каждой также есть сочетание клавиш, чтобы никогда не целиться в глиф в 16 пикселей:

| Сочетание | Панель |
| --- | --- |
| `Super + Ctrl + A` | Аудио |
| `Super + Ctrl + W` | Сеть |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | Дисплей |
| `Super + Ctrl + P` | Питание |
| `Super + Ctrl + Alt + D` | Календарь |
| `Super + Ctrl + Alt + E` | Мировые часы |
| `Super + Ctrl + 1-9` | Переключить n-ю панель в правой секции |

Панели — не просто отображение данных. Именно там вы действительно делаете дело:

- **Аудио** имеет главный слайдер громкости, выбор устройства вывода и микшер для каждого приложения, чтобы можно было убавить одну вкладку браузера, не трогая всё остальное.
- **Сеть** сканирует Wi-Fi, показывает уровень сигнала, подключается и позволяет выбрать провайдера DNS.
- **Bluetooth** перечисляет ваши устройства с подключением/отключением и уровнями батареи.
- **Питание** показывает статистику батареи, переключает профили питания (запоминает отдельный выбор для батареи и сети переменного тока) и печатает некоторую системную информацию.
- **Дисплей** несёт слайдер яркости, размер текста, пресеты масштабирования монитора и — когда у вас несколько экранов — элементы управления для каждого монитора. См. [мониторы](33-monitors.md) для более глубокой истории.
- **Часы** открывают сетку месяца с номерами недель ISO и переключением месяцев.

Каждая панель принимает клавиатуру, а также мышь: стрелки перемещают, Return активирует, Tab переходит к соседней панели, а Escape закрывает.

`Super + Ctrl + 1-9` считает панели слева направо в правой секции, пропуская трей, поскольку у него нет собственной панели. Так что число соответствует значку, на который вы бы указали.

### Tailscale и Dropbox

Ещё два виджета появляются на панели только после установки соответствующей службы из **Установить → Служба**, и оба стоит знать, потому что они делают больше, чем сообщают статус.

Панель **Tailscale** подключает и отключает tailnet, переключается между аккаунтами и выбирает выходной узел (ваши собственные машины и регионы Mullvad оба появляются в этом списке). Она также просматривает ваши машины — и при выбранной машине `s` отправляет ей файлы через Taildrop, что является самым быстрым способом переместить файл на телефон или другой ноутбук. `c` копирует IP машины, `n` — её имя, а `d` — полное DNS-имя. На каждой строке машины также есть кнопка отправки, если вы предпочитаете щёлкать. То же самое из терминала — `omarchy tailscale send <machine> [file...]`.

Панель **Dropbox** обрабатывает вход, показывает, сколько хранилища вы использовали, и перечисляет недавно синхронизированные файлы.

Удаление любой службы убирает её виджет с панели.

## Индикаторы

Маленький кластер в центре — это виджет индикаторов. Это глифы состояния для режимов, которые вы включили: не беспокоить, ночной свет, поставленное в очередь [напоминание](09-reminders.md), активная запись экрана, не засыпать и [диктовка](11-text-extraction-dictation.md). Они загораются, когда режим активен, и в противном случае не мешают — наведите курсор слева от часов (над ними на вертикальной панели), чтобы взглянуть на неактивные. Щелчок по индикатору переключает этот режим. Ещё один — только статус: удалённая сессия загорается красным, пока кто-то подключён к этой машине через gliff.

Если вы предпочитаете, чтобы они всегда были видимы, установите `alwaysShow` в `true` на виджете. А если вас интересуют только некоторые из них, перечислите нужные в `items`: `["Dnd", "Reminder", "NightLight"]`. Можно иметь несколько виджетов индикаторов, чтобы разные секции показывали разные подмножества.

## Перестановка панели

Панель настраивается сама. Вам не нужно открывать файл конфигурации, чтобы что-то переместить.

Возьмите пустой участок панели вокруг центра и перетащите его к другому краю экрана, и панель переместится туда — слева, справа, сверху или снизу всё работает, и каждый виджет адаптируется (вертикальные панели возвращаются к компактным формам только со значками). Щелчок и удержание начинает то же перетаскивание. Дважды щёлкните левой кнопкой мыши по тому же пустому месту, чтобы циклически изменить фон панели от прозрачного к стеклянному и непрозрачному. И перетащите любой виджет, чтобы переупорядочить его или бросить в другую секцию.

Виджет, который нужен под рукой, но не должен всегда быть на виду, можно поместить в ящик трея: перетащите его на трей — и ящик откроется, чтобы его принять. Он расположится там после значков приложений, будет появляться всякий раз вместе с ящиком и не даст ящику закрыться, пока открыта его панель. Чтобы вернуть его обратно, перетащите его из ящика на панель.

Если вы предпочитаете выбирать из меню, в **Действия → Внешний вид → Панель меню** есть положение, а **Фон панели** выбирает, как отрисовывается панель: **Непрозрачная панель**, **Стеклянная панель** (просвечивающая, с размытием того, что за ней) или **Прозрачная панель**.

Для тех же вещей есть команды, что и нужно для настройки [dotfiles](31-dotfiles.md):

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.clock --section center --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

Чтобы добавить или удалить виджет полностью, используйте команды плагинов. `omarchy plugin list` печатает каждый виджет, известный оболочке, с его id, а затем:

```bash
omarchy plugin enable omarchy.media --section center
omarchy plugin disable omarchy.weather
```

## Скрытие панели

`Super + Shift + Space` переключает панель выкл и обратно вкл, не убивая оболочку — панели и сочетания клавиш продолжают работать, вы просто возвращаете пиксели. Это также есть в меню в **Действия → Внешний вид → Панель меню → Скрыть панель**.

## Файл конфигурации

Всё хранится в `~/.config/omarchy/shell.json` под ключом `bar`. Вот сокращённая версия:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "centerAnchor": "omarchy.clock",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

Каждый виджет — одна запись в одном из трёх массивов раскладки, а его настройки находятся прямо в этой записи — нет отдельного файла настроек и нет подобъекта `config`. `format`, `formatAlt` часов (на что переходит правый щелчок) и `verticalFormat` живут прямо там, в `{ "id": "omarchy.clock" }`.

`centerAnchor` называет один центральный виджет, который закрепляется точно в центре экрана, а остальные располагаются по бокам. Именно так часы остаются строго по центру, даже когда погода и бейдж обновления приходят и уходят. Установите его в пустую строку, и центральный список просто центрируется как группа.

Одно правило стоит усвоить: **как только у вас есть собственный `shell.json`, он каноничен**. Пока вы ничего не настраивали, оболочка читает файл Omarchy по умолчанию. В момент, когда вы перетаскиваете виджет, запускаете `omarchy bar` или редактируете файл сами, вы становитесь его владельцем — нет глубокого слияния, поэтому новые виджеты по умолчанию в будущих релизах Omarchy не появятся на вашей панели автоматически. `omarchy bar defaults` возвращает поставляемую раскладку, когда нужен чистый лист.

Тот же файл также хранит ваши тайминги простоя на верхнем уровне, вне ключа `bar`: `idle.screensaver` и `idle.lock`, оба в секундах с момента перехода в простой. Так, заставка по умолчанию срабатывает через 150 секунд, а блокировка — через 300.
