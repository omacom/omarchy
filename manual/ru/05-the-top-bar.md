# Верхняя панель

Полоса вдоль верхней части экрана — это панель Omarchy. Это не прикрученная сбоку панель состояния, а часть оболочки Omarchy, единого долгоживущего процесса Quickshell, который также рисует меню, уведомления, всплывающие окна OSD и экран блокировки. Поэтому она идеально оформлена в одной теме со всем остальным, а панель открывается мгновенно, вместо того чтобы запускать новое приложение.

Она же — единственный элемент рабочего стола, который всегда находится на экране, поэтому стоит знать, что делают все эти маленькие значки.

## Что на ней по умолчанию

Панель состоит из трёх секций. Слева находятся логотип Omarchy (средство запуска меню) и индикаторы рабочих пространств. В центре — индикаторы состояния, часы, Elsewhen (мировые часы), погода и значок обновления Omarchy. Справа: системный трей, раскладка клавиатуры (когда настроено больше одной), агенты, bluetooth, сеть, аудио, дисплей и питание.

Некоторые из них появляются только тогда, когда им есть что сказать. Раскладка клавиатуры появляется только если вы настроили больше одной раскладки. Значок обновления появляется только когда ждёт обновление Omarchy. А значок агентов появляется при первом обнаружении Omarchy использования ИИ для кодинга на машине (см. [ИИ](17-ai.md)).

## Щелчки по панели

Почти каждый виджет что-то делает при левом, правом и среднем щелчке, а несколько из них реагируют на прокрутку. Именно это люди и упускают — за правой и средней кнопками скрывается много хорошего.

| Виджет | Левый | Правый | Средний / прокрутка |
| --- | --- | --- | --- |
| Меню | Меню Omarchy | Новый терминал | — |
| Рабочие пространства | Сфокусировать это рабочее пространство на этом мониторе | — | Прокрутка: следующее/предыдущее рабочее пространство |
| Часы | Всплывающее окно календаря | Переключить формат подписи | Средний: выбор часового пояса |
| Погода | Всплывающее окно прогноза | Полная погода в виде уведомления | Средний: обновить |
| Аудио | Панель аудио | Отключить звук | Средний: панель · прокрутка: громкость |
| Микрофон | Отключить микрофон | — | Средний: панель аудио · прокрутка: громкость входа |
| Сеть | Панель сети | — | — |
| Bluetooth | Панель Bluetooth | Включить/выключить радио | — |
| Дисплей | Панель дисплея | — | Прокрутка: яркость |
| Питание | Панель питания | Включить/выключить процент заряда батареи | — |
| Медиа | Воспроизведение/пауза | Всплывающее окно с обложкой | Средний: следующее · прокрутка: предыдущее/следующее |
| Агенты | Панель агентов | Запустить вашего агента | Средний: следующая подписка |
| Трей | Наведите курсор, чтобы открыть выдвижную панель | Правый щелчок по шеврону для управления | — |
| Обновление Omarchy | Запустить обновление | — | — |

Не всё в этой таблице есть на вашей панели из коробки. Виджет медиа (MPRIS now-playing, с прокручивающимися дорожкой и исполнителем) и виджет микрофона встроены, но по умолчанию отключены — добавьте их, если хотите, как описано ниже.

## Панели

Щелчок по значку на панели открывает панель — полноценное всплывающее окно с ползунками, списками и навигацией с клавиатуры, а не подсказку. У каждой есть и горячая клавиша, так что целиться в глиф размером 16 пикселей не нужно:

| Горячая клавиша | Панель |
| --- | --- |
| `Super + Ctrl + A` | Аудио |
| `Super + Ctrl + N` | Сеть |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | Дисплей |
| `Super + Ctrl + P` | Питание |
| `Super + Ctrl + Alt + D` | Календарь |
| `Super + Ctrl + Alt + E` | Мировые часы |
| `Super + Ctrl + 1-9` | Включить/выключить n-ю панель в правой секции |

Панели — это не просто показания. Именно в них вы реально делаете дело:

- **Аудио** имеет главный ползунок громкости, выбор устройства вывода и микшер по приложениям, так что вы можете убавить звук одной вкладки браузера, не трогая всё остальное.
- **Сеть** сканирует Wi-Fi, показывает уровень сигнала, подключается и позволяет выбрать провайдера DNS.
- **Bluetooth** перечисляет ваши устройства с подключением/отключением и уровнями заряда батареи.
- **Питание** показывает статистику батареи, переключает профили питания (запоминает отдельный выбор для батареи и для AC) и выводит некоторую системную информацию.
- **Дисплей** содержит ползунок яркости, размер текста, пресеты масштабирования монитора и — когда у вас больше одного экрана — элементы управления для каждого монитора. Более подробно см. [мониторы](33-monitors.md).
- **Часы** открывают сетку месяца с номерами недель ISO и переходом по месяцам.
- **Мировые часы** содержат строку для каждого города, с его погодой и тем, как проходит его день. Поиск находит города, а также часовые пояса, поэтому Fort Lauderdale — это Fort Lauderdale, а не New York. Если в строке сверху назван не тот город, щёлкните по ней и укажите, где вы находитесь; выберите место в другом часовом поясе, и системные часы тоже переместятся туда, что удобно в путешествии. Наведите курсор на город и щёлкните кнопку с человеком, чтобы указать, кто там живёт, — обычными именами или дескрипторами GitHub с `@`, чтобы подтянуть и их фотографии.

Каждая панель управляется с клавиатуры так же, как и мышью: стрелки перемещают, Return активирует, Tab переходит к соседней панели, а Escape закрывает.

`Super + Ctrl + 1-9` считает панели слева направо в правой секции, пропуская трей, поскольку у него нет собственной панели. Так что номер соответствует значку, на который вы бы указали.

### Tailscale и Dropbox

Ещё два виджета появляются на панели только после установки соответствующей службы из **Install → Service**, и о обоих стоит знать, потому что они не просто сообщают состояние.

Панель **Tailscale** подключает и отключает tailnet, переключается между учётными записями и выбирает выходной узел (в этом списке появляются и ваши собственные машины, и регионы Mullvad). Она также просматривает ваши машины — и когда одна из них выбрана, `s` отправляет на неё файлы через Taildrop, что является самым быстрым способом перенести файл на телефон или другой ноутбук. `c` копирует IP машины, `n` — её имя, а `d` — её полное имя DNS. На каждой строке машины есть и кнопка отправки, если вы предпочитаете щёлкать. То же самое из терминала — `omarchy tailscale send <machine> [file...]`.

Панель **Dropbox** управляет входом, показывает, сколько хранилища вы использовали, и перечисляет недавно синхронизированные файлы.

Удаление любой из служб убирает её виджет обратно с панели.

## Индикаторы

Маленькая группа в центре — это виджет индикаторов. Это глифы состояния для включённых вами режимов: не беспокоить, ночная подсветка, поставленное в очередь [напоминание](09-reminders.md), активная запись экрана, не засыпать и [диктовка](11-text-extraction-dictation.md). Они загораются, когда режим активен, а в остальное время не мешают — наведите курсор в любом месте панели, чтобы взглянуть на неактивные. Щелчок по индикатору включает или выключает этот режим. Ещё один работает только как состояние: удалённый сеанс горит красным, пока кто-то подключён к этой машине через gliff.

Если вы предпочитаете, чтобы они всегда были видны, установите `alwaysShow` в `true` на виджете. А если вас интересуют только некоторые из них, перечислите нужные в `items`: `["Dnd", "Reminder", "NightLight"]`. У вас может быть больше одного виджета индикаторов, так что разные секции могут показывать разные подмножества.

## Перестановка панели

Панель настраивает себя сама. Чтобы перемещать элементы, не нужно открывать файл конфигурации.

Возьмите пустой участок панели вокруг центра и перетащите его к другому краю экрана, и панель переместится туда — слева, справа, сверху или снизу, всё работает, и каждый виджет адаптируется (вертикальные панели переходят к компактным формам только со значками). Нажатие и удержание начинает то же перетаскивание. Дважды щёлкните левой кнопкой по тому же пустому месту, чтобы циклически сменить фон панели с прозрачного на стеклянный и на непрозрачный. И перетаскивайте любой виджет, чтобы изменить его порядок или бросить его в другую секцию; остальные виджеты раздвинутся, чтобы освободить место там, где он приземлится.

Середина панели — это ящик: всё, что в нём находится, остаётся центрированным как одна группа, а виджеты с обеих его сторон свисают с его краёв. Пока вы перетаскиваете виджет, ящик отображается как контур или как линия поперёк панели, когда он пуст, и вы можете бросить виджет в него или рядом с ним. Когда бросок должен был бы приземлиться в ящике, ящик расширяется, чтобы принять виджет.

Виджет, который вы хотите держать под рукой, но не всегда на виду, может отправиться в выдвижную панель трея: перетащите его на трей, и выдвижная панель откроется, чтобы принять его. Он находится там после значков приложений, появляется всякий раз, когда появляется выдвижная панель, и держит свою выдвижную панель открытой, пока его панель поднята. Перетащите его обратно на панель, чтобы вернуть его на место.

Если вы предпочитаете выбирать из меню, в **Appearance → Menu Bar** есть позиция, а **Bar Background** выбирает, как рисуется панель: **Opaque Bar**, **Glassy Bar** (прозрачная, с размытием того, что за ней) или **Clear Bar**.

Те же вещи имеют команды, а именно это вам и нужно для настройки [dotfiles](31-dotfiles.md):

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

Чтобы добавить или полностью удалить виджет, используйте команды плагинов. `omarchy plugin list` выводит каждый виджет, известный оболочке, с его id, а затем:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## Скрытие панели

`Super + Shift + Space` выключает и снова включает панель, не убивая оболочку — панели и горячие клавиши продолжают работать, вы просто возвращаете себе пиксели. Это также есть в меню в **Appearance → Menu Bar → Hide Bar**.

## Файл конфигурации

Всё это хранится в `~/.config/omarchy/shell.json`, под ключом `bar`. Вот сокращённая версия:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "opaque",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

Каждый виджет — это одна запись в одном из пяти массивов компоновки, а его настройки находятся прямо в этой записи — отдельного файла настроек и подобъекта `config` нет. `format`, `formatAlt` (то, на что циклически переключает правый щелчок) и `verticalFormat` часов находятся прямо там, в `{ "id": "omarchy.clock" }`.

`center` — это ящик в середине панели: всё в нём центрируется на экране как одна группа. `centerBegin` и `centerEnd` свисают с обеих сторон ящика, именно так часы остаются точно по центру, даже когда погода и значок обновления появляются и исчезают. Поместите больше одного виджета в `center`, и они будут центрированы вместе; оставьте его пустым, и `centerBegin` с `centerEnd` встретятся в середине панели.

Одно правило, которое стоит усвоить: **как только у вас есть собственный `shell.json`, он каноничен**. Пока вы ничего не настраиваете, оболочка читает файл Omarchy по умолчанию. В тот момент, когда вы перетаскиваете виджет, запускаете `omarchy bar` или редактируете файл сами, вы владеете им — глубокого слияния нет, поэтому новые виджеты по умолчанию в будущих выпусках Omarchy не появятся на вашей панели автоматически. `omarchy bar defaults` возвращает поставляемую компоновку всякий раз, когда вы хотите начать с чистого листа.

Тот же файл содержит и ваши тайминги простоя на верхнем уровне, вне ключа `bar`: `idle.screensaver` и `idle.lock`, оба в секундах с момента, когда вы ушли в простой. Так что заставка по умолчанию включается через 150 секунд, а блокировка — через 300.
