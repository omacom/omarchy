# Аппаратная аутентификация

### Аутентификация по отпечатку пальца

Многие ноутбуки оснащены датчиком отпечатков пальцев для аутентификации. Вы можете использовать его в Omarchy, запустив _Setup > Security > Fingerprint_ в меню Omarchy (`Super + Space`).

При этом откроется изображение отпечатка пальца на весь экран, которое будет заполняться по мере касания датчика. За кулисами Omarchy установит пакет для работы с отпечатками пальцев, снимет ваш отпечаток, проверит его — и вы сможете использовать отпечаток пальца для разблокировки с экрана блокировки (который можно вызвать сочетанием `Super + Ctrl + L`), входа в режим sudo и подтверждения системных запросов.

Когда экран блокировки выключит дисплей, датчик переходит в режим покоя для экономии энергии, поэтому перед касанием датчика разбудите экран любой клавишей или касанием тачпада.

Когда крышка ноутбука закрыта, запрос отпечатка пальца автоматически пропускается, и вы сразу переходите к вводу пароля, а не ждёте датчик, до которого не можете дотянуться. Если вам нужно работать на внешней клавиатуре без датчика, просто нажмите `CTRL + C`, когда во время `sudo` появится запрос отпечатка пальца.

Удалить аутентификацию по отпечатку пальца можно в пункте _Remove > Security > Fingerprint_ в меню Omarchy.

### Аутентификация Fido2

Если вы используете устройство Fido2, вы можете настроить его для аутентификации `sudo` с помощью пункта _Setup > Security > Fido2_ в меню Omarchy (`Super + Space`). Однако это распространяется на `sudo` и запросы системной авторизации, а не на разблокировку компьютера.

Удалить аутентификацию fido2 можно в пункте _Remove > Security > Fido2_ в меню Omarchy.
