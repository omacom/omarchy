# Дотфайлы

Omarchy настраивается в основном через так называемые дотфайлы, которые живут в `~/.config`. Считайте, что это ваши файлы для ваших изменений. Файлы, которые живут в `/usr/share/omarchy`, принадлежат самой Omarchy, и соваться в них не стоит. Если вам нужно изменить что-то в `/usr/share/omarchy`, вместо этого следует переопределить значение в `~/.config`.

Основные конфиги можно редактировать прямо из меню Omarchy (`Super + Space`), например _Настройка > Сочетания клавиш_, _Настройка > Ввод_ и _Настройка > Конфигурация > [файл]_. Когда вы делаете это таким способом, любой процесс, который нужно перезапустить после правок конфига, будет перезапущен автоматически после того, как вы выйдете из редактора (по умолчанию это Neovim — `:wq`, не забудьте! — но это можно изменить через _Настройка > По умолчанию > Редактор_).

Вот список ключевых файлов в `~/.config` и того, чем они управляют:

| Файл | Назначение |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | Главный конфиг Hyprland. Загружает настройки Omarchy по умолчанию плюс ваши файлы переопределений ниже. [Подробнее о конфигах Hyprland](https://wiki.hypr.land/Configuring/). |
| `~/.config/hypr/bindings.lua` | Ваши собственные сочетания клавиш и переопределения настроек по умолчанию. |
| `~/.config/hypr/monitors.lua` | Настройки монитора, которые не покрывает панель мониторов, например поворот, дополнительные режимы или отключённое состояние монитора. |
| `~/.config/hypr/input.lua` | Управляет раскладкой клавиатуры, настройками мыши и тачпада. |
| `~/.config/hypr/looknfeel.lua` | Управляет зазорами, рамками, анимациями и остальными аспектами внешнего вида. |
| `~/.config/hypr/autostart.lua` | Управляет дополнительными процессами, запускаемыми вместе с сеансом. |
| `~/.config/omarchy/shell.json` | Управляет оболочкой Omarchy: положением панели, компоновкой и виджетами, а также заставкой, блокировкой и таймингами простоя. |
| `~/.config/foot/foot.ini` | Управляет вашим терминалом (по умолчанию это foot). |
| `~/.XCompose` | Определяет ваши эмодзи для быстрого доступа и автодополнение имени/email. Не забудьте выполнить `omarchy-restart-xcompose` после внесения изменений. |

Если в итоге вы внесёте много изменений, настраивая всё под себя, будет хорошей идеей сделать резервную копию всех этих дотфайлов. [Stow — отличный способ это сделать](https://www.youtube.com/watch?v=NoFiYOqnC4o).

### Запуск своих приложений вместе с сеансом

Если вы хотите, чтобы что-то запускалось каждый раз при входе в систему — демон синхронизации, приложение для чата, ваш собственный скрипт, — поместите это в `~/.config/hypr/autostart.lua`:

```lua
o.launch_on_start("my-service")
```

Так команда запустится как часть сеанса, и при выходе из системы всё будет корректно завершено.

### Запуск скриптов при системных событиях

Omarchy срабатывает хуками в несколько моментов, и вы можете навесить на них свои скрипты. Они живут в `~/.config/omarchy/hooks/<event>.d/`, по одному каталогу на событие, и каждый исполняемый файл внутри запускается, когда событие происходит:

| Событие | Когда запускается |
| ----- | ------------ |
| `post-boot` | Сразу после запуска рабочего стола |
| `post-update` | Ближе к концу `omarchy update`, после пакетов, миграций и перезапуска служб, до обновления инструментов mise |
| `pre-refresh-pacman` | После того как `omarchy refresh pacman` повторно синхронизирует конфигурацию пакетов, до того как она обновит пакеты; переключение канала запускает его на том же шаге обновления |
| `theme-set` | После смены темы (название темы в `$1`) |
| `font-set` | После смены шрифта (название шрифта в `$1`) |
| `battery-low` | Когда заряд батареи становится низким (процент в `$1`) |

Хук `pre-refresh-pacman` — это место, где должны находиться пользовательские репозитории или строки `IgnorePkg`, поскольку он запускается до транзакции пакетов. Оба связанных с обновлением хука запускаются от вашего пользователя после того, как Omarchy сбрасывает кэшированную авторизацию sudo, поэтому хуку, использующему `sudo`, нужна собственная авторизация, и он может запросить ваш пароль.

В каждом из этих каталогов уже лежит файл `.sample`, показывающий, как должен выглядеть хук, — уберите `.sample` из названия, чтобы он заработал. Чтобы установить скрипт, написанный вами в другом месте, используйте `omarchy hook install post-boot ~/my-hook` — команда скопирует его туда и сделает исполняемым.

### Добавление своих пунктов меню

Меню Omarchy (`Super + Space`) можно расширить своими строками, отредактировав `~/.config/omarchy/extensions/omarchy-menu.jsonc`. Записи задаются точечным id, и именно id определяет их место в дереве, поэтому `personal` появится в корневом меню, а `personal.notes` — внутри него:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

Переиспользуйте существующий id — и вы переопределите эту строку вместо добавления новой. В поставляемом файле все доступные поля задокументированы в виде комментариев.

### Добавление собственных экспортов, функций и алиасов оболочки

Omarchy поставляется с кучей эргономичных алиасов и полезных функций, но очень часто хочется добавить свои. И алиасы, и функции, и экспорты следует добавлять в `~/.bashrc`. Этот файл не будет перезаписан при обновлениях. Если вы хотите изменить какие-либо настройки Omarchy по умолчанию, их тоже можно спокойно добавить сюда.

### Изменение внутренних файлов Omarchy

Слушайте, это ваш компьютер. Вы можете делать с ним что угодно, но я бы не советовал вносить изменения напрямую в файлы в `/usr/share/omarchy`. Они принадлежат пакету Omarchy в pacman, поэтому ваши изменения просто будут перезаписаны при следующем обновлении. Лучше просто переопределите любые значения по умолчанию, которые вам не нравятся, в папке `~/.config/*`.

Таким способом можно изменить практически всё, например сочетания клавиш по умолчанию. Просто отредактируйте `~/.config/hypr/bindings.lua`, чтобы, скажем, заменить [Obsidian](https://obsidian.md/) на [Joplin](https://joplinapp.org/) (устанавливается командой `omarchy-pkg-add joplin-bin`):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` удаляет существующее сочетание перед добавлением замены. Она принимает те же аргументы, что и `o.bind`, включая помощники запуска и параметры сочетаний. Используйте `o.bind`, чтобы добавить сочетание, или `hl.unbind`, чтобы удалить его без замены.

Если вы настаиваете на том, чтобы ковыряться во внутренних файлах Omarchy, переключитесь на канал dev через _Обновление > Канал > Dev_. Это привяжет Omarchy к git-копии исходного кода в `~/omarchy`, которую вы вольны менять сколько душе угодно. Никто здесь не будет указывать вам, что делать!

### Сброс всех изменений

Если в итоге вы наведёте бардак в конфигурациях, вы всегда можете вернуть их к значениям по умолчанию через _Обновление > Конфигурация_ в меню Omarchy. Или выполнив `omarchy reinstall configs`, чтобы сбросить всё.
