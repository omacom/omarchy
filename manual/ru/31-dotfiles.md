# Дотфайлы

Omarchy в основном конфигурится через так называемые дотфайлы в `~/.config`. Это считается твоими файлами под твои правки. Файлы в `/usr/share/omarchy` принадлежат самой Omarchy — туда не лезь. Если надо поменять что-то из `/usr/share/omarchy` — перезаписывай значение в `~/.config` вместо этого.

Ключевые конфиги правятся прямо из меню Omarchy (`Super + Space`): вроде _Настройки > Мониторы_, _Настройки > Хоткеи_, _Настройки > Ввод_ и _Настройки > Конфиг > [файл]_. Так любой процесс, которому нужен рестарт после правок конфигов, рестартнет сам, как выйдешь из редактора (Neovim по умолчанию — `:wq`, помни! — а меняется через _Настройки > Приложения по умолчанию > Редактор_).

Вот список ключевых файлов в `~/.config` и что они рулят:

| Файл                  | Назначение              |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | Главный конфиг Hyprland. Тянет дефолты Omarchy плюс твои оверрайды ниже. [Про конфиги Hyprland подробнее](https://wiki.hypr.land/Configuring/).  |
| `~/.config/hypr/bindings.lua` | Свои хоткеи и оверрайды дефолтных. |
| `~/.config/hypr/monitors.lua` | Рулит мониторами, резолюцией и позицией. |
| `~/.config/hypr/input.lua` | Рулит раскладкой, мышью и тачпадом. |
| `~/.config/hypr/looknfeel.lua` | Рулит гэпами, бордюрами, анимациями и остальным луком. |
| `~/.config/hypr/autostart.lua` | Рулит лишними процессами со стартом сессии. |
| `~/.config/omarchy/shell.json` | Рулит шеллом Omarchy: позиция панели, layout и виджеты, плюс тайминги скринсейвера, лока и простоя. |
| `~/.config/foot/foot.ini` | Рулит терминалом (foot по умолчанию). |
| `~/.XCompose` | Задаёт быстрые эмодзи и нейм/почта-автокомплит. После правок прогони `omarchy-restart-xcompose`. |

Накопил кучу правок под свой сетап — забэкапь все эти дотфайлы. [Stow — отличный способ](https://www.youtube.com/watch?v=NoFiYOqnC4o).

### Свои приложения со стартом сессии

Хочешь, чтобы что-то бежало при каждом логине — синк-демон, чат-приложение, свой скрипт, — клади в `~/.config/hypr/autostart.lua`:

```lua
o.launch_on_start("my-service")
```

Стартует команду частью сессии — при логауте приберётся как положено.

### Свои скрипты на системные события

Omarchy палит хуки в горсти моментов — свои скрипты вешаются на них. Живут в `~/.config/omarchy/hooks/<event>.d/` — по каталогу на событие, и каждый исполняемый файл там бежит, когда событие случается:

| Событие | Когда бежит |
| ----- | ------------ |
| `post-boot` | Сразу как десктоп поднялся |
| `post-update` | К концу `omarchy update`: после пакетов, миграций и рестартов сервисов, до обновления mise-тул |
| `pre-refresh-pacman` | После того как `omarchy refresh pacman` пересинкнул конфиг пакетов, до обновления пакетов; смена канала гоняет его на том же шаге рефреша |
| `theme-set` | После смены темы (имя темы в `$1`) |
| `font-set` | После смены шрифта (имя шрифта в `$1`) |
| `battery-low` | Когда батарея просела (процент в `$1`) |

Хук `pre-refresh-pacman` — туда кастомные репозитории и строки `IgnorePkg`: он бежит до пакетной транзакции. Оба апдейтных хука бегут от твоего юзера после того, как Omarchy сбросит закешированную sudo-авторизацию, — так что хук с `sudo` нуждается в своей авторизации и может спросить пароль.

В каждом из каталогов уже лежит `.sample`-файл, показывающий форму хука, — сними `.sample` с имени, чтобы заработал. Скрипт, написанный в другом месте, ставится через `omarchy hook install post-boot ~/my-hook` — скопирует и сделает исполняемым.

### Свои пункты меню

Меню Omarchy (`Super + Space`) расширяется своими строками правкой `~/.config/omarchy/extensions/omarchy-menu.jsonc`. Записи keyed dotted id, и id кладёт их в дерево: `personal` покажется в корневом меню, а `personal.notes` — внутри него:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"","label":"Notes","action":"omarchy-launch-editor ~/notes"},
```

Переиспользуй существующий id — перезапишешь ту строку вместо добавления новой. Файл из коробки со всеми доступными полями, расписанными комментами.

### Свои шелл-экспорты, функции и алиасы

В Omarchy из коробки куча эргономичных алиасов и полезных функций, но своё добавлять — обычно: и алиасы, и функции, и экспорты клади в `~/.bashrc`. Этот файл обновлениями не затрут. Дефолты Omarchy поменять — тоже сюда можно, спокойно.

### Правка внутренних файлов Omarchy

Слушай, это твой компьютер. Твори с ним что хочешь, но я бы не советовал лезть править файлы в `/usr/share/omarchy` напрямую. Они принадлежат pacman-пакету Omarchy — правки просто затрутся на следующем обновлении. Лучше перезаписывай не нравящиеся дефолты в папке `~/.config/*`.

Этим путём меняется почти всё — вроде дефолтных хоткеев. Просто правь `~/.config/hypr/bindings.lua`: скажем, замени [Obsidian](https://obsidian.md/) на [Joplin](https://joplinapp.org/) (ставится через `omarchy-pkg-add joplin-bin`):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` сначала снимает существующий хоткей, потом добавляет замену. Аргументы те же, что у `o.bind`, включая лаунч-хелперы и опции хоткеев. Через `o.bind` добавляешь хоткей, через `hl.unbind` — снимаешь без замены.

Упоролся хакать внутренние файлы Omarchy — переключайся на dev-канал через _Обновить > Канал > Dev_. Он линкует Omarchy на git-чекаут исходников в `~/omarchy` — меняй вволю, сколько влезет. Тут тебе никто не указ!

### Сброс любых правок

Намесил в конфигах кашу — всегда можно откатить к дефолтам через _Обновить > Конфиг_ в меню Omarchy. Или через `omarchy reinstall configs`, чтобы сбросить всё.
