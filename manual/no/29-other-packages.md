# Andre pakker

Arch har en fantastisk rikdom av pakker tilgjengelig for nesten enhver type programvare mellom det offisielle repoet og Arch User Repository (AUR).

Det kunne ikke vært enklere å bruke heller. Du installerer en ny Arch-pakke ved å gå til _Installer > Pakke_ i Omarchy-menyen (`Super + Space`) og skrive pakken du vil ha. Den filtrerer fuzzy-listen over alle pakker automatisk. (Du kan også gjøre det manuelt med `omarchy pkg add [package]` i terminalen).

Du kan gjøre det samme med AUR, bare bruk _Installer > AUR_. Bare husk at AUR ikke er kontrollert av Arch-teamet. Det er som RubyGems eller npm. Hvem som helst kan laste opp.

Hvis du vil fjerne en pakke, kan du bruke _Fjern > Pakke_ fra Omarchy-menyen. Den fjerner pakken, konfigurasjonsfilene og avhengigheter. (Du kan også gjøre det manuelt med `omarchy pkg drop [package]`).
