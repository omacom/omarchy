# Påminnelser

Omarchy har en innebygd måte å sette enkle påminnelser på, basert på en nedtellingsur og med en melding. Du kan gjøre dette via `Super + Ctrl + R`, se alle som er satt via `Super + Ctrl + Alt + R`, og fjerne alle via `Super + Ctrl + Shift + R`. Alt er også tilgjengelig via _Utløs > Påminnelse_. Du kan også bruke CLI-et med `omarchy reminder 7 'Tea ready'`.
