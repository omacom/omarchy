# Ubao wa Kunakili Uliounganishwa & Historia

Kawaida kwenye Linux, unahitaji `Ctrl + Shift + C/V` kunakili na kubandika kwenye terminal na `Ctrl + C/V` kufanya hivyo kila mahali pengine. Ni vigumu kuzoea kwa mtu yeyote ambaye hakuzaliwa na kulelewa kwenye Linux! Vivyo hivyo kubadili kutoka super hadi ctrl, kama unatoka kwenye Mac.

Omarchy inatatua matatizo yote mawili kwa vitufe vya haraka vya ubao wa kunakili vilivyounganishwa vinavyofanya kazi (karibu) kila mahali. Ndivyo hivi:

| Hotkey | Command |
| ------- | ----------- |
| Super + A | Chagua vyote |
| Super + C | Nakili |
| Super + X | Kata |
| Super + V | Bandika |
| Super + Ctrl + V | Historia ya ubawo wa kunakili |

_Kumbuka kuwa zana nyingi za agent zitatumia `Ctrl + V` kubandika picha, lakini `Super + V` kubandika maandishi._

Tumia `Super + A`, kisha `Super + C` kunakili kila kitu katika sehemu ya maandishi iliyolengwa au programu nyingine inayounga mkono `Ctrl + A`. Kwenye terminal, `Ctrl + A` huhamia mwanzo wa mstari wa amri badala ya kuchagua maandishi yake.

### Historia ya ubao wa kunakili

Historia ya ubao wa kunakili hutolewa na Omarchy shell na hufanya kazi kwa maandishi na picha zote mbili. Huiwasha kwa `Super + Ctrl + V` na kuchagua ingizo lako kwa return, ambayo hubandika moja kwa moja kwenye programu uliyokuwa ndani yake. Tumia `Shift + Return` kuilnakili tu kwenye ubao wa kunakili, `Alt + Return` kuifungua, `Delete` kuiondoa kutoka kwenye historia, na `Shift + Delete` kufuta historia nzima.
