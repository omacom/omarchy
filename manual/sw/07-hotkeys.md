# Vifunguo vya Mkato

Unaweza kuona vifunguo vyote vikuu vya kibodi kwa `Super + K` (vifunguo vya Tmux kwa `Super + Alt + K` na vifunguo vya Herdr kwa `Super + Ctrl + K`).

| `Ctrl + Alt + Tab`| Zunguka lengo mbele kupitia vifuatilia |
| `Ctrl + Alt + Shift + Tab`| Zunguka lengo nyuma kupitia vifuatilia |

Vifunguo vya mkato vya kubadilisha ukubwa hutumia vitufe halisi `code:20` na `code:21` (XKB `<AE11>` na `<AE12>`), bila kujali herufi zilizochapishwa kwenye kibodi. Kwenye kibodi za US vitufe hivi ni `-` na `=`; kwenye kibodi za Kijapani (JIS) ni `-` na `^`; kwenye kibodi za Kihispania ni `'` na `¡`. Kwenye JIS, `Super + ^` ni `Super + Equal`, wakati `Super + Shift + -` (ambayo huchapa `=`) ni `Super + Shift + Minus`.

## Ubao wa kunakili wa jumla

| Kifunguo cha Mkato                  | Kazi              |
| ----------------------- | --------------------- |
| `Super + A`           | Chagua vyote katika programu zinazotumia `Ctrl + A`    |
| `Super + C`           | Nakili    |
| `Super + X`           | Kata (sio katika terminali)    |
| `Super + V`           | Bandika    |
| `Super + Ctrl + V`           | Kidhibiti cha ubao wa kunakili    |

Kwa kawaida kwenye Linux, unahitaji `Ctrl + Shift + C/V` kunakili na kubandika katika terminali na `Ctrl + C/V` kufanya hivyo kila mahali pengine. Vifunguo hivi vya mkato vya ubao wa kunakili vilivyounganishwa vya Omarchy hufanya kazi kila mahali.

## Kunasa

| Kifunguo cha Mkato              | Kazi                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Picha ya skrini                      |

| `Super + Ctrl + C` | Menyu ya kunasa |
| `Alt + Print Screen`            | Rekodi ya skrini                     |
| `Super + Print Screen` | Kichaguzi cha rangi |
| `Super + Ctrl + Print Screen` | Kutoa maandishi hadi kwenye ubao wa kunakili |
| `Super + Alt + [` | Fanya wekeleo la webcam kuwa dogo zaidi wakati wa kurekodi |

| `Alt + Shift + L` | Nakili URL ya sasa kutoka kwenye webapp au Chromium |
| `Alt + Shift + D` | Pakua video iliyo kwenye ukurasa wa sasa hadi `~/Videos` |

Kwa rekodi za skrini, kifunguo cha mkato kwanza huuliza sauti unayotaka, kisha huanza kurekodi. Kibonyeze tena kusimamisha. Tazama [picha za skrini na kurekodi](12-screenshots-recording.md) kwa maelezo.

Chaguo zote za kunasa pia zinapatikana chini ya _Trigger > Capture_ katika menyu ya Omarchy (`Super + Space`).

## Tmux
