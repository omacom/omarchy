# Mikato ya Kibodi

Unaweza kuona vifungo vyote vikuu vya kibodi kwa `Super + K` (vifungo vya Tmux kwa `Super + Alt + K` na vifungo vya Herdr kwa `Super + Ctrl + K`).

Mikato ya kubadilisha ukubwa hutumia vitufe halisi `code:20` na `code:21` (XKB `<AE11>` na `<AE12>`), bila kujali herufi zilizochapishwa kwenye kibodi. Kwenye kibodi za US vitufe hivi ni `-` na `=`; kwenye kibodi za Kijapani (JIS) ni `-` na `^`; kwenye kibodi za Kihispania ni `'` na `¡`. Kwenye JIS, `Super + ^` ni `Super + Equal`, ilhali `Super + Shift + -` (ambayo huandika `=`) ni `Super + Shift + Minus`.

## Ubao wa kunakili unaotumika kila mahali

| Kifunguo cha Mkato                  | Kazi              |
| ----------------------- | --------------------- |
| `Super + A`           | Chagua vyote katika programu zinazotumia `Ctrl + A`    |
| `Super + C`           | Nakili    |
| `Super + X`           | Kata (si katika terminali)    |
| `Super + V`           | Bandika    |
| `Super + Ctrl + V`           | Kidhibiti cha ubao wa kunakili    |

Kawaida kwenye Linux, unahitaji `Ctrl + Shift + C/V` kunakili na kubandika katika terminali na `Ctrl + C/V` kufanya hivyo kila mahali pengine. Mikato hii iliyounganishwa ya ubao wa kunakili ya Omarchy hufanya kazi kila mahali.

| Kifunguo cha Mkato              | Kazi                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Picha ya skrini                      |

| `Super + Ctrl + Print Screen` | Toa maandishi hadi kwenye ubao wa kunakili |

Unaporekod skrini, kifunguo cha mkato kwanza huuliza sauti unayotaka, kisha huanza kurekodi. Kibonyeze tena kusimamisha. Tazama [picha za skrini na kurekodi](12-screenshots-recording.md) kwa maelezo.

Chaguo zote za kunasa pia zinapatikana chini ya _Trigger > Capture_ katika menyu ya Omarchy (`Super + Space`).

## Tmux

Kitufe cha kiambishi awali ni `Ctrl + Space` (`Ctrl + B` pia hufanya kazi). Unaweza kubadilisha vifungo hivi katika `~/.config/tmux/tmux.conf`.

### Paneli

| Kifunguo cha Mkato                  | Kazi              |
| ----------------------- | --------------------- |
| `Prefix + v` | Gawa paneli kando (wima) |
| `Prefix + h` | Gawa paneli chini (mlalo) |
| `Prefix + x` | Ua paneli |
| `Prefix + z` | Geuza kuza paneli (skrini nzima) |
| `Alt + Enter` | Gawa paneli chini (bila kiambishi awali) |
| `Alt + Shift + Enter` | Gawa paneli kando (bila kiambishi awali) |

### Vitendaji vya mpangilio wa Tmux

Vitendaji hivi lazima viendeshwe ndani ya kipindi cha Tmux.

| Amri | Kazi |
| ------- | -------- |
