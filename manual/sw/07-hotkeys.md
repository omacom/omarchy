# Vitufe vya Mkato

Unaweza kuona vifunganisho vyote vikuu vya kibodi kwa `Super + K` (vifunganisho vya Tmux kwa `Super + Alt + K` na vifunganisho vya Herdr kwa `Super + Ctrl + K`).

## Ubao wa kunakili wa jumla

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Super + C`           | Nakili    |
| `Super + X`           | Kata (si katika terminali)    |
| `Super + V`           | Bandika    |
| `Super + Ctrl + V`           | Kidhibiti cha ubao wa kunakili    |

Kwa kawaida kwenye Linux, unahitaji `Ctrl + Shift + C/V` ili kunakili na kubandika katika terminali na `Ctrl + C/V` ili kufanya hivyo kila mahali pengine. Vitufe hivi vya mkato vya ubao wa kunakili vilivyounganishwa vya Omarchy hufanya kazi kila mahali.

## Kunasa

| Hotkey              | Function                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Picha ya skrini                      |
| `Super + Ctrl + Alt + C`            | Picha ya skrini (picha hiyo hiyo, kwa kibodi zisizo na kitufe cha Print Screen) |
| `Super + Ctrl + C` | Menyu ya kunasa |
| `Alt + Print Screen`            | Rekodi skrini                     |
| `Super + Print Screen` | Kiteua rangi |
| `Super + Ctrl + Print Screen` | Uchukuaji wa maandishi hadi ubao wa kunakili |
| `Super + Alt + [` | Fanya ufunikaji wa webcam kuwa mdogo zaidi wakati wa kurekodi |
| `Super + Alt + ]` | Fanya ufunikaji wa webcam kuwa mkubwa zaidi wakati wa kurekodi |
| `Alt + Shift + L` | Nakili URL ya sasa kutoka webapp au Chromium |
| `Alt + Shift + D` | Pakua video iliyo kwenye ukurasa wa sasa hadi `~/Videos` |
| `Super + Ctrl + X` | Anza/simamisha udikteti (inahitaji _Setup > Defaults > Dictation_) |
| `Right Alt` / `F9` | Udikteti wa push-to-talk (inahitaji Voxtype au Superwhisper) |

Kwa kurekodi skrini, kitufe cha mkato kwanza huuliza sauti unayotaka, kisha huanza kurekodi. Kibonyeze tena ili kusimamisha. Tazama [picha za skrini na kurekodi](12-screenshots-recording.md) kwa maelezo.

Chaguo zote za kunasa pia zinapatikana chini ya _Trigger > Capture_ katika menyu ya Omarchy (`Super + Space`).

## Tmux

Kitufe cha kiambishi awali ni `Ctrl + Space` (`Ctrl + B` pia hufanya kazi). Unaweza kubadilisha vifunganisho hivi katika `~/.config/tmux/tmux.conf`.

### Vidirisha

| Hotkey                  | Function              |
| ----------------------- | --------------------- |
| `Prefix + v` | Gawanya kidirisha kando (wima) |
| `Prefix + h` | Gawanya kidirisha chini (mlalo) |
| `Prefix + x` | Ua kidirisha |
| `Prefix + z` | Badilisha ukuzaji wa kidirisha (skrini nzima) |
| `Alt + Enter` | Gawanya kidirisha chini (bila kiambishi awali) |
| `Alt + Shift + Enter` | Gawanya kidirisha kando (bila kiambishi awali) |
| `Alt + Escape` | Ua kidirisha (bila kiambishi awali) |
| `Ctrl + Alt + Arrows` | Hamia kati ya vidirisha |
| `Ctrl + Alt + Shift + Arrows` | Badilisha ukubwa wa vidirisha |

### Vitendakazi vya mpangilio wa Tmux

Vitendakazi hivi lazima viendeshwe ndani ya kipindi cha Tmux.

| Command | Function |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Unda mpangilio wa dev wenye kihariri, AI, na terminali |
| `tdlm <ai> [<second_ai>]` | Unda mpangilio wa dev kwa kila saraka ndogo |
| `tsl <count> <command>` | Unda mpangilio wa swarm wenye vidirisha vingi |
