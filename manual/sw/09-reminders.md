# Vikumbusho

Omarchy ina njia iliyojengewa ndani ya kuweka vikumbusho rahisi vinavyotegemea kipima muda cha kuhesabu nyuma na vyenye ujumbe. Unaweza kufanya hivi kupitia `Super + Ctrl + R`, kuona vyote vilivyowekwa kupitia `Super + Ctrl + Alt + R`, na kufuta vyote kupitia `Super + Ctrl + Shift + R`. Kila kitu kinapatikana pia kupitia _Anzisha > Kikumbusho_. Unaweza pia kutumia cli kwa `omarchy reminder 7 'Tea ready'`.
