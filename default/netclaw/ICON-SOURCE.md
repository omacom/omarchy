# NetClaw application icon

`applications/icons/netclaw.png` is John Capobianco’s NetClaw application artwork, supplied through the [NetClaw App Store listing](https://apps.apple.com/us/app/netclaw/id6800859524) and included at his request. Retrieved on 2026-09-10 from Apple’s artwork CDN at 256 × 256 pixels. Copyright © 2026 automateyournetwork.

The desktop entry uses `Icon=netclaw`; per-user provisioning installs the PNG in the standard hicolor icon theme. No custom menu renderer or icon-font glyph is required.
