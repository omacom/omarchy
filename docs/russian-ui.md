# Русский интерфейс (паттерн, ждёт обвязки)

> Статус: словарь и контракт ниже готовы, но шелл пока не читает `OMARCHY_UI_LANGUAGE` и не грузит словарь — шаги переключения заработают после QML-обвязки (по образцу #10776 или решению #7284). Не обещает рабочий свитч сегодня.

Целевая механика: меню Quickshell Omarchy говорит по-русски. Язык интерфейса следует за локалью десктопа: когда `LANG` или `LANGUAGE` начинаются с `ru`, подписи меню, системное меню и месяцы/дни календаря показываются по-русски. Остальные языки остаются на английском.

Можно задать язык только для Omarchy, не трогая остальную систему:

```bash
export OMARCHY_UI_LANGUAGE=ru-RU  # русский
export OMARCHY_UI_LANGUAGE=en     # английский
```

Переменную в `~/.config/environment.d/omarchy.conf` + перелогин — и навсегда. ID команд меню, имена скриптов и приложений не переводятся, поэтому хоткеи, автоматизация и сторонние расширения совместимы. Новые пункты меню пиши с английским `label`, русское соответствие — в `shell/i18n/ru_RU.js`, новые ключи коммить туда же.

Строки (242 ключа) — из живого русского пака (вычитан носителем): меню, панели, OSD. Механика — по образцу китайского `zh_CN.js` (#10776).
