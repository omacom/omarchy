# Omarchy 术语表 (Glossary)

| 英文词条 (English) | 简体中文 (zh_CN) | 适用场景与上下文备注 |
| :--- | :--- | :--- |
| **Setup** | 设置 | 系统设置根分类 / 初始配置 |
| **Settings** | 设置 | 系统与应用偏好设置 |
| **Defaults** | 默认应用 / 默认值 | 默认浏览器、终端、编辑器配置项 |
| **Style** | 外观 | 主题、字体、背景等外观样式配置 |
| **Theme** | 主题 | 桌面色彩与控件主题 |
| **Background** | 背景 | 桌面壁纸与背景图 |
| **Font** | 字体 | 等宽字体与界面字体 |
| **Network** | 网络 | 网络控制面板与菜单入口 |

| **Bluetooth** | 蓝牙 | 蓝牙控制面板与设备管理 |
| **Audio** | 音频 | 音频输入输出控制面板 |
| **Display** | 显示 | 显示控制面板与屏幕参数 |
| **Monitor** | 显示器 | 物理显示器硬件 |
| **Power** | 电源 | 电源管理面板 |
| **Battery** | 电池 | 电池状态与百分比 |
| **Power Profile** | 电源模式 | 节能 / 平衡 / 高性能切换 |
| **Install** | 安装 | 安装软件或组件 |
| **Remove** | 卸载 / 移除 | 卸载应用 / 移除插件与网络条目 |
| **Update** | 更新 | 检查并更新组件 |
| **System** | 系统 | 电源、锁屏、会话管理 |
| **Lock** | 锁定 | 锁定屏幕 |
| **Suspend** | 挂起 | 睡眠/待机状态 |
| **Hibernate** | 休眠 | 写入磁盘休眠 |
| **Reboot** | 重启 | 重新启动计算机 |
| **Shutdown** | 关机 | 关闭计算机电源 |
| **Logout** | 退出登录 | 注销当前用户会话 |
| **Confirm** | 确认 | 确认对话框肯定动作 |
| **Cancel** | 取消 | 确认对话框否定动作 |
| **Close** | 关闭 | 关闭窗口或面板 |
| **Save** | 保存 | 保存配置 |
| **Search** | 搜索 | 菜单及下拉框搜索 |
| **No matches** | 没有匹配项 | 搜索无结果空状态 |
| **Nothing here yet** | 这里还没有内容 | 初始空状态 |
| **Connected** | 已连接 | 网络与蓝牙已连接状态 |
| **Disconnected** | 未连接 | 设备未连接状态 |
| **Pair** | 配对 | 蓝牙设备配对 |
| **Forget** | 忘记 | 忘记设备 / 忘记网络 |
| **Enable** | 启用 | 启用插件或服务 |
| **Disable** | 禁用 | 禁用插件或服务 |
| **Workspace** | 工作区 | 桌面虚拟工作区 |
| **Terminal** | 终端 | 终端仿真器 |
| **Browser** | 浏览器 | 网页浏览器 |
| **Editor** | 编辑器 | 代码编辑器 |
| **Plugin** | 插件 | Omarchy 扩展插件 |
| **Package** | 软件包 | 软件包管理条目 |
| **Keybindings** | 快捷键 | 键盘快捷键速查 |
| **Screensaver** | 屏幕保护 | 屏保展示与触发 |
| **Screenshot** | 截图 | 捕获屏幕截图 |
| **Screenrecord** | 录屏 | 屏幕视频录制 |
| **Transcode** | 转码 | 媒体文件格式与分辨率转码 |
| **Share** | 分享 | 快捷分享文件、文字、二维码 |
| **Toggle** | 开关 | 快捷操作子菜单：系统开关集合 |
| **Speed Test** | 测速 | 网络与磁盘性能测速面板与快捷操作 |
| **Measure again** | 再次测量 | 测速完成后重新测量动作 |
| **Clipboard** | 剪贴板 | 剪贴板历史与管理 |
| **Emoji** | 表情符号 | 表情选择器 |
| **Reminder** | 提醒 | 提醒事项工具 |
| **DNS Provider** | DNS 提供商 | 网络面板 DNS 切换 |
| **Output Device** | 输出设备 | 音频播放设备 |
| **Input Device** | 输入设备 | 麦克风录音设备 |
| **Brightness** | 亮度 | 显示器与键盘背光亮度 |
| **Text Size** | 文字大小 | 界面全局文字缩放 |
| **Scale** | 缩放 | 显示器分辨率缩放 |
| **Back to today** | 回到今天 | 日历面板快速定位当天 |
| **Pin / Unpin** | 固定 / 取消固定 | 托盘图标状态固定 |
| **Show / Hide** | 显示 / 隐藏 | 托盘图标显隐切换 |
| **Prepaid credits** | 预付额度 | AI 编程 Agent 余额与额度 |
| **Limits** | 限额 | 会话与周期速率限制 |
